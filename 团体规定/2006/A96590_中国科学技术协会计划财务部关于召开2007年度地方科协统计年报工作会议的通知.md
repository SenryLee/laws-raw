# 中国科学技术协会计划财务部关于召开2007年度地方科协统计年报工作会议的通知

## 中国科学技术协会计划财务部关于召开2007年度地方科协统计年报工作会议的通知（科协计发计字[2006]75号）

各省、自治区、直辖市、副省级城市科协办公室（计划财务部），新疆生产建设兵团科协办公室：

根据中国科协统计工作计划安排，经研究，定于2006年9月25日至28日召开2007年度地方科协统计年报工作暨统计培训会议，会期4天，9月25日至26日召开统计年报工作会议，9月27日至28日统计培训。本次会议委托青海省科协承办。现将会议有关事宜通知如下：

**一、**会议的主要内容：

1. 总结和表彰2006年度地方科协统计年报工作；

2. 布置2007年度地方科协统计年报工作；

3. 讲解年报统计报表和汇总软件；

4. 统计业务培训。

**二、**参加会议人员及要求：

请各省、自治区、直辖市、副省级城市科协和新疆生产建设兵团科协负责综合统计工作的部门负责人和具体工作人员各1名参加会议，并于2006年9月20日前将会议回执传真至青海省科协办公室。

**三、**报到方式：

报到时间：2006年9月24日，全天报到。

报到地点：青海省西宁市建国路61号西宁大厦 （从西宁火车站乘1路、22路、40路、101路在西宁大厦站下车即到）
