# 中国科学技术协会关于举办科技期刊与科技社团发展研讨会的预备通知

各有关全国学会、有关期刊出版单位：

为了发挥科技期刊对科技社团和学科发展的促进作用，探讨学会主办期刊与科技社团工作、学科发展之间相互促进、共同发展的机制，中国科协拟于2006年12月中旬举办科技期刊与科技社团发展研讨会。现将有关事项通知如下：

**一、**会议主题

科技期刊与科技社团发展

**二、**参会要求

请各全国学会负责人、学会主办期刊负责人，科技期刊从业人员及有关专家、学者根据会议主题积极提交论文，参会资格根据论文入选情况确定。

**三、**组织方式

由中国科协学会学术部主办，中国金属学会承办。

**四、**时间、地点

2006年12月中旬在北京举行。

**五、**会议征文

1．研讨内容

（1）科技社团主办期刊的体制改革

科技期刊和科技社团如何贯彻落实《中共中央国务院关于深化文化体制改革的若干意见》和《新闻出版总署关于深化出版发行体制改革工作的实施方案》。

（2）科技社团主办期刊与科技社团的关系

从行政、经济、业务指导、合作等角度分析，探讨科技社团主办期刊与科技社团之间的关系及相互影响。

（3）科技社团主办期刊与学科发展的关系

2．论文要求

本次会议入选论文将于2006年底收入中国科协学会学术部主编的2006年科技出版学术交流活动论文集（书名待定）正式出版，征文具体要求见附件2。

**六、**其它

1．会议报名截至时间为2006年11月24日，请按时提交会议回执及论文。

2．会议正式通知将于12月初发出。

附件2

科技期刊与科技社团发展研讨会征文要求

为做好本次会议的学术交流工作，现将征文具体要求通知如下：

**一、**论文征集要求

（一）论文所反映的信息和学术成果须为作者原创、未公开发表过，每位作者限投一篇论文，请勿一稿多投。

（二）论文请勿涉及保密内容；请作者确保论文内容的真实性和客观性，文责自负。

（三）论文投送截止日期为2006年11月24日（当地邮戳为准）。论文作者需填写并提交会议回执。

（四）无论论文入选与否，均不退还来稿及相应软盘。

**二、**论文格式要求

（一）论文需报送全文，文稿请用word录入排版。字数不超过5000字。打印稿和电子文本各1份。

（二）论文应完整扼要，涉及主要观点的图片、曲线和表格不能缺少。如稿件内容不清或文章篇幅超长等原因，编辑有权删改。

（三）论文结构请按下列顺序排列：

1．大标题（第一行）：三黑字体，居中排。

2．姓名（第二行）：小三楷字体，居中排。

3．作者单位或通信地址（第三行）：按省名、城市名、邮编顺序排列，用小三楷字体。

4．关键词：需列出4个关键词，小三楷字体。第1个关键词应为二级学科名称。学科分类标准执行国家标准（GB/T13745－92）。

5．正文：小四号宋体。文中所用计量单位，一律按国际通用标准或国家标准，并用英文书写。文中年代、年月日、数字一律用阿拉伯数字表示。

6．参考文献：文章必须有参考文献。“参考文献”4字作为标题，字体五黑，居中，其他字体五宋。文献著录格式如下：

（1）著作：作者姓名.书名.出版社名，出版年月，页码（如有两个以上作者，作者间用逗号分开）

（2）期刊：作者姓名.文章名.期刊名，年份，卷（期）、页码。

7．作者简介：请在参考文献之后附作者简介。“作者简介”请用字体五黑左起顶格排，后空一格，接排。作者简介字体五宋，100字以内，包括姓名、工作单位、电话、传真、电子信箱等，如作者为中国科协所属全国学会会员，请列出参加的全国学会名称、中国科协个人会员登记号。
