# 全国妇女联合会办公厅关于召开全国省区市妇联主席工作会议的通知

## 全国妇女联合会办公厅关于召开全国省区市妇联主席工作会议的通知（妇厅字[2006]10号）

各省、自治区、直辖市妇联，新疆生产建设兵团妇联，计划单列市、省会城市妇联，解放军总政治部、武警部队政治部，中直机关妇工委、中央国家机关妇工委，全国妇联机关各部门、各直属单位：

全国妇联定于2006年7月5日至7日在吉林省长春市召开全国省区市妇联主席工作会议。会期两天半。

**一、**会议主题

充分发挥妇联组织作用，团结动员广大妇女积极投身社会主义新农村建设。

**二、**参会范围

全国妇联主席、副主席、书记处书记；各省区市妇联主席及办公室主任；新疆生产建设兵团妇联主席；各计划单列市、省会城市妇联主席；各直辖市1名区（县）妇联主席；解放军总政治部、武警部队政治部有关负责同志各1人；中直机关妇工委、中央国家机关妇工委负责同志各1人；全国妇联机关各部门及各直属单位1名主要负责同志。

**三、**报到时间

7月4日全天

**四、**报到地点

吉林省长春市南湖宾馆

**五、**其他事项

1、7月4日晚20：00召开预备会，请各省区市妇联主席，解放军总政治部、武警部队政治部有关负责同志，中直机关妇工委、中央国家机关妇工委负责同志准时参加。

2、请于6月20日前将参会人员名单报全国妇联办公厅（请各省区市妇联将本省区市参会人员名单统一报送）；请于6月29日前将抵达长春市的时间、航班（车）次传真至吉林省妇联，以便安排接站。

3、7月7日下午开始返程。因正处旅游旺季，请在本地预订返程票；确需在吉林省预订返程票的，请提前10天告知吉林省妇联，并传真身份证复印件。

4、会议不安排随行人员住会。
