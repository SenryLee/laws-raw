# 中国网球协会关于2015年耐克全国网球青少年排名赛(陕西杨凌站)补充通知

各参赛单位及运动员：

2015年NIKE全国网球青少年排名赛U16第11-12站、U12第6站将分别于6月15日至28日、6月29日至7月12日在陕西杨凌青少年网球学校举行。现将有关事宜通知如下：

一、报名：

执行《2015年全国网球项目竞赛规程》，报名方式为自行网上报名；提前两天报到和赛前练习；报名网址：www.imcta.cn(咨询电话：4008—981—081)。

二、签到：

U16(第11站)

单打预赛签到时间：6月14日(星期日)下午14:00—16:00；

双打签到时间：6月16日(星期二)上午9:00—11:00；

单打正选赛签到时间：6月16日(星期二)下午14:00—16:00；

U16(第12站)

单打预赛签到时间：6月21日(星期日)下午14:00—16:00；

双打签到时间：6月23日(星期二)上午9:00—11:00；

单打正选赛签到时间：6月23日(星期二)下午14:00—16:00。

U12(第6站)

第一排位赛签到时间：6月28日(星期日)14:00—17:00；

第二排位赛签到时间：7月1日(星期三)14:00—16:00 ；

第三排位赛签到时间：7月4日(星期六)14:00—16:00 ；

排名赛签到时间：7月7日(星期二)14:00—16:00 。

三、比赛场地：陕西杨凌青少年网球学校(陕西杨凌产业路农高会B馆)，

室内丙烯酸材质硬地。

四、比赛用球：Dunlop – Fort。

五、住宿地点和食宿标准：

杨凌国际会议中心酒店

住宿标准：220元/天/双人间

餐费标准：120元/天/人

酒店地址：(中国陕西杨凌新桥北路1号)

联 系 人：姚老师

电 话： 18189159255 / 029—87031909 / 87031616(传真)。

六、交通指引：自行到达住宿地点(交通指引可拨打18189159255姚老师)

杨凌国际会议中心酒店位于渭惠路与新桥路交汇处。 距离杨凌火车站约1.7公里，距离杨凌汽车站约2.1公里； 距离西安咸阳国际机场约78公里。

1)、飞机，西安咸阳国际机场→机场大巴车→咸阳南汽车站换乘杨凌班车→抵达杨凌汽车站→乘出租杨凌国际会展中心酒店；

2)、高铁，出发地→西安北站→杨凌南站(高铁站)→出租杨凌国际会展中心酒店。(或者选择出发地直达杨凌南站)

3)、普通列车，出发地→杨凌镇站乘→坐出租车杨凌国际会议中心酒店。

4)、自驾车→陕西境内后上西宝(西安至宝鸡)高速，至杨凌高速收费站下，第一个红绿灯左转，直行至下一个十字路口红绿灯即杨凌高新酒店十字路口右转，前行路过两个红绿灯左转十字路口即是杨凌国际会展中心酒店。
