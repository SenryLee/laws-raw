# 中国林学会2015影像自然中国摄影比赛征稿通知

由中国林学会与中国绿色时报社联合主办的“2015影像自然中国摄影比赛”征稿了。

一、比赛组别设置

按参赛作品内容，比赛分为四个类别：野生动物类（鸟类除外）、野生鸟类、野生植物类和自然景观类。

二、奖项设置

1. 野生动物类、野生鸟类、野生植物类和自然景观类各设：

一等奖1名，获奖证书+奖金2000元（税前）

二等奖3名，获奖证书+奖金600元（税前）

三等奖6名，获奖证书+两年24期《森林与人类》杂志（价值432元）

纪念奖15名，获奖证书+一年12期《森林与人类》杂志（价值216元）

2. 获奖者所获奖金税费由主办单位代扣代缴。

3. 获奖名单将于2015年6月在《中国绿色时报》、《森林与人类》杂志、中国林学会网站及相关媒体发布。《中国绿色时报》、《森林与人类》杂志将选登部分优秀作品。

三、参赛作品要求

1. 参赛作品必须作者亲自摄制，可使用软件在不改变作品原貌的情况下做必要的后期处理（包括转换为JPEG格式，以及转格式之中的色彩微调），但不得对原始影像进行删改、添加、合成等技术调整。

2. 参赛作品须为数码照片，彩色、黑白不限，格式要求为JPEG，文件长边不小于2000像素，单幅、组图均可。参赛作品以电子邮件发送或光盘邮寄，不接受冲印照片。入围作品需要提交原作品（主办方会另行通知），照片要求大于4M，并保留完整的EXIF信息。

3. 参赛者可以提交不同作品参与不同组别的比赛。自2012年1月1日后刊发在《森林与人类》杂志上的作品均可参赛，参赛者可只填写参赛表格无需再发送照片。

四、参赛作品提交

1.下载参赛表格并详细填写。可从中国林业新闻网（www.greentimes.com）、中国林学会官网（www.csf.org.cn）和森林与人类杂志新浪博客（http://blog.sina.com.cn/senlinyurenlei）下载参赛表格，并在参赛表格中清楚填写拍摄地点（省、市、县）、拍摄时间（年、月、日）和所拍摄的内容，通过作品介绍展示图片背后的故事与关联知识。［点击下载］

2. 即日起开始接受参赛作品，截止时间为2015年4月30日。作品可通过电子邮件发送或邮寄光盘。

以“拍摄人-作品名称-联系电话-详细地址-邮编”作为文件名称，将作品和参赛表发送至比赛指定邮箱：yxzrzg@163.com ；或邮寄到：（100714）北京市东城区和平里东街18号国家林业局中国绿色时报社《森林与人类》编辑部刘艳丽收，电话：010-84238272，010-84238676。

五、组织机构

（一）主办单位：中国林学会、中国绿时报社

（二）协办单位：国家林业局摄影协会

（三）承办部门：中国绿色时报社《森林与人类》编辑部、中国林学会科普部

（四） 参赛咨询：中国绿色时报社《森林与人类》编辑部电话：010-84238272、84238676

六、主办单位声明（请参赛者仔细阅读）

1. 主办者尊重并保障参赛作品的著作权，而由参赛人的原因所造成的著作权纠纷由参赛人自行解决。

2. 本次比赛不收参赛费，所有参赛作品均不退还。

3. 所有参赛作品的版权均归原版权所有人所有，且在照片使用中享有署名权；主办方无意的署名遗漏情形可以获得免责。

4. 凡投稿参赛者即视为授权主办单位拥有该作品之使用权。主办单位将参赛作品用于科普公益宣传以及与本次比赛相关的评审、宣传、网站展示等时，不再另行支付稿费。若需将参赛作品用于主办单位旗下正式出版物或网站，将按相关稿费标准支付稿酬。
