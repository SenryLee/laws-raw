# 中国科学技术协会关于举办中国科协系统领导干部研究班的通知

各位学员：

为贯彻落实胡锦涛总书记在纪念中国科协成立50周年大会上的讲话精神，进一步提高科协系统领导干部科学发展能力，促进科协事业更好更快发展，经中国科协领导同意，定于今年4月举办中国科协系统领导干部研究班。现将有关事项通知如下：

**一、**参加人员

中国科协机关各部门、各事业单位主要负责人，各省区市、副省级城市、部分省会城市科协党组书记或主要负责同志。

**二、**时间和地点

时间：2009年4月8-14日，时间7天。

地点：中国浦东干部学院。

**三、**内容和方式

培训内容包括坚持科学发展观，增强党性修养；当前国内外经济形势与对策；科技创新与科协文化建设；现代管理理念与领导艺术；科技人才培养与海外高层次人才引进；基层组织建设与建设科技工作者之家。

研究班以课堂讲授为主，辅以现场教学、分组研讨和大会交流。研讨提纲见附件1。

**四、**有关要求

1. 请结合本地区、本部门、本单位近年来有特色、效果好的某项工作，从经验、做法、体会、建议等方面准备一份典型材料，字数不限，于4月3日前将电子版发送中国科协组织人事部。

2. 请围绕研讨内容准备好发言提纲。

3. 研究班结束后，提交一份总结，可以根据培训内容和研讨提纲，结合自身工作，选取一个具体角度撰写，不少于2000字。请于5月15日前将总结电子版发送中国科协组织人事部。

**五、**其他事项

1. 4月7日（周二）全天在中国浦东干部学院图书信息中心一楼注册中心报到。注册中心24小时值班，分机电话：021-28288918、28288919。浦东干部学院位置图见附件2。

2. 请学员准备2寸正面免冠彩色照片4张。

3. 请学员自备正装一套。

4. 请学员自行购买往返车机票。若需安排接站，或有特殊饮食要求，请提前与会务组联系。

附件1

中国科协系统领导干部研究班研讨提纲

围绕“学习贯彻胡锦涛总书记“12?15”讲话精神、推进科协事业更好更快发展”主题，进行研讨。

研讨提纲：

1. 如何发挥科协特色和优势，为保持国民经济平稳较快增长和促进社会和谐稳定作贡献？

2. 如何以科技工作者为本，切实为科技工作者提供优质高效服务？

3. 如何进一步搭建平台，推动科普资源共建共享？

4. 如何加强科协基层组织建设，增强科协组织的凝聚力和影响力？
