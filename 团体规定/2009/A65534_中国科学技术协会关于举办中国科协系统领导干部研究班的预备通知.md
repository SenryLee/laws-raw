# 中国科学技术协会关于举办中国科协系统领导干部研究班的预备通知

机关各部门、各直属单位，各省、自治区、直辖市、副省级城市科协，部分省会城市科协，新疆生产建设兵团科协：

为贯彻落实胡锦涛总书记在纪念中国科协成立50周年大会上的讲话精神，进一步提高科协系统领导干部科学发展能力，促进科协事业发展，经中国科协领导同意，定于今年4月举办中国科协系统领导干部研究班。现将有关事项通知如下：

**一、**参加人员

中国科协机关各部门、各事业单位主要负责人，各省区市、副省级城市、部分省会城市、新疆生产建设兵团科协党组书记或主要负责同志。

**二、**时间和地点

时间：2009年4月8-14日，时间7天。

地点：中国浦东干部学院。

**三、**培训方式

研究班安排课堂讲授、现场教学、分组研讨和大会交流。培训内容和研讨提纲见附件1。

**四、**有关要求

1．请参加培训人员，将本地区、本部门、本单位近年来有特色、效果好的某项工作，从经验、做法、体会、建议等方面准备典型材料一份，文字不限，将电子版于4月3日前发送至中国科协组织人事部。

2．围绕研讨内容准备发言提纲。

3．研究班结束时，提交一份总结，可以根据培训内容和研讨提纲，结合自身工作，选取一个具体角度撰写，不少于2000字。

**五、**其他事项

1．参加培训人员往返差旅费由所在单位承担，其他费用由中国科协组织人事部负责。

2．请参加培训人员填写《中国科协系统领导干部研究班人员报名表》（附件2），于2009年3月17日前传真至中国科协组织人事部，并将报名表电子版发送电子邮箱。

附件1

中国科协系统领导干部研究班培训内容和研讨提纲

围绕“学习贯彻胡锦涛总书记“12·15”讲话精神、推进科协事业更好更快发展”主题，进行培训和研讨。

培训内容：

1. 坚持科学发展观，增强党性修养；

2. 当前国内外经济形势与对策；

3. 科技创新与科协文化建设；

4. 现代管理理念与领导艺术；

5. 科技人才培养与海外高层次人才引进；

6. 基层组织建设与建设科技工作者之家。

研讨提纲：

1. 如何发挥科协特色和优势，为保持国民经济平稳较快增长和促进社会和谐稳定作贡献？

2. 如何以科技工作者为本，切实为科技工作者提供优质高效服务？

3. 如何进一步搭建平台，推动科普资源共建共享？

4. 如何加强科协基层组织建设，增强科协组织的凝聚力和影响力？
