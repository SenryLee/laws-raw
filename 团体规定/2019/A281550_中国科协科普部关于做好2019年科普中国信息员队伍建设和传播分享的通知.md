# 中国科协科普部关于做好2019年科普中国信息员队伍建设和传播分享的通知

科协普函基字〔2019〕10号

各省、自治区、直辖市科协科普部，新疆生产建设兵团科协科普部：

为推进科普中国落地应用和科普中国e站转型升级，将科普中国信息员打造成为服务基层群众的"移动科普中国e站",切实打通科普传播的"最后一公里",助推公民科学素质跨越提升。现就做好2019年科普中国信息员队伍建设和传播分享等相关工作通知如下。

一、科普中国信息员定义

科普中国信息员（科普中国APP内简称科普员）是完成科普中国APP实名注册认证并经常性开展科普信息传播的用户。科普中国信息员要下载使用科普中国APP,通过微信群、QQ群、公众号等社交渠道将科普中国信息传递给周边群众，积极配合有关部门参与各类科技教育与传播普及活动。

二、工作目标

各有关单位要按照面向基层、专兼并重、服务全民的原则，综合利用各种手段建设科普中国信息员队伍，吸纳更多公众成为科学知识的倡导者、传播者、践行者，实现科普信息分类精准推

送，营造全民科学素质工作浓厚氛围。

三、主要任务

（一）宣传推广

各有关单位要结合工作实际，通过线上线下相结合的全方位宣传推广科普中国品牌，让广大群众深入了解科普中国优质内容资源、传播分享科普信息知识，引导公众注册成为科普中国信息员。

（二）注册认证

各有关单位要广泛组织动员科技工作者、科普中国e站管理员、社区居民、农村村民、医院医生等加入科普中国信息员队伍，指导有关人员根据《科普中国APP使用手册简介（3.16版）》（附件）的说明进行注册认证和传播分享。

（三）人员培训

中国科协科普部和中国科学技术出版社制作科普中国信息员培训视频供各地用于人员培训，并可根据省级科协需求适时派出培训讲师，原则上不参与地市级和县级培训。各级科协可在科普中国APP选择对应管理等级，查看本地区科普中国信息员队伍数量、活跃度等有关情况，要结合实际组织基层科协有关业务负责同志、科普中国信息员等进行培训交流活动，提高本地区科普中国内容资源传播分享能力。

（四）激励引导

中国科协科普部和中国科学技术出版社将定期发布各省科普中国信息员队伍建设和传播分享情况，并通过积分激励兑换、各类线上活动、宣传典型人物和案例等方式有效提升公众积极性，并计划于年底组织科普中国信息员年度研修交流活动，届时根据各省情况择优遴选。各有关单位要根据有关财政要求，探索建立本地区科普中国信息员队伍建设激励机制，对表现突出的单位和科普中国信息员要予以表扬，大力挖掘宣传本地区科普中国信息员的典型经验，以点带面推动科普中国信息员队伍良性发展。

四、有关要求

（一）加强组织领导。各有关单位要高度重视，将科普中国信息员队伍建设和传播分享作为科普中国e站转型升级、实现科普中国落地应用的主要抓手，结合本地实际，打破固化思维模式，统筹协调相关资源，有力推进相关工作。

（二）强化互联网思维。各有关单位要坚持用户思维和公众利益至上，强化激励动员、弱化行政干预，避免出现行政强订指标、强制下载注册、过后卸载删除、"僵尸粉"暴涨等情况。

（三）加强队伍管理。各有关单位要以有效发挥科普中国信息员作用为根本目标，以区域内科普中国信息员传播量和活跃度为主要评价导向，避免出现重建设轻管理、重数量轻质量的现象，杜绝形式主义、政绩工程。

（四）及时反馈沟通。各有关单位要认真总结科普中国信息员建设情况和工作成效，梳理总结典型经验，及时与科学普及出版社反馈问题建议、提供典型案例，共同提升科普信息化服务水平，更好满足公众需求。
