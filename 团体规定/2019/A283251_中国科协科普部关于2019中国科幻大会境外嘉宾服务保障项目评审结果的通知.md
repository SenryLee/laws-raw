# 中国科协科普部关于2019中国科幻大会境外嘉宾服务保障项目评审结果的通知

科协普函传字〔2019〕71号

各有关单位：

为深入贯彻落实《全民科学素质行动计划纲要实施方案（2016-2020年）》《中国科协科普发展规划（2016-2020年）》《中国科协2019年科普工作要点》，打造普惠创新、全面动员、全民参与的社会化科普大格局，繁荣科普科幻创作，促进中国科幻事业产业发展，中国科协科普部组织实施2019中国科幻大会境外嘉宾服务保障项目，通过申报评审方式遴选确定承担单位。

按照《中国科协科普部关于组织实施2019中国科幻大会境外嘉宾服务保障项目申报评审的通知》（科协普函传字〔2019〕64号）要求，经过项目申报、资格审查和专家评审，决定由中国科协新技术开发中心承担2019中国科幻大会境外嘉宾服务保障项目（评审结果见附件）。请项目承担单位严格按照项目合同和申报书的要求，认真组织实施项目，按期参加项目的部署沟通、中期检查、评估和验收工作。
