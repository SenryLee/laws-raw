# 中国细胞生物学学会关于发布《人胚胎干细胞》团体标准的公告

中细生发〔2019〕4号

根据国家标准化管理委员会、民政部制定的《团体标准管理规定》，现批准发布《人胚胎干细胞》团体标准，标准编号为T/CSSCR002- 2019， 本标准于2019年2月26日发布，自2019年8月26日起正式实施。

特此公告。

中国细胞生物学学会

2019年2月26日
