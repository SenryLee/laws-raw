# 中华全国供销合作总社关于保障农村商品质量安全严防供销合作社流通假冒伪劣商品的通知

各省、自治区、直辖市及计划单列市、新疆生产建设兵团供销合作社，中国供销集团有限公司及其相关成员企业：

农村商品质量安全，事关群众健康和合法权益，事关农村社会和谐稳定和乡村振兴战略实施。供销合作社作为农村现代流通的主导力量，在保障农村商品流通和安全有效供应方面肩负重要责任。为保障农村商品质量安全，坚决杜绝假冒伪劣商品经过供销合作社经营服务网络流入农村市场，现就有关要求通知如下：

一、严格农村消费品的质量管理，保障农村商品安全有效供应。要加强对所属连锁超市、便利店、食品门店等农村经营网点的商品质量管理，特别是要严把农村消费量大、直接关系农民身体健康的食品、日化用品等商品品类的“出口关”，坚决杜绝假冒伪劣商品通过供销合作社网络流入农村市场。要重点规范农村加盟店、村级便利店等质量管理薄弱环节的经营管理，统一品牌标识和经营标准，依托龙头企业提高商品统一配送率，强化商品货源管理，确保商品质量安全。支持系统流通企业根据农村居民消费能力和消费结构，通过开发自有品牌等方式，组织适销对路、质优价廉的商品，加大供应力度，推进安全可靠商品下乡进村，带动农村消费市场环境不断优化。

二、加强农产品市场的经营管理，提高农产品质量安全水平。要加强对所属农产品批发市场、农贸市场及各类农产品经营企业的经营管理，加快农产品检验检测和质量追溯体系建设，严格落实销售记录制度，如实记录相关信息，建立来源可追、去向可查、责任可究的信息链条。农产品市场、农产品电商平台要加强对经营主体的资质审查，禁止出现无证无照、进假售假、超范围经营等行为，帮助和指导经营主体建立商品质量控制体系，督促经营主体认真落实进货查验、索证索票和安全自查制度，确保采购销售的农产品来源合法、质量可控。基础设施落后、设施设备不符合质量安全规定的农产品市场，要抓紧进行改造提升。

三、推进放心农资供应，确保农民用肥安全。加快经营服务网络升级建设；大力发展现代农业服务中心、农资连锁经营、庄稼医院、直销直供、农资合作社等农资经营新业态；积极推进绿色农资行动，畅通放心农资下乡进村渠道，提高安全优质农资产品覆盖面。加快推进农资企业向现代农业综合服务商转型升级，创新经营服务模式，通过开展测土配方施肥、水肥一体化、统防统治、农技培训等农业社会化服务，引导农民科学合理使用农资，并提升其自我保护能力。加快推进肥料、农药、种子等主要农资产品质量安全追溯体系建设，实施全程可追溯管理，依托系统相关农资行业协会，加强行业自律和信用体系建设，确保供应农资的质量。

四、夯实流通网络建设基础，提升安全商品的供应能力。各级供销合作社要抓紧制定本系统流通网络建设规划，加快建设以县域为重点、物流配送中心为支撑，覆盖县、乡、村三级的流通网络，有效提升供销合作社在保障农村商品安全供应方面的主渠道能力。推动流通企业大力发展连锁经营，打造一批集仓储、运输、分拨、配送、信息、交易功能于一体的区域物流配送中心。发展具有配送功能的乡镇直营店，提高对村级网点的商品配送能力。依据各地乡村规划布局，新建和改造一批村级经营网点、综合服务社，开展农村商品连锁经营和综合服务。加快电子商务、大数据等信息技术应用，推动流通企业创新商业模式，加强与电商平台的对接融合，实现优势互补，建设面向农村的电子商务服务平台、网络和渠道，为农村提供安全、便利、实惠的消费环境。

五、强化组织领导，切实抓好商品质量安全工作。各级供销合作社要从推进乡村振兴战略实施的高度，增强责任意识，把商品质量安全工作摆在重要位置，切实抓好抓出成效，维护和擦亮“供销合作社”金字招牌，让老百姓放心、安心。要配备专门的工作机构和人员，建立健全长效工作机制，抓好日常监督管理，做好对所属流通企业商品质量的巡检和抽查工作。要加强对经营人员的教育培训，指导其树立和强化质量安全意识和诚信守法意识。要在各类农村网点大力宣传商品质量安全知识，提高农村居民的消费维权意识和识假辨假能力，营造良好的消费环境和氛围。流通企业要树立质量为先、信誉至上的经营理念，认真落实食品安全责任，建立严格的商品质量控制体系，细化优化业务流程，确保经营商品安全可靠。

中华全国供销合作总社
