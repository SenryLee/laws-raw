# 共青团中央关于认真学习王兆国同志在纪念《中国青年》创刊80周年座谈会上的讲话的通知

## 共青团中央关于认真学习王兆国同志在纪念《中国青年》创刊80周年座谈会上的讲话的通知（中青发[2003]32号　二○○三年十月二十八日）

共青团各省、自治区、直辖市委，军委总政治部组织部，全国铁道团委，全国民航团委，中直机关团工委，中央国家机关团工委，中央金融团工委，中央企业团工委：

在纪念《中国青年》创刊80周年座谈会上，中共中央政治局委员、全国人大常委会副委员长王兆国发表了重要讲话。王兆国同志在讲话中充分肯定了《中国青年》杂志80年来所取得的辉煌业绩，精辟总结了《中国青年》杂志的光荣传统、历史经验和精神财富，对新时期进一步办好《中国青年》杂志提出了明确要求。认真学习王兆国同志的讲话，对于全团深入贯彻落实党的十六大精神和十六届三中全会精神，进一步掀起学习贯彻“三个代表”重要思想新高潮，更好地推动团属文化事业的发展，巩固和扩大团的思想舆论阵地，具有十分重要的意义。各级团组织尤其是团的宣传思想文化战线的同志要认真学习，深刻领会，把讲话精神切实贯彻落实到实际工作中去，为开创青少年文化事业的新局面，为中国特色社会主义文化事业的发展作出新的贡献。

在纪念《中国青年》创刊80周年

座谈会上的讲话　　　

（2003年10月18日）　　

王兆国

同志们、朋友们：

今天，在党的十六届三中全会胜利闭幕、我国首次载人航天飞行圆满成功的喜庆日子里，我们欢聚一堂，召开这个座谈会，纪念《中国青年》杂志创刊80周年，回顾历史、总结经验，展望未来、明确方向，有着重要的意义。在这里，我首先向《中国青年》杂志社全体员工表示热烈的祝贺！向全体与会同志致以亲切的问候！向为这份杂志的发展呕心沥血、做出巨大贡献的老领导、老同志表示崇高的敬意和衷心的感谢！

党中央历来十分重视《中国青年》这份杂志，党的三代领导集体都曾对杂志的创办工作做出过明确的指示。今天，中共中央政治局常委李长春同志专门发来了贺信，大家一定要认真学习、全面贯彻中央的指示精神，发扬传统、与时俱进，团结和引导广大青年投身中华民族的伟大复兴，为中国青年事业的发展做出新的更大的贡献。

我曾经做过共青团和青年工作，与《中国青年》杂志社有过比较多的接触，对《中国青年》有着特殊的感情。正如刚才几位同志在发言中所讲的，《中国青年》是一本具有光荣传统、辉煌历史的杂志，我们的青年时代都是在这本杂志的启迪、教育和引导下度过的。一本青年杂志能够延续80年，和中国革命风云变幻的历史交织在一起，和一代又一代中国青年的命运结合在一起，创造了值得称道的辉煌业绩，必定有独到的历史经验值得总结和提炼，必定有宝贵的精神财富需要继承和发扬。

对于《中国青年》的光荣传统、历史经验和精神财富，可以简要地归结为三句话：

第一句话，始终坚持正确的舆论导向，服从服务于党和国家的工作大局，是《中国青年》80年成长的主线。在80年的历史中，《中国青年》始终满腔热情地宣传党的路线、方针、政策，鼓舞和激励了一代又一代青年投身新民主主义革命，投身社会主义革命和建设，投身改革开放的伟大实践，成为我们党教育青年、引导青年的坚强阵地。《中国青年》是中国青年运动的一部分，是中国共青团事业的一部分，也是我们党的事业的一部分。历史经验表明，只有自觉融入到党领导的伟大事业之中，《中国青年》才有生存的基础和发展的舞台，才能始终保持旺盛的生机与活力。

第二句话，始终走在时代的前列，紧紧把自己的命运与国家和民族的命运结合在一起，是《中国青年》80年最鲜明的特色。在大革命的日子里，党的早期领导人恽代英、萧楚女、邓中夏、张太雷等在上海创办和编辑出版了《中国青年》，以大无畏的革命精神，在青年中传播和宣传马克思列宁主义，唤醒了一批又一批青年积极投身革命。建国后，在毛泽东、周恩来、邓小平等老一辈革命家的亲切关怀下，《中国青年》积极响应党的号召，引领广大青年在社会主义革命和建设中立足本职岗位、建功立业成才。特别是在“文化大革命”结束后拨乱反正的关键时期，在“真理标准”讨论等一系列重大问题上，《中国青年》发挥了重要的作用。十三届四中全会以来，《中国青年》按照江泽民同志提出的要求，在团结和引导青年沿着党指引的中国特色社会主义道路奋勇前进方面，做出了积极的贡献。实践反复证明，只有始终在党的指引下，走在时代前列，与国家民族同呼吸、共命运，《中国青年》才能得到党的高度信任，才能得到包括广大青年在内的人民群众的衷心喜爱。

第三句话，始终为青年服务，努力构建中国青年的精神家园，是《中国青年》80年不变的使命。《中国青年》为青年提供的，主要是思想文化和道德情操方面的精神食粮。通过不断推出青年英模人物、为青年树立人生标杆，《中国青年》实践了为青年服务、构建青年精神家园的诺言。丁佑君、向秀丽、安业民、雷锋、王杰……，一个又一个典型，正是通过《中国青年》走向广大青年，影响和带动了几代青年的健康成长。毛泽东同志“向雷锋同志学习”的题词，就是为《中国青年》“学雷锋”专辑而写的，并将学雷锋的活动在全国范围持续开展起来。这种服务还体现在与青年共同探讨人生等方面，二十世纪八十年代初，由《中国青年》发起的人生观问题大讨论，影响了当时整整一代人。所有这些说明，只有坚持不懈地用毛泽东思想、邓小平理论和“三个代表”重要思想武装教育青年，引导和教育青年树立正确的世界观、人生观和价值观，《中国青年》才能更加切实地服务青年、团结青年、凝聚青年。

今天，面对新世纪新阶段的新形势和新要求，《中国青年》要继承优良传统，坚持与时俱进，不断形成新的局面、创造新的业绩，必须进一步明确以下三点。

第一，要牢牢把握正确的政治方向。本世纪头20年，是我国经济发展的一个重要的战略机遇期，全面建设惠及十几亿人口的更高水平的小康社会，是一个宏伟的目标，也是一项艰巨的任务。在党中央的坚强领导下，在团中央的直接指导下，团结和引导青年投身于全面建设小康社会的伟大事业，是《中国青年》在新的历史时期的重要使命。要完成这一光荣使命，最重要的是要认真学习、深刻领会“三个代表”重要思想，坚持以“三个代表”重要思想统领整个办刊工作，努力用“三个代表”重要思想去教育青年、引导青年，把青年的思想和认识进一步统一到党和国家的战略部署上来，把青年的智慧和力量进一步凝聚到全面建设小康社会、实现中华民族伟大复兴的宏伟目标上来。

第二，要坚持突出面向青年的办刊宗旨。奋发进取、昂扬向上的一代又一代青年，是《中国青年》赖以生存和发展的肥沃土壤。只有深深地扎根于中国青年之中，《中国青年》才能始终保持来自青年、又服务青年的本色。必须看到，每一代青年都有自己的光彩，每一代青年也有不同的特点。今天的青年一代，是伴随着我国改革开放的历史进程成长起来的一代新人，他们有着强烈的竞争意识、民主观念、创新精神和较高的科学文化素质。要服务好今天的青年一代，首先就要了解青年一代，研究青年一代，真正做到有的放矢地解决他们思想上的困惑，切切实实地帮助他们走上健康正确的人生道路。在实现全面建设小康社会的历史进程中，《中国青年》只有坚持服务当代青年的成长成才，不断满足当代青年的精神需求，才能真正成为当代青年的良师益友。

第三，要始终保持奋发进取的精神状态。80年的辉煌已成历史，《中国青年》要继续走过未来漫长的道路，青春长驻、长盛不衰，最根本的就是要始终保持奋发进取这么一股劲头。在当前建立和完善社会主义市场经济体制的历史条件下，如何在风云变幻的市场挑战面前闯出一条新路，是《中国青年》面临的重大课题和艰巨任务。希望同志们在成绩和荣誉面前保持头脑清醒，居安思危、未雨绸缪；在困难和挑战面前不沮丧、不气馁，增强信心，迎难而上，勇敢地肩负起自己的职责，积极探索，锐意进取，与时俱进，开拓创新。只要大家同心同德、共同努力，《中国青年》就一定会拥有更加光明的前景和美好的未来。

同志们，胡锦涛同志在今年7月25日接见团中央新一届领导班子成员时强调指出：“共青团事业的发展正处在一个新的历史起点上。”我相信，《中国青年》一定会珍视80年宝贵的精神财富，在以胡锦涛同志为总书记的党中央领导下，以邓小平理论和“三个代表”重要思想为指导，全面贯彻党的十六大精神，努力贴近生活、贴近实际、贴近青年，始终站在时代的前列，引领广大青年在全面建设小康社会的历史进程中再立新功、再创伟业！
