# 中国科学技术协会关于召开中国科协系统地方科协综合统计年报工作会议的通知

## 中国科学技术协会关于召开中国科协系统地方科协综合统计年报工作会议的通知（科协计发计字[2008]138号）

各省（自治区、直辖市）、副省级城市、计划单列市科协计财部（办公室），新疆生产建设兵团科协办公室：

为认真做好中国科协系统地方科协综合统计年报工作，经研究，定于12月15-17日在湖北省武汉市召开地方科协综合统计年报工作会议。现将有关事宜通知如下：

**一、**会议的主要内容

1. 总结2008年度综合统计年报工作；

2. 安排2009年度综合统计年报工作；

3. 讲解新修订的统计制度和统计报表；

4. 讲解新修订的统计报表填报软件。

**二、**会议时间、地点

会议时间：2008年12月15-17日，14日全天报到；

报到地点：湖北省武汉滨湖大厦（武汉市武昌区东湖路325号湖北省博物馆对面）

**三、**参加会议人员

请各省级科协，副省级、计划单列市科协，新疆生产建设兵团科协统计工作负责人和统计工作人员各1人参加。

**四、**其他事项

1. 本次会议将进行统计报表填报软件培训，请各单位自带笔记本电脑；

2. 本次会议承办单位为湖北省科协。请各单位将会议回执于2008年12月8日之前，传真至湖北省科协信息中心；

3. 为减轻承办单位的会费负担，会议将按国家规定标准收取一定费用。

4. 联系人及电话
