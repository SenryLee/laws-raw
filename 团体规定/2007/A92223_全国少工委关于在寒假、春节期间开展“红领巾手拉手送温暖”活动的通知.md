# 全国少工委关于在寒假、春节期间开展“红领巾手拉手送温暖”活动的通知

各省、自治区、直辖市少工委：

2007年寒假、春节将至，配合全团开展的“真情助困进万家，爱心奉献促和谐”活动，为使所有需要帮助的少年儿童特别是那些农村留守少年儿童、进城务工人员子女和家庭困难的少年儿童感受到少先队组织对他们的关怀，让那些需要帮助的老人、残疾人感受到红领巾对他们的关心，用实际行动为社会和谐作出贡献，全国少工委决定2007年寒假、春节期间，在广大少先队员中广泛开展“红领巾手拉手送温暖”活动。现将有关事宜通知如下。

**一、**活动主题

“爱心手拉手，和谐共成长”

**二、**活动内容

1.开展“手拉手送温暖行动”。深入开展“手拉手关爱留守儿童行动”和“城市少年儿童与进城务工人员子女手拉手”等活动，通过开展“制定一份爱心计划、结交一位手拉手小伙伴、写一封手拉手联谊信、为手拉手小伙伴寄送一张自制新年贺卡或一份新年礼物、同过一次手拉手主题队会”等“五个一”活动，促进城市少年儿童与农村少年儿童的群体交流与互动，增进了解、互帮互助，共同快乐成长。东部发达地区少先队组织要积极开展为对口支援地区的留守少年儿童和贫困少年儿童捐助活动，赠送一批书籍、文具等学习和生活用品。

2.开展“雏鹰送温暖小队”活动。依托“雏鹰假日小队”，突出地方特色，力争在每一个省会城市、地（市）级城市和县城组织万支、千支和百支“雏鹰送温暖小队”，发动广大少先队员力所能及地帮助身边有困难的小伙伴，通过帮助补习功课、交流谈心、节日联欢、赠送学习用品等形式，送去少先队组织的温暖；组织少先队员深入社区困难家庭、残疾人家庭、军烈属家庭、敬老院、老年公寓，通过捐赠零花钱、帮助打扫卫生、义务写春联、书写新春寄语、开展文艺联欢活动等多种形式，力所能及地为身边困难群体送去温暖。农村少先队组织要发挥“留守小队”的作用，把农村留守少年儿童组织起来开展丰富多彩的假期活动，引导他们与小伙伴互帮互学、相互激励，并积极为身边困难群众提供力所能及的帮助。

3.开展“红领巾手拉手送温暖行动统一队日”活动。配合全团安排，发动城乡少先队组织利用寒假前最后一次队会时间，集中开展一次“红领巾手拉手送温暖行动统一队日”活动。以学校少先队大队或社区少先队大队为基本单位，组织少先队员广泛开展“红领巾义写春联帮困助学”活动、“红领巾跳蚤市场”义卖捐赠活动、“红领巾辉映夕阳红”敬老服务、“红领巾助残”等队日活动，推动形成“红领巾手拉手送温暖”活动的高潮。

4.各级少先队组织要积极争取和动员各种社会资源，广泛开展为困难少年儿童送助学金、送学习生活用品等送温暖活动。在留守儿童集中的地区，少先队组织要号召广大少先队辅导员积极开展“两节家访”、“温暖热线”、与留守少年儿童结对帮教等活动，把团队组织的温暖送到需要帮助的少年儿童身边。

**三、**活动要求

一要高度重视，精心组织。“红领巾手拉手送温暖”活动是少先队组织长期开展的少年儿童能够做到、乐于参与的重要品牌活动，也是少先队组织参与和谐社会建设的重要举措。各级少先队组织要高度重视，及早安排，切实将这项活动开展好。各地少先队组织要在寒假前对少先队员的基本情况进行一次调查，对那些农村留守儿童、进城务工人员子女和其他家庭生活有困难的队员要做到心中有数。同时要发动少先队员对自己居住社区或临近社区的“五保户”、军烈属、残疾人的情况进行了解，制定为他们送温暖的计划。

二要突出重点，注重实效。要充分发挥基层少先队组织的作用，为需要帮助的困难少年儿童特别是农村留守儿童和进城务工人员子女送去关怀和温暖，通过深入农家和农民工家庭，就近就便、力所能及地为进城务工人员子女和农村留守学生小伙伴送去温暖。要以体验教育为基本途径，组织动员广大少年儿童积极参与“红领巾手拉手送温暖”活动，引导少先队员们自觉地为需要帮助的同龄人和社会上的弱势群体提供力所能及的帮助，让他们懂得互助友爱的道理，体验帮助他人的快乐，理解社会和谐的时代主题和中华民族的传统美德所具有的丰富内涵，提高他们的思想道德素质。

三要加强宣传，营造氛围。各地要充分利用广播、电视、报刊、网络等新闻媒体，特别是少先队队报队刊，大力宣传“红领巾手拉手送温暖”活动中的感人事迹、典型经验、成功做法和主要成效，使少先队员的好思想、好品行感召社会，影响成人，努力营造扶危济困、团结互助的良好社会风尚，为构建社会主义和谐社会作出积极贡献。

请各地在1月15日前将开展“红领巾手拉手送温暖”活动计划报全国少工委办公室。活动开展后，请及时将有关情况报团中央少年部（全国少工委办公室）宣教处。
