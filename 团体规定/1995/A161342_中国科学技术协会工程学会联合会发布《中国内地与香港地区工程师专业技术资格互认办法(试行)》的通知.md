# 中国科学技术协会工程学会联合会发布《中国内地与香港地区工程师专业技术资格互认办法(试行)》的通知

经主管部门批准，现将《中国内地与香港地区工程师专业技术资格互认办法(试行)》公布，自公布之日起试行。

凡需要办理工程师专业技术资格互认的单位或个人，可直接与中国科协工程学会联合会专业技术资格互认办公室联系，办理有关申报手续。

中国科学技术协会工程学会联合会

1995年3月10日

中国内地与香港地区工程师

专业技术资格互认办法(试行

)

**一、**总则

1、中国科学技术协会工程学会联合会(以下简称科协工程联)受中国科协委托组成工程师专业技术资格互认指导委员会(以下简称指导委员会)，作为中国内地和香港地区专业技术资格互认的中国内地的工作机构。

2、指导委员会下设专业技术资格互认办公室(以下简称资格互认办公室)，承办日常组织、协调和受理互认申请工作。

3、指导委员会按照双方签定的协议中规定的人员范围、专业范围和技术资格层次和相应的条件制定互认程序和互认条件。

4、本办法通过适当的方式，对外通告需要办理工程师专业技术资格互认的有关单位和人员。

5、指导委员会按照有关条件对申请工程师专业技术资格互认者进行审查，审查合格者发给互认合格证明文件，然后再由申请者持科协工程联的证明文件到香港工程师学会办理注册手续。

**二、**互认程序

1、我方资格互认办公室每年公布受理互认资格的具体时间、地点及截止日期。申请者到指定机构办理有关资格互认手续。

2、我方资格互认办公室对个人申报材料根据互认条件进行初审，然后将初审意见上报指导委员会，进行审定。

3、我方资格互认办公室对申请资格互认合格者发给由科协工程联认可的资格互认合格证明文件，证明文件加盖科协工程联主席印戳。资格互认办公室将互认合格者制成名单，并负责送交香港工程师学会。

4、香港工程师学会根据我方资格互认办公室签发的资格互认合格证明文件及送交的名单，进行验戳后办理注册手续。

5、申请资格互认未合格者，可申请复议。

**三、**互认申报条件

1、互认对象

原在中国内地工作，现在香港定居或已接受港方工作任务并由中国内地有关单位按规定条件和程序评定的具有高级工程师专业技术资格的专业技术人员。

2、互认专业(暂定)

机械设计专业

机械制造专业

工业工程专业

3、学历要求

申请者必须是经认可的大学本科毕业或在大学(学院)至少有八个学期的学习经历，并取得毕业证书。

4、外语要求

基本具有英语听、说、读、写的能力。

5、技术工作经历要求

从事本专业技术工作至少十年以上。

6、接受继续教育要求

接受本专业继续教育的时间不少于三个月。

7、申请费用

申请者必须预付所需一切申请费用，如申请未被接纳则部分或全部退还费用。

**四、**申请者需要提供的证明文件

1、在香港工作的证明或已接受香港方面任务的证明。

2、国家教育委员会承认的学历证书。

3、国家人事部认可的高级工程师专业技术资格证书。

4、从事技术工作的经历证明和接受继续教育的证明。

**五、**附则

1、互认申报条件中规定的七个条件必须同时具备。

2、申请者提供的文件，必须为经过证明有效的复印件。

3、互认合格者的名单报中国科协备案。

4、本办法由中国科协工程学会联合会负责解释。
