# 中华全国供销合作总社办公厅关于印发《供销合作社积极参与推进农膜治理工作方案》的通知

各省、自治区、直辖市、新疆生产建设兵团供销合作社，中国供销集团有限公司及相关成员企业，中国农业生产资料流通协会、中国再生资源回收利用协会：

加强农膜治理事关农业生产安全，事关我国生态文明和美丽乡村建设。习近平总书记对加强塑料污染治理作出重要批示，党中央、国务院就治理白色污染进行了一系列部署，今年9部门联合印发《关于扎实推进塑料污染治理工作的通知》（发改环资〔2020〕1146号，以下简称《通知》），明确了供销合作社参与推进农膜治理的工作安排。中华全国供销合作总社（以下简称总社）高度重视，为指导全系统积极参与到农膜治理工作中，结合供销合作社实际，研究制定了《供销合作社积极参与推进农膜治理工作方案》（以下简称《方案》，附件1），现印发你们，请认真组织落实。

参与农膜治理是供销合作社融入党和国家工作大局的必然要求，是深化综合改革、拓展为农服务领域的重要举措，各级供销合作社要切实提高政治站位，进一步增强责任感、使命感，将认真组织和推动本系统积极参与农膜治理作为落实中华全国供销合作社第七次代表大会精神的一项重要任务来抓，主动作为、创新实践、务求实效，努力使供销合作社在推进乡村振兴战略和促进生态文明建设中作出更大贡献。

《方案》从总体思路、基本原则、工作目标、主要任务、重点工作、推进步骤和保障措施等七个方面对系统参与农膜治理工作进行了部署指导，明确将“组织开展供销合作社农膜回收利用试点”，请各省级供销合作社和中国供销集团根据《方案》要求，抓紧组织本系统开展农膜治理试点的申报工作，于11月10日前将试点单位申报表（附件2）和本省贯彻落实的具体工作方案报总社经济发展与改革部，总社将根据各地申报的情况，制定试点工作细化方案，确保供销合作社参与农膜治理工作整体有序推进实施。

附件：1、供销合作社积极参与推进农膜治理工作方案

2、农膜治理试点单位申报表

## 供销合作社积极参与推进农膜治理工作方案

为深入贯彻落实党中央、国务院关于减少农业面源污染，保护和改善生态环境，促进农业可持续发展的战略部署，按照国家相关部委关于推进塑料污染治理、开展农膜回收行动等一系列工作要求，针对废旧农膜回收组织化程度不高、市场主体积极性不强、回收加工体系不健全等突出问题，为充分发挥供销合作社行业优势和组织优势，在促进农膜治理中发挥更大作用，结合各地实践经验和有效做法，就供销合作社参与废旧农膜回收利用制定如下工作方案。

一、总体思路

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实新发展理念，在发改、财政、农业农村、生态环境等部门指导支持下，供销合作总社组织全系统积极行动，统筹调动中国供销集团及骨干龙头企业相关力量，发挥农业生产资料供应和再生资源回收利用行业优势，依托供销合作社组织体系和基层为农服务网络，整合资源、拓展功能，创新机制、提高效率，打造供销合作社农膜供应、使用、回收、加工、利用产业体系，在地方党委政府统一领导下，通过政策引导、示范引领、分类推进，使供销合作社在推进标准化农膜使用、废旧农膜治理和促进农业绿色发展等方面发挥积极作用。

二、基本原则

--政府统一领导，部门合作联动。废旧农膜回收利用是一项复杂的系统工作，涉及多领域、涵盖多环节，仅靠一个部门或单位难以独立完成。必须落实属地管理责任，在党委政府统一领导下，协调农业、发改、环保、供销等多部门合作，建立联动机制，合力推进废旧农膜回收利用。

--财政支持引导，创新市场运作。废旧农膜回收利用具有较强的公益性，特别是农用地膜回收难度大，利用价值低，需要政府予以适当财政资金补贴弥补市场失灵。参与农膜回收利用的各类经营主体，要在政府政策支持下，积极创新运作模式，最大限度发挥市场化作用，降本增效，积极探索废旧农膜回收利用可持续长效机制。

--整合多方资源，明确工作重点。从农膜治理的目标导向、问题导向、结果导向着眼，立足行业优势，发挥合作经济组织独特作用，因地治宜找准供销合作社参与农膜回收利用工作的切入点、明确工作范围和职责定位，与相关部门密切协作，充分整合系统内外资源，构建符合当地实际的工作机制。

--示范引领带动，分类有序推进。供销合作总社加强顶层设计，依托中国供销集团和重点地区，开展典型引路、试点先行、分类推进。根据各地废旧农膜回收利用难易程度和工作基础，选择不同地区开展工作试点。认真总结经验做法，及时复制推广，有序推进系统农膜回收利用工作。

三、工作目标

用2-3年的时间，通过典型引路和全面推进，聚焦县域，以及棉花、玉米、马铃薯等特色农业产业，整合资源、拓展功能，构建起具有供销合作社特点的农膜供应、销售、推广、回收、加工、利用体系。在供应环节，发挥农资供应主渠道作用，搭建高标准农膜供应分销网络；在回收环节，依托供销合作社基层为农服务网点，改造和建设高效便利的废旧农膜回收网络；在加工利用环节，发挥再生资源回收利用行业优势，改造和建设布局合理的废旧农膜加工利用网络。

四、主要任务

（一）积极参与农业农村部地膜治理示范县建设。贯彻落实九部委联合印发的《关于扎实推进塑料污染治理工作的通知》精神，加强与农业农村部门的协作，积极推进农膜治理。支持内蒙古、甘肃和新疆供销合作社加大力度，指导本地区示范县供销合作社主动与农业农村部门沟通对接，充分发挥供销合作社优势，因地治宜，明确重点，积极承接具体工作，参与示范县农膜回收利用全链条或局部环节建设工作，助力示范县建立以旧换新、经营主体上交、专业化组织回收、加工企业回收等多种方式的回收利用机制，形成技术可推广、运营可持续、政策可落地、机制可复制的示范样板。推动示范县实现加厚地膜全面推广使用、回收加工体系基本建立、当季地膜回收率达到80%以上，率先实现地膜基本资源化利用。

（二）组织开展供销合作社农膜回收利用试点。综合考虑区域分布特点、工作基础条件和覆膜作物的代表性等，充分发挥供销合作社组织优势和行业优势，通过系统申报、省级推荐，选择部分有良好基础条件、工作积极性高的省、市、县实施单位，开展供销合作社废旧农膜回收利用试点建；支持中国供销集团组织中农、中再生等成员企业与地方供销合作社合作，围绕关键环节和重点领域，开展农膜回收利用产业链试点探索，形成典型经验和做法，在全系统推广复制。总社将积极争取国家发改委、农业农村部等部门对试点工作的指导和支持。

（三）推动供销合作社系统构建废旧农膜回收利用体系。各级供销合作社要把构建废旧农膜回收利用体系作为深化供销合作社综合改革、服务乡村振兴的重要内容统筹予以推进，并与实施供销合作社培育壮大工程，提升供销合作社再生资源回收利用产业有机结合。充分发挥全系统基层经营服务网点、农资和再生资源行业优势，供应标准化农膜，降低土壤农膜残留，减少环境污染；引导带动农民和各类新型农业经营主体科学规范使用高标准农膜，降低回收难度和成本；对使用完毕的农膜开展机械化捡拾、专业化回收；对回收后的农膜进行符合环保要求的加工处理，实现资源化利用。通过开展废旧农膜回收利用，进一步拓展供销合作社基层为农服务功能，提升为农服务水平，在环境污染防治、建设美丽乡村中做出供销合作社应有的贡献。

五、重点工作

（一）改造和建设高效便捷的废旧农膜回收网络。

1.工作内容：以供销合作社基层综合为农服务网点为载体，构建废旧农膜回收网络，指导县域供销合作社积极配合农业农村部门，开展专业化、组织化回收，健全当地废旧农膜回收利用体系。

2.实施主体：县级供销合作社为主。

3.具体做法：

--在当地党委政府，特别是农业农村部门的支持下，充分依靠“村两委”，拓展供销合作社农村基层网点为农服务功能，在原有的土地托管、配方施肥、统防统治、农机作业等农业社会化服务内容基础上，增加农膜回收业务，实现功能叠加。

--对现有回收网点实施标准化改造，完善经营管理流程，做到明码标价、店面整洁、堆放有序、及时转运，打造规范有序、整洁环保的回收示范网络，建设供销合作社区域农膜专业化回收体系。

--在有条件的地区推广农膜回收机具的应用，推广机械化、半机械化农膜回收，与农膜供应环节衔接，发挥供销合作社农资流通主渠道作用，加强农膜回收机具研发和技术集成，提供农机租赁和机械化回收服务。

--创新废旧农膜回收方式，探索“互联网+智能回收”等回收模式，开展现金收购，大力推行以旧换新、以物易物等回收方式，以先进的回收方式促进回收效率提升。

（二）改造和建设布局合理的废旧农膜加工利用网络。

1.工作内容：以供销合作社再生资源企业为抓手，推动废旧农膜加工和资源化利用体系建设，根据运输条件和废旧农膜回收数量，合理布局废旧农膜加工和资源化利用网点，提升废旧农膜资源化利用水平。

2.实施主体：中国再生资源开发有限公司、系统各级供销合作社所属再生资源企业及相关经营主体。

3.具体做法：

--发挥中国再生资源开发有限公司作用，推动废旧农膜加工和资源化利用体系建设。

（1）中再生公司加强与地方供销合作社合作，发挥龙头企业作用，有效挖掘原有资源条件，利用已有厂区或新建加工线，就近就地按区域集中开展废旧农膜资源化利用。

（2）在中再生公司系统内具备收集和加工能力的各基地园区布点进行废旧农膜回收和加工工作。依托公司在河北、山东、河南、重庆、四川、宁夏现有的基地园区，按照由分散到集中的方式，对农膜预处理环节网点进行建设、布局，将预处理好的农膜资源集中到公司在河南、四川的加工中心进行处理。

--各级供销合作社所属再生资源企业及相关经营主体积极推进废旧农膜资源化利用加工设备改造升级，提高废旧农膜资源化利用水平，扩大加工利用产能，对接下游加工利用企业，做到集中处置、科学处理、循环利用，避免二次污染。

--发挥中国再生资源回收利用协会作用，引导联合社会力量，推动行业内再生资源回收利用企业积极参与废旧农膜回收利用工作，加强与各地供销合作社的沟通联系，帮助引进相关农膜加工和资源化利用企业。

（三）搭建高标准农膜供应分销网络。

1.工作内容：以供销合作社农资流通渠道为依托，加强源头把控，推进高标准农膜生产、推广和销售，搭建高标准农膜供应分销网络。

2.实施主体：中国农业生产资料集团公司、系统各级供销合作社所属农资企业及相关经营主体。

3.具体做法：

--发挥中国农业生产资料集团公司行业龙头企业示范引导作用，推进高标准农膜供应。

（1）利用公司自有免检商标及先进农膜配方，生产、推广和销售新国家标准0.01mm地膜，在有条件的地区推进0.01mm以上加厚地膜的生产、推广和销售。加强监督管理，引导所属农资经营网点提供标准化农膜销售，严禁销售不合格农膜。

（2）探索建立农膜生产规范，成立行业自治组织，吸纳农膜生产企业在规范生产的前提下，纳入供销合作社供膜体系，建立生产企业白名单制度，引领农膜供应市场规范运行。

（3）在条件允许的情况下，并购（控股、参股）重组一批规模较大、质量稳定、技术先进、销售范围较广的高标准农膜生产厂，增强供销合作社主渠道生产供应能力，确保农膜生产使用标准化。

（4）增强产业链条紧密性，与回收环节有机衔接，通过以旧换新模式，推进标准化农膜供应。加强与供销合作社基层为农服务中心和废旧农膜回收利用企业的联合合作，探索形成农膜“标准化供应-标准化铺膜-标准化回收”模式，形成产业链闭环，由提供产品向提供服务转变。

（5）开展地膜回收率测试，探索最佳地膜厚度和配方方案。在新疆植棉地区，进行同配方0.01毫米、0.02毫米、0.03毫米、0.04毫米厚度对比实验和4种厚度情况下普通配方和新技术配方对比实验，对比不同厚度和配方的地膜回收效果及风化老化程度，探索最佳地膜厚度和配方方案；探索可降解地膜生产和使用。相关测试成果供国家有关部门参考。

--各地供销合作社所属农资企业及相关经营主体，通过对符合条件的生产厂家实行定点采购，指导规范厂家组织高标准农膜生产，确保承销的农膜厚度不小于0.01mm。

--发挥中国农业生产资料流通协会作用，动员联合社会力量，在全行业宣传推广高标准农膜的生产和销售，在供应环节减少、杜绝不合规农膜的产生，营造良好的行业氛围。

（四）在全系统范围内广泛开展废旧农膜回收利用宣传动员和交流培训。

1.工作内容：供销合作总社加强工作指导，以多种形式组织全系统开展工作交流，宣传推介典型经验。以中华合作时报社、中国供销合作网、声像中心等媒体平台、培训中心和各级供销合作社农业社会化服务网络、农业生产技术人才为依托，加强宣传培训，提高农民和各类经营主体对废旧农膜回收利用的认知度，引导规范农民使用加厚地膜、积极参与农膜回收。

2.实施主体：供销合作总社相关部门、所属媒体平台和培训中心、主管协会和各级供销合作社农技服务主体。

3.具体做法：

--总社及时传达废旧农膜回收利用方面的新政策、新要求，加强与发改、农业农村等部门的沟通互动，形成政策宣传合力。

--利用总社培训中心和各级供销合作社培训机构，加强先进覆膜方式和农艺措施的宣传、培训、推广示范，推进农膜覆盖技术合理应用，降低农膜覆盖依赖度，减少使用量，引导农民科学使用农膜，鼓励有条件的地区探索可降解农膜品种发掘和使用，推进农膜使用减量化、科学化。

--依托供销合作社县有运营服务中心、乡镇有服务平台、村有服务站点的农业社会化服务网络和农业生产技术人才，指导所在地基层供销社、农民合作社，严格执行农膜使用标准，提升农民和各类经营主体对标准农膜的认知度和接受度。

--充分利用总社中华合作时报社、中国供销合作网、声像中心和各级供销合作社官方网站等媒体平台，加大相关法律法规的宣传培训力度，提高广大农民对农膜回收行动的认识，引导规范农民使用加厚地膜、积极参与地膜回收，营造良好社会氛围。

六、推进步骤

--2020年9月底前，向系统印发《供销合作社积极参与推进农膜治理工作方案》，部署工作，启动试点申报。积极与国家发改委、农业农村部沟通，争取政策支持。

--2020年10月，指导全系统开展农膜治理试点工作，组织申报试点单位，研究谋划试点方案。

--2020年11月，组织会议培训，动员部署相关工作，指导省级供销合作社编制试点工作方案，明确工作重点和任务目标，启动废旧农膜回收利用试点建设。

--2021年上半年，跟踪系统工作进展情况，总结交流各地典型经验做法，及时研究推进下一步工作。

七、保障措施

（一）加强组织领导。建立由总社分管领导指导的推进废旧农膜回收利用工作机制，经济发展与改革部牵头，会同相关部局、中国供销集团、中国农业生产资料流通协会、中国再生资源回收利用协会等单位参加，共同推进有关工作。中国供销集团要指导相关成员企业加强与地方供销合作社的沟通联系，积极推进农膜治理试点工作。各级供销合作社要加强组织领导，把推进农膜治理用工作作为一项重要工作摆上议事日程，成立工作专班，明确职责，制定详细工作方案，按步骤有序推进，确保工作取得实效。总社将利用通报、信息简报等形式，定期总结宣传各地经验做法和工作进展情况。

（二）加大政策协调。总社利用“新网工程”资金，支持系统废旧农膜回收利用体系建设。对确定的废旧农膜回收利用试点加强指导，在资金投入方面予以倾斜；加强与国家发展改革委、农业农村部、财政部等部门的沟通协调，积极争取相关政策和资金支持；加强与国开行、农发行等金融机构的沟通协调，争取相关信贷支持。各级供销合作社要积极向地方党委政府汇报，争取把供销合作社纳入到参与当地废旧农膜回收利用工作中；积极参与政府购买服务工作，承接相关废旧农膜回收利用项目；加强与当地农业农村、发改、财政、生态环境、工信、住建、商务、文旅、市场监管等部门的沟通协调，争取相关支持。

（三）加强培训指导。充分发挥供销合作社系统农资、再生资源等行业协会作用，研究制定切实可行的废旧农膜回收利用方案。强化技术培训，加快新技术、新产品、新设备的示范推广，为农膜回收行动提供全程科技服务。加强对农膜回收专业化服务组织的技术指导，科学推进农膜回收、加工、再利用社会化服务。
