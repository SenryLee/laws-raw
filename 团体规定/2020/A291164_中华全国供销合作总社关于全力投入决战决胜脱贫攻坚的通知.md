# 中华全国供销合作总社关于全力投入决战决胜脱贫攻坚的通知

供销经字〔2020〕13号

各省、自治区、直辖市及新疆生产建设兵团供销合作社，中华全国供销合作总社各部局、中国供销集团有限公司及其成员企业、各直属事业单位、各主管社团：

2020年是全面打赢脱贫攻坚战收官之年。当前，脱贫攻坚已经进入全面总攻、决战决胜的关键时刻。为深入贯彻落实习近平总书记在决战决胜脱贫攻坚座谈会上重要讲话精神，充分发挥供销合作社行业特点和系统优势，全力投入决战决胜脱贫攻坚，中华全国供销合作总社（以下简称总社）现就有关工作通知如下。

一、提高政治站位，切实增强投入决战决胜脱贫攻坚战的责任感和使命感

习近平总书记在决战决胜脱贫攻坚座谈会上的重要讲话，统揽全局、高屋建瓴，站在实现“两个一百年”奋斗目标的历史高度，向全党全国全社会发出脱贫攻坚总攻动员令，吹响总攻冲锋号，具有很强的思想性、指导性和现实针对性，是决战决胜脱贫攻坚的根本遵循和行动指南。全系统要深入学习领会习近平总书记重要讲话精神,进一步提高政治站位、强化责任担当，切实把思想和行动统一到习近平总书记重要讲话精神上来，不折不扣地落实好党中央关于决战决胜脱贫攻坚的决策部署，确保如期完成脱贫攻坚目标任务。

供销合作社是为农服务的合作经济组织，是党和政府做好“三农”工作的重要载体。全力投入决战决胜脱贫攻坚，是供销合作社的重大责任和使命，是关键时刻践行宗旨意识、体现责任担当的重大考验，也是供销合作社提升为农服务能力和实力的重大机遇。全系统要立足全局增强使命感，把握职能增强责任感，聚焦任务增强紧迫感，以更加坚定的决心、更加有力的举措、更加精细的工作，推动脱贫攻坚各项政策举措落实落地。

今年是脱贫攻坚战最后一年，收官之年又遭遇疫情影响，各项工作任务更重、要求更高，必须集中力量，全力投入决战决胜脱贫攻坚。要以脱贫攻坚为统领，全面整合系统资源，压实脱贫攻坚责任，瞄准工作目标，抓住工作重点，加快补齐短板弱项，为脱贫攻坚全面收官作出新的更大贡献。

二、狠抓贯彻落实，高质量完成重点工作任务

（一）大力开展消费扶贫行动。加强贫困地区农产品产销对接，开展消费扶贫是供销合作社发挥流通网络优势，助力脱贫攻坚的重要途径。按照线上线下相结合的方式，线上依托“扶贫832平台”等各类电商平台，线下组织系统商贸连锁、农产品批发市场等流通企业设立消费扶贫专区专柜，构建扶贫产品线上线下销售体系，促进各类流通、电商企业与贫困地区建立长期稳定的供销关系。积极组织开展贫困地区农产品进机关、进企事业单位、进社区等活动，动员系统广大干部职工及全社会力量，通过“以购代捐”“以买代帮”等形式，集中购买贫困地区农产品。在高质量办好海南“冬交会”等各类展会基础上，打造具有供销合作社特色的展会品牌，更好的帮助贫困地区推介、展示、销售农产品。积极探索“联采联销”农产品洽谈交易方式，形成全系统农产品销售的整体合力，逐步提升供销合作社影响力、带动力。建立贫困地区农产品滞销快速响应机制，利用“供销应急通”平台，及时上传农产品供需情况，实现农产品供需双方互联互通。鼓励系统大型冷链物流企业、农产品批发市场在贫困地区布局建设仓储保鲜冷链物流设施。加快贫困地区县、乡、村三级配送网络建设，加强与第三方物流企业合作，减少中间环节，实现快递物流高效配送。

（二）全力建设运营好“扶贫832平台”。按照财政部、国务院扶贫办和总社联合印发的《政府采购贫困地区农副产品实施方案》要求，从供给、需求和平台三方面协同发力，举全系统之力共同建设运营好“扶贫832平台”。中国供销电子商务有限公司要持续优化平台功能，加快促进供应商入驻和商品上线，实现832个贫困县全覆盖；切实提高平台供需双方体验感，挖掘供应商供货潜能，激活预算单位采购潜力；根据脱贫攻坚阶段性重点任务，策划形式多样的主题销售活动，做好“三区三州”深度贫困地区、52个未摘帽贫困县等重点地区和重点产品的推介；统筹谋划“扶贫832平台”与“供销e家”、“国家贫困县名优特产品网络博览会”的对接融合。各级供销合作社要全力支持“扶贫832平台”建设，切实发挥主动性和创造性，加强与财政、扶贫等有关部门沟通汇报，形成工作合力，深度参与平台建设和运营，积极在“扶贫832平台”上采购农产品的同时，贫困地区供销合作社要主动做好供应商组织、商品推送、包装物流、质量把控等工作。

（三）认真做好定点扶贫和对口支援工作。各级供销合作社要按照中央关于脱贫攻坚“四个不摘”的要求和各级党委政府的统一部署，切实履行好定点扶贫责任，按照帮在要处、扶在难处、干在实处的要求，认真做好定点帮扶工作。把定点帮扶与帮扶县供销合作社改革发展共同谋划，把帮扶点作为综合改革的实验点，培育壮大帮扶县供销合作社实力，提升为农服务能力。按照尽锐出战的要求向定点帮扶地区选优派强扶贫挂职干部。加大对帮扶地区资金和项目投入力度，因地制宜发展扶贫产业，带动贫困户稳定脱贫。通过直接购买和帮助销售等方式构建长期稳定的产销关系，帮助贫困户实现持续增收。加大对帮扶地区贫困户技能培训力度，增强自我发展能力。总社将继续加大对潜山、寻乌、安远3个定点扶贫和对口支援县的帮扶，统筹整合资源，创新帮扶方式，巩固脱贫攻坚成效。

（四）聚焦深度贫困地区和52个未摘帽贫困县集中攻坚。各级供销合作社要继续推动资金、项目、举措向“三区三州”深度贫困地区和52个未摘帽贫困县聚焦倾斜，通过开展消费扶贫、产业扶贫、科教扶贫等，把深度贫困地区的农业社会化服务和商品流通服务作为供销合作社发展壮大的主战场，助力如期完成脱贫摘帽任务，实现可持续发展。鼓励支持中国供销集团联合系统龙头企业，探索建立扶贫协作产业联盟，采取更加灵活的市场化方式到深度贫困地区和未摘帽贫困县投资兴业，参与当地经济社会建设。总社财政专项资金、产业发展基金、基层组织发展专项资金将加大对深度贫困地区和未摘帽贫困县的支持力度。

（五）积极开展东西部扶贫协作。建立东西部供销合作社对口扶贫协作机制。东部地区供销合作社要加强与西部贫困地区的项目合作，根据贫困地区资源禀赋，组织系统有实力的龙头企业赴贫困县投资扶贫项目，完善销售贫困地区产品终端建设，助力西部贫困地区脱贫攻坚。充分利用好各类展示展销会，搭建东西部产销对接平台，展示推介西部贫困地区优质特色农产品，组织动员东部地区供销合作社积极购买西部贫困地区产品。推动东部地区社有龙头企业农业社会化服务和农产品加工能力与西部地区对接；支持和鼓励系统区域间建立扶贫协作联盟，促进贫困地区优质农产品资源与发达地区市场对接，实现合作共赢。

（六）努力克服疫情对脱贫攻坚的影响。要坚持在常态化疫情防控中加快推进各项扶贫工作，确保高质量完成决战决胜脱贫攻坚目标任务。充分发挥系统流通网络和渠道优势，组织好产销对接，多渠道解决受疫情影响导致的农产品卖难问题。充分发挥系统合力，积极采购和帮助销售湖北等地重要农产品。保障贫困地区和贫困户的农资供应，创新经营服务模式，提供技术指导、代耕代种、土地托管等社会化服务。大力支持扶贫产业发展，积极有序推进扶贫项目复工复产，不断提高扶贫产业发展水平和带贫减贫效益。积极推动就业扶贫，鼓励系统各类用工企业努力拓宽就业渠道、增加就业岗位，优先保障贫困劳动力就业。

三、加强统筹谋划，积极探索解决相对贫困长效机制

（一）实施供销合作社培育壮大工程。坚持把脱贫攻坚与服务乡村振兴有机衔接，将探索建立解决相对贫困长效机制与持续深化供销合作社综合改革统筹谋划，在相对贫困地区实施供销合作社培育壮大工程，以发展壮大县级供销合作社，健全基层组织体系，完善联合社指导服务体系和发挥社有企业支撑带动作用为重点，壮大相对贫困地区供销合作社组织基础，拓展经营服务领域，提升经营服务能力，提高组织带动水平，增强内生发展动力，加快建立为农民生产生活服务的综合平台。

（二）提升扶贫产业带动力。发挥供销合作社在棉花、茶叶、果品、食用菌、蜂产品、畜产品等领域的传统优势，围绕带动相对贫困地区特色农产品产业发展，培育发展一批大型龙头企业和新型农业经营主体，加强与农户的有效对接，在资金、技术、渠道等方面开展针对性帮扶。积极推进农村一二三产业融合发展，构建相对完整的产业链条，最大限度地将产业增加值留在相对贫困地区，持续稳定增加贫困群众收入。

（三）持续做好“志智双扶”。深入推进科教扶贫，充分依托系统科研院所、职业院校、行业协会以及社有企业等多方力量，加强对相对贫困地区农户和各类新型农业经营主体的科技和就业培训服务，提高自我发展能力，全系统力争用3年的时间培训干部群众30万人次以上。充分发挥供销合作社产业类别和经营主体众多优势，积极吸纳贫困群众就业，激发贫困群众脱贫致富的内生动力，构建“造血式”脱贫长效机制。对贫困家庭学生开辟绿色招生渠道，优先落实助学优惠政策，优先推荐和安排就业。

四、加强组织领导，为决战决胜脱贫攻坚提供坚强保障

（一）严格落实责任。各级供销合作社要认真落实脱贫攻坚责任，主要负责同志要亲自抓。坚持精准方略，认真研究制定全力投入决战决胜脱贫攻坚方案，确保党中央、国务院脱贫攻坚决策部署得到贯彻落实。总社扶贫工作领导小组成员单位要根据自身职责，加大工作力度，压实工作责任，确保各项任务目标高质量完成。

（二）完善激励督导机制。围绕脱贫攻坚加强专项督导，为打赢脱贫攻坚战助力护航。将系统扶贫工作纳入总社综合业绩考核内容，激励各地切实做好脱贫攻坚工作。把“督”与“战”结合起来，推动和督促有关单位抓好工作落实，对扶贫项目、资金实施情况进行跟踪问效。

（三）加强作风建设。强化扶贫领域作风建设，力戒形式主义、官僚主义，减轻基层负担。深入推进抓党建促脱贫攻坚，充分发挥基层党组织的战斗堡垒作用和党员干部的先锋模范作用。针对工作中的重点难点问题，要深入基层调查研究，推动工作落实。加大对扶贫挂职干部的关心关爱，在工作上加强指导，在生活上加大保障。

（四）加大脱贫攻坚宣传力度。做好脱贫攻坚政策解读，讲好中国减贫故事。营造系统上下参与扶贫的良好氛围，依托合作时报社、网站、声像中心等媒体平台，紧紧围绕供销合作社脱贫攻坚工作，广泛宣传报道系统、特别是基层一线脱贫攻坚先进典型和成功案例，讲好供销合作社扶贫故事。

中华全国供销合作总社

2020年4月15日
