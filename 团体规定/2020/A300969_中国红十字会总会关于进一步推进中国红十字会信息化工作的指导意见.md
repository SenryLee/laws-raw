# 中国红十字会总会关于进一步推进中国红十字会信息化工作的指导意见

各省、自治区、直辖市红十字会，新疆生产建设兵团红十字会，总会机关各部室、各直属单位：

为深入贯彻落实习近平总书记关于红十字事业重要指示精神，推动中国特色红十字事业高质量发展，充分发挥红十字会作为党和政府在人道领域联系群众的桥梁纽带作用，根据《中共中央关于加强和改进党的群团工作的意见》《中华人民共和国红十字会法》《中国红十字事业发展规划纲要（2020—2024年）》，现就进一步推进中国红十字会信息化工作，提出如下指导意见。

一、总体要求

（一）指导思想

坚持以习近平新时代中国特色社会主义思想为指导，围绕助力建设网络强国、数字中国，以推动全国红十字系统全面深化改革、实现高质量发展为主线，以实施创新驱动发展战略、加快数字化转型为牵引，按照“总会主导、上下联动、信息共享、业务协同”总体思路，着力推进全国红十字系统信息化工作统筹，着力推进信息化技术与红十字工作深度融合，着力推进全国红十字系统数据资源共享共用，通过信息化工作创新发展推动中国特色红十字事业高质量发展。

（二）基本原则

1. 统一指导，统筹推进。树立全国一盘棋思想，从红十字事业发展全局出发，加强对信息化工作统一指导，强化对信息化工作统筹管理，推进核心信息系统推广应用，全面提升红十字信息化工作科学化、标准化和体系化水平。

2. 因地制宜，分步实施。根据各地信息系统建设现状和未来业务发展需求，分步骤、分阶段推进红十字信息系统建设，试点先行、总结经验，分步推进、全面发展，实现信息系统在各级红十字会所有业务流程的全面覆盖。

3. 上下联动，协同共享。强化工作责任，明确职责分工，积极构建总会统一协调、各级红十字会主动作为的工作格局。加强总会与地方红十字会、地方红十字会与相关部门之间的联系互动，打破信息封锁，实现数据交互共享，充分发挥信息化整体效能。

4. 强化管理，保障安全。严格落实网络安全相关法律法规，强化关键信息基础设施和重要信息系统安全保障，加强数据安全管理和个人信息保护，提高网络安全应急处置能力和水平。

（三）工作目标

1. 总体目标

认真学习领会习近平总书记关于群团工作重要论述和红十字事业重要指示精神，全面贯彻落实“十四五”规划关于加强数字社会、数字政府建设，提升公共服务、社会治理等数字化智能化水平的相关要求，以推进信息化系统广泛应用为目标，以整合各级业务数据为核心，加强基础建设，建立标准统一、互联互通、安全可控的红十字会数据平台。利用大数据分析指导工作，提升红十字会信息化工作整体水平和管理能力。着力打造“数字红会”，推动全国红十字系统各项工作高效运转、公开透明，提升公信力，为中国特色红十字事业高质量发展提供有力支撑。

2. 阶段目标

第一阶段：梳理整合省级红十字会信息化资源，编制红十字信息化资源目录。制定统一、规范、兼容的红十字信息化工作标准。建设总会信息化系统和数据中台，开展与部分省级红十字会互联互通试点工作。

第二阶段：省级红十字会全部建成信息化系统和数据平台。通过数据中台，实现总会和全部省级红十字会信息化系统互联互通、数据共享和业务协同，通过大数据分析指导业务工作，有条件的可拓展至地市级红十字会。

第三阶段：总会和省级红十字会信息化系统拓展至县（市）级红十字会，建立全国红十字系统从总会到地方，从数据采集到分析应用，从信息发布到业务管理的大数据体系。

二、工作任务

（一）制定统一标准

参照国家标准、行业标准和地方标准，围绕信息基础设施、信息资源、应用服务、信息安全等，逐步制定统一的红十字信息化标准，构建框架合理、层次清晰、权威科学、规范完整的信息化标准体系，并做好与国家相关部门基础数据库和重大信息化工程之间的有效衔接。

（二）建立数据中台

总会牵头建立数据中台，以数据中台为依托，构建大数据中心，集成各级红十字会的各类业务数据，形成从采集、处理、分析、应用的全流程数据处理系统，实现全国大数据资源共享，为开展业务工作、研究决策和推进公开透明提供数据支撑。

（三）统一系统应用

加强灾害与物资管理系统、全国志愿服务信息系统、筹财管理系统、救灾指挥中心系统、中华骨髓库业务信息系统、中国人体器官捐献志愿登记管理系统、中国人体器官捐献案例报告管理系统、应急救护培训管理系统等总会核心业务系统在全国红十字系统的推广与应用。根据业务需求，不断优化各系统功能，拓展各系统应用范围和领域，完善管理制度和结构，实现核心业务系统运用范围全覆盖。

（四）推进系统迭代

地方红十字会要按照统一的信息化标准，积极推进本地信息化系统的建设、迭代，统一业务规则，优化业务流程，细化业务逻辑，规范业务操作，深入挖掘现有信息化系统潜力，通过合理升级改造，提高系统的兼容性、稳定性，实现与数据中台的数据交互。

（五）构建信息网络

加强信息网络建设，形成有利于数据共享、互联互通的基础环境，为红十字业务系统跨地区、跨层级、跨部门联动提供支撑。充分利用政务外网等成熟的专用网络，根据业务需求自上而下完成网络接入，构建贯通全国红十字系统的内、外网联动的纵向网络结构。推动各级红十字会与相关部门之间的横向网络对接，打破信息壁垒，实现部门之间系统对接与数据交换。

（六）强化网络安全

高度重视网络安全工作，严格遵守《中华人民共和国网络安全法》，成立网络安全领导机构，网络安全工作责任落实到人；严格落实等级保护等制度，加强网络与信息安全管理；建立健全网络安全责任制和信息通报机制，完善网络安全检查、风险评估等制度；制定网络安全事件监测预警与应急预案，组建应急处置技术支撑队伍，开展安全应急演练，不断提升网络安全态势感知、监测预警和应急处置能力；加强与公安、网信办等部门的协调联动，做好网络安全风险和事件的处置、反馈、备案工作，依法依规对网络攻击、失泄密等问题进行查处。

三、保障措施

（一）提高思想认识，加强组织领导

总会网络安全和信息化工作领导小组统筹协调全国红十字系统信息化工作各类重大事项，建立健全信息化工作机制，明确目标、责任和实施机构，加大工作督导力度。各级红十字会要高度重视信息化工作，充分认识信息化在红十字事业改革发展中的重要作用，切实履行主体责任，把信息化工作列入改革发展重要议程，加强研究和指导，主要领导亲自挂帅，靠前指挥。建立完善信息化管理工作机构，明确职责，确保各项举措落到实处。

（二）纳入发展规划，确保落实到位

要把信息化工作纳入红十字事业长远发展规划，积极争取政府信息化资源和资金支持。将信息化工作经费纳入预算管理，设立信息化专项资金，集中投入、持续支持、统一管理、专款专用，同时要加强资金使用监管。

（三）强化专业支撑，培养专门人才

充分依靠社会资源，发挥好外部专家团队的力量，根据红十字会工作特点，加强对红十字会信息化工作的研究和指导。注重人才培养，各级红十字会要积极发现和选配既熟悉信息化技术又了解红十字会业务工作的人才，为高质量开展工作提供保障。定期组织培训，提高全员信息化应用水平。

（四）完善管理机制，加强监督考核

各级红十字会要建立信息化工作管理制度机制，制定发展规划，完善保障措施。编制公共信息资源开放目录，建立公共信息资源开放保密审查机制，实现红十字会数据对社会有序开放，支持各类市场主体对数据资源的创新应用。将信息化建设成效列入各级红十字会年度工作考核内容，总会将加大对地方红十字会信息化工作的考核力度。及时总结推广典型经验，推进信息化建设工作更好更快地向前发展。

中国红十字会总会
