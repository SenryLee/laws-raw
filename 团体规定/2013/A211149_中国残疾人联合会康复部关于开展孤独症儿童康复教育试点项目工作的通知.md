# 中国残疾人联合会康复部关于开展孤独症儿童康复教育试点项目工作的通知

## 中国残疾人联合会康复部关于开展孤独症儿童康复教育试点项目工作的通知（康函（2013）10号）

北京、山西、内蒙古、吉林、福建、江西、河南、湖北、广东、重庆、陕西、甘肃省（区、市）残联康复部：

为加强孤独症儿童康复教育工作，中央财政安排专项彩票公益金4600万元，用于2013-2015年实施孤独症儿童康复教育试点项目。为规范项目实施，中国残联康复部组织孤独症儿童康复教育领域的专家、一线康复机构负责人、中国精协和康复管理人员组成的专家委员会，研究确定了资金的使用方向和相关技术标准。现就有关事项通知如下：

**一、**任务分配

根据全国孤独症儿童康复工作发展现状，本着选择不同区域、重点扶持中西部、当地已有机构具备较好基础条件且经扶持能够发挥区域技术资源中心作用的原则，确定了12个省（区、市）为试点项目省（区、市），有关任务分配见附件1。

**二、**扶持机构要求和遴选标准

接受资助的机构原则上必须是承担“七彩梦行动计划”贫困孤独症儿童康复项目或地方孤独症儿童康复项目的定点机构，机构成立时间不低于三年，“自强自律”创建活动达标机构可以作为参考条件。具体遴选标准见附件2。

**三、**资助标准和资金使用

资助标准为每个机构每年平均资助30万元，具体资助金额将由康复部组织专家根据各机构在职教师和受训孤独症儿童的规模、工作业绩等情况按比例进行资助。项目申报为每年一次，项目执行不合格的机构次年不能申报资助。

资金使用方向为人员培训和基础设备配备两方面，原则上人员培训经费占60%，基础设备配置经费占40%。人员培训内容包括基础培训（上岗培训）和继续教育培训（专项培训、讲座、论坛、学术交流等），培训教材由中国残联统一指定，培训机构由中国残联康复部指定相关的教学机构或康复协会承担。基础设备配备清单见附件3，各机构可根据自身情况选配。

**四、**申报程序

1. 各项目省残联康复部按要求组织申报和审核（资助机构申报表见附件4），并按照任务数进行初选后，统一于11月5日前上报中国残联康复部；

2. 中国残联康复部组织专家组，根据各地申报情况研究确定扶持机构名单和扶持资金额度，向社会公示5个工作日后，于11月30日前将补助资金下拨至项目省残联，并由各省残联拨付各机构实施项目。

附件2

孤独症儿童康复教育项目机构遴选标准（试行）

为实施孤独症儿童康复教育项目，遴选出符合条件的机构予以扶持，特制定本标准。

**一、**机构建设

（一）机构基础要求

1．孤独症儿童康复教育机构（以下简称“机构”）是为孤独症谱系障碍儿童提供专业康复服务的社会机构，一般要有独立法人资格，机构成立时间不少于三年，取得相关政府职能部门从业批准，符合国家对儿童医疗、康复和教育机构的相关要求。

2．开展孤独症儿童康复教育服务；向家长提供指导、咨询、培训和孤独症儿童的转介等服务。

（二）规模与场地环境

1．全日制在训孤独症儿童数20名以上。

2．机构设在安全区域内，所在场地具有安全保障设施及措施（遇突发事件易疏散）。室内外设计合理、通风良好、装饰适合孤独症儿童特点，有适合孤独症儿童活动的户外运动场地。

3．室内场地总使用面积达到200平米，功能分区包括集体训练室（面积达到60平米）、个别训练室（至少3间）、家长/儿童休息场所和专供儿童使用的卫生间；具备康复评估室、教师办公室、家长培训教室等功能区；提供儿童午餐的需有独立厨房操作间。

4.凡开设的相关课程，均配有相适应的教学场地。

（三）设备设施

1．配备开展孤独症儿童康复教育的基本教学设备。

2．根据儿童年龄段配备相应的玩教具。

3．凡开设的相关课程，均配有相应的康复及教学设备。

4．配有标准化和规范化的孤独症儿童康复评估工具C-PEP（中国大陆版）或PEP3（香港版）选其一，或其他公认的评估体系。

**二、**队伍建设

1．机构人员队伍主要包括专业教师、康复训练人员、保育员和行政管理、后勤人员等。配备的人员应热爱康复事业，具备奉献精神。

2. 配备专职业务主管，业务主管须具备大学及以上学历，从事孤独症儿童教育康复工作五年以上。

3．业务主管负责开展孤独症儿童的评估，制定康复教育计划，指导专业人员按照计划开展训练，针对受训儿童情况调整教学和训练计划和方法，组织开展教学质量评估。

4．按照专业教师和康复训练人员与在训儿童小于1：4的比例配备。专业教师须有有效教师证，具备大专以上学历，其中具备特殊教育、幼儿教育、医学、康复和心理专业背景的教师不少于60%。康复训练人员应具备大专以上相应专业学历并接受过相关专业培训。

5．专业教师和康复训练人员要累计参加超过60学时省级以上残联主办或委托专业机构举办的孤独症康复专业培训并考核合格，每年需接受继续教育培训超过30学时。

**三、**业务开展

1．为每个在训的孤独症儿童建立康复教育档案，内容包括：医院诊断证明（在三级甲等综合医院儿科或精神科确诊），入学评估，训练计划（包括学期计划、月计划和周计划），训练和活动记录，康复效果和教学评估，影像资料。

2. 根据评估结果对孤独症儿童制定并实施个别化教育计划。

3．个别训练要根据评估结果制定有针对性的训练计划。

4. 开展集体训练要根据受训孤独症儿童程度分级和年龄相近的原则分组教学

5．机构对在训孤独症儿童每半年进行一次康复效果评估，每月组织由康复专业人员、专业教师和家长共同参与的针对在训儿童情况和教学情况的交流，以合理调整和改进康复教育计划和目标。

6． 每年由残联组织专家对机构进行抽查评估，内容包括：专业教师的教学和康复训练，对孤独症儿童的效果评估和家长满意度调查问卷。

7．开展家长培训，传授孤独症儿童康复知识和方法，指导家长配合并在家庭开展训练；建立家长联系制度，记录在训情况与家长沟通反馈。

8、与相关专业机构建立联系，根据受训孤独症儿童的情况进行及时的转介。有转介记录，情况说明清楚，解释合理，得到家长认可和相关机构配合。

**四、**质量控制

1． 根据上级管理机构要求通过年检，上一年度无重大责任事故。

2. 按国家要求规范用工制度，落实相应保障；全部服务人员取得健康合格证。

3. 建立各项规章制度，包括卫生保健、安全管理、康复业务管理、财务管理、服务管理、档案管理、设备管理制度等，每年度进行检查和总结。

4．家长满意率达到80%，投诉率小于2%。

5．在训儿童建档率100%，内容完整率90%。

6．收费标准、岗位职责、服务流程等制度公示，接受公众监督。

7．生源稳定，在训半年以上儿童达到60%，一年以上达到20%。
