# 中国科协学会学术部关于推荐第十届光华工程科技奖评审专家的通知

## 中国科协学会学术部关于推荐第十届光华工程科技奖评审专家的通知（科协学函管字〔2013〕172号）

有关全国学会、协会、研究会秘书处（办公室）：

按照《关于开展第十届光华工程科技奖候选人推荐工作的通知》、《关于公示第十届光华工程科技奖候选人材料的通知》，第十届光华工程科技奖提名工作已进入中国科协遴选推荐阶段。现请你会按分组领域（见附件1）推荐1名专家作为评审专家组人选。评审专家推荐原则：

1. 学术水平保证原则。推荐的评审专家应为本领域权威专家，具备正高级职称，优先推荐中国工程院院士和中国科学院院士。

2. 同行评审原则。推荐的评审专家应与本届候选人学科领域一致或相近。

3. 回避原则。推荐的评审专家应避免与候选人有直接利益关系（如同一单位、直系亲属、师生关系等）。

4. 时间、地域保障原则。评审工作会议拟定于10月30日上午在北京举行，推荐的评审专家应能按时、全程参加评审。优先推荐北京地区的专家。

请你会接到通知后，积极联系、确定、推荐专家参与评审工作，并请按要求填写《第十届光华工程科技奖评审专家推荐表》（见附件2），于2013年10月22日前反馈至会务承办单位中国力学学会。如无法推荐专家，请于10月21日前反馈我部学会管理处。专家评审会议具体安排将另行通知。
