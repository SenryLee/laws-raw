# 中国科学技术协会学术部关于开展2013年度中国科协学会改革发展基础工程项目总结工作的通知

## 中国科学技术协会学术部关于开展2013年度中国科协学会改革发展基础工程项目总结工作的通知（科协学函管字〔2014〕4号）

有关学会、协会、研究会秘书处（办公室）：

为疏理2013年度中国科协学会改革发展基础工程项目成果，提炼项目承担学会改革工作经验，根据《中国科协项目管理办法（试行）》的要求，拟开展项目绩效总结工作。现将有关事项通知如下：

**一、**总结内容

1. 项目完成情况；

2. 绩效、创新点、亮点；

3. 重点工作、社会效果与媒体报道；

4. 项目实施取得的经验及存在问题；

5. 经费支出情况。

**二、**有关要求

1．总结项目目标完成情况

学会应加强对项目总结工作的组织领导，对照《项目合同书》的目标任务，总结好承诺完成的任务，对未能完成的任务要具体说明。

2．注重项目绩效的总结和分析

在开展项目总结时，应结合学会的实际，认真疏理和总结项目的重点工作、社会效果与媒体报道情况，深入分析和挖掘创新点、亮点和绩效，对项目成果进行提炼和评估，对项目效益进行归纳和展望。

3．按时报送总结报告

请有关学会于1月24日前提交总结报告纸质版和电子版（电子版发送到xuehuiguanli@cast.org.cn）。纸质文本要求一式三份，以A4开本打印，加盖学会公章和法定代表人签章。

总结报告提交情况将作为项目考核及今后审批项目的重要依据。总结报告内容将向社会公布。
