# 中国计划生育协会关于印发《中国计划生育协会青春健康工作五年规划（2014-2019年）》的通知

国计生协[2014]72号

各省、自治区、直辖市计生协，计划单列市、新疆生产建设兵团计生协：

10月30-31日中国计生协在上海召开了“生育关怀—青春健康”工作五年规划终期评估总结暨青春健康教育基地现场会，全面回顾和总结了第一个青春健康五年规划（2008-2013年）实施成果，发布了第二个《中国计划生育协会青春健康工作五年规划（2014—2019年）》，授予全国21个符合标准的青春健康俱乐部为中国计生协青春健康教育示范基地，宣布成立中国计生协青春健康专家组和师资团队。中国计生协常务副会长杨玉学在会上发表重要讲话，并强调全面推进青春健康工作常态化。

为全面推进青春健康工作在全国的常态化，进一步贯彻和落实上海会议精神，现将此次发布的《中国计划生育协会青春健康工作五年规划（2014-2019年）》印发给你们（附后），希望各地按照规划要求，因地制宜地制定本地的青春健康五年工作规划，确定年度工作重点；加强机制建设，将青春健康工作纳入协会常规工作，统一部署、要求、管理和考核；加强阵地建设，根据《中国计生协关于建议统一青春健康标识的通知》（国计生协[2012]58号）,建立和完善以计生协为主体的“青春健康俱乐部”；加强队伍建设，培养高素质的专家队伍、师资队伍和青年志愿者队伍，积极推进青春健康工作的科学化、规范化和可持续发展；加强项目化管理，以项目运作的方式推进青春健康工作。中国计生协将根据各地项目计划，加强监督评估，并为各地提供支持。

附件：中国计划生育协会青春健康工作五年规划（2014-2019年）
