# 中国农业机械学会关于举办“2014中国科协会员日暨2014中国农业机械学会工作研讨会”的通知

学会学字（2014）21号

我会各分支机构及相关省级农机学会：

兹定于2015年1月8-9日在北京举办“2014中国科协会员日暨2014中国农业机械学会工作研讨会”，现将有关事项通知如下：

一、会议时间、地点

2014年1月8日10:00～至9日14:00，北京宽沟雁栖山庄（北京市怀柔区雁栖湖雁青路21号,010-69666699）。

二、参加人员

中国农业机械学会各分支机构秘书长或代表，欢迎地方农机学会秘书长自愿参加活动。

三、会议报名、出发等

1. 请参加活动的人员务必于2014年12月26日下班前，以电话或邮件方式报名。

电话: 010-64882291；邮箱：csam@caams.org.cn，联系人：袁爱洁。

2. 请参会人员务必在1月8日10:00前到达中国农机院（北京市朝阳区德外北沙滩一号）新办公楼前，集体乘车前往。1月9日14:00，集体乘车返回到中国农机院。

3. 会议统一提供安排食宿，双人标间住宿。

4. 会期之外另需在京安排住宿的同志请电话联系秘书处。

四、会议内容

1. 听取对学会2014工作总结、2015工作计划意见建议；

2. 布置并交流各分支机构2014工作总结、2015工作计划；

3. 听取举办2015学术研讨会暨学会十届二次理事会的建议；

4. 介绍研讨开展2015年社会组织评估工作的初步计划；

5. 其他事项。

五、其他要求

1.请各分支机构认真做好2014年分会总结工作，内容包括年度主要工作成绩、综合数据（活动名称、活动时间和地点、活动次数、参加人数以及交流或会议发表的论文篇数等）、典型事例、经验体会和存在问题等。总结报告要求实事求是，突出重点。主要工作应有数据体现，所取得的工作成绩、效益及有关数据要翔实可靠，确保准确无误；典型事例要有导向意义；对存在问题的分析要客观。

2.请各分支机构认真做好2015年分会活动计划，内容包括2015年工作的指导思想、主要思路、计划和重点项目。具体要求：提出2015年工作的指导思想、工作要点和重点项目，要有整体性思路，避免具体工作的罗列，应在现有工作基础上有所创新、发展。

上述2014年分会工作总结和2015年分会工作计划（字数不限），请将文字版带至会上，并于会前将电子版发至学会邮箱：csam@caams.org.cn。
