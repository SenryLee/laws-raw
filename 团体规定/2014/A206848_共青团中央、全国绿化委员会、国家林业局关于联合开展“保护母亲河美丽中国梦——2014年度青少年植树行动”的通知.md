# 共青团中央、全国绿化委员会、国家林业局关于联合开展“保护母亲河美丽中国梦——2014年度青少年植树行动”的通知

## 共青团中央、全国绿化委员会、国家林业局关于联合开展“保护母亲河　美丽中国梦--2014年度青少年植树行动”的通知（中青联发[2014]5号）

各省、自治区、直辖市团委、绿化委员会、林业厅（局），各有关部门（系统）绿化委员会，中国人民解放军、中国人民武装警察部队绿化委员会，新疆生产建设兵团团委、绿化委员会、林业局，内蒙古、吉林、龙江、大兴安岭森工（林业）集团公司：

为认真贯彻党的十八大和十八届三中全会精神，教育引导青少年增强生态环保意识，积极参与植树造林和生态保护，为促进生态文明、建设美丽中国作贡献，共青团中央、全国绿化委员会、国家林业局决定抓住“保护母亲河行动”实施15周年的有利时机，牢牢把握“树”在“山水林田湖”整个生态体系中的本源作用，以植树造林为重点，开展“保护母亲河　美丽中国梦--2014年度青少年植树行动”。现将有关事宜通知如下。

**一、**活动时间

2014年全年，以3月至5月春季植树季为重点。

**二、**主要内容

1. 以两个统一行动周为抓手，广泛开展集中性植树护绿等生态环保活动。4月21日至4月27日，抓住植树造林有利时机，开展“全国青少年植树护绿周”活动，启动一批青年林工程和青少年绿色家园示范项目，各地统一行动，广泛动员青少年集中开展植树造林和植绿护绿活动。3月17日至23日，围绕世界森林日和世界水日两个重要环保纪念日，开展“全国青少年生态环保实践周”活动，发动各级团组织开展形式多样、青少年喜闻乐见的宣传教育和实践活动。

2. 结合全民义务植树运动，大力推进青少年身边增绿活动。以“县县青年林，村村青年路”为五年工作目标，组织青少年积极参与城乡绿化。通过城乡结对共建青年林（路）、“网上认养、网下种植”、种植纪念树、认养领养林木绿地、保护古树名木、生态监护等广覆盖、易参与的方式，在青少年中营造植绿、爱绿、护绿、兴绿的良好氛围。鼓励和引导公众利用城市的屋顶阳台、建筑外立面、室内空间等开展“立体植树种草”活动；利用农村道路、渠系两侧和闲置地、边角地、废弃地等，开展四旁植树活动，实现人人参与行动，绿化美化，共建生产、生活、生态协调的美好家园。

3. 围绕三个绿色，深化青少年生态环保工作。积极整合党政资源，依托合作伙伴捐建冠名纪念林、“微公益”募资造林等载体，支持和指导基层围绕江河湖泊流域，推进绿色工程建设。结合各地实际，广泛开展丰富多彩的流域性、地域性青少年生态环保宣传教育和实践活动，重点探索新媒体和文化载体运用，充分借助社会知名人士影响力，选树宣传生态环保典型，着力传播绿色理念。扩大青少年生态环保社团骨干培训和小额资助等项目覆盖面，开展全国性青少年生态环保社团调研，筹备成立中国青少年生态环保社团联盟，召开中国青少年生态环保社团年会，探索建立全国性的社团互动机制，培育青少年绿色队伍。

**三、**有关要求

1.高度重视。开展“保护母亲河--2014年度青少年植树行动”是贯彻落实党的十八大和十八届三中全会关于生态文明建设伟大战略的实际行动，是组织动员广大青少年参与美丽中国建设、引领全社会践行生态文明的重要载体。各地团组织和绿化、林业部门要高度重视，加强合作，早作安排，精心组织，并结合地方实际，创造性设计和开展活动，通过项目、资金支持和带动各级层层落实，广泛动员青少年和社会公众普遍参与，掀起植树护绿行动热潮。

2.完善机制。各级团组织和绿化、林业部门要建立常态化的沟通联络和分工协作机制，发挥各自优势，形成工作合力。团组织主要负责活动策划、人员组织、媒体宣传、社会化筹资与动员等；绿化、林业部门主要负责将青少年植树活动纳入当地造林绿化总体规划，加强技术指导，与团组织协商确定便于青少年参与的植绿护绿活动。各省级团委要加强督导，通过制定科学、合理的统计指标体系和动态报送、通报制度，汇总掌握基层工作进展情况，及时报送团中央农村青年工作部。

3.加强宣传。各地要切实把宣传作为工作的重要组成部分，加强宣传力度，创新方式方法，扩大活动影响。各级团组织要进一步加强与主流媒体和网络新媒体的合作，用好网站、微信、手机短信、QQ群和各级保护母亲河行动官方微博，充分借助主流媒体的品牌影响力和专业性，发挥新媒体的实时性、交互性等优势，积极面向青少年和社会公众发布活动信息，普及生态知识，宣传生态文明理念，不断扩大活动的覆盖面和影响力。要及时总结推广各地的好做法、好经验，挖掘和树立优秀典型，将其纳入各级“母亲河奖”评选表彰范围。

请省级团委征求本省（区、市）林业部门意见后，将本地区开展2014年青少年植树行动的有关安排和本地区春季植树季活动总结分别于2月21日和5月9日前报团中央农村青年工作部。
