# 中国科学技术协会国际联络部关于及时交纳2014年度国际组织会费的通知

## 中国科学技术协会国际联络部关于及时交纳2014年度国际组织会费的通知（科协外函〔2014〕28号）

各全国学会、协会、研究会办公室、相关国际组织中国委员会：

中国科学技术协会2014年度国际组织会费交纳工作现启动，请各单位积极配合，按照规定的时间和要求及时递交会费申请材料。

已列入财政部国际组织会费支持计划的国际组织会费，请相关学会、协会、研究会和国际组织中国委员会于2014年4月30日前提交如下纸质材料：

1．国际组织会费申请表

2．国际组织关于交纳会费的通知（Invoice）；

3．2013年“交纳国际组织会费总结表”，请按表格要求填写有关内容，每个国际组织填写一份。

交纳国际组织会费申请表、总结表请到以下地址下载：

http：//www.cast.org.cn/n35081/n35668/n35773/n39961/n39992/10218378.html

未列入财政部国际组织会费支持计划的国际组织会费，请各学会、协会、研究会和国际组织中国委员会自行安排交纳。
