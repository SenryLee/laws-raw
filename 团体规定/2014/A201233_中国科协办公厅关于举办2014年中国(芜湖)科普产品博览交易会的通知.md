# 中国科协办公厅关于举办2014年中国(芜湖)科普产品博览交易会的通知

## 中国科协办公厅关于举办2014年中国（芜湖）科普产品博览交易会的通知（科协办函普字〔2014〕98号）

各全国学会、协会、研究会，各省、自治区、直辖市科协，新疆生产建设兵团科协：

为深入贯彻落实党的十八大、十八届三中全会精神和习近平总书记系列重要讲话精神，全面实施《全民科学素质行动计划纲要实施方案（2011-2015年）》，推动公益性科普事业和经营性科普产业发展，促进科普产品的研制、交流与推广，培育、壮大科普展览和展品市场，使科普工作更好地服务于经济社会发展和全民科学素质建设工作，中国科协与安徽省人民政府将于2014年11月7-9日在安徽省芜湖市联合举办2014年中国（芜湖）科普产品博览交易会（以下简称科博会）。科博会由安徽省科协和芜湖市人民政府具体承办。

本届科博会以“共建创新平台、发展科普产业”为主题，以“展示产品精品化、运行管理规范化、发展方向国际化”为目标，以实物、样品、模型、图片、广告、音像以及技术转让、商贸洽谈、信息发布等形式，现场展示科技最新成果类、科普出版类、科普展览和展品开发制作类、科学艺术和玩具类、科普教育类、科普网站和科普游戏软件类、科普旅游及综合类等七大类科普展品的最新成果。科博会期间，还将举办全国科技馆发展论坛和科普游戏创作与传播论坛等有关活动。

请各全国学会、协会、研究会，各地科协根据情况积极组织本系统、本地区科普产品研制、生产单位参展参会，具体事宜可与科博会组委会秘书处联系。

2014年中国（芜湖）科普产品博览交易会

总体方案

2014年中国（芜湖）科普产品博览交易会（以下简称科博会）拟定于2014年11月7-9日在安徽省芜湖市国际会展中心举办。

**一、**指导思想

以邓小平理论、“三个代表”重要思想、科学发展观为指导，贯彻落实党的十八大、十八届三中全会和习近平总书记系列重要讲话精神，深入实施《全民科学素质行动计划纲要》、《中共安徽省委安徽省人民政府关于实施创新驱动发展战略进一步加快创新型省份建设的意见》和《皖江城市带承接产业转移示范区规划》。按照建立公益性科普事业与经营性科普产业并举机制的要求，以“展示产品精品化、运行管理规范化、发展方向国际化”为目标，突出“高、新、外、招、奖、坛”的特色，搭建科普资源共建共享平台，打造中国科普资源集散中心，推动科普事业和科普产业协同发展，促进全民科学素质提高。

**二、**展会主题

共建创新平台　发展科普产业

**三、**举办单位

主办单位：中国科学技术协会　　安徽省人民政府

承办单位：安徽省科学技术协会　安徽省芜湖市人民政府

**四、**展示内容、形式

（一）展示内容

1.科技最新成果类展品：包括航天、航海、高铁、互联网、智能手机、云计算等；

2.科普出版类展品：科普图书（含电子图书）、报刊杂志、挂图、声像制品等；

3.科普展览、展品开发制作类展品：科技馆、自然科学博物馆、流动科技馆展品，科技活动中心规划设计及展项、展品、展具、电子科普画廊展品；

4.科学艺术、玩具类展品：科普艺术品，科普益智玩具等；

5.科普教育类展品：科普教育器材及教具、软件；

6.科普网站、科普游戏软件类展品：科普电子信息网络技术，网上科技馆，科普网站软件，科普动漫及科普游戏；

7.科普旅游及综合类展品：科普旅游项目，科普表演剧，家用科普设备及产品；

8.安徽省百所高校百万大学生科普创意创新大赛优秀作品展。

（二）展览形式

实物、样品、模型、图片、广告、音像以及现场展示、现场销售、货物留购、技术转让、商贸洽谈、招商引资、信息发布等。

境外科普产品可采用：1.由中国商会统一担保；2.由参展企业交纳保证金的方式参展。若需留置，按海关规定办理报关手续。

（三）展位及展区设置

科博会设室内3米×3米标准展位1000个（含特装展位）。

科博会期间将举办“全国科技馆发展论坛”、“科普游戏创作与传播论坛”等有关活动。
