# 中国科协学会学术部关于开展2014年传统出版单位数字化转型示范工作的通知

中国科协学会学术部关于开展2014年传统出版单位数字化转型示范工作的通知

（科协学函刊字〔2014〕142号）

各全国学会、协会、研究会办公室（秘书处），各期刊出版单位：

为进一步深化传统出版单位数字化转型示范工作，加快传统出版业向数字出版转型升级步伐，促进数字出版产业整体发展，根据国家新闻出版广电总局有关要求，开展2014年传统出版单位数字转型示范工作。现将相关事项通知如下。

**一、**示范目的

组织开展传统出版单位数字化转型示范工作，是贯彻落实党和国家文化建设战略决策，实现新闻出版强国目标的重要工作举措，目的在于通过统一标准和评估程序，遴选一批传统出版单位，总结推广其积极探索数字化转型的先进经验，带动传统出版整体转型升级，推动数字出版产业加快发展。此次遴选确定的“数字化转型示范单位”将参加2015年国家新闻出版广电总局开展的第二批全国“数字出版转型示范单位”评估工作。

**二、**申报对象

中国科协主管、经过国家新闻出版广电总局正式批准设立的期刊出版单位。编辑部、事业部等非独立法人主体，以及已被确定为首批国际级“数字出版转型示范单位”的传统出版单位不在

此次评估范围之内。

**三、**具体要求

1．请各申报单位按照本通知所附信息采集表的要求认真填写申报材料，于2014年7月10日前，将申报材料及补充材料的纸质版（一式6份并加盖单位公章）报送至中国科协学会学术部期刊出版处，电子版发送至指定邮箱qkzz@cast.org.cn。

2．申报材料收集后将根据国家出版广电总局要求提交中国音响和数字出版协会进行评估。

3．示范单位确定后，中国科协将加强对示范单位的跟踪和指导，切实帮助示范单位解决实际问题和困难，进一步推动加快其转型升级步伐，更好地发挥示范单位的引领带动作用。
