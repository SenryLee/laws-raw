# 中华全国工商业联合会办公厅关于组织开展第五次民营企业军民两用高新技术及产品研发生产情况专项调查的通知

全联厅字〔2014〕45号

各省、自治区、直辖市和新疆生产建设兵团工商联，全联科技装备业商会：

为贯彻落实党的十八届三中全会关于“推动军民融合深度发展”的战略部署，引导优势民营企业进入军品科研生产和维修领域，根据工作安排，现组织开展第五次民营企业军民两用高新技术及产品研发生产情况专项调查。

本次专项调查，采取企业报送与实地考察相结合的方式。全国工商联经济部在收到《第五次民营企业军民两用高新技术及产品研发生产情况专项调查表》（包括光盘、照片）后，将组织军民融合发展研究专家组进行评审，把符合条件的企业及产品编入《军民两用高新技术民营企业及产品推荐目录（第五册）》，送军方各有关部门参考，并在适当时候组织召开相关产品推介会，为军方和民营企业牵线搭桥。

各地工商联要高度重视本次专项调查，深入调查了解，积极推荐确有潜力进入军品科研生产和维修领域的民营企业。请相关民营企业认真如实填报调查表（见附件），并于2015年3月15日前将调查表文字稿及所刻录的光盘各一份（企业场景及产品照片请编辑在专项调查表内；如需另附照片，照片必请背书：企业名称、产品名称、照片编号等），报送所在省级工商联审核后加盖公章于2015年3月31日前递送全国工商联经济部。凡有涉密内容的表格、照片、光盘在寄送过程中，请务必严格遵守保密规定，一律通过邮政机要渠道送达。

《第五次民营企业军民两用高新技术及产品研发生产情况专项调查表》亦可从全国工商联网站（www.acfic.org.cn）下载、复印。

本次专项调查为国家财政部拨款项目，征集信息并向军方推荐时，均不向企业收取任何费用。
