# 中国科学技术协会学术部关于申报2014年度中国科协学会管理制度改革基础培育工程项目的通知

## 中国科学技术协会学术部关于申报2014年度中国科协学会管理制度改革基础培育工程项目的通知（科协学函管字〔2014〕25号）

各全国学会、协会、研究会秘书处（办公室），各省、自治区、直辖市科协学会部，新疆生产建设兵团科协学会部：

为加快推进社会组织管理制度改革，发挥学会在加强社会管理，推动社会服务创新和社会治理体制建设中的重要作用，中国科协拟实施学会管理制度改革基础培育工程，现将项目申报事宜通知如下：

**一、**项目类型及要求

（一）学会管理制度改革培育工程资助项目（项目编号：XHGL201401）

A类资助项目：治理结构基础建设类（项目编号：XHGL201401-A）

（1）推进民主办会机制的落实。探索民主选举、民主决策、民主监督的管理机制。支持学会探索竞选和差额选举办法。健全理事会（常务理事会）议事规则。建立监事、司库等内部自律机制，推行重大事项通报制度和内部监督制度。从机制上防止行政化倾向，实现民主办会；

（2）改革挂靠体制和分支机构管理体制。探索挂靠体制的改革途径，试行多种挂靠或无挂靠体制。健全对分支机构的管理机制，建立和完善分支机构的管理办法，逐步实现对分支机构动态管理、定期评估、有进有出的管理模式；

（3）改革办事机构用人机制。支持学会实行以竞争和流动为核心的动态人事管理办法。鼓励选聘和向社会招聘学会专职人员。建立因岗选人、竞争上岗、优化组合、能进能出的用人制度，探索吸引人才、用好人才的机制。支持学会建立健全规章制度，规范工作程序。改善办公条件，提高办公自动化、信息化水平。

B类资助项目：会员服务管理基础能力建设类（项目编号：XHGL201401-B）

（1）健全会员服务工作基础。支持学会建立会员服务管理制度。落实会员工作机构和人员。探索建立学会会员工作站、会员之家等会员工作基层组织。推广中国科协个人会员管理系统，提高学会会员管理服务的信息化水平；

（2）改善对会员的服务。完善会员服务项目，开展会员日活动，拓宽服务会员的渠道。定期向会员征询意见和建议。反映会员的呼声和诉求，维护会员合法权益。

C类资助项目：自主服务社会基础能力建设类（项目编号：XHGL201401-C）

学会根据业务领域和需求，面向市场和社会主动自行开展的社会化服务工作，科学技术普及、继续教育等中国科协另有专门经费支持的工作除外。

D1类创新试点项目：民主机制建设试点--学会民主治理建设试点项目（项目编号：XHGL201401-D1）

（1）修改章程并制定理事会、常务理事会会议制度，明确规定任期内学会理事、常务理事两次无故缺席或三次请假缺席者自动按辞去学会职务处理；

（2）建立监事会监事制度。全国会员代表大会选举产生由会员代表组成的监事会，并在章程中对监事会职权予以明确。监事会监督学会理事会、常务理事会民主决策情况，并根据章程和理事会、常务理事会会议制度监督出席情况，落实有关要求。

D2类创新试点项目：民主机制建设试点--学会青年科技人才组织建设试点项目（项目编号：XHGL201401-D2）

（1）成立或完善学会青年科技工作者工作机构；

（2）针对学科热点问题组织青年科技工作者召开的青年科技热点论坛；

（3）针对学会发展问题组织青年学会发展论坛，可与青年科技热点论坛同期召开；

（4）形成科技热点研讨报告和学会发展研讨报告，并提交常务理事会审议通过。

E类创新试点项目：会员服务管理试点--学会会员满意度报告试点项目（项目编号：XHGL201401-E）

（1）配合中国科协和指定第三方机构完成全样本会员满意度状况调查研究；

（2）提供调查所需的全体会员信息；

（3）调查形成的会员满意度年度报告提供给全体理事参考，并作为理事会改进会员服务工作的基础资料。

F类创新试点项目：社会影响力试点--学会公益服务试点项目（项目编号：XHGL201401-F）

（1）立足学会所在领域，结合学会自身特点组织开展社会救助、社会福利、社区服务等公益性质的社会服务活动；

（2）活动在主流媒体等相关媒体上有一定数量的报道；

（3）活动应能吸引社会资源参与，能从企业等单位争取一定的配套支持。

项目目标：A、B、C类项目承担单位需选择相关内容作为项目任务；D、E、F类项目承担单位需同时完成全部项目内容。

项目数量：A、B、C类共35项左右，其中支持全国学会25项，支持地方学会10项；D1、D2、E、F每类各3项。

经费额度：A、B类每项8万元，C类每项12万元；D1类每项7万元，承担本项目可同时获得1项A类项目配套资助；D2类每项10万元；E类每项5万元，承担本项目可同时获得1项B类项目配套资助；F类每项18万元。

项目周期：自2014年2月-2014年12月。D、E、F类项目视项目第一年度执行情况安排第二年度的延续性资助。

申报对象：A、B、C类项目：中国科协所属全国学会，各省（自治区、直辖市）科协学会部；D、E、F类项目：中国科协所属全国学会。其中D1类项目承担单位应为2014年理事会换届学会或有相关基础的学会，E类项目承担单位中有专门的会员服务机构和会员数据库的学会优先。

每个省级科协限推荐1个省级学会申报1个项目。每个全国学会限报1个项目，申报D1类和E类项目的学会不需要重复申报配套资助项目。

申报学会应2012年度社团年检合格。民政部全国性社会组织评估等级结果为5A、4A的学会优先考虑。

学会能力提升专项优秀科技社团奖获奖学会不提供配套资助。

（二）学会管理制度改革与服务体系研究项目（项目编号：XHGL201402）

1.学会管理制度改革研究项目（项目编号：XHGL201402-1）

项目内容：2013年，《国务院机构改革和职能转变方案》提出要改革社会组织管理制度，加快形成政社分开、权责明确、依法自治的现代社会组织体制，中国科协所属全国学会管理面临重大改革。为了顺应改革和社会管理的发展趋势，本课题拟瞄准我国社会组织管理制度改革的新方向，以加强科协组织建设和规范科技社团的整体发展为目标，开展针对性研究，形成研究报告，为中国科协适应形势发展，指导学会建设提供重要参考。

项目数量：1项。

经费额度：20万。

项目周期：自2014年2月-2014年11月。

申报对象：

具有独立法人资格的高等院校、科研机构和社会团体等，并具有完成课题必备的人才条件和物质条件。

申报单位应长期从事社会团体研究，有成熟的社团研究力量，了解中国科协所属全国学会情况。能联系社会组织管理制度改革相关主管单位参与研究的，优先考虑。

2. 涉及国家重大领域的科技社团在社会组织改革过程中管理与发展的转型研究项目（项目编号：XHGL201402-2）

项目内容：随着社会组织改革的推进，科技社团的管理与发展方向面临重大的转变，涉及有关国家安全、社会安全、人民健康等相关的学科领域的科技社团，在管理与发展过程中明显不同于其他类别科技社团。本课题拟研究如何在国家创新体系中发挥这类社团的独特优势，研究社会组织改革过程中，在规范化、制度化、自律和监管等方面的具体措施与办法，提出这类社团今后改革发展的具体意见。

项目数量：1项。

经费额度：15万。

项目周期：自2014年2月-2014年11月。

申报对象：

具有独立法人资格的高等院校、科研机构和社会团体等，并具有完成课题必备的人才条件和物质条件。

申报单位应长期从事社会团体研究，有成熟的社团研究力量，了解中国科协所属全国学会情况。

（三）学会管理制度改革基础培育交流项目（项目编号：XHGL201403）

全国学会秘书长沙龙项目（项目编号：XHGL201403）

项目内容：采取“科协搭台、学会唱戏”的方式，搭建全国学会秘书长非正式交流平台。请申报单位围绕学会管理制度改革和学会基础能力培育自选主题，以交流思想、沟通信息、促进工作、增进友谊为主要目的，邀请全国学会秘书长参加。

项目数量：2项。

经费额度：每项10万。

项目周期：2014年12月前完成。

申报对象：中国科协所属全国学会。

**二、**申报要求

1．各申报单位应按照本通知及《2014年度中国科协学会学术项目申报指南》要求进行项目设计，客观真实填报申请材料。

2．经费预算应符合《中国科协项目管理办法》的规定。学会发展理论研究课题管理费严格按国家科技三项经费管理规定执行，不得超过课题资助总额的5%。课题申报单位未明确承诺将严格执行此规定者，将作无效申报处理。

3. 项目申报、实施、总结等相关材料将适时酌情公开。

4．报送材料要求

（1）学会管理制度改革基础培育工程资助项目（XHGL201401）、秘书长沙龙项目（XHGL201403）需提交《中国科协学会管理制度改革基础培育工程资助类项目申报书》其中，各省级学会申请资助项目的，另需报送加盖公章的省科协推荐函一份。

（2）学会管理制度改革与服务体系研究项目（XHGL201402）：提交《中国科协学会管理制度改革基础培育工程课题类项目申报书》纸质文本一式十份，同时发送电子文本到xuehuiguanli@cast.org.cn。
