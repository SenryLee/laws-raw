# 中国登山协会关于在张家界举办2014年全国户外安全教育计划末站巡讲暨活动总结研讨班的通知

各地方登山协会，安全讲座承办单位，户外爱好者：

“全国户外安全教育计划”自去年正式启动以来，共有30余个省市地区提出正式申请或有意向举办讲座。经过筛选，本年度共在沈阳、天津、上海、东莞、广州、深圳、成都、西安、宁波、温州、济南、绍兴等全国16个城市举办了巡回讲座及3期安全宣导员培训，共有超过5000人的直接受众，取得了良好的社会反响和宣传效果。

为了更好地总结经验，表彰先进，为明年的继续开展奠定基础，中国登山协会定于12月14日-15日在张家界举办2014年全国户外安全教育计划末站巡讲暨活动总结研讨班。我们热忱期待您的到来，给予“全国户外安全教育计划”一如既往的关注与支持。

现将有关事宜通知如下：

一、名称：2014年全国户外安全教育计划末站巡讲暨活动总结研讨班

二、时间：

讲座：2014年12月14日下午(12月13日或12月14日中午前报到)

研讨班：2014年12月15日上午(12月14日报到，15日下午离会)

三、地点：张家界市大成山水国际酒店(张家界市大庸西路，市区与机场路交汇处)

四、参会人员：

1.2014年安全讲座承办单位主要负责人或代表

2.安全教育计划各工作组主要负责人

3.安全教育计划讲师团成员代表

4.有意向承办2015年安全讲座的承办单位代表

5.赞助商代表

6.媒体代表

五、会议内容

1.2014年全国户外安全教育计划活动总结通报

2.讲座活动承办地经验交流分享

3. 安全宣导员培养模式研讨

4. 其他相关工作研讨

5. 2014年全国巡回讲座先进单位评选

六、报名报到

1.报名时间与方法：请有意参加此研讨班并符合报名条件的相关人员认真阅读相关注意事项，并按要求准备相关材料，报名表填好后，于2014年12月10日前以邮件形式递交并等待确认。(参加讲座不需要提交报名表)

3.报到地点：张家界市大成山水国际酒店大堂。

七、会议须知

1.会议期间天气寒冷，请备好防寒衣物；

2.2014年度巡讲及安全宣导员培训承办单位与会代表请提前准备总结发言材料；

3.请大家提前妥善安排会议期间的个人生活、工作事宜，以免冲突，如有特殊情况请提前说明；

八、经费说明

1. 2014年安全讲座及宣导员培训举办地主要负责人或组织方代表会议期间的食宿费用由中国登山协会承担，交通费自理；

2.安全教育计划讲师团成员代表的食宿费用由中国登山协会承担，交通费自理；

3.其他符合报名条件的代表费用自理。
