# 全国妇联、中央文明办、共青团中央等关于庆祝2014年“六一”国际儿童节的联合通知

全国妇联、中央文明办、共青团中央、教育部、民政部、文化部、国家卫生和计划生育委员会、国家新闻出版广电总局关于庆祝2014年“六一”国际儿童节的联合通知

（妇字〔2014〕17号）

各省、自治区、直辖市妇联、文明办、团委、教育厅（教委）、民政厅（局）、文化厅（局）、卫计委、广播影视局、新闻出版局：

2014年“六一”儿童节即将到来，为了让儿童度过一个快乐而有意义的节日，“六一”期间要围绕贯彻落实中央关于未成年人思想道德建设工作的重要部署，以面向儿童开展社会主义核心价值观宣传教育为主题，组织开展适合儿童特点、丰富多彩的庆祝活动。现将有关事项通知如下。

**一、**组织开展争做美德少年主题实践活动。各地、各有关部门要按照中央文明办等部门联合印发的《关于运用重要时间节点深化“我的中国梦”主题教育实践活动通知》精神，抓住“六一”儿童节时间节点，围绕主题，精心设计并组织开展贴近儿童生活、富有时代气息的争做美德少年主题实践活动。要深化拓展已开展的“做一个有道德的人”“小公民道德实践”“红领巾相约中国梦”“学雷锋志愿服务”等活动，深入挖掘、广泛宣传美德少年先进事迹，面向儿童深入浅出地讲解中国梦的基本内涵，大力弘扬友善、孝敬、诚信等中华民族传统美德，宣传普及社会主义核心价值观“三个倡导”24个字，培养树立崇德向上、见贤思齐的良好风尚。

**二、**组织开展良好家风家教宣传展示活动。各地、各有关部门在节日期间，要以弘扬倡导良好家风家教为重点，组织开展“家风”讨论、讲家风家教故事、家规家训征集、传承好家风的好妈好爸推荐等亲子互动活动，全国妇联及各级妇联组织已开展了寻找“最美家庭”活动。要通过开展家风家教宣传展示活动，积极传承夫妻和睦、尊老爱幼、科学教子、勤俭持家、邻里互助的家庭美德，引导广大家长树立良好家风，注重自身修养，注意行为举止，以身作则、言传身教，为孩子健康成长营造良好家庭环境。教育广大儿童传承家庭美德，注重生活点滴，培养良好道德品质。

**三、**组织开展丰富多彩的文化娱乐活动。节日期间，各地、各相关部门要组织开展多种形式的关爱慰问活动，特别要关注农村留守流动儿童、流浪儿童、孤残儿童、贫困家庭儿童等特殊困境儿童群体，使他们切身感受到党和政府以及社会各界的关怀。要集中推出一批为儿童办实事的民生工程，大力宣传儿童优先的理念，动员全社会力量为儿童健康成长做好事、办实事。要精心推介一批体现童真童趣、蕴含向上精神的优秀文化作品，组织开展具有思想导向、教育内涵，也符合儿童特点的文体娱乐活动，通过举办儿童影视剧展演、亲子读书活动、儿童才艺展示等文化娱乐活动，丰富儿童节日生活，使广大儿童在丰富多彩的活动中愉悦身心、陶冶情操。各地、各有关部门要高度重视，通力合作，突出主题，寓教于乐，为广大儿童欢度节日营造良好氛围。
