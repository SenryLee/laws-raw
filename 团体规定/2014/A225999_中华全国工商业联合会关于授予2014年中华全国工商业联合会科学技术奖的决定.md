# 中华全国工商业联合会关于授予2014年中华全国工商业联合会科学技术奖的决定

全联发〔2014〕11号

各省、自治区、直辖市和新疆生产建设兵团工商联，各直属商会：

为贯彻落实党的十八大和十八届三中、四中全会精神，实施国家创新驱动战略，构建以企业为主体的技术创新体系，鼓励和引导民营企业依靠技术创新实现转型升级，根据《中华全国工商业联合会科学技术奖工作办法》，2014年全国工商联开展了科技进步奖和科技创新企业家奖的评选工作。经各地工商联和有关直属商会推荐、专家评审、社会公示，全国工商联决定授予“宽带光纤接入系统核心芯片和成套设备的开发及产业化”等101个项目中华全国工商业联合会科技进步奖，授予广州市香雪制药股份有限公司董事长王永辉等27位企业家中华全国工商业联合会科技创新企业家奖。

希望获奖的民营企业和民营企业家再接再厉、勇于创新、不断超越、再创佳绩。希望广大民营企业以获奖企业为榜样，担负起时代赋予的历史使命，重视技术创新，勇于攻坚克难，以技术创新引领企业发展、促进转型升级，为全面建成小康社会、实现中华民族伟大复兴中国梦作出更大贡献。

附件：1.2014年中华全国工商业联合会科技进步一等奖名单

2.2014年中华全国工商业联合会科技进步二等奖名单

3.2014年中华全国工商业联合会科技进步三等奖名单

4.2014年中华全国工商业联合会科技创新企业家奖名单

中华全国工商业联合会

2014年12月17日
