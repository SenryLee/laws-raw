# 中国科协学会学术部关于举办2014年全国学会秘书长工作会议的通知

## 中国科协学会学术部关于举办2014年全国学会秘书长工作会议的通知（科协学函管字〔2014〕6号）

各全国学会、协会、研究会秘书处（办公室）：

为深入贯彻十八大和十八届二中、三中全会精神，传达中央对中国科协工作的指示意见和中央有关重要会议精神，加强对全国学会工作的指导，拟定于2014年1月27日下午在中国科技会堂举办2014年全国学会秘书长工作会议。现将有关事项通知如下：

**一、**主要内容

贯彻中央书记处对中国科协工作的指示，传达中央经济工作会议、中央城镇化工作会议、中央农村工作会议精神，传达中国科协八届八次常委会和八届五次全委会精神，总结和部署年度学会学术工作，发布2014年度中国科协学会学术重点活动申报指南。

**二、**参加人员

请各全国学会秘书长或常务副秘书长出席会议，每会1人。

**三、**时间、地点

1．时间：2014年1月27日，下午14：00-17：00。

2．地点：中国科技会堂B309会议室（北京市海淀区复兴路3号），总机电话：010-68518822。

**四、**其他事项

1．会议委托中国科协学会服务中心承办。请各全国学会于

2014年1月21日前将会议回执（见附件）电子邮件或传真到中国科协学会服务中心学会服务工作处。

2．会议期间为京外学会参会人员提供食宿，住宿安排标准间，最迟请于28日中午前离会。在京各学会参会人员不安排住宿。

3．京外学会参会人员于2014年1月26日下午开始在中国科技会堂报到；在京学会参会人员于27日下午13：00-13：50在会场报到。

4．请参会人员凭本通知报到。由于会场停车位紧张，建议在京学会参会人员尽量乘坐公共交通工具参会。

5．会议不安排接送站，请参会人员自行前往会议地点。
