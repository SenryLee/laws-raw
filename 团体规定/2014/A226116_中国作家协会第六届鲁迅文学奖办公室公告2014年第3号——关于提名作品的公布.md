# 中国作家协会第六届鲁迅文学奖办公室公告2014年第3号——关于提名作品的公布

## 第六届鲁迅文学奖评奖办公室公告

[2014年]第3号

第六届鲁迅文学奖各评奖委员会经过认真阅读讨论，于2014年8月7日分别投票表决产生了提名作品。现将提名作品目录予以公示。公示期截止于8月10日，在此期间，如发现提名作品有不符合《鲁迅文学奖评奖条例》的情况，请向评奖办公室提出。

评奖办公室电话：(010)88960077转1009、3009、4012

电子邮箱：lxwxj6@163.com

第六届鲁迅文学奖评奖办公室

2014年8月7日
