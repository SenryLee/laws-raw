# 中国残疾人联合会办公厅关于2014年全国残疾人组织建设“强基育人”工程有关事项的通知

## 中国残疾人联合会办公厅关于2014年全国残疾人组织建设“强基育人”工程有关事项的通知（残联厅发〔2014〕27号）

各省、自治区、直辖市残联，新疆生产建设兵团残联，黑龙江垦区残联：

全国残疾人组织建设“强基育人”工程实施以来，在各级残联的共同努力下取得了明显成效，各级残疾人组织进一步健全，残疾人工作者队伍综合素质和服务能力进一步提升，各项工作全面推进。

2014年是全国残联系统“基础管理建设年”，实施“强基育人”工程是“基础管理建设年”的重要组成部分，对于进一步加强各级残联的基础管理工作，规范残联组织队伍建设，具有重要的推动作用。鲁勇理事长特别指出：“城乡社区残疾人基层组织是残联组织有效履行‘代表、服务、管理’职能的工作之基、活力之源，必须持之以恒，常抓不懈。基础不牢，地动山摇。要采取更加有效措施推动‘强基育人’工作的创新发展，努力带出一支政治上靠得住、工作上有本事、作风上接地气，对残疾人和残疾人事业充满感情的基层工作队伍，以有效焕发基层残疾人组织工作活力。”

按照中国残联《全国残疾人组织建设“强基育人”工程实施方案》（残联厅[2012]4号）的总体部署和《中国残疾人联合会关于深入开展“基础管理建设年”活动的意见》（残联发〔2014〕16号）的要求，为做好2014年度“强基育人”工程各项工作，经中国残联领导同志同意，现就有关事项通知如下：

**一、**各级残联在实施2014年“强基育人”工程的过程中，要根据“重点突出、亮点鲜明、操作性强、实效评估”的原则，以扎实的日常工作为基础，突出体现残疾人工作者教育培训、班子建设和残疾人干部配备、专职委员培育、“基础管理建设年”、自强与助残表彰、基层残疾人组织建设、志愿助残、残疾人证核发、专门协会、社会工作等重点工作，以及承担中国残联试点任务、当地特色鲜明的创新亮点工作，并在考虑地域差异、分类指导的前提下，尽可能将各项工作加以量化，以确保考核评估更为科学合理，更具可操作性。

**二、**各省（区、市）残联要严格按照《全国残疾人组织建设“强基育人”工程实施方案》的总体要求，紧密结合当地实际，采取有力措施，加强领导，精心组织，积极推动2014年度“强基育人”工程工作的全面实施，确保各项目标任务及时高效完成。

**三、**鼓励工作创新。加大“创新亮点工作”加分值，鼓励各地在保证常规工作顺利完成的基础上，进一步突出地方特色，提高组联工作的自主创新性。各省（区、市）要以工作案例的形式，将创新亮点工作形成专题报告，报送至中国残联。

**四、**实施“中国残联考查、省级残联自查、被服务对象满意度调查相结合”的三维评价体系，提高考核评估的公正客观性。各级残联要在11月20日前完成自我评估，同时提交2014年度自评报告和任务评估表。省级残联在自查的同时，要以问卷等形式，在各专门协会、社会组织代表和残疾人中开展被服务对象满意度调查。中国残联组联部将择时通过抽查、互查等评估方式，按区域分类对各省（区、市）残联“强基育人”工程的执行情况进行督导评估，并通报评估结果。
