# 共青团中央、中华全国青年联合会、欧美同学会关于举办“丝路引擎·创业高地”——2014陕西省海外学人回国创业周的通知

为贯彻落实党的十八届三中全会关于“广泛吸引境外优秀人才回国或来华创业发展”和团的十七届二中全会相关要求，引导海外学人回国创业，推进海外人才资源与国内经济发展需求对接融合，团中央、全国青联、欧美同学会决定举办2014陕西省海外学人回国创业周活动。现将活动相关事宜通知如下：

一、活动主题

丝路引擎?创业高地

二、活动时间

2014年7月15日至17日

三、活动地点

陕西省西咸新区

四、组织机构

主办单位：共青团中央、全国青联、欧美同学会

承办单位：共青团陕西省委、陕西省青联、西咸新区管委会、中国青年科技工作者协会、全国青联留学人员联谊会

协办单位：西咸新区欧美同学会

五、内容日程

主要开展交流座谈、项目对接、政策咨询、投资推介、人才引进等相关活动。

1.第一天（7月15日　星期二） 报到

2.第二天（7月16日　星期三） 座谈会及实地考察

上午：海外学人回国创业座谈会

（1）海外学人代表发言；

（2）入区知名企业代表发言；

（3）欧美同学会西部创新创业中心揭牌仪式;

（4）西咸新区代表发言；

（5）参观西咸新区规划展厅。

下午：赴西咸所辖五个新城实地考察（沣西、秦汉、沣东等地）。

3.第三天（7月17日　星期四） 推介及洽谈咨询活动

上午：投资推介会及总结会

（1）五大新城介绍情况；

（2）重点企业、机构、项目推介会；

（3）洽谈讨论及政策咨询活动；

（4）总结会。

下午：返程。
