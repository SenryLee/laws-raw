# 中国科学技术协会学术部关于举办2014年全国学会继续教育工作人员培训班(第一期)的通知

## 中国科学技术协会学术部关于举办2014年全国学会继续教育工作人员培训班（第一期）的通知（科协学函改字〔2014〕217号）

各全国学会、协会、研究会秘书处（办公室）：

为拓展学会继续教育业务领域的工作思路，提升学会继续教育工作人员的业务能力及学会继续教育项目管理水平，拟于2014年10月在北京举办2014年第一期全国学会继续教育工作人员培训班。现将有关事项通知如下：

**一、**培训内容

主要针对继续教育相关政策解读、中国科协继续教育工作现状及其相关项目介绍、继续教育的工作模式及方式方法案例分享、继续教育培训主题策划甄选等方面进行培训及座谈。

**二、**参加人员

全国学会负责继续教育相关工作的人员。每个学会1个名额。

**三、**时间

2014年10月9日下午报到，10-11日培训。

**四、**地点

中国科协科普示范绿化基地

**五、**有关事项

1.请各全国学会于2014年10月8日前将参加培训人员名单，以电子邮件或传真的形式反馈至中国科协学会服务中心继续教育与培训处。培训班回执见附件1。

2.请于10月9日下午15：00前持通知到中国科技会堂大堂（复兴路3号）报到，培训班安排统一车辆前往培训地点。自行前往的人员请在报名表上注明。行车参考线路见附件2。

**六、**联系人及联系方式

培训班由中国科协学会学术部主办，学会服务中心承办。学会服务中心继续教育与培训处具体承担有关会务工作。
