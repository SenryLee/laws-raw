# 中国统计学会关于报送2014年统计学会工作总结的通知

统会字[2014]05号

各省、自治区、直辖市统计学会，重点城市统计学会；新疆生产建设兵团统计学会；各专业统计学会、分会：

年终将至，为总结2014年中国统计学会的工作，研究布署2015年的学会工作，并为2014年底召开中国统计学会会长办公会做准备，请你们按照如下要求，抓紧做好本地区、本专业统计学会2014年度的工作总结及2015年工作计划。内容包括：

（一）2014年开展科研和学术交流活动情况。

（二）2014年工作的主要经验、存在的问题。

（三）2015年工作计划，包括工作思路、工作计划和重点科研项目，以及主要学术交流活动。

工作总结以纸质和电子形式于2014年11月25日之前报中国统计学会秘书处。
