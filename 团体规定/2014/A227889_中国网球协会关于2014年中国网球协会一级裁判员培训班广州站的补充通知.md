# 中国网球协会关于2014年中国网球协会一级裁判员培训班广州站的补充通知

各相关单位及裁判员：

2014年中国网球协会一级裁判员培训班广州站将于12月20日—21日在广州开发区国际网球学校举行，相关事宜通知如下：

一、报到时间：裁判员12月19日全天(星期五)；

二、报到地点：科城假日酒店(广州市萝岗区科学城映日路1号)。

三、办理住宿时，请听从统一安排。

四、请携带身份证、一级裁判员证、英语等级证等相关证件。

五、此次培训班不进行临场实习。

六、因故不能参加培训的学员，请于12月16日前告知中国网球协会竞赛部(010-67117147)。

七、培训日程

![](https://zk-img.faxin.cn//Uedit_Upload/6356634079433579692450757.jpg)

八、交通指引：

1、飞机：至广州白云国际机场，乘坐出租车至酒店(50Km，约200元)，机场快线8A1号线至华夏国际商务酒店(约90分钟，30元/人)，早07：25—晚21：15(每30分钟一班车)；

2、火车：火车东站或广州火车站，乘坐出租车至酒店(约50--80元)。

附件：2014年中国网协一级网球裁判员培训班广州站学员名单

中国网球协会
