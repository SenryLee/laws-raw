# 共青团中央办公厅关于举办2014年“培养计划”民族地区挂职干部总结培训活动的通知

## 共青团中央办公厅关于举办2014年“培养计划”民族地区挂职干部总结培训活动的通知（中青办发[2014]40号）

共青团北京、天津、辽宁、上海、江苏、浙江、福建、山东、广东省（直辖市）委：

为进一步做好从民族地区到经济相对发达地区挂职锻炼的年轻干部的培养工作，团中央决定举办2014年“培养计划”民族地区挂职干部总结培训活动。现将有关事宜通知如下。

**一、**培训时间

2014年8月4日至9日（4日报到，9日返程）。

**二、**培训地点

江西省井冈山市，全国青少年井冈山革命传统教育基地。

**三、**参加人员

参加2014年“培养计划”第一批挂职锻炼的全体干部，共计76人。

**四、**主要内容

1. 学习培训。围绕党的十八大、十八届三中全会精神和中华民族伟大复兴“中国梦”、习近平总书记在北京大学师生座谈会上的重要讲话精神、党的群众观点和群众路线、党的民族政策和民族工作，以及团的十七届二中全会精神、民族地区共青团工作和青少年民族团结教育等内容开设专题讲座。

2. 专题研讨。围绕“践行党的群众路线，深入青年转变作风”“民族地区青少年思想引导工作方式创新”“民族地区服务青少年成长成才的实际困难和工作建议”“积极践行社会主义核心价值观”等内容进行分组讨论。

3. 素质拓展。依托井冈山教育基地的特色课程设置，组织实施“三湾改编”“红军的一天”等团队素质拓展类情景教学体验课程。

4. 总结座谈。召开2014年“培养计划”工作总结座谈会。

**五、**具体要求

1. 请于7月28日17：00前将以下材料以特快专递寄出：（1）《2014年“培养计划”民族地区年轻干部挂职锻炼总结鉴定表》（见附件，可由中国共青团网《通知》栏目查阅下载），一式三份，加盖印章。（2）本省（直辖市）接收工作总结报告，加盖印章。团中央统战部联系人：洛桑顿珠、芦尊，电话：010-85212678、18513717967、13601150929。地址：北京市前门东大街10号，邮编：100051。

2. 请通知挂职干部于7月28日17：00前报送以下材料。（1）个人证件照电子版（底色不限）；（2）挂职期间撰写的调研报告（word电子版），文档名称统一使用“派出省（自治区）--姓名”的格式。以上材料请发送至tzymzzjc@126.com。

3. 请通知挂职干部于8月4日8：00-18：00自行前往全国青少年井冈山革命传统教育基地报到，地址：江西省吉安市井冈山市茨坪红军北路49号，报到时携带2寸个人免冠彩色照片2张（底色不限）。井冈山教育基地联系人：张侨，电话：0796-6563906，电子邮箱：870943902@qq.com。

4. 请通知挂职干部：培训安排有外出教学环节，请自备运动鞋；井冈山当地天气多变，请视情况准备雨具、保暖衣物、洗漱用品及出行常备药品等。

5. 活动期间的食宿、交通、培训、参观费用由团中央承担，赴井冈山单程交通费由团中央承担，仅限火车硬座/硬卧（按照财务报销的相关规定）及动车、高铁二等座。返程交通费自理，回所在单位报销。提前报到和延期返程不安排食宿。

6. 总结培训活动原则上不得请假，挂职干部因特殊情况不能参加的，需请示接收省（直辖市）团委和派出省（自治区）团委，并报团中央统战部批准。
