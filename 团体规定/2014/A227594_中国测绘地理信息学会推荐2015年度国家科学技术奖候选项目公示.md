# 中国测绘地理信息学会推荐2015年度国家科学技术奖候选项目公示

中国测绘科学研究院牵头完成的“国家数字城市地理空间框架技术体系构建与应用”项目经中国测绘地理信息学会推荐为2015年度国家科学技术奖候选项目，现将项目进行公示。公示期从2014年12月2日到2014年12月11日。如对拟推荐项目有疑义，请通过以下方式向中国测绘地理信息学会实名书面反映。

联系人：马志勇

联系电话：010-63881401

附件：“国家数字城市地理空间框架技术体系构建与应用”项目材料

中国测绘地理信息学会

2014年12月2日
