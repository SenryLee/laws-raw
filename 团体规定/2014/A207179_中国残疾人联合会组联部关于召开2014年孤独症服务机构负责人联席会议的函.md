# 中国残疾人联合会组联部关于召开2014年孤独症服务机构负责人联席会议的函

中国残疾人联合会组联部关于召开2014年孤独症服务机构负责人联席会议的函

（残联组联函〔2014〕3号）

各省、自治区、直辖市残联，新疆生产建设兵团残联，黑龙江农垦总局残联，相关服务机构：

为了深入贯彻落实党的十八大精神，创新协会工作，加强残疾人社会组织的服务与管理，中国精协孤独症委员会拟于2014年3月在上海召开全国孤独症服务机构负责人第四次联席会议，公布第二批“自强自律”创建活动达标名单，启动第三年“自强自律”创建活动。

**一、**时间：

2014年3月27-29日（27日孤独症委员会会议，同时大会代表报到；28日为联席会议；29号为康复论坛）。

**二、**地点：

上海复旦大学（邯郸路220号）。

**三、**主办单位：

中国精神残疾人及亲友协会，上海市残疾人联合会

**四、**协办单位：

上海市精协，闵行区残疾人联合会

**五、**承办单位：

上海爱好儿童康复培训中心

**六、**参加人员：

中国残联、中国精协、上海市残联有关领导；各省、自治区、直辖市相关国有和民办孤独症服务机构（限150家机构联席会成员）负责人（共计约180人）。

**七、**主要内容：

包括孤独症委员会会议、联席会议、康复论坛。具体安排如下：

（一）3月27日下午，孤独症委员会会议

1.中国精协孤独症委员会2009-2013年五年工作总结及下一步发展战略；

2.宣布《关于调整中国精协孤独症委员会主任副主任及成员的决定》；

3.讨论通过中国精协孤独症委员会2014年工作重点及人员分工；

4.讨论通过孤独症服务协会相关文件；

5.中国精协孤独症委员会新任主任作小结发言。

（二）3月28日，联席会议

1.开幕式，领导讲话；

2.上海市残联介绍本市孤独症服务情况；

3.中国残联康复部介绍相关工作；

4.孤独症服务组织自强自律创建活动第二阶段情况分析与第三阶段重点；

5.公布全国第二批自强自律达标机构评选结果并就评估过程进行说明；

6.第二批达标机构授牌；

7.宣布《关于调整中国精协孤独症委员会主任、副主任及成员的决定》

8.讨论通过孤独症服务业协会章程 ；

9.选举产生孤独症服务协会理事会；

10.CNABA教师培训成果汇报。

（三）3月29日，康复论坛

主题：孤独症人士家庭支持及社区康复/机构组织能力建设。

**八、**相关要求

（一）请各级残联及时将本通知转交所属孤独症康复机构；

（二）本次培训名额控制在180人内，优先满足各省残联推荐和会议定向邀请人员的需要，自由报名至额满为止，中国精协将发同意参会函。

（三）会议免收会务费和期间餐费。住宿、往返路费及其他费用自理。

（四）请各机构主要负责人参加会议，每个机构限一人参会。请务必在3月10日以前将回执发到邮箱cappdr@126com，以便会议统一订房并做好其他相关安排。

（五）会议不安排接站，代表自行报到。

（六）未尽事宜，由中国精协孤独症委员会负责解释。
