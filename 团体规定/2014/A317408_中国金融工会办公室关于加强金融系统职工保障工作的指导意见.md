# 中国金融工会办公室关于加强金融系统职工保障工作的指导意见

## 关于加强金融系统职工保障工作的指导意见

为充分发挥金融系统各级工会在推动科学发展、服务职工群众、促进劳动关系和谐以及金融改革、发展、稳定中的重要作用，根据国家和全国总工会的有关要求，现就加强金融系统职工保障工作提出如下意见。

一、重要意义

做好职工保障工作，是工会贯彻落实党中央关于加快转变经济发展方式、保障和改善民生、加强和谐社会建设等一系列重大决策部署的具体体现；是工会履行维护职能，为职工做好事、办实事、解难事的重要举措；是不断推动解决职工在劳动就业、收入分配、社会保障等方面切身利益的重要抓手和有效平台；是调动职工积极性，增强单位、企业凝聚力的重要途径。金融系统各级工会要充分认识工会保障工作在党和国家工作大局以及促进企业可持续发展中的重要地位和作用，切实增强做好新形势下工会保障工作的责任感、使命感和主动性，进一步提高服务职工的能力和水平。

二、总体要求

深入贯彻落实科学发展观，坚持服务中心、服务基层、服务职工，紧密结合中心工作，不断创新工作思路，改进工作方法，完善工作内容，加强调查研究和“源头”参与力度，着力构建帮扶、维权、服务三位一体的工作格局，在重点做好关爱帮扶困难职工工作的基础上，力争在维护职工合法权益、满足金融系统职工特别是基层职工多元化需求等方面取得新突破。

三、工作目标

（一）进一步健全机制。建立完善以困难职工、困难劳模、单亲困难女职工等为重点对象的关爱帮扶机制；建立完善以劳动合同、集体合同及工资集体协商为基本载体的职工权益维护机制；建立完善以全面提高职工保障工作水平为根本目的的人文关怀机制，不断推进金融系统职工保障工作实现常态化、长效化、精细化。

（二）进一步突出实效。结合金融系统各单位实际，以职工满意为根本标准，实行精细化操作，通过各级工会积极有效的工作，力争取得实实在在成果：确保职工患重病、大病能得到本单位至少两级工会组织的及时有效帮扶；确保职工每年参加一次体检；确保职工至少有一份医疗或养老方面的补充保障；确保职工每年能够享受带薪休假。

四、工作任务

（一）切实做好困难职工帮扶工作

1.建立健全困难职工档案。建立动态的困难职工档案和困难劳模、单亲困难女职工专项档案，并利用科技手段加强对档案的动态管理。困难职工帮扶档案应着力加强信息采集分析，通过分析，重点掌握困难职工的数量构成、各级工会组织的帮扶情况等，努力做到信息完整、真实、准确、及时，为当好困难职工的第一知情人、第一报告人打下良好基础。

2.建立帮扶平台（站点）。积极推进会员人数在2万人以上的金融机构逐级建立帮扶平台（站点）。各总行（会、司）工会相关职能部门应明确责任分工，建立沟通协调机制，做好上级工会和基层工会帮扶平台（站点）工作的衔接、配合，充分发挥基层帮扶平台（站点）的作用，履行好第一帮扶人的职责。

3.多渠道筹集帮扶资金。工会经费每年应安排一定比例资金作为帮扶工作专项资金，列入工会年度经费预算，保证帮扶工作正常开展；及时反映，加强沟通，积极争取行政资金支持；适时组织动员爱心捐助，不断增加帮扶资金来源渠道和数额，增强帮扶有效性。

4.切实做好“送温暖”活动。在继续开展好元旦、春节期间“送温暖”活动的同时，进一步做好对困难职工的日常帮扶工作。采取有效措施，努力形成“日常帮扶、重点帮扶、突发意外帮扶”的工作格局。积极整合各种资源，形成全方位、多层次帮扶态势，不断提高帮扶能力和水平。

（二）全面加强职工保障工作

1.监督劳动合同制度和基本保障制度执行情况。督促单位结合实际，认真履行劳动合同，依法保障职工权益，落实好国家在职工社会保障方面的有关法律、法规，加大对职工社会基本保障权益落实情况的民主监督，坚持将按时足额为职工缴纳社会保险费等职工社会保障权益落实情况作为职工代表大会审议、监督的重要内容，确保国家政策法律规定的基本养老保险、基本医疗保险、工伤保险、失业保险、生育保险等惠及职工。

2.推动建立职工补充保障制度。积极协调各方，努力推动建立和完善职工补充保障制度，形成“工会运作、行政支持、职工参与”的三位一体的职工补充互助互济保障工作体系。发挥工会贴近职工和作为群众组织的特殊优势，积极创办或组织职工参加有关方面主办的职工大病医疗、重大灾害保障等互助互济活动，提高职工保障水平。

3.不断丰富和改善职工精神文化生活。与职工之家、职工小家建设活动相结合，大力组织开展健康文明的文化体育活动，丰富职工精神文化生活，陶冶情操，缓解压力，不断提高职工队伍的凝聚力、向心力，提升职工的幸福感和对单位的归属感。

4.做好差别化的基层职工疗休养工作。与落实国家带薪休假制度相结合，逐步创造条件，将更多的职工，特别是基层一线职工纳入疗休养范围。与有关方面密切配合，积极整合资源，按照“双赢”原则，联系、培育一批职工疗休养“定点”单位，促进职工疗休养事业的开展和落实。

5.做好对职工的在职培训。积极组织职工参加技术比武、岗位练兵等“工会搭台，业务唱戏”的劳动竞赛活动，全面提升职工的综合素质和职业技能。积极协助人力资源等部门做好职工在岗培训和职业生涯等，帮助职工完善职业规划，维护好职工的发展权。

6.加强对职工的法律服务。组织职工学习《劳动法》、《劳动合同法》、《社会保险法》等职工权益保障方面的法律法规，在职工中普及劳动关系、权益保障等法律知识，提高职工的法律意识和依法维权能力。

7.重视对职工的人文关怀。结合各单位实际，从单纯对职工物质层面的帮扶，延伸扩展到对职工精神、心理层面的帮扶和关怀。将人文关怀纳入帮扶范围，积极组织开展职工心理健康疏导、心理减压、情感抚慰等多种形式的人文关怀活动，引导培养职工树立积极健康和乐观向上的心态，努力在工作实践中完善具有金融行业特色的人文关怀机制。

五、组织领导

（一）切实履行责任。工会主要负责同志要重视职工保障工作。工会领导集体要定期研究相关工作，定期向党组织报告工作情况。建立、完善工作制度，加强工作协调、指导和服务。

（二）加强调查研究。深入研究职工保障工作在新形势下面临的新情况、新挑战，深入职工，深入基层，及时掌握职工群众的工作生活状况和思想动态以及诉求，努力推动职工最关心、最直接、最现实问题的解决。

（三）加强工会保障干部自身建设。工会保障干部要深入学习国家有关社会保障政策和法律法规，深入思考，认真调研，不断提高履职能力，努力成为工会保障工作领域政策方针的“解答者”、职工利益诉求的“代言人”。
