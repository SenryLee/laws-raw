# 中国测绘地理信息学会关于公布“省级测绘地理信息学会能力提升建设、承接政府转移职能突出工作典型”评选结果的通知

测学发[2014]127号

根据《省级测绘地理信息学会能力提升建设、承接政府转移职能突出工作典型评审规则》，中国测绘地理信息学会组织开展了省级测绘地理信息学会能力提升建设、承接政府转移职能突出工作典型评选工作。

本次评选，共收到15个省级测绘地理信息学会推荐的工作典型28项，经学会秘书处形式审查，有11个省级测绘地理信息学会的23项申报材料合格。经评审委员会评审，评选结果如下：

一、获奖工作典型

（一）突出工作典型6个。

1、北京测绘学会“北京市工程技术系列测绘专业中级职称评审”；

2、北京测绘学会“北京市建筑行业测量验线工和放线工岗位培训”；

3、黑龙江省测绘地理信息学会“黑龙江省民营测绘地理信息企业技术人员初级职称评审”；

4、海南省测绘学会“海南省测绘地理信息市场信用信息评价”；

5、湖北省测绘地理信息学会“湖北省测绘科学技术奖励”；

6、安徽省测绘学会“安徽省测绘资质年度注册及测绘作业证书管理”。

（二）优秀工作典型10个。

1、北京测绘学会“技术标准和规范制定”；

2、黑龙江省测绘地理信息学会科学技术奖；

3、浙江省测绘与地理信息学会科学技术奖；

4、湖北省测绘地理信息学会“湖北省测绘地理信息市场信用信息评价”；

5、陕西省测绘地理信息学会科学技术奖；

6、四川省测绘地理信息学会“科技项目咨询、成果评估及鉴定”；

7、福建省测绘地理信息学会科学技术奖；

8、安徽省测绘地理信息学会科技奖励；

9、云南省测绘地理信息学会科学技术奖；

10、内蒙古自治区测绘科学技术奖。

三、奖励方式

1、颁发中国测绘地理信息学会“突出工作典型”、“优秀工作典型”证书；

2、评选出的6个“突出工作典型”，分别奖励培育扶持经费5万元。
