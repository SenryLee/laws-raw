# 2014年度中国质量协会质量技术奖拟奖项目公示

为促进我国质量技术进步，表彰在质量技术领域中做出突出贡献的单位或个人，经国家科学技术奖励工作办公室批准，“中国质量协会质量技术奖” 于2005年设立，每年评审一次 。

2014年度质量技术奖拟奖项目已通过中国质量协会质量技术奖评审委员会评选产生，现予以公示，公示期为2015年1月20日至2015年2月20日。

对拟奖项目有异议者，可向中国质量协会质量技术奖励工作办公室书面提出。《异议表》可从中国质量网（www.caq.org.cn）“质量技术奖”栏目下载。

优秀六西格玛项目评选结果由全国六西格玛管理推进工作委员会另行发布。
