# 中国审计学会关于表彰2014年度优秀审计论文的通知

各省、自治区、直辖市和计划单列市审计学会，新疆生产建设兵团审计学会，审计署各特派办理论研究会（组），中国审计学会各理事：

为促进提高审计理论研究水平，鼓励多出高质量的审计理论研究成果，根据《中国审计学会优秀审计论文评选办法（试行）》，学会秘书处组织对入选2014年学会举办的“公共资金绩效审计”研讨会和学会与北京工商大学联合举办的“自然资源资产离任审计”研讨会入选论文共93篇进行了评选。经专家组初评和评选委员会审定，两个研讨会各9篇论文被评为优秀审计论文，其中一等奖各1篇、二等奖各2篇、三等奖各6篇，现对这18篇优秀审计论文予以表彰（名单见附件）。

希望受到表彰的优秀审计论文作者再接再厉，不断提高审计理论研究深度和水平，取得新成果。学会广大会员要勤于思考、勇于创新，努力提升审计理论研究素养，以受到表彰的优秀审计论文为借鉴，积极参加审计理论研讨活动，为推动审计工作科学发展贡献力量。
