# 2014年度中华全国工商业联合会科学技术奖评审结果公示

2014年度中华全国工商业联合会科学技术奖的评审工作已经完成。经专家评审并由全国工商联主席办公会议审定，评出科技进步一等奖项目9个、二等奖项目18个、三等奖项目75个，科技创新企业家27人（见附表）。根据《中华全国工商业联合会科技进步奖实施细则》和《中华全国工商业联合会科技创新企业家奖实施细则》，现予以公示。

自公示之日起10日内（截至2014年12月14日24时），任何单位和个人对本次评选的科技进步奖项目和科技创新企业家有异议的，可向全国工商联科学技术奖励工作办公室实名投诉或举报。
