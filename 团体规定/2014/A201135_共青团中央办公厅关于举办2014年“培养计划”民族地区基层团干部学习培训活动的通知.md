# 共青团中央办公厅关于举办2014年“培养计划”民族地区基层团干部学习培训活动的通知

## 共青团中央办公厅关于举办2014年“培养计划”民族地区基层团干部学习培训活动的通知（中青办发[2014]39号）

共青团内蒙古、吉林、湖北、湖南、广西、四川、贵州、云南、西藏、甘肃、青海、宁夏、新疆自治区（省）委：

为进一步加大对民族地区县乡两级团干部的培养力度，团中央决定举办2014年“培养计划”民族地区基层团干部学习培训活动。现将有关事宜通知如下。

**一、**培训时间

2014年8月4日至9日（4日报到，9日返程）。

**二、**培训地点

江西省井冈山市，全国青少年井冈山革命传统教育基地。

**三、**参加人员

民族地区县级团委、乡镇团委主要负责同志，共计24人（名额分配详见附件1）。

**四、**主要内容

1. 学习培训。围绕党的十八大、十八届三中全会精神和中华民族伟大复兴“中国梦”、习近平总书记在北京大学师生座谈会上的重要讲话精神、党的群众观点和群众路线、党的民族政策和民族工作，以及团的十七届二中全会精神、民族地区共青团工作和青少年民族团结教育等内容开设专题讲座。

2. 专题研讨。围绕“践行党的群众路线，深入青年转变作风”“民族地区青少年思想引导工作方式创新”“民族地区服务青少年成长成才的实际困难和工作建议”“积极践行社会主义核心价值观”等内容进行分组讨论。

3. 素质拓展。依托井冈山教育基地的特色课程设置，组织实施“三湾改编”“红军的一天”等团队素质拓展类情景教学体验课程。

4. 总结座谈。召开2014年“培养计划”工作总结座谈会。

**五、**具体要求

1. 推荐要求：（1）原则上推荐任职6个月以上的团县委书记及乡镇团委书记。（2）优先推荐在乡镇实体化大团委工作中成绩突出的团干部。（3）五个自治区优先推荐少数民族的团委书记，其他省份优先推荐民族自治县、民族乡的团委书记。（4）人口较少民族和边境地区可优先推荐。

2. 请如实填报2014年“培养计划”民族地区基层团干部学习培训活动推荐表（见附件2，可由中国共青团网《通知》栏目查阅下载），经审核、盖章后，于7月11日17：00前传真至010-85212354，并将推荐表电子版、证件照电子版以电子邮件的形式发送到tzymzzjc@126.com。团中央统战部联系人：洛桑顿珠、芦尊，电话：010-85212678、18513717967、13601150929。

3. 参加活动人员请于8月4日8：00-18：00自行前往全国青少年井冈山革命传统教育基地报到，地址：江西省吉安市井冈山市茨坪红军北路49号，报到时携带2寸个人免冠彩色照片2张（底色不限）。井冈山教育基地联系人：张侨，电话：0796-6563906，邮箱：870943902@qq.com。

4. 培训安排有外出教学环节，请学员自备运动鞋；井冈山当地天气多变，请学员视情况准备雨具、保暖衣物、洗漱用品及出行常备药品等。

5. 活动期间的食宿、交通、培训、参观费用由团中央承担，赴井冈山单程交通费由团中央承担，西藏、新疆可乘飞机，其他省份限火车硬座/硬卧（按照财务报销相关规定）及动车、高铁二等座。返程交通费自理，回所在单位报销。提前报到和延期返程不安排食宿。
