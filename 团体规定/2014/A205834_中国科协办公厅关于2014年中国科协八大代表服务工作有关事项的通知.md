# 中国科协办公厅关于2014年中国科协八大代表服务工作有关事项的通知

各省、自治区、直辖市科协：

为深入贯彻中国科协八大精神，切实将“代表大会代表实行任期制”落到实处，在中国科协党组书记处的领导和重视关心下，在各省（自治区、直辖市）科协大力支持下，2013年中国科协先后组织开展了代表履职专题培训、代表调研课题专项资助、邀请代表出席重大活动等，为代表更好地履行职责、发挥作用提供了有效支撑。

2014年，请各省（自治区、直辖市）科协继续加强探索和创新，切实做好中国科协八大代表各项服务工作。现将有关事项通知如下：

**一、**服务对象

本省（自治区、直辖市）内的中国科协八大代表，包括由全国学会、国资委、解放军总政治部推荐的中国科协八大代表。

**二、**内容和方式

认真组织做好中国科协八大代表的日常联系和服务工作。通过组织开展走访看望、考察调研、研讨交流等活动，努力保障代表的知情权、参与权、选择权、监督权，为代表履职创造条件、搭建平台，做好支撑和服务工作，激励代表为国家科技事业和中国科协事业发展作出更大贡献。

**三、**有关事项及要求

1.请各省（自治区、直辖市）科协认真总结2013年代表服务工作有关情况，安排筹划好2014年代表服务工作，并形成书面材料，于2014年3月25日前将电子版报中国科协办公厅，请填写《代表服务工作联系表》（附件）并传真至中国科协办公厅，中国科协将给予一定的年度工作经费补贴。

2.在各有关省（自治区、直辖市）科协的大力支持和参与下，中国科协代表服务创新试点工作已开展两年。近期，中国科协办公厅将会同有关方面对各创新试点单位进行评估检查、总结验收。请各创新试点单位认真总结近两年来取得的好经验和好做法，同时注意查找存在的问题和难点，并提出改进工作的意见建议，形成高质量的总结材料，于2014年3月25日前将电子版报中国科协办公厅。

3.2014年，中国科协将在以往工作的基础上进一步加强促进代表履职意识和履职能力提升的相关工作，继续组织开展走访看望、代表调研课题专项资助等活动，请各省（自治区、直辖市）科协配合做好相关具体工作。
