# 共青团中央办公厅、国家发展改革委办公厅关于组织青年志愿者服务2014年春运的通知

共青团中央办公厅、国家发展改革委办公厅关于组织青年志愿者服务2014年春运的通知

（中青办联发[2014]1号）

各省、自治区、直辖市，新疆生产建设兵团及计划单列市团委、春运工作领导小组办公室：

2014年春运从1月16日至2月24日结束，共计40天。根据《国家发展改革委关于认真做好2014年春运工作的意见》（发改运行〔2013〕2632号）要求，为进一步提高春运服务能力和水平，共青团中央、国家发展改革委决定动员组织广大青年志愿者积极服务春运。现将有关事项通知如下。

**一、**加强志愿者组织工作

青年志愿者有理想、有奉献精神，是一支重要的力量。各地春运办要把春运志愿服务工作纳入春运工作的总体安排，加强工作协调，组织更多的志愿者参加春运。各级团组织、青年志愿者组织要主动与当地春运办、运输、公安等部门和单位加强沟通联系，掌握对春运青年志愿者的需求，制定和完善专门的春运青年志愿服务工作方案，合理配备志愿者力量，确保志愿者扎实有效开展各项志愿服务。

**二、**大力开展志愿者动员和招募

各级团组织要积极整合各类志愿者组织的力量，充分运用现有的志愿者服务站、服务基地等服务阵地开展春运志愿者动员和招募工作，广泛组织青年志愿者参加春运服务。春运志愿服务主要是在车站、机场、码头、高速公路服务区等场所，为旅客提供乘车引导、问询答疑、秩序维护、老弱病残旅客帮扶等服务，严禁安排青年志愿者从事高危性志愿服务。

**三、**做好志愿者培训和管理

各级团组织要加大志愿者的培训力度，落实志愿者岗前培训、岗位培训、专业培训和安全培训。要会同有关部门，紧密围绕春运志愿服务内容，做好志愿者服务礼仪、服务技巧、安全知识、突发事件应急处理流程等方面的培训，切实提高志愿服务水平。要进一步强化志愿者的日常管理，规范使用青年志愿者统一标识，严格落实志愿者注册管理制度，做好志愿者服务时间认定、激励表彰等工作。

**四、**做好志愿者保障工作

各级团组织、青年志愿者组织要积极与相关部门做好沟通，落实春运志愿者装备、餐饮、交通、工作经费等各项保障，科学安排志愿者服务内容和工作强度，保证人员批次递补，确保志愿者服务期间的人身安全。所服务场所的管理部门要支持做好各项保障工作，当地春运办要给予必要的协调和配合。

**五、**加强春运志愿服务宣传

各地春运办要将志愿者服务宣传作为春运宣传的重要组成部分，联合当地共青团组织，利用新闻媒体和网站等媒介，大力宣传春运志愿服务工作中的优秀志愿者和感人事迹，积极营造志愿服务春运的良好社会氛围，扩大春运志愿服务的社会影响，组织和感召更多的青年志愿者加入到志愿服务春运的行列中来，为和谐春运贡献力量。

各地春运工作总结中要包含志愿者服务的内容。各地团组织要做好春运青年志愿服务数据统计和工作总结工作，并请于3月6日前将工作总结及活动中涌现的优秀志愿者典型（个人和集体）上报至团中央青年志愿者工作部。
