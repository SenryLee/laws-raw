# 中国网球协会关于2015年全国网球裁判员注册的通知

全国各省、自治区、直辖市体育局竞训处(网球协会)：

为加强全国网球裁判员队伍的组织建设，使裁判队伍的管理更加系统规范，以适应日益增多的各类网球赛事对裁判员的需要，根据《网球国家级裁判员注册管理办法》，现将2015年网球国际级、国家级裁判员注册有关事项通知如下：

一、时间：

2014年12月15日至2015年1月31日，逾期不再办理。

二、注册资格：

年龄在60岁以下的网球国家级以上级别裁判员(国家级、国际级)。

预备国家级裁判员不需注册。

三、注册要求：

(一)由符合资格裁判员自行网上在线办理注册手续(www.imcta.cn)。

(二)各省、自治区、直辖市裁判员管理机构统一填写《网球国际级、国家级裁判员注册情况汇总表》(附件1)报各省、自治区、直辖市行业主管部门备案。

(三)注册费：在线缴纳。

国际级：200元/人

国家级：100元/人

(四)填表须知：

注册登记表格(附件2)必须认真、详实、逐栏填写，发至imcta@tennis.org.cn,否则不予注册。

(五)未在期限内注册的裁判员，将不安排本年度的裁判工作，连续两年未注册者，将取消其裁判员资格。

四、其它有关网球裁判员注册的要求，严格按照《网球国家级裁判员注册管理办法》执行。

五、在线注册流程：(见附件3)

六、裁判员工作选派和要求：

(一)2015年的裁判员工作安排仍将采取申请制度，参照《中国网球协会2015年竞赛计划和安排》以就近申请的原则，填写申请表(附件4)，发至ctajsb@sina.com

预备国家级也可填写赛事申请表。

(二)中国网球协会是中国境内举办的国际、国内网球赛事选派裁判员的唯一组织，其它任何单位或个人未经中国网球协会批准不得跨省调派裁判员。

(三)中国网球协会继续支持和鼓励国内裁判员出国执行裁判任务，但如与国内赛事需要发生冲突时，将以国内赛事为主。同时，裁判外出工作需按规定时限向中国网球协会提出申请并得到批准。

(四)未经中国网球协会批准，凡国家级以上裁判员不得私自参与全国性各类网球比赛裁判工作。一经发现，严肃处理。

(五)已选派的裁判员如因特殊原因无法执行裁判工作任务时，需提前10天向中国网球协会请假(书面)，以便另行安排，任何单位或个人不得私自替换，无故不参加工作的裁判员将停止其1年的全国各类赛事裁判资格。

(六)根据2014年下发的注册文件要求，对于未按要求执行的裁判员，将给予警告等相应处分。

(七)连续2年未参加全国性专业比赛工作的裁判员不再安排其全国性裁判工作。

(八)裁判员在接到派出任务后，至少提前1天(运动员签到开始前)到赛区报到，并不得乘坐飞机、软卧、高铁一等座位和绕道赴赛区。如无特殊情况乘坐飞机和软卧、一等座位高铁者，多于部分票款费用自付。

七、2012—2014年注册期未提交照片的裁判员(丢失注册证需要补办证件的，请在邮件中说明)，请将两张本人近期〔二寸〕免冠正面彩色照片寄至北京中网泰尼斯体育发展中心。邮寄地址：北京市东城区左安门内大街3号大宝饭店526，邮编100061 。
