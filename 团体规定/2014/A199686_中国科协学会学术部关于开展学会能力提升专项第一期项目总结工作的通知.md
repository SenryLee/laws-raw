# 中国科协学会学术部关于开展学会能力提升专项第一期项目总结工作的通知

## 中国科协学会学术部关于开展学会能力提升专项第一期项目总结工作的通知（科协学函改字〔2014〕191号）

有关全国学会、协会秘书处（办公室）：

为做好学会能力提升专项（以下简称专项）第一期项目的总结，同时为第二期项目论证工作提供支撑，开展专项第一期项目总结工作。现将有关要求说明如下：

**一、**总结内容

总结梳理2012年学会能力提升专项第一期实施以来的工作情况、重要成果及典型案例，主要坚持以下原则：

--服务国家大局。项目总结要立足国家全面深化改革的总体要求，重点围绕国家治理现代化、创新驱动发展战略等宏观形势和任务。

--全面总结。按照项目实施管理办法及专项资金管理办法，对照项目任务书，全面总结项目实施以来，学会在服务创新、服务社会和政府、服务科技工作者及服务自身发展等四个能力提升方面的各项工作。

--突出增量。详细分析项目实施前后能力培育变化情况，认真梳理和量化各项工作的增加值和绩效（含2014年全年预估数）。

--凸显亮点。服务科技、经济、社会发展中心工作需求的有力举措；体制机制创新、品牌打造、业务拓展或有明显提升的亮点工作；显著提高学会凝聚力、影响力、公信力的重点工作。

--强调示范性。在总结具体工作的基础上，梳理体制机制创新方面的共性规律和取得的突破，凝炼可复制可推广的做法、经验和模式。

--注重系统性。将能力提升和项目总结摆在学会事业总体发展层面通盘考虑，注重分析有关重点工作的体系化和协作链，以及与其他相关工作的统筹协同。

--力求可持续性。总结推动工作职能化、制度化、常规化的机制和做法。进一步思考提出下一阶段学会改革创新和能力提升的总体思路。

**二、**提交素材

1．项目总结：主要包括背景、目标、内容、亮点、措施、管理、资金、问题、建议、思考等，可添加附件。编写要求详见附件1。

2．典型案例：至少3个，每个典型案例4000字左右。编写要求详见附件2。

3．创新点：按照附件3提示和“一事一点”的原则，全面梳理学会业务工作创新点。每一小点不超过200字，具体描述该项工作的目的、内容、效果等。例如：“针对**行业**问题，于**年*月举办首届‘**大会’，参会人员***人，辐射**个行业单位，形成有关专家建议，成为国内**领域最大规模的学术交流平台”。

4．统计表：详见附件4。

学会能力提升专项第一期项目总结报告

编写要求

**一、**总体原则

围绕提升“四个能力”、建设一流科技社团的总体目标，按照项目目标和工作任务，全面总结项目执行以来的实施情况，完整呈现项目实施从酝酿、策划、组织实施到完成的全貌，突出学会工作特色和亮点，概括学会能力建设经验，具有较高的可操作性及可借鉴性。

**二、**内容结构

（一）背景与目标。简要描述项目设计背景、主要目标、重点任务等。

（二）项目完成情况。简要描述项目实施的总体概况。分提升服务创新能力、提升服务社会和政府能力、提升服务科技工作者能力、提升服务自我发展能力四个方面总结各项工作实施情况。

（三）项目绩效。一是围绕项目绩效目标，总结项目在服务中心工作，提升四个能力，创新体制机制，提升学会凝聚力、影响力、公信力等方面的主要成果。二是总结梳理项目亮点，以及具有示范推广意义的做法、模式和经验等。

（四）项目领导和资金管理。描述对项目的组织领导情况、制度完善情况和资金管理情况。做好财务验收工作有关准备。

（五）问题与建议。一是如实描述项目实施中存在的主要问题和不足，包括未完成情况的说明。二是围绕解决问题、进一步推进学会改革创新，提出有关建议和思考。

（六）下一步工作思路。下一步学会改革创新和能力提升有关工作的总体考虑或计划。

**三、**格式要求

文字用word文档。题目用小二号小标宋体，一级标题用四号黑体，二级标题用四号楷体_GB2312，三级标题以下（含）均用四号仿宋_GB2312体，正文用四号仿宋_GB2312体。具体详见模板。

**四、**附件要求

总结材料应附项目有关成果材料清单，并提交主要成果的佐证材料，如汇编、书籍、制度、照片等。

附件2

学会能力提升专项第一期项目典型案例

编写要求

**一、**编写原则

项目案例应围绕一项重点工作，突出增量、特色和亮点，完整呈现项目实施从酝酿、策划、组织实施到完成的全貌，总结概括能力建设经验，具有较高的可操作性及可借鉴性。案例撰写要确保“事、点、法、数、评”等要素齐全，即项目的指向明确，重点内容具体清晰，实施的机制方法科学合理并符合财政项目要求，经费测算和使用符合有理有据，项目有可评估的量化指标。行文应条理清楚、有理有据，文字高度凝炼、生动形象。每个学会不少于3个案例。

**二、**主要内容

案例由三部分构成，不超过4000字。

第一部分：引言。概要介绍项目策划背景、目的意义、实施概况、组织领导、管理制度等。700字左右。

第二部分：案例描述。实施的详细过程，重点突出项目的创新点与特色，实施过程中出现的主要问题及采取的措施。最好穿插一两个形象、生动的实例，以增强可读性。2000字左右。

第三部分：效益与经验。围绕“四个能力”及对学会凝聚力、影响力、公信力等，总结项目取得的主要效益。项目形成的可复制可推广的做法、模式和经验等。项目实施中的主要不足。800字左右。

第四部分：下一步工作考虑。对此项工作进一步提升、拓展的计划安排。500字左右。

第五部分：典型案例概况表。

|  |  |
| --- | --- |
| 工作性质 | 此项工作是一次性还是持续性的工作？ |
| 绩　　效 | 此项工作属于直接的能力提升点，还是能力提升后拓展形成的工作点？ |
| 经费来源 | 此项工作总支出经费及来源。来源包括能力提升专项支持、学会活动收入等。 |
| 形　　态 | 此项工作是相对独立的单项工作，还是已与其他工作形成比较系统、协同的工作链？ |

**三、**案例格式

文字用word文档。题目用小二号小标宋体，一级标题用四号黑体，二级标题用四号楷体_GB2312，三级标题以下（含）均用四号仿宋_GB2312体，正文用四号仿宋_GB2312体。具体模板同总结报告模板。

**四、**配图要求

提供有代表性的、与文章内容相结合的图片不少于3张。要求画面清晰，jpeg格式，每张至少500K大小。请将每张图片单独命名后作为文件报送，切勿粘贴到word文档内，以保证图片印刷质量。
