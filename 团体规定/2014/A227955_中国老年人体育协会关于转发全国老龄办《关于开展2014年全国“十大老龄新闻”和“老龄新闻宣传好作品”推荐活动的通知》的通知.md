# 中国老年人体育协会关于转发全国老龄办《关于开展2014年全国“十大老龄新闻”和“老龄新闻宣传好作品”推荐活动的通知》的通知

体老字〔2014〕100号

各省、自治区、直辖市、计划单列市、新疆生产建设兵团老年人体育协会，各行业老年人体育协会，有关单位：

2014年是全面贯彻《中国老龄事业发展“十二五“规划》、大力实施新修订的《老年人权益保障法》、切实落实国务院《关于加快发展养老服务业的若干意见》、加快推进基层老年协会建设、广泛发动第二届全国“敬老文明号”和第五个全国“敬老月”活动丰收之年，为进一步加强老龄宣教育传工作，全国老龄工作委员会办公室决定开展2014年度全国“十大老龄新闻”和“老龄新闻宣传好作品”推荐活动。

为响应全国老龄工作委员会办公室号召，加强对老年体育工作的宣传，现转发《关于开展2014年全国“十大老龄新闻”和“老龄新闻宣传好作品”推荐活动的通知》，请各单位按照通知要求，积极组织推荐候选新闻事件和新闻作品，于2014年12月22日前报中国老年人体育协会秘书处(请提供电子版，并在作品中标注新闻发表单位)，由协会初评后报组织单位参加评选。
