# 共青团中央办公厅关于转发《中国青少年研究会第四届理事会组成方案与理事候选人推选办法》的通知

## 共青团中央办公厅关于转发《中国青少年研究会第四届理事会组成方案与理事候选人推选办法》的通知（中青办发[2014]52号）

共青团各省、自治区、直辖市委，解放军总政治部组织部，全国铁道团委，全国民航团委，中直机关团工委，中央国家机关团工委，中央金融团工委，中央企业团工委，新疆生产建设兵团团委：

中国青少年研究会自1999年1月成立以来，对全团青少年研究事业的发展和青少年工作水平的提高起到了积极的推动作用。按照《中国青少年研究会章程》规定，中国青少年研究会第三届理事会任期已满，今年将推选产生第四届理事会。

为做好理事推选和换届工作，现转发《中国青少年研究会第四届理事会组成方案与理事候选人推荐办法》。请各省级团委按照要求，做好理事候选人的推荐工作，于10月30日（星期四）前报中国青少年研究会办公室。

中国青少年研究会第四届理事会组成方案

与理事候选人推荐办法

根据《中国青少年研究会章程》的有关规定及前三届理事会的组成情况，中国青少年研究会第四届理事会组成方案与理事候选人推荐办法如下：

**一、**理事会组成原则

根据《中国青少年研究会章程》和日常业务开展的实际需要，第四届理事会的组成将贯彻以下原则：

一是强化学术性。大力吸纳全国青少年研究方面的知名专家学者进入理事会，使中国青少年研究会切实成为凝聚、整合全国青少年研究资源的组织平台和权威学术机构。

二是体现广泛性。注重内外结合、优势互补，除共青团系统内的青少年、青运史研究方面的专家学者外，也要重视各地社科系统、高等院校、教育科研系统、企业界和其他社会团体的专家学者和热心人士所占的比重和数量。

三是注重实用性。扩大热爱青少年研究事业，具有较高科研水平的学术带头人、学科带头人所占数量，使理事会和常务理事会成为务实高效的学术领导机构。

**二、**理事会和常务理事会构成

（一）理事会构成

第四届理事会理事人选约160名，由以下三方面人士组成：

1. 团中央机关各部门及与青少年研究工作关系密切的直属单位负责人；

2. 各省青少年研究机构负责人，省内知名青少年研究专家；

3. 社会各界热心青少年研究的专家、学者及相关人士。

（二）常务理事会构成

依照《中国青少年研究会章程》，从利于开展工作，发挥作用的角度考虑，常务理事拟设21人，由以下人士担任：

1. 团中央相关领导及相关部门部长或副部长；

2. 中国青少年研究中心、中国青少年研究会相关负责人；

3. 中国青年政治学院、中国青年报、团中央网络影视中心相关负责人；

4. 青少年研究领域的知名专家学者。

**三、**常设领导机构与工作机构设置

按照《中国青少年研究会章程》规定，中国青少年研究会常设领导机构为常务理事会。本会日常工作机构为秘书处，负责重大科研项目与重要事项的协调、落实。秘书处下设办公室，受秘书长领导，负责处理日常事务。第四届理事会领导机构设置如下：

1. 会长1名；

2. 常务副会长（法人代表）1名；

3. 副会长17名；

4. 秘书长1名；

5. 副秘书长30名。

**四、**理事、常务理事、会长、副会长、秘书长、副秘书长产生办法

1. 各地理事人选由各省级团委根据理事分配名额，通过适当方式推选出本地（本系统）理事人选，经本省级团委审核，报送中国青少年研究会办公室；中央国家机关有关部委，人民团体，科研机构，高校，新闻单位和团中央机关及直属单位的理事人选由中国青少年研究会办公室协商提出，经中国青少年研究中心审议，报团中央书记处分管书记同意。全体理事候选人均将提请中国青少年研究会会员代表大会审议通过。

2. 常务理事候选人由研究会办公室协商提出，经中国青少年研究中心审议，报团中央书记处分管书记同意，提请中国青少年研究会第四届理事会第一次全体会议审议通过。

3. 研究会会长、副会长、秘书长、副秘书长及各专业委员会主任、副主任人选由中国青少年研究会办公室协商提出，经中国青少年研究中心审议，报团中央书记处分管书记同意，提请中国青少年研究会第四届理事会第一次理事会全体会议审议通过。

**五、**专业委员会设置

为进一步凝聚专业力量，从实际出发，形成自身特色，中国青少年研究会设以下3个专业委员会：

1.青年研究人才队伍建设专业委员会

2.家庭教育研究专业委员会

3.青少年社会教育研究专业委员会。

专业委员会负责学科建设和日常学术活动的开展。专业委员会主任、副主任、委员由常务理事或理事担任。
