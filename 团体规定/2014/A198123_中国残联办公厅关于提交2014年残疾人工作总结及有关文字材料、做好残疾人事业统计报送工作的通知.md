# 中国残联办公厅关于提交2014年残疾人工作总结及有关文字材料、做好残疾人事业统计报送工作的通知

## 中国残联办公厅关于提交2014年残疾人工作总结及有关文字材料、做好残疾人事业统计报送工作的通知（残联厅函〔2014〕251号）

各省、自治区、直辖市及计划单列市残联，新疆生产建设兵团残联，黑龙江垦区残联：

为了解掌握2014年残疾人工作整体情况，研究安排2015年工作，现就各地提交2014年残疾人工作总结及有关文字材料、报送统计信息有关事项通知如下：

**一、**关于提交2014年残疾人工作总结、工作亮点和做好2015年残疾人工作、制定好残疾人事业“十三五”发展纲要的意见建议

请各地残联及时开展年度工作总结，认真对照年初印发的《2014年残疾人工作要点》，梳理工作现状，总结成绩和经验，查找问题与不足，形成3000字左右的文字报告。对于本地2014年残疾人工作中最具特点、最富有成效的亮点内容，请单独形成300字左右的文字材料。在总结工作过程中，要检查各项工作完成情况，进一步加大工作力度，确保年度任务圆满完成。

2015年是全面落实残疾人事业“十二五”发展纲要的收官之年，也是制定残疾人事业“十三五”发展纲要的关键一年。请各地残联围绕贯彻落实党中央、国务院发展残疾人事业的决策部署，结合本地特点和工作实际，研究提出做好2015年残疾人工作，制定好残疾人事业“十三五”发展纲要的意见建议。

请于2014年11月25日前将上述三份材料通过电子邮件和《全国残联信息资料报送管理系统》报中国残联。电子邮件地址：bgt@cdpf.org.cn，《报送管理系统》的网址：http：//fagao.cdpf.org.cn。各地残联通过各自的用户名和密码登录《全国残联信息资料报送管理系统》，在“总结及要点”栏目节点下报送相关文件和材料。如原有登录用户名及密码遗忘或有相关技术问题请与中国残联信息中心张然联系。

**二、**关于做好2014年残疾人事业统计报送工作

统计数据是各项业务工作进展的直接反映，是做好年度工作总结与下年度工作部署的重要依据。各地残联要加强领导和统筹，业务部门与综合统计部门紧密配合，认真做好统计数据的按时填报和逐级审核工作，严格控制数据质量，提高快报与年报、台帐数据的一致性，保证数据真实、准确、及时地反映业务工作进展。请按照《关于做好2014年度残疾人事业统计工作的通知》（残联厅函〔2014〕202号）规定的时间和上报要求做好数据报送工作。
