# 中国科学技术协会调研宣传部关于召开中国科协2014年度调查类调研课题中期评审会的通知

各课题承担单位：

根据《中国科协科技工作者状况调查项目管理办法》，中国科协调研宣传部拟于2014年9月29日在北京中国科技会堂举行2014年度调查类调研课题中期评审会，汇报日程安排见附件。请各课题组准备汇报材料，按时参会，一般不得缺席。有关要求如下：

**一、**参加中期汇报的课题组从研究思路、研究进展、阶段性研究成果、存在问题和不足等方面，特别是调查问卷的设计工作进行汇报，每个课题25分钟，其中课题组汇报时间10分钟，专家评议15分钟。

**二、**参加中期汇报的课题组需准备汇报PPT和10份纸质汇报材料，并将电子和纸质材料在会前提交工作人员。

**三、**各课题组原则上由主要负责人汇报。未通过中期评估的课题不予拨付后续经费，并通知所在单位。

**四、**各课题组汇报的具体时间如有调整，工作人员将另行通知。
