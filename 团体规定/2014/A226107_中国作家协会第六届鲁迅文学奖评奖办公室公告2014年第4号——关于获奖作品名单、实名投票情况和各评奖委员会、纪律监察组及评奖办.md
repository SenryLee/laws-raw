# 中国作家协会第六届鲁迅文学奖评奖办公室公告2014年第4号——关于获奖作品名单、实名投票情况和各评奖委员会、纪律监察组及评奖办公室名单的公布

## 第六届鲁迅文学奖评奖办公室公告

2014年第4号

第六届鲁迅文学奖各评奖委员会对经过公示的提名作品进行了认真评审，于2014年8月11日分别投票表决，产生了七个奖项的获奖作品。现将获奖作品名单、实名投票情况和各评奖委员会、纪律监察组及评奖办公室名单予以公布。

特此公告。

第六届鲁迅文学奖评奖办公室

2014年8月11日
