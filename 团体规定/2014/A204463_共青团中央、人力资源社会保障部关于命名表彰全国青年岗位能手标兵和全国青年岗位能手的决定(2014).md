# 共青团中央、人力资源社会保障部关于命名表彰全国青年岗位能手标兵和全国青年岗位能手的决定(2014)

## 共青团中央、人力资源社会保障部关于命名表彰全国青年岗位能手标兵和全国青年岗位能手的决定（中青联发[2014]9号）

近年来，各地区、各行业深入开展青年岗位能手活动，组织广大青年职工练就过硬本领、提高技能水平、增强创新能力，一大批熟练掌握专业知识技能、立足岗位扎实奉献的青年岗位能手在活动中脱颖而出。

为表彰先进、树立典型，共青团中央、人力资源社会保障部联合开展了全国青年岗位能手标兵和全国青年岗位能手评选活动，在综合技能竞赛、国家重点工程实施、全团“寻找最美青工”活动和日常工作实践等方面情况的基础上，经广泛发动、多种方式择优推荐和严格审核，决定授予山东省济南市城肥清运管理二处工人于海等30名同志“全国青年岗位能手标兵”称号，授予首钢京唐钢铁联合有限责任公司酸轧日修钳工陈云等585名同志“全国青年岗位能手”称号。

全国青年岗位能手标兵和全国青年岗位能手是各行各业青年职工的先进代表，集中体现了当代青年职工追求梦想、爱岗敬业、刻苦学习、创新创造、扎实奉献的优秀品质。

共青团中央、人力资源社会保障部号召全国广大青年职工以先进典型为榜样，学习他们志存高远、报效祖国的理想信念，学习他们敬业奉献、锐意进取的职业精神，学习他们脚踏实地、艰苦奋斗的优秀品格，在全面建成小康社会、实现中国梦的历史进程中建功立业。

希望受到表彰的同志珍惜荣誉，再接再厉，取得更大的成绩。各级团组织、人力资源社会保障部门要通力协作介绍好、宣传好先进典型；要不断深化青年人才培养工作，努力造就一支高素质青年职工队伍，为全面深化改革、推动经济社会持续健康发展作出更大的贡献。
