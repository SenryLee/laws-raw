# 中国林学会关于推荐中国林学会林下经济分会第一届委员会委员候选人的通知

中林会学字[2014]56号

各省、自治区、直辖市林业厅（局），林学会，中国林学会各有关分会，专业委员会，各有关单位和专家：

为加强林下经济学术交流，深化林下经济理论研究，推广林下经济典型模式和经验，促进生态林业民生林业发展，经中国林学会常务理事会批准，学会决定成立林下经济分会。

中国林学会林下经济分会是中国林学会分支机构之一，是顺应近年来我国林下种植、养殖、森林旅游观光以及森林景观综合利用等林下经济蓬勃发展的新形势而成立的。其主要任务是开展林下经济学术交流，活跃学术思想，促进学科发展与科技创新；推广林下经济科学技术与发展模式，促进农民增收和地方经济发展；发挥“智库”优势，开展林下经济咨询服务；加强科技与经济的结合，促进生态林业民生林业发展；加强国际民间交流与合作，促进学术和智力交流；普及林业和生态知识，促进生态文明和美丽中国建设。

为做好林下经济分会成立的有关筹备工作，经研究，中国林学会秘书处面向有关单位征集分会委员候选人，现将有关事项通知如下：

一、委员候选人条件

林下经济分会委员候选人必须具备以下条件之一：

1. 热心学会工作，能组织或参与林下经济分会活动；

2. 从事或熟悉林下经济研究、教学或经营和管理工作；

3. 在林下经济学科领域取得一定科技成果和教学业绩；

4. 在林下经济发展中取得较好经营成绩和管理成效；

5. 具有一定学术造诣或管理经验，自愿为林下经济学科发展和管理奉献力量。

二、委员候选人产生方式

分会委员候选人采取单位推荐和本人自荐的方式。

三、推荐单位及名额

（一）推荐单位

1. 全国林业及有关高等院校、科研机构；

2. 国家林业局有关司局和直属事业单位；

3. 各省、自治区、直辖市林业厅（局）、林学会；

4. 农业等部门相关单位；

5. 相关国有或民营企业。

（二）推荐名额

各单位推荐名额原则上不超过2名。

四、截止时间

本次委员候选人推荐截止时间为2014年12月5日，请各单位和个人在截止时间前将委员候选人推荐表发邮件或传真至中国林学会秘书处。
