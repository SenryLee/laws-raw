# 中国科协学会学术部关于举办中国科协学会改革发展论坛(第二期)的通知

## 中国科协学会学术部关于举办中国科协学会改革发展论坛（第二期）的通知（科协学函改字〔2014〕190号）

有关全国学会、协会、研究会秘书处（办公室），有关单位：

科技奖励评价是学会服务科技、经济、社会发展中心工作的重要着力点，专家队伍建设是确保科技奖励评价权威公正的核心内容，为进一步推动科技奖励评价工作的改革、创新和发展，拟围绕科技奖励评价专家队伍建设为主题，举办第二期中国科协学会改革发展论坛，本期论坛由中国公路学会承办。现将有关事项通知如下：

**一、**论坛主题

学会科技奖励评价工作中的专家队伍建设

**二、**论坛的主要内容与议题

1．同行评价在科技奖励评价工作中的作用；

2. 如何建立科学的专家遴选和举荐机制，确保选出权威公正的专家；

3．专家队伍的公开公示制度建设；

4.专家在科技奖励评审工作中的作用发挥；

5．学会奖励评价工作专家队伍的工作制度建设，如问责制、淘汰制、回避制度等；

6. 与专家队伍建设相关的其他议题。

**三、**时间和地点

会议时间：2014年8月29日8：30-16：00，会期一天，京外代表请于8月28日报到。

会议地点：北京竹园宾馆（北京市西城区旧鼓楼大街小石桥24号）

**四、**参加人员

中国科协所属全国学会主管或承担科技奖励工作，具有一定理论积累和实践经验的人员，每学会报名人数限2人以内。

**五、**论坛组织形式

（一）主办与承办单位

主办单位：中国科协学会学术部

承办单位：中国公路学会

（二）组织形式

主题发言与自由讨论相结合

**六、**论坛征集交流要点

为确保交流效果，激发思想碰撞，形成切实可行的改革发展思路和建议，请参加本论坛的学会提供至少1篇与论坛主题相关的文章。

因时间较紧，文章提交的形式为“交流要点”即可，要求观点明确新颖，行文简洁明了，内容有较强的针对性、建议性和可操作性，字数不少于1000字。

论坛结束后，将对提交的全部交流要点进行遴选，精选出的交流要点，再商请作者形成正式论文，收录到中国科协2014年学会改革发展论坛汇编中。

**七、**报名及投稿

（一）请将交流要点全文电子版于2014年8月20日前发送至中国公路学会。邮件主题请标明“中国科协学会改革发展论坛（第二期）”。

（二）报名截止日期为2014年8月24日中午12：00。请于8月24日前以电子邮件方式提交参会意向反馈表（附件1）和调查问卷（附件2）。
