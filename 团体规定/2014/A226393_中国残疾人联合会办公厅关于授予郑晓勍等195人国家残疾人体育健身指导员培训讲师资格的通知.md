# 中国残疾人联合会办公厅关于授予郑晓勍等195人国家残疾人体育健身指导员培训讲师资格的通知

残联厅函（2014）320号

各省、自治区、直辖市残联，新疆生产建设兵团残联：

为进一步推进各地残疾人体育健身指导员培训工作的开展，确保完成残疾人体育工作“十二五”实施方案培养3万名残疾人体育健身指导员的工作任务，中国残联于2014年11月在北京体育大学举办了第六期和第七期国家残疾人体育健身指导员师资培训班。

经培训、考核，决定授予郑晓勍等195人国家残疾人体育健身指导员培训讲师（初级）资格。请各省级残联做好本地国家残疾人体育健身指导员培训讲师的登记和备案工作，于2015年1月16日前将获得讲师资格的国家残疾人体育健身指导员培训讲师登记表（见附件2）统一汇总后传真或邮寄至中国残联体育部，并将电子版发送至中国残联体育部邮箱。
