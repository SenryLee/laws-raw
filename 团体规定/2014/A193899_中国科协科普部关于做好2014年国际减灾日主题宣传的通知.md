# 中国科协科普部关于做好2014年国际减灾日主题宣传的通知

## 中国科协科普部关于做好2014年国际减灾日主题宣传的通知（科协普函综字〔2014〕75号）

各全国学会、协会、研究会科普部，各省、自治区、直辖市科协科普部，新疆生产建设兵团科协科普部：

今年10月13日是第25个国际减灾日，主题是“提升抗灾能力就是挽救生命--老年人与减灾”。为做好今年“国际减灾日”各项工作，国家减灾委员会日前下发《国家减灾委员会关于做好2014年国际减灾日主题宣传的通知》（国减发〔2014〕4号）。

请各全国学会、协会、研究会科普部，各省、自治区、直辖市科协科普部和新疆生产建设兵团科协科普部，结合今年国际减灾日主题认真组织各项科普宣传活动，并将总结报告（电子版）于11月10日前报至中国科协科普部。
