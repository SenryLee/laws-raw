# 共青团中央办公厅关于开展驻外团工委“一起回家”、“一起过年”活动的通知

## 共青团中央办公厅关于开展驻外团工委“一起回家”、“一起过年”活动的通知（中青办发[2014]2号）

共青团各省、自治区、直辖市委，新疆生产建设兵团团委：

为进一步巩固驻外团工委建设成效，切实增强各级驻外团工委组织活力和服务能力，扩大对外出务工青年群体的有效覆盖，团中央决定近期集中开展“一起回家”、“一起过年”活动，推进驻外团工委的建设和工作。现将有关要求通知如下。

**一、**时间安排

2014年1月-2月

**二、**工作目标

以各地跨省流动、省内跨地市流动外出务工青年和他们的家属为主要服务对象，抓住春节期间外出务工青年集中返乡、过年的有利时机，开展实实在在的服务活动，切实增强驻外团组织对外出务工青年的有效工作覆盖。

**三、**主要内容

以“一起回家”、“一起过年”为主题，在春节前后一段时间集中开展一系列服务外出务工青年活动，帮助他们安全便捷返乡、平安快乐过年，增强驻外团组织对外出务工青年的吸引和凝聚。

1. 帮助购买车票。通过提前预售、团体购票、送票上门的方式，帮助工作或居住较为集中外出务工青年更加便捷的购买返乡和回程车票。

2. 提供出行便利。组织青年志愿者在火车站、长途汽车站、水运客运站、城市和交通枢纽站等地，设置共青团服务岗（站），为返乡务工青年提供志愿服务。与客运管理部门或企业协调，在客流集中的线路上安排中长途包车直达、上门接客等便利服务。在青年农民工流动重点城市间开行的列车编组中，安排“外出务工青年”专用车厢或专门区域，为外出务工青年提供相对舒适的乘车环境。

3. 发布实用信息。充分利用手机短信、微博、微信、QQ群、论坛等渠道，向外出务工青年提供汇款资费、邮递网点、年货采购、行包托运、乘车须知、安全常识等实用信息，并适时发送节日问候和真诚祝福，让外出务工青年感受到团组织的温暖。

4. 慰问送温暖。针对农村留守儿童、农村留守老人和在城市过年的外出务工青年及其子女等群体，集中开展送温暖、送祝福活动，向他们赠送保暖衣物、文体用品、米面粮油、春联福字等“年货”，给他们送去团组织的祝福和关心。

5. 组织新年聚会。针对留在城市过年的外出务工青年，在他们集中就业的企业和居住的社区，开展形式多样的新年聚会或文化娱乐活动，通过组织新年联谊会、放映贺岁电影、观看民俗演出、游览市井庙会、观看或者演出家乡戏等活动，丰富外出务工青年春节期间的业余文化生活，拉近团组织与普通青年的距离。

6. 组织亲情交流活动。各地团组织和驻外团工委要充分利用固定电话、移动通讯、网络视频等通讯手段，组织开展亲情视频、网络拜年等亲情交流活动，为青年农民工与家乡亲人交流提供便利。

**四、**有关要求

务工青年流出地和流入地团组织要密切合作、形成合力，扎实做好“一起回家”、“一起过年”活动，为外出务工青年提供实实在在的服务。流出地和流入地团组织要分别形成活动总结。各地在开展服务外出务工青年活动中的新闻线索，要随时反馈团中央组织部，便于统筹安排新闻宣传。总结材料请于2014年2月28日前报团中央组织部。
