# 中国资产评估协会关于2023-2024年中国资产评估协会重大研究课题立项评审结果的公告

## 关于2023-2024年中国资产评估协会重大研究课题立项评审结果的公告

2023年11月10日，中国资产评估协会发布了《关于征集2023-2024年中国资产评估协会重大研究课题承研单位的公告》（中评协公告〔2023〕23号）。根据《中国资产评估协会研究课题管理办法》，中国资产评估协会组织专家对符合重大研究课题申报要求的材料进行了立项评审，确定了5个重大研究课题的承研单位。现将立项评审结果公告如下：

2023-2024年中国资产评估协会重大研究课题立项评审结果

|  |  |  |
| --- | --- | --- |
| 序号 | 课题名称 | 承研单位 |
| 1 | 《基于应用场景的企业数据资产价值评估研究》 | 北京卓信大华资产评估有限公司 |
| 2 | 《专精特新企业价值评估研究》 | 首都经济贸易大学 |
| 中南财经政法大学 |
| 3 | 《境外国有资产评估研究》 | 北京国融兴华资产评估有限责任公司 |
| 4 | 《政府公共数据资源资产化过程中的价值评估研究》 | 江西财经大学 |
| 5 | 《评估机构如何开展ESG业务研究》 | 天昊国际房地产土地资产评估集团有限公司 |
