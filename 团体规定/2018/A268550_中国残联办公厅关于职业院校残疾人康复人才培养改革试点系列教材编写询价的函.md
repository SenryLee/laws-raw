# 中国残联办公厅关于职业院校残疾人康复人才培养改革试点系列教材编写询价的函

相关出版单位：

按照中国残联办公厅、教育部办公厅《关于开展职业院校残疾人康复人才培养改革试点工作的通知》[残联厅发（2016）19号]要求，中国残疾人联合会（以下简称中国残联）将开展职业院校残疾人康复人才培养改革试点系列教材编写工作，拟通过询价方式确定编写任务承接单位。现将有关事项函告如下：

一、项目情况

（一）项目背景

为推动职业院校康复类专业人才培养模式改革创新，提升残疾人康复人才培养水平，2016年，中国残联和教育部共同启动了职业院校残疾人康复人才培养改革试点工作，为保障试点工作顺利推进，中国残联组织有关专家启动了试点系列教材编制工作，确定将编写《康复医学概论》《运动治疗技术》《作业治疗技术》《康复护理》《物理因子治疗技术》5本教材。

（二）工作要求

1.组织人员对国内外该专业学科领域的实际状况、先进理念做准确的分析，制定合理的教材大纲和工作方案。

2.确定由熟悉并了解该专业学科领域的权威专家、一线工作者组成编写组，多方调研、科学论证，确保内容通俗易懂，贴近职业院校教学实际工作需求。

3.形成教材样稿。

4.根据专家论证意见和有关方面意见修改后形成最终教材。

（三）完成时间

2018年11月20日前完成最终稿。

（四）经费预算

不超过95万元。

二、报价文件

（一）文件内容

1.出版单位简介、组织机构、人员构成。

2.企业法人营业执照。

3.资质证书。

4.教材出版方案。

5.报价（费用构成）。

6.服务承诺。

7.项目负责人与编写成员简介。

8.近五年承担的主要教材编写出版清单。

9.其他需要说明的事宜。

（二）相关要求

1.单位名称应填写全称。

2.报价文件不得随意涂改和增删。

3.报价文件原件1份、双面复印件5份密封包装，封口处加盖单位公章。

三、文件递交

（一）递交时间

2018年8月30日12:00前，超过截止时间递交文件将不予受理。

（二）递交地点

北京市西城区西直门内南小街186号中国残联康复部。

四、项目评审

中国残联将组织评审组，按照“公开、公平、公正、效益”的原则，对编写出版方案、报价、服务承诺、编写人员情况等因素进行综合评审。根据评审情况，从满足服务要求与实际需要的单位中择优选取服务商。
