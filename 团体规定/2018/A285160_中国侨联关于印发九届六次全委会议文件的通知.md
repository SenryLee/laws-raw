# 中国侨联关于印发九届六次全委会议文件的通知

中侨发〔2018〕1号

各省、自治区、直辖市侨联，中央直属机关、中央国家机关、中央企业侨联，新疆生产建设兵团侨联，中国侨联机关各部门、各直属企事业单位：

现将万立骏主席在中国侨联九届六次全委会议上题为《深入学习宣传贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，扎实推进新时代侨联工作改革发展》的工作报告、《关于深入学习宣传贯彻党的十九大精神，广泛团结联系海外侨胞和归侨侨眷，共同致力于中华民族伟大复兴的决议》、《中国侨联九届六次全委会议增补委员、常委名单》、有关决议及李卓彬副主席的总结讲话印发你们，望结合工作实际，认真组织学习贯彻。
