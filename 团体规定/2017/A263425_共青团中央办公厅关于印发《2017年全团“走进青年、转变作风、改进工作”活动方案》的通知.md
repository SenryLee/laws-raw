# 共青团中央办公厅关于印发《2017年全团“走进青年、转变作风、改进工作”活动方案》的通知

中青办发〔2017〕10号

共青团各省、自治区、直辖市委,中央军委政治工作部组织局群团处,全国铁道团委,全国民航团委,中直机关团工委,中央国家机关团工委,中央金融团工委,中央企业团工委,新疆生产建设兵团团委:

现将《2017年全团“走进青年、转变作风、改进工作”活动方案》印发给你们,请遵照执行。

共青团中央办公厅

2017年7月7日

## 2017年全团“走进青年、转变作风、改进工作”活动方案

按照团中央书记处要求,今年将在全团继续开展“走进青年、转变作风、改进工作”活动。有关安排如下。

一、活动主题

走进青年、转变作风、改进工作

二、时间安排

团中央机关分两批开展活动。第一批时间为7月31日至8月18日,9月1日(星期五)前提交工作报告。第二批时间为8月21日至9月8日,9月22日(星期五)前提交工作报告。第一批人员相对集中,各部门除留一名局级干部在机关处理日常工作外,其余局级干部均参加第一批调研。

三、人员和地点安排

团中央调研组由书记处同志或局级干部带队,人数一般3至4人。办公厅按照均衡原则给各部门分配调研省份,由各部门进行内部调配、分组并与地方团委进行对接,分组情况报办公厅汇总。参加最近一批下沉的干部不参加本次活动。

四、主要任务

活动期间,团中央各调研组均应完成5项任务。

1.调研问题,提出对策。每个调研组从题目清单(附件1)中选择1个主题目,也可同时选择1至2个副题目,由办公厅作适当统筹后,以调研任务通知单形式反馈调研组。各调研组可根据题目自主设计开展调研工作,着眼未来一段时期内共青团事业的创新发展,针对具体问题研究提出对策建议。有关研究成果应在提交工作报告时一并提交。

2.检查成效,督促落实(附件2)。各调研组根据团中央第一轮综合督导对各地的反馈意见,逐项检查有关工作要求在基层的整改落实情况,尚未落实的要督促说明原因并制定整改计划。结合6项重点工作中期考核结果,督促所到省份团委按照全团统一部署,进一步推进重点工作。检查各地其他工作项目的推进情况,收集和研究工作中存在的突出问题,及时给出指导意见。检查督促有关情况要写入工作报告。

3.谈心谈话,作出评价。每个调研组应与所到省份所有地市级团委书记和不少于80%的区县级团委书记分别进行一次谈心谈话,了解他们对工作的认识和感受,就下一步的工作给出有针对性的指导意见。活动结束后,调研组应对该省份团干部的精神面貌、工作成效等作出整体评价,写入工作报告。同一省份有两个以上调研组的,相互间要做好沟通协调。

4.联系青年,了解社会。调研组成员应结合“1+100”工作“五个一”制度要求,参加“一学一做”基层团组织活动、志愿服务活动等以团员、青年为主体的活动,充实个人“1+100”工作对象并加强日常联系。有计划地了解和学习基层党政在开展脱贫攻坚、深化改革、舆论引导、民主协商等方面工作的情况,深入基层一线体验国情社情民情,提高思想认识,积累工作经验。

5.梳理经验,发掘典型。各调研组应注重梳理和提炼基层在破解全团共性问题上的好经验好做法,发现行之有效的创新做法和形象鲜活的典型人物。每个调研组应围绕承担的调研题目提炼若干具有示范借鉴意义的典型案例,写入工作报告。

五、工作要求

1.认真开展谋划。着眼为召开团十八大做好调研准备,以深化改革为主题,系统研究当前工作中的牵动性、瓶颈性问题,对未来一段时期全团的重点工作进行初步谋划。

2.加强工作指导。把本次活动作为联系支持基层的重要抓手,在活动中尽可能广泛地接触基层团干部,深入了解具体情况,认真研究突出问题,及时为基层提供指导和帮助。

3.密切联系青年。自觉落实直接联系青年的各项制度要求,有效回应青年提出的疑惑和困难,力所能及地帮助解决一些实际问题,要力争建立起经常性联系。

4.严格作风要求。认真贯彻中央八项规定精神,严格遵守团中央落实中央八项规定精神的实施办法和团干部下基层调研的相关规定,扎扎实实深入基层,展现优良工作作风。

各省级、地市级团委要参照团中央有关安排设计和开展活动,于10月13日(星期五)前提交本级及所属地市级团委开展活动的综合工作报告。

附件1

## 调研题目备选清单

1.影响青少年价值观塑造的核心要素

可重点研究如何在海量的现象中抽象出一般的价值观塑造规律,如何对不同类型的思想引导工作手段进行具有指导意义的效果评估,如何根据影响力标准对思想引导工作对象进行深度区分等问题。

2.深化从严治团的实现路径

可重点研究新形势下党中央提出从严治团课题的背景和核心要求,团的自身特点对落实从严治团的客观要求,从严治团概念的内涵与外延,如何从信念养成、纪律约束等方面对深化从严治团进行整体设计等问题。

3.共青团先进性建设的实现路径

可重点研究少先队员“全员入队”与少先队组织具有先进性二者之间的逻辑关系,在共青团员思想领域开展先进性建设的关键环节和工作抓手,新形势下保持和发挥共青团先进性的工作机制建设等问题。

4.新形势下的青年组织体系建设

可重点研究如何适应现代社会发展对组织体系建设提出的新要求,如何实现网络建团等新的组织方式与传统组织方式协调发展,因社会成员角色的多重性而对其进行多重组织覆盖的必要性和可行性等问题。

5.共青团专挂兼干部队伍激励和约束机制建设可重点研究如何通过制度化手段吸引优秀人才到团的岗位接受锻炼,如何激发在岗专挂兼职干部的工作积极性,如何提升专挂兼干部岗位匹配的专业化和科学化水平等问题。

6.建设以需求为导向的工作资源整合机制

可重点研究如何在现有组织体系框架内实现工作资源的精准供给和顺畅流转,如何以工作牵动力为依据对存量资源进行优化配置,如何运用网络等新载体在更大范围内广泛争取资源等问题。

提示:每个课题均需提炼2至3个具有示范借鉴意义的典型案例,作为调研报告附件一并报送。

附件2

## 督促检查工作任务清单

一、检查综合督导意见的整改落实情况

根据团中央第一轮综合督导对各地的反馈意见,重点围绕改革攻坚、从严治团、“一学一做”3项工作,逐项检查有关工作要求在该省(区、市)和基层的整改落实情况。

二、检查其他重点项目的部署推进情况

1.《中长期青年发展规划(2016—2025年)》贯彻落实。一是启动本地区青年发展规划制定工作情况。以中共中央、国务院出台的中长期青年发展规划为指导,结合地方实际启动本地区青年发展规划编制工作,并注意与本地区经济社会发展规划及相关专项规划相衔接,争取纳入发展改革部门专项规划。坚持规划的社会发展规划子规划属性,避免成为单一的共青团部门规划或服务青年的工作规划。省级团委牵头省级青年发展规划编制和实施工作,遵循规划制定出台的一般工作规律和工作程序。参照改革方案评估程序,在正式出台前,征求团中央规划办意见。二是建立落实规划的跨部门联席会议协调机制情况。根据规划要求,县级以上都要建立青年工作联席会议机制,统筹协调中长期青年发展规划在本地区的落实,协调本地区青年发展规划编制和实施。

三是建立省级青年发展监测数据库情况。结合实际建立规划监测指标体系,开展年度数据监测,建立和完善省级青年发展监测数据库,及时将有关数据报送团中央规划办。

2.网上共青团建设。一是“青年之声”工作情况,包括重点工作的部署和督导、探索开展网上思想引领工作、与全团重点工作项目有机融合、提升平台运营的活跃度、开展服务青年相关活动、加强品牌宣传推广等方面的情况。二是网络舆论引导工作情况,包括网络舆论引导工作、队伍建设、阵地的建设和运营、参与重大任务、落实共青团宣传思想工作产品化战略、承接重点项目和工作创新、互联网企业团建等方面的情况。
