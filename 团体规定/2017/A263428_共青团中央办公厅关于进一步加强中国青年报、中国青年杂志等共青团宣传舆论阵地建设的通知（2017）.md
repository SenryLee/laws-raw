# 共青团中央办公厅关于进一步加强中国青年报、中国青年杂志等共青团宣传舆论阵地建设的通知（2017）

## 共青团中央办公厅关于进一步加强中国青年报、中国青年杂志等共青团宣传舆论阵地建设的通知

中青办发〔2017〕14号

共青团各省、自治区、直辖市委,中央军委政治工作部组织局群团处,全国铁道团委,全国民航团委,中直机关团工委,中央国家机关团工委,中央金融团工委,中央企业团工委,新疆生产建设兵团团委:

为深入学习宣传贯彻党的十九大精神,充分发挥中国青年报、中国青年杂志等团属新闻舆论阵地在宣传习近平新时代中国特色社会主义思想,宣传党的基本理论、基本路线、基本方略,促进青少年健康成长,服务共青团改革发展中的积极作用。现就有关事项通知如下。

一、充分认识新形势下加强中国青年报、中国青年杂志等团属新闻舆论阵地建设的重要意义

团的新闻舆论工作是党的新闻舆论工作的重要组成部分。团属新闻舆论阵地是青少年思想政治引领的重要依托,是做好新形势下党的青年群众工作的重要抓手。党的十八大以来,团属媒体深入学习宣传贯彻以习近平同志为核心的党中央对新形势下共青团和青少年工作提出的一系列重要要求,紧紧围绕党政工作大局、全团重点工作和青少年成长需求,传播党的声音,反映青年呼声,全面报道共青团改革成果,唱响了主旋律,传播了正能量。

党的十九大为全党全国人民在新时代新征程上续写新篇章、夺取新胜利指明了前进方向、提供了根本遵循,同时也为广大青年接力奋斗实现中国梦、为共青团组织履行光荣时代使命提出了重要要求、寄予了殷切期望。学习宣传贯彻党的十九大精神,是全团当前和今后一个时期的首要政治任务。中国青年报作为团中央机关报,中国青年杂志作为团中央机关刊,对于宣传党的十九大精神,引导激励广大团员青年深入学习贯彻习近平新时代中国特色社会主义思想、奋勇投身新时代建功立业,有着特殊重要的作用。各级团组织要从党的新闻舆论工作大局和为党做好新时代青年群众工作的高度,共同做好团属新闻舆论阵地的巩固提升工作,不断扩大中国青年报、中国青年杂志在各级团组织和广大团员青年中的覆盖面。

二、进一步办好中国青年报、中国青年杂志等团属报刊中国青年报、中国青年杂志等团属媒体要以学习宣传贯彻习近平新时代中国特色社会主义思想为统领,把牢正确导向,突出青年特色,提升发展水平,充分发挥面向广大青少年、为党的事业凝心聚力的重要作用。

要始终坚持党管媒体原则。坚持正确的政治方向和舆论导向,坚持团结稳定鼓劲、正面宣传为主的方针,坚持稳中求进工作总基调,聚焦青少年思想价值引领的主业,主动担当,积极作为,及时有效地传播党的理论和路线方针政策,引导帮助广大青年增强“四个意识”、坚定“四个自信”,更加紧密地团结凝聚在以习近平同志为核心的党中央周围。

要坚持青年导向。主动适应青年群体分众化、差异化、流动化的趋势,适应共青团改革的需要,把握好青年思想意识特点和阅读需求,积极创新理念、内容、体裁、形式、方法、手段、业态、体制、机制,让宣传报道工作更贴近青年,更具有针对性、实效性和感染力。

要加快融合发展。按照中央关于媒体融合发展的各项决策部署,抢抓机遇,乘势而上,充分借助新媒体传播优势,推动业态升级和融合发展,构建舆论引导新格局。加强人才建设,打造一支政治坚定、业务精湛、作风优良的新闻工作队伍,为团属媒体的持续健康发展提供有力支撑。

三、进一步扩大中国青年报、中国青年杂志等团属报刊的覆盖面和影响力

要加强组织领导。各级团组织要认真贯彻落实“全团办,为全团”的方针,加强组织领导,采取切实措施,做好中国青年报、中国青年杂志的发行工作,确保2018年度发行数量总体稳定。要坚决贯彻执行党和国家有关报刊发行的各项规定,不得将团属报刊订阅情况与工作考核、评比评优等挂钩。

要突出重点领域。各级团组织要在抓好整体征订工作的同时,着力推进机关、学校、企业、部队等系统和青年聚集度高的重点城市的征订发行工作,铁道、民航、金融和中央企业等行业系统要大力推进基层单位及营业网点的征订工作。要巩固全国大中学校班级团支部和“青年文明号”集体、青少年宫、青年之家、青少年维权岗的报刊订阅工作。要按照团的宣传阵地紧跟组织建设的要求,结合近年来全团在城乡区域化团建、“两新”组织团建、驻外团组织建设、行业系统团建、青少年综合服务平台建设等方面取得的新进展,做好跟进发行,更好地服务于新建团组织和聚集在其中的团员青年。

要争取多方支持。各级团组织要按照《关于中国共产主义青年团团费收缴、使用和管理的规定》精神使用好订报订刊经费。要积极整合社会资源,面向缺少经费的基层团组织、经济困难学生、“西部计划”志愿者、大学生村官和少数民族地区青少年等青年群体赠订团属报刊。地市级以上团组织要积极向相关党政领导赠阅。要积极争取党委宣传部门和新闻出版行政主管部门支持,把中国青年报、中国青年杂志等团属报刊纳入当地公共文化项目。经济较发达地区团组织要把赠阅团属报刊作为支持中西部地区团组织的重要举措。

要更好推动工作。团的各级领导机关和广大团干部要把阅读团属报刊作为及时了解全团工作部署、加强全团重点工作研究、相互学习借鉴经验的重要手段。团的基层组织要结合青年关注的社会现象、社会问题和思想上普遍存在的困惑,通过开展读报读刊讨论交流等活动,帮助广大团员青年释疑解惑,形成正确积极的思想认识。

中国共青团杂志是团中央面向各级团组织和广大团干部的工作指导刊物,中国少年报是中国少年先锋队的队报,中华儿女杂志是全国青联的机关刊。各级团组织要和少先队、青联组织一起,做好中国共青团杂志、中国少年报、中华儿女杂志等团属报刊的发行工作,充分发挥其在引导服务团干部、少年儿童、服务青联工作中的积极作用。

共青团中央办公厅
