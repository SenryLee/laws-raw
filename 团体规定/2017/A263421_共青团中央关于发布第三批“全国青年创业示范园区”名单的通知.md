# 共青团中央关于发布第三批“全国青年创业示范园区”名单的通知

中青办发〔2017〕5号

共青团各省、自治区、直辖市委,全国铁道团委,全国民航团委,中直机关团工委,中央国家机关团工委,中央金融团工委,中央企业团工委,新疆生产建设兵团团委:

2016年以来,各级团组织顺应“大众创业、万众创新”的时代潮流,紧贴青年创新创业的实际需求,按照《“全国青年创业示范园区”管理办法(试行)》要求,持续推动青年创业园区建设工作,为促进青年创新创业提供了有利条件、搭建了广阔舞台,取得了良好的工作成效。

为进一步深化全国青年创业示范园区建设,构筑青年创新创业服务实体阵地,经各地申报、资质审核和量化评估,确定创业公社等37家单位为第三批“全国青年创业示范园区”。

希望第三批“全国青年创业示范园区”单位不断总结经验,积极探索创新,充分发挥示范、带动和辐射作用,为服务青年创新创业作出更大的贡献。各级团组织、青年创业园区要主动借鉴示范园区的经验做法,不断创新建设运营模式,提升综合服务能力,集中力量培育和孵化青年创新创业项目,在支持青年创新创业方面发挥更大作用。

附件:第三批“全国青年创业示范园区”名单

共青团中央办公厅

2017年4月7日
