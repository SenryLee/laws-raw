# 中国侨联办公厅关于认真组织学习《习近平谈治国理政》第二卷的通知

中侨厅〔2017〕40号

各省、自治区、直辖市侨联，中央直属机关、中央国家机关、中央企业侨联，新疆生产建设兵团侨联：

经党中央批准，中央宣传部会同中央文献研究室、中国外文局，近日编辑出版了《习近平谈治国理政》第二卷。根据中共中央办公厅转发《中央宣传部、中央组织部关于认真组织学习〈习近平谈治国理政〉第二卷的通知》要求，结合侨联实际，现就学习贯彻工作通知如下。

一、深刻领会重大意义，切实增强学习贯彻的自觉性坚定性党的十八大以来，以习近平同志为核心的党中央团结带领全党全国各族人民，推动党和国家事业取得历史性成就、发生历史性变革，中国特色社会主义进入新时代。党的十九大把习近平新时代中国特色社会主义思想确立为党必须长期坚持的指导思想，实现了党的指导思想又一次与时俱进。习近平总书记是习近平新时代中国特色社会主义思想的主要创立者。党的十八大以来，在领导全党全国推进党和国家事业的实践中，习近平总书记以马克思主义政治家、理论家的深刻洞察力、敏锐判断力和战略定力，提出了一系列具有开创性意义的新理念新思想新战略，为习近平新时代中国特色社会主义思想的创立发挥了决定性作用、作出了决定性贡献。

《习近平谈治国理政》第二卷生动记录了以习近平同志为核心的党中央团结带领全党全国各族人民在新时代坚持和发展中国特色社会主义的伟大实践，集中反映了习近平新时代中国特色社会主义思想的发展脉络和主要内容，是深入学习掌握习近平新时代中国特色社会主义思想和党的十九大精神的权威读本。

各级侨联组织要把学习贯彻习近平新时代中国特色社会主义思想作为当前和今后一个时期的重大政治任务，作为增强政治意识、大局意识、核心意识、看齐意识，维护习近平总书记党中央的核心、全党的核心地位，维护党中央权威和集中统一领导，在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致的实际举措。

二、坚持理论联系实际的学风，切实把习近平新时代中国特色社会主义思想学习成果转化为侨界的生动实践

各级侨联组织和侨联广大党员干部要把《习近平谈治国理政》第二卷和先期出版的《习近平谈治国理政》第一卷，作为深入学习领会习近平新时代中国特色社会主义思想和党的十九大精神的权威读本，在“学懂、弄通、做实”上下功夫。一是要结合实际学。把学习《习近平谈治国理政》第二卷与第一卷贯通起来，与学习贯彻党的十九大精神结合起来，与贯彻落实习近平总书记对群团改革、侨务工作的重要论述结合起来，与侨情变化和侨联工作实际结合起来，把学习成果转化为深化侨联改革的务实措施，转化为推动侨联工作再上新台阶的具体行动。二是要带着目的学。要通过学习，牢牢坚持党的领导，牢固树立“四个意识”，把政治建设摆在首位，坚定党的理想信念宗旨，坚决维护总书记的核心地位，坚定不移听党话、跟党走。要通过学习，加强对归侨侨眷和海外侨胞的思想引领，夯实党的侨界群众基础，最大限度将侨胞团结在党的周围。要通过学习，着力增强全系统侨联干部的学习本领、政治领导本领、改革创新本领、科学发展本领、依法执政本领、群众工作本领、狠抓落实本领、驾驭风险本领，打造一支让党放心、侨胞满意的侨务工作实干家队伍。三是要以实际成效检验。要坚持学以致用，通过扎实的工作成效体现学习贯彻情况，各级侨联组织要把加强党的建设，深化强“三性”、去“四化”目标，推进基层组织建设和基层工作，增进为党和国家工作大局服务水平，密切党与侨界群众的血肉联系，作为检验学习贯彻情况的标准。

三、加强组织领导，营造浓厚氛围

各级侨联组织要以高度的使命感和责任感，系统学习、深入学习，切实把思想和行动统一到习近平新时代中国特色社会主义思想上来，统一到党的十九大确定的重大决策部署上来。各级侨联党组理论学习中心组要带头学好用好这部重要著作，推动侨联组织全系统深入领会习近平新时代中国特色社会主义思想的时代背景、科学体系、精神实质、实践要求，深入领会这一思想的重大政治意义、理论意义、实践意义，不断提高侨联干部马克思主义水平。各级侨联组织部门要把学习《习近平谈治国理政》第二卷与干部教育培训、加强领导班子建设和基层党组织建设结合起来，纳入“两学一做”学习教育常态化制度化和即将开展的“不忘初心、牢记使命”主题教育的重要内容，确保学习教育党组织全覆盖。各级侨联文化宣传部门要把握宣传规律，创新方法载体，全方位、多角度宣传报道，突出反映学习《习近平谈治国理政》第二卷、解决实际问题的具体实践和工作成效，及时反映学习实践中的先进典型，激发广大侨界干部群众的学习热情，营造学习贯彻浓厚氛围。侨联所属社团要充分发挥自身优势，开展各具特色的学习教育活动。

各地侨联学习宣传贯彻情况要及时报告中国侨联。

中国侨联办公厅

2017年12月8日
