# 中国残疾人联合会关于开展公共场所卫生间无障碍设施调查的函

## 关于开展公共场所卫生间无障碍设施调查的函

北京、河北、上海、安徽、江西、广东、重庆、云南、云南、陕西省(市)残联和肢协：

为了维护我国残疾人合法权益，保障残疾人平等参与社会生活，共享社会物质文化成果，国务院颁布了《无障碍环境建设条例》。在贯彻落实《无障碍环境建设条例》与《无障碍设计规范》的过程中，公共场所无障碍环境取得了积极成绩，但仍存在不少问题。为了解我们公共场所卫生间无障碍环境建设情况，经中国残联领导同志同意，由中国肢残人协会组织，在全国部分省市开展公共场所卫生间无障碍设施情况调查活动。具体函告如下：

一、调研时间

2017年4月。

二、调研地点

北京、河北、上海、安徽、江西、广东、重庆、云南、陕西省(市)所辖地区内公共场所的厕所卫生间。

三、调研内容

（一）所在地区公共场所的厕所间无障碍设施；

（二）所在地区公共场所厕所间内外的无障碍环境（包括厕所间全程使用过程和往返厕所间道路）；

（三）调研以省为单位，每省20个卫生间；

（四）对公共场所厕所间内外的无障碍环境进行拍照，形成调研报告并填写调查表。

四、其他要求

（一）请有关省市残联和肢协充分重视此项调研工作，组织肢残人亲身体验，认真收集各方意见，汇集总结形成调研报告；

（二）请于4月28日前将调研报告、调查表及相关照片电子版发至中国肢协办公邮箱。
