# 中国残联办公厅关于做好“十三五”期间特奥工作的通知

各省、自治区、直辖市残联，新疆生产建设兵团残联：

“十二五”期间，我国特奥工作取得了显著成绩，基层特奥工作日趋活跃，特奥比赛活动普遍开展，积极推动发展融合运动，我国参加特奥运动的智力残疾人已达到120万。为做好“十三五”期间特奥工作，实现特奥运动员和特奥融合运动员增长10%的目标，经中国残联领导同志同意，现就有关事项通知如下。

一、充分认识特奥工作的重要性

关心、帮助包括智力残疾人在内的广大残疾人，是我国社会主义制度优越性的必然要求和具体体现，也是各级党委、政府和全社会的共同责任。在加快推进残疾人全面小康的进程中，要特别关注智力残疾人这个特殊困难群体。开展特奥运动是帮助智力残疾人走出家庭，融入社区、迈向社会的重要途径。通过体育这个平台，智力残疾人接触了社会、突破了身心障碍，强壮了身体，提高了参与社会生活的能力。

各级残联要把特奥作为残联的一项重要工作，按照《“十三五”加快残疾人小康进程规划纲要》及配套实施方案明确特奥工作任务要求，协调民政、教育、体育等部门，把特奥工作纳入规划，统筹资源，把特奥工作摆到重要位置，作为活跃基层残疾人生活、改善智力残疾人生活状况、宣传和推动残疾人事业发展的重要工作来抓，为智力残疾人参加特奥活动提供便利和服务，积极协调、组织、动员社会各界，完成“十三五”的任务目标。

二、大力发展特奥融合运动,全面提升特奥活动质量

（一）大力开展特奥融合运动。各级残联要发挥积极性和主动性，重视智协、普通学校、特教学校、俱乐部、社区、街道的辐射带动作用，定期组织多样化人群参与特奥融合运动，形成传统，设立特奥融合运动学校，在融合篮球、足球、滚球等项目基础上，拓展更多融合运动项目，让更多智力残疾人、更多健全人伙伴参与到形式多样、喜闻乐见的特奥融合运动项目中来，精神互勉，残健共融，携手共进。到2020年，各省（区、市）特奥运动员、融合伙伴要实现10%的增长。

（二）积极推进基层特奥活动。各级残联要继续坚持因地制宜，指导基层开展特奥活动，充分发挥智协作用，做到特奥活动形式多样化、开展经常化、管理规范化，动员、组织、吸引更多的健全人同智力残疾人参加特奥训练、竞赛和非体育项目活动，满足智力残疾人就近、就地、就便参加特奥活动的需求。要安排专门人员协调负责社区特奥工作，建立制度和规范，会同基层体育部门、居委会组织开展特奥培训工作，要充分利用和发挥特教学校、残疾人活动站的集中优势和带动作用，争取每个社区做到“月月有比赛，周周有活动”，争取每年至少组织一次智力残疾人综合体育活动。要组织好每年7月20日全国特奥日活动，同时借助8月8日全民健身日等节庆活动开展特奥活动，形成声势。

（三）抓好特奥竞赛工作。充分发挥体育竞赛活动对特奥发展的杠杆作用。以政府引导为主，发挥市场机制作用，鼓励支持地方残联、智协、特奥组织、残疾人体育机构、特教学校以及其他社会组织及机构举办国际特奥邀请赛、全国比赛、区域邀请赛、交流赛、城市赛，社区赛、校际赛、融合赛等形式多样、多层级的竞赛活动，以特奥竞赛带动特奥训练、日常特奥活动的开展，让更多智力残疾人拥有更广阔的天地。每年举办的特奥活动，省级不少于3次、市级不少2次、县级不少于1次。

（四）加强特奥教练员和工作人员培养。各级残联、特奥组织要把特奥教练员、工作人员的培训纳入残疾人体育工作培训计划，将特奥知识纳入“残疾人健身指导员”培训内容，借助体育系统教练、教育系统的教师资源培养更多的特奥教练员，注重在体育院校学生中推广普及特奥知识，储备教练员资源。

（五）开展好特奥非体育活动。要动员、组织医务人员、学生、志愿者、智力残疾人家长及亲友等各种社会资源参与和支持特奥活动，并提供服务，开展好“家庭支持联络网”“运动员领袖计划”“运动员健康计划”“幼儿运动员计划”“健康社区”等非体育活动。

（六）认真做好特奥统计台账填报工作。各级残联要把特奥统计台账填报工作作为本地特奥工作总结和展示的重要内容，每年精心组织，有效实施，做到统计内容清晰、准确，并按要求做好填报工作。

三、借助筹办2022年冬奥会和冬残奥会契机，发展冬季特奥运动

各级残联、特奥组织、智协要借助我国筹办2022年冬奥会和冬残奥会契机，将智力残疾人参与冰雪运动纳入“三亿人参与冰雪运动”大局，创造条件满足智力残疾人参与冰雪运动的需求，提高智力残疾人参与率。

（一）拓展冬季特奥运动项目。要巩固推广世界冬季特奥会项目雪鞋走、越野滑雪、地板曲棍球、速度滑冰、花样滑冰等项目，拓展高山滑雪等项目。同时开发开展适合智力残疾人特点的冰壶、冰蹴球、趣味滑雪等项目。

（二）开展形式多样的特奥冰雪活动。要充分利用智力残疾人特教学校、残疾人体育中心、托养机构等机构资源，采取体育与教育相结合、运动与文化相结合、普及与提高相结合的方式，广泛开展智力残疾人冰雪运动培训，发展冰雪项目，举办冰雪赛事和推广活动，让更多的智力残疾人参与冰雪运动，享受冰雪运动快乐。

（三）创造条件方便智力残疾人参与冰雪运动。要在群众性冰雪活动组织、冰雪项目体育设施建设和器材配备、研发、推进公共冰雪体育设施、自强健身示范点等方面考虑智力残疾人特殊需求，提供服务，为智力残疾人就近就便参与冰雪运动创造条件、提供保障。

四、加强宣传力度,营造良好社会氛围

各级残联、特奥组织、智协要制定宣传计划，充分发挥互联网优势，开展形式新颖、影响广泛的宣传活动，借助宣传橱窗、电视及平面媒体、门户网站、新媒体等宣传渠道，普及特奥运动知识，宣传特奥发展成果，提升特奥运动的社会关注度和影响力，营造社会各界关注智力残疾人，关心、支持特奥运动的良好氛围。

中国残联办公厅
