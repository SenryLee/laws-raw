# 共青团中央关于组织广大团员青年深入学习宣传贯彻习近平总书记在中国政法大学考察时重要讲话精神的通知

## 关于组织广大团员青年深入学习宣传贯彻习近平总书记在中国政法大学考察时重要讲话精神的通知

中青发〔2017〕10号

共青团各省、自治区、直辖市委,中央军委政治工作部组织局群团处,全国铁道团委,全国民航团委,中直机关团工委,中央国家机关团工委,中央金融团工委,中央企业团工委,新疆生产建设兵团团委:

5月3日,习近平总书记在中国政法大学考察时发表了重要讲话,讲话从全面推进依法治国、法制人才培养工作、青年成长成才、共青团始终保持先进性等多个方面提出了重要要求,为全团进一步做好新形势下党的青年群众工作、团结带领广大团员青年不忘初心跟党走提供了科学指引和根本遵循。为深入学习宣传贯彻习近平总书记重要讲话精神,团结带领广大团员青年以奋发向上的精神状态迎接党的十九大胜利召开,共青团中央决定,在全团部署开展学习习近平总书记在中国政法大学考察时重要讲话精神专题活动,有关要求通知如下。

一、深刻把握习近平总书记重要讲话精神的重大意义,汇聚广大团员青年的思想共识

习近平总书记的重要讲话立意高远、思想深邃、主题鲜明、内涵丰富,各级团组织和广大团员青年要认真学习领会,把准精神要义,提升思想认识。

1.讲话进一步丰富发展了马克思主义青年观和习近平总书记青年工作思想。党的十八大以来,以习近平同志为核心的党中央把青年摆在党和人民事业的重要位置,强调青年一代有理想有担当,国家就有前途、民族就有希望,实现中华民族伟大复兴就有源源不断的强大力量。在中国政法大学考察时,习近平总书记深刻指出,中国的未来属于青年,中华民族的未来也属于青年。

强调青年一代的理想信念、精神状态、综合素质,是一个国家发展活力的重要体现,也是一个国家核心竞争力的重要因素。这一系列的鲜明观点和重要论断,深刻概述了青年的历史成绩和未来责任、个体作用和群体定位,体现了辩证唯物主义和历史唯物主义的思想光辉,体现了历史逻辑、理论逻辑和时间逻辑的辩证统一,进一步发展了马克思主义青年观的立场、观点和方法,也进一步丰富了习近平总书记青年工作思想。

2.讲话进一步明确了当代青年的时代责任和成长路径。

习近平总书记指出,当今中国最鲜明的时代主题,就是实现“两个一百年”奋斗目标、实现中华民族伟大复兴的中国梦。强调当代青年要树立与这个时代主题同心同向的理想信念,勇于担当这个时代赋予的历史责任,励志勤学、刻苦磨练,在激情奋斗中绽放青春光芒、健康成长进步。强调坚定跟党走这个初心,是我国广大青年的政治选择,也是我国广大青年的人生航向。勉励广大青年学生要珍惜韶华,潜心读书,敏于求知,做到德智体美全面发展,毕业后为祖国和人民施展自己的才华,实现自己的人生价值。这一系列的重要论述和要求,是习近平总书记青年工作思想的重要组成部分,充分体现了习近平总书记对当代青年的关怀厚爱和殷切期望,也深刻阐明了当代青年的发展规律和成长路径。

3.讲话进一步指明了青少年和共青团工作的目标方向和根本遵循。习近平总书记强调,共青团是党的助手和后备军,要始终保持先进性,广大团员青年坚定跟党走,就是初心。强调要多用正能量鼓舞激励学生,注重培养学生的思想道德素养,等等。特别是习近平总书记专程参加了基层团支部组织的“不忘初心跟党走”主题团日活动,并深情寄语团员青年,充分体现了以习近平同志为核心的党中央对青少年和共青团工作的高度重视和亲切关怀。习近平总书记的重要讲话,深刻揭示了党的青年群众工作的基本规律,凸显了共青团的根本任务和政治责任,强调了共青团改革发展的重点领域和关键环节,为新形势下改进创新青少年和共青团工作指明了前进方向,提供了根本遵循。

二、广泛组织形式多样、生动活泼的学习教育活动,积极运用全媒体开展宣传工作,迅速掀起学习习近平总书记重要讲话精神的热潮

全团要把学习贯彻习近平总书记重要讲话精神作为当前一项重要政治任务,与正在开展的“学习总书记讲话做合格共青团员”教育实践、“青春喜迎十九大·不忘初心跟党走”宣传教育和从严治团紧密结合,以高度的责任感和使命感,切实把习近平总书记重要讲话精神学习好宣传好贯彻好,把总书记的关怀厚爱与殷切期望传递到广大团员青年的心上。

1.带头开展学习活动。团的各级领导机关干部要带头学习,把习近平总书记重要讲话精神纳入全团理论学习中心组学习重要内容,纳入团干部教育培训内容。要采取集体学习研讨、个人自学、专题调研、专题讲座等方式,组织各级专、挂、兼职团干部认真学习领会讲话原文,深入交流学习体会,切实增强学习效果。要与学习贯彻习近平总书记重要讲话精神和治国理政新理念新思想新战略结合起来,不断提高思想认识,把讲话要求转化为内心自觉。

2.开展主题宣讲交流。把学习宣传贯彻习近平总书记重要讲话精神作为“千场宣讲交流”“分享团走基层”“与信仰对话”“与人生对话”“彩虹人生”“四进四信”“青年马克思主义者培养工程”“三下乡”等活动和工作的重要内容,组织党政领导、专家学者、优秀青年和团干部,发动青联、学联、少工委等各类青少年组织和社团,深入学校、企业、农村、机关、社区等领域,广泛开展宣讲报告、座谈交流等学习教育活动。结合落实“走转改”大宣传大调研、常态化下沉基层、向基层服务对象报到、团干部联系青年等工作,积极开展灵活多样的宣讲活动,确保讲话精神传达到各领域团员青年和基层团干部。

3.组织主题团日活动。充分利用全年各个重要时间节点,广泛开展以学习习近平总书记重要讲话精神为主题的学习座谈、交流讨论、征文演讲、故事分享等团日活动,引导团员青年进一步坚定理想信念,进一步坚定中国特色社会主义道路自信、理论自信、制度自信、文化自信,不断增强对党的信心、信任和信赖,不断增强对以习近平同志为核心的党中央的拥护爱戴,不断增强“听党话、跟党走”的思想和行动自觉。各级团组织要继续开展“不忘初心跟党走”主题团日活动,团中央书记处全体同志将带头为所联系团支部讲团课,团的各级领导机关干部要为在直接联系青年工作中所联系的团支部讲团课。

4.发挥榜样示范作用。积极选树青年五四奖章获得者、向上向善好青年、优秀共青团员、青年岗位能手、农村青年致富带头人、优秀青年志愿者等青年典型,组织他们紧紧围绕对习近平总书记重要讲话精神的学习思考,结合自身的学习成长经历,深入基层广泛开展分享活动,与更多的青年互动,让更多的青年受益。大力宣传各行各业青年典型的青春故事和精神品格,影响带动更多青年牢记总书记嘱托,励志勤学、刻苦磨炼,不忘初心跟党走。

5.加强全媒体宣传。各级各类团属宣传思想舆论阵地要通过开设专题专栏、组织重点文章等方式,加强对习近平总书记重要讲话精神的阐释解读,宣传讲话在广大团员青年中引起的强烈反响,报道各地团组织和团员青年学习宣传贯彻讲话精神的好做法好经验,营造浓厚的学习氛围。要充分发挥全团双微矩阵、“青年之声”、团属网站、APP等各类新媒体平台作用,积极开展“我是团员”“迎接十九大”“砥砺奋进的五年”等主题网络活动,吸引青年网友广泛参与,不断扩大学习宣传总书记重要讲话精神的覆盖面和影响力。积极运用青年喜闻乐见、便于接受的形式开展学习教育,积极创作推广《团团带你学》《跟总书记学》《青年网络公开课》《团课》等宣传教育产品,采取微电影、视频、动画、H5、游戏等贴近青年的形式,把习近平总书记重要讲话精神更便捷、更有效、更广泛地传播到团员青年中去,真正让讲话精神入脑入心。

三、以习近平总书记重要讲话精神为指导,把共青团的先进性贯彻到引领广大青年“不忘初心跟党走”的实际行动中引导广大团员青年把习近平总书记的重要要求转化为实际行动,不断坚定“不忘初心跟党走”的理想信念,不断坚定为实现中华民族伟大复兴中国梦而奋斗的信心决心,在决胜全面小康的具体实践中贡献青春力量、展现青春风采。

1.引领广大青年在网上弘扬主旋律、传播正能量。严格落实党的意识形态工作要求,把共青团的先进性延伸到网络空间,做到勇于举旗亮剑、澄清缪误,主动适应网上舆论引导工作新形势新要求,提升网络舆论引导的指挥效能和整体水平,努力在全党网络舆论引导总体格局中发挥更大作用。要深化青年网络文明志愿行动、“阳光跟帖”行动,大力推进“中国青年好网民”主题活动,特别是针对网络上攻击党的领导、诋毁共产主义、虚无革命历史、抹黑英雄模范等歪风邪气,团结广大团员青年旗帜鲜明地开展斗争,响亮地发出“青年好声音”。

2.促进广大青年学生全面发展、助力立德树人。深入贯彻落实全国高校思想政治工作会议精神,在高校扎实开展“一学一做”教育实践和相关主题教育活动,组织广大青年学生深入学习习近平总书记重要讲话精神,切实做到入脑入心。引导青年学生通过暑期社会实践平台广泛开展宣讲活动,面向社会各界群众深入开展普法工作,努力在实践中培养当代大学生的法治精神。将学习宣传讲话精神作为各级团学骨干培训的重要内容,在“青年马克思主义者培养工程”和高校团学干部培训中组织示范学习,对优秀学习成果进行展示传播。鼓励团学干部在面向青年师生的直接联系服务工作中,结合实际组织开展形式多样的学习活动,努力做到工作到支部、引导面对面。结合青年学生成长成才的实际需求,运用网络新媒体等载体开发关于学习讲话精神的系列优质内容产品、进行广泛传播。

3.组织广大青年助力脱贫攻坚、创新创业创优。抢抓国家制定实施《中长期青年发展规划(2016—2025年)》的重大机遇,坚持党管青年原则,科学组织实施,健全各级规划体系,形成促进青年发展的新动力。依托“青年建功十三五·青春献礼十九大”主题实践,组织开展青年岗位建功系列活动。聚焦集中连片特困地区和国家扶贫开发工作重点县,做实“脱贫攻坚青春建功行动”;以“青创先锋”系列活动为统揽,通过组织创新创效实践活动,不断提高职业青年的自主创新能力;实施中国青年“岗位创优”行动,持续打造“创青春”系列工作品牌。组织各领域共青团员充分发挥自身先进性,在立足岗位创新创业创优的过程中实现个人的健康成长,带动广大青年为改革发展稳定大局作出积极贡献。

4.引导广大团员保持增强先进性、发挥模范作用。围绕保持和增强政治性、先进性、群众性的目标要求,大力加强团员队伍建设,进一步严格团员发展,抓好严格标准、严格程序、严格培养、严格纪律等重点环节。进一步加强团员教育管理,形成以“三会两制一课”为主要内容的团员教育管理长效机制,切实增强团员的先进性和光荣感。进一步激发和弘扬团员的先锋模范作用,常态化开展团员先锋岗(队)创建活动,推动各级团组织逐步建立表彰工作体系,不断加大对基层先进典型的宣传力度。扎实推动团员成为注册志愿者,引导广大团员广泛开展各类志愿服务。

5.维护和增进青少年合法权益、服务成长成才。加强法治宣传教育,让青少年在点滴行为习惯养成中培养对制度、规则的尊重,从小明确基本的法律底线和行为边界。配合司法行政机关加强未成年人专门工作机构建设,扩大公益性法律人才队伍,培育熟悉青少年身心特点的青年法治实务工作者。加强对青少年维权类社会组织和青少年事务社工的联系、培育和引导,在实践中提高他们的专业服务能力。健全未成年人社会观护体系,共同做好预防青少年违法犯罪、青少年权益维护和法律援助工作。深化青少年毒品预防教育,不断增强青少年识毒、防毒、拒毒的意识和能力。加强青少年法治工作智库建设,在相关立法、修法过程中及时提出有利于青少年成长发展的意见建议。

各级团组织要按照通知要求,结合各自实际制定工作方案,认真抓好贯彻落实。

共青团中央
