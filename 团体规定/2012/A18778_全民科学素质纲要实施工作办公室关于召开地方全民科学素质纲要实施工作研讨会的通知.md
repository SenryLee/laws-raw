# 全民科学素质纲要实施工作办公室关于召开地方全民科学素质纲要实施工作研讨会的通知

## 全民科学素质纲要实施工作办公室关于召开地方全民科学素质纲要实施工作研讨会的通知（纲要办函〔2012〕3号）

各省、自治区、直辖市、副省级城市纲要办（科协），新疆生产建设兵团纲要办：

为认真贯彻落实国务院领导同志听取《全民科学素质行动计划纲要》（以下简称《科学素质纲要》）实施情况汇报会精神，总结回顾2011年全民科学素质工作，部署2012年工作任务，定于2012年4月下旬召开地方全民科学素质纲要实施工作研讨会。现将有关事项通知如下：

**一、**时间和地点

1．时间：2012年4月24日-27日（24日报到）。

2．地点：贵州省贵阳市花溪区迎宾路贵州花溪迎宾馆。

**二、**参加人员

1．省、自治区、直辖市和新疆生产建设兵团科学素质纲要实施工作办公室成员单位负责同志各4人（科协系统出席人数不得超过2人）。

2．副省级城市科学素质纲要实施工作办公室成员单位负责同志各1人。

3．全民科学素质纲要实施工作办公室各成员单位成员或联络员。

**三、**会议内容

1．传达学习国务院听取《科学素质纲要》实施情况汇报会精神。

2．总结2011年全民科学素质工作，部署2012年工作任务。

3．全民科学素质工作专题讲座。

4. 交流各地《科学素质纲要》实施工作经验和做法。

**四、**有关事项

1．请各单位填写参会回执（见附件1），于4月13日前分别传真到贵州省科协科普部和全民科学素质纲要实施工作办公室。

2．参会人员食宿费由全民科学素质纲要实施工作办公室负责，往返差旅费自理。会议安排接送站。
