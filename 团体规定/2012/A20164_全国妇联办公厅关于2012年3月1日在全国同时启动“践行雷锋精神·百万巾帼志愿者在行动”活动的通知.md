# 全国妇联办公厅关于2012年3月1日在全国同时启动“践行雷锋精神·百万巾帼志愿者在行动”活动的通知

各省、自治区、直辖市妇联，新疆生产建设兵团妇联：

为认真贯彻《中共中央办公厅关于深入开展学雷锋活动的意见》，根据全国妇联《关于在广大妇女中深入开展学雷锋活动的通知》要求，定于2012年3月1日在全国各省区市同时启动“践行雷锋精神·百万巾帼志愿者在行动”活动。现将有关事宜通知如下：

**一、**请各省区市妇联3月1日在基层社区同时举办“践行雷锋精神·百万巾帼志愿者在行动”活动启动仪式，并迅速在各地推开，掀起广大妇女学雷锋活动的热潮。

**二、**“践行雷锋精神·百万巾帼志愿者在行动”活动以城乡社区“妇女之家”为依托，重点帮扶困难家庭、单亲家庭、空巢家庭、残疾人家庭，重点关爱留守流动妇女儿童、贫困单亲母亲、空巢孤寡老人，重点开展践行文明礼仪、法律宣传咨询、情感关怀抚慰、家庭关系调适、邻里冲突调解、科学教育子女、社区环境美化、群众文化健身等志愿服务活动，确保活动真正开展在基层、开展在社区、开展在群众身

边，取得扎扎实实的成效。

**三、**请各地妇联高度重视、迅速行动、精心安排，认真做好相关组织落实工作。切实加大新闻宣传力度，形成宣传声势，着力扩大活动的社会影响力和对妇女群众的吸引力。

请各地妇联在3月6日前将举行启动仪式以及新闻宣传等相关工作情况报全国妇联。
