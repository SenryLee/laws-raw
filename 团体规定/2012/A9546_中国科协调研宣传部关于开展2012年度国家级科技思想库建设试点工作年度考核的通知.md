# 中国科协调研宣传部关于开展2012年度国家级科技思想库建设试点工作年度考核的通知

各有关单位：

根据《中国科协国家级科技思想库建设试点管理办法（试行）》的有关规定，中国科协调研宣传部拟于近期对各试点单位建设工作进行年度考核，现将有关事宜通知如下：

**一、**时间和地点

1.时间：10月29日报到，30-31日开会，11月1日离会。

2.地点：北京市顺义区马坡顺安北路金宝花园酒店。

**二、**考核对象

中国科协国家级科技思想库建设两批试点单位，共26个地方科协。

**三、**考核方式

1.考核采取各试点单位汇报和专家评议相结合的方式。

2.各试点单位就工作进展情况提交书面报告，一式10份，于会议当日提交评审专家组审阅。

3.各试点单位就试点工作进展情况，向评审组进行当面汇报（要求制作PPT），时间为15分钟；各试点单位接受评审专家组质询，时间为10分钟。

4.评审专家根据试点单位汇报情况进行综合评议，并确定各试点单位的考核等级。

**四、**注意事项及联系方式

1.请各试点单位按照《国家级科技思想库建设试点管理办法（试行）》及《关于加强国家级科技思想库建设试点工作的指导意见》有关要求，于参会前准备好详细的书面汇报材料，一式十份，同时按照15分钟时间要求，准备好汇报的PPT。

2.各试点单位参会汇报人员，包括分管领导和思想库建设试点工作的具体负责同志。参会人员名单须于10月27日前报中国科协调宣部。

3.无正当理由不参加汇报的，将取消试点单位资格。
