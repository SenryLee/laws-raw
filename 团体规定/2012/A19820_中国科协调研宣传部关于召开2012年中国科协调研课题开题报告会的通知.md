# 中国科协调研宣传部关于召开2012年中国科协调研课题开题报告会的通知

## 中国科协调研宣传部关于召开2012年中国科协调研课题开题报告会的通知（科协调函综字【2012】5号）

各课题承担单位：

2012年中国科协调研课题立项评审结果公告已于1月初发布，请各课题承担单位参加于3月16-18日在北京中国科技会堂召开的开题报告会，具体要求如下：

1．各课题组就研究重点、研究思路、研究方法、研究团队和经费预算等，作10-15分钟汇报，专家提出意见和建议。

2．各课题组汇报时须准备PPT和7份纸质汇报材料。

3．各课题组参加开题时，须同时提交已填好的《课题任务书》5份。《课题任务书》电子版可从中国科协调研宣传部网页下载。

4．课题负责人不到会或无故不参加开题的，作自动放弃处理。
