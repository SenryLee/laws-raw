# 中国科协科普部关于表扬“2012年度科普工作优秀学会”的决定

## 中国科协科普部关于表扬“2012年度科普工作优秀学会”的决定（科协普函综字〔2012〕78号）

各全国学会、协会、研究会秘书处（办公室）：

2012年度，全国学会积极动员团体会员和个人会员组织开展科普活动，开发集成科普资源，加强科普传播，科普工作取得了新的成绩。

为加强对全国学会科普工作的指导和支持，进一步调动全国学会的科普工作积极性，根据《中华人民共和国科学技术普及法》（以下简称《科普法》）和国务院颁布的《全民科学素质行动计划纲要（2006-2010-2020年）》（以下简称《科学素质纲要》）关于积极开展表彰奖励工作的精神，经综合考核，中国科协科普部、学会部决定，对在2012年度弘扬科学精神、传播科学思想、倡导科学方法、普及科学知识工作中做出显著成绩和贡献的中国力学学会等41个单位给予表扬。

希望各全国学会以受到表扬的学会为榜样，按照《科学素质纲要》的要求，切实担负起为提高全民科学素质服务的社会责任，不断加强自身建设，增强科普工作能力和水平，进一步发挥在推动科普事业发展中的独特作用。支持、组织、指导会员开展科普活动，为广大会员提供实现自身价值的机会。大力加强科普专家队伍和志愿者队伍建设，开发集成科普资源，为提高全民科学素质做出新贡献。

附件：“2012年度科普工作优秀学会”名单

中国科协科普部
