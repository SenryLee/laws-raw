# 共青团中央办公厅关于召开2012年全国省级团委办公室主任会议的通知

## 共青团中央办公厅关于召开2012年全国省级团委办公室主任会议的通知（中青办发[2012]46号）

共青团各省、自治区、直辖市委办公室，解放军总政治部组织部，全国铁道团委办公室，全国民航团委办公室，中直机关团工委办公室，中央国家机关团工委办公室，中央金融团工委办公室，中央企业团工委办公室：

为进一步推动落实团中央书记处关于集中全团力量支持基层的一系列重要部署，积极配合开展乡镇实体化“大团委”建设，落实好《共青团中央财政部关于进一步支持和推动共青团基层组织建设和基层工作的意见》（中青联发〔2012〕20号），定于2012年10月13日（星期六）至14日上午（星期日）在四川成都召开全国省级团委办公室主任会议。有关事宜通知如下。

**一、**会议内容

研究梳理各地支持基层的具体举措和经验做法，特别是落实中青联发〔2012〕20号文件的具体情况，交流争取财政支持的经验，分析存在的问题，探讨解决的方式方法；研究办公室系统抓全团重点工作督导的有效方式。

**二、**参加人员

各省级团委办公室主要负责同志。

**三、**会议地点团中央办公厅

四川省成都市新华宾馆（地址：成都市青羊区江汉路29号，宾馆总台：028-86687128，总机：028-89497777）

**四、**有关要求

1.要求各省级团委办公室正职参会，因特殊事由不能参会，请提前沟通。

2.请各省级团委办公室主要负责同志会前围绕会议内容准备交流材料，于10月11日17：00前报团中央办公厅。关于落实中青联发〔2012〕20号文件的基本情况：已经与有关部门联合出台制度性措施的省（自治区、直辖市），同时报送制定下发的相关文件；正在沟通协调的省（自治区、直辖市），着重报告拟议中的经费支持具体标准、各级财政分担比例等情况；还未取得具体进展的省（自治区、直辖市），着重报告近期推动落实的工作安排；另，如掌握本省（自治区、直辖市）内有关地市在此项工作中出台的制度性措施，也请一并报告有关情况和相关文件。同时，请各省级团委办公室主要负责同志根据上述材料做好发言准备。

3. 10月12日（星期五）全天报到，工作人员在火车站、机场接站。
