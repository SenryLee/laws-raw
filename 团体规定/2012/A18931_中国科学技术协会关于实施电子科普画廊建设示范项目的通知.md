# 中国科学技术协会关于实施电子科普画廊建设示范项目的通知

## 中国科学技术协会关于实施电子科普画廊建设示范项目的通知（科协普函础字〔2012〕11号）

各相关省、自治区、直辖市科协科普部：

为贯彻《全民科学素质行动计划纲要实施方案（2011-2015年）》，落实《科普基础设施发展规划（2008-2010-2015年）》，加强基层科普设施建设，推动全国科普“站栏员”创新发展，中国科协科普部2012年在部分省实施电子科普画廊建设示范项目，现将有关事项通知如下：

**一、**项目目标

集成社会优质科普资源，建设电子科普画廊、开发科普视频资源，发展科普画廊网络，为公众提高科学素质提供最便捷、有效的服务，探索科普基础设施共建共享的运行、管理机制；总结推广先进经验，推动全国电子科普画廊建设发展。

**二、**项目内容

2012年在已经开展电子科普画廊建设的吉林省、内蒙古自治区、北京市、江苏省、山西省实施电子科普画廊建设示范项目，每个省给予30万元的项目资金资助，项目主要内容包括：

（一）探索电子科普画廊建设、运行方式，建立与社会有关单位共建共享及运行维护、安全防护的机制；

（二）探索开发、集成电子科普画廊视频资源，建设播放网络等工作机制；

（三）建立健全总结电子科普画廊建设标准、运行管理办法等标准、规定。

**三、**有关要求

（一）请相关省科协按实际情况推荐本地1至2个示范项目承担单位，示范项目承担单位原则上为有一定工作基础的地（市、区）或县（市）科协和相关单位；组织填写申报材料（见附件），加具意见后于2012年3月31日前将申报材料纸质版一式四份（盖省科普部签章）和电子版报中国科协农技中心；

（二）各相关省科协请按照项目内容和要求指导示范项目单位开展相关工作，认真总结经验，于2012年10月30日前将示范项目总结材料报中国科协农技中心。上报材料包括：1.电子科普画廊建设典型经验（包括电子科普画廊建设标准、运行管理办法、视频资源建设机制，与社会有关单位共建共享机制以及相关经验）；2.科普视频资源；3.电子科普画廊建设图片；4.本省科普“站栏员”建设工作总结。

（三）中国科协将适时对示范项目进行经验总结和交流推广。
