# 共青团中央办公厅关于召开全国乡镇实体化“大团委”建设工作电视电话会议的通知

## 共青团中央办公厅关于召开全国乡镇实体化“大团委”建设工作电视电话会议的通知（中青办发[2012]45号）

共青团各省、自治区、直辖市委：

团中央定于2012年10月9日上午召开全国乡镇实体化“大团委”建设工作电视电话会议。有关事宜通知如下。

**一、**时间、地点

2012年10月9日（星期二）上午9：00-11：00。全国主会场设在团中央机关四楼大会议室，各省、市、县设分会场。

**二、**主要任务

安排部署乡镇实体化“大团委”建设工作。

**三、**会议安排

陆昊同志讲话。

**四、**参会人员

1. 全国主会场。团中央书记处有关同志，农村部、组织部全体同志，其他部门的相关负责同志。

2. 省级分会场。团省（自治区、直辖市）委、新疆建设兵团团委班子成员，农村部、组织部全体同志，其他部门负责同志。（可与省会城市共同设立分会场）

3. 地市级分会场。团地市委班子成员，各部门负责同志。（可根据实际情况，组织周边区县听会）

4. 县级分会场。团县（市、区）委全体同志（含驻点干部、高校挂职干部），乡镇团委书记、副书记、委员，5名农村专业合作组织负责人。

**五、**有关要求

1. 省、市、县三级团委要及时与所在地电信或联通部门分别接洽，争取支持，落实分会场具体事宜，确保相关人员足额参会。

2. 请各团省（自治区、直辖市）委汇总本地区设立分会场及参会人数情况，于10月8日12：00前报团中央农村部（联系人：冉勇，电话：010－85212810，传真：010－85212024）。

3. 原则上不得请假。省级团委负责同志如有特殊事由不能参会，要以单位名义书面向团中央办公厅请假（联系人：黄健，电话：010－85212301，传真：010－67013305）。

4. 各团省（自治区、直辖市）委要认真组织所辖区域相应层级的人员参会，并及时贯彻落实会议有关部署。请于10月10日17：00前将本地区各分会场实际参会人数报团中央农村部。

附件：全国各省（自治区、直辖市）电视电话会议室联系表（略）

共青团中央办公厅
