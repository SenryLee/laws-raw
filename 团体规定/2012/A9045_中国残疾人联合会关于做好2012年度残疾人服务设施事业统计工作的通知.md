# 中国残疾人联合会关于做好2012年度残疾人服务设施事业统计工作的通知

## 中国残疾人联合会关于做好2012年度残疾人服务设施事业统计工作的通知（残联厅〔2012〕125号）

各省、自治区、直辖市残联，新疆生产建设兵团残联，黑龙江农垦总局残联：

为了保证“十二五”期间残疾人事业统计数据的连续性，进一步做好2012年度中国残疾人事业统计工作。经中国残联领导同意，决定增加2012年残疾人服务设施统计台账、相应调整年报填报方式。现将有关事项通知如下：

**一、**2012年服务设施台账

（一）填报口径。

2012年残疾人服务设施台账共包括6张表，延续2011年的填报口径（具体内容请参看附件1）。

1.综合服务设施是指以综合服务设施立项的，具有就业服务、职业培训、康复指导、文体活动、辅具供应、法律服务功能的设施，至少具备四项以上功能的设施才能填报。

2.康复设施是指以康复设施立项的，以康复医学为基础，运用医疗、工程、教育、职业、心理、社会等康复手段，对残疾人进行康复治疗和训练服务，提高或恢复其功能，使他们能够重返社会的场所。

3.托养设施是指以托养设施立项的，以智力、精神及重度残疾人为服务对象，提供托管、养护服务为主，辅以针对残疾人特点的康复、教育、职业技能培训等服务的设施；托养设施主要包括生活技能训练用房、康复用房、培训与教育用房、就业训练与生产劳动用房、托养住宿用房、生活用房、辅助用房等。

（二）台账填报注意事项。

1.填报范围。填报范围为各级残联所有的综合服务设施、康复设施、托养设施情况，挂靠的不填（具体内容请参看附件1）。

2.不能重复填报。一个机构只能在一类机构中填报，不能重复填报。如：×××省×××康复中心，在康复设施台账中填报，就不能再在填报到综合服务设施台账中填报。

3.认真核实所填数据的单位。建设用地面积、建设规模、总投资等使用的单位均不一致，要准确填写，数据过大或过小都要认真核查。如：建筑面积单位是“万平米”；投资单位是“万元”。

**二、**2012年服务设施年报

（一）填报方法。

服务设施年报三张表数据在统计系统中由台账直接点击运算生成，不需手动填报（具体内容请参看附件2）。

（二）注意事项。

《残疾人康复设施建设》、《残疾人托养设施建设》两张表填报范围在2012年报报表制度中说明为“2011年起中央安排投资项目”，现更正为“截止到2012年底各级残联所有的康复设施、托养设施项目”，与台账一致，由台账运算生成。

**三、**数据审核

各级残联要加强对上报数据的逐级审核工作，把握好与历史数据的延续性，如与历史数据有出入，请查明原因。如：在设施个数上必须满足“本年累计已投入使用项目个数”大于等于“上年累计已投入使用项目个数” 与 “本年新投入使用项目个数”之和；本年台账中若有“新投入使用项目”，上年台账中应填报有“在建”或“筹建”的同一个项目；“建设规模”、“总投资”等指标处于在建或竣工等不同状态下数据相差不应较大等。

如出现与历史数据不符或有其他特殊原因无法填报等情况，请各省级负责基建和项目管理的相关部门将问题以文字报告的形式单独呈报，其中包括本省各级服务设施建设与填报情况、与以往数据衔接情况，以及其他需要说明的相关情况，在上报统计数据时通过电子邮件同时报送至中国残联计财部与信息中心。

**四、**报送要求及时间

请各级残联负责基建和项目管理的相关部门抓紧完成本省数据收集工作，通过“中国残疾人事业统计管理系统”完成数据的录入、审核工作；各级残联统计部门应配合做好系统的使用与数据的汇总和上报工作。

报送时间请严格执行中国残联下发的《关于做好2012年度残疾人事业统计工作的通知》（残联厅〔2012〕108号）的要求。省级台账数据上报时间为2013年1月15日前；省级年报上报时间为2013年1月18日前。

**五、**联系方式

填报过程中涉及业务及指标内容方面的问题请直接与中国残联计财部联系，有关软件系统的技术问题请通过省级残联统计人员与中国残联信息中心联系。

服务设施台账指标解释

表1.

残疾人服务设施建设档案表

1、所在区划：指建设项目所在地区，可遴选。

2、级别：根据隶属的残联级别选择省级、市级或县级。

3、填报单位：直接管理该项目的本级残联全称，如河北省石家庄市长安区残联。

4、服务设施名称：填写服务设施建设项目立项报告批复中的全称。如河北省石家庄市正定县残疾人综合服务设施。

5、服务设施类型：填写立项批复报告中的项目功能，可遴选。

----综合服务设施是指以综合服务设施立项的，具有就业服务、职业培训、康复指导、文体活动、辅具供应、法律服务功能的设施；至少具备四项以上功能的设施才能填报。

----康复设施是指以康复设施概念立项的，以康复医学为基础，运用医疗、工程、教育、职业、心理、社会等康复手段，对残疾人进行康复治疗和训练服务，提高或恢复其功能，使他们能够重返社会的场所；由康复中心、聋儿康复中心、辅具中心提供相应服务。

①康复中心用房包括：急诊部、门诊部、医技部、住院部、康复部、科研教学、行政管理、文体活动、生活用房、保障系统用房等；

②聋儿康复中心用房包括：教学部、康复部、门诊部、社区辅导部等；

③辅具中心用房包括：辅具展示、肢体辅具科、听力语言辅具科、视力辅具科、假肢矫形器科、无障碍工程科、综合评估科、住宿部、社会工作科、库房等。

----托养设施是指以托养设施概念立项的，以智力、精神及重度残疾人为服务对象，提供托管、养护服务为主，辅以针对残疾人特点的康复、教育、培训、职业技能培训等服务的设施；托养设施主要包括生活技能训练用房、康复用房、培训与教育用房、就业训练与生产劳动用房、托养住宿用房、生活用房、辅助用房等。

当该项目选择综合服务设施时，填写残疾人综合服务设施建设规模及投资明细表（表2）、文件明细表（表5）。

当该项目选择托养设施时，填写残疾人托养设施建设规模及投资明细表（表3）、文件明细表（表5）。

当该项目选择康复设施时，填写残疾人康复设施建设规模及投资明细表（表4）、文件明细表（表5）。

6、设施内独立法人机构名称：填写设施内具有独立法人资格的机构名称，如单独挂牌的聋儿康复机构、辅具中心等，挂靠残联的机构不填。

7、机构性质：按上一条所列机构实际情况选择全额事业单位、差额事业单位、自收自支事业单位、企业单位或其他。

8、服务设施状态：按照设施本年度进程选择筹建、在建和竣工，对应填入筹建时间、在建时间、竣工时间、投入使用时间。

筹建：已取得立项批复但未开工的项目；在建：已开工，但未竣工的项目；竣工：取得由设计单位、建设单位、施工单位、监理单位共同签字的四方验收单的项目。

筹建时间：立项报告的时间；在建时间：取得建设项目开工证的时间；竣工时间：由设计单位、建设单位、施工单位、监理单位共同签字的四方验收单时间。投入使用时间：指服务设施实际投入使用的时间。

9、建设性质：按照设施建设情况选择新建、改扩建。如设施是以合建、租赁或借用等方式使用的，此指标为空，并请在备注中简要说明。

10、服务设施产权性质：按房产权属选择自有/非自有。如选择产权“非自有”时，对产权不明、无产权等情况请在备注中简要说明。

2、填报单位　指按照国家行政区划确定的县级及县级以上残联须填报。

3、各上报单位分别填报自身设施情况明细，不进行汇总直接上报。

4、填报依据：（1）残疾人托养设施是为智力、精神和其他重度残疾人提供基本生活照料服务，开展生活技能训练、职业康复、职业培训与教育、工（农）疗、就业前训练等业务，组织残疾人从事简单生产劳动，以及相应的文化教育和休闲娱乐活动的场所。（2）填报单位应填报本级所属托养设施，社区、街道相关设施无需填报。租赁设施开展托养服务的，也应填报，并在“备注”中注明。

5、若有其他需要说明问题，可在"备注"中注释。

服务设施年报指标解释

表1.

残疾人综合服务设施建设

1、已投入使用项目：指所建综合服务设施已竣工验收并开展为残疾人服务的设施。

其中，"本年度新投入使用项目"指在本年度1月1日到本年度12月31日之间新投入使用的设施。

2、累计已投入使用项目："指截止到本年度12月31日，已经投入使用的全部设施。

3、在建项目：指正在建设项目，包括已开工但未竣工项目及已竣工但未投入使用项目（可在"备注"中说明）。

4、筹建项目：指已立项但未开工的项目。

5、建设用地面积：指所建综合服务设施所用土地的面积。[1平方米 ＝ 0.0015亩]

6、建设规模：即建筑面积，又称建筑展开面积。指所建综合服务设施各层使用面积、辅助面积和结构面积的总和。

7、总投资：新增固定资产建设期间的支出合计。
