# 共青团中央办公厅、全国少工委办公室关于组织实施“国培计划(2012)”——中小学骨干少先队大队辅导员培训项目的通知

## 共青团中央办公厅、全国少工委办公室关于组织实施“国培计划（2012）”--中小学骨干少先队大队辅导员培训项目的通知（中青办联发[2012]6号）

各省、自治区、直辖市团委、少工委，新疆生产建设兵团团委、少工委：

根据《教育部办公厅、财政部办公厅关于做好2012年“国培计划”实施工作的通知》（教师厅〔2012〕3号）总体部署，经研究，共青团中央、全国少工委决定组织实施“国培计划（2012）”--中小学骨干少先队大队辅导员培训项目。

**一、**培训时间及地点

培训时间：2012年8月19-28日（8月19日报到）。培训10天（60学时）。

培训地点：中国青年政治学院。

**二、**培训对象及条件

（一）全国100名获得省级及以上表彰的现职优秀少先队大队辅导员，应兼顾城市和农村（见附件1）。

（二）民族地区50名获得地市以上表彰的现职优秀少数民族少先队大队辅导员（见附件2）。

**三、**培训目标

通过培训，更新辅导员教育观念和知识，提高辅导员工作技能，增强辅导员对少年儿童进行社会主义核心价值体系教育，特别是讲党讲社会主义祖国的能力，培养政治素质过硬、职业素质优良的骨干辅导员，加强少先队辅导员队伍建设。

**四、**培训方式

采取集中培训方式进行，坚持理论与实践相结合，将专题学习与案例研讨、观摩实践与反思体验相结合。

**五、**培训内容

（一）专业理念与师德。少先队的基本范畴和主要工作思路，中小学教师专业标准（试行）与少先队辅导员的专业发展；党对少先队工作的要求，少先队的组织属性、根本任务、基本职能及近期工作。

（二）学科理论知识。少年儿童组织与思想意识教育基本原理；少年儿童组织与思想意识教育方法；少年儿童重要思想意识形成的心理规律；少年儿童组织认同与组织管理；少年儿童思想意识的影响因素及其运用；多元文化下的政治推广与少年儿童；民族宗教政策和理论（民族班课程）。

（三）工作方法技能。运用少先队组织生活教育少年儿童的工作方法和技能；少先队灌输培养少年儿童对党和社会主义祖国朴素感情的代表性方法；少先队活动课程；当代教育引导孩子的理念与方法（民族班不选修）；少先队活动设计和文化产品；新媒体运用与少先队；少先队实训活动；如何设计少年儿童喜欢的爱党爱社会主义祖国主题活动；少先队工作热点、难点研究（民族班不选修）；民族地区少先队工作及少年儿童民族团结教育的重要方法（民族班课程）；如何设计少年儿童喜欢的民族团结教育活动（民族班课程）。

**六、**培训组织与管理

团中央少年部（全国少工委办公室）、教育部教师工作司负责项目统筹管理工作。各省级团委、少工委负责本地参训学员的遴选、组织管理和学习支持服务工作。中国青年政治学院负责项目具体实施工作。

**七、**有关要求

（一）各省级少工委要按照遴选条件和项目名额分配表遴选参训学员，填写《“国培计划（2012）”--中小学骨干少先队大队辅导员培训项目学员信息汇总表》（附件3），于7月31日前以传真形式报送至全国少工委办公室，由全国少工委报“国培计划”项目办（以下简称项目办）。已经参加过国培计划的辅导员不再选派。

（二）中国青年政治学院要于8月3日前将培训通知书寄至各省级少工委，各省级团委、少工委在收到培训通知书后要及时通知学员参训。

（三）中国青年政治学院在培训结束后15日内将培训项目绩效自评报告、学员评价表等材料提交至项目办，并通过“国培计划”项目管理系统提交电子版。

（四）培训班额为每班50人。教育部提供专项经费，用于支付参训学员培训费、食宿费、资料费等。中国青年政治学院严格按照项目工作要求和有关财务规定编制培训经费预算表（须加盖本单位公章），于8月3日前报送至项目办，经审核批准后先行拨付培训经费的60％。培训任务结束后，培训单位提交项目经费决算报告（须加盖本单位财务专用章），经绩效考评后拨付余额。中国青年政治学院保留培训费用原始单据备查。

（五）教育部将采取网络匿名评估、专家实地考察评估和第三方评估等方式对承办院校培训绩效进行考核。绩效考核内容主要包括培训实施方案执行情况、培训效果、经费使用管理情况等。考核结果将作为资质调整、任务分配的重要依据。

（六）查询项目具体工作事宜和下载表格，请登录“国培计划”网站（www.gpjh.cn）。
