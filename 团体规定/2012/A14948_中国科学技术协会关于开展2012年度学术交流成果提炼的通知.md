# 中国科学技术协会关于开展2012年度学术交流成果提炼的通知

全国学会、协会、研究会办公室（秘书处）：

按照《中国科协学会决策咨询资助计划管理办法》规定，中国科协调宣部会同学会部、学会服务中心开展2012年度第一批学术交流成果提炼工作，鼓励支持学会将学术交流成果转化为服务党和政府科学决策的政策建议，发挥好学会在建设国家级科技思想库中的独特作用。现将有关事项通知如下：

1、根据全国学会上报的2012年学术会议计划，确定了第一批有潜在政策建议价值的学术会议（见附件），请有关学会做好此类会议成果的提炼工作。此后需进行成果提炼的学术会议目录将以适当方式另行公布。

2、鼓励和支持全国学会自主选择若干重要学术会议，开展交流成果提炼，努力放大学术会议的政策和社会影响。

3、通过以奖代补、奖补结合的方式，对完成质量较好的学术会议成果提炼工作给予专项资助，支持全国学会进一步做好决策咨询工作。
