# 2012年地方科协学会学术工作座谈会报到通知

## 2012年地方科协学会学术工作座谈会报到通知（科协学函综字〔2012〕209号）

各省、自治区、直辖市、副省级城市科协学会部，新疆生产建设兵团科协学会部：

2012年地方科协学会学术工作座谈会的筹备工作已基本就绪，现将报到事宜通知如下。

**一、**会议时间、地点

（一）时间：12月11日全天报到，12-13日开会。

（二）地点：山东省临沂市颐正园宾馆（临沂市北城新区，电话：0539-7017888）。

（三）接站：12月11日全天，济南、临沂机场、火车站（建议直接到临沂）按回执安排接站，请参会代表在回执上注明航班、车次。

**二、**注意事项

（一）请参会代表按要求将会议材料电子版发送给山东省科协学会部王晶（xhb@sdast.org.cn）。

（二）参会人员食宿费收取标准230元/人/天，公共费用由中国科协承担。如需住单间请务必在回执中注明，并另加200元/人/天的住宿费用。

（三）请填写参会代表回执，并于12月5日前将回执传真或发送电子邮件至山东省科协学会部。
