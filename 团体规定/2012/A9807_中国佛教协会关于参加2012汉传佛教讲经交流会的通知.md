# 中国佛教协会关于参加2012汉传佛教讲经交流会的通知

## 中国佛教协会关于参加2012汉传佛教讲经交流会的通知（中佛会〔2012〕174号）

各省、自治区、直辖市佛教协会，中国佛学院：

经各地佛教协会及中国佛学院推荐并经我会审核，参加“2012汉传佛教讲经交流会”的讲经法师名单已确定。现将与会相关事项通知如下：

**一、**报到时间

11月5日15：00前（自行前往）。

**二、**报到地点

浙江宾馆（杭州市西湖区三台山路278号，电话：0571～87180808）

**三、**报销事宜

请参加交流会的法师保留好交通费用的票据以便报销。

**四、**联系人及电话

中佛协教务部：贺　敬　13146786696

杭 州 市佛协：汪永祥　13958127013

请及时将本通知内容转达参加讲经交流会的法师。

二〇一二年十月十八日
