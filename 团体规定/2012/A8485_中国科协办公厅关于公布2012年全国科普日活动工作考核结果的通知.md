# 中国科协办公厅关于公布2012年全国科普日活动工作考核结果的通知

## 中国科协办公厅关于公布2012年全国科普日活动工作考核结果的通知（科协办发普字〔2012〕48号）

各全国学会、协会、研究会，各省、自治区、直辖市、副省级城市科协，新疆生产建设兵团科协：

2012年9月，各全国学会、各级科协按照中国科协办公厅《关于举办2012年全国科普日活动的通知》（科协办发普字〔2012〕29号）的要求，围绕《全民科学素质行动计划纲要》的工作主题“节约能源资源、保护生态环境、保障安全健康、促进创新创造”，开展了形式多样、内容丰富的科普活动，活动圆满成功。

根据全国学会和省级科协的工作总结和推荐，2012年11月中国科协对全国科普日工作进行了考核。根据考核结果，北京市科协等276个单位被评为“2012年全国科普日活动优秀组织单位”，北京国际科学电影展等144项活动被评为“2012年全国科普日活动优秀特色活动”。希望受到表扬的单位认真深入学习、贯彻落实党的十八大精神，再接再厉，奋发进取，努力做好今后全国科普日等各项科普工作，为提高全民科学素质，增强自主创新能力，建设创新型国家做出新的、更大的贡献。
