# 中国残联办公厅关于举办2012年全国轮椅广播健身操训练营的通知

各省、自治区、直辖市残联，新疆生产建设兵团残联：

为落实残疾人事业“十二五”发展纲要和《全民健身计划（2011-2015年）》，丰富活跃残疾人体育健身活动，经中国残联领导同志同意，决定于2012年12月在天津市举办全国轮椅广播健身操训练营。现将有关事项通知如下：

**一、**时间与地点

（一）时间：2012年12月11日至15日（11日报到，15日离会）。

（二）地点：天津巨川国际商务酒店（地址：天津市滨海新区塘沽京塘路1155号，联系人：谢曙光 电话：13920163581）

**二、**训练内容

学习轮椅广播健身操相关术语及基本理论，掌握规范动作、技术要领以及教学教法，观摩天津市残疾人体育健身活动，学习成果评估考核。

**三、**学员资质条件

（一）基层从事残疾人工作人员，各地残疾人体育管理人员，学校从事残疾人体育教学和训练人员，并将承担本省（区、市）残疾人体育健身指导员培训任务的人员。

（二）应具有较强的爱心和责任感，并具有一定的组织能力和讲解能力。

**四、**名额分配

具体名额分配见附件1。

**五、**推荐方法

由各省（区、市）残联负责按要求推荐人员参加学习，并将2012年全国轮椅广播健身操推荐表（加盖公章）（见附件2）收集整理后，于12月3日前传真发送至中国残联体育部或将电子版发送至tyb@cdpf.org.cn。

**六、**经费

学员往返交通费由各地承担；训练营期间食宿和资料费用由中国残联承担。

**七、**有关要求

（一）各地残联做好学员推荐工作，选派综合素质和业务能力较强的业务骨干参加学习。

（二）各地残联推荐学员时，与本省推进、实施残疾人体育健身指导员培训工作安排相结合，保证学员的人员数量和学习时间，学习期间学员不得请假。

（三）请学员自备运动服装，报到时携带1张2寸免冠彩照。

（四）请于2012年12月3日前将回执表（见附件3）传真至天津市滨海新区塘沽残联，以便安排接送站和返程票预订等事宜。
