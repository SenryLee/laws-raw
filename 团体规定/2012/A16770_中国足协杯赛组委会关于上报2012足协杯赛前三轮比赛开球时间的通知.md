# 中国足协杯赛组委会关于上报2012足协杯赛前三轮比赛开球时间的通知

东芝2012中国足协杯赛抽签工作已于4月25日完成，为保证本年度足协杯前三轮比赛的顺利进行，请相关参赛单位根据足协杯赛的比赛日期，上报本赛区主场比赛的开球时间，足协杯赛组委会将根据各参赛单位上报的比赛开球时间制定相应比赛日程，所涉及的参赛单位如下：

第一轮（5月26日）：湖北青年、陕西老城根、广东青年、山东男足、东莞南城、上海中邦、贵州智诚、河北中基

第二轮（6月2日）：重庆力帆、北京八喜、沈阳沈北、湖南浏阳河、上海特莱士、成都谢菲联、天津松江、深圳茅台红钻、呼和浩特东进、武汉卓尔、延边长白虎、广东日之泉

第三轮（6月27日）：河南建业、大连阿尔滨、上海申鑫、广州富力、杭州绿城、江苏国信舜天、山东鲁能泰山、上海申花、长春亚泰、青岛中能、大连实德、贵州茅台

如因电视转播及统一商务活动要求需调整某些场次的比赛日期及开球时间，中国足协将在赛前两周通知有关赛区及俱乐部。

附件为《东芝2012 中国足协比赛开球时间申报表》，请各有关单位在5月6日17：00前将申报表同时传真至中国足协职业部和福特宝公司。
