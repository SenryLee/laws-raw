# 全国妇联办公厅关于报送2012年妇联有关工作数据的通知

## 全国妇联办公厅关于报送2012年妇联有关工作数据的通知（妇厅字[2012]17号）

各省、自治区、直辖市妇联办公室，新疆生产建设兵团妇联办公室：

为筹备全国妇联十届五次执委会议，根据《全国妇联2012年工作要点》，请就有关重点工作推进的数据情况进行统计填报（报表附后）。填报要求如下：

1．填报工作要严谨细致、认真负责，统计指标要填报完整，统计数据要客观、有效。

2．统计时限：2012年1月1日-10月20日

3．请各省区市妇联办公室及时登陆中国妇女网下载统计表，提前部署并组织好填报工作。请于10月30日前将本省统计表电子版通过“中国妇女网信息交流站”报送，同时将纸质材料经主管领导签字、加盖公章后报全国妇联办公厅信息处。

联系人：杨莹瑛

联系电话：010-65103031

附件：2012年度妇联有关工作数据统计表

全国妇联办公厅

2012年10月15日
