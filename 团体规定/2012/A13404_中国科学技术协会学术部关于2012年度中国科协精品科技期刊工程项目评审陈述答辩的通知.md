# 中国科学技术协会学术部关于2012年度中国科协精品科技期刊工程项目评审陈述答辩的通知

## 中国科学技术协会学术部关于2012年度中国科协精品科技期刊工程项目评审陈述答辩的通知（科协学发〔2012〕112号）

各有关全国学会，各有关期刊出版单位：

2012年度中国科协精品科技期刊工程项目评审会定于7月24日在中国科技会堂召开，请申报精品科技期刊培育计划和科技期刊国际推广计划各项目的期刊出版单位及其主办单位各选派一名负责人（共2人）参加项目陈述答辩。现将有关事项通知如下：

**一、**时间地点

时间：7月24日9：00至17：00。

会议地点：中国科技会堂（北京市复兴路3号）。

答辩会议室详见申报项目单位陈述安排表。

等候室：B104、B305；会务组： B206。

**二、**陈述方式和内容

各申报单位按照排定顺序依次进入答辩会议室，由陈述人向评审专家组进行8分钟的项目陈述（采用ppt形式），主要内容包括：申报单位实际情况及项目实施条件、任务目标设立情况及项目预期效益、项目可行性及实施计划、保障措施等方面。陈述完毕后由评审专家提问，陈述人进行答辩。

**三、**具体要求

1.请各申报单位代表于陈述前30分钟到达会议地点，在等候室等待工作人员通知。项目陈述时间顺序和会议室安排详见附件1；

2.请各申报单位务必于7月16日前将陈述答辩回执（附件2）以电子邮件形式进行反馈。
