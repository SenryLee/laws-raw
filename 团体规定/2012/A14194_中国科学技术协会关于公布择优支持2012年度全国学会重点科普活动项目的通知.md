# 中国科学技术协会关于公布择优支持2012年度全国学会重点科普活动项目的通知

## 中国科学技术协会关于公布择优支持2012年度全国学会重点科普活动项目的通知（科协普函综字〔2012〕42号）

各有关全国学会、协会、研究会科普部（普委会）：

为深入贯彻落实《全民科学素质行动计划纲要》，进一步提高全国学会科普工作能力和水平，重点扶植、培育一批具有一定影响力的品牌科普活动，促进全国学会科普工作持续发展，中国科协科普部2012年继续组织实施全国学会重点科普活动项目。在项目申报阶段共收到82个全国学会申报的98个项目。经过资格审查和项目评审，决定择优支持24个全国学会的24个项目（名单见附件），每个项目资助额为10万元。

请各项目承担单位按照《中国科协项目管理办法》和项目书要求，认真做好项目的组织实施工作，并在项目完成后按时报送总结。

附件：2012年全国学会重点科普活动项目支持名单
