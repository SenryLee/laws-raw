# 中国科协计划财务部关于举办2012年度全国学会财务决算培训的通知

## 中国科协计划财务部关于举办2012年度全国学会财务决算培训的通知（科协计函财字〔2012〕59号）

各全国学会办公室（财务）：

为了做好2012年度全国学会财务决算工作，经研究，兹定于2012年12月19-21日在广东珠海市举办2012年度全国学会财务决算培训，现将培训有关事项通知如下：

**一、**培训内容

1. 总结2011年度全国学会财务决算编报工作；

2．表彰2011年度全国学会财务决算编报优秀单位；

3．讲解2012年度全国学会财务决算报表和软件；

4．财务决算编报工作经验交流。

**二、**培训要求

1．请各学会派1名负责财务决算工作的主管会计人员参加培训。

2．请参会人员自带笔记本电脑，操作演示财务决算报表网络填报方式。

3．请各单位于2012年12月13日前，将会议回执传真至会务组，传真电话：（0871）4127994。

联系人：阎　　勤 13013330788

余　　琼 13908854798、13888088133

高玉鑫 13811975713

4．本次培训会务工作委托中华医学会承担。

附件：2012全国学会财务决算培训参会回执
