# 中国残联计财部关于做好中国残联直属预算单位国库集中支付会计对账工作的通知

## 中国残联计财部关于做好中国残联直属预算单位国库集中支付会计对账工作的通知（残联计财函[2012]21号）

各直属预算单位：

为加强财政资金管理，规范中央财政资金国库集中支付会计对账行为，确保财政资金支付安全，财政部、中国人民银行近日印发了《中央财政国库集中支付会计对账办法》（财库[2011]180号），我会已将该文件链接发布在中国残联计财部网页上，请各单位组织相关人员认真学习并遵照执行；现就中国残联直属预算单位国库集中支付会计对账工作要求如下：

**一、**加强基层单位与开户银行之间对账工作

各直属预算单位必须与开户银行之间按月按时对账，并于每月终了后5个工作日内将与开户银行对账结果、异常及更正情况以电子邮件形式报计财部财务处（jcb_cwc@cdpf.org.cn，邮件标题：“××单位2012年×月零余额账户对账情况”；自2012年2月起）。

**二、**做好与代理银行总行对账工作

计财部财务处将汇总各直属预算单位对账情况，并在规定时间内与代理银行总行对账。

**三、**做好与财政部对账工作

计财部将与财政部国库司按季在季度终了后15个工作日内将对账结果报财政部国库司。

**四、**管理与监督

对违反《中央财政国库集中支付会计对账办法》规定，有下列行为之一的，依法追究其责任：

（一）不按规定的时间及要求发出对账单；

（二）伪造、变更或提供虚假对账单；

（三）不按规定核对和反馈对账信息或反馈虚假对账信息；

（四）对账中发现问题不及时核查原因并予以更正；

（五）不配合相关单位核查和解决对账中发现的问题；

（六）对账过程中，违反保密规定和信息安全规定。

有上述所列行为之一的有关人员，造成财政资金重大损失、构成犯罪的，移交司法机关追究刑事责任；尚未构成犯罪的，视情节轻重，予以通报，相关责任人由其所在单位给予行政处分或处以罚款。

有上述所列行为之一的预算单位，视情节轻重，予以通报，并适用《财政违法行为处罚处分条例》。
