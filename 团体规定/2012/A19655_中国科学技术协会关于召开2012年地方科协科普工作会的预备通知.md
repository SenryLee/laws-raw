# 中国科学技术协会关于召开2012年地方科协科普工作会的预备通知

## 中国科学技术协会关于召开2012年地方科协科普工作会的预备通知（科协普函综字〔2012〕6号）

各省、自治区、直辖市、副省级城市科协科普部，新疆生产建设兵团科协科普部：

为学习贯彻中央书记处和国务院对全民科学素质工作和科普工作的指示精神，落实中国科协八大和八届二次全委会议精神，总结2011年的工作，部署2012年重点工作，中国科协科普部定于3月22-23日（21日报到）在四川召开地方科协科普工作会议。现将有关事项通知如下：

**一、**会议内容

总结2011年工作，交流各地科普工作经验，部署2012年重点工作。

**二、**参会人员

各省、自治区、直辖市、副省级城市和新疆生产建设兵团科协分管科普工作的领导同志和科普部负责同志各1名。

**三、**有关要求

请各地于3月14日前将本单位参会人员和2011年科普工作总结（电子版）报至四川省科协科普部。

会议具体时间地点另行通知。
