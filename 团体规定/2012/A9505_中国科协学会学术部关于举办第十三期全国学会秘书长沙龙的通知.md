# 中国科协学会学术部关于举办第十三期全国学会秘书长沙龙的通知

## 中国科协学会学术部关于举办第十三期全国学会秘书长沙龙的通知（科协学函管字〔2012〕191号）

各全国学会、协会、研究会办公室（秘书处）：

为贯彻落实全国科技创新大会有关精神，搭建全国学会工作交流合作平台，促进秘书长之间的工作沟通与合作，交流学会在提升服务社会能力方面的新经验、新做法，拓宽各学会的工作思路和方法，定于2012年11月22日-23日在天津市举办第十三期全国学会秘书长沙龙活动。现将有关事项通知如下：

**一、**主题

发挥学会自身优势 提升服务社会能力

**二、**时间和地点

时间：2012年11月22日-23日，21日报到，会期两天。

地点：天津市赛象酒店（天津市南开区新技术产业园区梅苑路8号）。

**三、**参会人员

中国科协所属全国学会秘书长（或副秘书长），每个学会限报一个名额。由主办单位根据会议预先确定的名额，按报名回执的先后确定参会代表。

**四、**会议组织

中国科协学会学术部主办，中国抗癌协会承办。

**五、**其他

1．会议统一提供食宿，安排住标准间；若有住单间需求，请在回执中注明，并自行交纳相应费用。参会代表交通费自理。

2．参会代表名额确定以报名先后顺序为据。请有意参加沙龙的学会于2012年11月10日前确定一名参会代表，并将会议回执传真或E-mail至中国抗癌协会办公室。参会代表资格将于11月中旬确定并通知有关学会。

3．请参会代表围绕会议主题准备发言内容。

4．会务组安排接送站，自行前往的代表，请于2012年11月21日（周三）在天津赛象酒店（天津市南开区新技术产业园区梅苑路8号，前台电话：022- 23768888，400 777 9188）大堂报到。
