# 中国残联办公厅、国家体育总局办公厅关于印发2012年全国残疾人体育各竞赛项目规程的通知

各省、自治区、直辖市残联、体育局，新疆生产建设兵团残联、体育局：

为进一步做好残疾人体育工作，推进残疾人体育事业发展， 2012年将举办系列全国残疾人体育赛事。现将《2012年全国残疾人体育各竞赛项目规程》印发给你们，请遵照执行。

中国残联办公厅　

国家体育总局办公厅

二〇一二年七月十日

2012年全国盲人乒乓球比赛规程

**一、**主办单位

中国残疾人联合会、国家体育总局、中国残奥委员会

**二、**承办单位

辽宁省残疾人联合会、辽宁省体育局、辽宁省残疾人体育协会

**三、**时间

2012年11月12日至17日

**四、**地点

辽宁省沈阳市

**五、**参赛单位

以省（区、市）为单位，每省（区、市）两支队伍参加

**六、**竞赛分组

公开级男子组、公开级女子组

**七、**竞赛项目

男子团体、女子团体、男子单打、女子单打

**八、**参赛资格

（一）参赛选手必须符合视力残疾选手达到B3级的最低分级标准。

（二）参赛单位须为参赛选手办理人身保险。

（三）选手必须经过县级以上医务部门检查，证明身体健康状况适合参加所报项目的比赛。

**九、**参赛办法

（一）以省（区、市）为单位报名，每省（区、市）限报参赛队伍2支。

（二）每参赛队伍男、女团体限报各1队；单打每参赛队伍限报男、女选手各4人。

（三）工作人员与运动员比例为1：3。

（四）每省（区、市）应指定一名残联系统工作人员担任总领队。

**十、**竞赛办法

（一）竞赛规则。

执行中国残奥委员会印发的《盲人乒乓球比赛规则》。可在中国残疾人体育网站（www.cpc2008.org.cn）查询。

（二）竞赛形式。

1、比赛的形式将根据报名人数采取淘汰附加赛或分组循环赛，具体办法在《竞赛补充通知》中进一步说明。

2、团体赛按考比伦杯的出场顺序排列。其中双打运动员名单须在比赛前指定。

3、团体赛和单项比赛均采取五局三胜制，每局比赛采用11分制。

4. 盲人组最低分级标准为B3级，采取公开级比赛。

（三）竞赛规定。

1. 选手比赛时一律配戴眼罩。眼罩自备，如经检查不合将使用大会提供的眼罩。

2. 竞赛分组：由技术代表、裁判长主持的抽签会决定。

3. 种子运动员由中国残奥委员会根据第八届全国残疾人运动会乒乓球比赛成绩确定。

4. 比赛用球：使用国产白色40mm乒乓球。训练用球各队自备。

5. 参赛选手不得无故弃权，否则将取消所有后续比赛资格，视情节按有关纪律规定进行处理。

6. 运动员因伤病请假，应有大会医生证明及领队签字，须经技术代表批准。

**十一、**名次录取与奖励办法

（一）名次录取办法。

单项和团体赛各单项均录取前八名。

（二）奖励办法。

获得个人赛和双人赛各单项前八名的选手，颁发证书和奖品。获得团体赛前八名的队伍颁发奖杯。

（三）设“体育道德风尚奖”，评选办法另发。

**十二、**技术人员要求

除中国残奥委员会委派的技术人员外，其他裁判员及工作人员均由承办单位负责安排。

**十三、**报名和报到

（一）报名

各单位于2012年10月8日前，将盖有单位公章的报名表

一式两份，分别传真或邮寄至中国残联体育部和承办单位。

（二）报到

各队于2012年11月12日报到，提前报到需与承办单位联系。

**十四、**费用

（一）各代表队在规程规定人数内的人员，赛会期间食宿费每人每天交纳人民币90元，往返差旅费用均由组队单位自理。

（二）超编选手及工作人员、提前抵达或推迟离会的人员费用自理。

（二）主办单位选派人员的往返交通费及赛会期间食宿费用由组委会承担。

**十五、**比赛冠名

比赛冠名须报主办单位授权。

**十六、**联系人及联系方式

2012年全国聋人乒乓球锦标赛竞赛规程

**一、**主办单位

中国残疾人联合会、国家体育总局、中国聋人体育协会

湖北省残疾人联合会、湖北省体育局、武汉市残疾人联合会

**三、**时间

2012年10月15日至20日

**四、**地点

湖北省武汉市

**五、**参赛单位

各省、自治区、直辖市、新疆生产建设兵团

**六、**竞赛类别

听力残疾

**七、**竞赛项目

男子团体、女子团体、男子单打、女子单打、男子双打、

女子双打、混合双打

**八、**参赛资格

（一）参赛运动员必须在中国聋人体育协会进行注册。

（二） 参赛运动员必须符合聋人运动员的最低听力测试标准（双耳听力损失均大于55分贝）。

（三）经县级以上医务部门检查，证明身体健康状况适合参加所报项目的比赛。

**九、**参赛办法

（一）以省、自治区、直辖市、新疆生产建设兵团为单位报名参加。

（二）每单位男、女团体限报各1队；单打每单位男、女限报各4人。双打每单位男、女限报各2对。

（三）工作人员与运动员人数比例为1：3。

**十、**竞赛办法

（一）竞赛规则

执行国际乒乓球联合会最新审定的乒乓球竞赛规则。

（二）竞赛形式

1、比赛的形式将根据报名人数选择采取淘汰赛或循环赛或结合等形式，具体办法在《竞赛补充通知》中进一步说明。

2、团体赛按考比伦杯的出场顺序排列。其中双打运动员名单须在比赛前指定。

3、团体赛采取五局三胜制。单打和双打均采取五局三胜制，每局采用11分制。

4、双打和混合双打可以跨省市配对参加。

（三）竞赛规定

1、运动员参赛时必须持有参赛证。

2、运动员参赛时不允许佩戴助听器。

3、竞赛分组：由技术代表、裁判长主持的抽签会决定。

4、种子运动员由中国聋人体育协会根据第八届全国残疾人运动会乒乓球比赛成绩和2011年世界锦标赛比赛成绩确定。

5、各单位报名时，应按运动员技术水平，由强至弱排列顺序。

6、比赛用球：使用国产白色40mm乒乓球。训练用球各队自备。

7、运动员不得无故弃权，否则将取消所有后续比赛资格，视情节按有关纪律规定进行处理。

8、运动员因伤病请假，应有大会医生证明及领队签字，须经技术代表批准。

（四）兴奋剂检测

中国聋人体育协会将按照国家体育总局兴奋剂检测中心拟定的检测计划进行抽测。

**十一、**名次录取及奖励办法

（一）录取办法

团体、单项均录取前六名，6人（队）以下（含6人或6队）减一录取。

（二）奖励办法

获得前三名的运动员分别颁发金、银、铜牌和证书，获得四至六名的运动员颁发证书。

（三）设“体育道德风尚奖”，办法另发。

（二）报到

**十四、**费用

100米、200米、400米、800米、1500米、5000米、10000米、100米栏、400米栏、3000米障碍、4×100米接力、4×400米接力、跳高、撑竿跳高、跳远、三级跳远、铅球、铁饼、标枪、链球、七项全能。

**八、**参赛资格：

（一）参赛运动员必须在中国聋人体育协会进行注册。

（二）参赛运动员必须符合聋人运动员的最低听力测试标准（双耳听力损失均大于55分贝）。

（三）经县级以上医务部门检查，证明身体健康状况适合参加所报项目的比赛。

**九、**参赛办法：

（一）以省、自治区、直辖市、新疆生产建设兵团为单位报名，限报男女运动员共25人。

（二）每单位每项限报3人，每人限报3项（接力除外）；接力比赛，每项每单位限报男、女各1队。

（三）每队工作人员与运动员的比例为1：3。

**十、**竞赛办法：

（一）执行中国田径协会审定的最新《田径竞赛规则》。

（二）比赛检录时，运动员必须持有参赛证。

（三）运动员比赛时，需穿着印有单位名称的统一服装（背心、短裤）。接力比赛时，运动员必须穿着印有单位名称的统一服装（背心、短裤）。

（四）除撑竿自备外，其它比赛器材由大会组委会提供。

（五）参赛级别确认后，无故不参加比赛者，将取消所有比赛成绩和后续项目的比赛资格；视情节按有关纪律规定处理。

（六）运动员在参赛时不得使用助听器。

（七）运动员因伤病请假，应有大会医生证明及领队签字，并须经技术代表批准。

（八）兴奋剂检测：中国聋人体育协会将按照将国家体育总局兴奋剂检测中心拟定的2012年检测计划进行抽测。

**十一、**名次录取、计分与奖励办法：

（一）录取办法：

1、单项：各单项按名次录取前六名，参赛六人以下（含六人）减一录取。

2、团体总分录取前八名。

（二）计分办法：

1、各单项录取前六名，按7、5、4、3、2、1计分；全能项目、接力项目录取前六名，按14、10、8、6、4、2计分，不足六人按高限录取计分。

2、超、创纪录计分：在每一个赛次（包括田径的全能的每一个单项）中，创全国纪录并超世界纪录加7分；创全国纪录并平世界纪录加4分；创全国纪录并未超、平世界纪录加1分；同一项目，多次超、创纪录者，以超、创最高纪录一次计分。

3、按各单位各项名次得分，创全国纪录及超、平世界纪录得分，累计计算团体总分，排列团体名次。如总分相等，以超世界纪录多者名次列前；若仍相等，以创全国纪录多者名次列前；若还相等，获金牌数多者名次列前，以此类推。

（三）奖励办法：

1、单项：获得前三名的运动员，分别颁发金、银、铜牌和证书；获得四至六名的运动员，颁发证书。

2、团体：获得团体总分前八名的单位颁发奖杯。

（四）设“体育道德风尚奖”。

**十二、**技术人员：

除主办单位委派的技术人员外，其他技术人员均由承办单位负责安排。
