# 中国科学技术协会关于申报全国科普教育基地特色科普活动项目的通知

## 中国科学技术协会关于申报全国科普教育基地特色科普活动项目的通知（科协普函础字〔2012〕24号）

各有关全国学会、协会、研究会，各省、自治区、直辖市科协科普部，新疆生产建设兵团科协科普部：

为贯彻落实《全民科学素质行动计划纲要实施方案（2011-2015）》，支持和引导全国科普教育基地进一步挖掘科普资源，拓展科普活动内容、创新活动形式，提升全国科普教育基地科普活动策划、组织与实施能力，逐渐树立全国科普教育基地科普活动品牌，中国科协科普部2012年将开展全国科普教育基地特色科普活动项目申报工作。现将有关事项通知如下：

**一、**申报对象

经中国科协认定的全国科普教育基地（2010-2014年）。

**二、**申报条件

1.参与面广，时效性强。活动要求连续举办两年以上；活动单次参与人数或累计参与人数多，影响范围广，持续时间长，能够紧扣社会热点问题，及时有效地普及科学知识。

2.主题突出，特色鲜明。围绕“节约能源资源、保护生态环境、保障安全健康、促进创新创造”主题，紧扣当前社会热点以及公众密切关注的问题；在活动目的、受众、内容、媒介、成果等方面具有显著区别于其他科普活动的风格和特点。

3.内容丰富，形式新颖。活动传播的信息科学、严谨、全面、准确，贴合公众需求；活动形式多样，突出互动、体验、参与、游艺，能充分调动公众参与。

4.科普效果显著。活动受到领导重视、媒体关注和社会各界好评。活动教育意义深刻，社会关注度高，社会反响强烈，公众评价高，活动效果好。

5.有一定的资源成果。活动需生成科普活动资源包等资源成果，且资源包在同类型科普教育基地中具有普适性，并能在全国其他公益性科普活动中推广使用。

**三、**申报办法

1.项目采取网络申报与纸质申报同时进行的方式。用户登录全国科普教育基地官方网站（www.kpjd.org.cn）即可按操作说明进行网络申报。

2.网络申报结束可自动生成纸质材料。纸质材料打印后一式两份报推荐单位，由推荐单位核实汇总后并加盖公章一并报送中国科协科普活动中心。相关辅助材料（如音视频资料、相片、新闻报道等）一并报送。

3.推荐单位须在规定时限内登录申报平台，审核申报信息，并进行网上推荐。

4.时间安排：全国科普教育基地网上填报时间为2012年4月16日至5月11日，推荐单位网上审核时间为5月12日至21日。中国科协纸质材料接收日期截至5月28日。

**四、**评审与资助

中国科协将组织相关专家对申报项目进行评审，提出评审意见，对评出的特色科普活动项目给予相应的经费支持，并以一定形式进行宣传推广。
