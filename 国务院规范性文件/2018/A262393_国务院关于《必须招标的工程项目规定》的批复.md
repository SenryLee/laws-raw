# 国务院关于《必须招标的工程项目规定》的批复

国函〔2018〕56号

国家发展改革委：

国务院批准《必须招标的工程项目规定》（以下简称《规定》），由你委公布，公布时注明“经国务院批准”。《规定》的施行日期由你委根据实际情况确定。《规定》施行之日，2000年4月4日国务院批准、2000年5月1日原国家发展计划委员会发布的《工程建设项目招标范围和规模标准规定》同时废止。

国务院

2018年3月8日
