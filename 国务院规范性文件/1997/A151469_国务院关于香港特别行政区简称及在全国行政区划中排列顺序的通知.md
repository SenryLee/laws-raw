# 国务院关于香港特别行政区简称及在全国行政区划中排列顺序的通知

## 国务院关于香港特别行政区简称及在全国行政区划中排列顺序的通知（国函［１９９７］１１４号　１９９７年１２月１５日）

各省、自治区、直辖市人民政府，国务院各部委、各直属机构：

现将香港特别行政区的简称及在全国行政区划中的排列顺序通知如下：

**一、**香港特别行政区简称“港”。

**二、**在全国行政区划序列中，香港特别行政区列在台湾省之前。
