# 决定废止《煤炭经营监管办法》

## 中华人民共和国国家发展和改革委员会令

第23号

为贯彻落实党中央国务院关于深化“放管服”改革、加快政府职能转变的要求，现决定废止《煤炭经营监管办法》（2014年中华人民共和国国家发展和改革委员会令第13号），自公布之日起执行。

主任：何立峰

2019年3月28日
