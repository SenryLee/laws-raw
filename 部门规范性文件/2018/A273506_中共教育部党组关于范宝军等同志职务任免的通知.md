# 中共教育部党组关于范宝军等同志职务任免的通知

教党任〔2018〕304号

中共兰州大学委员会：

经与中共甘肃省委商得一致，2018年10月31日研究决定：

范宝军、沙勇忠同志任中共兰州大学委员会委员、常委；免去李正元同志的中共兰州大学委员会副书记、常委、委员，安黎哲同志的中共兰州大学委员会常委、委员职务。

中共教育部党组

2018年12月28日
