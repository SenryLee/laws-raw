# 国土资源部公告2018年第3号——国土资源部关于甘肃省永昌县—肃南县罗圈崖一带金矿普查等五个勘查许可证自行废止的公告

## 国土资源部关于甘肃省永昌县—肃南县罗圈崖一带金矿普查等五个勘查许可证自行废止的公告

根据《矿产资源勘查区块登记管理办法》（国务院令第240号）第十条和《国土资源部关于进一步规范矿产资源勘查审批登记管理的通知》（国土资规〔2017〕14号）的有关规定，经核实，甘肃省永昌县—肃南县罗圈崖一带金矿普查、甘肃省天祝县庄浪河一带金矿普查、甘肃省天祝县北西雷公山附近铜矿普查、甘肃省肃南县寺大隆一带铜矿地质普查和甘肃省肃南县松木滩铜矿地质普查等5个勘查项目在勘查许可证有效期届满前未依法办理延续登记申请手续，勘查许可证自有效期届满之日起已经自行废止。现予以公告。探矿权基本信息如下：
