# 国家文物局办公室关于在湖北省文物保护单位岳飞城遗址保护范围内进行207国道荆门团林至砖桥段一级公路建设项目的意见

办保函〔2018〕777号

湖北省文物局：

你局《关于207国道荆门团林至砖桥段一级公路涉及省级文物保护单位岳飞城遗址保护范围的请示》（鄂文物〔2018〕26号）收悉。经研究，我局意见如下：

一、暂不同意在湖北省文物保护单位岳飞城遗址保护范围内进行207国道荆门团林至砖桥段一级公路建设项目。

二、该项目应做以下必要的修改和完善：

（一）应加强考古资料整理和研究，科学评价岳飞城遗址的价值，进一步说明项目穿越岳飞城遗址保护范围的必要性。

（二）应进行207国道选线的多方案比选，建议在遗址西侧保护范围外开展207国道局部改道工程，尽量避让遗址保护范围。

（三）进一步深化文物影响评估报告，应客观、真实评估岳飞城遗址价值、布局、性质与公路的关系。

三、请你局指导项目建设单位，根据上述意见进一步修改和完善所报方案，按程序另行报批。

专此函复。

国家文物局办公室

2018年7月26日
