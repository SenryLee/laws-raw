# 国家粮食和物资储备局关于在湖南省启动2018年中晚稻最低收购价执行预案的通知

国粮发〔2018〕267号

中国储备粮管理集团有限公司：

你公司《关于湖南省启动2018年中晚稻最低收购价执行预案的请示》（中储粮〔2018〕260号）收悉。根据国家发展改革委、国家粮食和物资储备局等部门《关于印发小麦和稻谷最低收购价执行预案的通知》（国粮发〔2018〕99号）有关规定，经研究，同意自11月17日起在湖南省内符合条件的相关地区启动2018年中晚稻最低收购价执行预案。

国家粮食和物资储备局

2018年11月16日
