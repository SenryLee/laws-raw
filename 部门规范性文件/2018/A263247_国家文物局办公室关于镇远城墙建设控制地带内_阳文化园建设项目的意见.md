# 国家文物局办公室关于镇远城墙建设控制地带内?阳文化园建设项目的意见

办保函〔2018〕303号

贵州省文物局：

你局《关于审批全国重点文物保护单位镇远城墙建设控制地带内?阳文化园建设项目的请示》（黔文物呈〔2018〕9号）收悉。经研究，我局意见如下：

一、拟建隧道距离文物本体较近，对文物安全和景观风貌影响较大，暂不同意所报项目。

二、具体修改意见如下：

（一）进一步论述拟建项目及选址的必要性，补充镇远城墙建设控制地带的管理规定和建设控制要求。

（二）调整设计方案，地下隧道应远离城墙，确保隧道建设不影响城墙基础稳定；地下隧道出入口玻璃亭高度超过城垣，影响文物景观，建议取消出入口玻璃亭，采用备选方案露天出入口。

（三）应充分考虑施工振动对城墙安全的影响，制定必要的文物保护措施和应急预案，确保文物安全。

（四）修改完善文物影响评估报告，准确、客观评估拟建项目对文物本体及景观风貌的影响，避免大幅套用方案内容。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善后，另行报批。

国家文物局办公室

2018年4月10日
