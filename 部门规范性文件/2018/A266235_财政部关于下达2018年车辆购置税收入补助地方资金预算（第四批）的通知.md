# 财政部关于下达2018年车辆购置税收入补助地方资金预算（第四批）的通知

财建〔2018〕263号

有关省、自治区、直辖市、计划单列市财政厅（局）：

根据车辆购置税收入补助资金相关规定以及《交通运输部关于申请下达2018年度车辆购置税资金安排地方及兵团交通运输项目预算的函》（交财审函〔2018〕243号），现下达你省（自治区、直辖市、计划单列市）2018年车辆购置税收入补助地方资金预算（第四批），用于靠港船舶使用岸电项目支出预算（项目代码：Z135060000035；政府收支分类科目：214交通运输支出），具体项目、金额及绩效目标见附件。

请按照有关规定安排使用，加强资金管理，提高资金和靠港船舶岸电设施使用效益。

附件：1.2018年年车辆购置税收入补助地方资金（第四批）支出预算总表（不发地方）

2.2018年车辆购置税收入补助资金用于靠港船舶使用岸电项目整体绩效目标表（不发地方）

3.2018年车辆购置税收入补助地方资金用于靠港船舶使用岸电项目分省绩效目标总表（不发地方）

4.2018年车辆购置税收入补助地方资金（第四批）支出预算明细表（分发地方）（略）

5.2018年车辆购置税收入补助地方资金用于靠港船舶使用岸电项目绩效目标表（分发地方）（略）

财政部

2018年6月15日
