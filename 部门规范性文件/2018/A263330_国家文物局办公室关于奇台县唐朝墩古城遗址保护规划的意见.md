# 国家文物局办公室关于奇台县唐朝墩古城遗址保护规划的意见

办保函〔2018〕312号

新疆维吾尔自治区文物局：

你局《关于报送〈奇台县唐朝墩古城遗址文物保护规划（2017-2030）〉的请示》(新文物字〔2017〕37号)收悉。经研究，我局意见如下：

一、暂不同意唐朝墩古城遗址保护规划。

二、对该规划提出以下修改意见：

（一）加强考古调查和研究工作，进一步明确城址的分布范围、结构布局和城内遗存情况，为科学编制规划提供依据。

（二）结合考古工作成果科学调整保护区划，根据环壕位置适当扩大保护范围，建设控制地带边界可依据规划道路边界适当外扩。

（三）加强保护措施的针对性，完善专项规划内容。环境整治措施应与各类建设控制地带的控制要求相对应；展示规划应加强水磨河展示内容；进一步明确城址外西北角的土墩性质，慎重考虑停车场等配套设施建设选址。

（四）进一步规范图文表达，校核图纸。

三、请你局指导规划编制单位联合专业考古研究单位，根据上述意见进一步修改和完善唐朝墩古城遗址保护规划后，按程序另行报批。

国家文物局办公室

2018年4月11日
