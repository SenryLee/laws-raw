# 中国气象局办公室关于转发《2018年全民科学素质行动工作要点》的通知

气办函〔2018〕88号

各省（区、市）气象局，各直属单位，各内设机构：

近日，全民科学素质纲要实施工作办公室印发了《2018年全民科学素质行动工作要点》（纲要办发〔2018〕3号），明确了2018年全民科学素质工作重点任务，请各单位结合实际认真贯彻落实，以实施《全民科学素质行动计划纲要（2006—2020年）》为契机，有效提升公民气象科学素养，为建设创新型国家和世界气象强国筑牢基础。有关要求如下：

一、深刻领会提升全民科学素质的重要意义，提高对气象科普工作重要性的认识

认真贯彻落实习近平新时代中国特色社会主义思想和党的十九大精神，深刻领会习近平总书记关于“科技创新、科学普及是实现创新发展的两翼，要把科学普及放在与科技创新同等重要的位置”的重要指示，在新时代气象现代化建设和全民科学素质行动总体布局中，准确把握气象科普工作的时代需求和现实意义。切实把气象科普工作由“软任务”变成“硬措施”，协同推进气象科技创新和气象科普“一体两翼”均衡发展。

二、完善气象科普管理机制，提升气象科普工作水平

充分利用国家和省级全民科学素质纲要办公室“大联合、大协作”的工作机制，构建“政府推动，部门协作，社会参与”的气象科普工作社会化格局，推进气象科普深度融入地方全民科学素质行动，全面融入服务地方经济发展大局。强化气象科技创新、重大气象服务、重大业务建设成果的科普化应用。加强气象科普工作目标考核管理，提升各级业务、科研单位从事科普工作积极性。加强气象科普培训工作，引导和鼓励广大科技工作者积极投身气象科普事业。完善多元投入机制，强化财政资金保障，引导和鼓励社会机构、企业、个人通过众筹众包、项目共建、捐款捐赠、政府购买服务等多种方式参与气象科普事业，推动气象科普传播现代化、科普时空全域化、科普资源社会化发展。

三、创新气象科普载体，提高气象科普服务质量效益

加强气象科普基础设施建设与管理，提高各类气象科普教育基地建设效益。以国家气象公园建设为抓手打造科普新阵地，着力在科普小镇和特色小镇打造气象科普品牌，推动气象元素融入科普中国乡村e站、社区e站等建设。面向广大青少年、农民、城镇劳动者、领导干部和公务员、部队官兵等重点人群，有针对性地开展气象科普活动，强化对革命老区、民族地区、边疆地区、集中连片贫困地区等薄弱地区的气象科普精准帮扶。发挥世界气象日、气象科技活动周等重要活动品牌带动作用，持续开展同行凝聚、跨界合作的气象科普示范活动。提高气象科普研发创作能力和科学传播水平，实施“互联网+科普”行动，促进优质科技与科普资源开放共享，提升气象科普产品、科普服务的精准、有效供给能力和信息化水平。
