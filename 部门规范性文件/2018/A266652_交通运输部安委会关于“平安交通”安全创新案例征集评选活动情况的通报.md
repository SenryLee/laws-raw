# 交通运输部安委会关于“平安交通”安全创新案例征集评选活动情况的通报

交安委〔2018〕3号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），中国远洋海运、招商局、中交建设集团，部海事局、救捞局，长江、珠江航务管理局，中国船级社，部科学研究院，人民交通出版社，中国交通企业管理协会：

为贯彻落实习近平总书记关于安全生产的重要指示，深入推进交通运输安全生产领域改革发展，全力推动行业安全生产改革创新，宣传推广行业好的经验、做法、成果，结合今年“安全生产月”活动，部安委办在全国范围内开展了“平安交通”安全创新案例征集活动，广泛征集行业在安全管理、科技兴安、安全文化等方面自主创新、务实管用、成效显著的典型案例。经各单位报送推荐和专家评选，共选出“特别推荐”案例15个，“重点推荐”案例40个，“优秀案例”80个（详见附件）。现将相关情况通报如下：

一、总体情况

本次安全创新案例征集为我部近十年来首次举办，部安委办组织北京市交通委员会、中国船级社、部科学研究院、人民交通出版社、中国交通企业管理协会等单位共同筹办。各地交通运输管理部门、行业央企、部属有关单位积极响应、主动参与、周密组织、加强指导，共申报各类案例325个，其中安全管理类216个、科技兴安类95个、安全文化类14个。为做好案例遴选工作，部安委办组织由行业管理部门、科研院所、协会组织、新闻出版、第三方服务机构等方面专家12名，按照创新性、实操性、实效性、可推广性等因素对案例进行交叉评分。经专家评分和推荐，共评选出135个优秀案例，其中安全管理类103个、科技兴安类25个、安全文化类7个，这些案例在不同方面、不同程度呈现出创新亮点，体现改革创新理念在行业得到了充分发展，也为行业“科技兴安”战略的实施形成良好基础。

二、案例亮点

本次各单位报送案例立足于实际安全管理需求，涵盖了行业与企业、监管与自查、人员与环境、科技与文化等多个方面，主要呈现出以下四个亮点。

一是科技创新与应用的新举措、好做法多。报送的325个案例中科技兴安类有95个，占比29.2%；评选出的135个案例中科技兴安类有25个，占比18.5%。行业对新科技的研发与应用积极性高，尤其是行业重点领域安全生产的信息化创新与应用快速发展，与企业生产经营各环节日趋融合，发挥的关键管控效果逐渐显现。如船舶安全监督选船系统（上海海事）、船舶监控智能语音提醒系统（河北海事）、道路运输企业安全生产管理系统（中交企协）等案例创新性强，通过信息化手段实现全过程、全方位的安全监管，有利于提升安全管理水平。

二是基层有实效、有创新的案例多。申报案例中超过50%的案例是基层部门和人员在工作中不断总结经验、改进提升中形成的，为解决安全生产领域一些顽症痼疾提供了很好借鉴。如12345科学安全监管体系（长航局）、道路危货运输企业联合联盟安全管理模式（重庆）、新型公交车安全逃逸系统（广东）、营运车辆防碰撞技术问题研究（河南）等案例立足基层安全管理实际，创新了基层单位安全管理模式。

三是行业首创性、全新性的案例多。本次案例展示了行业企业主动作为、敢于担当的精神，不拘泥于过去的老思维、旧方法，而是积极探索行之有效的新方式、新手段。如京津冀综合交通保障应急联动机制（北京）立足于京津冀协同发展和冬奥会大背景，采用桌面演练与实战演练相结合方式进行京津冀地区暴雪巨灾天气交通保障应急联动；交通运输行业安全生产千分制评价（北京）基于企业安全生产标准化建设指标，优化完善形成千分制评价体系对行业安全生产现状进行全方位量化，实施“全面体检”；构建安全巡查长效机制（天津）实现了对交通运输管理部门、委直属单位、行业市属集团公司和中央驻津企业的全面覆盖，均对推动行业安全生产水平提升具有重要借鉴意义。

四是行业可推广、可复制的案例多。大部分案例在行业相关领域具有较强的可推广、可复制性，进一步优化完善后广泛推广应用，可有效提升企业落实安全生产主体责任能力，强化安全监管执法效果，提升行业安全生产水平。如交通运输隐患排查治理体系研究（湖南）、以“互联网+安全+保险”为核心的道路运输第三方安全监测服务平台项目（辽宁）、基于流动机械信息化的车联网（中交集团）、典型海事案例在促进水上交通安全中的应用（部海事）、企业安全教育服务监管平台（安徽）等都已实地应用，案例效果较明显，操作性强，将互联网与安全管理有效结合，具有较高的使用和推广价值。

三、有关工作要求

一是高度重视，强化组织领导。各部门各单位要充分认识科技创新对引领行业安全发展的重要作用，高度重视安全创新工作，出台有关政策措施积极引导、鼓励、支持行业企业、科研单位、第三方案机构开展有关创新以及研发应用工作，并做好部安委办组织的安全创新案例征集相关工作。部安委办也将出台有关制度和措施，定期开展全国范围的安全创新案例征集评选活动，使典型案例评选、推广工作成为提升交通行业安全生产水平的有效手段。

二是广泛宣传，强化典型表彰。为充分鼓励引导行业创新，营造安全发展良好氛围，各部门各单位应对“特别推荐、重点推荐、优秀案例”三个档次案例尤其是本单位入选的案例和成果进行表彰，充分运用报刊、网络、展览、培训、业务交流等多种平台和方式强化宣传，营造敢创新、学先进、破难题、强安全的“科技兴安”氛围，鼓励引导行业涌现更多更好的各类安全创新案例。部安委办将对本次入选案例集结出版，由人民交通出版社负责具体出版工作（联系人：屈闻聪010-85285852，85285972）。

三是深度利用，强化推广应用。为进一步发挥行业智慧和科技创新的关键作用，各部门各单位应结合科技兴安工作，对入选案例予以重点关注，对基础好、效果好、前景好的优秀案例要鼓励引导有关力量进行深度挖掘，进一步优化完善，凝行业智慧、聚社会资源，切实推动利用科技手段和先进管理方式，解决安全生产顽症痼疾。要注重先进经验做法和科技装备手段的推广应用，切实提升行业安全生产风险管控能力和隐患治理水平，有效遏制安全生产重特大事故发生，为行业安全发展和交通强国建设发挥更大作用。
