# 国家文物局办公室关于司马迁墓和祠古道保护维修项目的意见

办保函〔2018〕539号

陕西省文物局：

你局《关于上报司马迁墓和祠古道保护维修工程设计方案的请示》（陕文物字〔2018〕31号）收悉。经研究，我局意见如下：

一、所报方案拟在古道上建设木栈道，对古道本体会产生直接影响，并改变了古道的整体外观，必要性不足，我局不同意该方案。

二、应基于现状对古道本体进行必要的保护修缮，如，以恰当材料和工艺填塞凹坑及流失灰缝，以改善其排水情况；对部分保存状况较差的石材考虑以牺牲层进行表面防护，定期保养维护等。填充材料和牺牲层强度不得高于原石材，但不宜用素土，同时应做好色彩样板比选和施工工艺控制。如有必要，可编制专项方案另行报批。

三、请你局指导有关单位，按照上述意见和《古建筑保养维护规程》，做好对司马迁墓和祠古道的日常保养维护工作，确保文物安全。

特此函复。

国家文物局办公室

2018年6月1日
