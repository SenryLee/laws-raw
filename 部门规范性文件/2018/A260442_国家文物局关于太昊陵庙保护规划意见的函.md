# 国家文物局关于太昊陵庙保护规划意见的函

文物保函〔2018〕55号

河南省文物局：

你局《关于再次报批淮阳县太昊陵庙保护规划的请示》（豫文物〔2017〕106号）收悉。经研究，我局意见如下：

一、原则同意所报太昊陵庙保护规划。

二、对该规划提出以下修改意见：

（一）加强太昊陵庙与城市历史格局关系的研究，全面、客观评估历史环境；完善对太昊陵庙庙墙范围内建设项目的评估内容，明确评估结论；深入评估水害、病害等对文物本体的影响；补充历次修缮工程实施情况及效果评估。在客观评估的基础上，进一步加强保护措施的针对性，防止过度维修。

（二）完善环境整治措施，明确提出不协调建筑的整治措施，以及太昊陵庙东侧商业地块建设活动的控制要求，保护整体历史格局。加强庙会等大型集会活动的游客量预测和管理控制，针对重大节日活动提出安消防措施，确保文物及人员安全。

（三）补充考古调查和研究相关章节，研究太昊陵庙历史格局演变，进一步分析庙墙、古水系以及各建筑遗址之间的关系。

（四）加强本规划与相关规划的衔接。进一步完善、精炼文本，规范图纸表达。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的太昊陵庙保护规划报请河南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好太昊陵庙的各项保护、管理工作，妥善解决土地用途调整、环境整治等涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2018年1月18日
