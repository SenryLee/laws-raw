# 国家粮食和物资储备局关于在河南省启动2018年小麦最低收购价执行预案的通知

国粮发〔2018〕137号

中国储备粮管理集团有限公司：

你公司《关于河南省启动2018年小麦最低收购价执行预案的请示》（中储粮〔2018〕144号）收悉。根据国家发展改革委、国家粮食和物资储备局等部门《关于印发小麦和稻谷最低收购价执行预案的通知》（国粮发〔2018〕99号）有关规定，经研究，同意自6月13日起在河南省内符合条件的相关地区启动2018年小麦最低收购价执行预案。

国家粮食和物资储备局

2018年6月12日
