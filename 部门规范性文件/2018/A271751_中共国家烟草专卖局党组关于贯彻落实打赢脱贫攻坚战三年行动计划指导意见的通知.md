# 中共国家烟草专卖局党组关于贯彻落实打赢脱贫攻坚战三年行动计划指导意见的通知

国烟党〔2018〕212号

行业各直属单位，国家局、总公司机关各部门、各单位：

党的十八大以来，以习近平同志为核心的党中央把脱贫攻坚工作纳入“五位一体”总体布局和“四个全面”战略布局，作为实现第一个百年奋斗目标的重点任务，并作出一系列重大部署和安排，全面打响脱贫攻坚战。党的十九大明确把精准脱贫作为全面建成小康社会必须打好的三大攻坚战之一，作出了新的部署。近期，中央印发《关于打赢脱贫攻坚战三年行动的指导意见》，提出了未来三年打赢脱贫攻坚战的总体要求、目标任务和重点工作，要求各单位、各部门切实增加责任感和使命感，采取更有力的行动、更扎实的工作，集中力量攻克贫困的难中之难、坚中之坚，确保2020年贫困地区和贫困群众同全国一道进入全面小康社会。

烟草行业历来高度重视扶贫工作。积极参与脱贫攻坚工作是认真贯彻落实党中央、国务院决策部署的要求，是发挥行业优势和履行政治责任的要求，是践行“国家利益至上、消费者利益至上”行业共同价值观的有力举措，是树立“责任烟草”良好形象的重要抓手。目前距离2020年全面建成小康社会还有不到三年的时间，作为全面建成小康社会的底线任务和标志性指标，行业各单位要深刻认识打好打赢脱贫攻坚战的重大政治和现实意义，切实把思想和行动统一到党中央、国务院的决策部署上来。为进一步统一思想、提高站位、明确责任，现就烟草行业贯彻落实打赢脱贫攻坚战三年行动计划提出以下要求。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻落实习近平总书记关于扶贫工作的重要论述，增强“四个意识”，坚定“四个自信”，做到“两个维护”，坚持精准扶贫精准脱贫基本方略，充分发挥烟草行业体制优势，进一步加强领导、强化担当，对标对表、把准方向，改进作风、真抓实干，确保党中央、国务院关于打赢脱贫攻坚战三年行动计划的各项决策部署在烟草行业落地生根，谱写新时代烟草行业助力脱贫攻坚的新篇章。

二、工作目标

行业各单位要在国家局党组和地方党委政府的领导下，全面支持、主动作为、积极参与到打赢脱贫攻坚战三年行动中去。以更加有为的政治担当、更加扎实的工作作风、更加昂扬的精神状态，充分发挥行业优势，创新工作方法，尽职尽责，做到扶贫政策宣传到位、群众工作落实到位、扶贫项目支持到位、资金使用监管到位、产业带动跟进到位、党建扶贫引领到位，确保烟草行业各单位帮扶的贫困地区和贫困人口三年如期完成脱贫攻坚目标任务，与全国人民一道进入全面小康社会。

三、工作要求

（一）提高政治站位，加强组织领导。

行业各单位要深入学习习近平总书记关于扶贫工作的重要论述，全面领会打赢脱贫攻坚战三年行动的总体要求，进一步统一思想认识，提高政治站位，坚持真心实意扶真贫、真扶贫，坚决助力打赢脱贫攻坚战。各级党组织要加强对扶贫工作的组织领导，把扶贫工作摆上重要议事议程。主要领导是第一责任人，要建立完善工作机制，研究制定工作计划，出台实施真正管用的工作措施。

（二）聚焦精准施策，务求取得实效。

行业各单位要全力支持、密切配合地方党委政府的脱贫攻坚工作，充分发挥烟草体制优势，按照精准施策的原则，研究制定针对性的产业扶贫措施和公益扶持项目，切实完成好地方党委政府交付的扶贫工作任务。要进一步加大对西藏、四省藏区、南疆四地州和四川凉山州、云南怒江州、甘肃临夏州等深度贫困地区的支持力度，有对口支持任务的单位，要确保扶贫项目及时安排到位，扶贫资金及时拨付到位，挂职干部及时派驻到位。对于四川凉山等具备烟草产业基础的深度贫困地区，行业各有关单位要出台扶持政策，充分发挥产业支撑作用。继续落实好行业援藏、援疆以及整族帮扶等一系列重要工作举措，务求取得实效。

（三）继续做好烟农增收工作。

烟叶产业发展要服务脱贫攻坚大局，紧盯“两不愁、三保障”目标，聚焦贫困烟区、贫困烟农，坚持以产业扶贫为突破口，并通过发展多元增收产业激发贫困人口内生动力，带动贫困烟区加快发展。行业各单位要保持贫困地区烟叶计划相对稳定，种植计划向贫困烟农适当倾斜，持续做好烟农增收工作。同时要按照国家局党组要求，进一步加大精准帮扶力度，以2017年烟叶种植计划面积为基数，按照国务院《“十三五”脱贫攻坚规划》确定的贫困县范围，对贫困县烟农减少的种植面积，由烟草行业每亩补助400元，用于烟农调整产业结构，降低因计划减少给烟农带来的损失，巩固脱贫成果。

（四）扎实推进国家局机关定点扶贫工作。

加强国家局党组对扶贫工作的领导。调整充实扶贫工作领导小组，由国家局党组主要负责同志担任领导小组组长，补充机关党建部门和廉政部门主要负责同志为领导小组成员。

推进宁夏红寺堡区精准扶贫项目落地生效，促进弘德包装印刷材料厂提质增效；继续加大对湖北竹山、竹溪两县烟叶生产扶持力度，稳定两县烟叶种植规模，助力烟农增收。充分发掘消费扶贫潜力，发挥烟草行业流通领域和直营店优势，定期举办定点扶贫地区农特产品产销衔接会，鼓励行业各单位定向采购国家局定点扶贫地区农特产品。

继续加大对定点扶贫地区资金支持力度。从2018年开始，竹山、竹溪两县年度扶贫资金各增加500万元至每年各2500万元，红寺堡区年度扶贫资金增加500万元至每年2000万元。

积极探索“党建+扶贫”的扶贫新模式。安排国家局、总公司机关有关部门党支部在定点扶贫地区范围内分别确定1个贫困村作为对口帮扶单位，组织开展支部联学联建活动；国家局机关党委利用返还党费加大对定点扶贫地区的资金支持力度， 在定点扶贫地区范围内选取30个左右符合补助条件的贫困村，按照每村每年10万元的标准，连续补助3年，用于建设基层党组织活动场所或支持空壳村发展集体经济。

加大督促检查力度。以《国家烟草专卖局定点扶贫县脱贫攻坚督促检查工作实施办法》（国烟计〔2018〕139号）出台为契机，全面开展督导工作，督促地方党委、政府落实脱贫攻坚主体责任。

（五）加强扶贫干部管理，切实改进作风。

要按照《国务院扶贫开发领导小组关于开展扶贫领域作风问题专项治理的通知》（国开发〔2017〕10号）要求，加强扶贫领域作风建设，切实督促扶贫干部进一步转变工作作风。注重在脱贫攻坚一线培养和锻炼干部，加大对扶贫干部的培训力度，关心扶贫干部的成长，改善扶贫干部的工作条件。各级党组织要建立走访慰问制度，定期深入到各自负责扶贫地区开展调研督导，走访慰问挂职干部。

行业各单位要在以习近平同志为核心的党中央坚强领导下，深入贯彻落实党的十九大精神和习近平总书记关于扶贫工作的重要论述，齐心协力、团结一致，牢记使命、攻坚克难，助力打赢脱贫攻坚战三年行动计划各项目标任务如期圆满完成。
