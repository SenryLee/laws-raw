# 中华人民共和国财政部公告2018年第54号——决定第二次续发行2018年记账式附息（五期）国债的公告

## 中华人民共和国财政部公告

2018年第54号

根据国家国债发行的有关规定，财政部决定第二次续发行2018年记账式附息（五期）国债，已完成招标工作。现将有关事项公告如下：

一、本次国债计划续发行410亿元，实际续发行面值金额410亿元。

二、本次续发行国债的起息时间、票面利率等要素均与2018年记账式附息（五期）国债相同，即起息日为2018年3月8日，票面年利率为3.77%；按年付息，每年3月8日（节假日顺延，下同）支付利息，2025年3月8日偿还本金并支付最后一次利息。经招标确定的续发行价格为101.42元，折合年收益率为3.63%。本次续发行的国债从招标结束后至2018年5月3日进行分销，从5月7日起与之前发行的同期国债655.9亿元合并上市交易。

其他事宜按《中华人民共和国财政部公告》（2018年第2号）规定执行。

特此公告。

中华人民共和国财政部

2018年5月2日
