# 农业农村部办公厅关于公布中国-联合国粮农组织南南合作特别贡献机构和个人评选结果的通知

农外办〔2018〕14号

我国自1996年起参与联合国粮农组织（以下简称“FAO”）框架下的农业南南合作，先后向28个发展中国家派出了近1100名农业专家。在相关单位及人员的支持下，我国专家坚持真实亲诚理念，扎根海外一线，艰苦奋斗、无私奉献，用中国理念和技术带动当地农业发展，赢得了国际社会的广泛赞誉，实现了“民心相通”，为推动构建人类命运共同体做出了积极贡献。

根据我国与FAO签署的有关协定，为肯定和鼓励对南南合作项目做出突出贡献的机构与个人，我部与FAO共同组织了南南合作特别贡献机构和个人评选活动。按照工作作风、业务绩效、奖惩情况等评选条件，经相关单位推荐，共评选出10家南南合作特别贡献机构和35位个人（名单附后）。相关证书已由我部韩长赋部长和FAO总干事联名签署。

请各单位以适当形式和活动做好通报工作，积极开展事迹宣传，做好典型推广，形成示范效应，营造良好氛围，继续采取切实措施，推动新时期农业南南合作事业取得更大成效。

2. 南南合作特别贡献个人名单
