# 国家文物局办公室关于北京市密云区古北口卧虎山段长城修缮加固工程方案的意见

办保函〔2018〕99号

北京市文物局：

你局《关于密云区古北口卧虎山段长城（304号敌楼、347号敌台、348号敌楼-351号敌楼）抢险加固工程方案的请示》（京文物〔2017〕831号）收悉。经研究，我局意见如下：

一、所报方案前期勘察不足，病害分析不够全面、准确，工程性质和规模不明确，保护措施的必要性和可行性论述不足,缺乏具体做法和图纸表达，且图文矛盾。我局暂不同意所报方案。

二、该项目应做好以下工作：

（一）应深化现状勘察，核实修缮对象的原始形制、材质、做法及工艺，分段、分类详细描述文物本体的残损现状，进一步分析本体病害类型、成因和发展趋势，为方案设计提供可靠依据。

（二）应以现状修缮为主，坚持最小干预原则，严格控制工程范围和工程量，有效控制或减缓残损状况发展。暂不同意完全恢复中层地面、墙面、券洞、雉堞、衬墙等工程内容。

（三）进一步完善墙体衬砖补砌、地面整修、券洞加固补强的具体做法和内容，并分析钢构件加固的必要性，补充做法说明和设计图纸。暂不同意以钢构件加固304号敌楼，建议进一步评估病害发展趋势，另行制定保护措施。

（四）完善文本和图纸，做到文本、照片和图纸等内容统一。补充相关敌台、敌楼除顶面外其他部位的设计内容。

三、请你局根据上述意见及我局《文物保护工程设计文件编制深度要求》和《长城保护维修工作指导意见》指导完善密云区古北口卧虎山段长城304号敌楼（长城认定编码：110228352101170349）、347号敌台（长城认定编码：110228352101170395）、348号敌台（长城认定编码：110228352101170396）、349号敌台（长城认定编码：110228352101170397）、350号敌台（长城认定编码：110228352101170398）、351号敌台（长城认定编码：110228352101170399）修缮加固项目方案，按要求履行审批程序。
