# 交通运输部办公厅关于举办全国交通运输行业道路货物运输驾驶员职业技能竞赛的通知

交办人教函〔2018〕1106号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

为进一步加强交通运输高技能人才队伍建设，提高道路货物运输驾驶员业务技能水平，弘扬工匠精神，营造良好从业环境，部决定举办全国交通运输行业道路货物运输驾驶员职业技能竞赛。经交通运输部同意，现将有关事项通知如下：

一、组织机构

本届竞赛由交通运输部主办，为交通运输行业类竞赛。竞赛组建全国交通运输行业道路货物运输驾驶员职业技能竞赛组织委员会（以下简称组委会，成员名单见附件1），负责竞赛组织领导工作。部职业资格中心、中国交通报社、中国汽车保修设备行业协会为承办单位，东方时尚驾驶学校股份有限公司、世达工具（上海）有限公司、北京福田戴姆勒汽车有限公司、北京宣爱智能模拟技术股份有限公司等企业为协办单位。

组委会秘书处（成员名单见附件2）设在部职业资格中心，负责竞赛具体实施工作，组织技术专家制定竞赛技术方案、评分标准及相关竞赛技术性文件等。

二、竞赛主题

安全、绿色、高效。

三、组织形式

分预赛和全国总决赛两个阶段。预赛由各省级交通运输主管部门，按照本通知及技术方案组织实施。全国总决赛由主办单位组织实施，决赛具体事项另行通知。

四、竞赛内容

竞赛内容分为理论知识竞赛和技能操作竞赛两部分。其中，理论知识占30%，技能操作占70%。具体竞赛内容和评判标准详见竞赛技术方案（另行发布）。

五、参赛报名条件及要求

（一）以道路货物运输为主要经济来源的营运性道路货物运输驾驶员；

（二）持有《中华人民共和国机动车驾驶证》（准驾车型A2）和《中华人民共和国道路运输从业人员从业资格证》（2017年12月31日以前核发）；

（三）具有较强的安全责任意识和熟练的驾驶技能，近3年内无重大以上交通责任事故；

（四）近3年诚信考核等级均达到AA级以上；

（五）参赛选手报名时还需提供以下材料：

1.《参赛选手报名表》（见附件3）；

2.身份证复印件；

3.驾驶证复印件；

4.从业资格证复印件；

5.道路交通安全主管部门出具的3年内无重大以上交通责任事故记录证明；

6.诚信考核证明。

六、奖项设置

（一）个人奖项。

1.参加全国总决赛的前20名优胜选手，由部授予“全国交通技术能手”称号；

2.全国总决赛评出一等奖1名，二等奖4名，三等奖5名，由竞赛组委会颁发获奖证书；

3.参加全国总决赛的所有选手由竞赛组委会颁发荣誉证书。

（二）团体奖项。

1.授予参加全国总决赛团体成绩前10名的单位团体奖；

2.授予全国总决赛组织工作出色的单位优秀组织奖；

3.授予竞赛承办和协办单位等突出贡献奖。

七、时间安排

（一）2018年7月，印发竞赛通知、技术方案；

（二）7—9月，有关单位举办预赛或选拔赛；

（三）10—11月，组织全国总决赛及闭幕式；

（四）12月，印发竞赛表彰决定等。

八、其他事项

（一）请各有关单位加强组织领导，精心策划，广泛宣传，积极开展职业技能培训和赛前训练，鼓励和支持从业人员参赛。要通过竞赛促培训、促学习、促交流，带动和激励广大技能人员爱岗敬业、苦练技能、精益求精，营造人人争当技术能手的良好氛围。

（二）请于7月31日前将负责竞赛工作的部门、联系人及联系方式报竞赛组委会秘书处。

（三）举办预赛的有关单位请于8月20前将预赛计划报竞赛组委会秘书处。各地预赛须在9月30日前完成，并做好参加全国总决赛的准备工作。

（四）竞赛组委会秘书处联系方式：
