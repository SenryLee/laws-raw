# 国家文物局办公室关于建新遗址保护规划的意见

办保函〔2018〕273号

山东省文物局：

你局《关于呈报〈建新遗址保护规划〉的请示》（鲁文发〔2017〕77号）收悉。经研究，我局意见如下：

一、暂不同意建新遗址保护规划。

二、对该规划提出以下修改意见：

（一）进一步加强考古研究，系统梳理已有考古工作成果，明确遗址分布范围、文物构成和保护对象等，客观评价建新遗址在山东地区大汶口文化中的重要意义，归纳、总结影响遗址安全的主要因素，为规划编制提供依据。

（二）应进一步论证枣木高速与245 省道穿越区域的保护管理强度，综合考虑遗址分布范围、保护管理和村镇建设发展需要，合理确定保护区划，适当缩小保护范围北部和西部边界，增强可操作性。补充建设控制地带的建筑密度、人口数量调控等要求。

（三）应针对文物病害情况，科学研提保护措施和具体保护项目，论证保护范围内清理深根植物的必要性和可行性，调整植被清理和固土措施；后伏村基础设施建设、道路整治、河道环境整治、防治水土流失等不属于文物保护措施，应纳入相应专项规划。

（四）完善专项规划内容，综合考虑建新遗址的展示利用定位，合理确定展示方式、功能分区、展示服务设施建设等，科学展现建新遗址的历史文化价值，并做好与相关规划的衔接。

（五）进一步梳理、完善文本，规范图文表达，减少错漏。

三、请你局指导规划编制单位联合专业考古研究单位，根据上述意见进一步修改和完善建新遗址保护规划后，按程序另行报批。

国家文物局办公室

2018年3月30日
