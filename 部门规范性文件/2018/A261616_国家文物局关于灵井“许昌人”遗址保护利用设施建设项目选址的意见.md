# 国家文物局关于灵井“许昌人”遗址保护利用设施建设项目选址的意见

文物保函〔2018〕154号

河南省文物局：

你局《关于报批灵井“许昌人”遗址保护利用设施建设项目设计方案的请示》（豫文物〔2017〕369号）收悉。经研究，我局意见如下：

一、原则同意灵井“许昌人”遗址保护利用设施建设项目涉及全国重点文物保护单位灵井“许昌人”遗址保护范围的选址方案。

二、该项目应进一步明确覆土保护、地面标识及遗址周边排水、降水、防渗措施，严格控制拟建建筑体量和外立面材料，注意与遗址及其周边环境风貌相协调。应细化展示设施内部功能设置，采用灵活、多样的展示方式，重点阐释“许昌人”在中国旧石器考古研究中的地位和意义，注意展示的科普性和教育性。同时，加强施工过程管理，确保文物安全。

三、请你局组织专业考古研究单位，在项目拟建区域进一步开展必要的考古调查和发掘工作。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

四、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，按照《中华人民共和国文物保护法》第十七条的规定，报河南省人民政府批准。

五、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促工程部门切实做好施工过程中的文物保护工作，确保文物安全。

国家文物局

2018年2月8日
