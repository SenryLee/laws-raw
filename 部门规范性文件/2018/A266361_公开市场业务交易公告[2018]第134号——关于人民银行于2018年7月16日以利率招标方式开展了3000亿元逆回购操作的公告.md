# 公开市场业务交易公告[2018]第134号——关于人民银行于2018年7月16日以利率招标方式开展了3000亿元逆回购操作的公告

## 公开市场业务交易公告

[2018]第134号

为对冲税期高峰、政府债券发行缴款和金融机构缴存法定存款准备金等因素的影响，维护银行体系流动性合理充裕，人民银行于2018年7月16日以利率招标方式开展了3000亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 1700亿元 | 2.55% |
| 14天 | 1300亿元 | 2.70% |

中国人民银行公开市场业务操作室

二〇一八年七月十六日
