# 住房城乡建设部办公厅关于杨晓瑞申报勘察设计注册工程师注册弄虚作假行为的通报

建办市函〔2018〕119号

各省、自治区住房城乡建设厅，北京市规划国土委，天津、上海、重庆市建委：

经查，杨晓瑞在申报勘察设计注册工程师注册过程中，存在提供虚假材料申请注册的违规行为。为加强注册执业管理，根据《勘察设计注册工程师管理规定》（建设部令第137号）的有关规定，现对杨晓瑞给予通报批评，一年内不受理其注册申请，并将其不良行为在全国建筑市场监管公共服务平台上予以公布，记入信用档案。

附件：弄虚作假申报勘察设计注册工程师注册人员名单

中华人民共和国住房和城乡建设部办公厅

2018年3月5日
