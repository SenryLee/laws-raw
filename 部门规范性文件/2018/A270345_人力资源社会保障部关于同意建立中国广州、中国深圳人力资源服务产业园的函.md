# 人力资源社会保障部关于同意建立中国广州、中国深圳人力资源服务产业园的函

人社部函〔2018〕131号

广东省人民政府：

《广东省人民政府关于商请支持设立中国广州、中国深圳人力资源服务产业园的函》（粤府函〔2018〕86号）收悉。经研究，同意在广东省广州市建立国家级人力资源服务产业园，名称定为“中国广州人力资源服务产业园”，规划为“一江两岸、双核驱动、多点支撑”，围绕广州珠江两岸打造人力资源服务业商圈，以天河人才港和琶洲互联网创新人才集聚区为双核，番禺青年人才创新创业服务园区、广州开发区海外高层次人才服务园区、南沙粤港澳人才合作示范园区、越秀现代服务业人才服务园区、花都临空产业人才服务园区为多点支撑。同意在广东省深圳市建立国家级人力资源服务产业园，名称定为 “中国深圳人力资源服务产业园”，规划为“一园四区、多点支撑”，以深圳人才园、龙岗区天安云谷智慧广场、南山区深圳湾科技生态园、宝安区人才园为核心园区，前海国际人力资源服务产业园、罗湖区粤港澳大湾区人才创新园为支撑园区。

中国广州、中国深圳人力资源服务产业园建设工作应认真贯彻党的十九大关于在人力资本服务领域培育新增长点、形成新动能的精神，落实国家关于加快发展现代服务业和人力资源服务业的要求，按照人力资源和社会保障事业发展总体部署，围绕更好服务就业优先战略和人才强国战略，坚持发挥市场在资源配置中的决定性作用和更好发挥政府作用，促进人力资源服务业健康快速发展。

中国广州、中国深圳人力资源服务产业园建设要立足服务华南、辐射港澳，加快建设粤港澳大湾区人才高地。要充分调动各方面积极性，完善政策体系，强化管理服务，加强政策、人才、资金、信息等方面的支持，确保产业园建设不断取得成效，在服务广东省乃至全国经济社会发展、促进就业创业和优化人才配置中发挥重要作用。

产业园建设和发展的有关情况，请及时向我部报告。

人力资源社会保障部

2018年10月17日
