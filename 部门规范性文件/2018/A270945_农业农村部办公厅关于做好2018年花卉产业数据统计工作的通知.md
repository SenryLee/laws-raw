# 农业农村部办公厅关于做好2018年花卉产业数据统计工作的通知

农办农〔2018〕20号

各有关省、自治区、直辖市农业（农业农村、农牧、农村经济）厅（委、局），北京市园林绿化局、福建省林业厅、广西壮族自治区林业厅、海南省林业厅、宁夏回族自治区林业厅：

为做好2018年全国花卉产业统计工作，现就有关事项通知如下。

一、 填报花卉产业统计报表

按照《花卉产业统计报表制度》要求，做好2018年本省（区、市）花卉产销情况、花卉生产经营实体情况、花卉保护地栽培情况、主要花卉产销情况等数据的汇总和整理工作，并通过花卉产业综合统计系统填报相关报表。填报系统的网址为：http://cjkz.agri.gov.cn。

二、 总结2018年花卉产业发展情况

对本省（区、市）2018年花卉产业发展情况进行总结，包括本地区花卉生产的基本情况及特点、主要做法及存在问题、2019年花卉产业发展趋势分析及工作安排等。

三、 有关要求

请于2019年1月20日前完成网络填报，并将有关统计报表及总结文字材料发送到 zzyjzc@agri.gov.cn。

联系人：农业农村部种植业管理司经作处 尚怀国，电话：010—59192895。
