# 国家文物局办公室关于万荣后土庙保护范围和建设控制地带内环境整治项目的意见

办保函〔2018〕139号

山西省文物局：

你局《关于审批万荣后土庙环境整治工程设计方案的请示》（晋文物〔2017〕197号）收悉。经研究，我局意见如下：

一、扫地坛、张仪古道及观景长廊项目位于文物保护范围内，建设依据不足，对文物影响较大，我局不同意以上项目。

二、请你局指导当地人民政府按照《国家文物局关于万荣后土庙保护规划意见的函》（文物保函〔2017〕1952号）的要求，抓紧修改完善万荣后土庙保护规划，报请山西省人民政府公布实施。万荣后土庙环境整治的范围、对象、措施以及展示利用项目应以公布的保护规划为依据。

三、请你局指导地方人民政府正确处理文物保护与旅游开发的关系，相关新建项目应尽可能避让文物保护范围，同时调整展示方式，妥善做好万荣后土庙保护、管理工作，切实保护文物安全。

国家文物局办公室

2018年2月23日
