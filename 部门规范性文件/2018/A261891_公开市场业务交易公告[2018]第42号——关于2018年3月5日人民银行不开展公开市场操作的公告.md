# 公开市场业务交易公告[2018]第42号——关于2018年3月5日人民银行不开展公开市场操作的公告

## 公开市场业务交易公告

[2018]第42号

考虑到金融机构法定存款准备金退缴和地方国库现金管理操作可对冲央行逆回购到期等因素的影响，为维护银行体系流动性合理稳定，2018年3月5日人民银行不开展公开市场操作。

中国人民银行公开市场业务操作室

二〇一八年三月五日
