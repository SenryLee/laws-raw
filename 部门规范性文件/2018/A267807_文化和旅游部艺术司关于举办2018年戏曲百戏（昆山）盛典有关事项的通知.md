# 文化和旅游部艺术司关于举办2018年戏曲百戏（昆山）盛典有关事项的通知

艺戏函〔2018〕67号

各省、自治区、直辖市文化厅（局），新疆生产建设兵团文化广播电视局，国家京剧院：

为充分展示和利用全国地方戏曲剧种普查成果，展现全国348个戏曲剧种的独特魅力，激发戏曲剧种活力和戏曲院团潜力，文化和旅游部艺术司、江苏省文化厅定于2018年10月至12月在江苏省昆山市共同举办戏曲百戏（昆山）盛典。该活动计划连续举办3届，在3年内将全国348个戏曲剧种的经典剧目（折子戏）集中到昆山进行展演。现将有关事项通知如下：

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大和十九届二中、三中全会精神，贯彻落实中办、国办《关于实施中华优秀传统文化传承发展工程的意见》精神，坚持“二为”方向、“双百”方针，坚持创造性转化、创新性发展，坚定文化自信，坚守中华文化立场，坚持以人民为中心的创作导向，传承和弘扬中华优秀传统文化，弘扬社会主义核心价值观，推动戏曲艺术繁荣发展。

二、宗旨、主题

宗旨：戏曲的盛会　百姓的节日

主题：汇中国百戏　展戏曲新颜

三、主、承办单位

主办：文化和旅游部艺术司、江苏省文化厅

承办：昆山市人民政府、苏州市文化广电新闻出版局

四、主要内容

（一）组织剧种经典剧目（折子戏）展演

2018年戏曲百戏（昆山）盛典将组织约120个戏曲剧种到昆山演出。大戏演出1场，折子戏组台（由4-5个剧种组成，每个剧种1个折子戏）演出2场。剧种名单见附件1。

（二）召开主题性专家研讨会

活动期间，召开1次关于戏曲的主题性专家研讨会，探讨戏曲在新时代的传承发展路径及未来蓝图。

（三）筹建戏曲博物馆和“百戏之林”

征集各参演剧种的道具、服装、书刊、音像等物品，筹建戏曲博物馆。邀请各参演单位和嘉宾种植象征本剧种的树木，共建“百戏之林”，设立纪念铭牌。

五、剧目（折子戏）推荐要求

（一）推荐条件

所推荐的剧目（折子戏）必须是该剧种的代表性经典作品，能体现剧种的表演艺术精粹，弘扬社会主义核心价值观。大戏一般时长90分钟左右，折子戏一般时长15分钟左右。

（二）推荐材料

1.《2018年戏曲百戏（昆山）盛典参演剧目（折子戏）推荐表》（附件2）1份；

2.剧目（折子戏）剧本、演出视频各2份，剧种、剧团、剧目（折子戏）、主演介绍及剧照等（除剧本、演出视频外，均为电子版）。

推荐材料由省级文化行政部门汇总提交至昆山市文化广电新闻出版局。截止日期为2018年9月5日（以寄出邮戳为准）。

六、经费安排

参加本次活动人员的交通食宿等费用由参演单位自理，主办单位将统一提供演出场地、承担场租费用，并综合考虑距离远近等因素给予参演单位适当演出补助。

七、工作安排

（一）主办单位将组织专家对推荐的剧目（折子戏）进行审看，排出演出日程，并于2018年9月通知参演单位。

（二）活动期间，主办单位将组织宣传报道，请各参演单位予以配合，共同做好本次活动宣传工作。

（三）活动期间，主办单位将组织对演出进行同步录像，作为资料留存，请各参演单位积极配合。

八、联系方式

推荐材料邮寄地址：江苏省昆山市前进中路409号昆山市文化广电新闻出版局文化艺术科，邮编：215300。
