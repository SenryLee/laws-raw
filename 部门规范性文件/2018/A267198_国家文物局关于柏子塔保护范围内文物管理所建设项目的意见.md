# 国家文物局关于柏子塔保护范围内文物管理所建设项目的意见

文物保函〔2018〕841号

湖北省文物局：

你局《关于呈报柏子塔文物管理所建设项目相关材料的请示》（鄂文物〔2018〕17号）收悉。经研究，我局意见如下：

一、原则同意柏子塔保护范围内文物管理所建设项目和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）应严格遵守湖北省人民政府关于柏子塔保护区划的管理规定和控制要求，严格控制新建建筑的高度、规模和外观样式。应进一步评估周围建设条件，研究将项目选址移出保护范围的可能性，并根据柏子塔文物管理所的实际需求，进一步降低建筑高度，缩减建筑面积。

（二）应补充拟建建筑平面图，并核实建筑面积，避免前后不一。按效果示意图选择合适的外墙和屋面材料，确保拟建建筑与文物本体及周边风貌相协调，外墙面不得采用真石漆。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》有关规定履行相关程序后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局

2018年7月30日
