# 自然资源部办公厅关于启用自然资源部地质灾害防治单位资质管理专用章的通知

自然资办函〔2018〕1663号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中央军委后勤保障部军事设施建设局，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

根据工作安排，“自然资源部地质灾害防治单位资质管理专用章”自印发之日起生效，原“中华人民共和国国土资源部地质灾害危险性评估单位资质管理专用章”“中华人民共和国国土资源部地质灾害治理工程单位资质管理专用章”同时废止。

自然资源部办公厅

2018年12月17日
