# 工业和信息化部办公厅关于2018年第二季度通信建设工程质量监督和安全生产情况的通报

工信厅通信函〔2018〕340号

各省、自治区、直辖市通信管理局，中国电信集团有限公司、中国移动通信集团有限公司、中国联合网络通信集团有限公司、中国铁塔股份有限公司，相关单位：

现将2018年第二季度全国通信建设工程质量和安全生产情况通报如下：

一、基本情况

（一）质量监督情况。本季度共申报质量监督项目52025项，办理竣工验收备案项目28767项（附件1）。通信工程质量监督机构开展工程实体抽查项目1736项，抽查发现问题的项目75项（附件2）。

（二）安全生产情况。本季度发生一起较大生产安全事故。2018年5月16日，山东省邮电工程有限公司在河南省郑州市中牟县承建郑州移动本地传输网骨干线路通信管道光缆布放工程施工时，发生井下中毒事故，造成3名施工人员死亡。目前相关单位正积极配合当地政府开展事故调查及事故处理工作。

二、存在的主要问题

从本季度情况看，抽查发现的问题主要包括：

（一）工程质量问题。一是蓄电池架、光纤配线架未按规范要求进行加固；二是铁塔接地扁钢未按规范要求与铁塔底座法兰盘连接，室外地排地线连接处未按规范要求采取防锈处理；三是光缆与电力电缆交越处未按规范要求采取保护措施；四是管孔未按规范要求进行防火封堵。

（二）相关企业的问题。一是部分电信企业未严格履行基本建设程序，未按规定要求办理工程质量监督申报和竣工验收备案手续，工程合同中未明确安全生产费数额；二是部分设计企业设计文件未对涉及施工安全的重点部位和环节进行说明，未明确防雷接地施工工艺和抗震设防要求，未对基础开挖、塔身吊装作业的安全措施提出要求；三是部分施工企业项目负责人、专职安全生产管理人员未通过相应的安全生产考核，未按规定就有关安全施工的技术要求向作业人员说明，现场施工人员有限空间作业未做到“先通风、再检测、后作业”，施工组织设计未编制安全技术措施和临时用电方案；四是部分监理企业监理实施细则未编制安全监理内容，未督促施工单位对存在的问题及时进行整改，未严格审查施工组织设计中的安全技术措施。

（三）抽检材料和设备的问题。本季度抽查的工程使用的材料和设备中，经检测未达到相关产品质量标准要求的共12批次（附件3）。存在的主要问题包括：一是蝶形光缆单根垂直燃烧试验不符合标准要求；二是阻燃馈线外导体直流电阻不符合标准要求；三是光缆终端盒绝缘电阻、耐电压强度不符合标准要求；四是光缆交接箱光纤活动连接器端面几何尺寸不符合标准要求。

三、2018年第一季度通报问题的整改情况

中国电信集团有限公司要求存在问题的5个省分公司进行整改，14个工程项目及2项材料和设备检测存在的问题均已逐项整改落实，对涉及参建单位内部管理的问题督促其整改落实。对检测存在问题的材料进行清理，对相关供应商暂停其供货并进行违约金处罚，督促其加强产品质量管控。同时，督促施工单位、监理单位加强施工现场安全管理和员工安全生产相关培训教育；要求各单位严格按规定履行建设程序，加大对工程现场的检查力度，深入开展自查和整改，确保通信建设工程质量和安全。

中国移动通信集团有限公司督促存在问题的6个省公司进行整改，12个工程项目及2项材料和设备检测存在的问题已全部整改完成。对检测存在问题的材料和设备，要求供应商严格依据合同约定进行责任追究并督促整改。相关省公司加强质量监督申报管理，依据合同对相关施工单位进行罚款处理，约谈了相关监理单位责任人；要求设计单位规范设计交底内容及设计交底文件审核管理，开展设计交底资料自查；要求施工单位加强施工人员安全培训，规范现场安全行为；要求监理单位履行监理职责。同时，要求公司各单位全面贯彻落实《通信建设工程质量监督管理规定》，并通过强化工程建设标准化和规范化管理、加大材料和设备质量检测力度等方式进一步提升公司工程管理水平。

中国联合网络通信集团有限公司相关部门和省分公司相互配合，逐项目逐环节落实整改责任和整改措施，5个省分公司的5个工程项目及1项材料和设备检测存在的问题已全部整改完成。对通报中存在问题的材料和设备，相关省分公司已暂停采购，要求厂家进行全面整改，并对该厂家在库物资进行全面检测。要求省分公司按要求办理质量监督申报和竣工验收备案手续，严格落实安全生产费的计取和支付。同时，从加强安全生产培训、建立健全隐患排查治理工作机制、部署安全生产大检查等方面巩固治理成果，确保工程质量和施工安全。

四、相关要求

各通信管理局要加强信息化管理，督促电信企业进行质量监督申报和竣工验收备案工作。要强化对工程质量和安全生产的检查，按季度报送实体工程抽查情况，做好问题项目的后续跟踪和督促整改工作。要严格落实生产安全事故报告制度，按要求在2小时内将较大及以上生产安全事故基本情况报部，并按季度定期报送本地区发生的一般生产安全事故情况。

各电信企业要按要求开展质量监督申报和竣工验收备案工作，严格落实工程质量和安全生产管理要求，对通报的问题要认真整改落实，避免同类问题反复发生。从完善制度流程、强化责任落实、加大检查力度等多方面提升工程建设管理水平。要强化对工程中使用材料、设备的到货检测，加强对供货企业的违约失信考核。各电信企业总部应于2018年11月30日前将《2018年第二季度抽查工程项目发现主要问题汇总表》（附件2）和《2018年第二季度抽检材料和设备发现问题汇总表》（附件3）所列问题的整改情况书面报部（信息通信发展司），我部将在下季度通报整改情况。
