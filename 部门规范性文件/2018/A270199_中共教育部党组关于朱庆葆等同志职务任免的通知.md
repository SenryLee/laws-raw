# 中共教育部党组关于朱庆葆等同志职务任免的通知

教党任〔2018〕210号

中共江南大学委员会：

经与中共江苏省委商得一致，2018年9月21日研究决定：

朱庆葆同志任中共江南大学委员会委员、常委、书记；免去朱拓同志的中共江南大学委员会书记、常委，周小浦同志的中共江南大学委员会副书记、常委、纪律检查委员会书记职务。

中共教育部党组

2018年9月30日
