# 农业农村部对十三届全国人大一次会议第1358号建议的答复

## 对十三届全国人大一次会议第1358号建议的答复

农办议〔2018〕280号

沈昌健代表：

您提出的"关于大力培养新型职业农民，助推农村脱贫攻坚的建议"收悉。经商财政部、人力资源社会保障部、教育部，现答复如下。

一、 关于加强新型职业农民政策扶持

近年来，我部积极推动教育培训、规范管理、政策扶持"三位一体"的新型职业农民培育制度建设，通过创设专门政策扶持支持职业农民成长发展。一是对接新型经营主体扶持政策。我部会同有关部门认真贯彻中央要求，积极推动新型职业农民对接新型农业经营主体扶持政策，通过土地流转、产业扶持、财政补贴、金融保险、人才奖励激励等政策措施，鼓励新型职业农民带头创办家庭农场、农民合作社等各类新型农业经营主体，发展多种形式的适度规模经营。二是支持返乡创业。中央高度关注农民工等人员返乡创业工作，先后出台《国务院办公厅关于支持农民工等人员返乡创业的意见》（国办发〔2015〕47号）、《国务院办公厅关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》（国办发〔2016〕84号）等文件，从制度层面就建立多层次多样化的返乡创业格局进行了部署。我部联合有关部门积极推动政策落实，通过建立推进协调机制，举办农村创业创新项目创意大赛，强化农村双创园区（基地）建设，实行就业创业服务、创业培训、职业技能鉴定等政策，营造良好的返乡创业环境。2013—2017年，全国各级财政累计安排资金超过4000亿元，支持各项就业创业扶持政策的落实。三是推进新型职业农民认定管理。2015年，我部印发《关于统筹开展新型职业农民和农村实用人才认定工作的通知》，对生产经营型职业农民进行认定管理和新型职业农民证书发放管理，鼓励专业技能型和专业服务型职业农民参加国家职业技能鉴定，全面推进以新型职业农民为重点的农村实用人才认定管理，将现有扶持政策更加精准地落实到职业农民头上。

下一步，我部将联合有关部门完善新型职业农民扶持政策，加大力度支持返乡创业，积极营造支持新型职业农民健康发展的良好政策环境，吸引、储备更多人才留在乡村、发展农业。

二、关于大力发展农民职业教育培训

我部高度重视农民职业教育工作，近年来多措并举，积极创新培育机制，加大职业农民职业教育培训力度。一是充分利用职业教育资源开展培训。2014年，我部联合教育部印发《中等职业学校新型职业农民培养方案试行》，鼓励新型职业农民采用半农半读、农学交替等方式，分阶段完成学业。各地根据实际情况积极探索，制定切实可行的具体政策，开展多形式农民职业教育。目前，福建、北京、江苏、河北等省市都探索出了很好的实践经验模式。二是创建农村职成教育示范县。2013年以来，教育部门开展国家级农村职业教育和成人教育示范县创建，目前已成功创建三批159个县（市、区），通过搭建示范县展示与交流平台、加强职业学校建设、开展新型职业农民培训，深入推进农村职业教育与培训工作。三是大力实施农村实用人才带头人示范培训。自2007年以来，我部联合中央组织部大规模开展农村实用人才带头人和大学生村官示范培训，面向村党组织书记及村"两委"其他成员、大学生村官、新型农业经营主体负责人、返乡下乡创业人员等组织和带领农民群众脱贫致富的带头人进行培训。11年来，累计培养留得住、用得上、干得好的农村带头人9万余人。四是积极开展职业技能培训。人力资源社会保障部门依托技能院校和职业培训机构，开展针对农村劳动者和返乡农民工的创业培训、就地就近转移培训。2014年以来，人力资源社会保障部在全国组织开展农民工职业技能提升计划"春潮行动",力争到2020年使新进入劳动力市场的农村转移劳动者都有机会接受一次就业技能培训。仅2017年，就培训898万人次，为提升农村劳动者就业创业能力、促进就业发挥了积极作用。五是不断健全教育培训体系。积极构建党委政府主导，农业部门牵头，公益性培训机构为主体，市场力量和多方资源共同参与的教育培训体系。不断强化各级农广校的主体支撑作用，凝聚农业院校、科研院所、农民合作社、农业企业、农业园区等多种资源，以广泛方式积极参与新型职业农民培育工作。

下一步，我部将联合有关部门不断健全完善培育机制，加快构建"专门机构+多方资源+市场主体"的农民教育培训体系，发展壮大爱农业、懂技术、善经营的新型职业农民队伍，为现代农业发展和乡村振兴战略注入源源不断动力。

三、关于加强组织领导

培育新型职业农民是一项开创性事业，我部高度重视，积极推动全国上下提高认识，凝聚力量，加快构建新型职业农民队伍。一是强化顶层设计。连续7年中央1号文件及中央有关文件都对新型职业农民培育作出部署要求。2018年中央1号文件更是从乡村振兴人才支撑的角度，以全面建立职业农民制度为统领，对大力培育新型职业农民作出专门部署。我部会同有关部门认真贯彻落实中央部署，印发《"十三五"全国新型职业农民培育发展规划》，明确了"十三五"期间我国新型职业农民培育的指导思想、目标任务和保障措施。自2014年新型职业农民培育工程实施以来，中央财政持续加大资金支持力度，累计投入70.9亿元，培训超过400万人次。目前，全国18个省（区、市）制订了省级新型职业农民认定管理办法、意见、细则，1096个县市出台了新型职业农民扶持政策。二是加强规范管理。我部联合财政部加强培育体系绩效管理，推动培育制度建设和工作落实，逐步建立中央对省、省对县、县对培训机构的分层绩效考核机制，鼓励各地探索由第三方进行培育效果评价的模式。自2016年以来我部开展年度绩效考评，按照每年发布的《全国新型职业农民培育工作绩效考核指标体系（试行）》，健全完善激励约束机制，全面开展绩效考核工作。2017年起对培训教师、培训班组织和培训效果实行线上考核，对考评结果进行通报，并与下一年新型职业农民培育任务资金安排、评优奖励挂钩。三是加强表彰奖励。为了强化典型示范作用，激发新型职业农民创业创新热情，我部每年组织评选"十佳农民",每两年评选一批"风鹏行动·新型职业农民".通过表彰奖励，树立了一批扎根农村、事迹突出、带动能力强的新型职业农民典型。各地也注重先进典型树立，如山西省2017年评选推介出首届全省"十佳新农民",弘扬"重农爱农尚农"新风尚，吸引更多优秀人才投身乡村振兴。

下一步，我部将继续抓好《"十三五"全国新型职业农民培育发展规划》落实工作，会同有关部门积极推动全面建立职业农民制度，进一步夯实培育新型职业农民的制度基础，为乡村人才振兴提供有力支撑。

感谢您对新型职业农民培育工作的关心，希望今后继续对我部工作给予支持。
