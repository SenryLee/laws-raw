# 国土资源部办公厅关于转发中央国家机关政府采购中心网上竞价管理办法和政府集中采购信息类产品协议供货管理办法的通知

国土资厅函〔2018〕133号

各预算单位：

为进一步规范网上竞价和协议供货采购行为，提高采购质量和效率，强化履约管理，依据《中华人民共和国政府采购法》、《中华人民共和国政府采购法实施条例》和有关行政法规的规定，中央国家机关政府采购中心修订了《网上竞价管理办法》（国机采〔2017〕16号）和《政府集中采购信息类产品协议供货管理办法》（国机采〔2017〕17号），现转发给你们，请遵照执行。

2018年1月30日

附件：《中央国家机关政府采购中心网上竞价管理办法》（国机采〔2017〕16号）、《中央国家机关政府集中采购信息类产品协议供货管理办法》（国机采〔2017〕17号）
