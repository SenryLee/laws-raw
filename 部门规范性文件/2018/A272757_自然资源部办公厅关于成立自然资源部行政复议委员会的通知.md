# 自然资源部办公厅关于成立自然资源部行政复议委员会的通知

自然资办发〔2018〕52号

各省、自治区、直辖市自然资源主管部门，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

为切实加强对行政复议工作的领导，提升自然资源系统法治建设水平，发挥行政复议在保障和监督依法行政、防止和纠正违法或不当行政行为中的重要作用，经批准决定成立自然资源部行政复议委员会（以下简称部复议委员会）及自然资源部行政复议委员会办公室（以下简称部复议委员会办公室）。现将有关事项通知如下：

一、部复议委员会主要职责及组成人员

（一）主要职责

贯彻实施行政复议法律法规，审定自然资源行政复议相关制度；审定重大、复杂、疑难的行政复议案件及因行政复议决定引起的重大行政诉讼案件；审定自然资源行政复议行政应诉工作情况报告；研究议定行政复议行政应诉工作中反映的重大问题，审定行政复议行政应诉约谈、通报工作；审定行政复议工作的其他重要事项。

二、部复议委员会办公室组成及主要职责

部复议委员会下设办公室，设在法规司，负责统筹协调部行政复议和行政应诉工作。办公室主任由法规司主要负责人兼任，副主任及办公室成员由法规司、信息中心、不动产登记中心（法律中心）的相关同志组成。办公室具体事务由部不动产登记中心（法律中心）承担。

部复议委员会办公室的主要职责是：组织实施行政复议法律法规，起草自然资源行政复议相关制度；组织办理行政复议和行政应诉案件，对重大、复杂、疑难的行政复议案件及因行政复议决定引起的重大行政诉讼案件提出处理建议；组织起草自然资源行政复议行政应诉工作情况报告；定期组织对普遍性规律性问题进行研究，提出行政复议行政应诉约谈、通报建议；监督部复议委员会议定事项的落实情况；承办部复议委员会交办的其他事项。

三、其他事项

为对外开展部行政复议和行政应诉工作，刻印部复议委员会办公室专用章，办公室成员配发统一的工作证。

各司局和派驻地方的国家自然资源督察局的行政复议和行政应诉联络员，负责组织协调本司局（单位）与办公室的具体联络工作。
