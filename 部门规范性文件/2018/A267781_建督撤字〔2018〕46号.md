# 建督撤字〔2018〕46号

陈光腾：

经调查核实，你在莆田市仙游县建设工程质量安全监督站工作期间，违规将一级注册结构工程师资格证书注册在莆田市建筑设计有限公司，存在以欺骗手段取得注册的行为。

我部于2018年3月7日向你发出《住房城乡建设部撤销行政许可意见告知书》（建督撤告字〔2018〕11号），你于2018年4月3日签收，并提出书面陈述、申辩。经研究，决定不予采纳该陈述、申辩意见。

依据《中华人民共和国行政许可法》第六十九条、第七十九条和《勘察设计注册工程师管理规定》（建设部令第137号）第二十九条，应当撤销你的一级注册结构工程师注册，鉴于你申请注销了一级注册结构工程师注册，已不具有可撤销的内容，我部决定对你作出自本决定书发出之日起3年内不得再次申请该项注册的处理决定。

如对本决定不服，你可自收到本决定书之日起60日内向我部申请行政复议或6个月内向人民法院提起行政诉讼。
