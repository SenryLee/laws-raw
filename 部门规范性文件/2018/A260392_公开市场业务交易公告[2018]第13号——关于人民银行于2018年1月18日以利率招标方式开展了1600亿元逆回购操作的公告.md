# 公开市场业务交易公告[2018]第13号——关于人民银行于2018年1月18日以利率招标方式开展了1600亿元逆回购操作的公告

## 公开市场业务交易公告

[2018]第13号

人民银行于2018年1月18日以利率招标方式开展了1600亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 800亿元 | 2.50% |
| 14天 | 700亿元 | 2.65% |
| 63天 | 100亿元 | 2.95% |

中国人民银行公开市场业务操作室

二〇一八年一月十八日
