# 国家文物局办公室关于开展2018年度文物考古机构评估工作的通知

办保函〔2018〕1100号

各有关省（自治区、直辖市）文物局（文化和旅游行政部门）：

为贯彻落实中共中央办公厅、国务院办公厅《关于加强文物保护利用改革的若干意见》精神，进一步引导文物考古机构注重自身建设和发展，提升文物考古机构的学术科研和社会服务水平，国家文物局决定组织开展2018年度文物考古机构评估工作。现就具体事宜通知如下：

一、评估组织

本次评估工作由国家文物局组织，委托中国人事科学研究院具体实施。评估工作包括综合评价63家文物考古机构2018年度田野考古、科学研究、社会服务等业务工作完成情况、职责履行情况、机构建设管理水平，以及国内文物考古机构总体情况评估，客观分析文物考古机构整体发展水平、存在问题，提出工作建议。

评估工作于2018年11月至2019年9月开展，分为四个阶段：

（一）2018年11月至2019年1月，由文物考古机构填写报送评估材料；

（二）2019年2月至4月，由中国人事科学研究院组织集中开展专家评估；

（三）2019年5月至6月，由中国人事科学研究院抽取10%的参评单位进行现场复核；

（四）2019年7月至9月，编写完成评估总报告和分报告。

二、评估对象

具备考古发掘资质的63家文物考古机构（附件1）。

三、评估方式

本次评估以《文物考古机构评估导则》（附件2）为主要评估依据，采取自我评估、专家评估、现场评估相结合的方式。本次评估年限区间为2018年1月至2018年12月。

四、相关要求

（一）各有关省（自治区、直辖市）文物行政部门和各文物考古机构应提高认识，指定专人具体负责此次评估工作，确保工作进度和质量。

（二）各有关省（自治区、直辖市）文物行政部门应加强监督和指导，督促各文物考古机构及时提交相关材料，认真审核材料的真实性和有效性，协助做好现场复核工作，确保评估过程的公平、公正、公开。

（三）各文物考古机构应按照《文物考古机构评估导则》要求，认真填写2018年《文物考古机构自评报告》（附件3）。上述报告（一式两份，含电子文档）应经相应的省级文物行政部门核准，并于2019年1月30日前寄送至中国人事科学研究院。

（四）附件1-3可在国家文物局网站（www.sach.gov.cn）的通知公告栏中下载。
