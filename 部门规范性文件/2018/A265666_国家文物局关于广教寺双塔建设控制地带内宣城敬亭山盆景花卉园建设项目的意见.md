# 国家文物局关于广教寺双塔建设控制地带内宣城敬亭山盆景花卉园建设项目的意见

文物保函〔2018〕641号

安徽省文物局：

你局《关于宣城敬亭山盆景花卉园项目涉及广教寺双塔建设控制地带的请示》（皖文物保〔2018〕43号）收悉。经研究，我局意见如下：

一、原则同意广教寺双塔建设控制地带内宣城敬亭山盆景花卉园建设项目和你局意见。

二、具体修改意见如下：

（一）拟建项目不应压占保护范围，并应严格遵守建设控制地带的控制要求。

（二）深化设计方案，补充拟建项目与广教寺双塔保护区划的关系图，并对边界关系的处理作出说明；完善现状总平面图，标明文物本体与拟建区域的平面和竖向关系；补充交易中心、推广中心、小木屋、育苗区等建筑单体的位置平面图、外观设计图，以及建筑风格、色彩、材料、做法等设计说明。

（三）应重新编制文物影响评估报告，科学、客观评估拟建项目对文物安全和景观风貌的影响，进行必要的景观视线分析，并依据评估结论进一步完善设计方案。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》有关规定履行相关程序后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

专此函复。

国家文物局

2018年6月19日
