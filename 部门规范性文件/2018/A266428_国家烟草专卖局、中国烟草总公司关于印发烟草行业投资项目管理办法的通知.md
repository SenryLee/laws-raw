# 国家烟草专卖局、中国烟草总公司关于印发烟草行业投资项目管理办法的通知

## 国家烟草专卖局　中国烟草总公司关于印发烟草行业投资项目管理办法的通知

国烟计〔2018〕17号

行业各直属单位，国家局、总公司机关各部门、各单位：

《烟草行业投资项目管理办法》已经国家局办公会议审议同意，现印发给你们，请认真遵照执行。2016年2月18日印发的《烟草行业投资项目管理办法》（国烟计〔2016〕50号）同时废止。
