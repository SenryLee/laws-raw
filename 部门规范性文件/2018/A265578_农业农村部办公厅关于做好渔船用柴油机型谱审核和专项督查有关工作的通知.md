# 农业农村部办公厅关于做好渔船用柴油机型谱审核和专项督查有关工作的通知

农办渔〔2018〕48号

渔船用柴油机型谱制度颁布实施以来，对加强渔船规范化管理，合理标注渔船用柴油机功率，保障海洋渔船“双控”制度和相关政策的顺利实施发挥了重要作用。为依法履行渔船用柴油机的监督管理，切实做好渔船检验职责划转后的相关衔接工作，现就进一步加强渔船用柴油机型谱审核和专项督查工作有关事项通知如下。

一、切实加强渔船用柴油机源头管理

各级渔业主管部门及其渔政渔港监督管理机构要高度重视，按照《农业部关于进一步加强国内渔船管控实施海洋渔业资源总量管理的通知》（农渔发〔2017〕2号），以及《渔船用柴油机型谱与标识管理办法》（农渔发〔2014〕3号）和《渔船用柴油机型谱与标识专项督导核查实施方案》（农办渔〔2016〕54号）等有关规定，进一步统一思想、提高认识，切实加强渔船用柴油机的源头管理，强化柴油机型谱审核和专项督查工作，确保渔船检验管理职责调整后，渔业船舶特别是渔船用柴油机的监督管理工作更加高效，不受机构改革影响。

二、进一步明确渔船用柴油机型谱审核公布程序

按照《渔船用柴油机型谱与标识管理办法》等有关规定，在政策调整完善和新工作机制建立前，渔船用柴油机型谱审核程序为：柴油机制造企业提出型谱审查申请后，由各省（区、市）渔业主管部门组织初审，合格后直接送型谱审核专家委员会秘书处（上海海洋大学）进行内审，由其定期或不定期组织专家对申报材料进行集中审核，出具评审意见报我部渔业渔政管理局审定公示后公布实施。同时，根据各地执行中反馈的意见，自本通知下发之日起，暂不受理增压非中冷柴油机型谱申请。已受理的，暂不审核公布。

三、做好渔船用柴油机型谱与标识专项督查

按照《渔船用柴油机型谱与标识专项督导核查实施方案》等有关要求，中国水产科学研究院渔业机械仪器研究所（国家渔业机械仪器质量监督检验中心）作为渔船用柴油机型谱与标识专项督导核查工作组牵头单位，负责制定2018年专项督查具体方案，会同有关省（区、市）渔业主管部门及其渔政渔港监督管理机构，结合我部组织开展的“船证不符”专项执法行动，切实加大柴油机制造企业和实船核查力度，坚决纠正渔船实际功率与证书记载内容不一致，柴油机制造企业不如实标注铭牌、不准确铅封供油机构，渔民擅自拆除柴油机调速器和喷油泵铅封、调整柴油机关键配置等违规现象。

各省（区、市）渔业主管部门要结合“十三五”渔船“双控”制度实施，组织对渔船用柴油机型谱规定贯彻落实情况进行总结，提出意见建议于2018年7月15日前报我部渔业渔政管理局。中国水产科学研究院渔业机械仪器研究所、上海海洋大学要结合近年来渔船用柴油机审核和专项督查情况，认真进行总结评估，梳理分析存在的问题，组织专家研究论证，提出进一步强化渔船用柴油机管理的政策措施建议尽快报我部渔业渔政管理局。

农业农村部办公厅
