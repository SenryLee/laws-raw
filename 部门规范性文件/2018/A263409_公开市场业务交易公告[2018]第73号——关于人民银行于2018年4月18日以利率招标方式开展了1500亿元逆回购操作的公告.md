# 公开市场业务交易公告[2018]第73号——关于人民银行于2018年4月18日以利率招标方式开展了1500亿元逆回购操作的公告

## 公开市场业务交易公告

[2018]第73号

为对冲税期等因素的影响，维护银行体系流动性合理稳定，人民银行于2018年4月18日以利率招标方式开展了1500亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 1500亿元 | 2.55% |

中国人民银行公开市场业务操作室

二〇一八年四月十八日
