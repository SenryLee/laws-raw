# 国家文物局办公室关于西门街古建筑群保护范围和建设控制地带内保护利用设施建设项目的意见

办保函〔2018〕438号

云南省文物局：

你局《关于请求批准剑川县西门街古建筑群保护利用设施建设项目初步设计方案的请示》（云文物〔2018〕57号）收悉。经研究，我局意见如下：

一、拟建项目设计依据不足，方案深度不够，暂不同意所报方案。

二、具体修改意见如下：

（一）论证管理用房和厕所、照壁的建设依据和选址依据；补充西门街古建筑群保护范围和建设控制地带的管理规定和建设控制指标；补充建设项目总平面图，明确拟建建筑与西门街古建筑群保护区划的关系，标明各项技术指标。

（二）深化设计方案，加强现状勘察，给排水设计应详细调查古街原排水系统，最大限度保存历史信息；涉及开挖原有历史铺装的，应严格恢复原状；补充拟建建筑设计图、项目范围内地面铺装现状图、施工后铺装设计图，保护院落和街巷历史环境风貌的真实性。

（三）制订在文物院落范围内敷设管线、安装器材的详细文物保护措施和应急预案，确保文物安全。

（四）修改文物影响评估报告，准确、客观评估拟建项目对文物本体及景观风貌的影响。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善后，另行报批。

国家文物局办公室

2018年5月18日
