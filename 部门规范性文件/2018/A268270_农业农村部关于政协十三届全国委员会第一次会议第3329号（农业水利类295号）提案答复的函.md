# 农业农村部关于政协十三届全国委员会第一次会议第3329号（农业水利类295号）提案答复的函

## 关于政协十三届全国委员会第一次会议第3329号（农业水利类295号）提案答复的函

农办案〔2018〕69号

吴德委员：

您提出的关于"破解‘猪周期’难题 保护养猪生产者积极性的提案"收悉。经商商务部、工业和信息化部、证监会、银保监会、财政部，现答复如下。

我国是养猪大国，猪肉产量稳居世界首位。2017年我国生猪出栏6.9亿头，同比增长0.5%,猪肉产量5340万吨，同比增长0.8%.猪肉是城乡居民的主要肉食品，在肉类消费构成中占比约64%,猪价变化一头连着城乡居民的"菜篮子",一头连着农民的"钱袋子",保护和稳定生猪生产意义重大。

上世纪九十年代中期以来，我国肉类生产快速发展，短缺问题基本解决，随之也出现了明显的"猪周期"现象。一方面，价格波动是市场配置资源的常态，是市场机制发挥作用的正常表现；另一方面，猪价大起大落也会给产业稳定发展和居民正常消费带来不利影响。客观地讲，"猪周期"无法消除，但可以通过缓解猪价周期性波动减轻负面影响。

一、关于加快和推进生猪期货市场和价格保险建设

生猪期货是发现价格、对冲风险的重要手段，但如何避免一些社会资本进入生猪期货市场违规炒作套利，以及交割方式与标准等一些具体操作层面的问题还需要进一步探索。2017年12月，大连商品交易所向中国证券监督管理委员会上报了生猪期货立项申请，拟依托大型标准化生猪养殖企业，上市活体交割的生猪期货。目前，证监会已经批复同意该立项申请，下一步将督促大连商品交易所加强市场调研，认真做好生猪期货的合约设计和规则论证工作，并就防范生猪期货可能出现的交割风险做出预案，加快推进生猪期货上市。

生猪价格保险对帮助养殖场户规避猪肉价格大幅波动导致的市场风险有重要意义，银保监会对此高度重视。2014年，保险机构开始开发相关产品，并逐步扩大试点范围。2017年，生猪目标价格保险保费收入4.05亿元，承保生猪732万头，提供风险保障89.95亿元，支付赔款3.7亿元，简单赔付率达到91.36%.特别是2017年下半年以来，猪肉价格持续下跌，为了更好的服务养殖场户，缓解猪肉价格下跌给养猪产业带来的风险，2018年5月，银保监会组织召开座谈会，要求保险公司发挥大局意识，在猪肉价格下行期间做好理赔服务。下一步，我部将配合相关部门，积极研究改进价格保险产品，做好风险防控，努力保障养猪场户可持续生产。

二、关于实行生猪养殖登记制度和构建生猪养殖诚信体系

为了提高生猪生产和市场价格数据的时效性、准确性、权威性，2008年，我部开始实施"百场千村万户"定点监测计划。依托定点监测体系，我部每月发布生猪存栏、能繁母猪存栏变化情况，每周发布活猪、猪肉、仔猪等畜产品市场价格情况，在关键节点加强生猪生产形势解读，引导养殖场户调整生产。为了进一步完善畜牧业监测预警，实现全国养殖场信息联网、统一管理、数据共享，2017年初，我部启动了畜禽规模养殖场信息直联直报平台建设。养殖场在直联直报平台备案后将被赋予具有唯一性的生产经营单位代码，为信息交换、行政执法和追溯管理提供支撑。目前直联直报平台建设进展顺利，已初步具备养殖场备案、项目管理、生产监测、畜禽粪污资源化利用监测、大数据分析等功能。下一步，我部将与银保监会、畜牧业龙头企业合作，依托生产经营单位代码，加快构建养殖场户的信用体系，并与养殖补贴、金融贷款、保险服务等业务挂钩，维护养殖业正常有序发展。

三、关于加大科技投入

近年来，我部高度重视畜牧业种质领域科研工作。特别是针对生猪产业，成立了国家生猪产业技术体系，在体系设置中依据生猪养殖关键环节，设立了遗传改良、营养与饲料、疫病防控、生产与环境控制、加工以及产业经济等8个重点研究室，在全国建立了34个试验站。科研力量上，汇集了一批院士和全国生猪养殖技术方面的高精尖专家。该体系2017年获得国家科技进步二等奖、全国创新争先奖、国家脱贫攻坚奉献奖各1项，省级科技进步一等奖及技术发明一等奖4项，成绩显著。下一步，我部将继续加大对国家生猪产业技术体系的支持和指导力度，增强生猪育种、养殖、疾病防控等关键环节技术创新能力，推动生猪产业全面转型升级。

四、关于鼓励企业延长产业链

生猪产业化程度低，饲料、兽药、养殖、加工、运销等相互脱节，产业链条不完整，缺乏利益共享、风险共担的共生机制，是导致猪价呈现周期性大幅波动和产业链利益分配不均衡的原因之一。近年来，中央财政通过农业生产发展资金，支持各地结合当地实际情况，延伸农业产业链，提升价值链。下一步，我部将在不干预企业、商家正常市场行为的前提下，引导和鼓励生猪产业相关企业开展养殖、屠宰、加工、销售一体化经营，提高生产和消费的结合度，降低由于生产需求错配导致的波动风险。

五、关于加强猪肉冷链物流建设和猪肉产品深加工

完善的冷链物流基础设施是提高畜产品流通效率，降低产品流通损耗，促进养殖场户增收的保障。近年来，农产品冷链物流基础设施建设积极推进。2016—2017年，中央财政安排20亿元，用于支持河北等10个省市推进产地预冷集配、低温加工仓储配送等基础设施建设，加强冷库、冷藏车等设施设备温度监控体系建设，完善冷链物流标准体系，加强专业技能培训，全面提升我国冷链物流信息化、标准化水平。下一步，我部将协调有关部门，拓宽资金支持渠道，降低冷链物流成本，提高流通效率，推动农畜产品冷链流通标准化工作，加快构建全国农畜产品流通骨干网络，提升冷链物流现代化水平。

六、关于鼓励规模化生产，转变生产方式

我国生猪生产规模化水平较低，全国约有53%的出栏肥猪由年出栏500头以下小散养殖户提供，极易出现"一哄而起，一哄而散"的情况，导致生产和市场价格大幅波动。近年来，我部通过开展标准化规模养殖示范创建，完善生猪调出大县奖励政策，支持养殖场基础设施改造升级，生猪养殖"小规模、大群体"盲目生产的局面逐步改变。2017年，全国生猪规模养殖比重达到46.9%,比2012年提高了8.5个百分点，比2007年提高了25.1个百分点，规模养殖场正在成为生猪市场供应的主力。同时，生猪产业绿色发展持续推进，中央财政安排了20亿元，支持18个省共120个县推进畜禽粪污资源化利用，其中北京、天津、江苏、浙江4省（市）开展整省推进，石家庄市、驻马店市等5个地级市开展整市推进。下一步，我部将继续优化生猪养殖区域布局，统筹种养加协调发展，促进养殖废弃物综合利用，加快推进生猪产业转型升级和绿色发展。

七、关于提高行业准入门槛，建立长效职业培训机制

"猪粮安天下".我国目前仍有3000万养猪场户，其中99%以上是年出栏不足500头的小散户，生猪养殖仍是不少地区农民增收的重要渠道。特别是在一些贫困地区，发展养猪业是脱贫攻坚的首选产业。鉴于当前的实际情况，暂不宜设置生猪行业准入门槛。

建立长效职业培训机制，对提高生猪产业从业人员整体素质，提升畜牧产业发展质量具有积极意义。从2012年开始，我部启动实施了包括养殖场户在内的新型职业农民培育工程，取得了显著成效。截至"十二五"期末，全国新型职业农民规模达到1272万人，比2010年增长55%,新型职业农民正在成为现代农业建设的主导力量。2018年，我部继续分层分类培育新型职业农民，全年计划培育100万人以上，同时开展了万名畜牧养殖大户、万名种粮大户等示范培育工作。下一步，我部将继续加大新型职业农民培育工作支持力度，加强畜牧养殖行业培训需求调研和内容设置，提升培育针对性，加强过程管理和标准建设，突出培育规范性，加强政策扶持和延伸服务，提高培育有效性，发展壮大一支爱农业、懂技术、善经营的新型职业农民队伍。

感谢您对畜牧业发展的关心，希望今后继续对我部工作给予支持。

农业农村部

2018年8月24日
