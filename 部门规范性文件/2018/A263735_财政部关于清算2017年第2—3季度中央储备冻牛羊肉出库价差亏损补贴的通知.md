# 财政部关于清算2017年第2—3季度中央储备冻牛羊肉出库价差亏损补贴的通知

财建〔2018〕123号

商务部：

你部《关于申请核拨2017年2—3季度出库中央储备冻牛羊肉价差亏损补贴的函》（商运函〔2018〕21号）收悉。根据你部申请和我部驻北京市财政监察专员办事处审核意见，经研究，现拨付中央储备冻牛羊肉出库价差亏损费用补贴8,191.49万元，通过你部2018年部门预算“2220503肉类储备”科目“中央储备肉利息费用补贴资金”项目解决。

请尽快办理领款手续，并切实加强国家储备肉管理工作，及时将补贴资金转拨给承储企业。

财政部

2018年4月8日
