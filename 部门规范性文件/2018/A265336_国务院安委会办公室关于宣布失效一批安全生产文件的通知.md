# 国务院安委会办公室关于宣布失效一批安全生产文件的通知

安委办〔2018〕17号

各省、自治区、直辖市及新疆生产建设兵团安全生产委员会，国务院安委会有关成员单位：

为贯彻落实党中央、国务院关于加强法治政府建设的决策部署，进一步推进依法行政，国务院安全生产委员会办公室对印发的文件进行了全面清理,决定对其中82件文件宣布失效。有关文件自本通知印发之日起一律停止执行，不再作为行政管理的依据。

附件：宣布失效的安全生产文件目录

国务院安委会办公室

2018年6月4日
