# 国家文物局办公室关于在潼川古城墙建设控制地带内进行宏达·东门里二期C块地项目的意见

办保函〔2018〕1218号

四川省文物局：

你局《关于报送〈潼川古城墙建设控制地带内宏达·东门里二期C块地建筑方案〉的请示》（川文物〔2018〕104号）收悉。经研究，我局暂不同意在潼川古城墙建设控制地带内进行宏达·东门里二期C块地项目。

一、对所报方案提出以下修改完善意见：

（一）应严格按照我局办公室《关于潼川古城墙建设控制地带内宏达·东门里二期C块地——东门片区危旧房棚户区改造项目的意见》（办保函〔2018〕920号）要求，补充历史文化街区内传统建筑等的现状评估，深化现状勘察，调整完善设计方案。

（二）调整C2地块设计，凡传统民居建筑应原位、原样修复，不得改变其格局、路网、位置和结构形式，可根据后期功能需求做部分改造设计，如局部立面、室内装修及基础设施布线等。尽可能续用原有构件。

（三）应加强对东门传统民居形制、材料、工艺等方面的记录与研究。

（四）进一步缩小新建建筑的规模、体量和高度，优化新建建筑的外观设计，并明确其结构形式和材料等。地面不宜全部采用现代硬质铺装。

（五）进一步规范图纸表达。核对地块用地性质标注；进一步明确建设区域与保护区划的关系。

三、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2018年12月19日
