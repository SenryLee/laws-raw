# 自然资源部公告2018年第32号——自然资源部关于南丹县南星锑业有限责任公司茶山锑矿等3个矿山地质环境保护与土地复垦方案通过审查的公告

## 自然资源部公告

2018年第32号

## 自然资源部关于南丹县南星锑业有限责任公司茶山锑矿等3个矿山地质环境保护与土地复垦方案通过审查的公告

根据《土地复垦条例》《矿山地质环境保护规定》等有关规定，南丹县南星锑业有限责任公司茶山锑矿等3个矿山地质环境保护与土地复垦方案通过审查，现予公告。

附件：3个通过审查的矿山地质环境保护与土地复垦方案名单

自然资源部

2018年8月12日

附件
