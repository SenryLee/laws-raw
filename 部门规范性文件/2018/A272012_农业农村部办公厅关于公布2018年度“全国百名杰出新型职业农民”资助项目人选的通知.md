# 农业农村部办公厅关于公布2018年度“全国百名杰出新型职业农民”资助项目人选的通知

农办科〔2018〕30号

各省、自治区、直辖市及计划单列市农业农村（农业、农牧）厅（局、委），新疆生产建设兵团农业局，黑龙江省农垦总局、广东省农垦总局：

为进一步营造关心农业、关注农村、关爱农民的良好社会氛围，激励在“三农”事业中作出突出贡献、被群众广泛认可的优秀职业农民代表，经各地推荐、组织遴选、社会公示等环节，农业农村部决定对宋绍堂等100名新型职业农民给予资助（名单附后）。

希望受资助的“全国百名杰出新型职业农民”再接再厉，进一步转变观念，紧跟时代步伐，充分发挥榜样作用，带领广大农民创业创新、增收致富，为加快推进农业农村现代化再立新功。各级农业部门要广泛宣传“全国百名杰出新型职业农民”的优秀事迹、积极弘扬他们的先进理念、大力推广他们的经营模式，进一步完善制度和政策措施，培养更多爱农业、懂技术、善经营的新型职业农民，为实施乡村振兴战略提供有力的人才支撑。

附件：2018年度“全国百名杰出新型职业农民”资助项目人选名单

农业农村部办公厅

2018年12月13日
