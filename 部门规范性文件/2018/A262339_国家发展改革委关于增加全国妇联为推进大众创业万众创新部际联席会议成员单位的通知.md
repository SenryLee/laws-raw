# 国家发展改革委关于增加全国妇联为推进大众创业万众创新部际联席会议成员单位的通知

发改高技〔2018〕414号

推进大众创业万众创新部际联席会议各成员单位：

为全面贯彻党中央、国务院实施创新驱动发展战略、推进大众创业万众创新的战略部署，加强统筹协调，形成工作合力，经商推进大众创业万众创新部际联席会议全体成员单位同意，现增加全国妇联为推进大众创业万众创新部际联席会议成员单位， 全国妇联杨柳同志为联席会议成员。

特此通知。

国家发展改革委

2018年3月12日
