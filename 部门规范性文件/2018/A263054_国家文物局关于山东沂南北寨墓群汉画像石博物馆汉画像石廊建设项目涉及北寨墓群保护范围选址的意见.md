# 国家文物局关于山东沂南北寨墓群汉画像石博物馆汉画像石廊建设项目涉及北寨墓群保护范围选址的意见

文物保函〔2018〕315号

山东省文物局：

你局《关于呈报〈山东沂南北寨汉画像石博物馆汉画像石廊改建工程方案〉的请示》（鲁文发〔2018〕19号）收悉。经研究，我局意见如下：

一、原则同意山东沂南北寨汉画像石博物馆汉画像石廊建设项目涉及全国重点文物保护单位北寨墓群保护范围的选址方案。

二、该建设项目应严格控制施工范围和建筑高度、体量，进一步优化结构设计，减少钢筋混凝土仿古构件的粗笨感，使其与文物周边环境相协调。同时，应制定现场文物保护措施，确保文物安全。

三、请你局组织专业考古研究单位，在项目拟建区域进一步开展必要的考古调查和发掘工作。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

四、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，按照《中华人民共和国文物保护法》第十七条的规定，报山东省人民政府批准。

五、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促工程部门切实做好施工过程中的文物保护工作，确保文物安全。

国家文物局

2018年3月30日
