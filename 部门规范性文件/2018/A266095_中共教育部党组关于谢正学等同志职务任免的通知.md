# 中共教育部党组关于谢正学等同志职务任免的通知

教党任〔2018〕106号

中共华中科技大学委员会：

经与中共湖北省委商得一致，2018年6月4日研究决定：

谢正学同志任中共华中科技大学委员会常委、副书记，张新亮、解孝林同志任中共华中科技大学委员会委员、常委；免去丁汉初同志的中共华中科技大学委员会常务副书记、常委职务。

中共教育部党组

2018年6月20日
