# 财政部关于下达2018年民航发展基金转移支付项目预算的通知

财建〔2018〕283号

有关省、自治区、直辖市、计划单列市财政厅（局）：

根据《财政部民航局关于民航发展基金预算管理有关问题的通知》（财建〔2016〕362号）等有关规定和中国民用航空局《关于2018年民航发展基金转移支付预算调整的函》（民航函〔2018〕508号），现下达你省（自治区、直辖市、计划单列市）2018年民航发展基金转移支付项目预算（项目代码：Z165060100005）, 其中地方机场投资补助项目、中小机场补贴项目、贷款贴息项目分别列2146901、2146904、2146999科目，具体机场、金额、政府收支分类科目及绩效目标详见附件。此次预算下达的同时一并下达绩效目标。

请尽快将资金拨付有关单位，切实加强对资金的管理和监督，提高资金使用效益。为进一步加强预算绩效管理，请在组织预算执行中对照你省（区、市）区域绩效目标做好绩效监控，确保年度绩效目标如期实现。同时，请参照中央做法，做好省（区、市）内预算绩效管理工作,将你省（区、市）绩效目标及时分解至具体项目，每个项目都要填报绩效目标及指标，作为绩效执行监控和绩效评价的依据。分项目绩效目标请抄送财政部驻你省（区、市）财政监察专员办事处。

附件：1. 2018年民航发展基金转移支付资金方案总表（含提前下达，不发地方）

2. 2018年民航发展基金转移支付资金支出预算总表（不发地方）

3. 2018年民航发展基金转移支付资金支出预算表（分发地方）（略）

4. 2018年民航发展基金转移支付整体绩效目标表（不发地方）

5.2018年民航发展基金转移支付绩效目标表（分发地方）（略）

财政部

2018年6月18日
