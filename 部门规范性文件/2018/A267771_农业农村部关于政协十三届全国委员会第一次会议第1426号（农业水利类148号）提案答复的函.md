# 农业农村部关于政协十三届全国委员会第一次会议第1426号（农业水利类148号）提案答复的函

## 关于政协十三届全国委员会第一次会议第1426号（农业水利类148号）提案答复的函

农办案〔2018〕56号

马露委员：

您提出的关于推进农民创新创业的提案收悉。经商商务部、银保监会和自然资源部，现答复如下。

一、关于加大政策宣传，推动创新创业示范点建设

2015年，我部牵头制定推进农民创业创新行动计划（2015—2017年），对农民返乡创业创新进行规划指导，并积极开展创业创新宣传推介。2016年，国务院办公厅印发《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》（国办发〔2016〕84号），我部在国新办举行了专题新闻发布会，解读文件政策，回应社会关切。随后，召开支持返乡下乡创业创新工作视频会议，韩长赋部长出席会议并讲话，对贯彻落实国办文件精神、推进返乡下乡创业创新工作进行安排部署。同时，通过广播、电视、报纸、网络、微信、微博、宣传册、明白纸等多种形式，广泛宣传相关政策举措。2017年，我部分别在贵州、河南、北京、上海举办了农村创业创新成果展；组织举办了全国农村创业创新项目创意大赛，共有27个省（区、市）3万多人参赛，评选出20个优秀项目，帮助选手获得资金、技术、市场支持。每年10月，发展改革委和中国科协联合举办全国大众创业万众创新宣传周活动，出版发行中国大众创业万众创新发展报告，开展“创响中国”巡回接力活动等。

2015年，国务院印发《关于加快构建大众创业万众创新支撑平台的指导意见》（国发〔2015〕53号），首批选择15个城市开展小微企业创业创新基地城市示范工作，在部分区域、高校和企业部署建设首批28个“双创”示范基地。此外，我部经过各地遴选推荐、专家评审和公示，向社会宣传推介200个全国农村创业创新优秀带头人典型案例和100个典型县范例。今年3月，在四川省金堂县举办现场交流活动，宣传推广特色产业拉动、产业融合创新驱动、返乡下乡能人带动、创业创新园区（基地）集群、龙头骨干企业带动五大双创典型模式。

下一步，我部将通过举办第二届全国农村创业创新创意项目大赛、全国农村创业创新经验交流会、农村创业创新论坛和成果展览展示等活动，鼓励和支持更多返乡下乡人员创业创新，进一步营造全社会关心支持农村创业创新的良好氛围。

二、关于加快农地流转市场建设，建立和完善相应的保障机制

2014年，中共中央办公厅、国务院办公厅联合印发《关于引导农村土地经营权有序流转发展农业适度规模经营的意见》，推动农村承包土地经营权流转和适度规模经营发展，形成了一系列的政策措施。2016年，我部印发《农村土地经营权流转交易市场运行规范（试行）》，进一步明确土地经营权在流转交易市场进行交易的相关规程。

国土资源部在全国33个县（市、区）开展农村土地制度改革试点工作，积极探索“同权同价、流转顺畅、收益共享”的集体经营性建设用地入市制度，推动建立城乡统一的建设用地。2017年，会同发展改革委联合印发《关于深入推进农业供给侧结构性改革做好农村产业融合发展用地保障的通知》（国土资规〔2017〕12号），在加强建设用地计划指标支持、鼓励土地复合利用等方面提出了具体支持措施，做好农村一二三产业融合发展的用地保障工作。现阶段，对于其他暂未获得法律授权开展入市改革试点活动的地区，可以在符合现行法律法规的前提下，依据国务院支持农村一二三产业融合发展、促进乡村振兴等文件精神，依法使用集体建设用地。

三、关于强化农民培训，搭建创新创业平台

2014—2017年，中央财政安排85.9亿元用于新型职业农民培育工程，重点对种养大户、家庭农场主、农民合作社骨干、农业社会化服务人员和返乡涉农创业者进行专题培训，提高其生产经营能力和专业技能，共计培训新型职业农民500万人。同时，加强培训师资库、基地建设，吸纳7.5万名师资入库，遴选发布100个全国新型职业农民培育示范基地，推荐入库各类基地1.2万个。2017年，我部印发《关于全国农产品加工业人才培训等三个行动方案的通知》（农办加〔2017〕28号），部署在全国开展农产品加工业、农村创业创新、休闲农业和乡村旅游百万人才培训行动。计划到2020年，以农村创业创新人员、企业家、创业导师等为重点，培训农村创业创新人才40万人次。

在搭建创业创新平台方面，我部按照政府搭建平台、平台聚集资源、资源服务创业的总思路，联合12个部门印发《关于促进农村创业创新园区（基地）建设的指导意见》（农加发〔2017〕3号），对农村创业创新园区（基地）建设作出全面部署。公布了1096个农村创业创新园区（基地）目录，依托一些中高等院校、知名村镇、大型企业的见习基地、实训基地、众创空间、创新工厂等建设一批孵化园（基地），为创业创新者提供可选择的场所和服务。商务部会同财政部、国务院扶贫办开展了电子商务进农村综合示范工作，支持农村电商公共服务体系和物流配送体系建设，推动整合农村相关物流服务网络和设施，为农村创业青年开展电子商务提供基础保障。截至目前，累计支持了756个示范县；2017年，全国农村网络零售额达12448.8亿元，全国农产品网络零售额达2436.6亿元，全国农村网商985.6万家，带动就业超过2800人。

下一步，我部将在实施乡村就业创业促进行动中，开展农村创业创新“百县千乡万名带头人”培育工作和百万人才培训行动，培育乡村就业创业人才队伍。

四、关于落实财政金融支持，打造资金扶持平台

2012—2018年，中央财政安排农产品产地初加工补贴资金52亿元，补贴农户、合作社、中小企业建设产地初加工设施，降低鲜活农产品产后损失，延长农产品销售期，拓宽农民增收渠道。2015—2017年，中央财政安排农村一二三产业融合试点资金52亿元，支持让农民合理分享二三产业增值收益的经营主体，发展农村一二三产业融合，带动农民分享加工流通环节的增值收益。此外，我部还积极与中国农业银行、中国农业发展银行、国投创益基金等投融资机构合作，加大信贷和基金支持力度。

2017年，中国银行推出“中银新农通宝”“中银林权通宝”等系列产品，以生鲜品作为抵押品，解决农业领域抵押担保难问题。银保监会不断加强监管引领，督促银行业金融机构切实增加涉农贷款投放，加大对农民创新创业的支持力度。截至2018年3月，全国涉农贷款余额达到31.55万亿元。

下一步，银保监会将积极稳妥推进农村承包土地经营权、农民住房财产权、集体经营性建设用地使用权抵押贷款试点，在适合开展林权抵押贷款的地区扩大业务覆盖面，为农户贷款提供更好的融资便利。继续开发针对不同主体的小额贷款产品，灵活确定农村小额贷款期限；进一步完善大型农机具、农业生产设施和加工设备融资租赁服务措施；引导银行业金融机构与全国农业信贷担保体系合作，加快与国家、省市县各级农业信贷担保公司对接，充分发挥政策性担保风险增信作用，建立政府、银行、融资担保机构共同参与、合力分担风险的可持续合作模式。

五、关于完善信息服务体系，打造专业服务平台

2017年，我部先后举办了全国“互联网+”现代农业工作会议暨新农民创业创新大会和全国新农民新技术创业创新博览会，交流了农村创业创新最新成果和农业新技术新模式，展示了1038家单位最新农业技术创新应用成果，深化了全社会对“互联网+”现代农业的认识，形成了政府、企业和社会各方力量共同推进的格局。认定了两批106个全国农业农村信息化示范基地，成立了农业信息化标准委员会，构建了农业信息化评价指标体系，农业信息化发展基础进一步夯实。通过实施国家物联网应用示范工程智能农业项目和农业物联网区域试验工程，总结推广了426项节本增效农业物联网软硬件产品、技术和模式。积极探索农业电子商务新模式，组织开展苹果电商销售月行动和贵州土鸡电商专项促销行动，帮助地方政府建立特色产业长效扶贫机制。实施农产品电商出村工程，推动建立农业农村电商发展服务体系和新型农产品供应链体系，带动农民脱贫增收。

我部还建设了一批农兽药基础数据平台、国家农产品质量安全追溯管理信息平台、重点农产品市场信息平台、新型经营主体信息直报平台。加快对国家农业数据中心云化升级改造，加强涉农数据的采集、汇聚和关联分析，提高农业生产管理、指挥调度等数据支撑能力。通过益农信息社就近为农民和新型农业经营主体提供便捷高效的服务。截至2018年2月底，全国共建成运营益农信息社16.9万个，累计培训村级信息员53.6万人次，提供公益服务7960万人次，开展便民服务2.33亿人次，实现电子商务交易额167亿元。

下一步，我部将采取有力措施，落实相关扶持政策，进一步推进“互联网+”现代农业三年行动，促进农业信息化建设。

感谢您对农业农村工作的关心，希望今后继续关心和支持我部工作。

农业农村部

2018年8月17日
