# 国家文物局关于白鹤梁题刻水下保护体交通廊道外防撞设施工程的意见

文物保函〔2018〕109号

重庆市文物局：

你局《关于白鹤梁题刻水下保护体交通廊道外防撞设施工程初步设计报告的请示》(渝文物〔2017〕325号)收悉。经研究，我局意见如下：

一、白鹤梁题刻水下保护体交通廊道外防撞设施工程对于确保文物及航行、人员安全具有十分重要的意义，我局对所报白鹤梁题刻水下保护体交通廊道外防撞设施工程设计思路无异议。

二、白鹤梁题刻水下保护体交通廊道外防撞设施工程尚需做好以下几方面工作：

（一）进一步明确该工程项目环境条件、使用条件，包括荷载条件、安全准则等，对计算所需参数做进一步校核，并在科学测算的基础上，进一步补充完善工程可行性研究，确保工程技术路线的合理性与适用性。

（二）补充分析防撞工程实施前、实施后项目区所在河段的水流形态、河势变化情况。同时，应对通航水位超过175米和低于145米的时的安全状况进行校核。

（三）充分考虑斜坡交通廊道和水平交通廊道的自身稳定性、已有防护措施等因素，结合科学计算和必要的数据模拟，对工程设计做进一步优化完善，合理确定工程位置及范围，优化调整工程平剖面布置，并严格控制工程规模和体量。同时，应进一步开展防撞效果分析。

（四）施工设计应注意钢管桩接头部位的处理措施，并开展必要的前期试验。

三、请你局指导白鹤梁题刻水下保护体交通廊道外防撞设施项目业主单位，会同设计单位，根据上述意见进一步深化工程可行性研究，优化工程初步设计，并做好相应的施工图设计。相关工程可行性研究报告、初步设计报告及施工图设计由你局批准，并应履行航道、海事等相关部门审批程序。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡等各项准备工作。施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

五、请你局切实加强管理，督促、指导相关单位做好维修后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

国家文物局
