# 国家文物局关于集安市通沟村村民新建住宅房涉及洞沟古墓群保护范围选址的意见

文物保函〔2018〕320号

吉林省文物局：

你局《关于集安市通胜街道通沟村村民谭洪珍拟在全国重点文物保护单位洞沟古墓群保护范围内新建住宅房的请示》（吉文物发〔2017〕273号）收悉。经研究，我局意见如下：

一、原则同意集安市通胜街道通沟村村民谭洪珍新建住宅房涉及全国重点文物保护单位洞沟古墓群保护范围的选址方案。

二、新建房屋应按照文物保护规划要求和现有方案设计，严格控制建筑高度、体量、面积，房屋外观形制应与周边民宅保持一致，减少对周边环境风貌的影响。

三、请你局组织专业考古研究单位，在项目拟建区域进一步开展必要的考古调查和发掘工作。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

四、待考古工作结束后，请你局根据考古结果和文物保护的需要，指导优化项目选址及建设方案，按照《中华人民共和国文物保护法》第十七条的规定，报吉林省人民政府批准。

五、请你局督促地方文物部门做好对项目建设的全程监管和施工过程中的文物保护工作，确保文物安全。

国家文物局

2018年3月30日
