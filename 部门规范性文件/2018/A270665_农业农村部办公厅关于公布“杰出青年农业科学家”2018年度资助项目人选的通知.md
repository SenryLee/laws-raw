# 农业农村部办公厅关于公布“杰出青年农业科学家”2018年度资助项目人选的通知

农办人〔2018〕63号

为深入贯彻落实党的十九大精神，落实2018年中央1号文件和《乡村振兴战略规划（2018—2022年）》有关部署要求，进一步加强农业科研后备人才队伍建设，激发广大青年农业科技人员创新创业活力，促进优秀青年农业科学家脱颖而出，农业农村部决定继续实施“杰出青年农业科学家”资助项目。经过组织申报、单位推荐、评选公示等环节，共产生宁约瑟等25名“杰出青年农业科学家”2018年度资助项目人选。现予公布（名单附后）。

希望受资助的人员珍惜荣誉、再接再厉，紧跟新时代步伐，充分发挥表率作用，在农业科技创新实践中再创新业、再立新功。广大青年农业科技工作者要以受资助者为榜样，认清青年在中国特色社会主义新时代肩负的使命，增强责任担当意识，争做科技创新精神的弘扬者、科技兴农的引领者、先进生产力的开拓者、社会主义核心价值观的践行者，引领支撑乡村全面振兴和农业农村现代化。

农业农村部办公厅
