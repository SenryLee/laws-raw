# 国家文物局关于马厂塬遗址保护规划的意见

文物保函〔2018〕554号

青海省文物管理局：

你局《关于马厂塬遗址文物保护规划的请示》（青文物局〔2018〕23号）收悉。经研究，我局意见如下：

一、原则同意马厂塬遗址保护规划。

二、所报规划应进行以下必要的修改完善：

（一）应核实遗址分布范围，梳理文物构成和保护对象，明确文物本体及历史环境要素，科学评估马厂塬遗址的价值。

（二）应根据文物分布情况和保护管理的实际需要，综合确定保护区划及其具体边界，建议进一步缩小建设控制地带范围，并说明甲、丙两区划为重点保护区的依据。

（三）应针对文物本体保存现状、病害情况、影响因素等，研提文物本体保护措施，完善保护范围内安全防护、监测、边坡加固、冲沟加固、水土流失防治、河道防护等具体措施要求。

（四）细化专项规划内容，根据遗址保护管理需要减少居民搬迁数量，明确搬迁时序；环境整治、植被绿化及景观设计应与遗址周边环境特征相符，避免过于城市园林化；进一步明确遗址价值展示主题、内容和方式等，研提展示服务设施的规模、数量、选址等基本要求，注意做好相关规划衔接。

（五）进一步规范图文表达，合理核减经费预算。

三、请你局指导地方人民政府组织规划编制单位和甘肃省文物考古研究所，按照上述意见对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的马厂塬遗址保护规划报请青海省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府切实加强文物保护管理和机构建设，制定专项管理法规，并提出具体实施步骤和保障措施，妥善解决土地用途调整、环境整治等问题，有效保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2018年5月24日
