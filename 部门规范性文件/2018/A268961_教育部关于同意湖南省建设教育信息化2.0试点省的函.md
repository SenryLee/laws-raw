# 教育部关于同意湖南省建设教育信息化2.0试点省的函

教技函〔2018〕71号

湖南省人民政府：

《湖南省人民政府关于请批准建设教育信息化2.0试点省的函》（湘政函〔2018〕88号）收悉。为贯彻落实中央领导指示精神，经研究，同意你省组织开展教育信息化2.0试点省建设。请围绕加快教育现代化、建设教育强国发展目标，进一步完善实施方案，落实配套政策等相关支持保障条件，尽快启动并加快推进试点省建设工作。有关进展情况与成效请及时报送我部科技司。

（联系人及电话：任昌山 010-66097208）

教育部

2018年9月14日
