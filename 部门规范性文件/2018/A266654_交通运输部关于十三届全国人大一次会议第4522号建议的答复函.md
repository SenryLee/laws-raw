# 交通运输部关于十三届全国人大一次会议第4522号建议的答复函

## 关于十三届全国人大一次会议第4522号建议的答复函

交规划建字〔2018〕135号

陈文琴代表：

您关于加大对少数民族贫困山区村组公路硬化支持力度的建议收悉。关于“对南涧县山区农村公路硬化项目给予重点支持和倾斜”的建议，经我部认真研究，现答复如下：

我部高度重视贫困地区农村公路建设，“十三五”期制定了《“十三五”交通扶贫规划》，将南涧县在内的革命老区、民族地区、边疆地区、贫困地区全部纳入支持范围，给予特殊政策倾斜支持。近期，我部又印发了《交通运输脱贫攻坚三年行动计划（2018—2020年）》，明确交通脱贫行动计划，以按时保质完成乡镇和建制村通硬化路等建设任务。

“十三五”期我国农村公路建设任务仍然十分繁重，建设重点方面，一是加快推进剩余乡镇、建制村通硬化路建设，到2019年实现所有具备条件的乡镇和建制村通硬化路。二是推进撤并建制村等较大人口规模自然村通硬化路建设，支持云南省“直过民族”和沿边地区20户以上自然村通硬化路建设（南涧县也在支持范围内），推动交通建设项目尽量向进村入户倾斜。三是加强农村公路安全生命防护工程建设和危桥改造，推进窄路基路面公路合理加宽改造，提高农村通客运线路安全水平。四是支持一批资源路、旅游路、产业路建设，推进“交通+特色产业”扶贫。

支持政策方面，我部按照交通扶贫项目优先安排、资金优先保障、工作优先对接、措施优先落实的“四个优先”原则，大幅度提高贫困地区农村公路建设补助标准，其中建制村通硬化路补助资金已占平均工程造价的70%以上。根据统计数据，截至2017年底，云南省内各贫困县已实现100%具备条件的建制村通硬化路。据了解，云南省人民政府将通过涉农资金整合、发行地方债券、央企支援资金等方式，有序推进深度贫困县50户以上不搬迁自然村通硬化路建设。

地方人民政府是农村公路建设养护的责任主体。我部将继续督促云南省、大理州、南涧县人民政府按照“中央统筹，省负总责、市县抓落实”的管理体制，在中央加大支持力度的同时，统筹各类资源，调动各方力量，加快农村公路建设。

感谢您对交通运输工作的关心和支持。

交通运输部

2018年6月27日
