# 退役军人事务部办公厅关于举办全国军休干部庆祝新中国成立70周年文艺汇演的通知

各省、自治区、直辖市退役军人事务厅（局）：

为隆重庆祝新中国成立70周年，充分展示70年来的光辉历程和伟大成就，凝聚广大移交政府安置的军休干部为全面建成小康社会、夺取新时代中国特色社会主义伟大胜利、实现中华民族伟大复兴的中国梦贡献力量的政治热情，根据中央精神，我部决定，在2019年国庆期间举办全国军休干部庆祝新中国成立70周年文艺汇演。现将有关事项通知如下：

一、组织形式及时间安排

文艺汇演分预赛、复赛和决赛三个阶段进行。

（一）预赛阶段（2019年5月前）。

自下发通知之日起，各地要迅速部署、层层发动，将优秀节目自下而上推荐。在此基础上，每个省、自治区、直辖市原则上遴选2-3个节目，录制视频，于5月30日前报送部军休服务管理司。专家评审团队将根据节目的内容、形式和质量，选出优秀节目参加复赛。

（二）复赛阶段（2019年6月）。

复赛采取现场比赛的方式，按照地理位置分南北两个片区举办。

南部片区包括上海、江苏、浙江、安徽、福建、江西、湖北、湖南、广东、广西、海南、重庆、四川、贵州、云南、西藏等16个省（自治区、直辖市）。

北部片区包括北京、天津、河北、山西、内蒙古、辽宁、吉林、黑龙江、山东、河南、陕西、甘肃、青海、宁夏、新疆等15个省（自治区、直辖市）。

（三）决赛汇演阶段（2019年国庆前后）。

决赛在北京市举办。从复赛中选出贴近主题、形式新颖、表现优异的节目，进一步完善后，参加集中决赛汇演。

复赛、决赛具体时间、地点安排等，另行通知。

二、参加人员

节目表演人员以军休干部为主，工作人员可适当参与。参演人员须身体健康、无严重疾病和传染病、能胜任排练和演出，年龄原则上不得超过75岁。

三、节目内容

（一）主题鲜明。突出思想内涵，把文艺汇演与学习宣传贯彻习近平新时代中国特色社会主义思想和党的十九大精神结合起来，大力弘扬以爱国主义为核心的民族精神和以改革创新为核心的时代精神，做到思想性与艺术性相统一。

（二）富有特色。紧密联系军休实际，充分展示军休干部爱党爱国爱军的精神风貌、丰富多彩的老年生活、积极向上的精神状态，努力增强节目吸引力、感染力。

（三）形式多样。节目要力求丰富多彩，喜闻乐见。舞蹈、歌曲、戏曲、器乐演奏类节目，演出时间原则上不超过6分钟；小品、诗歌朗诵类节目，演出时间原则上不超过9分钟。

（四）力求效果。深入挖掘军休优质资源，聘请专业人员进行创作、指导，在节目广度和深度上下功夫，在节目内容和形式上求精湛。

四、奖励办法

为激发军休干部的创作热情，提高节目质量，我部将聘请国家级专业评委根据节目类型进行分组评比。南北两个片区复赛和北京决赛分别设置如下奖项：

（一）歌唱类，包括合唱、独唱、戏曲等，设最佳演唱奖1个，其他为优秀演唱奖。

（二）舞蹈类，包括独舞、群舞等，设最佳表演奖1个，其他为优秀表演奖。

（三）器乐类，包括独奏、重奏、合奏等，设最佳演奏奖1个，其他为优秀演奏奖。

（四）语言类，包括小品、诗歌朗诵等，设最佳表演奖1个，其他为优秀表演奖。

（五）综合类，根据整体表现，评出最佳风格奖、最佳组织奖、最佳创意奖、最佳舞台效果奖等。

五、有关要求

（一）提高认识，加强组织领导。此次文艺汇演，是退役军人事务部门成立后组织的首次全国性军休干部大型活动。各地要高度重视，坚持把文艺汇演作为践行社会主义核心价值观、推进"文化养老"的一项重要内容，摆上议事日程，专题研究部署，扎实做好节目准备和活动组织相关工作。

（二）深入发动，做到广泛参与。各地要在为全国文艺汇演选拔推荐优质节目基础上，督促各军休服务管理机构组织各类文体活动，鼓励广大军休干部踊跃参与，使群众性精神文化生活更加丰富多彩，把庆祝新中国成立70周年推向高潮。

（三）严密组织，确保安全圆满。各地要把安全摆在首位，科学筹划，精心安排，提前做好各种预案。参加活动的军休干部，必须身体健康，征得家属、子女同意。要选派责任心强的工作人员全程陪同，全心照顾好军休干部。

退役军人事务部办公厅
