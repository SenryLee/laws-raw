# 公开市场业务交易公告[2018]第117号——关于人民银行于2018年6月21日以利率招标方式开展了1000亿元逆回购操作的公告

## 公开市场业务交易公告

[2018]第117号

为对冲央行逆回购到期等因素的影响，稳定半年末资金面，人民银行于2018年6月21日以利率招标方式开展了1000亿元逆回购操作，再考虑到央行对金融机构法定准备金付息和临近月末财政开始支出等因素，银行体系流动性总量将进一步走高。

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 600亿元 | 2.55% |
| 14天 | 400亿元 | 2.70% |

中国人民银行公开市场业务操作室

二〇一八年六月二十一日
