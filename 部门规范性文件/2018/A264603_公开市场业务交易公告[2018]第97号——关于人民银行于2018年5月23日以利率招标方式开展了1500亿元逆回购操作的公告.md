# 公开市场业务交易公告[2018]第97号——关于人民银行于2018年5月23日以利率招标方式开展了1500亿元逆回购操作的公告

## 公开市场业务交易公告

[2018]第97号

临近月末财政支出可一定程度对冲央行逆回购到期等因素的影响，为维护银行体系流动性合理稳定，人民银行于2018年5月23日以利率招标方式开展了1500亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 800亿元 | 2.55% |
| 14天 | 700亿元 | 2.70% |

中国人民银行公开市场业务操作室

二〇一八年五月二十三日
