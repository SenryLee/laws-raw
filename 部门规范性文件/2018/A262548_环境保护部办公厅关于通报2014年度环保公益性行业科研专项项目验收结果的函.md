# 环境保护部办公厅关于通报2014年度环保公益性行业科研专项项目验收结果的函

## 关于通报2014年度环保公益性行业科研专项项目验收结果的函

环办科技函〔2018〕356号

2014年度环保公益性行业科研专项各项目承担单位：

根据原国家环保总局《公益性行业科研专项经费管理暂行办法》（环办〔2007〕53号）、《公益性行业科研专项经费环保项目验收规范(试行)》（环科函〔2010〕1号）、《关于进一步加强环保公益性行业科研专项经费项目验收工作的补充通知》（环科函〔2011〕17号）和《环保科研人员信用管理暂行办法》（环科函〔2009〕24号）的有关规定，我部组织开展了2014年度环保公益性行业科研专项项目验收工作，对38个项目的任务完成情况和经费使用情况进行评价。验收结果表明，项目总体完成情况良好，38个项目均按照项目任务书要求完成了研究任务和考核指标，专项经费使用较合理，为我部中心工作和重点任务提供了重要的科技支撑。

为奖优惩劣，加强项目管理，现决定对“北京地区大气臭氧污染特征、发展态势和控制途径研究”等21个产出明显、创新性较强、成果得到应用、总体评价为优的项目提出表扬，项目负责人信用等级评定为优。

希望受表扬的项目单位和负责人再接再厉，继续深化成果应用，做好成果的宣传与普及工作。

请各有关单位高度重视科研项目管理，学习借鉴受表扬项目承担单位和负责人的经验和做法，加强监督管理，规范科研经费使用，强化科研项目产出与应用，做好成果凝练、宣传与科学普及工作，切实发挥科研项目成果对环境管理的支撑作用。
