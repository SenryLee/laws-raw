# 中共教育部党组关于田祖荫、刘锦同志任职的通知

教党任〔2018〕269号

部内各司局、各直属单位：

中共教育部党组2018年11月13日决定，任命田祖荫同志为教育督导局局长、国务院教育督导委员会办公室主任（试用期一年），任命刘锦同志为国际合作与交流司司长。

中共教育部党组

2018年11月27日
