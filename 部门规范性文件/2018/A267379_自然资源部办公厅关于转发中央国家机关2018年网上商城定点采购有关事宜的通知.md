# 自然资源部办公厅关于转发中央国家机关2018年网上商城定点采购有关事宜的通知

自然资办函〔2018〕814号

各预算单位：

根据《中央预算单位2017-2018年政府集中采购目录及标准》（国办发〔2016〕96号），中央国家机关政府采购中心通过公开招标方式确定了2018年网上商城定点供应商，并印发了《关于中央国家机关2018年网上商城定点采购有关事宜的通知》（国机采〔2018〕6号），现转发给你们，请遵照执行。

自然资源部办公厅

2018年7月26日

附件：关于中央国家机关2018年网上商城定点采购有关事宜的通知（国机采[2018]6号）
