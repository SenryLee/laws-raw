# 国家体育总局体操中心关于2019-2020年全国体操赛事和活动招标的通知

## 体育总局体操中心关于2019-2020年全国体操赛事和活动招标的通知

各省、自治区、直辖市体育局竞体处、体操中心，军委训练管理部训练局军事体育处、各有关单位、企业和个人：

为进一步做好我国体操项目赛事和活动的组织工作，我中心于2018年6-7月以公开招标形式确定了2019-2020年全国体操部分赛事的承办单位，剩余赛事由于无人投标导致流标。为保证赛事申办工作的公平透明，我中心现面向全社会，再次以公开招投标形式征集流标的2019-2020年全国体操余下赛事、以及部分体操活动的承办单位，有关事宜具体如下。

一、招标赛事概况

公开招标的赛事和活动是由国家体育总局体操运动管理中心、中国体操协会主办的全国性体操赛事体系中的比赛及全国优秀后备人才训练营。各项赛事和活动具体情况如下：

全国青年体操锦标赛是全国青年最高水平、最高规格的比赛，是青奥会、世青赛、亚青赛等国际重大比赛的选拔赛。全国青年体操冠军赛为全国青年次高水平、次高规格的比赛。以上两项比赛的参赛人员为国内最高水平的青少年体操运动员。青年比赛是全国范围内选拔优秀体操后备人才、培养奥运希望之星的重要比赛。

全国少年体操比赛是全国少年最高水平、最高规格的比赛，参赛人员为男、女9岁以上的高水平少年体操运动员。是全国范围内选拔优秀体操后备人才、培养奥运希望之星的重要比赛。

全国优秀体操后备人才训练营是针对体操项目青少年后备人才开展的体育活动，以国家队教练、专家授课、实践教学、集中训练等为主，目的在于提高青少年体操运动员的技术水平和教练员的执教水平。

二、申办条件及要求

（一）投标人必须是在中华人民共和国境内注册的具有独立法人资格的企业、事业单位或政府部门；

（二）投标人（仅限企业）须为具有承办体育活动许可的独立法人资质的机构，且注册资金不低于人民币500万元；

（三）投标人在近五年内（2013年1月-2017年12月）有类似体育活动组织经验，在人员、设备、资金等方面具有承担招标项目运营的专业能力；

（四）投标人应保证有能力按承办计划提供合格的活动场地、器材等；

（五）投标人应保证有能力协调安排与活动规模相适应的交通、食宿等条件；

（六）各项赛事所需经费不足部分由投标人自筹；投标人近三年财务状况良好，具有足够的资金来承担本项目；

（七）投标人没有任何违法、违规行为；

（八）本项目不接受联合体投标，不接受法人为同一人的两个或两个以上公司投标。

三、申办材料

（一）资信和资质证明（投标企业须提供），包括企业的规模、经济实力、赞助商及媒体等客户服务能力、社会形象和商业信誉方面的整体说明材料。同时需要提交以下材料：

1.有效的营业执照；

2.税务登记证复印件；

3.法人代表或法人授权委托人身份证复印件；

4.近两年经会计师事务所审计过的年度财务报表；

5.当地政府或体育局提供的同意投标公函。

（二）申办报告（需加盖公章）；

（三）承办单位及团队主要人员简介；

（四）活动规划和活动筹备方案；

（五）举办过的体操赛事或活动和其他比赛或活动情况简介，主要运营人员具有大型体育活动经验及能力的证明材料；

（六）对申办赛事或活动的人力、资金和服务的投入承诺；

（七）安全保卫方案和突发事件应急预案。

四、申办材料递交时间、地点

（一）请有意向申办的单位于2018年12月5日前将材料邮寄到以下地址：

国家体育总局体操运动管理中心体操部

地址：北京市东城区体育馆路5号

联系人：杨磊

联系方式：010-67175307

（二）申办材料应密封并在最外层包装上注明申办单位、联系人及联系方式。未在12月5日前递交到达的申办材料不予受理（以邮局邮戳或快递公司邮寄单据上的寄出时间为准）。

五、评标流程

（一）申请承办单位条件审核

我中心收到申办材料后，将对所有有意承办赛事或活动的单位资质进行审核、评估，筛选出符合申办条件的单位。

（二）申请承办单位的选择

1.如果本次招标活动所涉及的各项比赛或活动无单位申请

承办或申办单位均不符合本公告第二条规定的申办条件和要求，则相关比赛或活动招标流标。如果每项比赛或活动符合条件的申办单位超过一家，我中心将组织评标委员会，通过评标产生中标单位。如果每项比赛或活动符合条件的申办单位只有一家，我中心将对其承办条件、能力进行专家论证。

2.同等条件下，具备以下条件者将优先考虑中标：

（1）拟连续两年申办比赛或活动，按照申办比赛或活动级别程度高低（A、B、C）进行排序。

（2）近五年内有过全国体操比赛或活动组织经验者，比赛级别高、办赛效益高（主办方和参赛方评价好、推广宣传比赛和体操项目效果好，有电视转播等）。

（3）申请承办单位的资金投入多者。

（三）申请承办单位的公示

我中心将于12月份对投标产生的承办单位在中国体操协会官方网站进行公示，公示时间待定。公示期为5个工作日，公示内容如下：

1.活动名称；

2.拟中标单位名称。

六、其他

公示结束后，我中心将与无异议的中标单位签订赛事或活动承办协议，商定合作有关事宜，约定双方的权利与义务。
