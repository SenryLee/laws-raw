# 国家煤矿安全监察局关于印发煤矿安全监察执法文书样式、制作规范和模板的通知

煤安监监察〔2018〕35号

各省级煤矿安全监察局：

经国家煤矿安监局局长办公会审议通过，现将修订后的《国家煤矿安全监察执法文书样式》《国家煤矿安全监察执法文书制作规范》和《国家煤矿安全监察执法文书制作模板》予以印发，自2019年1月1日起施行。《国家煤矿安全监察局关于印发国家煤矿安全监察执法文书样式的通知》（煤安监监察〔2016〕14号）、《国家煤矿安全监察局关于印发〈国家煤矿安全监察执法文书制作规范〉和〈国家煤矿安全监察执法文书制作模板〉的通知》（煤安监监察〔2016〕22）同时废止。

附件：

1.国家煤矿安全监察执法文书样式

2.国家煤矿安全监察执法文书制作规范

3.国家煤矿安全监察执法文书制作模板

国家煤矿安全监察局

2018年12月11日
