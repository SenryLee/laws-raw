# 国家文物局办公室关于大明宫遗址炕底寨区域环境整治方案的意见

办保函〔2018〕1027号

陕西省文物局：

你局《关于大明宫遗址炕底寨区域环境整治方案的请示》（陕文物字〔2018〕92号）收悉。经研究，我局暂不同意该项目。

一、对所报项目方案提出以下修改意见：

（一）应补充说明大明宫遗址保护规划涉及该区域的保护规划管理规定，并就项目内容作出符合性说明。

（二）应对相关区域进行全面考古勘探，明确地下遗存埋藏情况，在此基础上完善文物影响评估。

（三）应制订在大明宫保护范围以外进行项目选址建设的比选方案。

（四）进一步补充详细的现存建筑改造设计内容。补充现存建筑结构稳定性评估报告，明确改造依据；补充说明现存建筑总面积及改造建筑所占比例，明确具体改造设计内容及要求，并绘制改造建筑位置详图、设计图及改造前后对比图等；明确改造建筑使用年限及使用年限期满后的处理措施等。

（五）补充说明相关建筑地下管线处理措施，建议采用浅埋处理；如涉及新建，其建筑基础亦需作浅埋处理，地表建筑宜采用轻型结构。

（六）优化建筑设计，根据实际需要合理压缩建筑体量，降低建筑高度，力求与周边环境相协调。

二、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2018年10月24日
