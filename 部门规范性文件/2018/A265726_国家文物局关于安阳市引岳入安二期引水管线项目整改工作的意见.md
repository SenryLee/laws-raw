# 国家文物局关于安阳市引岳入安二期引水管线项目整改工作的意见

文物保函〔2018〕640号

河南省文物局：

你局《关于安阳市引岳入安二期引水管线工程项目选址的请示》（豫文物〔2018〕67号）收悉。经研究，我局意见如下：

一、原则同意安阳市引岳入安二期引水管线项目整改措施和你局意见。

二、请你局组织专业考古研究单位，在项目涉及区域进一步开展全面的考古调查和发掘工作。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

三、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，按照《中华人民共和国文物保护法》第十七条、第十八条的规定，分别报河南省人民政府和城乡建设规划部门批准。

四、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促工程部门切实做好施工过程中的文物保护工作，确保文物安全。

五、请你局督促地方人民政府严格落实《中华人民共和国文物保护法》和固岸墓地保护管理规定，履行文物保护的主体责任，妥善处理文物保护与地方经济发展的关系，确保文物安全。

专此函复。

国家文物局

2018年6月20日
