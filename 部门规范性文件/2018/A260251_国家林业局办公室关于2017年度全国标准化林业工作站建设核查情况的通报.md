# 国家林业局办公室关于2017年度全国标准化林业工作站建设核查情况的通报

办站字〔2018〕4号

各省、自治区、直辖市林业厅（局），新疆生产建设兵团林业局：

为进一步规范标准化林业工作站建设，确保建设质量和成效，全面提升林业站管理服务水平和能力，我局组织开展了2017年度全国标准化林业工作站（以下简称“标准站”）建设核查工作。现将有关情况通报如下：

本次主要核查2015年下达的标准站建设项目。核查对象是已经完成项目建设任务，且在省级林业主管部门向我局提交的检查验收报告中确认合格的乡镇林业工作站。全国纳入核查对象的林业工作站共501个。根据我局标准站建设核查的相关规定，全国共抽取109个核查对象进行了现场核查。合格站平均得分为92.2分。最终确认2017年度全国共有477个林业工作站达到合格标准，授予“全国标准化林业工作站”名称（名单见附件）。

标准站建设是强化基层基础、筑牢林业基石的一项重要举措。地方各级林业主管部门要进一步严把入口关，提高标准站建设成效；要强化检查指导，确保标准站建设质量；要创新思路，积极作为，着力提高基层林业站的管理与服务能力。每个标准站都要以更高的标准要求自己，努力争创优秀标准站，示范带动本系统综合水平继续提升，为实施乡村振兴战略、建设美丽中国做出更大贡献。

附件：2017年度核查合格全国标准化林业工作站名单
