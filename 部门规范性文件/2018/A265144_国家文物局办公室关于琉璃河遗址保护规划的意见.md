# 国家文物局办公室关于琉璃河遗址保护规划的意见

办保函〔2018〕567号

北京市文物局：

你局《关于报审北京〈琉璃河遗址保护规划〉的请示》（京文物〔2018〕217号）收悉。经研究，我局意见如下：

一、暂不同意琉璃河遗址保护规划。

二、所报规划应做以下必要的修改和完善：

（一）应切实加强与考古单位的合作，全面梳理琉璃河遗址已有考古资料，明确遗址分布范围、格局、性质和时代等，在此基础上确定保护对象和重点，为科学编制规划提供依据。

（二）应深化文物价值评估和现状评估内容，说明地上遗存保存现状、大石河与遗址的关系、遗址展示和管理现状等，分析、归纳主要问题和原因。

（三）应根据文物保护管理需要、城镇建设发展现状和地形地貌特征等，综合确定保护区划及管理规定，说明保护范围扩大、建设控制地带分类原因和依据，进一步调整保护区划范围、建设控制地带分类等，增强可操作性。建议将环境协调区调整为建设控制地带，并将大石河纳入保护区划。

（四）应充分考虑琉璃河遗址特点，细化保护措施，调整回填展示、界桩设置等措施强度，避免过度干预。

（五）应结合北京城市功能定位，科学确定琉璃河遗址的展示利用方式，论证建设考古遗址公园思路的可行性，审慎研提设施建设规模、选址和功能等，明确展示内容、主题和游客量控制要求等。

（六）完善专项规划内容，细化村庄搬迁和控制规划，明确搬迁规模、分期和建构筑物高度、色彩、体量等具体控制要求；考古研究规划应重点明确遗址分布范围、格局和价值内涵，以考古调查勘探为主，明确具体工作任务和实施分期；补充大石河整治、土地性质调整、人口调控等具体内容。

三、请你局指导规划编制单位联合专业考古研究单位，根据上述意见对琉璃河遗址保护规划做进一步修改和完善后，按程序另行报批。

专此函复。

国家文物局办公室

2018年6月6日
