# 中共教育部党组关于葛世荣、杨仁树同志职务任免的通知

教党任〔2018〕189号

中共中国矿业大学（北京）委员会：

经与中共北京市委商得一致，2018年9月21日研究决定：

葛世荣同志任中共中国矿业大学（北京）委员会委员、常委、副书记；免去杨仁树同志的中共中国矿业大学（北京）委员会副书记、常委、委员职务。

中共教育部党组

2018年9月25日
