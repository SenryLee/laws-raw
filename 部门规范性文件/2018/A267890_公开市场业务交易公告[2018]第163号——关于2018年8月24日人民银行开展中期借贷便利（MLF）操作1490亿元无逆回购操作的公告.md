# 公开市场业务交易公告[2018]第163号——关于2018年8月24日人民银行开展中期借贷便利（MLF）操作1490亿元无逆回购操作的公告

## 公开市场业务交易公告

[2018]第163号

为对冲政府债券发行缴款、央行逆回购到期等因素的影响，加强货币政策与财政政策的协调配合，维护银行体系流动性合理充裕，2018年8月24日人民银行开展中期借贷便利（MLF）操作1490亿元，无逆回购操作。

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 1年 | 1490亿元 | 3.30% |

中国人民银行公开市场业务操作室

二〇一八年八月二十四日
