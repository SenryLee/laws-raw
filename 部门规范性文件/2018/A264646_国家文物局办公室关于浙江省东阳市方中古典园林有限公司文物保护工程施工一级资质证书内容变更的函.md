# 国家文物局办公室关于浙江省东阳市方中古典园林有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2018〕431号

浙江省文物局：

你局《关于浙江省东阳市方中古典园林有限公司要求办理文物保护工程资质证书变更的请示》（浙文物发〔2018〕125号）收悉。

经研究，我局同意浙江省东阳市方中古典园林有限公司文物保护工程施工一级资质证书中的经济性质由“有限责任公司”变更为“私营有限责任公司（自然人控股或私营性质企业控股）”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2018年5月15日
