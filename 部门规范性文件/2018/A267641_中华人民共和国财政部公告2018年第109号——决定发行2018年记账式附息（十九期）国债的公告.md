# 中华人民共和国财政部公告2018年第109号——决定发行2018年记账式附息（十九期）国债的公告

## 中华人民共和国财政部公告

2018年第109号

根据国家国债发行的有关规定，财政部决定发行2018年记账式附息（十九期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

一、本期国债计划发行410亿元，实际发行面值金额410亿元。

二、本期国债期限10年，经招标确定的票面年利率为3.54%，2018年8月16日开始计息，招标结束后至8月16日进行分销，8月20日起上市交易。

三、本期国债为固定利率附息债，利息按半年支付，利息支付日为每年的2月16日、8月16号（节假日顺延，下同），2028年8月16日偿还本金并支付最后一次利息。

其他事宜按《中华人民共和国财政部公告》（2018年第2号）规定执行。

特此公告。

中华人民共和国财政部

2018年8月15日
