# 公开市场业务交易公告[2018]第107号——关于2018年6月6日人民银行开展MLF操作4630亿元对冲到期后MLF余额新增2035亿元无逆回购操作的公告

## 公开市场业务交易公告

[2018]第107号

为维护银行体系流动性合理稳定，同时进一步加大对小微企业、绿色经济等领域的支持力度，促进信用债市场健康发展，在2018年6月1日宣布适当扩大中期借贷便利（MLF）担保品范围的基础上，2018年6月6日人民银行开展MLF操作4630亿元，对冲到期后MLF余额新增2035亿元。当日无逆回购操作。

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 1年 | 4630亿元 | 3.30% |
