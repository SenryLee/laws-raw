# 国家烟草专卖局办公室关于印发2018年政务公开工作要点的通知

国烟办新〔2018〕234号

行业各直属单位，国家局、总公司机关各部门、各单位：

现将《国家烟草专卖局2018年政务公开工作要点》印发给你们，请认真贯彻执行。

国家烟草专卖局办公室

2018年6月8日

## 国家烟草专卖局2018年政务公开工作要点

烟草行业2018年政务公开工作，要全面贯彻党的十九大和十九届二中、三中全会精神，以习近平新时代中国特色社会主义思想为指导，深入落实党中央、国务院关于全面推进政务公开工作的系列部署，坚持统筹兼顾、突出重点，大力推进决策、执行、管理、服务、结果公开，注重解读回应，提升服务实效，优化平台建设，强化制度保障，不断提升政务公开的质量和效率，助力烟草行业稳中向好发展。

一、主动做好公开解读回应工作

（一）围绕重点领域加强信息公开。抓好政府采购、工程建设项目招标投标等公共资源配置领域政府信息公开制度的贯彻落实。逐步公开采购项目公告、采购文件等采购项目信息，有关投诉和监督检查等处理决定，违法失信行为记录等监督处罚信息。加大涉及公共利益、公众权益的政策文件等相关信息公开力度，使政策执行更加阳光透明。继续做好人大代表建议和政协委员提案办理结果公开。把重点领域信息公开纳入主动公开基本目录，持续加以推进。在政府信息公开工作年度报告中公布重点领域信息公开情况，接受社会监督。加强“双随机、一公开”监管，多渠道全方位及时公开综合监管和检查执法信息，提高监管效能和公正性，增强监管威慑力和公信力。

（二）围绕稳定市场预期加强政策解读。牢牢把握推动高质量发展的根本要求，聚焦供给侧结构性改革主线，围绕贯彻新发展理念、全面深化改革、强化专卖管理、服务脱贫攻坚、履行全面从严治党主体责任等重大部署，解读好相关政策措施、执行情况和工作成效，服从和服务于“五个大局”，引导市场预期，赢得群众的理解和支持。落实信息发布主体责任，主动召开新闻发布会、吹风会，深入解读政策背景、重点任务、后续工作考虑等，及时准确传递权威信息和政策意图。对一些专业性较强的政策，牵头起草部门要注重运用客观数据、生动实例等，进行形象化、通俗化解读，把政策解释清楚，避免误解误读，为推动政策落实营造良好环境。

（三）围绕社会重大关切加强舆情回应。增强舆情风险防控意识，密切监测收集苗头性舆情，针对涉及行业管理体制、生产经营活动等的误导和不实信息，做到及时预警、科学研判、妥善处置、有效回应。加强与宣传、网信、公安、通信管理等部门的协调，加强与新闻媒体的沟通，提高政务舆情回应的主动性、针对性、有效性。稳妥做好突发事件舆情回应工作，及时准确发布权威信息。开展政务舆情应对工作效果评估，建立问责制度，对重大政务舆情处置不得力、回应不妥当、报告不及时的责任单位及相关责任人员，要予以通报批评或约谈整改。

二、用好线上线下政务服务平台

（四）深入推进网上办事服务公开。按照《国务院关于加快推进“互联网+政务服务”工作的指导意见》（国发〔2016〕55号）要求，借鉴推广“不见面审批”等典型经验和做法，不断创新服务方式，优化营商环境，为市场主体添活力，为人民群众增便利。进一步推动行政许可事项网上办理，实现办事材料目录化、标准化，让群众办事更明白、更便捷。依据国务院各部门信息共享机制，推进行业有关行政许可信息纳入国家统一平台，减少循环证明和重复证明。逐步稳妥推进省级局与地方政府网站信息系统的互联互通。按照国办政务信息系统整合共享重点任务落实方案的要求，完善烟草行业政务信息资源整合共享系统，集成整合各类政务信息资源，为政府网站实现政务信息资源共享、业务协同和数据服务奠定基础。建立完善网民留言、咨询的受理、转办和反馈机制，及时处理答复，为群众提供更好服务。

（五）不断提升实体政务大厅服务能力。加强实体政务大厅建设管理，推动线下线上融合，统筹服务资源，统一服务标准，理顺工作机制，强化部门协调，群众和企业必须到现场办理的事项力争“只进一扇门”、“最多跑一次”。加强实体政务大厅软硬件设施配备，优化力量配置，做好人员、设施、经费保障。建立完善激励约束制度，加强工作人员管理，严肃纪律作风，规范服务行为，切实提高服务效率和质量。

（六）持续优化审批办事服务。注重核实公开的行政许可事项服务信息是否准确规范、与实际工作是否一致等，发现问题及时督促整改。清理并公开行政许可事项办理需要提供的各类证照、证明材料，没有法律法规依据的一律取消。不断完善行政许可事项服务指南，服务指南之外不得增加其他要求。实行线上线下办事服务信息同源管理，建设和使用统一的咨询问答知识库、政务服务资源库，确保线上线下办事服务信息内容准确一致，方便群众和企业办事。

三、持续优化政务平台建设

（七）强化政府网站建设管理。认真落实《政府网站发展指引》（国办发〔2017〕47号），整合政务信息资源，完善政务服务功能，畅通政民互动渠道，逐项落实重点任务。加强政府网站内容建设，继续办好信息公开、政策解读、回应关切等栏目，为公众提供更及时更准确的信息服务。继续加强常态化监测，确保季度抽查合格达标。开展行业政府网站创新发展试点工作，形成一批适应行业高质量发展的网站样板。优化行业网站绩效考评体系，不断提高行业网站管理服务水平。完善政府网站安全保障机制，做好防攻击、防篡改、防病毒、防瘫痪、防泄密等工作。建立健全政府网站用户信息保护制度，确保用户信息安全。

（八）用好各类政务服务新平台。充分发挥微博、微信、移动客户端灵活便捷的优势，做好信息发布、政策解读和办事服务工作，进一步增强公开实效，提升服务水平。按照“谁开设、谁管理”的原则，落实主体责任，严格内容审查把关，不得发布与职能没有直接关联的信息，信息发布失当、造成不良影响的要及时整改。加强“两微一端”日常监管和维护，对维护能力差、关注用户少的可关停整合。按照《国务院办公厅关于做好政府公报工作的通知》（国办发〔2018〕22号）要求，指定专人负责，建立工作机制，推动政府公报工作规范有序开展。

四、贯彻落实政府信息公开条例

（九）修订完善政府信息公开工作办法。在《中华人民共和国政府信息公开条例》修订颁布后，进一步修订完善我局政府信息公开工作办法。对照条例要求全面梳理应当主动公开的政府信息，未公开的要及时向社会公开。进一步做好依申请公开工作，建立健全接收、登记、办理、答复等流程，依法保障公民、法人和其他组织获取政府信息的权利。

（十）加强政府信息公开审查工作。政府信息公开前要依法依规严格审查，特别要做好对公开内容表述、公开时机、公开方式的研判，避免发生信息发布失信、影响社会稳定等问题。要依法保护好个人隐私，除惩戒公示、强制性信息披露外，对于其他涉及个人隐私的政府信息，公开时要去标识化处理，选择恰当的方式和范围。

（十一）修订完善信息公开目录。进一步丰富信息公开内容，及时更新并对外发布主动公开目录，有效扩大信息公开的影响力。目录编制要充分体现“五公开”、政策解读、舆情回应、公众参与等要求。

行业各直属单位要参照本要点，结合本单位实际，认真抓好落实。要进一步加强政务公开工作能力建设，围绕贯彻落实新条例、政策解读、政务舆情回应等，抓好业务学习培训。国家局将加强相关工作的督促检查和考核评估。
