# 中共教育部党组关于张宗益、周绪红同志职务任免的通知

教党任〔2018〕9号

中共重庆大学委员会：

经与中共重庆市委商得一致，2017年12月27日研究决定：

张宗益同志任中共重庆大学委员会副书记，免去张宗益同志的中共重庆大学委员会常务副书记、周绪红同志的中共重庆大学委员会副书记、常委职务。

中共教育部党组

2018年1月8日
