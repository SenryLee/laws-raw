# 中共应急管理部党组关于认真学习贯彻落实《关于进一步激励广大干部新时代新担当新作为的意见》的通知

应急党〔2018〕5号

各省级煤矿安全监察局党组，应急管理部机关各司局、国家煤矿安全监察局机关各司室、驻部纪检组、消防局、国家安全生产应急救援指挥中心及各直属事业单位、社会组织党委（总支、支部）：

近日，中共中央办公厅印发了《关于进一步激励广大干部新时代新担当新作为的意见》（以下简称《意见》）。为认真学习贯彻落实《意见》精神，营造干事创业、风清气正的良好政治生态，加快推进应急管理事业改革发展，现就有关事项通知如下：

一、充分认识《意见》的重大意义，深刻领会精神实质

《意见》深入贯彻习近平新时代中国特色社会主义思想和党的十九大精神，面向新时代、顺应新形势、落实新要求、聚焦新问题，坚持严管和厚爱结合、激励和约束并重，以有效调动广大干部干事创业的活力和动力为主线，以解决干部不想为、不能为、不敢为等现实问题为重点，从七个方面提出了明确要求，是建立激励机制和容错纠错机制的基本遵循，是建设高素质专业化干部队伍的重大举措，对于充分调动和激发干部队伍的积极性、主动性、创造性，以奋发有为、昂扬向上的工作热情投入应急管理事业，为决胜全面建成小康社会、夺取新时代中国特色社会主义伟大胜利、实现中华民族伟大复兴的中国梦不懈奋斗，具有十分重要的现实意义。

各级党组织要认真组织好《意见》的学习宣传贯彻工作，结合深入学习贯彻习近平新时代党建思想，通过集中研讨、学习交流等多种形式，深刻领会《意见》出台的重要意义，全面把握精神实质，切实增强贯彻落实的政治自觉和责任自觉，努力建设一支忠诚、干净、担当的应急管理干部队伍，凝聚起干事创业的强大合力，加快构建统一领导、权责一致、权威高效的国家应急能力体系，为国家长治久安、人民幸福安康提供有力保障。

二、认真贯彻落实《意见》精神，形成干事创业的良好政治生态

（一）锤炼对党绝对忠诚的政治品格。只有对党绝对忠诚，才能真正为党分忧、为党担责、为党尽责。各单位党组织要加强干部思想教育，引导广大干部强化“四个意识”，坚定“四个自信”，坚决维护习近平总书记在党中央和全党的核心地位，坚决维护以习近平同志为核心的党中央权威和集中统一领导。从中华民族长远发展和实现“两个一百年”奋斗目标的战略高度，深刻认识肩负的重大使命，满怀激情地投入应急管理事业中，用行动和担当诠释对党的绝对忠诚。

（二）以认真务实的精神解决干部思想问题。各单位党组织要采取“三会一课”、民主生活会等方式，组织党员干部认真学习、深入讨论，结合本单位和个人实际，真正把自己摆进去、把思想摆进去，认真查摆存在的突出问题和不正之风，深入剖析干部干事顾虑重重、畏手畏脚的思想根源，研究制定针对性落实措施，真正解决干部不想为、不能为、不敢为的思想问题。

（三）树立重实干重实绩的用人导向。坚持好干部标准，结合机构改革，拓宽用人视野、扩大选人范围，突出实践实干实效，大力选拔敢于负责、勇于担当、善于作为、实绩突出的干部，让想干事、能干事、干成事的干部有机会有舞台。对个性鲜明、坚持原则、敢抓敢管、不怕得罪人的干部，符合条件的要大胆使用；对不担当不作为的干部，根据具体情节该免职的免职、该调整的调整、该降职的降职，使能上能下成为常态。

（四）大力弘扬正气。全面贯彻落实习近平总书记“三个区分开来”的重要指示，建立健全容错纠错机制，旗帜鲜明为敢于担当负责的干部撑腰鼓劲。及时为受到不实反映的干部澄清正名、消除顾虑，坚决纠正坐而论道、说三道四等不正之风，坚决整治无中生有、诽谤诬告等歪风邪气。完善干部考核评价机制，切实解决干与不干、干多干少、干好干坏一个样的问题，使政治坚定、奋发有为的干部得到褒奖和鼓励，使慢作为、不作为、乱作为的干部受到警醒和惩戒，努力构建风清气正的良好政治生态。

（五）注重宣传先进典型。注意挖掘和发现推进应急管理事业中改革创新、干事创业的先进典型，充分运用中国应急管理报、应急管理部政府网站和党建工作简报、党建信息管理网等媒体平台，大力宣传先进事迹和工作业绩，发挥示范引领作用，激励广大干部见贤思齐、奋发有为，为应急管理事业改革发展不懈奋斗。

三、抓住领导干部“关键少数”，切实发挥示范表率作用

（一）带头学习贯彻。各级领导干部要通过党组（党委）中心组学习、专题研讨等方式，对《意见》精神先学一步、学深一步。结合庆祝建党97周年，7月份以“新时代新担当新作为”为主题，各单位党组织书记要集中开展讲党课活动，深入理解和贯彻《意见》精神，充分调动和激发党员干部参与机构改革、投身应急事业的积极性、主动性、创造性。

（二）带头严抓敢管。领导干部要旗帜鲜明支持保护担当者、鼓励褒奖有为者。加强干部日常监督管理，及时提醒、“咬耳扯袖”，确保不出事、干成事。对不正之风要敢于斗争，对不良和失实言论要敢于批评纠正，坚决不能让其发酵升级、败坏风气。要坚持严格管理与关心爱护相结合，真诚为干部成长着想，真心解决实际问题，让干部安心、安身、安业。

（三）带头担当作为。领导干部要切实发挥“头雁”效应，以身作则、率先垂范，在应急管理工作实践中要亲力亲为、上心上手，勇于担当、积极作为，带头承担责任，日常工作兢兢业业，关键时刻冲锋在前，带动广大干部职工切实履行职责，当好党和国家的“守夜人”，坚决维护广大人民群众生命财产安全和社会稳定。

各单位学习贯彻《意见》情况和建议，要及时报应急管理部党组。

中共应急管理部党组

2018年5月30日
