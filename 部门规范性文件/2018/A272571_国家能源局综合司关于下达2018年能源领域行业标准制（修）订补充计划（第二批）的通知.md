# 国家能源局综合司关于下达2018年能源领域行业标准制（修）订补充计划（第二批）的通知

国能综通科技〔2018〕191号

各有关单位：

附件：2018年能源领域行业标准制（修）订补充计划（第二批）项目汇总表
