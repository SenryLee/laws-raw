# 自然资源部办公厅关于进一步做好应急测绘保障工作的通知

自然资办函〔2018〕1946号

各省、自治区、直辖市自然资源主管部门，新疆生产建设兵团自然资源主管部门，部直属有关单位，部机关各司局：

应急测绘是为各类突发公共事件提供地理信息和现代测绘技术的基础支撑，是国家突发事件应急体系的重要组成部分，是指挥决策和抢险救灾的保障和依据。目前，各地机构改革基本到位，各地区各单位要按照“连续、稳定、转换、创新”的要求，进一步做好应急测绘保障工作。现就有关事项通知如下：

一、连续稳定，持续做好应急测绘保障服务

做好应急测绘保障工作是《测绘法》明确的法定职责，提供应急测绘保障是自然资源管理部门“三定”重要职责。在机构改革的过渡时期，各地区各单位要确保应急测绘保障工作不断、节奏不乱，坚持发挥测绘地理信息专业优势，持续提供应急测绘保障服务。一要提前做好数据准备。针对本地区多发易发灾害类型、时间和特点，提前收集、整理重点防范地区的各类专题信息和测绘成果资料，有针对性地组织制作各种专题测绘产品，超前部署、提前研判，积极做好应对准备。二要积极配合灾情预警。充分发挥地理信息数据资源优势、技术优势和人才队伍优势，积极配合开展灾害隐患排查和监测预警，为研判灾情、决策部署提供测绘地理信息成果和技术支持。三要主动提供保障服务。灾情一旦发生，要立即启动应急测绘保障预案，开通成果提供绿色通道，主动与本地区政府部门或应急管理部门沟通联系并保持信息畅通，积极提供已有适用的各类测绘地理信息，并根据有关方面的实际需求和要求，及时开展航空摄影信息获取、实地测绘、数据处理和加工制作、地理信息系统研发等。

二、提升能力，完善应急测绘保障工作机制

国家应急测绘保障能力建设项目将于2019年底完成，航空应急测绘、应急现场勘测、应急快速集成处理与分发服务以及应急测绘地理信息资源共享等系统即将建成并投入使用，与此相适应的应急测绘保障工作机制亟需同步规划建设。一要根据机构调整和人员岗位变动情况，尽快调整重组本地区本单位应急测绘保障领导和办事机构，统筹协调本地区本单位应急测绘保障工作。二要结合目前工作实际，注重与国家及地方有关应急预案的衔接，适时修订本地区本单位应急测绘保障预案和工作流程。三要积极开展技术研发和队伍建设。加强技术攻关，提高应急地理信息获取、处理、制作、研发和快速出图等能力。组织应急管理理论知识和测绘高新技术等培训，开展应急保障演练，选调优秀人员充实应急测绘专业人才队伍，提高应急测绘保障队伍的素质和能力。四要加强宣传。重视信息报送，应急测绘保障情况及时报送当地政府，同时报我部地理信息管理司。要通过门户网站，主动、及时发布可公开的灾区影像和地图信息，帮助公众全面、准确了解灾情，理性应对灾害。通过网络、报纸等各类公众媒体适时进行宣传报道，在全社会积极营造了解支持应急测绘保障工作的良好氛围。

三、找准定位，积极发挥应急测绘保障作用

应急测绘是为应对自然灾害、事故灾难、公共卫生事件、社会安全事件等突发公共事件提供高现势性、高可靠性、高效率地理信息成果和技术支撑的基础性工作，不是独立的专项应急工作，各单位要与系统内、部门间、军队以及社会紧密协作，满足相关部门的需要，更好地发挥作用。一要加强系统内部沟通协调，树立全国“一盘棋”意识，与上下级部门保持畅通无阻的信息沟通联系渠道，注重协同配合开展应急测绘工作。根据应急工作需要，及时向国家申请数据资源支持，统筹协调跨地区、跨区域装备和队伍支持，确保积极有力提供应急保障。二要理顺军地、部门间应急测绘保障联动协作机制。与有关应急主管部门、军队有关单位签署合作共享协议，建立军地合作、部门联动的应急测绘保障服务机制和应急地理信息资源共享机制，形成应急信息互联互通、应急资源共建共享、优势互补、协同高效的应急测绘保障服务体系，拓展应急测绘保障的广度和深度。三要充分发挥社会力量。鼓励企业积极参与应急测绘工作，建立有效的应急测绘保障社会动员机制，将有关企业纳入应急测绘保障服务体系，鼓励和引导其在应急测绘中发挥积极作用。

各地区各单位要增强大局意识、责任意识，站在维护人民群众生命财产安全和国家安全的高度，充分认识做好应急测绘保障工作的重要性和必要性，进一步提高工作敏感性，高度重视、加强领导，切实抓紧抓好抓实应急测绘保障工作。

为保证应急测绘保障工作连续性，请各地区各单位分别于2018年12月31日前将应急测绘工作负责人及联络员（见附表）、2019年1月20日前将2018年度应急测绘保障工作开展情况报我部地理信息管理司。
