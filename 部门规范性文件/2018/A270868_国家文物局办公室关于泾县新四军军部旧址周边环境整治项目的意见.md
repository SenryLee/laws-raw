# 国家文物局办公室关于泾县新四军军部旧址周边环境整治项目的意见

办保函〔2018〕1072号

安徽省文物局：

你局《关于审核泾县新四军军部旧址周边环境整治方案的请示》（皖文物保〔2018〕76号）收悉。经研究，我局认为所报“方案”未与《新四军军部旧址文物保护规划》有关文物保护区划的管理规定相对应，“文物影响评估报告”未对环境整治项目的合理性及其实施对文物本体及环境的扰动进行评估，我局暂不同意该环境整治方案。

请你局指导有关单位严格按照《新四军军部旧址文物保护规划》的要求，科学设计环境整治的目标和措施，认真做好文物影响评估，重新编制环境整治方案，按程序另行报批。

专此函复。

国家文物局办公室

2018年11月6日
