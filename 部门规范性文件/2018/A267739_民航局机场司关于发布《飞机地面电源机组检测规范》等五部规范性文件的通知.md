# 民航局机场司关于发布《飞机地面电源机组检测规范》等五部规范性文件的通知

民航各地区管理局，各运输航空公司，各机场公司，各有关民用机场专用设备检验机构、制造商：

为规范有关民用机场专用设备检测工作，我司组织编写了《飞机地面电源机组检测规范》（AC-137-CA-2018-01）、《飞机地面静变电源检测规范》（AC-137-CA-2018-02）、《飞机地面空调机组检测规范》（AC-137-CA-2018-03）、《飞机充氧设备检测规范》（AC-137-CA-2018-04）和《机场特种车辆底盘检测规范》（AC-137-CA-2018-05），现发布施行。

在执行过程中，各单位如有意见建议，请及时函告我司。有关电子文档可在民航局政府网站机场司子站“标准资质”一栏下载，也可在民用机场专用设备信息管理系统“标准规范”一栏下载。

民航局机场司

2018年8月7日

附件：

《飞机地面电源机组检测规范》（AC-137-CA-2018-01）

《飞机地面静变电源检测规范》（AC-137-CA-2018-02）

《飞机地面空调机组检测规范》（AC-137-CA-2018-03）

《飞机充氧设备检测规范》（AC-137-CA-2018-04）

《机场特种车辆底盘检测规范》（AC-137-CA-2018-05）
