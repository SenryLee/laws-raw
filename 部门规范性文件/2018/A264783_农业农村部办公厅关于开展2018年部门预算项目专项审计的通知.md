# 农业农村部办公厅关于开展2018年部门预算项目专项审计的通知

农办财〔2018〕45号

各有关单位：

为进一步规范部门预算项目管理实施，提高项目资金使用效益，根据我部部门预算项目专项审计有关管理规定，2018年我部拟对“农产品质量安全监管（国家农产品质量安全县创建）”等3个部门预算项目进行专项审计。现将有关事项通知如下：

一、审计项目和内容

（一）对“农产品质量安全监管（国家农产品质量安全县创建）”项目和“物种品种资源保护费”项目进行资金使用情况审计

对黑龙江、辽宁、江苏、浙江、福建、江西、湖北、湖南、广东、广西、海南、四川、云南、陕西、新疆等15个省（自治区）农业部门组织实施的“农产品质量安全监管（国家农产品质量安全县创建）”“物种品种资源保护费”2个部门预算项目进行专项审计。主要审计2016—2017年度项目的管理制度建设与执行情况、项目实施及完成情况、项目资金的收支与核算情况、项目绩效目标实现情况、项目有关的财务审计检查整改落实情况等。

（二）对“海洋渔业资源调查与探捕”项目进行绩效审计

对有关单位2017年承担实施的“海洋渔业资源调查与探捕”项目进行绩效审计。主要审计项目决策与组织实施情况、项目资金使用和管理情况、项目绩效指标设置与实现情况、项目绩效过程管理情况等。

二、审计人员和时间安排

由我部财务司和相关项目管理司局组成审计组进行审计。现场审计时间为2018年6月上旬至7月中旬，各单位审计的具体时间，我部将于审计进驻前分别另行通知。

三、其他事项

（一）各有关单位要高度重视，密切配合此次专项审计，及时提供有关资料（含电子数据）和必要的工作条件。

（二）对审计中发现的问题，有关单位要认真整改，并及时报送审计整改情况。审计组将结合此次审计，对以前年度专项审计反映问题的整改情况进行回访检查。

（三）各有关单位收到本通知后，请确定1名审计联系人，并将姓名、职务、联系方式于6月1日前传真至我部。
