# 国家文物局关于辉发城址保护规划的意见

文物保函〔2018〕179号

吉林省文物局：

你局《关于报送〈吉林省辉南县辉发城址文物保护规划〉的请示》（吉文物发〔2017〕101号）收悉。经研究，我局意见如下：

一、原则同意辉发城址保护规划。

二、所报规划应更名为《辉发城址保护规划》，考虑将环境协调区变更为二类建设控制带的可能性，并进一步完善保护措施，增强针对性和适用性。同时，应校核规划文本，做到科学准确，并提高图纸精度。

三、请你局指导地方人民政府组织规划编制单位和专业考古研究单位，按照上述意见对规划进行必要的修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》的要求，将经我局备案的辉发城址保护规划报请吉林省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府切实加强辉发城址的保护和管理工作，加强专门保护管理机构建设，完善专项管理法规，并提出具体实施步骤和保障措施，妥善解决土地用途调整、道路调整、居民搬迁以及环境整治等问题，确保规划顺利实施。

国家文物局

2018年2月26日
