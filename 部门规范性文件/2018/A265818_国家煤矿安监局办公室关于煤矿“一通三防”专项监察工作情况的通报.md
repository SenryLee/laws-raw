# 国家煤矿安监局办公室关于煤矿“一通三防”专项监察工作情况的通报

煤安监司办〔2018〕8号

各省级煤矿安全监察局：

现将2018年度煤矿“一通三防”专项监察开展情况通报如下：

一、开展情况

按照国家煤矿安监局统一部署，从2018年2月至5月，各省级煤矿安监机构（以下简称“省局”）开展了为期4个月的煤矿“一通三防”专项监察，取得了较好效果。截至5月底，全国共发生瓦斯事故6起、死亡22人，同比减少3起、27人，分别下降33.3%和55.1%；没有发生重特大瓦斯事故，同比减少2起、22人；较大事故同比减少1起、5人。

（一）严格监察执法，加大处罚力度。截至5月底，全国共开展监察2975矿次、监察矿井2814处，占全国矿井总数的41.2%，完成了突出矿井、复产复工矿井及3年内发生事故矿井全覆盖。查处一般隐患3.2万条、重大隐患219条，其中移送地方督办166条，实施行政处罚1622次、罚款18723.79万元，责令停产整顿矿井122矿次，停止采掘作业工作面984个，停止使用相关设施设备1792个（台），暂扣安全生产许可证158处，下达执法文书14924份，提请关闭矿井4处。

其中，12个开展异地交流执法的省局共监察矿井61处，查处一般隐患989条、重大隐患6条，实施行政处罚70次、罚款664.1万元，责令停产整顿矿井5处，停止采掘作业面31个，停止使用设备设施13个（台），暂扣安全生产许可证3处，下达执法文书146份。

（二）强化组织领导，细化专项监察方案。各省局认真落实有关要求，主要领导亲自负责，组织研究专项监察各项工作部署，编制专项监察方案，集中专业监察人员，带队开展监察，保障了本地区专项监察顺利实施。内蒙古局成立了由局领导任组长的4个专项督查组，结合实际把监察内容细化为表格，针对不同情况制定了针对性监察方案。安徽局把“一通三防”重大风险管控清单制定、管控措施及以往问题整改等8个方面列为必查内容，确定了“8+8”项必查内容，督促问题整改落实。河南局结合实际提出了“三个明确”：明确监察内容及工作要求、明确监察时间阶段安排、明确异地交流执法工作安排；认真做到“三个严格”：严格开展专项监察集中执法、严格开展专项监察异地交流执法、严格督促各分局开展专项监察。

（三）突出工作重点，提高监察执法效能。始终抓住煤矿重大隐患，对重点企业、重点矿区和重点部位进行了全覆盖监察，强化了监察效果。安徽局对煤矿“三不”问题（安全责任制不落实、重大风险管控不力、现场管理不到位），采取“四丢”措施（丢面子、丢票子、丢帽子、丢饭碗），依法按上限处罚。河北局创新监察执法手段，充分利用执法终端和多参数报警信息矿灯，实现对安全隐患的现场取证；通过购买专业服务对矿井安全监控系统电源质量、软件功能、双机切换等进行检查检测，现场试验采掘工作面甲烷传感器的故障闭锁、超限断电功能，对突出矿井采掘工作面瓦斯参数进行现场实测。江苏局有针对性地开展“零点行动”（凌晨下井监察），重点检查灾害严重采掘头面等场所安全状况和人员定位、监测监控等系统运行情况。

（四）加强异地执法，学习交流监察经验。开展异地交流执法的各省局均由局领导带队，抽选本省精干监察力量组成检查组，与被检查省局沟通协调，共同制定执法工作方案，执法检查中坚持高标准、严要求，执法后及时分析总结经验和不足，相互学习借鉴。山西煤监局抽调2名专家型监察员和3名专家组成检查组赴贵州交流执法，监察矿井5处，共查出各类隐患97条（其中重大安全隐患4条），责令2个采煤工作面、7个掘进工作面停止作业，实施行政罚款109万元，责令2处矿井停产整顿并暂扣安全生产许可证。陕西局在云南开展异地交流执法后，云南局及时组织全体监察员召开专题座谈会，学习、借鉴陕西局好的工作经验和方法，各分局根据学习成果，组织全体人员参与开展解剖式监察。

（五）严格责任追究，狠抓责任落实。各省局严格对标对表，逐条逐项深入检查，对查出的问题隐患不讲情面、不留余地，对存在重大隐患的矿井给予责令停产整顿和大额罚款等严厉处罚，处理了一批存在严重违法违规行为的煤矿企业和主要负责人，起到了有力的震慑作用。山东局强化隐患责任倒查，严格责任追究，既追究煤矿相关责任人，又追究集团公司相关责任人。安徽局采取严肃事故问责、强化企业监管等两个4项措施，针对人为造成工作面监控传感器失效、工作面回风系统不独立和瓦斯抽采钻孔涉嫌造假等问题，分别对淮南矿业集团张集煤矿、邹庄煤矿，皖北煤电公司祁东煤矿实施了50万元以上经济处罚，并约谈了淮南矿业集团、皖北煤电集团分管安全负责人、安全管理职能部门负责人和有关煤矿矿长。宁夏局针对神华宁煤集团红柳煤矿故意隐瞒掘进工作面问题罚款214万元并责令停产整顿，对主要负责人罚款14.9万元。

二、存在的主要问题

通过专项监察，发现煤矿“一通三防”工作还存在诸多问题，通风管理和瓦斯防治等方面基础依然薄弱，必须引起高度重视。

（一）“一通三防”事故隐患仍大量存在。专项监察查处的3.2万条一般隐患中，矿井通风管理不落实4299项、占13.81%，安全监控系统运行不正常3462项、占11.12%，防尘措施落实不到位2768项、占8.89%，瓦斯防治制度不落实2332项、占7.49%，矿井防灭火施落实不到位2042项、占6.56%，防突措施不落实1272项、占4.09%。矿井通风管理、安全监控系统运行、瓦斯综合防治等问题突出。

（二）采掘失调、接续紧张对矿井通风系统和瓦斯综合治理影响大。部分煤矿抽、掘、采失衡，造成通风系统不合理、不稳定，存在违规串联通风、风量不足、风速超限等问题，甚至采取剃头下山开采，如河北省大社矿、黑龙江双鸭山市和平煤矿、鸡西煤业宝来煤矿部分巷道和硐室风流紊乱或未实现独立通风。部分煤矿采掘不合理，不能保证瓦斯抽采时间和空间，瓦斯综合治理措施难于落实，抽采不达标，进而在钻孔施工、突出危险性预测、效果检验等各环节造假，冒险进行采掘作业，造成瓦斯超限。

（三）“一通三防”技术管理、现场管理滑坡。部分煤矿防突设计、防火设计、作业规程、瓦斯抽采达标评判报告、矿井瓦斯地质图等编制不规范，内容不完善。部分煤矿采掘工程平面图、通风系统图、监控系统图等图纸绘制不规范、填绘不准确。部分煤矿瓦斯抽采钻孔施工质量差，达不到设计要求、留有空白带。部分煤矿瓦斯检查制度执行不严格，瓦斯日报、班报、瓦斯记录牌板填写不规范。部分煤矿开采自燃甚至容易自燃煤层未按照防灭火专项设计要求实施防灭火措施，束管监测系统不能正常使用，如河北开滦集团崔家寨矿开采自燃煤层未按防止自然发火设计组织生产，黑龙江新安煤矿、双阳煤矿、新陆煤矿束管监测系统不能正常使用。部分煤矿防尘、降尘设施失效，不按规定定期清扫、冲洗沉淀煤尘、造成煤尘堆积。

（四）安全监控系统运行不正常。部分煤矿安全监控系统传感器不按规定进行调校、测试，传感器安设位置不当，风电闭锁、甲烷电闭锁和断电范围不符合规定，监控系统维护人员数量不足、业务能力差，瓦斯报警未按规定进行分析处理，对瓦斯超限原因分析不清或分析流于形式，如郑州煤炭工业（集团）有限责任公司芦沟煤矿、黑龙江双鸭山亚泰煤业有限公司三井、东荣一矿部分局部通风机未设置风电闭锁装置。个别煤矿仍存在采取挪移传感器位置、包裹传感器等造假手段导致甲烷传感器失效，或者擅自修改超限报警、断电值和瓦斯超限数据等问题，如湘煤集团少数煤矿为逃避处罚，在打钻或放炮前移开甲烷传感器，或在地面调度室发现监控系统瓦斯超限报警时故意拆断信息系统数据线、阻止数据上传。

三、下一步工作要求

针对全国煤矿“一通三防”存在的问题，各级煤矿安监机构要立足于查处大隐患、防范遏制瓦斯和火灾等重特大事故，督促煤矿企业强化安全生产主体责任，全面提升煤矿安全保障能力。

一要用好“一通三防”专项监察结果，对薄弱环节、重点矿井纳入下半年重点监察执法计划，进一步完善监察执法工作机制，推进煤矿安全监察执法规范化、信息化。对存在重大隐患、弄虚作假等违法违规矿井要盯住不放，督促企业做好瓦斯零超限目标管理，持续推进重大风险管控和灾害治理。

二要贯彻落实《煤矿瓦斯等级鉴定办法》，监督煤矿企业按规定做好瓦斯等级鉴定，特别是煤与瓦斯突出矿井鉴定，该升级的必须升级、该“戴帽”的必须“戴帽”，并做好升级“带帽”后的矿井改造管理工作。

三要推进煤矿安全监控系统升级改造，到今年底，大型矿井、煤与瓦斯突出矿井应当完成升级改造工作。要督促煤矿企业使用好、维护好安全监测监控系统，严格落实瓦斯零超限目标管理制度，倒逼瓦斯综合防治工程措施落实到位。

四要督促煤矿企业优化矿井生产布局、科学组织生产、确保采掘生产的正常接续，严厉打击超能力、超强度、超定员违规生产行为，对瓦斯防治工程措施落实不到位、抽采不达标，抽掘采接续紧张、防突能力不足的煤矿，必须依法停产整顿、重新核定产能。

五要严格落实国家煤矿安监局《关于有效防范和遏制煤与瓦斯突出事故的通知》，坚决做到“七个一律”，督促煤矿企业强化重大灾害超前治理、源头治理，强化现场管理、落实两个“四位一体”防突措施，有效防范遏制煤与瓦斯突出事故。
