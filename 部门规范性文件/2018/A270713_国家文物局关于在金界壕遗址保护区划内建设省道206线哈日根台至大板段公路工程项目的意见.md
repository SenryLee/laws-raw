# 国家文物局关于在金界壕遗址保护区划内建设省道206线哈日根台至大板段公路工程项目的意见

文物保函〔2018〕1336号

内蒙古自治区文物局：

你局《关于省道206线哈日根台至大板段公路工程穿越金界壕遗址的请示》（内文物字〔2018〕41号）收悉。经研究，我局原则同意在金界壕遗址保护范围和建设控制地带内实施省道206线哈日根台至大板段公路工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构进一步勘察确认所报项目相关金界壕遗址段落的地下遗存分布情况，评估地面及地下遗存保护状况，确保拟建公路桥梁、相关设施选址和施工区域完全避让地面及地下遗存分布区域。

（二）应适当增加拟建公路桥梁的桥墩与金界壕遗址地面及地下遗存之间的安全距离。

（三）应细化施工期间金界壕遗址防护措施、废弃物处置措施、施工和运营期间的减振措施、文物保护应急预案以及施工后期的场地清理与环境恢复措施，避免对金界壕遗址及其生态环境、景观风貌造成负面影响。

（四）应补充设置金界壕遗址保护标志碑、界桩及保护展示说明牌等相关措施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2018年10月29日
