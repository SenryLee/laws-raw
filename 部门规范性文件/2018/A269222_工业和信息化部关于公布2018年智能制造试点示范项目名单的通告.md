# 工业和信息化部关于公布2018年智能制造试点示范项目名单的通告

工信部装函〔2018〕343号

按照《工业和信息化部办公厅关于开展2018年智能制造试点示范项目推荐的通知》，经各地方工业和信息化主管部门推荐、专家评审和网上公示，2018年智能制造试点示范项目名单已经确定，现予以公布。
