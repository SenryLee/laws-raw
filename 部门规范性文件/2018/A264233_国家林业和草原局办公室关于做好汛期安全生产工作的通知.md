# 国家林业和草原局办公室关于做好汛期安全生产工作的通知

办改字〔2018〕59号

各省、自治区、直辖市林业厅（局）,内蒙古、吉林、龙江、大兴安岭、长白山森工（林业）集团公司,新疆生产建设兵团林业局,国家林业和草原局各司局、各直属单位：

近日，国内外接连发生多起安全事故，造成重大人员伤亡。党中央、国务院高度重视，习近平总书记作出重要指示，强调近期各类安全事故频繁发生，必须引起高度重视。当前，我国一些地区已陆续进入汛期，引发生产安全事故的风险加大。为认真贯彻落实习近平总书记重要指示精神，有效防范林业行业汛期发生重特大生产安全事故，按照国务院安全生产委员会的部署，现将有关要求通知如下：

一、加强组织领导，严格落实安全生产责任制

各地林业主管部门、局各有关司局和直属单位要深入学习贯彻习近平总书记关于安全生产的重要思想，认真研判本地区、业务主管领域安全生产面临的形势，进一步增强红线意识、责任意识和风险意识。要切实加强组织领导，明确汛期林业安全生产工作机构和人员，主要负责同志要亲自安排部署，分管负责同志要亲自检查推动。要按照“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，对本地区、业务主管领域可能存在的安全风险和隐患进行全面分析和评估，科学制定防范应对方案和措施。

二、突出工作重点，深入开展隐患排查治理

各地林业主管部门、局各有关司局和直属单位要深刻吸取其他行业近年来发生的汛期事故灾难教训，针对汛期强降雨、洪水、台风、泥石流、高温等灾害因素对林业安全生产威胁加大的风险，集中力量组织一次安全生产大检查。营林造林、国有林区、国有林场、自然保护区、森林公园、沙漠公园、湿地公园等业务主管司局和直属单位要按照“谁主管、谁负责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，切实履行好行业安全生产工作指导职责。要紧紧抓住林业行业容易发生群死群伤的重点领域，深入开展安全隐患治理。对检查过程中发现的重大隐患和违法违规行为，依法责令停产停业整改。要坚决杜绝冒险作业，遇有极端天气要及时停止作业，确保人员安全。内蒙古、吉林、龙江、大兴安岭、长白山森工（林业）集团公司要进一步落实好企业安全生产主体责任，自觉接受属地监管。

三、加强应急管理，不断提高科学应对处置能力

各地林业主管部门、局各有关司局和直属单位要进一步健全完善与相关部门的联合会商、信息共享、协调联动工作机制，不断强化沟通联系，充分运用自然灾害预测预报成果，科学研判灾害态势，及时、准确发布安全生产预警信息。要针对汛情特点，进一步完善安全生产应急预案，组织开展经常性的应急演练，强化应急人财物保障。要指导和督促林业生产经营单位加强应急准备，强化对一线职工化解险情和自救互救的教育培训。加强应急值守，严格执行领导干部带班、关键岗位24小时值班和事故信息报告制度。一旦发生事故险情，要及时报告并启动预案，妥善应对处置，把损失降到最低程度。对玩忽职守、责任不落实、人员不到位和抢险不及时而造成重大伤亡事故的，要依法依规严肃追究有关负责人的责任。

特此通知。
