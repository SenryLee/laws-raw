# 国家文物局关于张太雷旧居建设控制地带内辅楼改造方案的意见

文物保函〔2018〕379号

江苏省文物局：

你局《关于审批张太雷旧居建设控制地带内辅楼修缮方案的请示》（苏文物保〔2018〕55号）收悉。经研究，我局意见如下：

一、原则同意张太雷旧居建设控制地带内辅楼改造项目。

二、对所报方案提出以下修改意见：

（一）进一步明确工程内容仅限于非文物建筑——辅楼改造工程。涉及张太雷旧居文物本体修缮的相关内容应按程序另行报批。

（二）进一步完善辅楼改造方案，应以消除现状安全隐患、对室内部分功能格局做适当调整为主要目标，不建议在本次改造中扩大其平面尺寸、增加层数；充分考虑辅楼改建过程中对张太雷旧居文物本体可能产生的影响，并予补充相应的防护性措施。同时，应补充对张太雷旧居及纪念馆整体情况的描述，加强历史研究及格局分析，明确辅楼与文物本体的关系、辅楼与旅馆的关系等。

（三）进一步完善文物影响评估报告，客观评估辅楼改造工程对文物安全、环境风貌等方面的影响，并提出相应的减缓措施。

三、请你局指导有关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十八条规定，履行相应的审批程序后实施。工程施工期间，请你局加强监管，确保文物安全。

四、请你局指导当地人民政府组织专业机构，按照《关于张太雷旧居保护规划编制立项的批复》（文物保函〔2015〕3237号），抓紧编制张太雷旧居保护规划，明确区划范围内建设控制要求，统筹文物保护、环境整治等方面的工作。

专此。

国家文物局

2018年4月18日
