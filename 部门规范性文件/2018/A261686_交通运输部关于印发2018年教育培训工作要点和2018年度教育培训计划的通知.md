# 交通运输部关于印发2018年教育培训工作要点和2018年度教育培训计划的通知

交人教函〔2018〕96号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），部属各单位，部内各司局：

现将《2018年交通运输部教育培训工作要点》和《2018年度交通运输部教育培训计划》印发给你们，请按照《中央和国家机关培训费管理办法》和《交通运输部教育培训项目管理暂行办法》等要求，认真组织实施，抓好贯彻落实。

交通运输部

2018年2月13日
