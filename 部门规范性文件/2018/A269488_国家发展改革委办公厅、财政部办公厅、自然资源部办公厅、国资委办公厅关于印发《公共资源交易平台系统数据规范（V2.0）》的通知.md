# 国家发展改革委办公厅、财政部办公厅、自然资源部办公厅、国资委办公厅关于印发《公共资源交易平台系统数据规范（V2.0）》的通知

## 关于印发《公共资源交易平台系统数据规范（V2.0）》的通知

发改办法规〔2018〕1156号

各省、自治区、直辖市及计划单列市、副省级省会城市公共资源交易平台整合牵头部门、发展改革委、财政厅、自然资源主管部门、国资委，新疆生产建设兵团发展改革委、财务局、自然资源主管部门、国资委：

为深化各级公共资源交易平台互联互通，促进公共资源交易数据汇聚共享，我们对《公共资源交易平台系统数据规范（V1.0）》进行了修订，形成了《公共资源交易平台系统数据规范（V2.0）》，现予印发，请认真贯彻执行。

附件：公共资源交易平台系统数据规范（V2.0）
