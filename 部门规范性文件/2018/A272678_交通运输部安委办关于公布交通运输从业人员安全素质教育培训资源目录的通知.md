# 交通运输部安委办关于公布交通运输从业人员安全素质教育培训资源目录的通知

交安委办函〔2018〕111号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），部属各单位，中远海运、招商局、中交建设集团：

为贯彻落实党中央、国务院和部安全生产有关决策部署，进一步强化交通运输安全生产教育培训工作，加快打造一批安全素质高、能力强、本领硬的交通运输从业人员队伍，按照《交通运输部办公厅关于关于印发交通运输从业人员安全素质提升实施方案的通知》（交办安监〔2016〕164号）的有关工作部署，我办在广泛调研的基础上，编制了交通运输从业人员安全素质教育培训资源目录（见附件）。现印发你们，并就有关事项通知如下：

一、深刻认识加强交通运输安全教育培训的重要意义。人为因素是交通运输安全生产中最活跃的影响因素，是决定安全生产水平的关键因素。当前交通运输安全生产事故总量居于高位，暴露出交通运输从业人员安全意识不强、安全技能不足、安全素质不高等问题仍然突出。要深刻认识当前加强从业人员安全生产安全教育培训的重要性、迫切性和艰巨性，切实以加强安全教育培训促进人员安全素质提升，筑牢安全生产"人防"底线。

二、深入组织开展交通运输安全教育培训。资源目录是对部属或共建高校、有关职业技术院校、公路水路行业中央企业、部管社团、部属单位安全教育培训资源的梳理汇总。各单位、各部门要及时将资源目录转发企业，指导督促辖区有关交通运输企业充分利用教育培训资源，突出抓好重点领域、重点环节、重点岗位、关键技能的安全教育培训，不断提升从业人员安全意识和安全技能。同时，还要按照有关要求，加强企业主要负责人和安全生产管理人员培训和考核，逐步提高相关人员安全管理能力。

三、及时反馈安全教育培训有关情况。各部门、各单位要跟踪了解并系统分析辖区内有关单位或所属企业开展安全教育培训的情况，督促企业落实安全教育培训责任，深入了解培训机构培训能力，根据企业反映的培训效果，对有关培训机构进行调研分析，将能力强、培训效果好的安全教育培训资源及时向我办推荐反馈。我办将根据有关情况不断完善培训资源目录，推动行业安全教育培训工作再上新台阶。
