# 环境保护部、水利部关于印发《全国集中式饮用水水源地环境保护专项行动方案》的通知

## 关于印发《全国集中式饮用水水源地环境保护专项行动方案》的通知

环环监〔2018〕25号

各省、自治区、直辖市人民政府，新疆生产建设兵团：
