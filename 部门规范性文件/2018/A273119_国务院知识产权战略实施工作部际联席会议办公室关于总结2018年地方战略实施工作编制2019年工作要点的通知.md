# 国务院知识产权战略实施工作部际联席会议办公室关于总结2018年地方战略实施工作编制2019年工作要点的通知

国知战联办〔2018〕24号

各省、自治区、直辖市、新疆生产建设兵团知识产权局（知识产权管理部门）：

为贯彻落实党的十九大和十九届二中、三中全会精神，贯彻落实党中央、国务院决策部署，深入实施国家知识产权战略，加快建设知识产权强国，根据《国务院关于新形势下加快知识产权强国建设的若干意见》和《“十三五”国家知识产权保护和运用规划》任务部署，国务院知识产权战略实施工作部际联席会议办公室现组织开展2018年地方知识产权战略实施工作总结及2019年工作要点编制工作。具体要求如下：

请商地方知识产权战略实施相关部门，对照《2018年地方知识产权战略暨强国建设实施工作要点汇编》，总结2018年本地知识产权战略实施工作。结合地方实际，填写《2019年地方知识产权战略实施工作要点表》（见附件）。其中，具体内容应简明扼要，突出创新性工作、持续推进的重点工作和特色工作，避免一般性工作描述，年度成果形式要可考核、可评价。

请于2019年1月20日前将商地方知识产权战略实施相关部门确认的2018年工作总结及2019年要点表报联席会议办公室。

特此通知。

附件：2019年地方知识产权战略实施工作要点表

国务院知识产权战略实施工作部际联席会议办公室
