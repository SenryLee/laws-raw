# 财政部关于下达2018年车辆购置税收入补助地方资金预算（第三批）的通知

财建〔2018〕262号

有关省、自治区、直辖市、计划单列市财政厅（局）：

根据《财政部 交通运输部 商务部关于印发<车辆购置税收入补助地方资金管理暂行办法>的通知》（财建〔2014〕654号）、《财政部 交通运输部关于<车辆购置税收入补助地方资金管理暂行办法>的补充通知》（财建〔2016〕722号）和《财政部 交通运输部关于进一步明确车辆购置税收入补助地方资金补助标准及责任追究有关事项的通知》（财建〔2016〕879号）等有关规定，以及《交通运输部关于申请下达2017年车辆购置税资金安排地方建设项目预算（第二批）的函》（交财审函〔2017〕326号），现下达你省（自治区、直辖市、计划单列市）2017年车辆购置税收入补助地方资金（第三批），主要用于交通运输重点项目及一般公路建设项目支出（项目代码：Z135060000035；政府收支分类科目：214交通运输支出），同时下达相关绩效目标，具体项目、金额及绩效目标见附件。

请按照有关文件规定安排使用，加强资金管理，提高资金使用效益。要及时将贫困县涉农资金整合试点范围内资金分解下达到县，其中用于贫困县的资金增幅不低于该项资金平均增幅。分配给贫困县的涉农资金一律采取“切块下达”，资金项目审批权限完全下放到县，不得指定具体项目或提出与脱贫攻坚无关的任务要求。

附件：1. 2018年车辆购置税收入补助地方资金（第三批）重点项目支出预算表（不发地方）

2. 2018年车辆购置税收入补助地方资金（第三批）一般建设项目支出预算表（不发地方）

3. 2018年度车辆购置税收入补助地方资金转移支付整体绩效目标表（不发地方）

4. 2018年度车辆购置税收入补助地方资金专项转移支付分省绩效目标总表（不发地方）

5. 2018年车辆购置税收入补助地方资金（第三批）重点项目支出预算表（分发地方）（略）

6. 2018年车辆购置税收入补助地方资金（第三批）一般建设项目支出预算表（分发地方）（略）

7. 2018年车辆购置税收入补助地方资金专项转移支付绩效目标表（分发地方）（略）

财政部

2018年6月15日
