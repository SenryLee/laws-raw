# 国家文物局关于来鹤亭边坡抢险加固项目意见的函

文物保函〔2018〕614号

云南省文物局：

你局《关于请求批准来鹤亭抢险修复工程方案的请示》（云文物〔2018〕49号）收悉。经研究，我局意见如下：

一、原则同意来鹤亭边坡抢险加固项目和你局意见。

二、所报方案现状勘察深度不足，加固措施缺乏针对性，工程规模偏大且必要性论证不足，文本、图纸不规范，应进行认真调整、完善。具体修改意见如下：

（一）补充细化现状勘察，深化方案设计依据，并提高评估工作的专业性。应分析已发生滑坡、垮塌的类型、规模、性质等，明确灾害性质系局部垮塌还是大规模垮塌；应深化地层岩性和地质结构勘察；明确边坡的地质条件，科学、客观地评估边坡的稳定性等。

（二）应根据现状勘察结论，提出有针对性的加固措施。建议开展多方案比选，科学研究、合理确定加固措施，避免过度干预，不应大规模改变边坡形态；应充分考虑加固措施对文物所在山体稳定性的影响，避免次生灾害；应客观评估各方案对景观环境的影响，并补充减缓外观影响的具体措施。

（三）所报方案剖面A-A、C-C坡比为1：1，应论证采用植被保护代替锚杆格构措施的可行性；补充论证剖面B-B抗滑桩的有效性和可行性。

（四）补充现状总平面图、地形测绘图及必要的措施详图等，规范图纸标注。

（五）方案中不应包括维护设施、管理用房、卫生间等内容，如确有必要，须单独编制方案另行报批。

（六）工程概算虚高，应实事求是予以核减。

三、具体抢险方案由你局指导有关单位按照上述意见进行修改、完善并经你局批准后实施。该项目的勘察设计和施工单位应符合国家关于岩土工程资质的相关要求。

四、项目实施前，请督促地方有关单位加强监控，及时采取应急支护措施，防止次生灾害发生，确保文物和人员安全。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促有关方面和项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、涉及来鹤亭边坡抢险加固项目以外的文物维修项目，应按我局《关于进一步优化文物保护项目审批的通知》(文物保发〔2016〕25号)文件要求，另行履行报批程序。

国家文物局

2018年6月13日
