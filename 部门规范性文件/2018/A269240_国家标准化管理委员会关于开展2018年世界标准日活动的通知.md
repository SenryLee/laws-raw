# 国家标准化管理委员会关于开展2018年世界标准日活动的通知

国标委发〔2018〕59号

各省、自治区、直辖市及计划单列市、副省级城市、新疆生产建设兵团质量技术监督局（市场监督管理部门），国务院各有关部委、行业协会、集团公司，中国标准化研究院、全国组织机构统一社会信用代码数据服务中心、中国物品编码中心、中国质检出版社、中国标准化协会，各有关全国专业标准化技术委员会：

10月14日是第49届世界标准日。国际电工委员会（IEC）、国际标准化组织（ISO）、国际电信联盟（ITU）将2018年世界标准日的主题确定为“国际标准和第四次工业革命”，同时发布了英文宣传海报，并联合发出世界标准日祝词（见附件1）。

为贯彻落实党中央国务院关于标准化工作的决策部署，开展好2018年世界标准日系列活动，标准委制定了《第49届世界标准日宣传活动方案》（见附件2），将在世界标准日当天举办2018年世界标准日主题活动。世界标准日前后，标准委还将会同有关部门开展工业4.0暨智能制造标准化专题研讨会、新标准化法进校园、标准化实验基地开放周等一系列活动。

为广泛凝聚社会共识，营造全社会关心支持标准化工作的良好氛围，切实做好2018年世界标准日宣传工作，现将有关事项通知如下：

一、提高认识，加强领导。各地方、各部门及各有关单位要围绕世界标准日主题，参照《第49届世界标准日宣传活动方案》，结合工作实际，总结工作成效，特别是要提炼标准化助力智能制造和产业升级、引领先进制造业发展的好经验、好做法，组织开展丰富多彩、各具特色的活动，宣传标准化工作成绩，普及标准化理念方法，营造全社会知标准、守标准、用标准的浓厚氛围，充分发挥标准化对经济社会发展的重要支撑作用。

二、广泛动员，统筹协调。各地方、各部门及各有关单位既要组织做好本单位世界标准日活动，又要广泛动员、统筹协调相关国家技术标准创新基地、区域标准化研究中心、标准化示范区和试点单位，以及学校、社区、机关、企业，开展全方位、多层次的世界标准日活动，凝聚标准化工作共识，形成推动标准化工作的合力。

三、扎实推进，务求实效。各地方、各部门及各有关单位要严格遵守相关法律法规和中央八项规定精神，注重简朴、实效，杜绝铺张浪费，扎实组织开展好各项活动。要总结和推广好的做法和经验，及时向标准委报送活动开展情况，标准委将及时进行宣传报道。请各地方、各部门及各有关单位于10月31日前，将世界标准日活动总结（包括活动基本情况、取得的成效、有关工作建议等）报送标准委。
