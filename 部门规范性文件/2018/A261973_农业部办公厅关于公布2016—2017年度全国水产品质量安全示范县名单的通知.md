# 农业部办公厅关于公布2016—2017年度全国水产品质量安全示范县名单的通知

农办渔〔2018〕17号

各省、自治区、直辖市渔业主管厅（局），新疆生产建设兵团水产局：

根据《农业部办公厅关于做好2016年全国水产品质量安全示范县创建和可追溯试点建设工作的通知》（农办渔〔2016〕35号）和《关于做好2016年水产品质量安全示范县和可追溯试点考核验收工作的通知》（农渔科函〔2017〕48号）的有关要求，我部对有关县(市)的全国水产品质量安全示范县创建工作进行了现场考核验收。根据验收结果，现授予江苏省昆山市等4个县（市）“2016—2017年度全国水产品质量安全示范县”称号，现予以公布。

各示范县要再接再厉，发扬成绩，按照验收专家组意见继续完善有关工作，注重总结提升，形成可借鉴可推广的经验，发挥示范和辐射带动作用，为全面提升水产品质量安全水平作出积极贡献。

附件：2016-2017年度全国水产品质量安全示范县名单

农业部办公厅
