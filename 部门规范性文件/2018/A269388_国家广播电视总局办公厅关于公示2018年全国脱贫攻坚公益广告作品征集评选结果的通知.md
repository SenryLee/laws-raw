# 国家广播电视总局办公厅关于公示2018年全国脱贫攻坚公益广告作品征集评选结果的通知

广电办发〔2018〕96号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央广播电视总台办公厅，电影频道节目中心，中国教育电视台：

为深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，展示党的十八大以来脱贫攻坚成就，分享交流精准扶贫精准脱贫经验，助力营造打好精准脱贫攻坚战的浓厚社会氛围，2018年6月国家广播电视总局和国务院扶贫办联合开展了脱贫攻坚公益广告作品征集暨展播活动，得到社会各界积极响应。经活动组委会审核，共评出一、二、三类作品及优秀类、入围类作品共80件，现予以公示。公示内容可以在国家广播电视总局政府网站（网址：www.sapprft.gov.cn）通知公告区中查询。

请立即向辖区内有关单位或个人通报公示内容。有关单位和个人均可就公示内容存在的问题，于10月7日前向国家广播电视总局传媒司反映。

联系人：许旭，010-86098540。

附件：1.2018年全国脱贫攻坚公益广告作品征集活动广播类扶持作品名单

2.2018年全国脱贫攻坚公益广告作品征集活动电视类扶持作品名单

国家广播电视总局办公厅

2018年9月29日
