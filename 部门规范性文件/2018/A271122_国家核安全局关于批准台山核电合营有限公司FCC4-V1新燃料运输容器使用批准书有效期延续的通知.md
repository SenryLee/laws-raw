# 国家核安全局关于批准台山核电合营有限公司FCC4-V1新燃料运输容器使用批准书有效期延续的通知

## 关于批准台山核电合营有限公司FCC4-V1新燃料运输容器使用批准书有效期延续的通知

国核安函〔2018〕93号

台山核电合营有限公司：

你公司《关于申请延续FCC4-V1型新燃料运输容器使用批准书的请示》（广核台〔2018〕53号）收悉。

根据《放射性物品运输安全管理条例》及其配套规章《放射性物品运输安全许可管理办法》的有关规定，我局对你公司提交的FCC4-V1新燃料运输容器使用批准书有效期延续申请材料进行了审查，认为FCC4-V1新燃料运输容器能够满足相关要求，决定向你公司颁发延续后的FCC4-V1新燃料运输容器使用批准书（见附件），有效期至2023年10月31日。

你公司在使用FCC4-V1新燃料运输容器实施运输过程中，必须严格遵循FCC4-V1新燃料运输容器使用批准书规定的各项条件，确保运输安全。

我局授权华南核与辐射安全监督站负责放射性物品运输活动的现场监督检查，请你单位予以配合。

附件：FCC4-V1新燃料运输容器使用批准书

国家核安全局

2018年11月13日
