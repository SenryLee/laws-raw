# 国家核安全局关于颁发2018年第四批民用核设施核反应堆（研究堆）操纵人员执照的通知

## 关于颁发2018年第四批民用核设施核反应堆（研究堆）操纵人员执照的通知

国核安发〔2018〕272号

中国原子能科学研究院，清华大学：

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的有关规定，我局对中国原子能科学研究院、清华大学报送的民用核设施核反应堆操纵人员执照申请进行了审查，认为巴元佐等26人满足取照相关要求，批准向上述26人颁发民用核设施核反应堆操纵人员执照（基本信息见附件）。

特此通知。

附件：民用核设施核反应堆（研究堆）操纵人员执照基本信息

国家核安全局

2018年10月10日
