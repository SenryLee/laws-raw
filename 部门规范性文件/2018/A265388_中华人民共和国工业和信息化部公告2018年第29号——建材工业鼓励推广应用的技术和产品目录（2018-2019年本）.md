# 中华人民共和国工业和信息化部公告2018年第29号——建材工业鼓励推广应用的技术和产品目录（2018-2019年本）

## 中华人民共和国工业和信息化部公告

2018年第29号

为推动建材行业转型升级、降本增效，加快供给侧结构性改革，在化解水泥平板玻璃行业产能严重过剩矛盾的同时，引导资本等要素流向建材领域新兴产业和传统产业技改项目，促进产融对接，补齐发展短板，培育壮大新动能，我部组织编制了《建材工业鼓励推广应用的技术和产品目录（2018-2019年本）》，现予公告。

附件：建材工业鼓励推广应用的技术和产品目录（2018-2019年本）
