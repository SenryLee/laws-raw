# 司法部关于开展2018年度外国律师事务所驻华代表机构年度检验的通知

司发通〔2018〕140号

北京、天津、辽宁、上海、浙江、福建、广东省（市）司法厅（局）：

根据《外国律师事务所驻华代表机构管理条例》的规定，请你们按照下列要求，依法开展本行政区域内外国律师事务所驻华代表机构2018年度检验工作：

一、在2018年12月31日之前，通知本行政区域内外国律师事务所驻华代表机构，于2019年3月31日之前依法提交年度检验材料，接受年度检验。

二、对于代表机构未按时报送年度检验材料接受年度检验，或者未通过年度检验的，应当依法及时给予相应的行政处罚。

三、在2019年5月31日前将年度检验意见连同本通知附件表格一并报司法部，年度检验意见应对本辖区内代表机构的人员（包括首席代表、代表和雇员）、机构、业务领域、业务收入、纳税、受处罚情况，总部基本信息以及与国内律师事务所的合作情况进行整理、汇总和分析，并对存在的问题提出相应的意见和建议。年度检验报告和相关表格的电子版用光盘一并提交。对通过年检的代表机构，由司法部予以公告。

在开展年度检验工作中遇到的问题，请及时与部律师工作局联系。

联系人：张莹　010-65153053
