# 交通运输部办公厅关于表扬2017—2018年度全国12328电话十佳服务中心和百佳工作者的通报

交办运〔2018〕170号

为贯彻落实党中央、国务院决策部署，加快推进交通运输行业治理体系和治理能力现代化，着力改进提升综合运输服务水平，部将管好用好12328交通运输服务监督电话（以下简称12328电话）系统作为重要的民生工程，不断加大工作力度。各地交通运输主管部门和12328电话服务中心围绕打造交通运输服务监督"一号通",凝心聚力，攻坚克难，持续加强12328电话系统建设和运行管理工作。广大12328电话工作人员辛苦工作，任劳任怨，真情服务，无私奉献，推进12328电话系统运行服务质量持续改善，人工接通率、平均等待时长等主要指标稳步向好，12328电话成为群众和行业的"连心桥""好帮手""晴雨表".为充分发挥先进典型的示范带动作用，激励广大交通运输干部职工认真做好12328电话服务工作，经各地审核推荐、专家评选及网站公示，经交通运输部同意，决定对2017—2018年度表现突出的河北省12328电话服务中心等全国十佳12328电话服务中心，以及冯萌萌等全国百佳12328电话工作者进行通报表扬。

希望受到表扬的12328电话服务中心和工作者珍惜荣誉、再接再厉、再创佳绩。希望全国交通运输行业以先进典型为榜样，积极进取，奋发有为，爱岗敬业，无私奉献，全力做好12328电话服务工作，进一步提升12328电话服务质量和水平，更好地发挥倾听民声、畅通民意、排解民忧、汇集民智的作用，为建设人民满意交通作出新的更大贡献。
