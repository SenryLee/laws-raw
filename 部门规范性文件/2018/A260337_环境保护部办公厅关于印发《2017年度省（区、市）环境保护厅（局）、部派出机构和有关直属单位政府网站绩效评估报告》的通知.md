# 环境保护部办公厅关于印发《2017年度省（区、市）环境保护厅（局）、部派出机构和有关直属单位政府网站绩效评估报告》的通知

## 关于印发《2017年度省（区、市）环境保护厅（局）、部派出机构和有关直属单位政府网站绩效评估报告》的通知

环办厅函〔2018〕59号

各省、自治区、直辖市环境保护厅（局），新疆生产建设兵团环境保护局，各派出机构、直属单位：

为贯彻落实《关于全面推进政务公开工作的意见》《政府网站发展指引》等文件精神，进一步深化环保系统政务公开，强化全国环保系统政府网站建设与管理，根据政府网站绩效评估工作的有关要求，我部组织信息中心开展了2017年度环保系统政府网站绩效评估工作。

在历年对省级环境保护厅（局）政府网站开展绩效评估基础上，本次评估首次将10个派出机构和25个直属单位网站纳入评估范围。从评估结果看：各省级环境保护厅（局）政府网站不断深化信息公开，全面提升网上服务，积极推动互动交流，持续加强网站管理，网站建设水平和服务能力逐年提升。各派出机构及直属单位网站加快发展建设，逐步完善网站各项功能，丰富网站信息内容，网站建设呈现良好发展趋势。

现将评估报告印发给你们（见附件），请结合实际，不断提高网站建设管理水平，推动环保系统政府网站科学、规范、创新发展。

附件：2017年度省（区、市）环境保护厅（局）、部派出机构和有关直属单位政府网站绩效评估报告

环境保护部办公厅

2018年1月11日
