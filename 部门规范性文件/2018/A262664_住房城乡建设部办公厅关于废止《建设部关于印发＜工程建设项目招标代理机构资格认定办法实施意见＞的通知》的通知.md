# 住房城乡建设部办公厅关于废止《建设部关于印发＜工程建设项目招标代理机构资格认定办法实施意见＞的通知》的通知

建办市〔2018〕15号

各省、自治区住房城乡建设厅，直辖市建委，新疆生产建设兵团建设局：
