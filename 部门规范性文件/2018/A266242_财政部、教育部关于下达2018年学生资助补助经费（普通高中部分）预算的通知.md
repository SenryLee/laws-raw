# 财政部、教育部关于下达2018年学生资助补助经费（普通高中部分）预算的通知

## 财政部　教育部关于下达2018年学生资助补助经费（普通高中部分）预算的通知

财科教〔2018〕36号

有关省、自治区、直辖市、计划单列市财政厅（局）、教育厅（局、教委）：

根据教育部提供的数据，现下达你省（自治区、直辖市、计划单列市）2018年学生资助补助经费（普通高中部分）预算，详见附件1。请列205“教育支出”相关项。现将有关事项通知如下：

一、各地应严格按照《财政部 教育部关于建立普通高中家庭经济困难学生国家资助制度的意见》（财教〔2010〕356号）和《财政部 教育部关于免除普通高中建档立卡家庭经济困难学生学杂费的意见》（财教〔2016〕292号）要求，足额落实应由地方承担的资金，及时下达经费预算，合理确定国家助学金分档标准，并确保建档立卡等家庭经济困难学生优先获得资助。

二、为贯彻落实党的十九大关于“全面实施绩效管理”的决策部署，切实提高财政资金使用效益，请在组织预算执行中对照你省区域绩效目标（附件2）做好绩效监控，确保年度绩效目标如期实现。同时，做好本省绩效目标分解下达工作，并抄送财政部驻当地财政监察专员办事处。

三、各地要切实加强资金管理，确保资金使用安全、规范、有效。对于挤占、挪用、虚列、套取资金等行为，将按照《预算法》《财政违法行为处罚处分条例》等有关规定严肃处理。

2.学生资助补助经费（普通高中部分）区域绩效目标表
