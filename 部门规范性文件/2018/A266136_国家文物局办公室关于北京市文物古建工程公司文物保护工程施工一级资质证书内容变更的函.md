# 国家文物局办公室关于北京市文物古建工程公司文物保护工程施工一级资质证书内容变更的函

办保函〔2018〕682号

北京市文物局：

你局《关于北京市文物古建工程公司申请文物保护工程施工资质证书单位地址变更的请示》（京文物〔2018〕799号）收悉。

经研究，我局同意北京市文物古建工程公司文物保护工程施工一级资质证书中的单位地址由“北京市东城区禄米仓5号”变更为“北京市东城区天坛东里北区11楼迤北”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2018年6月27日
