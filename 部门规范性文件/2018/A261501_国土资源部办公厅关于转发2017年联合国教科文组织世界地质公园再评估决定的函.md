# 国土资源部办公厅关于转发2017年联合国教科文组织世界地质公园再评估决定的函

国土资厅函〔2018〕228号

北京、内蒙古、浙江、福建、湖北、四川、陕西省（区、市）国土资源主管部门：

2018年2月6日，收到联合国教科文组织世界地质公园秘书处来函（附件1），并转来联合国教科文组织世界地质公园理事会对2017年中国接受重新验证（即再评估）的9个联合国教科文组织世界地质公园再评估最终决定。

2017年6-8月，联合国教科文组织世界地质公园秘书处组织专家对我国的延庆、阿拉善沙漠、克什克腾、雁荡山、泰宁、神农架、兴文、秦岭终南山和香港等9个世界地质公园建设情况进行了再评估实地考察。2017年9月16日-17日，教科文组织世界地质公园理事会在中国贵州织金洞世界地质公园举行会议，审议了2017年全球35个世界地质公园再评估报告及考察情况,确定了再评估最终结果，其中包括我国的9个世界地质公园。

现将联合国教科文组织对我国9个世界地质公园的再评估结果（附件2）和再评估决定函（附件3）转给你们。请督促有关地方人民政府和世界地质公园管理机构，认真研究教科文组织世界地质公园理事会提出的意见和建议，尽快制定整改方案，做好下一评估期世界地质公园建设的相关工作。

2018年2月13日

附件 :

1. 联合国教科文组织世界地质公园秘书处来函及译文

2. 2017年中国联合国教科文组织世界地质公园再评估结果

3. 联合国教科文组织世界地质公园理事会对9个世界地质公园的再评估决定函
