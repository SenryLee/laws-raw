# 交通运输部办公厅关于下达2018年度水运工程标准编制计划的通知

交办水函〔2018〕1019号

各标准主编单位：

根据财政部对2018年交通运输战略规划政策标准规范等研究制定项目支出预算的批复及我部相关要求，现将2018年度水运工程标准编制计划下达给你们。各标准主编单位要按照《交通运输部关于印发<水运工程标准管理办法>的通知》（交水发〔2012〕665号）和合同要求，抓紧组织开展标准编制工作，延续项目应确保按计划完成送审稿阶段工作，新列项目应按本计划在2018年底前完成工作大纲编制工作，并报我部（水运局）。

各标准主编单位要进一步加强标准编制的质量和进度管理，确保如期保质完成编写任务。因客观原因不能按期完成的，主编单位应及时提出调整进度计划的申请，报我部（水运局）批准。我部将把标准编制工作纳入信用管理，加强督促检查，对标准编制进度滞后、质量不符合要求的主编单位进行约谈；被约谈两次的主编单位，暂停两年标准立项申请资格；被约谈两次以上的主编单位，视情延长暂停申请资格年限。

交通运输部办公厅

2018年7月3日
