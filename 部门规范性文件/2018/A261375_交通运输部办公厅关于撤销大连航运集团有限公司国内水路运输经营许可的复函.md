# 交通运输部办公厅关于撤销大连航运集团有限公司国内水路运输经营许可的复函

交办水函〔2018〕200号

辽宁省交通厅港航管理局：

你局《关于撤销大连航运集团有限公司国内水路运输经营许可的请示》（辽交港航运发〔2017〕66号）收悉。经交通运输部同意，现将有关意见函复如下：

鉴于大连航运集团有限公司已不具备《国内水路运输管理条例》（国务院令第625号）、《国内水路运输管理规定》（交通运输部令2016年第79号）规定的许可条件，经你局监督整改后仍不符合国内水路运输企业相关经营资质要求，根据《国内水路运输管理条例》等规定，决定撤销大连航运集团有限公司的国内水路运输经营许可。该公司《国内水路运输经营许可证》（编号：交辽XK0304）自动注销。

请你局将本决定送达该公司。

交通运输部办公厅

2018年2月2日
