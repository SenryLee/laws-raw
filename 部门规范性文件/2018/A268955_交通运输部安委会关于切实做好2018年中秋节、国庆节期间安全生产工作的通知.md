# 交通运输部安委会关于切实做好2018年中秋节、国庆节期间安全生产工作的通知

交安委明电〔2018〕6号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），中远海运、招商局、中交建设集团，部属各单位：

2018年中秋节、国庆节将至，为切实做好节日期间安全生产工作，国务院安委会办公室、应急管理部印发了《关于切实做好2018年中秋节、国庆节期间安全生产工作的通知》（安委办明电〔2018〕12号），现转发给你们，请认真贯彻落实，严防各类事故发生，保障交通运输安全生产形势稳定，现提出有关工作要求如下：

一、切实加强组织领导，狠抓安全责任和措施落实

中秋节、国庆节假期临近，群众出行和公众活动相对集中，客货运输繁忙期、建设施工高峰期、自然灾害频发期三期叠加，交通运输安全生产面临巨大的压力和挑战。各部门、各单位要切实增强责任感和紧迫感，切实认清做好当前交通运输安全生产工作的极端重要性，加强节日期间安全生产工作的组织领导，紧密结合正在开展的平安交通百日行动，周密安排部署，完善保障方案，细化工作措施，落实层级责任，要在各地党委、政府支持下，加强与公安、安监等部门密切配合，加强行业内的协调联动，形成工作合力，确保节日期间的安全生产形势稳定。

二、扎实推进平安交通百日行动，强化风险管控和隐患治理

各部门、各单位要按照部关于安全生产工作的部署，扎实推进平安交通百日行动，深入开展风险隐患排查，列明重大风险和重大隐患清单，严格落实重大风险管控措施和重大隐患挂牌督办制度。要针对道路“两客一危”运输、水上交通、公路运营、港口危险化学品存储和装卸作业、公路水运工程建设方面存在的突出问题，强力开展专项治理，及时发现和整改消除隐患，有效防范各类事故发生。要根据节日期间交通运输安全生产特点，在节前开展针对性的监督检查，及时掌握重点工作进展情况，并加强跟踪督办，确保专项行动成效不反弹、问题不回潮。

三、突出重点领域，加强现场监督管理

道路运输领域，要加强长途客运、旅游包车、客运站场、危险货物运输等的安全管理，强化重点营运车辆动态监控，严肃查处超员超载、疲劳驾驶等违法违规行为。认真落实长途客运班车源头安全检查，严格落实旅客实名制，特别要强化旅游包车安全运营管理。要加强城市轨道交通设施设备检查，有效消除信号故障，加大巡查巡检力度，确保运营安全。要加强高速公路、国省道、长大桥隧以及农村公路等重点路段巡查，及时消除安全隐患。要联合有关部门继续加大网约车营运安全监管，督促平台公司严格落实各项管理措施，强化车辆及驾驶员管理，坚决遏制恶性事件。

水路运输领域，继续加大现场监管力度，充分运用VTS、AIS、CCTV、电子巡航等手段，重点加强对“六区一线”水域，尤其是渡口、客运码头、旅游景区等水域的动态监管。要紧盯“四类重点船舶”，特别要加强客船安全监管，严禁水上客运船舶无证经营、不适航营运，严格落实水路旅客运输实名制管理要求，严禁客运船舶超载、超员、超区域航行等行为。要吸取“8·15”“和航兴龙”客船险情教训，督促客运企业、船舶加强气象信息收集，严禁客船超抗风等级航行。要加大消防安全隐患排查整治力度，完善灭火救援预案，强化战备值勤，确保水上消防安全。

港口生产领域，要继续开展危险货物港口作业安全治理专项行动和港口危险货物储罐安全专项整治，督促港口企业依法依规从事生产经营，强化安全隐患排查治理。要认真履行港口安全生产监管职责，加大客运码头等人员密集场所和港口危险货物装卸、存储作业设施设备的监督检查力度，严厉打击不遵守安全操作规程、不合规船舶靠泊装卸等作业行为，确保港口生产作业安全。

公路水运工程领域，要突出桥梁隧道施工、高边坡和临崖临水作业和海上作业，立足工程建设实际，全面加强施工现场安全管理，狠抓隐患排查治理，保证施工现场机械设备、临时性工程安全运行，严格落实安全保障措施，有效防范施工安全事故。要吸取四川“9·15”汶马高速公路隧道突发突水突泥造成人员伤亡事件的教训，增强风险意识，加强风险防控，对施工现场可能发生的重大风险作一次梳理，完善应急预案，强化应急处置。要高度重视并切实做好极端天气下施工现场的安全管理，严防大风、暴雨、泥石流、滑坡等突发自然灾害可能对施工作业现场、驻地造成危害，及时撤离涉险人员。

四、超前预警预防，做好安全防范和保通保畅

近期我国多地遭遇强降雨，东部沿海连续遭受台风袭击，据气象部门预测，今后一段时间防汛防台形势依然严峻，还有秋台风登陆，部分地区可能出现秋汛。各部门、各单位要保持清醒认识，对当前防汛防台工作进行再部署、再检查、再落实，密切关注气象变化和影响，及时发布预警信息，严防自然灾害引发交通运输生产安全事故。要针对中秋节，特别是国庆黄金周期间小客车免费通行情况下的车流、客流特点，密切关注路网实时动态，采取有效措施，切实做好路网保通保畅工作。

五、加强应急管理，及时妥善应对各类突发事件

要切实加强值班和应急值守工作，严格落实岗位责任制和节日期间领导带班、关键岗位24小时值班制度，并安排信息技术保障人员一并参与值班。进一步完善应急预案，强化应急演练，增强应急工作实战性，加强救助抢险车船、飞机的维护保养，做好应急待命工作，一旦发生突发事件和事故险情，做到科学应对、及时妥善处置，并按照有关规定及时、准确上报信息。同时，要密切关注舆情动态，充分发挥新闻媒体的舆论引导作用，及时发布权威信息，有效应对舆情。

安全生产信息报送要求：请于10月7日15：00前，将10月1日至7日辖区内发生的公路水路行业统计口径内安全生产事故信息及国庆期间安全生产特点分析报部安委办，同时按照相关规定及时报告交通运输重特大安全生产事故信息，严禁迟报、漏报和瞒报。联系人：刘剑，联系电话：010-65292651，邮箱：liujian@mot.gov.cn。
