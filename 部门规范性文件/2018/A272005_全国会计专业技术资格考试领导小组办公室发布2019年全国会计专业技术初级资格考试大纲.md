# 全国会计专业技术资格考试领导小组办公室发布2019年全国会计专业技术初级资格考试大纲

为明确2019年全国会计专业技术初级资格考试评价标准，全国会计专业技术资格考试领导小组办公室制定了2019年全国会计专业技术初级资格考试大纲，现予发布。

附件1：2019年经济法基础考试大纲

附件2: 2019年初级会计实务考试大纲

全国会计专业技术资格考试领导小组办公室

2018年12月13日
