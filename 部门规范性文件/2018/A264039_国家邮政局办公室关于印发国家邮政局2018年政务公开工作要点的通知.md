# 国家邮政局办公室关于印发国家邮政局2018年政务公开工作要点的通知

国邮办函〔2018〕167号

国家邮政局机关各司室、直属各单位：

按照《国务院办公厅关于印发2018年政务公开工作要点的通知》（国办发〔2018〕23号）要求，结合工作实际，办公室制定了《国家邮政局2018年政务公开工作要点》，经局领导批准，现予印发，请认真贯彻落实。

国家邮政局办公室

2018年4月28日

## 国家邮政局2018年政务公开工作要点

国家邮政局2018年政务公开工作的总体目标是：全面贯彻党的十九大和十九届二中、三中全会精神，以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党中央、国务院关于全面推进政务公开工作的系列部署，坚持统筹兼顾、突出重点，大力推进决策、执行、管理、服务、结果公开，不断提升政务公开的质量和实效，推动邮政管理部门切实转变政府职能、深化简政放权、创新监管方式，促进邮政业持续健康发展，助力建设人民满意的服务型政府。

一、着力加强公开解读回应工作

(一)围绕建设法治政府全面推进政务公开。要把公开透明作为政府工作的基本要求，坚持以公开为常态、不公开为例外，经国家邮政局办公会议、专题会议等讨论决定的事项、制定的政策，除依法需要保密的外应及时公开，以公开促进依法行政和政策落地见效，充分保障人民群众的知情权。制定出台涉及公共利益、公众权益的政策文件，要对公开相关信息作出明确规定，使政策执行更加阳光透明。进一步推进人大代表建议和政协委员提案办理结果公开，对社会广泛关注、关系国计民生的建议和提案，承办单位原则上要公开答复全文（办公室牵头，各司室按职责分工负责）。

(二)围绕重点领域加大主动公开力度。一是继续推进“放管服”改革信息公开。推进各级邮政管理部门“三个清单”编制工作，以清单管理推动简政放权，各类清单及时向社会公开；持续推进邮政各项行政许可的信息公开，向社会公开法定职能、法律依据、实施主体、职责权限、管理流程、监督方式等事项（政策法规司、普遍服务司、市场监管司按职责分工负责）。二是推进行业监管和执法信息公开。全面实施“双随机、一公开”监管，多渠道全方位及时公开行业监管和执法信息，提高管理效能和公正性，增强监管威慑力和公信力。继续贯彻落实《邮政行政执法信息公开规定》，全面加强市场监管，深入推进执法信息公开，加大对违法违规行为的信息公示力度，加强市场准入负面清单管理，健全行政监督、执法与信息披露机制，推进诚信体系建设。继续发布快递市场监管报告和中国快递发展指数，引导市场预期（政策法规司、普遍服务司、市场监管司按职责分工负责）。三是推进财政资金信息公开。深入推进预决算公开，进一步细化国家邮政局系统预、决算公开，部门预算和决算要全部公开到支出功能分类的项级科目，并区分基本支出和项目支出,方便公众查阅和监督（办公室负责）。针对行业重大建设项目，做好审批、核准、备案等结果公开，着力推进实施过程信息公开（各司室按职责分工负责）。

(三)围绕稳定市场预期加强政策解读。一是牢牢把握高质量发展的根本要求，聚焦深入推进邮政业供给侧结构性改革、《快递暂行条例》宣贯、邮政业更贴近民生7件实事等重大决策重要工作部署，解读好相关政策措施、执行情况和工作成效，赢得人民群众的理解和支持（办公室牵头，政策法规司、普遍服务司、市场监管司按职责分工负责）。二是主要领导要履行好重大政策“第一解读人”职责，通过政策吹风会、新闻发布会、在线访谈等方式，深入解读政策背景、重点任务、后续工作考虑等，及时准确传递权威信息和政策意图（办公室负责，中国邮政快递报社配合）。三是对专业性较强的政策，起草部门要注重运用客观数据、生动实例等，进行形象化、通俗化解读，把政策解释清楚，避免误解误读。重点做好《快递暂行条例》宣贯工作，集中宣传大力营造《条例》实施的良好氛围（政策法规司负责，相关司室、中国邮政快递报社配合）。持续推动行业标准公开和宣贯，加强定期行业统计信息、经济运行分析通报，快递服务、普遍服务满意度调查，邮政业消费者申诉情况通报以及行业安全生产突发事件等信息公开，强化服务意识，提高政府机关的公信力（政策法规司、普遍服务司、市场监管司、邮政业安全中心按职责分工负责）。

(四)围绕社会重大关切加强舆情回应。一是切实增强舆情风险防控意识，密切监测收集苗头性舆情，特别是涉及行业重大决策、与行业密切相关的重要政务舆情，做到及时预警，科学研判、妥善处置、有效回应（办公室负责，政策法规司、普遍服务司、市场监管司、发展研究中心、中国邮政快递报社配合）。二是建立完善与宣传、网信、公安、通信管理等部门的快速反应和协调联动机制，加强与新闻媒体的沟通联系（办公室负责，发展研究中心、中国邮政快递报社配合）。三是稳妥做好突发事件舆情回应工作，及时准确发布权威信息，提高政务舆情回应的主动性、针对性、有效性（办公室、中国邮政快递报社负责，相关司室配合）。

二、着力提升政务服务工作实效

(五)推进网上办事服务公开。按照《国务院关于加快推进“互联网+政务服务”工作的指导意见》（国发〔2016〕55号）以及《国家邮政局推进“互联网+政务服务”工作分工方案》要求，不断创新服务方式，简化优化服务流程，规范整合办事平台，提升政务服务能力水平，激发市场活力和行业创造力，最大程度利企便民，让企业和群众办事更加方便快捷。一是及时公开“互联网+政务服务”有关政策的落实情况及阶段性成果。公开网上办事大厅服务事项清单，推动更多事项在网上办理，实现办事材料目录化、标准化（办公室牵头，相关司室按职责分工负责）。二是建立完善网民留言、咨询的受理、转办和反馈机制，及时处理答复，为群众提供更好服务（办公室负责，邮政业安全中心、中国邮政快递报社配合）。

(六)优化审批办事服务。一是开展办事服务信息专项检查，重点检查公开的办事服务信息是否准确规范、与实际工作是否一致等，发现问题及时整改（普遍服务司、市场监管司按职责分工负责）。二是进一步规范和完善办事指南，办事指南之外不得增加其他要求；办事条件发生变化的事项，应在完成审批程序后1个工作日内公开变更后的相关信息和具体实施时间（普遍服务司、市场监管司按职责分工负责）。

三、着力推进政务公开平台建设

(七)强化政府网站建设管理。一是认真落实《政府网站发展指引》（国办发〔2017〕47号），做好日常监测和季度抽查，不断提高政府网站管理服务水平（办公室负责，中国邮政快递报社配合）。二是加强政府网站内容建设，丰富信息资源，强化信息搜索、办事服务等功能（中国邮政快递报社负责，相关司室配合）。三是大力推进政府网站集约化建设，建立健全站点建设、内容发布、组织保障等体制机制（中国邮政快递报社负责）。四是规范政府网站域名管理，年内完成全系统网站部署互联网协议第六版（IPv6）改造工作。完善政府网站安全保障机制，做好防攻击、放篡改、防病毒等工作（发展研究中心负责）。

(八)充分发挥政府信息公开专栏网上“文件库”作用。一是组织、督促机关各司室和指导各省（区、市）邮政管理局、市（地）邮政管理局充分利用政府信息公开管理系统推进信息公开（办公室负责）。二是加强政府信息公开专栏使用，按职责更新相关栏目，提高主动公开率，应公开的及时公开，根据需要政府信息公开专栏和网站双公开，确保网上“文件库”权威、全面（各司室按职责负责）。

(九)用好国家邮政局官方微博微信。充分发挥政务微博微信灵活便捷的优势，做好信息发布、政策解读和办事服务工作，进一步增强公开实效，提升服务水平；加强微博微信日常维护和监管，落实管理主体责任，严格内容审查把关，不得发布与政府职能没有直接关联的信息，信息发布失当、造成不良影响的要及时整改（中国邮政快递报社负责）。

四、着力推进政务公开制度化规范化

(十)贯彻落实政府信息公开条例。严格落实新《中华人民共和国政府信息公开条例》，修订完善《国家邮政局政府信息公开工作办法》，做好衔接过渡工作；对照新条例要求全面梳理应当主动公开的政府信息，未公开的要及时向社会公开；进一步规范依申请公开工作，建立健全接收、登记、办理、答复等流程，依法保障公民、法人和其他组织获取政府信息的权利（办公室负责，相关司室配合）。

(十一)完善组织领导。调整政府信息公开工作领导小组以及办公室成员及职责（办公室负责）。

(十二)加强政府信息公开审查工作。依法依规开展政府信息公开保密审查；做好对公开内容表述、公开时机、公开方式的研判，避免信息发布失信、影响社会稳定等问题；依法保护好个人隐私，除惩戒公示、强制性信息披露外，对于其他涉及个人隐私的政府信息，公开时要去标识化处理，选择恰当的方式和范围（办公室牵头，相关司室按职责分工负责）。

(十三)完善主动公开基本目录。根据职责任务变化动态调整国家局主动公开目录；年底前编制完成全系统主动公开基本目录并对外发布（办公室负责，相关司室配合）。

机关各司室和相关直属单位要高度重视本要点部署的各项任务，结合实际制定具体措施，明确承办处室和责任人，认真抓好落实。相关工作开展情况将纳入绩效考核。办公室将适时组织工作情况督查，并通报督查结果。
