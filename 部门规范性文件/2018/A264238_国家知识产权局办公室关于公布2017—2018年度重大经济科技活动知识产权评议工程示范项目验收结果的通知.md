# 国家知识产权局办公室关于公布2017—2018年度重大经济科技活动知识产权评议工程示范项目验收结果的通知

## 关于公布2017—2018年度重大经济科技活动知识产权评议工程示范项目验收结果的通知

国知办函协字〔2018〕226号

各有关地方知识产权局：

按照《国家知识产权局办公室关于2017年重大经济科技活动知识产权评议工程示范项目验收评审的通知》（国知办函协字〔2018〕63号）要求，我局委托第三方单位对2017年重大经济科技活动知识产权评议工程示范项目承担单位整体工作开展情况和评议项目作了量化考核，并组织专家进行了验收评审。现将验收结果公布。

请各地方局全面总结优秀等次单位的工作经验，加大工作成果推广应用力度，进一步提高知识产权评议工作水平。

特此通知。

国家知识产权局办公室

2018年5月2日
