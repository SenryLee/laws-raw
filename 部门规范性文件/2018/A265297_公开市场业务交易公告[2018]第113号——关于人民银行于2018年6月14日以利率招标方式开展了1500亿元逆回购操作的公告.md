# 公开市场业务交易公告[2018]第113号——关于人民银行于2018年6月14日以利率招标方式开展了1500亿元逆回购操作的公告

## 公开市场业务交易公告

[2018]第113号

人民银行于2018年6月14日以利率招标方式开展了1500亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 700亿元 | 2.55% |
| 14天 | 500亿元 | 2.70% |
| 28天 | 300亿元 | 2.85% |

中国人民银行公开市场业务操作室

二〇一八年六月十四日
