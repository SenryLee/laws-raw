# 国家文物局办公室关于郝家台遗址保护规划的意见

办保函〔2018〕1066号

河南省文物局：

你局《关于再次上报漯河郝家台遗址保护规划的请示》（豫文物〔2018〕59号）收悉。经研究，我局暂不同意所报规划。

一、所报规划应做以下必要修改和完善：

（一）应加强与专业考古单位的合作，充分梳理已有考古研究成果和2015-2016年考古勘探成果，在此基础上理清遗址分布范围、价值与保存现状，合理确定规划范围、保护对象与环境要素等，明确规划思路和措施。

（二）深化现状评估，科学评价保护区划内城乡建设、道路、农田等情况以及文物影响，合理调整保护区划及其具体边界，确定管理规定和建设控制要求。应将京广铁路西侧城墙、城壕等遗迹纳入保护范围，尽可能完整保留城址结构。补充说明建设控制地带的划定依据。

（三）加强保护措施与现状评估结论的对应性，明确保护对象、类型及要求，增加铁路运营振动影响监测内容。

（四）进一步完善专项规划内容，增强针对性和可操作性。环境整治规划应明确整治对象、目标、范围和措施；客观评估建设陈列展示馆、游客服务中心的必要性和运营维护问题，避免过度展示；进一步论证村庄搬迁计划的必要性与可行性，合理确定村庄搬迁规模、人口调控措施等。

（五）完善考古工作规划内容。考古工作应以黄淮地区龙山时代社会面貌、城市建造特点、古环境为研究重点，明确研究课题、技术路线、工作安排等。

（六）完善管理规划内容，明确管理机构、权责和运行机制等内容；做好与相关规划的衔接。

（七）进一步规范图文表达，明确图例标注；完善安防专项规划图；补充社会调控规划数据和规划分期图。

二、请你局指导有关单位根据上述意见进一步修改和完善郝家台遗址保护规划，按程序另行报批。

国家文物局办公室

2018年11月5日
