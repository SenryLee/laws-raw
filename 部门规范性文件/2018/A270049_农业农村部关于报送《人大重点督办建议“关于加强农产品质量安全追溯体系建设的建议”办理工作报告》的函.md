# 农业农村部关于报送《人大重点督办建议“关于加强农产品质量安全追溯体系建设的建议”办理工作报告》的函

农质函〔2018〕3号

根据《关于做好重点督办建议有关工作的通知》（常办联字〔2018〕22号）精神，我部会同发展改革委、财政部、市场监管总局对重点督办的“关于加强农产品质量安全追溯体系建设的建议”内容进行了认真研究，按要求完成了办理工作。我们对办理工作进行了认真总结，形成了《人大重点督办建议“关于加强农产品质量安全追溯体系建设的建议”办理工作报告》，并征求了相关部门意见，现报送你单位。

农业农村部

2018年10月17日
