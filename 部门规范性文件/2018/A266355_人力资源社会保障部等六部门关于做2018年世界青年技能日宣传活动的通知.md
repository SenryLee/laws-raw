# 人力资源社会保障部等六部门关于做2018年世界青年技能日宣传活动的通知

人社部函〔2018〕68号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）、工业和信息化厅（委、局）、商务厅（局）、国资委、总工会、团委：

2014年12月18日，第69届联合国大会通过决议，将每年的7月15日确定为世界青年技能日。近年来，我国技能人才培养工作取得了显著进展，在第44届世界技能大赛上中国代表团取得了优异成绩，上海成功获得第46届世界技能大赛举办权，技能人才队伍不断壮大。为了进一步营造劳动光荣、技能宝贵、创造伟大的社会氛围，鼓励更多青年走上技能成才之路，人力资源社会保障部、工业和信息化部、商务部、国资委、全国总工会、共青团中央决定联合开展2018年世界青年技能日宣传活动，现就有关事项通知如下：

一、时间和主题

（一）时间：2018年7月15日

（二）主题：新时代 新技能 新梦想

二、宣传重点

各地要结合世界青年技能日主题，全面梳理总结青年技能人才培养方面的经验，展示人才培养成就，宣传活动重点突出以下内容，并结合各地各单位实际不断丰富。

（一）宣传政策措施。宣传党的十九大报告关于技能人才队伍建设、弘扬劳模精神和工匠精神的决策部署。宣传党和国家关于新时期产业工人队伍建设改革、提高技术工人待遇、推行终身职业技能培训制度等政策措施。宣传国家和地方在创新技能人才培养培训、评价使用、竞赛选拔、表彰激励等方面的政策措施。

（二）宣传发展成就。宣传技工教育在人力资源开发工作中的重要地位，梳理技工教育在不同历史时期的发展成就和贡献。宣传技工院校人才培养模式和办学特色、技能脱贫千校行动阶段性成果、工学一体校企合作成果、技工院校优秀毕业生技能成才的经验做法等。

（三）宣传重点活动。紧扣世界青年技能日主题，重点宣传技能人才培养领域重点活动。宣传第44届世界技能大赛中国代表团取得的优异成绩，展示技能人才培养成果；宣传2018年中国技能大赛各比赛项目，展示各地选手风采；宣传第一届全国技工院校教师职业能力大赛，展示师资队伍建设成果。

（四）宣传先进典型。宣传在世界技能大赛等技能竞赛中获奖以及受到各级党委、政府表彰的优秀青年技能人才的成长经历、突出成绩、先进事迹等。宣传历届中华技能大奖获得者、全国技术能手和享受国务院特殊津贴的高技能人才的先进事迹。

三、工作要求

（一）做好组织协调。各地人社部门要高度重视、精心策划、精准发力，制定具体方案，明确责任分工，组织技工院校、职业培训机构做好世界青年技能日宣传工作。要主动争取同级宣传主管部门及新闻单位对此次宣传工作的重视和支持，积极邀请当地主要领导出席世界青年技能日有关活动，邀请社会各界代表参与宣传活动。要会同其他有关部门，组织各类企业、各级工会和共青团参与相关宣传活动，扩大世界青年技能日影响力。

（二）提升宣传效果。宣传活动要针对重点宣传对象，精准宣传，精心组织，讲求实效。要面向青年学生和学生家长重点宣传青年技能人才的典型事迹，宣传技能成才、技能报国的理念。要面向农村地区、贫困地区重点宣传技能扶贫政策、技能脱贫千校行动成果，引导建档立卡贫困家庭子女通过学习技能，走技能脱贫之路。要面向社会大众重点宣传技工教育发展成就，提高全社会对青年技能成才、技能就业的认可程度。

（三）扩大宣传影响力。要将集中宣传与日常宣传相结合，传统媒体与新兴媒体相结合，进行多层次、多角度、全方位的宣传，扩大宣传影响力。要组织主题活动，7月15日，各地人社部门要组织本区域内各技工院校、职业培训机构，会同工会、共青团组织及其他有关部门在公共场所举办“世界青年技能日宣传活动”。要进行集中宣传，在世界青年技能日宣传活动期间，充分发挥广播、电视、报刊等传统媒体以及微博、微信、互联网等新兴媒体作用，及时刊发宣传材料。要形成长期宣传机制，在技工院校校园内广泛张贴技能成才宣传材料，弘扬劳模精神和工匠精神，营造劳动光荣的社会风尚和精益求精的敬业风气。

（四）及时总结上报。各地人社部门要认真总结上报青年技能人才队伍建设的典型案例、特色做法、工作亮点等素材，及时汇总上报举办世界青年技能日宣传活动的新闻材料，以便向中央有关媒体和部属媒体推荐报道。各地要做好宣传活动总结，并于7月底前报人力资源社会保障部职业能力建设司。

四、其他有关事项

人力资源社会保障部将继续统一制作世界青年技能日宣传画、宣传折页，各地可直接从人力资源社会保障部出版集团网站（www.class.com.cn）下载宣传画电子版，用于网站、电子屏幕展示，或根据实际需求，制作纸质宣传画、宣传折页并广泛张贴、发放。
