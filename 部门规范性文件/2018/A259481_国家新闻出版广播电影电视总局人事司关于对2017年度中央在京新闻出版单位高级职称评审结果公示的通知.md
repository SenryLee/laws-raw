# 国家新闻出版广播电影电视总局人事司关于对2017年度中央在京新闻出版单位高级职称评审结果公示的通知

## 关于对2017年度中央在京新闻出版单位高级职称评审结果公示的通知

新广人教〔2018〕4号

经国家新闻出版广电总局新闻专业、出版专业、经济会计专业、工程专业高级职称评审委员会评审，2017年度中央在京新闻出版单位新闻专业、出版专业、经济专业、会计专业、工程专业高级职称评审结果已产生。按照工作程序，现将评审结果予以公示，公示时间为2018年1月2日-1月10日。如有异议，请于公示期内以书面或电话形式向总局人事司反映。

国家新闻出版广电总局人事司电话：86098763

地址：北京市复兴门外大街2号，邮编：100866

附件：

1.2017年度中央在京新闻单位新闻专业高级职称评审通过人员名单

2.2017年度中央在京出版单位出版专业高级职称评审通过人员名单

3.2017年度中央在京新闻出版单位经济专业高级职称评审通过人员名单

4.2017年度中央在京新闻出版单位会计专业高级职称评审通过人员名单

5.2017年度中央在京新闻出版单位工程专业高级职称评审通过人员名单

国家新闻出版广电总局人事司

2018年1月2日
