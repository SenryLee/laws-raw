# 住房城乡建设部办公厅关于2017年四季度建筑工程施工转包违法分包等违法行为查处情况的通报

建办市函〔2018〕84号

各省、自治区住房城乡建设厅，直辖市建委，新疆生产建设兵团建设局：

现将2017年四季度各地住房城乡建设主管部门上报的建筑工程施工转包违法分包等违法行为查处情况通报如下：

一、基本情况

按照《住房城乡建设部办公厅关于定期报送打击建筑工程施工转包违法分包等违法行为情况的通知》（建办市函[2017]224号）要求，全国31个省、自治区、直辖市和新疆生产建设兵团向我部报送了2017年四季度建筑工程施工转包违法分包等违法行为查处情况（查处汇总情况见附件）。各地排查项目82070个，涉及建设单位55958家、施工单位62653家。

二、违法行为查处情况

（一）违法行为类别情况。

各地共排查出2747个项目存在各类建筑市场违法行为。其中，存在违法发包行为的项目160个，占违法项目总数的5.82%；存在转包行为的项目52个，占违法项目总数的1.89%；存在违法分包行为的项目96个，占违法项目总数的3.49%；存在挂靠行为的项目30个，占违法项目总数的1.09%；存在“未领施工许可证先行开工”等其它市场违法行为的项目2409个，占违法项目总数的87.71%。

各地查处有违法行为的建设单位1228家；有违法行为的施工企业2066家，其中，有转包行为的企业53家，有违法分包行为的企业95家，有挂靠行为的企业15家，有出借资质行为的企业24家，有其它违法行为的企业1879家。

（二）处罚类别情况。

各地住房城乡建设主管部门对存在违法行为的企业和人员，分别采取了停业整顿、限制投标资格、没收违法所得、吊销执业资格、罚款等一系列行政处罚或行政管理措施。其中，责令停业整顿的企业189家，限制投标资格的企业105家，给予通报批评、诚信扣分等处理的企业953家；没收违法所得金额15万元，吊销执业资格10人，给予通报批评、诚信扣分等处理的个人854人；罚款总额33283.46万元（含个人罚款1528.8万元）。

（三）各地查处工作情况。

从各地查处的违法工程项目数量看，山东、重庆2省（市）查处力度较大，分别查处项目394个、338个（见图1）。

对以上查处工作力度大、位居前列的省、直辖市予以表扬。

请各地进一步提高思想认识，严格按照建办市函[2017]224号文件要求，继续严厉打击建筑工程施工转包违法分包等违法行为，加大对各类违法行为的查处力度，加强对市、县级建设主管部门工作的督查，进一步明确工作责任人，加强数据核实、把关，于每季度结束后10日内及时将本行政区域内统计数据和基本情况报我部建筑市场监管司。
