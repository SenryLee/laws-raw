# 国家广播电视总局通告〔2018〕3号——国家广播电视总局关于2017年度全国电视动画片制作发行情况的通告

## 国家广播电视总局通告

〔2018〕3号

## 国家广播电视总局关于2017年度全国电视动画片制作发行情况的通告

根据电视动画片管理的有关规定，现将国家广播电视总局电视动画片审查委员会、各省级电视动画片审查机构，以及受总局委托的中央广播电视总台电视动画片审查机构2017年度审查发行的国产电视动画片情况予以通告。

附件：1.2017年度核发《国产电视动画片发行许可证》目录

2.2017年度推荐播出优秀动画片目录

国家广播电视总局

2018年8月27日
