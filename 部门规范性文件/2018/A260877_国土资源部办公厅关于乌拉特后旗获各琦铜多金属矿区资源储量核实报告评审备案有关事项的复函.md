# 国土资源部办公厅关于乌拉特后旗获各琦铜多金属矿区资源储量核实报告评审备案有关事项的复函

国土资厅函〔2018〕92号

巴彦淖尔西部铜业有限公司:

《关于<内蒙古自治区乌拉特后旗获各琦铜多金属矿区资源储量核实报告>在内蒙古自治区国土资源厅备案的请示》（西铜字〔2017〕139号）收悉。

经研究，按照《国土资源部关于完善矿产资源开采审批登记管理有关事项的通知》（国土资规〔2017〕16号）的有关精神，乌拉特后旗获各琦铜多金属矿区矿产资源储量报告（含核实报告）评审备案工作由内蒙古自治区国土资源厅负责。请按相关规定到该厅办理。

2018年1月22日
