# 国家文物局办公室关于故宫延庆殿区古建筑群油饰、彩画及裱糊保护项目的意见

办保函〔2018〕330号

北京市文物局：

你局《关于故宫延庆殿区古建筑群油饰、彩画保护工程设计方案的请示》（京文物〔2018〕102号）收悉。经研究，我局意见如下：

一、该项目前期勘察分析不够细化，保护措施不尽完善，暂不同意所报故宫延庆殿区古建筑群油饰、彩画保护工程设计方案。

二、具体修改意见如下：

（一）完善勘察与检测分析。补充环境监测、红色和黑色颜料分析、西配殿彩画表面涂刷材料分析等数据；核实胶结材料分析结果中发现蛋类蛋白的情况；校核对制作技术的现场勘查结果与分析检测结果。

（二）应根据对延庆殿区古建筑群的价值评估，结合后续展示利用，明确该区油饰、彩画和裱糊修缮的总体原则，根据评估结论进一步论证设计思路，研提现状保护、重绘、补绘等不同做法，明确各项措施所适用的具体范围、预期效果，并在图纸中予以标注。对价值较高的早期彩画宜尽可能保留。

（三）进一步完善保护修复试验。补充将原有材料作为保护材料的修复试验，做好常用和传统加固材料的比对工作，如麻灰地仗的空鼓回贴加固等；建议研究彩画表面泛白的形成机理和病害治理技术。

（四）进一步完善修缮材料和工艺。补充细化彩画重绘、补绘的工艺和材料要求，修缮设计应重点参考原有工艺做法，工艺改变应进行审慎论证；注意比对现状勘察和修缮设计一览表；在老化产物和对彩画影响不明确的情况下，审慎使用显现加固剂；贴金表面油垢清洗应慎重，避免残留清洗液渗入金层下部造成金层脱落。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善后，另行报批。

国家文物局办公室

2018年4月16日
