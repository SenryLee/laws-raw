# 农业部办公厅关于报送2017年度养殖环节病死猪无害化处理情况的通知

农办医〔2018〕2号

各省、自治区、直辖市、计划单列市畜牧兽医（农牧、农业）厅（局、委、办）:

按照《动物防疫等补助经费管理办法》和《动物疫病防控财政支持政策实施指导意见》等有关文件精神，为做好2017年度养殖环节无害化处理补助经费测算工作，提高“包干下达”经费的科学性和合理性，现请你省（区、市）认真统计核实2017年3月1日至2018年1月31日期间养殖环节病死猪无害化处理数量。对于处理率（处理数量/养殖量×100%）高于10%的县，或处理数量较往年同期增幅20%以上的县，要逐一列出，并说明原因和核查情况。请于2018年2月9日前，以正式文件形式将无害化处理病死猪总数和统计核查情况报我部。请各省（区、市）高度重视此项工作，严格按照农财两部有关文件精神，切实加强病死畜禽无害化处理监管，加强过程监管和绩效考核，强化信息公开，防范廉政风险。要不断提升科学养殖水平，有效降低动物疫病发生风险和死亡率。
