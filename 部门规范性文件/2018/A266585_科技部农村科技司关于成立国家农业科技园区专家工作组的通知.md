# 科技部农村科技司关于成立国家农业科技园区专家工作组的通知

国科农函〔2018〕59号

各省、自治区、直辖市及计划单列市科技厅（委、局），新疆生产建设兵团科技局，各有关单位，各有关专家：

为进一步提高国家农业科技园区管理水平，充分发挥专家在园区管理方面的决策咨询和技术指导作用，根据《国家农业科技园区管理办法》要求，经国家农业科技园区协调指导小组管理办公室批准，现成立国家农业科技园区专家工作组。

专家工作组受国家农业科技园区协调指导小组管理办公室（科技部农村科技司）委托，负责农业科技园区发展战略与政策研究，为农业科技园区建设提供咨询和技术指导，并参与相关论证、评审、过程监管、验收、评估等工作。任期自文件公布之日起至2020年12月31日。

附件：1. 国家农业科技园区专家工作组名单

2. 国家农业科技园区专家工作组工作规则

科技部农村科技司
