# 国家广播电视总局办公厅关于2018年3月全国引进境外影视剧许可证情况的通知

广电办发〔2018〕19号

各省、自治区、直辖市新闻出版广电局：

根据总局电视剧管理的有关规定，现将2018年3月全国引进境外影视剧的情况予以通知。

附件：2018年3月同意发行的境外影视剧目录

国家广播电视总局办公厅

2018年5月15日
