# 国家文物局关于山西中条山集团胡家峪矿业有限公司桐木沟铜矿采区涉及北峪铜矿遗址的意见

文物保函〔2018〕627号

山西省文物局：

你局《关于山西中条山集团胡家峪矿业有限公司桐木沟铜矿采区涉及北峪铜矿遗址有关事宜的请示》（晋文物〔2018〕57号）收悉。经研究，我局意见如下：

一、原则同意山西中条山集团胡家峪矿业有限公司继续使用省级文物保护单位北峪铜矿遗址保护范围内已有矿区设备。

二、请你局指导有关单位加强日常管理，不得随意扩大巷道范围。如涉及在省级文物保护单位北峪铜矿遗址保护范围内进行其他建设工程或者爆破、钻探、挖掘等作业的，应按照《中华人民共和国文物保护法》第十七条规定报批。

专此函复。

国家文物局

2018年6月14日
