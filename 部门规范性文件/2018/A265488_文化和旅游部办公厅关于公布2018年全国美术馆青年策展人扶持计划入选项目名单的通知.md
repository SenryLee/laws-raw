# 文化和旅游部办公厅关于公布2018年全国美术馆青年策展人扶持计划入选项目名单的通知

办艺发〔2018〕33号

各省、自治区、直辖市文化厅（局），新疆生产建设兵团文化广播电视局，中央军委政治工作部宣传局，中国美术馆、中国国家画院：

2018年全国美术馆青年策展人扶持计划评选工作已经顺利完成。经过专家小组初评和复评，并经文化和旅游部审核，共评出9个入选项目。现入选项目名单予以公布，文化和旅游部对每个入选项目给予10万元经费补贴。

请相关单位和人员严格按照《文化部办公厅关于开展2018年全国美术馆青年策展人扶持计划的通知》（办艺函〔2018〕43号）要求，做好入选项目的组织实施工作。各有关文化厅（局）应采取有力措施，加强监督、指导和管理，做好项目内容的审核把关，确保项目顺利实施。

特此通知。
