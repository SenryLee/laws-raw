# 交通运输部办公厅关于2018年中国技能大赛——第十届全国交通运输行业职业技能大赛优胜单位和个人的通报

交办人教〔2018〕171号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

2018年中国技能大赛——第十届全国交通运输行业职业技能大赛于2018年11月闭幕，共有来自全国30个省（自治区、直辖市）代表队的248名职业组选手和415名学生组选手分别参加了水路危险货物运输员、城市轨道交通列车司机、城市轨道交通行车值班员和筑路工4个职业（工种）全国总决赛。总决赛成绩经大赛组委会确认有效。经交通运输部同意，现将优胜单位和个人名单公布如下：

一、水路危险货物运输员大赛

（一）江苏省交通运输厅等10家单位获团体前十名（名单见附件1）。

（二）大连港油品码头公司李云龙获个人一等奖，日照港集团有限公司李更新等4人获个人二等奖，日照港集团有限公司田丰瑞等5人获个人三等奖（名单见附件2）。

（三）上海市交通委员会等14家单位获优秀组织奖（名单见附件3）。

（四）南京港（集团）有限公司获大赛贡献奖。

二、城市轨道交通列车司机大赛

（一）四川省交通运输厅等10家单位获职业组团体前十名（名单见附件4）。

（二）湖南铁道职业技术学院等10所院校获学生组团体前十名（名单见附件5）。

（三）广州地铁集团有限公司黄伟强获得职业组个人一等奖，广东广佛轨道交通有限公司李冲等4人获职业组个人二等奖，深圳市地铁集团有限公司黄锦华等5人获职业组个人三等奖（名单见附件6）。

（四）湖南铁道职业技术学院钟杰、刘舟扬、刘派获学生组个人一等奖，广州市交通运输职业学校曾俊启等12人获学生组个人二等奖，浙江交通职业技术学院宦浩炜等15人获学生组个人三等奖（名单见附件7）。

（五）广西壮族自治区交通运输厅等42家单位获大赛优秀组织奖（名单见附件8）。

（六）广州地铁集团有限公司、重庆道驰科技有限公司、庞贝捷漆油贸易（上海）有限公司获大赛贡献奖。

（七）郑州捷安高科股份有限公司获大赛特殊贡献奖。

三、城市轨道交通行车值班员大赛

（一）河南省交通运输厅等10家单位获职业组团体前十名（名单见附件9）。

（二）广州铁路职业技术学院等10所院校获学生组团体前十名（名单见附件10）。

（三）广东广佛轨道交通有限公司严家升获职业组个人一等奖，广州地铁集团有限公司屈跃华等4人获职业组个人二等奖，南宁轨道交通集团有限责任公司陈昱等5人获职业组个人三等奖（名单见附件11）。

（四）广州铁路职业技术学院王菲、刘家明、谭彤、张佳霖、赵奕丹获学生组个人一等奖，广东交通职业技术学院许晓泽等20人获学生组个人二等奖，武汉铁路职业技术学院陈媛媛等25人获学生组个人三等奖（名单见附件12）。

（五）上海市交通委员会等44家单位获大赛优秀组织奖（名单见附件13）。

（六）广州地铁集团有限公司、重庆道驰科技有限公司、庞贝捷漆油贸易（上海）有限公司获大赛贡献奖。

（七）郑州捷安高科股份有限公司获大赛特殊贡献奖。

四、筑路工大赛

（一）江苏省交通运输厅等10家单位获职业组团体前十名（名单见附件14）。

（二）湖南交通职业技术学院等10所院校获学生组团体前十名（名单见附件15）。

（三）重庆市永川区公路管理所唐勇获压路机职业组个人一等奖，重庆市公路养护管理段李传华等4人获压路机职业组个人二等奖，湖北省宜都市三立路桥工程建设有限责任公司兰方新等5人获压路机职业组个人三等奖；成都华川公路建设集团有限公司晏启红获挖掘机职业组个人一等奖，南京市路桥工程总公司顺美兵等4人获挖掘机职业组个人二等奖，杭州路达公路工程总公司秦帅等5人获挖掘机职业组个人三等奖（名单见附件16）。

（四）四川交通职业技术学院李兴国获学生组个人一等奖，湖南交通职业技术学院李旺等4人获学生组个人二等奖，云南交通职业技术学院袁志聪等5人获学生组个人三等奖（名单见附件17）。

（五）贵州省交通运输厅等31家单位获大赛优秀组织奖（名单见附件18）。

（六）中联重科股份有限公司获大赛特殊贡献奖。

根据大赛奖励办法，各职业（工种）职工组全国总决赛前20名的优胜选手，由部授予“全国交通技术能手”称号。经对大赛总决赛成绩审核认定，部决定授予大连港油品码头公司李云龙等76名同志“全国交通技术能手”称号，并颁发证书（名单见附件19）。重庆市永川区公路管理所唐勇等4名同志为已获得“全国交通技术能手”称号的优胜选手，不再重复授奖（名单见附件20）。

希望优胜单位和个人珍惜荣誉，再接再厉，充分发挥先锋模范作用，大力弘扬工匠精神，积极促进大赛成果转化，不断提升技能水平，为交通强国建设作出更大贡献。
