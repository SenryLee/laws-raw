# 国家烟草专卖局办公室关于2018年三季度工商统计数据质量的通报

国烟办综〔2018〕414号

各省级局（公司）、工业公司，中国烟草实业发展中心：

2018年三季度，卷烟生产经营统计系统运行正常，数据质量稳定，因数据错误重报次数同比减少，卷烟生产打码报废明显降低，出入库扫码、条烟打码操作均保持良好状态。现将具体情况通报如下：

一、工业企业

（一）总体情况。

1.数据报送情况。三季度各工业企业日报未发生重报，零重报率为100%（详见附件1）。

2. 卷烟码段报废情况。三季度全国卷烟打码报废率为0.01%,较去年同期0.03%明显降低。江苏、江西、广西、陕西中烟工业有限责任公司报废量低于10万支，湖南中烟有限责任公司报废率下降较多，上海烟草集团有限责任公司、四川中烟工业有限责任公司报废率略高（详见附件1）。

3.各省级工业公司卷烟商业到货扫码不可识别情况。工业企业扫码到商业不可识别率为0.003%，较去年同期0.01%明显降低。广西、重庆、四川、陕西中烟工业有限责任公司发货到商业扫码不可识别量小于30万支，上海烟草集团有限责任公司、广东中烟工业有限责任公司扫码到商业不可识别率略高（详见附件1）。

（二）月报情况。

丝束购耗存月报填报错误，如四川中烟工业有限责任公司；生产耗嘴棒月报填报错误，如吉林烟草工业有限责任公司。

二、商业企业

（一）总体情况。

1.数据报送情况。各商业企业共发生重报3次，比去年同期减少1次，33个省级公司中30个未发生数据重报，350个地市级公司中有347个未发生重报，零重报比率达到99.1%（详见附件2）。

2.到货入库识别情况。三季度全国商业到货入库不可识别率明显降低。北京、山西、内蒙、大连、江苏、浙江、福建、江西、山东、深圳、重庆、贵州、云南、青海、宁夏到货入库均实现百分之百识别，广东到货入库不可识别率略高，超过0.02%（详见附件2）。

3.打码情况。三季度全国商业打码率为99.97%，高于去年同期0.1个百分点。27家省级局所属单位实现全部打码销售，天津打码率略低（详见附件3）。

（二）主要问题。

操作错误。如河北罚没烟价格数据录入错误，吉林、河南系统操作错误。

三、下一步工作要求

（一）请各单位加强对统计、业务操作人员统计制度及操作规范的培训，针对本次通报情况及今年统计专项检查中自查工作查找的问题，立即完善配套制度并进行整改，确保数据质量。

（二）请各单位高度重视业务系统基础信息维护工作，确保信息更新及时、准确，杜绝影响数据准确问题出现。

附件：1.2018年三季度各省级工业公司重报及生产报废和发货到商业扫码不可识别情况表

2.2018年三季度各省级局重报及到货扫码不可识别情况表

3.2018年三季度各省级局条烟打码率情况表
