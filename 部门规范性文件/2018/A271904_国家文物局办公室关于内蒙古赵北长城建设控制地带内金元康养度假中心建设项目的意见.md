# 国家文物局办公室关于内蒙古赵北长城建设控制地带内金元康养度假中心建设项目的意见

办保函〔2018〕1139号

内蒙古自治区文物局：

你局《金元康养度假中心涉及战国赵北长城遗址方案的请示》（内文物字〔2018〕94号）。经研究，我局暂不同意在赵北长城建设控制地带内实施金元康养度假中心建设项目。

一、对所报方案提出以下修改完善意见：

（一）应对照各类规划和管理文件中有关该段长城的保护管理规定和建设控制要求，进一步校核拟建项目相关设计。

（二）应控制项目建设总体规模，避免贪大求全。进一步完善建筑选址，尽量远离长城遗址。深化建筑设计，明确建筑体量和高度，建筑形式应充分借鉴吸收当地传统建筑特征。

（三）进一步深化场地的绿化景观设计，应选种当地特色植物构造生态景观带，对新建建筑进行遮挡，减少项目对北侧长城景观风貌的影响。

（四）应补充相关设计，对该段长城的价值及保护管理状况等，以适当方式进行保护、阐释和展示。

（五）进一步规范和完善方案文本和图纸，如补充拟建项目与长城保护区划关系图、规划建筑高度控制图；补充各功能区建筑高度、体量等设计说明。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2018年11月27日
