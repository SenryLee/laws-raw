# 商务部办公厅关于印发《2018年商务执法工作要点》和《2018年商务执法领域市场秩序专项整治方案》的通知

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门:

为打造良好营商环境和消费环境、促进消费升级，现将《2018年商务执法工作要点》及《2018年商务执法领域市场秩序专项整治方案》印发给你们，请结合本地实际，认真贯彻执行。

商务部办公厅

2018年7月17日
