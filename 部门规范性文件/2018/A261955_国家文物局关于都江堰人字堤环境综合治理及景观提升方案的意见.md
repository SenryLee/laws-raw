# 国家文物局关于都江堰人字堤环境综合治理及景观提升方案的意见

文物保函〔2018〕203号

四川省文物局：

你局《关于报送〈都江堰滨江东岸土地一级整理启动段（都江堰-人字堤）环境综合治理及景观提升方案〉的请示》（川文物〔2017〕128号）收悉。经研究，我局意见如下：

一、原则同意所报都江堰人字堤环境综合治理及景观提升方案，并提出以下修改意见：

（一）进一步评估拟实施项目对都江堰价值和历史风貌的影响，并确保新建相关设施和游客活动不影响人字堤正常发挥防洪功能。

（二）展示内容应围绕世界文化遗产价值阐释进行设计。完善展示流线和标识系统设计，明确项目建设区域与景区入口、景区内部道路的衔接关系，可适当增加展示、服务设施，并补充游客安全防护措施。

（三）减少整治区域内的硬化地面和人工水面面积，整治后的停车场面积不得超过现有停车场面积，并改用生态停车场设计，以优化都江堰参观游线的总体布局，增加人字堤绿化面积。

（四）深化项目区域现状调查评估，明确各类建筑、构筑物、水利设施的价值和功能，对于非文物保护单位但具有历史价值的建筑、构筑物、水利设施等应尽可能保留、保护和展示。

（五）对于项目区域内与世界文化遗产保护展示无关的建筑，确需拆除的，应对拆除后的土地用途予以明确；如现状保留的，应明确其今后功能和风貌整治要求，建议调整为世界文化遗产保护、管理、展示等功能。

（六）简化新增设栏杆、灯杆等设施的外观设计，栏杆宜采用轻质、牢固、成本较低且具有地域特色的材质式样，高杆灯的高度宜适当降低，避免对世界文化遗产景观风貌造成负面景观影响。

二、请你局指导相关单位对拟实施项目区域进行全面的考古调查和勘探，明确地下遗址、遗迹分布情况，厘清该区域的历史格局，并根据考古调查和勘探情况完善方案设计。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，按照《中华人民共和国文物保护法》第十七条的规定，报四川省人民政府批准后实施。

四、项目实施过程中，请你局加强管理，确保工程质量和工地安全，遇有文物遗存等重要发现，应立即停止施工并组织研究，调整设计方案。

五、请你局指导、督促相关单位尽快完成青城山—都江堰世界文化遗产保护管理规划编制工作并履行审核程序，进一步统筹考虑该世界文化遗产的保护、管理、展示等问题。

国家文物局
