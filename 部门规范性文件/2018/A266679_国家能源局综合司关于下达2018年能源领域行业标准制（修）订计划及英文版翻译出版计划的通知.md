# 国家能源局综合司关于下达2018年能源领域行业标准制（修）订计划及英文版翻译出版计划的通知

国能综通科技〔2018〕100号

各有关单位：

经研究，现将2018年能源领域行业标准制（修）订计划（共计812项，见附件1）及2018年能源领域行业标准英文版翻译出版计划（共计62项，见附件2）下达给你们，请认真组织各有关标准化技术委员会、标准起草单位、翻译承担单位抓好落实，按时完成任务。

附件：1. 2018年能源领域行业标准制（修）订计划项目汇总表

2. 2018年能源领域行业标准英文版翻译出版计划项目汇总表

国家能源局综合司

2018年7月10日
