# 国家能源局综合司关于印发《国家能源局2018年资质管理工作要点》的通知

国能综通资质〔2018〕49号

各派出能源监管机构：

为贯彻落实全国能源工作会议精神和局党组有关工作部署，扎实做好2018年资质管理工作，资质中心制定了《国家能源局2018年资质管理工作要点》。请你们结合工作实际，认真组织实施。

附件：国家能源局2018年资质管理工作要点

国家能源局综合司

2018年3月23日
