# 国家文物局关于全国重点文物保护单位荆坪村古建筑群保护范围内房屋重建项目的意见

文物保函〔2018〕446号

湖南省文物局：

你局《关于在全国重点文物保护单位荆坪村古建筑群保护范围内村民修建房屋的请示》（湘文物报〔2017〕138号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、对该项目提出以下修改意见：

（一）重建房屋应坚持原址翻建，不得超过原有房屋的规模、体量和高度，且应基本保持该民居的传统外观、形式和材料。

（二）考虑到居民使用的实际需求，重建后的房屋内部可以进行合理改造，增加现代生活设施，提升建筑物理性能和居住的适宜性。

（三）由于重建房屋距文物建筑较近，应补充工程实施中的文物保护应急预案，确保文物建筑安全。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》的规定履行相应的审批手续后实施。工程施工期间，请你局加强监管，确保文物安全。

国家文物局

2018年5月8日
