# 国家发展改革委办公厅关于同意延长江苏省泗阳县佳鼎实业有限公司等八家公司债券核准文件有效期的函

发改办财金〔2018〕1476号

江苏省、浙江省、湖南省、广东省、四川省、贵州省发展改革委：

报来《关于转报泗阳县佳鼎实业有限公司申请延长公司债券核准文件有效期的请示》（苏发改财金发〔2018〕1032号）、《关于转报盐城市城南新区开发建设投资有限公司申请延长绿色债券核准文件有效期的请示》（苏发改财金发〔2018〕1043号）、《关于转报安吉县国有资本投资运营有限公司要求延长公司债券核准文件有效期的请示》（浙发改财金〔2018〕513号）、《关于申请延长永州市冷水滩区高科技工业园建设投资有限责任公司债券核准文件有效期的请示》（湘发改〔2018〕311号）、《关于延长佛山市禅城区城市设施开发建设有限公司债券批文有效期的请示》（粤发改财金〔2018〕476号）、《关于转报资阳市凯利建设投资有限责任公司延期发行2018年企业债券申请的请示》（川发改〔2018〕373号）、《关于转报眉山市东坡发展投资有限公司延期发行2018年企业债券申请的请示》（川发改〔2018〕391号）、《关于转报仁怀市水务投资开发有限责任公司延长企业债券核准文件有效期的请示》（黔发改财金〔2018〕1294号）收悉。经研究，现函复如下。

一、同意将《国家发展改革委关于江苏省泗阳县佳鼎实业有限公司发行公司债券核准的批复》（发改企业债券〔2017〕334号）文件有效期延长12个月至2019年11月24日。

同意将《国家发展改革委关于江苏省盐城市城南新区开发建设投资有限公司发行绿色债券核准的批复》（发改企业债券〔2017〕329号）文件有效期延长12个月至2019年11月22日。

同意将《国家发展改革委关于浙江省安吉县国有资本投资运营有限公司发行城市停车场建设专项债券核准的批复》（发改企业债券〔2017〕338号）文件有效期延长12个月至2019年11月28日。

同意将《国家发展改革委关于湖南省永州市冷水滩区高科技工业园建设投资有限责任公司发行公司债券核准的批复》（发改企业债券〔2017〕354号）文件有效期延长12个月至2019年12月21日。

同意将《国家发展改革委关于广东省佛山市禅城区城市设施开发建设有限公司发行公司债券核准的批复》（发改企业债券〔2017〕345号）文件有效期延长12个月至2019年12月10日。

同意将《国家发展改革委关于四川省资阳市凯利建设投资有限责任公司发行公司债券核准的批复》（发改企业债券〔2017〕332号）文件有效期延长12个月至2019年11月24日。

同意将《国家发展改革委关于四川省眉山市东坡发展投资有限公司发行公司债券核准的批复》（发改企业债券〔2017〕330号）文件有效期延长12个月至2019年11月22日。

同意将《国家发展改革委关于贵州省仁怀市水务投资开发有限责任公司发行公司债券核准的批复》（发改企业债券〔2017〕337号）文件有效期延长12个月至2019年11月27日。

二、请你委督促发行人按照《公司法》《证券法》《企业债券管理条例》和有关规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

三、请你委督促发行人按要求及时做好信息披露及债券资金管理，按照核准的募集资金投向合规使用债券资金，认真落实偿债保障措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅

2018年10月16日
