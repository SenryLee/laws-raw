# 国家邮政局关于落实国务院大督查要求开展专项督查的通知

国邮电传〔2018〕48号

各省、自治区、直辖市邮政管理局，国家局直属各单位，机关各司室：

为推动党中央、国务院重大决策部署和政策措施贯彻落实，根据《国务院关于开展2018年国务院大督查的通知》要求，决定在全国邮政管理系统开展一次专项督查。现就有关事项通知如下：

一、总体要求

认真贯彻落实党的十九大精神、中央经济工作会议部署，紧紧围绕《政府工作报告》提出的目标任务，围绕经济社会发展和改革存在的突出问题，围绕处理好政府和市场关系，围绕深化“放管服”改革和转变政府职能，围绕人民群众和市场主体反映强烈的堵点、梗阻和瓶颈问题，切实发挥督查“利器”作用，推动各项政策落实和措施见效，确保党中央、国务院政令畅通、令行禁止，确保完成全年经济社会发展主要目标任务。

二、督查重点

在全面督查中央经济工作会议部署和《政府工作报告》提出目标任务的基础上，重点督查六个方面工作。

（一）打好三大攻坚战和实施乡村振兴战略

1.加大东西部扶贫协作和对口支援力度，及精准扶贫工作情况。

2.绿色发展相关工作情况。

3.深入推进农业供给侧结构性改革，推进乡村振兴战略情况。

（二）推进创新驱动发展

4.推动新旧动能转化，做大做强新兴产业集群，改造提升传统产业情况。

5.清理废止有悖于激励创新的陈规旧章、有碍于释放创新活力的繁文缛节情况。

6.对新产业新业态新模式实施包容审慎监管情况。

7.加强技能人才队伍培养，加大高技能人才激励等深化人才发展体制改革情况。

（三）深化“放管服”改革

8.全国深化“放管服”改革转变政府职能电视电话会议部署贯彻落实情况。

9.落实“五个为”和“六个一”要求（即为促进就业创业降门槛，为各类市场主体减负担，为激发有效投资拓空间，为公平营商创条件，为群众办事生活增便利；企业开办时间再减一半，项目审批时间再砍一半，政务服务一网通办，企业和群众办事力争只进一扇门，最多跑一次，凡是没有法律法规依据的证明一律取消）情况。

10.五年来国务院取消、下放或调整的简政放权事项落实情况。

11.全面实施全国统一的市场准入负面清单制度情况。

12.加快政府信息系统互联互通，打通信息孤岛情况。

13.全面推进政务公开情况。

14.全面推开“多证合一”、“证照分离”改革情况。

15.全面推行“双随机、一公开”监管，整合各类市场监管平台情况。

16.清理规范行政事业性收费情况。清理整顿中介服务收费情况。

（四）持续扩大内需

17.推动网购、快递健康发展情况。

18.“十三五”规划纲要确定的重大工程建设项目实施情况。

19.中央预算内投资项目开工建设、资金使用情况。

20.鼓励民间投资、放宽市场准入、破除各种隐性壁垒等政策措施落实情况。

（五）推进高水平开放

21.推进“一带一路”建设，深化沿线大通关合作情况。

22.扩大国际产能合作，带动中国制造和中国服务走出去情况。

23.全面落实准入前国民待遇加负面清单管理制度情况。

（六）保障和改善民生，改进作风

24.落实安全生产责任情况。

25.整治“四风”，特别是力戒形式主义、官僚主义情况。

三、有关要求

各单位要紧紧围绕中央经济工作会议部署和《政府工作报告》提出的任务要求，对照六个方面督查重点，认真开展全面自查，梳理政策措施落实情况，查找工作中存在的主要不足和突出问题，有针对性提出整改措施以及完善政策措施的工作建议。自查报告要坚持问题导向、目标导向，反映问题、提出整改措施及相关建议的篇幅应达到总篇幅的60%以上，务必于7月20日前报送国家局办公室。

国家邮政局

2018年7月10日
