# 人力资源社会保障部办公厅关于2018年度监理工程师资格考试合格标准有关问题的通知

人社厅发〔2018〕87号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局），大连市人力资源社会保障局：

根据2018年度监理工程师资格考试数据统计分析，经商住房城乡建设部，现将考试合格标准有关问题通知如下：

各科目合格标准

|  |  |  |
| --- | --- | --- |
| 科目名称 | 合格标准 | 试卷满分 |
| 建设工程合同管理 | 66 | 110 |
| 建设工程质量、投资、进度控制 | 96 | 160 |
| 建设工程监理基本理论与相关法规 | 66 | 110 |
| 建设工程监理案例分析 | 72 | 120 |

二、请各地按上述合格标准对监理工程师资格考试应试人员成绩进行复核，与我部人事考试中心核对相关数据，确认无误后，按要求逐项填写《2018年度监理工程师资格考试情况统计表》（见附件），于2018年8月31日前报我部人事考试中心备案，该表数据作为发放资格证书的依据。

三、请按照有关文件精神，及时向社会公布考试合格标准，并抓紧做好资格证书发放等考试后期的各项工作。

附件：2018年度监理工程师资格考试情况统计表

人力资源社会保障部办公厅

2018年8月13日
