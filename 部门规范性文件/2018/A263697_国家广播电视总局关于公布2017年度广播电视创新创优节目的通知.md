# 国家广播电视总局关于公布2017年度广播电视创新创优节目的通知

新广电发〔2018〕49号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央广播电视总台，中国教育电视台：

2017年，全国广播电视机构深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，坚定文化自信，坚持以人民为中心的创作导向，坚持“小成本、大情怀、正能量”，制作播出了一大批发展中国特色社会主义文化、传播社会主义核心价值观的好节目，受到广泛好评。为了发挥优秀广播电视节目的示范引领作用，经评议，确定中央人民广播电台《那年我高考》等8个广播节目、中央电视台《中国诗词大会（第二季）》等18个电视节目为“2017年度广播电视创新创优节目”，并给予每个广播节目15万元、每个电视节目20万元的资金扶持。

各广播电视机构要认真学习这些优秀节目的好做法、好经验，坚持讲品位、讲格调、讲责任，深入生活，扎根人民，创作生产更多思想精深、艺术精湛、制作精良相统一的好节目，更好地满足新时代人民日益增长的美好生活需要。

扶持资金将由总局下拨至各省新闻出版广电局和中央广播电视总台，各省局负责将扶持资金分发至所属相关广播电视机构。请各省局和中央广播电视总台于4月20日前，将收款收据和账户信息（收款单位、开户银行、账号）用邮政特快专递（EMS）邮寄至总局宣传司（地址：北京市西城区复兴门外大街2号，邮政编码：100866）。

附件：2017年度广播电视创新创优节目名单

国家广播电视总局

2018年3月30日
