# 司法部办公厅关于同意林汉武等393名委托公证人2019年度注册的通知

司办通〔2018〕171号

中国法律服务（香港）有限公司：

根据《中国委托公证人（香港）管理办法》规定，经我部审查，决定对林汉武等393名中国委托公证人（香港）予以2019年度注册。请你公司通知中国委托公证人（香港）协会代我部办理注册手续。

附件： 中国委托公证人（香港）2019年度注册名单（393名）

司法部办公厅

2018年12月17日
