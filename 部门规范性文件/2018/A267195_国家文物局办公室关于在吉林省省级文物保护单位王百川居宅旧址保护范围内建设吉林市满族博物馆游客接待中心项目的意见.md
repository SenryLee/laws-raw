# 国家文物局办公室关于在吉林省省级文物保护单位王百川居宅旧址保护范围内建设吉林市满族博物馆游客接待中心项目的意见

办保函〔2018〕787号

吉林省文物局：

你局《关于吉林省满族博物馆修建游客接待中心项目涉及省级文物保护单位王百川居宅旧址保护范围和建设控制地带的请示》（吉文物发〔2018〕116号）收悉。经研究，我局意见如下：

一、暂不同意所报方案。

二、对该方案提出以下修改意见：

（一）建议在拆除现办公用房的基础上，在旧址保护范围或建设控制地带内选取适当位置，新建小规模临时性建筑，以暂时满足游客接待等服务需求。

（二）新建临时性建筑应尽量简洁、大方，满足基本功能需求即可，不必规模过大。同时，新建临时性建筑的外观设计应注意与旧居及其周边环境相协调，并确保其可识别性。

三、请你局指导相关单位，根据上述意见认真修改、调整方案，按程序另行报批。

四、请你局指导当地人民政府切实加强王百川居宅旧址的保护管理，在旧址保护范围外协调安排必要的建设用地，以满足吉林省满族博物馆新建永久性游客接待中心的需求，最大化发挥旧址的社会效益。

国家文物局办公室

2018年7月30日
