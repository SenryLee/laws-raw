# 文化和旅游部艺术司关于举办2018年全国梆子声腔优秀剧目展演有关事项的通知

艺戏函〔2018〕51号

北京市、天津市、河北省、山西省、内蒙古自治区、江苏省、安徽省、山东省、河南省、陕西省、甘肃省、宁夏回族自治区、新疆维吾尔自治区文化厅（局），新疆生产建设兵团文化广播电视局：

为传承弘扬中华优秀传统文化，传播交流梆子声腔艺术，推动地方戏曲传承发展，中宣部文艺局、文化和旅游部艺术司将于2018年9月至10月在河北省石家庄市举办2018年全国梆子声腔优秀剧目展演。现将有关事项通知如下：

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大和十九届二中、三中全会精神，贯彻落实中共中央办公厅、国务院办公厅《关于实施中华优秀传统文化传承发展工程的意见》精神，坚持“二为”方向、“双百”方针，坚持创造性转化、创新性发展，坚定文化自信，坚守中华文化立场，坚持以人民为中心的创作导向，传承和弘扬中华优秀传统文化，弘扬社会主义核心价值观，推动戏曲艺术繁荣发展。

二、剧种范围

秦腔、晋剧、豫剧、河北梆子、同州梆子、汉调桄桄、蒲剧、上党梆子、北路梆子、老调、武安平调、永年西调、宛梆、怀梆、大平调、山东梆子、莱芜梆子、枣梆、徐州梆子、淮北梆子等20个以梆子腔为主的地方戏曲剧种。

三、剧目推荐及遴选

剧目推荐采取以梆子声腔主要代表性分布区域定额推荐，主办单位集中遴选的办法，由相关省（区、市）文化厅（局）、新疆生产建设兵团文化广播电视局分别推荐本地区具有代表性的剧目。其中，秦腔由陕西省推荐不超过5台，甘肃省、宁夏回族自治区各推荐不超过3台；晋剧由山西省推荐不超过5台；豫剧由河南省推荐不超过5台；河北梆子由河北省、北京市、天津市各推荐不超过3台；同州梆子、汉调桄桄由陕西省各推荐不超过3台；蒲剧、上党梆子、北路梆子由山西省各推荐不超过3台；老调、武安平调、永年西调由河北省各推荐不超过3台；宛梆、怀梆由河南省各推荐不超过3台；大平调由河南省、山东省各推荐不超过3台；山东梆子、莱芜梆子、枣梆由山东省各推荐不超过3台；徐州梆子由江苏省推荐不超过3台；淮北梆子由安徽省推荐不超过3台。此外，新疆维吾尔自治区、新疆生产建设兵团可在秦腔与豫剧两剧种中择优推荐不超过3台；内蒙古自治区可在晋剧与北路梆子两剧种中择优推荐不超过3台。

四、剧目推荐要求

坚持思想精深、艺术精湛、制作精良，注重推荐反映改革开放40周年发展成就、体现改革创新时代精神的剧目，坚持名团名家名剧标准，精选梆子声腔剧种中具有代表性的优秀现代戏、新编历史剧和整理改编传统戏。

五、申报材料

推荐的剧目要求报送剧本5份、演出视频1份（拷录在U盘里）并填写推荐表，由剧目演出单位所在省（区、市）文化厅（局）出具书面推荐意见并加盖公章。

推荐截止日期为2018年7月20日，以寄出邮戳为准。逾期不报视为自动放弃。

六、工作安排

（一）主办方将组织专家集中遴选30台左右参演剧目（含不少于2台改革开放40周年题材优秀剧目）在石家庄展演，每台剧目演出2场。

（二）主办方为每个演出单位提供演出场地、舞台基础设备、70人的食宿及路途费用，并给予一定数额的运输及演出补贴。演员、行头、化妆、装卸台人员及对舞台设备有特殊要求的，由演出剧团自行解决，或由主办方协调设备，费用需院团自理。
