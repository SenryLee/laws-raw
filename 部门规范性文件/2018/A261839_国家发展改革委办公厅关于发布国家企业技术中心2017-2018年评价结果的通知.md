# 国家发展改革委办公厅关于发布国家企业技术中心2017-2018年评价结果的通知

发改办高技〔2018〕237号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团发展改革委，有关省经信委（工信委），海南省科技厅：

根据《国家企业技术中心认定管理办法》（第34号令，以下简称《管理办法》），我们委托第三方机构对国家企业技术中心进行了评价，现将2017-2018年评价结果通知如下：

海尔集团公司等54家企业技术中心得分在90分及以上，评为优秀；太原重型机械集团有限公司等1176家企业技术中心评价得分在65分至90分（不含90分）之间，评为良好；安徽海螺集团有限责任公司等94家企业技术中心评价得分在60分至65分（不含65分）之间，评为基本合格；山西华顿实业有限公司等7家企业技术中心评价得分在60分以下，评为不合格。请你们将评价结果转告相关企业。

根据《管理办法》，请你们负责指导和督促安徽海螺集团有限责任公司等94家企业技术中心改进工作，加快企业技术中心建设步伐。江西钨业集团有限公司与江西稀有金属钨业控股集团有限公司合并为江西钨业控股集团有限公司，原有两家国家企业技术中心将相应合并成新的江西钨业控股集团有限公司国家企业技术中心；中国长城计算机集团公司等13家企业技术中心及分中心因自身原因未报送评价材料，其国家企业技术中心及分中心资格将自动撤销；对于评价不合格的企业技术中心，将撤销其国家企业技术中心及分中心资格。合并、撤销的名单将由我委、科技部、财政部、海关总署、税务总局联合发文另行通知。

本评价仅针对国家企业技术中心2016年年度工作，不涉及企业其他方面的工作。

同时，为引导企业加大研究开发投入、增强自主创新能力，我们将国家企业技术中心所在企业2016年研究与试验发展经费支出额前50名、发明专利拥有量前50名也一并予以公布。

附件：1.国家企业技术中心2017-2018年评价结果（针对2016年年度工作）

2.研究与试验发展经费支出额前50名企业

3.发明专利拥有量前50名企业

国家发展改革委办公厅

2018年2月22日
