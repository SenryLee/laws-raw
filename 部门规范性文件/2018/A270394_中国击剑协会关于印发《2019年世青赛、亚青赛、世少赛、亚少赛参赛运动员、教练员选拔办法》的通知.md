# 中国击剑协会关于印发《2019年世青赛、亚青赛、世少赛、亚少赛参赛运动员、教练员选拔办法》的通知

各有关单位：

为进一步做好击剑项目竞技体育后备人才培养工作，确保2019年世青赛等重要国际赛事参赛人员选拔工作公平、公正、公开进行，根据中国击剑协会《国际青少年击剑比赛运动员、教练员选拔办法》，经协会教练员委员会会议审议通过，现将《2019年世青赛、亚青赛、世少赛、亚少赛参赛运动员、教练员选拔办法》印发实施，请遵照执行。

特此通知。

附件：选拔办法

中国击剑协会

2018年10月31日
