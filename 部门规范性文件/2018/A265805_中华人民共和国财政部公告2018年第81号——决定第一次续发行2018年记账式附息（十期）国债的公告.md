# 中华人民共和国财政部公告2018年第81号——决定第一次续发行2018年记账式附息（十期）国债的公告

## 中华人民共和国财政部公告

2018年第81号

根据国家国债发行的有关规定，财政部决定第一次续发行2018年记账式附息（十期）国债，已完成招标工作。现将有关事项公告如下：

一、本次国债计划续发行450亿元，实际续发行面值金额 450.5亿元。

二、本次续发行国债的起息时间、票面利率等要素均与2018年记账式附息（十期）国债相同，即起息日为2018年5月17日，票面年利率为3.02%；到期一次还本付息，2019年5月17日（节假日顺延）偿还本金并支付利息。经招标确定的续发行价格为100.101元，折合年收益率为3.23%。本次续发行的国债从招标结束后至2018年6月21日进行分销，从6月25日起与之前发行的同期国债410亿元合并上市交易。

其他事宜按《中华人民共和国财政部公告》（2018年第2号）规定执行。

特此公告。

中华人民共和国财政部

2018年6月20日
