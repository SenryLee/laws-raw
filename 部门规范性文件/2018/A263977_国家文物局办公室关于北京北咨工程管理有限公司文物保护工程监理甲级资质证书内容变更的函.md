# 国家文物局办公室关于北京北咨工程管理有限公司文物保护工程监理甲级资质证书内容变更的函

办保函〔2018〕370号

北京市文物局：

你局《关于北京北咨工程管理有限公司文物保护工程监理甲级资质证书增资和变更法定代表人的请示》（京文物〔2018〕299号）收悉。

经研究，我局同意北京北咨工程管理有限公司文物保护工程监理甲级资质证书中的法定代表人由“王革平”变更为“温晓莹”，注册资金由“1000万元”变更为“2130万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2018年4月24日
