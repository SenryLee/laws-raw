# 自然资源部公告2018年第29号——自然资源部关于2018年第八批注册测绘师注册审批结果的公告

## 自然资源部公告

2018年第29号

## 自然资源部关于2018年第八批注册测绘师注册审批结果的公告

根据《注册测绘师制度暂行规定》和《注册测绘师执业管理办法（试行）》，经审核，宋帆等337人符合初始注册条件，准予初始注册；王朔等596人符合延续注册条件，准予延续注册；田庆等21人符合变更注册条件，准予变更注册；沈其炜等7人符合注销注册条件，准予注销注册。

特此公告

自然资源部

2018年7月26日

附件 :

1. 准予初始注册人员名单

2. 准予延续注册人员名单

3. 准予变更注册人员名单

4. 准予注销注册人员名单
