# 自然资源部办公厅关于加快推进群众办事堵点疏解相关工作的通知

自然资办函〔2018〕1800号

各省、自治区、直辖市自然资源主管部门，新疆生产建设兵团自然资源主管部门：

为落实国家发展改革委《关于全力以赴确保完成百项堵点疏解工作的通知》要求，督促指导各地加快解决涉及自然资源主管部门的11个堵点问题，确保2018年底前全面完成，现将有关事项通知如下。

一、高度重视，加快推进堵点疏解工作

百项堵点疏解工作直接关系到群众的切身利益，是贯彻落实国务院加快推进政务服务“一网通办”和企业群众办事“只进一扇门”“最多跑一次”、深化“放管服”改革的具体工作要求。各省级自然资源主管部门要高度重视，在省级人民政府和牵头部门的统一部署下，全力以赴推进解决涉及自然资源主管部门的堵点问题。各地要深入贯彻落实全国深化“放管服”改革转变政府职能电视电话会议精神，采取信息集成、流程集成、人员集成等方式，推动全面优化不动产登记流程、压缩办理时间，减证便民、提质增效，切实提升便民利民服务水平。要结合不动产登记窗口作风问题专项整治工作的要求，全面落实《中共自然资源部党组关于开展不动产登记窗口作风问题专项整治工作的通知》（自然资党发〔2018〕7号）、《自然资源部关于全面推进不动产登记便民利民工作的通知》（自然资发〔2018〕60号）、《国家税务总局 自然资源部关于深化部门合作减轻群众负担提高便民利民服务水平的通知》（税总发〔2018〕47号）等文件规定，改进工作作风、提高业务效能。各地要紧扣堵点问题，对尚未得到有效解决的，逐项分析原因，采取有针对性的举措，倒排时间，确保年底前全面完成任务；对统计为已解决的，深入基层一线核实落实情况，确保打通“最后一公里”。

二、集中攻坚，切实提高堵点疏解的数量和质量

部针对涉及自然资源主管部门的11个堵点问题逐项细化明确了解决标准，提出了解决路径并提供了参考案例。各地要对照《群众办事百项堵点涉及自然资源主管部门情况表》（附件1），结合本地实际集中攻坚。一是精减申请材料。办理不动产登记时，不得要求申请人提供身份证、营业执照、户口簿复印件，除户口簿作为身份证明材料的以外，不得要求提交户口簿原件；办理建设工程规划许可证时，之前在同一个部门办理其他手续已提交营业执照复印件等资料的，通过系统推送，不再作为申报要件。二是加强信息共享。各级自然资源主管部门通过政府共享数据交换平台、部门间专线连接等方式，加强与市场监管、公安、税务等部门信息共享，在办理不动产登记时，能够通过部门信息共享获取的企业营业执照、个人身份和户籍、纳税等信息不再要求申请人提供；同时，各级自然资源主管部门要夯实数据基础，严格规范不动产登簿行为，提高不动产登记信息质量和完整性，相关部门需要核验不动产权证书信息的，不动产登记机构要积极提供登记簿信息共享服务，为企业和群众办理不动产登记、规划许可、税收、企业注册等业务提供便利。三是严格依法行政。办理不动产登记时严禁要求申请人提供没有法律法规依据的证明或其他申请材料。自然资源主管部门应当主动与市场监管等部门沟通，办理相关业务是否确需查验不动产登记证书、证明，对于没有法律法规依据、不符合“放管服”改革要求的，要协调取消；确实需要的，通过与不动产登记机构信息共享取得。四是提升便民利民水平。进一步优化不动产登记流程，实行不动产交易、登记、税务“一窗受理、并行办理”，收取一套材料，减轻群众负担，让群众“最多跑一次”。加强政务公开，在办公场所、门户网站清晰公开办理不动产登记申请材料目录、示范文本、办理时限等。

三、压实责任，确保按时完成工作任务

各级自然资源主管部门要切实加强领导，压实责任，强化部门衔接，对牵头解决的堵点问题，要主动沟通协调，加大力度，逐项解决；对配合解决的堵点问题，要积极提供数据支撑。重点围绕工作进展滞后、统筹协调不足、堵点解决不实等问题，进一步深入研究排查，确保严格按时限要求解决问题。省级自然资源主管部门要及时上报堵点疏解工作进展情况表（附件2），同时，结合地方机构改革情况，督促市、县自然资源主管部门做好堵点疏解工作，切实解决群众办理不动产登记、规划许可等业务中的堵点问题。部将收集典型案例经验，对于堵点疏解措施得当、效果明显的地方，全面总结推广，对于疏解不力的地方予以通报。

请各省级自然资源主管部门于12月31日前，将堵点疏解工作进展情况报部。
