# 自然资源部办公厅关于表彰原国土资源部、原国家海洋局2017年度考核先进单位、绩效管理先进单位和考核优秀人员的通知

自然资办发〔2018〕19号

各司局、各单位：

2017年，各司局、各单位领导班子和干部职工主动作为，履职担当，涌现出了一批成绩突出的先进单位和优秀个人。为表彰先进、树立典型，激励各单位和广大干部职工更加深入学习贯彻习近平新时代中国特色社会主义思想，更加积极主动贯彻落实党的十九大精神，进一步推进党中央、国务院和部党组重大决策部署的贯彻落实，根据原国土资源部、原国家海洋局2017年度领导班子和干部考核及绩效评估结果，结合领导班子综合研判、巡视和平时了解掌握的情况，经部党组审议，并报国家公务员局备案同意公务员奖励事项，确定原国土资源部法规司等16个单位为2017年度考核先进单位，规划司等14个单位为2017年度绩效管理先进单位；原国土资源部陈国庆、原国家海洋局古妩等25名2015至2017年度连续3年考核优秀的同志记三等功；原国土资源部夏俊、原国家海洋局高忠文等164名2017年度考核优秀的同志给予嘉奖；经研院贺明玉、大洋办李波等33名直属单位领导干部为2017年度考核优秀人员（原国家测绘地理信息局2017年度考核表彰详见《关于给予白振栋等21人奖励的决定》〈测办发﹝2018﹞8号〉）。直属单位被确定为考核优秀的人员，请各单位参照《公务员奖励规定（试行）》给予相应奖励。

希望受到表彰的先进单位和优秀个人珍惜荣誉，再接再厉，继续发挥模范表率作用，在自然资源管理工作中作出新的更大的贡献。

2018年8月14日
