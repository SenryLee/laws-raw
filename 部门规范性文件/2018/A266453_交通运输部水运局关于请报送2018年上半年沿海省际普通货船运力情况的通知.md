# 交通运输部水运局关于请报送2018年上半年沿海省际普通货船运力情况的通知

水运国内函〔2018〕113号

北京、天津、河北、辽宁、吉林、黑龙江、上海、江苏、浙江、安徽、福建、江西、山东、湖北、湖南、广东、广西、重庆、海南省（区、市）港航（航务、水运、运输、地方海事）管理局（处）：

为掌握我国沿海省际普通货船运力发展情况，请你单位按附表格式填报本辖区内2018年上半年沿海省际普通货船运力有关情况，并于2018年7月13日下班前将EXCEL电子版报我局。电子信箱：sysgnc@ mot.gov.cn。
