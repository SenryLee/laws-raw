# 人力资源社会保障部关于职业培训教材工作委员会更名及调整委员人选的通知

人社部函〔2018〕126号

各省、自治区、直辖市人力资源社会保障厅（局）、国务院有关部门人事（劳动、教育）司、有关行业协会人力资源社会保障工作机构、有关单位：

我部职业培训教材工作委员会自2000年成立以来，在加强技工教育和职业培训教材建设、推动技工教育和职业培训事业发展、促进就业和培养技能人才等方面发挥了积极作用。为适应教材建设工作发展需要，经研究，我部决定将“人力资源和社会保障部职业培训教材工作委员会”名称变更为“人力资源和社会保障部技工教育和职业培训教材工作委员会”，贯彻党和国家关于教材工作的重大方针政策，指导推动全国技工教育和职业培训教材工作。同时，对委员人选进行调整，在有关单位推荐人选的基础上，确定了技工教育和职业培训教材工作委员会委员名单（见附件），现予以公布。地方委员实行席位制，由有关省、自治区、直辖市人力资源社会保障厅（局）分管职业能力建设工作的厅（局）长担任所在地方委员；当分管人员发生变动时，由接任人员递补担任地方委员。

希望各地、各有关单位创造有利的工作条件，积极支持委员的工作；希望各委员充分发挥作用，履职尽责，努力工作，为推进技工教育和职业培训教材建设工作做出贡献。

人力资源社会保障部

2018年9月28日

附件：人力资源和社会保障部技工教育和职业培训教材工作委员会名单
