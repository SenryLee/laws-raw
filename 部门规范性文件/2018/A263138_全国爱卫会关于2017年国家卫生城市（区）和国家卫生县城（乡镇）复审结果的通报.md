# 全国爱卫会关于2017年国家卫生城市（区）和国家卫生县城（乡镇）复审结果的通报

全爱卫发〔2018〕2号

各省、自治区、直辖市和新疆生产建设兵团爱卫会：

根据《国家卫生城市评审与管理办法》和《全国爱卫会关于做好下放国家卫生乡镇（县城）评审工作的指导意见（试行）》的有关规定，全国爱卫办组织专家对2017年进入复审程序的国家卫生城市（区）进行了评审，对各地上报的国家卫生县城（乡镇）复审结果进行了抽查。

复审和抽查结果表明，大多数城市（区）、县城（乡镇）高度重视爱国卫生工作，在获得国家卫生城镇荣誉称号后，继续推进卫生创建工作全面深入开展，健全城市卫生长效管理机制，努力解决影响群众健康的突出问题，不断加强城镇社会卫生综合治理，巩固和发展了国家卫生城镇创建成果，发挥了典型示范作用。但个别城镇在获取荣誉称号后，对巩固提高工作重视程度不够，工作滑坡明显，特别是在旧城区、背街小巷、城中村、城乡结合部和“五小”行业等方面的基础设施建设薄弱，日常卫生管理不到位，群众反映比较强烈，整体卫生水平与国家卫生城镇标准存在一定的差距。根据暗访和评审结果，现通报如下：

一、重新确认北京市顺义区等100个城市（区）为国家卫生城市（区），重新确认北京市延庆区八达岭镇等114个县城（乡镇）为国家卫生县城（乡镇）。名单附后。

二、暂缓确认河南省平顶山市、贵州省凯里市为国家卫生城市；暂缓确认湖南省怀化市沅陵县、河南省信阳市吴陈河镇、新疆维吾尔自治区呼图壁县为国家卫生县城（乡镇）。希望有关城镇严格按照《国家卫生城市标准》和《国家卫生乡镇（县城）标准》进行认真整改，上述市县将于2018年重新复审。

三、上海市青浦区、宝山区、嘉定区、徐汇区，江苏省宿迁市、福建省泉州市、山东省诸城市、湖南省株洲市、重庆市大渡口区等9个城市（区），在巩固国家卫生城市工作方面成效显著，在复审中成绩突出，予以通报表扬。

四、天津市和平区、山西省原平市、山西省长治市、黑龙江省黑河市、浙江省温州市、湖南省永州市、四川省西昌市、云南省曲靖市、广西壮族自治区百色市等9个城市（区）, 在巩固国家卫生城镇工作方面滑坡明显，湖南省益阳市2017年发生聚集性疫情，予以通报批评。
