# 国家核安全局关于同意中国第一重型机械股份公司等7家单位民用核安全设备许可证和三菱电机株式会社等2家境外单位注册登记确认书信息变更的通知

## 关于同意中国第一重型机械股份公司等7家单位民用核安全设备许可证和三菱电机株式会社等2家境外单位注册登记确认书信息变更的通知

国核安函〔2018〕52号

中国第一重型机械股份公司、东方电气（武汉）核设备有限公司、武汉重工铸锻有限责任公司、中广核研究院有限公司、中国电建集团核电工程有限公司、中国核工业二三建设有限公司、中国核工业第五建设有限公司、三菱电机株式会社、Curtiss-Wright Flow Control Corporation:

根据《民用核安全设备监督管理条例》及其配套规章的有关规定，我局对相关单位民用核安全设备许可证及境外单位注册登记确认书信息变更的申请进行了审查。经研究，同意中国第一重型机械股份公司、东方电气（武汉）核设备有限公司、武汉重工铸锻有限责任公司、中广核研究院有限公司、中国电建集团核电工程公司、中国核工业二三建设有限公司、中国核工业第五建设有限公司等7家单位民用核安全设备许可证信息变更（见附件1）和三菱电机株式会社、Curtiss-Wright Flow Control Corporation等2家境外单位注册登记确认书信息变更（见附件2）。

附件：1.民用核安全设备许可证变更信息

2.境外单位注册登记确认书变更信息

国家核安全局

2018年6月28日
