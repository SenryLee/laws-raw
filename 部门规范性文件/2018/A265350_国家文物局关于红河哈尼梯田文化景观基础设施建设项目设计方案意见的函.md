# 国家文物局关于红河哈尼梯田文化景观基础设施建设项目设计方案意见的函

文物保函〔2018〕598号

云南省文物局：

你局《关于对红河哈尼梯田世界文化遗产区基础设施建设方案进行审查的请示》（云文物〔2018〕37号）收悉。经研究，我局意见如下：

一、原则同意所报世界文化遗产红河哈尼梯田文化景观基础设施建设项目。

二、对该项目设计方案提出以下具体意见：

（一）应进一步论证建设四处管理用房的必要性，管理用房建设应符合保护规划相关要求，原则上不得扩大规模。合理调整管理用房高度，其高度以不超过村落文物建筑高度为宜。

（二）遗产区内绿化不得采取园林化、景观化的绿化方式，避免对遗产原有生态环境和景观风貌造成过度干预。

（三）补充说明不同类型拟建道路和灌渠的适用范围并做进一步评估，根据评估结论对道路和灌渠的选型、铺设范围作进一步优化。水泥槽灌渠、塑木栈道及平台对景观环境影响较大，如非必要不得选用，以免对遗产价值及环境风貌造成不利影响。

（四）进一步规范和完善方案文本和图纸。补充塑木道路大比例尺设计图以便进行文物影响评估。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，按照《中华人民共和国文物保护法》第十七条、第十八条的规定，报云南省人民政府和城乡建设规划部门批准实施。

四、请你局加强施工过程的监管，确保文物及周边环境安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2018年6月11日
