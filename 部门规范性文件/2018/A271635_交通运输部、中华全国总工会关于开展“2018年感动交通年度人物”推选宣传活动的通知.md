# 交通运输部、中华全国总工会关于开展“2018年感动交通年度人物”推选宣传活动的通知

## 交通运输部　中华全国总工会关于开展“2018年感动交通年度人物”推选宣传活动的通知

交政研函〔2018〕817号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），有关省市交通（海员）工会，有关中央交通运输企业、工会，部管各社团，部属各单位：

为深入学习宣传贯彻习近平新时代中国特色社会主义思想和党的十九大精神，在全国交通运输行业大力培育践行社会主义核心价值观，展现新时代建设交通强国新气象新风貌，交通运输部、中华全国总工会决定联合开展“2018年感动交通年度人物”推选宣传活动（以下简称推选宣传活动）。现将有关事项通知如下：

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大精神，大力弘扬“两路”精神和新时代交通精神，深入挖掘、广泛宣传交通运输行业先进人物和感人事迹，讲好交通故事，传播交通好声音，积极营造共同建设交通强国的良好舆论氛围，激励广大干部职工新时代新担当新作为，为决胜全面建成小康社会，建设社会主义现代化强国，实现中华民族伟大复兴提供坚强的交通运输保障。

二、组织领导

推选宣传活动由交通运输部和中华全国总工会联合主办。中国交通报社、中国海员建设工会和新华社新华网、新媒体中心共同承办。交通运输部政策研究室负责统筹活动的组织开展，承办单位负责做好相关具体工作。

三、推选标准和范围

（一）推选标准。

参选人物的先进事迹原则上应发生在2018年，或在2018年得到社会舆论广泛好评，在行业内外产生了良好影响，在培育践行社会主义核心价值观中发挥了表率作用，具备如下特点：

一是典型性。体现忠诚担当、忠于职守的政治品格和职业操守，具有强烈责任意识、严谨工作作风、精湛专业技能，是交通运输行业广大干部职工的优秀代表。

二是时代性。继承发扬“两路”精神和新时代交通精神，继承发扬逢山开路、遇水架桥的奋斗精神，为建设交通强国作出突出贡献，体现了勇创一流的精神志气。

三是引领性。积极践行社会主义核心价值观，对人民群众高度负责，自觉深入地把非凡英雄精神体现在平凡工作岗位上，做出了不平凡的业绩，为建设人民满意交通作出了表率。

四是感动性。事迹特别感人，能够充分体现中华优秀传统文化、红色革命文化和社会主义先进文化内涵，具有强大的道德感染力和精神感召力，感动、带动了广大干部群众，展现了新时代交通人良好的精神面貌。

（二）推选范围。

推选活动面向全国交通运输行业基层干部职工或从业人员，个人或团队均可以参加。

（三）推选方式。

推选活动采用“自下而上、上下结合”的方式。各地交通运输部门推荐的候选人物材料汇总至省（区、市）交通运输厅（局、委），报送至活动组委会办公室。部管国家局、部直属单位、交通行业学会协会、中央交通运输企业等推荐的候选人物材料可直接报送至活动组委会办公室。

活动组委会办公室根据交通运输行业群众性精神文明创建活动的开展情况，以及“爱岗敬业 明礼诚信”社会主义核心价值观主题实践情况，对先进典型事迹进行重点发掘、培树和宣传。社会公众也可直接向活动组委会办公室推荐先进人物。

四、活动时间

推选宣传活动从2018年12月开始，至2019年4月结束，分四个阶段。

（一）推荐候选人物。

2018年12月1日至2019年2月1日，各单位根据通知要求宣传发动，广泛遴选，按照有关标准确定候选人，填写“2018年感动交通年度人物推荐表”（见附件），报送至活动组委会办公室。推荐单位要提供纸质材料原件并加盖单位公章，邮寄至活动组委会办公室。相关文字、图片电子版发送至指定邮箱。

材料具体要求如下：

1.图片：图片采用jpg或tif格式，分辨率不低于800万像素（3264×2448），以横图为主（其中一张图片比例为4:3），须提供推荐人物正脸照一张，图片均需提供文字说明。

2.文字：文字材料篇幅在1500字左右，并有描述性题目。

3.视频：视频比例为16：9，时长10至15分钟，视频格式需采用标准视频格式（MPEG/AVI/MP4/MOV），分辨率为全高清（1920×1080）。

（二）确定年度人物候选人。

2019年3月1日至3月10日，组织行业内外专家从推荐人选中，推选出“2018年感动交通年度人物”候选人。

（三）推选十大年度人物候选人。

2019年3月10日至3月31日，通过新华网、新华社微信公众号、新华社客户端、新华社微悦读小程序、交通运输部政府网站及政务新媒体平台、《工人日报》、中工网、《中国交通报》及其新媒体平台、中国交通新闻网等中央和行业媒体，集中宣传“2018年感动交通年度人物”候选人事迹，组织网络投票，并经专家评议，推选出“2018年感动交通十大年度人物”候选人。

（四）发布和学习宣传年度人物。

2019年4月，审定“2018年感动交通十大年度人物”“2018年感动交通年度人物”“2018年感动交通年度人物推选宣传活动最佳组织贡献单位”等名单，印发文件，组织报告活动，在全行业广泛学习宣传感动交通年度人物先进事迹。

五、工作要求

（一）高度重视，精心组织。要充分认识推选宣传活动对提升行业软实力、树立交通好形象、推动交通强国建设的重要作用，加强组织领导，主要领导要亲自部署安排，明确专门负责同志，健全工作机制，提供工作保障。

（二）创新手段，广泛发动。要充分发掘宣传身边典型，用身边人、身边事教育职工、带动行业、引导群众，汇聚强大正能量。充分运用传统媒体、新兴媒体以及组织宣传手段做好动员，把推选宣传活动作为宣传展示交通运输良好形象的重要契机，积极关注交通运输部、中华全国总工会相关政务新媒体及新华社、新华网微信、小程序，下载客户端，提升推选宣传活动的传播力、引导力、影响力、公信力。

（三）依法合规，加强统筹。要坚持公开、公正、客观、真实的原则，严格遵守推选的标准和流程，确保推选宣传活动权威。同时，要把推选宣传活动同各单位各部门深入开展的“最美”系列宣传有机结合起来，集中力量，层层推优，让交通运输先进人物传开叫响、深入人心。
