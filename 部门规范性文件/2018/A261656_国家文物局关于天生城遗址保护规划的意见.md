# 国家文物局关于天生城遗址保护规划的意见

文物保函〔2018〕173号

重庆市文物局：

你局《关于天生城遗址保护规划的请示》(渝文物〔2018〕20号)收悉。经研究，我局意见如下：

一、原则同意天生城遗址保护规划。

二、应深化考古研究，明确遗址历史格局、遗产构成、遗存分布和功能体系，按遗存类型重新进行现状评估，并制定保护措施；建议强化一类建设控制地带的控制力度，明确划为禁建区或调整为一般保护区；细化展示内容，根据考古工作成果确定游线和路网布局；加强规划衔接，补充制定遗址西侧城市规划衔接要求，控制周边视线通廊关系。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的天生城遗址保护规划报请重庆市人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好天生城遗址的各项保护、管理工作，妥善解决土地用途调整、环境整治等涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2018年2月26日
