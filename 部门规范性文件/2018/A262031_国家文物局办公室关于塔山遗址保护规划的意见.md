# 国家文物局办公室关于塔山遗址保护规划的意见

办保函〔2018〕193号

浙江省文物局：

你局《关于上报全国重点文物保护单位象山塔山遗址保护规划的请示》（浙文物发〔2018〕31号）收悉。经研究，我局意见如下：

一、暂不同意塔山遗址保护规划。

二、对该规划提出以下修改意见：

（一）进一步加强考古研究，系统梳理已有考古工作成果，明确遗址分布范围和保存现状，为编制保护规划提供依据。

（二）应根据文物分布范围、保护管理需要综合确定保护区划，论证保护范围与一类建设控制地带合并的可行性；合理制订管理规定，保护范围内不得进行与文物保护无关的建设活动，一类建设控制地带不宜设为禁建区。

（三）调整保护措施，论证、明确覆罩保护、回填保护的具体对象、范围和措施要求；完善考古工作规划，慎重考虑考古发掘的必要性和学术目标；环境规划中水污染、大气污染、噪声防治等措施针对性不强，建议删除。

（四）应针对遗址特点科学确定展示目标和方式，明确各展示节点的展示主题和内容，注意展现遗址整体景观风貌，弱化遗址广场等城市园林化设计。

（五）进一步规范图文表达，保护规划图的控制要求应与文字表述相符；图纸应准确标注保护对象；补充考古遗迹分布图。

三、请你局指导规划编制单位联合专业考古研究单位，根据上述意见进一步修改和完善塔山遗址保护规划后，按程序另行报批。

国家文物局办公室

2018年3月7日
