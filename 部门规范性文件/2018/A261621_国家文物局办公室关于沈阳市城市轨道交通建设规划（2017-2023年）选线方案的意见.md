# 国家文物局办公室关于沈阳市城市轨道交通建设规划（2017-2023年）选线方案的意见

办保函〔2018〕118号

辽宁省文物局：

你局《关于沈阳市城市轨道交通建设规划（2017-2023年）的请示》（辽文物〔2017〕65号）收悉。经研究，我局意见如下：

一、暂不同意所报轨道交通建设规划选线方案。

二、对所报方案提出以下修改意见：

（一）进一步明确拟选轨道交通线路与福陵等全国重点文物保护单位保护范围及建设控制地带的位置关系。轨道选线应尽量避让文物保护单位，减少对文物本体的影响。

（二）补充轨道交通建设对文物影响的专项评估，重点评估轨道线路在施工及运营期间可能产生的振动、地面沉降等对文物造成的影响；经评估存在安全隐患的区段，应制定相应的防护加固预案。

（三）建设控制地带内的地铁站点项目应符合建设控制地带的相关建设规定，其外观应与文物原有周边环境风貌相协调。

（四）拟选线路涉及省、市县级文物保护单位保护范围和建设控制地带的，应按《文物保护法》相关规定依法报批。

三、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此。

国家文物局办公室

2018年2月8日
