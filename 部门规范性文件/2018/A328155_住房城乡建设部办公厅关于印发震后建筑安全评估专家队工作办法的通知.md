# 住房城乡建设部办公厅关于印发震后建筑安全评估专家队工作办法的通知

建办质〔2018〕33号

各省、自治区住房城乡建设厅，直辖市建委（规划国土委）：

为进一步落实《住房城乡建设系统地震应急预案》（建质〔2013〕136号），规范震后建筑安全评估工作，提高住房城乡建设系统震后应急处置工作针对性，我部制定了《震后建筑安全评估专家队工作办法》。现印发给你们，请遵照执行。

住房和城乡建设部办公厅

2018年6月21日
