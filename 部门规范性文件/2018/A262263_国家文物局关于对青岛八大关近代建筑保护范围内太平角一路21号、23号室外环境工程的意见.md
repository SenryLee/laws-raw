# 国家文物局关于对青岛八大关近代建筑保护范围内太平角一路21号、23号室外环境工程的意见

文物保函〔2018〕230号

山东省文物局：

你局《关于呈报青岛八大关近代建筑——太平角一路21号、23号室外环境工程景观设计方案的请示》（鲁文发〔2018〕1号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、对所报项目提出以下修改完善意见：

（一）补充说明建筑始建年代和院落主要特征，工程地面铺装、绿化布置应与文物建筑历史风格相近。

（二）适当缩小院落硬铺装规模，建议将草坪绿化与地面铺装相结合。同时，应尽量降低围墙高度，以保持八大关近代建筑群开放通透的传统院落景观效果。

（三）新增设施安装应遵循可逆原则，便于拆除；尽量减少雕塑等小品设计。

三、请你局指导有关单位，按照上述意见对所报方案进行修改完善，并根据《中华人民共和国文物保护法》第十七条的有关规定，报山东省人民政府批准后实施。

国家文物局

2018年3月12日
