# 交通运输部办公厅关于印发公路水路行业2018年年度和2019年定期统计调查制度的通知

各省、自治区、直辖市、新疆生产建设兵团、计划单列市交通运输厅（局、委），长江航务管理局、珠江航务管理局，有关单位：

交通运输部对公路水路行业2018年年度和2019年定期统计调查项目履行了审批或备案手续，经国家统计局审批的统计调查项目19项，批准文号为“国统制〔2018〕136号”，有效期至2021年11月；经国家统计局备案的统计调查项目2项，备案文号为“国统办函〔2018〕471号”，有效期至2023年10月。另有8项统计调查项目在有效期内继续执行（详见附件）。所有统计调查项目的制度文本可在交通运输部政府网站下载。请有关业务主管司局做好相关统计调查项目的布置与培训工作。

各单位要高度重视，精心组织，坚持依法统计、依法治统，严把数据质量关，坚决杜绝统计造假、弄虚作假，确保2018年年度和2019年定期统计调查项目顺利实施。

附件：公路水路行业统计调查项目表

交通运输部办公厅
