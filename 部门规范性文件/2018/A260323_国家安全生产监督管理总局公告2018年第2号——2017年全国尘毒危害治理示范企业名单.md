# 国家安全生产监督管理总局公告2018年第2号——2017年全国尘毒危害治理示范企业名单

## 国家安全生产监督管理总局公告

2018年第2号

为推动重点行业领域尘毒危害治理工作，提高企业尘毒危害治理水平，更好维护职工职业安全健康权益，2016年8月以来，国家安全监管总局在全国组织开展了尘毒危害治理示范企业创建工作。在各地区推荐并经专家审核基础上，确定北京中丽制机工程技术有限公司等11家企业为全国尘毒危害治理示范企业，现予公告。

国家安全监管总局将通过有关媒体对示范企业治理经验进行宣传。

附件：2017年全国尘毒危害治理示范企业名单

国家安全监管总局

2018年1月15日
