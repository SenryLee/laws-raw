# 国家信访局2017年信访宣传工作要点

国信办发〔2017〕2号

2017年是党和国家历史上具有特殊重要意义的一年，信访宣传工作要深入贯彻党的十八大和十八届三中、四中、五中、六中全会精神，全面落实以习近平同志为核心的党中央关于信访工作的决策部署，按照全国宣传部长会议和全国信访局长会议有关要求，以迎接宣传贯彻党的十九大为主线，以宣传信访工作制度改革和信访法治化建设为重点，讲好信访故事，壮大信访主流声音，为深入推进信访工作创新发展提供有力思想舆论支持。

一、开展“迎接十九大”主题宣传活动。围绕迎接党的十九大和第八次全国信访工作会议召开，组织开展集中宣传活动。通过中央主要新闻媒体和都市媒体、网络媒体，重点宣传党的十八大以来中央关于信访工作的决策部署和中央领导同志的重要指示批示精神；宣传信访工作制度改革所取得的成就以及信访工作在反映社情民意、维护群众合法权益、促进社会和谐过程中所作出的贡献；宣传全国信访系统的重大典型经验和优秀信访干部的先进事迹。深入宣传各地贯彻落实党的十九大精神、推动信访工作创新发展的好经验好做法，不断把学习宣传贯彻党的十九大精神活动引向深入。

二、深化信访工作制度改革成果宣传。结合“责任落实年”，宣传各地贯彻落实《信访工作责任制实施办法》的具体举措和成效。宣传“信访网上投、事项网上办、结果网上评、问题网上督、形势网上判”的工作模式，以及信访信息化工作的新进展、新成效。围绕全年重点工作，宣传信访业务规范化建设、信访问题及时就地解决、信访积案化解、信访督查督办机制完善、信访干部队伍建设等方面的做法成效，全面展示改革带来的新变化、取得的新成果，集聚社会各界支持信访工作和信访工作制度改革的正能量。

三、营造信访法治化浓厚氛围。按照依法治国宣传报道要求，宣传信访部门依法解决群众合理诉求的成功做法及工作成效。重点宣传信访部门在访诉分离、依法分类处理信访诉求、逐级走访、律师参与信访工作等信访法治化建设方面的重要举措和成效。加强政策解读、曝光典型案例，引导广大群众正确认识和行使信访权利，引导信访部门运用法治思维和法治方式深化改革、化解矛盾。宣传信访立法的重要意义和工作进展，营造法治信访良好舆论环境。

四、打造信访宣传品牌。加强宣传策划和议题设置，主动讲好信访故事。开展“最美信访干部”学习宣传活动，激励和引导广大信访干部爱岗敬业、无私奉献，让全社会进一步理解、支持信访工作。创新方式方法，继续推进“领导干部谈信访”网上系列访谈和媒体参与信访事项统筹实地督查工作，组织开展“我在基层做信访”系列报道、新媒体创作大赛、“与改革同行”征文等主题活动。加强工作指导，引导各地打造独具特色的宣传品牌，进一步树立信访部门良好形象。

五、完善新闻发布工作机制。健全新闻发布内部联动机制和媒体沟通机制，加强各级信访部门间信息沟通对接，积极为媒体采访报道提供便利，提高同媒体特别是新兴媒体打交道的能力。健全常态化新闻发布工作机制，定期公开新闻发言人信息，定期组织新闻发布会、通气会、吹风会等发布活动，主动释疑解惑、回应关切、增进共识，掌握舆论引导的话语权、主动权。

六、做优做强信访宣传阵地。适应新形势下做好宣传舆论工作要求，深化“互联网+信访宣传”，做好门户网站及微信、微博、政务头条号等新媒体建设工作，形成权威发布、集群发声、强势传播的信访全媒体矩阵。培育信访系统有影响力的新媒体账号，打造接地气、贴民心、广覆盖的新媒体名片。做好《人民信访》等内刊编辑发行工作，推动内刊和新媒体融合发展，整合资源、形成合力，牢牢把握信访宣传舆论阵地的主导权。

七、压实宣传工作责任。按照属地管理、分级负责和谁主管谁负责的原则，明确工作责任，将宣传工作与重点业务工作同步研究、同步推进、同步落实。加强对信访部门内部刊物、出版物、新媒体平台等宣传阵地管理，规范稿件审核流程，把准政治导向。加强信访系统通讯员、新媒体管理员队伍建设，切实提升政治素质和业务能力。
