# 国家文物局办公室关于山阴县新广武3段长城巡护步道建设项目的意见

办保函〔2018〕1007号

山西省文物局：

你局《关于山阴县新广武3段长城巡护步道方案设计的请示》（晋文物〔2018〕93号）收悉。经研究，我局意见如下：

一、所报方案尚需进行以下必要的修改和完善：

（一）应在整修的基础上充分利用现有步道，不得改变其位置及走向，并严格控制重新铺装的范围及工程量。新增步道设计宽度不得超过1.2米，路面铺装材料应选择本地自然石材并采用生态铺装方式，不得使用砖质或花岗岩材料。

（二）应调整各类附属设施设计。休息平台不得采取女墙与垛口相结合形制，地面铺装应与步道铺装一致。护栏、椅凳等应采用本地自然石材或木材，压缩设计尺度，其外观、色彩等应与长城及周边环境相协调。保护标志应符合相关标准、规范要求，尽量融入文物环境，同时加强内容设计，做到全面、科学、准确。

（三）应拆除现有停车场、厕所，并恢复原有地形地貌。拟建生态停车场、厕所、管理用房等不得在保护范围内选址。停车场建设需严格控制规模，地面应采用生态铺装方式，减少硬化面积。应适当压缩拟建厕所、管理用房的体量，其外观设计应当简洁质朴，鼓励采用移动式、装配式的非永久性设施。

（四）应细化施工方案，明确施工场地布置、线路安排、工作规范、施工工艺等，避免因施工导致长城文物本体及周边生态环境、景观风貌遭到破坏。施工后期应对施工场地及周边因施工受到影响的区域，适当选取本地植被进行局部环境修复，但应避免园林化，且不得进行大规模改造绿化。

（五）应补充各类设施的设计详图及设计效果图，并深化文物影响评估，客观评估拟建项目对长城文物本体安全及周边生态环境、景观风貌的影响，对方案提出优化建议。

二、请你局指导有关单位根据上述意见对方案进行修改完善，并按照《国家文物局关于进一步加快推进“十三五”时期文化旅游提升工程中全国重点文物保护单位保护利用设施建设项目的通知》（文物保函〔2018〕1246号）的要求，对该项目具体建设内容及方案进行核准，根据《中华人民共和国文物保护法》的有关规定，报有关部门履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局办公室

2018年10月18日
