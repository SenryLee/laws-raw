# 交通运输部关于公布2017年度水运工程设计、施工和监理信用评价结果的公告

根据《水运工程设计和施工企业信用评价办法（试行）》（交水发〔2014〕113号）、《公路水运工程监理信用评价办法》（交质监发〔2012〕774号），交通运输部组织开展了2017年水运工程设计、施工和监理信用评价，对各省级交通运输主管部门及部属单位报送的信用评价结果进行了汇总，形成了全国综合信用评价结果，现予公布。

特此公告。

交通运输部

2018年8月20日

附件：

附件1-2017年度全国水运工程设计企业信用评价汇总表

附件2-2017年度全国水运工程施工企业信用评价汇总表

附件3-2017年度全国水运工程监理企业信用评价汇总表

附件4-2017年度全国水运工程监理工程师失信扣分情况汇总表

附件5-2015-2017年度全国水运工程监理工程师失信扣分情况汇总表
