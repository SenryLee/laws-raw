# 国家体育总局冬运中心关于印发2018-2019年度全国自由式滑雪空中技巧U系列赛竞赛规程的通知

## 体育总局冬运中心关于印发2018-2019年度全国自由式滑雪空中技巧U系列赛竞赛规程的通知

各相关单位：

按照《体育总局青少司关于做好2018年U系列赛事体系建设转移支付经费使用工作的通知》和《体育总局青少司关于启动2018年全国青少年U系列赛事专项评估工作的通知》要求，冬运中心将于2019年1月18日-20日在河北省张家口市崇礼区云顶滑雪场举办2018-2019年度全国自由式滑雪空中技巧U系列赛。为顺利开展各项工作，推动赛事取得圆满成功，现将2018-2019年度全国自由式滑雪空中技巧U系列赛竞赛规程印发相关单位，请遵照执行。

附件：空中技巧U系列赛竞赛规程

国家体育总局冬季运动管理中心

2018年12月12日
