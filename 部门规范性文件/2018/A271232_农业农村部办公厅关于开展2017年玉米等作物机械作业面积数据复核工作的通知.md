# 农业农村部办公厅关于开展2017年玉米等作物机械作业面积数据复核工作的通知

农办机〔2018〕27号

各省、自治区、直辖市农机（农业、农业农村、农牧、农村经济）局（厅、委、办），新疆生产建设兵团农业局：

近日，国家统计局发布了《2018中国统计年鉴》，明确“依据第三次全国农业普查结果，对2007—2016年农业数据进行了修订”，并同步衔接发布了2017年农作物播种面积等相关数据。据此，我部组织测算了8大主要作物的机械化率，发现因玉米等播种面积修订变化幅度较大，以致其机械化率相关数据异常。为做好与国家统计局相关数据的衔接，及时发布2017年全国农机化统计年报，我部决定组织复核玉米等作物机械作业面积数据，请按本通知要求抓紧开展以下工作。

一是统一复核本地区玉米机耕、机播、机收面积、免耕播种面积。二是根据本地区实际情况复核其它主要作物机械作业面积，重点针对《2018中国统计年鉴》中2017年主要作物播种面积较《2017中国统计年鉴》中2016年对应数据变化幅度超过10%的作物机械作业面积。有关复核情况填报2017年主要作物机械作业情况复核表（见附件）。省、市、县三级均使用“全国农机化统计系统”报送数据的单位，复核数据在系统中同步调整；未全面使用该系统报送数据的单位，复核数据在本省系统中同步调整，全省数据在“全国农机化统计系统”体现。

请于12月7日前将附件电子版和纸质材料（须加盖公章）报送我部，系统数据同步调整到位。逾期视同无异议。
