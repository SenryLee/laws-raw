# 国家文物局关于李氏家族旧宅文物保护规划的意见

文物保函〔2018〕388号

安徽省文物局：

你局《关于批准李氏家族旧宅文物保护规划的请示》（皖文物保〔2018〕14号）收悉。经研究，我局意见如下：

一、原则同意所报规划。

二、对该规划提出以下修改意见：

（一）进一步深化对李氏家族旧宅的历史研究，明确文物原有格局、范围及演变过程。

（二）在深入研究和评估的基础上梳理文物本体构成，近期复建旧宅不属于文物本体。

（三）完善价值评估，客观评价李氏家族旧宅的历史价值、科学价值和艺术价值，突出旧宅核心价值。

（四）进一步完善现状评估。应对近年开展的保护修缮工程效果进行评估；文物建筑与管理用房应分开评估；补充周边建设活动对文物历史环境的影响评估。

（五）完善建设控制地带管理规定，严格控制建筑高度、体量和建筑形式。

（六）建议结合基础设施规划，对周边道路标高等提出要求，保证文物院落排水通畅。

（七）补充与上位规划及相关规划的衔接章节。

（八）完善图文表达。应在规划图纸中明确规划范围，补充李氏家族旧宅历史沿革分析图，细化文物院落相关图纸。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的李氏家族旧宅文物保护规划报请安徽省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好李氏家族旧宅文物的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2018年4月19日
