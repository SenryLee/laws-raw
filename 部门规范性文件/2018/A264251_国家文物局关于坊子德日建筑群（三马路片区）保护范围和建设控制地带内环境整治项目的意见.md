# 国家文物局关于坊子德日建筑群（三马路片区）保护范围和建设控制地带内环境整治项目的意见

文物保函〔2018〕449号

山东省文物局：

你局《关于坊子德日建筑群（三马路片区）环境整治工程的请示》（鲁文发〔2018〕35号）收悉。经研究，我局意见如下：

一、原则同意坊子德日建筑群（三马路片区）保护范围和建设控制地带内环境整治项目建设方案。

二、对所报方案提出以下修改完善意见：

（一）进一步加强坊子德日建筑群（三马路片区）的核心价值、历史格局与功能等研究与分析，并据此对环境整治项目作进一步优化。环境整治要以文物建筑为主体，突出展示坊子德日建筑群三马路片区历史风貌，应进一步简化铺装、绿化等措施，避免过度景观化。

（二）铁路两侧的围栏不宜使用铁艺栏杆，文物建筑和其他历史建筑外墙亦应保持原有风貌，不应涂刷黄色或白色涂料。

（三）进一步规范方案图纸，环境整治效果图中建筑形态应是建筑实景，不应为虚拟模块。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十七条、十八条规定，履行相应审批手续后实施。工程施工期间，你局应加强监管，确保文物安全。

国家文物局

2018年5月8日
