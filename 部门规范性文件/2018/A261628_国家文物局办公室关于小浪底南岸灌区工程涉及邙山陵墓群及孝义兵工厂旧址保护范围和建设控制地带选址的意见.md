# 国家文物局办公室关于小浪底南岸灌区工程涉及邙山陵墓群及孝义兵工厂旧址保护范围和建设控制地带选址的意见

办保函〔2018〕88号

河南省文物局：

你局《关于小浪底南岸灌区工程涉及邙山陵墓群及孝义兵工厂旧址保护范围和建设控制地带选址的请示》（豫文物〔2017〕288号）收悉。经研究，我局意见如下：

一、所报建设项目部分管线穿越邙山陵墓群核心保护区，影响较大，我局暂不同意小浪底南岸灌区工程涉及邙山陵墓群保护范围的选址方案，对该工程涉及孝义兵工厂旧址保护范围的方案无异议。

二、所报方案尚需做以下必要的修改和完善：

（一）调整总干渠、三干渠、四干渠及五干渠的选址位置，避让邙山陵墓群中部遗存密集区，尤其是东汉帝陵群片区。建议考虑将总干渠与已有中州渠合并的可能性，并绕避汉魏洛阳故城保护范围。

（二）优化各支渠的选址位置，尽量避让邙山陵墓群遗存密集区，尤其是帝陵组群片区。

（三）进一步明确拟建渠线施工方式，研提有针对性的文物保护方案，补充渠线运营阶段监测及文物保护预案。

三、请你局指导建设单位，根据上述意见对所报方案做进一步修改和完善后，按程序另行报批。同时，应进一步开展工程涉建范围内考古调查和勘探工作，为编制工程方案提供依据。

国家文物局办公室

2018年1月30日
