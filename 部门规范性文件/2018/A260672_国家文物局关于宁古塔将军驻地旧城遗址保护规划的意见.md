# 国家文物局关于宁古塔将军驻地旧城遗址保护规划的意见

文物保函〔2018〕108号

黑龙江省文物管理局：

你局《关于〈宁古塔将军驻地旧城遗址文物保护规划〉的请示》（黑文管字〔2017〕12号）收悉。经研究，我局意见如下：

一、原则同意宁古塔将军驻地旧城遗址保护规划。

二、所报规划应进一步细化保护范围管理规定，补充提出二类建设控制地带内村庄发展的指导性意见，明确建筑翻建新建、人口安置、业态调整等的具体要求；补充分析海浪河对遗址的影响，并提出针对性措施；根据价值评估完善展示规划，重点突出遗址在统一多民族国家形成和融合方面的重要意义。

三、请你局指导地方人民政府组织规划编制单位和专业考古研究单位，按照上述意见对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的宁古塔将军驻地旧城遗址保护规划报请黑龙江省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府切实加强宁古塔将军驻地旧城遗址的保护和管理工作，加强专门保护管理机构建设，完善专项管理法规，并提出具体实施步骤和保障措施，妥善解决土地用途调整、环境整治等涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2018年1月25日
