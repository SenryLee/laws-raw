# 国家文物局关于三门塘旅游景区污水处理厂项目选址的意见

文物保函〔2018〕22号

贵州省文物局：

你局《关于呈报三门塘古建筑群建设控制地带内实施旅游景区污水处理厂及其配套管网建设工程项目的请示》（黔文物呈〔2017〕40号）收悉。经研究，我局意见如下：

一、原则同意三门塘旅游景区污水处理厂选址和你局意见。

二、对所报项目提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》与贵州省人民政府关于三门塘古建筑群保护范围和建设控制地带的相关管理规定，严格控制工程量和工程范围，尽量减少对文物及其景观环境的影响。补充三门塘古建筑群保护范围和建设控制地带的管理规定和具体控制指标。

（二）进一步优化污水外理厂外观设计，其结构形式和外观风貌应与古建筑群及周边景观相协调，可研提多种比选方案。同时，应采取一定的绿化遮挡措施，尽量减小污水处理厂对古建筑群的景观影响。

（三）进一步补充、细化石板路开挖恢复相关措施，应按文物保护工艺施工，尽量使用原有路面石材，保持原材料、原工艺。

（四）应充分考虑地质条件、开挖方式、与文物的距离以及古建筑的结构特征等，制定有针对性的、可行的文物保护措施，避免管道横穿古建筑，同时尽可能远离古建筑并采取必要的加固措施及安全监测，确保文物安全。

（五）进一步完善相关图纸。补充污水管网布设等的具体做法和相关图纸。工程断面图应科学规范，如实标注工程构造尺寸，明确具体工程做法。

（六）应调整完善文物影响评估报告，科学、客观评估建设项目对文物安全及其景观环境的影响。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十七条、第十八条的规定，分别报贵州省人民政府和城乡建设规划部门批准。施工中请加强监管，确保工程质量和文物安全。

国家文物局

2018年1月9日
