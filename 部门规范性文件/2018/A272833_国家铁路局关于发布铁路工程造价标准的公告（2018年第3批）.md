# 国家铁路局关于发布铁路工程造价标准的公告（2018年第3批）

## 国家铁路局关于发布铁路工程造价标准的公告

（2018年第3批）

国铁科法〔2018〕103号

现公布《铁路工程概算定额（第一册 路基工程）》（TZJ 2101-2018）等13项铁路工程造价标准（详见附件1），自2019年3月1日起实施。《铁路工程概算定额（第一册 路基工程）》（铁建设〔2010〕223号）等13项铁路工程造价标准（详见附件2）同时废止。

以上标准由中国铁道出版社出版发行。
