# 中国证券监督管理委员会对十三届全国人大一次会议第5044号建议的答复

## 对十三届全国人大一次会议第5044号建议的答复

《关于加强私募基金自律管理的建议》收悉。经认真研究并商国家发展改革委，现就有关问题答复如下：

促进私募基金健康持续发展，加强私募基金行业管理，要处理好行政监管与行业自律的关系，明确各自边界，既要加强行政监管，也要发挥好行业自律管理的效能。行政监管和行业自律的定位不同，行政监管主要借助法律法规及依法行使的强制性行政手段对市场主体进行约束，而行业自律是行业协会进行自主治理的重要形式，主要通过制定行业规范和标准等，规范行业机构的市场行为，促进行业机构之间的公平竞争，营造建立良好的市场环境。因此，建议中提出的“健全私募基金法律法规”“提高私募基金管理人股东条件”和“试行分级监管”三项内容，其本质属于依法实施行政监管的范畴；建议中提出的“培养私募基金从业人员”属于行业协会自律管理的内容。

**一、**关于建议中涉及的行政监管事项

一是健全私募基金法律法规。2014年8月我会发布《私募投资基金监督管理暂行办法》（以下简称《私募办法》），明确对私募基金行业采取事后登记备案的管理模式。此后，我会指导中国证券投资基金业协会先后出台一系列自律规则，有效地促进了行业规范发展。同时，我会积极配合原国务院法制办持续推动《私募投资基金管理暂行条例》（以下简称《私募条例》）的立法进程，进一步夯实私募投资基金在资金募集、资金托管、投资运作等各环节的制度基础。2017年《私募条例》已正式向社会公开征求意见。2018年，我会继续配合国务院立法部门根据公开征求意见反馈情况对《私募条例》进行修订。目前，我会正在落实《关于规范金融机构资产管理业务的指导意见》要求，加快修订《私募办法》，细化监管规则。同时，我会指导基金业协会进一步提升工作透明度，在已发布一系列自律规则、问题解答的基础上，近期先后发布《私募基金管理人登记须知》《私募投资基金备案须知》，并内置于协会“资产管理综合报送业务平台”系统，不断对外公开并细化登记备案相关标准。

二是提高私募基金管理人股东资质。相较银行、证券、信托等传统金融机构监管法律法规对发起人、股东等准入条件有明确要求的状况，现有法律法规并未对私募管理人及股东设置具体的准入条件和禁入约束。我会从扶优限劣、从严监管的角度出发，指导基金业协会在开展私募基金管理人登记过程中，结合私募行业实际情况完善准入标准，要求私募基金管理人主业集中明确，注重从机构注册资本、经营范围、实际业务开展情况、财务状况、展业计划等多方面加以甄别，对于具有优质股东背景的申请机构优先支持，起到了一定的扶优限劣作用。下一步，我会将与立法部门沟通，建议在《私募条例》中强化对基金管理人和股东的规范要求。

三是实行分级监管，改变监管思路。我会为提升私募基金监管效能，优化监管资源配置，推进差异化监管，正在探索并推进私募基金管理人分类分级机制，以私募基金管理人风险管理和持续合规情况为基础，结合私募基金管理人类别和综合情况，对各类私募基金管理人实施分类分级评价，为差异化监管提供依据。

**二、**关于建议中涉及的行业自律管理事项

中国证券投资基金业协会作为私募投资基金行业的自律性组织，接受中国证监会和国家民政部的业务指导和监督管理。为提高私募行业从业人员专业水平，基金业协会自2014年开始对私募基金从业人员进行注册管理。目前，针对从业人员资质准入，协会发布了《基金从业资格考试管理办法（试行）》，开展基金从业人员考试并出版配套教材；针对私募基金从业人员资格注册管理，协会已发布《关于进一步规范私募基金管理人登记若干事项的公告》、《私募基金登记备案相关问题解答（九）、（十一）、（十二）》、《关于基金从业人员资格管理实施有关事项的通知》等。为开展行业培训工作，基金业协会还同步建立与之对应的人员管理系统，要求从业人员每年完成一定的培训时长。下一步，基金业协会将继续完善从业人员管理自律规则，更加科学高效组织基金从业资格考试，强化从业人员合规培训、考核评价和问责制度，夯实私募基金行业的人才基础。
