# 教育部办公厅关于开展2018年“圆梦蒲公英”暑期主题活动的通知

教基厅函〔2018〕50号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

为深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，贯彻落实立德树人根本任务，纪念改革开放40周年，推动落实《中小学德育工作指南》，帮助广大中小学生度过一个安全、快乐、充实而有意义的暑假，教育部决定2018年继续开展“圆梦蒲公英”暑期主题活动。有关事项通知如下：

一、活动主题

圆梦蒲公英

二、活动目的

围绕“圆梦蒲公英”主题举办暑期系列活动，结合纪念改革开放40周年，引导广大中小学生培育和践行社会主义核心价值观，在活动中传承和弘扬优秀传统文化、革命文化和社会主义先进文化，不断增强中小学生对祖国、民族和家乡的热爱，培养社会责任感、创新精神和实践能力，提升科学素养和科学探究水平，促进广大中小学生全面发展和健康成长。

三、活动内容

1.“我眼中的改革开放40周年”活动。各地要组织学生通过绘画，观影，走访，制作相册，拍摄视频，参观博物馆、纪念馆等形式，感受祖国改革开放以来的巨大变化，充分认识中国共产党团结带领人民坚持改革开放，自力更生，艰苦创业，开辟中国特色社会主义道路所取得的伟大成就，进一步增强广大中小学生爱党爱国爱人民的情感。

2.“我是劳动小能手”活动。各地要引导学生根据自身特点，选择合适的劳动项目和内容，组织学生开展以勤俭节约为主题的体验活动，城镇学校可结合实际情况组织学生参加公益劳动与志愿服务，农村学校可结合实际情况在农忙时节组织学生帮助家长进行适当的农业生产劳动，鼓励学生积极参加家务劳动，树立劳动光荣的正确观念和节约意识，掌握劳动技能，养成劳动习惯。

3.“美丽中国主题研学”活动。各地要充分利用全国中小学研学实践教育基地、营地，组织开展生态文明等主题研学实践教育活动，让广大中小学生在活动中感受祖国大好河山，树立爱护自然、保护生态意识，提高生态文明素养，引导学生践行绿色生活方式，逐渐形成低碳环保、文明健康的生活习惯。

4.“追寻红色记忆”活动。各地要将红色文化和革命传统教育纳入学生暑期社会实践、夏令营等活动，突出地域特色和文化特色，组织中小学生到革命历史遗址、革命历史博物馆、革命先辈纪念馆等场所参观，引导学生了解中国革命史和中国共产党的历史，继承革命传统，传承红色基因，不断树立为共产主义远大理想和中国特色社会主义共同理想而奋斗的信念和信心。

5.“乡村学生看县城”活动。各地要根据实际面向乡村、贫困地区开展乡村学生看县城活动，在保障安全的前提下，组织贫困地区学生和乡村留守儿童走入城市、县城，走进博物馆、科技馆、示范性综合实践基地、青少年活动中心、少年宫、研学实践教育基（营）地等场所，广泛开展参观学习、交流互动、体验分享等活动，帮助他们在丰富多彩的活动中感受现代文明，开阔视野、陶冶情操、全面发展。

6.“走进科学世界”活动。各地要依托科技馆、乡村少年宫、中小学科普教育社会实践基地等资源，组织开展“青少年科学调查体验活动”“全国青少年科学影像节活动”等各类科普教育活动，帮助广大青少年在活动中了解科学知识、提高实践能力，激发他们对创新创造的兴趣，促进青少年科学素质的提高。

7.“品味经典图书”活动。各地中小学校要与家庭密切沟通合作，组织学生在假期阅读经典图书，以学校（年级、班级）或家庭为单位，开展名篇佳作赏析、读书心得讨论、读书笔记和读书报告撰写等活动。组织参加2018年暑期“我的书屋 我的梦”农村少年儿童阅读实践活动，以农家书屋为平台，引导农村中小学生在阅读中享受快乐，丰富假期文化生活。

四、工作要求

1．高度重视，统筹规划。各地要切实发挥各级青少年校外教育工作联席会议办公室的统筹协调职能，加强各成员单位交流合作，充分调动各系统资源，精细谋划、积极推动各项活动开展，形成体现校外教育内涵发展的“圆梦蒲公英”活动品牌。

2．认真组织，注重公益。各地要结合实际，从青少年身心发展和锻炼成长的需要出发，制定本地区活动方案和实施计划，开展形式多样的教育实践活动。要不断创新活动的形式和载体，提高活动的针对性。要坚持公益性原则，与相关部门密切配合，鼓励和倡导各类公益性活动设施向青少年免费开放，为青少年就近就便参加暑期活动提供条件。

3．广泛宣传，确保安全。各地在开展各项暑期活动中要使用统一的“圆梦蒲公英”暑期主题活动标志（见附件），加大宣传力度，充分利用各类媒体，开展多角度、大范围的舆论宣传工作，营造关注青少年健康成长的良好氛围。同时，各地教育行政部门和各类青少年学生校外活动场所要加强安全防范，制定活动安全保障方案及应急预案，落实安全措施，在活动开始前对学生进行安全教育，帮助青少年提高安全意识、自我保护意识和应急能力。

五、活动成果材料报送要求

1．各省（区、市）要做好2018年暑期活动的总结工作，选取各地暑期活动中地方特色突出、显示度较高、影响力较大的典型活动，形成“圆梦蒲公英”暑期活动成果。

2．成果材料要文字简洁、重点突出，2000字以内为宜。每项活动配3—5张有代表性的照片，以表现学生活动为主。报送的照片要有图注，文件不小于1兆，格式为jpg。

3.请于2018年8月31日前报送本省（区、市）2018年暑期活动的成果材料。材料电子版发送至指定邮箱，纸质版材料加盖省级教育行政部门公章后邮寄至教育部基础教育司德育与校外教育处。
