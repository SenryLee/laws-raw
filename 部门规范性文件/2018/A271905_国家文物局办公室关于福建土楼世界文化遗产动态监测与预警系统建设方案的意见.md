# 国家文物局办公室关于福建土楼世界文化遗产动态监测与预警系统建设方案的意见

办保函〔2018〕1140号

福建省文物局：

你局《关于报送世界文化遗产福建土楼动态监测与预警系统建设方案的请示》（闽文物字〔2018〕220号）收悉。经研究，我局暂不同意世界文化遗产福建土楼动态监测与预警系统建设方案。

一、对所报方案提出以下修改完善意见：

（一）应统筹考虑南靖、永定、华安三地世界文化遗产福建土楼各自的特点和需求，统一开展监测预警体系建设，确保体系的整体性。

（二）系统梳理福建土楼申报世界遗产时所做承诺，以及世界遗产委员会相关决议和国际古迹遗址理事会评估报告等文件对福建土楼保护管理提出的要求，作为监测预警体系建设的重要参考。

（三）应组织专业机构深入开展现场勘察，进一步强化前期评估工作，全面准确掌握病害类型、根源和发展趋势，明确外部自然环境影响因素，查找当前保护管理存在的问题，为确定监测对象、内容、指标、范围和技术手段等提供科学依据。评估分析应做到科学合理，对台风、地震等自然灾害的影响应分别进行评估，建设项目影响评估应区分文物保护工程，不可混为一谈。

（四）进一步补充、细化监测数据项和监测指标，完善监测措施。针对夯土墙贯通裂隙、屋顶瓦面漏洞、彩画病害等重点监测内容应在充分研究论证的基础上，提出切实有效的监测技术手段，并详细说明实施方法。

（五）补充对村落环境以及村民私搭乱建、不规范用火用电、不规范经营行为等方面的监测内容。

（六）监测预警体系建设应与现行管理体系进行整合和衔接。各土楼目前设置的墙体沉降、裂缝和电气火灾监测设备，应与监测数据采集、预警、应急处置等各环节设施设备进行有效对应，实现监测预警体系对日常管理工作的有效支撑。

（七）对已经开展的监测工作进行评估，充分利用已有的监测数据和监测设备，简化方案设计，科学合理布局，整体研发，减少重复的系统平台建设，节约经费。如中国世界文化遗产监测预警系统总平台已发布免费版“监测云”系统，本项目无需重复建设移动式监测系统等。

（八）根据各地的实际情况和管理模式，明确开展监测工作的责任主体，细化系统中的角色分配。应考虑公众在监测系统建设和运行中的知情权、参与权。发挥土楼内居民、基层管理者等日常相关人员在监测体系中的作用和特长，减少不必要的设备配置以及维护，建立人机配合的监测体系。

（九）应补充监测系统建成运行期间的定期评估方案，以便根据评估结果对系统及时进行调整和完善。

（十）应根据国家文物局《古建筑保养维护规程》，做好世界文化遗产福建土楼的日常保养维护工作；严格控制福建土楼遗产区和缓冲区内的建设活动，对于任何可能影响世界文化遗产突出普遍价值、真实性和完整性的修缮和建设项目，在实施前依法履行报批程序。

二、请你局指导有关单位，根据以上意见对方案进行修改完善后，按程序另行报批。

专此函复。
