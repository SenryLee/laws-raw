# 交通运输部办公厅关于优化调整12328电话信息统计制度的通知

交办运〔2018〕87号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

按照《交通运输部办公厅关于开展12328电话系统信息分析工作的通知》（交办运〔2015〕37号）要求，各级交通运输主管部门认真开展信息统计分析工作，建立了12328电话信息统计制度，较好地发挥了12328电话倾听民声、畅通民意、汇集民智的作用。但是，随着交通运输改革发展进程不断加快，运输服务新模式、新业态不断涌现，原有的信息统计制度已不能满足人民群众日益多元化的服务需求，不适应管理部门日益精细化的工作需要。为此，交通运输部决定对12328电话系统信息统计制度进行优化调整。经交通运输部同意，现将有关工作通知如下：

一、加快调整电话系统信息统计体系

部在既有工作基础上，组织编制了《12328交通运输服务监督电话系统业务类型编码表》（以下简称《业务类型编码表》，见附件）。各省级交通运输主管部门要按照《业务类型编码表》，加快调整12328电话系统信息统计业务架构，逐级梳理调整各级业务分类编码，各地可根据需要在《业务类型编码表》最子级业务的基础上进一步细化业务分类及编码。同时，要加快开展电话系统功能升级、接口改造、联网调试等工作，确保部、省信息统计内容一致、步调一致。电话系统联网运行、信息报送、工单转办等业务接口均应以完整的业务编码结构（含父级业务编码）报送数据，所有业务编码应与《业务类型编码表》保持一致，有自行细化业务分类的，应归并转换为与《业务类型编码表》相对应的最子级业务编码后再报送。

二、进一步优化升级电话系统功能

各省级交通运输主管部门要根据新调整的12328电话系统信息统计业务架构和各级业务编码，加快优化调整12328电话系统服务功能，确保电话工单受理、转办、统计、监测等业务功能需求。要进一步加快电话系统知识库升级、维护和配套服务，提供灵活快捷的业务分类选择等操作功能，最大限度降低话务员的工作强度。要进一步优化电话系统服务质量监测和评价功能，提高电话系统服务质量监测评估效果，进一步提升12328电话系统运行服务水平。

三、进一步完善电话系统统计分析制度

12328电话系统统计分析工作是12328电话服务管理的基础性、统领性工作，是12328电话服务管理工作重要的价值体现。各级交通运输主管部门要结合此次电话系统信息统计制度优化调整，进一步提高电话系统统计分析工作质量，完善电话系统服务功能，增强12328电话便民利民服务水平和行业决策支撑能力。一是建立常态化工作机制。进一步明确电话受理、转办、回访等全链条信息统计内容和要求，明确相关岗位职责和具体责任人，建立层层审查、逐级复核、重点抽查相结合的质量管控机制，形成工作闭环，确保数据统计真实、准确、完整，确保信息报送顺畅、及时、高效。二是进一步加强数据挖掘分析。要充分利用12328电话系统联网运行技术优势，积极探索将大数据技术引入统计信息分析工作，通过对巨量数据的整合分类和对比分析，深入研判趋势、寻找规律、发现问题，让信息统计分析工作发挥更大作用。三是加强工作督导考评。各地要结合《12328交通运输服务监督电话系统运行服务质量考评暂行办法》（交办运〔2017〕135号），建立电话系统统计分析和信息报送工作的督导考评机制，加强对12328服务中心、话务员、工单承办单位等相关责任主体的督导考评，并将考评结果作为有关部门和单位绩效考核的重要内容。四是进一步加强统计分析成果应用。不断丰富应用载体，通过编制信息分析工作报告、舆情快报、信息专报等形式，全方位、多渠道展现12328信息统计分析成果。要积极拓宽应用范围，将信息统计分析成果更多地应用到服务领导决策、完善行业管理政策措施、提高交通运输服务水平、加强行业监管、维护行业稳定等实际工作中，不断改进提升运输服务水平。为加强经验交流推广，请各省级交通运输主管部门每季度梳理总结本辖区利用12328电话系统开展的便民利民服务典型案例（内容包括主要做法、服务效果、经验与启示等），并于下季度前5个工作日内报部（电子邮箱：12328@mot.gov.cn）。

四、有关工作要求

部将从2019年1月1日起，按照《业务类型编码表》，启动升级后的12328电话系统统计分析工作，各省级、地市级12328电话系统应在2018年11月底前完成电话系统信息统计体系调整、系统平台升级和联网调试等准备工作。2018年12月，部将组织开展试运行，有关工作进展情况和运行结果将纳入12328电话运行服务质量年度考评内容。各级交通运输主管部门要组织12328电话服务中心等有关单位制定专门工作计划，明确责任分工，倒排工期，确保全国一盘棋。使用自主开发电话系统软件的省份，要组织有关技术单位加快软件升级和技术测试；使用基础通用性软件的省份，且未经过二次开发的，可向中国交通通信信息中心免费申请升级的基础通用性软件，如经其他单位进行过二次开发的，可向开发单位咨询解决方案，明确系统改造升级工作要求，必要时可向中国交通通信信息中心联系申请支持。部级12328电话系统2018年8月底将具备联调测试条件。完成电话系统信息统计体系调整和系统升级的省份，要及时与中国交通通信信息中心联系，申请与部级系统联网调试。各省级交通运输主管部门要加强对辖区内各地市工作的督导检查，及时发现并协调解决有关问题，对于未能按期完成联网调试、试运行以及影响全国统计分析工作统一开展的省份，部将视情予以通报批评。

部2015年印发的《交通运输部办公厅关于开展12328电话系统信息分析工作的通知》（交办运〔2015〕37号）中与以上内容相抵触的，以此文为准。
