# 国家文物局关于南京城墙保护范围和建设控制地带内实施西北护城河整治工程——截流井施工项目的意见

文物保函〔2018〕470号

江苏省文物局：

你局《关于审批南京市鼓楼区西北护城河整治工程——截流井施工工程方案设计的请示》（苏文物保〔2018〕43号）收悉。经研究，我局意见如下：

一、原则同意南京城墙保护范围和建设控制地带内实施西北护城河整治工程-截流井施工项目和你局意见。

二、对该方案提出以下修改完善意见：

（一）R54截流井位于南京城墙保护范围内，距离城墙本体过近，建议移出保护范围，同时应做好文物保护措施，避免工程施工影响地下遗存和城墙基础安全。

（二）明确清淤疏浚工程和生态补水工程的具体范围、与南京城墙的关系、工程措施以及文物保护要求；清淤工程部分标段清理深度在1米以上，应妥善做好保护措施和应急预案，避免破坏护城河原有形态和遗存。文物影响评估报告应补充评估相关内容。

（三）岸线修复应结合历史环境，统筹进行材质、风貌和植物景观设计，保持一定连续性，避免岸坡分段差异过大。岸线贯通如涉及南京城墙保护范围和建设控制地带，应另报工程方案和文物影响评估报告。进一步确认护城河挡墙是否属南京城墙文物本体，如为本体应按文物保护工程另行上报修复工程方案。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》的有关规定分别履行相应报批程序后实施。

四、清淤工程实施前应进行必要的考古工作，如有重要发现，应及时调整设计方案。请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局

2018年5月9日
