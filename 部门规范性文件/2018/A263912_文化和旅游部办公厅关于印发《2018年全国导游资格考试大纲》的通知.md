# 文化和旅游部办公厅关于印发《2018年全国导游资格考试大纲》的通知

办旅函〔2018〕41号

各省、自治区、直辖市旅游发展委员会、旅游局:

为做好2018年全国导游资格考试工作，现将《2018年全国导游资格考试大纲》印发给你们，请认真贯彻执行。《2018年全国导游资格考试大纲》电子版可从文化和旅游部（旅游事业 旅游产业）网（www.cnta.gov.cn）“通知公告”栏目中下载。

特此通知。

文化和旅游部办公厅

2018年4月24日

附件：2018年全国导游资格考试大纲
