# 文化和旅游部人事司关于组织开展2017年度入选万名旅游英才计划项目验收工作的通知

各省、自治区、直辖市文化和旅游行政部门，新疆生产建设兵团商务局（旅游局）：

根据文化和旅游部万名旅游英才计划工作安排及项目实施有关要求，决定于近期对2017年度入选万名旅游英才计划的部分项目开展验收工作。现将有关事项通知如下：

一、 工作目的

全面了解2017年度万名旅游英才计划项目执行情况，总结人才培养成效和项目实施经验，加大项目成果转化应用及宣传力度，充分发挥万名旅游英才计划在全国旅游人才工作中的引领示范作用。

二、验收对象

验收对象为2017年度入选的万名旅游英才计划培养项目，包括研究型英才培养项目、实践服务型英才培养项目、“双师型”教师培养项目、旅游数据与旅游统计人才培养项目和“金牌导游”人才培养项目。

三、验收方式

项目负责人提交项目总结报告和相关材料，经所在院校或省级文化和旅游行政部门审核后报送相应项目执行办公室。其中，研究型英才培养项目报送至全国旅游管理专业学位研究生教育指导委员会秘书处，实践服务型英才培养项目和“双师型”教师培养项目报送至全国旅游职业教育教学指导委员会秘书处，旅游数据与旅游统计人才培养项目报送至中国旅游研究院（数据中心），“金牌导游”人才培养项目报送至文化和旅游部人才中心。项目材料应由项目负责人所在单位统一报送，不接受个人报送。

四、验收内容

（一）项目计划完成情况；

（二）项目成果成效、典型经验和突出做法；

（三）项目对行业产业的影响；

（四）项目经费使用情况。

五、其他

（一） 请于2018年12月21日前将项目总结和有关材料（包括反映项目主要成果的文字、图片和其他多媒体资料，出版物、论文、报刊等可把主要信息转化为图片资料）电子版以及项目总结纸质版（一份）邮寄至相应项目执行办公室。本通知及附件可在文化和旅游部网站下载。
