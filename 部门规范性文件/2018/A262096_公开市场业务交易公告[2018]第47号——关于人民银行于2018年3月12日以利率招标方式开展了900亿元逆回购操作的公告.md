# 公开市场业务交易公告[2018]第47号——关于人民银行于2018年3月12日以利率招标方式开展了900亿元逆回购操作的公告

## 公开市场业务交易公告

[2018]第47号

为对冲税期等因素的影响，维护银行体系流动性合理稳定，人民银行于2018年3月12日以利率招标方式开展了900亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 500亿元 | 2.50% |
| 28天 | 400亿元 | 2.80% |

中国人民银行公开市场业务操作室

二〇一八年三月十二日
