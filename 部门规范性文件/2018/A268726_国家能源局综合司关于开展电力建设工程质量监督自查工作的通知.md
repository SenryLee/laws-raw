# 国家能源局综合司关于开展电力建设工程质量监督自查工作的通知

各电力建设工程质量监督机构：

为进一步加强电力建设工程质量监督管理，规范电力建设工程质量监督机构（以下简称电力质监机构）工作行为，进一步提高质量监督工作成效，经研究，决定组织电力质监机构开展电力建设工程质量监督自查工作。现将有关事项通知如下。

一、自查内容（ 包括但不限于）

（一）机构建设方面

1.是否将政府委托的质量监督职能与企业内部工程质量管理进行界定。

2.是否按照现行质监规定要求设立工程质量监督项目站。

3.是否建立内部管理制度，并严格执行。

（二）工作开展方面

1.是否按规定做到质监全覆盖。

2.是否存在拒绝为符合要求的电力建设工程办理质监注册手续的行为。

3.是否规范履行质监程序。

4.是否按现行质监大纲要求规范开展阶段性质监工作；是否存在任意缩减质监阶段的行为。

5.是否存在对发现的重大质量问题隐瞒不报的行为。

6.是否严格执行质监工作要求和廉政工作纪律。

7.是否按规定报送质监工作信息。

二、时间安排

各电力质监机构按自查内容开展自查工作，同时对进一步做好质监工作提出意见建议。请于10月底将自查总结报告报送我局电力可靠性管理和工程质量监督中心。

三、自查方式

通过查看近两年质量监督档案、内部管理制度等，梳理质量监督工作的开展情况，对照自查内容和相关规定查找问题，提出有针对性的解决措施。对在监工程要逐一进行自查，发现问题及时处理，确保在监工程质量安全。

四、有关要求

（一）加强组织领导，明确责任分工。各电力质监机构要充分认识质量监督自查工作的重要性，加强组织领导，明确责任分工，确保工作成效。

（二）深入查找原因，做好整改闭环。各电力质监机构对自查发现的问题，能立即整改的立行立改，暂时不能整改的要制定时间表和整改措施，并深入查找原因，举一反三，做到问题整改闭环，同时健全完善相关管理制度，建立防范问题发生的长效机制，切实提高质监工作水平。我局将对各电力质监机构的自查情况进行抽查。
