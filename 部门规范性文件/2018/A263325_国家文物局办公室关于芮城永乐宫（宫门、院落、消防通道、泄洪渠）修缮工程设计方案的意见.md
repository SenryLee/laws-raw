# 国家文物局办公室关于芮城永乐宫（宫门、院落、消防通道、泄洪渠）修缮工程设计方案的意见

办保函〔2018〕331号

山西省文物局：

你局《关于审批芮城永乐宫（宫门、院落、消防通道、泄洪渠）修缮工程设计方案的请示》（晋文物〔2017〕221号）收悉。经研究，我局意见如下：

一、该项目方案经多轮修改，仍然存在勘察不够完善，设计深度不足，部分保护措施不合理等问题，须作较大调整、修改，主要意见如下：

（一）进一步完善现状勘察，补充对屋面、油饰现状做法及砖、瓦材料规格等的调查记录。补充围墙、消防通道大门、排水沟、泄洪渠等的现状勘测图，标示现状病害问题范围。

（二）调整完善宫门修缮设计。大木构架修缮措施与现状不符，干预力度过大，应予调整，如补充勘察未发现明显病害，主要解决屋面木基层及其以上构造层的问题即可；细化木构件修缮措施，各类措施应与构件、病害分别对应，不应笼统描述；核实“剔除木构件风化部分”、“铁件加固细小裂缝”、“木构件钻生”、“挠洗见新柱顶石”等措施的必要性和合理性；风化、碎裂而不影响结构安全和使用的墙、地面砖石构件，不得更换、揭墁；补充砖、瓦等材料的规格、材质等要求；核实散水方砖和室内方砖的尺寸关系，并明确垫层做法和泛水要求；暂缓实施砖石构件防风化处理。

（三）调整完善院落修缮设计。不得全面重做甬路及院落地面，应尽可能减少扰动，解决其局部排水问题即可，避免整饰一新。明确围墙不同修缮措施的适用范围，补充详细设计图纸并标示修缮范围和工程量。

（四）调整完善消防通道修缮设计。宫门前小广场地面铺装应与保护规划要求相符；按照消防规范完善消防通道平面及剖面设计；消防通道改造涉及原有铺装的，应尽可能续用；调整消防通道大门选址及外观设计，应与历史环境相协调。

（五）调整完善泄洪渠修缮设计。明确泄洪渠、排水沟不同处理措施（整修、重砌）的段落范围，作图标示。应尽可能疏通、续用原沟渠。

（六）规范文字说明，删除“槽钢加固”等无关内容。

三、请你局指导有关单位按照上述意见及我局办保函〔2017〕287号、办保函〔2016〕384号、办保函〔2015〕1599号等文件的要求，认真修改、完善后另行报批。

四、请你局切实加强管理，督促、指导相关单位做好永乐宫的日常养护工作，及时发现和排除隐患，确保文物安全。
