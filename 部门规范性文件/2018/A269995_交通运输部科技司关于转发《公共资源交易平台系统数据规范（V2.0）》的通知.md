# 交通运输部科技司关于转发《公共资源交易平台系统数据规范（V2.0）》的通知

## 关于转发《公共资源交易平台系统数据规范（V2.0）》的通知

科技信息函〔2018〕164号

部属各单位：

现将国家发展和改革委员会办公厅、财政部办公厅、自然资源部办公厅、国务院国有资产监督管理委员会办公厅联合印发的《公共资源交易平台系统数据规范（V2.0）》转你单位，请在相关平台建设和数据使用方面遵照执行。

交通运输部科技司

2018年10月23日

附件：公共资源交易平台系统数据规范
