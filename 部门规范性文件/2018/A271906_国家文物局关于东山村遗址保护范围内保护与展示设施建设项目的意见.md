# 国家文物局关于东山村遗址保护范围内保护与展示设施建设项目的意见

文物保函〔2018〕1502号

江苏省文物局：

你局《关于审批张家港市东山村遗址保护与展示设施建设项目方案（修改稿）的请示》（苏文物保〔2018〕293号）收悉。经研究，我局原则同意在东山村遗址保护范围内实施保护与展示设施建设项目。

一、所报方案尚需做以下必要的修改和完善：

（一）加强现场勘察和考古资料梳理，根据遗址保存现状、室内环境控制和地下水控制要求，深化拟建建筑的功能设计，进一步调整建筑内温湿度、光照等控制措施，补充设置填砂排水沟和集水井的文物影响评估、日常维护要求等。

（二）保护棚建设应重点满足考古工作需要，后期展示设计应根据考古工作成果进一步深化、调整，并根据考古工作进展适时启动相关设计和展陈设施提升项目。

（三）补充项目运营及维护成本分析。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的监管，组织南京博物院等专业机构和考古人员全程参与指导，确保工程质量和文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究处理意见和保护方案，报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

专此函复。

国家文物局

2018年11月29日
