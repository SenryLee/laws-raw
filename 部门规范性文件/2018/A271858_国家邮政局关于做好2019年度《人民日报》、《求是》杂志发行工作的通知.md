# 国家邮政局关于做好2019年度《人民日报》、《求是》杂志发行工作的通知

国邮发〔2018〕116号

各省、自治区、直辖市邮政管理局，中国邮政集团公司：

为了落实《中共中央办公厅关于做好2019年度<人民日报>、<求是>杂志发行工作 严格规范报刊发行秩序的通知》（厅字〔2018〕132号）（以下简称《通知》）要求，切实做好2019年度党报党刊发行工作，现将有关事项通知如下：

一、提高政治站位，充分认识做好党报党刊发行工作重大意义

《通知》指出，做好2019年度《人民日报》、《求是》杂志发行工作，对于深入学习宣传贯彻习近平新时代中国特色社会主义思想和党的十九大精神，贯彻落实习近平总书记在全国宣传思想工作会议上的重要讲话精神，引导广大干部群众增强“四个意识”，坚定“四个自信”，为决胜全面建成小康社会、夺取新时代中国特色社会主义伟大胜利、实现中华民族伟大复兴的中国梦而奋斗，具有重要意义；对于进一步推进党的新闻事业健康发展，巩固党中央机关报和机关刊物在意识形态领域的主导地位，建设具有强大凝聚力和引领力的社会主义意识形态，具有重要意义。

各级邮政管理部门和邮政企业要充分认识做好党报党刊发行工作的重要政治意义，全面贯彻落实《通知》精神，以高度的责任感和使命感，坚定不移的履行好党报党刊发行职责，强化政治担当，密切协同配合，确保2019年度党报党刊发行工作顺利开展。

二、强化责任担当，进一步提高党报党刊发行质量

（一）切实做好党报党刊征订零售工作。邮政企业要全面贯彻落实《通知》精神，集中人力物力，做好党报党刊征订工作。密切配合当地宣传等部门，采取有效措施确保订阅数量稳定。要继续做好党报党刊零售工作，邮政营业场所要按要求订购并摆放一定数量的《人民日报》、《求是》杂志供读者阅读，市地级以上城市邮政报刊亭要设立《人民日报》、《求是》杂志特约销售点。要根据市场需求增加零售网点，逐步覆盖到县一级邮政报刊亭。

（二）努力提升党报党刊投递服务水平。邮政企业要合理配置资源，科学组织作业，进一步优化邮路组织。总结推广利用客运班车、高铁和航空等运输方式代运党报党刊的经验。切实做好内部质量管控，做到内部各环节以及与印厂的有效衔接，努力提升运输投递等各环节时效，完善延迟交报应急处理机制。要在巩固县级党政机关党报当日见报工作成果的基础上，进一步提高当日见报率。充分发挥自身网络优势，确保中央向中西部和东北地区农村党支部、全国高校党支部赠阅的《人民日报》、《求是》杂志及时送达。

三、积极履职尽责，进一步做好党报党刊发行组织协调工作

（一）积极做好服务保障工作。各级邮政管理部门要加强与交通运输管理部门的联系，积极争取对党报党刊运输的政策支持。充分发挥政府部门协调联动机制，主动联系地方党委以及宣传、财政等部门，共同解决邮政企业遇到的困难和问题，努力为党报党刊发行创造良好环境。

（二）切实履行监督管理职责。各级邮政管理部门要及时跟踪了解当地党报党刊征订情况，扎实做好党报党刊投递服务质量的监督检查，督促邮政企业不断提高发行服务质量，满足人民群众在新时代对党报党刊信息服务的更高要求。

《光明日报》、《经济日报》发行工作参照本通知执行。请中国邮政集团公司在2019年1月3日前将2019年党报收订情况报国家邮政局。
