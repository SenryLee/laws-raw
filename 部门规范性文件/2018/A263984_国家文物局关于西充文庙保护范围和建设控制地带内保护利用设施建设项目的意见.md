# 国家文物局关于西充文庙保护范围和建设控制地带内保护利用设施建设项目的意见

文物保函〔2018〕438号

四川省文物局：

你局《关于报送〈西充文庙保护利用设施建设项目勘察设计方案〉的请示》（川文物〔2018〕17号）收悉。经研究，我局意见如下：

一、原则同意西充文庙保护范围和建设控制地带内保护利用设施建设项目和你局意见。

二、所报方案应做以下必要修改和完善：

（一）调整设计思路，进一步调减拟建项目。设计目标以提升文物的景观环境，满足管理服务基本需求为主，避免过多建设项目对文物及环境造成负面影响。补充西充文庙保护范围和建设控制地带的管理规定和具体控制要求。

（二）加强现状勘察，对文庙院内地面铺装、植被梳理、围墙修缮、基础管线等工程内容，应细化现状勘察内容及残损原因分析，提出结论性意见和具体措施。植被梳理应避免过度园林化倾向。

（三）优化建设项目选址，减小新建管理用房体量，其高度、规模、体量必须符合西充文庙建设控制地带的控制要求，避免对文庙本体及周边山地景观风貌等造成影响。

（四）消防通道的设置应结合西充文庙消防设施专项工程进行。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》第十七条、十八条的有关规定分别报四川省人民政府和城乡建设规划部门批准后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局

2018年5月2日
