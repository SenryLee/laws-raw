# 自然资源部办公厅关于做好岁末年初安全防范工作的通知

自然资电发〔2018〕57号

各省、自治区、直辖市自然资源主管部门，中国地质调查局及部其他直属单位，各派出机构：

2019年是新中国成立70周年，是决胜全面建成小康社会的关键之年。为认真贯彻落实习近平总书记关于做好岁末年初安全生产工作的重要指示和中办、国办《关于做好2019年元旦春节期间有关工作的通知》精神，统筹做好节日期间自然资源系统安全管理工作，有效应对各类灾害，坚决遏制重特大事故，按照《国务院安委会办公室 应急管理部关于做好岁末年初安全防范工作的通知》（安委办明电〔2018〕20号）有关部署，现就有关事项通知如下。

一、严防麻痹松懈思想，层层压实安全责任

岁末年初历来是安全生产的关键期，特别是元旦春节期间群众出行和大型群众性活动增多，人流物流车流剧增，同时受低温、雨雪、冰冻等灾害性天气影响，事故易发多发。要始终绷紧神经，不能有丝毫松懈、半点马虎，深入研判岁末年初事故规律特点，切实把重大风险搞清弄准，加强各类安全风险防控和隐患治理，狠抓岁末年初各项安全防范责任措施落实，有针对性地制定严密的防范管控工作方案。

部系统直属单位要认真学习和落实最近李克强总理针对北京交通大学实验室爆炸引发火灾的事故所作的重要批示精神，进一步把安全生产责任和措施落实到位，抓紧完善相关管理制度，防范各类安全事故发生。主要领导要亲力亲为，切实负起领导责任，严格落实安全防范责任措施。要把安全生产责任落实到每个环节、每个岗位和每名员工，深入细致开展隐患排查治理，严防各类事故发生，确保安全生产形势稳定。

二、全面排查整治各类安全隐患，强化安全风险管控

地方各级自然资源主管部门要在地方人民政府安委会的统一领导下，积极配合有关部门突出重点行业领域，深入开展冬季安全检查，全面排查管控安全风险、及时治理安全隐患。要配合有关部门突出抓好煤矿和非煤矿山隐患排查与治理，加强瓦斯、水灾等重大灾害防治，严肃查处非法勘查开采等行为，严防节日期间非法违法突击生产。继续配合公安部门开展打击整治枪支爆炸物品违法犯罪专项行动，严防违法违规勘查开采矿产资源引发安全事故。强化测绘外业安全管理，加强在高原、荒漠、海上等困难区域和城市人员车辆密集区域测绘作业管理与安全防范，禁止在暴雪、大风等恶劣气候条件下作业，加强外业队伍返回驻地交通安全管理，避免发生交通事故。

中国地质调查局及部其他直属单位、各派出机构要结合本单位实际，持续组织开展冬季安全生产检查，深入排查、有效管控各类安全风险，及时整治消除各类安全隐患。要严格执行危险化学品、易燃易爆物品安全管理规定，强化安全防范措施，杜绝违规操作和储存，严防发生爆燃、爆炸、中毒等事故。要针对冬季火灾事故规律特点，加强火灾风险隐患排查治理，严格整治“三合一”“多合一”场所和违规使用易燃装修装饰材料、消防设施缺失损坏、疏散通道堵塞、电气线路老化破损等问题，有效管控火灾风险，及时消除火灾隐患，严防火灾事故发生。要严格施工现场安全管理，认真落实冬季施工安全措施，严禁雨雪、大风天气强行组织施工。

三、强化应急防范，有效防范应对自然灾害

地方各级自然资源主管部门要强化部门联动，加强灾害性天气监测预警，切实抓好地质灾害监测预警、海洋预警预报和风险提示，严格落实防灾避险措施，避免自然灾害造成群死群伤事件。要配合有关部门进一步健全完善安全生产应急预案，进一步强化值班值守和应急联动，确保一旦发生事故险情能协助有关部门及时科学有效应对和处置。

中国地质调查局及部其他直属单位、各派出机构要根据节日特点加强应急准备，落实救援队伍、装备、物资等应急资源，完善应急预案，强化应急演练。要加强值班值守，严格执行领导干部带班、关键岗位24小时值班制度和事故信息报告制度。要加强对冬季用火用电用气、烟花爆竹燃放等安全知识和逃生自救等常识的宣传，提高安全防范能力。节日期间正常工作的单位要加强员工特别是重点岗位人员安全管理和教育培训，稳定职工思想，强化安全意识，提升全员安全技能和应急处置能力。
