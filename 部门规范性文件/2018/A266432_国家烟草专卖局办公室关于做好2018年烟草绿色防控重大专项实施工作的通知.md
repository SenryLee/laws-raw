# 国家烟草专卖局办公室关于做好2018年烟草绿色防控重大专项实施工作的通知

国烟办综〔2018〕81号

行业各直属单位，各有关单位：

按照《国家烟草专卖局关于启动实施烟草绿色防控重大专项的通知》（国烟科〔2016〕305号）总体部署，结合《国家烟草专卖局办公室关于印发烟草绿色防控重大专项实施工作方案和技术方案的通知》（国烟办综〔2017〕193号）要求，现将2018年烟草绿色防控重大专项实施工作安排如下:

一、指导思想

按照高质量发展的要求，牢固树立和贯彻新发展理念，立足蚜茧蜂，走出蚜茧蜂，构建烟草病虫害绿色防控新模式，实现从蚜茧蜂单项技术到烟草绿色防控技术体系的跨越；立足烟草，走出烟草，实现从烟草农业到大农业的跨越，不断扩大推广面积、减少化学农药用量，降低烟叶农药残留，提升防治综合效益，保障烟区农产品质量和生态环境安全，推进乡村绿色发展，提升烟草行业正能量，打造责任烟草新名片，使烟草农业成为我国农业绿色发展和生态文明建设的典范。

二、目标任务

（一）扩大推广面积。各烟叶主产省（区、市）绿色防控综合示范区面积、辐射区面积要分别达到本省植烟面积的3%以上、20%以上，主推绿色防控技术不少于2项。重大专项“三虫三病”技术首席专家在全国建设一批单项靶标示范区，各靶标示范区面积不低于1500亩。综合示范区和辐射区具体目标见附件1，单项靶标示范区具体目标见附件2。

（二）减少化学农药用量。各烟叶主产省（区、市）绿色防控综合示范区化学农药用量较2015年减少40%以上，辐射区化学农药用量较2015年减少20%以上；各单项靶标示范区化学农药用量与2015年相比减少40%以上，其中蚜虫、病毒病的单项靶标示范区，防治蚜虫、病毒病的化学农药用量分别减少100%。

（三）降低烟叶农药残留。各烟叶主产省（区、市）要最大限度降低绿色防控综合示范区和辐射区烟叶的农药残留，并确保绿色防控综合示范区的烟叶农药残留不超限。保持全部烟叶产区农药残留逐年降低。

（四）提升防治综合效益。各烟叶主产省（区、市）绿色防控综合示范区、辐射区的烟叶病虫害损失率分别低于8%、10%，并合理控制绿色防控技术成本，实现烟草绿色防控的经济、社会和生态等综合效益最优。

三、具体要求

1．加强生态区统筹协调。八大生态区工作组要切实加强对生态区绿色防控重大专项的统筹，强化生态区内各主产省的协作，共同确定生态区重大专项年度目标任务，共同制定生态区重大专项具体推进措施，共同完善生态区绿色防控模式，确保本生态区绿色防控重大专项整体协同实施。

2．强化关键技术突破。重大专项技术首席专家要进一步突破“三虫三病”绿色防控关键技术瓶颈。各烟叶主产省（区、市）要因地制宜开展绿色防控关键技术研究和本地化研究，加快构建绿色防控技术体系，持续提升绿色防控技术的先进性、实用性和可操作性。

3．突出政策措施引导。各烟叶主产省（区、市）要相互借鉴先进经验和做法，制定出台具有引领性、针对性的政策措施，充分发挥政策措施的“指挥棒”作用，切实提高烟草绿色防控工作的积极性、主动性和创造性。

四、保障措施

1．组织保障。烟草绿色防控重大专项由国家局科技司牵头，中国烟叶公司协助。生态区工作组（名单见附件3）负责生态区内绿色防控重大专项的统筹协调，主产省执行组（名单见附件4）负责部署安排本省烟草绿色防控工作，确保技术推广落实落地。

2．技术保障。烟草绿色防控重大专项专家委员会（名单见附件5）和重大专项全国技术专家组（名单见附件6）负责为八大生态区及各烟叶主产区提供技术支持和技术服务。各生态区和烟叶产区要加强与专家委员会和技术专家组的沟通对接，及时解决实施过程中出现的共性关键技术问题。

3．经费保障。“三虫三病”绿色防控技术研究与推广经费，以各产区投入为主。鼓励和支持各产区加大绿色防控领域科技项目立项，并列入省级局（公司）、地（市）级公司科技项目计划。鼓励和支持重大专项技术首席专家依托单项靶标示范区，在各产区开展单项靶标绿色防控技术立项研究。鼓励和支持各产区加大绿色防控中非化学农药的烟叶产前投入，并逐步降低化学农药的烟叶产前投入。涉及重大基础及共性技术研究，可在总公司立项。涉及产前投入或固定资产投入的，按相关管理规定执行。各省级局（公司）、地（市）级公司要加强预算管理，规范列支，强化监督，确保资金使用规范合理。

4．监督检查。国家局将继续组织相关检查组赴各烟叶主产省（区、市）实地检查重大专项推进情况，结果以通报形式下达。各烟叶产区省级局（公司）要强化对重大专项年度实施工作的监督检查，及时反馈意见、通报检查结果和督促整改。

五、其他事项

1．请重大专项技术依托单位中国农业科学院烟草研究所，牵头制定2018年度烟草绿色防控重大专项技术方案。

2．请各生态区牵头省份抓紧制定本生态区绿色防控模式，各烟叶主产省工作组对照本方案，抓紧制定本省（区、市）2018年度烟草绿色防控重大专项实施方案，于2018年3月30日前报送国家局科技司（联系人：韩非，电话：010—63605920，电子邮件：hanfei@tobacco.gov.cn）。

3．2018年度全国绿色防控技术培训安排在贵州省遵义市，由贵州省烟草公司遵义市公司、中国农业科学院烟草研究所和烟草行业病虫害生物防治工程研究中心共同承担，贵州省烟草专卖局（公司）协助。
