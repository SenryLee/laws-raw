# 国家计委关于核定张家口发电厂二期工程上网电价的通知

（2000年9月13日　计价格[2000]1410号）

北京市、天津市、河北省计委、物价局，华北电力集团公司：

河北省物价局报来《关于张家口发电厂6号机组上网电价的请示》（冀价工字[2000]第41号）收悉。经研究，核定张家口发电厂二期工程6、7、8号机组上网电价为每千瓦时0.379元（含税），与京津唐电网销售电价调整一并执行。

特此通知。
