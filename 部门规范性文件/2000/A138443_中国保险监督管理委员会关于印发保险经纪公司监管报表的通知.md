## 中国保险监督管理委员会关于印发保险经纪公司监管报表的通知（保监发[2000]212号　2000年11月3日）

各保险经纪公司：

为掌握各保险经纪公司业务发展状况，加强对各保险经纪公司的监管，现印发《保险经纪公司监管报表》，并将有关事项通知如下：

**一、**《保险经纪公司监管报表》于2000年第4季度开始报送。

**二、**上报保监会的监管报表一律使用A4型纸，并依次编定页数，加具封面，装订成册。各保险经纪公司的报表封面上应注明：公司名称、地址、开业年份、报表所属时段、送出日期等，并由公司法人代表、部门经理签名或盖章。

**三、**报送方式为每季后15日内，先以传真及电子文件传输方式将报表报送保监会，后将报表软盘及正式报表以特快专递的方式报送保监会。报送保监会的正式报表一式两份。

**四、**其他有关监管报表的要求，比照《保险监管报表暂行管理办法》执行。

@2　五、监管报表报送地址：北京市阜成门内大街410号中国保监会财会部统计信息处；邮编：100034。传真电话：010—66018879。

## 报表文件命名规则

1．报表文件名长度为8位；

第一位为报表种类代码：M表示月报，S表示季报，H表示半年报，Y表示年报；

第二至五位为各保险经纪公司拼音缩写(见后表)；

第六位为年份：0表示2000年，1表示2001年，依此类推；

第七至八位为顺序号：月报为01—12，季报为01—04，半年报为01—02，年报为01。

```
┌───┬─────────────────┬────────┐

│ 序号 │　　公司名称　　　　　　│　　拼音缩写　　│

├───┼─────────────────┼────────┤

│　1　 │　　江泰保险经纪有限公司　　　　　│　　JTJJ　　　　│

├───┼─────────────────┼────────┤

│　2　 │　　长城保险经纪有限公司　　　　　│　　CCJJ　　　　│

├───┼─────────────────┼────────┤

│　3　 │　　上海东大保险经纪有限公司　　　│　　SHDD　　　　│

└───┴─────────────────┴────────┘
```

例：江泰保险经纪有限公司2000年12月份月报为：MJTJJ012；

江泰保险经纪有限公司2000年四季度季报表为：SJTJJ004；

江泰保险经纪有限公司2000年下半年报为：HJTJJ002；

江泰保险经纪有限公司2000年年报为：YJTJJ001。

2．每年1、2、4、5、7、8、10、11月报送月报一个模板文件；每年3、9月需报送月报和季报两个模板文件；每年6月需报送月报、季报和半年报三个模板文件；每年12月需报送月报、季报、半年报和年报四个模板文件。

## 附件四：　　　　　报表电子文件的形成及传输方法

**一、**本报表模板软盘的系统环境为Windows98下

Excel2000；

**二、**随文件下发的软盘中文件为单个监管报表模板文件，各公司每次报送报表时，首先新建一个Excel工作簿中“Sheetl、Sheet2、 Sheet3．．．．．．”内并填入数据，填入数据时请填在模板文件黄色区域相应栏目内，蓝色区域为禁止写入区域(已用密码加以保护)，紫色区域为报表说明区域，数据填写完毕后在保存文件时，应选择“保存类型”中“模板”即可形成一个模板文件

；

**三、**此模板文件一份保存在一张软盘中，随正式报表以特快专递方式寄送保监会，另一份以电子文件方式传输至保监会的计算机上

；

**四、**传输报表电子文件时，首先打开Windows下的超级终端，然后新建一个连接，输入电话号码(号码为010—66011871)后进行拨号连接，连接成功后点击“发送”，然后点击“浏览”选择电子文件后即可进行文件传输

；

**五、**各公司对软盘中的报表模板格式不得擅自进行修改。
