# 中华人民共和国海关公告－－对进口重质燃料油执行暂定税率

## 中华人民共和国海关公告（１９９６年１１月１０日）

根据国务院关税税则委员会决定，自１９９６年１１月１１日至１９９７年３月３１日对进口重质燃料油执行暂定税率如下：

```
品名　　　　　　　税则号列　　　　　　　　　暂定税率

重质燃料油　　　　２７１０．００４０　　　　３％
```

特此公告。

（注：此公告已由各地海关于１９９６年１１月１０日对外公布。）
