# 农业部办公厅厅关于做好2009年疯牛病监测工作的通知

## 农业部办公厅厅关于做好2009年疯牛病监测工作的通知（农办医[2009]11号）

为进一步做好我国牛海绵状脑病（疯牛病）监测工作，防堵疯牛病传入境内，保障牛肉产品安全，现就疯牛病监测工作有关事项通知如下：

**一、**各地要严格按照《牛海绵状脑病监测方案（第二版）》的有关规定和我国疯牛病监测任务目标，组织各级动物疫病预防控制机构采集病料。各地应根据本辖区内牛的饲养规模，兼顾采样数量和监测分数，重点采集4-7岁有神经症状临床疑似病牛、紧急屠宰牛、死牛的脑样品，确保完成年度的监测分数值。不同牛群对应的监测分数值及各地应完成的监测分数值和采样数量详见附件一。

**二、**采样过程中要认真填写采样单，对临床疑似病牛进行拍照或摄像，建立详细的采样档案。所有档案、图片和录像等材料连同采集到的样品一起送至国家牛海绵状脑病检测实验室。采样单见附件二.

**三、**各地可根据采样的具体情况，将收集好的样品先冷冻保存或甲醛固定保存，由专人负责管理和送样。至少每三个月送样一次。

**四、**各地于2009年9月30日前完成本年度采样监测工作。中国动物卫生与流行病学中心、中国农业大学于11月30日前将2009年疯牛病监测工作总结报我部兽医局。

各地要高度重视疯牛病监测工作，认真完成采样送样工作。同时，要积极配合中国动物卫生与流行病学中心、中国农业大学开展疯牛病的相关调查工作。

附件一：

样品采集要求

根据OIE对不同种类、年龄牛海绵状脑病（以下称BSE）高发牛群的监测要求，充分考虑我国牛群的地理、品种和年龄分布特征，我国BSE监测的样品采集要求如下。

**一、**临床症状划分

根据BSE流行病学特点，OIE将牛群按照感染BSE可能性的不同，分为四个亚群。

（一） 临床疑似牛

30月龄以上呈不明原因渐进性行为变化或神经症状的牛。有一些病牛可能只出现部分症状，其严重程度亦不一致，但这样的牛仍然要按照潜在的BSE感染牛进行检测和调查。这类牛根据不同的年龄段，可获得不同的监测分数（见表1）。

不明原因渐进性行为变化或神经症状主要表现如下：

行为表现：甩头；磨牙；过度舔舌；耳朵竖立；落伍；挤奶时持续踢踏；经常伸展脖子；像拉马车样低头站立；面对舍门或障碍物犹豫不前；不愿进挤奶室；走路时后肢过度摇摆或伸展。

神经症状：颤抖；兴奋；胆怯；恐惧；狂怒；意识异常；转圈运动；共济失调；瘫痪/局部麻痹；感觉过敏如听觉、触觉、视觉异常；没有外伤或感染而濒临死亡。

表1　不同年龄段的临床疑似牛监测分数值对应表

|  |  |
| --- | --- |
| 年龄段 | 监测分数值 |
| 1岁≦年龄＜ 2岁 | 0 |
| 2岁≦年龄＜ 4岁 | 260 |
| 4岁≦年龄＜ 7岁 | 750 ★ |
| 7岁≦年龄＜ 9岁 | 220 |
| 年龄≧ 9岁 | 45 |

注释：★表示重点采集对象。

（二） 紧急屠宰牛

30月龄以上不能走路，不愿行动，不能自主站立或走动的牛；30月龄以上紧急屠宰或宰前检疫要销毁的牛。这些牛可能出现A中的某些临床症状，但与BSE的症状还不一致。根据诊断出BSE的国家的经验，这类症状的牛群属于BSE发病较高的牛群。这类牛根据不同的年龄段，可获得不同的监测分数（见表2）。

（三） 死牛

30月龄以上死于养殖场、运输途中或屠宰场的牛。这些牛可能在死前出现A中所列的临床症状，但与BSE的症状不一致。根据诊断出BSE的国家的经验，这类牛群也属于发病较高的牛群。这类牛根据不同的年龄段，可获得不同的监测分数（见表3）。

注释：★表示重点采集对象。

（四） 正常屠宰牛

正常屠宰的36月龄以上的牛。

诊断出BSE的国家的经验表明，BSE在这种亚群的牛流行率最低。因此，此亚群是最不适于检测BSE的动物群体。但是，从这种亚群采样会有助于流行病学的调查和BSE控制措施的效力验证。对36月龄以下的正常屠宰牛进行检测几乎毫无意义。这类牛根据不同的年龄段，可获得不同的监测分数（见表4）。

**二、**年龄划分

根据BSE的流行病学特点和OIE法典规定，最具检测价值的年龄是4－7岁，其次为2－4岁和7－9岁，但是从科学的角度来看，各个年龄段的牛都应采集。

**三、**2009年应采集样品数量和应完成监测分数值

在全国范围内，根据各省、市、自治区养牛量不同确定每年采集样品数量。奶牛养殖量大的河北、内蒙古、黑龙江和新疆每年至少采集临床疑似牛（详见一、临床症状划分）50-80头份，其中80%以上为奶牛脑样品，另外需采集其他类型牛（详见一、临床症状划分）的脑样品，其中50%以上为奶牛脑样品；山东、陕西、北京、天津、山西、辽宁、吉林、江苏、河南、四川、云南、甘肃、青海、宁夏14个省、市、自治区每年至少采集临床疑似牛10-50头份，其中80%以上为奶牛脑样品，另外需采集其他类型牛的脑样品，其中50%以上为奶牛脑样品；湖北、广西、广东、上海、重庆、江西、浙江、贵州、福建、安徽、湖南、海南和西藏13个省、市、自治区每年至少采集临床疑似牛5-30头份，其中80%以上为奶牛脑样品，另外需采集其他类型牛的脑样品，其中50%以上为奶牛脑样品。

各地在保证完成上述采样任务的前提下，可根据本辖区内牛群的地区分布、养殖密度、品种和年龄结构将任务分解细化。
