# 科技部关于开展《国家中长期科学和技术发展规划纲要(2006－2020年)》执行情况检查评估工作的通知

## 科技部关于开展《国家中长期科学和技术发展规划纲要（2006－2020年）》执行情况检查评估工作的通知（国科发计〔2009〕425号）

各省、自治区、直辖市及计划单列市科技厅（委、局），新疆生产建设兵团科技局，国务院有关部门科技司（局），中科院、工程院、自然基金委、中国科协：

实施《国家中长期科学和技术发展规划纲要（2006－2020年）》（以下简称《规划纲要》），建设创新型国家，是坚持科学发展观、开创社会主义现代化建设新局面的重大战略举措，是全党全社会的共同事业。为全面贯彻《中共中央国务院关于实施科技规划纲要，增强自主创新能力的决定》（以下简称《决定》），推进《规划纲要》战略任务的落实，科学制定“十二五”科技规划，科技部将组织开展《规划纲要》在“十一五”期间执行情况的检查评估工作。现就有关事项通知如下：

**一、**评估意义

《规划纲要》是新时期指导我国科学和技术发展的纲领性文件。切实执行《规划纲要》，提高自主创新能力，是全面建设小康社会、构建社会主义和谐社会的有力支撑。加强对《规划纲要》执行情况的跟踪分析，适时开展检查评估，对于推进任务落实，提高实施水平，确保《规划纲要》的目标实现具有重要意义。

《规划纲要》的各项战略任务在“十一五”期间已经启动实施，“十二五”将进入攻坚阶段。本次检查评估工作，要深入落实党的十七大精神，紧紧围绕创新型国家建设的目标要求，对《规划纲要》在“十一五”期间的执行情况进行全面客观的检查评估，把握进展，总结经验，形成关于自主创新战略实施情况的基本判断；查找问题，提出建议，为“十二五”科技规划的制定提供有效支撑和服务，进一步推动《规划纲要》在全社会的贯彻实施。

**二、**评估重点

本次检查评估以《规划纲要》的任务部署为主线，以“十一五”期间全国科技工作为对象，重点内容包括：

（一）《规划纲要》颁布实施产生的积极影响和战略意义，包括科技创新环境的整体优化，本地方、本部门重大科技发展战略与总体思路的形成与提出等。

（二）自主创新战略实施的总体判断，包括战略目标的实现程度，关键指标进展，本地方、本部门在创新型国家建设中已经取得的成效等。

（三）“十一五”期间任务部署的分析评价。重点是国家科技重大专项的启动实施情况，科技计划布局调整，专项科技行动的推进，本地方、本部门重大科技工程、重大计划、重点项目的出台和执行情况，以及为贯彻落实《规划纲要》采取的其他重大举措等。

（四）科技工作在调整产业结构、转变增长方式、改善民生中发挥的支撑和引领作用，特别是在应对金融危机、培育战略性产业和新兴产业等方面做出的贡献。

（五）技术创新体系建设的突破性进展，特别是企业主体地位的确立、创新创业服务体系建设、产学研结合的模式和机制、科技与经济结合的新途径等方面。

（六）科技创新能力建设情况，特别是在科技投入、人才队伍、基地建设、资源共享等方面的机制创新和重大进展。

（七）激励自主创新的政策体系建立情况，特别是《规划纲要》配套政策的落实，经济政策和科技政策的协调互动，在财税、金融、政府采购等方面的政策创新等。

（八）《规划纲要》执行过程中存在的突出问题。

**三、**组织方式

本次检查评估工作由科技部牵头组织，各地方、各部门共同参与，委托相关专业评估机构研究分析，广泛听取有关专家意见。

（一）各有关部门按照《决定》和《规划纲要》的要求，结合主管业务，围绕评估重点，对各自负责领域的科技工作进行自查评估，提交自查评估报告。

（二）各地方结合当地搣中长期科技规划攠和搣十一五攠科技规划，围绕评估重点，对地方贯彻落实《规划纲要》的有关情况进行自查评估，评估报告报送科技部，抄送省级人民政府。

（三）科技部委托专业评估机构按照评估要求，通过收集公开信息、问卷调查、专家访谈等方式，并参考自查评估报告，开展若干专题评估。

（四）科技部在自查评估报告和专题评估报告的基础上，开展重点地区和部门的抽样调研，起草《规划纲要》执行情况总体评估报告，上报国务院。

**四、**自查评估的工作要求

自查评估是开展《规划纲要》总体评估的基础和依据，对于准确把握创新型国家建设进程具有重要意义。各地方、各部门要把自查评估工作摆上重要议事日程，落实责任，扎实推进。有关要求如下：

（一）精心组织，密切配合。科技部门要充分发挥在《规划纲要》自查评估工作中的牵头作用，并积极配合做好专题评估及抽样调研；动员协调相关部门，按照要求开展自查评估；成立工作班子，制订具体方案，确保评估工作有序进行。阶段性成果和结论要及时向地方政府、部门领导汇报。

（二）客观公正，深入研究。要认真汇总本地方、本部门搣十一五攠科技发展主要指标（截至2009年6月底）和任务推进情况，总结规划实施对经济社会发展的推动作用。对照《规划纲要》的任务目标要求，从当前的时间节点出发，通过数据对比分析，判断任务目标的实现程度并分析原因。同时对2015年任务目标进行预测，提出未来科技工作的建议。评估结论要观点清晰，有典型案例和可靠数据支撑。

（三）明确重点，科学评估。要在对《决定》和《规划纲要》进行再学习、再领会的基础上，明确本地方、本部门科技工作与《规划纲要》任务部署的对应关系，确定评估方向与重点。扎实开展调研工作，注重听取科学家和技术专家，特别是本地方、本部门曾经参加过《规划纲要》战略研究和编制工作专家的意见。要在调查研究和综合分析的基础上，对“十一五”期间《规划纲要》执行情况提出客观、公正的评估意见。鼓励各单位结合实际工作开展重点评估，突出反映重大举措和成绩，研究重大问题。

（四）把握节点，及时报送。各单位要按照要求，抓紧组织力量开展工作，于9月30日前完成自查评估，将自查评估报告（8000字左右）、信息采集表格及相关附件报我部（包括书面材料和电子版）。同时确定一位同志负责联系此项工作，姓名及通讯方式请于8月7日前报送科技部计划司。

自查评估报告撰写提纲

**一、**“十一五”期间贯彻执行《规划纲要》的总体情况

1. 《规划纲要》颁布实施对本地方、本部门产生的积极影响。

2. 根据“自主创新、重点跨越、支撑发展、引领未来”的方针，本地方、本部门“十一五”期间确立的科技工作思路、发展战略。包括本地方、本部门为贯彻落实《规划纲要》出台的规划、意见、决定等重要文件（附文件原文、条目汇总表）。

3. 本地方、本部门“十一五”目标的实现程度以及未来预期。

4. 对本地方、本部门贯彻执行《规划纲要》的情况做出基本判断。

**二、**科技任务的部署实施情况

1. 基本情况。对应《规划纲要》中重点领域、重大专项、前沿技术、基础研究等部分的任务部署，各部门重点围绕相关国家科技重大专项、部门科技计划、专项科技行动等，梳理领域的科技任务部署情况；各地方重点围绕本地出台的重大工程、重大项目，地方科技计划等，梳理本地区的科技任务部署情况。

2. 进展和成效。突出任务部署提高科技自身发展能力、提高自主创新能力方面取得的积极效果，在调整产业结构、转变增长方式、改善民生中发挥的支撑和引领作用，在应对金融危机、培育战略性产业和新兴产业等方面做出的贡献等。

3. 存在问题分析。重点关注任务部署的领域布局是否恰当，是否存在重点领域支持不足、任务难以落实或进展缓慢等问题，并分析原因。

4. 对策建议。提出需要加强的领域，以及任务推进的对策等。

**三、**科技体制改革与国家创新体系建设情况

1. 体制改革基本情况。包括现代科研院所制度建立、科技管理体制改革的情况等。

2. 国家创新体系建设基本情况。包括技术创新体系、知识创新体系、区域创新体系等的建设情况等，突出企业主体地位的确立、创新创业服务体系建设、产学研结合的模式和机制、科技与经济结合的新途径等。

3. 成效和经验。

4. 存在问题分析。

5. 对策建议。

**四、**重要政策与措施的落实情况

1. 落实《规划纲要》配套政策及其实施细则的基本情况。

2. 地方、部门激励自主创新政策出台实施情况（附文件原文、条目汇总表）。

3. 《规划纲要》重要措施的落实情况。重点反映科学普及、国际合作、创新文化建设等方面。

4. 成效和经验。

5. 存在问题分析。

6. 对策建议。

**五、**科技投入与科技基础条件平台情况

1. 科技投入情况。包括建立多元化多渠道的科技投入体系、调整和优化投入结构，提高科技经费使用效益、政府科技投入对全社会科技投入的引导作用等内容。要求提供2005年以来科技投入总量和强度变化、经费来源结构、执行部门和领域结构、投入方式等的相关数据，可附数据表格。

2. 科技平台建设情况。本地方、本部门（重点）实验室、重大基础科学设施、工程技术研究中心、基础条件平台、技术转移或成果转化服务平台等科技创新基地建设情况。在推进科技资源共享方面取得的突出进展和成绩。

3. 成效和经验。

4. 存在问题分析。

5. 对策建议。

**六、**人才队伍建设情况

1. 基本情况。包括培养造就具有世界前沿水平的高级专家、创新人才培养、企业培养和吸引科技人才、吸引留学和海外高层次人才等方面。

2. 成效和经验。

3. 存在问题分析。

4. 对策建议。

**七、**总结和建议

1. 《规划纲要》执行的重要经验总结。

2．遇到的典型问题及原因分析。

3. “十二五”期间落实《规划纲要》的建议。

4. 对规划研究、制定和实施的建议和意见。

**八、**相关附件

1．需要重点说明的问题（重点评估材料）。

2．地方、部门“十一五”科技规划和中长期科技规划。

3．2005-2008年度科技工作总结。

4．近期向省人大、政协汇报的有关材料。

5．其他重要文件及数据。
