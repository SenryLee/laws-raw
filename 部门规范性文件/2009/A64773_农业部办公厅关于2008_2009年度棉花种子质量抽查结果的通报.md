# 农业部办公厅关于2008/2009年度棉花种子质量抽查结果的通报

## 农业部办公厅关于2008/2009年度棉花种子质量抽查结果的通报（农办农[2009]36号）

各产棉省（自治区）农业（农林、农垦）厅（委、局）、新疆生产建设兵团农业局：

为进一步规范棉种生产管理，提高棉种质量，我部组织对2008/2009年度部分棉种生产与经销单位的棉种进行了抽查。现将有关情况通报如下：

本次抽查范围为河北、山东、河南、江苏、湖北、安徽、湖南、新疆等8个主产棉省（区）的35家棉种生产与经销单位，共抽取了35份样品。抽查的品种都是目前主产棉区的当家品种或主推品种，代表种子数量59.8万公斤，涉及种子库存量538.0万公斤。检测方法与结果判定采用GB/T 3543.1～3543.7-1995《农作物种子检验规程》、GB 4407.1-2008《经济作物种子 第1部分：纤维类》中的规定。

对抽查的35份样品进行了纯度、净度、发芽率和水分4个必检项目的全项检验，所抽样品综合判定均为合格，总体抽样合格率为100%，4个单项合格率均为100%，比2007/2008年度上升了5.9个百分点。

--纯度。总平均值98.6%，最低93.9%，最高为100 %。

--净度。总平均值99.8%，其中包衣子和光子样品的净度平均值为100%；毛子样品的净度平均值为99.4%。

--发芽率。总平均值82%，其中包衣子样品的发芽率平均值86%，最低为76%；光子样品的发芽率平均值82%，最低为78%；毛子样品的发芽率平均值为77%，最低为63%。

--水分。总平均值9.8%，最高为11.6%。

--带菌情况。在15份毛子样品中，检测出黄萎病菌的样品有9份，占60.0%，检测出枯萎病菌的样品有8份，占53.3%。黄萎病菌样品带菌率比去年上升了35.0个百分点， 枯萎病菌样品带菌率比去年上升了3.3个百分点。

下一步，各级农业行政主管部门要加强棉种检验检疫，防止枯、黄萎病蔓延，切实抓好棉种质量监督和市场管理，维护生产者和消费者利益，促进棉花生产稳定发展。
