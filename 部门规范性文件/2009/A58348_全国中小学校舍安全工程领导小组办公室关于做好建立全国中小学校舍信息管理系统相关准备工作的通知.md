# 全国中小学校舍安全工程领导小组办公室关于做好建立全国中小学校舍信息管理系统相关准备工作的通知

## 全国中小学校舍安全工程领导小组办公室关于做好建立全国中小学校舍信息管理系统相关准备工作的通知（全国校安办函〔2009〕54号）

各省、自治区、直辖市，新疆生产建设兵团中小学校舍安全工程领导小组办公室：

根据工作计划，全国中小学校舍信息管理系统（以下简称系统）网络版将于2010年1月1日正式投入使用。系统拟首先物理部署到中央和省两级。为便于各地做好准备工作，我办组织专家制订了《全国中小学校舍信息管理系统（一期）技术保障方案》（附件），现予以印发，并提出如下要求：

**一、**进一步认识建立系统的重大意义，高度重视此项工作。建立系统是国务院的明确要求，是实施全国中小学校舍安全工程的现实需要和重要内容，是提高校舍管理水平的有效手段，是推进教育信息化建设的具体措施。对于全面掌握全国中小学校舍信息，保证校舍安全工程的顺利实施，提升教育管理水平，促进教育事业科学发展，都具有十分重要的意义。

**二、**切实落实人员、场地和经费，建立保障系统运行和维护的长效机制。各省级系统的运行维护、技术支持和数据中心建设应依托各省教育信息中心（无教育信息中心的依托教育信息化相关部门），充分整合利用现有资源，配备足够的专业技术人员。各地应尽快落实系统建设和运行维护所需经费，加强经费管理，提高经费使用效益。设备的采购程序应符合国家的有关规定。系统的建设和维护是一项长期工作，各地要建立保障系统正常运行的工作机制和各项管理制度，不断提高保障水平。

**三、**按时间要求做好各项准备工作。各地应在2009年10月15日之前，完成制订各省系统技术保障方案，明确技术支持负责单位、人员配备、场地面积、省级数据中心网络环境、软硬件配备和经费落实情况等，并报全国校安办备案；应在2009年12月15日之前，将各省系统技术保障方案中的各项内容配备到位。

**1.概述党中央、**国务院高度重视学校校舍安全工作。汶川地震后，胡锦涛总书记、温家宝总理多次做出重要指示，要求把学校校舍建成最牢固、最安全、最让人民群众放心的建筑。国务院于2009年启动了全国中小学校舍安全工程（以下简称“校安工程”），对全国城市和农村、公立和民办、教育系统和非教育系统所有中小学，都要进行逐栋排查、鉴定、规划，对存在安全隐患的校舍进行加固改造或拆除重建，达到抗震设防标准，提高综合防灾能力。按照国务院要求，为配合“校安工程”的实施，拟建立“全国中小学校舍信息管理系统”（以下简称“校舍系统”），逐步建立起覆盖全国中小学校基于单体建筑物的校舍信息电子档案数据库，并在此基础上开发和完善中央、省、地市、县和学校各级“校舍系统”，以全面掌握中小学校舍安全信息，及时了解工程进展情况，实现安全监控与预警、投资监管和统筹管理，为“校安工程”和校舍安全管理提供服务，满足各级政府和部门工作需要，为未来中小学信息化建设提供支撑，提高政府的科学管理水平和教育现代化水平。

《全国中小学校舍信息管理系统技术保障方案》是为保证“校舍系统”在全国按期顺利部署和运行而制定的。方案主要内容包括系统使用单位的人员配备、场地和省级数据中心网络及软硬件建设等要求。

**2.人员配备**　各级教育行政部门依托教育信息中心（无教育信息中心的依托教育信息化相关部门）建立“校舍系统”技术支持中心，配备一定数量的系统运维服务和技术支持人员，以保障“校舍系统”安全稳定可靠地运行，并为下级单位和学校提供技术指导和支持服务。系统运维人员应承担设备运行管理、应用系统运行管理、数据管理和安全管理等工作；技术支持人员承担用户服务与支持工作。

“校舍系统”人员基本配备建议如下：

|  |  |
| --- | --- |
|  | 建议配备人员数 |
| 省级 | 12-20人（专职） |
| 地市级 | 4-6人（专职） |
| 区县级 | 2-4人（专职） |
| 学校级 | 1人 |

**3.场地**　3.1 机房要求

各级教育行政部门应为“校舍系统”提供一定规模和条件的机房保障。

省级数据中心机房要求具备防尘防静电、不间断电源、空调系统、电视监控、消防系统、安全系统（门禁）等功能，具有主设备区、电源空调区和操作控制区等区间，并具备一定的消防、防盗、防雷和安全监控等能力，按照国家标准及行业标准设计和施工。机房面积应保证80-120平方米以上。

3.2 办公场地

根据“校舍系统”各级单位的人员配备规模和工作需要，各级教育行政部门和相关学校应为相关人员提供必要的办公条件和场所。

**4.省级数据中心**　4.1 网络系统

“校舍系统”省级数据中心网络应具有高可靠性和高安全性。应运用网络负载均衡、服务器集群等技术提高可靠性，通过防火墙、VPN设备、入侵检测和信息安全审计等提高网络安全性。

4.2 网络通讯

省级数据中心的网络通讯接入中国教育科研网（Cernet）的带宽应大于20Mbps，本省所辖下级教育单位有接入非中国教育科研网的应建立相应线路，保障相关单位能够顺畅连接使用“校舍系统”。

4.3 服务器系统

服务器系统是数据中心的主要信息处理设施，提供了数据中心的计算资源。

1．服务器选型。服务器系统选型应遵循技术先进性、高可用性、易维护性、灵活的扩展性、良好的开放性原则；

2．服务器系统应按照“校舍系统”应用规模和计算资源的需求，配置服务器数量，并支持系统基础服务和中间件、报表、图片引擎、地图、遥感影像等应用服务；

3．采用服务器虚拟化技术，可在一台物理服务器上同时运行多个虚拟服务器，提高服务器硬件使用率。

4.4 数据存储

“校舍系统”的省级数据中心应配备专门的存储系统。有效改善存储资源使用效率，并能够扩展满足未来业务不断发展所带来的数据存储需求。

存储容量应达到10TB-40TB，可扩展到100TB以上。

4.5 软件支撑平台

1.操作系统。服务器操作系统配置主流的64位Linux/Unix和Windows。

2．数据库系统。配置 “校舍系统”支持的主流大型企业级高性能关系型数据库，并与中央级“校舍系统”保持兼容。

3．其他支撑系统。根据“校舍系统”对支撑环境的要求，省级数据中心应配备相应支撑系统。

4.6 网络信息安全

省级数据中心需通过安全管理制度、安全设备及相关技术，保证数据存储、操作、传输的安全。

4.7 数据备份与恢复

省级数据中心需配备数据备份和恢复系统，保证数据可靠性。

4．网络及安全设备

省级数据中心应根据“校舍系统”应用需求配备FC交换机、负载均衡设备、网络交换机、出口智能路由设备、VPN、防火墙、入侵检测和安全审计等设备，保证网络吞吐量、访问性能和安全。
