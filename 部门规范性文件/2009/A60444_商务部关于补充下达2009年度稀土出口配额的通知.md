# 商务部关于补充下达2009年度稀土出口配额的通知

根据商务部2009年第55号公告，现补充下达2009年稀土一般贸易出口配额：

|  |  |  |
| --- | --- | --- |
| 序号 | 公司名称 | 配额数量（吨） |
|
| 1 | 烟台鹏宇科工贸有限公司 | 981 |
| 2 | 赣县红金稀土有限公司 | 482 |
| 3 | 徐州金石彭源稀土材料厂 | 527 |

请各有关地方商务主管部门通知本地企业，同时密切跟踪企业出口情况，相关问题及时报商务部（外贸司）。
