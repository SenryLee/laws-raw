# 国家外国专家局国外人才信息研究中心关于举办2010外籍人才招聘会(上海)的通知

## 国家外国专家局国外人才信息研究中心关于举办2010外籍人才招聘会（上海）的通知

各有关单位：

经国家外国专家局批准，由国家外国专家局国外人才信息研究中心和上海国际人才交流协会主办的2010上海外籍人才招聘会将于2010年4月3日在上海宏安瑞士酒店苏黎世厅举办，为期一天。

外籍人才招聘会自2005年第一届举办以来，已经成功举办了九届，历届招聘会介绍及有关信息请登录招聘会专门网站www.safea.gov.cn/jobfair/查询。这种招聘形式已经得到用人单位和外籍人才的认可，越来越多的用人单位希望通过招聘会储备和选拔优秀的外籍人才，并借此提高招聘效率。

招聘会具体事项如下：

**一、** 时间：2010年4月3日（星期六）9：00-16：

00

**二、** 地点：上海宏安瑞士酒店苏黎世厅上海市静安区愚园路1号

**三、** 服务内容及收费标准：

标准展位A：2m（长）×2m（宽）×2.2m（高），价格：3000元/个

标准展位B：2m（长）×2m（宽）×2.2m（高），价格：4000元/个

标准展位C：4m（长）×2m（宽）×2.2m（高），价格：5000元/个

优惠：

2010年2月26日前报名并交费，每个展位优惠500元；2010年3月12日前报名并交费，每个展位优惠300元；凡参加过历届上海外籍人才招聘会的参展单位一律优惠500元，但不享受前两项优惠活动。

2. 会场提供免费的茶水，每家参展单位2份免费午餐

3. 用人单位形象宣传

通过投影设备在招聘会现场对用人单位进行形象宣传（限于影音资料）。价格：500元/120分钟。

4. 媒体宣传

招聘职位将在中国国际人才网（ChinaJob.com）免费发布30天（根据参展单位要求，可以在招聘会召开之前或之后）。

5. 会刊资料

会刊在招聘会当天发放给所有参会的外籍人士和用人单位。内容包括招聘会相关介绍，参会单位招聘信息等；并提供会刊广告服务，为参会单位提供专门版面做形象宣传，收费标准为：1/4 版面 1000元人民币；1/2版面2000元人民币；整版面3000元人民币。

所有参会单位的英文名称及展位号将免费发布在会刊上。

6. 后续服务

以优惠价格提供外籍人才招聘、培训等服务内容。
