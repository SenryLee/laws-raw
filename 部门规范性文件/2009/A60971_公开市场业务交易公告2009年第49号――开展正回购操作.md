# 公开市场业务交易公告2009年第49号――开展正回购操作

## 公开市场业务交易公告（2009年第49号）

人民银行于本周二（7月7日）以利率招标方式开展了正回购操作。具体情况如下：

正回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 28天 | 900亿元 | 1.00% |
| 91天 | 800亿元 | 1.05% |
