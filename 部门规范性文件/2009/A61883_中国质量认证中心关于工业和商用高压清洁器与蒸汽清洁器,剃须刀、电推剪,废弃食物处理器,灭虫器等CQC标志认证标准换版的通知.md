# 中国质量认证中心关于工业和商用高压清洁器与蒸汽清洁器,剃须刀、电推剪,废弃食物处理器,灭虫器等CQC标志认证标准换版的通知

## 中国质量认证中心关于工业和商用高压清洁器与蒸汽清洁器，剃须刀、电推剪，废弃食物处理器，灭虫器等CQC标志认证标准换版的通知

各相关企业：

CQC标志认证工业和商用高压清洁器与蒸汽清洁器、剃须刀和电推剪、废弃食物处理器和灭虫器等四类产品所对应的新版国家标准已颁布，新旧标准对应关系如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 产品名称 | 原标准 | 新标准 | 新版标准实施日期 |
| 工业和商用高压清洁器与蒸汽清洁器 | GB 4706.1-1998IEC 60335-2-79：1995 | GB 4706.1-1998GB 4706.89-2008 | 2009年7月1日 |
| 剃须刀、电推剪及类似器具 | GB 4706.1-1998GB 4706.9-2003 | GB 4706.1-2005GB 4706.9-2008 | 2009年7月1日 |
| 废弃食物处理器 | GB 4706.1-1998GB 4706.49-2000 | GB 4706.1-2005GB 4706.49-2008 | 2009年9月1日 |
| 灭虫器 | GB 4706.1-2005GB 4706.76-2004 | GB 4706.1-2005GB 4706.76-2008 | 2009年9月1日 |

现将以上四类产品执行新版标准要求通知如下：

**一、**　自公告之日起至新版标准实施日期，企业可自愿选择按新版标准或旧版标准申请认证；新版标准实施日期后，应采用新版标准实施认证。

**二、**　对于工业和商用高压清洁器与蒸汽清洁器和灭虫器两类产品，由于新旧标准差异较小，无需送样检测，旧版证书持有人提交标准换版变更申请后，可直接换发新版认证证书。

**三、**　对于剃须刀、电推剪及类似器具和废弃食物处理器两类产品，旧版证书持有人提交标准换版变更申请后，需进行全项检测，检测合格后，换发新版认证证书。

**四、**　旧版标准证书持有人应于新版标准实施后、下一次跟踪检查之前，向CQC提交标准换版的变更申请（点击“填写认证申请书”后，选择“填写CQC自愿性产品认证变更申请书”按钮，提交变更申请）。工业和商用高压清洁器与蒸汽清洁器和剃须刀、电推剪及类似器具两类产品标准换版工作截止到2010年6月30日。废弃食物处理器和灭虫器两类产品标准换版工作截止到2010年8月31日。

**五、**　逾期未完成标准换版的认证证书，CQC将予以暂停。暂停期满仍未完成换版的将予以撤销。
