# 农业部办公厅关于印发《农机安全技术检验员培训大纲》、《农机事故处理员培训大纲》、《拖拉机联合收割机驾驶考试员培训大纲》的通知

## 农业部办公厅关于印发《农机安全技术检验员培训大纲》《农机事故处理员培训大纲》《拖拉机联合收割机驾驶考试员培训大纲》的通知（农办机［2009］32号）

各省、自治区、直辖市农机管理局（办公室）：

为了加强农机安全监理工作，规范农机安全技术检验员、农机事故处理员和拖拉机联合收割机驾驶考试员的培训考核工作，根据《农机安全监理人员管理规范》，我部制定了《农机安全技术检验员培训大纲》、《农机事故处理员培训大纲》、《拖拉机联合收割机驾驶考试员培训大纲》，现予印发，请遵照执行。

附件：1.农机安全技术检验员培训大纲

2.农机事故处理员培训大纲

3.拖拉机联合收割机驾驶考试员培训大纲

农业部办公厅　

二○○九年八月三日

附件1：

农机安全技术检验员培训大纲

本大纲根据《农机安全监理人员管理规范》制定，适用于农机安全技术检验员的培训、考核。

**一、**培训目标

通过培训，学员熟知相关规定以及安全技术检验员的职位要求，掌握农机安全技术检验项目和方法，具备正确使用农机安全检验设备能力，能够履行农机安全技术检验员职责。

**二、**培训对象

符合申请农机安全技术检验员资格的农机安全监理人员。

**三、**培训内容

（一）相关法律法规及标准

（二）安全技术检验员职位要求

（三）拖拉机联合收割机安全技术检验

（四）农机安全技术检验设备使用与维护

（五）其他危及人身财产安全的农业机械安全检验

（六）实践操作

**四、**培训方法

采取集中培训的方式，理论讲授和实践操作相结合。

**五、**培训时间

理论培训15小时，实践操作11小时，考核4小时。时间分配如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 项　　目 | 培 训 内 容 | 培训时间 　　（小时） | |
| 理论培训 | 相关法律法规及标准 | 2 | 15 |
| 安全技术检验员职位要求 | 0.5 |
| 拖拉机联合收割机安全技术检验 | 8 |
| 农机安全技术检验设备使用与维护 | 2 |
| 其他危及人身财产安全的农业机械安全检验 | 2.5 |
| 实践培训 | 拖拉机联合收割机唯一性认定 | 0.5 | 11 |
| 拖拉机联合收割机外观检查 | 0.5 |
| 拖拉机联合收割机运转检验 | 2 |
| 拖拉机制动性能台试检验 | 3 |
| 拖拉机联合收割机制动性能路试检验 | 3 |
| 拖拉机联合收割机前照灯性能、烟度、喇叭声级和转向盘的转向力、转向角的检验 | 2 |
| 考　　核 | 理论考试 | 2 | 4 |
| 实践考核 | 2 |
| 合　　计 |  | | 30 |

**六、**培训组织和考核

省级农机安全监理机构组织培训、考核，考核项目包括理论考试和实践考核两个部分。考核内容根据培训大纲和全国统一的培训教材确定，理论考试试题从题库中抽取，实行闭卷考试。理论考试和实践考核成绩评判实行百分制， 80分以上为合格。

附件2：

农机事故处理员培训大纲

本大纲根据《农机安全监理人员管理规范》制定，适用于农机事故处理员的培训、考核。

**一、**培训目标

通过培训，学员熟悉相关规定以及事故处理员的职位要求，掌握农机事故处理程序、方法和事故的统计、报告，具备正确使用农机事故勘查设备的能力，能够履行农机事故处理员职责。

**二、**培训对象

符合申请农机事故处理员资格的农机安全监理人员。

**三、**课程设置

（一）相关法律法规及规定

（二）农机事故处理员职位要求

（三）农机事故处理程序

（五）农机事故处理文书

（六）农机事故勘查装备

（七）农机事故应急处置

（八）农机事故典型案例分析

（九）农机事故现场勘查模拟实践

**四、**培训方法

采取集中培训的方式，理论讲授和实践操作相结合。

**五、**培训时间

理论培训22小时，实践操作4小时，考核4小时。时间分配如下：

**六、**培训组织和考核

省级农机安全监理机构组织培训、考核，考核项目包括理论考试和实践考核两个部分。考核内容根据培训大纲和全国统一的培训教材确定，理论考试试题从题库中抽取，实行闭卷考试。理论考试和实践考核成绩评判实行百分制， 80分以上为合格。

附件3：

拖拉机联合收割机驾驶考试员培训大纲

本大纲根据《农机安全监理人员管理规范》制定，适用于拖拉机联合收割机驾驶考试员的培训、考核。

通过培训，学员熟悉相关规定以及考试员的职位要求，掌握拖拉机、联合收割机驾驶人考试的程序、要求和评判标准，具备驾驶人考试工作的组织能力，能够履行拖拉机联合收割机驾驶考试员职责。

**三、**培训内容

（一）相关法律法规及规定

（二）考试员职位要求

（三）驾驶人考试规定

（四）考试工作的组织实施
