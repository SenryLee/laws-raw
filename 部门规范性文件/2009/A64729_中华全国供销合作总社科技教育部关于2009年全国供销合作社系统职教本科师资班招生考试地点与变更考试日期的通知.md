# 中华全国供销合作总社科技教育部关于2009年全国供销合作社系统职教本科师资班招生考试地点与变更考试日期的通知

## 中华全国供销合作总社科技教育部关于2009年全国供销合作社系统职教本科师资班招生考试地点与变更考试日期的通知（供销科教字[2009]5号）

各省、自治区、直辖市供销合作社教育主管部门，山西财经大学、安徽财经大学、山西大学商务学院：

根据全国供销合作总社科技教育部和教育部高校学生司联合印发的《关于做好2009年全国供销合作社系统中等职业学校职教本科师资班招生工作的通知》（供销科教字[2009]1号）的精神，2009年供销合作社系统职教本科师资班招生考试在江西省南昌市举行，考试日期变更为2009年5月9日至12日（8日报到）。现将具体事宜通知如下：

**一、**考试时间：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 时　间 | 5月9日 | 5月10日 | 5月11日 | 5月12日 |
| 上午9：00---11：00 | 考前预备会 | 数学 | 面试 | 面试 |
| 下午 3：00---5：00 | 语文 | 外语 | 面试 |  |

**二、**考试报到（领准考证）时间、地点：2009年5月8日下午3点至6点在南昌市洪都宾馆大堂（南昌市阳明路249号）。

**三、**考生注意事项：

1、考生报到时领取《准考证》，同时交纳300元报名考试费。

2、考生必须携带《身份证》、《学生证》和《准考证》提前十五分钟进入考场。

3、考生食宿安排在南昌市洪都宾馆及周边其他宾馆，考生凭本《通知》复印件或下载件到宾馆自行登记入住享受优惠价格（洪都宾馆：160-200元/标准间；东湖宾馆：100元左右/标准间；滨江宾馆220元/标准间），费用自理。
