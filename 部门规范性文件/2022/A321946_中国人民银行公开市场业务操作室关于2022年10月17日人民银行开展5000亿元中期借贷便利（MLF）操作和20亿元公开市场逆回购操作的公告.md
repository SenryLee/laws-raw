# 中国人民银行公开市场业务操作室关于2022年10月17日人民银行开展5000亿元中期借贷便利（MLF）操作和20亿元公开市场逆回购操作的公告

## 公开市场业务交易公告

〔2022〕第201号

为维护银行体系流动性合理充裕，2022年10月17日人民银行开展5000亿元中期借贷便利（MLF）操作和20亿元公开市场逆回购操作，充分满足了金融机构需求。具体情况如下：

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 5000亿元 | 2.75% |

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 20亿元 | 2.00% |

中国人民银行公开市场业务操作室

二〇二二年十月十七日
