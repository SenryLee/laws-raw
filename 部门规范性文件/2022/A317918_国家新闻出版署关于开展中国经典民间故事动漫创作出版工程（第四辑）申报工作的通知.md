# 国家新闻出版署关于开展中国经典民间故事动漫创作出版工程（第四辑）申报工作的通知

国新出发电〔2022〕17号

各省、自治区、直辖市和新疆生产建设兵团新闻出版局，中央和国家机关有关部委、有关人民团体出版单位主管部门，中央各重点出版集团：

为贯彻落实中央办公厅、国务院办公厅印发的《关于实施中华优秀传统文化传承发展工程的意见》，国家新闻出版署组织实施中国经典民间故事动漫创作出版工程，目前已推动出版三辑148种动漫图书。为加快推出更多动漫出版精品，现就申报中国经典民间故事动漫创作出版工程（第四辑）有关工作通知如下。

一、总体要求

深入学习贯彻习近平新时代中国特色社会主义思想，从中华文化资源宝库中汲取营养，从中国经典民间故事中挖掘题材，坚定文化自信，坚守中华文化立场，传承中华文化基因，生动表现、深刻阐发中华优秀传统文化价值内涵。坚持以人民为中心的出版和创作导向，不忘本来、吸收外来、面向未来，对中华优秀传统文化进行创造性转化和创新性发展，赋予中国经典民间故事当代特色和时代光彩，增强中华优秀传统文化的生命力和影响力。弘扬社会主义核心价值观，把社会效益放在首位，讲品位、讲格调、讲责任，做到思想精深、艺术精湛、制作精良相统一。

二、申报方向

1. 以生动民间故事展现中华人文精神。汲取中华优秀传统文化的思想精华，树立正确的历史观、民族观、国家观和文化观，以中国经典民间故事为蓝本，生动讲述中华民族在数千年文明进程中培育和形成的思想观念、人文精神和道德规范，弘扬中华文化精神。

2. 以经典动漫形象表现中华文化魅力。围绕中国经典民间故事进行创作加工，刻画具有中华文化基因、富有大众亲和力的动漫形象，使经典民间故事“动”起来，让优秀传统文化“活”起来。通过可触可感、喜闻乐见的动漫形象积极展现中华历史文化深厚积淀，阐释中国人的情感追求和审美趣味，表现博大精深的中国智慧、中国精神、中国力量，展示丰富多彩、生动立体的中国形象。

3. 以创新艺术手法体现当代文化活力。坚持古为今用，推陈出新，把中华优秀传统文化的有益思想、艺术价值与时代特点和要求相结合，在题材体裁上追求创新，在观念风格上突出特色。挖掘中国经典民间故事的时代价值，积极进行当代表达，赋予其新的精神内涵和世界意义，使中华民族最基本的文化基因与当代文化相适应、与现代社会相协调，展现既继承传统优秀文化又弘扬时代精神、既立足本国又面向世界的当代中国文化创新成果。

三、申报要求

1. 申报单位应具有良好的出版业绩和社会信誉，具备完成中国经典民间故事动漫创作出版工程项目的条件和能力，近3年来没有违规处罚记录。

2. 申报项目应符合申报方向，每个项目以1个故事蓝本为基础进行创作和出版，主线清晰，故事完整，主创人员明确，著作权完整、版权清晰。

3. 申报项目出版形式可为漫画、连环画、绘本等，正式出版或计划出版项目均可申报。其中，已出版项目应为2020年7月至2022年6月期间出版的产品；计划出版项目应已签订出版合同，具备80%的完成度，并确保在2022年12月前如期出版。

4. 每个单位最多申报10种项目。其中，系列成套出版的，一套计1种。

四、申报材料

1. 填写完整并加盖公章的《中国经典民间故事动漫创作出版工程（第四辑）项目申请书》（在国家新闻出版署网站下载）2份，电子版发送至yxdzchu@126.com。

2. 申报单位营业执照、出版许可证复印件，申报主体及单位主要负责人近3年来无违反新闻出版法规的声明各1份。

3. 申报单位主要负责人和主要创作人员身份证复印件、原创作品承诺书及有关版权证明材料各1份。

4. 申报项目样书（样张）2套。其中，尚未出版的项目应提交完成文本改编的全本分镜草图样本及能够展示作品故事情节、人物形象的绘画样张。

申报材料均不退还，请申报单位自行留底。

五、申报程序

申报单位备齐申报材料，按要求填写《中国经典民间故事动漫创作出版工程（第四辑）项目申请书》，报送省级出版主管部门。省级出版主管部门审核同意并加盖公章后，于2022年8月30日前将全套申报材料寄送至北京市西城区宣武门外大街40号（邮编：100052，联系人：郑加可，电话：010－83138687）。中央在京单位可直接报送至以上地址。

国家新闻出版署将通过评审确定入选项目，对入选项目予以出版资助，对重点项目组织宣传推介。
