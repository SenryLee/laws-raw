# 中国气象局科技与气候变化司关于批准建设雷电等6个培育类重点开放实验室的通知

气科函〔2022〕70号

河北省气象局、辽宁省气象局、湖南省气象局、陕西省气象局，中国气象科学研究院，国防科技大学、南京信息工程大学、无锡学院，雄安创新研究院，航天新气象科技有限公司、国网电力科学研究院武汉南瑞有限责任公司：

中国气象局重点开放实验室（以下简称部级重点实验室）是气象科技创新体系的重要组成部分，是在气象领域孕育重大原始创新、解决国家和区域重大科学技术问题的重要力量。为贯彻党的二十大精神，落实《气象高质量发展纲要（2022—2035年）》部署，优化部级重点实验室布局，发挥科技创新主力军作用，按照《中国气象局重点开放实验室管理办法》（气发〔2021〕143号，以下简称《管理办法》），经中国气象局研究，确定雷电等6个实验室为培育类部级重点实验室。

|  |  |  |
| --- | --- | --- |
| 序号 | 实验室名称 | 依托单位 |
| 1 | 雷电重点开放实验室 | 中国气象科学研究院、国网电力科学研究院武汉南瑞有限责任公司 |
| 2 | 生态系统碳源汇重点开放实验室 | 南京信息工程大学、无锡学院、航天新气象科技有限公司 |
| 3 | 高影响天气（专项）重点开放实验室 | 国防科技大学气象海洋学院、湖南省气象局 |
| 4 | 东北冷涡研究重点开放实验室 | 中国气象局沈阳大气环境研究所 |
| 5 | 秦岭和黄土高原生态环境气象重点开放实验室 | 陕西省气象局 |
| 6 | 雄安大气边界层重点开放实验室 | 河北省气象局、雄安创新研究院 |

各依托单位要根据《管理办法》要求，加大对实验室的支持力度，加强实验室建设和运行管理，完善科学研究和工作条件，吸引和聚集高层次气象科技人才，提升实验室的科技攻关、业务转化和人才培养水平。通过1—2年的实验室建设和培育，经评估合格后纳入部级重点实验室序列。
