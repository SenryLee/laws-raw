# 中国气象局关于批准成立地球系统数值预报等9个中国气象局重点开放实验室的通知

气发〔2022〕132号

北京市气象局、福建省气象局、湖北省气象局、广东省气象局、重庆市气象局，国家气象中心、中国气象局地球系统数值预报中心、中国气象局气象探测中心、中国气象科学研究院、中国气象局气象发展与规划院、华风气象传媒集团有限责任公司，北京大学、复旦大学、南京大学、河海大学、中山大学、中国民用航空飞行学院：

中国气象局重点开放实验室（以下简称部级重点实验室）是气象科技创新体系的重要组成部分，是在气象领域孕育重大原始创新、解决国家和区域重大科学技术问题的重要力量。为贯彻党的二十大精神，落实《气象高质量发展纲要（2022—2035年）》部署，优化部级重点实验室布局，发挥科技创新主力军作用，按照《中国气象局重点开放实验室管理办法》（气发〔2021〕143号），经研究，中国气象局决定批准“地球系统数值预报”等9个实验室为部级重点实验室。

|  |  |  |
| --- | --- | --- |
| 序号 | 实验室名称 | 依托单位 |
| 1 | 中国气象局地球系统数值预报重点开放实验室 | 中国气象局地球系统数值预报中心 |
| 2 | 中国气象局城市气象重点开放实验室 | 北京城市气象研究院、中山大学大气科学学院、南京大学大气科学学院 |
| 3 | 中国气象局雷达气象重点开放实验室 | 中国气象科学研究院、南京大学大气科学学院、中国气象局气象探测中心 |
| 4 | 中国气象局龙卷风重点开放实验室 | 广东省气象局、北京大学 |
| 5 | 中国气象局气候资源经济转化重点开放实验室 | 重庆市气象局、中国气象局气象发展与规划院 |
| 6 | 中国气象局水文气象重点开放实验室 | 国家气象中心、河海大学 |
| 7 | 中国气象局航空气象重点开放实验室 | 华风气象传媒集团有限责任公司、中国民用航空飞行学院 |
| 8 | 中国气象局海峡灾害天气重点开放实验室 | 福建省气象局、复旦大学 |
| 9 | 中国气象局流域强降水重点开放实验室 | 中国气象局武汉暴雨研究所 |

各依托单位要切实履行部级重点实验室建设和运行管理的主体责任，落实有关政策和配套经费，加大对实验室的支持力度，强化考核监督和激励举措，组织实验室开展科技攻关、业务转化、人才培养和开放合作，为气象高质量发展提供强有力科技支撑。
