# 中华人民共和国海事局关于印发2022年度船舶技术法规立项计划的通知

海船规〔2022〕33号

《中华人民共和国海事局2022年度船舶技术法规立项计划》已经2022年2月9日中华人民共和国海事局第2次局长办公会审议通过，现予公布。

中华人民共和国海事局

2022年2月14日

## 中华人民共和国海事局2022年度船舶技术法规立项计划

第一类：年内公布的技术法规

|  |  |  |
| --- | --- | --- |
| 序号 | 名称 | 主要内容 |
| 1 | 氢燃料电池动力船舶技术与检验暂行规则 | 根据氢燃料在船舶上储存、供应、加注、使用及安全研究和实船设计方案等情况，制定船舶使用氢燃料电池作为动力源的技术要求和检验制度性要求。 |
| 2 | 吨位丈量规则 | 统筹现行各船舶技术法规中吨位丈量相关内容。 |
| 3 | 船用产品检验规则 | 在《船用产品检验规则2018》基础上贯彻落实《海上交通安全法》要求，厘清船用产品检验模式，补充船用产品证书格式等。 |
| 4 | 海上移动式平台技术  规则 | 在《海上移动平台法定检验技术规则（2016）》基础上完善海上移动式平台技术要求，包括海上移动式居住平台、渔业养殖平台、休闲旅游平台、起重平台等新型海上移动式平台技术要求等。 |
| 5 | 海上移动式平台检验  规则 | 在《海上移动平台法定检验技术规则（2016）》基础上完善海上移动式平台检验制度性要求，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
| 6 | 船舶自主航行试验技术与检验暂行规则 | 根据IMO自主航行船舶临时导则，结合国内自主航行船舶技术发展现状和试验需求，制定船舶自主航行试验相关技术和检验要求。 |
| 7 | 国内航行海船法定检验技术规则修改通报 | 纳入国内航行海船必须支持北斗系统要求和基于北斗系统一体化集成终端技术要求，完善船舶使用岸电相关标注标识，协调《油品运输大气污染物排放标准》（GB 20951-2020）等，补充新建船舶能效设计指数要求等。 |
| 8 | 内河船舶法定检验技术规则修改通报 | 纳入基于北斗系统的一体化集成终端技术要求，完善船舶使用岸电相关标注标识，协调《油品运输大气污染物排放标准》（GB 20951-2020）等，补充新建船舶能效设计指数要求等。 |
| 9 | 国际航行海船法定检验技术规则修改通报 | 纳入近年来相关国际公约修正案，协调《油品运输大气污染物排放标准》（GB 20951-2020）等。 |
| 10 | 国内航行小型海船技术规则 | 在《沿海小型船舶法定检验技术规则（2016）》基础上区分普通客船、旅游客船不同技术要求，纳入锂电池在国内航行小型海船上应用的相关要求，补充国内航行小型海船近海航区技术要求等。 |
| 11 | 内河小型船舶技术规则 | 在《内河小型船舶法定检验技术规则（2016）》基础上区分普通客船、旅游客船不同技术要求，补充全垫升气囊浮体气垫船等特殊船型技术要求等。 |
| 12 | 国内海洋渔船检验规则 | 在《国内海洋渔船法定检验技术规则（2019）》基础上完善国内海洋渔船检验制度性要求，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
| 13 | 特定航线江海直达法定检验技术规则修改通报 | 将通州湾江海直达航线可行性研究成果纳入船舶技术法规等。 |
| 14 | 游艇法定检验暂行规定修改通报 | 在《游艇法定检验暂行规定（2013）》基础上增加船舶自动识别系统（AIS）要求等。 |

第二类：年内通过专家评审的技术法规

|  |  |  |
| --- | --- | --- |
| 序号 | 名称 | 主要内容 |
| 1 | 国内海洋渔船技术规则 | 在《国内海洋渔船法定检验技术规则（2019）》基础上厘清渔船技术法规与建造规范边界，纳入国内海洋渔船安全技术专项研究成果等。 |
| 2 | 国内航行海船检验规则 | 在《国内航行海船法定检验技术规则（2020）》基础上梳理现有国内航行海船相关技术规则、规程等船舶技术法规中的检验制度性内容，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
| 3 | 内河船舶检验规则 | 在《内河船舶法定检验技术规则（2019）》基础上梳理现有内河船舶相关技术规则、规程等船舶技术法规中的检验制度性内容，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
| 4 | 海上固定设施技术规则 | 制定海上固定设施技术要求，包括海上固定风电设施、渔业养殖设施和旅游休闲设施等的技术要求。 |
| 5 | 海上固定设施检验规则 | 制定海上固定设施检验制度性要求，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
| 6 | 海上浮动设施技术规则 | 制定海上浮动设施技术要求，包括海上浮动渔业养殖设施、发电设施和旅游休闲设施等的技术要求。 |
| 7 | 海上浮动设施检验规则 | 制定海上浮动设施检验制度性要求，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
| 8 | 内河浮动设施技术规则 | 制定内河浮动设施技术要求，包括内河趸船、旅游休闲设施等的技术要求。 |
| 9 | 内河浮动设施检验规则 | 制定内河浮动设施检验制度性要求，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
| 10 | 醇燃料动力船舶技术与检验暂行规则 | 根据IMO醇类燃料动力船舶临时导则，结合国内研究成果，制定船舶使用醇燃料技术要求和检验制度性要求。 |

第三类：研究起草的技术法规

|  |  |  |
| --- | --- | --- |
| 序号 | 名称 | 主要内容 |
| 1 | 拖航检验规则 | 在《海上拖航法定检验技术规则（1999）》基础上补充内河拖航检验相关要求，与《海上交通安全法》《内河交通安全管理条例》等法律法规协调等。 |
| 2 | 起重设备技术与检验规则 | 在《起重设备法定检验技术规则（1999）》基础上完善船用起重设备技术和检验要求，与《特种设备安全法》要求相适应。 |
| 3 | 国际航行海船技术规则 | 在《国际航行海船法定检验技术规则（2014）》基础上纳入历年修改通报内容和IMO相关技术文件要求，完善国际航行海船技术要求。 |
| 4 | 国际航行海船检验规则 | 在《国际航行海船法定检验技术规则（2014）》基础上结合国际公约，制定国际航行海船检验制度性要求，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
| 5 | 游艇技术规则 | 全面梳理评估《游艇法定检验暂行规定（2013）》，结合近年来实施情况反馈完善分类标准等技术要求，确保游艇安全技术水平不低于一般船舶。 |
| 6 | 游艇检验规则 | 全面梳理评估《游艇法定检验暂行规定（2013）》，完善检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等检验制度性要求。 |
| 7 | 潜水器技术规则 | 制定潜水器与潜水系统技术要求，包括耐压壳体及材料、生命支持系统、机械设备及管路系统、电气及消防、人员救生等技术要求。 |
| 8 | 潜水器检验规则 | 制定潜水器与潜水系统检验制度性要求，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
| 9 | 内河渔船技术规则 | 在《内河渔船法定检验技术规则（2019）》基础上厘清内河渔船技术法规与建造规范边界，纳入木质渔船技术要求等。 |
| 10 | 内河渔船检验规则 | 在《内河渔船法定检验技术规则（2019）》基础上完善内河渔船检验制度性要求，包括检验类型、检验范围、检验项目、检验方法、证书格式、检验和发证程序等。 |
