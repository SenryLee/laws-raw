# 科学技术部中国生物技术发展中心关于征集2022年度ICGEB联合研究项目的通知

## 中国生物技术发展中心关于征集2022年度ICGEB联合研究项目的通知

各有关单位：

受科技部委托，中国生物技术发展中心作为国际遗传工程和生物技术中心（以下简称ICGEB）中国分中心及联络办公室，负责归口管理ICGEB与我国在生物技术领域的科技合作、人员培训、学术交流等活动，促进中国与ICGEB及其各成员国的合作与交流。

根据ICGEB的工作计划，现启动2022年度ICGEB联合研究项目（含一般项目和归国人员早期启动项目）征集工作。项目申请书需在线填报（https://isg.icgeb.org/auth/login），申请者注册账号之后方可进行填报。

项目有关内容及要求等详见下表及网站（https://www.icgeb.org/activities/grants/）。

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **项目类别** | **申报条件** | **申报范围** | **推荐数量** | **资助额度** | **资助周期** |
| 一般项目 | 无特殊要求 | 基础生命科学、人类卫生健康、工业生物技术、农业生物技术、生物能源等领域 | 3项 | 最高25000欧元/年 | 3年 |
| 归国人员早期启动项目 | 1.年龄不超过40周岁；  2.至少2年海外研究经历；  3.归国时间不超过2年。 | 2项 |

申请者请严格按照上述网址及申报指南（附件）中的有关要求填写和提交申请表。申报截止日期为2022年4月30日，逾期提交的项目将不予受理。

中国生物技术发展中心将组织专家对所提交的申请书进行评审，最终向ICGEB推荐3项一般项目以及2项归国人员早期启动项目进行终评。获资助学者将获得不超过25000欧元/年、3年共75000欧元的经费资助。
