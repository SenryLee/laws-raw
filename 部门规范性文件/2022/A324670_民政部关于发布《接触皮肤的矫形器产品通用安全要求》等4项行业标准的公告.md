# 民政部关于发布《接触皮肤的矫形器产品通用安全要求》等4项行业标准的公告

## 民政部公告

第539号

## 关于发布《接触皮肤的矫形器产品通用安全要求》等4项行业标准的公告

《接触皮肤的矫形器产品通用安全要求》等4项推荐性行业标准已经民政部批准，现予以发布，自2023年1月1日起实施。

|  |  |  |
| --- | --- | --- |
| 序号 | 标准号 | 标准名称 |
| 1 | MZ/T 191—2022 | 接触皮肤的矫形器产品通用安全要求 |
| 2 | MZ/T 192—2022 | 假肢和矫形器定制件 3D打印技术指南 |
| 3 | MZ/T 193—2022 | 儿童福利机构防控呼吸道传染病管理规范 |
| 4 | MZ/T 194—2022 | 儿童福利机构标准体系建设指南 |
