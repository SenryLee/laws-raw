# 民政部公告第196号－－全国性社会团体分支机构成立、变更、注销登记公告

## 民政部公告

（第196号）

## 全国性社会团体分支机构成立登记公告

根据《社会团体登记管理条例》和《社会团体分支机构、代表机构登记办法》的规定，下列社会团体的分支（代表）机构准予成立登记，现予以公告。

|  |  |
| --- | --- |
| 名　　称 | 登记证号 |
| 中国太平洋经济合作全国委员会对外经济技术合作委员会 | 4332-6 |
| 中国政治学会科学发展与政治和谐研究专业委员会 | 3978-3 |
| 中国建筑业协会航天工程建设分会 | 4213-20 |

以上社会团体分支机构，自公告之日起一个月内到民政部民间组织服务中心办理相关手续。

## 全国性社会团体分支机构变更登记公告

根据《社会团体登记管理条例》和《社会团体分支机构、代表机构登记办法》的规定，经审核，下列社会团体的分支机构准予变更登记，现予以公告。

|  |  |  |  |
| --- | --- | --- | --- |
| 名　　称 | 变更事项 | 变更前 | 变更后 |
| 中国航空学会信号和信息处理专业分会 | 名称 | 中国航空学会信号和信息处理专业分会 | 中国航空学会信息融合专业委员会 |
| 中国航空学会人体工程、航医、救生专业委员会 | 名称 | 中国航空学会人体工程、航医、救生专业委员会 | 中国航空学会航空机电、人体与环境工程专业委员会 |
| 中国航空学会测试专业委员会 | 名称 | 中国航空学会测试专业委员会 | 中国航空学会测试技术专业委员会 |
| 中国航空学会飞行力学及飞行试验专业委员会 | 名称 | 中国航空学会飞行力学及飞行试验专业委员会 | 中国航空学会飞行试验专业委员会 |
| 中国航空学会自动控制专业委员会 | 名称 | 中国航空学会自动控制专业委员会 | 中国航空学会制导、导航与控制专业委员会 |
| 中国航空学会结构设计及强度专业委员会 | 名称 | 中国航空学会结构设计及强度专业委员会 | 中国航空学会结构与强度专业委员会 |

以上社会团体分支机构，自公告之日起一个月内到民政部民间组织服务中心办理相关手续。

## 全国性社会团体分支机构注销登记公告

根据《社会团体登记管理条例》和《社会团体分支机构、代表机构登记办法》的规定， 经审核，下列社会团体的分支（代表）机构准予注销登记，现予以公告。

名称

中国建筑学会城市交通规划分会

中国有色金属加工工业协会

中国县镇经济交流促进会城市郊区工作委员会

中国县镇经济交流促进会山区与贫困地区工作委员会

中国县镇经济交流促进会沿海发达地区工作委员会

中国县镇经济交流促进会中西部地区工作委员会

中国仪器仪表学会汉字信息处理系统分会

以上社会团体分支机构，自公告之日起一个月内到民政部民间组织服务中心办理相关手续。
