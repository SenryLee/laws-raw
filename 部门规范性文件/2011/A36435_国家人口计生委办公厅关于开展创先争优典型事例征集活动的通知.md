# 国家人口计生委办公厅关于开展创先争优典型事例征集活动的通知

## 国家人口计生委办公厅关于开展创先争优典型事例征集活动的通知（人口办宣教函〔2011〕40号）

各省、自治区、直辖市人口计生委，计划单列市、新疆生产建设兵团人口计生委，解放军、武警部队计划生育领导小组办公室，中直机关、中央国家机关人口计生委：

为推进人口计生系统创先争优活动的深入开展，结合全国人口和计划生育系统先进集体和先进工作者评选表彰工作，国家人口计生委决定开展全国人口计生系统创先争优典型事例征集活动。现将有关事项通知如下：

**一、**事例内容

事例内容应围绕近年来全国人口和计划生育系统在推动科学发展、促进社会和谐、服务人民群众、加强基层组织、建设一流队伍等方面涌现出的“五好”基层党组织和“五带头”共产党员的积极实践和典型事迹。

**二、**征集范围

（一）各地推荐事例不超过5个，尽量涵盖本省（区、市）、地（市、州）、县（区、市）、乡（镇、街道）、村（居）五级；应注重挖掘基层党组织和一线共产党员的先进事迹；将所报事例排出优先顺序，以便汇编成册。

（二）在推荐事例中，今年全国人口和计划生育系统先进集体候选单位和先进工作者候选人应占一定比例。

**三、**事例要求

（一）推荐事例必须真实可信，严禁虚构、杜撰和夸张。各省（区、市）人口计生委作为本省（区、市）事例推荐工作的唯一负责单位，应收集汇总本省（区、市）候选事例并严格把关，为上报事例撰写评语（100字之内），并统一报送。

（二）推荐事例应采用故事性写作手法，通过具体生动的人物和事件反映主题，体现典型性和创新性，富于感染力和表现力，切忌写成工作总结和情况汇报。

（三）推荐事例格式参考附件，其中主要内容部分不超过1500字，可附1至3张主题照片。

（四）各地需同时报送纸质和电子版事例，纸质事例加盖公章后邮寄至国家人口计生委宣传教育司或机关党委；电子版事例请发送邮件至：anlizhengji@sina.com，邮件标题注明推荐省份和事例名称， 推荐表和照片以附件形式发送。

（五）事例征集截止时间为2011年3月15日。

| 主要内容（1500字内） | “全体党员个个要牢记，强堡垒做先锋活动主题；创先争优人人当模范，各项工作努力争第一……践行承诺干事创业，立足岗位奋发进取；急难险重勇于冲在前，为民服务努力办实事。……” 　　兔年新春，一首由某省龙凤村民自编自演的花灯戏《十谢共产党》火遍乡村，红透网络。无独有偶，由某省某市人口计生委自编自演的歌曲《创先争优之歌》也迅速传唱开来，许多单位将此歌曲作为春节文艺晚会的主旋律曲目，成为该市春节前后文艺活动一道靓丽的风景线。 　　创先争优之歌给力走红是该市创先争优活动的一个缩影。2010年以来，该市在连续3年开展创先争优活动的基础上，根据中央和省市委部署，在市直人口计生系统进一步深入开展了创先争优活动，有力地推动了机关党的建设和各项业务工作的全面发展，打造出一流的人口计生队伍。 　　该市人口计生委对创先争优活动非常重视，大力营造良好氛围。开办了“创先争优活动亮点评选展示栏”、“创先争优活动成果一览表”、“党员干部创先争优光荣榜”和“学习园地”4个固定的宣传栏外。要求党员干部人人佩戴胸徽，摆放“共产党员先锋岗”桌签。在机关会议室和各科室，统一制作张贴了精美的宣传标语，真正做到“一个支部一个堡垒、一块牌子一份责任、一名党员一面旗帜”。 　　公开承诺是创先争优活动的基础工作和关键环节。在工作中，他们把承诺与制定今年的业务工作计划、目标及个人的学习成长计划目标结合起来，从单位到个人，分三个层面层层进行了公开承诺。一是机关党总支的承诺。委党组要求，市直人口计生系统班子、队伍建设要内强素质、外树形象，全面打基础、上水平、创一流；各项业务工作要求突破、求创新、上位次、争第一。全委总体和各方面工作都要发扬“见红旗就扛、有第一就争”的精神，在以往工作位次的基础上，瞄准一流目标，争先进、夺位次、上台阶。凡是有量化考核的工作都要努力争第一，其它工作竭尽所能创经验、出典型、创一流。以一流的工作业绩检验队伍建设的成果和水平，为党旗增光添彩。根据这一要求，党总支提出了“业务工作争第一、机关党建创一流、纪律作风作表率、为民服务当先锋”四个方面的承诺。二是根据党总支的承诺，各支部、科室和各单位制定自己的承诺。报单位领导审查后在机关公开承诺。三是党员和干部职工的承诺。 　　承诺是活动的起点，而践诺是活动的关键，评诺是活动的动力。他们将承诺、践诺、评诺与各方面工作有机结合起来，实行了四个结合。即与全委中心业务工作相结合，与全面加强机关党的建设相结合，与机关和直属单位绩效考核相结合，与工作创新和亮点评选相结合。承诺的过程实际上也是制定业务工作计划目标和层层分解任务指标的过程，践诺、评诺的过程实际上调度业务工作和业务工作总结评比的过程。 　　他们设立党员先锋岗和党员示范窗口，通过领导点评等方式，及时表扬活动中涌现出的好人好事。他们还在委机关树立了任劳任怨、勤勤恳恳工作的典型，发挥优秀共产党员的先进模范作用。“七一”期间，全委机关和直属单位集中表彰奖励了一批活动中涌现的优秀党员。 　　2010年9月29日，市委、市政府专门召开了由市五大班子领导、县市区人口计生工作“五职责任人”和市直部门主要负责人参加的人口计生工作大会，专门对人口计生委予以通报表彰，记集体二等功。这是市人口计生委连续三年获得二等功奖励。这样高规格地对一个部门进行表彰奖励，在该市历史上是第一次。市人口计生委班子连续四年在市委年度考核中满意率为100％，在全市行风万人评活动中一直名列前茅。 | | |
