# 国家文物局关于《中国文物年鉴2011》约稿的通知

## 国家文物局关于《中国文物年鉴2011》约稿的通知（办政函〔2011〕548号）

各省、自治区、直辖市文物局（文化厅），各直属单位及相关单位：

《中国文物年鉴2011》是我局组织、中国文物信息咨询中心编辑出版的一部反映2010年度全国文物和博物馆行业发展状况的重要类编书目。为保障《中国文物年鉴2011》按计划出版，现就有关事项通知如下：

**一、**请确定一名负责本省、自治区、直辖市或单位《中国文物年鉴2011》组稿工作联系人，并于2011年8月15日前将联系人姓名及联系方式报中国文物信息咨询中心年鉴编辑部。

**二、**请按照“《中国文物年鉴2011》内容格式要求及注意事项”（见附件）尽快组织、撰写相关稿件。

**三、**请于2011年10月30日前将稿件内容以电子邮件形式发送至：nianjian@sach.gov.cn，并请注明稿件作者姓名、电话、电子信箱地址、身份证号（发稿费用）、邮编、单位、地址等相关信息。

附件：

《中国文物年鉴2011》内容格式要求及注意事项

《中国文物年鉴2011》记述各地（单位）2010年文物事业发展的基本情况。为保证编辑体例统一，内容翔实，资料确切，请按照以下格式及内容要点组织稿件，并可结合本地（单位）特色适当省略或补充内容，总字数请控制在3000～8000之间：

省、市、自治区名称（或国家文物局直属单位及相关单位名称）

【概述】

2010年某某省（自治区、市）或某某单位文物事业发展概述，包括法规建设、执法督察、不可移动文物的保护与管理、考古发掘、博物馆等等。

【法规建设】

重要法规的制定、出台过程情况。

【执法督察与安全保卫】

文物普法工作，文物保护法宣传情况；打击文物盗窃、走私犯罪活动情况、大案要案查处情况；文博系统安全保卫概况。

【不可移动文物的保护和管理】

（一）概况

全国重点和省级重点文物保护单位的数量；2010年度新公布全国重点和省级重点文物保护单位的数量、名称；重要文物保护单位保护规划的编制和公布情况；重要文物保护工程投入经费及重大工程项目情况等。

（二）大遗址保护

重要大遗址保护方法、经验、成果等。

（三）全国重点文物保护单位

全国重点文物保护单位管理。

（四）世界文化遗产

1．世界文化遗产项目的申报、评审；

2．世界文化遗产保护、管理制度和方法。

【考古发掘】

（一）概况

重大考古新发现；考古发掘报告的数量、名称；考古发掘项目的获奖情况。

（二）重要考古项目

1.某某考古项目

发掘时间、发掘面积、出土重要文物及价值等

2.某某考古项目

发掘时间、发掘面积、出土重要文物及价值等

……

【博物馆与可移动文物保护】

（一）博物馆

1.可移动文物的保护、管理和研究；

2.博物馆间的交流与合作；

3.重要文物陈列展览。

（二）可移动文物保护

1.文物数量、等级等基本情况

2.可移动文物保护修复基地建设情况；

3.可移动文物保护技术和方法及其应用情况。

【社会文物管理】

文物拍卖、文物商店及文物进出境审核等相关情况。

【科技与信息】

文博科技与信息发展情况。

【文博教育与培训】

文博教育、培训情况。

【文博宣传与出版】

宣传活动的形式以及效果；重要文献或图书出版情况。

【机构及人员】

机构总数及分类数（分类包括文物保护管理机构、博物馆、文物商店、文物科研机构、其他文物机构等）及2010年新增数量；人员数量（大专以下、大专、大学本科、硕士、博士，职称-初级、中级、副高、正高，按单位性质分，按隶属关系分），新增数量；表彰情况（先进单位、先进个人等）。

【对外交流与合作】

文物赴外展览及引进展览；重要来访及外访活动；重要的涉外合作项目。

【其它】

其它重要事件或信息。

注意事项：

为规范《中国文物年鉴?2011》的内容、格式，减少不必要的错误，提高年鉴编辑效率，提请各位撰稿人注意：

1.《中国文物年鉴》以国家文物局的立场和口吻介绍国内2010年的文博事业发展情况，因此内容要尽可能全面，文中涉及的数据、日期要客观、翔实、准确，注意说明数据统计的来源和统计截止年月日，避免使用套话、非客观评述或口语化语言，避免使用不确切的、容易造成误解的简称。

2.主题下如果内容较多，请统一使用一级标题（一）（二）（三）……及二级标题1.2.3……，请避免使用三级标题。

3.常见不规范用语和符号及规范用语和符号对比见下表：

|  |  |
| --- | --- |
| 不规范用语和符号 | 规范用语和符号 |
| 我省、我局、我所、我馆 | 用省、局、所、馆的全称如“江苏省”“江苏省文物局”等 |
| 目前，迄今为止 | 截至某年某月某日止 |
| 今年、去年 | 2010年、2009年 |
| 1月2日-3月5日 | 1月2日～3月5日 |
| 第1-6批国保单位 | 第一至第六批国保单位 |
| 某地-某地高速公路 | “某地”不能简写，必须写全称 |
| 30件套 | 30件（套） |
| “5.18”、“4.18” | “5·18”、“4·18” |
| “十二·五” | “十二五” |
| 《某某展览（或陈列）》 | “某某展览（或陈列）” |

4.国家文物局直属单位及相关单位由于业务较专一，可按本单位业务流程组织相关内容，不受此内容格式要求限制。
