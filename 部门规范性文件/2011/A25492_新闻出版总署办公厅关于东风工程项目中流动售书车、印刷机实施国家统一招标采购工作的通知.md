# 新闻出版总署办公厅关于东风工程项目中流动售书车、印刷机实施国家统一招标采购工作的通知

## 新闻出版总署办公厅关于东风工程项目中流动售书车、印刷机实施国家统一招标采购工作的通知（新出厅字[2011]369号）

内蒙古、广西、四川、云南、西藏、甘肃、青海、宁夏、新疆省（自治区）、新疆生产建设兵团新闻出版局：

根据《“十二五”少数民族新闻出版东风工程建设规划》，流动售书车和大宗专业技术设备由国家统一组织采购。为做好此项工作，现将有关事项通知如下：

**一、**统一采购的品目和采购方式

经商国家发改委，国家统一组织采购的品目为列入《“十二五”少数民族新闻出版东风工程建设规划》建设项目中的流动售书车和单台（套）批准概算在150万元以上（含150万元）的印刷机。采购方式为国内公开招标。含上述两种设备的建设项目按照基本建设程序在地方发展改革部门履行可研报告等审批手续并落实配套资金后，由新闻出版总署牵头组织招标采购。

**二、**组织机构和职责

（一）设立招标工作组（以下简称“工作组”），由总署财务司和有关省（自治区）新闻出版局选派人员组成，工作组组长由财务司司长担任，工作组负责组织落实招标采购工作，包括制订工作计划、选取委托招标代理公司、审核招标文件、参与和监督开评标工作等。工作组下设流动售书车招标和印刷机招标两个工作小组，由有关的项目法人派人参加，具体参与相关设备的招标评标工作。

（二）驻署纪检组监察局对招标活动活动全过程进行监督。

（三）省（自治区）新闻出版局负责招标需求书的论证审定。项目法人负责编制招标需求书、确定中标人、签订和执行合同、组织验收。

**三、**工作步骤

（一）省（自治区）新闻出版局组织编制上报招标需求书。招标需求书包括项目名称、设备内容、批准概算、资金来源、技术指标、质量及维护培训要求、交货时间、交货地点等内容（招标需求书的编写可参考附件范例）。

（二）成立工作组。工作组根据设备采购的时间、技术等需求，制订工作计划，研究确定采购项目的分类打包，组建相应的工作小组。

（三）工作组选取招标代理公司。招标代理公司组织招标采购，确定各种设备的中标候选人。

（四）项目法人确定中标人，与中标人签订并执行政府采购合同。

**四、**招标工作程序

（一）招标委托。工作组与招标代理公司签订招标委托协议。协议由工作组长签字，加盖总署办公厅章。招标代理公司根据招标采购品目分类打包情况，逐项开展招标工作。招标代理费用按实际成本或有关文件规定确定，由项目中标方支付。

（二）招标、开标、评标。招标、开标和评标工作由招标代理公司负责组织，在北京进行。

1.编制招标文件及发布招标公告。招标代理公司按照国家有关法律法规的要求，根据项目招标需求书编制招标文件及招标公告，报经工作组审核，由工作组长签字确认后发布。

2.开标。开标由招标代理公司主持，工作组及纪检监察部门派人现场监督。

3.评标。评标委员会组成方法：招标代理公司从专家库随机抽取相关领域的专家（5人）和项目法人的代表（招标工作小组成员）共同组成评标委员会。招标代理公司负责联系组织评标委员会评标。评标委员会评标并推荐3个以上（含3个）合格的中标候选人。

（四）定标及合同签定。项目法人根据招标代理公司的评标报告，（如有必要，对中标候选人进行资格后审），确定中标人。招标代理公司依据工作组的通知，发中标公告及中标通知书。中标通知书发出后，项目法人组织合同谈判小组与中标人进行合同谈判、订立合同，省级新闻出版行政部门的纪检监察部门进行监督。

（五）到货验收。省（自治区）新闻出版局和项目法人（或设备使用单位）共同组织设备到货验收，并向国家发改委、新闻出版总署和省级发改部门提交到货验收报告。

**五、**工作安排及要求

（一）计划2011年11月下旬在北京进行一次招标采购。

（二）2011年11月15日前，省（自治区）新闻出版局完成招标需求书组织编制工作，并将招标需求书、地方发展改革部门批件、配套资金证明文件报送总署财务司，同时报送参加工作组及工作小组人员名单。工作组由各省级新闻出版局选派一人参加，工作小组由项目法人单位选派一人参加，（参加工作组和工作小组的可以为同一人）。参加工作小组人员需取得项目法人单位授权参与评标的委托书。

（三）各省（自治区）新闻出版局要高度重视东风工程建设工作，抓紧组织编制上报可研报告等报批文件，协调有关部门和项目单位落实配套资金，加快工作进度。除国家统一采购的设备外，其他采购按照当地政府采购的有关规定抓紧实施，力争东风工程各项目早见成效。

**七、**设备基本技术要求：

1.总则

1.1　本技术需求书适用于东风工程流动售书车项目。包括流动售书车本体及附属装置、设备的功能、结构、性能、安装和试验等方面的技术要求。

本技术需求书所提出的是最低限度的技术要求，并未对一切技术细节做出规定，也未充分引述有关标准和规范的条文。制造商、代理商应保证提供符合本技术条件书和现行工业标准的优质产品。

如果制造商、代理商没有以书面方式对本技术条件书的条文提出异议，那么采购方将认为制造商提供的产品完全符合本技术条件书的要求。

在签订合同之后，到开始制造之日的这段时间内，采购方有权提出因规范标准和规程发生变化而产生的一些补充修改要求，制造商、代理商应遵守这个要求，具体款项内容由供需双方共同商定。

本技术需求书所使用的标准，如遇到与供应方所执行的标准不一致时，按较高的标准执行。如果本技术需求书与现行使用的有关国家标准以及部颁标准有明显抵触的条文，制造商、代理商应及时书面通知采购方进行解决。

制造商、代理商须提供所供设备在国内文化产业的供货业绩和良好运行记录。

2.设备使用的环境和条件

2.1　使用地点：室外。

2.2　主要运行环境为西部县、乡镇、农村、偏远地区或牧区等交通及路况相对较差的地区。

3.技术要求

所提供的流动售书车必须是技术先进、经济合理、成熟可靠的产品，并具有较高的灵活性，能够满足主要针对社区、学校、部队、乡镇、农村及牧区的图书售卖要求，在售书作业以外可经过简单操作改变成为其他用途的轻型厢式货车。

3.1　流动售书车的型式

3.1.1　二类底盘型式

平头驾驶室、单、（双）排座、驱动型式为4×2，后双胎，柴油发动机。

3.1.2 车厢型式

3.1.2.1　独立封闭式厢体。

3.1.2.2　系统应在短时间内被展开成为一个开放式的书店，并有利于读者购书和工作人员服务管理。

3.1.2.3　后尾门及侧门的设计应保障售书作业及发行运输时货物先进先出的或后进先出等需求。

3.1.2.4　厢体外缘安装铝合金装饰型材，厢体底板及尾部外缘除外。

3.1.2.5　厢体顶板与铝合金装饰型材之间应有防漏措施。

3.1.2.6　厢体外部铆钉应排列整齐，间距相等。

3.1.2.7　厢体后部上侧及侧门上部应安装防雨槽。

3.1.2.8　厢体采用钢骨架和“三明治”结构，顶部厢板厚度不小于40mm，侧面厢板厚度不小于40mm，前部厢板、侧门及尾门厚度不小于40mm。

3.1.2.9　车厢底板应铺设防滑耐磨平整的底板。

3.2　流动售书车的运行要求

3.2.1　制造商必须保证满足采购方提出的流动书店技术参数，并能在第2条《设备使用的环境和条件》中指明的环境下长期安全运行。

3.2.2　制造商使用的二类底盘应是中华人民共和国国家发展和改革委员会《车辆企业和产品公告》内产品。

3.2.3　流动售书车系统技术要求应符合《QC/T453-2002厢式运输车》的有关规定。

3.2.4　流动售书车运行安全技术要求应符合《GB7258-2004 机动车运行安全技术条件》的有关规定。

3.2.5　流动售书车污染物排放应符合《GB3847-1999压燃式发动机和装用压燃式发动机的车辆排气可见污染物限值及测试方法》、《GB17691-2001 车用压燃式发动机排气污染物排放限值的测量方法》的有关规定。

3.2.6　车厢内应设置有防止车载展品展具撞击厢板的防撞机构和与车载展品配套的紧固装置。

3.2.7　流动售书车应在外部适当位置配备航空电源插座和移动电缆，移动电缆长度应大于50m。车内采用24V和220V双电源系统，220V电源功率大于1kw。

3.2.8　流动售书车内应设置24V和220V电源插座，以便收银机或其他电器使用。

3.2.9　流动售书车车厢内应设有专用的车载功放音响与麦克风。

3.2.10　流动售书车应有标牌，其内容和安装位置应符合《Q C/T 18411-2001道路车辆产品标牌》的规定。

3.2.11　流动售书车车厢内应配备足够的照明设备，安装于车厢顶部。使用电压分别为24V（直流）和220V（交流）。

3.2.12　车内应设有储物箱柜，可分类存放工具、照明用具及杂物。

3.2.13　车厢内所有装置应可拆卸，经简单操作可成为其他用途的轻型箱式货车。

3.3　图书展示系统技术要求

3.3.1　流动售书车书架应轻便，耐用，颜色和样式适宜图书销售且与车身协调一致，展示方式多样。在行车过程中应可与车厢固定且书籍不得滑落。

3.3.2　流动售书车应设置可平置书籍的平台，且展开回收要便捷可靠。

3.3.3　流动售书车图书展示量不低于6万元码洋。

3.3.4　流动售书车单件展示用具重量不大于15公斤。

3.3.5　流动售书车展具及书籍的展开时间不大于10分钟，收纳时间不大于15分钟。

3.3.6　展开和收纳过程中需徒手搬运的图书不得超过总量的20%

3.3.7　图书售卖时应可安装充足的照明，且24V与220V可切换，照明用具安装回收要便捷安全。

3.3.8　售书区左右两侧上部应安装两只功率不得小于100W的扬声器。

3.4　防雨篷的要求

3.4.1　在售书区上方应预留设置折叠雨篷的空间，以保证在天气变化时书籍的完好。

3.4.2　雨篷必须排水合理。

3.4.3　雨蓬覆盖面积合理并有适当余量。

3.4.4　雨篷的收放为手动方式。

3.4.5　雨篷折叠后不得超出车厢平面。

3.5　车身图案及油漆的要求

3.5.1　流动售书车车身图案应美观大方，包含新华书店的规范标识及车辆的统一编号，油漆涂层应符合《QC/T484-1999 汽车油漆涂层》的有关规定。

3.5.2　流动售书车整车车身在油漆前表面应进行除油、除锈、脱脂处理。

3.5.3　流动售书车表面不平处采用刮原子灰处理，使车身表面平整。

3.5.4　流动售书车外部油漆完成后所有角边应光滑、无颗粒。

3.5.5　流动售书车车身图案所用油漆采用高级豪华大型客车专用进口油漆。

3.5.6　流动售书车车身表面油漆应保证抗紫外线，7年内不退色、不褪光，保持原有的亮度和光度。

3.6　流动售书车平衡支撑系统的要求

3.6.1　流动售书车应在车厢的底部设置支撑，以保证展具展开后的安全平稳作业。

3.6.2　流动售书车平衡支撑系统采用机械支撑，每个支撑腿可独立操作。

3.6.3　支撑腿未收起时驾驶室有提示报警装置。

3.6.4　应保证备件的互换性。

4.设备规范

4.1　所提供的车辆必须是一台制造商提供的最终车辆，包括标准化的外观、配备安全有效及保证可靠运行所需的附件和备件、制造商的规范服务等。
