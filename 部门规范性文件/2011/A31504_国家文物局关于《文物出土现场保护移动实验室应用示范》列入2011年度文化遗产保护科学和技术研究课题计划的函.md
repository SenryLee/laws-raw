**二、**课题的目标、主要研究内容及预期研究成果

|  |
| --- |
| 课题研究的目标和意义： 　　文物出土现场移动实验室是国家十一五科技支撑计划项目研究成果。实验室具有考古现场空间信息采集、文物埋藏环境调查、出土文物材质和保存状况检测、考古现场环境信息采集以及出土文物保护等多项功能。移动实验室研制完成后，已在相继在山东寿光双王城遗址、陕西西安机场扩建工程考古发掘现场、陕西西安凤熙园汉墓以及山西大河口西周墓地开展了空间信息采集、出土文物材质分析和文物埋藏环境调查等项工作。现场试验结果表明，移动实验室能够为考古现场发掘现场的考古研究和出土文物保护提供多方面的技术支持，显著提高了考古发掘过程中获取的信息量，是考古现场开展文物保护工作和现场考古研究有效的技术支撑平台。 　　为扩散移动实验室研究和实践中的技术，加速最新科研成果所形成的知识流动，使移动实验室成果尽快在实际工作中得到转化和应用。本项目计划联合北京大学、荆州文物保护中心、浙江大学、陕西考古研究院等多家单位，选择适合考古工地，在三处考古现场开展移动实验室技术培训和技术服务。所开展的工作和培训内容如下： 　　1、结合新的考古规程，开展移动实验室空间信息采集技术系统操作培训，具体包括：航空拍摄、近景摄影测量，计算机手工绘图和考古现场信息管理系统的操作方法。 　　2、遗址现场埋藏环境调查方法培训。具体为便携式离子色谱可溶盐测定方法、酸碱度测定方法、含水量测定方法，结合现场环境分析数据，为考古现场土遗址加固和保护提供基础数据。 　　3、移动实验室文物材质和病害分析单元培训。具体包括便携式X荧光、便携式拉曼光谱、便携式红外、便携式显微镜以及便携式X透射等仪器在金属文物、壁画、玉器、陶器等材质、病害以及工艺的调查方法。 　　4、移动实验室现场微生物鉴定单元培训。具体开展现场微生物样品采集方法、微生物培养和显微镜鉴定方法等。 　　5、现场应急保护方法培训。具体包括，整体打包提取方法、脆弱质文物临时固型方法、北方干旱漆器现场提取保护方法、南方漆木漆和丝绸现场提取保护方法以及陶质彩绘和壁画现场保护方法。 　　通过结合具体的考古发掘工作，分别在陕西、湖北等地开展以上内容的技术培训。通过培训进一步促进现场考古和保护工作的有机结合，探索在新技术支持下的考古发掘的理论和方法。 |

|  |
| --- |
| 主要研究内容、拟解决的主要问题和难点分析： 　　现代考古学既是对古代遗产的发现，又是细致的科学分析，同时还是富有创造性构想的工作。从本质上说，考古学是一种令人激动的探求，是对我们自己和已逝的古代知识的求索。移动实验室技术系统正式顺应了现代考古学的发展趋势，在技术体系的设计方法上兼顾了考古学发展更深更广的研究领域。多种分析装备的小型化和便携化，使得在考古现场对遗迹遗痕的准确判定、文物出土材质分析、多种不明出土文物的性质判别变为现实。多种科学方法的介入，使得在考古工作过程中，能够获取更加丰富的遗址信息，并且使许多出土文物特别是脆弱质文物在第一时间得到妥善保护，为后续保护和考古研究提供最完备的文物资料。本项目中主要解决的难点有以下几个方面： 　　1、结合国家文物局颁布的新的田野考古规程，进一步补充和完善移动实验室技术系统，使其更加实用化，同时具有可操作性，是本项目的难点之一。 　　2、移动实验室开发的空间信息采集系统，能够采集考古现场宏观、中观、微观的空间信息，并在实践中得到了较好的应用。但考古现场类型复杂，空间形状各异，如何在实际应用中完善空间信息采集系统，积累更多的经验，最后形成标准规范，是本项目的难点之一。 　　3、文物移动实验室的分析单元是由多种小型便携式仪器组合而成，相对于实验室大型仪器，在监测范围和精度方面都有较大的局限性，因此在实际应用中，如何积累更多的标准数据，拓展便携式仪器的分析范围和精度，充分发挥多种仪器组合获取更多信息方面是本项目的难点之一。 　　4、移动实验室的现场保护单元是由针对多种出土文物的专有工具和化学药品组成，通过本项目的实际应用，在实践中，改良更加方面的现场保护专有工具，并配合适当的保护材料，形成针对各类出土文物保护方法的配套工具是本项目的难点之一。 　　5、移动实验室的技术系统需要在实践中不断积累经验，形成更多的工作案例。因此选择适合的考古工地，充分发挥移动实验室技术系统的优势，也是本项目的难点之一。 |

|  |
| --- |
| 课题研究的主要创新点： 　　1、形成移动实验室空间信息采集系统硬软件标准，并制定出相应的标准操作规范。 　　2、形成移动实验室针对各类文物材质、病害工艺的便携式仪器组合测定方法，形成一套标准数据库，并制定标准的操作规程。 　　3、为三个省份培养一批移动实验室专业人才。 |

|  |
| --- |
| 研究的技术路线和研究方法： 　　技术路线为： 　　选择陕西周公庙遗址、湖北熊家冢遗址和湖南一处遗址为应用示范现场并开展相关培训工作。 　　1、针对不同考古现场的实际情况，制定移动实验室工作方案。 　　2、开展空间信息采集工作。 　　3、开展埋藏环境调查工作。 　　4、开展针对出土文物的分析检测工作。 　　5、针对脆弱质出土文物提出具体保护建议。 　　6、在实际工作中培养移动实验室专有人才。 |

|  |
| --- |
| 预期成果及成果形式： 　　1、移动实验室空间信息采集规范。 　　2、移动实验室分析系统规范。 　　3、培养45名移动实验室使用专有人才。 |
