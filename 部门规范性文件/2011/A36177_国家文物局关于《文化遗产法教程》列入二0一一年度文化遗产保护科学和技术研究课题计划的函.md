# 国家文物局关于《文化遗产法教程》列入二0一一年度文化遗产保护科学和技术研究课题计划的函

## 国家文物局关于《文化遗产法教程》列入二0一一年度文化遗产保护科学和技术研究课题计划的函（文物博函〔2011〕240号）

中国人民大学：

经我局研究，决定委托你校承担《文化遗产法教程》（合同编号：20110201）课题，负责人：王云霞。该课题列入国家文物局2011年度文化遗产保护科学和技术研究课题计划，课题补助经费10万元，研究时限为2011年3月-2012年2月。

按照《文物保护科学和技术研究课题管理办法》的有关规定，我局补助经费分两期拨付，现随文拨付第一期经费7万元。第二期经费待课题通过结项验收后另行拨付。请专款专用，确保绩效。收到课题补助经费后，请将收据寄至北京市东城区朝阳门北大街10号国家文物局办公室财务处（邮编100020）。

国家文物局　　　

二〇一一年二月二十五日
