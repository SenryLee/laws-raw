# 科学技术部、银监会关于推荐银行科技型中小企业信贷项目咨询专家的通知

## 科学技术部、银监会关于推荐银行科技型中小企业信贷项目咨询专家的通知（国科发财〔2011〕642号）

各省、自治区、直辖市、计划单列市科技厅（委、局）、银监局，各产业技术创新战略联盟，各有关单位：

为进一步发挥科技专家的作用，支持银行业金融机构加大对科技型中小企业的融资服务，根据银监会、科技部《关于进一步加大对科技型中小企业信贷支持的指导意见》（银监发〔2009〕37号）和《关于选聘科技专家参与科技型中小企业项目评审工作的指导意见》（银监发〔2009〕64号）要求，科技部、银监会于2010年试点启动了科技专家参与科技型中小企业信贷项目评审工作，取得了积极成效。在已有工作基础上，科技部会同银监会建立了银行科技型中小企业信贷项目科技专家咨询系统（以下简称专家咨询系统），专门为银行发放科技型中小企业信贷提供技术咨询和服务。为进一步完善专家咨询系统建设，提高服务效率和能力，现就推荐科技专家进入专家咨询系统的有关工作通知如下：

**一、**高度重视，积极推荐

当前，融资难已成为制约科技型中小企业成长的关键瓶颈。其中，银行在信贷调查和评审中，对企业技术发展和核心知识产权的把握能力不足，是影响科技型中小企业融资的重要因素之一。科技专家参与银行科技型中小企业信贷评审是化解银行与企业之间的信息不对称、促进科技和金融结合、缓解科技型中小企业融资难和培育发展战略性新兴产业的重要措施。要充分认识科技专家参与信贷评审的重要意义，结合本地科技发展实际情况，切实做好专家咨询系统科技专家的推荐工作。

**二、**专家申报条件

1. 具有扎实的专业知识与从业记录，在相应领域从事科技研发或科研管理工作10年以上，熟悉本领域发展的技术水平和总体情况；

2. 热心科技事业发展，关注科技型中小企业成长，愿意向银行科技型中小企业信贷项目提供咨询和顾问服务；

3. 了解金融、银行常识，能够正常参加信贷项目评审和咨询工作；

4. 参加过国家科学技术发展战略规划的相关编制工作，有现代企业经营管理经历，具备相应金融知识的专家优先；

5. 各级科技行政主管部门在职公务员不得担任专家。

**三、**推荐程序和要求

1. 地方科技部门会同地方银监局，共同开展本地区科技专家的推荐工作。

2. 科技专家填写并向地方科技部门报送《科技专家推荐表》。

3. 地方科技部门会同地方银监局审核拟推荐的科技专家信息，在将相关要求通知拟推荐专家并征求专家本人同意后，填写《科技专家推荐汇总表》，并由地方科技部门和地方银监局联合报送至科技部。

4. 鉴于产业技术创新战略联盟地域跨度大、专业性强，联盟可独立开展科技专家的推荐工作。联盟应在通知拟推荐专家并征求专家本人同意后，填写《科技专家推荐汇总表》，并报送至科技部政策法规司，科技部政策法规司审核后送科技部科研条件与财务司汇总。

**四、**其他事项

科技部将会同银监会围绕国家重点支持的高新技术领域，从地方科技部门、各产业技术创新战略联盟、行业协会及其他单位推荐的科技专家以及国家科技计划专家库中，择优选取一批专家纳入专家咨询系统，重点向银行业金融机构提供科技型中小企业信贷项目或其他涉及科学技术项目的专业技术咨询服务。

专家咨询系统是为银行科技型中小企业信贷项目评审提供技术服务的网络工作平台，主要提供咨询、交流、评审和培训等服务。银行须登录专家咨询系统聘请专家参与信贷项目的咨询、论证、评审工作。

科技部、银监会委托中国银行业协会负责专家咨询系统的日常维护和管理工作。科技专家在参与银行科技型中小企业信贷项目评审过程中，遇有问题可向科技部、银监会反映情况，提出意见和建议。

附件1：

专家的职责、权利和义务

**一、**专家的主要职责及工作范围

参与科技部、银监会和中国银行业协会及银行组织的专业技术咨询服务等，通过科技专家选聘系统了解银行咨询需求，为银行信贷项目涉及的专业技术把关定位，进言献策，但不参与项目可行与否的最终决策。

**二、**专家享有的权利

（一）专家有权被邀请参与科技部、银监会或中国银行业协会组织的有关专业会议、专题研讨会、咨询和培训活动；

（二）专家进行独立评审，提供技术服务的最终意见，不受任何单位和个人的干预；

（三）在不涉及商业秘密的前提下，专家有权了解技术服务活动目的，认为技术服务所依据的信息不充分时可以要求补充相关资料；

（四）对不适宜参加的咨询服务活动可以申请并拒绝参与；

（五）专家有权接受银行支付的一般性技术服务报酬。有权就所承担的特殊项目、重大项目的深度技术服务，与银行协商适当提高技术服务报酬。为充分调动专家的积极性，使之为科技项目提供更好的技术服务，专家提供的深度技术服务报酬，以及交通、食宿等相关费用由银行另行商定支付；

（六）专家有权直接向科技部、银监会或中国银行业协会反映情况，提出意见和建议。

**三、**专家应履行的义务

（一）遵守职业道德，公正、公平、客观和科学地进行咨询论证；对所提出的咨询论证意见承担相应责任；

（二）自觉保守国家秘密和被咨询单位的商业秘密，对所知悉的技术服务事项以及相关资料严守保密规定；

（三）在规定期限内完成受理的技术服务；因故不能参加技术服务，应及时告知银行；对与专家本人有利害关系的咨询事项应主动申请并回避；同时，按照要求在专家咨询系统内对上述内容进行登记；

（四）在完成咨询服务后，按照中国银行业协会要求对咨询银行进行评价；

（五）在专家个人信息发生变更时及时报备科技部；

（六）接受科技部、银监会和中国银行业协会的监督和管理。

**四、**符合下列情况之一，专家应当主动申请回避

（一）技术服务项目与专家有利益关系的；

（二）参与项目竞争的直接竞争者和间接向项目提供服务的；

（三）项目单位的人员（包括离退休人员）；

（四）项目上级主管部门的工作人员；

（五）与项目存在经济利益关系、可能影响公正性的；

（六）由于身体等原因，无法完成项目技术服务的。
