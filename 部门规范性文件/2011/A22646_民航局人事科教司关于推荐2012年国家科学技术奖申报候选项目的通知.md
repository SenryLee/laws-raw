# 民航局人事科教司关于推荐2012年国家科学技术奖申报候选项目的通知

各有关单位：

根据国家科技奖励办《关于2012年度国家科学技术奖励推荐工作的通知》（国科奖字［2011］64号）精神，现将2012年度民航推荐工作事宜通知如下：

**一、**推荐办法和要求。根据国家奖励办推荐要求和民航情况，今年民航采取单位推荐、评审择优方式，向国家奖励办推荐民航申报国家科技奖项目。请各单位遵照国家科技奖励办64号文件（可从网上下载）要求，组织推荐并填写推荐材料，推荐材料包括书面推荐书2套（含原始件1套，复印件1套，其中推荐书主件和附件一并装订成册），推荐书电子版（刻录成1张光盘），于2012年2月16日前将推荐项目报民航局人事科教司，各单位限推荐一个项目。

**二、**推荐书填写要求。请从国家科技奖励办门户网站www.nosta.gov.cn下载。

特此通知

民航局人事科教司　

二O一一年十二月三十日
