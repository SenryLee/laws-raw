# 国家核安全局关于批准释放中国实验快堆“初始功率提升”控制点的通知

## 国家核安全局关于批准释放中国实验快堆“初始功率提升”控制点的通知（国核安发[2011]28号）

中国原子能科学研究院：

你院《关于申请释放中国实验快堆“初始功率提升”控制点的请示》（原安发〔2011〕6号）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》和《研究堆运行安全规定》，我局组织专家对中国实验快堆B阶段调试试验完成情况及C阶段调试工作准备情况进行了检查，认为中国实验快堆已按要求完成了调试大纲规定的B阶段的调试试验项目，对C阶段调试工作的准备情况满足相关要求，对遗留问题已经按要求进行了处理，满足“初始功率提升”控制点的释放条件，现批准释放该控制点。

你院应严格按照核安全法规及批准的《中国实验快堆调试大纲》的要求，开展中国实验快堆C阶段的调试工作。若需要对调试大纲所列的试验项目进行调整，应按要求报我局审评批准后方可实施。

附件：中国实验快堆初始功率提升控制点释放前检查报告

二○一一年一月二十五日

附件：

中国实验快堆初始功率提升控制点释放前检查报告

检查单位名称：国家核安全局

被检单位名称：中国原子能科学研究院

检查日期：2011年1月18日至1月19日

**一、**检查依据

1、中华人民共和国民用核设施安全监督管理条例及其实施细则

2、研究堆设计安全规定

3、研究堆运行安全规定

4、研究堆调试

5、中国实验快堆最终安全分析报告

6、中国实验快堆首次装料批准书条件

**二、**检查范围

1、中国实验快堆B阶段调试管理和质量保证管理情况；

2、中国实验快堆B阶段调试试验完成情况；

3、中国实验快堆C阶段调试工作准备情况；

**三、**检查活动

检查组由国家核安全局、环境保护部华北核与辐射安全监督站、北京核安全审评中心、苏州核安全中心等单位的专家组成（名单见附表一）。

检查组根据检查内容分成两个小组，采用听取汇报、文件检查及访谈等方式进行了检查。中国原子能科学研究院（参会名单见附表二）对相关工作进行了汇报并积极配合了检查。

**四、**检查结论和整改要求

（一）中国实验快堆调试管理和质量保证管理情况

检查组对中国实验快堆在B阶段的调试管理和质量保证大纲实施情况进行了检查，认为中国实验快堆基本按照《中国实验快堆调试大纲（C版）》及《中国实验快堆调试质量保证大纲（B版）》的要求实施了B阶段的调试工作，调试管理有效，质量活动可控。检查组发现问题或提出要求如下：

1、对于仪表管理、文件修订管理及培训管理等程序文件，要结合实际情况，进一步修订。

2、抽查到的大部分工作许可证签字不全（隔离项、终止项没签），已经开始使用CBA（计算机辅助隔离系统），但相应的管理程序没有及时升版。

（二）中国实验快堆B阶段调试试验完成情况

检查组对中国实验快堆调试大纲规定的B阶段需完成的调试试验相关文件进行了检查，认为中国实验快堆已基本按要求完成了B阶段调试试验项目，试验基本达到了调试大纲对B阶段的要求和目的，初步验证了中国实验快堆在零功率状态下的相关性能，具体情况如下：

1. 中国实验快堆B阶段调试大纲规定试验项目共30项，截止2011年1月18日，已完成试验项目27项，剩余其中2项已向国家核安全局申请采用A阶段的试验结论，另外1项申请转到C阶段进行；由A阶段转移到B阶段的16项试验项目，完成13项，剩下试验项目已向国家核安全局申请转到C阶段进行。

2. 国家核安全局选定的6项调试试验监督项目，已全部完成，并通过华北核与辐射安全监督站的审查。

3. B阶段没有发生需要报告的核安全事件，所发生的异常均得到妥善处理。

4. B阶段的调试总结报告已通过中国原子能研究院的审查认可。

（三）中国实验快堆C阶段调试工作准备情况

检查组对中国实验快堆C阶段调试工作准备情况进行了检查，认为C阶段调试工作组织机构和职责分工已基本明确，编制了相关的文件，C阶段试验程序的编制情况能够满足要求。

检查组抽查了部分试验程序，发现如下问题，中国实验快堆在以后的工作中要认真改进：

1．个别试验验收准则不完善或不合适。

2．有些试验程序格式不符合相关试验程序编制管理程序的要求。

根据以上三个方面的检查结果，检查组认为，中国实验快堆B阶段的调试活动基本上符合调试大纲、质保大纲及核安全法规的要求，调试结论可信，满足调试大纲规定的验收要求；C阶段的调试工作已准备就绪。检查组认为，中国实验快堆“初始提升功率”控制点满足释放要求。
