# 中国地质调查局关于召开武当桐柏大别地区找矿方向研讨会通知

各有关单位：

近年来，武当-桐柏-大别地区找矿成果显著，安徽金寨沙坪沟钼矿等取得重大找矿突破，显示该区具有很好的找矿前景。为交流找矿成果，研讨成矿地质背景和找矿方向，部署“十二五”地质找矿工作，经中国地质调查局与安徽省国土资源厅协商，定于2011年9月25～28日在安徽省六安市召开武当－桐柏－大别地区找矿方向研讨会。现将有关事项通知如下。

**一、**会议组织

主办单位：中国地质调查局

安徽省国土资源厅

承办单位：中国地质调查局南京地质调查中心

中国地质调查局天津地质调查中心

中国地质调查局武汉地质调查中心

安徽省地质矿产勘查局

协办单位：安徽省地质调查院

**二、**会议内容

1. 成矿地质背景和找矿方向研讨。

2. 公益性工作思路和部署建议研讨。

3. 典型找矿成果交流。

4. 野外现场考察。

**三、**参加单位

（一）中国地质调查局：局领导，有关部室，天津、武汉、南京地质调查中心，发展研究中心，地科院资源所。

（二）安徽省国土资源厅。

（三）河南、安徽、湖北省地勘局及地调院。

（四）中国地质大学（北京）、中国地质大学（武汉）、南京大学、合肥工业大学、长安大学

（五）特邀单位及领导：

1. 国土资源部地质勘查司领导。

2. 河南、湖北国土资源厅领导。

（六）有关专家
