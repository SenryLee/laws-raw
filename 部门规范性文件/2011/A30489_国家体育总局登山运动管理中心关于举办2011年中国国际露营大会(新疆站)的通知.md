# 国家体育总局登山运动管理中心关于举办2011年中国国际露营大会(新疆站)的通知

## 国家体育总局登山运动管理中心关于举办2011年中国国际露营大会（新疆站）的通知

各省、自治区、直辖市户外运动俱乐部、大专院校及相关从业机构：

由国家体育总局、新疆维吾尔族自治区人民政府批准，国家体育总局登山运动管理中心、中国登山协会、新疆维吾尔族自治区体育局主办，新疆登山运动管理中心、新疆登山协会、乌鲁木齐天山大峡谷风景区承办的2011年中国国际露营大会（新疆站）将于2011年8月18日-21日在新疆维吾尔族自治区乌鲁木齐天山大峡谷风景区举办。现将竞赛规程发给你们，请认真组织，做好参赛工作。

特此通知。

附件：1、2011年中国国际露营大会（新疆站）规程

2、2011年中国国际露营大会（新疆站）报名表

国家体育总局登山运动管理中心

二〇一一年七月五日

2011年中国国际露营大会（新疆站）竞赛规程

**一、**比赛组织单位：

批准单位：国家体育总局

新疆维吾尔自治区人民政府

主办单位：中国登山协会

新疆维吾尔自治区体育局

承办单位：新疆登山运动管理中心

新疆登山协会

乌鲁木齐天山大峡谷景区管理集团有限公司

新疆国际体育旅行社

**二、**比赛时间和地点：

比赛时间：2011年8月18日-21日

比赛地点：新疆乌鲁木齐天山大峡谷风景区

**三、**比赛项目及组别

（一）竞赛项目：

（1）男女个人山地竞速赛

1、男子个人赛（20公里）

2、女子个人赛（15公里）

（2）山地自行车越野赛（21公里）

1、男子个人赛

2、女子个人赛

（二）群众参与体验赛事：

1. 扎帐篷比赛

2. 推手比赛

3. 走扁带比赛

4. 飞镖比赛

5. 魅力新疆摄影大赛

（三）表演项目：

1．乐队表演

2．露天电影

3.热气球表演

4.滑翔伞表演

5.航空模型

6.风筝

**四、**参赛资格：

（一）参赛以团队形式报名，不接受个人报名，每名运动员均可参加上述各项比赛。

（二）参赛队员须身体健康，无心、脑等不宜从事大强度运动的疾病或既往病史（须出具县级以上医院健康证明）。

（三）参赛队伍比赛期间须统一着装（全身统一着装）。

（四）群众参与体验组以团体或个人报名，须身体健康。

**五、**比赛规则：（另行发布）。

山地竞速参照中国登山协会制定的山地竞速项目竞赛规则

山地自行车参照本组委会制定的山地自行车越野赛比赛规则

本会制定的群众参与体验赛事的各项规则（包括）

1.　　魅力新疆摄影大赛评奖办法

2.　　扎帐篷比赛规则

3.　　推手比赛规则

4.　　喝啤酒大赛规则

5.　　飞镖比赛规则

6.　　走扁带比赛规则

**六、**录取名次和奖励办法：

（一）在规定的时间内，按要求完成当天的赛程，计成绩。

（二）最终名次按各项目比赛的用时由少到多排列，时间少者名次列前。若成绩相等，则名次并列，无下一名次；群众体验项目按各项目规则要求产生名次。

（三）总奖金 11.2万元人民币。每项比赛分别录取前八名，颁发证书和奖金；摄影大赛1等奖1名、2等奖2名、3等奖3名、优胜奖5名颁发证书和奖金。

**七、**参赛要求：

（一）以各省、区（市）、户外运动、俱乐部或其他组织为单位，各参赛队除运动员外，可报领队1人，教练员1至2人。

（二）竞赛装备器材：竞赛装备器材除各项目竞委会准备的之外，运动员个人装备要由自己准备。

（三）报名时间：报名时间截止到8月1日，逾期不予报名。

（四）参赛运动员有专业技能技术基础，身体健康，有体检健康证明。

（五）参赛运动员年龄要求在18至55周岁，群众参与体验赛事以各项规则要求。

（六）各项目按各小项录取前八名，发放获奖证书、奖杯、奖金或奖品。

（七）各参赛代表团统一报名至新疆登山运动管理中心“国际露营大会组委会”（各项目具体竞赛规程及报名表另发）。

（八）内地各代表团参赛运动队往返交通自理， 8月18日、8月21日晚食宿由大会负责；赛事期间露营装备、伙食自理，大会按照各俱乐部、代表队人数提供季节水果、蔬菜等；由乌鲁木齐市往返天山大峡谷交通由组委会负责。

（九）赛会为运动员投保人身意外险，本次赛会投保体育赛事组织险。

**九、**报名方法：

（一）竞赛项目

各单位按要求填写报名表（见附件），加盖所代表单位的公章，并将报名表于2011年8月1日前以传真或电子邮件（有公章影印的扫描件）方式报组委会。组委会根据区域分布及运动经历确定参赛运动队资格，以收到组委会报名确认函为获得参赛资格标准。

（二）群众体验项目

群众体验项目以团体或个人形式报名，报名要求见单项比赛竞赛规则，具体日程安排以秩序册及赛前技术会发布为准。
