# 教育部办公厅关于举办2011继续教育数字化学习资源共享与服务成果展览会的通知

## 教育部办公厅关于举办2011继续教育数字化学习资源共享与服务成果展览会的通知（教职成厅函[2011]29号）

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局，有关部门（单位）教育（人事）司（局），部属各高等学校，有关单位：

为贯彻落实《国家中长期教育改革和发展规划纲要（2010-2020年）》提出的“到2020年，基本实现教育现代化，基本形成学习型社会，进入人力资源强国行列”的战略目标，展示、宣传和推广近年来我国继续教育在数字化学习资源建设与服务方面取得的优秀成果，进一步推动全社会优质继续教育数字化学习资源的开放与共享，加快发展继续教育，推动学习型社会建设，我部决定举办“2011继续教育数字化学习资源共享与服务成果展览会”（以下简称展会）。现将有关事宜通知如下：

**一、**展会主题及意义

展会以“促进数字化学习资源建设与开放，搭建优质资源共享与交流平台，服务全民学习与终身学习，推动学习型社会建设”为主题。集中展示我国数字化学习资源建设与服务取得的重要成果，展示数字化学习资源在促进教育教学改革、终身学习、教育信息化等方面的主要成就，建立数字化学习资源建设、开放、共享、交流的新机制，搭建数字化学习资源的供需与交流平台，推进全社会优质数字化学习资源的开放与共享，促进继续教育更好地服务经济社会发展和百姓多样化学习需求，为建设人人皆学、时时能学、处处可学的学习型社会创造条件。

**二、**展会主要内容

展会主要展示不同类型、层次的优质数字化学习资源；各类优秀的数字化教学平台、管理平台与服务平台；数字化学习资源在学习型城市、农村、部队、行业、企业、社区建设中的典型应用模式与服务成果；现代信息技术在创新教学模式、学习模式、服务模式中的典型成果；信息社会的未来学习模式与学习组织。

展会期间将举办数字化学习资源及继续教育项目的供需洽谈交流会，开展系列继续教育项目启动仪式和宣传活动。同时，相关机构和学术团体也将举办以继续教育、终身学习为主题的系列交流会。

展会期间将举办社会公众参与的数字化学习体验活动，并免费发放资源卡和学习卡。

**三、**展会组织机构

主办单位：教育部

承办单位：高等教育出版社、全国高校现代远程教育协作组

教育部成立展会组委会，负责具体组织实施工作。

**四、**展会时间、地点

展会于2011年7月 16日至18日在北京国家会议中心举办。

**五、**展区分布

设“中心区”、“地方区”、“行业区”、“高校区”、“企业区”、“出版区”六个展区。

“中心区”主要展示三方面内容：数字化学习资源与服务平台（包括数字化资源中心项目，百所高校资源开放项目，精品课程，有关省市教育资源库，出版社有关资源等）；虚拟学习环境与场景（包括网络虚拟现实学习环境，未来教室，以及多网融合、多屏兼容的学习模式，社区、乡村、行业、企业、军营等不同类型的数字化学习中心学习模式，家庭学习模式，远程呼叫中心服务模式等）；典型应用案例（学习型行业案例，学习型城市案例，现代远程教育试点高校案例，网上考试和质量监管案例）等。

其他展区由参展单位自主设计，展示在继续教育数字化资源建设与服务方面的突出成果。

**六、**参展办法和观摩要求

各省级教育行政部门、有关部门（单位）教育（人事）司（局）负责向所属高等学校、职业学校、相关培训机构、企业、协会转发本通知，动员组织在数字化学习资源建设与应用方面取得显著成效的单位报名参加。

1．部属高校和69所现代远程教育试点高校可直接报名参展，地方高校、省地级电大经省级教育行政主管部门推荐集中参展。

2. 地方、行业、企业、协会等方面有关资源建设、服务，软件研发的机构，以及其他符合参展条件的机构可向组委会办公室申请参展。

各参展单位要高度重视，认真准备，布展工作要围绕主题，重点突出，精心设计，服从组委会的统一部署和要求。

展会向社会开放，各有关单位要积极发动、组织相关人员参观展会并参加相关活动。公众可自由观摩、体验。

**七、**报名审批办法

组委会将组织专家对申请参展单位及参展项目进行审核。审核通过的单位，组委会将正式通知参展。

参展单位须填写参展申请表（见附件1）和参展资源、软件统计表（见附件2、3），参展申请表接受截止日期为2011年6月10日。参展资源、软件统计表接受截至日期为2011年6月20日。具体参展要求及参展办法见附件4。

展会申请资料可从中国现代远程与继续教育网首页（http：//www.cdce.cn/）下载。

附件4：

参展条件及参展办法

**一、**参展条件

1. 参展单位应有独立的法人资质，并符合“展会主要内容”的范围。

2. 参展单位所展展品，必须符合国家有关知识产权的法律法规。

3. 展出内容应突出反映数字化学习资源建设及服务取得的优秀成果。

4. 展区采用统一规划、统一部署的方式，展示的内容应是组委会批准的内容，并由组委会指定参展位置和面积。

**二、**参展办法

1. 参展单位应准确详细填写《参展申请表》、《参展资源统计表》和《参展软件统计表》，并在规定时间发送电子邮件至组委会联系人信箱（liuhy@hep.com.cn）。

2. 参展单位在得到组委会确认后，双方签订参展合同书。并请参展单位按照合同书要求将展位费汇至组委会指定的开户银行帐号，同时将汇款单传真至组委会办公室（报到时统一领取发票）。

3. 展会设中心展区、地方展区、行业与企业展区、现代远程教育试点高校展区、学校展区、数字化资源研发与服务单位展区。

“中心区”集中展示优秀的数字化学习资源，典型的应用与服务成果，数字化学习的发展趋势与前景。其它展区由参展单位展示本单位在数字化学习资源建设、共享、服务等方面取得的优秀成果。

4. 组委会办公室在确认参展合同书和相关费用后，将向参展单位寄发《展位确认书》和《参展商手册》，内含展会主要活动日程安排、食宿安排、布展、后勤服务等相关规定和内容。参展单位应按照要求认真及时填写、提交相关表格，高效地完成参展活动。
