# 中国气象局关于发布《船舶自动气象观测数据格式》等6项气象行业标准的通告

## 中国气象局关于发布《船舶自动气象观测数据格式》等6项气象行业标准的通告（2011年8月30日）

国务院各部委、各直属机构办公厅（室），黑龙江农垦总局、森工总局，新疆生产建设兵团气象局，各省、自治区、直辖市气象局，各直属单位，各内设机构：

中国气象局批准《船舶自动气象观测数据格式》等6项气象行业标准（见附件），现予以公布，自2011年9月1日起实施。

附件：《船舶自动气象观测数据格式》等6项气象行业标准

|  |  |  |
| --- | --- | --- |
| 序号 | 标准编号 | 标准名称 |
| 1 | QX/T 122-2011 | 船舶自动气象观测数据格式 |
| 2 | QX/T 123-2011 | 无线电探空资料质量控制 |
| 3 | QX/T 124-2011 | 大气成分观测资料分类与编码 |
| 4 | QX/T 125-2011 | 温室气体本底观测术语 |
| 5 | QX/T 126-2011 | 空盒气压表（计）示值检定箱测试方法 |
| 6 | QX/T 127-2011 | 气象卫星定量产品质量评价指标和评估报告要求 |
