# 国家食品药品监督管理局行政受理服务中心公告第81号——关于2012年元旦放假安排的公告

## 国家食品药品监督管理局行政受理服务中心公告（第81号）

关于2012年元旦放假安排的公告

根据《国务院办公厅关于2012年部分节假日安排的通知》，现将国家食品药品监督管理局行政受理服务中心2012年元旦放假期间对外受理工作安排通知如下：

2011年12月31日（星期六）内部整理，不对外受理。2012年1月1日-1月3日放假。2012年1月4日起正常受理。

国家食品药品监督管理局行政受理服务中心

二〇一一年十二月二十日
