# 国家认监委关于组织2012年检验检疫标准化工作计划研讨的通知

各检验检疫标准化专业委，国际检验检疫标准与技术法规研究中心，福建、江西、广东、广西、陕西、新疆检验检疫局，中国检验检疫科学研究院：

为总结2011年检验检疫标准化专业委工作进展，研究布置2012年检验检疫标准化重点工作，经研究，拟于2011年12月8-9日在京组织2012年检验检疫标准化工作计划研讨。现将有关事项通知如下：

**一、**会议内容

1.总结各专业委2011年度计划完成情况；

2.研讨并部署2012年相关重点工作；

3.布置年底前专业委应完成的相关工作。

**二、**参会人员

1.检验检疫标准化专业委秘书长、副秘书长及秘书1名。各专业委秘书长、副秘书长名单见附件。
