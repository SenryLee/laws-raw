# 国家发展和改革委员会东北振兴司关于确定全国老工业基地调整改造规划研究课题承担单位的公告

为做好《全国老工业基地调整改造规划》（“十二五”国家级专项规划）的研究编制工作，我司于2010年12月2日在国家发展改革委门户网站上发布了《关于公开征选全国老工业基地调整改造规划研究课题承担单位的公告》。本次研究课题公开征选活动得到了有关高校和研究单位的积极响应和大力支持，共收到有效申报材料76份。经过对申报材料进行认真、严格评审，综合考虑申报团队的综合实力和研究基础、研究思路的把握和设计、研究内容的深度和研究方案的可行性等因素，我们确定了本次课题公开征选的入选单位，具体如下：

**一、**“十二五”时期老工业基地调整改造战略定位与总体思路研究

中国科学院地理科学与资源研究所（金凤君团队）

**二、**老工业基地产业结构调整研究

东北财经大学（肖兴志团队）

**三、**老工业基地城市综合功能提升研究

中国科学院东北地理与农业生态研究所（张平宇团队）

**四、**中西部老工业基地调整改造专题研究

湖北省社会科学院（姚莉团队）

重庆大学（陈仲常团队）

西北大学（任保平团队）

**五、**老工业基地调整改造政策措施研究

东北师范大学（杨大光团队）

吉林大学（徐传谌团队）

请入选单位认真准备课题研究大纲，我们将于2月中旬召开会议，听取各单位研究情况汇报，并组织开展调研。请入选单位尽快与我们联系。

感谢各申报单位对本次课题公开征选活动的热情支持！欢迎大家继续关注东北振兴司相关课题公开征选工作。
