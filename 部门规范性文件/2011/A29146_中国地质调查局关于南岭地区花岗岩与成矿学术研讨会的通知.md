# 中国地质调查局关于南岭地区花岗岩与成矿学术研讨会的通知

各有关单位：

1999年国土资源大调查实施以来，中国地质调查局组织有关院校、科研和生产单位联合开展南岭地区花岗岩与成矿攻关研究，取得了一批重要成果，并在指导地质找矿方面取得显著效果。为了进一步总结研究成果，提高成矿理论研究水平，指导南岭地区找矿突破战略行动的实施，经中国地质调查局与南京大学充分协商，定于2011年9月5日-8日在南京共同召开南岭地区花岗岩与成矿学术研讨会。有关事项通知如下。

**一、**会议组织

主办单位：中国地质调查局

南京大学

承办单位：中国地质调查局武汉地质调查中心

中国地质调查局南京地质调查中心

南京大学地球科学与工程学院

南京大学内生金属矿床成矿机制研究国家重点实验室

**三、**会议主题

（一）花岗岩演化与成矿关系研究

1. 南岭地区花岗岩时空演化与成矿作用（南京大学陈骏）；

2. 南岭地区花岗岩成矿能力研究（南京大学王汝成）；

3. 南岭地区成矿花岗岩特征研究（武汉地调中心王晓地）；

4. 南岭地区花岗岩成岩成矿年代学研究（南京大学陆建军）；

5. 南岭地区燕山期复式岩体中补体与主体的成因联系及其成矿意义（北京大学陈斌）。

（二）成矿规律与找矿预测研究

1. 南岭地区成矿规律与找矿方向（武汉地调中心付建明）；

2. 南岭地区钨锡金属矿床分布规律、矿床模型及成矿背景（地科院资源所毛景文）；

3. 南岭成矿体系、全位成矿缺位找矿及深部勘查技术与方法探讨（地科院资源所王登红）；

4. 湘南地区矿产资源潜力评价 （湖南地调院黄革非）；

5. 广东始兴地区找矿实践与探索（南京地调中心肖惠良）。

（三）矿产资源调查与深部找矿

1. 南岭地区找矿重要发现与进展（中国地质调查局）；

2. 湘南地区矿产调查评价与成果（湖南地调院）；

3. 粤北地区矿产调查评价与成果（广东地调院）；

4. 赣南地区矿产调查评价与成果（江西地调院）；

5. 桂北地区矿产调查评价与成果（广西地调院）；

6. 危机矿山深部找矿进展与成果（地调局发展中心）。

**四、**参加会议单位

（一）中国地质调查局：局领导，有关部室，武汉、南京地质调查中心，发展研究中心，地科院资源所。

（二）南京大学：校领导，南京大学地球科学与工程学院，南京大学内生金属矿床成矿机制研究国家重点实验室。

（三）项目承担单位：湖南地调院、广东地调院、广西地调院、江西地调院，有色湖南局、有色地质调查中心，北京大学、中国地质大学（北京）、中国地质大学（武汉）、中山大学、东华理工大学。

（四）特邀单位及领导：

3. 省区地勘局：湖南、广东、广西、江西地勘局领导。
