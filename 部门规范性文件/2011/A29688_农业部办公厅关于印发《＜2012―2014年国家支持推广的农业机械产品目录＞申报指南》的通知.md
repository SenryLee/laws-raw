# 农业部办公厅关于印发《＜2012―2014年国家支持推广的农业机械产品目录＞申报指南》的通知

## 农业部办公厅关于印发《〈2012-2014年国家支持推广的农业机械产品目录〉申报指南》的通知（农办机［2011］42号）

各省、自治区、直辖市农机管理局（办公室）：

《2009-2011年国家支持推广的农业机械产品目录》（包括年度调整中增加的产品）将于今年底到期。为做好《2012-2014年国家支持推广的农业机械产品目录》的编制工作，按照农业部、财政部、国家发展和改革委员会联合颁布的《国家支持推广的农业机械产品目录管理办法》（农机发［2005］7号），我部编制了《〈2012-2014年国家支持推广的农业机械产品目录〉申报指南》（以下简称《指南》），现予印发。请各地按照《指南》要求，认真组织好相关企业申报和产品审核推荐工作，并在规定时间内向我部报送相关材料。《指南》及相关附件除发布本书面文本外，同时在中国农业机械化信息网（ht-tp：//www.amic.agri.gov.cn）发布。

附件：《2012-2014年国家支持推广的农业机械产品目录》申报指南（略）

二○一一年七月二十五日
