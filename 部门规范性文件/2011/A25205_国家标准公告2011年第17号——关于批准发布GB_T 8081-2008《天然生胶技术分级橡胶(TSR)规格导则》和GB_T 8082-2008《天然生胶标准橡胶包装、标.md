# 国家标准公告2011年第17号——关于批准发布GB/T 8081-2008《天然生胶技术分级橡胶(TSR)规格导则》和GB/T 8082-2008《天然生胶标准橡胶包装、标志、贮存和运输》2项国家标准第1号修改单的公告

## 国家标准公告（2011年第17号）

关于批准发布GB/T 8081-2008《天然生胶 技术分级橡胶（TSR）规格导则》和

GB/T 8082-2008《天然生胶 标准橡胶包装、标志、贮存和运输》2项国家标准第1号修改单的公告

国家标准化管理委员会批准GB/T 8081-2008《天然生胶 技术分级橡胶（TSR）规格导则》和GB/T 8082-2008《天然生胶 标准橡胶包装、标志、贮存和运输》2项国家标准第1号修改单，自2011年12月20日起实施，现予以公布（见附件）。

二〇一一年十一月十日

附件：

GB/T 8081-2008《天然生胶 技术分级橡胶（TSR）规格导则》

国家标准第1号修改单

**一、**标准第6章“表2”增加恒黏胶（SCR CV）、浅色胶（SCR L）、全乳胶（SCR WF）三个规格，TSR的技术要求为：

|  |  |  |  |
| --- | --- | --- | --- |
| 性能 | 恒黏胶  （SCR CV） | 浅色胶  （SCR L） | 全乳胶  （ SCR WF） |
| 颜色标志，色泽 | 绿 | 绿 | 绿 |
| 留在45μm筛上的杂质（质量分数）/%，最大值 | 0.05 | 0.05 | 0.05 |
| 灰分（质量分数）/%，最大值 | 0.5 | 0.5 | 0.5 |
| 氮含量（质量分数）/%，最大值 | 0.6 | 0.6 | 0.6 |
| 挥发分（质量分数）/%，最大值 | 0.8 | 0.8 | 0.8 |
| 塑性初值（P0），最小值 | - | 30 | 30 |
| 塑性保持率（PRI），最小值 | 60 | 60 | 60 |
| 拉维邦颜色指数，最大值 | - | 6 | - |
| 门尼黏度，ML（1＋4）100℃ | 60±5  （见注1） | - | - |

**二、**标准第8章中“对于未改、扩建的企业生产的胶包，每个胶包的净含量可按40kg±0.2kg执行，但自2012年1月1日起生产的胶包，每个胶包的净含量应按本标准的规定执行。”修改为：

对于未改、扩建的企业生产的胶包，每个胶包的净含量可按40kg±0.2kg执行，但自2015年1月1日起生产的胶包，每个胶包净含量40kg±0.2kg的包装规格应停止执行。

GB/T 8082-2008《天然生胶 标准橡胶包装、标志、贮存和运输》

国家标准第1号修改单

**一、**标准“3.1.1胶包净含量”修改为：

每个胶包的净含量为33.3kg或35kg（允许±0.5%），对于未改、扩建的企业生产的胶包，每个胶包的净含量可按40kg±0.2kg执行，但自2015年1月1日起生产的胶包，每个胶包净含量40kg±0.2kg的包装规格应停止执行。
