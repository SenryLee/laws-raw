# 中国科学院计划财务局关于报送2012年度国家科学技术奖励推荐项目(人选)材料的通知

## 中国科学院计划财务局关于报送2012年度国家科学技术奖励推荐项目（人选）材料的通知（计字〔2011〕232号）

院属各有关单位：

为贯彻国家科学技术奖励制度改革，做好我院2012年度国家科学技术奖励推荐工作，根据国家科学技术奖励工作办公室《关于2012年度国家科学技术奖励推荐工作的通知》（国科奖字〔2011〕64号） 和我院各专业评审组的推荐意见，现将报送2012年度国家科学技术奖励推荐项目（人选）材料的有关事宜通知如下：

**一、**推荐项目（人选）

院根据国家科学技术奖励工作办公室分配的指标，共推荐45项国家科学技术奖励项目。推荐国家最高科学技术奖候选人2人、国际科学技术合作奖候选人3人（不占指标）。具体推荐项目及候选人详见《院推荐2012年度国家科学技术奖励项目（人选）表》。院对推荐的项目要在全院范围内进行公示，各有关单位应对院推荐的项目主要完成人所在单位相应进行公示，公示无异议或虽有异议但经处理后再次公示无异议的项目方可推荐国家科学技术奖励；涉及国家安全与国防类（专用）和涉密项目，在适当范围内公示。

**二、**推荐材料

1. 请严格按照国家科学技术奖励工作办公室推荐工作的通知和《2012年度国家科学技术奖励推荐工作手册》的要求填写《推荐书》。国家科学技术奖励推荐号和校验码待2012年1月16日国家科学技术奖励管理业务平台开通后由院下达，非国家安全与国防类国家科学技术奖励推荐项目（人选）的推荐材料均需在登录国家科学技术奖励管理业务平台（http：//168.160.158.231/jltj）后在线填写和上传。国家安全与国防类（专用）和涉密项目推荐材料纸质版及电子版材料须由专人报送我局，其中电子版材料只能以光盘形式报送，一律不得通过网络报送。

国家科学技术奖励工作办公室《关于2012年度国家科学技术奖励推荐工作的通知》（国科奖字〔2011〕64号）和《2012年度国家科学技术奖励推荐工作手册》请登录国家科学技术奖励工作办公室门户网站www.nosta.gov.cn下载。

2.《推荐书》“推荐单位意见”栏，请代院填写，最后一段统一填写为“经评审，同意推荐该项目（或候选人）为国家X奖（国家最高科学技术奖、国际科学技术合作奖或国家自然科学奖、国家技术发明奖、国家科技进步奖）X等奖”。推荐日期统一填写为2012年2月27日。“推荐单位意见”栏内不要加盖项目完成单位公章，由院统一加盖主管部门公章。

3. 推荐国家科学技术奖励项目（人选）的纸质版材料和电子版材料，须经院组织审核通过后推荐；非国家安全与国防类国家科学技术奖励项目（人选）的电子版材料，需同时登录院ARP系统“知识产权管理”模块进行提交（只提交推荐书主件）。

4. 书面《推荐书》3套（含原始件1套，复印件2套，其中推荐书主件和附件一并装订成册）；国家最高科学技术奖候选人还需报送《推荐书》从基本情况到推荐意见九个部分内容合订简本31套；国家科学技术进步奖科普类项目还需附4套科普作品；专用项目还需报送推荐书首页和项目简介各1份。

**三、**报送时间

审核修改时间：2012年2月13-14日报送审核修改国家自然科学奖项目；2012年2月15-16日报送审核修改国家技术发明奖、国家科学技术进步奖项目和国家最高科学技术奖、国际科学技术合作奖。

正式报送时间：2月20-21日报送国家自然科学奖项目；2月22-23日报送国家技术发明奖、国家科学技术进步奖项目和国家最高科学技术奖、国际科学技术合作奖。

推荐材料报送不得邮寄。为扩大推荐指标，鼓励从地方或部门等渠道进行推荐，但须及时报院备案，以便及时通知调整推荐项目。

报送地址：院计划财务局知识产权处（340室）。
