# 中国地质调查局关于2011年度地下水分析技术培训会的通知

各有关实验室：

为了持续提高地下水样品分析测试技术水平，加强承担地下水污染调查样品分析任务实验室的技术能力建设，定于2011年12月举办地下水分析技术培训研讨会议。现将有关事宜通知如下：

**一、**会议组织

组织单位：中国地质调查局科外部、水环部

承办单位：国家地质实验测试中心

**二、**会议内容

|  |  |  |
| --- | --- | --- |
| 序号 | 内容 | 时间安排 |
|  |  |  |
| --- | --- | --- |
| 1 | 地调局十二五地下水污染调查评价工作部署 | 2012.12.21， 9：00-10：00 |
| 2 | 地下水污染地质调查评价必测有机指标的检测技术方法解读 | 2012.12.21， 10：00-17：00 |
| 3 | 有机分析结果判别与质量控制 | 2012.12.22， 8：30-15：00 |
| 4 | 安排地下水无机组分检测能力验证工作与样品发放 | 2012.12.22， 15：00-15：30 |
| 5 | 有机分析标准分析方法征求意见与研讨 | 2012.12.22， 15：40-17：00 |

**三、**参加人员

已获得和拟申请地下水污染调查测试能力资格认定实验室的地下水有机分析领域授权签字人和有机分析技术人员。

**四、**会议时间和地点

会议日期：2011年12月21日— 12月22日，12月20日报到。

会议地点：北京世纪国建宾馆，北京市海淀区车公庄西路10号，010-58329999 （总机）。

**五、**会议费用

会议费：800元/人/班，食宿统一安排，费用自理。

**六、**重要提示

1、各单位务必回执，并于12月16日前以电子邮件或传真方式反馈给会议联系人（附件），会务组将根据收到回执的先后次序安排住宿等会务工作，因近年末，会议用房紧张，逾期未反馈回执的代表，住宿安排难以保证。

2、“地下水无机组分检测能力验证计划”要求复查换证和申请地下水污染调查无机测试能力资格认定的实验室必须参加，其他实验室自愿参加。不参加本次会议的实验室，也请反馈回执，我们将依据回执邮寄能力验证样品，逾期不补。

3、会议不安排接站，请代表自行前往。
