# 中国保险监督管理委员会培训中心关于2011年公开招聘应届高校毕业生资格复审、笔试及面试安排的公告

## 中国保险监督管理委员会培训中心关于2011年公开招聘应届高校毕业生资格复审、笔试及面试安排的公告（保监公告〔2011〕9号　2011年3月3日）

中国保监会培训中心2011年公开招聘应届高校毕业生的报名、审核工作已截止，经研究现已确定参加笔试人员名单（见附件一、附件二），为做好考试组织工作，现将有关事项公告如下：

**一、**时间安排

资格复审时间：2011年3月11日上午8：30-11：00；

笔试时间安排：2011年3月12日上午9：00-11：30；

面试时间安排：2011年3月13日上午9：00 ，入围面试人员将在2011年3月12日晚20：00前收到电话通知，请保持手机处于开机状态。面试顺序由现场抽签决定。

**二、**考试确认

请入围笔试的考生于2011年3月6日前，将是否参加笔试及面试的意见以电子邮件方式发送到jun_li_01@circ.gov.cn进行确认。标题格式为：“学校＋姓名＋确认参加”，邮件含以下个人信息：身份证号码、报考职位、目前所在学校、手机号码、需要说明的其他问题。

**三、**资格复审

资格复审合格者领取准考证。缺少材料或经审核与个人信息不符的考生，取消笔试资格。

考生须携带以下材料：

（一） 教育培训岗：

1. 本人身份证原件及复印件；

2. 学生证原件及复印件；

3. 英语六级证书原件及复印件；

4. 1寸免冠正面彩照2张；

（二） 综合管理岗

1. 本人身份证原件及复印件；

2. 学生证原件及复印件；

3. 1寸免冠正面彩照2张；

4. 提供一张由本人制作的视频作品光盘。

**四、**注意事项

（一）笔试、面试当天，入围考生请携带本人身份证和准考证，提前20分钟到达考试地点。考试开始后30分钟内，不得交卷离场；开始考试30分钟后，迟到人员不得入场。距离考试结束15分钟内不得交卷离场。

（二） 考生考试时请自带文具，不得携带手机等通讯工具进入考场，自行携带的须将通讯工具关闭，并交考场管理人员统一管理。

（三） 考生参加考试期间的食宿、交通费用由考生自理，请考生安排好行程，并注意安全。

**五、**资格复审、笔试、面试地点及乘车路线

资格复审、笔试及面试地点为北京市西城区金融大街15号鑫茂大厦（西二环月坛北桥东南角），中国保监会办公楼三层302会议室（从大楼西门经步行梯到三层）。

1. 公交路线：乘坐21路、423路、456路、939路、618路到阜成门南站。

2. 地铁路线：地铁2号线阜成门C口出，向南直行。

联系电话：010－66288058；

联系人：李珺
