# 国家知识产权局保护协调司关于举办第三期“知识产权战略大讲堂”活动的通知

各有关单位：

为进一步宣传国家知识产权战略，充分研讨知识产权战略实施过程中遇到的新情况新问题，促进知识产权战略更有效实施，国家知识产权战略实施工作部际联席会议办公室成功举办了两期“知识产权战略大讲堂”，分别邀请国家知识产权局前任局长王景川、中南财经政法大学校长吴汉东做了题为《国家知识产权战略的回顾与展望》、《知识产权国际发展态势与中国应对策略》的报告。鉴于各单位同志对本活动反响热烈，现决定举办第三期“知识产权战略大讲堂”活动。

现将有关事宜通知如下：

**一、**主题

中国版权制度之选择

**二、**主讲人

王自强

中华人民共和国新闻出版总署（国家版权局）法规司司长

**三、**时间

2011年11月16日上午9：00-11：00

**四、**地点

国家知识产权局1号楼3层报告厅

请各单位根据情况安排相关人员参加本次活动，并请提前将参加人员名单发给联系人。

特此通知。

附件：王自强简历

国家知识产权局保护协调司

二〇一一年十一月九日

附件：

王自强简历

王自强，现任中华人民共和国新闻出版总署（国家版权局）法规司司长。王自强同志长期从事版权行政管理工作，历任新闻出版总署（国家版权局）版权管理司处长、副司长、司长及中国国家版权局新闻发言人。此外，他还兼任中国版权协会副理事长，中国知识产权研究会副理事长，中国电影版权保护协会名誉理事长。

曾组织参与《中华人民共和国著作权法》及其配套行政法规、规章的制定及修改工作。曾担任联合国教科文组织《版权公报》（中文版）主编。曾参与版权战略等多个重大课题研究。
