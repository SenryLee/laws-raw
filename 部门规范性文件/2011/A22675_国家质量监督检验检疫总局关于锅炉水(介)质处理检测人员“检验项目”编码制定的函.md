# 国家质量监督检验检疫总局关于锅炉水(介)质处理检测人员“检验项目”编码制定的函

## 国家质量监督检验检疫总局关于锅炉水（介）质处理检测人员“检验项目”编码制定的函（（2011）质检特便字第2033号）

中国锅炉水处理协会：

你协会《关于锅炉水（介）质处理检测人员“检验项目”编码制定的请示》收悉，经研究，现回复如下：

1、同意你协会提出的对锅炉水（介）质处理检测人员证书中“检验检测项目”实施编码建议，并在证书上使用下述编码：

|  |  |  |
| --- | --- | --- |
| 序号 | 项目 | 编码 |
| 1 | 锅炉水处理检测员 | GSY |
| 2 | 有机热载体检测员 | GRY |
| 3 | 锅炉水处理检测师 | GSS |
| 4 | 有机热载体检测师 | GRS |
| 5 | 高级检测师（双向） | GSR |
| 6 | 高级检测师（电站锅炉水处理） | GSG |

2、你协会和中国特种设备检测研究院法规标准部在修订《锅炉水（介）质处理检测人员考核规则》时应将上述内容编入。

二〇一一年十二月二十九日
