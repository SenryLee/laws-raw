# 民政部、国家体委、国家教委关于1987年3月举办首届中国特殊奥林匹克运动会的通知

## 民政部、国家体委、国家教委关于1987年3月举办首届中国特殊奥林匹克运动会的通知（[86]民城函第267号　1986年10月10日）

各省、自治区、直辖市民政厅(局)、体委、教委：

根据国际特殊奥运会的宗旨，为使所有弱智人士都能参加各种形式的体育比赛活动，给他们创造锻炼身体、显示勇气的机会，体现我国政府对弱智人士的关怀，加强弱智人的康复工作，发展我国特殊奥林匹克运动，并为组团参加1987年8月第七届国际特殊奥运会作好准备，民政部、国家体委、国家教委同意中国智残人体育协会的决定，于1987年3月举办首届中国特殊奥林匹克运动会(以下简称特奥会)。现将有关事项通知如下：

**一、**特奥会的规模和名额分配。根据我国弱智人体育运动开展较晚和尚未普及的实际情况，这次特奥会的规模不宜过大，参赛运动员为300名，教练员和工作人员100名，观察员69名。由开展这项运动比较有基础的北京、上海、天津、江苏、广东、湖南六省、市和广州、南京、武汉、长沙、西安、沈阳六市派出代表队参加。其他省、自治区各派三名观察员观摩比赛。运动员和教练员、工作人员名额分配(见附件一)。

**二、**运动员条件。凡8岁以上、智商在70以下的弱智人均可参加比赛。根据国际特奥会的宗旨，运动员要按运动能力、智商高低和残疾程度分组报名。每个参赛的年龄组中都要有运动能力不同、智商及残疾度不同(轻度、中度、重度)的运动员。

运动员必须经过医生诊断确认为弱智者。如发现弄虚作假的，一律取消比赛资格。

**三、**比赛项目、办法和规则。有关比赛项目等事宜，我们同意中国智残人体育协会制定的《首届中国特殊奥运会规程》(见附件二)，望各地遵照执行。

**四、**报名时间和地点。首届中国特奥会定于1987年3月25日至30日在广东深圳市举办。本届特奥会由广东省深圳市民政局、体委、教育局共同承办。参赛单位务必于1987年1月底以前将《首届中国特奥会报名表》(见附件三)和《弱智运动员登记表》(见附件四)分别寄广东省深圳市民政局、体委。各省、自治区观察员名单也一并报出。

**五、**运动员服装和队旗。参赛的运动员服装和队旗必须有特殊奥运会的标志 (见附件五)。

**六、**经费。各地代表队和观察员往返路费自理。食、宿费由大会统一解决。

各地要加强对弱智人体育运动的组织领导，积极开展这项运动，认真选拔好运动员参加本届全国特奥会比赛，为促进社会主义精神文明建设，为进一步发展我国的弱智人体育运动作出贡献。

附：

首届中国特殊奥运会规程

**一、**主办单位：中国智残人体育协会。

**二、**参赛办法：

1．参加单位：北京、上海、天津、广东、江苏、湖南等6省、直辖市和广州、南京、长沙、武汉、西安、沈阳等6市组队参加比赛，其他各省、自治区派观察员观摩比赛。

2．报名人数：每个参赛单位领队1人，教练员、运动员和工作人员总人数不得超过名额分配数。

3．运动员条件：凡8岁以上，智商在70以下的弱智人均可参加比赛。运动员要按照运动能力、智商高低和残疾程度分组报名。每个参赛年龄组中要有运动能力不同、残疾程度不同的运动员。

4．报名运动员可报名参加二个单项兼一项接力比赛。

**三、**比赛办法：

1．年龄组：

```
┌───────┬─────────┬──────────────────┐

│　　　组别　　│　　个人项目　　　│　　　　集体项目　　　　　│

├───────┼─────────┼──────────────────┤

│　　少年一组　│　　8岁至11岁│　　　　　　　　　　　　　　　　　　│

│　　少年二组　│　　12岁至15岁　　│　　　　　　　　　　　　　　　　　　│

│　　青年组　　│　　16岁至21岁　　│　　16岁至21岁　　　　　　　　　　　│

│　　成年组　　│　　22岁以上　　　│　　22岁以上　　　　　　　　　　　　│

├───────┴─────────┴──────────────────┤

│备注：当某组内队员数不足以进行比赛时，该组队员应安排到下一较高年龄组比赛│

└────────────────────────────────────┘
```

2．竞赛项目

径赛：①男、女少年组：

50米、100米、200米、400米、800米、4×100米接力；

②男、女青年组、成年组：

100米、200米、400米、800米、1500米、4×100米接力。

田赛：①男、女少年组：

跳远、立定跳远、铅球、垒球掷远；

②男、女青年组、成年组：

跳高、跳远、立定跳远、铅球(男4公斤，女2公斤)。

足球：①个人技术：各年龄组的传球、运球、掷球、射门；

②团体对抗赛：(男子)场地为40×30米，6人制，用4号球或5号球，全场比赛30分钟。

乒乓球：各年龄组的男女单打和团体赛。

3．比赛规则：

①严格采取国际特殊奥运会制定的《特殊奥林匹克运动竞赛规则》。

②按性别、年龄及运动能力和智商高低、残疾程度分组。根据预报成绩，每组内队员间的成绩之差不能超过10％；每组运动员为3—8人。都要有残疾轻度、残疾中度、残疾重度的运动员。

4．运动员服装和队旗：

各省、自治区、直辖市和各市的弱智人体育运动队队旗和运动员的服装，由各省、自治区、直辖市和各市自己制发。队旗和运动员服装必须有特殊奥运会的标志。
