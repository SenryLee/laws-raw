# 国家药品监督管理局药品注册司已批准临床研究的新药品种公告(第20号)－－公布L－洒石酸托特罗定等药品

## 国家药品监督管理局药品注册司已批准临床研究的新药品种公告（第20号）(药管注[2000]221号)

各省、自治区、直辖市药品监督管理局或卫生厅（局）医药管理局部门、解放军总后卫生部：

现将2000年6月9日前已批准临床研究的新药品种予以公告。自本公告之日起各省级药品监督管理部门应停止受理相同品种的新药临床研究申请。

化学药品

```
药品名称　　　　　　　　　类别　　　　　　剂型

L-洒石酸托特罗定　　　　　二　　　　　　　原料

L-洒石酸托特罗定片　　　　二　　　　　　　片剂
```
