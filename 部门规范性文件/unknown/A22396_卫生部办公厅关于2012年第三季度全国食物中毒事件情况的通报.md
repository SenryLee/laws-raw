# 卫生部办公厅关于2012年第三季度全国食物中毒事件情况的通报

## 卫生部办公厅关于2012年第三季度全国食物中毒事件情况的通报（卫办应急发〔2012〕120号）

各省、自治区、直辖市卫生厅局，新疆生产建设兵团卫生局，中国疾病预防控制中心、卫生部卫生监督中心：

2012年第三季度，我部通过突发公共卫生事件网络直报系统共收到全国食物中毒类突发公共卫生事件（以下简称食物中毒事件）报告65起，中毒2382人，其中死亡50人。与2011年同期相比，报告起数减少11.0%，中毒人数减少26.1%，死亡人数减少18.0%。现将有关情况通报如下：

**二、**中毒事件原因分析

（一）按食物中毒原因分析，第三季度，微生物性食物中毒事件的中毒人数最多，占总中毒人数的53.6%，主要是由沙门氏菌、蜡样芽胞杆菌、副溶血性弧菌、肉毒毒素等引起的细菌性食物中毒。这与夏季气温高、湿度大，食物易受到微生物污染有关。有毒动植物及毒蘑菇引起的食物中毒是第三季度食物中毒事件造成人员死亡的主要原因，主要中毒因素为毒蘑菇、河豚毒素和未煮熟的四季豆等。

（二）按食物中毒场所分析，第三季度，发生在家庭的食物中毒事件报告起数和死亡人数最多。其中，有毒动植物及毒蘑菇引起的食物中毒事件最多，分别占家庭食物中毒事件报告起数和死亡人数的63.2%和73.3%；其次是微生物性食物中毒事件，分别占家庭食物中毒事件报告起数和死亡人数的23.7%和22.2%。第三季度集体食堂食物中毒事件主要发生在学校，占集体食堂食物中毒事件总报告起数和中毒人数的75%和79.9%。

**三、**下一步工作要求

（一）各地卫生部门应认真分析本地区食物中毒事件发生情况，与教育、旅游等部门加强沟通与合作，有针对性地加强学校食堂、热点旅游景区餐饮单位等重点场所和农村地区自采野生蘑菇和野菜等重点环节的预防控制工作。

（二）各地卫生部门要与新闻宣传等有关部门密切配合，结合当地居民饮食结构、生活习惯以及气候特点等，采取多种形式开展食品安全知识宣传和健康教育工作，增强公众的食品卫生安全意识，促进公众养成良好的饮食卫生习惯，有效减少食物中毒事件的发生。
