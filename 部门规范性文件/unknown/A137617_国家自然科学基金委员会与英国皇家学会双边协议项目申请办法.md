# 国家自然科学基金委员会与英国皇家学会双边协议项目申请办法

## 国家自然科学基金委员会与英国皇家学会双边协议项目申请办法（2001年）

国家自然科学基金委员会与英国皇家学会于1988年在北京签定了科技合作谅解备忘录。根据该双边协议，双方共同资助由中英研究人员共同实施的合作研究项目（Joint Project）。从1998年起，国家自然科学基金委员会与英国皇家学会每年确定最多5个合作研究项目，每个项目实施期限为3年。英国皇家学会对每个项目提供每年最多6000英镑的资助，用于中国研究人员在英期间的生活费和英国研究人员访华的国际旅费；国家自然科学基金委员会资助中国研究人员访英的国际旅费和英国研究人员在华的生活费。

**一、**申请项目的基本条件：

1. 申请合作项目的我国研究人员必须是在研基金项目的主持人或主要参与人，且从申请合作项目的次年1月1日起其在研基金项目离结题时间有两年（含两年）以上；

2. 合作项目的主持人和参与人必须有博士学位或副教授以上专业职称；

3. 合作双方有良好的合作基础。

**二、**申报要求：

1． 填写“国家自然科学基金国际合作交流项目申请书”（一式两份），并按填表要求附上有关材料。申请书下载网址：http：//www.nsfc.gov.cn/。

2．填写英国皇家学会项目申请表“Application for a China Joint Project Grant” （一式两份）。申请表下载网址：http：//www.royalsoc.ac.uk/funding/jp/chinasum.htm。

3．出具三封英文推荐信“China Joint Project Referee Statement”，推荐人为中国研究人员，推荐信格式的下载网址同2。

4．除推荐信外，所有申请材料于11月15日前（以邮戳为准）报国际合作局西欧处。推荐信由推荐人于11月15日前（以邮戳为准）直接寄给国际合作局西欧处。

**三、**通报最终结果：

西欧处于次年4月中旬书面通知申请人其项目是否批准并纳入国家自然科学委员会与英国皇家学会的合作协议。批准并纳入协议的合作项目即可立即开始执行。
