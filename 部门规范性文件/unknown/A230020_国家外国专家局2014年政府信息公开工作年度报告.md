# 国家外国专家局2014年政府信息公开工作年度报告

根据《中华人民共和国政府信息公开条例》（以下简称《条例》）要求，现公布2014年国家外国专家局政府信息公开年度报告。本报告包括概述、主动公开政府信息情况、依申请公开政府信息情况、政府信息公开收费及减免情况、因政府信息公开申请行政复议和提起行政诉讼情况、信息公开工作存在的主要问题及改进措施等。报告中所列数据的统计期限自2014年1月1日起至2014年12月31日止。

一、概述

2014年，国家外国专家局认真贯彻《条例》精神，切实加强政府信息公开制度和能力建设，加大引智重点工作信息公开力度，及时回应社会关切，不断提高公开实效，信息公开工作取得了新进展。

（一）加强组织领导。外专局政务公开工作领导小组负责政务公开工作的组织领导，并对外专系统政务公开工作进行指导和协调。领导小组办公室设在局办公室，负责政务公开的日常管理工作。

（二）提高新闻宣传报道实效。结合引智工作特点，修订国家外国专家局《新闻宣传工作管理办法》，新增了政策解读和对外宣传单元，使新闻宣传工作更加规范化、制度化。重视引智重大活动宣传的组织策划。创新引智宣传主题，加强与媒体全方位合作。

（三）完善信息发布及解读机制。对2013年建立的国家外国专家局信息发布专家解读机制进一步完善，根据实际需要适时更新“信息发布专家库”，新增政策解读章节，明确规定引智政策解读的范围、形式、原则等内容，使政策解读工作更加规范化、制度化。

（四）加强政府信息公开平台建设。继续加强对政府网站的建设和管理，优化信息公开目录系统，完善在线咨询等栏目，进一步发挥了门户网站的信息公开主渠道作用。利用网络平台及时公布出国培训的最新规定和有关情况，积极做好境外培训机构信息发布，方便项目单位查询。编印并在政府网站上公布“2014年度境外培训机构名册”。

二、主动公开信息情况

（一）加大引智重点领域信息主动公开力度。2014年，印发了《国家外国专家局2014年政府信息公开重点工作安排》，并认真抓好贯彻落实。通过我局政府网站主动公开各类引智政务信息380余条。利用《国家外国专家局简报》、《专家工作通讯》、《国际人才交流》等渠道，及时发布有关信息，方便引智项目单位、外国专家及社会公众获取引智政务信息。

（二）做好财政预决算和“三公”经费公开。在政府网站设立专栏公开相关信息，一是国家外国专家局2013年部门决算，包括“公共预算收入支出决算表”、“公用预算收入决算表”、“公共预算支出决算表”、“公共预算财政拨款收入支出决算表”、“政府性基金预算支出决算表”以及“三公”经费支出决算、行政经费支出统计数据。二是国家外国专家局2014年部门预算，包括“收支预算总表”、“收入预算表”、“支出预算表”、“财政拨款支出预算表”、“政府性基金预算收支表”以及“三公经费财政拨款预算表”。

（三）推进行政审批信息公开。按照国务院行政审批制度改革领导小组工作部署，网上公开我局行政审批事项的具体项目编码、项目名称、审批类别、设定依据等内容，回复社会对我局行政审批事项的意见建议。研究行政许可事项的提前取消和非行政许可审批事项的清理调整工作，完成并上报《国家外国专家局关于报送推进行政审批制度改革工作情况的函》。

三、依申请公开信息情况

2014年，为进一步规范依申请公开工作，我局制定了《国家外国专家局政府信息依申请公开规定》。本年度共受理政府信息公开申请2件，均为纸质信件方式申请，我局已全部按规定予以答复。

四、收费及减免情况

2014年，我局未发生因依申请公开信息收取或减免费用的情况。

五、咨询处理情况

2014年，我局门户网站共答复公众留言55条。

六、行政复议和行政诉讼情况

2014年，我局未接收到有关政府信息公开事务的行政复议申请及行政诉讼。

七、存在的问题和改进措施

2014年，国家外国专家局政府信息公开工作取得了一定成效，但也存在着一些问题，如政府信息公开渠道单一、相关配套制度和环节要求有待进一步完善等。下一步，我们将针对存在的问题，努力做好以下几个方面的工作：

（一）拓宽信息公开渠道。在继续做好外专局政府网站建设的基础上，探索利用微信、微博等新媒体平台的信息发布和运行管理机制，加大主动公开信息的工作力度，及时回应社会关切的相关问题。

（二）做好依申请公开工作。在认真执行《国家外国专家局政府信息依申请公开规定》的基础上，继续规范工作流程，完善局机关内部沟通协调机制。

（三）继续开展相关业务培训。努力建立培训工作常态化机制，加强对信息公开工作人员、政府网站工作人员等业务培训，提高外专局政府信息公开工作的能力和水平。
