# 商务部办公厅关于开展2014年零售业节能状况调查的通知

## 商务部办公厅关于开展2014年零售业节能状况调查的通知（2014年）

各省、自治区、直辖市、计划单列市及新疆建设兵团商务主管部门：

为贯彻落实《国务院关于印发“十二五”节能减排综合性方案的通知》（国发[2011]26号）要求，做好流通领域节能减排工作，全面掌握零售企业能耗水平，有针对性地提出零售业节能改造关键环节和政策支持重点，2014年我部将继续开展零售业节能状况调查工作。现将有关事项通知如下：

**一、**调查对象

本次调查的对象为各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门（以下简称各地商务主管部门）和部分零售企业。零售企业包括总部和门店。请各地商务主管部门组织本行政区域内不少于10家零售企业（总部）参加，每家零售企业选取2个典型门店（共计20个门店）参加。为保证数据的可比性，推荐企业应尽量与2013年参与调查的企业相同（2013年企业名单见附件4）。且推荐企业总部所在地应为本行政区域。有条件的地区可适当增加推荐调查企业数量。

**二、**调查方法

此次调查将采取网上问卷调查和典型企业走访相结合的方法。

（一）网上问卷调查：各地商务主管部门和参与调查企业登录我部流通业发展司网站“再生资源信息管理系统”中的“零售业节能状况调查”栏目进行填报（网址为：http：//zszy.syggs.mofcom.gov.cn/）。商务主管部门填报附件1，调查企业总部填报附件2和附件3。

登录方式：商务主管部门使用原“再生资源信息管理系统”中“省市县登录”栏目登录，后台将增加“零售业节能状况调查”模块供管理部门填报信息、分配企业用户名；调查企业通过“零售业节能状况调查企业登录”栏目登录，用户名由各地商务主管部门通过系统分配。

具体登录及填报方法详见栏目使用说明或向技术支持人员咨询。

（二）典型企业走访：选择部门重点地区商务主管部门进行电话沟通或上门沟通，并根据各企业的问卷反馈情况，选取部分典型企业进行走访。

**三、**有关要求

（一）请各地商务主管部门高度重视此次调查工作，附件1于6月30日前填报完成。

（二）请各地商务主管部门做好企业填报的督促工作，确保填报质量。附件2和附件3请于7月15日前完成审核。

**三、**企业在实施环保节能工作中最关心的问题

1．目前影响零售企业节能实施的最大障碍是

□政府对零售节能的支持力度不足

□无法及时了解新政策信息，特别是相关政府部门的鼓励政策或资金支持信息

□企业决策者重视度不够，相关管理制度和工作流程不完善

□相关标准及工具缺失，影响企业准确评价节能技术应用及节能效益

□用于整体节能系统的资金前期直接投入过大，影响企业实施系统改造进程

□缺乏相关专业人才，对节能设备技术的应用把握度不足

□节能一次性投入的资金占流动资金比例过大，影响企业正常运营

□其他　　　

2．企业下一步的节能推动工作重点是

□结合自建物业比例加大，更加关注提高建筑的整体节能效率

□继续完善管理节能手段，优化工作流程，注重提高整体节能效率

□继续对既有门店进行节能改造并扩大节能技术改造应用范围

□2014年以后的新开门店将全方位采用节能技术设备，打造节能型门店

□尝试采用合同能源管理模式，推动门店的节能项目实施进度

（比较认可的方式：A. 效益型合同能源管理，B. 效益保障型合同能源管理。C.能源费用托管型合同能源管理）
