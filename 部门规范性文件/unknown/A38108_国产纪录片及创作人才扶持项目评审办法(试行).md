# 国产纪录片及创作人才扶持项目评审办法(试行)

*注：本篇法规已被：广电总局办公厅关于2011―2012年度优秀国产纪录片及创作人才扶持项目申请事项的通知（发布日期：2012年3月21日，实施日期：2012年3月21日）废止

## 国产纪录片及创作人才扶持项目评审办法（试行）（广办发宣字[2011]41号）

**一、**评审宗旨

国产纪录片及创作人才扶持项目用于鼓励和扶持国产纪录片的创作、生产和播出。国产纪录片及创作人才扶持项目评审工作坚持以邓小平理论和“三个代表”重要思想为指导，全面贯彻落实科学发展观，坚持正确的舆论导向，坚持贴近实际，贴近生活，贴近群众；支持和鼓励具有中国特色、内容积极向上、体现民族精神、民族风格和民族特色的国产纪录片，做到思想精深、艺术精湛、制作精良；支持和鼓励国产纪录片人才的培养和发展，培养和扶持一批实力雄厚、竞争力强的国产纪录片制作机构，打造一批有中国风格和国际影响的国产纪录片品牌；支持和鼓励播出机构加强对国产纪录片的播出与宣传，为国产纪录片提供充分展示与交流的平台。

**二、**评审项目

国产纪录片及创作人才扶持项目共设立8个奖项，每个奖项设最佳奖1个、提名奖5个。

奖项及奖金设置如下：

|  |  |  |
| --- | --- | --- |
| 奖　　项 | 最佳奖 | 提名奖 |
| 最佳国产纪录片导演奖 | 5万元 | 3万元 |
| 最佳国产纪录片编剧奖 | 5万元 | 3万元 |
| 最佳国产纪录片短片奖 | 10万元 | 5万元 |
| 最佳国产纪录片中篇奖 | 15万元 | 8万元 |
| 最佳国产纪录片长篇奖 | 20万元 | 11万元 |
| 最佳国产纪录片栏目奖 | 20万元 | 11万元 |
| 最佳国产纪录片制作机构奖 | 30万元 | 15万元 |
| 最佳国产纪录片播出机构奖 | 30万元 | 15万元 |

**三、**评审程序

国家广电总局设立国产纪录片及创作人才扶持项目评审委员会，对扶持项目进行评审。

各省级广播影视行政部门对所辖区域内申请评奖的项目进行参评资格审核，确定参评项目符合所申请奖项的要求，确定参评机构和个人资料的真实性与合法性，审核合格的项目报广电总局国产纪录片及创作人才扶持项目评审委员会评审。各省、自治区、直辖市申请每类项目的数量不超过4个，2010年国产纪录片产量达到200小时以上的申请参评的每类奖项不超过8个。

解放军总政宣传部负责部队系统2010年度国产纪录片及创作人才扶持项目参评资格审核，确定参评项目符合所申请奖项的要求，确定参评者的资料真实性与合法性；

中直有关单位、中央电视台、中国电影集团公司、中国教育电视台负责对本单位申请评奖的项目进行参评资格审核，确定参评项目符合所申请奖项的要求，确定参评机构和个人的资料真实性与合法性。

解放军总政宣传部、中直有关单位、中央电视台、中国电影集团公司、中国教育电视台审核合格的项目报广电总局国产纪录片及创作人才扶持项目评审委员会评审，各单位申请每类项目的数量不超过4个，2010年国产纪录片产量达到200小时以上的申请参评的每类奖项不超过8个。

**四、**参评条件

（一）参评最佳国产纪录片导演奖，要求导演坚持“二为”方向和“双百”方针，贴近实际、贴近生活、贴近群众，弘扬主旋律，提倡多样化，遵循国产纪录片艺术规律，具有独到的导演手法和出色的实践能力，作品表现手法运用得当，作品思想性、艺术性、观赏性俱佳。

（二）参评最佳国产纪录片编剧奖，要求编剧坚持“二为”方向和“双百”方针，贴近实际、贴近生活、贴近群众，弘扬主旋律，提倡多样化，遵循国产纪录片艺术规律，剧本逻辑关系严谨，体现出高超的创意能力，充分考虑目标受众的接受特点，作品思想性、艺术性、观赏性俱。

（三）参评最佳国产纪录片短片奖，要求作品为展示当代中国精神风貌，记录社会历史发展重要进程，弘扬中华民族优秀传统文化，展现中国优美自然风光，传播科学思想文化，普及科学技术知识的纪录片。作品总长度为200分钟以内。

（四）参评最佳国产纪录片中篇奖，要求作品为展示当代中国精神风貌，记录社会历史发展重要进程，弘扬中华民族优秀传统文化，展现中国优美自然风光，传播科学思想文化，普及科学技术知识的纪录片。作品总长度为200分钟至400分钟。

（五）参评最佳国产纪录片长篇奖，要求作品为展示当代中国精神风貌，记录社会历史发展重要进程，弘扬中华民族优秀传统文化，展现中国优美自然风光，传播科学思想文化，普及科学技术知识的纪录片。作品总长度为400分钟以上。

（六）参评最佳国产纪录片栏目奖，要求该栏目积极播出国产纪录片，并具有较好的社会影响力，2010年播出国产纪录片50小时以上。能够主动参与国产纪录片的制作、播出与宣传等相关工作，为推动国产纪录片产业发展发挥了积极作用。栏目运营良好，具备持续发展能力。

（七）参评最佳国产纪录片制作机构奖，要求该机构2010年生产的、具有自主知识产权的国产电视纪录片达到100小时以上，国产纪录片制作生产运营良好，具备持续发展能力。

（八）参评最佳国产纪录片播出机构奖，要求播出机构具有较大的社会影响力，积极播出国产纪录片，2010年播出国产纪录片1000小时以上。同时，积极扶持国产纪录片项目，主动参与国产纪录片的投资、制作、播出与宣传等相关工作，为推动国产纪录片产业发展起到强有力的促进作用。

**五、**国产纪录片及创作人才扶持项目评审工作分初评与终评两个步骤进行。初评结果将在国家广电总局政府网站上向社会公示，接受社会监督。凡发现弄虚作假等不良现象，一经核实，立即取消参评资格，并向社会公布。

**六、**本办法自发布之日起实施，由国家广播电影电视总局负责解释。
