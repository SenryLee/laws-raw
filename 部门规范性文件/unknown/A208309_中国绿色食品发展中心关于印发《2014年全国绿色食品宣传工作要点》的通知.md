# 中国绿色食品发展中心关于印发《2014年全国绿色食品宣传工作要点》的通知

## 中国绿色食品发展中心关于印发《2014年全国绿色食品宣传工作要点》的通知（中绿市[2014]55号）

各地绿办（中心）：

为进一步做好绿色食品宣传工作，充分发挥舆论导向作用，营造全社会支持绿色食品事业发展的良好氛围，中心研究拟定了《2014年全国绿色食品宣传工作要点》，现印发给你们，请结合本地实际参照执行。

各地绿办要加强组织领导，充分认识绿色食品宣传工作的重要性，把宣传工作作为促进绿色食品持续健康发展的重要举措。要统筹兼顾，提前谋划好宣传目标、制定好宣传计划、落实好宣传措施。要利用电视、广播、报刊等传统媒体和互联网、4G网络、移动终端等新兴媒体的作用和优势，策划开展形式多样、特色鲜明的新闻宣传活动，充分宣传和展示绿色食品工作取得的突出亮点。要注重舆论引导，针对社会各界普遍关注的绿色食品热点问题，主动答疑解惑，加大引导力度，加强正面宣传，营造良好的舆论环境。要注意总结经验，及时报送重要新闻宣传稿件和典型素材，认真整理年度新闻宣传报道资料。

2014年全国绿色食品宣传工作要点

总体思路：以党的十八大、十八届三中全会、中央农村工作会议、全国农业工作会议精神为指导，紧紧围绕推动绿色食品持续健康发展的总目标，统筹安排、创新形式、加大力度搞好宣传工作，充分发挥舆论引导作用，为加强审核监管、健全诚信体系、全力打造品牌、服务“三农”大局、促进绿色食品事业与生态文明建设深度融合，营造良好氛围，为提升绿色食品认知度和美誉度、增强影响力和竞争力提供有力支持。

**一、**围绕重点工作部署，大力宣传推进绿色食品发展的重要举措

1、宣传绿色食品工作形势和任务。宣传十八届三中全会、中央农村工作会议、全国农业工作会议、2014年中央1号文件关于生态文明建设、农业可持续发展和农产品质量安全工作的政策精神，宣传中心2014年的工作目标任务，把中央和农业部的方针政策融入到绿色食品工作中，转化为推动绿色食品发展的动力、责任和措施。

2、宣传加强重点工作的措施和成效。以召开2014年“全国‘三品一标’工作会议”为契机，突出宣传绿色食品在优化审核程序、规范标志使用、加强证后监管等方面的工作举措和力度，积极推广各地在监管机制创新和工作进展方面取得的成效，引导全系统齐心协力、扎实抓好重点工作。

**二、**围绕监管年活动，大力宣传绿色食品监管工作

3、宣传各地加强绿色食品监管工作的措施办法。宣传近年来全国绿色食品监管体系队伍建设取得的成就，营造统筹协调、充实力量、措施有力、合力推进农产品质量安全监管的新氛围。挖掘和宣传监管工作中鲜活的事例和典型人物，在全系统形成争先创优的良好氛围。

4、宣传绿色食品企业加强监管工作的先进典型。组织各地绿色食品企业开展交流，推出在履行监管检查职责、遵循监督检查制度等方面突出的典型，总结经验和工作亮点，宣传绿色食品企业在从事生产经营活动中严保产品质量的好制度好做法。挖掘和宣传绿色食品企业内检员工作成绩突出的先进典型，向媒体和社会推介，展示监管工作一线工作人员的作风和风貌。

**三、**围绕诚信体系建设，大力宣传绿色食品发展模式

5、宣传绿色食品先进的管理模式。宣传绿色食品依据技术标准开展质量审核、通过质量审核落实标准化生产、通过标志管理打造品牌形象的管理模式，以及这种模式对于加强农产品质量安全管理工作和行业诚信体系建设所发挥的重要技术支撑作用。

6、宣传绿色食品诚信企业典型。通过宣传引导，发挥典型示范作用，使诚信经营成为行业理念和文化，成为核心价值观，促进全行业加强自律，诚信经营，共同维护品牌信誉，提高品牌公信力。

**四、**围绕持续健康发展，大力宣传绿色食品品牌效应

7、宣传绿色食品基础知识和基本理念。面向社会公众，积极宣传绿色食品概念、基本理念和宗旨、“从土地到餐桌全程质量控制”的技术路线，以及“两端监测、过程控制、质量认证、标识管理”的质量保证措施等内容，突出体现绿色食品“安全”和“优质”的本质特征以及在生态文明建设中发挥的促进作用，增强绿色食品对公众的亲和力。

8、宣传绿色食品对我国农业品牌建设的促进作用。宣传绿色食品作为农业部推出的安全优质农产品品牌，在整合农业资源、引领农业产业化发展中的积极作用；宣传绿色食品对提升企业产品品牌形象和价值、增强市场竞争力所起的推动作用；特别是注意收集、挖掘、总结和宣传绿色食品企业，通过品牌建设、提质增效、开拓市场的典型案例，宣传绿色食品对消费者的质量承诺，培育消费者对农业品牌的信任感。

**五、**围绕推动学习交流，大力宣传各地促进绿色食品发展的好政策与好做法。

9、宣传各地党和政府关心支持绿色食品发展的新部署、新要求、新政策、新举措，促进相互学习，提升绿色食品工作的地位，扩大社会影响。

10、宣传各地推动绿色食品发展举办的重要活动、重大举措，促进相互交流，不断丰富工作内涵，创新工作方式，提高工作效能。
