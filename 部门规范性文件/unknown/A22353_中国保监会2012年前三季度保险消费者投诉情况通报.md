# 中国保监会2012年前三季度保险消费者投诉情况通报

## 中国保监会2012年前三季度保险消费者投诉情况通报（2012年）

近期，保险消费者权益保护局对2012年前三季度保监会及各保监局受理的所有涉及保险消费者权益的有效投诉件进行了统计分析。现将有关情况通报如下：

**一、**总体情况

2012年前三季度，中国保监会及各保监局共接收各类涉及保险消费者权益的有效投诉总量10289件，同比增长159.10%，反映有效投诉事项12365个 ，同比上升174.84%。其中，电话投诉7265件，占有效投诉总量70.61%，同比增长5758.87%；信件投诉1549件，占比15.05%，同比下降9.73%；网络投诉784件，占比7.62%，同比下降34.17%；来访投诉691件，占比6.72%，同比下降26.49%。2012年5月，12378维权热线开通成为保险消费者表达诉求的重要渠道。

前三季度，中国保监会及各保监局共办结各类涉及保险消费者权益的有效投诉事项11583个，办结率达93.68%，帮助消费者维护经济利益总计17177.16万元。全国各级保险行业协会共受理各类保险合同纠纷调处申请11013件，实际调处7548件，为消费者挽回经济损失16466.24万元。

（一）从投诉件涉及的地区看，保险消费者投诉分布于除西藏之外的35个地区，投诉绝对量居前10位的省区市依次为：北京（1841件）、山东（1022件）、河南（947件）、广东（849件）、浙江（562件）、江苏（487件）、河北（482件）、辽宁（399件）、福建（351件）、陕西（347件）。上述10个省区市的投诉量占有效投诉总量的70.82%。

（二）从投诉事项涉及的机构看，涉及保险公司的12201个，同比上升182.17%，其中，财产险公司5268个，占投诉事项总量的42.60%，同比上升198.47%；人身险公司6933个，占比56.07%，同比上升170.93%；涉及中介机构的164个，占比1.33%，同比下降6.29%。

（三）从投诉事项涉及的类别看，保险公司涉及侵害消费者权益的违规类投诉2957个，占投诉事项总量的23.91%，同比上升60.01%；保险公司涉及合同纠纷类投诉9244个，占比74.76%，同比上升273.34%；中介机构涉及侵害消费者权益的违规类投诉133个，占比1.08%，同比下降19.88%；中介机构涉及合同纠纷类投诉31个，占比0.25%，同比上升244.44%。

（四）从投诉事项涉及的营销渠道看，个人代理渠道2759个，占投诉事项总量的22.31%；银邮代理渠道2005个，占比16.22%；直销渠道1008个，占比8.15%；电销渠道693个，占比5.60%；兼业代理渠道152个，占比1.23%；专业代理渠道148个，占比1.20%。

（五）投诉处理情况。前三季度，各保监局共办理各类涉及侵害消费者权益的投诉达11300件，实际办结11110件，办结率达98.32%，帮助消费者维护经济利益总计17177.16万元。具体如下：

前三季度，各保监局受理的涉及侵害消费者权益的违规类投诉2104件，其中，查实存在侵害消费者权益的违法违规问题259件；部分属实的482件，对此各保监局给予有关公司和责任人员警告39次，罚款340万元，此外还对75人次进行监管谈话，下发监管函65份；查不属实的452件，无法查实的911件。主要原因是：投诉人提供的证据不足，在无法获取其他证据的情况下难以认定违法事实；个别消费者对保险业务认识存在偏差，对保险公司退保和赔付金额存在过高要求，双方难以达成一致意见。

前三季度，各保监局受理的涉及合同纠纷类投诉9421件。其中诉求已解决的6315件，诉求部分解决的599件，两项之和占合同纠纷类投诉73.39%，诉求未解决的2507件。

（六）合同纠纷调处情况。前三季度，全国各级保险行业协会共受理各类保险合同纠纷调处（包括调解、业内裁决和仲裁等多种形式）申请11013件，实际调处7548件，调处率达68.54%，为消费者挽回经济损失16466.24万元。其中，调解7350件，调解成功6240件，调解成功率84.90%，涉及金额12556.61万元；业内裁决88件，消费者接受裁决结果的74件，涉及金额100.98万元；仲裁110件，消费者胜诉94件，涉及金额863.39万元。

**二、**投诉涉及的主要保险公司

（一）财产险公司

前三季度，保监会和各保监局收到涉及财产险公司的投诉4242件。其中投诉量居前5位的公司依次为：人保产（1087件）、平安产（758件）、太保产（480件）、阳光产（328件）、国寿产（195件），这5家公司投诉量总和占财产险公司投诉总量的67.14%。从单位保费的投诉件数分析，财产险公司每亿元保费 投诉量平均值为1.031件，高于平均值的市场主体共有23家 。

图3 前5家财产险公司每亿元保费投诉量（略）

人保产投诉量居财产险公司第一（1087件），其中涉及车险损失核定和理赔纠纷的问题有698件。

（二）人身险公司

前三季度，保监会和各保监局收到涉及人身险公司的投诉5916件。其中投诉量居前5位的公司依次为：中国人寿（1431件）、平安寿险（903件）、新华人寿（618件）、太保寿险（533件）、泰康人寿（496件），这5家公司投诉量总和占人身险公司投诉总量的67.29%。从单位保费的投诉件数分析，人身险公司每亿元保费投诉量平均值为0.758件，高于平均值的人身险公司共有40家。

中国人寿投诉量居人身险公司第一。其中有692件涉及分红险，主要反映营销员误导消费者或代签名等违法违规问题。

1.理赔纠纷。前三季度，财产险理赔纠纷事项共计3873个，占财产险合同纠纷投诉的80.69%，其中，反映理赔纠纷其他的1974个，反映损失核定争议的1127个，反映保险责任争议的724个，反映保险金领款资格的29个，反映交强险实际操作的19个。在各类业务中，车险合同纠纷共计4335个，其中理赔纠纷3501个，占车险合同纠纷的80.76%，主要反映理赔责任认定不合理、异地出险内部协调不畅、程序繁琐等原因导致公司拖延理赔等问题。

此外，反映责任险、工程险和农业险等其他财产险理赔纠纷的投诉事项290个，主要反映与保险公司沟通渠道不畅通，以及公司长期拖赔、无理拒赔等问题。

2.承保纠纷。前三季度，财产险承保纠纷事项共计647个，占财产险合同纠纷投诉的13.48%。主要反映保险费计算不合理、保单信息打印错误以及购买保险时承诺赠送的礼品未按时赠送等问题。

1.销售误导。前三季度，人身险公司涉及销售误导2090个，占人身险公司违法违规类投诉的83.97%。投诉居前5位的公司依次为：中国人寿（331个）、平安寿险（261个）、新华人寿（255个）、太保寿险（153个）、泰康人寿（127个），其总和占人身险公司销售误导类投诉的53.92%。从涉及的险种看，投诉分红险最多（1252个），占人身险销售误导投诉的59.90%，万能险152个，普通寿险108个。主要表现为销售时过高承诺产品收益、故意隐瞒免责事项以及将存单变保单等。

2.退保纠纷。前三季度，人身险公司涉及退保纠纷投诉有1675个，占人身险公司合同纠纷总量的37.69%。其中，涉及分红、万能、投连等人身险新型产品1179个，占人身险退保纠纷的70.39%。大多数新型保险产品退保的原因，是对产品的投资收益不认同。同时，销售时未全面如实讲解产品以及误导消费者购买与自身实际情况不符的保险理财产品，也是导致退保的重要原因。

3.健康险理赔纠纷。涉及人身险理赔给付投诉共计1237个，其中投诉医疗险、疾病险等健康保险就有432个，主要表现为保险责任认定不合理，理赔手续繁琐及理赔时效慢。

（三）中介机构投诉

前三季度，中介机构涉及消费者权益的投诉事项164个，其中涉及保险中介机构的销售误导投诉133个，占中介机构投诉的81.10%。销售误导投诉中，银邮代理88个，占比66.17%；专业代理23个，占比17.29%；兼业代理机构11个，占比8.27%；其他11个，占比8.27%。主要反映银邮兼业代理机构销售时未全面如实告知产品的详细信息而产生的合同纠纷问题。

各保监局要高度重视保险消费者权益保护工作，密切关注群体性事件投诉的动向，做到底数清、情况明、不遗漏，充分发挥投诉信息汇集和预警机制作用。同时，各局要采取有效措施，及时化解保险消费者投诉。对会机关转办的投诉件，应严格按照办结时效的要求，及时办理投诉件，注重办结时效。

各保险公司对监管机关转办的投诉件，要逐一梳理分析、逐一落实责任，切实减少保险消费者投诉。对于投诉人诉求合理合法的，要及时解决；诉求要求合理，但因客观条件不具备导致一时难以解决的，要解释沟通，取得理解；对于双方分歧较大，确实不能达成一致的，要积极引导其通过行业调解、仲裁、诉讼等渠道解决。各公司要切实改善服务质量，减少越级投诉，不断提高保险消费者的满意度。
