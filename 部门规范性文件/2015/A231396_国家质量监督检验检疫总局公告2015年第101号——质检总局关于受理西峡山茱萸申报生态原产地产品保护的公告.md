# 国家质量监督检验检疫总局公告2015年第101号——质检总局关于受理西峡山茱萸申报生态原产地产品保护的公告

## 国家质量监督检验检疫总局公告

2015年第101号

## 质检总局关于受理西峡山茱萸申报生态原产地产品保护的公告

日前，河南省宛西制药股份有限公司申请对西峡山茱萸产品进行生态原产地产品保护。根据《原产地标记管理规定》及其实施办法和《生态原产地产品保护工作导则》《生态原产地产品保护评定通则》等规定，经河南出入境检验检疫局初审，我局委托中国生态道德教育促进会评定，西峡山茱萸产品符合相关规定的保护条件，我局拟对其实施生态原产地产品保护。现将本次拟保护的产品及相关信息公告如下：

|  |  |
| --- | --- |
| 产品名称 | 申报单位 |
| 西峡山茱萸 | 河南省宛西制药股份有限公司 |

如有关单位或个人对上述产品申请生态原产地产品保护持有异议，可自公示之日起1个月内向我局生态原产地产品保护管理办公室书面提出，并说明异议具体内容及理由。
