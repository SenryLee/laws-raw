# 2015年度航空物探调查项目飞行任务承担人竞争性谈判优选结果公告

中国国土资源航空物探遥感中心于2015年5月14日对2015年度5个调查项目飞行任务承担人开展竞争性谈判优选。

优选会议审阅了各航空公司资质文件，各评委专家在航空公司对飞行服务方案现场汇报的基础上，通过提问、交流，对各航空公司进行评分，最终优选出各项目飞行任务承担单位。整个评审过程在公平、公正、公开的环境下顺利进行。

中国国土资源航空物探遥感中心感谢各航空公司的大力支持和参与，希望各承担单位严格履行调查项目质量技术要求，制定严密的安全保障措施，积极推进工作进度，顺利完成飞行任务。

各项目飞行任务承担人优选结果如下：

|  |  |
| --- | --- |
| **优选项目** | **飞行任务承担单位** |
| 准噶尔盆地中西部航空重磁综合调查 | 珠海中航通用航空有限公司 |
| 塔里木盆地东北部航空重磁综合调查 | 珠海中航通用航空有限公司 |
| 敦煌-阿克塞地区航磁调查 | 上海中瑞通用航空有限公司 |
| 陕西商南－丹凤航空物探（磁/放）调查 | 上海中瑞通用航空有限公司 |
| 新疆可可托海—萨尔托海地区航磁调查 | 北京首航直升机股份有限公司 |

如对优选结果有异议，可向中国国土资源航空物探遥感中心监察审计处提出书面申诉材料。
