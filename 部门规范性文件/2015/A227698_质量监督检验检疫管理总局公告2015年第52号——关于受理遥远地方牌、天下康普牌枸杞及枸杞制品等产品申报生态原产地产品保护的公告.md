# 质量监督检验检疫管理总局公告2015年第52号——关于受理遥远地方牌、天下康普牌枸杞及枸杞制品等产品申报生态原产地产品保护的公告

## 质量监督检验检疫管理总局公告

2015年第52号

## 关于受理遥远地方牌、天下康普牌枸杞及枸杞制品等产品申报生态原产地产品保护的公告

日前，青海康普生物科技股份有限公司等单位申请对遥远地方牌、天下康普牌枸杞及枸杞制品等7个产品进行生态原产地产品保护。根据《原产地标记管理规定》及其实施办法和《生态原产地产品保护工作导则》《生态原产地产品保护评定通则》等规定，经青海出入境检验检疫局、广东出入境检验检疫局、山东出入境检验检疫局、湖北出入境检验检疫局、重庆出入境检验检疫局初审，我局委托中国检验认证集团测试技术有限公司、北京万诚信用评价有限公司评定，遥远地方牌、天下康普牌枸杞及枸杞制品等7个产品符合相关规定的保护条件，我局拟对其实施生态原产地产品保护。现将本次拟保护的产品及相关信息公告如下：

|  |  |  |
| --- | --- | --- |
| 序号 | 产品名称 | 申报单位 |
| 1 | 遥远地方牌、天下康普牌枸杞及枸杞制品 | 青海康普生物科技股份有限公司 |
| 2 | 红江牌红江橙 | 广东省红江农场 |
| 3 | 西贝牌生猪 | 广东省广宁县八一生态农场 |
| 4 | 荟之纯牌芦荟饮品系列、瑷露德玛牌芦荟化妆品系列 | 台山美环健芦荟制品有限公司 |
| 5 | 吉祥云牌复方阿胶浆 | 山东东阿阿胶股份有限公司 |
| 6 | 随州“神农缘”牌香菇 | 湖北炎帝农业科技股份有限公司 |
| 7 | 三峡“阳菊牌”菊花代用茶 | 云阳芸山农业开发有限公司 |

如有关单位或个人对上述产品申请生态原产地产品保护持有异议，可自公示之日起1个月内向我局生态原产地产品保护管理办公室书面提出，并说明异议具体内容及理由。
