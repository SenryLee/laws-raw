# 国家质量监督检验检疫总局公告2015年第135号——质检总局关于公布获得生态原产地保护产品名单的公告

## 国家质量监督检验检疫总局公告

2015年第135号

## 质检总局关于公布获得生态原产地保护产品名单的公告

根据《原产地标记管理规定》及其实施办法、《生态原产地产品保护评定通则》等规定，经审核评定，批准大方皱椒等2项产品为生态原产地保护产品，准予其使用生态原产地产品保护标志，自即日起实施保护。现将获得生态原产地保护的产品名单予以公布。

|  |  |  |
| --- | --- | --- |
| 序号 | 产品名称 | 申报单位 |
| 1 | 大方皱椒 | 贵州省大方县人民政府 |
| 2 | 大方天麻 | 贵州省大方县人民政府 |

质检总局

2015年11月17日
