# 国家质量监督检验检疫总局公告2015年第102号——质检总局关于公布获得生态原产地保护产品名单的公告

## 国家质量监督检验检疫总局公告

2015年第102号

## 质检总局关于公布获得生态原产地保护产品名单的公告

根据《原产地标记管理规定》及其实施办法、《生态原产地产品保护评定通则》等规定，经审核评定，批准北京冠捷显示产品等5项产品为生态原产地保护产品，准予其使用生态原产地产品保护标志，自即日起实施保护。现将获得生态原产地保护的产品名单予以公布。

|| 序号 | 产品名称 | 申报单位 |
|  |  |  |
| --- | --- | --- |
| 1 | 北京冠捷显示产品 | 冠捷显示科技（中国）有限公司 |
| 2 | 北京天海气瓶 | 北京天海工业有限公司 |
| 3 | 武家嘴大米、茶叶 | 南京武家嘴生态农业发展有限公司 |
| 4 | 依源牌铁皮石斛及其制品 | 苏州神元生物科技股份有限公司 |
| 5 | 森山铁皮枫斗及其制品 | 浙江森宇实业有限公司 |
