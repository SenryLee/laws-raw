# 国家质量监督检验检疫总局公告2015年第123号——质检总局关于受理四川华欧橄榄油和油橄榄苗木等产品申报生态原产地产品保护的公告

## 国家质量监督检验检疫总局公告

2015年第123号

## 质检总局关于受理四川华欧橄榄油和油橄榄苗木等产品申报生态原产地产品保护的公告

日前，四川华欧油橄榄开发有限公司等单位申请对四川华欧橄榄油和油橄榄苗木等10个产品进行生态原产地产品保护。根据《原产地标记管理规定》及其实施办法和《生态原产地产品保护工作导则》《生态原产地产品保护评定通则》等规定，经四川出入境检验检疫局初审，我局委托北京万诚信用评价有限公司评定，四川华欧橄榄油和油橄榄苗木等10个产品符合相关规定的保护条件，我局拟对其实施生态原产地产品保护。现将本次拟保护的产品及相关信息公告如下：

|  |  |  |
| --- | --- | --- |
| 序号 | 产品名称 | 申报单位 |
| 1 | 四川华欧橄榄油和油橄榄苗木 | 四川华欧油橄榄开发有限公司 |
| 2 | “峰桃”牌富硒桃花米 | 达州市桃花米业有限公司 |
| 3 | 东柳醪糟(东汉牌、东柳牌) | 四川东柳醪糟有限责任公司 |
| 4 | “绿升”牌开江橄榄酒 | 四川天源油橄榄有限公司 |
| 5 | 万源富硒马铃薯 | 万源市农业技术推广站 |
| 6 | 万源富硒茶 | 万源市茶叶局 |
| 7 | 万源富硒辣椒 | 万源市宝莱特农业开发有限公司 |
| 8 | 万源旧院黑鸡、万源旧院黑鸡蛋 | 万源市畜禽品种改良站 |
| 9 | 万源珍珠花菜及其制品 | 万源市花萼绿色食品有限公司 |
| 10 | 万物生蜂桶蜂蜜 | 万源市太一蜂业有限公司 |

如有关单位或个人对上述产品申请生态原产地产品保护持有异议，可自公示之日起1个月内向我局生态原产地产品保护管理办公室书面提出，并说明异议具体内容及理由。
