# 国家质量监督检验检疫总局关于进口圭亚那和美国原木传带检疫性有害生物的警示通报

## 关于进口圭亚那和美国原木传带检疫性有害生物的警示通报

进出境动植物检验检疫风险预警表

质检动警（2015）第33号 2015年7月1日

|  |  |
| --- | --- |
| 预警标题 | 关于进口圭亚那和美国原木传带检疫性有害生物的警示通报 |
| 预警事由 | 近期，福建检验检疫局多次从圭亚那进口铁木豆原木中截获大量的活体有害生物。有的批次原木截获活的检疫性有害生物中对长小蠹（*Platypus parallelus*）、赤材小蠹（*Xyleborus ferrugineus*），以及其他重要林木害虫靓眼斑天牛（*Agaone notabilis*）、拆斑尼胸天牛（*Nyssodrysternum signiferum*）、黑齿斑天牛（*Odontocera molorchoides*）、哈维斑天牛（*Odontocera javieri*）、刺膝天牛（*Chlorida festiva*）、天牛（*Cycnidolon batesanium*）、星吉丁属（*Chrysobothris amabilis*）。  辽宁检验检疫局从美国进口山核桃原木中截获了共检出了脊虎天牛（*Xylotrechus* sp.）、叩甲（*Elateridae*）、姬蜂（*Ichneumonidae*）、果蝇（*Drosophilidae*）、步甲（*Carabidae*）、蚁科（*Formicidae*）、郭公虫(*Cleridae*)、烟草甲(*Lasioderma serricorne*)、中对长小蠹(*Platypus parallelus*)、材小蠹(*Xyleborus* sp.)、红足楔天牛(*Saperda discoidea*)、楔天牛(*Saperda* sp.)、美洲稀蠊(*Parcoblatta Americana*)，其中中对长小蠹(*Platypus parallelus*)及红足楔天牛(*Saperda discoidea*)为检疫性有害生物。 |
| 涉及产品  （HS编码） | 原木  前四位为4403 |
| 涉及国家 | 圭亚那、美国 |
| 预警措施 | 1、各局要加强对进口北美和南美国家阔叶木的检验检疫，一旦发现有害生物，要及时送实验室进行鉴定，如确定为检疫性有害生物的，要立即监督实施检疫处理，防止疫情传入。  2、各局要及时将疫情截获情况报告总局，以便总局对外通报并对进口原木开展风险分析。  3、有效期一年。 |
