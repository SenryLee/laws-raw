# 国家质量监督检验检疫总局关于严防活昆虫随邮寄物非法进境的警示通报

## 关于严防活昆虫随邮寄物非法进境的警示通报

进出境动植物检验检疫风险预警表

质检动警〔2015〕第038号　 2015年7月29日

|  |  |
| --- | --- |
|  | |
| 标　题 | 关于严防活昆虫随邮寄物非法进境的警示通报 |
| 预警事由 | 近日，北京检验检疫局在望京国际邮件处理中心查验现场从来自英国的邮件中截获昆虫一批，共计6只，经鉴定为大王虎甲和蟋蟀，其中大王虎甲为全国首次截获。产于非洲南部的大王虎甲虫是世界最大的虎甲，体长可达60mm，由于其中的非对称颚齿极端巨大，且生性凶猛，对人和动物极具攻击性。 |
| 涉及产品 | 昆虫 |
| 涉及国家或地区 | 英国 |
| 预警措施 | 1.各局应保持高度警惕，加大对进境邮寄物的查验力度，发现非法邮寄活昆虫进境的，要依法予以截留，并将情况及时上报总局动植司。  2.各局要进一步加强社会宣传和公众教育工作，提醒公众严格遵守我国相关法律法规的规定，切勿邮寄禁止进境物。  3.各局要加强与海关、邮政等部门的合作。积极争取进驻查验，建立防控协作机制，切实提升执法把关效能。 |
