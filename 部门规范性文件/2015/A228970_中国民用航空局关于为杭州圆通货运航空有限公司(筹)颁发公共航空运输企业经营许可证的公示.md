# 中国民用航空局关于为杭州圆通货运航空有限公司(筹)颁发公共航空运输企业经营许可证的公示

杭州圆通货运航空有限公司（筹）2014年8月5日经民航局批准筹建，目前筹建工作已基本完成，申请公共航空运输企业经营许可证。民航华东地区管理局已完成对其初审。根据《公共航空运输企业经营许可规定》（民航总局令第138号），有关情况公示如下：

一、公司名称：杭州圆通货运航空有限公司

二、企业地址：浙江省杭州市萧山国际机场空港大道

三、基地机场：杭州萧山国际机场

四、企业类型：有限责任公司

五、注册资本：人民币肆亿元整

六、法定代表人：喻会蛟

七、经营范围：国内（含港澳台）、国际航空货邮运输业务

八、投资人及其出资方式、比例：

|  |  |  |  |
| --- | --- | --- | --- |
| 投资人名称 | 出资额（人民币） | 出资方式 | 出资比例 |
| 上海圆通蛟龙投资发展（集团）有限公司 | 36000万元 | 现金 | 90% |
| 喻会蛟 | 2000万元 | 现金 | 5% |
| 张小娟 | 2000万元 | 现金 | 5% |
| 合 计 | 40000万元 |  | 100% |

九、申请经营许可证的准备情况

1、已办理工商营业执照；

2、已制定公司章程；

3、已与民航浙江安全监督管理局机关后勤服务中心签订了办公用房租赁协议；

4、国家发展改革委员会已同意其引进3架B737-300型货机（其中从ACG公司购买2架，从扬子江快运航空有限公司经营租赁1架）；

5、已与杭州萧山国际机场有限公司签订了机场使用协议；

6、民航局适航司已批准其飞机外部喷涂方案；

7、民航华东地区空管局浙江分局已同意其使用130.650MHZ作为航务管理频率，并为其提供航务通信、航行情报和气象等服务保障；

8、经国际民航组织正式注册，民航局空管局向其指配了三字代码HYT和无线电呼号（中文无线电呼号为速派、英文无线电呼号为QUICK AIR）；国际航协向其指定了二字代码YG并已受理其三字结算码申请;

9、民航局运输司已批准其国内运输总条件及相关运输凭证样式，国际运输总条件已准予备案；

10、中国人民财产保险股份有限公司已确认其加入民航联合保险机队保单，同意为其承保地面第三者责任险等保险；

11、已招聘飞行人员12人、维修人员31人、签派人员8人、运输人员5人（上述专业技术人员均已签订劳动合同）；

12、经上海泾华会计师事务所有限公司审验（验资报告—泾华会计师【2015】NY100012号），各股东的出资4亿元人民币已缴足；

13、根据《民用航空器飞行事故应急反应和家属援助规定》（民航总局令第155号）的要求，已制定《家庭救援计划》；

14、公司总裁

苏秀锋，原长龙国际货运航空有限公司总裁
