# 中国国土资源部经济研究院博士后科研工作站招收2015年度博士后研究人员公告

## 中国国土资源经济研究院博士后科研工作站招收2015年度博士后研究人员公告

中国国土资源经济研究院博士后科研工作站的办站方针是围绕国土资源重点工作，以国土资源经济研究重大项目为依托，推动学科创新，吸引、培养高层次优秀人才，建设国家一流的博士后科研工作站，服务支撑国土资源管理工作。

根据我院2015年科研工作需要，与北京大学、中国地质大学（北京）等博士后流动站联合面向社会公开招收2015年度博士后研究人员。现将有关事项公告如下：

一、申请条件

1.在国内外已获得博士学位或已经通过博士学位论文答辩；

2.品学兼优，身体健康，具有较强科研能力、敬业和团队合作精神的创新型优秀人才；

3.所学专业和博士毕业论文符合我院科研工作需要；

4.年龄在40周岁以下。

同时，本院拟招收外籍（境外）和留学博士来院从事博士后研究工作，申请条件如下：

1.年龄一般不超过35周岁；

2.近三年在国外（境外）世界排名前100名的高校获得博士学位；

3.在读博士期间取得突出的研究成果；

4.非英语国家的人员应具有良好的中文（或英文）听、说、读、写能力。

二、申请人应递交的材料及注意事项

1.《中国国土资源经济研究院博士后自荐表》（请从中国国土资源经济研究院网站：http://www.calre.org.cn/博士后工作站，表格用宋体小五号字填写。表格照片处采用个人近期免冠一寸数码照片）。

2.博士学位证书复印件或答辩决议书及有关证明材料。

3.两篇以上已公开发表并能够代表本人学术水平的论文。

三、相关福利待遇

中国国土资源经济研究院将为博士后研究人员提供科研及生活条件，具体条款参见《中国国土资源经济研究院博士后科研工作站管理办法》。

四、研究方向

|  |  |  |  |
| --- | --- | --- | --- |
| 序 号 | 专　 业 | 工作经历 | 研究方向 |
| 1 | 地质矿产勘查、产业经济及相关专业 | 具有野外地质工作经历、矿政管理工作经历者优先 | 地勘行业发展战略 |
| 2 | 信息工程及相关专业 | 具有国土资源信息化工作经验、能够独立编程者优先 | 国土资源信息化标准化研究 |
| 3 | 金属矿产采选及相关专业 | 具有矿山生产实践或数据库建设经验者优先 | 矿产资源节约与综合利用研究 |
| 4 | 采矿及相关专业 | 具有两年以上采矿工作经验者优先 | 矿业权管理研究 |
| 5 | GIS、地理、环境科学及其他 | 具有两年以上地质环境科学工作经验者优先 | 资源环境承载力评价 |

五、招收程序

1．报名

请将自荐表、证明材料（扫描件）及论文等相关材料发至电子邮箱（kejichu2010@163.com）。

2．资格审查

按照研究方向及条件，我院对收到的自荐表等材料进行分类筛选，并进行资格审查，审查合格者方可参加面试。

3．面试

面试人员须提供本人身份证、学位学历证及相关学术成果。面试时间、地点另行通知。

4．确定拟接收人选

综合面试情况，经研究，确定最终拟接收人选。

5．考察

组织人员赴拟接收博士所在学校或单位进行考察，通过查阅本人档案、同有关人员谈话等方式，进一步了解拟接收博士的综合素质和业务能力。

6．进站

考察结束后，经研究，对满足研究方向要求的博士，签订联合培养协议，办理进站手续。
