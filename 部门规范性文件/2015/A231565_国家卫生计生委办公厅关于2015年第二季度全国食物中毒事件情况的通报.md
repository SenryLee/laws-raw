# 国家卫生计生委办公厅关于2015年第二季度全国食物中毒事件情况的通报

国卫办应急发〔2015〕41号

各省、自治区、直辖市卫生计生委，新疆生产建设兵团卫生局，疾控中心、监督中心：

2015年第二季度，我委通过突发公共卫生事件管理信息系统共收到全国食物中毒类突发公共卫生事件（以下简称食物中毒事件）报告40起，中毒1748人，其中死亡18人。与2014年同期相比，报告起数减少13.0%，中毒人数增加4.3%，死亡人数减少45.5%。现将有关情况通报如下：

一、食物中毒事件报告情况

（一）按月报告情况。

|  |  |  |  |
| --- | --- | --- | --- |
| 月份 | 报告起数 | 中毒人数 | 死亡人数 |
| 4月 | 6 | 277 | 2 |
| 5月 | 20 | 951 | 7 |
| 6月 | 14 | 520 | 9 |
| 合计 | 40 | 1748 | 18 |

第二季度，5月份报告的事件起数和中毒人数最多，分别占第二季度总报告起数和中毒总人数的50.0%和54.4%。6月份报告的死亡人数最多，占第二季度死亡总人数的50%。

（二）按食物中毒原因分类情况。

|  |  |  |  |
| --- | --- | --- | --- |
| 中毒原因 | 报告起数 | 中毒人数 | 死亡人数 |
| 微生物性 | 22 | 1143 | 1 |
| 化学性 | 3 | 79 | 2 |
| 有毒动植物及毒蘑菇 | 12 | 390 | 14 |
| 不明原因或尚未查明原因 | 3 | 136 | 1 |
| 合计 | 40 | 1748 | 18 |

第二季度，微生物性食物中毒事件的事件起数和中毒人数最多，分别占总报告起数和中毒总人数的55.0%和65.4%。 有毒动植物及毒蘑菇引起的食物中毒事件死亡人数最多，占死亡总人数的77.8%。

与2014年同期相比，微生物性食物中毒事件报告起数增加1起，中毒人数减少15.0%，死亡人数减少1人；化学性食物中毒事件报告起数增加3起，中毒人数增加79人，死亡人数增加2人；有毒动植物及毒蘑菇引起的食物中毒事件报告起数减少42.9%，中毒人数增加1.1倍，死亡人数减少50.0%。

（三）按食物中毒场所分类情况。

| --- | --- | --- | --- |

| 集体食堂 | 13 | 827 | 0 |

| 饮食服务单位 | 12 | 585 | 1 |
| 其他场所 | 3 | 90 | 5 |
| 合计 | 40 | 1748 | 18 |

第二季度, 发生在集体食堂的食物中毒事件报告起数和中毒人数最多，分别占总报告起数和中毒总人数的32.5%和47.3%。发生在家庭的食物中毒事件死亡人数最多，占死亡总人数的66.7%。

与2014年同期相比，发生在集体食堂的食物中毒事件报告起数增加3起，中毒人数增加26.5%，均无死亡；发生在家庭的食物中毒事件报告起数减少50.0%，中毒人数减少21.9%，死亡人数减少63.6%；发生在饮食服务单位的食物中毒事件报告起数增加20.0%，中毒人数减少1.5%，死亡人数增加1人；发生在其他场所的食物中毒事件报告起数增加1起，中毒人数减少20.4%，死亡人数增加5人。

（四）学生食物中毒事件报告情况。

第二季度，报告学生食物中毒事件10起，中毒598人，无死亡。其中，9起发生在学校集体食堂，中毒人数占学生食物中毒总人数的92%。

由微生物引起的食物中毒事件7起，有毒动植物及毒蘑菇引起的食物中毒事件3起。其中微生物引起的食物中毒事件中毒人数占学生食物中毒总人数的63.0%。

与2014年同期相比，学生食物中毒事件报告起数减少3起，中毒人数减少28.1%，均无死亡。

（五）剧毒鼠药中毒事件报告情况。

第二季度，全国报告剧毒鼠药中毒事件1起，中毒39人，无死亡。剧毒鼠药中毒人数占化学性食物中毒事件中毒人数的49.4%。

二、食物中毒事件原因及场所分析

（一）按食物中毒发生原因分析，第二季度，微生物性食物中毒事件的事件报告起数和中毒人数最多，主要致病因子为沙门氏菌、蜡样芽胞杆菌及副溶血性弧菌。有毒动植物及毒蘑菇引起的食物中毒事件死亡人数最多，主要致病因子为毒蘑菇、未煮熟四季豆、生番茄及野菜。化学性食物中毒事件主要致病因子为亚硝酸盐和毒鼠强。

（二）按食物中毒发生场所分析，第二季度，发生在集体食堂的食物中毒事件报告起数和中毒人数最多。其中，微生物引起的食物中毒事件9起，中毒507人；有毒动植物及毒蘑菇引起的食物中毒事件4起，中毒320人。发生在家庭的食物中毒事件死亡人数最多。其中，有毒动植物及毒蘑菇引起的食物中毒事件6起，中毒30人，死亡9人；微生物性食物中毒事件4起，中毒203人；化学性食物中毒事件1起，中毒10人，死亡2人；不明原因或尚未查明原因的食物中毒事件1起，中毒3人，死亡1人。

三、下一步工作建议

（一）各地卫生计生部门要根据本地区夏季食物中毒事件发生情况和特点，加强预防食物中毒的健康防病知识宣传教育工作。针对微生物性食物中毒高发情况，宣传普及科学的食品加工、储存方法；针对当地居民采食野生植物和蘑菇的生活习惯，通过有效宣传提高公众识别有毒植物及毒蘑菇、防范中毒事件发生的能力。

（二）洪涝、台风灾害发生地区卫生计生部门在救灾防病工作中要高度重视食物中毒事件预防和控制工作，加强健康教育宣传，提升公众防范意识和能力，及时发现、救治食物中毒病例，减少食物中毒导致的死亡。
