# 国家质量监督检验检疫总局关于严防贝克剑线虫随邮寄物进境的警示通报

## 关于严防贝克剑线虫随邮寄物进境的警示通报

## 进出境动植物检验检疫风险预警表

质检动警【2015】第036号　 2015年7月29日

|  |  |
| --- | --- |
|  | |
| 标　题 | 关于严防贝克剑线虫随邮寄物进境的警示通报 |
| 预警事由 | 近日，上海出入境检验检疫局邮检办事处从所截获的邮寄自日本的石菖蒲种苗中检出贝克剑线虫（Xiphinema Bakeri），系全国首次检出该种检疫性有害生物。  贝克剑线虫属于剑线虫属，可寄生于植物根部，影响根系长势，甚至造成根部肿大或坏死等症状。贝克剑线虫也是南芥菜花叶病毒的传播介体，此病毒是我国进境植物检疫性有害生物之一，可侵染约174属215种植物，会严重危害蔬菜、花卉、树木等多种经济作物。 |
| 涉及产品 | 禾本科及其他植物繁殖材料 |
| 涉及国家或地区 | 日本 |
| 预警措施 | 1.各局应保持高度警惕，按照“绿蕾”专项行动要求，加大对进境旅客携带物、邮寄物的查验和检疫鉴定力度，严厉打击非法携带和邮寄植物种子种苗随旅客携带物、邮寄物进境。  2.各局要进一步加强社会宣传和公众教育，提醒公众严格遵守我国相关法律法规的规定，切勿携带、邮寄禁止进境物。 |
