# 国家质量监督检验检疫总局关于严防鹰嘴豆象随邮寄物进境的警示通报

## 关于严防鹰嘴豆象随邮寄物进境的警示通报

进出境动植物检验检疫风险预警表

质检动警〔2015〕第037号 2015年7月29日

|  |  |
| --- | --- |
|  | |
| 标　题 | 关于严防鹰嘴豆象随邮寄物进境的警示通报 |
| 预警事由 | 近日，黑龙江检验检疫局邮局办事处工作人员截获了一批来自印度的鹰嘴豆、香料等植物繁殖材料。经现场检疫，在鹰嘴豆中发现大量豆象科生活成虫，进一步鉴定后确认为我国禁止进境的植物检疫性有害生物——鹰嘴豆象（Callosobruchus analis F.），系黑龙江口岸首次检出。  鹰嘴豆象是世界性储粮害虫，也是东南亚地区重要的储藏豆类主要害虫，是我国重要的检疫性有害生物。主要随寄主植物的调运远距离传播。其繁殖力强、危害严重，在仓库和田间均可危害，一旦传入，将对我国农业生产和粮食储备带来重大威胁。 |
| 涉及产品 | 鹰嘴豆、香料等植物繁殖材料 |
| 涉及国家或地区 | 印度 |
| 预警措施 | 1.各局应保持高度警惕，按照“绿蕾”专项行动要求，加大对进境旅客携带物、邮寄物的查验和检疫鉴定力度，严厉打击非法携带和邮寄植物种子种苗随旅客携带物、邮寄物进境。  2.各局要进一步加强社会宣传和公众教育，提醒公众严格遵守我国相关法律法规的规定，切勿携带、邮寄禁止进境物。 |
