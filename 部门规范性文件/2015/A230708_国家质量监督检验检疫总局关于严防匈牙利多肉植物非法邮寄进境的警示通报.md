# 国家质量监督检验检疫总局关于严防匈牙利多肉植物非法邮寄进境的警示通报

## 关于严防匈牙利多肉植物非法邮寄进境的警示通报

进出境动植物检验检疫风险预警表

质检动警[2015]第034号2015年7月28日

|  |  |
| --- | --- |
|  | |
| 标 题 | 关于严防匈牙利多肉植物非法邮寄进境的警示通报 |
| 预警事由 | 近日，四川检验检疫局陆运办事处工作人员从匈牙利邮寄入境的邮包（EA009885746HU）中查获活体植物36株，经鉴定，包括铁甲丸(*Euphorbia bupleurifolia*) 8株，飞龙 (*Euphorbia stellata*) 21株，白皮摩罗(*Raphionacme procumbens*)1株、何鲁牵牛(*Ipomoea holubii*)1株，扁平龟甲龙(*Dioscorea sylvatica*)2株，雾冰玉(*Eriospermum dregei*)3株，其中铁甲丸、飞龙属于《濒危野生动植物种国际贸易公约》（CITES公约）附录II内濒危野生植物。四川检验检疫局已依法对该批植物繁殖材料做了销毁处理。 |
| 涉及产品 | 多肉植物 |
| 涉及国家  或地区 | 匈牙利 |
| 预警措施 | 1.各局应保持高度警惕，按照“绿蕾”专项行动、“眼镜蛇三号行动”要求，加大对来自匈牙利的旅客携带物、邮寄物的检疫查验力度，严厉打击非法携带和邮寄植物种子种苗、包括濒危野生植物进境以及走私、逃漏检等违法行为。  2.各局要进一步加强社会宣传和公众教育，提醒公众严格遵守我国相关法律法规的规定，切勿携带、邮寄禁止进境物。 |
