# 国家质量监督检验检疫总局关于严防火龙果X病毒随旅客携带物进境的警示通报

## 关于严防火龙果X病毒随旅客携带物进境的警示通报

进出境动植物检验检疫风险预警表

质检动警[2015]第035号　 2015年7月29日

|  |  |
| --- | --- |
|  | |
| 标　题 | 关于严防火龙果X病毒随旅客携带物进境的警示通报 |
| 预警事由 | 近日，厦门机场检验检疫局五通办从所截获的台湾旅客携带进境的火龙果种苗中检出仙人掌X病毒（*Cactus virus X*，CVX）、蟹爪兰X病毒(*Zygocactus virus X*，ZyVX) 、火龙果X病毒 (Pitaya virus X，PiVX)共三种病毒。其中火龙果X病毒系全国首次检出。  该批火龙果种苗中还检出尖孢镰刀菌、大量小杆线虫、及其它自由生活线虫等三种有害生物，其中尖孢镰刀菌是五通口岸首次检出。这些有害生物极易通过扦插、土壤、水等途径传播，一旦引入种植，将对本地的水果种植带来较大危害。目前，该批火龙果种苗已作销毁处理。 |
| 涉及产品 | 火龙果种苗 |
| 涉及国家或地区 | 台湾 |
| 预警措施 | 1.各局应保持高度警惕，按照“绿蕾”专项行动要求，加大对进境旅客携带物、邮寄物的查验和检疫鉴定力度，严厉打击非法携带和邮寄植物种子种苗随旅客携带物、邮寄物进境。  2.各局要进一步加强社会宣传和公众教育，提醒公众严格遵守我国相关法律法规的规定，切勿携带、邮寄禁止进境物。 |
