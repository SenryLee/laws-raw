# 国土资源部油气资源战略研究中心2015年度接收应届毕业生招聘公告

根据我单位事业发展和人才队伍建设需要，拟面向社会公开招聘全日制高校毕业生。现将有关事项公告如下：

一、招聘对象

全日制普通高等院校2015年应届本科及以上毕业生。（详见列表）

二、基本条件

1.具有中华人民共和国国籍；

2.遵守宪法和法律；

3.具有良好的品行；

4.具有岗位报需的专业条件；

5.适应岗位需要的身体条件；

6.具备岗位所需要的其他条件。

三、招聘岗位及职位要求

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **岗位编号** | **岗位名称** | **招考人数** | **专业基础** | **备注** |
| 001 | 油气信息 | 2 | 石油地质 | 硕士研究生及以上学历（生源地不限） |
| 002 | 资源评价、战略研究 | 2 | 地质、石油地质 | 硕士研究生及以上学历（其中京内生源1名） |
| 003 | 油气地质研究 | 2 | 石油地质 | 硕士研究生及以上学历（其中京内生源1名） |
| 004 | 油气矿业权审查 | 1 | 石油地质 | 硕士研究生及以上学历 　　（生源地不限） |
| 005 | 督察管理 | 2 | 地质、石油地质 | 硕士研究生及以上学历（其中京内生源1名） |
| 006 | 国外能源战略与政策研究 | 1 | 石油地质 | 硕士研究生及以上学历 　　（生源地不限） |
| 007 | 财务出纳 | 1 | 会计 | 本科学历，京内生源 |

四、报名事项

1．报名截止时间：2015年3月12日。

2．报名者请填写《国土资源部油气资源战略研究中心公开招聘2015年应届毕业生报名表》（见附件1），并以附件的形式发送电子邮件至xuanqushi@126.com。邮件主题和附件文件名请按照以下格式填写：姓名+应聘岗位。

3．在国土资源部网站（http://www.mlr.gov.cn）及油气中心门户网站（http://www.sinooilgas.com）公布通过资格审查参加笔试人员名单。

咨询电话：010－66558864；010-66558853

电子邮箱：xuanqushi@126.com。

地址：北京市西城区阜内大街88号，国土资源部油气资源战略研究中心203房间

五、考试事项

中心根据各岗位笔试成绩由高到低的顺序，按照不低于1：3的比例确定面试人员。面试人员名单及具体面试时间、地点，将在国土资源部网站和油气中心网站发布通知。
