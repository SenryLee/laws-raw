# 中国国土资源经济研究院招聘2015年高校应届毕业生公告

中国国土资源经济研究院（简称经研院）是国土资源部直属事业单位，主要任务是开展国土资源政策法规、战略规划、市场配置、资源经济、环境经济、产业经济、技术与经济标准、节约与综合利用、矿业权管理等基础和应用研究，为国土资源管理提供基础业务支撑和决策咨询服务。

根据业务发展需要，我院计划公开招聘2015年高校应届毕业生7名。

一、招聘范围

全日制普通高等院校2015年应届毕业生。

二、基本条件

1．遵纪守法，品行端正，思想政治素质好，能够履行事业单位人员的义务。

2．工作态度积极，有事业心、责任感，具有开拓创新精神，有志于投身国土资源经济研究事业。

3．身体健康，能吃苦耐劳，具备适应岗位要求的身体条件和心理素质。

4．学习成绩优良，具备较强的计算机应用能力和较高的英语水平。

三、岗位需求

经研院公开招聘2015年应届毕业生岗位需求情况见附表1。

四、招聘程序

招聘工作按照报名、资格审查、笔试、面试、体检、确定拟接收人选、公示、考察、聘用等程序进行。

（一）报名

1．报名材料

报名者须完整提交经研院公开招聘2015年应届毕业生报名表（见附表2）、经研院公开招聘2015年应届毕业生报名情况表（见附表3）、个人简历（简明扼要）三份材料。

报名人员应对所提供材料的真实性负责，凡弄虚作假的，一经发现，取消考试或聘用资格。

2．报名方式

报名者可采用邮寄报名材料或发送电子邮件方式进行报名（采用一种报名方式即可）。

邮寄地址：北京市259信箱，中国国土资源经济研究院组织与人事处，邮编：101149。

电子邮箱：jyyrsc219@126.com，邮件主题和附件名为：姓名+应聘岗位代码+岗位名称。

3．报名时间

我院接收报名材料的时间为：自即日起至2015年3月15日17:00止。

4．咨询电话：010-61595917、010-61595939

联系人：顾海旭、厉福荣

（二）资格审查

按照岗位需求及条件，我院对收到的个人简历进行分类筛选，并对学历、专业等进行资格审查，审查合格者方可参加笔试。

报名人员请于2015年3月18日前登录我院外网（www.calre.org.cn）查询资格审查结果。

（三）笔试

笔试由国土资源部统一组织。笔试时间、地点另行通知。应考人员参加笔试时，必须携带身份证。笔试成绩可通过咨询电话查询。

笔试结束后，按岗位分别排队，按照笔试成绩从高分到低分的顺序，确定每个岗位招聘人数5倍的人员参加面试。

（四）面试

面试时间、地点另行通知。面试人员须提供本人身份证、学生证、所在学校教务部门盖章的报名表一份。上述证件均为原件，缺少上述证件者，不得参加面试。

（五）体检

对拟接收人选，由我院统一安排体检。

（六）确定拟接收人选

综合笔试、面试成绩和体检结果，经研究，确定最终应届毕业生拟接收人选。

（七）公示

在我院外网对拟接收应届毕业生人选进行公示，公示时间为5个工作日。

（八）考察

组织人员赴拟接收应届毕业生所在学校进行考察，通过查阅本人档案、同有关人员谈话等方式，进一步了解拟接收应届毕业生的综合素质和业务能力。

（九）聘用

考察结束后，经研究，对满足岗位要求的拟接收应届毕业生，我院与其签订事业单位聘用合同，办理接收手续。

五、待遇

被录用的应届毕业生，我院按照国家关于事业单位工作人员收入分配的有关规定，执行相应的工资及福利待遇。

中国国土资源经济研究院
