# 国家质量监督检验检疫总局公告2015年第85号——质检总局关于受理北京冠捷显示产品等产品申报生态原产地产品保护的公告

## 国家质量监督检验检疫总局公告

2015年第85号

## 质检总局关于受理北京冠捷显示产品等产品申报生态原产地产品保护的公告

日前，冠捷显示科技（中国）有限公司等单位申请对北京冠捷显示产品等4个产品进行生态原产地产品保护。根据《原产地标记管理规定》及其实施办法和《生态原产地产品保护工作导则》《生态原产地产品保护评定通则》等规定，经北京、江苏、浙江出入境检验检疫局初审，我局委托北京万诚信用评价有限公司、中国生态道德教育促进会、中国检验认证集团测试技术有限公司评定，北京冠捷显示产品等4个产品符合相关规定的保护条件，我局拟对其实施生态原产地产品保护。现将本次拟保护的产品及相关信息公告如下：

|  |  |  |
| --- | --- | --- |
| 序号 | 产品名称 | 申报单位 |
| 1 | 北京冠捷显示产品 | 冠捷显示科技（中国）有限公司 |
| 2 | 北京天海气瓶 | 北京天海工业有限公司 |
| 3 | 依源牌铁皮石斛及其制品 | 苏州神元生物科技股份有限公司 |
| 4 | 森山铁皮枫斗及其制品 | 浙江森宇实业有限公司 |

如有关单位或个人对上述产品申请生态原产地产品保护持有异议，可自公示之日起1个月内向我局生态原产地产品保护管理办公室书面提出，并说明异议具体内容及理由。
