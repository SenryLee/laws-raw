# 国家铁路局综合司关于开展铁路行业科技创新基地申报工作的通知

根据《铁路行业科技创新基地管理办法（试行）》（国铁科法规〔2020〕38号，以下简称《办法》），国家铁路局决定开展铁路行业科技创新基地申报工作。现将有关事项通知如下：

一、研究方向

本次铁路行业科技创新基地的申报包括以下研究领域的重点研究方向。

（一）移动装备

1.高速列车本构安全技术

2.重载快捷货运装备技术

3.磁浮交通装备技术

（二）基础设施

1.特殊复杂环境下长大桥梁建造技术

2.特殊复杂环境下长大隧道建造技术

3.BIM技术应用研究

（三）能源牵引

1.铁路牵引供电系统建设与运维技术

2.铁路新型能源系统技术

3.新型铁路供电技术

（四）通信控制

1.新一代铁路移动通信技术

2.列车自主运行控制技术

3.北斗基定位导航与数据传输铁路应用技术

4.铁路电磁安全与防护技术

（五）安全保障

1.铁路运营主动安全保障与风险防控技术

2.重大突发公共事件下铁路应急处置技术

二、申报要求

（一）申报单位应为拟申报铁路行业科技创新基地的依托单位，请根据《办法》有关规定，切实做好申报组织和申报材料审核确认工作，并应在基地建设发展中给予明确的政策、资金支持。

（二）已认定的国家工程研究中心、国家重点实验室等国家级科技创新基地不再列入铁路行业科技创新基地申报范围。

（三）拟申报基地的名称应精简凝练，准确反映基地的重点研究方向，并统筹考虑未来发展需要。

（四）申报材料中使用的统计数据时间为2015年10月1日至2020年9月30日。

（五）请于2020年10月23日前，将铁路行业科技创新基地申请表（见附件）一式1份（另附申报材料电子版，光盘刻录）寄送至北京市海淀区复兴路6号院国家铁路局科技与法制司综合技术处（100891），逾期不予受理。

按照《办法》规定，国家铁路局将组织进行综合评估后公布2020年铁路行业科技创新基地认定结果。
