# 国家文物局关于在青岛德国建筑基督教堂建控地带内建设地铁出入口及附属设施意见的函

文物保函〔2020〕901号

山东省文化和旅游厅：

你厅《关于报送在全国重点文物保护单位——青岛德国建筑基督教堂建设控制地带内建设地铁出入口及附属设施的请示》（鲁文旅呈〔2020〕154号）收悉。经研究，我局原则同意在青岛德国建筑基督教堂建设控制地带内建设青岛市地铁4号线沂水路站地铁出入口及附属设施。

一、所报项目方案尚需作以下必要的修改：

（一）补充工程调整后地铁站施工完整方案，补充工程开挖范围与基督教堂保护范围和建设控制地带关系的图纸。

（二）A2出入口施工须严格遵循“短进尺、弱爆破、勤监测”原则，将爆破振速控制在安全允许值内。补充沂水路站车站主体结构爆破施工时监测数据和分析报告，论证A2出入口施工时基督教堂的安全性，进一步优化施工措施，并加强文物建筑变形监测。

（三）地铁工程在此段轨道的设计中，需采用高等级轨道防振措施，列车运行振动要满足《古建筑防工业振动技术规范》（GB/T50452-2008）标准要求，尽可能减少地铁日常运行对文物建筑的不利影响。同时，应建立长期的基督教堂建筑稳定性监测。

（四）增加该段地铁施工中预防塌方等突发事件的防控预案。

二、请你厅指导相关单位根据以上意见对所报项目方案进行完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你厅会同相关部门加强对项目实施的全程监管，组织专业机构参与指导，确保文物安全。项目实施中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2020年9月21日
