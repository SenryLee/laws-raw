# 国家文物局办公室关于贵州保利文物古建有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2020〕357号

贵州省文化和旅游厅：

你厅《关于贵州保利文物古建有限公司文物保护工程施工资质有关事项变更的请示》（黔文旅呈〔2020〕19号）收悉。

经研究，我局同意贵州保利文物古建有限公司文物保护工程施工一级资质证书中的单位地址由“贵州省贵阳市观山湖区百花湖乡温水村”变更为“贵州省贵阳市观山湖区阳关大道麒龙商务港A地块2号楼15层6号”，法定代表人由“孙钦铧”变更为“饶剑”，经济性质由“有限责任公司”变更为“有限责任公司（自然人投资或控股）”，注册资金由“2000万元”变更为“13500万元”。请你厅通知申请单位携带资质证书副本到我局办理相关手续。

请你厅指导督促资质单位按照我局《关于上线试运行全国文物保护工程资质单位数据库和甲、一级资质单位在线管理系统的通知》（文物保函〔2019〕1253号）要求，尽快完成数据库填报工作，所报信息经审核通过后，甲一级资质单位的信息变更须通过在线管理系统申请办理。

国家文物局办公室

2020年5月12日
