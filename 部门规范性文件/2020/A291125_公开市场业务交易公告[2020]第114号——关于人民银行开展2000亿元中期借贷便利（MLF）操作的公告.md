# 公开市场业务交易公告[2020]第114号——关于人民银行开展2000亿元中期借贷便利（MLF）操作的公告

## 公开市场业务交易公告

[2020]第114号

2020年6月15日，为维护银行体系流动性合理充裕，人民银行开展2000亿元中期借贷便利（MLF）操作，充分满足了金融机构需求。今日无逆回购操作。具体情况如下：

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 2000亿元 | 2.95% |

中国人民银行公开市场业务操作室

二〇二〇年六月十五日
