# 中国人民银行关于2020年9月25日人民银行以利率招标方式开展了900亿元逆回购操作的公告

## 公开市场业务交易公告

[2020]第190号

为维护季末流动性平稳，2020年9月25日人民银行以利率招标方式开展了900亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 14天 | 900亿元 | 2.35% |
