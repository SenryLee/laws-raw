# 文化和旅游部对十三届全国人大三次会议第3158号建议的答复

您提出的《关于发展特色文化产业促进西部少数民族地区脱贫攻坚的建议》收悉，经商农业农村部、国务院扶贫办，现答复如下：

我国西部少数民族地区文化资源富集、文化积淀深厚，具备发展文化产业的天然基础，推动西部少数民族地区特色文化产业发展对于促进区域协调发展、助力经济发展方式转变、巩固脱贫成果、促进优秀民族文化传承与弘扬具有重要意义。近年来，我部会同有关部门，深入贯彻党中央、国务院关于脱贫攻坚有关决策部署，通过加强规划引导、支持项目建设、搭建支撑平台、强化人才培养等方式，鼓励和支持包括西部少数民族地区在内的贫困地区深入挖掘历史文化、红色文化、优秀民族文化、非物质文化遗产（以下简称“非遗”）等特色资源发展特色文化产业，推动将特色资源优势转化为产业优势。

一、关于加大资金投入，完善基础设施

党中央、国务院高度重视农村基础设施建设对脱贫攻坚、乡村振兴的重要支撑作用，对加强农村公共基础设施建设作出明确部署。国务院办公厅印发《关于创新农村基础设施投融资体制机制的指导意见》《关于保持基础设施领域补短板力度的指导意见》，要求聚焦脱贫攻坚、农业农村等重点领域，进一步加大基础设施建设力度。2019年，经中央全面深化改革委员会审议通过，发展改革委、财政部联合印发《关于深化农村公共基础设施管护体制改革的指导意见》，着力提升管护水平和质量。农业农村部立足职能，制定出台《社会资本投资农业农村指引》，引导社会资本有序投入农业农村。农业农村部联合发展改革委组织实施农村人居环境整治整县推进项目，2020年落实中央预算内投资30亿元，推进157个县开展垃圾污水治理等基础设施建设。

国务院扶贫办配合财政部开展支持贫困县统筹整合使用财政涉农资金试点工作，通过整合各类涉农资金投入贫困地区，支持实施一批基础设施建设项目。

我部配合发展改革委实施“十三五”时期文化旅游提升工程，累计支持西部地区1168个文化和旅游基础设施建设项目，下达中央预算内资金154亿元。在电子商务方面，2020年“文化和自然遗产日”，我部会同商务部、国务院扶贫办共同支持阿里巴巴、京东、拼多多等网络平台举办“非遗购物节”，搭建起非遗等特色文化产品和旅游商品从农村到城市、从线下到线上的桥梁，打通相关产品从生产到销售的“最后一公里”。据统计，“非遗购物节”当天，各电商平台相关产品下单数超过300万笔，销量超过800万件，成交金额近4亿元。

下一步，农业农村部将立足职能，与有关部门强化沟通协调、协作配合，进一步推动补齐农村地区公共基础设施建设短板，为乡村地区产业发展、脱贫攻坚提供支持，不断增强广大群众的获得感、幸福感和安全感。国务院扶贫办将进一步研究落实文化和旅游扶贫政策措施，持续推动贫困村基础设施建设。我部将进一步加强与发展改革委、国务院扶贫办等部门的沟通对接，在明确中央和地方财权事权和支出责任划分的基础上，积极为贫困地区文化和旅游相关基础设施建设争取资金支持。

二、关于开展技能培训，增强就业脱贫

我部高度重视提升包括西部少数民族地区在内的贫困地区文化产业人才队伍建设水平。一是结合主办各类文化产业培训班，加大对西部少数民族地区的支持，并通过资金、师资等方式，支持西部少数民族地区实施人才培训项目，培养一批熟悉文化产业政策，具备较强规划、组织、策划、实施能力的人才。2004年至2018年，举办西部文化产业经营管理人才培训班14期，累计培训超过1500人次。组织实施“文化产业双创扶持计划”，引导支持文化企业、机构面向贫困地区，通过产业培育、吸纳就业、技能培训等方式开展文化产业扶贫。二是以传统工艺为重点实施中国非遗传承人群研修研习培训计划，2015年以来，支持在云南大理、新疆哈密、青海果洛等贫困地区、少数民族地区设立15家传统工艺工作站，帮助当地传承人群提高传承能力，促进就业生产，其中有7家设立在西部地区。联合国务院扶贫办确定包括云南怒江在内的10个“非遗+扶贫”重点支持地区，建设非遗扶贫就业工坊，全面推进非遗助力精准扶贫，帮助建档立卡贫困人员学习传统工艺和相关技能，带动贫困户就业增收、实现脱贫。

下一步，我部将继续结合实施文化产业相关人才培训以及中国非遗传承人群研修研习培训计划，进一步加大对西部少数民族地区特色文化产业人才队伍建设的支持力度，通过开展就业技能、经营管理能力等实用性培训，强化特色产业发展的人才支撑，助力贫困人口就业增收。

三、关于培育龙头企业，增强市场主体的带动性、益贫性

我部高度重视培育和发展各类文化市场主体，通过支持文化企业发展、打造优势品牌、促进创新创业等，带动西部少数民族地区文化产业发展质量效益持续提升。一是结合举办相关重点展会、项目对接会等活动，加强对西部少数民族地区文化企业、项目的宣传推介，通过引入各类优质资源与当地文化企业、项目对接，促进双方在投融资、研发、技术、市场、人才等多方面开展交流合作。二是培育特色品牌。组织实施藏羌彝特色文化品牌培育项目征集遴选等工作，支持文化企业打造特色品牌。通过“创意下乡”活动，对民间手工艺、民居、餐饮等特色资源深入挖掘、提炼，加强人员培训和交流，打造特色产业品牌。三是结合推动文化产业创新创业，支持西部少数民族地区完善文化产业领域创新创业服务体系、搭建支撑平台，以特色文化产业创新创业项目实施，带动贫困人口就业增收。

下一步，我部将继续关注西部少数民族地区文化企业发展，进一步加大对优质文化企业、项目的宣传推介力度，促进对接合作，加强指导和服务，支持重点文化企业做强做大做优，发挥示范带动作用。鼓励和支持西部少数民族地区文化企业深入挖掘特色资源，发展具备地方特色和民族风情的特色文化产业，为企业开展的品牌培育等工作搭建支撑平台，鼓励授权合作。持续推动文化产业领域创新创业，促进西部少数民族地区文化产业发展。

四、关于创新管理机制，提升特色文化产业扶贫整体效益

我部高度重视完善推动特色文化产业发展的体制机制保障。一是积极加强与发展改革委、财政部、国务院扶贫办等部门的沟通联络，争取相关政策、资金支持，各地也围绕推动特色文化产业发展积极建立相关工作机制。目前，各级、各部门协同推进特色文化产业发展的格局已基本形成，您提出的建立相关机制的建议在工作中已有体现。二是以在西部地区命名的6家国家级文化产业示范园区及创建园区、3家国家级文化产业试验园区和93家国家文化产业示范基地为依托，持续推动提升园区、基地建设水平，通过集聚资源、服务企业，发挥典型示范和引领带动作用，助推文化产业高质量发展。三是建设完善文化和旅游部产业公共服务平台，共建设子平台（系统）13个，为产业发展提供人才培养、品牌服务、项目服务、投融资对接、国际交流合作等方面的支撑。四是在产业扶贫相关项目实施中，注重事中事后监管，会同相关省级文化和旅游部门，实时跟进项目实施，确保相关资金用到实处、发挥实效。

下一步，我部将继续与有关部门密切协作，并加强与西部少数民族地区各级文化和旅游部门的沟通联络，加强对特色文化产业发展的支持指导，推动将产业扶贫各项决策部署落到实处。进一步完善支持机制，加大投入力度，全面推进非遗助力精准扶贫工作。加强对国家级文化产业示范园区、试验园区和国家文化产业示范基地的支持指导，推动获创建资格的国家级文化产业示范园区规范开展创建工作。做好文化和旅游产业公共服务平台建设，提升服务质量。

感谢您对文化和旅游工作的关心与支持！

文化和旅游部
