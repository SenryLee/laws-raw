# 国家文物局关于授予北京建工建筑设计研究院等单位文物保护工程甲一级资质的通知

文物保发〔2020〕1号

各省、自治区、直辖市文物局（文化和旅游厅/局），新疆生产建设兵团文物局：

根据《中华人民共和国文物保护法》《中华人民共和国文物保护法实施条例》和《文物保护工程管理办法》《文物保护工程勘察设计资质管理办法》《文物保护工程施工资质管理办法》《文物保护工程监理资质管理办法》（试行）的有关规定，经审核并公示，我局决定授予北京建工建筑设计研究院等单位文物保护工程甲一级资质（名单见附件）。请根据有关规定，进一步加强相关管理工作。

特此通知。

附件：1．增加业务范围的勘察设计甲级资质单位名单

2．升级的勘察设计甲级资质单位名单

3．增加业务范围的施工一级资质单位名单

4．升级的施工一级资质单位名单

国家文物局

2020年1月6日
