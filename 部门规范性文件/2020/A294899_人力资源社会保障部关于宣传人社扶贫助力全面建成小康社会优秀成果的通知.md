# 人力资源社会保障部关于宣传人社扶贫助力全面建成小康社会优秀成果的通知

人社部函〔2020〕101号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）：

为深入贯彻落实习近平总书记关于“脱贫攻坚既要做得好，也要讲得好”重要讲话精神，经部领导审定，今年5月下旬部办公厅印发了《关于开展人社扶贫助力全面建成小康社会优秀成果宣介活动的通知》。活动启动以来，各级人社部门认真组织、积极推荐，共向部活动工作小组推荐218个优秀成果备选对象。9月，人社部微信公众号展示了174个初选结果。这些备选对象汇聚了众多触动人心、实效突出的人社扶贫经验做法，展现了奋战在一线、勇于担当、迎难而上的人社扶贫干部风采，挖掘了一批帮扶与自强相结合的就业脱贫贫困劳动力的感人脱贫故事，获点赞总数达1624万个。经认真评审，最终选出100个优秀成果，其中人社扶贫工作优秀案例40个、人社扶贫优秀干部40名、帮扶与自强相结合的就业脱贫贫困劳动力典型20名（见附件）。这些优秀成果涉及人社扶贫各领域，是人社扶贫工作的先进代表，创造了生动鲜活的扶贫实践，凝结着广大人社干部的智慧、心血和汗水，是人社扶贫成果的集中体现。

各级人力资源社会保障部门要按照中央决策部署，切实发挥职能作用，学习优秀成果的经验做法，扎实开展工作，让人社扶贫惠民政策更好助力贫困群众脱贫，高质量完成人社扶贫目标任务。要采取多种方式加强人社扶贫优秀成果宣传，进一步扩大人社扶贫工作社会影响力和感染力，树立人社部门心系人民、服务民生的良好形象，营造全面建成小康社会良好氛围。
