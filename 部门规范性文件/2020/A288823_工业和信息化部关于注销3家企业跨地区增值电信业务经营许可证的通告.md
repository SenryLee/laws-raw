# 工业和信息化部关于注销3家企业跨地区增值电信业务经营许可证的通告

近期，中科凯普（天津）卫星导航通信技术有限公司等3家企业（详见附件）向工业和信息化部提交申请，要求注销其持有的跨地区增值电信业务经营许可证，并依据《电信业务经营许可管理办法》（工业和信息化部令第42号）规定，提交了股东会关于终止经营的决定、做好用户善后处理工作承诺书及解决用户善后问题的情况说明等材料。

为维护市场秩序，保障用户合法权益，工业和信息化部于2020年2月12日起至2020年3月11日公示了上述企业拟注销跨地区增值电信业务经营许可证的相关信息，听取社会意见，接受社会监督。公示期未收到异议。

经审核，工业和信息化部认为中科凯普（天津）卫星导航通信技术有限公司等3企业符合退出电信业务市场条件，根据《电信业务经营许可管理办法》第三十一条规定，现注销其相关跨地区增值电信业务经营许可证。

特此通告。

附件：注销跨地区增值电信业务经营许可的企业名单（2020年第2批）
