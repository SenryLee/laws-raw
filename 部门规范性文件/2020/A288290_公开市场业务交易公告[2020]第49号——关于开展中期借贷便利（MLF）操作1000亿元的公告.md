# 公开市场业务交易公告[2020]第49号——关于开展中期借贷便利（MLF）操作1000亿元的公告

## 公开市场业务交易公告

[2020]第49号

2020年3月16日，人民银行实施定向降准，释放长期资金5500亿元。同时，开展中期借贷便利（MLF）操作1000亿元。今日不开展逆回购操作。具体情况如下：

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 1000亿元 | 3.15% |

中国人民银行公开市场业务操作室

二〇二〇年三月十六日
