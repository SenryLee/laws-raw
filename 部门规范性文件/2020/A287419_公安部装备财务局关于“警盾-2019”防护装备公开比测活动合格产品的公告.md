# 公安部装备财务局关于“警盾-2019”防护装备公开比测活动合格产品的公告

## 关于“警盾-2019”防护装备公开比测活动合格产品的公告

公装财〔2020〕51号

为提升警用防护装备质量、保护公安民警生命安全，经报公安部领导批准，2019年8月至12月，我局组织开展了“警盾-2019”防护装备公开比测活动，对国内91家企业328型警用防弹头盔和防弹衣进行了比赛测试。比测活动公开报名，企业自愿免费参加，比测规则公开发布，检测机构公开招标确定，样品去标识盲测，全程阳光透明、公平公正。

现将比测合格产品公开发布，欢迎社会各界和警用装备生产企业继续关注和参与“警盾”系列比测活动，不断提高警用防护装备质量，促进警用装备在开放、公平、竞争的环境中持续健康发展。

附件：“警盾-2019”防护装备公开比测活动合格产品

公安部装备财务局

2020年1月22日
