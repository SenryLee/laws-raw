# 公开市场业务交易公告[2020]第29号——关于2020年2月17日人民银行开展了2000亿元中期借贷便利（MLF）操作和1000亿元7天期逆回购操作的公告

## 公开市场业务交易公告

[2020]第29号

为对冲央行逆回购到期等因素的影响，维护银行体系流动性合理充裕，2020年2月17日人民银行开展了2000亿元中期借贷便利（MLF）操作和1000亿元7天期逆回购操作。具体情况如下：

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 2000亿元 | 3.15% |

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 1000亿元 | 2.40% |

中国人民银行公开市场业务操作室

二〇二〇年二月十七日
