# 农业农村部对十三届全国人大三次会议第1783号建议的答复

## 对十三届全国人大三次会议第1783号建议的答复

农办议〔2020〕400号

欧阳华代表：

您提出的关于实施乡村振兴注重绿色产业发展的建议收悉。经商科技部、教育部、工业和信息化部、文化和旅游部、财政部，现答复如下。

一、关于创新绿色发展路径试点

国家相关部门结合不同行业发展特点，指导不同地区结合实际探索绿色产业发展典型路径。一是2017年中办、国办印发《关于创新体制机制推进农业绿色发展的意见》，成为指导当前和今后一个时期农业绿色发展的纲领性文件。为推动农业绿色发展，指导各地大力开展绿色发展先行先试工作，我部会同国家发展改革委等7部门评估确定两批80个国家农业绿色发展先行区。各先行区围绕农业废弃物资源化利用、提升绿色优质农产品供给等开展先行先试，初步探索出一批可推广可复制的发展模式。二是2019年我部印发《农业绿色发展先行先试支撑体系建设管理办法（试行）》，进一步建立和完善绿色农业技术体系、标准体系、产业体系、经营体系、政策体系和数字体系等六大体系，开展长期固定观测试验站建设，为强化农业绿色发展提供支撑。三是工业和信息化部深入实施绿色制造工程，发布一批绿色制造系统集成项目典型案例，培育一批绿色制造系统解决方案供应商，为1万多家工业企业提供绿色制造系统集成服务，在钢铁、化工等重点行业累计创建1402家绿色工厂、118个绿色工业园区，遴选1097种绿色设计产品。

下一步，我部将会同有关部门加强联系指导，深入开展调查研究，培育一批绿色制造供应商、节能诊断服务商，进一步推动相关领域绿色发展先行先试工作取得实效。

二、关于构建绿色技术创新体系

国家相关部门通过出台文件、建设创新平台、培养创新人才、成立科技创新联盟等措施，持续提升绿色技术创新水平。一是2018年教育部制定发布《高等学校乡村振兴科技创新行动计划（2018—2022年）》，推动高校加快构建服务支撑乡村振兴科技创新体系。立项建设“长江经济带大宗水生生物产业绿色发展”等5个教育部工程研究中心，强化绿色技术研发，深化校企、校地合作。实施人才培养提质行动计划，完善乡村振兴人才培养模式，加快培养不同类型农林人才，打造一支懂农业、爱农村、爱农民的乡村振兴人才队伍。二是科技部建成节水灌溉、农产品保鲜、生物农药等国家工程技术研究中心，在绿色技术领域开展工程技术研发、成果转化与产业化、技术培训推广等。同时，建成以“干旱半干旱地区现代农业发展”“有机旱作农业”为主题的国家农业高新技术产业示范区，推广和应用绿色产业技术。三是我部印发《农业绿色发展技术导则（2018—2030年）》，着力推动构建支撑农业绿色发展的技术体系，引导全国农业科技创新重点转移到绿色发展。为推进产学研用深度融合，成立东北玉米秸秆综合利用、华北地下水超采区节水增效等国家农业科技创新联盟。

下一步，我部将会同相关部门统筹推进国家农业高新技术产业示范区等基地平台建设，推动绿色投入品创制、绿色循环模式创新和高校人才培养，支持农业绿色产业创新发展。

三、关于促进绿色技术创新成果转化

为加快科技成果转化，国家相关部门印发行动计划、推动技术成果示范应用、培育服务机构，不断提升成果转化水平。一是2016年教育部印发《促进高等学校科技成果转移转化行动计划》，明确提出“建立科技成果协同创新机制，完善科技成果转移转化市场需求导向”，积极引导高校加强科技成果展示与推广构建线上信息服务与线下实体服务相结合的高校科技成果转移转化服务网络和服务体系。二是我部示范推广北斗导航下智慧麦作技术、畜禽粪污异位发酵床、集装箱绿色高效循环水养殖技术等一大批绿色高效技术模式，促进相关产业提质增效转型升级。同时，不断推动技术成果示范应用，在全国建设秸秆打捆直燃技术试点150处，在西北地区建设100个农膜回收示范县。三是工业和信息化部加大传统行业绿色化改造的力度，大力培育工业节能与绿色发展第三方服务机构，2019年为3536家企业提供工业节能诊断服务，挖掘企业节能潜力。

下一步，我部将会同相关部门培育建设一批绿色产业相关技术成果转化基地，推动先进节能节水、资源综合利用、环保技术成果转化和示范应用。

四、关于实施乡村绿色生态引领行动

国家相关部门高度重视生态宜居乡村建设，以绿色发展引领乡村建设。一是2019年国办印发《关于切实加强高标准农田建设提升国家粮食安全保障能力的意见》，要求各地开展绿色农田建设示范，推动耕地质量保护提升、生态涵养、农业面源污染防治和田园生态改善有机融合。截至目前，我部分解下达各地高标准农田建设任务约2.4亿亩。二是2016年以来，我部会同财政部等有关部门扎实推进耕地轮作休耕制度试点工作，试点面积由616万亩扩大到3112万亩，试点省份由9个增加到17个，指导各地集成示范综合配套技术体系。三是我部全面推进标准化生产、加快推进追溯管理体系建设、品牌化生产，主要农产品例行监测合格率97%以上、在国家农产品质量安全追溯平台上传数据量达11.3万条、“两品一标”农产品总数超过4.3万个，2019年会同财政部启动实施地理标志农产品保护工程，针对一批特色农产品开展保护提升。

下一步，我部将会同相关部门指导各地因地制宜开展绿色农田建设示范，继续推进耕地轮作休耕制度试点，全面推进国家追溯平台推广应用，开展追溯示范创建，加快农产品地理标志有序健康发展。

五、关于强化特色小镇绿色产业功能

国家相关部门高度重视城乡统筹发展，结合特色产业、优势资源挖掘等，持续为乡村振兴注入绿色发展新动能。一是2016年住房城乡建设部、国家发展改革委、财政部印发《关于开展特色小镇培育工作的通知》，明确提出“产业定位准确，特色鲜明，战略新兴产业、传统产业、现代农业等发展良好、前景可观”的培育要求。二是2018年文化和旅游部会同相关部门印发《关于促进乡村旅游可持续发展的指导意见》，将“生态优先，绿色发展”作为发展原则之一，注重开发与保护并举，因地制宜发展生态资源依托型乡村旅游产业。截至2017年，认定两批403个全国特色小镇，其中包括宜兴市丁蜀镇。三是2019年文化和旅游部联合国家发展改革委启动全国乡村旅游重点村名录建设工作，截至目前已公布两批1000个全国乡村旅游重点村，其中包括江苏省宜兴市西渚镇白塔村，并且中国农业银行在首批320个重点村贷款余额达74亿元，用于支持重点村文化和旅游产品的开发与推广。

下一步，我部将会同有关部门加强政策指导与项目建设，发挥优质品牌示范带动作用，加强乡村旅游智慧化建设，促进乡村产业振兴和生态振兴。

六、关于建立绿色产业综合配套政策

近年来，国家相关部门采取税收优惠、环保补助、绿色信贷等配套政策措施，积极支持绿色产业创新发展。一是财政部对纳税人从事《资源综合利用产品和劳务增值税优惠目录》中所列的资源综合利用项目，实行增值税即征即退政策，对符合环保条件的企业可享受企业所得税优惠政策，对符合国家和地方规定应税污染物排放相关标准的可免征或减少环境保护税。二是中央财政通过农业资源及生态保护补助资金支持包括江苏省在内的各省推进农业绿色发展，各地可按照政策要求在实施方案范围内开展相关工作。三是工业和信息化部实施绿色标准化行动计划，研究制定一批节能、节水、资源综合利用、绿色制造等领域绿色标准，加大绿色信贷对县域工业的支持力度，与中国农业银行合作，支持在县域经济中积极发展绿色产业，开发绿色技术和产品。

下一步，我部将会同有关部门继续做好现行税收优惠等政策的宣传和落实工作，同时不断完善相关政策措施，切实加强农业生态资源保护。

感谢您对我部工作的关心，希望继续对“三农”工作给予支持。
