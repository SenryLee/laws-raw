# 国家文物局关于公布2019年度全国博物馆名录的通知

文物博发〔2020〕9号

各省、自治区、直辖市文物局（文化和旅游厅/局），新疆生产建设兵团文物局：

依据《博物馆条例》《博物馆管理办法》有关规定，现将2019年度全国博物馆名录予以公布。

请各省、自治区、直辖市文物局（文化和旅游厅/局），新疆生产建设兵团文物局继续做好博物馆数据的备案与公开工作，逐步建立博物馆年报制度和信息公开制度，主动接受社会监督，更好发挥博物馆公益属性和公共服务功能。

特此通知。

附件：2019年度全国博物馆名录

国家文物局
