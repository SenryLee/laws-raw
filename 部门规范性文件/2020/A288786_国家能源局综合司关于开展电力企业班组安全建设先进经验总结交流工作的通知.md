# 国家能源局综合司关于开展电力企业班组安全建设先进经验总结交流工作的通知

各派出机构，全国电力安全生产委员会各企业成员单位，各有关电力企业：

为贯彻落实《2020年电力安全监管重点任务》工作部署，充分发挥先进典型的示范引领和正面导向作用，促进电力企业进一步夯实安全生产基础，推动安全生产主体责任落地落实，防范遏制各类事故发生，现就开展电力企业班组安全建设先进经验总结交流工作通知如下。

各电力企业要及时梳理发现所属单位在班组安全建设方面的典型案例，提炼成熟可行、有效管用的工作经验，按照“实践、评估、优化、再实践”的模式，持续完善班组安全建设方式方法和管理措施，并在单位系统内宣介推广和借鉴学习，大力营造“比、学、赶、帮、超”的安全生产良好氛围，促进所有基层班组和一线人员的安全意识、技能、管理等综合素养全面提升。

请各电力企业认真组织所属单位特别是基层单位总结班组安全建设工作，包括体制机制设计、规章制度建立、标准规程执行、教育培训实施、安全投入保障、安全活动开展、外包队伍班组管理、作业现场管控、技术和管理手段改进创新、事故教训汲取和经验反馈、安全文化建设、人文关怀和问题化解等方面工作的开展情况及取得的成效，形成文字材料（含电子版），随时报送我局电力安全监管司。

请各派出机构及时将本通知转发辖区内电力企业，督促企业积极开展班组安全建设先进经验总结交流工作。

我局将对各企业报送的典型案例和经验总结材料开展审查筛选，择优在《电力安全信息》刊发，并在国家能源局门户网站发布或向《中国电力报》、中国电力新闻网等行业媒体平台推荐登载；根据工作开展情况，还将适时通过召开现场交流会等形式向全行业推广介绍优秀经验。

## 文字材料有关要求

1. 标题要简练易懂，可以涵盖案例和经验的核心内容。

2. 材料内容要客观真实，可以是班组安全建设的某一方面工作，也可以是几个方面的工作，但要重点阐述工作开展过程和已取得的实效。

3. 字数宜控制在2000字以内，可配相关图表。

4. 需注明报送单位名称及联系人姓名、职务、电话、通信地址。
