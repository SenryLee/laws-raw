# 国家体育总局办公厅关于做好2019年度机关文书档案立卷归档工作的补充通知

## 体育总局办公厅关于做好2019年度机关文书档案立卷归档工作的补充通知

各司、局：

鉴于新冠肺炎疫情防控期间不宜举办线下集中培训，为顺利完成总局机关2019年度文书档案立卷归档工作，提升立卷整理质量，根据国家档案局和体育总局相关制度规定、标准规范，我们制定了《文书档案立卷归档操作说明》予以印发，供大家学习参考。相关文档可在“国家体育总局政府网站办公厅页面（http://www.sport.gov.cn/bgt/）的文件公告栏目”中查看并下载。

各部门档案移交时间延长至2020年5月31日。

附件：1. 文书档案立卷归档操作说明

2. 关于印发《国家体育总局文件材料归档范围和文书档案保管期限规定》的通知

体育总局办公厅

2020年3月10日
