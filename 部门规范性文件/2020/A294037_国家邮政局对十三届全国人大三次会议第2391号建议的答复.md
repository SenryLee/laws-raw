# 国家邮政局对十三届全国人大三次会议第2391号建议的答复

## 对十三届全国人大三次会议第2391号建议的答复

国邮函〔2020〕97号

史贵禄代表：

您提出的关于“村村通快递，打通村民致富最后一公里”的建议（第2391号）收悉。经商交通运输部、中华全国供销合作总社，现答复如下：

国家邮政局以及相关部门和单位一直高度重视农村快递物流发展，会同相关部委开展了大量的工作。

一是健全配套政策。2019年，国家邮政局联合国家发展改革委、财政部、农业农村部、商务部、文化和旅游部、中华全国供销合作总社出台《关于推进邮政业服务乡村振兴的意见》，支持县、乡、村三级快递物流体系建设，持续提升邮政业服务“三农”能力。“不忘初心、牢记使命”主题教育期间，国家邮政局提出“快递进村”工程。2020年，印发《“快递进村”三年行动方案（2020-2022年）》，明确发展目标、主要模式和工作要求。此外，推动国务院办公厅在2019年印发的《交通运输领域中央与地方财政事权和支出责任划分改革方案》中，明确将快递服务末端基础设施相关职责列入地方事权，为争取地方财政资金，支持农村快递发展，提供了有效支撑。

二是推动资源集约共享。国家邮政局研究提出邮快合作、快快合作、驻村设点、快交合作、快商合作、其他合作等6种“快递进村”的主要模式，鼓励市场主体成本共担、资源共享，实现合作共赢。在邮快合作方面，2019年，国家邮政局组织在黑龙江、四川、甘肃、青海、西藏5省（区）开展试点。目前，邮快合作不仅在5个试点省（区）进展良好，还带动24个省（区、市）积极参与。在快交合作方面，2019年，交通运输部、国家邮政局、中国邮政集团有限公司联合印发《关于深化交通运输与邮政快递融合推进农村物流高质量发展的意见》，还组织开展农村物流服务品牌宣传推广工作。目前，首批25个农村物流服务品牌项目已向社会公布。

三是注重发挥供销合作社作用。中华全国供销合作总社持续推进“新农村现代流通服务网络工程”，大力发展连锁经营、物流配送等现代流通方式，完善城乡经营网络覆盖。目前，供销合作系统有连锁企业5997家、配送中心9663个，发展连锁、配送网点84.6万个。供销合作企业还与邮政、快递等企业加强业务合作。供销合作系统近1800家开展配送业务的企业中，已有80%以上与邮政、顺丰等开展合作。中华全国供销合作总社还加快农产品冷链物流体系建设，专门成立中国供销冷链物流有限公司，优化冷链物流设施布局，加快提升冷链物流水平。

四是规范农村快递服务。2019年，针对群众反映的乡镇快递末端网点违规收费现象，国家邮政局在全国组织开展两轮专项清理整顿，对违规收费行为形成了强力震慑，有力地维护了用户合法权益。2020年，将快递末端网点违规收费行为纳入常态化监管事项，持续保持对违法行为的监管打击力度。在打击违法行为的同时，督促快递企业落实《快递暂行条例》规定，遵守共同的服务约定，在服务质量、安全保障、业务流程等方面实行统一管理，加强人员培训，提升队伍专业化水平。

您在建议中对农村快递物流的短板进行了深入分析，所提政策建议针对性强，对推进农村快递物流体系建设具有积极的借鉴意义。2020年，国家邮政局在全国范围内启动“快递进村”工程。各地将按照《“快递进村”三年行动方案（2020-2022年）》确定的任务目标，分阶段有序推进快递服务直投到村。同时，组织在河北、内蒙古、黑龙江、江苏、安徽、青海6个省（区）和太原、吉林、济宁、驻马店、黄冈等15个市（州）开展“快递进村”试点，健全基础网络，优化发展环境，推动融合发展，提升服务质效，以试点工作带动全国“快递进村”工程更快、更好推进。下一步，国家邮政局将持续优化农村快递发展环境，积极争取更多有利政策出台，在快递业“十四五”规划中重点谋划农村快递物流体系建设。同时，持续推进“快递进村”工程，推广多种合作模式，加强农村快递服务规范化建设，提升农村快递服务专业化水平。交通运输部将以持续提升农村物流服务网络覆盖率为主线，结合农村物流服务品牌建设，进一步促进交通运输与邮政快递融合发展。中华全国供销合作总社将推进实施“供销合作社培育壮大工程”，鼓励各级供销合作社与邮政、快递企业强化业务合作，共建高效便捷的农村快递物流体系。

感谢您对快递业发展的关心和支持！

国家邮政局

2020年9月2日
