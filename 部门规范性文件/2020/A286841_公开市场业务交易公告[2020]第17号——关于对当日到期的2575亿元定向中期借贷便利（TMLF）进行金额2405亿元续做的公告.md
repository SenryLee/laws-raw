# 公开市场业务交易公告[2020]第17号——关于对当日到期的2575亿元定向中期借贷便利（TMLF）进行金额2405亿元续做的公告

## 公开市场业务交易公告

[2020]第17号

2020年1月23日，人民银行根据金融机构需求情况，对当日到期的2575亿元定向中期借贷便利（TMLF）进行了续做，续做金额为2405亿元。今日无逆回购操作。具体情况如下：

TMLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 1年 | 2405亿元 | 3.15% |

中国人民银行公开市场业务操作室

二〇二〇年一月二十三日
