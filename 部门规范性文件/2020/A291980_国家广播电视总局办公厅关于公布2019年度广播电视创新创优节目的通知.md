# 国家广播电视总局办公厅关于公布2019年度广播电视创新创优节目的通知

广电办发〔2020〕166号

各省、自治区、直辖市广播电视局，新疆生产建设兵团文化体育广电和旅游局，中央广播电视总台办公厅、中国教育电视台：

2019年，全国广播电视机构深入学习贯彻习近平新时代中国特色社会主义思想，聚焦“庆祝新中国成立70周年”主题，坚持以人民为中心的创作导向，深入生活、扎根人民，坚持“小成本、大情怀、正能量”，制作播出了一批弘扬主旋律、传承中华优秀传统文化、传播社会主义核心价值观、贴近时代、群众喜闻乐见的优秀节目，产生了良好社会效益。

为表彰创新创优节目，发挥优秀广播电视节目的示范引领作用，经评议，确定中央广播电视总台《共和国声音日历》、北京广播电视台《中共中央在香山》等6个广播节目，中央广播电视总台《故事里的中国》《中国地名大会》、上海广播电视台《这就是中国》、江苏电视台《从地球出发》等24个电视节目为“2019年度广播电视创新创优节目”，每个节目给予5万元的资金扶持；确定《我家住在解放路》《思想的田野》2个集体创作的节目为“2019年度广播电视创新创优特别节目”。

各级广播电视播出机构要认真学习借鉴这些节目的好做法、好经验，坚定文化自信，创作生产更多弘扬主旋律、传承中华优秀传统文化、传播社会主义核心价值观、具有鲜明中国特色和时代气息的优秀自主创新节目。

节目扶持资金由广电总局拨付至各省广播电视局、中央广播电视总台、中国教育电视台，各省广电局负责将扶持资金分发至所属获奖单位。请各省广电局、中央广播电视总台、中国教育电视台将收款收据和账户信息（收款单位、开户银行、账号）用邮政特快专递（EMS）邮寄至广电总局宣传司（地址：北京市西城区复兴门外大街2号，邮政编码：100866）。

附件：2019年度广播电视创新创优节目名单

国家广播电视总局办公厅

2020年7月10日
