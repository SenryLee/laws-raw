# 商务部办公厅关于转发财政部2019年度部门决算工作的通知

商办财函〔2020〕9号

各特派员办事处，各直属事业单位，有关驻外经商机构：

为做好2019年度部门决算编制工作，现将《财政部关于2019年度部门决算工作的通知》（财库[2019）54号，以下简称《通知》）转发给你们，并就有关事项通知如下：

一、请各单位高度重视、精心组织，按照《通知》要求，夯实决算编制基础，确保决算编制以收付实现制为基础、以预算会计核算生成的数据为准；依法依规编制决算，做到收支真实、数额准确、内容完整、报送及时。

二、请各单位务必于2020年2月14日前将决算报表、填报说明、分析报告及电子数据报送部财务司。相关单位应当按照财政部驻所在地监管局决算审核工作要求，将本单位决算同时抄送财政部驻所在地监管局。决算会审具体事项另行通知。

《通知》、部门决算报表软件、参数更新、报表编制说明等其他编审资料可登陆财政部网站-国库司频道-财政国库管理栏目下载（http://gks.mof.gov.cn/guokujizhongzhifuguanli_1/）。编报过程中有何问题，请及时与部财务司联系。

商务部办公厅

2020年1月9日
