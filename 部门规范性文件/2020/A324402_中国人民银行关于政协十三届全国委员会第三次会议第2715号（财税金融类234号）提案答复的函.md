# 中国人民银行关于政协十三届全国委员会第三次会议第2715号（财税金融类234号）提案答复的函

王鹏杰委员：

您提出的关于支持中小微企业发展的提案收悉，现将涉及我行职责范围的意见函告如下：

**一、**关于进一步推进金融体制改革，大力发展小微金融，缓解民营企业融资难、融资贵问题

人民银行高度重视支持中小微企业和民营企业发展。2019年以来，人民银行积极贯彻落实党中央、国务院决策部署，实施稳健的货币政策，改革完善贷款市场报价利率（LPR）形成机制，会同有关部门制定出台了一系列金融支持政策措施，督促引导金融机构持续加大对中小微企业的金融支持力度，缓解民营企业融资难融资贵问题。

（一）创新直达实体经济的货币政策工具。

一是出台中小微企业贷款延期还本付息政策。2020年6月出台《中国人民银行 银保监会 财政部 发展改革委 工业和信息化部关于进一步对中小微企业贷款实施阶段性延期还本付息的通知》（银发〔2020〕122号），将中小微企业贷款期限最长延至2021年3月底，对普惠小微贷款应延尽延，并对执行该政策的地方法人银行给予延期贷款本金的1%作为激励。

二是加大普惠小微信用贷款发放支持力度。2020年6月出台《中国人民银行 银保监会 财政部 发展改革委 工业和信息化部关于加大小微企业信用贷款支持力度的通知》（银发〔2020〕123号），通过再贷款专用额度购买符合条件的地方法人银行新发放普惠小微信用贷款的40%，激励银行增加小微信用贷款发放。

（二）加大中小微企业信贷支持力度。

一是推动提升小微金融服务能力，加大小微信贷支持。出台《中国人民银行 银保监会 发展改革委 工业和信息化部 财政部 市场监管总局 证监会 外汇局关于进一步强化中小微企业金融服务的指导意见》（银发〔2020〕120号），优化外部政策激励和地方融资环境，提升金融机构小微金融服务能力，大幅增加小微企业信用贷款、首贷和无还本续贷。

二是加大制造业中小企业的中长期融资支持。联合发展改革委等部门制定支持制造业中长期融资的意见，建立部门协调会商机制，加强政策协调配合，支持制造业企业中长期融资，做到贷款期限与企业生产周期相匹配。

三是加大重点群体创业就业资金支持。联合财政部等部门印发《财政部 人力资源社会保障部 中国人民银行关于进一步加大创业担保贷款贴息力度 全力支持重点群体创业就业的通知》（财金〔2020〕21号），对额度10万以下的个人创业担保贷款免除反担保，降低小微企业新招用人数占比要求，加大对小微企业创业的支持力度。截至2020年一季度末，有117万人获得创业担保贷款支持，比年初新增24万人；贷款余额1516亿元，同比增长33.9%。

（三）运用结构性货币政策，引导金融机构加大对民营和制造业企业的支持。

一是发挥好定向降准的引导作用，对服务县域农商行和仅在省域内经营的城商行实施定向降准，并扩大普惠金融定向降准政策支持范围。

二是积极运用好再贷款、再贴现等政策工具，发挥对民营企业定向调控、精准滴灌的积极作用，促进降低企业融资成本。

三是加强宏观审慎评估（MPA）的结构引导作用，在MPA中设置民营企业专项考核，引导金融机构加大民营和中小微企业贷款和信用贷款的投放。

（四）拓宽民营企业直接融资渠道。

采取建立债券发行“绿色通道”、延长债券发行额度有效期、合理调整信息披露时限等针对性措施，支持受疫情影响较重地区、行业以及疫情防控相关企业发债融资，2020年上半年共支持民营企业发行债券4056亿元，同比增长45%。积极支持商业银行特别是中小银行发行债券补充资本，提升信贷投放能力，2020年上半年共支持35家商业银行发行4414亿元资本债券。

总体看，各项措施取得了积极成效，民营和中小微企业实际融资成本显著降低。2020年2月和4月，1年期LPR和5年期以上LPR两次下降，分别累计降低30个基点和15个基点。6月新发放企业贷款利率为4.64%，较上年12月下降48个基点，降幅明显超过同期1年期LPR的降幅，充分体现了LPR的方向性和指导性。其中，中小微企业融资“量增、价降、面扩”。截至6月末，普惠小微贷款余额13.5万亿元，同比增长26.5%，增速比上年末高3.4个百分点，连续4个月创有统计以来的新高。6月新发放普惠小微贷款平均利率为5.3%，比2019年末下降0.5个百分点。

下一步，人民银行将继续深化LPR改革，疏通货币市场利率向贷款利率的传导渠道，有序推进存量贷款利率转换，推动降低贷款实际利率，指导金融机构落实好延期还本付息和信用贷款发放等政策措施，支持民营和中小微企业发展。

**二、**关于进一步深化行政司法改革，提高政府服务效率，优化民营企业和中小微企业营商环境

人民银行积极推进“放管服”改革、优化行政审批服务，采取多项措施积极提升政府服务效能，为中小微企业发展营造良好的营商环境。

（一）扎实推进“证照分离”改革，营造良好营商环境。

人民银行按照《国务院关于在自由贸易试验区开展“证照分离”改革全覆盖试点的通知》（国发〔2019〕25号，下称25号文）要求，制定《在自由贸易试验区开展“证照分离”改革全覆盖试点工作实施方案》（银发〔2019〕310号文印发，下称《实施方案》），有效降低企业制度性交易成本，优化营商环境，激发市场活力和社会创造力。

一是落实改革举措，优化审批服务。人民银行共有10项行政许可纳入“证照分离”改革全覆盖范围，均采取优化审批服务的改革方式，具体举措涵盖全程网上办理、缩短办理时限、压减申请材料、延长许可有效期等内容。目前，各项改革举措有序实施，进入全国银行间债券市场备案、黄金及其制品进出口审批等事项已全程实现网上申请、办理，国库集中支付代理银行资格认定和商业银行、信用社代理支库业务审批两项事项办理时限由20个工作日缩短为15个工作日，银行卡清算机构准入、支付业务许可证核发等事项取消了无犯罪证明、验资证明、经营金融业务许可证复印件等材料提交要求，国库集中支付代理银行资格认定有效期限由3年延长至5年。

二是坚持放管结合，加强事中事后监管。人民银行不断加强审批与监管的衔接，健全监管规则和标准，按照25号文和《实施方案》规定的事中事后监管措施，全面推行“双随机、一公开”监管，通过现场和非现场两种监管手段的有机融合，实现监管“全覆盖”“无死角”。2020年上半年，人民银行印发《关于2020年度执法检查工作的通知》（银办发〔2020〕50号文），统筹安排全系统年度执法检查项目，提高执法检查的协同性、有效性。

三是依法推进改革，稳步将改革举措推向全国。按照重大改革于法有据的要求，人民银行梳理了“证照分离”改革涉及的规章、规范性文件。经过评估后，启动了3件规范性文件的修改程序。同时，鉴于10项行政许可事项均具备在全国开展“证照分离”改革的条件，人民银行在修改规范性文件的同时，将一并在全国开展“证照分离”改革。

（二）修订行政许可实施办法，提升政务服务水平。

人民银行贯彻落实党的十九届四中全会精神和《中华人民共和国行政许可法》修改的新要求，修订《中国人民银行行政许可实施办法》（中国人民银行令〔2020〕第1号），细化完善了行政许可的受理、审批流程，对部分行政许可事项设置简易程序，将审批时限压缩至受理后5日内，提高审批效率，降低办事成本，减轻申请人负担。同时，根据新办法，对现有13项行政许可服务指南进行全面修订，将“放管服”改革和优化营商环境要求落到实处。
