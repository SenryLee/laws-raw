# 中国人民银行关于政协十三届全国委员会第三次会议第1698号（财税金融类203号）提案答复的函

莫天全委员：

您提出的关于加快建设我国信用评级机构，提高在国际信用评级市场话语权的提案收悉，现答复如下：

近年来，人民银行会同发展改革委、财政部、证监会等部门持续推动我国信用评级行业高质量发展，在加强行业顶层设计、补齐监管短板、扩大对内对外开放、规范行业发展等方面开展大量工作。

一是加强信用评级行业顶层设计，不断完善信用评级监管制度建设。2019年11月，人民银行、发展改革委、财政部、证监会联合出台并组织实施我国信用评级行业首个跨市场联合规章《信用评级业管理暂行办法》（中国人民银行令〔2019〕5号发布），明确行业规范发展的政策导向，建立信用评级统一监管框架，为加强信用评级监管奠定了制度基础。

二是落实党中央、国务院扩大金融业对外开放决策部署，推动我国信用评级业高水平对内对外开放。信用评级行业对外开放是稳步扩大金融市场对外开放的重要组成部分。人民银行遵循国际规则，积极推动征信业对外开放。2017年7月，人民银行发布公告，允许在华外资金融服务公司提供信用评级服务。2019年7月、2020年5月，国务院金融稳定发展委员会办公室发布有关金融业对外开放的公告，其中进一步明确信用评级对内对外开放相关措施。国际三大评级机构中的标普、惠誉先后于2019年1月、2020年5月获准进入银行间债券市场展业。

三是持续规范清理信用评级市场，促进国内评级机构通过资源整合做大做强。2018年9月，人民银行、证监会发布联合公告，推动跨市场评级监管统一和资质互认。2019年7月，中证鹏元资信评估有限公司、远东资信评估有限公司获准进入银行间债券市场展业。2020年2月，中诚信国际信用评级有限公司、中诚信证券评估有限公司成功合并，成为我国首个跨市场的评级机构整合案例。《信用评级业管理暂行办法》实施后，人民银行进一步规范清理评级市场，促进评级资源集聚。截至2020年8月末，已有近半数不符合条件的存量评级机构被注销备案。

四是联合加强评级监管，促进评级市场规范发展。人民银行联合有关部门加强对评级机构的现场与非现场监管。近年来，多家评级机构被出具业务提示函，受到窗口指导；个别评级机构被罚暂停业务，对市场形成有效震慑。2020年以来，人民银行会同证监会等部门进一步加强评级执法检查力度，目前正在重点整治评级虚高和评级市场乱象等问题。银行间市场交易商协会指导自律组织完善评级自律管理制度体系，加强自律管理和自律处分，推动评级市场利益方以市场化方式成立外部评级风控委员会，成为我国首个跨市场的评级行业自律机制。发展改革委按照《国务院关于加快推进社会信用体系建设 构建以信用为基础的新型监管机制的指导意见》（国办发〔2019〕35号）要求，对信用评级机构等市场主体探索性地开展了公益性的公共信用综合评价，作为政府内部应用信息推送至相关监管部门参考使用；依法依规推动行政处罚、严重失信名单等信用评级机构信用状况信息在“信用中国”网站进行公示，供市场主体参考使用。

五是督促国内评级机构提升执业质量和评级质量。人民银行等部门持续督促评级机构通过高质量的评级服务增强市场认可度，提升市场声誉和市场公信力，为提高国际国内话语权打好基础；鼓励国内评级机构加强评级技术、数据系统的研发积累，加快构建评级专业人才体系，强化合规内控，遵循独立客观公正的原则开展业务，以发挥信用评级在资产定价、风险揭示等方面的功能；将评级质量作为监管关注重点，加强对评级质量问题的执法检查力度。

六是推动国内评级机构加快国际化发展。人民银行会同有关部门积极支持国内评级机构拓展境外评级业务。截至2020年8月，国内评级机构已为110只熊猫债进行信用评级，另有3家国内评级机构在香港设立分支机构，对95家境外主体开展评级。同时，鼓励国内评级机构积极开展境外信用研究。目前，国内评级机构已建立覆盖全球大部分国家（地区）的主权评级体系，并发布包括“一带一路”沿线国家（地区）在内的100多个国家（地区）的主权评级结果和全球信用风险分析报告，有效降低了我国境外投融资风险。此外，支持国内评级机构加强国际交流与合作，已有部分评级机构加入亚洲信用评级协会（ACRAA）、亚洲证券业与金融市场协会（ASIFMA），并与德国、俄罗斯、巴基斯坦、哈萨克斯坦等国家的金融机构或评级机构开国际交流与合作。

下一步，人民银行将会同有关部门进一步推动我国信用评级业高水平对内对外开放，强化评级监管，支持有条件、有基础的评级机构快速、规范发展，不断提高我国信用评级的国际话语权。

感谢您对金融工作的关心和支持。欢迎访问人民银行门户网站（www.pbc.gov.cn），了解人民银行最新工作动态及金融领域的相关信息。

中国人民银行

2020年12月1日
