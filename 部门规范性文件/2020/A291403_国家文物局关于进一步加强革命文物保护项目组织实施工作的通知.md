# 国家文物局关于进一步加强革命文物保护项目组织实施工作的通知

文物革函〔2020〕384号

各省、自治区、直辖市文物局（文化和旅游厅/局），新疆生产建设兵团文物局：

为深入贯彻落实中办、国办《关于实施革命文物保护利用工程（2018－2022年）的意见》，加大革命文物维修保护工作力度，提升保护展示水平与质量，现就进一步加强革命文物保护项目组织实施的有关事项通知如下。

一、高度重视革命文物保护项目组织实施

省级文物行政部门要提高政治站位，切实担负起本行政区域牵头抓总的主体责任，坚持抢救性和预防性保护并重、保护修复和宣传展示统筹的原则，扎实推进革命旧址维修保护行动计划和馆藏革命文物保护修复计划，有序实施革命文物集中连片保护利用工程，指导地方人民政府和市县级文物行政部门做好项目策划和储备，加大协调保障力度，确保项目顺利实施。

二、优化革命文物保护项目审批流程

各地应按照“放管服”改革要求，进一步优化革命文物保护项目申报审批程序。其中全国重点文物保护单位和馆藏一级文物中的革命文物保护项目，由其保护管理机构和文物收藏单位编制保护项目计划书（见附件1），省级文物行政部门研究汇总后，编制本省（自治区、直辖市）革命文物保护项目年度计划方案申报表（见附件2），连同各项目计划书通过国家文物局综合行政管理平台（http：//gl.ncha.gov.cn）集中报审。报送时间原则上为每年6月1日-7月15日，各地可视情况于每年12月补报。申请项目应具备短期内启动实施的条件，申报材料应真实、准确。

经国家文物局批复同意列入年度计划方案的项目，除另有要求的外，其余均委托省级文物行政部门按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）要求对技术方案进行审批。技术方案获批同意后10个工作日内，须将修改完善的技术方案通过综合行政管理平台报国家文物局备案。

经国家文物局批复同意列入年度计划、三年内未报审技术方案的项目，须重新申报项目计划书。全国重点文物保护单位突发险情的，由省级文物行政部门在指导做好抢险支护的同时，组织制定抢险方案直接报国家文物局审批。安消防类革命文物保护项目按原有方式申报。

三、统筹推进革命文物保护利用片区建设

各革命文物保护利用片区所涉及的省级文物行政部门应创新体制机制，加强沟通协调，共同研究制定片区革命文物保护利用总体工作规划，明确发展目标、主要任务和重点项目，统筹实施革命文物集中连片保护利用工程，充分发挥片区示范引领作用。相关总体工作规划应征求国家文物局意见。

省级文物行政部门可根据各片区总体工作规划，结合重要时间节点和具体工作安排，选择其中价值重大的项目（包括省级文物保护单位），汇总列入年度计划方案表申报，经国家文物局批准同意后，可按程序申请年度国家文物保护专项资金。

四、强化革命文物保护项目管理

省级文物行政部门应加强指导监督，强化项目检查管理，做好项目竣工验收，确保项目进度和工程质量，并在每年3月1日前将上一年度革命文物保护项目技术方案审批、备案和实施情况报国家文物局，作为下一年度计划方案审批的参考依据。

请各地按照本通知要求认真做好工作部署，及时总结实践经验，工作中出现的新情况新问题请及时反馈国家文物局。国家文物局将进一步加强指导和督查，确保革命文物保护展示工作质量稳步提升。

特此通知。
