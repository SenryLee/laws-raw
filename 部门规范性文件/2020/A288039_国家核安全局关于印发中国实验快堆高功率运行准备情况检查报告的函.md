# 国家核安全局关于印发中国实验快堆高功率运行准备情况检查报告的函

## 关于印发中国实验快堆高功率运行准备情况检查报告的函

国核安函〔2020〕20号

中国原子能科学研究院：

根据《关于开展中国实验快堆高功率运行准备情况检查的通知》（核电函〔2020〕02号）的相关安排，我局组织检查组于2020年1月13日至14日对你院中国实验快堆高功率运行准备情况进行了检查。

现将检查报告印发给你院，你院应采取有效措施，落实检查报告中提出的各项要求，确保中国实验快堆运行安全。

国家核安全局

2020年3月6日

附件：中国实验快堆高功率运行准备情况检查报告
