# 文化和旅游部关于政协十三届全国委员会第三次会议第2349号（文化宣传类121号）提案答复的函

您提出的《关于后新冠肺炎疫情时期的文旅产业振兴的提案》收悉，经商发展改革委、工业和信息化部、交通运输部、商务部、市场监管总局，现答复如下：

新冠肺炎疫情对文化产业和旅游产业发展造成了巨大影响。文化和旅游部坚决贯彻党中央、国务院关于统筹推进疫情防控和经济社会发展的决策部署，加强与有关部门的协调配合，加大产业扶持力度，解决文化和旅游企业特别是中小微企业实际困难，推动文化产业和旅游产业恢复重振。

一、关于“统筹兼顾，致力于产业生态的整体复苏”

疫情发生以来，文化和旅游部会同有关部门研究制定了一系列帮助企业纾困、推动产业发展的扶持政策。在制定政策过程中，重点关注和解决中小微文化和旅游企业的发展困难和政策诉求。针对中小微企业融资难、压力大等问题，切实做好中小微文化和旅游企业的帮扶工作。一是资金支持方面。2020年3月，财政部、文化和旅游部印发通知，调剂部分2020年中央财政已提前下达的旅游发展基金支出用途，重点用于支持中小微旅游企业贷款贴息。二是货币政策方面。文化和旅游部印发通知，推动各地文化和旅游部门与人民银行分支机构对接，指导文化和旅游企业用好人民银行新增的再贷款、再贴现专用额度，使受疫情影响较大的旅游娱乐、住宿餐饮行业的小微企业得到重点支持。三是减税降费方面。文化和旅游部会同有关部门研究出台了减免中小微企业增值税、延长困难企业亏损结转年限、阶段性免征中小微企业社保费、缓缴住房公积金、减免房租等政策，广大中小微文化和旅游企业从中受益。四是金融扶持方面。文化和旅游部与中国工商银行签订战略合作协议，新增1000亿元专项授信用于支持文化和旅游企业应对疫情复工复产。有关部门出台了对中小微企业贷款实施临时性延期还本付息、引导金融机构发行小微企业专项金融债券等政策。2020年上半年，民营企业发债4056亿元，同比增长45%，净融资1638亿元。其中文化和旅游企业发债约900亿元，同比增长139%。五是稳定就业方面。2020年2月份，文化和旅游部印发通知，指导各地文化和旅游部门积极开展免费线上培训，协调减免导游会费，加强导游劳动权益保障，全力保持导游队伍稳定。此外，文化和旅游部还会同有关部门出台了实施部分职业资格“先上岗、再考证”、中小微企业吸纳就业补贴等政策。

下一步，文化和旅游部将会同有关部门，继续加强对中小微文化和旅游企业的关注和扶持，推动现有扶持政策落地实施，帮扶文化和旅游企业纾困解难，推动文化产业和旅游产业复苏。

二、关于“协同一致，实现对全产业链的协调支持”

疫情发生后，为统筹推进疫情防控和经济社会发展，国务院成立了联防联控工作机制、复工复产推进工作机制和宏观政策协调机制。相关工作机制对加强部门协调联动、统筹制定产业扶持政策、推动文化和旅游行业复苏发挥了重要作用。一是协同共享产业信息。文化和旅游部在国务院联防联控工作机制、国务院宏观政策协调机制安排下，与有关部门积极配合，加强文化和旅游领域疫情影响、复工复产信息共享。二是协同制定扶持政策。文化和旅游部加强与有关部门的沟通协调，共同研究出台一系列扶持政策，涉及文化和旅游场所开放、文化和旅游消费、中央预算内投资、旅游发展基金等产业发展相关环节。三是协同推进复工复产。文化和旅游部、交通运输部、商务部、卫生健康委单独或联合印发旅游景区、旅行社、剧院等演出场所、上网服务场所、娱乐场所、餐饮、住宿、国内游轮等疫情防控指南，指导相关企业有序复工复产。2020年7月，文化和旅游部印发通知恢复旅行社跨省团队游业务，交通运输部随后印发通知指导稳妥有序恢复省际旅游客运。

下一步，文化和旅游部将会同有关部门，在中央文化体制改革和发展工作机制、国务院联防联控工作机制、国务院宏观政策协调机制、国务院旅游业工作部际联席会议等工作机制安排下，加强协调联动，进一步研究制定有针对性的政策举措，推动文化产业和旅游产业高质量发展。

三、关于助力企业“自力更生、苦练内功、化危为机”

疫情发生以来，文化和旅游部会同有关部门通过多种形式及时向社会发布文化和旅游领域疫情防控、复工复产、市场动态等情况，树立行业信心，引导企业发展。对中央层面和各地出台的纾困惠企政策进行全面梳理，并在文化和旅游部网站设立“应对疫情支持企业发展政策措施”专栏，帮助各地文化和旅游部门与企业及时了解掌握政策，推动政策真正惠及企业。编发文化和旅游企业抗击疫情、推动发展的典型案例，稳定企业发展信心。搭建公益性培训平台，根据不同类型企业需求，陆续开设了“文旅产业云讲堂”“红色旅游云课堂”“旅游景区公益云课堂”“度假休闲大讲堂”等线上公益课程，累计学习超过100万人次，帮助企业苦练内功，提升企业运用政策水平和从业人员能力素质。

下一步，文化和旅游部将继续从信息发布、政策宣传解读、人才培训等方面，加强对文化和旅游企业的支持和服务，推动文化和旅游企业在常态化疫情防控下平稳有序运营和可持续发展。

感谢您对文化和旅游工作的关心与支持！

文化和旅游部
