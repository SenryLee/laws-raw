# 国家文物局办公室关于小双桥遗址建设控制地带内郑州连霍北C（2020）005号地块建设项目意见的函

办保函〔2020〕810号

河南省文物局：

你局《关于上报郑州连霍北C（2020）005号地块建设项目设计方案的请示》（豫文物〔2020〕130号）收悉。经研究，我局不同意在小双桥遗址建设控制地带内实施郑州连霍北C（2020）005号地块建设项目。

一、拟建项目紧邻小双桥遗址保护范围，请你局指导有关单位，在项目拟建区域内开展全面的考古发掘工作，明确该区域地下文物分布情况，及其与小双桥遗址的关系，并根据考古工作成果论证项目选址的必要性和可行性。

二、请你局加强指导，督促郑州市人民政府结合国土空间规划工作，抓紧编制小双桥遗址保护规划，明确管理规定和具体建设控制指标，协调处理文物保护利用与城市建设、民生改善的关系。相关建设项目方案，应在郑州市人民政府公布小双桥遗址管理规定和具体建设控制指标后，按程序另行报批。

专此函复。

国家文物局办公室

2020年9月10日
