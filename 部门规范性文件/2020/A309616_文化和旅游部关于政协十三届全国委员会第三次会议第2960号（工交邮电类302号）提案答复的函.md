# 文化和旅游部关于政协十三届全国委员会第三次会议第2960号（工交邮电类302号）提案答复的函

您提出的《关于后疫情时代推动我国邮轮产业高质量发展的提案》收悉，由我部会同税务总局、工业和信息化部、财政部办理，现答复如下：

一、关于加强邮轮产业顶层规划，将其提升为国家战略的建议

党中央、国务院高度重视邮轮产业发展。2013年，习近平总书记视察海南凤凰岛国际邮轮港时指出，“大力发展邮轮产业是一件利国利民的好事”“要大力发展邮轮产业，建造我们自己的邮轮”。2018年，《中共中央 国务院关于完善促进消费体制机制 进一步激发居民消费潜力的若干意见》指出，要积极培育重点领域消费市场，支持邮轮游艇等消费向大众化发展。2019年，国务院办公厅印发的《关于进一步激发文化和旅游消费潜力的意见》提出，支持邮轮游艇旅游等业态发展。2018年，我部会同交通运输部等部委印发的《关于促进我国邮轮经济发展的若干意见》提出，要推动我国邮轮产业链迈向全球价值链中高端，促进我国邮轮经济升级发展。

当前，我国已经成为旅游大国，正在向旅游强国迈进，邮轮旅游作为休闲度假旅游业态，已成为旅游业重要的组成部分，在满足人民群众对美好生活的需要上起到了积极作用。邮轮旅游也逐渐成为壮大海洋旅游经济、拓展蓝色发展空间、促进消费升级的重要抓手，对于服务“一带一路”倡议、建设海洋强国具有重要意义。

下一步，我部将积极协调有关部门，加强邮轮产业顶层规划设计，支持将邮轮产业逐步上升到国家战略高度，充分调动各地积极性，进一步统筹相关政策、资金、人才等资源，大力发展邮轮产业。

二、关于鼓励中资邮轮公司成为重振邮轮产业龙头的建议

我国是全球最大的邮轮新兴市场和全球第二大邮轮客源国，随着我国新冠肺炎疫情得到有效控制，在疫情防控常态化下，各行各业复工复产复业有序推进，我国邮轮产业恢复以及可持续发展问题提上重要议程。全球邮轮业界普遍认为，中国邮轮产业长期向好的发展趋势不会改变，特别是我国天津港对“歌诗达赛琳娜号”邮轮的成功处置，增强了我国邮轮产业发展的底气和信心，也在全球范围树立了模范标杆，为邮轮新冠肺炎疫情应急处置提供了中国方案。

2020年3月，交通运输部印发了《船舶船员新冠肺炎疫情操作指南》，明确了航运公司应当建立船舶防控新冠肺炎疫情管理计划，包括船上隔离计划，指导船舶成立疫情防控工作组，由船长担任组长、船上部门负责人担任组员，完善各项疫情防控工作制度，监督船上所有人员落实各项防控措施。《船舶船员新冠肺炎疫情操作指南》被国际海事组织（IMO）采用，向所有成员国、政府间和非政府国际组织推介。

下一步，我部将积极配合相关部门，推动中资邮轮公司开展邮轮公共卫生安全体系建设，并与挂靠港口城市的应急防疫体系相匹配，鼓励并支持中资邮轮公司按照现有政策，设计出更多更好的邮轮旅游产品，在可防可控的前提下，开展邮轮旅游产品的推广活动，推动中资邮轮尽早实现复航。

三、将邮轮列入重大科技装备攻关工程项目的建议

“十三五”期间，围绕解决邮轮产业“卡脖子”问题，工业和信息化部积极推进邮轮关键技术研发。2017年1月，工业和信息化部等6部门印发《船舶工业深化结构调整加快转型升级行动计划（2016—2020年）》（工信部联装〔2016〕447号），提出要“组织实施大型邮轮、智能船舶等一批重大创新工程和专项”“要适应国内邮轮游艇等传统高端消费潜力加速释放的趋势，加快实现邮轮自主设计和建造，大力发展中小型游艇和新型游艇设计制造。”

近年来，工业和信息化部先后组织实施了大型邮轮研发专项、13万总吨级大型邮轮工程等科研工程项目，并开展了中型邮轮设计建造、极地小型邮轮设计建造、邮轮重量控制、邮轮动力系统及辅助系统集成设计、邮轮舱室环境控制系统、邮轮美学设计等关键技术研发项目，其中部分科研成果已经得到实际应用。

下一步，我部将配合相关部门，围绕推动邮轮产业高质量发展，不断推进邮轮产业核心技术研发，逐步解决邮轮产业“卡脖子”问题。指导国内邮轮研发设计单位加强与医疗卫生界的交流合作，加大对邮轮疫情防控的研究力度，为后疫情时代我国邮轮产业可持续发展提供保障。

四、关于优化中资邮轮产业营商环境，构建新生态体系的建议

2018年，我部会同交通运输部等部委印发《关于促进我国邮轮经济发展的若干意见》，明确支持中资方便旗邮轮及五星红旗船队发展。2019年，交通运输部印发《关于推进海南三亚等邮轮港口海上游航线试点的意见》，提出基于海南海域情况及海南国际邮轮发展状况，在五星红旗邮轮投入运营前，先期在海南三亚、海口邮轮港开展中资方便旗邮轮无目的地航线试点。2014年，财税部门发文，明确铁路、船舶等运输设备制造新购的固定资产可缩短折旧年限或采取加速折旧的办法。2018年，财税部门出台政策，明确单位价值500万元以下的设备、器具可一次性在税前扣除。2020年，财税部门出台政策，将交通运输业、旅游业等受疫情影响较大的困难行业企业2020年发生的亏损，最长结转年限由5年延长至8年。以上这些措施，有效缓解了中资邮轮的资金压力，帮助中资邮轮实现可持续发展。

交通运输部门持续推进“放管服”改革，不断优化邮轮多点挂靠许可的服务和流程，提高许可效率。按照《老旧运输船舶管理规定》，邮轮属客船，超过30年船龄的船舶应强制报废。这项制度是为了强制淘汰落后老旧运输船舶，优化我国船舶船龄结构，提升运输安全保障能力和服务质量，增强我国邮轮市场竞争力，促进我国造船工业发展。

下一步，我部将积极配合相关部门，不断改善中资邮轮发展营商环境，通过产业政策调整，解决制约中资邮轮发展瓶颈问题，继续推动中资邮轮和五星红旗邮轮加速进入我国邮轮旅游市场，为人民群众提供更多更好的邮轮旅游产品。

五、关于加大对邮轮产业融资和税收支持的建议

近年来，工业和信息化部联合财政部、人民银行、银保监会等部门开展了产融合作工作，不断加强对邮轮产业的金融扶持和支持力度，提升金融服务邮轮产业发展的能力和效率。通过释放相关金融政策，有导向性、针对性地引导更多的企业、资本参与到邮轮产业发展上。目前，在第二批产融合作试点城市方案中，已将船舶工业作为试点城市重点发展的产业，这将吸引更加多元化的资本进入邮轮产业，推动邮轮产业发展。

近年来，国家出台了一系列减税降费的政策，包括将增值税的17%和11%两档税率降至13%和9%，进一步扩大增值税进项抵扣范围，试行期末留抵退税制度，对高新技术企业给予15%的企业所得税低税率优惠，对制造业领域企业实行固定资产加速折旧优惠等政策，这些政策涵盖了邮轮产业的研发设计、总装建造、运营服务等多个领域，对降低邮轮相关企业税务成本，支持邮轮相关产业发展具有积极意义。

下一步，我部将继续配合相关部门，充分考虑促进邮轮产业发展的实际需要，统筹落实好相关税收金融政策，支持社会资本投入邮轮产业，为促进邮轮产业高质量发展提供动能。

感谢您对文化和旅游工作的关心与支持。

文化和旅游部
