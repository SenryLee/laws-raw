# 中华人民共和国审计署公告2020年第3号——审计署移送违纪违法问题线索查处情况

## 中华人民共和国审计署公告

2020年第3号

## 审计署移送违纪违法问题线索查处情况

审计署持续跟踪了解移送有关部门的违纪违法问题线索查处情况，近期了解到的査处情况如下，

**一、**原中国船舶重工集团有限公司总经理XXX涉嫌利用职务之便为他人谋取利益问题

审计发现，2006年至2015年，XXX涉嫌利用职务之便，为他人与大连船舶重工集团有限公司合作成立公司及公司后续经营等事项提供帮助。2016年12月，审计署将此问题线索移送中央纪委调查。2018年12月，XXX被开除党籍、开除公职。2019年7月，XXX以受贿罪、国有公司人员滥用职权罪被判处有期徒刑12年，并处罚金80万元，追缴全部违法所得。

**二、**中信银行原党委副书记、行长孙德顺涉嫌接受利益输送问题

审计发现，2010年至2016年，孙德顺在交通银行和中信银行任职期间，涉嫌利用职务之便以权谋私，并接受利益输送。2019年3月，审计署将此问题线索移送中央纪委国家监委调查。2020年3月，孙德顺被开除党籍，按规定取消相关待遇，收缴违纪违法所得，并移送检察机关审查起诉。

**三、**中煤科技集团有限公司原总经理陈伟涉嫌违规协助外部企业办理保理业务问题

审计发现，2009年至2013年，经陈伟批准同意，中煤科技集团有限公司为一家外部企业出具实际不存在的应收账款确认函，帮助其办理银行保理业务。2017年4月,审计署将此问题线索移送国资委调查。2019年12月，陈伟以单位受贿罪、受贿罪被判处有期徒刑11年，并处罚金200万元，追缴违法所得1400万元。

**四、**上海联东地中海国际船舶代理有限公司原总经理邹斌涉嫌受贿问题

审计发现，2009年至2015年，邹斌在担任公司筹备组成员和总经理期间，涉嫌利用职务便利，谋取巨额不当利益。2018年11月，审计署将此问题线索移送上海市公安局调查。2020年4月，邹斌以受贿暴被判处有期徒刑12年，并处罚金200万元，追缴赃款予以没收。

**五、**中国银行湖南省分行原国际业务部总经理周云伯涉嫌受贿问题

审计发现，2012年至2014年，周云伯涉嫌利用职务之便，为离职员工黄勇套取贷款提供便利并收受贿赂。2016年10月，审计署将此问题线索移送湖南省检察院调查。2019年12月，周云伯以违规出具金融票证罪、受贿罪被判处有期徒刑6年，芳处罚金20万元，没收违法所得。2019年9月，黄勇以骗取金融票证罪、行贿罪被判处有期徒刑5年，并处罚金300万元。

**六、**徽商银行公司银行部原总经理吴耘涉嫌违规入股金融公司问题

审计发现，2016年，吴耘涉嫌违规入股上海融葵投资管理有限公司，利用职权帮助该公司获得徽商银行业务并从中谋取非法利益。2019年7月，审计署将此问题线索移送安徽省纪委监委调查。2019年11月，吴耘被开除党籍，取消退休待遇，追缴吴耘及其他涉案人员非法所得8445万元，并移送检察机关审查起诉。

**七、**山西省平遥县财政局原统评股股长常斗录等人涉嫌玩忽职守问题

审计发现，2014年，常斗录等12人涉嫌在专项资金申报审核过程中把关不严，致使中央财政关闭小企业补助资金276.17万元被骗取。2017年10月，审计署将此问题线索移送山西省晋中市纪委调查。至2019年9月，常斗录等3人被开除党籍、开除公职，6人受到党内警吿、党内严重警告等处分，3人受到政务警告处分。

**八、**重庆市酉阳县住房城乡建设委员会房管科原科长彭华涉嫌违规挪用住宅专项维修资金问题

审计发现，2015年至2019年，彭华涉嫌利用职务便利，截留住宅专项维修资金2684万元，并将部分资金用于个人购房、购车O2019年10月，审计署将此问题线索移送重庆市纪委调查。2020年1月，彭华被开除党籍、开除公职，并移送司法机关。

**九、**山西省吕梁市石楼县龙交乡阳崖村原党支部书记贺淑林涉嫌骗取财政资金问题

审计发现，2015年，贺淑林涉嫌利用虚假申报材料，骗取财政资金。2018年7月，审计署将此问题线索移送吕梁市监察委调查。至2019年8月，贺淑林受到开除党籍处分，被判处有期徒刑1年4个月，缓刑2年，并处罚金5000元。

**十、**黑龙江省桦南县和湖南省新晃县4名公职人员涉嫌在工程建设中违规问题

审计发现，2016年至2017年，两县4名公职工作人员在危房改造建设和易地扶贫搬迁安置工程中涉嫌违规。2018年和2019年，审计署将问题线索分别移送两省纪检监察机关调查。至2019年底，4名公职人员受到留党察看2年、党内严重警告以及免职和政务降级等处理处分，并处以罚金。

**十一、**黑龙江省兰西县、望奎县、海伦市部分村镇工作人员涉嫌骗取财政补贴问题

审计发现，2013年至2016年，上述3县16名村镇工作人员涉嫌骗取财政资金等。2018年至2019年，审计署将此问题线索移送黑龙江省纪委调查。至2019年12月，16人受到党内警吿、党内严重警告、开除党籍等处分，其中2人被判处2年或5年有期徒刑。

**十二、**云南省香格里拉市水务局原副局长马卫民等人未认真履职导致财政资金被骗取套取问题

审计发现，2015年至2018年，马卫民等人在高效节水灌溉、通村公路等项目实施过程中未认真履行职责，导致施工企业虚报工程量骗取财政资金。2019年4月，审计署将此冋题线索移送云南省纪委监委调查。2019年10月至12月，马旦民受到开除党籍、开除公职处分，以受贿罪被判处有期徒刑1年，缓刑2年，并处罚金12万元；其他23名相关责任人分别受到党内严重警告、政务撤职、诫勉谈话等处理处分；相关施工企业负责人以诈骗罪被判处有期徒刑10年，并处罚金10万元。

**十三、**鸡西市工业和信息化委员会原工作人员于某涉嫌骗取职工养老金问题

审计发现，2014年至2018年，于某涉嫌通过编造虚假资料骗取养老金。2018年11月，审计署将此问题线索移送黑龙江省公安厅调查。2019年9月，于某以诈骗罪被判处有期徒刑6个月，并处罚金4万元，追缴资金7.32万元。

**十四、**黑龙江省医院康复科护士王某涉嫌骗取医保基金问题

审计发现，2012年至2016年，王某以其胞姐名义多次虚假住院，涉嫌骗取医保基金。2017年2月，审计署将此问题线索移送黑龙江省公安厅调查。2019年9月，王某以诈骗罪被判处有期徒刑3年，缓刑4年，并处罚金3万元，追缴资金22.35万元。
