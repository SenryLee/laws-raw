# 文化和旅游部对十三届全国人大三次会议第1728号建议的答复

您提出的《关于进一步加大力度，推动旅游公共服务体系建设》的建议收悉，经商住房和城乡建设部、交通运输部、自然资源部，现答复如下：

文化和旅游部长期以来高度重视旅游公共服务工作，以旅游厕所革命、游客服务中心、旅游交通等工作为抓手，不断提升旅游公共服务水平。

一是狠抓旅游厕所革命，努力补齐旅游公共服务短板。2015年以来，文化和旅游部深入贯彻落实习近平总书记重要批示精神，先后制定实施《全国旅游厕所建设与管理三年行动计划（2015—2017）》《全国旅游厕所建设与管理新三年行动计划（2018—2020）》。截至2020年8月，全国共建设旅游厕所12.7万座，其中已有12万座旅游厕所在手机电子地图上进行了位置标注。旅游厕所取得了量的突破和质的提升，从满足基本功能到景观化、人性化、特色化、生态化、智能化发展，厕所“脏乱差”现象在许多地方得到明显改变，广大群众和游客对厕所的满意度显著提升。

二是加强顶层设计，探索建立旅游公共服务体系。制定出台《城市旅游服务中心规范》行业标准，明确城市旅游服务中心综合站、二级站、服务点三级设施网络的基本功能、服务内容、服务规范等。2019年，根据文化和旅游融合发展的新要求，文化和旅游部启动了旅游服务中心和公共文化机构融合发展试点工作。制定出台《“十三五”全国旅游公共服务规划》，配合交通运输部等部门出台《关于促进交通运输与旅游融合发展的若干意见》（交规划发〔2017〕24号），对交通与旅游融合发展工作进行了总体部署，提出了建立健全交通运输与旅游融合发展的运行机制，基本形成“快进”“慢游”旅游交通基础设施网络，旅游交通产品供给能力明显增强的总体目标，为各地推进交通与文化和旅游融合发展指明了方向。

下一步，结合您提出的具体建议，我部将会同住房和城乡建设部、交通运输部、自然资源部等部门，进一步加大改革创新力度，不断完善旅游公共服务体系。

一是以疫后建设为抓手，推进旅游厕所革命再上新台阶。新冠肺炎疫情的爆发，对推进旅游厕所革命提出了更高的要求。旅游厕所是公共卫生防疫的重要阵地，下一步我们将引导各地在旅游厕所设施建设、管理服务等各方面采用更高的标准和更严的要求。继续推进基础设施建设，加强移动厕所配备，保证充足的厕位数量和更大的单厕位面积，避免如厕排队和人员拥挤现象；加强节水、节能，无水冲、泡沫冲，生物降解等新技术运用，提高粪污收集和处理水平，坚决避免发生粪口传播；加强体温检测设备、通风设备、空气除菌消毒设备、除菌洗手液等设施设备配置，加强保洁人员配备和每日清洁、消毒频次，确保旅游厕所随时处于干净、卫生状态。

二是切实加强旅游服务中心体系建设。修订完善旅游服务中心建设管理标准，推动主要旅游目的地旅游服务中心向集文化和旅游服务于一体的公共服务设施转型升级。在旅游资源较集中的地区，依托乡镇文化站、村文化室，增设旅游信息咨询、休憩娱乐、停靠换乘、农特产品展示等服务，建设一批有历史记忆、特色鲜明的乡村文化旅游服务中心。推动公共图书馆、文化馆等公共文化服务机构，根据实际条件和需要，融入旅游信息咨询服务功能。推广现代新媒体、新技术和新手段，结合公共文化云等公共数字文化工程项目，完善线上特别是移动终端旅游信息咨询服务功能，提高旅游信息服务设施效能。探索建成一批集国家政策宣传、旅游咨询、文娱体验等功能于一体的全国旅游服务中心示范项目。

三是探索推进交通与文化和旅游融合发展。配合交通运输部门，鼓励依托城市综合客运枢纽、道路客运站点、高铁站建设布局合理、功能完善的游客集散中心。鼓励有条件的地区在公共图书馆、文化馆增设旅游大巴临时停靠点。推进干线公路与重要景区、乡村旅游区连接，强化旅游客运、城市公交对旅游景区、景点、乡村旅游区的服务保障。推进城市绿道、骑行专线、登山步道、慢行系统、交通驿站等旅游休闲设施建设。积极推进国家风景道旅游公共服务示范工程建设，重点谋划推动川藏公路风景道、海南环岛风景道、长江三峡风景道等25条国家旅游风景道旅游公共服务设施建设与管理。

四是不断优化和完善旅游景区道路交通标识标牌体系。加强《旅游景区公共信息导向系统设置原则与要求》国家标准的宣传培训和贯彻执行，推动各地完善交通沿线及关键节点的旅游交通导览引导系统，将观景台、旅游标识标牌等设施与交通基础设施统一规划和设计，重点推进3A级及以上景区、省级及以上旅游度假区、重点乡村旅游点等主要旅游资源在高速公路、国道、省道等主要公路沿线的交通引导标识体系建设，有机融入当地人文特色，提升文化内涵，确保旅游交通标识设置规范、清晰明确、快速识别。

五是建立健全旅游志愿服务体系。培育旅游文明引导、游览讲解、质量监督、旅游咨询、应急救援等志愿者队伍。依托景区景点、旅游公共服务设施、公共文化服务机构、社区等建立旅游志愿者服务工作点。完善中国旅游志愿者管理信息服务平台，制定中国旅游志愿者服务管理办法，建立健全旅游志愿者招募、注册、培训、管理、考核、评价、激励、保障等制度体系。

感谢您对文化和旅游工作的关心与支持！

文化和旅游部

2020年9月24日
