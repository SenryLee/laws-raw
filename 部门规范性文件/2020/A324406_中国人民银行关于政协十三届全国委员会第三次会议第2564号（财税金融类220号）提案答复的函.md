# 中国人民银行关于政协十三届全国委员会第三次会议第2564号（财税金融类220号）提案答复的函

宋鑫委员：

您提出的关于商业银行信贷支持长江大保护的提案收悉，现将涉及人民银行职责范围的意见函告如下：

2020年以来，人民银行坚持以习近平新时代中国特色社会主义思想为指导，坚决贯彻党中央、国务院决策部署，坚持实施稳健的货币政策，根据疫情防控和复工复产的阶段性特点，灵活把握调控的力度、节奏和重点，加大金融支持实体经济力度，为做好“六稳”“六保”工作营造适宜的货币金融环境，为支持长江大保护提供重要的融资支持。

总量上，人民银行通过降准、再贷款再贴现、创新直达实体经济的货币政策工具、推动公司信用类债券净融资同比多增等措施，已推出9万亿元货币金融政策支持措施，保持总量充足。价格上，持续释放贷款市场报价利率（LPR）改革降低贷款利率潜力，引导1年期LPR下行30个基点，推动贷款利率明显下降。下调支农再贷款、支小再贷款、再贴现利率，推动金融让利支持实体企业渡过难关。结构上，运用再贷款、再贴现等结构性货币政策工具，从支持重点企业抗疫保供，到支持中小企业复工复产，再到提升对中小微企业的普惠性金融支持，因时因势、精准有效支持了实体经济。

前期出台的各项政策措施对支持实体经济取得了显著效果。一是货币信贷逆势大幅增长。2020年前7个月，银行业金融机构新增贷款13.1万亿元，同比多增2.4万亿元。二是社会综合融资成本明显下降。8月，企业贷款平均利率为4.62%，创统计以来新低，同比下降0.68个百分点，降幅明显超过同期1年期LPR的降幅。三是中小微企业融资“量增、价降、面扩”。截至2020年7月末，普惠小微贷款余额同比增长27.5%，增速明显快于整体贷款增速；6月新发放普惠小微贷款平均利率为5.08%，比上年12月下降0.8个百分点；7月末普惠小微贷款支持小微经营主体3007万户，同比增长21.7%。

关于降低长江大保护贷款利率水平的问题。

近年来，我国加快推进利率市场化改革并取得重要进展，目前我国的利率管制已经放开，金融机构根据客户的信用记录、担保品质量、综合贡献等因素，自主确定贷款利率水平。若限制金融机构贷款利率，不利于其按照市场化、商业可持续原则自主定价，可能影响对长江大保护项目提供信贷的积极性，反而不利于缓解其融资难融资贵问题。

感谢您对金融工作的关心和支持。欢迎登录人民银行门户网站（www.pbc.gov.cn），了解人民银行最新工作动态及金融领域的相关信息。
