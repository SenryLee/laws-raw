# 中国人民银行关于政协十三届全国委员会第三次会议第3993号（财税金融类303号）提案答复的函

孙昌隆委员：

您提出的关于维护社会稳定、规范金融市场秩序的提案收悉，现将涉及人民银行职责范围的内容答复如下：

随着金融科技的不断发展，我国金融行业出现了许多新业态和新模式，各类金融产品创新层出不穷。同时，相关风险也不断累积并逐渐暴露，对金融监管工作提出了新要求。您提出的规范金融市场秩序的相关建议,对于保障最广大人民群众的切身利益，维护金融业总体平稳健康发展具有重要的借鉴意义。

**一、**关于加强政府金融监督管理职责，防范金融风险问题

（一）关于明确中央和地方监管职责划分的建议。目前，中央和地方的监管职责划分已有明确规定。2013年11月出台的《中共中央关于全面深化改革若干重大问题的决定》明确提出，界定中央和地方金融监管职责和风险处置责任。2017年召开的第五次全国金融工作会议明确，在坚持金融管理是中央事权的前提下，完善中央和地方金融监管职责分工，赋予地方政府相关金融监管职责。小额贷款公司、融资担保公司、区域性股权市场、典当行、融资租赁公司、商业保理公司、地方资产管理公司等，由中央金融监管部门制定规则，地方金融监管部门实施监管。强化地方金融监管部门对辖区内投资公司、开展信用互助的农民专业合作社、社会众筹机构、地方各类交易场所等的监管，提高准入门槛，严格限定经营范围。地方金融监管的原则是中央统一规则、地方实施具体监管，中央对地方金融监管纠偏问责。

（二）关于中央层面不断完善金融监管法律法规的建议。人民银行高度重视相关金融监管立法问题，积极推进金融领域相关基础性法律制度建设。一是持续推进金融法律修改制定工作。目前，中国人民银行法修改、商业银行法修改、反洗钱法修改、保险法修改已列入全国人大常委会2020年度立法工作计划。二是继续推动相关金融法规制定工作。《非存款类放贷组织条例》已列入国务院2020年立法工作计划，《防范和处置非法集资条例》已报送国务院审批，《地方金融监督管理条例》、《非银行支付机构条例》等正在加快起草制定。三是持续推进相关监管制度建设。人民银行会同有关部门按照国务院办公厅印发的《互联网金融风险专项整治工作实施方案》（国办发〔2016〕21号文）要求，不断完善互联网金融各领域监管政策体系，P2P网络借贷行业已建立“一个办法、三个指引”监管框架，互联网资产管理行业和互联网保险行业明确了持牌经营要求。此外，非银行支付行业已建立备付金集中存管制度，虚拟货币交易、代币发行融资和互联网外汇交易等活动已经明令禁止。

下一步，人民银行将会同有关部门做好金融风险防范和处置及相关法律法规的立、改、废，基本明确地方金融监管的法律依据和授权，为深化金融供给侧结构性改革，打好防范化解金融风险攻坚战提供法律保障。

**二、**关于加强综合监管执法力度，强化部门之间监管协调和信息共享问题

在中央金融监管部门加强立法的同时，部分省（区、市）政府聚焦属地金融监管与属地金融风险处置等问题，出台了地方金融监管条例或意见，有效弥补地方金融监管短板和空白；充分发挥各省（区、市）金融委办公室地方协调机制的作用，推动地方金融监管部门细化监管要求，在市场准入、经营范围、内部运营、风控体系等方面加强监管，引导地方金融组织合规经营。

特别是2016年以来，按照党中央、国务院决策部署，人民银行会同相关部门指导各级地方政府坚定持续开展互联网金融风险专项整治，建立了中央和地方“双牵头”工作机制，即人民银行抓总、相关领域监管部门分别牵头、其他相关部门积极支持，各地方人民政府在中央各部门指导下落实属地整治和风险处置责任。工作中，中央各部门密切协调配合，加强信息共享，各地切实落实属地责任，推动互联网金融风险整治取得实效。在各方共同努力下，条块结合、紧密配合的监管协作机制已初步建立。

下一步，人民银行将继续与各部门加强监管协作和信息共享，会同有关部门制定地方金融监管相关规则，不断完善地方金融监管法律法规体系。

感谢您对金融工作的关心和支持。欢迎登录人民银行门户网站（www.pbc.gov.cn），了解人民银行最新工作动态及金融领域的相关信息。
