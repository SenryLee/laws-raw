# 农业农村部办公厅关于公布农业农村部兽药GMP检查员名单的通知

农办牧〔2020〕52号

各省、自治区、直辖市农业农村（农牧、畜牧兽医）厅（局、委），新疆生产建设兵团农业农村局，中国农业科学院、全国畜牧总站、中国动物疫病预防控制中心、中国兽医药品监察所、中国动物卫生与流行病学中心：

根据《兽药管理条例》《兽药GMP检查员管理办法》规定，经推荐、进选和考核，375名检查员符合要求，聘任为新一届农业农村部兽药GMP检查员，承担兽药GMP检查验收和飞行检查等具体工作，其中王海良等161名检查员为检查组组长。《农业部办公厅关于公布农业部兽药GMP检查员名单的通知》（农办医〔2014〕 62号）自本通知发布之日起废止。
