# 生态环境部办公厅关于解除中铝山西新材料有限公司和山西阳煤丰喜肥业（集团）有限责任公司临猗分公司挂牌督办的通知

## 关于解除中铝山西新材料有限公司和山西阳煤丰喜肥业（集团）有限责任公司临猗分公司挂牌督办的通知

环办执法函〔2020〕106号

山西省生态环境厅：

2019年5月9日、6月20日，我部分别印发《关于对5家重点排污单位主要污染物排放严重超标问题挂牌督办的通知》（环办执法函〔2019〕475号）和《关于对6家重点排污单位主要污染物排放严重超标问题挂牌督办的通知》（环办执法函〔2019〕566号），对中国铝业股份有限公司山西分公司（现更名为：中铝山西新材料有限公司）、山西阳煤丰喜肥业（集团）有限责任公司临猗分公司进行挂牌督办。按照督办要求，你厅督促相关地方和排污单位积极整改，并向我部提交了解除挂牌督办的申请。

根据排污单位整改情况和污染物排放自动监测数据，中铝山西新材料有限公司、山西阳煤丰喜肥业（集团）有限责任公司临猗分公司基本达到督办要求，同意解除挂牌督办。请你厅继续加强监督管理，督促排污单位严格履行生态环境保护主体责任，确保污染物稳定达标排放。

生态环境部办公厅

2020年3月12日
