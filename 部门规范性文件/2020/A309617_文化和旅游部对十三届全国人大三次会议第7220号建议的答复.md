# 文化和旅游部对十三届全国人大三次会议第7220号建议的答复

您提出的《关于加快高质量建设一批城市文化旅游目的地的建议》收悉。该建议由我部主办，发展改革委、住房城乡建设部、交通运输部、林草局、铁路局、民航局协办，现答复如下：

建设城市文化和旅游目的地，发展全域旅游，对打造文化高地和世界级旅游目的地，推动文化和旅游融合及高质量发展，具有十分重要的意义。

我部一直以来高度重视城市文化和旅游目的地建设，在城市品牌建设方面，秉持“宜融则融、能融尽融”的原则，鼓励各级文化和旅游部门采取多种方式充分发掘和保护其所在城市特有的人文和旅游资源，通过丰富文化领域提升城市品牌内涵、打造城市品牌多样性；通过促进旅游行业发展提升城市品牌的国际知名度和美誉度。不断打造完善“美丽中国”品牌，积极支持各地举办各类国际性文化和旅游活动，组织国内相关部门参与国际性旅游展会；努力办好中国国际旅游交易会，同时支持我驻外使领馆、海外文化中心和旅游办事处举办多种多样的文化和旅游宣传推介活动，为国内推广城市品牌打造更多国际平台。在筹划上述活动中，有意识地引导各参与单位整合资源、突出特色，将我国城市品牌作为入境旅游推广的亮点。下一步，我部将在做好现有工作基础上，进一步加强调研、培训、创新宣传手段等工作，提升各地打造城市品牌、进行国际推介的能力，同时积极开拓海外全媒体宣介渠道，为我城市品牌推广创造更广阔的平台。

一、关于顶层规划设计

《“十三五”时期文化旅游提升工程》中明确提出支持中西部重点旅游目的地的旅游公共信息服务、公共交通服务、安全保障服务等公共服务设施建设，以及重点景区的道路等基础设施建设，推动旅游咨询中心、区域性旅游应急救援基地、游客集散中心、旅游交通引导标识系统以及旅游数据中心等建设。“十三五”时期，通过实施文化旅游提升工程，共安排中央预算内投资284亿元，支持了2249个公共文化服务设施、国家文化和自然遗产保护利用设施、旅游基础设施和公共服务设施，支持各地因地制宜地完善旅游基础设施建设，推动健全重点旅游目的地的旅游基础设施和公共服务体系。

二、关于构建复合型、特色化的城市文化和旅游产品体系

《国务院办公厅关于进一步激发文化和旅游消费潜力的意见》（国办发〔2019〕41号）提出“鼓励打造中小型、主题性、特色类的文化旅游演艺产品”“到2022年，培育30个以上旅游演艺精品项目，扩大文化和旅游有效供给”。2019年3月，文化和旅游部办公厅印发《关于促进旅游演艺发展的指导意见》，提出“鼓励发展中小型、主题性、特色类、定制类旅游演艺项目，形成多层次、多元化供给体系”。目前，我部委托有关机构开展了旅游演艺精品名录、旅游演艺品牌排行榜等相关工作。

三、关于聚焦主客共享，提升城市旅游交通服务品质

近年来，民航局注重发展各类市场主体、修建机场、完善国内国际航线和民航服务质量管理体系，优化服务流程，为文化和旅游业发展做好航空网络支撑。截至2019年底，我国共有运输航空公司62家，颁证运输机场238个，已开通定期航班航线5521条，其中国内航线4568条（含港澳台航线111条）、国际航线953条，通航65个国家的167个城市。目前，绝大多数国内航线均已按照登记航线管理，许可手续已大幅简化；一半以上的国际航线均不限指定承运人数量和运力额度，航空公司可随时根据市场需求和地方发展需要，安排旅游客源地与目的地间航线航班。下一步，民航局将继续引导各航空公司完善和优化航线网络，全方位提升旅客航空出行体验。

四、关于改善城市环境，塑造、建设、传播城市品牌

住房城乡建设部推动城市信息模型（CIM）基础平台建设。2018年设立了广州、厦门、北京城市副中心、南京、雄安新区5个试点城市（地区），要求建设基于“多规合一”管理平台的BIM审查审批系统，并在此基础上探索构建城市信息模型（CIM）平台，为智慧城市建设奠定基础。2020年7月印发《关于开展城市信息模型（CIM）基础平台建设的指导意见》。推进生态修复城市修补工作，指导各地系统治理“城市病”，截至2019年，58个试点城市累计开展生态修复城市修补项目9789项，投资1.5万亿元，试点城市面貌实现了从“乱”到“治”的重大转变，受到城市居民的广泛好评。通过深入贯彻落实习近平生态文明思想，积极引导各地以国家园林城市系列建设为抓手，统筹推进城市基础设施建设，加强城市园林绿化建设力度，积极拓展城市绿色公共空间，提升城市绿地功能品质，城市人居和生态环境得到有效改善。截至2019年底，全国已命名19个国家生态园林城市、384个园林城市，363个园林县城、79个园林城镇。全国城市建成区绿地率、绿化覆盖率、人均公园绿地面积分别达到37.89%、41.83%和14.46平方米。

林草局2004年提出建设国家森林城市。目前，全国有194个城市被授予国家森林城市称号，有22个省（区、市）开展了省级森林城市系列创建活动，有17个省（区、市）开展了国家级和省级森林城市建设，建成了一大批森林城市、森林县城、森林小镇和森林村庄示范区，取得了可喜的成效。

五、下一步工作计划

我部在研究制定“十四五”旅游专项规划、实施文化旅游提升工程等工作中，将统筹考虑推动一批高质量文化和旅游目的地发展，并重点支持符合条件的世界级旅游目的地、全域旅游综合目的地的相关旅游基础设施和公共服务设施建设，助推相关城市文化和旅游高质量发展。同时，贯彻落实《国务院办公厅关于促进全域旅游发展的指导意见》部署安排和有关要求，以创建示范区为抓手，以促进示范区产业发展为核心，以强化示范区品牌建设为重点，以提升全域旅游人才素质为支撑，通过发展全域旅游促进旅游业高质量发展。此外，我部将积极推动旅游演艺转型升级、提质增效，培育一批旅游演艺精品项目，加强宣传推广，充分发挥旅游演艺作为文化和旅游融合发展重要载体的作用，进一步丰富文化和旅游产品供给。

我部还将配合住房城乡建设部、林草局着力加强城市设计管理，拓展城市信息模型（CIM）基础平台智慧应用，开展城市生态修复功能修补工程，加强生态园林城市建设，提升森林景观质量，提高生态服务水平，丰富生态旅游产品，弘扬森林生态文化。

感谢您对文化和旅游工作的关心与支持。

文化和旅游部
