# 体育总局办公厅关于报送体育服务综合体典型案例的通知

各省、自治区、直辖市体育局：

体育服务综合体是指依托体育场馆、户外运动休闲空间、商业空间等载体，以体育服务为核心吸引，有效组合体育、健康、文化、旅游、休闲、娱乐、商业等功能，且各功能间相互依存、相互支撑、相互裨益的多功能、多业态、高效益的体育消费聚集区。根据空间载体的不同，体育服务综合体可分为体育场馆型、户外运动休闲空间型、商业空间载体型和其他四种类型（见附件1）。

近年来，各地创新思路、积极探索，在支持打造各类体育服务综合体方面积累了一些实践经验和成功做法，有效促进了体育消费升级和体育产业发展。为贯彻落实《国务院办公厅关于促进全民健身和体育消费推动体育产业高质量发展的意见》，应对新冠肺炎疫情对体育产业影响，促进体育消费回补和潜力释放，体育总局将征集一批体育特色鲜明、服务功能完善、经济效益良好的体育服务综合体典型案例，为各地加快培育体育服务综合体、打造体育消费新模式提供示范和借鉴。现将有关事项通知如下：

一、案例推荐

（一）所推荐典型案例要突出特色、展现亮点，既要有鲜活的实践做法，又要有经验的提炼升华，文字要求言简意赅、逻辑严密，有较强的可读性，能从方法上启发思路，从模式上提供借鉴，从实践上引导创新，有一定代表性。字数控制在4000字以内，可配图说明。

（二）所推荐典型案例的相关情况、数据和措施要确保真实、客观，特别是数据要准确、全面，杜绝弄虚作假。

二、报送要求

（一）请参照模板要求（见附件2）编写案例材料。每大类体育服务综合体推荐不超过1个典型案例。

（二）请各省（区、市）体育局于8月14日前将案例材料报送至体育总局经济司，并附电子版。电子邮件标题需注明“××省（区、市）体育服务综合体典型案例”字样。

三、其他

（一）请各省（区、市）体育局紧密结合工作实际，深入调查比较，遴选典型案例，认真做好报送工作。

（二）体育总局将组织专家对报送典型案例进行遴选，将优秀案例汇编成册，并开展相应示范、宣传和推广。

| **商业空间**  **载体型** | 体育服务  主导型 | 以体育为商业空间载体的主题元素，以体育服务为主导，并有休闲、娱乐、文化、餐饮、健康、商务等元素。 |
| 体育服务  导入型 | 以商业综合体为载体，在商业空间中导入体育服务功能，提供健身休闲、体育培训等服务。 |
| **其他类型** | 未涵盖在上述类型中的其他体育服务综合体类型。 | |

体育服务综合体典型案例撰写模板

一、基本情况

案例的基本情况，包括背景、概况及效益等方面。（该部分控制在500-1000字以内，可配图）

二、主要特点

案例的主要特点，包括在空间载体、运营模式、服务内容等方面解决的主要问题、方式方法及创新点等。（该部分控制在500-1000字以内，可配图）

三、经验做法

案例的经验做法，包括在综合体建设运营、提升体育消费水平、经济社会效益等方面的经验和举措。（该部分控制在1500-2000字以内）
