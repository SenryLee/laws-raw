# 文化和旅游部关于政协十三届全国委员会第三次会议第4367号（文化宣传类283号）提案答复的函

您提出的《关于尽快制定抢救、保护与收藏年迈艺术家的作品和藏品的政策以及具体实施方案的提案》收悉。我部会同国家文物局进行了认真研究，现答复如下：

近年来，随着经济社会快速发展，文化事业更加繁荣，美术事业迎来更好发展机遇，作为美术事业重要基础和组成部分的国家美术收藏工作也蓬勃开展，一大批年迈艺术家的作品及藏品入藏国有美术文化机构，极大丰富了国家美术收藏。但在民间收藏日趋兴盛，艺术市场空前活跃的形势下，以捐赠性收藏为主要藏品来源的国有美术文化机构在开展收藏工作时也面临较大压力和挑战。我部一直高度重视该项工作，指导并支持国有美术文化机构积极加强对年迈艺术家的作品及藏品进行保护和利用。

在政策研究制定方面，2019年，我部委托上海市文化和旅游局、浙江省文化和旅游厅、广东省文化和旅游厅分别开展民营美术馆规范化管理、公共美术馆服务标准建设、美术馆藏品征集管理等方面的调查研究，已经形成初步成果。此外，我部还针对《国家美术作品收藏和捐赠奖励项目实施办法（暂行）》修订工作开展调研，征集相关单位和专家意见，力图使该项政策更好适应新时代美术事业发展要求，更具科学性和有效性。国家文物局调整完善《文物出境审核标准限制出境书画名家名单》，指导国家文物出入境审核管理部门加强审核，防止年迈艺术家的重要作品及藏品流失境外。目前，国家文物局正研究起草《博物馆藏品征集规程》，将进一步规范博物馆征集藏品的相关程序标准，为博物馆开展年迈艺术家作品及藏品征集工作提供有力指引。

在具体收藏工作推进方面，2020年，我部组织实施国家美术作品收藏和捐赠奖励项目，推动中国艺术研究院、中国美术馆、中华艺术宫（上海美术馆）、江苏省美术馆等8家美术馆（机构）实施了14个捐赠收藏项目，沈鹏、戴泽、宋源文等一批年迈艺术家捐赠了自己的作品，古元、容庚、姜丹书等艺术家、学者的家属捐赠了相关藏品。2015年以来，我部推动相关国有美术文化机构完成了110个捐赠项目的收藏工作，其中重要的年迈艺术家及其亲属的捐赠项目占比超过93%，入藏美术作品及相关文献资料近2万件。

在藏品利用和宣传推广方面，我部通过组织实施全国美术馆馆藏精品展出季活动，推动美术馆加强藏品展示研究。此外，我部在全国美术馆藏品普查工作顺利完成的基础上，开展了《全国美术馆馆藏精品集（1949—2019）》的编辑出版工作。

总体来说，国家美术作品收藏工作取得了一定成绩，但与美术事业繁荣发展要求和人民群众期待还有一定差距，尤其是您提出的年迈艺术家作品及藏品收藏工作，尚需进一步加强。

在工作的推进过程中，我们也了解到，年迈艺术家在处置自己的作品时取向更加多元，除无偿捐赠至国有美术文化机构外，一些作品通过市场交易等方式进入民营美术馆、艺术博物馆等美术机构，也得到了充分展示和宣传推广，丰富了人民群众的精神文化生活。

2016年，国务院印发《关于推进中央与地方财政事权和支出责任划分改革的指导意见》（国发〔2016〕49号），强调要“最大限度减少中央对微观事务的直接管理，发挥地方政府因地制宜加强区域内事务管理的优势，调动和保护地方干事创业的积极性和主动性”。对于收藏工作，地方政府和相关单位有充分的自主权。近年来，在我部推动下，各地政府更加重视美术作品收藏工作，持续加大投入，各地的美术馆作为收藏工作的实施主体，立足各地实际，根据各自馆藏资源、学术定位、收藏标准以及经费预算等情况，研究制定收藏规划，并积极推进落实，取得了较大成果。

下一步，结合您提出的建议，我们将从以下几方面加强此项工作：一是结合上述调研工作，委托相关单位，在尊重艺术家的财产权、隐私权的前提下，针对年迈艺术家作品及藏品收藏工作开展专项调研，了解艺术家捐赠意愿。对于有捐赠意愿的艺术家，我们将推动地方政府和美术馆积极跟进。二是通过制度建设加强顶层设计，修订完善《国家美术作品收藏和捐赠奖励项目实施办法（暂行）》，同时，加强藏品征集管理工作研究，开展藏品征集管理规范等相关制度建设，进一步明确相关工作要求，不断提高收藏工作水平。三是进一步引导推动地方政府和相关单位积极关注年迈艺术家作品及藏品收藏工作，立足实际，加大投入，强化宣传引导，畅通捐赠渠道，让更多的年迈艺术家深入了解美术馆的收藏定位、标准以及捐赠方式、程序，鼓励艺术家进行捐赠，让更多作品入藏国有美术馆。四是通过组织实施的各项美术文化活动，推动美术文化机构加强

感谢您对文化和旅游工作的关心与支持！
