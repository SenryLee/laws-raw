# 公开市场业务交易公告[2020]第100号——关于2020年5月26日人民银行以利率招标方式开展了100亿元逆回购操作的公告

## 公开市场业务交易公告

[2020]第100号

为维护银行体系流动性合理充裕，2020年5月26日人民银行以利率招标方式开展了100亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 100亿元 | 2.20% |

中国人民银行公开市场业务操作室

二〇二〇年五月二十六日
