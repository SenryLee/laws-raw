# 生态环境部办公厅关于解除打击固体废物环境违法行为专项行动中挂牌督办问题的通知

## 关于解除打击固体废物环境违法行为专项行动中挂牌督办问题的通知

环办执法函〔2020〕478号

江苏省生态环境厅：

按照《关于对2019年打击固体废物环境违法行为专项行动中发现的突出问题挂牌督办的通知》（环办执法〔2019〕57号），你厅督促相关地方和企业落实限期整治、溯源调查、依法查处、信息公开等整改工作要求。苏州市昆山格鸿电子材料有限公司未按规范贮存危险废物、盐城市响水县省属黄海农场226省道旁堆存疑似危险废物、淮安市淮阴区马头镇堆存大量废旧塑料和编织废料、南京八幸药业科技有限公司在原址填埋危险废物、扬州市江北包装制品有限公司未按规定管理产生的危险废物等5个固体废物问题的整治基本达到督办要求，你厅向我部提交了解除挂牌督办的申请。

经核查，现对以上5个问题解除挂牌督办。请你厅督促相关地方人民政府进一步落实生态环境保护职责，巩固挂牌督办整改成果，举一反三，持续推进固体废物监管工作，加大环境执法力度；督促企业落实环境保护主体责任，严厉打击涉固体废物环境违法行为，积极防范环境风险，促进环境质量持续改善。
