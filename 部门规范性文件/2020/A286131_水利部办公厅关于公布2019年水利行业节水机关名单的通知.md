# 水利部办公厅关于公布2019年水利行业节水机关名单的通知

办节约〔2020〕4号

部机关各司局，部直属各单位，各省、自治区、直辖市水利（水务）厅（局），新疆生产建设兵团水利局：

为深入贯彻"节水优先"方针，落实水利部党组打好节约用水攻坚战工作部署，各地各单位积极探索节水机关建设模式，扎实开展节水机关建设。按照计划安排，经对2019年度完成建设任务的水利部机关、部直属单位机关、省级水行政主管部门机关进行审核，43家单位达到验收标准，现将2019年水利行业节水机关名单予以公布（名单附后）。

希望通过验收的单位再接再厉，巩固建设成果，总结推广建设经验，深化节水宣传教育，发挥节水标杆示范作用，带动全社会节约用水。

水利部办公厅

2020年1月7日

附件：2019年水利行业节水机关名单
