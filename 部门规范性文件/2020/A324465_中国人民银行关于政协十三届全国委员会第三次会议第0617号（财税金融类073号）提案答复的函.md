# 中国人民银行关于政协十三届全国委员会第三次会议第0617号（财税金融类073号）提案答复的函

宋海委员：

您提出的关于保持金融政策及主要措施支持精准扶贫五年不变的提案收悉，经商财政部、银保监会、证监会，现答复如下：

**一、**关于保持现有金融支持精准扶贫政策力度问题

人民银行、银保监会等部门认真贯彻落实党中央、国务院决策部署，充分发挥金融在脱贫攻坚中的支持作用，围绕货币政策工具、金融市场产品、支付服务和信用体系建设、金融消费者权益保护等多个方面，制定金融助推脱贫攻坚、金融支持深度贫困地区、切实做好2019年—2020年金融精准扶贫工作等系列政策文件并推动落实。此外，人民银行创设并完善扶贫再贷款政策，创新扶贫小额信贷、产业扶贫贷款等产品；银保监会明确对贫困地区实施差异化监管政策，引导银行保险机构增加对贫困地区的金融供给，为打赢打好脱贫攻坚战提供了有力支撑。截至2020年二季度末，全国金融精准扶贫贷款余额达4.2万亿元，贫困人口及已脱贫人口贷款余额7429亿元，覆盖面达25.8%，产业精准扶贫贷款余额1.6万亿元，同比增长30%。

目前，人民银行等部门按照习近平总书记“摘帽不摘责任、摘帽不摘政策、摘帽不摘帮扶、摘帽不摘监管”的“四个不摘”要求，继续保持金融帮扶政策总体稳定，对已脱贫地区信贷资源投放力度不减，巩固脱贫成果。以扶贫再贷款政策为例，按照现行规定，扶贫再贷款可展期4次，支持期限最长可至2025年。

下一步，人民银行、银保监会等部门将按照打赢脱贫攻坚战后的总体要求，联合相关部门研究完善金融支持政策，巩固脱贫成果防止返贫，探索支持解决相对贫困的长效机制，为推进乡村经济长远发展奠定坚实的金融基础。

**二、**关于建立专门的政策性扶贫机构，发挥政策性金融扶贫作用问题

人民银行、银保监会等部门不断完善金融扶贫组织体系，指导金融机构内设扶贫金融部门，发挥金融扶贫作用，加强风险防范，切实加大对脱贫攻坚的支持力度。

一是发挥开发性、政策性金融机构的扶贫作用。指导国家开发银行、农业发展银行设立扶贫金融事业部，支持易地扶贫搬迁、贫困地区基础设施建设等，有效发挥开发性、政策性金融机构扶贫作用。截至2020年二季度末，农业发展银行金融精准扶贫贷款余额1.5万亿元，国家开发银行金融精准扶贫贷款余额7752亿元。

二是充分发挥商业性金融机构支农扶贫作用。推动农业银行、邮储银行设立“三农”金融事业部，大中型商业银行普遍设立普惠金融事业部，引导农村中小金融机构坚守支农支小定位，下沉金融服务重心，充分满足贫困群众和扶贫产业发展的融资需求。鼓励商业银行尤其是城商行、农商行根据自身经营情况，在市场化、法治化框架下积极投放扶贫贷款。

三是加强商业性金融扶贫领域风险防范。坚持金融支持与风险防范两手抓，高度关注扶贫领域融资可能存在的风险，指导金融机构加强对扶贫小额信贷等信贷资产质量的监测，推动建立健全贫困地区融资风险分担和补偿机制，支持有条件的地方设立扶贫贷款风险补偿基金和担保基金，做好风险防范，促进金融扶贫可持续。同时，加强政策宣传和金融知识普及活动，帮助农村居民、贫困户提升金融素养水平，增强其风险意识。

新设专门的政策性扶贫机构，与现有开发性、政策性金融机构业务存在交叉，而且新设机构的人力物力成本较高，也存在与当前精简机构和人员的行政管理体制改革方向如何衔接等问题，因此需要审慎研究相关工作。

下一步，人民银行将会同相关部门，在如期打赢脱贫攻坚战，统筹推进金融扶贫和乡村振兴金融服务有机衔接的基础上，不断完善政策措施，加强前瞻性研究。同时，继续支持开发性、政策性银行立足自身行业定位，按照国家脱贫攻坚有关要求，持续做好金融扶贫和乡村振兴金融服务工作。

**三、**关于政策引导促进扶贫参与主体多元化问题

人民银行、银保监会、证监会等部门持续加强金融政策指导，推动完善金融扶贫组织体系，改进完善金融服务，推动构建与高质量完成金融扶贫任务相适应的金融扶贫政策体系和组织体系，促进扶贫参与主体多元化。

一是加强金融扶贫政策指导。人民银行联合银保监会、证监会等部门先后出台《关于金融助推脱贫攻坚的实施意见》（银发〔2016〕84号文）、《关于金融支持深度贫困地区脱贫攻坚的意见》（银发〔2017〕286号文）、《关于切实做好2019年—2020年金融精准扶贫工作的指导意见》（银发〔2019〕124号文）等政策文件，引导各类金融机构细化落实金融扶贫措施，加大对贫困地区的资金支持，加大产品创新力度，提高金融扶贫成效。

二是推动各类金融机构加大资源投入。人民银行、银保监会等部门加强对包括开发性、政策性银行和商业性大中小型银行在内的金融机构的督促指导，提出金融扶贫考核工作目标，每季度对考核完成情况进行汇总通报。

三是不断拓宽金融扶贫融资渠道。证监会、人民银行等部门积极发挥资本市场作用，对贫困地区企业首次公开发行股票、新三板挂牌、发行债券、并购重组等开辟绿色通道，推动扶贫票据等融资产品在银行间市场发行，创新易地扶贫搬迁专项金融债，以市场化方式引导社会资本投向贫困地区和扶贫项目，支持贫困地区产业发展，帮助贫困群众稳定脱贫。

下一步，人民银行等部门将从健全具有高度适应性、竞争力、普惠性的现代金融体系的全局出发，持续加强政策指导和监测评估，引导更多机构积极参与扶贫事业。

**四、**关于进一步完善农村贫困地区和贫困人口融资型担保体系问题

财政部会同有关部门不断创新财政支农方式，设立国家融资担保基金，不断完善政府性融资担保体系建设，建立银行与担保机构之间，中央、省、市、县四级担保机构之间的多层次风险分担机制和业务联动机制，实现基金、担保机构、银行三方互动，有效减轻商业银行和担保机构支农支小的后顾之忧。

一是推进农业信贷担保体系建设。2016年，财政部等部门推动成立国家农业信贷担保联盟有限公司，并加大对地方建立农业信贷担保体系工作的指导。截至2020年二季度末，已注册成立33家省级农业信贷担保公司，设立分支机构1304家。2020年，财政部印发《关于进一步做好全国农业信贷担保工作的通知》（财农〔2020〕15号文），要求省级财政进一步健全担保费用补助和业务奖补政策，推动省级农业信贷担保公司加快业务发展。

二是发挥政府性融资担保作用。财政部印发《关于充分发挥政府性融资担保作用为小微企业和“三农”主体融资增信的通知》（财金〔2020〕19号文）等文件，要求政府控股的融资担保再担保机构要积极为小微企业和“三农”主体融资增信，扩大业务规模，及时履行代偿责任，推动金融机构加大对包括已脱贫地区在内的小微和“三农”的信贷支持。同时，强化考核激励，督促国家融资担保基金加快对支小支农成效明显的地市级政府融资担保机构开展股权投资，引导各级政府性融资担保机构精准聚焦支小支农业务。

下一步，人民银行、银保监会将继续配合财政部等部门，不断完善农村融资担保体系，进一步加大对地方省级以下担保体系的支持力度，着力解决农村贫困地区担保问题。

**五、**关于进一步创新农村金融服务方式和产品的建议

近年来，人民银行、银保监会等部门不断加强政策指导，引导金融机构结合金融扶贫和乡村振兴金融服务要求，不断创新金融产品和服务；同时，深入推进完善支付清算、征信等普惠金融服务，满足农村地区多样化的金融需求。

一是创新金融产品和服务，推动农业产业化发展。人民银行积极引导金融机构用好用足扶贫小额信贷、农户小额信用贷款、创业担保贷款，在返乡创业试点地区拓展返乡创业企业信用贷款业务，助力农民工返乡创业，巩固脱贫成果。同时，积极稳妥开展农村承包土地经营权抵押贷款、林权抵押贷款，推动厂房和大型农机具抵押、圈舍和活体畜禽抵押、动产抵押、仓单和应收账款质押、农业保单融资等信贷业务，鼓励对资信良好、资金周转量大的家庭农场发放信用贷款，发展农业供应链金融，推动实现信贷助力已脱贫人口走向农业产业化发展的道路。

二是加强农村支付服务环境建设，推动支付结算创新。人民银行不断完善贫困地区支付服务基础设施建设，有序推广中央银行会计核算系统，方便农村金融机构“居家式”办理业务，借助现代科技手段发展线上业务，深入开展移动支付便民工程，为农民提供足不出村的便捷金融服务。指导中国银联联合商业银行推出“乡村振兴主题卡”，在有效提供存取款、转账等基本支付功能的基础上，附加助农贷款、补贴发放、农产品生产销售等特色服务，满足已脱贫地区和人口多样化金融需求。目前，贫困地区约有5万个农村银行网点接入人民银行支付系统，接入率达96%；贫困地区网上银行、手机银行开通数均超过2亿户；乡村振兴主题卡累计发卡规模达1000万张。

三是落实征信为民理念，持续推进农村信用体系建设。人民银行积极指导分支机构开展农户信用信息征集、信用评价和信息应用，上线运行新一代金融信用信息基础数据库，完善金融信用信息基础数据库，引导和推动金融机构、政府部门等制定相关配套政策措施，助力有信用的农户融资发展。截至2020年二季度末，全国累计建立农户信用档案1.89亿户，对1.34亿农户开展信用评定。

四是深入开展金融教育，推进普惠金融发展。人民银行、银保监会发挥数字渠道优势，持续开展集中性金融知识普及活动，推动金融知识纳入国民教育体系，阻断贫困代际传递，增强可持续脱贫动力。完善普惠金融指标体系，指导地方开展普惠金融试点建设，提升农村居民的金融素养水平，防止脱贫群众再返贫。

下一步，人民银行、银保监会等部门将持续引导金融机构创新金融产品，优化金融服务，加大对农业产业化发展的金融支持。同时，继续推进农村支付服务体系和信用体系建设，推动网络支付等新兴支付方式向农村发展，优化金融信用信息基础数据库功能，深入开展普惠金融等工作，帮助已脱贫地区和人口巩固脱贫成果，做好与乡村振兴金融服务的有效衔接。

感谢您对金融工作的关心和支持。欢迎登录人民银行门户网站（www.pbc.gov.cn），了解人民银行最新工作动态及金融领域的相关信息。
