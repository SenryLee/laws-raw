# 国家文物局办公室关于山东省文物工程公司文物保护工程施工一级资质证书内容变更的函

办保函〔2020〕355号

山东省文化和旅游厅：

你厅《关于山东省文物工程公司变更施工一级资质证书信息的请示》（鲁文旅呈〔2020〕68号）收悉。

经研究，我局同意山东省文物工程公司文物保护工程施工一级资质证书中的单位地址由“山东省济南市历下区广智院街146号”变更为“济南市上新街51号”。请你厅通知申请单位携带资质证书副本到我局办理相关手续。

请你厅指导督促资质单位按照我局《关于上线试运行全国文物保护工程资质单位数据库和甲、一级资质单位在线管理系统的通知》（文物保函〔2019〕1253号）要求，尽快完成数据库填报工作，所报信息经审核通过后，甲一级资质单位的信息变更须通过在线管理系统申请办理。

国家文物局办公室

2020年5月12日
