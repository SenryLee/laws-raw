# 国家能源局综合司关于同意莲花等49座水电站大坝安全注册登记的复函

国能综函安全〔2020〕14号

大坝安全监察中心：

报来《关于莲花等49座水电站大坝安全注册检查意见的请示》（坝监安监〔2019〕106号）收悉。经研究，函复如下。

一、同意青海积石峡，重庆浩口，湖南托口，四川民治、猴子岩，西藏果多，云南木加甲一级，贵州角木塘、象鼻岭等9座水电站大坝以及海南琼中抽水蓄能电站上库、下库2座大坝安全初始注册，注册登记等级均为甲级。

二、同意新疆斯木塔斯，湖北朝阳寺，四川小沟头、毛滩、吉鱼、龙洞，云南威远江、罗闸河二级等8座水电站大坝安全初始注册，注册登记等级均为乙级。

三、同意黑龙江莲花、镜泊湖，辽宁桓仁、回龙山，吉林雪山湖，福建安砂、水口，湖南东坪，四川仙女堡、千佛岩、小天都、金康、龙凤，广西洞巴、西津、左江，云南糯租、赛珠、高桥、油房沟、柏香林、杨柳滩，贵州黄花寨、挂治、石垭子等25座水电站大坝，以及辽宁蒲石河抽水蓄能电站上库、下库，安徽琅琊山抽水蓄能电站上库等3座大坝安全换证注册，注册登记等级均为甲级。

四、同意云南倮马、克田等2座水电站大坝安全换证注册，注册登记等级为乙级。

五、请你中心重点督促落实辽宁蒲石河抽水蓄能电站下库入库洪水预报能力不足、云南罗闸河二级水电站大坝泄洪和冲沙闸门调度及操作不规范、四川毛滩水电站防洪堤存在较大渗水并缺少相应应急处置方案、广西洞巴水电站大型漂浮物失控危及大坝安全应急预案不健全等问题的整改。

请你中心继续按照规定要求做好水电站大坝安全技术监督和管理保障工作，配合有关派出能源监管机构督促电力企业加强大坝安全管理，限期完成注册现场检查和定期检查发现问题整改，确保问题隐患闭环管理。

国家能源局综合司

2020年1日10日
