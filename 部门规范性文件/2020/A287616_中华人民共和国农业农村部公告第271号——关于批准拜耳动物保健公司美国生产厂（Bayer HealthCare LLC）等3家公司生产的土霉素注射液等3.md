# 中华人民共和国农业农村部公告第271号——关于批准拜耳动物保健公司美国生产厂（Bayer HealthCare LLC）等3家公司生产的土霉素注射液等3种兽药产品在我国再注册的公告

## 中华人民共和国农业农村部公告

第271号

根据《兽药管理条例》和《兽药注册办法》规定，经审查， 批准拜耳动物保健公司美国生产厂（Bayer HealthCare LLC）等3家公司生产的土霉素注射液等3种兽药产品在我国再注册，核发《进口兽药注册证书》,并发布修订后的产品质量标准、说明书和标签，自发布之日起执行。此前发布的前述产品兽药质量标准、说明书和标签同时废止。

特此公告。

附件：1.进口兽药注册目录

2.质量标准（略）

3.说明书和标签

农业农村部

2020年02月21日
