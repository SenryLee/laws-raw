# 民政部公告第477号——民政部关于发布《志愿服务基本术语》等3项行业标准的公告

## 民政部公告

第477号

## 民政部关于发布《志愿服务基本术语》等3项行业标准的公告

《志愿服务基本术语》、《行政区域界桩数据交换格式》和《行政区域界线数据交换格式》3项推荐性行业标准已经民政部批准，现予以发布，自2020年3月24日起实施。

|  |  |  |
| --- | --- | --- |
| 序号 | 标准号 | 标准名称 |
| 1 | MZ/T 148-2020 | 志愿服务基本术语 |
| 2 | MZ/T 149-2020 | 行政区域界桩数据交换格式 |
| 3 | MZ/T 150-2020 | 行政区域界线数据交换格式 |

民政部

2020年3月24日
