# 国家邮政局关于授予“2019年快递服务现代农业金牌项目”的通知

国邮发〔2020〕6号

各省、自治区、直辖市邮政管理局，国家局直属各单位、机关各司室：

2019年是邮政业助力打赢脱贫攻坚战的关键年。《中共中央 国务院关于坚持农业农村优先发展做好“三农”工作的若干意见》提出，“发展壮大乡村产业，拓宽农民增收渠道”“实施‘互联网+’农产品出村进城工程”。全行业坚持以习近平新时代中国特色社会主义思想为指导，积极发挥产业优势，全面贯彻落实党中央、国务院关于脱贫攻坚的重大决策部署，在服务网络不断向农村地区下沉的基础上，精准对接现代农业，在促进快递服务农业生产领域取得显著成效，为脱贫攻坚做出了突出贡献。

各地邮政管理部门按照2019年全国邮政管理工作会议提出的“继续打造‘快递+’农业金牌项目”的工作要求，主动担当、积极作为，在充分发挥市场在资源配置中决定性作用的同时，有效发挥政府部门作用，抓住本地农产品“上行”特点，培育出37个业务量突破千万件的快递服务现代农业项目。

上述项目普遍具有政府组织协调力度强、服务现代农业模式新、调动社会资本投入多、农村网络覆盖范围广和支撑乡村振兴作用大的特点。项目所在地邮政管理部门在政治上提高站位，在思想上高度重视，在落实上精准到位，在部署上周密有力。为进一步发挥“快递服务现代农业金牌项目”的品牌作用，充分体现地方政府和寄递企业工作成果，助力乡村振兴战略全面实施，决定授予江苏宿迁沭阳花木、安徽亳州花草茶、广西柳州螺蛳粉等37个业务量达到千万件的项目为“2019年快递服务现代农业金牌项目”（具体项目名单见附件）。

各省（区、市）邮政管理部门要充分发挥金牌项目的示范带头作用，加大宣传引导力度，树立表彰先进的工作导向，推动打造数量更多、质量更优的金牌项目。项目所在地邮政管理部门要向当地党委、政府汇报表彰情况，突出行业在支持地方经济发展方面的作用，积极推动《国务院办公厅关于印发交通运输领域中央与地方财政事权和支出责任划分改革方案的通知》精神的落实，争取地方政府在农村快递末端网络建设方面的支持，为快递“下乡”“进村”营造良好的政策环境。其他地区邮政管理部门要学习借鉴相关工作经验，推动农村快递服务网络建设，挖掘当地快递服务农业特点和发展潜力，争创2020年金牌项目。

全系统要充分认识快递服务现代农业在推动快递“下乡”“进村”、助力脱贫攻坚方面的重要支撑作用，持续推动、力求实效，确保2020年再上新台阶，为全面实施乡村振兴战略奠定坚实基础。

附件：2019年全国快递服务现代农业金牌项目名单
