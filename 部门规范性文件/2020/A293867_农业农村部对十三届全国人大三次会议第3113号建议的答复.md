# 农业农村部对十三届全国人大三次会议第3113号建议的答复

## 对十三届全国人大三次会议第3113号建议的答复

农办议〔2020〕86号

郭玫代表：

您提出的关于将中药材纳入国家有机肥替代化肥行动的建议收悉。经商财政部，现答复如下。

一、关于将中药材种子种苗纳入良种补贴范围

为切实加强中药材种子管理，促进中药材产业健康发展，2016年我部联合中医药局、中国中医科学院等单位启动《中药材种子管理办法》制定工作，多次赴甘肃陇西、广西玉林等中药材生产基地开展联合调研，召开专题座谈会，广泛听取有关专家、管理人员、生产经营者意见，反复修改完善。目前，《中药材种子管理办法》已形成草案，内容涵盖种质资源保护、品种选育与登记、生产经营、市场监管及进出口等方面，整体工作取得阶段性进展。同时，为提升中药材制种基地建设水平，2019年我部认定了甘肃陇西、贵州大方、山东平邑、湖南邵东、湖北英山、安徽霍山、福建邵武、云南云县等8个中药材制种大县，对中药材种子科研生产、良种良法配套示范等予以支持，全面提升中药材制种保障能力。

关于您提到的农作物良种补贴，2016年中央财政全面推开农业“三项补贴”改革，调整优化支出结构，将农作物良种补贴、种粮农民直接补贴和农资综合补贴合并为农业支持保护补贴，政策目标调整为支持耕地地力保护和粮食适度规模经营，不再对农作物良种单独予以补贴。

下一步，我部将加大工作力度，推进《中药材种子管理办法》尽快出台，加快选育中药材新品种，改善品种结构，提升品质等级。

二、关于将中药材纳入有机肥替代化肥试点范围

有机肥替代化肥是农业绿色发展五大行动的重要内容，各级农业农村部门坚持绿色发展理念，强化政策扶持，突出创新驱动，取得了阶段性成效。一是生产生态双赢，农民施用有机肥的习惯逐步形成，农业的生态涵养功能更加突显。二是减量增效同步，通过增施有机肥，减少化肥使用，农产品品质提高、附加值提升，实现了节本增收、提质增收。三是探索了一套有效的组织方式和政策框架，建立了中央统筹、省级负责、县级实施的工作机制，初步形成了以政府购买服务为主、施用补助为辅的补贴制度。

下一步，我部将在总结经验的基础上，扩大果菜茶有机肥替代化肥试点范围，探索将中药材纳入实施内容，集成推广一批中药材有机肥替代化肥技术模式，促进中药材产业高质量发展。

三、关于在中药材上禁用高毒农药

针对目前缺乏中药材专用农药的现状，我部安排专门资金支持开展中药材等特色小宗作物用药调查及试验，加快推进中药材等特色小宗作物用药试验技术评审和登记。近年来，我部对46种高毒高风险农药采取了全面禁用措施；对20种农药采取了限制使用措施，其中禁止甲拌磷、克百威、内吸磷等15种高毒高风险农药在中草药上使用，严格管控约束中草药用药，确保中草药生产安全。开展监督抽查，按照“双随机一公开”的要求，采取随机抽样、重点抽样、专项抽样相结合的方式，组织开展农药产品质量监督抽查，重点对主要农药市场、“黑名单”农药企业及果菜茶和中药材用药进行抽查，严厉查处违规经营行为，净化农药市场、确保产品质量。

下一步，我部将进一步加强农药市场的规范管理，净化市场环境，规范中药材生产安全用药，保障中药材产品质量。

感谢您对我部工作的关心，希望继续对“三农”工作给予支持。
