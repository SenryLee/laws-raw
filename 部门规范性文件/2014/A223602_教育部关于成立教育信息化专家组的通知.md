# 教育部关于成立教育信息化专家组的通知

教技函[2014]67号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

为全面落实教育规划纲要和教育信息化十年发展规划，加快推进教育信息化进程、保障教育信息化科学发展，充分发挥专家学者在教育信息化规划、重要政策以及重大问题上的研究、咨询、指导作用，经研究，决定成立教育信息化专家组。现将有关事项通知如下：

**一、专家组的性质**

教育信息化专家组是在教育部信息化领导小组领导下，对教育信息化工作进行研究、咨询、指导的专家组织。

**二、主要任务**

1.参与对教育信息化发展战略规划、重大方针政策、重要文件以及重大项目等的咨询论证。

2.跟踪国内外教育信息化发展趋势，对教育信息化重大问题进行专题研究，提出政策建议。

3.面向教育信息化具体实践，开展多种形式的调研指导、学术研讨等。

4.委托的其他任务。

**三、专家组的组成**

教育信息化专家组成员主要由各级各类学校、政府、相关机构和企业等在信息化、信息技术、教育教学、管理等方面具有深入研究和丰富经验的专家学者组成，专家组设组长1人，副组长2人，秘书长1人。本届专家组任期自2014年12月1日起至2017年12月31日止。

附件：教育信息化专家组名单。

教育部

2014年12月9日
