# 国家体育总局青少司关于做好2014年青少年体育统计年报工作的通知

各省、自治区、直辖市体育局，新疆生产建设兵团体育局：

2013年体育总局青少司在全国范围内布置了青少年体育基础数据统计工作，得到了各地方体育局及青少年体育管理人员的高度重视和全力配合。在各地上报的基础上，我司现已基本完成了2012年全国青少年体育基础数据的汇总工作。为更好地发挥青少年体育基础数据对青少年体育工作的推动作用，根据工作安排，2014年将继续开展全国青少年体育统计工作，现将有关事宜通知如下。

**一、**责任单位

各省（区、市）体育局青少处（或相关责任处室）负责本行政辖区内青少年体育统计年报工作。

**二、**填报内容及时间

为更加及时、准确地反应青少年体育工作实际，今年将完成2013年和2014年两个年度的数据统计工作。

（一）2013年统计数据（截止时间2013年12月31日），请于2014年11月30日前完成填报工作。

（二）2014年统计数据（截止时间2014年12月31日），请于2015年1月31日前完成填报工作。

**三、**填报工作说明及要求

（一）请各单位以统计工作为契机，系统梳理本省（区、市）青少年体育工作基本情况，加强对各方面数据的收集、整理和建档工作，力求统计数据的真实性和准确性。

（二）《全国青少年体育统计年报报表》由8套表格组成，表1为综合表，表2至表8为基层表。表1数据应在表2至表8数据基础上汇总形成。

（三）请各省（区、市）体育局青少处（或相关责任处室）高度重视此项工作，组织好对下级部门和基层单位的培训工作，确保各项统计指标数据的真实性和准确性。

（四）从今年起《全国青少年体育统计年报报表》的相关数据需经网络系统填报完成，填报网址：www.qsnty.org。各地市级单位汇总表1数据时，应在下属各基层单位所有表2至表8基础数据完成上报后，再进行汇总。

请各单位完成网络填报后，将《表1：全国青少年体育基础数据调查统计表》打印并加盖省（区、市）体育局公章后，采用特快专递寄至体育总局科研所青少中心。
