# 中国地震局党组关于张敏、王保国、刘杰3同志职务任免的通知

中国地震局党组关于张敏、王保国、刘杰3同志职务任免的通知

中国地震台网中心党委：

2013年12月20日中国地震局党组决定，免去张敏同志中国地震台网中心党委副书记、纪委书记职务，另有任用。

2014年2月11日中国地震局党组决定，任命王保国同志为中国地震台网中心纪委书记，任职试用期1年；任命刘杰同志为中国地震台网中心副主任，任职试用期1年。

特此通知

中国地震局党组

2014年4月9日
