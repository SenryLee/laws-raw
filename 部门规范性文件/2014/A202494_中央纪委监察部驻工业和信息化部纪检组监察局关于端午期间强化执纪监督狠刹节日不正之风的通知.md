# 中央纪委监察部驻工业和信息化部纪检组监察局关于端午期间强化执纪监督狠刹节日不正之风的通知

部系统各级纪检监察机构：

端午将至，为廉洁过节，坚决刹住节日不正之风，现就进一步强化执纪监督，深化中央八项规定精神落实通知如下：

各级纪检监察机构要坚守责任担当，认真落实驻部纪检组监察局4月29日《关于“五一”、端午期间强化执纪监督深化中央八项规定精神落实的通知》要求，扭住落实中央八项规定精神不放，抓住端午这个节点，加强思想教育，突出工作重点，严格执纪问责，重点查处利用公款购买赠送粽子等节礼、互相宴请、公款旅游、公车私用，违规发放津贴补贴、奖金和实物等各种福利，出入私人会所、高档娱乐场所及各种变通变相、隐蔽规避的隐形“四风”问题。

要进一步加大惩戒问责力度，对违纪违规行为“零容忍”，发现一起、查处一起、点名道姓通报曝光，不断巩固和深化成果。要快查快办端午期间违反中央八项规定精神的违纪违法案件，并在办结后3个工作日内向驻部组局报告违纪人姓名、工作单位及职务职级、主要违纪事实、处理结果等，驻部组局将在部门户网站和部内网点名道姓公开曝光。对违反中央八项规定精神等违纪违法行为匿情不报、压案不查的，将严肃追究有关领导责任。

端午期间，驻部组局将通过举报信箱（jcjjubao@miit.gov.cn）随时受理违反廉洁过节要求的信访举报，并按照“零容忍”的要求严肃处理，坚决刹住节日期间不正之风。

中央纪委监察部驻工业和信息化部纪检组监察局

2014年5月29日
