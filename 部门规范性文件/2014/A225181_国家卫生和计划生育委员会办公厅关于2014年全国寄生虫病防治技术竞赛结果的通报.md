# 国家卫生和计划生育委员会办公厅关于2014年全国寄生虫病防治技术竞赛结果的通报

国卫办疾控函〔2014〕1169号

各省、自治区、直辖市卫生计生委，新疆生产建设兵团卫生局：

为进一步提高全国疾控机构专业技术人员的寄生虫病防治理论水平与检测技能，增强各地重点和常见寄生虫病的综合防治能力，2014年9月17日-19日，我委在山东省济南市举办了全国寄生虫病防治技术竞赛。全国共有31个省（自治区、直辖市）的124名选手参加了本次竞赛，其中县级及以下专业机构选手有69名，占55.65%，30岁及以下选手有60名，占48.39%，初级职称选手84名，占67.74%。现将竞赛结果通报如下：

竞赛评出个人奖36项，团体奖10项，优秀组织奖5项，团体鼓励奖2项。有24名参赛选手、16个省份代表队获奖。江苏省、江西省、安徽省和湖北省代表队分别荣获团体奖前4名。安徽省铜陵县血防站刘志宏荣获综合考核和个人技能操作考核一等奖。贵州省疾控中心朱爱娅、江苏省血吸虫病防治研究所刘耀宝、云南省地方病防治所宋静等三人荣获个人理论考核一等奖。

根据对本次竞赛结果的初步分析，80.64%的参赛选手总成绩达到及格水平，其中理论知识考核及格率较高，达到98.39%，但镜检技能考核及格率仅为46.77%，仅有14个省的团体理论成绩与技能成绩同时达到及格水平，反映出地方寄生虫检测中技能操作环节欠规范、镜检识别能力不高等问题。与前两年相比，各地区之间的差距缩小，中部省份成绩明显提高，西藏、青海等西部省份进步显著。各省级卫生计生行政部门和疾病预防控制中心对本次竞赛高度重视，开展多层培训遴选优秀选手参赛，达到了以赛代训、以赛促防的目的。

针对本次竞赛反映出的问题，各省级卫生计生行政部门要建立和培训寄生虫病防治技术师资队伍，有针对性地开展基层防治机构和医疗机构实验室检测能力培训，不断提高我国寄生虫病防治水平。
