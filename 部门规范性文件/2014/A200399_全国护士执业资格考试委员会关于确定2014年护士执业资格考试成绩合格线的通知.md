# 全国护士执业资格考试委员会关于确定2014年护士执业资格考试成绩合格线的通知

各考区：

经研究，2014年护士执业资格考试成绩合格线为：专业实务77分，实践能力79分。一次考试通过两个科目为考试成绩合格。

特此通知。

全国护士执业资格考试委员会

2014年7月18日
