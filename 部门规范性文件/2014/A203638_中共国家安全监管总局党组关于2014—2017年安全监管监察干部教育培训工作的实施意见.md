# 中共国家安全监管总局党组关于2014—2017年安全监管监察干部教育培训工作的实施意见

## 中共国家安全监管总局党组关于2014-2017年安全监管监察干部教育培训工作的实施意见

（安监总党〔2014〕18号）

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局党组，各省级煤矿安全监察局党组，总局和煤矿安监局机关各司局、应急指挥中心及各直属事业单位、社团组织党委（总支、支部）：

为深入贯彻落实党的十八大精神和党中央、国务院关于加强安全生产工作的一系列重要决策部署，培养造就高素质安全监管监察干部队伍，根据中共中央《2013-2017年全国干部教育培训规划》，结合安全生产工作实际，现就2014-2017年安全监管监察干部教育培训工作提出如下实施意见。

**一、**总体思路和目标要求

坚持以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想和科学发展观为指导，深入贯彻落实党的十八大精神，牢牢把握加强党的执政能力建设、先进性和纯洁性建设这条主线，紧紧围绕安全生产工作大局，坚持分级分类、按需施教、学以致用、注重实效，全面深化干部教育培训改革，全面提升干部教育培训质量，努力培养信念坚定、敢于担当、善抓落实、职业内行、自身严格的优秀安全监管监察干部，为推动科学发展安全发展、促进安全生产形势持续稳定好转提供思想保障和人才支撑。

全国安全监管监察系统处级及以上干部人均年脱产培训时间不少于110学时，其他干部人均年脱产培训时间不少于90学时。到2017年，全国安全监管监察系统干部网络培训覆盖率达到90%以上，每人每年网络培训学时数不低于50学时。

**二、**重点培训内容

（一）深入开展马克思主义基本原理和中国特色社会主义理论体系学习培训。组织广大干部深入学习马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观和习近平总书记系列重要讲话精神，引导干部深刻领会中国特色社会主义的科学内涵，用科学理论武装头脑，提高运用马克思主义立场、观点和方法分析解决安全生产问题的能力，推动实施安全发展战略，不断促进安全生产工作创新发展。

（二）大力加强党性党风党纪、党史国史和社会主义核心价值体系教育。加强党章的学习培训、党的纪律特别是政治纪律教育，突出马克思主义群众观点和党的群众路线教育、作风教育和反腐倡廉教育。加强党史国史特别是党领导人民的奋斗史、创业史、改革开放史教育。组织广大干部深入学习社会主义核心价值体系，加强中国特色社会主义共同理想教育和社会主义道德教育。把党性教育和社会主义核心价值观教育与安全监管监察实践紧密结合起来，引导干部增强安全意识、使命意识。

（三）着力抓好业务能力培训。准确把握新形势下安全生产特点规律，积极开展安全生产红线意识、安全发展理念和安全发展战略教育。大力开展安全生产法律法规知识培训，提高依法监管水平。开展煤矿、非煤矿山、危险化学品、烟花爆竹、职业卫生、应急管理等行业领域业务培训，引导广大干部树牢安全生产红线意识，练好推动安全发展本领。

（四）积极开展知识更新教育。组织引导干部学习政治、经济、文化、社会、生态和历史、科技、法律等方面的知识，开展与安全生产工作密切相关的新知识新技能培训，帮助广大干部拓宽眼界思路、优化知识结构、提高科学人文素养。

**三、**重点培训对象及措施

（一）党政领导干部。以理论武装、党性教育和能力提升为重点，加强各级领导干部特别是党政主要负责人的培训。

主要措施：（1）省部级领导干部。认真按照中央组织部《2013-2017年省部级在职领导干部脱产学习进修计划》安排，做好省部级干部到中央党校等院校参加理论培训的协调保障工作。采取集中学习研讨和个人自学相结合的方式，组织好国家安全监管总局党组中心组理论学习。（2）司局级领导干部。国家安全监管总局每年选调30名左右司局级领导干部到中央党校等院校参加理论培训；每年安排50名左右司局级干部到中央党校等七所高校参加干部选学。每年安排20名左右省级煤矿安监局党政负责人参加专题研究班。（3）地方领导干部。国家安全监管总局每年举办1期市（地）领导干部安全生产专题研究班；定期开展煤矿、金属非金属矿山、危险化学品、烟花爆竹安全生产重点县（市、区）党政领导干部安全生产专题培训。

各级党组（党委）中心组集中理论学习安排，每季度不少于1次。

（二）国家安全监管总局和国家煤矿安监局机关各司局、应急指挥中心（以下统称机关各司局）及省级煤矿安监局（含所属监察分局）干部。以加强思想政治建设和业务能力建设为重点，加强机关干部的培训。

主要措施：国家安全监管总局每年举办2期党校处级干部理论进修班、2期煤矿安全监察分局负责人专题研究班、1期新入职人员岗前培训班。定期举办处级干部任职培训班、重点岗位业务培训班。推进中青年干部轮岗交流，适当开展中青年干部跨部门轮岗交流和基层挂职锻炼。

各省级煤矿安监局商驻地党委组织部门，安排一定比例局处级干部参加省级干部教育培训机构学习培训；按时上报年度干部教育培训计划，抓好本单位党政干部的理论教育和业务培训工作，指导煤矿安全监察分局干部教育培训工作。

机关各司局、各省级煤矿安监局机关集中理论学习安排，每季度不少于2次。

（三）直属事业单位干部。以加强思想政治建设、提高创新能力和服务保障水平为重点，加强直属事业单位干部特别是专业技术人员的培训。

主要措施：国家安全监管总局每年选派高层次人才参加国家专业技术人才知识更新工程等高级研修项目；组织开展注册安全工程师、安全评价师等职业化人员的继续教育培训。

各省级煤矿安监局抓好本级直属事业单位干部的教育培训工作，积极推荐专业技术人员参加在职攻读学位和继续教育。

各直属事业单位统筹制定本单位年度教育培训计划，自行安排理论教育和业务培训时间。

（四）地方安全监管部门干部。以强化红线意识、提高安全监管能力为重点，加强地方安全监管部门干部的培训。

主要措施：国家安全监管总局每年举办2期省级安全监管局负责人、2期市（地）安全监管局负责人专题研讨班。分行业举办安全监管执法资格和专题业务培训班；开展基层执法人员示范培训。

各省级安全监管局按照分级培训原则，加强县、乡两级地方政府分管领导干部安全生产专题培训，组织开展本地区安全监管部门干部的业务培训，突出抓好基层执法人员培训。

**四、**培训能力建设

（一）健全培训需求调研制度。准确把握组织需求、岗位需求和干部需求，健全以需求为导向的培训计划生成机制。严格执行干部培训办班计划申报制度，改进培训班次设置。建立健全以组织调训为主、干部选学为辅的参训机制，对主要领导干部、重点岗位干部和新任职干部有计划地安排调训，实行点名调训。

（二）完善学习培训考核评价机制。健全干部培训登记、考核、跟踪管理等制度。把干部教育培训工作情况作为各级领导班子和干部年度考核的重要内容。建立干部年度理论学习考试制度，年度理论学习考试成绩未达到优秀的，年度考核不得确定为优秀。制定干部教育培训质量评估办法，实行重点班次班主任跟班制度，持续提升干部培训质量。

（三）加强教材、师资和演练基地建设。进一步完善安全监管监察干部培训大纲，编写安全监管监察干部理论学习读本，按类别编制干部学习培训教材。定期开展教师讲课大赛、课件评比大赛。加强师资队伍建设，探索建立领导干部上讲台制度，注重从优秀领导干部、专家学者、先进模范人物、优秀基层干部中选聘兼职教师，积极构建素质优良、专兼结合的干部教育培训师资库。加强国家安全监管监察执法综合实训基地、应急救援培训演练基地和干部教育培训基地建设。

（四）加快干部网络学院建设。加快建设安全监管干部网络学院和煤矿安全监察干部网络学院。建立健全干部培训电子档案。开发安全生产网络视频课程，建立健全数字图书资料库。积极拓展网络培训，完善干部网络在线学习培训机制，逐步推行网上自主选学。分类探索利用手机平台进行网络在线学习。全面推进安全培训信息管理平台建设。

（五）加强学风建设。弘扬理论联系实际的马克思主义学风，注重理论教育与党性锻炼相结合、课堂教学与安全生产实践相结合。全面贯彻落实中央组织部《关于在干部教育培训中进一步加强学员管理的规定》（中组发〔2013〕8号），建立学风建设监督检查制度，严格学员管理制度。把学风情况纳入干部培训考核评价体系，作为衡量干部作风的重要依据，作为评估培训机构办学质量的重要指标。

**五、**组织领导

各级安全监管监察部门和有关单位要高度重视，加强组织领导，把干部教育培训工作摆上重要位置，列入党组（党委、党总支、党支部）工作重要内容。各级领导干部特别是党政主要负责同志要带头学、亲自抓，加强调查研究，及时解决干部教育培训工作中的困难和问题。

国家安全监管总局将对本意见的贯彻落实情况进行督促指导，各级安全监管监察部门要对本地区本单位干部教育培训工作进行检查评估，确保各项任务扎实推进、取得实效。
