# 环境保护部关于印发江河湖泊生态环境保护系列技术指南的通知

环办[2014]111号

各省、自治区、直辖市环境保护厅（局）：

为贯彻落实党中央、国务院“让江河湖泊休养生息”和十八大以及十八届三中全会关于“生态文明建设”的战略部署，加快对水质较好湖泊（含水库，下同）的保护，避免众多水质较好湖泊走“先污染、后治理”的老路，环境保护部、发展改革委、财政部印发了《水质较好湖泊生态环境保护总体规划（2013-2020年）》（以下简称《规划》）。为推进《规划》实施，指导各地开展水质较好湖泊生态环境保护工作，我部组织编制了《湖泊生态安全调查与评估技术指南（试行）》等七项技术指南。现印发给你们,请参照执行。

附件：江河湖泊生态环境保护系列技术指南（共七项）

环境保护部办公厅

2014年12月23日
