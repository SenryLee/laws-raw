# 国家新闻出版广电总局关于开展2014年全民阅读活动的通知

国家新闻出版广电总局关于开展2014年全民阅读活动的通知

（新广出发〔2014〕34号）

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，解放军总政治部宣传部新闻出版局，中央和国家机关各部委、各民主党派、各人民团体出版单位主管部门，中国出版集团公司，中国教育出版传媒集团有限公司，中国科技出版传媒集团有限公司：

开展全民阅读活动是我国构建公共文化服务体系的一项重要部署，对培育和践行社会主义核心价值观，提高国民思想道德素质和科学文化素质，建设社会主义文化强国，增强国家文化软实力，实现中华民族伟大复兴中国梦具有重要意义。国家新闻出版广电总局在多年倡导并组织开展全民阅读活动建设“书香中国”的基础上，决定在2014年继续深入开展全民阅读活动。现就有关事项通知如下。

**一、**围绕中心开展各种形式的主题读书活动。围绕学习宣传贯彻党的十八届三中全会精神、习近平总书记系列重要讲话精神、培育和践行社会主义核心价值观、中国梦宣传教育、庆祝新中国成立65周年等重大主题，推出一批优秀主题出版物。广泛开展形式多样的主题读书活动，通过主题出版物展示展销、主题演讲、中华优秀传统文化经典诵读、读书征文、知识竞赛等丰富多彩的阅读活动，激励人们为实现中华民族伟大复兴中国梦而奋斗。

**二、**充分发挥优秀出版物的引领作用。各地各部门要加强优秀出版物的推荐和引导，按照分类指导、阶梯阅读的要求，完善针对不同年龄、不同职业、不同文化水平读者的推荐机制。要继续开展“向全国青少年推荐百种优秀图书”、“向全国青少年推荐50种优秀音像电子出版物”、“向全国少年儿童推荐优秀少儿报刊”、“大众喜爱的50种图书”等优秀出版物推荐活动。各地要着力在优秀出版物的宣传推广上下功夫，组织媒体深度宣传报道，在各大书店设立专柜，开展专题展示展销活动，充分发挥优秀出版物的引领作用，引导广大群众多读书，读好书。

**三、**培育巩固一批“书香中国”活动品牌。组织开展“书香中国”系列活动，协调各方力量，努力办好具有地域特色的“读书季”、“读书月”、“读书周”、“读书节”活动，培育和巩固“书香岭南”、“书香荆楚”、“江苏读书节”、“三湘读书月”、“书香中国·上海周”、“北京阅读季”、“深圳读书月”、“苏州阅读节”等知名阅读活动品牌，将书博会、书展、书市等各种行业展会与全民阅读活动有机结合起来，吸引广大读者积极参与。要做好首届全国“书香之家”推荐活动入选家庭的宣传工作，挖掘感人故事，充分发挥阅读典型的引领示范作用。倡导有条件的地区开展“书香之乡（镇）”、“书香之县（市）”推荐活动。

**四、**面向基层开展全民阅读“七进”活动。推动基层群众阅读，传播阅读理念，培育阅读习惯，提高阅读能力，是推动全民阅读活动的重要工作。要开展“全民阅读·报刊行”活动、“全民数字阅读活动”，办好“强素质、作表率”主题读书讲坛，充分利用农家书屋、职工书屋、社区书屋、连队书屋、城乡阅报栏（屏）等平台开展各种形式的读书活动，深入推动全民阅读进农村（牧区）、进社区、进校园、进军营、进企业、进机关、进家庭，真正将全民阅读活动推广到基层群众中去。

**五、**加强全民阅读公共服务体系建设。要进一步完善全民阅读公共服务体系，加强阅读设施建设，开展全民阅读志愿服务，鼓励社会各界开展各种捐书助读活动，参与全民阅读公共服务体系建设。鼓励各地扩大政府文化资助和文化采购，探索向困难群体免费发放购书券，继续开展“文化助残公益行动”等，重点保障贫困地区留守儿童、进城务工人员子弟、残障人士等特殊困难群体的基本阅读需求。

**六、**继续推动全民阅读立法和规划工作。要继续推动《全民阅读促进条例》、《国家全民阅读中长期规划》的起草、制订工作。鼓励各地积极推动全民阅读立法工作，以地方法规的形式将全民阅读纳入法制化轨道，推动全民阅读工作常态化、制度化。各地要加强对全民阅读的规划引导，结合实际情况，研究制订当地的全民阅读中长期规划，进一步明确全民阅读的主要目标、主要任务和保障措施等。

**七、**努力营造“书香中国”浓厚氛围。充分发挥“全民阅读媒体联盟”成员单位以及各类媒体的重要作用，鼓励各类媒体办好全民阅读的专栏、专题、专版、访谈节目等，加强书评、排行榜的引导和管理，使之充分发挥积极导向作用。各地要围绕“4·23世界读书日”、“六一”国际儿童节、“十一”国庆节等重点节庆日，通过投放全民阅读公益广告等多种形式，组织新闻媒体做好宣传推广工作，各地新华书店要开展优惠售书活动，延长书店营业时间，方便读者购书。

**八、**加强对全民阅读的组织协调。要进一步建立健全全民阅读活动组织领导机构，推动设立全民阅读指导委员会。各地要协调宣传、文化、财政、教育、民政、法制等部门以及工会、共青团、妇联等人民团体，建立和完善全民阅读公共服务体系建设组织领导和协调机制，统筹服务网络建设，指导开展本地区的全民阅读工作。

各省级新闻出版广播影视管理部门要根据本通知要求，精心制订本地区2014年全民阅读活动工作方案，并认真总结2013年开展全民阅读活动的相关工作情况，于3月底前一并上报总局。总局今年将会同有关部门召开全国全民阅读工作会议，交流近年来各地各部门开展全民阅读活动的好经验、好做法，并表扬一批先进组织单位和优秀项目。

国家新闻出版广电总局

2014年3月10日
