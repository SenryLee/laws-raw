# 国家铁路局科技与法制司关于2014年青年拔尖人才支持计划申报推荐工作的通知

国家铁路局科技与法制司关于2014年青年拔尖人才支持计划申报推荐工作的通知

各有关单位：

根据《中共中央组织部办公厅等关于做好2014年青年拔尖人才支持计划申报推荐工作的通知》（组厅字〔2014〕17号）以及《科技部政策法规司关于做好2014年青年拔尖人才支持计划科技部平台申报推荐工作的补充通知》（国科政函〔2014〕13号），现将2014年青年拔尖人才支持计划人选申报推荐工作通知如下：

**一、**申报条件

具有中国国籍，申报截止日期前在企业、科研院所、部分高校（不含教育部直属高校及地方学校）等单位工作1年以上的在聘青年人才。同时应具备以下条件：

1.拥护党的路线方针政策，热爱祖国，遵纪守法，品行端正；

2.恪守学术道德和职业道德，学风正派，诚实守信；

3.在自然科学领域崭露头角，获得国际国内较高学术成就，具有较好创新发展潜力，有一定社会影响；

4.1977年1月1日以后出生；

5.一般应获博士学位；

6.已经入选国家“千人计划”、“万人计划”的青年人才不在本计划支持之列；

7.已参评过青年拔尖人才但未入选者，申报时必须有新的成果。同一申报人申报本计划不得超过2次。

**二、**有关要求

1.各单位要重视推荐开展原创性研究以及在企业从事科技成果转化和技术创新的优秀青年人才。

2.推荐人选登陆中国人才网（rencai.people.com.cn）下载申报书客户端进行填写。

3.附件材料按《关于做好2014年青年拔尖人才支持计划申报推荐工作的通知》规定顺序排列，并整合为一个PDF文件（每个不超过15M，超过分为两个及以上），并按“姓名＋附件材料”进行命名。

4.人选所在工作单位要指导申报人如实填写申报材料，认真审核把关，确保材料的真实性。

5.申报材料包括推荐函、《青年拔尖人才支持计划自然科学类申报书》及附件（一式三份）、推荐人选信息汇总表。纸质申报材料用A4纸双面打印，合并装订。

请各单位于2014年6月15日前将推荐人选材料（纸质和电子版）报送国家铁路局科技与法制司，联系电话：010-51897712。我局组织评审后，将按照推荐指标要求向科技部平台推荐。
