# 中共国家民族事务委员会党组关于常一青等3同志任职的通知

## 中共国家民族事务委员会党组关于常一青等3同志任职的通知（民党发〔2014〕21号）

中共中南民族大学委员会：

经中共国家民委党组2014年7月1日研究，并商中共湖北省委同意：

常一青同志任中南民族大学党委副书记；

杨胜才同志任中南民族大学党委常委

李俊杰同志任中南民族大学党委委员、党委常委。

中共国家民委党组

2014年7月22日
