# 国家新闻出版广电总局办公厅关于开展2014年出版物进口经营单位年检登记工作的通知

国家新闻出版广电总局办公厅关于开展2014年出版物进口经营单位年检登记工作的通知

各省、自治区、直辖市新闻出版广电局：

根据《出版管理条例》和《关于核发出版物进口经营许可证及实行年检制度的通知》（新出外[2006]1238号）有关规定，现就2014年出版物进口经营单位年检工作的有关事项通知如下：

**一、**年检内容

（一）按照《出版管理条例》中设立出版物进口经营单位的条件逐一对照检查。

（二）出版物进口经营单位要上报上一年度1月1日至12月31日的经营状况报告。报告内容包括：一年来的进出口经营状况数字统计，包括种数（种次）、数量（册、张、份、盒）、金额（万美元）等；是否建立健全进口出版物内容三级审查制度；是否在规定时间内向所在地省级新闻出版广电行政部门或新闻出版广电总局上报备案进口出版物目录；是否未经批准在境内举办境外出版物展览；是否进口过含有《出版管理条例》禁载内容的出版物；是否将含有禁载内容的进口出版物供货给零售市场；是否超范围经营等。

（三）总结检查一年来是否有其他违反国家法律、法规及各项管理规定的行为，经营活动中有无被处罚记录。

如存在上述问题应及时查找原因，制订整改措施。

**二、**年检程序

（一）各出版物进口经营单位（包括各出版物进口经营单位的子公司）要按照通知要求认真进行自查，写出年度总结，填写所附年检登记表，于9月22日前将总结报告及年检登记表报所在地新闻出版行政部门。各省（区、市）新闻出版广电行政部门对上述材料进行审核后，写出审核意见，连同各出版物进口经营单位的总结报告、年检登记表、年检情况汇总表于10月13日前报送总局。年检登记表一式三份，一份报我局，其余二份分别由省级新闻出版广电行政部门和各出版物进口经营单位存档。在各地有分公司的出版物进口经营单位，其分公司须于9月12日前将年检材料报到所在地新闻出版行政部门，所在地新闻出版广电行政部门对上述材料进行审核后，写出审核意见，再由分公司将审核意见、本公司的总结报告、年检登记表等年检材料报到总公司，总公司将年检材料汇总后于9月22日前统一报所在地新闻出版广电行政部门进行年检。

（二）总局收到上报的年检材料后，予以审核批复。通过年检的出版物进口经营单位持总局批复件及经营许可证副本到总局进口管理司加盖年度检验章。盖章之后，出版物进口经营许可证方可继续使用。

**三、**年检结果的处理

（一）出版物进口经营单位在年检过程中，如发现有违反《出版管理条例》的，将依法对其进行处罚。

（二）出版物进口经营单位有下列问题之一的，将视情节轻重予以警告、暂缓年检，或不予通过年检等处理：

1. 不具备设立出版物进口经营单位基本条件的；

2. 未设立进口出版物内容三级审查制度的；

3. 将含有禁载内容的进口出版物供货给零售市场的；

4. 超范围经营或一年未从事出版物进口经营业务的；

5. 对违规行为隐瞒不报的；

6. 违法行为被查处后拒不改正或者没有明显整改效果的；

7. 未在规定时间内递交总结报告和年检登记表的；

8. 存在其他违反法律、法规和各项管理规定的。

（三）受到警告或暂缓年检的出版物进口经营单位应认真进行整改，暂缓年检期间不得开展出版物进口经营活动。暂缓年检的期限由新闻出版广电总局确定，一般不超过6个月。6个月内问题解决的，按照本通知规定重新办理年度检验，通过年检后在其出版物经营许可证副本上加盖年度检验章。如6个月内问题仍未解决，将注销其出版物进口经营许可证。

（四）不予通过年检的出版物进口经营单位由新闻出版广电总局注销其出版物进口经营许可证，被注销出版物进口经营许可证的出版物进口经营单位不得再从事出版物进口经营业务。

**四、**时间要求

自本通知发布之日起，开始出版物进口经营单位年检工作。各省（区、市）新闻出版广电行政部门于2014年10月13日前将本省（区、市）出版物进口经营单位2013年度进口经营状况的总结报告、年检登记表、年检情况汇总表（年检登记表和年检情况汇总表可登陆新闻出版广电总局网站http：//www.gapp.gov.cn/ -门户网通知公告栏目下载）报送总局。

请各省（区、市）新闻出版广电行政部门将此通知转发到本行政区域内的各出版物进口经营单位。
