# 国家工商总局商标局关于在2014年亚太经济合作组织会议期间调休放假的通告

根据国务院批准、北京市政府发布的《关于在2014年亚太经济合作组织会议期间调休放假的通告》和国家工商总局办公厅《关于在2014年亚太经济合作组织会议期间调休放假的通知》要求，我局将于11月7日至11月12日调休放假（共6天）。在此期间，我局商标注册大厅、驻中关村办事处商标申请受理窗口和商标注册网上申请暂停办理业务。11月2日（星期日）、15日（星期六）正常上班并办理业务，商标注册网上申请正常开放。

特此通告。

国家工商总局商标局

2014年10月31日
