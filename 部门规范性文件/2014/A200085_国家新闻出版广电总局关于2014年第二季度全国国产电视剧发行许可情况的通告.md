# 国家新闻出版广电总局关于2014年第二季度全国国产电视剧发行许可情况的通告

国家新闻出版广电总局关于2014年第二季度全国国产电视剧发行许可情况的通告

（通告[2014]8号）

根据国家电视剧内容管理的有关规定，现将总局及各省级广播影视行政部门2014年第二季度全国《国产电视剧发行许可证》颁发统计情况予以通告。

2014年4-6月，全国各类电视剧制作机构共计生产完成并获准发行国产电视剧115部4118集，题材比例情况如下：

现实题材剧目共计68部2268集，分别占总比例的59.13%、55.08%。其中，当代题材共计67部2232集，分别占总部、集数的58.26%、54.20%；现代题材共计1部36集，分别占总部、集数的0.87%、0.87%。

历史题材剧目共计45部1798集，分别占总比例的39.13%、43.66%。其中，近代题材共计36部1451集，分别占总部、集数的31.30%、35.24%；古代题材共计9部347集，分别占总部、集数的7.83%、8.43%。

重大题材共计2部52集，分别占总部、集数的1.74%、1.26%。其中，重大革命2部52集。
