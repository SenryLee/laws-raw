# 工业和信息化部公告2014年第28号――车辆生产企业及产品(第259批)

## 工业和信息化部公告（2014年第28号）

根据《中华人民共和国行政许可法》和《国务院对确需保留的行政审批项目设定行政许可的决定》的规定，现将许可的汽车、摩托车、三轮汽车和低速货车生产企业及产品（第259批）和《节能与新能源汽车示范推广应用工程推荐车型目录》（第56批）予以公告。

附件：车辆生产企业及产品（第259批）（略）

2014年4月14日
