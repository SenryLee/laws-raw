# 全国打击非法行医专项行动领导小组办公室关于进一步做好宣传工作的通知

全国打击非法行医专项行动领导小组办公室关于进一步做好宣传工作的通知

（打非专项行动办函〔2014〕6号）

各省、自治区、直辖市及新疆生产建设兵团打击非法行医专项行动领导小组办公室：

全国进一步整顿医疗秩序打击非法行医专项行动（以下简称“专项行动”）启动以来，各地区积极利用各种媒体，采取多种形式，积极开展宣传工作，为专项行动营造了良好的社会氛围。为进一步增强群众对非法行医的辨识能力，我办组织制作了动画片、海报和折页等一批宣传材料（电子版见国家卫生计生委官方网站专项行动专题区），包括打击无证行医、“两非”、非法医疗美容、医托、非法义诊、违规医疗广告等内容。请各地充分利用宣传材料，按照《关于做好进一步整顿医疗秩序打击非法行医专项行动深入巩固阶段工作的通知》（国卫办监督发〔2014〕16号）要求，结合本地区实际，针对不同区域、不同人群，创新形式，继续深入开展宣传工作，形成对非法行医群防群控的有利局面。
