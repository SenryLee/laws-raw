# 国家安全生产监督管理总局公告2014年第18号――甲级资质安全评价机构变更名称表

国家安全生产监督管理总局公告

（2014年第18号）

按照《国家安全监管总局关于进一步规范安全评价机构监管工作的通知》（安监总规划〔2013〕79号）要求，中国职业安全健康协会、福建省安全生产科学研究院、陕西省安全生产科学技术中心、云南省安全生产评价检测中心等4家事业单位（协会）已单独注册成立企业法人，完成安全评价业务脱钩剥离等工作。经原单位申请，由所在省级安全监管局审核推荐，同意该4家机构变更名称等事项，现予以公告（详见附件）。评价机构名称变更后，其从业范围保持不变，资质有效期至2015年12月底。
