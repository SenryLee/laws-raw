# 工业和信息化部办公厅关于开展2014年通信建设安全生产月活动的通知

## 工业和信息化部办公厅关于开展2014年通信建设安全生产月活动的通知（工信厅通函〔2014〕299号）

各省、自治区、直辖市通信管理局，中国电信集团公司、中国移动通信集团公司、中国联合网络通信集团有限公司，相关单位：

为贯彻落实《国务院安委会办公室关于开展2014年全国“安全生产月”和 “安全生产万里行”活动的通知》（安委办〔2014〕7号），定于2014年6月1日至30日在通信建设领域开展“安全生产月”活动。现将有关事项通知如下：

**一、**总体目标

以党的十八大和十八届三中全会精神为指导，以宣传贯彻习近平总书记关于安全生产系列重要讲话精神、大力实施安全发展战略为主线，以“强化红线意识、促进安全发展”为主题，以普及安全生产法律法规、落实安全生产责任、加强隐患排查治理、推进安全生产状况持续稳定好转为目标，紧密结合通信建设工程安全生产实际，精心组织，周密安排，营造积极参与“安全生产月”和 “安全生产万里行”活动的良好氛围，有效防范和坚决遏制通信建设领域安全生产事故的发生。

**二、**活动内容

（一）开展安全生产宣传活动。宣传贯彻习近平总书记关于安全生产系列重要讲话精神，深入学习《安全生产法》、《建设工程安全生产管理条例》等法律法规以及《通信建设工程安全生产操作规范》（YD 5201-2014）等。

（二）开展安全生产事故警示教育活动。组织观看警示教育片《盲洞·迷途》、《生产安全事故典型案例盘点（2014版）》以及《通信线路工程人孔作业施工安全操作》宣传片等，对典型事故进行剖析，深刻吸取教训，用事故教训推动企业落实责任、完善措施，防范同类事故发生，全面提高从业人员安全生产意识。

（三）开展安全应急预案演练活动。围绕通信建设工程安全生产事故易发多发环节，组织开展一次实质性的预案应急演练，要立足实际，突出重点，制定完善应急预案，提高预案的实用性和可操作性，更好地普及安全生产应急常识。

（四）深化“打非治违”行动。针对近几年安全生产事故特点，结合2013年安全生产检查发现的突出问题和事故隐患，持续开展通信建设领域“打非治违”行动，坚决纠正违规违章作业行为，及时曝光非法违法建设行为，有效防范和坚决遏制非法违规行为导致的安全生产事故，切实维护人民群众生命财产安全。

**三、**工作要求

各单位要把“安全生产月”活动与安全生产管理工作紧密结合起来，统筹安排，上下联动、统一步调，结合通信建设工程特点，开展各具特色、形式新颖、内容丰富的宣传活动，充分发动主流媒体参与安全生产宣传报道，发挥好微博、微信、手机报等新媒体作用，加强舆论监督，扩大宣传声势，形成更加有利于安全生产的浓厚氛围。

各省（区、市）通信管理局要加强领导，认真做好“安全生产月”活动的组织工作，强化宣传引导，着力提高全行业的安全生产意识，结合通信工程质量安全生产检查工作，指导和督促有关企业落实安全生产责任，确保活动取得实效。7月10日前将本地区开展活动的总结报部（通信发展司）。

各相关单位要高度重视，精心筹划，细化分工，落实责任，做到每项活动责任到人、措施到位，确保活动顺利开展。各电信企业集团公司于7月10日前将集团公司开展活动的总结报部（通信发展司）。
