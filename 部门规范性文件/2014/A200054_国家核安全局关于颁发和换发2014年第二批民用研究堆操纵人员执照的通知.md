# 国家核安全局关于颁发和换发2014年第二批民用研究堆操纵人员执照的通知

## 国家核安全局关于颁发和换发2014年第二批民用研究堆操纵人员执照的通知（国核安发[2014]170号）

国防科工局：

根据《民用核设施安全监督管理条例》及其实施细则有关规定，我局对清华大学核能与新能源技术研究院民用核设施操纵人员执照考核进行了监督，对执照申请文件进行了审核，结合你局的审查意见，认为朱江等53人具备了民用核设施操纵人员资格，批准颁发民用研究堆操纵人员执照（基本信息见附件1）；认为姚伟满足换发执照条件，批准换发民用研究堆操纵人员执照（基本信息见附件2）。

请相关核设施营运单位按规定程序于2014年8月31日前到我局领取执照。
