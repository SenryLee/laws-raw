# 商务部公告2014年第61号——决定准予浙江物产港洲石化有限公司等成品油批发经营许可

## 中华人民共和国商务部公告

2014年第61号

依据《行政许可法》、《原油市场管理办法》、《成品油市场管理办法》的有关规定，经审核，决定准予浙江物产港洲石化有限公司、德州国力化工科技有限公司、黑龙江哈铁对外经贸公司、天津江东建材有限公司、中海油湖南销售有限公司、宁夏东来能源化工有限责任公司、山东玉皇盛世化工销售有限公司、河北新启元能源销售有限公司、中国石油化工股份有限公司北京延庆康庄油库、包头市天蒙石油有限公司成品油批发经营许可。

注销上海华东中油销售有限公司大连保税区分公司、河南省柏庄石油储运股份有限公司、开封宏达中油销售有限公司、宁夏宝能实业有限公司成品油批发经营许可。

注销大连添羽商贸有限公司、大连环海石油仓储有限公司、大连旅顺船务总公司、中国石油天然气股份有限公司大连开发区油气销售分公司、岳阳和诚石油化工有限公司成品油仓储经营许可。

商务部

2014年8月22日
