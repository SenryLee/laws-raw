# 中国地震局关于地震安全性评价执业资格核准行政审批取消后相关事务移交中国灾害防御协会的通知

中国地震局关于地震安全性评价执业资格核准行政审批取消后相关事务移交中国灾害防御协会的通知

(中震函[2014]38号)

中国灾害防御协会：

根据《国务院关于取消和下放一批行政审批项目的决定》（国发〔2013〕44号），中国地震局实施的“地震安全性评价执业资格核准”行政审批已取消。经研究决定，该项行政审批事项取消后相关工作移交你协会办理，现将有关事项通知如下：

**一、**一级地震安全性评价工程师注册工作

由你协会负责一级地震安全性评价工程师注册、变更、延续、注销等工作。一级地震安全性评价工程师注册证书和执业印章由你协会发放。一级地震安全性评价工程师注册信息应及时报送中国地震局。

相关工作的管理办法在中国地震局和人社部对原有管理规定修订完成前，参照《地震安全性评价工程师制度暂行规定》（国人部发〔2005〕72号）、《一级地震安全性评价工程师注册实施办法》（中震防发〔2008〕153号）执行。文件条款执行主体为中国地震局的改由你协会执行。

**二、**一级、二级地震安全性评价工程师继续教育工作

由你协会负责一级、二级地震安全性评价工程师继续教育年度计划制定、组织实施、充抵学分认定等工作。

相关工作的管理办法在中国地震局和人社部对原有管理规定修订完成前，参照《地震安全性评价工程师制度暂行规定》（国人部发〔2005〕72号）、《地震安全性评价工程师继续教育管理办法（试行）》（中震防发〔2012〕56号）执行。

**三、**一级地震安全性评价工程师执业资格考试

经与人社部相关部门沟通，“地震安全性评价执业资格核准”行政审批取消后，资格考试的组织部门和考试方式等相关问题需在相关管理规定修订明确后移交，2014年资格考试仍沿用原有的组织形式，即人社部和中国地震局共同组织考试，公布通过人员名单。

请你协会按照通知要求，做好相关转移接续工作和继续教育工作，认真履行职责，加强管理，保证地震安全性评价工程师制度的顺利平稳过渡。

特此通知。

中国地震局

2014年3月11日
