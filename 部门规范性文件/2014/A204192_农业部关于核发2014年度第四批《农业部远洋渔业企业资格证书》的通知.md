# 农业部关于核发2014年度第四批《农业部远洋渔业企业资格证书》的通知

## 农业部关于核发2014年度第四批《农业部远洋渔业企业资格证书》的通知（农渔发[2014]19号）

根据《远洋渔业管理规定》，我部同意授予中渔环球海洋食品有限责任公司、大连海陆丰远洋渔业开发有限公司、威海市恒源渔业有限公司、福建万通渔业有限公司、福建世海渔业有限公司、广州市华宇远洋渔业有限公司、湛江外海实业有限公司共7家企业2014年度农业部远洋渔业企业资格（第四批），并核发《农业部远洋渔业企业资格证书》。请你单位收到上述《农业部远洋渔业企业资格证书》后，及时发放到有关远洋渔业企业。

农业部

2014年4月15日
