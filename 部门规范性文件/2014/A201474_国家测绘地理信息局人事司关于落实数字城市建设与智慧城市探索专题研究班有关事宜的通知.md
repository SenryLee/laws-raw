# 国家测绘地理信息局人事司关于落实数字城市建设与智慧城市探索专题研究班有关事宜的通知

## 国家测绘地理信息局人事司关于落实数字城市建设与智慧城市探索专题研究班有关事宜的通知（测人函〔2014〕45号）

有关省、自治区、直辖市、新疆生产建设兵团党委组织部：

按照中央组织部《关于印发〈2014年中央组织部委托中央和国家机关有关部委举办地方党政领导干部专题研究班计划〉的通知》（组通字〔2014〕4号，附件1）要求，现将由我局承办的数字城市建设与智慧城市探索专题研究班有关事宜通知如下：

**一、**时间地点

时间：2014年9月15日至19日（周一至周五）。

地点：广东省广州市。

**二、**主要内容

深入学习贯彻党的十八大、十八届三中全会和习近平总书记系列讲话精神，以李克强总理视察中国测绘创新基地时的讲话为指导，推动《国务院办公厅关于促进地理信息产业发展的意见》贯彻落实，推进数字城市建设和应用，开展智慧城市探索，促进地方测绘地理信息事业加快发展，为经济社会发展提供更好的服务。

**三、**参训人员

按照中央组织部通知要求，请相关省（区、市）抽调1名市（地、州、盟）政府分管测绘地理信息工作的副市长（专员、州长、盟长）参加，新疆生产建设兵团抽调1名师市分管测绘地理信息工作的领导干部参加，具体名额分配见附件1。

**四、**学员选派

请相关省（区、市）、新疆生产建设兵团党委组织部尽快确定参加人员，填写《数字城市建设与智慧城市探索专题研究班报名回执》（附件2），并于2014年8月1日（星期五）前传真至国家测绘地理信息局人事司。

根据中央组织部干部教育局要求，参训学员不带随员。

**五、**学员报到

报到时间：2014年9月14日（星期日）。

具体报到地点及接站等其他事宜另行通知。
