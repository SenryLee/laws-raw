# 科学技术部办公厅关于印发《国家文化科技创新工程西部行动方案》的通知

## 科学技术部办公厅关于印发《国家文化科技创新工程西部行动方案》的通知（国科办高〔2014〕38号）

有关省、自治区、直辖市科技厅（委），新疆生产建设兵团科技局：

为充分发挥西部地区文化资源优势，加强西部区域间协同以及与东部科技、人才、金融等优势资源的对接，强化科技支撑和商业模式创新，推动西部地区文化产业发展，提升文化产业竞争力，促进西部地区转型升级发展，科技部会同有关部门，组织编制了《国家文化科技创新工程西部行动方案》。现将行动方案印发你们，请结合本地区实际情况，组织做好落实工作，并将组织落实情况于每年年底前以书面形式报送科技部高新司。

科技部办公厅

2014年7月8日

国家文化科技创新工程西部行动方案

根据《国家文化科技创新工程纲要》，为充分发挥西部文化资源优势，推进西部地区传统文化产业提升和新兴文化业态发展，促进西部地区转型升级，科技部拟联合有关部门和西部地区，依托国家文化科技创新工程，组织实施国家文化科技创新工程西部行动，特制定行动方案如下。

**一、**背景与意义

当前，国际文化和科技融合呈现加速发展态势，发达国家文化产业持续高速增长，已经成为推动经济发展、提升产业竞争力和国际影响力的重要引擎。中央高度重视文化与科技的融合发展，党的十八大和十七届六中全会都明确提出，要加强文化科技创新，促进文化与科技融合，推动文化产业成为国民经济支柱性产业。2012年5月，科技部、中央宣传部会同有关部门，启动实施了国家文化科技创新工程，从政策支持、基地建设、项目支撑、创新体系建设等多个方面，推动文化和科技融合，有力地促进了文化产业的发展，以科技引领的新兴文化业态发展势头强劲，成为推动地区经济发展和结构转型的重要动力。

我国西部地区幅员辽阔、文化资源丰富，具有发展文化产业的良好基础条件和巨大的市场空间。近年来，西部地区大力发展文化产业，2012年实现文化产业增加值3149.2亿元，占地区生产总值（GDP）比重达到2.76%。但与其他地区相比，西部地区在文化科技创新、文化资源挖掘和开发利用、新兴文化业态发展等方面还存在较大差距，制约着文化产业的发展和新兴文化消费市场的形成。当前，我国正处于实施创新驱动发展战略的关键时期，科技创新成为推动地区经济发展的关键支撑。充分发挥西部文化资源优势，实施文化科技创新工程西部行动，加强文化和科技融合，创新文化产业发展模式，将西部资源优势转变为产业优势，对于西部地区突破资源、环境等重大瓶颈制约，实现经济的跨越发展，探索创新驱动发展的新路径，具有重大意义。

**二、**指导思想和基本原则

（一）指导思想。

深入贯彻落实党的十八大和十七届六中全会精神，实施创新驱动发展战略，以国家文化科技创新工程为依托，充分发挥西部文化资源优势，加强西部区域间协同以及与东部科技、人才、金融等优势资源的联合，强化科技支撑和商业模式创新，推动西部地区文化产业发展，提升文化产业竞争力，促进西部地区转型升级发展。

（二）基本原则。

市场拉动、企业主体。强化需求导向和市场意识，充分发挥市场在文化科技创新资源配置中的积极作用。强化资源整合，加强产学研合作，充分发挥企业在文化产业发展和科技创新中的主体地位。

科技支撑、模式创新。充分运用现代科技手段，通过技术集成创新，强化对西部地区文化产业发展的支撑。积极推动模式创新，培育西部文化产业新业态。

区域协同、东西合作。按照文化资源禀赋和文化产业发展的内在规律，加强整体布局和区域间协同。加强与东部地区的合作，实现协同发展、互利共赢。

因地制宜，突出特色。结合区域文化资源和产业发展条件，聚焦重点，突出特色，因地制宜，形成充满活力、各具特色、优势互补的西部文化产业发展大格局。

**三、**总体目标和主要任务

（一）总体目标。

在国家文化科技创新工程的总体框架下，充分挖掘和利用西部地区特色文化资源，加强文化和科技融合，创新西部文化产业发展模式，提升西部传统文化产业发展水平，培育建立西部文化产业新兴业态。加强西部文化产业集聚发展，优化文化产业布局，培育若干科技含量高、特色鲜明的文化产业集群、产业带或产业圈。完善文化科技创新体系，提升文化科技创新能力。提升西部文化产业国际化水平，推动西部文化产业走出去。

--到2020年，西部特色文化产业得到快速发展，培育一批科技含量高的龙头文化企业和文化品牌，西部地区文化产业增加值占GDP比重明显提升，成为区域经济重要产业。

--在西部地区建设15家以上国家级文化和科技融合示范基地，基本形成以西部丝绸之路文化带、青藏高原文化带、西南少数民族文化走廊为主线，以西部中心城市特色文化产业圈为重点的西部特色文化产业集群发展格局。

--文化科技创新能力大幅提升，文化领域高新技术企业数量明显增加，文化科技企业拥有的专利数平均达5件以上，科技对文化产业的贡献率超过55%。

--文化科技创新体系不断完善，建立15个以上文化产业公共技术服务平台和一批文化科技金融服务平台，培育20个以上特色文化科技产业联盟，建立若干文化类大学科技园，建设一批文化类的专业孵化器和生产力促进中心，建立一批东西部合作的文化科技融合创新中心，培育一批文化科技创新团队和领军人才。

（二）主要任务。

1. 充分利用数字化技术，促进西部文化资源的深度挖掘和利用。

充分挖掘西部地区丰富的民族民间传统文化和特色文化资源，研究制定西部文化资源知识体系和数字化通用技术标准规范，研究民族文化资源基因库的提取、分类、信息标注和检索等技术，构建西部民族文化资源基因库，促进文化资源整合和共享。强化文化资源的开发利用，基于大数据分析、虚拟现实等现代网络信息和数字化技术手段，开展文化资源信息集成、工艺再造等技术集成应用，提升民族语言文字的信息化应用，促进民族音乐资源和衍生产品开发运营，提高民族文化资源数字典藏的体验和推广水平。

2. 积极应用移动互联网及数字多媒体技术，提升西部文化旅游的市场吸引力和运营管理水平。

加强文化、科技、旅游、商业等多种业态有机融合，结合西部旅游资源和文化旅游产业发展特色，充分利用地理信息位置服务、电子商务综合服务和O2O模式（线上和线下）、数字多媒体等相关技术、装备与模式，全面提升客户消费新业态，建设一批规范化、专业化、国际化并具有西部特色的示范项目，推动数字文化旅游、主题文化乐园、文化实景互动展演等特色文化产业规模化、专业化发展，推动西部文化旅游，从浅表式的观光向休闲度假、互动体验式转化，做大做强西部文化旅游产业。

3. 加强模式创新和技术集成创新，培育西部中心城市文化新业态。

适应现代网络经济转型发展新趋势，充分发挥西部中心城市的人文和科教优势，加强技术集成创新与新型商业模式的有机融合，培育发展创意设计、移动游戏、数字化音乐、网络影视与数字娱乐、网络化学习与数字出版、现代演艺等新兴网络文化服务产业，通过文化展览与文化演艺交叉融合创新模式，提升文化体验与都市文化消费新业态，提高西部文化产业核心竞争力。

4. 加强西部文化科技产业载体建设，优化西部文化科技产业布局。

以西部丝绸之路文化带和西南少数民族文化走廊为纽带，以西部大中城市文化产业圈为中心，加强区域协调与联动，结合区域文化产业发展独特优势和发展特点，建设一批国家级文化和科技融合示范基地，打造一批科技含量高、公共服务能力强、特色鲜明、优势互补的文化科技产业集群，优化西部文化科技产业布局。

5. 加强文化科技创新体系建设，优化文化科技创新环境。

加强文化和科技的有机融合，积极推动东西部联合成立重点领域文化科技产业技术创新战略联盟，合作建立文化科技融合创新中心，建立一批文化类大学科技园、专业孵化器和生产力促进中心，培育一批创新团队和人才，整合资源，为西部文化产业发展提供共性关键技术和系统集成解决方案、商业模式推广与运营、战略咨询、标准制定、行业培训、人才培养等科技服务。

6. 加强国际合作，推动西部文化产业走出去。

充分利用“丝绸之路经济带”和“海上丝绸之路”建设的有利契机，支持西部地区积极开展文化科技国际合作，在人才、技术、资金、项目、市场等方面加强与国外的合作与交流，充分利用国际市场和资源，推动西部文化产业走出去。

**四、**保障措施

1. 加强组织领导，发挥各级政府的引导作用。科技部会同有关部门和地方，成立西部行动领导协调小组，形成合力，加强对整个行动的指导。各地要完善工作机制，开展战略研究，明确本地科技支撑文化产业发展的发展目标、重点任务和政策措施。

2. 采取有力措施，加强对西部行动计划的支持。科技部将利用国家文化科技创新工程及其他科技计划或专项，加强对西部行动计划的支持。有关部门也要整合资源，加强对西部行动的支持力度。各级地方政府要采取有效措施，加强对西部行动有关任务承担主体的支持。

3. 加强区域合作，促进东西部文化科技的强强联合。支持西部地区有关地方加强区域合作，围绕文化产业集群、产业带或产业圈的发展，加强资源、技术、人才、资金等方面的合作与交流，互为支持，共谋发展。支持和鼓励西部地区文化科技领域企业、高校和研究院所加强与东部的合作，促进东部地区技术、人才、资金、管理等优势与西部地区文化资源优势的强强联合，充分利用全国资源，促进西部地区文化产业发展。
