# 国家知识产权局办公室关于调整2014年全国专利代理人资格考试北京地区考场地点的通知

北京地区考生：

根据《北京市人民政府关于在2014年亚太经济合作组织会议期间调休放假的通告》（京政发〔2014〕32号）的安排，需要对专利代理人资格考试北京地区考场地点的既定安排进行调整。现就有关事宜通知如下：

**一、**11月1日，专利法律知识、相关法律知识科目的考试按照原定考场设置，在北京科技大学和中华女子学院举行。请北京地区考生按照准考证副证上确定的学校地点按时前往相应考场参加考试。

**二、**11月2日，专利代理实务科目的考试不能在原定的北京科技大学和中华女子学院考场举行，调整到北京市海淀区教育培训学校、北京电大开放教育学院（西直门校区）、北京广播电视大学北校区、北京市现代商务培训中心（团结湖大厦）、北京市汽车职业技术培训中心（北京汽车工程学院）、北京房地产职工大学（劲松校区）和北京化工大学举行。

**三、**请北京地区全体考生即日起登录国家知识产权局网站“专利代理人资格考试报名系统”，重新打印本人准考证副证，按照准考证副证上面确定的学校地点，按时前往调整后的考场参加考试。

**四、**请北京地区考生密切关注近期国家知识产权局网站“专利代理人资格考试”专栏、北京市知识产权局网站相关通知，通过查询“考场调整对照表”确定本人专利代理实务科目考试的考场对应具体教室，确保按照调整后的考场安排参加考试。

11月2日考试当天，应当合理安排出行时间和路线，确保能够准时参加考试。请广大考生互相转告。

特此通知。

国家知识产权局办公室

2014年10月21日
