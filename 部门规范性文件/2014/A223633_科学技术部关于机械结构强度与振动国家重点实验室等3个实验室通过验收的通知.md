# 科学技术部关于机械结构强度与振动国家重点实验室等3个实验室通过验收的通知

国科函基〔2014〕244号

教育部：

按照《国家重点实验室建设与运行管理办法》（国科发基[2008]539号）的要求，2014年8至12月科技部对“机械结构强度与振动”等3个实验室的建设计划完成情况分别组织专家进行现场验收。验收专家组认为，这些实验室在凝练研究方向、条件建设、队伍建设、运行管理和制度建设、开展科学研究等方面做了大量工作，取得了重要进展，完成了建设计划任务书规定的各项指标，符合国家重点实验室总体要求，能按照相应的管理办法正常运行。科技部对验收专家组的意见进行了认真研究，决定批准这3个实验室通过验收（名单见附件）。

希望上述3个国家重点实验室根据《国家重点实验室建设与运行管理办法》的要求，结合验收专家组提出的建议，完善实验室的运行管理，明确定位，突出创新，注重研究成果的水平与国际学术影响，加强合作研究与青年骨干人才培养，重视开放共享，努力在出成果、出人才等方面取得新的进展，带动本领域学科发展。请主管部门和依托单位继续大力支持国家重点实验室的工作，为实验室的发展创造良好的环境和条件。

附件：通过验收的3个国家重点实验室名单

科 技 部

2014年12月29日
