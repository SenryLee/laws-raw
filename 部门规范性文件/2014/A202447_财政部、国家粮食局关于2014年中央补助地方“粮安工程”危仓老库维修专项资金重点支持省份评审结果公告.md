# 财政部、国家粮食局关于2014年中央补助地方“粮安工程”危仓老库维修专项资金重点支持省份评审结果公告

财政部、国家粮食局关于2014年中央补助地方“粮安工程”危仓老库维修专项资金重点支持省份评审结果公告

按照《财政部 国家粮食局关于启动2014年“粮安工程”危仓老库维修改造工作的通知》（财建[2014]100号）有关要求，2014年5月29日，经财政部、国家粮食局共同组织专家评审，河南、安徽、湖北、山东、四川、吉林、内蒙古、河北共8省（区）被确定为2014年中央补助地方“粮安工程”危仓老库维修专项资金重点支持省份，现予公告。
