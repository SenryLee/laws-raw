# 民政部办公厅关于报送《2014慈典：慈善救助信息使用手册》发放联络人的通知

民政部办公厅关于报送《2014慈典：慈善救助信息使用手册》发放联络人的通知

各省、自治区、直辖市民政厅（局），新疆生产建设兵团民政局：

为深入贯彻落实党的十八大和十八届三中全会精神，推动慈善事业更好地服务社会公众特别是困难群众，帮助有需要的公众准确、便捷地获取救助信息，按照《民政部办公厅关于广泛开展慈善项目信息征集工作的通知》（民办函﹝2013﹞397号）要求，在各地民政部门的积极配合下，我部遴选了近2000个优秀慈善项目，并委托《环球慈善》杂志社梳理编印了《2014慈典：慈善救助信息实用手册》（以下简称《慈典》），XXX部长为此书亲自作序。

《慈典》是我国第一个系统整理的、比较全面展示正在运作的慈善项目的慈善救助资源信息手册，清晰呈现了众多慈善组织的详细信息，分类介绍了涉及群众生活主要方面的慈善项目，反映了当前我国慈善领域资源分布状况，是慈善资源信息公开和对接的创新举措，在我国现代慈善事业发展中具有开创性意义。为更好地应用《慈典》，根据部领导指示，拟将首批《慈典》寄发至全国各省（自治区、直辖市）民政厅（局）、新疆生产建设兵团民政局以及各国家级贫困县（名单见民政部网站社会福利和慈善事业促进司慈善和社会捐助处网页）民政局免费使用。请各省（自治区、直辖市）民政厅（局）、新疆生产建设兵团民政局确定处室联络人及本省（自治区、直辖市）各国家级贫困县民政局联络人，准确填写《〈2014慈典：慈善救助信息实用手册〉发放联络人信息表》（见附件），并于7月4日前将《信息表》同时以传真和电子表格的形式报至民政部社会福利和慈善事业促进司慈善和社会捐助处。此外，请协助安排国家级贫困县民政局收到《慈典》后，尽快将其发放给乡镇民政助理员使用。
