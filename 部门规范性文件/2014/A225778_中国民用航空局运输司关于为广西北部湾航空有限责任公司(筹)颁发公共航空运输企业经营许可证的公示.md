# 中国民用航空局运输司关于为广西北部湾航空有限责任公司(筹)颁发公共航空运输企业经营许可证的公示

广西北部湾航空有限责任公司（筹）2014年7月21日经民航局批准筹建，目前筹建工作已基本完成，申请公共航空运输企业经营许可证。民航中南地区管理局已完成对其初审。根据《公共航空运输企业经营许可规定》（民航总局令第138号），有关情况公示如下：

一、公司名称：广西北部湾航空有限责任公司

二、企业地址：广西南宁吴圩国际机场基地航空公司办公楼

三、基地机场：南宁吴圩国际机场

四、企业类型：有限责任公司

五、注册资本：人民币叁拾亿元整

六、法定代表人：吴重阳

七、经营范围：国内航空客货运输业务，从南宁始发至港澳台的航空客货运输业务，从南宁始发至周边国家的国际航空客货运输业务

八、投资人及其出资方式、比例：

|  |  |  |  |
| --- | --- | --- | --- |
| 投资人名称 | 出资额（人民币） | 出资方式 | 出资比例 |
| 天津航空有限责任公司 | 21亿元 | 现金和实物 | 70% |
| 广西北部湾投资集团有限公司 | 9亿元 | 现金和实物 | 30% |
| 合 计 | 30亿元 |  | 100% |

九、申请经营许可证的准备情况

1．已制定公司章程；

2．广西机场管理集团有限责任公司南宁吴圩国际机场已同意为其提供办公用房；

3．民航局已批准其引进天津航空有限责任公司作为资产注入的3架E190飞机，并从天津航空有限责任公司以经营租赁方式引进2架E190飞机；

4．已与广西机场管理集团有限责任公司南宁吴圩国际机场签订了机场使用协议；

5．适航司已批准飞机外部喷涂方案；

6．民航中南地区管理局已同意其使用131.3MHZ作为航务管理频率

7．民航中南地区空中交通管理局广西分局已同意为其提供航务通信、航行情报和气象等服务保障；

8．经国际民航组织正式注册，民航局空管局向其指配了三字代码CBG和无线电呼号（中文无线电呼号为浪花、英文无线电呼号为SPRAY；国际航协向其指定了二字代码GX和三字结算码872;

9．运输司已批准其国内运输总条件及相关运输凭证样式，国际运输总条件已准予备案；

10．中国平安财产保险股份有限公司已确认其加入海航机队大保单，同意为其承保地面第三者责任险等保险；

11．天津航空有限责任公司已同意向其转让飞行人员50人、维修人员72人、签派人员12人、乘务人员60人、运输人员20人、安全员20人，广西北部湾航空有限责任公司（筹）已承诺在取得经营许可证后将与上述专业技术人员签订劳动合同；

12．经北京安致勤会计师事务所审验（验资报告—安致勤验字[2014]第2011号），各股东的首期出资9亿元人民币已缴足，其余出资按公司章程缴足，符合《公司法》相关要求。

13．根据《民用航空器飞行事故应急反应和家属援助规定》（民航总局令第155号）的要求，已制定《家庭救援计划》。

14．公司总裁

吴重阳，云南祥鹏航空有限责任公司副总裁

各利害关系人及有关单位如有意见，请于2015年1月12日前将书面意见反馈至民航局运输司。
