# 国家质量监督检验检疫总局计量司关于确定2014年参加中国计量科学研究院科研课题研究人员的通知

## 国家质量监督检验检疫总局计量司关于确定2014年参加中国计量科学研究院科研课题研究人员的通知（质检量函〔2014〕11号）

各有关省、自治区、直辖市、计划单列市、副省级市计量科学（测试技术）研究院（所），苏州市计量测试研究所，无锡市计量科学研究所：

按照《质检总局计量司关于做好2014年选派计量技术骨干参加科研课题研究的通知》（质检量函〔2014〕2号）文件要求，全国共35个计量科学（测试技术）研究院（所）推荐了63名人员。根据专业和课题需要，经商中国计量科学研究院，确定53名计量技术骨干（见附件）参加2014年中国计量科学研究院科研课题研究。现将有关事项通知如下：

1. 请有关单位通知本人，并及时与中国计量科学研究院科技发展部取得联系，确定具体报到时间。报到截止日期为2014年5月31日。

2. 如有特殊情况无法按计划参加科研课题研究的，请派出单位及时书面通知计量司，说明原因。
