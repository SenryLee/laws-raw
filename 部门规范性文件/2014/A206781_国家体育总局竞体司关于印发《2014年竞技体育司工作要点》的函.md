# 国家体育总局竞体司关于印发《2014年竞技体育司工作要点》的函

## 国家体育总局竞体司关于印发《2014年竞技体育司工作要点》的函（体竞字[2014]10号）

各省、自治区、直辖市、新疆生产建设兵团体育局，总参军训部军事体育训练局、总政宣传部文体局，有关运动项目管理中心：

为深入贯彻落实党的十八大、十八届三中全会精神和2014年全国体育局长会议刘鹏局长讲话精神，认真做好2014年全国竞技体育工作，现将经体育总局领导批准的《2014年竞技体育司工作要点》印发给各单位供参阅。

竞体司

2014年1月28日

2014年竞技体育司工作要点

**一、**主要思路

认真贯彻落实党的十八大、十八届三中全会精神和2014年全国体育局长会议刘鹏局长讲话精神，按照总局党组开展群众路线教育实践活动落实整改工作的“两方案一计划”要求，认真抓好工作落实，进一步解放思想，改革创新，积极推进竞技体育发展方式的改革调整，创新竞技体育的管理体制和运行机制，促进我国竞技体育综合实力的不断提升，推动体育强国建设。

**二、**工作要点

（一）全力以赴，做好2014年索契第22届冬奥会备战参赛工作，争取运动成绩和精神文明双丰收。

1、全面分析参赛形势和主要对手情况，制定实施各参赛项目程序化参赛方案。加强参赛代表团赛风赛纪和反兴奋剂以及安全工作的教育与管理，强化思想政治工作和励志教育，全方位做好中国体育代表团的各项组织、服务和保障工作。

2、制定实施中国体育代表团参赛指挥计划和方案，建立快捷高效的参赛指挥体系，确保指挥系统高效、通畅运转，做好参赛中各种突发事件应急方案与预案。争取运动成绩和精神文明双丰收。

（二）统筹规划，细化落实，全面推进2016年第31届里约奥运会的各项备战工作。

1、全面分析并研究确定各项目中心里约奥运会的任务目标。与各项目中心签订《承担2016年里约奥运会任务责任书》，充分调动各项目中心备战奥运会的积极性和创造性。

2、加强总局备战领导小组对备战工作的检查、监督和指导。以“集中与分散相结合”的形式，继续对各项目中心备战工作进行“盘点”，不断总结经验，查找问题，增添与完善备战工作的办法和措施。

3、继续推动训练、管理理论和实践创新。组建好国家队身体运动功能训练团队；组织实施国家队总主教练员年度业务述职考评工作；进一步扩大国家队实施训练质量管理评估的试点工作；认真推进里约奥运会赛前训练营的各项筹建工作。

4、积极配合，组织开展好国家队思想政治工作和励志教育工作。发挥思想政治工作优势，强化运动员精神、意志、心理和作风的锤炼。

（三）认真做好2014年仁川第17届亚运会的备战参赛工作和南京第2届青奥会的组织与参赛工作。

1、精心部署，认真做好仁川第17届亚运会的备战参赛工作。仁川亚运会是2016年里约奥运会前的一次重要练兵和“中考”，要着眼于里约奥运会培养锻炼人才、磨合队伍，积累实战经验，认真做好本届亚运会的选拔和组团参赛工作，争取运动成绩和精神文明双丰收。

2、精心组织，认真做好南京第2届青奥会的组织和参赛工作。第2届青奥会是继北京奥运会后我国举办的又一个奥林匹克盛会，要与江苏省、南京市有关部门紧密配合，认真做好各项竞赛组织和筹备工作。同时要全面做好我参加第2届青奥会的选拔和组团参赛工作。

（四）积极推广第12届全运会和全国综合性运动会的改革成果，落实好各项要求。

1、节俭筹办好4个国际、国内综合性运动会。继续按照习近平总书记“厉行节约、反对铺张、开创新风”的重要指示精神，扎实有序推进2014年南京第2届青奥会的竞赛组织工作，研究确定2015年福建第1届全国青年运动会、2016年新疆第13届全国冬季运动会和2017年天津第13届全国运动会的调整改革和组织筹办工作。

2、研究并制定《全国综合性运动会组织管理办法》。巩固和推广第12届全运会改革成功经验，以精简节约为原则，研究制定《全国综合性运动会组织管理办法》，对综合性运动会的筹办工作提出具体要求与规范，使综合性运动会的改革成效制度化、规范化。启动2019年第2届全国青年运动会申办工作。

（五）进一步转变职能，积极破解难题，加强竞技体育基础性、法规性和长效性工作。

1、深入调研足、篮、排“三大球”发展的体制机制问题，促进发展方式的调整转换，努力提升足、篮、排“三大球”运动水平。

2、加强对全国单项竞赛制度的调研，调整改革单项竞赛的管理办法。继续加大对赛风赛纪专项治理的力度，使从严整治赛风赛纪常态化、法制化。

3、研究制定《全国教练员注册管理办法》，总结第一批全国精英教练员培养计划的经验与问题，启动第二批精英教练员的培训工作。

4、做好新颁布的《国家体育训练基地管理办法》、《全国性单项体育协会命名训练基地监督管理办法》，以及《运动员技术等级管理办法》和《运动员技术等级标准》的各项实施工作。

5、修订《全国运动员注册与交流管理办法（试行）》、《裁判员管理办法》、《体育运动项目成绩统计办法》等竞技体育法规。

（六）大力转变作风，切实加强竞体司干部队伍思想作风和廉政建设。

深入贯彻落实党的十八大、十八届三中会会精神，巩固开展党的群众路线教育实践活动成果，认真执行《国家体育总局工作规则》，坚决反对“四风”，加强干部队伍思想、组织、作风建设和廉政建设，深入工作实际，注重调查研究，切实转变作风，提高工作效率，全身心地为基层做好服务，努力打造竞体司一支政治强、业务精、作风正的干部队伍。
