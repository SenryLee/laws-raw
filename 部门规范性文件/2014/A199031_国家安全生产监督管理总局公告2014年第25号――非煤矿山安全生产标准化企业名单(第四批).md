# 国家安全生产监督管理总局公告2014年第25号――非煤矿山安全生产标准化企业名单(第四批)

国家安全生产监督管理总局公告

（2014年第25号）

根据《企业安全生产标准化评审工作管理办法（试行）》（安监总办〔2014〕49号）的规定，经考评，安徽省皖北煤电集团有限责任公司含山恒泰非金属材料分公司等7家企业为金属非金属矿山安全生产标准化一级企业，中国石油西南油气田分公司川东北气矿等90家企业为石油行业安全生产标准化一级企业，中海石油（中国）有限公司天津分公司渤中25-1油田等33家企业为海洋石油安全生产标准化二级企业，海洋石油-奥帝斯完井服务有限公司为海洋石油安全生产标准化三级企业，现予公告。有效期为自公告之日起3年。

附件：非煤矿山安全生产标准化企业名单（第四批）

国家安全监管总局

2014年9月5日
