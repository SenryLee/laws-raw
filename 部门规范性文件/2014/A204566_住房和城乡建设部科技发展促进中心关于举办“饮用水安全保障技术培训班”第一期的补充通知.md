# 住房和城乡建设部科技发展促进中心关于举办“饮用水安全保障技术培训班”第一期的补充通知

有关单位：

受住房城乡建设部建筑节能与科技司委托，我中心承办“饮用水安全保障技术培训班”的组织和具体会务工作，现将第一期水厂改（扩）建工程设计与运行管理技术培训有关事项通知如下：

**一、**培训时间、地点

（一）培训时间

2014年5月21日全天报到，5月22日至25日培训（专家讲座、学习讨论、现场参观）。

（二）培训地点

无锡太湖花园度假村（江苏省无锡市山水东路8号，0510-85555888），酒店周边地图及乘车路线见附件1。

**二、**讲座内容及主讲人

（一）我国饮用水安全保障相关政策研读

--住房城乡建设部城市建设司　章林伟　副巡视员

（二）水厂改（扩）建技术需求、目标和指导原则

--中国城镇供水排水协会　刘志琪　副秘书长

（三）江苏省水厂水质提升管理经验介绍

--江苏省住房城乡建设厅　林国峰　主任

（四）水厂改（扩）建技术总体对策与思考

--深圳市水务（集团）有限公司　张金松　总工

（五）水厂强化常规技术典型案例分析

--北京市市政工程设计研究总院有限公司　郄燕秋　教授级高工

（六）水厂膜处理技术典型案例分析

--上海市政工程设计院总院（集团）有限公司　沈袭昌　教授级高工

（七）水厂深度处理技术典型案例分析

--中国市政工程中南设计研究总院有限公司　邓志光　副院长

（八）适合我国国情的消毒技术

--清华大学　　刘文君　教授

（九）水厂预处理和深度处理研究与总结

--同济大学高乃云　教授

（十）改（扩）建水厂运营的经验交流

--无锡市自来水总公司

（十一）适应新标准的饮用水处理新工艺、新设备、新产品

具体安排以报到时议程为准。

**三、**费用

培训费用：1500元/人（含资料费）。食宿统一安排，费用自理。住宿标准：标准间400元/间，高级单人间450元/间。

**四、**注意事项

（一）培训班期间，凭回执（见附件2）安排食宿及相关活动，回执请于2014年5月8日前传真到住房城乡建设部科技发展促进中心。

（二）请学员报到时交一寸彩色照片1张（背面署名），用于办理住房城乡建设部继续教育证书。
