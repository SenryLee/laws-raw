# 农业部办公厅关于印发《农业部2014年度绩效管理实施方案》的通知

## 农业部办公厅关于印发《农业部2014年度绩效管理实施方案》的通知（农办办〔2014〕16号）

《农业部2014年度绩效管理实施方案》已经2014年第3次部常务会议审议通过，现印发你们，请认真贯彻落实。

农业部办公厅

2014年4月10日

农业部2014年度绩效管理实施方案

党中央、国务院对推进政府绩效管理高度重视，提出了明确要求。党的十八大报告提出，要“创新行政管理方式，提高政府公信力和执行力，推进政府绩效管理”。党的十八届三中全会明确提出，要“严格绩效管理，突出责任落实，确保权责一致”。新修订的《国务院工作规则》第34条规定：“国务院及各部门要推行绩效管理制度和行政问责制度”。为贯彻落实中央的部署要求，扎实做好2014年度绩效管理工作，根据《农业部绩效管理办法》规定，制定本方案。

**一、**总体思路

认真贯彻落实党中央、国务院关于推进政府绩效管理的战略部署，按照部党组提出的“坚定不移推进，持续改进提高”的总体要求，在全面总结我部绩效管理实践经验的基础上，科学设计指标体系，改进评估考核方法，创新管理体制机制，统筹推进部机关司局绩效管理、直属事业单位绩效管理和专项工作延伸绩效管理，切实提高绩效管理的效率和水平，促进行政效率提高和工作作风转变，推动农业农村经济又好又快发展。

**二、**机关司局和试点事业单位绩效管理

（一）实施范围

在20个机关司局全面开展绩效管理。事业单位绩效管理试点范围由12个调整为17个（事业单位绩效管理试点范围见附件1），做到每个司局都有归口管理事业单位参与试点。其中，机关服务局纳入到试点事业单位范围进行考核评估（有关工作程序参照机关司局），新增农业部管理干部学院、农业部农村经济研究中心、农业部农村社会事业发展中心、全国农业展览馆、农业部规划设计研究院、农业部财会服务中心、中央农业广播电视学校、中国农垦经济发展中心等8个单位，中国农业科学院烟草研究所、中国水产科学研究院淡水渔业研究中心、中国热带科学院生物技术研究所、农业部规划设计研究院设施农业研究所等4个二级单位改由其所在院组织开展绩效管理。

（二）工作内容

1.制定绩效计划任务书。紧紧围绕部党组“两个千方百计、两个努力确保、两个持续提高”的目标任务，把党的十八大、十八届三中全会关于“三农”工作的决策部署、中央1号文件、政府工作报告、中央八项规定以及农业部1号文件、为农民和部系统干部职工办实事等相关重点工作列为绩效计划任务。

2.编制绩效管理指标体系。在2013年“职责履行”实行三级指标管理的基础上，2014年绩效管理指标全部实行三级指标管理，每项三级指标对应一项具体工作，并落实到承办处室，实现精细化管理，形成全员参与绩效管理的良好局面。各司局、各试点事业单位要将绩效计划任务书的内容全部细化为绩效指标，能量化的一律量化，不能量化的应提出可衡量的标准，明确责任主体、落实措施和完成时限。依据上年度绩效反馈意见，明确整改方向，提出整改目标和措施，并将整改落实情况列为职责履行中的单项指标。突出抓好“坚持不懈抓好粮食等重要农产品生产”等19项核心指标（见附件2），牵头司局必须将其列入本司局绩效管理指标，增加权重，强化措施，确保落实；有明确工作任务的参与司局和单位也要相应列出指标，作为绩效管理的重点内容。

3.强化过程管理。各司局、各试点事业单位要加强进展动态监测，定期分析完成情况及存在问题，强化措施确保落实。根据本方案确定的时间节点安排扎实开展中期评估工作。按时将承担的各项临时性工作任务细化为指标。因不可抗力或政策因素确需调整指标的司局和试点事业单位，要按时完成调整工作。过程管理中，各司局要充分发挥绩效管理信息系统的作用，实时填报、每月检查各项指标任务落实进展情况，要加强与归口管理试点事业单位的绩效沟通，强化指导和监督。

4.实施绩效评估。各司局年终评估由部绩效办组织实施，试点事业单位年终评估由归口管理司局会同部绩效办组织实施。按照司局和试点事业单位自评、评估小组核实司局、司局核实归口试点事业单位、部绩效办复核、部绩效管理领导小组审核、部党组审定的程序进行，不断完善评估标准和方法，逐步扩大群众参与度，持续提高评估结果的客观性、公正性和可信度。年终评估方案另行制定。

（三）实施步骤与时间安排

1.组织培训。4月中旬，部绩效办以办公厅文件印发《农业部2014年度绩效管理实施方案》，4月下旬对机关司局、试点事业单位综合处（办公室）有关负责人及工作人员进行培训，部署安排绩效管理工作。

2.制定绩效计划任务书和指标体系。5月8日前，各司局、各试点事业单位完成2014年度绩效计划任务书制定和绩效管理指标体系编制。机关司局通过绩效管理信息系统完成计划任务书和指标体系填报，试点事业单位绩效计划任务书、指标体系经归口管理司局初审后，提交电子版与纸质版。

3.部绩效办审核。5月中旬，部绩效办对各司局、各试点事业单位的绩效计划任务书和指标体系进行审核，提出修改意见并反馈。

4.签署绩效计划任务书，印发绩效管理指标体系。5月下旬，各司局、各试点事业单位对绩效计划任务书和指标体系进行修改完善后，由部绩效办报请分管部领导审核和部绩效管理领导小组审定。机关司局的绩效计划任务书由分管部领导与各司局负责人签署，试点事业单位的绩效计划任务书由分管部领导、归口管理司局负责人和单位负责人签署。绩效管理指标体系以办公厅文件统一印发实施。

5.开展中期评估。8月上旬，部绩效办印发中期评估通知。8月下旬，各司局、各试点事业单位完成自评，着重分析核心指标和重点工作任务完成情况，形成中期评估自评报告报部绩效办，其中试点事业单位自评报告需经归口管理司局审核。8月底前，部绩效办完成机关司局抽查核实，机关司局完成归口事业单位评估核实并将核实情况及时报部绩效办。9月中旬，部绩效办形成《农业部2014年度绩效管理中期评估报告》。

6.调整指标和细化临时性工作任务。10月上旬，部绩效办印发通知。10月31日前，各司局将调整指标和临时性工作任务细化指标的申请报部绩效办。各试点事业单位将调整指标和临时性工作任务细化指标的书面申请、电子版报归口管理司局审核同意后，报部绩效办。部绩效办初审后报领导小组审定。11月下旬，向各司局、各试点事业单位反馈关于同意调整指标和临时性工作任务细化指标的函。

7.组织年终评估。12月中旬，部绩效办分别印发机关司局、试点事业单位年终评估方案，部署评估考核工作，并开展动员培训。2015年1月上旬，各司局、各试点事业单位完成自评，向部绩效办提交各项自评材料，其中试点事业单位自评材料需经归口管理司局审核同意；1月下旬，评估小组完成司局核实工作，司局完成归口试点事业单位核实工作并将审核结果报部绩效办，人事劳动司负责满意度测评，驻部纪检组监察局会同直属机关纪委、财务司提出违规失职评估意见。2015年3月中旬前，部绩效办完成复核工作，将2014年绩效管理评估结果报部绩效管理领导小组审核后，报部党组审定。2015年3月底，部绩效办形成《农业部2014年度绩效管理总结报告》，并向社会公开。

**三、**绩效管理创新项目

（一）实施范围

20个机关司局和17个试点事业单位。

（二）工作内容

各司局、各试点事业单位分别设立1个创新项目，力求通过创新项目实施解决制约农业农村经济科学发展的体制、机制、管理、政策等深层次问题，努力在关键环节、重点领域、工作机制和运转模式上实现创新突破，进一步提升农业农村经济工作水平，提高为“三农”服务的工作效率。

（三）实施步骤与时间安排

1.创新项目申报。5月8日前，各司局、各试点事业单位报送《农业部2014年度创新项目立项申报表》（见附件3）和创新项目实施方案。其中，各司局通过绩效管理信息系统填报，事业单位需报送纸质件和电子版材料，且需经归口管理司局审核同意。5月中旬，部绩效办报分管部领导审核、部绩效管理领导小组审定。

2.创新项目实施与评估。经审定后的创新项目以办公厅文件印发实施。各司局、试点事业单位按照实施方案切实抓好项目落实。12月中旬，部绩效办印发创新项目评估方案，与年终评估一同部署，2015年1月下旬，组织开展创新项目评估。

**四、**专项工作延伸绩效管理

（一）实施范围

继续对强农惠农富农政策落实等6项专项工作开展延伸绩效管理。其中，强农惠农富农政策落实（农机购置补贴和基层农技推广体系建设）和加强重大动物疫病防控等2项延伸绩效管理在全国范围内实施；稳定发展粮食生产、稳定发展“菜篮子”产品生产、加强农产品质量安全监管等3项在东、中、西部各选择部分省（区、市）试点，并继续扩大覆盖范围；农业投资项目延伸绩效管理继续选择近几年农业重大投资项目对有关省级农业部门和部属事业单位进行延伸绩效管理试点，并适当扩大试点范围。同时，启动农业行政审批制度改革落实情况延伸绩效管理工作，将省级农业部门在农业行政审批事项“接”“放”“管”三个方面的贯彻落实情况纳入延伸绩效管理。

（二）工作内容

各牵头司局就2013年度开展的6项专项工作延伸绩效管理，以“自评＋核实”的方式对省级农业部门开展评估。同时，制定印发2014年度专项工作延伸绩效管理实施方案，并强化过程管理，确保各项重大政策、项目落到实处。

（三）实施步骤与时间安排

1.开展2013年度专项工作延伸绩效管理评估。4月至5月，各省级农业部门根据专项工作延伸绩效管理评估方案完成自评；牵头司局完成查验核实，分别形成评估结果报告。6月上旬，由部绩效办汇总后报部绩效管理领导小组审核、部常务会议审定。6月底前，完成年度延伸绩效管理工作总结报告。7月份，在全国农业厅局长视频会（片区座谈会）上对2013年度延伸绩效管理成绩突出的省级农业部门给予表扬，并以部函的形式通报相关省级人民政府。

2.印发2014年度专项工作延伸绩效管理实施方案。5月中旬前，各牵头司局研究起草2014年度专项工作延伸绩效管理实施方案，部绩效办进行初审。5月底前，各牵头司局印发通知，征求各省级农业部门、有关部属事业单位及相关方面意见，并对实施方案作进一步修改完善。6月上旬，将实施方案报分管部领导审核和部绩效管理领导小组审定。6月底前以农业部文件印发实施。

3.加强绩效沟通与过程监管。实施方案印发后，各牵头司局应组织省级农业部门、部属事业单位进行延伸绩效管理培训，加强指导沟通和督促检查，确保专项工作延伸绩效管理各项任务顺利完成。

**五、**其他工作

（一）继续完善绩效管理制度

1.工作内容。在认真总结试点事业单位绩效管理和专项工作延伸绩效管理工作经验基础上，出台事业单位绩效管理和专项工作延伸绩效管理实施办法。

2.实施步骤与时间安排。4月，研究制定相关制度起草方案；5月至9月，组织领导小组成员单位和牵头司局赴相关事业单位、省级农业部门开展调研；10月，形成制度办法的初稿，征求各方面意见；12月底前，按程序报请部常务会审定后印发实施。

（二）开展绩效管理信息系统四期建设

1.工作内容。结合机关司局指标体系实现三级指标管理，研发司局内设处室绩效管理模块，并继续完善指标制定、过程管理、年终评估等功能。研究开发事业单位绩效管理信息系统，实现事业单位绩效管理年终评估无纸化。

2.实施步骤和时间安排。4月上旬，结合今年绩效管理指标体系编制工作，完成绩效管理信息系统指标制定功能的调整和完善；4月下旬，组织开展系统操作培训；5月至6月，完成信息系统需求调研，正式启动信息系统四期建设。10月底前，完成全部建设内容并对现有系统进行升级和调试。11月底前，信息系统正式投入使用。

（三）绩效管理课题研究

1.工作内容。委托有关科研单位，结合我部绩效管理实践，开展第三方评估制度、专项工作延伸绩效管理、事业单位分类绩效管理等相关课题研究，发挥专家“智库”作用，强化理论对实践的指导，为绩效管理深入推进提供理论支撑。

2.实施步骤与时间安排。4月底前，与课题承担单位签订委托协议，成立课题组，明确课题的任务、内容与预期目标。课题研究过程中，部绩效办加强与各课题组的沟通交流，密切关注课题研究进展，及时将研究成果转化到绩效管理实践中。12月底前，各课题组提交课题研究成果。鼓励各牵头司局、各归口管理司局结合专项工作延伸绩效管理和事业单位绩效管理开展相关课题研究。

**六、**有关要求

2014年是贯彻落实党的十八届三中全会精神、全面深化农业农村改革发展的第一年，各司局、各试点事业单位要不断深化对绩效管理的认识，紧紧围绕“两个千方百计、两个努力确保、两个持续提高”的中心任务，坚持目标导向、创新工作方法、狠抓措施落实，不断激发和调动广大干部职工的积极性、主动性，进一步推动工作落实和作风转变。要坚持实行绩效管理“一把手”责任制，主要领导要亲自抓，定期听取工作汇报，及时研究解决难点问题，做到绩效管理与业务工作协同开展、融为一体，防止“两张皮”。要将绩效目标分解到处室、落实到岗位，鼓励对内设处室开展绩效管理，把农业部战略目标实现与司局单位绩效提升和干部职工个人成长进步有机统一起来，为农业农村经济持续健康发展提供有力保障。
