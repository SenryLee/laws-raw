# 农业部办公厅关于召开全国农垦工作会议的通知(2014)

## 农业部办公厅关于召开全国农垦工作会议的通知（农办垦[2014]10号）

各省、自治区、直辖市及广州、南京、大连市农垦主管部门，海拉尔农牧场管理局，大兴安岭农场管理局，新疆生产建设兵团办公厅及农业局：

根据我部工作安排，决定召开全国农垦工作会议。现将有关事项通知如下：

**一、**会议内容

深入贯彻落实党的十八大、十八届三中全会和中央经济工作会议、中央农村工作会议和全国农业工作会议精神，分析当前农垦经济社会发展面临的新形势新任务，谋划今后一个时期农垦发展思路，研究探讨实施农垦联合联盟联营战略，培育国际大粮商计划的路径、方式和措施。

**二、**会议时间

2014年4月9日，会期一天。4月8日报到。

**三、**会议地点

北京渔阳饭店。

地址：北京市朝阳区新源西里中街18号。

总机：（010）64669988。

**四、**参加人员

1.各省、自治区、直辖市及广州、南京、大连市农垦主管部门，海拉尔农牧场管理局，大兴安岭农场管理局主要负责同志；新疆生产建设兵团办公厅和农业局负责同志。

2.部机关有关司局负责同志，中国农垦经济发展中心领导班子成员。

3.中国农林水利工会负责同志。

4.有关部委和新闻媒体代表。

**五、**有关要求

（一）请各单位合理安排工作，保证主要负责同志按时参加会议。主要负责同志因故不能参加会议，请在回执上说明原因。

（二）请各单位深入分析农垦面临的新机遇和新挑战，认真提出今后一个时期农垦发展的新思路新举措，形成文字材料带到会上交流。

（三）请各单位填好会议回执（附件），于2014年4月1日前传真至农垦局综合处。传真：010-59192659，电话：010-59192648、59192657。报到前与会代表如有变动，请及时将变动情况报告农垦局综合处。

（四）请各垦区将2013年大事记电子稿发送到nkjzhch@agri.gov.cn。

（五）请按分配名额参加会议，不要超员。请会议代表凭此通知原件或复印件自行前往北京渔阳饭店报到。

附件：全国农垦工作会议报名回执

农业部办公厅
