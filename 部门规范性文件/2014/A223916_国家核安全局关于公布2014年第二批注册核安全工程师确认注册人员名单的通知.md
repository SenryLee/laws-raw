# 国家核安全局关于公布2014年第二批注册核安全工程师确认注册人员名单的通知

国核安发[2014]297号

各相关执业单位：

根据《注册核安全工程师执业资格制度暂行规定》（人发〔2002〕106号）和《关于注册核安全工程师注册确认有关事项的通知》（国核安发〔2011〕40号）的有关要求，我局对各相关执业单位递交的2014年第二批注册核安全工程师注册申请、延续注册申请和注册领域变更申请进行了审查，现将符合条件的357名注册人员名单（见附件1）、376名延续注册人员名单（见附件2）和4名注册领域变更人员名单（见附件3）予以公布。

特此通知。

附件：1.2014年第二批注册核安全工程师注册人员名单

2.2014年第二批注册核安全工程师延续注册人员名单

3.2014年第二批注册核安全工程师注册领域变更人员名单

国家核安全局

2014年12月25日
