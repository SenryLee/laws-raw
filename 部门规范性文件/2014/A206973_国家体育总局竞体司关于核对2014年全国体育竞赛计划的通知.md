# 国家体育总局竞体司关于核对2014年全国体育竞赛计划的通知

各运动项目管理中心：

根据各中心上报的2014年全国体育竞赛计划，经整理、审核，现将拟印发的计划挂至国家体育总局网站竞体司专栏（www.sport.gov.cn），请认真进行核对，并于1月30日前将有关意见反馈竞体司。

有关事项说明如下：

**一、**没有确定地点的比赛不列入竞赛计划。

**二、**综合性比赛如“运动会、运动大会”等一事一报，不列入竞赛计划。

**三、**本项目与其它项目有交叉，容易造成混淆和纠纷的比赛一事一报，不列入竞赛计划。

**四、**请各中心按时反馈，不反馈的视为无意见。
