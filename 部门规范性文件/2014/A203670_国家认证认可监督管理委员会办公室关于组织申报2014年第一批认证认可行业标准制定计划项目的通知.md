# 国家认证认可监督管理委员会办公室关于组织申报2014年第一批认证认可行业标准制定计划项目的通知

各相关机构：

为充分发挥技术标准对认证认可工作的支撑保障作用，在充分调研需求基础上，我委研究确定了《2014年第一批认证认可行业标准申报范围》（以下简称《申报范围》，见附件1）。现就组织申报工作有关事项通知如下：

**一、**制标范围

本批申报范围主要包括能源管理体系认证、实验室能力验证、基础标准等重点领域。

**二、**申报要求

1.本次申报的项目限定在《申报范围》之内，《申报范围》以外项目，我委将在后续工作中陆续安排，本次申报不予受理。

2.项目申报单位应具备完成标准项目所需的技术力量，并在人、财、物等资源方面提供必要的支持。

3.申报的项目应在1-2年内完成起草工作。

**三、**材料报送要求

1、申报单位请填写《认证认可行业标准制定项目计划建议书》（每个项目填写一份，见附件2）和《认证认可行业标准计划项目申报汇总表》（一个单位填写一份，见附件3）。如有成熟的标准草案，请一并上报。

2、各单位应于2014年5月31日前以公文形式将正式材料寄送我委联系人，同时发送电子文本至联系人电子邮箱。

| 7 | 能力验证物品 均匀性、稳定性检验的一般原则和统计方法 | 制定 | 适用范围和主要研究内容：  　　本标准旨在为更好地制备和检验能力验证物品提供支持，为能力验证物品的均匀性和稳定性检验提供一般原则和统计方法。包括：建立量值溯源、评估有关测量不确定度的方法，测量方法的选择原则，和均匀性检验、稳定性检验的数理统计方法。  　　同时，考虑不同能力验证类型，如：定性、定量，不同检测领域之间的区别和与国际标准的协调。必要时，提供具有参考价值的典型案例。  　　标准应有助于帮助能力验证提供者在实施过程中理解均匀性和稳定性检验的统计原理，保证能力验证物品的质量，从而确保在国家或国际范围内测量结果的可比性、准确性和一致性。  　　拟解决的关键问题及创新之处：  　　在一个典型的能力验证项目中，为了正确地进行均匀性和稳定性检验，既要具备检测方法及其特性的全面知识，也要具备均匀性检验、稳定性检验等统计方法的全面知识。这些必需的技能组合式的能力验证物品的生产和检验变得非常复杂，其中最大的挑战是将这些技能组合起来使项目顺利实施。  　　因此，本标准旨在为能力验证样品的质量保证，尤其是均匀性稳定性检验提供依据，从而保证能力验证计划实施的质量。填补国内缺乏能力验证物品均匀性稳定性检验标准的空白。　起草单位必须是能力验证提供者，有承办过认监委、认可委等的能力验证经历，并且参与了该领域有关文件起草、规划等活动。起草人一直从事能力验证活动，有丰富的经验，有能力验证组织经验单位优先。 |  |
