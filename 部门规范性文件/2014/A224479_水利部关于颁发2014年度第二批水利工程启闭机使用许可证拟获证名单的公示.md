# 水利部关于颁发2014年度第二批水利工程启闭机使用许可证拟获证名单的公示

根据有关规定，水利部组织对2014年第二批水利工程启闭机使用许可证申请企业进行了质量保证体系审查和产品质量检测，现将审检合格的水利工程启闭机使用许可证拟发证企业名单予以公示，请有关单位和个人进行监督。公示时间2014年11月4日-13日。

联系单位：水利部产品质量监督总站

联 系 人：王晗塒

联系电话：010－63204460
