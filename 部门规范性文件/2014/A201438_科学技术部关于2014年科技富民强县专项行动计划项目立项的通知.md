# 科学技术部关于2014年科技富民强县专项行动计划项目立项的通知

## 科学技术部关于2014年科技富民强县专项行动计划项目立项的通知（国科发农〔2014〕160号）

各省、自治区、直辖市及计划单列市科技厅（委、局），新疆生产建设兵团科技局：

为深入贯彻落实党的十八大和十八届三中全会精神，实施创新驱动发展战略，积极推进新形势下基层科技工作，培育壮大县域特色优势产业，根据《科技富民强县专项行动计划实施方案（试行）》、《科技富民强县专项行动计划资金管理暂行办法》和《科技富民强县专项行动计划绩效考评实施细则》的要求，科技部和财政部组织专家对各地方申报的2014年度科技富民强县专项行动计划项目实施方案进行了咨询论证和财务评审。根据论证和评审结果，核定“昌平区优质草莓高效栽培技术示范与推广”等295个项目予以立项（见附件）。

各省（区、市）要严格按照相关要求，结合推行科技特派员制度和特色产业链建设，根据项目批复意见，抓紧完善实施方案，并认真组织实施。各地方要加强对项目实施的管理、监督和考核，切实保证政策落实和资金到位。各县（市、区）政府要高度重视，加强领导，采取有效措施，认真完成各项任务，确保科技富民强县专项行动计划工作取得实效。

联系方式：科技部农村科技司基层科技处 010-58881400
