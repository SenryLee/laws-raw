# 中共教育部党组关于秦世成等同志 职务任免的通知

教党任[2014]123号

中共中国农业大学委员会：

经与中共北京市委商得一致，2014年9月23日研究决定：

秦世成同志任中共中国农业大学纪律检查委员会书记，宁秋娅同志任中共中国农业大学委员会常委、副书记，辛贤同志任中共中国农业大学委员会委员、常委；免去翟志席同志的中共中国农业大学委员会副书记、常委、中共中国农业大学纪律检查委员会书记，傅泽田、郭大同志的中共中国农业大学委员会常委职务。

中共教育部党组

2014年10月21日
