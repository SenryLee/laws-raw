# 农业部办公厅关于做好2014年农机化培训工作的通知

## 农业部办公厅关于做好2014年农机化培训工作的通知（农办机〔2014〕5号）

各省、自治区、直辖市及计划单列市农机（农业、农牧）局（厅、委、办），新疆生产建设兵团农业局，黑龙江省农垦总局：

为深入贯彻2014年中央1号文件精神，落实农机化教育培训“十二五”规划，切实做好2014年农机化培训工作，进一步加强农机化人才队伍建设，推动农机化科学发展。现将有关事项通知如下。

**一、**及早部署，深入推进培训大行动。按照《农业部办公厅关于深入开展农业机械化教育培训大行动的通知》（农机办〔2012〕15号）精神，今年要继续推进全国农机化教育培训大行动（以下简称大行动）。通过大行动，可以加快打造有文化、懂技术、会操作、善经营的新型农机手和新型职业农民，优化农机化人才队伍结构，夯实农机化发展基础，提升人才队伍整体素质。各级农业机械化主管部门要将大行动作为推动农业机械化发展的重要任务来抓，及早部署，精心组织，加强领导，实行一把手负责制，确保大行动工作抓紧抓好抓到位。要进一步完善体制机制，增加投入，挖掘资源，改进方法，丰富内容，创新方式，强化教育培训质量，努力完成各省（区、市）的农机化培训目标任务，全年全国培训农机化管理人员20万人次、推广科技人员80万人次、实用人才450万人次以上，进一步提升农业机械化人才队伍的能力素质。

**二、**加强管理人员培训。按照依法行政、强化履职尽责等要求，进一步加强各级农机管理人员的培训，努力培养造就一支管理能力强、乐于奉献的农机化管理人才队伍。要加强县级以上农机管理人员的思想政治、“三农”政策理论、农机化法律法规和业务知识等方面的培训，提高服务意识，转变工作作风，全面提高农机管理人员的履职能力。2014年，我部委托部管理干部学院、中国农业大学中国农业机械化发展研究中心开展基层农机购置补贴工作人员培训，重点培训县级农机化主管部门主要负责同志和农机购置补贴具体工作人员。

**三、**加强科技推广人员培训。积极发挥农业机械化科研院所、高等院校的作用，加强产学研推用结合，依托行业科技、支撑计划等重大科研项目，集聚和培养农机化高级科技人才。要加强基层农机化技术推广人员培训，重点培养县以下推广人员的示范推广、技术服务能力和县以上推广人员的技术创新、成果转化能力，加强农机化技术推广队伍建设。要加强农业机械试验鉴定、安全监理等专业技术人员培训，加快知识更新，不断提高专业技术水平和业务素质。我部委托部农机化技术开发推广总站、部规划设计研究院组织开展重要农时季节农机化技术示范培训。

**四、**加强实用人才培训。加大农机实用人才队伍培训力度，采取措施，培养新型职业农民。积极实施阳光工程农机培训，重点加强农机合作社带头人、农机驾驶操作和维护修理人员等实用人才的培训，提高作业服务能力，增强致富本领。要充分发挥农机职业技能培训和鉴定示范基地的作用，加强农机技能人才培训，优化农机技能人才队伍结构。进一步推进农机职业技能培训与维修管理、安全监理、技术推广等工作的结合，创新农机职业技能培训、鉴定模式。鼓励开展农机职业技能竞赛活动，激发农机人员学技能、比技能、用技能的热情。要结合农机购置补贴政策实施，组织好新购机农民技术培训，提高农机手掌握使用现代农业装备的水平。我部委托部农机鉴定总站会同相关农机企业开展“政企联动”农机维修高技能人才培训和农机合作社理事长培训。

**五、**加强拖拉机驾驶培训管理。各省级农机化主管理部门要加强对拖拉机驾驶培训的监管，按照农业部令第41号《拖拉机驾驶培训管理办法》的要求，开展检查指导工作，了解情况总结经验，查找问题，研究对策，并形成拖拉机驾驶培训管理情况报告，于7月5日前报送我部农机化管理司。

各级农机化主管部门要加强与有关部门的密切配合，充分吸引社会力量参与培训，采取事企联合、校企联动等方式，鼓励相关企业、农机社会化服务组织等共同参与培训活动。要紧紧围绕农业机械化发展的需求，采取现场演示、送教进村、科技入户、技能竞赛等多种形式，大胆探索培训新形式，创新培训方式方法，吸引更多的农民机手参加培训学习。各省（区、市）农机化主管部门要将今年农业机械化教育培训方案于3月底前报送我部农业机械化管理司；将具体培训进展情况和全年的工作总结分别于7月5日、12月5日前报送我部农业机械化管理司。

农业部办公厅
