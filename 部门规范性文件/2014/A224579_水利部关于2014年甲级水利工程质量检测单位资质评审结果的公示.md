# 水利部关于2014年甲级水利工程质量检测单位资质评审结果的公示

根据《水利工程质量检测管理规定》（水利部令第36号）的有关规定，我部组织开展了2014年甲级水利工程质量检测资质申请和延续的评审工作。为保证评审质量，广泛接受社会监督，现将评审合格的甲级水利工程质量检测资质单位名单予以公示。如对评审结果有异议，请在公示期内以实名反映或举报。

公示时间：2014年7月14日至7月20日
