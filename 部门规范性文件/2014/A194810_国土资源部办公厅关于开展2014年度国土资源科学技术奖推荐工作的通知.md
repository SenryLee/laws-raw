# 国土资源部办公厅关于开展2014年度国土资源科学技术奖推荐工作的通知

## 国土资源部办公厅关于开展2014年度国土资源科学技术奖推荐工作的通知（国土资厅发〔2014〕5号）

各省、自治区、直辖市国土资源主管部门，新疆建设兵团国土资源局，解放军土地管理局，中国地质调查局，武警黄金指挥部，部其他直属单位，部机关各司局，中国土地学会、中国地质学会和中国地质矿产经济学会：

为做好2014年度国土资源科学技术奖的推荐工作，现将有关事项通知如下：

**一、**推荐方式

推荐国土资源科学技术奖应按照《国土资源科学技术奖励办法》（以下简称《办法》）规定的奖励范围和评审标准，由推荐单位对报奖材料进行审核，经推荐单位科技专家委员会初审合格，并分别在推荐单位和申报单位公示10个工作日后统一推荐。

**二、**推荐指标

国土资源科学技术奖实行限额推荐（推荐指标详见附件1）。各单位可在指标外推荐1套科普作品和1项由青年科技人员（1973年12月31日后出生）作为第一完成人的成果。

推荐项目的前5位主要完成人同一人同一年度只能申报1项报奖项目。对不符合此项要求的推荐项目视为形式审查不合格。

各单位推荐的报奖项目，推荐一等奖和二等奖的比例为1：3；项目等级的最终确定由国土资源科学技术奖励评审委员会评选产生。

**三、**推荐材料

申报国土资源科学技术奖应按照《办法》要求组织推荐，推荐材料是国土资源科学技术奖评审的基本依据，必须严格按要求填写。

1.国土资源科学技术奖推荐书和附件材料，可在3月9日后通过国土资源部网站“在线申报”或“科技与国际合作”栏，按照填报流程说明和要求在线填写和推荐。涉密项目由推荐单位联系申报。

2.推荐单位完成网上推荐后，从申报系统中导出打印推荐书和附件，装订成册，并加盖公章，一式二份（其中一份应注明原件归档）。同时，提交与报奖项目有关的研究报告、图件和专著材料一份（套），提交的书面申报材料与网上申报材料应完全一致，所有推荐材料概不退回。

3.报奖项目成果应在2012年1月31日以前已完成综合技术评价（指鉴定、评审或验收），国土资源管理研究类项目应在2013年1月31日以前已完成综合技术评价。时间不足或未经技术评价的报奖项目不予受理。

4.申报2013年度国土资源科学技术奖未获奖，或经批准退出2013年度评审的项目，以及已获得国家或省级科学技术奖的项目不予受理。

5.所有报奖项目应在2013年12月31日前已完成科技成果登记。

6.推荐单位以正式函（函中须说明组织推荐过程、公示情况及结果）报送推荐材料，并附推荐项目汇总表二份。

**四、**推荐评审专家

为进一步完善国土资源科学技术奖评审工作，请各单位推荐国土资源领域高水平专家进入国土资源科学技术奖评审专家库（推荐条件见附件3）。各推荐单位严格按照条件推荐专家，一方面要重新审核已入库专家，对符合条件的专家更新信息，另一方面要补充推荐新的专家。所有的专家信息由推荐单位统一审核确认盖章后上报。

**五、**推荐时间

1.报奖项目

由推荐单位统一按时限报送国土资源部信息中心科技成果管理办公室，单个项目自行报送的材料不予受理。推荐截止：网上推荐为2014年5月25日，纸质材料为2014年5月31日（以邮戳日期为准），逾期不予受理。

2.评审专家

请推荐单位通知拟推荐专家于2014年4月1日-10日通过部门户网站科技与国际合作专栏登陆国土资源科学技术奖评审专家系统填写专家信息表，打印后由推荐单位加盖公章，于4月20日前报送至国土资源部信息中心科技成果管理办公室。

附件3

国土资源科学技术奖评审专家推荐条件及填报方式

**一、**国土资源科学技术奖评审专家推荐条件

1．拥护中华人民共和国宪法，遵守国家法律和社会公德。

2．具有严谨的科学态度和良好的职业道德，为人公道正派，学风严谨。

3．遵守评审纪律，不泄露评审情况、评审结果和候选成果的技术秘密。

4．热心科技奖励工作，积极参加评审活动，能够保证充足时间参加评审工作。

5．有较广的知识面和较丰富的科学研究或技术开发的阅历，熟悉本专业、本学科领域国内外当前的科学技术发展动态。

6．目前仍然在研究开发、专业管理一线从事研究开发或专业管理工作，身体健康，年龄一般不超过55岁。

7．有较好的综合分析评价能力和表达能力。

8．具有教授、研究员、教授级高级工程师或同等级别技术职称；主持完成3项以上（含3项）国家级或省部级科研项目；获得1项以上（含1项）国家级或省部级科技奖励，并且排名在前3位。

**二、**国土资源科学技术奖评审专家系统填报

请登陆国土资源部门户网站（http：//www.mlr.gov.cn）科技与国际合作专栏--在线服务栏目--国土资源科技奖励专家系统。

1.原系统已有专家，可用身份证号直接登陆，登陆密码123456，登陆系统后可自行修改密码；新增专家需用18位身份证号进行注册，密码自行设置。

2.登陆后，请专家对系统所有信息项进行修改完善，确保完整准确。特别是“从事专业”、“可参加评审领域”、“主要学术成就”等信息，要根据自身情况填写合适的专业领域，并从系统生成打印表。

3.完成在线填报后，请打印专家信息表，并由推荐单位加盖公章，于4月20日前报送国土资源部信息中心科技成果管理办公室。
