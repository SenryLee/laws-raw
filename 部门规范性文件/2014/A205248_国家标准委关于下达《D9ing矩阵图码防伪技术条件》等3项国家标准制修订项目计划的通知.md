# 国家标准委关于下达《D9ing矩阵图码防伪技术条件》等3项国家标准制修订项目计划的通知

## 国家标准委关于下达《D9ing矩阵图码防伪技术条件》等3项国家标准制修订项目计划的通知（国标委综合〔2014〕9号）

全国防伪标准化技术委员会：

为大力提高我国防伪技术能力，建立健全防伪标准体系，现将《D9ing矩阵图码防伪技术条件》等3项国家标准制修订项目计划（见附件）下达你委员会，请组织主要起草单位，抓紧落实和实施计划，在标准起草中加强与有关方面的协调，广泛听取意见，保证标准质量和水平，按时完成国家标准制修订任务。

附件：《D9ing矩阵图码防伪技术条件》等3项国家标准计划项目汇总表

国家标准委

2014年3月24日
