# 国家质量监督检验检疫总局公告2014年71号――关于受理宇通节能与新能源客车等产品申报生态原产地产品保护的公告

## 国家质量监督检验检疫总局公告（2014年71号）

关于受理宇通节能与新能源客车等产品申报生态原产地产品保护的公告

日前，郑州宇通客车股份有限公司等单位申请对宇通节能与新能源客车等8个产品进行生态原产地产品保护。根据《原产地标记管理规定》及其实施办法、《生态原产地产品保护工作导则》和《生态原产地产品保护评定通则》等规定，经河南出入境检验检疫局、浙江出入境检验检疫局、福建出入境检验检疫局、天津出入境检验检疫局初审，我局委托中国生态道德教育促进会、中国检验认证集团测试技术有限公司、北京万诚信用评价有限公司评定，宇通节能与新能源客车等8个产品符合相关规定的保护条件，我局拟对其实施生态原产地产品保护。现将本次拟保护的产品及相关信息公告如下：

|  |  |  |
| --- | --- | --- |
| 序号 | 产品名称 | 申报单位 |
| 1 | 宇通节能与新能源客车 | 郑州宇通客车股份有限公司 |
| 2 | 采云间绿茶 | 浙江采云间茶业有限公司 |
| 3 | 蓟县鹊山鸡（花入羽）、蓟县鹊山鸡真野鸡蛋（花入羽） | 天津东山鹊山鸡养殖专业合作社 |
| 4 | 南日鲍、“海帝”牌南日鲍制品、“渔太太”牌南日鲍制品 | 莆田市秀屿区南日鲍协会 |
| 5 | 青田石雕 | 青田县石雕行业协会 |
| 6 | 青田田鱼、青田田鱼干 | 青田县稻鱼共生行业协会 |
| 7 | 丽水梅峰茶叶（梅峰红茶、梅峰绿茶） | 浙江梅峰茶业有限公司 |
| 8 | 丽水本润覆盆子 | 丽水市本润农业有限公司 |

如有关单位或个人对上述产品申请生态原产地产品保护持有异议，可自公示之日起1个月内向我局生态原产地产品保护管理办公室书面提出，并说明异议具体内容及理由。
