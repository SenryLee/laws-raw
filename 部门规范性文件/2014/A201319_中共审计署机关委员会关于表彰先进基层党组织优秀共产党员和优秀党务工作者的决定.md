# 中共审计署机关委员会关于表彰先进基层党组织优秀共产党员和优秀党务工作者的决定

署机关各单位、各派出审计局党总支、党支部，中国时代经济出版社党委：

2011年以来，审计署机关各基层党组织认真贯彻党的路线方针政策和署党组的决策部署，紧紧围绕审计中心工作，着力加强党的思想建设、组织建设、作风建设、反腐倡廉建设、制度建设，积极推进学习型、服务型、创新型党组织建设，不断增强创造力、凝聚力和战斗力，充分发挥党组织的战斗堡垒作用和共产党员的先锋模范作用，为审计发挥国家利益捍卫者、公共资金守护者、权力运行“紧箍咒”、反腐败利剑、深化改革“催化剂”作用，推动完善国家治理和实现可持续发展，提供了坚实的思想和组织保障，涌现出一批先进基层党组织、优秀共产党员和优秀党务工作者。

经全体党员和各基层党组织推荐，机关党委研究并报署党组批准，决定授予办公厅第二党支部等20个基层党组织“2011至2014年度先进基层党组织”称号，授予许君等71名同志“2011至2014年度优秀共产党员”称号，授予许荣荣等39名同志“2011至2014年度优秀党务工作者”称号。上述受到表彰的各基层党组织，领导班子讲政治、顾大局、守纪律，一把手认真履行“一岗双责”，充分发挥了表率作用；党员队伍思想政治素质高，党员意识强，纪律严明，履职尽责到位，作风严谨细致；认真落实组织生活制度和各项工作制度，内部管理顺畅有序；充分发挥职能作用，工作业绩突出；支部在党员和群众中有较高威信，得到大家的支持和拥护。受到表彰的优秀共产党员，重视政治理论和业务学习，工作积极努力，严格遵规守纪，甘于奉献，乐于助人，弘扬正气。受到表彰的优秀党务工作者，热爱党务工作，认真组织落实各项党建任务，关心党员、群众的成长进步，积极践行党的群众路线。

希望受到表彰的先进基层党组织、优秀共产党员和优秀党务工作者，珍惜荣誉，谦虚谨慎，开拓进取，再立新功。审计署机关各基层党组织和广大党员要以受到表彰的先进基层党组织、优秀共产党员和优秀党务工作者为榜样，牢记党的宗旨、坚定理想信念，围绕中心、服务大局、开拓创新、团结奋斗，进一步加强学习型、服务型、创新型党组织建设，进一步提高机关党建工作科学化水平，争创一流工作业绩，为推动审计事业可持续发展做出更大贡献。
