# 商务部外贸发展局关于请做好2014年德国科隆国际游戏展中国文化贸易展区组展工作的通知

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门，有关单位：

为支持文化企业开拓国际市场，进一步推动中国文化产业“走出去”，商务部定于2014年8月在德国科隆国际游戏展（GAMESCOM）上设中国文化贸易展区（以下简称科隆展）。科隆展是商务部主办的非商业性境外展会（以下简称非商展）。

根据商务部内部职能调整，自2014年起，外贸发展局负责非商展业务的组织实施工作。考虑到项目延续性，外贸发展局邀请通用国际广告展览有限公司作为合作承办单位，共同负责展会筹备等有关工作。请各地商务主管部门按照有关要求组织本地企业做好参展工作，现将有关事项通知如下：

**一、**时间： 2014年8月13-15日。

**二、**地点： 德国科隆国际博览中心（Koeln Messe）。

**三、**规模： 约270平方米，30个展位。

**四、**参展单位：与科隆展内容相关的文化贸易企业，列入2013-2014年度国家文化出口重点企业公示名单中的企业，各地重点培育和发展的文化企业。

**五、**参展范围：个人电脑、电子游戏机、电信设备、掌上电脑、网络游戏、移动游戏、游戏软件、教育软件、家用及其他软件，认证代理机构、维修保养机构、媒体、开发商等。

**六、**具体参展事宜将另行通知。
