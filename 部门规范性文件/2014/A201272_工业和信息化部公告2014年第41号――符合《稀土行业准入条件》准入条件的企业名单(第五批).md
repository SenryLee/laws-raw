# 工业和信息化部公告2014年第41号――符合《稀土行业准入条件》准入条件的企业名单(第五批)

## 工业和信息化部公告（2014年第41号）

根据《稀土行业准入条件》和《稀土企业准入公告管理暂行办法》，经企业申报，省级工业和信息化主管部门核实、专家复核、现场核查、以及网上公示，现将符合《稀土行业准入条件》的企业名单（第五批）予以公告。
