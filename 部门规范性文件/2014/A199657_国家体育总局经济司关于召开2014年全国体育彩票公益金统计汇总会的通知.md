# 国家体育总局经济司关于召开2014年全国体育彩票公益金统计汇总会的通知

各省、自治区、直辖市体育局：

为了贯彻落实总局领导对切实加强公益金使用管理工作的要求，推动公益金统计工作规范化、制度化建设，根据《彩票管理条例》、《彩票管理条例实施细则》、《彩票公益金管理办法》，围绕着加强公益金使用管理，我司开展了彩票公益金统计与绩效评估专项课题研究。

根据工作计划，我司拟召开2014年全国体育彩票公益金统计汇总会。现具体通知如下：

**一、**会议时间

拟定于9月2日-4日召开。2号报到，3号全天、4号上午开会，4号下午离会。

**二、**会议地点

上海奥林匹克俱乐部，地址：上海市徐汇区中山南二路1800号（八万人体育场旁）。

**三、**会议内容

（一）2013年度各省（区、市）体育彩票公益金统计报表填报情况交流、数据汇总；

（二）各省（区、市）体育彩票公益金管理情况讨论交流；

（三）各省（区、市）体育彩票公益金统计工作讨论交流；

（四）公益金报表统计报表制度培训及问题解答。

**四、**参会人员

各省（区、市）体育局公益金管理处室负责人1名；各省（区、市）体育局具体填报汇总责任人1名；总局经济司；总局体彩中心；上海体育学院课题研究组。

**五、**其他事项

（一）本次会议期间食宿费用由会议承担，往返交通费用自理，请提前安排好行程；

（二）请参会人员务必携带2013年度各自省（区、市）体育彩票公益金统计报表的纸质版、电子版参会；

（三）为了便于讨论交流，请各省（区、市）提前准备好关于公益金管理、使用、统计方面的书面交流材料；

（四）请于2014年8月25日（星期一）前将报名表、往返日程表加盖公章传真至总局经济司和上海市体育局；报名表、往返日程表电子版请发送至jjs_cpgyj@163.com。
