# 国家体育总局人事司关于开展2014年总局系统司局级干部选学报名的通知

## 国家体育总局人事司关于开展2014年总局系统司局级干部选学报名的通知（体人字〔2014〕60号）

各厅、司、局，各直属单位：

为全面贯彻落实党的十八大和十八届三中全会精神，深入学习贯彻习近平总书记系列讲话精神，按照中央关于加强和改进干部教育培训、提高干部素质和能力的要求，根据《2013-2017年全国干部教育培训规划》和中组部《关于开展2014年中央和国家机关司局级干部选学工作的通知》（干教函字〔2014〕13号）要求，现就做好2014年总局系统司局级干部选学报名工作有关事项通知如下。

**一、**报名范围

根据中央和国家机关司局级干部选学工作统一安排，总局各厅司局、各直属单位2010年以来未参加过选学的干部均应报名参加。已安排参加2014年中组部调训人员可不参加。

**二、**课程选报及学时要求

（一）必修课。凡参加选学的干部须完成8学时必修课的学习（2013年以来参加过中央党校进修班、中青班学习的干部可不参加）。必修课相关具体安排届时另行通知。

（二）选修课。选修课程累计学习时间一般不少于40学时。参加选学的干部原则上选择1个专题班及若干门讲座（见《2014年中央和国家机关司局级干部选学手册》），如不满40学时，可在中国干部网络学院（www.cela.gov.cn）选学，以达到规定学时。根据中组部给总局下达的选学名额情况，国防大学相关选学课程不列入本次选学报名范围之内。

**三、**有关要求

（一）请各部门、各单位根据《2014年司局级干部选学名额分配表》（附件1）认真做好选学报名工作，并填写《2014年司局级干部选学报名表》（附件2）、《2014年司局级干部选学各单位联络员信息表》（附件3）。

（二）《2014年司局级干部选学报名表》中学号一栏由总局人事司统一填写。

（三）各单位要高度重视干部选学工作，加强选学工作的统筹协调和审核把关，特别要做好干部选学信息的核准工作，确保干部选学学时达到要求。要确定1名相关工作人员担任联络员，做好沟通联络工作，及时了解选学安排等信息，督促本单位参训的司局级干部按时参加学习。

（四）《2014年中央和国家机关司局级干部选学手册》列出了每个专题班的具体举办时间，请报名参训的司局级干部根据工作安排选择选学专题，合理解决工学矛盾，原则上不允许调课或请假。

（五）根据报名工作进度安排，请务必于2月28日（星期五）下班之前完成报名和课程选报工作，并将有关材料纸制版和电子版

同时报送人事司科技干部处，电子版请发至rsskgc@sport.gov.cn。

本通知及附件电子版可在总局网站人事司“文件公告”栏下载。
