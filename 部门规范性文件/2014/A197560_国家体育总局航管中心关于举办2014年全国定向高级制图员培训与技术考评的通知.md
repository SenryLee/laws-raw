# 国家体育总局航管中心关于举办2014年全国定向高级制图员培训与技术考评的通知

## 国家体育总局航管中心关于举办2014年全国定向高级制图员培训与技术考评的通知（航管字〔2014〕329号）

各有关单位：

为了推动定向运动的普及与提高，储备和选拔更多优秀定向运动制图后备人才，我中心定于2014年11月28日至12月2日在广东省肇庆市举办全国定向高级制图员培训与技术考评，现将有关事宜通知如下：

**一、**主办单位：国家体育总局航空无线电模型运动管理中心。

**二、**承办单位：广东省肇庆学院。

**三、**时间和地点：

（一）时间：2014年11月28日至12月2日，其中11月28日报到，12月2日下午离会。

（二）地点：广东省肇庆市。

**四、**主要内容：

（一）培训

1、定向运动地图规范；

2、OCAD制图软件；

3、野外实地测图方法。

（二）培训结业考试

考评内容：

1、理论笔试：包含定向地图规范、定向运动规则、定向地图知识、绘图软件、定向英语、路线设计等；

2、野外实地测图：主要考察野外现地测图的实际能力，重点是测图的质量和速度；

3、OCAD绘图软件：主要考查OCAD绘图软件应用能力，重点是电脑绘图的质量和速度；

4、个人地图作品考评：重点考评定向地图的质量。

向考核成绩60分以上者，颁发2014年全国定向运动制图员培训班结业证书。考核成绩90分以上者可优先选派参加全国性定向比赛制图工作。考核成绩作为申报定向运动制图员等级的主要参考条件。

**五、**报名条件：

热爱定向运动且具有较高定向制图水平者。本次不接受初学者报名。报名后接到地图委员会报名确认者为报名成功。

**六、**经费：

差旅、食宿自理，免收培训费。

**七、**报名与报到：

（一）报名：请于2014年11月20日前将报名表发送至oacmap@126.com。

（二）报到地点：广东省肇庆市肇庆星湖玉兰花度假酒店，每人每天170元（含三餐）。地址：肇庆市北岭七星岩旅游度假区二区（位于肇庆大道北岭山盘古路段，临近肇庆党校）

1、广州到肇庆市的乘车信息：

广州主要城际汽车站都有到肇庆的大巴车，每小时一班。

2、从机场到肇庆市的乘车信息：

广州新白云机场有到肇庆的大巴，每天8：20～22：00，每1小时左右有一班，全程约1.5～2小时到肇庆。
