# 中国水利水电勘测设计协会2014年度全国水利水电勘测设计行业信用等级评价结果公示

根据《全国水利水电勘测设计行业信用评价办法》和《全国水利水电勘测设计行业信用评价办法实施细则》，在会员单位和行业单位自愿申报的基础上，本着"公平、公正、公开、科学"的原则，经协会信用评价专家组评审、信用评价工作委员会审议、协会审定，现对取得2014年度全国水利水电勘测设计行业信用等级单位进行公示，以广泛接受行业和社会监督。公示期为15天。

如有不同意见需要反映，请在公示期内以书面形式将反映情况寄（送）至中国水利水电勘测设计协会（邮寄的材料以邮戳日期为准）。单位反映情况须加盖公章，个人反映情况须签署真实姓名，并留下联系电话。
