# 工业和信息化部办公厅关于做好2014年工业企业知识产权运用能力培育工程工作的通知

有关省、自治区、直辖市及计划单列市、新疆生产建设兵团工业和信息化主管部门：

2014年是工业企业知识产权运用能力培育工程（以下简称培育工程）深化实施之年。为贯彻落实十八届三中全会关于“加强知识产权运用和保护”的精神、国务院《工业转型升级规划（2011-2015年）》有关知识产权工作的部署，指导和推动各地结合实际开展培育工作，现就做好2014年工业企业知识产权运用能力培育工程工作通知如下：

**一、**工作思路

围绕工业转型升级的关键环节，强化企业的主体意识，以工业企业知识产权管理制度建设为重点，着力发挥地方工业和信息化主管部门的推动作用，将知识产权运用能力培育工作与相关政策措施紧密结合，提升企业运用知识产权参与市场竞争的能力。

**二、**主要目标

在1000家企业宣贯与推广《工业企业知识产权管理指南》（以下简称《指南》），80%的培育工程试点企业（以下简称“试点企业”）建立知识产权管理制度；制定《工业企业知识产权运用能力评估指标》（以下简称《评估指标》）；选拔一批省级知识产权运用示范企业；试点企业知识产权获得数量年均增长15%以上；在8个省市开展知识产权运用试点。

**三、**重点工作

（一）推动企业建立知识产权管理制度

部组织省市和支撑机构在试点企业开展10期《指南》宣贯与解读活动，组织专家分片区开展帮扶咨询活动，指导试点企业根据《指南》功能模块加强管理制度建设；总结试点企业典型做法，汇编企业知识产权运用案例集，推广成功经验。

（二）开展知识产权实务培训

省市结合本地知识产权运用能力培育工作的基础和条件，面向企业知识产权主管和相关业务人员，开展知识产权实务培训。部根据地方需求，整合专家资源，建立专家团队，分类分主题分区域开展知识产权专题培训10次以上。

（三）制定《评估指标》，指导试点企业开展评估

部组织省市和支撑机构制定《评估指标》。省市参照《评估指标》将企业知识产权运用能力培育与推动企业技术创新的措施手段相结合，指导、督促试点企业对照《评估指标》开展检查评估和改进。省市结合评估工作选拔省级知识产权运用示范企业，为2015年树立知识产权运用标杆企业打好基础。

（四）开展知识产权运用试点

省市围绕工业转型升级关键环节，增强本地区培育工程与相关政策的关联性，积极争取地方政府资金支持，开展特色产业或产业聚集区知识产权运用。在创新体系建设、品牌建设、标准制定、成果应用推广等方面做好政策措施的衔接，探索形成运用知识产权支撑工业转型升级的路径与机制。

（五）加大宣传与经验交流力度

部组织“媒体走进试点”系列报道，充分利用部属报刊和网站等媒体开辟专栏专题，宣传试点企业成功案例、省市培育工程推进成效；定期出版《工业知识产权运用能力培育工程专刊》；在全国知识产权宣传周和中国专利周期间集中展示工业和信息化系统推动知识产权运用工作的成效，召开知识产权运用能力培育工作经验交流会。

**四、**有关要求

（一）请按照《工业和信息化部关于实施工业企业知识产权运用能力培育工程的通知》（工信部科[2012]391号）以及本通知的要求，因地制宜制订本地区2014年度培育工程工作方案，采取有力措施推进培育工程，并于2月28日前将工作方案报部（科技司）。

（二）请根据本地工作实际，做好第二批试点企业增报工作，更新第一批试点企业2013年度信息，填报《工业企业知识产权运用能力培育工程试点企业信息表》（附件1），于2月28日前报部（科技司）。

（三）请省市组织试点企业填报《2014年培育工程试点企业知识产权培训需求情况表》（附件2），于2月28日前反馈部（科技司）。

（四）请省市结合本地工作实际，视情况填报《2014年省市拟开展知识产权运用工作项目申报表》（附件3），于2月10日前报部（科技司）。我部将依据申报情况，遴选知识产权运用试点项目纳入《2014年工业和信息化部知识产权推进计划》予以支持。
