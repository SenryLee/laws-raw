# 中国民用航空局运输司关于2014年夏秋航季颁发、撤/注销国内航线经营许可情况的信息通告(二)

## 中国民用航空局运输司关于2014年夏秋航季颁发、撤/注销国内航线经营许可情况的信息通告（二）

经民航局航空运输（通用航空）委员会审议通过，现将2014年夏秋航季季中第二批新增涉及北京、上海、广州三大城市机场的区际国内航线经营许可颁发、撤/注销情况和在部分航线上增加班次情况通告如下：

1、核准航线经营许可

国航等5家航空公司新增属核准范围的国内航线经营许可10条，共132班。东航等4家航空公司在属核准范围的12条航线上每周共增加162个航班。

2、登记航线经营许可

东航等6家公司新增属登记范围的国内航线经营许可11条，共140班（含货运航线经营许可2条，共14班）。东航等5家公司在属登记范围的27条航线上每周共增加370个航班。

3、撤/注销国内航线经营许可

撤销川航1家航空公司属核准范围的国内航线经营许可1条；注销南航和川航2家航空公司属登记范围的国内航线经营许可共4条。（以上详见附表）
