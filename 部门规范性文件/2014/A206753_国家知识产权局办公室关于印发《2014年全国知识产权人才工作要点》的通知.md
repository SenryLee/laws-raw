# 国家知识产权局办公室关于印发《2014年全国知识产权人才工作要点》的通知

## 国家知识产权局办公室关于印发《2014年全国知识产权人才工作要点》的通知（国知办发人字﹝2014﹞4号）

各省、自治区、直辖市、新疆生产建设兵团知识产权局；局机关各部门，专利局各部门，局直属各单位、各社会团体：

经局批准，现将《2014年全国知识产权人才工作要点》印发，请结合实际贯彻落实。

特此通知。

国家知识产权局办公室

2014年1月29日

2014年全国知识产权人才工作要点

2014年全国知识产权人才工作总体要求是，深入学习贯彻党的十八大、十八届二中、三中全会精神，坚持党管人才原则，以科学人才观为指导，围绕中心，服务大局，深化改革，攻坚克难，落实国家中长期人才发展规划和知识产权人才“十二五”规划，完善知识产权人才体系，实施重大人才工程计划，全面推进知识产权人才队伍建设，为实施国家知识产权战略、推动创新驱动发展提供人才支撑。

**一、**学习贯彻党的十八大、十八届二中、三中全会精神

（一）加强知识产权人才工作创新。认真学习党的十八大、十八届二中、三中全会关于人才工作的新思想，巩固党的群众路线教育实践活动成果，深入研究知识产权人才成长规律，加大知识产权人才工作创新力度，以市场配置知识产权人才资源，将知识产权人才潜力转化为人才红利。

（二）加大知识产权人才宣传力度。深入解读和广泛宣传中央对人才工作的新要求新部署，利用人才工作简报、知识产权报、知识产权人才信息网络平台等媒体宣传全国知识产权人才工作的新举措新成效，树立知识产权人才典型，营造有利于知识产权人才成长发展的良好氛围。

**二、**贯彻落实国家中长期人才发展规划

（三）推动制定知识产权保护政策。推动《职务发明条例》《知识产权保护信用评价办法（试行）》等知识产权保护政策的制定出台，加大创新创业人才服务支持力度，搭建激发知识产权创造、运用、保护和管理的政策环境。

（四）落实专业技术人才知识更新工程。加强专业技术人才知识产权培训，联合人力资源社会保障部举办专业技术人才知识产权高级研修班，培养现代服务业急需紧缺的知识产权人才。发挥国家级专业技术人员继续教育基地（中国知识产权培训中心）的作用，加强远程网络平台和教材建设。

**三、**加强知识产权人才体系建设

（五）健全人才体系建设工作运行机制。建立全国知识产权人才重要事项报送制度，健全知识产权人才工作督促落实机制。推动各省级知识产权局落实人才体系目标任务，建立各省（区、市）知识产权人才工作会议制度。

（六）完善知识产权人才评价发现机制。建立和完善知识产权人才的专业技术评价体系，推动设立面向知识产权专业技术人员的专业技术职务任职资格评定制度和专利管理师、专利信息分析师等职业能力认证制度。

（七）推动高校知识产权人才培养。积极推动高校设立知识产权学院，加强知识产权学科建设，加大知识产权人才培养力度。推动建立国家知识产权人才培养基地。举办高校知识产权师资培训班、知识产权暑期学校等培训项目。

（八）大力开展知识产权人才培训。研究制定全国知识产权教育培训分类指导大纲，制定《国家知识产权局干部教育培训规划》，建立分级分类的教育培训体系。打造全国知识产权局局长高级研修班等精品示范项目。

**四、**实施重大人才工程和计划

（九）培养知识产权高层次人才。选拔120名全国知识产权领军人才和120名百千万知识产权人才工程百名高层次人才培养人选，举办国内外知识产权人才高端培训。充分发挥领军人才的示范引领作用，带动知识产权人才队伍整体发展。

（十）建设国家知识产权培训基地。制定出台《关于加强国家知识产权培训基地工作的意见》，突出基地特色，共享培训资源，培养师资队伍，探索研究国家中小微企业知识产权培训基地运行模式及人才培养途径。

（十一）加强人才信息网络平台管理。出台《国家知识产权人才库和人才信息网络平台管理办法》，整合人才信息资源，提高知识产权人才公共服务能力，推动省级知识产权局建设本地区知识产权人才库。

**五、**夯实知识产权人才工作基础

（十二）开展知识产权人才调查研究。深入企业、服务业进行知识产权人才专题调研，了解知识产权人才需求，围绕中小微企业人才培养、企业知识产权人才状况等开展软课题研究，为制定知识产权人才工作政策提供依据和参考。

（十三）加强知识产权人才工作队伍建设。加强对人才工作队伍的培养培训和实践锻炼，提升人才工作队伍改革创新、理论研究、沟通协调等方面的能力和水平，促进知识产权人才工作的科学化水平不断提高。
