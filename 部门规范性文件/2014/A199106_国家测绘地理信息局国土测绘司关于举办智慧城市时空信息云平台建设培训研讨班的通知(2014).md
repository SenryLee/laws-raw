# 国家测绘地理信息局国土测绘司关于举办智慧城市时空信息云平台建设培训研讨班的通知(2014)

## 国家测绘地理信息局国土测绘司关于举办智慧城市时空信息云平台建设培训研讨班的通知（测国土函〔2014〕42号）

各省、自治区、直辖市测绘地理信息行政主管部门：

为做好智慧城市时空信息云平台建设技术指导，推动试点工作有效开展，定于近期开展培训研讨工作，有关事项函告如下。

**一、**培训时间

报到：2014年9月24日

培训：2014年9月25－26日

**二、**培训地点

山东省济南市美得乐大酒店

地址：济南市历下区历山路74号

联系电话：0531－66577777

**三、**参加人员

各省、自治区、直辖市测绘地理信息行政主管部门选派3名从事数字城市、智慧城市建设管理或技术工作的人员参加培训。

**四、**主要内容

1．国家测绘地理信息局关于智慧城市时空信息云平台建设试点工作的总体安排；

2．国内外智慧城市建设的有关情况；

3．智慧城市时空信息云平台建设要点与技术指南解读；

4．智慧济宁时空信息云平台案例介绍；

5．技术问题研讨。

**五、**其他

1．请各省、自治区、直辖市测绘地理信息行政主管部门汇总本地参加培训人员名单，统一填写培训回执（见附件），并于9月19日前分别传真反馈至国家测绘地理信息局和山东省国土资源厅，需要接机、接站的请明确航班号或车次。

2．请中国测绘科学研究院做好培训内容及授课工作准备，请山东省国土资源厅协助做好有关培训会务工作。
