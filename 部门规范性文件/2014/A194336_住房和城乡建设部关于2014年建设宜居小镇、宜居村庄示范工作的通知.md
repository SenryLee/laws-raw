# 住房和城乡建设部关于2014年建设宜居小镇、宜居村庄示范工作的通知

## 住房和城乡建设部关于2014年建设宜居小镇、宜居村庄示范工作的通知（建村函[2014]105号）

各省、自治区住房城乡建设厅，直辖市建委（建交委、农委），新疆生产建设兵团建设局：

为贯彻落实党的十八大、中央城镇化工作会议以及中央农村工作会议精神，现将2014年建设宜居小镇、宜居村庄（以下简称宜居村镇）示范有关工作通知如下：

**一、**开展不同层次的宜居村镇示范工作

各地要按照宜居村镇示范指导性要求，做好宜居村镇示范工作，并将具有广泛示范意义的镇和村庄向我部推荐。要组织开展好省、市、县各级宜居村镇示范，探索符合本地实际的宜居村镇建设目标和具体方法，形成不同类型的宜居村镇建设优秀范例，制定基本要求或标准，指导宜居村镇建设。

**二、**组织报送2014年宜居村镇示范材料

请各省（区、市）住房城乡建设部门根据本地宜居村镇示范开展情况，按自愿、择优的原则推荐3个建制镇和3个行政村作为候选，于2014年9月15日前将有关示范材料报送我部。我部将组织专家审查和实地调研，审核后公布2014年建设宜居小镇、宜居村庄示范名单。

示范材料包括宜居小镇、宜居村庄材料表、说明材料和有关视频材料（可选）。宜居小镇示范材料表按附件3填报，宜居村庄示范材料表按附件4填报，同时提交纸质材料与电子文档。说明材料包括小镇、村庄简介，对照示范材料表内容逐项以文字、照片和图纸等方式进行说明（其中宜居村庄应对所辖20户以上自然村逐一说明“宜居”内容），照片应拍摄于一年内，统一制作成A3横向版式的PPT文件提交。视频材料时长不超过5分钟，文件格式不限。材料表、说明材料和视频文件可视情况提供光盘或U盘。
