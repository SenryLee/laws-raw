# 国家档案局2013年度政府信息公开工作年度报告

## 国家档案局2013年度政府信息公开工作年度报告（2014年3月）

本报告根据《中华人民共和国政府信息公开条例》（以下简称《条例》）要求编制，由开展政府信息公开工作情况、主动公开政府信息情况、依申请公开政府信息情况、咨询处理情况、存在问题和改进措施等组成。本年度报告中所列数据的统计期限自2001年1月1日起至2013年12月31日止。本年度报告的电子版可在国家档案局政府网站（www.saac.gov.cn）下载。如对本年度报告有疑问，请与国家档案局办公室联系。地址：北京市西城区丰盛胡同21号邮编：100032联系电话：010-66176354

按照《条例》的要求，现将2013年度国家档案局政府信息公开工作年度报告公布如下：

**一、**政府信息公开工作总体情况

2013年，档案局政府信息公开工作总体运行状况良好，进一步完善了各项工作制度，加强政府信息公开队伍建设，增强软硬件设施的配备，在以下几方面取得了一些成效。

（一）出台有关办法，进一步规范政府信息公开报送工作

2013年6月18日，《国家档案局政府网站管理办法（试行）》（以下简称《办法》）正式出台。这是继《国家档案局政府信息公开工作管理办法（试行）》《国家档案局政府信息公开指南》之后，档案局出台的又一涉及政府信息公开工作的规范性文件。《办法》中多处涉及政府信息公开工作，并对信息报送、内容审核、监督、考核等工作作了明确规定。

1. 明确规定局属各部门、各单位要指定1名业务骨干作为网站信息员，负责监督已确定公开的政府信息及时上网公布等工作。网站信息员实行备案制，因换岗、调动等原因调整时，及时报备更新。

2. 明确规定除法定保密事项外，信息内容必须按照《条例》要求，遵循“准确、权威、及时”和“谁发布，谁负责；谁承诺，谁办理”的原则，在政府网站上予以公开。

3. 明确建立信息报送责任制度和上网审批制度，同时对审核内容进行了具体说明。

4. 明确建立信息报送考评制度并制定了详细的考评规定，按年度评选先进单位和优秀信息员。

（二）举办培训班，进一步提高政府信息公开报送工作认识

根据实际工作情况，档案局专门举办了为期2天的信息员培训班，学习有关办法的同时，普及政府信息公开理念及基本知识，以点带面，从提高信息员对政府信息公开工作的认识入手，进一步增强做好档案局政府信息公开工作的能力。

（三）增加网站安全检测项目，进一步保证政府公开信息安全

档案局政府信息公开的主要渠道是通过国家档案局官方网站发布，网站的安全直接关系到政府公开信息的安全。今年，档案局与运维公司协商，在原有网站安全检测服务项目的基础上，增加了网络连通性检测、网页篡改检测、网页挂码检测和敏感信息检测等四项服务，使网页信息的安全性有了大幅度提升。

（四）多方增加途径，进一步拓宽政府信息公开渠道

在国家档案局官方网站、中央国家机关政府信息查阅中心公布政府信息的同时，档案局还积极探索其他公开渠道，分别通过《中国档案报》《中国档案》杂志以及档案年鉴等媒介，公开公布有关政府信息，进一步扩大信息的受众面，增强其影响力。

（五）继续强化学习，进一步提升政府信息公开工作服务水平

2013年，档案局中央国家机关政府信息查阅中心工作人员进一步加强业务学习，利用中央国家机关政府公开信息查阅管理系统为广大查阅者提供服务。特别是对于不懂电脑操作、不知道自己需要哪些具体文件的查阅群众，工作人员根据其诉求，通过自己的工作经验和业务知识帮助其查找，得到了查阅者的肯定。

**二、**主动公开政府信息情况

（一）国家档案局政府公开信息的主要内容

截至2013年底，累计主动公开2001年至2013年国家档案局政府公开信息330条，全文电子化率为100%。其中，2013年主动公开政府信息19件。

在累计主动公开的政府信息中，会议文件类信息55条，占总数的17%；政策法规、标准类信息87条，占总数的26%；档案馆（室）工作类信息69条，占总数的21%；经济科技、农业农村档案工作类信息43条，占总数的13%；档案宣传、教育工作类信息20条，占总数的6%；档案科技工作类信息40条，占总数的12%；档案工作对外交流类信息7条，占总数的2%；机关事务类9条，占总数的3%。在2013年主动公开的19件政府信息中，会议文件类信息3条，占总数的16%；政策法规、标准类信息3条，占总数的16%；档案馆（室）工作类信息3条，占总数的16%；经济科技、农业农村档案工作类信息1条，占总数的5%；档案宣传、教育工作类信息4条，占总数的21%；档案科技工作类信息2条，占总数的10%；机关事务类3条，占总数的16%。

1.公开了会议类文件，如《国家档案局中央档案馆关于印发全国档案局长馆长会议文件的通知》《国家档案局关于印发全国社会主义新农村建设档案工作示范县经验交流会文件的通知》和《国家档案局办公室关于印发全国数字档案馆（室）建设推进会文件的通知》。

2.公开了政策法规、标准类文件，如《档案管理违法违纪行为处分规定》和《国家档案局办公室关于编制2013年制修订档案行业标准项目计划的通知》。

3.公开了档案馆（室）工作类文件，如《国家档案局办公室关于市、县级国家综合档案馆测评工作进展情况的通报》和《国家档案局关于严格执行财政部、发展改革委关于取消利用档案收费规定的通知》。

4.公开了经济科技、农业农村档案工作类文件，如《集体林权制度改革档案管理办法》。

5.公开了档案宣传、教育工作类文件，如《国家档案局关于印发〈2013年全国档案宣传工作要点〉的通知》和《国家档案局印发〈关于开展向朱志伟同志学习活动的决定〉的通知》。

6.公开了档案科技工作类文件，如《国家档案局办公室关于组织推荐2013年国家档案局科技项目的通知》和《档案信息系统安全等级保护定级工作指南》。

7.公开了机关事务类文件，如《国家档案局2012年度部门决算》和《国家档案局2013年部门预算》。

（二）中央国家机关政府公开信息查阅中心工作情况

中央国家机关政府公开信息查阅中心汇集了2001年至2013年国家档案局主动公开的政府信息纸质目录330条、纸质文件330件；全年共征集和接收全国人大、国务院办公厅、环境保护部、审计署、民政部、商务部等国家部委以及北京、天津、西安、浙江省等人民政府的公报或公告（文告）268期，共364份；接待公众查阅国家档案局及其他中央国家机关政府公开信息632人次，提供政府公开信息1788件（份），打印（复印）信息资料17368页，邮寄、传真18件。在政府信息公开工作中，档案局未收取任何费用，不存在违规收费问题。

**三、**依申请公开政府信息情况

中央国家机关政府公开信息查阅中心负责现场办理依申请公开政府信息手续。

（一）申请情况及申请处理情况

本年度受理依申请公开国家档案局政府信息5件，依申请公开1件，其余4件不属于政府信息公开范围。

（二）申请行政复议及提起行政诉讼情况

本年度共接到申请行政复议4人次，均及时依法予以受理。

本年度未接到行政诉讼。

**四、**咨询处理情况

2013年共接受公民咨询19人次，其中，主要为电话咨询，全部予以答复。

**五、**存在的主要问题和改进措施

（一）存在的主要问题

一是政府信息公开的内容亟需丰富；二是政府信息公开工作监督考核机制有待完善；三是政府信息公开宣传力度尚需加大。

（二）改进措施

一是继续主动向其他单位取经，积极学习和借鉴政府信息公开工作的经验和好做法，拓宽思路，丰富公开信息的内容；二是继续梳理工作流程，积极推动各部门各单位信息报送内部制度建设，保证政府信息公开工作按照既定的流程有效运作；三是加强对政府信息起草者及审批者的宣传培训力度， 从源头进一步加强政府信息公开工作。
