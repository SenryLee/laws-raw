# 商务部关于印发《2014年度甘草及甘草制品出口配额第二次招标中标企业名单及其额度表》的通知

根据《出口配额招标办法》及《工业品出口配额招标实施细则》的有关规定，出口商品配额招标委员会对2014年度甘草及甘草制品出口配额进行了第二次招标，并确定了中标企业和中标数量。现将《2014年度甘草及甘草制品出口配额第二次招标中标企业名单及其额度表》印发给你们。各中标企业一律凭商务部下达的中标企业中标数量和招标委员会下发的《申领配额招标商品出口许可证证明书》申领出口许可证。请各有关发证机关严格按照相关规定核发出口许可证。

附件：2014年度甘草及甘草制品出口配额第二次招标中标企业名单及其额度表

商务部

2014年7月28日
