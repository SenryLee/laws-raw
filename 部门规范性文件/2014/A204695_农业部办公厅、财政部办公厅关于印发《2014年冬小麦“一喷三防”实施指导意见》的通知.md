# 农业部办公厅、财政部办公厅关于印发《2014年冬小麦“一喷三防”实施指导意见》的通知

## 农业部办公厅、财政部办公厅关于印发《2014年冬小麦“一喷三防”实施指导意见》的通知（农办财〔2014〕24号）

相关省（自治区、直辖市、计划单列市）农业（农牧、农村经济）厅（局、委、办）、财政厅（局），新疆生产建设兵团农业局、财务局：

为贯彻落实中央1号文件和中央农村工作会议精神，大力推广应用农业防灾减灾稳产增产关键技术，提高农业防灾减灾能力，今年在冬小麦主产区组织实施“一喷三防”技术。为保证各地扎实开展相关工作，我们研究制定了《2014年冬小麦“一喷三防”实施指导意见》，现印发给你们，请遵照执行。
