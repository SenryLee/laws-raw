# 水利部关于2014年水利工程建设监理单位资质延续审核结果的公示

根据《水利工程建设监理规定》（水利部令第28号）和《水利工程建设监理单位资质管理办法》（水利部令第29号公布，水利部令第40号修改）规定，我部开展了2014年度水利工程建设监理单位资质延续审核工作，现将审核结果予以公示（见附件）。如有异议，请在公示期内以实名反映或举报。

公示时间：2014年10月28日至11月3日

受理部门：水利部建设与管理司

联 系 人：熊平 王竑

联系电话：010-63202982、63202715

电子信箱：jgs@mwr.gov.cn

通信地址：北京市西城区白广路二条二号

邮 编：100053

请各流域机构、各省（区、市）水利（水务）厅（局）转登到本单位门户网站，同步公示。
