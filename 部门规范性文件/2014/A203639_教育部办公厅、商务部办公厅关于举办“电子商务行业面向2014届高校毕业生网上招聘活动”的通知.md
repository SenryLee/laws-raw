# 教育部办公厅、商务部办公厅关于举办“电子商务行业面向2014届高校毕业生网上招聘活动”的通知

## 教育部办公厅、商务部办公厅关于举办“电子商务行业面向2014届高校毕业生网上招聘活动”的通知（教学厅函[2014]15号　2014年5月4日）

各省、自治区、直辖市教育厅（教委）、商务主管部门，计划单列市及新疆生产建设兵团教育局、商务主管部门，有关省、自治区人力资源社会保障厅（局）、福建省公务员局，教育部直属各高等学校：

为贯彻落实党的十八届三中全会精神，进一步拓宽高校毕业生就业渠道，促进以高校毕业生为重点的青年就业工作，同时满足电子商务行业人才需求，经研究，定于5月20日-6月2日举办“电子商务行业面向2014届高校毕业生网上招聘活动”。现将有关事项通知如下：

**一、**此项活动由教育部和商务部主办，教育部全国高等学校学生信息咨询与就业指导中心承办，全国大学生就业公共服务立体化平台（新职业网www.ness.org.cn）提供技术支持。活动期间，企业招聘信息和高校毕业生求职信息将在新职业网免费发布，供企业和高校毕业生浏览查询。

**二、**各省级高校毕业生就业主管部门和高等学校要积极宣传、组织应届高校毕业生参加本次网上招聘会，提前做好各项准备工作。各地商务主管部门要及时将本通知精神传达给辖区内相关电子商务企业，企业用人单位要根据岗位空缺和需求情况，认真做好需求信息的收集整理、上报等相关准备工作。

**三、**活动期间，各省级高校毕业生就业主管部门、各高校就业工作部门须将招聘活动图标置于所属就业网站显著位置，并与新职业网活动专题页面做相关链接，以引导更多企业及高校毕业生参与到此次活动中。为提高高校毕业生与企业对接成功率，各级高校毕业生就业主管部门可根据当地实际情况，以此次活动为契机，组织电子商务企业走进校园，举办多种类型的校园现场招聘活动。

**四、**请参与网上招聘活动的企业按统一数据格式和要求，将招聘信息以电子邮件或传真方式于5月18日前报送教育部全国高等学校学生信息咨询与就业指导中心，报送格式及要求详见附件。
