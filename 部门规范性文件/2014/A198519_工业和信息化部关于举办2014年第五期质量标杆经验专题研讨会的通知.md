# 工业和信息化部关于举办2014年第五期质量标杆经验专题研讨会的通知

## 工业和信息化部关于举办2014年第五期质量标杆经验专题研讨会的通知（工科函[2014]291号　2014年9月22日）

江苏省、内蒙古自治区、上海市、浙江省、安徽省和新疆维吾尔自治区工业和信息化主管部门，工业和信息化部电子第五研究所、中国质量协会，有关综合性行业协会，有关工业企业：

根据《工业和信息化部办公厅关于组织开展2014年工业企业质量标杆学习交流活动的通知》（工信厅科函[2014]392号）有关工作要求，我司定于10月16至17日在江苏省无锡市举办2014年第五期质量标杆经验专题研讨会。现将有关事项通知如下：

**一、**会议内容

（一）质量标杆经验分享

1. 巨石集团有限公司介绍实施卓越绩效模式的经验；

2. 北新集团建材股份有限公司介绍实施全面质量管理的经验；

3. 红豆集团有限公司介绍基于客户需求的服务接触点管理的实践经验；

4. 江苏东渡纺织集团有限公司介绍实施“六精六细”管理的经验；

5. 宇龙计算机通信科技（深圳）有限公司介绍实施卓越绩效模式的经验。

（二）企业质量诊断

会议期间安排质量管理专家与参会企业代表进行座谈，针对质量经营提出诊断建议。

1．诊断团队：质量专家、经验丰富的企业管理者；

2．诊断方向：质量经营；

3．参加此诊断的企业请于10月10日前向我司报名。

（三）企业现场交流

参观质量标杆所在企业，开展交流互动活动。

**二、**活动时间和地点

活动时间：10月16（周四）至17日（周五），9：00-18：00，会期两天。

报到时间：10月15日14：00-20：00

活动地点：锡州花园酒店

酒店电话： 0510-88686888

酒店地址：江苏省无锡市锡山区二泉中路68号

**三、**参会人员

有关省（市）工业和信息化主管部门负责质量工作的人员；工业企业负责质量工作的高层管理人员和业务骨干；工业行业协会负责质量工作的人员，质量协会负责人；其他相关企业质量管理人员。

**四、**其它事项

1、本次活动由工业和信息化部科技司主办，江苏省经济和信息化委员会、中国质量协会承办。

2、请各位质量标杆经验介绍嘉宾准备ppt材料，时间40分钟（介绍30分钟，交流10分钟），请于9月30日前将ppt发送至qmb@caq.org.cn。

3、请各省（市）工业和信息化主管部门负责组织本地区企业代表参会；请工业行业协会组织本行业企业代表参会。

4、请各位代表于10月10日前将《会议回执》（见附件2）发送至中国质量协会。中国质量协会将在会前及时把参会人员汇总反馈至各有关工业和信息化主管部门。

5、本次活动会议资料及活动不收费，会议代表交通、食宿费用由参会单位自理。

附件3：

乘车线路

**一、**无锡项放苏南国际机场到锡州花园酒店路线

乘机场大巴至无锡火车站，在南广场换乘80、100路公交车在柏庄桥下车，向东直行200米过一个十字路即到，在北广场换乘93路公交车在锡山区政府站下车，向北直行200米过一个十字路即到。

**二、**无锡火车站到锡州花园酒店路线

1）在火车站南广场乘坐80、100路公交车在柏庄桥下车，向东直行200米过一个十字路即到。

2）在火车站北广场乘坐93路公交车在锡山区政府站下车，向北直行200米过一个十字路即到。

**三、**无锡高铁东站到锡州花园酒店路线

可在高铁东站乘坐722路公交车在柏庄桥下车，向东直行200米过一个十字路即到。

**四、**走沪宁高速至酒店的路线

在沪宁高速无锡东出口下，不要上高架，延地面路线直行至东亭路，右转上东亭路，往北直行至二泉路，左转上二泉路直行200米即到锡州花园酒店。
