# 中国农机化信息网信息中心关于推荐中国农机化信息网2014年度好信息的通知

各中国农业机械化信息网信息员：

为激励各地信息员撰写和提交农业机械化方面的新闻报道、文章和信息，特别是鼓励信息员实地采访、进行原创的积极性，提高农机化信息宣传工作质量水平，中国农业机械化信息网信息中心决定启动2014年度好信息评选工作。现将有关事项通知如下：

**一、**推荐作品入选条件

1．必须是中国农业机械化信息网信息员原创作品；

2．必须是在中国农业机械化信息网上登载过的；

3．推荐作品登载时间段自2013年10月1日至2014年9月30日。

**二、**推荐作品数量

推荐作品数量不限。作品查询可在中国农业机械化信息网首页进行高级搜索。

**三、**推荐作品截止日期及报送方式

请在2014年10月20日前，将所推荐作品按照信息员常规提交信息方式报送（各地动态栏目）。提交推荐作品时请注明作品标题及网上登载时间。
