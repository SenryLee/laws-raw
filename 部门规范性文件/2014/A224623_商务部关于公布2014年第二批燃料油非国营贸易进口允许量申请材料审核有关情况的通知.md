# 商务部关于公布2014年第二批燃料油非国营贸易进口允许量申请材料审核有关情况的通知

根据商务部2013年第69号公告《公布2014年成品油（燃料油）非国营贸易进口允许量申领条件、分配原则和相关程序》（以下简称《公告》）要求，中国五矿化工进出口商会对第二批新申请2014年燃料油非国营贸易进口允许量企业报送的材料进行了审核，商务部外贸司对审核情况进行了复审。截止2014年2月28日，共有29家企业报送了申请材料，其中符合《公告》要求的有21家企业。现将材料齐全企业名单进行公示（附件1），公示期为2014年3月20-26日。公示期间，对公示名单有异议的，可向商务部（外贸司）提请公示复核。同时公布材料不齐全企业名单及所缺材料（附件2），公示期间，各相关企业仍可将补充材料报送至商务部外贸司，同时抄送中国五矿化工进出口商会。
