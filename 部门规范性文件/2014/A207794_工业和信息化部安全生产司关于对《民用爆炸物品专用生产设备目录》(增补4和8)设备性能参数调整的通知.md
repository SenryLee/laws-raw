# 工业和信息化部安全生产司关于对《民用爆炸物品专用生产设备目录》(增补4和8)设备性能参数调整的通知

## 工业和信息化部安全生产司关于对《民用爆炸物品专用生产设备目录》（增补4和8）设备性能参数调整的通知（工安函[2014]4号）

各省、自治区、直辖市民爆行业行政主管部门：

经审定，同意对《民用爆炸物品专用生产设备目录》（增补4和8）中所公告的石家庄成功机电有限公司的胶状乳化炸药装药机（CRDZY型（直式）和CRDZY型（盘式））的装药规格和产能范围调整如下，特此通知。

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 设备规格型号 | 适用的直径范围 | 产能范围 |
| 1 | CRDZY型（直式） | Φ60mm～Φ200mm | 3.6t/h～6.0t/h |
| 2 | CRDZY型（盘式） | Φ27mm～Φ50mm | 2.0t/h～5.4t/h |
| 3 | Φ50mm～Φ120mm | 4.6t/h～6.0t/h |

2014年1月8日
