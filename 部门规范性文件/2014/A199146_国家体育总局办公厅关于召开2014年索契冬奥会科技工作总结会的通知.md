# 国家体育总局办公厅关于召开2014年索契冬奥会科技工作总结会的通知

## 国家体育总局办公厅关于召开2014年索契冬奥会科技工作总结会的通知（体科字【2014】114号）

各有关单位：

为全面总结2014年索契冬奥会科研攻关与科技服务工作，研究部署备战2018年平昌冬奥会科技工作，经研究，决定召开2014年索契冬奥会科技工作总结会。现将有关事宜通知如下：

**一、**会议时间及地点

（一）时间：2014年9月10日14：00-16：30。

（二）地点：国家体育总局办公楼201会议室。

**二、**会议内容

（一）总局领导讲话。

（二）科教司领导作2014年索契冬奥会科技工作总结报告。

（三）对第22届冬奥会科研攻关与科技服务项目贡献奖进行表彰，对在2014年索契冬奥会科研攻关与科技服务中做出突出贡献的单位和个人进行表扬。

（四）获奖代表作经验报告。

**三、**参会人员

（一）受表彰的科研项目负责人、合作单位代表和先进个人。

（二）备战2014年冬奥会科技专家组有关人员。

（三）总局科教司、竞技体育司、体育经济司、人事司、宣传司领导。

（四）冬季运动管理中心领导、相关项目部及科研部门负责人、相关运动项目主总教练代表。

（五）黑龙江省、吉林省、辽宁省体育局分管领导、职能处室负责人及体育科学研究所负责人。

（六）总局体育科学研究所、运动医学研究所、反兴奋剂中心、北京体育大学、体育信息中心主要领导及职能处室负责人。

（七）沈阳体育学院、哈尔滨体育学院、吉林体育学院主要领导及职能处室负责人。

**四、**具体要求

（一）会议报到地点为天坛饭店。京外参会人员请于9月10日上午11点前报到。京内参会人员请于9月10日下午13：30前直接到会议地点报到。京外代表食宿由大会负责安排。

（二）参会人员自行参会，往返交通费自理。

（三）请各有关单位负责通知本单位获奖的科研项目负责人、合作单位代表和先进个人，并统一填写报名回执。

（四）请务必于9月5日17：00前将报名回执传真至冬季运动管理中心科研信息部。
