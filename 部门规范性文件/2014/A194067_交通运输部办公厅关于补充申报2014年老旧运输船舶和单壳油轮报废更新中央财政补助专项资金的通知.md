# 交通运输部办公厅关于补充申报2014年老旧运输船舶和单壳油轮报废更新中央财政补助专项资金的通知

各省、自治区、直辖市交通运输厅（委）：

今年5月份申报的2014年老旧运输船舶和单壳油轮报废更新中央财政补助专项资金已经拨付。为加快推进老旧运输船舶和单壳油轮报废更新工作，请各单位按资金管理办法（财建〔2014〕24号）补充申报2014年老旧运输船舶和单壳油轮报废更新中央财政补助专项资金。现将有关事项通知如下：

**一、**申报内容

2014年9月15日前，各单位向部水运局报送以下材料（含电子版）：

（一）除今年5月份已申报的船舶外，2013年1月1日至2014年8月31日已拆解船舶、对应新建完成船舶情况以及资金需求汇总表（表格格式见附件1）。

（二）除今年5月份已申报的船舶外，2014年9月1日至2014年12月31日拟拆解船舶、对应拟新建船舶情况以及资金需求汇总表（表格格式见附件2）。

**二、**有关要求

（一）对于今年上半年已拨付的中央财政资金，各单位应配合省级财政部门做好资金下达工作，督促市级交通运输主管部门会同同级财政部门将补助资金及时发放给申请企业。

（二）对于此次补充申报的资金，各级交通运输主管部门应加强审核，防止数据虚报、漏报，同时加强组织实施力度，督促申请企业按计划拆解和新建船舶，保证政策实施效果。
