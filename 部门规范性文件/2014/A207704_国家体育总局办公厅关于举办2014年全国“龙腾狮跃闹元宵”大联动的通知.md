# 国家体育总局办公厅关于举办2014年全国“龙腾狮跃闹元宵”大联动的通知

各省、自治区、直辖市、计划单列市、新疆生产建设兵团体育局，总参军训部军事体育训练局、总政宣传部文化体育局，各行业体协：

经国家体育总局批准，全国“龙腾狮跃闹元宵”大联动已连续举行了7年，产生了很好的社会影响，有力的推动了舞龙舞狮运动的发展。为进一步打造这一品牌活动，营造健康欢乐的节日气氛，定于2014年元宵节期间继续举行全国“龙腾狮跃闹元宵”大联动活动。为确保活动圆满成功，现将有关事项通知如下：

**一、**活动名称

2014年全国“龙腾狮跃闹元宵”大联动

**二、**主办单位

国家体育总局社会体育指导中心

中国龙狮运动协会

**三、**承办单位

各省（区、市）社会体育主管部门

各省（区、市）龙狮运动协会

各行业体协和有关单位

**四、**活动时间

2014年2月10日-20日期间

**五、**活动要求

（一）承办单位必须统一活动主题-2014年全国“龙腾狮跃闹元宵”大联动，副题可自行确定。

（二）必须以舞龙舞狮等龙狮文化为活动主要内容。

（三）要扩大参与人群范围，组织城市、乡村的不同人群加入大联动活动。

（四）2014年全国“龙腾狮跃闹元宵”大联动启动仪式将于2014年2月14日在河南省周口市淮阳县举行，承办单位可自行组织当地活动的启动仪式。

加入大联动活动的单位要严格执行大型体育活动有关规定，认真制定安全预案和具体措施，确保活动安全。

承办单位认真填写《2014年全国“龙腾狮跃闹元宵”大联动报名表》，主办单位确认报名截止日期为2014年2月10日。

**六、**报送材料

（一）请各承办单位按时限报送《2014年全国“龙腾狮跃闹元宵”大联动报名表》，按要求报送有关材料。

（二）报送材料内容：

1. 承办单位开展本次大联动的通知；

2. 整体活动方案（含安全方案）；

3. 举办活动的影像视频（不少于30分钟）；

4. 2014年全国“龙腾狮跃闹元宵”大联动情况汇总表（由承办单位统计填报）。

（三）各承办单位统一将有关材料于2014年4月30日前报送主办单位。

（四）以大联动活动情况为主，并结合年度舞龙舞狮活动开展情况，给予部分单位以体育彩票资金资助。
