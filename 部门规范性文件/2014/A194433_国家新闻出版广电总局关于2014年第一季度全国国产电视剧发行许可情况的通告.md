# 国家新闻出版广电总局关于2014年第一季度全国国产电视剧发行许可情况的通告

国家新闻出版广电总局关于2014年第一季度全国国产电视剧发行许可情况的通告

根据国家电视剧内容管理的有关规定，现将总局及各省级广播影视行政部门2014年第一季度全国《国产电视剧发行许可证》颁发统计情况予以通告。

2014年1-3月，全国各类电视剧制作机构共计生产完成并获准发行国产电视剧70部2403集。根据总局以及各省电视剧管理部门的月报备案统计，题材比例情况如下：

现实题材剧目共计35部1139集，分别占总比例的50%、47.4%。其中，当代题材共计33部1059集，分别占总部、集数的47.14%、44.07%；现代题材共计2部80集，分别占总部、集数的2.86%、3.33%。

历史题材剧目共计33部1192集，分别占总比例的47.14%、49.6%。其中，近代题材共计25部887集，分别占总部、集数的35.71%、36.91%；古代题材共计8部305集，分别占总部、集数的11.43%、12.69%。

重大题材共计2部72集，分别占总部、集数的2.86%、3%。其中，重大革命2部72集。
