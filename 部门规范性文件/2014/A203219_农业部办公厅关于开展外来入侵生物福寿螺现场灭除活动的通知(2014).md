# 农业部办公厅关于开展外来入侵生物福寿螺现场灭除活动的通知(2014)

## 农业部办公厅关于开展外来入侵生物福寿螺现场灭除活动的通知（农办科[2014]21号）

近年来，我国南方部分省份外来入侵物种福寿螺不断扩散与蔓延，给当地农业生产和生态安全造成严重危害。为有效防范外来入侵物种，保障农业生产安全，保护生物多样性，经研究，定于2014年5月19日-21日在湖北省开展主题为“灭除外来入侵生物，保护生态家园”的福寿螺现场灭除活动。现就有关事宜通知如下。

**一、**活动内容

（一）开展福寿螺现场集中灭除；

（二）参观福寿螺综合防治技术示范区，交流外来入侵生物综合防治成果、方法与经验；

（三）开展现场宣传与咨询活动，发放防控技术资料和明白纸，提高社会各界防控意识和技术水平

；

**二、**参加人员

（一）上海、江苏、浙江、安徽、福建、江西、湖南、广东、广西、海南、重庆、四川、贵州、云南等省（区、市）农业环境保护站或农业厅科教处负责人；

（二）农业部农业生态与资源保护总站、中国农业科学院、中国农学会、中央农业广播电视学校、农业部环境保护科研监测所等单位专家。

（三）湖北省农业厅及有关市、县农业部门负责人。

活动邀请相关新闻媒体记者参加。

**三、**时间与地点

（一）时间：5月19日报到，20日现场灭除。

（二）活动地点：湖北省英山县。
