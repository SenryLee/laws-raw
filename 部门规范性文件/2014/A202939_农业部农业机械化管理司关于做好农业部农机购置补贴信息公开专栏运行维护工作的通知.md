# 农业部农业机械化管理司关于做好农业部农机购置补贴信息公开专栏运行维护工作的通知

## 农业部农业机械化管理司关于做好农业部农机购置补贴信息公开专栏运行维护工作的通知（农机产〔2014〕71号）

各省、自治区、直辖市及计划单列市农机（农业、农牧）局（厅、委、办），新疆生产建设兵团农业局，黑龙江省农垦总局、广东省农垦总局：

为认真贯彻落实部领导批示精神，进一步加大农机购置补贴信息公开力度，引导基层农机购置补贴信息公开专栏规范化建设，我司组织开发了2014版农业部农机购置补贴信息公开专栏（以下简称“部级补贴公开专栏”），并于近日在中国农业机械化信息网正式上线运行。现就部级补贴公开专栏运行管理维护工作有关事项通知如下：

**一、**部级补贴公开专栏设置

部级补贴公开专栏共设置9个一级栏目，8个二级栏目，各栏目主要公开的内容如下。

（一）综合要闻：党中央国务院近期出台的关于农机化、农机购置补贴实施的决策部署和政策规定，农业部、财政部和有关部委发布政策法规和提出工作要求，党中央国务院及部省领导视察指导农机化和农机购置补贴实施工作，省级补贴实施重点工作进展和重要新闻动态等。

（二）行政通知：设置中央通知和地方通知2个二级栏目。中央通知包括农业部、财政部等部委关于补贴实施、监管工作部署要求；地方通知包括省级农机化、财政等部门关于补贴实施、监管工作部署要求等。

（三）各地资讯：省、地、县三级农机购置补贴工作重要新闻重要活动及好经验、好做法等。

（四）曝光台：设置违规通报和黑名单2个二级栏目。违规通报包括部级和省级农机化主管部门印发的违规惩处通知通报等；黑名单包括部级和省级农机化主管部门将农机经销企业及其法定代表人列入黑名单的有关情况和印发的通知等。

（五）政策法规：设置中央政策和地方政策2个二级栏目。中央政策包括农机化促进法、农机监管条例及党中央国务院的相关文件和关部委关于农机化发展扶持政策等；农财两部的补贴资金管理办法、实施指导意见、规章制度和权威解读，农业部文件、农业部办公厅文件以及农机化司重要司函；有地方政策包括省级农机化主管部门印发的补贴资金管理办法、实施方案等。

（六）领导讲话：农业部、财政部及农机化司、财务司、驻部组局等部司领导关于农机化及农机购置补贴的讲话等。

（七）简报信息：农机化司发布的农机化情况和农机购置补贴专刊等。

（八）省级信息公开：设置省级补贴公开专栏网址链接和各地补贴咨询投诉电话2个二级栏目。省级补贴公开专栏网址链接包括38个省级补贴公开专栏的网址链接；各地补贴咨询投诉电话包括省、市、县三级政策咨询受理电话、政策投诉举报电话、补贴机具质量投诉电话等。

（九）举报投诉：补贴机具质量投诉平台和补贴工作与政策咨询投诉平台。

**二、**主要任务分工

我司牵头组织部级补贴公开专栏运行维护和管理服务工作，具体任务由农业部农业机械试验鉴定总站、农业部农业机械化技术开发推广总站和省级农机化主管部门按职能分工共同完成。

（一）农业部农机鉴定总站具体负责部级补贴公开专栏的设置、建设、升级等技术支持服务，负责信息整理编审发布和监督检查等日常管理维护，负责补贴机具质量投诉平台维护。

（二）农业部农机推广总站负责部级补贴公开专栏网络投诉平台维护，对举报投诉进行内容筛选、初步核实和政策解答，并配合开展投诉调查处理，定期提交举报投诉情况报告。

（三）省级农机化主管部门指定专人作为部级补贴公开专栏信息员，依据工作要求和专栏设置，负责向部级补贴公开专栏统一提交涉及本省的所有信息。各省补贴信息员报名表（见附件1）请于5月23日前以电子邮件形式报部农机鉴定总站。

综合要闻、各地资讯等栏目信息应及时提交，行政通知、曝光台、政策法规等栏目信息自文件发布之日起5个工作日内提交，其他重要信息按规定要求提交。各省补贴信息员点击“农业部农机购置补贴信息公开专栏”首页右上角“管理登录”，输入用户名和密码进行登录后，进入“农机购置补贴信息公开专栏内容管理系统”提交相关信息。为保证确保信息安全，请妥善保管用户名和密码。用户名和初始密码见附件2，登陆后应定期更新密码。

各省补贴信息员要做好省级补贴公开专栏网址链接维护更新，发生变化后，应于5个工作日内将新网址链接以电子邮件形式报送部农机鉴定总站。要定期登陆部级补贴公开专栏，点击本省网址链接，确保准确有效。

专栏运行初期，各省补贴信息员负责提供省、市、县三级政策咨询受理电话、政策投诉举报电话、补贴机具质量投诉电话，以上信息请以省为单位汇总填入地方补贴咨询投诉联络信息采集表（见附件3），并于6月10日前以电子邮件形式报送部农机鉴定总站。专栏运行过程中，地方补贴咨询投诉联络信息发生变化的，由各省补贴信息员负责在“农机购置补贴信息公开专栏内容管理系统”中及时更新，并定期组织自查，确保联系畅通。

**三、**有关要求

一是加强领导，明确分工。部级补贴公开专栏是农业部网络发布农机购置补贴权威信息的总出口，是与省级补贴公开专栏互联互通的中心枢纽，是引导基层农机购置补贴信息公开专栏建设的示范样板。建设好维护好部级补贴公开专栏是加大政策实施公开力度、提升为民服务能力、主动接受社会监督、正面引导社会舆情的重要举措，各级农机化主管部门要高度重视，加强组织领导，明确工作责任，保障工作条件，切实将部级补贴公开专栏的各项任务全部落实到位。

二是强化审查，确保权威。通过部级补贴公开专栏发布的补贴信息涉及面广、影响大，对信息的权威性和准确性要求高。要建立健全信息收集机制，特别是本省补贴方面的政策法规和重要文件、违规查处情况应重点收集、及时汇总。要严格执行信息审查程序，各地提交的信息须经本单位补贴工作的分管领导主要负责同志审核，确保数据准确、信息真实、来源可靠，符合保密有关规定。实行“谁提交、谁负责，谁审核、谁负责”的责任追究制度，出现虚假信息和明显工作失误引起不良影响的，要追究收集、审核、提交等环节的工作人员责任和有关领导责任。

三是定期抽查，严格考核。今年，我司将严格监督检查，强化过程管理，加大绩效引导，建立健全部级补贴公开专栏运行维护长效机制。今年继续对农机购置补贴信息公开实行延伸绩效管理，将部级补贴公开专栏运行维护作为重点考核内容，将定期组织抽查并向社会通报结果，抽查情况直接作为绩效考核评分依据。抽查前我司将以短信形式预通知，各地要提前开展自查，发现问题抓紧完善，并结合部级抽查情况认真整改，避免问题拖延解决和重复出现，以抽查促整改，以考核促公开。

四是加快建设，发挥作用。要充分发挥部级补贴公开专栏的示范引导作用，借鉴参照栏目设置和工作要求，建设好省级补贴公开专栏。要指导督促市县补贴公开专栏建设，通过教育培训、督导检查、绩效管理等，确保今年年底前各级补贴专栏全部建设到位。要加大宣传推广力度，在补贴挂图、明白纸、宣传册等资料上都要标注部级和本省补贴公开专栏网址，以权威平台、完整信息和及时发布树立起补贴公开专栏的品牌效应，力争用一到两年时间在补贴信息公开中成为中坚力量，发挥主导作用。

我司和两站指派专人负责部级补贴公开专栏运行维护，各地如有问题，请及时联系。
