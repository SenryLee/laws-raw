# 财政部公告2014年第61号――关于发行2014年记账式贴现(四期)国债的公告

财政部公告

（2014年第61号）

根据国家国债发行的有关规定，财政部决定发行2014年记账式贴现（四期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

**一、**本期国债计划发行150亿元，实际发行面值金额150亿元。

**二、**本期国债期限182天，经招标确定的发行价格为98.087元，折合年收益率为3.96%，2014年8月25日开始计息，招标结束后至8月27日进行分销，8月29日起上市交易。

**三、**本期国债低于票面面值贴现发行，2015年2月23日（节假日顺延）按面值偿还。

其他事宜按《中华人民共和国财政部公告》（2014年第1号）规定执行。

特此公告。

财政部

2014年8月22日
