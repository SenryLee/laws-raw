# 农业部公告第2089号――关于给法国维克有限公司核发《进口兽药注册证书》的公告

## 农业部公告（第2089号）

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准法国维克有限公司生产的头孢氨苄片在我国注册，核发《进口兽药注册证书》，并发布产品质量标准、说明书和标签，自发布之日起执行。

批准美国礼来公司英国生产厂生产的替米考星预混剂在我国再注册和变更注册，核发《进口兽药注册证书》，并发布修订后的产品质量标准、说明书和标签，自发布之日起执行。此前发布的同品种兽药产品质量标准同时废止。

**一、**头孢氨苄片说明书和标签样稿

（一）头孢氨苄片说明书

头孢氨苄片说明书

兽用

【兽药名称】

通用名：头孢氨苄片

商品名：乐利鲜®（Rilexine®）

英文名： Cefalexin Tablets

汉语拼音： Toubao’anbian Pian

【主要成分】　头孢氨苄

【性状】　本品为带棕色斑点的类白色长方形片。

【药理作用】抗生素类药。主要通过抑制细菌细胞壁，使细胞内容物膨胀至破裂溶解，从而达到杀菌作用。本品为广谱抗生素。对革兰氏阳性菌和革兰氏阴性菌均有抗菌作用，如葡萄球菌（包括抗青霉素菌株）、链球菌、大肠杆菌、克雷白杆菌和沙门氏菌等。犬口服后吸收迅速，生物利用率达90%。本品在组织体液中分布良好。给药后24小时，血浆中仍能检测到头孢氨苄。头孢氨苄的消除主要以尿的形式排出（85%），尿液峰浓度比血浆峰浓度高。

【适应证】犬：用于治疗对头孢氨苄敏感的大肠杆菌和变形杆菌引起的轻度尿路感染及由葡萄球菌属引起的皮肤感染。

猫：用于治疗对头孢氨苄敏感的大肠杆菌和变形杆菌引起的轻度尿路感染，由葡萄球菌属、巴氏杆菌属引起的皮肤及皮下感染。

【用法与用量】以头孢氨苄计。内服，每次每1 kg体重，犬、猫15mg，每日2次，或按下表推荐用量使用：

|  |  |
| --- | --- |
| 体重（kg） | 用药量 |
| 5 | 75mg 1片 |
| 5-10 | 75mg 2片 |
| 10-15 | 75mg 3片 |
| 15-20 | 300mg 1片 |
| 20-30 | 300mg 1.5片 |
| 30-40 | 600mg 1片 |
| 40-60 | 600mg 1.5片 |
| ＞60 | 600mg 2片 |

【不良反应】犬和猫偶有呕吐或/和腹泻。

【注意事项】

1．不要用于已知对头孢菌素或其它β-内酰胺族过敏的动物。

2．可能会产生过敏反应。

3．远离食品和饮水。

4．请放置在儿童不能达到的地方。

5．已用或未用完的产品需要安全抛弃。

【规格】　（1）75mg　（2）300mg　（3）600mg

【包装】　7片/板。2板/盒，20板/盒，30板/盒。

【贮藏】　密封保存。

【有效期】　36个月。

【进口兽药注册证号】

【生产企业】　　法国维克有限公司 Virbac

地址：1ere， Avenue 2065 M LID， 06516 Carros， France

**二、**替米考星预混剂说明书和标签样稿

（一）替米考星预混剂说明书

替米考星预混剂说明书

兽用

【兽药名称】

通用名：替米考星预混剂

商品名：泰勇（Pulmotil）

英文名：Tilmicosin Premix

汉语拼音：Timikaoxing Yuhunji

【主要成分】　替米考星

【性状】　本品为淡黄色至淡红棕色颗粒。

【药理作用】　半合成的大环内酯类抗生素。主要抗革兰氏阳性菌和支原体，对少数革兰氏阴性菌也有效。其对胸膜肺炎放线杆菌、畜禽支原体和巴氏杆菌的抗菌活性比泰乐菌素强。

内服本品后吸收快，组织穿透力强，分布容积大。肺中浓度高。半衰期可达 1-2 日，体内维持时间长。

【适应证】　用于治疗猪胸膜肺炎放线杆菌、巴氏杆菌及支原体引起的感染。

【用法与用量】　以替米考星计。混饲：每 1000kg 饲料，猪 200～400g，连用 15 日。

【不良反应】　按推荐剂量给药，未见不良反应。

【注意事项】 （1）仅用于治疗。

（2）本品对眼睛有刺激性，可引起过敏反应，避免直接接触。

【休药期】　猪14日。

【规格】　20%

【包装】

【贮藏】　遮光，密闭，在干燥处保存。

【有效期】　24个月。

【进口兽药注册证号】

【生产企业】　美国礼来公司英国生产厂 （Eli Lilly and Company Limited）

地址：Fleming Road， Speke Liverpool， Merseyside L24 9LN， UK
