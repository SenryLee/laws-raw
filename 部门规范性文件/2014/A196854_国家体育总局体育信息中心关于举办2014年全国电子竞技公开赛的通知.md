# 国家体育总局体育信息中心关于举办2014年全国电子竞技公开赛的通知

各省、自治区、直辖市、计划单列市体育局，相关部门和单位：

为了进一步促进电子竞技在我国的发展，提高我国电子竞技运动员的综合竞技水平，经研究，定于2014年12月5日- 12月7日在山东省青岛市举办2014年全国电子竞技公开赛。

现将竞赛规程印发给你们，请各省自治区、直辖市、计划单列市电子竞技主管部门和有关单位认真组织好本地区内的运动员报名注册和参赛准备工作。

附件：2014年全国电子竞技公开赛竞赛规程

国家体育总局体育信息中心

2014年8月15日

附件：

2014年全国电子竞技公开赛竞赛规程

赛事名称：全国电子竞技公开赛

（英文：National Electronic Sports Open，简称：NESO）

**一、**竞赛时间： 2014年12月5日 - 12月7日

**二、**竞赛地点： 山东省青岛市国际会展中心

**三、**组织机构

主办单位： 国家体育总局体育信息中心

承办单位： 山东省青岛市体育局

上海网映文化传播有限公司（英文：NEOTV）

**四、**竞赛项目：六个大项

（一） 魔兽争霸Ⅲ 冰封王座（个人）；

（二） 星际争霸II 虫群之心 （个人）；

（三） 英雄联盟 （团队5人）；

（四） 刀塔2 （团队5人）；

（五） FIFA ONLINE （1V1）；

（六） NBA2KONLINE （3V3）

；

**五、**参赛单位

（一）队伍数量

各省、自治区、直辖市、计划单列市均可派代表队参赛，各参赛单位可派出1支参赛队伍；

（二）队伍名称格式

各队队名需以各省、自治区、直辖市计划单列市名称为首，如“上海队”，如以地市（或区、县）名义参赛，可以在冠名中加入地市（或区、县）名称，如“四川绵阳队”

**六、**参赛资格

（一）年满18周岁的中国公民均可报名参赛，性别不限；

（二）报名运动员由各组团单位审核后报组委会；

（三）运动员参赛资格由组委会审核通过后方可参赛；

（四） 运动员的代表资格须经组委会注册，注册截止后，不得变更。

**七、**参赛办法

（一）每代表队各个项目至多可报名参赛的名额：

1.魔兽争霸Ⅲ 冰封王座 ：　1-2 人；

2.星际争霸II 虫群之心 ：　　　1-2人；

3.英雄联盟：　　　　　　　　1-2团队5人或10 人；

4.刀塔2：　　　　　　　　　1团队5人；

5.FIFA ONLINE：　　　　1人；

6.NBA2K ONLINE：　　　　　　3人（团队）。

（二）运动员不得兼项参赛。

（三）英雄联盟， 刀塔2比赛每队可报5人，低于5人不得参赛； NBA2K ONLINE 可报3人，低于3人不得参赛。

（四）每代表队至多可报领队1人。

**八、**参赛单位队伍组建

参赛单位可通过选拔赛方式或自行组建队伍的方式进行组队。如以选拔赛方式进行组队，需赛前15天向大赛组委会提交赛事规程。自行组队的队伍可以直接报名。

**九、**全国电子竞技公开赛赛制

（一）第一阶段：采用单局单循环积分淘汰赛小组积分小组前两名进入下一阶段。

（二）第二阶段：采用单败三局两胜淘汰赛，直至产生最终排名。

（三）竞赛编排：采用抽签方式进行。

（四）分组循环赛积分方式：在分组循环赛中，胜一场得 3分，平一场得1分，负一场得0分，依照此原则进行小组排名。

（五）如有特殊情况，赛制可能进行适当调整，赛制以各项目选手手册公布赛制为准。

（六）比赛弃权：

（1）运动员主动放弃比赛资格或未按规定时间参加检录视为弃权。

（2）主动弃权须由领队或教练员签字确认。

（3）弃权选手组委会保留对其追加处罚的权利，包括但不限于弃权。选手成绩不录入队伍总成绩，取消报销资格及赛事奖金。

（七）参赛运动员自备比赛用外置设备（鼠标、键盘、耳机、手柄、方向盘）；禁止携带、使用移动存储设备。

（八）赛制最终解释权归全国电子竞技公开赛赛事组委会所有。

**十、**服装：

（一）各代表队可在赛前向组委会申请穿着本代表队队服，经组委会审批同意，代表队运动员可在比赛中穿着本代表队队服。

（二）如代表队运动员没有统一服装，运动员必须穿着组委会提供的选手服。

**十一、**积分与排名

（一）各代表队每个项目的运动员按照名次取得积分，未获名次取得参赛基础分。每代表队各个项目运动员取得积分之和为该代表队的团体总分。如该代表队在团队（英雄联盟）项目中有2支参赛队伍，只记录成绩靠前队伍积分。

参赛队员如为各地方代表队原户籍选手，积分按原积分120%计算（团队项目3名队员如为原户籍选手，则该队伍积分按120%计算）。

（二）各项目计分方法：

|  |  |
| --- | --- |
| 名次 | 分数 |
| 第一名 | 15 |
| 第二名 | 10 |
| 第三名 | 7 |
| 第四名 | 6 |
| 第五-八名 | 3 |
| 参赛分 | 1 |

（三）积分排名：

1．各代表队名次依据团体总分分数进行排列，分数高者列前；

2．若分数相同，第一名名次居多者列前。以此类推第二名、第三名名次；

3．若分数、 名次均相同，取团体项目名次居多者列前；

4．若以上均相同，则排名并列。

**十二、**奖励

（一）设立各个项目名次奖及团体总分奖。

（二）奖励办法：

1．各个项目前3名颁发证书、奖金。

2．团体总分前3名，颁发证书。

团体总分冠军将保存“2014全国电子竞技冠军杯”奖杯，奖杯次年将交回全国电子竞技公开赛组委会。

**十三、**报名与注册

（一）报名时间：　 8月25日--9月19日

（二）参赛队伍限额：前12支报名代表队将获得比赛参赛资格，12支之后报名队伍将按报名顺序作为替补

（三）报名方式：采用网上注册和书面报名相结合的方式；

1．网上注册：各单位须于2014年9月19 日前在官方报名页面进行注册，页面地址：neso.neotv.com.cn ； 在接到报名信息后，NESO组委会将在3个工作日内以电话或邮件的方式联系报名单位；

2．书面报名：在NESO组委会联系报名单位后，组委会将发放具体书面报名表（可在官方报名页面下载），请各参赛单位加盖公章以传真方式发至体育信息中心电子竞技部；并在报名截止日期前（以邮戳为准）将报名表原件邮寄至体育信息中心电子竞技部；书面报名表为各单位的最终报名名单；

（三）报名材料：

1．2014年全国电子竞技公开赛报名表（加盖公章） ；

2．参赛人员近期免冠1寸照片一张（白底） ；

3．参赛人员身份证复印件一张。

（四）资格审核组委会将于报名截止日起7个工作日内对全部报名参赛运动员进行资格审核，审核合格后，方可参赛。

**十四、**经费

（一）差旅费：各参赛单位按照选手人数进行差旅补贴，每个选手补贴上限为1500元，超出部分参赛单位自理，领取补贴需提供相应票据凭证（票据仅限于交通费用票据）。

（二）食宿费：赛事期间住宿酒店由大赛组委会提供，赛程内餐饮由大赛组委会提供，其余住宿餐饮事宜由各参赛队伍自理。

（三）选手如有弃权弃赛或严重违反赛事纪律的情况，组委会将对该代表队进行相应处罚。
