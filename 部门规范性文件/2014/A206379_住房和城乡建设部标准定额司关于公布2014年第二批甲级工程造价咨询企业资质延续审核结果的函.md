# 住房和城乡建设部标准定额司关于公布2014年第二批甲级工程造价咨询企业资质延续审核结果的函

## 住房和城乡建设部标准定额司关于公布2014年第二批甲级工程造价咨询企业资质延续审核结果的函（建标造函[2014]14号）

各省、自治区住房和城乡建设厅，直辖市建委（建交委），各有关工程造价咨询企业管理机构：

根据《工程造价咨询企业管理办法》（建设部令第149号）的规定，我司组织了甲级工程造价咨询企业资质延续的审核工作。现将合格的北京中海华造价咨询有限公司等42家以及1家不予延续的企业名单予以公布。

附件：1．2014年第二批甲级工程造价咨询企业资质延续名单

2．甲级工程造价咨询企业资质延续审核未予通过名单（略）
