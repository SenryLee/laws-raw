# 财政部注册会计师考试委员会关于印发《注册会计师全国统一考试大纲——专业阶段考试(2014年度)》和《注册会计师全国统一考试大纲——综合阶段考试(2014年度)》的通知

财政部注册会计师考试委员会关于印发《注册会计师全国统一考试大纲--专业阶段考试（2014年度）》和《注册会计师全国统一考试大纲--综合阶段考试（2014年度）》的通知

（财考[2014]5号）

各省、自治区、直辖市财政厅（局）注册会计师考试委员会：

《注册会计师全国统一考试大纲--专业阶段考试（2014年度）》和《注册会计师全国统一考试大纲--综合阶段考试（2014年度）》已经财政部注册会计师考试委员会2014年度第一次会议审议通过，现予印发。
