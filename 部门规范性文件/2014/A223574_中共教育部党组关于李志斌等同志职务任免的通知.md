# 中共教育部党组关于李志斌等同志职务任免的通知

教党任[2014]143号

中共华东师范大学委员会：

经与中共上海市委商得一致，2014年12月2日研究决定：

李志斌、汪荣明同志任中共华东师范大学委员会常委；免去范军同志的中共华东师范大学委员会常委职务。

中共教育部党组

2014年12月11日
