# 中共教育部党组关于郭琦等同志职务任免的通知

## 中共教育部党组关于郭琦等同志职务任免的通知（教党任[2014]80号）

中共兰州大学委员会：

经与中共甘肃省委商得一致，2014年6月9日研究决定：

郭琦同志任中共兰州大学委员会常委、副书记，曹爱辉同志任中共兰州大学委员会委员、常委、副书记，李玉民、曹红同志任中共兰州大学委员会委员、常委；免去景涛、何晓东同志的中共兰州大学委员会常委职务。

中共教育部党组

2014年6月23日
