# 中国保监会、财政部关于开展2014年农业保险检查的通知

中国保监会、财政部关于开展2014年农业保险检查的通知

（保监产险〔2014〕21号）

各保监局，财政部驻各省、自治区、直辖市、计划单列市财政监察专员办事处：

在党中央、国务院的高度重视和指导下，近年来各有关方面共同努力，引导和推动我国农业保险快速发展，为服务“三农”发挥了积极作用，但也面临一些挑战和问题。根据《保险法》《农业保险条例》等有关规定，为贯彻落实党中央、国务院有关精神，全面总结农业保险工作情况，进一步规范市场行为，完善农业保险制度，推动农业保险持续健康发展，保监会、财政部决定对农业保险经营情况开展联合检查，现将有关事项通知如下：

**一、**检查对象

（一）保监会、财政部联合检查组负责河北等4省检查。保监会、财政部成立农业保险联合检查领导小组，统筹协调本次检查活动。领导小组下设4个联合检查组，由保监会系统（包括保监局）、财政部驻各省、自治区、直辖市、计划单列市财政监察专员办事处（以下简称专员办）检查人员组成，分别负责河北、吉林、黑龙江、河南4省的农业保险检查，检查对象为上述4省所有农业保险经营主体。

（二）各地检查工作小组负责本地区检查。上述4省之外的各保监局成立农业保险检查工作小组，负责本省（区、市）农业保险检查，检查对象至少选择1家辖区内市场份额排名居前的农业保险经营主体。上海、安徽保监局分别对安信农业保险股份有限公司、国元农业保险股份有限公司总公司及其所在省市的农业保险业务进行检查。各保监局、专员办应当加强沟通协调，相互配合，专员办要及时了解检查相关情况。

**二、**检查时间和检查重点

本次检查时间自2014年4月开始，2014年6月底结束。检查组应当于检查结束后15个工作日内完成检查报告，并按相关规定和程序提出处理意见。本次检查重点检查2013年度农业保险业务经营状况（包括经营行为的合规性、内控管理的有效性、农业保险发展情况评估等），可根据检查工作需要向前追溯或向后延伸。

**三、**检查工作要求

（一）加强组织领导。各保监局、专员办应当从贯彻落实党中央、国务院精神和确保国家支农政策效应的高度，提高认识，周密部署，精心组织，确保检查效果。

（二）严守检查纪律。各保监局、专员办应当严格依法检查，切实执行中央八项规定和相关检查要求，严守工作纪律，规范检查程序，自觉遵守保密规定。

（三）密切协作配合。各保监局、专员办应当根据各自职责，发挥各自优势，加强协作配合，注意方式方法，共同做好此次检查工作，并将有关情况及时上报。

（四）检查调研结合。各保监局、专员办应当将检查与调研相结合，总结农业保险工作成效经验，了解农业保险经营模式，查找分析存在问题，提出相关政策建议。

（五）依法严肃查处。各保监局、专员办应当按照相关规定，结合情节轻重，依法查处相关违规行为。对于严重违规行为，应依法从严从重处理，促进农业保险规范健康发展。
