# 国家标准化管理委员会关于全国人类工效学标准化技术委员会换届及征集委员的通知

各有关单位：

根据《全国专业标准化技术委员会管理规定》（国标委办[2009] 3号）的相关要求，第六届全国人类工效学标准化技术委员会（SAC/TC7）任期届满，拟于近期筹备换届工作。本着相关方广泛参与的原则，现向各有关单位公开征集第七届全国人类工效学标委会委员。具体要求如下：

**一、**征集范围

全国人类工效学标准化技术委员会（SAC/TC7）主要负责人类工效学领域国家标准的制修订工作，对口国际标准化组织人类工效学技术委员会（ISO/TC159）。现面向全国该领域的相关科研机构、高等院校、政府部门、行业协会、生产企业、检测机构等单位征集委员人选。

**二、**委员条件

1、人类工效学相关领域的专家或技术骨干，熟悉本专业的业务工作，并具有较高的理论水平和较丰富的实践经验；

2、具有高级专业技术职称，从事相关工作5年及以上的在职人员；

3、熟悉和热爱标准化工作，遵守技术委员会章程，能积极参加技术委员会组织的各项活动，认真履行委员的职责和义务；

4、所在单位同意推荐。

**三、**申报程序及要求

1、委员候选人须认真填写《全国专业标准化技术委员会委员登记表》（见附件），推荐单位负责审查登记表内容，单位负责人在登记表指定位置签署意见并加盖单位公章；

2、请于2014年8月2日前，将登记表纸制材料一式三份（贴本人近期正面免冠二寸彩色照片，另附同底照片2张）邮寄至SAC/TC7秘书处，同时提交委员登记表电子文档至：ranlh@cnis.gov.cn ；

3、秘书处将组织评审组对委员候选人资料进行评议，通过对报名单位及个人的工作能力综合评定，确定委员名单，报国家标准化管理委员会批准。
