# 国家质量监督检验检疫总局、国家发展和改革委员会联合公告2014年第38号——关于公布核准和注销资格的设备监理单位名单的公告

## 国家质量监督检验检疫总局、国家发展和改革委员会联合公告（2014年第38号）

关于公布核准和注销资格的设备监理单位名单的公告

根据《设备监理管理暂行办法》（国质检质联〔2001〕174号）、《设备监理单位资格管理办法》（国家质检总局令2002年第28号）的有关规定，国家质量监督检验检疫总局、国家发展和改革委员会决定将核准资格的设备监理单位、核准资格的乙级升甲级/扩大专业设备监理单位和注销资格的设备监理单位名单予以公布。

特此公告。

附件：1. 核准资格的设备监理单位名单

2. 核准资格的乙级升甲级/扩大专业设备监理单位名单

3. 注销资格的设备监理单位名单

质检总局

国家发展改革委

2014年4月8日
