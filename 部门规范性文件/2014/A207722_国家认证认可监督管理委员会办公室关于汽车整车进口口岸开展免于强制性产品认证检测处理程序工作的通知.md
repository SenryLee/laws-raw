# 国家认证认可监督管理委员会办公室关于汽车整车进口口岸开展免于强制性产品认证检测处理程序工作的通知

各直属出入境检验检疫局、进口汽车整车强制性产品认证指定认证机构、指定实验室：

近年来，国家陆续批准增加了一批汽车整车进口口岸。各相关直属检验检疫局在开展进口汽车认证监管过程中，会遇到特殊用途车辆需进行免予强制性产品认证检测处理程序（以下简称特殊检测处理程序）的情况。为做好进口汽车特殊检测处理程序工作，现对汽车整车进口口岸开展特殊检测处理程序的有关政策和工作要求明确如下：

**一、**特殊检测处理程序实施主体

所有国家批准从事进口汽车整车贸易的口岸所在地直属检验检疫局均可开展进口汽车特殊检测处理程序工作。

**二、**特殊检测处理程序实施的适用范围

按照《关于进一步完善和规范免于强制性认证特殊用途进口汽车检测处理程序的通知》（国认证〔2011〕48号）规定，对进口汽车特殊检测处理程序适用范围进一步明确为反恐安全、抢险救灾、应急指挥、体育竞技、道路试验、国家重大生产建设项目和最终用户使用（商务部门进口许可证上列明的进口目的或使用用途须为单位或个人自用）。特殊检测处理程序不适用于一般贸易的进口车辆。

**三、**特殊检测处理程序实施的工作要求

（一）各局应严格按照认监委《关于调整免予强制性产品认证检测处理程序的公告》（2008年第38号公告）、《关于进一步完善和规范免于强制性认证特殊用途进口汽车检测处理程序的通知》（国认证〔2011〕48号）和《关于明确免于强制性认证特殊用途进口汽车检测处理程序的有关要求的通知》（国认证〔2011〕74号）等规定要求，做好进口汽车特殊检测处理程序的实施工作。

（二）各局应按照就近、便利、有效监管的原则，使用进口汽车整车强制性产品认证指定实验室或者其在口岸设立的具备汽车特殊检测处理程序要求的检测项目的全项能力，并获得计量认证和认可的现场检测实验室开展特殊检测处理程序工作。

（三）各局应配备熟悉强制性产品认证制度及相关标准要求的专业管理人员，使用认监委统一的“免于强制性产品认证的特殊用途进口产品检测处理管理系统”对进口汽车特殊检测处理程序工作实施电子化管理。各局专业管理人员应尽快熟悉免于强制性产品认证的特殊用途进口产品检测处理管理系统的使用，并掌握相关工作流程，做好实施工作。

（四）各局应加强进口汽车特殊检测处理程序工作相关政策的宣传、引导，加强与地方政府部门沟通协调，切实履行好监管职责。
