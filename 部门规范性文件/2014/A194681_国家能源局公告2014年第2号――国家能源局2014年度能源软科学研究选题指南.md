# 国家能源局公告2014年第2号――国家能源局2014年度能源软科学研究选题指南

## 国家能源局公告（2014年第2号）

国家能源局根据能源发展战略、规划和2014年能源工作重点任务，在听取各方面意见的基础上，编制了《国家能源局2014年度能源软科学研究选题指南》，现予公布。

国家能源局鼓励单位和个人在从事能源领域相关研究时参考指南确定选题，以便更好地为制定能源重大政策服务。国家能源局2014年度能源软科学研究优秀成果奖将重点评选本指南范围内的研究成果。

参考指南确定相关研究课题的单位和个人可以与国家能源局法制和体制改革司建立联系。

联系方式：电子邮箱nyrkxyj@163.com。
