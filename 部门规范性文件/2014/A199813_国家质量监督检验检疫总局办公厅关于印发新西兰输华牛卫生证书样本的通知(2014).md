# 国家质量监督检验检疫总局办公厅关于印发新西兰输华牛卫生证书样本的通知(2014)

## 国家质量监督检验检疫总局办公厅关于印发新西兰输华牛卫生证书样本的通知

（2014年8月8日　质检办动函[2014]709号）

各直属检验检疫局：

总局已就新版新西兰输华牛卫生证书与新西兰方面达成一致。现将卫生证书样本（见附件，纸质证书样本随后寄发）印发你们，请各局据此做好新西兰输华牛卫生证书的核查工作。《关于印发新西兰输华牛卫生证书样本的通知》（国质检动函[2005]615号）中的新西兰输华牛卫生证书样本同时废止。

新版证书样本可在“外国官方检疫证书分析与验证识别系统”（http：／／10．37．0．1／ciqcert／homepage．htm）中查询。

附件：新西兰输华牛卫生证书样本（略）
