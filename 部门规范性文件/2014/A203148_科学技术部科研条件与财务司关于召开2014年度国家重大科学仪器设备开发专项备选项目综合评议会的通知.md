# 科学技术部科研条件与财务司关于召开2014年度国家重大科学仪器设备开发专项备选项目综合评议会的通知

各位专家：

为做好2014年度国家重大科学仪器设备开发专项（简称仪器开发专项）备选项目的遴选工作，兹定于2014年5月16日，在万寿庄宾馆召开仪器开发专项综合评议会，会期1天。

各项目单位严禁联系有关专家，影响综合评议公正性，一经发现，将取消参评资格。

特此通知。
