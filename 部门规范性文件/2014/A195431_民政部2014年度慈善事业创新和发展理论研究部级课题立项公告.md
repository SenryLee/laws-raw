# 民政部2014年度慈善事业创新和发展理论研究部级课题立项公告

民政部2014年度慈善事业创新和发展理论研究部级课题立项公告

自《民政部2014年度慈善事业创新和发展理论研究部级课题指南》公布以来，社会各界广泛关注，踊跃申报，共收到95家单位共计136份课题申报材料。结合专家评审结果和当前慈善事业行政管理工作需要，经研究，确定以下12个重点课题、20个自选课题。对重点课题，我司近期将与其承担单位签订《民政部科研任务书》，每个课题给予1万元经费支持；对自选课题，结项后根据成果质量水平给予一定荣誉奖励。希望课题承担者组织力量认真开展研究，并于2014年12月30日前向我司提交研究报告。逾期未提交研究报告的，视为未完成研究任务，且不予结题。

在此次课题研究组织开展过程中，华北电力大学人文学院社会企业研究中心承担了大量工作，对此我们表示诚挚感谢。
