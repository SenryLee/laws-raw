# 全国旅游星级饭店评定委员会公告2014年第3号――关于取消五星级旅游饭店资格的公告

## 全国旅游星级饭店评定委员会公告（2014年第3号）

关于取消五星级旅游饭店资格的公告

2014年6月27日，经全国旅游星级饭店评定委员会研究决定，取消北京锦江富园大酒店、山西晋城金辇大酒店、山东东方海天酒店等三家饭店的五星级旅游饭店资格。

特此公告。

全国旅游星级饭店评定委员会

2014年6月30日
