# 国家知识产权局公告第203号――关于注销长春成铭专利商标代理有限公司的公告

## 国家知识产权局公告（第二○三号）

关于注销长春成铭专利商标代理有限公司的公告

根据《专利代理条例》和《专利代理管理办法》的规定，依当事人申请，在已经妥善处理各种尚未办结的事项后，同意注销长春成铭专利商标代理有限公司。

特此公告。

国家知识产权局

2014年7月2日
