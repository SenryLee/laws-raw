# 中央国家机关住房资金管理中心关于2014年月缴存额年度调整相关数据的通知

中央国家机关各部门、各单位住房公积金管理机构：

现将北京住房公积金管理委员会审议通过的，2014住房公积金年度月缴存额年度调整有关数据通知如下：

**一、**住房公积金缴存比例

2014住房公积金年度（2014年7月1日至2015年6月30日）住房公积金缴存比例为12％。

**二、**住房公积金缴存额上限

2014住房公积金年度月缴存额上限是上一年度北京市全市职工月平均工资的300%，分别乘以当年单位和职工住房公积金缴存比例之和：5793×3×12%×2＝4170元（四舍五入）。

**三、**住房公积金缴存基数下限

2014住房公积金年度月缴存基数下限是2014年北京市最低工资标准1560元，下岗、内退等类似情况职工月缴存基数不得低于2014年北京市基本生活费1092元。
