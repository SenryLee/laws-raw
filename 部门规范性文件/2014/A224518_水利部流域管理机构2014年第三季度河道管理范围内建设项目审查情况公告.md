# 水利部流域管理机构2014年第三季度河道管理范围内建设项目审查情况公告

为促进依法行政，加强行政审批的监督管理，现将2014年第三季度水利部流域管理机构河道管理范围内建设项目审查情况公告如下：

水利部流域管理机构2014年第三季度审查同意的河道管理范围内建设项目共计78项，其中长江水利委员会36项，黄河水利委员会19项，淮河水利委员会7项，海河水利委员会5项，珠江水利委员会9项，松辽水利委员会2项，太湖流域管理局0项。

附件：水利部流域管理机构2014年第三季度河道管理范围内建设项目审查情况统计表

建设与管理司

2014年10月13日
