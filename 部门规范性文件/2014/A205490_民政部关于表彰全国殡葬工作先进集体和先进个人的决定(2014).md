# 民政部关于表彰全国殡葬工作先进集体和先进个人的决定(2014)

民政部关于表彰全国殡葬工作先进集体和先进个人的决定

（民发〔2014〕49号）

各省、自治区、直辖市民政厅（局）、各计划单列市民政局，新疆生产建设兵团民政局：

近年来，全国殡葬系统在党中央、国务院和各级党委、政府的正确领导下，坚持以邓小平理论、“三个代表”重要思想、科学发展观为指导，服从和服务于经济社会发展的大局，深入践行“以民为本、为民服务、为民解困”的民政工作宗旨，以改革创新的精神攻坚克难，持续推进殡葬改革，强化殡葬公共服务，坚持依法规范管理，倡导移风易俗新风尚，为保障和改善民生、推进生态文明、促进社会进步做出了积极贡献，涌现出一大批先进集体和先进个人。

为鼓励先进，发扬成绩，激励斗志，民政部决定，对北京市八宝山殡仪馆等179个殡葬工作先进集体和祝金岳等288名殡葬工作先进个人进行表彰。希望受表彰的先进集体和先进个人珍惜荣誉，戒骄戒躁，再接再厉，充分发挥模范带头作用，为殡葬改革和殡葬事业发展再创佳绩、再立新功。

全国各级民政部门、殡葬服务单位和广大殡葬干部职工要向受表彰的全国殡葬工作先进集体和先进个人学习，发扬锐意创新、不断进取的开拓精神，恪守爱岗敬业、求真务实的工作作风，秉持心系群众、服务人民的为民情怀，努力建设人民满意的服务型集体，打造作风优良的高素质队伍。

当前，我国正进入经济社会快速发展、全面建成小康社会的关键时期，殡葬改革和殡葬事业面临新的发展机遇，我们要紧密团结在以习近平同志为总书记的党中央周围，深入贯彻党的十八大和十八届三中全会精神，全面落实中共中央办公厅、国务院办公厅《关于党员干部带头推动殡葬改革的意见》，凝心聚力，锐意进取，深化改革，不断创新体制机制，提高为民服务水平，保障群众基本殡葬服务需求，加快殡葬领域生态文明建设，努力谱写殡葬事业科学发展的新篇章。
