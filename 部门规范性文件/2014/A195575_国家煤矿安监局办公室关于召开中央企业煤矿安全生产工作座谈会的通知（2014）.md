# 国家煤矿安监局办公室关于召开中央企业煤矿安全生产工作座谈会的通知（2014）

## 国家煤矿安监局办公室关于召开中央企业煤矿安全生产工作座谈会的通知（煤安监司函办〔2014〕32号）

各有关单位：

定于11月6日在北京召开中央企业煤矿安全生产工作座谈会。国家安全监管总局、国务院国资委、国家煤矿安监局领导同志将出席会议并讲话。现将有关事项通知如下：

**一、**会议主要内容

通报中央企业煤矿安全检查情况，分析面临的形势和存在的问题，开展警示教育，部署下一步中央企业煤矿安全生产工作。

**二、**参会人员

1.11个中央企业煤矿安全生产检查组组长单位和参加检查的4个省级煤矿安全监管部门有关负责人。

2.有关中央企业集团总部董事长或总经理、分管煤矿安全生产工作的负责人及煤矿安全生产管理部门主要负责人。

3.国家安全监管总局、国务院国资委、国家煤矿安监局有关领导同志及有关司（局、室）负责人。

4.邀请中国安全生产报（中国煤炭报）和国家安全监管总局政府网站记者参会。

**三、**会议时间和地点

时间：11月6日下午2：30至5：00，会期半天。

地点：国家安全监管总局机关A511会议室（地址：北京市东城区和平里北街21号）。

**四、**其他事项

请按要求派员出席会议，并于11月3日12：00前将会议代表回执（见附件）传真至国家煤矿安监局行管司。

联系人及电话：梁子荣，010-64464294（带传真）。

附件：会议代表回执

国家煤矿安监局办公室
