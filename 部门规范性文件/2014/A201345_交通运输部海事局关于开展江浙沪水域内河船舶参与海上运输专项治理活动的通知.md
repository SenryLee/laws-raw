# 交通运输部海事局关于开展江浙沪水域内河船舶参与海上运输专项治理活动的通知

## 交通运输部海事局关于开展江浙沪水域内河船舶参与海上运输专项治理活动的通知（海通航〔2014〕391号）

上海、江苏、浙江海事局、上海市、江苏省、浙江省地方海事局：

近期，我国沿海水域连续发生多起涉及内河运输船舶的水上交通事故，造成重大人身作伤亡和较大社会影响。为保障辖区水上交通安全，维护航运和水上施工市场秩序，贯彻落实《交通运输部　国家安全监管总局关于开展水上交通安全“打非治违”专项整治活动的通知》（交海发〔2014〕72号）精神，我局决定从2014年7月1日起，对内河船舶从事海上运输行为突出的江浙沪水域开展为期3个月的专项治理，重点治理对象为内河船舶参与海上运输的违法行为，以及为违法参与海上运输的内河船舶装、卸或过驳砂石的宕口、码头、浮吊等。我局组织制定了《江浙沪水域内河船舶参与海上运输专项治理活动实施方案》（见附件），请你单位按照方案的要求，抓紧落实。

请各有关单位在6月30日前，将本单位活动方案报我局。我局将根据活动开展情况，适时组织现场检查和督察。

在治理活动中，各单位应注意沟通协调，发挥好现场指挥部的作用。同时应注意总结经验，为常态化管理奠定基础。

交通运输部海事局

2014年6月20日

附件：

江浙沪水域内河船舶参与海上运输专项治理活动实施方案

为进一步加强对内河船舶参与海上运输和施工作业的治理，保障水上人命财产安全，维护良好航运和水上施工市场秩序，根据《交通运输部　国家安全监管总局关于开展水上交通安全“打非治违”专项整治活动的通知》（交海发〔2014〕72号）文件精神，制定本方案。

**一、**指导思想

以科学发展观为统领，坚持以人为本，树立安全发展理念，按照交通运输部“打非治违”总体部署和要求，坚持“属地为主、源头管理、堵疏结合、区域联动、综合治理”的方针，贯彻落实部海事局《关于全面落实砂石运输船安全管理长效机制的实施意见》和《海事系统全面落实防治船舶超载运输长效管理机制的实施意见》的要求，规范水上运输秩序、施工秩序和航行秩序，消除安全隐患，确保水上交通安全形势持续稳定。

**二、**活动目标

通过江浙沪海事部门与地方有关部门的联动执法，严肃查处内河船舶参与海上运输的违法行为，促进并落实政府部门监管主体责任，不断增强从业人员安全意识，提高船员和从业人员的守法自觉性，全面规范内河船舶运输行为，减少水上交通事故发生，打造平安交通。

**三、**活动时间

2014 年7月1日至2014年9月31日。

**四、**治理对象

重点治理内河船舶参与海上运输的违法行为以及为违法参与海上运输的内河船舶装、卸或过驳砂石的宕口、码头、浮吊等。

**五、**组织机构

交通运输部海事局成立“江浙沪水域内河船舶参与海上运输专项治理活动领导小组”，负责活动的统一指挥和协调；在上海海事局设现场协调部，负责现场信息沟通和行动协调等。

**六、**活动主要内容和要求

（一）加强组织领导，落实监管责任

各单位应当根据本方案的要求，结合辖区实际，制定本辖区活动实施方案；加强组织领导，切实落实监管责任，明确监管重点、监管要求和责任人，严格安全责任追究制度，确保各项活动内容和工作要求得到有效落实。辖区发生水上交通事故涉及内河船舶参与海上运输的，要按照“四不放过”原则追究相关单位和人员的管理责任。

（二）加强宣传和动员工作

各单位要通过网络、电视、报纸等新闻媒介和签证、现场检查、典型案例、走访调研、召开座谈会等方式向地方政府、内河运输船舶经营人、从业人员宣传安全和运输法规，宣讲内河船舶参与海上运输属于违规违法行为，宣传其危害性；督促内河船舶增强守法观念、提高安全意识、加强安全管理、落实安全责任。各单位可邀请媒体记者参与现场执法报道，做好有关政策、安全知识，特别是有重大影响事件的报道，争取社会舆论支持，营造良好的活动氛围。

（三）点线面结合，水陆空并进

一是摸清现状底数，做到有的放矢。各单位应摸清本辖区砂石料装卸码头、宕口、浮吊以及参与海上运输的内河船舶及其主要航线等基本信息，登记造册建立专门档案，在此基础上有针对性开展专项治理工作。

二是点线面结合，全面布控。各单位要根据参与海上运输内河船舶的活动特点，结合网格化管理，充分利用和整合海事执法资源，合理调配船艇和执法人员，强化监管力度，坚持源头治理，坚持始发港严控、中途港严查、目的港严处的管理要求，加大治理和查处力度。结合辖区实际，在适当水域和相关宕口、码头、浮吊附近设置拦截检查线、检查点，明确责任船艇和人员，加强对参与海上运输的内河船舶进行现场检查。上海海事局联合浙江海事局利用固定翼飞机加强对海上砂石装运点和主要运输航路巡视、监控。

（四）严把关口，严格监管

实行24小时巡查执法模式，根据掌握的夜间非法装卸砂石多发区域实施驻点检查或巡回检查等方式，严厉查处非法违法行为。砂石料装货地辖区海事管理机构可联合当地交通主管部门督促装货码头、宕口对出港运石船舶进行源头控制，防止存在内河船舶参与海上运输的违法违规行为。各海事管理机构对申报目的港为沿海区域的内河船舶不予办理出港签证，并对相关船舶记录并重点监控。途经港辖区海事管理机构要加强现场监管，在安全可控的条件下，对违法船舶实施拦截检查。

（五）信息共享，联动攻坚

一是建立联动协作机制、信息通报制度、违法船舶协查/重点跟踪制度以及处理反馈制度。对发现参与海上运输的内河船舶的海事部门除对该船舶依法处罚外，还应对该船船籍港、始发港/装货地、目的港/卸货地进行询问核实，装卸地在本辖区的应对装卸地进行调查，联合地方政府进行整改，同时安排力量加强巡查；装卸地、船籍港不在本辖区的，应通过联络员将相关情况通报相关海事管理机构；接到通报的海事管理机构应对船舶所属公司进行走访调查，对相关装卸点进行调查，联合地方政府进行整改，同时安排力量加强巡查。对查实的参与海上运输的内河船舶存在拒绝接受处理或逃避处理等行为的，按照《重点跟踪船舶监督管理规定》的要求处理。部海事局将适时对相关工作进行督查、通报。

二是各单位要主动协调地方政府交通主管、安监、公安等相关职能部门参与本次联合整治行动，并根据辖区实际设置违法船舶查扣区，加强对违法船舶管控，有条件的在查扣区安排应急拖轮和值班警力。

三是各单位应要求辖区参与砂石装卸的宕口、码头、浮吊签订安全生产承诺书，不得为参与海上运输的内河船舶装、卸或过驳货物，一经发现将通报当地政府交通主管部门，由交通主管部门查处，并停止其作业、责令其整改。

（六）严格处罚

一是对存在参与海上运输行为内河船舶的行政处罚，各单位要按照部海事局《常见海事违法行为行政处罚裁量基准》对应档次相应幅度的上限进行处罚，发现一件查处一件。对存在参与海上运输行为的内河船舶，还要按照相关规定对船长及其承担直接责任的船员进行处罚。对于涉嫌无证驾驶、妨碍执行公务的人员可移交公安处理。对于在规定时间内完成行政处罚和违法行为纠正且签署《安全生产承诺书》的船舶，经相关海事管理机构领导同意，可以到指定码头卸货。

二是各单位对发现的违法船舶依法处罚后，须将处罚信息反馈船籍港海事管理机构，并建议船籍港海事管理机构对船舶所属公司实施监督检查。船籍港海事管理机构须特别加强对存在“代而不管”现象航运公司的监督检查，督促相关企业认真落实安全生产主体责任。对船舶无法进行有效管理的体系内航运公司，船籍港海事管理机构可采取约谈、实施附加审核、到港必查等管理措施进一步加强安全管理。

（七）坚持疏堵结合。各单位在严肃查处内河船舶参与海上运输行为的同时，要研究扶持海船参与海上砂石运输的相关政策，从船员培训、公司管理、船检管理等方面研究措施鼓励和扶持海船参与海上砂石运输，以市场手段调节海上砂石运输行业，规范海上砂石运输秩序。

（八）做好工作记录。 各单位要做好活动工作记录备查，包括巡查宕口、码头、浮吊的情况，跟踪标识，拦截和查处内河船舶参与海上运输的情况（包括船名、船籍港、始发地、目的地、载货情况、违法类型和处置情况等），并按要求报送有关工作表（见附表2和附表3）。

（九）建立长效机制。各单位在本次专项治理活动末期，应进一步完善措施，强化管理，建立长效机制。自10月1日开始，内河船舶参与海上运输监管工作纳入常态化管理，各单位参照本次专项治理活动的相关要求，结合本辖区实际，细化方案、完善措施、持续开展。
