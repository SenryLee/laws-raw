# 国家测绘地理信息局办公室关于报送2014年工作总结和2015年工作思路的通知

## 国家测绘地理信息局办公室关于报送2014年工作总结和2015年工作思路的通知（测办函〔2014〕103号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位：

为谋划部署2015年工作任务，筹备召开好全国测绘地理信息局长会议，推进测绘地理信息领域深化改革顺利进行，请各单位、各部门报送测绘地理信息2014年工作总结和2015年工作思路。现将有关事项通知如下：

**一、**要高度重视。做好全年总结工作对推动测绘地理信息事业深化改革、加快转型升级发展具有重要作用。各单位各部门要高度重视、认真部署，通过做好工作总结，吸取经验，理清发展思路，推动工作再上新的台阶。

**二、**要突出重点。紧密结合深入学习贯彻落实党的十八大、十八届三中、四中全会精神，围绕《2014年测绘地理信息工作要点》所确定的中心工作和重点任务，认真总结工作中采取的重要举措、创新做法和突出成效，以及工作中的体会、存在的问题，提出明年需重点开展的工作、深化改革的重要举措和对国家测绘地理信息局的意见建议。

**三、**要全面客观。总结既肯定成绩、总结经验，也要分析差距、查找问题，尽量采用对比等方式表现，用统计数据和典型事例说明，做到既要全面系统，又要简明扼要，具有本单位特点。对暂不能全面获取的统计数据，可以适当估算至年底。

**四、**请各单位、各部门将“2014年工作总结和2015年工作思路”的书面材料于2014年11月20日前报送至国家局办公室，同时发送电子版（发送后请电话确认），字数控制在3000字以内，并请提供主要工作成效摘要（字数不超过300字）。国家局办公室将汇编各单位材料，并作为全国测绘地理信息局长会议材料。
