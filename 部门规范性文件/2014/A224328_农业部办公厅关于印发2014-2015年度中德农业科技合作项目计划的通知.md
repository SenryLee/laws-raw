# 农业部办公厅关于印发2014-2015年度中德农业科技合作项目计划的通知

农办科〔2014〕48号

各有关单位：

根据中德农业科技合作第22次工作组会议磋商结果，2014-2015年度共安排中德农业科技合作项目48项（见附件），现将项目实施计划下达你单位，并就有关事项通知如下。

一、请项目承担单位尽快与德方合作单位和专家取得联系，确保项目按实施计划执行。

二、根据此前中德农业科技合作工作组会议协议，专家国际旅费和食宿交通费均由派出国负担。

三、请各项目单位于2015年11月30前向我部科技教育司报送项目总结，主要内容包括人员互访情况、合作研究进展及项目开展取得的成效。
