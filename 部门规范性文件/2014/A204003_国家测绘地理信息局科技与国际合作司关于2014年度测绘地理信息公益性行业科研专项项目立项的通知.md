# 国家测绘地理信息局科技与国际合作司关于2014年度测绘地理信息公益性行业科研专项项目立项的通知

## 国家测绘地理信息局科技与国际合作司关于2014年度测绘地理信息公益性行业科研专项项目立项的通知（测科函〔2014〕6号）

各有关单位：

“中国SLR系统性能提升关键技术及应用”等16个项目（详见附件）已通过科技部重复项目审查和财政部批准立项，纳入我局2014年度测绘地理信息公益性行业科研专项计划。

项目承担及协作单位要严格按照财政部、科技部相关管理办法和《测绘地理信息公益性行业科研专项项目管理办法（试行）》、《测绘地理信息公益性行业科研专项经费管理办法（试行）》的有关规定和要求，尽快启动实施项目，切实加强经费管理，健全完善内部制度，提高资金使用效益，确保项目的研究开发任务和目标按期完成。各项目组要严格按照《测绘地理信息公益性行业科研专项项目任务书》中明确的研究内容、技术路线、主要成果及考核指标等要求抓紧开展研究工作。
