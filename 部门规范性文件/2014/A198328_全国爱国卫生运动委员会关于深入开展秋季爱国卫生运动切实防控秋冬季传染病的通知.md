# 全国爱国卫生运动委员会关于深入开展秋季爱国卫生运动切实防控秋冬季传染病的通知

## 全国爱国卫生运动委员会关于深入开展秋季爱国卫生运动切实防控秋冬季传染病的通知（卫发明电〔2014〕62号）

各省、自治区、直辖市和新疆生产建设兵团爱卫会，全国爱卫会各成员单位：

2014年7月以来，广东、云南等部分地区相继发生登革热疫情，病例数较去年同期大幅增加，目前南方仍是蚊虫活跃季节，登革热疫情存在进一步扩散风险。同时，当前鼠类正值繁殖高峰时期，流行性出血热等传染病进入高发季节，防控形势不容乐观。为进一步做好秋冬季传染病防控工作，切实保障人民群众身体健康，全国爱卫会决定，各地要在近期深入开展一次秋季爱国卫生运动。现就有关事项通知如下：

**一、**切实加强组织领导

各级爱卫会要根据本地工作实际和秋冬季防控重点疾病，明确工作目标、重点任务和具体安排，确定工作方案，组织协调各成员单位，宣传动员广大群众，掀起一次清洁环境、防治疾病的秋季爱国卫生运动新高潮。此次秋季爱国卫生运动时间为2014年10月，历时一个月。各级爱卫办要发挥综合协调作用，明确各部门职责任务，形成部门联动的工作局面。卫生计生部门要加强疫情和病媒生物监测报告，加强病例的早发现、早诊断、早治疗，落实免疫接种等工作。住房城乡建设部门要落实清扫保洁制度，及时清理卫生死角。环保部门要积极推动城乡环境污染整治，依法查处环境违法行为。教育部门要加强对学生的健康教育，改善学校教学、生活环境。宣传部门要组织各类媒体广泛宣传卫生防病知识。民政部门和工会、共青团、妇联要积极组织城乡社区、社会组织以及广大职工、青年、学生和妇女，参与环境综合治理和卫生防病工作。爱卫会其他成员单位要按照职责分工，组织开展好相关活动。

**二、**集中开展城乡环境卫生综合整治

各地要结合各类卫生创建活动，动员全社会，在城乡范围内广泛开展一次环境卫生集中整治活动。要彻底清除背街小巷、城中村、城乡结合部和铁路公路沿线的卫生死角，重点对学校、机场、车站、港口等人员聚集场所和农贸市场、建筑工地、“五小行业”等进行集中的环境卫生治理，规范活禽经营市场秩序，努力创造一个良好的卫生防病环境。

**三、**强化病媒生物防制

各地要认真贯彻落实《病媒生物预防控制管理规定》（全爱卫发〔2009〕9号），遵循以环境治理为主的综合防制原则，集中组织开展一次灭蚊灭鼠活动。特别是发生登革热疫情的重点地区，要落实属地责任、部门责任、单位责任和个人责任，把防蚊灭蚊措施落实到每个社区、单位和家庭，动员群众翻盆倒罐，清除室内和庭院积水，铲除蚊虫孳生环境。要坚持合理用药，建立健全病媒生物监测网络，加强病媒生物监测调查，及时评价防制效果，做到科学除害。

**四、**广泛开展健康教育

各地要充分利用各类大众传媒，采取专家访谈、信息发布、微博、微信、短信以及海报、单张等多种形式，创新宣传方式，有针对性地加强爱国卫生宣传，普及秋冬季重点传染病防治知识，进一步提高群众自我保健能力和及时主动就医意识。学校要加强学生防病知识教育，通过“小手拉大手”等活动来带动家庭和社会。国庆长假前后，在机场、车站、港口以及重点公共场所，要加大流动人口的宣传教育，防止疾病的流行扩散。

**五、**加大检查指导力度

各级爱卫办要会同有关部门加强督促检查，对重点地区工作进展情况进行现场督导，发现问题要及时督促解决，确保各项措施落实。要畅通监督渠道，主动接受社会和公众监督，认真梳理、整改群众反映的问题。对于各级卫生城镇、各类卫生先进单位的督导检查结果应作为复审抽查依据。

全国爱卫会办公室将抽查部分地区工作开展情况，各省级爱卫会要在11月15日前将此次活动开展情况总结报全国爱卫会办公室。

全国爱国卫生运动委员会

2014年9月30日
