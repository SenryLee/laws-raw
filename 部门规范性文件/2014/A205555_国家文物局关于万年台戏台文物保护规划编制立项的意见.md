# 国家文物局关于万年台戏台文物保护规划编制立项的意见

## 国家文物局关于万年台戏台文物保护规划编制立项的意见（办保函〔2014〕172号）

湖北省文物局：

你局《关于申请万年台戏台保护规划立项的请示》（鄂文物文[2013]127号）收悉。经研究，我局意见如下：

**一、**所报立项报告对规划编制的必要性、可行性说明不足，文本针对性、深度不够，我局暂不同意万年台戏台保护规划编制立项。

**二、**所报立项报告尚需做以下必要的修改和完善：

（一）进一步补充分析该规划编制的必要性、可行性。

（二）补充前期调研和现状调查，科学分析文物本体及周边环境面临的主要问题和破坏因素，制定有针对性的规划框架。

（三）补充、深化立项文本，如补充戏台周边环境的图纸、卫星影像和现状照片等。

（四）补充规划编制经费取费依据。

请你局根据上述意见，组织相关单位修改、完善该保护规划立项报告，经你局核准后，另行报批。

专此。

国家文物局

2014年03月11日
