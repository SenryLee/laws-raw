# 中国地震局党组关于张志波、孙建中、郭洪义3同志职务任免的通知

中共黑龙江省地震局党组：

2014年2月11日中国地震局党组决定，并征得中共黑龙江省委同意：

任命张志波同志为黑龙江省地震局副局长、党组副书记，主持工作；

任命郭洪义同志为黑龙江省地震局党组成员、纪检组组长，任职试用期1年；

免去孙建中同志黑龙江省地震局局长、党组书记职务，另有任用。

特此通知

中国地震局党组

2014年5月5日
