# 国家文物局关于召开2014年大运河遗产保护管理工作会议的通知

## 国家文物局关于召开2014年大运河遗产保护管理工作会议的通知（办保函〔2014〕788号）

各有关省（直辖市）文物局：

为全面总结回顾大运河保护和申遗工作进展，落实世界遗产委员会会议有关决议要求，研究部署下一阶段大运河遗产保护管理工作，我局定于近期召开2014年大运河遗产保护管理工作会议。现将有关事项通知如下：

**一、**会议时间及地点

（一）会议时间：2014年9月25日至27日。其中，25日报到，26日下午召开大运河遗产保护管理工作会议，27日疏散。

（二）会议地点：江苏省扬州市（具体地点另行通知）。

**二、**会议内容

通报第38届世界遗产委员会会议大运河申遗项目审议情况及有关会议决议；总结大运河保护和申报世界遗产工作主要成绩和经验；分析近期大运河保护工作存在主要问题；研究部署下一阶段大运河保护管理工作。我局领导将出席会议并发表讲话。

**三、**参会人员

主办和承办单位代表；大运河沿线省（直辖市）文物行政部门负责同志1～2人，大运河沿线地市人民政府负责同志1～2人，大运河31个遗产组成部分监测管理机构以及相关专业机构负责同志各1人；受邀媒体记者。

**四、**参会准备

（一）请各相关省（直辖市）文物行政部门组织本省（直辖市）相关地市参会，并汇总本省（直辖市）参会人员名单。

（二）请各相关省（直辖市）文物行政部门和地市人民政府分别准备本省（直辖市）、本地市大运河保护管理工作报告，重点阐述今后及下一阶段工作计划，由所在省（直辖市）文物行政部门汇总并做会议发言。

（三）请各相关省（直辖市）文物行政部门将汇总的参会人员名单和工作报告于2014年9月15日前，通过电子邮件报送至我局，同时抄送大运河联合申报世界文化遗产办公室。

**五、**参会费用

参会人员旅费自理，会议期间食宿费用由主办单位承担。
