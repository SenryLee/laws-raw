# 环境保护部公告2014年第47号――关于公布符合环保核查要求的草甘膦(双甘膦)生产企业名单(第一批)的公告

## 环境保护部公告（2014年第47号）

关于公布符合环保核查要求的草甘膦（双甘膦）生产企业名单（第一批）的公告

根据《关于开展草甘膦（双甘膦）生产企业环保核查工作的通知》（环办〔2013〕57号）要求，我部对申请企业进行了核查，形成了第一批符合环保核查要求的草甘膦（双甘膦）生产企业名单，现予以公告。

为进一步提升企业污染防治水平，我部将持续开展草甘膦（双甘膦）生产企业环保核查工作，发布符合环保核查要求的草甘膦（双甘膦）生产企业名单，并对已公告的草甘膦（双甘膦）生产企业进行复查和抽查，发现不符合环保核查要求的，将予以撤销。

附件：符合环保核查要求的草甘膦（双甘膦）生产企业名单（第一批）

环境保护部
