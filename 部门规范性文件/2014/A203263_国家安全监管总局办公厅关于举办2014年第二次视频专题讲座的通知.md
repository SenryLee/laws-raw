# 国家安全监管总局办公厅关于举办2014年第二次视频专题讲座的通知

国家安全监管总局办公厅关于举办2014年第二次视频专题讲座的通知

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局，各省级煤矿安全监察局，总局和煤矿安监局机关各司局、应急指挥中心，各在京直属事业单位、社团组织：

国家安全生产监督管理总局（以下简称总局）定于5月16日（星期五）15时举办2014年第二次视频专题讲座，由中国矿业大学（北京）教授傅贵同志讲解“事故预防的行为安全方法”（相关课件可从总局网站下载）。

请各单位组织相关人员按时参加。请总局和国家煤矿安监局机关各司局、应急指挥中心，各在京直属事业单位、社团组织于5月15日前，将拟参加人数报送总局培训中心；请各省级安全监管局和煤矿安监局于5月19日前，将参训情况统计表（见附件）反馈总局培训中心。

请各省级安全监管局和煤矿安监局通知有关人员按照总局通信信息中心要求，于5月16日13时开机准备。

联系人及电话：李少娇，010-64463627、64463870（传真）。
