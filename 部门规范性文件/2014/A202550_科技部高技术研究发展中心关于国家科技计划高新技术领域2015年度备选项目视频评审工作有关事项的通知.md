# 科技部高技术研究发展中心关于国家科技计划高新技术领域2015年度备选项目视频评审工作有关事项的通知

各省、自治区、直辖市、计划单列市科技厅（委、局），各项目推荐单位，各项目申报单位和项目技术负责人：

受科技部高新技术发展及产业化司委托，我中心将对通过形式审查的国家科技计划高新技术领域2015年度备选项目组织进行视频评审。现将评审工作有关事项通知如下：

**一、**评审工作安排

1. 评审时间。评审将于6月5日-6月25日进行。各领域将根据项目指南技术方向设立评审组，聘请同行专家进行评审。项目答辩评审时间安排详见附件1，我们同时通知负责视频答辩的地方科技主管部门。

2. 评审方式。评审采取网络视频答辩评审的方式进行。按照属地化原则，项目申报单位在所在地的地方科技主管部门设置的视频答辩会议室参加答辩；评审专家在科技部高技术研究发展中心设置的视频评审会议室进行评审。

3. 答辩安排。每个项目答辩时间为30分钟，主要包括三个环节：评审专家核对答辩人身份、答辩人陈述、评审专家提问。其中，答辩人陈述时间不超过20分钟，提问及回答提问的时间不超过10分钟。若超时，将自动切入下一个项目答辩。

4. 评审专家。评审专家名单将于评审前3天在科技部网站（www.most.gov.cn）和科技部高技术研究发展中心网站（www.htrdc.com）公布。

5. 应急措施。因意外造成视频评审系统无法连接时，将启用应急措施，采用电话音频系统继续答辩，答辩时间不做调整。

**二、**评审组织工作要求

（一）地方科技主管部门工作要求。

请各省、自治区、直辖市、计划单列市科技厅（委、局）（以下简称地方科技主管部门）协助我们组织好视频评审工作。若有问题，请及时与我们联系。

1. 请地方科技主管部门指定的评审工作人员和网络技术人员在评审期间保持通信畅通，做好答辩的安排协调和技术保障工作，对出现的问题及时沟通，现场解决。

2. 请各地方视频答辩室保证设备支持发送双流。

3. 根据答辩安排，请提前一天与参加视频答辩的项目申报单位联系，确认具体答辩地点和时间，保证答辩人员能按时参加答辩。

4. 请指定专人管理各视频答辩室，并组织好参加视频答辩的单位按照答辩安排和答辩要求参加答辩，维持答辩现场的工作秩序，做好答辩人员的接待和服务工作，保证答辩工作顺利进行。

5. 因意外情况造成视频评审系统无法连接时，将启用应急措施，采用音频系统继续答辩。请在各视频答辩评审会议室设置直拨电话一部，供应急使用。

（二）项目技术负责人要求。

1. 项目技术负责人原则上须亲自参加答辩。每个项目参加答辩的人员原则上不超过3人。

2. 评审将重点针对项目的研究目标和内容的重要性、可行性、创新性和前沿性、技术路线的可行性、研发团队科研能力、申报单位和参与单位的研发资质、经费需求的合理性等进行。请做好陈述材料的准备，建议使用PPT演示文稿。

3. 请严格按照预定的时间顺序进行答辩。项目技术负责人应提前与所在地方科技主管部门视频答辩会议室联系，落实答辩事宜。各地方科技主管部门视频答辩会议室联系方式详见附件2。

4. 建议每个项目的答辩人员提前1小时到达指定答辩地点。答辩人员未能按时参加答辩的视为自动放弃评审。

评审遵从公平、公正、公开的原则。项目申请方不得有影响专家评审公正性的违规违纪行为，如经查实确有此行为，将取消承担国家科技计划课题资格。
