# 国家邮政局关于《邓小平同志诞生一百一十周年》纪念邮票印制和销售服务专项监督检查情况的通报

国邮发〔2014〕191号

各省、自治区、直辖市邮政管理局：

《邓小平同志诞生一百一十周年》纪念邮票于2014年8月22日发行。为依法履行邮票发行监管职责，国家邮政局在全国范围内组织开展了对《邓小平同志诞生一百一十周年》纪念邮票印制与销售服务的专项监督检查。现将有关情况通报如下：

一、监督检查工作开展情况

2014年8月7日，国家局发文通知各省（区、市）邮政管理局（以下简称省局），安排部署此次监督检查工作，提出了检查重点和相关要求。同时，发文中国邮政集团公司，要求其做好该套邮票的销售服务工作。

从反馈情况看，各省局高度重视，精心组织，一方面安排省级以下邮政管理机构（以下简称各市（地）局）和监督员做好此次监督检查，另一方面及时与邮政企业进行沟通，通过听取汇报等方式，要求其认真准备，确保按时按量销售。多数省局通过了解掌握本行政区域内的邮票零售数量等相关情况，为开展检查打下了基础。发行首日，各省局有选择地对重点邮票销售网点服务情况进行了检查。

各市（地）局结合本地实际情况，细化监督检查方案，重点做好以下工作：一是在发行日前对邮票销售服务信息公布情况进行检查，与邮政企业沟通了解情况，二是在首发日当天对邮票销售情况进行现场检查，并对发现的问题要求企业现场改正。

大多数省局和大多数市（地）局及时将检查情况通报本行政区域内邮政企业，内蒙古、黑龙江、浙江、福建、江西、山东、河南、湖北、湖南、海南、重庆、贵州、新疆等地部分市（地）局还对检查中发现的问题下发了整改通知书，并跟踪落实。

8月14日，国家邮政局赵晓光副局长亲自赴北京邮票厂对该套邮票的印制、发运等情况进行了现场检查，并听取了印厂负责人的汇报，对邮票印制和组织发运工作提出要求。

二、销售监督检查的整体情况

据统计，此次共监督检查434个地级市（含直辖市的区、县）的1131个邮票销售网点，调查用户8575名。监督范围基本覆盖地级以上城市，检查网点占全国纪特邮票销售网点总数的38.3%。

（一）邮票销售信息公布情况

在检查网点中，93.4%的网点向社会公布了该套邮票的邮票名称、枚数、面值等信息。92.9%的网点公布了销售时间、种类、价格等新邮销售服务信息。90.8%的网点公布了零售数量信息。与《甲午年》生肖邮票检查情况相比，公布邮票销售信息的网点比率基本持平，略有下降。

（二）邮票供应情况

绝大多数纪特邮票销售网点能够在发行日前收到该套邮票，在发行首日提供邮票销售服务。据统计，在发行首日，94.4%的网点按时提供预订邮票领取服务。94.6%的网点供应了零售邮票。82.3%的用户对邮票供应量表示“满意”，13.9%的用户表示“基本满意”。

（三）服务态度和环境秩序情况

从检查情况看，用户对营业人员的服务态度普遍认为较好，87.8%的用户认为服务态度“好”，10.6%认为“较好”。对网点的环境和秩序，用户评价也较高，88.1%的网点获得“好”的评价，10.6%的网点获得“较好”的评价。上海、河南、新疆等省（区、市）部分网点采取有效措施，维护现场秩序，取得了良好效果。

（四）规范服务情况

此次检查中，未发现采用搭售等方式强迫消费者购买其他商品的情况；没有发现邮政企业低于、高于面值或者售价销售邮票 。

（五）邮票印制质量评价情况

从用户反映来看，大部分用户认为该套邮票印制质量较好，对邮票墨色、套印、打孔等的评价较高，“好”的评价比率分别为89.4%、90.0%、90.2%，“较好”的评价比率分别为9.6%、9.3%、8.5%。

三、存在的主要问题

依照《邮票发行监督管理办法》有关规定，此次检查发现邮票销售服务方面仍存在以下问题：

（一）部分省（区、市）纪特邮票销售服务信息公布有待加强。

仍存在部分网点未公布邮票销售服务信息，其中未公布零售数量的网点比率为9.2%。云南、内蒙古、广西等省（区）网点在纪特邮票发行日前公告邮票信息及销售服务信息的比率较低，其中内蒙古未于发行日前公告零售数量的网点比率达50%以上。山西、山东、四川、贵州、河南、海南、湖北、陕西、新疆等省（区）部分网点未公布邮票销售服务信息，尤其是邮票零售数量。此外，部分省（区、市）网点存在公布信息不准确现象，部分网点消费者反映，网点张贴销售公告的时间过晚，给用户造成不便。

（二）存在提前销售邮票行为，部分网点不能在邮票首发日按时提供预订取票、零售服务。

检查发现，陕西省榆林市航宇路邮政大楼邮资票品局集邮门市邮票销售网点于8月20日已经提前开始销售《邓小平同志诞生一百一十周年》纪念邮票。

广西、内蒙古、云南等省（区）不能按时提供预订取票、零售服务的网点比率达30%。广西、四川、西藏、新疆等省（区）部分县的销售网点未能及时到货，导致发行首日不能提供预订取票和零售服务。安徽部分纪特邮票销售网点不提供本次邮票的零售服务，给消费者带来不便。

（三）部分省（区、市）纪特邮票零售数量仍然不能满足消费者需求。

从检查情况看，甘肃、陕西消费者对邮票供应量不满意比率相对较高，不满意比率分别为12.8%、9.4%。山西、黑龙江、福建、四川、北京、安徽、湖北、海南、河南、江西、西藏等省（区、市）也反映邮票供应量不足，不能满足消费者需求。

（四）邮票销售服务水平有待进一步提高。

陕西、福建、四川、江苏、海南等省消费者反映，由于破版不当等原因，买到的邮票存在边缘破损、出现缺口现象，影响了邮票收藏价值；广西、福建、江西等省（区）个别网点存在网点秩序混乱等情况。

四、评价与要求

总体来看，各级邮政管理部门积极贯彻落实《邮票发行监督管理办法》有关规定，认真组织安排，做好监督检查工作。此次专项检查，共有邮政管理部门执法人员954人、特邀邮政监督员763人参加。山西等局在检查中认真听取消费者意见和建议，并及时反馈邮政企业，要求其认真研究、妥善处理；山东滨州市邮政管理局针对阳信县邮政企业在发行日前未按规定做好信息公示、发行日当天未按规定向社会提供邮票销售服务行为，按照《邮票发行监督管理办法》的规定，做出了“警告”的行政处罚，维护了消费者的合法权益。

同时也应该看到，纪特邮票印制和销售中仍存在一定问题，各级邮政管理部门要进一步督促邮政企业提高服务质量和水平。现就继续做好邮票印制和销售监管工作提出以下要求：

（一）继续加强邮票发行监管行政执法工作，切实维护消费者利益。对于检查中发现的邮政企业违反邮票印制和销售有关规定的行为，要及时进行通报，督促整改。对于那些经通报仍无改进的问题，要严格按照《邮政行政处罚程序规定》和《邮票发行监督管理办法》有关规定，做好取证工作，依法立案查处。

（二）进一步建立健全邮票监督检查长效机制，加强邮票销售日常检查。要结合本省（区、市）实际情况，逐步建立行之有效的沟通协调工作机制。开展邮票销售情况监督检查是各省局邮票发行监管的重点工作之一，应贯穿于全年日常工作当中。各省局要充分发挥政府监管、社会监督、企业自律三位一体的监管体系作用，切实做好邮票印制和销售的监督检查工作，促进集邮市场健康发展。
