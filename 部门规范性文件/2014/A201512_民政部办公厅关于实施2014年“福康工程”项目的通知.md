# 民政部办公厅关于实施2014年“福康工程”项目的通知

民政部办公厅关于实施2014年“福康工程”项目的通知

（民办函〔2014〕213号）

内蒙古自治区、广西壮族自治区、重庆市、四川省、贵州省、云南省、西藏自治区、陕西省、甘肃省、青海省、宁夏回族自治区、新疆维吾尔自治区民政厅（局），新疆生产建设兵团民政局：

为提高西部地区福利机构及贫困残障者的康复保障水平，按照民政部本级福利彩票公益金使用计划，2014年，民政部将继续实施“福康工程”项目。现将有关事项通知如下：

**一、**项目基本情况

（一）实施范围及内容。

1.对西部地区福利机构集中供养的“三无”、长期安置的残障者及社会贫困家庭残障者免费配置假肢、矫形器等辅具产品；

2.继续为西部地区福利机构免费配置室内移动辅具、残障者专用生活起居床、可折叠洗浴床等无障碍辅具产品，提升机构的无障碍化水平；

3.对西部地区福利机构集中供养的“三无”、长期安置的残障者及社会贫困家庭残障者中的肢体畸形患者进行手术矫治，结合辅具配置实施康复。

**二、**项目组织管理

本项目由民政部主管，国家康复辅具研究中心具体承办，西部地区各省（自治区、直辖市）民政厅（局）配合实施。

**三、**项目实施步骤

（一）需求汇总。2014年6月底之前完成对西部地区辅具配置以及矫治手术需求数据的初步汇总。

（二）实地调研。2014年6月-7月，由民政部有关司局、国家康复辅具研究中心联合组成调研组，实地核实辅具需求情况及相关安装条件。

1.调研对象。各地近年已实施及2014年拟推荐实施“福康工程”的福利机构及受助对象。

2.调研内容。对近年来“福康工程”项目实施后的辅具使用情况进行回访；调查了解福利机构及基层贫困残障者2014年度对各类辅具产品的实际需求、建议和意见，与基层民政机构工作人员座谈交流，探讨建立“福康工程”项目长效机制，更好地为民政对象中的残障者解决实际问题。

（三）辅具配置及康复手术。

1.2014年12月前，联合地方民政直属康复辅具装配机构，完成对西部地区假肢、矫形器配置工作；与各地民政机构密切合作，由国家康复辅具研究中心附属康复医院完成西部地区肢体残障患者手术矫治工作。

2.2014年12月前，完成福利机构辅具的配发及安装工作。

**四、**有关工作要求

（一）认真做好相关数据统计工作。按项目实施计划安排，各项目省份根据实际情况，将本地区福利机构及社会贫困残障者需配置的各类辅具以及肢残患者手术矫治需求数据（见附件1-3）汇总，于6月30日前报送国家康复辅具研究中心。此次统计数据将作为2014年“福康工程”实施的重要依据，各地要确保有关数据信息真实、准确、可靠。

（二）积极做好相关协调配合工作。各项目省份民政部门对项目实施过程中存在的问题、有关方面的反映和工作建议及时进行反馈，并配合做好调研和项目实施工作。
