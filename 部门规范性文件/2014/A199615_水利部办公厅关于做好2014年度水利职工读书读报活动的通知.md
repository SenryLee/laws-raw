# 水利部办公厅关于做好2014年度水利职工读书读报活动的通知

## 水利部办公厅关于做好2014年度水利职工读书读报活动的通知(办宣〔2014〕158号　2014年8月19日)

部机关各司局，部直属各单位，各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局：

基层水利职工读书读报提升素质活动自2012年开展以来，活动内容和形式不断丰富，广大水利职工积极参与，取得了良好效果。在总结前两年活动经验成效的基础上，活动从2014年开始变更为“水利职工读书读报活动”，活动周期调整为自然年度.2014年度活动举办时间为8-12月，现将有关事项通知如下：

**一、**活动组织

活动由水利部办公厅、人事司，中国水利报社主办，黄河万家寨水利枢纽有限公司协办。

**二、**活动安排

本年度开展两期答题活动，每期活动期限为两个月。第一期为常规有奖答题，题目及答题卡将于8月上旬刊出；第二期为水文专项有奖答题，题目及答题卡将于10月中旬刊出。

（一）答题方式。活动除采用报纸答题和网络答题两种形式外，还特别开通微信答题。每期题目及答题卡在《中国水利报》连续刊登3次。水利部网站（www.mwr.gov.cn）和中国水利网站（www.chinawater.com.cn）同步开设网络答题专区。可搜索关注微信公共账号“水利职工读书读报”或扫描报纸成网站提供的二维码进入微信平台按要求答题。

为便于读者准确获取相关知识，题目刊出前，答题相关内容将在中国水利报上集中刊出。

（二）答题内容。第一期答题内容将紧紧围绕中央有关水利重大决策部署和水利部中心工作展开，包括新出台的重要条例和办法、重要会议精神，以及水资源常识等。第二期答题内容将重点突出“大水文”发展理念和水文工作“三夯实、五强化”的要求，围绕水文改革发展重点工作，就水文职工的职责、基本技能、水文法规、水文文化建设等应知应会常识组织题目。

**三、**奖项设置

（一）“读书读报幸运读者”。一期一评，每期40名，从每期纸质、网络和微信答题全部正确的参赛人员中随机抽取。

（二）“读书读报优胜集体”。共20名，根据各单位提交的答题活动组织情况等材料综合评分择优选取。

所有获奖名单将在《中国水利报》、水利部网站、中国水利网站上公布。

**四、**活动要求

（一）各单位要高度重视并切实加强组织领导，认真组织发动本单位职工参与答题。

（二）参与人员可从《中国水利报》获取答题卡，答题卡复印有效，答题完毕将答题卡邮寄到中国水利报社记者读者部；也可登陆水利部网站、中国水利网站，或通过微信平台进行在线答题。参加每期答题的水利系统干部职工，经所在单位人事部门核实后，可按12学时登记培训时间。

（三）申报“读书读报优胜集体”的单位，要认真填写《水利职工读书读报活动情况介绍表》（见附件），并提交500字左右的活动组织情况介绍。
