# 中共国土资源部党组关于印发2014年国土资源部党组中心组学习计划的通知

## 中共国土资源部党组关于印发2014年国土资源部党组中心组学习计划的通知（国土资党发[2014]6号）

国家海洋局、国家测绘地理信息局，中国地质调查局及部其他直属单位，各派驻地方的国家土地督察局，部机关各司局：

《2014年国土资源部党组中心组学习计划》已经部党组审定，现印发给你们。请按照学习计划的要求，结合本司局、本单位实际，对全年学习做出安排，并认真抓好落实。

中国共产党国土资源部党组

2014年2月10日

2014年国土资源部党组中心组学习计划

按照《中央宣传部中央组织部关于组织党委(党组)中心组深入学习习近平总书记系列讲话精神的通知》、《中央组织部关于做好县处级以上领导干部学习贯彻习近平总书记系列讲话精神集中轮训工作的通知》、中央国家机关工委有关要求、全国国土资源工作会议部署和部党组群众路线教育实践活动整改落实方案，制定2014年中共国土资源部党组中心组学习计划如下。

**一、**指导思想

2014年是贯彻落实党的十八届三中全会精神、全面深化改革的第一年，是弘扬优良作风、推进密切联系群众常态化长效化的一年，国土资源改革发展各项工作任务重大而艰巨。部党组中心组要高举中国特色社会主义伟大旗帜，坚持以邓小平理论、“三个代表”重要思想、科学发展观为指导，认真学习、贯彻落实党的十八大、十八届三中全会和习近平总书记系列讲话精神，不断加强理论武装，紧紧围绕“尽职尽责保护国土资源、节约集约利用国土资源、尽心尽力维护群众权益”，进一步统一思想、明确思路，为贯彻落实中央重大决策部署、全面完成2014年国土资源管理工作、推动国土资源事业改革发展提供强有力的理论指导和思想政治保证。

**二、**学习内容和具体安排

2014年，部党组中心组将在中央组织部、中央宣传部和中央国家机关工委的指导下，坚持以领导班子和领导干部为重点，以提升党性修养和思想作风为根本，以推动中心工作为目的，把党组中心组学习与国土资源改革发展大局相结合，切实抓好思想理论武装工作，重点开展四个专题学习。

(一)开展习近平总书记系列讲话精神专题学习。按照《中央宣传部中央组织部关于组织党委(党组)中心组深入学习习近平总书记系列讲话精神的通知》要求，通过召开党组 (党委)中心组学习会、辅导讲座、集中轮训、交流研讨等形式，认真学习研读习近平总书记系列讲话原文，深入领会习近平总书记围绕改革发展稳定、内政外交国防、治党治国治军等各方面发表的一系列重要讲话中提出的新思想、新观点、新论断、新要求，深刻把握习近平总书记系列讲话贯穿的立场观点方法，学深吃透其中的主要内容和精神实质，不断加强理论武装工作，更好地把思想和行动统一到中央重大决策部署上来。

在学习安排上，一是按照“全面掌握精神、密切联系实际”的原则要求，拟开展两次党组中心组集中学习。第一次是待全体部党组成员参加中央党校举办的省部级干部学习贯彻习近平总书记系列讲话精神研讨班后，召开部党组中心组专题学习会，党组成员交流学习体会，全面掌握系列讲话精神，进一步深化思想认识；第二次是结合落实全国国土资源工作会议精神，部党组成员集中研讨如何在国土资源工作中贯彻落实好习近平总书记系列讲话精神，推动国土资源事业改革发展。二是举办专题辅导讲座，重点围绕中国特色社会主义、社会主义民主政治和依法治国，邀请权威专家系统解读讲话精神。三是组织集中轮训，部党组带领党员干部分期分批深入学习领会讲话精神。(贯穿全年，一、二季度侧重)

(二)开展贯彻落实党的十八届三中全会精神，深化国土资源管理改革专题学习。深入学习贯彻党的十八届三中全会、中央经济工作会议、中央城镇化工作会议、中央农村工作会议和全国“两会”精神，深刻学习领会中央领导同志对全面深化改革和国土资源工作作出的一系列重要指示精神，通过召开研讨会、开展专题调研、举办辅导讲座等多种形式，深入研究思考，进一步统一思想认识，明确工作思路，加强顶层设计，积极探索实践，确保国土资源管理改革有序推进。

在学习安排上，一是组织专题研讨。要深刻领会中央领导同志关于严防死守耕地红线、节约集约利用土地和积极稳妥推进土地管理制度改革的重要指示精神，深入理解和准确把握三中全会关于土地管理制度改革的重大举措和核心要求，本着“坚守底线、试点先行”的原则，认真研究稳妥推进土地管理制度改革的思路框架和试点工作方案；要深入学习领会中央关于自然资源管理制度改革的部署要求，充分研究论证并提出自然资源管理制度和体制机制改革的总体思路和框架，着手探索构建系统完整的自然资源管理制度体系；深入学习领会国务院机构改革和职能转变方案，认真研究加快推进土地矿政审批制度改革的具体措施。二是开展专题调研。与年度调研工作安排相结合，充分利用基层联系点工作机制，重点围绕夯实土地权能、完善征地制度、农村宅基地管理、农村集体经营性建设用地入市等问题开展调查研究。(贯穿全年，二、三季度侧重)

(三)开展密切联系群众、加强机关作风建设常态化长效化专题学习。认真学习贯彻中央关于反对“四风”、密切联系群众、弘扬优良作风常态化长效化的要求，坚持边学习边实践边总结，抓住整改落实和建章立制两个关键，着力形成作风建设的长效机制，巩固教育实践活动成果，通过作风改进提高部门公信力、执行力和服务能力。

在学习安排上，一是开展坚定理想信念主题教育实践活动，引导党员干部将树立远大目标与做好当前工作紧密结合，进一步坚定共产主义理想信念，坚持用中国特色社会主义理论体系武装头脑，立足本职，胸怀大局。二是组织专题研究。围绕征地补偿安置、“小产权房”清理、地质灾害防治、土地整治等涉及群众切身利益的突出问题，研究切实可行的解决办法，进一步完善维护和保障群众权益的相关制度和程序，强化维护群众权益的执法监督力度，依法严肃查处与民争利、损害群众合法权益的行为；研究制定贯彻落实《党政机关厉行节约反对浪费条例》的实施办法，修订关于进一步改进部、局级干部工作作风、密切联系群众的若干规定，严控“三公”经费支出，严格执行住房、车辆配备和使用等规定，厉行勤俭节约。(贯穿全年，三、四季度侧重)

(四)开展党风廉政建设专题学习。认真学习贯彻十八届中央纪委三次全会和国务院廉政工作会议精神，通过召开党组中心组学习会、典型案例教育、举办辅导讲座等方式，认真研究加强廉政风险防控建设，推进国土资源领域专项治理的有效措施，增强领导干部廉洁从政意识和拒腐防变能力。

在学习安排上，一是召开党组中心组学习会，深入学习习近平总书记在十八届中央纪委三次全会上的重要讲话、王岐山同志代表中央纪委常委会作的工作报告和国务院廉政工作会议精神，进一步提高思想认识，严明组织纪律，研究贯彻落实的具体措施。二是组织专题研讨。按照中央要求，结合部门实际，认真研究部署国土资源部党风廉政建设和反腐败工作，研究制定国土资源系统健全惩治和预防腐败体系2013-2017年工作规划。加强纪检工作规律研究，不断推进部直属机关纪检工作思路、方法、内容和体制机制创新。三是举办专题辅导讲座。坚持理论学习与典型案件教育相结合，利用国土资源学习大讲堂平台，邀请权威专家作加强党风廉政建设和反腐败工作专题辅导，教育引导党员干部特别是领导干部进一步增强党章意识、纪律意识，自觉用党章规范言行，严格遵守党的纪律特别是政治纪律，对中央要求令行禁止。四是深化党风廉政宣传教育。以党性党风党纪教育和道德品行教育为重点，深入开展示范教育、警示教育和岗位廉政教育。大力发掘和培育廉洁从政先进典型，充分发挥典型示范作用，注重用身边人和事强化警示效果。深入开展“廉洁国土”创建活动，继续推进廉政文化进机关、进基层、进家庭，进一步深化国土资源廉政文化建设，树立清廉机关形象。通过通报典型案例、组织实地考察等形式开展警示教育。(贯穿全年，一、四季度侧重

)

**三、**有关要求

(一)中心组成员要带头学习，发挥好示范引领作用。要充分发挥党组中心组成员的示范引领作用。部党组成员不仅要加强对分管司局和联系单位的学习指导，还要带头学习、亲自参与、深入研讨，主动结合工作实际谈认识、说体会、想问题、谋思路，努力建设学习型领导班子，把学习当成一种生活态度、一种工作责任、一种精神追求，作为提高思想政治素质和理论水平、提高管理能力和服务水平的有效途径，按照理论武装头脑、指导实践、推动工作的要求，深入学习贯彻十八届三中全会精神，准确把握党和国家新的重大战略部署和指示要求，用以指导国土资源管理工作。不断增强政治定力，提升党性修养，进一步坚定中国特色社会主义道路自信、理论自信和制度自信。坚持开展基层调研，把理论学习和业务学习、向书本学习和向实践学习结合起来，不断增强工作的前瞻性、预见性、主动性和政治敏感性。

(二)坚持学以致用，以学习指导和促进实际工作。要大力弘扬理论联系实际的马克思主义学风，紧密结合国土资源改革发展的实际，坚持知与行相结合、务虚与务实相结合、学习研究与解决重大现实问题相结合，既专注于学习，又躬身于实践，使党员干部把党组中心组学习成果科学地应用到实践中，推动国土资源管理工作改革发展。要围绕国土资源管理的重点领域和关键环节，带着问题以及解决问题的初步思路和政策措施，加强理论学习，深入基层调研，开展务虚研讨。通过学习总结实践、探索实践、推动实践，增强政策措施的针对性、监管的有效性和运行的协调性，提高党员领导干部善治善为的能力，推动保护资源、保障发展、维护权益各项措施落实到位。

(三)创新学习方式方法，提升学习的吸引力和影响力。充分利用国土资源学习大讲堂平台，进行重要理论辅导、政经形势报告、热点问题分析和重要政策解读等；充分发挥网上学习大讲堂和视频会议系统的作用，创建共享互动的远程教育平台和开放畅通的网络宣传平台，增强学习的灵活性；探索创新集中轮训、实地调研、专题研讨、培训考察、学习交流会等多种学习形式，提升学习的科学有效性。

(四)构建促进和保障学习的长效机制，确保学习实效。健全和落实党组书记负总责、党组成员亲自参与并加强指导、部机关党委和办公厅组织协调、一级抓一级、层层抓落实的领导体制和学习机制。要采取有效措施，确保学习安排落实到位。部党组层面，每两个月至少开展1次专题学习讨论，每季度至少举办1次党组中心组(扩大)学习活动，党组中心组全年集中学习时间累计不少于12个工作日；部机关各司局、各直属单位和各派驻地方的国家土地督察局要根据党组中心组学习计划安排，结合本单位实际，本着集中学习与分散组织相结合的原则，认真组织开展学习活动。
