# 农业部公告第2060号――关于给英特威国际有限公司等3家公司核发《进口兽药注册证书》的公告

## 农业部公告（第2060号）

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准英特威国际有限公司等3家公司生产的芬苯达唑粉等6种兽药产品在我国再注册，核发《进口兽药注册证书》，并发布修订后的产品质量标准、说明书和标签，自发布之日起执行。此前发布的同品种兽药产品质量标准同时废止。

批准硕腾公司生产的癸氧喹酯预混剂在我国变更注册。

特此公告。
