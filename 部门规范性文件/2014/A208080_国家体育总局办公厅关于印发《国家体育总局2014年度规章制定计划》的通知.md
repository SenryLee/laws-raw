# 国家体育总局办公厅关于印发《国家体育总局2014年度规章制定计划》的通知

各司、局，有关直属单位：

现将《国家体育总局2014年度规章制定计划》印发给你们，请各有关单位在组织起草工作时，注意以下问题：

**一、**深入贯彻党的十八届三中全会精神，以转变政府职能，建设法治政府和服务型政府为指导，做好规章制定工作。

**二、**按照《行政许可法》、《立法法》和行政审批制度改革要求，严格遵守有关立法权限规定，防止违规设定行政许可、非行政许可审批和备案事项，切实维护法制统一。

**三、**按照《国家体育总局规章制定程序规定》，认真做好规章调查研究、征求意见等组织起草工作。

**四、**报请局长办公会审议发布的部门规章，必须在计划规定时间内按时完成。

**五、**2014年度规章制定计划既包括部门规章，也包括规范性文件，仅规范总局本级内部事务的规范性文件原则上不列入本计划。

各部门、各单位在计划实施过程中，如有必须调整的项目，请及时与政策法规司联系。
