# 国家机关事务管理局关于2014年公共机构节约能源资源工作安排的通知

国家机关事务管理局关于2014年公共机构节约能源资源工作安排的通知

（国管节能〔2014〕33号）

2014年是深入贯彻落实党的十八届三中全会精神、全面深化改革的第一年，也是完成公共机构节能“十二五”规划任务的关键一年。国家机关事务管理局关于公共机构节约能源资源工作的总体要求是：按照“紧紧围绕建设美丽中国，深化生态文明体制改革”的要求，协调推进在管理体制机制改革方面实现新的突破；坚持以节约型公共机构建设为主线，突出抓好机关、学校、医院三个重点领域节能工作；落实“使市场在资源配置中起决定性作用”的要求，积极推进利用市场机制实施节能改造和新产品新技术推广应用；大力推进公共机构能源资源管理信息化建设，逐步建立能源消费定额标准体系。通过努力，实现全国公共机构人均综合能耗和人均水耗同比分别下降3.2%，单位建筑面积能耗同比下降2.5%。现就今年的主要工作安排通知如下：

**一、**加强业务指导和制度建设

协调指导各地区、各部门完善公共机构节能法规制度和标准体系。制定公共机构节约能源资源考核办法、公共机构节能节水技术产品参考目录及管理办法，组织编制节约型公共机构示范单位分类评价标准。

推动和指导教科文卫体和行业系统节能工作。加大力度协调推动教育部所属高校、卫生部所属医院能源资源消费统计、节能改造工作。推进科技、文化、体育系统所属单位节能工作。

**二、**推进节约型公共机构示范单位创建

会同发展改革委、财政部完成第一批节约型公共机构示范单位创建工作，公布节约型公共机构示范单位名单。组织开展第二批节约型公共机构示范单位创建活动。积极开展绿色建筑行动，推进公共机构既有办公建筑绿色改造。组织推进中央国家机关16个节约型办公区建设工作。推动中央国家机关所属单位建设节约型公共机构工作。

**三、**推动节水和资源回收利用工作

会同水利部推进公共机构节水型单位建设，指导各地区制定节水型单位建设标准，确定一批节水示范单位。组织推动中央国家机关所属公共机构创建节水型单位。继续推进中央国家机关和各地区公共机构废旧商品回收体系建设，会同商务部门重点做好中央国家机关废旧灯管回收处理工作。组织实施中央国家机关餐厨垃圾就地资源化处理项目。

**四、**推广节能新产品、新技术和合同能源管理机制

完成2014年财政补贴高效照明产品推广工作，组织对近年来高效照明产品推广情况进行检查。协调发展改革委、财政部落实LED照明产品推广计划。推动公共机构建设分布式光伏发电系统。继续开展电力需求侧管理和能源管理体系建设试点工作。

印发《公共机构合同能源管理实施指南》，召开现场推广会，开展业务培训。组织部分高校、医院等公共机构运用合同能源管理等方式开展节能改造。做好公共机构节能、绿色节能关键技术研究与示范两个国家科技支撑计划项目实施的管理工作。

**五、**实施中央国家机关节能改造

编制中央和国家机关节约型办公区评价导则实施指南、中央国家机关数据中心机房节能改造指南和节能运行指导手册。组织实施中央国家机关260万平方米办公建筑和部分高校、医院供热计量节能改造。开展中央国家机关320万平方米办公建筑节能监管体系建设。完成中央国家机关数据中心机房、水泵变频、循环水复式过滤器等项目节能改造。推广应用节能插座。协调发展改革和财政部门落实中央国家机关所属在京公共机构供热计量节能改造、节能型电开水器等项目资金。

**六、**强化统计和监督考核工作

推进公共机构节能工作信息化建设，制定公共机构节能管理信息系统建设方案，推广应用公共机构能耗统计信息系统。组织开展能源审计工作。

分解下达2014年中央国家机关节能指标。组织各地区公共机构和教育部直属高校能源资源消费统计数据会审。对各地区公共机构2013年度节能目标完成情况进行核查，加强重点地区工作督导。开展中央国家机关及所属单位节约能源资源工作考核。

**七、**深入开展宣传培训

大力开展公共机构落实生态文明建设部署和《党政机关厉行节约反对浪费条例》等法律法规宣传教育。组织开展2014年公共机构节能宣传周和低碳日活动，筹划落实好各项主题宣传活动。抓好日常节能宣传，定期编发简报，及时更新维护公共机构节能网站内容，通过新闻媒体大力宣传公共机构节能减排成效和经验。

编制公共机构节能培训纲要，完善公共机构节能培训课程体系。分层次、分区域、分系统举办公共机构节能管理干部培训班。组织开展公共机构节能管理远程培训。举办中央国家机关节约型办公区建设、办公建筑节能监管体系、数据中心机房节能改造等业务培训。

新的一年，公共机构节约能源资源工作改革发展的任务十分繁重。各地区、各部门要根据中央关于推进生态文明建设的统一部署，按照《“十二五”节能减排综合性工作方案》和《公共机构节能“十二五”规划》要求，以切实降低公共机构能源资源消耗为出发点和落脚点，结合实际扎实做好今年各项工作。
