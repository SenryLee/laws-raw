# 国家民委关于举办2014年民族题材优秀专题专栏暨民族题材好新闻推荐活动的通知

文宣函[2014]196号

中央主要新闻媒体、重点新闻网站，委属各新闻单位及所属网站：

2014年，各新闻媒体围绕共同团结奋斗、共同繁荣发展的民族工作主题，大力宣传以习近平同志为总书记的党中央关于做好新形势下民族工作的一系列重要指示精神，生动展示近年来特别是党的十八大以来民族工作、少数民族和民族地区发展取得的巨大成就，集中报道在民族团结进步事业中涌现出来的先进典型，为中央民族工作会议的召开和会议精神的贯彻落实营造了良好的舆论氛围。为回顾和总结2014年的民族工作宣传报道，进一步调动各媒体宣传贯彻中央民族工作大政方针、改进创新民族工作宣传的积极性主动性，我委将于年底举办2014年民族题材优秀专题专栏暨民族题材好新闻推荐活动。

**一、推荐标准**

（一）推荐的作品应充分体现党的十八大精神和习近平总书记系列重要讲话精神，充分体现中央民族工作会议精神和党和国家关于民族工作的大政方针，坚持为人民服务、为社会主义服务、为民族工作大局服务。

（二）推荐作品应以反映民族团结和国家统一为主旨的核心价值和核心利益，反映党的民族理论、民族政策和民族区域自治制度优越性，反映各民族团结友爱的优良传统和平等团结互助和谐的社会主义民族关系，反映民族地区经济社会发展成就、民族工作的重大事件、热点问题、少数民族优秀文化和先进典型等为题材。

（三）推荐作品应以坚持团结稳定鼓励、正面宣传为主的方针，坚持正确的舆论导向，落实“三贴近”要求，新闻性、时效性、感染力强，内容真实，主题鲜明，富于创新，为人民群众喜闻乐见。

**二、推荐作品时间、范围**

（一）时间

作品发布于2013年12月20日至2014年12月10日之间。

（二）范围

中央主要新闻媒体、重点新闻网站和国家民委所属新闻单位及所属网站等刊（播）发的与民族工作有关的专题专栏、新闻消息、社论、通讯系列报道、广播电视作品、网络原创消息评论通讯、首发摄影作品等。

**三、推荐和奖励办法**

（一）两项推荐内容均以各新闻媒体为单位统一向推荐委员会推荐，由各单位填写推荐表报送至国家民委文宣司。

（二）拟推荐国家民委2014年民族题材优秀专题专栏30个；民族题材好新闻分别设特别奖和一、二、三等奖，共40篇。

（三）推荐作品在各媒体及新闻单位自主推荐的基础上，由推委会甄选把关，报推委会领导最后审定。

（四）按照惯例，入选的推荐作品颁发证书（国家民委章）及奖金，在国家民委网站主页进行公示。

（五）拟于12月下旬公布国家民委2014年民族题材优秀专题专栏暨民族题材好新闻推荐活动入选名单。

**四、作品推荐和报送要求**

（一）每单位推荐专题专栏原则上不超过3个，好新闻不超过5篇（组）。

（二）好新闻与专题专栏可重复推荐。

（三）专题专栏须注明推荐单位。好新闻须注明作者姓名，作者超过1人的，姓名排序以刊发时为准。

（四）报送内容包括作品推荐表和电子版。

1.专题专栏和好新闻推荐表分别包括《国家民委2014年度民族题材优秀专题专栏推荐目录》、《国家民委2014年度民族题材优秀专题专栏推荐表》；《国家民委2014年民族题材好新闻推荐目录》、《国家民委2014年民族题材好新闻推荐表》。

2.专题专栏和好新闻的推荐表格均需报送纸质版，加盖推荐单位公章后，寄送至国家民委文宣司。推荐作品只需报送电子版，并发至指定工作邮箱。

（五）请各新闻单位务必于12月12日前将材料报送齐全，逾期不补。

附件：1.《国家民委2014年度民族题材优秀专题专栏推荐目录》

2.《国家民委2014年度民族题材优秀专题专栏推荐表》

3.《国家民委2014年民族题材好新闻推荐目录》

4.《国家民委2014年民族题材好新闻推荐表》

以上通知和相关表格请登录国家民委网站（www.seac.gov.cn）主页“通知公告”下载电子版。
