# 人力资源和社会保障部办公厅关于做好2014—2015学年度全国技工院校华育奖助学金评定发放工作的通知

## 人力资源和社会保障部办公厅关于做好2014-2015学年度全国技工院校华育奖助学金评定发放工作的通知（人社厅函〔2014〕345号）

有关省、自治区人力资源社会保障厅：

2008年，我部与北京华育助学基金会共同设立“全国技工院校华育奖助学金”（以下简称奖助学金）。该奖助学金实施六年来，共资助万名品学兼优、家庭经济困难的技工院校学生，在帮助其顺利完成学业，培养国家建设需要的技能人才方面起到积极的促进作用。为进一步做好2014-2015学年度奖助学金评定发放工作，现将有关事项通知如下：

**一、**2014-2015学年度奖助学金共计300万元人民币，奖助学金标准为每人3000元。

**二、**奖助学金的资助对象为品学兼优、家庭经济困难的技工院校二年级和在国家级、省级技能大赛中获奖，品学兼优且家庭经济困难的技工院校三年级学生。经我部与北京华育助学基金会共同商定，本学年度奖助学金发放地区为安徽、山东、河南、广东、广西、陕西、甘肃7个省（自治区）。具体名额及奖助学金数额详见附件1。后续年度奖助学金发放地区将视情况进行调整。

纳入资助范围的地区，可在人社部门举办或综合管理的技工院校中，选择边远、贫困地区的学校列入受助学校范围。各地受助名额分配应相对集中，避免过度分散。

**三、**奖助学金发放管理工作继续委托中国职工教育和职业培训协会（以下简称“中国职协”）承担。有关省级人社部门应高度重视奖助学金发放管理工作，加强组织领导，认真指导有关学校做好奖助学金的评定发放工作，并根据《2014-2015学年度全国技工院校华育奖助学金管理办法》（以下简称“管理办法”，附件2），制定本地区奖助学金具体评定办法，对奖助学金的落实情况进行监督检查。要将技工院校华育奖助学金纳入当地技工院校学生资助管理工作体系统一部署实施。

受助技工院校需与北京华育助学基金会签订《全国技工院校华育奖助学金资助协议书》，严格执行奖助学金申领办法，发给学生的奖助学金不得用于抵扣学生在校期间的其它费用，并做好受助学生的资格审查和资料报送工作。

**四、**各有关省级人社部门和受助技工院校要严格按照管理办法和2014-2015学年度全国技工院校华育奖助学金评定发放工作流程（附件3）的要求，在规定时间内报送相关材料，并确保材料齐全、内容真实准确。未能按规定要求和时间上报，影响整体工作进度的，将视情况削减下年度该地区奖助学金额度或取消受助资格。

**五、**各有关省级人社部门和技工院校要认真做好华育奖助学金评定发放工作总结，做好华育奖助学金评定发放的实施效果评估工作，加强对关键指标、数据的统计、分析，并在此基础上认真撰写总结报告。同时，要做好华育奖助学金受助学生典型励志事例的搜集、整理工作，充分利用报刊、电视、网络等媒介进一步加大宣传报道力度，提升华育奖助学金的社会关注度及社会影响力。

**六、**2014-2015学年度奖助学金相关文件可登陆中国职协网站（www.zhongguozhixie.com.cn）查阅，相关电子表格亦可下载填写并打印。各地、各院校在材料填报过程中如遇问题，可及时与中国职协联系。

附件2

2014-2015学年度全国技工院校

华育奖助学金管理办法

**一、**奖励目的

为帮助品学兼优、家庭经济困难的技工院校学生顺利完成学业，激励他们自强自立、勤奋学习、积极上进，促进其实现稳定、高质量就业，早日成为国家建设需要的技能型人才。

**二、**奖励对象

在教学质量好、就业率高的技工院校中推选奖励对象发放华育奖助学金：

（一）品学兼优且家庭经济困难的技工院校二年级学生；

（二）在国家级、省级技能大赛中获奖，品学兼优且家庭经济困难的技工院校三年级学生。

**三、**奖助学金标准

奖助学金标准定为每人3000元。

**四、**组织实施

（一）本奖助学金由北京华育助学基金会出资。2014年，人力资源社会保障部综合考虑当年奖助学金总额、各地技工院校基本情况和地区贫困程度等多种因素，与北京华育助学基金会共同商定在全国范围内选取7个省份实施华育奖助学金项目。中国职工教育和职业培训协会（以下简称“中国职协”）依托有关省级人力资源社会保障部门承担奖助学金的发放管理工作。

（二）有关省级人力资源社会保障部门应加强组织领导，依据本办法，制定本地区奖助学金具体评定办法，认真指导有关学校做好奖助学金的评定发放工作，各省要确定一名工作联系人负责协调有关工作，并对奖助学金的落实情况进行监督检查。具体组织工作可依托技工院校学生资助管理工作机构实施。受助学校应严格按照奖助学金申请办法，配备一名工作联系人，具体负责数据汇总提交、受奖助学生资格审查、考核管理和资料报送工作。

**五、**评发程序

（一）申请

1.由符合条件的学生本人向所在学校提交书面申请，并逐项认真填写《全国技工院校华育奖助学金申请表》。

2.申请学生本人出具一份自荐信，阐述自己目前的学习情况，家庭情况，未来规划等。三年级学生还应同时提供在国家级或省级技能大赛中获奖相关证明材料的复印件。

3.学校组织专人依据本地区省级人力资源社会保障部门下发的奖助学金评定办法进行初评。由学生户籍所在地民政部门等相关部门根据学生本人家庭经济收入情况出具家庭经济困难证明。

（二）审核

1.学校审查评定。学校要严格按照程序逐项审核申请学生所填报内容的真实性。全面考察申请学生的家庭经济状况、本人的思想品德、学习成绩（三年级学生包括技能竞赛获奖情况）、平时的生活状态以及对受奖励的态度。

在学校全面考察核实的基础上拟出初选名单，在一定时间、范围内公示，无异议者，由学校汇总《全国技工院校华育奖助学金申请表》（含学生自荐信、家庭经济困难证明、三年级学生技能竞赛获奖证明）、填写《全国技工院校华育奖助学金受奖学生统计表》，并附公示材料、学校汇款信息（户名、开户行、账号）等，一并报送至省级人社部门。

2. 省级人社部门审定。省级人社部门审核各学校报送的材料准确无误后，填写《全国技工院校华育奖助学金受奖学生汇总表》，将上述材料原件等一并报送至中国职协。

3. 中国职协复核。中国职协复核各地报送的全部材料齐全无误后，集中送达北京华育助学基金会。

4.北京华育助学基金会核定。北京华育助学基金会对全国技工院校华育奖助学金有关材料进行最终核定，并与受助学校签订《全国技工院校华育奖助学金资助协议书》，同时向受助学校按学期分两笔拨付奖助学金款。

（三）发放

1.受助学校收到奖助学金款后，应开具由财政部门监制的合法、有效捐赠票据交北京华育助学基金会。并在规定时间内举行公开发放仪式，公布受奖助学生名单，将奖助学金发放到受奖助学生手中。

2.各受助学校应将学生每学期领款签名的《全国技工院校华育奖助学金发放统计表》及相关宣传报道材料、颁奖照片等资料，经省级人社部门汇总后，报送中国职协，由中国职协交北京华育助学基金会。

3.北京华育助学基金会对受奖助的学生实行定期追踪监督机制，基金会通过多种方式检查受奖助学生的情况以及资金发放情况。受助学校要积极配合基金会的追踪检查工作，定期提供有关数据和受助学生的情况。

上述评定发放程序详见《全国技工院校华育奖助学金评定发放工作流程》。

**六、**材料报送要求

（一）有关省级人社部门、学校应严格按照奖助学金评定发放工作流程，在规定时间内报送相关材料，并确保材料齐全、内容准确无误。

（二）各有关省级人社部门上报材料均应按本省实施华育奖助学金项目学校名单顺序汇总整理并排列，各校上报材料均应按《全国技工院校华育奖助学金评定发放工作流程》中标注的材料顺序依次排列并装订。除票据外，其余全部纸质材料均使用A4纸张，并加盖公章；图片均冲印6寸大小，图片及音像资料电子版应同时上报光盘。

附件8

全国技工院校华育奖助学金

总结报告内容提要

**一、**基本情况

省级总结报告须简要说明本省（区）主要经济指标，包括本省（区）国家级、省级贫困县数量及分布情况、全省（区）技工院校数量及分布情况等。

学校总结报告须提供学校基本情况，及学生必须支出的人均年费用情况（学费、书本费、餐费、住宿费等）、农村户口学生数量及占比情况、持有效家庭经济困难证明的学生数量及占比情况等。

**二、**组织实施情况

省级总结报告须说明年度受助学校择定原则及情况，并重点介绍本部门如何指导本省（区）有关学校做好奖助学金的评定发放工作，以及进行监督检查的情况。

学校总结报告须介绍奖助学金的评定发放工作的组织领导情况、执行奖助学金管理办法情况，重点介绍受奖助学生审查评定环节的做法和经验。

**三、**实施效果及评价

省级人社部门的总结报告须列明本地区受助学校、分年级受奖助学生人数、受奖助金额等。往年列入华育奖助学金范围的省份，还应统计分析本地区自享受华育奖助学金以来受奖助学生的毕业、就业情况。

学校总结报告须列明本校分年级受奖助学生人数、受奖助金额等。往年列入华育奖助学金范围的技工院校还应统计本校自享受华育奖助学金以来受奖助学生的毕业、就业情况。

实施效果评价部分还应包括收集整理来自学生、家长、学校乃至社会各方的反映，以及华育奖助学金受奖助学生的典型励志事例等。

**四、**存在问题及下一步工作建议

有关地区、学校在对本地区、本学校华育奖助学金评定发放工作进行认真总结的基础上，对存在问题进行仔细梳理，并针对存在问题提出具体改进措施。同时亦可对华育奖助学金评定发放整体工作提出意见或建议。
