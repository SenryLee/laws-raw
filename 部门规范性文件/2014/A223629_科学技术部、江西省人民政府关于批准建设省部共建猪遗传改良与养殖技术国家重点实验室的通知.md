# 科学技术部、江西省人民政府关于批准建设省部共建猪遗传改良与养殖技术国家重点实验室的通知

国科发基〔2014〕367号

江西省科技厅：

为贯彻落实党的十八大、十八届三中全会、四中全会和全国科技创新大会精神，深化科技体制机制改革，进一步完善国家重点实验室体系建设，科技部决定通过创新机制、省部共建的方式建设一批省部共建国家重点实验室，以加强中央政府和地方的资源集成，加大创新驱动区域经济社会发展的力度。根据江西省人民政府的推荐，科技部与江西省人民政府联合对猪遗传改良与养殖技术重点实验室进行了专家论证，认为该实验室符合省部共建国家重点实验室的相关要求，现决定批准建设（名单附后）。

省部共建国家重点实验室建设将主要围绕区域发展的战略布局与区域特色开展高水平基础研究和应用基础研究，引领区域科技创新，服务地方经济发展。省部共建猪遗传改良与养殖技术国家重点实验室的建设和日常管理以江西省人民政府为主，江西省人民政府每年为实验室提供不少于500万元的专项经费，作为实验室的基本科研业务和开放运行经费，并在科研项目、人才培养引进以及条件建设等方面给予优先支持。依托单位在建设期每年给予实验室不少于500万元的配套经费，并在人才引进、研究生培养和对外交流与合作等方面给予优惠政策。科技部将通过项目和人才计划对省部共建国家重点实验室予以支持。

建设期间，实验室和依托单位应按照《国家重点实验室建设与运行管理办法》的要求，坚持高标准建设目标，进一步凝炼发展方向，提升科研水平，加强队伍和实验条件建设，建立健全运行管理机制，努力成为区域内组织高水平科学研究、聚集和培养优秀科研人才、开展学术交流的重要基地。建设计划完成后，将纳入现有国家重点实验室体系，参加相应的考核评估工作。请抓紧落实各项工作，按期完成建设任务。

特此通知。
