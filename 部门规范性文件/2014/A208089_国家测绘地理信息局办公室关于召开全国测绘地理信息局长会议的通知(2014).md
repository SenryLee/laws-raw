# 国家测绘地理信息局办公室关于召开全国测绘地理信息局长会议的通知(2014)

## 国家测绘地理信息局办公室关于召开全国测绘地理信息局长会议的通知（测办[2014]1号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司室，各有关单位：

经国务院批准，国家测绘地理信息局定于2014年1月13日至14日在北京召开全国测绘地理信息局长会议。现将有关事项通知如下：

**一、**会议主题

认真学习贯彻习近平总书记一系列重要讲话精神和李克强总理、张高丽副总理重要讲话与批示精神，全面贯彻落实党的十八届三中全会精神和中央经济工作会议等会议精神，总结2013年测绘地理信息工作，交流工作实践经验，分析面临的形势，部署2014年重点任务，统一思想，凝聚力量，推动测绘地理信息事业深化改革、跨越发展。

**二、**参加会议人员

国家测绘地理信息局领导班子成员、总工程师；各省、自治区、直辖市测绘地理信息行政主管部门主要负责同志；计划单列市测绘地理信息行政主管部门主要负责同志；新疆生产建设兵团测绘地理信息主管部门负责同志；国家测绘地理信息局直属单位、局机关各司室主要负责同志；中国测绘地理信息学会、中国地理信息产业协会、中国卫星导航定位协会、全国地理信息标准化技术委员会主要负责同志；国际摄影测量与遥感学会主席；北京市测绘设计研究院、天津市测绘院、内蒙古自治区测绘地理信息局、安徽省测绘地理信息局、山东省国土测绘院主要负责同志；武汉大学、郑州测绘学校负责同志；部分地理信息企业负责人。

**三、**会议时间：1月13日－14日（12日报到）

会议地点：中国测绘创新基地

报到地点：北京市丰台区大成路9号宾馆

（京外代表）

国家测绘地理信息局办公室秘书处

（2506房间）（京内代表）

**四、**有关要求

（一）请各单位、各部门将参会人员名单回执（见附件）于1月9日前传真至国家测绘地理信息局办公室，并同时传真至国家测绘地理信息局机关服务中心，以便安排接送站（机）。

（二）请各直属局和重庆测绘院组织机关干部，通过国家局视频会议系统收看13日上午大会。
