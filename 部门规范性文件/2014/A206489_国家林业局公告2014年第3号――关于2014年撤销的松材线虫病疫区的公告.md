# 国家林业局公告2014年第3号――关于2014年撤销的松材线虫病疫区的公告

## 国家林业局公告（2014年第3号）

根据《植物检疫条例》和《全国林业检疫性有害生物疫区管理办法》（林造发〔2013〕17号）的有关规定，现将我国2014年撤销的松材线虫病疫区公告如下：

安徽省：滁州市南谯区，马鞍山市雨山区。

福建省：厦门市海沧区。

江西省：上饶市鄱阳县。

湖北省：黄冈市红安县。

广东省：深圳市龙岗区。

广西壮族自治区：百色市隆林各族自治县（2013年发现的松材线虫病疫情，经当年防治后达到拔除标准）。

贵州省：遵义市红花岗区。

陕西省：商洛

国家林业局
