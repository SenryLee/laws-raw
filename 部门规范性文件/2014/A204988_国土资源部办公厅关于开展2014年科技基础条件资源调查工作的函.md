# 国土资源部办公厅关于开展2014年科技基础条件资源调查工作的函

## 国土资源部办公厅关于开展2014年科技基础条件资源调查工作的函（国土资厅函〔2014〕262号）

各有关单位：

按照《科技部 财政部关于开展2014年科技基础条件资源调查工作的通知》（国科发计〔2014〕50号）要求，部将组织开展2014年科技基础条件资源调查工作（以下简称“科技资源调查”），有关要求如下：

**一、**科技资源调查的主要内容

原值50万元以上大型科学仪器设备的状态、利用和共享情况，科技数据库建设和利用情况，部门批准建立的研究试验基地基本情况，法人单位概况等。

调查标准时点为2013年12月31日，时期资料为2013年度。

**二、**科技资源调查的对象

1． 部系统内科研院所：部系统内科研院所，23家，名单见附件1。

2．部系统外科研平台：部依托省厅、属地化地勘单位、高校等，批准建设的部级重点实验室、质量监督检测中心、野外科学研究与观测基地。部系统内外科研平台名单见附件2。

**三、**调查工作安排

调查工作由部科技合作司、财务司共同组织，由地调局协助组织局属单位调查，具体调查工作由经研院承担。具体调查工作安排如下：

1．部系统内科研院所调查工作安排：（1）调查单位通过“国家科技基础条件资源调查管理信息系统”（www.nstic.gov.cn或www.escience.gov.cn）网上在线填报、审核和上报数据。（2）部对各单位填报的数据进行网上审核。（3）各单位打印通过部审核的《国家重点科技基础条件资源调查总表》、《研究试验基地调查总表》、《科技数据库基本信息》、《公益类科研机构改革与发展情况》加盖单位公章报部。（4）部统一汇交科技部、财政部，并更新数据库，编制相关技术数据报告。已参加调查的单位沿用已有的用户名和密码，登录系统并按照流程进行数据更新。

2．部系统外科研平台调查工作安排：（1）调查单位从“国土资源部网站（www.mlr.gov.cn）-科技管理”下载并填报《国家重点科技基础条件资源调查表》的表2《研究试验基地概况》和表2-1《科研仪器设备清单》，经依托单位审核加盖公章后，于2014年5月10日前一式1份报部科技与国际合作司，同时报电子版1份。

**五、**其他

此次调查内容涉及单位人员、财务、科研仪器设备和研究试验基地等多方面情况，需要单位科技、人事、财务、研究基地等多部门配合。请各单位高度重视，做好组织协调。
