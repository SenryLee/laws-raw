# 农业部渔业渔政管理局关于提供2014年增殖放流细化方案的函

## 农业部渔业渔政管理局关于提供2014年增殖放流细化方案的函（农渔资环便[2014]192号）

各省、自治区、直辖市及计划单列市渔业主管厅（局），新疆生产建设兵团水产局，中国水产科学研究院、全国水产技术推广总站：

近期，财政部下达了《关于拨付2014年农业资源及生态保护补助资金的通知》（财农[2014]63号），确定了各省（区、市）及有关单位2014年增殖放流资金规模。考虑到各地申报的2014年增殖放流资金规模与实际安排情况存在一定差异，根据农、财两部办公厅《关于做好2014年渔业资源保护和转产转业工作的通知》（农办财[2014]44号），为尽快下达2014年增殖放流任务，提高增殖放流工作的科学性和可操作性，请你单位根据已下达的资金规模（具体资金分配请咨询我处），在原申报方案基础上研究提出2014年增殖放流细化方案（格式见附件，细化方案包括经济物种和珍稀濒危物种，原则上不支持物种跨水系放流，特别是鲤、鲫等品种较多的种类，只能放流原水域土著种），加盖公章后于7月28日前传真至我局资环处，并发送电子邮件至zihuanchu@126.com。增殖放流资金规模有所增加的地区或单位原则上放流数量要相应增加。各地上报方案经我局审核后，将以我部办公厅文件形式正式下达2014年增殖放流任务。

说明：

1.　请对照《关于拨付2014年农业资源及生态保护补助资金的通知》（财农[2014]63号），列出全部计划放流水域及放流品种名称、相应规格和数量，包括经济物种和珍稀濒危物种。

2.　所列放流水域及相应放流品种原则上应与《全国水生生物增殖放流总体规划》和《全国珍稀濒危水生动物增殖放流规划》规定的放流水域和品种保持一致，并与2014年各地上报的《渔业资源保护和转产转业项目申报书》中的放流水域和品种相统一。

3.　各省（区、市）分别列出经济物种和濒危物种的增殖放流细化方案，其中沿海省（区、市）请分别列出海水和淡水增殖放流细化方案。

4.　中国水产科学研究院请参照上述格式分别列出四个增殖站放流细化方案。

5.　全国水产技术推广总站和新疆生产建设兵团请参照上述格式填报增殖放流细化方案。
