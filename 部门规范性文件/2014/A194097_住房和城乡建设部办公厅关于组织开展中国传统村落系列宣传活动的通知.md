# 住房和城乡建设部办公厅关于组织开展中国传统村落系列宣传活动的通知

## 住房和城乡建设部办公厅关于组织开展中国传统村落系列宣传活动的通知（建办村函[2014]518号）

各省、自治区住房城乡建设厅，直辖市建委（农委）：

根据部领导指示，为加强传统村落宣传工作，现就组织开展传统村落系列宣传活动通知如下：

**一、**宣传对象

各省（区、市）已列入中国传统村落名录的村落。

**二、**宣传内容

宣传中国传统村落保护的重要性，包括传统村落历史、文化、科学、艺术和经济价值、地区民族特色以及传统村落风貌；传统村落保护的迫切性和面临的问题；传统村落保护工作进展和政策；保护工作的好典型、好经验。

**三、**宣传方式

（一）组织省内重要的平面媒体、电视和网络媒体，以专栏、新闻和专题报道的方式，全面报道传统村落的保护工作情况。

（二）组织媒体记者赴保护较好的传统村落现场实地采访报道。

（三）组织本地传统村落保护专家撰写传统村落保护政策和技术解读文章，在相关媒体刊发。

（四）组织在机场、车站等人流密集公共场所投放宣传广告。

（五）利用简报、内部情况通报等现有渠道开展工作宣传。

（六）组织开展便于群众参与的专题活动，宣传传统村落保护。

（七）开展其他形式的宣传。

**四、**定期上报宣传活动情况

请你厅（委）确定专人负责传统村落宣传工作，并将联系人信息于本月31日前报我部村镇建设司。各地传统村落宣传情况应及时报我部，并纳入对各地传统村落保护工作的评价。
