# 国家安全生产监督管理总局公告2014年第16号――关于核准鞍钢股份有限公司热轧带钢厂等企业为企业一级企业名单的公告

国家安全生产监督管理总局公告

（2014年第16号）

根据《全国冶金等工贸企业安全生产标准化考评办法》（安监总管四〔2011〕84号）的有关规定，经考评，核准鞍钢股份有限公司热轧带钢厂等60家企业为冶金安全生产标准化一级企业（第八批），中国铝业股份有限公司贵州分公司等8家企业为有色安全生产标准化一级企业（第三批），巴彦淖尔中联水泥有限公司等107家企业为建材安全生产标准化一级企业（第三批），北汽福田汽车股份有限公司山东多功能汽车厂等145家企业为机械制造安全生产标准化一级企业（第十五批），北京顺鑫农业股份有限公司创新食品分公司等36家企业为轻工安全生产标准化一级企业（第一批），广东中烟工业有限责任公司等3家企业为烟草安全生产标准化一级企业（第二批），广东合捷国际供应链有限公司等4家企业为商贸安全生产标准化一级企业（第二批），现予公告。有效期自公告之日起3年。
