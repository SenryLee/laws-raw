# 国家知识产权局办公室关于印发《2014年下半年知识产权政务信息报送要点》的通知

各省、自治区、直辖市及计划单列市、副省级城市、新疆生产建设兵团知识产权局；局机关各部门，专利局各部门，局直属各单位、各社会团体：

2014年上半年，全国知识产权系统政务信息工作继续保持良好势头，共采用各地上报信息319条，采用局内各部门单位报送政务信息108条，编报《知识产权局信息》32期、《知识产权局简报》3期，编发《知识产权工作动态》12期。下半年，各部门各单位要紧紧围绕知识产权工作重点、难点、热点问题报送信息。要进一步加强调查研究，客观、全面地反映真实情况和问题，加强综合分析，提出政策建议；要积极借助社会研究力量和专家资源开展专题调查，及时就重要情况和问题向有关单位约稿；要进一步提高信息编辑水平，力求主题鲜明、结构完整、题文相符、逻辑严密，字数一般不超过800字，特别重要的信息不超过2000字；要进一步规范信息收集、编辑、审核、报送等工作程序，报送《知识产权局信息》《知识产权局简报》的稿件，须经本部门本单位主管负责人审定签发。

报送《知识产权局信息》《知识产权局简报》的稿件请发电子邮件至 maning@sipo.gov.cn，报送《知识产权工作动态》的稿件请发电子邮件至 gongzuodongtai@sipo.gov.cn。

特此通知。

国家知识产权局办公室

2014年7月28日

2014年下半年知识产权政务信息报送要点

紧紧围绕国务院出台的稳增长、促改革、调结构、惠民生有关任务措施，以及 2014 年全国知识产权局局长会议精神和要求，认真总结各项重点任务落实情况，及时反映本地区、本部门工作新进展、新情况、新问题，着重在以下方面报送信息。

**一、**关于深化实施知识产权战略

落实 2014 年知识产权战略实施推进计划和专利事业发展战略推进计划情况。探索建设知识产权强国、强省、强市、强县（区）、强企的进展和经验。区域、地方知识产权战略、政策推进落实情况。

**二、**关于提升知识产权创造和运用水平

促进专利创造质量提升的做法和成效。实施专利导航工程的进展和成效。促进创新成果专利化、资本化、产业化的新举措、新成效。知识产权投融资、专利保险工作新进展。

**三、**关于加强知识产权保护

开展执法维权“护航”专项行动进展情况，特别是专利领域群体侵权、反复侵权及假冒专利行为等重大案件查处情况。专利行政执法工作成效，快速维权中心建设运行情况。电子商务领域、专业市场、展会、大型商业场所等执法维权工作新成效。自贸区知识产权保护情况。

**四、**关于改进知识产权管理与服务

知识产权服务业标准化、知识产权评议规范工作进展情况。推进专利信息服务的情况。知识产权服务品牌机构培育和知识产权服务业集聚区建设进展和成效。知识产权促进京津冀协同发展、促进东北等老工业基地振兴、促进中原经济区发展等工作进展情况、存在的问题及建议。知识产权助力中小企业发展、服务企业“走出去”的举措、成效和经验。

**五、**关于涉外知识产权

有关组织、机构和权威专家对国际知识产权规则变革趋势的分析判断。主要国家知识产权政策特别是对华知识产权政策新动向及主要关切点。国外机构和企业在华知识产权活动情况。我企业“走出去”过程中遭遇知识产权纠纷情况。
