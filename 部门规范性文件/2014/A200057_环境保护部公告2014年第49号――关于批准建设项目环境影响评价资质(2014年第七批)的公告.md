# 环境保护部公告2014年第49号――关于批准建设项目环境影响评价资质(2014年第七批)的公告

## 环境保护部公告（2014年第49号）

关于批准建设项目环境影响评价资质（2014年第七批）的公告

根据《建设项目环境影响评价资质管理办法》（原国家环境保护总局令第26号）的有关规定，我部对申请建设项目环境影响评价资质（以下简称资质）的机构进行了审查。现将资质批准有关事项（2014年第七批）公告如下：

**一、**批准江苏国恒安全评价咨询服务有限公司等3家机构乙级资质。

**二、**批准河北圣洁环境生物科技工程有限公司等10家机构资质中的评价范围调整。

**三、**批准中国水电顾问集团北京勘测设计研究院等7家机构资质证书中的机构名称变更。

**四、**批准北京中环瑞德环境工程技术有限公司等11家机构资质延续。

**五、**批准交通运输部环境保护中心等48家机构资质证书中的法定代表人或住所变更。

上述批准事项的相关情况详见附件。请相关机构于60日内到指定地点领取资质证书，其中第二至第五项中的机构应在领取资质证书时携带原资质证书正、副本原件，第三项中的机构应在领取资质证书前，办理环境影响评价专职技术人员岗位证书和环境影响评价工程师登记证变更手续。

自本公告发布之日起，上述第二至第五项中的机构原资质证书正、副本原件及其缩印件同时作废，不得继续使用。
