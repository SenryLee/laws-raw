# 农业部办公厅关于开展2014年度棉花主栽品种纤维品质抽查的通知

## 农业部办公厅关于开展2014年度棉花主栽品种纤维品质抽查的通知（农办农〔2014〕42号）

有关省、自治区农业厅（委员会）、新疆生产建设兵团农业局：

为监测我国棉花主栽品种的纤维品质状况，我部今年继续委托农业部棉花品质监督检验测试中心，对棉花主产区主栽品种的棉花纤维质量进行抽样检测。现将有关事项通知如下。

**一、**抽查范围

新疆、河北、山东、江苏、湖北、安徽、河南、江西和湖南9个主产棉省（区）的86个受检单位（名单详见附表）。

**二、**检验项目

纤维上半部平均长度、整齐度指数、断裂比强度、马克隆值、伸长率、反射率、黄度和纺纱均匀性指数等。

**三、**抽样时间

2014年10～12月，具体时间由抽检单位确定。

**四、**抽检单位

农业部棉花品质监督检验测试中心（地址：河南省安阳市文峰区黄河大道38号，联系人：唐淑荣，电话：0372-2525391、13569017156）。

**五、**有关要求

1.各省（区）棉花生产主管部门要积极配合，大力支持，及时通知各受检单位，保证抽检任务顺利完成。

2.各受检单位可以自行确定1～3个棉花主栽品种，每个品种取有代表性的1000克籽棉作为抽检样品，并分别注明样品的品种名称、产地、该品种在当地的种植面积等信息，杂交棉需注明品种代别。

3.抽检单位要认真完成抽检任务，科学公正检测样品的纤维品质，确保检测结果真实准确。
