# 教育部办公厅关于召开2014年度职业教育与成人教育工作视频会议的通知

## 教育部办公厅关于召开2014年度职业教育与成人教育工作视频会议的通知（教职成厅函[2014]7号）

各省、自治区、直辖市教育厅（教委），各计划单列市教育局，新疆生产建设兵团教育局，各行业职业教育教学指导委员会：

为深入贯彻党的十八大和十八届三中全会精神，全面落实国务院关于加快发展现代职业教育的部署，我部定于2014年3月25日（星期二）15：00召开2014年度职业教育与成人教育工作视频会议。现将有关事项通知如下。

**一、**会议主要任务

总结2013年职成教工作，交流推动职业教育与继续教育改革创新的思路措施和发展经验，研究部署2014年度职成教工作。

**二、**会场安排

主会场设在教育部机关北楼二层报告厅。各省（区、市）教育厅（教委），各计划单列市和新疆生产建设兵团教育局设分会场。

**三、**与会人员

1. 主会场：教育部负责同志；行业职业教育教学指导委员会主任委员或秘书长；教育部相关司局、直属单位各1位负责同志；

邀请人力资源和社会保障部2位司局负责同志；中华职教社、中国职业技术教育学会、中国成人教育协会、北京师范大学国家职业教育研究院各1位负责同志。

2. 分会场：省级教育行政部门分管职业教育（含中等、高等职业教育）、成人继续教育（社会教育、终身教育）工作的负责同志及处室负责同志，中职招生工作的负责同志，教育信息化部门负责同志；中等职业教育改革发展示范学校和高等职业学校校长，行业、企业、研究机构代表（由各地自行确定并组织参会）。

**四、**其他事项

1.定于3月24日（星期一）10：00-11：00进行网络视频调试。请各分会场提前做好系统的联调测试准备工作，届时派专人负责。如遇技术问题，请及时与主会场联系，联系电话010-66097587。

2.请在主会场出席会议的单位于3月21日（星期五）12：00前将与会人员姓名、单位及职务、联系电话、车号报我部职业教育与成人教育司。

3.请各地于3月21日（星期五）12：00前将分会场出席会议的负责同志姓名、单位、职务及参会人数报至我部职业教育与成人教育司。

4. 届时请与会人员提前15分钟进入会场。
