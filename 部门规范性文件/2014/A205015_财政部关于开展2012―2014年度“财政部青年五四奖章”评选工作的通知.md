# 财政部关于开展2012―2014年度“财政部青年五四奖章”评选工作的通知

## 财政部关于开展2012-2014年度“财政部青年五四奖章”评选工作的通知

为表彰、宣传先进青年典型，激励广大财政青年立足岗位，在财政中心工作中发挥生力军作用，为促进全面深化改革和经济社会发展作贡献，根据《中央国家机关青年五四奖章评选表彰办法》，定于今年“五四”前开展2012-2014年度“财政部青年五四奖章”评选表彰活动。另外，中央国家机关工委将于近期开展第三届“中央国家机关五四青年奖章”评选工作，我们将在我部评选表彰的基础上，从中选拔推荐第三届“中央国家机关青年五四奖章”人选。

**一、**评选项目

（一）财政部青年五四奖章标兵10名。

（二）财政部青年五四奖章46名左右。

**二、**评选条件

（一）政治上过硬，对党忠诚。大局观念强，认真学习掌握中国特色社会主义理论体系，在本单位政治理论学习活动中积极主动，起到模范带头作用。

（二）锐意进取，在工作中取得突出成绩。有着强烈的责任感和使命感，爱岗敬业，敢于担当，勇于创新，在财政事业改革发展中积极奉献，在本职工作中取得突出成绩，在青年干部中模范带头作用明显。

（三）品德高尚，好学上进。作风正派，严格自律，勤政廉政，敢于迎接挑战，注重个人道德操守，始终保持立高行远、恪勤求真的精神状态，能代表财政青年的形象和风貌。

（四）年龄40周岁以下（1974年5月1日之后出生），财政部机关及在京直属单位的正式干部和职工。

**三、**评选办法与步骤

“财政部青年五四奖章”候选人由各单位申报。

“财政部青年五四奖章标兵”从“财政部青年五四奖章”候选人中评选产生，各单位不用另行单独申报。

2012-2014年度“财政部青年五四奖章”评选分推荐、评选、表彰奖励、宣传学习4个步骤进行。实施办法如下：

第一阶段：推荐（4月4日前完成）

各单位要根据评选方案的要求，在青年中进行广泛宣传，把推荐的过程作为树典型、学榜样、赶先进的过程。提名确定推荐对象要充分发扬民主，严格按照要求准备推荐材料，认真进行考察并按时上报评选工作办公室（设在机关团委）。

推荐名额根据各单位40周岁以下青年干部人数按比例分配（详见附表1）。推荐的候选人将作为“财政部五四青年奖章”、“财政部五四青年奖章标兵”和第三届“中央国家机关青年五四奖章”候选对象。

对在财政部青年工作中表现突出、作出较大贡献的优秀青年干部，机关党委可直接提名参评。

第二阶段：评选（4月17日前完成）

评选工作办公室召开会议研究候选人事迹材料，表决产生“财政部五四青年奖章”和第三届“中央国家机关青年五四奖章”推荐人选，提交机关党委审定。

第三阶段：表彰奖励

“财政部青年五四奖章” 和“财政部青年五四奖章标兵”获得者由财政部机关党委授予荣誉称号，与机关团委同期开展的财政部2013-2014年度“优秀团员”、“优秀团干部”和“五四红旗团组织”评选工作一起召开表彰会。

第四阶段：宣传学习

部机关各级党、团组织通过多种方式，广泛宣传获奖者先进事迹，充分发挥典型引路作用，在广大青年中努力形成学先进、赶先进、超先进、见行动的浓厚氛围。

**四、**工作要求

（一）各部门要高度重视，加强对评选工作的组织领导，把推荐工作与青年人才培养工作有机结合起来。要与同期开展的财政部2013-2014年度“优秀团员”、“优秀团干部”和“五四红旗团组织”评选工作评选结合起来统筹考虑，选拔出事迹突出、代表性强、青年干部公认的优秀青年干部。要考虑到上届表彰活动获奖人选情况，特别注重发现新人，培养和发现更多的青年人才。

（二）评选工作办公室将对“五四青年奖章标兵”候选人进行直接考察，听取推荐对象所在单位和人事、纪检等部门的意见。考察结束后，对推荐对象进行综合审定，形成考察推荐意见，递交评委会。

（三）推荐人选按要求填写相应推荐登记表（附表2，一式二份），并提供电子版。“推荐对象事迹”一栏将作为评选主要依据，应认真、详细、准确填写，1500字左右。登记表须经所在部门党团组织审核盖章，并由负责人签字。事迹材料中涉及到奖项的须随表提供证书复印件。

（四）4月4日前将推荐材料报评选工作办公室，逾期未报视为自动放弃。
