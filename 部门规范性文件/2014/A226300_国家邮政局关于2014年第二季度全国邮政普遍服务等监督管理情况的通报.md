# 国家邮政局关于2014年第二季度全国邮政普遍服务等监督管理情况的通报

国邮发[2014]148号

各省、自治区、直辖市邮政管理局：

2014年二季度，各省、自治区、直辖市邮政管理局（以下简称省局）认真贯彻落实全国邮政管理工作会议和邮政普遍服务监督管理工作会议精神，开展邮政普遍服务、特殊服务和邮票发行等监督管理工作。现将有关情况通报如下：

一、行政审批与备案管理

（一）撤销营业场所审批。二季度，全国17个省（区、市）邮政管理局（以下简称省管局）共计收到邮政企业撤销提供邮政普遍服务的邮政营业场所申请82个，受理82个，上期转来未办结申请31个，本期批复同意67个，不同意38个，未办结转至下期8个。截至6月底，2014年全国共有22个省管局累计收到邮政企业撤销提供邮政普遍服务的邮政营业场所申请154个，受理153个，上期转来未办结17个，批复同意111个，不同意51个，未办结转至下期8个。

（二）停限办业务审批。二季度，全国5个省管局收到邮政企业停止办理或者限制办理普遍服务和特殊服务业务申请32个，受理33个，上期转来未办结申请1个，本期批复同意30个，不同意1个，转至下期3件。截至6月底，2014年全国共有11个省管局累计收到邮政企业业务停限办申请40个，受理40个，批复同意37个，不同意1个。

（三）备案管理情况。二季度，全国27个省管局收到邮政企业提交的备案材料608份，其中：备案新增邮政营业场所330个，备案邮政普遍服务营业场所信息变更222个，备案撤销不提供邮政普遍服务营业场所2处，备案暂时停止或限制办理邮政普遍服务业务35个，备案恢复办理邮政普遍服务业务19个。截至6月底，全国27个省管局累计收到邮政企业提交的备案材料1205份，其中：备案新增邮政营业场所448个，备案邮政普遍服务营业场所信息变更505个，备案撤销不提供邮政普遍服务营业场所9处，备案暂时停止或限制办理邮政普遍服务业务105个，备案恢复办理邮政普遍服务业务138个。

二、邮政服务监督管理

二季度，全国各级邮政管理部门继续开展邮政普遍服务、机要通信、邮票销售、“扫黄打非”等监督检查工作。共计检查25922人次，检查邮政营业场所10585处，下发检查通报229份，下发责令改正通知书548份，做出行政处罚25件。

（一）行政处罚。二季度，黑龙江、江苏、安徽、福建、山东、河南、湖南、甘肃等8省邮政管理部门对邮政企业违法违规行为做出行政处罚决定25件，罚款40.4万。其中，处罚事由为擅自撤销邮政普遍服务营业场所的11件，擅自停限办邮政普遍服务和特殊服务业务的3件，不符合《邮政普遍服务标准》的9件，违反邮票发行销售规定的1件，监控设备无法正常使用的1件。

（二）邮政设施普查。截至6月底，全国除四川省以外其余30个省已完成了邮政营业场所的实地核查工作，其中25个省份完成了核查数据信息的录入工作，全国录入“邮政基础设施管理信息系统”的邮政场所数累计46291处，总进度已达到98%。目前内蒙古、浙江、江西、四川、云南、贵州没有完成核查录入工作。安徽等省已录入“邮政基础设施管理信息系统”的数据信息存在一定质量问题，需认真复核、把关。

（三）邮政普遍服务业务开办专项检查。二季度，邮政管理部门继续开展邮政普遍服务业务开办实地核查工作。截至6月底，各级邮政管理部门共进行实地核查690人次。全国3000个计划在2014年恢复开办邮政汇兑的局所中，有642个局所已开办。各省局积极组织安排人员对2013年恢复办理普遍服务四项基本业务的局所进行复查，对发现的问题要求企业进行整改。山西省局对检查中发现的违法违规问题，及时约谈企业负责人，下达责令改正通知书25份。

（四）邮政专用标志车辆检查。根据国家局在一季度通报中提出的相关要求，各级邮政管理部门对邮政专用标识车辆开展了日常检查。其中甘肃省兰州局对快递企业冒用带有邮政专用标志车辆的违法行为实施了行政处罚。湖南省永州局对全市邮政企业的邮政专用标志车辆进行了实地核查并登记拍照建档，郴州局在检查时发现邮政企业漏报专用标识车辆，督促邮政企业补报整改。宁夏局通过与交管部门协作等方式，对邮政企业的有邮政专用标志车辆建立了信息台账，加强了监督管理。

（五）邮政普遍服务营业场所网上公开。截至6月底，国家局、全国所有省局以及地市局三级邮政管理部门均已在政府网站进行了邮政普遍服务营业场所公示，已有46717个营业场所在政府网站上进行了公示。

（六）机要通信检查。邮政管理部门对辖区内邮政机要通信营业场所和投递网点开展检查，二季度全国共检查860处机要通信服务网点，截至6月底共计检查1441处机要通信服务网点。检查发现的问题主要是：部分网点安防设施不达标，安全管理规定执行不到位。海南省局在检查时发现个别网点存在未安装监控系统、未配备机要投递专用车辆、未严格执行总包双人开拆制度等问题。云南局发现部分机要局（所）无专用机要通信运输车辆、人员配置达不到保密规定的要求等问题。

（七）邮票印制和销售专项检查。二季度，全国共监督检查邮票销售网点1649处（次），分别对《纪念黄埔军校建校九十周年》《2014青岛世界园艺博览会》、《中国古典文学—红楼梦》等纪特邮票的发行工作进行了监督检查。截至6月底，累计监督检查3187处（次）。从检查情况看，总体良好，但是仍存在部分地区邮票销售网点未能提前公示邮票零售数量、偏远地区当日到票不准时、首日封不能准时发售等问题。内蒙古局在检查时发现部分邮票销售网点未能公示邮票名称、枚数、面值、零售数量等信息，针对发现的问题，内蒙古局已要求企业进行整改。

（八）邮政特邀监督员开展监督情况。二季度，全国邮政特邀监督员开展社会监督13448人次，监督员查看服务网点11964个，走访消费者16871人次，监督员监督报告10605份，反映问题1629条，提出建议和意见860条。截至6月底，全国邮政特邀监督员上半年共开展监督活动28387人次，监督报告22369份，查看服务网点24442个，走访消费者36368人次，反映问题3511条，提出建议和意见1768条。

（九）“扫黄打非”专项检查。各级邮政管理部门按照国家“扫黄打非”工作的有关要求开展工作。上半年，各级邮政管理部门共计检查邮政企业及快递企业收寄场所23043处，一线人员签订责任书73820份，查堵非法出版物424册，抽查邮政报刊发行企业731个，抽查接办目录8434个，报刊经营者签订责任书10576份，检查报刊亭5173处。

二、邮政普遍服务保障情况

（一）推进空白乡镇邮政局所补建工作。截至2014年6月底，全国8440个乡镇补建邮政局所计划中，竣工6337个，验收3566个，其中移交邮政企业2567个，投入运营的邮政局所1710个。

各局高度重视推进补建局所工作，把补建工作摆到最重要的位置，抓紧抓实。如：北京局与市邮政公司召开工作推进会，针对每个局所议定了具体解决方案。协调市发改委着力解决建设、资金问题，取得积极进展。河北局联合省发改委对衡水、沧州5县6镇进行了调研督导。约谈省邮政公司加强补建局所的移交运营工作。通过全省会议、培训等平台介绍交流先进省市的经验做法，并及时将有关市局好的经验和做法转发全省指导各市局工作。保定、衡水市将补建项目列为市政府督查室督查项目予以重点督办。山西局领导多次深入乡镇调研局所建设选址及工程质量、工程进度等情况。辽宁局以专题会议形式向省公司主要负责人通报工作情况并提出工作要求。与省发改委沟通后，达成了加快补建工作进度的共识。浙江局针对未竣工网点，与省发改委研究下发通知。分管局领导带队分赴宁波、丽水、温州等地开展督查。福建局协调省发改委召开全省协调推进会。要求各相关市（地）局于5月30日前就当前辖区内尚未完工或已竣工但未运营的补建乡镇邮政局所，向所在地邮政企业下发限期责令改正通知书。江西局联系地方发改委和邮政企业开展实地督导，对部分选址不能确定、工程进展缓慢、验收移交存在分歧的补建项目进行现场办公，共同协商推进措施。广东局分管副局长带队到省邮政公司召开专题会议，传达学习国家局有关会议精神和工作要求，双方就补建项目遇到的具体问题逐一进行研究，并商讨解决方案。四川局会同省发改委、省邮政公司在乐山召开了第一批市邮政管理局、发改委、邮政公司参加的空白乡镇邮政局所补建推进会。贵州局将安顺市作为“快建快交”的试点，对安顺经验和做法进行梳理总结，积极向贵州省政府汇报。省政府在安顺市普定县召开由省政府牵头，相关职能部门参与，分管副省长参加的全省“小康讯”邮政基础设施建设观摩推进会，会议要求以安顺市为榜样，组织好空白乡镇网点建设、验收、移交工作。青海局积极向省政府汇报空白乡镇网点补建进展情况及存在的困难，争取政府支持政策，副省长对此做出批示。宁夏局第二批群众路线教育实践活动领导小组分别对吴忠市、固原市、中卫市补建工作进行了现场调研，对补建工作提出要求。西藏昌都、山南、林芝地区政府部门专门召开专题会，山南地区行署把补建工作列入为民服务“十心”工程。拉萨和山南局争取到了政府补贴资金。

（二）“村邮户箱”建设持续推进。各级邮政管理部门继续加强与当地政府部门的沟通和协调，积极完善信报箱设置验收工作机制。辽宁省盘锦市局提出《关于做好城镇住宅信报箱建设与管理的提案》，加强与市政府相关部门的协作配合，加快推进城镇居民楼信报箱建设，保障居民通信权利，为邮政企业履行普遍服务义务提供条件和支持。河南省焦作局利用全市行政审批制度改革的契机，将住宅信报箱设计图纸审查和住宅信报箱竣工验收成功纳入全市保留的行政审批事项，并制订了电子审批流程方案，完成了网上服务大厅建设工作。广东省佛山市邮政管理局抓住当地调整行政审批和社会服务事项的有利契机，积极作为，主动介入，成功将“住宅信报箱验收”纳入全市工程建设项目竣工验收管理，在工程竣工联合验收阶段增加“住宅信报箱验收”事项，并将“住宅信报箱验收”作为全市行政审批和社会服务新增事项予以公布。

（三）邮政管理部门积极争取保障邮政普遍服务的政策措施，开展创新工作。四川省绵阳、成都等地开展了便民服务站建设。邮政便民服务站不仅提供代收费业务，还新增公交地铁卡充值、信用卡业务、POS刷卡消费、智能电卡充值、旅游产品代理、代收交通违法罚款、代售电影票和航空机票、“天府通”充值等便民服务。辽宁省深化交邮合作。鞍山市台安县客运站建立了邮政便民服务站，开办代收水电费、通信费等服务项目。辽阳市长途客运总站为市邮政公司提供2处报刊零售点，代理邮政报刊零售业务；邮政企业在客运总站售票大厅、候车室分别设立2处便民服务站，开办代收移动、联通、电信话费及国家电网电费等业务。

三、下一阶段主要工作

下半年，各级邮政管理部门要按照2014年全国邮政管理工作会议的总体部署和国家局年中工作座谈会的会议精神，扎实推进各项工作，确保完成全年任务。

（一）加快推进空白乡镇补建局所建设运营工作。推动局所补建工作，确保年底目标任务完成仍然是各项工作中的重中之重。第三季度是实现2014年补建工作任务目标的关键时期，各局务必要采取有力措施，抓紧推进，取得实质性成效。一是要立足目标，加快推进速度。海南、浙江、山东、广东、北京、湖北、福建、重庆、天津等要确保在年内摘掉乡镇邮政服务空白的帽子；吉林、广西、宁夏、云南、内蒙古等要力争在年内摘掉乡镇邮政服务空白的帽子。其他15个省份要按照进度要求，加快推进建设、验收和运营工作，确保阶段目标如期实现。黑龙江、河南、新疆、陕西、四川，补建任务重、进度较慢的局要尽快赶上总体进度。二是要加强协调配合，发挥行业管理作用。各级邮政管理部门要配合发改部门做好项目跟踪，全面掌握本辖区补建局所的工程进度。对工作进展缓慢的地区，要逐一排查问题、摸清原因、推动问题解决和落实。三是要发扬啃骨头的精神，采取多种有效措施，解决难题。补建局所推进工作越到后期，遇到的困难越多越难。各局要发扬敢打硬仗、善打硬仗的精神，原则性与灵活性相结合，在选址、建设、资金、产权、运营等方面遇到困难时，要吃透精神，用活政策，因地制宜解决难题。四是要依法履责，确保竣工邮政局所有效运营。各级邮政管理部门要督促邮政企业及早落实运营条件，确保局所移交后3个月内投入运营，要求企业对投入运营的补建局所及时办理备案登记，备案信息要准确详实，并提供局所照片和相关资料复印件。

（二）加强行政执法工作。一是继续组织开展法定业务开办专项检查工作，把握2014年恢复开办全业务局所的整体进度，有序推进工作，保证年底完成计划目标；对2013恢复开办全业务的局所积极进行复查，发现问题尽快督促整改。二是继续加强邮政普遍服务合标执法检查，重点查处邮政投递服务质量问题。三是继续加强对邮政车辆的日常执法检查，重点查处邮政企业违法使用邮政专用标识车辆的行为和社会冒用、盗用邮政专用标识车辆的违法行为。四是要将邮件时限测试工作与行政执法工作有机结合，在平信交寄完成后，要组织市（地）局对投寄测试平信的邮筒（箱）进行实地检查，记录检查结果，如发现未按规定频次开取邮筒（箱）的，应按法定程序取证并予以相应处理。

（三）全面完成邮政普遍服务营业场所信息公开工作。一是尚未完成实地核查和信息录入的省，要加大工作力度，加强督办，确保在8月底快完成核查任务和数据信息录入任务。对管理系统显示数据信息有误的省份，要做好核对修正工作，确保数据质量。二是各级邮政管理部门要及时对还未公示的普遍服务营业场所在政府门户网站尽快进行公示，对于已公示的局所信息有变化的，要及时更新相应的内容。

（四）做好第三季度通报工作。各省局要按时完成第三季度向市（地）局和邮政企业的通报工作，同时抄送国家局普遍服务司。通报内容应反映第三季度工作重点，相关数据统计要规范准确，口径一致，同时将邮件时限测试的相关内容纳入到本省的季度通报中。
