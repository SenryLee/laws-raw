# 国家测绘地理信息局关于印发国家测绘地理信息局2014年立法工作计划的通知

## 国家测绘地理信息局关于印发国家测绘地理信息局2014年立法工作计划的通知（国测法发〔2014〕1号）

机关各司室：

《国家测绘地理信息局2014年立法工作计划》已经局长办公会审议通过，现印发给你们。为全面贯彻落实党的十八大、十八届三中全会、习近平总书记系列重要讲话精神，以及国务院办公厅《关于促进地理信息产业发展的意见》，现就做好国家测绘地理信息局2014年立法工作提出以下意见：

**一、**突出立法重点。要紧紧围绕国家测绘地理信息局今年的中心工作，把贯彻落实《国务院办公厅关于促进地理信息产业发展的意见》、优化产业发展政策环境、政府机构职能转变、行政审批制度改革、简政放权需要制定或修订的法律、行政法规、规章、规范性文件项目作为重中之重，集中力量攻关，及时完成起草和审核工作。同时做好市场监管、基础设施、技术装备、依法行政、公共服务等方面法规、规章、规范性文件的制定和修订，继续做好党的群众路线教育实践活动建章立制工作，巩固教育实践活动成果。

**二、**坚持立改废并举。要坚持法规“立、改、废”并举，按照2014年全国测绘地理信息局长会的部署，开展法律、法规、规章和规范性文件的全面梳理，抓紧清理妨碍事业发展、制约市场主体活力释放的规定和做法。由法规与行业管理司牵头、机关各司室配合，按照司室职责分工对涉及到的法律、法规、规章和规范性文件进行梳理。对于妨碍事业发展、制约市场主体活力释放的，要列出清单，提出废止或者修改的建议；对于需要补充完善的，应提出立法建议。法规与行业管理司统一汇总审核后，对于需要废止的，依照法定程序办理；需要修改补充完善的，法规与行业管理司统筹列入相应规划计划内分步进行。同时，要在此基础上，开展测绘地理信息法制建设综合调研，提出加强测绘地理信息立法工作和法制建设的意见和建议。

**三、**严格行政许可。起草法律、行政法规、规章和规范性文件，必须切实贯彻国务院“今后一般不新设许可”的要求。要把使市场在资源配置中起决定性作用和更好发挥政府作用有机结合起来，深入推进行政审批制度改革，进一步简政放权，提高行政效率。要把立法的重点切实转变到提供公共服务上来，强化对市场活动的事中事后监管。规章和规范性文件需要对上位法设定的行政许可进行细化的，要严格在上位法规定的许可范围、许可对象内进行，不允许任意扩大。

**四、**加强计划执行。机关各司室要严格按照《国家测绘局法规制定程序规定》的要求，对本司室负责的年度立法项目，明确进度，落实责任，做好调研、起草、论证和征求意见工作，按时完成立法任务，保证立法质量。法规与行业管理司要切实做好年度立法项目的指导、协调、审核等工作，确保立法计划顺利完成。

附件：

国家测绘地理信息局2014年立法工作计划

围绕2014年测绘地理信息工作要点，局2014年立法工作的总体思路是：认真贯彻党的十八大、十八届三中全会以及习近平总书记系列重要讲话精神，以李克强总理、张高丽副总理重要讲话和指示批示为指导，全面落实《国务院办公厅关于促进地理信息产业发展的意见》，结合巩固党的群众路线教育实践活动成果，按照全国测绘地理信息局长会的部署，加快建设符合国家改革发展新要求、适应新型服务业态发展规律和发展趋势的测绘地理信息法制体系。

2014年国家测绘地理信息局立法项目共计15项。

**一、**出台类项目（9项）

（一）建设法治政府，强化测绘地理信息统一监督管理，促进地理信息产业发展，繁荣地图市场，提高公共服务水平，需要修改的法律和行政法规。（2项）

1．修订《中华人民共和国测绘法》。《中华人民共和国测绘法》（以下简称《测绘法》）修订实施十多年来，党和国家不断对测绘地理信息工作提出新要求，测绘地理信息事业迅速发展，测绘地理信息的外延、内涵、功能、产品形式和服务模式等都发生了巨大变革，现行《测绘法》已经不能满足测绘地理信息事业发展及管理的需要。为适应新形势，有必要修订《测绘法》。2013年在深入开展实地调研，广泛收集资料的基础上，完成了《测绘法》修订草案初稿。2014年将继续深入开展调研、论证、协调、修改等工作，形成《测绘法》修订草案上报稿。该项目已列入国务院2014年立法工作计划。（法规与行业管理司牵头、机关各司室配合）

2．制定《地图管理条例》。随着经济社会的发展，特别是互联网地图服务的快速发展，地图管理工作出现了很多新情况、新问题，为加强地图管理，维护国家主权、安全和利益，繁荣地图市场，提高公共服务水平，有必要在《中华人民共和国地图编制出版管理条例》的基础上制定《地图管理条例》。条例已经国务院法制办审核通过，2014年继续配合国务院法制办做好条例出台前的相关工作。（法规与行业管理司、地理信息与地图司）

（二）贯彻落实《国务院办公厅关于促进地理信息产业发展的意见》，优化产业发展政策环境需要修订和制定的规范性文件。（3项）

3．修订《测绘资质管理规定》及《测绘资质分级标准》。

为适应测绘地理信息行业发展的新情况对资质管理工作提出的新要求，科学合理调整产业准入门槛，拓展测绘资质管理的覆盖面，完善测绘资质审批程序和监督检查制度，加强测绘资质许可的事后监管，优化地理信息产业发展环境，有必要修订《测绘资质管理规定》和《测绘资质分级标准》。（法规与行业管理司）

4．修订《测绘地理信息市场信用管理办法》和《测绘地理信息市场信用评价标准》。为贯彻落实十八届三中全会明确提出建立健全社会诚信体系、激发社会组织活力等要求，加强诚信体系建设，营造公平守信市场环境，提升信用评价结果的科学性和适用性，有必要对《测绘地理信息市场信用管理暂行办法》和《测绘地理信息市场信用评价标准（试行）》进行修订。（法规与行业管理司）

5．修订《测绘工程产品价格》。随着经济的快速发展，部分测绘项目成本费用额已经高于《测绘工程产品价格》，为进一步规范测绘工程产品价格，加快建立开放透明的市场规则，营造公平发展的环境，有必要对2002年颁布的《测绘工程产品价格》进行修订。（规划财务司）

（三）加快事业转型升级，提高核心竞争力，夯实数据基础，增强服务能力，需要修订的规范性文件。（2项）

6．制定《全国卫星导航定位连续运行基准站网管理办法》。为加强卫星导航定位连续运行基准站网的统筹管理，加快建成框架统一、定位精准、功能完备、分级管理、服务高效的全国卫星导航定位连续运行基准站网，有必要制定《全国卫星导航定位连续运行基准站网管理办法》。（国土测绘司）

7．修订《国家基础测绘项目管理办法》。《国家基础测绘项目管理办法（试行）》印发于2001年，办法中的相应内容与现行的管理方式不相适应，已不能满足管理的实际需求，有必要对办法进行修订和完善。（国土测绘司）

（四）强化依法行政，规范行政审批行为，促进测绘地理信息市场公平，需要修订的部门规章和规范性文件。（2项）

8．修订《地图审核管理规定》。正在制定的《地图管理条例》修改完善了地图审核管理有关内容，为与上位法保持一致，有必要修订《地图审核管理规定》有关内容。（地理信息与地图司）

9．修订《测绘行政审批程序规定》。按照国务院行政审批制度改革工作要求，我局将取消或下放部分行政审批项目；同时由于上位法修订，地图审核等行政审批内容发生变化，为与上位法保持一致，需修订《测绘行政审批程序规定》。（法规与行业管理司牵头，相关司配合）

**二、**调研类项目（6项）

积极开展测绘地理信息法制建设综合调研，进一步强化依法行政，促进测绘地理信息市场公平，完善基础设施建设，推动地理信息资源共享利用，维护地理信息安全，研究制定和修订的行政法规和规范性文件。（6项）

1．修订《中华人民共和国测量标志保护条例》。随着社会主义市场经济的发展，条例中的一些规定已经不能适应新形势下测绘地理信息工作的需要，在实践中出现了一些亟待解决的问题。鉴于测量标志建设、保管、使用、维护、管理等出现的新情况，有必要对条例进行修订。（地理信息与地图司）

2．制定《测绘地理信息行政执法自由裁量权基准制度》。为贯彻落实《国务院关于印发全面推行依法行政实施纲要的通知》及十八届三中全会“完善行政执法程序，规范执法自由裁量权，加强行政执法监督”的要求，将自由裁量权具体化、细节化防止其滥用，从而减少“同案不同罚”、“合法不合理”、“人情案”和“态度案”等情况的发生。有必要制定《测绘地理信息行政执法自由裁量权基准制度》。（法规与行业管理司）

3．修订《测绘市场管理暂行办法》。《测绘市场管理暂行办法》实施十多年以来，市场不断发育壮大，出现了许多新情况新问题；《国务院办公厅关于促进地理信息产业发展的意见》对规范和繁荣测绘地理信息市场提出了新要求；促进测绘地理信息市场公平已列入《2014年测绘地理信息工作要点》。为进一步规范测绘地理信息市场，维护测绘地理信息市场秩序，有必要对原暂行办法进行修订，并改为《测绘地理信息市场管理办法》。（法规与行业管理司）

4．制定《测绘行政执法错案责任追究办法》。为建设责任政府、法治政府，加强行政执法监督，促进行政机关及其工作人员依法行使职权，预防或减少行政执法错案的发生，保护公民、法人和其他组织的合法权益，有必要制定《测绘行政执法错案责任追究办法》。（法规与行业管理司）

5．修订《测绘管理工作国家秘密范围的规定》。随着经济社会发展对测绘成果需求的日益旺盛和迫切，测绘成果应用范围的不断拓展、应用层次的不断深入，测绘成果保密与应用之间的矛盾日益突出，现有的测绘成果保密范围划分不合理，使用限制过严，在一定程度上影响了地理信息资源开发利用水平，影响了信息化建设和地理信息产业的发展，增加了保密工作成本及使用风险，有必要对《测绘管理工作国家秘密范围的规定》进行研究修订，进一步推动测绘成果社会化应用。（地理信息与地图司）

6．制定《测绘地理信息技术装备标准化测试管理办法》。为促进新技术装备的推广与应用，提高新设备新技术应用的可靠性，维护生产企业合法利益，保障成果与服务质量，确保国家地理信息安全，有必要制定《测绘地理信息技术装备标准化测试管理办法》。（科技与国际合作司）
