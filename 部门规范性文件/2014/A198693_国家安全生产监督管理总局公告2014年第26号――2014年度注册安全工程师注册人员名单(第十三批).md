# 国家安全生产监督管理总局公告2014年第26号――2014年度注册安全工程师注册人员名单(第十三批)

国家安全生产监督管理总局公告

（2014年第26号）

根据《注册安全工程师管理规定》（国家安全监管总局令第11号）和《国家安全监管总局办公厅关于贯彻实施〈注册安全工程师管理规定〉有关事项的通知》（安监总厅人事〔2007〕44号），经各单位组织申报，省级、部门注册机构初审，国家注册机构审核合格，国家安全监管总局批准下列3147名符合注册安全工程师注册条件的人员注册，特此公告。

自公告之日起接受社会监督。任何单位和个人如对公告有异议，应当以真实身份（单位提出的应当加盖公章，个人提出的应当由本人签字）书面向国家安全监管总局人事司反映。

联系人及电话：XXX俊，010-64463146、64898716（注册咨询）。

地址：北京市东城区和平里北街21号，邮编：100713。
