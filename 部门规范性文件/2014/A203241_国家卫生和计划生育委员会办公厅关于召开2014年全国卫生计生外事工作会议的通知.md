# 国家卫生和计划生育委员会办公厅关于召开2014年全国卫生计生外事工作会议的通知

## 国家卫生和计划生育委员会办公厅关于召开2014年全国卫生计生外事工作会议的通知（国卫办国际函〔2014〕402号）

各省、自治区、直辖市、计划单列市及新疆生产建设兵团卫生计生委（卫生厅局、人口计生委），委机关各司局，有关委直属和联系单位，国家中医药管理局办公室：

为贯彻落实2014年全国卫生计生工作会议精神，交流全国卫生计生国际合作信息和经验，部署重点工作，定于2014年6月在辽宁沈阳召开全国卫生计生外事工作会议。现将有关事项通知如下：

**一、**会议内容

回顾和总结近三年来卫生计生国际合作与交流工作，分析国际国内形势变化和面临的挑战，明确卫生计生外事工作方向和目标。

**二、**会议时间和地点

时间：2014年6月6日（周五），会期1天。6月5日报到，6月7日离会。

地点：辽宁省沈阳市辽宁大厦（沈阳市皇姑区黄河南大街105号，电话：024-86081166）。

**三、**参会人员

（一）委领导，委机关各司局负责同志、国家中医药管理局、国家食品药品监督管理总局、总后卫生部外事主管部门负责同志各1人；

（二）各省、自治区、直辖市、计划单列市及新疆生产建设兵团卫生计生委（卫生厅局、人口计生委）分管外事工作的负责同志和外事主管部门负责同志各1人；

（三）委有关直属和联系单位负责同志和外事主管部门负责同志各1人。

**四、**其他事项

（一）请各地、各单位统一填写参会回执（见附件），于5月23日前反馈我委国际司。

（二）参会人员食宿费用由会议统一承担，其他费用自理。会议不安排接、送站，请自行前往会议地点报到。
