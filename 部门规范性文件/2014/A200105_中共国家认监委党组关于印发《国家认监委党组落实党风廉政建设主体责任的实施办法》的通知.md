# 中共国家认监委党组关于印发《国家认监委党组落实党风廉政建设主体责任的实施办法》的通知

## 中共国家认监委党组关于印发《国家认监委党组落实党风廉政建设主体责任的实施办法》的通知（国认党组〔2014〕11号）

各部室、下属单位：

为落实党的十八届三中全会精神及质检总局有关要求，切实发挥认监委党组在领导认监委党风廉政建设中的主体责任，进一步加强党风廉政建设和反腐败工作，特制定《国家认监委党组落实党风廉政建设主体责任的实施办法》，现印发你们，请监督执行。

国家认监委党组

2014年7月28日

国家认监委党组落实党风廉政建设主体责任的实施办法

“落实党风廉政建设责任制，党委负主体责任，纪委负监督责任”是以习近平同志为总书记的新一届中央领导集体对反腐倡廉形势正确判断后作出的重大决策，是更好落实党要管党、从严治党方针，加强党风廉政建设，深入开展反腐败斗争的重要制度支撑和根本保障。认监委党组为贯彻中央的这一要求，落实《中共质检总局党组关于落实党风廉政建设主体责任的实施意见》，切实担当起领导党风廉政建设的主体责任，进一步加强认监委党风廉政建设和反腐败工作，特制定本实施办法。

**一、**责任的主体

落实党风廉政建设责任制是认监委党组一班人必须严守的政治纪律。认监委党组和党组成员，是认监委党风廉政建设的责任主体。

（一）认监委党组对认监委党风廉政建设工作负全面领导的集体责任。

（二）党组书记是认监委党风廉政建设第一责任人，对全委党风廉政建设负全面领导责任。

（三）认监委党组成员是分管工作部门党风廉政建设的直接责任人，对分管工作负主要领导责任。

**二、**主体的责任

党组和党组成员对党风廉政建设实行集体领导和分工负责相结合，坚持谁主管、谁负责，对党风廉政建设和其他业务工作实行“一岗双责”。

（一）认监委党组承担全面领导的集体责任

认监委党组要认真学习贯彻中央和总局有关党风廉政建设的部署和要求，把党风廉政建设纳入党组重要议事日程，部署开展党性党风党纪和廉洁从政教育，及时分析和研判认监委党风廉政建设形势。结合实际制定党风廉政工作计划、目标要求和具体措施，将工作任务分解落实到相关单位，明确责任和要求。定期召开党风廉政建设工作会议，部署全委党风廉政建设工作。建立党组书记和纪检组长情况沟通机制，对重大问题及时进行沟通和研究。加强监督检查，推动工作落实。定期向总局报告党风廉政建设责任制落实情况。

（二）认监委党组书记承担第一责任人责任

党组书记对认监委党风廉政建设重点工作要亲自部署，重大问题亲自过问，定期听取有关党风廉政建设工作情况汇报，对全委党风廉政建设形势做到情况明晰。对重要案件亲自督办，支持纪检部门查处违纪违法问题，为办案创造条件、排除干扰。重点任务亲自协调，对一个时期内的突出问题，有针对性地提出要求和具体措施。

（三）党组成员承担“一岗双责”责任

党组成员根据工作分工，切实抓好分管范围内的党风廉政建设工作，担负好分管范围第一责任人的责任。坚持党风廉政建设与分管业务工作同研究、同部署、同检查、同落实。及时分析分管范围内党风廉政建设工作形势，梳理明确业务领域廉政风险，研究制定防控措施，防止业务领域廉政风险。加强对分管部门和单位领导干部的教育、管理和监督，防止分管范围内人员违法违纪问题的发生。

**三、**落实主体责任的主要任务

（一）选好用好管好干部，防止出现选人用人上的不正之风和腐败问题

按照《党政领导干部选拔任用工作条例》规定和总局有关制度，进一步完善和落实选拔任用、干部交流等措施，切实改进民主推荐、民主测评的方法，加强对干部选拔任用工作全过程的监督，抓好认监委领导干部在企业兼职的清理整顿工作和领导干部报告个人事项工作，规范行使选人用人权，从严选拔干部、从严管理监督干部，坚决反对和严厉查处选人用人上的不正之风。

（二）坚决纠正损害群众利益的行为

结合党的群众路线教育实践活动的开展，着力解决认监委党员干部“四风”方面存在的问题，严格执行行风建设“十不准”规定，加强窗口建设，深入开展政风行风评议活动。从人民群众最关注的质量安全需求做起，从人民群众最关心的突出问题抓起，从解决认证认可暨检验检测工作的热点难点问题做起，加大对违规机构和违规人员的查处力度，提高认证认可与检验检测行业的整体诚信水平，整治损害群众切实利益的不正之风。

（三）强化对权力运行的制约和监督，从源头上防治腐败

把职能转变、简政放权作为廉政建设的重点，加快新一轮行政审批项目清理，加强对已取消下放事项的落实情况的监督检查，重点防止出现以权谋私和新的权力寻租问题。加强政务公开工作，推进行政许可审批网上申报、网上办理、网上发证。不断完善电子监察系统，运用“制度加科技”手段，把对关键节点、重点对象的廉政风险防控要求嵌入到业务系统中，使权力可控、可查、可纠。继续推进财务管理制度改革，加强审计监督。

（四）领导和支持执纪执法部门查处违纪违法问题

加强对纪检监察工作的领导，支持纪检监察机构全面履行党章赋予的职责，实现转职能、转方式、转作风，做到聚焦主业、突出主业，有案必查、有腐必惩，严肃查办腐败案件，坚决整治损害人民群众利益的不正之风。尤其要重点查处问题线索反映集中、群众反映强烈、现在重要岗位且可能还要提拔使用的党员干部，坚决惩治腐败。

（五）管好班子，带好队伍

党组一班人要牢固树立不抓党风廉政建设就是严重失职的意识，把管人放在突出位置，动态跟踪干部的思想状况、作风状况和廉洁自律表现。党组书记要主动履行第一责任人的职责，带头严明党的纪律，带头执行中央“八项规定”和“约法三章”，管好自己、抓好班子、带好队伍，对出现的苗头性问题，及时提醒，敢于批评，对班子成员履行主体责任的情况进行监督，对落实主体责任不到位的，及时提醒、批评、纠正。党组成员要切实增强履行“一岗双责”的自觉性、主动性，带头遵守廉政准则、组织纪律和廉洁自律各项规定，管好家属、管好身边工作人员和分管单位领导干部，当好廉洁从政的表率。

**四、**发挥纪检监督职责

（一）加强对纪检监察工作的领导

党组领导并支持纪检监察机构全面履行党章赋予的职责，落实“三转”要求，强化监督、执纪、问责职能。进一步完善线索处置和案件查办情况定期向上级纪检监察部门报告制度，健全纪检监察干部激励机制，充分发挥纪检监察机构的职能作用。

（二）建立党组与纪检组在党风廉政建设和反腐败工作上的协调机制

自觉接受纪检监察部门的监督，主动听取纪检组的工作意见建议，全面了解掌握党员干部作风和纪律方面的问题，有针对性地抓好党风廉政建设。对苗头性、倾向性问题，早提醒、早纠正、早查处，及时约谈、诫勉，防止小问题变成大问题。充分运用纪检组查办案件中暴露出的问题和监督检查出的问题，及时开展警示教育，举一反三，有针对性地建章立制，堵塞漏洞。

**五、**完善相关制度

（一）完善“一岗双责”制度

党组成员要认真履行“一岗双责”，加强对分管工作及部门（单位）落实反腐倡廉任务的分类指导和督促落实。修订实行党风廉政建设责任制的实施办法，健全责任分解、检查监督、责任追究的完整链条，加大责任追究力度。层层传导压力，按照“谁主管、谁负责”的原则，督促指导各部门和单位一把手履行本部门和单位党风廉政建设第一责任人的责任、领导班子成员对职责范围内党风廉政建设的主要领导责任。

（二）建立党风廉政建设责任制的检查考核制度

在机关绩效考核中增加和强化对党风廉政建设情况的考核，完善检查考核的评价标准、指标体系，明确检查考核的内容、方法和程序。把落实党风廉政建设责任制情况，作为领导干部考核评价的重要内容，作为提拔使用、评先评优的重要依据，并进行廉政审核，坚持廉政一票否决。

（三）建立“一案双查”、约谈和责任追究等制度

对于重大腐败案件，既要追究当事人责任，又要追究相关领导责任，用问题导向来推动主体责任的落实。完善党风廉政建设谈话制度，党组成员定期约谈分管部门和单位负责人，对其进行党性党风党纪教育，对分管部门干部出现廉洁自律苗头性、倾向性问题的，及时进行诫勉谈话。
