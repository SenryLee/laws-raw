# 工业和信息化部关于杨拴昌、张春生任职的通知(2014)

## 工业和信息化部关于杨拴昌、张春生任职的通知（工信部任〔2014〕15号）

中国电子信息产业发展研究院：

工业和信息化部党组决定：

杨拴昌任职试用期满，考核合格，正式任中国电子信息产业发展研究院副院长；

张春生任职试用期满，考核合格，正式任中国电子信息产业发展研究院副院长；

以上两位同志的任职时间自2012年10月24日起计算。

工业和信息化部

2014年2月8日
