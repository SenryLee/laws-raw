# 环境保护部办公厅关于发布《重点环境管理危险化学品目录》的通知

环办[2014]33号

各省、自治区、直辖市环境保护厅（局），环境保护部各环境保护督查中心，新疆生产建设兵团环境保护局，辽河保护区管理局：
