# 农业部办公厅关于印发2014年“稳定发展粮食生产”延伸绩效管理工作实施方案的通知

## 农业部办公厅关于印发2014年“稳定发展粮食生产”延伸绩效管理工作实施方案的通知（农办农[2014]41号）

河北、内蒙古、辽宁、吉林、黑龙江、江苏、安徽、山东、河南、湖北、湖南、四川、江西、山西、福建、广西、云南、陕西、甘肃等省、自治区农业（农牧业、农村经济）厅（委），黑龙江省农垦总局：

为深入贯彻中央农村工作会议和中央1号文件精神，完善“米袋子”省长负责制，汇聚社会力量，集中相关资源，强化政策扶持，加强科技服务，切实把发展粮食生产作为“三农”工作的首要任务，千方百计促进粮食生产稳定发展，农业部决定2014年继续开展“稳定发展粮食生产”延伸绩效管理试点。现将《农业部2014年度“稳定发展粮食生产”延伸绩效管理工作实施方案》和《2014年度“稳定发展粮食生产”延伸绩效管理指标体系》印发你们，请认真组织实施。

2. 农业部2014年度“稳定发展粮食生产”延伸绩效管理指标体系。

2014年8月29日

附件1

农业部2014年度“稳定发展粮食生产”延伸绩效管理工作实施方案

为深入贯彻中央农村工作会议和中央1号文件精神，完善“米袋子”省长负责制，汇聚社会力量，集中相关资源，强化政策扶持，加强科技服务，切实把发展粮食生产作为“三农”工作的首要任务，千方百计促进粮食生产稳定发展，农业部决定2014年继续开展“稳定发展粮食生产”延伸绩效管理试点。

**一、**实施范围

根据《农业部2014年度绩效管理实施方案》和2013年度“稳定发展粮食生产”延伸绩效管理试点工作情况，2014年进一步扩大延伸绩效管理试点范围，对13个粮食主产区河北、内蒙古、辽宁、吉林、黑龙江、江苏、安徽、山东、河南、湖北、湖南、四川、江西和6个非主产区的山西、福建、广西、云南、陕西、甘肃省（自治区），以及黑龙江省农垦总局开展“稳定发展粮食生产”延伸绩效管理试点。

**二、**总体思路和原则

总体思路：立足日常工作，围绕目标任务，强化结果导向，突出过程管理。

按照“简便易行，逐步完善，自评为主，审核监督”的原则，通过考核评估，推动责任落实，促进措施到位。

**三、**评估考核内容与指标

（一）稳定粮食播种面积，15分。全省（自治区）粮食播种面积（以国家统计局公布数据为准，国家统计局未公布的，以各省上报农情数据为准，下同）稳定在前三年平均水平以上，满分15分。低于前三年最低水平，不得分；将前三年最低水平与平均水平的差值15等分，比前三年平均水平每减少一等分的面积扣1分，最多扣15分；比前三年最高水平每增加一等分面积加1分，最多加5分。

（二）稳定提高粮食产量，20分。全省（自治区）粮食总产量稳定在前三年平均水平以上，满分20分。低于前三年最低水平，不得分；将前三年最低水平与平均水平的差值20等分，比前三年平均水平每减少一等分的产量扣1分，最多扣20分；比前三年最高水平每增加一等分产量加1分，最多加5分。

（三）加强示范带动和科技支撑，20分。完成农业部下达的万亩高产示范片创建任务，增产效果明显满分5分；增产模式攻关取得良好进展，增产效果显著满分4分；科学施肥、耕地质量建设与保护、节水技术等新技术集成与推广实施取得显著成效满分5分；粮食生产用种供应充足、质量安全满分6分。

（四）加大行政推动和政策支持力度，15分。行政推动有力满分6分；全面落实中央扶持政策，及时出台地方配套政策满分9分。任一项政策未达到预期效果的，减1分，累计减分不超过15分。

（五）努力减轻自然灾害损失，17分。全省（自治区）应对气象灾害工作主动、科学防灾减灾措施有力，损失粮食产量（上报农业部农情调度数）低于前三年平均水平得满分8分，粮食因灾损失每多**万吨扣1分，最多扣8分；重大病虫监测预警及时准确，粮食病虫损失率总体控制在5%以下满分9分，每多0.5个百分点扣1分，最多扣9分。

（六）发展新型生产经营主体和现代物质装备，13分。粮食生产规模经营主体（含种粮大户、家庭农场和粮食生产合作社）个数比上年增加10％以上满分5分，每少1个百分点扣0.5分，最多扣5分；以粮食生产经营加工为主的农业产业化龙头企业与农户建立紧密型利益联结机制满分2分，未建立不得分；农作物耕种收综合机械化水平达到65%以上，或一种主要粮食作物1个薄弱环节机械化水平比上年增增幅超过2个百分点，满分6分，每少完成1项扣1分，最多扣6分。

（七）创新性奖励分，10分。对得到中央主要领导肯定行批示的，或在政策扶持、项目管理、行政推动、技术服务等方面有重大创新并得到领导好评，或承担农业部组织重大活动有突出贡献，以上情况给予加分奖励，最高累计不超过10分，未得到以上批示等奖励项目的不得分。

**四、**评估考核方法

（一）考评方法。考评采取省级农业部门自评、农业部种植业管理司牵头部内相关司局组织审核，并根据最终得分确定考评档次。审核一般采取书面审核，必要时进行抽查审核。考评档次分为优秀、良好和一般。

（二）数据采集。全省（自治区）粮食面积、产量采用国家统计局确认的农调队数据，因自然灾害损失粮食产量采用种植业管理司农情调度系统上报农业部数据。粮食生产家庭农场、专业合作社个数采用农村经济体制与经营管理司的统计数据，农作物机械化水平数据由省（区、市）农机化主管部门提供。

（三）赋分办法。赋分实行“基础分＋效果分＋奖励分”的办法，即完成该项指标可得该项分值90%的基础分，10%的分值根据指标完成的质量和效果分档赋效果分，奖励分最高20分。省级农业部门自评和农业部审核时，依据以下标准。

1.工作措施有力、全面按时完成绩效指标的，得该项指标分值90%的基础分。

2.工作有亮点，得该项指标分值的91%-93%。如在省报、省电视台、省广播电台等省级新闻媒体上有专题宣传报道的，或向同级党委、政府和农业部报送相关信息并被采用的，或在以同级党委、政府名义召开的会议上作典型经验交流发言的，或受到农民群众、服务对象、有关部门单位、地方党委政府好评的。

3.工作成效明显，得该项指标分值的94%-97%。如在人民日报、中央电视台、中央人民广播电台、农民日报、央视七套农业节目、中国农业信息网等新闻媒体上有专题宣传报道的，或得到同级党委、政府负责人肯定性批示，或得到同级党委办公厅、政府办公厅和农业部办公厅表彰奖励，或超额完成目标任务5%以上的，或在全国有关会议上作典型经验交流发言的，或争取政策有重大突破的。

4.工作成效显著，得该项指标分值的98%-100%。如得到同级党委、政府主要负责人和农业部部长以上领导同志肯定性批示，或得到省、部级以上表彰的，或产生巨大经济社会效益的。

5.工作重大创新和重大成效，奖励分10分。得到中央主要领导肯定性批示的，奖励5分；中央政治局常委或副总理肯定性批示的，奖励3分；地方政府对粮食生产新增重大投入、出台相关法律法规或面对重大自然灾害组织特别有力的，奖励3-5分；承担农业部布置的重大活动，或承担粮食增产模式攻关等区域性协调工作，在行政推动、技术支撑等方面有突出创新行为的，奖励2-3分。累计不超过10分。

上述效果分赋分标准，每项只可对应一项指标。

工作质量和效果有上述多项的不累计，按最高项赋分。

绩效管理指标未完成的，以该项指标分值90%为基准，按照指标体系中设定的评分标准进行相应扣分。出现重大错误、失误、延误的，或造成严重后果的，该项指标不得分。

**五、**进度安排

7月底前，制定印发2014年度延伸绩效管理工作实施方案及指标体系模板。

8月底前，试点省（自治区）农业行政主管部门制定上报本省（自治区）实施方案和《2014年度“稳定发展粮食生产”延伸绩效管理指标体系》。

9月底前，以农业部办公厅文件印发《2014年度“稳定发展粮食生产”延伸绩效管理指标体系》。

2015年2月底以前，试点省（自治区）农业行政主管部门对上年“稳定发展粮食生产”延伸绩效管理考评项目进行自评，将评估报告连同考评依据材料一并报种植业管理司。

2015年4月底以前，种植业管理司牵头组织审核各省（自治区）自评估情况，并确定考评档次，报送农业部办公厅（部绩效办）。

**六、**结果运用

探索、总结和完善“稳定发展粮食生产”绩效管理考评机制和指标体系，充分运用考核评估信息，分析存在的问题，研究改进措施，促进绩效持续提升。经考评，被确定为优秀档次的省级农业行政主管部门，由农业部通报省政府，并在全国农业厅局长会议上予以表彰。考核评估结果还将作为“粮食综合生产能力”指标考核评价和制定相关扶持政策的重要参考。

**七、**保障措施

为了确保“稳定发展粮食生产”延伸绩效管理工作顺利开展，农业部成立“稳定发展粮食生产” 延伸绩效管理考评领导小组和考评工作小组。由种植业管理司主要负责人为组长，农村经济体制与经管管理司、市场信息司、发展计划司、财务司、科技教育司、种子管理局、农机化司、农垦局、农产品质量安全监管局分管负责人为成员，主要负责审定年度实施方案和各省（自治区）指标体系，研究确定各省（自治区）的考评档次。

“稳定发展粮食生产” 延伸绩效管理考评工作小组由种植业管理司主管负责人为组长，种植业管理司综合处、粮油处，农村经济体制与经管管理司、市场信息司、发展计划司、财务司、科技教育司、种子管理局、农机化司、农垦局、农产品质量安全监管局有关处一名处级干部为成员，主要负责拟定年度实施方案，具体审核各省（自治区）指标体系和自评情况。

各省（自治区）农业行政主管部门要明确负责牵头实施的处室和联络员，并将牵头处室名称和联络员姓名、联系方式（办公室电话、手机、传真号码和电子邮箱）报送农业部种植业管理司。
