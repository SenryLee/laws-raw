# 国家核安全局关于颁发2014年第一批核动力厂操纵人员执照的通知

## 国家核安全局关于颁发2014年第一批核动力厂操纵人员执照的通知（国核安函[2014]8号）

国家能源局：

你局《关于魏君安等193人申请核电厂反应堆操纵人员执照的函》（国能核电〔2013〕220号）等文件收悉。

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则有关规定和你局的审查意见，我局对辽宁红沿河核电有限公司等2家营运单位民用核设施操纵人员执照申请文件进行了审核，认为赵立辉等20人具备了民用核设施操纵人员资格，批准颁发执照（批准颁发执照的操纵人员名单、执照号和有效期见附件）。

特此通知。
