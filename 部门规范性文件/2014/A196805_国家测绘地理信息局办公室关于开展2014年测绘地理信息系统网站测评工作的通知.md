# 国家测绘地理信息局办公室关于开展2014年测绘地理信息系统网站测评工作的通知

## 国家测绘地理信息局办公室关于开展2014年测绘地理信息系统网站测评工作的通知（测办〔2014〕52号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位：

为贯彻落实《国务院办公厅关于进一步加强政府网站管理工作的通知》（国办函〔2011〕40号）、《国务院办公厅关于开展重点领域网络与信息安全检查行动的通知》（国办函〔2012〕102号）、《国务院办公厅关于进一步加强政府信息公开回应社会关切提升政府公信力的意见》（国办发〔2013〕100号）和《关于加强党政机关网站安全管理的通知》（中网办发文〔2014〕1号），促进测绘地理信息部门网站建设，提高服务水平，发挥网站在信息公开、在线办事、互动交流等方面的重要作用，国家测绘地理信息局将在2014年继续开展测绘地理信息系统网站测评工作。现就有关事项通知如下：

**一、**测评范围

参加本次测评的网站范围：2014年6月1日前建成并投入使用的各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位、有关测绘单位的门户网站（见附件1）。

**二、**测评方式

充分尊重客观现实，引导规范网站群建设模式，坚持客观、公正的基本原则，委托第三方专业测评机构开展测评。

**三、**测评依据

（一）工业和信息化部印发的《政府网站发展评估核心指标体系（试行）》。

（二）2014年度测绘地理信息系统网站测评指标体系（见附件2）。

**四、**时间安排

（一）分阶段测评：8月－11月

1．第一阶段：抽取信息公开、互动渠道反馈等部分指标进行测评，考核时间为2014年8月。

2．第二阶段：抽取办事服务等部分指标进行测评，考核时间为2014年9月。第一、二阶段测评结果由国家测绘地理信息局管理信息中心通过发函的方式反馈给各参评单位，要求各单位针对自身存在的问题和不足进行整改完善，各单位应根据实际情况在第三阶段测评前反馈自身整改情况，作为第三阶段的考核依据。

3．第三阶段：结合第一、二阶段各单位网站问题的整改情况重新考核整套指标体系，并依据整改效果在网站年度测评总成绩上酌情减分，考核时间为2014年11月。

各阶段的测评指标详见《2014年测绘地理信息系统网站测评指标体系》（附件2）。

（二）网站运维管理调查与特色栏目推荐：10月10日－10月25日

各单位认真填写《2014年测绘地理信息系统网站运维管理与特色推荐问卷》（附件3），加盖公章后于10月25日前反馈至国家测绘地理信息局管理信息中心，电子文档请一并反馈。

（三）审核结果：12月

由第三方专业测评机构汇总所有数据，形成最终结果以及各参评单位的分报告、总报告，由局管理信息中心负责审核。

（四）结果发布：12月底

以内部情况通报的方式发布《关于2014年测绘地理信息系统网站测评情况的通报》，以专题的形式在国家测绘地理信息局网站上发布结果。

请各参评单位高度重视此次网站测评工作，认真做好相应准备，依据指标体系对网站进行必要的调整完善，并积极做好自评工作。
