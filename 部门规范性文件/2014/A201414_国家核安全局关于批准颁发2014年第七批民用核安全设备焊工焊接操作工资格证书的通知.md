# 国家核安全局关于批准颁发2014年第七批民用核安全设备焊工焊接操作工资格证书的通知

## 国家核安全局关于批准颁发2014年第七批民用核安全设备焊工焊接操作工资格证书的通知（国核安发[2014]138号）

各聘用单位：

根据《民用核安全设备监督管理条例》和《民用核安全设备焊工焊接操作工资格管理规定》（HAF603），我局对大连宝原核设备有限公司等6家民用核安全设备焊工焊接操作工考核中心的焊工项目考试评定报告进行了审查（考试编号见附件1），认为大连宝原核设备有限公司等17家聘用单位的135名焊工焊接操作工符合相关要求，批准颁发民用核安全设备焊工焊接操作工资格证书（基本信息见附件2），共计208项合格项目。

特此通知。
