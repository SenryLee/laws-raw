# 中央国家机关政府采购中心关于延长2012―2014年度中央国家机关电梯定点有效期的通知

## 中央国家机关政府采购中心关于延长2012-2014年度中央国家机关电梯定点有效期的通知

2012-2014年度中央国家机关电梯定点有效期于2014年3月31日截止。目前，新一期限额内电梯定点的相关招标工作正在进行中。为保障中央国家机关限额内电梯业务顺利开展，现将2012-2014年度中央国家机关电梯定点的有效期延长至新一期入围供应商中标结果公布。

特此通知。
