# 全国工业产品生产许可证办公室关于公布2014年第三批工业产品生产许可证注册审查员期满换证暨注册人员名单的通知

## 全国工业产品生产许可证办公室关于公布2014年第三批工业产品生产许可证注册审查员期满换证暨注册人员名单的通知（全许办〔2014〕6号）

各省、自治区、直辖市工业产品生产许可证办公室，相关产品审查部：

根据《中华人民共和国工业产品生产许可证管理条例》（国务院令第440号）、《中华人民共和国工业产品生产许可证管理条例实施办法》（国家质检总局令第80号）和《工业产品生产许可证核查人员管理规定》（总局2011年第11号公告）的规定，2014年第三批由天津、河北、辽宁、江苏、山东、河南、陕西省（市）生产许可证办公室和钢筋混凝土用带肋钢筋、危险化学品、特种劳动防护、人民币伪钞鉴别仪、农机、摩托车乘员头盔产品生产许可证审查部推荐的期满换证人员255人（见附件1），2014年第三批由山西、江苏、安徽、广西、陕西省（自治区）生产许可证办公室和铁路专用、钢筋混凝土用带肋钢筋产品生产许可证审查部推荐的注册审查员204人（见附件2），经审核合格，符合换证、注册条件，现予以公布。
