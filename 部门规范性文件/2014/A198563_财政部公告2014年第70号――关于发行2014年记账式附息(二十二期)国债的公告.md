# 财政部公告2014年第70号――关于发行2014年记账式附息(二十二期)国债的公告

财政部公告

（2014年第70号）

根据国家国债发行的有关规定，财政部决定发行2014年记账式附息（二十二期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

**一、**本期国债计划发行220亿元，实际发行面值金额224.5亿元。

**二、**本期国债期限1年，经招标确定的票面年利率为3.71%，2014年9月22日开始计息，招标结束后至9月24日进行分销， 9月26日起上市交易。

**三、**本期国债为固定利率附息债，到期一次还本付息，2015年9月22日（节假日顺延）偿还本金并支付利息。

其他事宜按《中华人民共和国财政部公告》（2014年第1号）规定执行。

特此公告。

财政部

2014年9月19日
