# 农业部关于印发《农业应急管理信息化建设总体规划(2014－2017年)》的通知

## 农业部关于印发《农业应急管理信息化建设总体规划（2014－2017年）》的通知（农办发[2014]1号）

各省、自治区、直辖市、计划单列市农业（农牧、农村经济）、农机、畜牧、兽医、农垦、乡镇企业、渔业厅（局、委、办），新疆生产建设兵团农业局，部机关相关司局、有关直属单位：

根据国务院关于加强突发事件应急管理有关部署要求，为贯彻落实《农业部关于进一步加强农业应急管理工作的意见》，加快推进农业应急管理信息化建设工作，提升农业突发公共事件应急管理水平，农业部制定了《农业应急管理信息化建设总体规划（2014－2017年）》，现印发给你们，请结合实际认真贯彻落实。

农业部

2014年1月13日
