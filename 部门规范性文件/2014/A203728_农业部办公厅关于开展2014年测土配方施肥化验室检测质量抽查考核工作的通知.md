# 农业部办公厅关于开展2014年测土配方施肥化验室检测质量抽查考核工作的通知

## 农业部办公厅关于开展2014年测土配方施肥化验室检测质量抽查考核工作的通知（农办农〔2014〕21号）

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）厅（委、局），新疆生产建设兵团农业局，黑龙江农垦总局：

为提高测土配方施肥化验室检测水平，确保土壤检测数据质量，我部组织开展2014年度测土配方施肥化验室检测质量抽查考核工作，现将有关事宜通知如下。

**一、**考核对象

本次考核对象为100个项目县（场、单位）化验室（名单见附件1），本次考核对象是从已抽查的712个以外的测土配方施肥项目县（场、单位）化验室中随机抽取产生。

**二、**考核项目

土壤pH（采用电位法，水土比为2.5：1）、土壤有机质（采用油浴加热重铬酸钾氧化－容量法）、土壤全氮（采用凯氏法）、土壤有效磷（采用碳酸氢钠浸提－钼锑抗比色法）和土壤速效钾（采用乙酸铵浸提－火焰光度计法）。

**三、**时间安排

全国农业技术推广服务中心负责抽查考核的组织工作。

5月26－6月5日，全国农业技术推广服务中心统一将样品发放到省级农业部门，再由省级农业部门发放到被考核项目县（场、单位）。

6月6－15日，被考核单位完成样品检测任务，并填报样品检测结果汇总表（见附件2）直接报送到全国农业技术推广服务中心。

6月底，分析汇总抽查考核情况，通报抽查考核结果。

8月底，考核不合格单位完成整改工作，以省为单位向全国农业技术推广服务中心提交整改报告。

9月底，重新考核不合格单位。

**四、**有关要求

请各省（区、市）农业部门加强对被考核项目县（场、单位）的技术指导和监督检查。被考核项目县（场、单位）要高度重视，所有考核项目检测必须在本单位化验室由本单位化验员完成，严禁弄虚作假。被考核项目县（场、单位）报送样品检测结果汇总表的同时，附上参与考核项目检测的化验员、审核员和批准人的姓名、单位、职务职称等相关信息。规定时间内无故不上报考核结果者按不合格处理。

联系人：全国农业技术推广服务中心土壤肥料质量监测处郑磊，地址：北京市朝阳区麦子店街20号楼，邮编：100125，电话：010－59194504，59194730（传真）。
