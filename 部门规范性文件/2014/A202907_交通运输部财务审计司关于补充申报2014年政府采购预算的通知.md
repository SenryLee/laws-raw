# 交通运输部财务审计司关于补充申报2014年政府采购预算的通知

各有关单位：

为加强政府采购预算管理，规范政府采购行为，现就2014年“二上”预算后调增的部分补报政府采购预算的事项通知如下：

**一、**各单位应根据批复的部门预算及政府采购预算的实际情况，对需要补报政府采购预算的项目，严格按照国务院办公厅公布的集中采购目录及采购限额标准，申报政府采购预算。

**二、**各单位在补报政府采购预算时，请按照本通知所附申报表格式填列（见附件，可在交通运输部政府网站财务审计司子站政府采购栏目下载）。

**三、**各单位请于5月30日前，将补报政府采购预算的相关材料（正式文件和光盘各一份）报我司。

联系人：孟丽静 联系电话：010-65292963
