# 全国爱卫办关于开展2014年“全球洗手日”和“世界厕所日”宣传活动的通知

## 全国爱卫办关于开展2014年“全球洗手日”和“世界厕所日”宣传活动的通知（全爱卫办函〔2014〕11号）

各省、自治区、直辖市和新疆生产建设兵团爱卫办，全国爱卫会各成员单位：

2014年10月15日是第7个“全球洗手日”，宣传主题是“选择洗手，选择健康”；11月19日是第2个“世界厕所日”，宣传主题是“平等与尊严”。为切实开展好两个宣传日活动，提高全民卫生意识，促进人民群众健康，现就活动有关事项通知如下：

**一、**突出宣传重点

各地要结合两个宣传日的活动主题，精心组织策划，结合本地实际制定宣传方案，以完善公共环境的洗手设施和加强农村地区无害化卫生厕所建设为重点，广泛宣传卫生基础设施在群众形成良好卫生习惯、预防控制疾病暴发流行等方面的重要作用，促进全社会的普遍重视。要注重在托幼机构和中小学校宣传正确的洗手方法，开展形式新颖、互动性强的洗手活动，引导少年儿童从小树立科学洗手观念。要从多角度、多侧面阐释清洁卫生厕所对于公众健康和社会文明的重要意义，宣传农村改厕和城市公厕建设成果，促进全社会重视厕所文明建设。

**二、**创新宣传形式

各地要把卫生防病形势宣传、改厕工作的成就宣传、好经验好作法的典型宣传相结合，丰富宣传内容，让群众爱听爱看，引起共鸣。要充分发动社区、农村群众自建的文娱团队参与宣传活动，通过一些有吸引力和感染力的小品、快板、歌舞等，使宣传内容入脑入心。要适应微博、微信等新媒体传播规律，动员社会力量参与，加强可视化作品的制作和宣传，扩大传播范围。要在机场、车站、港口以及重点公共场所，利用LED广告屏和广播等形式，加大对流动人口的宣传教育。

**三、**强化宣传效果

各地要充分发挥爱国卫生运动的优势，加强组织领导，开展丰富多彩的宣传活动，注重营造共同关注、广泛参与的良好氛围。各级爱卫办要加强统筹协调，与宣传、教育、农业、住建以及工会、共青团、妇联等部门密切配合，明确任务分工和责任落实，认真做好宣传动员和工作总结，确保宣传活动取得实效。国家卫生城市（乡镇）要结合巩固卫生创建成果的工作，带头开展宣传活动，充分发挥典型示范作用。

在活动期间，我办将发布相关宣传信息、海报和短片，供各地参考使用。

全国爱卫办

2014年9月30日
