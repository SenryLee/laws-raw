# 中华全国供销合作总社办公厅关于召开2014全国农资科技博览会暨农民合作社与农资供应商、农产品采购商对接会的通知

## 中华全国供销合作总社办公厅关于召开2014全国农资科技博览会暨农民合作社与农资供应商、农产品采购商对接会的通知（供销厅函农字【2014】47号）

各省、自治区、直辖市及新疆生产建设兵团供销合作社：

为进一步落实中华全国供销合作总社（以下简称总社）五届九次理事会议精神，搭建为农服务的综合平台，总社农业生产资料局、合作指导部定于2014年10月14-15日在山东省潍坊市举办“2014全国农资科技博览会暨第二届农民合作社与农资供应商、农产品采购商对接会”，同时举办2014年度中国农资经销商年会、供销合作社基层组织建设系列培训--农民合作社建设培训班。现将有关事项通知如下：

**一、**会议主题

合作 创新 共赢，搭建为农服务综合平台

**二、**举办单位

指导单位：中华全国供销合作总社

主办单位：中华全国供销合作总社农业生产资料局、中华全国供销合作总社合作指导部、山东省供销合作社联合社、潍坊市人民政府

承办单位：中国农业生产资料流通协会、潍坊市供销合作社、郑州欧亚国际展览有限公司、贸促会供销合作分会

支持媒体：中华合作时报社、农资导报、中国化工信息中心

**三、**会议内容

（一）2014全国农资科技博览会

1、设立肥料信息交流暨产品交易展区、植保技术交流暨农药产品交易展区、种子信息交流暨产品交易展区、农业机械交易展区、节水灌溉及温室技术设备交易展区。

2、为集中展示我国肥料产品优化升级的最新成果，专设新型肥料及BB肥展区。

（二）农民合作社与农资供应商对接会及2014年度中国农资经销商年会

1、农资企业对新服务、新技术、新产品进行推介；农民合作社代表与农资企业洽谈对接，并签订产品购销及服务定制意向协议。

2、交流农资企业与农民合作社合作共赢典型经验。

3、发布“2013中国农资流通行业年度发展报告”。

4、发布“2013年中国农资流通企业综合竞争力排名”（前100名）及“2013年度中国农资行业知名品牌”。

5、现场投票评选“2014年度中国农资经销商最佳合作厂家”（前30名）。

（三）农民合作社与农产品采购商对接活动

1、农产品采购商代表介绍超市采购要求及相关流程。

2、农产品采购商与农民合作社代表洽谈对接，并签订采购意向协议。

3、设置农产品展台专区，对农民合作社的特色优质农产品进行展览展示。

（四）农民合作社建设培训班

1、供销合作社理论与实践。

2、农民合作社发展形势任务。

3、标准化生产、品牌化经营、市场化对接。

4、交流互动。

**四、**会议时间与地点

（一）2014全国农资科技博览会

1、展会时间：2014年10月14～15日，会期两天。10月12～13日为展会报到及布展时间。

2、地点：山东省潍坊市富华国际展览中心。

3、展商报到时间及地点：2014年10月12～13日，山东省潍坊市富华国际展览中心内展商报到处。

（二）农民合作社与农资供应商、农产品采购商对接会及2014年度中国农资经销商年会

1、会议时间：2014年10月14～15日，会期一天半。

2、会议地点：

现场洽谈地点：富华国际展览中心内对接洽谈区。

对接会地点：富华会议中心1层多功能厅。

3、报到时间：10月13日全天报到。

报到地点：潍坊富华大酒店（A座）大堂。

（三）农民合作社建设培训班

1、培训时间：2014年10月13～15日。

2、培训地点：富华会议中心1层多功能厅。

3、报到时间：10月12日全天报到。

4、报到地点：潍坊富华大酒店（B座）大堂。

**五、**参会及参展人员

总社、山东省有关领导，总社有关部局、山东省供销合作社及潍坊市相关负责同志，各省级供销合作社合作指导处或相关业务处室负责同志，农产品采购商，肥料、种子、农机、农膜、农药等生产商、经销商代表，农民合作社（示范社）代表等。
