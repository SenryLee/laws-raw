# 科学技术部基础研究司关于开展科技基础性工作专项项目科学数据汇交培训工作的通知

## 科学技术部基础研究司关于开展科技基础性工作专项项目科学数据汇交培训工作的通知（国科基函〔2014〕23号）

国务院有关部门科技主管单位，各项目承担单位：

为了规范科技基础性工作专项项目科学数据汇交工作，确保汇交数据的质量，我司拟于7月4日在北京组织开展专项项目科学数据汇交培训工作，对已验收和拟验收项目进行数据汇交培训。现将有关事项通知如下：

**一、**培训对象

2006年、2007年和2008年立项的所有项目，以及2009年立项的一般项目，共104个项目，具体项目清单见附件1。

**二、**培训内容

1. 专项项目科学数据汇交总体流程；

2. 专项项目科学数据汇交方案编制；

3. 专项项目基本信息和元数据填报；

4. 专项项目数据说明文档编写；

5. 专项项目标本资源描述信息填写；

6. 专项项目科学数据汇交方式与文件整理；

7. 专项项目数据汇交软件工具使用。

**三、**集中培训方式

以集中授课的方式，开展对上述7项内容的培训，并上机进行数据汇交软件工具的操作。此次培训工作由中科院地理科学与资源研究所承办。

**四、**有关要求

1. 请各项目依托部门和承担单位高度重视，认真组织，每个项目必须委派1名负责项目科学数据汇交业务的骨干人员参加培训。

2. 培训人员应提前熟悉附件3至5的材料，了解项目数据汇交的内容、流程和要求。

3. 培训人员应熟悉各自项目产生的科学数据基本情况、信息化及保存状况等。可提前进行汇交方案、元数据、数据文档等的试填，以便更好的交流讨论。

4. 培训人员自带笔记本电脑（提前安装Office软件、网络浏览器软件等）。

5. 培训人员往返交通费、食宿费自理。

6. 请于6月30日前将参加人员回执（见附件2）发送至：lexf@igsnrr.ac.cn。

**五、**培训时间和地点

1. 培训时间：2014年7月4日9：00-17：00。京外单位7月3日下午报到，京内单位可于4日8：00-8：45报到。

2. 培训地点：北京西郊宾馆（海淀区王庄路18号）。

**六、**联系人及联系方式

科技部基础研究司综合计划处：祝学衍。

电　话：010-58881556。

中科院地理科学与资源研究所：乐夏芳，杨雅萍，诸云强。

电　话：010-64888092，64889452，64888056。

E-mail：lexf@igsnrr.ac.cn，yangyp@igsnrr.ac.cn，zhuyq@igsnrr.ac.cn。

元数据填写说明：

1. 资源唯一标识：系统自动产生。

2. 资源学科分类：资源所属的学科分类，参照国家学科分类与代码，选择到二级学科分类。

3. 资源中文名称：反映资源内容及主要特征的中文名称。

4. 资源英文名称：中文名称对应的英文名称。

5. 资源描述摘要：资源内容、特征等的简要描述。

6. 关键词：可以是多个，中间用“，”隔开。

7. 资源类型：可以是数据、图集、志书、典籍、标本资源、标准规范、论文专著和研究报告等。

8. 资源格式：资源存在的格式。可以有多个，中间用“，”隔开。

9. 资源时间：资源内容的时间点或时间范围。数据、图集、志书、典籍时间是指其内容表达的时间，而标本资源时间指采集、制备的时间，标准规范时间是指正式发布的时间，论文专著是指正式发表或出版的时间，研究报告是指编撰完成的时间。

10. 资源地点：资源内容表述的地理位置。数据、图集、志书典籍地点是指其内容所表达的地点；标本资源指采集的地点（产地）。

11. 最新修订时间：资源的最新更新时间。资源没有修订时，为资源的形成时间。

12. 共享方式：完全开放共享、协议共享、暂不共享中的其中一种。完全开放共享是指用户可以自由获取资源；协议共享是指用户需要提出申请，签署协议后获取资源；暂不共享是指出于国家安全、保密等原因，暂不对外共享或需要经过主管部门审批后才能共享的资源。

13. 资源质量描述：对表述资源质量的资源精度、适用范围，以及资源采集、加工处理采用的仪器设备、标准规范、模型方法等的描述。

14. 在线链接地址：在线获取或访问资源的网络地址。可以有多个链接地址，中间用“，”隔开。

15. 缩略图：反映资源概貌、内容或特征的图片，可以是多张图片。

16. 来源项目：支持数据资源产生的基础性工作专项项目的信息，包括：项目编号、项目名称、项目负责人和第一承担单位。

17. 资源负责方：产生资源或拥有资源处置权并对资源质量负责的个人及单位信息，包括：负责人姓名、电子邮箱、联系电话、传真、所在单位名称、地址、邮编。

18. 资源管理方：保藏、管理和对外提供资源服务的单位及联系人信息，包括：单位名称、联系人姓名、电子邮箱、联系电话、传真、地址、邮编。项目承担单位如果没有专门管理资源和提供服务的机构时，可不填写此项。待资源汇交上来后，由科学数据管理机构作为资源的管理方，补充完善此信息。

19. 元数据管理信息：元数据编写人姓名、联系电话、电子邮箱以及元数据的最新更新时间。
