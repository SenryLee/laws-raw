# 国管局公共机构节能管理司2014年高校节能宣传作品征集活动组委会关于公布2014年高校节能宣传作品获奖名单的通知

国管局公共机构节能管理司2014年高校节能宣传作品征集活动组委会关于公布2014年高校节能宣传作品获奖名单的通知

（节能函〔2014〕26号）

各省、自治区、直辖市和新疆生产建设兵团教育厅（教委、局）、机关事务管理部门、团委，教育部等部门直属高校：

在国家机关事务管理局、教育部、共青团中央联合举办的2014年高校节能宣传作品征集活动中共有71件作品被评为平面设计类、视频类、标识标语类作品一、二、三等奖和优秀奖，40个单位获优秀组织奖。根据征集活动方案有关安排，现将获奖名单予以公布。

附件：2014年高校节能宣传作品征集活动获奖名单。

2014年高校节能宣传作品征集活动组委会

2014年7月8日
