# 工业和信息化部办公厅关于组织开展2014年度铸造行业准入公告申报工作的通知

## 工业和信息化部办公厅关于组织开展2014年度铸造行业准入公告申报工作的通知（工信厅装函[2014]197号）

根据《铸造行业准入条件》，为做好2014年度铸造行业准入公告申报工作，现将有关事宜通知如下：

**一、**请你单位组织本地区铸造企业开展准入公告申报工作，企业须按照《铸造行业准入公告管理办法》（工信部装［2013］375号）的要求，在全国铸造企业准入公告申报平台（http：//zr.foundry.com.cn）进行网上填报，并提交书面申请材料。

**二、**请于8月31日前，将你们审查合格的申请企业名单和企业准入申报材料（每家企业1份）报送工业和信息化部（装备工业司）。

**三、**对已公告企业，请按《铸造行业准入公告管理办法》的要求，督促企业在公告申报平台上及时更新年度数据。并对企业保持准入条件情况进行监督检查。检查结果请于6月30日前报送工业和信息化部（装备工业司）。

**四、**今后年度申报工作如不另行通知，均按照上述程序办理。

工业和信息化部办公厅

2014年3月27日
