# 交通运输部科技司关于开展2014年度交通运输建设科技成果推广目录申报工作的通知

## 交通运输部科技司关于开展2014年度交通运输建设科技成果推广目录申报工作的通知（科技项目函〔2014〕66号）

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），天津市交通运输和港口管理局，天津市市政公路管理局，有关科研院所、高等院校，部属各单位，大型交通运输企业：

为加强科技成果向现实生产力的转化，推动交通运输建设科技成果的推广应用，根据《关于开展交通运输建设科技成果推广目录发布工作的通知》（科技项目函〔2011〕174号）的要求，我司将组织开展2014年度交通运输建设科技成果推广目录。现将有关事项通知如下：

**一、**申报要求

此次申报主要面向经省部级科技主管部门鉴定的交通运输建设科技成果，具体如下：

（一）围绕加快发展平安交通的重点任务，针对交通运输系统安全、设施安全、运输安全和环境安全，重点支持监测预警技术、检测评估技术、仿真决策技术、维修加固技术和应急保障等方面的科技成果。

（二）围绕集中连片特困地区交通扶贫，援疆、援藏，加快绿色循环低碳交通运输发展等工作部署，重点支持农村公路建设养护、农村公路安全保障、资源循环利用、生态环境保护等方面的科技成果。

（三）列入2011年度推广目录的63项科技成果《推广证书》将于2014年9月13日有效期满自动失效，成果持有单位可在此次申报工作期间再次申请列入推广目录。

**二、**申报程序

申报单位须登录西部交通建设科技项目管理中心网站（http：//www.glzx.gov.cn/）进行申报。网上申报截止时间为2014年6月30日。

网上申报成功后，将系统生成的申报书打印并加盖公章，连同相关证明材料一式三份（分别装订成册），经主管部门签署推荐意见后，于2014年7月11日前报西部交通建设科技项目管理中心（以送达时间为准），逾期将不予以受理。
