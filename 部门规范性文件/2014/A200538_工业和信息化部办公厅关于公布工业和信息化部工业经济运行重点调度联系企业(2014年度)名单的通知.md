# 工业和信息化部办公厅关于公布工业和信息化部工业经济运行重点调度联系企业(2014年度)名单的通知

## 工业和信息化部办公厅关于公布工业和信息化部工业经济运行重点调度联系企业（2014年度）名单的通知（工厅运行[2014]360号）

为做好工业经济运行监测分析工作，推动工业企业问卷调查工作深入开展，鼓励企业继续认真、及时地参与问卷填报，在企业自愿申报基础上，我部确定2012年二季度至2013年四季度连续4次以上完成有效问卷报送的2035户企业为“工业和信息化部工业经济运行重点调度联系企业（2014年度）”，其中，由省（区、市）负责组织的重点调度联系企业857家（中心城市除外），由中心城市负责组织的重点调度联系企业1178家（详见附件）。

近年来，在各省（区、市）、中心城市工业和信息化主管部门以及工业企业的大力支持下，工业企业问卷调查工作取得了积极成效，企业反映的情况为准确研判工业经济运行走势提供了重要参考支撑，工业企业问卷调查已成为分析判断经济形势、了解企业生产经营情况和诉求的重要渠道。希望各省（区、市）、各中心城市、各重点调度联系企业再接再厉，坚持不懈地做好问卷调查工作，各地参加问卷调查企业的户数应力争达到占规模以上企业户数的3-5%。

我部将完善相关制度，实行动态管理，每年审核公布一次，逐步建立重点调度联系企业退出机制，对连续多次不参与调查的重点调度联系企业进行动态调整。列入工业经济运行重点调度联系企业名单同时在我部门户网站上公布。各级工业和信息化主管部门要加大对重点联系企业的服务，协调帮助企业解决生产经营当中遇到的问题，及时向企业提供工业经济运行情况、行业运行动态及问卷调查情况，为企业发展创造良好环境，促进工业经济平稳健康发展。
