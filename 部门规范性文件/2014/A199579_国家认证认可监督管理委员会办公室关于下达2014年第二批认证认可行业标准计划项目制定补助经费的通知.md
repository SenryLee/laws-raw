# 国家认证认可监督管理委员会办公室关于下达2014年第二批认证认可行业标准计划项目制定补助经费的通知

各有关单位：

现将2014年第二批认证认可行业标准制定补助经费予以下达，并对经费使用的要求通知如下：

**一、**本次下达的经费主要用于支持2014年首批立项的认证认可行业标准制定计划项目，具体分配见附件1、2。

**二、**各单位应根据本通知要求抓紧落实经费，确保按计划完成各项标准制定任务。

**三、**请各单位收到经费后，组织项目负责人填写《认证认可行业标准制（修）订计划项目经费预算表》（以下简称《预算表》，见附件3），并将《预算表》于9月30日前反馈我委科技与标准管理部。各单位应按照上报的《预算表》使用补助经费，我委将根据项目执行进度对经费使用情况进行检查。

**四、**请各单位根据相关财务规定的要求加强经费使用管理，专款专用，并按年度上报经费使用情况和绩效报告。

**五、**联系人

国家认监委科技与标准管理部 冯增健；

电话：010-82262774，010-82260840（FAX）；
