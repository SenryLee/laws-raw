# 农业部公告第2116号――新兽药注册目录

## 农业部公告（第2116号）

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准申联生物医药（上海）有限公司等4家单位申报的猪口蹄疫O型合成肽疫苗（多肽2600＋2700＋2800）兽药产品为新兽药，现核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

批准常州同泰生物药业科技有限公司等4家单位申报的狂犬病灭活疫苗（SAD株）变更注册，并发布修订后的产品试行规程、质量标准、说明书和标签，自发布之日起执行，此前发布的同品种兽药产品质量标准同时废止。

**一、**猪口蹄疫O型合成肽疫苗（多肽2600＋2700＋2800）说明书和标签

（一）猪口蹄疫O型合成肽疫苗（多肽2600＋2700＋2800）说明书　　兽用

【兽药名称】

通用名　猪口蹄疫O型合成肽疫苗（多肽2600＋2700＋2800）

商品名　无

英文名　Swine Foot and Mouth Disease Type O Synthetic Peptide Vaccine（Peptides 2600＋2700＋2800）

汉语拼音 Zhu Koutiyi O Xing Hechengtai Yimiao（Duotai 2600＋2700＋2800）

【主要成分与含量】　含猪口蹄疫O型病毒多肽2600、2700和2800至少各25μg/ml。

【性状】　乳白色略带黏滞性乳状液。

【作用与用途】　用于预防猪O型口蹄疫。免疫期为6个月。

【用法与用量】　耳根后深层肌肉注射。每头猪接种1.0ml。首免后间隔4周再接种1次，此后每隔4～6个月加强免疫1次。

【不良反应】　个别猪注射后可能出现体温升高、减食或停食1～2日，随着时间延长，症状逐渐减轻，甚至消失。

【注意事项】　（1）本品仅用于接种健康猪。

（2）使用前应充分摇匀。

（3）本品严禁冻结，使用前应使疫苗达到室温。

（4）如出现疫苗瓶破损、含有异物或破乳分层等异常现象时，切勿使用。

（5）疫苗开启后，限当日用完。

（6）用过的疫苗瓶、器具和未用完的疫苗等应进行无害化处理。

（7）屠宰前28日内禁止使用。

【规格】　（1）50ml/瓶 （2）100ml/瓶

【包装】　（1）50ml×100瓶/箱 （2）100ml×50瓶/箱

【贮藏与有效期】　2～8℃保存，有效期为12个月。

【批准文号】

【生产企业】

仅在兽医指导下使用

**二、**狂犬病灭活疫苗（SAD株）说明书和标签

（一）狂犬病灭活疫苗（SAD株）说明书

兽用

【兽药名称】

通用名　狂犬病灭活疫苗（SAD株）

商品名　无

英文名　Rabies Vaccine， Inactivated（Strain SAD）

汉语拼音　Kuangquanbing Miehuoyimiao（SAD Zhu）

【主要成份与含量】　疫苗中含有灭活的狂犬病病毒（SAD株），每头份至少为2.0IU。

【性状】　红色混悬液，久置后，下层有易摇散的淡乳白色沉淀。

【作用与用途】　用于预防犬的狂犬病，免疫期为12个月。

【用法与用量】　适用于3月龄以上的犬，皮下或肌肉注射，每只每次1ml，建议在3月龄时进行首次免疫，疫苗首免后14日应加强免疫1次，以后每年加强免疫1次。

【不良反应】　一般无可见的不良反应。

【注意事项】　（1）本品切勿冻结。

（2）仅用于接种健康犬。

（3）本品可在妊娠期间使用。

（4）使用前应将疫苗恢复至室温（15～25℃），并充分摇匀。

（5）疫苗瓶开启后，应在3小时内用完。

（6）用过的疫苗瓶、器具和未用完的疫苗等应进行无害化处理。

【规格】　（1）1ml/瓶　（2）5ml/瓶　（3）10ml/瓶

【包装】　（1）10瓶/盒　（2）20瓶/盒　（3）50瓶/盒

【批准文号】

【贮藏与有效期】　2～8℃保存，有效期为24个月。

【生产企业】

仅在兽医指导下使用
