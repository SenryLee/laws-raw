# 农业部办公厅关于印发《利用远程教育平台开展农业专业技术人员知识更新培训2014年工作方案》的通知

## 农业部办公厅关于印发《利用远程教育平台开展农业专业技术人员知识更新培训2014年工作方案》的通知（农办人[2014]21号）

为贯彻落实《国家中长期人才发展规划纲要（2010-2020年）》和《农村实用人才和农业科技人才队伍建设中长期规划（2010-2020年）》，大力加强农业专业技术人才队伍建设，按照《2014年农业部人才工作要点》的部署，我部决定继续利用全国农业远程教育平台，大规模开展农业系统专业技术人员知识更新远程培训。现将《利用远程教育平台开展农业专业技术人员知识更新培训2014年工作方案》印发你们，请结合各地实际，细化培训方案，加强统筹协调，精心组织实施，严格管理考核，及时反馈情况，确保培训工作取得实效。

农业部办公厅

2014年4月8日
