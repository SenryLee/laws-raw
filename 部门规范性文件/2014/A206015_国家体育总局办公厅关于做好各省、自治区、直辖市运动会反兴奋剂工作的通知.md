# 国家体育总局办公厅关于做好各省、自治区、直辖市运动会反兴奋剂工作的通知

各省、自治区、直辖市、新疆生产建设兵团体育局，有关直属单位：

各省、自治区、直辖市和新疆生产建设兵团通过每4年举办运动会（以下简称省运会）展示和检验本地区体育事业发展成就， 选拔优秀体育后备人才。2014年绝大多数的省、自治区、直辖市和新疆生产建设兵团将举办省运会，省运会年也是兴奋剂问题的多发、易发年。为保护省运会参赛运动员，尤其是青少年运动员的身心健康，维护公平公正的体育精神，各单位要严格按照国务院《反兴奋剂条例》和国家体育总局有关反兴奋剂规定，依据“严令禁止、严格检查、严肃处理”的反兴奋剂方针，加强省运会反兴奋剂宣传教育，加大检查监督力度，切实做好省运会的反兴奋剂工作。现将有关要求通知如下：

**一、**切实加强对省运会反兴奋剂工作的组织领导

各省级体育行政主管部门对本行政区域内的省运会反兴奋剂工作全面负责，要加强对省运会反兴奋剂工作的组织领导，成立省运会反兴奋剂工作组织机构，建立健全反兴奋剂工作责任制，省、自治区、直辖市、新疆生产建设兵团体育局“一把手”要负总责，分管领导直接负责，将反兴奋剂作为竞赛组织工作的重要内容，有针对性制定省运会反兴奋剂工作计划和方案，并认真组织实施。

**二、**加强反兴奋剂宣传教育工作

坚持“预防为主、教育为本”的原则，开展省运会反兴奋剂教育资格准入制度活动，参加省运会决赛阶段比赛的运动员及其辅助人员必须接受反兴奋剂教育培训、通过考试、签署反兴奋剂承诺书并宣誓，经主办单位审批通过后，才能取得省运会参赛资格。具体实施办法和相关要求按照国家体育总局反兴奋剂中心规定执行。同时鼓励各主办单位结合本地区实际，采取其他生动活泼、形式多样的手段，针对参赛运动员及其辅助人员开展反兴奋剂宣传、教育和培训。

**三、**进一步加大省运会兴奋剂检查监督力度

为确保运动员干干净净参加省运会，鼓励各主办单位按照总局《关于做好委托兴奋剂检查工作的通知》（体反兴奋剂字〔2010〕106号）有关要求，在省运会备战和预决赛期间开展委托兴奋剂检查工作，省运会决赛阶段原则上必须开展兴奋剂检查，检查数量和方案由各主办单位依据项目设置、参赛人数等相关因素确定，经反兴奋剂中心批准后按照有关规定严格实施。发生兴奋剂违规行为的，应当依据国务院《反兴奋剂条例》和总局相关规定给予严肃处理，并将兴奋剂违规和处理情况及时上报总局科教司、反兴奋剂中心和有关项目中心，上述委托检查的阳性例数不计入总局对该省阳性例数的累计。

国家体育总局将开展针对省运会运动员的兴奋剂检查，各有关单位要积极配合。反兴奋剂中心要针对各省运会的特点制定有针对性的检查计划，根据需要对省运会各阶段实施赛外或比赛期间的兴奋剂检查，查出的兴奋剂违规行为将依据国务院《反兴奋剂条例》和总局相关规定给予严肃处理。

**四、**加强运动员治疗用药、营养品和食品安全的管理，严防误服误用事件的发生

各主办单位应参照《体育总局办公厅关于做好运动员肉食品安全保障工作有关事宜的通知》（体科字〔2013〕18号）和《体育总局办公厅关于进一步加强运动员肉食品、药品及营养品安全使用和管理的通知》（体科字〔2013〕123号）文件要求，采取有效措施，加强参赛运动员食品、药品及营养品安全保障工作。严格挑选供运动员使用的安全肉食品，加强运动员日常生活管理，避免食源性药源性兴奋剂问题的发生。

**五、**严格执行国务院《反兴奋剂条例》，未经批准，各主办单位不得自行开展兴奋剂检查工作，禁止任何单位非法进行兴奋剂检测，干扰正常的反兴奋剂工作。国家体育总局将对违规实施兴奋剂检查的情况进行督查，对于违规实施兴奋剂检查、检测的，体育总局将对相关单位给予通报，并对违规人员进行严肃处理。

**六、**坚决杜绝任何群体性兴奋剂违规事件的发生

省运会年易发生群体性使用兴奋剂事件，各主办单位对一些重点运动队要加强教育管理，坚决杜绝群体性兴奋剂违规事件的发生。

总局将成立由有关职能部门组成的反兴奋剂监督组，对省运会反兴奋剂工作开展全面检查监督。

请各主办单位在本通知下发之日起一个月内，将成立省运会反兴奋剂组织机构情况、反兴奋剂工作计划和工作措施以书面形式报送总局科教司，省运会结束后一个月之内上报省运会反兴奋剂工作总结（重点总结有创新性的工作措施），上述材料同时抄送反兴奋剂中心。

为进一步拓宽、畅通信访举报渠道，提倡和鼓励实名举报。
