# 人力资源社会保障部、中国人民银行关于评选中国人民银行先进集体先进工作者和劳动模范的通知

各省、自治区、直辖市人力资源社会保障厅（局），国家外汇管理局，中国人民银行上海总部，各分行、营业管理部，各省会（首府）城市中心支行，各直属企事业单位，中国银联股份有限公司、上海黄金交易所、汇达资产托管有限责任公司、中国银行间市场交易商协会、银行间市场清算所股份有限公司、中国支付清算协会：

近年来，中国人民银行系统广大干部职工坚持以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻党的十八大和十八届二中、三中全会精神，认真贯彻习近平总书记系列重要讲话精神，开拓创新，真抓实干，加强宏观调控、维护金融稳定、推进金融业改革与发展，为经济社会发展做出了积极贡献，涌现出一大批先进集体和个人。为表彰先进、树立典型，充分调动中国人民银行全系统干部职工的积极性、主动性和创造性，增强广大干部职工的进取心和荣誉感，人力资源社会保障部、中国人民银行决定，评选表彰一批中国人民银行先进集体、先进工作者和劳动模范。现将有关事项通知如下：

**一、**评选范围和表彰名额

（一）评选范围

1.“中国人民银行先进集体”评选范围：中国人民银行总行机关、上海总部内设机构各处室；国家外汇管理局内设机构各处室及直属单位内设部门；各分行、营业管理部、省会（首府）城市中心支行、副省级城市中心支行内设机构；各地市中心支行机关及内设机构；县支行；各直属企事业及相关单位内设部门（含下属单位）。

2.“中国人民银行先进工作者”和“中国人民银行劳动模范”评选范围：中国人民银行系统在职工作人员。

已经获得省部级以上先进工作者或劳动模范等荣誉称号的人员，如在近5年内做出新的突出贡献，可推荐评选。

（二）表彰及推荐名额

本次评选表彰名额为：中国人民银行先进集体32个；中国人民银行先进工作者和劳动模范共32名。

中国人民银行先进集体、先进工作者和劳动模范实行差额评选，各单位按照《中国人民银行先进集体、先进工作者和劳动模范推荐名额分配表》（见附件2）分配的名额进行推荐申报。

**二、**评选条件

（一）中国人民银行先进集体评选条件

坚持以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻党的十八大和十八届二中、三中全会精神，坚决贯彻执行党的路线、方针、政策。领导班子团结协作、作风民主、勤政务实、廉洁自律，密切联系群众，有较强的凝聚力和战斗力，干部职工有良好的职业道德和行为规范、较强的专业技能和创新能力，单位管理科学、运行规范，规章制度健全并得到较好执行。原则上须设立5年以上，近5年内无违法违纪现象，没有出现重大责任事故或造成严重不良社会影响的问题。同时，具备下列条件之一的可作为推荐对象：

1．认真履行职责，在制定和执行金融宏观调控政策、防范和化解金融风险、提高金融服务和管理水平、实施外汇管理等方面措施得力，取得显著成效。

2．持续推进金融业改革发展，工作组织实施有力度，在事关金融业改革发展的重要领域和关键环节，取得实质性突破。

3．坚持与时俱进，在深化企业改革、强化风险防控、推进产品、服务和经营模式创新等方面做出突出业绩，在本地区、本系统走在前列，具有典型示范作用。

4．在系统建设和内部管理等方面做出显著成绩。

5．在其他方面做出突出贡献。

（二）中国人民银行先进工作者和劳动模范评选条件

模范遵守国家法律法规，模范遵守社会公德、职业道德、家庭美德，爱岗敬业，无私奉献，具有较高的思想政治素质、高尚的道德品质、优良的工作作风和广泛的群众基础，模范带头作用突出。原则上须在中国人民银行系统连续工作5年以上。同时，具备下列条件之一的可作为推荐对象：

1．有较强的业务素养和专业技能，在制定和执行金融宏观调控政策、防范和化解金融风险、提高金融服务和管理水平、实施外汇管理等方面做出突出贡献。

2．有较强的创新意识和创新能力，在推进金融业改革发展的各项工作中做出突出贡献，在事关金融业发展的重要领域取得重大突破。

3．长期工作在基层服务一线或条件艰苦、工作困难的岗位，恪尽职守、勤勉奉献，在服务群众、奉献社会等方面具有典型示范作用。

4．在系统建设和内部管理等方面做出显著成绩。

5．在其他方面做出突出贡献。

**三、**评选程序和要求

（一）坚持群众路线，充分发扬民主，严格执行“两审三公示”制度。在推荐评选中，要坚持公开、公平、公正的原则，严格按照自下而上、逐级推荐、差额评选、民主择优的方式进行。严格执行“两审三公示”制度，即实行初审和复审两次审核，分别在本单位、省级范围和全国范围内进行公示。

1．按照评选条件，拟推荐对象由所在单位民主推荐，领导班子集体研究决定，并在本单位公示5个工作日。公示内容包括拟推荐对象的基本情况和主要事迹。

2．拟推荐对象经所在单位自下而上逐级审核推荐，各省级评选机构对推荐程序的规范性、推荐材料的真实性以及拟推荐对象的身份、简历、实际情况等进行审核后，提出初审推荐对象，撰写初审推荐工作报告，内容包括：本地区初审推荐工作组织情况、推荐过程、推荐对象本单位公示情况、推荐对象主要事迹等，并在规定时间内，将初审推荐工作报告等推荐材料报送评选表彰工作领导小组办公室。

其中，在京直属企事业及相关单位由中国人民银行机关党委统一负责推荐评选工作；京外直属企事业及相关单位由推荐单位直接向评选表彰工作领导小组办公室推荐。

3．评选表彰工作领导小组办公室对推荐材料进行初审，提出正式推荐对象候选名单，报评选表彰工作领导小组审定后，反馈各省级评选机构。各省级评选机构以适当形式在本地区范围内对正式推荐对象进行公示，公示内容包括推荐单位名称、个人姓名和简要事迹，公示时间为5个工作日。公示无异议后报送复审推荐材料。

直属企事业及相关单位参照省级评选机构要求进行公示并报送正式材料。

4．评选表彰工作领导小组对推荐对象进行复审，确定拟表彰对象，并在全系统范围内公示5个工作日。根据公示情况，确定正式表彰对象。

（二）坚持评选条件，确保评选质量。各单位要严格按照评选推荐条件开展评选工作，认真做好把关工作，对推荐程序的规范性、推荐材料的真实性切实负起责任。要坚持以政治表现、工作实绩作为衡量标准，优中选优，推荐的先进集体和个人要有突出的事迹，确保先进性、典型性和代表性，严格杜绝带“病”表彰。

推荐对象是企业（指具有法人资格的企业）、社团（指具有法人资格的社会团体）或企业、社团负责人的，须按照管理权限征求当地县以上纪检（监察）、审计、工商、税务（国税、地税）、环境保护、人力资源社会保障、安全生产、计划生育等部门意见，其中社团或社团负责人还须征求民政部门意见（附件7、附件9）。

先进工作者和劳动模范推荐对象均须征求计划生育部门意见，先进工作者推荐对象还须按照干部管理权限，征求有关纪检监察、干部管理等部门意见（附件8）。

凡有违反国家政策、法规，发生较大事故，或存有严重职业危害，拖欠职工工资，欠缴职工养老、工伤、医疗、失业、生育保险行为的单位，该单位及其负责人不能参加推荐评选。

（三）坚持面向基层和工作一线。严格评选条件，重点向长期在条件艰苦、工作困难地方工作的同志倾斜。先进工作者评选中处级干部比例控制在总数的20%以内，副厅局级或相当于副厅局级及以上单位和个人不参加评选。劳动模范评选中一线工作人员比例不低于60%，企业负责人（指具有法人资格的企业及其下属企业的董事长、党委书记、总经理、经理，下同）和社团负责人（指具有法人资格的社会团体的会长、秘书长，下同）的比例控制在劳动模范总数的10%以内。在单位担任领导职务、具有高级职称并继续从事教学、科研等方面工作，做出特殊贡献的专家和学术带头人，可以按科研人员对待参加评选。

（四）严肃评选工作纪律。各评选机构要严格纪律，加强监管，确保平等参选，杜绝“带帽推荐”。对未严格按照评选条件和规定程序推荐的单位和个人，经查实后撤销其评选资格，并取消该单位或地区参加下一届评选表彰活动的资格。对在授予荣誉称号工作中有严重失职、渎职或弄虚作假、借机谋取私利、收受贿赂等违法违纪行为的人员，按照有关规定予以严肃处理。

（五）按时报送评选材料。各评选机构和参评单位要严格履行规定程序，按时、保质、按名额报送推荐对象有关材料，确保工作进度，过时不报视为放弃。

各省级评选机构于2014年10月30日前报送初审材料。初审材料包括：评选推荐工作报告、《中国人民银行先进集体初审推荐登记表》（附件3）、《中国人民银行先进工作者和劳动模范初审推荐登记表》（附件4）、《推荐对象汇总表》（附件10）、推荐对象基本情况和主要事迹。其中，基本情况和主要事迹要内容准确、业绩突出，先进集体、先进工作者和劳动模范推荐登记表内事迹简介字数在300字左右，另附详实事迹材料，字数控制在2000字以内。

各省级评选机构于2014年11月30日前报送正式推荐材料。正式推荐材料包括：正式推荐工作报告、《中国人民银行先进集体推荐审批表》（附件5）、《中国人民银行先进工作者和劳动模范推荐审批表》（附件6）、《企业和社团征求意见表》（附件7）、《先进个人征求意见表》（附件8）、《企业和社团负责人征求意见表》（附件9）。其中先进事迹材料主要包括工作实绩、社会效益、经济效益和突出事迹参与程度等，字数控制在2000字以内。推荐的先进集体需附6寸反映本单位工作的不同内容彩色照片8张，推荐的先进个人需附2寸免冠红底彩色近照5张、5寸免冠彩色近照1张，并在照片背面注明单位、姓名。

初审材料以电子版形式报送，正式推荐材料及照片请同时报送电子版和纸质版。纸质版用A4纸，一式5份。要严格按照填表说明填写相关表格，不得随意改变格式。表格电子版可在中国人民银行网站（http：//www.pbc.gov.cn/）下载。

**四、**奖励办法

坚持精神奖励和物质奖励相结合，以精神奖励为主的原则，对评选出的先进集体授予“中国人民银行先进集体”荣誉称号，颁发奖牌和证书；对评选出的先进个人，分别按规定授予“中国人民银行先进工作者”、“中国人民银行劳动模范”荣誉称号，颁发奖章和证书，享受省部级先进工作者和劳动模范待遇。

**五、**组织领导

人力资源社会保障部、中国人民银行联合成立中国人民银行先进集体、先进工作者和劳动模范评选表彰工作领导小组（见附件1），负责评选表彰工作的组织领导和评审工作。领导小组下设办公室，设在中国人民银行人事司，负责评选表彰的日常工作。各地可成立相应的组织机构，加强领导，精心组织，密切配合，做好本地区先进集体和个人的推荐评选工作。为保证评选工作顺利进行，请各省级评选机构确定1至2名联系人，于2014年9月30日前，将联系人名单及联系电话报中国人民银行人事司。

各地在做好本次评选表彰推荐工作的同时，要结合本地区实际情况，加强对先进典型事迹的宣传，强化激励导向，使评选表彰工作更好地为推进人民银行事业科学发展服务。
