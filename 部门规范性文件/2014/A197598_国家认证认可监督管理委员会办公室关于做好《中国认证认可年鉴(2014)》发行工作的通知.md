# 国家认证认可监督管理委员会办公室关于做好《中国认证认可年鉴(2014)》发行工作的通知

## 国家认证认可监督管理委员会办公室关于做好《中国认证认可年鉴（2014）》发行工作的通知

各直属出入境检验检疫局，各省、自治区、直辖市及新疆生产建设兵团质量技术监督局，各检验检测认证从业机构，各部室、下属单位：

《中国认证认可年鉴（2014）》（以下简称《年鉴（2014）》）在各方的积极参与和热心支持下，已按既定计划出版。为做好相关发行工作，现将有关事项通知如下：

**一、**《年鉴（2014）》由国家认监委主编，国务院有关部委、各地质检部门、广大认证认可从业机构和企事业单位共同参与撰写。该年鉴系统、翔实地记述了我国认证认可工作的最新情况、最新经验及最新成就，充分展现了认证认可行业的业绩和风采，弘扬了认证认可的核心价值观；同时汇集了认证认可工作发展的最新数据，全面收集了我国认证认可的法律法规、工作信息、发展动态等相关资料，是全面了解认证认可工作的普及性读物、认证认可监督管理及从业人员的必备工具书、企事业单位开展认证认可工作的权威指南。请各单位高度重视，认真组织做好宣传推荐工作，保证《年鉴（2014）》的顺利发行。

**二、**为保证各有关方面全面、准确、完整地了解认证认可工作情况，建议各单位将《年鉴（2014）》重点配发给认证认可和检验检测工作的主管领导、业务部门、科研机构和从业人员，充分发挥利用好该年鉴的信息资源和工作参考价值。

**三、**请各地质检两局和各相关机构及时组织订阅，并向本地区相关单位和获证组织做好宣传发行工作，有条件的地区可以统一组织订购。
