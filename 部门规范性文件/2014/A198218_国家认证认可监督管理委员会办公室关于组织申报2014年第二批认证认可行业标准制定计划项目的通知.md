# 国家认证认可监督管理委员会办公室关于组织申报2014年第二批认证认可行业标准制定计划项目的通知

各有关单位：

为充分发挥标准对认证认可工作的支撑保障作用，在充分调研需求的基础上，我委研究确定了《2014年第二批认证认可行业标准制定计划项目申报范围》（以下简称《申报范围》，见附件1）。现就组织申报工作有关事项通知如下：

**一、**制标范围

本批《申报范围》重点关注服务认证领域。

**二、**申报要求

1.本次申报的项目限定在《申报范围》之内，《申报范围》以外的项目，本次申报暂不予受理。

2.项目申报单位应具备完成标准项目所需的技术力量，并在人、财、物等方面提供必要的支持。

3.申报的项目应在1-2年内完成起草工作。

**三、**材料报送要求

1.申报单位请填写《认证认可行业标准制定项目计划建议书》（每个项目填写一份，见附件2）和《认证认可行业标准计划项目申报汇总表》（一个单位填写1份，见附件3）。如有成熟的标准草案或草案框架请一并上报。

2.各单位应于2014年10月31日前以公文形式将正式材料寄送联系人，同时发送电子文本至联系人邮箱。
