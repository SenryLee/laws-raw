# 国家体育总局科教司关于召开国家科技支撑计划项目“我国冬奥会重点项目取得突破的关键技术研究与应用”课题验收会的通知

各课题承担单位，课题负责人、有关专家：

受科技部社发司、条财司委托，我司决定组织召开国家科技支撑计划项目“我国冬奥会重点项目取得突破的关键技术研究与应用”课题验收会。现将有关事宜通知如下：

**一、**会议时间、地点

（一）时间：2014年8月7-8号（周四、五）8：30-17：00。

（二）地点：国家奥林匹克体育中心运动员公寓（北京市朝阳区安定路1号）。

**二、**会议安排

（一）科技部社发司、总局科教司有关领导讲话。

（二）项目组组长讲话。

（三）课题验收专家组组长主持验收会。

1.课题组汇报课题执行情况（30分钟）；

2.专家组提问、质询（20分钟）；

3.专家组形成课题验收意见（20分钟）。

**三、**有关要求

（一）请有关单位、课题负责人高度重视课题验收工作，做好相关准备工作，课题负责人必须到会汇报。

（二）课题组从课题的目标任务、研究工作情况、取得的科研成果及在实践中应用所取得的效益、经费使用情况等方面进行汇报，准备投影，课题验收材料15份（正反面打印），财务验收材料3份（含审计报告原件、财务验收申请报告、相关票据复印件等）以及草拟专家验收意见1份（电子版）带到会场。

（三）课题验收会结束后将对整改工作和项目验收工作进行部署，请各课题组参会人员全程参会。

（四）参会人员交通自理，餐费及京外代表住宿费由会议负担。

（五）京外参会人员于8月6日20：00前到奥体中心报到。请各课题组务必于7月31日16：00前将参会人员信息传真至科教司科技处。
