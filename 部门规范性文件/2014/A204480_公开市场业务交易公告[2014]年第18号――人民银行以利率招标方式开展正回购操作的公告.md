# 公开市场业务交易公告[2014]年第18号――人民银行以利率招标方式开展正回购操作的公告

## 公开市场业务交易公告（[2014]年第18号）

人民银行于本周二（4月8日）以利率招标方式开展了正回购操作。具体情况如下：

正回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 14天 | 470亿元 | 3.80% |
| 28天 | 160亿元 | 4.00% |

中国人民银行公开市场业务操作室

二〇一四年四月八日
