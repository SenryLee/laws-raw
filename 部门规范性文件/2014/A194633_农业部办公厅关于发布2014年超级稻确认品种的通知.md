# 农业部办公厅关于发布2014年超级稻确认品种的通知

## 农业部办公厅关于发布2014年超级稻确认品种的通知（农办科[2014]12号）

各省（区、市）农业厅（委、局），有关单位：

为加强超级稻示范推广工作，根据农业部《超级稻品种确认办法》（农办科〔2008〕38号），在各地申报和专家评审的基础上，我部新确认“龙粳39”“莲稻1号”等18个品种为2014年农业部超级稻品种（见附件）。同时，根据超级稻品种退出规定，决定取消推广面积达不到要求的“协优9308”“武粳15”“龙稻5号”“宁粳1号”“新稻18号”“新丰优22”“培两优3076”“准两优1141”等8个品种超级稻品种资格，不再冠名“超级稻”。截至目前，由我部冠名的超级稻示范推广品种共111个。请各地农业部门按照有关要求，认真做好2014年超级稻示范推广工作。
