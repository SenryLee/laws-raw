# 国家质量监督检验检疫总局直属机关团委关于命名表彰“2013―2014年度质检总局直属机关青年文明号”的决定

## 国家质量监督检验检疫总局直属机关团委关于命名表彰“2013-2014年度质检总局直属机关青年文明号”的决定

2013年，各单位团组织以邓小平理论、“三个代表”重要思想、科学发展观为指导，认真贯彻落实党的十八大、十八届三中全会和习近平总书记系列讲话精神，坚持党建带团建的原则，坚持围绕质检中心工作、服务质检改革大局，全面深化青年文明号创建活动，涌现出一批优秀青年集体，为树立刚正廉明的依法行政形象、科学权威的技术执法形象、可亲可信的人民质检形象作出了表率。

为表彰先进，树立榜样，激励更多的青年投身青年文明号活动，进一步促进总局直属机关青年文明号创建工作可持续发展，经严格评选并报总局直属机关党委审定，总局直属机关团委决定命名中国特种设备检测研究院压力容器事业部等5个青年集体为“2013-2014年度质检总局直属机关青年文明号”。

希望受表彰的青年集体珍惜荣誉，谦虚谨慎，再接再厉，扎实工作，不断取得新的成绩，为继续深化总局直属机关青年文明号活动做出更大的贡献。各争创集体要以先进为榜样，立足岗位，扎实工作，积极进取，以改革创新的精神抓质量、保安全、促发展、强质检，为加快转变经济发展方式，加快提质增效升级，促进经济持续健康发展作出新的贡献。
