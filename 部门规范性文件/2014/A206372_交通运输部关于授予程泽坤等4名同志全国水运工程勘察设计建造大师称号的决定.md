# 交通运输部关于授予程泽坤等4名同志全国水运工程勘察设计建造大师称号的决定

交通运输部关于授予程泽坤等4名同志全国水运工程勘察设计建造大师称号的决定

各省、自治区、直辖市交通运输厅（局、委），天津市、上海市交通运输和港口管理局，有关企事业单位：

根据《交通运输部关于印发＜全国水运工程勘察设计建造大师选拔办法＞并开展选拔工作的通知》（交水发〔2013〕434号）要求，经选拔，决定授予程泽坤等同志“全国水运工程勘察设计建造大师”称号。名单如下：

（一）全国水运工程勘察设计大师：

程泽坤 男 中交第三航务工程勘察设计院有限公司

周 海 男 中交上海航道勘察设计研究院有限公司

（二）全国水运工程建造大师：

李一勇 男 中交第一航务工程局有限公司

曹根祥 男 中交第三航务工程局有限公司

希望以上同志再接再厉，与时俱进，再创佳绩，为我国水运建设事业发展做出新的更大贡献。

交通运输部

2014年2月17日
