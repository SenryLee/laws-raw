# 工业和信息化部信息化推进司关于公开征集2014年信息化和工业化融合管理体系贯标服务机构的通知

各有关单位：

按照《信息化和工业化深度融合专项行动计划（2013-2018年）》（工信部信〔2013〕317号）工作部署和要求，我部组织编制并发布了《信息化和工业化融合管理体系 要求（试行）》（工业和信息化部公告2014年第3号），2014年将在全国500家企业开展贯标试点工作，选择和支持一批服务机构为试点企业贯标提供咨询服务，建立和完善认定服务体系，2014年底前完成200家企业的达标认定。现公开征集贯标服务机构，有关事项通知如下：

**一、**服务机构推荐条件

（一）中华人民共和国境内注册的企事业单位，财务状况和运营情况良好。

（二）具有从事专业咨询服务的团队和能力。

（三）具有企业信息化等两化融合相关咨询服务经验。

**二、**工作程序及要求

（一）请申报服务机构于2014年2月28日前将申请材料（见附件）纸质版（一式两份）报送工业和信息化部（信息化推进司），电子版（可无公章）统一发送到指定电子邮箱（见联系人电子邮件）。超过规定时限不予受理。

（二）申报服务机构在工业和信息化部门户网站（www.miit.gov.cn）下载申请材料格式的电子文档。

（三）申报服务机构应自愿分享试点工作经验和贯标案例。

（四）我部将组织专家对申请材料进行评审，会同部内有关司局审查后，遴选一批服务机构参加培训，考核达标后公布首批服务机构名单。
