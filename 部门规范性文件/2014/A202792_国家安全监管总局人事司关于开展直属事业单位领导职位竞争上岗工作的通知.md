# 国家安全监管总局人事司关于开展直属事业单位领导职位竞争上岗工作的通知

国家安全监管总局人事司关于开展直属事业单位领导职位竞争上岗工作的通知

（人事函〔2014〕74号）

各省级煤矿安全监察局，总局和煤矿安监局机关各司局、应急指挥中心，各直属事业单位：

为贯彻落实国家安全监管总局（以下简称总局）党组关于通过竞争上岗方式选拔部分领导干部的决定，根据《党政领导干部选拔任用工作条例》、《党政机关竞争上岗工作暂行规定》、《中共国家安全监管总局党组选拔任用干部工作办法》和有关法律、法规，现就部分直属事业单位领导干部竞争上岗工作有关事项通知如下：

**一、**竞争上岗职位

中国安全生产报社（中国煤炭报社）和华北科技学院（中国煤矿安全技术培训中心）党委副书记兼纪委书记各1名，中国煤矿工人大连疗养院（总局大连职业病防治康复中心）党委书记1名。

**二、**竞争上岗原则

竞争上岗工作坚持党管干部原则，坚持五湖四海、任人唯贤，坚持德才兼备、以德为先，坚持注重实绩、群众公认，全面准确贯彻民主公开竞争择优方针，坚持考试与考察相结合，坚持人岗相适。

**三、**报名条件

（一）基本条件。

具备《党政领导干部选拔任用工作条例》规定的六项基本条件和七项任职资格；有较高的政治素质和政策理论水平，具备履行岗位职责所需的能力素质；实绩突出，群众公认，勤奋敬业，作风过硬，廉洁自律。

应当具有5年以上工龄和2年以上基层工作经历，一般应当具有在下一级两个以上职位任职的经历，具有大学本科以上文化程度，身体健康，有5年以上党龄。

（二）职位条件。

中国安全生产报社（中国煤炭报社）和华北科技学院（中国煤矿安全技术培训中心）党委副书记兼纪委书记职位：应当为现任副司局级干部或在正处长岗位工作三年以上的干部。熟悉党务和纪检监察工作，有较强的组织协调和语言、文字表达能力；具有较强的开拓创新意识，坚持原则，敢于负责，公道正派。

中国煤矿工人大连疗养院（总局大连职业病防治康复中心）党委书记职位：应当为现任副司局级干部或在正处长岗位工作三年以上的干部；熟悉党的路线方针政策和法规，熟悉基层党组织建设和党务工作，有较强组织领导和语言、文字表达能力。具有较强的大局意识、责任意识、开拓创新意识，坚持原则，敢于担当，公道正派。

**四、**报名范围

中国安全生产报社（中国煤炭报社）和华北科技学院（中国煤矿安全技术培训中心）党委副书记兼纪委书记报名范围是：总局和煤矿安监局机关、应急指挥中心以及总局在京直属事业单位符合条件的人员。

中国煤矿工人大连疗养院（总局大连职业病防治康复中心）党委书记报名范围是：总局和煤矿安监局机关、应急指挥中心、总局各直属事业单位、各省级煤矿安监局及其所属事业单位符合条件的人员。

**五、**报名方法

（一）报名时间。2014年5月23日至5月27日。

（二）报名方式。报名人员从总局网站下载报名表，填写后连同2张本人近期二寸免冠正面同底彩色照片，报人事司干部一处。报名人员应对提交材料的真实性负责。凡弄虚作假者，一经查实，即取消考试资格或任用资格。

本通知未尽事宜，请直接向人事司咨询，联系电话：010－64463267、64463315（带传真）。

填表说明：

“出生年月（岁）”栏中填写出生年月和年龄。年龄为计算到报名时间的实足年龄。

“籍贯”和“出生地”按现在的行政区划分填写，要填写省市或县的名称，如“辽宁大连”、“河北盐山”。直辖市就直接填写市名，如“上海”、“重庆”等。

“入党时间”栏填写加入中共的时间。民主党派成员需在“入党时间”栏内注明民主党派名称，如“民建”、“九三”等，不填写加入民主党派的时间，加入多个民主党派的，须如实填写，如“民建”、“民盟”。是民主党派成员又是中共党员的，在填写党派名称的同时，还要填写加入中共的时间。

“出生年月”、“入党时间”、“参加工作时间”要如实填写，填写时，年份一律用4位数字表示，月份一律用2位数字表示，如“1972.05”。

“健康状况”根据本人的具体情况填写“健康”、“一般”或“较差”；有严重疾病、慢性疾病或身体伤残的，要如实简要填写。

“专业技术职务”栏中，填写主管部门评定的中级以上专业技术职务。

“熟悉专业有何特长”栏中填写干部所熟悉的工作业务及专长。

“学历学位”栏分为全日制教育和在职教育两类。填写的具体要求是：

（1）“学历”应填写接受相应教育的最高学历。各类成人高等院校毕业生，应以国家教育行政部门和经其认可的部门、单位出具的学历证明为依据；接受党校教育的，以各级党校出具的学历证明为依据。

（2）“全日制教育”栏填写通过全日制教育获得的最高学历；“在职教育”栏填写以其他学习方式获得的最高学历。“毕业院校系及专业”栏填写与学历相对应的毕业院校、系和专业。

（3）在党校学习获得学历的情况分为两类：一类是国民教育学历，其中：通过全日制教育获得的，填入“全日制教育”栏；通过在职学习获得的，填入“在职教育”栏。另一类是党校学历，均填入“在职教育”栏，并在研究生、大学或大专学历前加“中央党校”或“省（区、市）委党校”。

（4）1970-1977年恢复高考制度以前入学的高等院校毕业生，填写“大学普通班”学历。

（5）接受学历教育“结业”或“肄业”的，应予注明，如：大学结业、研究生肄业等。

（6）高中及以下学历，毕业院校系及专业栏不填写。

（7）获得学历同时也获得学位的，应同时填写，并写明何学科学位。如，通过全日制教育获得了大学本科学历、理学学士学位，就在“全日制教育”栏中填写“大学理学学士"（在一栏中分两行填写，见下表）。

（9）以上学历、学位中，涉及国民教育学历、学位，需有国家教育行政部门承认的学历证书、国务院授权的高校或科研机构颁发的学位证书以及按规定应进入个人档案的相关材料；涉及国外学习取得的学历、学位，按其培养规格、学习年限、学业成绩或学分，比照我国高等教育相应层次的培养要求，由国家教育行政部门认证；涉及党校学历需有党校颁发的学历证书以及按规定应进入个人档案的相关材料。

“现任职务及任职时间”栏中填写干部担任的主要职务，如：“XX司XX处处长”。任职时间以本次担任职务时间为准，并具体到XXXX年XX月。

“职级及职级时间”栏中填写与现任职务对应的职级，职级时间为担任同职级最早职务时间。

“报名竞争职位”栏中填写选定的本次竞争上岗3个职位中的一个，不得多报。

“是否服从调剂”栏中填写“是”或“否”。

“简历”从参加工作时填起，大、中专院校学习毕业后参加工作的，从大、中专院校学习时填起。简历的起止时间填到月（年份用4位数字表示，月份用2位数字表示），前后要衔接，不得空断（因病休学、休养、待分配等都要如实填写）。

“奖惩情况”栏，填写受省、部级以上的奖励和记功；受处分的，要填写何年何月因何问题经何单位批准受何种处分，何年何月经何单位批准撤销何种处分。没有受过奖励和处分的，要填“无”。

“近三年年度考核结果”栏中填写2011、2012、2013年的年度考核情况，没有年度考核结果的，应采取写实的办法注明。

“家庭主要成员及重要社会关系”栏，主要填写干部本人的配偶、子女和父母的有关情况。已去世的，应在原工作单位及职务后加括号注明。称谓、姓名、出生年月、政治面貌、工作单位及职务要填写准确。称谓的写法要规范：配偶为妻子、丈夫，子女为儿子、女儿，多子女为长子、次子、三子、长女、次女、三女等，父母为父亲、母亲。干部的配偶及子女有在国（境）外学习、工作、定居和在中外合资或外资企业工作的，其所在院校、定居地点、工作单位及职务，应如实填写。家庭主要成员及重要社会关系要填写填表时的真实情况。

“自我评价”栏由报名者对个人基本素质、能力水平、民主作风、工作作风、思想作风等方面进行评价，客观分析自己有哪些优点，存在哪些不足。要写明自己熟悉的业务，对哪些领域的问题有研究，取得的研究成果，如发表论文、获奖及出版专著等情况。可另附纸。

“本单位审核意见”栏中应填写本单位对干部简历核实情况和是否同意报名的意见，并加盖印章。

“资格审查意见”栏由人事司对报名干部资格审查后填写。
