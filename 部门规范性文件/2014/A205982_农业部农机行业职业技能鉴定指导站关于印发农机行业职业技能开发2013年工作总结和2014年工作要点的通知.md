# 农业部农机行业职业技能鉴定指导站关于印发农机行业职业技能开发2013年工作总结和2014年工作要点的通知

## 农业部农机行业职业技能鉴定指导站关于印发农机行业职业技能开发2013年工作总结和2014年工作要点的通知（农机职鉴[2014]1号）

各农机职业技能鉴定站：

现将《农机行业职业技能开发2013年工作总结和2014年工作要点》印发给你们，请结合实际，及早谋划，抓好落实。

附件：2013年工作总结和2014年工作要点

农业部农机行业职业技能鉴定指导站

2014年2月26日

附件

2013年工作总结和2014年工作要点

在上级主管机构的支持、指导下，在各级农机职业技能培训鉴定机构的大力配合下，农机行业职业技能开发工作持续稳定发展。

**一、**2013年主要工作和成效

（一）以稳步增长为目标，推进工作落实

部指导站及早谋划，年初下发了《2013年农机行业职业技能开发工作要点》。各省结合实际，以会议或文件形式，布置全年工作，并落实实施。为加强工作交流，部指导站印发两期鉴定信息，并于10月份组织召开农机职业技能培训鉴定工作座谈会，宣传先进经验，寻找工作创新点，研讨新形势下农机职业技能开发的重点和发展方向。2013年度全行业共完成农机技能人才培训鉴定10.1万人次，其中高级工以上人才比例占3.7%。

（二）以市场需求为导向，拓展开发范围

2013年，农业部组织5期农机维修高技能人才和师资培训班，举办一期农机合作社理事长培训班，示范带动全国农机高技能人才培养和新型职业农民培训。江苏和浙江举办了全省的农机职业技能竞赛，选拔高技能人才；黑龙江、吉林、辽宁、上海、广东、贵州等地以农机维修网点和农机生产、经销企业维修人员为重点，加强农机修理工职业准入；天津面向农业产前、产中和产后服务，积极开拓农机操作工、挖掘机驾驶员等新工种培训鉴定；山东、山西、安徽、四川等多地开展了农机合作社理事长培训，加强新型社会化服务主体培育和经理人培养。

（三）以基地创建为契机，加快体系建设

2013年1月，农业部公布首批103家全国农机职业技能培训和鉴定示范基地，促进了各地加快完善职业技能开发体系建设的步伐。海南省提交了农机职业技能鉴定站建站材料；河南省确认了第二批省级培训鉴定基地13个；安徽省批复成立宿州市鉴定分站，实现职业技能鉴定在全省17个市的全面覆盖；新疆在塔城、和田等地成立地区鉴定站；湖南省充分整合资源，新建立了3个省级培训鉴定基地。

（四）以规范培训鉴定为核心，强化组织管理

为规范质量管理，部指导站与各省农机职业技能鉴定站签订质量管理责任书，2013年质量工作重点是严格执行鉴定试卷提取和严格审查鉴定报告流程，做到了开展鉴定的省级鉴定站试卷提取率100%，上报材料无遗漏。重庆、辽宁、黑龙江等多地建立完善工作制度，狠抓工作质量。江苏省通过严格程序、加强业务指导、培训质量督导员等手段，保证了全年2250万“获证奖补”资金的安全使用。

（五）以夯实基础为重点，提升开发能力

2013年第四批职业技能鉴定体系建设项目开始实施，农机行业9家单位获近400万元设备补贴，整体培训鉴定能力进一步提升。2013年举办全国农机职业技能鉴定考评员培训班3期和1期复训班，共培养考评员887名，提升了工作队伍能力素质。指导站组织开发《水稻插秧机操作工》培训教材和修订《农机修理工》鉴定试题库，江苏省组织修订《联合收割机驾驶员》教材，增强了培训鉴定技术支撑。

**二、**2014年工作思路和重点工作

2014年，农机职业技能开发继续围绕农业、农机化中心工作，深入贯彻落实科学发展观和人才强农战略，以建设高素质新型职业农民队伍为目标，不断规范管理，创新机制，提升能力，保障质量，切实为农机化发展和农业现代化建设提供人才支撑和智力保障。

（一）加强研究，推进农机化高技能人才能力提升示范

根据部司任务安排，继续承办好3-4期 “政企联动”农机维修高技能人才及师资培训班，研究高级工以上维修人才的技能成长途径，确立大中型拖拉机、联合收割机、水稻插秧机等主要农业机械的高技能维修示范培训大纲，探索技师和高级技师等高技能人才的科学鉴定考评方案。结合行业与地方实际，推进各地开展“校企联合”、“政企联动”、“企社共建”等多种形式的高技能人才培养工作。配合各地需求，指导办好各类农机技能竞赛工作。

（二）加强指导，推进农机化重点人群技能开发

引导各地开展多形式多层次的农机技能培训鉴定工作，努力实现全年培训鉴定发证8万人次。以农机大户、合作社机手为重点，培养造就一大批既精通农机驾驶、维修技术，又掌握农艺栽培技术的新型职业农民。以农机经销服务企业和维修网点修理工为重点，落实职业准入，提升维修服务能力。以合作社理事长为重点，开展经理人培训鉴定，培育新型农机社会化服务主体。围绕设施种植、养殖机械化，加强设施农业装备操作工等新职业的技能开发，推进全程、全面机械化人才先行。

（三） 加强管理，推进培训和鉴定基地规范化建设

积极开展全国农机职业技能培训和鉴定示范基地创建活动，做好已有示范基地的创建经验总结和调研，了解各基地的条件、教具课件使用和管理制度规范等情况，加强基地业务指导和规范化管理。组织开展农机职业技能培训鉴定通用教具、设备和课件的选型推荐，组织第二批全国农机职业技能培训和鉴定示范基地申报与评审，发布教具设备选型结果和第二批示范基地名单。

（四）加强培训，推进考评员等工作队伍能力提升

组织举办3-4期农机职业技能鉴定考评员培训或复训班，培训内容围绕规范工作流程、端正考评行为、严格质量管理等核心，坚持结合典型案例讲授考评技术与技巧的有效方式，增加新政策解读和新形势分析，加强经验交流和工作研讨，切实提高培训的针对性和实用性，保证培训质量和效果。继续加强考评员、督导员等资格管理与换证，加强指导师资与教练员的知识更新培训，鼓励土专家和老技师等加入师资队伍，持续提升职业技能开发工作队伍能力。
