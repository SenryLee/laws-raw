# 财政部关于开展2014年下半年北京地区宣传文化单位增值税先征后退审核工作时间安排及有关事项的通知

各相关退税单位：

为进一步规范宣传文化单位增值税先征后退审批工作，现就2014年下半年退税申报有关事项通知如下：

**一、**本年报送的退税资料，在财政部北京专员办《一般增值税先征后退操作规程》（财驻京监[2010]137号）要求资料内容基础上，增加了部分资料并调整了相关表格，具体内容详见《在京宣传文化增值税先征后退工作操作指南》（2014年修订）。

**二、**按照下表指定时间安排办理退税

|  |  |
| --- | --- |
| 区县 | 出版社、报社、杂志社 |
| 海淀区 | 9月16日开始第1、2个工作日（单位名称第一个字以拼音“z”打头的单位） |
| 9月16日开始第3、4个工作日（上述单位以外的单位） |
| 朝阳区 | 9月16日开始第5、6个工作日（单位名称第一个字以拼音“z”打头的单位） |

**三、**当月申报的退税资料不合格的一律退回。需重新申报的，相关单位必须在5个工作日内进行重新申报，以保证退税工作效率。
