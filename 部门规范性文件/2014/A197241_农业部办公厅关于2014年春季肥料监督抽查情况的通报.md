# 农业部办公厅关于2014年春季肥料监督抽查情况的通报

## 农业部办公厅关于2014年春季肥料监督抽查情况的通报（农办农〔2014〕25号）

根据《农业部办公厅关于开展2014年春季肥料监督抽查工作的通知》（农办农〔2014〕6号），今年3月至5月，我部组织6家部级肥料质检中心，对河北等12个省（区）的全国农企合作推广配方肥企业和农资市场肥料产品进行了监督抽查。现将监督抽查结果通报如下。

**一、**基本情况

此次监督抽查由农业部种植业管理司、全国农业技术推广服务中心组织，农业部肥料质量监督检验测试中心（石家庄）、农业部肥料质量监督检验测试中心（沈阳）、农业部肥料质量监督检验测试中心（郑州）、农业部肥料质量监督检验测试中心（杭州）、农业部肥料质量监督检验测试中心（广州）和农业部肥料质量监督检验测试中心（成都）等6家部级质检中心负责实施。在河北、内蒙古、辽宁、吉林、黑龙江、江苏、安徽、江西、山东、河南、湖北和湖南等12个省（区）共计抽取复混肥料（复合肥料）、掺混肥料（BB肥）样品158个，涉及肥料生产企业112家、肥料经销企业（个体商户）76家。

**二、**抽查结果

（一）总体情况。此次抽查的158个肥料样品中，检验结果合格的142个，合格率为89.9%。其中，复混肥料（复合肥料）样品122个，检验结果合格的109个，合格率为89.3%；掺混肥料（BB肥）样品36个，检验结果合格的33个，合格率为91.7%。

（二）全国农企合作推广配方肥企业抽查情况。此次抽查全国农企合作推广配方肥企业33家，其中31家企业的样品抽查结果为合格，合格率为93.9%；抽查样品62个，合格率95.2%。

（三）农资市场抽查情况。此次抽查农资市场48个，涉及76家肥料经销单位。其中，63家肥料经销单位的样品抽查结果为合格，抽查合格率为82.9%；抽查样品96个，合格率86.5%。

**三、**主要问题

此次监督抽查发现的不合格产品主要是单一养分或总养分含量不足。其中，氮含量不足的样品5个，占不合格样品数的31.3%；磷含量不足的样品2个，占不合格样品数的12.5%；钾含量不足的样品8个，占不合格样品数的50%；总养分含量不足的样品9个，占不合格样品数的56.3%。不合格产品名单详见附件。

**四、**处理意见

（一）进一步核查不合格产品。各地农业行政主管部门要加强对本次抽查不合格肥料生产企业和经销商监督检查，及时纠正违法行为，防止给农业生产造成更大损失。

（二）督促企业落实整改措施。各有关省（区）农业行政主管部门要依法对存在问题的生产者、经营者进行处理。对产品质量不合格的，要督促企业加强管理，切实提高质量。对产品不合格的农企合作推广配方肥企业，要责令其限期整改，整改不力的，取消其农企合作推广配方肥企业资格。请有关省（区）农业行政主管部门于7月31日前将企业整改情况报我部种植业管理司。

（三）确保农民生产用肥安全。各级农业行政主管部门要会同工商、质量监督等部门，切实做好重点时期、重点品种、重点区域和重点市场的肥料监督抽查，营造全社会共同打击假冒伪劣肥料的氛围，净化肥料市场秩序，维护农民群众和合法企业利益。要加强对农企合作推广配方肥企业和国家财政补贴项目所用肥料中标企业的监督管理，实施严格的质量追溯和全程监管。
