# 国家测绘地理信息局机关工会关于印发局机关工会2013年工作总结及2014年工作要点的通知

## 国家测绘地理信息局机关工会关于印发局机关工会2013年工作总结及2014年工作要点的通知（测机工〔2014〕1号）

各工会小组：

现将《国家测绘地理信息局机关工会2013年工作总结及2014年工作要点》印发给你们，请结合各单位实际，认真做好各项工作。

国家测绘地理信息局机关工会

2014年2月24日

局机关工会2013年工作总结及2014年工作要点

**一、**2013年主要工作情况

2013年，在直属机关党委的领导支持下，在全体工会委员的共同努力下，机关工会围绕中心，服务大局，较好地完成了各项工作任务。

（一）突出重点、服务大局，为事业发展提供正能量

开展“光盘行动”的倡议活动。积极响应党中央厉行勤俭节约、反对奢侈浪费的号召，机关工会向在中国测绘创新基地工作和就餐的干部职工发出开展“光盘行动”的倡议书，这次活动得到局党组的大力支持，得到了局机关和各直属单位的有力配合。国家局党组书记、局长徐德明和其他各位局领导都在倡议书上签名，各司室负责同志及广大干部职工也踊跃签名，努力做“光盘行动”的实践者和推动者。通过活动，使广大干部职工从思想深处认识到党中央号召厉行勤俭节约、反对奢侈浪费的重大意义，厉行节约、文明用餐已成为广大干部职工的自觉行动，就餐浪费现象明显减少，“光盘行动”收到实实在在的成效，广大干部职工结合群众路线实践教育活动，正在用实际行动贯彻中央八项规定和局党组十项措施。

组织开展杨艳萍同志先进事迹宣传。积极响应局党组号召，主动同中国能源化学工会沟通、协调，积极收集、整理了近五万字宣传杨艳萍同志先进事迹材料，以国家局名义推荐杨艳萍同志参加全国“五一劳动奖章”的评选，并及时将杨艳萍同志的先进事迹从我局网站上直接链接到中国能源化学工会网站，广泛宣传杨艳萍先进事迹，扩大测绘地理信息工作的社会影响。年内在中国能源化学工会网站上刊登了宣传我局工会工作的新闻报道6篇。

（二）搭建平台、创新方式，丰富干部职工文化生活

组织学习党的十八大精神主题赛诗会活动。积极响应中央国家机关工委和国土部直属机关工会号召，组织局属各单位职工积极参加活动，共征集到35篇作品，其中：有10篇作品在中央国家机关工委获奖，15篇作品在国土部直属机关工会获奖，我局荣获优秀组织奖。积极协助直属机关工会举办了测绘系统第三届“九成杯”乒乓球比赛，组建了机关乒乓球队，积极参加比赛并荣获优秀组织奖。协助直属机关工会组织了在京单位的“迎新春团拜会”，为大家奉献一场职工自编自演的文艺演出。

根据机关和各单位工作特点，广泛组织丰富多彩的文化体育活动。年内，组织机关工会女职工观看了“庆三八名家金曲文艺演唱会”。在中国创新基地院内组织了跳绳比赛，110余人参加了比赛，比赛因地制宜，就地取材，最大限度地节省了经费支出，体现了崇尚文明、勤俭办事的良好风尚，受到大家的欢迎和充分肯定。制定全年电影播放计划，在测绘创新基地定期播放电影24部，并及时组织职工观看。为机关工会会员等发放了北京世博园门票。积极组建机关乒乓球代表队，参加了北京测绘院组织的乒乓球友谊赛，并荣获第二名的好成绩。通过这些活动，使广大职工扩大交流，增进友谊，激发活力，有力推动了测绘地理信息文化建设和事业发展。

（三）以人文本、关心职工，激发干部职工精神动力

牢固树立一切为了职工、事事想着职工、处处依靠职工的理念，注重人文关怀，加强职工服务体系建设。积极开展送温暖走访慰问活动，争取多方筹集资金，2013年在中央国家机关工委为我局困难职工及全国劳模争取到了困难补助金、劳模慰问金38000元。关心女职工的健康，积极协调有关部门，为女职工增加了体检项目。继续组织了带薪休假工作。年内为全体职工办理了电影卡、公园年卡及生日贺卡，主动探望住院职工，切实关心生育女职工，积极帮助家庭困难职工，增加了工会组织的感召力和向心力，增强了职工队伍的凝聚力和战斗力，推动了各项工作的开展。

（四）夯实基础、完善体系，切实加强工会自身建设

组织完成了国土资源部直属机关工会组织的评优评先工作，我局机关工会工作受到好评，有1人被评为优秀工会工作者，2人被评为优秀工会积极分子，1人被评为优秀职工。组织完成了我局所属单位省部级以上劳模人员基本情况调查摸底工作，建立了我局劳模数据库。按照中央国家机关工委《关于开展2013年度工会年报调查工作》的部署，较好地完成了相关材料的申报工作。完成了国土部直属机关工会组织的工会会员登记和发放会员证工作，使工会会员管理工作进一步制度化、规范化。认真做好机关工会财务预决算工作，落实了年度工会经费，为做好机关工会工作提供了经费保证。

**二、**2014年工作要点

2014年局机关工会总体思路：以习近平总书记系列重要讲话精神为指导，以弘扬测绘精神和发扬“快干好”务实作风为重点，以广泛开展文化体育活动为抓手，以服务职工、维护职工权益为宗旨，按照局党组的部署和直属机关党委的要求，结合行业实际，突出工会特点，发挥机关工会组织作用，为测绘地理信息事业转型升级、跨越发展提供保障服务。

（一）发挥典型带动作用，激发职工创造精神。把学习习近平总书记重要讲话为政治任务，贯穿于机关工会工作始终。积极向上级工会组织汇报，努力争取支持，使杨艳萍同志走出测绘行业，树立成为全国劳模和典型，大力营造干事创业、建功立业、争当先进的良好氛围。积极配合有关部门开展劳动竞赛等活动，强化广大职工的主人翁意识，激发工作积极性、主动性和创造性。

（二）开展形式多样文体活动，促进精神文明建设。坚持组织竞赛性活动同鼓励日常性锻炼相结合，开展体育健身同进行文化怡心相结合，年内组织拔河、跳绳、羽毛球等比赛，在测绘创新基地放映电影，积极组织广大职工参加各项文化活动。

（三）切实发挥工会组织作用，维护职工合法权益。努力为职工解难事、做好事、办实事，切实维护职工合法权益。深入推进工会帮扶工作常态化、长效化，积极开展困难职工调查摸底工作，继续大力争取上级工会组织的帮扶慰问资金。协助有关部门做好职工健康体检、带薪休假等工作，做好生病住院职工、生育女职工慰问工作。

（四）努力加强工会自身建设，促进工作再上台阶。加强工会干部政治理论和工会知识学习，夯实各项工作基础，提高工作能力和水平。增强对外协调和对内统筹能力，整合工会资源，聚合工作力量，不断创新机关工会工作机制，提高工作效率和水平。
