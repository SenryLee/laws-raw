# 商务部流通产业促进中心关于2014年中央储备冻猪肉数量检查、核实和质量公检有关事项的通知

## 商务部流通产业促进中心关于2014年中央储备冻猪肉数量检查、核实和质量公检有关事项的通知（商流促字〔2014〕8号）

各承储单位：

根据《商务部发展改革委财政部中国农业发展银行关于下达2014年第一批中央储备冻猪肉入储计划的通知》（商运函[2014]127号）要求，我中心负责中央储备冻猪肉数量检查、核实和质量公检工作。为保证检查工作顺利开展，提高工作效率，现将有关事项通知如下：

**一、**做好检查准备工作

（一）规范储备肉码放

中央储备肉实行专库、专垛储存、专人专账管理。入库堆码时应规范操作，不同生产厂、不同商品编码的中央储备猪肉要单独堆码，留足七距，垛与垛之间要有有效间隔，足够人员或装卸设备进出，堆码整齐，便于清点和出库。每垛要按规定悬挂中央储备肉垛卡，并及时按库眼建立完整的中央储备肉库存明细，每发生一笔记录一笔，做到帐帐相符、帐实相符。中央储备肉要与地方储备肉严格分开，要与企业自营肉严格分开。

（二）做好入储冻肉初检，准备相关检查资料

承储单位应做好初检工作，查验动物（产品）检疫合格证、肉品品质检验合格证，并整理好各个标的中央储备冻猪肉的商品台账、交接单（原始码单）、动物（产品）检疫合格证明、肉品品质检验合格证等资料以备检查。地方不能开具动物（产品）检疫合格证的需提供主管部门出具的证明。

**二、**及时递交检查申请

承储单位应在完成收储后以书面形式向我中心提出检查申请（申请格式见附件），为便于您及时收到公检证书和发票，请准确填写申请表中的联系地址。同时，按每吨40元的标准支付公检费至以下账户：

户名：商务部流通产业促进中心

我中心在接到承储单位入库检查申请和汇款凭证（传真件）后的3个工作日内到承储冷库现场实施检查。

**三、**提供必要的防护用品和釆样工具

请各承储单位为检查人员提供进入冷库现场所需的棉大衣、棉裤、棉帽、棉鞋等个人防护用品和采样所需电钻、电锯等工具。
