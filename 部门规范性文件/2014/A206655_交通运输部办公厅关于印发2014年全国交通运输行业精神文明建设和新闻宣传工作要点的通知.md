# 交通运输部办公厅关于印发2014年全国交通运输行业精神文明建设和新闻宣传工作要点的通知

## 交通运输部办公厅关于印发2014年全国交通运输行业精神文明建设和新闻宣传工作要点的通知（厅政法字〔2014〕25号）

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），天津市市政公路管理局，天津市、上海市交通运输和港口管理局，部属各单位，部内各单位，部管各社团，有关中央交通运输企业：

现将《2014年全国交通运输行业精神文明建设和新闻宣传工作要点》印发给你们，请结合实际认真贯彻执行。

交通运输部办公厅

2014年2月7日

2014年全国交通运输行业精神文明建设和新闻宣传工作要点

2014年是交通运输行业贯彻落实党的十八届三中全会精神、推进全面深化改革的开局之年，也是全面完成“十二五”交通规划目标任务，加快推进综合交通、智慧交通、绿色交通、平安交通“四个交通”发展的重要一年。交通运输行业精神文明建设和新闻宣传工作的总体要求是：高举中国特色社会主义伟大旗帜，以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻落实党的十八大和十八届二中、三中全会精神，贯彻落实习近平总书记系列讲话精神，贯彻落实全国宣传思想工作会议和全国交通运输工作会议精神，坚持稳中求进、改革创新，紧紧围绕实现中华民族伟大复兴的中国梦，紧紧围绕加快推进“四个交通”发展，深入实施宣传思想工作五大工程，凝聚共识，形成合力，为推进综合交通运输体系发展、服务全面建成小康社会提供强大的精神动力和良好的舆论支持。

**一、**深入学习宣传贯彻习近平总书记系列讲话精神和党的十八届三中全会精神

进一步深化习近平总书记系列讲话精神和党的十八届三中全会精神的学习宣传贯彻，引导交通运输行业干部职工把握核心要义、领会思想精髓，用讲话精神和三中全会精神武装头脑、指导实践、推动工作。

明确学习贯彻的重点内容。深入学习领会习近平总书记关于坚持和发展中国特色社会主义、实现中华民族伟大复兴的中国梦、全面深化改革开放、推动科学发展、做好宣传思想工作等方面的深刻论述，认真领会讲话提出的新思想、新观点、新论断、新要求。深化对党的十八届三中全会提出的一系列重要思想观点、重大任务举措的认识和把握，引导干部职工把思想和行动统一到三中全会精神上来，把智慧和力量凝聚到三中全会确定的各项任务上来。

紧密结合交通运输工作实际。紧紧围绕部党组关于全面准确、深入系统地学习贯彻习近平总书记系列讲话精神和三中全会精神的总体要求，组织开展形式多样、内容丰富的学习贯彻活动。紧紧围绕2014年全国交通运输工作会议的部署要求，把讲话精神和三中全会精神与加快推动“四个交通”发展结合起来，与交通运输行业全面深化五项改革、抓实八个方面工作结合起来，推动各项工作的深入开展。

加强政策解读和宣传报道。组织邀请专家讲理论、干部讲政策，深化对习近平总书记系列讲话和全会提出的重要思想观点、重大任务举措的宣传解读。充分发挥交通运输行业报刊台网等媒体和政务微博、微信等新媒体的平台优势，发挥交通运输工具、场所的区位优势，加大交通运输行业开展学习贯彻活动的宣传报道力度。

**二、**积极培育和践行社会主义核心价值观

在全行业兴起培育和践行社会主义核心价值观的热潮，大力倡导“人便于行、货畅其流、服务群众、奉献社会”的行业核心价值观和“艰苦奋斗、勇于创新，不畏艰险、默默奉献”的交通精神。

精心落实中央部署。认真贯彻落实《中共中央办公厅印发＜关于培育和践行社会主义核心价值观的意见＞的通知》（中办发〔2013〕24号），作好工作安排，制定具体方案，明确年度重点，组织集中宣传，在全行业广泛开展社会主义核心价值观宣传教育。认真把握社会主义核心价值体系的科学内涵和践行要求，深入开展行业核心价值体系践行活动，推动社会主义核心价值观学习践行活动制度化、常态化。

注重抓好结合融入。全面推进核心价值倡导行动、道德模范引领行动、文明主题创建行动、文化品牌培育行动和行业形象塑造行动，坚持宣传教育、示范引领、实践养成相统一，注重政策保障、制度规范、法律约束相衔接，把“三个倡导”融入宣传教育的全过程，融入交通运输行业广大干部职工的生产生活，不断提升交通运输行业干部职工的思想道德素质，不断提升行业文明水平。

不断创新活动载体。把思想引导和制度规范结合起来，创新宣传教育方式，丰富实践载体，切实推动行业核心价值观内化于心、外化于行。组织开展交通运输行业核心价值体系“学习实践教育月”活动，举办“核心价值观大家谈”系列活动，推进交通运输行业核心价值观进机关、进港站、进车船、进工地。

**三、**深入开展交通运输行业群众性精神文明创建活动

充分发挥交通运输部门的组织指导作用，深入开展文明行业创建活动，坚持服务人民、奉献社会，突出诚信教育，增强道德自觉，进一步形成文明服务的行业风气和文明和谐的社会风尚。

明确总体目标要求。以扩大群众参与、提升职工文明素质和行业文明程度为目标，深入研究新时期精神文明创建工作，深入推进文明主题创建行动、行业形象塑造行动。不断更新创建理念、创新活动载体，引导交通运输行业干部职工进一步升华共同理想、弘扬时代精神、培养职业道德、树立行业新风。

抓好活动载体建设。不断丰富“学树建创”活动载体，进一步推动行业群众性文明创建活动广泛深入开展。切实做好党政机关作风和文明建设，深入开展学习“人民满意公务员”活动。抓好机场、车站、港口、出租车等窗口单位的文明创建活动。继续深入开展“寻找最美活动”、“感动交通人物”等主题活动，充分发挥先进典型的模范引领作用，深入开展向先进典型学习活动，加大典型宣传力度，不断挖掘、培树具有行业特色和时代精神的先进典型。

建立健全工作机制。研究探索文明单位、文明示范窗口建设测评体系，完善评选表彰制度和机制，开展文明单位、文明示范窗口等评选表彰工作。配合有关部门做好劳动模范和先进工作者、全国青年文明号等主题创建活动，不断扩大群众性文明创建活动的覆盖面和影响力，全面提高行业优质文明服务水平，提高公众满意度。

**四、**扎实推进交通运输文化建设示范工程

以提升交通运输行业软实力为目标，加强行业文化建设，不断完善适应“四个交通”发展要求、符合先进文化发展规律、具有鲜明时代特征、体现行业发展特色的行业文化体系。

深入实施文化建设“十百千”工程。以十大交通运输文化品牌、一百家交通运输文化建设示范单位、一千名交通运输行业先进典型评选工作为抓手，推进行业文化建设工作深入开展。加快推进交通运输文化品牌培育行动，精心培育打造一批内涵丰富、特点突出、体系完备、质量过硬、享誉全国的交通运输文化品牌。加强观摩交流，总结推广经验，充分发挥文化品牌和文化建设示范单位对行业文化建设的辐射带动作用，使行业发展的软实力、竞争力日益增强，不断提升交通运输行业的社会美誉度和影响力。

**五、**大力加强交通运输行业思想道德建设

把道德教育和实践养成融入贯穿交通运输行业精神文明建设的各方面、全过程，以行业思想道德建设水平的提升，为深入开展社会公德、职业道德、家庭美德、个人品德教育注入新的力量。

明确活动目标导向。大力推进道德模范引领行动，深入实施行业道德建设工程。弘扬中华传统美德，弘扬时代新风，引导职工在社会做个好公民，在单位做个好职工，在家庭做个好成员，全面提高行业干部职工道德素质。从群众身边的事情抓起，从基本行为规范抓起，从一点一滴抓起，不断增强全行业思想道德建设的针对性和实效性。

选树行业道德建设典型。组织开办“职业道德讲堂”，推广“职业道德讲堂”的经验，大力弘扬交通精神和职业道德。围绕解决诚信缺失、道德失范两个突出问题，结合行业窗口单位试点情况向全行业窗口单位拓展。大力整治行业窗口服务中的不正之风。选树一批行业道德建设标杆，促进宣传道德模范常态化、平民化。

组织开展文明交通出行专项活动。进一步弘扬文明出行、文明运输的理念，加强交通运输行业职工文明素质建设，不断提升文明服务水平。倡导文明出行，引导和规范公民行为，为文明出行创造和谐良好的交通运输环境，提升中国公民出境旅游文明素质。开展长期的、形式多样的宣传教育活动，切实形成文明服务的行业风气和文明出行的社会风尚。

**六、**不断深化交通运输行业重大主题宣传

结合交通运输行业重大事件和重要时间节点，精心策划、周密组织，有序实施，灵活运用各级各类媒体，深化交通运输行业重大主题宣传报道，不断提高交通运输新闻宣传的导向性、实效性和影响力。

宣传报道现代综合交通运输体系不断完善。宣传报道综合交通、智慧交通、绿色交通、平安交通“四个交通”发展对经济社会产生的巨大推动作用。宣传报道国家高速公路建设、集中连片特困地区扶贫工作和农村公路建设成就。宣传报道我国提升海运业综合竞争力，推进港口转型升级，加快推进长江等内河水运发展、落实国家推进长江经济支撑带战略部署的措施、做法和成效。策划组织开展丝绸之路交通运输峰会、独龙江公路通车、青藏川藏公路通车60周年等重大主题宣传活动，组织开展交通建设成就摄影展宣传活动。

宣传报道交通运输服务质量不断提升。围绕春运、“十一”黄金周等重点时段交通运输保障，重点物资、抢险救灾物资运输等工作，宣传报道交通运输行业不断提升服务质量的新做法、好经验，以及一线职工坚守岗位、无私奉献的感人事迹。围绕推进物流发展，宣传报道货运枢纽（物流园区）建设、交通运输物流公共信息平台建设，以及甩挂运输、铁水联运的工作进展和阶段性成果。围绕落实国务院关于城市优先发展公共交通指导意见，开展公交都市创建活动、绿色公交出行活动宣传。围绕“公路三乱”整改，宣传整改活动取得的成效。围绕加强交通运输出行服务，宣传ETC全国联网、12328交通服务热线开通、节假日高速公路小客车免费通行政策等有关情况。

宣传报道平安交通和绿色循环低碳交通发展。围绕公路水路安全监管工作，宣传报道“平安交通”和“安全风险管理”试点示范、公路安保工程、轨道交通安全管理、重点通航水域和重点运输车船安全监管、应急救助和抢险打捞能力建设等方面的经验做法。围绕绿色循环低碳交通运输体系建设，宣传试点示范活动、“车船路港”千企专项行动、清洁能源在交通运输行业推广应用等方面取得的成效和经验，做好“节能宣传周”活动宣传。

**七、**进一步完善交通运输行业新闻发布工作机制

不断建立健全交通运输行业新闻发言人制度，推进新闻发言人专业化、专职化，着力提高新闻发布的时效性、针对性，做好重大事件的新闻发布，及时回应社会关切，塑造公开、透明的政府形象和行业形象。

建立健全新闻发言人制度。进一步加强交通运输行业新闻发言人制度建设，加强新闻发言人培训工作，提升新闻发言人的履职能力，完善新闻发言人参与了解重要决策的工作机制和工作流程。建立健全专题新闻发布策划研讨机制，精心设计新闻发布的主题、形式、内容，准确把握发布时机。完善专家学者解读机制，通过“第三方发声”做好政策解读。

灵活运用各类新闻发布平台。充分发挥中央新闻媒体影响力大、关注度高的作用，加强与中央主流媒体的沟通协调，及时通过权威的主流平台发布新闻。注重发挥中国交通报等行业报刊杂志的宣传阵地作用，集中优势新闻资源，做好信息发布和政策解读，把行业媒体打造成强大的主流舆论阵地。适应新媒体、自媒体的发展，积极探索通过政府网站、门户网站、政务微博、微信、手机报等载体及时发布行业信息和服务资讯，不断增强交通运输信息的覆盖面和感染力。

增强新闻发布的时效性和针对性。围绕部党组以及各级党委政府关于交通运输工作的重大部署和重点工作，精心设计议题，主动组织新闻发布。规范新闻发布流程，建立定时定点、有序发布的机制。完善例行新闻发布机制和重大新闻动态发布机制，做好交通运输重大突发事件的新闻发布，及时解疑释惑，提高应急反应能力。

**八、**不断提升交通运输热点问题舆情研判和舆论引导工作水平

完善舆情收集机制，及时掌握交通运输行业相关舆情信息，提升舆情研判的针对性和有效性，不断壮大舆论引导工作队伍，提升舆论引导水平，为推进“四个交通”发展营造良好的舆论环境。

加强舆情收集研判。进一步健全完善舆情信息监测、收集、研判体系，确保第一时间发现涉及交通运输行业的苗头性、倾向性信息。加强与业务部门、相关专家的联席研判，结合具体工作，准确判断舆情走向和发展态势，提出舆情应对建议，为科学有效处置舆情奠定基础。

及时回应热点舆情。加强突发事件应急宣传工作的规范化、专业化、制度化建设，建立健全应急反应机制，提高突发事件新闻发布的质量和水平，有效回应社会关注。编写出版《交通热点面对面》，权威解读交通热点。加强与新闻宣传部门及重点媒体的沟通协调，争取理解支持。对不实信息或谣言，及时通过权威媒体予以驳斥和辟谣，遏制不良信息的蔓延和传播。

做好网上舆论引导。精心组织网上正面宣传和热点引导，唱响网上主旋律，打好主动仗，以大量的正面宣传信息，遏制负面舆论的生存空间。充分发挥各级交通运输政务微博、微信的优势，加强与人民群众的互信互动，拉近行业与群众的距离，赢得群众的信赖和好感。适应新媒体的发展，不断加强网络新技术新应用的研究探索。加强网络宣传队伍建设，建立交通运输行业网络评论员队伍。

**九、**加强组织领导，不断提升精神文明建设和新闻宣传工作的科学化水平

加强队伍建设和制度建设，完善保障机制，进一步增强责任感和紧迫感，切实提升交通运输行业精神文明建设和新闻宣传工作的科学化水平。

实施基础条件保障工程。坚持党委统一领导、各级领导班子负责，将精神文明建设和新闻宣传工作作为本部门、本单位的重点工作，摆上日程，抓实抓好，做到方向上牢牢把握、工作上研究指导、政策上大力支持、投入上切实保障。提供必要的工作经费，保证常态化工作经费和重大主题、重大活动的专题经费，推动各项工作落到实处、取得实效。
