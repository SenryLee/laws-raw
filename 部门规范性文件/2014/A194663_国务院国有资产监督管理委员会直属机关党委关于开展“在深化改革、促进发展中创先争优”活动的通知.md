# 国务院国有资产监督管理委员会直属机关党委关于开展“在深化改革、促进发展中创先争优”活动的通知

各厅局、直属事业单位、直管协会、部分京外企业在京单位党委（总支、支部）：

2014年是贯彻落实党的十八届三中全会精神、全面深化改革的开局之年，也是开启国资国企改革发展新局面的关键一年。为动员和组织直属机关广大党员干部围绕国资委党委提出的中心任务和本单位重点工作，在推进国资国企改革发展中创先争优、建功立业，根据直属机关党委年度党建工作安排，决定在直属机关范围内组织开展“在深化改革、促进发展中创先争优”活动。

**一、**活动主题

认真贯彻落实党的十八届三中全会精神和中央各项决策部署，在国资委党委的领导下，解放思想、振奋精神，积极投身全面深化改革的伟大实践中，着力在深化改革、破解难题、推动发展中创先进、争优秀，认真履行职责，做好本职工作，全力以赴完成2014年各项任务，为全面深化国资国企改革、完善国资监管体制提供强大动力和坚强保证。

**二、**活动部署

开展“在深化改革、促进发展中创先争优”活动要以“实际行动推进改革、立足岗位争创佳绩”为载体，把创先争优活动落实到全面深化国资国企改革的各项工作之中。组织直属机关广大党员干部深入学习领会三中全会的深刻内涵和精神实质，准确把握全面深化国资国企改革的目标任务和重要举措，按照委党委关于深化国资国企改革的部署和要求，紧密结合本单位实际，把国资国企改革与创先争优活动结合起来，通过创先争优活动激发广大党员干部的工作热情、改革意识和创新精神，引导广大党员干部深入基层，加强调研，在本职岗位和工作实践中加强对深化国资监管、国企改革发展热点难点问题的研究，破解发展难题，努力在发展混合所有制经济、建立健全现代企业制度、完善国资监管体制等方面取得实实在在的突破，为深入推进国资国企改革保驾护航，为完成全年工作任务提供保证。

直属机关各级党组织要按照中央关于将创先争优长效化、常态化的要求，紧密结合本单位实际，精心设计活动内容。机关各厅局要结合本厅局业务工作和在深化国资国企改革、推动央企发展中的中心任务，组织广大党员干部紧紧围绕委党委关于深化国资国企改革的部署安排和今年7个方面33项工作任务开展创先争优。管理局系统要坚持“第一任务、第一责任”，认真落实好老同志“两项待遇”，切实加强机关后勤服务保障体系建设，不断提高保障能力，努力提供一流服务。直属事业单位要根据各自特点，发挥自身优势，组织广大党员在服务保障国资委机关高效运转和推进国资国企改革中勇挑重担、争创佳绩。直管协会要围绕转变发展方式，化解产能过剩，实现行业振兴，充分发挥服务政府、服务行业、服务企业的桥梁纽带作用，在实际工作中争创一流业绩。京外企业在京单位要激励广大党员干部努力工作，积极应对复杂经济形势，在不断提升企业管理水平、努力完成经营指标中比学赶超。

直属机关党委将通过精品工作展示等活动，引导党员干部增强精品意识，提高履职能力，成为本职工作的行家里手。直属机关各单位要运用各种手段营造良好的工作氛围，激励广大党员干部立足岗位创佳绩，履行职责争优秀，把全面深化国资国企改革、推动央企发展不断引向深入。直属机关党委将适时组织召开创先争优活动工作交流会。

**三、**工作要求

直属机关各级党组织要按照直属机关党委的工作安排，紧紧围绕全面深化国资国企改革任务，结合本单位中心工作，精心组织，狠抓落实，确保活动扎实推进，取得满意效果。

一是要高度重视，加强领导。创先争优是加强党的基层组织建设的一项经常性工作，活动的重点在基层，责任在领导，关键看效果。各级党组织要高度重视、精心组织、加强领导、统筹安排，严格按照直属机关党委的要求，以高度的政治责任感和良好的精神状态，把活动抓紧抓好，抓出成效。

二是要广泛发动，制定计划。各级党组织要通过多种形式广泛动员，号召广大党员干部积极参与，形成在推进改革中争先进，在促进发展中当优秀的良好风气。各单位要根据深化国资国企改革的任务和业务工作实际，研究制定本单位党组织“在深化改革、促进发展中创先争优”活动的工作安排。

三是要结合实际，有序推进。各单位要结合全面深化国资国企改革工作开展创先争优活动，要使创先争优活动与深化改革工作有机融合，相互促进，通过创先争优活动推动国资国企改革发展不断取得新进展，通过深化国资国企改革发展把创先争优活动不断引向深入。

四是要巩固成果，取得实效。各级党组织要借鉴党的群众路线教育实践活动的成功经验，通过继续抓好整改落实，巩固和扩大教育实践活动成果，以好的作风抓改革；借鉴管理提升活动的好经验好做法，向管理要效益，向创新要活力，保证直属机关“在深化改革、促进发展中创先争优”活动扎实推进，取得实效。

请各级党组织及时将开展“在深化改革、促进发展中创先争优”活动的进展情况和经验做法报直属机关党委。

直属机关党委

2014年3月3日
