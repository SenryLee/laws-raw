# 财政部办公厅关于组织开展中央级事业单位所办企业员工持股情况摸底调查的通知

财政部办公厅关于组织开展中央级事业单位所办企业员工持股情况摸底调查的通知

（财办教〔2014〕27号）

党中央有关部门财务司（局），国务院有关部委、有关直属机构财务司（局），全国人大常委会办公厅机关事务管理局，全国政协办公厅机关机关事务管理局，高法院司法行政装备管理局，高检院计划财务装备局，有关人民团体财务司（局），有关中央管理企业，新疆生产建设兵团财务局：

为落实党的十八届三中全会《中共中央关于全面深化改革若干重大问题的决定》有关要求，根据中央关于全面深化改革的工作部署，为全面梳理和掌握国有企业员工持股情况，现对中央级事业单位所办企业员工持股情况进行摸底调查。现将有关事项通知如下：

**一、**调查内容

包括员工持股企业的总体情况（如已经实施员工持股的企业情况、引入员工持股方式、持股员工人数比例、员工持股比例等）；企业实际操作和政策监管的成功经验；在员工持股实践中存在的问题和下一步需要解决的问题；相关政策建议等。具体内容详见附件。

**二、**具体要求

（一）请各部门（单位）高度重视、积极配合，认真做好此次调查工作。各部门（单位）应当在审核、汇总和梳理总结的基础上，于6月25日前将调查报告和调查表（格式电子版可在财政部门户网站教科文司频道下载）报送至财政部教科文司，并将电子版发送至shiyezichanchu@aliyun.com。

（二）此次调查的时间范围为截至2012年12月31日。

（三）如果本部门（单位）没有员工持股情况，也请来函说明。

**一、**员工持股企业总体情况

共有XXX家事业单位在XXX户所办企业（含子企业）实施过员工持股。涉及出资额XXX亿元，员工XXX万人。截至2012年底，XXX家事业单位下属的XXX户所办企业保有员工持股，涉及资产总额XXX亿元、净资产XXX亿元、持股员工XXX万人。

（一）员工持股企业的基本特点。如业务领域、持股企业规模（大中小型企业，标准参见财统字〔2011〕75号）、管理层级、是否上市等。

（二）员工持股企业的经营和发展情况。如引入员工持股当年和2012年底，员工持股企业的资产负债率（加权平均，下同）、营业利润率、净资产回报率。自首次引入持股到2012年底，员工持股企业总资产、净资产、营业收入、营业利润年化增长率。

（三）员工持股企业股权结构。除国有和员工持股外，包含其他非国有股东的企业户数。

（四）引入员工持股方式。如共同设立新公司、向员工增资扩股、受让存量国有资产等方式的企业户数。

（五）持股员工人数比例。如持股人数占所在企业总人数的平均比例，以及只引进高管持股户数、只引进高管和关键岗位骨干持股户数、一般员工与高管、关键岗位骨干共同持股的企业户数。

（六）员工持股比例。如员工持股总比例及分布，员工人均持股比例及分布。

（七）员工出资数额。如人均出资数额及分布。

（八）员工持股方式。如个人直接持股、个人直接同时为他人代持、职工持股会，通过有限公司、有限合伙制企业、信托计划等间接入股的企业户数及比例。

（九）员工出资方式。采取现金出资、非现金出资、混合出资、无偿奖励股权等方式的企业户数及比例。

（十）股权调整情况。引入员工持股后进行过股权调整的企业户数。
