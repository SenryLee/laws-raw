# 中国地震局关于做好地震安全性评价人员执业资格核准行政审批取消后相关工作的通知

中国地震局关于做好地震安全性评价人员执业资格核准行政审批取消后相关工作的通知

各省、自治区、直辖市地震局：

地震安全性评价人员执业资格核准是中国地震局和各省（区、市）地震局（以下简称“省级地震局”）负责实施的行政审批事项，根据《国务院关于取消和下放一批行政审批项目的决定》（国发〔2013〕44号），中国地震局负责实施的一级地震安全性评价工程师执业资格核准已取消，相关工作已移交中国灾害防御协会（见附件）。根据国务院行政审批制度改革精神，结合地震安全性评价行业实际，现将地震安全性评价人员执业资格核准取消后有关工作通知如下：

**一、**尽快完成相关行政审批事项的取消和工作移交

各省级地震局负责的二级地震安全性评价工程师执业资格核准和一级地震安全性评价工程师初审相关行政审批事项应予取消。已经取消的，二级地震安全性评价工程师执业资格核准的相关工作应尽快移交有关协会（学会），一级地震安全性评价工程师初审的相关工作应立即停止实施；尚未取消的，应及时予以取消。

**二、**二级地震安全性评价工程师注册

二级地震安全性评价工程师执业资格核准取消且相关工作移交协会（学会）后，在中国地震局和人社部对原有管理规定修订完成前，人员注册工作可暂参照现有管理规定，文件条款执行主体为省级地震局的改由协会（学会）执行。

协会（学会）负责二级地震安全性评价工程师注册、变更、延续、注销等工作，二级地震安全性评价工程师注册证书和执业印章由协会（学会）发放，协会（学会）应及时将二级地震安全性评价工程师注册信息报相应省级地震局和中国地震局，各省级地震局负责本省（区、市）区域内二级地震安全性评价工程师注册的监督管理。

**三、**一级地震安全性评价工程师初审

各省级地震局负责的一级地震安全性评价工程师初审不再实施。取得一级地震安全性评价工程师资格的人员，应通过聘用单位，由申请人直接向中国灾害防御协会提出注册申请，协会做出审查决定后，将注册人员信息报中国地震局和相应省级地震局。

**四、**二级地震安全性评价工程师资格考试和执业监管

经与人社部相关部门沟通，地震安全性评价人员执业资格核准行政审批取消后，地震安全性评价工程师执业资格考试拟由职业准入类变为职业水平评价类，人社部已将工作方案上报国务院待审定。资格考试的方式和组织需在国务院正式审定后明确。

加强对地震安全性评价工程师执业的监督管理是保证工作质量的重要措施，各省级地震局要依据《地震安全性评价工程师执业管理办法》（中震防发〔2012〕57号）的规定，加强本地区地震安全性评价工程师的执业监督管理。

取消地震安全性评价执业资格核准，是地震部门落实行政审批制度改革的重要工作，各省级地震局要高度重视，按照本通知要求，认真履行职责，加强监督管理，做好二级地震安全性评价工程师执业资格核准的取消和相关的交接工作，保证地震安全性评价工程师制度的顺利平稳过渡。

请各省级地震局于4月18日前将取消行政审批事项和相关工作移交的情况，以及下一步工作计划报中国地震局震害防御司。
