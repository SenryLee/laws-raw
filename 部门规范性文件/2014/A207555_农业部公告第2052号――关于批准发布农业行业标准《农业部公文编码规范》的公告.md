# 农业部公告第2052号――关于批准发布农业行业标准《农业部公文编码规范》的公告

## 农业部公告（第2052号）

《农业部公文编码规范》业经专家审定通过，现批准发布为中华人民共和国农业行业标准，标准号为NY/T2536-2014，自2014年7月1日起实施。

特此公告。

农业部

2014年1月14日
