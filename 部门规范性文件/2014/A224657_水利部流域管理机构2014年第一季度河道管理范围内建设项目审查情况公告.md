# 水利部流域管理机构2014年第一季度河道管理范围内建设项目审查情况公告

为促进依法行政，加强行政审批的监督管理，现将2014年第一季度水利部流域管理机构河道管理范围内建设项目审查情况公告如下：

水利部流域管理机构2014年第一季度审查同意的河道管理范围内建设项目共计71项，其中长江水利委员会31项，黄河水利委员会11项，淮河水利委员会20项，海河水利委员会1项，珠江水利委员会6项，松辽水利委员会1项，太湖流域管理局1项。

附件：水利部流域管理机构2014年第一季度河道管理范围内建设项目审查情况统计表

建设与管理司

2014年4月14日
