# 住房和城乡建设部建筑节能与科技司、住房和城乡建设部标准定额司关于召开新修订的《绿色建筑评价标准》宣贯培训会议的通知

## 住房和城乡建设部建筑节能与科技司、住房和城乡建设部标准定额司关于召开新修订的《绿色建筑评价标准》宣贯培训会议的通知（建科综函[2014]156号）

各省、自治区住房城乡建设厅，直辖市、计划单列市建委（建设局），新疆生产建设兵团建设局：

新修订的国家《绿色建筑评价标准》（GB/T50378-2014）已由我部正式发布，自2015年1月1日起实施。为做好新标准的贯彻实施，使有关人员深入理解、准确把握标准相关要求，统一绿色建筑评价尺度，推进全国绿色建筑评价工作健康发展，根据2014年住房和城乡建设部机关培训计划和2014年度工程建设标准培训计划安排，现定于2014年12月1日至3日，在北京召开该标准宣贯培训会议。现将有关事项通知如下：

**一、**会议内容

（一）宣传推动我国绿色建筑健康发展；

（二）解读新修订的《绿色建筑评价标准》（GB/T50378-2014）条款；

（三）结合新标准修订介绍绿色建筑方案设计和评价方法。

**二、**参会人员

各地住房城乡建设主管部门绿色建筑评价标识管理工作和标准化管理工作具体负责人，住房城乡建设部绿色建筑评价标识专家委员会成员，以及有关从事绿色建筑开发、设计、施工、运营、评审工作的专业技术人员。

请各省、自治区住房城乡建设厅，直辖市、计划单列市建委（建设局）、新疆生产建设兵团建设局统一组织相关人员参加培训。因会议规模受限，各省市限报10人，并于2014年11月25日前将参会回执（见附件1）用电子邮件发送至会议联系邮箱。

**三、**时间和地点

时间：2014年12月1日全天报到，2、3日培训，会期两天。

地点：北京远望楼宾馆四层会议厅（地址：北京市海淀区北三环中路57号；电话：010-62013366；网址：www.yw57.cn）。

**四、**承办单位

本次会议由住房城乡建设部建筑节能与科技司、标准定额司联合主办，由标准主编单位中国建筑科学研究院会同北京科海之滨国际会展服务有限公司承办。
