# 国家海洋局关于取消和下放行政审批项目的公告

根据《国务院关于取消和调整一批行政审批项目等事项的决定》（国发〔2014〕27号），决定取消下放国家海洋局3项行政审批项目，其中取消2项，下放管理层级1项，现予公布。

2014年10月28日

附件：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 项目名称 | 设定依据 | 处理决定 |
| 1 | 外国人进入国家级海洋自然保护区审批 | 《中华人民共和国自然保护区条例》（国务院令第167号） | 下放至省级人民政府海洋行政主管部门 |
| 2 | 海洋石油勘探开发溢油应急计划审批 | 《中华人民共和国海洋环境保护法》 | 取消 |
| 3 | 海岸工程建设项目环境影响报告书审核 | 《中华人民共和国海洋环境保护法》 | 取消 |
