# 国管局办公室关于开展中央国家机关办公区节能监管系统建设有关工作的通知

国管局办公室关于开展中央国家机关办公区节能监管系统建设有关工作的通知

（国管节能〔2014〕27号）

中央国家机关各部门、各单位办公厅（室）：

为贯彻落实国务院《节能减排“十二五”规划》，提高中央国家机关用能管理信息化、精细化水平，我局决定组织开展中央国家机关节能监管系统建设工作，现就有关事项通知如下：

**一、**建设内容

中央国家机关节能监管系统是通过安装能源资源分类分项计量装置，对中央国家机关各部门、各单位办公区内的动力、采暖、空调、照明、给排水等各种设施设备的能耗数据进行即时采集，使用远程传输技术实现电、水、热、气等能源资源消耗情况的实时监测和预警、动态分析和评估的管理信息系统，主要为优化系统运行、完善节能管理、实施节能改造及合同能源管理服务等工作提供技术支持。该系统包括各部门、各单位办公区节能监管子系统和中央国家机关节能监管汇总系统两部分。我局负责中央国家机关节能监管系统建设工作的组织实施和监督管理，并承担中央国家机关节能监管汇总系统的建设工作；各部门、各单位负责各自办公区节能监管子系统建设工作。

**二、**进度安排

我局已完成总集成管理单位和各部门节能监管子系统建设施工单位入围招标等前期准备工作。今年10月，中央国家机关节能监管系统建设工作启动；10月底前完成第一批20个部门的节能监管子系统建设方案编制及审批，年底前完成建设工作；2015年3月底前，完成其余部门节能监管子系统建设方案编制及审批，年底前完成建设工作。

**三、**工作要求

我局组织编制了《中央国家机关办公区节能监管系统建设工作方案》。各部门、各单位要按照分工安排，认真抓好项目实施工作：一是抓紧编制办公区节能监管子系统实施方案，向我局申报立项，按照核准后的建设方案组织实施；二是加强组织领导，建立节能管理、基建、物业、信息（保密）管理等有关方面共同参与的内部协作机制；三是按照节能监管汇总系统数据库接口标准和安全要求，合理选用系统软件和技术措施，确保系统稳定运行、数据平稳传输；四是项目竣工验收后，要在年度节能工作总结中报送节能监管系统运行使用效果及能耗数据分析利用情况。

国管局办公室

2014年9月22日

附件

中央国家机关办公区节能监管系统建设

工作方案

为落实国务院《节能减排“十二五”规划》，加快推进中央国家机关办公区节能监管系统建设，确保建设方案科学合理、施工安全规范、造价经济合理，提高中央国家机关用能管理信息化、精细化水平，根据财政部、国管局有关工程管理的要求，制定本工作方案。

**一、**工作目标

按照“统筹规划、分步实施、加强运维、注重实效”的原则，2015年底前完成中央国家机关节能监管系统建设工作，实现中央国家机关办公区电、水、热、气等能源资源消耗数据分类分项计量、动态采集、统计分析，为各部门、各单位节能管理精细化提供技术支持。

中央国家机关节能监管系统包括各部门、各单位办公区节能监管子系统（以下简称子系统）和中央国家机关节能监管汇总系统（以下简称汇总系统）两部分。除因办公用房产权等特殊情况外，各部门、各单位均应建设办公区节能监管子系统；国管局在此基础上建设汇总系统。

**二、**各单位职责

（一）项目牵头单位。

国管局为本项目牵头单位，负责项目全过程的管理和监督。包括：组织招标确定项目总集成管理单位、施工单位入围企业名单，组建评审专家库；批复各部门子系统建设方案；履行项目监管职责，组织制定项目建设标准、实施流程和管理办法，监管项目汇总平台建设及分平台建设工程进度、质量和节能效果；负责项目总预算控制并办理国库支付手续。同时，组织开展汇总系统的建设工作，确定汇总系统工程监理单位，监管汇总系统建设进度及质量，组织竣工验收。

（二）建设（使用）单位。

各部门、各单位为建设（使用）单位，负责本部门子系统的建设工作和使用管理，包括：组织编制并申报项目建设方案及概算；组织施工单位比选和施工方案评审确定项目施工单位；按规定选定工程监理单位；协调现场施工条件，做好施工安全管理和信息安全保密工作，确保工程进度、质量和节能效果；协助办理资金支付手续；落实人员做好子系统的长期运行管理工作。

（三）总集成管理单位。

通过公开招标确定，总集成管理单位为中国建筑科学研究院、中国节能环保集团、安徽省安泰科技股份有限公司、建研科技股份有限公司、北京中船信息科技有限公司、赛尔网络有限公司、中节能六合天融环保科技有限公司组成的联合体。总集成管理单位负责汇总系统实施建设，制定统一的数据库接口标准和格式安全要求，汇总分析各部门能耗监测数据，并确保数据传输安全。同时，总集成管理单位作为项目管理单位和技术支持单位履行以下职责：协助各部门组织项目建设方案和施工单位评审；协调组织施工单位建设各部门子系统；组织开展项目预算审核和工程结算，编制财务决算报告；组织建设过程评估和效果后评价；系统运行管理培训与指导；提供全过程顾问咨询服务。

（四）工程监理单位。

汇总系统工程监理单位由国管局按照有关规定确定，子系统工程监理单位由各部门、各单位在国管局公开招标确定的中央国家机关房屋建设工程监理定点企业入围名单中选择，监理费按照建安工程费的1%计取。工程监理单位负责对施工安全、质量、进度等进行监管；组织计量器具的抽查检验；配合做好施工进度款审核、资产变更等工作。

（五）施工单位。

施工单位由各部门、各单位在国管局通过公开招标确定的中央国家机关节能监管系统建设入围施工单位名单中选择。施工单位负责各部门子系统建设、系统及设备维护保修、后期节能诊断和顾问咨询服务，确保能耗监测系统安全可靠运行、数据可靠上传至总系统。

**三、**实施流程

（一）项目申请及批复。

1.建设方案编制。各部门、各单位从入围施工单位名单中选择3家施工单位开展现场踏勘，按照《中央国家机关办公区节能监管系统工程技术指南》、《中央和国家机关节约型办公区评价导则（试行）》的有关要求，充分利用已有计量器具，结合楼宇自控系统情况，统筹规划本部门节能监管系统建设工作，编制系统建设方案。建设方案应当达到初步设计深度，建设方案文件应包含改造方案文件和设计文件两部分。改造方案文件应当包括项目概况、用能现状分析、供暖空调等主要用能设备设施运行参数、系统建设必要性分析、分类分项计量内容及深度、系统建设技术措施及参数、工程量清单及概算、运行保障服务措施等。设计文件应当包括设计说明书、各专业设计图纸、工程概算书、主要设备和材料表。

2.建设方案评审及施工单位确定。各部门、各单位会同总集成管理单位召开专家评审委员会进行建设方案评审，确定项目建设方案和相应的中标施工单位。评审专家从国管局与总集成管理单位共同组建的专家库中随机抽取产生，评审专家为5人（含）以上单数，其中1人为建设单位代表。专家评审委员会重点评审建设方案合理性、数据采集传输可靠性、监测系统的易用性、数据分析有效性和经济合理性等并出具书面评审报告。

3.项目申请与批复。各部门、各单位确认本部门建设方案及施工单位后，以部门名义向国管局申请立项和投资概算。国管局根据建设方案评审报告，参考总集成管理单位意见办理项目立项、概算批复手续。各部门、各单位依据批复文件确定的建设内容和资金额度，组织施工单位开展深化设计。项目建设资金由国管局在中央国家机关节能监管体系建设补贴资金中统筹安排。

（二）施工组织。

施工单位与建设（使用）单位签订施工合同后，应当在3个工作日内报总集成管理单位备案。施工单位应当严格按照项目深化方案和施工进度计划开展项目建设，并确保施工过程满足相关安全、质量、保密规定。各部门、各单位负责监督施工单位按时保质完成改造工作。总集成管理单位、工程监理单位配合各部门、各单位做好项目实施过程中的相关工作。

（三）竣工验收。

施工单位应当按照总集成管理单位提出的子系统数据上传标准格式和安全要求对系统稳定性、可靠性进行专业测试，确保各子系统数据安全稳定上传。系统测试通过后，各部门、各单位严格按照国家及北京市相关规定和《中央国家机关办公区节能监管系统工程技术指南》要求，组织施工、监理、总集成管理等单位进行项目竣工验收，施工单位应当提交完善的竣工图纸资料及竣工结算报告，同时提交节能初步效果报告。

（四）节能服务及效果评估。

项目建成使用后，各部门、各单位应当组织施工单位按月、按季度对用能数据进行统计分析，提出节能工作优化建议，并根据相关建议改进节能管理工作；每年组织施工单位进行项目节能效果评估，并编制项目节能评价报告，并由施工单位报送总集成管理单位审核，不提交节能效果报告的不予办理尾款支付手续。有条件的部门应当积极采用合同能源管理等方式实施节能改造。

**四、**资金支付

本项目改造资金支付采用国库直接支付方式，由资金申请单位（总集成管理、施工、工程监理等单位）填写《国务院机关事务管理局节能改造基本建设资金支付核定单》并依次报送监理单位、建设（使用）单位审核后，报送国管局办理支付手续。

工程款支付进度为：施工单位与建设（使用）单位签订实施合同后可申请支付合同金额30%的预付款；项目完成竣工验收后可以申请支付至结算审计确定的工程结算金额的85%。余款作为系统运行服务费，从验收合格日起稳定运行满1年且通过节能效果评估后，支付工程结算金额的10%；稳定运行满3年且通过节能效果评估，支付工程结算金额的5%。

**五、**有关事项

各部门、各单位要切实加强节能监管系统建设工作的组织管理，认真抓好实施改造工作：

（一）建立由节能管理部门牵头，物业、信息（保密）管理等有关单位共同参与的内部协作机制，抓紧组织实施。

（二）建立健全节能监管系统运行管理制度和操作规程，明确运行管理负责机构、人员及职责分工，系统的运行维护应由专业技术人员负责。质保期满后，自行确定后期运行维护管理方式，鼓励以购买市场化服务、合同能源管理等方式为系统运行维护提供支持。

（三）要严格控制工程预算支出，除按照《中央国家机关建设项目工程变更管理办法（试行）》的有关程序批准的重大设计变更外，一律不予办理工程增项变更。

（四）相关资料及施工单位名单可从公共机构节能网（http：//ecpi.ggj.gov.cn）下载。
