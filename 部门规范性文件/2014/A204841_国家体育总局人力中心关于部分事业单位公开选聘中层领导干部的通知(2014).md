# 国家体育总局人力中心关于部分事业单位公开选聘中层领导干部的通知(2014)

## 国家体育总局人力中心关于部分事业单位公开选聘中层领导干部的通知（2014年4月）

总局各厅、司、局，京内各直属单位：

根据国家体育总局关于事业单位中层领导干部公开选聘工作的有关要求，受有关单位的委托，现就游泳中心、体操中心、武术中心、科研所公开选聘中层领导干部的有关事项通知如下：

**一、**公开选聘岗位

游泳中心1个、体操中心1个、武术中心2个、科研所4个，共计8个岗位。岗位情况详见附件1。

**二、**选聘范围

总局机关公务员和京内直属单位正式在编工作人员。

**三、**报名条件

报名人员应符合相应的岗位资格条件要求，具体详见附件1。

**四、**基本程序

（一）报名

报名采取个人自荐和组织推荐相结合的方法。报名者填写《国家体育总局事业单位公开选聘中层领导干部报名表》（附件2，可从中国体育人才网www.tyrc.gov.cn“公开选聘”专栏中下载），由所在单位审核盖章后，于4月10日-14日将报名表（贴2寸照片）及一张2寸照片交人力中心。报名期间（截至4月14日16：00）允许报名人员查询报名情况，可调整报名岗位1次。

报名地点：总局东办公楼人力中心人事代理部410、430房间。

（二）资格审查

人力中心按照报名资格及条件、岗位要求对报名者进行资格审查。对于取消选聘的岗位，允许报考该岗位人员改报其他岗位1次。资格审查的结果将在国家体育总局网站、中国体育人才网公布。

（三）考试

考试包括笔试、面试，考试范围为《党政领导干部公开选拔和竞争上岗考试大纲》规定的内容，其中笔试设定合格分数线。根据笔试成绩，按1：3的比例确定参加面试人选。笔试、面试时间初步定为4月19日和4月26日，具体时间和地点另行通知。

面试前如出现中途退出的情况，将根据笔试成绩在合格分数线以上按由高到低进行递补。

（四）确定考察人选

根据笔试、面试成绩之和，按1：2的比例确定考察人选。

考察前如出现中途退出的情况，将由其他进入面试范围人员按笔、面试成绩之和由高到低进行递补。

（五）考察

考察实行预告制，由选聘单位向被考察对象所在单位发布考察预告。选聘单位成立考察组，对被考察对象的德、能、勤、绩、廉等情况进行全面考察。

（六）确定拟聘人选

选聘单位根据考察情况，由领导班子集体研究确定拟聘人选，并报人事司备案。

（七）聘任

根据备案的结果，选聘单位按照相关规定实施聘任。

**五、**其他事项

（一）请各部门（单位）积极支持总局事业单位公开选聘中层领导干部工作，及时传达、张贴本通知，鼓励符合条件人员踊跃报名，并为竞聘人员创造条件，保证其按时、按要求参加竞聘。

（二）公开选聘工作是总局建立健全干部选拔任用的竞争激励机制、扩大干部选拔视野、促进干部交流而搭建的一个选才、用才的平台，竞聘人员要自觉遵守公开选聘的有关规定，遵守考试纪律，尊重考官，不得弄虚作假、欺骗组织，不得搞不正当活动。如因特殊原因中途退出的，须在面试、考察工作开展之前提出书面申请。

（三）公开选聘工作将由人事司、监察局进行指导和监督。人力中心严格遵守组织人事工作纪律，按照有关规定和程序进行公开选聘，保证公开选聘工作的客观、公正、透明，欢迎大家予以监督。

本次公开选聘的相关信息将在国家体育总局网站（www.sport.gov.cn）、中国体育人才网（www.tyrc.gov.cn）上公布，欢迎大家查询。
