# 农业部办公厅关于做好2014年海洋伏季休渔工作的通知

## 农业部办公厅关于做好2014年海洋伏季休渔工作的通知（农办渔[2014]32号）

沿海各省、自治区、直辖市渔业主管厅（局）：

为更好地养护和合理利用海洋生物资源，近年来，我部对海洋伏季休渔制度进行了调整和完善。2013年12月，我部发布《农业部关于调整黄渤海区刺网休渔时间的通告》（农业部通告〔2013〕3号），决定将黄渤海区刺网休渔时间调整为6月1日12时至9月1日12时，东海区和南海区刺网休渔政策暂不变更，并公布了调整后的海洋伏季休渔规定。2014年伏季休渔在即，为做好相关工作，经商中国海警局，现提出要求如下。

**一、**加强组织领导，健全休渔管理机制。海洋伏季休渔制度是养护海洋生物资源、建设海洋生态文明、促进海洋渔业可持续发展的重要举措，是满足沿海捕捞渔民生计需要和实现渔区社会稳定的重要制度保证。沿海各级人民政府要进一步提高对实施海洋伏季休渔重要性的认识，各级渔业行政主管部门及其所属的渔政监督管理机构要将执行海洋伏季休渔制度作为贯彻落实《中国水生生物资源养护行动纲要》和《国务院关于促进海洋渔业持续健康发展的若干意见》（国发〔2013〕11号）的重要任务，不断建立健全地方政府统一领导、渔业主管部门具体负责、有关部门密切配合的休渔管理机制，确保各项休渔管理措施落到实处。

**二、**加大宣传力度，营造良好社会氛围。海洋伏季休渔制度自1995年实施以来，经过数次调整完善，已经成为我国最重要和最具影响力的渔业资源养护管理制度，取得了良好的生态效益、经济效益和社会效益。为继续保持和充分发挥伏休政策对资源养护的作用，提高社会各界保护海洋渔业资源的意识，各地要继续加大伏休宣传力度，充分运用广播、电视、报纸、互联网、手机短信等多种形式，深入渔港、渔船、渔村、渔户，将调整后的伏休制度以及我部关于海洋捕捞渔具最小网目尺寸制度及禁用渔具规定进行广泛宣传，使资源养护政策家喻户晓、深入人心，争取广大渔民及社会各界的理解、支持和配合。要及时向当地人民政府反映休渔渔民情况，积极协助政府和有关部门妥善解决休渔期间困难渔民的生产生活问题，维护渔区社会稳定。

**三、**加强执法监管，依法维护休渔秩序。要严格按照《渔业法》《渔业捕捞许可管理规定》等法律法规和《农业部关于实施海洋捕捞准用渔具和过渡渔具最小网目尺寸制度的通告》及《农业部关于禁止使用双船单片多囊拖网等十三种渔具的通告》规定，组织调配各级渔政、港监、船检力量，明确分工，落实责任，强化休渔期间港口监管和海上检查工作。要继续加强北纬35度、北纬26度30分和闽粤交界附近海域及其他省际间交界海域的海上执法管理工作。要加强休渔期间渔运船的监管，坚决制止渔运船为非法作业渔船提供收购、运输、补给等后勤服务。要针对重点违规行为组织开展专项执法行动，设立并公布休渔管理举报电话，继续实施好举报奖励制度，充分发挥群众监督作用，动员社会力量，共同维护休渔秩序。机动渔船底拖网禁渔区线外侧海上伏休管理工作由中国海警局具体部署。

**四、**采取多种措施，养护水生生物资源。各地要充分利用伏季休渔的有利时机，组织实施好海洋生物资源的增殖放流。要根据增殖放流规划和年度实施方案，多方争取增殖放流资金投入，扩大增殖放流规模；要强化增殖放流管理，尽量安排休渔期间放流，提高增殖放流效果。要积极主动地介入海洋工程、海岸工程等涉渔建设项目环境影响评价工作，及时、妥善处理渔业水域污染事故和生态灾害突发事件。要继续推进海洋类型水生生物自然保护区和水产种质资源保护区的设立，加强保护区管理，做好海洋渔业资源调查监测和幼鱼资源保护工作，采取各种有效措施养护海洋生物资源及生态环境，建设海洋生态文明。

**五、**加强调查研究，不断完善伏休政策。近年来，社会各界对加强海洋渔业资源保护的要求和呼声不断提高。为此，我局在专题调研基础上，综合各方意见，于今年2月研究提出了2015年海洋伏季休渔调整方案（征求意见稿），在发文征求沿海各相关省级渔业主管部门和海区渔政局意见的同时，也在互联网上征求意见。考虑到伏季休渔制度是一项事关沿海渔民切身利益的重大资源养护政策，我部对该项制度的调整和变更始终非常慎重。此次计划调整的2015年伏季休渔制度涉及作业方式和渔民较多，影响范围较广，各地务必要高度重视、认真研究，充分利用伏休期间再次广泛征求渔民群众、基层执法部门、行业协会、科研单位的意见，并将有关意见建议及时反馈我局。

休渔结束后，各省、自治区、直辖市渔业行政主管部门要对海洋伏季休渔执行情况进行认真总结，并将总结情况于10月底前以正式文件报我部渔业渔政管理局。
