# 工业和信息化部关于刘茂先等3名同志职务任免的通知

## 工业和信息化部关于刘茂先等3名同志职务任免的通知（工信部任〔2014〕21号）

黑龙江省通信管理局：

工业和信息化部党组决定：

刘茂先兼任国家计算机网络与信息安全管理中心黑龙江分中心主任；

姚家康任黑龙江省通信管理局副局长（试用期一年）；

以上两名同志的任职时间自2014年1月24日党组会决定之日起计算；

免去姜延吉的黑龙江省通信管理局副局长、国家计算机网络与信息安全管理中心黑龙江分中心主任职务。

工业和信息化部

2014年2月24日
