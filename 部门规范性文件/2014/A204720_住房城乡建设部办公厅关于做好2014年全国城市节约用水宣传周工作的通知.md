# 住房城乡建设部办公厅关于做好2014年全国城市节约用水宣传周工作的通知

住房城乡建设部办公厅关于做好2014年全国城市节约用水宣传周工作的通知

（建办城函[2014]188号）

各省、自治区、直辖市住房城乡建设厅（市政管委、建委、水务局），新疆生产建设兵团建设局：

为贯彻落实《国务院关于加强城市基础设施建设的意见》（国发[2013]36号），以及近期习近平总书记关于“要深入开展节水型城市建设，使节约用水成为每个单位、每个家庭、每个人的自觉行动”的指示精神，各地要以全国城市节约用水宣传周为契机，进一步加大城市节水工作力度。今年全国城市节约用水宣传周（5月11日至17日）的主题是：全面推进城市节水，点滴铸就生态文明。现就有关事项通知如下：

**一、**充分认识开展节水型城市建设的重大意义

节水是解决城市水安全问题的重要举措，也是提升水环境承载能力、改善城市水环境的有效手段，对促进新型城镇化和生态文明建设具有重要意义。开展节水型城市建设，是落实城市节水工作职责的有效抓手。要充分发挥节水型城市的示范激励作用，带动其他城市共同落实有关节水制度，深入推动城市节水工作。今年降雨量较常年大幅下降的地区，更要强化城市节水，做好旱情防范工作，保障供水安全。

**二、**加大宣传力度，全面推进城市节水工作

（一）启动宣传周仪式

各地要至少选择2个城市在5月11日举行全国城市节约用水宣传周启动仪式，营造宣传周活动的热烈气氛，促进社会各界重视和公众参与，推动宣传活动深入开展。

（二）加大节水型城市建设的宣传力度

各地要围绕今年节水宣传周主题，精心组织，全面部署，充分利用各种媒介开展广泛、深入的宣传活动。重点宣传节水型企事业单位、节水型小区的典型事迹和经验，带动城市节水工作。普及节水知识，增强市民节水意识，倡导科学用水，营造全社会节水氛围。

为配合节约用水宣传周工作，我部委托中国城镇供水排水协会组织制定了城市节水宣传画图案，各地可登陆住房城乡建设部网站（www.mohurd.gov.cn）或者中国城镇供水排水协会网站（www.cuwa.org.cn）下载，自行组织印发和张贴。

（三）加快推进城市节水工作

一是强化城市节水规划引导，通过城市总体规划合理规划布局市政公用设施，落实节水要求，做好城市节水专项规划的编制和实施。二是加快城市节水相关市政公用设施建设，推动建筑中水回用和加快污水再生利用，严格控制供水管网漏损；积极推行低影响开发建设模式，建设具有自然积存、自然渗透、自然净化功能的海绵城市。三是住房城乡建设（城市节水）部门要会同发展改革等部门按照国家节水型城市考核标准，全面开展节水型居民小区、节水型单位、节水型企业建设活动，使节水成为每个单位、每个家庭、每个人的自觉行动。四是要充分发挥节水管理机构的作用，抓好城市节水专项规划目标任务和相关规章制度的落实，强化日常管理。

**三、**切实加强有关宣传活动的组织领导

各省级住房城乡建设（城市节水）主管部门负责组织辖区内城市围绕主题，有计划、有步骤地开展形式多样、内容丰富的宣传活动。各城市创建国家节水型城市领导小组和城市节水管理部门要发挥好行业协会等社会组织的作用，组织有关单位，落实好宣传周各项活动。

请各地按本通知要求，抓紧部署相关工作。

为扩大城市节水工作宣传和影响，有关城市节水工作典型事迹和先进经验，请各地审核汇总后于4月30日前报送中国城镇供水排水协会节水委员会，我部将择优在中国建设报等媒体进行宣传推广。
