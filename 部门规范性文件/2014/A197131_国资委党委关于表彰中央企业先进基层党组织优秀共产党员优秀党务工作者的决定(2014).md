# 国资委党委关于表彰中央企业先进基层党组织优秀共产党员优秀党务工作者的决定(2014)

## 国资委党委关于表彰中央企业先进基层党组织优秀共产党员优秀党务工作者的决定（国资党委组织〔2014〕141号）

各中央企业党委（党组）：

党的十八大以来，中央企业各级党组织和广大共产党员、党务工作者，坚持以邓小平理论、“三个代表”重要思想、科学发展观为指导，认真学习贯彻党的十八大、十八届三中全会精神和习近平总书记系列重要讲话精神，扎实开展党的群众路线教育实践活动，紧紧围绕全面深化改革、促进企业科学发展中心任务，立足岗位，奋发进取，在稳增长、转方式、调结构，提升企业核心竞争力，发展壮大国有经济方面发挥了重要作用。特别是在载人航天、探月工程、“蛟龙”号研制及海试任务等国家重点工程建设、重大专项工作中，在应对重大突发事件、完成急难险重任务中，各级党组织和广大共产党员、党务工作者不畏艰难，顽强拼搏，勇于奉献，充分发挥了政治核心作用、战斗堡垒作用和先锋模范作用，展现了共产党员的优良作风和时代风貌，涌现出一大批先进基层党组织、优秀共产党员和优秀党务工作者。

为鼓励先进，学习先进，激励各级党组织和广大共产党员、党务工作者在深化国资国企改革、实现“十二五”规划目标中创先争优、建功立业，国资委党委决定，对鞍钢集团公司鞍山钢铁矿业公司齐大山铁矿党委等144个先进基层党组织、褚利东等172名（含追授2名）优秀共产党员、丁荣昌等106名优秀党务工作者予以表彰，并分别授予“中央企业先进基层党组织”、“中央企业优秀共产党员”、“中央企业优秀党务工作者”称号。

国资委党委号召中央企业各级党组织和广大共产党员、党务工作者，要向受表彰的先进集体和优秀个人学习。学习他们坚定理想信念，忠诚党的事业，矢志不渝报效国家的不懈追求；学习他们始终以党和人民的利益为重，牢记宗旨，心系群众，淡泊名利，克己奉公的高尚品德；学习他们求真务实，爱岗敬业，勤勉尽责，攻坚克难的优良作风；学习他们解放思想，勇于实践，锐意改革，开拓进取的创新精神。国资委党委希望受到表彰的先进集体和优秀个人，要珍惜荣誉，加倍努力，再创佳绩。

中央企业各级党组织和全体共产党员，要更加紧密地团结在以习近平同志为总书记的党中央周围，高举中国特色社会主义伟大旗帜，团结带领广大职工群众，积极践行社会主义核心价值观，不断巩固扩大群众路线教育实践活动成果，真抓实干，开拓进取，努力推动国资国企改革发展再上新台阶，为中央企业保增长和国民经济稳增长，为全面建成小康社会、实现中华民族伟大复兴中国梦做出新的更大贡献。
