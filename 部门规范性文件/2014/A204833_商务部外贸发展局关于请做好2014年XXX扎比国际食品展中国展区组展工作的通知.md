# 商务部外贸发展局关于请做好2014年XXX扎比国际食品展中国展区组展工作的通知

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门，有关单位：

为支持农产品企业开拓国际市场，进一步扩大农产品出口，商务部定于2014年11月在阿联酋XXX扎比举办的XXX扎比食品展（SIAL MIDDLE EAST）上设中国展区（以下简称食品展）。食品展是商务部主办的非商业性境外展会（以下简称非商展）。

根据商务部内部职能调整，自2014年起，外贸发展局负责非商展的组织实施工作。考虑到项目延续性，外贸发展局将邀请中国食品土畜进出口商会作为合作承办单位，共同负责展会筹备等有关工作。请各地商务主管部门按照有关要求组织本地企业做好参展工作，现将有关事项通知如下：

**一、**时间： 2014年11月24-26日

**二、**地点：阿联酋XXX扎比国家展览中心（ADNEC）

**三、**规模：约300平方米

**四、**参展单位：相关的农产品及食品企业。

**五、**展品范围：休闲食品、非酒精类饮料，茶、咖啡、乳制品、奶制品及蛋制品、肉类及肉类制品、新鲜及脱水水果和蔬菜、甜食类、坚果类、罐头食品、食用油、速食类、海产品等。

**六、**具体参展事宜将另行通知。
