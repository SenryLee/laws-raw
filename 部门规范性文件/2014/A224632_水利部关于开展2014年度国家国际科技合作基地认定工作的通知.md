# 水利部关于开展2014年度国家国际科技合作基地认定工作的通知

各有关单位：

根据科技部通知，科技部现已启动2014年度国家国际科技合作基地认定工作，详细内容见如下链接。请感兴趣的单位根据科技部通知要求认真做好申报材料编制工作，并于2014年6月11日（星期三）12:00前将申请材料函报我司（申请材料在科技部要求份数基础上再增加一份供我司存档），逾期不予受理。我司将根据申报情况择优报送科技部。
