# 国家核安全局关于同意CAP1000项目屏蔽电机主泵部分设计分析活动分包的复函

国核安函[2014]182号

沈阳鼓风机集团核电泵业有限公司：

你公司《关于对CAP1000项目设计分析活动进行分包的请示》（沈鼓核电发〔2014〕20号）收悉。经研究，我局同意你公司将三门二期、海阳二期、陆丰一期CAP1000屏蔽电机主泵项目部分设计分析活动（见附件）分包给具有相应设计资质的上海核工程设计研究院，并提出如下核安全管理要求：

**一、**沈阳鼓风机集团核电泵业有限公司作为民用核安全设备设计和制造单位应对本次CAP1000屏蔽电机主泵的设计承担全面责任。

**二、**上海核工程设计研究院作为CAP1000屏蔽电机主泵关键部件计算分析的分包方应对本次设计分包带来的质量影响承担技术责任。

**三、**沈阳鼓风机集团核电泵业有限公司及上海核工程设计研究院应根据核安全法规要求加强设计过程控制，按职责分工开展主泵关键部件的分析计算工作，并接受环境保护部华北核与辐射安全监督站的监督检查。

特此函复。

附件：可分包设计分析活动

## 可分包设计分析活动

一、CAP1000反应堆冷却剂泵抗震分析

CAP1000反应堆冷却剂泵地震工况下的受力分析及评定主泵在地震期间的惰转停机特性。

二、CAP1000反应堆冷却剂泵壳和主封头压力边界分析

1. CAP1000反应堆冷却剂泵（RCP）泵壳和主密封组件压力边界部件最终设计结构的应力和热力分析；

2. 当反应堆冷却剂系统瞬变时，泵体、定子封头和密封焊缝、轴承水电阻测温装置、轴承水出口接管、定子壳和法兰、C密封环和连接焊缝、定子端环、主法兰螺栓和螺母的应力和疲劳分析。

三、CAP1000反应堆冷却剂泵安全相关部件分析

1. 叶轮、导叶应力与疲劳分析；

2. 叶轮地震分析；

3. 叶轮超速分析；

4. 吸入导管和吸入导管帽螺钉计算分析；

5. 热屏帽螺钉联接安全性分析。

其中，叶轮及其固定螺栓和导叶等零部件的分析在沈阳鼓风机集团核电泵业有限公司（以下简称沈鼓）完成。沈鼓提供模型和载荷，上海核工程研究设计院派遣人员到沈鼓与沈鼓人员共同完成应力与疲劳分析、地震分析和超速分析。
