# 国家测绘地理信息局关于做好2014年测绘地理信息行政执法工作的通知

## 国家测绘地理信息局关于做好2014年测绘地理信息行政执法工作的通知（国测法发〔2014〕3号）

各省、自治区、直辖市测绘地理信息行政主管部门：

为了认真贯彻落实2014年全国测绘地理信息局长会议要求，深入推进测绘地理信息行政执法工作，进一步提升全国测绘地理信息系统行政执法能力，现就有关工作通知如下：

**一、**充分认识加强测绘地理信息行政执法工作的重要意义

《国务院办公厅关于促进地理信息产业发展的意见》（国办发〔2014〕2号）（以下简称意见）对测绘地理信息行政执法工作提出了新要求，《意见》指出，要“依法严厉打击非法获取、处理地理信息行为”。2014年全国测绘地理信息局长会议明确要求，各级测绘地理信息行政主管部门“要进一步加大监督执法力度，扩大监督执法范围，提高监督执法频次。完善监督执法方式和手段，提升联合执法合力”。

近年来，我国测绘地理信息产业快速发展，产业规模不断扩大，服务领域不断拓宽。与此同时，市场主体多元化、服务模式多样化、应用服务社会化，也使得市场监管难度增大，违法违规、不正当竞争等行为时有发生，对行政执法工作提出了新的挑战。当前测绘地理信息行政执法工作面临着执法力度不够、手段比较单一、技术相对落后、装备配备不足的现状，难以满足新形势下行政执法工作的需要。因此，各级测绘地理信息行政主管部门必须进一步增强做好行政执法工作责任感和使命感，把加强和改进行政执法作为一项重要工作，予以高度重视，采取有力措施，促进行政执法各项工作扎实有效推进。

**二、**依法扩大执法范围，提高监督执法频次

各级测绘地理信息行政主管部门要不断加大执法工作力度，采取有效措施，依法扩大执法范围，提高监督执法频次，严厉打击各类测绘地理信息违法行为。

一是依法履行职责，扩大监督执法范围。进一步扩大监督执法的覆盖面，特别是对新兴测绘地理信息领域实施有效监管；实现市场活动全程监管，尤其是对测绘地理信息项目招投标以及市场交易过程中的不正当竞争行为加强监管；严格按照现有的法律法规从事监督执法活动，确保法律法规有效执行。

二是加强日常监管，提高监督执法频次。要建立健全日常监管长效机制，采取专项执法、重点执法、定期执法相结合的方式，加大检查频次。下移执法工作重心，充分发挥市、县两级测绘地理信息行政主管部门贴近单位，掌握具体情况的优势，加强日常监管和执法活动。

三是完善执法手段，实现执法关口前移。将执法重点从事后处罚前移至事前监督，通过资质巡查、信用评价等方式，对有违法记录或不诚信行为的企业实施重点监控，及时发现制止违法行为。进一步向测绘单位做好宣传和服务，增强守法意识。

四是整合执法力量，建立联合执法机制。在现有工作基础上，继续深化与相关部门的联合执法工作机制。逐步推行局内综合执法机制，统筹协调各类测绘行政执法活动，整合执法力量，提高执法效果。

**三、**加强执法能力建设，提升行政执法水平

各级测绘地理信息行政主管部门要加强行政执法制度建设，进一步落实行政执法责任制，建立健全执法评议考核机制和行政执法错案追究制度。规范行政执法自由裁量权，压缩执法权力的弹性空间。开展行政执法职责、执法流程、执法文书标准化建设，规范具体执法行为。

《测绘地理信息行政执法证管理办法》（国土资源部令第58号）将于7月1日起施行。各级测绘地理信息行政主管部门要按照国家局《关于贯彻实施〈测绘地理信息行政执法证管理办法〉的通知》（测办〔2014〕28号）要求，开展行政执法人员培训考核，建立完善行政执法人员岗前培训、日常培训、轮训的常态化工作机制。做好测绘地理信息行政执法管理信息系统启用和执法证的申领、审查和管理工作，确保执法证换证工作顺利实施。

各级测绘地理信息行政主管部门要为行政执法工作提供必要保障，将行政执法经费纳入财政预算，充实执法队伍力量，配备必要的执法装备，满足现场执法办案、调查取证需要。

国家测绘地理信息局
