# 财政部金融司关于印发外国政府贷款工作信息的通知(2014)

财政部金融司关于印发外国政府贷款工作信息的通知

（财金便函〔2014〕61号）

各省、自治区、直辖市、计划单列市财政厅（局），新疆生产建设兵团财务局：

为进一步加强外国政府贷款管理，及时通报工作进展，便于有关单位掌握主要国别贷款的最新要求，我们整理汇总了外国政府贷款的有关工作信息。请结合你地区实际情况，做好贷款管理工作。
