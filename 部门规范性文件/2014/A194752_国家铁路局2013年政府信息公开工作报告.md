# 国家铁路局2013年政府信息公开工作报告

国家铁路局2013年政府信息公开工作报告

（2014年3月）

本报告根据《中华人民共和国政府信息公开条例》和《国家铁路局政府信息公开实施办法》编制。本报告包括概述、主动公开政府信息情况、依申请公开政府信息情况、政府信息公开的收费情况、因政府信息公开申请行政复议或提起行政诉讼的情况、工作中存在的主要问题及改进措施等。本报告的电子版可在国家铁路局网站（www.nra.gov.cn）查阅或下载。如对本报告有疑问，请与国家铁路局联系（通信地址：北京市复兴路6号院国家铁路局政府信息公开办公室；邮编：100891；联系电话：010-51897601；电子邮箱：xxgk@nra.gov.cn）。

**一、**概述

2013年中央决定实行铁路政企分开改革。3月14日第十二届全国人民代表大会第一次会议批准《国务院机构改革和职能转变方案》，3月21日国务院办公厅印发《国家铁路局主要职责内设机构和人员编制规定》（国办发〔2013〕21号），7月11日国家局召开第一次局机关干部大会，原铁道部机关分流到国家铁路局机关的公务员陆续到位，开始边组建边履职。局党组从建局之初就高度重视政府信息公开工作，按照国务院有关要求，结合国家铁路局职责定位和工作实际，多次专题研究信息公开工作，成立了国家铁路局政府信息公开工作领导小组，协调推进政府信息公开的重点工作，设立了政府信息公开办公室，制定了《国家铁路局政府信息公开实施办法》（国铁综〔2013〕27号），明确了政府信息公开工作职责和公开范围、方式、程序以及监督保障机制等事项。同时，建立了国家铁路局新闻发言人制度，聘请专家加强政策解读工作。考虑铁路改革的实际和搭建政府信息公开平台的需要，局党组积极推动新建国家铁路局政府网站工程，在国家有关部门大力支持下，用了近半年时间完成了网站工程立项、可研批复、政府采购、网页设计、内容收集等各项工作，2014年1月6日国家铁路局政府网站正式开通运行。

**二、**主动公开政府信息情况

在抓紧建设政府网站的同时，国家铁路局通过在交通运输部网站开设专栏公布政府信息。

一是公开监管履职的重要文件，包括国家铁路局、地区铁路监督管理局内设机构、主要职责和人员编制，国家铁路局工作规则、国家铁路局政府信息公开实施办法等。

二是公开行政审批事项，在网上公布了国务院先后取消的两批铁路行政审批项目，对保留的行政许可项目名称、依据、程序、期限、申请行政许可需要提交的全部材料目录、许可办理情况、联系方式等，全部在网上公开，并提供网上下载行政许可申请书表格。

三是贯彻“开门立法”精神，网上公开铁路规章草案，包括《铁路机车车辆设计生产维修进口许可办法》、《铁路运输安全设备生产企业认定办法》、《铁路机车车辆驾驶人员资格许可办法》、《违反＜铁路安全管理条例＞行政处罚实施办法》等四件规章草案，通过政府网站公开征求社会公众意见。

四是加强政策法规解读，对新出台的《铁路安全管理条例》以答新华社记者问形式进行解读宣传，并在网上发布条例释义，帮助公众理解政策法规的内涵和要求。

五是开设互动邮箱，接受公众意见建议和投诉咨询，积极回应社会关切。

**三、**依申请公开政府信息情况及其他情况

2013年国家铁路局共受理政府信息公开申请4件，全部为信函形式申请。上述申请已全部在法定答复期限内办理完结。对依申请公开政府信息的暂未收费。没有因信息公开申请行政复议或提起行政诉讼。

**四、**存在问题及改进措施

2013年的下半年，新设立的国家铁路局处于边组建边履职的特殊阶段，政府信息公开的相关工作制度、组织机构、工作队伍、公开平台、办事程序等各方面都在建立完善的过程中，信息公开工作刚刚起步。2014年，国家铁路局将认真贯彻落实中央关于全面深化改革的决策和国务院关于加强政府信息公开工作的要求，从提高执政水平和能力、推进国家治理体系和治理能力现代化的高度，充分认识做好新形势下政府信息公开工作的重要性，着力从以下几个方面改进提高：

1．发挥政府网站在信息公开中的主渠道作用。在全面履职的基础上，充分发挥政府网站作用，全面加强信息公开：一是进一步推进铁路行政审批信息公开，公开国家铁路局行政审批事项清单，公开权力运行流程，接受社会监督；二是推进财政资金信息公开，依法公开部门预算决算以及所有财政拨款安排的“三公”经费等信息，让“财政资金”在阳光下运行；三是加强公共资源配置和公共服务信息公开，公开政府采购信息，逐步建立政府采购预算、执行、结果全过程信息公开制度；推进工程建设项目信息公开，深化项目监管、招标、投标等信息公开工作；推动科技管理和项目经费信息公开，建立健全科研项目和资金管理信息公开制度；四是加强铁路行业监管信息公开，依法公开安全生产事故信息，建立预警预防信息发布和事故应急处置救援信息公开机制；加强监督检查和行政处罚信息发布，实行违法企业公告制度，健全完善网上投诉举报受理制度。

2. 认真做好依申请公开工作。规范依申请公开办理工作，完善受理、审查、处理、答复以及保存备查等各个环节的流程，依法依规满足人民群众的特殊信息需求。提升依申请公开服务能力，畅通受理渠道，提高工作效率，方便公众申请。改进完善申请办理方式，加强与申请人沟通，做好解疑释惑工作，引导公众正确行使申请权和救济权。

3．健全完善工作制度。一是进一步优化主动公开和依申请公开的工作机制，建立健全信息公开工作考核、评议制度，完善信息公开监督保障机制。二是进一步优化信息公开指南，细化公开范围和目录，方便公众查询和获取。三是健全完善新闻发言人工作制度，通过新闻媒体加强行业监管履职过程中的信息发布。四是建立健全政务舆情收集、研判、处置和回应机制，密切关注监管履职过程中的重要政务舆情，及时发现、研判需要回应的相关舆情和热点问题，重视客观、权威的信息发布，通过信息公开消除不实传言和误解。五是完善政府网站互动类栏目回复办理程序，办好公众互动类栏目，及时回应公众关切。六是加强政府信息公开工作人员的培训，不断提高相关工作人员的思想认识、政策水平和业务素质。
