# 国家旅游局办公室、国家开发银行办公厅关于印发2014全国优选旅游项目名录的通知

## 国家旅游局办公室、国家开发银行办公厅关于印发2014全国优选旅游项目名录的通知（旅办发〔2014〕175号）

各省、自治区、直辖市旅游局（委），国家开发银行各分行：

根据《关于做好全国优选旅游项目推荐工作的函》（旅规财函〔2014〕86号）相关要求，综合考虑项目成熟度、市场前景和开工条件，国家旅游局与国家开发银行共同组织专家遴选了135个旅游项目，确定为《2014全国优选旅游项目名录》。现将有关事项通知如下：

**一、**各省级旅游部门和当地国开行分行要抓紧对接，积极推动优选项目建设，帮助项目单位解决投融资过程中的实际困难，密切跟踪优选项目进展情况，为优选项目的招商和融资做好服务工作。旅游发展基金贷款贴息资金将优先支持获得贷款的优选项目。

**二、**国开行各分行要将优选项目纳入各分行项目储备库，积极开展项目评审工作，促使优选项目顺利推进，在政策允许范围内给予优先支持。

**三、**请各省级旅游部门和国开行各分行保持沟通，年底前将优选项目落地等相关情况报送国家旅游局和国家开发银行。
