# 国家质量监督检验检疫总局公告2014年第7号――关于公布2013年烟花爆竹等5类产品质量国家监督专项抽查结果的公告

## 国家质量监督检验检疫总局公告（2014年第7号）

关于公布2013年烟花爆竹等5类产品质量国家监督专项抽查结果的公告

根据《中华人民共和国产品质量法》和《产品质量监督抽查管理办法》的规定，2013年，质检总局对烟花爆竹、LED照明产品、车用汽油、车用柴油、机械压力机5类产品质量进行了国家监督专项抽查，现将抽查结果予以公布（详见附件）。

烟花爆竹共抽查了河北、安徽、江西、山东、湖北、湖南、广西、海南、重庆、四川、贵州、陕西12个省、自治区、直辖市254家企业生产的360批次产品，主要依据GB 10631-2013《烟花爆竹 安全与质量》、GB 19593-2004《烟花爆竹 组合烟花》等标准要求，对标志、包装、外观、引燃时间、引燃装置、手持部位、漂浮物和雷弹、部件牢固度、结构与材质、结构尺寸、药种、药量、禁用药物、燃放缺陷、其他燃放性能、计数误差、烧成率17个项目进行了检验，结果有62家企业生产的75批次产品不符合标准要求。

LED照明产品共抽查了北京、山西、辽宁、上海、江苏、浙江、福建、湖北、广东、四川10个省、直辖市82家企业生产的108批次LED照明产品，产品范围包括LED筒灯和普通照明用自镇流LED灯。主要依据GB 7000.1-2007《灯具 第1部分：一般要求与试验》和GB 24906-2010《普通照明用50 V以上自镇流LED灯 安全要求》等标准要求，分别对结构、外部接线和内部接线、防触电保护、耐久性试验、耐热、耐火、标志、互换性、机械强度、电源端子骚扰电压、辐射电磁骚扰、谐波电流等项目进行了检验，结果有21家企业生产的22批次产品不符合标准要求。

车用汽油共抽查了北京、上海、江苏3个省、直辖市63家企业生产或销售的70批次产品，主要依据DB 11/238-2012《车用汽油》、DB 31/427-2013《车用汽油（沪Ⅴ）》、DB 32/2354-2013《车用汽油（苏Ⅴ）》等标准要求，对研究法辛烷值、抗爆指数、铅含量、铁含量、锰含量、密度、馏程、溶剂洗胶质含量、未洗胶质含量、诱导期、硫含量、铜片腐蚀、水溶性酸或碱、机械杂质及水分含量、博士试验、氧含量、甲醇含量、苯含量、烯烃含量、芳烃含量、烯烃＋芳烃含量21个项目进行了检验，结果全部合格。

车用柴油共抽查了北京、上海2个直辖市30家企业生产或销售的30批次产品，主要依据GB 19147-2013《车用柴油（Ⅴ）》、DB 11/239-2012《车用柴油》等标准要求，对色度、硫含量、酸度、铜片腐蚀、水分、机械杂质、运动粘度（20℃）、凝点、冷滤点、闪点（闭口）、十六烷值、十六烷指数、馏程（50%回收温度）、馏程（90%回收温度）、馏程（95%回收温度）、密度（20℃）、10％蒸余物残炭、灰分18个项目进行了检验，结果全部合格。

机械压力机共抽查了江苏、浙江、山东、广东4个省60家企业生产的60批次产品，主要依据GB 27607-2011《机械压力机 安全技术要求》等标准要求，对机械压力机的制动器和离合器、分转式离合器压力机的基本要求、液压和气动系统一般要求、滑块装模高度调整和行程调节、整转式离合器压力机的基本要求、安全防护措施的选择、所有人员的防护、人工手动上下料的防护措施、闭合模具、固定式防护装置、光电保护装置、双手操纵装置、安全距离、电机和离合器的联锁、单次行程装置、解救被困人员、脚踏操作与双手操作、超载保护装置、控制和监控功能、分转式离合器压力机的冗余和监控、抑制、选择开关、隔离开关、位置开关、控制装置、允许滑块运动、防止离合器重新结合的装置、电气危险、噪声限值，以及联锁、可控和超前开启的防护装置30个项目进行了检验，结果有51家企业生产的51批次产品不符合标准要求。此外，山东淄博标鑫冲压机械厂、淄博东驰机床制造有限公司2家企业违法拒绝接受监督抽查。

针对本次抽查中发现的质量问题，质检总局已通报相关部门，并责成相关省（自治区、直辖市）质量技术监督部门，依据法律法规的规定，对抽查不合格产品及其生产企业、拒检企业进行处理。
