# 国家旅游局关于开展旅游信息化机构队伍和12301旅游服务热线情况调研的函

旅信函〔2014〕17号

各省、自治区、直辖市和新疆生产建设兵团旅游局（委）信息中心：

根据工作需要，遵照局领导指示，在各省级旅游局信息中心提交旅游信息化工作情况的基础上，就旅游信息化机构队伍和12301旅游服务热线情况进行专项调研。有关事项和要求如下：

一、本次调研重点以省级为主，并委托省级旅游部门信息中心对所辖地市级、县区级情况进行调研并汇总情况。

二、请各单位安排专人认真如实填写所附调研表，在完成本地区（系统）调研的基础上认真填写汇总表（所有表格均请从国家旅游局官网下载使用），经主要负责同志审核后，于2014年12月5日前将电子版以电子邮件方式发至国家旅游局信息中心。

三、我们在汇总各地情况后，以合适方式将有关情况通报各省级旅游局信息中心，并注意做好相关信息的保密工作。

四、调研填报过程中遇到问题，请通过电子邮件、或电话方式及时与我们联系。
