# 人力资源和社会保障部办公厅关于公布2014-2015年度劳动出版“技能雏鹰”奖学金获奖名单的通知

人社厅函〔2014〕471号

有关省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）：

根据《人力资源社会保障部办公厅关于做好2014-2015年度劳动出版“技能雏鹰”奖学金评定发放工作的通知》（人社厅函〔2014〕205号）要求，经有关技工院校推荐、各地人社部门审核、部奖学金评审委员会核定并公示，共评选出2014-2015年度劳动出版“技能雏鹰”奖学金获奖者200名（名单见附件），奖学金标准为每人3000元。

希望获得奖学金的同学牢固树立敬业守信、精益求精的职业精神，再接再厉、戒骄戒躁、奋发图强，不断学习新知识、新技能，走技能就业、技能成才之路，为实现中华民族伟大复兴的中国梦贡献力量。

附件：2014-2015年度劳动出版“技能雏鹰”奖学金获奖名单

人力资源社会保障部办公厅

2014年12月15日
