# 国家外国专家局关于实施“引智青年志愿者行动计划”的通知

各省、自治区、直辖市外国专家局，各有关高校、企业引智归口管理部门：

为大力弘扬“奉献、友爱、互助、进步”的志愿服务精神，培养青年引智干部服务社会的意识和实践能力，稳定外专系统干部队伍，加强干部队伍能力建设，服务引智工作大局，国家外国专家局拟实施“引智青年志愿者行动计划” （以下简称“计划”）。计划从全国外专系统和高校、企业、科研机构等重点引智单位招募选拔150-200名青年志愿者，组成志愿为引智事业服务的团体，通过组织青年志愿者进行志愿服务活动，为我国引智事业提供志愿服务。现将具体工作通知如下：

**一、**组建方式

1.由各省（区、市）外专局负责同志、各高校、企业引智归口管理部门负责同志负责，做好各省（区、市）外专系统青年的动员工作。

2.各单位对申请加入的青年进行资格审查，资格审查通过者填写个人登记表，报送国家外国专家局“引智青年志愿者行动计划”秘书处。

3.国家外国专家局机关团委负责相关活动的组织。

**二、**志愿者行动计划任务

1. 选拔优秀青年志愿者参与由国家外国专家局主办的大型会议和国际人才交流活动的具体工作，包括翻译、联络、组织、宣传等；

2. 协助我局人事司及相关部门选拔优秀青年志愿者以各种形式短期帮助工作、上挂锻炼等；

3. 协助我局人事司及相关部门选拔优秀青年志愿者加入我局派出学习与驻外工作的人员储备库；

4. 为引智青年对外交往工作提供意见、建议和短期培训，加强引智青年干部队伍之间的交流，为能力建设搭建平台；

5. 在志愿者服务期间，做好引智事业的地区传播、行业传播以及各种新媒体的传播，扩大引智工作的影响力；

6. 其他国家外国专家局交办的任务。

**三、**志愿者要求

1. 年龄在25-40岁之间，具有大学本科以上学历，中共党员或共青团员，政治立场坚定；

2. 有参与引智工作，特别是国际交流的积极意愿，有一定外事能力和经验；

3. 有较强的口头或文字表达能力；

4. 熟练掌握一门外语（英语、德语、日语、俄语等语种优先考虑），了解国际政治、经济、国际关系、计算机等领域的相关知识。

**四、**机构设置

（一）领导机构

1. 牵头人1名，由局机关党委书记担任。

2. 协调人3名，由局机关党委及相关司室负责人担任。

（二）工作机构和工作机制

1．由局机关团委负责实施，下设秘书处。局机关团委书记为秘书处负责人，负责具体的组织协调事务。

2．各省（区、市）可设联络人2名，联络人如因工作调整不再负责此项工作时，需及时告知秘书处。

**五、**组建时间安排

1．申请上报时间：2014年2月12日-3月10日

2．计划启动仪式：2014年3月底（具体时间另行通知）

**六、**其他

请有关省、区、市外专局和高校、企业引智归口管理部门，按照通知要求推荐人员，并于2014年2月21日前将“引智青年志愿者推荐表”和报名汇总表传真并寄至国家外国专家局“引智青年志愿者行动计划”秘书处。
