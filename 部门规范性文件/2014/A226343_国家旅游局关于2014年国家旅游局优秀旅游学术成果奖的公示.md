# 国家旅游局关于2014年国家旅游局优秀旅游学术成果奖的公示

2014年国家旅游局优秀旅游学术成果奖评审工作于近期结束。经国家旅游局批准，本年度共37项成果获奖。其中，专著类成果奖11项，学术论文类成果奖22项，研究报告类成果奖3项，教材类成果奖1项。现将结果予以公示，公示期为11月20日—11月26日。

公示期间，如有异议，请以书面或口头形式与国家旅游局优秀旅游学术成果评奖秘书处（中国旅游研究院科研管理部）联系。

联系人：夏少颜、贾媛媛

电话： 85166003，85166018

E-mail：research@cnta.gov.cn

附件：《2014年国家旅游局优秀旅游学术成果奖获奖名单》
