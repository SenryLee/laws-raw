# 国家卫生和计划生育委员会办公厅、中国残联办公厅关于开展2014年全国“爱眼日”活动的通知

## 国家卫生和计划生育委员会办公厅、中国残联办公厅关于开展2014年全国“爱眼日”活动的通知（国卫办医函〔2014〕396号）

各省、自治区、直辖市卫生计生委（卫生厅局）、残联，新疆生产建设兵团卫生局、残联：

2014年6月6日是第19个全国“爱眼日”，今年“爱眼日”的活动主题为“关注眼健康，预防糖尿病致盲”。糖尿病是全球性的重大公共卫生问题，也是威胁我国居民健康的主要慢性疾病。糖尿病眼部并发症如糖尿病视网膜病变等会严重损害视力健康，是目前主要的致盲原因之一。加强健康宣教，提高广大群众对糖尿病眼部并发症的认识和重视，有效控制血糖，及早、定期进行眼科检查，可以有效预防、延缓糖尿病导致的视力损害。

各级卫生计生行政部门和残联要以“爱眼日”为契机，充分发挥政府主导作用，认真组织好本次全国“爱眼日”宣传活动。各地要根据本地区实际情况，将预防糖尿病致盲的宣传活动与日常眼科、内分泌科诊疗工作结合起来，通过义诊、健康讲座以及广播电视、互联网宣传等方式传播眼保健知识和国家防盲治盲政策，积极引导广大群众，特别是糖尿病患者关注眼健康，采取有效措施，积极防治糖尿病眼部并发症。

请各省级卫生计生行政部门和残联于6月20日前将本地区相关活动开展情况报国家卫生计生委和中国残联。
