# 水利部关于水资源论证报告书评审专家名单的公示

根据《关于开展水资源论证报告书评审专家选聘工作的通知》（办资源〔2013〕236号），我部组织各流域机构、各省（自治区、直辖市）水利（水务）厅（局）、部直属有关单位和全国有关行业协会开展了新一轮水资源论证报告书评审专家选聘工作。经过严格评审，确定了水利部水资源论证评审专家库的专家人选。现将专家名单予以公示（见附件）。

公示时间：2014年10月29日至11月6日
