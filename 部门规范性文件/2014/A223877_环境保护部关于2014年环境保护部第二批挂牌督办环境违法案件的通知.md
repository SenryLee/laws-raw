# 环境保护部关于2014年环境保护部第二批挂牌督办环境违法案件的通知

环办[2014]107号

江苏省、山东省、河南省、广东省、湖南省、四川省、云南省环境保护厅：

2014年9月，我部组织各环境保护督查中心对16个省（区、市）环保专项行动督查时发现，部分产业集聚区和工业园区环境问题集中，部分企业存在违反建设项目环境保护管理规定、污染治理设施不配套或不正常运行、超标排放、危险废物管理不规范等问题。

根据《环境违法案件挂牌督办管理办法》，我部决定对广东省广州市花都区石灰厂和铸造企业群、云南省文山马塘工业园区、河南省煤气（集团）有限责任公司义马气化厂、江苏沙钢集团锡兴特钢有限公司、山东鲁维制药有限公司、湖南省怀化市3家钒工业企业、四川翔升钢结构工程有限公司、云南省砚山县滇常铁合金有限责任公司、云南楚雄矿冶有限公司牟定郝家河铜矿环境违法案件挂牌督办。

请你们按照督办要求（见附件）认真抓好各项工作。在挂牌督办事项完成后，将解除挂牌督办书面申请（附相关材料）报送我部。我部各环境保护督查中心负责核查挂牌督办环境违法案件的整改情况。同时，请你们指导、督促地方政府和环保部门加大执法监管力度，做到查处到位、整改到位、责任追究到位，及时向社会公布案件查处情况，接受社会监督。

## 环境违法案件基本情况及督办要求

一、广东省广州市花都区石灰厂和铸造企业群环境违法案

基本情况：广州市花都区70余家石灰厂，普遍存在环保手续不齐全、无任何脱硫除尘设施、原料和废渣无抑尘措施露天堆放等问题，其中建丰石灰厂未经竣工环保验收擅自投产，拒不执行花都区环保局责令其4个石灰窑停止生产的要求，废气无组织排放，原料和废渣露天堆放。该区茶塘村区域51家小型铸造企业主要设备为国家明令淘汰的冲天炉，大部分仍在非法生产，在道路旁随意倾倒炉渣。

督办要求：督促当地政府对石灰厂和铸造企业进行全面排查和综合整治，依法取缔落后工艺设备。责成当地环保部门依法责令违法建设项目停止生产，未经批准不得恢复生产，逾期不执行处理处罚要求的，依法申请法院强制执行；限期改正污染物处理设施不正常运行和固体废物处理处置不规范问题，处以罚款。在挂牌督办期间，我部暂停审批花都区除民生工程、节能减排、生态环境保护和基础设施建设以外的项目，省、市环保部门应同步暂停审批。

督办期限：请于2015年5月底前完成挂牌督办事项。

二、云南省文山马塘工业园区环境违法案

基本情况：云南省文山马塘工业园区未按照规划环评要求建设污水处理厂、事故应急池、中水储存池等环境基础设施；未依法组织规划环境影响的跟踪评价。园区内33家石材企业中有32家未经竣工环保验收擅自投产，19家工业企业中4家未批先建。其中文山市金仪铟业科技有限责任公司3台回转窑和配套压滤设备未批先建，烟气碱洗废水蒸发结晶装置长期闲置，厂区环境差；云南文冶有色金属有限公司未按环评要求建设破碎、筛分工段布袋收尘装置，水淬渣储存场未采取有效的防渗措施，环境管理不规范；云南文山铝业有限公司锅炉脱硫设施不正常运行，在线监测设施维护不到位，循环流化床锅炉无脱硝装置，氮氧化物排放浓度难以达标，环境管理薄弱。

督办要求：督促当地政府对园区石材企业和工业企业进行全面排查和综合整治；责令园区限期完善环境基础设施，及时组织跟踪评价。责成当地环保部门依法责令违法建设项目停止生产，未经批准不得恢复生产，逾期不执行处理处罚要求的，依法申请法院强制执行；依法责令超标排放的企业限期治理，责令污染处理设施不正常运行的企业限期改正，并处以罚款。在挂牌督办期间，我部暂停审批文山市除民生工程、节能减排、生态环境保护和基础设施建设以外的项目，省、市环保部门应同步暂停审批。

督办期限：请于2015年5月底前完成挂牌督办事项。

三、河南省煤气（集团）有限责任公司义马气化厂环境违法案基本情况：该厂1号烟囱冒黑烟，1、2号机组除尘设施无组织

排放严重；中控系统及烟气自动监控系统均无监测数据。督办要求：依法责令该厂限期改正污染物处理设施不正常运行的问题，并处罚款；督促该厂规范内部环境管理，确保污染物稳定达标排放。

督办期限：请于2015年5月底前完成挂牌督办事项。

四、江苏沙钢集团锡兴特钢有限公司环境违法案

基本情况：该公司4台33平方米烧结机属于落后设备未按期淘汰，其中3台仍在生产，无脱硫设施，未安装在线监测设备；矿料露天堆放。

督办要求：督促当地政府依法取缔落后工艺设备；督促该公司规范内部环境管理，确保污染物稳定达标排放。

督办期限：请于2015年5月底前完成挂牌督办事项。

五、山东鲁维制药有限公司环境违法案

基本情况：该公司自备电厂1台130吨锅炉于2012年建成并投入生产，无环保审批手续；1台130吨锅炉、2台75吨锅炉、2台 35吨锅炉氮氧化物超标排放；污水处理站未按技改环评要求建设相关工艺设备，私自挖设2个氧化塘贮存处理后的废水。

督办要求：依法责令该公司违法建设项目停止生产，未经批准不得恢复生产，逾期不执行处理处罚要求的，依法申请法院强制执行；限期治理超标排放的问题，并处以罚款；责令该公司严格落实环境影响评价文件及批复的各项要求，发生重大变动的应当重新报批，对擅自挖设的氧化塘进行妥善处理。

督办期限：请于2015年5月底前完成挂牌督办事项。六、湖南省怀化市3家钒工业企业环境违法案

基本情况：湖南省怀化市钒冶炼行业污染严重，当地环保部门多次组织开展综合整治，但部分企业仍不能实现稳定达标排放。其中湖南新宏大钒业有限公司未按要求完成“三同时”验收，总排口出水氯化物和氨氮超标，雨污分流不完善，初期雨水进入地下溶洞，环境安全隐患突出；沅陵县友诚实丰矿业有限公司总排口出水氯化物浓度超标10.36倍、氨氮超标13.8倍，总排放口不规范、无标识标牌，未建设自动监控设施；沅陵县菩恩矿业有限责任公司总排口出水氯化物超标14.45倍，氨氮超标4.14倍。

督办要求：督促当地政府对钒冶炼行业进行全面排查和综合整治。依法责令违法建设项目停止生产，未经批准不得恢复生产，逾期不执行处理处罚要求的，依法申请法院强制执行；限期治理超标排放的问题，并处以罚款。督促企业规范内部环境管理，确保污染物稳定达标排放。

督办期限：请于2015年5月底前完成挂牌督办事项。

七、四川翔升钢结构工程有限公司环境违法案

基本情况：该公司于2008年建成投产，至今未办理环评审批手

续；喷漆工序未配套建设漆雾收集处理设施；危险废物漆渣（HW12）露天贮存，无“三防”措施，不能提供漆渣转运联单和相关审批手续；抛丸机粉尘收集设施不完善，现场粉尘堆积严重。

督办要求：依法责令该公司违法建设项目停止生产，未经批准不得恢复生产，逾期不执行处理处罚要求的，依法申请法院强制执行；限期改正污染物处理设施不配套、危险废物管理不规范等问题，并处以罚款。督促该公司规范内部环境管理，确保污染物稳定达标排放。

督办期限：请于2015年5月底前完成挂牌督办事项。八、云南省砚山县滇常铁合金有限责任公司环境违法案

基本情况：该公司未按环评要求建设生活污水二级处理设施，生活污水直接排放至厂外水渠；生产废水管道泄漏严重，部分生产废水排放至厂外水渠，不符合环评提出的生产废水循环使用要求； 6300KVA矿热炉收尘系统不完善，烟尘无组织排放严重；厂区存在“跑冒滴漏”现象，部分原料露天堆放，环境管理较差。

督办要求：依法责令该公司严格落实环境影响评价文件及批复的各项要求，发生重大变动的应重新报批；限期改正污染物处理设施不配套、不正常运行等问题，并处以罚款；督促该公司规范内部环境管理，确保污染物稳定达标排放。

督办期限：请于2015年5月底前完成挂牌督办事项。九、云南楚雄矿冶有限公司牟定郝家河铜矿环境违法案

基本情况：该企业未按深部采矿技改项目环评要求建设“絮凝沉淀+重金属化学沉淀”设施，矿井涌水仅进行自然沉淀后排放；未按环评要求收集、处理废石场淋滤水；未按环评要求建设事故应急池；尾矿库地下水未进行监测。

督办要求：依法责令该公司严格落实环境影响评价文件及批复的各项要求，发生重大变动的应重新报批；限期改正污染物处理设施不配套问题，并处以罚款；督促该公司规范内部环境管理，确保污染物稳定达标排放。

督办期限：请于2015年5月底前完成挂牌督办事项。
