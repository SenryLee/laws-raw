# 国家测绘地理信息局办公室关于印发国家测绘地理信息局机关2014年会议计划和调研计划的通知

## 国家测绘地理信息局办公室关于印发国家测绘地理信息局机关2014年会议计划和调研计划的通知（测办〔2014〕14号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司室：

为贯彻落实中央八项规定精神，规范会议组织管理，提高调研工作质量，经国家局局长办公会议审定，现将局机关2014年会议计划和调研计划印发给你们，并就有关事项通知如下：

**一、**严格执行计划，控制数量和规模

机关各司室要按照《国家测绘地理信息局会议管理办法》（国测办发〔2013〕13号）有关规定，坚持厉行节约、规范简朴、务实高效的原则，认真执行会议计划，不得突破会议规模、规格、会期、经费预算等各项指标。调研工作要根据确定的调研内容，紧密结合业务工作和基层工作实际，合理确定调研形式。为减少基层负担，每个调研组人数原则上应控制在4人以内。提倡联合调研和综合调研，不得在短期内对同一地区、同一单位重复进行调研。

要严格控制计划外会议，确因工作需要必须召开的，主办司室要按照局会议管理办法的规定，本着一事一批的原则进行请示，经局长办公会审定后方可召开。

对临时性小型会议，不列入会议计划管理，参会人员发生的交通、食宿等费用按差旅费报销。

**二、**加强组织管理，力求务实高效

机关各司室要按照会议计划，提早谋划，统筹安排，争取用一个会议解决多个问题，切实改进会风。要认真做好会议筹备组织工作，把握好会议主题和内容，制定详细可行方案，着力解决实际问题。会议方案、筹备情况、会议主报告等会议材料应提前10个工作日报局领导审示。

要认真做好调研组织管理工作，切实避免形式主义，突出重点，确保调研效果。各省（区、市）测绘地理信息行政主管部门要积极协助配合，并作好相关安排。调研组应在调研结束后15个工作日内提交调研报告，以供局工作决策参考。

机关各司室要认真抓好计划的落实，并在2014年12月底前，将会议计划和调研计划实施情况报局办公室。局办公室将对计划的落实情况进行督促检查，及时向局党组报告，并在2015年初进行通报。

国家测绘地理信息局办公室
