# 财政部国库司关于延长2014年5月份政府采购甲级代理机构资格认定工作期限的通知

财政部国库司关于延长2014年5月份政府采购甲级代理机构资格认定工作期限的通知

各有关代理机构：

按照《政府采购代理机构资格认定办法》（财政部令第61号）第二十二条规定，经部领导批准， 2014年5月份政府采购甲级代理机构资格认定工作延期十个工作日。预计将于2014年7月10日左右公示拟认定资格的政府采购代理机构名单，8月1日左右颁发甲级《资格证书》。5月份申请延续甲级资格的代理机构，在网上公告认定结果前，可以继续开展相关代理业务。

特此通知。

财政部国库司

2014年6月25日
