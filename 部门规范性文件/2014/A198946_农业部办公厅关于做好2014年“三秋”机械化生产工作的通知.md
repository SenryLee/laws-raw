# 农业部办公厅关于做好2014年“三秋”机械化生产工作的通知

## 农业部办公厅关于做好2014年“三秋”机械化生产工作的通知（农办机[2014]23号）

各省、自治区、直辖市及计划单列市农机（农业、农牧）局（厅、委、办），新疆生产建设兵团农业局，黑龙江省农垦总局：

大力推进秋收、秋种、秋整地机械化作业，对于夺取秋粮丰产丰收，实现全年农业生产目标具有重要意义。为贯彻落实中央关于抓好粮食生产的部署，高质量、高效率地组织好今年“三秋”机械化生产，现将有关要求通知如下。

**一、**加强组织领导，努力完成目标任务

今年“三秋”机械化生产工作的目标是：力争全国投入“三秋”生产的各类农业机械达到2900万台（套）；实现玉米机收水平超过55%，中晚稻机收水平超过80%，小麦机播水平稳定在86%以上，油菜、马铃薯、花生等农作物的秋收和秋冬种生产机械化水平进一步提高；确保秋季深松整地面积达到1亿亩。各地要把“三秋”机械化生产作为当前农机化工作的中心任务，加强组织领导，制定工作方案，细化目标任务，强化责任落实，狠抓措施到位。要努力提高农机具完好率、出勤率和作业效率，保障秋冬季农业生产顺利进行。

**二、**落实扶持政策，扎实开展各项准备

各地要加快今年购机补贴资金的实施进度，当前应重点向玉米收获机、水稻联合收割机、深松机、大中型拖拉机等重点机具倾斜，督促农机生产企业做好新机具的交机、安装和调试等工作，尽快在“三秋”生产中发挥作用。“三秋”大忙之前，要组织农机干部和技术人员深入乡村农户和田间场院，指导农机手对作业机具普遍进行一次检查、维修和保养，保证机具以良好的技术状态投入秋季作业。要采取集中辅导和分片定点相结合的方法开展技术培训，不断提高农机手的驾驶操作技能。要加强与公安、交通、供油企业等单位的配合，落实农机跨区作业的扶持政策，做好农机柴油供应。要协调农机生产企业和经销商做好配件供应和售后服务，履行农机产品“三包”服务承诺。

**三、**精心组织调度，推进秋季跨区作业

要密切关注天气变化和“三秋”生产进度，及时为机手和农户提供信息服务，加强机具的组织调度，推动机具合理流动和高效作业。针对今年部分地区可能出现的玉米成熟期偏晚、小麦秋种农时偏紧的情况，科学调配作业任务和机具，努力做到秋粮成熟一亩、收获一亩，土地腾茬一亩、播种一亩。在组织好水稻、玉米跨区机收的基础上，积极开展秋季农机跨区机播、深松整地等作业。积极引导农机合作社等农机社会化服务组织开展订单作业，严格执行农业技术要求和作业规范，努力提高“三秋”生产的组织化程度和作业质量。

**四、**立足抗灾救灾，大力推广先进技术

针对前期我国北方部分地区高温干旱和南方部分省份的低温阴雨，以及可能发生的病虫危害和秋季霜冻的影响，各地要牢固树立抗灾夺丰收的思想，组织专家制定分区域、分灾种、分作物的农机抗灾技术方案，因时因地落实好农机防灾减灾技术措施。要重点抓好东北的玉米、水稻和南方的中晚稻机收工作，切实发挥农业机械在抢农时、抗灾害的重要作用。要继续大力推广应用保护性耕作、秸秆还田、机械深松、精量播种、化肥深施、镇压保墒、节水灌溉、高效施药等节本增效新技术、新机具，积极推进农机与农艺融合、农机化与信息化融合，不断提高“三秋”农业机械化生产的科技水平。

**五、**依法开展监理，确保农机安全生产

“三秋”生产既是农机作业的高峰期，也是农机事故的易发期、多发期。各地要坚持“安全第一，预防为主，综合治理”的方针，进一步落实安全生产责任制，深入开展农机安全“打非治违”和“平安农机”“为农民服务”活动。要进一步加强农机安全教育，做好事故隐患排查治理，开展农机安全生产督导检查，预防重特大事故发生。要与安全监督、公安交通管理等有关部门密切配合，加强对违规发放牌证的治理力度，严格查处拖拉机和联合收割机无牌行驶、无证驾驶和未检验营运等违法行为，努力提高农业机械的“上牌率、检验率和持证率”，为“三秋”机械化生产创造安全和谐的环境。

**六、**强化信息宣传，努力营造良好氛围

各地要加强与新闻媒体合作，认真组织策划“三秋”农机化生产宣传报道，大力宣传玉米机收、油菜机播等农机化的新亮点，广泛报道农机化在技术集成、节本增效、推动规模经营中发挥的重要作用，以及在“稳面积、增单产、抢农时、防灾害”等方面的重要贡献，为“三秋”机械化生产营造良好的舆论氛围。要认真执行《农业机械化生产信息报送制度》和考核办法，进一步做好“三秋”机械化生产进度统计和信息报送工作，准确反映各地工作进度和成效。在11月20日前，向农业部农机化管理司报送今年“三秋”机械化生产工作总结。

农业部办公厅

2014年9月9日
