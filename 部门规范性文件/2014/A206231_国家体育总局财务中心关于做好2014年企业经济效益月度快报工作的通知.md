# 国家体育总局财务中心关于做好2014年企业经济效益月度快报工作的通知

各直属单位：

按照财政部《关于做好2014年企业经济效益月度快报工作的通知》（财办企〔2013〕113号）要求，现将体育总局2014年企业经济效益月度快报工作有关事项通知如下：

**一、**编报范围为事业单位所办国有及国有控股企业。

**二、**中国体育报业总社、已纳入中央国有资本经营预算实施范围的企业要每月报送合并后的财务数据。

**三、**各企业可登陆体育总局官方网站，在“直属单位-财务中心-通知公告”栏中点击下载2014企业财务月报软件，或直接输入网址（http：//pan.baidu.com/s/1hqytR0K）下载。

**四、**企业财务月报数据应于次月5日前上报财务中心，上报邮箱为cwzxrj＠126.com。2014年1月、2月月报合并上报。

各企业在编报财务月报时遇到情况和问题，请与财务中心资产管理处联系。

联系人：徐映、唐华
