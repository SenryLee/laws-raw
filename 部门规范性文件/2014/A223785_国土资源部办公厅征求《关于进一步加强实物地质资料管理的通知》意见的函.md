# 国土资源部办公厅征求《关于进一步加强实物地质资料管理的通知》意见的函

国土资厅函﹝2014﹞1282号

各省、自治区、直辖市国土资源主管部门，中国地质调查局：

为进一步加强实物地质资料管理，我司组织拟定了《进一步加强实物地质资料管理的通知（征求意见稿）》，现印发你单位征求意见。请提出修改意见，并于2014年12月15日前将书面意见传真我司。

联系人及电话: 潘薪如 010-66558379

传真：010-66558277

2014年12月5日
