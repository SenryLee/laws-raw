# 国家新闻出版广电总局办公厅关于开展“百社千校书香童年”阅读活动的通知

国家新闻出版广电总局办公厅关于开展“百社千校书香童年”阅读活动的通知

（新广出办函〔2014〕147号）

各相关出版单位：

为深入贯彻落实党的十八大、十八届二中、三中全会和习近平总书记系列重要讲话精神，培育和践行社会主义核心价值观，进一步加强中国梦宣传教育，引导少年儿童健康阅读，营造有利于少年儿童健康成长的社会氛围，不断丰富广大少年儿童的精神文化生活，国家新闻出版广电总局决定近期开展“百社千校书香童年”阅读活动。现就有关事项通知如下。

**一、**活动内容

总局遴选出100家出版单位，与分布在全国各地，特别是老少边穷地区的1000所小学共同开展“百社千校书香童年”阅读活动。通过举办优秀少儿读物捐赠、知名作家进校园、读书征文、主题演讲、经典诵读等丰富多彩的阅读活动，在全国少年儿童中形成“爱读书、读好书、善读书”的良好阅读风气。

**二、**活动要求

1.要围绕中国梦宣传教育、培育和践行社会主义核心价值观以及弘扬中华优秀传统文化等主题，开展多种形式的阅读活动，提高少年儿童的思想道德素质和科学文化素质，激励少年儿童为实现中华民族伟大复兴的中国梦而奋斗。

2.要加强阅读指导，把握正确导向，倡导阶梯阅读。要根据少年儿童的阅读心理和阅读规律，提供一批思想性、知识性、科学性、艺术性、趣味性相统一的优秀少儿读物，满足少年儿童的阅读需求。

3.要充分利用课外实践活动和暑假时间开展阅读活动。要结合各地区、各出版单位的实际情况，根据少年儿童的特点，创新活动形式，丰富活动载体，充分调动少年儿童阅读的积极性、主动性，引导少年儿童广泛参与阅读活动。

4.要体现公益性活动的宗旨，服务基层，服务学校，服务学生，不得增加教师、家长和学生负担。

5.要加强宣传报道。要结合总局开展的“书香中国万里行”活动，组织新闻媒体广泛宣传活动中涌现出来的先进典型和先进经验，扩大社会影响。

6.要加强组织领导，精心策划，确定开展阅读活动的对口小学，制订详细活动方案，原则上每家出版单位联系的小学不少于10所，确保阅读活动扎实开展，取得实效。

**三、**活动起止时间

“百社千校书香童年”阅读活动从5月下旬开始，9月底结束。请各出版单位将活动方案、活动总结报告分别于5月30日、10月15日前，报送至总局出版管理司图书处。总局将于2014年年底召开总结会，表彰一批在活动中表现突出的出版单位。
