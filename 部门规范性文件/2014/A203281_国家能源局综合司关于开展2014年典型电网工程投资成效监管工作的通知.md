# 国家能源局综合司关于开展2014年典型电网工程投资成效监管工作的通知

## 国家能源局综合司关于开展2014年典型电网工程投资成效监管工作的通知（国能综监管〔2014〕359号）

各有关派出机构，国家电网公司、南方电网公司、内蒙古电力公司：

为进一步提升电网工程造价管理水平，提高电网工程运行实效，国家能源局决定对部分典型电网工程（见附件1）开展投资成效监管工作。现将有关事项通知如下：

**一、**工作内容

1.项目造价分析

对工程核准投资、初设概算和竣工决算等相关造价资料进行对比分析；采用设计容量和实际容量分别计算造价指标，将实际运行成果与建设成本挂钩，评析项目经济性及造价控制过程的有效性。

2.运行情况分析

从工程技术指标方面，对比设计预期分析工程运行实效，主要包括工程投运后在系统中的实际作用、输送电量、工程可用率、输电损耗等。

3.电价成本分析

通过收集的建设投资、运行成本明细、损耗率等实际运行数据，测算输电成本，与收集的各工程现行（或已核准）输电价格进行对比分析。

4.社会效益分析

通过从促进经济发展、缓解环保压力等方面对工程的社会效益进行综合分析，剖析工程完工后场地环境保护、噪声影响控制等方面情况，对比工程设计能力、分析工程环保实效。

**二、**时间安排

1.材料报送阶段（2014年5月～6月）

电网企业准备基础数据，填写《电网工程运行信息表》（见附件2）、《电网工程环保信息表》（见附件3）和《电网工程造价信息表》（见附件4），编写《电网工程投资成效报告》（提纲见附件5），并于6月底前报国家能源局市场监管司（区域内或省内电网项目同时报送国家能源局相应派出机构）。

2.资料汇总分析和现场察看阶段（2014年7月～8月）

组织有关派出机构、电规总院、中电联等单位人员和专家，赴跨区电网工程进行现场察看。非跨区电网工程由项目所在地监管机构组织现场察看工作。电网企业配合准备现场察看项目有关资料（资料清单详见附件6）。现场察看具体时间另行通知。
