# 交通运输部办公厅关于发布《内河航运工程定额人工、材料基价单价》(2014版)的通知

## 交通运输部办公厅关于发布《内河航运工程定额人工、材料基价单价》（2014版）的通知（交办水〔2014〕135号）

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），天津市交通运输和港口管理局，长江、珠江航务管理局，长江口航道管理局，有关内河航运建设工程设计、施工企业和建设管理单位，部属有关单位：

《内河航运工程定额人工、材料基价单价》（2014版）（以下简称《单价》）已编制完成，经交通运输部同意，现发布使用。

本单价与水运工程行业标准《内河航运水工建筑工程定额》（JTS275-1-2014）、《内河航运工程船舶机械艘（台）班费用定额》（JTS275-2-2014）、《内河航运设备安装工程定额》（JTS275-3-2014）、《内河航运工程参考定额》（JTS/T275-4-2014）、《水运工程混凝土和砂浆材料用量定额》（JTS277-2014）等配套使用。

本《单价》由交通运输部水运局负责管理和解释。

交通运输部办公厅

2014年7月4日
