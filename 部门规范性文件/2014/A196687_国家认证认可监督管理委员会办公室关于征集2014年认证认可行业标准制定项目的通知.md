# 国家认证认可监督管理委员会办公室关于征集2014年认证认可行业标准制定项目的通知

各有关单位：

为充分发挥技术标准对认证认可工作的支撑保障作用，我委现面向各认证认可从业机构公开征集2014年认证认可行业标准制定项目。现将有关要求通知如下：

**一、**项目征集范围

1.认证认可通用原则和要求；

2.规范认可活动的标准项目；

3.规范认证活动的标准项目（不含产品标准）；

4.规范认证检查活动的标准项目；

5.规范实验室能力验证活动的标准项目；

6.其他规范认证认可行业相关活动的标准项目。

**二、**项目征集要求

1.重点征集认证认可领域现有技术文件（认可规范、备案的技术规范等）拟转化的项目，工作中已相对成熟或基本定型并适合在行业内推广的项目，以及及认证认可事业发展急需的项目。

2.项目提出单位应具备完成标准项目所需的技术能力，并在人财物等方面提供必要的支持。

3.提出的项目能在1-2年内完成起草工作。

4.鼓励项目提交标准大纲或标准草案。

**三、**材料报送要求

1.提出项目的单位请填写《认证认可行业标准计划项目申请汇总表》（见附件1，每单位填写一份）和《认证认可行业标准制定项目计划建议书》（见附件2，每个项目均需填写）。

2.请各单位于2014年9月15日前将正式文件报送我委联系人，同时将电子版材料发至联系人电子邮箱。我委将尽快组织相关专家进行审议，研究确定本年度标准制定计划项目。
