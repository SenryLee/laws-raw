# 国家认证认可监督管理委员会办公室关于部分CCC目录新增产品强制性认证实施有关问题的通知

各有关强制性产品认证指定认证机构、检测实验室、技术专家组：

为确保新列入CCC目录的儿童乘员用约束系统、部分消防产品（以下简称新增产品）强制性认证工作统一、有序、顺利地实施，现就上述新增产品强制性认证工作实施的相关技术问题做如下说明和安排，请遵照执行。

**一、**做好各项技术准备工作

1.各指定机构应深刻认识强制性产品认证工作的重要性和严肃性，应集中力量按照《强制性产品认证管理规定》、《强制性产品认证机构、检查机构和实验室管理办法》等相关要求，尽快完成实施强制性产品认证前的各项技术准备工作，包括相关文件的完善、资源的配备、人员培训以及与有关方面接口关系的建立等；应将认证实施细则及其他相关公开文件报认监委备案，并在本机构网站上向社会公布。

2.各指定认证机构应加强合作，建立沟通机制，确保认证实施的一致性，同时也应按要求加强对签约检测机构间认证实施一致性的管控；各儿童乘员用约束系统产品指定检测实验室应在前期实验室间比对基础上认真分析，总结经验及不足，落实比对试验形成的相关操作规范要求，确保检测操作一致性及检测结果公正、准确。

3.指定认证机构对各检测机构的试验方案及检测报告格式进行梳理和统一。各检测机构对合格判定中易存在差异的检测项目，应按照强制性产品认证技术专家组对相关项目的检测操作规范及合格判定尺度形成的技术决议统一执行。

**二、**关于认证检测收费的要求

1.各指定机构应严格遵守国家发改委《关于重新核定强制性产品认证收费标准的通知》（发改价格〔2009〕1034号），不得变相降低和提高认证收费标准。

2.对新增产品涉及的检测收费项目，相关强制性产品认证技术专家组应尽快提出建议草案并报国家认监委。各指定机构应严格按照认监委向国家价格主管部门备案的检测项目及标准执行。

**三、**产品自愿性认证结果的承认

依照《认证认可条例》规定设立、具有经国家认监委批准的相应业务范围、取得国家认可资格的产品认证机构颁发的新增产品自愿性认证证书，在符合如下要求的条件下，在强制性产品认证中应予以承认：

1.新增产品自愿性认证实施规则与强制性认证实施规则存在差异的，应补充检测或补充工厂审查；

2.原自愿性产品认证检测机构应为现国家认监委指定承担该产品强制性认证的检测机构；

3.强制性产品认证所承认的新增产品自愿性认证证书的截止日期为2015年8月31日。

**四、**认证证书中的产品种类编码

儿童乘员用约束系统强制性产品认证证书中的产品种类编码为2207；消防产品强制性产品认证证书中的产品种类编码见附表。
