# 国家认证认可监督管理委员会党组关于印发《国家认监委党组中心组2014年学习计划》的通知

## 国家认证认可监督管理委员会党组关于印发《国家认监委党组中心组2014年学习计划》的通知（国认党组〔2014〕1号）

委党组成员：

结合《质检总局党组中心组2014年学习计划》的具体部署和我委实际，特制定《国家认监委党组中心组2014年学习计划》。

附件：国家认监委党组中心组2014年学习计划

国家认监委党组

2014年2月13日

附件

中共国家认监委党组中心组2014年学习计划

为切实搞好我委党组中心组学习工作，认真落实我委党的群众落线教育实践活动整改落实方案，积极推进认监委领导班子思想政治建设，根据《国家质检总局党组中心组2014年学习计划》的具体部署，结合认证认可工作实际，制定2014年委党组中心组学习计划。

**一、**指导思想

以党的十八大和十八届三中全会精神为指导，以中国特色社会主义理论体系为基本内容，坚持用党的最新理论成果武装头脑、指导实践、推动发展，不断提高党组中心组成员的领导能力和决策能力，确保中央大政方针在认证认可系统得到坚决贯彻落实，为认证认可事业科学发展提供坚强保证。

**二、**学习重点

（一）认真组织对习近平总书记系列讲话精神的深入学习

深入学习领会习近平总书记关于坚持和发展中国特色社会主义、关于实现中华民族伟大复兴的中国梦、关于全面深化改革、关于推进科学发展、关于社会主义民主政治和依法治国、关于加强宣传思想工作、关于国际关系和我国外交战略、关于加强党的建设等重要论述。对习近平总书记陆续发表的重要讲话，及时组织学习贯彻。

（二）认真组织对党的十八届三中全会精神的深入学习

系统学习党的十八届三中全会通过的《中共中央关于全面深化改革若干重大问题的决定》，充分认识在新起点上全面深化改革的重大意义，准确把握全面深化改革的指导思想、总体目标和基本原则，深刻领会中央对全面深化改革提出的主要任务和重大举措。以中央精神统一思想，凝聚力量，推进认证认可事业改革发展。

（三）认真组织对党和国家新出台的重大方针政策的学习

对中央召开的重要会议、出台的重要文件、作出的重大部署，及时安排时间进行集中学习。包括中央经济工作会议、十二届全国人大二次会议和政协十二届二次会议精神及国务院工作报告等。学习十八届中央纪委三次全会精神以及党中央、国务院关于加强党风廉政建设的新要求、新指示。准确把握精神实质，紧密联系认证认可工作实际，坚决贯彻中央要求，确保各项工作落到实处。

（四）认真组织对党内法规和党建理论的学习

认真学习关于提高党的建设科学化水平相关理论。对按照《中央党内法规制定工作五年规划纲要（2013-2017年）》陆续出台的党内法规，及时组织学习。

（五）认真组织与认证认可领域全面深化改革相关知识的学习

组织学习政治经济理论、法律法规、信息化管理、认证认可业务、质量文化和其他质检知识，特别是加强与认证认可业务领域改革任务相关联的科技与管理知识的学习。

**三、**学习方法

（一）开展个人自学

个人自学作为中心组学习的主要形式，也是开展集中学习的前期准备。中心组成员根据党组规定的学习内容制定自学计划，按计划开展自学，做好笔记。同时紧密结合认证认可实际开展自学，坚持工作学习化、学习工作化，缺什么、补什么，做到学以致用、学用相长。

（二）开展集中学习

采取组织党组中心组成员集中学习交流、每年不少于6次，参加总局“质检大讲堂”的辅导报告、召开理论务虚研讨会、举办和参加专题学习研讨班等形式学习。

（三）组织学习轮训

委党组中心组成员参加总局举办的“学习贯彻党的十八届三中全会精神和习近平总书记系列讲话精神”轮训班。

（四）开展调研促学

每位党组中心组成员，着眼关系认证认可领域改革与发展的重要问题，确定调研课题，深入基层和群众开展调查研究，积极撰写调研报告并开展交流探讨。

（五）开展共享式学习

党组中心组开展集中学习时，适当扩大参加学习人员的范围，委机关各部室和直属单位主要负责人一起参加学习和讨论，促进学习成果共享。

**四、**时间安排

第一季度：分专题开展对《中共中央关于全面深化改革若干重大问题的决定》和习近平总书记在十八届三中全会上的讲话精神的学习；突出重点开展对中央经济工作会议精神的学习；组织对十八届中央纪委三次全会精神学习。

第二季度：认真学习习近平总书记系列讲话精神，党组中心组成员要参加“习近平总书记系列讲话精神专题培训”；对习近平总书记陆续发表的重要讲话，及时安排学习。开展好对全国“两会”通过的《2014年政府工作报告》的学习。

第三季度：组织学党章、学党史、学党建理论。有重点地组织对新出台党内法规的集中学习。结合开展“纪律教育月”活动，安排加强党风廉政建设方面学习内容。

第四季度：组织对党的十八届四中全会精神和中央经济工作会议精神的学习。同时结合组织召开党组民主生活会，开展民主法治与党的群众路线内容的学习。

以上未尽的学习事项，要按照总局有关通知要求组织安排和尽快落实。
