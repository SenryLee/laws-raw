# 国家质量监督检验检疫总局公告2014年第135号——关于批准中理检验有限公司等企业设立、变更检验鉴定机构资格的公告

## 国家质量监督检验检疫总局公告

2014年第135号

## 质检总局关于批准中理检验有限公司等企业设立、变更检验鉴定机构资格的公告

根据《中华人民共和国进出口商品检验法》及其实施条例和《进出口商品检验鉴定机构管理办法》的规定，经质检总局审核，批准中理检验有限公司等16家企业自公告之日起获得进出口商品检验鉴定业务许可，批准深圳华通威国际检验有限公司等6家检验鉴定机构变更许可事项。现将许可、变更情况公告如下：

一、获得许可的检验鉴定机构和许可范围

（一）中理检验有限公司。许可范围：进出口石油、化工品、矿产品、农副产品、木材、机械设备的检验鉴定业务，监视装卸，货物残损、价值鉴定，运载工具装运技术条件检验、承退租鉴定。不含实验室检测活动。

（二）河北恒达商品检验有限公司唐山海港分公司。许可范围：化工品、矿产品、机电产品、轻纺产品、金属材料及其制品检验及鉴定业务。不含实验室检测活动。

（三）河北恒达商品检验有限公司黄骅港分公司。许可范围：化工品、矿产品、机电产品、轻纺产品、金属材料及其制品检验及鉴定业务。不含实验室检测活动。

（四）河北恒达商品检验有限公司曹妃甸分公司。许可范围：化工品、矿产品、机电产品、轻纺产品、金属材料及其制品检验及鉴定业务。不含实验室检测活动。

（五）上海高分子材料研究开发中心。许可范围：非金属材料的物理机械性能、化学性能检测。

（六）上海市医疗器械检测所。许可范围：从事进出口医疗器械检验。

（七）上海赛孚燃料检验有限公司。许可范围：进出口煤炭、焦炭、燃料油、柴油、润滑油检验；散装货物重量鉴定。

（八）上海科见服装检验有限公司。许可范围：纺织品、服装、床上用品及其配套服饰类的检验、整理和包装。

（九）深圳泛亚检验有限公司。许可范围：进出口商品委托检验鉴定业务，社会委托的商品检验鉴定业务，微生物元素的检测、化验，商品及其运输工具的消毒除害业务，及相关咨询服务。

（十）宁波市信测检测技术有限公司。许可范围：电子电气产品的安规、电磁兼容测试以及电子电气产品的验货。

（十一）山东出入境检验检疫局检验检疫技术中心。许可范围：进出口商品检验、鉴定、测试及相关技术服务。

（十二）必维申美商品检测（上海）有限公司淄博分公司。许可范围：陶瓷、玻璃制品的安全项目检测。

（十三）福建中检汽车检测有限公司。许可范围：汽车安全、环保项目测试。

（十四）珠海中理商品检验有限公司。许可范围：进出口商品规格、数重量、残损和装运技术条件的委托检验鉴定业务。不含实验室检测活动。

（十五）云南中检检验检测技术有限公司。许可范围：委托检验、鉴定、评估、技术检测；检验检测技术研究、发开与技术服务、技术转让、咨询；检验检测试剂研发。

（十六）中龙检验认证（香港）有限公司。许可范围：工业品、消费品等装运前检验，玩具及儿童用品、消费品等测试。

二、批准变更的检验鉴定机构名单和变更事项

（一）批准深圳华通威国际检验有限公司（国质检检许字〔032〕号）变更机构性质、投资者名称、注册资本，保持原资格证书号和许可范围不变。

（二）批准欧陆检测技术服务（上海）有限公司（国质检检许字〔193〕号）变更注册资本、投资总额，保持原资格证书号和许可范围不变。

（三）批准亚士得产品质量咨询（深圳）有限公司（国质检检许字〔200〕号）变更投资者名称，保持原资格证书号和许可范围不变。

（四）批准南通清溪服装检品技术开发有限公司（国质检检许字〔242〕号）变更投资者名称，保持原资格证书号和许可范围不变。

（五）温州确思特检测验货有限公司（国质检检许字〔269〕号）变更机构名称、法人代表、投资者名称、注册资本变更，变更后的名称为温州方圆检验认证有限公司，保持原资格证书号和许可范围不变。

（六）广州市纤维产品检测院（国质检检许字〔349〕号）变更机构名称，变更后的名称为广州纤维产品检测研究院，保持原资格证书号和许可范围不变。
