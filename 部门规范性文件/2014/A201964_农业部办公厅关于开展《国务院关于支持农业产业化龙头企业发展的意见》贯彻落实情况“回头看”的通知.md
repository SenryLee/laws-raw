# 农业部办公厅关于开展《国务院关于支持农业产业化龙头企业发展的意见》贯彻落实情况“回头看”的通知

## 农业部办公厅关于开展《国务院关于支持农业产业化龙头企业发展的意见》贯彻落实情况“回头看”的通知（农办经[2014]12号）

各省、自治区、直辖市农业（农牧、农村经济）厅（局、委、办），新疆生产建设兵团农业局：

为深入推进《国务院关于支持农业产业化龙头企业发展的意见》（国发〔2012〕10号，以下简称《意见》）贯彻落实，经全国农业产业化联席会议研究决定，由我部牵头组织开展《意见》贯彻落实情况“回头看”，检查扶持政策落实进展情况，掌握政策完善的新需求，分析龙头企业发展面临的新问题。请你们进行全面梳理总结。有关事宜通知如下。

**一、**主要内容

（一）总体情况。认真总结贯彻落实《意见》进展情况、采取的措施、取得的成效和经验，分析落实中存在的困难和原因、龙头企业当前发展面临的问题，提出下一步工作措施和政策建议，形成总体报告。

（二）实施意见出台情况。整理汇总省级政府贯彻落实《意见》的实施文件出台情况，省级部门出台相关实施办法情况（相关文件请提供复印件）；以及农业产业化专项资金变化情况，填报《实施意见出台情况汇总表》（见附件1）。

（三）政策措施落实进展情况。对照《意见》提出的62条政策措施，逐条梳理落实进展情况，包括哪些政策措施已经落实、哪些政策措施正在落实中、哪些政策措施还没有落实，填报《政策措施落实进展情况汇总表》（见附件2）。

（四）创新性政策措施出台情况。在《意见》提出的扶持政策措施之外，本地区因地制宜制定的创新性政策措施，请汇总整理，填报《创新性政策措施出台情况汇总表》（见附件3）。

**二、**有关要求

贯彻落实好《意见》是当前和今后一个时期农业产业化工作的重中之重，各地要高度重视，安排专人负责，把这项工作抓紧抓实。《意见》涉及发改、财政、商务、金融、税务等多个部门，请各省（区、市）农业产业化主管部门积极与相关部门沟通协调，加快推进贯彻落实工作，并牵头汇总整理本地区的贯彻落实情况。同时，通过督导检查、走访调研、召开座谈会等形式，了解龙头企业扶持政策落实情况和存在的突出问题。

请于8月15日前将总体报告和《实施意见出台情况汇总表》《政策措施落实进展情况汇总表》《创新性政策措施出台情况汇总表》以正式文件形式报送我部农业产业化办公室，并发送电子文档。近期，我部将派出调研组赴部分省（区、市）就《意见》贯彻落实情况进行专题调研。
