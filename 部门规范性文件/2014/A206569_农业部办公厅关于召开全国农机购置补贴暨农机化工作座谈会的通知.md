# 农业部办公厅关于召开全国农机购置补贴暨农机化工作座谈会的通知

## 农业部办公厅关于召开全国农机购置补贴暨农机化工作座谈会的通知（农办机[2014]4号）

各省、自治区、直辖市及计划单列市农机（农业、农牧）局（厅、委、办），新疆生产建设兵团农业局，黑龙江省农垦总局、广东省农垦总局：

为深入贯彻落实中央1号文件精神，总结、交流各地2013年农机购置补贴政策实施和农机化工作成效经验，全面部署2014年及今后一段时期重点工作，我部定于2月下旬召开全国农机购置补贴暨农机化工作座谈会。现将有关事项通知如下。

**一、**会议内容

（一）总结交流2013年全国农机购置补贴政策实施及农机化工作成效、做法和经验。

（二）安排部署2014年及今后一段时期重点工作。

（三）部署农机购置补贴廉政风险防控工作，签订落实农机购置补贴政策工作责任书。

**二、**参加人员

各省、自治区、直辖市、计划单列市农机管理局（办公室），新疆生产建设兵团农机局，黑龙江省农垦总局农机局，广东省农垦总局农机化工作主要负责同志和农机购置补贴工作主管处长。农业部农机试验鉴定总站、农机推广总站、中国农机安全报社主要负责同志和有关处（室）处长（主任）。每个单位参会人数不超过2人。

邀请财政部农业司、农业部财务司、农业部农垦局、驻农业部纪检组监察局和中国农业大学中国农机化发展研究中心有关同志参加。

**三、**会议时间、地点

时间：2月21日开会，20日报到，会期1天。

地点：南京市双门楼宾馆，地址：南京市虎踞北路185号，总机：025-58800888。

**四、**有关要求

（一）提前准备座谈讨论发言。请各省围绕农机购置补贴和农机化重点工作，提前做好座谈讨论准备。典型交流发言单位及材料要求等将另行通知。

（二）按要求及时报名参会。请于2月14日前，将会议报名回执（见附件）以电子邮件的方式报我部农机化管理司产业发展处。联系人：孙少磊、赵威，电话：010-59192862，Email：njhcyc@agri.gov.cn。

（三）具体会务工作委托江苏省农机管理局承办。联系人：孟德富，电话：025-83275127、13645191245。
