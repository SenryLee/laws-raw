# 国家认监委办公室关于组织召开食品化妆品检验专业委2014年工作会议暨标准集中审定会的通知

## 国家认监委办公室关于组织召开食品化妆品检验专业委2014年工作会议暨标准集中审定会的通知（认办科函〔2014〕132号）

各直属检验检疫局、总局食品局、标准法规中心、中国检科院、认可中心、研究所：

为总结2013年度食品化妆品检验标准化技术委员会工作情况，做好2014年度各项工作任务布置，并对本专业标准进行审定，我委定于2014年8月12日～13日在吉林省长春市组织召开食品化妆品检验专业委2014年工作会议暨标准集中审定。现就有关事项通知如下：

**一、**会议内容

（一）总结2013年度食品化妆品检验专业委工作，布置本年度工作任务；

（二）审定《出口粮谷中克螨特残留量检验方法》等33项食品化妆品检验专业行业标准，清单见附件1。

**二、**参会人员

（一）食品化妆品专业委全体委员，其中参加审定人员名单见附件2；

（二）标准主要起草人；

（三）特邀总局食品局、标准法规中心派员参会，人员自定。

**三、**报到时间、地点

（一）报到时间：2014年8月12日中午前报到；

（二）报到地点：长春市，一品吉粮国际酒店。

**四、**相关事项

（一）请食品化妆品专业委参会委员做好2013年工作梳理及2014年工作建议；

（二）请标准起草人自带笔记本电脑、审定材料（标准送审稿、编制说明、征求意见汇总表、验证材料等）的纸质文本12份及电子文本，每项标准需缴纳审定费2000元；

（三）交通食宿费用自理；

（四）请参加人员于8月5日前将会议回执（附件3）通过传真或电子邮件反馈联系人；因故不能参加的，请向国家认监委科技标准部和专业委秘书处请假。
