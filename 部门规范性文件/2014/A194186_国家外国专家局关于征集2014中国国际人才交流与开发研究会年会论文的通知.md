# 国家外国专家局关于征集2014中国国际人才交流与开发研究会年会论文的通知

各省、自治区、直辖市和副省级城市外国专家局，新疆生产建设兵团外国专家局，国务院有关部委引智归口管理部门及各有关单位：

2014中国国际人才交流与开发研究会年会组委会现面向全国引智系统和关心引智事业的理论研究人员开展论文征集活动，诚挚期待各地、各系统引智理论研究和实践工作者积极参与，踊跃投稿。

**一、**征文内容

围绕习近平总书记5月22日在上海与外国专家座谈时的讲话，着眼于新的历史发展时期促进引智事业和积极开发利用国际人才资源，结合引进国外人才和智力的重大理论和现实问题进行解读与交流，参考题目见附件《论文参考标题》。

**二、**征集要求

投稿论文应具有理论研究和实践价值，未公开发表，未参加过其他评奖活动，内容有独到见解， 数据真实，引证准确，引注规范；能客观公正地分析当前我国引智事业中存在的主要问题、解决办法以及取得的成效。

论文应包括摘要、关键词、正文、注释、参考文献等内容。注释采取页下注，参考文献附正文后。论文正文篇幅应在5000-8000字左右，同时提交作者简介和联系方式，欢迎踊跃投稿。

特提醒，烦请在2014年10月15日之前将符合学术规范的论文和论文摘要电子版发到联系人邮箱，并附上论文题目的英文翻译，以便制作会议议程和编辑论文集。

会议将评选出优秀论文并结集出版，优秀论文的作者将获邀在研讨会上发言，并将由清华大学CNKI网络数据库全文收录。
