# 国家体育总局直属机关工会关于举办2014年国家体育总局干部职工围棋比赛的通知

机关各分会、各直属工会：

为活跃总局干部职工的文化生活，进一步推动全民健身运动的开展，直属机关工会决定举办2014年国家体育总局干部职工围棋比赛。现将有关事项通知如下：

**一、**比赛时间、地点

时间：4月12日（星期六）13：00-17：00。

地点：北京东城区天坛东路80号中国棋院二层大厅（南二环玉蜓桥东北角）。

**二、**主办单位

国家体育总局直属机关工会。

**三、**承办单位

国家体育总局棋牌运动管理中心。

**四、**竞赛项目

围棋个人赛，分别设公仆组、栋梁组、公开组和女子组共4个组别。

**五、**参赛办法

（一）参赛人员符合两种及以上组别身份的，可根据自己的实际情况选择对应的组别，曾获得过职业围棋段位的棋手不得参赛。分组情况如下：

公仆组：司局级及以上领导干部；

栋梁组：处级干部；

公开组：所有干部、职工；

女子组：所有女干部、职工。

（二）300人以上单位限报8人，100至300人单位限报6人，100人以下限报4人。

（三）请从总局网站-机关党委-通知公告中自行下载报名表，认真填写后于3月21日前发电子邮件至pxtgb@263.net。相关信息也将登载在中国棋牌网（www.qipai.org.cn）公告栏和普及培训专栏。

联系人：张文东　电话：13910220931、87559126。

丁文静　电话：87559232

任再芳　电话：87182412

**六、**竞赛办法

（一）采用2002年中国围棋协会审定的《围棋竞赛规则》。

（二）本次比赛将根据各组报名人数最终确定竞赛方式，在抽签编排前最终确认分组循环后淘汰或单败淘汰等。

（三）抽签定于4月9日上午10：00在中国棋院二层举行。各单位可派领队或参赛棋手为代表参加。未到抽签现场的单位，裁判人员将指定人员现场代其抽签。

（四）每方时限30分钟包干，超时判负。裁判长可根据报名及其他情况赛前调整用时。

**七、**录取名次与奖励

（一）根据每组参赛人数给予奖励。

（二）获奖棋手在赛后（约下午5：00）均可和主、承办方安排的职业围棋高段棋手下多面打指导棋。

**八、**竞赛及裁判人员由主、承办单位商定。

**九、**未尽事宜另行通知。
