# 国家邮政局公布2014年7月份邮政行业运行情况

1-7月份，邮政企业和全国快递服务企业业务收入（不包括邮政储蓄银行直接营业收入）累计完成1755.5亿元，同比增长23.2%；业务总量累计完成1934.5亿元，同比增长34.7%。

7月份，全行业业务收入完成250.9亿元，同比增长25.7%；业务总量完成292.5亿元，同比增长32.6%。

1-7月份，邮政函件业务累计完成35.4亿件，同比下降9.5%；包裹业务累计完成3440.5万件，同比下降12.7%；报纸业务累计完成112亿份，同比下降1.6%；杂志业务累计完成6.5亿份，同比下降5.5%；汇兑业务累计完成8193万笔，同比下降19.9%。

1-7月份，全国快递服务企业业务量累计完成70.2亿件，同比增长52.9%；业务收入累计完成1061.3亿元，同比增长41.9%。其中，同城业务收入累计完成133.6亿元，同比增长56.2%；异地业务收入累计完成587.5亿元，同比增长39.2%；国际及港澳台业务收入累计完成171.1亿元，同比增长12.7%。

7月份，快递业务量完成11.1亿件，同比增长48.7%；业务收入完成163.8亿元，同比增长38.9%。

1-7月份，同城、异地、国际及港澳台快递业务收入分别占全部快递收入的12.6%、55.4%和16.1%;业务量分别占全部快递业务量的25.3%、72.3%和2.4%。与去年同期相比，同城快递业务收入的比重上升1.1个百分点，异地快递业务收入的比重下降1个百分点，国际及港澳台业务收入的比重下降了4.2个百分点。

![](https://zk-img.faxin.cn//Uedit_Upload/6356840572423185949813609.jpg)![](https://zk-img.faxin.cn//Uedit_Upload/6356840572821135163895675.jpg)

1-7月份，东、中、西部地区快递业务收入的比重分别为82.9%、9.4%和7.7%，业务量比重分别为81.8%、10.7%和7.5%。与去年同期相比，东部地区快递业务收入比重下降了0.2个百分点，快递业务量比重上升了0.8个百分点；中部地区快递业务收入比重上升了0.2个百分点，快递业务量比重下降了0.4个百分点；西部地区快递业务收入比重持平，快递业务量比重下降了0.4个百分点。

![](https://zk-img.faxin.cn//Uedit_Upload/6356840587204142973090305.jpg)![](https://zk-img.faxin.cn//Uedit_Upload/6356840587630510164385990.jpg)

2014年1-7月份，快递服务品牌集中度指数CR8为78.7，较上半年下降了0.1。
