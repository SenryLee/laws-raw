# 国家测绘地理信息局办公室关于召开2014年全国测绘地理信息局长座谈会的通知

各省、自治区、直辖市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司室：

国家测绘地理信息局研究决定，近日在京召开2014年全国测绘地理信息局长座谈会。现将有关事项通知如下：

**一、**会议内容

深入学习贯彻党的十八届三中全会精神和习近平总书记系列重要讲话精神，交流上半年工作经验，研究深化测绘地理信息领域改革的思路对策，着力推动全国测绘地理信息领域全面深化改革，加快推进测绘地理信息事业转型升级、跨越发展。

**二、**会议时间、地点

（一） 会议时间：

2014年7月10至11日上午，会期一天半（9日报到）

（二）会议地点：中国测绘创新基地。

**三、**参加人员

（一）国家测绘地理信息局局长、副局长、党组成员、总工程师。

（二）各省、自治区、直辖市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，1名主要负责同志。

（三）局所属各单位、机关各司室、中国测绘学会、中国地理信息产业协会、中国卫星导航定位协会党政主要负责同志。

**四、**其他事项

（一）各单位发言不全面汇报上半年工作，主要围绕会议主题，谈本单位、本部门工作中取得的典型经验、存在的困难和问题，对全面深化测绘地理信息领域改革的思路，对国家局改进工作的建议等。每单位1名主要负责同志发言，时间不超过8分钟。

（二）发言提纲请自行印制90份（格式见附件1）报到时交会议会务组统一分发。

（三）请各单位、各部门妥善安排参会同志的工作日程，中途不得请假，并于7月7日17：00前将会议报名表（见附件2）传真至局办公室秘书处。

（四）会议统一安排接送站，请将接送站信息表（见附件3）传真至局机关服务中心办公室。
