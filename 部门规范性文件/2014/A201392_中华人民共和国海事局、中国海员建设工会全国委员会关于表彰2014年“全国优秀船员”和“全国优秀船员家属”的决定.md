# 中华人民共和国海事局、中国海员建设工会全国委员会关于表彰2014年“全国优秀船员”和“全国优秀船员家属”的决定

## 中华人民共和国海事局、中国海员建设工会全国委员会关于表彰2014年“全国优秀船员”和“全国优秀船员家属”的决定(海船员〔2014〕390号)

有关省、自治区、直辖市海员（交通）工会，有关航运企事业单位工会：

在全面建成小康社会，实现中华民族伟大复兴的新征程中，广大船员立足本职，无私奉献，顽强拼搏，为中国航运事业发展和海洋强国建设作出了巨大贡献。广大船员家属作为中国航运事业的一个特殊群体，在努力做好本职工作的同时，勇挑家庭生活重担，用实际行动支持亲人献身航运事业，为稳定船员队伍、促进航运发展发挥了重要作用。

为表彰先进，树立榜样，充分发挥先进典型的示范引领作用，中华人民共和国海事局和中国海员建设工会全国委员会决定，授予李耀鹏等100名船员“全国优秀船员”称号，授予吴海燕等100名同志“全国优秀船员家属”称号。

希望受表彰的先进个人珍惜荣誉，再接再厉，以此为新起点，再立新功。同时也希望广大船员和船员家属以他们为榜样，艰苦奋斗、自强不息，为中国航运强国建设不断贡献力量。

2.“全国优秀船员家属”名单

中华人民共和国海事局

中国海员建设工会全国委员会
