# 财政部公告2014年第55号――关于发行2014年记账式附息(十七期)国债的公告

财政部公告

（2014年第55号）

根据国家国债发行的有关规定，财政部决定发行2014年记账式附息（十七期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

**一、**本期国债计划发行260亿元，实际发行面值金额260亿元。

**二、**本期国债期限20年，经招标确定的票面年利率为4.63%，2014年8月11日开始计息，招标结束后至8月13日进行分销， 8月15日起上市交易。

**三、**本期国债为固定利率附息债，利息按半年支付，利息支付日为每年的2月11日、8月11日（节假日顺延，下同），2034年8月11日偿还本金并支付最后一次利息。

其他事宜按《中华人民共和国财政部公告》（2014年第1号）规定执行。

特此公告。

财政部

2014年8月8日
