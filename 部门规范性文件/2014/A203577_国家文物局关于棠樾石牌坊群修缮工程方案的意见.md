# 国家文物局关于棠樾石牌坊群修缮工程方案的意见

## 国家文物局关于棠樾石牌坊群修缮工程方案的意见（办保函〔2014〕318号）

安徽省文物局：

你局《关于请求审批＜歙县棠樾石牌坊群修缮设计方案＞的请示》（皖文物保[2013]181号）收悉。经研究，我局意见如下：

**一、**应加强对石材材质差异性的分析，调查石牌坊群每一处单体的病害，判断其病害类型、程度，绘制病害图，分析病害原因，在此基础上，提出针对性的保护措施和材料工艺。保护措施实施前，应进行前期筛选、试验，保证其适用性和安全性。

**二、**加强对地基不均匀沉降问题的分析和评估，并制定相应的措施。

**三、**对不影响结构安全的裂隙不宜采取环氧树脂材料封堵和注浆，宜采用无机材料。

**四、**污染的清理需要严格控制实施对象和面积。风化加固材料应在风化严重的区域使用，严格控制使用面积。

**五、**应有监测计划方案，包括施工前、施工期间以及长期监测措施。

**六、**应有排水系统整治、脚手架搭设等详细说明和图纸。

请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织具有相关资质和石质文物保护经验的单位重新编制方案，并按程序报批。

国家文物局

2014年5月5日
