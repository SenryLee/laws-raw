# 国家旅游局办公室关于做好2014年全国旅游团队服务管理系统推广应用工作的通知

## 国家旅游局办公室关于做好2014年全国旅游团队服务管理系统推广应用工作的通知（旅办发〔2014〕36号）

各省、自治区、直辖市旅游局（委）：

2013年，“全国旅游团队服务管理系统”（以下简称“团队系统”）的推广应用工作继续稳步推进，“旅游团队电子行程单管理子系统”、“旅游保险报送和检查子系统”正式上线运行，与电子行程单管理相配套的“导游服务微信服务号”已经启用。截至2013年年底，“团队系统”已覆盖至全国32个省份（含新疆建设兵团）、321个副省级和地市级城市、17449家旅行社，累计旅游团队信息突破110万个，累计游客信息突破2000万人次。2013年，“团队系统”在服务行业日常管理、维护市场秩序、提升企业管理水平、应对突发事件等方面发挥了突出的作用。为进一步做好2014年“团队系统”的推广应用工作，现就有关事项通知如下：

**一、**工作目标

1.“旅游团队动态子系统”推广应用年度目标。一是实现副省级和地市级城市推广应用覆盖率超过80%，全国智慧旅游城市推广应用覆盖率100%；二是实现出境游组团社使用覆盖率100%，其他旅行社使用覆盖率超过60%，全国智慧旅游城市旅行社使用覆盖率超过80%。

2.“旅游团队电子行程单管理子系统”推广应用年度目标。一是实现旅游质监执法机构使用覆盖率超过60%，其中，全国智慧旅游城市旅游质监执法机构使用覆盖率100%。二是实现旅行社使用覆盖率超过60%，全国智慧旅游城市旅行社使用覆盖率超过80%。

3.“旅游保险报送和检查子系统”推广应用年度目标。实现旅行社责任险在线报送和检查覆盖率100%，旅行社在线报送旅游意外险覆盖率超过30%。

**二、**工作任务和安排

1．国家旅游局举行“旅游团队电子行程单管理子系统”培训班，培训系统功能操作，解决“团队系统”在推广应用工作中存在的主要问题，培训对象主要为各省及重点城市的旅游质监执法机构有关人员。

2．各级旅游主管部门结合本地实际，制定本地区2014年度推广应用工作方案，全面部署工作，组织学习并贯彻落实《全国旅游团队服务管理系统使用管理办法（试行）》（以下简称《管理办法》）。

3．各级旅游主管部门对“团队系统”进行再宣传、再培训、再推广，重点是进一步推广应用“旅游团队电子行程单管理子系统”。

4．各级旅游质监执法机构要在今年“十一”黄金周前，实现使用在线移动手持设备，开展“旅游团队电子行程单”检查。

**三、**工作要求

1.精心组织，狠抓落实。各级旅游主管部门要切实加强组织领导，发挥《管理办法》的制度规范作用，严格按照本地工作方案推进各项工作，确保推广应用工作顺利进行。全国智慧旅游城市是旅游信息化建设的重点城市，要发挥示范带头作用。

2.密切配合，协同推进。“团队系统”是一套功能丰富的综合平台，推广应用工作涉及行业监管、质监执法、旅游保险等多个部门，各级旅游主管部门要明确分工，落实责任部门。各部门要按照方案分工各负其责，密切配合，协同推进“团队系统”推广应用工作。

3.保障安全，保障经费。一是各级旅游主管部门要按照《管理办法》相关规定，制定、完善本地区的“团队系统”信息安全管理制度，安全使用系统帐户和系统数据信息。二是各级旅游旅游主管部门要将推广应用“团队系统”列为2014年度重点工作，将有关经费支出纳入年度预算，切实保障移动检查设备购置、举办培训班等经费投入。

4.应用数据，服务行业。为了充分应用累计的数据信息，“团队系统”已开发出旅行社业务统计信息查询、三大旅游市场业务统计表查询、旅游应急统计报表查询、高级数据检索查询等服务功能。“团队系统”运维单位还将提供旅游监管、市场分析、行业动态等多个角度的个性化数据分析服务。各级旅游主管部门要利用好数据查询分析服务，切实提高服务和管理水平，促进企业和行业发展。
