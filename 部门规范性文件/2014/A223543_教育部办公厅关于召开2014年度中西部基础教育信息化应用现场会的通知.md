# 教育部办公厅关于召开2014年度中西部基础教育信息化应用现场会的通知

教基二厅函[2014]24号

河北、山西、内蒙古、辽宁、吉林、黑龙江、安徽、江西、河南、湖北、湖南、广西、海南、重庆、四川、贵州、云南、西藏、陕西、甘肃、青海、宁夏、新疆等省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

为推动信息技术在中小学校广泛应用，推进信息技术与教育理念、教学内容和教学方法的逐步深度融合，发挥其在育人方式、课堂教学和教育方法改革方面的更大作用，以经验促发展，以典型带应用，定于2014年11月25日（星期二）在安徽芜湖召开2014年度中西部基础教育信息化应用现场会，会期一天，现将有关事宜通知如下。

**一、会议主题及主要内容**

会议主题：以教育信息化应用促进教学质量提高。

主要内容：

1. 安徽省基础教育信息化应用情况介绍；

2. 部分省市基础教育信息化应用经验交流；

3. 探讨利用信息技术手段提高农村中小学教学质量的政策和方法。

**二、参会人员**

1. 教育部领导同志，有关司局负责同志。

2. 各有关省、自治区、直辖市和新疆生产建设兵团教育行政部门分管负责同志1人，分管处室负责同志1人。

**三、其他事项**

1. 请于11月20日前将参会回执反馈至教育部基础教育二司。

2. 请参会人员11月24日到安徽省芜湖市繁昌县马仁山庄福苑一楼（电话：0553-7217888，13605691028）报到。
