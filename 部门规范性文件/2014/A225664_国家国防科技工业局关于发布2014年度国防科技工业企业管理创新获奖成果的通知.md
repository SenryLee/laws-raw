# 国家国防科技工业局关于发布2014年度国防科技工业企业管理创新获奖成果的通知

各有关单位：

2014年各军工集团公司推荐参评的管理创新成果,经专家初审、评审并经国防科技工业企业管理创新成果评审委员会审定，确定获奖成果177项，其中一等奖29项，二等奖67项，三等奖81项。经公示无异议，现予以发布。

附件：2014年度国防科技工业企业管理创新成果获奖项目名单

2014年12月29日
