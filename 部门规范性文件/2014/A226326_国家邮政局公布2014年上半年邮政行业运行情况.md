# 国家邮政局公布2014年上半年邮政行业运行情况

上半年，邮政企业和全国快递服务企业业务收入（不包括邮政储蓄银行直接营业收入）累计完成1504.6亿元，同比增长22.8%；业务总量累计完成1642亿元，同比增长35.1%。

6月份，全行业业务收入完成267.7亿元，同比增长23.2%；业务总量完成295.2亿元，同比增长32.7%。

上半年，邮政函件业务累计完成31亿件，同比下降9.3%；包裹业务累计完成3039.8万件，同比下降12.7%；报纸业务累计完成95.5亿份，同比下降1.6%；杂志业务累计完成5.6亿份，同比下降5.5%；汇兑业务累计完成7201.2万笔，同比下降17.4%。

上半年，全国快递服务企业业务量累计完成59亿件，同比增长53.7%；业务收入累计完成897.5亿元，同比增长42.5%。其中，同城业务收入累计完成111.9亿元，同比增长56.9%；异地业务收入累计完成497.8亿元，同比增长39.9%；国际及港澳台业务收入累计完成144.9亿元，同比增长12.9%。

6月份，快递业务量完成11.3亿件，同比增长56.5%；业务收入完成162.4亿元，同比增长40.3%。

上半年，同城、异地、国际及港澳台快递业务收入分别占全部快递收入的12.5%、55.5%和16.1%;业务量分别占全部快递业务量的25.1%、72.4%和2.5%。与去年同期相比，同城快递业务收入的比重上升1.2个百分点，异地快递业务收入的比重下降1个百分点，国际及港澳台业务收入的比重下降了4.3个百分点。

![](https://zk-img.faxin.cn//Uedit_Upload/6356840470966219531635636.jpg)![](https://zk-img.faxin.cn//Uedit_Upload/6356840471420809375846768.jpg)

上半年，东、中、西部地区快递业务收入的比重分别为82.8%、9.5%和7.7%，业务量比重分别为81.7%、10.8%和7.5%。与去年同期相比，东部地区快递业务收入比重下降0.2个百分点，快递业务量比重上升了0.9个百分点；中部地区快递业务收入比重上升了0.2个百分点，快递业务量比重下降了0.5个百分点；西部地区快递业务收入比重持平，快递业务量比重下降了0.4个百分点。

![](https://zk-img.faxin.cn//Uedit_Upload/6356840476017391405940935.jpg)![](https://zk-img.faxin.cn//Uedit_Upload/6356840476506063287580840.jpg)

2014年上半年，快递服务品牌集中度指数CR8为78.8，较1-5月下降0.1。
