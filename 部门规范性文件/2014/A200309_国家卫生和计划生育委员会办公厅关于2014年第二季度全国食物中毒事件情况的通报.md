# 国家卫生和计划生育委员会办公厅关于2014年第二季度全国食物中毒事件情况的通报

## 国家卫生和计划生育委员会办公厅关于2014年第二季度全国食物中毒事件情况的通报（国卫办应急发〔2014〕41号）

各省、自治区、直辖市卫生计生委（卫生厅局），新疆生产建设兵团卫生局，中国疾病预防控制中心、卫生监督中心：

2014年第二季度，我委通过突发公共卫生事件网络直报系统共收到全国食物中毒类突发公共卫生事件（以下简称食物中毒事件）报告46起，中毒1676人，其中死亡33人。与2013年同期相比，报告起数增加21.1%，中毒人数增加15.0%，死亡人数增加37.5%。现将有关情况通报如下：

**一、**食物中毒事件报告情况

（一）按月报告情况。

|  |  |  |  |
| --- | --- | --- | --- |
| 时间 | 报告起数 | 中毒人数 | 死亡人数 |
| 4月 | 9 | 489 | 1 |

| 合计 | 46 | 1676 | 33 |

第二季度，6月份报告的食物中毒事件起数、中毒人数和死亡人数最多，分别占总报告起数、总中毒人数和总死亡人数的56.5%、38.1%和84.8%。

（二）按食物中毒原因分类情况。

第二季度， 微生物和有毒动植物及毒蘑菇引起的食物中毒事件各报告21起，分别占总报告起数的45.7%；微生物性食物中毒事件的中毒人数最多，占总中毒人数的80.3%；有毒动植物及毒蘑菇引起的食物中毒事件死亡人数最多，占总死亡人数的84.8%。第二季度，未收到化学性食物中毒事件报告。

与2013年同期相比，微生物性食物中毒的报告起数和中毒人数分别增加40.0%和34.8%，死亡人数增加2人；有毒动植物及毒蘑菇引起的食物中毒报告起数和死亡人数分别增加40.0%和64.7%，中毒人数减少30.3%。

第二季度， 发生在家庭的食物中毒事件报告起数和死亡人数最多，分别占总报告起数和总死亡人数的52.2%和100.0%；发生在集体食堂和饮食服务单位的食物中毒事件中毒人数分别占总中毒人数的39.0%和35.4%。

与2013年同期相比，发生在集体食堂的食物中毒报告起数与去年持平，中毒人数增加21.8%，均无死亡；发生在家庭的食物中毒报告起数和死亡人数分别增加20.0%和50.0%，中毒人数减少24.5%；发生在饮食服务单位的食物中毒报告起数和中毒人数分别增加6起和107.0%，均无死亡。

第二季度，学校共发生食物中毒13起，中毒832人，无死亡；其中8起发生于学校集体食堂，中毒561人，占学生食物中毒总人数的67.4%。

微生物引起的学生食物中毒事件报告起数和中毒人数最多，分别占总报告起数和总中毒人数的76.9%和84.3%。

与2013年同期相比，学生食物中毒的报告起数增加85.7%，中毒人数增加1.1倍，均无死亡。

（五）剧毒鼠药中毒事件报告情况。第二季度，全国无剧毒鼠药中毒事件报告。

**二、**食物中毒事件原因及场所分析

（一）分析食物中毒原因，第二季度微生物性食物中毒人数最多，占总中毒人数的80.3%，主要是由沙门氏菌、蜡样芽胞杆菌、致病性大肠杆菌、副溶血性弧菌、葡萄球菌肠毒素、椰毒假单胞菌、志贺氏菌、雷极普罗威登菌、枸橼酸杆菌等引起的细菌性食物中毒。有毒动植物及毒蘑菇引起的食物中毒死亡人数最多，主要中毒因素为毒蘑菇、未煮熟四季豆、蓖麻子、野生蜂蜜等。

（二）分析食物中毒发生场所，第二季度发生在家庭的食物中毒报告起数和死亡人数最多。其中，有毒植物及毒蘑菇引起的食物中毒事件18起，死亡28人；微生物性食物中毒事件4起，死亡2人；不明原因或尚未查明原因的食物中毒事件2起，死亡3人。农村家庭自办宴席食物中毒事件5起，中毒237人，死亡2人，报告中毒人数占第二季度家庭食物中毒事件中毒人数的75.2%，中毒原因均为微生物性食物中毒。

**三、**下一步工作建议

（一）建议食品安全监管有关部门加强对农村家庭自办婚丧嫁娶和升学宴等宴席的食品安全的监管指导。

（二）各级卫生计生部门要切实加强对有毒动植物及毒蘑菇食物中毒事件的临床救治、流行病学调查和实验室检测工作。建议有毒动植物及毒蘑菇食物中毒事件报告较多省份及时发出健康提示信息，加强健康教育宣传工作，提高公众识别有毒动植物及毒蘑菇的能力及中毒后的自救能力。

（三）发生洪涝灾害地区的卫生计生行政部门要高度重视灾区食品和饮用水卫生安全工作，加强预防食物中毒的宣传教育工作，指导饮用水源保护和饮用水消毒工作，有效预防灾区食物中毒事件的发生。
