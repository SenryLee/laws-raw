# 国家邮政局关于对相关企业因架构调整申请快递业务经营许可审核情况的公示

顺丰速运有限公司、上海快捷快递有限公司、全一快递有限公司等三家企业向我局申请快递业务经营许可。我局依法进行了审核。上述三家企业均为内部架构调整后新设立的法人企业。原有获得快递业务经营许可的法人主体，将在履行有关程序后，注销快递业务经营许可。

现将审核情况公示如下：

一、申请审核情况

1. 顺丰速运有限公司

申请企业名称：顺丰速运有限公司

企业地址：深圳市宝安区国际机场航空货运站一栋二层211室

企业类型：有限责任公司

经营范围：国内快递（邮政企业专营业务除外）

经营地域：北京、天津、河北、山西、内蒙古、辽宁、吉林、黑龙江、上海、江苏、浙江、安徽、福建、江西、山东、河南、湖北、湖南、广东、广西、海南、重庆、四川、贵州、云南、西藏、陕西、甘肃、青海、宁夏、新疆（详见分支机构名录）

2. 上海快捷快递有限公司

申请企业名称：上海快捷快递有限公司

企业地址：青浦区北青公路9138号1幢3层E区373室

企业类型：有限责任公司（国内合资）

经营范围：国内快递（邮政企业专营业务除外）

经营地域：上海市、江苏省淮安市、湖南省长沙市、重庆市

3.全一快递有限公司

申请企业名称：全一快递有限公司

企业地址：深圳市福田区红荔西路莲花三村现代花园2楼西B03

企业类型：有限责任公司

经营范围：国内快递（邮政企业专营业务除外）

经营地域：广东省（深圳市、江门市）、北京市、浙江省（绍兴市、温州市）、陕西省西安市

二、公示时间

公示时间：2014年7月24日—2014年7月30日。

三、监督方式

各利害关系人及有关单位如有意见，请于公示期内将书面意见反馈至国家邮政局市场监管司，并提供联系方式。

通信地址：北京市西城区北礼士路甲8号国家邮政局市场监管司，邮编：100868。

监督电话：010-88323247；传真：010-88323376。
