# 国家认证认可监督管理委员会关于下达2014年度“国家认监委认证认可科技支撑计划”项目的通知

## 国家认证认可监督管理委员会关于下达2014年度“国家认监委认证认可科技支撑计划”项目的通知（国认科〔2014〕78号）

各有关单位：

2014年度国家认监委认证认可科技支撑计划项目已完成评审，现将2014年度国家认监委认证认可科技支撑计划项目下达你单位（详见附件1），具体有关事项通知如下：

**一、**任务书填报

请各项目承担单位认真编报《国家认监委认证认可科技支撑计划项目任务书》（详见附件2），各项目承担单位科技管理部门加强审核把关。项目研究内容可根据项目评审专家意见进行修改完善，但要求考核指标明确、可量化、可考核，特别是核心研究内容应与项目建议书保持一致。

**二、**项目执行过程中注意事项

请各项目承担单位加强科研项目管理，做好项目进度检查、督促工作，确保科研任务顺利完成。加强项目实施过程中的监督检查制度、信息报送制度和重大事项报告制度。

请各项目承担单位加强科研经费的管理和监督，落实项目自筹经费。项目承担单位应与参与单位加强联系，参加单位应积极配合，共同完成好研究工作。

**三、**报送要求

请各项目承担单位将任务书打印书面文本（加盖公章，一式三份）提交到相关分专业技术委员会（简称“分专业委”），相关分专业委审查后（加盖公章）于10月10日前报送至我委科技与标准管理部，电子版发至loud@cnca.gov.cn。
