# 住房和城乡建设部关于增补住房和城乡建设干部学院等3家单位为一级注册建造师继续教育培训单位的通知

建市施函[2014]175号

一级注册建造师继续教育各专业牵头部门，各省、自治区住房城乡建设厅，直辖市建委（建设交通委），总后基建营房部：

经中国建筑业协会推荐和我司审核，现决定增补住房和城乡建设干部学院、南通市通州区建筑职工中等专业学校、内蒙古建筑职业技术学院（内蒙古自治区建筑职工培训中心）等3家单位为建筑工程专业一级注册建造师继续教育培训单位。请相关部门加强对培训单位的管理，确保继续教育质量。

住房城乡建设部建筑市场监管司

2014年12月17日
