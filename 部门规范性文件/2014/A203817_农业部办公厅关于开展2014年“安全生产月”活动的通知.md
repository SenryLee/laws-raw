# 农业部办公厅关于开展2014年“安全生产月”活动的通知

## 农业部办公厅关于开展2014年“安全生产月”活动的通知（农办办〔2014〕19号）

各省、自治区、直辖市、新疆生产建设兵团农业（农牧）、农机、畜牧、兽医、渔业厅（局、委、办），黑龙江、广东垦区，部机关各司局、部属各单位：

按照《国务院安委会办公室关于开展2014年全国“安全生产月”和“安全生产万里行”活动的通知》要求为深入宣传贯彻习近平总书记关于安全生产系列重要指示精神，进一步加强农业安全生产宣传教育工作，发出安全生产最强音，营造农业安全生产好环境，农业部决定集中在6月份开展2014年“安全生产月”活动。现将活动有关事项通知如下：

**一、**指导思想

以党的十八大、十八届三中全会和全国宣传思想工作会议精神为指导，以宣传贯彻习近平总书记系列重要讲话精神、大力实施安全发展战略为主线，通过集中开展系列安全生产宣传教育活动，强化“红线”意识，弘扬安全文化，普及安全知识，树立安全理念，提升安全素养，为有效防范和坚决遏制重特大事故，促进农业安全生产状况持续稳定好转提供强大精神动力、文化力量和舆论支持。

**二、**活动主题

强化红线意识，促进安全发展。

**三、**组织领导

成立农业部“安全生产月”活动组织委员会（以下简称组委会），部安委会主任、副主任为“安全生产月”活动组委会主任、副主任。组委会下设办公室，办公室设在农业部安全生产委员会办公室，负责组织、指导、协调、督导各行业、各司局和各单位开展“安全生产月”活动。

**四、**农业部系统重点活动安排

（一）组织“安全生产月”活动启动仪式。5月底，利用农业部机关学习平台---“每月讲坛”，特邀有关专家为全体机关干部和部属单位领导作安全生产专题讲座并启动我部“安全生产月”活动。

（二）开展宣传贯彻习近平总书记关于安全生产重要讲话精神专题活动。“安全生产月”期间，各单位要专题组织干部职工认真学习由全国组委会组织编印的《习近平总书记关于安全生产重要讲话精神学习读本》（领取时间另行通知），以学习会、座谈会形式组织大家畅谈学习习近平总书记关于安全生产重要指示的体会和感受，进一步加深对安全生产工作重要性的认识，提升对做好安全生产工作的自觉性。

（三）开展安全知识进机关活动。6月初，组织各单位干部职工观看《安全生产典型事故案例盘点（2014版）》警示教育片。各单位应采取专家授课、发放安全生产知识读本等方式开展安全教育活动，重点突出消防安全、交通安全、科研实验、地下空间、险境逃生等安全内容的教育，进一步提高思想认识，强化安全意识，提高安全素质，规范安全行为。

（四）开展安全生产宣传活动。通过农民日报、农村工作通讯、中央电视台农业频道、中国农业信息网、中国农机化导报、中国农民手机报等媒体，对安全生产法律法规及相关知识、农业安全生产工作情况、农业系统开展“安全生产月”活动情况等进行集中宣传报道，营造安全生产的强大舆论氛围。

（五）开展安全应急预案演练活动。“安全生产月”期间，各单位要结合实际，有针对性地开展应急预案演练。通过演练，进一步检验预案各环节响应的顺畅性、实用性及参练人员的知晓性和普及性，充分发挥预案在防范和处置事故中的有效作用。

（六）部属各单位开展灵活多样的活动。部属各单位要结合本单位实际，开展形式多样的安全生产宣传、教育、培训活动，增强广大干部职工的安全生产意识，提高安全生产技能；要以开展“安全生产月”活动为契机，加强管理，落实责任，推进建立安全生产长效机制。

**五、**农业行业重点活动安排

（一）农机行业。组织开展“农机安全生产月”系列活动。一是开展送农机安全知识下乡活动，向广大农民群众及农机手进行安全专题宣讲，切实提高安全生产意识和能力。二是举办农机安全生产宣传咨询活动，6月16日，在山西、广西、湖南三省同步开展农机安全生产宣传咨询日活动，通过现场发放机手安全倡议信、农机安全生产知识宣传画册和农机安全操作挂图，广泛宣传农机安全法律法规和安全操作知识。三是开展农机安全生产事故警示教育活动，组织事故案例和事故模拟应急演练，组织开展农机监理干部与百名农机手谈心对话活动，吸取事故教训，强化安全意识，推动“平安农机”创建活动深入开展。四是开展“三夏”农机安全生产大检查活动，以全国“安全生产月”活动为契机，深入重点地区开展农机安全生产大检查，确保“三夏”农机抢收抢种作业安全。

（二）畜牧行业。“安全生产月”活动期间，广泛宣传《中华人民共和国草原法》、《草原防火条例》等法律法规，普及防火减灾知识，努力提高广大干部群众的防火意识；组织举办“警民携手护草原防火减灾保安全”活动，切实提升草原火灾防控能力；强化草原火灾监测和草原火险气象等级预警预报工作，指导督促各地全面落实各项草原防火措施；加强火灾隐患排查和应急处置，要求重点草原防火省区继续组织力量加大对重点地段和关键部位的巡查力度，严格管控火源，及时消除火灾隐患。

（三）兽医行业。组织各地兽医部门通过培训、咨询、警示教育、应急演练等形式宣传兽医实验室生物安全工作，增强相关人员生物安全意识和防护水平。组织开展兽医实验室生物安全自查和专项检查，及时纠正、严厉查处违法违规行为。

（四）农垦行业。开展宣传贯彻习近平总书记关于安全生产重要讲话精神专题活动，加大宣传力度和深度，营造强大的学习宣传声势。举办安全生产宣传咨询日活动，向职工群众广泛宣讲安全生产知识。开展安全生产事故警示教育周活动，组织垦区各单位集中观看典型事故案例警示教育片《盲洞、迷途》、《安全生产事故典型案例盘点（2014版）》，举办事故案例教育展览和教训反思大讨论警示教育活动。开展安全生产应急预案演练周活动和安全生产检查活动。

（五）渔业行业。组织各级渔业主管部门积极开展“文明渔港”和“平安渔业示范县”创建活动，进一步提高地方政府重视渔业安全生产，推进渔业安全社会化管理，全面提升渔业安全生产管理水平。组织各地开展渔业船员培训，全面核查各地渔船船员持证上岗情况，坚决查处船员无证上岗、未按标准配员的行为，强化船主安全生产主体责任，堵塞管理漏洞。与海事部门联合组织开展商渔船碰撞事故警示教育活动，加强对渔民和商船船员宣传教育，提高渔民和航运企业安全生产意识，让安全生产理念植心入脑。

**六、**有关要求

（一）加强领导，落实责任。各行业、各单位要充分认识开展“安全生产月”活动的重要性，对活动的开展进行动员部署并成立活动组织机构，加强领导，落实责任，精心谋划，周密组织，做到有方案、有项目、有行动。

（二）强化宣传，营造氛围。要结合本行业、本单位实际情况，充分运用报刊、广播、电视、互联网等大众传媒，利用宣传栏、文化橱窗、广播站等阵地，采取演讲、安全知识和技能竞赛、公益广告等多种形式，组织好宣传咨询活动，形成强大宣传声势，唱响安全发展主旋律。

（三）突出重点，注重实效。要从本行业、本单位工作特性出发，有针对性地开展安全生产宣教活动，对安全生产高危行业、重点岗位、特定群体的宣传教育要做到全覆盖、无遗漏。通过开展“安全生产月”活动，使各行业、各单位对安全生产更加重视、更加尽责；使干部职工安全生产意识和防范事故的能力，更加全面、更加提升。为全面完成全年农业安全生产工作目标任务、提高农业安全生产水平做出贡献。

请各单位于7月6日前将2014年“安全生产月”活动开展情况报送部安委会办公室。
