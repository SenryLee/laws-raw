# 国家旅游局公告2014年第14号――旅行社停止经营出境旅游业务公告

## 国家旅游局公告（2014年第14号）

旅行社停止经营出境旅游业务公告

根据《旅行社条例》和《中国公民出国旅游管理办法》以下1家旅行社注销出境旅游业务，自2014年4月10日起停止经营出境旅游业务：

```
序号　　　　旅行社名称　　　　许可证编号　　　　经营场所

01　　　　　海南海方圆国际　　L-HAN-CJ00028海口市海甸四东

旅行社有限公司　　　　　　　　　　　路大成商务度假

公寓办公区四层
```

特此公告。

国家旅游局

2014年4月10日
