# 国家文物局关于景德镇御窑厂遗址珠山南麓遗址、北麓遗址本体保护方案的意见

## 国家文物局关于景德镇御窑厂遗址珠山南麓遗址、北麓遗址本体保护方案的意见（办保函〔2014〕589号）

江西省文物局：

你局《关于呈报〈御窑厂珠山南麓遗址、北麓遗址本体保护方案〉的请示》（赣文物局字〔2014〕143号）收悉。经研究，我局意见如下：

**一、**景德镇御窑厂遗址珠山南麓遗址、北麓遗址本体保护方案缺乏必要的水文地质专项勘察，保护措施针对性不足，且存在干预过大的倾向，我局暂不同意该方案。

**二、**所报方案尚需做以下必要的修改和完善：

（一）应补充水害治理的专项设计。补充必要的水文地址参数，在开展专项水文地质勘察的基础上，查明地表水渗入、地下水侵蚀及粘质土毛细水作用等对遗址本体所造成的不良影响，并提出有针对性的保护措施。同时，应补充现挡水墙的设计依据、设计参数、质量标准、平面布置及施工技术要求等。

（二）遗址本体加固应贯彻最小干预原则，以现状保护为主。建议对较危险的现存陡立的遗址本体的保护以物理方法为主，少用化学方法，主要解决其稳定性问题。同时，不得对遗址本体进行人为切削。

（三）应补充遗址本体渗透加固的渗透深度指标，并开展必要的前期试验，对渗透效果进行检验。

（四）遗址防排水处理应注意与保护房改造有机结合。

（五）补充遗址本体监测及保存环境监测的具体设计。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织方案设计单位对所报方案作进一步修改和完善后，委托我局认定的第三方咨询评估机构进行方案技术评审，并依据第三方咨询评估机构的评估结论进行审批。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

**五、**请你局督促地方人民政府切实加强景德镇御窑厂遗址的保护和管理，做好日常巡查和看护，确保遗址安全。

国家文物局
