# 国家体育总局直属机关工会关于开展2014年度工会统计年报调查工作的通知

各直属工会：

为了及时掌握工会组织建设及工会各项重点工作的进展情况，为工会各项工作提供准确的统计数据资料，根据中央国家机关工会联合会的统一部署，现将国家体育总局2014年度工会统计年报调查工作有关事项通知如下：

**一、**本次统计年报调查的标准时点为2014年9月30日。

**二、**各基层工会编码编制方法为12位数字，前10位为“7133000000”，后2位为基层工会序列号。各直属工会序列表见附件。

**三、**各基层工会要指派专人负责统计工作。填报软件需到http：//ghtj.acftu.org/下载离线填报软件和《2014基层工会调查表》（版本日期2014.9.22完整版）。填报结果通过软件“备份与上报”-“上报到离线版”功能生成电子数据（.dat格式）发送到dw@sport.gov.cn邮箱，并将表格打印，在封页上签字、加盖公章，务必于2014年11月5日前报送总局直属机关工会。

**四、**各直属单位工会要切实加强对工会统计年报调查工作的组织领导，充分认识及时准确掌握统计数据的重要性和必要性，遵守统计法规，坚持实事求是，同时要注意将年报结果与2013年普查的相关数据进行比对，如果出现较大幅度变化，必须认真核对，查找原因，做出书面说明，确保数据真实、有效，高质量地按期完成工会统计年报调查工作任务。
