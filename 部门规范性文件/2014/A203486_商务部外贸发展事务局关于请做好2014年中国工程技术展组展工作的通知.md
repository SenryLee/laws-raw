# 商务部外贸发展事务局关于请做好2014年中国工程技术展组展工作的通知

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门，有关单位：

为展示我国工程承包企业的业绩与实力，宣传和推广我国工程承包行业的技术实力和工程水平，加强我国与有关国家在工程承包领域的合作，2014年10月，商务部将在沙特首都利雅得举办中国工程技术展（以下简称工程展）。为扩大展会影响，保证展会效果，工程展将与2014年沙特国际轨道交通展同期举办。

工程展是商务部非商业性境外办展项目（以下简称非商展）。根据商务部内部职能调整，自2014年起，由外贸发展局负责非商展的组织实施工作。考虑到项目延续性，外贸发展局邀请中国对外工程承包商会作为支持单位，西麦克国际展览有限公司作为合作承办单位，共同负责展会筹备等有关工作。请各地商务主管部门按照有关要求组织本地企业做好参展工作，现将有关事项通知如下：

**一、**时间：2014年10月27-29日

**二、**地点：沙特利雅得国际会展中心 （新馆）

**三、**规模：约3000平方米

**四、**展出内容：各类基础设施，包括道路、港口、交通、电力及电力设备、信息技术、电信设施，工程机械、建材、汽车、船舶、航空航天等。

**五、**展品集货截止时间：8月15日，具体参展事宜将另行通知。
