# 国家安全生产应急救援指挥中心关于印发2014年安全生产应急管理工作要点的通知

## 国家安全生产应急救援指挥中心关于印发2014年安全生产应急管理工作要点的通知（应指综合〔2014〕4号）

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局，各省级煤矿安全监察机构，有关中央企业：

现将《2014年安全生产应急管理工作要点》印发给你们，请结合自身工作实际，认真抓好贯彻落实。

国家安全生产应急救援指挥中心

2014年1月27日

附件：

2014年安全生产应急管理工作要点

2014年安全生产应急管理工作总体思路和任务是：深入贯彻落实习近平总书记、李克强总理等中央领导同志的一系列重要指示精神和全国安全生产电视电话会议、全国安全生产工作会议精神，坚持问题导向、大力固本强基、完善救援体系、健全“一案三制”、提升应对能力，把好“红线”的最后一道防线，为促进全国安全生产形势持续稳定好转做出新的贡献。

**一、**加强应急处置工作。一是抓好国务院安委〔2013〕8号文件精神贯彻落实。分地区、分行业召开宣讲会或座谈会，全面掌握文件精神，准确把握工作重点，认真落实应急管理工作的企业主体责任、地方政府属地责任。指导各地区、各部门、各单位认真对照文件查找存在的问题，制定整改措施，逐项抓好落实。加强事故应急处置警示教育，及时通报有关情况。下半年，组织对文件贯彻落实情况进行专项检查，总结经验，通报工作。二是完善事故应急处置相关工作制度。推动各地区、各行业建立健全事故应急处置分级指导配合制度、总结与评估制度、应急处置奖励与责任追究制度，采取有力措施，加大落实力度，提高事故应急处置工作规范化水平。三是开展应急处置能力建设试点。围绕应急响应、指挥协调、现场管控、应急保障、信息发布、医疗救护、善后处置等重点环节，组织开展国家、地方、企业等不同层面的应急处置能力建设试点。年内，国家安全生产应急救援指挥中心分别在河北、广东组织进行矿山、化工园区试点工作，发挥典型示范作用。四是加强对重特大事故现场应急处置工作的督促指导。根据事故性质和等级及时派出工作组，督促各地区、各有关部门和单位如实上报事故情况，指导事故应对处置工作，协调相关应急资源，确保科学、安全、有效施救。

**二、**创新应急管理体制机制。一是推动地方应急管理机构建设。认真落实国务院关于加强安全生产应急管理机构建设的指示要求，指导市（地）级和重点县完善组织系统、配备专职人员、明确工作职责、建立制度机制、落实保障条件，充分发挥应急管理机构的组织协调和综合监管作用。二是健全完善应急联动机制。加强联合应对事故灾难的预测预警、指挥协调和救援保障等机制建设，强化预防和处置生产安全重特大事故区域联动协作机制、军地应急救援联动机制，形成地企一体、政企一体、军地一体协调应对事故灾难的格局。三是创新化工园区应急管理模式。全面总结推广广东惠州大亚湾化工园区在救援基地建设、应急救援队伍建设、应急资源整合及相关配套规章标准制度建设等方面的经验做法和其他地区、部门、单位创造的好经验、好做法，推动应急管理体制机制、手段方法创新。四是开展安全生产应急管理大检查。采取暗查抽查方式，组织以应急预案、应急演练、应急机构、应急队伍建设和重大危险源监控、应急物资储备等为主要内容的应急管理大检查工作，推动各地区、各部门、各单位应急管理责任落实。充分发挥应急救援队伍专业技术优势，组织各类应急队伍积极参加隐患排查治理工作。深入开展与煤矿矿长谈话工作，督促落实煤矿安全“双七条”规定和应急管理工作要求。

**三、**加强应急管理法制建设。一是加快安全生产应急管理条例立法进程。围绕应急准备、应急响应、应急救援、应急评估、应急保障、监督与管理等重大问题开展立法研究，进一步理清政府、企业、社会组织在平时应急准备、战时应急救援中的职责与义务，积极协调有关部门推动条例出台工作。二是加强安全生产应急管理标准制定工作。修订《生产安全事故应急预案管理办法》、《煤矿安全规程》（应急救援部分）、《矿山救援规程》、《生产安全事故应急演练指南》，研究制定应急预案评审指南。推动地方标准制定工作，强化依法管理。三是完善安全生产应急管理配套政策措施。积极协调相关部门和地区从国家和地方两个层面研究出台国家（区域）矿山应急救援队伍运行维护费用、应急处置工作保障等财政支撑政策。出台实施《国家投入应急救援国有资产监督管理暂行办法》。四是依法严厉查处违章指挥行为。大力开展吸取吉林通化矿业集团八宝煤矿、四川芙蓉集团杉木树煤矿瓦斯爆炸事故和山东中石化东黄输油管道原油泄漏爆炸事故应急处置教训活动，严格按照有关规定规范应急处置工作中的各类指挥行为。加大事故应急处置的跟踪、评估力度，依法追究违规指挥责任。五是抓好安全生产应急管理“十二五”规划实施工作。按照规划任务分工，建立以政府为主导、安全监管部门统一管理、行业主管部门分工负责的工作机制。完善绩效考核制度，对规划明确的目标任务、建设项目等完成情况进行调度分析，及时采取有效措施，全面推动规划落实。

**四、**强化应急预案和演练工作。一是建立健全现场处置方案。将应急处置措施细化、分解、落实到每个具体岗位，深入开展危险因素辨识和应急能力评估，进一步督促基层企业完善现场处置方案，提高第一时间应对事故灾难水平。二是开展应急预案建设试点。按照实用管用和卡片化的要求，组织开展应急预案简明化标准化研究试点，推动各级政府、各类生产经营单位应急预案建设。指导企业编制班组和重点岗位应急处置要领。三是强化应急预案评审、备案和衔接工作。加强对应急预案编制过程的形式审查和备案后实施情况的执法检查，注重将风险评估和应急资源调查报告纳入备案内容，建立地方各级人民政府与企业相衔接的应急预案体系，提高应急预案的针对性、实用性和操作性。四是加强各级、各专业应急预案演练。以有限空间作业和人员密集型企业等行业（领域）为重点，以班组、车间一线职工为对象，深入开展安全生产月应急预案演练周活动。

**五、**推动应急科技进步。一是加强安全生产应急平台建设。按照国家应急平台体系建设要求和标准，加快推进省级、地（市）级、重点县和有关部门、中央企业、国家矿山应急救援队应急平台建设，推动开展互联互通工作。进一步深化应急资源普查，全面摸清和掌握应急资源情况，充分利用现有各专项业务数据资源完善应急资源数据库。二是抓好应急救援科技成果推广应用。认真落实煤矿安全生产“七大攻坚”举措，突出抓好重大矿山事故钻孔救援关键技术及配套装备应用研究。加大安全生产应急救援科技“四个一批”项目实施力度，建立产学研用合作机制。加强应急救援关键技术与装备的科技攻关与研发，推动科技成果转化、推广应用及示范工程建设，提高应急救援科技保障能力。三是组织开展应急救援装备的成套性和适应性评估。针对近年来重特大事故案例，对不同事故应急处置所需装备的成套性、适应性进行综合评估，及时查找存在问题，改进装备配备工作。探索救援装备投资走市场化、社会化、合作化新路子。四是开展事故救援关键技术装备征集活动。收集整理煤矿灾区二次爆炸危险性判定、矿井透地通信、危险化学品泄漏爆炸预警等技术装备，为事故救援提供技术装备支撑。

**六、**加大应急培训与宣传教育力度。一是突出应急管理工作培训重点。抓好政府分管领导和监管监察机构、相关企业负责同志的培训，提高应急处置指挥能力。加大对地（市）级、重点县应急管理人员业务培训，不断提高业务水平和履职能力。总结推广有关地区企业一线员工应急培训经验，推动企业应急培训工作深入开展。二是加强应急救援队伍能力建设。开展经常性思想政治教育工作，坚定队伍理想信念，培养队伍职业意识，强化队伍敬业精神，激发队伍工作活力。落实国家矿山应急救援队“六加一”试点成果，深化“四队一组”功能建设。进一步强化区域矿山、国有大（中）型企业等应急救援队能力建设。积极推动实训演练基地和矿山医疗应急救援队项目建设。严格落实救护队质量标准化考核规范等制度标准，大力开展以新技术、新装备、新战术应用为重点的救援队伍指战员培训和训练，全面提升实战能力。三是深化应急宣传教育。结合“六五”普法、“安全生产月”和“防灾减灾日”等重大活动，开展安全生产应急理念、法规政策和应急知识普及工作，增强全民应急意识。建立省、市、县和大中型企业的应急管理宣传教育通讯员队伍体系，定期组织通讯员业务技能培训。协调宣传部门和新闻媒体推出一批有重大影响力的先进典型，积极营造向社会传递正能量的舆论氛围。
