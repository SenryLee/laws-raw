# 国家铁路局关于发布铁道行业标准的公告——工程建设标准2014年第4批

## 国家铁路局关于发布铁道行业标准的公告

（工程建设标准2014年第4批）

国铁科法〔2014〕60号

现公布《高速铁路设计规范》（TB 10621-2014）行业标准，自2015年2月1日起实施。《高速铁路设计规范（试行）》（TB 10621-2009）同时废止。

本标准由国家铁路局科技与法制司负责解释，由中国铁道出版社出版发行。

国家铁路局

2014年12月1日
