# 国家测绘地理信息局关于印发《2014年全国测绘地理信息普法依法治理工作要点》的通知

## 国家测绘地理信息局关于印发《2014年全国测绘地理信息普法依法治理工作要点》的通知（国测法发〔2014〕2号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司室：

为做好2014年全国测绘地理信息普法依法治理工作，推进“六五”普法规划各项目标全面落实，根据《2014年全国普法依法治理工作要点》（普法办发〔2014〕1号），结合国家测绘地理信息局年度重点工作计划，我局制定了《2014年全国测绘地理信息普法依法治理工作要点》。现印发给你们，请结合实际，认真贯彻落实。

国家测绘地理信息局

2014年4月23日

2014年全国测绘地理信息普法依法治理工作要点

2014年是全面深化改革的开局之年，是落实“六五”普法规划的关键之年。根据《2014年全国普法依法治理工作要点》，2014年全国测绘地理信息普法依法治理工作总体思路是：以科学发展观为指导，全面贯彻落实党的十八大、十八届二中、三中全会及习近平总书记系列重要讲话精神，紧紧围绕测绘地理信息工作大局，抓好法制宣传教育活动，推动测绘地理信息“六五”普法规划全面落实，加强测绘地理信息法治建设，为测绘地理信息事业健康发展营造良好的法治环境。

**一、**贯彻落实党的十八届三中全会精神，将法制宣传教育工作推向新高度

（一）深入学习宣传党的十八大和十八届二中、三中全会以及习近平总书记有关社会主义民主法治建设系列重要讲话精神，深刻理解和把握社会主义民主法治建设的精髓，按照新目标、新要求，加强法制宣传教育工作，把测绘地理信息法制宣传教育工作不断推向新高度。

（二）加强以宪法为核心的法制宣传教育工作，采取有效措施，使广大测绘地理信息干部职工充分了解我国的根本政治制度、基本经济制度，增强对国家的责任感和使命感。尤其是各级测绘地理信息行政主管部门的领导干部和工作人员，要带头学习宪法，遵守宪法，维护宪法权威，按照宪法和法律赋予的权力，履行好自己的职责。

（三）着重学习宣传《测绘法》及其配套法规规章，特别是对新颁布和新修订的法规规章，要深刻领悟其精神，提高依法行政的法治理念。《地图管理条例》颁布后，各级测绘地理信息行政主管部门要迅速组织学习，并开展宣传贯彻和培训工作，落实好地图管理工作中各项新规定、新要求。

（四）加强与测绘地理信息事业发展密切相关法律法规的学习，尤其是《行政许可法》、《行政处罚法》等规范政府行为的法律法规，不断提高测绘地理信息行政主管部门依法行政的能力和水平。根据测绘地理信息工作特点，还应学好有关突发事件应对、规范招投标等方面的法律法规，增强应急保障能力，强化市场监管，为营造公开公平公正的测绘地理信息市场环境和良好的竞争秩序提供法律保障。

**二、**抓好重点对象学法，增强尊法守法用法意识

（五）切实加强对各级测绘地理信息行政主管部门领导干部、公务员的法制宣传教育工作，不断拓展学习的新方法、新途径。通过自学，集中培训，以考促学等形式，实现领导干部、公务员法制教育制度化、经常化。通过学习，不断提高领导干部依法决策、依法办事的意识及能力。

（六）为不断提高行政执法人员依法行政水平和执法能力，熟练掌握和运用法律法规履行行政执法职责，要继续加大对测绘地理信息行政执法人员的培训力度。按照有关规定，各级测绘地理信息行政主管部门应当组织好对相应测绘地理信息行政执法人员的培训工作，严格行政执法人员岗位培训考核制度，真正实现严格规范公正文明执法。

（七）促进各测绘地理信息从业单位学法知法守法和用法的法制宣传教育工作，要求测绘地理信息从业单位及相关人员要熟悉了解掌握相关的法律法规知识，提高依法经营的自觉性，以及运用法律维护自己的合法权益和运用法律手段解决各种经济纠纷的能力和水平，为测绘地理信息事业的健康发展创造良好的社会环境。

**三、**继续深化“法律六进”活动，不断扩大法制宣传覆盖面

（八）以“8·29”测绘法宣传日、“美丽中国”第二届全国国家版图知识竞赛和少儿手绘地图大赛等宣传活动为抓手，广泛、深入普及测绘地理信息法律法规及国家版图知识，切实推进测绘地理信息法制宣传教育活动进机关、进乡村、进社区、进学校、进企业、进单位，提升宣传效果，将“法律六进”活动落实到实处。

（九）积极拓展法治宣传阵地，充分利用公共场所电子显示屏、楼宇电视和公交、地（城）铁等交通工具上的移动电视开展法制宣传，在车站、机场、医院、银行等公共区域，组织开展法制报告会、法律知识竞赛、法制教育征文、演讲比赛等群众喜闻乐见、寓教于乐的宣传活动，使宣传活动更便捷，更贴近群众，增强法制宣传教育的影响力、渗透力和感染力。

（十）加大对普法依法治理工作的宣传教育力度，一方面充分利用中国测绘报、政府网站、广播、电视、报刊、网络和移动通讯等大众媒体，另一方面充分发挥微博、微信、QQ群等新媒体的宣传作用，形成新媒体普法平台的集群优势和规模效应，不断扩大新媒体普法宣传的覆盖面。

**四、**不断加大依法治理力度，促进地理信息产业健康发展

（十一）依法扩大监督执法范围，提高监督执法频次，完善监督执法方式和手段，进一步规范测绘地理信息市场秩序。健全联合执法机制，继续做好对重点领域测绘地理信息违法案件的查处工作，尤其是规范测绘地理信息项目招投标，打击恶意竞争等方面，加大知识产权保护，推进市场交易规范化，营造公平竞争的发展环境。

（十二）完善市场诚信制度体系，进一步贯彻落实《测绘地理信息市场信用信息管理暂行办法》，严格执行评价标准，做好测绘地理信息单位信用评价工作。要不断深入推进测绘地理信息单位依法治理工作，调整优化测绘地理信息产业结构，全面提升测绘地理信息为经济社会发展的保障能力和服务水平。

（十三）进一步健全法制宣传教育工作的领导体制和工作机制，要积极与测绘地理信息学会、协会等社团组织开展普法共建活动，充分利用社会资源，扩大宣传领域，提升社会影响力，促进全社会熟悉了解并自觉遵守测绘地理信息法律法规，依法从事测绘地理信息活动。同时，要加强普法依法治理工作交流，不断提高法制宣传教育工作水平。
