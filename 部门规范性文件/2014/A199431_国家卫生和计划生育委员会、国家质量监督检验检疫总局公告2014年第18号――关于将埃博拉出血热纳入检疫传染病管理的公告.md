# 国家卫生和计划生育委员会、国家质量监督检验检疫总局公告2014年第18号――关于将埃博拉出血热纳入检疫传染病管理的公告

## 国家卫生和计划生育委员会、国家质量监督检验检疫总局公告（2014年第18号）

关于将埃博拉出血热纳入检疫传染病管理的公告

经国务院批准，现将埃博拉出血热纳入《中华人民共和国国境卫生检疫法》规定的检疫传染病管理。

特此公告。

国家卫生和计划生育委员会

国家质量监督检验检疫总局

2014年8月27日
