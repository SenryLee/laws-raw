# 中国地震局党组关于任利生、孙亚强、陈凤学3同志职务任免的通知

中共吉林省地震局党组：

2013年12月20日中国地震局党组决定，并征得中共吉林省委同意，免去任利生同志吉林省地震局局长、党组书记职务，另有任用。

2014年2月11日中国地震局党组决定，并征得中共吉林省委同意，任命孙亚强同志为吉林省地震局局长、党组书记；任命陈凤学同志为吉林省地震局巡视员，免去其吉林省地震局副局长、党组成员职务。

特此通知

中国地震局党组

2014年5月5日
