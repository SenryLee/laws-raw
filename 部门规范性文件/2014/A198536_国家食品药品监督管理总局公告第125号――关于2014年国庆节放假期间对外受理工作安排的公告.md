# 国家食品药品监督管理总局公告第125号――关于2014年国庆节放假期间对外受理工作安排的公告

## 国家食品药品监督管理总局公告（第125号）

关于2014年国庆节放假期间对外受理工作安排的公告

根据《国务院办公厅关于2014年部分节假日安排的通知》，现将国家食品药品监督管理总局行政事项受理服务和投诉举报中心2014年国庆节放假期间对外受理工作安排通知如下：

2014年10月1日-7日放假；2014年9月28日（星期日）全天受理； 9月30日（星期二）上午半天受理，下午内部整理；10月11日（星期六）全天受理。

请大家合理安排递交资料时间，以免影响申报受理。

国家食品药品监督管理总局行政事项受理服务和投诉举报中心

二〇一四年九月十九日
