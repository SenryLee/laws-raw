# 农业部公告第2138号――新兽药注册目录

【主要成分与含量】　主要成分为多肽和核糖，成品中每毫升多肽含量应不低于1.5mg，核糖含量应不低于45µg。

【不良反应】　无不良反应。

【注意事项】　（1）浑浊或变色者勿用。

（2）注射器械应无菌，注射部位应消毒。

（3）用过的器具和未用完的注射液等应进行无害化处理。

【规格】　（1）5ml/瓶　（2）10ml/瓶　（3）20ml/瓶　（4）50ml/瓶　（5）100ml/瓶

【贮藏与有效期】　2～8℃保存，有效期为24个月。

【包装】　10瓶/盒

【批准文号】

**三、**非泼罗尼滴剂说明书和标签

（一）非泼罗尼滴剂说明书

兽用外用药

【兽药名称】

通用名：非泼罗尼滴剂

商品名：

英文名：Fipronil Spot On Solutions

汉语拼音：Feipoluoni Diji

【主要成分】 非泼罗尼

【性状】 本品为淡黄色澄清液体。

【药理作用】 药效学 非泼罗尼与昆虫神经中枢细胞上γ－氨基丁酸受体结合，阻塞神经细胞的氯离子通道，从而干扰虫体中枢神经的正常功能，导致昆虫和螨的中枢神经系统过度兴奋而死亡。

药动学 非泼罗尼为高亲脂性药物，药物滴在犬的肩胛骨间的皮肤上，藉由皮肤表面的油脂扩散，投药24小时内分布至全身表面并储存于皮脂腺中，之后经由皮肤正常的皮脂分泌而持续释放至皮肤表面及毛发上。经皮肤吸收进入血液的量很少，但分布较为广泛，主要贮存在脂肪组织。进入全身系统的非泼罗尼主要代谢为其磺酰物，与未代谢的非泼罗尼通过尿液和粪便排出体外。

【适应证】用于驱杀犬体表的跳蚤。

【用法与用量】 外用。滴于皮肤：用手分开用药处毛发，使其表皮外露，轻轻挤压药管使药液沿短线均匀滴在宠物皮肤表面，自热风干。对于跳蚤感染的地区或病例间隔1个月用药一次。

|  |  |  |
| --- | --- | --- |
| 犬体重（kg） | 选择涂药部位 | 用药量（ml） |
| 体重＜10　（小型犬） | 颈部3点 | 0.67 |
| 10≤体重＜20（中型犬） | 颈、背部5点 | 1.34 |
| 20≤体重＜40（大型犬） | 颈、背部5点及前肢腋下 | 2.68 |
| 体重≥40（巨型犬） | 颈、背部5点及腋下、腹股沟 | 4.02 |

【不良反应】 舔食药液的犬出现短时流涎，主要是由于药物载体中含酒精成分所致。

【注意事项】 1.使用过程中避免药液污染水、食物或饲料；贮存时避免动物或儿童触及。

2. 禁止内服。误服后的处理：若能够吞咽，可灌服清水，并及时就医。

3. 防止药液溅入眼内，若不慎溅入，立即用清水充分冲洗眼睛15～20分钟，直至不适感消失，若仍有明显不适感，应及时就医。

4. 勿与皮肤直接接触，若沾染皮肤，用肥皂水充分清洗，若冲洗后仍有不适感，应及时就医。

5. 不得用于8周龄以下的幼犬。

6. 仅供外用。

【休药期】 无。

【有效期】 二年。

【规格】 （1）0.67ml：67mg　（2）1.34ml：134mg　（3）2.68ml：268mg　（4） 4.02ml：402mg

【包装】 0.67 ml/支，1.34 ml/支，2.68 ml/支，4.02 ml/支。

【贮藏】 遮光，在阴凉干燥处保存。

【批准文号】

【生产企业】湖北美天生物科技有限公司
