# 农业部办公厅关于做好2014年花卉产业数据统计工作的通知

农办农〔2014〕51号

各省（自治区、直辖市）农业（农牧、农村经济、林业）厅（委、局）花卉主管部门，北京市园林绿化局：

为做好2014年全国花卉产业统计工作，现就有关事项通知如下。

一、填报花卉产业统计报表

按照《花卉产业统计报表制度》要求，做好2014年本省（区、市）花卉产销情况、花卉生产经营实体情况、花卉保护地栽培情况、主要花卉产销情况等数据的汇总和整理工作，并通过花卉产业综合统计系统填报相关报表，填报系统的网址为：http://cjkz.agri.gov.cn。

二、总结2014年花卉产业发展情况

对本省（区、市）2014年度花卉产业发展情况进行总结，内容包括本地区花卉生产的基本情况及特点、主要做法及存在问题、2015年花卉产业发展趋势。

三、有关要求

请于2015年3月10日前完成网络填报，并将有关统计报表及总结文字材料发送到zzyjzc@agri.gov.cn。
