# 水利部关于全国中小河流治理项目管理系统升级完善设计与部署（2014年度）评标结果公示

## 全国中小河流治理项目管理系统升级完善设计与部署（2014年度）评标结果公示

招标人：水利部海河水利委员会

全国中小河流治理项目管理系统升级完善设计与部署（2014年度）项目在海委监察处的监督下，于2014年4月10日在海委主楼六楼会议室完成开标、评标工作。评标委员会对所有投标人的投标文件进行综合评审后，推荐：

第一中标候选人：天津市龙网科技发展有限公司

第二中标候选人：天津开发区先特网络系统有限公司

现将该评标结果予以公示，接受社会各界监督。公示期为2014年4月11日至2014年4月13日。
