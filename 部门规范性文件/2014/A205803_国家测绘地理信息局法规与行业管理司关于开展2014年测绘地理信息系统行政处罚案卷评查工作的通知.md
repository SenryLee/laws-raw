# 国家测绘地理信息局法规与行业管理司关于开展2014年测绘地理信息系统行政处罚案卷评查工作的通知

## 国家测绘地理信息局法规与行业管理司关于开展2014年测绘地理信息系统行政处罚案卷评查工作的通知（测管函〔2014〕8号）

各省、自治区、直辖市测绘地理信息行政主管部门：

为落实行政执法责任制，增强层级监督，进一步规范行政执法行为，提高行政执法能力和水平，根据《测绘地理信息行政处罚案卷评查暂行办法》，国家局每年都组织开展测绘地理信息系统行政处罚案卷评查工作（以下简称“案卷评查工作”）。各级测绘地理信息行政主管部门通过案卷评查工作，提高了行政执法水平，强化了行政执法监督，完善了行政处罚案卷评查的各项制度和案卷评查标准，进一步提高了案卷评查工作的科学性、规范性，案卷评查工作取得了实效。

2014年国家局还将继续组织开展案卷评查工作。评查范围为各级测绘地理信息行政执法机关2013年7月1日至2014年6月30日期间，适用一般程序并已办结的测绘地理信息行政处罚案卷。评查内容、标准，以及评查步骤和时间安排与2013年开展的案卷评查工作安排相同。

希望各级测绘地理信息行政主管部门加强组织领导，明确工作责任，确保案卷评查工作的顺利进行，工作中遇到的问题请及时与我司联系。
