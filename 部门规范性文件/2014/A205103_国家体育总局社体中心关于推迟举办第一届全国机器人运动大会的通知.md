# 国家体育总局社体中心关于推迟举办第一届全国机器人运动大会的通知

## 国家体育总局社体中心关于推迟举办第一届全国机器人运动大会的通知（社体字〔2014〕167号）

各省、自治区、直辖市、计划单列市、新疆生产建设兵团体育局社体中心（群体处、体总秘书处），总参军训和兵种部体育训练局，总政宣传部文化体育局，各行业体协，有关大专院校：

我们原定于2014年8月7日至17日在黑龙江省哈尔滨市举行第一届全国机器人运动大会（见社体字〔2013〕445号），现因准备工作不够充分及其他原因不能如期举办，拟推迟到2015年举办，具体时间另行通知。

由于我们工作不慎，给你们带来的工作影响，敬请谅解。

特此通知。

体育总局社体中心

2014年3月26日
