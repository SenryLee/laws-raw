# 国家卫生计生委办公厅关于印发培育和践行社会主义核心价值观2014年工作方案的通知

## 国家卫生计生委办公厅关于印发培育和践行社会主义核心价值观2014年工作方案的通知（国卫办宣传函〔2014〕378号）

各省、自治区、直辖市卫生计生委（卫生厅局、人口计生委），新疆生产建设兵团卫生局、人口计生委，委机关各司局，委直属和联系单位：

根据中宣部办公厅关于印发《2014年组织推动培育和践行社会主义核心价值观工作指导方案》（中宣办发[2014]12号）的通知精神，现制定我委培育和践行社会主义核心价值观2014年工作方案。

**一、**深入学习，促进广大卫生计生工作者准确理解和全面把握社会主义核心价值观

（一）深入学习领会。通过举办讲座、推出理论文章、举办“面对面大讲堂”、“读讲一本书”报告会、典型事迹报告会等多种形式，组织全系统认真学习贯彻中央《关于培育和践行社会主义核心价值观的意见》，促进广大干部深刻领会社会主义核心价值观的重要内涵。

（二）组织大讨论。在全系统开展社会主义核心价值观大讨论，通过召开座谈会、在线访谈等形式，邀请专家学者、先进人物、实际工作者等充分交流研讨，在讨论中进一步促进深入理解和准确把握社会主义核心价值观的内涵，并进一步挖掘提炼卫生计生核心价值观。

（三）开展主题征文。上半年在全系统开展“培育和践行社会主义核心价值观”主题征文活动，紧紧围绕“三个倡导”24个字，进一步深化认识，增强培育和践行社会主义核心价值观的自觉性、坚定性。

（四）组织课题研究。把卫生计生核心价值体系内容及传播研究纳入科研课题研究规划，组织有关专家学者深化研究，推出有针对性和影响力的研究成果，为总结提炼系统核心价值观提供智力支持。

（五）创作文艺作品。通过搭建创作平台、提供智力支持、推荐评奖评优等方式积极支持鼓励文艺工作者创作反映卫生计生核心价值观的各种文艺作品。不断培养卫生计生工作者的文艺素养，提高其自觉运用文艺作品培育、弘扬核心价值观的能力。

**二、**积极宣传，营造培育和践行社会主义核心价值观的良好舆论氛围

（一）开办网上专栏。在健康报、人口报和我委官方网站开办专栏，刊登中央主要精神部署、大讨论主要成果、优秀征文来稿，以及地方涌现的典型人物和先进事迹，营造浓厚宣传氛围。

（二）组织新闻采访。结合第二批党的群众路线教育实践活动，协调中央主要媒体，组织行业媒体，大力宣传报道各地卫生计生窗口单位优质服务的工作经验和敬业奉献的先进事迹；官方微博、微信不定期推出相关内容，积极传播社会主义核心价值观。

**三、**抓好结合，把培育和弘扬社会主义核心价值观贯彻到各项工作中

（一）与构建和谐医患关系宣传相结合。加强卫生计生核心价值观的高层倡导，与中央党校、国家行政学院等干部培训阵地合作，加强医学人文与医患沟通等内容的宣传倡导。

（二）与卫生计生典型宣传相结合。积极指导办好2013-2014年度“我最喜爱的健康卫士”、“群众满意的医疗卫生机构”和“中国计生十佳人物”的推选，通过媒体宣传、集中展示等活动，大力宣传医德楷模、医德标兵和健康卫士等先进事迹；指导地方做好“最美人物”、“中国好人”等宣传推介活动，加大向央视各类宣传平台的推荐力度。

（三）与重要主题宣传相结合。结合新中国成立65周年以及卫生计生重要节庆日、纪念日，开展各类宣传活动；通过“五个一”工程奖、“中国人口文化奖”等评选，加大对社会主义核心价值观题材优秀文艺作品的宣传评价，引领卫生计生文艺作品创作方向。

（四）与优化户外宣传环境相结合。推出一批反映卫生计生核心价值观的标语口号，更新宣传内容，优化宣传载体，加大覆盖力度，将弘扬高尚医德医风与营造尊医重卫风尚有机结合，引导公众建立合理就医预期，打造户外正能量。

国家卫生计生委办公厅
