# 国家外国专家局办公室关于公布2014年度境外培训机构名单的通知

## 国家外国专家局办公室关于公布2014年度境外培训机构名单的通知（外专办发〔2014〕39号）

各省、自治区、直辖市及副省级城市外国专家局，新疆生产建设兵团外国专家局，国务院各部委、各直属机构引智归口管理部门：

根据《国（境）外培训渠道管理暂行办法》（外专发〔1999〕4号）规定，现将2014年度境外培训机构认定情况予以公布。

**一、**经有关单位推荐和评估，国家外国专家局评审，2014年共认定301家境外培训机构（名单附后）。

（一）新认定以下12家境外培训机构：

1.瑞士圣加伦马利克管理中心（编号144101）

2.德国农业协会（编号144901）

3.韩国能率协会（编号148201）

4.韩国韩中文化经济友好协会（编号148202）

5.美国国际城市管理协会（编号140001）

6.加拿大皇家大学（编号140101）

7.英国斯旺西大学（编号144401）

8.罗马尼亚中-欧卓越中心（编号144001）

9.香港大学专业进修学院（编号145201）

10.中谊国际（香港）管理学院有限公司（编号145202）

11.香港文汇报有限公司（编号145203）

12.香港大公国际传媒学院有限公司（编号145204）

（二）暂停与以下6家境外培训机构合作关系：

1.美国克勤国际企业集团（编号990010）

2.英国格林威治大学（编号274402）

3.德国亚琛技术大学（编号214908）

4.意大利依斯沃知识体系有限公司（编号253901）

5.澳大利亚墨尔本大学（编号226101）

6.澳大利亚热带北昆士兰州技术学院（编号226102）

（三）恢复与以下3家境外培训机构合作关系：

1.美国乔治亚大学（编号280002）

2.美国美中商业咨询中心（编号990024）

3.香港管理专业协会（编号995204）

**二、**各地区各部门出国（境）培训归口管理部门要认真执行《国（境）外培训渠道管理暂行办法》等有关规定，及时反映与境外培训机构合作情况及有关问题。

**三、**各单位在组织出国（境）培训项目时，要选择与培训主题专业对口的高层次大学、专业培训机构等境外培训机构合作，提高培训的针对性和实效性。

**四、**境外培训机构要遵守中国政府有关出国（境）培训的政策规定，切实做好培训承接工作，确保培训质量和效益。

**五、**国家外国专家局出国培训管理司将严格管理，严肃查处机构使用中出现的违纪违规问题，杜绝中介转手等不正之风。对违反《国（境）外培训渠道管理暂行办法》等有关规定的境外培训机构，停止与其继续合作。
