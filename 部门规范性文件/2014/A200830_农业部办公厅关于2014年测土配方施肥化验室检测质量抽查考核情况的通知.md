# 农业部办公厅关于2014年测土配方施肥化验室检测质量抽查考核情况的通知

## 农业部办公厅关于2014年测土配方施肥化验室检测质量抽查考核情况的通知（农办农[2014]30号）

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）厅（委、局），新疆生产建设兵团农业局，黑龙江省、广东省农垦总局：

近期，我部在未经考核的全国测土配方施肥补贴项目县（场、单位）中，随机选择100个县（场、单位）进行化验室检测质量抽查考核。现将抽查考核情况通报如下。

**一、**考核结果

此次考核的100个项目县（场、单位）涉及30个省（自治区、直辖市）及新疆生产建设兵团、黑龙江农垦。其中，有99个项目县（场、单位）按时上报了检测结果，云南省盈江县因受灾未上报检测结果。考核内容涉及土壤pH、有机质、全氮、有效磷和速效钾等5项。经专家评审，本次抽查考核有77个项目县（场、单位）化验室的检测数据合格，合格率为77.8%（见附件1）。在22个不合格的项目县（场、单位）化验室中，5项考核结果均不合格的项目县（场、单位）化验室有1个；3项考核结果不合格项目县（场、单位）化验室有1个；2项考核结果不合格项目县（场、单位）化验室有7个；1项考核结果不合格项目县（场、单位）化验室有13个（见附件2）。

**二、**存在的主要问题

一是省际之间差异较大。本次抽查考核有5个省（区、市）的所有被抽查项目县（场、单位）考核结果均不合格，有16个省（区、市）的所有被抽查项目县（场、单位）考核结果均合格，两者之间形成了较大的反差。

二是个别项目县检测结果存在显著偏差。本次抽查考核不合格的项目县（场、单位）由于对检测数据质量把关不严，对明显不合理检测结果未进行排查，导致检测数据偏差较大。如天津市宝坻区、山西省右玉县、福建省罗源县、福建省松溪县、江西省万载县、西藏自治区扎囊县和黑龙江农垦前哨农场在全氮考核项目检测结果明显高出正常土壤全氮含量10倍以上。

三是部分项目县质量把关意识淡薄。本次抽查考核不合格的项目县（场、单位）中存在少数化验室“样品检测结果汇总表”未严格执行“批准人、审核人、制表人”三级审核签字，对检测结果的数值修约未严格依据相关要求执行。

**三、**整改要求

一是抓好整改工作。各省（区、市）及中央直属垦区农业部门要督促本次抽查考核不合格项目县（场、单位）认真分析查找原因，强化样品检测、方法确认、环境控制、仪器设备管理和质量控制等各环节的管理，按时完成相关整改工作。8月31日前，以省为单位将整改情况报我部种植业管理司和全国农业技术推广服务中心。我部将根据整改落实情况，对不合格项目县（场、单位）进行重新考核。

二是强化管理与培训。各省（区、市）及中央直属垦区农业部门要高度重视土壤质量检测工作，加强对项目县（场、单位）化验室的督导，促进项目县（场、单位）化验室“找差距、提水平”，确保检测数据质量。通过集中培训和现场指导等多种方式，进一步提高化验室管理水平和检测能力。

各省（区、市）农业部门及中央直属垦区在安排明年测土配方施肥补贴项目资金时，要适当调减本次抽查考核不合格的项目县（场、单位）的项目资金，对整改后重新考核仍不合格的项目县（场、单位），要暂停实施测土配方施肥项目。
