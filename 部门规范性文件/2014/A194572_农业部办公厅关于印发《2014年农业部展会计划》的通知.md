# 农业部办公厅关于印发《2014年农业部展会计划》的通知

## 农业部办公厅关于印发《2014年农业部展会计划》的通知（农办市[2014]1号）

各省（自治区、直辖市）农业（农牧、农村经济）、畜牧、兽医、渔业、农垦、农产品加工厅（委、局），新疆生产建设兵团农业局，部机关各司局、有关直属事业单位和行业协会：

《2014年农业部展会计划》业经农业部2014年第1次常务会议审议通过，现予印发。

请各主办、承办单位切实负起牵头责任，按照《农业部展会工作管理办法》（农市发﹝2014﹞1号）要求，精心组织，认真筹备，注重实效，防止铺张浪费，在展会结束后一个月内，向我部市场与经济信息司提交书面总结。

联系电话：010-59193279，邮政编码：100125，电子邮箱：nybscc@126.com。
