# 环境保护部办公厅关于印发《环境保护部2014年度业务培训计划》的通知

## 环境保护部办公厅关于印发《环境保护部2014年度业务培训计划》的通知（环办函[2014]212号）

各省、自治区、直辖市环境保护厅（局），新疆生产建设兵团环境保护局，辽河保护区管理局，解放军环境保护局，机关各部门，各部属单位：

为深入贯彻落实党的十八届三中全会和2014年全国环境保护工作会议精神，积极探索环保新路、推进生态文明、建设美丽中国，努力建设高素质的环保干部队伍，我部制定了《环境保护部2014 年度业务培训计划》（以下简称《计划》），现印发给你们，请结合实际，认真落实。

各部门、各单位要认真贯彻中央关于改进工作作风、密切联系群众“八项规定”精神，加强学风建设，严肃培训纪律，转变工作作风，厉行勤俭节约，反对铺张浪费；严格执行《中央和国家机关培训费管理办法》等规定，严肃培训财经纪律；要认真执行培训计划，加强监督管理，做好服务保障，开展效果评估，切实提高培训针对性和实效性。

本《计划》内的培训班，面向环保系统举办的，由各级环保部门负责组织学员参加；面向社会举办的，由各地根据工作需要，自主决定是否派人参加。培训经费来源为预算内经费的，培训费（含食宿费）由主办单位承担；培训经费来源为其他的，需参照《中央和国家机关培训费管理办法》有关标准缴纳培训费（含食宿费），各地各部门可自愿参加。
