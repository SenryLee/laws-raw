# 国土资源部公告2014年第3号――关于聘任第四批国家级矿产督察员的公告

## 国土资源部公告（2014年第3号）

关于聘任第四批国家级矿产督察员的公告

根据《国土资源部关于聘任第四批国家级矿产督察员的通知》（国土资电发〔2013〕54号）的要求，国土资源部已组织完成第四批国家级矿产督察员推荐、审核、培训和考试工作，共有1402名同志被聘任为第四批国家级矿产督察员，任期3年，从2014年1月1日至2016年12月31日止，现予以公告。

2014年3月21日
