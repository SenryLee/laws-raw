# 国家体育总局办公厅关于印发《体育总局青少司2014年工作要点》的通知

各省、自治区、直辖市体育局，新疆生产建设兵团体育局、有关直属单位：

为开展好2014年青少年体育工作，推动青少年体育科学发展，现将《体育总局青少司2014年工作要点》印发给你们，供你们参考，并结合实际，做好本地区青少年体育工作。

体育总局办公厅

2014年1月16日

体育总局青少司2014年工作要点

2014年是实现《青少年体育“十二五”规划》的关键之年。青少司将认真学习贯彻党的十八大和十八届三中全会精神，进一步加强顶层设计，继续推动政策法规建设工作；强化对各级公办体校贯彻落实国办23号文件的检查督导，召开全国业余训练工作会议，突出体制机制创新，进一步调动各省市和项目中心的积极性，改革创新，巩固加强竞技体育后备人才培养体系；加强体育行政部门的引领作用，协调相关部门，在青少年体育“组织、活动、场地”开展和建设方面力求新突破。建立青少年体育工作评估体系，开展青少年体育健身活动调查，努力提高青少年公共体育服务水平。重点做好以下八个方面工作：

**一、**加强政策法规建设

继续研制《青少年体育振兴规划》。在对《青少年体育“十二五”规划》总结、检查、评估基础上，着手开展《青少年体育“十三五”规划》研制工作。

**二、**筹备召开全国业余训练工作会议，全面扎实推进竞技体育后备人才培养工作

制定并实施《各奥运项目竞技体育后备人才培养中长期发展规划》。研究制定《关于进一步加强竞技体育后备人才培养工作的指导意见》。研究基层业余训练教练员待遇、职称、晋升、考核标准工作，并配合相关部门予以落实解决。提升青少年运动员选材、训练的科技水平，整合国内业余训练科研专家资源，分专题开展年度工作。

**三、**联合教育部门督导省市开展运动员文化教育情况

按照国办﹝2010﹞23号文件和体青字﹝2012﹞77号文件要求，将全国各省市贯彻落实工作当成当前竞技体育后备人才培养的头等大事来抓。在列入国家教育督导序列的基础上，会同教育部、财政部、中编办等相关部门联合督导检查，重点督导贯彻落实进展缓慢的省市，督导检查结果上报国务院并及时通报全国各省区市，对贯彻落实不力的单位进行通报批评并限期整改。开展重点督导和帮扶，积极与教育、编办等相关部门协调，争取领导的重视与支持，保证各项政策落实到每个市县，每所体校。

**四、**推进全国青少年业余训练运动员信息管理系统工作

整合各省市信息系统资源，研制并颁布《全国青少年业余训练运动员信息管理办法》，采集全国中等体育运动学校和各省市青少年业余训练运动员的个人基础信息，开发相关信息管理模块，初步建成信息系统框架，并使部分内容开始运行。

**五、**启动实施青少年人群体育健身活动和体质状况抽测工作

在2014年体育健身活动和体质状况抽测调查工作中增加6-19岁儿童青少年人群，及时了解和全面掌握儿童青少年健身活动和体质状况的变化趋势，形成全国国民全年龄段体育健身活动和体质状况的动态“抽测”管理体系，为制订《青少年体育“十三五”规划》和《青少年体育振兴规划》提供科学依据。

**六、**转变政府职能，加强体育社团建设，筹备成立中国青少年体育俱乐部联合会

发挥全国体育运动学校联合会的作用，加强联合会内部建设和制度建设，逐步承担起体校相关业务工作。按照中国青少年体育俱乐部联合会的筹备工作安排，研制联合会有关管理制度和文件，争取2014年获得民政部正式批复，召开联合会成立大会。

**七、**抓好新修订的《体育传统项目学校管理办法》的贯彻落实工作，开展体育传统项目学校联赛

按照新修订的管理办法，重新规划传统校的建设与资助的政策，整合资源，进一步发挥体育传统校培养体育后备人才的基础作用。继续会同教育部和总局相关项目管理中心举办全国体育传统校篮球、排球、田径、游泳、武术5个项目的联赛，进一步规范赛事组织，提高办赛质量，并推动各省市先期开展本地区的传统校比赛，争取把传统校赛事的比赛成绩纳入到等级评定标准中。

**八、**研究实施青少年体育社会指导员计划

协调总局职能部门和相关单位，研究在社会体育指导员中设立青少年体育社会指导员岗位，组织相关部门研制培训教材、计划，并在相关培训中尝试实施。

此外，认真做好以下各项常规性工作：召开全国青少年体育工作会议；办好2014年阳光体育大会；修订出台《国家高水平体育后备人才基地认定办法（2017-2020）》，开展国家高水平体育后备人才基地中期检查；完成教学训练大纲的修订，资助并指导检查各项目青少年训练营活动；修订全国体育运动学校联合会章程，加强全国各级各类体校规范建设；开展赛前运动员文化测试；加强体育传统项目学校和青少年体育俱乐部的建设和管理，规范青少年户外体育活动营地的建设和资助，继续开展阳光体育系列活动；进一步提升校园足球工作的质量和水平；开展全国青少年体育基础数据统计；继续开展青少年体育工作者培训；围绕青少年体育的热点难点问题，开展工作性研究；加强青少年体育宣传；开展青少年体育国际赛事及交流活动等。
