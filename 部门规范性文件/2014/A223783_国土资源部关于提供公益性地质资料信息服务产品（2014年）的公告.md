# 国土资源部关于提供公益性地质资料信息服务产品（2014年）的公告

为推进基础性公益性地质资料信息的社会化服务，方便社会公众借阅利用，进一步为找矿突破战略行动提供服务支撑，国土资源部组织全国地质资料馆和实物地质资料中心等单位开发了一批涵盖地质调查成果、实物地质资料及文献数据资料等公益性地质资料信息服务产品，包括全国重要地质钻孔数据库（2014年）、整装勘查区文献专题数据库（2014年）等（见附件）。

上述资料从即日起向社会提供公开利用，需借阅利用地质资料的用户，可登陆相关网站查阅或凭本人居民身份证到馆借阅利用。

如有意见建议可通过以下方式反映：

全国地质资料服务监督电话：010-58584900

监督邮箱：cls_zlc@mail.mlr.gov.cn

特此公告。

2014年12月4日
