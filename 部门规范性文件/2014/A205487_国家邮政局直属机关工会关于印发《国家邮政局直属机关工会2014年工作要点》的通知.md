# 国家邮政局直属机关工会关于印发《国家邮政局直属机关工会2014年工作要点》的通知

## 国家邮政局直属机关工会关于印发《国家邮政局直属机关工会2014年工作要点》的通知（机直工[2014]3号）

国家局机关各司局、直属各单位工会：

《国家邮政局直属机关工会2014年工作要点》已经国家局直属机关工会第二届委员会二次全会审议通过，现印发给你们，请结合工作实际，认真贯彻落实。

国家邮政局直属机关工会

2014年3月12日

国家邮政局直属机关工会2014年工作要点

2014年，国家邮政局直属机关工会工作总体要求：以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入学习贯彻党的十八大和十八届二中、三中全会精神，学习贯彻习近平总书记系列重要讲话精神，认真落实工会十六大确定的奋斗目标，团结动员广大职工在全面深化邮政改革、加快推进现代邮政业建设中发挥主力军作用。围绕中心任务，加强基础建设，开展岗位建功，弘扬先进文化，活跃机关生活，服务干部职工，以改革创新精神推进工会各项工作，努力建设学习型、服务型、创新型机关工会组织。重点做好以下工作：

（一）深入学习贯彻党的十八大和十八届二中、三中全会精神。采取个人自学、集中学习、参观学习等多种形式，认真学习贯彻党的十八大和十八届二中、三中全会精神，学习贯彻习近平总书记系列重要讲话精神，重点学习贯彻习近平总书记4.28和10.23重要讲话和中国工会十六大精神，并作为工会干部培训的重要内容，把握精神实质，指导工作实践，进一步认清形势，明确方向，强化责任，坚定信心。

（二）积极开展“中国梦.邮政情”宣传教育活动。按照全国总工会开展“中国梦.劳动美”主题教育的部署，结合邮政业实际，深入开展“中国梦.邮政情”宣传教育活动，增进广大干部职工对实现邮政业中国梦的强烈共识。以庆祝建党93周年和建国65周年为契机，与机关党委和新闻宣传中心联合组织开展“中国梦.邮政情”征文和座谈活动，引导干部职工把实现个人理想与做好本职工作、推进行业发展紧密结合起来，以爱岗敬业的实际行动为现代邮政业建设做出贡献。

（三）围绕国家邮政局中心工作，大力开展岗位建功和劳动竞赛活动。组织开展“我为现代邮政业建设献一计”合理化建议征集活动，动员引导干部职工提高能力，为建设现代邮政业积极建言献策、贡献力量。配合机关党委组织开展“当一天邮递员、快递员”岗位实践活动，体会一线职工的责任和艰辛，增强“三个服务”的意识。积极参加中央国家机关工会联合会组织开展的“第二届公文写作技能比赛”，进一步形成钻研业务、提高技能的风气。

（四）落实中央“八项规定”和《党政机关厉行节约反对浪费条例》，构建廉洁高效、勤俭节约、文明和谐的国家局机关。贯彻执行中央“八项规定”和《党政机关厉行节约反对浪费条例》，带头落实国家局党组《关于落实中央＜八项规定＞的措施》，切实改进机关工作作风。协助办公室和机关党委搞好以“转变职能、改进作风”为主题的文明机关（处室）主题实践活动，倡导廉洁高效、勤俭节约之风，推进文明和谐机关建设。

（五）积极推进机关文化建设和精神文明建设，精心培育机关优秀文化。大力弘扬社会主义核心价值体系，积极践行邮政行业“诚信、服务、规范、共享”的核心价值理念，围绕提升行业服务质量和道德水平，创新文明创建活动，积极出谋划策，研究探索新形势下加强机关精神文明建设的新思路。认真落实国家邮政局《关于大力推进邮政行业文化建设的指导意见》，推动机关文化建设创新，培育国家邮政局机关优秀文化，引导群众在文化建设中自我表现、自我教育、自我服务。

（六）广泛开展健康文明的主题活动，进一步活跃机关文化生活。适时邀请专家组织主题学习讲座，提升干部职工思想理论水平。“三八妇女节”组织妇女干部职工参加“现代女性礼仪与形象”讲座。“五四青年节”与机关团委一起组织青年干部职工进行学习培训。“八一建军节”组织复转军人及现役军人家属开展座谈和学习参观活动。春节协助办公室和机关党委组织好机关团拜会。适时在机关组织电影放映。

（七）认真组织各类群众性体育比赛，努力形成“积极生活、快乐工作”的良好氛围。进一步推动《中央国家机关干部职工健身行动实施意见》的落实，突出机关特点，按照“大众、健康、活力”的原则，大力开展积极向上的体育活动。对启动一年时间的“倡导绿色交通出行，弘扬红色长征精神”健走活动进行总结、评比和表彰，坚持做好课间广播体操锻炼，组织干部职工进行春秋季户外锻炼和比赛。积极参加国家机关工委和工会联合会组织的“公仆杯”系列体育活动。开展健康大讲堂活动，邀请专家为干部职工普及健康知识。

（八）继续做好送温暖活动，下大力为干部职工办实事解难题。加强和改进新形势下党的群众工作，坚持和巩固党的群众路线教育实践活动成果，认真抓好整改落实。充分发挥工会组织联系群众的桥梁纽带作用，加大扶贫帮困和送温暖工作力度，进一步凝聚人心、鼓舞人心、温暖人心。本着服务全体职工、关爱特定群体、援助特殊困难的原则，扎实做好送温暖、办实事、解难题工作。继续做好探望生病住院职工、慰问特殊困难职工等工作。组织机关和直属单位单身青年参加青年交友联谊活动。督促所属相关工会健全劳动关系，建立和谐劳资关系，积极维护干部职工权益。

（九）进一步加强工会自身建设，努力打造学习型、服务型、创新性机关工会。进一步健全各单位工会组织，完善工作制度，规范工会经费的收缴、管理和使用。进一步明确两委人员的工作职责和任务分工，强化责任意识，增强工作动力。上半年，组织新一届直属机关工会“两委”委员业务培训，提高工会干部业务素质和工作能力。深化机关工会工作理论研究，总结经验，探索规律，创新方法，提高效率，提升工会工作科学化、规范化、制度化水平。
