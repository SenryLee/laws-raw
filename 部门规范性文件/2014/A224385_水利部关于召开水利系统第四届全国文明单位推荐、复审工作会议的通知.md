# 水利部关于召开水利系统第四届全国文明单位推荐、复审工作会议的通知

部直属各单位，各省、自治区、直辖市水利（水务）厅（局），各计划单列市面上水利（水务）局，新疆生产建设兵团水利局：

根据中央文明委《关于评选表彰全国文明城市、文明村镇、文明单位的暂行办法》和2014年工作安排，今年年底中央将评选表彰第四届全国文明单位。为指导各单位认真、严谨、规范做好推荐申报工作，定于12月上旬在北京召开水利系统第四届全国文明单位推荐、复审工作会议。现将有关事项通知如下：

一、会议时间

2014年12月5日（周五）下午2：00，会期半天。

二、会议地点

部机关大院北楼207会议室。

三、参会人员

部直属各单位,各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局文明办主任1人；水利系统全国文明单位（见附件1)党委书记1人。

四、有关事项

1、请各单位认真填写会议报名表(见附件2)，于2014年12月3日中午前通过电子邮件发至水利部文明办。

联 系 人：姜莉　廖晓瑜

办公电话：010-63202070、010-63202815

电子邮箱：wmb@mwr.gov.cn

2、严格控制参会人数,不得超员

3、请参会人员提前10分钟入场，将手机等通信设备关闭或设置静音状态。

附件：1、参会水利系统全国文明单位名单(共23家)

2、水利系统第四届全国文明单位推荐、复审工作会议报名表

水利部精神文明建设指导委员会办公室

2014年12月2日
