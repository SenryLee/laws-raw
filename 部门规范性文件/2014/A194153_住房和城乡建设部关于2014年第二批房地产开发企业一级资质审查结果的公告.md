# 住房和城乡建设部关于2014年第二批房地产开发企业一级资质审查结果的公告

根据《行政许可法》、《城市房地产开发经营管理条例》和《房地产开发企业资质管理规定》，我部对2014年第二批申报房地产开发一级资质企业进行了审查。现将核准房地产开发一级资质的河北盛泽房地产开发有限公司等86家企业名单予以公布。

特此公告。

附件：核准的房地产开发一级资质企业名单

住房城乡建设部

2014年8月25日
