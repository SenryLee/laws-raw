# 农业部办公厅关于印发“全国十佳农民”2014年度资助项目人选的通知

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）、农机、畜牧、兽医、农垦、乡镇企业、渔业厅（局、委、办），新疆生产建设兵团农业局，部机关各司局、各直属单位:

2014年，在党中央、国务院的正确领导下，各级党委、政府和农业部门扎实工作，亿万农民群众辛勤劳动，粮食生产实现了“十一连增”，农民增收实现了“十一连快”，成为经济社会发展的突出亮点，为稳增长、促改革、调结构、惠民生大局提供了有力支撑。

为巩固农业农村经济发展好形势，进一步鼓励广大农民扎根农村基层、发展农业生产，营造全社会关心农业、关注农村、关爱农民的良好氛围，农业部设立了“全国十佳农民”资助项目，决定对张秀霞等10名在2014年农业生产中做出贡献的农民给予资助（名单附后）。

希望受资助的“全国十佳农民”珍惜荣誉，再接再厉，继续发挥模范带头作用，争做家庭经营的基石、合作组织的骨干、社会化服务组织的中坚，为推动现代农业发展、促进“三农”事业进步再立新功。各级农业部门要广泛宣传“全国十佳农民”的优秀事迹，积极弘扬他们的先进理念，大力推广他们的经验做法，进一步加强农村实用人才队伍建设，培养一大批具有较强市场意识，懂经营、会管理、有技术的新型职业农民，为全面深化农村改革和加快发展现代农业提供强有力的人才支撑。

附件：“全国十佳农民”2014年度资助项目人选名单

农业部办公厅

2014年12月18日
