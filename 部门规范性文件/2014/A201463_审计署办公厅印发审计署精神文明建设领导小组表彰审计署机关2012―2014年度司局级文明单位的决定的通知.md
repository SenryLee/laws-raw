# 审计署办公厅印发审计署精神文明建设领导小组表彰审计署机关2012―2014年度司局级文明单位的决定的通知

## 审计署办公厅印发审计署精神文明建设领导小组表彰审计署机关2012-2014年度司局级文明单位的决定的通知

署机关各单位、各派出审计局：

现将审计署精神文明建设领导小组表彰审计署机关2012-2014年度司局级文明单位的决定印发给你们。

2014年6月18日

审计署精神文明建设领导小组表彰审计署机关2012-2014年度司局级文明单位的决定

党的十八大以来，审计署机关各单位以中国特色社会主义理论为引领，深入学习习近平总书记系列讲话精神，紧紧围绕审计中心工作，积极培育和践行审计人员核心价值观，广泛开展富于审计机关特色的文明创建活动，营造了团结和谐、积极进取的良好氛围。广大干部职工理想信念坚定，严格执行各项纪律规定，坚持“实、高、新、严、细”作风要求，恪守《审计署工作人员文明守则》，思想道德水平不断提高，文明审计意识不断增强，精神状态更加饱满，文明举止更加规范，在推动完成审计和其他各项工作任务，促进审计事业科学发展中发挥了重要作用，涌现出一批成绩突出、群众公认的先进典型。

为充分展示署机关精神文明创建活动的丰硕成果，进一步调动各单位参与精神文明创建活动的积极性，推动全署精神文明建设深入发展，经自愿申报、组织审核、民主推荐、署精神文明建设领导小组决定并报署党组批准，授予财政审计司等17个单位“2012-2014年度司局级文明单位”荣誉称号。

希望受表彰的文明单位珍惜荣誉、谦虚谨慎、发扬成绩、再接再厉，在精神文明创建工作中更好地发挥示范带头作用。同时希望署机关其他单位以受表彰的文明单位为榜样，进一步提高文明创建意识，创新文明创建方式，提升文明创建热情，总结文明创建经验，为审计工作更好地推动实现国家治理现代化，提供坚实的智力支持和精神保障。
