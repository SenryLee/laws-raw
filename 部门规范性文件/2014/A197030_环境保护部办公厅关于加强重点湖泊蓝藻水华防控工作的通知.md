# 环境保护部办公厅关于加强重点湖泊蓝藻水华防控工作的通知

环境保护部办公厅关于加强重点湖泊蓝藻水华防控工作的通知

（环办函[2014]796号）

上海市、江苏省、浙江省、安徽省、云南省人民政府办公厅：

入夏以来，太湖、巢湖均出现数次蓝藻水华现象，发生时间较2013年有所提前。滇池外海北部水域出现蓝藻富集。为加强防控蓝藻水华大面积暴发，确保饮用水安全，现就有关事项通知如下：

**一、**加密监测，强化蓝藻水华预警预报。为及时掌握蓝藻水华发生发展情况，应采取水质采样监测、卫星遥感监测、人工巡查相结合的方式，密切关注蓝藻发生、聚集与水质变化，及时发布蓝藻水华监测预警信息。

**二、**强化应急，提高蓝藻打捞处置能力。要加强应急值守，严格信息报告制度，强化信息公开，建立健全蓝藻水华预警体系。加强蓝藻打捞清运人员配置，强化蓝藻打捞防控的装备、物资准备，加强饮用水水源地、湖泛易发区等重点水域蓝藻打捞和围挡。

**三、**加强预防，确保水源地水质与供水安全。加强饮用水水源水质监控，落实自来水厂原水和供水24小时连续检测，督促指导供水企业做好应急深度处理的技术保障和物资储备，确保饮用水安全。

**四、**加强污染防治，严格环境监管。以饮用水水源地、主要入湖河流为重点，排查整治环境安全隐患，严厉打击违法排污行为，确保污水处理设施正常运行。

环境保护部办公厅
