# 商务部投资促进事务局关于定期举行中韩雇佣许可制韩国语水平考试的通知

2014年5月2日，我局与韩国产业人力公团签订了《中韩雇佣许可制韩国语水平考试及技能测试实施协议》。协议规定，双方将于每年9月第四周的周六，定期在中国举行雇佣制韩国语水平考试。若因不可抗拒因素导致无法进行考试，经双方协商一致后，可视情况取消或更改考试日期。根据雇佣制业务需要，可视情况在上半年增加一次韩语考试。具体考试日期由投资促进局和人力公团在考试前三个月共同商定。

2014年4月27日，第三次中韩雇佣许可制韩国语水平考试遵循各省自愿原则，在黑龙江、山东、河南3省成功举行。根据中韩双方签订的考试协议，如无特殊情况，将于2014年9月第四周的周六，在吉林、黑龙江、山东、河南4省举行第四次中韩雇佣许可制韩国语水平考试。

关于考试报名、考场等具体事项，我局及4省地方公共机构将在考试前提前在网站发布通知，请广大有意赴韩务工的劳务人员根据自身情况合理安排韩语学习等务工准备。

有关雇佣制赴韩工作流程、费用及注意事项等可查看我局网站发布的《赴韩务工问答》（http：//www.fdi.gov.cn/1200000031_3_42_0_7.html）。
