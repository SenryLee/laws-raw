# 商务部关于举办第十届中国食品博览会的通知

各省、自治区、直辖市、计划单列市及新疆建设兵团商务主管部门，有关单位：

商务部与四川省人民政府定于2014年9月19-21日，在成都市共同主办第十届中国食品博览会（以下简称食博会）。本届食博会将进一步加强专业化改造，市场化运作，以减量提质提升办展实效。通过展览展示、信息发布、研讨对接等活动，促进产销对接、拉动食品消费，推进食品流通方式创新。现将有关事项通知如下：

**一、**展会内容

本届食博会规划展览面积3万平方米，设国际标准展位1500个，由6个展区组成。展会期间，将举办食品行业趋势发布会、食品经销商渠道建设研讨会、中小企业投融资辅导会等系列活动。同时，开设中国食品餐饮采供信息平台，实现线上线下互动。（详见附件1）

**二、**展会特点

本届食博会通过缩短展期时间，压缩展览面积，加大专业观众组织力度，提升参展参会企业质量；充分调动各类社会机构的参与积极性，发挥其行业优势，实现逐步去行政化；严格落实中央八项规定，取消开幕式、晚宴等活动，简化接待安排，鼓励支持企业采用可回收材料，减少展材垃圾污染。

**三、**其他事宜

定于4月24日在成都市举办第十届食博会方案说明会，就食博会方案及相关政策做说明。会议具体地点及安排另行通知，参会人员往返交通费用自理。请各单位收到通知后，将参会人员报名表（详见附件2）传真至四川博览事务局。有关食博会具体事宜，请及时与组委会衔接沟通。

**五、**展览展示

第十届食博会以减量提质、注重实效为原则，实现专业化转型升级。规划展览面积3万平米，设国际标准展位1500个，由6个展区组成。凡报名参展参会的企业，须经组委会审核通过，方可获得参展商和采购商资格。

（一）综合食品展区：全国各省市有代表性的名优特新食品，获得有机认证的食品、地理标志食品。由全国品牌食品、四川特色食品、国际食品三个部分组成。

（二）肉食水产展区（第十届中国肉业博览会）：肉与肉制品，屠宰加工设备及技术，肉品安全检测追溯产品及技术，海洋水产食品，深加工水产食品。

（三）酒饮展区：茶叶、茶业深加工产品、茶食品、茶保健品、茶器具、茶叶保鲜及贮存技术；红酒、白酒、啤酒、果酒、黄酒及酒类器皿；饮用水、功能性饮料、果汁、咖啡。

（四）粮油展区：大米、杂粮、普通食用油、橄榄油、山茶油、亚麻籽油、粮油精加工食品、小麦及加工制品、豆制品等。

（五）食品原料及配料展区：食品添加剂、食品配辅料、调味料、天然食品原料、营养保健品原料、有机配料等。

（六）食品餐饮设备及服务展区：食品生产加工设备、包装机械、食品检测设备、喷码设备、冷链储运设备及技术，餐厨设备及用品，食品及餐饮信息化系统及技术等。

**六、**主要活动

（一）2014食品行业趋势发布会

将邀请相关业务司局，专业市场机构，分时段发布食品消费、农产品流通、天然食品原料、营养保健等食品领域流通现状及趋势。

（二）2014中国食品经销商渠道建设研讨会

将邀请行业知名营销专家，就电子商务、渠道建设、品牌营销等食品经销商关注焦点话题作深入分析。期间邀请行业专家点评明星趋势产品。

（三）中小企业投融资辅导会

将邀请知名投融资机构，针对中小食品企业发展中遇到的缺资金、缺管理、缺技术等问题提供咨询辅导，并安排投融资项目对接洽谈。

**七、**线上采供一站式服务

为帮助参展商和采购商建立对接长效机制，商务部流通产业促进中心建立中国食品餐饮采供信息平台，结合展会平台，实现线上线下一站式采供服务。凡经组委会审核通过的参展商和采购商，均可免费注册为平台会员。会员可获得食品行业及展会资讯电子期刊，并发布采供信息。

**八、**采购商邀请

为提高企业参展成效，组委会将充分利用各种资源和渠道，全面加大采购商组织力度。招商对象包括食品经销商、代理商、进出口贸易商、饭店餐饮企业、连锁商超、跨国零售集、网络电商、专业食品批发市场、境外商协会等。

**九、**宣传推广

多渠道、分时段、全方位开展食博会品牌宣传与推广。加大与行业专业媒体、主流大众媒体的合作，赴境内外重点城市开展招商推介会，利用食博会官方网站、微博、微信等新媒体及展会APP软件应用，扩大展会在国内外的影响力和知名度。
