# 住房和城乡建设部关于批准2014年第十五批注册监理工程师延续注册人员名单的通知

建市监函[2014]166号

各省、自治区住房城乡建设厅，直辖市建委（建交委），新疆生产建设兵团建设局，国务院有关部门建设司，总后基建营房部工程局：

根据《注册监理工程师管理规定》（建设部令第147号）及注册监理工程师有关规定，经审核，张显宇等2148名申请注册监理工程师延续注册人员符合延续注册条件，准予注册。

特此通知。

附件：注册监理工程师延续注册人员名单
