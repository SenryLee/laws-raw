# 国家核安全局关于批准颁发2014年第一批民用核安全设备焊工焊接操作工资格证书的通知

## 国家核安全局关于批准颁发2014年第一批民用核安全设备焊工焊接操作工资格证书的通知（国核安发[2014]14号）

各相关聘用单位：

根据《民用核安全设备焊工焊接操作工资格管理规定》（HAF603），我局组织有关单位对中国能源建设集团江苏省电力建设第一工程公司等6家民用核安全设备焊工焊接操作工考核中心组织的焊工项目考试（考试编号见附件1）进行了监督检查。根据检查结果，现批准向苏州海陆重工股份有限公司等9家聘用单位、朱姣等38位民用核安全设备焊工焊接操作工，颁发民用核安全设备焊工焊接操作工资格证书（见附件2），共计79项合格项目。

特此通知。
