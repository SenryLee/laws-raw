# 国家宗教事务局宗教研究中心关于做好国家宗教事务局2014年度科研项目中期检查工作的通知

各有关单位、项目负责人：

国家宗教事务局2014年度科研项目中期检查工作于2014年8月15开始，8月30日结束。请项目负责人如实填写《国家宗教事务局年度科研项目中期检查表》，8月30日前，纸质表格经所在单位科研管理部门审核盖章后，连同电子版表格报国家宗教事务局宗教研究中心。请在国家宗教事务局网站“科研项目管理”板块“资料下载”中下载表格。
