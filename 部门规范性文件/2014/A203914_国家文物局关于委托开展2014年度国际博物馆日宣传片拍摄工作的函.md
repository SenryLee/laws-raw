# 国家文物局关于委托开展2014年度国际博物馆日宣传片拍摄工作的函

## 国家文物局关于委托开展2014年度国际博物馆日宣传片拍摄工作的函（办博函〔2014〕283号）

中国文物信息咨询中心：

为丰富2014年度国际博物馆日的宣传内容、扩大其社会影响力、创新博物馆文化的传播途径，增进公众对博物馆事业的了解，经我局研究，现委托你中心结合2014年国际博物馆日主题“博物馆藏品架起沟通的桥梁”，组织拍摄主题宣传片。我局补助经费48.95万元，请专款专用，确保绩效。

工作内容包括：起草“2014年国际博物馆日主题宣传片”制作方案。撰写“2014年国际博物馆日主题宣传片”拍摄脚本大纲。完成宣传片的拍摄、剪辑和后期制作，按技术要求提供相关成果。制作光盘并提供100套成品。

此函。

国家文物局

2014年4月23日
