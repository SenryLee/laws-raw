# 国家体育总局乒羽中心关于2014年全国性乒乓球比赛用球的通知

各参赛单位：

经研究，2014年全国性乒乓球比赛用球的情况如下：

**一、**使用赛璐珞球（旧球）的比赛：

全国锦标赛（预赛）、俱乐部超级联赛、俱乐部甲A比赛（第一站）、俱乐部甲B比赛。

**二、**使用塑料球（新球）的比赛：

全国锦标赛（决赛）、全国青年锦标赛、全国少年锦标赛、全国少年比赛（南、北方赛区）、全国少儿杯赛总决赛、俱乐部甲A比赛（第二站）、俱乐部甲C比赛、俱乐部甲D比赛、俱乐部乙A比赛、俱乐部乙B比赛。

特此通知。

体育总局乒羽中心

2014年4月8日
