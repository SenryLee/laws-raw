# 工业和信息化部办公厅关于报送年度工业清洁生产工作情况的通知

## 工业和信息化部办公厅关于报送年度工业清洁生产工作情况的通知（工信厅节函[2014]127号）

各省、自治区、直辖市及计划单列市、新疆生产建设兵团工业和信息化主管部门，有关中央企业：

为贯彻落实《工业清洁生产推行“十二五”规划》，全面准确掌握各地区清洁生产工作进展情况，我们对《关于报送工业和通信业清洁生产工作情况的通知》（工信厅节函〔2009〕224号）中要求报送的内容进行了修订，增设了氮氧化物、重金属等污染物削减指标，调整、细化了开展清洁生产所覆盖的行业类别。

请认真做好年度工业清洁生产有关工作情况总结，按照报送表（见附件，电子版可在我部网站下载）的要求填报年度清洁生产工作情况信息，于2014年5月1日前将2013年度清洁生产工作情况报送我部（节能与综合利用司），同时将电子版发至huanbaochu123@163.com。

自2015年起，请于每年3月1日前将上一年度清洁生产工作情况报送我部。

[2]开展清洁生产培训情况：“政府管理人员”指各级政府管理人员参　加清洁生产培训的人次；“企业数”指开展清洁生产培训的规模以上工业企业数，包括企业在内部开展过清洁生产培训或企业主要负责人参加过清洁生产培训。“企业参加培训人数”指企业员工参加过内部或外部清洁生产培训的人次。

[5]清洁生产技术改造情况：“提出的清洁生产技术改造项目数”指通过评估的清洁生产审核报告中确定的清洁生产中高费项目，或直接采用国家公布的清洁生产技术推行方案等目录上的技术进行技术改造的项目数量之和。“已实施清洁生产技术改造项目数”指实施完成并通过有关部门组织的清洁生产实施效果评估验收的项目数。

[6]清洁生产实施效果情况：“环境效果”中污染物的削减量均为削减的产生量；“经济效果”实施清洁生产技术改造项目后产生的经济效益。

[7]已开展清洁生产所覆盖行业的企业数量：“总计”中指大类行业开展清洁生产的总数，如：有色行业开展清洁生产企业“总计”数量，其中“铅锌冶炼”、“稀土”两个子行业分别的数量。
