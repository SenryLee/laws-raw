# 国家体育总局游泳中心关于举办第六届全国水中健身操比赛的通知

各有关单位：

为全面贯彻落实《全民健身条例》，推动我国水中健身活动的发展，由国家体育总局游泳运动管理中心、中国游泳协会、江苏省体育局联合主办，江苏省社会体育管理中心、江阴市人民政府承办，江阴市体育局协办的“第六届全国水中健身操比赛”，将于2014年12月6日至7日在江阴体育中心游泳馆举行。现将有关事项通知如下：

**一、**仲裁委员会

张梅（游泳中心、女）、孔庆玮（江苏省游泳中心）、江阴市体育局1人。

**二、**裁判

（一）总裁判长：温宇红（北体大、女）

（二）副总裁判：张军（武汉体院、女）、肖红（西安体院、女）、马吉光（上海体院）

（三）裁判长：尤玉青（上海）、李晓寰（游泳中心、女）、朱玉琼（湖北、女）、李波（北体大、女）

（四）各队可自派1名裁判员。

**三、**要求

（一）请上述人员于12月4日到江阴体育中心游泳馆报到。地址：江阴市澄江中路19号，联系人：陆巍，电话：0510-86841150手机：15852618832，传真：0510-86841150，电子邮箱：670021525@qq.com。

（二）请所有裁判员自学《全国水中健身操竞赛规则》（见游泳字[201]XX号文件）。

（三）裁判员不得兼任教练员和领队工作。

（四）凡参加裁判工作者，必须参加赛前培训。

（五）请各参赛队指定专人，报到时确认参赛项目、交纳报名费和由本人签名的《自愿参加比赛责任书》。

（六）请各参赛队于11月10日前填写住房预订表（见附件4）传真至0510-86841150。

（七）请各参赛队指定专人于12月5日19：00参加组委会，裁判、领队和教练员技术会议，未参加者责任自负。

**四、**经费

（一）组委会为各参赛队提供不超过8人（其中领队1人、教练员1人，参赛者6人）适当的伙食补贴。

（二）各参赛队食宿每人每天260元（酒店，双人房，含餐费及驻地、赛场往返交通），如需单人房补差价每天100元。

（三）总裁判长、副总裁判长的食宿、差旅费（硬卧火车票或打折机票）由组委会负担。

（四）各参赛队自派裁判员的食宿费由组委会负担。

附件1

第六届全国水中健身操竞赛规程

**一、**时间和地点

2014年12月6日至7日在江阴体育中心游泳馆举行。

**二、**竞赛项目

（一）徒手规定动作操：双人、集体

（二）器械操：双人棒操、双人板操、双人划手掌操

集体棒操、集体板操、集体划手掌操

（三）深水徒手操：集体

**三、**表演项目

水中舞蹈、水中瑜珈、水中太极、水中搏击等

**四、**参加单位

中国游泳协会冬泳、成人团体会员单位、大专院校、游泳俱乐部。

**五、**参加办法

（一）高校组分为体育院校组和普通院校组，仅限在校师生报名参赛。

（二）中学组、小学组仅限在校生报名参赛。

（三）分龄组

1、50岁组以上（1964年以前出生）；所有成员年龄需在50周岁以上。

2、36-49岁组（1978年至1965年出生）；允许1至2人年龄超过49周岁。

3、18-35岁组（1996年至年1979出生）；允许1至2人超过35周岁。

（四） 报名人员每人交纳21元保险费，参赛人员每人每项报名费10元。

（五）各队报名人数不限。各项目限报1个队，器械双人项目限报1项。器械集体项目限报2项，集体项目限报4至12人。

（六）各项比赛限报1名领操员。

**六、**竞赛办法

（一）采用国家体育总局游泳运动管理中心2014 年公布的《全国水中健身操竞赛规则》（2014年修订版）。详见游泳字[2014]　　号文件。

（二）徒手规定动作操10个规定动作中，至少使用8个，按顺序编排成套路，每个动作至少重复8次。手臂在水下的动作时间累积不少于2分钟。

（三）棒操、板操、划手掌操，每项器械在水下的时间累积不少于2分钟。

（四）深水徒手操每人需佩戴浮力腰带在深水或浅水中进行，双脚不能接触池底。

（五）表演项目限4分钟以内完成。

（六）各队必须参加徒手规定动作操比赛。

（七）参加徒手规定动作操、器械操、深水徒手操及表演项目必须使用不同的音乐。

（八）所有项目只进行一次性决赛，按成绩排列名次，成绩相同名次并列，取消下一名次。

（九）参赛人员检录时，必须向裁判员出示《参赛证》，无证者不得参加比赛。

（十）凡冒名顶替和弄虚作假者，均取消本参赛队比赛成绩，并按照有关竞赛条列给予处罚。

**七、**录取名次与奖励

（一）各项目各组录取前8名，颁发由国家体育总局统一制作的“全国体育竞赛获奖证书”。

（二）其他参赛者颁发纪念证书。

（三）团体总分录取前8名，颁发团体奖。

（四）评选“编排奖”、“表演奖”“领操员奖”。

（五）团体总分计分办法

1、徒手操、器械操、深水徒手操按9、7、6、5、4、3、2、1记分。

2、徒手操、器械操、深水徒手操参加人数从第5至12人，每增加1人加0.5分。

3、表演项目不得少于4人，每项记取5分。从第5至12人，每增加1人加0.5分。

4、有陆上领操员的每项加1分。

5、团体总分按各队徒手操、器械操、深水徒手操名次得分、人数加分、表演项目得分、领操员加分累计相加排列名次；总分相同，以第1名多者列前；再相同，以第2名多者列前，依此类推。

**八、**报名和报到

（一）请各参赛队必须用电脑规定的格式填写报名表（加盖公章），于11月5日（当地邮戳为准）以电子邮件和邮寄/传真至承办单位（邮编：214400，地址：江阴市澄江中路19号江阴体育中心，联系人：陆巍，电话：0510-86841150

手机：15852618832，传真：0510-86841150，电子邮箱：670021525@qq.com）。

（二）请各参赛队请于12月5日12：00前到大会指定宾馆住宿。

**九、**仲裁和裁判

仲裁、裁判长由国家体育总局游泳运动管理中心选派，其他裁判员由承办单位选派。

**十、**未尽事宜，另行通知。
