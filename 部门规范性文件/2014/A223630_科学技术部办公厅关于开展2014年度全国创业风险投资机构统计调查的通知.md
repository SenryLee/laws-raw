# 科学技术部办公厅关于开展2014年度全国创业风险投资机构统计调查的通知

国科办资〔2014〕60号

各省、自治区、直辖市、计划单列市科技厅（委、局），各国家高新区管委会，各地方创业风险投资协会：

创业风险投资机构统计是国家科技管理中一项重要的基础性工作，也是科技金融工作的重要组成部分。为加快推动我国创业风险投资业的健康持续发展，培育发展战略性新兴产业，支撑和引领经济发展方式转变，加快建设创新型国家，按照2015年工作部署，科技部、商务部、国家开发银行等部门将于近期开展第13次全国创业风险投资年度调查工作。经国家统计局批准（国统制〔2014〕154号），本项调查为国家科技专项统计，统计数据正式编入《中国科技统计年鉴》，现将有关事项通知如下：

**一、加强组织保障**

各地科技管理部门、国家高新区管委会和创业风险投资协会等应高度重视创业风险投资统计调查工作。按照《中华人民共和国统计法》及相关法律法规认真组织实施，责成具体负责人，明确责任，进一步完善统计制度，提高统计工作的效率与质量。通过专项调查工作，摸清本地区创业风险投资的总量与规模、投资方向、退出、需求等基本情况，加强与地方创业风险投资协会、创业风险机构的联系和沟通。

**二、完善调查员信息**

调查负责人和调查员是开展统计调查工作的具体工作人员，也是顺利开展调查工作的关键。请各地方调查部门认真核对各地调查员信息（见附件1），如出现调查负责人或调查员信息变更，请于2015年1月15日前将有关补充或变更情况报送至中国科学技术发展战略研究院（见附件2）。

**三、工作组织与指导**

全国创业风险投资机构统计调查的组织与指导工作由科技部资源配置与管理司负责，中国科学技术发展战略研究院具体实施。调查期间将举办相应的研讨和培训活动，以提升调查人员专业素质，增进相互了解与学习，总结成功经验与做法。统计调查工作使用“中国创业风险投资信息系统（www.ivcc.cn）”平台进行填报（使用指南见附件3），调查工作交流QQ群为“中国创业风险投资”，群号85031581。

**四、工作时间安排**

2015年1月全国创业风险投资统计调查正式启动；

2015年4月底全国创业风险投资统计调查结束；

2015年下半年召开全国创业风险投资统计调查总结会。
