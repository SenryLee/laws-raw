# 农业部办公厅关于召开2014年全国秋粮暨全年粮食形势分析会议的通知

## 农业部办公厅关于召开2014年全国秋粮暨全年粮食形势分析会议的通知（农办农[2014]43号）

为准确研判今年秋粮及全年种植业生产形势，定于9月中旬在北京召开全国秋粮暨全年粮食形势分析会议。现就有关事项通知如下。

**一、**会议内容

（一）秋粮及全年粮食生产形势分析，重点分析生产特点和增减产原因，特别是对旱涝灾害的影响进行评估，并说明本省（区、市）统计、气象、粮食等有关部门的粮食面积、单产、总产预计情况；

（二）全年经济作物生产形势分析，包括棉油糖菜等主要经济作物种植面积、单产、总产，并与上年农业部门数据同口径比较；

（三）交流各地促进粮食和种植业稳定发展的做法，包括各地促进粮食生产发展出台的政策措施、采取的重大行动、应用的关键技术等；

（四）交流各地开展农情田间定点监测试点工作的有关情况。

**二、**时间地点

时间：2014年9月14日报到，15日-16日开会，会期1.5天。

地点：北京市永安宾馆（地址：北京市朝阳区农展馆北路甲5号，电话：010-65011188）。

**三、**参加人员

（一）各省、自治区、直辖市农业（农牧、农村经济）厅（委、局）、新疆生产建设兵团农业局分管农情信息工作的处室负责人或熟悉情况的同志1人。

（二）国家统计局、中国气象局、国家粮食局有关人员。

**四、**其他事项

请各省（区、市）按照会议内容要求，认真做好调查研究和综合分析，及时填报9月份农情调度月历表30-35，于9月10日前将参会人员名单（姓名、性别、民族、单位、职务、电话）和综合分析材料发送至种植业管理司农情信息处，并将综合分析材料打印10份带到会上交流。
