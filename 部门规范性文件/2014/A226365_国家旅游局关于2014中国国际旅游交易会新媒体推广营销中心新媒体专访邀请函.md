# 国家旅游局关于2014中国国际旅游交易会新媒体推广营销中心新媒体专访邀请函

各有关旅游局（委）、旅游景区管委会（管理局）、旅游集团公司：

由中国国家旅游局信息中心主办，乐途旅游网、大象群文化传播有限公司承办的 “2014中国国际旅游交易会新媒体推广营销中心新媒体专访”（以下简称中国旅游网络专访）,将于11月14日-16日在上海举办的2014中国国际旅游交易会展馆中1号馆1A02举行。

本届中国国际旅游交易会首次开设新媒体推广营销中心，将在现场以多媒体访谈和现场智能体验方式为各地宣传推广旅游，届时将通过国家旅游局官方微博和乐途旅游网视频直播，并通过新华网、央视网、人民网等各大媒体实时直播，全方位、多角度展现各相关地区、单位在美丽中国和智慧旅游中取得的成果与成功经验。活动在国家旅游局所在的1号展馆举办，具体安排和内容详见附件2、3。

为确保此次活动效果，请有意参加本次活动的单位，于2014年10月31日之前，将回执（详见附件1）通过传真或邮件方式回传至邀约组。

诚挚期待贵单位参加！
