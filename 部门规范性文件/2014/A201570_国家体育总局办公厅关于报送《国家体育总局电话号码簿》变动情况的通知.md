# 国家体育总局办公厅关于报送《国家体育总局电话号码簿》变动情况的通知

各省、自治区、直辖市、计划单列市、新疆生产建设兵团体育局，总参军训部军事体育训练局、总政宣传部文化体育局，有关体育院校，各行业体协，各司、局，各直属单位，相关单位：

2013年体育总局办公厅编印了《国家体育总局电话号码簿》，并印发全国体育系统。经过一年时间，有些部门和单位在人员、机构设置、电话号码等方面都发生了变化。为便于日常工作使用，请各部门各单位对照2013版《电话号码簿》，将涉及本部门本单位电话号码的变动情况进行填报（无变化不填报），于6月30日前将变动情况统计表（见附件，可在总局政府网站办公厅子站内下载）报送体育总局办公厅（逾期没有报送视为无变化）。《电话号码簿》涉及的机构和人员变动情况截至2014年6月30日。

联系人：肖淼、梁斌

电话：（010）87182143、87182838

传真：（010）67131907

电子邮箱：msc@sport.gov.cn

2.2013年国家体育总局电话号码统计表（其它单位适用）

3.2013年国家体育总局电话号码统计表（行业体协适用）

体育总局办公厅
