# 国家质量监督检验检疫总局直属机关党委关于在五四青年节举办“铁血丹心铸军魂——中国人民解放军军事体育运动大队英模报告会”的通知

## 国家质量监督检验检疫总局直属机关党委关于在五四青年节举办“铁血丹心铸军魂--中国人民解放军军事体育运动大队英模报告会”的通知

认监委、标准委、总局各司局、在京各直属单位：

为纪念五四运动95周年，深入贯彻习近平总书记关于青年和青年工作的系列重要讲话精神，引导激励京区质检系统青年干部坚定理想信念，积极投身质检深化改革的伟大征程，总局直属机关团委拟于5月4日举办“铁血丹心铸军魂--中国人民解放军军事体育运动大队（简称八一军体大队）英模报告会”。现将有关事项通知如下：

**一、**报告会时间、地点

2014年5月4日（周日）15：30-16：30，总局5楼报告厅

**二、**主讲嘉宾

八一军体大队英模报告团

**三、**主持人

总局党组副书记、副局长梅克保

**四、**主要内容

（一）15：30-15：50 播放八一军体大队纪录片

（二）15：50-16：30 英模报告会

**五、**参加人员

（一）认监委、标准委，总局各司局，在京各直属单位党组织1名分管青年工作的负责同志；

（二）总局机关，认监委、标准委40岁以下青年干部；

（三）各直属单位团组织负责人、40岁以下团员青年代表。

**六、**注意事项

（一）请各单位参会人员于15：20之前入场，按照桌签指示就坐，报告会期间注意保持会场秩序；

（二）为充分调动青年干部参与热情，相互启发、深入学习英模精神，报告会后拟开展“微言大义”活动，请各单位团组织引导、鼓励参会团员、青年干部将聆听报告会的感受回复到质检青年微信公众账号，总局机关团委将及时进行收集整理、宣传报道。

请各单位于4月28日17：00前将参会回执报送总局直属机关团委（传真及外网邮件）。
