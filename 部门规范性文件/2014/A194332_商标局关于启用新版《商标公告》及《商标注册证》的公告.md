# 商标局关于启用新版《商标公告》及《商标注册证》的公告

第十二届全国人民代表大会常务委员会第四次会议通过的《关于修改＜中华人民共和国商标法＞的决定》于2014年5月1日起施行。为贯彻执行修改后的《中华人民共和国商标法》，自2014年5月1日起，启用新版《商标注册证》及《商标公告》，特此公告。
