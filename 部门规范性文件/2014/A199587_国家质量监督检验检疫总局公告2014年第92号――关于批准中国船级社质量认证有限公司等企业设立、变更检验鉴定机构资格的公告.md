# 国家质量监督检验检疫总局公告2014年第92号――关于批准中国船级社质量认证有限公司等企业设立、变更检验鉴定机构资格的公告

## 国家质量监督检验检疫总局公告（2014年第92号）

关于批准中国船级社质量认证有限公司等企业设立、变更检验鉴定机构资格的公告

根据《中华人民共和国进出口商品检验法》及其实施条例和《进出口商品检验鉴定机构管理办法》的规定，经质检总局审核，批准中国船级社质量认证有限公司等15家企业自公告之日起获得进出口商品检验鉴定业务许可，批准东莞市信测科技有限公司等4家检验鉴定机构变更许可事项。

现将许可、变更情况公告如下：

**一、**获得许可的检验鉴定机构和许可范围

（一）中国船级社质量认证有限公司。许可范围：根据客户委托，从事进出口锻件、轧制钢材、金属制品、制冷设备、传动机械、管道设备检验业务，不包括实验室检测活动。

（二）北京华检永泰检验技术服务有限公司。许可范围：根据客户委托，从事进出口机电产品、电子电器产品、轻纺产品、石油化工品的检验鉴定，不包括实验室检测活动。

（三）天津天鑫机动车检测服务有限公司。许可范围：进出口汽车检测。

（四）天津天浩机动车检测服务有限公司。许可范围：进出口汽车检测。

（五）天津天检机动车检测服务有限公司。许可范围：进出口机动车检测。

（六）吉林检验检疫局检验检疫技术中心。许可范围：进出口商品检验、检测和鉴定。

（七）宁波中盛产品检测公司。许可范围：进出口石油产品、轻纺产品、矿产品、机械设备、电子电器、纺织品的检验、检测、鉴定服务。

（八）慈溪市天瑞消费品检测技术有限公司。许可范围：进出口轻工产品、化工产品、工艺品、玩具、自行车、健身器材、鞋类、食品接触材料、农产品、化妆品、危险品、塑料制品的检测服务。

（九）青岛邦尔泰国际物流有限公司。许可范围：进出口服装、箱包、寝装等纺织品及杂货的检验、整理服务和咨询业务。不包括实验室检测活动。

（十）日一新国际物流（上海）有限公司。许可范围：进出口服装鞋帽等整理加工、检针检品业务。不包括实验室检测活动。

（十一）广州市纤维产品检测院。许可范围：进出口纤维、纺织品及服装、皮革及毛皮制品、鞋类、土工布、玩具及儿童用品、羽绒、饰品及服装附件、染料及助剂、塑料制品、纸制品的检验。

（十二）佛山市沃特测试技术有限公司。许可范围：进出口电子电气产品（家用电器、灯具、信息技术设备、音视频产品、电源、玩具）的电磁兼容、可靠性、能效与安全性的检测；电子电器、五金、塑胶、纺织品、儿童玩具产品中限制物质的化学检测。

（十三）必维毕法克检验（上海）有限公司广州分公司。许可范围：协助总公司在许可范围内开展检验、鉴定业务。

（十四）深圳科检服饰整理有限公司东莞分公司。许可范围：承接进出口服装、床上用品、室内装饰用品、家具、杂货、纺织面料及纤维的整理、分拣、检验、测试（不含漂、洗、染工艺）。

（十五）苏州UL美华认证有限公司广州分公司。许可范围：进出口产品安全测试、检验服务，电子、机械、材料及环保产品及相关产品的测试、检验服务，电磁兼容及电讯测试服务。

**二、**批准变更的检验鉴定机构名单和变更事项

（一）批准东莞市信测科技有限公司（国质检检许字〔276〕号）变更投资者名称，保持原资格证书号和许可范围不变。

（二）批准广州杰信检验技术服务有限公司（国质检检许字〔192〕号）变更法人代表、投资者名称和机构性质，保持原资格证书号和许可范围不变。

（三）批准上海惠幸服装整理有限公司（国质检检许字〔149〕号）变更投资者名称，保持原资格证书号和许可范围不变。

（四）批准上海众材工程检测有限公司（国质检检许字〔267〕号）变更法人代表、投资者、注册资本，保持原资格证书号和许可范围不变。

质检总局
