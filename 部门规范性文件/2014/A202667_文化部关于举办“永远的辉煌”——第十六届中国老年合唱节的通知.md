# 文化部关于举办“永远的辉煌”——第十六届中国老年合唱节的通知

## 文化部关于举办“永远的辉煌”--第十六届中国老年合唱节的通知

各省、自治区、直辖市文化厅（局），新疆生产建设兵团文化广播电视局：

“永远的辉煌”--中国老年合唱节是文化部为促进老年群众歌咏活动广泛开展、丰富老年人精神文化生活而举办的全国性群众文化活动。自1999年起每年举办一届，至今已成功举办15届，集中展现了全国老年群众合唱活动的丰硕成果，展示了我国老年人积极乐观、昂扬向上、奋发进取、老有所为的精神风貌，受到了全国老年朋友的热烈欢迎，产生了积极而广泛的社会影响。经研究，文化部定于2014年9月在山东省淄博市举办“永远的辉煌”--第十六届中国老年合唱节。现就有关事项通知如下：

**一、**活动时间

2014年9月22日-26日

**二、**活动地点

山东省淄博市张店区

**三、**组织机构

主办单位：文化部

承办单位：文化部公共文化司、山东省文化厅、淄博市人民政府、张店区人民政府、中国合唱协会。

上述单位共同组成“永远的辉煌”--第十六届中国老年合唱节组委会。

**四、**活动内容

“永远的辉煌”--第十六届中国老年合唱节以老年团队合唱风采展示为主，并由承办地自行举办相关文化活动。

**五、**参演团队要求

（一）各省、自治区、直辖市文化厅（局），新疆生产建设兵团文化广播电视局要在广泛开展老年合唱活动的基础上，推荐1-2支当地优秀老年合唱团参加。

（二）每团总人数不得超过45人（包括钢琴伴奏、特色乐器演奏员、指挥、团长或领队）。演唱人数不得超过42人。

（三）参演合唱队员年龄原则上在50岁以上，最高年龄不得超过75岁。要求团员身体健康，70岁以上团员需提供医院健康证明。指挥和伴奏人员年龄可以低于50岁。

（四）参演人员演出应统一着装。

**六、**参演节目要求

（一）每团报送2-3首曲目，其中1首为指定曲目，须从20首“中国梦”第一批主题新创作歌曲中选择（歌曲名单见附件，曲谱和歌词等资料统一下载。邮箱地址：zgmgequ@163.com，密码：zhongguomeng），允许对演唱曲目进行编配合唱曲谱和钢琴伴奏谱。其余1-2首为自选合唱曲目，演唱总时长不得超过15分钟。

（二）自选曲目应适合老年人特点，鼓励演唱具有地方特色的优秀合唱作品，并注重思想性和艺术性相结合。

（三）伴奏形式：钢琴、手风琴、个别特色乐器（5件以下）或无伴奏，现场不得使用伴奏带。

**七、**报名要求

（一）各省、自治区、直辖市文化厅（局），新疆生产建设兵团文化广播电视局负责本省（区、市）合唱团的资格审查和选拔报送工作。报送材料需加盖文化厅（局）公章。

（二）报送材料包括：

1. 合唱团简介（200字以内）；

2. 合唱团成员年龄和健康证明；

3. 合唱团演唱剧照，指挥、团长照片；

4. 演唱曲目及曲谱，包括根据指定曲目改编的合唱谱、钢琴伴奏谱；

5. 词曲作者、合唱编配、指挥、团长、钢琴伴奏及团员名单和联系方式。

**八、**其他事项

（一）为提高老年合唱水平，鼓励各地优秀老年合唱团队积极参与合唱活动，我部将从参演合唱团中评审出5个优秀合唱团，参加第十一届中国艺术节“群星奖”音乐门类合唱比赛决赛。

（二）各参演合唱团队的往返路费和食宿费自理，组委会对食宿费用给予部分补贴。具体安排由承办单位另行通知。

（三）合唱节期间，组委会将安排各团队深入社区、企业演出，各参演团队应服从组委会统一安排。

（四）各省、自治区、直辖市文化厅（局），新疆生产建设兵团文化广播电视局要在团队组织、人员安全及经费保障方面切实负起责任，确保合唱节的安全和顺利举办。
