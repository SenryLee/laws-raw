# 中国证券监督管理委员会公告〔2014〕18号

## 中国证券监督管理委员会公告

2014年第18号

根据中国证券监督管理委员会《上市公司并购重组专家咨询委员会工作规则》（证监会公告[2012]2号）的有关规定，中国证券监督管理委员会补选以下4人为中国证券监督管理委员会第二届上市公司并购重组专家咨询委员会委员。现公告如下（按姓氏笔画排序）：

王建平、任澎、贾文勤、颜志元。

中国证监会

2014年6月5日
