# 交通运输部公告2014年第41号――关于发布《水运工程测量定额》(JTS273-2014)的公告

交通运输部公告

（2014年第41号）

关于发布《水运工程测量定额》（JTS273-2014）的公告

现发布《水运工程测量定额》（以下简称《定额》）。本《定额》为强制性行业标准，编号为JTS273-2014，自2015年1月1日起施行。《航道测量工程定额》（基技字〔1995〕16号）同时废止。

本《规定》由交通运输部水运局组织交通部疏浚工程定额站等单位编制完成，由交通运输部水运局负责管理和解释，由人民交通出版社出版发行。

特此公告。

交通运输部

2014年8月9日
