# 国家邮政局关于做好南京青奥会期间邮政服务和寄递安全工作的通知

各省、自治区、直辖市邮政管理局：

第二届夏季青年奥林匹克运动会（以下称南京青奥会）将于2014年8月16日至28日在江苏南京举行，这是继北京奥运会、上海世博会、广州亚运会之后，我国承办的又一项国际综合性重大活动。为切实做好南京青奥会期间邮政服务和寄递安全工作，现将有关要求通知如下：

一、加强领导，切实增强政治责任感。做好邮政服务和寄递安全工作是确保南京青奥会成功举办的重要保障。各级邮政管理部门要深刻领会习近平总书记关于“办好青奥盛会”的重要指示精神，充分认清当前邮路安全方面面临的严峻形势，切实增强做好各项工作的使命感、责任感、紧迫感。要充分借鉴北京奥运会、上海世博会、广州亚运会期间邮政服务与安全工作的成功经验，坚持“积极主动、各司其职、联合作战、共同负责”的工作思路和“保核心、保重点”的工作原则，加强领导，完善机制，明确责任，细化措施，坚持高标准、高质量组织落实好南京青奥会期间邮政服务和寄递安全工作，确保寄递渠道安全畅通，确保圆满完成各项服务保障任务。

二、精心组织，扎实做好邮政服务保障工作。各省（区、市）邮政管理局要牢固树立全国“一盘棋”思想，指导邮政企业、快递企业制定专门服务方案，采取有效措施做好服务工作，确保青奥会期间各网点正常营业，保障邮件、快件及时、准确收投。江苏省邮政管理局、南京市邮政管理局要充分利用举办南京青奥会的契机，结合开展“绿色邮路、助力青奥”环境大扫除专项行动，着力抓好行业服务方面突出问题的集中整治，进一步规范企业服务行为，严格业务操作规程，全面落实服务、申诉受理等各项管理制度，推动本地区寄递服务水平整体提升。要突出抓好涉奥场所邮政服务保障工作，指导邮政企业制定周密的运动员驻地、比赛场馆、媒体中心等涉奥场所邮政服务保障方案，挑选政治过硬、业务素质好的工作人员派驻邮政临时服务网点，做好相关礼仪和纪律要求培训，加强对涉及赛会官员、运动员以及媒体记者邮件的专项管理，实行专车运输、专人投递，确保服务时限。要会同有关部门做好对周边邮政报刊亭的监督检查工作，指导邮政企业做好青奥会宣传、集邮品售卖等服务，依法查处销售非法出版物等违法行为。

三、严密防范，确保青奥会期间邮路安全万无一失。当前，影响行业安全发展的不利因素较多，各省（区、市）邮政管理局要坚持“万无一失”的标准，采取有效措施，全力维护寄递渠道安全畅通。一是严格抓好源头防范，督促邮政企业、快递企业认真落实收寄验视、安全检查、加盖验视章等制度措施，严把收寄关口，坚决将各类禁寄物品堵截在寄递渠道之外。二是重点抓好涉奥场所寄递安全保障，江苏省邮政管理局、南京市邮政管理局要会同公安、国家安全等部门，严格落实涉奥邮件、快件特殊安全保障措施。所有涉奥邮件、快件必须经邮政企业实行统一扎口，集中安检并加盖安检章后，由邮政企业专人、专车投递至涉奥场所。三是充分发挥邮路安全“护城河”作用，上海、山东、安徽、江西、浙江等周边省（市）以及北京、广州、深圳、武汉等重点城市，要加大对发往南京的邮件、快件安全检查和抽查力度，对涉奥邮件、快件严格落实100%安检要求。四是坚持抓好安全生产工作，督促企业落实安全生产主体责任，对重点部位、重点环节逐一认真排查，及时发现与整改各类安全隐患，坚决防止发生重特大安全生产事故。

四、完善预案，妥善处置青奥会期间各类突发事件。各省（区、市）邮政管理局要严格按照《国家邮政业突发事件应急预案》、《邮政行业安全信息报告和处理规定》等制度要求，进一步落实应急管理职责，制定完善青奥会期间的专项应急预案，督促企业搞好人力、物资、车辆、场地及相关设备等应急准备，适时组织开展应急演练，确保一旦发生自然灾害、事故灾害、公共卫生事件、社会安全事件等突发事件时，能够及时、有效处置，最大限度减少损失和影响。南京青奥会举办期间，各省（区、市）邮政管理局要认真落实值班和领导带班制度，遇有重大问题和事件，要在积极妥善处置的同时，第一时间报告国家邮政局。
