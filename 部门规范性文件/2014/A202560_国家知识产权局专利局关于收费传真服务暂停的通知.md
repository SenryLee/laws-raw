# 国家知识产权局专利局关于收费传真服务暂停的通知

因办公地点线路停电改造，2014年5月28日（周三）至5月30日（周五）每晚18：00至次日8：00专利局收费处传真服务暂停。缴费人如需发送传真补充缴费信息，建议在8：00至18：00之间进行，或可通过电子邮件发送至shoufeichu@sipo.gov.cn。

由此带来的不便敬请谅解。

国家知识产权局专利局

2014年5月28日
