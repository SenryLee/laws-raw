# 中国银行业监督管理委员会银行三部关于加强在华外资银行案件及信息科技风险防范的指导意见

## 中国银行业监督管理委员会银行三部关于加强在华外资银行案件及信息科技风险防范的指导意见（银行三部［2014］100号）

各银监局外资银行监管处室：

在经济形势变化、市场环境变化和内部管控不足的共同影响下，在华外资银行案件和信息科技风险呈现上升趋势。今年以来，风险事件数量较去年同期明显增加，暴露出部分银行在风险防范、内控机制建设以及员工行为管理等方面存在不足。为督促在华外资银行进一步提升风险管控的针对性和有效性，请做好以下工作：

**一、**督促银行强化分支机构管控和员工管理

一是构建有效的本地治理架构，落实本地治理职责，注重平衡条线管理和机构管理，部分网点扩张较快的银行应进一步强化分支机构管控能力；二是切实改进和加强员工管理，及时关注员工异常行为，加大对失范行为的检查力度；三是采取有效措施降低基层员工流失率，针对关键岗位和管理岗位加强人才储备；四是加强对各级员工的法律合规教育和风险防范培训，增强各级管理人员合规意识，建设良好合规文化。

**二、**督促银行强化案件责任追究机制

一是严格问责程序，落实风险责任，对于部分情节较为严重的案件，在严肃追究直接责任人的同时，应加大对管理层的责任追究力度；二是鼓励银行同业间建立员工不良行为信息交流机制，遏制员工“带病流动”现象。

**三、**督促银行提高信息科技风险本地管控水平

一是督促外资银行加快完善信息科技风险管理体系，将信息科技系统建设纳入全面风险管理；二是提升信息科技风险治理能力、关键技术和防护水平，重点防控电子银行、网络攻击、业务外包等领域的风险；三是加强应急演练和压力测试，做好应急处置，加强信息安全防护和外包风险管理，确保信息系统安全稳定运行。

**四、**加大监管力度，做好监管基础工作

一是将案件和信息科技风险事件多发、迟报、瞒报、漏报、整改不力的银行列入重点监测和提示名单，视情况采取更为严格的监管措施；二是将案件和信息科技风险事件的发生、整改和责任追究等情况纳入监管评级、风险评估、资本要求、高管任职资格以及市场准入等统筹考虑；三是深入剖析典型案例和多发事件，分析梳理风险事件发生的原因和暴露出的问题，及时通报和共享相关风险信息，避免类似事件再次发生；四是做好案件和风险事件的统计分析和上报工作，确保相关风险信息报告及时准确。

**一、**案件风险情况

今年以来，外资银行案件和案件风险事件较去年同期大幅增加，并呈现以下特点：一是案情趋于多样化，涉及借记卡盗刷、骗取银行贷款、盗窃客户资金、挪用银行资金、职务侵占等多种类型：二是多为外部侵害或外部人作案，2起为银行遭受骗贷、3起为客户借记卡遭到盗刷，2起涉及银行内部员工：三是个别机构风险事件频发；四是风险多由外部渠道被动暴露，如公安机关办案、客户举报、法律诉讼等，仅有2起事件为银行自查发现；五是操作风险与信用风险呈交织态势，部分行业受经济增速放缓影响较大，风险逐步显现，骗贷、恶意逃废债务等行为明显增多。

**二、**信息科技风险情况

信息科技风险事件较去年同期有所增加，13起事件共涉及8家外资法人银行和3家外国银行分行。从事件后果看，6起事件造成支付转账系统服务中断，5起事件造成网上银行业务停滞，1起事件造成所有与计算机系统相关业务暂停，1起造成核心系统部分模板无法访问。从事件原因看，4起事件为受母行系统故障影响，3起为自身硬件设施物理损坏，2起为自身软件问题，2起为系统管理人员操作失误，其余2起均为受外部因素影响，如自然灾害、外部网络故障等。详细情况如下表所示：

**三、**暴露出的主要问题

（一）业务拓展速度和风险管控能力不匹配

一是部分银行绩效考评过于强调经营业绩增长。特别是部分韩国银行，高管层受到三年派遣期因素的影响，更加看重其任期内的业务发展，对风险控制的重视程度不够，绩效考评中内控和合规指标所占权重较低，导致部分机构对内审或监管发现的内控缺陷重视不够、相关问题整改不到位。二是资源投入不足，风险防控基础较为薄弱。为控制成本，部分银行特别是新设分支机构的岗位职责不能做到有效分离，存在一人多岗、一岗多责现象，导致必要的复核程序出现缺失，埋下操作风险隐患。部分银行在业务快速发展过程中资源配置不合理，中后台人员比例失衡。三是风险防范意识不足，风险管控措施滞后。近年来，韩国银行银行卡盗刷事件频繁发生，银行认为主要原因是韩籍客户沿袭在韩国时的用卡习惯，向刷卡单位透露个人信息和账户密码。但非现场分析和走访发现，韩国银行在快速发卡的同时却忽视对其韩籍客户进行风险教育和风险提示，未及时采取有针对性的防范措施，在相关系统建设、客户账户安全管理等方面存在不足。花旗中国信用卡业务迅猛发展，但风险管控水平未能与业务增长匹配，不仅信用风险逐渐暴露，投诉、信访及声誉风险等事件集中出现，个别已离职员工还因涉嫌信用卡诈骗接受公安机关调查。

（二）员工管理存在薄弱环节

一是员工带病流动带来操作风险隐患。大部分外资银行对违规员工的处罚和问责力度不够，处理结果多以劝退为主，且银行之间缺乏针对员工不良行为信息的共享机制，员工“带病流动”现象较为普遍。二是高管层频繁变动影响风险管理有效性。部分银行高管轮岗完全由母行决定，定期成批更换高管；部分银行同时对分行行长与副行长进行更换；甚至有个别银行7年内更换了6位个人业务条线主管。高管层的频繁更换极大地影响了银行各项政策的稳定性和一致性，导致各项风险管控措施的执行效果大打折扣。三是基层员工流失率居高不下加大操作风险管理难度。随着外资银行管理半径不断扩大，部分银行分支机构已延伸到县域，营业网点和员工人数也颇具规模，但员工流失率仍然居高不下，个别银行零售条线流失率高达70%-80%，个别地区流失率在50%以上。基层员工的频繁流动不仅不利于银行规章制度的执行和落实，也易引致员工短期行为。

（三）系统独立性不足

一是部分银行硬件设施投入和系统本地维护能力不足。部分银行过分依赖外包服务，且对外包风险缺乏有效管控。二是虽然在华外资银行已陆续将核心业务系统迁入境内，但部分银行仍高度依赖母行人员和技术支持。此外，仍有部分业务系统置于境外母行，易遭受风险跨境传染。三是部分银行缺乏有效应急预案和快速处理机制，商业持续性管理系统和灾备中心建设也有待加强。
