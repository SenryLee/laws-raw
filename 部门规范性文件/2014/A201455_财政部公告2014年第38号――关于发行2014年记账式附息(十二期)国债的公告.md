# 财政部公告2014年第38号――关于发行2014年记账式附息(十二期)国债的公告

财政部公告

（2014年第38号）

根据国家国债发行的有关规定，财政部决定发行2014年记账式附息（十二期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

**一、**本期国债计划发行280亿元，实际发行面值金额280.1亿元。

**二、**本期国债期限10年，经招标确定的票面年利率为4%，2014年6月19日开始计息，招标结束后至6月23日进行分销， 6月25日起上市交易。

**三、**本期国债为固定利率附息债，利息按半年支付，利息支付日为每年的6月19日、12月19日（节假日顺延，下同），2024年6月19日偿还本金并支付最后一次利息。

其他事宜按《中华人民共和国财政部公告》（2014年第1号）规定执行。

特此公告。

财政部

2014年6月18日
