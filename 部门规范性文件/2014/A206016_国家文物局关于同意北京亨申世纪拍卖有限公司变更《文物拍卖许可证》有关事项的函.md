# 国家文物局关于同意北京亨申世纪拍卖有限公司变更《文物拍卖许可证》有关事项的函

## 国家文物局关于同意北京亨申世纪拍卖有限公司变更《文物拍卖许可证》有关事项的函（办博函〔2014〕89号）

北京市文物局：

你局《关于北京亨申世纪拍卖有限公司申请变更＜文物拍卖许可证＞相关内容的函》（京文物〔2014〕119号）收悉。

经审核，同意北京亨申世纪拍卖有限公司《文物拍卖许可证》住所变更为北京市朝阳区劲松三区甲302楼12层1208室。变更后的《文物拍卖许可证》随后发给你局。

国家文物局

2014年2月25日
