# 中国民用航空局运输司关于2014年夏秋航季换发国内航线经营许可等情况的信息通告

按照管理程序，同意国航等11家公司部分涉及北京、上海、广州三大城市机场的区际航线经营许可由核准改为登记管理，并按程序对上述航线经营许可进行换发，具体情况通告如下：

1、登记航线

国航等11家公司属登记范围的国内航线经营许可88条，共1982班。

2、注销国内航线经营许可

注销东航、南航和海航属登记范围的国内航线经营许可5条。（以上详见附表）
