# 交通运输部公路局关于报送2014年农村公路工作总结的函

## 交通运输部公路局关于报送2014年农村公路工作总结的函（交公便字〔2014〕189号）

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

为全面总结2014年全国农村公路工作开展情况，研究部署2015年重点工作，请你们对2014年农村公路建设养护管理工作进行总结。有关事宜通知如下：

**一、**总结内容

（一）基本情况。

1.建设方面。包括完成建设投资、农村公路各建设类别实施情况，与交通运输“十二五”规划目标的对标情况等，并填写附件1；

2.养护方面。包括基本情况、实施效果、管理体制、养护运行机制、管养资金需求与落实情况等，并填写附件2。

（二）主要政策措施。

1.本年度省政府、人大针对农村公路发展出台的重要政策、法规或正在研究的重大问题，以及省厅、省局出台的重要文件。

2.省、市、县三级将农村公路发展纳入政府目标考核情况，配套的政策措施及成效。

3.《交通运输部关于推行农村公路建设“七公开”制度的意见》（交公路发〔2014〕100号）的贯彻落实情况。

（三）问题和建议。

1.全面梳理当前农村公路发展中存在的主要问题，并分析问题产生的原因。

2.按照习近平总书记重要批示要求，结合农村公路发展实际，重点就转变农村公路发展模式、加强农村公路建设管理、农村公路发展资金筹集和使用、深化农村公路管养体制改革、完善农村公路法律法规制度体系和加强农村公路保护等方面提出相关政策建议。

**二、**有关要求

做好2014年的农村公路总结工作，对准确分析判断当前农村公路建设与养护管理现状，安排好今后的农村公路工作具有重要意义。请各单位高度重视，认真总结，于11月30日前将总结报部公路局，并发送电子版。
