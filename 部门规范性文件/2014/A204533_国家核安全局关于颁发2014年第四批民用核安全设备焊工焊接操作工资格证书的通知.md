# 国家核安全局关于颁发2014年第四批民用核安全设备焊工焊接操作工资格证书的通知

## 国家核安全局关于颁发2014年第四批民用核安全设备焊工焊接操作工资格证书的通知（国核安发[2014]61号）

各聘用单位：

根据《民用核安全设备监督管理条例》和《民用核安全设备焊工焊接操作工资格管理规定》，我局对中国核工业二三建设有限公司等5家民用核安全设备焊工焊接操作工考核中心的焊工项目考试评定报告进行了审查（考试编号见附件1），认为中国核工业二三建设有限公司等13家聘用单位的66名焊工焊接操作工符合相关要求，批准颁发民用核安全设备焊工焊接操作工资格证书（基本信息见附件2），共计115项合格项目。

特此通知。
