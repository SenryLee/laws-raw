# 住房和城乡建设部稽查办公室关于请报送2014年重点稽查执法工作情况总结的通知

建稽综函[2014]45号

各省、自治区住房城乡建设厅，直辖市建委（建交委）及有关部门，新疆生产建设兵团建设局：

按照《住房和城乡建设部2014年重点稽查执法工作方案》（建稽[2014]33号）的要求，请你们对本地区住房城乡建设系统2014年重点稽查执法工作进行总结。内容主要包括：

**一、**动员部署和组织落实情况。包括制定本地区2014年重点稽查执法工作实施方案，围绕中心任务提出稽查执法工作重点和具体要求，分解落实工作责任，采用哪些形式进行宣传部署，调研督导检查情况等。

**二、**开展重点稽查执法工作情况。包括在城镇保障性安居工程建设管理、房地产市场监管、城乡规划实施、城市建设管理、住房公积金、农村危房改造、建筑节能、建筑市场和工程质量安全和工程建设强制性标准实施等方面，地市级主管部门自查和省级主管部门检查情况；发出整改/执法文书，查处或纠正违法违规案件，曝光典型案例以及解决群众反映强烈的突出问题等情况。

**三、**体制机制建设和创新情况。包括出台相关配套政策制度，建设市场诚信体系，改进和创新监督检查方式，建立长效机制，将重点稽查执法工作纳入常态化监管范畴，探索稽查执法与制度建设、行政许可、选优评奖等业务工作联动，以查促管，推动住房城乡建设事业科学发展等。

**四、**存在问题的改进情况。对本地区重点稽查执法工作中存在的问题采取的解决措施及取得的成效等。

**五、**2015年工作思路。2015年进一步做好重点稽查执法工作的思路、建议和措施等。

请组织县级以上地方住房城乡建设主管部门（含建设、规划、房管、住房公积金、市政、园林部门）填写《住房城乡建设系统2014年重点稽查执法工作情况统计表》（见附件，电子版请到http://jcb.mohurd.gov.cn下载），并统计、汇总数据，于2014年12月10日前将工作总结和汇总表书面材料及电子版光盘一并报部稽查办。

填表说明：

1．本表统计范围包括省、市、县各级住房城乡建设主管部门（含建设、规划、房管、住房公积金、市政、园林部门），由省级住房城乡建设主管部门汇总。

2．本表统计时间为2013年11月1日至2014年10月31日。

3．专项检查指专门针对某一类问题开展监督检查的次数，同项检查内容分多人次检查的只计为1次。如对保障性安居项目的工程质量进行一次全面检查，应计为1次。

4．发整改/执法文书件数是指在专项检查工作中，对发现的违法违规问题发出整改要求或执法要求的文书件数。

5．曝光典型案例件数是指在系统内或向社会公开曝光的违法违规案件数量。

6．稽查执法中发现的突出问题是指在专项检查工作中，发现的本地区城镇保障性安居工程建设管理、房地产市场监管等10方面最多的违法违规问题。如城镇保障性安居工程建设管理方面可以是保障性安居项目违规分配、城乡规划实施方面可以是违反总体规划违规建设或违反详规建设等。
