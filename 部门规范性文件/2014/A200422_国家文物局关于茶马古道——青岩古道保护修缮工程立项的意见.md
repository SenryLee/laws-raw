# 国家文物局关于茶马古道——青岩古道保护修缮工程立项的意见

## 国家文物局关于茶马古道--青岩古道保护修缮工程立项的意见（办保函〔2014〕448号）

贵州省文物局：

你局《关于送审＜茶马古道青岩古道保护修缮立项报告＞的请示》（黔文物呈〔2014〕93号）收悉。经研究，我局批复如下：

**一、**暂不同意茶马古道--青岩古道修缮工程立项。

**二、**请你局指导有关单位对青岩古道进一步开展现场勘察和保存状况评估，调查掌握古道的原始做法和用材，为修补已消失的古道路提供设计依据。同时，从必要性和可行性等方面进一步完善立项报告，明确维修具体内容和拟采取的维修技术手段，另行报批。

**三、**目前阶段应结合文物保护规划编制，做好茶马古道--青岩古道的清理和标识展示工作。

国家文物局

2014年7月17日
