# 国家认证认可监督管理委员会公告2014年第33号――关于浙江省医学科学院安全性评价研究中心良好实验室规范(GLP)到期复查合格的公告

## 国家认证认可监督管理委员会公告（2014年第33号）

关于浙江省医学科学院安全性评价研究中心良好实验室规范（GLP）到期复查合格的公告

根据国家认监委2008年第17号公告及《国家认监委关于修订良好实验室规范（GLP）及评价程序的有关文件的通知》、《良好实验室规范原则》和《良好实验室规范符合性评价程序》的有关要求和程序，经国家认监委组织中国合格评定国家认可中心进行检查合格，浙江省医学科学院安全性评价研究中心近期通过我委的GLP到期复查，批准该实验室可以继续在化学品“毒性研究”和“致突变研究”等方面开展GLP研究，并出具GLP研究报告。浙江省医学科学院安全性评价研究中心的GLP实验室资格有效期为2014年9月17日-2017年9月16日。

特此公告。

国家认监委

2014年9月29日
