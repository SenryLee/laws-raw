# 住房和城乡建设部关于印发《住房城乡建设部直属机关2014年工会工作要点》的通知

## 住房和城乡建设部关于印发《住房城乡建设部直属机关2014年工会工作要点》的通知（建机工[2014]4号）

各直属工会、部机关各司局工会小组：

现将《住房城乡建设部直属机关2014年工会工作要点》印发你们，请结合本单位实际，认真贯彻落实。

直属机关工会

2014年4月10日

住房城乡建设部直属机关2014年工会工作要点

2014年，直属机关工会工作总的要求是：以邓小平理论、“三个代表”重要思想和科学发展观为指导，认真学习贯彻党的十八大和十八届二中、三中全会精神以及中国工会十六大精神，特别是习近平总书记系列重要讲话精神，认真贯彻中央关于全面深化改革一系列重大决策部署，按照中央国家机关工会联合会和部直属机关党委的部署，努力服务中心工作，竭诚为职工服务，切实发挥好联系群众的桥梁纽带作用，在保证中心工作完成、促进和谐单位建设中发挥积极作用。

**一、**深入学习贯彻中央精神和习近平总书记系列讲话精神，积极动员职工在全面深化改革中岗位建功

（一）深入学习贯彻中央精神和习近平总书记系列讲话精神。积极配合党组织学习宣传党的十八届三中全会精神，在推动本单位学习贯彻十八届三中全会精神中发挥积极作用，引导广大干部职工自觉与党中央保持高度一致，不断把思想和行动统一到中央的决策部署上来。组织工会干部重点学习习近平总书记关于工人阶级和工会工作的重要讲话精神，进一步增强广大工会干部做好工会工作的使命感和责任感，结合工会工作实际抓好贯彻落实。

（二）积极开展岗位建功活动。结合党的十八届三中全会精神，抓好中国工会十六大精神的学习贯彻，深入开展“中国梦?劳动美”主题教育活动，引导广大干部职工深刻认识在全面深化改革中担负的重要职责。大力宣传劳模精神，认真总结宣传本单位先进典型事迹，引导职工学先进、见行动、做贡献，努力营造弘扬正气、学习先进的良好氛围。继续开展“创建学习型组织，争做知识型职工”活动，结合工作实际开展形式多样的岗位劳动技能培训或竞赛，引导和促进职工不断提高综合素质。按照中央国家机关工会联合会部署，组织参加中央国家机关第二届公文写作技能比赛。

**二、**积极推动民主管理，更好地为职工群众服务

（三）切实为职工群众服务。积极发挥工会组织的优势，推动以职代会等适合本单位特点的途径和方式参与单位民主决策、民主管理、民主监督，保障职工的知情权、参与权、表达权和监督权。坚持推进职工之家建设，畅通诉求反映渠道，进一步凝聚人心、鼓舞人心、温暖人心。在维护职工合法权益中发挥作用，协助有关部门做好劳务合同、职工“五险”、职工休假等各项工作。

（四）深入开展困难职工帮扶工作。充分履行工会“职工困难第一知情人、第一帮助人、第一报告人、第一督促解决人”的职责，及时了解困难职工的情况，特别是老劳模、老先进工作者、特困职工的困难，不断完善困难职工档案。配合党政部门深入开展困难职工帮扶工作，重点做好春节、五一、十一等重要节日期间“送温暖”活动，落实经常性“送温暖”制度。结合宣传使用中央国家机关职工心理健康咨询服务热线，建立健全维护职工心理健康的工作机制，加强对职工的人文关怀和心理疏导。

**三、**开展丰富多彩的职工文体活动，推进和谐单位建设

（五）积极开展群众文化活动。以庆祝建国65周年为契机，积极开展丰富多彩、主题鲜明、积极向上、群众参与广泛的文化活动，丰富职工文化生活，陶冶职工情操。支持摄影协会开展活动。培育组建新的职工文体活动兴趣组织，带动职工文体活动的开展。

（六）广泛开展群众性健身体育活动。直属机关工会在上半年举办第七届羽毛球友谊赛。下半年，举办第九届乒乓球友谊赛、第八届在职干部与离退休干部局老干部台球友谊赛、第五届迎新春桥牌双人赛。组队参加中央国家机关的有关比赛。支持乒乓球俱乐部、羽毛球协会、桥牌协会开展活动。各单位工会要根据本单位实际组织开展形式多样的体育活动，促进职工健身活动的广泛开展。

**四、**不断加强工会组织的自身建设

（七）加强工会组织建设。加强工会组织建设，督促到届工会按时换届；推动有条件的社团组建工会，扩大工会组织覆盖。配合中央国家机关工会联合会做好机关工会工作条例的制订和实施工作。重视加强工会干部的培训工作，直属机关工会适时举办工会干部培训班。

（八）进一步规范工会经费管理。继续严格执行《工会会计制度》、《工会预算管理办法》、《基层工会经费收支管理办法》，规范财务管理，提高工会财务管理水平。认真落实《中央国家机关工会联合会关于调整工会经费上缴办法的通知》，按规定做好工会经费收缴工作。进一步发挥经审会对本级经费使用情况的审查和监督作用，使工会经费管理更加规范化、制度化。
