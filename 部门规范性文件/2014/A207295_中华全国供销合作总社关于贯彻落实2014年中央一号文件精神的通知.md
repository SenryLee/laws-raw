# 中华全国供销合作总社关于贯彻落实2014年中央一号文件精神的通知

各省、自治区、直辖市及计划单列市、新疆生产建设兵团供销合作社：

为深入贯彻落实《中共中央 国务院关于全面深化农村改革加快推进农业现代化的若干意见》（中发〔2014〕1号）（以下简称中央一号文件）精神，加快供销合作社改革发展，推动中央强农惠农富农政策更好落实，现就有关要求通知如下：

**一、**深入学习领会文件精神，切实把思想和行动统一到中央决策部署上来。2014年中央一号文件是在党的十八届三中全会作出全面深化改革总体部署之后，中央出台的第一个一号文件。文件对新时期全面深化农村改革、加快推进农业现代化作出了部署，是指导当前和今后一个时期农业和农村工作的纲领性文件。特别是文件单列一条，对加快供销合作社改革发展提出明确要求，充分体现了党中央、国务院对供销合作社工作的高度重视和支持，充分反映了新时期“三农”工作对供销合作社深化改革、加快发展、担当重任的迫切要求。当前和今后一个时期，全系统要把学习好、贯彻好、落实好中央一号文件精神作为首要政治任务，精心组织、周密安排，通过多种形式的学习和宣讲，掌握精神实质，把握科学内涵，明确目标任务，教育引导广大干部职工切实把思想统一到中央的分析判断上来，把行动统一到中央的决策部署上来。要通过学习，深刻领会中央关于新时期“三农”工作的战略思想和战略布局，准确把握中央提出的强化农业支持保护制度、深化农村土地制度改革、构建新型农业经营体系、加快农村金融制度创新、健全城乡发展一体化体制机制等8个方面的重点任务，准确把握中国特色新型农业现代化的根本要求是要走出一条生产技术先进、经营规模适度、市场竞争力强、生态环境可持续的道路，准确把握全面深化农村改革的核心要义是要让农民平等参与现代化进程、共同分享现代化成果。要联系供销合作社实际，在融会贯通上下功夫，在学以致用上下功夫，将中央的要求转化为谋划推进供销合作社改革发展的具体行动，在促进新时期农村经济社会发展中承担更多任务、发挥更大作用。

**二、**解放思想，改革创新。中央一号文件明确指出，要解放思想、改革创新，用改革的思路和办法破除体制机制弊端，这为加快供销合作社改革发展提供了强大武器和基本遵循。各级供销合作社要进一步解放思想、开阔视野，站在战略和全局高度，认真分析、全面把握中央一号文件给供销合作社带来的历史机遇与使命要求，切实增强责任感紧迫感，切实增强使命意识和历史担当，紧紧抓住并切实用好机遇，坚定信心、攻坚克难，奋力开创供销合作事业新局面。要进一步深化改革、开拓创新，紧紧围绕中央一号文件决策部署，着眼于全面深化农村改革的新形势，着眼于加快推进农业现代化的新任务，按照改造自我、服务农民的总要求，下大决心和大气力解决制约改革发展的体制机制障碍，激发内生动力和发展活力，增强可持续发展能力。要进一步集中力量、重点突破，抓住健全农业社会化服务体系、加强农产品市场体系建设、加快发展农村合作金融、密切供销合作社与农民联系、推进供销合作社组织体系创新等关键环节，大胆改革创新，大胆探索实践，努力将供销合作社打造成为农民生产生活服务的生力军和综合平台，成为中国特色农村工作体系和农村服务体系的重要组成部分。

**三、**加强组织领导，狠抓贯彻落实。中央关于新时期“三农”工作和供销合作社工作的大政方针已定，关键要抓好落实。各级供销合作社要将学习贯彻中央一号文件精神摆上重要议事日程，按照中央要求和地方党委政府部署，完善领导体制和工作机制，提出具体实施意见，明确工作进度和任务分工，扎扎实实抓好贯彻落实。主要负责同志要担负起组织领导责任，对文件贯彻落实亲自动员、亲自部署，加强工作指导，强化督促检查，务求取得实效。要进一步加强和改进作风，不断巩固和扩大党的群众路线教育实践活动成果，以时不我待的精神，只争朝夕、埋头苦干，把全部心思和精力集中到干事创业上来，一项工作一项工作、一个环节一个环节地抓落实。要加强宣传报道，运用多种媒体手段，大力宣传中央强农惠农富农政策，大力宣传供销合作社贯彻落实中央一号文件的新举措、新进展、新成效，结合“走基层、转作风、改文风”活动，推出一批来自基层一线、生动鲜活的先进人物和典型事迹报道，营造良好舆论氛围。要加强政策协调，各级供销合作社要认真研究和梳理政策，积极向党委政府汇报，主动与有关部门沟通，最大限度争取各方面关心与支持，共同推动中央决策部署落到实处。

各级供销合作社要及时将学习贯彻落实中央一号文件精神的情况报告总社。

中华全国供销合作总社

2014年1月20日
