# 科学技术部基础研究司关于召开2014年地方基础研究工作会议的通知

## 科学技术部基础研究司关于召开2014年地方基础研究工作会议的通知（国科基函〔2014〕32号）

各省、自治区、直辖市、计划单列市科技厅（委、局），新疆生产建设兵团科技局：

为贯彻落实党的十八届三中全会和习近平总书记关于科技工作的一系列重要讲话精神，研讨“十三五”基础研究发展思路，进一步发挥基础研究在创新驱动发展中的作用，经研究，定于2014年10月16-17日在甘肃兰州召开2014年地方基础研究工作会议，届时李萌部长将出席会议并作重要讲话。现将有关事宜通知如下：

**一、**会议主题

提升基础研究水平，支撑区域创新体系建设。

**二、**会议内容

贯彻学习习近平总书记关于科技工作的一系列重要讲话精神，进一步发挥基础研究在实施创新驱动发展战略中的作用；讨论“十三五”基础研究发展思路；交流地方基础研究工作取得的新成绩和新经验；研讨促进地方和企业增加基础研究投入的措施；研讨推进区域创新能力建设的新机制。

**三、**参会人员

严格控制参会人数。邀请各省、自治区、直辖市科技厅（委），新疆生产建设兵团科技局主管基础研究的领导1人及相关职能处室负责人1人，计划单列市科技局相关职能处室负责人1人。

**四、**时间和地点

报到时间：2014年10月15日（全天）；

报到地点：宁卧庄宾馆8号楼（地址：甘肃省兰州市城关区天水中路20号，电话：0931-8271888）；

会议时间：2014年10月16日-17日，会期一天半。
