# 环境保护部公告2014年第20号――关于批准和注销建设项目环境影响评价资质(2014年第四批)的公告

## 环境保护部公告（2014年第20号）

关于批准和注销建设项目环境影响评价资质（2014年第四批）的公告

根据《建设项目环境影响评价资质管理办法》（原国家环境保护总局令第26号）的有关规定，我部对申请建设项目环境影响评价资质（以下简称资质）及注销资质的机构进行了审查。现将资质批准和注销有关事项（2014年第四批）公告如下：

**一、**批准河北晶淼环境咨询有限公司机构资质中的评价范围调整。

**二、**批准中国水电顾问集团西北勘测设计研究院等2家机构资质证书中的机构名称变更。

**三、**批准陕西中圣环境科技发展有限公司等3家机构资质延续。

**四、**批准北京机电院高技术股份有限公司等6家机构资质证书中的法定代表人或住所变更。

**五、**因法人资格终止，注销烟台市牟平区环境保护科研所资质。

上述事项的相关情况详见附件。请上述第一至四项中的机构于60日内携带原资质证书正、副本原件到指定领证地点换领资质证书，其中第二项中的机构应在领取资质证书前，办理环境影响评价专职技术人员的岗位证书和环境影响评价工程师登记证变更手续。第五项中的机构应于20日内将原资质证书正、副本交（寄）回我部，并办理环境影响评价专职技术人员的岗位证书变更和环境影响评价工程师注销登记手续。自本公告发布之日起，上述机构原资质证书正、副本原件及其缩印件同时作废，不得继续使用。
