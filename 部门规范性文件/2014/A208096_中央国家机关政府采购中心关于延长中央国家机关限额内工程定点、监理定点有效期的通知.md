# 中央国家机关政府采购中心关于延长中央国家机关限额内工程定点、监理定点有效期的通知

2012-2013年度中央国家机关限额内工程定点、监理定点有效期已于2013年12月31日截止。目前，新一期限额内工程定点、监理定点的相关招标工作正在进行中。为保障中央国家机关限额内工程和监理业务顺利开展，现将2012-2013年度限额内工程定点、监理定点的有效期延长至新一期入围供应商中标结果公布。

特此通知。
