# 监察部驻国家卫生和计划生育委员会监察局、国家卫生和计划生育委员会统计信息中心关于开展全国卫生计生系统纪检监察机构组织建设情况调查的通知

## 监察部驻国家卫生和计划生育委员会监察局、国家卫生和计划生育委员会统计信息中心关于开展全国卫生计生系统纪检监察机构组织建设情况调查的通知（驻国卫监发[2014]1号）

各省、自治区、直辖市、新疆生产建设兵团卫生计生委（卫生厅局、人口计生委）纪检组（纪委）、监察室（处）、统计信息中心，国家卫生计生委有关直属单位，国家中医药管理局：

为全面了解掌握全国卫生计生系统纪检监察机构组织建设、人员配备等情况，推进卫生计生系统纪检监察队伍建设，进一步加强和改进卫生计生系统纪检监察工作，定于2014年9月开展全国卫生计生系统纪检监察机构组织建设情况调查。现将有关事项通知如下：

**一、**调查范围

本次调查工作主要包括以下单位的纪检监察机构（含派驻纪检监察机构）组织建设情况：

（一）各省（区、市）、市（地、州、盟）、县（市、区、旗）卫生计生委（卫生厅局、人口计生委）；

（二）二级及以上公立医院；

（三）县级及以上疾病预防控制中心；

（四）县级及以上卫生监督机构；

（五）县级及以上妇幼保健院；

（六）计划生育科研院（所）和县级计划生育技术服务站。

**二、**调查内容

（一）被调查单位（本级）纪检监察组织机构设置及组织形式等情况；

（二）被调查单位（本级）纪检监察工作人员（指所从事的岗位明确具有纪检监察职责的人员）配备情况，包括姓名、年龄、性别、学历、职务、工作属性及年限等情况（调查具体内容详见相关调查表）。

**三、**调查方法

（一）由驻国家卫生计生委纪检组监察局和国家卫生计生委统计信息中心联合下发本通知后，地方各级卫生计生委（卫生厅局、人口计生委）纪检组（纪委）、监察室（处）和统计信息中心，应及时将通知及相关调查表转发至辖区内属于调查范围内的有关机构（含其他部门行业所属公立医院），并对辖区内的调查工作做出统一安排和部署。

国家卫生计生委属（管）医院的调查工作由所在地省级卫生计生行政部门负责安排部署，中国医学科学院所属医院的调查工作由中国医学科学院纪委负责安排部署，国家中医药管理局属（管）医院的调查工作由国家中医药管理局纪委负责安排部署，北京医院、中日友好医院、中国疾病预防控制中心、国家卫生监督中心、国家人口计划生育科研所直接按本通知要求进行统计上报。

（二）本次调查范围内的各有关机构均需自行下载相关调查表电子版，并认真组织填报。具体下载方法如下：

1、登陆国家卫生计生委网站“驻国家卫生计生委纪检监察局”主页（http：//www.nhfpc.gov.cn/jcj/index.shtml）；

2、进入“综合管理”栏目，查找调查工作通知；

3、进入通知页面，点击附件链接，下载相关调查表。

（三）调查范围内的各有关机构要严格按照录入文件的格式和要求，既要做好本机构相关组织建设调查表的填报工作，也要组织机构内纪检监察工作人员填报相关人员调查表，并做好统计上报工作。

**四、**报送方式

调查范围内的各有关机构在认真填写组织调查表和工作人员调查表后，经本单位主要负责人审核确认并加盖公章，将加盖公章的调查表扫描文件及调查表的电子文档以附件形式一并直接发送至国家卫生计生委统计信息中心邮箱helei@nhfpc.gov.cn。

**五、**组织实施

本次调查工作由驻国家卫生计生委纪检组监察局统一组织领导，国家卫生计生委统计信息中心具体负责调查设计、数据收集与分析。地方各级卫生计生委（卫生厅局、人口计生委）、纪检组（纪委）监察室（处）和统计信息中心共同负责本辖区内相关机构调查工作的组织、指导和督促。卫生计生系统各级纪检监察机构负责本机构及本机构工作人员相关数据的填报工作，统计信息中心负责指导和督报。

**六、**有关要求和时间安排

（一）各有关单位要高度重视，加强领导，精心组织，落实责任，注重配合，严格审核，确保在规定时间内高质量地完成调查工作。

（二）各单位调查表上报的截止时间为2014年9月30日。

（三）驻国家卫生计生委纪检组监察局与国家卫生计生委统计信息中心将组织调查督导组，对各地调查质量进行抽查。

（四）调查中如遇到问题可通过电话或QQ群及时咨询、报告，避免影响调查工作的效率和质量。

填表说明

**一、**填写方法

1. 报表中每项必填，不能空项。

2.　有选项的，直接填写数字；回答年龄、时间，不要填写数量单位和汉字。

3.　表1-2填写单位本级纪检监察工作人员，不统计单位下设部门或二级单位从事纪检监察相关工作的人员情况。

4.　表格填不下，可续表。

**二、**调查表的指标解释

1.单位全称：填写被调查单位的全称，即省（区、市）、地（市）、县（市、区）卫生计生委（卫生厅局、计生委）的名称，而不是纪检监察机构的名称。

2. 单位：指本级卫生计生委（卫生厅局、计生委）。不是指纪检监察机构。

3. 双派驻：由省（市、县）级纪委监察厅（局）派驻纪检组监察室。“双派驻”机构为一个机构两个名称，履行纪检监察两种职能。

4. 单派驻：由省（市、县）级纪委或监察厅（局）单独派驻的纪律检查或监察机构。

5. 借调：指从事纪检监察工作半年及以上的非本单位编制人员。
