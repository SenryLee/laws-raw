# 农业部办公厅关于开展2014年种子生产基地专项检查行动的通知

## 农业部办公厅关于开展2014年种子生产基地专项检查行动的通知（农办种〔2014〕19号）

有关省、自治区、直辖市农业（农牧、农村经济）厅（委、局），新疆生产建设兵团农业局及种子检验机构：

当前正值杂交玉米、杂交稻制种关键时期。为强化种子市场源头治理，严厉打击制种基地无证生产、品种套牌侵权等违法行为，根据《打击侵犯品种权和制售假劣种子行为专项行动实施方案》（农办种〔2013〕30号），我部定于8月下旬起组织开展杂交玉米、杂交稻种子生产基地专项检查行动。现将有关事项通知如下。

**一、**检查内容

（一）制种企业资质检查。检查制种企业证照是否齐全、资质是否符合要求，是否具有品种权许可或制种委托手续，质量控制体系及生产档案是否健全。

（二）企业生产情况核查。核查企业生产的品种、地点与许可证注明项目是否一致，制种面积与生产信息报送情况是否一致，是否存在无证生产、租借许可证生产等行为。

（三）制种田品种真实性抽检。各地要主动搜集违法违规制种的线索，结合历年基地、市场、企业检查情况，对群众反映侵权生产问题突出的地块、问题企业的基地进行重点检查，并抽取制种田生产品种的杂交穗，进行品种真实性检测。

（四）加工调运环节检查。在种子加工环节，抽取种子样品进行品种真实性检测。在种子调运季节，检查调运种子的生产许可、去向和数量。

**二、**组织方式

本次行动采取有关省（区、市）自查和农业部抽查相结合的方式。请各有关省（区、市）根据农办种〔2013〕30号文件和本通知要求，对本辖区杂交玉米、杂交稻制种基地组织开展拉网式检查。

我部将在各地自查的基础上，结合各方面举报线索，对江苏、湖北、甘肃、新疆等省（区）和新疆生产建设兵团的制种基地进行重点检查，并对种业全程可追溯试点企业基地信息追溯情况进行检查。检查分组及分工等具体安排由我部种子管理局另行通知。

品种真实性检测采用SSR分子标记方法，检测对照采用我部收集的品种标准样品。我部抽查杂交玉米、杂交稻种子样品的真实性检测分别由北京玉米种子检测中心、农业部农作物种子质量监督检验测试中心（深圳）承担。省级抽查样品的真实性检测，有检测能力的自行检测，无检测能力的可从我部考核合格种子检验机构中，选取合适单位开展检测。

**三、**工作要求

（一）确保取得实效。各有关省（区、市）种子管理机构要对本辖区种子生产情况进行核实，并列出生产单位、生产品种、生产地点、面积及联系方式清单，分级组织逐一核查。要广泛发动维权企业举报无证、侵权生产等违法线索，并进行重点检查跟踪。品种真实性抽检应覆盖辖区制种面积的30%以上、制种企业数量的40%以上。

（二）严格规范程序。检查和检验人员要严格执行规定程序，规范做好抽样、记录及取证等各项工作。抽样时务必要求企业如实提供、并确认生产品种的真实名称。要规范完整填写抽样单等信息，妥善留存相关凭证证据，拍照或复印留存制种合同等凭证证据，认真履行样品确认、结果通知等程序，确保形成完整证据链。发现存在无证生产、制种企业不配合检查或抽样等行为的，检查人员应当书面说明情况，由当地种子管理机构加盖公章予以确认，同时通知当地农业行政主管部门调查处理。在行动中要严格执行中央八项规定要求，做到公正规范、廉洁自律、不徇私情。

（三）依法从严查处。有关省（区、市）农业行政主管部门对专项检查行动发现的无证生产、品种套牌侵权等违法行为要逐一立案，每案必查，查必彻底。要按照《农业部关于印发〈农业行政处罚案件信息公开办法〉的通知》（农政发〔2014〕3号）要求，及时公开案件查处信息。要充分利用新闻媒体，加大典型案件曝光力度，继续营造种子打假高压氛围。请于11月底前将案件查处结果连同行动总结报送我部种子管理局。

我部近期将组织11个检查组赴重点地区进行监督检查。请有关单位按要求选派好有关人员按时参加检查（人员分配表见附件），并于8月20日前将参加人员名单报送我部种子管理局。
