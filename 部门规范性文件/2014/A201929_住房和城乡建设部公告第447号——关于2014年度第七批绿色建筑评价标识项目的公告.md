# 住房和城乡建设部公告第447号——关于2014年度第七批绿色建筑评价标识项目的公告

住房和城乡建设部公告

（第447号）

关于2014年度第七批绿色建筑评价标识项目的公告

根据《绿色建筑评价标识管理办法》（建科[2007]206号）、《绿色建筑评价标准》（GB/T50378-2006）、《绿色建筑评价技术细则》（建科[2007]205号）、《绿色建筑评价技术细则补充说明（规划设计部分）》（建科[2008]113号）、《绿色建筑评价技术细则补充说明（运行使用部分）》（建科函[2009]235号）、《绿色工业建筑评价导则》（建科[2010]131号）和相关地方标准，我部组织开展了2014年度第七批绿色建筑评价标识项目评价工作。经审定，苏州有轨电车研发大楼等45个项目获得绿色建筑评价标识。

现予公布。

附件：2014年度第七批绿色建筑评价标识项目

住房城乡建设部

2014年6月13日
