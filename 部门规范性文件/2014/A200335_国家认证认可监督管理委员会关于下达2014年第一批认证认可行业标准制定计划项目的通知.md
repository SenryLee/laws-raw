# 国家认证认可监督管理委员会关于下达2014年第一批认证认可行业标准制定计划项目的通知

## 国家认证认可监督管理委员会关于下达2014年第一批认证认可行业标准制定计划项目的通知（国认科〔2014〕59号）

各有关单位：

为适应认证认可事业发展要求，充分发挥行业标准在认证认可重点工作领域中的重要作用，在广泛征集需求并经业内专家审议基础上，我委研究确定了《2014年第一批认证认可行业标准制定计划项目》（见附件1），现将计划下达各有关单位。为确保该批计划项目的有效实施和管理，现将有关事项通知如下：

**一、**项目承担单位应在计划下达后及时研究制定标准起草工作方案，填写并提交《认证认可行业标准制修订项目任务书》（见附件2），成立标准起草小组，在人员、经费、设备条件及相关资源利用等方面提供保障，尽快启动标准起草工作。

**二、**该批标准计划项目由我委统一安排征求意见、审定等工作。请项目承担单位及时将各工作环节所需材料报送我委指定联系人。

征求意见环节所需材料包括：

1.上报材料的公文；

2.认证认可行业标准草案编制说明（参考格式见附件3）；

3.标准征求意见稿；

4.计划任务书（复印件）；

以及上述材料的电子版。

标准审定环节所需材料包括：

1.上报材料的公文；

2.标准草案（送审稿）；

3.编制说明；

4.征求意见汇总处理表；

5.计划任务书（复印件）；

6.其他应提交的材料；

以及上述材料的电子版。

**三、**项目承担单位应加强项目过程管理与协调，遇有重大问题应及时向我委汇报；同时提供标准研制配套经费保障，确保标准研制各环节工作顺利推进。

**四、**鼓励项目承担单位吸纳有条件和能力、愿意共同参与标准制修订活动的科研院所、企事业单位参加项目起草小组的工作。

**五、**联系人及方式

1.中国认证认可协会：李爽，联系电话：010-65994435，Email：lis@ccaa.org.cn；地址：北京市朝阳区朝外大街甲10号，邮编：100020。

2.国家认监委科标部：冯增健，联系电话：010-82262774，Email：fengzj@cnca.gov.cn。
