# 环境保护部关于750千伏乌鲁木齐北～吐鲁番～哈密输变电工程竣工环境保护验收意见的函

## 环境保护部关于750千伏乌鲁木齐北～吐鲁番～哈密输变电工程竣工环境保护验收意见的函（环验[2014]71号）

新疆电力公司：

你公司提交的《750kV乌鲁木齐北～吐鲁番～哈密输变电工程竣工环境保护验收申请》及相关验收材料收悉。我部组织验收组于2011年10月对工程进行了竣工环境保护验收。经研究，现函复如下：

**一、**工程建设内容

（一）扩建750千伏乌鲁木齐北变电站。站址位于新疆维吾尔自治区乌鲁木齐市，本期建设高压电抗器2组，750千伏出线2回。

（二）新建750千伏吐鲁番变电站。站址位于新疆维吾尔自治区吐鲁番地区，本期建设1500兆伏安主变1组，高压电抗器4组，750千伏出线4回，220千伏出线5回。

（三）新建750千伏哈密变电站。站址位于新疆维吾尔自治区哈密地区，本期建设1500兆伏安主变1组，高压电抗器2组，750千伏出线2回，220千伏出线5回。

（四）新建750千伏乌鲁木齐北～吐鲁番～哈密输电线路。线路路径全长约580公里，途径新疆维吾尔自治区乌鲁木齐市、吐鲁番地区和哈密地区。

工程总投资约444271万元，其中环保投资约4988.5万元，占总投资的1.12%。

**二、**中国电力工程顾问集团中南电力设计院出具的《750kV乌鲁木齐北～吐鲁番～哈密输变电工程竣工环境保护验收调查报告》表明：

（一）变电站及线路周围环境敏感点的工频电场强度、工频磁感应强度监测值均符合《500千伏超高压送变电工程电磁辐射环境影响评价技术规范》（HJ/T24-1998）要求。

（二）变电站厂界昼、夜间噪声监测值均符合《工业企业厂界环境噪声排放标准》（GB12348-2008）3类标准，工程周围环境敏感点昼、夜间噪声监测值均符合《声环境质量标准》（GB3096-2008）相应功能要求。

（三）变电站周围采取了护坡、排水沟等工程措施，站内道路路面进行了硬化。施工临时用地已进行平整和植被恢复，线路塔基周围已恢复原有功能。工程采取了水土保持和生态恢复措施。

（四）变电站生活污水经处理后定期清运或蒸发处理，不外排。变电站设有事故油池，产生的废变压器油等危险废物交有资质单位处理，满足变电站运行的各项环保要求。

（五）通过公众意见调查可知，92.5%的被调查公众对本工程的环境保护工作表示满意或基本满意，7.5%的被调查公众表示无所谓，无不满意意见。

**三、**工程环境保护手续齐全，落实了环境影响评价报告书和批复文件提出的污染防治及生态保护措施，工程竣工环境保护验收合格。

**四、**工程投入运行后应做好电磁、声环境的日常监测工作。我部委托新疆维吾尔自治区环境保护厅及乌鲁木齐市、吐鲁番地区、哈密地区环境保护局负责该工程运行期的环境保护监督检查工作。

**五、**你单位应在收到本文起20日内，将批准后的验收调查报告分送新疆维吾尔自治区环境保护厅及乌鲁木齐市、吐鲁番地区、哈密地区环境保护局。
