# 住房和城乡建设部办公厅关于请按月报送工程质量终身责任制落实情况的通知

建办质函[2014]844号

各省、自治区住房城乡建设厅，直辖市建委，新疆生产建设兵团建设局：

为及时了解各地落实工程质量终身责任制的工作进展，推进工程质量治理两年行动实施，请各地按月报送本地区落实情况。主要内容包括：五方主体项目负责人质量终身责任承诺、永久性标牌和质量信用档案制度落实情况，监督执法检查情况，整改落实情况，违法违规典型案例曝光情况等。具体数据请按附件格式填写。

请各地高度重视报送工作，于每月10日前将上月进展情况报送我部工程质量安全监管司。

联系人及电话：范宏柱　 010-58933293（兼传真）

附件：工程质量终身责任制落实情况月报表

中华人民共和国住房和城乡建设部办公厅

2014年12月22日
