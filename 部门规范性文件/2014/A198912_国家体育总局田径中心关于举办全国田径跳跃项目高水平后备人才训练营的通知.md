# 国家体育总局田径中心关于举办全国田径跳跃项目高水平后备人才训练营的通知

各省、自治区、直辖市、计划单列市体育局青少处、田径中心，各有关体育院校：

为了加强田径跳跃项目高水平后备基地建设和教练员培训工作，促进后备人才培养，定于10月21日-11月2日在山东省青岛市体育运动学校举办全国田径跳跃项目高水平后备人才训练营。全国田径跳高、撑竿跳高、跳远、三级跳远项目奥林匹克高水平后备人才基地（见附件一）每个单位选派1名教练员、4名运动员参加，将聘请部分专家、高水平专项教练员参与训练营组织、指导训练和教练员培训工作。现将有关事宜通知如下：

**一、**报名与报到

（一）《报名表》（见附件二）请于9月25日前传真至我中心青少部，传真：010-67142515；联系人：金玲，电话：010-87183451.

（二）请于10月21日到山东省青岛市李沧区金水路69号青岛市体校报到，联系人：李洁，电话：0532-81935105，13953253902。

**二、**各单位参加人员差旅费自理，训练营期间食宿费由我中心负担。

**三、**聘请白二宇、王嘉陵、黄健民、李怀光、王万培、熊杰、麦国强、刘俭、张仁杰、邹振先、XXX等部分专家、高水平专项教练员参加工作，差旅、交通、食宿、劳务等费用由我中心支付。

体育总局田径中心

2014年9月10日
