# 文化部办公厅关于公布2014年全国美术馆馆藏精品展出季活动目录的通知

办艺函〔2014〕141号

各省、自治区、直辖市文化厅（局）：

2014年全国美术馆馆藏精品展出季活动项目评选工作已经顺利完成。经过专家委员会的认真评审，并报文化部审核通过，共有41个项目入选《2014年全国美术馆馆藏精品展出季活动目录》，现将该目录予以公布，并将相关工作通知如下：

**一、**所报项目纳入《2014年全国美术馆馆藏精品展出季活动目录》的美术馆应当按照《文化部办公厅关于开展2014年全国美术馆馆藏精品展出季活动的通知》（办艺函〔2014〕5号）要求以及既定的展览计划，认真组织、周密安排，积极开展好公共教育、宣传推广工作，努力提高展览社会效益，确保入选展览项目高质量完成。

**二、**凡纳入《2014年全国美术馆馆藏精品展出季活动目录》的项目，在展览举办及相关宣传等活动中，应标注“文化部2014年全国美术馆馆藏精品展出季”标识。文化部不作为《2014年全国美术馆馆藏精品展出季活动目录》中具体展览项目的主办单位。

**三、**所推荐项目纳入《2014年全国美术馆馆藏精品展出季活动目录》的各省、自治区、直辖市文化厅（局）应当采取有力措施，保障活动的顺利实施，指导并支持相关美术馆做好入选项目的宣传推广工作，督促相关美术馆做好展览的组织筹备、展出和总结工作。

**四、**文化部将对入选项目进行统一的宣传和推广，并对展览成果进行汇集，请各省、自治区、直辖市文化厅（局）及相关美术馆积极做好配合工作。展览结束后，各馆需对项目进行认真总结。文化部将根据入选项目的展览效果和社会反响，以及总结情况进行验收评审，评选出优秀展览项目，给予奖励性补贴；并将对在此次活动中组织工作等表现突出的文化厅（局）予以表扬。
