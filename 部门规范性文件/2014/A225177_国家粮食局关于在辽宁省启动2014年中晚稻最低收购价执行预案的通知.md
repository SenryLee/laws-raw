# 国家粮食局关于在辽宁省启动2014年中晚稻最低收购价执行预案的通知

国粮调〔2014〕261号

中国储备粮管理总公司：

你公司《关于在辽宁省启动2014年中晚稻最低收购价执行预案的请示》（中储粮〔2014〕862号）收悉。根据国家发展改革委等部门《关于印发2014年中晚稻最低收购价执行预案的通知》（发改经贸〔2014〕2104号）有关规定，经研究，同意即日起在辽宁省启动2014年中晚稻最低收购价执行预案。

国家粮食局

2014年12月5日
