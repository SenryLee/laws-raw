# 国家知识产权局办公室关于公布2014年知识产权分析评议服务示范创建机构名单的通知

各省、自治区、直辖市、新疆生产建设兵团知识产权局，各有关单位：

按照《国家知识产权局办公室关于开展2014年知识产权分析评议服务示范机构培育工作的通知》（国知办函协字〔2014〕148号）要求，我局组织开展了2014年国家知识产权分析评议服务示范创建机构培育工作。通过机构自愿申报、国务院有关部门及各省（区、市）知识产权局审核推荐，经过初评及集中汇报专家现场评审、网站公示等环节，确定33家2014年知识产权分析评议服务示范创建机构，现将名单公布。各省（区、市）知识产权局要结合实际，落实好相关工作，进一步加大支持力度，为知识产权分析评议服务发展创造良好环境。

特此通知。

国家知识产权局办公室

2014年8月28日
