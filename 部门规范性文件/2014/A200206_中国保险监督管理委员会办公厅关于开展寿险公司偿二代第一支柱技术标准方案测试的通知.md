# 中国保险监督管理委员会办公厅关于开展寿险公司偿二代第一支柱技术标准方案测试的通知

## 中国保险监督管理委员会办公厅关于开展寿险公司偿二代第一支柱技术标准方案测试的通知（保监厅函〔2014〕318号）

各人身保险公司：

自2012年3月中国保监会启动第二代偿付能力监管制度体系建设（简称偿二代）以来，各项工作进展顺利。在广泛听取各方意见基础上，我会对偿二代体系下寿险公司的认可资产、寿险业务保单负债评估及量化风险资本要求的计量方法进行了深入研究和多次论证，形成了寿险公司偿二代第一支柱技术标准的初步方案。根据工作程序，我会决定开展技术标准的“方案测试”，以确定各对比方案对我国寿险业实际风险状况的吻合度、敏感度和有效性。现将有关要求通知如下：

**一、**测试内容

各对比方案下，寿险公司认可资产、认可负债、量化风险最低资本、偿付能力充足率的数额及其对不同情景的反应。

**二、**测试对象

各寿险公司、健康险公司和养老险公司的全部业务，包括所有寿险业务和非寿险业务。

公司可根据自身业务结构情况，选取主要业务（比如现行法定准备金规模占比之和不低于90%），按照本通知测算方案计算，并对其它业务采用合理的近似方法估计。

**三、**测试时点

本次测算以2013年12月31日为测试时点，公司采集该时点各项实际数据，分别测算现实情景和低利率假设情景下的偿付能力状况。其中，现实情景采用2013年12月31日实际市场信息，低利率假设情景根据2009年12月31日实际市场信息经适当调整后得到。

**四、**测试方法

（一）实际资本。

1.资产评估。根据《保险公司偿付能力监管规则第x号：实际资本》（附件1）和《认可资产评估测试方案》（附件2）确定认可资产。

2.负债评估。非寿险业务（主要包括短期意外险和短期健康险）认可负债根据《保险公司偿付能力监管规则第x号：实际资本》（附件1）确定认可负债；寿险业务准备金根据《寿险合同负债评估测试方案》（附件3）确定，其他认可负债根据《保险公司偿付能力监管规则第x号：实际资本》（附件1）确定认可负债。

3.实际资本为认可资产减去认可负债。

（二）量化风险最低资本。

1.利率风险最低资本。根据《利率风险最低资本测试方案》（附件4）计算。

2.其它市场风险和信用风险最低资本。根据《保险公司偿付能力监管规则第x号：市场风险最低资本（财产保险公司）》（附件5）、《保险公司偿付能力监管规则第x号：信用风险最低资本》（附件6）计算。

3.保险风险。非寿险业务保险风险最低资本根据《保险公司偿付能力监管规则第x号：保险风险最低资本（非寿险业务）》（附件7）计算；寿险业务保险风险最低资本根据《保险公司偿付能力监管规则第x号：保险风险最低资本（寿险业务）》（附件8）计算。

4.风险相关性及最低资本汇总。根据《保险公司偿付能力监管规则第x号：最低资本》（附件9）、《风险相关性矩阵》（附件10）计算得到量化风险最低资本。

5.保险合同负债的损失吸收调整。对本次测算，公司可以自行决定是否计算保险合同负债的损失吸收调整，计算方法可参考《保险合同负债的损失吸收》（附件11）。

（三）偿付能力充足率。

公司根据实际资本除以量化风险最低资本，得到偿付能力充足率。偿付能力充足率测算对比方案为认可资产、认可负债等相关对比方案的指定组合：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
|  | 资产评估 | 最优估计 | 风险边际 | 利率风险 |
| 方案一 | 附件2  方案一 | 附件3  折现率方案一 | 附件3  风险边际方案二 | 附件4  利率风险方案一 |
| 方案二 | 附件2  方案二 | 附件3  折现率方案二 | 附件3  风险边际方案一 | 附件4  利率风险方案二 |
| 方案三 | 附件2  方案一 | 附件3  折现率方案三 | 附件3  风险边际方案二 | 附件4  利率风险方案三 |

**五、**测试要求

（一）请各公司高度重视，认真研究，精心组织实施。公司主要负责人担任本次测试工作第一责任人，并明确相关高管人员的分管责任，精算、财务、投资等相关部门密切配合，建立协调高效的工作团队和工作机制。

（二）各公司应准确采集基础数据，严格按照监管规则开展测试。

（三）各公司应于8月11日17：00前将填报完成的数据模板（附件12）、测试结果以及有关对比方案的意见和建议（至少应包含附件13《征求意见问卷》列出的相关问题），通过保监会电子文件传输系统报送信息模块报送至保监会财会部，报送材料应经公司相关高管人员和主要负责人审阅签批。

（四）请各公司于7月29日前通过邮件向我会财会部报送测试工作联系人及联系电话、联系邮箱等信息。
