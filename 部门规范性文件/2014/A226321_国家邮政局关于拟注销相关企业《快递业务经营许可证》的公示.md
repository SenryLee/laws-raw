# 国家邮政局关于拟注销相关企业《快递业务经营许可证》的公示

根据《快递业务经营许可管理办法》第二十一条和《快递业务经营许可注销管理规定》第九条第（二）项规定，拟注销以下企业快递业务经营许可证，现予公示。

一、拟注销许可证企业名单

1.北京星晨急便速递有限公司

企业名称：北京星晨急便速递有限公司

许可证号：国邮20100218A

注册地址：北京市顺义区空港物流基地物流园八街1号

注销原因：快递业务经营许可证有效期内停止经营

2.深圳市鑫飞鸿快递有限公司

企业名称：深圳市鑫飞鸿快递有限公司

许可证号：国邮20110322A

注册地址：深圳市龙岗区内环路鹏达花园9号楼167铺

注销原因：快递业务经营许可证有效期内停止经营

二、公示时间

公示时间：2014年7月21日—2014年8月4日。

三、监督方式

如有异议，请于公示期内将书面意见反馈至国家邮政局市场监管司，并提供联系方式。

通信地址：北京市西城区北礼士路甲8号国家邮政局市场监管司，邮编：100868。

监督电话：010-88323247；传真：010-88323376。
