# 国家认证认可监督管理委员会办公室关于下拨2014年度认证行政监管专项经费的函

## 国家认证认可监督管理委员会办公室关于下拨2014年度认证行政监管专项经费的函（认办可函〔2014〕151号）

各直属检验检疫局，各省、自治区、直辖市质量技术监督局：

根据各局上报2014年网格化监管工作方案及工作任务安排，国家认监委认可部已将2014年度认证行政监管专项经费下拨你局，用于支付2014年度网格化检查工作产生的交通、住宿、午餐等费用。请按照专款专用、厉行节约的原则使用经费，并于2014年11月底前将绩效报告报国家认监委认可部。

附件：1.各直属出入境检验检疫局拨款表

2.各省级质量技术监督局拨款表

认监委办公室
