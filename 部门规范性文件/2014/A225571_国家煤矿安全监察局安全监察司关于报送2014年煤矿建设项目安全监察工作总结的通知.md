# 国家煤矿安全监察局安全监察司关于报送2014年煤矿建设项目安全监察工作总结的通知

煤安监司函监察〔2014〕69号

各省级煤矿安全监察局：

为全面总结2014年煤矿建设项目安全设施设计审查、安全设施竣工验收以及现场监察等工作情况。现就有关事项通知如下：

1．请各省级煤矿安全监察局认真汇总、分析2014年煤矿建设项目安全监察工作开展情况，主要包括工作制度完善落实情况、实际工作中取得的成熟经验和体会、当前存在的突出矛盾与问题、贯彻落实《国务院办公厅关于进一步加强煤矿安全生产工作的意见》（国办发〔2013〕99号）情况，下一步工作意见及建议等。

2．按附表格式填报辖区内2014年在建煤矿项目基本情况、煤矿建设项目安全设施设计审查和竣工验收工作开展情况、现场监察执法情况，以及2015年大型煤矿建设项目安全设计审查预计报批情况。各项数据统计日期为2013年12月1日～2014年11月30日。

3．为进一步了解《国家煤矿安全监察局关于2012年煤矿建设项目安全监察工作情况的通报》（煤安监监察〔2013〕8号）中“三同时”工作的落实情况，请说明是否将设计或者新增的生产能力在45万吨/年以下的井工煤矿建设项目安全设施设计审查和竣工验收工作收回由省局负责，仍实行由分局负责的请说明理由，并说明审查和验收批复上报国家局备案的情况。

4．上述材料加盖公章后，于2014年12月10日前报送国家煤矿安监局安全监察司（包括电子版）。
