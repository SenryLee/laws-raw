# 国家减灾委员会关于做好2014年国际减灾日主题宣传的通知

## 国家减灾委员会关于做好2014年国际减灾日主题宣传的通知（国减发〔2014〕4号）

国家减灾委员会各成员单位，各省、自治区、直辖市减灾委员会，各计划单列市减灾委员会，新疆生产建设兵团减灾委员会：

今年10月13日是第25个国际减灾日，联合国国际减灾战略（UNISDR）确定今年国际减灾日主题是“Resilience is for Life”，与老年人和灾害有关。经与UNISDR沟通和确认，中文主题译为“提升抗灾能力就是拯救生命--老年人与减灾”。

我国是世界上遭受自然灾害影响最严重的国家之一，灾害种类多，分布地域广，发生频率高，造成损失重。近年来，我国人口老龄化加速，老年人口基数大、增长快，高龄化、空巢化趋势明显，失能、半失能老人比例高。随着老年人口增长高峰到来，今后一段时期我国人口老龄化进程将进一步加快，据预测，到2015年全国60岁以上老年人将达2.21亿（老年人口比重达16%），到2030年全国老年人口规模将会翻一番。老年人由于年龄和体能所限，在自然灾害面前具有一定的脆弱性，尤其是多灾易灾地区的农村留守老人和城市空巢老人，子女多在外地务工或工作，如遭受地震、山体滑坡、山洪、泥石流等突发自然灾害，由于缺乏亲属及时帮助，其逃生避险和自救互救能力会显著降低。鉴于老年人群体的特殊性，各地区、各有关部门在制定防灾减灾救灾政策、编制应急预案时，要充分考虑到老年人的特殊需求，统筹做好防灾减灾救灾各项工作；灾害来临前，政府有关部门一旦发布灾害预警，要确保每一位老年人能及时获取信息，同时及时组织开展人员排查，并根据需要及时做好转移安置和逃生避险工作；灾害发生后，要统筹做好灾区老年人的生活、起居、医疗、康复等保障工作，帮助生活困难的老年人做好灾后民房恢复重建，并安排专人或志愿者做好心理抚慰工作；在日常组织开展社区应急演练、防灾减灾培训、现场观摩体验等活动时，要积极吸纳老年人参与，充分发挥他们的专长和经验，增强社区居民防灾减灾意识和自救互救技能，提升全社会抗风险能力。

请各地区、各有关部门结合今年国际减灾日主题，按照职责做好相关工作。

国家减灾委员会

2014年9月9日
