# 国家体育总局等十部委关于开展2014年国民体质监测工作的通知

## 国家体育总局等十部委关于开展2014年国民体质监测工作的通知（体群字【2014】5号）

各省、自治区、直辖市体育局、教育厅（教委）、科技厅（局）、民（宗）委（厅、局）、民政厅（局）、财政厅（局）、农业厅（局）、卫生计生委（卫生厅局）、统计局、总工会：

根据《全民健身条例》、《全民健身计划（2011-2015年）》和《国民体质监测工作规定》等相关规定，决定于2014年开展第四次全国国民体质监测工作。

请接此通知后，认真按照《2014年国民体质监测工作方案》的规定，做好各项筹备工作，确保本次监测工作的顺利实施。
