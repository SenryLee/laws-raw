# 财政部办公厅关于调整广西壮族自治区电脑福利彩票21选5“好运彩”开奖次数的通知

## 财政部办公厅关于调整广西壮族自治区电脑福利彩票21选5“好运彩”开奖次数的通知（财办综[2004]163号）

中国福利彩票发行管理中心：

你中心报来的《关于广西电脑福利彩票增加“好运彩”开奖次数的请示》（中彩发字[2004]71号）收悉。根据《彩票发行与销售管理暂行规定》等规定，经研究，现将有关事项通知如下：

一、同意你中心调整广西壮族自治区电脑福利彩票21选5“好运彩”的开奖次数，并按批准的游戏附则组织销售。调整后游戏命名为“快乐十分”，每15分钟开奖一次，开奖采用电子摇奖系统和设备，销售时间从每天上午九点至晚上二十一点。

二、正式上市销售前，广西壮族自治区福利彩票发行中心需将销售实施方案，包括开奖及公证、技术准备、广告宣传、正式销售日期等报广西壮族自治区财政厅审核，批准后上市宣传销售。

三、广西壮族自治区福利彩票发行中心在对外公告和宣传中，必须注明财政部、广西壮族自治区财政厅的批准文件、核准文件名称及文号。

四、请你中心严格按照现行彩票管理制度规定，督促广西壮族自治区福利彩票发行中心做好彩票销售工作，认真做好对外宣传公告工作，加强彩票发行销售的安全管理，确保“快乐十分”游戏的顺利实施。

附件：广西风采21选5电脑福利彩票“好运彩”（快乐十分）游戏附则

二○○四年八月六日

附件：

广西风采21选5电脑福利彩票“好运彩”（快乐十分）游戏附则

**第一条**　根据财政部《彩票发行与销售管理暂行规定》和中国福利彩票发行管理中心《中国福利彩票（电脑乐透型）发行规则》以及《广西风采电脑福利彩票21选5游戏规则》之相关条款，制定本附则。

**第二条**　本附则是《广西风采电脑福利彩票21选5游戏规则》之附加规则。《广西风采电脑福利彩票21选5游戏规则》之总则、发行、兑奖、附则均适用于本附则。

**第三条**　广西福利彩票发行中心在保持原广西风采电脑福利彩票21选5游戏不变的基础上，增加“好运彩”的开奖次数，每15分钟开奖一次，并把这种游戏命名为“快乐十分”。“快乐十分”每天销售12小时，共开奖48次。

**第四条**　广西风采“快乐十分”以广西风采21选5的开奖号码进行投注，2-4个号码的组合称为一注，每注人民币2元

**第五条**　广西风采“快乐十分”按期销售，期号使用目前21选5期号之后增加两位数实现，如200411008。

**第六条**　广西风采“快乐十分”可在全区福利彩票投注站进行投注。投注方法可分自选号码投注和机选号码投注；当期投注和多期投注；单倍投注和多倍投注。

**第七条**　投注站为有纸投注，投注号码经投注机打印出票，确认无误后，交投注者保存。该打印票即为广西风采小组合游戏电脑福利彩票，为中奖者唯一的兑奖凭证。该打印票不记名、不挂失、不返还本金。

**第八条**　自选号码投注是将投注者选定的号码输入投注机进行投注；机选号码投注是由投注机随机产生的投注号码进行投注。

**第九条**　当期投注是指只购买当期的彩票，多期投注是指购买从当期起连续若干期的彩票；多倍投注是同样的号码购买多倍的投注。

**第十条**　广西风采“快乐十分”按好运2、好运3、好运4实行奖金分列，奖金为销售总额的50%，其中当期返奖49%，调节基金1%，只设一个奖级，奖金采用中奖注数均分，单注奖金以元为单位取整。当期奖金设奖具体如下表：

|  |  |  |
| --- | --- | --- |
| 类别 | 中奖条件 | 奖金 |
| 好运4 | 所选4个号码与开奖号码5个号码中任意4个相同 | 按中奖注数平分当期奖金 |
| 好运3 | 所选3个号码与开奖号码5个号码中任意3个相同 | 按中奖注数平分当期奖金 |
| 好运2 | 所选2个号码与开奖号码5个号码中任意2个相同 | 按中奖注数平分当期奖金 |

**第十一条**　广西风采“快乐十分”好运2、好运3、好运4均分设奖池，奖池资金由单注奖金封顶后约余额以及未中出奖金构成。奖池资金与当期实现奖金一并派发当期奖金

**第十二条**　调节基金包括按当期销售总额1％提取部分、弃奖奖金和单注奖金按元取整后的余额。调节基金用于设置该游戏的特别奖。

**第十三条**　当期每注号码只有一次中奖机会，不能兼中兼得，特别设奖除外。

**第十四条**　兑奖时间、期限、方法均同广西风采21选5游戏规则。

**第十五条**　本附则由广西福利彩票发行中心解释。

**第十六条**　本附则自发布之日起实施。
