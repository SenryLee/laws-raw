# 财政部办公厅关于云贵川联合销售22选5电脑福利彩票增加小组合游戏的通知

## 财政部办公厅关于云贵川联合销售22选5电脑福利彩票增加小组合游戏的通知（财办综[2004]209号）

中国福利彩票发行管理中心：

你中心报来的《关于云、贵、川联合销售22选5电脑福利彩票增加小组合游戏的请示》（中彩发字［2004］105号）收悉。根据《彩票发行与销售管理暂行规定》等制度规定，经研究，现将有关事项通知如下：

**一、**同意你中心在云贵川22选5电脑福利彩票的基础上增加小组合游戏，并按批准的游戏附则组织销售。

**二、**22选5电脑福利彩票小组合游戏的销售量按三省分地区核算，分别计入各自销售总量，并以此为依据计提彩票公益金和发行经费。请你中心督促云南、贵州、四川省福利彩票发行中心，严格按照所批准的联合销售管理办法、资金结算办法和游戏附则做好小组合游戏的销售工作。

**三、**云南、贵州、四川省福利彩票发行中心应在正式销售小组合游戏前，将销售实施方案，包括技术系统、广告宣传、正式销售日期分别报送同级财政部门，经核准后上市销售。

**四、**云南、贵州、四川省福利彩票发行中心应做好对外公告和宣传工作，并在公告中注明财政部的批准文件名称及文号。

附件：云、贵、川联合销售22选5电脑福利彩票游戏附则

二○○四年十月十八日

附件：

云、贵、川联合销售22选5电脑福利彩票游戏附则

**第一条**　根据《彩票发行与销售管理暂行规定》和《中国福利彩票（电脑乐透型）发行规则》以及《云、贵、川联合销售22选5电脑福利彩票游戏规则》之相关条款，制定本附则。

**第二条**　本附则是《云、贵、川联合销售22选5电脑福利彩票游戏规则》之附加规则。《云、贵、川联合销售22选5电脑福利彩票游戏规则》之总则、发行、兑奖、附则均适用于本附则。

**第三条**　云、贵、川三省福利彩票发行中心在联合销售电脑福利彩票22选5游戏的基础上，增加选3中3、选4中4之投注，本投注方式统称小组合投注，并按相应选号个数分别简称为“好运3”和“好运4”。每注金额人民币2元。

**第四条**　22选5小组合游戏按期销售，期号与22选5游戏相同。

**第五条**　22选5小组合游戏可在三省福利彩票投注站进行投注。投注方法可分自选号码投注和机选号码投注；当期投注和多期投注；单倍投注和多倍投注。

**第六条**　投注站为有纸投注，投注号码经投注机打印出票，确认无误后，交投注者保存，该打印票即为22选5小组合游戏电脑福利彩票，该彩票是中奖者唯一的兑奖凭证。此打印票不记名、不挂失、不返还本金。

**第七条**　自选号码投注是将投注者选定的号码输入投注机进行投注；机选号码投注是由投注机随机产生的投注号码进行投注。

**第八条**　22选5小组合游戏按“好运3”“好运4”实行奖金分列，奖金为各自销售总额的50%，其中当期返奖49%，调节基金1%，只设一个奖级，奖金采用中奖注数均分，单注奖金以元为单位取整。具体如下表：

|  |  |  |
| --- | --- | --- |
| 类别 | 中奖条件 | 奖金 |
| 好运4 | 所选4个号码与开奖号码5个基本号中任意4个相同 | 按中奖注数平分当期奖金 |
| 好运3 | 所选3个号码与开奖号码5个基本号中任意3个相同 | 按中奖注数平分当期奖金 |

**第九条**　22选5小组合游戏好运3、好运4均分设奖池，奖池资金由单注奖金以元为单位取整后的余额以及未中出奖金、弃奖奖金以及超过单注奖金封顶部分构成。奖池资金与当期奖金一并派发当期中奖奖金。

**第十条**　当期每注号码只有一次中奖机会，不能兼中兼得，特别设奖除外。

**第十一条**　兑奖时间、期限、方法均同22选5游戏规则。

**第十二条**　本附则由各省福利彩票发行中心在所辖行政区域内负责解释。

**第十三条**　本附则自发布之日起实施。
