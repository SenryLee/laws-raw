# 水利部南水北调规划设计管理局关于南水北调工程水泵模型同台测试工作征集受试水泵模型的通知

各有关单位：

南水北调东线第一期工程需新建21座和改造3座大型低扬程泵站，泵型选择的科学合理性直接关系到泵站工程的建设投资、运行维护费用、水价和供水安全。为了提高南水北调泵站设计质量，努力保证水泵性能资料的可靠性与准确性，水利部决定在前期工作阶段开展水泵模型同台测试工作。该项工作的管理规定与工作大纲已通过南水北调工程水泵模型同台测试工作领导小组和专家组审定，并在水利部相关网站上公示。

现向国内征集适用于南水北调工程的水泵模型，欢迎垂询，欢迎参与！请有意向提供受试水泵模型的单位，尽快填写水泵模型的征集回执，以便同台测试工作的安排。

**1、**总则

1.1　为保证南水北调工程前期工作阶段水泵模型同台测试工作科学规范进行，提高公信度，依据有关法律、法规，特制定本管理规定。

1.2　南水北调工程水泵模型同台测试（以下简称同台测试）是指在已通过省部级或以上部门鉴定的同一水泵试验台上，对适用于南水北调工程的各种规格的水泵模型进行测试。

1.3　同台测试应按照《南水北调工程水泵模型同台测试工作大纲》（以下简称工作大纲）规定的范围和要求进行集中测试。

1.4　同台测试工作应在受试单位自愿的基础上进行，不应拒绝受试单位参与测试的要求，但受试单位提供的受试水泵模型中同一规格的仅安排测试一台（套）。所有受试水泵模型的测试顺序由领导小组办公室确定。

1.5　参与测试的水泵模型属于受试单位的财产，参与同台测试的人员应对受试单位的受试水泵模型的原始技术资料保密。

1.6　同台测试工作的主要任务：

1.6.1　为南水北调工程泵站前期设计阶段水泵选型论证提供可靠、准确的水泵模型性能试验资料。

1.6.2　对南水北调工程已经完成初步设计的泵站所选的水泵模型参数和性能进行复核检查。

1.6.3　为完善我国低扬程大流量水泵型谱积累技术资料。

**2、**组织机构

2.1　由水利部会同国家质量监督检验检疫总局成立南水北调工程水泵模型同台测试工作领导小组（以下简称“领导小组”）。

2.2　领导小组下设办公室，设在水利部南水北调规划设计管理局。办公室负责领导小组的日常工作。领导小组负责同台测试工作的组织和领导；负责测试过程中重大问题的决策；负责对测试过程中发生的争议进行协调，必要时负责提请有关部门仲裁。

2.3　同台测试工作设立专家组、监督组和测试组。

2.3.1　专家组成员由领导小组聘任。专家组负责明确测试的方法、标准、要求、技术规定；审定工作大纲；对测试过程中的技术问题提出解决办法，评审测试成果。

2.3.2　监督组成员由领导小组聘任。监督组按照工作大纲的要求监督全部测试过程。对测试结果签字确认并对领导小组负责。

2.3.3　测试组由承担同台测试单位具有相应资质的技术人员组成并报领导小组备案。测试组负责水泵模型的接收、保管、安装、拆卸、调试及试运转；按照工作大纲的要求进行测试；负责对测试成果的整理、分析，建档编写测试报告。

**3、**公正性保证

3.1　承担同台测试单位应具有独立开展测试业务的能力和资质，不参与受试模型的研制工作，具有良好的职业信誉。应严守公正地位，不受来自行政、经济或其它方面的影响和干预，严格按照工作大纲以及有关质量手册与程序文件，独立地开展测试工作。

3.2　参加同台测试的所有受试单位和人员，不得利用宴请、馈赠、行贿或其它不正当手段，从事任何影响或有损于测试公正性的活动。

3.3　参与同台测试工作的单位和人员，未经允许，不得将受试单位提供的水泵模型翻拍和测绘，不得将原始技术资料向第三方提供，不得利用原始技术资料进行技术开发及技术咨询。

3.4　领导小组对违背公正性原则的一切行为将负责提请有关部门严肃查处并追究责任。

**4、**质量保证

4.1　试验台必须通过省部级或以上部门组织的鉴定。试验台测试最大效率总误差应不超过±0.4%。

4.2　用于测试的仪器仪表，均应按国家质量监督检验检疫总局有关规定进行校验，并在有效期内使用。检定证书应提交监督组备案。

4.3　所有测试工作应建立测试工作质量保证体系，按照工作大纲的规定进行，控制测试关键环节，严格测试程序，提高测试水平，测试方法、测试成果的分析和报告的编写均应符合国家和行业相关标准的要求。

4.4　参与测试工作的有关测试人员应经过与其承担任务相应的培训，具有相应的专业技术知识和经验，持证上岗。

4.5　测试组应制定测试细则、测试流程，建立岗位责任制。

**5、**测试成果管理

5.1　同台测试的最终成果由领导小组办公室负责管理备案，并统一发布。

5.2　受试单位通过向领导小组办公室申请，在统一发布前可获得本单位受试水泵模型的最终测试结果。

**6、**测试经费

6.1　同台测试试验台测试费用（包括测试组、监督组、专家组的工作费用）由南水北调工程前期工作经费中专项安排，不向受试单位收取。

6.2　受试模型测试所需要的包装、运输、保险以及由此发生的其它费用，均由受试单位承担。

6.3　在水泵模型安装、测试期间，由于受试单位设计或选材不当、水泵模型制造不良、受试单位技术人员的安装调试指导错误、提供的技术资料及文件错误等导致水泵模型的个别部件或设备损坏，应由受试单位承担责任并自行负责修复。如果经监督组确认由于其结构设计或水力设计不良、选材、制造不当，因其性能指标偏低而不宜再参加同台测试的模型，不再进行测试。

6.4　受试单位在模型测试期间派驻试验台的有关人员所发生的交通、食宿等各项费用自理。

6.5　受试单位如对测试成果提出异议，要求复测时，受试单位需要支付复测和首测的费用。

**7、**附则

7.1　本规定经南水北调工程水泵模型同台测试工作领导小组审定后执行。

7.2　本规定由南水北调工程水泵模型同台测试工作领导小组办公室负责解释。

**1、**水泵模型征集

1.1　水泵模型的征集应遵循公开、广泛的原则。征集范围为适合南水北调工程选型使用的有关水泵模型，包括受试单位拥有知识产权（含使用权）的从国外引进的水泵模型。

1.2　提供测试的水泵模型如果发生产权纠纷，应由受试单位自行负责。

1.3　对受试水泵模型的基本要求

1.3.1　同台测试的水泵模型主要为轴流式与混流式；

1.3.2　受试单位提供的水泵模型过流部件（如压水室、叶轮、吸水室以及导叶等），应严格按设计图纸制造，并符合水泵模型试验验收规定的制造允差。过流部件的制造和选材应充分考虑整个试验期间对其刚度、强度的要求。水泵模型段必须留有合适的与试验台设备的接口，联轴器的要求见附图，应成对提供DN350mm模型泵进、出口联结法兰。

1.3.3　水泵模型的叶轮和过流部件表面应光滑、型线加工准确。

1.3.4　受试模型水泵叶轮标称直径均为300mm。

**2、**水泵模型的交接

水泵模型运抵承担同台测试试验台后，在监督组的监督下，由测试组和受试单位的技术人员共同进行水泵模型、随机备品备件、专用工器具（如果有）、安装调试技术图纸和资料等的交接并填写交接清单。交接清单应详细写明相互交接的设备、部件及技术资料的名称、规格、数量、外观质量等，经三方负责人签字确认后在监督组的监督下进行存放。

每台（套）水泵模型测试工作结束后，应在监督组的监督下进行水泵模型的拆卸和临时封存，拆卸和封存记录应经监督组和测试组负责人签字确认并报领导小组办公室备案。

**3、**受试水泵模型编号

按照《南水北调工程水泵模型同台测试工作管理规定》的要求，测试组应对所有受试水泵模型按下列形式统一编号：

TJ（测试年份）-泵类型代号-水泵模型序号

具体说明如下：

3.1　测试年份

以年份的后两位数表示。如2004年，应以“04”表示。

3.2　泵类型代号

```
蜗壳混流式　　　　HLW

导叶混流式　　　　HLD

轴流式　　　　　　ZL

离心式　　　　　　CP
```

3.3　水泵模型序号

对每种水泵类型，按进行同台测试时间先后顺序连续编号，以两位阿拉伯数（01～99）表示。

**4、**水泵模型的安装、调试和试运转

水泵模型的安装、调试和试运转工作应在监督组的全程监督下由测试组进行，受试模型单位的技术人员应积极配合并提供现场安装和调试技术服务与指导。

4.1　安装前的工作

水泵模型在试验台安装前，被测模型的受试单位应就水泵模型的安装调试技术要求向监督组和测试组进行技术交底；在监督组的监督下，核查模型的安装尺寸、安装精度要求，对水泵流道主要几何尺寸、叶片翼型厚度及叶片根部厚度进行测量并记录，对模型泵主要部件的材质进行记录，详细检查模型各转动部分的润滑和密封情况。

上述技术交底、检查和测量记录应由监督组、受试单位和测试组三方签字确认。

4.2　水泵模型的安装和调试

受试单位提供的水泵模型将被安装在试验台专门制作的水泵支架上。该支架应具有足够的刚度、强度，并便于水泵模型的安装、拆卸和调整。

水泵与转速转矩传感器之间采用弹性柱销式联轴器，转速转矩传感器与水泵轴之间只有扭矩传递。

在水泵模型安装过程中，应详细检查模型各转动部分的润滑和密封情况。为获得准确、可靠的测试结果，应严格检查转轮叶片与转轮室之间的间隙，要求最小间隙不应小于0.15mm。

对于可调叶片的水泵模型，在改变叶片安放角时，必须保持叶片轴线位置不变，不得另行调整叶片与叶轮室、轮毂体的间隙，单个叶片转角的允许偏差为±0.25o。

安装、调试结果应由监督组、受试单位和测试组三方负责人签字确认。

4.3　水泵模型试运转

在水泵模型机组的安装调试完成后，在监督组监督下，由测试组进行模型泵组的试运转工作。试运转的主要目的是排除整个循环系统中的游离气体，检查水泵模型转动系的轴承、密封、噪声和振动情况。试运转记录和结果应经监督组、受试单位和测试组负责人签字确认。

试运转过程中，如果水泵模型出现密封不良、噪声和振动过大、部件频繁损坏等现象，经测试组和监督组确认系由于水泵模型结构或水力设计不良、选材或制造不当引起而无法进行正常测试时，将停止该套水泵模型的测试工作，详细记录停止测试的原因并报领导小组备案。

**5、**水泵模型测试

5.1　同台测试内容

同台测试工作试验内容包括模型泵段效率试验和模型泵段汽蚀试验。具体测试方法见附录。

5.2　测试标准及规范

测试工作应按照现行有效的国家、行业有关水泵、水轮机试验标准并参照相关国际标准、规范进行。

```
《离心泵、混流泵和轴流泵试验方法》　　　　　　　　　　GB/T18149-2000

《离心泵、混流泵和轴流泵验收试验规程》　　　　　　　　ISO/DIS5198

《水泵模型验收试验规程》　　　　　　　　　　　　　　　SL140-97

《蓄能泵模型验收试验国际规程》　　　　　　　　　　　　IEC497

《水轮机模型验收试验国际规程》　　　　　　　　　　　　IEC193

《用考虑比尺效应的水力机械模型验收试验确定原型性能》　IEC995

《南水北调工程水泵模型同台测试工作管理规定》
```

5.3　测试周期

完成一台套水泵模型从接受、安装、调试、试运转、测试到模型拆卸、封存全过程平均所需要的时间约为5～7个工作日。各阶段需要的工作时间分布大致如下：

```
单套水泵模型的接收、检查及必要的尺寸测量　　　　　　　0.5～1个工作日

单套水泵模型的安装、调试及试运转　　　　　　　　　　　1～2个工作日

水泵模型在不同叶片安放角下的效率试验和汽蚀试验　　　　3个工作日

试验成果的初步分析及水泵模型的拆卸和临时封存　　　　　0.5～1个工作日
```

5.4　测试成果的封存

经过监督组签字确认后的每套水泵模型所有测试成果应及时封存，封存记录应经监督组和测试组负责人签字确认。

**6、**测试成果的评审和验收

同台测试全部完成后，由领导小组办公室组织测试成果的评审和验收。测试组应准备如下成果资料：

6.1　测试报告

测试组应向评审专家组提交经监督组、测试组技术负责人签字；测试单位盖章的测试报告，该报告应包括以下主要内容：

试验台有关技术资料；

试验台测量方法、测量精度；

试验台仪器、仪表的标定；

同台测试试验内容及测试要求；

试验日期、人员、水泵模型编号、环境条件；

受试水泵模型的有关资料、主要几何尺寸及有关照片；

受试水泵模型的测试与计算结果、特性曲线及图表；

测试误差分析。

6.2　原始测试记录

测试组应将受试水泵模型的原始检查记录和原始测试记录资料整理后装订成册并存档，以供评审专家组核查。

7.1　本工作大纲经南水北调工程水泵模型同台测试工作专家组审定后执行。

7.2　本工作大纲由南水北调工程水泵模型同台测试工作领导小组办公室负责解释。
