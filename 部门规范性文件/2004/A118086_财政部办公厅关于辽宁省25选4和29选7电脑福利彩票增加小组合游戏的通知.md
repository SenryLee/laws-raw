# 财政部办公厅关于辽宁省25选4和29选7电脑福利彩票增加小组合游戏的通知

## 财政部办公厅关于辽宁省25选4和29选7电脑福利彩票增加小组合游戏的通知（财办综[2004]31号）

中国福利彩票发行管理中心：

你中心报来的《关于辽宁省电脑福利彩票增加小组合游戏的请示》（中彩发字[2004]27号）收悉。根据《彩票发行与销售管理暂行规定》等制度规定，经研究，现将有关事项通知如下：

**一、**同意你中心在辽宁省25选4和29选7电脑福利彩票中增设小组合游戏，并按所报游戏附则组织销售。

**二、**正式销售前，辽宁省福利彩票发行中心需将销售实施方案，包括技术准备、广告宣传、正式销售日期报辽宁省财政厅审核，批准后上市宣传销售。

**三、**辽宁省福利彩票发行中心在对外公告和宣传中，必须注明财政部、辽宁省财政厅的批准文件、核准文件名称及文号。

**四、**请你中心严格按照现行彩票管理规定，督促辽宁省福利彩票发行中心做好彩票销售工作。

附件：1.辽宁省25选4电脑福利彩票游戏附则

2.辽宁省29选7电脑福利彩票游戏附则

二○○四年四月二日

附件l：

辽宁省25选4电脑福利彩票游戏附则

**第一条**　根据则一政部《彩票发行与销售管理暂行规定》和中国福利彩票发行管理中心《中国福利彩票（电脑乐透型）发行规则》以及《辽宁省25选4电脑福利彩票游戏规则》之相关条款，制定本附则。

**第二条**　本附则是《辽宁省25选4电脑福利彩票游戏规则》之附加规则。《辽宁省25选4电脑福利彩票游戏规则》之总则、发行、一开奖、兑奖、附则等条款均适用于本附则。

**第三条**　辽宁省福利彩票发行中心在25选4游戏（以下简称“辽宁省25选4”）基础上，增加从25个号码中选1中特别号码、选2中2个基本号码、选3中3个基本号码的投注方式，统称小组合游戏，并按选号个数分别称为“好运1”、“好运2”、“好运3”。每注人民币2元。

**第四条**　“辽宁省25选4”小组合游戏按25选4销售期销售，期号以彩票销售结束日界定，按日历年度编排。

**第五条**　“辽宁省25选4”小组合游戏可在全市福利彩票投注站进行投注。投注方法可分自选号码投注和机选号码投注；当期投注和多期投注；单式投注、复式投注和胆拖投注；单倍投注和多倍投注。

**第六条**　投注站为有纸投注，投注号码经投注机打印出票，确认无误后，交投注者保存，该打印票即为“辽宁省25选4”小组合游戏电脑福利彩票，该彩票是中奖者唯一的对奖凭证。此打印票不记名、不挂失、不返还本金。

**第七条**　单倍投注是从25个号码中选择1个、2个、3个作为1注。多倍投注是同样的号码进行多倍的投注。

**第八条**　“辽宁省25选4”小组合游戏按“好运1”、“好运2”、“好运3”实行奖金分列，奖金分别为当期销售总额的50%，其中当期返奖49%，调节基金1%。只设一个奖级，奖金按中奖注数均分，单注奖金以元为单位取整。当期奖金设奖具体如下表：

|  |  |  |
| --- | --- | --- |
| 类　别 | 中奖条件 | 奖　　金 |
| 好运3 | 所选3个号码与开奖号码4个基本号码中任意3个相同 | 按中奖注数平分当期奖金 |
| 好运2 | 所选2个号码与开奖号码4个基本号码中任意2个相同 | 按中奖注数平分当期奖金 |
| 好运1 | 所选1个号码与开奖号码特别号码相同 | 按中奖注数平分当期奖金 |

**第九条**　“辽宁省25选4”小组合游戏“好运1”、“好运2”、“好运3”均分设奖池，奖池资金由未中出奖金和超过单注奖金封顶部分构成。“好运1”、“好运2”和“好运3”奖池资金和当期奖金一并派发当期中奖奖金。

**第十条**　调节基金包括按当期销售总额1%提取部分、弃奖奖金和单注奖金按元取整后的余额。调节基金用于设置特别奖。

**第十一条**　“辽宁省25选4”小组合游戏单注奖金最高封顶500万元，超过部分进入奖池。

**第十二条**　“辽宁省25选4”小组合游戏中奖号码均采用“辽宁省25选4”的正常开奖号码。

**第十三条**　当期每注号码只有一次中奖机会，不能兼中兼得，特别设奖除外。

**第十四条**　“辽宁省25选4”小组合游戏兑奖时间、期限、方法均同“辽宁省25选4”游戏规则。

**第十五条**　本附则由辽宁省福利彩票发行中心解释、修订。

**第十六条**　本附则自发布之日起实施。
