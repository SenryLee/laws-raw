# 财政部办公厅关于甘肃、青海、宁夏省(自治区)25选7电脑福利彩票增加小组合游戏的通知

## 财政部办公厅关于甘肃、青海、宁夏省（自治区）25选7电脑福利彩票增加小组合游戏的通知（财办综[2004]183号）

中国福利彩票发行管理中心：

你中心报来的《关于甘、青、宁三省（区）电脑福利彩票25选7增加小组合投注的请示》（中彩发字[2004]88号）收悉。根据《彩票发行与销售管理暂行规定》等制度规定，经研究，现将有关事项通知如下：

**一、**同意你中心在甘青宁25选7电脑福利彩票的基础上增加小组合游戏，并按批准的游戏附则组织销售。

**二、**25选7电脑福利彩票小组合游戏的销售量按三省区分地区核算，分别计入各自销售总量，并以此为依据计提彩票公益金和发行经费。请你中心督促甘肃、青海、宁夏三省区福利彩票发行（管理）中心，严格按照所批准的联合销售管理办法、资金结算办法和游戏附则做好小组合游戏的销售工作。

**三、**甘肃、青海、宁夏三省区福利彩票发行（管理）中心应在正式销售小组合游戏前，将销售实施方案，包括技术系统、广告宣传、正式销售日期分别报送同级财政部门，经核准后上市销售。

**四、**甘肃、青海、宁夏三省区福利彩票发行（管理）中心应做好对外公告和宣传工作，并在公告中注明财政部的批准文件名称及文号。

附件：甘青宁25选7电脑福利彩票游戏附则

二○○四年九月六日

附件：

甘青宁25选7电脑福利彩票游戏附则

**第一条**　根据《彩票发行与销售管理暂行规定》和《中国福利彩票（电脑乐透型）发行规则》以及《甘肃、青海、宁夏三省区25选7电脑福利彩票游戏规则》之相关条款，制定本附则。

**第二条**　本附则是《甘肃、青海、宁夏三省（区）25选7电脑福利彩票游戏规则》之附加规则。《甘肃、青海、宁夏三省（区）25选7电脑福利彩票游戏规则》之总则、发行、兑奖、附则均适用于本附则。

**第三条**　甘、青、宁三省（区）福利彩票发行管理中心在“黄河风采”电脑福利彩票7/25游戏（以下简称“黄河风采-7/25”）的基础上，增加选1个号码、选2个号码、选3个号码、选4个号码、选5个号码的投注，本投注方式统称为“好运彩”小组合游戏，并按相应选号个数分别简称为好运1、好运2、好运3、好运4、好运5，每注彩票人民币2元。

**第四条**　“好运彩”按“黄河风采-7/25”销售期销售，期号与“黄河风采-7/25”游戏相同。

**第五条**　“好运彩”可在甘、青、宁三省（区）福利彩票投注站进行投注。投注方法可分自选号码投注和机选号码投注；当期投注和多期投注；单式投注和复式投注。

**第六条**　投注站为有纸投注，投注号码经投注机打印出票，确认无误后，交投注者保存，该打印票即为“好运彩”电脑福利彩票，该彩票是中奖者唯一的兑奖凭证。此打印票不记名、不挂失、不返还本金。

**第七条**　自选号码投注是将投注者选定的号码输入投注机进行投注；机选号码投注是由投注机随机产生的投注号码进行投注。

**第八条**　“好运彩”按好运1、好运2、好运3、好运4、好运5实行奖金分列，奖金为销售总额的50%，其中当期返奖49%，调节基金1%。只设一个奖级，奖金采用中奖注数均分，单注奖金以元为单位取整。

**第九条**　“好运彩”按好运1、好运2、好运3、好运4、好运5分设奖池，奖池资金由未中出奖金和超过单注奖金封顶部分构成。奖池资金与当期实现奖金一并派发当期奖金。

**第十条**　调节基金包括按当期销售总额1％提取部分、弃奖奖金和单注奖金取整后的余额、逾期未退票的票款。调节基金用于设置特别奖。

**第十一条**　“好运彩”游戏单注奖金最高封顶500万元，超过部分进入奖池。

**第十二条**　“好运彩”中奖号码采用“黄河风采-7/25”的正常开奖号码。具体设奖方案如下：

|  |  |  |
| --- | --- | --- |
| 类 别 | 中　奖　条　件 | 奖　金 |
| 好运5 | 所选5个号码与开奖号码  7个基本号中任意5个相同 | 按中奖注数平分当期奖金 |
| 好运4 | 所选4个号码与开奖号码  7个基本号中任意4个相同 | 按中奖注数平分当期奖金 |
| 好运3 | 所选3个号码与开奖号码  7个基本号中任意3个相同 | 按中奖注数平分当期奖金 |
| 好运2 | 所选2个号码与开奖号码  7个基本号中任意2个相同 | 按中奖注数平分当期奖金 |
| 好运1 | 所有1个号码与开奖号码特别号码相同 | 按中奖注数平分当期奖金 |

**第十三条**　当期每注号码只有一次中奖机会，不能兼中兼得，特别设奖除外。

**第十四条**　“好运彩”游戏在投注站兑奖，若单注奖金超过2000元（含）在市、州彩票中心兑奖。兑奖期限同“黄河风采-7/25”。

**第十五条**　本附则由甘、青、宁三省（区）福利彩票发行管理中心解释。

**第十六条**　本附则自发布之日起实施。
