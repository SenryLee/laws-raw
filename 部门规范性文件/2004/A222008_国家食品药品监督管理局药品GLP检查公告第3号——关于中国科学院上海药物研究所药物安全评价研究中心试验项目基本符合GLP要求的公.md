# 国家食品药品监督管理局药品GLP检查公告第3号——关于中国科学院上海药物研究所药物安全评价研究中心试验项目基本符合GLP要求的公告

国家食品药品监督管理局药品GLP检查公告（第3号）

（国食药监安[2004]375号）

根据《中华人民共和国药品管理法》的有关规定，依据《药物非临床研究质量管理规范》（GLP）及《药物非临床研究质量管理规范检查办法》，国家食品药品监督管理局组织有关专家对中国科学院上海药物研究所药物安全评价研究中心实施GLP情况进行了检查。经检查，该机构以下试验项目基本符合GLP要求，现予公告。

```
机 构 名 称　　　　　　　　　　　　　　试 验 项 目

中国科学院上海药物研究所　　1、单次给药毒性试验（啮齿类、非啮齿类）；

（药物安全评价研究中心）　　2、多次给药毒性试验（啮齿类、非啮齿类）；

3、生殖毒性试验；

4、遗传毒性试验（Ames、微核、染色体畸变）；

5、致癌试验；

6、局部毒性试验；

7、免疫原性试验；

8、安全性药理；

9、毒代动力学试验。
```

国家食品药品监督管理局

二○○四年八月三日
