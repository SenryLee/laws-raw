# 国家食品药品监督管理局GLP检查公告第6号——关于国家成都中药安全评价中心试验基本符合GLP要求的公告

国家食品药品监督管理局GLP检查公告（第6号）

（国食药监安[2004]589号）

根据《中华人民共和国药品管理法》的有关规定，依据《药物非临床研究质量管理规范》（GLP）及《药物非临床研究质量管理规范检查办法》，国家食品药品监督管理局组织有关专家对国家成都中药安全评价中心实施GLP情况进行了检查。经检查，该机构以下试验基本符合GLP要求，现予公告。

```
机构名称　　　　　　　　　　　　试验项目

国家成都中药安全性评价中心　1．单次给药毒性试验（啮齿类、非啮齿类）；

2．多次给药毒性试验（啮齿类、非啮齿类）；

3．生殖毒性试验；

4．遗传毒性试验（Amcs、微核、染色体畸变）；

5．致癌试验；

6．局部毒性试验；

7．免疫原性试验；

8．安全性药理试验；

9．毒代动力学试验。
```

国家食品药品监督管理局

二○○四年十二月九日
