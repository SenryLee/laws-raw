# 国家广电总局关于中央电视台少儿频道改为不加密播出的通知

为贯彻落实中共中央、国务院《关于进一步加强和改进未成年人思想道德建设的若干意见》和总局《广播影视加强和改进未成年人思想道德建设实施方案》，自2004年5月14日起，在亚太1A卫星上加密播出的中央电视台少儿频道已改为不加密播出，用户使用普通卫星数字接收机即可收转，原用接收机可继续使用。中央电视台少儿频道接收参数如下：

亚太1A卫星：东经134度

下行中心频率：4160MHz

下行极化方式：水平

前向纠错：3/4

符号率：27.5Msps。

国家广电总局

二00四年五月二十一日
