# 科学技术部关于开展国家科技基础条件平台2002年度、2003年度项目检查的通知

## 科学技术部关于开展国家科技基础条件平台2002年度、2003年度项目检查的通知（国科发财字[2004]541号）

各有关单位：

为加强国家科技基础条件平台项目的管理，规范资金的使用，提高资金的使用效益，保证项目的顺利完成，科技部、财政部将共同组织项目检查工作组对平台项目进行检查，检查结果将作为项目评价的重要依据。现将有关事项通知如下：

**一、**项目检查的范围和形式

本次检查项目的范围为2002年在科技基础性工作专项中立项的平台试点项目和2003年立项的经费额度为100万元以上的平台项目。

本次检查采取自查、会议检查和现场检查三种形式。

**二、**具体要求

项目承担单位要积极配合项目检查工作组的工作，如实报告项目进展情况和存在的问题。

项目承担单位要对项目进行认真自查，第一承担单位负责编写《国家科技基础条件平台项目自查报告》、《国家科技基础条件平台项目预算执行情况自查报告》（自查报告的格式从科技部网站下载：http：//www.most.gov.cn/通知通告栏目），并报上级主管部门签署意见，其他参加单位须对自查报告签署意见并盖章。

在项目检查工作组进行会议检查和现场检查时，项目各参加单位均应到场，如未到场则视为不接受检查。

请项目承担单位于2005年1月25日前将项目自查报告（纸质版一式八份及电子版）报送科技部条件财务司、财政部教科文司。

会议检查和现场检查在自查后进行，具体时间及有关要求另行通知。

**二、**项目检查报告（提纲）

（一）项目进展情况概述

实施的技术方案，采取的共享措施，对国家科技基础条件平台建设及经济社会发展产生的影响，项目实施后对行业和领域的科技进步已经产生的意义和作用等。

（二）主要工作内容、阶段目标和成果

在整体工作方案中，现阶段的工作内容及重点任务，本项目的已经实现的阶段目标、成果及其表现形式、资源整合情况、社会共享形式和范围，以及项目风险控制情况等。

（三）工作机制情况

各参加单位协作情况，项目任务分工的完成情况，经费、人员安排的落实情况，与项目第一承担单位之间的互动与沟通情况等。

（四）实施进度

项目进展阶段是否与总体设计方案及项目实施周期、时间进度表符合。

（五）考核指标的完成

主要包括项目成果运行与共享状况；形成国家科技基础条件平台相关基地和人才队伍情况；形成行业标准、国家标准和国际标准情况等。指标要求真实、具体、可靠。

（六）项目经费情况

项目支出经费总额，与项目阶段目标是否对应，变更原因；单位自筹及从其他渠道获得资金的落实情况。

（七）项目执行中存在的问题及难点

（八）与本项目相关的其它内容和证明材料

**三、**承担单位（项目实施过程中研究人员、实验或试验设备及条件和资金等方面的相关支持或承诺的兑现状况）

**四、**各参加单位意见（盖章）

**五、**主管部门意见（对项目的工作基础、项目实施可行性和申报单位相关能力的说明，部门对该项目的相关支持和配套保证的落实情况）

国家科技基础条件平台项目预算执行情况自查报告(主要内容提纲

)

**一、**项目基本信息

（一）项目承担单位基本情况

简要说明项目承担单位情况及主管部门名称。如果承担单位发生机构变化的要说明。

（二）项目立项基本情况

简要说明项目基本情况，包括项目名称、项目编号、项目起止时间、项目负责人等。

（三）项目协作情况

1.说明预算批准的项目协作情况，包括协作单位、协作内容、协作经费等。实际发生的项目协作情况和预算相比是否有调整，如有调整是否报批。

2.是否与协作单位签定合同（或协议），合同中对于协作内容是否有具体约定。

（四）项目完成情况

简要说明项目完成和验收情况。未完成的要说明是项目未到期，还是经批准延期、未经批准延期等。（只需说明属于哪种情况即可）

**二、**专项经费的财务管理、会计核算情况

1.简要说明单位层次的主要财务管理制度、核算模式、支出审批权限等；

2.列出为承担的项目制订的管理制度；

3.说明该项目是否独立核算、专款专用，是否按全成本核算；

4.说明项目购置的固定资产管理、使用情况。

**三、**项目预算安排及执行情况

（一）预算安排情况

说明下达预算的文件号，安排预算详细情况，有无调整。

（二）专项经费到位情况

说明财政专项资金拨入的总额、拨款的时间及金额、拨入单位等具体情况。需说明是否与预算一致。

（三）专项经费拨付情况

1.说明项目承担单位收到专项资金后，向项目协作单位下拨经费的时间、数额、拨入的单位名称；

2.有批准预算的外协项目要说明专项经费是否按批准预算足额、及时下拨；

3.专项经费拨付如有调整，说明原因及是否报批。

（四）配套经费到位情况

说明已到位配套经费情况，配套经费到位率，到位形式及使用、结余情况，并提供相应证明材料。

（五）项目经费使用情况

按“支出科目”（即人员费、购置费、相关业务费等）说明项目经费实际支出情况。需与预算对比说明，对于支出科目调整较大的，要说明原因。

以下两项需重点说明：

1.仪器设备购置（试制）情况。购置（试制）设备发生调整及预算外购置的，要说明理由。

2.项目管理费支出情况。说明项目管理费是据实列支还是提取的，对于提取的情况要说明提取的比例和实际使用。

（六）项目经费结余情况

说明经费的实际结余情况，结余的原因及使用计划。

**四、**项目经费管理和使用中存在的主要问题

说明：1.以上预算执行情况的统计期为项目开始实施起至2004年12月31日止；

2.附表的统计期同上。

附表：1.国家科技基础条件平台项目预算执行情况表；

2.国家科技基础条件平台项目购置（试制）固定资产登记表。
