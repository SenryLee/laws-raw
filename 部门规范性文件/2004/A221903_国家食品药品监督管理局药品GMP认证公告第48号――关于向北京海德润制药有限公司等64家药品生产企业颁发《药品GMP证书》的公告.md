# 国家食品药品监督管理局药品GMP认证公告第48号――关于向北京海德润制药有限公司等64家药品生产企业颁发《药品GMP证书》的公告

国家食品药品监督管理局药品GMP认证公告

（第48号）

根据《中华人民共和国药品管理法》的有关规定，依照国家食品药品监督管理局颁布的《药品GMP认证管理办法》，经按程序进行现场检查和审核批准，同意向北京海德润制药有限公司等64家药品生产企业颁发《药品GMP证书》。
