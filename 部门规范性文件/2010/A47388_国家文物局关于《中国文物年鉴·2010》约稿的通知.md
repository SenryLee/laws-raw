# 国家文物局关于《中国文物年鉴·2010》约稿的通知

## 国家文物局关于《中国文物年鉴·2010》约稿的通知（办政函[2010]369号）

各省、自治区、直辖市文物局（文化厅、文管会），国家文物局机关各部门、各直属单位：

《中国文物年鉴·2010》由国家文物局组织编委会，中国文物信息咨询中心承担具体组稿及编辑出版工作，反映2009年度全国文物博物馆事业的发展状况。

为保证《中国文物年鉴·2010》征稿顺利，按时出版，现通知如下：

**一、**请确定本省、自治区、直辖市的《中国文物年鉴·2010》编辑负责人，于2010年6月30日前向中国文物信息咨询中心年鉴编辑部报送负责人姓名及联系方式。

**二、**请按照“《中国文物年鉴·2010》内容要求及注意事项”（见附件）组织撰写和编辑稿件。

**三、**请于2010年8月30日前将稿件电子版发送到年鉴专用电子信箱：nianjian@sach.gov.cn，稿件电子版前面请注明稿件作者姓名、电话、电子信箱地址、身份证号等相关信息。

附件：

《中国文物年鉴·2010》内容要求及注意事项

国家文物局机关各部门、直属单位、故宫博物院、中国国家博物馆、中国古迹遗址保护协会稿件内容要求（3000字以上）：

叙述2009年度的工作，标题简单明了，内容重点突出，详略得当。

各省、自治区、直辖市稿件内容要求：

**一、**不可移动文物

（一）不可移动文物保护

1、简述

2、文物保护单位

--各级文物保护单位的数量、名称（国家级、省级、市县级，分别按类别--古遗址、古墓葬、古建筑、石窟寺及石刻、近现代重要史迹及代表性建筑、其他六类统计，下同）

--本年度新公布文物保护单位的数量、名称（省级、市县级，分别按类别统计）

--其他不可移动文物数量（未公布级别的）

--第三次全国文物普查新发现文物数量、名称（总数、类别）

3、文物保护规划

--本年度新公布全国重点文物保护单位保护规划的数量及名称

4、文物保护工程

--本年度文物保护工程的数量、名称及投入经费

--本年度全国重点文物保护单位保护工程的数量、名称及投入经费

5、大遗址保护

--大遗址数量、名称

--大遗址保护工作情况（采取措施、投入经费、取得效果等）

（二）考古发掘

1、简述

2、本年度重大考古新发现

3、本年度考古发掘项目的数量、名称、进度情况（发掘面积、出土重要文物、重要意义等）

4、本年度出版考古发掘报告的数量、名称、印数

5、本年度考古发掘项目的获奖情况

（三）世界文化遗产（包括文化遗产、文化与自然双遗产）

1、简述

2、本年度世界文化遗产的保护和管理情况（会议、活动、项目等）

3、本年度世界文化遗产监测巡视情况

**二、**可移动文物

（一）博物馆

1、简述

2、国有文物系统博物馆数量（总数、分类别），其中本年度新增数量、名称；免费开放博物馆数量及名称

3、国有非文物系统博物馆数量，其中本年度新增数量、名称

4、非国有文物系统博物馆数量（总数、分类别），其中本年度新增数量、名称

5、藏品数量（总数、珍贵文物数量、一级文物数量，按单位性质分，按隶属关系分）

6、本年度接收、征集、修复藏品数量（总数、珍贵文物数量、一级文物数量，按单位性质分，按隶属关系分）

7、博物馆陈列展览数量（总数，按单位性质分，按隶属关系分），其中上年延续陈列展览数量、本年度新举办陈列展览数量；博物馆陈列展览投入经费

8、博物馆陈列展览获奖情况

博物馆参观人数（总人数、青少年观众、外国观众、团体观众）

博物馆门票收入、其他收入

（二）民间收藏文物

1、简述

2、文物拍卖企业数量，其中本年度新增数量；具有一、二、三类文物拍卖资质的企业数量

3、本年度审核文物拍卖活动场次、拍卖标的数量，其中禁止上拍的文物数量；本年度文物拍卖成交总额

4、文物商店的数量，其中本年度新增数量；文物库存数量（总数、一级文物），其中本年度新增数量

5、本年度审核文物商店销售文物的数量，销售金额

（三）文物进境出境

1、简述

2、文物进境数量

3、文物出境审核数量（总数、出境数量、进境复出境数量），其中不准出境的文物数量

（四）文物保护科技与科研

1、简述

2、国家级、省级文物保护科研基地的数量、名称

3、本年度重大文物保护科技项目的数量、名称

4、本年度文物科研论文及资料整理完成情况（总数、专著数量、图录数量、论文数量，按性质分--考古研究、古建研究、其他研究）

（五）文博信息化

1、简述

2、省级文物信息中心建设情况（机房面积、专业人员、内外网络、存储设备、安全设施、经费投入等）

3、本年度重大文博信息化建设项目（第三次文物普查、文物调查及数据库管理系统建设、长城资源调查等）进度

4、文物数据资源总量、类别，其中本年度新增数量

5、信息技术应用情况

6、文物信息化管理软件、系统开发及应用情况

**三、**政策法规与宣传

1、简述

2、本年度新出台文物保护规章、规范性文件数量、名称（并附全文）

3、本年度文物保护宣传情况（事件、活动、材料等）

**四、**安全督察

1、简述

2、本年度文物安全情况

3、本年度重大文物案件及处理情况

**五、**机构与人员

1、简述

2、机构数量（总数，分类别--文物保护管理机构、博物馆、文物商店、文物科研机构、其他文物机构，分隶属关系--中央、省、市、县），收支情况，其中本年度新增数量

3、人员数量（总数，学历--大专以下、大专、大学本科、硕士、博士，职称-初级、中级、副高、正高，按单位性质分，按隶属关系分），其中本年度新增数量

4、本年度举办培训数量、名称、培训学员人数（总数、分批次）

5、取得文物保护工程勘察设计资质的单位的数量（总数，甲级、乙级、丙级、暂定级）、名称，取得文物保护工程勘察设计职业资格的人员的数量、姓名；其中本年度新增的数量、名称（姓名）

6、取得文物保护工程施工资质的单位的数量（总数，一级、二级、三级、暂定级）、名称，取得文物保护工程施工职业资格的人员（项目负责人、技术负责人、工种人员）的数量、姓名；其中本年度新增的数量、名称（姓名）

7、取得文物保护工程监理资质的单位的数量（总数，甲级、乙级、丙级、暂定级）、名称，取得文物保护工程监理职业资格的人员（监理工程师、监理员）的数量、姓名；其中本年度新增的数量、名称（姓名）

8、取得考古发掘资质的单位数量、名称；其中本年度新增的数量、名称

9、取得考古发掘领队资格的人员数量、姓名；其中本年度新增的数量、姓名

10、取得文物拍卖专业人员资格的人员数量、姓名

11、取得可移动文物修复资质单位的数量、名称（总数、分类）

12、取得文物进出境审核鉴定员资格的人员数量、姓名；其中本年度新增的数量、姓名

13、安全保卫人员数量（按单位性质分，按隶属关系分），其中在编人员数量

14、表彰情况（文物工作先进县、先进单位、先进个人等）

**六、**对外交流

1、简述

2、文物出境展览项目数量、名称；外展文物（总数、一级品）数量、名称

3、文物进境展览项目数量、名称；展览文物数量、名称

4、团组出境、进境交流情况

**七、**填报相关表格（由于表格较多，将以电子邮件的形式单独发放，请认真填写并提交编辑部）

1、文物保护工程统计表（国保）（共2表）

2、文化遗产行业信息化发展综合情况表（共3表）

3、文物保护科学研究综合情况表（共11表）

**八、**注意事项

为规范《中国文物年鉴?2010》的内容、格式，减少不必要的错误，提高年鉴编辑效率，提请各位撰稿人注意：

1、主题或板块用黑体四号字，并用粗括号括起，如【物质文化遗产资源】；

2、内容根据主题或板块来进行组织，每个主题或板块下面，按时间顺序叙述，使用仿宋四号字，单倍行距；

3、内容要尽可能全面，内容中涉及的数据、日期要客观、翔实、准确，注意说明数据统计的来源和统计截止年月日，避免使用套话、非客观评述或口语化，避免使用不确切的、容易造成误解的简称；

4、图片要求每个供稿单位提供4-6张，JPG格式（1M以上），另放另发，不放置在文章中，图片要编号，并附一个文档文件，介绍图片内容；

5、事件主角要明确，不能缺失或上下不统一。

6、使用规范用语和符号，如下表所示：

|  |  |
| --- | --- |
| 不规范用语和符号 | 规范用语和符号 |
| 我局、我所、我馆 | 用局、所、馆的全称如“江苏省文物局” |
| 目前，迄今为止 | 截至某年某月某日止 |
| 今年、去年 | 2009年、2008年 |
| 1月2日-3月5日 | 1月2日～3月5日 |
| 第1-6批国保单位 | 第一至第六批国保单位 |
| 某地-某地高速公路 | “某地”不能简写，必须写全称 |
| 30件套 | 30件（套） |
