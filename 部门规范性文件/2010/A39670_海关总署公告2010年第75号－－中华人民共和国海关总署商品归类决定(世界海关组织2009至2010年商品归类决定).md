## 海关总署公告（2010年第75号）

为便于进出口货物的收发货人、经营单位及其代理人正确确定进出口货物的商品归类，保证《商品名称及编码协调制度公约》顺利执行，根据《协调制度公约》的有关规定及世界海关组织（WCO）的要求，海关总署现公布《中华人民共和国海关总署商品归类决定（世界海关组织2009至2010年商品归类决定）》（详见附件）。

商品归类决定自本公告发布之日起执行。

特此公告。

| 商 　　品 　　描 　　述 | 附一个无线游戏控制器，一个控制蓝光/DVD/CD光驱的无线遥控器，一个记忆卡适配器，一根电源线，一根连接游戏机与音频/视频设备的电缆，一根USB电缆和一根网线。游戏机的组成部件如下：  -1个中央处理器单元（CPU）  -256MB主内存（RAM）  -256MB显示内存（VRAM）  -1个2.5英寸的60GB硬盘  -1个蓝光/DVD/CD光盘驱动器（只读）  -1个图像控制器  -4个USB端口  -1个记忆棒插槽  -1个SD卡插槽  -1个CF卡插槽  -1个以太网连接器  -1个HDMI端口  -1个AV多媒体（AV Multi）输出端口  -1个数字音频输出（可选）端口  该设备采用以太网（10BASE-T，100BASE-TX，1000BASE-T）、WIFI（IEEE 802.11b/g）和蓝牙（Bluetooth 2.0）协议连接。除无线遥控器之外，多种设备都可与游戏机连接，例如USB或无线鼠标和键盘、电视信号接收器及显示器。  该设备有以下功能：  1.　　　运行视频游戏专用软件；  2.　　　将蓝光光盘、DVD盘或者CD盘的数据转成供电视信号接收器或音频系统可识别的视频/音频信号；  3.　　　采用Linux或其他操作系统；  4.　　　运行基于Linux的终端的应用程序，包括电子邮件、文字处理系统、网络浏览器以及图像浏览器；  5.　　　无线游戏遥控器上有几个控制按键，主要用于操作视频游戏。 | | | | |
