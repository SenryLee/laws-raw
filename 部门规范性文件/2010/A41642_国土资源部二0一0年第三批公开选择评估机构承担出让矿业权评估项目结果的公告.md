# 国土资源部二0一0年第三批公开选择评估机构承担出让矿业权评估项目结果的公告

2010年10月18日，国土资源部储量司在部油气中心107会议室（国土资源报社1楼）举办了公开选择评估机构现场会。部办公厅和矿业权评估机构均派人到会监督观摩全过程。

为保证公平、公正，在现场首先将报名合格的评估机构随机排序，然后进行计算机摇号，现将摇号的结果予以公告。
