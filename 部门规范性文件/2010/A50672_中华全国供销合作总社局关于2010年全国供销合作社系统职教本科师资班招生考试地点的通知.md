# 中华全国供销合作总社局关于2010年全国供销合作社系统职教本科师资班招生考试地点的通知

## 中华全国供销合作总社局关于2010年全国供销合作社系统职教本科师资班招生考试地点的通知（供销科教字[2010]4号）

各省、自治区、直辖市供销合作社，山西财经大学、安徽财经大学、山西大学商务学院：

根据全国供销合作总社科技教育部和教育部高校学生司联合印发的《关于做好2010年全国供销合作社系统职教本科师资班招生工作的通知》（供销科教字[2009]27号）精神，2010年全国供销合作社系统职教本科师资班招生考试于5月15日至17日在北京京铁大酒店进行，现将有关事项通知如下：

**一、**考生报到：考生于2010年5月14日下午3：00至6：00在京铁大酒店（北京西站南广场东侧）大堂报到，报到时领取《准考证》、抽取《面试号》，同时缴纳考试费300元。

**二、**考试地点、时间：笔试地点在京铁大酒店2层大会议室，面试地点待考生报到时另行通知。

|  |  |  |  |
| --- | --- | --- | --- |
| 时　 间 | 5月15日 | 5月 16日 | 5月17日 |
| 上午9：00---11：00 | 语文 | 外语 | 面试 |
| 下午 2：30---4：30 | 数学 | 面试 | 面试 |

**三、**招生院校负责人与考生见面会时间、地点：5月15日8：20在京铁大酒店2层大会议室（笔试考场）召开招生院校负责人与考生见面会。参加人员：全体考生、带队老师及相关人员等。

**四、**考生注意事项：考生必须携带《身份证》、《学生证》和《准考证》提前十五分钟进入考场。

**五、**考生住宿安排：

1、京铁大酒店为考试点，地点：北京西站南广场，每天200元/2人标准间（天井房180元），京铁大酒店房间预订电话：010-63955511转前台；

2、瑞尔威连锁饭店为备用住宿点（离考试点步行约十分钟），地点：北京西站北广场东附楼，每天200元/2人标准间（含早餐、免费宽带），瑞尔威连锁饭店房间预订电话：010-63959988-8073，13701296635（刘经理）。

考生凭本《通知》复印件或下载件自行登记入住享受此优惠价格，费用自理。

**六、**京铁大酒店乘车路线：

1、北京西站下火车后从南出站口出站左拐进京铁大酒店；

2、北京站下火车后乘122路公共汽车至北京西站南广场下车到达京铁大酒店；

3、北京南站下火车后乘72路公共汽车至北京西站南广场下车到达京铁大酒店

4、首都机场乘机场巴士（首都机场-西客站）16元到终点站北京西站南广场中盐饭店下车至京铁大酒店。

5、入住瑞尔威连锁饭店的考生从北京西站北广场①出站口穿过地下通道到南广场出口左拐至京铁大酒店（步行约10分钟）。

请各省级供销合作社教育主管部门及时将本《通知》（下载地址：www.chinacoop.com教育培训栏目）告知考生所在学校。
