# 教育部办公厅、农业部办公厅关于联合举行首届全国“农校对接”洽谈会的通知

## 教育部办公厅、农业部办公厅关于联合举行首届全国“农校对接”洽谈会的通知(教发厅函[2010]30号)

各省、自治区、直辖市教育厅（教委）、农业厅（局、委、办）：　

为贯彻落实《中共中央国务院关于加大统筹城乡发展力度 进一步夯实农业农村发展基础的若干意见》（中发〔2010〕1号）中提出的关于“发展农业会展经济，支持农产品营销。全面推进双百市场工程和农超对接，重点扶持农产品生产基地与大型连锁超市、学校及大企业等产销对接，减少流通环节，降低流通成本”的要求，把“农校对接”工作引向深入，为有关各方搭建供需见面、透明度高、选择性大，具有集约化联采形式的对接平台，经研究，决定由教育部发展规划司、农业部农村经济体制与经营管理司主办，中国高等教育学会后勤管理分会承办，天津市宁河县人民政府协办，共同举行首届全国“农校对接”洽谈会。现将有关事项通知如下：

一、会议内容

1．开幕式：领导讲话、宣布开幕。

2．参展洽谈：各地学校后勤行业组织、高等学校主管领导和相关后勤领导与各地农民专业合作社、大型连锁商业企业、冷链物流企业相互了解情况，洽谈采购或合作意向。

3．论坛：洽谈会期间召开有政府部门、有关行业组织和特邀企业参加的“农校对接”论坛（论坛题目见附件）。

二、参会人员

1．各省、自治区、直辖市教育厅（教委），部分省、自治区、直辖市农业厅（局、委、办）主管领导；

2．各地学校后勤行业组织领导；

3．各高等学校主管领导和相关后勤领导；

4．各地农民专业合作社、大型连锁商业企业、冷链物流企业。

三、会议地点和时间

地点：天津滨海国际会展中心（地址：天津经济技术开发区第五大街）

时间：2010年7月7日－9日

望各有关方面充分重视并积极参与此次会议，周密做好相关准备工作，并将参会人员名单于2010年6月25日前报会务组（010-62513736 62511857 62510297传真：62510987）。

附件：

首届全国“农校对接”洽谈会方案

【会议定位】高起点、集约化、品牌化、专业化的交易盛会

【主办单位】教育部发展规划司、农业部农村经济体制与经营管理司

【承办单位】中国高等教育学会后勤管理分会

【协办单位】天津市宁河县人民政府

【会议地点】天津滨海国际会展中心

【会议时间】2010年7月7日－9日

【报名截止时间】2010年6月25日

【会议规模】

1．展馆面积约40000平方米，标准展位数量约1800个。

2．组团采购数量：千余所高校洽谈订购，米面油肉蛋禽副食蔬菜等物资订单约100亿人民币。

【会议组织】

教育行政部门、学校后勤行业组织负责组织当地高校和食堂经营企业，针对学校食堂2010年下半年米面油肉蛋禽副食蔬菜等物资需求的品种和数量，准备订单，参加“农校对接”洽谈。

七个试点地区的农业主管部门负责组织当地四十家大型农民专业合作社，准备所能提供的米、面、油、肉、蛋、禽、蔬菜等农产品品种、数量、时令价格、运输方式等宣传材料，参加“农校对接”洽谈。承办单位对参会各农民专业合作社提供免费展台和一人两天免费食宿。

【论坛主题】

1．立足学校食堂特点，借鉴“农超对接”经验，开展“农校对接”工作。

2．充分发挥相关行业组织、电子商务信息交易平台在“农校对接”工作中的作用。

3．建立适合“农校对接”要求的物流配送体系和可追溯源头的鲜活农产品质量安全体系。

4. 学校食堂专业化、集约化发展现状及展望。

5.“农校对接” 在国家产业结构调整及转变经济发展方式中的作用。

6．“农校对接” 与建立“冷链物流体系”的联动效应。

7．“农校对接”对中国农副产品走向国际市场的作用。

8． 金融体系在“农校对接”中的作用。
