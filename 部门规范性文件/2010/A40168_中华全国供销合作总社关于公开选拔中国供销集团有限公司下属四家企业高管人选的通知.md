# 中华全国供销合作总社关于公开选拔中国供销集团有限公司下属四家企业高管人选的通知

## 中华全国供销合作总社关于公开选拔中国供销集团有限公司下属四家企业高管人选的通知（供销企字〔2010〕65号）

各省、自治区、直辖市及计划单列市、新疆生产建设兵团供销合作社，总社各部局、中国供销集团有限公司及其成员企业、各直属事业单位、各主管社团：

为切实推进企业改革和发展，深化企业人事制度改革，进一步拓宽选人用人范围，经研究，决定面向全国供销合作社系统公开选拔中国供销集团有限公司（以下简称中国供销集团）下属海南果蔬食品配送有限公司（以下简称海南果蔬）董事长和总经理人选，中再资源再生开发有限公司（以下简称中再资源）副总经理人选，新合作商贸连锁集团有限公司（以下简称新合作）副总经理人选，中国供销农产品批发市场控股有限公司（以下简称农发公司）副总经理人选。现将实施方案予以印发。

上述四家企业是中国供销集团所属企业，其中，海南果蔬是海南省首家获得输入美国水产品HACCP验证和欧盟注册的水产加工龙头企业，年加工水产品原料总量为2万吨，深加工8000吨，2009年销售收入7000万元；中再资源是我国最大的专业性再生资源回收加工企业，回收加工网点近2000个，年回收加工再生资源能力达400万吨，2009年销售收入106亿元；新合作是全国日用消费品经营龙头企业，拥有县及县级以下加盟网点8万多个，总营业面积近600万平方米， 2009年销售收入300亿元；农发公司于2009年9月成立，主要业务是改造、建设农副产品批发市场，发展农副产品精加工，组织全国名优农产品常年的展示和交易。希望各地供销合作社和有关单位要切实重视这次公开选拔工作，认真做好宣传和组织动员，鼓励本单位符合条件的干部积极报名参加选拔。

四家企业的基本情况可登录企业网站（海南果蔬网址：http：//www.hnseafood.com；中再资源网址：http：//www.zgzszy.com；新合作网址：http：//www.ncschina.com；农发公司网址：http：//www.chinaapm.com）查阅。

关于公开选拔四家企业

高管人选工作的实施方案

为切实推进企业改革和发展，深化企业人事制度改革，根据工作需要，决定面向全国供销合作社系统公开选拔中国供销集团下属海南果蔬食品配送有限公司（以下简称海南果蔬）董事长和总经理人选、中再资源再生开发有限公司（以下简称中再资源）副总经理人选、新合作商贸连锁集团有限公司（以下简称新合作）副总经理人选、中国供销农产品批发市场控股有限公司（以下简称农发公司）副总经理人选，根据有关规定，结合中国供销集团出资企业实际，制定本实施方案。

**一、**指导思想

为加快提升中国供销集团下属海南果蔬、中再资源、新合作、农发公司四家企业市场竞争力和龙头带动作用，本着拓宽选人范围、扩大用人视野，不断深化社有企业人事制度改革的思路，按照民主、公开、竞争、择优的原则，选拔具有改革创新精神，业绩突出，善经营、会管理、年富力强的优秀人才。

**二、**报考条件

1、拥护党的路线、方针和政策，政治素质好。遵规守法，品行端正，诚信廉洁，勤奋敬业，团结合作，作风严谨，有强烈的事业心、责任感和开拓创新精神，有良好的职业素养。

2、熟悉现代企业经营管理，具有较强的决策能力、经营管理能力、市场应变能力和组织协调能力，业绩突出。

3、系统报考者一般应具有在大、中型企业班子成员岗位任职一年以上的经历，所在企业年销售收入2亿元以上或净资产总额3000万以上或年利润总额500万以上。总社直属企业中层正职以上管理人员，总社机关正处以上干部，直属事业单位、主管社团班子成员。

4、具有大学本科以上学历，身体健康，年龄在45岁左右。

此外，熟悉水产加工及出口业务，了解再生资源产业政策，熟悉连锁零售企业的运行模式和管理方式，有连锁零售行业10年以上及大型连锁零售企业高管职务5年以上从业经历，具有丰富的农产品流通运作实践经验，熟悉投融资业务的相关岗位报考人员优先考虑。

**三、**选拔方式

凡供销合作社系统内符合规定条件者可自愿报名。经资格审查后，按考生与岗位比例不低于8︰1组织笔试；每个岗位按笔试成绩自高分到低分按5︰1进入面试；面试结束后，参加面试的人员到报考企业进行公开演讲，笔试、面试和公开演讲成绩分别占总成绩的40%、50%和10%；根据总成绩，按3︰1进入组织考察；根据考试和考察情况，综合比较，最后按规定由组织研究确定被聘人选。

**四、**具体步骤

（一）制定实施方案。

（二）信息发布。面向系统印发通知，并在中国供销合作网、中国供销集团网站和中华合作时报发布公告。

（三）组织报名。报名时须提供以下材料：

1、报名表（总社直属单位由本单位加盖公章、系统各单位由本单位和上级供销合作社人事部门加盖公章）；

2、个人身份证复印件（验原件）；

3、学历、学位证书复印件（验原件）；

4、近期彩色照片2张（2寸照）。

（四）资格审查。领导小组办公室对报名材料进行审查，经审查符合条件的人员参加考试。

（五）笔试。重点考察考生企业经营管理的综合素质和能力水平。

（六）面试。采取半结构化面试方式进行，即报考者根据报考岗位先进行竞职陈述，之后主考官按专家命题提问，最后考官自由提问。面试时间每人1小时。采取体操计分法。组成9人考官组，考官名单由领导小组审定。

（七）公开演讲。面试结束后，参加面试的考生，按报考岗位分别在四家企业员工大会上进行竞职演讲，由参会员工现场打分。采取体操计分法（根据参会员工人数，去掉不同的最高分和最低分）。

（八）组织考察。组成若干考察组，分赴候选人单位进行全面考察。

（九）确定人选。根据考试成绩和考察情况，由领导小组进行比较研究，提出建议人选，经组织集体讨论后确定被聘人选。

（十）正式聘用。组织体检和公示之后，按程序推荐和聘用。实行一年试用期，试用期满后进行考核，考核合格者继续聘任，不合格者解除聘任合同。

**五、**时间安排

工作时间大致安排2个月，具体为：

2010年11月22日-11月28日，前期准备阶段；

2010年11月29日-12月24日，动员和发布方案、组织报名、资格审查阶段（报名截至日期为2010年12月24日）；

2010年12月27日-2011年1月4日，笔试、面试阶段；

2011年1月5日-2011年1月17日，组织考察阶段；

2011年1月18日-1月28日，研究确定人选、体检、公示和正式聘用阶段。
