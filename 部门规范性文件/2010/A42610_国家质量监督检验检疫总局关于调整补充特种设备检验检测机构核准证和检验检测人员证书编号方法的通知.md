# 国家质量监督检验检疫总局关于调整补充特种设备检验检测机构核准证和检验检测人员证书编号方法的通知

## 国家质量监督检验检疫总局关于调整补充特种设备检验检测机构核准证和检验检测人员证书编号方法的通知（质检特函〔2010〕53号）

各省、自治区、直辖市质量技术监督局：

根据《关于实施特种设备行政许可调整改革工作有关问题的通知》（国质检特[2009]478号）的规定和工作要求，为统一和规范《特种设备检验检测机构核准证》和《特种设备检验检测人员证书》的编号，我局对原编号方法进行了调整和补充，现予以公布。

本通知发布之日起，《关于调整特种设备检验检机构核准证和检验检测人员证编号方法的通知》（质检特设函[2004]2号）同时废止。

附件：特种设备检验检测机构核准证和检验检测人员证书编号方法

二〇一〇年九月二十一日

附件：

特种设备检验检测机构核准证和特种设备

检验检测人员证书编号方法

**一、**特种设备检验检测机构核准证编号方法

（一）基本格式

×××　×　××　×××－××××

×××　证书项目代号

×　 机构类型代号

××　地区代码

×××　顺序号

－××××　有效期年份

共14位，包括“－”。

（二）代号含义

（1）证书项目代号

由两个字母和一个数字表示为TS7。

（2）机构类型代号

由一个数字表示

|  |  |
| --- | --- |
| 机构类型 | 代号 |
| 质检系统检验机构 | 1 |
| 企业自检机构 | 2 |
| 行业检验机构 | 5 |
| 无损检测机构 | 3 |
| 气瓶检验机构 | 4 |
| 型式试验机构 | 6 |
| 水质检验机构 | 7 |
| 安全阀校验机构 | 8 |

（3）地区代码

由两位数字表示，是审批发证机关所在地的省级区域的行政区划代码。国家质检总局审批颁发的核准证编号中的地区代码，境内机构用10表示、境外机构用00表示。

省级行政区划代码采用GB/T2260-1999《中华人民共和国行政区划代码》中规定的代码的前两位 （见附录）。

（4） 顺序号

由三位数字表示。按审批发证机关所审批的该类型机构的顺序编号。如果超过999，则用字母与数字混合表示。如顺序号为1020，则表示为A20；顺序号为1120，则表示为B20；依次类推。

（三）举例

如：经国家质检总局审批发证的境内质检系统检验机构，总排列顺序为100，许可证有效期至2012年。

表示为：TS7110100－2012

如：经国家质检总局审批发证的境内企业自检机构，总排列顺序为10，许可证有效期至2013年。

表示为：TS7210010－2013

如：经国家质检总局审批发证的境内行业检验机构，总排列顺序为810，许可证有效期至2013年。

表示为：TS7510810－2013

如：经国家质检总局审批发证的境外型式试验机构，总排列顺序为99，许可证有效期至2014年。

表示为：TS7600099－2014

如：经国家质检总局审批发证的境内无损检测机构，总排列顺序为1001，许可证有效期至2014年。

表示为：TS7310A01－2014

如：经辽宁省质量技术监督局审批发证的气瓶检验机构，总排列顺序为1101，许可证有效期至2015年。

表示为：TS7421B01－2015

如：经浙江省质量技术监督局审批发证的安全阀校验机构，总排列顺序为101，许可证有效期至2015年。

表示为：TS7833101－2015

**二、**特种设备检验检测人员证书编号方法

特种设备检验检测人员证书编号按照获证人员身份证件号码填写。
