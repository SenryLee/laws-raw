前言

本标准由人力资源社会保障部劳动监察局提出。

本标准由人力资源社会保障部信息中心归口。

本标准起草单位：人力资源社会保障部信息中心、人力资源社会保障部劳动监察局。

本标准主要起草人：尚建华、翟燕立、赵森、杨春明、崔尧、汪诚。

引言

为建立统一的劳动保障监察信息标准，规范全国劳动保障监察管理信息系统建设，支持各级劳动保障监察机构的信息共享和信息交换，制定《劳动保障监察管理信息系统基础指标集与代码》标准，并作为全国劳动保障监察信息化管理、应用软件开发和信息资源共享的基础信息规范。

该标准是人力资源社会保障管理信息系统指标体系的组成部分，是劳动保障监察管理信息系统指标体系的核心内容。

劳动保障监察管理信息系统基础指标集与代码

## 1　范围

本标准规定了全国人力资源社会保障部门在劳动保障监察管理信息系统建设时所使用的基础指标集，及其指标类型、指标长度和计量单位等。

本标准适用于地市级以上人力资源社会保障部门劳动保障监察管理信息系统的数据处理、交换和共享。

## 3　术语和定义

下列术语和定义适用于本文件。

**3.**1

劳动保障监察　labor and social security inspection

人力资源和社会保障行政机关依法对用人单位遵守劳动保障法律法规的情况进行监督检查，发现和纠正违法行为，并对违法行为依法进行行政处理或行政处罚的行政执法活动。

**3.**2

劳动保障监察机构　 labor and social security inspection institution

由县级以上各级人民政府人力资源和社会保障行政部门建立，负责具体实施劳动保障监察工作的机构。

**3.**3

劳动保障监察员　labor and social security inspector

县级以上各级人民政府人力资源和社会保障行政部门执行劳动保障监督检查公务的人员。劳动保障监察员包括专职监察员和兼职监察员。

**3.**4

用人单位　 employing unit

具有用人权利能力和用人行为能力，运用劳动力组织生产劳动，且向劳动者支付工资等劳动报酬的单位，包括企业和个体工商户、国家机关、事业单位、社会团体、职业中介机构、职业技能培训机构和职业技能考核鉴定机构、无营业执照或者已被依法吊销营业执照且有劳动用工行为的组织或个人。

**3.**5

劳动保障监察网格　　labor and social security inspection grid

各级劳动保障监察机构根据管辖规定，按照管辖区域内用人单位的数量和监管难度，以街道（乡镇）或社区为基础划分的若干管理网格。

## 4　指标编码结构

指标代码采用层次编码法，由字母和数字混合构成，共六位，前三位从左至右依次表示指标的定义级别、业务类别、信息主体类型或政策参数，后三位为顺序号，结构如下：

a）定义级别：描述定义该指标的单位级别，即人力资源社会保障部门的行政级别，用1个大写英文字母表示。指标的定义级别，见表1。

表1　指标定义级别

|  |  |  |
| --- | --- | --- |
| 指标级别 | 含义 | 说明 |
| A | 部级 | 本标准所有指标均为部级 |
| B | 省级 | 由省级人力资源社会保障部门定义的指标 |
| C | 市级 | 由地市级人力资源社会保障部门定义的指标 |
| D | 县级 | 由县级人力资源社会保障部门定义的指标 |

b）业务类别：描述该指标所属的业务类别，用1个大写英文字母表示。指标的业务类别，见表2。

表2　业务类别

|  |  |  |
| --- | --- | --- |
| 业务类别 | 含义 | 说明 |
| A | 综合类 | 两项以上业务共用的指标 |
| B | 法制及劳动关系类 | 人力资源和社会保障立法、行政诉讼、行政复议等领域的指标，以及劳动合同、劳动保障监察、劳动人事争议调解仲裁等领域的指标 |
| Z | 其他 | 不能纳入以上各项业务分类之中的指标 |

c）信息主体类型：描述该指标所述的信息主体类型或政策参数，用1个大写英文字母表示。指标的信息主体类型，见表3。

表3　信息主体

|  |  |  |
| --- | --- | --- |
| 信息主体 | 含义 | 说明 |
| A | 政策参数 | 政策文件中有关参数的指标 |
| B | 单位 | 反映用人单位、参保单位（含学校、家庭、人力资源社会保障事务代理机构）基本属性、人力资源和社会保障业务属性的指标 |
| C | 个人 | 反映劳动者、居民、参保人员基本属性及其人力资源社会保障业务属性的指标（含人力资源社会保障部门工作人员基本属性指标） |
| E | 辅助性主体 | 为实现业务而建立的多项业务共用的辅助性指标 |
| F | 机构 | 反映提供人力资源社会保障管理服务职能的组织或团体的指标，以及反映组织或团体工作人员特有的业务属性指标（如仲裁员证号、劳动保障监察证号等）。组织或团体指人力资源社会保障系统内各类行政管理机构、经办机构、服务机构，以及提供人力资源社会保障相关服务的社会服务机构，如银行、邮局、地税、医院、药店等 |
| Z | 其他主体 | 不在以上范围内的主体 |

d）顺序号：3个阿拉伯数字，取值范围为001～999。顺序号可分段使用；停用的指标，其原用顺序号不再使用；停用后又恢复使用的指标，仍使用原顺序号。顺序号确需超过999时，可从百位到个位逐步扩充使用大写英文字母A-Z，不使用字母O、字母I和字母L。
