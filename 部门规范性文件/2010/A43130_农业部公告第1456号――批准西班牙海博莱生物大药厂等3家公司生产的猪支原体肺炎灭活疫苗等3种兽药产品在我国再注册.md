# 农业部公告第1456号――批准西班牙海博莱生物大药厂等3家公司生产的猪支原体肺炎灭活疫苗等3种兽药产品在我国再注册

## 农业部公告（第1456号）

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准西班牙海博莱生物大药厂等3家公司生产的猪支原体肺炎灭活疫苗等3种兽药产品在我国再注册，现核发《进口兽药注册证书》，并发布修订后的产品质量标准、标签和说明书，自发布之日起执行。原我部发布的同品种兽药质量标准同时废止。

特此公告

二〇一〇年九月九日
