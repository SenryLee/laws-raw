# 农业部公告第1489号――批准上海高科联合生物技术研发有限公司等3家公司申报的重组溶葡萄球菌酶粉等3种兽药产品变更注册，并发布修订后的产品质量标准、标签和说明书

## 农业部公告（第1489号）

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准杨凌凯那英多克隆动物药业有限公司等15家单位申报的犬细小病毒免疫球蛋白注射液等6种兽药产品为新兽药，现核发《新兽药注册证书》，并发布产品试行规程、质量标准、标签和说明书，自发布之日起执行。

批准上海高科联合生物技术研发有限公司等3家公司申报的重组溶葡萄球菌酶粉等3种兽药产品变更注册，并发布修订后的产品质量标准、标签和说明书，自发布之日起执行。原我部发布的同品种兽药质量标准同时废止。

特此公告。

二〇一〇年十一月二十六日
