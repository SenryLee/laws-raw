# 农业部办公厅关于印发第16届广州亚运会国内参赛马匹检疫合格证明样式的通知

## 农业部办公厅关于印发第16届广州亚运会国内参赛马匹检疫合格证明样式的通知（农办医[2020]77号）

为进一步规范国内参加广州亚运会马术比赛马匹隔离期间的检疫监管工作，按照《动物防疫法》、《动物检疫管理办法》和《农业部办公厅关于加强广州亚运会国内参赛马匹检疫监督工作的通知》（农办医〔2010〕30号）等要求，我部制定了《第16届广州亚运会国内参赛马匹检疫合格证明》，现印发给你们。本检疫证明仅适用于第16届广州亚运会国内参赛马匹隔离检疫合格后使用，一畜一证，请认真贯彻执行。

| 马流行性  感冒 | 不同年龄马发病，发病快，发病率高，病死率低。有咳嗽、流鼻涕、发烧症状。羞明流泪，眼结膜潮红，充血水肿，颌下淋巴结肿胀。病马常表现肌肉震颤，肩部肌肉最明显，且马匹因肌肉酸痛而不爱活动。 | | | |  |

| 日本脑炎 | 初期体温高达39.5～41℃，可视粘膜潮红或轻度黄染，精神不振，食欲减退，肠音稀少而弱，粪少而干。不同类型表现不一：或呆立不动，低头耷耳，常出现异常姿势，后期卧地不起，或感觉消失；或狂躁不安，乱冲乱撞，后期因衰落而卧地不起，四肢呈游泳状；或沉郁和兴奋交替出现，嘴唇歪斜，眼球震颤，饮水障碍；或病初步行不稳，继而后肢不能站立而卧地。 | | | |  |
| 马脑脊髓炎 | 发热、厌食和精神萎靡，严重时出现狂燥不安、失明、共济失调、精神极度沉郁、卧地不起、痉挛等症状。 | | | |  |
| 马鼻疽 | 急性型常见体温升高，呈不规则热（39～41℃）和颌下淋巴结肿大等全身性变化。肺鼻疽主要表现为干咳，肺部可出现半浊音、浊音和不同程度的呼吸困难症状；鼻腔鼻疽可见一侧或两侧鼻孔流出浆液、黏液性脓性鼻汁，鼻腔黏膜上有小米粒至高粱米粒大的灰白色圆形结节突出黏膜表面；皮肤鼻疽常于四肢、胸侧和腹下发生局限性有热有痛的炎性肿胀并形成硬固的结节。 | | | |  |
| 马梨浆虫病 | 高稽留热，体温40-41℃，病畜精神沉郁，反应迟钝、肌肉振颤，重病者昏迷。粘膜轻度充血，渐变苍白，并有黄疸；呼吸急促，心悸亢进，节律不齐。病初粪便干硬，后转为腹泻，粪便多粘膜，甚至带血。尿频，量少，尿含蛋白，重症病例尿中含有血液。病马常因贫血，心力衰竭和呼吸困难而死亡。 | | | |  |
| 马传染性  贫血 | 急性型表现为高热稽留。可视黏膜潮红，轻度黄染；随病程发展逐渐变为黄白至苍白；在舌底、口腔、鼻腔、阴道黏膜及眼结膜等处，常见鲜红色至暗红色出血点。亚急性型呈间歇热。发热39℃以上，持续3～5天退热至常温，经3～15天间歇期又复发。慢性型表现为不规则发热，但发热时间短。 | | | |  |
| 马媾疫 | 公马包皮前端水肿，逐步蔓延到阴囊、包皮、腹下及股内侧。尿道黏膜潮红肿胀，尿道口外翻，排出少量混浊的黄色液体。母马阴唇肿胀，逐渐波及乳房、下腹部和腹内侧，阴道黏膜潮红、肿胀、外翻，常排出少量黏液一脓性分泌物，频频排尿，呈发情状态。病马屡配不孕，或妊娠后易流产。 | | | |  |
| 伊氏锥虫病 | 发热，有渐进性贫血、消瘦和乏力。体表淋巴结轻度肿胀。尿量减少，尿色深黄。 | | | |  |
| 尼帕病 | 发热、严重肌痛、脑脊膜炎。临床表现为急性呼吸道疾病，明显的神经系统疾病。 | | | |  |
| 亨德拉病 | 具有严重的呼吸困难和高死亡率，脸肿、大量的泡沫样鼻腔流出液，有些马呈神经症状。 | | | |  |
| 西尼罗河热 | 表现为病毒性脑炎或脑脊髓炎，发热，有些表现虚弱肌肉震颤和颅神经缺损。 | | | |  |
