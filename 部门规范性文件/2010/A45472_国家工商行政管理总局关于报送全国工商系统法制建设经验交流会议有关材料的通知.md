# 国家工商行政管理总局关于报送全国工商系统法制建设经验交流会议有关材料的通知

各省、自治区、直辖市工商行政管理局：

为了贯彻落实国务院即将召开的全国依法行政工作会议精神，加强工商行政管理机关法制建设，总局拟于今年九月召开全国工商系统法制建设经验交流会。会议将总结交流全国工商系统贯彻国务院《全面推进依法行政实施纲要》、加强法制建设的工作经验，表彰工商系统法制工作先进单位和先进个人，研究部署新形势下的工商法制工作。总局周伯华局长、付双建副局长将到会并作重要讲话。为了做好全国工商系统法制建设经验交流会的筹备工作，现请提供以下相关材料：

**一、**拟在全国工商系统表彰的法制工作先进集体、先进个人和行政复议工作先进集体、先进个人及法制宣传教育先进集体、先进个人名单（具体推荐要求见附件1）

**二、**地方工商行政管理相关立法情况（见附件2）

**三、**地方工商行政管理机关制度建设情况（见附件3）

**四、**地方工商行政管理机关法制队伍建设情况（见附件4）

以上材料请于2010年8月10日前报至国家工商行政管理总局法规司，并通过网络报送电子版。

附件1：

全国工商行政管理系统法制工作先进集体、先进个人和行政复议工作先进集体、

先进个人及法制宣传教育先进集体、先进个人的具体推荐要求

近年来，全国工商行政管理系统以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，充分发挥工商行政管理职能作用，为工商行政管理法制建设和经济社会的发展做出了重要贡献，涌现出了一大批先进集体和个人。为了总结经验，表彰先进，促进工作，国家工商行政管理总局决定在今年下半年召开全国工商系统法制建设经验交流会，拟表彰工商法制工作先进集体、先进个人和工商行政复议工作先进集体、先进个人及法制宣传教育先进集体、先进个人。具体推荐要求如下：

**一、**推荐范围及名额

（一）推荐范围

1. 全国工商行政管理系统法制工作先进集体的推荐范围是：市（地）、县级工商行政管理局（市场监督管理局）。

2. 全国工商行政管理系统法制工作先进个人的推荐范围是：地方各级工商行政管理机关从事法制工作3年以上的正式工作人员。

3. 全国工商行政管理系统行政复议工作先进集体的推荐范围是：县级以上地方各级工商行政管理机关法制机构。

4. 全国工商行政管理系统行政复议工作先进个人的推荐范围是：工商行政管理系统内从事行政复议工作满3年的正式工作人员。

5.2006-2010年全国工商行政管理系统法制宣传教育先进集体。参评对象为地（市）、县（市）级工商行政管理机关。

6.2006-2010年全国工商行政管理系统法制宣传教育先进个人。参评对象为工作事迹突出，工作成绩显著的工商行政管理法制宣传教育工作者。

（二）推荐名额

全国工商行政管理系统法制工作先进集体推荐名额为93名（省、自治区、直辖市各3名）、先进个人为124名（省、自治区、直辖市各4名）；全国工商行政管理系统行政复议工作先进集体推荐名额为31名（省、自治区、直辖市各1名）、先进个人为31名（省、自治区、直辖市各1名）；2006-2010年全国工商行政管理系统法制宣传教育先进集体推荐名额为62名（省、自治区、直辖市各2名）、先进个人为62名（省、自治区、直辖市各2名）。没有行政复议案件或者办理行政复议案数量少的单位不推荐全国工商行政管理系统行政复议工作先进集体和先进个人。

**二、**推荐条件

（一）全国工商行政管理系统法制工作先进集体的推荐条件是：

1. 坚持以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，认真执行党的路线、方针、政策，认真贯彻落实《全面推进依法行政实施纲要》，大力推进法制建设取得显著成绩。

2. 正确执行工商行政管理法律法规，努力做到监管与发展、监管与服务、监管与维权、监管与执法的统一，积极推进制度化、规范化、程序化、法治化建设，努力构建法制工作长效机制，在更新执法理念、健全执法机制、完善执法程序、规范执法行为、创新监管方式等方面，在建章立制、执法监督、复议应诉、法制宣传培训等工作中取得显著成效，得到当地政府的肯定和社会认可。

3. 重视工商法制建设。主要领导和分管领导定期听取法制机构工作汇报，专题研究法制工作，积极采纳法制机构建议。工商法制工作被纳入重要议事日程。

4. 认真抓好领导班子建设、党员队伍建设、和谐文明机关建设、基层工商所执法队伍建设和反腐倡廉建设，努力建设政治上过硬、业务上过硬、作风上过硬的干部队伍。近三年内未发生违法违纪案件。

5. 在依法治国、依法行政工作中有其他突出贡献的。

（二）全国工商行政管理系统法制工作先进个人的推荐条件是：

1. 认真学习邓小平理论和“三个代表”重要思想，深入贯彻落实科学发展观，认真执行党的路线、方针、政策，模范遵守国家的法律法规，忠于党、忠于祖国、忠于人民、忠于工商行政管理事业，全心全意为人民服务。

2. 热爱工商法制工作，有高度的事业心和责任感，忠于职守，勇于负责，依法行政，秉公执法，勤奋工作，无私奉献，工作成绩显著。

3. 业务素质过硬，刻苦钻研工商法制业务，熟悉并善于运用法律理论及法律知识解决实际问题，对工商工作指导作用显著。

4. 关心集体，团结同志，严于律己，清正廉洁，作风正派。

5. 在法制工作中有其他突出成绩的。

（三）全国工商行政管理系统行政复议工作先进集体的推荐条件是：

1．坚持以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，认真贯彻执行党的路线、方针、政策，善于运用法律手段解决行政争议，保护公民、法人或者其他组织合法权益，维护社会和谐稳定成效显著。

2．依法履行行政复议应诉职责，创新行政复议审理方式，积极运用调解、和解等手段有效化解行政争议，办理行政复议案件数量较多、质量高、效果好。

3．指导和推动行政复议应诉工作，促进依法行政效果明显。

4．领导班子团结协作，机构设置、人员配备符合相关规定。

5．办案制度完备，法律文书规范，案卷档案管理有序。

6. 在行政复议工作中有其他突出成绩的。

（四）全国工商行政管理系统行政复议工作先进个人的推荐条件是：

1．坚持以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，认真贯彻执行党的路线、方针、政策，在政治上、思想上和行动上自觉与党中央保持一致。

2．善于运用中国特色社会主义理论指导行政复议实践，政治素质高，作风过硬，清正廉洁，深受人民群众欢迎。

3．具备较高的专业素养和理论水平，行政复议案件办理质量高、数量多，经手办理的案件多数能够实现“案结事了”，制作的法律文书叙述清楚，逻辑严谨，论证充分，说理性强。

4.在行政复议工作中有其他突出成绩的。

（五）2006-2010年全国工商行政管理系统法制宣传教育先进集体评选条件是：

1．组织领导坚强有力。建立健全领导小组和办事机构。将法制宣传教育工作纳入工商行政管理工作重要议事日程，定期研究部署。

2．保障机制落实到位。普法经费列入年度财政预算，按时足额到位，做到专款专用。建立健全工商行政管理法制宣传教育工作监督检查和奖惩制度。

3．周密部署工作扎实。有“五五”普法规划，年度有工作计划，有部署，有检查，有总结。领导干部学法制度化，坚持依法决策、依法管理。充分调动工商行政管理系统干部学习法律知识的积极性，定期组织开展针对性强、形式多样的法制宣传教育活动。建立健全领导干部学法制度和单位内部各项工作制度，规范单位内部行为，把各项工作纳入法治化管理轨道。注意加强工商行政管理法制宣传教育阵地建设和队伍建设。

4．工作突出成效显著。工商行政管理系统干部的法律素质和单位内部的法治化管理水平明显提高，法制宣传教育工作在本地区、本系统处于领先水平。

（六）2006-2010年全国工商行政管理系统法制宣传教育先进个人评选条件是：

1．在 “五五”普法期间，能够以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，模范遵守和执行党的路线、方针、政策及国家的法律法规。

2．认真履行职责，积极参与组织、协调、检查、督促工商行政管理法制宣传教育工作，为提高工商行政管理干部法律素质、营造良好的执法环境作出突出成绩。

3．围绕工商行政管理系统的中心工作和群众关注的热点、难点问题，开展有针对性的工商行政管理法制宣传工作，充分发挥法制宣传教育工作在本地区、本系统的改革发展稳定中的职能作用。

4．工作扎实，勇于开拓创新，善于开展调查研究，积极运用理论指导实践。

在推荐工作中，各地工商行政管理机关要严格履行程序，坚持公开、公平、公正的原则；要坚持推荐条件，严格把关，确保推荐质量，切实做到好中选优；各地要对所推荐的先进集体和先进个人征求同级纪检监察部门意见并在当地进行公示；要高度重视此次推荐工作，并以此为契机，在系统大张旗鼓地树立典型、弘扬先进，努力营造争先创优的良好氛围，为打造一支优秀的工商行政管理队伍发挥积极作用。
