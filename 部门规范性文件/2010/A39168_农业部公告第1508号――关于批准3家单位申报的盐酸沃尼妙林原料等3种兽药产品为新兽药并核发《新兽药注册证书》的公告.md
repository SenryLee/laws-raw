# 农业部公告第1508号――关于批准3家单位申报的盐酸沃尼妙林原料等3种兽药产品为新兽药并核发《新兽药注册证书》的公告

## 农业部公告（第1508号）

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准浙江海正药业股份有限公司等3家单位申报的盐酸沃尼妙林原料等3种兽药产品为新兽药，现核发《新兽药注册证书》，并发布产品试行规程、质量标准、标签和说明书，自发布之日起执行。
