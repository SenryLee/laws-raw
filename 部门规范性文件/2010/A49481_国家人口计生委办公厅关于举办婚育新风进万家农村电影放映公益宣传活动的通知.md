# 国家人口计生委办公厅关于举办婚育新风进万家农村电影放映公益宣传活动的通知

（人口厅发〔2010〕29号）

山西省、浙江省、湖北省、湖南省、四川省人口计生委，广播电影电视局：

利用农村电影放映向全国广大农村地区宣传科学、文明、进步的婚育观念是一条十分有效的途径。将人口公益广告片和优秀国产故事片结合起来，深入到农村田间地头、乡镇广场放映，为农民群众送去婚育新风和电影文化，是科技、文化、卫生"三下乡"活动的好形式。为此，国家人口计生委、国家广电总局将联合举办婚育新风进万家农村电影放映公益宣传活动，现将具体事项通知如下：

**一、**活动组织

指导单位：国家人口计生委、国家广电总局。

主办单位：国家人口计生委宣传教育司、国家广电总局电影局

承办单位：中国人口宣传教育中心、中国电影集团公司、山西、浙江、湖北、湖南、四川省人口计生委、广播电影电视局。

**二、**活动安排

活动名称：婚育新风进万家全国农村电影放映公益宣传活动。

放映时间：2010年4月-7月。

放映形式：活动期间，在各地行政村内免费放映婚育新风进万家公益宣传片（约3分钟）及1部国产新故事片。

总场次：1万场，具体场次分配见附件。

**三、**首映式安排

（一）全国首映式安排。

1.时间：2010年4月26日

2.地点：山西省阳泉市盂县

3.首映式内容：

（1）国家人口计生委、国家广电总局、山西省领导讲话，农民观众代表发言。

（2）当地农村特色文艺表演、现场知识问答互动。

（3）婚育新风进万家公益片放映，国产新故事片放映。

（二）各省当地首映式安排。

1.时间：5月-7月。

2.首映式内容：参照全国首映式内容和形式，由各省人口计生委组织实施当地现场活动，当地农村电影院线公司配合公益专场放映活动。

**四、**活动要求

（一）鉴于该项活动涉及面广，参与人数多，组织工作量大，请各级人口计生委、广电行政管理部门高度重视、加强合作，精心组织，确保效果，协调当地基层单位，制定好具体实施方案，并做好安全保障工作。

（二）做好放映、监播及统计工作。各农村电影院线公司要严格按照放映要求，提供优质放映服务，规范、如实填写放映监播单并做好统计汇总工作。

（三）此次活动结束后，将对放映活动成果以图片展方式进行公开展示，请各有关单位将以下资料汇总上报：

1.各地放映活动总结报告，连同当地首映式照片5张，由省人口计生委报国家人口计生委宣传教育司。

2.各地农村放映现场照片：选择当地3-5个有代表性的行政村，每村提供放映现场照片2张，并将监播单、统计结果和照片由各农村电影院线公司汇总至中影新农村数字电影放映公司。
