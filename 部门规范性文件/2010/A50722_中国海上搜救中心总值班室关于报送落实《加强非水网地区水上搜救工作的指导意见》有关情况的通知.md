# 中国海上搜救中心总值班室关于报送落实《加强非水网地区水上搜救工作的指导意见》有关情况的通知

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）、海（水）上搜救中心，上海市交通运输和港口管理局，长江、珠江航务管理局：

为加强非水网地区水上搜救工作、提高非水网地区搜救应急保障能力，2009年交通运输部下发了《关于加强非水网地区水上搜救工作的指导意见》（交搜救发[2009]306号，以下简称《指导意见》）。一年来，非水网地区交通运输部门在加强水上搜救能力建设方面做了大量工作，并取得了明显成效。但各地落实《指导意见》的情况也不平衡，为进一步落实《指导意见》，推进非水网地区搜救能力建设。现就有关事项通知如下：

**一、**请各单位认真填写《非水网地区落实＜指导意见＞情况报送表》（以下简称《报送表》，见附件1，）具体填写内容依照《报送表》填写说明填写（见附件2）。

**二、**各单位将落实情况以书面及电子两种形式于4月12日前报中国海上搜救中心。（附件1，《报送表》可在交通运输部外网-中国海上搜救中心司局主页中下载）

**三、**中国海上搜救中心将在近期组织召开非水网地区搜救体系建设座谈会，对落实《指导意见》加强搜救体系建设进行交流。

附件2：

非水网地区落实“指导意见”情况报送表

填写说明

为提高非水网地区水上搜救工作，按照2009年交通运输部下发的《关于加强非水网地区水上搜救工作的指导意见》（交搜救发[2009]306号）的精神，请将非水网地区水上搜救工作进展情况按照《报送表》填写，具体说明如下：

**一、**水上搜救“一案三制”建设

1.水上搜救预案体系建设：本地区水上搜救工作预案编制修订情况。包括：省级预案、市级预案、航运企业预案及针对不同险情制定的分预案和各类险情的应急处置程序，请列出相关文件名称。

2.水上搜救体制建设：结合本地区实际特点填写水上搜救体制建设情况，包括水上搜救中心及各分中心的具体规划和进展情况。

3.水上搜救机制建设：填写本地区建立水上搜救联席会议机制，预测预警、信息报告、应急响应、善后处置等联动机制的建设情况。

4.水上搜救法制建设：请列出本地区制定的水上搜救相关法规和规章的文件名称或者进展情况。

**二、**水上搜救能力建设

1.编制水上搜救体系建设规划：请重点填写水上搜救监测预警系统、信息与应急指挥系统、应急队伍、通信保障能力、科技支撑能力和演练体系等建设规划的具体情况。

2.建设水上搜救应急平台：填写本地区结合地域特点建设水上搜救应急平台的具体情况。

3.水上搜救队伍建设：填写本地区对水上搜救管理人才、专业人才和技术人才队伍建设情况，以及社会水上搜救志愿者的建设情况。

4.水上应急物资储备工作：填写对现有水上搜救资源的普查和整合情况，专业救助物资和装备的储备情况。

**三、**水上预防预警工作和应急处置工作

1.水上风险隐患排查和控制：按照分级管理、重点突出、全面推进的原则，填写针对本地区实际情况具体开展的风险隐患普查工作，掌握本区域内风险情况，具体落实风险隐患综合防范和处置措施。

2.水上搜救预警工作：填写建立险情预警系统，建立预警信息通报和发布制度的情况，通过各种专业手段发布预警信息的具体数据等。

3.水上险情处置工作建设：填写本地区处置水上突发事件的应急反应能力的评估和特重大事件的后评估工作。

**四、**水上搜救宣传教育工作

1.水上搜救宣传教育工作：填写对水上搜救预案和应急救助知识的宣传教育的具体做法和成效。

2.水上搜救管理培训工作：填写本地区组织开展搜救知识培训的规划、培训效果及培训考核的有关情况。
