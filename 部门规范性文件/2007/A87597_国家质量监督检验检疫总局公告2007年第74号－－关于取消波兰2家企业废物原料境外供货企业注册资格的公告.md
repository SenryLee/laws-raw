# 国家质量监督检验检疫总局公告2007年第74号－－关于取消波兰2家企业废物原料境外供货企业注册资格的公告

*注：本篇法规已被：国家质量监督检验检疫总局公告2010年第83号――关于公布进口可用作原料的固体废物国外供货商有效注册登记资格的公告（发布日期：2010年8月6日，实施日期：2010年8月6日）废止

## 国家质量监督检验检疫总局公告(2007年第74号)

关于取消波兰2家企业废物原料境外供货

企业注册资格的公告

近日，总局在对波兰的进口废物原料境外供货企业实施后续监督管理的现场检查中发现，（GRUPA FOLLAREX）FOLIAREX SPOLKA JAWNA等2家企业注册材料与实际情况严重不符，不具备获得注册资格的基本条件。为保护我国环境，防止境外有毒有害废物向我国转移，维护进口废物原料的贸易秩序，根据《中华人民共和国进出口商品检验法实施条例》第53条和国家质检总局2004年第48号公告的规定，现公告如下：

**一、**自公告发布之日起，取消下列进口废物原料境外供货企业的注册资格：

```
┌───┬────────────────────────┬────────┬─────────────┐

│　　　│企业名称　　　　　　　　　　　　　　　　　　　　│　　　国家　　　│　　注册编号　　│

├───┼────────────────────────┼────────┼─────────────┤

│1│(GRUPA FOLLAREX)FOLIAREX SPOLKA JAWNA　　　│　　　波兰　　　│　　　　A616041506　　　　│

│　　　│　　　　　　　　　　　　　　　　　　　　　　　　│　　　　　　　　│　　　　　　　　　　　　　│

├───┼────────────────────────┼────────┼─────────────┤

│2│PPHU EKO-POL TADEUSZ WOJCIK　　　　　　　　│　　　波兰

│　　　　A616041510　　　　│

│　　　│　　　　　　　　　　　　　　　　　　　　　　　　│　　　　　　　　│　　　　　　　　　　　　　│

└───┴────────────────────────┴────────┴─────────────┘
```

**二、**各地检验检疫机构要严格把关，禁止上列取消注册资格的企业所供废物原料进境。

二〇〇七年五月二十一日
