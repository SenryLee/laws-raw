# 国家质量监督检验检疫总局关于开展特种设备“六一”安全宣传教育活动的通知

## 国家质量监督检验检疫总局关于开展特种设备“六一”安全宣传教育活动的通知（质检办特函〔2007〕222号）

各省、自治区、直辖市质量技术监督局：

6月1日是《特种设备安全监察条例》的实施日，6月份也正值“全国安全生产月”活动时间，为进一步贯彻落实《特种设备安全监察条例》、广泛普及特种设备安全知识、提升全社会的安全意识，创建安全、和谐的环境，总局决定于6月份，在全国范围内开展特种设备安全知识普及教育活动。请各省、自治区、直辖市质量技术监督部门根据本地实际情况，结合当地特种设备安全工作的突出特点，采用不同的方式和形式，深入学校、社区、工矿企业、特种设备使用频繁的单位和地区进行特种设备安全知识的普及教育活动，宣传特种设备安全的法律、法规、特种设备正确的使用方法和应急知识。

为对此次宣传活动起引导和示范作用，在6月1日国际儿童节来临之际，总局办公厅、特种设备局拟于5月底举办由部分小学参与的，以“为了孩子的安全快乐，为了明天”为主题，以特种设备安全知识竞赛为主要形式的“六·一”宣传教育活动，并免费发放《消费指南》宣传专刊。

为保证各地开展特种设备安全知识普及教育活动效果，各省、自治区、直辖市质量技术监督部门应认真筹划，制订切实可行的方案，落实宣传工作具体措施，确保宣传教育的实际效果。请各省于2007年5月25日前将方案报送总局特种设备局。

二〇〇七年五月十六日
