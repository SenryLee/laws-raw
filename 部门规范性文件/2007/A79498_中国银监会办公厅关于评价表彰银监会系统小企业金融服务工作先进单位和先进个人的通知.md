# 中国银监会办公厅关于评价表彰银监会系统小企业金融服务工作先进单位和先进个人的通知

## 中国银监会办公厅关于评价表彰银监会系统小企业金融服务工作先进单位和先进个人的通知（银监办通[2007]302号）

各银监局：

为及时总结各地小企业金融服务工作的有益经验，进一步提高小企业金融服务工作水平，促进小企业持续快速健康发展，银监会将表彰一批在小企业金融服务工作中表现突出的先进单位和先进个人。为了做好表彰工作，现就评选先进单位和先进个人的有关事项通知如下：

**一、**考核评价的主要内容

（一）小企业金融服务工作的制度建设情况。主要评价各银监局根据辖内的具体情况，研究制定小企业金融服务工作制度文件的有关情况。

（二）小企业金融服务工作的队伍建设情况。主要评价各银监局在建立小企业金融服务工作的组织机构，组建小企业金融服务工作队伍的有关情况，以及各银监局通过专业化的业务培训，促进辖内银行业监管人员和银行业金融机构小企业信贷人员了解国内外小企业授信工作的良好做法与先进的监管理念，提高监管人员对小企业授信工作的监管能力，帮助银行业金融机构不断提高开展小企业贷款业务的能力和水平等方面的情况。

（三）小企业金融服务工作的信息工作情况。主要评价各银监局在交流和反映辖内小企业金融服务工作方面的进展情况。

（四）促进银行业金融机构与小企业的沟通合作情况。主要评价各银监局在采取各种有效的方式，疏通银行业金融机构和小企业之间的信息渠道，促进银行业金融机构和小企业之间信贷对接的情况。

（五）小企业金融服务工作外部环境方面的情况。

1. 建立联合工作机制。主要评价各银监局与有关部门加强合作，充分发挥合作各方的职能作用和信息优势，共同推进小企业金融服务工作的情况。

2. 营造良好舆论氛围。主要评价各银监局通过各种媒体，多角度、多层面地宣传完善小企业金融服务工作的重要性，报道辖内银行业金融机构小企业授信工作等的进展情况。

3. 建立风险补偿基金。主要评价各银监局在争取政府有关部门设立小企业贷款风险补偿专项基金方面的工作情况。

4. 降低相关收费标准。主要评价各银监局在争取政府有关部门出台降低小企业授信业务相关收费标准方面的工作情况。

5. 出台有利的财税政策。主要评价各银监局在争取地方财政、税收部门出台鼓励银行业金融机构改善对小企业信贷支持力度的财政、税收政策方面的工作情况。

6. 完善中介服务体系。主要评价各银监局协同有关部门促进小企业信用担保机构增强担保能力，加强小企业征信体系建设，促进小企业信用评级机构、风险投资机构的发育和发展等方面的工作情况。

7. 创造良好信用环境。主要评价各银监局协同有关部门采取相关措施，不断完善辖内小企业授信工作信用环境方面的工作情况。

8. 其他工作。主要评价各银监局协同有关部门采取其他措施，改善小企业金融服务外部环境方面的工作情况。

（六）小企业金融服务工作的实际成效。主要评价各银监局辖内地方法人银行业金融机构小企业授信工作的进步度，包括地方法人银行业金融机构引进小企业贷款技术援助，并结合本行特点进行自主信贷技术创新的情况。

（七）小企业授信业务的风险监管情况。主要评价各银监局在加强对辖内银行业金融机构小企业授信业务风险监管方面的工作情况。

（八）地方政府对辖内小企业金融服务工作的满意度。主要考察地方政府领导对银监局小企业金融服务工作的评价情况。

各银监局可将辖内银监分局的工作进展情况涵盖在内。

**二、**考核评价的具体方法

各银监局按照上述考核评价内容，真实、准确、简要地填写《银监会系统小企业金融服务工作考核评价情况表》（附件1）的各项内容，并报送所需的附件材料。

对各银监局小企业金融服务工作的考核评价采取百分制，各项内容的评价标准具体如下：

（一）小企业金融服务工作的制度建设情况。该项满分3分。根据各银监局研究制定小企业金融服务工作制度文件的有关情况进行评分，最高3分，最低0分。

（二）小企业金融服务工作的队伍建设情况。该项满分7分。根据各银监局建立小企业金融服务工作组织机构、配备具体负责小企业金融服务工作人员的情况进行评分，最高2分，最低0分；

根据各银监局举办小企业金融服务工作培训班的次数、规模等情况进行评分，最高5分，最低0分。

（三）小企业金融服务的信息工作情况。该项满分3分。根据各银监局编辑简报等形式定期反映和交流小企业金融服务工作、研究整理国内外小企业金融服务工作有关资料的情况进行评分，最高3分，最低0分。

（四）促进银行业金融机构与小企业的沟通合作情况。该项满分7分。根据各银监局采取各种措施促进银行业金融机构与小企业沟通合作的有关情况进行评分，最高7分，最低0分。

（五）完善小企业金融服务工作外部环境方面的情况。该项满分20分。

1. 建立联合工作机制。该项满分3分。根据各银监局与地方有关部门建立联合工作机制，充分发挥合作各方的职能作用和信息优势，共同推进小企业金融服务工作的情况进行评分，最高3分，最低0分。

2. 营造良好舆论氛围。该项满分3分。根据各银监局通过报纸、杂志、广播、电视或互联网等新闻媒体，多角度、多层面宣传小企业金融服务工作的情况进行评分，最高3分，最低0分。

3. 建立风险补偿基金。该项满分5分。根据各银监局争取地方政府有关部门在全辖范围内设立了小企业贷款风险补偿专项基金的情况进行评分。争取地方政府有关部门在全辖设立小企业贷款风险补偿专项基金的，得5分；争取地方政府有关部门在辖内部分地区设立了小企业贷款风险补偿专项基金的，得2-4分；向地方政府提出设立小企业贷款风险补偿专项基金建议的，得1分。

4. 降低相关收费标准。该项满分2分。争取政府有关部门在全辖范围内出台了降低小企业授信业务相关收费标准的，得2分；只在辖内部分地区争取出台了降低小企业授信业务相关收费标准的，得0.5-1.5分；向地方政府提出降低小企业授信业务相关收费标准建议的，得0.5分。

5. 出台有利的财税政策。该项满分2分。争取政府有关部门在全辖范围内争取出台了鼓励银行业金融机构加大信贷投入的财政、税收政策的，得2分；只在辖内部分地区争取出台相关财政、税收政策的，得0.5-1.5分；向地方政府提出出台鼓励银行业金融机构加大信贷投入的财政、税收政策建议的，得0.5分。

6. 完善中介服务体系。该项满分2分。根据各银监局协同有关部门在辖内完善中介服务体系工作的具体措施和成效进行评分，最高2分，最低0分。

7. 创造良好信用环境。该项满分3分。根据各银监局在加强辖内小企业授信工作的信用环境建设方面采取的相关措施与成效进行评分，最高3分，最低0分。

（六）小企业金融服务工作的实际成效。该项满分30分。具体根据各银监局辖内地方法人银行业金融机构小企业授信余额增幅、小企业授信余额占授信余额比重的增幅、小企业授信户数增幅等方面的情况进行综合排名。最高30分，最低0分。

（七）小企业授信业务的风险监管情况。该项满分30分。

1. 在全辖范围内建立了小企业授信业务统计制度并进行定期监测分析的，得5分；在辖内部分地区建立了小企业授信业务统计制度并进行定期监测分析的，得1-4分；未建立小企业授信业务统计制度的，不得分。

2. 在全辖建立并启动了小企业授信违约信息通报机制的，得5分；在辖内部分地区建立了小企业授信违约信息通报机制的，得1-4分；未建立小企业授信违约信息通报机制的，不得分。

3. 辖内地方法人银行业金融机构小企业授信业务的质量情况。该项满分20分，具体根据各银监局辖内地方法人银行业金融机构小企业贷款不良率、小企业贷款不良率的升降幅度等情况进行综合排名，最高分20分，最低分0分。

（八）奖励加分方法。

1. 各银监局上报的完善小企业金融服务工作信息，被银监会《小企业金融服务工作动态》或《银监会简报（小企业金融服务增刊）》采用的，每篇信息加1分。

2. 协助银监会完善小企业金融服务领导小组办公室承办会议或培训班的，按会议或培训班的规模大小，每次加3-5分；协助开展专项调研的，每次加4分。

3. 各银监局在推动地方法人银行业金融机构引进小企业贷款技术援助并结合本行特点进行自主信贷技术创新的，加2-10分。

4. 各银监局的小企业金融服务工作得到地方政府良好评价的，加1-5分。

5. 各银监局在完善小企业金融服务工作方面采取了其他创新做法的并取得良好成效的，加2-10分。

各银监局在完善小企业金融服务工作的制度建设、队伍建设、信息工作、促进银企沟通合作、外部环境、实际成效和风险监管等七个方面的得分加总即为该局综合考核得分。奖励加分上不封顶。综合考核得分与奖励加分合计为年终总分。按年终总分高低排出各银监局在完善小企业金融服务工作中的考评名次。

**三、**评价表彰的具体方法

（一）评价表彰的组织领导。由银监会完善小企业金融服务领导小组负责组织对各银监局的小企业金融服务工作进行评价表彰，银监会完善小企业金融服务领导小组办公室负责评价表彰的具体工作。

（二）评价表彰的程序。首先由各银监局按照上述要求自评并填写《银监会系统小企业金融服务工作考核评价情况表》（附件1），然后由银监会相关监管部门对各银监局小企业金融服务工作的进展情况提出意见，最后由银监会完善小企业金融服务领导小组办公室进行综合评价。

（三）小企业金融服务工作先进单位和先进个人的表彰名额。各银监局在报送考核评价的有关材料的同时，报送一名小企业金融服务工作先进个人的相关事迹材料。

与此同时，请各银监局依据《中国银监会办公厅关于评价表彰银行业金融机构小企业授信工作先进单位和先进个人的通知》的有关办法，提出本辖区地方法人银行业金融机构小企业授信工作先进单位和先进个人名单。

各银监局提出本局小企业金融服务工作先进个人人选以及辖内法人银行业金融机构小企业授信工作先进个人人选时，应注重考察其政治表现，同时，着重考察其在完善小企业金融服务工作中所取得的突出成绩。

**四、**评价表彰的时间

请各银监局于2008年1月18日前，将《银监会系统小企业金融服务工作考核评价情况表》以及所需的附件材料报银监会完善小企业金融服务领导小组办公室，并同时报送拟表彰的本辖区地方法人银行业金融机构小企业授信工作先进单位和先进个人名单（附相关材料）。

银监会将对2007年小企业金融服务工作的先进单位和先进个人进行表彰。
