# 建设部标准定额司关于同意黑龙江省《HS―ICF外墙外保温建筑节能体系技术规程》地方标准备案的函

## 建设部标准定额司关于同意黑龙江省《HS-ICF外墙外保温建筑节能体系技术规程》地方标准备案的函（建标标备便[2007]129号）

黑龙江省建设厅：

你厅《关于黑龙江省工程建设标准申请备案的函》收悉。经研究，同意该标准作为“中华人民共和国工程建设地方标准”备案，备案号为J11055-2007。

该项标准的备案公告，将刊登在近期出版的《工程建设标准化》刊物上。
