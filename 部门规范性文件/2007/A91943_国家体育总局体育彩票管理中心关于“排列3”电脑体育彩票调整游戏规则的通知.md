# 国家体育总局体育彩票管理中心关于“排列3”电脑体育彩票调整游戏规则的通知

根据财政部《关于排列3电脑体育彩票派奖活动的通知》（财办综【2006】118号）文件，排列3玩法调整游戏规则，由原来的“奖池资金累计超过10亿元以上部分自动转为调节基金”调整为“奖池资金累计超过5亿元以上部分自动转为调节基金”。

特此通知。

国家体育总局体育彩票管理中心

二OO七年一月十二日
