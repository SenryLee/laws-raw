# 国家食品药品监督管理局药品GLP认证公告第16号——关于发给广州中医药大学科技产业园有限公司、辽宁省食品药品检验所GLP认证批件的公告

国家食品药品监督管理局药品GLP认证公告（第16号）

（国食药监安[2007]746号）

根据国家食品药品监督管理局《药物非临床研究质量管理规范认证管理办法》的规定，经资料审查、现场检查和审核批准，广州中医药大学科技产业园有限公司、辽宁省食品药品检验所申请的以下试验项目符合药物非临床研究质量管理规范（GLP）要求，现发给GLP认证批件，并予以公告。

|  |  |  |
| --- | --- | --- |
| 机 构 名 称 | 试 验 项 目 | 批件编号 |
| 广州中医药大学科技产业园有限公司（新南方药物安全性评价中心） | 1.单次和多次给药毒性试验（啮齿类） 　　2.单次和多次给药毒性试验（非啮齿类，不包括灵长类） 　　3.局部毒性试验 　　4.生殖毒性试验 　　5.遗传毒性试验（Ames、微核、染色体畸变） | GLP07004004 |
| 辽宁省食品药品检验所（药物安全评价中心） | 1.单次和多次给药毒性试验（啮齿类） 　　2.局部毒性试验 　　3.免疫原性试验 　　4.安全性药理试验 | GLP07005005 |

国家食品药品监督管理局

二○○七年十二月十日
