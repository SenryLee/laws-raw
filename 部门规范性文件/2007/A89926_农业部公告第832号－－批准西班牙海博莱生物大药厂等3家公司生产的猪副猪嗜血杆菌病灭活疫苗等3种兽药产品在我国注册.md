# 农业部公告第832号－－批准西班牙海博莱生物大药厂等3家公司生产的猪副猪嗜血杆菌病灭活疫苗等3种兽药产品在我国注册

## 农业部公告（第832号）

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准西班牙海博莱生物大药厂等3家公司生产的猪副猪嗜血杆菌病灭活疫苗等3种兽药产品在我国注册，现核发《进口兽药注册证书》，并发布产品质量标准、标签和说明书，自发布之日起执行。
