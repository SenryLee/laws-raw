# 中国人民银行办公厅关于调整城镇储户问卷调查范围的通知

## 中国人民银行办公厅关于调整城镇储户问卷调查范围的通知（2008年10月24日　银办发[2008]253号）

人民银行上海总部，各分行、营业管理部，各省会(首府)城市中心支行：

城镇储户问卷调查制度从1993年实施以来，为人民银行及时了解我国居民的投资、储蓄和消费意向，制定货币政策提供了大量参考信息。随着我国经济的快速发展，城镇储户问卷调查制度在实施中出现一些问题：一是近年来我国城市经济发展不同步，造成原方案中58个调查城市对全国城市的总体代表性减弱；二是因城市功能区域划分变化，造成原方案中抽取的调查网点(储蓄所)对总体的代表性减弱，储户样本结构的代表性减弱。

为增强调查样本的代表性，总行在大量调研的基础上，成立了由国内抽样专家和相关人员组成的工作小组，对储户问卷调查抽样方案进行了修订，并决定根据修订后的抽样方案对城镇储户问卷调查制度中的调查范围(调查城市和调查储蓄所)进行调整，具体调整方案如下：

**一、**调查城市和调查储蓄所的调整

根据城镇储户问卷调查城市抽样方案(见附件1)，最终确定50个调查城市：

直辖市(4个)①（备注：①城市行政级别根据《中国城市统计年鉴2005》中行政级别分组标准划分，全国城市共分为直辖市(4个)、副省级市(15个)、地级市(268个)、县级市(374个)四级。）：北京、上海、天津、重庆；

副省级市(5个)：广州(广东)、长春(吉林)、南京(江苏)、杭州(浙江)、西安(陕西)；

县级市(7个)：长乐(福建)、大理(云南)、库尔勒(新疆)、凯里(贵州)、冀州(河北)、绥芬河(黑龙江)、赤壁(湖北)。

**一、**前言

比较《中国城市统计年鉴1997》和《中国城市统计年鉴2006》，我们会发现年鉴中新增了一些城市统计的经济指标，如移动电话年末用户数、国际互联网年末用户数等，说明评价城市经济发展的指标逐渐发生了变化，因此，在中国人民银行城镇储户调查抽样方案的设计中，如何采取比较科学合理的指标对城市进行分层显得非常关键。同时，从1999年到现在，随着经济的持续发展，我国的600多个大中小城市发生了很大的变化，由于各个城市经济发展不均衡，原来方案中的58个城市也需要作出局部调整，使之在各项指标上能够代表全国城市的总体。

城市分层的主要目的是提高精度，分层指标要按照使调查的主要目标量的层内方差尽可能小，层间方差尽可能大的原则来选择。因此，确定合适的分层指标来对我国的城市进行分层，在此基础上抽取城市，使得抽到的城市样本能够基本代表全国城市，是本抽样方案的主要任务。

**二、**城市抽取思路

本抽样方案借鉴1999年抽样方案中城市抽取的思路，并充分考虑城市的发展变化，进而探讨此次抽样设计中城市抽取的方法。

2007年抽样方案城市抽取的总体思路：首先准备城市抽取的抽样框，其次选择合适的指标对城市进行分层，再次采用合适的指标确定每层应抽取的城市数目，最后根据合适的指标抽取具体的城市。

**三、**城市抽取过程及结果

(一)抽样框准备

根据最新的《中国城市统计年鉴2006》的汇总，全国共有661个城市(由于一些县级城市行政区划的变更，由市改为区，所以比《中国城市统计年鉴1997》的城市数目少了5个)，包括地级及以上城市287个，县级城市374个，其中拉萨的数据缺失因而略去。

《中国城市统计年鉴2006》对地级及以上城市和县级城市分别进行数据统计，两类城市共有的与人口和经济相关的指标有9个，分别为“年末总人口(万人)”、“人口密度(人/平方公里)”、“地区生产总值(万元)”、“第一产业生产总值(万元)”、“第二产业生产总值(万元)”、“第三产业生产总值(万元)”、“限额以上批发零售贸易业商品销售总额(万元)”、“职工平均工资(元)”、“当年实际使用外资金额(万美元)”。其中，当年实际使用外资金额指标的数据缺失116个，因此将该指标舍去。将660个城市的名单以及8个相关的人口指标、经济指标①（备注：①《中国城市统计年鉴2006》的地级及以上城市的指标数据分成“全市”和“市辖区”两类，鉴于调查的总体为全国城镇居民，因此录入“市辖区”的经济指标数据，文中不再单独注明。县级城市未作区分，直接录入全市的数据。）录入数据库，形成抽样框。

(二)确定分层指标及城市分层

1.确定分层指标的原则。

·参考1999年抽样方案中的分层指标。

·指标与居民消费、储蓄等调查的问题密切相关。

·将相关经济指标分成不同的类别，依据不同类别的重要性确定各类别指标的数量。

·在同类指标里面，相关性高的可以相互替代，从中进行选择。

·分层指标确定后进行聚类分析时，所聚成的类别是容易解释的。

2.城市分层。

把两类城市共有的8个相关的人口指标和经济指标的数据汇总，从中选择合适的指标作为分层指标，利用SPSS软件的聚类分析方法对全国660个城市进行分层。

根据确定分层指标的原则，1999年抽样方案中的指标尽量都选用，因此，8个共有指标中的“年末总人口”、“人口密度”、“职工平均工资”三个指标作为必选指标。其他5个经济指标中由于“第一产业生产总值”与调查对象(城镇居民)的关系不大，因此舍弃；“第二产业生产总值”对居民的消费储蓄可能没有直接的影响，舍弃此指标。剩下的3个经济指标包括“第三产业生产总值”、“地区生产总值”和“限额以上批发零售贸易业商品销售总额”。

由于1999年抽样方案中的“社会消费品零售总额”和“城乡居民储蓄年末余额”这两个指标在《中国城市统计年鉴2006》中缺失县级城市部分数据。因此，考虑用地级及以上城市和县级城市其他3个共有的指标来代替这两个指标。把“社会消费品零售总额”和“城乡居民储蓄年末余额”与3个共有的指标“第三产业生产总值”、“地区生产总值”和“限额以上批发零售贸易业商品销售总额”两两作相关分析。相关分析的结果发现：“第三产业生产总值”与“社会消费品零售总额”的相关性(0.981)，以及与“城乡居民储蓄年末余额”(0.989)的相关性都高于其他两个指标，所以“第三产业生产总值”是一个关键的分层指标。因此，将“年末总人口”、“人口密度”、“职工平均工资”和“第三产业生产总值”作为城市的分层指标。这四个指标类型涵盖人口指标(“年末总人口”、“人口密度”)、收入指标(“职工平均工资”)和经济指标(“第三产业生产总值”)，能够比较全面地描述城市的经济发展水平。

利用SPSS软件，把4个指标的数据标准化，使各个指标的数量级相同，然后进行聚类分析，经反复测试，将660个城市分成6层的结果比较理想。

(四)确定入样指标及各层抽取的具体城市

上述提到最终确定了城市的四个分层指标，包括“年末总人口”、“人口密度”、“职工平均工资”和“第三产业生产总值”，其中，“第三产业生产总值”与城市的经济发展水平密切相关，因此将“第三产业生产总值”作为确定各层单元抽中概率的指标(简称入样指标)。按照PPS抽样法，使各层内每个城市被抽中的概率，等于该城市的“第三产业生产总值”与对应层的“第三产业生产总值”之比。

第一层包括北京和上海两个城市，根据表1每层应抽取城市数的结果，这一层应抽取两个城市，因此北京和上海两个城市均入选。

第二层包括广州和深圳两个城市，通过比较深圳、广州的各项指标数据以及第二层各指标数据的平均值，发现深圳的各项指标低于第二层的平均值，而广州的各项指标高于平均值。考虑到广州人口比较多，并且在全国经济发展中发挥着重要作用，因此选择广州代表本层城市。

第三层到第六层中抽取城市的过程如下：

·将每层中的全部城市按“第三产业生产总值”的大小顺序排列，并对全部城市求和。

·确定每个城市的“第三产业生产总值”占对应层全部城市“第三产业生产总值”总和的比例及累计百分比，使总和为1。

·利用EXCEL软件产生0～1之间的均匀分布的随机数，根据各随机数落在各城市对应累计百分比的范围，确定被抽中的城市。

·在随机抽取城市时，抽取几套样本城市，然后从中初选一套样本。如果该样本城市在地域分布上或四个指标上不理想，需要进行适当的调整时，从备用的样本城市中选取。

·在每层中抽取城市时，使选择的城市在地域分布上尽可能代表全国城市的分布。

三、抽取储户

**一、**前言

本方案以《1999年中国人民银行城镇储户调查抽样方案》为参考，以2007年《中国人民银行摸底调查报告》为基础，在第一步抽取城市的基础上抽取储蓄所和储户，以五大银行储蓄所网点为抽样框、以“日均业务笔数”和“日均业务金额”(即“日均业务笔数”与“日均单笔业务金额”的乘积)为备选指标，将储蓄所排序之后进行PPS抽样，随后抽取相应的储户。

储蓄所抽取思路和原则

本方案以1999年储蓄所抽取方案为参考，在保证抽样精度的前提下兼顾可操作性。由于“储蓄所抽取”工作拟交由各城市人民银行分行独立实施，因此需保证各个城市标准统一、操作实施过程简洁明了、易于操作。

2007年抽样方案储蓄所抽取的总体思路为：首先准备储蓄所抽取的抽样框，其次选择有代表性的指标，最后根据选择的指标抽取具体的储蓄所。

**二、**储蓄所抽取过程

(一)抽样框准备

·以工行、农行、建行、中行、邮政储蓄银行五大银行的储蓄所网点为二级抽样框

根据《中国人民银行摸底调查报告》，超过八成(80.5%)的被访者平时去银行网点办理业务，而这部分被访者在性别、年龄、教育程度、职业和收入水平五个方面的情况和总样本人口的情况基本一致，说明去银行网点的用户人口特征目前大体上可以代表城镇居民。

而在去银行网点的居民中，工行、农行、建行、中行、邮政储蓄银行五大银行使用者覆盖了去银行网点用户的96.9%，五大银行使用者与去银行网点的用户的人口特征分布没有显著性差异，说明，五大银行储蓄所的使用者可以大致代表城镇居民，以五大银行储蓄所网点作为二级抽样框是可行的。

在《摸底调查报告》中曾经提出，可以对使用自动柜员机的用户进行调查作为辅助，但考虑到实际操作情况，自动柜员机分布众多且位置复杂，单独调查可操作性差。如果与银行储蓄所网点的调查合并，以“在银行营业厅内部的自动柜员机”最为便利，实际上仍然是对银行储蓄所网点进行调查。在实施中可以以银行网点大门为限，凡进入银行大门的银行用户不论是办理柜台业务，或是办理自动柜员机业务，均纳入调查总体，根据相应的规则对其进行进一步抽取。

(二)入样指标选择

·日均业务笔数

由于抽样的目标总体为“城镇居民”，所以选择能够反映到银行储蓄所办理业务的居民流动量的指标为宜，而银行储蓄所网点的“日均业务笔数”是每天到银行办理业务的居民数量的近似反映，是抽取储蓄所的首选指标。

·日均单笔业务金额

“日均单笔业务金额”反映的是储蓄所平均业务规模，与“日均业务笔数”综合，反映储蓄所整体规模差异。而不同的储蓄所，由于其自身定位差异，或所处地理位置差异，“日均单笔业务金额”也有所不同。有的储蓄所人流大、业务多，但日均单笔业务金额规模可能相对较小。

·日均业务金额

“日均业务金额”可以看做是“日均业务笔数”与“日均单笔业务金额”的乘积，是上述两个指标的综合反映。既涉及了居民流动量，同时也兼顾了储蓄所的业务金额规模。

·“日均”时长选择

就“日均”的选择而言，主要关心的是各个储蓄所之间的比例关系，如果在一个时间范围内考虑，出现波动，则各个储蓄所都会有波动，是每周、每月还是每季度平均差别可能不大，要根据各个数据的获取难易程度而定。

统一规定以2007年全年的数据为准，计算“日均业务笔数”和“日均单笔业务金额”。如果整年的数据难以获取，则可根据数据获取的难易程度相应缩短数据时限，统一规定以2007年某一季度或某一月份的数据为准进行平均。

(三)抽样方法

在具体的抽样时，有两种方法可供选择，方法1是采用PPS 抽样，方法2是采用分层抽样。

方法1： PPS抽样

也即是根据与储蓄所规模大小成比例的概率来抽取的方法。

其入样指标也有两个可供选择，分别是使用指标A “日均业务笔数”和指标B “日均业务金额”(即“日均业务笔数”与“日均单笔业务金额”的乘积)。

由于无论选择A指标或B指标，进行PPS抽样的步骤和方法是一致的，只是在指标选择的称呼上有所差别，所以下文中使用入样指标X代表已选定的指标。

具体过程：

1.搜集城市辖区内五大银行所有面向储户办理业务的储蓄所网点(如果抽中的为地级市，则为市辖区内所有储蓄所；若抽中的为县级市，则为县城辖区内所有储蓄所)相关指标。

2.按照入样指标X(指标A “日均业务笔数”或指标B “日均业务金额”)对储蓄所由大到小进行排序，最后以1为起始序号顺序为所有储蓄所编号。

3.计算每个储蓄所在入样指标累计百分比中所处的位置，也就是根据入样指标×累计百分比计算所得的区间。

若某市共有N个储蓄所，则第n个储蓄所的累计百分比区间位置为

```
∑Xn-1　　　∑Xn

［————　,————］

```

其中，ΣXN表示所有N个储蓄所的入样指标X相加得到的总和，ΣXn表示前n个储蓄所的入样指标x之和。

4.样本单元间的距离K：

```

```

其中，8为最终抽取的储蓄所个数，而“1”为N个储蓄所的累计百分比，即100%。

5.计算抽中的累计百分比数字，对比储蓄所累计百分比区间得到抽中的储蓄所。

在0至0.125的区间内选择一个随机数(小数点后三位有效数字)作为起点(设为i)，依次加K (0.125)，得到i，i＋K，i ＋2K…i＋7K共8个数字，保留为百分比形式。将这8个百分比数字与N个储蓄所的累计百分比区间进行比较，若某一储蓄所的累计百分比区间包含上述8个百分比数字中的一个，则选中该储蓄所。若某储蓄所的累计百分比区间包含上述8个百分比数字中的两个，则说明由于该储蓄所的指标X特别大，被抽中了两次，该储蓄所的样本量需要加倍，即最终调查7个储蓄所，该特大储蓄所调查的人数是其他储蓄所的2倍。

6.查看抽中的储蓄所所在位置及各项指标等，适当调整，使储蓄所所在位置比较分散，各指标的样本均值与总体均值大体一致。

方法2：分层抽样

使用“日均业务笔数”与“日均单笔业务金额”作为聚类指标，使用SPSS统计分析软件将每个城市的储蓄所聚为8类，实际上分为8层，之后每层随机抽取一个有代表性的储蓄所。

此种方法更为精确，但具体的实施过程复杂，不适宜各个分行独立实施。

考虑到各个抽中城市的储蓄所的抽取由各地来执行，从便于操作的角度，建议选择方法1。

(四)储蓄所数量选择

根据1999年方案，每个城市选取了8个储蓄所网点、每个网点调查50名被访者，即8×50共400名被访者。

从成本角度来考虑，选取8个储蓄所网点，在实际操作中便于巡查人员监督和管理，同时具有规模效益，花费的人力、物力更少，相对节约成本。

**三、**抽取储户

调查的实施时间建议为3天左右，不同人口背景特征的人群在使用银行方面有差异，包含平时和周末，可以尽可能多地抓住更多不同人口背景特征的人群，使得调查更为精确。建议统一设为“周四至周六”或“周日至周二”。

参考1999年方案，在每个抽中的储蓄所内，按储户进门的时间顺序，每隔M人调查1人，直到调查了50人为止。M的大小可以根据储蓄所的具体情况确定。

如储蓄所平均每天人流量为100人，三天内人流量约为300人，为完成50人，可隔6人调查1人(被访问者包含在6人中)，直到完成50人为止。

为使调查便于实施，可将各个储蓄所根据具体情况分段。例如，平均每天人流量为50～100人的，隔3人调查1人；100～200人的，隔6人调查1人；200～500的隔12人调查1人；500人以上的隔30人调查1人。人流量低于50人的，可根据具体情况，适当放宽调查实施天数，到1星期左右，每隔3人调查1人，直到完成50人。

如果调查过程中被访者拒绝接受访问，则顺延至下一人，完成后以接受访问的人为起点，对第M人再进行访问。

以上仅为建议，可根据储蓄所人流量的具体情况进行调整。
