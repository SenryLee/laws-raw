# 中国银监会关于批准渣打银行(中国)有限公司筹建大连分行的函

## 中国银监会关于批准渣打银行(中国)有限公司筹建大连分行的函(银监函[2008]238号)

渣打银行（中国）有限公司：

你行行长曾璟璇女士2007年8月13日签署的致我会的函收悉。

根据《中华人民共和国外资银行管理条例》（国务院令第478号，以下简称《条例》）和《中华人民共和国外资银行管理条例实施细则》（中国银行业监督管理委员会令2006年第6号，以下简称《实施细则》）的有关规定，批准你行筹建大连分行。

请你行自接到本批文之日起15日内到大连银监局领取开业申请表，并按《条例》和《实施细则》的规定开展大连分行的筹建工作。在筹建期内，你行应成立“渣打银行（中国）有限公司大连分行筹备组”，指定筹备组负责筹建事项，并将筹备组负责人名单报告大连银监局。该筹备组应接受大连银监局的监督、检查和指导。筹建期结束时该筹备组解散。

筹建完成后，你行应按照《条例》和《实施细则》的规定向中国银监会提出开业申请。

二○○八年七月二十三日
