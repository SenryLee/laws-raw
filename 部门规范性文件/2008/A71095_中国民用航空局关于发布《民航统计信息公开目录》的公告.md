# 中国民用航空局关于发布《民航统计信息公开目录》的公告

根据《中华人民共和国政府信息公开条例》和《民航行政机关政府信息公开办法》的规定，为了方便公民、法人及社会其他组织查阅和使用属于公开范围的民航统计信息，同时为规范民航统计信息的公开工作，特制定本目录，现予以发布。本目录于2009年1月1日正式执行。

中国民用航空局　

二00八年九月十八日

民航统计信息公开目录

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 编号 | 公开信息名称 | 主要指标或内容描述 | 发布周期和时限 | 发布渠道 |
| 1 | 机场生产统计公报 | 上一年度我国民用航空所有通航机场的旅客、货邮吞吐量和飞机起降架次。 | 每年4月底以前 | 中国民航报  民航政府网站 |
| 2 | 月度全行业发展统计快报 | 全行业月度运输生产的概况。主要包括：①分国内、国际、港澳航线月度和年度累计完成的运输总周转量、旅客周转量、旅客运输量、货邮周转量、货邮运输量以及它们与去年同期相比的增长比率；②月度正班客座率和载运率统计以及它们与上月和去年同期相比的增长比率。 | 每月十五日以前（节假日顺延） | 民航政府网站 |
| 3 | 《从统计看民航》 | 以年刊的形式全面介绍我国民用航空事业年度发展概况，内容包括“资源概况”、“航空运输发展指标”、“通用航空发展指标”、“效益指标”、“航空安全与服务质量评价指标”、“历史发展指标”、“世界航空”和“附录”8个部分。 | 每年9月底以前 | 民航出版社 |
