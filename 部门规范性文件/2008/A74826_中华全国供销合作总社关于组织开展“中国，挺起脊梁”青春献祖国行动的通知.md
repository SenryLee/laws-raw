# 中华全国供销合作总社关于组织开展“中国，挺起脊梁”青春献祖国行动的通知

各直属团委、支部：

5月12日四川省汶川县发生强烈地震，给人民群众生命财产造成重大损失。党中央、国务院迅速组织、周密部署抗震救灾工作，胡锦涛总书记、温家宝总理亲赴灾区，指导抗震救灾工作。中国人民在巨大的困难面前，顽强地挺起脊梁，积极投入到这场抗震救灾的战役中。

为了弘扬爱国、团结、奉献、互助的精神，进一步在抗震救灾活动中教育青年、引导青年、凝聚青年、激励青年，按照中央国家机关团工委的有关部署和要求，中华全国供销合作总社（以下简称总社）直属机关团委决定，在各直属团组织中开展“中国，挺起脊梁”青春献祖国行动。具体内容通知如下：

**一、**立足本职、服务大局

紧密结合当前抗震救灾的形势，突出青春献祖国主题，引导团员青年立足本职，做好抗震救灾工作：

1. 要认真学习、坚决贯彻中央政治局常委会会议精神和中央领导的重要指示，把团员青年的思想统一到中央的要求上来。

2. 及时关注抗震救灾最新进展情况，通过各种形式，向广大团员青年进行宣传，真正与灾区群众心连心。

3. 引导广大团员青年立足本职、坚守岗位，保障总社各项工作的顺利推进。

**二、**结合实际、支援灾区

进一步发挥各级团组织和团员青年在抗震救灾工作中生力军和突击队的作用，结合本单位实际进一步做好对灾区支援工作：

1. 开展“交纳一次特殊团费”活动。要求全体团员（含保留团籍党员）每人交纳0.2元-10元作为抗震救灾特殊团费。

2. 迅速调查本单位四川籍团员青年情况，及时开展走访慰问。努力做到尽快发现问题、解决问题，鼓励他们安心工作，勇敢面对困难。

3. 围绕灾区的实际需要，动员鼓励团员青年积极参加义务献血等爱心活动。

4. 开展“我能为灾区人民做什么”讨论活动。各级团组织要引导团员青年认识到，既要满怀激情地投身到抗震救灾工作中，情系灾区，爱心奉献；又要思考如何理性、有序、持久地开展对灾区的救助，如何有效地帮助灾后重建。

**三、**学习英雄、教育青年

积极开展向抗震救灾英雄和灾区人民学习、向对我国给与国际人道主义援助的世界各国人民学习的活动。

1. 收集并宣传在抗震救灾工作中涌现出来的英雄人物的先进事迹，号召团员青年向他们学习，并以此来团结、教育、激励团员青年。

2. 开展演讲、主题征文、座谈讨论等多种形式的主题教育活动，引导青年深入思考学习抗震救灾精神，激发青年的爱国主义热情，增强青年的历史责任感和使命感。

总社直属机关各级团组织要高度重视，精心组织，并将主题活动开展情况及时报送到直属机关团委。

二00八年五月二十日
