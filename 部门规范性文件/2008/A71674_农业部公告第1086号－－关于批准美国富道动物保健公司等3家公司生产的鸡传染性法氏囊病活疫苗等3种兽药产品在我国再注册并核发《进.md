# 农业部公告第1086号－－关于批准美国富道动物保健公司等3家公司生产的鸡传染性法氏囊病活疫苗等3种兽药产品在我国再注册并核发《进口兽药注册证书》的公告

## 农业部公告(第1086号)

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准美国富道动物保健公司等3家公司生产的鸡传染性法氏囊病活疫苗等3种兽药产品在我国再注册，现核发《进口兽药注册证书》，并发布修订后的质量标准、标签和说明书，自发布之日起执行。原发布的同品种进口兽药质量标准、标签和说明书同时废止。
