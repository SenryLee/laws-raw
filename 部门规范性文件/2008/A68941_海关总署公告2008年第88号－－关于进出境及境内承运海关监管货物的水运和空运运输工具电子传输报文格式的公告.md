进出境及境内承运海关监管货物的水运和空运运输工具电子传输报文格式制定说明

**一、**进出境水运、空运运输工具信息电子传输报文根据中华人民共和国海关对运进出境运输工具监管有关法律法规及监管业务要求制定，包括运输工具备案、运输工具动态、运输工具单据、回执等报文，其中运输工具动态报文参考世界海关组织数据模型（WCO Data Model v2.0）制定。

**二、**报文定义要求

1．报文标准

报文格式采用W3C的XML标准，编码格式采用UTF-8，采用单个XML文件向海关传输，原则上应不大于2M。

2．报文结构

报文采用作为根节点，根节点下面分为和两个部分。下面节点里面为运输工具申报内容，具体格式请参考报文XSD定义文档。报文节点的命空间为urn：datamodel：standard：CN：[name]：1，其中[name]部分标注报文的类型，具体[name]定义请参考报文类型定义。

3．报文文件名称

运输工具报文文件名称规则为：CN_[name] _1p0_[sender_code]_[send_time].xml，其中CN代表中国海关，[name]名称参考报文类型定义，“1p0”中的“1”代表报文格式的主版本号、“0”代表副版本号，[sender_code]代表发送方代码，长度最大为5位，[send_time]代表发送时间，精确到秒，采用yyyyMMddhhmmss格式。

**三、**字段类型说明

字段类型的定义采用字段类型＋长度的描述方式，具体说明如下。

|  |  |
| --- | --- |
| 字段类型 | 类型含义 |
| N | 数字类型 |
| an | 字符类型 |

|  |  |
| --- | --- |
| 长度 | 长度含义 |
| N | 字段为固定长度，长度为n |
| ..n | 字段为可变长度，最长为n |
| ..n，m | 字段为可变长度小数，小数点前最长n位，小数点后最长m位 |

长度为固定长度的字段必须填满要求的长度，字符类型在末尾补空格，数字类型在开头补零。可变长度类型的字段必须去掉开头和末尾的空格。

**四、**按照要求，如需对报文进行数字签名，则采用W3C颁布的XML数字签名规范（即：W3C XML signature recommendation on 12 February 2002）进行加签处理，其中：采用C14N规范对报文进行规范化；签名类型为封外加签（Enveloping Signature），即： 元素中包含了进行数字签名的元素，而被签名元素为　元素的子元素；签名证书遵循X.509 V3标准；摘要算法采用sha-1；签名算法采用RSA；对签名结果作PEM编码。
