# 全国卫生专业技术资格考试办公室关于做好2008年度卫生专业技术资格延期考试有关工作的通知

各考区：

因汶川地震灾害等因素影响，部分考区、考点推迟了2008年度卫生专业技术资格考试。现经卫生部、人力资源社会保障部研究同意，全国卫生专业技术资格考试办公室定于2008年10月举行2008年度卫生专业技术资格延期考试。现将有关事项通知如下：

**一、**参加延期考试的考生范围

1、已在四川、重庆、西藏考区的各考点和陕西汉中、甘肃陇南考点报名，未能按期参加2008年度卫生专业技术资格考试的考生；

2、已在其他考区、考点报名，因参加抗震救灾医疗队，未能如期参加2008年度卫生专业技术资格考试的考生。

**二、**考试时间

1、纸笔做答考试时间安排如下：

|  |  |  |
| --- | --- | --- |
| 考试科目 | 考试日期和时间 | |
| 基础知识 | 10月11日 | 9：00-11：00 |
| 相关专业知识 | 14：00-16：00 |
| 专业知识 | 10月12日 | 9：00-11：00 |
| 专业实践能力 | 14：00-16：00 |

2、人机对话考试时间安排如下：

|  |  |  |
| --- | --- | --- |
| 考试科目 | 考试日期和时间 | |
| 基础知识 | 10月11、12、13、14日 | 8：30-10：00 |
| 相关专业知识 | 11：00-12：30 |
| 专业知识 | 14：00-15：30 |
| 专业实践能力 | 16：30-18：00 |

各考区要认真做好延期考试的组织实施工作，及时把考试时间通知到考生，努力为考生参加考试创造良好条件。要严格按照《卫生专业技术资格考试考务规则》（卫考办发[2003]4号）和《专业技术人员资格考试违纪行为处理规定》（人事部第3号令）的要求，加强对考试工作的指导、监督、检查，落实责任制，切实做好考试的保密工作，严防泄密，确保延期考试工作顺利完成。
