# 教育部高等教育司关于印发“大学英语教学系统运行环境配置要求”的通知

## 教育部高等教育司关于印发“大学英语教学系统运行环境配置要求”的通知（教高司函[2008]77号）

有关高等学校：

近年来，高等学校积极推动大学英语教学改革，建立基于计算机和网络的大学英语教学模式。在推进教学改革过程中，由于部分高校配置的教学系统运行环境与我部委托研发的五套大学英语教学软件系统要求标准不相匹配，不同程度影响了大学英语教学改革成效。为了进一步推动高校大学英语教学改革，促进高校教学设施充分发挥效益，避免造成不必要的浪费，我司委托有关出版社制订了“大学英语教学系统运行环境配置要求”。现印发给你们，望有关高校在系统建设时参照。

附件：大学英语教学系统运行环境配置要求

教育部高等教育司

二○○八年四月二日

附件：

大学英语教学系统运行环境配置要求《新时代交互英语》教学软件系统

**一、**网络环境

1. 网络辅助平台服务器应安装在支持24小时运行的网络中心内；

2. 学生机应安装在能够支持与服务器数据交换的计算机网络教室或学生宿舍内；

3. 在校园网环境下，学生机与服务器之间的网络带宽应在100M以上；

4. 在广域网（Internet）环境下，学生机与服务器之间的网络带宽应在ADSL的带宽环境以上。

**二、**网络辅助平台服务器运行环境

1. 软件环境

操作系统：

Microsoft Windows 2000 Server

Microsoft Windows 2000 Advanced Server

Microsoft Windows Server 2003

数据库：

Microsoft SQL Server 2000、Microsoft SQL Server 2005

Microsoft. NET Framework 1.1

2. 硬件环境

CPU：服务器CPU，P4 2.0G以上

硬盘：SCSI硬盘，至少10G剩余硬盘空间

内存：2G或以上

光驱：CD-ROM驱动器

硬件：USB接口

3. 安装注意事项

出于安全性的考虑，在安装网络辅助平台之前，请以具有系统管理员权限的身份登录。另外，请确认安装了全部网络辅助平台的所有操作系统以及必须安装的最新操作系统补丁。

如果是Windows 2000 Server，请确认安装了SQL Server 2000及其最新相关补丁程序，以避免网络病毒侵入系统。

到目前为止，至少要给系统要打上Windows 2000 Service Pack 4、SQL2000 Service Pack 4、IIS 相关的补丁。

**三、**（PC版）客户端软、硬件配置环境

1. 软件环境

Windows操作系统：

Microsoft Windows 98及以上操作系统（Microsoft Windows 2000 系列、Microsoft Windows XP、Microsoft Windows Server 2003）

2. 硬件环境

CPU：PⅢ/赛扬700以上处理器

显卡：支持DirectX7以上接口

声卡：支持麦克风及录音

光驱：CD-ROM驱动器

硬盘：至少6G剩余硬盘空间

内存：512M或以上

**四、**NC机的厂商选择及软、硬件环境

（一）NC机的厂商选择

1. 目前通过我们测试的适用《新时代交互英语》的“网络透明计算机（NC机）”有湖大远程一个品牌，建议使用该厂商生产的NC机。

注意：社会上还有其他品牌的所谓“NC机”和“无盘工作站”，它们与上述“透明计算机”有本质的区别，没有经过我们的测试，不能保证适用于《新时代交互英语》网络版教学系统，请学校确认后采购，以免造成不必要的损失。

2. 测试过的NC系统使用的平台为：Windows98、Windows2000。

（二）NC服务器的软硬件环境

原则上我们不建议用户在NC服务器上安装网络辅助平台，如果用户一定在NC服务器上安装网络辅助平台，那NC服务器的软硬件配置要达到新时代交互英语网络辅助平台服务器软硬件安装环境。

（三）NC学生机软、硬件环境

1. 软件环境

Microsoft Windows 98及以上操作系统（Microsoft Windows 2000 系列、Microsoft Windows XP、Microsoft Windows Server 2003）。

2. 硬件环境

CPU：赛扬CPU，1.0G以上

显卡：支持DirectX7以上接口

声卡：支持麦克风及录音

网卡：10M及以上

硬盘：NC服务器上至少有10G以上硬盘空间安装客户端程序，至少能给每个NC用户分配50M以上的独立存储空间

内存：128兆或以上

3. 安装注意事项

1）安装客户端的机器系统盘能够临时写入文件；

2）每个NC用户有独立的使用空间，方便写入个性化的录音文件；

3）操作系统能够安装Java、Soap、QuickTime、Shockwave、MediaPlayer软件；

4）NC客户端与NC服务器之间的网络连接在100M以上。

**五、**其他

对于Vista操作系统能否正常安装使用《新时代交互英语》客户端学习系统，目前尚未得到正式测试。

《大学体验英语》教学软件系统

《大学体验英语》教学软件系统的安装分为三部分：一是教师端的安装，二是学生端的安装，三是自动更新服务器的安装。教师端、学生端及自动更新服务器互联组成一个局域网，教师端记录学生学习的全部信息，如登录时间、学习时长、听力成绩、口语成绩、学习进度等等；学生端安装《大学体验英语》教学软件系统的全部学习素材；自动更新系统连接Internet 分别为学生端和教师端下载最新的升级程序并自动更新教师端软件和每一台学生端软件。

《新视野大学英语》教学软件系统

新视野大学英语教学软件系统是在Unix系统下开发的支持多平台运行的教学管理平台，运行本系统需要服务器端和客户端的软硬件配置达到系统所需的基本要求。服务器端是保障系统运行和进行日常维护的平台，客户端是供学生、教师和管理员进行学习和教学管理的平台。服务器端和客户端需通过局域网环境连接起来才能正常运行。详细的系统软硬件配置要求如下：

**一、**服务器软硬件配置要求

硬件配置要求：

第一方案：支持并发数200以下

CPU：至强2.8G ×2

内存：2G

硬盘：72G SCSI×3 Raid 5

网卡：1000M

UPS：支持700瓦服务器工作一小时

第二方案：支持并发数800以下

CPU：至强 2.8G ×4

内存：4G

硬盘：72G SCSI ×6 Raid 5

网卡：1000M 双网卡

UPS：支持700瓦服务器工作一小时

补充说明：

1. “并发数”指同一时间点最多承载的动态在线人数，而不是指账号或用户数。

2. 硬盘空间的大小根据学校上传文件大小和数量的具体需求而定。学校上传资源的需求大则对硬盘空间需求大，反之类推。

软件配置要求：

操作系统：Windows 2000/2003 Server；Unix（Redhat Linux 9.0及以上版本、FreeBSD 4.11及以上版本）

**二、**客户端软硬件配置要求

硬件配置要求：

Pentium Ⅲ及以上处理器

100M网卡

显示器支持800*600及以上分辨率

256 MB内存

1000MB以上硬盘空间

64倍速CD-ROM光驱

32MB RAM以上显卡

16 bit以上、支持Windows操作系统的声卡

软件配置要求：

Windows 2000/Windows XP操作系统

IE 6.0及以上版本浏览器

支持DirectX 5.2以上的驱动程序

Microsoft Media Player 9.0及以上版本

Adobe Flash player 8.0及以上版本

Microsoft Speech Recognition Engine 4.0a及以上版本的英文语音识别系统（外研社提供）

网页录音插件（外研社提供）
