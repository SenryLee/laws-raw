# 教育部高等教育司关于公布2008年上半年精品课程师资培训计划的通知

## 教育部高等教育司关于公布2008年上半年精品课程师资培训计划的通知（教高司函［2008］36号）

各省、自治区、直辖市教育厅（教委）：

根据《关于实施精品课程师资培训项目的指导意见》（教高司函〔2007〕175号）的要求，为进一步推进高等学校精品课程建设工作，使国家精品课程发挥应有的示范作用，促进优质教学资源的广泛应用和共享，不断提高高校教师的教学水平，2008年继续开展精品课程师资网络培训工作。经研究，现将2008年上半年国家精品课程师资培训计划公布如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |

| 2 | 法理学 | 3月28日-30日 | 张文显（吉林大学） |

精品课程师资培训项目以精品课程的教学经验、理念、技术和方法为主要培训内容。培训对象为高等学校承担与所开课程相同或相近教学任务的在职教师。主讲教师主要由国家精品课程项目主持人和高等学校教学名师奖获奖教师担任。4月15日-16日举办的精品课程建设专题培训高级研修班的主要培训对象为教学管理人员和开展精品课程建设的教师等。

精品课程师资培训的主播教室设在教育部全国高校教师网络培训中心（设在高等教育出版社），在各分中心设网络教室（见附件）。拟参加培训的教师在网培中心网站http：//www.enetedu.com上登记报名，优先选择本行政区域的培训地点参加培训。

对经学校有关部门推荐参加精品课程师资培训的教师，考评合格后颁发由我司和人事司共同签章的“高等学校骨干教师培训证书”。对参加培训并获得证书的教师，所在学校应承认其接受继续教育的经历，记入相关档案，并作为教师职务评聘的参考依据之一。

研修班的具体通知由网培中心另行发出，相关信息同时在网培中心网站上予以公布。

2008年下半年开展的培训课程计划为：材料科学与工程基础、Visual Basic程序设计、数字信号处理、自动控制原理、大气污染控制工程、植物学、诊断学、内科学、普通心理学、现代生物学导论、数学物理方法、电磁学、概率论、物理化学、会计学、财务管理、人力资源管理、国际金融学、计量经济学、管理信息系统、市场营销学、行政管理学、财政学、中国传统文化概论、民法学、大学语文、中国现当代文学史、哲学通论等。

请各省、自治区、直辖市教育厅（教委），按照《关于实施精品课程师资培训项目的指导意见》的相关规定和要求，积极组织安排教师参加培训，并将此文转发本地所有高校。
