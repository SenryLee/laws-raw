# 教育部高等教育司关于批准大学生创新性实验计划研究项目立项的通知

## 教育部高等教育司关于批准大学生创新性实验计划研究项目立项的通知（教高司函[2008]17号）

有关高等学校：

为更好地推动大学生创新性实验计划工作的开展，加强对大学生创新性实验计划的研究和指导，经研究，我司批准以下课题项目立项，具体如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 项目名称 | 项目牵头学校 | 项目参与学校 | 项目负责人 | 经费 |
| 以创新实验为平台的大学生创新教育体系的构建 | 中南大学 | 清华大学、北京大学、华中科技大学、北京理工大学、中国农业大学 | 陈启元 | 3万 |
| 大学生创新性实验计划的组织实施过程管理研究 | 东南大学 | 南京大学、浙江大学、中南大学、同济大学、大连理工大学 | 郑家茂 | 3万 |

项目起止时间为2007年9月至2008年9月，纳入高等学校本科教学质量和教学改革工程项目中进行管理，项目结束后由我司组织验收。

请你们按照项目任务书中所列的研究计划，认真做好项目的组织管理工作，严格管理项目经费，确保高质量按时完成项目的研究任务。希望有关高等学校高度重视立项项目的研究与实践工作，给予必要的政策和不少于1：1配套经费支持，确保立项研究取得实质性进展和较大成果。

教育部高等教育司　

二〇〇八年一月十五日
