# 教育部高等教育司关于批准国家精品课程研究项目立项的通知

## 教育部高等教育司关于批准国家精品课程研究项目立项的通知(教高司函[2008]225号)

有关高等学校：

为了进一步做好国家精品课程建设工作，加强对国家精品课程建设的研究指导和管理，经研究，我司批准以下项目立项：

|  |  |  |  |
| --- | --- | --- | --- |
| 项目名称 | 承担院校 | 主持人 | 经费（万元） |
| 本科国家精品课程指标体系的研究与修订 | 华中科技大学 | 许晓东 | 3 |
| 国家精品课程建设规划研制 | 大连理工大学 | 李志义 | 3 |
| 国家精品课程复核的政策分析 | 华中科技大学 | 周光礼 | 3 |
| 高等职业院校精品课程建设机制的研究与实践 | 成都航空职业  技术学院 | 熊 熙 | 3 |
| 高校网络教育精品课程指标体系的研究与实践 | 北京师范大学 | 黄荣怀 | 3 |
| 网络教育精品课程申报与评审系统的开发与维护 | 北京交通大学 | 陈 庚 | 3 |

项目起止时间为2008年10月至2009年10月，纳入“高等学校本科教学质量和教学改革工程”项目中进行管理，项目结束后我司组织验收。

请你们提交项目任务书，按照研究计划，认真做好项目的组织管理工作，严格管理项目经费，确保高质量地按时完成项目的任务。希望有关高校高度重视立项项目工作，给予必要的政策和不少于1：1配套经费支持，确保立项项目按时保质完成任务。

教育部高等教育司

二〇〇八年十月二十二日
