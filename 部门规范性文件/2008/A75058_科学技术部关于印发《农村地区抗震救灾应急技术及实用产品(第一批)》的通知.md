# 科学技术部关于印发《农村地区抗震救灾应急技术及实用产品(第一批)》的通知

## 科学技术部关于印发《农村地区抗震救灾应急技术及实用产品（第一批）》的通知

为贯彻落实党中央、国务院对抗震救灾工作的部署和要求，充分发挥科技在抗震救灾中的作用，科技部在认真分析四川地震灾情的基础上，针对地震灾区抗震救灾的迫切需要，组织多学科专家认真筛选适合灾区当前抗震救灾工作应急技术和产品，从农村民居、农村安全饮水、动物疫病防治、农业生产应急恢复等四个方面筛选出一批应急适用技术和产品，现作为第一批农村地区抗震救灾应急技术及实用产品予以发布。为了使这些实用技术和产品尽可能方便地为灾区服务，除了对技术和产品进行介绍外，还特别提供了相关生产厂商和技术持有者的名单以及联系方式。由于时间匆促，难免还有不当之处，我们将根据有关部门、地方的需要和反馈，对实用技术和产品进行及时更新和补充。

**一、**地震灾害后村镇重建规划技术

（一）功能与用途

用于地震灾害后镇、乡和村庄规划的综合防灾规划技术。

（二）技术要点

1、城镇体系规模等级与镇乡村布局规划技术：对于高震区或地震多发区的镇、乡和村庄，在确定体系等级规模与布局时应充分考虑地震危害影响，参照该区域抗震设防标准，经济合理的确定高震区域多震区的镇、乡和村庄规模，有条件的应逐步迁出上述地区，选择安全地带异地重建，不宜在上述地区新增镇、乡和村庄数量或继续扩大其规模。

2、建设用地选择与用地布局技术：城镇建设用地选择应充分考虑地震环境因素，不应在有断层活动、断裂带发育或有地震次生灾害发生影响地段内进行建设。对于地震动峰值 ≥ 0.4的地区（10度区）不宜作为城镇建设用地。

在城镇建设用地布局上，应充分考虑地震次生灾害的可能影响，对易产生次生灾害源的工厂、仓库等要害建筑应布局在城镇主要城区外围并与居住区保持足够的安全距离。商场、学校、医院、剧院等人流集中的公共服务设施、医疗卫生设施用地应选址于场地稳定、无滑坡、崩塌、泥石流等不良地质灾害潜在危险影响的地段内。

3、城镇绿化用地规划技术：城镇绿地系统规划应充与避灾疏散场所规划相结合，应根据有关规定设置必要的紧急避难设施。作为避灾疏散场所使用的公园绿地应选择在场地稳定、无不良地质灾害潜在影响的地段内，并应保证至少有两个以上的不同方向出入通道。

4、城镇基础设施建设与生命线工程：对于关系到城镇居民生命财产安全的通讯、供电、供水、供热、燃气、消防等生命线工程，以及中小学、幼儿园、医院等重要公共服务设施应提高相应抗震设防等级，以减少重大灾害情况下的人员伤亡与财产损失。

5、城镇道路规划技术：城镇道路系统规划除应满足一般情况下的通行需要，还应充分考虑震灾影响，规划中应结合城镇道路系统规划确定主要避灾疏散通道位置，作为避灾通道使用的城镇道路，其红线宽度应满足必要的有效宽度使用要求，满足人员疏散、紧急救护、物资运输等需求。

镇、乡和人口大于200人以上的村庄应至少保持两个以上不同方向的出入通道。

**三、**羌族传统民居保护与恢复技术

（一）功能与用途：

对我国羌族最主要的聚居地岷江地区列为各级文物保护单位的羌族独特的传统建筑遗产，包括民居、碉楼等进行保护与恢复。

（二）技术要点

1、民居

（1）建造形式与居住功能：羌族建筑一般多为碉式建筑，又称碉房或碉楼。建筑无一定朝向，一般依山势而建、背山面川。单体住居平面呈长方形，外墙石砌，室内木构；住居外观基本不着色。若建房用地毗连时，建筑多为3～4层：底层为牲畜圈和厕所，二层为起居层，以石台阶与室外相连，三层为储藏层，四层为晒台和储藏间，建筑层高较低。若建房用地较宽畅时，建筑多数为独立的二层楼，坡屋顶与平屋顶结合；碉房首层为堂屋、厨房等房间，设有少量卧室，二层用于居住及储物，屋顶平台用于晒粮及室外活动；牲畜围圈多单独设置。

（2）建筑材料与工艺：羌族民居的建造与修复材料，主要包括石材（天然块石、片石、卵石为主）、木材（用于梁架、楼层等处）和黄土（用于夯筑墙体、石材砌筑、楼面铺设等）；传统的外墙建造工艺可分为以垒石与夯土2大类，内部结构以木构为主。

2、碉楼

（1）羌族的碉楼是我国拥有2000余年历史的珍贵的文化遗产，又称“羌碉”，分为石碉（用石块垒砌的）和土碉（用粘土夯筑而成的）2大类，平面以四角为主，另有少量六角、八角、十一角和十三角。

（2）羌碉在造型特色和砌筑工艺上与藏碉有一定区别，一般在四角碉顶部靠后部有升起的照楼，碉楼背部有鱼脊状突出。

（4）碉楼中有经堂、壁画或其他特殊功能的应采取重点保护措施。

3、保护措施：

（1）凡属于各级文物保护单位的建筑（群）、碉楼和村寨一律按照文物保护要求实施保护措施、执行报批程序。

（3）其他非传统建筑的修复应尽可能在外观上与传统建筑和谐，尽可能少用石棉瓦等现代简易材料，避免不和谐景观。

1、突击排涝降渍，及时清沟整畦。地震会损坏田间排灌设施，而且地震后常伴随大雨，因此受淹受渍田块要及时疏通积水，降低水位，尽量缩短受淹的时间。在土壤墒情适宜时要及时扶茬壅根并做好田间松土和杂草的清除工作

2、清理菜地，分类处理。受灾严重的菜地要立即清理烂菜死菜，沙质土壤的菜地可马上整地起畦抢播抢种或移植菜苗，粘土为主的菜地待水退后稍微晒干再整地起畦播种或移植菜苗。

3、多种早种速生菜。一是抓紧时间直播一批速生早熟叶菜类蔬菜，如苋菜、小白菜、空心菜、木耳菜等。这些蔬菜宜采用直播，不移植，20天后可以上市，丰富市场供应。二是播种早熟大白菜、早萝卜、早花菜等品种，做到提早上市、缩短“伏缺”时间，增加经济收入。

4、加强肥水管理。灾情较轻的菜地要加强现有蔬菜的肥水管理，种植叶菜类蔬菜以氮肥为主，薄施勤施；种植瓜类、茄果类、豆类蔬菜应该氮、磷、钾肥配合使用。

5、注意病虫害发生，慎用农药保安全。地震后的暴雨易引起蔬菜病害，应迅速喷洒一至二次灭菌清、多菌灵、托布津之类的杀菌剂，防止病菌从伤口侵入；如发现虫害应喷施杀虫剂，但严格禁止使用甲胺磷等农药。

6、使用防虫网和遮阳网覆盖技术。遮阳网有遮强光、降温、保湿和防暴雨的作用，防虫网防虫效果明显，是种植夏季反季节蔬菜的先进技术。一般采用播种后及时覆盖，移植菜苗时覆盖，阳光强烈时覆盖和暴雨来临前覆盖等方法。

7、加强基础设施建设，完善菜地水利设施，健全排灌系统。要保证大明沟、腰沟、围沟、畦沟四沟配套、畅通，做到旱能灌，涝能排，保证蔬菜生长的适宜条件。

**二、**地震灾害后高山蔬栽培管理要点

（一）功能与用途

快速恢复蔬菜生产、确保蔬菜市场供应

（二）技术要点

此次地震灾害给我国四川等地生活和生产造成了前所未有的损失，尽快恢复蔬菜生产是灾区灾后重建的重要环节。由于四川是我国高山蔬菜的重要产区，特此简述近阶段高山蔬菜生产应注意的几个方面供参考。

1、选择适宜品种：海拔1200-1800米的高山地区，主要以喜冷凉的十字花科蔬菜（萝卜，结球甘蓝、大白菜）为主，目前正处于播种阶段，选择耐低温抽薹的适宜品种是关键。萝卜品种如天鸿春、雪单1号、汉白玉、千首大根、阳春白雪、金阳春等；大白菜如高冷地、山地王新观春、改良京春白等；甘蓝京丰1号、铁球、署王、冠军、中甘18和中甘21等。

海拔800-1200米的二高山地区，主要以喜温的的茄果类蔬菜（番茄、辣椒、茄子）、豆类（四季豆、豇豆）、瓜类（黄瓜、丝瓜、瓠子、小南瓜）、甜玉米等为主，目前正处于苗期或定植期。未播种或受灾严重的还可补播。一般选择耐贮运，抗病、商品性状优良的品种。辣椒如中椒6号、佳美、超大椒王、中椒106、早杂2号；番茄如鸿福4号、中蔬9号、以色列绿枝；四季豆如美国供给者、双青玉豆王等。

2、培育壮苗和病害防治：萝卜采用直播方式，大白菜采用营养块育苗，甘蓝采用有机质苗床育苗。高山大白菜起苗后用链霉素、氯氰菊酯和乐斯本等杀虫杀菌剂喷根部，或用链霉素1包兑1桶药水沾根。高山甘蓝育苗期间加强管理，防止病虫害如猝倒病、立枯病及小菜蛾等危害，定植前一周揭开所有覆盖物炼苗，进行耐低温或高温、干旱锻炼，苗龄30-40天左右，当植株长到4-5片真叶时定植到大田。

茄果类苗期主要注意防止疯长，防治细菌性疮痂病。在定植前l～2天，秧苗用65％代森锌500倍或50％多菌灵1000倍液喷施，使幼苗带药带土到田。

**三、**番茄快速育苗技术

（一）功能与用途

缩短番茄种植周期，提早成熟，提高资源利用率和生产效益。

（二）技术要点

1.　穴盘选择。一般选用72孔或50孔塑料穴盘，即每盘可育苗72株或50株。

2.　基质准备。根据番茄定植需苗量，准备塑料穴盘数量。按每1000盘72孔穴盘用基质4～5立方米配制混合基质。

3.　基质配制。草炭∶蛭石＝2∶1或草炭∶蛭石∶废菇料＝1∶1∶1（全部为体积比），覆盖料用蛭石。

4.　施肥方法。每立方米混合基质加入15∶15∶15氮、磷、钾三元复合肥2.5千克，或每立方米基质加入1.2千克尿素和1.2千克磷酸二氢钾，肥料与基质混拌均匀后备用。苗期三叶一心后，可结合喷水进行1～2次叶面喷肥。

5.　种子处理。用50～55℃温水浸种20分钟，换20～30℃水浸种4～5小时，然后播种、催芽。或播前用10％磷酸三钠水溶液浸种20分钟，然后用清水将种子上的药液冲洗干净，换20～30℃水浸种4～5小时，再催芽播种。

6.　播种深度。1.0厘米左右为宜。

7.　水分管理。播种后，将育苗基质喷透水（穴盘排水孔有水珠溢出），使基质持水量达到200％以上；苗期子叶展开至2叶1心，水分含量为持水量的65～70％；3叶1心至成苗，水分含量保持在60～65％。

8.　温度管理。催芽期间，室内温度可保持25～27℃，预计3～4天出苗。当苗盘中60％出苗，即可将苗盘摆放进育苗温室。日温25℃，夜温16～18℃为宜。当夜温偏低时，可采用地热线加温或其它临时加温措施（烟道加温或热风炉加温等），以免影响出苗速率和出现猝倒病。二叶一心后夜温可降至13℃左右，但不要低于10℃。白天酌情通风，降低空气相对湿度。

9.　病虫害防治。番茄苗期主要病害是猝倒病、立枯病、早疫病、病毒病。虫害为蚜虫、白粉虱。

（1） 防治猝倒病、立枯病：播前进行基质消毒，控制浇水，浇水后放风，降低空气湿度。幼苗期夜温不得低于10℃，发病初期喷洒百菌清、多菌灵、代森锌800倍液等。

（2） 防治早疫病：播前用福尔马林进行种子处理，发病初期喷施百菌清、代森锌、波尔多液、利得等。

（3） 防治病毒病：播前用10％的磷酸三钠水溶液浸种20分钟，取出冲洗干净。在苗期注意遮阴降温，防止基质含水量过大。

（4） 防治蚜虫：喷施乐果乳剂、功夫乳油、好年冬、虫螨克、绿浪，还可用灭蚜乳油加上发烟剂进行熏烟，效果比直接喷药好。

（5） 防治白粉虱：可喷施扑虱灵、功夫乳油、绿浪或1％溴氰菊酯施放烟剂，还可进行黄板诱蚜。

10.　补苗和分苗。

采用穴盘育苗时，应在第一片真叶展开时，观察幼苗出苗情况，发现缺苗时抓紧将缺苗孔补齐。用72孔穴盘育番茄苗，也可以先播在128孔或288孔苗盘内，当小苗长至一片真叶时，移至72孔苗盘内，这样可有效利用温室面积，减少能耗。

11.　成苗标准。株高15～18厘米，茎粗4.5毫米，叶面积在90～100平方厘米，6～7片真叶，苗龄50～60天。

**四、**西瓜快速育苗技术

（一）功能与用途

缩短西瓜种植周期，克服逆境为害，提早成熟，提高资源利用率和生产效益。

（二）技术要点

1.　育苗基质

常用的育苗基质有泥炭、珍珠岩、蛭石、蘑菇渣等，配方为：草炭：珍珠岩（粒径3毫米）比例为7：3或蘑菇渣：草炭比例为3：1，每立方米基质加入15∶15∶15氮、磷、钾三元复合肥2.0千克和2.0千克膨化鸡粪，混拌均匀，用福尔马林100倍液熏闷2天消毒，敞开通风2天后，即可装盘。穴盘用72孔塑盘或泡沫塑料盘，也可用8厘米×8厘米营养钵。装料时，用筛去除结块基质和鸡粪，育苗基质装至孔穴3／4为宜并振实。

2．播前处理

（1）　晒种与选种：播前做好晒种工作，也可在35℃恒温通风烘种48小时，人工或盐水选种，并做好种子发芽率试验。根据种子发芽率增加5～10％来确定用种量。

（2）　灭菌与浸种：一般将种子进行55℃温汤浸种或福尔马林100倍液消毒15分钟，清洗后用温水（25℃左右）浸种3～4小时。

（3）　催芽：将种子用洁净半湿纱布或毛巾包裹，置30～32℃恒温箱内催芽，每日早晚清洗种子2次。挑出露白种子播种。一般新种子催芽16小时左右露白，如种子破口正遇晚上，应经常检查，或及时调低催芽温度至25℃。

（4）　播种：采用播种流水线作业，不需浸种和播前催芽，直接进行干籽播种。人工播种时，播种前1天润湿基质，将种子平放于穴内，1穴1粒，发芽较长的种子直插于穴内，上覆1.0～1.5厘米厚蛭石。

3.　幼苗期管理

（1）　催芽：将播种好的穴盘放入催芽室中，控制室温30～32℃，相对湿度90％左右，用喷淋系统保持育苗基质湿润。用干籽播种，西瓜出苗一般需要3～4天；如用已经催芽后的种子播种，出苗时间约为2天。当多数幼苗子叶出土时，将育苗盘移至绿化室。

（2）　绿化：绿化室的温度白天掌握在24℃～27℃，夜间18～20℃。阴、雨天温度降低3℃。穴盘中培养基质较少，应及时酌情喷水。子叶充分展开时绿化结束，西瓜苗春季绿化一般需要7天。

4.　苗期管理

西瓜第1片真叶展开后，白天升温至28℃～30℃，并用无土栽培营养液（EC值0.8～1.2）每隔7天浇1次；每平方米安装60W白炽灯进行补光至16小时，每增加1片真叶，缩短1小时补光时间，促进雌花形成和分化。出苗前7～10天降温（白天20℃、夜间15℃），控肥控水，进行炼苗。

5.　出苗

穴盘育苗一般时间比较短，当西瓜幼苗达到4叶1心时，即可出苗大苗，苗龄约30～35天。出苗前1天用清水浇透基质，用专用起苗器或竹片轻轻起苗，不可拔苗，以免伤根和散坨。起苗后及时按规格装箱，搬运时应小心轻放。
