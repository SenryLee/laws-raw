# 公开市场业务交易公告2008年第61号――发行2008年第九十三期、第九十四期央行票据并开展正回购操作

## 公开市场业务交易公告（2008年第61号）

人民银行于本周四（8月14日）以价格（利率）招标方式发行了2008年第九十三期、第九十四期央行票据，并开展了正回购操作。具体情况如下：

第九十三期、第九十四期央行票据发行情况

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 名称 | 发行量 | 期限 | 价格 | 参考收益率 |
| 2008年第九十三期央行票据 | 410亿元 | 3个月  （91天） | 99.16元 | 3.3978% |
| 2008年第九十四期央行票据 | 40亿元 | 6个月  （182天） | 98.19元 | 3.6969% |

正回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 28天 | 300亿元 | 3.20% |
