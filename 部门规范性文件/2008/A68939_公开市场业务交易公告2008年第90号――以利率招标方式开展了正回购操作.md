# 公开市场业务交易公告2008年第90号――以利率招标方式开展了正回购操作

## 公开市场业务交易公告（2008年第90号）

人民银行于本周二（12月2日）以利率招标方式开展了正回购操作。具体情况如下：

正回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 28天 | 100亿元 | 1.61% |

此外，自本周起暂停发行1年期中央银行票据。

中国人民银行公开市场业务操作室

二○○八年十二月二日
