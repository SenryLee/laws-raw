# 中华全国供销合作总社关于2008年全国供销合作社系统职教本科师资班招生考试地点的通知

## 中华全国供销合作总社关于2008年全国供销合作社系统职教本科师资班招生考试地点的通知（供销科教字[2008]17号）

各省、自治区、直辖市供销合作社，山西财经大学、安徽财经大学、山西大学商务学院：

根据全国供销合作总社科技教育部和教育部高校学生司联合印发的《关于做好2008年全国供销合作社系统中等职业学校职教本科师资班招生工作的通知》（供销科教字[2008]1号）的精神，2008年供销合作社系统职教本科师资班招生考试定于2008年5月10日至12日在河南省郑州市进行。现将具体事宜通知如下：

**一、**考试地点：河南省财经学校（郑州市优胜北路3号）

**二、**考试时间：

|  |  |  |  |
| --- | --- | --- | --- |
| 时 间 | 5月10日 | 5月11日 | 5月12日 |
| 上午9：00---11：00 | 语文 | 外语 | 面试 |
| 下午 2：30---4：30 | 数学 | 面试 | 面试 |

**三、**报到（领准考证）时间、地点：2008年5月9日下午2点至6点在河南宾馆大堂

**四、**考生注意事项：

1、考生报到时领取《准考证》，同时交纳300元报名考试费。

2、考生必须携带《身份证》、《学生证》和《准考证》进入考场。

3、考生食宿统一安排在河南宾馆（郑州市金水路26号），考生自行登记入住，费用自理。

4、乘车路线：从郑州火车站乘K6路或34路、21路公交车至新通桥站下车，沿金水路向西200米路北即到（郑州七中西边）。从郑州机场乘机场大巴至郑州民航大酒店下车，再乘出租车至河南宾馆（车费8元），或从机场乘出租车直接至河南宾馆（车费100元左右）。

从河南宾馆去考场路线：由宾馆出门左转沿健康路向北至优胜北路再向西100米即到河南省财经学校。
