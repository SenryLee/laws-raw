# 国土资源部中央地质勘查基金管理中心公开选择评估机构承担2006年中央地质勘查基金试点矿业权评估项目结果的公告

2008年11月7日，按照规定的程序，国土资源部中央地质勘查基金管理中心在北京举办了“试点探矿权评估项目委托机构现场选择会”，国土资源部储量司评估处有关领导亲临现场指导，34家有效报名承担地勘基金评估项目的矿业权评估机构到现场参加摇号。

为保证公平、公正，在现场首先由评估机构的代表随机抽取各自机构的数字代号，然后进行计算机摇号，摇号过程按照有关规定实施，结果如下：

|  |  |  |
| --- | --- | --- |
| 项目编号 | 项目名称 | 中选机构名称 |
| 2007521001 | 贵州省册亨县百地金矿普查 | 北京汇贤达评估咨询有限公司 |
| 2007151010 | 内蒙古自治区东乌珠穆沁旗塔尔巴格吐铜多金属矿及外围普查 | 北京地博资源科技有限公司 |
| 2007221001 | 吉林省柳河-安口镇一带金矿普查 | 北京山连山矿业开发咨询有限责任公司 |
