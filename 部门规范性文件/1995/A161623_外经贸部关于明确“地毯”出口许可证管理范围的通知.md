# 外经贸部关于明确“地毯”出口许可证管理范围的通知

## 外经贸部关于明确“地毯”出口许可证管理范围的通知（１９９５年２月１０日）

各省、自治区、直辖市及计划单列市外经贸委（厅），外经贸部驻各地特派员办事处，配额许可证事务局，各进出口商会、协会，各总公司，工贸公司：

根据招标工作的需要，现将“地毯”的商品编码和管理范围明确如下：

```
顺序号　　商品名称　　　　　　　　商品编码　　　　　　计量单位

５０　　地毯：

羊毛结织栽绒地毯　　　　５７０１１０００　　平方米

其他材料结织栽绒地毯　　５７０１９０００　　平方米

“开来姆”等手织地毯　　５７０２１０００　　平方米

制成的起绒地毯　　　　　７０２４０００　　　平方米

制成的非起绒地毯　　　　５７０２９０００　　平方米

羊毛簇绒地毯　　　　　　５７０３１０００　　平方米
```

以上商品均占“地毯”出口招标配额。部计算中心将制作新的商品库软盘下发，各发证单位应严格按计算中心要求装入计算机。在签发“地毯”出口许可证时，需严格按照外经贸部出口商品配额招标办法及其实施细则的有关规定，凭中标企业名单、企业中标数量、协调价格、《申请配额有偿招标商品出口许可证证明书》签发出口许可证。如发现问题，请及时与部对外贸易管理司联系。
