# 财政部关于免征中国乐凯胶片集团公司进口自用二手设备进口税收的通知

## 财政部关于免征中国乐凯胶片集团公司进口自用二手设备进口税收的通知（财税[2001]218号　2001年12月21日）

海关总署：

经国务院批准，对中国乐凯胶片集团公司在规划投资总额内进口价值120万元英磅和38万美元的自用二手设备，即照相原纸造纸设备和片环实验涂布机，免征关税和进口环节增值税。

请通知有关海关遵照执行。
