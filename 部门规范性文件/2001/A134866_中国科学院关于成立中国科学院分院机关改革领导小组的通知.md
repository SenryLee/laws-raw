# 中国科学院关于成立中国科学院分院机关改革领导小组的通知

## 中国科学院关于成立中国科学院分院机关改革领导小组的通知（科发人教字[2001]280号）

院属各分院、院机关各部门：

经院党组同意，决定成立中国科学院分院机关改革领导小组(以下简称：领导小组)。

领导小组组长：杨柏龄　副组长：郭传杰　何岩

领导小组成员：李志刚　赵勤　蒋崇德　黄海霞

分院机关改革领导小组办公室设在人事教育局，办公室主任由黄海霞兼任。

中国科学院

2001年7月24日
