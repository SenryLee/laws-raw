# 文化部关于文化信息资料上网的通知

中华文化信息网是文化部主办的行业性政府网站。为了全面反映我国各地文化工作的成绩和取得的进展，根据部领导关于加强中华文化信息网内容建设的指示精神，现将有关文化信息上网工作的要求通知如下：

**一、**上网范围

文化系统县级以上(含县级)文化单位。

**二、**上网方式

除有条件的省(区、市)文化厅局自建文化信息网外，所有需上网的单位，请将所需上网内容加盖本单位公章后直接寄送文化部办公厅中华文化信息网收。中华文化信息网免费制作上网。

**三、**上网内容

1、各省、地(市)、县(市)2000---2001年文化工作综述(1000---3000字)

2、各地重大文化节庆活动介绍

3、2000--2001年度受省级及省级以上表彰的文化工作先进单位、先进个人事迹

4、各地关于文化工作、文化调研的成果

5、各地重要文化资源及可开发利用资源介绍

6、各地特色文化产品、文化品牌介绍

7、各地文化单位基本情况简介(500字以内，包括负责人简历、照片、联系方式等

)
