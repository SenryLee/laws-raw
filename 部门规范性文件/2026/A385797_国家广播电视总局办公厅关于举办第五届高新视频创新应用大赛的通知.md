# 国家广播电视总局办公厅关于举办第五届高新视频创新应用大赛的通知

广电办发〔2026〕250号

各省、自治区、直辖市广播电视局，新疆生产建设兵团文化体育广电和旅游局，广电总局直属有关单位、各实验室依托单位，中央广播电视总台办公厅、电影频道节目中心、中国教育电视台，各网络视听平台，有关科研院所、高校，有关行业协会，有关企事业单位：

为深入贯彻落实习近平文化思想和习近平总书记关于科技创新重要指示批示精神，充分发挥高新视频技术优势，聚焦用户体验提升，推动高新视频在视听领域的创新应用与产业成熟，赋能行业高质量发展，广电总局决定举办第五届高新视频创新应用大赛。现将有关事项通知如下：

**一、**主办单位及时间

主办单位：国家广播电视总局

承办单位：中国广播电视社会组织联合会

活动时间：2026年10月至2027年4月

**二、**赛道设置

本次大赛聚焦高新视频领域，按照技术突破、场景创新2个板块，共设置7个赛道。大赛将围绕技术先进性、场景适配性、用户体验提升、产业推广价值等方面，遴选技术质量优、创新性强、可落地推广的高新视频创新应用项目。

（一）技术突破

技术突破板块分为高新视频制播、传输分发、虚拟采集与制作3个赛道，具体申报要求如下：

1.高新视频制播

面向内容制播场景，依托云化、软件化、IP化系统架构，融合高新视音频新技术，实现制播流程敏捷化、业务能力弹性扩展，适配多元内容快速生产与融合播出。

2.传输分发

面向高码流、高质量、稳定可靠的传输需求，依托5G、卫星、边缘CDN等基础设施，实现低时延、高可靠、带宽高效利用的端到端传输与内容分发。

3.虚拟采集与制作

面向虚拟视听内容生产创作需求，依托虚拟拍摄、LED实时渲染、虚实融合等技术，提升虚拟视听内容生产效率与画面质量，产出4K/8K超高清虚拟类成果。

（二）场景创新

场景创新板块分为文旅文博场景创新、体育与演艺场景创新、教育科普场景创新、智慧生活与商务场景创新4个赛道，具体申报要求如下：

4.文旅文博场景创新

依托超高清、VR/AR/MR、沉浸式、互动视频技术，面向旅游景区、文博场馆、文化遗址、非遗体验空间等场景，评选超高清+文旅、VR/AR导览、沉浸式文博展示、数字文物复原等融合应用项目。

5.体育与演艺场景创新

依托超高清、VR/AR/MR、沉浸式、互动视频技术，面向体育场馆、赛事现场、剧院剧场、演艺新空间等场景，评选超高清体育转播、自由视角/多视角观赛、VR赛事直播、沉浸式演艺（含球幕/环幕舞美）等融合应用项目。

6.教育科普场景创新

依托超高清、VR/AR/MR、沉浸式、互动视频技术，面向学校课堂、科普场馆、理论宣讲阵地等场景，评选超高清理论宣传节目、VR实训模拟、沉浸式科普体验、互动教育视频等融合应用项目。

7.智慧生活与商务场景创新

依托超高清、VR/AR/MR、沉浸式、互动视频技术，面向智能座舱、智慧家庭、电商直播、远程商务等场景，评选超高清车载显示、沉浸式智慧家庭体验、互动电商直播等融合应用项目。

**三、**工作安排及要求

大赛分为申报、预赛、决赛三个阶段。

（一）申报阶段

1.申报主体。各省、自治区、直辖市广播电视局，新疆生产建设兵团文化体育广电和旅游局及时转发通知，广泛组织本地区相关产学研用单位以法人主体名义申报。广电总局直属有关单位、各实验室依托单位，中央广播电视总台办公厅、电影频道节目中心、中国教育电视台，各网络视听平台、有关科研院所、高校、行业协会、相关企事业单位直接申报。

2.申报项目要求。每个单位牵头申报项目总数不超过10个，单个赛道申报项目不超过2个。各申报单位须对申报项目的合规性、真实性、材料完整性负责。

3.申报渠道及时间。各申报单位通过“科技视听”公众号或扫描下方二维码，获取网上申报链接，用电脑以线上方式填写提交申报信息，并上传相关证明材料。申报截止时间为2026年12月10日24:00，届时申报系统将自动关闭，逾期不予受理。请各单位合理安排时间，提前完成申报。

（二）初赛阶段

由相关领域专家审查项目申报材料，按照统一评审标准对项目技术创新性、应用成熟度、示范价值和推广前景进行综合评价，遴选入围决赛项目。

（三）决赛阶段

进入决赛的项目，需在大赛指定的时间段内进行方案阐述、视频展示、现场答辩，专家评审组对各项目进行综合评定打分，根据成绩进行排序。综合预赛、决赛得分和参赛项目整体水平，遴选出各类奖项并公示。

**四、**其它事项

同一参赛项目只能由一个完成单位牵头，不得多头申报或重复申报；一经查实，取消该项目参赛资格。如参赛项目由多个单位共同完成，相关单位须提前做好沟通协调，明确由第一完成单位作为牵头申报单位。主要完成单位不超过3个，并在项目申报书“主要完成单位”一栏内按顺序填写。因完成单位排序或申报主体产生纠纷的，取消该项目参赛资格。参赛项目主要完成人不得超过10人，且须按贡献大小排序。
