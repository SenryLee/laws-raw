# 全国银行间同业拆借中心关于变更CFETS-国泰君安主力债券指数系列名称的公告

## 关于变更CFETS-国泰君安主力债券指数系列名称的公告

中汇交公告〔2026〕1号

全国银行间同业拆借中心即日起变更CFETS-国泰君安10年期主力国债指数和CFETS-国泰君安10年期主力国开债指数名称，编制方案其余部分保持不变，具体变更内容如下：

|  |  |  |
| --- | --- | --- |
|  | 变更前 | 变更后 |
| 指数名称 | CFETS-国泰君安10年期主力国债指数 | CFETS-国泰海通10年期主力国债指数 |
| CFETS-国泰君安10年期主力国开债指数 | CFETS-国泰海通10年期主力国开债指数 |

以上变更内容即日起正式生效，可通过中国货币网（www.chinamoney.com.cn）查询。

全国银行间同业拆借中心

2026年1月4日
