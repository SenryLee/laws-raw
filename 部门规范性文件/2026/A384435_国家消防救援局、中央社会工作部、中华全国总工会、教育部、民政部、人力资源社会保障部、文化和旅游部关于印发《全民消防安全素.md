# 国家消防救援局、中央社会工作部、中华全国总工会、教育部、民政部、人力资源社会保障部、文化和旅游部关于印发《全民消防安全素质提升行动工作方案（2026—2030年）》的通知

国家消防救援局 中央社会工作部 中华全国总工会

## 全民消防安全素质提升行动工作方案（2026—2030年）

为深入贯彻国务院办公厅《关于加强基层消防工作的意见》（国办发〔2026〕6号），切实加强和改进消防宣传教育培训工作，全面提升全民消防安全素质，营造良好消防安全环境，特制定本方案。

**一、**总体要求

坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平总书记关于安全生产和消防工作的重要指示批示精神，认真贯彻落实《中华人民共和国消防法》等法规文件，大力普及消防基本常识，突出消防基本技能实操实训，开展消防疏散自救演练，强化火灾事故警示教育，努力实现人人受到消防教育、个个掌握消防技能，全面提升公民消防安全素质，筑牢防灾减灾救灾的人民防线，确保火灾形势持续稳定向好。

——公民消防安全意识进一步增强。自觉遵守消防法律法规，主动学习消防安全知识，积极参与消防培训演练，科学应对火灾险情，树立“知常识、识风险、会避险”的消防安全意识。

——公民消防基本技能进一步提高。掌握安全用火用电用气等日常火灾防范方法，学会正确报告火警、火场逃生自救及常见灭火器材使用等基本技能，具备“会发现、会报警、会自救、会扑救初起火灾”的消防安全能力。

——重点人群防控能力进一步提升。消防安全责任人和管理人员能够组织检查并督促落实火灾隐患整改工作，消防安全明白人能够及时发现并消除火灾隐患，消防控制室值班人员能够熟练操作控制室设备及联动设施，微型消防站人员和志愿消防队员能够快速响应、协同处置，一线岗位人员熟练掌握消防器材操作和人员疏散方法，具备“会查改隐患、会扑救初起火灾、会组织疏散逃生”的应急处置能力。

——公民接受消防宣传培训渠道进一步拓宽。消防科普教育基地运行管理更加规范，消防救援站开放力度持续加大，媒体多维度宣传格局进一步健全，公民获取消防知识技能的渠道更加便捷畅通，消防宣传教育逐步实现常态化，做到“宣传有平台、体验有阵地、工作有队伍、覆盖无盲区”。

**二、**主要内容

（一）消防常识普及行动

主要任务：通过消防常识普及行动，使全体公民掌握火灾报警的内容和方法，熟知报告火警的要点，养成发现火情立即拨打“119”电话的习惯；了解火灾和烟气危害知识，知晓其发生和蔓延规律，具备“小火快跑、浓烟关门”的意识；掌握灭火器材使用方法，熟知灭火器材的位置，会扑救初起火灾；了解消防产品基础知识，具备识假辨假能力；掌握火场逃生自救的技能，养成了解疏散路线和自救器材存放位置的良好习惯，树立躲火避烟的自救意识，掌握科学的火灾逃生方法。

主要措施：

1. 深化消防宣传“五进”工作。结合行业特点和生产生活实际，开展消防宣传进企业、进农村、进社区、进学校、进家庭活动，加强企业员工全员消防安全教育，推动学校将消防安全教育融入日常教学，深入落实《全民消防知识普及要点》（附件1）。

2. 构建消防安全宣传网络。依托电视、广播、报刊等主流媒体播放消防公益广告；利用社交、音频等新媒体推送消防知识；在政府门户网站、权威政务APP等平台开设消防宣传专区，发布消防知识；在影院、宾馆等场所的开机视频中设置消防安全提示；利用通信运营商短信平台发送消防公益信息；运用社区宣传栏、农村应急广播等载体开展消防知识宣传。

3. 强化消防科普教育。发挥消防科普教育基地作用，定期更新展品展项，配备专（兼）职讲解人员，常态化开展科普活动和体验培训；推动现有防灾减灾体验场所、党群服务中心等增设消防科普内容，鼓励支持社区设立消防体验场所。

4. 培育消防宣传志愿队伍。加大消防志愿者招募培训力度，实行实名注册，加强规范管理，专业化开展志愿服务；广泛吸收网格员、保安员、燃气维修员以及新就业群体等加入消防志愿服务队伍，结合业务服务同步开展入户消防宣传，通过12345政务服务便民热线、12350安全生产举报投诉电话等渠道反映身边火灾隐患；鼓励加油站、邮政、电信等连锁网点培育消防志愿宣传骨干，设置固定消防宣传点。

5. 加大消防专业权威支持。加大消防救援站向社会开放力度，接受团体及个人预约，消防救援站每月至少开放一次，消防宣传月等时间节点增加开放场次；落实消防监督人员每周半天开展消防宣传培训制度；鼓励消防救援人员在灭火救援任务完成后向群众开展宣传教育。

（二）基本技能实操实训行动

主要任务：面向单位消防安全责任人和管理人员、消防安全明白人、消防控制室值班人员、微型消防站人员和志愿消防队员以及护理人员、医务人员、保安员、保洁员等一线岗位人群，全面落实《消防基本技能实操实训指南》（附件2）要求，增强“见火不慌，抬手就灭”的意识，养成“小火会用灭火器，大火会用消火栓”的良好习惯。

灭火器操作培训。掌握灭火器的分类、适用范围及注意事项，开展“灭真火”实操练习，培养发现火情后迅速使用就近灭火器扑救的意识和能力。

消防软管卷盘操作培训。掌握其基本用途和使用方法，开展“出真水”实操练习，增强重点人员初起火灾自救的意识和能力。

室内消火栓操作培训。掌握消火栓基本用途和使用方法，开展“出真水”实操练习，强化重点人员协同配合训练，增强控制初起火灾蔓延的意识和能力。

防烟面具操作培训。掌握防烟面具（过滤式消防自救呼吸器）适用场景及注意事项，开展模拟浓烟环境下的佩戴练习，学会自己熟练佩戴和帮助他人佩戴的方法技巧，培养逃生避险时主动使用防烟面具的意识和能力。

主要措施：

1. 纳入职业培训。将实操实训纳入各类职业技能培训学校课程，组织实操体验；用人单位、使用劳务派遣用工的用工单位和劳务派遣单位落实对护工、保安等人员的消防教育培训制度，在职业技能培训中强化消防技能培训权重；推动各类职业技能鉴定机构在焊工等职业资格的报考取证环节，增加消防技能内容；强化消防职业技能鉴定工作，严格落实《消防控制室“四快”处置规程和“五知”评价标准》（附件3）。

2. 行业部门统筹培训。发挥各行业部门条线管理优势，结合实际确定具体重点人员，将消防基本技能实操实训纳入年度安全工作重点任务；行业主管部门按照各自职能，组织和监督管理消防安全教育培训工作，并纳入相关工作检查；支持行业协会、商会发挥行业自律作用，倡议开展宣传培训。

3. 单位常态化培训。落实《社会单位“五类重点人群”消防安全职责》（附件4），制定年度实操实训工作计划，采取多种形式对人员培训；强化职工岗前消防安全培训，建立定期复训制度，培养单位实操实训骨干；鼓励各单位充分利用既有场地、自有消防设施和装备器材以及即将到期的灭火器、过滤式消防自救呼吸器开展培训；建立实操实训激励机制，作为工资绩效评定、员工评先评优的重要内容；鼓励保险公司参保火灾责任险单位开展消防安全培训。

（三）疏散自救演练行动

主要任务：广泛组织党政机关、行业部门、社会单位人员以及社区（村）居民开展疏散自救演练，力争让每个公民参加一次贴近真实火场的消防疏散自救演练，掌握基本逃生自救常识和技能，增强消防安全意识，提升紧急情况下的应急处置、疏散逃生和自救互救能力。

主要措施：

1. 党政机关率先示范演练。聚焦机关办公建筑结构、功能分区及人员特点，制定针对性的演练预案，并定期动态更新；明确负责疏散演练的牵头部门和负责人，每年至少组织1次演练，重点演练指挥调度、逃生路线熟悉、楼层引导分流等内容；各级领导干部率先垂范、带头参与，在实战演练中提高认识，组织领导本地区消防事业高质量发展。

2. 行业部门统筹组织演练。行业部门制定年度演练计划，指导所属单位修订完善疏散演练预案，根据建筑布局、人员变动等情况动态更新；行业主管部门督促本行业、本系统每年组织应急演练；消防救援部门加强对行业部门演练预案制定、组织实施、修订完善的指导，建立火灾快速联勤联调机制。

3. 社会单位突出实战演练。认真落实《社会单位灭火和应急疏散预案编制及实施导则》，分级制定演练预案；演练时间充分考虑不同场景下的实际需求，人员密集场所可选择在早晚高峰时段开展，其中寄宿制学校、养老机构、医院等增加夜间或午休时段的针对性演练；火灾高危单位至少每季度组织1次演练，其他单位至少每年组织1次演练；在一定区域范围内社会单位建立消防安全联演工作机制；消防救援部门根据需要适时与社会单位开展联合演练。

4. 城镇社区分批覆盖演练。城镇社区居委会结合辖区建筑特点、人口结构及火灾风险，每年制定分批次演练计划；演练可采取楼栋单元演练、院落集中演练等形式，覆盖不同时段、不同场景，有序组织居民参与演练；有条件的可结合社区微型消防站拉动，同步测试消防通道畅通情况、消防水源及灭火器材完好率。

（四）案例教育警示行动

主要任务：健全以吸取教训为导向的火灾案例警示教育机制，深入剖析火灾事故的深层次原因，采取多种形式把每起亡人及有影响的火灾向全社会广为宣传，从惨痛的火灾事故中深刻汲取教训，从成功的应急处置中学习消防安全知识，从严肃的追责问责中受到警示警醒，推动各类责任主体知敬畏、存戒惧、守底线。

主要措施：

1. 现场警示。对发生在建（构）筑物内、与生产生活密切相关且有影响的一般火灾，组织周围群众、事发地街道及周边单位负责人、辖区同类单位负责人，通过张贴公告、实物展示、复盘推演、亲历者讲述、互动交流等形式，通报火灾事故基本情况及教训，讲解同类型火灾的防范和人员疏散逃生要点及消防安全责任，使受众直观感受火灾危害，提高安全意识，掌握逃生技能，督促对类似问题开展自查自改。

2. 会议警示。较大及以上或有影响火灾事故，提请属地政府召开警示教育会议，组织事故发生地行业部门、涉事单位等相关负责人参会，通报事故基本情况、直接原因、问题教训、整改和防范措施建议等，发生火灾的属地政府、行业主管部门和单位现身说法、深刻反思，真正把别人的教训当成自己的教训，防止屡屡重蹈覆辙。

3. 媒体警示。充分利用线上线下媒体平台，广泛播放警示教育片，强化舆论监督；在公共区域、重点场所，利用电子显示屏、橱窗海报、楼宇电视等媒介常态化开展警示宣传；消防救援部门落实新闻发布制度，定期通报火灾形势和火灾案例。

**三、**实施步骤

（一）部署发动。多部门联合部署发动，全面启动全民消防素质提升行动工作。指导各地细化工作措施，明确责任分工和时间节点。支持各地因地制宜开展全民消防安全素质调查，为靶向开展消防宣传提供支撑。

（二）组织实施。各地负责统筹制定本地区年度工作计划，明确量化目标和时间节点，组织推动各项任务落地见效。各有关部门负责条线指导，结合实际细化落实措施，督促所属单位抓好执行。及时总结典型经验，适时召开交流会。

（三）深化提升。组织开展提升行动总体目标评估，针对实施中发现的问题和不足，开展重点攻坚和查漏补缺。制定出台相关政策文件和技术标准，建立全民消防安全素质提升长效机制。

**四、**有关要求

各有关部门要主动提请当地党委、政府将全民消防安全素质提升行动纳入重要议事日程，注重统筹协调，强化经费保障，科学组织实施。各地党委社会工作部门要加强统筹协调，为消防志愿者队伍建设、消防志愿服务发展等予以支持和指导；各级总工会要加强工人群体消防安全培训，提高消防技能在“安康杯”竞赛中的权重；各地教育部门要将消防教育融入课程与社会实践，常态化开展公开课、职业院校技能大赛等活动；各地民政部门要重点督促养老、儿童福利等机构落实消防宣传、实操实训和疏散演练；各地人力资源社会保障部门要指导和监督企业、事业单位将消防安全知识纳入职工教育、培训内容；各地文化和旅游部门要将消防文化融入群众性文化活动，督促公共文化场馆、景区等人员密集场所开展消防宣传教育；各地消防救援部门要主动靠前服务，加强业务指导，帮助培养一批消防安全“明白人”，同时要统筹媒体资源，积极争取免费刊播消防公益广告渠道。
