# 财政部关于印发《彩票市场调控资金管理办法》的通知

财综〔2026〕41号

各省、自治区、直辖市财政厅（局），中国福利彩票发行管理中心、国家体育总局体育彩票管理中心：

为进一步加强和规范彩票市场调控资金管理，提高资金使用效益，根据国家预算管理和彩票管理有关规定，财政部对《彩票市场调控资金管理办法》进行了修订。现予以印发，请遵照执行。

为确保政策衔接，彩票市场调控资金2026年预算执行等工作继续按照《财政部关于印发<彩票市场调控资金管理办法>的通知》（财综〔2021〕17号）执行，2027年及以后年度预算申报、执行等工作按照本通知执行。结合工作实际，对2027年预算申报时间进行适当调整，请省级财政部门于2026年8月14日前报送申报材料。

## 彩票市场调控资金管理办法

**第一条** 为加强和规范彩票市场调控资金管理，提高资金使用效益，促进国家彩票事业持续健康发展，根据《中华人民共和国预算法》及其实施条例、《彩票管理条例》及其实施细则、中央对地方转移支付资金管理等相关规定，制定本办法。

**第二条** 本办法所称彩票市场调控资金，是指通过上缴中央财政的彩票发行机构业务费安排的，专项用于统筹全国彩票市场省际之间、机构之间、品种之间协调发展，强化彩票监管、保障彩票发行销售安全、维护彩票市场秩序，宣传彩票公益属性和社会责任等方面的资金，通过中央对地方转移支付方式分配下达。

**第三条** 彩票市场调控资金按照以下分工管理：

财政部负责制定彩票市场调控资金管理办法，确定年度预算总规模和分省份分配方案，明确整体绩效目标，按照预算管理规定程序下达预算，组织开展预算绩效管理。财政部可根据工作需要，组织或委托第三方机构开展重点绩效评价。

彩票发行机构负责建立本系统市场调控机制，统筹全国彩票市场实际情况，审核本系统资金需求，提出分配建议方案和绩效目标审核意见；结合彩票市场调控需要，适时研究提出分配因素及权重调整建议。

省级财政部门负责统筹本省份福利彩票、体育彩票市场实际情况，审核彩票销售机构资金需求和绩效目标，研究提出本省份资金需求和区域绩效目标；负责本省份预算分解下达、资金监管、预算绩效管理等工作。

彩票销售机构负责开展本单位彩票市场调控资金项目储备，申报资金需求，提出绩效目标；按照本办法规定和省级财政部门下达的预算和绩效目标，具体组织预算执行、绩效自评等工作。

**第四条** 彩票市场调控资金的分配和使用应当遵循客观公正、统筹协调、突出重点、讲求绩效的原则，统筹考虑各地实际情况，向落实重点任务、工作成效突出的地区倾斜，重点支持优化彩票品种游戏结构、防范化解市场风险等工作，有力促进彩票事业健康发展。

**第五条** 彩票市场调控资金的使用范围包括：

（一）提高彩票监管能力。主要用于组织开展彩票销售活动风险排查，提升异常销售预警能力，对违规销售彩票和彩票市场其他违法违规行为实施常态化监督；落实国家彩票监管要求，组织开展相关专项工作；完善彩票监管信息技术手段等支出。

（二）保障彩票发行销售安全。主要用于专用机房、灾备机房、彩票开奖场所、兑奖服务场所、彩票存储专用仓库、销售系统等业务设施的升级和改造，以及彩票投注专用设备的购置和维护等支出。

（三）维护彩票市场秩序。主要用于加强彩票销售场所准入管理，制定销售场所标准，开展代销者业务培训，规范代销行为，配合相关部门打击非法彩票等支出。

（四）开展彩票公益宣传。主要用于国家彩票公益属性和社会责任宣传，彩票全过程规范管理的公信力宣传，以及开展购彩风险提示，引导理性可持续购彩行为等支出。

（五）支持彩票发行销售业务创新。主要用于在彩票游戏产品、销售渠道、业务运行方面开展试点工作或创新发展等支出。

（六）对因不可抗力事件造成彩票销售场所暂停销售，需维持其基本运转且难以通过地方留存发行费弥补的成本费用进行补助。

（七）经财政部核定与彩票市场调控相关的其他支出。

上述“开展彩票公益宣传”、“支持彩票发行销售业务创新”使用范围，不包括彩票游戏派奖、促销、营销活动。

彩票市场调控资金使用应突出重点，聚焦落实国家推进彩票市场健康发展和加强监管有关要求，与地方留存发行费支出进行合理区分。彩票市场调控资金不得用于彩票机构人员支出、日常公用支出、办公设备购置和维护，“三公”经费支出，兴建楼堂馆所，偿还债务、罚款、捐赠等支出，以及未经批准的项目或与彩票事业发展无关的其他项目。除上述第六项使用范围外，不得用于销售场所租金或经营补贴。

**第六条** 彩票市场调控资金采取因素法分配，包括基础类因素、引导类因素、规范类因素三类。

基础类因素（权重25%），主要包括总人口数、销售场所数、地方留存彩票发行费等子因素。上述地方留存彩票发行费是指除上缴中央财政的彩票发行机构业务费之外的其他发行费。

引导类因素（权重50%），主要包括重点支持品种或游戏的年销量及年人均销量、试点示范成果、彩票市场调控资金使用成效等子因素。上述重点支持品种或游戏，由财政部结合彩票监管实际及彩票发行机构建议研究确定；试点示范是指财政部明确开展的试点工作或形成具有全国意义的制度机制创新示范成果有关工作。

规范类因素（权重25%），主要包括地方彩票市场秩序情况、彩票市场调控资金合规使用情况、资金申报规范性和质量等子因素。

财政部可结合相关工作实际及彩票发行机构建议，研究确定和适时调整上述三类因素的子因素。

**第七条** 财政部对省级财政部门报送的彩票市场调控资金绩效自评结果进行审核打分，在此基础上设置绩效评价调节系数，对资金分配情况进行适当调节。绩效评价调节系数按照下表取值：

|  |  |  |
| --- | --- | --- |
| 序号 | 年度绩效自评审核打分 | 绩效评价调节系数 |
| 1 | ≥90分 | 1 |
| 2 | ≥80分且＜90分 | 0.9 |
| 3 | ≥70分且＜80分 | 0.8 |
| 4 | ≥60分且＜70分 | 0.7 |
| 5 | ＜60分 | 0. 　　6 |

**第八条** 财政部按照以下公式测算安排分省份资金：

某省份资金补助比例=某省份基础类因素/∑有关省份基础类因素×25%+某省份引导类因素/∑有关省份引导类因素×50%+某省份规范类因素/∑有关省份规范类因素×25%某省份分配数=彩票市场调控资金年度预算总额×某省份资金补助比例×绩效评价调节系数/∑（有关省份资金补助比例×绩效评价调节系数）如上述公式测算出的某省份分配数大于其资金需求申报数，则按照申报数下达资金。

**第九条** 彩票市场调控资金按照以下程序申请：

彩票销售机构按照本办法规定的彩票市场调控资金使用范围，提出预算年度拟组织开展的项目内容、资金需求和绩效目标，同时提供上一年度资金管理使用有关情况等，报送省级财政部门审核。

省级财政部门统筹本地区福利彩票、体育彩票市场实际情况，审核彩票销售机构资金需求，结合年度彩票监管重点工作和项目储备情况，研究提出本省份资金需求，于每年7月31日前将申报材料纸质文件和电子文档报送财政部。申报材料应包括：上一年度资金管理使用有关情况，具体包括对照第五条规定的使用范围，分类说明项目组织实施、资金使用、工作成效等情况；试点示范成果、地方彩票市场秩序、资金合规使用等情况。预算年度拟组织开展的项目内容、必要性及可行性、资金需求数和区域绩效目标、预期成效等。财政部要求报送的其他材料。上述内容含本省份总体情况、分福利彩票和体育彩票系统情况。

财政部及时将有关申报材料转送彩票发行机构。彩票发行机构应当根据本系统彩票事业发展规划、年度彩票发行销售重点工作、上一年度彩票市场调控资金执行情况等，制定彩票市场调控目标和措施，审核本系统拟组织开展的项目情况、资金需求，提出本系统资金分配建议方案和绩效目标审核意见，并提供相关资金测算基础数据，包括本系统上一年度分省份销售场所数量、分省份留存彩票发行费金额、分省份分品种游戏彩票销量，对各省份试点示范成果、彩票市场调控资金使用成效、规范彩票市场秩序、资金申报规范性和质量打分等情况，以及财政部要求报送的其他材料，于每年8月31日前书面报送财政部。

省级财政部门、彩票发行机构、彩票销售机构分别对相关申报材料和测算基础数据的真实性、准确性负责。

**第十条** 彩票市场调控资金预算按照以下程序分配下达：

财政部结合彩票市场发展状况、省级财政部门提出的资金需求、彩票发行机构提出的分配建议方案和绩效目标审核意见、彩票发行机构业务费上一年度结余等情况，合理确定下一年度彩票市场调控资金预算总规模和整体绩效目标，依据本办法规定确定分省份预算数。

财政部按照预算法和预算管理有关规定，于每年10月31日前提前下达下一年度彩票市场调控资金预算，并在全国人大批准预算后90日内正式下达资金预算和绩效目标，抄送彩票发行机构和财政部有关监管局。

省级财政部门在收到资金预算后，应当在30日内合理分配、分解下达预算和绩效目标，并抄送财政部当地监管局。

彩票销售机构应当按照预算管理有关规定做好资金使用项目储备，聚焦贯彻落实重大决策部署，区分轻重缓急进行排序，设立符合实际、储备充足、切实可行的项目库。省级财政部门应当按照预算管理规定对项目库进行审核，未纳入项目库的项目原则上不得安排预算。项目应由彩票销售机构统一组织实施，各地可结合实际和彩票监管职责分工，统筹确定项目参与主体，按照预算管理规定使用资金。

**第十一条** 各级财政部门、彩票发行机构及彩票销售机构应当按照全面实施预算绩效管理的要求，强化绩效目标管理，做好绩效监控和绩效评价，并加强评价结果应用。

年度预算执行结束后，省级财政部门应当组织彩票销售机构对照绩效目标开展绩效自评，统筹彩票市场调控资金总体使用情况，形成本省份资金绩效自评报告，按时报送绩效自评有关材料，不得以彩票销售机构绩效自评代替区域绩效自评。

省级财政部门和彩票销售机构是绩效自评工作的责任主体和实施主体，应当确保自评结果真实、准确、客观，严禁弄虚作假。

**第十二条** 各级财政部门、彩票发行机构以及彩票销售机构应当按照预算和国库管理有关规定，依法依规分配和使用资金，规范预算执行，强化内部控制，及时防范化解各类风险，不得截留、挤占、挪用资金，不得擅自扩大支出范围和提高支出标准。资金使用过程中，涉及政府采购的，应当按照政府采购有关法律法规及制度执行。彩票市场调控资金原则上应在当年执行完毕，当年未支出的资金按照结转结余资金管理有关规定管理。

**第十三条** 彩票市场调控资金依法接受财政、审计等部门的监督。各级财政部门、彩票发行机构及彩票销售机构应当加强对彩票市场调控资金使用情况的监督管理，依法依规开展财会监督检查，及时发现和纠正有关问题，确保资金安全。彩票市场调控资金纳入预算常态化监督范围，各级财政部门依托预算管理一体化系统转移支付监控模块，加强预算执行常态化监督。发现问题及时处理，根据情况进一步采取追回已拨付资金、扣减预算等措施强化监督。财政部各地监管局按照工作职责和财政部要求对彩票市场调控资金使用管理情况进行监督。

**第十四条** 各级财政部门、彩票发行机构、彩票销售机构及其工作人员在资金分配、使用、监督等工作中，存在滥用职权、玩忽职守、徇私舞弊等行为的，依法追究相应责任。

**第十五条** 省级财政部门可根据本办法，结合本地实际情况，制定具体实施办法。

**第十六条** 本办法自发布之日起施行，实施期限为5年。
