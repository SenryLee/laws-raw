# 人力资源社会保障部关于加强人力资源社会保障领域政策和服务高品质供给的意见

人社部发〔2026〕44号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）：

为深入贯彻落实党中央、国务院关于加大保障和改善民生力度、提高人民生活品质的决策部署，优化扩大人力资源社会保障领域政策和服务高品质供给，进一步做好保障和改善民生工作，现提出以下意见。

一、总体要求

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大和二十届历次全会精神，认真落实四中全会部署，坚持以人民为中心的发展思想，坚持全面深化改革，坚持有效市场和有为政府相结合，坚持尽力而为、量力而行，着眼更加注重提质增效、普惠公平、智慧便捷、均衡可及，提高人社领域政策和服务供给水平，推动解决人民群众急难愁盼问题，加强普惠性、基础性、兜底性民生建设，形成制度更加成熟、保障更加有力、治理更加高效的供给格局，不断增强人民群众的获得感、幸福感、安全感。

二、系统集成优化政策供给

**（一）**强化协调联动的政策导向。注重平衡民生与发展、民生与安全的关系，主动适应高质量发展和高品质生活需要，强化人社政策与经济、产业、社会等政策的一致性，聚焦促进高质量充分就业、高素质现代化人力资源培育、高水平参加社会保险、工资收入合理增长等，构建同向发力、良性互动、稳定预期的政策供给机制。完善具有基础性、改革性、累积性的人社政策制度框架，统筹当前和长远、局部和整体、需要和可能，发挥存量政策和增量政策集成效应，保持连续性、稳定性、可持续性。强化城乡、区域、群体间政策协同，健全人力资源匹配、社保关系转移接续、人才评价互认、劳动关系治理、档案转递通办等机制，推动畅通劳动力和人才社会流动渠道。

**（二）**丰富精准适配的政策工具。加强急需紧缺领域政策供给，顺应人工智能和新质生产力发展，特别是新产业、新业态、新模式、新职业等，因时因势、因地制宜创新完善政策举措，增强灵活性、包容性，及时制定修订相关法律法规，不断补齐制度短板。精准对接高校毕业生、灵活就业和新就业形态劳动者、农民工等重点群体，以及不同类型用人主体差异化需求，围绕全生命周期、全职业生涯重点事项，强化因人施策、因企施策、因业施策，完善岗位供求、薪酬分配、评价激励、权益保障等市场化、规范化指引指南。加强对困难人员、大龄劳动者、低收入群体、防止返贫致贫对象等群众政策帮扶，兜牢民生底线。

**（三）**增强可感可及的政策成效。坚持问题导向、目标导向，科学增加政策供给，围绕产业布局、群体特征、企业所需等，建立“需求采集—分析研判—靶向施策—效果评估”机制，简化政策流程、实施路径，更加便于操作执行。深入推进人社政策“看得懂、算得清”，加强政策精准推送、直达快享，畅通落地见效的“最后一公里”。根据经济社会发展和政策历史经纬、实施效果等情况，动态调整优化政策措施、力度、节奏等，充分释放政策红利，积极推动化解历史遗留问题。

三、集约高效扩容服务供给

**（四）**健全均等普惠的服务体系。完善人社基本公共服务制度和内容，适时纳入群众急需的服务项目，推进公共服务常住人口广覆盖、用人主体广惠及。促进服务资源向基层下沉、向农村覆盖、向边远地区和生活困难群众倾斜，鼓励有条件、有需求的地方合理布局服务网点，建设“家门口”就业服务站、“15分钟”社保服务圈、“30分钟”培训服务圈等，推动服务更加均衡可及。提升人社公共服务标准化水平，完善服务规范、办事流程、质量评价等标准体系，加强区域间标准统筹、服务融通。积极培育职业指导、职业信息分析、社保规划、劳动关系协调等服务力量，增加专业化精细化服务供给。

**（五）**拓展便利通畅的服务渠道。推进线上线下服务全贯通，推动线下服务“一窗通办”，实现统一受理和一站式办理，完善全国人社政务服务平台、国家社保公共服务平台等全国性线上服务平台，促进全领域事项“应接尽接、应上尽上”，更多政策服务“掌上办”、“指尖办”、“一网通办”，畅通12333热线等人工服务。深化实施“高效办成一件事”集成改革，以企业和群众眼中的“一件事”为标准，优化流程、精简材料、缩短时限，推进更多高频事项打包办、关联办、跨域办，让数据多跑路、群众少跑腿。关注老年、残疾等特殊群体需要，加强适老化与无障碍改造，设置绿色通道，提供帮代办、上门办、陪同办等暖心服务。

**（六）**升级数智赋能的服务模式。深化“大数据＋铁脚板”精准服务，实现服务从“可办、能办”向“好办、智办”转变。深入实施数字人社建设行动，加快推进“人工智能＋人社”应用发展，在确保安全的前提下，稳妥有序构建一体化信息平台、数字化应用场景、智能化服务体系，探索人工智能大模型应用和人机协同工作模式。聚焦求职招聘、参保缴费、待遇申领、资格认证、补贴发放、权益保障等重点环节和事项，丰富智能问答、智能引导、智能填单、智能核验、智能回访等应用，推动无感智办。加强跨层级、跨地区、跨部门数据共享与业务协同，提升身份认证、电子印章验签、用户管理等支撑能力，建立健全大数据辅助决策机制。

四、加强高品质供给支撑保障

**（七）**健全清单化供给管理推进机制。结合实施人社领域“十五五”规划，每年推出一批政策和服务供给事项，各地人社部门结合实际细化完善富有本地特色的重点事项清单，构建动态调整、闭环管控、品质导向的常态化供给管理模式。加强统筹协调和指导推动，健全管理科学、上下联动、运行顺畅的供给保障工作体系，创新思路和方法，打造一批特色鲜明、温暖民生、撬动性强的工作品牌、服务品牌、活动品牌，健全为民办实事长效机制。加强工作总结评估，创造更多可复制、可推广的新鲜经验，及时研究新情况、解决新问题。

**（八）**培育多元专业的供给主体。完善政府和市场优势互补、协同发力的供给方式，围绕群众和用人主体多层次、差异化、个性化需求，引导市场力量参与扩容供给。运用政府购买服务、以奖代补、政策扶持、揭榜挂帅等方式，支持市场力量在就业培训、社保服务、人才服务、劳动关系协调等方面，提供多元化、专业化、增值化服务。支持公共服务机构与人力资源服务机构、职业培训机构、创业孵化基地、社会组织等合作，鼓励志愿服务力量参与公益服务。支持市场力量参与相关政策制定、标准开发、技术创新。完善市场准入和监管机制，规范市场行为，引导诚信服务，提升供给质量。

**（九）**夯实基层基础工作支撑。强化人社基层机构设施布局、资源配置、服务能力建设，打造环境友好、服务规范、运行安全的经办场所，积极融入社会治理，注重为基层减负，增强工作效能。各地结合工作实际，统筹协调、合理安排就业补助、人才发展、产业引导等资金基金，向政策和服务供给的重点任务、重大举措、重要项目倾斜，加强资金使用管理和安全规范运行。加强人社系统干部和人员队伍作风能力建设，培厚对党忠诚、民生为本、人力赋能、廉洁实干的人社文化，深入推进依法行政，进一步提升服务意识、专业素养、工作水平。

各级人力资源社会保障部门要提高政治站位，把党的领导贯穿政策和服务高品质供给全过程，细化任务措施，明确工作责任，强化与规划实施衔接联动，切实抓好各项任务落实落细。树立和践行正确政绩观，科学理性，求真务实，真抓实干，一件事情接着一件事情办，一年接着一年干，把惠民生、暖民心、顺民意的工作做到实处。充分利用传统媒体和新媒体平台，宣传解读人社政策和服务高品质供给的重点举措、工作成效和先进典型，及时回应社会关切，营造良好氛围。
