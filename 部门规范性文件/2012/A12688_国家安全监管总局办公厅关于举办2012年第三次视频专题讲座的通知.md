# 国家安全监管总局办公厅关于举办2012年第三次视频专题讲座的通知

## 国家安全监管总局办公厅关于举办2012年第三次视频专题讲座的通知（安监总厅培训〔2012〕106号）

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局，各省级煤矿安全监察局，总局和煤矿安监局机关各司局、应急指挥中心，有关在京直属事业单位、社团组织：

国家安全生产监督管理总局（以下简称总局）定于8月14日（星期二）15时举办2012年第三次视频专题讲座，由上海交通大学教授、博士生导师蒋祖华讲授“人因工程与事故预防”（讲授提纲可从总局网站下载）。

请各单位组织相关人员按时参加。请总局和国家煤矿安监局机关各司局、应急指挥中心，有关在京直属事业单位、社团组织于8月10日前，将拟参加人数报送总局培训中心；各省级安全监管局和省级煤矿安全监察局于8月15日前，按照附表要求将参训人数及有关意见建议反馈总局培训中心。

请各省级安全监管局和省级煤矿安全监察局通知有关人员按照总局通信信息中心要求，于8月14日13时开机准备。

联系人及电话：王巧巧，010-64463627、64463870（传真）。
