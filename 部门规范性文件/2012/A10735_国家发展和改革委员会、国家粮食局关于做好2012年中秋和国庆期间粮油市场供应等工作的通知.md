# 国家发展和改革委员会、国家粮食局关于做好2012年中秋和国庆期间粮油市场供应等工作的通知

## 国家发展和改革委员会、国家粮食局关于做好2012年中秋和国庆期间粮油市场供应等工作的通知（国粮电〔2012〕11号）

各省、自治区、直辖市及新疆生产建设兵团发展改革委、粮食局、物价局，中国储备粮管理总公司、中粮集团有限公司、中国华粮物流集团公司、中国中纺集团公司：

2012年中秋节和国庆节即将来临，为切实做好当前粮食购销和市场调控工作，确保节日期间粮油市场供应和价格基本稳定，现就有关问题通知如下：

**一、**高度重视当前粮油市场保供稳价工作

在中央一系列强农惠农富农政策的有力推动下，2012年我国粮食生产继续保持良好势头，夏粮和早籼稻继续增产，秋粮有望再获丰收，粮食产需继续保持总量基本平衡的格局。各地各有关部门认真贯彻落实中央决策部署，继续把抑制食品价格过快上涨作为稳定物价的重点，积极采取有效措施，加强粮食市场调控，粮食市场运行总体平稳，为稳定消费价格总水平发挥了重要作用。2012年以来，我国粮食进口增加较多，粮食收购进展顺利，国家粮食库存充裕，完全可以保证市场供应。但由于受劳动力和生产资料等成本上涨影响，国内粮食市场价格继续保持平稳上涨态势，特别是6月份以来国际市场粮油价格大幅上涨，给国内市场粮油价格带来较大的上涨压力。随着中秋节和国庆节日的临近，粮油消费进入旺季，保供稳价工作任务仍然艰巨。各地要按照“粮食省长负责制”的要求，在本地区粮油市场保供稳价领导小组的统一组织协调下，认真分析当前粮油市场形势，抓紧制订和完善保障节日期间粮油供应的具体工作方案并认真组织实施，进一步强化措施，落实责任，确保节日期间本地区粮油市场供应和价格基本稳定。

**二、**切实保障粮油市场供应

做好粮油市场供应工作，是各级粮食行政管理部门的重要职责，也是事关国计民生和经济平稳运行的政治责任。要针对节日期间市场需求旺盛等情况，进一步加强货源组织调度，确保成品粮油市场供应不断档、不脱销，保持粮油市场价格基本稳定。要督促有关企业保证正常加工生产，及时投放适销对路的粮油商品，增加花色品种，确保零售企业特别是大型连锁超市等小包装粮油货源充足，充分满足多样化市场需求。要重点关注学校、低收入群体和厂矿企业的粮油供应情况，保证贫困人口、水库移民、退耕还林等缺粮地区的口粮供应。云南、贵州等地要按照《国家粮食局关于切实做好云南贵州抗震救灾工作确保灾区粮油供应的紧急通知》（国粮电〔2012〕9号）的有关要求，切实做好抗震救灾和受灾地区粮油市场供应等工作。有关中央粮食企业要树立大局意识，主动服务国家宏观调控，带头执行国家政策，加大粮油及其制品的生产和投放，配合做好粮油市场供应工作，稳定粮食市场价格。

**三、**确保粮油供应质量安全

各级粮食行政管理部门要高度重视粮油质量安全工作，坚持标本兼治、重在治本的工作原则，全面梳理粮油质量安全隐患和监管薄弱环节，进一步完善相关措施，切实落实监管责任，督促粮食经营者严格执行粮食销售出库质量检验制度，严防不符合国家食品安全要求的粮食流入节日口粮市场。要根据节日消费市场的特点，深入推进“放心粮油”进农村进社区活动。以放心粮油示范企业和大中型粮油骨干企业为依托，扩大服务领域，增加服务网点，把安全优质的“放心粮油”送进城乡千家万户。要充分发挥粮食部门职能作用，利用粮油质检机构的专业技术优势，积极配合工商、技术监督等相关部门开展成品粮油的质量安全监测抽查工作，加大对大型粮油批发市场、超市和农贸市场等销售粮油的扦样检验力度，确保粮油供应质量安全，让广大城乡居民安全消费、放心消费。

**四、**加强粮油市场监测，适时投放储备

各地粮食、价格主管部门要进一步加强本地区粮油市场和价格的监测、分析和预警工作，及时掌握主要粮油商品生产加工和供应等情况，密切关注国内外粮油市场价格变化，科学研判粮油供求形势及其发展趋势，定期发布粮油供求及价格信息，指导粮食企业积极做好粮油购销工作，正确引导粮油生产和流通。要建立健全监测预警信息报告制度，加大监测频率和密度，提高粮油市场监测工作的针对性和准确性。国家有关部门将继续安排最低收购价和国家临时存储粮的竞价销售，并适时增加投放数量，以满足市场需求。各地也要根据本地区市场情况和调控需要，适时投放地方粮油储备，稳定本地区成品粮油市场价格，避免市场出现大幅波动。一旦出现价格异常波动和群众排队购买等情况，要迅速采取应对措施，重要情况要及时向省级人民政府和国家有关部门报告。

**五、**积极做好粮食应急各项准备

各地要有针对性地制订粮油应急供应预案，并进一步细化和完善储备粮油应急动用方案，充分做好应对粮价波动、重大自然灾害和极端气候等突发情况的应急准备工作。要定期开展对本地区成品粮油储备承储企业的检查，确保数量真实、质量良好，确保调得动，用得上，有保障。各地还要加强对应急加工、供应企业生产经营情况的核查，确保能够满足应急工作的需要。要抓住今年粮食丰收、市场粮源较多的有利时机，进一步充实地方储备库存，确保地方储备粮油规模指导性计划落实到位。

**六、**优化粮食库存布局

各地要加强对本地区粮源情况的研究分析，对粮源不足或分布不合理可能影响粮食供应的，要立即采取措施筹措粮源，积极组织“柜台前移”。中储粮总公司及地方有关部门要进一步加大工作力度，切实抓好今年已下达的政策性粮食跨省移库计划的落实，力争提前完成跨省移库任务，进一步优化粮食库存布局。主销区粮食行政管理部门要根据当地粮食消费需求、库存等情况，主动加强与产区的沟通衔接，组织指导企业均衡有序到产区采购，定期统计有关企业购粮的数量、价格和运输需求等。主产区粮食行政管理部门要加强粮食运输的组织协调，及时与铁路、交通部门进行沟通，做好调度工作，均衡安排运输，提高运输效率。对于粮食运输确有困难的，尤其是对销区到产区采购保证市场供应所需调控粮源的，各地要及时上报，以便协调铁路、交通等部门统筹安排运力，保障重点粮食的运输。

**七、**积极做好粮食收购工作

当前，夏季粮油和早籼稻收购工作正在进行，秋粮收购即将展开。各地粮食行政管理部门要认真落实国家粮食收购政策，引导各类粮食企业积极入市收购，充分发挥国有粮食企业收购主渠道作用，争取多掌握粮源，为国家宏观调控打好物质基础。要督促收粮企业严格执行国家政策，坚持依质论价、优质优价、公平定等、准确计量、敞开收购、随到随收、现款结算、不打白条，真心诚意地帮助农民增收，切实保护好种粮农民利益。各地粮食部门和有关企业要主动加强与农发行的沟通协调，落实好收购资金，满足收购需要，确保收购工作顺利进行。

**八、**加大市场监管力度

各地和各有关单位要按照《国家政策性粮食出库管理暂行办法》的有关规定，加强国家政策性粮食销售出库监管，督促承储企业认真履行合同，确保国家政策性粮食按质、按量、及时出库投放市场，充分发挥国家政策性粮食在宏观调控中的作用。各地粮食、价格主管部门要与相关部门加强沟通协调，密切合作，进一步加强对粮油收购、加工、批发、零售等重点环节的监督检查，对重点企业、大型粮油批发市场、超市和农贸市场开展巡查，督促企业加强自律，规范经营行为，承担社会责任。各级价格主管部门要坚决打击串通涨价、捏造散布涨价信息、恶意囤积、哄抬价格以及价格欺诈等违法行为，对相关案件要发现一起、严办一起，绝不姑息，切实维护正常的市场流通秩序。

**九、**正确把握舆论宣传导向

各地要加强对粮油市场形势的正面宣传和舆论引导，大力宣传我国粮食连续丰收、市场供应充足等情况，积极报道各地采取的保供稳价措施，防止虚假信息的发布和传播误导市场，稳定群众心理预期，为保持国内粮油市场价格基本稳定创造良好的舆论氛围。

做好中秋、国庆节日期间粮油购销和市场供应工作，任务繁重，责任重大。各地要高度重视，切不可掉以轻心，要进一步落实粮食省长负责制，把保证粮油市场供应和价格基本稳定作为当前一项重要任务，加强领导，落实责任，周密安排，精心组织，建立节假日值班制度和领导带班制度，切实把粮油保供稳价的各项政策措施落实到位，让全国人民度过欢乐、祥和的节日，以优异的成绩迎接党的十八大胜利召开！
