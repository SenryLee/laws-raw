# 住房和城乡建设部直属机关工会关于印发《住房和城乡建设部直属机关2012年工会工作要点》的通知

## 住房和城乡建设部直属机关工会关于印发《住房和城乡建设部直属机关2012年工会工作要点》的通知（建机工[2012]3号）

各直属工会、部机关各司局工会小组：

现将《住房和城乡建设部直属机关2012年工会工作要点》印发你们，请结合本单位实际，认真贯彻落实。

直属机关工会　　

二〇一二年一月三十日

住房和城乡建设部直属机关2012年工会工作要点

2012年直属机关工会工作总的要求是，以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，按照中央国家机关工会联合会和部直属机关党委的部署，认真学习贯彻党的十七大和十七届三中、四中、五中、六中全会精神，以迎接党的十八大召开和学习宣传贯彻十八大精神为主线，推动党工共建创先争优，努力服务中心工作，竭诚为职工服务，在保证中心工作完成、推进和谐单位建设中发挥积极作用。

**一、**坚持服务大局、服务中心工作，动员广大干部职工立足本职、争创一流

（一）按照党组织的部署，广泛宣传党的十七大以来落实科学发展观、推进住房和城乡建设事业取得的巨大成就，宣传党领导下的群众工作取得的丰硕成果；组织开展多种形式的主题活动，营造迎接党的十八大胜利召开的良好氛围；组织学习宣传党的十八精神，结合工会工作实际，抓好贯彻落实。

（二）注重发挥先进模范的引领作用，特别是以身边的榜样感染、教育、凝聚职工自觉践行社会主义核心价值体系。配合党组织做好宣传教育工作，引导职工把思想统一到中央精神和部党组的部署上来，关心和支持本单位改革发展稳定工作，为完成部和本单位中心任务做贡献。继续开展“创建学习型组织，争做知识型职工”活动，积极参加中央国家机关工会联合会组织的公文写作比赛，组织开展适合本单位工作特点的劳动技能竞赛和岗位练兵活动，鼓励和支持职工结合本职工作加强学习，努力提高科学文化和技术技能素质。积极开展“讲文明、树新风”活动，加强社会公德、职业道德、家庭美德教育，不断提高职工思想道德修养。

**二、**积极推动民主管理，坚持更好地为职工服务

（三）发挥工会组织优势，推动以职代会等形式参与单位民主决策、民主管理、民主监督，保障职工的知情权、参与权、表达权和监督权。及时了解职工需求，畅通诉求反映渠道，密切党群、干群关系。协助有关部门做好劳务合同、职工“五险”、职工休假等工作，在维护职工合法权益中发挥积极作用。

（四）充分履行工会“职工困难第一知情人、第一帮助人、第一报告人、第一督促解决人”的职责，着力解决职工群众最关心、最直接、最现实的利益问题。及时了解掌握困难职工的情况，特别是老劳模、老先进工作者、特困职工的情况，不断完善困难职工档案。积极配合党政部门加大帮扶工作力度，重点做好春节、五一、十一等重要节日期间“送温暖”活动，落实经常性“送温暖”制度。加强与央务鹊桥工程、央务心理咨询工程的联系，协助做好服务工作。

**三、**努力服务职工文化需求，开展丰富多彩的文体活动

（五）围绕迎接党的十八大召开和学习宣传贯彻十八大精神，组织开展丰富多彩的群众性文化活动。配合党组织积极推动单位文化建设，不断丰富内涵，创新载体，营造良好的单位文化环境和氛围。支持摄影协会开展活动，培育组建新的职工文体活动兴趣组织，带动职工文体活动的开展。

（六）广泛开展群众性健身活动。上半年，会同部文明办举办“讲文明、树新风”健身长走活动，举办第五届羽毛球友谊赛；下半年，举办第七届乒乓球友谊赛、第六届在职干部与离退休干部局老干部台球友谊赛、第三届迎新春桥牌双人赛。积极推广第九套广播操。组队参加中央国家机关的有关比赛。支持乒乓球俱乐部、羽毛球协会、桥牌协会开展活动。各单位工会要根据本单位实际组织开展形式多样的体育活动，促进职工健身活动的广泛开展。

**四、**不断加强工会组织的自身建设

（七）努力探索工会工作的特点和规律，更新工会工作理念，充分运用信息化、网络化等现代手段，使直属机关工会工作更加科学化、规范化、制度化。加强工会组织建设，督促到届工会按时换届；推动有条件的社团组建工会，扩大工会组织覆盖。上半年，评选表彰先进工会组织、优秀基层工会干部和工会活动积极分子，树立典型，弘扬先进。重视加强工会干部的培训工作，直属机关工会继续举办工会干部培训班。

（八）规范工会经费的管理和使用，贯彻新《工会会计制度》、《工会预算管理办法》和《基层工会经费收支管理办法》，督促各单位工会足额、按时缴纳会费。继续开展工会财务人员培训，提高工会财务管理水平。进一步发挥经审会对本级经费使用情况的审查和监督作用，使工会经费管理更加规范化、制度化。
