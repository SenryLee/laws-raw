# 国家食品药品监督管理局食品安全监管司关于调整2012年全国餐饮服务食品安全检验工作会议时间的通知

国家食品药品监督管理局食品安全监管司关于调整2012年全国餐饮服务食品安全检验工作会议时间的通知

（食药监食函[2012]63号）

各省、自治区、直辖市及新疆生产建设兵团食品药品监督管理局，北京市卫生局、福建省卫生厅：
