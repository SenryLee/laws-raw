# 国家体育总局关于2012全国排球高水平后备人才培训基地训练营活动通知

有关省、市体育局业务主管部门：

为进一步加大排球后备人才培养力度，促进排球运动的可持续发展，经研究决定在福建漳州体育训练基地举办2012年全国排球高水平后备人才培训基地训练营活动。现将有关事宜通知如下：

**一、**日程安排

男线训练营：2012年8月1日-12日（8月1日报到，8月12日离开）；

女线训练营：2012年8月14日-25日（8月14日报到，8月25日离开）；

报名截止时间为7月1日。

**四、**活动内容

排球训练理论知识讲座、形态指标测量、身体素质测试、观摩公开课、比赛交流等。

**五、**经费

（一）运动队食宿、场地等有关费用由国家体育总局排球运动管理中心负担，其他差旅费、医疗费等自理。

（二）各队参加训练营人员：每队可参加16名，其中领队1名、教练员2名、队医1名、运动员12名。超编人员有关食宿费用自理（每人每天150元）。

**六、**要求

（一）各队自带训练服、鞋、球等训练装备。

（二）通知中所列各参加单位必须按时报到，如有特殊情况，须经所属省、市体育局业务主管部门请假，并报国家体育总局排球运动管理中心批准。
