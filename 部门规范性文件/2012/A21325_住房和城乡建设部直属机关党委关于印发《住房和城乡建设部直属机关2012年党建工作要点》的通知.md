# 住房和城乡建设部直属机关党委关于印发《住房和城乡建设部直属机关2012年党建工作要点》的通知

## 住房和城乡建设部直属机关党委关于印发《住房和城乡建设部直属机关2012年党建工作要点》的通知（建党办[2012]2号）

各直属党委、总支、支部：

现将《住房和城乡建设部直属机关2012年党建工作要点》印发你们，请结合实际，认真贯彻落实。

直属机关党委　　

二〇一二年一月三十日

住房和城乡建设部直属机关2012年党建工作要点

2012年，直属机关党建工作的总体要求是：深入学习贯彻党的十七大和十七大以来历次全会精神，以迎接党的十八大召开和学习宣传贯彻十八大精神为主线，围绕服务中心、建设队伍两大任务，继续推进学习型党组织建设，深入开展创先争优活动，扎实做好抓基层打基础工作，全面加强直属机关党的建设，不断提高党建工作科学化水平，为完成部中心工作提供坚强保证。

**一、**以党的十八大召开为契机，大力加强思想政治建设

（一）营造党的十八大胜利召开的浓厚氛围。按照规定程序和要求，圆满完成党的十八大代表候选人和中央国家机关党代表会议代表推选工作。广泛宣传党的十七大以来经济建设、政治建设、文化建设、社会建设、生态文明建设和党的建设的伟大成就与宝贵经验，宣传坚持科学发展、加快转变经济发展方式、促进社会和谐取得的显著成绩，宣传党的执政能力建设和先进性建设取得的重大进展，宣传住房城乡建设事业取得的巨大成就以及直属机关党建工作的丰硕成果，大力营造党的十八大胜利召开的浓厚氛围。“七一”前，以“向党的十八大献礼”为主题，采取召开专题组织生活会、宣传学习先进典型、社会实践、专题调研、走访慰问老党员和困难党员等多种形式，普遍开展一次主题党日活动。

（二）抓好党的十八大精神的学习宣传贯彻。党的十八大召开后，把学习宣传贯彻大会精神作为直属机关党的建设的重大政治任务抓紧抓好，迅速兴起学习宣传贯彻的热潮。通过组织中心组学习、举办专题学习班、组织专题辅导和报告会等多种形式，引导党员干部紧密结合实际开展学习研讨，切实把思想和行动统一到十八大精神上来，把智慧和力量凝聚到实现十八大确定的宏伟目标和各项任务上来。结合部中心工作和各单位实际，深入研究贯彻落实十八大精神的思路和重点，以十八大精神为指导努力开创住房城乡建设各项工作新局面。

（三）深化理论武装工作，抓好社会主义核心价值体系学习教育。坚持用中国特色社会主义理论体系武装党员干部，引导党员干部深入学习掌握党的基本理论、基本路线、基本纲领、基本经验，学习马克思主义经典著作，系统掌握马克思主义立场、观点、方法，深入学习胡锦涛总书记在庆祝中国共产党成立90周年大会上的讲话精神，不断增强坚持中国特色社会主义道路、理论体系和制度的自觉性、坚定性，努力将学习成果转化为工作思路和政策措施。深入开展理想信念教育，加强形势政策教育、国情教育、革命传统教育和改革开放教育，引导党员干部坚定对马克思主义的信仰和对中国特色社会主义的信念，努力成为实践社会主义核心价值体系的模范。加强道德建设，引导党员干部带头弘扬民族精神和时代精神，自觉践行社会主义荣辱观。认真落实中央关于开展学雷锋活动的部署，结合实际组织开展学雷锋活动。组织开展直属机关文化建设专题调研，总结交流好的经验做法，推动社会主义核心价值体系建设的贯彻落实。

（四）推进学习型党组织建设活动。坚持以领导班子和领导干部为重点，以提高思想政治素质为根本，深入推进学习型党组织建设活动。加强和改进中心组学习，发挥领导干部帮学带学促学作用。落实新一轮大规模培训、大幅度提高党员干部素质任务，发挥直属机关党校作用，创新培训内容和方式，不断增强教育培训的针对性和实效性。运用部干部学习网等新形式增强学习效果，结合实际开展学习竞赛、业务交流、成果展示等活动。建立健全党员干部教育培训、述职述学、学习考评机制。及时了解党员干部思想动态，完善党员干部思想状况定期研究分析制度，注重人文关怀和心理疏导，不断增强思想政治工作的针对性和实效性。

（五）加强领导班子思想政治建设。着力强化党的基本理论学习，强化能力培训和实践锻炼，强化宗旨教育和群众路线教育，进一步健全党内生活，严格党内监督，认真解决领导班子和领导干部思想政治建设上存在的突出问题，进一步增强政治意识、大局意识、责任意识和忧患意识。促进领导班子认真落实民主集中制，落实党员领导干部双重组织生活制度，不断提高民主生活会质量，自觉开展批评与自我批评，努力形成团结协作、高效运转的工作机制。

**二、**深入开展创先争优活动，推动创先争优常态化常效化

（六）深化创先争优活动。以窗口单位和服务行业为民服务、机关干部深入基层为民服务为重点，在推动中心工作、履行岗位职责、服务人民群众中创先争优。进一步推动窗口单位和服务行业创先争优，重点组织开展好“打造一流作风、建设一流队伍、展现一流形象、提供一流服务”主题实践活动，扎实做好群众评议、公开承诺等工作，以直属机关创先争优活动成果推动系统窗口单位和服务行业创先争优活动的深入开展。认真贯彻中央创先争优活动领导小组《关于在创先争优活动中进一步推动各级党政机关和干部深入基层为民服务的指导意见》，采取多种形式，积极推动机关干部深入基层、深入群众，知民情、解民忧，让群众切实感受到创先争优带来的新变化。

（七）做好创先争优活动总结表彰工作。按照“五个好”、“五带头”基本要求，对创先争优活动开展情况进行总结表彰，全面展现两年多来创先争优活动成果，进一步营造学习先进、赶超先进、争当先进的良好氛围。做好向工委和中央组织部推荐“2010-2012年创先争优活动”先进基层党组织和优秀共产党员各项工作。

（八）建立健全创先争优长效机制。加强创先争优理论和实践问题研究，认真梳理行之有效的经验做法，提炼上升为制度规范，探索建立健全创先争优长效机制。建立健全领导责任机制，努力形成以上带下、以下促上、上下联动的创先争优常态化工作格局；建立健全统筹推进机制，以创先争优活动为重要载体，统筹推进党的思想、组织、作风、制度和反腐倡廉建设；建立健全考评保障机制，把创先争优纳入党建工作考核和年度干部考核的重要内容，将考核结果作为考核单位党建工作和评价干部工作实绩的重要依据。

**三、**认真贯彻落实《条例》，不断加强组织和作风建设

（九）做好抓基层打基础工作。加强对贯彻落实《中国共产党党和国家机关基层组织工作条例》及部《实施办法》的督促检查。认真开展“基层组织建设年”活动，进一步健全基层党建工作制度体系、组织体系、保障体系，加强分类指导，不断增强基层党组织的创造力、凝聚力和战斗力。机关党组织坚持高标准严要求，着力强化组织功能，增强组织活力，发挥好示范带头作用；直属事业单位党组织结合事业单位特点，围绕中心开展工作，努力在事业单位改革发展中发挥好作用；部管社团党组织着力健全组织、规范管理，进一步探索发挥作用的途径和方法。深入推进党支部品牌建设，不断提高党支部工作水平。认真贯彻落实中央《关于党的基层组织实行党务公开的意见》及部《实施办法》，积极推进党务公开，切实保障广大党员的知情权、参与权、选举权和监督权，进一步调动党员干部干事创业的积极性。完善党内激励、关怀、帮扶机制，在政治上、工作上、生活上关心爱护广大党员，特别是帮助在艰苦环境中工作的党员、生活困难党员和老党员解决实际困难。

（十）抓好作风建设。按照保持党员干部作风纯洁的要求，以坚持党的实事求是的思想路线为切入点，大力加强作风建设，切实解决在作风建设方面存在的突出问题。教育引导党员干部坚持走群众路线，认真开展下访、走访活动，努力做到察民意、听民声、聚民心，把实现好、维护好、发展好最广大人民根本利益作为检验纯洁性的试金石，想问题、作决策、干工作都从群众利益出发，求真务实、真抓实干。坚持奋发向上、百折不挠的精神，弘扬勤俭节约、艰苦奋斗的作风，自觉抵制拜金主义、享乐主义、铺张浪费等不良风气。坚持以作风建设推进服务型政府建设，积极推动政府职能转变，不断提高公共服务水平，带头改进文风会风，以优良的党风带政风促行风。

（十一）加强党务干部队伍建设。加强对党务干部的教育、培养和使用，着力提高政治素质和业务能力，激发工作热情和干劲。按照守信念、讲奉献、有本领、重品行的要求，切实选好配强各级党组织负责人，继续举办好党务干部培训班，不断提高开展党务工作的能力和水平。始终关心党务干部成长，加大教育培训、学习考察、岗位交流和实践锻炼力度，努力为党务干部成长进步创造条件，促使党务干部为直属机关党建工作发挥更大作用。

**四、**大力加强廉政风险防控工作，深入推进反腐倡廉建设

（十二）加强反腐倡廉宣传教育。认真学习贯彻中央纪委七次全会、国务院第五次廉政工作会议，以及全国住房城乡建设系统党风廉政建设工作会议精神，引导党员干部进一步明确任务要求。严明党的纪律，加强对中央重大决策部署落实情况和党的政治纪律执行情况的监督检查，确保中央政令畅通。加强党性党风党纪教育、警示教育、岗位廉政教育，创新方式方法，增强教育实效。深入推进廉政文化建设，不断强化党员干部的廉政意识，大力营造廉荣贪耻的良好氛围。

（十三）抓好廉洁自律各项规定制度的落实。认真落实党员领导干部《廉政准则》及相关规定，重点抓好党员领导干部报告个人有关事项制度的落实。继续抓好部党组建立健全惩治和预防腐败体系2008-2012年工作规划《实施意见》、工委《关于加强和改进中央国家机关各部门在京直属单位反腐倡廉建设工作的意见》的贯彻落实。推动领导干部述职述廉、民主评议、诫勉谈话、经济责任审计等制度的落实。不断规范服务和收费行为，规范评比达标表彰活动。巩固“三公经费”、公务用车和“小金库”专项治理工作成果，切实加强长效机制建设。坚持重大节日和集中休假前的廉政提醒制度，并在节后对落实情况进行检查。严格落实党风廉政建设责任制及“两同时”制度，加强责任考核。

（十四）加强廉政风险防控工作。认真落实部党组关于加强廉政风险防控工作的《实施方案》，引导党员干部进一步统一思想，提高认识，增强做好廉政风险防控工作的积极性和主动性。坚持围绕中心、服务发展，以规范权力运行为核心、以加强风险防范为重点、以强化监督制约为保证，抓好加强廉政风险防控每个阶段、每个环节的工作，确保工作实效。各单位主要负责人切实承担起第一责任人职责，带头查找廉政风险，带头制定防控措施，带头抓好自身和本单位的廉政风险防控工作。做好信访举报工作，加大案件查处力度。

**五、**着眼和谐机关和谐单位建设，不断提升精神文明建设和统战群众工作水平

（十五）推动精神文明创建、做好社会管理综合治理各项工作。在已有工作基础上，继续巩固创建中央国家机关文明单位成果。以转变政府职能、提高依法行政能力为重点，以建设一流队伍为目标，不断深化“创建文明机关争做人民满意公务员”活动。以加强思想道德建设和职业道德建设为重点，扎实推进直属事业单位和部管社团精神文明创建活动。认真落实部党组关于加强和创新社会管理的《意见》，努力解决群众关心的热点难点问题，影响和谐稳定的源头性、基础性问题，构建加强和创新社会管理长效机制。继续做好同“法轮功”等邪教组织斗争的各项工作，维护直属机关稳定，为党的十八大胜利召开创造和谐稳定的环境。

（十六）加强对统战和群众工作的领导。继续做好与统战联系对象和归侨侨眷的联系、慰问工作。加强对工青妇组织的领导和支持，进一步探索群众工作的特点和规律，加强工青妇组织建设，完善工作机制，创新工作方法，更好地动员和组织干部职工为实施“十二五”规划建功立业。充分发挥工青妇组织在构建和谐机关和谐单位中的作用，继续组织开展“讲文明树新风”活动，结合各自特点，广泛开展岗位建功、巾帼建功、业务技能比赛等活动，进一步提高干部职工素质。积极反映干部职工诉求，坚持开展丰富多彩的文体活动，开展经常性“送温暖”活动。巩固和扩大团员主题实践活动成果，深入开展“到基层去、向身边学”主题实践活动及关注民生、关爱弱势群体系列公益活动。积极开展适合女职工特点的活动，为提高女职工的能力素质创造条件。
