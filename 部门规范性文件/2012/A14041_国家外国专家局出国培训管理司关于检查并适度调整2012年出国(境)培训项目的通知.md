# 国家外国专家局出国培训管理司关于检查并适度调整2012年出国(境)培训项目的通知

## 国家外国专家局出国培训管理司关于检查并适度调整2012年出国（境）培训项目的通知

各省、自治区、直辖市及副省级城市外国专家局，新疆生产建设兵团外国专家局，国务院各部门、各直属机构引智归口管理部门：

为落实中央《关于进一步加强因公出国（境）管理的若干规定》（中办发【2008】9号）和《关于坚决制止公款出国（境）旅游的通知》（中办发【2009】12号），切实提高2012年出国（境）培训项目质量和效益，拟于近期对2012年出国培训项目执行情况进行检查，同时对项目进行适度调整，现就有关事项通知如下：

**一、**各地区各部门要全面检查2012年出国（境）培训项目执行情况，准确统计并填写相关信息（附表1、2）。

1、认真检查2012年审批类出国（境）培训项目计划执行情况。各引智归口管理部门对尚未报批执行的审批类项目须进行分析调查，准确掌握项目进展情况，今年确定执行的项目应在10月10日前完成材料申报；已完成报批手续的审批类项目应按计划抓紧执行；已执行完毕的项目需尽快办理经费核销。

2、认真检查并掌握2012年审核类出国（境）培训项目计划执行情况。重点了解已执行项目的培训质量和效果，加强对境外培训机构的效果评估。

**二、**按照“总量控制、计划管理”、“有保有压、服务经济”的要求，从严控制因公出国（境）培训项目调整计划，须在今年批复的年度计划数额内调整。

**三、**各地区各部门调整中拟增加的培训项目，必须与本地区本部门中心工作紧密相关，符合《国民经济和社会发展十二五规划纲要》和《国家中长期人才发展规划纲要（2010-2020）》确定的重点。

1、审批类培训项目：拟增加的审批类项目，除在“增补项目”栏（附表1）汇总外，还须按照项目计划审报要求，填报审批类培训项目申请表；凡当年不能执行的审批类项目，应在“取消项目”栏（附表1）列出并说明原因。

2、审核类培训项目：本着人员增量低于减量、项目分类调整原则，提出微调意向并附增补项目必要性说明。党政干部类、专业技术类和企业管理类项目只能在同类型项目中置换，从严控制党政干部出国（境）培训规模。

以上检查及调整情况，请于7月15日前报送至出国培训管理司。
