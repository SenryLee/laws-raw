# 国土资源部公告2012年第22号――关于设立第二批找矿突破战略行动整装勘查区的公告

## 国土资源部公告（2012年第22号）

关于设立第二批找矿突破战略行动整装勘查区的公告

根据找矿突破战略行动总体部署，国土资源部于2011年3月2日公告发布了首批47片找矿突破战略行动整装勘查区名单及范围。为加快推进找矿突破战略行动，国土资源部决定在全国设立第二批31片找矿突破战略行动整装勘查区，现将其名单及范围予以公告。

为保障整装勘查工作合理布局、有序推进，国土资源部正在组织相关省级国土资源行政主管部门编制整装勘查区实施方案（含勘查工作部署及矿业权设置方案）。自本公告发布之日起，暂停受理整装勘查区内矿业权空白区的新立探矿权采矿权申请（已设探矿权转采矿权仍可正常办理），待整装勘查区实施方案批准后，按方案要求整合和出让矿业权；在方案批准已以前，对急需引入资金开展勘查等特殊情形，由省级国土资源主管部门向国土资源部说明理由，符合规划，经批准，允许新设探矿权。
