# 农业部农机化管理司安全监理处关于开展农机安全生产督导调研工作的通知

## 农业部农机化管理司安全监理处关于开展农机安全生产督导调研工作的通知（农机安[2012]8号）

各省、自治区、直辖市及计划单列市农机（农业、农牧）局（厅、委、办），新疆生产建设兵团农业局，黑龙江省农垦总局、广东省农垦总局：

为贯彻落实《国务院安委会办公室关于开展安全生产督导调研的通知》（安委办明电[2012]4号）要求，进一步推动“农机安全生产年”活动深入开展，有效预防重特大农机事故发生，决定于近期在全国范围内组织开展农机安全生产督导调研活动。现就有关事项通知如下：

**一、**督导内容

（一）贯彻落实2012年安全生产控制指标和《农业部办公厅关于做好农机事故统计报告和分析评估工作的通知》（农办机[2012]8号）的情况。检查各地农机安全生产指标落实、农机事故统计报告和分析评估工作情况。

（二）贯彻落实《安全生产“十二五”规划》（国办发[2011]47号）和《全国农业机械安全监理“十二五”规划》（农办机[2011]58号）情况。检查各地“十二五”期间，农机安全监理工作部署情况。

（三）贯彻落实《农业部办公厅关于贯彻落实农机安全监理惠农政策的通知》（农办机[2012]2号）情况。检查各地对小型微型企业免征农机监理行政事业性收费落实情况。

（四）贯彻落实《农业部办公厅关于严格禁止违规发放拖拉机牌证的通知》（农办机[2011]47号）精神情况。检查各地治理违规办理牌证行为和清理收回违规牌证情况。

（五）各地当前农机安全生产中出现的新情况、新问题、创新性做法，存在的问题及对策建议，部署继续深入扎实开展“安全生产年”活动情况。

**二、**时间安排

督导工作自2012年2月下旬开始至3月。具体时间由各督导组与相关省农业机械化主管部门衔接。

**三、**人员组成

请各省、自治区、直辖市农业机械化主管部门及其农机安全监理机构按照安委办明电[2012]4号文件和本通知的部署要求，组织督导组开展本地区农机安全生产督导调研活动。农业部农业机械化管理司及农业部农机监理总站将组织两个调研组对部分省（区、市）进行重点督导调研。

第一组　农业部农业机械化管理司领导带队。督导地区：吉林、福建。

第二组　农业部农机监理总站领导带队。督导地区：四川、贵州。

**四、**有关要求

（一）各地要高度重视，分管领导带队组成督导组，选派熟悉业务的同志参加督导工作，督导中各地要及时提供有关材料和数据资料，确保督导组圆满完成各项督导调研任务。

（二）督导组要严格遵守厉行节约的各项规定，做到轻车简从，减少陪同，深入基层，采取召开座谈会、实地查看等形式，详细了解情况。

（三）各地切实加大安全知识宣传力度，提高农民安全意识，减少事故隐患，为全国“两会”期间农机安全生产工作营造良好的氛围。

（四）各地要按照工作部署，于3月底前向农业部农业机械化管理司报告督导调研工作总结。
