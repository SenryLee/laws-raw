# 国家文物局关于开展文化遗产保护领域科学和技术研究2013年度重点课题建议征集工作的通知

## 国家文物局关于开展文化遗产保护领域科学和技术研究2013年度重点课题建议征集工作的通知（办博函〔2012〕503号）

各有关单位（文物报、网上发布）：

为贯彻落实《国家文物保护科学和技术发展“十二五”规划（2011-2015年）》，加强行业创新体系建设，进一步调动社会力量参与文化遗产保护科技工作，经研究，我局决定组织开展文化遗产保护领域科学和技术研究2013年度重点课题（以下简称重点课题）建议征集工作。现将有关事项通知如下：

**一、**征集类别与重点范围

2013年度重点课题建议的征集类别主要包括应用基础研究、应用研究和技术开发。

（一）应用基础研究

1.针对我国馆藏文物因劣化机理研究薄弱而制约保护技术进步的现状，以科学揭示文物劣化过程的物理和化学原理为目标，探明材质劣化影响因素、劣化过程和腐蚀产物，建立检测与分析的新方法。

2.针对不可移动文物在自然环境下因材质劣化导致的力学性能降低、结构失衡及濒临危险等状况，以建立不可移动文物结构稳定性评价方法为研究目标，探明影响结构稳定性的常见因素与机理，以及结构整体安全稳定状态的变化与损毁规律，建立结构稳定性诊断评价方法。

（二）应用研究与技术开发

1.围绕金属文物有害锈转化、脆弱陶质文物快速脱盐、脆弱纺织品和纸质文物清洗与接枝加固、竹木漆器微结构修复与整形加固、骨角质文物的生物技术修复等重要紧迫需求，研发共性关键技术。

2.围绕墓葬壁画霉菌防治、遗址博物馆生物病害防治、壁画与石质文物清洗、石窟寺危岩体加固效果评价等重要紧迫需求，研发共性关键技术。

3.围绕考古遗址识别、地下遗迹遗存预探测、考古发掘信息快速记录、脆弱出土文物微环境控制与封存、出土文物与埋藏环境的现场快速分析检测，以及考古发掘过程中各类文化堆积状况和包含物的量化描述等重要紧迫需求，研发共性关键技术和集成技术。

4.以加强博物馆低碳运营工艺设计、提升博物馆陈列展览的文化与艺术表现能力为目标，开展集成技术研究与示范，开展适合于博物馆陈列展览需要的声光电技术、虚拟现实、人机交互、知识工程和新媒体技术等现代技术应用研究。

**二、**推荐要求

（一）课题建议单位应为具有较强科研能力和科研条件，并具有独立法人资格的文博单位、高等学校、科研院所和企业。鼓励多家单位联合推荐。

（二）课题建议负责人应具有3年以上文化遗产保护领域科研经历，且作为负责人的在研省部级以上科研项目（课题）不得超过2项。

（三）应根据重点范围明确提出课题的研究目标和考核指标，提炼出需要解决的理论方法问题或核心和关键技术，突出研究重点。

（四）应围绕研究目标组建研究队伍。鼓励研究队伍跨单位、跨领域合作，充分体现优势互补。

**三、**受理工作

（一）国家文物局科研课题管理办公室（以下简称“课题办”）负责课题建议的受理工作。

（二）受理期限为2012年6月12日至8月10日。课题建议负责人填写课题建议书，经建议单位签字盖章后于8月10日前报送课题办（以邮戳时间为准）；建议书扫描件（PDF格式）于8月10日下午14：00前发送至ktb@sach.gov.cn，逾期将不予受理。

（三）课题办将对课题建议书进行形式审查，有下列情况之一的将不予受理：

1.建议单位或负责人不符合基本条件；

2.建议书编写不符合规定格式。

课题建议书（包括不予受理的建议书）将不予退回，由课题办统一处理。
