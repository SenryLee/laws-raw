# 国家文物局关于新四军第五师司令部旧址之国际招待所旧址文物保护工程勘察设计方案的意见

## 国家文物局关于新四军第五师司令部旧址之国际招待所旧址文物保护工程勘察设计方案的意见（办保函〔2012〕711号）

湖北省文物局：

你局《关于申报新四军第五师司令部旧址之国际招待所旧址文物保护工程勘察设计方案的请示》（鄂文物发[2012]150号）收悉。经研究，我局意见如下：

（一）建筑现状情况描述不清，应补充深化勘察，补充完善建筑原有形制和构造的调查，对建筑原物、原做法和后期改造部分加以区分鉴别。应补充墙体砌筑做法和材料、砖规格，补充关于室内地面、屋面原做法、形制的说明和图纸等。

（二）较多维修措施与建筑现状情况不符，应进一步校核，如屋面现状描述为“无系统排水”，维修方案中要求清理天井排水，前后不符。木装修设计中出现“木楼板”描述，与单层建筑形制不符。屋面做法有冷摊瓦和苫背两种描述，应校核。

（三）应根据现状勘察采取针对性、具体的维修措施。维修设计应避免过于原则、概念化，并补充完善工程的量化控制。

（四）修缮对象为乡村普通民居，在更换、修理木构件时，建议保留原形制特征，避免过于规格化、规整化。建筑外墙面的白灰层罩面做法已形成一定历史感，若清除抹灰易伤及砌筑缝，且不利于墙体稳定，建议维持原状。

（五）图纸图量不足，未能全面、完整表述建筑形制和所存问题，应补充、规范文本和图纸。补充反映正房的横剖面图。补充完善立、剖面图的残损标注，校核图面上的标高与尺寸等。校核文本中的文字错误。

请你局根据上述意见，组织相关单位进一步修改、完善方案，经你局审核后另行报批。

专此。

国家文物局　　　

二〇一二年五月二十五日
