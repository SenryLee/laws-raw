# 中国银监会关于当前重点风险防范和改革发展工作的通知

## 中国银监会关于当前重点风险防范和改革发展工作的通知（银监发〔2012〕47号）

各银监局，各政策性银行、国有商业银行、股份制商业银行、金融资产管理公司，邮政储蓄银行，银监会直接监管的信托公司、企业集团财务公司、金融租赁公司：

上半年以来，在党中央、国务院的正确领导下，面对全球经济金融复杂严峻的形势，我国经济发展总体保持了缓中趋稳的格局，但经济运行中的困难和矛盾仍比较突出。同时，随着经济增速回调，金融改革加快推进，银行业的经营环境、市场结构和发展模式正在发生变化，面临的风险日趋复杂。各银行业金融机构要将思想统一到党中央和国务院对形势的判断上来，充分认识环境的复杂性和风险的不确定性，稳中求进地开展各项工作，更加注重防范风险，进一步深化改革，维护银行体系稳健运行，更为有效地支持实体经济稳步增长。现就银行业重点风险防范及下一阶段银行业改革发展工作提出以下要求，请各银行业金融机构认真贯彻执行。

**一、**加强对重点领域的风险防范

（一）继续扎实推进地方政府融资平台贷款风险管控

各银行总行要充分发挥主导作用，进一步加强平台贷款风险管控。一是要严格平台贷款总量控制。各银行业金融机构应严格按照《中国银监会关于加强2012年地方政府融资平台贷款风险监管的指导意见》（银监发〔2012〕12号）规定，继续加强对平台贷款总量的控制。二是要严格落实平台整改条件。继续按照有关政策要求，持续推动融资平台在抵押担保、贷款期限和还款方式等方面的整改，切实釆取有效措施缓释平台贷款潜在风险。三是要严格执行信贷分类结果。加强平台信贷准入管理，严格执行各行年初自行评定的平台客户信贷分类结果，严格贷款管理。同时要更加细致地做好“分类管理、区别对待、逐步化解”工作，防止“一刀切”，防范资金链断裂，防止由于应贷未贷出现“半拉子”工程。下半年，银监会将加强现场检查，对于平台贷款现金流测算、总量控制、存量贷款风险缓释和信贷分类等方面存在的违规情况，督促落实整改，严肃责任追究。

（二）进一步加强房地产信贷风险管理

一是要不折不扣坚决贯彻落实国家房地产调控政策。银行业金融机构要严格执行二套（及以上）住房认定标准，实行对二套房的差别化首付成数和利率政策，以及三套房停贷政策，配合地方政府认真落实重点城市限购政策，坚决抑制投资投机性购房需求。二是要继续强化房地产贷款风险防控。督促房地产开发企业加快销售，对回笼资金实行封闭管理并及时偿还贷款，防止其违规挪用。对于开发企业在多家银行办理同一项目住房按揭贷款的做法，银行应在银行同业协会的支持下，探索建立信息共享和账户对接机制。要继续做好对房地产开发企业的持续监测和风险动态排查工作，重点关注贷款一年内到期的开发企业资金链情况，对存在还款压力的开发企业，督促其通过转让项目、出售股权、增加抵押物等方式，尽快缓释风险。要密切关注开发企业融资行为，防止其违规套取银行资金。对参与高利贷、资金链断裂甚至涉嫌非法集资的开发企业，应尽早介入开展债权处置。三是要加强房地产信托风险管理。继续执行房地产信托业务事前报告制度，防止盲目扩张。重点关注今明两年到期的房地产信托项目，加强对房地产企业现金流的监测，对于高风险项目，信托公司要做好应对方案，落实责任制。

（三）着力加强信用风险前瞻性管理

一是要努力提高贷款五级分类的准确性。科学细化分类标准，特别是关注类贷款的具体标准。进一步完善贷款质量考核制度，更加注重信用风险计量的前瞻性和科学性，防止不良贷款考核压力导致分类不实。要做好与财税部门的沟通协调，加大拨备计提和损失类贷款核销力度，积极应对贷款风险暴露。二是要有效防范重点行业、重点区域风险。对于“两高一剩”和淘汰落后产能等领域，以及受经济波动影响较大的行业，要加强风险管控，合理设定行业贷款规模。要加强对新兴产业的研究，防止短期内投资过度，形成过剩产能。对于部分经济增速下行明显、企业经营困难加剧、不良贷款上升较快的地区，要开展区域性专项风险排查，制定风险处置预案。三是要切实加强风险管理的前瞻性和全面性。要有效识别各类风险之间的关联性，监测风险传导渠道，加强全面风险管理。建立健全风险预警系统，不断完善压力测试的技术和方法，确保压力测试的结果在银行风险管理中得到有效应用。

（四）毫不动摇抓好案件风险防控

狠抓案件高发领域的防控工作，严格落实重要员工轮岗、对账要求，切实规范柜台业务操作行为。进一步完善内控合规制度建设，提高执行力。充分发挥业务条线、风险及合规管理、内审三道防线的作用，定期开展内控合规管理有效性评估。要强化违规问责和案件报送制度。各银行业金融机构要杜绝案件报送和移送工作中的被动麻木现象，严禁迟报瞒报。

（五）积极强化流动性风险管理

银行业金融机构尤其是中小金融机构要提高负债来源的稳定性。探索主动负债方式，适当降低负债集中度，拓展多元化的负债来源。纠正不规范的吸存行为，严禁通过返还现金、科目转换等方式违规揽储、虚增存款。要加强流动性指标监测，强化日均指标考核，尽快纠正“冲时点”行为。密切跟踪监测金融市场波动，科学测算理财产品、同业往来等业务对现金流的影响，合理规划资金来源和运用，做好流动性压力测试并完善应急计划。

（六）加快提高市场风险管理水平

一是加强对市场风险的有效监控，建立有效的风险管理政策与程序、分析报告机制、重大风险应急机制、新产品和新业务的风险管理机制。二是进一步完善市场风险，尤其是汇率、利率风险的识别、计量、监测和控制方法，加强对风险敞口的准确估值，建立和实施有效的限额管理制度，为市场风险计提充足的资本。三是加强对国内外金融市场的跟踪监测，根据市场变化以及银行风险承受能力，对风险偏好、风险管理政策、程序和资产组合进行必要调整。

（七）切实防范民间借贷、非法集资等风险传染

进一步筑牢与民间借贷、非法集资之间的防火墙。严禁银行从业人员充当资金中介或直接参与民间借贷。对于通过民间借贷搭桥掩盖贷款风险等问题，应予以高度重视。要继续严密监控贷后资金用途和流向，严防信贷资金通过各种途径流入民间借贷市场。尽可能掌握客户参与民间借贷情况，对于参与高利贷、非法集资等违法金融活动的客户，及早釆取措施，维护银行业资产安全。

银行业金融机构是风险防控的责任主体，是风险防控的第一责任人。各机构要层层落实风险防控责任，要加大风险责任追究力度。银监会各部门、各级机构要加强监管工作的有效性和针对性，要进一步落实监管责任。银行业金融机构和银监会系统对各类风险要早发现、早暴露、早处置，防止风险扩大，要严守底线，防止出现区域性、系统性风险。

**二、**更加有效地支持实体经济稳步增长

各银行业金融机构要在坚持“风险可控、商业可持续”原则的基础上，紧密结合经济运行周期特征，及时调整经营策略和信贷政策，优化信贷投向，将有限的信贷资源真正服务于实体经济的有效需求。

（一）继续加大对国家重点建设项目的支持

银行业金融机构要配合国家重大项目实施，积极支持重点项目建设，并把握好支持方式和重点。对于已批准的国家重点建设项目，要做好前期准备，及时给予资金支持。对于已批准的在建续建项目，要按照信贷承诺，提供后续贷款。对于已完工的项目，给予必要的建设配套和生产运营贷款。对重点铁路和公路项目的有效信贷需求继续给予及时支持。同时，要按照国家“十二五”规划要求，加强对经济结构调整、节能减排、环境保护和自主创新等方面的金融服务，将绿色信贷理念落到实处。

（二）持续改进小微企业和“三农”金融服务

在经济下行阶段，部分小微企业经营困难加剧，信贷风险上升。银行业金融机构要科学分析小微企业风险变化，正确区分外部环境恶化引起的周期性风险与自身竞争力下降引起的长期风险，加强对符合产业政策、有市场、有需求、可持续运营的小微企业的金融扶持，并充分考虑企业的承受能力，合理定价，不要一味上浮贷款利率。各银行业金融机构要确保实现今年小微企业贷款增量、增速“两个不低于”的目标。同时，要进一步增强“三农”金融服务能力。保障农田水利等农业基础设施建设、粮食生产和“菜篮子”工程的信贷需求，支持农业科技推广运用。要深入推进农村中小金融机构阳光信贷工程，合理确定分支机构贷款权限，实行信贷过程公开化、透明化管理，提高服务效率，扩大贷款覆盖面。目前正处于夏粮收购的关键时期，要做好粮棉油收购信贷资金的供应与管理。

（三）积极支持保障房等合理住房信贷需求

继续加强对保障性安居工程的信贷支持，重点支持以省级平台为主开展的公租房、廉租房、棚改房等三类保障房建设。支持中低价位、中小套型普通商品房建设。优先办理居民家庭首套真实自住购房按揭贷款。

（四）加大对消费和出口的支持力度

大力发展消费金融，满足多样化的消费融资需求。加强对节能、新技术消费产品、汽车和耐用消费品等领域的信贷支持，进一步发挥汽车金融公司、消费金融公司拉动消费的作用。要努力提高出口金融服务水平。对拥有自主知识产权、核心技术、自主品牌的出口企业，提供多元化的出口融资服务。探索多种方式，对暂时遇到困难但有良好发展前景的出口企业提供融资支持。继续支持风险管理到位的“走出去”企业的合理融资需求。

（五）深入落实不规范经营专项治理各项要求

银行业金融机构要严格执行“七不准”、“四公开”等各项要求，杜绝各种不合理收费。按照“科学合理、公开透明”的原则，在全面公示收费项目的基础上，确保服务收费的合理性。收费项目和价格的确定，既要考虑银行自主定价权，也要兼顾广大金融消费者，特别是低收入群体的承受能力。不断完善客户投诉处理机制。要把推进专项治理与完善公司治理有机结合，将治理要求真正体现在银行内控和发展规划之中。目前，银监会正积极会同国家发改委、人民银行等部门，加快推进《商业银行服务价格管理办法》、《银行服务价格政府定价和政府指导价目录》等规范性文件的制定工作。这些文件正式公布之后，各银行业金融机构要严格贯彻执行，切实完善价格管理，并做好对合理收费项目的宣传解释工作。

**三、**加快推进银行业改革转型

（一）积极推动新监管标准实施

经国务院批准，今年六月份银监会公布了《商业银行资本管理办法（试行）》，标志着国际监管新标准在我国由政策制定阶段转向落地实施阶段。银行业金融机构要结合新监管标准的实施，全面加强风险管理，不断强化自我约束，将监管政策真正转化为自身加强风险管控、稳健经营的内在要求。

一是认真制定落实资本达标规划。按照新监管标准的要求，制定并实施过渡期内达标规划。各银行要统筹考虑和安排资本补充，有计划、有步骤、积极平稳地实现达标。二是做好新标准监管报表填报工作。监管资本的准确计量是新标准能否顺利实施的基础和前提。新监管报表涉及面广、内容复杂、填报要求高，在相当长一段时期内还将是“新旧并行”。银行业金融机构要将新监管报表的准确填报与本机构新监管标准的实施紧密结合，与资本和风险管理水平的提升紧密结合，在IT支持、人员配备、业务培训等方面统筹规划，保证资本充足率报表的准确填报。各机构主要负责人要对本机构各项监管指标数据的真实性负责。三是大中型银行要积极稳妥地实施新资本协议中的内评法。大中型银行要积极落实监管评估意见，加快资本管理高级法准备工作的整改进度。银监会将根据银行整改进展和申请情况，适时开展高级法的验收与核准工作。四是多渠道拓宽资本补充来源。要抓住当前盈利水平较好的有利时机，提高利润留存比例，扩大内源性资本补充。同时，积极探索通过发行优先股、创新资本工具或开拓境外发行市场等方式，多渠道筹集资本。五是优化资产结构，控制风险资产规模，有效配置和使用资本，实现协调可持续发展。

（二）着力加快银行业金融机构差异化战略转型

一是明确市场定位，提高差异化竞争能力。银行业金融机构要积极培育适合自身发展的目标市场、核心客户群、重点业务，开发个性化、差异化、适合客户需求的各类金融产品，在此基础上收取合理的服务管理费，拓展非利息收入，逐渐改变过于依赖利差的盈利模式。二是以利率市场化改革为契机，全面加强风险定价能力建设。要完善金融产品定价管理体系，建立有效的定价策略和技术工具，要兼顾覆盖风险和合理收益的需要，根据特定客户群体的需求和风险特征，不断提高风险定价的科学性，避免跟风盲从，维护理性、有序的竞争环境。三是建立健全科学的激励机制。要结合近期印发的《银行业金融机构绩效考评监管指引》等要求，将业务发展与风险防控统筹考虑，考评指标体系应兼顾效益与风险、当期成果与可持续发展。

（三）进一步加强内部基础建设，切实提高管理能力

新监管标准实施、利率市场化进程加快以及客户对银行服务要求的提高，都对银行业金融机构信息系统建设和数据质量管理提出了更高要求。一是要尽快筑牢信息基础，科学合理规划，加大资源投入，争取在短时期内把信息系统建设推上一个新台阶。同时做好信息科技风险监测防范，确保信息安全，并以此提升管理效率。二是要进一步夯实数据基础，各银行业金融机构要加强数据管理，充实人力资源，完善制度方法，明晰数据流程，探索建立与本机构业务特点和发展战略相匹配的数据信息管理模式，不断提高内部管理数据、监管报送数据和市场披露数据的准确性、及时性和完整性。

中国银行业监督管理委员会
