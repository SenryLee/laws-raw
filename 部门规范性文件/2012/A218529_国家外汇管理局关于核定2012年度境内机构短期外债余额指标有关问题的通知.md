# 国家外汇管理局关于核定2012年度境内机构短期外债余额指标有关问题的通知

（2012年4月16日）

汇发[2012]12号

为促进国际收支基本平衡，国家外汇管理局决定对2012年度境内机构短期外债余额指标总规模基本维持不变。同时，为引导银行配合国家宏观调控政策，支持中西部地区发展，改进小微企业融资环境，适度调减了指标历史基数较大、资金拆入和非居民存款比重较高的银行指标，增加了指标历史基数较小的中小银行指标。银行类金融机构受指标控制的短期外债，每日末余额不得超过外汇局核定的指标。
