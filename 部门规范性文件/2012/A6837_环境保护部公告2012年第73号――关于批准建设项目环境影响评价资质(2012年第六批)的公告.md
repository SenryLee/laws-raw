# 环境保护部公告2012年第73号――关于批准建设项目环境影响评价资质(2012年第六批)的公告

## 环境保护部公告（2012年第73号）

关于批准建设项目环境影响评价资质（2012年第六批）的公告

根据《建设项目环境影响评价资质管理办法》（原国家环境保护总局令第26号）的有关规定，我部对申请建设项目环境影响评价资质（以下简称“资质”）的机构进行了审查。现将资质批准有关事项（2012年第六批）公告如下：

**一、**批准北京博诚立新环境科技有限公司等11家机构资质中的评价范围调整（调整的评价范围详见附件1）。

**二、**批准太原市环境科学研究设计院等8家机构资质中的机构名称变更（变更后的机构名称详见附件2）。

**三、**批准新疆鼎耀工程咨询有限公司等7家机构资质延续（机构名单及评价范围详见附件3）。

**四、**对清华大学等21家机构资质证书中的法定代表人或住所予以变更（机构名单及变更情况详见附件4）。

**五、**因环评专职人员达不到相应资质条件，对包头市核新环保技术有限责任公司等2家机构缩减环境影响报告书评价范围（缩减的评价范围详见附件1）。各机构在缩减的评价范围之内，已与建设单位签订环境影响评价技术服务合同的项目，应于2013年1月31日前，将申请继续完成原项目的书面请示及项目清单（附电子版）和相应的合同原件及复印件报我部，经我部审核后，方可继续完成。

请上述第一至五项中的机构于60日内，到指定领证地点领取资质证书，其中第二项中的机构应在领取资质证书前，办理环境影响评价专职技术人员岗位证书变更和环境影响评价工程师登记手续；第一至五项中的机构应在领证时携带原资质证书正、副本原件；自本公告发布之日起，上述第一至五项中的机构原资质证书正、副本原件及其缩印件同时作废，不得继续使用。

领证地点：环境保护部环境工程评估中心资质管理与培训部（北京安外北苑路28号迪蒙综合楼4层408室）
