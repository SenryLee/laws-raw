# 新闻出版总署关于开展2012年图书质量专项检查活动的通知

## 新闻出版总署关于开展2012年图书质量专项检查活动的通知（新出字[2012]60号）

各省、自治区、直辖市新闻出版局，新疆生产建设兵团新闻出版局，解放军总政治部宣传部新闻出版局，中央和国家机关各部委、各民主党派、各人民团体出版单位主管部门，中国出版集团公司，中国教育出版传媒集团有限公司，中国科技出版传媒集团有限公司：

为深入贯彻落实党的十七届六中全会精神和全国新闻出版工作会议精神，加强出版物质量管理，进一步规范和完善出版单位质量保障体系，进一步提高出版物质量，更好地满足人民群众不断增长的文化需求，迎接党的十八大胜利召开，新闻出版总署将2012年确定为“出版物质量规范年”，对科技图书和文化历史类图书进行重点质量检查，对各出版单位质量保障体系建设和实施情况进行检查。现将有关事项通知如下。

**一、**检查的组织机构

本次检查活动由总署、省级新闻出版行政部门和中央出版单位主管部门共同组织实施。总署统一部署督导，各省级新闻出版行政部门和中央出版单位主管部门对所辖和所属出版单位的科技图书和文化历史类图书、质量保障体系建设和实施情况进行检查。

**二、**检查的原则

本次检查范围包括各出版单位2011年1月至2011年12月出版的科技图书和文化历史类图书（以图书版权页出版时间为准），以及出版单位的质量保障体系建设和实施情况。各省级新闻出版行政部门和中央出版单位主管部门要依据《出版管理条例》、《图书质量管理规定》和《图书质量保障体系》，认真检查，严格执法，杜绝任何形式的地方保护主义和部门保护主义，规范和完善出版单位的质量保障体系，促进出版物质量的提高。

**三、**检查的重点

各省级新闻出版行政部门和中央出版单位主管部门要根据所辖和所属出版单位出版的科技图书和文化历史类图书实际情况，确定检查品种和数量。对于没有出版上述品种图书的出版单位，选择其在规定时间范围内出版的其他品种的图书。各省级新闻出版行政部门和中央出版单位主管部门还要对所辖和所属出版单位的质量保障体系建设和实施情况进行认真检查，督促出版单位进一步规范和完善质量保障体系。

**四、**检查阶段及时间安排

1.出版单位自查阶段。2012年3-4月，各出版单位按照10%的比例对本单位出版的科技图书和文化历史类图书质量进行自查，对本单位的质量保障体系建设和实施情况进行总结，于4月30日前将图书检查报告、质量保障体系总结报告报省级新闻出版行政部门和中央出版单位主管部门。

2.各省级新闻出版行政部门和中央出版单位主管部门抽查阶段。5-7月，省级新闻出版行政部门和中央出版单位主管部门根据出版单位自查书目，视所辖和所属出版单位情况，每家每类至少抽查1种图书；对所辖和所属出版单位的质量保障体系建设和实施情况进行专项检查，于7月31日前将图书抽查结果和质量保障体系检查情况报总署。

3.总署抽查阶段。7-8月，总署重点抽查部分出版单位的科技图书和文化历史类图书，抽查部分出版单位的质量保障体系建设和实施情况。

4.公布检查结果阶段。9-10月，汇总分析各省级新闻出版行政部门和中央出版单位主管部门报送的检查材料，以及总署重点抽查的结果。10月底，对外发布检查结果公告，通报对总署检查出的编校质量不合格图书和相关出版单位的处罚决定。

**五、**报送材料方式

总署出版管理司委托总署出版产品质量监督检测中心接收并整理各省级新闻出版行政部门和中央出版单位主管部门报送的材料和样书。请各省级新闻出版行政部门和中央出版单位主管部门按照本《通知》所要求的时间，将检查材料和样书邮寄至总署出版产品质量监督检测中心，邮寄地址：北京市丰台区太平桥西里38号楼620房间，邮政编码：100073，联系人：夏悦，联系电话：010-63486425、65280664。邮寄纸质材料请在信封外面标注：2012年图书质量专项检查材料。电子版材料发至电子信箱：174885011@qq.com。

各省级新闻出版行政部门和中央出版单位主管部门要认真执行本《通知》所布置的各项工作，可根据实际情况制定具体实施细则。总署将在本次专项检查活动的收尾阶段，召开一次总结会，通报检查中发现的问题，表扬一批在图书质量管理工作中表现突出的省级新闻出版行政部门和中央出版单位主管部门。
