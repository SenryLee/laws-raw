# 中国地质调查局关于2012年中国地质大学等三所高校公共管理硕士研究生招收工作的通知

局属各单位、局机关各部室：

2012年，国土资源部继续与中国地质大学（北京、武汉）、南京农业大学联合培养公共管理硕士（MPA）研究生，现将《关于2012年在国土资源系统培养公共管理硕士（MPA）研究生的通知》（国土资人教函[2012]82号）转发给你们。请各单位人事部门负责本单位的人员推荐和资格审查工作，要注意从具有发展潜力的领导干部和业务骨干中推荐人选。
