# 农业部办公厅关于通报表扬2012年度农产品加工信息工作先进单位与优秀信息员的通知

## 农业部办公厅关于通报表扬2012年度农产品加工信息工作先进单位与优秀信息员的通知（农办企[2012]28号）

各省、自治区、直辖市、计划单列市及新疆生产建设兵团农产品加工业主管部门：

中国国家农产品加工信息网建立8年来，通过不断加强功能建设，提高信息宣传与服务能力，目前已成为内容丰富、特色鲜明、功能齐全的农产品加工业权威性网站。今年以来，加工网重点在新闻质量、宣传推广、功能拓展等方面加大力度，访问量不断攀升，日点击量达10万余次，并与多家网站建立了链接共享，充分发挥了新闻宣传、政策指导、信息服务等方面优势，为促进农产品加工业发展起到了重要作用。

中国国家农产品加工信息网取得的成绩，离不开全国信息工作单位的大力支持与广大信息员的辛勤劳动。在今年信息编辑报送工作中，涌现出一批优秀信息员，不仅信息报送数量多、质量高，而且主动关注行业热点与焦点，积极编写原创信息，为推进网站信息内容建设做出了重要贡献。

为鼓励先进、巩固成果、激励工作，经综合评比，决定对福建省农产品加工推广总站等10家先进单位及马军等10名优秀信息员予以通报表扬。

希望受表扬的单位和个人再接再厉，努力推进中国国家农产品加工信息网再上新台阶。各单位要认真学习先进单位和优秀信息员的工作经验，更加扎实地做好农产品加工信息宣传工作。
