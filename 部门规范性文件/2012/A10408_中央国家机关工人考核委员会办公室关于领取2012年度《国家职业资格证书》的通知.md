# 中央国家机关工人考核委员会办公室关于领取2012年度《国家职业资格证书》的通知

根据中央国家机关工人考核委员会办公室工作安排，现将2012年度职业技能鉴定合格标准及证书领取事宜通知如下：

**一、**合格标准

职业技能鉴定理论、实操考核成绩满分100分，60分合格。

**二、**领证须知

中央国家机关工人考核委员会办公室于2012年10月24、25、26日，在北京北方朗悦酒店紫竹桥店集中发放2012年度职业技能鉴定考核成绩单和《国家职业资格证书》。届时，单位人事部门持本单位介绍信统一领取。

参加本年度理论、实操考试单项成绩不合格者，可在下一年度报名参加补考。请各单位注意报名时间。

**三、**交通路线

开车路线：行至西三环紫竹桥后向西前行，第一个出口到辅路，继续行至车道沟10号院，中国兵器大厦和工商银行中间的路口向右拐进一直向北即到。

乘车路线：乘334、114、360、714、347、632、437、334等可以到车道沟桥东站下，下车后向东直行30米到车道沟10号院即可。

地铁线路：地铁动物园站下，北口出，然后西边10米公交站换乘，347、714、437、114、360等线路均可。
