# 中国证券监督管理委员会创业板发审委2012年第23次会议审核结果公告

中国证券监督管理委员会创业板发行审核委员会2012年第23次会议于2012年3月27日召开，现将会议审核结果公告如下：

北京太空板业股份有限公司（首发）获通过。

浙江金卡高科技股份有限公司（首发）获通过。

创业板发行监管部
