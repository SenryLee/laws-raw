# 国家质量监督检验检疫总局公告2012年第47号――关于发布《电梯监督检验和定期检验规则--液压电梯》等3个特种设备安全技术规范的公告

## 国家质量监督检验检疫总局公告（2012年第47号）

关于发布《电梯监督检验和定期检验规则--液压电梯》等3个特种设备安全技术规范的公告

根据《特种设备安全监察条例》规定，国家质检总局制定了《电梯监督检验和定期检验规则--液压电梯》、《电梯监督检验和定期检验规则--自动扶梯与自动人行道》以及《电梯监督检验和定期检验规则-杂物电梯》等3个特种设备安全技术规范，现予批准发布施行。
