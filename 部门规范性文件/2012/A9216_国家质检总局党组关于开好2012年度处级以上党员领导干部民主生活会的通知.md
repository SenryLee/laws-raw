# 国家质检总局党组关于开好2012年度处级以上党员领导干部民主生活会的通知

## 国家质检总局党组关于开好2012年度处级以上党员领导干部民主生活会的通知（国质检党组发[2012]149号）

各直属检验检疫局党组，认监委、标准委党组，总局机关各司局，各直属挂靠单位：

根据中共中央纪委、组织部《关于开好2012年度县以上党和国家机关党员领导干部民主生活会的通知》（组通字〔2012〕33号），为使处级以上党员领导干部更好地学习党的十八大精神，坚持讲政治、顾大局、守纪律，紧密结合本单位领导班子和领导干部的思想、作风实际，开好2012年度质检系统处级以上党员领导干部民主生活会。现就有关要求通知如下：

**一、**民主生活会主题

学习贯彻党的十八大精神，保持党的纯洁性。

**二、**抓住主要环节，精心做好准备工作

要严格按照《关于改进县以上党和国家机关党员领导干部民主生活会的若干意见》（中组发〔2000〕3 号） 的要求，认真做好会前各项准备工作。一是组织学习。要认真组织学习党的十八大报告和十七大以来历次全会精神，学习胡锦涛同志在庆祝建党90周年大会上的重要讲话和十七届中央纪委第七次全会上的重要讲话精神，学习《党员领导干部廉洁从政若干准则》、《关于党员领导干部报告个人有关事项的规定》等党纪条规，进一步增强政治意识、大局意识、廉洁自律意识和遵纪守法观念。要坚持自学和集中学习相结合，专题研讨和辅导报告相结合，提高学习实效，为开好民主生活会奠定坚实的思想基础。二是征求意见。要向干部群众通报2011年度民主生活会整改措施落实情况，接受监督。要充分发扬民主，通过发放征求意见表、召开座谈会等多种形式广泛征求干部群众的意见，并将收集到的意见原汁原味地反馈给领导班子及领导干部本人。三是开展谈心。领导班子主要负责同志与班子成员之间、班子成员相互之间都要进行谈心，充分交流思想，交换意见，达到促进团结、共同提高的目的。四是自我剖析。领导干部本人要紧密结合民主生活会主题，根据学习心得和群众所提意见，认真进行自我剖析，撰写发言提纲。要重点剖析思想、作风、纪律、廉政等方面存在的不足及原因。

**三、**紧紧围绕主题，认真开展对照检查

民主生活会上，各单位党组（党委、总支、支部）要对2011 年度民主生活会整改措施落实情况进行说明和总结。领导班子成员要紧紧围绕会议主题，联系思想和工作实际，认真开展党性分析和对照检查。对照检查的内容是：对照学习党的十八大报告和胡锦涛同志在十七届中央纪委第七次全会上关于保持党的纯洁性的重要论述，在保持思想纯洁、组织纯洁、作风纯洁和清正廉洁方面找差距、摆不足，明确努力的方向。要对照检查坚定理想信念，加强党性锻炼，遵守政治纪律，贯彻落实党的路线方针政策和重大决策部署、保持政令畅通的情况；检查自觉践行党的宗旨，密切联系群众，加强领导班子和领导干部作风建设，解决干部群众反映最突出问题的情况；检查坚持党的干部路线，公道正派选人用人，正确对待个人晋升，遵守组织人事纪律的情况；检查贯彻落实民主集中制，按照集体领导、民主集中、个别酝酿、会议决定的原则决定重大事项，自觉接受党组织和人民群众监督的情况；检查落实党风廉政建设责任制，遵守领导干部廉洁从政有关制度规定及执行个人有关事项报告制度的情况。剖析检查要全面深刻、触及思想和灵魂，并做好自查自纠。

深入开展批评与自我批评。要针对领导班子及个人思想、工作中存在的问题和征求意见的情况，认真开展批评和自我批评，防止和纠正民主生活会上谈工作多谈思想少、讲成绩多讲问题少的现象，切实增强民主生活会的思想性、政治性和原则性。领导班子主要负责人要切实发挥好“第一责任人”的作用，带头开展批评与自我批评，带头详细报告个人有关事项；班子成员之间要互相开展批评。自我批评要正视问题，剖析根源；相互批评要实事求是，开诚布公。要避免简单地以会前谈心代替会上开展批评与自我批评的情况。

**四、**注重实效，制定和落实整改措施

认真进行整改。领导班子及成员对群众普遍关心、反映强烈和民主生活会上查找出来的问题，要逐个进行研究，有针对性地提出整改措施，明确具体责任人。会后，要及时制定整改措施落实方案，明确整改重点，落实整改责任，限时进行整改。本次民主生活会形成的整改措施和干部群众对上次民主生活会整改落实情况，要在一定范围内向干部群众通报。

**五、**加强督促指导，不断提高民主生活会质量

认监委、标准委党组，各直属检验检疫局党组，各直属、挂靠单位在开好本级领导班子民主生活会的同时，要组织好所属处级以上党员领导干部的民主生活会。按照一级抓一级的原则，严格落实上级党委（党组）成员指导下级党组织民主生活会制度，上级党委（党组）成员至少要参加1个下级领导班子的民主生活会。

总局直属机关党委（政工办）、人事司和监察局，要做好各直属检验检疫局党组、总局机关各司（厅、局）和在京各直属、挂靠单位领导班子民主生活会的指导和督促检查工作。

民主生活会可安排在第四季度召开，最迟不晚于2013年第一季度。各直属检验检疫局在民主生活会前15天，其他单位在民主生活会前一周，要将召开民主生活会的具体时间、地点报民主生活会的联系单位（附件1、2），同时报总局直属机关党委（政工办）。各直属检验检疫局报总局直属机关党委（政工办）。

各单位要在民主生活会后15天内上报民主生活会专题报告。民主生活会专题报告统一报总局直属机关党委（政工办），同时分别抄送总局人事司和监察局。民主生活会报告内容包括召开会议的情况、领导班子成员发言材料、会前征求到的干部群众意见材料、会后制定的整改措施和上一年度民主生活会整改措施落实情况等。各单位要把坚持民主生活会制度和会上对照检查、会后整改落实的情况作为考核评价领导班子和主要领导干部的重要内容。
