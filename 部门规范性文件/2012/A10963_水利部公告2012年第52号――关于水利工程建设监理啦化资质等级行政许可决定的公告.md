# 水利部公告2012年第52号――关于水利工程建设监理啦化资质等级行政许可决定的公告

## 水利部公告（2012年第52号）

关于水利工程建设监理啦化资质等级行政许可决定的公告

根据《水利工程建设监理规定》（水利部令第28号）和《水利工程建设监理单位资质管理办法》（水利部令第29号公布，水利部令第40号修改）规定，经审核和公示，现作出水利工程建设监理单位资质等级行政许可决定：

同意宜昌委工程建设监理中心等42家单位取得水利工程施工监理专业甲级资质，北京中城建建设监理有限公司等70家单位去的水利工程施工监理专业乙级资质，湖南泽通实业有限公司等219家单位取得水利工程施工监理专业丙级资质；同意黄河勘测规划设计有限公司等10家单位取得水土保持工程施工监理专业甲级资质，吉林松辽工程监理监测咨询有限公司等33家单位取得水土保持工程施工监理专业乙级资质，河南宏宇工程监理咨询有限公司等69家单位取得水土保持工程施工监理专业丙级资质；同意黄河国际工程咨询（河南）有限公司等5家单位取得机电及金属结构设备制造监理专业甲级资质，山西黄河水利工程咨询有限公司等11家单位取得机电及金属结构设备制造监理专业乙级资质；同意中水淮河工程有限责任公司等21家单位取得环境保护监理专业资质（不分级）。

关于领取2012年监理单位资质证书的说明

**一、**从9月17日起，各流域机构、各省（自治区、直辖市）水利（水务）厅（局）、新疆生产建设兵团水利局请派专人到我部建设与管理司统一领取今年批准的监理单位资质证书，按照水利部公告2012年第52号许可的监理单位名单进行换发或者首发。

**二、**监理单位可通过原申报渠道从各流域机构、各省（自治区、直辖市）水利（水务）厅（局）、新疆生产建设兵团水利局联系领取证书。

**三、**监理单位如果急用，也可联系确认后，携带本单位出具的介绍信自行到我部建设与管理司领取。

**四、**每个单位可领取水利部公告2012年第52号1份，监理单位资质证书正本1份、副本4份。其中：

1、监理单位资质证书正本无封面，副本使用深蓝色封面，业务手册使用红色封面。

2、增加或者晋升资质的单位换发全套证书，但不换发封面，在领取证书时需同时交回原证书正副本。

3、新批准监理单位应同时领取监理单位业务手册4份。

**五、**各流域机构、各省（自治区、直辖市）水利（水务）厅（局）、新疆生产建设兵团收回的监理单位旧证书请统一进行销毁。
