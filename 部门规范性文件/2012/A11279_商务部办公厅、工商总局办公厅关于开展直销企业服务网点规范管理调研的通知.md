# 商务部办公厅、工商总局办公厅关于开展直销企业服务网点规范管理调研的通知

## 商务部办公厅、工商总局办公厅关于开展直销企业服务网点规范管理调研的通知（商办秩函[2012]958号）

各省、自治区、直辖市商务主管部门、工商行政管理局，各计划单列市商务主管部门：

为规范直销企业经营行为，促进直销业健康发展，商务部、工商总局决定就直销企业服务网点规范管理开展专题调研。现将有关事项通知如下：

**一、**请各地商务、工商部门加强沟通合作，互相配合，共同做好相关调研工作。商务部、工商总局将组成联合调研组，近期赴部分地区开展实地调研（行程另行通知），请配合调研组做好组织协调工作。

**二、**请各地商务、工商部门按照服务网点管理工作调研提纲（见附件1）要求，就服务网点管理工作现状、存在问题及建议形成报告，于2012年9月30日前报商务部（市场秩序司、外资司）和工商总局（直销监管局）。

**三、**商务部将在直销行业管理信息系统开设“2012年服务网点调研专栏”，请各地商务主管部门通知本地区直销企业，于2012年9月30日前通过“2012年服务网点调研专栏”填报《服务网点明细情况表》（见附件2），将《直销企业服务网点情况汇总表》（见附件3）及本企业服务网点管理情况、直销产品退换货情况报告（报告提纲见附件4）通过省级（含计划单列市）商务主管部门、省级工商行政管理局报商务部（市场秩序司、外资司）和工商总局（直销监管局）。

附件1

服务网点管理工作调研提纲

**一、**直销企业服务网点核查工作基本情况、存在问题及意见、建议。（包括：对服务网点的选址、硬件设施、管理制度、人员配备等方面有无细化要求，对加强直销企业服务网点变更管理的意见建议等）

**二、**直销企业服务网点监管工作基本情况、存在问题及意见、建议。

**三、**商务、工商部门在直销管理工作中的协作配合情况及意见、建议。

**四、**直销企业、有关政府部门、专家、消费者等对服务网点设立、核查、监管工作的意见、建议。

**五、**服务网点在提供直销产品展示、信息咨询、退换货及其他服务方面实际发挥的作用。

**六、**其他意见、建议。

注：

1.直营（自建）：是指服务网点由直销企业投资建设并直接管理的方式。

2.加盟（授权）：是指直销企业与其他单位、个人签订协议，服务网点由后者投资建设并直接管理的方式。

3.代理商：是指与直销企业签订委托代理合同（不发生产品所有权转移），以直销企业名义销售该企业产品的经营者。

4.经销商：是指向直销企业购买产品，以自己的名义销售该企业产品的经营者。

5.营业执照：是指服务网点法定代表人或负责人在相同地点因从事产品销售等经营活动而办理的营业执照。

6.服务网点以其他方式设立的，负责人还有其他兼职身份的，请在备注中简要说明。

7.变更其他信息：是指《服务网点情况表》中除“城市”、“所在区县”以外的其他信息发生变更。“城市”、“所在区县”信息发生变更的，属于“减少服务网点”。

附件4

服务网点管理及直销产品退换货报告提纲

**一、**服务网点管理

（一）本企业关于服务网点的设立标准及要求（选址、硬件设施、管理制度、人员配备等）。

（二）本企业服务网点变更是否重新报当地商务主管部门进行核查，并报商务部备案。

（三）本企业服务网点发生违规经营的案件情况，本企业采取的预防和惩戒措施。

（四）对完善服务网点设立、管理的意见建议。

**二、**直销产品退换货

（一）本企业向消费者、直销员提供的直销产品退换货方式及各种退换货方式的具体操作流程。

（二）2011年全年、2012年上半年分别向消费者、直销员退换货案件数/产品数、金额；每种退换货方式所占比例。

（三）对完善直销产品退换货制度的意见建议。
