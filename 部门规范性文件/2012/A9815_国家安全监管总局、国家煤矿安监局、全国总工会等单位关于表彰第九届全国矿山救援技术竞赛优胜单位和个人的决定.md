# 国家安全监管总局、国家煤矿安监局、全国总工会等单位关于表彰第九届全国矿山救援技术竞赛优胜单位和个人的决定

（安监总应急〔2012〕126号）

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局、总工会、团委，有关产煤省煤炭行业管理部门，各省级煤矿安全监察局，神华集团公司、中煤能源集团公司：

第九届全国矿山救援技术竞赛于2012年8月27日至29日在宁夏回族自治区石嘴山市成功举办，来自全国25个省（区、市）和新疆生产建设兵团的30支矿山救援队伍、270名矿山救护指战员参加了竞赛，充分展示了我国矿山救援队伍和救护指战员勤学苦练、拼搏进取、奋勇争先的优良作风和敬业精神，涌现出一批思想过硬、纪律严明、作风顽强、技术精湛的优胜代表队和优秀队员。国家安全监管总局、国家煤矿安监局、全国总工会、共青团中央研究决定，对竞赛中获得优异成绩的单位和个人进行表彰（名单详见附件），并授予荣誉称号。

希望受到表彰的单位和个人，珍惜荣誉、戒骄戒躁、勇于创新、再创佳绩。各单位要以受到表彰的集体和个人为榜样，学习他们顽强拼搏、奋勇争先的优良作风和严肃认真、精益求精的敬业精神。各有关单位要认真总结参加本次矿山救援技术竞赛的经验教训，将这次竞赛作为一个新起点， 进一步强化矿山救援队伍日常训练，推动队伍训练科学化、制度化、规范化，不断提升矿山救援队伍的整体素质和战斗力，为建设更加高效的应急救援体系和推动矿山应急救援事业发展作出新的、更大的贡献。
