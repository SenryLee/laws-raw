# 国务院国有资产监督管理委员会关于表扬2012年度中央企业管理提升活动优秀组织单位的通报

## 国务院国有资产监督管理委员会关于表扬2012年度中央企业管理提升活动优秀组织单位的通报（国资发改革〔2012〕224号）

中央企业管理提升活动启动以来，按照国资委的统一部署，在中央企业积极努力下，活动总体进展良好，取得了阶段性成效。中央企业高度重视管理提升活动，全面梳理管理短板和薄弱环节，自觉将管理提升活动与企业日常经营紧密结合，坚持边查边改，积极开展开源节流、降本增效，有效应对了不利的外部环境，为实现保增长、保稳定奠定了坚实基础。

为总结经验，鼓励先进，促进活动深入开展，根据2012年度各中央企业管理提升活动组织推进及关键节点完成情况，经研究，决定授予中国核工业集团公司等40家企业 “2012年度中央企业管理提升活动优秀组织单位”称号，并予以通报表扬。

各中央企业要进一步提高认识，把管理提升活动作为贯彻落实党的十八大精神的重要举措，加强相互学习、相互交流，为实现做强做优、培育具有国际竞争力的世界一流企业做出新的贡献。
