# 外国专家局出国培训管理司关于协助做好2012年度境外培训机构评估年检工作的通知

各驻外办事机构：

为配合开展2012年度境外培训机构年检工作，按照“国（境）外培训渠道管理暂行办法”的要求，请协助做好以下工作：

**一、**及时了解掌握2012年度各相关境外培训机构业务开展情况，按照公布的“2012年度境外培训机构名册”，核查机构法人、联系人、联系方式等基本信息及其变动情况，请签字盖章确认。

**二、**督促这些培训机构提交今年以来接待团组的总结报告，认真审查其真实性，在其报告上签字盖章并提出意见建议。

请在2012年9月5日前，将以上材料发传真或电子邮件到出国培训管理司。
