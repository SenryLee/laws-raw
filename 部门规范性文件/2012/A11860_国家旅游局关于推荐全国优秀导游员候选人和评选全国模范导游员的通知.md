# 国家旅游局关于推荐全国优秀导游员候选人和评选全国模范导游员的通知

## 国家旅游局关于推荐全国优秀导游员候选人和评选全国模范导游员的通知（旅发〔2012〕45号）

各省、自治区、直辖市旅游局（委）：

近年来，广大导游员作为我国旅游从业人员队伍的重要力量，在服务游客、奉献旅游的过程中，爱岗敬业、恪尽职守，表现了良好素质和精神风貌，涌现出许多感人至深、可歌可泣的先进人物和事迹。为树立榜样、弘扬正气，充分调动广大导游员的工作积极性，提升导游员的服务意识和服务水平，在旅游行业树立导游员的良好形象，经全国评比达标表彰工作协调小组批准，国家旅游局决定，2012年评选表彰全国优秀导游员200名、全国模范导游员10名。现就有关事项通知如下：

**一、**推荐评选范围和表彰名额

（一）推荐评选范围：持有导游证或讲解员证，从事导游讲解工作一般在5年以上，导游讲解服务时间每年不少于100个工作日，5年内无扣分记录。

（二）表彰名额：此次表彰“全国优秀导游员”200名、“全国模范导游员”10名（名额分配详见附件一）。

**二、**推荐评选条件

（一）“全国优秀导游员”评选条件

1.思想道德素质好

⑴ 热爱祖国，拥护党的路线、方针、政策。

⑵ 遵纪守法，遵守社会公德和职业道德，诚实守信。

⑶ 认真执行《导游人员管理条例》及有关规定，为游客提供热情周到的优质服务。

2.导游业务能力强

⑴ 导游专业功底扎实，刻苦钻研业务，有创新精神。

⑵ 知识面宽，熟悉各相关景区点的自然文化历史背景，导游技能技巧熟练，语言生动、文明。

⑶ 实践经验丰富，具有较强的应变能力、协调能力和处置实际问题的能力。

3.工作业绩突出

⑴ 工作勤奋，表现出色，有先进事迹。

⑵ 执行重大任务表现突出，完成任务好。

⑶ 获得过相关技能称号或有关方面的表彰。

（二）“全国模范导游员”评选条件

以“全国优秀导游员”评选条件为基础，同时具备下列条件之一：

1. 在保护国家、集体、游客生命财产安全，维护国家、集体、游客利益以及捍卫国家法律、法规，防止重大事故、应对突发事件，抵制行业不正之风等方面有重大贡献。

2. 注重提升导游服务质量，忠实践行诚实守信，积极借鉴国内外先进经验，做到文明服务、个性服务、细微服务，整体服务质量在全行业具有较强示范作用。

3. 在参加国家重大活动和平时工作中，具有很强的应变能力、协调能力和处理实际问题的能力，经验丰富、业绩突出，在行业中享有较高威信。

4. 事迹突出，具有先进性、创新性和典型性，能发挥模范带头作用，在行业内影响广泛。

**三、**推荐评选程序和要求

（一）严格履行程序，坚持逐级推荐

坚持公平、公正、公开的原则，严格履行“两审三公示”的推荐程序。首先由基层单位经民主程序提出推荐人选，并在本单位公示3天；然后经单位所属地县级以上旅游行政部门自下而上逐级审核，由省级旅游行政部门根据名额分配和评选条件遴选产生全国优秀导游员候选人名单，在本地区公示3天，并按时将推荐材料报全国旅游系统评选表彰工作领导小组办公室审核；审核通过后，按差额推荐的原则，由全国模范导游员评审小组研究提名，经全国旅游系统评选表彰工作领导小组审定，从210名全国优秀导游员候选人中确定10名全国模范导游员和200名全国优秀导游员人选，在全国范围内公示5天，并下发表彰决定。

（二）严格评选纪律，确保评选质量

对未严格按照评选条件和规定程序推荐的个人，经查实后撤销其评选资格。对于在推荐评选和授予荣誉称号工作中有严重渎职或者弄虚作假、借机谋取私利、收受贿赂等违法违纪行为的人员，按照有关规定予以处理。

（三）按时报送材料，确保工作进度

1. 全国优秀导游员候选人推荐报告（一份），内容包括：人选产生程序、单位意见及公示结果，一律使用A4纸打印。

2. 《全国优秀导游员候选人推荐表》（一式三份，见附件二），推荐表可到国家旅游局网站下载（www.cnta.gov.cn）。

3. 推荐候选人近期正面免冠正装2吋彩色照片1张、工作照1张（照片背面标注人名）。

请各省、自治区、直辖市旅游局（委）和新疆生产建设兵团旅游局于10月15日前将以上材料的纸质版和电子版报送全国旅游系统评选表彰工作领导小组办公室。逾期不报，视为自动放弃。

**四、**奖励办法

（一）在全国范围内下发表彰决定，授予200名导游员“全国优秀导游员”荣誉称号；授予10名导游员“全国模范导游员”荣誉称号。

（二）召开表彰大会，颁发证书和奖章。

（三）“全国模范导游员”予以导游等级奖励晋升一次，最高晋升等级为高级；“全国优秀导游员”予以导游等级考试中加20分的奖励一次。

**五、**组织领导

成立全国旅游系统评选表彰工作领导小组，由国家旅游局有关局领导和司室领导组成，负责本次评选表彰工作的组织领导和审定工作。领导小组成员：
