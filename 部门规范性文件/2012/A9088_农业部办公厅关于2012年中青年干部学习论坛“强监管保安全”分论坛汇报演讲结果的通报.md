# 农业部办公厅关于2012年中青年干部学习论坛“强监管保安全”分论坛汇报演讲结果的通报

## 农业部办公厅关于2012年中青年干部学习论坛“强监管保安全”分论坛汇报演讲结果的通报（农办质[2012]65号）

部机关各司局和直属事业单位，各有关省级农业（畜牧兽医、渔业、农垦）厅（局、委、办）和农科院（所）：

为推进学习型机关建设，提高中青年干部素质能力，在部机关各司局、各直属单位和各地农业部门的大力支持下，10月31日，农业部农产品质量安全监管局在农业部大楼举行了“强监管保安全”分论坛汇报演讲。经过评委对各位优秀论文作者（代表）汇报演讲的综合评定，农业部农产品质量安全中心杨玲同志荣获回报演讲特等奖，农业部科技发展中心王艳同志和河南省农业科学院李淑芳同志荣获汇报演讲一等奖，农业部农产品质量安全中心陈思同志、农业部农村经济研究中心刘洋同志和中国农业科学院油料作物研究所丁小霞同志荣获汇报演讲二等奖，现予通报，予以表扬。请农业部农产品质量安全中心指导杨玲同志做好参加农业部中青年干部学习论坛总论坛汇报演讲的准备工作。

农业部办公厅
