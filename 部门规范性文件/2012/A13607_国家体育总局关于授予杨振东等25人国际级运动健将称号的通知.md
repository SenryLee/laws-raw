# 国家体育总局关于授予杨振东等25人国际级运动健将称号的通知

## 国家体育总局关于授予杨振东等25人国际级运动健将称号的通知（体竞字[2012]105号）

各省、自治区、直辖市、新疆生产建设兵团体育局，总参军训和兵种部体育训练局、总政宣传部文化体育局，各行业体协，有关体育院校，各运动项目管理中心：

根据《运动员技术等级管理办法》的规定，按照《运动员技术等级标准》，经审核，现授予滑冰、滑雪、赛艇、皮划艇、举重、田径、游泳、体操、排球、羽毛球、高尔夫球等11个项目，杨振东等25人国际级运动健将称号，名单如下：
