# 中共国家安全监管总局党组关于认真学习宣传贯彻党的十八大精神的通知

## 中共国家安全监管总局党组关于认真学习宣传贯彻党的十八大精神的通知（安监总党〔2012〕23号）

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局党组，各省级煤矿安全监察局党组，总局和煤矿安监局机关各司局、应急指挥中心及各直属事业单位、社团组织党委（总支、支部）：

党的十八大是在我国进入全面建成小康社会决定性阶段召开的一次十分重要的大会，是一次高举旗帜、继往开来、团结奋进的大会。为认真学习宣传贯彻党的十八大精神，进一步推动安全发展战略的实施，促进全国安全生产形势持续稳定好转，根据中央和中央国家机关工委的部署，现就有关要求通知如下：

**一、**充分认识学习宣传贯彻党的十八大精神的重大意义，切实把思想认识统一到党的十八大精神上来

党的十八大高举中国特色社会主义伟大旗帜，以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观为指导，分析了国际国内形势发展变化，回顾总结了过去五年的工作和党的十六大以来的奋斗历程及取得的历史性成就，确立了科学发展观的历史地位，提出了夺取中国特色社会主义新胜利必须牢牢把握的基本要求，确定了全面建成小康社会和全面深化改革开放的目标，对新的时代条件下推进中国特色社会主义作出了全面部署，对全面提高党的建设科学化水平提出了明确要求。党的十八大报告旗帜鲜明、思想深刻、求真务实，描绘了全面建成小康社会、加快推进社会主义现代化的宏伟蓝图，为党和国家事业进一步发展指明了方向，是我们党团结带领全国各族人民夺取中国特色社会主义新胜利的政治宣言和行动指南，是马克思主义的纲领性文献。大会通过的《中国共产党党章（修正案）》，体现了党的重大理论观点和重大工作部署，对以改革创新精神全面推进党的建设新的伟大工程、提高党的建设科学化水平提出了明确要求。

认真学习宣传贯彻党的十八大精神，要深刻领会党的十八大主题，高举中国特色社会主义伟大旗帜，以邓小平理论、“三个代表”重要思想、科学发展观为指导，解放思想，改革开放，凝聚力量，攻坚克难，坚定不移沿着中国特色社会主义道路前进，为全面建成小康社会而奋斗；深刻领会过去5年和10年党和国家事业取得新的历史性成就，同时要居安思危，进一步认真解决前进道路上的困难和问题；深刻领会科学发展观的历史地位和指导意义，必须更加自觉地把推动经济社会发展作为深入贯彻落实科学发展观的第一要义，更加自觉地把以人为本作为深入贯彻落实科学发展观的核心立场，更加自觉地把全面协调可持续作为深入贯彻落实科学发展观的基本要求，更加自觉地把统筹兼顾作为深入贯彻落实科学发展观的根本方法；深刻领会中国特色社会主义的丰富内涵和夺取中国特色社会主义新胜利的基本要求；深刻领会全面建成小康社会和全面深入改革开放的目标；深刻领会社会主义经济建设、政治建设、文化建设、社会建设、生态文明建设等方面的重大部署；深刻领会全面提高党的建设科学化水平，确保党始终成为中国特色社会主义事业坚强领导核心的总体要求。

全国安全监管监察系统要迅速掀起学习宣传贯彻党的十八大精神的热潮，切实把思想和行动统一到党的十八大精神上来，全面把握党的十八大提出的重大思想、战略举措和目标任务对安全生产工作的新要求，更加自觉地用党的十八大精神武装思想、指导实践，在以习近平同志为总书记的党中央坚强领导下，高举中国特色社会主义伟大旗帜，以科学发展观为行动指南，毫不动摇、与时俱进地推进安全生产工作不断向新水平新成效迈进。

**二、**紧密联系实际贯彻落实党的十八大精神，进一步明晰工作思路，大力推进安全发展

党的十八大报告强调要“强化公共安全体系和企业安全生产基础建设，遏制重特大安全事故”，充分体现了中央对安全生产工作的高度重视，明确了新时期安全发展的重点任务和努力方向，是实施安全发展战略的具体化要求。强化公共安全体系建设，要求为实施安全发展战略提供组织和制度保障，充分调动各级各类资源和力量，把安全生产纳入经济社会发展的全过程，齐抓共管，促进安全生产与经济社会一体化、持续协调发展，实现安全生产长治久安。强化企业安全生产基础建设，进一步突出了企业作为安全生产的责任主体，明确了实施安全发展的着眼点和着力点，要求抓住影响安全生产的关键环节，加强安全监管，严格执法监察，夯实安全发展根基。遏制重特大安全事故，是我国现阶段安全生产工作最迫切、最现实、最重要的任务，是实施安全发展战略的重要目标，要求各级安全监管监察机构充分认识到我国仍处于生产安全事故多发易发的特殊历史时期，安全生产工作的长期性、复杂性和艰巨性仍很突出，必须牢记使命，忠于职守，始终不渝地为维护人民群众生命财产安全而不懈努力。

学习贯彻党的十八大精神，要着重围绕以下八个方面，进一步研究完善思路，推进工作：一是大力实施安全发展战略。安全发展是科学发展的重要内容，也是科学发展的重要保障。要坚持把安全发展的理念落实到社会管理、生产经营建设的每一个环节，把实现安全发展的目标作为衡量各地区、各行业领域、各生产经营单位安全生产工作的基本标准，实现安全与发展有机统一，切实走安全发展之路。二是进一步完善安全监管监察体制机制。按照加强和创新社会管理的要求，推进安全监管监察工作创新，以强化基层安全监管监察能力为重点，建立完善覆盖全面、监管到位、监督有力的政府监管和社会监督体系，着力增强安全执法水平和效果。三是切实强化安全生产责任落实。进一步完善以企业主体责任、政府和部门监管责任、属地管理责任为主要内容的安全生产责任制度，突出强化企业法定代表人、实际控制人第一责任者的责任，把安全生产作为企业固本强基的重要举措纳入企业发展战略，健全安全管理机构和规章制度，加大安全投入，加强技术改造、隐患排查治理和安全生产标准化建设，强化安全基础。四是扎实推进安全生产法治化建设。抓紧修订制定《安全生产法》、《矿山安全法》、《安全生产应急管理条例》等相关法律法规，认真落实《国务院关于进一步加强企业安全生产工作的通知》（国发〔2010〕23号）、《国务院关于坚持科学发展安全发展促进安全生产形势持续稳定好转的意见》（国发〔2011〕40号）等重要文件所明确的相关政策措施。坚持依法治安，继续严厉打击非法违法生产经营建设行为，治理纠正违规违章行为，依法依规严肃事故查处和责任追究。五是全面提高安全科技支撑能力。按照实施创新驱动发展战略的要求，着力构建以企业为主体、市场为导向、产学研相结合的安全生产技术创新体系，加强安全生产关键技术装备研发，大力实施安全先进适用项目推广工程，不断提高安全生产机械化、自动化、信息化水平。六是着力加强安全应急救援体系建设。坚持一手抓预防、一手抓应急，完善7个国家级和14个区域性矿山应急救援基地，加快建设其他行业领域国家救援基地。坚持与现代化应急救援要求相适应，注重加强专业化救援队伍建设，扩充配备性能可靠、机动性强的救援装备设施，切实增强事故快速救援的实战能力。七是持续加强安全教育培训。切实抓好以企业主要负责人和安全生产管理人员、特殊工种人员为重点的专项培训，加大以农民工为重点的全员培训力度，强化安全法制教育和实践技能培训，积极培育先进的安全文化，引领打造一支安全素质过硬的职工队伍。八是从严抓好安全监管监察队伍建设。坚持以人为本、立党为公、执政为民，以维护人民群众生命财产安全为最高职责，从增强安全监管执法能力的实际需要出发，切实加强思想建设、组织建设、作风建设、反腐倡廉建设和制度建设，深入开展创先争优、“争做安全发展忠诚卫士，创建为民务实清廉安监机构”等主题实践活动，着力建设作风扎实、业务精通、严格执法、廉洁奉公的安全监管监察队伍。

**三、**以党的十八大精神为指导，切实加强当前安全生产工作

今年以来，通过全社会各方面的共同努力，全国安全生产状况继续呈现总体稳定、持续好转的发展态势，事故总量、较大事故、重特大事故进一步下降，但安全基础仍不牢固，威胁安全生产的各类事故隐患仍很突出。目前到年底一个多月的时间内，是稳定安全生产形势、实现继续深入扎实开展“安全生产年”活动目标的关键阶段。全国安全监管监察系统要坚持以党的十八大精神为指导，自觉做到思想不放松、监管不放松、执法不放松，乘势而上、紧上抓紧、严上加严，突出关键问题，抓住薄弱环节，严格监管执法，狠抓工作落实，确保安全生产“三项目标任务”的实现。

（一）毫不松懈地推进“打非治违”专项行动。对年底前一些地方和企业可能出现的突击生产、盲目复产复工等苗头性、倾向性问题和重点非法违法问题，要抓住不放，在组织开展“打非治违”专项行动“回头看”过程中，将“打非”与“治违”紧密结合，注重“回头”严管、严查、严打，加强重点地区、重点行业领域和单位的安全整治，严防非法违法行为反弹回潮，做到彻底治理、不留后患。

（二）进一步加大煤矿和非煤矿山整顿关闭力度。结合转变经济发展方式、调整产业结构，以攻坚的决心和措施，务必在煤矿和非煤矿山整顿关闭上抓深入、求实效，取信于民。要将关闭任务一一落实到县乡和企业单位，抓好关闭目标、时间、责任、政策和保障措施“五落实”。对今年年底前要关闭的625处小煤矿，要登报公示，盯住不放，确保关闭到位。要认真落实《国务院办公厅转发安全监管总局等部门关于依法做好金属非金属矿山整顿工作意见的通知》（国办发〔2012〕54号）精神，实施激励推动政策，加快整顿工作进度，确保实现今年关闭目标。

（三）继续深化隐患排查治理。切实加强煤矿、非煤矿山、交通运输、危险化学品、烟花爆竹、建筑施工、民用爆炸物品、冶金、消防等重点行业领域隐患排查治理，特别是要针对冬季和临近年底的季节性、阶段性特点，有针对性地加强安全专项整治。要把煤矿安全作为重中之重，加强重大隐患挂牌督办和现场治理，该停产整顿的绝不含糊，该取缔关闭的绝不动摇。要坚持“一矿出事故、万矿受教育”，发挥事故警示教育作用，切实改进安全生产工作，严密防范同类事故重复发生。

（四）切实加强安全生产基础建设。根据党的十八大提出的新思想新观点新要求，认真总结分析安全生产工作的规律特点和实践经验，着眼于强化安全生产基础建设、建立完善安全生产长效机制，深入研究本部门、本单位当前和明年的安全生产工作重点，破解安全发展难题，将贯彻党的十八大精神真正转化为推动安全生产工作的实际行动。

**四、**高度重视，强化学习宣传贯彻党的十八大精神工作的组织领导

学习好、领会好、宣传好、贯彻好、落实好党的十八大精神，是全国安全监管监察系统当前和今后一个时期的首要政治任务。各级党组织要高度重视，切实增强政治意识、大局意识、责任意识，把学习宣传贯彻党的十八大精神摆上重要议事日程，切实加强组织领导，原原本本学习党的十八大报告和党章，学习习近平同志在党的十八届一中全会上的重要讲话精神，利用多种形式，提高学习成效。中共国家安全监管总局党组在中央国家机关工委的指导下，创新学习形式，党组中心组（扩大）学习党的十八大精神会议将在线直播。各级领导干部特别是各单位党政主要负责同志要以身作则、带头学习，理解吃透党的十八大精神，掌握其中的新思想新理论；要率先垂范、带头宣讲，结合本地区、本单位实际，深入讲解安全生产新形势新任务，充分调动广大干部职工解放思想、勇于创新、真抓实干的积极性。要精心组织，处理好工学关系，科学制定学习计划，明确学习内容和时间，设计学习思考研讨题。要周密部署，分专题、分层次、分时段开展各具特色的学习活动，通过组织宣讲、辅导讲座、集中办班、专题研讨、座谈交流等形式，增强学习效果，并对所属事业单位、社会团体全覆盖。安全监管监察系统内报刊、政府网站要设置专栏专题，及时反映学习贯彻动态，登载辅导材料以及基层同志的体会文章，促进学习宣传贯彻党的十八大精神活动广泛开展。

要注重联系实际，把学习活动融入加强安全生产工作中，做到目标同向、安排同步、工作同力，形成两手抓、两促进的工作机制，推动学习宣传贯彻党的十八大精神向广度和深度拓展，凝聚力量，攻坚克难，进一步加强安全生产工作，推动实施安全发展战略，实现全国安全生产形势持续稳定好转，为全面建成小康社会创造更加稳定的安全生产环境。

请各单位将学习贯彻党的十八大精神情况及时报送或抄报中共国家安全监管总局党组。党的关系在地方的，要同时报地方党委。

中共国家安全监管总局党组
