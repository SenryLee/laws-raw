# 国家质量监督检验检疫总局关于举办总局直属机关青年五四奖章表彰会暨“到一线去，向基层学”调研实践活动启动仪式的通知

各单位团组织：

为贯彻落实创先争优活动的有关部署和要求，在总局直属机关团员青年中积极营造崇尚先进、学习先进、争当先进的氛围，引导团员青年“到群众中去、拜人民为师”，总局直属机关团委决定于5月4日举办直属机关青年五四奖章表彰会暨“到一线去，向基层学”调研实践活动启动仪式。现将有关事宜通知如下：

**一、**时　间：2012年5月4日（周五）上午10：00

**二、**地　点：总局机关419会议室

**三、**议　程：

1. 宣读“中央国家机关青年五四奖章”表彰决定和“总局直属机关青年五四奖章”表彰决定；

2. 为“中央国家机关青年五四奖章”获得者和“总局直属机关青年五四奖章”获得者颁奖；

3. 请“中央国家机关青年五四奖章”获得者和“总局直属机关青年五四奖章”获得者代表发言；

4. 播放总局“下基层、访民情、强质检”活动片，介绍今年开展活动情况；

5. 青年干部代表宣读倡议书；

6. 直属机关党委领导讲话。

**四、**参加人员：

1. “中央国家机关青年五四奖章”获得者；

2. “总局直属机关青年五四奖章”获得者；

3. 各单位团组织负责人；

4. 各单位团员青年代表（5-10人）。

**五、**要　求：

开展主题实践活动，引导青年深入基层，是今年中央国家机关各级团组织的一项重要工作，各单位团组织要高度重视，精心设计，结合本单位实际，认真组织各类专题调研实践锻炼活动，引导青年到基层单位去，向实践学习，向先进模范学习，以实际行动迎接党的十八大。

二〇一二年四月二十五日
