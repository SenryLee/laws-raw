# 国家体育总局直属机关党委关于在创先争优活动中开展基层组织建设年的通知

各直属党委、支部：

中央确定2012年为基层组织建设年。近日，中央组织部印发了《关于在创先争优活动中开展基层组织建设年的实施意见》（中组发[2012]6号，以下简称《意见》），全面部署了基层组织建设年的有关工作。为认真落实《意见》要求，扎实开展基层组织建设年各项工作，现将有关事项通知如下：

**一、**总体要求

开展基层组织建设年活动，是深化创先争优活动的重要举措，对于加强党的基层组织建设，迎接党的十八大胜利召开，具有十分重要意义。

基层组织建设年要紧紧围绕“强组织、增活力、创先争优迎十八大”这一主题，全面落实党的十七大和十七届四中全会提出的基层党建工作各项任务，着力解决基层组织建设中的突出问题，切实增强基层党组织的创造力、凝聚力、战斗力，不断完善基层组织建设体制机制，按照“抓落实、全覆盖、求实效、受欢迎”的工作要求，扎实推进基层组织建设年各项工作，使基层党组织战斗力、基层党组织书记素质、党员队伍生机活力、基层党建工作保障水平和制度化水平得到全面提升。

**二、**基本内容

基层组织建设年，要紧密结合各部门、各单位工作实际，既要全面贯彻《意见》要求，整体推进各项工作，又要突出重点，集中力量抓好基层组织建设的大事、难事、实事，重点做好以下工作：

1、认真做好调查摸底，对基层党支部进行分类定级。3月底前，由各直属党委、支部进行自查，切实摸清本单位党组织设置情况，确定好每名党员的组织归属。组织机构设置不健全、不合理的，要迅速建立和重新设置，特别是有分支机构的单位，要根据实际情况，建立或理顺党组织关系，着力解决好管理缺位、虚化、脱档等问题。国家运动队的党员，要按规定转移正式或临时党组织关系，具有3名以上正式党员的，要成立正式或临时党支部，常年集训的国家队，争取设立正式党支部。3月底，各直属党委要将本单位党组织机构设置情况报送直属机关党委备案。

通过调查，切实把握基层党组织建设情况，在此基础上对基层党支部进行分类定级。直属机关党委制订《国家体育总局基层党支部分类定级实施办法》，统一评定标准，对各直属党支部党建工作进行综合考核测评，根据考评结果，评定出“好、较好、一般、较差”四个等级。各直属党委按照《国家体育总局基层党支部分类定级实施办法》确定的程序，制订符合本单位实际的评级标准，对所属党支部进行分类定级。通过分类定级，达到巩固先进、推动一般、整顿后进的目的。分类定级在3月底前完成。

2、及时进行换届选举，增强基层党组织活力。2012年任期届满或超任期的直属党委、支部，要全部进行换届选举。确有特殊情况，不能按期换届的，要向直属机关党委写出书面报告，说明理由。各直属党委，要监督和指导所属超任期党委、支部完成好换届选举。

3、落实制度，健全组织生活。各直属党委、支部，要制订年度党组织活动计划，基层党支部，要增强自主开展活动的能力，认真落实好“三会一课”制度，坚持每季召开一次支部党员大会、上一次党课，每月召开一次支部委员会，一至两次党小组会。党员领导干部要带头讲党课。坚持每年召开两次组织生活会，对党员进行一次民主评议，开展一次党性分析，每名党员至少每半年要向党支部进行一次思想汇报。保持基层党组织活动规范化、经常化，严格加强对党员队伍的监督、管理，增强党员党性意识，加强党性修养。

4、配合中央国家机关工委开展“走进基层党支部”活动。中央国家机关工委将于2012年7月前，开展“走进基层党支部、总结支部工作法”活动，深入调研、挖掘和宣传基层党支部“服务中心、建设队伍”的好经验好做法。直属机关党委按照工委的要求，要做好先进典型的推荐提名工作，安排记者对先进典型进行蹲点采访，广泛宣传其先进事迹和经验。

5、大力加强基层党支部书记培训。各直属党委要以加强基层党组织建设、增强基层党组织战斗力为主题，开展党支部书记培训。要进一步扩大基层党支部书记培训规模，提高培训质量，丰富培训内容，改进培训方式，不断增强党支部书记“抓党建、带队伍、促发展”的意识和能力。直属机关党委将举办培训示范班。

**三、**加强组织领导和考核评价

各直属党委、支部要把加强基层组织作为今年创先争优活动的重点，以创先争优为动力，全面落实基层组织建设年各项任务。直属党委、支部主要负责同志要认真履行第一责任的职责，带头抓基层党建工作，领导班子成员要达成共识，形成抓基层党建工作的合力。要研究制订基层组织建设年工作计划，指定专人负责各项具体工作。

要将基层组织建设年各项工作与健全完善党建工作制度有机结合，年底，各直属党委、支部要建立至少一项实在管用的基层党建工作制度；要与单位业务工作有机结合，发动广大党员建言献策；要与破解难题相结合，至少解决一个制约基层党建工作发展的难题；要与解决群众实际困难相结合，至少解决一个群众期盼的实际问题。

要研究建立基层党建工作考核评价体系。党员领导干部，要带头将党建工作纳入党员领导干部述职、评议党员领导干部、考核党员领导干部的范围。做到述职述党建，评议评党建，考核考党建。

各直属党委、支部要尽快制订基层组织建设年工作方案，并将工作方案、基层组织活动计划、基层组织分类定级情况及结果报直属机关党委备案。有关工作情况请及时上报。

国家体育总局基层党支部分类定级实施办法

根据中央国家机关工委印发的《关于认真落实〈关于在创先争优活动中开展基层组织建设年的实施意见〉的通知》要求，为了在基层组织建设年强化基层党建工作，对国家体育总局各基层党支部进行分类定级。通过分类定级，达到巩固先进、推动一般、整顿后进的目的，促进基层党组织建设全面发展。

**一、**分类定级等级

按照工委要求，基层党组织分类定级共分为好、较好、一般、较差四个等级。

**二、**分类定级对象

体育总局所属全部基层党支部均应参加分类定级。

**三、**实施步骤

（一）直属党支部的分类定级（包括机关党支部、人力中心党支部、基金中心党支部）。

1、制订分类定级考核标准。直属机关党委制订统一考核参考标准，将党支部工作内容进行量化打分；

2、召开支部党员大会，对分类定级工作进行动员部署，使党员群众明确测评内容。

3、组织自评。组织所属党员、群众对党支部建设情况进行测评打分，党员、群众参与率不低于95%。根据测评结果确定初步等次。得分90分（含）以上的为“好”；70（含）--89分为较好；60（含）--69分为一般；60分以下为较差。

4、召开党支部委员会，根据自评结果、本支部党建工作水平，研究确定本支部应申报的评定等次。

5、上报评定申请材料。向直属机关党委上报评定申请材料，充分阐述所应评定等次的理由。

6、直属机关党委召开常委会，依据各直属党支部的申请材料和自评结果，确定各直属党支部的评定等次。

7、对被评定为“较差”等级的党支部，由直属机关党委对支部书记进行谈话，责令限期整改。年底再次进行评定。

（二）直属党委所属党支部的分类定级

1、召开全体党员大会，对分类定级工作进行动员部署，使党员、群众明确分类定级的意义和内容。

2、制订分类定级工作方案，指定负责人。

3、结合实际，参照直属党支部分类定级考核参考标准，研究制订所属党支部分类定级考核标准。

4、各基层党支部组织自评。由各基层党支部组织所属党员、群众对党支部建设情况进行测评打分，党员、群众参与率不低于95%。根据测评结果确定初步等次。得分90分（含）以上的为“好”；70（含）--89分为较好；60（含）--69分为一般；60分以下为较差。

5、召开党支部委员会，根据自评结果、本支部党建工作水平，研究确定本支部应申报的评定等次。

6、上报评定申请材料。向直属党委上报评定申请材料，充分阐述所应评定等次的理由。

7、召开党委会，依据各基层党支部的申请材料和自评结果，确定各所属党支部的评定等次。

8、对被评定为“较差”等级的党支部，由直属党委书记对支部书记进行诫勉谈话，责令限期整改。年底再次进行评定。

**四、**结果上报

（一）直属党支部应报送的材料

1、3月23日前，报送评定等次申请材料、自评结果。

2、3月29日前，报送分类定级工作总结。

3、被评定为“较差”等级的党支部，4月6日前，报送整改措施。

（二）直属党委应报送的材料

1、3月29日前，报送分类定级总结和所属党支部的评定结果。

2、4月6日前，将被评为“较差”等级的党支部的整改措施报直属机关党委备案。
