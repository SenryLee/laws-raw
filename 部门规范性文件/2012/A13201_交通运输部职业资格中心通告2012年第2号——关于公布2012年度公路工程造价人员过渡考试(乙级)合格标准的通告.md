# 交通运输部职业资格中心通告2012年第2号——关于公布2012年度公路工程造价人员过渡考试(乙级)合格标准的通告

## 交通运输部职业资格中心通告（2012年第2号）

关于公布2012年度公路工程造价人员过渡考试（乙级）合格标准的通告

2012年度公路工程造价人员过渡考试（乙级）合格标准已经确定，现公布如下：

公路工程造价基础理论及相关法规：60分

公路工程造价的计价与控制：60分

公路工程造价案例分析：60分

公路工程技术与计量：60分

二○一二年七月十七日
