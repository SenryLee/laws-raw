# 国家自然科学基金委员会国际合作局关于2012年度国家自然科学基金委员会与韩国国家研究基金会协议项目申报截止日期延期及申报路径更新的通知

**一、**因韩方申报系统原因，应韩方要求，2012年度国家自然科学基金委员会与韩国国家研究基金会协议项目申报截止日期延长至2012年2月2日（以邮戳为准）。

**二、**因我委项目申报系统升级，2012年度国家自然科学基金委员会与韩国国家研究基金会协议项目申报路径更新如下：

合作交流：登陆ISIS科学基金网络信息系统后，点击界面办事快捷通道的“项目申请”－点击右侧“新增项目申请”－展开“国际（地区）合作与交流项目”－点击“合作交流（组织间合作协议项目）”右侧“填写申请”－选择合作协议下拉菜单中“NSFC－NRF（中韩）”。然后按系统要求输入要依托的基金项目批准号后即进入具体申请书填写界面。

双边学术研讨会：登陆ISIS科学基金网络信息系统后，点击界面办事快捷通道的“项目申请”－点击右侧“新增项目申请”－展开“国际（地区）合作与交流项目”－点击“在华召开国际（地区）学术会议（组织间合作协议项目）”或“出国（境）参加协议双（多）边学术会议（组织间合作协议项目）”右侧“填写申请”－选择合作协议下拉菜单中“NSFC－NRF（中韩）”。然后按系统要求输入要依托的基金项目批准号后即进入具体申请书填写界面。
