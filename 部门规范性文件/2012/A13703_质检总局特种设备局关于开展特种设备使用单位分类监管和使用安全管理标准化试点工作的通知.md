# 质检总局特种设备局关于开展特种设备使用单位分类监管和使用安全管理标准化试点工作的通知

## 质检总局特种设备局关于开展特种设备使用单位分类监管和使用安全管理标准化试点工作的通知（质检特函〔2012〕41号）

各省、自治区、直辖市质量技术监督局：

为进一步加强特种设备使用环节安全监察工作，提高特种设备安全监察工作的有效性和针对性，落实《2012年特种设备安全监察与节能工作要点》，现将2012年开展特种设备使用单位分类监管和特种设备使用安全管理标准化工作（以下简称分类监管和管理标准化工作）的有关事项通知如下，请各地结合实际，认真组织落实。

**一、**工作任务及要求

为稳步推进分类监管和管理标准化工作，在2011年部分省市试点工作的基础上，今年在全国开展试点工作，以不断完善和验证此项工作的相关方法及准则，为建立该项工作的长效机制奠定基础。

（一）试点对象。

对在用特种设备数量10万台以上（以2011年统计数据为准，含10万台）的省（直辖市、自治区），每省至少选择20家特种设备使用单位作为试点，同时开展分类监管和管理标准化工作。试点单位应当包括危险化学品生产或使用、充装类和其他涉及公共安全的特种设备使用单位（每类至少2家）。其他省试点单位的数量和类型自定。

（二）试点工作依据和方法。

使用单位分类方法应用基于风险的评价准则，采用基于风险的特种设备安全监管关键技术研究课题（“十二五”国家科技支撑计划项目）的研究成果《特种设备使用单位风险评价实施细则》（试行）、《特种设备使用单位风险评价打分表》（试行）。为减轻工作量，我局组织专家编写了特种设备使用单位风险评价系统软件及其使用说明。各地可采取企业自评，监察人员或行业协会等第三方复评的方式利用软件进行试点分类评价，并将评价结果进行总结，完成试点实证分析报告。管理标准化工作采用的使用管理标准为我局组织部分省市编制的《特种设备使用安全管理规范》（试行）。推进管理标准化工作时，各地可与当地安全生产标准化建设工作相结合，根据实际情况，在《特种设备使用安全管理规范》（试行）的基础上，通过制订相应的地方标准，细化要求，推进使用单位达标。

（三）工作要求。

1．推进分类监管和管理标准化工作时，各地应与特种设备“打非治违”和“风险排查”工作及日常安全监察工作相结合。

2. 各地要努力探索不同类别使用单位的管理措施，对风险类别不同的使用单位可采取挂牌、列入黑名单、与安全生产准入挂钩、调整现场安全监察频次等措施实施差异化监管。

3．请各地完成试点后及时进行总结，并将总结报告和分类监管实证分析报告在2012年11月15日前提交至总局特种设备局锅容处。
