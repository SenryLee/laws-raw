# 工业和信息化部关于2012年三季度通信建设工程质量监督和安全生产情况的通报

## 工业和信息化部关于2012年三季度通信建设工程质量监督和安全生产情况的通报（工信部通函〔2012〕617号）

各省、自治区、直辖市通信管理局，中国电信集团公司、中国移动通信集团公司、中国联合网络通信集团有限公司，相关单位：

为进一步提高通信建设工程质量和安全生产水平，现将2012年三季度全国开展通信建设工程质量监督和安全生产的情况通报如下：

**一、**基本情况

2012年三季度，31个省（自治区、直辖市）通信管理局报送了通信工程质量监督情况（见附件1），电信企业共申报工程质量监督项目24866项，办理竣工验收备案项目6991项，通信工程质量监督机构开展实体抽查项目568项，抽查发现问题62项（见附件2）。

本季度未收到通信建设工程安全生产事故报告。

**二、**存在的主要问题

通过通信工程质量监督机构开展的质量监督抽查和巡查，发现在通信工程质量和安全生产方面主要存在以下问题：

（一）部分电信企业未按基本建设程序进行工程建设，工程开工时间早于设计合同、施工合同签订时间；依法应招标而未招标；未按合同约定的时间组织竣工验收；施工合同中无安全生产费的支付条款；未办理质量监督申报和备案；档案资料归档不规范；将工程发包给不具有相应资质的企业；监理费取费不符合相关规定；设备加固不符合抗震设防要求，机房无消防设备，存在安全生产隐患。

（二）部分施工企业不重视安全生产工作，专职安全生产人员未取得《安全生产考核合格证》；光缆与电力线交越未作保护，光缆布放不规范；电源线进站房未采用埋入方式；光缆加强芯未与机架绝缘，接地线线径不符合要求；存在超资质施工问题。

（三）部分设计企业的设计文件未提出具体的安全控制环节、防控点及安全保障措施；工程预算未按通信行业定额编制；设计文件没有体现强制性标准条文；设计图纸没有加盖出图专用章；以分公司名义签订设计合同。

（四）部分监理企业制定的安全生产实施细则缺乏针对性，未对施工单位的施工组织计划进行审查。

**三、**2012年二季度通报问题的整改情况

中国电信对存在问题的8个省的项目进行了逐项整改，对涉及参建单位的问题督促其整改落实，存在问题的25个项目已全部整改完成。并要求各省级公司继续开展自查和整改，巩固工程建设领域突出问题专项治理的工作成果，加强安全生产费支付管理，优化流程管理，合法合规完成工程建设任务。

中国移动要求存在问题的11个省公司分析问题产生原因，提出整改措施，存在问题的32个项目已全部整改完成。同时要求各公司从遵循基本建设程序和施工及验收质量要求、履行质量监督申报和备案手续、工程档案资料完整齐备、安全生产管理到位，严格设计质量管理、规范招投标活动等方面入手，完善管理制度，保证各项管理制度落实到位。

中国联通要求存在问题的10个省级公司逐一对项目落实整改，存在问题的27个项目已全部整改完成。要求加强项目全过程管理，对项目批复、项目进度、投资完成等情况进行跟踪与分析，确保建设项目按时按质完成；同时责成相关单位逐步完善项目管理、招标采购管理、工程建设管理等相关制度，固化工程监管流程，建立健全工程管理长效机制。

**四、**相关要求

各通信管理局要继续巩固通信建设领域突出问题专项治理成果，督促企业进一步完善工程建设管理各项制度，加大通信工程质量抽查力度，对工程建设违法违规行为予以严厉查处，确保工程建设质量和安全。同时做好全年通信工程质量监督和安全生产管理工作总结，于2013年1月20日前将全年工作总结与四季度开展工程质量监督和安全生产工作的情况一并报部（通信发展司）。

各电信企业要将通信建设领域突出问题专项治理要求落到实处，规范建设行为，杜绝同类问题的发生，并逐步建立通信建设工程管理长效机制。请各电信集团公司总部于2013年1月20日前将《2012年三季度抽查工程项目存在问题汇总表》所列项目的整改情况汇总报部（通信发展司），部将在下次通报中对整改情况进行通报。
