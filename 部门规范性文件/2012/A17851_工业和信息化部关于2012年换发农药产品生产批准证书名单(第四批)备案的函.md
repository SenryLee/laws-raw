# 工业和信息化部关于2012年换发农药产品生产批准证书名单(第四批)备案的函

## 工业和信息化部关于2012年换发农药产品生产批准证书名单（第四批）备案的函（原材料司备函[2012]76号）

根据《农药管理条例》的有关规定，现将审核合格并换发农药生产批准证书的50个产品名单予以备案。有关事项如下：

**一、**本次换发农药生产批准证书的有效期规定如下：原药品种农药生产批准证书有效期为5年；加工、复配、分装品种农药生产批准证书有效期为3年。

**二、**获证产品应当在有效期满3个月前向工业和信息化部提出换证申请，逾期将不予办理。

**三、**获得农药生产批准证书的企业必须在产品包装上注明生产批准证书编号。
