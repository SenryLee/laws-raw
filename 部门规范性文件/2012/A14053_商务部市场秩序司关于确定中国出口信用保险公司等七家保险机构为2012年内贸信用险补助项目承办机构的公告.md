# 商务部市场秩序司关于确定中国出口信用保险公司等七家保险机构为2012年内贸信用险补助项目承办机构的公告

根据《关于2012年支持开展放心肉服务体系建设等项目有关问题的通知》（财办建[2012]100号）要求，经保险机构自愿申报、主管部门资格审定及对外公示程序，现确定以下七家保险机构为2012年国内贸易信用保险保费补助项目承办保险机构：

1.中国出口信用保险公司、2.中国平安财产保险股份公司、3.中国人民财产保险股份公司、4.中国太平洋财产保险股份公司、5.安邦财产保险股份有限公司、6.中国大地财产保险股份有限公司、7.中银保险有限公司。
