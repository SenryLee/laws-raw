# 电监会办公厅、发展改革委办公厅、能源局综合司关于黑龙江省开展电力直接交易试点的通知

黑龙江省工信委、物价局，东北电监局：

《黑龙江省电力用户与发电企业直接交易试点实施方案》（黑工信电力联呈〔2012〕130号）收悉。经研究，现通知如下：

**一、**同意哈药集团制药总厂、鸡西浩市新能源有限公司2家电力用户与华电哈尔滨第三发电厂等11家发电企业（见附件）开展电力直接交易试点，直接交易价格由交易双方协商确定。

**二、**黑龙江省电力用户与发电企业直接交易试点输配电价暂按《国家发展改革委办公厅关于核定黑龙江省电力用户与发电企业直接交易试点输配电价有关问题的批复》（发改办价格[2012]2909号）确定的标准执行，损耗率由黑龙江省物价局参照近两年电网实际损耗率确定。

**三、**发电企业、电力用户和电网企业应按国家电监会、国家工商行政管理总局联合印发的《大用户与发电企业直接交易购售电合同（示范文本）（试行）》和《大用户与发电企业直接交易输配电服务合同（示范文本）（试行）》（电监市场[2009]29号）签订相关合同，并报政府有关部门和电力监管机构备案。

**四、**参与直接交易的发电企业直接向大用户供电的发电容量，在安排计划上网电量时适当剔除。

**五、**其他事项按照国家电监会、国家发展改革委和国家能源局联合下发的《关于完善电力用户与发电企业直接交易试点工作有关问题的通知》（电监市场[2009]20号）相关规定执行。按照上述条件，若需扩大试点范围或增加试点企业，请按程序报批后执行。

附件：黑龙江省电力用户与发电企业直接交易试点企业名单
