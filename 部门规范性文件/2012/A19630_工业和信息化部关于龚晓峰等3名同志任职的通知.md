# 工业和信息化部关于龚晓峰等3名同志任职的通知

## 工业和信息化部关于龚晓峰等3名同志任职的通知（工信部任[2012]10号）

工业和信息化部国际经济技术合作中心：

工业和信息化部党组决定：

龚晓峰任工业和信息化部国际经济技术合作中心主任（正局级）；

曹建华任工业和信息化部国际经济技术合作中心副主任（正局级）；

姜冠雄任工业和信息化部国际经济技术合作中心副主任（副局级）。

以上3名同志的任职时间自2012年3月1日党组会决定之日起计算。
