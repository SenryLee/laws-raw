# 中共教育部党组关于黄泰岩等同志职务任免的通知(2012)

## 中共教育部党组关于黄泰岩等同志职务任免的通知（教党任[2012]48号）

中共武汉大学委员会：

经研究并与中共湖北省委商得一致，任命黄泰岩同志为中共武汉大学委员会副书记，蒋昌忠同志为中共武汉大学委员会副书记、纪律检查委员会书记，冯友梅同志为中共武汉大学委员会委员、常委，谈广鸣同志为中共武汉大学委员会常委；免去俞湛明同志的中共武汉大学委员会副书记、常委、纪律检查委员会书记，黄从新同志的中共武汉大学委员会常委职务。

中共教育部党组　　

二○一二年五月二十九日
