# 国家知识产权局办公室关于开展2012年全国专利信息领军人才和专利信息师资人才选拔工作的通知

各省、自治区、直辖市、计划单列市、新疆生产建设兵团、副省级城市知识产权局；局机关各部门，专利局各部门，局直属各单位、各社会团体：

为切实加强专利信息人才队伍建设，根据国家知识产权局《关于加强全国专利文献信息传播与利用工作的意见》（国知发办字〔2011〕151号），“十二五”期间我局将在全国选拔培养100名左右的专利信息领军人才和300名左右的专利信息师资人才。现就2012年全国专利信息领军人才和专利信息师资人才选拔工作通知如下。

**一、**选拔目标

2012年度在全国范围内选拔30名左右专利信息领军人才，其中：专利信息战略运用方向10名，专利信息分析与竞争情报方向10名，企业专利信息管理方向5名，专利信息资源组织和管理方向5名。

2012年度在全国范围内选拔100名左右专利信息师资人才。其中：专利信息检索方向40名，专利信息分析方向30名，专利信息利用方向30名。

**二、**选拔范围

专利信息领军人才和师资人才的选拔，在全国范围内开展，人选范围涵盖知识产权系统、专利信息服务机构、企事业单位、高等院校和科研机构、图书情报机构等。

**三、**选拔条件

（一）专利信息领军人才选拔条件

1.具有较高的政治素养、良好的思想品德和职业道德。

2.知识结构合理、具有较强研究能力。

3.从事专利信息相关工作5年以上。

4. 近3年在公开刊物发表专利信息相关论文3篇以上（含3篇），或主持省（自治区、直辖市）级以上（含省级）专利信息利用相关项目/课题2次以上（含2次），或主编专利信息相关论著1部以上（含1部）。

5.专利信息战略运用方向领军人才，应熟悉国家重大发展战略等宏观政策，掌握国内外知识产权发展态势，能够对专利信息在经济发展、企业经营中的运用提出建设性、导向型的观点和建议，为国家、地区和企业专利战略制定提供决策参考。

专利信息分析与竞争情报方向领军人才，应对专利信息利用有较深入研究，精通检索技能和方法，掌握专利信息分析和竞争情报研究的理论和方法，能够熟练利用专利信息挖掘技术、市场和经济情报，能够独立组织、管理或指导专利分析与竞争情报项目。

企业专利信息管理方向领军人才，应具有企业管理经验，熟悉专利信息检索、分析流程及工具，熟悉企业知识产权管理体系，能够结合企业实际情况建立专利信息相关运用机制，熟练运用专利信息解决企业知识产权相关问题。

专利信息资源组织和管理方向领军人才，应精通专利信息资源的收集、加工、管理的相关知识，掌握数字化建设相关技术，具有专利信息资源收集、加工和管理项目的经验，在专利信息资源组织和管理方面有所创新。

（二）专利信息师资人才选拔条件

1.具有较高的政治素养、良好的思想品德和职业道德。

2.具有授课经验，近两年承担培训授课任务3次以上。

3.近3年在公开刊物发表过专利信息相关论文，或参与过专利信息相关课题研究和报告撰写工作，或参与撰写过专利信息相关论著。

4.专利信息检索方向师资人才，应具有专利信息检索经验，善于讲授专利信息检索方法，如基于各信息资源的专利技术信息检索、专利新颖性及创造性检索、同族专利检索、法律状态检索的策略、方法和技能。

专利信息分析方向师资人才，应具有专利信息分析经验，善于讲授专利信息分析方法，如专利技术发展趋势分析、专利信息定性分析、专利性分析、专利侵权分析、专利价值分析、竞争对手分析等方法。

专利信息利用方向师资人才，应具有专利信息利用工作经验，善于结合工作实践和案例讲授专利信息综合运用的方法与技巧，如创新主体在战略制定、技术创新、科研立项、专利申请、技术引进、产品出口、专利预警、侵权诉讼等方面的综合运用，或政府及行政机构在制定政策、趋势预测、项目审批、成果鉴定和市场监管等方面专利信息的综合运用。

**四、**推荐方式和名额分配

参选人员可通过组织推荐与专家推荐两种方法产生。

（一）组织推荐

各省（区、市）、新疆生产建设兵团、计划单列市、副省级城市知识产权局，国家知识产权局局机关各部门、专利局各部门及局直属各单位、各社会团体根据推荐名额开展推荐工作，并负责对本地区/部门申报材料进行核实、初评，按时上报。

1.专利信息领军人才的推荐名额

各省（区、市）、新疆生产建设兵团、计划单列市、副省级城市知识产权局，国家知识产权局局机关各部门、专利局各部门及局直属各单位、各社会团体分别可推荐1名参评人员。

2.专利信息师资人才的推荐名额

（1）各省（区、市）、新疆生产建设兵团分别可推荐不超过3名参评人员。

（2）计划单列市、副省级城市知识产权局分别可推荐不超过2名参评人员。

（3）国家知识产权局局机关各部门、专利局各部门及局直属各单位、各社会团体分别可推荐不超过2名参评人员。

各有关单位和部门应对符合专利信息师资人才评选条件的人员进行排序。

（二）专家推荐

国家知识产权专家库入选专家可根据评选条件推荐参评人员，参加专利信息领军人才选拔的参评人员需有3名专家推荐，参加专利信息师资人才选拔的参评人员需有2名专家推荐。专家推荐产生的参评人员数量不限且不占参评人员所在单位推荐名额。

请各单位各部门以及推荐专家于2012年5月30日前报送有关材料。国家知识产权局将组织专家进行评审，确定2012年度专利信息领军人才和专利信息师资人才。
