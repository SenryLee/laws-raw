# 财政部办公厅关于切实做好中央补助地方财政经建系统专项转移支付预算执行管理工作的通知

## 财政部办公厅关于切实做好中央补助地方财政经建系统专项转移支付预算执行管理工作的通知（财办建[2012]37号）

各省、自治区、直辖市、计划单列市财政厅（局）：

近年来，地方财政经建系统按照财政科学化精细化管理要求，不断加强预算管理，加快预算执行进度，取得了较为明显的成效，但有部分省（区、市）还存在预算执行进度偏慢等问题，影响了全国整体预算执行进度，也不利于更好地发挥资金使用效益和政策效能。为切实增强中央补助地方财政经建系统专项转移支付（以下简称“经建专项资金”）预算执行的时效性和均衡性，促进财政经建政策的有效落实，现就加快预算执行进度有关问题通知如下：

**一、**高度重视，充分认识加快经建专项资金预算执行的重要性和紧迫性。经建专项资金规模大，政策涉及面广，惠及千家万户城乡居民，预算执行的水平和效率直接关系到他们的切身利益，关系到民生大局。要充分认识加快预算执行的重要性和紧迫性，切实增强抓好预算执行的责任感和使命感，进一步提高认识，统一思想，完善措施，真抓实干，确保经建专项资金预算执行再上一个新台阶。

**二、**吃透政策，准确把握政策内涵和程序要求，提高政策执行效率和预算执行进度。要认真学习经建专项资金政策文件，对政策内涵、管理规定、申报程序、时限要求等，要认真领会，吃透吃准，准确把握，减少偏差，切实提高政策执行力，进而推动加快经建专项资金预算执行。

**三、**及早着手，扎实做好经建转移支付前期准备工作。前期准备是项目实施的基础，是预算执行的关键，要下大力气做好项目管理和资金拨付的前期准备工作。要更加注重做好项目规划、评估评审、可行性论证等基础性工作，关键是提早入手、精心准备、科学论证，建立项目库并实行滚动管理，为提高经建专项资金预算执行进度，做好项目储备和程序准备。

**四、**分类推进，切实加快经建专项资金预算执行。经建专项资金种类繁多、管理各异，要区别不同情况，采取相应措施，个性化地推进预算执行。对补助个人的资金，要在收到款项后规定的工作日内将资金足额兑付到补助对象。对救灾类资金，要在收到款项后的24小时内拨付，确保资金的时效性和应急性。对按因素法切块下达的资金，要严格按照管理要求及时拨付，不得在省、市级财政长时间滞留。对以收定支、据实结算等特殊管理要求资金，要提前做好数据的分析测算，必要时先预拨、后清算。对其他按项目管理的资金，应提前核实项目信息、制定工作方案、简化拨款流程，及时将资金拨付项目承担单位。

**五、**奖优罚劣，建立严格的激励约束机制。对经建专项资金预算执行，要实行主管厅（局）长负责制，并层层分解落实，将责任落实到岗，将任务分解到人，将进度明确到具体时点。要实行严格的奖罚办法：对预算执行综合排名靠前的省（区、市），公开表扬并抄送省（区、市）政府办公厅，在安排下年相关经建专项资金时予以适当倾斜。对预算执行综合排名靠后的省（区、市），除通报批评并抄送省（区、市）政府办公厅以外，在安排下年相关经建专项资金时予以扣减。

**六、**及时报送，建立完善信息报送制度。为实现信息的上通下达和经验共享，建立完善经建专项资金预算执行信息报送制度。各省（区、市）财政厅（局）应当按要求向财政部经建司报送相关信息：一是要按季度报送本省（区、市）经建专项资金预算执行进度情况，二是要及时总结本省（区、市）经建专项资金预算执行好的做法和典型经验并随时上报。
