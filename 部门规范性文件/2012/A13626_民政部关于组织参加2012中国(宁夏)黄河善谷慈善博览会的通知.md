# 民政部关于组织参加2012中国(宁夏)黄河善谷慈善博览会的通知

## 民政部关于组织参加2012中国（宁夏）黄河善谷慈善博览会的通知

各省、自治区、直辖市民政厅（局），各计划单列市民政局，新疆生产建设兵团民政局：

为展示城市慈善发展成就和宁夏黄河善谷成果，民政部决定和宁夏回族自治区人民政府共同主办2012中国（宁夏）黄河善谷慈善博览会（以下简称“善博会”）。这是继在深圳举办首届中国公益慈善项目交流展示会后，民政部联合地方推进慈善事业发展的又一重要举措。为办好善博会，组织协调好参会事宜，现就有关事项通知如下：

**一、**善博会概况

（一）善博会简介。善博会是立足西部、辐射全国的国家级、国际化慈善交流合作平台。通过展示我国城市、区域慈善事业发展成就，展示、推介宁夏黄河善谷战略和成效，促进西部慈善需求与全国慈善资源的有效对接，研讨慈善事业创新发展的走向和路径，推动慈善事业科学发展。

（二）善博会主题。黄河善谷 大爱华夏

（三）时间和地点。定于2012年8月26日至28日在宁夏银川市和吴忠市举行。

（四）活动内容。主要包括慈善成就展（包括城市慈善成就展、公益慈善组织展、乐善企业展等）、“宁夏黄河善谷行”、“黄河善谷”高峰论坛、慈善项目推介、宁夏“黄河善谷奖”颁奖文艺晚会以及第二届“中国城市公益慈善指数”发布活动六项内容。

（五）招展范围。招展对象包括城市、国内外公益慈善组织、乐善企业、国际交流代表团等。

**二、**相关情况说明

（一）本次展览主要分为中国慈善成就展区、城市公益慈善成就展区、公益慈善组织展区、黄河善谷展区、乐善企业展区、国际交流展区等。

（二）城市展区以城市为单位设置展位。今年2月，民政部下发了《关于开展2010年和2011年全国城市公益慈善事业发展情况调查的通知》（民函〔2012〕44号），各省（自治区、新疆生产建设兵团）可从参与申报公益慈善事业发展情况的城市中选择参展，名额不限。直辖市和计划单列市单独参展。

（三）组委会为参展单位免费提供展位。善博会期间为各省（自治区、直辖市）、计划单列市、新疆生产建设兵团代表团观摩人员免费提供5人以内的食宿。参展单位人员费用自理。

**三、**会议主要日程

1. 8月26日17：30 招待会；

2. 8月26日19： 30中国（宁夏）黄河善谷慈善博览会开幕式；

3. 8月26日20：00“黄河善谷奖”颁奖文艺晚会；

4. 8月27日8：30善博会开展，9：30“黄河善谷”高峰论坛

5. 8月27日14：30第二届“中国城市公益慈善指数”发布活动；

6. 8月27日至28日“黄河善谷行”活动；

7. 8月28日16：00慈善项目签约仪式及善博会成果发布会。

**四、**工作要求

（一）高度重视，积极参与。善博会是慈善事业全面交流展示的综合性平台，请各地高度重视，精心组织，下发通知组织本地区城市做好参展准备工作，积极与善博会组委会办公室联系，了解参展的具体要求以及合作事宜，认真组织，踊跃参会参展。

（二）突出重点，保证质量。本次善博会是继在深圳举办的首届慈展会重点展示公益慈善项目成就后，以展示各地城市总体慈善发展成就为主题的国家级博览会，各地在参展组织工作中要突出这一主题和重点，择优选择慈善事业发展突出的城市报名参展，并要指导各参展城市精心组织，周密策划展出内容，力争使布展内容全面、真实、生动。

（三）加强联系，落实责任。请各省（自治区、直辖市）民政厅（局）、各计划单列市民政局、新疆生产建设兵团民政局指定专人负责，于7月20日前将本地参展城市目录、通信联络方式等相关情况，以传真和电子邮件方式报善博会城市招展办公室。
