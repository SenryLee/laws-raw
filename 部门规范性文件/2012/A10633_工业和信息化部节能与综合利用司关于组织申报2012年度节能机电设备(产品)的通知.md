# 工业和信息化部节能与综合利用司关于组织申报2012年度节能机电设备(产品)的通知

## 工业和信息化部节能与综合利用司关于组织申报2012年度节能机电设备（产品）的通知

各省、自治区、直辖市及计划单列市、新疆生产建设兵团工业和信息化主管部门，有关行业协会：

为满足我国工业节能工作对节能机电设备的需求，进一步推广与应用节能机电设备（产品），加快淘汰高耗能落后机电设备（产品），促进工业转型升级，实现工业可持续发展，我部拟结合《“十二五”节能环保产业发展规划》（国发[2012]19号）和《工业节能“十二五”规划》（工信部规[2012]3号），提出一批国家鼓励发展的节能机电设备（产品），请你们组织本区域内节能机电设备研发和制造单位进行申报。现就有关事项通知如下：

**一、**申报范围

本次申报的节能机电设备（产品），是指满足当前和今后一个时期我国节能减排市场重点需求，能效水平领先、技术先进、节能经济性良好、社会认可度高的设备（产品）。本次申报范围为内燃机、工业锅炉、中小型电机、变压器、电焊机、冲天炉、热处理设备、泵、风机、空气压缩机、制冷设备、注塑机、工业电炉等在国民经济建设中广泛使用的机电设备（产品）。

**二、**申报要求

（一）申报企业应填写《节能机电设备（产品）申报表》（见附件2）；

（二）申报企业根据设备（产品）所属行业提供相应的材料，具体要求见附件3。申报产品为系列产品时，应按照产品规格提供相应的材料（单独装订成册）；

（三）申报单位应保证所报材料内容真实、可靠。对于提供虚假申报材料的，三年内不得重新申报。

（四）各省级工业和信息化主管部门以及相关行业协会根据申报材料要求组织有关节能机电设备（产品）研发和设计单位（包括当地的中央企业集团企业）进行申报，并按本通知要求对申报材料进行审核汇总，填报申报汇总表（附件1），连同研发、制造单位填报的节能机电设备（产品）申报表以及相应材料等纸质文件（一式二份）于2012年11月16日前报送我部（节能司），电子版发送至jienengchu@miit.gov.cn（抄送mlbz@cmtf.net.cn）。申报表格及相关要求电子版请登录我部网站（http：//www.miit.gov.cn）节能司子网站下载。

我司委托机械工业节能与资源利用中心组织有关专家对推荐的机电设备产品进行论证和审议，最终形成《节能机电设备（产品）推荐目录（2012年）》。

填表说明

1、申报项目按每种规格产品“填一张表”的原则填写。

2、产品的设计、制造与命名符合国家现行法规、标准要求。系列产品要将产品型号逐一填写清楚，注明产品型号编制依据的标准。

3、申报的节能机电设备（产品）必须经过省级以上资质的专业节能检测机构的检测，并提供有效的节能检测报告。

4、“单位名称”应填写具有独立法人资格的单位全称；若是两个单位联合推荐，应将主要单位填写在前。

6、“负责人”应为企业法人，“联系人”为负责设备申报工作的人员，并填写联系方式。

7、“单位性质”应与工商登记相符。

8、“产品名称及型号” 要按国家或行业标准的规定填写产品名称及型号。没有标准的产品填写应规范、准确，并说明原因。不要使用 “高效” 、“新型”等修饰词。

10、“主要技术参数”应详细填写反映设备技术水平的技术参数。技术参数名称按国家标准或行业标准填写，包括性能指标、效率指标、可靠性指标等。

11、“实际能效指标”为推荐设备（产品）的实际耗能情况，并注明执行的国家能效标准或行业能效标准的名称及能效等级。

12、“产品适用领域”应填写详细的应用领域，如单元式空调的应用领域应填写为“宾馆、体育场馆、影剧院、厂房”等。

13、“证明资料”应是省级以上资质的专业检测机构的检测报告、鉴定证书、认证证书及其他相关证明。

14、“推荐理由”应将新老设备的能耗情况进行对比，尽可能给出具体数据。包括技术水平、节能效果、市场占有率等内容。

15、“企业简单情况说明” 应主要叙述生产规模、业务领域、研发能力、产品获奖情况以及未来规划等内容。

17、“节能机电设备推荐表”的申请单位须加盖公章。

附件3

产品分类申报要求

**一、**内燃机申报要求

（一）申报产品条件

1.申报产品拥有自主知识产权，产权所属清晰、无争议；

2.系列产品应符合以下条件：

（1）关键结构必须相同；（2）主要技术措施相同。

（二） 申报材料

1.企业营业执照、制造许可证、产品商标等资质材料的复印件；

2.质量保证体系建立与运行情况的证明材料复印件，包括质量管理获奖情况、质量体系认证情况及认证证书等资料；

3.产品性能检测报告，包括排放检测报告；

4.获得专利或奖励的证明材料的复印件；

5.产品的用户使用报告（3份以上）；

6.科技成果鉴定报告；

7.产品试制总结（对申报产品进行总体介绍，对节能措施和创新点进行详细介绍，并附产品外形照片）；

8.产品设计、制造执行的质量、安全及节能环保标准或技术条件汇总表，包括国家标准、行业标准、企业标准等；

9.与同类产品节能效果的对照汇总表，包括国内和国外同类产品；

10.申报产品近二年的销售记录汇总表。

**二、**工业锅炉申报要求

（一）申报产品条件

1.申报产品为自主开发或引进技术，技术产权所属清晰、无争议，且销售量达到表1 要求。

表1

|  |  |
| --- | --- |
| 锅炉容量（D，t/h或Q，MW） | 二年内销售量（台） |
| D≤6或Q≤4.2 | ≥10 |
| 6 | ≥6 |
| D＞20或Q＞14 | ≥4 |

2.系列产品应符合下列条件：

（1） 炉型、结构必须相同；

（2） 主要技术措施相同；

（3） 产品容量划分区间为：D≤6 t/h（或Q≤4.2MW）、6 t/h20 t/h（或Q＞14 MW）三个系列；

（4） 系列产品中至少有一个产品的销售量符合表1 的要求，其他产品至少各有一台已投入使用。

（二） 申报材料

1.企业营业执照、制造许可证、产品商标等资质材料的复印件；

2.质量保证体系建立与运行情况的证明材料复印件，包括质量管理获奖情况、质量体系认证情况及认证证书等资料；

3.产品热工性能试验报告和环保性能试验报告（锅炉产品环保性能试验必须与锅炉热工性能测试同时进行，测试时间为近二年内）；

4.获得专利或奖励的证明材料的复印件；

5.产品的用户使用报告（3份以上）；

6.科技成果鉴定报告；

7.产品试制总结（对申报产品进行总体介绍，对节能措施和创新点进行详细介绍，并附产品外形照片）；

8.产品设计制造执行的质量、安全及节能环保标准或技术条件汇总表，包括国家标准、行业标准、企业标准等；

9.其他证明材料：

（1）设计原理图；

（2）配套辅机节能标识及主要辅机（风机、水泵、电机）电耗、锅炉本体钢耗数值；

（3）机械层燃锅炉配用的炉排总图或安装使用说明书；

（4）申报产品近二年的销售记录汇总表。

表3
