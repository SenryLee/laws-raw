# 国家文物局关于金沙遗址保护规划修编立项的意见

## 国家文物局关于金沙遗址保护规划修编立项的意见（办保函〔2012〕204号）

四川省文物管理局：

你局《关于金沙遗址保护规划编制立项的请示》（川文物保〔2011〕98号）收悉。经研究，我局意见如下：

**一、**所报材料缺少现有金沙遗址保护规划执行情况和存在问题以及修编必要性、修编原则和思路等方面的具体说明，前期准备和研究不够，我局暂不同意金沙遗址保护规划修编立项。

**二、**请你局指导地方人民政府结合遗址保护和申报世界文化遗产需要，重点做好遗址本体和出土文物保护、现有展陈水平提升、考古遗址公园建设、学术研究等方面工作，并根据实际情况适时考虑金沙遗址保护规划修编问题，妥善处理遗址保护和城市经济发展之间的关系。

国家文物局　　

二〇一二年三月十二日
