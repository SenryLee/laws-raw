# 国家体育总局关于印发2012年“愽达电机杯”全国健美锦标赛暨2012年亚洲健美锦标赛选拔赛竞赛规程的通知

参赛保证书

1、本队（人）自愿报名参加本次比赛及一切相关活动（以下统称“比赛”）；

2、本队（人）遵守本次比赛竞赛规程、规则及组委会所制订的各项规定、要求；

3、本队（人）身体健康，已做好参赛准备并办理保险；

4、本队（人）对参赛可能出现的风险，已准备必要的防范措施；本队（人）愿意承担比赛期间发生的自身意外风险责任，且同意组委会不承担任何形式的赔偿；

5、本队（人）同意接受组委会在比赛期间提供的现场急救性质的医务治疗，但在医院救治等发生的相关费用由本队（人）自理；

6、本队（人）授权组委会及指定媒体无偿使用本人的肖像、姓名、声音和其它个人资料用于比赛的组织和推广；

7、为维护健美运动的纯洁性、公正性，保护健美运动员的身心健康，本队（人）保证在本次比赛中，坚决反对和绝不使用有害健美运动发展及运动员身心健康的任何违禁物品。若有违反，我们愿意接受大会组委会依据国家有关规定所给予的相应处罚。

8、本队已认真阅读并全面理解以上内容，且对上述内容予以确认并承担相应的法律责任。
