# 国家核安全局关于颁发和换发2012年第一批核动力厂操纵人员执照的通知

## 国家核安全局关于颁发和换发2012年第一批核动力厂操纵人员执照的通知（国核安发[2012]46号）

国家能源局，中核核电运行管理有限公司，核电秦山联营有限公司，秦山第三核电有限公司，大亚湾核电运营管理有限责任公司，江苏核电有限公司，福建宁德核电有限公司，辽宁红沿河核电有限公司：

国家能源局《国家能源局关于华雪等338人申请核电厂反应堆操纵人员执照的函》（国能电力〔2012〕27号）、《国家能源局关于侯英东等187名核电厂反应堆操纵人员换发执照的函》（国能电力〔2012〕70号），中核核电运行管理有限公司《关于申请对秦山第二核电厂3、4号机组操纵人员进行资格审查的请示》（核秦培发〔2011〕425号）、《关于申请对秦山第二核电厂1、2号机组操纵人员进行资格审查的请示》（核秦培发〔2011〕432号）、《关于秦山核电厂1、2号机组操纵人员申请换发新执照的请示》（中核运行安发〔2012〕12号）、《关于秦山第二核电厂3、4号机组操纵人员申请换发新执照的请示》（核秦核安发〔2012〕15号）、《关于秦山第三核电厂15名操纵人员换发执照的请示》（中核运行安发〔2011〕89号），大亚湾核电运营管理有限责任公司《广东大亚湾核电厂/岭澳核电厂操纵人员执照换发的请示》（广核运〔2012〕12号）、《岭澳核电厂3号和4号机组操纵人员执照换发的请示》（广核运〔2012〕13号）、《关于2011年广东大亚湾核电厂及岭澳核电厂操纵员（RO）/高级操纵员（SRO）资格审查的请示》（广核运〔2012〕14号）、《关于2011年岭澳核电厂3号和4号机组操纵员（RO）/高级操纵员（SRO）资格审查的请示》（广核运〔2012〕15号），江苏核电有限公司《关于田湾核电站第五批高级操纵员资格审查的请示》（苏核发〔2011〕322号）、《关于申请田湾核电站第八批操纵员换照资料审查的函》（苏核发〔2011〕495号），福建宁德核电有限公司《关于2011年宁德核电厂第一批操纵员资格核准的请示》（闽宁核〔2012〕19号），辽宁红沿河核电有限公司《关于辽宁红沿河核电厂操纵员资格审查的请示》（辽红核〔2011〕74号）收悉。经审核，现通知如下：

根据《中华人民共和国民用核设施安全监督管理条例》（HAF001）及其实施细则有关规定和国家能源局的审核意见，我局对中核核电运行管理有限公司等5家营运单位民用核设施操纵人员执照申请文件进行了审核，认为华雪等334人具备了民用核设施操纵人员资格，批准颁发执照；认为侯英东等181人具备了民用核设施操纵人员资格，批准换发执照（批准颁发换发执照的操纵人员名单、执照号码和有效期见附件）。

附件：1.批准颁发执照人员名单（略）

2.批准换发执照人员名单（略）

二○一二年三月三十日
