# 国家文物局关于复核长城认定材料的通知

## 国家文物局关于复核长城认定材料的通知（办保函〔2012〕54号）

各有关省、自治区、直辖市文物局（文化厅）：

根据《关于开展长城认定工作的通知》（文物保函〔2011〕1159号）要求，长城沿线各有关省（自治区、直辖市）向我局提交了长城认定申请文件和附件（包括长城资源认定申请表、已认定长城资源登记表、省级长城资源概述）等相关材料。受我局委托，长城资源调查工作项目组组织有关专家对上述材料进行了审核，并根据专家意见协助各地对有关材料进行了修改、完善。

为确保长城认定工作的科学性和准确性，现请你局（厅）对经专家审核修订的你省（自治区、直辖市）长城资源认定申请表、已认定长城资源登记表等长城认定材料（附后）进行复核。经你局（厅）复核同意的长城认定材料将作为我局正式发布长城认定结论的主要依据。复核工作有关要求如下：

**一、**复核工作内容

请你局（厅）高度重视复核工作，尽快组织相关人员对你省（自治区、直辖市）全部长城认定材料内容逐条、逐项进行复核，并参照长城认定材料表格体例，分别编制申请认定长城资源复核意见表和已认定长城资源复核意见表，详细列明需要修改或补充的长城资源条（项）及具体内容，并相应重新核定长城资源相关统计数据，修订省级长城资源概述。复核同意的长城资源条（项），不列入复核意见表。

**二、**复核文件报送

请你局（厅）根据复核工作情况，编制长城认定材料复核工作报告。涉及重大修改的，应在复核工作报告中详细说明理由；如有必要，可提前与我局或长城资源调查工作项目组进行沟通。申请认定长城资源复核意见表、已认定长城资源复核意见表和修订后的省级长城资源概述应作为复核工作报告附件。请你局（厅）在2012年3月10日之前，将长城认定材料复核工作报告及附件（含电子版）一式两份报送至我局。逾期未报送复核文件的，视为无异议。

专此。

附件：经专家审核修订的各有关省（区、市）长城资源认定申请表、已认定长城资源登记表（略）
