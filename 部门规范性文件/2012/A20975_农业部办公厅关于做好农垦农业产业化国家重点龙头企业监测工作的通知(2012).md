# 农业部办公厅关于做好农垦农业产业化国家重点龙头企业监测工作的通知(2012)

## 农业部办公厅关于做好农垦农业产业化国家重点龙头企业监测工作的通知（农办垦[2012]13号）

有关省、自治区、直辖市及计划单列市农垦主管部门，新疆生产建设兵团办公厅：

根据《农业产业化国家重点龙头企业认定和运行监测管理暂行办法》，我部决定对农垦系统69家农业产业化国家重点龙头企业（名单见附件1）2011年的经营情况进行监测，现将有关事宜通知如下：

**一、**农垦系统69家国家重点龙头企业要认真阅读填表说明（见附件3），如实填写《农垦农业产业化国家重点龙头企业情况监测表》（见附件2），并报垦区农业产业化主管部门审核。

**二、**垦区农业产业化主管部门要认真组织本垦区的产业化国家重点龙头企业填报《农垦农业产业化国家重点龙头企业情况监测表》，经审核无误后，于4月20日前以电子文本（电子邮件）形式报送我部农垦局科技经贸处。

**三、**中国农垦信息网（网址：www.chinafarm.com.cn/gov）同时刊发此通知和监测表，各垦区和龙头企业可在网上下载。

**四、**网上填报。在报送电子文本的同时，将国家重点龙头企业情况监测表通过中国农垦信息网（网址：www.chinafarm.com.cn/cyh）完成网上填报，网上填报说明见附件3。

**五、**因改制等特殊情况不能报送的企业，要提出详细的文字说明材料，经垦区农业产业化主管部门确认并盖章后，报我部农垦局科技经贸处。在填报过程中如有其它问题，请及时与我部农垦局科技经贸处联系。

附件3：

农垦农业产业化国家重点龙头企业情况监测表填表说明

**一、**指标说明

1.数据型指标。均以2011年的数据为准。

2.企业登记注册类型（代号2）。指企业在工商行政管理机

关登记注册的类型，如：国有企业、集体企业、股份合作企业、联营企业、有限责任公司、股份有限公司、私营企业、港澳台商投资公司、外商投资公司等。

3.企业类型（代号9）。按国家重点龙头企业认定标准分为加工型、市场型。加工型企业应填报所有指标；市场型企业在指标19、20、33、34项填写交易额情况，指标54、55、56可不填。

4.主要原料类别（代号30）。指企业主营产品的主要原料类别。一级类别只填写1类，二级类别可填写1-2个。

主要原料类别分为以下十三类：

（1）粮食类（小麦、稻米、玉米、其它）；

（2）油料类（油菜、花生、大豆、其它）；

（3）棉麻类（棉花、亚麻、其它）；

（4）糖类（甘蔗、甜菜）；

（5）水果类（苹果、柑橘、梨、葡萄、桃、菠萝、其它）；

（6）蔬菜类（番茄、胡萝卜、食用菌、其它）；

（7）林特产品类（花卉、茶叶、中草药、山野菜、其它）；

（8）肉类（猪肉、牛肉、羊肉、鸡肉、鸭肉、其它）；

（9）蛋类（鸡蛋、鸭蛋、其它）；

（10）乳类（牛乳、其它）；

（11）皮及皮毛制品类（皮革、羽绒、其它）；

（12）水产品类（鱼类、虾类、贝类、其它）；

（13）其它（种子、其它）。

括号内为二级分类名，填表时请将二级分类名填在括号内。填写方式为：面粉加工企业填为“粮食类（小麦）”、肉制品加工企业填为“肉类（猪肉、牛肉）”、果汁加工企业填为“水果类（苹果、桃）”等。

5.主营产品名称（代号31）。直接填写企业主营产品，最多不超过三个，每个名称之间以“，”（逗号）分隔。

6.主营产品产量（代号32）。按产品名称（代号31）排在第一位的产品产量填报。

7.主营产品销售收入（代号33）。按产品名称（代号31）排在第一位产品的销售收入填报。

8.主营产品销售收入的行业排名（代号34）。指由权威机构认定的行业排名，并出具证明材料。没有确切资料可不填写。

9.表4中代号35、36、37、38、39、40填报企业整体营销及进出口情况。

10.主要原料名称（代号44），填报三种主要的原料名称。

11.合同制（代号48）。指企业通过合同等契约方式向农户收购或销售农副产品，合同双方具有明确的权利、义务关系，合同具有法律效力。基地农户能按合同要求进行生产和出售产品，龙头企业能按合同提供服务、收购农产品并及时结算。

12.合作制（代号49）。指龙头企业与基地农户建立了较密切的长期合作关系，并按一定的方式（如按交易量）将一部分农副产品加工、运销等增值的利润返还给农户（包括实行二次分配）。

13.股份合作制（代号50）。指股份制或股份合作制产业化组织按照股金比例进行利润分红。

以上三种都不属于的填其它。

14.代号12、22、23、35、36、46指标，请填入乘以100％以后的数字。
