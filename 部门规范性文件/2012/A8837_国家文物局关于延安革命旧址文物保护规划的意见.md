# 国家文物局关于延安革命旧址文物保护规划的意见

## 国家文物局关于延安革命旧址文物保护规划的意见（办保函〔2012〕994号）

陕西省文物局：

你局《关于呈报延安革命纪念地旧址总体保护规划的请示》（陕文物字[2012]121号）收悉。经研究，我局原则同意所报规划内容，同时提出修改、完善意见如下：

**一、**进一步明确规划定位。建议将该规划定位于延安市革命旧址总体保护规划大纲，用于指导延安市革命旧址的整体保护与利用。

**二、**进一步收集、补充区域性的现状基础资料，如灾害分布、社会经济发展状况、城镇发展趋势等，总体评估旧址保护面临的困难和压力，提出区域性的文物保护与利用策略。

**三、**建议针对延安市革命旧址面临的管理问题，就完善保护管理体系、加大地方性法规的制订提出建议，为革命旧址的整体保护提供组织、法律保障。

**四、**应综合考虑文物保护、红色旅游、爱国主义教育等相关的管理渠道，利用各自的优势和资源综合设定保护管理的支撑和保障体系。

**五、**补充保护规划与城市总体规划等相关规划的衔接内容。

**六、**进一步规范相关图纸与文字表述。补充旧址分布图、必要的保护区划图等。

**七、**应在该规划大纲的基础上，按照《全国重点文物保护单位保护规划编制要求》及其它相关规定，根据需要分别编制各文物保护单位的保护规划，并依法履行相关的报批程序。

专此。

国家文物局　　　

二〇一二年十一月十二日
