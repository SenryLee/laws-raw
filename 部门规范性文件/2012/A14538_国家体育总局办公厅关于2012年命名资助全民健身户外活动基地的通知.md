# 国家体育总局办公厅关于2012年命名资助全民健身户外活动基地的通知

## 国家体育总局办公厅关于2012年命名资助全民健身户外活动基地的通知（体群字[2012]107号）

北京、山西、辽宁、吉林、黑龙江、江苏、安徽、福建、河南、广西、四川、贵州、云南、陕西、宁夏、新疆：

根据《全民健身户外活动基地命名资助办法（试行）》（体群字[2008]97号）（以下简称《办法》）的有关规定，经对各单位的申报材料进行评审，决定在2012年对22个“全民健身户外活动基地”（以下简称“基地”）给予命名和资助。现将有关事宜通知如下：

**一、**有关省（区、市）体育局要严格按照《办法》有关资金使用、评估复审等规定，加强对“基地”建设管理的指导和监督，确保资助资金专款专用和“基地”体育场地设施运营安全。

**二、**获得命名的“基地”要树立品牌意识，严格执行《体育场所开放条件与技术要求》（GB19079）等有关国家标准和技术规范，不断提高服务水平和质量，在“基地”建设管理方面树立示范。

**三、**对社会影响大、社会效益好、在全民健身场地设施建设管理方面真正具有示范意义的“基地”，国家体育总局将在综合评估后继续给予支持。

附件：2012年命名资助全民健身户外活动基地名单
