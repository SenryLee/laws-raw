# 中华全国供销合作总社关于召开全国供销合作职业技术教育学会五届二次会议暨2013年职教本科师资班招生工作会议的通知

各省、自治区、直辖市供销合作社教育主管部门；学会各会员单位、理事；各有关单位领导、专家：

根据全国供销合作职业技术教育学会（以下简称学会）《章程》及五届一次会议（厦门）决定，学会五届二次会议定于2012年12月11日在全国供销合作社职业院校校长培训班期间一并举行。现将有关事项通知如下：

**一、**会议主题

学习贯彻《国家中长期教育改革发展纲要（2010-2020年）》、《中华全国供销合作总社 教育部关于进一步推进供销合作社职业教育改革和发展的意见》（供销科联字[2011]7号）、《中华全国供销合作总社中华人民共和国教育部关于在全国供销合作社系统开展职业教育集团化办学试点工作的意见》（供销科联字[2012]9号）精神，推进职业教育改革创新和职业教育集团化办学，加快建设供销合作社现代职业教育体系，推动供销合作社职业教育科学发展。

**二、**会议内容

1.总结2012年全国供销合作职业技术教育学会工作，安排部署2013年工作；

地址：太原市太榆路武宿机场南（山西大学商务学院内）电话：0351-7942416　传真：0351-7942426　邮政编码：030031

2.召开全国供销合作职业教育教学指导委员会年度工作会议。

3.召开2013年全国供销合作社系统职教本科师资班招生工作布置会议。

4.举办全国供销合作社职业院校校长培训班。

**三、**参会对象

1.学会全体理事、常务理事、会长、副会长、秘书长、副秘书长；

2.全国供销合作职业教育教学指导委员会委员；

3.各省、自治区、直辖市供销社教育主管部门负责人；

4. 学会各专业委员会（科研工作、酒店管理、学生工作、教学工作）主任、副主任；

5.山西财经大学、安徽财经大学和山西大学商务学院招生办公室负责人；

6.特邀嘉宾：教育部高校学生司、教育部职业教育与成人教育司、中国职业技术教育学会、重庆市教育委员会、重庆市永川区人民政府等单位领导出席。

**四、**会议举办单位

主办单位：全国供销合作职业技术教育学会、中华全国供销合作总社科技教育部

承办单位：重庆市经贸中等专业学校

**五、**会议时间、地点

1.会议时间：2012年12月11日至14日共4天（12月10日报到）

2.会议地点：重庆市永川江鸿国际大酒店（五星级，地址：重庆市永川区人民西路589号，电话023-49666666）。

**六、**提交材料

学校办学成果展示资料（自带200份、报到时提交）

会务费由中华全国供销合作总社负担，住宿费自理（五星级酒店标准间398元/间/天）。
