# 国资委直属机关党委关于国资委直属机关深入学习宣传贯彻党的十八大精神的通知

各厅局、直属单位、直管协会、部分京外企业在京单位党委（总支、支部）：

党的十八大是在我国进入全面建成小康社会决定性阶段召开的一次十分重要的大会。大会批准了胡锦涛同志的报告，选举产生了新一届中央委员会和中央纪律检查委员会，是一次高举旗帜的大会、继往开来的大会、团结奋进的大会。直属机关各级党组织要按照中央的部署和中央国家机关工委、委党委的要求，把学习宣传贯彻党的十八大精神作为当前和今后一个时期的首要政治任务切实抓紧抓好。现就有关工作通知如下：

**一、**充分认识学习宣传贯彻党的十八大精神的重大意义

胡锦涛同志的报告，高举中国特色社会主义伟大旗帜，科学分析了国际国内形势发展变化，回顾总结了过去五年的工作和党的十六大以来的奋斗历程及取得的历史性成就，确立了科学发展观的历史地位，提出了夺取中国特色社会主义建设新胜利的基本要求，确定了全面建成小康社会和全面深化改革开放的目标，对新的时代条件下推进中国特色社会主义事业作出了全面部署，对全面提高党的建设科学化水平提出了明确要求。报告描绘了全面建成小康社会的宏伟蓝图，为党和国家事业进一步发展指明了方向，是党团结带领全国各族人民夺取中国特色社会主义新胜利的政治宣言和行动指南，是马克思主义的纲领性文献。

国资委承担着搞好国有企业，发展壮大国有经济，巩固党的执政基础的重要责任，在推动党和国家事业发展，实现全面建成小康社会宏伟目标中发挥着举足轻重的重要作用。直属机关各级领导班子和党组织是落实党的路线方针政策和各项工作任务的战斗堡垒，在学习宣传贯彻十八大精神中肩负着重要责任，学习宣传贯彻的成效如何，直接关系到能否将广大党员干部思想认识统一到十八大精神上来，直接关系到能否将十八大精神转化为加强国资监管推动央企改革发展的具体政策措施和制度机制，直接关系到能否坚定推动解决央企改革发展中的突出问题，直接关系到能否建设一支素质过硬、作风优良的党员干部队伍，直接关系到能否进一步提高直属机关党建工作科学化水平，为完成十八大确定的各项重大决策部署提供坚强保证。直属机关各级党组织和广大党员干部必须认清肩负的责任和使命，以更高标准、更严要求和更加奋发有为的精神状态，把学习宣传贯彻好十八大精神作为当前和今后一个时期的首要任务，把思想行动统一到十八大精神上来，把智慧力量凝聚到实现十八大确定的宏伟目标和各项任务上来，努力为实现十八大提出的目标任务作出新贡献。

**二、**全面准确地领会把握党的十八大基本精神

直属机关各级党组织要组织广大党员干部紧紧围绕党的十八大主题，原原本本学习党的十八大报告和新修改的党章，全面领会、准确把握党的十八大精神实质。

一是全面准确地领会把握中国特色社会主义的丰富内涵和基本要求。充分认识中国特色社会主义是当代中国发展进步的根本方向，只有中国特色社会主义才能发展中国。充分认识建设中国特色社会主义，总依据是社会主义初级阶段，总布局是五位一体，总任务是实现社会主义现代化和中华民族伟大复兴，基本要求是必须坚持人民主体地位，必须坚持解放和发展社会生产力，必须坚持推进改革开放，必须坚持维护社会公平正义，必须坚持走共同富裕道路，必须坚持促进社会和谐，必须坚持和平发展，必须坚持党的领导。

二是全面准确地领会把握科学发展观的历史地位和精神实质。深刻领会科学发展观是中国特色社会主义理论体系最新成果，开辟了当代马克思主义发展新境界，是中国共产党集体智慧的结晶，是指导党和国家全部工作的强大思想武器，同马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想一道，是党必须长期坚持的指导思想，更加自觉地把推动经济社会发展作为贯彻落实科学发展观的第一要义，把加强国资监管推动央企改革发展作为我们贯彻落实科学发展观的具体行动，在不断推进国资监管央企改革发展的过程中贯彻好、落实好科学发展观。

三是全面准确地领会把握过去五年的工作和党的十六大以来的奋斗历程及辉煌成就。全面把握党的十七大以来的五年是我们在中国特色社会主义道路上奋勇前进的五年，是我们经受住各种困难和风险考验、夺取全面建设小康社会新胜利的五年，各方面工作都取得新的重大成就。全面把握党的十六大以来我们党带领人民紧紧抓住和用好我国发展的重要战略机遇期，战胜一系列重大挑战，奋力把中国特色社会主义推进到新的发展阶段，巩固和发展了改革开放和社会主义现代化建设大局，提高了我国国际地位，彰显了中国特色社会主义的巨大优越性和强大生命力，增强了中国人民和中华民族的自豪感和凝聚力。

四是全面准确地领会把握全面建成小康社会和全面深化改革开放的目标任务和总体布局。深刻领会全面建设小康社会目标的基础上努力实现新的要求，全面把握我国社会主义经济建设、政治建设、文化建设、社会建设、生态文明建设的总体部署，加快完善社会主义市场经济体制和加快转变经济发展方式，坚持走中国特色社会主义政治发展道路和推进政治体制改革，扎实推进社会主义文化强国建设，在改善民生和创新管理中加强社会建设，大力推进生态文明建设。

五是全面准确地领会把握全面提高党的建设科学化水平的总体要求和根本任务。牢牢把握加强党的执政能力建设、先进性和纯洁性建设这条主线，坚持以人为本、执政为民，坚持解放思想、改革创新，坚持党要管党、从严治党，全面加强党的思想建设、组织建设、作风建设、反腐倡廉建设、制度建设，增强自我净化、自我完善、自我革新、自我提高能力，建设学习型、服务型、创新型的马克思主义执政党，确保党始终成为中国特色社会主义事业的坚强领导核心。务必增强忧患意识，始终保持清醒头脑；务必增强创新意识，始终保持奋发有为的精神状态；务必增强宗旨意识，始终把人民放在心中最高位置；务必增强使命意识，始终保持共产党人的政治本色。

**三、**联系实际切实抓好党的十八大精神贯彻落实

直属机关各级党组织要以高度政治责任感，把用党的十八大精神武装头脑、指导实践、推动工作作为学习宣传贯彻的出发点和落脚点，作为衡量学习贯彻成效的重要标准，不断把学习宣传贯彻十八大精神的各项工作推向深入。

一是把思想认识切实统一到党的十八大精神上来。引导广大党员干部毫不动摇以邓小平理论、“三个代表”重要思想、科学发展观为指导，坚定不移沿着中国特色社会主义道路前进，解放思想，改革开放，凝聚力量，攻坚克难，为如期实现全面建成小康社会目标贡献智慧和力量；坚决维护中央权威，在思想上政治上行动上始终与党中央保持高度一致，坚决贯彻党的理论和路线方针政策，坚决贯彻中央决策部署，切实做到讲政治、顾大局、守纪律。

二是把党的十八大精神真正转化为具体的措施。根据十八大提出的新思想新观点新要求新思路，总结国资委成立以来推进国资监管央企改革发展的经验，深入研究加快转变经济发展方式，坚持“两个毫不动摇”，深化企业改革，完善国资监管体制，推动央企改革发展稳定等一系列重大课题，进一步理清工作思路，研究制定今后一个时期的工作规划，明确近期的目标任务；按照十八大提出的总体布局和战略部署，提出本单位改革与发展的具体措施，把十八大精神落到实处。

三是以改革创新精神推动解决工作中的突出问题。对照十八大报告，认真开展自查，重点查找、梳理思想认识上存在的差距，特别是认真查找本单位不适应不符合科学发展观要求的突出问题、业务工作中存在的突出问题和薄弱环节，明确改进方向；把改革创新精神贯彻到工作各个环节，改变束缚科学发展的做法和规定、革除制约科学发展的体制机制障碍，努力破解发展难题，不断把国资监管央企改革发展事业推向前进。

四是建设素质过硬、作风优良的党员干部队伍。教育引导党员干部顾全大局，正确对待和运用手中权力，把监管和服务有机结合起来；围绕保持党的先进性和纯洁性，坚持倡导求真务实、亲民为民、负责敬业、艰苦奋斗之风，建设为民、务实、清廉机关，努力做到为党和国家大局服务，为完成单位中心任务服务，为基层和群众服务；深入开展管理提升活动，不断提高机关建设水平。

五是全面提高党的建设科学化水平。紧紧围绕“服务中心、建设队伍”这一机关党建工作的核心任务，找准党建工作和业务工作结合的切入点；坚持党要管党、从严治党，以坚定理想信念为重点加强思想建设，以夯实党执政的组织基础为目标加强组织建设，以保持党同人民群众的血肉联系为核心加强作风建设，以坚定不移反对腐败为导向加强反腐倡廉建设，以完善党建工作体制机制为保证加强制度建设，为国资监管央企改革发展各项任务的完成提供坚强的思想、政治和组织保证。

**四、**加强对学习宣传贯彻党的十八大精神工作的领导

直属机关各级党组织要增强政治意识、大局意识、责任意识，按照中央部署和委党委的要求，切实加强组织领导，认真学习，深刻领会，联系实际，讲求实效。

一是坚持领导带头。领导干部要以身作则、率先垂范，带头学习宣传贯彻十八大精神。各级中心组要迅速传达党的十八大精神，及时组织学习，深刻领会精神实质，研究贯彻落实的具体措施。各级领导干部要带头精心研读十八大文件，讲党课、作辅导报告。领导干部还要带头深入基层开展调查研究，了解实际情况，帮助解决实际问题，把学习贯彻十八大精神的工作落到实处。

二是加强组织领导。直属机关各级党组织要对学习宣传贯彻作出具体部署，制定具体实施方案。委党委将举办学习宣传贯彻十八大精神培训班，具备条件的单位也要举办培训班，集中时间对党员干部进行轮训；要组织党员干部在集中学习和自学的基础上，结合思想实际和工作实际，交流学习体会；要通过组织宣讲、辅导讲座、专题研讨、组织座谈等多种形式，推动学习宣传贯彻活动不断深入。各级工青妇等群众组织要结合自身实际，广泛开展各具特色的学习教育活动。各单位要充分利用新闻宣传、简报、专栏、网站等多种形式，营造学习宣传贯彻的浓厚氛围。

三是不断把学习宣传贯彻工作推向深入。各部门要把学习宣传贯彻党的十八大精神纳入重要议事日程，推动形成领导带头，一级带一级、层层抓落实的工作格局。制定系统的学习宣传贯彻计划，督促各项任务落到实处。把学习宣传贯彻党的十八大精神融入到业务工作中。深入挖掘总结本单位学习宣传贯彻党的十八大精神中的情况、做法、问题，把那些实践证明有效管用的经验做法提炼升华固定下来，推动学习宣传贯彻党的十八大精神向广度和深度拓展。

请各单位及时将学习宣传贯彻情况报直属机关党委。
