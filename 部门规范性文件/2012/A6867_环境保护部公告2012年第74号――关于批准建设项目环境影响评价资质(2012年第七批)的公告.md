# 环境保护部公告2012年第74号――关于批准建设项目环境影响评价资质(2012年第七批)的公告

## 环境保护部公告（2012年第74号）

关于批准建设项目环境影响评价资质（2012年第七批）的公告

根据《建设项目环境影响评价资质管理办法》（原国家环境保护总局令第26号）的有关规定，我部对申请建设项目环境影响评价资质（以下简称“资质”）的机构进行了审查。现将资质批准有关事项（2012年第七批）公告如下：

**一、**批准北京中咨华宇环保技术有限公司等24家机构资质中的评价范围调整（调整的评价范围详见附件1）。

**二、**批准中国京冶工程技术有限公司等12家机构资质中的机构名称变更（变更后的机构名称详见附件2）。

**三、**批准阜宁叶萌环境技术服务有限公司等11家机构资质延续（机构名单及评价范围详见附件3）。

**四、**批准中国科学院生态环境研究中心等29家机构资质证书法定代表人或住所予以变更（机构名单及变更情况详见附件4）。

请上述机构于60日内，携带原资质证书正、副本原件到指定领证地点领取资质证书，其中第二项中的机构应在领取资质证书前，办理环境影响评价专职技术人员岗位证书和环境影响评价工程师登记证变更手续。自本公告发布之日起，上述机构原资质证书正、副本原件及其缩印件同时作废，不得继续使用。

领证地点：环境保护部环境工程评估中心资质管理与培训部（北京安外北苑路28号迪蒙综合楼5层506室）

联系电话：（010）52931001， 52931012
