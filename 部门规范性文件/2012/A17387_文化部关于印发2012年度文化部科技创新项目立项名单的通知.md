# 文化部关于印发2012年度文化部科技创新项目立项名单的通知

## 文化部关于印发2012年度文化部科技创新项目立项名单的通知（文科技函〔2012〕522号）

北京、天津、河北、吉林、上海、安徽、山东、湖北、广东、广西、云南省（区、市）文化厅（局），本部外联局，中国艺术研究院、国家图书馆、国家博物馆、国家京剧院、中国数字文化集团有限公司、文化部艺术服务中心：

2012年度“文化部科技创新项目”评审工作已于近日完成，现将立项名单印发给你们，并就有关工作通知如下：

**一、**“文化部科技创新项目”的评审、立项和实施是我部文化科技司的重要工作之一，立项项目代表着文化科技创新研究工作的方向和水平，对促进科学技术在文化领域的广泛应用具有十分重要的作用，各有关单位应当予以高度重视。凡立项项目，都必须切实纳入工作计划，在经费、人员等方面予以支持，提供必要的条件，确保这一工作的顺利进行。

**二、**请各有关省、自治区、直辖市文化厅（局），各有关直属单位，原文化部直属高等艺术院校按照《文化部科技创新项目管理办法（暂行）》的规定和要求，组织立项项目承担单位认真填写《文化部科技创新项目合同》，于2012年4月20日前将合同文本寄回文化部文化科技司，合同文本下载地址http：//www.mcprc.gov.cn/sjzz/whkjs/ztlm/kjcxxm/201105/t20110526_125601.html。各项目承担单位应按照实际经费补助情况对立项项目研究目标、研究思路和技术路线进行适当调整，确保项目研究顺利开展。

特此通知。

二○一二年四月十七日
