# 国家测绘地理信息局创先争优活动领导小组关于印发《国家测绘地理信息局创先争优活动2012年工作要点》的通知

## 国家测绘地理信息局创先争优活动领导小组关于印发《国家测绘地理信息局创先争优活动2012年工作要点》的通知（国测党发〔2012〕12号）

各直属党委、总支、支部：

根据中央创先争优活动领导小组《关于印发〈深入开展创先争优活动2012年工作要点〉的通知》（创先发〔2012〕1号）和《关于印发〈中央国家机关创先争优活动2012年工作要点〉的通知》（国机创发〔2012〕1号）的要求，现将《国家测绘地理信息局创先争优活动2012年工作要点》印发给你们，请结合实际，认真抓好贯彻落实。

国家测绘地理信息局创先争优活动领导小组

二〇一二年三月七日

国家测绘地理信息局创先争优活动2012年工作要点

2012年，国家测绘地理信息局深入开展创先争优活动的总体要求是：坚持以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，以迎接党的十八大为主线，以推动科学发展、促进社会和谐、服务人民群众为主题，以立足本职岗位、破解发展难题、深入基层联系和服务群众为重点，坚持围绕中心、服务大局，认真落实“基层组织建设年”和测绘地理信息工作执行年、落实年、实干年的各项部署，组织引导各级党组织和广大党员履职尽责创先进、争优秀，努力为测绘地理信息事业科学发展提供动力和保证，以优异的成绩迎接党的十八大胜利召开。

**一、**围绕中心任务，推动测绘地理信息各项工作完成

（一）认真学习贯彻党中央国务院重要会议精神和中央领导对测绘地理信息工作的重要批示精神。组织各级党组织和广大党员结合中心任务和实际，深入学习贯彻胡锦涛总书记“七一”重要讲话精神，深刻认识提高党的建设科学化水平的基本内涵，进一步树立科学发展理念；学习贯彻党的十七届六中全会精神，深刻认识推进文化改革发展和测绘地理信息文化建设的重要性和紧迫性；学习贯彻全国“两会”精神，切实把党中央国务院的决策部署落实在测绘地理信息“十二五”发展的具体实践之中；学习贯彻李克强副总理、何勇书记视察中国测绘创新基地时重要讲话精神以及中央领导对测绘地理信息工作的重要批示精神，深刻认识测绘地理信息事业的新地位、新方向、新任务，推动各项工作顺利完成。

（二）围绕测绘地理信息事业“十二五”规划创先争优。围绕测绘地理信息事业“十二五”发展总体战略，以做大做强测绘地理信息事业为核心，突出重点强平台，完善功能扩服务，提升能力推监测，健全体制优结构，服务发展壮企业，增强实力建强国，把破解发展难题作为创先争优活动的着力点，引导各级党组织和广大党员进一步增强责任意识，提升工作能力，提高办事效能，在测绘地理信息重大项目、重点工作和急难险重任务中勇挑重担，奋勇争先，多做贡献。

（三）立足本职岗位深化争创活动。结合本单位本部门中心任务和岗位职责，层层分解任务，具体明确基层党组织和党员的争创要求。继续大力开展“五型机关”创建活动，以“快、干、好”的作风和干劲，打造为民、务实、清廉的良好机关形象。继续组织开展公开承诺，做到个个有目标、人人见行动。激励基层党组织和广大党员在本职岗位上创先进，在日常工作中争优秀，在干事创业中实现“五带头”。

**二、**强化服务意识，着力推动机关干部下基层转作风

（四）深化窗口服务单位创先争优。深入贯彻落实《关于在窗口单位和服务行业深入开展为民服务创先争优活动的指导意见》，各窗口服务单位和部门要始终牢记服务第一的思想，增强服务意识，改进服务作风，普遍推行公开服务事项、工作流程、办结时限制度，公示服务标准，亮出党员身份，亮明岗位职责，争创群众认可、企业满意的服务窗口，打造优质服务品牌，树立优秀服务标兵。

（五）开展广泛深入走访群众活动。要坚持工作重心下移，经常深入实际、深入基层、深入群众，倾听群众意见，反映群众诉求，疏导群众情绪，做到切实解决问题。要利用节假日，走访慰问测绘地理信息战线上的院士专家、老党员老干部和生活困难的党员、群众，做到真心关怀温暖。

（六）开展深入基层调查研究工作。贯彻落实中央关于做好机关干部直接联系和服务群众的有关要求，按照局2012年调研计划和“3＋1”重点工作安排，采取多种形式，积极推动机关干部下基层、进企业、摸实情、办实事、增感情、转作风，切实把调研成果转化为服务基层、服务企业的具体措施和具体行动。

（七）开展深入测绘地理信息企业挂职锻炼活动。坚持选派机关年轻干部赴测绘地理信息企业挂职锻炼，熟悉企业情况，体验企业生活，同时要真心实意、全力以赴地为企业搞好服务，帮助企业营造良好的发展环境，不断增强机关干部与基层、与企业的沟通和感情。

**三、**夯实组织基础，认真落实“基层组织建设年”各项部署

（八）加强基层党组织建设。按照“抓落实、全覆盖、求实效、受欢迎”的工作要求，把落实“基层组织建设年”各项部署与创先争优活动紧密联系起来。紧紧围绕“强组织、增活力、创先争优迎十八大”这一主题，对所有党支部进行分析和考核，评定等级，做好局直属机关党委的换届选举工作，深入开展测绘地理信息企业党组织建设情况调研，着力增强基层党组织的创造力、凝聚力和战斗力。

（九）开展党建工作培训。着眼于提高素质、增强能力、创新方法、落实责任，开展党建工作培训，进一步扩大培训范围，提高培训质量，丰富培训内容，改进培训方式，提升“抓党建、带队伍、促发展”的意识和能力。直属机关党委将适时举办测绘地理信息党建工作培训班。

（十）开展“走进基层党支部”活动。积极参加中央国家机关“走进基层党支部，总结党建工作法”活动，深入调研、挖掘和宣传“服务中心、建设队伍”的好经验好做法，形成可借鉴推广的、独具测绘地理信息特色的“支部工作法”。直属机关党委将选树2～3个近年来受表彰的先进基层党支部典型，上报中央国家机关工委加以宣传推广。

（十一）开展“强支部建设，促科学发展”优秀活动的评选工作。在局直属机关开展“强支部建设，促科学发展”主题活动评选，使一批内容丰富、主题突出、形式新颖、充满活力的支部主题活动脱颖而出。通过开展优秀支部主题活动评选，选树典型，打造品牌，凝聚力量，扩大影响，不断发挥基层党支部和广大党员围绕中心、服务大局的保障作用，实现党建工作与业务工作双融合、共促进的良好局面。

（十二）增强党员队伍生机活力。深入开展社会主义核心价值体系学习活动，强化教育引导、强化认知践行、强化制度规范，引导和推动党员、干部成为社会主义核心价值体系的楷模，成为践行新时期测绘精神的典范。认真落实中央关于开展学雷锋活动的部署，结合实际，组织开展学雷锋活动。建立健全党员教育、管理、服务长效机制，完善党内激励、关怀、帮扶机制，进一步增强党组织的凝聚力和号召力。

（十三）深化党群共建创先争优。以党组织创先争优带动群团组织创先争优，充分发挥工会、共青团、妇委会等组织联系群众的优势和作用，形成党内带党外、党员带群众齐争共创的生动局面。以纪念“三八”国际劳动妇女节为契机，举办“迎十八大，抒巾帼情”测绘女职工摄影比赛，营造巾帼建功、比学赶超的浓厚氛围；以纪念“五一”国际劳动节为契机，挖掘测绘地理信息战线优秀人物和先进集体，积极参加全国“五一”劳动奖章和“五一”劳动奖状的评选活动；以纪念“五四”青年节为契机，组织开展直属机关杰出青年和优秀青年评选表彰活动，选树一批表现杰出、具有标杆和榜样作用的青年典型，激励和引导广大青年积极投身测绘地理信息事业发展。

**四、**总结活动规律，认真做好创先争优表彰总结工作

（十四）以“学身边楷模、赞测绘群英”为主题，开展创先争优活动的专项表彰和宣传工作。按照中央统一部署，组织好创先争优评选表彰，并于“七一”前夕召开创先争优活动专项表彰大会，进一步发挥先进典型的示范引领作用。以“学身边楷模、赞测绘群英”为主题，通过多种形式开展测绘地理信息系统创先争优活动的宣传工作，树立典范，讴歌英模，使先进典型成为广大党员、干部的学习榜样和精神追求。充分利用中国测绘报、局门户网站专栏、创先争优简报等载体，大力宣传先进基层党组织和优秀共产党员的模范事迹和经验做法，扩大创先争优活动的影响力和带动力，掀起创先争优活动的新高潮。

（十五）全面总结创先争优活动。七一前，各单位要认真总结创先争优活动的意义、特点、做法、成效和经验，采取问卷调查、召开座谈会等形式，广泛听取党员群众的意见建议，分级总结，客观评估，进一步梳理活动中的好经验好做法。要建立领导点评、承诺践诺评诺、群众评议等方面的长效机制，推动每个党支部至少建立一项务实管用的组织制度，实现边实践、边总结、边提高。

**五、**加强组织领导，确保创先争优活动取得实效

（十六）抓好群众评议。认真贯彻《关于开展群众评议创先争优活动的通知》要求，扎实开展群众评议，做到每个基层党组织和党员都接受群众评议。对群众评议满意度高的党组织和党员大力宣传，发挥示范带头作用；对群众反映问题多的党组织和党员要明确努力方向，落实整改责任，限期整改，确保群众评议取得实效。

（十七）落实工作责任。各级党组织要加强分类指导，探索适合不同工作、不同岗位创先争优活动的目标任务和实践载体，提出有针对性的工作思路和要求；要积极引导党员参与创先争优活动，着力激发党员的内在动力，因地制宜地开展内容丰富、形式多样的争创活动，不断增强活动的针对性、实效性。各级党员领导干部要身体力行，将抓争创与抓工作相结合，带头落实各项任务，切实帮助基层解决实际问题。
