# 财政部注册会计师考试办公室关于2012年度注册会计师专业阶段考试打印准考证时间安排的通知

2012年度注册会计师专业阶段考试准考证打印时间，除北京外，可在2012年9月24日上午8点开始打印，截止时间为2012年10月12日24时；北京由于个别考点信息出现变化，推迟至2012年9月24日下午4点开始打印，截止时间为2012年10月12日24时。

如有任何问题，请拨打电话010-88250110，01088250117。
