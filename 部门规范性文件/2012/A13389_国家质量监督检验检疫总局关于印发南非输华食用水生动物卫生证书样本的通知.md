# 国家质量监督检验检疫总局关于印发南非输华食用水生动物卫生证书样本的通知

## 国家质量监督检验检疫总局关于印发南非输华食用水生动物卫生证书样本的通知（2012年7月12日　国质检动函[2012]396号）

各直属检验检疫局：

总局已就南非输华食用水生动物卫生证书样本与南非方面达成一致，现就有关事宜通知如下：

**一、**南非贸易与工业部(NRCS)下属的比勒陀利亚(Pretoria)、德班(Durban)、伊丽莎白(Elizabeth)和开普敦(Cape Town)4个分支机构按照南非有关法规对输华食用水生动物检验检疫并出具卫生证书，4个机构签发的卫生证书样本见附件(原件纸质样本随后寄发)，2012年7月15日后启运的南非输华水生动物应随附该卫生证书，请各检验检疫机构按附件证书样本进行查验。

新证书样本也可在“外国官方检疫证书分析与验证识别系统”(http：／／10．37．0．1／ciqcert／ homepage．htm)中查询。

**二、**卫生证书有关说明

(一)该部官员签发证书，在该4种初始彩色证书副本上盖有带签发日期的官方印章。

(二)证书的内容均采用黑色打印，证书签名为蓝色，加盖蓝色或红色的注有日期的官方印章。

(三)证书顶部两侧均有卫生证书编号，卫生证书标题后(即Num．Ref．”后)有签证机构代码和货物代码。

(四)证书防伪标识特征：

1．证书底版的蓝色或绿色以及黑色内容对水和溶剂高敏感，当遇到水或化学溶剂会时颜色会散开或字迹模糊。

2．证书上印有紫外线防伪标识，当置于紫外线下时会发光显示。

3．在证书的左上角有一个20mm*20mm的防伪标签设计，上有“secure”和“authentic”两字可见，证书标识印在此标签上，如果贯穿此标签的齿孔线脱落则说明该证书已经失效。

4．证书在两个地方用红色印刷体同时编号，即一个印在右上角，一个印在左上角。

附件：南非输华食用水生动物卫生证书样本(略)
