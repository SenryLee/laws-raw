# 国家质量监督检验检疫总局公告2012年第126号――关于注销北京北大正元科技有限公司等企业工业产品生产许可证的公告

## 国家质量监督检验检疫总局公告（2012年第126号）

关于注销北京北大正元科技有限公司等企业工业产品生产许可证的公告

根据《中华人民共和国行政许可法》、《中华人民共和国工业产品生产许可证管理条例》和《工业产品生产许可证注销程序管理规定》，质检总局决定对北京北大正元科技有限公司等企业的25张工业产品生产许可证予以注销（名单见附件）。

从即日起，被注销的证书和工业产品生产许可证编号停止使用。

特此公告。

附件：注销工业产品生产许可证的企业名单
