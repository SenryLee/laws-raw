# 国家质量监督检验检疫总局计量司关于批准成立全国力值硬度计量技术委员会材料试验机工作组的函

全国力值硬度计量技术委员会：

你委员会《关于上报成立＜全国力值硬度计量技术委员会材料试验机工作组＞的筹建方案》（MTC7第2012-008号）收悉。经研究，批准成立“全国力值硬度计量技术委员会材料试验机工作组”，该工作组秘书处设在山东省计量科学研究院。工作组（组成方案见附件）自批准之日起，即可参照《全国专业计量技术委员会工作章程》开展工作。
