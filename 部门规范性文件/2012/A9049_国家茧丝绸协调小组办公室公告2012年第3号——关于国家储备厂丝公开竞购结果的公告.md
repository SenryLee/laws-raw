# 国家茧丝绸协调小组办公室公告2012年第3号——关于国家储备厂丝公开竞购结果的公告

## 国家茧丝绸协调小组办公室公告（2012年第3号）

关于国家储备厂丝公开竞购结果的公告

根据《国家茧丝绸办关于投放国家储备厂丝的公告》（国茧协办2012年第1号），2012年11月6日，国家茧丝绸办在中机国际招标公司举行了国家储备厂丝公开竞购开价及评审。现将结果公告如下：

**一、**竞购报价情况

截止11月5日下午16时，共有193家获得竞购资格的丝绸生产、加工及贸易企业缴纳了竞购保证金，其中，192家企业在规定的期限内递交了《国家储备厂丝竞购表》。经现场开价，有效《国家储备厂丝竞购表》192份，共计报出889个有效竞购报价。

**二、**平均竞购价格

价格评审委员会通过电子评审系统对所有有效竞购报价进行计算，本次国家储备厂丝公开竞购平均竞购价格为321950元/吨。

**三、**成功企业确定

价格评审委员会通过电子评审系统，对所有有效竞购报价按其与平均竞购价格差额的绝对值由小到大排序，差额小者先得；差额绝对值相同时按递交《国家储备厂丝竞购表》时间的先后顺序确定排序，先递者先得。按上述排序，共有62家丝绸企业报出的96个竞购包为本次国家储备厂丝公开竞购成功包。
