# 农业部关于下达2012年渔政船项目第二批追加中央预算内投资计划的通知

## 农业部关于下达2012年渔政船项目第二批追加中央预算内投资计划的通知（农计发[2012]43号）

有关省、自治区、直辖市农业（农牧）、渔业厅（委、局），黑龙江农垦总局，部有关直属单位：

根据《国家发展改革委关于下达渔政船项目2012年第二批追加中央预算内投资计划的通知》（发改投资〔2012〕3452号），现下达你单位2012年渔政船项目中央预算内投资计划，并就有关事项通知如下。

**一、**要切实加强项目建设和资金管理。按照固定资产投资管理的有关规定，抓紧开展项目前期工作，积极督促有关方面抓紧开工建设，尽快形成实物工作量。加强对项目质量、进度和资金使用的监督管理，确保及早建成发挥效益。

**二、**各单位要按有关制度要求，加快项目执行进度，建立健全项目建设信息报送制度，本批投资计划执行情况和项目建设项目实行月报制度，要及时将项目建设进度、投资安排使用情况和建设成效等报送我部。

**三、**我部将配合国家发展改革委对工作落实情况进行专项稽察。

农业部　　

2012年11月23日
