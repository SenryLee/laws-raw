# 国家核安全局关于批准颁发2012年第九批民用核安全设备焊工焊接操作工资格证书的通知

## 国家核安全局关于批准颁发2012年第九批民用核安全设备焊工焊接操作工资格证书的通知（国核安发[2012]205号）

各相关聘用单位：

上海电气电站设备有限公司等5家民用核安全设备焊工焊接操作工考核中心组织的焊工项目考试已经结束（考试编号见附件1）。根据《民用核安全设备焊工焊接操作工资格管理规定》（HAF603），我局组织有关单位进行了审查，现批准向上海阀门厂有限公司等11家聘用单位赵克明等142位民用核安全设备焊工焊接操作工，颁发民用核安全设备焊工焊接操作工资格证书（见附件2），共计272项合格项目。
