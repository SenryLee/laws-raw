# 农业部农机推广总站关于召开2012年《农机科技推广》杂志编委会议的通知

## 农业部农机推广总站关于召开2012年《农机科技推广》杂志编委会议的通知（农机推（宣）发[2012]60号）

各省、自治区、直辖市农机推广站，新疆生产建设兵团农机推广站，黑龙江省农垦总局农机局农机推广站：

为进一步作好《农机科技推广》杂志宣传报道和编辑、出版、发行等项工作，定于2012年9月29日召开2012年《农机科技推广》杂志编委会议。现将有关事项通知如下：

**一、**会议内容

1．总结2012年杂志宣传报道及编辑、发行工作。

2．交流各地推动杂志发行工作的做法和经验。

3．商定2013年杂志发行计划。

**二、**参会人员

《农机科技推广》杂志编委，杂志协办单位负责人。

**三、**会议时间与地点

会议时间：2012年9月29日，会期半天。

会议地点：北京广西大厦（北京市朝阳区潘家园华威里26号，北京市东三环华威桥往西）。

**四、**其他事项

2012年《农机科技推广》杂志编委会议与“中国农业技术推广协会农业装备与工程技术分会换届会议”同期召开，会议报到、会议食宿等按照“协会换届会议”通知执行。

农业部农机推广总站
