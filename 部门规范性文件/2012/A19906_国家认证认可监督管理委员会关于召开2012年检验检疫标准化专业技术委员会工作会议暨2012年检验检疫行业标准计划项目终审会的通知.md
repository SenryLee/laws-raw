# 国家认证认可监督管理委员会关于召开2012年检验检疫标准化专业技术委员会工作会议暨2012年检验检疫行业标准计划项目终审会的通知

各直属检验检疫局、中国检验检疫科学研究院，各检验检疫标准化专业技术委员会：

为总结2011年各检验检疫标准化专业技术委员会工作情况，做好本年度各项工作任务布置，同时研究确定2012年检验检疫行业标准计划项目，我委定于2012年3月8日～10日在贵州省贵阳市召开2012年检验检疫标准化专业技术委员会工作会议暨2012年检验检疫行业标准计划项目终审会，现将有关事项通知如下：

**一、**会议内容

（一）总结各检验检疫标准化专业技术委员会2011年工作，布置2012年工作任务；

（二）专题交流检验检疫标准化工作进展；

（三）对2012年检验检疫行业标准计划项目进行终审。

**二、**参会人员

（一）参会人员名单见附件1；

（二）特邀国家质检总局卫生司、动植司、检验司、食品局、科技司、内审司派员参会。

**三、**会议报到时间、地点

（一）报到时间：2012年3月7日

（二）报到地点：贵阳南天酒店（贵阳市南厂路155号省军区内）

**四、**相关事项

（一）各检验检疫标准化技术委员会应在会前梳理完成本专业2011年主要工作亮点、存在的问题以及本专业2012年工作计划和建议以备研讨；

（二）各检验检疫标准化技术委员会秘书长应对本专业前期网上审议的情况做出总结并提出初步审议意见，供参会的专家审核；

（三）为交流专业委工作情况，研讨相关重点议题，请各专业委秘书长提前一天（3月6日）报到；

（四）参会人员自行携带笔记本电脑；

（五）参会人员食宿费用自理；

（六）参会人员确定行程后尽快将抵达时间、车次或航班电告会议承办单位联系人（参会回执见附件2）。参会人员应按时报到；各单位不得自行调换参会人员，因故不能到会的，须事先向我委科技与标准管理部请假。
