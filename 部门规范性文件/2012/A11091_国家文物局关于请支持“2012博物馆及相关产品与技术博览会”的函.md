# 国家文物局关于请支持“2012博物馆及相关产品与技术博览会”的函

## 国家文物局关于请支持“2012博物馆及相关产品与技术博览会”的函（办博函〔2012〕759号）

各省、自治区、直辖市文物局（文化厅）：

经国家文物局批准，由中国博物馆协会、中国自然博物馆协会和北京市文物局主办，中国博物馆协会市场推广与公共关系专业委员会、中国农业博物馆承办的“2012博物馆及相关产品与技术博览会”（简称博博会），将于2012年10月28-30日在北京全国农业展览馆新馆举办。本次博博会的主题是“科技进步、文化创意与博物馆发展”，主要活动包括全国博物馆免费开放成果展、全国博物馆优秀文化创意设计推介、博物馆综合展示、中外博物馆相关产品与技术展示和讲座、推介与洽谈，对于推介我国博物馆发展建设和业务科研成果，搭建博物馆相关领域新技术产品交流平台，促进博物馆及其相关机构文化创意产品的研发和市场推广，推动博物馆事业又好又快发展都具有重要意义。

为了切实办好此次博博会，现就有关事项函告如下：

**一、**请各省（区、市）文物行政部门高度重视，组织辖区内有关文博单位，特别是中央地方共建国家级博物馆、省级（含）以上博物馆和国家一级博物馆积极参加本次博博会相关展示推广活动。

**二、**请各省（区、市）文物行政部门安排专人负责本地区参加本次博博会有关事宜的联络工作，于2012年9月30日前将联络员的姓名、职务、办公电话、手机、电子邮箱等告知中国博物馆协会（博博会组委会办公室）。
