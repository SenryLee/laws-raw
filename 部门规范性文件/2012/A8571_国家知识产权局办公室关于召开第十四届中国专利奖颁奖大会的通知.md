# 国家知识产权局办公室关于召开第十四届中国专利奖颁奖大会的通知

各省、自治区、直辖市、计划单列市、副省级城市、新疆生产建设兵团知识产权局，国务院有关部门和单位知识产权工作管理机构，各有关全国性行业协会，各有关单位：

为加快推进创新型国家建设，全面实施知识产权战略，鼓励和表彰为技术（设计）创新和促进经济社会发展做出突出贡献的专利权人和发明人（设计人），国家知识产权局与世界知识产权组织定于2012年11月30日上午9∶00在北京举办“第十四届中国专利奖颁奖大会”。现将有关事宜通知如下：

**一、**主要内容

表彰第十四届中国专利奖获奖者；为获奖项目代表（金奖）颁奖。

**二、**参会人员

（一）推荐单位代表：各省、自治区、直辖市、计划单列市、副省级城市、新疆生产建设兵团知识产权局领导1人，有关部委及行业协会代表，院士等；

（二）各金奖项目领奖代表1-2人；

（三）各有关园区管委会、机构和企业代表；

（四）优秀奖获奖单位可自愿派1-2人参会。

各推荐单位及金奖项目领奖代表食宿费用由我局承担，其他参会人员食宿费用自理。

请各有关地方知识产权局、部委及行业协会组织本地区、部门、机构推荐的优秀奖获奖项目代表参会。

**三、**报名、报到事宜

请于11月21日中午12∶00前将报名回执传真至（010）62679666（仇雅静收）并发送电子邮件至yjqiu@ctex.cn。

11月29日全天报到，地点：全国人大会议中心（地址：北京市西城区西黄城根北街2号，电话：010-63091999）。不住会的代表请于11月30日上午8∶20前报到。

**四、**注意事项

（一）会务组将根据报名情况邮寄请柬，届时凭请柬参会（人大会议中心采取严格的出入审查制度，限本人凭请柬出入）。

（二）金奖项目领奖代表须于11月29日下午15∶00到全国人大会议中心礼堂签到、彩排，着正装。

特此通知。
