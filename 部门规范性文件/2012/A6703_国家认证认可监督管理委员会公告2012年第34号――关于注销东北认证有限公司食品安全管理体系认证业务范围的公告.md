# 国家认证认可监督管理委员会公告2012年第34号――关于注销东北认证有限公司食品安全管理体系认证业务范围的公告

## 国家认证认可监督管理委员会公告（2012年第34号）

关于注销东北认证有限公司食品安全管理体系认证业务范围的公告

东北认证有限公司是2002年经国家认监委批准设立的认证机构（批准号：CNCA-R-2002-010）。其《认证机构批准书》有效期至2014年12月10日。经审查，该公司已获批准的食品安全管理体系认证业务范围的专职认证人员数量已不能满足《中华人民共和国认证认可条例》第十条的规定。

经研究决定，自公告发布之日起注销东北认证有限公司食品安全管理体系认证业务范围。请持有东北认证有限公司该领域有效认证证书的组织，按照自愿原则选择其他经国家认监委批准的具有相关认证业务资质的认证机构转换认证证书。

特此公告。

国家认证认可监督管理委员会

2012年12月25日
