# 国家文物局关于闸口白塔保护工程可行性研究方案的意见

## 国家文物局关于闸口白塔保护工程可行性研究方案的意见（办保函〔2012〕699号）

浙江省文物局：

你局《关于要求审批＜全国重点文物保护单位闸口白塔保护工程可行性研究方案＞的请示》（浙文物发[2012]159号）收悉。经研究，我局提出以下意见：

**一、**新建的钢结构塔形罩，其尺度按照城市地标建筑进行设计，体形庞大，破坏了白塔原有的历史景观和环境。覆罩后，白塔从露天环境改为封闭环境，保存环境的改变易对白塔现状的稳定造成负面影响。

**二、**对于闸口白塔现存较严重的风化问题，请你局组织有关单位继续开展监测，根据监测结果开展科学评估、分析，统筹考虑白塔本体保护和历史环境风貌的保护，重新制订科学合理的保护方案。

专此。

国家文物局　　

二〇一二年六月七日
