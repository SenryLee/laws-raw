# 国家文物局关于撤拍“西泠印社2012秋季拍卖会”有关标的的函

## 国家文物局关于撤拍“西泠印社2012秋季拍卖会”有关标的的函（办博函〔2012〕966号）

浙江省文物局：

你局《文物拍卖标的审核意见》（受理编号：20120054）收悉。

经复核，“西泠印社2012秋季拍卖会”报审标的第147号“战国?蚁鼻银钱”、第148号“汉?五铢钱范?钱串一组”、第152号“战国?方足布一组”、第156号“北宋?大观通宝铁母（折三）”不得作为拍卖标的。

请你局通知西泠印社拍卖有限公司立即撤拍上述标的。

专此。

国家文物局　　　

二〇一二年十二月十四日
