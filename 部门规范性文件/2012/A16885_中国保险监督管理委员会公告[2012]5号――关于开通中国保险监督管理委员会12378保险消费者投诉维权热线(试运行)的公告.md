# 中国保险监督管理委员会公告[2012]5号――关于开通中国保险监督管理委员会12378保险消费者投诉维权热线(试运行)的公告

## 中国保险监督管理委员会公告（[2012]5号）

为畅通保险消费者投诉维权渠道，切实保护保险消费者合法权益，中国保险监督管理委员会决定即日起开通“中国保险监督管理委员会12378保险消费者投诉维权热线（试运行）”。现将有关事项公告如下：

**一、**受理范围

（一）保险消费者维权投诉；

（二）对保险市场违法违规行为的举报。

**二、**工作时间

工作日9：00-17：00

（新疆维吾尔自治区

10月-4月 10：00-14：00 15：00-19：00

5月-9月 9：30-13：30 15：00-19：00 ）

特此公告

中国保险监督管理委员会

二〇一二年四月二十六日
