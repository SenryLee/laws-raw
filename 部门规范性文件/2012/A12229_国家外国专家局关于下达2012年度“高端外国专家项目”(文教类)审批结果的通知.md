# 国家外国专家局关于下达2012年度“高端外国专家项目”(文教类)审批结果的通知

## 国家外国专家局关于下达2012年度“高端外国专家项目”（文教类）审批结果的通知

各省、自治区、直辖市及副省级城市外国专家局，新疆生产建设兵团外国专家局：

为落实中央人才战略，配合“外专千人计划”的实施，加快建设高层次外国专家队伍，国家外国专家局设立了“高端外国专家项目”。根据各地方外国专家局上报的项目材料，经专家评审，现下达2012年度“高端外国专家项目”（文教类）审批结果（附件1），请按以下要求认真执行：

**一、**用人单位要严格按照已批准的项目计划聘请外国专家，保证专家在华工作时间，完善专家工作环境，充分发挥专家领军带头作用。对于所聘外国专家发生变更或专家来华时间明显不足的，用人单位应通过各地外国专家局报国家外国专家局终止项目执行。

**二、**“高端外国专家项目”经费列入“千人计划”配套引智经费预算，管理和使用应严格遵照《“千人计划”配套引智经费管理办法（暂行）》（外专发[2011]73号）。其中，专家国际旅费、生活费、城市间交通费等按《引进人才专家经费管理细则》（外专发[2010]87号）规定的标准支付，专家工薪补助标准按最高不超过合同工薪的60%支付。支付专家工薪的，不再支付零用费。

**三、**用人单位在项目完成后要及时总结，并将执行情况、成果总结报各地外国专家局，由地方外国专家局汇总后报国家外国专家局。对于聘请后未按计划开展工作或未取得预期成效的，国家外国专家局将减少或终止项目资助。对于不提交成果总结的，国家外国专家局不再受理用人单位第二年的项目申请。

**四、**各地外国专家局要认真监督已批准项目的执行情况，加强业务指导，组织评估验收，并汇总每个项目的总结和引智成果（附件2、附件3），于2012年12月31日前报送国家外国专家局教科文卫专家司。项目执行情况和成果总结是国家外国专家局调整和制定翌年“高端外国专家项目”计划的重要依据。

**五、**各地外国专家局应积极争取地方相关部门的配套支持，同时规范管理、优化服务，使项目效益最大化。

**六、**本通知及附件表格可从国家外国专家局网站下载。
