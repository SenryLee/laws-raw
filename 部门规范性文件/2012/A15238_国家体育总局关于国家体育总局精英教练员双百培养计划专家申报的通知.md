# 国家体育总局关于国家体育总局精英教练员双百培养计划专家申报的通知

有关单位：

为更好地实施国家体育总局精英教练员双百培养计划，进一步加强教练员人才队伍建设，现按照《国家体育总局精英教练员双百培养计划实施办法》，选拔专家参与该计划资助对象的遴选、督导、培训与考评工作，现将有关事宜通知如下。

**一、**申报范围

国家体育总局各奥运项目管理中心、各省（区、市）体育局、总参军训和兵种部体育训练局、总政宣传部文化体育局、国家体育总局体育科学研究所、各体育院校与有关单位的国家级教练员、专家教授、管理人员。

**二、**申报条件

（一）具备较高的思想政治素质，热爱祖国，热爱体育事业，具有较强的事业心、责任感和奉献精神。

（二）具备较高的业务素质，长期从事运动训练指导、教学、科学研究与相关管理工作，理论知识扎实，实践经验丰富，并取得一定的理论与实践成果。

（三）具有本科以上文化程度。教练员具备国家级专业技术职务，专家教授具备正高专业技术职务，管理人员具备处级以上行政职务。

（四）身体健康状况良好，能适应专家相关工作的要求。

**三、**申报时间与方式

（一）申报时间为2012年5月29日-6月5日。

（二）各有关单位根据通知内容组织本单位专家进行申报工作，申报采取个人自愿与单位推荐相结合的方式。

（三）各有关单位在规定时间内将申报专家填写的《国家体育总局精英教练员双百培养计划评审专家申报书》，连同推荐资料，包括被推荐人学历、学位、任职资格及本人身份有效证件复印件等一起报送国家体育总局教练员学院，报送时间以邮戳日期为准，报送材料同时包括电子件与纸质件。

**四、**专家确定

（一）教练员学院根据推荐人选资料结合教练员培养工作需要拟定专家名单，并上报国家体育总局教练员培训工作领导小组审核确定。

（二）入选专家接受培训并通过考核后，由国家体育总局颁发专家聘书（有效期为3年），并签订协议书，参与专家组相关工作。

请各单位高度重视专家申报工作， 在规定时间内报送相关材料。
