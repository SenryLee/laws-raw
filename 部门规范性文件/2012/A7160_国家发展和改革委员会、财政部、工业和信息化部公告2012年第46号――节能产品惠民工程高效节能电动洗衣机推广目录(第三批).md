# 国家发展和改革委员会、财政部、工业和信息化部公告2012年第46号――节能产品惠民工程高效节能电动洗衣机推广目录(第三批)

## 国家发展和改革委员会、财政部、工业和信息化部公告

（2012年第46号）

根据《财政部 国家发展改革委关于开展节能产品惠民工程的通知》（财建[2009]213号）和《财政部 国家发展改革委 工业和信息化部关于印发＜节能产品惠民工程高效节能电动洗衣机推广实施细则＞的通知》（财建[2012]277号），国家发展改革委、财政部、工业和信息化部组织对地方上报的高效节能电动洗衣机推广申请报告及相关材料进行了审核。现将节能产品惠民工程高效节能电动洗衣机推广目录（第三批）予以公告，自发布之日起开始实施。

附件：1、节能产品惠民工程高效节能电动洗衣机推广企业目录（第三批）；

2、节能产品惠民工程高效节能电动洗衣机推广目录（第三批）；

3、节能产品惠民工程高效节能电动洗衣机推广销售网点目录（第三批，请到www.jienenghuimin.org查阅、下载）（略）。
