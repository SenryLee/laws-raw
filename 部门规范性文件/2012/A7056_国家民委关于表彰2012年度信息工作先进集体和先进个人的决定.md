# 国家民委关于表彰2012年度信息工作先进集体和先进个人的决定

各省、自治区、直辖市及计划单列市民（宗）委（厅、局），新疆生产建设兵团民宗局，各民族工作信息直报点，委机关各部门、直属各单位：

2012年，各级民族工作部门和广大信息工作者坚持以邓小平理论、“三个代表”重要思想、科学发展观为指导，以迎接党的十八大胜利召开和深入学习贯彻落实十八大精神为主线，紧紧围绕党和国家民族工作大局，结合自身工作特点，切实加强信息工作，积极为中央和各级组织了解情况、指导工作和科学决策做好信息服务。国家民委决定，对信息工作成绩突出的广西壮族自治区民委等29个先进集体、赵武林等49名先进个人给予表彰。

希望受到表彰的集体和个人珍惜荣誉，再接再厉，不断取得新成绩。各级民族工作部门和广大信息工作者要向先进集体和先进个人学习，切实增强责任感、使命感，不断提高信息工作水平，为促进民族团结、实现共同进步作出新的更大贡献。
