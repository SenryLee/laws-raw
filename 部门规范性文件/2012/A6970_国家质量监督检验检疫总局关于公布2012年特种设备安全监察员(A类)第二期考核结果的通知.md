# 国家质量监督检验检疫总局关于公布2012年特种设备安全监察员(A类)第二期考核结果的通知

## 国家质量监督检验检疫总局关于公布2012年特种设备安全监察员（A类）第二期考核结果的通知

各省、自治区、直辖市质量技术监督局：

为满足特种设备安全监察工作的需要，进一步加强队伍建设，提高安全监察人员的依法行政水平，按照《特种设备安全监察人员管理办法》及《特种设备安全监察人员培训考核大纲》的要求，我局于2012年11月30日在青岛市对符合并申报特种设备安全监察员（A类）资格的61人进行了考核，合格56人。现将考核合格人员名单予以公布。

本次弃考人员如需参加以后的A类安全监察人员考核，需重新向总局特种设备局提交申请。

附件：考核合格人员名单（略）

国家质量监督检验检疫总局

2012年12月20日
