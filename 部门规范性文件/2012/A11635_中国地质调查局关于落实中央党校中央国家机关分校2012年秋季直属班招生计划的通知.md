# 中国地质调查局关于落实中央党校中央国家机关分校2012年秋季直属班招生计划的通知

局属各单位、局机关各部室：

近日，部人事司印发了《中央党校中央国家机关分校2012年秋季直属班招生通知》（国土资人教函[2012]109号），分配给我局15名处级党员干部培训名额。请各单位结合本单位处级党员干部培训实际，优先推荐中青年处级干部。地科院（含下属单位）上报3名人选，其他局属单位各上报1名人选。请各单位将《中央党校中央国家机关分校2012年秋季直属班报名表》（见人事司通知附件2）于9月12日前报局人事教育部综合处。

《中央党校中央国家机关分校2012年秋季直属班招生通知》（国土资人教函[2012]109号）请登录局外网和办公内网查询。
