# 国家质量监督检验检疫总局公告2012年第216号――关于公布2012年28类产品质量国家监督抽查结果的公告(三)

##

续（二）

附件18

土工合成材料产品质量国家监督抽查结果

本次共抽查了北京、天津、河北、辽宁、江苏、福建、山东、河南、湖北、广东、重庆、四川等12个省、直辖市69家企业生产的75种土工合成材料产品，包括土工布、土工格栅、土工膜、土工复合材料4种类型。

本次抽查依据《短纤针刺非织造土工布》GB/T17638-1998、《长丝纺粘针刺非织造土工布》GB/T17639-2008、《长丝机织土工布》GB/T17640-2008、《裂膜丝机织土工布》GB/T17641-1998、《塑料土工格栅》GB/T17689-2008、《塑料扁丝编织土工布》GB/T17690-1999、《聚乙烯土工膜》GB/T17643-1998、《非织造复合土工膜》GB/T17642-2008和经备案现行有效的企业标准及产品明示质量要求，对土工合成材料产品的2%伸长率时的拉伸强度、5%伸长率时的拉伸强度、CBR顶破强力、剥离强度、标称伸长率、标准强度对应伸长率、尺寸稳定性、垂直渗透系数、单位面积质量偏差、等效孔径、顶破强力、断裂强力、断裂伸长率、厚度、经纬向断裂伸长率、经纬向撕破强力、经向断裂强度、经向断裂强力、拉伸强度、耐静水压、水蒸气渗透系数、炭黑含量、梯形撕破强力（纵向）、纬向断裂强度、纬向断裂强力、直角撕裂强度、纵横向标准强度对应伸长率、纵横向断裂强度、纵横向撕破强力等29个项目进行了检验。

抽查发现有5种产品不符合标准的规定，涉及到炭黑含量、耐静水压、厚度项目。具体抽查结果见附件。

电动工具（电钻、电锤、角向磨光机）产品质量国家监督抽查结果

本次共抽查了河北、辽宁、吉林、上海、江苏、浙江、福建、广东、四川等9个省、直辖市72家企业生产的94种电动工具（电钻、电锤、角向磨光机）产品。

本次抽查依据《手持式电动工具的安全　第一部分：通用要求》GB3883.1-2005、《手持式电动工具的安全　第二部分：砂轮机、抛光机和盘式砂光机的专用要求》GB3883.3-2007、《手持式电动工具的安全　第二部分：电钻和冲击电钻的专用要求》GB3883.6-2007、《手持式电动工具的安全　第二部分：锤类工具的专用要求》GB3883.7-2005、《家用电器、电动工具和类似器具的电磁兼容要求 第1部分：发射》GB4343.1-2009等标准的要求，对电钻、电锤和角向磨光机产品的标志，防止触及带电零件的保护，发热，泄漏电流，电气强度，耐久性，不正常操作，机械危险，机械强度，结构，内部布线，电源联接和外接软线，接地装置，爬电距离、电气间隙和绝缘穿通距离，骚扰电压，骚扰功率等16个项目进行了检验。

抽查发现有13种产品不符合标准的规定，涉及到发热，电气强度，耐久性，机械危险，机械强度，结构，内部布线，电源联接和外接软线，爬电距离、电气间隙和绝缘穿通距离，骚扰电压项目。具体抽查结果见附件。

附件22

防爆低压起动器产品质量

国家监督抽查结果

本次共抽查了河北、山西、辽宁、上海、江苏、浙江、山东等7个省、直辖市68家企业生产的68种防爆低压起动器产品。

本次抽查依据《爆炸性环境 第1部分：设备 通用要求》GB3836.1-2010、《爆炸性环境 第2部分：由隔爆外壳“d”保护的设备》GB3836.2-2010、《爆炸性环境 第3部分：由增安型“e”保护的设备》GB3836.3-2010等标准的要求，对防爆低压起动器产品的产品标志、接地连接件、电气间隙和爬电距离、温度测定、热剧变试验、抗冲击试验、电缆夹紧试验、引入装置密封性能试验、隔爆接合面参数、外壳耐压试验、内部点燃的不传爆试验等11个项目进行了检验。

抽查发现有6种产品不符合标准的规定，涉及到隔爆接合面参数、抗冲击试验项目。具体抽查结果见附件。

附件25

商用电动食品加工设备产品质量

国家监督抽查结果

本次共抽查了北京、河北、辽宁、江苏、浙江、安徽、山东、湖北、湖南、广东等10个省、直辖市90家企业生产的90种商用电动食品加工设备产品。包括和面机，切片机，绞肉机（切肉机），搅拌机，切菜机，压、切面机，刨冰机，奶昔机等产品。

本次抽查依据《家用和类似用途电器的安全 商用电动饮食加工机械的特殊要求》GB 4706.38-2008等标准的要求，对商用电动食品加工设备产品的标志和说明，对触及带电部件的防护，输入功率和电流，工作温度下的泄漏电流和电气强度，泄漏电流和电气强度，非正常工作，稳定性和机械危险，机械强度，结构，内部布线，电源连接和外部软线，外部导线用接线端子，接地措施，螺钉和连接，电气间隙、爬电距离和固体绝缘等15个项目进行了检验。

抽查发现有14种产品不符合标准的规定，涉及到稳定性和机械危险、对触及带电部件的防护、电源连接和外部软线、接地措施、非正常工作、泄漏电流和电气强度、内部布线、结构、标志和说明项目。具体抽查结果见附件。

附件26

木工锯类机床产品质量国家监督抽查结果

本次共抽查了河北、辽宁、江苏、浙江、山东、河南、广东等7个省33家企业生产的33种木工锯类机床产品，包括锯板机、带锯机、圆锯机3种类型。

本次抽查依据《木工机床 安全通则》GB 12557-2010、《机械电气安全 机械电气设备第1部分：通用技术条件》GB5226.1-2008等标准的要求，对木工锯类机床产品的控制装置的安全工作装置、保护联结电路的连续性、操纵器、传动的安全、刀夹和刀具、电动机过热保护、电击防护、动力源故障或控制电路故障、工件抛射危险的防护、过电流保护、火和爆炸、机构功能动作试验、夹紧装置、加工区的防护、紧急停止、精度、绝缘电阻试验、空运转噪声、控制装置的安全性和可靠性、联锁装置、耐压试验、起动、渗漏、温升试验、正常停止等25个项目进行了检验。

抽查发现有9种产品不符合标准的规定，涉及到保护联结电路的连续性、电击防护、过电流保护、电动机过热保护、控制装置的安全性和可靠性、 紧急停止、精度、动力源故障或控制电路故障、安全工作装置项目。具体抽查结果见附件。
