# 民航局运输司关于部分外国航空公司开通至我国定期航线的信息通告(2012)

## 民航局运输司关于部分外国航空公司开通至我国定期航线的信息通告

经民航局批准，济州航空将于2012年6月22日起使用B737-800型飞机开通首尔-青岛往返定期客运航线，每周7班；泰国东方航空公司将于2012年7月2日起使用B737型飞机开通每周3班素叻他尼-昆明往返及于2012年7月14日起使用B737型飞机开通每周3班曼谷-昆明往返定期客运航线。

民航局运输司　

二零一二年六月八日
