# 农业部关于公布2012年渔业文明执法窗口单位的通知

## 农业部关于公布2012年渔业文明执法窗口单位的通知（农渔发[2012]33号）

2012年，全国各级渔政机构按照我部统一部署，以创先争优活动为载体，以渔政队伍规范化建设为主线，以渔民满意为目标，抓培训、严管理、转作风、树形象，渔业文明执法窗口单位创建活动取得明显成效。为鼓励先进，示范带动更多基层渔政机构加强渔政队伍建设，经严格考核并社会公示，我部决定授予黄渤海区渔政局“中国渔政112”船等30个渔政机构“2012年渔业文明执法窗口单位”称号，现予以公布。

希望被授予上述称号的单位进一步总结经验，发扬成绩，在现代渔政管理工作中积极发挥示范带头作用，努力创造新业绩，不断做出新贡献。各级渔政机构要向窗口单位学习，深入贯彻落实科学发展观，恪尽职守、规范执法，转变作风、服务渔民，在执法和服务工作中争创一流业绩，为推动渔业经济又好又快发展提供更加有力的保障。

农业部　　

2012年11月21日
