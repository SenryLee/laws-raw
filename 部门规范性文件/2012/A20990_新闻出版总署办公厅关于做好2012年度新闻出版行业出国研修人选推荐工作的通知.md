# 新闻出版总署办公厅关于做好2012年度新闻出版行业出国研修人选推荐工作的通知

## 新闻出版总署办公厅关于做好2012年度新闻出版行业出国研修人选推荐工作的通知（新出厅字〔2012〕49号）

各省、自治区、直辖市新闻出版局，新疆生产建设兵团新闻出版局，解放军总政治部宣传部新闻出版局，中央和国家机关各部委、各民主党派、各人民团体新闻出版主管部门，中国出版集团公司，署直各单位、署管各社会团体：

为加快新闻出版业“走出去”人才培养，进一步推动新闻出版人才国际交流，培养一批外向型经营管理人才、专业技术人才、翻译人才和复合型创新人才，新闻出版总署将组织新闻出版单位负责人和中青年业务骨干赴国外研修（见附件1）。现就做好研修人选推荐工作通知如下：

**一、**研修班次与内容

今年拟举办6期出国研修培训班，主要学习现代出版经营管理及数字出版业务知识。

1.赴澳大利亚悉尼科技大学的新闻媒体与手机平台结合及实时新闻培训班。

2.赴匈牙利布达佩斯康维尔斯大学的出版传媒企业在市场化条件下的生存与发展培训班。

3.赴美国纽约州立大学的出版经营与管理创新培训班。

4.赴英国威斯敏斯特大学的与英国报业对话媒介融合及数字化未来培训班。

5.赴德国不莱梅应用科技大学的期刊差异化战略与经营管理培训班。

6.赴美国纽约州立大学的数字和网络出版培训班。

**二、**推荐对象及条件

1.赴澳大利亚悉尼科技大学的新闻媒体与手机平台结合及实时新闻培训班主要推荐报业领军人才，报业集团和报社高层管理人员及部门负责人参加。

2.赴匈牙利布达佩斯康维尔斯大学的出版传媒企业在市场化条件下的生存与发展培训班主要推荐新闻出版行业领军人才，各出版单位高层管理人员及部门负责人参加。

3.美国纽约州立大学的出版经营与管理创新培训班主要推荐新闻出版行业领军人才，出版集团、出版社高层管理人员及中青年业务骨干参加。

4.赴英国威斯敏斯特大学的与英国报业对话媒介融合及数字化未来培训班主要推荐报业领军人才，报业集团和报社高层管理人员及部门负责人参加。

5.赴德国不莱梅应用科技大学的期刊差异化战略与经营管理培训班主要推荐期刊行业领军人才，期刊集团高层管理人员和期刊社担任副主编职务（含）以上的负责人参加。

6.赴美国纽约州立大学的数字和网络出版培训班主要推荐新闻出版行业领军人才，出版集团、出版社或期刊社负责人及中青年业务骨干参加。

推荐人选应具备下列条件：

1.年龄在45岁以下，单位负责人不超过55周岁，身体健康。

2.具有丰富的专业工作经验，并有良好的工作业绩。

3.原则上具有本科以上学历或副高级职称。

4.专业理论素养较高，能与外方开展业务交流研讨、英语水平较高的人员优先推荐。

**三、**推荐程序

地方新闻出版单位推荐国外研修培训人选，经本省（自治区、直辖市）新闻出版局审核汇总后报送新闻出版总署教育培训中心。中央在京新闻出版单位经主管部门同意可直接向总署教育培训中心报送本单位人选推荐表。推荐1名以上人选的单位要依据选拔条件确定推荐人选次序。新闻出版总署相关司局将根据培训内容、培训对象，并结合以往报名执行情况，对报名人员进行选拔。

**四、**工作要求

各省（自治区、直辖市）新闻出版局、出版集团、报业集团、期刊集团要把新闻出版（版权）人才的出国研修培训作为实施人才战略和“走出去”战略的重要举措，切实加强组织协调。各新闻出版单位要高度重视并积极选派优秀骨干人员出国研修，做好人选推荐工作。推荐表需于2012年3月5日前报送（同时发送传真）。
