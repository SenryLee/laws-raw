# 国家认监委关于召开2012年《中国认证认可年鉴》工作会议的通知

各直属出入境检验检疫局，各省、自治区、直辖市质量技术监督局，下属单位，相关认证机构：

为推动认证认可信息宣传工作深入开展，切实提高《中国认证认可年鉴》编纂质量和水平，经研究，决定召开2012年《年鉴》工作会议。现将有关事项通知如下：

**一、**会议时间、地点。会议定于5月8-9日在四川成都召开， 5月7日报到。

**二、**参会人员。请地方两局、下属单位、认证机构负责《年鉴》组稿工作或信息宣传工作的同志参加会议，各单位1人。

**三、**会议内容

1. 通报2011-2012年度《年鉴》工作进展情况，对《年鉴》编撰发行及稿件质量提出具体要求；

2. 就进一步加强和改进《年鉴》编撰发行工作进行研讨，听取地方两局、下属单位和认证机构的意见；

3. 总结《年鉴》编撰发行工作经验，表扬优秀组织单位。

**四、**有关事项

1. 会议地点在成都市四川花园宾馆，地址为：成都市锦江区走马街47号，总机：028-86653888。

2. 地方两局、下属单位的会议代表的食宿费用由办会方承担，差旅费自理；认证机构代表及各单位增派代表费用自理。

3. 四川检验检疫局负责会议代表的接送站，请各单位于5月4日前将回执传真至四川检验检疫局。
