# 工业和信息化部关于王勇等3名同志任职的通知

## 工业和信息化部关于王勇等3名同志任职的通知（工信部任〔2012〕65号）

工业和信息化部电子第五研究所（中国电子产品可靠性与环境试验研究所）：

工业和信息化部决定：

王　　勇任工业和信息化部电子第五研究所（中国电子产品可靠性与环境试验研究所）副所长；

牟宗庆任工业和信息化部电子第五研究所（中国电子产品可靠性与环境试验研究所）副所长；

万举勇任工业和信息化部电子第五研究所（中国电子产品可靠性与环境试验研究所）总工程师。

以上三名同志任职试用期一年，任职时间自2012年7月17日党组会决定之日起计算。
