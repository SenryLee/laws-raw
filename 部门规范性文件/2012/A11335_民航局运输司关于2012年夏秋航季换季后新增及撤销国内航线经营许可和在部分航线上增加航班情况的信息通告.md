# 民航局运输司关于2012年夏秋航季换季后新增及撤销国内航线经营许可和在部分航线上增加航班情况的信息通告

经民航局航空运输（通用航空）委员会审议，现将2012年夏秋航季换季后新增涉及北京、上海、广州三大城市机场的区际国内航线经营许许可颁发情况通告如下：

1、核准航线

东航等6家航空公司新增属核准范围的国内航线经营许可12条，共158班（详见附表1）。东航等4家航空公司在属核准范围的5条航线上每周共增加70个航班（详见附表2）。

2、登记航线

国航等6家公司属登记范围的国内航线经营许可23条，共258班（详见附表1）。东航等6家航空公司在属登记范围的34条航线上每周共增加458个航班（详见附表2）。

3、撤/注销国内航线经营许可

撤销厦航属核准范围的国内航线经营许可1条。（详见附表1）
