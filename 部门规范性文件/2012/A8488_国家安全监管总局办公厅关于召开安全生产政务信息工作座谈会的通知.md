# 国家安全监管总局办公厅关于召开安全生产政务信息工作座谈会的通知

## 国家安全监管总局办公厅关于召开安全生产政务信息工作座谈会的通知（安监总厅〔2012〕157号）

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局，各省级煤矿安全监察局，总局和煤矿安监局机关各司局、应急指挥中心，各在京直属事业单位：

经研究，定于2012年11月23日在福建省福州市召开安全生产政务信息工作座谈会。现将有关事项通知如下：

**一、**会议内容

认真学习贯彻国家安全监管总局领导同志关于安全生产政务信息工作的重要批示指示精神，总结和座谈交流近年来安全生产政务信息工作经验，结合新形势下安全生产工作的新要求，部署加强下一步安全生产政务信息工作。

**二、**参加人员

各单位政务信息工作部门负责人各1人。

**三、**会议时间及地点

（一）时间：11月23日，会期一天。11月22日报到。

（二）地点：福建省福州市闽江饭店（地址：福州市五四路130号）。

**四、**其他事项

（一）请各单位将参加会议的代表名单（包括姓名、性别、部门、职务、联系电话）于11月21日12时前传真至国家安全监管总局办公厅（联系电话：010-64463969〈带传真〉）。

（二）会议统一安排食宿，费用自理。

（三）11月22日全天在福州机场安排接站。请需要接站的代表提前将所乘航班及抵达时间反馈福建省安全监管局办公室。
