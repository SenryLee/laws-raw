# 国家质量监督检验检疫总局关于公布国家计量标准一级考评员名单的通知(2012)

## 国家质量监督检验检疫总局关于公布国家计量标准一级考评员名单的通知（2012年7月13日　国质检量函[2012]398号）

各省、自治区、直辖市质量技术监督局，中国计量科学研究院，各有关单位：

按照《计量标准考评员管理规定》(质技监局量函[1999]300号)的有关规定，经对考评员申请延期的资料进行审核，确认符合要求。现将准予延期的国家计量标准一级考评员名单(见附件)予以公布。
