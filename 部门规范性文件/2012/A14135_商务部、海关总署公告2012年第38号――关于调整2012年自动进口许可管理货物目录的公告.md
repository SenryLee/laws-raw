# 商务部、海关总署公告2012年第38号――关于调整2012年自动进口许可管理货物目录的公告

## 商务部、海关总署公告（2012年第38号）

根据《中华人民共和国对外贸易法》、《中华人民共和国货物进出口管理条例》和《货物自动进口许可管理办法》，现决定调整《2012年自动进口许可管理货物目录》，取消部分货物自动进口许可管理（详见附件），自2012年7月1日起执行。

附件：取消自动进口许可管理商品清单
