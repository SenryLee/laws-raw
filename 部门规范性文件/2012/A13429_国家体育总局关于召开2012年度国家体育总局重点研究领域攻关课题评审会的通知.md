# 国家体育总局关于召开2012年度国家体育总局重点研究领域攻关课题评审会的通知

有关单位、有关课题负责人：

按照2012年度国家体育总局重点研究领域攻关课题评审立项工作整体安排，我们决定召开评审会，对通过初审的科研课题进行立项评审，现将有关事项通知如下：

**一、**时间及地点：

（一）时间：2012年7月30-31日。

（二）地点：北体宾馆会议室（北京体育大学东南门向东）。

各课题评审具体时间及地点见分组表（附件）。

**二、**具体要求：

（一）各课题由承担人作申请报告，时间15分钟，其中技术报告10分钟，财务报告5分钟，并准备投影。技术报告重点从研究目的、研究内容、技术路线以及预期结果、考核指标等方面进行报告。财务报告重点从列支科目，支出依据等方面报告。课题承担人不能到会者，取消课题评审资格。

（二）请各课题负责人按照课题分组表准时参会，当天参会的课题负责人于会议当天8：00到北体宾馆三层会议室签到，并参加全体会议，由科教司部署相关工作。届时未报到的课题负责人，取消其评审资格。

（三）参会人员自带课题申报书一式五份。

（四）各课题组参会人员交通、食宿费自理。
