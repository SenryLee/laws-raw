# 农业部办公厅关于报送2012年国家现代农业示范区建设工作总结的通知

## 农业部办公厅关于报送2012年国家现代农业示范区建设工作总结的通知（农办计[2012]117号）

各省、自治区、直辖市、计划单列市农业厅（委、局），新疆生产建设兵团农业局，黑龙江省、广东省农垦总局：

根据《农业部关于创建国家现代农业示范区的意见》（农计发[2009]33号）要求，现就开展2012年国家现代农业示范区（以下简称示范区）建设情况总结工作通知如下：

**一、**总结内容

（一）建设成效。示范区在主导产业发展、农业设施装备建设、科技推广应用、发展规模经营、经营体制机制创新等方面取得的成效。

（二）创新举措。示范区在加强组织领导、推动规划引领、创新建设模式、出台扶持政策、争取资金投入、强化考核管理等方面采取的有亮点、有创新、有突破的做法。

（三）存在的主要问题。示范区建设中面临的主要问题和困难。

（四）下一步推进思路和打算。今后一段时期特别是2013年推进示范区建设的主要思路和打算。

（五）有关政策建议。对加快示范区建设的意见建议。

**二、**报送程序

各示范区对将年度建设工作总结材料（附建设情况表，见附件）提交省级农业主管部门审核后，由各省农业主管部门统一报送我部现代农业示范区管理办公室。各示范区总结材料原则上不超过4000字，有关数据可采用预计数。

**三、**报送要求

请各省农业主管部门按照本通知要求，组织各示范区认真开展总结工作，并于2012年11月15日前将第一批和第二批示范区的2012年度建设工作总结、建设情况表报送我部现代农业示范区管理办公室1套（电子版同时发至sfqglbgs@agri.gov.cn）。
