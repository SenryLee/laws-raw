# 农业部办公厅关于2012年全国饲料质量安全监测结果的通报

## 农业部办公厅关于2012年全国饲料质量安全监测结果的通报（农办牧〔2012〕48号）

各省、自治区、直辖市畜牧（农牧、农业）厅（委、局、办）、饲料工作（工业）办公室、饲料质检机构：

为加强饲料质量安全监管，严厉打击在饲料中添加瘦肉精、三聚氰胺等禁用物质的违法行为，提高饲料和养殖产品质量安全水平，2012年，我部继续在全国 30个省（区、市）组织开展了饲料质量安全监测工作。现将结果通报如下：

**一、**监测结果

2012年，共检查饲料生产企业、经营单位和养殖场户 12061个，抽检各类饲料样品17005批次。其中抽检商品饲料6616批次，产品合格率为95.71% ，比2011年提高0.2个百分点。

（一）主要商品饲料抽检结果。抽检配合饲料2495批次，合格率95.95% ；抽检浓缩饲料1091批次，合格率96.98% ；抽检添加剂预混合饲料738批次，合格率 88.48% 。其中，复合预混合饲料的合格率为90.10% ，微量元素预混合饲料的合格率为85.07% ，维生素预混合饲料的合格率为74.55% 。

（二）饲料添加剂和饲料原料抽检结果。抽检国产饲料添加剂584批次，合格率97.77% ；抽检进口饲料添加剂 200批次，合格率95.00% 。抽检动物源性饲料705批次，合格率95.32% ；抽检植物性饲料原料601批次，合格率99.33% 。

（三）饲料卫生指标抽检结果。在 4082批次饲料样品中检测重金属铅，超标率0.10% ；在2552批次饲料样品中检测重金属镉，超标率0.08% ；在 355批次鱼粉中检测重金属铬，超标率 1.41% ；在3941批次样品中检测沙门氏菌，超标率0.05% ；在 3391批次饲料样品中检测黄曲霉毒素 B1，超标率0.09% 。

（四）宠物饲料专项抽检结果。共抽检北京、上海、天津、重庆4个直辖市 45家宠物饲料经销单位的进口宠物饲料样品 190批次，产品合格率100% 。

（五）饲料中禁用物质抽检结果。共从生产、经营和使用环节抽检饲料样品 10389批次。检出 2批次隐性孔雀石绿，检出率为0.02% ；检出1批次赛庚啶，检出率为 0.01% ；检出 2批次三聚氰胺，检出率为0.02% ；没有检出克仑特罗、莱克多巴胺、沙丁胺醇、苏丹红、呋喃唑酮、地西泮、己烯雌酚、氯霉素、孔雀石绿等禁用物质。

（六）饲料标签检查结果。共抽查饲料产品标签8329个，合格率94.03% 。其中，抽查配合饲料和浓缩饲料标签 3542个，合格率94.35% ；抽查添加剂预混合饲料标签 859个，合格率 95.81% ；抽查国产饲料添加剂标签 547个，合格率 97.26% ；抽查进口饲料添加剂标签200个，合格率92.50% ；抽查进口宠物饲料标签190个，合格率为100% ；抽查动物源性饲料标签1078个，合格率84.69% ；抽查植物性饲料标签 560个，合格率 92.32% ；抽查精料补充料标签1341个，合格率98.28% 。

**二、**处理意见

从监测结果看，饲料产品合格率进一步提高，饲料中禁用物质检出率保持低水平，饲料质量安全状况总体上稳中有升。但是，配合饲料和浓缩饲料产品粗蛋白指标不合格、添加剂预混合饲料产品造假等问题仍较突出，非法添加禁用物质的隐患依然存在。下一步，各省（区、市）畜牧饲料管理部门要组织辖区内各级畜牧饲料管理部门继续加大饲料质量安全监管工作力度，重点做好以下工作。

（一）及时对2012年监测发现的违法企业和不合格产品查处情况进行汇总，2013年 3月 10日前将查处结果报我部畜牧业司（全国饲料工作办公室）。

（二）认真梳理辖区内饲料质量安全突出问题，切实做好 2013年饲料质量安全监测工作，着力强化检打联动和监督执法，推动进一步提高饲料质量安全水平。对 2012年抽检不合格的生产经营企业要重点监控，发现问题从严处理。

（三）进一步加强对各类获证饲料生产企业和饲料经营门店的监督检查，坚决取缔无证生产企业和管理混乱的企业，坚决查扣销毁“三无”饲料产品，严打制售假劣产品和添加禁用物质的违法行为。
