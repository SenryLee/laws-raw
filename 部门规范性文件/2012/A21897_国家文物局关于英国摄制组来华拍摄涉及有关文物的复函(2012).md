# 国家文物局关于英国摄制组来华拍摄涉及有关文物的复函(2012)

## 国家文物局关于英国摄制组来华拍摄涉及有关文物的复函（拍摄许可〔2012〕6号）

国家广播电影电视总局国际合作司：

你司关于英国KEO影片公司《中国味道之旅》摄制组来华拍摄涉及文物的函（外字[2011]169号）收悉。经研究，我局同意该摄制组于2012年2月25日至4月5日拍摄北京景山、北海及团城、故宫、慕田峪长城、天坛，广东开平碉楼、西关大屋建筑、陈家祠，浙江杭州西湖、六和塔、雷峰塔遗址、保俶塔、岳王庙、灵隐寺、净慈寺、拱宸桥，云南曼飞龙塔、沙溪兴教寺、松赞林寺，四川成都文殊院、青羊宫与二仙庵、武侯祠，新疆阿巴和加麻札（墓）、石头城遗址、艾提尕尔清真寺，福建土楼有关外景镜头。具体拍摄内容及拍摄方式等事宜请与当地文物部门协商确定。在拍摄过程中，请该摄制组严格服从文物管理人员安排，务必确保文物安全。

国家文物局　　

二〇一二年一月十二日
