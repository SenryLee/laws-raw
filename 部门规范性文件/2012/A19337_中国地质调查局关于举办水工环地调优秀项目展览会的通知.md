# 中国地质调查局关于举办水工环地调优秀项目展览会的通知

各有关单位：

为全面贯彻落实2012年全国地质调查工作会议和局地质调查工作会议精神，开展“质量年”活动，推进青年人才培养计划，营造人才成长的良好环境和氛围，拟于2012年4月6日至9日在西安举办水工环地质调查优秀项目展览暨青年学术交流会。现将有关事宜通知如下：

**一、**会议内容

（一）水工环地质调查优秀项目展览

在六大区中心和中国地质科学院地质调查项目原始资料展评活动基础上，选取20个水工环项目参加展览，促进各单位之间相互交流、学习，总结以往工作经验，查找存在问题，提出整改措施，进一步提高水工环地质调查项目的原始资料质量和成果水平。主要包括六个方面内容：地下水勘查、地下水污染调查、地质灾害详细调查、地面沉降调查和地质灾害监测预警、经济区和城市群地质调查。

每个参加展览的项目需携带以下原始资料和阶段性成果到会参展。

1.原始资料：①野外记录本、卡片或表格、工作手图、遥感用图、实际材料图等。②钻井编录、样品测试数据、动态观测数据等。③野外地质现象、监测站点、重要活动等具有典型意义的照片。④其它原始数据。

2.成果资料：①成果报告、阶段性总结、专报、各种宣传册等材料。②阶段性或最终性各类成果图件。③出版论文集、学术著作等其它资料。

（二）青年学术交流

每个局属有关单位推荐1-2名40岁以下青年业务骨干，开展青年学术交流，促进优秀青年人才的快速成长，评选优秀论文。

参加交流活动的青年业务骨干，以地调局近几年开展的水工环地质调查项目为题材，撰写相关学术论文（按《中国地质》杂志方式排版），并制作PPT进行学术交流。每人报告15分钟，答疑5分钟。成立评选委员会，评选前5名，予以表扬。

**二、**时间及地点

会议时间：4月6-9日（6日报到）

会议地点：西安市东晋桃源国际园林酒店（西安市经济技术开发区草滩生态产业园尚稷路5555号）

行车路线：由西安火车站乘坐9路、511路、703路公交车至北门站，换乘238路东晋桃园站下车即到。
