# 国家外国专家局经技司关于2012年度国家引进国外智力成果示范推广基地和国家引智示范单位年审工作的通知

各省、自治区、直辖市及副省级城市外国专家局，新疆生产建设兵团外国专家局，国务院有关部委引智归口管理部门：

根据《国家引进国外智力成果示范推广基地和国家引进国外智力示范单位管理办法》（外专发【2008】23号）（以下简称《管理办法》）的要求，现将2012年度国家引进国外智力成果示范推广基地（以下简称引智基地）和国家引进国外智力示范单位（以下简称示范单位）年审工作的有关事项通知如下：

**一、**各引智基地和示范单位（2012年新命名单位除外）均需参加今年年审，并请于11月30日前向所属引智归口管理部门报送《国家引进国外智力成果示范推广基地和国家引进国外智力示范单位年审表》，同时通过国家外国专家局“国家引进国外智力成果示范基地协作网”网站（www.yzxz.safea.gov.cn）报送电子文档。

**二、**各地方外专局和有关部委引智归口管理部门要负责组织好本地区、本部门引智基地和示范单位的年审工作，对引智基地和示范单位承担的示范推广任务完成情况及示范作用进行客观评估，并于12月20日前报送年度审查意见。未按要求进行年审或未按规定时间报送年审材料电子文档的引智基地和示范单位，将被视为年度审查不合格。

**三、**我局将在对各引智归口管理部门上报的引智基地和示范单位年审报告进行审定之后予以批复。

**四、**根据《国家引进国外智力成果示范推广基地和国家引进国外智力示范单位管理办法》有关规定，引智基地和示范单位年审事宜，请按照管理办法各项要求例行报送年审材料。凡逾期不报的单位，将被视为年审不合格。
