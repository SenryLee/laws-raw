# 交通运输部关于印发《交通运输部直属机关2012年党建工作要点》的通知

部机关和在京直属各单位党组织，中国民航局直属机关党委、国家邮政局机关党委：

现将《交通运输部直属机关2012年党建工作要点》印发给你们，请结合实际认真抓好落实。

二○一二年一月十六日

交通运输部直属机关2012年党建工作要点

交通运输部直属机关2012年党建工作的总体要求是：紧紧围绕“把握稳中求进总基调、努力推进交通运输科学发展安全发展”这条主线，以改革创新精神和求真务实作风切实抓好党的各项建设，不断提高机关党的建设科学化水平，努力走在行业基层组织建设的前头，走在中央国家机关的前列，为交通运输安全发展、稳定发展、协调发展、高效发展、创新发展、开放发展提供有力保证。

**一、**做好迎接十八大召开和学习贯彻十八大精神工作

（一）做好直属机关出席党的十八大代表选举提名推荐工作。要按照工委和党组的部署，结合直属机关实际，根据代表条件、构成和名额要求，突出先进性和代表性，严格遵循规定程序，充分发扬党内民主，切实加强组织领导，圆满完成部直属机关出席党的十八大代表选举提名推荐和中央国家机关党代表会议代表推选工作。

（二）营造喜迎十八大召开浓厚氛围。通过报刊、网站和专题展览，宣传十七大以来交通运输发展取得的新成就，宣传机关党的建设取得的新进展，宣传各级党组织和党员中的先进典型，展示各级党组织、广大党员践行立党为公、执政为民的生动实践，营造团结奋进的氛围。

（三）深入学习宣传贯彻十八大精神。开展“我和十八大代表谈体会”活动，邀请十八大代表走进机关，并通过中心组学习、辅导讲座、专题培训等形式，迅速兴起学习宣传贯彻十八大精神的热潮，切实把思想和行动统一到中央的部署要求上来。

**二、**务实推进学习型党组织建设

（四）加强形势政策宣传教育。深化中国特色社会主义理论体系武装工作，注重联系实际，不断提高党员干部思想理论素养，引导党员干部带头践行社会主义核心价值体系，筑牢共同的思想基础；抓好业务知识和技能学习，不断提高落实稳中求进、推进现代交通运输业的能力和水平。

（五）创新学习方式方法。通过党校教育、专题培训、交通大课堂、读书活动、青年讲坛等方式，全方位、多角度开展学习活动。鼓励党员干部深入实际、深入基层，针对交通运输发展面临的深层次矛盾和新情况新问题，特别是建设资金筹集、交通运输结构调整、区域城乡交通运输平衡发展、均等化与个性化服务、安全生产等突出问题，通过调查研究、实践锻炼等方式，提高破解难题、推动发展的能力。

（六）注重学习制度落实。落实党委（党组）中心组学习制度，发挥中心组学习的示范带头作用；认真落实党支部“三会一课”制度，推动完善党组织集体学习和党员干部个人学习相结合的学习制度，形成浓厚的学习氛围，提升队伍整体素质。

**三、**切实加强基层党组织建设

（七）深化创先争优活动。针对交通运输是窗口单位和服务行业的特点，深入开展为民服务创先争优活动，评选为民服务品牌，做好群众评议工作，切实使创先争优活动成为群众满意工程。抓好典型培树，按照中央统一部署，在“七一”前后开展创先争优专项表彰工作，加大宣传力度，发挥先进典型的示范引领作用。

（八）积极推进党内民主。坚持以保障党员民主权利为根本，进一步完善党内情况通报、党内选举、党内民主决策、党内民主监督等制度，推进党代表常任制；进一步提高党员领导干部民主生活会质量，落实民主集中制，提高决策科学化水平；进一步推进党务公开，逐步规范公开内容、公开程序和公开形式，切实保障广大党员的知情权、参与权、选举权、监督权。

（九）分类推进基层党组织建设。坚持从实际出发，因地制宜，分类指导，充分发挥机关和直属单位党组织的职能。及时指导任期届满的基层党组织按期完成换届选举工作。以开展“规范管理年”活动为抓手，进一步提升社团党建工作水平；加强和改进离退休干部职工党建工作。

（十）抓好党员队伍建设。做好党员教育、管理和服务工作，组织党员和入党积极分子培训，做好发展党员工作，优化党员结构；进一步完善党内激励、关怀、帮扶机制，加强人文关怀和心理疏导，帮助党员解决实际困难。

**四、**坚持不懈抓好作风和反腐倡廉建设

（十一）深化“学基层、学业务”联学活动。认真总结三年来开展活动的经验，巩固活动成果，建立长效机制，深化活动主题，组织党员干部走出机关，深入一线，立足司局和处室职责实际，立足岗位实际，从规划引导、政策完善、制度创新、措施改进等层面，解决基层和群众反映强烈的交通运输突出问题，切实增强服务基层、服务群众的本领。

（十二）深化机关文明创建。以“建设文明机关，争做人民满意公务员”和“学树建创”活动为载体，以评选机关文明处室为抓手，加强机关文明建设，增强机关党员干部公仆意识，引导党员干部更加注重履行社会管理和公共服务职能，不断提高机关工作效能，建设服务型政府部门。

（十三）落实反腐倡廉各项工作。加强对胡锦涛总书记在十七届中央纪委七次全会上的重要讲话精神的学习贯彻，增强对保持党的纯洁性的极端重要性和紧迫性的认识。按照“标本兼治、综合治理、惩防并举、注重预防”的方针，建立健全惩治和预防腐败体系。加强反腐倡廉教育和廉政文化建设，开展党性党风党纪教育和从政道德教育，促进党员领导干部廉洁自律。落实党风廉政建设责任制，重点推进廉政风险防控机制建设，加强对权力运行的监督检查，努力从源头上预防腐败。积极配合有关部门开展重点领域专项治理工作，做好信访和案件审理工作，发挥查办案件的惩戒和治本功能。加强纪检组织建设和纪检干部队伍建设。

**五、**着力推进和谐机关建设

（十四）增强思想政治工作和群众工作的针对性实效性。关心干部职工生活，继续开展送温暖和走访慰问活动，帮助解决实际问题；关注干部职工身心健康，举办健康知识讲座和心理健康辅导、单身职工联谊会；做好政治稳定排查工作，引导群众合理合法表达利益诉求。

（十五）丰富职工文化生活。组织观看具有思想性艺术性观赏性、职工喜闻乐见的文艺节目和影视作品，打造一批反映交通特色、具有时代特征的文学、影视、书画、摄影艺术作品和群众文艺产品，展示机关和在京单位文化建设成果。

（十六）充分发挥群团组织的桥梁纽带作用。开展岗位建功、青年创业、巾帼建功、技能比武等活动，动员和组织干部职工群众在实施交通运输“十二五”发展规划中建功立业。广泛开展群众性文化体育活动，举办直属机关第一届职工运动会，组建直属机关职工艺术团，做到年有计划、季有比赛，月有活动。从战略高度重视做好青年的教育、引导和培养工作，开展青年访谈、辩论赛等活动，激发青年投身事业的激情，组织青年参加实践锻炼活动，引导青年更加关注民生、更多参与公益事业，促进青年成长成才。

（十七）重视做好统战工作。支持各民主党派和侨联等组织开展活动，创造条件、搭建平台，进一步改进统战对象参政议政的渠道和方式。

**六、**推动机关党建工作创新

（十八）完善工作机制。进一步健全党组（党委）负总责、党组（党委）书记带头抓、分管领导具体抓、行政负责人“一岗双责”、职能部门综合协调、相关部门齐抓共管，一级抓一级、层层抓落实的党建工作机制，确保党的建设各项任务落到实处。

（十九）加强党务干部队伍建设。配齐配强基层党组织负责人，进一步优化党务干部队伍结构。通过学习交流、集中培训、实践锻炼等方式，进一步提高基层党组织负责人和工作骨干的政治素质和业务能力。关心党务干部成长进步，探索干部交流方式，畅通党务干部“进出口”通道，保持党务干部队伍活力。

（二十）推进党建工作理论创新。注重把握机关党建的科学规律和特点，围绕破解机关党建重点难点问题，加强调查研究，从实践中总结经验，探索机关党建的的理念载体和方法创新，形成规律性认识，更好地指导实践、推动工作，增强机关党建工作的针对性实效性和吸引力感染力。
