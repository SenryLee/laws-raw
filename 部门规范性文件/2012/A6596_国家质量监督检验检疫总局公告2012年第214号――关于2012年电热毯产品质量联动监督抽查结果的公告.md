# 国家质量监督检验检疫总局公告2012年第214号――关于2012年电热毯产品质量联动监督抽查结果的公告

## 国家质量监督检验检疫总局公告（2012年第214号）

关于2012年电热毯产品质量联动监督抽查结果的公告

为加强产品质量监督，维护消费者的合法权益，根据《中华人民共和国产品质量法》和《产品质量监督抽查管理办法》等法律法规，2012年8月至12月，质检总局组织有关地方质量技术监督局开展了电热毯产品质量联动监督抽查。现将结果予以公布。

本次联动抽查依据GB 4706.1-2005 《家用和类似用途电器的安全第1部分：通用要求》、GB 4706.8-2008 《家用和类似用途电器的安全电热毯、电热垫及类似柔性发热器具的特殊要求》等强制性国家标准的要求，对对触及带电部件的防护、输入功率和电流、耐潮湿、泄漏电流和电气强度、非正常工作、机械强度、结构、电源连接和外部软线项目进行了检测。

本次抽查采取流通领域和生产领域抽样相结合的方式进行，共涉及155家生产企业的173批次产品，合格124批次，不合格49批次，产品抽样合格率为71.7％。

本次抽查发现电热毯产品涉及的主要质量问题为输入功率和电流项目有16批次不合格，耐潮湿项目有1批次不合格，泄漏电流和电气强度项目有20批次不合格，非正常工作项目（只进行5层折叠试验）有12批次不合格，机械强度项目（只进行发热元件弯曲试验）有42批次不合格，结构项目有17批次不合格，电源连接和外部软线项目有24批次不合格。

质检总局已通知有关省（自治区、直辖市）质量技术监督部门按照有关法律法规的规定，对本次电热毯产品质量联动监督抽查不合格的产品及其生产企业责令限期整改，并依法进行处理。
