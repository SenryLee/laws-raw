# 教育部基础教育一司关于调整2012年《开学第一课》播出时间的通知

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

我部与中央电视台联合制作的2012年《开学第一课》即将播出，为了做好相关工作，我部近日已经印发《教育部办公厅关于中小学上好开学第一课的通知》（教基一厅函﹝2012﹞40号），请各地按要求及时通知到中小学校，组织学生观看。为便于广大中小学生和家长收看，现将节目播出时间调整如下：

2012年《开学第一课》于9月2日20：00至21：30在中央电视台第一套节目（CCTV-1）首播，9月3日9：00至10：30在中央电视台第一套节目（CCTV-1）再次播出。

教育部基础教育一司　

二〇一二年八月二十七日
