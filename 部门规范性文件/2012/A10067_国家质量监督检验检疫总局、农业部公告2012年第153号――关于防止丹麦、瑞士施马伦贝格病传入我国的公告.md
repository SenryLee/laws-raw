# 国家质量监督检验检疫总局、农业部公告2012年第153号――关于防止丹麦、瑞士施马伦贝格病传入我国的公告

## 国家质量监督检验检疫总局、农业部公告

（2012年第153号）

关于防止丹麦、瑞士施马伦贝格病传入我国的公告

2012年5月30日，丹麦检测发现2头牛呈施马伦贝格病毒（Schmallenberg Virus）抗体阳性。2012年7月20日，在瑞士泊尔尼地区的两家农场有母牛出现发热性腹泻，经检测证实感染了施马伦贝格病毒。

为防止施马伦贝格病疫情传入我国，保护我国畜牧业生产安全，根据质检总局与农业部2012年第67号联合公告的规定，将丹麦、瑞士列入施马伦贝格病名录，对丹麦、瑞士采取2012年第67号联合公告规定的检疫监管措施。

本公告自发布之日起施行

国家质量监督检验检疫总局

农业部　　

2012年10月12日
