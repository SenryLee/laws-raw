# 国家文物局关于阿根廷摄制组来华拍摄涉及有关文物的复函(2012)

## 国家文物局关于阿根廷摄制组来华拍摄涉及有关文物的复函（拍摄许可〔2012〕30号）

西班牙拉克罗盖制作公司：

你公司关于阿根廷电视台“美食家”栏目摄制组来华拍摄专题片涉及文物的函收悉。经研究，我局同意该摄制组于2012年5月5日至5月20日期间拍摄北京慕田峪长城、故宫、天安门、天坛、颐和园、十三陵，山西悬空寺、云冈石窟、佛宫寺释迦塔（应县木塔）、华严寺、恒山建筑群（北岳庙），陕西秦始皇兵马俑（坑上拍摄）、大雁塔、西安城墙有关镜头。具体拍摄内容及拍摄方式等事宜请与当地文物部门协商确定。在拍摄过程中，请该摄制组严格服从文物管理人员安排，务必确保文物安全。

国家文物局　　

二〇一二年四月十六日
