# 中国科学院关于举办财务人员培训班暨2012年度企业财务会计决算布置会的通知

## 中国科学院关于举办财务人员培训班暨2012年度企业财务会计决算布置会的通知（科资函字〔2012〕70号）

国科控股各持股公司、院属各单位：

根据国科控股财会人员培训5年规划，为加强各单位内控建设、依法纳税及合规经营的意识，决定举办企业内部控制及风险管理、营业税改增值税的培训班暨2012年度企业财务会计决算布置工作会。具体事项通知如下：

**一、**时间、地点

（一）时间：2012年12月12日～13日。12月11日报到，12月14日撤离。

（二）地点：重庆洪崖洞大酒店（重庆市渝中区沧白路56号）。酒店联系人：翁妍婕，联系电话：023-63992818。

**二、**培训内容

（一）企业内部控制与风险管理。

（二）营业税改增值税。

（三）布置2012年度企业财务会计决算。

**三、**主办单位：国科控股

承办单位：重庆绿色智能技术研究院

**四、**参会人员

（一）企业内部控制与风险管理、营改增税法培训

1、国科控股各持股企业的财会人员。

2、院属各单位的财会人员。

（二）2012年度企业财务会计决算布置

1、国科控股各控股企业财务部门负责人（或负责财务会计决算人员）1人。

2、各分院、合肥物质院负责企业财务会计决算1人。

**五、**其他

（一）请各单位务必于11月25日前（受酒店客房限制，过期不再受理）将参加人员名单报国科控股财务与稽核部孙晓军同志，电子邮箱：xjsun@cashq.ac.cn，联系电话：010­­-82525266，同时发送至重庆绿色智能技术研究院段国华同志，电子邮箱：duanguohua@cigit.ac.cn，联系电话：023-63063629。

（二）乘车路线

1、火车：乘出租车约9公里17元左右即到洪崖洞大酒店。

2、飞机：乘机场大巴到上清寺下车，再乘出租车约12元即到洪崖洞大酒店或在上清寺车站对面的“牛角沱公交枢纽站”乘坐322路到解放碑的临江门下，沿临江路步行5分钟左右即到洪崖洞大酒店。

机场乘出租车约60元即到洪崖洞大酒店。

（三）参会人员自报到日至离会日每人每天交150元住宿费（共三天）。

附件：会议回执
