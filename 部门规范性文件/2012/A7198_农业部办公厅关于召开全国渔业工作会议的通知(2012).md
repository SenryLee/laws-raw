# 农业部办公厅关于召开全国渔业工作会议的通知(2012)

## 农业部办公厅关于召开全国渔业工作会议的通知（农办渔〔2012〕158号）

根据我部统一安排，定于2012年12月下旬在北京召开全国渔业工作会议。现将有关事项通知如下：

**一、**会议内容

深入贯彻落实党的十八大、中央经济工作会议、中央农村工作会议和全国农业工作会议精神，回顾总结2012年渔业工作，部署安排2013年渔业重点工作。

**二、**会议时间和地点

会议时间：2012年12月23日（星期日）下午，会期半天。12月22日下午或23日上午报到。会议地点：京瑞大厦（北京市朝阳区东三环南路17号）。

**三、**参加人员

（一）沿海各省、自治区、直辖市及计划单列市渔业主管厅（局），各海区渔政局主要负责同志及相关处处长1人；内陆各省、自治区、直辖市和新疆生产建设兵团渔业主管厅（局）分管领导和渔业（水产）局（办、处）主要负责同志。中国水产科学研究院所属各所所长，院士，水产院校校长。

（二）渔业局、渔政指挥中心领导，在京直属渔业事业（社团）单位主要负责同志。

代表名额分配见附件1。

**四、**有关要求

（一）请各单位严格按代表名额派员参会，切勿超员。

（二）请各单位合理安排工作，保证主要负责同志按时参加会议，主要负责同志因故不能参加会议的，请在回执上说明原因。

（三）报到时间内在首都机场安排接站；宾馆提供订票服务，请会议代表尽量自行订返程车（机）票。
