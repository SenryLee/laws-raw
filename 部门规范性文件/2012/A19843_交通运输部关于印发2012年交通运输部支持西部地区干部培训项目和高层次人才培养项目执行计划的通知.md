# 交通运输部关于印发2012年交通运输部支持西部地区干部培训项目和高层次人才培养项目执行计划的通知

## 交通运输部关于印发2012年交通运输部支持西部地区干部培训项目和高层次人才培养项目执行计划的通知（交科技发〔2012〕85号）

西部地区各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），山西、吉林、黑龙江、安徽、江西、河南、湖北、湖南、海南省交通运输厅，西部地区干部培训工作承担单位：

为贯彻落实国家西部大开发战略，根据西部地区交通运输发展实际和干部培训工作需要，我部制定了《2012年交通运输部支持西部地区干部培训项目执行计划》和《2012年交通运输部支持西部地区高层次人才培养项目执行计划》，现印发给你们，请认真组织实施。

有关省级交通运输主管部门和西部地区干部培训承担单位要严格执行部《交通运输行业干部教育培训工作管理办法（试行）》（交科技发〔2012〕14号）和《交通运输部支持西部地区干部培训项目管理办法》（交科教发〔2003〕572号）。交通运输主管部门应将此执行计划纳入各自的干部教育培训年度计划，并认真做好学员的选派工作。培训承担单位要认真执行培训计划，做好培训内容设计、教材选择和教师安排等培训前期准备工作，加强对培训班的组织管理，切实提高培训质量，确保培训安全进行。
