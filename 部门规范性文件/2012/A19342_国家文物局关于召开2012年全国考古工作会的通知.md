# 国家文物局关于召开2012年全国考古工作会的通知

## 国家文物局关于召开2012年全国考古工作会的通知（办保函〔2012〕134号）

各省、自治区、直辖市文物局（文化厅）：

为进一步做好“十二五”时期的考古和大遗址保护工作，根据我局重点工作安排，拟定于今年4月召开2012年全国考古工作会。现将有关事项通知如下：

**一、**会议时间

2012年4月6日～7日，会期2天，4月5日报到，4月8日上午疏散。

**二、**会议地点

浙江省杭州市星都宾馆（杭州市文晖路448号）

**三、**与会人员

（一）各省、自治区、直辖市文物行政部门主管考古工作的负责同志1人

（二）具有考古发掘资质的单位负责人1人

（三）2009-2010年度国家文物局田野考古奖项目领队

（四）特邀专家、学者

（五）中国文物报社、文物出版社及其他新闻媒体

**四、**会议材料

请你局尽快组织所属行政区域内考古发掘资质单位认真总结近两年的考古工作及管理经验，并将有关文字、图片材料按规定格式制作成WORD文档（格式见附件），于3月23 日前发送至我局考古处电子邮箱。

请你局于3月23日前，将与会代表的单位、姓名、性别、民族、职务（职称）等内容告知浙江省文物局。请参会人员于4月1日前，将往返航班和车次信息告知浙江省文物局。会议不接待额外人员。
