# 商务部关于加强现代服务业综合试点项目进展情况报送和信息情况报送的通知

北京、天津、上海、重庆、辽宁、湖南、深圳商务主管部门：

为落实现代服务业综合试点工作会议精神，加强对试点工作进展情况的跟踪指导，加大对试点成效的宣传力度，我们建立了综合试点项目进展定期报送制度和信息报送制度。（其中，项目进展情况为按季度报送，信息和宣传材料为按月报送。）现将有关事项通知如下：

**一、**每季度第一个月15日前将现代服务业综合试点项目安排情况季度统计表、进展情况季度统计表（附件1、2）电子版报送我们（不需盖章）。初次报送时点为2013年1月15日。

**二、**每季度定期报送文字材料。包括：

1.试点工作本季度进展。包括体制机制建设情况、配套文件起草、配套政策进展和资金拨付情况等；

2.试点项目本季度进展情况概况；

3.工作取得的成效，包括相关领导批示等情况

；

**三、**每月15日前，请填报现代服务业综合试点信息报送及采用情况通报表（附件3），并随时报送相关宣传材料。如当地媒体对试点工作已有报道发表，也请报送我们。

我们将对各地项目进展情况、信息报送和采用情况进行汇总并排名，每月将相关情况反馈你们，并在商务部流通发展司网站公布，重要信息将并报部领导及国务院。请你们高度重视，认真报送表格及文字材料。
