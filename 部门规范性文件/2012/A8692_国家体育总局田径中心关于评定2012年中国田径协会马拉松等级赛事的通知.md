# 国家体育总局田径中心关于评定2012年中国田径协会马拉松等级赛事的通知

各马拉松赛事组委会：

2012 年共有30 个城市举办了31 场马拉松赛事。为进一步加强对中国境内举办的马拉松赛事的管理，使马拉松运动不断规范化，提升赛事品质，更好地促进中国马拉松运动健康、有序的开展，中国田径协会将对各城市举办的各类马拉松赛事不再进行最佳赛事和优秀赛事的评定，统一进行金、银、铜牌等级赛事的评定。在2012 年中国田径协会马拉松年会上将对符合标准并按要求申报的马拉松赛事授予等级赛事的标志，组委会可在2013 年度马拉松赛事宣传、推广时使用中国田径协会金、银、铜牌赛事等级标志和称号。

请各赛事组委会根据《中国田径协会马拉松赛事等级评定办法》（附件1）中的标准，申报符合相应等级赛事的级别，并填写《2012 年中国田径协会等级赛事申报表》（附件2），加盖公章后于2012 年12 月20 日前报到中国田径协会，并将电子版发至以下指定电子邮箱。

中国田径协会马拉松赛事等级评定办法

（试行）

**一、**总则

为进一步加强在中国境内举办的马拉松赛事的管理，使马拉松运动不断规范化，提升赛事品质，更好地促进中国马拉松运动健康、有序的开展，中国田径协会（以下简称：中国田协）将对各城市举办的各类马拉松赛事进行等级标准的评定，在每年的中国田协马拉松年会上对符合标准并按要求申报的马拉松赛事授予等级赛事的标志，各有关组委会可在下一年度马拉松赛事宣传、推广时使用相应的中国田协金、银、铜牌赛事标志和称号。

**二、**赛区组委会申报中国田协金、银、铜牌赛事的，须遵守中国田径协会有关马拉松赛事的各项要求和规定，并严格履行与中国田径协会签署的办赛协议，否则将不允许申报。

**三、**每场马拉松赛事以金牌、银牌、铜牌三个标准进行等级评定。

（一）金牌赛事标准

1、赛事组委会须按照中国田协《马拉松赛事管理规定》《全国马拉松赛事组织管理实施细则》和国际田联最新的竞赛规则组织赛事。

2、赛事路线须提交由国际田联/国际公路跑协会“B”级丈量员的丈量报告及国际管理员的批准证书。

3、整个赛道要进行分段分时交通管制，直到最后一名运动员完成比赛或到关门时间。

4、比赛时，须有中国田协观察员或其他有资格的人员乘坐前导车观察，以确保运动员所跑的路线为丈量路线。

5、须使用中国田协认证的感应计时公司，要有每5公里的分段计时，计时点分别为：5公里、10公里、15公里、20公里、半程、25公里、30公里、35公里、40公里和终点；半程马拉松的分段计时点为5公里、10公里、15公里、20公里和终点。

6、比赛应有完整的数据传输服务，及时提供运动员的分段计时和最终成绩给媒体、观众和网络。

7、根据中国田协相关规定，赛事报名截止后按照规定格式向中国田协上报规定的运动员报名数据。经中国田协审核后方可接受运动员报名。

8、男、女马拉松、半程马拉松前20名比赛成绩须在比赛结束后24小时之内通过电子邮件向中国田径协会提交（Excel、CSV等类似格式）。jingsaibu@athletics.org.cn。

9、所有选手比赛成绩须在最短的时间内通过组委会网站或中国田协网站提供给参赛选手。

10、要有专门的体育展示团队负责赛事展示。并在起点或终点提供视频大屏。

11、国外特邀选手须达到男、女各5名运动员。国外特邀运动员资格如下：

--国际田联世锦赛、世界半程马拉松锦标赛或奥运会马拉松比赛中取得前50名者；--比赛前24个月，男子马拉松成绩在2：10：30分、女子成绩在2：30分以内者；半程马拉松男子在62分以内、女子在70分以内者；（上述运动员的成绩信息可在国际田联官方网站查询）。

12、在年度全国排名男、女前20名的运动员各5名。

13、参赛选手规模须在3万人以上（含所有项目）。同时，参加马拉松项目的人数5000人以上。

14、赛事兴奋剂检查最少为12例EPO检测（男6，女6）样本；单性别比赛则为6例。所收样本必须在世界反兴奋剂机构认定的北京实验室进行检测。

15、组委会对文字、摄影媒体的服务需满足以下条件：

|  |  |
| --- | --- |
| 媒体中心 | 评论员信息系统（CIS系统）＋/或电视＋在指定限定区域的宽带 |
| 成绩服务 | 男、女前20名的纸质成绩的分发 |
| 网　　络 | 在指定网站上用本国语言及英语公布参赛名单和即时成绩，也可使用更多语言 |
| 新闻发布会 | 赛前赛后至少3次 |

16、赛事须在全国范围内进行全程电视直播。

以上全部15条中除11-13条可任选其中2项外，其他的条款是评定的必备条件。

（二）银牌赛事标准

1、赛事组委会须按照中国田协“马拉松赛事管理规定”、“全国马拉松赛事组织管理实施细则”和国际田联最新的竞赛规则组织赛事。

2、赛事路线须提交由国际田联/国际公路跑协会“C”级丈量员的丈量报告及国际管理员的批准证书。

3、整个赛道要进行分段分时交通管制，直到最后一名运动员完成比赛或到关门时间。

4、比赛时，须有中国田协观察员或其他有资格的人员乘坐前导车观察，以确保运动员所跑路线为丈量路线。

5、赛事可按照“全国马拉松赛事组织管理细则”的相关规定进行分段计时。

6、比赛应有完整的数据传输服务，及时提供运动员的分段计时和最终成绩给媒体、观众和网络。

7、根据中国田协相关规定，赛事报名截止后按照规定格式向中国田径协会上报规定的运动员报名数据。经中国田径协会审核后方可接受运动员报名。

8、男、女马拉松、半程马拉松前20名比赛成绩须在比赛结束后24小时之内通过电子邮件向中国田径协会提交（Excel、CSV等类似格式）。jingsaibu@athletics.org.cn。

9、所有选手比赛成绩须在最短的时间内通过组委会网站或中国田径协会网站提供给参赛选手。

10、要有专门的体育展示团队负责赛事展示。组委会须提供视频大屏，如实有困难，也应在特定的区域内为媒体提供电视转播实况。

11、国外特邀选手须达到男、女各5名运动员。国外特邀运动员资格如下：

--国际田联世锦赛、世界半程马拉松锦标赛或奥运会马拉松比赛中取得前60名者；

--比赛前24个月，男子马拉松成绩在2：12分、女子成绩在2：32分以内者；半程马拉松男子在63分、女子在72分以内者；（上述运动员的成绩信息可在国际田联官方网站查询）。

12、在年度全国排名男、女前30名的运动员各5名。

13、参赛选手规模须在2万人以上（含所有项目）。同时，参加马拉松项目的人数2500人以上。

14、赛事兴奋剂检查最少为6例EPO检测（男3，女3）样本；单性别比赛为3例。所收样本必须在世界反兴奋剂机构认定的北京实验室进行检测。

15、组委会对文字、摄影媒体的服务需满足以下条件：

|  |  |
| --- | --- |
| 媒体中心 | 电视＋在指定限定区域的网络 |
| 成绩服务 | 男、女前20名的纸质成绩的分发 |
| 网络 | 在指定网站上用本国语言及英语公布参赛名单和即时成绩 |
| 新闻发布会 | 赛前1次，赛后1次 |

16、赛事能够在全国卫星频道进行全程转播。

以上全部15条中除11-13条可任选其中1项外，其他的条款是评定的必备条件。
