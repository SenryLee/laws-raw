# 工业和信息化部通告第28号－－关于厦门顶尖电子有限公司等3家税控收款机产品生产企业资质证书期满换证的通告

## 工业和信息化部通告（第28号）

关于厦门顶尖电子有限公司等3家税控收款机产品生产企业资质证书期满换证的通告

各省、自治区、直辖市及计划单列市、新疆生产建设兵团工业和信息化部主管部门：

依据《税控收款机生产企业资质管理办法》，我部对税控收款机产品生产企业资质证书三年有效期届满申请换证的厦门顶尖电子有限公司、深圳市奥格立电子科技有限公司、青岛海信智能商用系统有限公司进行了审查，认定上述企业符合税控收款机产品生产企业资质要求，予以换发证书。现予公布。

附件：予以换发税控收款机产品生产资质证书的企业名单
