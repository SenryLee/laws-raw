# 农业部农业机械试验鉴定总站关于召开2012年农业机械安全鉴定和推广鉴定工作研讨会的通知

## 农业部农业机械试验鉴定总站关于召开2012年农业机械安全鉴定和推广鉴定工作研讨会的通知（农机鉴[2012]34号）

各有关单位：

为贯彻落实《农业机械安全监督管理条例》和《农业机械推广鉴定实施办法》的要求，部署2012年农业机械部级推广鉴定工作，提高农业机械部级推广鉴定项目管理工作规范性和一致性，农业部农业机械试验鉴定总站（以下简称“总站”）定于2012年3月下旬在四川成都召开“2012年农业机械安全鉴定和推广鉴定工作研讨会”。现将有关事项通知如下：

**一、**会议时间地点

时间：2012年3月26日至27日开会，3月25日下午报到；

地点：四川花园宾馆（地址：四川省成都市锦江区走马街47号）。

**二、**参会人员范围

拟邀请农业部农机化管理司科教处、安全监理处领导；农业部农机试验鉴定总站领导及有关部门人员；通过部级鉴定能力认定的各省站、专业站授权签字人及项目管理人员（各1人）。

**三、**会议内容

（一）介绍农业机械安全鉴定工作要求；

（二）介绍2012年农业机械部级推广鉴定实施相关要求（报告编制、项目管理、信息变更、项目收费等）；

（三）宣贯《农业机械部级推广鉴定实施细则》（农机鉴[2012]21号）；

（四）介绍农机推广鉴定监管系统软件的功能。

**四、**其他事项

（一）会务工作由北京燕泰会议服务有限公司承担。住宿统一安排，费用自理，会议不安排接站。

会议乘车路线：A、在成都市火车北站乘55路（2元）车在西南书城站下车步行200米至宾馆；若直接乘出租车至宾馆约20元；B、在机场乘坐机场民航大巴（10元）到终点站下车，再换乘出租车（约10元）到宾馆；若直接乘出租车至宾馆约80元。
