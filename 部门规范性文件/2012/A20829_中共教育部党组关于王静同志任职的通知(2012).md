# 中共教育部党组关于王静同志任职的通知(2012)

## 中共教育部党组关于王静同志任职的通知（教党任[2012]2号）

中共上海外国语大学委员会：

经研究并与中共上海市委商得一致，决定任命王静同志为中共上海外国语大学纪律检查委员会委员、书记。

中国共产党教育部党组

二○一二年二月十日
