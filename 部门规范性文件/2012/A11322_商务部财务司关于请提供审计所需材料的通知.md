# 商务部财务司关于请提供审计所需材料的通知

各特派员办事处、本部各直属事业单位：

审计署贸易审计局因工作需要，现对我部各特派员办事处、所属事业单位有关情况进行摸底调查，需填列有关表格和承诺书，其中各特派员办事处需填写的表格和承诺书见附件1，各直属事业单位需填写的表格与承诺书见附件2。
