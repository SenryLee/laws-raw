**二、**课题的目标、主要研究内容及预期研究成果

|  |
| --- |
| 课题研究的目标和意义： 　　本研究目的是针对馆藏文物保护修复管理现状和特点，按照经费预算管理的实际需求，结合《分类推进事业单位工资改革实施指导意见》的相关精神，开展馆藏文物保护修复工作量清单计价研究，形成《馆藏文物保护修复工作量清单计价规范》，为馆藏文物保护修复项目预算编制提供计价规范和程序，提高项目预算管理的规范化、科学化水平，进一步提高经费使用效率。 　　本研究的意义主要体现在以下几个方面： 　　第一，全面了解我国文物保护修复经费管理现状，为进一步提高文物保护修复预算编制水平，强化经费管理提供合理化政策建议。 　　第二，对文物保护修复经费管理进行深入研究，制订《馆藏文物保护修复工作量清单计价规范》，为规范文物保护修复经费预算管理提供政策工具。长期以来，馆藏物珍贵文物保护在国家预算中只是重点文物保护项目的子项目，没有单独立项，文物保护修复经费管理相对滞后，影响财政经费投入和使用效率。本研究项目的开展，将有效改变这一现状，提高文物保护修复经费管理水平，进而促进文物保护修复管理工作水平。 　　第二，促进文物保护修复经费投入，推动馆藏文物整体保护水平。按照目前现有经费投入水平，文物保护修复经费只能保证每年约3000件左右珍贵文物得到保护修复，而据估算，每年由于环境等因素造成的新损毁文物就近1.2万件，显然文物保护修复投入经费严重不足，保护修复经费需求与实际投入差距巨大，造成大量文物由于经费短缺而无法开展保护修复工作。《馆藏文物保护修复工作量清单计价规范》，将为馆藏文物保护修复项目预算编制提供计价规范和程序，极大地提高经费管理水平，促进国家对文物保护修复经费的投入。 |

|  |
| --- |
| 主要研究内容、拟解决的主要问题和难点分析： 　　主要研究内容： 　　1、文物保护修复管理现状调研：开展文物保护修复管理调研，重点了解文物保护修复经费管理现状，重点是文物修复经费预算管理和会计核算管理。根据实际需要，拟选择陕西、湖北、浙江、上海、北京等地的博物馆、文物保护修复中心、国家文物保护重点科研基地、考古研究院所等不同类型的文物保护修复机构进行重点调研。 　　2、文物保护修复工作计价方法研究：文物保护修复工作具有修复对象非标准性、操作者差异性、评价标准差异性等特点，传统的定额管理和现行的工程量清单计价管理均难以适应文物保护修复工作计价，因此必须另辟蹊径，建立适应文物保护修复工作特点的计价方法--分类分级计价法。即以文物保护修复工作流程为横坐标，从一般工作流程入手，细化工作内容，规范操作流程，确定单一工作内容的市场定价方法。同时，以文物分类分级管理为基础，以文物分级作为纵坐标，从文物分级管理要求确定不同级次的系数。 　　3、文物保护修复工作流程规范：分析研究不同文物保护修复的工作流程和工艺方法，归纳总结文物保护修复的一般性流程。首先，根据文物材质将文物进行分类，按照材质分类为：金属、石质、漆木器、陶瓷器、纺织品、纸张书画、壁画七类；其次，归纳总结文物修复的一般流程：健康评测、修复方案制定、文物本体修复、修复保护效果检测、建立修复档案：包括编写修复报告、建立修复档案；再则，对文物本体修复流程进行细化，在细化的基础上，明确主要工艺流程、使用设备、工具、主要材料等内容。 　　4、文物保护修复会计科目设置：文物保护修复工作属于公益性基本公益服务，不能或不宜由市场配置资源，因此在文物保护修复会计科目设置上，应更多地借鉴科研项目科目设置方法。 　　5、文物保护修复经费预算内控方法：由于流程分段和科目设置研究的局限，可采用历史数据确定。按照修复流程的分段比例控制和分科目的比例控制法。 　　本研究拟解决的关键问题是研究确定文物保护修复计价管理方法。目前国内外尚无规范的文物保护修复计价方法，国内已有的定额管理和工程量清单计价方法均不适合文物保护修复计价，因此从文物保护修复管理工作实际出发，建立文物保护修复工作计价方法是本研究的关键问题，合理的计价方法是规范计价工作的基础。 　　本研究的难点是分类分级计价法的纵横坐标数值的确定。横坐标数值是修复流程的分段费用构成，纵坐标是分级管理的不同级次文物费用系数。从现有的文物保护修复管理理论来看，很难从理论上推算其数值，只能从实践中测算经验数据，但现行会计核算制度很难取得这些数据。 |

| 课题研究的主要创新点： 　　根据课题查新显示，《馆藏文物保护修复工作量清单计价规范》的研究在国内外尚属首次，该研究的创新点主要表现在以下几个方面： 　　1、本研究从实际出发，将强化文物保护修复预算管理与事业单位改革进行有机结合。按照国务院2011年3月发布的《分类推进事业单位工资改革实施指导意见》精神，以后公益类事业单位的工资将由岗位工资和绩效工资两部分组成。因此，《馆藏文物保护修复工作量清单计价规范》要考虑项目支出中的绩效工资内容，将提高预算管理与调动职工积极性统筹考虑，使本研究具有前瞻性。 　　2、创新性建立文物保护修复工作量清单计价方法--分类分级计价法：首先，按照材质将文物分类为：金属、石质、漆木器、陶瓷器、纺织品、纸张书画、壁画七类；其次，按照文物价值分类，文物藏品分为珍贵文物和一般文物，珍贵文物分为一、二、三级；第三，在文物分类分级的基础上，以文物保护修复工作流程为横坐标，从一般工作流程入手，细化工作内容，规范操作流程，确定单一工作内容的市场定价方法。以文物分级作为纵坐标，从文物分级管理要求确定不同级次的系数。依据现有分级管理规定，以一般文物作为文物保护修复计价的基础，不同级次间按比例浮动，实行系数管理。 　　3、创新性设立文物本体保护修复工作量清单编制方法。根据文物保护修复对象、过程、评价的非标准化特点，以主要工艺或方法、主要设备、主要工具、主要材料为属性进行分解，作为明晰工作量的主要指标，便于实际操作。 　　4、创新设立文物保护修复会计科目，文物保护修复工作属于公益性基本公益服务，不能或不宜由市场配置资源，因此在文物保护修复会计科目设置上，应更多地借鉴科研项目科目设置方法。 　　5、创新性提出文物保护修复经费预算内控方法：考虑到文物保护修复的复杂性和专业性，文物保护修复经费采取分科目的比例控制法，便于财物部门审核。 |

| 研究的技术路线和研究方法： 　　考虑到本研究学科跨度大的实际，在研究队伍组成上，采取文物保护修复专家与财务管理专家相结合的办法联合攻关。首先，由国家文物局召集文物保护修复各领域的专家组成文物保护修复专家团队，归纳总结文物修复的一般程序和规律；其次，由项目承担方西安财经学院组成财务专家团队，对我国文物保护修复的实际进行调研，了解文物保护修复经费预算编制过程，经费使用过程等情况，并根据历史数据测算相关控制比例。 　　从文物保护修复的一般规律入手，研究分析文物保护修复的共性规律，撇开差异化的具体内容，重点研究保护修复的一般程序，规范、细化操作流程，通过流程涉及的工艺方法、设备、工具、材料等分项目的计价实际，探索总体规范计价的基础； 　　从历史数据分析入手，研究文物分类分级修复费用比例关系，单一文物保护修复不同阶段费用的比例关系，在此基础上归纳、总结文物保护修复费用构成，为预算编制管理提供数据支持。 　　本项目的研究方法： 　　1、调查法：采取实地调研、问卷调查、座谈会等形式，开展文物保护修复管理调研，重点了解文物保护修复经费管理现状，包括经费预算管理和会计核算管理。 　　2、经验总结法：经验总结法是通过对实践活动中的具体情况，进行归纳与分析，使之系统化、理论化，上升为经验的一种方法。在本研究中，文物保护修复流程的规范过程就是文物保护修复经验总结。 　　3、实证研究法：在本研究中，按照坐标计价法对已经发生的文物保护修复经费进行统计分析，研究经费构成。 　　4、案例分析法：通过典型案例的分析，归纳总结文物保护修复的一般流程和工艺方法。 　　5、定性分析法：定性分析法就是对研究对象进行“质”的方面的分析。文物按照材质分类。 　　6、定量分析法：修复费用比例测算及控制。 　　7、文献研究法：主要通过调查文献来获得资料，了解国内外文物保护修复计价方法和费用管理方法。 |

课题经费来源与支出预算表填写说明

**一、**直接费用

一般包括：人员费、设备费及相关业务费（其中含材料费、资料费、调研差旅费、小型会议费等）。

1、人员费，指为直接参加课题研究的全体人员支出的劳务费用。人员费预算控制在总经费的10%以内。

2、设备费，指课题研究过程中发生的仪器、设备、样品、样机购置和试制费用。设备费预算占课题总经费的30%以内。

3、相关业务费，指为课题支付的材料费、测试及化验费、会议费、差旅费、资料费、专家咨询费及其他费用等。

材料费，指课题研究过程中需要消耗的各种原材料、辅助材料、低值易耗品、元件、试剂、实验标本、部件等费用。大宗材料和贵重材料（单次采购价3000元以上）单独列示。

测试及化验费，指课题研究过程中需要支付的测试及化验费用。

会议费，指课题研究过程中需要组织召开的审查会、咨询会等各种会议发生的费用。每次会议预算应控制在5000元以内。

差旅费，指课题研究过程中需要支付的差旅费。差旅费预算占课题总经费的30%以内，主要课题研究人员按每人2000-5000元计算。

资料费，指课题研究过程中需要支付的打印、复印、扩印、照相、印刷、描晒图、制版及购买书籍、资料、文献检索、入网等各项费用。

专家咨询费，指支付给有关专家的咨询费用。由国家文物局组织的专家验收评审会、论证会，咨询费为500元/人；由课题组织单位和课题承担单位组织的验收评审会、论证会，咨询费为300元/人。专家咨询费不超过课题总经费支出预算的8%。

其他费用，指除上述六项费用外的其他各种相关费用。

**二、**间接费用

包括管理费（包含支付承担单位课题服务的人员费用和其他行政管理支出）、现有仪器设备和房屋的使用费和折旧费等，间接费用一般在课题总经费支出预算比例5%--15%。

**三、**协作研究费

指将部分工作委托给外单位协助完成所发生的费用。协作研究费一般不超过课题总经费的50%。超过50%的，国家文物局可根据实际情况对课题进行招标或直接委托进行。
