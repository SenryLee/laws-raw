# 国家测绘地理信息局办公室关于印发国家测绘地理信息局机关2012年会议计划和调研计划的通知

## 国家测绘地理信息局办公室关于印发国家测绘地理信息局机关2012年会议计划和调研计划的通知（测办〔2012〕14号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司局：

为贯彻落实党中央、国务院有关要求和我局2012年重点工作安排，进一步转变工作作风和工作方式，加强会议组织管理，确保调研工作整体协调有序。现将局机关2012年会议计划和调研计划印发执行，并将有关事项通知如下：

**一、**严格执行计划，控制数量和规格

机关各司局要高度重视会议组织和调研工作，以创建务实、高效、廉洁、节约型机关为目标，采取有效措施，严格执行会议计划和调研计划，控制会议、调研的数量和规格。

要严格按照《局会议管理办法》和《局工作规则》有关规定，认真执行会议计划，保证各项指标不突破。各司局召开的二类、三类会议，会期均不得超过2天，与会人员分别不得超过120人和60人。提倡利用视频会议和多个司局联合召开会议，用一个会议解决多个相关问题。

要根据业务需要和基层工作实际，合理确定调研内容、形式和参加人员，减少基层负担。要充分利用出差、开会到一线、基层等各种机会，开展考察走访、专家座谈等多种形式的调查研究。对多个司局到同一地区的调研活动，应组成联合调研组开展调研活动。

严格控制计划外会议和调研，确因工作需要必须安排的，主办单位要根据实事求是、一事一批的原则，详细说明依据，明确经费渠道，报分管局领导审核后报局长审批。

**二、**有序推进工作，提高质量和效率

机关各司局要按照计划安排，提早谋划，统筹安排，掌握工作节奏，精心组织实施，扎扎实实做好全年工作，特别要围绕2012年的九大任务，积极推进、抓出实效。

要认真做好会议筹备组织工作，把握好会议主题和内容，制定详细可行方案，着力解决实际问题。会议方案、筹备情况报告和会议文件材料应提前10个工作日报局领导审示。

要认真做好调研组织管理工作，切实避免形式主义，突出重点，丰富内容，确保调研效果。各省（区、市）要结合自身实际予以协助，并作好相关安排。调研结束后15个工作日内应提交调研报告，以供局工作决策参考。

各司局要认真抓好计划的落实，提高工作的规范化水平，并在2012年12月底前，将会议计划和调研计划实施情况报办公室。办公室应加强对会议和调研计划落实情况的督促检查。
