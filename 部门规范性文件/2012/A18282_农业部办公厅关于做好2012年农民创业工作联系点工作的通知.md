# 农业部办公厅关于做好2012年农民创业工作联系点工作的通知

## 农业部办公厅关于做好2012年农民创业工作联系点工作的通知（农办企[2012]7号）

各省、自治区、直辖市及计划单列市、新疆生产建设兵团乡镇企业行政管理部门：

为深入贯彻2012年中央1号文件精神，落实国务院批准实施的《促进就业规划（2011--2015）》有关部署，积极推动全国农民创业工作，按照《农业部办公厅关于公布全国农民创业工作联系点的通知》（农办企[2011]44号）要求，现就做好2012年农民创业工作联系点（以下简称联系点）工作通知如下：

**一、**工作目标和思路

农民创业是新时期发展农村二三产业、带动农民就业增收的有效途径。对促进城乡要素双向流动、建设社会主义新农村、壮大县域经济、加快城乡一体化发展和保持农村社会和谐稳定等都具有重大的现实意义。推进全国农民创业工作，需要理清思路、明确方向、整体推进、重点突破，抓好联系点工作是其中的重要环节。要按照“先行先试、总结经验、示范带动”的原则，努力在推动实践、了解情况、明确方向、培育典型等方面取得新进展，再上新台阶。

2012年农民创业工作联系点工作，要以“出台一个促进农民创业的指导性意见、建设一批农民创业基地、培育一批农民创业典型、培训一批农民创业主体、完善一个农民创业服务体系”（简称“五个一”）为突破点，努力探索一条“点创新、线延伸、面推广”的工作新路子，逐步形成政策支持、政府推动、部门负责、社会参与、农民自主的农民创业工作新局面，把联系点真正建成深入基层、深入农村、深入实际的实验基地和引领全国农民创业工作的示范点、试验田。

**二、**工作重点

各联系点要围绕“五个一”的总体要求，结合当地实际和农民创业需求，突出重点、创新机制、完善政策、强化措施，力争在重点工作上有所创新、有所突破。

（一）推动出台促进农民创业的指导性文件。加强政策扶持是推进农民创业的有力保障。要认真学习借鉴有关部门和地方的先进做法，结合当地实际，围绕降低创业成本、优化创业环境、加强创业服务、提高创业效率等，认真研究工商登记、土地流转、项目安排、创业辅导、教育培训、小额信贷、财政补贴、税费减免、专项资金等方面的扶持政策和措施，争取以政府名义出台一个促进农民创业的指导性文件。

（二）探索建立农民创业基地（园）。建立农民创业基地（园）是推进农民创业的有效载体。要积极争取地方政府和相关部门的支持，利用现有的乡镇工业园区、闲置厂房、闲置校舍、批发市场、楼宇和商业街等场所，建设一批设施完善、功能齐全、服务到位的农民创业基地（园），为农民创业搭建良好的发展平台。已经建立农民创业基地（园）的，要在完善基础设施建设、提升服务功能上下功夫，努力打造高水平的示范基地（园）。

（三）着力培育农民创业成功典型。实施典型引路是推进农民创业的重要机制。要优先支持农村能人、返乡农民工、大学生村官和合作组织带头人开展创业，加快培育一批有思想、有文化，敢闯敢干、勤于耕耘、敢为人先、勇于创业的创业带头人。认真总结好经验、好典型、好机制，利用各种媒体和创业农民的现身说法和现场示范等形式，加大宣传力度，营造良好环境。

（四）积极开展农民创业培训。加强创业培训是推进农民创业的重要手段。要整合财力和培训资源，积极协调教育、农业、劳动、建设、科技等部门的培训力量，针对农民创业需求和产业特点，不断创新培训机制。加强创业培训教师队伍建设，努力培育一支知识化、专业化的农民创业培训师队伍。加强对培训机构的监管，建立和完善公示、台帐、检查验收和信息反馈等制度，不断提高培训质量和效果。

（五）切实强化农民创业服务体系建设。服务体系建设是推进农民创业的重要依托。要选聘一批服务意识强、业务水平高的专业人员，成立农民创业服务机构，组织开展项目开发、方案设计、风险评估、开业指导、融资服务、管理咨询、技术服务、信息服务和市场拓展等专项服务。加强信息服务，建立农村劳动力资源信息库和农民创业项目信息库，建立农民创业服务热线，利用网络、电话、短信等平台及时准确地向农民提供涉及创业的政策信息、项目信息、市场信息等。积极开展市场拓展服务，鼓励农民创业者利用电子商务平台开展营销活动，降低营销成本，组织企业参加有关博览会、推介会和产品展示展销活动，多形式、多渠道培育市场、开拓市场。

**三、**有关要求

做好联系点工作，事关农民创业工作整体推进和发展方向，各级乡镇企业行政管理部门要进一步统一思想、提高认识、凝聚力量、扎实工作、务求实效，为农民创业营造良好的外部环境。

（一）加强组织领导。联系点所在县（市）乡镇企业行政管理部门要落实分工责任、明确目标任务，确保联系点工作的有效开展。联系点所在省（区、市）乡镇企业行政管理部门，要加强对联系点工作的督导检查和协调服务，对联系点存在的问题和困难，要积极帮助协调解决，在项目支持和资金安排上向联系点倾斜。我部将在教育培训、试点示范、宣传推介等方面加大工作力度，努力把联系点建成带动全国农民创业的示范点。

（二）发挥典型作用。各联系点要发挥好“工作示范点、信息采集点、政策探索点、理论实践点”的作用，深入研究新问题、新动态，挖掘好经验、好典型，探讨新思路、新举措，按照“五个一”的工作目标，不断完善工作方法和手段，创新工作载体和抓手，推动农民创业工作科学发展。

（三）搞好合作协作。要加强工作协调，积极争取党委政府的支持和相关部门的配合，调动各方力量，建立促进农民创业的部门协商工作机制和“领导支持、部门配合、社会参与、公共服务、协调一致”的农民创业服务机制，明确责任分工，形成支持农民创业的工作合力。

（四）强化联络沟通。各联系点要切实担负起工作联系职责，加强对上联络和沟通，定期上报工作开展情况，并于年初、年中和年底分别上报“五个一”工作的实施方案、工作进度和完成效果（见附表），我部将对联系点实行动态跟踪考核，及时通报各联系点工作情况，对工作成效突出的给予表扬。

（五）注重宣传推介。我部将通过农民日报、中国农业信息网等媒体和乡镇企业局工作动态等开展专题宣传，推广各地的好经验、好做法。各地也要充分利用报纸、网络、电视等媒体以及会议、论坛等重大活动，宣传扶持农民创业的政策、工作措施、创业典型，努力营造农民创业的良好舆论氛围。
