# 商务部办公厅关于开展2012年全国散装水泥宣传周活动的通知

各省、自治区、直辖市散装水泥主管部门，散装水泥办公室：

为深入贯彻落实科学发展观，建设资源节约型与环境友好型社会，加快推进散装水泥行业发展，商务部定于2012年6月11日-17日开展2012年全国散装水泥宣传周活动。现将有关事项通知如下：

**一、**宣传周主题

保护环境，城市禁止现场搅拌；惠农便民，农村推广散装水泥。

**二、**宣传周工作重点

广泛宣传发展散装水泥带来的重大环境效益和社会效益，为推广使用散装水泥工作营造良好的社会氛围，加快构建促进资源节约、环境友好的水泥生产和消费模式，推进散装水泥、预拌混凝土、预拌砂浆“三位一体”产业的全面协调可持续发展。重点宣传发展散装水泥、预拌混凝土、预拌砂浆对节约资源、保护环境、提高建设工程质量和加快新农村建设的重要意义；宣传国家关于发展散装水泥的方针、政策。

**三、**宣传周工作要求

宣传周期间，各地要结合本次宣传周主题，积极采取多种形式开展宣传活动，广泛宣传城市禁止现场搅拌混凝土及砂浆、农村发展使用散装水泥等方面工作成效，积极推广绿色、低碳的散装水泥发展理念，大力宣传推广应用散装水泥对促进节能减排的重要意义。同时，各级散装水泥办公室要主动向当地主管部门及相关部门汇报散装水泥宣传工作情况。

宣传周结束后，各地要将宣传周活动中好的做法和取得的成效等情况及时报送商务部。
