# 国家文物局关于召开2012年全国文物局长会议的补充通知

## 国家文物局关于召开2012年全国文物局长会议的补充通知（办秘函〔2012〕955号）

各省、自治区、直辖市文物局（文化厅），各计划单列市文物局（文化局），新疆生产建设兵团文化局，各直属单位：

根据中央有关精神和我局工作安排，原订于2012年12月25日至26日上午在北京召开的全国文物局长会议现改为12月25日召开，会期一天。12月24日报到，12月26日疏散。会议地点及参加人员不变。

特此通知。

国家文物局

二〇一二年十二月十一日
