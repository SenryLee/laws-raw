# 商务部公告2012年第78号――关于涂布白卡纸反倾销案延期的公告

## 商务部公告（2012年第78号）

关于涂布白卡纸反倾销案延期的公告

根据《中华人民共和国反倾销条例》的规定，2011年11月18日，商务部发布公告，决定对原产于美国的进口涂布白卡纸进行反倾销立案调查。

鉴于本案情况较为特殊和复杂，根据《中华人民共和国反倾销条例》第二十六条的规定，商务部决定将本案的调查期限延长6个月，即截止日期为2013年5月18日。

商务部　　

2012年11月16日
