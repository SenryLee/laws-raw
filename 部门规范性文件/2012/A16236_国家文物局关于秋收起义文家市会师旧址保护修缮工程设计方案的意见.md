# 国家文物局关于秋收起义文家市会师旧址保护修缮工程设计方案的意见

## 国家文物局关于秋收起义文家市会师旧址保护修缮工程设计方案的意见（办保函〔2012〕712号）

湖南省文物局：

你局《关于审批〈全国重点文物保护单位湖南省秋收起义文家市会师旧址保护修缮工程勘察设计方案〉的请示》（湘文物报[2012]54号）收悉。经研究，我局提出如下意见：

**一、**进一步明确修缮工程性质。根据残损现状，修缮工程应以保养为主，并据此调整相应的工程内容。

**二、**深化现状勘察，补充墙面做法、原油饰做法、灰塑做法以及檐部封檐板的规格、残损状况等内容。

**三、**补充完善文物保护的具体措施，如补充墙面、油饰和灰塑的做法；补充封檐板的规格、材料和做法要求等。

**四、**根据现状勘察结果，进一步核定需更换瓦面瓦件的数量。应最大限度保留原有瓦件，尽量减少更换量。

**五、**整治院落地面，拆除青砖和水泥地面改用当地产毛石边角料拼铺地面的做法既不符合历史原状，也不能避免梅雨季节青苔滋生的现象。建议经过调查试验后，再行确定地面整治方案。

**六、**进一步修改完善设计说明，补充设计图纸。如补充过街亭木质栏杆的设计详图等。

**七、**电力、给排水改造工程应补充详细设计方案。

请你局根据上述意见，组织相关单位进一步补充、修改方案，按程序另行报审。

专此。

国家文物局　　

二〇一二年五月九日
