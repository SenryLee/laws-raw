# 中国证券监督管理委员会发审委2012年第51次会议审核结果公告

中国证券监督管理委员会发行审核委员会2012年第51次会议于2012年3月23日召开，现将会议审核结果公告如下：

中国石油化工股份有限公司（可转换债券）获通过。

广东秋盛资源股份有限公司（首发）获通过。

发行监管部　　　

二〇一二年三月二十三日
