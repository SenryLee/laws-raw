# 国家林业局关于开展2009―2012年度预算执行自查自纠工作的通知

## 国家林业局关于开展2009-2012年度预算执行自查自纠工作的通知

各司局、各直属单位：

为进一步规范我局资金（资产）管理，确保资金安全运行和国有资产保值增值，提高财政资金使用效益，根据局党组部署，决定在全局范围开展2009-2012年度预算执行自查自纠工作。现就有关事项通知如下：

**一、**检查范围

（一）资金范围。

凡列入国家林业局部门预算的财政资金、基本建设资金，均属本次自查自纠范围。

（二）单位范围。

局机关各司局、局各直属单位。三级预算单位由其主管二级预算单位汇总自查自纠情况。

**二、**自查内容

一是审计署确定的预算执行审计工作重点。具体为：

1．国有资产管理情况。

2．科研项目管理和经费使用情况。

3．人员经费挤占公用经费、项目经费问题。

4．历年来审计发现问题的整改到位情况。

5．中央专款分配情况。

二是一般性预算执行审计工作要求，即财经法规执行情况，特别是部门预算完整性、管理规范性，以及预算执行科学性等方面存在的问题。具体包括7个方面的42项内容（详见附件1）o

**三、**时间安排

自查自纠工作从2012年12月15日至2013年1月20日结束。请各单位于2013年2月15日前，以正式文件将自查自纠结果报我局计资司。

文字材料和电子表格发送至F84238424@126.com。

**四、**工作要求

（一）务必高度重视此次自查自纠工作。

各单位一把手对本单位自查自纠工作负全责，要精心组织、周密部署；领导班子成员要统一思想，统一行动，按照分工各负其责。要成立组织机构，落实专门人员，把自查自纠任务和工作责任具体分解落实到各有关处室和具体人员。要制定详细的自查自纠工作方案，坚决杜绝走过场、敷衍了事的形式主义做法。

（二）严格按照财经法规进行自查自纠，对发现的问题如实报告。

各单位要根据国家财经法规的有关规定对本单位的预算执行情况进行一次全面的梳理，检查本单位的项目、财务管理和会计核算是否存在违反财经法规等情况。各单位对自查中发现的问题要如实上报，不得虚报、瞒报。对自查自纠不认真、走过场的单位，一经查出，将按有关规定严肃追究单位主要领导和相关责任人的责任，并采取相应措施予以调控。

（三）对存在的问题要深入分析，认真整改。

各单位对自查中发现的问题要进行深入分析，能立即整改的要立即整改；无法立即整改的要制定切实可行的整改方案，明确整改措施和时间，并认真落实。

（四）认真撰写自查自纠工作报告。

各单位上报的自查自纠工作报告要有情况、有分析、有建议。具体包括自查自纠工作的组织开展情况，自查发现的主要问题、涉及金额、原因分析以及整改落实情况。对确实属于体制和机制方面的原因，单位无法整改的问题，要提出改进的建议和意见。同时，据实认真填写附表2，并随文上报。
