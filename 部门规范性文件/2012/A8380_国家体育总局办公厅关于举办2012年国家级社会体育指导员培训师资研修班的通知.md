# 国家体育总局办公厅关于举办2012年国家级社会体育指导员培训师资研修班的通知

各省、自治区、直辖市、新疆生产建设兵团体育局，国家社会体育指导员培训基地：

为不断增强国家级社会体育指导员培训的科学性、针对性、实效性，进一步做好国家级社会体育指导员培训管理与教学工作，根据工作计划，决定举办2012年国家级社会体育指导员培训师资研修班。现将有关事宜通知如下：

**一、**时间

12月13日至15日（12月12日报到，12月16日离会）。

**二、**地点

广东省广州从化市

**三、**参加人员

（一）各省、自治区、直辖市、新疆生产建设兵团体育局主管部门工作人员1人。

（二）国家社会体育指导员培训基地培训工作负责人或国家级培训班负责人1人。

（三）国家级社会体育指导培训教学中讲授“新大纲”规定教学内容的教师2人。

（四）请严格按照规定人数报名，不得超编。

**四、**内容

（一）解析、培训2012年版《社会体育指导员技术等级培训教材》。

（二）征求《国家社会体育指导员培训基地评估办法》意见。

（三）交流国家级社会体育指导员培训管理与教学工作经验。

**五、**经费

参加研修班人员交通费用自理（可列入培训基地2012年培训经费开支），食宿费由研修班负担。

**六、**报名、报到

（一）请参加研修班人员将报名表（附件）一式两份于12月1日前分别传真至国家体育总局社会体育指导中心和广东省体育局群体处，

（二）请参加研修班人员于12月12日到从化市华辉度假村（从化市温泉镇温泉大道云星路39号）报到。

1.研修班在广州白云国际机场设接站处，10点30分后每两小时发一班车前往从化，请参加研修班人员尽量乘坐早班飞机。

2.研修班在广州各火车站不设接站处，请乘火车的人员到广州市大荣酒店（地址：广州市林和西路196号，电话：020-87014488） 集中，研修班将视人员到达情况，安排车辆前往从化。
