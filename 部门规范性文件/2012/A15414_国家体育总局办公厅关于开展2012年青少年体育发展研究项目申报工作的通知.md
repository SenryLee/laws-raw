# 国家体育总局办公厅关于开展2012年青少年体育发展研究项目申报工作的通知

各省、自治区、直辖市体育局，有关直属单位，各共建体育学院：

为充分发挥体育科技在我国青少年体育工作中的支撑和保障作用，公开、公平、公正地选择研究项目承担单位和负责人，调动全社会科研力量开展青少年体育科学研究，根据国家体育总局有关文件精神，结合具体实际工作，决定开展2012年度青少年发展研究项目的申报工作，现将有关事项通知如下：

**一、**项目申报范围

此次申报本着青少年体育研究工作必须坚持为领导决策服务、为科学管理和青少年体育工作实践服务的精神，围绕青少年体育工作中的重点、难点及热点问题展开理论研究和应用研究，体育总局青少司根据各业务实际工作需要拟定了2012年度青少年体育研究题目（名称详见附件）。此次研究项目分为三类：重点项目、一般项目和合作项目。

项目经费首先支持各方面研究力量在相关项目的研究基础上，开展延续和补充研究。各领域申报的研究项目要在原有的研究基础上突出创新，不断提高研究水平和层次。

另外，本次项目申报特设自由申报项目。申请人围绕青少年体育发展工作重大理论及政策问题，以及社会关心的青少年体育问题进行申报，根据专家评审意见，选3-5个项目进行立项。

**二、**申请人条件

（一） 申请人享有中华人民共和国公民权，遵守中华人民共和国宪法，拥护社会主义制度和中国共产党的领导。

（二） 申请人应具有副高级以上专业技术职称或硕士以上学位。

（三） 申请人必须从事实际研究工作并真正承担和负责项目的组织与实施。

（四） 研究项目参加者必须征得本人同意，否则视为违规申报。

（五） 研究项目第一申请人正在主持的省、部级以上科研课题不得超过2项。

（六） 青少年体育司每年的研究项目申请，申请人以第一申请人身份只能申请一项。

**三、**申报单位条件

（一） 在全国范围内具备开展相关研究和开发能力基础、能为招标研究项目实施提供必要条件保障的法人单位。

（二） 每个单位可单独申请，亦可多个单位联合申请。

（三） 申报单位需设有科研管理职能部门。

**四、**申报程序

（一）　　凡符合以上规定条件的单位及人员均可申报。

（二） 申报研究项目须于截止日期前从网上提交申报书，并将经单位审查合格的项目申报书一式5份（单位法人签署意见，加盖公章）报送至国家体育总局体育科学研究所青少年体育研究与发展中心。没有通过网上申报的研究项目不予受理。

**五、**项目管理

（一） 国家体育总局体育科学研究所青少年体育研究与发展中心负责研究项目的征集、项目招标、评审、立项、中期检查和验收结题工作。

（二） 国家体育总局体育科学研究所青少年体育研究与发展中心将组织专家对申报的科研项目进行评审。中标单位在同意遵守相关管理规定前提下签订计划任务书，并实施项目研究工作。

**六、**有关要求

（一） 按照有关要求如实填写申报材料，并保证没有知识产权争议。凡在申请中弄虚作假者，一经发现并查实后，取消申报资格；如获准立项，立即给予撤项处理并通报批评。

（二） 为保证申报和评审工作的公正性和严肃性，在评审会召开前，申报单位或个人不得以任何名义走访、咨询或邀请评审组专家进行申报辅导。

（三） 研究项目完成时限一般为1年。重点项目申报经费原则上不超过10万元，一般项目经费不超过5万元。合作项目经费不超过2万元。

（四） 获准立项的项目负责人在项目执行期间要遵守相关承诺，履行约定义务，按期完成研究任务，按要求进行项目成果验收。项目经费使用情况将由国家体育总局财务管理和审计中心进行审计。

（五） 各项目申报单位要加强对项目申报工作的组织和协调，认真审核，严格把关，择优推荐，努力提高申报质量。未经单位主管部门盖章同意的项目申报书，不予以受理。

（六） 项目申报受理时间截止至2012年6月24日，逾期不予受理。

附件1：　

2012年青少年体育发展研究项目名称

**一、**青少年体育公共服务体系构建研究

研究目标：

通过国内外青少年体育公共服务体系的比较，以及现状与发展对策的分析，为构建和完善我国体育公共服务体系提供参考依据。

研究内容：

1、 青少年体育公共服务体系的内涵和特点。

2、 我国青少年体育公共服务体系的组成和现状。

3、 国内外青少年体育公共服务体系的比较。

4、 我国青少年体育公共服务体系存在的问题和发展对策。

**二、**奥运项目后备人才中长期发展规划

研究目标：

全面分析我国各运动项目管理中心竞技体育后备人才培养现状，制定适合各项目发展的后备人才培养工作发展纲要，重点结合运动项目实际规划未来10年后备人才培养的方向和改革内容，为我国竞技体育的可持续发展提供强有力的支撑与保障。

研究内容

1. 调研分析我国各运动项目管理中心竞技体育后备人才培养现状。

2. 编制各运动项目管理中心竞技后备人才培养规划模板。

3. 汇编各运动项目管理中心竞技后备人才培养规划纲要。

4. 制定我国后备人才培养发展规划纲要。

**三、**我国社会力量办青少年体育社团组织现状及对策研究

研究目标：

为研究和了解青少年体育机构发展所需要的政策环境，向政府决策部门提供促进青少年体育机构发展的政策体系建议。

研究内容：

1. 国内外青少年体育机构及政策文献分析。

2. 青少年体育机构数量和现状的抽样调查。

3. 根据调查结果，针对不同发展现状的地区政策和发展状况相关性分析。

4. 青少年体育机构促进政策初步建议及后续研究框架设计。

**四、**全国青少年运动员注册及体育赛事整合研究

研究目标：

通过对当前各类青少年运动员注册管理系统的深入研究，建立全国青少年运动员注册管理系统。调研掌握体育系统和教育系统针对青少年人群的体育赛事组织情况，并对两者进行比较分析，提出进行赛事整合的可行性建议。

研究内容：

1. 全国青少年运动员注册管理办法的研制。

2. 全国青少年运动员注册管理系统的设计。

3. 体育系统和教育系统的青少年赛事组织现状。

**五、**全国青少年基础数据申报系统研究

研究目标：

通过构建青少年体育基础数据申报系统，为准确、定时获得青少年体育基础数据搭建平台。

研究内容：

1、 青少年体育基础数据申报指标体系。

2、 青少年体育基础数据申报表格的设计。

3、 青少年体育基础数据申报平台构建。

**六、**青少年校外体育活动中心建设标准与运营管理研究

研究目标：

为国家体育行政部门制定和颁布指导性政策提供理论依据；为青少年校外体育活动中心规范化建设提供参考。

研究内容：

1. 青少年校外体育活动中心建设标准研制。

2. 青少年校外体育活动中心人力资源配置与绩效评估。

3. 青少年校外体育活动中心运营管理模式及品牌培育。

**七、**青少年运动伤害险种研究

研究目标：

设立和推动“青少年阳光体育运动责任保险”机制，从根本上预防和解除青少年家庭、体育运动倡导者和组织管理者的后顾之忧。

研究内容：

1. 青少年体育运动伤害保障机制研究。

2. 社会力量举办青少年体育活动情况调查。

**八、**全国奥运项目业余训练布局的研究

研究目标：

对新时期奥运会项目的设置特点进行发展分析，进一步优化我国业余训练项目布局，制订保障重点项目布局的组织措施。

研究内容：

1. 新时期奥运项目设置的发展特征。

2. 国内重大比赛项目设置的配套措施。

3. 重点项目布局组织实施的保障措施。

**九、**全国各级各类体校办学标准评估体系研究

研究目标：

为了加强体育运动学校的宏观管理，解决目前的办学模式和竞技体育形式的矛盾，研制新的《体育学校办学水平评估指标体系》。

研究内容

1. 新的评估指标体系的制定原则。

2. 新的评估指标体系的参评单位及发展目标。

**十、**各级各类体育运动学校建设指南

研究目标：

规范和指导体校建设发展，优化我国体育人才培养体系，促进社会发展，提升体校教学和训练水平，实现自身可持续发展。

研究内容：

1. 我国各级各类体育运动学校的现状和相关问题。

2. 制定体校建设指南的必要性。

3. 校园体育建筑的特点和发展趋势分析。

4. 校园体育建筑建设指南体系与模块化研究。

**十一、**全国青少年体育发展指导体系研究

研究目标：

建立中国青少年体育活动内容体系和发展指导体系；建立青少年体育活动发展指导专家资源管理体系。

研究内容：

1. 中国青少年体育活动内容体系。

2. 中国青少年体育发展指导体系。

3. 中国青少年体育发展指导专家资源配置。

**十二、**青少年体育文化发展对策研究

研究目标：

科学界定和剖析当前我国青少年体育文化的概念、特点与时代特征，并在此基础上探索我国现阶段青少年体育文化的发展策略和保障体系建设，旨在全社会营造积极、健康的青少年体育文化，发挥青少年体育文化对青少年身心健康的促进作用，进而推进整体国民体质素质的全面提高。

研究内容

1. 青少年体育文化的内涵、外延、特质，以及当前我国青少年体育文化的背景分析。

2. 当前我国青少年体育文化发展的现状、问题与原因分析。

3. 当前推进我国青少年体育文化发展的对策建议。

4. 当前推进我国青少年体育文化发展的保障体系研究。

**十三、**国外青少年体育组织培育和监督管理研究

研究目标：

对国外青少年体育组织的类型和运行模式的基本体系进行梳理，对我国青少年体育组织的构建提供理论基础和实践依据。

研究内容

1. 国外青少年体育人才培养的组织体系。

2. 国外青少年体育人才培养的运行模式。

**十四、**青少年健康促进自我干预模式的构建

研究目标：

在分析青少年健康促进知识能力的现状与需求的基础上，进行青少年健康促进自我干预模式的原则、方法和途径等探索研究，最终构建具有运动特色的青少年健康促进自我干预模式。

研究内容：

1. 青少年健康促进知识能力的现状与自我干预需求的分析。

2. 青少年健康促进自我干预模式构建的目的、意义和必要性研究。

3. 青少年健康促进自我干预模式的构成要素分析。

4. 青少年健康促进自我干预模式的构建原则、方法和途径研究。

5. 青少年健康促进自我干预模式构建的推广策略研究。

**十五、**农村地区青少年体育活动发展对策研究

研究目标：

结合青少年体育活动的特点和相关发展理论，充分考虑农村青少年体育活动的基础资源结构和配置效率问题，向有关职能部门提出当前推动农村青少年体育活动的具体推动策略或实施路径，以期达到优化组织形式和资源配置的目的，并积极推动城乡青少年体育协调发展。

研究内容：

1. 农村青少年体育活动公共服务体系的结构性分析。

2. 农村青少年体育活动的组织形态及影响因素。

3. 农村青少年体育活动开展的推动策略。

**十六、**功能性力量训练对青少年身体素质发展实证研究

研究目标：

通过对比实验，就功能性训练对青少年身体素质的促进作用进行深入研究。

研究内容：

1. 功能性训练对青少年健康促进的研究。

2. 功能性训练促进青少年身心发展对策与手段研究。

**十七、**青少年校外体育服务模式构建研究

研究目标：

通过对青少年校外体育服务类型的研究，在借鉴国内外青少年校外体育服务成功经验的基础上，对他们的先进理念、成功模式和有效途径进行理论升华，探讨创新青少年校外体育服务模式。

研究内容

1. 研究青少年校外体育服务类型，提出构建青少年校外体育服务体系的设想。

2. 结合不同的组织形式、建设内容和建设路经，探讨青少年校外体育服务体系的建设。

3. 创新青少年校外体育服务模式。

**十八、**民族地区、边疆地区青少年体育发展战略研究

研究目标：

1. 构建系统的特殊区域青少年体育发展的理论体系；丰富完善青少年运动教育理论。

2. 为我国边疆少数民族地区青少年体育运动的发展问题的解决提供理论依据；为我国边疆少数民族地区青少年的运动教育，体质与健康水平的提高；生命与安全教育实践提供对策。

研究内容：

1. 边疆少数民族地区青少年体育运动机会均等问题及其对策研究。

2. 边疆少数民族地区青少年体质与健康状况及其对策研究。

3. 边疆少数民族地区运动与生命安全教育问题研究及其对策研究。

4. 边疆少数民族地区农村幼儿运动教育问题研究及其对策研究。

**十九、**对北京市青少年存在的肥胖和近视问题进行的科学干预措施研究

研究目标：

通过调查研究北京市部分中小学儿童青少年肥胖、近视的成因，有针对性地进行科学干预，评估效果，建立学校干预体系框架，为在北京市范围内推广以学校为基础的科学干预体系奠定理论基础和实践参考。

研究内容

1. 在试点学校建立肥胖、近视青少年体质档案。档案内容主要包括：视力、身高、体重、身体成分、肢体围度、锻炼和饮食习惯等指标。

2. 进行学生肥胖、近视的成因调查研究，形成有针对性的科学干预措施。

3. 形成生活方式、膳食营养、体育锻炼三方面干预模式。

4. 纳入学校教学体系，建立学校干预体系框架。

**二十、**自由申报项目

申请人围绕青少年体育发展工作重大理论及政策问题，以及社会关心的青少年体育问题进行申报。
