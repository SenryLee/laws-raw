# 国家核安全局关于换发2012年第一批民用研究堆操纵人员执照的通知

## 国家核安全局关于换发2012年第一批民用研究堆操纵人员执照的通知（国核安发[2012]49号）

中国原子能科学研究院，中国核动力研究设计院，清华大学核能与新能源技术研究院，北京凯佰特科技有限公司：

中国原子能科学研究院《关于牛胜利等同志换发操纵人员执照的请示》（原安发〔2012〕3号）、中国核动力研究设计院《关于中国核动力研究设计院研究堆操纵人员换发新执照的请示》（院安发〔2012〕61号）、清华大学核能与新能源技术研究院《关于办理“10MW高温气冷实验堆操纵人员换照”的申请》（清核请〔2012〕3号）、《关于办理“5MW低温核供热堆试验站操纵人员换照”的申请》（清核请〔2012〕4号）、《关于办理“屏蔽试验反应堆操纵人员换照”的申请》（清核请〔2012〕5号）、北京凯佰特科技有限公司《关于申请医院中子照射器操纵员换照的请示》（凯佰特办发〔2012〕002号）收悉。经审核，现通知如下：

根据《中华人民共和国民用核设施安全监督管理条例》（HAF001）及其实施细则有关规定，我局对中国原子能科学研究院等4家营运单位民用核设施操纵人员换照申请文件进行了审核，认为牛胜利等54人具备了民用核设施操纵人员资格，批准换发执照（批准换发执照的操纵人员名单、执照号码和有效期见附件）。

附件：批准换发执照人员名单（略）

二○一二年三月三十一日
