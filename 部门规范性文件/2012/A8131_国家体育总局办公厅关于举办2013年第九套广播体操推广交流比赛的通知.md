# 国家体育总局办公厅关于举办2013年第九套广播体操推广交流比赛的通知

## 国家体育总局办公厅关于举办2013年第九套广播体操推广交流比赛的通知（体群字[2012]201号）

各行业体协：

2011年8月8日国家体育总局正式向社会发布了第九套广播体操并与教育部等国家10部委联合下发了《关于在全国推广普及中华人民共和国第九套广播体操的通知》，要求各地、各部门广泛开展第九套广播体操培训工作，尽快将该套广播体操推广普及到群众中去。今年体育总局组织开展了第九套广播体操通讯赛、第九套广播体操展演展示等一系列推广普及活动，取得了良好的效果。

为更好地在各行业体协推广普及第九套广播体操，切实发挥其在增强广大干部职工健康水平中的作用，检验一年来推广普及第九套广播体操的成果，体育总局拟于2013年1月13日在京举办第九套广播体操推广交流比赛。现将比赛总规程及比赛规则印发给你们，希望按照要求，积极组队参赛。

附件2

2013年第九套广播体操推广交流比赛规则

## 第一章　总　 则

**一、**比赛目的

为深入贯彻落实《全民健身条例》推广普及广播体操活动的文件精神，广泛开展全民健身运动，不断增强人民健康意识，促进广大人民群众日常健身锻炼，展示人民群众积极向上、团结协作的精神面貌。展示多元的健身文化形式，弘扬传统的文化精神，提供科学的健身指导依据，全方位提高广大人民群众健康水平。

**二、**比赛内容

中华人民共和国第九套广播体操

**三、**成套动作时间

成套动作时间按《中华人民共和国第九套广播体操》的时间执行。

**四、**参赛人员

1、每队参赛人数为24人，参赛人员必须是身体健康的中华人民共和国公民。

2、参赛人员应为所报单位正式在编人员。

3、男队员不少于10人。

4、40岁（截至2013年1月13日）以上人员不少于50%。

5、如有特殊情况更换参赛人员时，需持有效证明，在比赛开始前，经组委会同意方可更换。

**五、**比赛方式

比赛采取一轮制进行。一轮比赛的出场顺序由组委会指定人员抽签决定。根据抽签结果确定出场顺序，各参赛队按照出场顺序进行比赛。

**六、**比赛服饰

各参赛队伍要求服装统一，着运动服，使之便于运动；可以佩戴表现饰物，饰物的材质、形状必须是安全的，饰物不能散落；发型要整洁，化妆要适度，精神饱满。

**七、**比赛场地

比赛场地为木质地板的平整地面。场地四周设标志线清楚地标出比赛区域，线宽均为5厘米，标志线属于比赛场地的一部分。

**八、**计分方法

中华人民共和国第九套广播体操规定动作满分为100分。裁判委员会设裁判长1名、裁判员5名。每位裁判员的评分最小单位精确到个位，参赛队的得分和最后得分均精确到小数点后2位。

裁判员根据参赛队比赛的表现进行综合评判。比赛中，裁判员的评分去掉一个最高分和一个最低分，所剩分数的平均分为得分，再减去裁判长减分为参赛队该轮比赛的最后得分。分数高者，名次列前；若最后得分相等，则名次并列。

比赛最后得分 ＝ 平均分 - 裁判长减分

## 第二章　规定动作评分

第九套广播体操规定动作的评分因素包括动作完成、精神面貌、进退场情况。

**一、**动作完成（80分）

（一）动作完成规则

包括预备节、第八节整理运动各5分，其它七节动作各10分，共计80分。

1、准确度：动作技术规范、动作路线清晰、动作方向明确。

2、幅度：始终保持正确的身体姿势、大幅度舒展的完成动作。

3、力度：动作要轻松而不懈怠、有力度而不僵硬。

4、一致性：所有参赛者以均衡一致的动作准确度、动作幅度、动作力度及精神面貌完成动作。

（二）动作错误的类型

1、动作姿势错误：指完成动作时未能始终保持正确的身体姿态。

2、动作部位错误：指完成动作时技术规范性及运动部位的准确性欠缺。

3、动作方向错误：指完成动作时未能达到规定方向、方位要求。

4、动作路线错误：指完成动作时未能清晰并正确地展示出动作的开始、动作的过程及动作的结束；动作的轨迹不准确。

5、动作节奏错误：指完成动作时未能正确的控制肌肉的用力与放松；完成动作时动作与音乐或口令未能地配合。

6、漏做动作：指完成动作时漏做一节或部分节拍。

7、附加动作：指完成动作时出现的多余动作。

（三）动作错误的扣分标准

1、小错误（扣至1分）：指与正确动作、姿势和节拍等有微小的偏差或动作错误角度与方向小于15°；

2、中错误（扣至2分）：指与正确动作、姿势和节拍等有明显的偏差或动作错误角度与方向在15°--30°之间；

3、大错误（扣至3分）：指动作严重偏离正确的姿势和节拍或动作错误角度与方向在30°--45°之间；

4、失误（扣5分）：指没有清晰的身体位置、失去平衡（如跌倒等）；

5、漏做动作：每漏做一节或部分节拍，扣去漏做部分的全部分值；

6、附加动作：在同节操中出现附加动作，扣1— 3分（1/3以下人数扣1分，1/3以上至2/3扣2分，2/3以上扣3分）。

动作完成减分标准参照表：

|  |  |  |
| --- | --- | --- |
| 错 误 程 度 | 减 分 程 度 | 减 分 内 容 |
| 小错误 | 减1分 | 与正确动作、姿势和节拍有微小偏差。 |
| 中错误 | 减2分 | 与正确动作、姿势和节拍有明显偏差。 |
| 大错误 | 减3分 | 与正确动作、姿势和节拍有严重偏差。 |
| 失误 | 减5分 | 失去平衡（跌倒）。 |
| 其它 | 减3-5分 | 每漏做或附加部分动作。 |
| 减该节分值 | 每漏做一节动作或部分节拍。 |
| 减2分 | 动作不整齐。 |

**二、**精神面貌（10分）

精神面貌是指队员至始至终表现出充沛的精力，充满自信，以自身的活力和激情完成动作并感染观众。（包括服装适合运动、颜色搭配协调）

30%以下的人欠缺上述精神面貌减1分，30%-50%之间减2分，50%以上减4分。

精分面貌减分标准参照表：

|  |  |  |  |
| --- | --- | --- | --- |
| 错　误 | 少数30% | 多数30%-50% | 大多数50%以上 |
| 精神面貌欠缺 | 扣至1分 | 扣至2分 | 扣至4分 |

**三、**进退场（10分）

1、进、退场队形的编排与设计的合理性及完成的一致性；

2、指挥员的口令清晰、声音宏亮、节奏准确。

30%以下的人动作不齐减1分，30%-50%之间减2分，50%以上减4分。

队列及队形变化整齐性扣分等级标准参照表

|  |  |  |  |
| --- | --- | --- | --- |
| 错　误 | 少数30% | 多数30%-50% | 大多数50%以上 |
| 队列、队形  变化不齐 | 扣至1分 | 扣至2分 | 扣至4分 |

**四、**裁判长减分

裁判长对比赛过程进行监控，并对出现的以下情况给予减分：

1、裁判长示意后30秒内未出场，减2分；60秒内未出场，减5分；超过90秒未出场视为弃权，取消比赛资格。

2、参赛人数多于或少于规定人数，减2分/人。

3、着装不符合规定，减2分。

4、比赛过程装束掉落，减2分。

## 第三章　特殊情况处理

参赛者遇到以下特殊情况时，应立即停止做动作并向裁判长反映，在问题解决后重做，成套动作结束后提出的要求将不被接受。

**一、**播放错音乐。

**二、**因设备等问题而出现的干扰。

**三、**参赛者责任外的情况而引起的比赛中断或终止。
