# 国家林业局公告2012年第3号――关于发布我国2012年撤销的松材线虫病疫区的公告

## 国家林业局公告（2012年第3号）

根据《植物检疫条例》的有关规定，现将我国2012年撤销的松材线虫病疫区公告如下：

浙江省：缙云县。

安徽省：南陵县、铜陵县、桐城市、枞阳县、青阳县。

福建省：南安市。

江西省：南昌县、分宜县。

广东省：始兴县。

重庆市：沙坪坝区。

陕西省：略阳县。

特此公告。

国家林业局　　

二〇一二年二月十日
