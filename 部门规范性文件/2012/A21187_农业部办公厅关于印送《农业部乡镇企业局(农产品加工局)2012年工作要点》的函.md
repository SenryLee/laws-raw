# 农业部办公厅关于印送《农业部乡镇企业局(农产品加工局)2012年工作要点》的函

## 农业部办公厅关于印送《农业部乡镇企业局（农产品加工局）2012年工作要点》的函（农办企函【2012】1号）

现将《农业部乡镇企业局（农产品加工局）2012年工作要点》印送你们，请结合本单位职能和工作计划，加强协作配合，共同推进2012年乡镇企业、农产品加工业和休闲农业工作。

二○一二年二月二日

农业部乡镇企业局（农产品加工局）2012年工作要点

为贯彻落实中央农村工作会议、全国农业工作会议、全国乡镇企业与农产品加工业工作会议精神，切实做好2012年乡镇企业、农产品加工业和休闲农业工作，根据《农业部关于做好2012年农业农村经济工作意见》（农发[2012]1号），制定本工作要点。

**一、**指导思想

以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，积极应对国内外复杂的经济形势，紧密围绕农业部中心工作，立足职能职责、明确工作定位、确立绩效目标、加强调查研究、细化工作措施、落实重点任务、优化资源配置、强化岗位职责，努力促进农民就业增收，推进农村二三产业持续快速发展和农村经济文化繁荣。

**二、**工作思路

按照加强科学谋划、提升工作成效的原则，增强工作措施的灵活性、针对性和创新性，推进各项职责任务的细化落实。乡镇企业方面，以转型提升为主线，加强工作指导，落实政策支持，优化发展环境，加快结构调整和布局优化，推动乡镇企业健康发展。农产品加工业方面，以提高农产品附加值为目标，认真组织实施产地初加工惠民工程，深化行业监测分析与预警，强化技术研发体系建设，加大技术研发和示范推广力度，积极推进主食加工业发展。休闲农业方面，抓住机遇，因势利导，巩固规范管理成效，加强典型示范带动，提升公共服务能力，开拓创意农业和传统农业文化挖掘工作新领域。

**三、**工作重点

（一）推动乡镇企业转型提升

1.加强政策研究和落实。围绕地区、发展模式、产业领域等要素的不同，开展乡镇企业差异化政策研究；积极参与国家推进中小企业发展工作，推动相关政策向农村中小企业倾斜，促进城乡中小企业统筹发展；结合乡镇企业结构调整、东西合作工作，推动国家中小企业发展战略、区域发展战略、节能减排战略等大政方针在农村中小企业和中西部地区的倾斜和落实。

2.加强农民创业指导服务。强化部门合作，推动出台《关于推进农民创业工作的指导意见》；加强调查研究、树立先进典型、推广成功的创业模式，适时召开全国农民创业工作经验交流会；抓好全国农民创业工作联系点工作，围绕扶持政策、基地建设、教育培训和公共服务等加大工作力度，逐步形成政府重视、部门牵头、社会关注、齐抓共管的农民创业工作推进机制。

3.加强区域经济合作和国际交流。拓展合作领域和渠道，举办农产品加工业投资贸易洽谈会，开展乡镇企业农产品加工业名优商品推介活动。支持中西部地区拓展特色农产品加工产品市场，培育一批知名特色农产品加工产品品牌和优秀企业；搭建市场拓展平台，探索中小型农产品加工企业产品“进城入市”新途径；召开全国区域经济合作工作座谈会，总结经验、做法和模式。继续推动实施“走出去”战略，举办外经人才培训，推进中欧农产品加工业技术交流，加强国际交流合作。

4.加强从业人员培训和职业技能开发。落实阳光工程培训任务，积极开展农产品加工、休闲农业、乡村手工业从业人员培训；推进乡镇企业职业技能开发和考核鉴定，推动企业技能人才评价试点工作；组织西部乡镇企业管理人员专题培训，探索开展挂职培训的新模式，提高西部乡镇企业管理人员实际工作能力。

5.加强行业指导和公共服务。做好乡镇企业统计年报汇总和经济运行分析，加强跟踪、联系，确保工作连续性、有效性；完善统计直报系统，加大考核督促，提高工作质量；组织直报点统计人员培训，提高能力、稳定队伍。加强融资服务，根据乡镇企业和农产品加工企业融资需求特点，配合有关部门和金融机构，研究制订有关金融服务政策措施，促进金融产品和服务的创新；探索促进融资的手段和渠道，积极推介各地开展融资服务的成功做法和经验，继续办好证券融资培训班。

（二）推动农产品加工业稳步发展

6.实施农产品产地初加工惠民工程。针对农产品产后贮藏、保鲜、干燥等初加工环节技术落后、设施简陋、损失浪费严重、影响质量安全的现状，通过财政以奖代补、部门技术指导、完善公共服务等综合措施，扶持农户和专业合作组织建设初加工设施。与财政部联合出台惠民工程实施指导意见；建立一支涵盖马铃薯贮藏、果蔬贮藏和制干等领域的专家队伍；编制培训教材并组织开展项目管理和技术人员培训；开发惠民工程管理信息系统；适时开展工程实施情况检查督导工作；做好2013年惠民工程技术储备工作。

7.加强农产品加工监测分析与预警工作。进一步完善农产品加工业经济运行分析平台建设，采集数据信息，按期分析经济运行情况，编制《农产品加工业发展报告》；针对重点监测品种，按期开展专题监测分析与预警；加强监测点运行管理，启动地区监测数据报送的试运行，提高监测数据和报告的定期报送质量，开展相关培训。

8.推进农产品加工技术研发体系建设和技术推广对接工作。以我部认定的农产品加工技术研发分中心为主体，整合资源、集中力量，加强体系内各单位的交流合作；加强农产品加工技术集成基地建设，完善并实施有关规划，分行业、分品种推进先进加工技术的中试转化；开展农产品加工各行业共性技术需求调研、重大关键技术筛选和成熟适用技术推广，在部分省区举办区域性科企技术对接活动。

9．探索推进主食加工业相关工作。启动实施主食加工业提升行动，举行启动仪式，组织主食加工生产技术、装备、产品展示、推介，召开主食加工业发展研讨会；组织观摩交流，邀请部分省市农产品加工业管理部门、相关企业、科研等服务机构的人员，参加启动活动，考察相关企业；开展主食加工业示范企业申报、认定，发布第一批 “主食加工业示范企业”；开辟信息服务平台，利用中国农业信息网和农产品加工信息网两个网站，开辟主食加工业专栏，大力宣传主食加工业提升行动，集中展示主食加工业示范企业、名品、精品和技术创新成果，积极营造主食加工业的发展氛围。

10．加强农产品加工标准化工作。跟踪CAC、ISO等国际标准组织以及美国、日本、韩国、欧盟等主要贸易国标准及相关政策的变动情况，为农产品加工企业采取积极的应对措施和我国农产品加工标准制修订提供参考依据。征集农产品加工标准制修订项目，制定2012年度农产品加工行业标准。

（三）推进休闲农业蓬勃发展

11．加强规范管理和示范引领。继续开展全国休闲农业与乡村旅游示范县和示范点创建及十大魅力乡村推荐活动，加强典型宣传，引导全国休闲农业持续健康发展；完善有关标准，引导各类休闲农业主体规范经营、提升水平；开展多层次人员培训，提高管理人员和从业人员的素质。

12．强化公共服务信息平台建设。进一步完善休闲农业公共服务“进城入户”信息系统功能，增加入库信息，加大宣传推介，扩大平台影响，支持“魅力城乡”网站良性发展，充分发挥其“方便市民、服务农民”的作用。

13．开展全国休闲农业创意精品推介活动。按照“研讨理论、展示成果、推动产业”的总体目标，研讨休闲农业创意发展理论，组织全国休闲农业创意精品大赛、创意论坛，开展休闲农业创意精品投资贸易对接活动等，培育休闲农业新亮点，实现资源文化优势向产业经济优势的转变。

14．开展中国重要农业文化遗产发掘工作。贯彻落实十七届六中全会精神，组织研究和制定一套符合我国实际的重要农业文化遗产认定标准，开展全国性农业文化遗产摸底工作，筛选认定一批中国重要农业文化遗产，进行保护、开发，并择优向联合国粮农组织等国际机构推荐申报世界重要农业文化遗产。

15．创造良好发展环境。与国家旅游局联合召开全国休闲农业与乡村旅游发展工作会议，交流经验、推进工作、表彰先进。开展休闲农业专题宣传活动，积极研究促进休闲农业发展的政策措施。

（四）强化体系和队伍建设

16．深入开展创先争优活动。将创先争优活动与绩效管理、机关建设等工作有机结合、统筹推进。制定科学合理的绩效任务指标，加强业务工作的目标性和计划性；充分发挥党支部的战斗堡垒作用和共产党员的先锋模范作用，解决制约科学发展的突出问题，努力建设文明和谐机关，营造实干、向上的良好风气。

17．加强学习调研。建设学习型机关，组织开展理论学习活动，强化政策理论学习；积极参加“百乡万户”、“接地气、察民情”等调研活动，强化对“三农”工作的全面了解；深入基层开展乡镇企业、农产品加工业和休闲农业相关专题调研，及时发现新情况新问题，总结、归纳和推广好经验、好做法，有针对性的提出政策建议和工作措施。

18.加强制度的建立健全和贯彻落实。完善各项工作规章制度，强化贯彻落实，形成事事有章法、人人守规矩的良好环境。进一步落实党风廉政建设责任制，加强反腐倡廉教育，认真贯彻落实廉政准则，明确工作程序，严格工作要求，规范资金管理，建立规范有序、程序明确、监督制约、务实高效的工作运行机制。

19.加强交流合作。进一步建立健全内外联动、配合协作的工作机制，形成工作合力。加强与国务院有关部门、科研院所和行业协会等的协调合作。充分调动和激发系统积极性，加强同地方管理部门的工作联系，在行政单位、事业单位和地方部门之间形成良好互动的工作格局。

20.加大宣传推介力度。充分发挥新闻媒体的舆论导向作用，积极宣传党中央、国务院关于乡镇企业、农产品加工业和休闲农业的方针政策、法律法规，宣传重点工作开展情况，推介各地发展成就、成功经验和先进典型，为乡镇企业、农产品加工业和休闲农业的持续健康发展，营造良好的舆论氛围和发展环境。
