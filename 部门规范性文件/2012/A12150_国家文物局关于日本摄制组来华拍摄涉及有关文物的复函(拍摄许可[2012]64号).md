# 国家文物局关于日本摄制组来华拍摄涉及有关文物的复函(拍摄许可[2012]64号)

## 国家文物局关于日本摄制组来华拍摄涉及有关文物的复函（拍摄许可〔2012〕64号）

中国电影合作制片公司：

你公司关于日本《世界文化遗产》摄制组来华拍摄专题片涉及文物的函（合函字[2012]531号）收悉。经研究，我局同意该摄制组于2012年9月24日至30日期间拍摄北京故宫、天坛，河北金山岭长城有关镜头。具体拍摄内容及拍摄方式等事宜请与当地文物部门协商确定。在拍摄过程中，请该摄制组严格服从文物管理人员安排，务必确保文物安全。

国家文物局　　

二〇一二年八月十四日
