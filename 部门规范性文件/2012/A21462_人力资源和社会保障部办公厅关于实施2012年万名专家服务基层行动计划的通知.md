# 人力资源和社会保障部办公厅关于实施2012年万名专家服务基层行动计划的通知

## 人力资源和社会保障部办公厅关于实施2012年万名专家服务基层行动计划的通知（人社厅函〔2012〕27号）

各省、自治区、直辖市人力资源社会保障厅（局），各副省级市人力资源社会保障局，福建省、厦门市公务员局：

根据《关于印发万名专家服务基层行动计划实施方案的通知》（人社部发〔2011〕123号）要求，我部将于2012年全面启动实施万名专家服务基层行动计划（以下简称“行动计划”）。现就贯彻落实《万名专家服务基层行动计划实施方案》，做好2012年相关工作通知如下：

**一、**提高认识，推进“行动计划”各项任务的贯彻落实

各省（区、市）人力资源社会保障部门要充分认识实施万名专家服务基层行动计划的重要性和紧迫性，把专家服务基层工作作为实施人才强国战略的重要内容，作为加强专业技术人才队伍建设的重要措施，切实加强对专家服务基层工作的组织领导，落实稳定的工作经费，配备精干的工作人员，推动“行动计划”各项任务的贯彻落实。要突出服务基层的针对性和实效性，进一步加大调查研究力度，深入了解本地区经济社会发展急需解决的重点难点问题，充分发挥政府人才工作和专家工作综合管理部门作用，积极探索专家服务基层的有效方式，集中力量破解一批基层发展关键技术难题，培养一批基层急需紧缺人才，转化一批应用前景良好的科技成果，开展一批基层社会事业公益性活动。要调动本省市区重点联系专家的主动性和积极性，带动技术、智力、管理、信息等要素流向基层，引领产业优化升级、加快科技成果转化、推进基层人才队伍建设。

**二、**突出重点，完成2012年专家服务基层重点任务

2012年是全面实施“行动计划”的开局之年，在抓紧研究制定本地区专家服务基层实施方案和政策措施的同时，要突出抓好以下各项重点任务：

（一）组织专家服务团，开展短期服务活动。围绕本地重大发展战略和重点领域、重点行业、特色产业等发展需要，根据基层单位服务需求，组织专家服务团，开展形式多样的短期服务活动，2012年，每省市区应组织不少于200名专家，分批次深入基层开展服务活动。

（二）加快建设一批专家服务基地。根据本地发展规划及战略布局和基层经济科技发展需要，在符合条件的经济技术开发区、创业园区、高新技术企业、基层科研机构、行业协会、城镇社区、农村县区等设立专家服务基地，以基地为平台，承接专家智力资源转移。基地建设工作开展较好的省市区，可逐渐向下铺开，形成上下贯通的专家服务平台体系。

（三）组织开展对口支援服务活动。根据本地经济科技发展和人才合作需要，依托目前各类区域对口支援、对口帮扶工作，协调组织相关领域专家到对口省区市基层开展多种形式的短期服务活动。东部经济较为发达省份，每年应组织开展最少2项对口支援服务活动。

围绕以上重点任务，各省市区可在本地区组织的重点服务活动或对口支援活动中，遴选2-3项具有一定代表性，影响广泛的重点项目上报我部。申报时明确活动时间、地点、专家数量、组织形式和具体服务内容等。我部将通过综合评估，对部分活动给予择优资助。

**三、**加强领导，切实提高专家服务基层的成效

各省（区、市）人力资源社会保障部门要高度重视万名专家服务基层“行动计划”的实施，要结合本地区实际情况，制定本地区“行动计划”的实施细则和工作计划，明确本地区专家服务基层的具体任务和目标，形成上下贯通，左右联系的工作体系，以实施“行动计划”带动服务基层活动全面开展。要利用多种宣传方式，加强对“行动计划”的宣传，让更多的专家了解“行动计划”，参与“行动计划”。要围绕用好用活人才、提高人才效能，不断创新专家服务形式，完善专家服务基层政策措施，健全专家服务基层工作机制，优化专家服务基层工作平台，形成专家选派、管理和跟踪服务的长效机制，更好发挥专家资源在经济发展方式转变中的智力支撑作用和在加强基层人才队伍建设中的引领带动作用，切实把服务基层活动做实做细，做成品牌，做出成效。

各省（区、市）重点服务项目申报函请于2012年3月15日前报我部专业技术人员管理司，来函请注明联系人、联系电话、拨款账户名、账号、开户银行（拨款账户需为省级人社部门机关账户）等。2011年获得我部资助的省（区、市），请一并报送2011年专家服务基层项目实施情况总结，我们将把2011年活动开展情况作为2012年重点项目遴选的重要评估依据（以上材料请一并报送电子文档）。
