# 国土资源部办公厅关于切实做好2012年国庆节期间及节后安全生产工作的通知

## 国土资源部办公厅关于切实做好2012年国庆节期间及节后安全生产工作的通知（国土资电发〔2012〕122号）

各省、自治区、直辖市国土资源主管部门，中国地质调查局及部其他直属单位：

为深入贯彻落实党中央、国务院关于加强安全生产工作的部署，切实加强国庆节期间及节后安全生产工作，有效防范和坚决遏制重特大事故，确保安全生产形势稳定，确保人民群众过一个欢乐、祥和、平安的节日，根据《国务院安委会办公室关于加强2012年国庆节期间及节后安全生产工作的通知》（安委办明电〔2012〕22号）的统一安排，现就做好国庆节期间及节后安全生产工作有关事项通知如下：

**一、**提高思想认识，加强组织领导，进一步落实安全生产责任

2012年国庆节适逢中秋节，是党的十八大召开前假期最长的节日。地方各级国土资源主管部门、地调局及部其他直属单位要从深入贯彻落实科学发展观、促进经济社会和谐发展，以良好的安全生产环境迎接党的十八大胜利召开的高度，充分认识做好国庆节期间及节后安全生产工作的重要性，紧密结合实际，加强组织领导，周密安排部署，抓好工作落实，切实保障人民群众生命财产安全。地方各级国土资源主管部门要按照同级人民政府的部署，落实职能分工，配合有关部门积极开展安全生产工作，加强联合执法，积极参加有关专项行动，切实加强对重点地区、重点企业的指导和督促检查，确保安全生产各项措施落实到位。地调局及部其他直属单位要进一步落实安全生产责任制，切实加强本单位安全生产指导和督促检查，认真组织开展自查自纠，及时整改事故隐患，确保各项工作措施落实到位。要加强节日期间在岗职工安全教育，防止松懈麻痹情绪，做到职责明确、责任到人、工作到岗，有效防范和坚决防止重特大事故发生，切实保障人民群众生命财产安全。

**二、**深入开展安全隐患排查治理和专项整治

地方各级国土资源主管部门要在本级人民政府的统一领导下，按照安委办明电〔2012〕22号文件的部署要求，积极参加节前集中开展的安全隐患排查治理和专项整治行动，加强联合执法，加大对无证勘查开采等违法行为的查处力度，积极配合安全监管等部门，对煤矿、非煤矿山等重点行业（领域）进行全面检查和排查，对发现的违法违规行为依法进行处理。突出煤矿这一重中之重，继续配合推进煤矿整顿关闭，指导督促矿山企业认真落实瓦斯治理各项措施和任务。配合有关部门加强非煤矿山安全监管，严防透水淹井、尾矿库垮坝、排土场坍塌等重特大事故，启动非煤小矿山关闭工作，严防应关闭的非煤小矿山突击生产。配合有关部门认真做好煤矿、非煤矿山企业节日期间停产和节后复产安全监管工作，督促矿山企业制订并落实节日期间停产检修作业和节后复产安全保障技术措施。

地调局及部其他直属单位要结合实际，针对本部门、本单位安全生产存在的突出问题和薄弱环节，开展全面彻底的安全隐患排查治理。对排查出的隐患，能整改的要立即整改；不能立即整改的，要落实责任、资金和整改措施，限期整改，并加强监控。要充分发挥群众的监督作用，加强引导，动员、鼓励全体干部职工关注和参与隐患排查治理工作。

**三、**加强节日期间应急值守和防范工作

严格落实岗位责任制，严格执行领导干部到岗带班和关键岗位24小时应急值班制度。所有应急值班人员必须坚守岗位，尽职尽责，严禁擅离职守。要严格执行事故信息报告制度，遇有重大矿山生产安全事故以及其他事故、紧急突发事件，要及时、准确上报，并积极配合有关部门妥善处置。

地方各级国土资源主管部门要配合有关部门加大对重大危险源、重要设施、重点部位的巡查监控，落实各项防范措施，进一步健全完善部门间预报预警、协调联动工作机制和通报制度，配合安全监管等部门制订国庆节期间安全生产应急预案，开展应急演练，加强对重点行业领域、重要设施、重点单位和场所应急准备工作检查，落实应对措施。地调局及部其他直属单位要进一步完善应急预案，加强应急演练，落实好应急组织机构、救援队伍、装备、物资等应急资源，增强干部职工的安全意识，提高自我保护和逃生能力。

**四、**继续配合抓好安全生产领域“打非治违”工作

地方各级国土资源主管部门要认真贯彻落实地方人民政府关于深入开展“打非治违”工作的部署，持之以恒，结合矿产资源开发实际，深入配合开展“打非治违”工作。要进一步加强矿产资源开发日常监管，突出解决煤矿、非煤矿山存在的违法违规问题，严格落实矿产资源违法违规案件查处责任。要进一步健全完善优势矿产开发秩序监管区域联动机制，持续优化矿产开发布局和结构，严格矿业权管理，进一步深化矿业权有形市场建设，积极推进和谐矿区建设，维护良好的矿产开发和安全生产秩序。

国土资源部办公厅
