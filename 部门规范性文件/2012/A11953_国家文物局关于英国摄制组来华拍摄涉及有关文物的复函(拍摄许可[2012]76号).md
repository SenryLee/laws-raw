# 国家文物局关于英国摄制组来华拍摄涉及有关文物的复函(拍摄许可[2012]76号)

## 国家文物局关于英国摄制组来华拍摄涉及有关文物的复函（拍摄许可〔2012〕76号）

甘肃省文物局：

你局关于英国伦敦大学考陶尔德艺术学院与英国马克?斯图尔特制作有限公司来华拍摄专题纪录片《佛教中隐匿的艺术》涉及文物的函（甘文局发[2012]188号）收悉。经研究，我局同意该摄制组于2012年10月拍摄甘肃敦煌莫高窟第61、85、96、158、254、260、263、320、329窟和榆林窟第3、25窟等11个洞窟的部分壁画、彩塑、洞窟建筑有关镜头。具体拍摄内容及拍摄方式等事宜请与当地文物部门协商确定。在拍摄过程中，请该摄制组严格服从文物管理人员安排，务必确保文物安全。

国家文物局　　

二〇一二年八月二十日
