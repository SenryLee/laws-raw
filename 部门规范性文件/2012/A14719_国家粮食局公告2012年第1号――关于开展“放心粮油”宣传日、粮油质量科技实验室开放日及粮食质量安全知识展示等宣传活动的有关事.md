# 国家粮食局公告2012年第1号――关于开展“放心粮油”宣传日、粮油质量科技实验室开放日及粮食质量安全知识展示等宣传活动的有关事项的公告

## 国家粮食局公告（2012年第1号）

根据2012年全国食品安全宣传周活动的总体安排，现将国家粮食局开展“放心粮油”宣传日、粮油质量科技实验室开放日及粮食质量安全知识展示等宣传活动的有关事项公告如下：

**一、**“放心粮油”宣传日活动

（一）时间

2012年6月16日上午9：00-12：00。

（二）地点

北京市门头沟区永定河文化广场。

（三）内容

1.放心粮油示范企业公开向消费者承诺保证食品安全；

2.展示粮油样品及快检仪器设备；

3.发放科普宣传材料；

4.接受消费者现场咨询等。

**二、**粮油质量科技实验室开放日活动

（一）时间

2012年6月18日全天。

（二）地点

北京市西城区百万庄大街11号粮科大厦十二层。

（三）内容

开放粮食质量安全检测相关实验室（3个），包括大型仪器检测实验室、微生物实验室，向公众介绍粮食质量安全检测技术和设备。

**三、**展示宣传日活动

（一）时间

2012年6月18日全天。

（二）地点

北京市西城区百万庄大街11号粮科大厦一层。

（三）内容

1.展板介绍粮食质量安全检测项目、检测方法和质量安全标准，以及消减和处理技术等；

2.展台展示粮食质量安全快检设备产品等；

3.视频播放储粮“四合一”技术及有关食品安全知识。

二〇一二年六月八日
