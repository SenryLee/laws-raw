# 国家食品药品监督管理局信息办关于中国药品电子监管网系统升级的通知

各有关单位：

为提升中国药品电子监管网系统的运行服务能力，监管网系统将于2013年1月1日0时至1月2日18时进行升级。在此期间，系统暂停监管码申请与激活、数据上传和查询等服务。请已入网的各级食品药品监管部门、药品生产与经营企业提前做好准备。期间，有任何问题，均可致电（010）95001111进行咨询。

2013年1月2日18时系统恢复正常后，有关企业应将系统暂停期间产生的数据及时补传至中国药品电子监管网。

给您工作带来的不便，敬请谅解。

国家食品药品监督管理局信息办

2012年12月31日
