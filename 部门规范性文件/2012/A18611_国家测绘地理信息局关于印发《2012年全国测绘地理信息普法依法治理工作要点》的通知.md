# 国家测绘地理信息局关于印发《2012年全国测绘地理信息普法依法治理工作要点》的通知

## 国家测绘地理信息局关于印发《2012年全国测绘地理信息普法依法治理工作要点》的通知（国测法发〔2012〕3号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属有关单位：

为做好2012年测绘地理信息普法依法治理工作，根据《2012年全国普法依法治理工作要点》和《2012年测绘地理信息工作要点》，我局制定了《2012年全国测绘地理信息普法依法治理工作要点》。现印发给你们，请结合本地区、本单位实际，制定普法依法治理工作年度计划，并认真组织实施。

国家测绘地理信息局　

二〇一二年三月二十六日

2012年全国测绘地理信息普法依法治理工作要点

2012年是全面实施“六五”普法规划的关键一年，也是测绘地理信息工作的执行年、落实年、实干年。全国测绘地理信息普法依法治理工作的基本要求是：以科学发展观为统领，认真学习贯彻李克强副总理视察中国测绘创新基地的重要讲话精神，紧紧围绕测绘地理信息工作大局，全面贯彻《全国测绘地理信息法制宣传教育第六个五年规划（2011－2015年）》，扎实开展法制宣传教育，深入推进依法治理，为测绘地理信息事业科学发展营造良好的法治环境。

**一、**贯彻实施测绘地理信息“六五”普法规划，营造良好法治环境。省级测绘地理信息行政主管部门要按照《全国测绘地理信息法制宣传教育第六个五年规划（2011－2015年）》的要求，建立健全普法领导机构和办事机构，明确普法依法治理工作的目标、任务和保障措施，紧紧围绕建设数字城市、推广应用天地图、开展地理国情监测以及推动地理信息产业大发展等重点工作，创新普法宣传形式，加大法制宣传教育力度，推动测绘地理信息“六五”普法规划各项目标任务的全面落实。

**二、**加强分类普法，提高依法行政和依法测绘水平。普法工作要突出重点、分类施教。测绘地理信息行业干部职工都要深入学习贯彻《中华人民共和国测绘法》及其配套法律法规规章。《地图管理条例》发布以后，要着力做好宣传、贯彻与实施工作。各级领导干部要带头学法用法，着力提高依法决策、依法管理的能力和水平。行政执法人员要加强对《关于加强测绘地理信息法治建设的若干意见》、《关于加强测绘地理信息行政执法工作的意见》、《测绘地理信息市场信用信息管理暂行办法》，以及《全国测绘地理信息行政执法职权分解》、《测绘地理信息行政处罚案卷评查暂行办法》等新出台政策文件的学习；还要认真学习行政许可法、行政处罚法、行政复议法、行政诉讼法、行政赔偿法等国家行政法律法规，牢固树立有权必有责、用权受监督、违法要追究的观念，促进严格执法、公正执法和文明执法。生产单位经营管理人员要以测绘地理信息、安全生产、合同、保密等法律法规为主要学习内容，着力提高依法测绘、依法经营能力，增强诚信守法和依法维权意识。

**三、**推进“法律六进”活动，提升全社会测绘地理信息法治意识。各级测绘地理信息行政主管部门要高度重视“8·29”测绘法宣传日及测绘法修订实施十周年的各项宣传活动，精心准备、周密部署，加强策划、注重创新，通过生动活泼、形式多样的宣传活动，大力推进测绘地理信息法律法规进机关、进乡村、进社区、进学校、进企业、进单位，吸引社会各界广泛参与，确保广播有声、电视有影、网络有文，大力营造测绘法宣传声势，提高公民的国家版图意识和地理信息安全保密意识，促使社会各界进一步关心、支持测绘地理信息工作，实现事业发展新跨越。

**四、**加强宣传阵地建设，提高测绘地理信息法制宣传效果。各级测绘地理信息行政主管部门要积极拓展测绘地理信息法制宣传教育新兴阵地，充分发挥各地测绘地理信息学会、协会、宣传中心、培训中心等机构联系面广、深入基层的优势，充分利用中国测绘科技馆和各地测绘地理信息科技馆、博物馆、展厅等场馆资源，充分发挥广播电视、报刊、网络、移动通讯等大众媒体和博客、微博客等新兴渠道的作用，积极组织开展各种丰富多彩的日常宣传活动，加大对普法依法治理工作先进典型的宣传，不断推进测绘地理信息法治文化建设。

**五、**坚持法制宣传与法治实践相结合，深入推进依法治理。各级测绘地理信息行政主管部门要继续加强测绘地理信息市场监管工作，各地要根据本地区实际情况，有针对性地开展“涉外、涉军、涉证、涉网”和“问题地图”等专项监管活动，进一步建立健全与相关部门的市场监管长效机制，形成监管合力，依法查处各类测绘地理信息违法案件。对重大典型案件要及时组织媒体曝光并进行政策法规解读，不断强化依法测绘、依法用图和国家安全保密意识，促进测绘地理信息市场健康发展。

**六、**加强督促检查，推动普法工作再上新台阶。各级测绘地理信息行政主管部门要建立健全普法信息报送和市场监管情况通报制度，及时沟通测绘地理信息普法依法治理的好做法、好经验。要加强对测绘地理信息普法依法治理工作的监督检查，把普法依法治理工作纳入年度考核体系，并健全细化考评内容和标准。要积极邀请各级党委、人大、政府、政协等部门通过不同渠道对测绘地理信息普法依法治理工作进行视察、调研、检查等，形成多方参与、多方支持的工作局面。通过有效的监督，确保“六五”普法规划的贯彻落实，推进测绘地理信息普法依法治理工作向纵深发展。
