# 商务部公告2012年第39号――关于批准国内贸易行业标准《粽子》(SB/T 10377-2004)第1号修改单的公告

## 商务部公告（2012年第39号）

商务部批准国内贸易行业标准《粽子》（SB/T 10377-2004）第1号修改单（详见附件），现予公布，自批准之日起实施。

附件：《粽子》（SB/T 10377-2004）第1号修改单

商 务 部　

2012年7月17日

附件：

《粽子》（SB/T 10377-2004）第1号修改单

本修改单经商务部于2012年7月17日以商务部公告[2012]39号批准，自批准之日起实施。

修改事项如下：

原标准中：

表5 理化卫生限量指标

|  |  |
| --- | --- |
| 项目 | 指标 |
| 酸价a（以脂肪计）（KOH）mg/g　 ≤ | 3.0 |
| 过氧化值b（以脂肪计）质量分数%≤ | 0.15 |
| a.b：仅适用于一动物性食品或坚果类为主要馅料者 | |

修改为：

表5 理化卫生限量指标

|  |  |
| --- | --- |
| 项目 | 指标 |
| 过氧化值a（以脂肪计）g/100g　 ≤ | 0.25 |
| a：仅适用于一动物性食品或坚果类为主要馅料者 | |
