# 科技部基础研究司、国家中医药管理局科技司关于召开973计划中医理论专题2011年度交流会议的通知

## 科技部基础研究司、国家中医药管理局科技司关于召开973计划中医理论专题2011年度交流会议的通知（国中医药科技中医便函〔2012〕26号）

各有关单位：

为进一步做好973计划中医理论专题的组织实施，加强专项内外的交流与合作，促进中医理论基础研究成果的应用推广，科技部基础研究司和国家中医药管理局科技司定于2012年3月初召开973计划中医理论专题2011年度实施情况交流会议。现将有关事宜通知如下：

**一、**主要议题

1. 介绍973计划中医理论专题总体情况；

2. 报告2011年结题验收项目主要成果；

3. 报告在研项目研究进展和下一步工作思考；

4. 交流中医理论基础研究相关领域的最新动态、发展趋势；

5. 介绍973计划中医理论专题2013年项目申报指南有关情况。

**二、**参加人员

1. 973计划专家顾问组和中医理论专题专家组有关专家；

2．973计划中医理论专题立项项目首席科学家、课题负责人及研究骨干；

3. 973计划中医理论专题立项项目及课题承担单位科研管理人员、项目办公室主要人员；

4. 科技部、国家中医药管理局及各地中医药管理部门有关领导。

**三、**时间和地点

时间：2012年3月1-2日，2月29日全天报到，会期2天。

地点：辽宁省沈阳市（具体安排另行通知）

**四、**会议安排

本次会议组织工作由国家中医药管理局科技司负责，辽宁中医药大学具体承办。会议邀请专家食宿及往返交通费用由会议负责；其他人员食宿可由会议统一安排，费用自理。

请973计划中医理论专题各项目、课题负责人和承担单位认真准备，按时参会。具体要求另行通知。
