# 农业部办公厅关于做好“农业科技促进年活动”总结和提供垦区基层农技推广体系建设有关情况的通知

## 农业部办公厅关于做好“农业科技促进年活动”总结和提供垦区基层农技推广体系建设有关情况的通知（农办垦【2012】71号）

各省、自治区、直辖市农垦主管部门，新疆生产建设兵团农业局，广东、海南、云南、广西省（区）农业厅，中国热带农业科学院：

为贯彻落实2012年中央1号文件和全国农业工作会议、全国农垦工作会议精神，全面推进农垦与热作产业科技进步，今年年初我部下发了《农垦落实“全国农业科技促进年活动”实施方案》（农办垦[2012]12号）。为全面总结一年来开展农业科技促进年活动取得的成效、经验和垦区基层农技推广体系建设情况，现就有关要求通知如下：

**一、**请你们根据《农垦落实“全国农业科技促进年活动”实施方案》的部署，对本地区、本单位开展的科技促进年活动进行全面总结。从工作部署、方案制定、任务落实、活动进展、实施效果、信息宣传等方面进行总结，分析取得的成效、经验和存在的问题，以及明年推进科技工作的设想。

**二、**请各省（区、市）农垦主管部门对垦区基层农技推广体系建设情况进行认真总结。主要总结今年中央1号文件中有关基层农业技术推广机构各项政策措施的落实情况（如机构建设政策、投入保障政策、基层农技人员待遇政策等落实情况），以及农业科研院校、专业合作组织、龙头企业开展农技服务情况。要把基层农技推广体系建设的好做法、好经验、好成效和遇到的问题总结出来，并研究提出解决问题的对策和建议，以便汇总分析，为今后加强协调争取政策做准备。

**三、**在认真分析总结的基础上，形成书面报告，于2012年11月25日前报送我部农垦局科技经贸处，同时发送电子邮件至nkjgych@agri.gov.cn。

农业部办公厅
