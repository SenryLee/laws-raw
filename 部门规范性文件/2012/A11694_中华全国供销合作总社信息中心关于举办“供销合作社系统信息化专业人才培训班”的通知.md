# 中华全国供销合作总社信息中心关于举办“供销合作社系统信息化专业人才培训班”的通知

各省、自治区、直辖市及新疆生产建设兵团、计划单列市、副省级省会城市供销合作社，有关地、市、县级供销合作社，社有企事业单位：

根据国家工业和信息化部等五部委下发的《农业农村信息化行动计划（2010-2012年）》的要求，以总社《关于进一步加强宣传工作的意见》为指导，为更好发挥系统内政务网站宣传作用，同时，有效运用现代管理技术，提升网络运营水平。将“电子政务”、“电子商务”等信息化管理方式运用到供销合作社系统工作的各个方面，并培养一批供销合作社系统的专业信息化人才。为此，中华全国供销合作总社信息中心决定举办供销合作社系统现代经营服务网络建设与信息化管理培训班，请各省社相关工作负责人做好对此次培训工作的组织。有关事宜通知如下：

**一、**培训对象

各地各级供销合作社办公室主任、副主任，信息化工作、电子政务、电子商务、网站维护等相关工作的部门负责人和业务骨干，社有企业、事业单位信息化建设相关负责人。

**二、**培训内容

1.　信息化发展政策与趋势，网站运营和电子商务的运作。

2.　总社信息中心信息化管理工作规划和“供销云”平台的架设。

3.　系统内，信息化实施优秀典型经验交流。

4.　网站维护实战技巧：新闻编辑、图片处理、专题制作、管理系统使用。

5.　手机终端的媒体运用：手机报制作与运营，投票、调查、商务等短信平台应用在活动举办中的助推作用。

6.　信息化平台相关技术功能演示。

**三、**培训方式

培训采取课堂教学、经验交流与实地考察相结合的方式，邀请信息化管理专家授课；由总社信息中心相关负责人介绍平台规划与搭建、网站维护、手机媒体运营等方面经验；邀请供销合作社系统内的成功案例介绍相关项目的基本情况、经验做法、盈利模式、运营情况、建设成效。

**四、**培训时间、地点

2012年9月19日-21日（19日报到）

地点：杭州市

**五、**报名方式

培训费2600元/人（含培训费、讲义资料费、网站维护“大礼包”，市内参观考察。培训期间食宿费，如住单人间，需另加400元/人），往返交通费用自理。

确定参加培训人员请将《报名表》（见附件）填好后，于2012年9月14日前通过传真或电子邮件的方式将报名表传至会务组。我们收到报名表后，于举办前1周内将正式日程和报到通知传真给参会人员。
