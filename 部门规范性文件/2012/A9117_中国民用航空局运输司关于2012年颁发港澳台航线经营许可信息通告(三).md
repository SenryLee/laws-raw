# 中国民用航空局运输司关于2012年颁发港澳台航线经营许可信息通告(三)

## 中国民用航空局运输司关于2012年颁发港澳台航线经营许可信息通告（三）

中国民用航空局近期陆续颁发了下列港澳台航线经营许可：

1. 扬子江快运航空公司9月27日开通杭州-香港全货运航线，每天安排1个往返航班；

2. 顺丰航空10月1日开通厦门-香港全货运航线，每天安排1个往返航班；

3. 中国国际航空公司10月29日起开通温州-桃园航线，每周安排3个往返航班；

4. 台湾华信航空公司10月28日开通温州-台北松山航线，每周安排3个往返航班；

5. 港龙航空公司10月28日开通香港-郑州航线和香港-温州航线，每天各安排1个往返航班；

6. 香港航空公司10月28日开通香港-哈尔滨航线，每天安排1个往返航班；

7. 台湾远东航空公司拟于11月24日开通桃园-合肥航线，每周安排2个往返航班。

中国民用航空局运输司
