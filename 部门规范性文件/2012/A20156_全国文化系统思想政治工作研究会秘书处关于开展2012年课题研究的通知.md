# 全国文化系统思想政治工作研究会秘书处关于开展2012年课题研究的通知

## 全国文化系统思想政治工作研究会秘书处关于开展2012年课题研究的通知（党委发字〔2012〕8号）

全国文化系统思想政治工作研究会会员单位：

根据基层组织建设年关于加强党建课题研究的任务要求，为提高基层党建工作理论水平，更好地服务于基层党组织开展思想政治工作，经研究，在全国文化文物系统内开展2012年思想政治工作课题研究。现就有关事项通知如下：

**一、**总体思路

以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，认真贯彻党的十七大和十七届历次全会及文化部2012年党的工作会议精神，以迎接党的十八大和学习贯彻十八大精神为主线，坚持围绕中心、破解难题，努力增强党建工作的针对性和实效性，更好地为文化大发展大繁荣提供思想政治保障，以优异成绩迎接党的十八大胜利召开。

**二、**课题方向

1、党员干部模范践行社会主义核心价值体系研究。

2、党的十六大以来思想政治工作创新研究。

3、加强和改进党对文化工作的领导研究。

4、加强文化领域领导干部思想政治和品德修养研究。

5、加强文化领域党的基层组织建设研究。

6、加强党的舆论宣传和引导作用研究。

7、加强党员干部当代知识和历史文化知识教育研究。

8、建立健全党员队伍纯洁机制研究。

**三、**具体要求

（一）开展课题研究是研究会的重点任务，各会员单位要高度重视此项工作，切实加强领导和指导，为课题研究提供经费和人员等方面的支持，确保按时完成论文写作。

（二）论文要有观点、有分析、有材料、有事例，能对促进文化工作起到理论指导作用；文章要学理通畅，文风质朴，行文规范。4至5千字为宜。

（三）请于3月16日前将选报的课题以及课题负责人、联系人和联系电话报送我会秘书处（文化部直属机关党委办公室）；并8月底前将课题研究成果电子版发送我会邮箱（whblyh@126.com）。

拟于今年9月前后召开全国文化系统思想政治工作研讨会，届时将交流各会员单位的研究成果。
