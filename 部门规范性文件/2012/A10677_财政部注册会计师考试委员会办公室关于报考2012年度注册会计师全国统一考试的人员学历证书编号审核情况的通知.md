# 财政部注册会计师考试委员会办公室关于报考2012年度注册会计师全国统一考试的人员学历证书编号审核情况的通知

为了做好2012年度注册会计师全国统一考试报名工作，保证报名人员符合考试资格的要求，财政部考办将报考2012年度注册会计师全国统一考试专业阶段考试的人员学历证书编号交由有关机构进行了验证，少数报名人员未通过审核。财政部考办提醒，未通过审核的报名人员不能下载打印专业阶段准考证。如有疑问，请联系报名所在地的地方考办。

财政部注册会计师考试委员会办公室

二○一二年九月二十一日
