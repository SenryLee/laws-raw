# 国家文物局关于南山、青天河、松花湖风景名胜区总体规划的意见

## 国家文物局关于南山、青天河、松花湖风景名胜区总体规划的意见（办保函〔2012〕720号）

住房和城乡建设部办公厅：

你办《关于征求南山、青天河、松花湖风景名胜区总体规划意见的函》（建办城函〔2012〕406号）收悉。经研究，我局意见如下：

**一、**南山风景名胜区总体规划

（一）补充景区内文物资源的分布情况和价值评估，说明不可移动文物的位置、名称、保护现状，并深化保护管理要求。景区内的开发建设、旅游设施等项目应优先考虑文物古迹及周边环境的保护要求，要依法履行报批程序。明确文物保护单位的保护范围和建设控制地带等相关内容，涉及文物保护单位的保护管理，要注意与文物保护专项规划相衔接。

（二）进一步明确苗族村寨的整体保护原则。建议在第六章“风景资源保护与培育规划”第三节“分类保护规划”中单列“民族村寨保护”一款，将有关传统民居、苗族村寨和苗族非物质遗产保护等内容合并表述，并同时细化保护措施。涉及民族村寨的旅游发展、基础设施等规划与建设应在保护文化遗产历史的真实性、风貌的完整性，以及当地民众生活的延续性的前提下，注重与改善原住民居住条件和生活质量相结合。

（三）第三十八条“景点规划”中相应“恢复古城风貌”、“恢复街巷格局”等表述应取消。

（四）在景区分级保护规划图中补充不可移动文物和民族村寨分布的图例标注和名称。

**二、**青天河风景名胜区总体规划

（一）在基础资料汇编中，补充景区不可移动文物资源保存现状和价值评估等内容，提出保护清单。

（二）补充景区内文物保护单位的保护现状、价值评估等内容，景区的规划与建设要注意与青天河摩崖、月山寺与塔林等重要文物保护单位文物保护规划相衔接。

（三）按照《中华人民共和国文物保护法》的有关规定，应在规划中明确不可移动文物已经全部毁坏的，应当实施遗址保护，不得在原址重建。第三十一条“人文景观规划”中对于“复修龙亭、清风殿……”等月山寺建筑的复建应慎重，必须进行必要的可行性论证。有关武馆、月山禅院等建设项目要尽量避让文物保护单位的保护区域，并严格控制新建筑的规模、体量、形式。

（四）补充不可移动文物分布图，以及青天河摩崖和月山寺等文物保护单位的保护区划图。

**三、**松花湖风景名胜区总体规划

（一）补充文物保护单位的保护清单，说明其保护现状，明确其保护级别和保护区划，深化保护措施。严格控制新建筑的规模、体量、形式，避免新建建筑对文物保护单位周边环境造成不利影响。

（二）历史建筑的保护管理应执行《历史文化名城名镇名村保护条例》的有关规定。

（三）增加文物古迹分布图，补充文物保护单位的保护区划图。

专此函复。
