# 国家文物局关于拨付2012年度《文物》期刊出版经费的函

## 国家文物局关于拨付2012年度《文物》期刊出版经费的函（文物政函〔2012〕1001号）

文物出版社：

根据我局部门预算，现将2012年度《文物》期刊出版经费30万元拨付你社。请专款专用，严格支出管理，确保工作绩效。

专此。

国家文物局　　

二〇一二年五月十七日
