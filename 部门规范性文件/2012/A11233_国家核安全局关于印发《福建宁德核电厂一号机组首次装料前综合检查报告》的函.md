# 国家核安全局关于印发《福建宁德核电厂一号机组首次装料前综合检查报告》的函

## 国家核安全局关于印发《福建宁德核电厂一号机组首次装料前综合检查报告》的函（国核安函[2012]132号）

福建宁德核电有限公司：

根据国家核安全法规的有关要求，我局组织检查组于2012年8月6日至10日对你公司宁德核电厂一号机组首次装料前核安全和环境保护设施情况进行了综合检查。现将检查报告（附后）印发你公司，请采取有效措施，落实检查报告中提出的各项要求，确保宁德核电厂一号机组首次装料和运行安全。

附件：福建宁德核电厂一号机组首次装料前综合检查报告

国家核安全局

2012年9月7日

附件：

福建宁德核电厂一号机组首次装料前综合检查报告

检查单位名称：国家核安全局

受检单位名称：福建宁德核电有限公司

检查日期：2012年8月6-10曰

**一、**检查依据

（一）《中华人民共和国放射性污染防治法》；

（二）《中华人民共和国民用核设施安全监督管理条例》及其实 施细则；

（三）《中华人民共和国核材料管制条例》及其实施细则；

（四）《核电厂核事故应急管理条例》及其实施细则；

（五）《民用核安全设备监督管理条例》及配套文件；

（六）《放射性废物安全管理条例》；

（七）《核电厂质量保证安全规定》；

（八）《核动力厂设计安全规定》；

（九）《核动力厂运行安全规定》；

（十）《福岛核事故后核电厂改进行动通用技术要求（试行）》 （国核安发〔2012〕98号）；

（十一）《宁德核电厂一、二号机组最终安全分析报告》；

（十二）《宁德核电厂一、二号机组质量保证大纲（调试阶段）》；

（十三）《宁德核电厂一、二号机组调试大纲》；

（十四）核电厂建造、安装和调试适用的相关标准规范；

（十五）国家核安全局发布的核安全审评原则和管理要求等。

**二、**检查内容

（一）质量保证；

（二）构筑物和核安全设备；

（三）系统调试和生产准备；

（四）实物保护和燃料贮存；

（五）应急准备；

（六）辐射防护；

（七）环境保护设施；

（八）许可证条件、审评遗留问题和福岛改进项目落实。

**三、**检查活动

2012年8月6-10日，我局组织检查组对福建宁德核电厂一号机 组首次装料前核与辐射安全和环境保护设施情况进行了综合检查 （名单见附一）。检查组听取了福建宁德核电有限公司（以下简称 “营运单位”）关于工程进展、质量管理、调试状况、实物保护和 新燃料贮存、生产准备、辐射防护与应急准备、役前检查和环保设 施“三同时”等情况的工作汇报。在听取汇报的基础上，检查组对 一号机组的相关设施和系统的现场情况进行查勘，对建造、调试和 生产准备的相关文件、程序、报告和记录进行了抽查，并与有关技 术和管理人员进行了对话。营运单位对检查给予了积极配合（名单 见附二），检查达到了预期目的。

**四、**检查结论和要求

检查组认为，宁德核电厂一号机组设计、建造和装料前调试阶段 的质量保证工作基本有效；与核安全有关的活动处于受控状态；生 产准备工作有序进行；有关土建施工、设备制造和安装不符合项， 调试、役前检查结果异常报告和重要事件的处理满足相关程序的要 求；人员的配置和培训基本符合要求；环境保护设施基本满足首次 装料的需求。

检查组认为目前营运单位对宁德核电厂一号机组首次装料的准 备工作是可以接受的，同时提出如下核安全管理要求：

（一）质量保证

1. 针对管理巡视规定、人员培训规定、调试试验报告等文件存 在要求不统一、执行不够严格、记录遗漏等问题，营运单位应修订完善相关程序并严格执行，同时保证质保记录的准确性、完整性和 可追溯。

2.　针对主控室未严格执行人员出入控制并存放未生效图纸、个 别厂房施工现场杂物较多、个别设备标识制作和保养不符合要求、以及工艺评定报告转移控制不严等问题，营运单位应严格执行程序， 加强现场、文件和物项管理，保证工程收尾阶段各项工作的质量。

（二）构筑物和核安全设备

1.针对反应堆厂房氢气复合器的编码、安装位置均与最终安全 分析报告（FSAR）描述不一致的问题，营运单位应在首次装料前向 我局说明原因，论证氢气复合器布置是否满足核安全法规的要求； 同时釆取纠正措施，保证氢气复合器的现场布置与FSAR-致。

2. 针对一号机组反应堆冷却剂系统（RCP）、安全注入系统（RIS）、 佘热排出系统（RRA）、安全壳喷淋系统（EAS）、化学和容积控制 系统（RCV）和三废处理系统尚有部分尾项未完成的情况，营运单位 应全面梳理对核安全功能有影响的工程尾项，确保在首次装料前按照质保程序完成尾项处理和安全相关系统移交。

3. 针对反应堆水池不锈钢覆面、安全级泵阀等设备不符合项处 理未完成、部分不符合项没有进行原因分析或分析过于简单的情况，营运单位应釆取有效措施，加强不符合项处理；对于核安全相关不 符合项的原因进行深入分析，确保核安全设备的质量和系统安全功 能。

4. 针对安全壳1RC预应力53号水平钢束和1RX预应力79号水 平钢束张拉最终伸长值不符合设计规定，未提供接收依据就原样接 受的问题，营运单位应在首次装料前向我局提交该不符合项处理依

据。

5. 针对稳压器波动管安装焊缝2GT位置见证件代表性不足的问 题，营运单位应尽快按照规范要求重做焊接见证件，在首次装料前 提交该见证件试验结果及相应的分析材料，并排查其他见证件与产品焊缝的代表性问题。

6. 针对安全级数字化仪控系统（DCS）机柜房间部分电缆桥架容 积率超出设计容量的情况，营运单位应进一步分析部分DCS电缆桥 架容积率超出设计规范时对桥架抗震和通风散热的影响，积极釆取 可能的措施予以改善，做好后续机组的经验反馈工作。

（三）系统调试和生产准备

1. 针对三废处理、辐射监测等系统的部分调试试验项目尚未完 成，以及已完成的调试试验项目遗留项未处理完成的情况，营运单位应在首次装料前按照要求完成所有调试试验项目、遗留项的缺陷 处理和相关的验证工作。

2. 针对个别调试试验过程中存在的问题（如蒸汽发生器水位试 验中液位就地指示仪表未端接、应急柴油发电机组重新加载试验中 主控制室空调系统和核辅助厂房通风系统未投入等），营运单位应 在首次装料前重新完成相关试验，并进一步加强调试管理，严格执行调试程序，确保试验的完整性。

3. 针对营运单位确定的首次装料前系统移交清单不能完全满足 装料需要的问题，营运单位应对首次装料前移交系统清单进行评价和升版，并按升版后的清单完成系统移交，在首次装料前向我局提 交评价和系统移交情况报告。

4. 针对电气厂房、燃料厂房、核辅厂房和应急柴油机厂房的部 分区域核清洁未完成，尚不具备移交生产运行的条件的情况，营运单位应在首次装料前按照核清洁程序要求完成相关厂房的核清洁工 作，以满足首次装料的核清洁要求。

（四）实物保护和燃料贮存

1. 针对实物保护系统部分系统和设备尚未完成安装和调试、部 分区域存在薄弱环节等情况，营运单位应在首次装料前对实物保护系统进行排查，釆取有效措施全面消除实物保护系统缺陷和不足， 保证实物保护系统满足法规要求。

2. 针对实物保护管理程序不够完善的问题，营运单位应在首次 装料前完成实物保护相关管理程序的修订和发布。

（五）应急准备

针对应急指挥中心与备用应急指挥中心尚未建立数据传输专 线、人员电子清点系统未建成等问题，营运单位应进一步加快落实 《福建宁德核电厂1号机组首次装料前场内核应急综合演习及核应 急准备检查报告》（国核安函〔2012〕93号）中提出的核安全管理 要求，釆取有效措施，确保在装料前完成整改。

（六）辐射防护

1. 针对部分辐射防护文件不够规范等情况，营运单位应在首次 装料前完成辐射防护管理文件的修订，规范个人剂量管理，进一步加强辐射防护工作人员的培训。

2. 针对反应堆厂房和核辅助厂房辐射控制区的建立和隔离、辐 射控制区电离辐射标志和警告标志的悬挂等方面存在的问题，营运单位应在首次装料前完善卫生出入口管理，完成辐射控制区隔离、 电离辐射标志和警告标志的悬挂，并完成辐射防护仪器仪表和辐射 防护用品的配置工作。

3. 针对部分辐射监测系统未完全投入使用的情况，营运单位应 在首次装料前完成相应系统的安装、调试并投入使用。

（七）环境保护设施

1.针对废物管理大纲及配套程序文件尚待升版、放射性固体废 物处理系统（TES）的水泥固化线及相关厂房不可用期间的临时方案 的要求和安全承诺尚未完全反映到运行程序文件中的情况，营运单 位应在首次装料前修订和完善放射性废物管理文件，并将TES及相 关厂房不可用期间临时方案的要求和安全承诺进一步细化到具体操 作程序中。

2.针对部分三废处理系统尚未完成安装和调试，如热机修厂房 和仓库厂房的通风系统未完成调试、核辅助厂房通风系统（DVN）高 效过滤器芯和碘过滤器芯未安装等情况，营运单位应加快三废处理 系统的安装和调试，确保与首次装料相关的三废处理系统在首次装 料前可用。

（八）许可证条件、审评遗留问题和福岛改进项目落实

1. 针对循环冷却排水口整体工程施工仍未完成的情况，营运单 位应在首次装料前向我局提交循环冷却排水口未完工对核电厂安全影响的分析报告和下一步的工作计划。

2. 针对二号机组应急柴油发电机组（2LHQ）替代厂址附加柴油 机的情况，营运单位应尽快完成2LHQ替代附加柴油发电机的临时规 程的编制和调试工作，确保2LHQ在首次装料前可用。

3. 针对循环水过滤系统（CFI）反冲洗管线贯穿重要厂用水系统 （SEC）泵坑A、B列隔墙的问题，营运单位应在首次装料前完成SEC泵A、B列的隔离改造（包括A、B列贯穿件的封堵，管道防断裂分 析和支料架更换）。

4. 营运单位应进一步做好福岛核事故经验反馈，按照《福岛核 事故后核电厂改进行动通用技术要求（试行）》（国核安发〔2012〕 98号），继续落实福岛核事故后安全改进。

营运单位应根据上述要求，完成在首次装料前必须完成的工作， 并经华东核与辐射安全监督站监督核查后，现场方具备首次装料的 条件。
