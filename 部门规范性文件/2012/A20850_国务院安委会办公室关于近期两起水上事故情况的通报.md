# 国务院安委会办公室关于近期两起水上事故情况的通报

## 国务院安委会办公室关于近期两起水上事故情况的通报（安委办〔2012〕6号）

各省、自治区、直辖市及新疆生产建设兵团安全生产委员会：

2012年2月2日3时40分左右，湖北省监利三洲水运公司所属的“三洲666”号运砂船（核载1500吨、实载1450吨，载17人），装载砂石经洞庭湖水域由湖南省岳阳市运往湖北省武汉市，当该船锚泊于洞庭湖芦苇场小山塘水域避风时，突然发生侧翻，船上17人全部落水，其中6人被当地渔民救起，目前已造成9人死亡、2人失踪。

2月2日9时左右，广东省阳江市阳西县籍“粤阳西96196”号渔船（船上共有14名船员）航行至广东省汕尾市海域时，船体向左侧倾斜并翻沉，14名船员全部落水，其中4人被编队作业渔船救起，目前已造成3人死亡、7人失踪。

依据有关规定，国务院安委会已对上述两起事故的查处实行挂牌督办，查处结果将及时向社会公布。据初步调查分析，上述事故暴露出部分地区水上应急处置能力不足、运砂船舶和渔船管理不严、从业人员未持证上岗等突出问题。为深刻吸取事故教训，举一反三，切实加强水上交通和渔业船舶安全生产工作，有效防范和坚决遏制类似事故的发生，特提出以下要求：

**一、**认真开展水上交通和渔业船舶安全检查，及时排查治理安全隐患。各地区和各有关部门要按照《国务院安委会办公室关于认真贯彻落实国务院第六次全体会议和全国安全生产电视电话会议精神切实加强第一季度安全生产工作的通知》（安委办明电〔2012〕3号）要求，认真开展水上交通运输和渔业船舶安全生产检查，特别是针对第一季度水上大雾、大风、寒潮等恶劣和极端天气多发的特点，采取有效措施，排除安全隐患，防范和遏制重大水上事故发生。

**二、**进一步加强重点船舶、重点水域安全监管。各地区和各有关部门要切实抓好砂石开采和运输船舶安全监管，切实落实对砂石开采和运输船舶的监管措施，严厉打击非法、无序采砂、运砂行为。要加强规律性研究，分析砂石船舶活动规律，制定相应整治措施，探索建立砂石船舶安全管理长效机制。各级渔业主管部门要进一步加大渔业船舶安全监督检查力度，严查渔船救生设施的有效配备，AIS设备、卫星终端设备的开机使用，以及渔船船员培训和持证上岗等情况，严格渔船进出港签证管理。海事和渔业执法部门要加强重点水域、复杂水域、山区河流等水域通航秩序维护，加大巡航力度，严厉打击违章冒雾航行、非锚地锚泊等各种违反规定的运输和作业行为，加强有效联动，减少商船与渔船碰撞事故发生。

**三、**加强天气预报预警工作，提高应急处置能力。冬春季节是寒潮、大风、雾霾等水上恶劣天气多发时期，也是渔业生产旺季，各级交通海事和渔业主管部门要进一步做好水上灾害性天气预警工作，继续完善水上遇险与安全信息接收与播发网络，及时部署防抗台风、大雾等极端天气，督促航运公司、运输船舶和渔船落实各项安全措施和航行、作业要求，切实落实船长、船东安全生产主体责任，进一步提高船舶驾驶人员的安全责任意识和技能，保障航行和作业安全。要加强与气象部门的联系，密切关注天气和海浪变化情况，及时通过岸台、广播、手机短信等渠道将天气预报预警信息通知到航运企业、运输船舶和船东、渔船，并督促其及时采取相应的安全防范措施。相关部门和企业要制定水上安全应急预案，加强应急演练，提高船员和相关单位应对水上突发灾害事故的应急处置能力。

**四、**严肃事故查处，严格责任追究。各有关地区要严格按照《生产安全事故报告和调查处理条例》（国务院令第493号）的规定，坚持“四不放过”和“科学严谨、依法依规、实事求是、注重实效”的原则，认真组织事故调查，查清事故原因，认定事故性质，总结事故教训，严肃追究事故责任，对于在事故中负有领导、监督、管理责任的单位和人员，要依法依规严肃处理。要认真执行事故查处挂牌督办制度，确保事故按期结案，及时向社会公布调查处理结果，并跟踪督促事故责任和整改措施的落实。

国务院安全生产委员会办公室
