# 农业部办公厅关于报送全国人大重点处理建议支持宁夏建设马铃薯种薯基地2012年追踪办理工作方案的函

## 农业部办公厅关于报送全国人大重点处理建议支持宁夏建设马铃薯种薯基地2012年追踪办理工作方案的函（农办计函[2012]57号）

全国人大常委会办公厅联络局：

按照《关于做好全国人大代表重点处理建议追踪办理工作的函》（常办联字[2012]23号）的要求，我部起草了关于支持宁夏建设马铃薯种薯基地重点建议的追踪办理工作方案，并征求了国家发展改革委、财政部的意见。现将追踪办理工作方案送上。下一步将按照工作方案认真做好重点建议办理工作。

二〇一二年四月二十八日

附件：

关于全国人大重点处理建议支持宁夏建设马铃薯种薯基地2012年追踪办理工作方案

《关于支持宁夏建设马铃薯种薯基地的建议》是2009年全国人大8个重点处理建议之一。按照全国人大常委会的要求，农业部会同国家发展改革委、财政部于当年按时完成了建议答复工作。为了进一步按照答复意见有序推进落实工作，本着坚持实事求是、尊重客观规律、加强调查研究、认真履行职责的原则，2012年追踪办理工作将按如下方案进行。

**一、**追踪重点

依据《对十一届全国人大二次会议第1022号建议的答复》（农办议[2009]357号），重点追踪以下三个方面内容：

（一）继续跟踪了解宁夏马铃薯种业发展状况，提出种业发展建设性意见。了解宁夏脱毒种薯在茎尖脱毒、脱毒苗分段繁育、原原种、原种、一级种薯、二级种薯的产销、成本以及质量控制等情况，分析宁夏脱毒马铃薯种薯基地建设投入产出效益。研究我国脱毒种薯推广迟缓的症结，探索适合我国国情的脱毒马铃薯产业发展之路。

（二）跟踪了解2009年以来支持宁夏马铃薯种薯基地建设的各项投资落实情况，提出增强项目建设效益的建设性意见。

（三）跟踪了解宁夏在脱毒马铃薯种薯基地建设中的可行做法和有益经验。重点了解宁夏在种薯基地建设中出台的一系列政策措施，各种投入的组织方式，建立的长效机制和促进产业可持续发展的措施。

**二、**主要措施

（一）加强各方沟通合作。农业部、国家发展改革委、财政部要根据各自职能，在宁夏相关部门积极配合下，努力推进重点建议办理落实工作，能够提前落实的要提前落实，难以落实的要及时作出说明，提出解决办法。

（二）加强实地调查研究。本着求真务实原则，认真开展调研，加强相关部委间以及宁夏相关部门的情况交流，在采取电话沟通、统计报表等方式调查的同时，重点开展实地调研，进一步摸清重点建议进展情况、基地建设的有益经验，密切与代表的沟通联系。

（三）实施项目进度跟踪。协调会办部委及其宁夏对口部门，加强对已立项项目资金到位、项目开工和进展情况的追踪统计工作；组织有关专家对在建项目进行中期评估和检查，敦促建成项目抓紧竣工验收，进一步发挥项目建设效益。

**三、**进度安排

（一）4月，起草2012年重点建议追踪办理工作方案，经征求国家发展改革委、财政部意见并完善后，报送全国人大常委会办公厅，抄送全国人大民委。

（二）5月，启动重点建议办理追踪工作方案，落实调研沟通工作的具体分工，拟定报表统计工作。

（三）6月－9月，按照任务分工，积极落实重点建议的各项措施，开展实地调研工作，交流重点建议办理情况。

（四）9月上中旬，各协办部门按照分工，在宁夏相关部门的配合下，总结重点建议落实情况，并书面函告农业部。

（五）9月下旬至10月中旬，农业部草拟重点建议办理工作情况，征求国家发改委、财政部意见后，报全国人大常委会办公厅。

二〇一一年四月二十七日
