# 中国证券监督管理委员会创业板发审委2012年第25次会议审核结果公告

中国证券监督管理委员会创业板发行审核委员会2012年第25次会议于2012年4月10日召开，现将会议审核结果公告如下：

杭州泰格医药科技股份有限公司（首发）获通过。

无锡上机数控股份有限公司（首发）未通过。

创业板发行监管部
