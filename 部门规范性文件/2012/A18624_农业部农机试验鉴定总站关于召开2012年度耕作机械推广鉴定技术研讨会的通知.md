# 农业部农机试验鉴定总站关于召开2012年度耕作机械推广鉴定技术研讨会的通知

## 农业部农机试验鉴定总站关于召开2012年度耕作机械推广鉴定技术研讨会的通知（农机鉴[2012]57号）

各有关单位：

为做好耕作机械部级推广鉴定工作，交流行业先进技术，促进行业又好又快发展，定于2012年4月下旬在重庆市召开2012年度耕作机械推广鉴定技术研讨会。现将有关事项通知如下：

**一、**会议内容

（一）介绍农机化发展及推广鉴定工作的新要求；

（二）介绍耕作机械部级推广鉴定工作程序；

（三）研讨微型耕耘机推广鉴定大纲；

（四）研讨耕整机推广鉴定大纲；

（五）研讨深松耕整地联合作业机推广鉴定大纲；

（六）研讨农业机械推广鉴定通则TZ4-2011《生产条件审查》。

**二、**参加人员

农机化司有关领导，总站相关人员，耕作机械（微耕机、耕整机、深松整地联合作业机等）生产企业质量负责人及质量管理部门负责人，有关省（区、市）农（牧）机试验鉴定站主管领导或相关业务处室负责人。

**三、**会议时间、地点

会议日期：2012年4月22日报到，23日至24日开会。

会议地点：重庆君巢酒店（地址：重庆市松树桥红石路150号聚信广场A栋）

酒店总机：023-67768544

乘车路线：

1.龙头寺火车站：乘车709路、201路、202路、820路到龙溪建材市场下车即到；乘出租车到酒店约15分钟，需15元左右。

2.菜园坝火车站： 乘车115路、120路到龙溪建材市场下车即到；乘出租车到酒店约15分钟，需15元左右。

3.江北国际机场：乘机场大巴到可乘座机场巴士（15元）到江北海关站下车，可乘121路，114路到龙溪建材市场下车即到；乘出租车到酒店约25分钟，需40元左右。

1、会议由北京燕泰会议服务有限公司承办。会议收取会议费、资料费共1300元/人，食宿统一安排，费用自理。
