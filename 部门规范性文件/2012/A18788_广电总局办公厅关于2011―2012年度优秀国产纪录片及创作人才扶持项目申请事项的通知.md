# 广电总局办公厅关于2011―2012年度优秀国产纪录片及创作人才扶持项目申请事项的通知

## 广电总局办公厅关于2011－2012年度优秀国产纪录片及创作人才扶持项目申请事项的通知（广办发宣字〔2012〕41号　2012年3月21日）

各省、自治区、直辖市广播影视局，新疆生产建设兵团广播电视局，中央电视台、中国电影集团公司、中央新影集团、中国教育电视台、解放军总政宣传部、中直有关单位：

根据《广电总局关于加快纪录片产业发展的若干意见》精神，国家广电总局制定了《2011-2012年度优秀国产纪录片及创作人才扶持项目评审办法（试行）》，并将开展相应评审工作。现将有关事项通知如下：

**一、**申请2011-2012年度优秀国产纪录片及创作人才扶持项目，其作品须为2011年1月1日至2012年6月1日，在国内广播影视播映机构首次播映的国产纪录片。

**二、**申请优秀国产纪录片导演、编剧、短片、中篇、长篇项目，从2012年广电总局第一、二批推荐的优秀国产纪录片中产生。

**三、**广电总局每批推荐的优秀国产纪录片，将通过国家广电总局政府网站向全社会公布，并书面通知各单位。

**四、**请各省级广播影视行政部门、解放军总政宣传部和中直有关单位、中央电视台、中国电影集团公司、中国教育电视台，向所辖（属）国产纪录片制作机构、播映机构传达本通知精神，并按照《2011-2012年度优秀国产纪录片及创作人才扶持项目评审办法（试行）》要求，认真做好本地区、本系统、本单位优秀国产纪录片及创作人才扶持项目的申请组织工作。

**五、**申请2011-2012年度优秀国产纪录片及创作人才扶持项目，请于2012年8月10日前，将申请材料寄至国家广电总局宣传管理司宣传处（地址：北京复兴门外大街2号，邮编：100866），申请材料要求详见《2011-2012年度优秀国产纪录片及创作人才扶持项目评审办法（试行）》第十条。

2011-2012年度优秀国产纪录片及创作人才扶持项目评审办法（试行）

**一、**广电总局设立优秀国产纪录片及创作人才扶持项目（以下简称“扶持项目”），以专项资金鼓励和扶持国产纪录片的创作、生产和播出。

**二、**扶持项目由广电总局组织评审委员会，对申报扶持项目的作品、栏目和机构进行评审。

**三、**扶持项目评审分初评、复评两个阶段进行。初评、复评结果将在广电总局政府网站上公布，接受社会监督。

凡发现弄虚作假等不良现象，一经核实，立即取消其今后参评资格，并向社会公布。

**四、**扶持项目共设9个类别，分别为：优秀国产纪录片导演、优秀国产纪录片编剧、优秀国产纪录片短片、优秀国产纪录片中篇、优秀国产纪录片长篇、优秀国产纪录片制作机构、优秀国产纪录片栏目、优秀国产纪录片播出机构、优秀国产纪录片组织机构。

**五、**扶持项目中优秀国产纪录片导演、编剧、短片、中篇、长篇项目，从获广电总局推荐的优秀国产纪录片中产生。

扶持项目中优秀国产纪录片制作机构、栏目、播出机构、组织机构项目，须参考获广电总局推荐优秀国产纪录片的制作、播出和组织参评情况。

非汉语普通话国产纪录片、栏目、机构，不参加扶持项目评审。

**六、**扶持项目各项目内分别按专业水准、作品质量、产量、播出量、国产与引进纪录片播出比例排序，以广电总局扶持项目评审委员会评审结果为准。

**七、**获评扶持项目，均可获得相应资金扶持。扶持金额依照每年度扶持项目专项资金额度、获评项目类别和在所获评项目中的排序确定。

扶持资金须用于鼓励创作、生产、播出优秀国产纪录片和扶持国内优秀纪录片创作人才。

**八、**各省级广播影视行政部门负责组织所辖区域内扶持项目工作，确定符合本《办法》和申报项目要求，报广电总局扶持项目评审委员会评审。

解放军总政宣传部负责组织部队系统扶持项目工作，确定符合本《办法》和申报项目要求，报广电总局扶持项目评审委员会评审。

中直有关单位、中央电视台、中国电影集团公司、中央新影集团、中国教育电视台负责组织本单位扶持项目工作，确定符合本《办法》和申报项目要求，报广电总局扶持项目评审委员会评审。

各单位申报参评优秀国产纪录片栏目、优秀国产纪录片制作机构、优秀国产纪录片播出机构的数量各不超过3个。

优秀国产纪录片组织机构，由广电总局扶持项目评审委员会根据各申报单位的业绩评定。

**九、**扶持项目评审坚持社会主义先进文化前进方向，坚持为人民服务、坚持为社会主义服务，坚持百花齐放、百家争鸣，坚持贴近实际、贴近生活、贴近群众；按照客观公正、优中选优的原则，鼓励弘扬社会主义核心价值体系，体现中国特色、民族特色和时代特色，内容积极向上，思想性艺术性观赏性相统一的优秀国产纪录片；扶持社会责任感强、思想端正、业务精湛、作风优良的纪录片创作优秀人才；扶持实力雄厚、资源充足、创作力量强、制作水平高的国产纪录片制作机构；扶持不断扩大国产纪录片播映规模，积极展播展映国产纪录片，努力拓展国产纪录片市场的栏目和播出机构。

（一）优秀国产纪录片导演，要坚持“二为”方向和“双百”方针，贴近实际、贴近生活、贴近群众，弘扬主旋律，提倡多样化，遵循国产纪录片艺术规律，具有独到的导演手法和出色的实践能力，作品表现手法运用得当，作品思想性、艺术性、观赏性相统一。

（二）优秀国产纪录片编剧，要坚持“二为”方向和“双百”方针，贴近实际、贴近生活、贴近群众，弘扬主旋律，提倡多样化，遵循国产纪录片艺术规律，体现出高超的创意能力，充分考虑目标受众的接受特点，思想性、艺术性、观赏性相统一。

（三）优秀国产纪录片短片、中篇、长篇，要积极展示当代中国精神风貌，记录中国社会历史发展重要进程，弘扬中华民族优秀传统文化，展现中国优美自然风光，传播科学思想文化，普及科学技术知识。

优秀国产纪录片短片，作品总长度为120分钟以内；优秀国产纪录片中篇，作品总长度为120分钟至300分钟；优秀国产纪录片长篇，作品总长度为300分钟以上。

（四）优秀国产纪录片制作机构，年度所生产且具有自主知识产权的国产电视纪录片须在100小时以上，能够主动参与国产纪录片宣传、推广及市场交易等相关工作，对国产纪录片产业发展起到积极的市场推动作用，运营良好，具备可持续发展能力。

（五）优秀国产纪录片栏目，要积极播出国产纪录片，并具有较好的社会影响力，年度播出国产纪录片占比70％以上，每期播出时长不少于15分钟，播出周期不低于每周一期。能够主动参与国产纪录片的制作、播出、推广及市场交易等相关工作，对国产纪录片产业发展起到一定的市场推动作用，运营良好，具备可持续发展能力。

（六）优秀国产纪录片播出机构，应具有较大的社会影响力，积极播出国产纪录片，年度播出国产纪录片须在1000小时以上，所播国产纪录片占比在70％以上。同时，能够积极扶持国产纪录片创作生产，主动参与国产纪录片的投资、制作、播出、推广及市场交易等相关工作，对国产纪录片产业发展起到有力的市场推动作用。

（七）优秀国产纪录片组织机构，应在扶持项目申报和年度推荐优秀国产纪录片工作中，全面落实广电总局有关要求，积极主动、组织有力、扎实认真，能够充分反映出本地区、本系统、本单位国产纪录片创作、生产、播出、推广、交易成果。

**十、**申报扶持项目，需提供以下材料：

1.省级广播影视行政部门的申报说明文件1份；

2.申请表一式2份；

3.国产纪录片光盘1套；

4.申报优秀国产纪录片栏目，须提供5期节目的DVD光盘1套、栏目年度国产纪录片的播出总量及国产、引进纪录片播出比例。同时，须按要求，提供年度内指定时期节目排播情况。

5.申报优秀国产纪录片制作机构，须提供机构年度国产纪录片产量，合拍片需单独说明。

6.申报优秀国产纪录片播出机构，须提供年度国产纪录片的播出总量、国产纪录片的外购（非本单位制作）比例、国产与引进纪录片播出比例。同时，须按要求，提供年度内指定时期节目排播情况。

**十一、**2011-2012年度扶持项目参评作品、栏目、机构的计算时间为：2011年1月1日至2012年6月1日。

**十二、**广电总局宣传管理司负责受理优秀国产纪录片及创作人才扶持项目申报材料。

**十三、**本办法由广电总局负责解释。

**十四、**《国产纪录片及创作人才扶持项目评审办法（试行）》（广办发宣字[2011]41号）自本《办法》发布之日起废止。
