# 教育部关于陈春阳等职务任免的通知(2012)

## 教育部关于陈春阳等职务任免的通知（教任[2012]58号）

西南交通大学：

经研究决定，任命陈春阳为西南交通大学校长，蒋葛夫、陈志坚、范平志、彭新实、蒲云、张文桂、冯晓云为西南交通大学副校长，免去濮德璋、蔺安林的西南交通大学副校长职务。

中华人民共和国教育部

二○一二年七月二十日
