# 国家发展和改革委员会公告2012年第26号――关于公布2012年工程咨询单位资格名单的公告

## 国家发展和改革委员会公告（2012年第26号）

根据《工程咨询单位资格认定办法》（中华人民共和国国家发展和改革委员会令第29号）、《国家发展改革委关于适用〈工程咨询单位资格认定办法〉有关条款的通知》（发改投资〔2009〕620号）的有关规定，现将国家发展改革委批准的2012年工程咨询单位资格名单予以公告。未予批准的，我委将通过有关初审机构告知申请人。工程咨询单位资格证书由中国工程咨询协会协助我委颁发。

附件：国家发展改革委批准的2012年工程咨询单位资格名单（略）

国家发展和改革委员会

2012年8月15日
