# 农业部关于切实做好2012年草原火灾防控工作的通知

## 农业部关于切实做好2012年草原火灾防控工作的通知（农牧发[2012]3号）

有关省、自治区草原防火指挥部、畜牧（农牧、农业）厅（局），新疆生产建设兵团草原防火指挥部、畜牧兽医局，黑龙江省农垦总局：

据农业部监测，2011年全国草原植被总体长势较好。随着草原生态补助奖励机制政策的实施，草原植被不断恢复，草原可燃物增多，草原火险等级升高。今年是实施草原生态保护补助奖励机制政策见成效的关键一年，党的十八大也即将在今年召开，做好今年的草原防火工作，任务艰巨、责任重大。各级草原防火主管部门要深刻认识做好今年草原防火工作的极端重要性，切实增强责任感和使命感，确保今年草原火灾防控各项工作落到实处。

**一、**落实防火条例，依法构建长效机制

深入学习贯彻落实《草原防火条例》，加快推进草原防火工作法制化建设，完善各项制度，实行依法治火。各级草原防火部门要在当地政府的领导下，进一步强化草原防火工作行政领导负责制和责任追究制，形成政府全面负责、部门齐抓共管、群众广泛参与的工作机制。要积极争取各级政府加强对草原防火宣传、监测预警、防火巡查和火灾隐患排查等各项工作的支持，构建草原防火物质保障长效机制。

**二、**加强防火宣传，提高全社会防火意识

要加大工作力度，创新工作机制，对《草原防火条例》和草原防扑火知识进行深入广泛的宣传。通过采取召开现场会、出动宣传车、发放明白纸、印制标语、公益广告、开展宣教和座谈等多种形式，提高全民的草原防火意识。着力推进草原防火知识上电视、上报刊、上网络、进课堂、进教材、进生产企业、进社区、进牧户，增强全社会和广大农牧民的扑火救灾和紧急避险知识，营造草原火灾群防群控的社会环境。

**三、**强化演练培训，提升应急队伍素质

不断完善和落实各级草原火灾应急预案，深入开展实战演练和培训工作，切实提升应急队伍素质。草原防火值班人员要熟练掌握值班工作规程、草原火情信息报送要求和信息传递流程，确保信息畅通。应急指挥人员要通晓应急工作程序和草原火灾扑救战术，提高指挥调度工作水平。扑火队员要融会贯通扑火技术战术，熟悉紧急避险方式方法，熟练掌握扑火机具的使用和保养，提高作战能力。

**四、**加强防火督查，彻底消除火灾隐患

我部将派出督查组赴内蒙古、新疆等重点草原防火区进行督查。有关省、市、县各级草原防火部门要加大督查工作力度，深入火险区县、乡、村、牧场，对草原火灾危险源进行检查监控，责成有关人员落实安全责任和防范措施。切实加强边境草原防火隔离带建设，防止外火入侵、内火外延。进一步规范和严格野外用火审批制度，加强对生产生活用火的指导和管控。在草原防火管制区和管制期，禁止野外用火。在“两会”、“清明”、“五一”、“十一”等重要时期，要确保人员到位，防扑火物资落实，重点部位全天候防范，采取严控措施，杜绝野外用火行为，彻底消除火灾隐患。

**五、**强化应急处置，努力减轻危害程度

各草原防火部门要积极落实专项资金，保证草原防火网络服务器可靠运行，并落实专人填报有关信息，确保草原防火综合系统真正发挥作用。在草原防火期，各级草原防火部门要严格执行值班制度，安排经过培训熟练掌握应急程序和应急系统软件设备操作的人员值班，切实做好对草原火情的监测报告和处置，确保火情信息及时上传下达。一旦发生火灾，迅速启动应急预案相应级别应急响应程序，及时报告火情动态，坚决杜绝火情报告不及时和信息内容不全面不客观现象的发生。各扑火队伍要做好扑救草原火灾的各项准备，做到发现火情能迅速出动扑救，积极消灭火灾，尽最大努力减轻火灾造成的损失。
