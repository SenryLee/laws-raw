# 环境保护部公告2012年第19号――关于批准建设项目环境影响评价资质(2012年第一批)的公告

## 环境保护部公告（2012年第19号）

关于批准建设项目环境影响评价资质（2012年第一批）的公告

根据《建设项目环境影响评价资质管理办法》（原国家环境保护总局令第26号）的有关规定，我部对申请建设项目环境影响评价资质（以下简称“资质”）的单位进行了审查。现将资质批准有关事项（2012年第一批）公告如下：

**一、**批准以下十家单位资质中的评价范围调整（调整的评价范围详见附件一）：

（一）山东省环境保护科学研究设计院

（二）中国工程物理研究院

（三）核工业二○三研究所

（四）河北水美环保科技有限公司

（五）兴安盟八思巴环境技术咨询有限公司

（六）江苏省交通规划设计院股份有限公司

（七）中国瑞林工程技术有限公司

（八）潍坊市环境科学研究设计院有限公司

（九）珠江水利委员会珠江水利科学研究院

（十）甘肃经纬环境工程技术有限公司

**二、**批准以下三家单位资质中的机构名称变更（变更后的机构名称详见附件一）：

（一）环境保护部环境发展中心

（二）常州市环境保护研究所

（三）苏州市环境工程有限责任公司

**三、**批准中国原子能科学研究院等34家单位建设项目环境影响评价资质延续（其中8家单位评价范围予以缩减，单位名单及评价范围详见附件二）。各单位在原有资质有效期之内，已与建设单位签订环境影响评价技术咨询合同的项目，超出此次批准的评价范围的，应于2012年3月31日前，将申请继续完成原项目的书面请示及项目清单和相应的合同复印件报我部备案，经我部审核后，方可继续完成。

**四、**同意以下13家单位资质中的法定代表人和（或）住所变更：

（一）环境保护部南京环境科学研究所

（二）青岛中油华东院安全环保有限公司

（三）朝阳市环境科学研究院

（四）宝钢工程技术集团有限公司

（五）上海辐达环保技术有限公司

（六）常州市环境保护研究所

（七）浙江省环境工程有限公司

（八）厦门嵩湖环境技术开发有限公司

（九）英德市德宝环境保护服务有限公司

（十）深圳市银台环保工程技术有限公司

（十一）钦州市环境科学研究所

（十二）中国航天科工集团○六一基地

（十三）陕西电力科学研究院

**五、**对遗失资质证书副本的江苏省设备成套有限公司予以补发证书。

请上述第一至五项中的单位于60日内，到指定领证地点领取资质证书，其中第二项中的单位应在领取资质证书前，办理环境影响评价专职技术人员岗位证书变更和环境影响评价工程师登记手续；第一至四项中的单位应在领证时携带原资质证书正、副本原件；第五项中的单位携带原资质证书正本原件。自本公告发布之日起，上述第一至四项中的单位原资质证书正、副本原件及其缩印件同时作废，不得继续使用。
