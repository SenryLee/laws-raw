# 审计署关于公布2012年审计署优秀博士学位论文名单的通知

各省、自治区、直辖市和计划单列市、新疆生产建设兵团审计厅（局），署机关各单位、各特派员办事处、各派出审计局，南京审计学院：

为了推动国家审计理论研究，引导和鼓励国内高等院校和科研院所博士生研究国家审计理论，加强理论研究人才队伍建设，培养高层次审计人才，促进国家审计事业健康发展。根据《审计署优秀博士学位论文评选办法》精神，审计署科研所组织开展了2012年审计署优秀博士学位论文评选工作。经专家评审委员会评审，审计长办公会议审定，并通过60天的公示，确定财政部财政科学研究所徐永胜《经济社会转型中的公共预算监督：体系构建与制度创新》等10篇博士学位论文获得优秀论文奖，其中2篇论文获得优秀论文特别奖（见附件）。现予公布。
