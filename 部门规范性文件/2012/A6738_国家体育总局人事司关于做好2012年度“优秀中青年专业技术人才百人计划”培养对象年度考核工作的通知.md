# 国家体育总局人事司关于做好2012年度“优秀中青年专业技术人才百人计划”培养对象年度考核工作的通知

各有关省、自治区、直辖市、新疆生产建设兵团体育局，各有关直属单位，各共建体育院校：

为加强对“优秀中青年专业技术人才百人计划”培养对象（以下简称“百人计划”培养对象）的跟踪培养和动态管理，根据《国家体育总局“优秀中青年专业技术人才百人计划”实施办法（试行）》有关规定，现就做好2012年度“百人计划”培养对象年度考核工作有关事项通知如下：

**一、**考核对象

“百人计划”培养对象。

**二、**考核内容与形式

考核内容以“百人计划”培养对象年度专业技术工作业绩为主（具体内容详见《“百人计划”培养对象年度进展报告》）。

考核采取个人如实填报《“百人计划”培养对象年度进展报告》、所在单位进行考核后签署考核意见的方式，考核结果分为优秀、合格、基本合格和不合格等四个等次。其中，各省区市体育局所属单位“百人计划”培养对象的考核结果需报上级人事主管部门复核并签署复核意见。

**三、**考核时间和报送材料要求

考核工作从发文之日起至2013年1月25日结束。请有关单位在2013年2月1日前将《“百人计划”培养对象年度进展报告》一式一份及其电子稿报送体育总局人事司。

**四、**其它事项

（一）各单位要重视考核工作，实事求是反映“百人计划”培养对象的有关情况。

（二）因特殊原因未能如期参加考核的人员，所在单位应出具书面说明材料，对逾期未报送考核材料的视为不参加考核。

（三）对不参加考核或考核结果为不合格的人员，将取消其“百人计划”培养对象资格。
