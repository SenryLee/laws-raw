# 教育部办公厅关于召开全国职业院校德育创新暨校园文化建设工作座谈会的通知

## 教育部办公厅关于召开全国职业院校德育创新暨校园文化建设工作座谈会的通知（教职成厅函[2012]27号）

各省、自治区、直辖市教育厅（教委），各计划单列市教育局，新疆生产建设兵团教育局，有关单位：

为加强和创新职业院校德育工作，展示职业院校校园文化建设成果，我部定于2012年6月28日在天津召开全国职业院校德育创新暨校园文化建设工作座谈会。现将有关事项通知如下。

**一、**会议内容

总结、交流各地各职业院校开展德育工作的经验和做法，探索职业院校德育创新的载体和途径，展示职业院校师生良好的精神风貌，分析当前职业院校德育工作面临的新形势、新任务，部署近一个时期职业院校德育工作。

**二、**会议时间、地点

时间：2012年6月28日下午2：00～5：00

地点：天津海河文华大酒店（天津市津南区海河教育园区新慧路2号）

**三、**与会人员

1.各省（区、市）教育厅（教委），各计划单列市和新疆生产建设兵团教育局分管职业教育的负责人，主管职业教育及德育工作有关处室负责人。

2.行业职业教育教学指导委员会代表。

3.职业院校负责人代表（由省级教育行政部门推荐，每省2～3人）。

4.中央文明办、共青团中央、人力资源和社会保障部、天津市政府、中华职业教育社有关部门负责人，教育部有关司局和直属单位负责人。

**四、**其他事项

1.请于2012年6月21日前将会议回执（见附件）传真至天津市教委职业技术教育中心。

2.请与会人员于6月27日（全天）到天津赛象酒店（天津华苑新技术产业园区梅苑路8号，电话：022-23768888）报到。如需接站，请在会议回执中注明。
