# 国家体育总局办公厅关于举办2012年竞技体育后备人才训练管理赴英国研修班的通知

各省、自治区、直辖市体育局，有关体育院校：

按照国家体育总局2012年培训工作计划，由体育总局青少司主办，体育总局干部培训中心承办的2012年竞技体育后备人才训练管理赴英国研修班将于2012年9月举办。现将有关事宜通知如下：

**一、**培训时间及地点

培训时间：2012年9月6日-29日。

国内预培训（9月6日-8日），在总局干部培训中心（北京体育大学内）进行。国外培训（9月9日-29日），在英国进行。

**二、**培训对象及要求

（一）各省、自治区、直辖市体育局负责青少年体育工作处级管理干部，各级各类体校校长或教练员；

（二）身体健康，工作5年以上，年龄不超过50岁。

**三、**培训内容

（一）英国青少年体育管理体制

（二）英国青少年运动员选材与人才培养渠道

（三）英国青少年体育运动训练模式

（四）英国青少年体育竞赛体系

（五）英国运动员学习、就业、社会保险等现状

（六）英国社会俱乐部与学校青少年体育发展情况

（七）英国青少年体育训练场馆、设施考察

（八）英国青少年体育发展经验总结与借鉴

**四、**培训经费

国内、外培训相关费用由学员所在单位负担，每位学员约54000元，并根据实际支出多退少补。国内培训往返交通费由学员所在单位负担。

**五、**有关要求

（一）各单位可推荐1-2名学员报名，请务必将推荐学员排序，我们将按照有关要求择优录取23人参加培训。

（二）推荐单位须签订出国培训承诺书。

（三）推荐人选须填写英国模拟签证表。

（四）请各单位高度重视参训人员的选拔和推荐工作，并于6月18日前将推荐人选名单报送至总局干部培训中心。
