# 中国共产党国家民族事务委员会党组关于杨崇清等3同志任职的通知

## 中国共产党国家民族事务委员会党组关于杨崇清等3同志任职的通知（民党发〔2012〕1号）

民族文化宫：

经研究决定，杨崇清同志任民族文化宫正司级调研员，肖志强、刁德俊同志任民族文化宫副司级调研员，任职时间从2012年1月17日算起。

中国共产党国家民族事务委员会党组

二○一二年二月二日
