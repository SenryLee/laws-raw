# 国家电力监管委员会关于三峡水力发电厂等45家企业标准化一级企业的公告

2012年12月14日，电监会安全监管局组织审核专家组对三峡水力发电厂等45家企业一级标准化企业评审报告（以下简称《评审报告》）进行了审核，审核专家组原则同意上述45个《评审报告》通过审核。按照《电力安全生产标准化达标评级管理办法》和《电力安全生产标准化达标评级实施细则》，现公告如下：
