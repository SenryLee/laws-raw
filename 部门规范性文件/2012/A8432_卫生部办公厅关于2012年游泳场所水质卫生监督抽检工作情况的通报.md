# 卫生部办公厅关于2012年游泳场所水质卫生监督抽检工作情况的通报

## 卫生部办公厅关于2012年游泳场所水质卫生监督抽检工作情况的通报（卫办监督发〔2012〕139号）

各省、自治区、直辖市卫生厅局，新疆生产建设兵团卫生局，中国疾病预防控制中心、卫生部卫生监督中心：

根据《卫生部办公厅关于印发2012年卫生监督重点检查计划的通知》（卫办监督发〔2012〕30号）的工作安排，我部于2012年6月至9月在全国范围内组织开展了游泳场所水质卫生监督抽检工作。现将有关情况通报如下：

**一、**组织实施情况

为进一步加强2012年夏季游泳场所的卫生监管工作，保障游泳者的健康和人身安全，各地按照我部工作要求，精心部署游泳场所专项监督检查工作，制定具体实施方案，明确提出了监督检查的工作目标、措施及要求，认真落实各项工作任务。北京、天津、辽宁、上海、浙江、宁夏等省（区、市）注重对游泳场所经营者的培训和指导，召开会议，组织培训，强化经营者卫生安全第一责任人的意识，要求经营者自觉履行《公共场所卫生管理条例实施细则》和《游泳场所卫生规范》的相关要求。在夏季游泳高峰期，北京、河北、上海、安徽、浙江、云南、宁夏等省（区、市）充分利用电视台、网络、报刊等公共媒体平台公布游泳场所卫生监督动态信息，扩大了卫生监督执法工作的公信力和影响力，强化了政府监管效果，收到了良好的社会效应。

**二、**游泳池水质卫生状况

2012年，我部共对全国8135家游泳池（馆）水质进行卫生抽检，共检测游泳池水细菌总数样品21580份，其中20274份合格，合格率为93.9%；共检测游泳池水大肠菌群样品21572份，其中21033份合格，合格率为97.5%；共检测游泳池水尿素样品21020份，其中18860份合格，合格率为89.7%；共检测游泳池水浑浊度样品21503份，其中21343份合格，合格率为99.3%；共检测游泳池水余氯样品20944份，其中17710份合格，合格率为84.6%；共检测游泳池水PH样品18866份，其中18280份合格，合格率为96.9％；共检测浸脚消毒池水余氯样品10910份，其中9742份合格，合格率为89.3%。与2011年同期相比，细菌总数、大肠菌群、余氯合格率均有提高。

检测结果显示，游泳池水尿素、余氯合格率较低。部分游泳场所未按照相关卫生要求在开放时间内做到每日定时补充一定量新水，池水更新不够，不能保证池水有良好的卫生状况，造成尿素超标。部分游泳场所硬件设施设备仍不能满足接待需要，浸脚池设置使用不规范、池水消毒剂投加不符合要求，自动消毒设施损坏未及时维修等问题，造成余氯合格率偏低，对游泳者卫生安全产生一定隐患。

**三、**下一步工作

（一）针对目前游泳场所存在的主要问题，加强指导，督促经营者及时整改，尽快达到有关卫生规范和标准要求。对整改不力或拒不整改的，必须加大监督执法力度，依法从严查处，并将查处结果向社会通报。

（二）进一步强化游泳场所经营者是卫生安全第一责任人的意识，提高其自觉守法意识，督促其切实落实游泳场所各项卫生管理制度和措施，进一步规范水质信息公示，确保游泳场所卫生安全。

（三）积极推进游泳场所卫生监督信息公示制度，将监督检查结果通过电视台、网络、报刊等公共媒体及时向社会公告，加大社会监督力度。同时要提醒广大群众尽可能选择到卫生条件好、设施齐备齐全、管理规范的游泳场馆进行娱乐休闲。
