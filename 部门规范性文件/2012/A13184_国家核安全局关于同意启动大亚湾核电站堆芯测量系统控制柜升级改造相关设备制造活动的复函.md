# 国家核安全局关于同意启动大亚湾核电站堆芯测量系统控制柜升级改造相关设备制造活动的复函

## 国家核安全局关于同意启动大亚湾核电站堆芯测量系统控制柜升级改造相关设备制造活动的复函（国核安函[2012]98号）

北京广利核系统工程有限公司：

你公司《关于启动大亚湾核电站1#和2#机组RIC系统现场控制柜升级改造合同中设备制造活动的请示》（广利核〔2012〕4号）收悉。经研究，现同意你公司启动大亚湾核电站1#和2#机组堆芯测量系统（RIC）现场控制柜升级改造相关设备的制造活动，并提出如下核安全管理要求：

**一、**在开展制造活动前，你公司应将活动备案文件报环境保护部华北核与辐射安全监督站，并在制造过程中有效运行核质保大纲及相关的控制程序，做好过程控制和质量管理，保证质量记录的完整性和可追溯性，确保核级产品质量。

**二、**在核级设备出厂前，你公司必须完成硬件鉴定和系统软件验证与确认工作，并将相关文件报我局审查认可。

**三、**营运单位应加强对制造活动的监造，并对相关核级设备的使用和运行安全承担全面责任。

特此函复。

二○一二年七月十八日
