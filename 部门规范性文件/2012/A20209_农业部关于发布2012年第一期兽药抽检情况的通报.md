# 农业部关于发布2012年第一期兽药抽检情况的通报

## 农业部关于发布2012年第一期兽药抽检情况的通报（农医发[2012]9号）

各省、自治区、直辖市畜牧兽医（农牧、农业）厅（局、办）：

按照我部统一部署，全国30个省级兽药监察所、新疆兵团兽药监察所和中国兽医药品监察所组织完成了2011年第四季度兽药质量监督抽检计划，现将抽检情况通报如下。

**一、**基本情况

2011年四季度共完成兽药监督抽检3524批，合格3250批，合格率为92.1%，不合格产品274批（附件1-1、附件1-2）。其中，本季度兽药评价抽检872批，合格830批，合格率为95.2%（附件2）；监测抽检1887批，合格1708批，合格率为90.5%；跟踪抽检532批，合格487批，合格率为91.5%；定向抽检233批，合格222批，合格率为95.3%。

从兽药抽检环节分析，2011年四季度从生产环节抽检735批，合格724批，合格率为98.5%，环比提高1.7个百分点；经营环节抽检2283批，合格2061批，合格率为90.3%，环比下降1个百分点；使用环节抽检506批，合格462批，合格率为91.3%，环比提高1个百分点。其中，水产用兽药抽检196批，合格179批，合格率为91.3%，环比提高6个百分点；蚕用兽药抽检14批，合格14批；蜂用兽药抽检3批，合格3批。

从抽检产品类别分析，2011年四季度抽检化药类产品1843批，合格1720批，合格率为93.3%，环比下降0.9个百分点；抗生素类产品抽检943批，合格871批，合格率为92.4%，环比下降0.1个百分点；中药类产品抽检715批，合格634批，合格率为88.7%，环比提高3.4个百分点；其他类产品抽检23批，合格22批，合格率为95.7%，环比提高5.7个百分点。

关于2011年四季度兽药抽检合格产品相关信息，请登陆“中国兽药信息网”查阅。

**二、**主要问题

2011年四季度抽检结果显示，兽药质量不合格主要表现在含量、鉴别等检查项目不达标。其中，含量不合格47.3%，鉴别不合格40.4%，性状不合格的占27.4%，检查不合格18.1%，其他项目不合格14.8%。导致兽药质量问题的主因突出表现在恶意造假，化药产品生产时减少原料药投料量；中药产品生产时违规改变组方；部分产品还存在伪造或套用兽药产品批准文号现象。

**三、**采取措施

（一）各地要集中力量组织开展假劣兽药清查活动，对非法生产、经营企业和使用单位要依法实施处罚。要加大兽药抽检力度，对改变兽药制剂组方，违规添加其他药物成分，伪造、套用文号的涉嫌恶意造假行为要依法严厉查处。

（二）各地要切实加强兽药GMP监管工作，建立兽药GMP巡查制度，强化对企业的指导监督，发现违法违规行为要依法处理。

（三）根据重点监控企业划分原则，判定山西新开元动物药业有限公司（含量无法测定、含量低于80%累计3批次）；河南赫福莱生物制药有限公司（改变组方添加违禁药物或其他药物成分累计2批次）；河南迪冉生物科技有限公司（被抽检产品少于50批且不合格产品累计7批）为重点监控企业。

（四）为强化兽药安全监管，提升兽药监督抽检效能，本年度对同一企业同一品种连续两次抽检不合格的产品，依法吊销该产品批准文号，并在一年内不予受理该产品批准文号的申报。对年度内被列入重点监控的企业，在省级兽医主管部门未完成立案查处，未向我部提交立案查处报告、行政处罚的有关法律文书、假劣兽药的召回销毁记录、企业整改报告和相关证明性资料前，暂不安排兽药GMP检查验收，不受理其兽药生产许可证、产品批准文号等行政许可申请。对年度内两次被列入重点监控的企业，视其违规行为不同程度，依法采取行政处罚措施，并在一年内不予受理该企业所有兽药行政许可申请。
