# 中科院基本建设局关于召开2012年度固定资产投资决算和基本建设项目决算布置视频会议的通知

院属各有关单位：

定于2012年12月28日召开院2012年度固定资产投资决算和基本建设项目决算布置视频会议。现将有关事宜通知如下：

**一、**会议时间：

2012年12月28日（星期五）上午9：00-11：

00

**二、**会议内容：

布置2012年度固定资产投资决算和基本建设项目决算工作。

**三、**参会人员：

各单位负责基本建设财务、事业财务、资产管理和国有及国有控股（指第一大股东）企业报表的编制人员。

**四、**会议地点：

1. 京区会场：

视频会议主会场设在北京院机关709会议室，分会场设在计算机网络信息中心507会议室（中关村南四街4号）、北京分院第一会议室（中关村南四街18号）。

中关村及北郊地区各单位到网络中心、北京分院分会场参会，其他单位到院机关709会议室主会场参会。

2. 京外分会场：

沈阳分院、长春分院、上海分院、南京分院、武汉分院、广州分院、成都分院、昆明分院、西安分院、兰州分院、新疆分院等11个分院、合肥物质科学研究院及大连化物所、东北地理所（黑龙江）、海洋所、中国科大、山西煤化所、青海盐湖所、西北高原生物所、版纳热植园、地化所、亚热带农业所、上海光机所（嘉定）、上海应用物理所、福建物构所、宁波材料所、烟台海岸带所、苏州医工所、青岛能源所、厦门城市所、天津工生所、深圳先进技术研究院、上海药物所、南京天光所、苏州纳米所、广州健康院、云南天文台、授时中心、水保所等研究所设立分会场，请相关参会人员在上述分会场参加会议。

3. 参会单位名单见附件

4. 无视频会接入点的单位请在本地区就近参加会议。如需单独开设分会场，请于通知之日起，3个工作日内与基建局综合处联系。

**五、**报表下载：

请各有关单位到院网站（www.cas.cn）《通知通告》中的《关于编报院2012年度固定资产投资决算和基本建设项目决算的通知》中自行下载并打印样表，以便决算布置会时使用。

**六、**组织工作

1、请视频会议分会场单位落实会议室地点，做好会议相关工作。

2、如遇问题，请与基本建设局财务综合处联系。

联系人：李莉、何峻、郑国强

联系电话：（010）68597306或（010）68597304 （010）68597349
