# 环境保护部公告2012年第26号――关于批准建设项目环境影响评价资质(2012年第二批)的公告

## 环境保护部公告（2012年第26号）

关于批准建设项目环境影响评价资质（2012年第二批）的公告

根据《建设项目环境影响评价资质管理办法》（原国家环境保护总局令第26号）的有关规定，我部对申请建设项目环境影响评价资质（以下简称“资质”）的机构进行了审查。现将资质批准有关事项（2012年第二批）公告如下：

**一、**批准安徽省环境科学研究院等11家机构资质中的评价范围调整（调整的评价范围详见附件一）。

**二、**批准浙江省环境保护科学设计研究院等两家机构资质中的机构名称变更（变更后的机构名称详见附件一）。

**三、**批准南开大学等17家机构建设项目环境影响评价资质延续（机构名单及评价范围详见附件二）。

**四、**同意中国电力工程顾问集团东北电力设计院等八家机构资质证书中的法定代表人或住所变更（机构名单及变更情况详见附件三）。

**五、**因环评专职人员发生变化，达不到相应资质条件，批准柳州市环境保护科学研究所缩减轻工纺织化纤类评价范围。该所在原有资质有效期和评价范围之内，已与建设单位签订环境影响评价技术服务合同且属于本次申请缩减的评价范围内的项目，应于2012年4月30日前，将申请继续完成原项目的书面请示及项目清单和相应的合同复印件报我部，经我部审核后，方可继续完成。

**六、**因资质证书有效期满未申请延续，对银川市环境保护研究所建设项目环境影响评价资质予以注销。该所须于30日内到指定领证地点交回原资质证书正、副本原件，同时办理环境影响评价专职技术人员岗位证书变更和环境影响评价工程师注销登记手续；在原有资质有效期和评价范围之内，已与建设单位签订环境影响评价技术服务合同的项目，应于2012年4月30日前，将申请继续完成原项目的书面请示及项目清单和相应的合同复印件报我部，经我部审核后，方可继续完成。

请上述第一至五项中的机构于60日内，到指定领证地点领取资质证书，其中第二项中的机构应在领取资质证书前，办理环境影响评价专职技术人员岗位证书变更和环境影响评价工程师登记手续；第一至五项中的机构应在领证时携带原资质证书正、副本原件；自本公告发布之日起，上述第一至六项中的机构原资质证书正、副本原件及其缩印件同时作废，不得继续使用。
