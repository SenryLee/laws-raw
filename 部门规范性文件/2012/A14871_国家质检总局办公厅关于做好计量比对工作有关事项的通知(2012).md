# 国家质检总局办公厅关于做好计量比对工作有关事项的通知(2012)

## 国家质检总局办公厅关于做好计量比对工作有关事项的通知（质检量函〔2012〕32号）

中国计量科学研究院、各全国专业计量技术委员会、各大区国家计量测试中心：

为了保障全国量值的准确可靠，认真做好计量比对工作，现将有关事项通知如下：

**一、**认真检查2011年计量比对计划项目执行情况

中国计量科学研究院、各全国专业计量技术委员会、各大区国家计量测试中心要认真检查2011年计量比对计划项目执行情况，并将完成情况与2012年6月底以前报总局计量司。不能按期完成的，组织单位应正式行文予以说明。

**二、**组织实施2012年计量比对计划项目

中国计量科学研究院、各全国专业计量技术委员会、各大区国家计量测试中心要按照《2012年国家质检总局计量比对计划项目表》（见附件1）和《2012年国家计量基、标准国际计量比对计划项目表》（见附件2）尽快组织实施计划项目。

**三、**编制申报2013年计量比对计划项目

中国计量科学研究院、各全国专业计量技术委员会、各大区国家计量测试中心要根据当前总局工作重点并结合计量工作实际情况，在细致调研基础上提出2013年计量比对计划项目，并将申报材料于2012年6月底前报总局计量司。

附件：1.2012年国家质检总局计量比对计划项目表

2.2012年国家计量基、标准国际计量比对计划项目表
