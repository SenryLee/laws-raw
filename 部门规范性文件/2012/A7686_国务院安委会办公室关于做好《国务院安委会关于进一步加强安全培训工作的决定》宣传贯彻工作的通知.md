# 国务院安委会办公室关于做好《国务院安委会关于进一步加强安全培训工作的决定》宣传贯彻工作的通知

## 国务院安委会办公室关于做好《国务院安委会关于进一步加强安全培训工作的决定》宣传贯彻工作的通知（安委办〔2012〕55号）

各省、自治区、直辖市及新疆生产建设兵团安全生产委员会，国务院安委会各成员单位，各中央企业：

为认真学习好、宣传好、贯彻落实好《国务院安委会关于进一步加强安全培训工作的决定》（安委〔2012〕10号，以下简称《决定》），进一步开创安全培训工作新局面，促进全国安全生产形势持续稳定好转，现就有关事项通知如下：

**一、**高度重视《决定》宣传贯彻工作

《决定》从落实党的十八大精神、贯彻科学发展观、实施安全发展战略的高度，进一步强调了安全培训工作的重要地位和作用，提出了新形势下安全培训工作的总体思路、工作目标和一系列政策措施，是当前和今后一个时期加强全国安全培训工作的纲领性文件。《决定》的制定出台，充分体现了党中央、国务院对安全培训工作的高度重视，也为安全培训工作创新发展提供了新的机遇。宣传贯彻好《决定》，对于动员各有关方面抓住机遇、创新措施、攻坚克难，进一步开创安全培训工作新局面具有十分重要的意义。

各级安委会、各有关部门和单位要提高认识，把宣传贯彻《决定》作为学习贯彻党的十八大精神的重要组成部分，作为当前和今后一个时期的一项重要任务，摆上议事日程。各级安委会要对宣传贯彻《决定》作出专门部署，提出具体要求，着力抓好落实。地方各级安委会和政府相关部门主要领导、企业主要负责人要亲自抓、负总责，召开党组（党委）会议或领导班子会议，认真研究宣传贯彻《决定》工作，制定具体实施方案。各级安委会办公室要发挥牵头抓总作用，当好参谋，创新实践，整合资源，示范引领，并及时组织召开安全培训工作会议，研究部署加强安全培训工作。

**二、**一定要把《决定》宣传贯彻到基层

《决定》内涵十分丰富，必须加大宣传力度，把《决定》精神转化为广大干部职工完善安全培训工作思路、强化工作措施的自觉行动。

各单位主要负责同志和领导干部要率先学习领会好《决定》精神，为本单位、本系统干部职工做好宣讲辅导。安全监管监察系统各级领导干部和全体同志尤其要认真学习、全面把握《决定》的基本精神和主要内容，增强贯彻落实的自觉性。

要深入开展安全培训下基层、进企业活动，县级以上安委会办公室要抽调优秀干部和安全培训教师，各组成2至3个讲师团，深入基层乡镇和企业免费宣讲《决定》，做到高危行业企业全覆盖。要把学习宣传《决定》作为培训安全监管监察干部、企业主要负责人和安全管理人员、安全培训教师等的重要内容。国务院安委会办公室将组织力量，编印《决定》学习读本，请各有关部门和各单位认真组织征订学习。

要充分利用互联网、报刊、电视、广播、短信等多种途径，通过组织记者座谈会、答记者问、开设专栏专题等多种方法，拓展宣传广度和深度，使“安全培训不到位是重大安全隐患”的意识进一步深入人心，营造全社会重视、关心、支持安全培训工作的良好氛围。

**三、**紧密联系实际，推动安全培训工作

地方各级安委会、国务院有关主管部门和中央企业要组织力量深入调研，认真查找本地区、本行业领域、本企业安全培训工作中存在的突出问题，紧密结合实际，层层研究制定《决定》实施意见，并明确责任分工，狠抓工作落实。

要将贯彻落实《决定》精神与总结谋划年度安全培训工作相结合，认真总结今年工作成绩和存在问题，统筹谋划明年工作的思路和对策，突出抓几件对安全培训工作有长远影响的大事、实事。各级安委会办公室要积极协调有关部门，注重将《决定》确立的各项新思路、新制度、新措施体现到其他政策文件之中。

抓安全培训的干部要树立“培训者首先接受培训”的意识，带头加强学习，加强作风建设，尽职尽责、忠于职守；要经常深入基层、深入企业、深入车间班组，扑下身子，认真开展安全培训调查研究，了解实情、掌握规律、找准问题，及时采取有针对性的措施，解决安全培训工作中的突出问题；要积极探索、大胆创新，对安全培训重点难点问题盯住不放，狠抓落实，务求实效；要大力总结推广安全培训的新鲜经验和有效做法，善于利用典型推动工作；要减少对办培训班的直接参与，由办培训为主向管培训、管考试、监督培训为主转变。

请各省级安委会、国务院有关主管部门及各有关中央企业于2013年2月底前将贯彻落实《决定》实施意见和学习宣传贯彻《决定》情况报送国务院安委会办公室。国务院安委会办公室将于2013年3月底前对各地区贯彻落实《决定》情况进行专项督查，并将有关情况予以通报。

国务院安委会办公室
