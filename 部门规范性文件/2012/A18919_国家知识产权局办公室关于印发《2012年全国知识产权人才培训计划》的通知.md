# 国家知识产权局办公室关于印发《2012年全国知识产权人才培训计划》的通知

各省、自治区、直辖市、新疆生产建设兵团知识产权局；各国家知识产权培训基地；局机关各部门，专利局各部门，局直属各单位、各社会团体：

为全面贯彻落实《国家中长期人才发展规划纲要（2010-2020年）》和《国家知识产权战略纲要》，进一步加强知识产权人才队伍建设，建立健全知识产权人才体系，为知识产权事业发展提供强有力支撑，根据《知识产权人才“十二五”规划（2011-2015年）》，制定《2012年全国知识产权人才培训计划》，经局批准，现予印发。请根据要求统筹安排，认真组织落实。

特此通知。
