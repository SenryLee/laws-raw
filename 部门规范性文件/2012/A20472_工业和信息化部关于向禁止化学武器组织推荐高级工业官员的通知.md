# 工业和信息化部关于向禁止化学武器组织推荐高级工业官员的通知

禁止化学武器组织是一个致力于彻底销毁现有化学武器、并对工业设施进行监控以防止研制、生产化学武器的国际组织。目前已有188个成员国，覆盖全球98％的人口和面积，以及98％的化学工业。我国是该公约的原始缔约国。近日该组织公布招聘信息，技术秘书处核查司招聘1名高级工业官员。如有意向，请于2月28日前向原材料工业司报名（电话：010-68205589/5590，传真：010-66010908）。职位和要求如下（详见www.opcw.org/ jobs）。

**一、**职位：

核查司工业核查处高级工业官员（级别为P-4）

**二、**主要职责：

1. 协助视察组完成视察，评估视察结果，并提出建议；

2. 向技秘处各部门提供化学和化工相关技术问题、履约相关政策问题的建议，向缔约国代表、行业协会、公司等提供工业相关和公约相关问题的建议；

3. 向工业磋商协调员提供协助；

4. 代表技秘处参加其他国际组织的会议，为工业视察员培训、国家主管部门培训、区域研讨会等提供培训素材。

**三、**要求：

1．知识和技能

化工或化学研究生学历，或本科学历并有9年以上工作经历；MBA优先考虑；良好的口头沟通和书面写作能力（英语）；很强的分析与判断能力；机智、灵活，能在多文化的环境中和谐工作。

2．经历

（1）研究生学历并有7年以上化工厂工作经历，或本科学历、9年以上化工厂工作经历，包括：化工生产和产品开发的支持性工作；工厂运行管理；工艺设计、开发和优化；过程安全管理（包括定量风险评估、危险和可操作性分析、监察等）；工厂设计或放大设计；不包括：化工销售或商务管理、化工政府部门工作时间；

（2）多个化工操作岗位的工作经历；

（3）多种化学工艺的经历；

（4）熟练使用办公软件。

特此通知。
