# 全国国家版图意识宣传教育和地图市场监管协调指导小组关于上报国家版图意识宣传教育和地图市场监管工作总结、表彰材料的通知

## 全国国家版图意识宣传教育和地图市场监管协调指导小组关于上报国家版图意识宣传教育和地图市场监管工作总结、表彰材料的通知（国图宣教管[2012]8号）

各省、自治区、直辖市国家版图意识宣传教育和地图市场监管协调指导机构：

2005年以来，全国国家版图意识宣传教育和地图市场监管协调指导小组（以下简称全国协调指导小组）各成员单位按照《国务院转发测绘局等部门关于加强国家版图意识宣传教育和地图市场监管意见的通知》（国办发[2005]5号）和中央领导同志重要批示精神，采取有效措施，扎实有效开展工作，公民的国家版图意识不断增强，地图市场秩序明显好转。2012年，各地、各有关单位积极组织开展国家版图意识宣传教育“进学校、进社区、进媒体”活动、参加全国国家版图知识竞赛和少儿手绘地图大赛（以下简称“三进、两赛”）等活动，公民的国家版图意识明显增强。

为认真总结2005年以来全国国家版图意识宣传教育和地图市场监管工作以及“三进、两赛”活动取得的成绩和经验，充分发挥各类优秀典型事迹的示范激励作用，进一步调动各地、各单位工作积极性和主动性，促进国家版图意识宣传教育和地图市场监管工作深入开展，全国协调指导小组拟于今年召开全国国家版图意识宣传教育和地图市场监管工作总结、表彰会议，对在工作中做出突出贡献、取得显著成绩的先进集体和个人进行表彰。现将有关事项通知如下：

**一、**做好总结工作

（一）各地要结合本地工作实际，对2005年来所开展的国家版图意识宣传教育和地图市场监管工作进行全面总结，包括总结各种形式的国家版图意识宣传教育活动、地图市场日常监管、互联网地图和地理信息服务网站监管、“问题地图”专项治理等工作情况，力求做到内容丰富、重点突出、文字精练、数据详实，特别要突出本地的工作重点、亮点和取得的成绩、经验，同时要认真分析工作中存在的问题和不足，对今后开展工作提出意见和建议。

（二）各地要认真总结本地区今年“三进、两赛”活动开展情况，包括“三进”活动启动仪式、向学校、社区赠送国家版图宣传材料、与学校 、社区、媒体开展各类宣传教育活动、“两赛”宣传组织、本地区参赛单位和人数统计等有关情况。总结材料要以有关宣传教育活动为基础，以数据为重点，以工作成效为亮点，同时分析在开展“三进、两赛”中存在的有关问题，提出有关意见和建议。

（三）各地要组织推荐自2005年来在国家版图意识宣传教育和地图市场监管工作中做出突出贡献的机构、单位和个人，各省级协调机构可推荐3-4名先进个人和1-2个先进集体参加国家版图意识宣传教育和地图市场监管工作表彰评选，提交推荐的先进个人和集体的详细申报材料并列出排名。

**二、**有关要求

（一）2005年以来国家版图意识宣传教育和地图市场监管工作总结、“三进、两赛”总结和表彰申报材料应分别撰写，同时报送。

（二）全国国家版图意识宣传教育和地图市场监管工作表彰评选对象优先考虑基层单位和个人，表彰规模和数量视各地近年来国家版图意识宣传教育和地图市场监管工作以及“三进、两赛”开展情况而定，测绘地理信息系统所占推荐先进集体和个人数不超过推荐总数的50%。有关工作开展较好的单位和地区，经商全国协调指导小组，可以适当增加推荐名额。各地提交的表彰申报材料须经当地协调指导机构审议通过。

（三）请各地于2012年11月15日前将工作总结材料和先进个人、先进集体的申报材料报全国协调指导小组办公室（设在国家测绘地理信息局地理信息与地图司），同时将电子文档发送至：ditu@sbsm.gov.cn。
