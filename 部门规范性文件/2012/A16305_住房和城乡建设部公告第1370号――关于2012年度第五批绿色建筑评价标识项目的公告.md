# 住房和城乡建设部公告第1370号――关于2012年度第五批绿色建筑评价标识项目的公告

## 住房和城乡建设部公告（第1370号）

关于2012年度第五批绿色建筑评价标识项目的公告

根据《绿色建筑评价标识管理办法》（建科[2007]206号）、《绿色建筑评价标准》（GB/T50378-2006）、《绿色建筑评价技术细则》（建科[2007]205号）和《绿色建筑评价技术细则补充说明（规划设计部分）》（建科[2008]113号），我部组织开展了2012年度第五批绿色建筑评价标识项目评价工作。经审定，青岛万科蓝山2.2期（7、8、11号楼）等11个项目获得绿色建筑评价标识。

现予公布。

住房和城乡建设部

二0一二年五月八日
