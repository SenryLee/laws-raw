# 国家文物局关于国家二、三级博物馆定级备案意见的函

## 国家文物局关于国家二、三级博物馆定级备案意见的函（文物博函〔2012〕170号）

北京、吉林、黑龙江、上海、山东、四川、甘肃省（市）文物局：

根据《全国博物馆评估办法（试行）》，我局委托中国博物馆协会组织专家对你局提交备案的国家二、三级博物馆定级评估材料进行了复核。根据专家复核评分，有关国家二、三级博物馆备案意见如下：

**一、**中国农业博物馆、黑龙江省博物馆、上海科技馆、山东博物馆、四川博物院、成都金沙遗址博物馆、甘肃省博物馆达到国家二级博物馆定级标准，列入国家二级博物馆名单。四平战役纪念馆、上海韬奋纪念馆达到国家三级博物馆定级标准，列入国家三级博物馆名单。

**二、**白城市博物馆、上海市历史博物馆、中国社会主义青年团中央机关旧址纪念馆在相关单项及总分上未达到国家二级博物馆定级最低得分，不列入国家二级博物馆名单。吉林市文庙博物馆、吉林市满族博物馆、伊通满族自治县博物馆、双辽市郑家屯博物馆、镇赉县博物馆、东北沦陷时期辽源矿工墓陈列馆、长白山满族文化博物馆、靖宇博物馆、抚松人参博物馆、临江市四保临江战役纪念馆、中共“二大”会址纪念馆、闸北革命史料陈列馆在相关单项及总分上未达到国家三级博物馆定级最低得分，不列入国家三级博物馆名单。

**三、**上海豫园和上海三山会馆尚不具备博物馆的相关条件，暂不具备参评资格。

专此函复。
