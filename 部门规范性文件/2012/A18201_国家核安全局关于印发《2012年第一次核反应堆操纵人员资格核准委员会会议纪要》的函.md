# 国家核安全局关于印发《2012年第一次核反应堆操纵人员资格核准委员会会议纪要》的函

## 国家核安全局关于印发《2012年第一次核反应堆操纵人员资格核准委员会会议纪要》的函（国核安函[2012]47号）

国家能源局，国家国防科技工业局，中国核工业集团公司，中国广东核电集团有限公司，中国电力投资集团公司，国家核电技术公司：

2012年3月6日，我局组织召开了2012年度第一次核反应堆操纵人员资格核准委员会会议。现将会议纪要印发给你们，请按要求做好相关工作。

附件：2012年度第一次核反应堆操纵人员资格核准委员会会议纪要

二○一二年三月三十一日

附件：

2012年度第一次核反应堆操纵人员资格核准委员会会议纪要

2012年3月6日，国家核安全局组织召开了2012年度第一次核反应堆操纵人员资格核准委员会会议。国家核安全局、环境保护部核与辐射安全中心、环境保护部相关地区核与辐射安全监督站参加了会议。国家能源局、国家国防科技工业局应邀出席会议，相关营运单位列席会议（附一）。

国家核安全局向会议介绍了核反应堆操纵人员执照管理工作流程，2012年度第一批核反应堆操纵人员执照申请文件的提交情况，核与辐射安全中心向会议介绍了该批次核反应堆操纵人员执照申请文件的审评情况，各相关地区核与辐射安全监督站向会议介绍了该批次取换照申请考试和操纵人员岗位管理信息的监督核查情况。

会议根据以上介绍，经讨论，建议国家核安全局根据相关法规核准提交申请的9个营运单位的核反应堆操纵人员资格。

会议还就核反应堆操纵人员执照管理过程中的相关问题进行了讨论，并提出了下述具体管理要求：

**一、** 国家核安全局每季度颁发一次核反应堆操纵人员执照。营运单位应在拟取得执照前三个月将执照申请书和岗位信息表报送国家核安全局（1份），并将岗位信息表抄送相关地区核与辐射安全监督站。申请文件中核设施名称应以附二所列核反应堆所在的核设施名称为准。

**二、** 各地区核与辐射安全监督站应根据执照考试监督和执照申请材料核查情况做出专题报告，执照考试监督报告应在考试完成后一个月内以单位正式公文形式报送国家核安全局；核查报告应在监督站收到岗位信息表后两个月内以单位正式公文形式报送国家核安全局，核查报告中必须明确对岗位信息表的核查结论。

**三、** 营运单位应保证执照申请文件及岗位信息表内容的完整、真实可靠、有案可查，签名盖章必须完备。对不满足要求的，国家核安全局不予核准，退回申请文件。原则上，国家核安全局不提审评问题，确需提出问题的，营运单位应以单位正式公文形式对审评问题进行答复，并加盖单位公章，报送国家核安全局。

**四、** 对于HAF001中高级操纵员执照申请者应满足“担任操纵员二年以上，成绩优秀者”要求的解释，在下一步工作中适时讨论。

**五、** 申请换发核动力厂《高级操纵员执照》或《操纵员执照》的申请者，在运行岗位值班时间应满足国核安发[2010]86号文要求，即在原执照有效期内任意连续12个月在运行岗位值班时间不得少于400小时，其中任意连续6个月在运行岗位值班时间不得少于150小时。岗位信息表值班记录的值班小时数应为实际已值班小时数。

**六、** 向国家核安全局备案的值长，必须获得营运单位的值长岗位授权。提交备案时必须提交值长岗位授权证书的复印件。

**七、** 执照申请者学历是非全日制正规学历的，必须提交有效的《高等教育学历认证报告》或《教育部学历证书电子注册备案表》。

**八、** 取照考核成绩和换照考核成绩栏中“主考人”一栏必须由操纵人员考评委员会委员手写签名。

**九、** 对于首次申请操纵员（RO）执照的申请者，可不提交岗位信息表。

二○一二年三月六日
