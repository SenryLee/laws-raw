# 中国绿色食品发展中心关于颁发绿色食品标志监督管理员证书的通知(2012)

## 中国绿色食品发展中心关于颁发绿色食品标志监督管理员证书的通知（农绿质[2012]4号）

有关绿办（中心）：

根据《绿色食品标志监督管理员注册管理办法》相关规定，我办对申请绿色食品标志监督管理员注册人员进行了资质审核、培训和考试，现将今年第一批通过审批正式注册107人监管员名单予以公布，《绿色食品监管员》证书一并寄发。请相关绿办（中心）加强对注册监管员的管理，合理分派监管任务，充分调动他们的积极性，最大限度地发挥监管员的作用。另请及时组织2012年到期的监管员换证工作。

特此通知。

附件：2012年第一批注册绿色食品标志监督管理员名单

二Ｏ一二年二月一日
