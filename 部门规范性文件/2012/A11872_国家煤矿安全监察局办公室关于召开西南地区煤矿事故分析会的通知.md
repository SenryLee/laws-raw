# 国家煤矿安全监察局办公室关于召开西南地区煤矿事故分析会的通知

## 国家煤矿安全监察局办公室关于召开西南地区煤矿事故分析会的通知（煤安监司办〔2012〕28号）

各有关单位：

为深入贯彻落实全国煤矿安全生产经验交流现场会、全国安全生产（季度）视频会的有关要求，推进煤矿“打非治违”专项行动，督促西南地区各省（自治区、直辖市）认真吸取煤矿事故教训，采取针对性有效措施，切实加强煤矿安全生产工作，控制重特大事故，降低较大事故，减少事故总量，国家煤矿安监局定于9月3日-4日在云南省昆明市召开西南地区煤矿事故分析会，会期1天半。现将有关事项通知如下：

**一、**会议内容

（一）分析全国尤其是西南地区煤矿事故主要特点、原因，认真吸取事故教训，督促西南地区清醒认识当前煤矿安全生产形势，增强做好煤矿安全生产工作的紧迫感和责任感。

（二）听取有关单位关于加强煤矿安全生产工作的汇报。

（三）分析事故案例，用事故教训推动工作，研究制定进一步加强煤矿安全生产工作、遏制重特大事故对策措施。

**二、**参会人员

1．云南、贵州、四川、重庆、广西、湖北、湖南煤矿安监局主要负责人及相关人员各1人。

2．云南省工业和信息化委员会、安全监管局，贵州省能源局，四川省经济和信息化委员会，广西壮族自治区安全监管局，湖北省安全监管局，湖南省煤炭工业局有关负责人及相关人员各1人。

3．云南煤矿安监局所辖各监察分局、贵州煤矿安监局盘江监察分局、湖南煤矿安监局衡阳监察分局主要负责人。

4．云南省曲靖市、贵州省六盘水市、湖南省衡阳市人民政府分管煤矿安全生产工作的负责人及所属煤矿安全监管部门主要负责人。

5．云南东源煤业集团公司、湖北宜化集团公司、湖南宜化集团公司、贵州宜化集团公司、四川省煤炭产业集团公司、重庆煤炭集团公司、湖南省煤业集团主要负责人及所属安全监管部门主要负责人。

6. 国家安全监管总局和国家煤矿安监局领导及总局办公厅、统计司负责人，国家煤矿安监局机关各司（室）主要负责人。

邀请中国安全生产报（中国煤炭报）、国家局政府网站记者到会报道。

**三、**会议报到时间及地点

报到时间：9月2日全天。

会议地点：云南省昆明市中国煤矿工人昆明疗养院（地址：云南省昆明市滇池国家旅游度假区怡景路3号，电话： 0871-4311123）。

**四、**其它事项

1.请各单位根据会议内容准备书面发言材料100份带到会上；请以下单位按拟定内容做重点发言：

湖南煤矿安监局针对辖区水害事故案例作剖析发言；

四川煤矿安监局针对辖区瓦斯事故案例作剖析发言；

贵州煤矿安监局针对辖区顶板事故案例作剖析发言；

云南煤矿安监局针对监察执法和事故调查作发言；

重庆煤矿安监局（重庆市煤炭工业管理局）针对瓦斯治理、水害防治作发言；

湖南省煤炭工业局针对整顿关闭和兼并重组作发言；

云南省曲靖市人民政府、贵州省六盘水市人民政府针对煤矿“打非治违”作典型发言；

湖北宜化集团公司就吸取事故教训、湖南省煤业集团针对隐患排查治理作发言。

2.请各单位严格按分配名额派员参加会议，并于8月28日17时前填报会议代表报名回执（详见附件）传真至云南省昆明市中国煤矿工人昆明疗养院（传真：0871－4313761）。

3.请有关省级煤矿安全监察局负责通知所辖相关监察分局，驻在辖区省级煤矿安全监管部门和煤炭行业管理部门及有关产煤市人民政府、煤矿企业参会。

4. 会议安排9月2日在昆明长水国际机场、昆明火车站全天接站。请需接站的代表提前将所乘航班或车次电告云南省昆明市中国煤矿工人昆明疗养院。
