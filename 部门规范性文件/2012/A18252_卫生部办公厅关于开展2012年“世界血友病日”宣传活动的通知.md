# 卫生部办公厅关于开展2012年“世界血友病日”宣传活动的通知

## 卫生部办公厅关于开展2012年“世界血友病日”宣传活动的通知（卫办医政函〔2012〕280号）

各省、自治区、直辖市卫生厅局，新疆生产建设兵团卫生局：

世界血友病联盟将每年的4月17日定为“世界血友病日”。2012年“世界血友病日”的主题为“共同努力，缩小差距”，旨在倡议世界各国积极采取行动，保证血友病患者人人享有医疗救治和卫生保健服务。为做好2012年“世界血友病日”宣传活动，提高社会公众和医务工作者对血友病的认知和关注程度，现就有关要求通知如下：

**一、**各级卫生行政部门要高度重视“世界血友病日”宣传活动，积极行动，认真策划，精心组织，通过开展宣传活动，努力营造全社会共同关爱血友病患者的良好氛围，推动我国血友病管理工作持续健康发展。

**二、**各级卫生行政部门要紧紧围绕“世界血友病日”宣传主题，认真研究制定宣传方案，组织医疗机构加强对医务人员血友病知识的宣教工作，增强医务人员对血友病的鉴别能力；组织专家面向公众开展义诊、健康咨询、专题讲座等活动，充分利用电视、广播、报刊等传统媒体和互联网、手机、公共交通视频等新兴媒介，大力开展血友病知识宣教，普及血友病知识；大力宣传血友病相关管理政策，充分发挥血友病信息管理定点医疗机构的作用，指导基层医疗机构做好血友病诊疗工作，倡导广大血友病患者积极到血友病信息管理定点医疗机构登记相关信息。

**三、**各级卫生行政部门要加强对血友病信息管理定点医疗机构的能力建设，不断提高医疗救治水平，组织开展对血友病患者的健康指导和培训活动，提高血友病患者的自我保健能力，为血友病患者提供优质的诊疗和卫生保健服务。
