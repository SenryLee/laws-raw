# 中共国家测绘地理信息局党组关于李赤一等3名同志职务任免的通知

## 中共国家测绘地理信息局党组关于李赤一等3名同志职务任免的通知（国测党发〔2012〕41号）

中共国家测绘产品质量检验测试中心临时委员会：

经国家测绘地理信息局党组研究决定：

李赤一同志兼任中共国家测绘产品质量检验测试中心临时委员会委员、书记（正局级）；

免去王起民同志的中共国家测绘产品质量检验测试中心临时委员会书记职务，改任临时委员会副书记（保留正局级待遇）；

丁明柱同志不再担任中共国家测绘产品质量检验测试中心临时委员会委员职务。

特此通知

国家测绘地理信息局党组

2012年10月11日
