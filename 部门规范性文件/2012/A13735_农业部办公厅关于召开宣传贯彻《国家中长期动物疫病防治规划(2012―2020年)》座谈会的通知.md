# 农业部办公厅关于召开宣传贯彻《国家中长期动物疫病防治规划(2012―2020年)》座谈会的通知

## 农业部办公厅关于召开宣传贯彻《国家中长期动物疫病防治规划（2012-2020年）》座谈会的通知（农办医[2012]32号）

各省、自治区、直辖市畜牧兽医（农牧、农业）厅（局、委、办），新疆生产建设兵团畜牧兽医局，中国动物疫病预防控制中心、中国兽医药品监察所、中国动物卫生与流行病学中心：

为贯彻落实《国家中长期动物疫病防治规划（2012-2020年）》（以下简称《规划》），经研究，我部拟于近期在西藏召开宣传贯彻《规划》 座谈会。现将有关事项通知如下：

**一、**会议时间

7月24日报到，25-26日开会。

**二、**会议主题

贯彻落实《国家中长期动物疫病防治规划（2012-2020年）》（以下简称《规划》），讨论《农业部关于实施＜国家中长期动物疫病防治规划（2012-2020年）＞的指导意见》。

**三、**会议地点

西藏自治区拉萨市西藏迎宾馆（拉萨市宇拓路3号，电话：0891-6355555）

**四、**会议日程

（一）7月25日上午，全体大会

1.介绍《规划》主要内容，通报当前疫情形势。

2.发展改革委、财政部、卫生部等《规划》联合起草部门有关司局负责同志发言。

3.高鸿宾副部长讲话。

（二）7月25日下午，分组讨论

讨论主题

1.落实高部长讲话精神。

2.讨论《农业部关于实施＜国家中长期动物疫病防治规划（2012-2020年）＞的指导意见》。

（三）7月26日上午，分组讨论及会议总结

**五、**参加人员

各省（自治区、直辖市）畜牧兽医（农牧、农业）厅（局、委、办）及新疆生产建设兵团畜牧兽医局分管动物防疫工作的负责同志，防疫处处长；

农业部办公厅、人事司、政法司、计划司、财务司、国际合作司、科教司、畜牧业司、农垦局等有关司局负责同志；中国动物疫病预防控制中心、中国兽医药品监察所、中国动物卫生与流行病学中心等部属事业单位负责同志；

邀请国家发展改革委、财政部、卫生部等联合起草《规划》部门的有关司局负责同志；邀请外交部、科技部、工业和信息化部、公安部、人力资源社会保障部、交通运输部、铁道部、工商总局、质检总局、林业局、中编办、法制办、解放军总后勤部、武警总部后勤部等部门有关同志参会。
