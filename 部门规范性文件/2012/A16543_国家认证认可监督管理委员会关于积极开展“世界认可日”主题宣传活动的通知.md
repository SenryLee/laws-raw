# 国家认证认可监督管理委员会关于积极开展“世界认可日”主题宣传活动的通知

各直属检验检疫局，各省、自治区、直辖市质量技术监督局：

为了贯彻落实全国认证认可工作会议精神，进一步扩大认证认可工作的社会影响力，认监委决定在6月9日“世界认可日”前后举办系列宣传活动。为确保宣传工作取得良好效果，特将有关事项通知如下：

**一、**以“世界认可日”宣传活动为契机，推动认证认可宣传工作深入开展。今年是实施“十二五”规划承上启下的重要一年，也是实现认证认可工作创新发展的关键一年。举办“世界认可日”系列宣传活动已列入总局和认监委宣传工作要点。今年，我国“世界认可日”的主题是“传递信任 服务发展--推进认证认可 夯实质量基础”。届时，国家质检总局、国家认监委将以此为主题在北京举办大型宣传活动，邀请国际认可组织和国内有关部门参加，中央在京媒体将全方位采访报道主题活动。地方两局要按照认监委的统一部署，制定工作计划，在“世界认可日”前后，组织大型宣传活动，联系媒体进行宣传报道，引导全社会广泛关注和重视认证认可工作。认监委网站将制作“世界认可日”宣传专栏，地方认证监管部门可将专栏内容在本局官方网站上链接。

**二、**以“世界认可日”宣传活动为抓手，进一步加强认证认可正面宣传。近期，媒体聚焦认证从业机构、第三方检验检测等重要工作，多次对此给予报道和关注。地方两局要高度重视认证认可宣传工作，加强与地方新闻媒体的合作和联系，建立媒体舆情的监测和预警机制，有效引导社会舆论，创新丰富宣传手段，树立认证认可的良好形象，推动认证认可工作深入开展。

**三、**为增强宣传工作的影响力，认监委组织制作了一批“世界认可日”宣传招贴画，请地方两局在6月9日前后张贴发放，广泛宣传。请地方两局于5月10日前将招贴画的接收人、需求数量，以邮件或电话方式告知认可中心办公室，联系人：苏秋玲，邮箱：suql@cnas.org.cn，电话：010-67105398。

**四、**做好“世界认可日”宣传活动的信息上报和工作总结。地方两局要切实加强信息交流工作，认真收集有关宣传活动的文字、图片和声像信息，及时上报信息和新闻稿件。活动结束后，对相关宣传工作进行整理和汇总，认监委将结合日常信息宣传工作，于年底对优秀单位进行表扬和通报。
