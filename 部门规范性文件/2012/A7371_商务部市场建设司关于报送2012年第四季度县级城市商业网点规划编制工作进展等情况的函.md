# 商务部市场建设司关于报送2012年第四季度县级城市商业网点规划编制工作进展等情况的函

各省、自治区、计划单列市及新疆生产建设兵团商务主管部门：

为做好商业网点规划工作，根据《商务部办公厅关于做好县级城市商业网点规划工作的通知》（商建字[2007]109号）要求，请你单位尽快统计2012年第四季度辖区内县级城市以及县（区）、乡（镇）商业网点规划编制工作进展情况和地级以上城市（含直辖市）商业网点规划修编情况，并于2013年1月15日（周二）前报我司。报送材料包括所在地工作进展情况报告及附表。规划已报政府审批的需附相关请示、报告，已经批准实施的需附政府批文。

此外，请辽宁、江西、山东省商务主管部门上报辖区内尚未获得政府批准实施的地级市（营口、吉安、临沂）商业网点规划最新进展情况。
