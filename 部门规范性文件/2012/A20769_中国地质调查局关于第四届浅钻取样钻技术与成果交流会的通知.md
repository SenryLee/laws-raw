# 中国地质调查局关于第四届浅钻取样钻技术与成果交流会的通知

各有关单位：

为加快地质调查浅层取样技术推广应用，提高浅层钻探取样技术在化探勘查、地质填图、野外异常查证等地质调查工作中的应用水平，及时总结近年来地质调查浅层取样技术取得的成果，根据中国地质调查局十二五规划及2012年工作部署安排，定于2012年3月中下旬召开第四届全国地质调查浅层取样钻技术与成果交流会。具体情况如下：

**一、**会议组织

主办：中国地质调查局科技外事部

承办：北京探矿工程研究所

**二、**会议内容

1.总结和交流近年来我国地质调查浅层取样钻技术的最新进展；

2.展望浅钻技术的应用前景及未来浅钻技术发展规划；

3.介绍浅钻装备的最新成果及多领域应用情况；

4.野外应用现场参观。

**三、**参加人员

有关地勘单位地质大调查技术负责人，从事勘探、钻探、物化遥和地质环境的专业技术人员及科研管理人员。

请参会代表将回执在3月10日前发至下列联系人，以便安排相关会务工作。

**四、**时间和地点

时间：初步定于3月中下旬，为期3天，具体日期详见二号通知。

地点：北京，具体地点详见二号通知

**五、**相关费用

1.按照有关规定，收取会务费1000元/ 人（含资料费）。

2.食宿统一安排，费用自理。
