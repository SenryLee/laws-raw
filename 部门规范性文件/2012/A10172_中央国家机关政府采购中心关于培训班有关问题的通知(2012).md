# 中央国家机关政府采购中心关于培训班有关问题的通知(2012)

## 中央国家机关政府采购中心关于培训班有关问题的通知

2012年10月16日－10月19日即将举办的政府集中采购业务培训班得到了各单位的积极响应，截至10月10号11：00时培训班名额已全部报满。由于培训场地的限制，暂不接受新的报名，敬请谅解。感谢您的支持。

中央国家机关政府采购中心

二Ｏ一二年十月十日
