# 农业部关于下达2012年农机行业优势农产品重大技术推广经费项目资金的通知

## 农业部关于下达2012年农机行业优势农产品重大技术推广经费项目资金的通知（农财发〔2012〕11号）

各有关单位：

根据《财政部关于批复农业部2012年部门预算的通知》（财预[2012]168号），经研究，现将2012年农机行业优势农产品重大技术推广经费下达给你们（详见附件），主要用于项目区开展水稻、玉米、油菜、花生、马铃薯等主要农作物关键生产环节机械化技术示范、组装配套全程机械化生产体系、开展保护性耕作等方面。请列入2012年政府收支分类科目2130106“技术推广与培训”。

该项目已列入财政国库集中支付范围，资金由财政部直接拨付项目单位。各项目单位要设置“农机行业优势农产品重大技术推广项目资金”明细账（财务核算实行统一管理而不单独建账核算的单位，应建立辅助备查账），严格按照项目实施方案及有关财务制度执行，专款专用，合理列支相关费用，项目实施中如有变更事项，应按照申报程序及时履行调整报批手续。主管部门要做好组织实施和监督检查工作，并于2012年12月31日前将项目执行情况、资金使用情况（分别按项目内容和经济分类进行分析）报送我部财务司和农业机械化管理司。

二〇一二年三月二十六日
