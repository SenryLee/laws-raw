# 国家电力监管委员会关于公布电力工程建设项目安全生产标准化达标评级评审机构的函

## 国家电力监管委员会关于公布电力工程建设项目安全生产标准化达标评级评审机构的函（安监函〔2012〕168号）

各派出机构，国家电网公司，南方电网公司，华能、大唐、华电、国电、中电投集团公司，各有关单位：
