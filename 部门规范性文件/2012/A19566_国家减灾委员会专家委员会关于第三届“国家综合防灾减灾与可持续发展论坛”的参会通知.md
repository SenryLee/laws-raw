# 国家减灾委员会专家委员会关于第三届“国家综合防灾减灾与可持续发展论坛”的参会通知

## 国家减灾委员会专家委员会关于第三届“国家综合防灾减灾与可持续发展论坛”的参会通知（国减专字[2012]1号）

各有关单位、专家：

在全球气候变化背景下，自然灾害风险进一步加剧，防灾减灾工作形势依然严峻。为促进综合防灾减灾领域政府、科研机构、企业和社会组织之间的沟通与交流，2010年和2011年，国家减灾委专家委员会成功举办了两届“国家综合防灾减灾与可持续发展论坛”，引起了广泛的社会关注，产生了良好的社会反响，得到了社会各界的高度赞誉，逐步形成了论坛的自身特色和品牌。

2012年，是我国发展进程中具有特殊重要意义的一年，也是实施“十二五”规划承上启下的重要一年。为进一步提高国家综合防灾减灾能力，促进经济社会全面协调可持续发展，国家减灾委专家委员会决定于今年“防灾减灾日”宣传周期间召开第三届“国家综合防灾减灾与可持续发展论坛”，有关事项通知如下：

**一、**论坛时间、地点

时间：2012年5月10日（星期四），会期1天

地点：北京（具体地点待定）

**二、**论坛组织方式

主办单位：国家减灾委专家委员会

承办单位：民政部国家减灾中心（卫星减灾应用中心）

国家行政学院应急管理培训中心

北京师范大学减灾与应急管理研究院

中国人民大学中国社会保障研究中心

参会人员：国家减灾委员会领导，国家减灾委成员单位、国家减灾委专家委员会、中国科学院、中国工程院、高等院校、相关研究机构和社会组织的知名专家学者、科技人员、管理人员，以及防灾减灾相关企业代表等。

**三、**论坛内容

结合2012年“防灾减灾日”主题，进一步深入探讨国家综合防灾减灾发展战略，提高重特大自然灾害综合风险防范水平，大力提高全民防灾减灾素养，加强科技成果在防灾减灾领域的转化应用，充分发挥专家学者的决策咨询作用，将论坛全力打造成综合防灾减灾领域内高层次、高水平的对话平台。

论坛由开幕式和专题论坛两部分构成。开幕式将邀请国家减灾委领导致辞，邀请防灾减灾领域权威专家围绕国家综合防灾减灾发展战略、防灾减灾宣传教育与意识培养、国家综合防灾减灾能力建设等热点问题作主旨报告。专题论坛分为国家综合防灾减灾战略研究、科技创新与灾害综合风险管理、综合防灾减灾能力建设等三个专题进行报告和讨论。

专题一：国家综合防灾减灾战略研究

主要内容：全球气候变化与综合防灾减灾，极端天气气候事件风险管理，防灾减灾公共服务和社会管理，防灾减灾现状、趋势与挑战，防灾减灾理念、原则和战略目标，防灾减灾法制、体制和机制，防灾减灾政策创制，防灾减灾人才战略，防灾减灾投入优化战略，防灾减灾文化建设等。

专题二：科技创新与灾害综合风险管理

主要内容：自然灾害发生机理与演变规律，灾害风险识别理论，灾害风险综合评估，灾害链的形成，互联网、物联网、云计算、数字地球、通信导航等关键技术在防灾减灾领域的应用，防灾减灾产业化与新材料、新产品和新装备研发，防灾减灾标准研究与制定，防灾减灾科技成果转化与推广应用，国内外巨灾典型案例对比分析，巨灾的跨区域影响，大城市和城市群的巨灾应对，应急指挥与救援救助，应急综合保障能力建设，救灾协同联动与社会动员，灾害风险综合治理，灾害风险转移分担与灾害保险等。

专题三：综合防灾减灾能力建设

主要内容：防灾减灾与区域发展规划，灾害监测预警能力建设，城乡区域和基层综合减灾能力建设，城市防灾减灾、防灾减灾工程建设，应急避难场所规划与建设，全国综合减灾示范社区创建，社区应急预案演练，日本3.11地震、泰国洪水、汶川地震、玉树地震、舟曲特大山洪泥石流等重特大自然灾害灾后恢复重建对比分析和经验交流，灾后恢复重建与区域经济社会可持续发展，灾害社会影响，灾后心理援助，公众防灾减灾意识培养、社会力量参与灾后恢复重建等。

**四、**参会须知

欢迎防灾减灾领域各有关单位的专家学者、科技人员、管理人员和企业代表向论坛秘书处报名参会。论坛不收取注册费，论坛期间统一提供工作餐，交通费、住宿费自理。有意参加本次论坛的人员请填写《第三届“国家综合防灾减灾与可持续发展论坛”回执表》（见附件1）并注明是否作报告和报告题目，并于4月15日前以传真或电子邮件的形式反馈至论坛秘书处。论坛秘书处收到回执表后，将予以确认，并详细告知日程安排等有关事项。

**五、**投稿须知

本次论坛面向国内灾害管理人员、科技工作者，以及关心防灾减灾事业的同志征集论文，论坛主办方将根据投稿情况编制本届论坛文集。

投稿者应于2012年4月20日前提交论文全文（论文格式见附件2），由论坛秘书处根据投稿情况邀请有关专家对论文进行评审，并于5月20日前通知作者论文评审结果和后续安排。投稿方式：通过电子邮箱将论文电子版提交至zhjw52811200@163.com，来稿须注明详细联系方式。

附件2：

第三届“国家综合防灾减灾与可持续发展论坛”征文格式

1.来稿应署真实姓名，注明第一作者个人信息，单位部门全称、地址、电话及邮编。第一作者个人信息包括性别、技术职称、学位及研究方向。

2.署名者应为稿件内容的主要责任者，署名人数一般不超过3人。

3.稿件篇幅一般以论文5页，短文3页为宜。

4.稿件层次编排如下：中文文题，作者姓名，单位名称、所在地、邮编，文摘，关键词，英文文题，英文文摘（包括英文单位名称及关键词），编号及作者个人信息（首页下注），正文，参考文献。

5.公式及文中物理量采用斜体，单位须使用法定计量单位，正体书写。矢量、张量和矩阵符号用黑科体。外文符号及物理量凡易混淆者，应注明文种、大小写、正斜体、黑白体等。

6.公式、图、表全文分别统一依次编号，图题、表题应同时标注英文。

7.参考文献限列作者亲自阅读和已公开发表或有案可查的主要文献，并按文内出现的先后次序编号，列于文后。

文献著录格式如下：

期刊：［序号］作者.文献题名［J］.刊名，年份，卷（期）：起止页码.

专著：［序号］作者.书名［M］.出版地：出版者，出版年.起止页码.

论文集：［序号］作者.文献题名［A］.论文集编者.论文集名［C］.出版地：出版者，出版年.所引文章起止页码.

学位论文：［序号］作者.文献题名［D］.授予单位所在城市：授予单位，授予时间.

外文文献著录规则同上。外国人名，姓前名后，名用缩写，不加缩写点。
