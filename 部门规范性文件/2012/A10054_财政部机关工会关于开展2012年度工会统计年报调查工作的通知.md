# 财政部机关工会关于开展2012年度工会统计年报调查工作的通知

机关各分工会、各直属单位工会：

按照中华全国总工会要求，为了及时掌握工会组织建设及工会各项重点工作的进展情况，保证工会各项工作统计数据资料基本需要，中央国家机关工会联合会印发了《关于开展2012年度工会统计年报调查工作的通知》。为贯彻落实文件精神，现将有关事项通知如下：

**一、**各基层工会负责本单位统计调查表的录入、填报工作，并报送部机关工会进行统一汇总。部机关各分工会只填2012年基层工会调查表和工会组织建设状况（表1）部分。各直属单位工会需填报2012年基层工会调查表和整套报表（表1-8）。

2012年度基层工会调查表的电子文档见附件。（基层工会如需调查表的电子文档，请到工会办公室拷贝）。

**二、**本次统计年报调查的标准时间点为2012年9月30日。

**三、**各级工会组织要切实加强对工会统计年报调查工作的组织领导，充分认识及时准备地掌握统计数据的重要性和必要性，指派专人负责统计工作，遵守统计法规，坚持实事求是，确保数据真实、有效，高质量地按期完成工会统计年报调查工作任务。

统计年报数据由填表人填好后应由工会主席审核、确认，并加盖公章，务必于2012年11月7日上午送交工会办公室。

"主要指标解释：

基层工会　包括单独基层工会、联合基层工会及其他类型的基层工会，不包括在劳务输出地建立的劳务工会员管理机构。

单独基层工会　指单个企业、事业、机关单位，经上级工会批准建立的基层工会委员会。会员人数不足25人的法人单位，虽未建立基层工会委员会，但经上级工会批准建立的工会组织，按单独基层工会统计。

联合基层工会　指会员不足25人的企业、事业、机关，由两个及以上单位组成，经上级工会批准联合建立的基层工会委员会。以联合基层工会中涵盖职工人数较多的国民经济行业及单位类型填报联合基层工会相应属性。

其他工会组织形式　指企业、事业单位、机关、个体之外的社会团体、民办非企业单位、基金会、居民委员会、村民委员会、律师事务所和其他组织所建立的基层工会。

基层工会涵盖单位　指该基层工会组织涵盖的企业、事业、机关单位数，由一个企业、事业、机关单位单独建立的基层工会填“1”。

职工　依据《中华人民共和国工会法》，职工指在本单位工作并由单位支付劳动报酬的各类人员。调查时点在册的临时工、季节工和小时工以及由于各种原因，已经离开本人的生产或工作岗位，并已不在本单位从事其他工作，但保留劳动关系、尚未找到相对稳定工作的不在岗职工。不包括离休、退休、退职人员，非公有制经济单位的投资者。

农民工　指户籍身份是农民，进入城镇在第二、三产业就业，以工资收入为主要生活来源的劳动者。

工会会员 不包括保留会籍的离休、退休、退职人员。

专职工会工作人员　指基层工会中不从事其他工作，专门从事工会业务工作的人员。

兼职工会工作人员　指基层工会中兼职从事工会业务工作的人员。

工会女职工委员会　指依据全国总工会印发的《工会女职工委员会工作条例》第十一条规定，企业、事业单位、机关和其他社会组织等工会中有女会员10人以上的应建立女职工委员会，不足10人的可以设女职工委员。

工会专职女职工工作人员　指在工会中专门从事或以从事女职工工作为主的工会工作人员。

工会兼职女职工工作人员　指在工会女职工组织中担任一定职务（如：女职工委员会委员），但以其他工作为主，兼做女职工工作的人员。　"

主要指标解释：

经济性裁员　指用人单位濒临破产进入法定调整期间或生产经营发生严重困难等原因而裁减的人员。

拖欠职工工资　指在岗职工在国家法定工作时间提供正常劳动的前提下，用人单位未按规定按时发放职工工资达1个月以上并在报告期内仍未补发的情况。拖欠金额的统计以劳动合同规定的职工基本工资和国家规定的补贴金额为标准统计；实行计件工资的单位，指应发而未发的计件工资额。

月工资水平低于当地最低工资标准职工　指年报调查时点9月30日的前一个月，即8月份月工资水平低于当地最低工资标准的职工。

领导干部联系困难职工户制度　指为推进“送温暖工程”，由工会出面协调组织，由领导干部与生活困难职工家庭结成帮困对子，有针对性地帮助职工解决生活中的一些实际困难而形成的制度。职工生活困难户包括家庭人均收入低于当地城镇居民最低生活保障标准或困难补助标准，或有其它特殊困难的职工家庭。领导干部指党政工领导干部。

企业年金 指企业及其职工在依法参加基本养老保险的基础上，自愿建立的补充养老保险制度，是多层次养老保险体系的组成部分，由国家宏观指导、企业内部决策执行。企业年金交费由企业和员工共同承担，单位缴费一般不超过上年度工资总额的十二分之一，单位和职工合计缴费一般不超过上年度工资总额的六分之一。企业年金实行市场化运营。

企业补充医疗保险　是基本医疗保险的补充形式，用于对城镇职工基本医疗保险制度支付以外由职工个人负担的医疗费用进行的适当补助。按照规定参加各项社会保险并按时足额缴纳社会保险费的企业，可自主决定是否建立补充医疗保险。

职工互助互济活动　指工会组织职工，遵循职工自愿参加、权利义务相结合、不以营利为目的的原则，通过职工个人缴纳互助费或政府、企业、工会以及社会多方资助等方式筹集资金，在职工发生疾病、工伤、意外伤害等特殊困难时，给予一定经济资助的互助互济活动。本指标指本单位内部开办的此类活动，仅仅是组织职工参加上级工会组织的职工互助互济活动或给职工购买保险不在统计范围。

　　工会直属文化宫、俱乐部　指工会设立的供职工组织报告、演出、游艺、书报阅览或办展览会等思想文化娱乐活动的阵地和场所。 　　工会直属图书馆（室）　指工会举办的图书馆（室）。本表仅统计藏书1万册以上的图书馆（室）。 　　工会直属体育场　指工会举办的，场地中心有足球场，周边有标准环形跑道，并建有固定看台的运动场。 　　工会直属体育馆　指工会举办的，有一定屋架跨度和屋架结构、设有固定看台、可供单一或多个运动项目训练比赛的室内体育建筑设施。 　　经费年度预、决算审查　既包括预算审查，也包括决算审查，缺一项都视为没开展。
