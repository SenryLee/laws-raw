# 科技部关于开展重大专项项目(课题)任务验收工作抽查的通知

## 科技部关于开展重大专项项目（课题）任务验收工作抽查的通知（国科发专〔2012〕783号）

各重大专项牵头组织单位：

为贯彻落实国务院对重大专项组织实施的要求，加强对重大专项项目（课题）验收工作的指导和监督检查，切实掌握验收工作开展情况，及时发现并解决验收工作中存在的问题，进一步规范重大专项项目（课题）验收工作，依据《国家科技重大专项项目（课题）验收管理办法》，科技部将会同发展改革委、财政部开展重大专项项目（课题）任务验收工作抽查。现将有关事项通知如下。

**一、**工作程序与方式

1. 成立抽查专家组。科技部会同发展改革委、财政部按电子与信息、能源与环保、生物与医药和先进制造四大板块成立4个验收工作抽查专家组，主要由监督评估专家和评估机构专家等组成。每次抽查工作从抽查专家组中选择2-4名专家具体实施。

2. 分专项开展抽查。验收工作抽查分为二种方式。一是抽查专家组同步参与专项项目（课题）验收，对其验收工作进行检查。二是在项目（课题）验收结束后，抽查专家组对该项目（课题）已开展的验收工作进行检查。

3. 抽查情况反馈与通报。及时向各专项牵头组织单位反馈抽查情况，同时将有关情况以简报或专报形式予以通报。验收工作的抽查情况，也作为监督评估评价专项组织管理的重要内容。

**二、**重点内容

重大专项任务验收抽查主要对项目（课题）任务验收工作的程序、内容、质量和结论进行检查。

1. 验收工作准备情况。重点检查验收材料的齐全性和规范性，验收专家组组成的合规性和合理性。

2. 验收工作组织情况。重点检查验收组织形式和评价方式的合规性和合理性，保密制度的执行情况等。

3. 验收工作过程情况。重点检查验收过程中验收专家组对《国家科技重大专项项目（课题）验收管理办法》要求的验收内容和依据任务合同书进行考查的情况。

4. 验收评议结论情况。重点检查专家意见的一致性，以及任务验收评议和结论情况等。

**三、**有关要求

请各专项牵头组织单位全力支持，配合做好验收工作的抽查，每个月底向三部门报送下一阶段验收工作计划。具体项目（课题）验收时间，提前10天通知三部门，以保证顺利开展验收工作的抽查。

附件：

国家科技重大专项项目（课题）任务验收工作抽查实施方案

根据《国家科技重大专项项目（课题）验收暂行管理办法》，按照重大专项2012年度工作计划部署，科技部会同发展改革委、财政部三部门组织开展重大专项项目（课题）任务验收工作的抽查。

**一、**目的意义

贯彻落实国务院对重大专项组织实施的要求，加强对重大专项项目（课题）验收工作的指导和监督检查，切实掌握验收工作开展情况，及时发现并解决验收工作中存在的问题，进一步规范重大专项项目（课题）验收工作，更好地推进重大专项顺利实施。

**二、**主要依据

1．国务院审定的重大专项实施方案。

2．《国家科技重大专项管理暂行规定》、《国家科技重大专项项目（课题）验收暂行管理办法》等文件。

3．《国家科技重大专项（民口）“十二五”发展规划》、各重大专项“十一五”实施计划、“十二五”实施计划和年度实施计划，验收工作计划等。

4．各重大专项项目（课题）申请书、任务合同书、预算书等。

**三、**重点内容

抽查工作主要对项目（课题）任务验收工作的程序、内容、质量和结论进行监督检查。

1. 项目（课题）任务验收工作准备情况。重点检查验收材料的齐全性和规范性，验收专家组组成的合规性和合理性。

2. 项目（课题）任务验收工作组织情况。重点检查验收组织形式和评价方式的合规性和合理性，保密制度的执行情况等。

3. 项目（课题）任务验收工作过程情况。重点检查验收过程中专家组对《国家科技重大专项项目（课题）验收管理办法》要求的验收内容和依据任务合同书进行考查的情况。

4. 项目（课题）任务验收评议结论情况。重点检查专家意见的一致性，以及任务验收评议和结论情况等。

**四、**组织分工

科技部会同发展改革委、财政部负责组织开展重大专项项目（课题）任务验收工作的抽查。

按电子与信息、能源与环保、生物与医药和先进制造四大板块成立4个验收抽查专家组，负责重大专项项目（课题）任务验收抽查工作的具体实施。抽查专家组由重大专项监督评估专家和评估机构专家等组成。项目（课题）抽查专家不能作为被抽查项目（课题）的验收专家。每次抽查工作从抽查专家组中选择2-4名专家实施。

科技部重大专项办公室会同发展改革委高技术产业司和财政部教科文司负责任务验收工作抽查的统筹协调。各专项实施管理办公室和总体组做好支持配合工作。

**五、**工作方式和程序

重大专项项目（课题）验收抽查工作分为二种方式：一是抽查专家组同步参与专项项目（课题）验收，对其验收工作进行检查；二是在项目（课题）验收结束后，抽查专家组对该项目（课题）已开展的验收工作进行检查。

1．对于同步参与验收的项目（课题），抽查专家需参与项目（课题）验收全过程，在验收工作结束后，抽查组专家填写《项目（课题）任务验收抽查记录评价表》。

2．对于已完成验收的项目（课题），由专项实施管理办公室会同验收专家组组长或副组长及项目（课题）承担单位汇报验收工作情况。抽查组专家在听取汇报和查验相关验收材料的基础上，填写《项目（课题）任务验收抽查记录评价表》。必要时，可察看现场。

3．抽查结束后，抽查专家组根据各专家意见，汇总形成项目（课题）任务验收抽查工作报告。工作报告主要内容包括对项目（课题）任务验收工作的总体评价，以及对项目（课题）任务验收工作的准备、组织、过程及结论情况的评价，存在的问题和建议等。

4．建立抽查信息动态通报机制。根据抽查情况，及时向各专项进行反馈，同时将有关情况以简报或专报形式予以通报。验收抽查的情况，作为重大专项监督评估评价专项组织管理的重要内容。

**六、**对抽查专家的要求

1．严格按照有关规定及办法要求，认真开展抽查，认真做好检查记录。

2．把握好政策，坚持原则，敢于负责。实事求是，指出问题，提出意见建议。

3．保证有充足的时间参与抽查工作，按时、保质完成抽查工作和任务；因特殊情况不能出席的，必须向组长请假。

4．严格遵守有关保密规定，为被检查单位技术和商业秘密保密。不得接受媒体采访，不得向其他无关人员泄露与抽查工作有关的任何信息。

5．廉洁自律，不得接受超标准接待和赠送的礼品、土特产品，不得接受被抽查单位的宴请，不得参与高消费娱乐活动。按规定交食宿费。

6．互相配合，团结协作，互相监督。
