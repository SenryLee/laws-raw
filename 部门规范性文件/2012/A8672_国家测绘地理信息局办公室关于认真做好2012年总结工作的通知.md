# 国家测绘地理信息局办公室关于认真做好2012年总结工作的通知

## 国家测绘地理信息局办公室关于认真做好2012年总结工作的通知（测办〔2012〕85号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司局：

2012年，测绘地理信息系统各单位各部门按照国家测绘地理信息局党组“强平台、扩服务、推监测、优结构、壮企业、建强国”的总体要求，认真贯彻落实全国局长会议精神，凝神聚力，扎实工作，各项工作取得了良好效果。为全面贯彻落实党的十八大精神，客观分析形势，认真总结经验，有针对性地谋划好明年工作，现就做好2012年总结工作通知如下：

**一、**充分认识做好总结工作的重要性。做好年度总结工作既是对今年工作的回顾与反思，也是对今后工作的思考与谋划，各单位各部门要高度重视，认真组织，将年度总结工作作为全面完成年度工作的一项重要内容，把总结今年工作与完成各项工作任务相结合，与年终考核、表彰相结合。

**二、**总结工作要突出重点，注重实效。要本着客观真实的原则，重点突出数字城市、天地图、地理国情监测、地理信息产业发展、体制机制完善等重点工作的进展情况，既肯定成绩、总结经验，也要分析差距、查找问题，尽量采用对比等方式表现，用统计数据和典型事例说明，做到既要全面系统，又要简明扼要。

**三、**要密切结合深入学习贯彻落实党的十八大精神，以科学发展观为指导，立足本部门本单位实际，认真研究，积极探索，开拓创新，力求突破，进一步理清发展思路，谋划部署好2013年工作，研究制定好改革和发展措施，推动工作再上新的台阶。

**四、**请将2012年工作总结和2013年工作思路的书面材料以文件形式于2012年12月5日前报送至国家测绘地理信息局办公室，同时发送电子版（发送后请电话确认）。国家测绘地理信息局办公室将把各单位材料汇编成册，作为全国测绘地理信息局长会议的会议材料予以发放。
