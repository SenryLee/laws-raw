# 教育部语言文字应用管理司关于公布国家级规范汉字书写教育特色学校名单的通知

## 教育部语言文字应用管理司关于公布国家级规范汉字书写教育特色学校名单的通知（教语用司函[2012]34号）

各省、自治区、直辖市教育厅（教委）、语委，新疆生产建设兵团教育局、语委：

为深入贯彻《国家通用语言文字法》，落实教育规划纲要，推行规范汉字，有效提高规范汉字书写教育质量和学生书写能力，我司开展了国家级规范汉字书写教育特色学校的建设、评选工作。根据相关文件要求，本着“分省评审、严格质量、控制数量”的原则，结合各省（区、市）实际情况，最终确定北京市东城区天坛东里小学等389所学校为国家级规范汉字书写教育特色学校。

各级语言文字工作机构和教育行政部门要对本地区国家级规范汉字书写教育特色学校进行有效监控，定期进行检查，保证其不断提高书写教育质量，保持特色；在以后工作中注意总结经验，加强指导，宣传国家级规范汉字书写教育特色学校的先进经验，注重发挥典型示范带动作用，切实建立加强规范汉字书写教育长效机制。

附件：国家级规范汉字书写教育特色学校名单

教育部语言文字应用管理司

二○一二年六月六日
