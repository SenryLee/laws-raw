# 中华全国供销合作总社关于举办供销社中层干部现代管理能力提升进修班的通知

## 中华全国供销合作总社关于举办供销社中层干部现代管理能力提升进修班的通知（供销培字〔2012〕12号）

各省（自治区、直辖市）、计划单列市、新疆生产建设兵团供销社，有关地（市）、县供销社及社属企业，各行业协会：

队伍建设的关键在中层，中层干部的综合素质和管理能力关系到供销合作事业发展的进程和质量。为进一步强化供销社系统中层干部管理素质，促进供销社事业跨越式发展，中华全国供销合作总社培训中心决定以提升三大管理能力为主题，以打造精品课程为目标，举办供销社中层干部现代管理能力提升进修班。现将有关事宜通知如下：

**一、**课程特色

1、课程定位：切合中层岗位的管理能力需求，量身定制课程；

2、内容安排：以提升有效执行力为核心，研修三大管理能力；

3、 研修目标：坚持学以致用，使管理变革成为自觉自愿的行为；

4、研修方式：专题讲座、情景游戏、经验互动、单元测试。

**二、**课程内容

|  |  |
| --- | --- |
| 能力模块 | 课程设置 |
| 自我管理能力 | 第一讲：中层干部的自我修养和管理魅力第二讲：中层干部的岗位分析与管理职责第三讲：规范化管理与工作效率提升第四讲：大会发言、工作汇报、研讨交流等讲话艺术第五讲：职场中人际关系协调与处理 |
| 绩效管理能力 | 第六讲：预算目标的制定与绩效考核管理第七讲：财务报表分析与运用第八讲：调研工作的开展和调研报告的编写第九讲：重点工作的规划与规划书的编写技巧 |
| 团队管理能力 | 第十讲：供销社文化的特点与部门团队文化建设第十一讲：有效激励的方法与团队授权的艺术第十二讲：会议组织与会议管理第十三讲：工作管理的过程控制与团队执行力提升 |

**三、**研修对象

各级供销社部门负责人；企业（集团）部门经理、分公司经理及业务骨干；行业协会部门负责人。

**四、**师资

邀请国内管理专家、总社培训中心教授、著名企业负责人进行专题授课。

**五、**教材

专题授课教材包括《中层干部的自我管理能力》、《中层干部的绩效管理能力》、《中层干部的团队管理能力》共三册，《测试手册》及《应用与行动手册》。

**六、**时间、地点

2012年7月20-26日（20日报到）　 北京

**七、**费用

研修费2800元/人（含专题授课费、教材费、考核费及教学管理费）。食宿统一安排，费用自理。

**八、**证书及管理

研修班考评合格者，将颁发《供销社中层干部现代管理能力提升进修班结业证书》，请参训者携带二张2寸免冠照片。各省级供销合作社人事教育部门对参训人员的学习档案和考评结果按照档案管理的要求妥善留存。

**九、**组织工作

中层干部现代管理能力提升进修班是总社2012年备案类重点培训项目，请各省级供销社人事教育部门给以足够重视，做好人员调训工作，认真落实参加进修班的人选名单。请报名单位于7月6日前将报名回执传真至总社培训中心，收到回执后我们将发出正式的确认函，告知详细的日程安排和地点。
