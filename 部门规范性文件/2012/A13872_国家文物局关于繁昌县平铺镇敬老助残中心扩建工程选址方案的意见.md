# 国家文物局关于繁昌县平铺镇敬老助残中心扩建工程选址方案的意见

## 国家文物局关于繁昌县平铺镇敬老助残中心扩建工程选址方案的意见（办保函〔2012〕608号）

安徽省文物局：

你局《关于转报繁昌县平铺镇敬老助残中心扩建工程的请示》（皖文物保[2012]60号）收悉。经研究，我局意见如下：

**一、**请你局组织考古单位在繁昌县平铺镇敬老助残中心周边开展考古工作，搞清该区域地下文物埋藏情况。如需进行考古发掘，请按程序填报考古发掘申请书。

**二、**待考古工作结束后，请你局指导方案设计单位根据考古结果和皖南土墩墓群保护管理相关规定，优化敬老助残中心周边区域选址方案，避让重要遗迹，尽可能远离周边的土墩墓；在不影响土墩墓群本体和环境风貌的前提下，考虑敬老助残中心原址加高扩建的可行性。

**三、**敬老助残中心相关选址比选方案经你局初审后，按程序另行报批。

国家文物局　　

二〇一二年六月三十日
