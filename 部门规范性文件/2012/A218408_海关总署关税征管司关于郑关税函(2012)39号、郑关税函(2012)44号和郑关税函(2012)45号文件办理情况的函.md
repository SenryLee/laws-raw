# 海关总署关税征管司关于郑关税函(2012)39号、郑关税函(2012)44号和郑关税函(2012)45号文件办理情况的函

## 海关总署关税征管司关于郑关税函〔2012〕39号、郑关税函〔2012〕44号和郑关税函〔2012〕45号文件办理情况的函（税管函[2012]61号　2012年05月25日）

郑州海关：

《郑州海关关于河南三丰铜业有限责任公司进口电子引线框架铜带精整包装机组免税问题的函》（郑关税函〔2012〕39号）、《郑州海关关于河南开祥精细化工有限公司进口增稠过滤装置免税问题的函》（郑关税函〔2012〕44号）和《郑州海关关于洛阳万基铝加工有限公司进口设备税收问题的函》（郑关税函〔2012〕45号）收悉。关于来函中涉及的相关进口设备是否属于《国内投资项目不予免税的进口商品目录（2008年调整）》或《进口不予免税的重大技术装备和产品目录（2010年修订）》所列商品范围问题，我司已向国家发展改革委去函征求意见。待国家发展改革委回复意见后，我司再复函你关明确相关事宜。

特此函告。
