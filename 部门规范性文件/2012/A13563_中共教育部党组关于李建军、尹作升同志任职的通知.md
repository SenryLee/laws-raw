# 中共教育部党组关于李建军、尹作升同志任职的通知

## 中共教育部党组关于李建军、尹作升同志任职的通知（教党任[2012]71号）

中共山东大学委员会：

经研究并与中共山东省委商得一致，任命李建军同志为中共山东大学委员会常务副书记（正厅级），尹作升同志为中共山东大学委员会常委、副书记。

中国共产党教育部党组

二○一二年七月九日
