# 质检总局特种设备局关于2012年度特种设备获证单位监督抽查情况的通报

## 质检总局特种设备局关于2012年度特种设备获证单位监督抽查情况的通报（质检特函〔2012〕75号　）

各省、自治区、直辖市质量技术监督局，有关单位：

为进一步加强特种设备获证单位的监督管理，规范特种设备生产、检验检测工作行为，提高产品质量和工作质量，根据《行政许可法》和《特种设备安全监察条例》的相关规定，2012年我局组织对105家获证生产单位、检验检测机构进行了监督抽查。现将有关情况通报如下：

**一、**监督抽查方式

此次监督抽查针对不同类型的单位继续采取不同的抽查方式。对生产单位，采取资料核查、到单位生产现场检查和产品安全质量抽样检验相结合的方式；对综合检验机构，采取到生产单位检查产品质量和到检验机构核查监检资料相结合的方式；对无损检测机构，采取到大型石化工程现场监督抽查的方式。

**二、**生产单位监督抽查情况

此次监督抽查共抽查生产单位80家，均为特种设备制造单位。其中锅炉制造单位10家，压力容器制造单位8家，气瓶制造单位20家，电梯制造单位18家，起重机械制造单位12家，大型游乐设施制造单位6家，场（厂）内专用机动车辆制造单位6家。锅炉压力容器制造单位以小锅炉和快开门式压力容器制造单位为重点，气瓶制造单位以液化石油气瓶制造单位为重点，机电类特种设备制造单位则以投诉举报、媒体曝光、检验中发现问题较多的单位为重点，主要抽查了电梯、起重机械、大型游乐设施和场（厂）内专用机动车辆制造单位。抽查的主要内容为获证单位条件是否持续符合相关法规和规范的要求，重点对企业资源条件的变化情况、质量保证体系的运行情况、产品质量控制情况等进行检查。从检查结果看，大部分被抽查单位能够按照国家法规、技术规范、标准的要求从事特种设备生产活动，产品质量基本能够得到保证，但仍有一些单位存在比较严重的产品质量问题，部分企业在取得制造许可后，资源条件下降，质量保证体系执行不到位，所生产的产品质量安全性能下降，不能满足安全技术规范的要求。具体情况如下：

（一） 锅炉压力容器生产单位

1．资源条件方面

部分制造单位不能持续满足《锅炉压力容器制造许可条件》（以下简称《许可条件》）的要求。主要是持证焊工、无损检测人员数量不足，责任人员无技术职称；射线曝光室基础设施、原材料存放场地等不能满足生产需要；少数气瓶生产单位爆破试验设备、热处理设备、水压试验设备等不能满足生产需要等。

2．质量保证体系建立和实施方面

部分单位质量保证体系不能满足《特种设备制造、安装、改造、维修质量保证体系基本要求》（TSG Z0004-2007）的要求，质量手册或者更新版本无批准人签字，管理评审未严格按照手册要求实施；不能及时更新相关法规规范和技术标准；缺少锅炉节能技术管理方面的规范和标准；部分气瓶制造企业材料移植标识、焊材标识、车间生产产品状态标识和检验标识等不符合要求；热处理、水压试验和气密性试验报告等无责任人签字；经监督检验的气瓶产品护罩上未打“TS”监检标识等。

3．产品质量方面

部分压力容器企业产品焊缝缺少焊工钢印，射线底片有质量问题；部分锅炉企业产品焊缝透照不符合标准的要求，产品焊接试板不符合安全技术规范的要求；大部分快开门压力容器企业的产品上没有按标准的规定留出门齿退让平台。

4．产品抽样检验方面

此次对企业生产的气瓶产品进行了现场抽样，集中检验。对液化石油气钢瓶进行了射线检测、水压爆破等7项检验，对钢质无缝气瓶进行了水压爆破、常温疲劳循环等6项检验。通过检验发现，个别企业生产的液化石油气瓶抽样产品的力学性能试验、水压爆破试验和射线检测不合格，无缝气瓶抽样产品的力学性能试验、常温疲劳循环试验不合格。

被抽查企业存在的具体问题见附件1。

（二）机电类特种设备制造单位

1．资源条件方面

少数制造单位资源条件不能持续满足许可条件要求。部分企业技术人员数量不足，持证焊工数量或资格达不到要求；少数企业生产车间的加工、校验等设施和工装调试设备不齐全；个别企业的生产场地已不再符合制造条件的规定。

2．质量保证体系建立和实施方面

部分企业质量保证体系不能有效运行，未能按安全技术规范的要求及时修订质量保证体系文件并履行批准程序，制造过程档案管理不完善，现场作业指导文件未按程序制定，记录表格未严格执行体系文件要求，记录表格填写不完整，未严格按照合格供方名录进行采购，缺少合格供方的评价见证资料；法规和标准未及时更新；产品的设计不符合现行标准规定；忽视用户的反馈意见，归档资料缺少问题和追踪处理记录；部分游乐设施产品缺少设计图纸，个别部件未按图纸进行制造；个别电梯企业产品合格证明和外包装上未按规定标注许可证信息；个别已停止生产或地址发生变更的企业，未及时向许可机关办理变更手续。

（三）处理意见

1．对存在问题的泰兴市现代压力容器制造有限公司、乐山市长江锅炉有限公司、河南省黄河锅炉厂等企业提出通报批评并责令整改。

2．对产品质量存在问题的浙江天恩压力容器制造有限公司和杭州安泰钢瓶有限公司提出通报批评，责令两公司彻查产品不合格原因并进行整改，由当地质监部门按照《特种设备安全监察条例》的有关规定予以相应的行政处罚。整改完成后再次进行产品抽样检验，检验合格并经当地质监部门确认后，监督检验单位方可继续对产品实施监督检验。

3．对天津市三志电梯有限公司、天津奥斯达电梯有限公司、安徽菲茵特电梯有限公司、安徽博士电梯有限公司等4家企业按照有关行政许可程序注销自动扶梯制造许可资格。

4．对存在问题较多的苏州化工装备有限公司和云南昆特机械设备制造有限公司2家企业提出通报批评并责令整改，我局和云南省质监局将按照行政处罚的有关程序依法作出处理。

5．对天津西玛格电梯公司和郑州市上电机械设备有限公司2家企业提出通报批评并责令整改，由当地质监部门按照《特种设备安全监察条例》的有关规定予以相应的行政处罚。

6．对上述企业实施监督检验的检验机构，必须认真查找本机构在监检工作中存在的缺失，举一反三 ，解决问题，制定切实有效的改进措施，并将整改报告报我局。

**三、**检验检测机构监督抽查情况

此次监督抽查重点检查综合检验机构的特种设备制造、安装监督检验工作质量和无损检测机构工作质量，共抽查了10家综合检验机构和15家无损检测机构。综合检验机构包括7家压力容器制造监检机构和3家电梯安装监检机构；15家无损检测机构均是正在现场实施国家重点工程无损检测的机构。抽查中发现的问题如下：

（一）综合检验机构

部分综合检验机构质量管理体系在实施中存在问题，如未制定质量目标考核办法，或未进行质量目标分解考核，或无考核记录，未进行管理评审，质量管理体系记录保存不齐全等；检验检测仪器设备未检定（校准）；检验记录和报告的填写不规范、不准确、不完整；监督检验人员未在相应的见证材料上签字确认，不按要求出具监检联络单和监检意见通知书等见证材料；不能严格执行检验规程、检验项目漏检、检验原始记录填写不规范等。

（二）无损检测机构

部分无损检测机构项目部配备的人员不满足质量体系的质控要求，质控负责人任职资格不满足要求，无损检测人员未注册等；现场使用的检测设备未检定（校准）或无设备标识和状态标识；检测原始记录信息不全或更改不符要求；射线底片存在错评或漏评现象；检测工艺卡和检测报告的编制、审核、批准不符合规定等。

被抽查检验检测机构存在的具体问题见附件2。

（三）处理意见

对存在问题较多或较严重的黑龙江省特种设备检验研究院、长春特种设备检测研究院、江西省锅炉压力容器检验检测研究院九江分院等3家综合检验机构和广东华泰检测科技有限公司、郑州石油天然气华龙无损检测有限公司等2家无损检测机构提出通报批评并责令整改，上述检验检测机构应制定切实有效的整改措施进行整改，并将整改报告报我局。

**四、**下一步工作要求

（一）各级质量技术监督部门应根据职责分工，依法对上述存在问题的生产单位、检验检测机构的整改情况进行监督检查。

（二）各省级质量技术监督部门要加强源头监管，加大辖区内获证单位的监督抽查和监检机构的监督管理，严肃查处违法违规行为；配合总局做好对本次监督抽查中发现严重问题单位的行政处罚。

（三）自本通报发出之日起2个月内，所有被抽查获证单位应对监督抽查备忘录中的不符合项目进行彻底整改并报送整改材料，整改材料应经当地省级质量技术监督部门确认后报送我局。

（四）各特种设备获证单位应对照监督抽查发现的问题，举一反三，全面进行自查自纠，不断提升特种设备产品质量和检验检测工作质量。

附件1

特种设备获证企业存在的具体问题

泰兴市现代压力容器制造有限公司：全部人员合同过期，快开门压力容器产品未按照企业标准《快开门式压力容器安全连锁装置》进行检查。

新乡锅炉制造有限公司：快开门安全连锁装置测试报告及记录描述的是模拟测试试验过程及结果，但缺少模拟测试试验的条件。

乐山市长江锅炉有限公司某钢板炉批号与材料质量证明书上的炉批号不一致，C级分厂焊材二级库去湿机损坏、库房相对湿度超过60%，焊条没有领用手续，焊缝射线底片有丢失现象；四川乐山雄狮锅炉有限公司某焊接试板弯曲试验不合格，但未进行复验，某产品筒节组焊工艺卡缺少产品试板纵缝焊接工序；乐山林江锅炉厂某已完工产品焊接试板没有进行力学性能试验。

河南省黄河锅炉厂：有两人未办理无损检测人员注册，设备档案不全，台账未更新，缺少必要的法兰检测平台、表面探伤机等；质量管理体系建立和运行方面，文件控制中缺少外来标准的采购、验收等具体控制内容，设计控制中缺少设计委托的内容，缺少快开门连锁保护装置调试的工艺守则，考核记录无签字栏，质保师更换未备案，材料入库无材料责任工程师签字，现场焊接设备无编号、无状态标识，产品法兰设计未采用新标准等问题；产品安全质量方面，所抽查产品的焊工钢印图中缺少焊缝及焊工钢印的标识，底片未放置像质计，并且存在因增感屏损坏产生的伪缺陷，热处理曲线中局部降温速度超过工艺规定的速度等。

苏州化工设备有限公司：部分操作人员未持证上岗，磁粉探伤机无提升力试块，密度片未检定，设备台帐与实际设备严重不符，设备无标识，板材库房未分区管理且无防护措施，不锈钢的卷板机、吊钩和碳钢支架无防护，无封头检验样板，叉车未定期检验，射线爆光室未取得放射性许可证等；质量保证体系建立与实施方面，质量目标不明确，质量检验计划、工序流转卡无责任人员签字，未明确各个责任人员所负的质量责任，未设置搪烧质量责任人员，未提供该公司所收集的与产品相关的法规、标准目录，未提供 “封头加工协议”评审资料且封头加工协议未见双方责任、验收标准等相关条款，合格分供方名录无批准人签字且资料不齐，热处理报告和温度记录热处理温度超过工艺规范要求，暗室洗片装置未见药液温度调节控制装置，未提供搪玻璃物理性能理化检验报告，干燥皿内的干燥剂已失效，不合格品无处置记录等；产品安全质量方面，搪玻璃反应釜“质量检验计划”、“工序流转卡”中，实际操作、检验记录、情况不全、缺少责任人员的签字确认，搪玻璃反应釜的材料质量证明书未放在产品质量技术档案中，未提供搪玻璃的相关检验、试验资料，不锈钢反应器提供的焊接工艺评定报告未按新标准转换等。

广州市狮牌钢瓶有限公司现场水压爆破试验机不能正常运行；南阳英威东风压力容器制造有限公司热处理设备无温度自动记录；江西长征金属制品有限公司水压试验设备损坏待修。

浙江天恩压力容器制造有限公司生产的WMA219-40-15型号无缝气瓶抽样产品的力学性能试验、常温疲劳循环试验不合格；杭州安泰钢瓶有限公司生产的YSP35.5型号液化石油气瓶抽样产品的力学性能试验、水压爆破试验和RT检测不合格。

检验检测机构存在的具体问题

黑龙江省特种设备检验研究院：质量管理体系实施记录见证材料不全；检验检测设备缺少检定状态标识，档案内容不全；电梯监督未执行现行电梯监督检验和定期检验规则。

江西省锅炉压力容器检验检测研究院九江分院：对存在严重问题的压力容器文件审核不严，未提出监检意见。

郑州石油天然气华龙无损检测有限公司：无损检测人员资格证未注册；超声检测记录中的焊缝编号有涂改现象；现场用于射线探伤的设备不齐全。
