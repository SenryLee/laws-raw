# 国家食品药品监督管理局公告2012年第57号――国家药品质量公告(2012年第3期，总第91期)

国家食品药品监督管理局公告

（2012年第57号）

国家药品质量公告

（2012年第3期，总第91期）

为加强药品质量监管，保障公众用药安全，根据国家药品抽验工作计划，国家食品药品监督管理局在全国范围内组织对氨苄西林等25个国家基本药物品种、注射用多索茶碱等5个其他制剂品种进行了质量抽验。结果显示，本次抽验的30个品种中，有36批次产品不符合标准规定。现将有关情况公告如下：

**一、**国家基本药物品种抽验结果

本次共抽验氨苄西林注射剂、头孢氨苄、阿昔洛韦、氯喹、苯海索、阿替洛尔、阿托品、硫酸亚铁、亚甲蓝注射剂、乙酰胺注射剂、鱼石脂软膏剂、水杨酸软膏剂、醋酸甲地孕酮片、复方庚酸炔诺酮注射液、去羟肌苷、阿米卡星注射剂、丙酸睾酮注射剂、双黄连合剂、五苓散、醋酸可的松滴眼液、注射用法莫替丁、注射用头孢唑林钠、肝水解肽注射液、口服补液盐I、口服补液盐II等25个国家基本药物品种，其中28批次产品不符合标准规定（见附件1、2）。

**二、**其他制剂品种抽验结果

本次共抽验白花蛇舌草注射液、多索茶碱注射液、氟尿嘧啶注射液、盐酸吡硫醇注射液、盐酸多巴酚丁胺注射液等5个品种，其中8批次产品不符合标准规定（见附件2）。

对本次抽验结果为不符合标准规定的药品及相关单位（详见附件），相关省（区、市）食品药品监督管理部门正在依法进行查处。请相关省（区、市）食品药品监督管理部门于2012年10月20日前，将查处结果报送国家食品药品监督管理局稽查局。

对本次抽验结果为符合标准规定的药品，请登录国家食品药品监督管理局网站公告通告栏目查阅。

特此公告。

附件：1．在生产环节抽验不符合标准规定的药品名单（略）

2．在经营使用环节抽验不符合标准规定的药品名单（略）
