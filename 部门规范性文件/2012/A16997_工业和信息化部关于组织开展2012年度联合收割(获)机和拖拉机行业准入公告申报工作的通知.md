# 工业和信息化部关于组织开展2012年度联合收割(获)机和拖拉机行业准入公告申报工作的通知

## 工业和信息化部关于组织开展2012年度联合收割（获）机和拖拉机行业准入公告申报工作的通知

各省、自治区、直辖市及计划单列市、新疆生产建设兵团工业和信息化主管部门：

根据我部《联合收割（获）机和拖拉机行业准入条件》（工业和信息化部2011年第23号公告）和《关于印发〈联合收割（获）机和拖拉机行业准入公告管理暂行办法〉的通知》（工信部装[2012]160号）要求，为做好2012年度联合收割（获）机和拖拉机行业准入公告申报工作，现将有关事宜通知如下：

**一、**请你单位组织本地区联合收割（获）机和拖拉机生产企业开展准入公告申报工作。企业应按照《联合收割（获）机和拖拉机行业准入公告管理暂行办法》第四条的规定提交申请材料。

**二、**请你单位将初审合格并汇总后的准入公告申请企业推荐名单和准入公告申请书（一式三份，并提交电子文档）于8月15日前报送工业和信息部（装备工业司）。

**三、**接到准入公告申请书后，我部将组织开展审查工作。经审查合格的公告申请企业名单，将在工业和信息化部网站上公示。无异议者，以公告方式予以发布。

**四、**今后年度申报工作均按照上述程序办理，不再另行通知。

工业和信息化部办公厅

二〇一二年四月二十四日
