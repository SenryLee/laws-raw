# 农业部农机化管理司关于报送全国农业机械化示范区2012年建设情况的通知

## 农业部农机化管理司关于报送全国农业机械化示范区2012年建设情况的通知（农机产[2012]151号）

各省、自治区、直辖市及计划单列市农机局（办公室），新疆生产建设兵团农机局，黑龙江省农垦总局农机局：

为全面了解和掌握全国农机化示范区工作成效，现就报送2012年示范区建设情况工作通知如下：

**一、**全面客观总结示范区建设成效

各示范区总结材料需单独成稿，材料提纲建议如下：

（一）引言

（二）2012年示范区建设情况。材料内容均需有数据支撑，2012年数据可采用预计数，并与2011年进行对比分析。

1.农机装备结构布局调整优化情况。请各示范区结合实施农机购置补贴政策，着重总结本区域重点农机装备结构发展和变化情况。

2.争取各方面投入情况。简要介绍获得中央、省、地、县各级财政的支持情况，承担重大建设项目情况，引进社会资本情况等。

3.重大农机化技术示范应用情况。结合实际，突出重点，介绍重点机具和技术创新应用成效，分析带动周边县域农机化技术进步等情况，总结提供农机化示范基地建设、农机化技术管理及农机手培训等情况。

4.农机专业合作社发展情况。重点提供今年以来农机专业合作社数量、入社成员数量、服务面积、服务机制、服务收益等情况。

5.平安农机创建情况。重点介绍围绕农机安全监理工作开展情况。

（三）经验与启示。立足县域经济发展全局，思考总结推进农机装备结构布局调整、转变农机化发展方式、建设现代农业的新做法、新成效、新经验、新启示。

（四）出现的新问题及建议。立足县域经济社会发展全局，从富民强县、发挥作用、引领示范等方面找出影响农业机械化发展的突出问题，并提出针对性强、切实可操作的建设性意见。

（五）其他需要单独总结的情况。主要指各示范区需要进一步反映的有特色有亮点的情况，请各地自主把握。

（六）附表。见附件。需要注意的是，今年农机化示范区农机装备结构布局调整情况表（2012）与往年略有不同，主要是不再填写拖拉机与作业机具配套比、拖拉机单位作业面积、拖拉机单位作业效益及拖拉机单位作业面积燃油消耗等相对指标，改为填写相关指标完成情况绝对值。

**二、**严格审核各示范区总结材料

各省级农机化主管部门负责对各示范区总结材料统一审核把关，要做到：一是对材料提出意见并反馈至各示范区进行完善，各示范区文字部分控制在2500字以内，力争文字精炼，观点鲜明。二是在上报文件中对每个示范区做出明确评价。三是对组织实施不得力，未能发挥有效作用的示范区，可提出调整建议。

**三、**及时报送总结材料

请各省级农机化主管部门认真组织各示范区做好总结和材料上报工作，于2012年12月20日之前将各示范区总结材料统一报送我部农机化管理司，同时发送电子邮件至农业部农机化司产业发展处。
