# 住房和城乡建设部关于全国城镇污水处理设施2012年第二季度建设和运行情况的通报

## 住房和城乡建设部关于全国城镇污水处理设施2012年第二季度建设和运行情况的通报（建城[2012]112号）

各省、自治区住房和城乡建设厅，海南省水务厅，北京、天津、上海市水务局，重庆市建委、市政管委，新疆生产建设兵团建设局：

根据我部“全国城镇污水处理管理信息系统”的汇总数据，现将2012年第二季度全国城镇污水处理设施建设运行情况通报如下：

**一、**城镇污水处理设施建设情况

截至2012年6月底，全国设市城市、县（下称“城镇”）累计建成城镇污水处理厂3243座，处理能力达到1.39亿立方米/日。目前，全国正在建设的城镇污水处理项目约1300个，处理能力近2600万立方米/日。

在657个设市城市中，已有640个城市建有污水处理厂，占设市城市总数的97.4%；累计建成污水处理厂1903座，形成处理能力1.15亿立方米/日。36个大中城市（直辖市、省会城市和计划单列市）建有污水处理厂436座，处理能力达4895万立方米/日，占全国设市城市污水处理厂处理能力的42.6%。

全国已有1192个县城（不含新疆生产建设兵团团场级单位）建成了污水处理厂，约占县城总数的73.3%；县城及部分建制镇累计建成污水处理厂1340座，处理能力2391万立方米/日。

本季度，宁夏回族自治区实现了辖区每个市（县）建成污水处理厂。全国已有21个省（区、市）实现了污水处理设施市（县）级别的全覆盖。

**二、**建成投运城镇污水处理厂运行与污染物削减情况

2012年第二季度，全国城镇污水处理厂累计处理水量103.56亿立方米，同比增长8.2%；运行负荷率达到82.1%，同比提高3.4个百分点，配套管网建设促进运行效率提高的作用逐步显现；累计削减化学需氧量（COD）总量278.05万吨，同比增长2.2%；平均削减化学需氧量（COD）浓度268.23mg/L。

36个大中城市城镇污水处理厂本季度累计处理水量39.20亿立方米，同比增长10.6%；运行负荷率高于全国平均水平5个百分点，达到87.25%；累计削减化学需氧量（COD）总量115.32万吨，同比增长1.2%；平均削减化学需氧量（COD）浓度289.17mg/L。

本季度尚有377座投入运行1年以上的城镇污水处理厂没有达到国家有关要求，平均运行负荷率不足60%，处理能力约为1146万立方米/日，占总处理能力的8.2%。

**三、**城镇污水处理工作考核情况

按照《城镇污水处理工作考核暂行办法》（建城函[2010]166号）的要求，我部对各省区和36个大中城市2012年上半年的城镇污水处理工作情况进行了考核、排序。省级考核前三名的是天津市、北京市和上海市，36个大中城市考核前三名的是郑州市、天津市和西安市。

**四、**城镇污水处理信息报告情况

各地运行项目信息上报情况整体较好。按处理能力统计，2012年第二季度总上报率为99%，北京、天津、重庆、辽宁、安徽、湖北、湖南、海南、广东、甘肃、宁夏等11个省（区、市）运行项目上报率为100%。本季度运行项目信息上报率最低的为内蒙古自治区。

在建项目上报率偏低。按项目数量统计，2012年第二季度总上报率仅为75%，北京、天津、上海、重庆、辽宁、江苏、安徽、贵州、湖南、海南等10个省（区、市）上报率为100%。本季度在建项目信息上报率较低的为内蒙古自治区、四川和云南省。

**五、**下一步工作要求

（一）抓好城市内涝防范。当前正值主汛期，各地要保持高度警惕，积极与气象部门沟通会商，做好暴雨内涝的防范与应急准备；加强对易涝点、施工工地、棚户区、低洼地等风险点，以及检查井、泵站、供电等设施的巡查和应急值守，防范积水引发的各类安全事故。

（二）抓好规划的落实与实施。国务院办公厅印发了《“十二五”城镇污水处理及再生利用设施建设规划》（国办发[2012]24号），建设任务十分紧迫。针对今年以来普遍出现的污水处理能力增速放缓现象，各地要根据国家规划的目标和任务，抓紧调整本辖区城镇排水与污水处理相关规划，将建设任务分解落实到市、县；督促各市、县编制、完善城镇排水与污水处理专项规划，将建设任务落实到具体项目，并做好项目前期的审核把关工作，积极争取国家资金支持。

（三）继续做好城镇污水处理设施建设运行存在问题的整改工作。去年我部印发了《关于尽快整改城镇污水处理设施建设运行存在问题的通知》（建城[2011]181号），要求对存在问题的污水处理项目进行自查自纠，并提出具体整改方案。对目前仍未整改到位的问题项目，各地要加快整改。我部将在近期组织开展整改情况“回头看”，对落实情况进一步督导。
