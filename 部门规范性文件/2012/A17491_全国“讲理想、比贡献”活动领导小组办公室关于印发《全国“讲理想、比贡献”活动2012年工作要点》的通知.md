# 全国“讲理想、比贡献”活动领导小组办公室关于印发《全国“讲理想、比贡献”活动2012年工作要点》的通知

## 全国“讲理想、比贡献”活动领导小组办公室关于印发《全国“讲理想、比贡献”活动2012年工作要点》的通知（全“讲理想、比贡献”组办发〔2012〕2号）

各省、自治区、直辖市“讲理想、比贡献”活动领导小组，新疆生产建设兵团“讲理想、比贡献”活动领导小组，各有关单位：

全国“讲理想、比贡献”活动领导小组审议通过了《全国“讲理想、比贡献”活动2012年工作要点》，现印发给你们，请认真贯彻执行。

附件：《全国“讲理想、比贡献”活动2012年工作要点》

全国“讲理想、比贡献”活动领导小组办公室

二〇一二年四月十四日

全国“讲理想、比贡献”活动2012年工作要点

2012年是实施“十二五”规划承上启下的重要一年，“讲理想、比贡献”活动要认真贯彻落实党中央、国务院对经济工作和科技工作的一系列重要方针和指示精神，突出把握好稳中求进的工作总基调，紧紧围绕科学发展主题和加快转变经济发展方式主线，充分发挥四部门联合协同作用，着力弘扬科学精神和创新精神，加强企业创新文化建设，在树立社会主义核心价值体系方面展现新气象；着力推动群众性技术创新活动深入开展，增强企业自主创新能力，在加快转变经济发展方式方面做出新贡献；着力引导创新要素向企业集聚，推动产学研用有机结合，在激发企业创造活力方面获得新突破；着力培养企业一线创新人才，促进企业各类创新型人才成长，在推动用好用活人才方面做出新成绩。通过大力表彰全国“讲理想、比贡献”活动涌现的先进典型，充分发挥典型示范作用，调动广大企业科技工作者的积极性、主动性和创造性，在扩大“讲理想、比贡献”活动社会影响方面迈上新台阶。

**一、**深入贯彻落实党的十七届六中全会精神，推进企业创新文化建设

把“讲理想、比贡献”活动作为推进企业创新文化建设的重要载体，组织开展各种具有较强针对性和实效性的创新实践活动。以“讲理想、比贡献”活动凝魂、聚气、育人，促进企业把社会主义核心价值体系熔铸于企业文化的生成培育之中，让“讲理想、比贡献”活动在企业再掀新高潮；通过举办“讲理想、比贡献”活动成果展、组织经验交流和研讨等活动，引导广大企业科技工作者积极参与“讲理想、比贡献”活动，努力营造有利于企业创新的氛围，让“讲理想、比贡献”成为广大企业科技工作者的自觉追求和实际行动；充分利用报纸、网络、期刊等，大力宣传“讲理想、比贡献”活动中涌现出来的突出事例、先进人物和工作成果，用榜样的力量激励和动员广大企业科技工作者投身自主创新的伟大实践，使“讲理想、比贡献”活动成为推动企业技术创新和企业创新文化建设的有社会影响的品牌活动。

**二、**紧紧围绕加快转变经济发展方式主线，组织开展“讲理想、比贡献”主题活动

充分发挥“讲理想、比贡献”活动领导小组成员单位联合协同作用，结合不同地区、不同行业、不同企业的特点，组织动员广大企业科技工作者，开展形式多样、丰富多彩的“讲理想、比贡献”主题活动。通过组织技术攻关、技术改造、技术革新、发明创造、提合理化建议等贴近企业发展实际的群众性技术创新活动，把广大企业科技工作者凝聚在“讲理想、比贡献”活动之中，让更多创新潜能释放出来，让更多群众性技术创新成果涌现出来，促进企业技术创新出成果、出效益、促发展，把企业引导到“以创新促转型、以转型促发展、以创新驱动发展”的内生增长的轨道上来。

以国家认定的企业技术中心所在企业、中央企业和国家高新技术产业开发区、国家经济技术开发区等高新技术企业集中、民营科技企业活跃、创新创业氛围浓厚的区域为重点，结合新形势、新要求，针对企业技术创新的重大需求，进一步丰富“讲理想、比贡献”活动内容、拓展活动空间，将建立企业专家工作站、专家服务中心活动，“金桥工程”为代表的促进产学研结合的活动，企业技术创新方法推广应用试点示范活动，依托科研机构、高校和学会开展的科技信息服务、科技成果转化等为企业引入创新要素的活动与“讲理想、比贡献”活动有机结合起来，为推动企业群众性技术创新活动注入创新资源，进一步增强活力，推动“讲理想、比贡献”活动向纵深发展。

**三、**充分发挥“讲理想、比贡献”活动平台作用，促进企业创新人才成长

把培养各类企业创新型人才作为“讲理想、比贡献”活动的重要任务，充分发挥院士专家技术引领作用，为企业培养层次分明、素质高、能力强的创新人才队伍。依托国家认定的企业技术中心和重点工程、重大科技专项，为企业培养和造就一批能够站在行业科技前沿、勇于开拓创新的各类领军人才；配合实施“海智计划”，拓展海外高层次人才联系渠道，为企业加快培育关键技术人才；鼓励全国学会和地方合作，面向企业一线科技工作者大力开展创新工程师培训和专利工程师培训，广泛开展层次不同、形式多样、内容丰富的学术交流活动，着力为企业培养创新人才；重点发挥企业科协组织作用，联合生产部门、人力资源等部门，通过开展技能培训、“讲理想、比贡献”活动专题立项等，提高技能型人才创新能力和实践能力，着力培养高层次技能型人才。

**四、**充分发挥“讲理想、比贡献”活动示范效应，进一步扩大“讲理想、比贡献”活动覆盖面

组织开展好全国“讲理想、比贡献”活动专题调研，系统总结全国“讲理想、比贡献”活动创造的鲜活经验和有益做法，挖掘特色亮点，认真分析存在的问题，深入研究当前的形势和任务，研究提出落实“十二五”时期全国“讲理想、比贡献”活动服务企业创新工作的基本思路、主要任务、具体措施和建议等，更好地发挥“讲理想、比贡献”活动在促进企业自主创新能力提升中的重要作用。

进一步加强中国科协等四部门联合协作，强化服务意识，创新服务手段，完善工作协调机制，积极推动各地“讲理想、比贡献”活动领导小组的工作，把有利于形成全社会创新氛围的积极因素调动起来，突出“讲理想、比贡献”活动的广泛性；进一步扩大企业科技工作者的参与度，注重将先进典型示范引路与提高活动覆盖面结合起来，把有利于调动企业科技工作者创造性的行之有效举措融入“讲理想、比贡献”活动，突出“讲理想、比贡献”活动的群众性；进一步丰富“讲理想、比贡献”活动内涵，把有利于推动企业技术创新的各项工作纳入“讲理想、比贡献”活动，突出“讲理想、比贡献”活动的实效性。

**五、**大力表彰先进典型，扩大“讲理想、比贡献”活动的社会影响

组织修订《全国“讲理想、比贡献”活动表彰奖励办法》，使“讲理想、比贡献”活动表彰奖励真正成为四部门推动工作的有效抓手，不断扩大“讲理想、比贡献”活动的社会影响。认真组织好申报、推荐和评审工作，发现先进典型，举荐先进典型；召开全国“讲理想、比贡献”活动表彰奖励大会，表彰全国“讲理想、比贡献”活动涌现出来的先进集体和先进个人；通过开展表彰奖励活动，大力宣传典型事迹，营造良好创新氛围，形成学习先进、争当先进、赶超先进的良好风尚，更好地发挥“讲理想、比贡献”活动表彰奖励对群众性技术创新活动的导向作用，以优异成绩迎接党的十八大胜利召开。
