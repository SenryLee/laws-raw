# 交通运输部公告2012年第59号――关于发布《水运支持保障系统工程设计总体技术要求》(JTS195—3—2012)的公告

## 交通运输部公告（2012年第59号）

关于发布《水运支持保障系统工程设计总体技术要求》（JTS195-3-2012）的公告

现发布《水运支持保障系统工程设计总体技术要求》（以下简称《要求》）。本《要求》为强制性行业标准，编号为JTS195-3-2012，自2013年1月1日起施行。

本《要求》由交通运输部组织交通运输部水运科学研究院等单位编制完成，由交通运输部水运局负责管理和解释，由人民交通出版社发行。

特此公告。

交通运输部　

2012年11月20日
