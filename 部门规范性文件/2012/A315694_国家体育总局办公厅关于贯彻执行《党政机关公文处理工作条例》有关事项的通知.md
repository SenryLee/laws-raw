# 国家体育总局办公厅关于贯彻执行《党政机关公文处理工作条例》有关事项的通知

## 体育总局办公厅关于贯彻执行《党政机关公文处理工作条例》有关事项的通知

体办字〔2012〕112号

各司、局，各直属单位：

2012年4月16日，中共中央办公厅、国务院办公厅印发了《党政机关公文处理工作条例》（中办发［2012］ 14号，以下简称《条例》），对现行的《中国共产党机关公文处理条例》和《国家行政机关公文处理办法》进行了修订。《条例》自2012年7月1日起施行，《中国共产党机关公文处理条例》和《国家行政机关公文处理办法》停止执行。

为贯彻执行《条例》相关规定，结合体育总局公文处理工作实际，现将拟制公文应注意的有关事项通知如下：

一、涉密公文应当标注份号，即绝密、机密、秘密文件都要标注份号。

二、根据公文紧急程度，紧急公文应当分别标注“特急“加急”，取消原有的“急件”。

三、公文标题由发文机关名称、事由和文种组成，公文标题要标注发文机关名称，使用全称或者规范化简称。

四、公文要有发文机关署名，属发文机关全称或者规范化简称。发文机关署名在成文日期之上，以成文日期为准居中编排。

五、公文的成文日期署会议通过或者发文机关负责人签发的日期。联合行文时，署最后签发机关负责人签发的日期。成文日期一般右空4字编排，用阿拉伯数字将年、月、日标全，年份应标全称，月、日不编虚位。

六、公文格式中取消“主题词”。

七、公文的抄送机关、印发机关和印发日期使用4号仿宋体字。

以上具体事项，自《通知》印发之日起在体育总局公文处理工作中施行。为学习好、贯彻好、落实好《条例》内容，体育总局办公厅将适时举办公文业务培训班，对《条例》的贯彻执行进行专题培训，进一步提高体育总局系统公文处理工作水平。

体育总局办公厅
