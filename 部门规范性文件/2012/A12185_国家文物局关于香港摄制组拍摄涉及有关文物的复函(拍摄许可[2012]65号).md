# 国家文物局关于香港摄制组拍摄涉及有关文物的复函(拍摄许可[2012]65号)

## 国家文物局关于香港摄制组拍摄涉及有关文物的复函（拍摄许可〔2012〕65号）

香港有线娱乐有限公司：

你公司关于派摄制组拍摄专题片涉及文物的函收悉。经研究，我局同意该摄制组于2012年8月拍摄北京八达岭长城、故宫、爨底下村古建筑群有关镜头。具体拍摄内容及拍摄方式等事宜请与当地文物部门协商确定。在拍摄过程中，请该摄制组严格服从文物管理人员安排，务必确保文物安全。

国家文物局　　

二〇一二年八月十四日
