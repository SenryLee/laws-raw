# 质检总局特种设备局关于开展2012年度特种设备行政许可获证单位和授权机构监督抽查工作的通知

## 质检总局特种设备局关于开展2012年度特种设备行政许可获证单位和授权机构监督抽查工作的通知（质检特函〔2012〕47号）

各省、自治区、直辖市质量技术监督局：

为加强特种设备行政许可获证单位和授权机构的监督，督促其持续满足许可或授权条件，我局决定近期组织开展部分特种设备行政许可获证单位和授权机构年度监督抽查工作。现将有关事项通知如下：

**一、**抽查方式

根据《2012年特种设备安全监察与节能监管工作要点》，围绕获证特种设备生产单位监督抽查，开展获证生产单位、检验检测机构、鉴定评审机构、锅炉能效测试机构工作质量联合抽查。

**二、**抽查对象

以来信来访和日常监察、检验、评审等工作中发现的薄弱环节为重点，结合上一年度的监督抽查情况，抽查特种设备有关的设计、制造、安装维修保养单位，以及检验检测机构（含型式试验机构）、锅炉能效测试机构和鉴定评审机构。

**三、**抽查时间

2012年8月初至11月底。

**四、**抽查人员组成

抽查工作由我局统一组织实施，抽查人员由我局从有关安全监察机构、检验检测机构、鉴定评审机构的专家中选取，请有关单位给予配合。

**五、**抽查安排

具体抽查对象和抽查日期由我局在抽查组到达前3天通知抽查对象所在地的省级安全监察机构，不通知被抽查单位。

**六、**抽查费用

抽查工作的相关费用全部由总局承担。

请有关质量技术监督局及被抽查单位对抽查工作给予支持和配合。请有关省级安全监察机构协调委派持证安全监察人员到现场协助抽查工作，以便对发现的违法违规行为及时取证、处理。

二〇一二年七月三十一日
