# 国家测绘地理信息局直属机关团委关于印发国家测绘地理信息局直属机关团委2012年工作要点的通知

## 国家测绘地理信息局直属机关团委关于印发国家测绘地理信息局直属机关团委2012年工作要点的通知（测直团发[2012]3号）

各直属团委、总支、支部：

现将《国家测绘地理信息局直属机关团委2012年工作要点》印发给你们。请结合本部门实际，认真贯彻落实。

国家测绘地理信息局直属机关团委

二○一二年三月二十日

国家测绘地理信息局直属机关团委2012年工作要点

2012年是中国共产主义青年团成立90周年，国家测绘地理信息局直属机关团委的总体工作思路是：坚持党建带团建的原则，紧紧围绕党和国家工作大局，以服务党政中心工作、服务青年成长为出发点和落脚点，加强共青团组织自身建设，提高团干部的工作能力和水平，提升团组织的吸引力、凝聚力、影响力。通过策划开展主题鲜明、健康有益、喜闻乐见的系列活动，弘扬测绘精神，加强测绘地理信息文化建设，引导青年关心、建言、推动测绘地理信息事业发展，激励青年岗位建功立业，团结带领广大青年以良好精神风貌和实际行动迎接党的十八大胜利召开。主要做好以下八个方面的工作：

一是举办纪念五四青年节主题活动。引导青年坚定共产主义远大理想和中国特色社会主义信念，把个人成长进步与测绘地理信息事业发展紧密联系起来，围绕中国共产主义青年团成立90周年和“五四”运动93周年开展纪念活动，展示测绘地理信息青年干事创业的锐意精神和聪明才智。

二是配合开展青年评优活动。在总结第六届国家测绘地理信息局直属机关杰出和优秀青年评选工作的基础上，配合局直属机关党委和人事司组织评选和表彰第七届局直属机关杰出青年和优秀青年，发挥典型榜样的示范带动作用，激励广大青年奋发向上，立足岗位建功立业。

三是打造好测绘青年论坛主题微博。充分发挥微博客具有的互动性强、关注度高、影响面广等特点，结合新形势下青年成长特点和实际需求，更好地发挥测绘青年论坛主题微博在展示青年才华、促进沟通交流等方面的独特作用，打造开放、健康、阳光的测绘地理信息青年网络平台。

四是加强培训交流，加大团干部队伍建设力度。举办直属局团干部交流研讨会暨业务培训班。拓展测绘地理信息部门共青团工作的影响力，加强能力建设，充实培训内容，不断增进系统内团干部的交流，为团干部的成长进步和更好地服务团员青年，提供更多的渠道和更广阔的空间。

五是组织青年“走出去”，拓展视野增长才干。组织青年走进其他部委，了解相关行业的发展情况、政策走向和青年工作状况。组织青年走进地理信息企业，引导青年关心和融入测绘地理信息事业发展，了解企业状况，学习先进经验，转变工作作风，服务行业发展。

六是开展寓教于乐的青年活动。适时邀请伟人后代讲授伟人生前的光辉品格和崇高精神，教育青年珍惜盛世年华，以实际行动报效祖国人民。举办新一届局在京直属单位青年篮球比赛，强健身体素质，丰富青年业余文化生活。积极为我局青年参加上级团组织的各项活动创造条件。

七是加强自身建设，提高青年工作水平。按照团章要求和共青团工作规则，指导并建立健全局在京直属单位团组织。开展局直属机关共青团第七届委员会换届工作。召开共青团国家测绘地理信息局直属机关第八次代表大会，听取第七届委员会工作报告，选举产生第八届委员会。

八是着手推动成立测绘地理信息青年联合会。为更好地发挥共青团组织的生力军和突击队作用，更好地团结青年、凝聚青年、服务青年，推动测绘地理信息事业大发展。适时启动成立测绘地理信息青年联合会的前期调研等相关准备工作，着手推动青年联合会尽快成立。
