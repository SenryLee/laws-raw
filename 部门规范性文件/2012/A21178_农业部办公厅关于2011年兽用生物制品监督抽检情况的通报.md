# 农业部办公厅关于2011年兽用生物制品监督抽检情况的通报

## 农业部办公厅关于2011年兽用生物制品监督抽检情况的通报（农办医[2012]4号）

各省、自治区、直辖市畜牧兽医（农牧、农业）厅（局、办），中国兽医药品监察所：

根据《农业部关于下达2011年兽药监督抽检计划的通知》（农医发[2011]12号）要求，我部组织中国兽医药品监察所完成了2011年兽用生物制品监督抽检任务。现将有关情况通报如下：

**一、**基本情况

2011年，对65家企业（58家国内生产企业、7家代理公司）产品实施监督抽检，抽检69个品种，总计353批疫苗。其中，合格产品338批（附件1），合格率为95.8%；不合格产品15批（附件2），不合格率为4.2%。具体情况如下：

（一）评价性抽检。对38家企业产品实施评价性抽检，抽检35个品种，共156批。其中，合格产品146批，合格率为93.6%；不合格产品10批，不合格率为6.4%。

（二）重点抽检。对33家企业产品实施重点抽检，抽检13个品种，共127批。产品全部合格，合格率为100%。

（三）跟踪抽检。对7家企业（含1家代理公司）产品实施跟踪抽检，抽检6个品种，共30批。其中，合格产品27批，合格率为90%；不合格产品3批，不合格率为10%。

（四）批签发核查抽检。对10家企业实施批签发核查抽检，抽检10个产品，共20批。产品全部合格，合格率为100%。

（五）进口产品抽检。对7家代理公司代理的8家国外企业产品实施抽检，抽检12个产品，共20批。其中，合格产品18批，合格率为90%；不合格产品2批，不合格率为10%。

**二、**结果分析

总体看，目前全国兽用生物制品监督抽检合格率呈稳步提升态势，2011年的合格率比2009年（93.7%）提高2.1个百分点，比2010年提高（94.6%）提高1.2个百分点。主要呈现以下几个特点：

（一）重大动物疫病疫苗合格率达到100%。2011年，共抽检127批重大动物疫病疫苗产品，其中高致病性禽流感疫苗24批，口蹄疫疫苗12批，高致病性猪蓝耳病疫苗58批，猪瘟疫苗33批，检验结果均符合标准规定，合格率首次达到100%，比2010年（99.2%）提高0.8个百分点。

（二）国产疫苗质量显著提升。2011年，共抽检了58个国内生产企业的327批产品，合格产品317批，合格率为96.9%，比2010年（95.2%）提高1.7个百分点。其中，54个企业的被检产品全部合格，占被检企业的93.1%，比2010年（87.3%）提高5.8个百分点。

（三）进口疫苗质量明显下降。2011年，共抽检7个国外企业生产的26批产品，合格21批，合格率为80.8%，比2010年（87.0%）下降6.2个百分点，比国产疫苗合格率（96.9%）低16.1个百分点，比全国总体合格率（95.8%）低15个百分点。

**三、**工作安排

根据检验结果，我部及地方兽医行政管理部门依据《兽药管理条例》等法规规定，加大监管力度，及时责成企业采取了召回和销毁产品、停止生产（进口）和限期整改等措施，开展了现场验收和飞行检查、试生产和再检验等工作，取得了显著成效。为进一步做好2012年兽用生物制品监督抽检工作，切实提高监督抽检工作效能，强化检打联动，保证兽用生物制品特别是重大动物疫病疫苗质量，下一步工作安排如下：

（一）切实落实监管责任。各级兽医行政管理部门应根据《兽药管理条例》、《农业部关于畜牧兽医行政执法六条禁令》等规定，进一步提高思想认识，切实落实监管责任，认真做好辖区内兽用生物制品监管工作。结合飞行检查、监督处罚等措施，加大监管力度，对生产销售假劣兽用生物制品等违法行为严肃处理，做到发现一处，查处一处，决不姑息。

（二）完善监督抽检责任制。中国兽医药品监察所要进一步强化监督抽检管理，完善监督抽检责任制。细化工作分工，科学分解任务，建立客观、公平、公正监督检验环境。及时汇总上报检验结果，增强抽检的实效性。

（三）强化重点产品抽检。中国兽医药品监察所要根据2012年全国兽药监督抽检工作总体部署，科学制定2012年全国兽用生物制品监督抽检计划，重点强化重大动物疫病疫苗抽检、强化进口产品抽检、强化用户反映的不良反应大的产品抽检。

我部将以兽用生物制品监督抽检为基础，逐步完善企业信用档案，强化不合格产品发布制度，及时公布不合格产品，积极推进兽用生物制品行业诚信体系建设。
