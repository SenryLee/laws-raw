# 国家体育总局办公厅关于上报组织开展2012年全民健身志愿服务活动方案的通知

各运动项目管理中心：

为深入贯彻落实《全民健身条例》和《全民健身计划》，把全民健身志愿服务工作机制引入全民健身事业发展的实践，弘扬志愿服务精神，有效整合社会资源，更好地满足广大群众日益增长的体育健身需求，不断提高体育公共服务的规模、质量和水平，推动全民健身事业实现跨越式发展，国家体育总局制定印发了《建立全民健身志愿服务长效化机制工作方案》（体群字[2010]201号），并组织优秀运动员、社会体育指导员、职业健身教练、体育科技工作者、体育院校师生开展了不同主题的全民健身志愿服务活动，获得广大群众的好评，对促进群众体育普遍化、经常化、科学化、生活化发挥了积极作用。为进一步推动全民健身志愿服务活动广泛深入地开展，决定支持各运动项目管理中心开展全民健身志愿服务活动，现将有关事宜通知如下：

**一、**充分认识开展全民健身志愿服务活动的重要意义，高度重视此项工作。刘鹏局长在今年群众体育工作会上要求“充分发挥各级单项体育协会的作用，不断创新全民健身工作机制”，形成“大群体”格局。近年来，国内各类体育赛事举办频繁，各单项体育协会受关注度不断提高，群众参与体育活动热情高涨，各运动项目管理中心在法规制度、竞赛组织、人才培养等方面日趋完善，已经具备开展全民健身志愿服务活动的条件。今年是奥运年，中国奥运健儿必将奋勇拼搏、力创佳绩。与此同时，各运动项目管理中心应该将开展全民健身志愿服务活动视为服务广大群众、促进全民健身的良好契机，作为对运动员进行理想信念教育，弘扬运动员爱国、奉献、团结、拼搏精神，增强运动队凝聚力和战斗力的重要活动内容。充分发挥优秀运动员、教练员社会知名度高、影响力大的优势，通过组织优秀运动员参与全民健身志愿服务，把服务他人、服务社会与实现个人价值有机结合起来，在奉献社会的过程中陶冶情操、提升境界，促进训练。

**二、**精心设计全民健身志愿服务活动方案。各运动项目管理中心要按照《建立全民健身志愿服务长效化机制工作方案》，结合实际制定本单位所负责的运动项目开展全民健身志愿服务活动方案，根据本中心所属运动项目特点，广泛开展形式多样、贴近群众、便于参与的全民健身志愿服务活动，特别是结合举办全国性赛事活动，协调处理好竞赛活动与志愿服务的关系，在比赛结束后组织参赛运动员、教练员、裁判员进入社区、村镇、厂矿、学校开展全民健身志愿服务，传授符合群众需求的健身方法、与群众一起进行体育锻炼、进行体育表演展示等，使广大群众感受体育带来的乐趣与益处，提高体育健身意识，养成科学、健康、文明的生活方式。

**三、**努力形成全民健身志愿服务活动品牌。各运动项目管理中心要充分认识全民健身志愿服务的长期性，在策划活动方案时，将今年的活动计划与今后的活动规划有机结合，持之以恒，形成传统，逐步打造开展全民健身志愿服务活动的名称、口号、标识，切实建立开展全民健身志愿服务活动长效化机制，努力形成本项目开展全民健身志愿服务活动品牌。

**四、**请各运动项目管理中心于4月20日前将活动方案报国家体育总局群体司组织建设处，总局将选择其中的优秀全民健身志愿服务活动给予资金支持。
