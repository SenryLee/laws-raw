# 全国老龄办关于征集2012年重阳节《红叶风采》文艺晚会节目的通知

各省、自治区、直辖市、计划单列市老龄工作委员会办公室，新疆生产建设兵团老龄工作委员会办公室：

中国老年艺术团是全国老龄工作委员会办公室领导下的全国性老年业余艺术团，委托中国老龄事业发展基金会代管。自2003年成立以来，在各地老龄办的大力支持下，中国老年艺术团连续9年成功举办了重阳节《红叶风采》大型文艺晚会，得到了中央领导同志、有关方面专家、艺术家及广大观众的一致好评，切实起到了推动基层老年群众文化活动蓬勃开展的作用。

2012年是党的第十八次大会召开之年，民政部、文化部、国家广电总局、全国妇联和全国老龄办将继续主办“第三届中国老年文化艺术节颁奖暨《红叶风采》大型文艺晚会”。晚会由中国老龄事业发展基金会承办，中央电视台现场录制，拟于重阳节当天黄金时段播出。为组织好此项活动，现将有关事项通知如下：

**一、**晚会主题和时间

晚会主题为“金风吹过叶更红”，晚会录制时间为重阳节（10月23日）前一周。

**二、**晚会的内容

晚会内容分为三个篇章。

第一篇章：“红色传承”。庆祝党的“十八大”召开，感恩党对广大老年人的培养、教育和关爱，歌颂党的光荣传统和老一辈无产阶级革命家的丰功伟绩。

第二篇章：“多彩时代”。反映老年朋友面对当今这多彩纷呈的时代，在维护权益、婚姻家庭、新生事物、心理调适等方面所遇到的各种问题，倡导积极乐观的生活态度，弘扬中华民族敬老爱老的传统美德。

第三篇章：“金色年华”。反映改革开放以来的社会经济发展，人民安居乐业，老年人老有所学、老有所为、老有所乐的幸福生活，倡导科学、健康、文明的生活方式，以无私奉献、积极进取的态度步入人生的第二个春天。

**三、**节目推荐及参演办法

1.节目主要由各省、自治区、直辖市、计划单列市老龄办和新疆生产建设兵团老龄办向中国老年艺术团推荐。

2.各地老年艺术团体经主管部门同意，也可向中国老年艺术团报送节目光盘。

3.解放军、中直机关、国家机关、国有大型企业老干部局可直接推荐本系统优秀节目。

4.各地老年艺术团体可登录中国老年艺术团网站，通过上传视频报送节目。

5.从今年全国老龄办举办的“第三届中国老年文化艺术节”中选拔优秀获奖节目。

推荐和报送的节目经中国老年艺术团导演组审查初选，确定为参演节目后，再进行重点加工。所有晚会入选节目都将发给纪念证书。所有推荐和报送节目的单位都将获赠晚会录制光盘。

**四、**节目标准

1.以小见大，以情动人，真实、生动、形象地反映当代老年人的生活和心声，较好地表现晚会主题。

2.形式新颖、类型多样，鼓励原创，特别欢迎小品、说唱、曲艺等语言类节目。

3.地方特色鲜明，民族特点突出。

4.参演人员以老年人为主体。

**五、**报送要求

1.报送节目种类：舞蹈、声乐、器乐、曲艺、小品、戏曲、服饰表演以及各种其他形式的语言类节目。节目要求录制成光盘（DVD格式），并附上节目简介、剧照。

2.报送节目截止时间：2012年6月15日。

3.在报送节目的同时，请将各自老年艺术团体的简介、负责人联系方式和代表性节目剧照，一并报送。
