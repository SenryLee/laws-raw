# 国家质量监督检验检疫总局关于2012年第2批产品质量国家监督抽查情况的通报

## 国家质量监督检验检疫总局关于2012年第2批产品质量国家监督抽查情况的通报（2012年6月26日　国质检监函[2012]318号）

各省、自治区、直辖市及新疆生产建设兵团质量技术监督局：

2012年2月至4月，国家质检总局组织了第2批产品质量国家监督抽查，涉及日用消费品、建筑和装饰装修材料、食品、工业生产资料、农业生产资料等5大类产品。现将抽查结果的主要情况通报如下：

**一、**基本情况

(一)本次共抽查了26类2339家企业生产的2374种产品(不涉及出口产品)，有2119种抽查合格，产品抽样合格率为89．3％。其中，吸油烟机、稻麦联合收割机抽样合格率为100％，食品用塑料容器、安全网、黄酒、压力锅等11类产品抽样合格率为90．0％至99．2％，童鞋、胶合板、家用燃气灶、啤酒瓶等10类产品抽样合格率为80．0％至89．9％：砂轮、滚动轴承、电子计价器等3类产品抽样合格率低于80％。

(二)按企业生产规模划分，本次抽查的大、中、小型企业数分别占抽查企业总数的13．6％、 19．8％、66．6％，产品抽样合格率分别为95．3％、93．0％、86，8％。

图：抽查企业数比例图(略)

一是抽查了9类699家企业生产的707种日用消费品，包括童车、童鞋、吸油烟机、家用燃气用具、电压力锅、电磁灶、厨房机械、啤酒瓶、食用塑料容器。

二是抽查了4类473家企业生产的473种建筑和装饰装修材料，包括胶合板、刨花板、钢化玻璃、机制簇绒地毯。

三是抽查了5类644家企业生产的647种食品，包括白酒、啤酒、黄酒、葡萄酒、蜜饯。

四是抽查了7类493家企业生产的517种工业生产资料，包括安全帽、安全网、电子计价秤、滚动轴承、砂轮、避雷器、机动车辆制动液。

五是抽查了30家企业生产的30种稻麦联合收割机。

(四)本次抽查主要特点。

一是加强发证产品监督。在本次抽查的26类产品中，涉及7类工业生产许可证产品，5类食品生产许可证产品，7类国家强制性认证产品，共占本次抽查产品类别总数的85．7％。

二是加大跟踪抽查力度。本次抽查中的25类产品是跟踪监督抽查，对其中上一次抽查产品质量不合格的255家企业进行了连续跟踪抽查。

三是突出抽查集中产区。结合产品区域分布特点，对吸油烟机、电磁灶、电压力锅、黄酒、滚动轴承、童车、童鞋等产品生产集中区企业进行了重点抽查。

**二、**抽查结果分析

(一)日用消费品。

1．童车。重点抽查了天津、河北、江苏、浙江、福建、广东等6个较为集中的产区，包括儿童自行车、儿童三轮车、儿童推车、婴儿学步车、其他玩具车辆5个品种。共抽查了116家企业生产的116种产品，约占全国获强制性认证证书童车企业总数的30％。本次共对童车产品的机械物理性能、燃烧性能、重金属迁移元素、产品标识4大类118个项目进行了检验。抽查结果表明：有93种产品符合标准规定：对2011年抽查不合格的22家企业跟踪抽查中，已有8家企业被行政处罚责令停产或暂停资格证书，其余的14家企业产品经抽样检验达标。抽查共检出23种产品不合格，主要质量问题是，个别儿童自行车存在锐利边缘，个别婴儿学步车的动态强度不达标，个别儿童推车的动态耐久性试验不合格等。

2．童鞋。抽查了北京、上海、江苏、浙江、福建、广东、四川等7个省市，共计抽查了100家企业生产的200种产品，包括儿童皮鞋、皮凉鞋、旅游鞋等品种，抽查企业数约占全国童鞋生产企业总数的10％，重点检验了耐磨性能、剥离强度、外底硬度、感官质量、衬里和内垫摩擦色牢度、鞋帮带拉出强度、游离甲醛、可分解有害芳香胺染料等8个项目。抽查结果表明：检出16种产品不合格，主要质量问题是，外底耐磨性能、帮带拉出强度、外底硬度、感官质量、游离甲醛等项目不达标。

3．吸油烟机。共抽查了广东、浙江、江苏3个主产区52家企业生产的60种产品，约占全国吸油烟机生产企业总数的13％。本次重点检验了吸油烟机的输入功率和电流、发热、工作温度下的泄漏电流和电气强度、泄漏电流和电气强度等16项安全指标及空气性能、吸油烟机噪声限值2项性能指标。本次所有被抽查产品全部符合标准规定。通过连续3年跟踪抽查，吸油烟机的风量、风压、噪声限值等指标的虚标现象得到了很大的改善。

4．家用燃气用具。共抽查了上海、江苏、浙江，湖南、广东、四川6个省(市)70家企业的70种产品，重点对家用燃气灶具的气密性、烟气中一氧化碳浓度、热效率、电气性能、燃气导管和铭牌标示适用燃气种类等17个项目进行了检验。抽查检出8种产品不合格，存在的主要质量问题是，2种产品热负荷偏差及主火实测折算热负荷不合格，2种产品燃气导管不合格，1种产品烟气中一氧化碳浓度不合格， 1种产品热效率不合格，2种产品气密性不合格。

5．电压力锅。共抽查了浙江、广东两2省80家企业生产的80种产品，约占全国生产企业总数的 40％。重点检验了电压力锅产品的输入功率和电流、发热、工作温度下的泄漏电流和电气强度、耐潮湿、泄漏电流和电气强度、爬电距离和固体绝缘等15项安全指标及产品与食物接触部分卫生要求(内胆)、密封圈卫生要求2项卫生指标。经检验，有5种产品密封圈卫生要求中正己烷蒸发残渣不合格，有1种产品与食物接触部分卫生要求中铬析出量超标。

6．电磁灶。共抽查了广东、江苏、浙江、上海等4个省(市)45家企业的45种产品，约占全国生产企业总数的四分之一。对包括产品的输入功率和电流、发热、工作温度下的电气绝缘和泄漏电流、耐潮湿、泄漏电流和电气强度、接地措施、能源效率等级等17个项目进行了检验。抽查结果表明：1种产品对触及带电部件的防护项目不合格，2种产品非正常工作项目不合格，4种产品机械强度项目不合格，1种产品电气间隙、爬电距离和固体绝缘项目不合格，4种产品能源效率等级项目不合格。

7．厨房机械。共抽查了广东、浙江、江苏、山东和河北5个省37家企业生产的37种产品，占全国生产企业总数的18．5％。抽查产品种类包括榨汁机、搅拌机、料理机、多功能食品加工机、打蛋机等。本次抽查重点对厨房机械产品的对触及带电部件的防护、输入功率和电流、发热、工作温度下的泄漏电流和电气强度、耐潮湿、泄漏电流和电气强度等16个安全性能指标进行了检验。抽查检出的主要质量问题为：1种产品对触及带电部件的防护不合格，2种产品发热项目不合格。

8．啤酒瓶。共抽查了23个省(区、市)79家企业生产的79种产品，抽查企业数约占全国生产企业的79％。重点检验了抗冲击、耐内压力、抗热震性、铅、镉、砷、锑等重金属溶出允许限量、满口容量和标志等9个主要项目。本次抽查检出的主要质量问题是：10种产品抗冲击指标不符合国家标准， 1种产品耐内压力指标不符合国家标准。

9．食品用塑料容器。共抽查了13个省(市)120家企业的120种产品，包括矿泉水瓶、饮料瓶、调料瓶、食用油瓶、水壶和水杯等，抽查企业数约占全国生产企业数的6％。重点对感官、脱色试验、蒸发残渣、重金属、跌落性能、耐内压力、酚等16个项目进行了检验。抽查发现1种产品的跌落性能不合格。

(二)建筑和装饰装修材料。

10．胶合板。共抽查了10个省(市)199家企业的199种产品，重点检验了产品的含水率、胶合强度和甲醛释放量等3个项目。经检验，有12种产品甲醛释放量超标，有5种产品胶合强度未达标，有4种产品含水率未达标。

11．刨花板。共抽查了16个省(区、市)147家企业的147种产品，重点对刨花板产品的吸水厚度膨胀率、静曲强度、内结合强度、表面结合强度等4项物理性能指标和1项甲醛释放量环保指标进行了检验。抽查结果表明：21种产品吸水厚度膨胀率超标，6种产品静曲强度不达标，5种产品内结合强度不达标，7种产品表面结合强度不达标，5种产品甲醛释放量超标。

12．钢化玻璃。共抽查了9个省(市)90家企业的90种产品，抽查企业数约占全国生产企业总数的4％。重点检验钢化玻璃产品的碎片状态、抗冲击性、霰弹袋冲击性能、耐热冲击性能、表面应力等 5个项目。本次抽查产品的抗冲击性、霰弹袋冲击性能、耐热冲击性能、表面应力均能符合标准的要求，抽查中发现的主要质量问题是，12种产品碎片状态不符合标准要求。

13．机制簇绒地毯。共抽查了13个省(市)37家企业的37种产品，抽查的企业数占全国同类产品企业总数的77．1％。重点对地毯外观保持性(六足)、绒簇拔出力、耐光色牢度、耐摩擦色牢度、毯面纤维类型及含量、阻燃性能(燃烧长度、临界热辐射通量)等7个项目进行了检验。抽查发现，2种产品阻燃性能--临界热辐射通量不合格，2种产品耐光色牢度不达标，1种产品绒簇拔出力不达标。

(三)食品。

14．白酒。共抽查了23个省(区、市)199家企业生产的200种产品，约占全国获证白酒生产企业总数的2．3％。重点对甲醇、铅、锰、甜蜜素、酒精度、总酸、总酯、固形物等12个项目进行了检验。抽查结果表明，甲醇、铅，锰等卫生安全指标的检验结果均符合标准规定，检出3种产品超范围使用甜蜜素，1种产品酒精度不合格，3种产品固形物超标，2种产品总酸、总酯不达标。

15．啤酒。共抽查了16个省(区、市)80家企业的80种产品，约占全国获证啤酒生产企业总数的15．3％。重点对啤酒产品的包装、警示语标注、酒精度、原麦汁浓度、甲醛、铅、致病菌、菌落总数、大肠菌群等15项指标进行了检验。抽查结果为，有79种产品抽查合格，检出1种啤酒的酒精度、原麦汁浓度指标未达到标准要求。

16．黄酒。共抽查了7个省(市)80家企业的80种产品，重点对非糖固形物、酒精度、氨基酸态氮、铅、苯甲酸、山梨酸、糖精钠、菌落总数等14个项目进行了检验。本次抽查发现的问题是，有1种产品菌落总数超标，有1种产品酒精度不达标，有1种产品超范围使用甜蜜素。

17．葡萄酒。共抽查了13个省(区、市)148家企业的150种产品，重点对酒精度、甲醇、苯甲酸、山梨酸、铅、菌落总数、大肠菌群、致病菌等14个项目进行了检验。抽查结果显示，检出3种产品菌落总数超标，1种产品酒精度与标称值不符。

18．蜜饯。共抽查了16个省(区、市)137家企业的137种产品，重点检验了蜜饯产品的甜蜜素、安赛蜜、总砷、铅、铜、菌落总数、大肠菌群、沙门氏菌、金黄色葡萄球菌等21个项目。本次抽查中山梨酸、糖精钠、总砷、铅、铜、大肠菌群、沙门氏菌、金黄色葡萄球菌、志贺氏菌、霉菌10项指标均符合标准要求。抽查检出2种产品菌落总数超标，1种产品超范围使用甜味剂--安赛蜜，8种产品超限量使用食品添加剂(苯甲酸、二氧化硫、甜蜜素、胭脂红)。

(四)工业生产资料。

19．机动车辆制动液。共抽查了19个省(市)54家企业的70种产品，重点检验了机动车辆制动液产品的平衡回流沸点、湿平衡回流沸点、运动粘度(-40℃、100℃)、pH值、低温流动性和外观、蒸发性能、容水性等7个指标。抽查检出的主要质量问题有：6种产品蒸发性能不达标，1种产品低温流动性和外观不合格，1种产品容水性不达标。

20．安全帽。共抽查了13个省(市)127家企业的130种产品，约占全国安全帽生产企业的40％。依据国家强制性标准，重点检验了冲击吸收性能等8个指标。抽查结果表明：本次抽查的大中型企业产品全部合格。检出9种小型企业的产品冲击吸收性能不合格，4种产品低温耐穿刺性能不合格。

21．复合外套无间隙金属氧化物避雷器。共抽查了13个省(市)59家企业的59种产品，约占全国避雷器生产企业的14％。本次抽查产品全部为35kv及以下交流系统用复合外套无间隙金属氧化物避雷器，重点检验了6项电气安全指标和1项密封性能指标。抽查结果表明：大中型企业产品质量较好，部分小型企业产品质量较差。本次抽查发现有5种产品雷电冲击残压试验不合格，4种产品长持续时间电流冲击耐受试验不合格，11种产品大电流冲击耐受试验不合格。

22．安全网。共抽查了8个省(市)60家企业的60种安全网产品，约占全国生产企业的25％。安全网按功能分为安全平网、安全立网及密目式安全立网3种。2011年抽查产品质量不合格的9家企业，在本次跟踪抽查中被检产品符合标准。抽查发现有3种密目式安全立网产品不合格，主要质量问题是耐冲击性能、阻燃性能、断裂强力×断裂伸长3个项目不合格。

23．砂轮。共抽查了16个省(市)119家企业的119种产品，包括陶瓷平形砂轮、树脂平形砂轮、橡胶平形砂轮、纤维增强树脂切割砂轮、修磨用钹形砂轮、单面凹带锥砂轮。重点检验了砂轮的外观、硬度、静平衡、回转试验、标志等9个项目。抽查检出16种产品孔径不合格，6种产品回转强度不合格， 5种产品硬度不合格，1种产品静平衡不合格，反映出部分企业生产工艺技术水平和质量管理工作较差。

24．滚动轴承。共抽查了浙江、江苏、河南、山东、辽宁、黑龙江6个轴承制造聚集区49家企业的49种产品，包括深沟球轴承、圆锥滚子轴承、圆柱滚子轴承、调心滚子轴承、推力球轴承等品种。重点对尺寸精度、旋转精度、外观、硬度、寿命可靠性、密封轴承(防尘、漏脂、温升)等项目进行了检验。其中，被检产品密封轴承(防尘、漏脂、温升)3项性能全部合格，为历年国家监督抽查该检验项目合格率最高的1次。本次抽查中发现部分小企业存在较多质量问题，检出8种产品寿命可靠性不合格、5种产品游隙超标、3种产品尺寸精度超标、3种产品工作表面烧伤不合格、3种产品残磁限值超标、1种产品显微组织不合格、1种产品振动(速度)不合格，有1家企业拒绝监督抽查。

25．电子计价秤。共抽查了7个省(市)25家企业的30种产品，重点对电子计价秤外观、功能、称量性能、除皮称量、重复性、湿热稳定状态、干扰性能等12个项目进行了检验。抽查结果表明，被检产品的外观、功能、称量性能、除皮称量、偏载、鉴别力、重复性、与时间相关测试的检验项目均符合标准／规程要求，但是有较多产品的温度试验和干扰试验项目质量问题多，有10种产品的温度测试项目不合格、8种产品的干扰性能测试项目不合格、7种产品的湿热稳定状态试验不合格、2种产品的倾斜测试项目不合格。

(五)农业生产资料。

26．稻麦联合收割机。共抽查了黑龙江、河北、河南、山东、江苏、浙江等9个省(区)30家企业的30种产品，被抽查的企业数约占全国生产企业总数的50％。重点对稻麦联合收割机的安全距离、防护装置和屏障的强度要求、制动性能、后视镜及喇叭、环境噪声、耳位噪声、标志、使用说明书中安全注意事项等31个项目进行了检验。本次所抽查的30种产品经检验综合判定全部达标。

**三、**跟踪抽查分析

(一)产品跟踪抽查情况。本次抽查的产品中，近5年已连续跟踪抽查2次以上的产品共有22类，占本次抽查产品类别总数的84．6％，跟踪抽查3次以上的产品有16类，占本次抽查产品类别总数的 61．5％。连续跟踪抽查结果表明：童鞋、吸油烟机、家用燃气灶、刨花板等产品抽查合格率有不同程度的提高，滚动轴承、避雷器的抽样合格率仍然不高，电子计价秤、电磁灶、砂轮等产品抽查合格率有所降低。

(二)生产企业跟踪抽查情况。本次对255家上次抽查不合格的企业进行了跟踪抽查，发现有78家企业已不再生产同类产品或已停产停业。在实际抽查到的170家中，有147家企业本次抽查合格，占总数的86．5％，有23家企业连续2次产品质量抽查不合格(详见附件1)。跟踪抽查结果反映出，各地质监部门针对前次抽查发现的问题，严格依法进行了抽查后处理工作，加大了依法关停整顿力度，督促生产企业查找质量问题原因，落实技术改进和完善质量控制等整改措施，切实起到了督促企业提高产品质量水平的重要作用。

**四、**处理意见

针对本次产品质量国家监督抽查中发现问题，各地质量技术监督部门应按照《中华人民共和国产品质量法》和《产品质量国家监督抽查管理办法》等法律法规的规定，做好以下工作：

(一)对于本次抽查中产品质量不合格的生产企业，严格依法进行处理。特别是对抽查中发现产品质量不符合国家强制标准的，应责令企业停止生产销售不合格产品，按照有关规定监督销毁或者作必要的技术处理。

(二)针对本次抽查中反映出的突出质量问题和共性质量问题，如电压力锅的密封圈卫生要求中正己烷蒸发残渣不合格、啤酒瓶的抗冲击指标不符合国家标准、刨花板的吸水厚度膨胀率超标、砂轮的孔径不合格等，要加大后续跟踪和监督检查力度。

(三)将本次抽查不合格产品情况通报地方政府及相关部门，加强对发证产品的后续监管，督促企业加强自律，提高守法意识，引导企业严格按照标准要求组织生产。

(四)请各省级质量技术监督部门严格依法做好本次抽查不合格产品生产企业的后处理工作，跟踪企业整改情况，尤其是做好近3年产品质量国家监督抽查中连续2次抽查不合格产品生产企业的后处理，并于2012年8月30日前，填报《2012年第2批产品质量国家监督抽查不合格产品生产企业后处理情况表》(附件2)，以正式文件和电子版形式报总局产品质量监督司：同时使用2011版国家监督抽查软件，填报后处理信息，将形成的软件数据报总局产品质量监督司。
