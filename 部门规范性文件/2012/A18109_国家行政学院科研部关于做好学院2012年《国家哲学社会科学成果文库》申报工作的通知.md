# 国家行政学院科研部关于做好学院2012年《国家哲学社会科学成果文库》申报工作的通知

各教研人员及有关人员：

经全国哲学社会科学规划领导小组批准，2012年《国家哲学社会科学成果文库》将在近期开始受理申报。为了做好此项工作，国家社科规划办下发了《关于做好2012年<国家哲学社会科学成果文库>申报组织工作的通知》，请大家登陆全国哲学社会科学规划办公室网站“《成果申报》”栏目查询（http：//www.npopss-cn.gov.cn）。现根据《通知》要求，将我院申报组织工作有关事项通知如下：

**一、**申报材料要求

1．《〈国家哲学社会科学成果文库〉申请书》一式4份。可从全国社科规划办网站“《成果文库》申报”栏目（网址：http：//www.npopss-cn.gov.cn/）下载，按要求用计算机填写，A3纸双面打印，中缝装订，填写好推荐意见。

2．装订成册的成果打印稿5套；成果概要一式7份，包括著作名称、目录、5千至1万字的成果内容介绍、主要参考文献，其中著作名称和目录须附英文译文。成果书稿A4纸双面印制、左侧装订成册，成果概要A3纸双面打印、中缝装订，成果书稿和概要不得直接或间接透露申请人姓名和单位等个人信息或相关背景材料。

3．以博士学位论文申报的，须提交论文原文，并附详细修改说明；以往年申请未入选成果申报的，须附详细修改说明。

4．电子光盘2份，须包含申请书、书稿、概要、附件等所有申报数据，并请标明申请人姓名、单位及学科分类。

**二、**申报受理时间和地点

请有意申报的同志提前与科研部联系，预先做好材料准备，在2012年6月18日-6月22日间，将材料送交科研部（学院主楼C413室）。过期不再受理。
