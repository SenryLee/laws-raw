# 民政部基层政权和社区建设司关于《“中国社区”标识规范应用手册》的通告

为规范“中国社区”标识的设计制作，加强城乡社区标识规范化管理，根据《民政部关于做好“中国社区”标识启用工作的通知》（民发〔2012〕66号）要求，现将《“中国社区”标识规范应用手册》予以公布，请有关使用单位遵照执行。

附件：“中国社区”标识规范应用手册（略）

民政部基层政权和社区建设司

二〇一二年六月五日
