# 民政部办公厅关于组织参加2012年中国(青岛)国际康复器具博览会的通知

## 民政部办公厅关于组织参加2012年中国（青岛）国际康复器具博览会的通知（民办函〔2012〕299号）

各省、自治区、直辖市民政厅（局），各计划单列市民政局，新疆生产建设兵团民政局：

为了展示国内外康复辅具行业的最新科研和实践成果，搭建国际间康复辅具产品、技术和信息交流的平台，促进我国康复辅具事业又好又快发展，由我部主管的中国康复器具协会将举办“2012年中国（青岛）国际康复器具博览会”。现将有关事项通知如下：

**一、**时间和地点

2012年10月20-22日，青岛国际会展中心1号馆（青岛市崂山区苗岭路9号）。

**二、**主题和内容

（一）博览会将坚持社会性和公益性特点，延续“展示宣传、交流合作、服务大众、共同发展”的主题，重点围绕残障人康复辅具服务、康复护理服务、精神文化服务、保健养生服务、信息服务、人才培训服务和康复服务品牌推广等方面进行展览，为国家养老助残工作贡献绵薄之力。

（二）博览会举办期间，将举办学术报告和技术交流会议。国内外知名专家学者将与参会人员共同分享康复辅具领域的新产品、新技术和新信息，促进行业理念创新，加强交流合作，推动行业有序发展。

**三、**参会方式

请各省、自治区、直辖市和新疆生产建设兵团民政厅（局）组织本地区、本行业的民政部门、科研机构、服务机构（含综合性社会福利机构、养老机构、残疾人福利机构、儿童福利机构、假肢矫形康复机构）和社会组织相关人员赴会观摩，积极参与各类主题研讨，加强与同行业的交流学习。

**四、**注意事项

（一）参加博览会的食宿费用自理。

（二）民政系统的参会事宜由中国康复器具协会负责协调。请各地以省为单位于10月12日前，将参会回执表（见附件）传真至中国康复器具协会组委会。详情可登录中国康复器具协会官方网站http：//www.crda.com.cn

（三）参会人员无需报到，博览会期间如有任何问题，请致电组委会工作人员。联系人：中国康复器具协会联络部，张峥，18611704115。

附件：参会回执表（略）
