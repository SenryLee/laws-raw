# 国家测绘地理信息局办公室关于召开2012年全国测绘地理信息局长座谈会的通知

## 国家测绘地理信息局办公室关于召开2012年全国测绘地理信息局长座谈会的通知（测办〔2012〕47号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司局：

国家测绘地理信息局党组研究决定，7月初在京召开2012年全国测绘地理信息局长座谈会。现将有关事项通知如下：

**一、**会议任务

进一步深入贯彻落实李克强副总理视察中国测绘创新基地时的重要讲话精神，以科学发展观为指导，总结上半年的工作，研究存在的问题，分析面临的形势，部署下半年重点任务，推进全年工作落实，以优异成绩迎接党的十八大胜利召开。

**二、**会议时间和地点

（一）会议时间：2012年7月12－14日上午（11日报到）

（二）会议地点：中华全国总工会国际交流中心（北京市顺义区后沙峪）

**三、**参加人员

（一）国家测绘地理信息局局长、副局长、党组成员、总工程师。

（二）各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门、新疆生产建设兵团测绘地理信息主管部门主要负责同志。

（三）局所属各单位、机关各司局、离退休干部办公室、中国测绘学会、中国地理信息产业协会、中国全球定位系统技术应用协会党政主要负责同志。

（四）北京市测绘设计研究院、天津市测绘院、内蒙古自治区测绘事业局、安徽省测绘局、山东省国土测绘院主要负责同志。

**四、**主要议程

（一）机关各司局、离退休干部办公室、局机关服务中心主要负责人发言。

（二）各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门、新疆生产建设兵团测绘地理信息主管部门主要负责人，部分测绘院（局）主要负责人，局所属单位主要负责人发言。

（三）国家测绘地理信息局领导讲话。

**五、**其他事项

（一）各单位重点针对本单位、本部门上半年重点工作推进成效、存在问题、下一步推进计划及建议进行发言，每单位1名主要负责人发言，发言时间不得超过8分钟。

（二）各单位“上半年工作小结和下半年重点工作落实计划”由国家测绘地理信息局办公室统一汇编成册，作为会议书面交流材料（字数要求不超3500字）。请各单位于6月28日前将材料电子文档报国家测绘地理信息局办公室，邮箱地址：zwxx@sbsm.gov.cn；联系电话：（010）63882521。

（三）请各单位妥善安排主要负责人的工作日程，确保按要求参加会议，参加会议不中途请假、不带助手。请于7月9日12：00前将会议报名表（见附件）传真至国家测绘地理信息局办公室和局机关服务中心办公室。
