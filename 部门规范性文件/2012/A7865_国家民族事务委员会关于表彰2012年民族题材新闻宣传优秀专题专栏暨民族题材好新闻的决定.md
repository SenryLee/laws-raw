# 国家民族事务委员会关于表彰2012年民族题材新闻宣传优秀专题专栏暨民族题材好新闻的决定

各有关新闻媒体：

2012年，各新闻单位高度重视民族宣传工作，广大新闻工作者积极关注民族题材新闻宣传，通过策划少数民族题材专题专栏、刊发系列文章等形式，积极宣传党的民族理论、民族政策和民族工作成就，普及民族知识，弘扬民族文化，反映各族人民心声，为促进民族团结进步营造了良好的舆论环境。为鼓励新闻单位和新闻工作者进一步做好民族工作宣传报道，根据《国家民委关于建立健全新闻宣传工作机制的实施意见》，决定对21家新闻媒体的30个专题专栏予以表彰，并颁发“2012年民族题材新闻宣传优秀专题专栏”获奖证书，对23家媒体的32篇（条）新闻作品予以表彰，并颁发“2012年民族题材好新闻”获奖证书。希望获奖的新闻单位和新闻工作者再接再厉，进一步加大民族工作宣传力度，为民族团结进步事业做出新的贡献。
