# 国家文物局关于邀请参加2012年全国文物局长会议的通知

## 国家文物局关于邀请参加2012年全国文物局长会议的通知（办秘函〔2012〕953号）

主送国办等有关部委：

根据2012年工作安排，国家文物局将于2012年12月25日至12月26日上午在北京召开全国文物局长会议，此次会议的主要内容是：学习贯彻党的十八大精神，落实全国文物工作会议的各项要求，总结2012年全国文物工作；部署2013年重点工作。

现特邀请你司局负责同志1人参加12月25日上午9：00在北京西藏大厦B座10层大宴会厅召开的全体会议。会期半天（地址：北京市朝阳区北四环东路118号；电话：010-64981133）

敬请于2012年12月18日前将参加会议回执传真至我局办公室秘书处。联系人：董琳 刘微；电话：56792211；56792130（传真）。

届时请参会人员持此会议通知于12月25日上午8：45前到西藏大厦A座大堂报到并参加会议。

特此通知。
