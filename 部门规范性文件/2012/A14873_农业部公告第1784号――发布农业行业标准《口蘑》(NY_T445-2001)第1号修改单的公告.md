# 农业部公告第1784号――发布农业行业标准《口蘑》(NY/T445-2001)第1号修改单的公告

## 农业部公告（第1784号）

经专家审定通过，我部审查批准，现发布农业行业标准《口蘑》（NY/T445-2001）第1号修改单，自发布之日起实施。

特此公告。

二〇一二年六月六日

附件：

农业行业标准《口蘑》（NY/T445-2001）第1号修改单

将5.2理化指标修订为：

|  |  |  |  |
| --- | --- | --- | --- |
| 项目 　　分类 | 粗蛋白（%） | 粗纤维（%） | 灰分（%） |
| 蒙古口蘑 | ≥29 | ≤9 | ≤11 |
| 大白桩口蘑 | ≥27 | ≤9 | ≤15 |
| 香杏口蘑 | ≥32 | ≤11 | ≤15 |
| 褐口蘑 | ≥34 | ≤11 | ≤12 |

水分含量按照GB 7096规定执行。
