# 中国地震局党组关于张雅玲同志退休的通知

中国地震局党组关于张雅玲同志退休的通知

（中震党发〔2012〕56号）

中共青海省地震局党组：

根据张雅玲同志提出提前退休的申请，按照《公务员法》有关规定，免去张雅玲同志青海省地震局副巡视员职务，按国家有关规定退休。

特此通知

二○一二年六月十八日
