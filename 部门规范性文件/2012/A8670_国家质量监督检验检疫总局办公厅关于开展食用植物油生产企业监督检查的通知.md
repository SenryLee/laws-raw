# 国家质量监督检验检疫总局办公厅关于开展食用植物油生产企业监督检查的通知

## 国家质量监督检验检疫总局办公厅关于开展食用植物油生产企业监督检查的通知（2012年11月14日　质检办食监函[2012]1045号）

各省、自治区、直辖市质量技术监督局：

为贯彻落实《国务院办公厅关于印发2012年食品安全重点工作安排的通知》(国办发[2012]16号)、国务院食品安全办《关于进一步加强“地沟油”专项整治工作的通知》(食安办[2012]26号)精神，深化食用油综合治理，进一步做好食用植物油质量安全监管工作，总局决定在全国范围内组织对获得食品生产许可证的食用植物油生产企业开展监督检查。有关事项通知如下：

**一、**检查范围和方式

本次食用植物油生产企业监督检查工作由各省级局组织对所有获得食品生产许可证的食用植物油生产企业监督检查。监督检查过程中，对发现的食品安全问题要查明原因，必要时展开全面检验。检验工作由指定的检验机构进行。

**二、**检查内容

各地要按照食品安全法律法规和《食品生产加工企业落实质量安全主体责任监督检查规定》(质检总局公告2009年第119号)的要求，监督检查企业资质、进货查验、过程控制及出厂检验等食品生产全环节。企业自行完成产品出厂检验的，要检查企业是否具备相应检验能力，委托检验机构检验的，要检查其是否具备相应资质。重点检查企业是否生产或使用“地沟油”，以及原辅料、添加剂、接触材料等可能会对食品造成污染的环节。对所使用原辅料、添加剂、接触材料、半成品及最终产品有疑议的，应组织抽样，送指定检验机构进行检验。检验工作由国家农副加工食品质量监督检验中心、黑龙江省质量监督检测研究院和湖南省产商品质量监督检验院承担，具体分工及联系方式见附件1。

**三、**问题处置

各地在监督检查过程中，发现企业存在违法行为的，要严格按照有关法律法规予以查处。对食品生产企业故意使用“地沟油”作为原料生产食品的，存在生产、使用“地沟油”的嫌疑的，要立即移交公安机关，配合做好进一步调查工作。

**四、**信息报送

各省级局填写《食用油监督检查情况统计表》(附件2)，形成食用植物油监督检查报告，于2012年 12月20日前报总局食品司。
