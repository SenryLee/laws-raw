# 新闻出版总署关于开展厉行节约工作专项检查的通知

## 新闻出版总署关于开展厉行节约工作专项检查的通知（新财预【2012】39号）

各署直单位：

根据国管局等四部委联合下发的《关于开展中央国家机关厉行节约工作专项检查的通知》（国管财【2012】177号），国管局等四部委定于今年上半年在中央国家机关开展厉行节约工作专项检查，检查范围包括机关本级及所属行政事业单位。

为做好总署的自查工作，现将有关事项通知如下：

**一、**组织开展全面自查

请各单位认真学习《中共中央办公厅 国务院办公厅关于进一步做好党政机关厉行节约工作的通知》（中办发【2011】13号）和国管局等四部委联合下发的《关于中央国家机关带头厉行节约发挥表率作用的通知》（国管办【2011】310号）精神，充分认识开展专项检查工作的重要性和必要性，结合单位实际情况，制定详细的工作计划，对照检查内容，组织开展厉行节约的自查工作，并撰写提交本单位自查报告。

**二、**自查内容

各单位要认真执行中央有关厉行节约、反对铺张浪费的规定和要求，要在保证工作任务不减、工作标准不变、工作质量不降的前提下，压减行政支出，降低行政成本，努力实现2011年用电、用水、用油、用气比2010年下降2％的目标。

（一）切实抓好厉行节约工作

1．节约用水。积极推广使用节水器具，切实搞好用水设备的维修，注重日常监管，坚决杜绝“长流水”和管道“跑、冒、涌、漏”现象。有条件的单位要积极开展再生水利用、雨水收集系统建设，努力达到节水型单位标准。

2．节约用电。严格执行空调控制标准，办公楼空调温度设置 夏季不低于26摄氏度，冬季不高于20摄氏度，充分利用自然通风，尽量少开空调和提前关闭空调。照明用电，尽可能使用自然光照明，杜绝长明灯、白昼灯。计算机、打印机、复印机等办公设备，坚持随用随关，减少待机消耗。加快推进空调、照明系统和信息机房等高消耗设施设备节电改造，积极推行合同能源管理。

3．节约用气。推进燃气锅炉采暖系统的节能诊断和改造，增加余热回收利用装置，减少能源浪费。大力推广使用节气型食堂炉具，年底前省直机关节气型食堂炉具使用率要达到2 0％以上。

4．节约耗材。要规范办公用品的采购、配备、领取、使用和管理。提倡使用环保铅笔、再生纸等节能环保用品，推广使用打印、复印、传真等办公设备可再生耗材，倡导低碳办公，推进无纸化办公，降低纸张消耗，实行双面用纸。树立健康文明、节约环保的理念和风尚，坚决抵制过度包装。严格控制会议数量、会期规模，充分运用网络视频、电视电话等方式召开会议，减少文件、会议材料、会费支出，注重会议质量，提高会议效率。

5．节约用粮。倡导崇尚节俭、科学饮食、健康消费的生活理念和饮食文化，进一步做好机关食堂和所属宾馆、招待所、培训中心等单位餐厅的节约粮食工作，加强粮食和其他副食及原材料的采购、贮存、加工管理，防止腐烂变质造成浪费。按照卫生可口、营养健康、经济适量的原则，烹制食品，努力减少剩余食物。

（二）从严控制“三公经费”支出

1．压减出国（境）经费支出。认真落实国家关于加强因公出国（境）管理的规定，严格出国（境）计划审核，从严控制经费预算，实现因公出国（境）经费预算零增长。相应减少因公出国（境）团组数和人数，严禁借考察、学习、培训、研讨、招商、参展等名义用公款变相出国（境）旅游。不得超预算或无预算安排出国（境）活动，不得接受或变相接受企事业单位资助，或向同级机关、下级机关和下属单位摊派、转嫁费用。严格执行出国（境）费用报销程序、范围和标准，凡超出公款报销范围的个人国（镜）外开支一律由个人承担。

2．控制公务用车经费支出。严格公务用车编制管理，规范审核程序和配备标准，严禁超编制、超标准配车，严禁对公务用车进行豪华装饰。。对闲置的公务用车实行调剂使用，对报废的公务用车实行集中拍卖，防止国有资产流失。进一步完善和加强公务用车使用管理，实行定点加油、定点维修、定点保险、凭卡加油、专人管理，减少公务用车运行费用支出，努力降低运行成本。积极开展公务用车问题专项治理，重点整治党政机关超编制、超标准配备公务用车，以及违规换车、借车、摊派款项购车、豪华装饰和公车私用等问题。领导干部变动工作岗位，能在现有车辆中配备小汽车的，不准配备新车。

3．减少公务接待费用支出。认真落实党政机关国内公务接待管理规定，进一步规范公务接待管理，建立健全管理制度，明确接待规范和标准。要简化迎送程序，实行定点接待。公务接待一般安排在机关食堂，按标准提供工作餐，尽量控制陪餐人数。严禁以举办会议、培训为名，列支、转移、隐匿接待费开支，不得向下级单位或其他关联单位转嫁接待费负担。加强对预算执行的管理，对一些非紧要、非“三最”（群众最关心、最现实、最直接）的事项，能压则压、该减则减、 当缓则缓，从严控制一般性支出，努力节约开支，确保预算平衡。要适时向社会公开“三公经费”预算及支出情况，主动接受社会监督。

（三）继续严格控制楼堂馆所建设

一要严格执行审批程序。继续从严控制机关办公楼等楼堂馆 所建设，确需建设的严格执行审批权限，履行审批程序。二要严格控制建设标准。落实节能设计评审，严格执行国家建设标准。做好项目全过程监管，严格遵守概算分解控制和工程变更管理规 定，从严控制概算调整，强化工程造价和投资控制，规范项目竣工决算管理。三要盘活存量，调剂余缺，纠正部分单位办公用房严重超面积的不合理现象，解决部分单位办公用房紧缺的困难。

（四）推进节能产品采购和信息工程共建共享。

1．认真做好节能产品采购工作。严格执行节能产品政府优先采购和强制采购制度，对节能产品清单中的计算机、打印机、照明产品等9类强制采购的产品实施集中采购，促进机关节水、电等能源资源的节约。

2．积极发挥政府采购规模效应。严格落实政府采购法，坚持依法采购，强化政府采购预算管理和计划管理，严格执行政府集中采购目录，推进批量集中采购，发挥政府集中采购的专业优势和规模效应，努力节约财政资金。

3．大力推进信息工程共建共享。把推进信息工程共建共享作为信息化建设的重点，按照“资源共享、业务协同、安全可靠、节省资金”的要求，切实减少重复建设，积极推进党政机关信息化建设，提高资金使用效益和信息工程设施设备利用率。

**三、**上报要求

各单位的自查报告要全面反映厉行节约工作进展及措施要求落实情况，总结成效，查找问题，提出下一步工作思路和措施。请于7月3日前报送总署财务司，联系人：董晋，联系电话：83138620。电子版发送至：cwsysc@163.com。
