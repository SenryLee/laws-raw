# 文化部机关党委关于印发《2012年文化部直属机关党建工作要点》和《2012年文化部直属机关纪检工作要点》的通知

## 文化部机关党委关于印发《2012年文化部直属机关党建工作要点》和《2012年文化部直属机关纪检工作要点》的通知（党委发字〔2012〕9号）

各司局、国家文物局、各直属单位党委（总支、支部）：

现将《2012年文化部直属机关党建工作要点》和《2012年文化部直属机关纪检工作要点》印发给你们。请结合本单位实际制订今年党建工作计划，并抓好贯彻落实。

特此通知。

二○一二年二月二十九日

附件1：

2012年文化部直属机关党建工作要点

2012年文化部直属机关党建工作的总体要求是：牢牢把握稳中求进、科学发展的总体思路，牢牢把握服务中心、建设队伍两大核心任务，以深入学习宣传贯彻十七届六中全会精神、迎接党的十八大胜利召开和开展基层组织建设年为主线，以改革创新精神和求真务实作风全面加强党的思想、组织、作风、制度和反腐倡廉建设，为文化改革发展工作提供坚强的思想、政治保证，以党的建设新成绩迎接党的十八大的胜利召开。

**一、**做好迎接党的十八大召开和学习宣传贯彻十八大精神工作

（一）按照中央要求，认真做好十八大代表推选工作和出席中央国家机关党代表会议代表推选工作。

（二）大力宣传党的十七大以来文化建设和党的建设取得的伟大成就，宣传文化系统基层党组织和党员干部中的先进典型，引导广大党员干部紧密团结在党中央周围，为文化改革发展贡献力量。

（三）党的十八大召开后，要把学习宣传贯彻会议精神作为重大政治任务抓紧抓好，精心组织会议精神的学习宣传，迅速兴起学习宣传贯彻十八大精神的热潮，切实把党员干部的思想和行动统一到十八大精神上来，把智慧和力量凝聚到实现十八大确定的宏伟目标和各项任务上来。

**二、**以基层组织建设年为契机，深化创先争优活动

（四）按照“抓落实、全覆盖、求实效、受欢迎”的工作要求，通过调查摸底、分类定级，健全组织、扩大覆盖，整改提高、晋位升级，学习先进、创先争优四个步骤开展活动，使基层党组织战斗力进一步提升，基层党组织书记素质进一步提升，党员队伍生机活力进一步提升，基层基础保障水平进一步提升，基层党建制度化水平进一步提升。

（五）以事业单位分类改革为契机，全面推进直属单位党建工作。注重社会组织党建工作，着力解决社会组织党建工作薄弱环节。

（六）抓好基层党组织书记培训。上半年完成新任党支部书记培训，与中央组织部联合举办一期全国文化文物系统党支部书记示范培训班。十八大之后举办基层党组织书记学习贯彻十八大精神专题培训班。

（七）总结创先争优做法和经验，每个基层党组织至少建立一项务实管用的制度，完善基层党务公开制度，落实“三会一课”、民主评议党员、党员教育培训制度、党员党性定期分析制度。

（八）继续开展窗口单位为民服务活动，促进窗口单位更新服务理念，创新服务方式，提高公共文化服务的能力和水平，把文化窗口办成人民满意的窗口。

（九）开展群众评议。以党支部为单位，采取简便易行的方法，主动接受群众对创先争优活动和党建工作的评价和监督，争取做到每个党支部和每名党员都接受评议。

（十）评选表彰全国文化文物系统在创先争优活动中涌现出来的先进基层党组织、优秀共产党员和优秀党务工作者。

**三、**继续开展学习型党组织建设

（十一）按照建设马克思主义学习型政党的要求，坚持以领导班子和领导干部为重点，以提高思想政治素质为根本，进一步推动学习型党组织建设，引导党员干部深入学习党的基本理论、基本路线、基本纲领、基本经验，深入学习贯彻胡锦涛总书记在建党90周年大会上的重要讲话精神和十七届六中全会精神，提高党员干部思想政治素养。

（十二）紧密结合实际，在广大党员中深入开展社会主义核心价值观学习教育活动，深入开展坚定理想信念主题教育、民族精神教育、时代精神教育、社会主义荣辱观和民族团结进步教育。

（十三）继续落实党员集中培训年度计划，根据《中共文化部党组关于加强和改进党员教育培训工作的意见》，继续做好专兼职党务干部培训工作，全面完成部直属机关党员轮训任务，并对三年党员集中培训情况进行总结。

**四、**进一步加强作风建设和反腐倡廉建设

（十四）抓好中央纪委第七次全会精神的贯彻落实，组织干部职工学习胡锦涛总书记在全会上的重要讲话，认真落实文化部2012年党风廉政建设工作会议提出的惩防体系建设年工作。

（十五）继续深入开展“走基层、转作风、改文风”活动，推进党务公开规范化，建立例行公开制度和依申请公开制度。

（十六）严明党的纪律，加强对党的纪律执行情况的监督检查，加强对中央重大决策部署落实情况的监督检查，保证中央政令畅通。

**五、**推动党建工作理论研究，提高党建工作科学化水平

（十七）认真贯彻全国党建研究会和中央国家机关党建研究会有关会议精神，加强党建理论研究，为文化党建工作提供理论支持。

（十八）承担全国思想政治工作研究会、全国党建研究会、中央国家机关党建研究会的课题研究工作。围绕建设社会主义文化强国、构建社会主义核心价值体系等课题开展调查研究，

（十九）向全国文化系统思想政治工作研究会会员单位征集论文，召开研究会年会。向全国党建研究会、中国政研会、中央国家机关党建研究会等上级研究会推荐论文。

**六、**认真做好群众工作

（二十）广泛开展群众性文化活动，积极营造和谐向上的氛围。广泛开展岗位建功、巾帼建功、青年创业创新、业务技能比赛等活动，进一步提高干部职工素质。

（二十一）完成文化部青年联合会和文化部直属机关妇女工作委员会换届选举。配合中国教科文卫体工会全国委员会适时召开全国文化系统职工“德艺双馨建功立业”经验交流会，共同举办“全国文化系统职工摄影展”。以纪念共青团成立90周年为契机，广泛开展一系列丰富多彩、生动活泼、富有青年色彩、对青年有吸引力的活动，组织团员赴基层调研并举办经验交流会。举办全国文化系统“迎接十八大文化青年书画摄影展”。

（二十二）做好统战、侨联工作，积极引导民主党派成员和党外专家在文化建设中发挥作用。

（二十三）结合实际深入开展学雷锋活动，推动学雷锋活动常态化，大力弘扬雷锋精神。

附件2：

2012年文化部直属机关纪检工作要点

2012年文化部直属机关党的纪检工作总体要求是：按照中央纪委七次全会和国务院第五次廉政工作会议的部署，认真落实文化部2012年党风廉政建设工作会议精神，坚持标本兼治、综合治理、惩防并举、注重预防的方针，严明党的纪律，以推进廉政文化建设为重点深化反腐倡廉教育，以改进领导机关和领导干部作风为重点加强作风建设，以推进廉政风险防控机制建设为重点加强惩治和预防腐败体系建设，为完成中心任务提供有力的纪律保证。

**一、**深入学习贯彻落实中央纪委七次全会和国务院第五次廉政工作会议精神

（一）认真抓好中央纪委七次全会和国务院第五次廉政工作会议精神的贯彻落实。组织党员干部和纪检干部深入学习胡锦涛同志在中央纪委七次全会上的重要讲话和贺国强同志的工作报告，深入学习温家宝同志在国务院第五次廉政工作会议上的重要讲话，统一思想认识，明确任务要求。结合各单位实际，提出贯彻落实会议精神的具体措施，加强监督检查，推动文化部党风廉政建设和反腐败工作深入开展。

（二）严明党的纪律，为党的十八大召开营造良好氛围。加强政治纪律教育，引导和督促党员干部自觉同以胡锦涛同志为总书记的党中央在政治上组织上行动上保持高度一致，坚决维护党的团结统一。严格执行党的政治纪律，加强对党的政治纪律执行情况的监督检查，对违反党的政治纪律、编造和传播政治谣言、参与非法组织和非法活动等行为，要依纪依法予以严肃查处。积极配合机关党委做好文化部出席党的十八大代表选举工作，确保选举风清气正。

（三）加强对中央重大决策部署落实情况的监督检查。坚决纠正有令不行、有禁不止的现象，保证党的十七届六中全会精神和中央重大决策部署的贯彻落实。把监督检查与专项治理、案件查处、责任追究结合起来，针对容易滋生腐败的部位和环节制定防治措施，不断提高监督检查的科学化、制度化、规范化水平。

**二、**切实加强机关和党员领导干部作风建设

（四）进一步加强作风建设。按照胡锦涛同志在中央纪委七次全会上关于保持党员干部作风纯洁的要求，切实加强机关和干部作风建设。大力弘扬密切联系群众、求真务实、艰苦奋斗、批评和自我批评的优良作风，进一步密切党群干群关系，以优良的党风促政风、带行风，树立为民、务实、清廉的形象。

（五）加大作风纪律整顿力度。加强对作风建设情况的监督检查。以保持同人民群众的血肉联系为重点，以坚持党的实事求是的思想路线为切入点，以思想教育、完善制度、作风整顿、严肃纪律为抓手，不断加大机关和领导干部作风方面突出问题的整顿力度。认真治理庸懒散问题，严肃处理不作为、乱作为等行为。把作风建设情况纳入党风廉政建设责任制考核范围，加强监督检查，对严重违反作风纪律的问题，及时进行查处。

**三、**深入开展反腐倡廉教育，大力加强机关廉政文化建设

（六）深化反腐倡廉教育。认真贯彻落实党的十七届六中全会精神和《关于加强领导干部反腐倡廉教育的意见》，大力加强政治品质和道德品行教育，继续深化示范教育、警示教育和岗位廉政教育，筑牢拒腐防变的思想道德防线。继续把党纪教育纳入文化部党员集中培训之中，认真总结新形势下文化工作领域反腐倡廉教育的实践和经验，继续发挥运用好《党建在线》等新兴媒体在促进反腐倡廉建设中的积极作用。

（七）开展廉政文化创建活动。坚持以领导机关和领导干部为重点，以树立领导干部秉公用权、廉洁从政价值理念为关键，扎实开展机关廉政文化创建活动。把廉政文化建设与加强机关文化建设、做好思想政治工作结合起来，开展内容丰富、主题鲜明、形式多样的教育活动，在文化部营造“以廉为荣、以贪为耻”的氛围，使广大党员干部把廉洁从政意识转化为精神追求、行为准则和自觉行动。

**四、**加强反腐倡廉制度建设

（八）认真检查各单位反腐倡廉制度建设任务的落实情况。加强对反腐倡廉制度执行情况的监督检查，严格落实各项制度，切实提高制度的执行力，维护制度的严肃性和权威性。

（九）全面推进廉政风险防控机制建设。认真贯彻落实中央关于加强廉政风险防控工作的文件精神，积极配合驻部纪检组把廉政风险防控工作与加强教育、完善制度、强化监督、查办案件结合起来，与推进政务公开、党务公开结合起来，进一步把惩治和预防腐败的要求落实到各个方面。

**五、**进一步强化监督工作

（十）加强党内监督工作。认真贯彻党内监督条例，进一步提高监督的针对性和实效性。加强与纪检组监察局、人事、财务、审计等部门的沟通协调，积极探索和创新机关纪委参与项目审批、干部选拔任用、工程建设招投标、政府采购等方面的监督方式，建立健全工作机制，进一步提高监督的能力和水平。

（十一）加强对领导干部廉洁自律执行情况的监督检查。继续抓好《关于实行党风廉政建设责任制的规定》、《中国共产党党员领导干部廉洁从政若干准则》及其《实施办法》的贯彻落实，着力解决党员领导干部在廉洁自律方面存在的突出问题。会同人事部门，认真执行领导干部报告个人有关事项和对配偶子女均已移居国（境）外的国家工作人员加强管理等制度。

**六、**严格依纪依法查办案件

（十二）做好信访举报工作。认真落实中央纪委《关于加强和规范纪检监察网络举报工作的意见》和《关于进一步加强纪检监察信访举报案件办理工作的意见》等，加强对来信来访反映问题的核查和督办工作，进一步规范信访举报程序，重点做好实名举报和网上举报的受理、查核和回复工作，进一步规范信访举报的交办、督办、查办和审核的各个环节，切实加强和改进信访举报工作。

（十三）加大专项治理力度。协助有关部门继续抓好工程建设领域突出问题、公务用车问题、“小金库”问题等专项治理工作，着力在健全长效机制上下功夫。加强对专项治理工作情况的监督检查，严肃查处违纪案件。

**七、**大力加强纪检组织自身建设

（十四）加强基层纪检组织建设。认真贯彻落实《关于加强和改进中央国家机关各部门在京直属单位反腐倡廉建设工作的意见》，以基层组织建设年为契机，积极争取各级党组织的重视和支持，建立健全直属单位纪检机构，不断充实和加强基层纪检组织建设。

（十五）加强纪检干部队伍建设。结合创先争优活动，努力建设一支忠诚可靠、服务人民、刚正不阿、秉公执纪的纪检干部队伍。组织开展反腐倡廉理论研究，扎实推进学习型纪检组织建设。继续坚持纪检干部年度培训工作，丰富培训内容，创新培训形式，全面提高纪检干部思想政治素质、业务素质和执纪能力，维护纪检组织的良好形象。
