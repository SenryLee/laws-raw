# 国家食品药品监督管理局公告2012年第3号――药品GMP认证公告(第239号)

国家食品药品监督管理局公告

（2012年第3号）

药品GMP认证公告（第239号）

按照国家食品药品监督管理局《药品生产质量管理规范认证管理办法》的规定，经现场检查和审核批准，北京托毕西药业有限公司等8家药品生产企业符合《药品生产质量管理规范（2010年修订）》要求，广东倍康制药有限公司符合《药品生产质量管理规范（1998年修订）》要求，发给《药品GMP证书》。

特此公告。
