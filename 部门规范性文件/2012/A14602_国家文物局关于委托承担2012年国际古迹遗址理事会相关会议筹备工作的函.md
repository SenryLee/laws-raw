# 国家文物局关于委托承担2012年国际古迹遗址理事会相关会议筹备工作的函

## 国家文物局关于委托承担2012年国际古迹遗址理事会相关会议筹备工作的函（文物保函〔2012〕1531号）

北京市文物局：

经国务院批准，中国古迹遗址保护协会和北京市人民政府将共同承办于2012年10月在北京召开的国际古迹遗址理事会（ICOMOS）执行委员会会议、顾问委员会会议暨国际科学研讨会。为确保会议顺利召开，现委托你局组织有关单位承担会议相关国际联络工作，包括代表网上注册、信息沟通和文件翻译等项内容。

随函拨付补助经费24万元，请你局抓紧组织开展相关工作；加强经费管理，专款专用。

专此。

国家文物局　　

二〇一二年六月十二日
