# 国家质量监督检验检疫总局公告2012年第152号――关于公布特种设备检验检测人员考试机构名单的公告

## 国家质量监督检验检疫总局公告（2012年第152号）

关于公布特种设备检验检测人员考试机构名单的公告

根据《特种设备安全监察条例》及《关于实施特种设备行政许可调整改革工作有关问题的通知》的有关要求，总局对各省级质量技术监督部门报送的特种设备检验检测人员考试机构资料进行了审查，现将确定的特种设备检验检测人员考试机构名单、考试项目等内容（见附件）予以公布（有效期暂定为二年）。

各考试机构应严格考试纪律，坚持公平、公正。严格按照特种设备相关安全技术规范的规定开展考试工作，并接受各级质量技术监督部门的监督。
