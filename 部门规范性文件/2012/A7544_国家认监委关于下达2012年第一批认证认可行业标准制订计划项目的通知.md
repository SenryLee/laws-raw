# 国家认监委关于下达2012年第一批认证认可行业标准制订计划项目的通知

各有关机构：

为适应认证认可行业的发展要求，充分发挥行业标准在认证认可工作中的重要作用，在广泛征集需求基础上，我委研究确定了《2012年第一批认证认可行业标准制订计划项目》（见附件），现将计划下达各有关单位。为确保该批计划项目的有效实施和管理，现就有关事项通知如下：

**一、**项目承担单位应在计划下达后及时研究制定标准起草工作方案，成立标准起草小组，在人员、经费、设备条件与资源等方面提供保障，尽快启动标准起草工作。

**二、**该批标准计划项目由我委统一安排征求意见、审定等工作。请项目承担单位及时将各阶段标准草稿报送我委。

**三、**项目承担单位应加强项目管理，合理安排人员、做好沟通协调、保证项目进度、加强过程控制等工作，遇有重大问题应及时向我委汇报。项目承担单位还应提供标准研制配套经费保障，确保标准研制各环节工作顺利推进。

**四、**鼓励项目承担单位吸纳有条件和能力、愿意共同参与标准制修订活动的科研院所、企事业单位参加项目起草小组的工作。

附件：2012年第一批认证认可行业标准制订计划项目

国家认监委

2012年12月9日
