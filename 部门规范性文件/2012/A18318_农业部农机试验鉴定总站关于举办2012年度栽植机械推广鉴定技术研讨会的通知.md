# 农业部农机试验鉴定总站关于举办2012年度栽植机械推广鉴定技术研讨会的通知

## 农业部农机试验鉴定总站关于举办2012年度栽植机械推广鉴定技术研讨会的通知（农机鉴[2012]58号）

各有关单位：

为了进一步贯彻落实《全国农业机械化工作会议》精神，促进农机化又好又快发展，规范水稻插秧机部级推广鉴定活动，促进企业技术进步和产品质量提高，定于2012年4月下旬在福建省福州市举办“2012年度栽植机械推广鉴定技术研讨会”。现将有关事项通知如下：

**一、**会议内容

（一）介绍农机化发展及推广鉴定工作的新要求；

（二）介绍部级推广鉴定前准备及申请应注意问题；

（三）讲解插秧机部级推广鉴定大纲实施中应注意问题；

（四）介绍部级推广鉴定及获证后应注意问题；

（五）交流插秧、直播、移栽等技术发展状况及市场策略。

**二、**参加人员

各插秧机、直播机、移栽机等生产企业质量负责人及检验部门负责人，通过部级鉴定能力认定的省（区、市）农（牧）机试验鉴定站相关领导或相关处室负责人。

**三、**时间、地点

会议时间：2012年4月26日报到， 4月27日至28日开会。

会议地点：福州市福飞南路199号，福建丽景假日大酒店。 宾馆总机：0591--87736666

乘车路线：

A、火车站：福州北站到酒店：的士10分钟，车价12元左右。 公交：火车站乘坐508抵达湖前站下车即到。

福州南站到酒店：的士40分钟，车价60元左右。公交：火车南站站牌乘坐306路抵达长乐路站转车129抵达湖前站下车；或火车站南站乘坐 305路到福兴中路转车108路抵达湖前站下车即到。

B、长乐机场：乘坐民航大巴25元/人，至市内下车换乘出租车约15元。直接乘坐出租车1个小时车程，约100元左右。

**四、**其他事项

会议由北京燕泰会议服务有限公司承办。会议费1300元/人，食宿统一安排，费用自理。

会议不安排接站，请代表自行前往。
