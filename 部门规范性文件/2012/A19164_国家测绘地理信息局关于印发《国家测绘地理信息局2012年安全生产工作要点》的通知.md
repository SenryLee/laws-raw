# 国家测绘地理信息局关于印发《国家测绘地理信息局2012年安全生产工作要点》的通知

## 国家测绘地理信息局关于印发《国家测绘地理信息局2012年安全生产工作要点》的通知（国测国发〔2012〕45号）

局所属各单位，局机关各司局：

国家测绘地理信息局2012年安全生产工作总体要求是：全面贯彻落实党的十七届五中、六中全会及中央经济工作会议精神，以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实《国务院关于坚持科学发展安全发展促进安全生产形势持续稳定好转的意见》（国发〔2011〕号，以下简称《意见》），坚持“安全第一，预防为主、综合治理”的方针，以科学发展、安全发展为总要求，以落实责任、强化管理、加强预防、应急处置、基础建设、科技支撑为主要措施，以有效防范和坚决遏制重大事故为工作目标，把各项责任落实到位，把各项措施落到实处，全力以赴做好安全生产各项工作，推动测绘地理信息事业科学发展安全发展。

**一、**贯彻精神，推动科学发展安全发展

（一）树立科学发展安全发展理念。大力宣传贯彻国务院《意见》、《安全生产“十二五”规划》（国办发〔2011〕47号，以下简称《规划》）等精神，牢固树立科学发展、安全发展理念，真正将安全作为各单位发展的前提和基础，实现安全与发展的有机统一。

（二）制定并落实安全生产计划。按照《意见》、《规划》以及本工作要点的总体要求，围绕科学发展、安全发展这一主题，各单位认真制定年度安全生产计划（或工作要点），将安全生产工作落实到管理和生产的各个环节，推进安全生产总体目标全面完成。

**二、**抓住重点，强化重大项目重要环节安全管理

重点加强对今年收官的海岛（礁）测绘一期工程和即将启动的国家现代测绘基准体系基础设施建设工程、地理国情监测项目等重大项目外业安全生产工作。

（三）切实加强外业人员管理。认真做好外业队伍中外聘人员的考核、选用；出测前务必进行作业规程、安全知识教育培训，结合测区特点开展安全工作交流；落实出测前的身体检查，确保外业人员健康出测；注重人文关怀，及时解决外业人员生产生活中的困难。

（四）进一步完善外业装备。落实用于安全生产的经费；配备相应的安全装备，包括通讯设备、定位设备、救援设施、急救药品以及服装等；做好仪器设备、车辆设施的检查维护；配备并使用相应的安全监控系统。

（五）严格外业作业安全管理。落实安全生产现场责任制，作业组长、安全责任人切实承担起管理、督促、监督安全生产工作的职责；认真抓好生产作业规范和安全生产规范的执行，坚决杜绝“违章指挥，违章操作，违反劳动纪律”的行为；严格执行报告制度，包括定期报告和外业生产每日零事故安全报告、事故报告制度等。海岛（礁）测绘外业生产工作，应严格执行《927工程安全生产管理规定》要求，将安全生产措施落到实处。

（六）认真做好安全生产监控。927工程安全监控系统已投入使用，有关部门要做好系统的维护与跟踪服务，保证使用效果，尚未纳入监控系统的单位要创造条件，尽快配置相关设备纳入监控系统。其他外业工作也逐步普及安全监控系统的使用，提升实时掌握外业安全状况的能力。

（七）努力提升应急保障能力。针对海岛（礁）工程等项目建设特点和外业环境实际情况，提前制定应急预案，并通过预案演练加以完善；生产中，做好与当地政府、测绘部门、驻军、武警、医院等单位的联系，以便发生突发事件是，得到快速有效地救助。

**三、**落实责任，不断强化安全生产监督管理

（八）严格落实主体责任。各单位认真履行安全生产主体责任，建立自我约束、持续改进的安全生产工作机制；落实单位一把手为第一责任人、分管领导具体负责的责任制，将安全生产工作层层细化、分解，落实到具体岗位、具体责任人。

（九）进一步完善制度体系。完善单位安全生产规章制度，形成贯穿本单位各层面的安全管理体系；建立健全安全生产激励约束、督促检查、问效问责、领导干部现场带班等制度。逐步形成规范有力的安全生产制度保障体系。

（十）切实加强监督管理。采取日常检查与监督抽查互补、警示约谈与黄牌警告结合、奖励先进与追究责任并举等措施，不断加大安全生产管理力度；重点加强对海岛（礁）测绘工程等重大测绘项目外业安全生产工作的督导；将安全生产工作情况纳入相关考核目标，对单位主要领导、主管领导和各级责任人履行安全生产职责情况进行考核；坚决执行安全生产“一票否决制”和安全事故责任追究制。

**四、**预防为主，切实搞好隐患排查整改

（十一）认真做好安全检查。按照“安全第一，预防为主、综合治理”的方针，各单位根据自身情况，在日常安全检查的基础上，安排3次以上全面检查工作，对发现的隐患、问题，要及时通报，限期整改，坚决消除不安全因素。有条件的，可开展风险评估、物资储备等方面的工作。

（十二）适时组织开展重点抽查。国家测绘地理信息局安委会根据国家要求和各单位检查情况组织抽查，对有关项目进行重点抽查，抽查结果将进行通报。对好的经验、做法予以表扬推广，对违反安全生产管理规定的行为坚决予以批评纠正，对发生安全生产责任事故的，严格按照规定处理。

**五、**教育培训，强化安全意识提升能力

（十三）结合“安全生产年”和“安全生产月”主题，举办丰富多彩、形式多样的安全生产宣传教育活动；开展相关法律法规、安全知识、安全技能学习培训；定期开展应急演练、消防演习等；组织安全经验工作交流，不断强化职工安全意识，提升自我保护和应急处理的能力。

**六、**科技支撑，提升安全保障水平

（十四）完善安全监控系统。继续利用定位、监控、通讯等技术手段，完善安全监控系统，实现连续、实时、全天候测绘地理信息安全服务。测绘地理信息项目，应在项目设计阶段即考虑安全问题，做到技术设计与安全设计同时进行。外业工作，应逐步采用安全监控管理，有效提升安全生产管理的时效性。

（十五）提升安全保障科技水平。增加安全生产投入，结合测绘地理信息工作特点，开展自主安全生产保障系统研发，进一步提升技术水平、工作效率，提高测绘地理信息安全保障能力。

国家测绘地理信息局2011年安全生产总结

2011年，国家测绘地理信息局安全生产工作在局党组的统一领导下，在局安全生产委员会的直接指挥下，坚持以人为本，安全发展理念，强化安全生产意识，落实岗位责任，健全安全生产管理体系，加大宣传培训力度，完善安全生产保障设施。全年安全生产形势总体平稳，为推进测绘地理信息事业健康稳定发展提供了有力支撑。现将情况总结如下：

**一、**提高认识，加强领导，落实安全生产责任。

国家测绘地理信息局党组高度重视安全生产工作，年初召开安全生产委员会工作会议，传达了国务院安全生产委员会全体会议、全国安全生产电视电话会议以及全国安全生产工作会议三个会议精神，要求各单位必须充分认识安全生产的重要性，坚持“安全第一，预防为主”的方针，从保证测绘职工生命财产安全，推动测绘地理信息事业科学稳定发展的高度抓好测绘安全生产工作。

根据各单位领导分工，年初及时调整了局安委会成员，印发了局2011年测绘安全生产工作要点，制定了全年测绘安全生产工作的计划，并提出2011年安全生产工作目标。要求各单位领导特别是主要领导认真学习并及时贯彻国务院关于安全生产工作的部署，落实局安委会安全生产工作的要求，切实履行安全生产第一责任人的职责，亲自抓好安全生产各项措施的落实。

各单位采取安全责任层层分解措施，与各部门负责人签订了安全生产目标责任书，将安全生产责任落实到人，明确了安全生产工作的目标和具体要求，切实有效的提高了各级管理人员的责任意识。

**二、**完善机制，强化监督，建立科学管理体系

各单位在深入学习《中华人民共和国安全生产法》的基础上，要求广大职工在生产作业过程中，认真执行《测绘安全生产管理规定》，严格遵守局安全生产工作规则及《测绘作业人员安全规范》。并根据自身情况，进一步完善各项配套规章制度，使测绘生产工作进一步规范化，标准化。

按照局安全生产工作要求，各单位加强了日常检查工作，基本建立了定期检查与抽查、各部门自查与职能部门集中检查相结合以及对隐患“跟踪复查”等制度，并认真加以落实。对检查出的问题、隐患及时通报，限期整改，坚决消除。各单位建立了安全生产检查月报、外业生产安全状况日报制度，建成了一套“横向到边，纵向到底”的全方位无缝安全管理体系，强化了安全生产监督力度，保障了测绘生产的安全。

**三、**突出重点，注重宣传，加强生产安全保障能力建设。

1、以保障重大项目及其外业工作的生产安全为工作重点。2011年，1：5万数据库更新、西部测图工作进入尾声，海岛（礁）测绘工作进入关键时期，国家基础测绘工作比较繁重。局安委会在年度工作要点中对重点项目安全生产的管理、保障应急等都提出了明确的要求。各单位围绕着重大项目的安全生产工作建立了相应的管理制度，严格规范测绘生产程序，密切监控外业生产状况，保证了重大项目的生产安全。

2、注重宣传，通过多种手段加强安全生产教育。广泛利用安全知识手册、光盘等，强化测绘安全生产知识宣传，全方位提升广大职工的安全生产意识和防范事故的能力。外业工作前，重点加强出测准备、培训交流、应急演练、后勤保障等方面的工作。各单位积极开展职工安全生产培训，黑龙江测绘地理信息局在春训期间专门邀请有关专家进行安全生产培训，参训人员近500人；重庆测绘院全年共组织安全学习培训69次，参与职工达到100%；其他单位也都进行了相应的培训、演练等工作，为全年生产工作的安全顺利开展打下了坚实的基础。

3、提升生产安全保障能力。各单位针对测绘外业工作任务繁重、环境较为复杂、突发性情况较易出现的特点，强化了交通、通讯、医疗等必要物资装备的保障力度，建立了安全生产应急预案和措施，有效的提升了生产安全保障能力。承担927工程任务的各单位对外业工作人员进行身体检查，对进入测区作业的车辆仔细检修、维护；配备了安全生产监控终端，并纳入到国家测绘地理信息局927工程安全生产监控系统，有效的保证了工程外业生产安全。

**四、**督促检查，整治隐患，保障测绘生产安全。

按照国家测绘地理信息局安委会要求，各单位分别组织了暑期、十一、春节前测绘安全生产检查工作。在各个部门，各测绘院、中队、班组自查的基础上，由各单位安全管理部门统一组织抽查，并将安全检查整体情况报告国家测绘地理信息局安委会。各单位重点围绕资料档案库房、计算机房、供电室等重点区域，开展周密的检查；春节前夕积极宣传燃放烟花爆竹的有关规定，并对燃放场地做了有效的规划，有效排除了安全隐患，强化了安全生产的防范力度，对避免事故的发生、保障安全起到了积极作用。

**五、**创新方法，提高效率，推进安全生产管理。

在国家测绘地理信息局安委会指导下，各单位开拓思路，在工作方法上大胆创新，通过网站、QQ群、手机短信等形式通报生产进展和安全信息，传达相关要求，强化职工安全生产意识，督促安全管理，掌握工作人员的生产状况，加大了安全生产的监控力度，提高了管理效率和力度。国家测绘产品质量检验测试中心在执行外业检验任务时，通过QQ群每日通告测区环境情况，及时提出安全注意事项和要求，报告安全进展；有关单位采用漫画形式编纂了《测绘生产安全手册》，利用通俗易懂的方式开展安全生产教育，便于职工理解和掌握。这些新方法、新形式的运用，对推进安全生产工作、提升管理水平产生了积极的作用。

主要问题

1、安全生产管理、各项制度落实有待加强。2011年黑龙江测绘地理信息局和海南测绘地理信息局均发生了生产事故，暴露出安全生产规章制度在执行过程中存在漏洞，安全监督管理力度亟需加强。为此，局安委会专门发文，要求各测绘生产部门，通过总结事故教训，严格执行安全生产的规章制度，强化安全生产监督管理力度，避免类似事故的再度发生。

2、职工安全生产意识和技能有待提高。测绘职工在外出作业时，尤其是在条件较为复杂地区，缺乏预见、防范事故的能力，安全意识不强。各单位要进一步加强安全生产的宣传教育力度，强化职工安全生产意识；根据外业生产环境针对性地开展安全生产技能培训，提升职工防范、处理突发性事故的能力，保障测绘生产的安全。

3、日常基础工作还需更加细致、周密。在各单位的安全生产检查、抽查工作中，均发现存在隐患问题，如在楼层通道处摆放杂物、部分灭火器已过有效期、安全门（安全通道）不畅通等。各单位要引起高度重视，从细处、小处开展工作，坚决消除隐患，营造安全工作环境，为保证生产安全打下牢固基础。

2011年安全生产工作在国家测绘地理信息局各级领导和广大职工的关心支持下，在各单位的共同努力下，总体进展顺利，没有发生安全生产责任事故，为测绘地理信息事业稳定、健康发展提供了有力保障。
