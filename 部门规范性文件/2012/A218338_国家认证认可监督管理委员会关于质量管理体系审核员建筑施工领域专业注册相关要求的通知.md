# 国家认证认可监督管理委员会关于质量管理体系审核员建筑施工领域专业注册相关要求的通知

## 国家认证认可监督管理委员会关于质量管理体系审核员建筑施工领域专业注册相关要求的通知（国认可【2012】49号）

各认证机构：

为提高我国工程建设筑施工企业质量管理水平，2010年6月10日国家认证认可监督管理委员会与住房和城乡建设部决定在建筑施工领域质量管理体系认证中应用《工程建设施工企业质量管理规范》（GB/T 50430-2007），统一组织了质量管理体系审核员建工领域的考试，针对建工领域审核员的知识状况和专业差异，决定建立建筑施工领域审核员专业注册制度。日前，中国认证认可协会发布了《质量管理体系审核员建筑施工领域专业注册要求》。现就相关事项通知如下：

**一、**建筑施工领域专业注册的级别与其质量管理体系审核员注册证书的级别相一致。对工程建设施工企业实施认证活动时，需同时持质量管理体系审核员注册证书和建筑施工领域专业注册证书。

**二、**已取得2010年10月、2011年3月和2012年6月建筑施工质量管理体系审核员考试合格证的认证人员，应在通知发布之日起三年内，依照中国认证认可协会发布的《质量管理体系审核员建筑施工领域专业注册要求》，完成建筑施工领域专业注册证书的换证工作。

**三、**为做好换证衔接，从事工程建设施工企业认证审核的认证人员，可在2015年6月30日前持建筑施工质量管理体系审核员考试合格证和质量管理体系审核员注册证书实施认证审核活动。2015年7月1日起，建筑施工质量管理体系审核员考试合格证废止。

请各认证机构认真做好所属认证人员的证书转换工作。

二〇一二年六月十九日
