# 新闻出版总署人事司关于做好新闻出版软件工程硕士在职研究生学习推荐报考工作的通知

有关省、自治区、直辖市新闻出版局，有关出版集团、发行集团、报业集团、期刊集团，总署机关各部门、署直各单位、署管各社会团体：

为贯彻党的十七届六中全会精神，加快培养造就德才兼备、锐意创新、结构合理、规模宏大的新闻出版人才队伍，进一步提高新闻出版从业人员整体素质，发挥总署人才培养基地-北京印刷学院教育资源优势，北京印刷学院将与北京交通大学联合面向新闻出版行业培养数字出版、数字印刷、传媒经济与管理方向的软件工程硕士研究生，现将《2012年北京交通大学软件工程硕士（单证MSE）招生简章》和《北京交通大学与北京印刷学院联合培养软件工程硕士（单证MSE）招生说明（非脱产）》转发给你们，请积极做好相关人员的推荐报考工作。

附件：

1.2012年北京交通大学软件工程硕士（单证MSE）招生简章（略）

2.北京交通大学与北京印刷学院联合培养软件工程硕士（单证MSE）招生说明（非脱产）（略）

新闻出版总署人事司
