# 国家行政学院科研部关于做好2012年国家社科基金中华学术外译项目申报工作的通知

各教研人员及有关人员：

经全国哲学社会科学规划领导小组批准，《2012年国家社科基金中华学术外译项目申报公告》业已发布，现转发给你们（见附件）。请符合申报条件的人员踊跃申请，详细情况和申报资料请登录全国哲学社会科学规划办公室网站（http：//www.npopss-cn.gov.cn/）查询和下载（见附件）。现将2012年中华学术外译项目申报工作有关事项通知如下：

**一、**申报材料要求

申请书一式7份，电子光盘一式3份，其他要求详见《公告》。

**二、**申报受理时间和地点

此项目全年受理，相关材料送科研部C413房间，我部负责做好组织服务工作。
