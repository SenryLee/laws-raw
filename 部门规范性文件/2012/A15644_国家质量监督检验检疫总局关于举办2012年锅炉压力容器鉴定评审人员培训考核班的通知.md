# 国家质量监督检验检疫总局关于举办2012年锅炉压力容器鉴定评审人员培训考核班的通知

各有关单位：

为满足特种设备行政许可工作需要，应相关鉴定评审机构要求，经国家质检总局特种设备安全监察局同意，中国特种设备安全与节能促进会定于6月26日至7月1日在北京举办锅炉压力容器鉴定评审人员培训考核班。

相关文件请登陆中国特种设备安全与节能促进会网站（www.cpase.org.cn）查询。

二○一二年五月二十一日
