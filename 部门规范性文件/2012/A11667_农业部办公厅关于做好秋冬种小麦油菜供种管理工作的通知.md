# 农业部办公厅关于做好秋冬种小麦油菜供种管理工作的通知

## 农业部办公厅关于做好秋冬种小麦油菜供种管理工作的通知（农办种〔2012〕25号）

有关省、自治区、直辖市农业（农牧）厅（委、局）：

今年上半年，我国部分小麦、油菜繁制种区受到阴雨等不利天气影响，种子产量和质量受到不同程度影响。为切实掌握秋冬种农业生产用种供种状况，确保秋冬种农业生产用种安全，根据《2012年种子执法年活动方案》，现就加强秋冬种供种管理工作提出如下要求：

**一、**开展秋季种子市场专项检查行动

各级农业行政主管部门要明确责任，分片包干，督促引导辖区内种子生产企业切实采取有效措施，加强质量控制，定期按批次开展种子质量检测，保证市场销售种子质量合格。河北、山西、江苏、浙江、安徽、江西、山东、河南、湖北、湖南、广西、重庆、四川、贵州、陕西、甘肃等16个小麦、油菜主产省（区、市）要开展秋季种子市场专项检查行动。主要检查项目，一是种子净度、水分和发芽率等质量指标检测；二是种子标签、经营许可及经营档案、品种审定及授权情况等。检查重点是种子集中交易市场及基层（县、乡）种子门市部，每个省（区、市）至少抽查30个门市部，每个门市部抽查2个种子样品。

**二、**切实加强小麦种子健康监管

赤霉菌可抑制小麦种子萌动，导致种子出苗弱、出苗率低、苗期枯死等现象，造成种子质量隐患。相关省农业行政主管部门要高度重视，采取切实措施，减轻赤霉病对种子供应的不利影响。一是加大工作力度，督导本地区小麦种子生产经营企业，加强精选加工，去除病粒，加大种子带菌量自检力度，确保种子质量；二是以省为单位进行种子抽样，检测带菌种子比例，根据检验情况研判种子质量，提出加大播量、播前药剂拌种等有针对性的应对措施；三是组织种子、植保、推广等部门加大抗性、耐性品种推介力度，要求种子管理部门加大抗性品种筛选、审定力度。

**三、**加强种子供需信息调度

各级农业行政主管部门要高度重视秋冬种种子信息调度，分作物、分品种开展种子数量和价格信息的调度，准确掌握辖区内小麦、油菜种子供求情况，及时发布行情信息，根据需求情况积极协调种子企业供种到位，科学引导种子跨区调运和品种间调剂。各级农业行政主管部门要联合物价、工商等部门依法加强市场价格监管工作，严厉打击哄抬价格等行为，稳定种子市场价格。

**四、**有关要求

有关省（区、市）农业行政主管部门要高度重视秋冬种种子供应工作，明确分工，责任到人。各级种子管理机构具体抓好落实，确保监管工作取得实效。请有关省（区、市）种子管理部门在9月15日之前将辖区内种子供求、价格监测情况报全国农业技术推广服务中心种子信息与技术处，在9月20日之前将秋冬种种子质量监督抽查和小麦种子健康监管情况报送全国农业技术推广服务中心种子检验处，在9月30日前将本省（区、市）市场检查总结报我部种子管理局市场监管处。对在工作过程中遇到的问题，请主动反映，并及时妥善处置。
