# 财政部、工业和信息化部关于下达2012年第一批科技成果转化项目补助资金的通知

## 财政部、工业和信息化部关于下达2012年第一批科技成果转化项目补助资金的通知（财建[2012]112号）

有关省（自治区、直辖市、计划单列市）财政厅（局）、工业和信息化主管部门：

2011年财政部、工业和信息化部对你省（自治区、直辖市、计划单列市）部分科技成果转化项目实行滚动支持。按照项目承担单位提出的年度任务目标，我们组织有关单位对滚动支持项目2011年目标完成情况进行了考核。根据考核情况，经研究，有关事项通知如下：

**一、**对项目实施进度较好、预期目标已基本完成的，2012年补助资金继续予以下达，项目名称、项目承担单位及补助金额详见附件。政府收支分类科目列“2060403产业技术研究与开发”。

**二、**对项目实施进度偏慢、实际完成情况与预期目标有较大差异的，2012年补助资金暂不下达，待2013年组织考核后根据目标完成情况确定，如项目实施仍无进展、预期目标仍未完成，2012年及以后年度补助资金不再下达，并将扣回以前年度补助资金；如项目实施情况较好，预期目标已完成，我们将于2013年下达后续补助资金。

**三、**请你们按照《财政部国家计委国家经贸委科技部关于印发〈产业技术研究与开发资金管理办法〉的通知》（财建[2002]30号）等文件要求，加强资金管理，专款专用，确保2012年补助资金及时、足额到位。同时，你们要加强对未完成目标项目的监督检查，督促项目承担单位加快实施进度，对项目实施中发现的问题，请及时将有关情况报告我们。
