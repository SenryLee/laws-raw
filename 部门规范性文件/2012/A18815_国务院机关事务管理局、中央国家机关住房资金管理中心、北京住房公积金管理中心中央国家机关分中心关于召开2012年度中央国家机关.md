# 国务院机关事务管理局、中央国家机关住房资金管理中心、北京住房公积金管理中心中央国家机关分中心关于召开2012年度中央国家机关房改资金管理工作会议的通知

## 国务院机关事务管理局、中央国家机关住房资金管理中心、北京住房公积金管理中心中央国家机关分中心关于召开2012年度中央国家机关房改资金管理工作会议的通知（国机房资〔2012〕74号）

中央国家机关各部门、各单位房改资金管理机构：

为做好中央国家机关房改资金（售房款、住宅专项维修资金）管理工作，经研究，决定召开2012年度中央国家机关房改资金管理工作会议。现就有关事项通知如下：

**一、**会议内容

（一）部署2012年中央国家机关房改资金管理相关工作；

（二）下达2012年度使用售房款发放住房补贴计划额度；

（三）通报房改资金管理信息系统及单位版运行情况；

（四）成立中央国家机关房改资金管理工作协作组；

（五）公布《房改资金优秀主管部门和优秀业务经办人员评选方案》；

（六）分组座谈讨论。

**二、**会议时间和地点

时间：2012年4月12日至13日。12日（星期四）14：00报到，13日（星期五）15：00返回。

地点：密云中航云湖度假村（总机：61021888，详细地址见附件）。

**三、**参会人员

各单位房改资金工作负责人1名（如售房款、住宅专项维修资金分属不同部门管理，参会人员可各1名）。

**四、**有关说明

（一）此次会议不收取费用。

（二）为做好参会人员食宿安排，各单位须于4月9日下班前，将会议报名表（见附件1）以传真方式发至资金中心。

（三）统一乘车人员请于4月12日下午13：00前在资金中心办公楼（朝外大街甲10号中认大厦）南门集合乘车。自驾车前往的人员请注意报到时间，并注意交通安全。
