# 国家体育总局科教司关于召开备战2014年索契冬奥会招标课题评审会的通知

冬运中心、有关单位、有关课题负责人：

根据备战2014年索契冬奥会国家队科研综合攻关研究课题立项工作的整体安排，我们决定召开评审会，对招标课题进行立项评审，现将有关事项通知如下：

**一、**时间及地点：

（一）时间：2012年10月22日（星期一）8：30-17：00

（二）地点：冬季运动管理中心运动员公寓8层会议室。

**二、**具体要求：

（一）请冬运中心相关国家队（项目部）领导和主总教练参加相关课题评审会议。

（二）各课题由承担人作申请报告，时间15分钟，其中技术报告10分钟，财务报告5分钟，并准备投影。技术报告重点从研究目的、研究内容、技术路线、创新点以及预期结果、考核指标等方面进行报告。财务报告重点从列支科目，支出依据等方面报告。课题承担人不能到会者，取消课题评审资格。

（三）参会人员自带课题申报书一式五份。

（四）各课题组参会人员交通、食宿费自理。
