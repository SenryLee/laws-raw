# 国家文物局关于委托开展预备名单专业审核工作的函

## 国家文物局关于委托开展预备名单专业审核工作的函（办保函〔2012〕123号）

中国古迹遗址保护协会：

为顺利完成《中国世界文化遗产预备名单》（以下简称预备名单）更新工作，我局现委托你单位承担预备名单更新的专业审核工作，并对有关工作提出以下要求：

**一、**请按照我局相关工作的总体部署，针对预备名单更新的专业审核工作，包括编制评估审核材料、筹备召开专家会议、组织书面评估和现场评估等工作，制订详细的工作实施方案。

**二、**请精心组织，周密安排，组织专门人员负责此项工作，并明确工作任务，合理安排工作时间，确保各项任务按时完成。

**三、**随函拨付工作经费15万元。请加强管理，专款专用。

专此。

国家文物局　　　

二〇一二年二月二十四日
