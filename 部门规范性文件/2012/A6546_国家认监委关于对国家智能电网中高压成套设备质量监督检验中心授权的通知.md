# 国家认监委关于对国家智能电网中高压成套设备质量监督检验中心授权的通知

苏州电器科学研究院股份有限公司：

根据《中华人民共和国标准化法》、《中华人民共和国产品质量法》、《中华人民共和国认证认可条例》及相关规定，国家认监委批准筹建的“国家智能电网中高压成套设备质量监督检验中心”（国认实函〔2012〕178号）已按要求完成筹建工作并通过了评审和验收。现对国家智能电网中高压成套设备质量监督检验中心授权。

**一、**国家智能电网中高压成套设备质量监督检验中心主要检验产品为智能电网中高压成套设备（详细内容见授权证书附表），授权证书编号为：〔2012〕国认监认字（519）号。

**二、**国家智能电网中高压成套设备质量监督检验中心应当在授权的检验产品范围内，开展产品质量监督检验业务。国家智能电网中高压成套设备质量监督检验中心的法律责任由你单位承担。

**三、**国家智能电网中高压成套设备质量监督检验中心开展的产品质量监督检验业务，受国家质检总局和国家认监委的监督和指导。

**四、**国家智能电网中高压成套设备质量监督检验中心应不断提高管理水平和技术能力，保证出具的检验数据公正、科学、准确。

**五、**请自收到本通知书十个工作日后到国家认监委实验室与检测监管部领取授权证书及印章。

国家认监委　

2012年12月27日
