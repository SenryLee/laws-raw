# 国家质量监督检验检疫总局公告2012年第226号――关于2012年第2、3批产品质量国家监督抽查不合格产品生产企业整改情况的公告

## 国家质量监督检验检疫总局公告（2012年第226号）

根据《中华人民共和国产品质量法》和《产品质量监督抽查管理办法》的规定，各相关省、自治区、直辖市质量技术监督局依法对2012年第2、3批产品质量国家监督抽查不合格产品及其生产企业进行了处理。目前，第2批经整改复查合格的企业190家、不合格的企业10家、产品停产的企业33家，因不满足复查检验条件等原因暂未完成复查检验工作的企业22家；第3批经整改复查合格的企业155家、不合格的企业7家、产品停产的企业24家，因不满足复查检验条件等原因暂未完成复查检验工作的企业25家。对复查检验不合格企业和暂未完成复查检验工作的企业，质检总局已责成相关省级质量技术监督部门加大处理力度和加强复查检验工作。
