# 国土资源部深入推进创先争优工作办公室关于召开国土资源部创先争优“两优一先”表彰视频大会的通知

部机关各司局，部直属单位，各派驻地方的国家土地督察局，中国地质调查局及其直属单位：

为表彰我部在创先争优活动中表现突出的先进基层党组织、优秀共产党员和优秀党务工作者（以下简称“两优一先”），进一步激励基层党组织和广大党员立足岗位争先进、创优秀，经部党组研究决定，于7月9日召开国土资源部创先争优“两优一先”表彰大会，现将有关事项通知如下：

**一、**时间

2012年7月9日（周一）下午2：30。

**二、**地点

部机关B503会议室。

**三、**参会人员

1. 在家部党组成员；

2. 获部创先争优“两优一先”表彰领奖单位和个人代表（另行通知）；

3. 部机关各司局全体党员干部；

4. 部各直属单位、北京督察局、中国地质调查局及其直属单位党政主要负责同志。

部各直属单位、中国地质调查局及各直属单位、九个土地督察局分别在所在地以视频会议方式组织党员干部收看大会实况。

**四、**会议内容

1. 部领导作重要讲话。

2. 部领导宣读表彰决定。

3. 部党组成员分别向获部创先争优“两优一先”称号的单位授牌，向个人颁发荣誉证书。

4. 获部创先争优“两优一先”表彰的7个单位的代表作典型发言。

请各司局、各单位于7月5日前将本单位参会人员名单传真至部深入推进创先争优工作办公室。
