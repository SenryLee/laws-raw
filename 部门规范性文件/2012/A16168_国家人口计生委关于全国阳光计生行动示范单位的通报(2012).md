# 国家人口计生委关于全国阳光计生行动示范单位的通报(2012)

## 国家人口计生委关于全国阳光计生行动示范单位的通报

（人口监察〔2012〕31号）

各省、自治区、直辖市人口计生委：

2011年4月以来，在第一批57个全国阳光计生行动示范单位的带动下，各地阳光计生行动深入推进，涌现出一批行风建设先进单位，率先实现了阳光管理、阳光服务、阳光维权，保障了人民群众对人口计生工作的知情权、参与权、表达权、监督权，推动了人口计生工作创新发展，赢得了群众的好评，受到了地方党委政府的表彰。

为充分发挥先进单位的示范作用，带动阳光计生行动全覆盖、规范化，全面落实人口计生权力公开、民主评议、监督维权，切实维护群众计划生育合法权益，努力建设人民满意的窗口单位和文明行业，经逐级推荐和审核，国家人口计生委决定，北京市海淀区人口计生委等205个单位为第二批全国阳光计生行动示范单位。

希望各省（区、市）人口计生委认真总结推广示范单位的做法，以点带面，全面推进本地区阳光计生行动，促进广大人口计生工作者更好地坚持以人为本，保证人口计生事业科学发展。希望各示范单位再接再厉、努力进取，为深化阳光计生行动，提高计划生育基本国策的执行力和群众满意度，做出新的更大贡献！

附件：全国阳光计生行动示范单位名单

二○一二年五月十日
