# 商务部流通发展司关于通报2012年部分中小商贸流通企业公共服务平台建设工作进度的函

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门：

根据《关于加强中小商贸流通企业公共服务平台建设工作联系的通知》，我司对部分试点地区的平台建设进度进行了跟踪摸底。从情况看，平台建设工作已取得阶段性成果，其中长沙市、青岛市和荆州市已顺利进入运营阶段，但各地进度很不平衡，一些地区进展相对缓慢（详见附件）。

希望各地尤其是进度滞后的试点地区，要积极发挥能动作用，争取多方支持，采取有效措施，加快建设进度，确保平台如期运行。
