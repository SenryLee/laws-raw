# 新闻出版总署办公厅关于调查新华书店有关数据的通知

各省、自治区、直辖市新闻出版局：

为贯彻落实党的十七届六中全会精神，进一步推进新闻出版产业结构调整，发展壮大出版物发行行业，拟就新华书店系统基本情况进行一次摸底调查。现将有关事项通知如下：

**一、**调查内容

各省（区、市）新华书店经营情况和基本情况，具体内容见附件1和附件2。其中，附件1中填报本省（区、市）新华书店系统2006年-2011年有关经营情况；附件2中填报本省（区、市）新华书店系统截至2011年底有关基本情况。

**二、**填报单位

省（区、市）新华书店系统已实现整合为单一集团或公司的地区，填报省级集团或公司相关数据；省（区、市）存在多家无直接资产隶属关系新华书店法人单位的，分别填报各独立新华书店法人单位有关数据。

**三、**报送时间

请各省（区、市）新闻出版局组织有关单位认真填报相关数据，并于2012年3月23日前将汇总数据纸质版（需加盖填报单位公章）和电子版（表格电子版可自新闻出版总署网站“通知公告”栏目中下载，新闻出版总署网站：www.gapp.gov.cn）报新闻出版总署。
