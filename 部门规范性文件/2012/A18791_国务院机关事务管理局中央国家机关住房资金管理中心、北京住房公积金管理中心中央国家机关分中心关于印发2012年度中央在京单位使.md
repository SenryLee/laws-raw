# 国务院机关事务管理局中央国家机关住房资金管理中心、北京住房公积金管理中心中央国家机关分中心关于印发2012年度中央在京单位使用售房款发放住房补贴计划的通知

## 国务院机关事务管理局中央国家机关住房资金管理中心、北京住房公积金管理中心中央国家机关分中心关于印发2012年度中央在京单位使用售房款发放住房补贴计划的通知（国机房资〔2012〕73号）

根据中央国家机关使用售房款发放住房补贴的相关政策，按照《关于做好2012年度使用售房款发放住房补贴计划申报工作的通知》（国管房改〔2011〕509号）要求，结合住房补贴历年发放情况及你单位申报的2012年度售房款使用计划，经研究，核定你单位2012年度使用售房款发放住房补贴计划额度为　万元。现就具体事项通知如下：

**一、**使用条件

（一）申请使用售房款发放职工住房补贴的单位，须首先按规定从售房款中足额提取住宅专项维修资金，未足额提取住宅专项维修资金的单位不能申请使用售房款发放住房补贴。

（二）申请使用售房款发放职工住房补贴的单位，须建立并完善单位职工住房档案，未按要求建立职工住房档案的单位不能申请使用售房款发放住房补贴。

（三）申请使用售房款发放职工住房补贴的单位，只限于中央在京各单位。

**二、**申请材料

（一）使用售房款发放职工住房补贴的申请；

（二）本通知第1页复印件；

（三）加盖单位公章的《2012年度中央在京单位住房补贴支出基础数据表》纸质及电子版，经过公示，拟发放住房补贴人员及金额与本年度售房款计划申报情况一致的，可不必重复报送；

（四）行政及财政补贴事业单位，需提供财政部或上级主管部门批复的2012年度中央行政事业单位住房改革支出预算表复印件；

（五）经费自理事业单位及中央在京企业需提供上级主管部门批复同意或职工代表大会讨论通过的住房补贴实施方案。

**三、**相关说明及注意事项

（一）对于行政及财政补贴事业单位，当财政部或上级主管部门下达的使用售房款发放住房补贴预算额度与国管局核定的使用额度不符时，以各单位上年末在资金中心开立的售房款专户内实际余额的20%为上限，核定单位可使用额度。

（二）部分单位存在2011年12月31日后支取2011年度住房补贴资金的情况，导致上年末售房款实际余额虚高，资金中心将在该单位支取2012年住房补贴时，根据实际情况调整2012年可使用额度。

（三）各单位报送2012年使用售房款发放住房补贴相关材料的截止日期为2012年12月31日。

（四）各单位可登陆资金中心网站（www.zzz.gov.cn）下载售房款使用申报的相关表格。
