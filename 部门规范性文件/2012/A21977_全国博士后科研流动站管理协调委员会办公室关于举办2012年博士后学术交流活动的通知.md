# 全国博士后科研流动站管理协调委员会办公室关于举办2012年博士后学术交流活动的通知

## 全国博士后科研流动站管理协调委员会办公室关于举办2012年博士后学术交流活动的通知（博管办〔2012〕3号）

有关省、市、自治区人力资源社会保障厅（局），中国科学院，中国社会科学院，解放军总政治部干部部，北京大学，清华大学，北京交通大学：

为进一步提高博士后研究人员培养质量，更好地为博士后研究人员搭建交流平台，扩大全国博士后学术交流规模，2012年将继续举办全国博士后学术交流活动。现就有关事项通知如下：

**一、**根据博士后工作发展情况和财政预算安排，2012年计划举办27个全国博士后学术交流活动，由全国博士后管委会办公室、中国博士后科学基金会和有关省、市、自治区主办，有关设站单位承办（详见附件）。

**二、**根据全国博士后管委会办公室下发的《关于做好2012年全国博士后学术交流工作的通知》（博管办[2011]101号），各有关省市、部门和设站单位根据经济社会发展形势和科技发展需要，选择了41个学术交流活动主题。经研究决定，选定生物医药、工程技术与装备开发等27个主题（详见附件）。

**三、**对列入计划的每个全国博士后学术交流活动拨款10万元（其中25个论坛经费已在2011年预拨，其余两个将在2012年拨付），不足部分请你们和有关设站单位落实解决。

**四、**请你们接到通知后，缜密组织，注重实效，充分发挥设站单位的力量和优势，共同做好全国博士后学术交流工作，为广大博士后研究人员创造良好的学术交流环境。
