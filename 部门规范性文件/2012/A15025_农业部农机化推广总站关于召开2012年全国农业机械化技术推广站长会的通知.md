# 农业部农机化推广总站关于召开2012年全国农业机械化技术推广站长会的通知

各省、自治区、直辖市及计划单列市农机推广站，新疆生产建设兵团和黑龙江省农垦总局农机推广站：

为贯彻落实2012年中央1号文件精神，部署全国农机化技术推广系统“全国农业科技促进年”活动，定于2012年6月中旬在青岛市召开2012年全国农业机械化技术推广站长会。现将有关事项通知如下：

**一、**会议内容

（一）学习贯彻2012年中央一号文件精神、贯彻落实“全国农业科技促进年”活动部署；

（二）总结交流2012年上半年农机化技术推广工作主要成效和经验，部署下阶段重点工作；

（三）参观现代农业示范基地。

**二、**会议时间、地点

时间：6月12日，会期一天，6月11日报到。

地点：青岛黄海饭店（青岛市延安一路75号，0532-82869278）

**三、**参加人员

（一）农业部及有关单位领导；

（二）各省、自治区、直辖市及计划单列市农机推广站，新疆生产建设兵团和黑龙江省农垦总局农机推广站站长和科室负责同志各1人。不得超员。

**四、**其他事项

为便于安排住宿和接站，请与会代表务必于6月7日17：00前将会议回执发送电子邮件至农业部农机推广总站和青岛市农机推广站邮箱。
