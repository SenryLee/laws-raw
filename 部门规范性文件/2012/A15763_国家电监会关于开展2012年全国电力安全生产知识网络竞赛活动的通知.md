# 国家电监会关于开展2012年全国电力安全生产知识网络竞赛活动的通知

## 国家电监会关于开展2012年全国电力安全生产知识网络竞赛活动的通知（办安全函[2012]223号　2012年5月18日）

各派出机构，国家电网公司，南方电网公司，华能、大唐、华电、国电、中电投集团公司，各有关电力企业：

为开展好2012年电力行业“安全生产月”活动，深入宣传和普及安全生产法规标准，进一步强化电力企业员工安全生产意识，提高电力安全生产和应急管理水平，根据《关于开展2012年电力行业“安全生产月”活动的通知》（办安全〔2012〕50号）总体部署，决定在电力行业开展以“科学发展，安全发展”为主题的全国电力安全生产知识网络竞赛活动（以下简称竞赛活动）。现将有关事项通知如下。

**一、**活动主题

科学发展，安全发展

**二、**活动时间和形式

竞赛活动时间：6月1日至6月30日。

参赛对象：广大电力企业干部职工。

参赛内容：《电力安全事故应急处置和调查处理条例》、《电力安全工作规程》（发电厂和变电站电气部分、电力线路部分、高压试验室部分）等法规规章标准，电力安全生产知识等。

答题方式：采取互联网答题的方式。

**三、**评选与奖励

竞赛活动设立个人竞赛奖和竞赛组织奖。竞赛结束后，电监会将对获奖个人和单位进行表彰。

**四、**有关要求

各单位要高度重视此次竞赛活动，提前部署，认真组织，电力安委会成员企业单位做好本单位的竞赛组织工作，派出机构做好辖区内地方电力企业的组织工作，为2012年电力行业“安全生产月”活动营造更加浓厚的安全生产氛围。

竞赛活动组织和竞赛规则请于5月30日后登录电监会门户网站（http：//www.serc.gov.cn）查询。
