# 农业部关于下达2012年渔业种质资源保护项目资金的通知

## 农业部关于下达2012年渔业种质资源保护项目资金的通知（农财发[2012]31号）

各有关单位：

根据《财政部关于批复农业部2012年部门预算的通知》（财预[2012]168号），经研究，现将2012年渔业种质资源保护项目经费下达给你们（详见附件），主要用于支持国家级和重点省级水生生物自然保护区开展生态修复及濒危物种救护等工作，开展豚类保护行动计划等工作。请列入2012年政府收支分类科目2130135“农业资源保护与利用”。

该项目已列入财政国库集中支付范围，资金由财政部直接拨付项目单位。各项目单位要设置“物种资源保护费”明细账（财务核算实行统一管理而不单独建账核算的单位，应建立辅助备查账），严格按照项目实施方案及有关财务制度执行，专款专用，合理列支相关费用，项目实施中如有变更事项，应按照申报程序及时履行调整报批手续。主管部门要做好组织实施和监督检查工作，并于2012年12月31日前将项目执行情况、资金使用情况（分别按项目内容和经济分类进行分析）报送我部财务司和渔业局

二〇一二年四月六日
