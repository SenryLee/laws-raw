# 国家测绘地理信息局创先争优活动领导小组关于表彰国家测绘地理信息局直属机关创先争优先进基层党组织和优秀共产党员的决定

## 国家测绘地理信息局创先争优活动领导小组关于表彰国家测绘地理信息局直属机关创先争优先进基层党组织和优秀共产党员的决定（国测党发[2012]24号）

各直属党委、总支、支部：

在党的基层党组织和党员中深入开展创先争优活动，是党的十七大和十七届四中全会提出的加强党的建设的一项重要举措。两年多来，国家测绘地理信息局直属机关各级党组织和广大党员，按照局党组统一部署和要求，紧紧围绕推动科学发展、促进社会和谐、服务人民群众、加强基层组织的总体目标，按照“五个好、五带头”的标准要求，扎实开展创先争优，取得了显著成效。为充分展示局直属机关创先争优的丰硕成果，进一步激励基层党组织、广大党员在测绘地理信息事业科学发展中充分发挥战斗堡垒作用和先锋模范作用，局创先争优活动领导小组决定，对在创先争优活动中表现突出的局机关办公室党支部等15个基层党组织和朱武等31名共产党员予以表彰，并分别授予“国家测绘地理信息局直属机关创先争优先进基层党组织”和“国家测绘地理信息局直属机关创先争优优秀共产党员”荣誉称号（名单附后）。

受表彰的先进基层党组织和优秀共产党员，是局直属机关基层党组织和广大党员的优秀代表，在推动测绘地理信息事业科学发展中比学习、比工作、比贡献，树新风、展新貌、立新功，以实际行动诠释了共产党人的先进和优秀，展示了共产党人的时代风采。局直属机关各级党组织要以受表彰的先进集体为榜样，围绕中心，服务大局，在抓领导班子、带党员队伍、建工作机制、创一流业绩、强宗旨意识等方面走在前，做表率。广大党员要以受表彰的优秀个人为榜样，在学习提高、争创佳绩、服务群众、遵纪守法、弘扬正气等方面走在前，做表率。

希望受表彰的先进基层党组织和优秀共产党员珍惜荣誉，谦虚谨慎，戒骄戒躁，再接再厉，不断确立新目标，实现新突破、创造新业绩。

我国测绘地理信息事业已经进入了全面、快速发展的新时代。局直属机关各级党组织和广大共产党员要以迎接党的十八大为主题，深入学习贯彻李克强副总理考察中国测绘创新基地时的重要讲话精神，围绕“构建数字中国、监测地理国情、发展壮大产业、建设测绘强国”的总体战略，不断总结和运用创先争优活动经验，切实加强党的先进性和纯洁性建设，充分发挥共产党员的先锋模范作用，推动创先争优常态化长效化，推动测绘地理信息事业再上台阶、再创辉煌，以优异成绩向党的十八大献礼。
