# 国家知识产权局办公室关于报送和公开2012年度知识产权(专利)展会信息的通知

## 国家知识产权局办公室关于报送和公开2012年度知识产权（专利）展会信息的通知

各省、自治区、直辖市、计划单列市、新疆生产建设兵团、副省级城市知识产权局；局直属有关单位、社会团体：

为加强全国知识产权系统展会工作的统筹安排，并做好政府信息公开，减少各种利用展会名义进行专利诈骗案件的发生，现就报送和公开2012年度知识产权（专利）展会信息有关工作通知如下：

**一、**报送范围

（一）计划申请以国家知识产权局作为主办、协办或支持单位的展会。

（二）2012年度各地计划举办的地方性知识产权（专利）展会。

（三）国家知识产权局直属单位、社会团体作为主办、协办或支持单位的展会。

**二、**报送要求

各省、自治区、直辖市、计划单列市、新疆生产建设兵团、副省级城市知识产权局负责本行政区域内有关展会信息的组织报送工作，局直属单位、社会团体负责本单位展会信息的报送工作。

请填写“知识产权（专利）展会信息表”（见附件，可到国家知识产权局政府网站“通知”栏下载）于2012年2月15日前以纸件和电子件形式报我局专利管理司。

**三、**展会信息公开

各地、各单位年度计划举办的展会要尽早启动，有关方案确定后，应及时向社会公开，并明确具体负责人的联系方式，方便社会公众查询。我局也将通过政府网站向社会公开有关展会信息。

请各地、各单位高度重视展会信息的报送和公开工作，如年内另有新增展会，按上述方式及时办理。

特此通知。
