# 国家文物局关于庆安会馆砖雕石刻维修保护方案的意见

## 国家文物局关于庆安会馆砖雕石刻维修保护方案的意见（办保函〔2012〕939号）

浙江省文物局：

你局《关于要求审批全国重点文物保护单位庆安会馆砖雕石刻维修保护方案的请示》（浙文物发[2012]234号）收悉。经研究，我局意见如下：

**一、**砖石表面风化产物的类型关系到其清洗材料与技术的选择，方案对风化产物的分析检测多为推算，依据不足。建议采用科学的分析技术以确定其成分，同时补充评估风化机理，提出对有害盐的清洗和脱盐处理措施。

**二、**进一步细化现状调查，按照标准记录病害，在病害调查的基础上补充病害图，并应明确病害面积的统计依据。

**三、**由于砖雕和石刻的材质不同，所使用保护措施及材料也不相同。方案应对砖雕和石刻分别进行病害调查，有针对性的制定保护措施并选择保护材料。

**四、**应补充保护材料的室外试验结果，如室外环境对保护材料的长期影响难以确定，建议加固和防水材料只用于文物表面损坏严重之处，不宜大面积使用。对使用部位应有长期监测计划。

**五、**试验证明环氧树脂不利于砖石文物粘接。应通过测定砖石强度，采用与砖石强度及物理性质相当的粘接材料。应尽量使用物理防护，少用或不用封护材料。

**六、**进一步规范方案中的用语，所用保护材料均应注明化学名称。如应明确OP-10等材料的成分和全称。

**七、**补充施工前后及施工过程中有关档案记录等内容。

**八、**应合理控制经费概算。

请你局根据上述意见，组织相关单位修改完善方案，经你局审核后，另行报批。

国家文物局　　　

二〇一二年八月二十四日
