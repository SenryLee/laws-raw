# 中共中国地质调查局党组关于认真学习宣传贯彻党的十八大精神的通知

## 中共中国地质调查局党组关于认真学习宣传贯彻党的十八大精神的通知（中地调党发〔2012〕30号）

局属各单位党委、局机关各党支部：

为深入学习宣传贯彻党的十八大精神，把广大党员干部群众的思想统一到党的十八大精神上来，把全局力量凝聚到全面保障和促进找矿突破战略行动的实践中来，根据中央、部党组的部署要求，结合我局实际，现就学习宣传贯彻好党的十八大精神通知如下。

**一、**充分认识学习宣传贯彻党的十八大精神的重大意义

党的十八大是在我国进入全面建成小康社会决定性阶段召开的一次十分重要的大会。大会审议通过了胡锦涛同志代表十七届中央委员会所作的报告。报告勾画了在新的历史条件下全面建成小康社会、加快推进社会主义现代化、夺取中国特色社会主义新胜利的宏伟蓝图，是我们党团结带领全国各族人民沿着中国特色社会主义道路继续前进、为全面建成小康社会而奋斗的政治宣言和行动纲领。大会审议通过的党章修正案，科学发展观作为党必须长期坚持的指导思想写入党章。党章修正案体现了党的理论创新和实践发展的成果，体现了党的十八大报告确立的重大理论观点、重大战略思想、重大工作部署，对坚持和改善党的领导、加强和改进党的建设提出了明确要求。大会选举产生了新一届中央领导集体，充分反映了我们党的事业兴旺发达、后继有人、永葆生机，充分反映了全党的意志和全国各族人民的心愿。认真学习宣传贯彻党的十八大精神，关系党和国家工作全局，关系中国特色社会主义事业长远发展，对于动员全党全国各族人民，在党中央的领导下，高举中国特色社会主义伟大旗帜，坚定不移沿着中国特色社会主义道路前进，奋力夺取全面建成小康社会新胜利，具有重大现实意义和深远历史意义。

局系统各级党组织当前和今后一个时期的首要政治任务，就是全面学习宣传贯彻落实党的十八大精神，把广大党员干部和职工的思想统一到十八大精神上来，把智慧和力量凝聚到落实党的十八大提出的重大战略部署和重大战略任务上，为实现党的十八大确定的奋斗目标和工作任务，为努力开创地质调查事业改革发展各项工作新局面而奋斗。

**二、**深刻领会党的十八大的精神实质

党的十八大的主题是高举中国特色社会主义伟大旗帜，以邓小平理论、“三个代表”重要思想、科学发展观为指导，解放思想，改革开放，凝聚力量，攻坚克难，坚定不移沿着中国特色社会主义道路前进，为全面建成小康社会而奋斗。认真学习领会十八大报告和党章修正案是学习贯彻党的十八大精神的核心内容。广大党员干部要原原本本学习党的十八大报告和党章，全面深刻领会党的十八大精神，自觉地用十八大精神武装头脑、指导实践、推动工作。

一是要深刻领会中国特色社会主义是党和人民长期实践取得的根本成就。中国特色社会主义是中国共产党和中国人民团结的旗帜、奋进的旗帜、胜利的旗帜。我们要全面建成小康社会、加快推进社会主义现代化、实现中华民族伟大复兴，必须始终高举中国特色社会主义伟大旗帜，坚定不移坚持和发展中国特色社会主义。

二是要深刻领会中国特色社会主义是由道路、理论体系、制度三位一体构成的。中国特色社会主义道路是实现我国社会主义现代化的必由之路，是创造人民美好生活的必由之路。中国特色社会主义理论体系是马克思主义中国化最新成果。中国特色社会主义制度符合我国国情，集中体现了中国特色社会主义的特点和优势，是中国发展进步的根本制度保障。

三是要深刻领会建设中国特色社会主义的总依据、总布局、总任务。建设中国特色社会主义的总依据是社会主义初级阶段、总布局是五位一体、总任务是实现社会主义现代化和中华民族伟大复兴。社会主义初级阶段是当代中国的最大国情、最大实际，我们在任何情况下都要牢牢把握这个最大国情，坚持“一个中心、两个基本点”不动摇。中国特色社会主义是全面发展的社会主义，我们要在经济不断发展的基础上，协调推进政治建设、文化建设、社会建设、生态文明建设以及其他各方面建设。我们党领导人民进行革命建设改革，就是要让中国人民富裕起来，国家强盛起来，振兴伟大的中华民族。我们要紧紧扭住这个总任务，一代一代锲而不舍干下去。

四是要深刻领会夺取中国特色社会主义新胜利的基本要求。必须坚持人民主体地位，必须坚持解放和发展生产力，必须坚持推进改革开放，必须坚持维护社会公平正义，必须坚持走共同富裕道路，必须坚持促进社会和谐，必须坚持和平发展，必须坚持党的领导，这些基本要求进一步回答了在新的历史征程上怎样才能夺取中国特色社会主义新胜利的基本问题。

五是要深刻领会提高党的建设科学化水平，确保党始终成为中国特色社会主义事业的坚强领导核心。牢牢把握加强党的执政能力建设、先进性和纯洁性建设这条主线，坚持解放思想、改革创新，坚持党要管党、从严治党，全面加强党的思想建设、组织建设、作风建设、反腐倡廉建设、制度建设，增强自我净化、自我完善、自我革新、自我提高能力，建设学习型、服务型、创新型的马克思主义执政党，确保党始终成为中国特色社会主义事业的坚强领导核心。

六是要深刻领会十八大对国土资源和地质调查工作提出的新任务、新要求。十八大报告中要求，“资源节约型、环境友好型社会建设取得重大进展”。在大力推进生态文明建设中明确提出，提高海洋资源开发能力，发展海洋经济，保护海洋生态环境，坚决维护国家海洋权益，建设海洋强国；支持节能低碳产业和新能源、可再生能源发展，确保国家能源安全；加强矿产资源勘查、保护、合理开发；要实施重大生态修复工程，增强生态产品生产能力，推进荒漠化、石漠化、水土流失综合治理；加强防灾减灾体系建设，提高气象、地质、地震灾害防御能力等新任务、新要求。这些都为地质调查事业提供了新的发展机遇，我们要深刻领会，切实贯彻落实。

**三、**紧密结合实际，把党的十八大精神贯彻落实到地质调查事业改革发展的各项工作中

学习贯彻党的十八大精神，要把思想认识切实统一到十八大精神上来，坚持理论联系实际，紧密联系本单位的工作实际和广大党员的思想实际，坚持学以致用、用以促学，把用党的十八大精神武装头脑、指导实践、推动工作作为学习的出发点和落脚点。

地质调查事业是党的事业的重要组成部分，要以党的十八大精神特别是十八大报告中对国土资源和地质调查工作提出的新任务、新要求为指导，从全面建成小康社会和全面深化改革开放、推进社会主义现代化建设的高度，使地质工作更加紧密地与国民经济和社会发展相结合，更加主动地为经济和社会发展服务，全面保障和促进地质找矿突破战略行动，加快世界一流地调局建设，实现中国地质调查事业的科学发展、和谐发展。

一是要把全面保障和支撑找矿突破战略行动作为我们工作的第一要务。坚持把公益服务作为我们整个工作的生命线；按照“统筹部署、科技引领、夯实基础、业务支撑、强化服务”的原则，全力推进重点成矿区带、找矿远景区、整装勘查区地质调查，为促进找矿突破奠定更加坚实的基础。

二是坚持科技创新，发挥科技引领作用。把地质科技创新摆在地质调查事业发展全局的核心位置，提高我局原始创新、集成创新和引进消化吸收再创新能力；着重在资源综合利用、重大基础地质问题、成矿理论、深部找矿理论与方法、关键技术方法等领域形成一批自主创新成果；组织全国的高等院校、科研院所联合攻关，加强基础学科建设与人才队伍培养，搭建技术交流平台，广泛开展技术交流和业务培训；大力研发新理论、新技术、新方法，加强新技术、新方法的示范与推广应用，使科技引领作用贯穿地质找矿全过程。

三是发挥地质工作在资源、环境和工程建设中的基础性先行性作用。我国可持续发展面临的人口、资源和环境三个突出问题中，资源和环境都与地质工作直接相关。要大力加强基础地质工作，进一步增强国内能源资源保障能力；提高海洋资源开发能力，实施好海洋地质调查重大专项，为维护国家海洋权益和提高海洋资源利用水平提供基础支撑；大力加强环境地质工作，做好地质环境调查工作，建设和完善地质灾害调查评价体系、监测预警体系、防治体系和应急体系四大体系，强化城市地质、农业地质调查成果的应用服务，积极应对全球气候变化，加强地下水和地质环境调查监测，为工业化、城镇化和农业现代化提供科学的信息服务，为建设良好生态环境提供地质基础支撑；进一步拓展服务功能，为城乡建设、区域经济发展服务，为国家重大工程建设支撑和服务。

四是大力推进地质文化建设。文化是民族的血脉，是人民的精神家园。根据地质调查工作特点，结合实际，切实加强文化建设。要加强社会主义核心价值体系的教育，弘扬“三光荣”精神，发扬“青藏精神”；加强地质文化宣传教育、文化产品制作、文学艺术创作、科学知识普及工作，开展丰富多彩的群众性文化活动，提高地质文化的生命力、渗透力、凝聚力，增强我局文化软实力。

五是全面加强党的建设，提高党的建设科学化水平。局系统党的建设牢牢把握加强党的执政能力建设、先进性和纯洁性建设这条主线，坚持“服务中心、建设队伍”，抓好思想建设这个根本、党性教育这个核心，加强对党员的理想信念教育，努力建设学习型、服务型、创新型党组织；深化干部人事制度改革，完善局竞争性选拔干部制度、干部考评机制、干部管理制度和干部培训制度；坚持党管人才，加大人才培养和引进力度，建立人才脱颖而出的机制，造就一支适合地质调查事业发展的人才队伍；加快建设一支人员精干、装备精良，具有创新能力的高素质、专业化国家地质调查队伍；开展“抓基层、打基础，全面活跃党支部”和大力开展党员谈心活动，夯实党的基础，加强基层组织建设；全面推进惩治和预防腐败建设，深化重点领域和关键环节改革，坚持教育、监督、惩治并重，加强局系统反腐倡廉建设。

**四、**加强领导，精心组织，认真抓好党的十八大精神的学习宣传贯彻工作

各单位要切实加强领导，精心组织，采取切实措施，迅速掀起学习宣传贯彻十八大精神的热潮。

一是要做好学习安排。各级党组织要高度重视、加强领导，精心筹划，周密安排，区分层次，突出重点，采取多种有效方式，扎扎实实地把十八大精神学习好、宣传好、贯彻好、落实好，务求取得实效。局党组率先垂范，召开中心组理论学习会，深入学习领会十八大精神，发挥示范带头作用。机关党委要抓紧对十八大精神的学习培训，举办专门的培训班，系统地学习培训十八大精神；要及时印发学习宣传贯彻十八大精神的实施方案，按方案推进局系统学习十八大精神的各项工作；要加强对学习情况的掌握，及时总结基层学习的经验，在全局进行推广。各单位党委要抓好自身学习，布置好所属支部的学习工作。局机关党支部要按照局的整体部署，抓好支部学习和每个党员群众的学习工作。局系统十八大精神学习贯彻工作，要形成一级抓一级，层层抓落实的生动局面。

二是要重点抓好领导干部的学习。各级领导干部要率先垂范，带头系统学习、全面领会、深刻理解、坚决贯彻党的十八大精神。各单位党委中心组要把学习党的十八大精神作为中心内容，制定系统学习计划，列出专题进行研讨。要组织班子成员原原本本、认认真真地学习十八大报告和各项决议，既要从整体上全面把握报告的基本精神，又要悉心领会报告提出的一系列重要思想观点，特别是要对一些重大理论观点、重大战略思想、重大工作部署进行深入思考和重点把握，把十八大精神和党的理论创新成果，转化为党员领导干部分析问题解决问题的科学方法和战略思想。

三是要认真抓好广大党员和职工群众的学习。通过举办专题辅导报告、研讨会、交流会、党员学习日等多种形式，组织广大党员集中时间、集中精力认真学习十八大报告和党章，使十八大精神人人领会、个个明白。通过组织征文比赛、举办知识竞赛等生动活泼的形式，帮助广大党员和群众掌握党的十八大精神的基本内容，有针对性地回答职工群众在学习中提出的问题，使十八大精神深入人心。

四是要认真组织好党的十八大精神的宣传。要制定宣传方案，加强组织协调，注重发挥报纸、网络、宣传栏等各种载体的优势和特色，采取行之有效的方式，广泛深入地开展各种宣传活动，贴近实际、贴近生活、贴近群众，既全面准确又深入浅出具体生动，形成学习贯彻党的十八大精神的良好氛围。工青妇等群众组织要充分发挥自身优势，开展各具特色的学习教育活动，使学习教育覆盖到各群体。

五是要全力完成好年初下达的各项重点工作任务目标。各单位、各部门要认真对照年初制定的重点工作任务目标分解表，逐项核实，逐条推进，全力完成。要切实搞好今年工作总结，认真谋划部署2013年各项重点工作任务目标，努力做到学习宣传十八大精神和推进工作两不误、两促进。

各单位要及时制定学习宣传贯彻工作方案，了解学习宣传贯彻情况，总结推广经验，切实加强指导，把学习宣传贯彻党的十八大精神不断引向深入。各单位要及时将学习宣传贯彻党的十八大精神的情况报局党组。

附件：

中国地质调查局深入学习宣传贯彻党的十八大精神工作方案

学习宣传贯彻党的十八大精神是当前和今后一段时间局的首要政治任务。为切实增强学习宣传贯彻活动的针对性和实效性，按照部党组部署，局党组研究决定，利用半年左右的时间，在局系统分阶段开展深入学习宣传贯彻党的十八大精神活动。具体安排如下：

**一、**基本原则

坚持理论联系实际原则；坚持阶段推进、突出重点的原则；坚持学习宣传贯彻十八大精神与抓好工作相结合，两不误、两促进的原则。

**二、**范围对象

局系统各级党组织、全体党员和干部职工。

**三、**方法步骤

（一）认真传达学习阶段（11月中旬--11月下旬）

阶段要求：认真传达学习党的十八大精神，确保覆盖到各级党组织和全体党员干部职工。掌握党的十八大的基本内容，加深对党的十八大提出的一系列新思想、新观点和新论断的认识和理解。

具体安排：

1.召开局党组会议和参加部干部大会传达党的十八大精神，各单位通过全体干部大会、党支部大会等形式层层传达学习。

2.组织党员、干部和职工特别是处以上党员干部通过集中学习和自学相结合的方式精读党的十八大报告、《党章》、习近平总书记在新一届中央政治局第一次集体学习会议上的重要讲话等文件材料，认真阅读原文，初步领会会议精神。

3.结合工作实际，系统学习梳理党的十八大报告对地质工作提出的新任务、新要求。

预期成果：

1.党的十八大精神传达到各级党组织、全体党员、干部和职工。

2.各单位、各部室要结合自身目标任务，领会党的十八大报告对地质工作提出的新任务、新要求 。

（二）深入学习领会阶段（11月下旬--12月中旬）

阶段要求：在传达学习的基础上，创新学习方式，组织开展深入学习、专题研讨，全面把握党的十八大的基本精神特别是对国土资源和地质调查工作提出的新任务和新要求，使十八大精神入脑入心。

具体安排：

1.举办局党组中心组学习十八大精神专题学习会会和各单位党委中心组理论学习会。

2.组织集中培训。举办党的十八大精神培训班、党务干部培训班和共青团干部培训班，培训局机关全体职工和党务干部、团干部。各单位要结合实际，对处以上干部进行一次集中培训，有条件的可扩大到全体干部职工。

3.开展各类活动。各级党组织、群众组织开展党的十八大精神知识答卷、知识竞赛等活动，通过各种形式加深对党的十八大精神的领会和把握。

4.开展重点研讨活动。结合十八大对国土资源、地质调查工作提出的新任务、新要求，对科技、资源、海洋、党建、青年、工会等学习贯彻十八大精神重点研讨。

5.交流学习体会。各单位、各部室以支部为单位举行一次内部交流，每个党员、干部和职工都要谈学习体会。组织一次局系统交流会，请部分部室、局属单位的领导、支部书记、党员和职工进行学习交流。在内部网络专栏发布每个党员、干部和职工的学习体会文章以及各部室、各单位的学习报告，供学习交流。

预期成果：

1.全面把握、准确领会党的十八大基本精神。

2.进一步把握地质调查工作面临的新形势、新任务、新要求。

3.每个党员、干部和职工撰写一篇学习体会文章。

4. 形成重点研讨材料。

（三）积极务虚谋划阶段（12月下旬--2013年1月中旬）

阶段要求：在深入学习的基础上，结合年度工作完成情况和年度总结，对照党的十八大对国土资源工作和地质调查提出的新任务和新要求，查找工作中的问题，找出差距，分析原因，开展务虚谋划，研究提出推进工作的初步思路、办法和措施。

具体安排：

1.局党组对照党的十八大精神，认真查找班子和个人在思想认识、精神状态、工作作风、执行能力和业务工作上存在的差距和不足，提出改进的初步思路和措施。各单位按照局党组的部署，以学习贯彻十八大精神为主要内容，召开一次民主生活会。

2. 各单位、各部室结合全年工作完成情况和年度工作总结，对照党的十八大精神梳理分析工作中的问题，认真分析工作中面临的新形势、新要求、新问题。

3.各单位要结合学习贯彻党的十八大精神，召开一次务虚会议，重点是对本单位工作的思考和对局工作的建议，会后及时报局。局党组召开务虚会，以学习贯彻十八大精神为主线，分析研判地质调查工作面临的形势，结合局属单位的工作思考和建议，梳理地质调查存在的突出问题和矛盾，研究提出解决问题、推进工作的思路和办法。

预期成果：

1.形成局党组和各单位民主生活会整改措施报告。

2.形成各单位学习贯彻十八大精神，推进工作的思路、措施和对局工作建议的报告。

3.形成明年工作以及今后一段时期地质调查事业改革发展思路。

（四）切实贯彻落实阶段（2013年1月中旬--3月底）

阶段要求：在前三个阶段的基础上，提出贯彻落实党的十八大精神的工作措施，并落实到2013年地质调查工作安排中。

具体安排：

1.召开全国地质调查工作会议和局工作会议暨党风廉政建设会议（简称局两会）。通过召开局两会，继续深入学习十八大精神，以十八大精神为指导，部署安排2013年地质调查各项工作，推进局系统党风廉政建设，全面保障和促进找矿突破战略行动。

2.各单位、各部室按照局两会精神，结合实际，加强调查研究，分别提出贯彻落实的具体举措，部署推进2013年各项工作。

预期成果：

1.形成地质调查工作2013年重点工作任务目标。

2.形成各单位、各部室2013年具体工作安排。

3.形成贯彻落实党的十八大精神、推进地质调查工作的有关政策措施。
