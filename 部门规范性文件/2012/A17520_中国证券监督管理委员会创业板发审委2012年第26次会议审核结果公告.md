# 中国证券监督管理委员会创业板发审委2012年第26次会议审核结果公告

中国证券监督管理委员会创业板发行审核委员会2012年第26次会议于2012年4月13日召开，现将会议审核结果公告如下：

银邦金属复合材料股份有限公司（首发）获通过。

湖南红宇耐磨新材料股份有限公司（首发）获通过。

创业板发行监管部
