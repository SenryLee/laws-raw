# 国家旅游局关于2012年第三季度全国旅行社统计调查情况的公报

## 国家旅游局关于2012年第三季度全国旅行社统计调查情况的公报（2012年11月20日）

按照国家旅游局制定、国家统计局批准的《旅游统计调查制度》，经各省、自治区、直辖市旅游行政管理部门审核，现将2012年第三季度全国旅行社统计调查情况汇总公报如下：

**一、**填报情况

统计系统显示，第三季度全国旅行社总数为24685家，完成第三季度报表填报的旅行社为23897家，占总数的96.81%（详见附件1）。

从填报情况看，除西藏、海南、河南、四川外，其他28个地区填报率都达到了90%以上，其中黑龙江、吉林、内蒙古、青海、山东、兵团六个省级单元的填报率达到100%。

**二、**国内、入境、出境旅游三大市场情况

（一）国内旅游市场

2012年第三季度全国旅行社组织国内旅游4113．55万人次、13725.66万人天，接待4830．99万人次、13126.67万人天（详见附件2），同比分别下降1.80%、增长22.39%、下降11.53%、增长26.51%。

第三季度旅行社组织国内旅游人次排名前十位的地区由高到低依次为广东、浙江、江苏、山东、上海、湖北、湖南、重庆、辽宁、北京（见图1）。

图1：第三季度组织国内旅游人次排名前十位的地区情况（略）

第三季度旅行社接待国内旅游人次排名前十位的地区由高到低依次为江苏、广东、浙江、山东、云南、湖北、福建、湖南、四川、上海（见图2）。

图2：第三季度接待国内旅游人次排名前十位的地区情况（略）

（二）入境旅游

2012年第三季度旅行社入境旅游外联490.87万人次、2132.48人天，接待682.08万人次、2399.10万人天（详见附件3），同比分别增长32.01%、增长28.06%，增长10.90%、增长13.50%。

第三季度旅行社外联入境旅游人次排名前十位的客源地国家或地区由高到低依次为香港、韩国、台湾、日本、俄罗斯、澳门、新加坡、美国、马来西亚、泰国（见图3）。

图3：第三季度外联入境旅游人次排名前十位的客源地国家或地区情况（略）

第三季度旅行社接待入境旅游人次排名前十位的客源地国家或地区由高到低依次为香港、台湾、韩国、俄罗斯、澳门、美国、日本、马来西亚、新加坡、泰国（见图4）。

图4：第三季度接待入境旅游人次排名前十位的客源地国家或地区情况（略）

（三）出境旅游市场

2012年第三季度旅行社出境旅游组织795.96万人次、4023.09万人天（详见附件4），同比分别增长46.12%和87.05%。

第三季度旅行社组织出境旅游人次排名前十位的目的地国家或地区由高到低依次为香港、澳门、韩国、泰国、台湾、日本、新加坡、马来西亚、法国、美国（见图5）。

图5：第三季度组织出境旅游人次排名前十位的目的地国家或地区情况（略）

（四）三大旅游市场情况

1.第三季度三大市场人次数比较

以国内组织人次、入境外联人次、出境组织人次三项指标数据为依据比较三大市场，2012年第三季度旅行社国内旅游人次明显高于入境和出境市场，所占份额达到76%（见图6）。

图6：第三季度三大旅游市场人次情况比较（略）

2.第三季度三大市场人天数比较

以国内组织人天、入境外联人天、出境组织人天三项指标数据为依据比较三大市场，2012年第三季度全国旅行社国内旅游人天明显高于入境和出境市场，所占份额达到69%（见图7）。

图7：第三季度三大旅游市场人天情况比较（略）

**三、**分地区三大市场总体情况

2012年第三季度旅行社三大市场组织（外联）接待人次（人天）汇总排序前十位的地区由高到低依次为广东、山东、浙江、江苏、北京、辽宁、湖南、上海、四川、福建（详见附件5）。
