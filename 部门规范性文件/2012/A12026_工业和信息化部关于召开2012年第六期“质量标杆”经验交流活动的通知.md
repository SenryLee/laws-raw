# 工业和信息化部关于召开2012年第六期“质量标杆”经验交流活动的通知

## 工业和信息化部关于召开2012年第六期“质量标杆”经验交流活动的通知（工信科简函[2012]424号）

各有关单位：

按照《关于组织开展2012年“质量标杆”学习实践活动的通知》（工信厅科函[2012]487号）的工作安排，兹定于2012年9月13-14日在广州召开2012年第六期全国“质量标杆”经验交流活动。现将有关事项通知如下：

**一、**活动内容

（一）“质量标杆”经验介绍：

1、珠海格力电器股份有限公司实施质量总体解决方案（TSQ）的实践经验；

2、郑州新开普电子股份有限公司实施质量总体解决方案（TSQ）的实践经验；

3、上海日用-友捷汽车电气有限公司实施可靠性管理的实践经验；

4、四川长虹电器股份有限公司实施可靠性工程的实践经验；

5、太原重型机械集团有限公司实施可靠性管理的实践经验；

6、广州南天电脑系统有限公司实施软件过程改进（CMMI）的实践经验。

（二）专家报告

1、TSQ在推动企业质量提升中的应用方法和案例介绍；

2、绿色电子制造质量保证的挑战与应对；

3、产品环境适应性设计和环境工程管理。

（三）对话交流

（四）企业现场参观

**二、**活动时间和地点

活动时间：9月13日，9：00-17：00；14日，9：00-11：00

报到时间：13日，8：00-8：50

活动地点：广州嘉鸿华美达酒店一楼鸿图厅（广州市天河区广园东路瘦狗岭路313号，电话：020-61131220，乘车路线见附件1）。

**三、**参会人员

企业负责质量工作的高层管理人员、业务骨干人员；报名本次交流活动企业所在地区工业和信息化主管部门、行业协会负责质量标杆活动的有关同志。

**四、**其他事项

1、请周边省市工业和信息化主管部门和行业协会组织企业参会；

2、本次会务工作由工业和信息化部电子第五研究所（中国赛宝实验室）、广东省经济和信息化委员会承办；

3、交流活动免费，交通、食宿费用由参会单位自理。

**五、**报名方法

请参加本次交流活动的有关单位，9月6日前将参加人员信息填写回执（见附件2）发送至maoj@ceprei.org或wangjm@ceprei.org。
