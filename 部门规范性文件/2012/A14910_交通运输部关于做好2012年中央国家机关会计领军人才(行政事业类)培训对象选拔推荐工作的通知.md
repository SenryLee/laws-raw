# 交通运输部关于做好2012年中央国家机关会计领军人才(行政事业类)培训对象选拔推荐工作的通知

## 交通运输部关于做好2012年中央国家机关会计领军人才（行政事业类）培训对象选拔推荐工作的通知（财综便字[2012]99号）

部属各单位：

近日，国务院机关事务管理局印发了《关于开展2012年中央国家机关会计领军人才培训的通知》（国管财[2012]152号，以下简称《通知》），为做好我部会计领军人才培训对象的选拔推荐工作，现将有关事项通知如下：

**一、**各单位要严格按照国管局要求，认真做好本单位的高级会计人员培训对象的选拔工作。

**二、**各单位参加培训选拔人员必须符合《通知》中行政事业类会计领军人才的报名基本条件。参加培训选拔人员须按要求填写《中央国家机关会计领军人才培训项目申请表》（以下简称《申请表》），各单位对《申请表》及相关证明材料要认真进行审核，并按规定提出审查意见并加盖公章。

**三、**请各单位于6月15日前将本单位参加培训选拔人员的《申请表》、相关证明材料（其中包括学历或学位证书的复印件）及一张2寸彩色照片报送我司（综合处）。

**四、**《通知》的具体内容，可登陆交通财会网（http：//www.moc.gov.cn/zichan/siju/caiwusi/）或国管局财务管理司网站（http：//www.ggj.gov.cn/cwgls）查阅下载，《申请表》可自行下载、打印。
