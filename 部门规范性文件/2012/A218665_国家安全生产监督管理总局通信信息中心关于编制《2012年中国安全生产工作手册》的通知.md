# 国家安全生产监督管理总局通信信息中心关于编制《2012年中国安全生产工作手册》的通知

国家安全生产监督管理总局通信信息中心关于编制《2012年中国安全生产工作手册》的通知

（安总信办[2012]12号）

各有关单位：

为认真贯彻落实《国务院关于坚持科学发展安全发展促进安全生产形势持续稳定好转的意见》，深入扎实开展以“科学发展、安全发展”为主题的“安全生产年”活动，进一步加强安全生产监管监察部门与企业之间，安全生产科研、教育、评价机构与企业之间的交流沟通，充分调动各方的力量，更好地为全面促进安全生产工作服务。国家安全生产监督管理总局通信信息中心（以下简称通信信息中心）决定继续编辑出版《2012年中国安全生产工作手册》（以下简称《手册》）。

《手册》将本着数据精确、实用性强、查阅方便、检索科学的原则，对全国的安全生产状况、重点行业运行情况、安全产品、安全生产技术、安全生产科技成果及相关的生产企业、安全生产研究、安全培训、安全评价机构进行详细地介绍。《手册》还将按行业分卷介绍安全生产领域相关企事业单位的基本情况，建设安全生产相关数据库，为国民经济各行业和专业人士提供权威、高效的信息支撑。

《手册》主要内容包括：安全监管总局年度安全生产工作重点、年度安全生产状况及相关统计数据和分析，对煤炭、非煤矿山、危险化学品、石油化工、电力、冶金、航空、水运、安全装备产业等经济运行情况，安全生产应急救援状况，安全生产重大项目的相关技术、产品介绍，重大安全生产技术和科研成果推荐，企业安全生产相关领域内的科技成果、产品、管理方式经验的推广介绍。

通信信息中心特向相关单位征集稿件，请各相关单位踊跃投稿。

附件： 1、《2012年中国安全生产工作手册》编制说明

2、《2012年中国安全生产工作手册》回执表

附件1：

《2012年中国安全生产工作手册》编制说明

**一、**编制内容

1. 单位基本情况及安全生产方面的情况介绍。

2. 单位主要领导人的介绍、安全生产先进事迹。

3. 安全生产方面的科技成果、所获奖项。

4. 安全防护装备、培训、演练和管理方面的情况。

5. 安全生产标准化和安全管理模式的情况。

6. 安全生产信息化方面情况。

7. 安全生产应急预案及演练，应急救援装备与管理系统的情况。

8. 事故预防预警及应急处置演练与管理，相应的管理信息系统、技术装备的情况。

**二、**征集稿件内容的要求

1．稿件分为宣传类和技术成果类。建议供稿单位至少提供一篇宣传类稿件和一篇技术成果类稿件。稿件中务必提供单位名称、通信地址、联系方式及邮箱、网址等联系信息。

2．宣传类稿件

（1）最多不超过4000字。稿件提供后通信信息中心有权将该稿件进行编辑整理后在有关媒体上刊载。

（2）根据征集内容提供企业主要领导人和企业风采的电子照片，每张图片一定要清晰，并注明图片名称以及所反映的内容。

（3）有独立网站的企业需提供域名。

3．新型安全技术、产品和安全管理模式的技术成果类稿件

（1）没有字数限制。此类稿件一经选用，酌情进行编辑修改后，在《手册》和相关网站、期刊上予以上刊载，并注明稿件提供单位及作者和编辑的名字。稿件提供后通信信息中心将有权对该稿件进行编辑整理后在有关媒体上刊载。

（2）提供成果奖项或产品、专利等的证明。
