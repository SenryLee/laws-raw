# 国家测绘地理信息局关于印发国家测绘地理信息局2012年立法工作计划的通知

## 国家测绘地理信息局关于印发国家测绘地理信息局2012年立法工作计划的通知（国测法发〔2012〕5号）

机关各司局：

《国家测绘地理信息局2012年立法工作计划》已经局务会议审议通过，现印发给你们，请认真贯彻执行。

国家测绘地理信息局

二〇一二年四月十八日

国家测绘地理信息局2012年立法工作计划

2012年是测绘地理信息工作的执行年、落实年、实干年。围绕国家测绘地理信息局的年度重点工作，2012年国家测绘地理信息局立法工作的总体思路是：按照“构建数字中国、监测地理国情，发展壮大产业、建设测绘强国”的总体战略，以服务测绘地理信息事业做大做强为核心，加快立法进程，着力抓好地图管理、地理信息资源开发和提供使用、测绘公共服务等方面法规、规章、规范性文件的制定和修订工作，推进依法行政，实现法制建设新突破。

对列入立法计划的立法项目，机关各司局要明确进度、落实责任，严格按照《国家测绘局法规制定程序规定》的要求，组织好调研、论证和征求意见工作，确保立法质量，按时完成立法任务。

2012年国家测绘地理信息局立法项目共计14项。

**一、**出台类项目（6项）

（一）行政法规

1、修订《中华人民共和国地图编制出版管理条例》（更名为《中华人民共和国地图管理条例》），已列为国务院2012年立法工作计划一档出台项目。继续配合国务院法制办，做好条例的调研、论证、协调、修改等工作，力争年内出台。（法规与行业管理司、地理信息与地图司）

（二）部门规章

2、修订《测绘行政执法证管理规定》（更名为《测绘地理信息行政执法证管理规定》）。国家测绘局更名为国家测绘地理信息局后，行政执法证件的样式、内容等也应当随之改变，有必要对现行《测绘行政执法证管理规定》进行修订，为开展新执法证件换发工作提供法律依据。（法规与行业管理司）

（三）重要规范性文件

3、修订《关于对外提供我国测绘资料的若干规定》。为加强对外提供我国测绘成果的管理，适应新形势下对外提供测绘成果的实际需要，有必要修订《关于对外提供我国测绘资料的若干规定》，进一步完善对外提供我国测绘成果的相关制度。（科技与国际合作司）

4、制定《测绘资质巡查办法》。为加强测绘市场监督管理，完善和强化测绘市场监管体系，提高监管效能，建立事前审查与事后监管相结合的监管模式，有必要制定测绘资质巡查办法，实现测绘资质动态监管。（法规与行业管理司）

5、修订《航空摄影管理暂行办法》（更名为《航空航天遥感影像项目管理办法》）。为加强航空航天遥感影像项目管理工作，提高项目管理水平和效率，更好地满足有关方面对遥感影像的迫切需求，有必要对1996年颁布实施的《航空摄影管理暂行办法》进行修订。（国土测绘司）

6、制定《测绘档案管理规定》。随着我国数字化测绘体系的迅速发展，按照国家档案局要求，应当建立健全与数字化测绘体系相适应的档案管理体制与管理制度，规范、引导测绘档案工作健康发展，确保测绘新产品特别是数字产品形成过程中的档案完整、准确、全面归档和充分利用，有必要制定《测绘档案管理规定》。（地理信息与地图司）

**二、**调研类项目（8项）

（一）法律

1、研究修订《中华人民共和国测绘法》，已列为国务院2012年立法工作计划三档研究论证类项目。《中华人民共和国测绘法》修订实施以来，测绘统一监管力度不断加强，基础测绘保障能力不断提高，测绘公共服务成效日益明显，对促进测绘事业健康快速发展，维护国家主权、安全和利益，发挥了重要作用。为了适应测绘地理信息事业发展的新形势，解决现有制度不适应客观实际的问题，有必要修订《中华人民共和国测绘法》，为测绘地理信息事业发展提供有力的法制保障。《中华人民共和国测绘法》今年完成局内调研，力争形成修订草案建议稿。（法规与行业管理司、机关有关司局）

（二）行政法规

2、研究制定《中华人民共和国测绘质量管理条例》。围绕条例制定的必要性、需解决的问题和设立的制度等，进一步开展调研论证。（国土测绘司、法规与行业管理司）

3、研究修订《中华人民共和国测量标志保护条例》。为适应新形势下测量标志保护工作的新情况和测绘地理信息工作的实际需要，切实加强测量标志的保护和管理，有必要对1996年颁布的《中华人民共和国测量标志保护条例》进行研究修订。（地理信息与地图司、法规与行业管理司）

（三）部门规章

4、研究修订《地图审核管理规定》。为解决地图审核工作中出现的新情况和新问题，进一步规范地图市场秩序，促进地图市场健康有序发展，有必要对《地图审核管理规定》进行研究修订。（地理信息与地图司）

5、研究修订《重要地理信息数据审核公布管理规定》。为总结近年来重要地理信息数据审核公布实践经验，进一步规范重要地理信息数据审核、公布的范围和程序，有必要研究修订《重要地理信息数据审核公布管理规定》。（地理信息与地图司）

（四）规范性文件

6、研究修订《测绘资质管理规定》及《测绘资质分级标准》。为适应测绘地理信息行业发展的新情况和对资质管理工作提出的新要求，有必要研究修订《测绘资质管理规定》和《测绘资质分级标准》。（法规与行业管理司）

7、研究制定《三维实景地图公开使用管理规定》。为规范三维实景地图的公开使用，推动三维实景地图的发展和应用，确保地理信息安全，有必要研究制定《三维实景地图公开使用管理规定》。（地理信息与地图司）

8、研究修订《测绘作业证管理规定》。随着测绘地理信息市场的发展，测绘作业范围越来越广，作业形式越来越多，为更好地维护测绘人员的作业权利，适应国家测绘局更名后的形势，有必要研究修订《测绘作业证管理规定》。（法规与行业管理司）
