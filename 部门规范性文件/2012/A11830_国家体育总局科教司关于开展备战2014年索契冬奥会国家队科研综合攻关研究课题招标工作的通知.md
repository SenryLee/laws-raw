# 国家体育总局科教司关于开展备战2014年索契冬奥会国家队科研综合攻关研究课题招标工作的通知

各有关单位：

为做好备战2014年索契冬奥会科技备战工作，依据《国家体育总局奥运科研攻关项目管理办法》有关规定，我司决定开展备战2014年索契冬奥会国家队科研综合攻关研究课题招标工作，现将有关事项通知如下：

**一、**招标指南

招标指南内容来源于国家队备战2014年索契冬奥会工作实际需要，涉及花样滑冰、速度滑冰、短道速滑、空中技巧、雪上技巧、越野滑雪、跳台滑雪、冰壶、冰球、单板平行大回转等运动项目，涵盖训练监控、技战术分析、运动心理等研究领域。（具体附后）

**二、**申请人条件

（一）申请人享有中华人民共和国公民权，遵守中华人民共和国宪法，拥护社会主义制度和中国共产党的领导。

（二）申请人应具有副高级以上专业技术职称或博士学位获得者。

（三）申请人必须从事实际研究工作并真正承担和负责课题的组织与实施。

（四）课题参加者必须征得本人同意，否则视为违规申报。

（五）课题第一申请人正在主持的省、部级以上科研课题不得超过2项（含2项）。

**三、**申报单位条件

（一）在全国范围内具备开展相关研究能力基础、能为招标课题实施提供必要条件保障的法人单位。

（二）每个单位可单独申请，亦可多个单位联合申请。

（三）申报单位需设有科研管理职能部门。

**四、**申报程序

（一）凡符合以上规定条件的单位及人员均可申报。

（二）申报课题须于截止日期前从网上提交申报书（总局网站点击进入），并将经单位审查合格的课题申报书一式5份（单位法人签署意见，加盖公章）报送至国家体育总局冬季运动管理中心科研信息部。没有通过网上申报的课题不予受理。

**五、**评审及立项

科教司将组织专家对申报的科研课题进行资格审查和专家评审。中标课题单位和负责人在同意遵守国家体育总局相关科研管理规定前提下签订计划任务书，并实施课题研究工作。

**六、**有关要求

（一）请按照国家体育总局科教司有关要求如实填写申报材料，并保证没有知识产权争议。凡在申请中弄虚作假者，一经发现并查实后，取消三年申报资格；如获准立项，立即给予撤项处理并通报批评。

（二）为保证申报和评审工作的公正性和严肃性，在评审会召开之前，申报单位或个人不得以任何名义走访、咨询或邀请评审组专家进行申报辅导。凡行贿评审专家的，一经查实，将予以公开通报批评；如获立项，一律撤项，五年之内不得申报国家体育总局科研课题。

（三）获准立项的课题负责人在课题执行期间要遵守相关承诺，履行约定义务，按期完成研究任务，按要求进行课题成果验收。课题经费使用情况将由国家体育总局财务管理和审计中心进行审计。

（四）各课题申报单位要加强对课题申报工作的组织和协调，认真审核，严格把关，择优推荐，努力提高申报质量。未经单位主管部门盖章同意的课题申报书，不予以受理。

（五）课题申报受理时间截止至2012年9月17日，逾期不予受理。

附件：

备战2014年索契冬奥会国家队科研综合攻关研究课题招标指南

**一、**花样滑冰难度跳跃技术稳定性的研究

研究重点：1.通过课题设计、研究、攻克和提高1到2种难新跳跃技术动作，保持高质量和稳定性的成功率，运用在第22届冬奥会比赛中，以优质高难跳跃技巧取胜，获得高技术水平分，并取得更多的加分；2.探索和总结一套科学、先进的提高花样滑冰跳跃技术水平的训练方法和手段，同时建立运动员技术档案。

经费概算：4万元。

**二、**结合规则有效提高花样滑冰技术分和节目内容分的研究

研究重点：1.技术方面：解决中国双人滑选手单人跳跃技术问题，提高动作的稳定性；2.艺术方面：提高运动员的文化艺术素质、进行系统的艺术能力训练。根据主力队员各自的特点设计个性化训练、制定不同的训练内容，各有侧重。

经费概算：4万元。

**三、**国家速滑队重点队员备战索契冬奥会训练过程控制关键技术的研究

研究重点：1.对我国速度滑冰训练理论与实践进行总结，进一步认识项目特征和制胜规律，对国内外近年来有关速度滑冰和一般训练学方面的最新研究成果进行分析，提高认识，转变思想，更新理念；2.全面了解我国国家队重点运动员竞技能力状态，准确把握个体特征，确定训练导向目标并制定针对性的训练方案；3.科学制定重点运动员两年的备战规划，对训练对象实施目标导向与过程控制相结合的训练与管理模式；4.对重点运动员的训练进行科学的监控，使运动员按既定的训练计划科学训练、成功参赛，实现竞赛目标。

经费概算：8万元。

**四、**短道速滑犯规判罚的对比分析与研究--国际规则修改对超越战术的影响

研究重点：为中国短道速滑队训练和参加国际比赛提供信息和分析结果，适应滑跑规则变化对技战术的影响，确保运动员的能力得到正常发挥。

经费概算：5万元。

**五、**新规则背景下短道速滑竞赛编排与冬奥会衔接的研究与实践

研究重点：1.全面解读新规则在实施过程中对裁判员执裁及运动员参赛的影响，改进我国短道速滑竞赛各项组织流程及裁判工作方法，全面与国际大赛接轨；2.改进短道速滑竞赛组织方案，结合以赛代训的竞赛机制，培养运动员、教练员全新的竞赛理念；3.研发全新的短道速滑比赛网络一体化系统，与国际大赛的竞赛信息化技术手段全面接轨。

经费概算：2万元。

**六、**国家自由式滑雪空中技巧队备战、参赛2014冬奥会的心理训练

研究重点：1.通过日常心理咨询帮助运动员解决训练中的心理问题，使运动员以良好心态参加训练；2.帮助运动员和教练员进行沟通，建立良好的训练氛围，提高训练效果；3.通过系统的心理训练提高运动员的心理抗压能力，进而提高比赛发挥的稳定性；4.以培养积极的、良好的思维习惯和行为习惯为心理训练和心理咨询的指导思想，帮助运动员通过平时积极习惯的养成，以自信、自控、自强的心理定向应对训练、比赛中的困难、挫折和意外。

经费概算：6万元。

**七、**自由式滑雪雪上技巧项目备战2014年冬奥会运动员心理稳定性的研究

研究重点：1.解决我国雪上技巧国家队在比赛中存在的一系列心理问题；2.重点提高我雪上技巧运动员在大赛中心理稳定性和抗干扰能力；3.掌握我国运动员心理特点；4.探寻雪上技巧项目心理发展规律，为运动员训练和比赛提供理论支撑。

经费概算：5万元。

**八、**越野滑雪陆地、雪上专项化训练方法有效衔接的研究

研究重点：研究设计陆地、雪期专项化训练器械模拟雪上技术技巧及所需体能强度、耐力，促进越野滑雪陆地、雪上专项化训练方法有效衔接过渡，并采集相关数据。研制训练方法所需要的专项训练器械，提供备战队伍使用，为运动员备战2014-2018年冬奥会提供科学有效的训练方法，并提供相关训练方法与技术理论支持。

经费概算：10万元。

**九、**跳台滑雪起跳前助滑速度的监控与提高

研究重点：1.匹配测速仪器；2.对各种连身服、雪鞋、雪板、雪蜡等不同器材的使用，测试速度；3.找到助滑速度快的助滑姿势；4.不同雪质对助滑速度的影响；5.夏季跳台助滑道条件，测试各种液体蜡、油脂、板底面等的速度。

经费概算：10万元。

**十、**冬季集体项目可持续性发展管理模式的研究

研究重点：改进冰壶队或其他集体项目的管理模式，有效地整合训练、科研、医疗、教育等各个分立的资源，优化组织的运行机制，使运动队保持在高竞技水平，为冰壶队在2014年索契奥运会中取得好成绩提供管理建议及技术支撑，也为今后可持续性发展提供有力的可行性管理方案。

经费概算：8万元。

**十一、**建立国际冰球发展中心对我国冰球运动发展战略影响的研究

研究重点：1.我国冰球运动发展现状及现今世界冰球运动发展趋势，剖析运动成绩下降的原因，提出解决问题的方法；2.建立国际冰联哈尔滨冰球教育发展中心机构，设立、开发《冰球训练、管理培训课程》，拓展学习资源，扩大对外交流。构建信息技术环境下，培养学员学习能力、合作能力、创新能力、实践能力的冰球运动训练理念的新型教学模式；3.对《冰球训练培训课程》开发设计的理论和教学的理论进行研究。

经费概算：5万元。

**十二、**单板平行大回转过门技术的综合研究

研究重点：通过本研究提高我国单板平行大回转项目运动员的过门速度和成功率，在奥运资格赛争取更多的积分，争取在冬奥会前拿到参赛资格。

经费概算：10万元。
