# 国家知识产权局专利文献馆关于2012年"春节"专利文献馆闭馆的通知

根据《国务院办公厅关于2012年部分节假日安排的通知》（国办发明电[2011]45号），2012年“春节”专利文献馆闭馆时间为2012年1月22日（星期日）至2012年1月28日（星期六），共7天。

1月29日（星期日）开馆。

特此通知。

国家知识产权局专利文献馆

2012年1月20日
