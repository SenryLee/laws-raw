# 中华全国供销合作总社关于表彰2012年全国供销合作社系统实施卓越绩效模式先进企业的决定

各省、自治区、直辖市、计划单列市、副省级省会城市、新疆生产建设兵团供销合作社质量管理机构，全国供销合作社系统实施卓越绩效模式先进企业，有关供销合作社及企事业单位：

2012年我国供销合作社系统广大企业通过导入卓越绩效模式，不断创新、持续改进，取得了显著成效，涌现了一批先进企业。为了进一步推动卓越绩效模式在各类组织中的学习和实践，树立全国实施卓越绩效模式的先进典型，根据中国质量协会《关于推荐2012年全国实施卓越绩效模式先进企业的通知》（中国质协字[2012]5号）精神，中国质量协会供销合作系统分会在今年2月发出《关于推荐2012年全国供销合作社系统实施卓越绩效模式先进企业的通知》（中国质协供字[2012]3号）。我会在各地推荐的基础上，经审核确认，决定对中农立华生物科技股份有限公司等16家全国供销合作社系统实施卓越绩效模式先进企业予以表彰，现予以公布（见附件1，排名不分先后）。

希望受表彰的企业再接再厉，坚持持续改进，不断追求卓越，努力提高产品、服务和经营质量，为提高我国供销合作社及企事业单位的综合实力做出新的贡献。
