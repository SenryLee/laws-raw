# 国家质量监督检验检疫总局计量司关于确定第四批参加中国计量科学研究院科研课题研究人员的通知

各省、自治区、直辖市、计划单列市、副省级市计量科学（测试技术）研究院（所），中国测试技术研究院：

按照总局《关于选派技术骨干参加中国计量科学研究院科研课题研究的通知》（质检办量函﹝2012﹞43号）文件要求，2012年全国35个副省级以上计量院（所）共推荐了114名技术人员到中国计量科学研究院进修，参与国家科研课题项目研究。经与中国计量科学研究院商议，共选择其中53名人员为第四批学员（名单见附件1）。为做好进修报到工作，现将有关事项通知如下：

1. 请有关单位填写《进修人员情况表》（见附件2），发送到指定邮箱，于2012年4月30日前发送到以下邮箱，以便中国计量科学研究院做好安排。邮箱地址：tianf@nim.ac.cn.

2. 请有关单位通知本人于2012年6月30日前到中国计量科学研究院报到，逾期未到者视为自动放弃进修。

3.如有特殊情况无法来进修的，请所在单位及时提出意见报计量司。
