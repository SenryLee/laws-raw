# 国家发展改革委地区经济司关于做好2012年度社会公开征集研究项目结题工作的通知

各课题组：

按照规定，截至2013年2月28日，我司2012年度社会公开征集研究项目（附件1）应完成并提交有关研究成果。为保证结题工作顺利展开，现将有关事宜通知如下：

**一、**成果提交：请各课题组于2013年2月28日前，严格按照《国家发展改革委地区经济司社会公开征集课题提交成果格式》（附件2）要求，提交纸质研究成果（包括全写本和简写本）各10份，电子版研究成果（包括全写本和简写本）各1份。

**二、**评审方式：我司收到研究成果后，将尽快组织专家进行评审，并将评审结果和修改意见反馈给课题组。如无需特别说明事项，课题组不参加评审。

## 国家发展改革委地区经济司社会公开征集研究项目提交成果格式要求

**一、**题目（三号宋体，居中，上空2行）。

**二、**正文（小四号宋体，段首前空二个字，上空一行，21磅行距），文中所用计量单位，一律按国际通用标准或国家标准，并用英文书写，如km2，kg等。文中年代、年月日、数字一律用阿拉伯数字表示，阿拉伯数字和英文字母用Times New Roman体。

一级标题：一、（小四号黑体，左空2字，段前、后各24磅）；

二级标题：（一）（小四号仿宋体，左空2字，段前、后各18磅）；

三级标题：1、（小四黑体），左空2字，段前、后各12磅）；

四级标题：（1）（小四宋体，左空2字，右空1字，接排正文）；

五级标题：（1）（左空2字，接排正文，用于无标题段落）；

六级标题：①（正文中接排，不另起行的序号，两段之间用分号）。

**三、**表格：标题用宋体五号加粗，居中，上、下各空0.5行；表格内文字用小五号宋体；表格设置度量单位为百分比，指定宽度为100%；表格内行间距设置为16磅；单元格对齐方式为上下、左右居中；资料来源用宋体五号字，如有两个以上资料来源分别用序号标出，中间用分号隔开；表格下空一行（具体示例如下）。

资料来源：1.×××；2.×××。

**四、**图：标题（五号宋体加粗）在图的下方居中，空一行。

**五、**参考文献（参考文献：此四字用小四号黑体，居中，上下各空一行，文献中文用五号楷体，阿拉伯数字和英文字母用Times New Roman体，单倍行距）文献著录格式如下：

1、著作：作者姓名.书名.出版社名，出版年月，页码（如有两个以上作者，作者间用逗号分开）；

2、期刊：作者姓名.文章名.期刊名，年份，卷（期）、页码。

**六、**课题组成员名单（课题组成员名单：此七字用二号宋体加粗，居中，上、下各空一行）格式如下：

课题组长：小三号仿宋，加粗，单占行；

姓名与工作单位及职称（或职务）之间空2字，小三号仿宋；

课题组成员：小三号仿宋，加粗，单占行；

姓名与工作单位及职称（或职务）之间空2字，小三号仿宋。
