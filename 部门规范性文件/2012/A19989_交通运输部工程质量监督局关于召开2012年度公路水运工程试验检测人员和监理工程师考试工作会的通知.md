# 交通运输部工程质量监督局关于召开2012年度公路水运工程试验检测人员和监理工程师考试工作会的通知

各省级交通质监机构：

为做好2012年试验检测人员和监理工程师考试相关工作，部质监局和部职业资格中心定于2012年3月16日至17日在云南召开考试工作会，现将有关事项通知如下：

**一、**会议时间：2012年3月17日 （全天）

报到时间：2012年3月16日 （全天）

**二、**会议地点：云南省交通休养院（昆明市西山区海口镇白鱼口）

**三、**会议主要内容：

1.通报2011年试验检测和监理过渡考试工作情况；

2.布置2012年试验检测和监理考试工作；

3.考务工作经验交流。

**四、**参加人员：各省级质监机构主管试验检测或监理考试工作的站（局）长及具体负责人员各1人（总数不超过2人）。

**五、**本次会议会务工作委托云南省交通运输厅工程质量监督局负责，请与会代表于3月12日前将回执传真至0871-3928966。
