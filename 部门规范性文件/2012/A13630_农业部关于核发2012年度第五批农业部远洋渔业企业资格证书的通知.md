# 农业部关于核发2012年度第五批农业部远洋渔业企业资格证书的通知

## 农业部关于核发2012年度第五批农业部远洋渔业企业资格证书的通知（农渔发【2012】18号）

山东省海洋与渔业厅、浙江省海洋与渔业局：

根据《远洋渔业管理规定》，我部同意授予舟山明州远洋渔业有限公司、舟山顺行远洋渔业有限公司、荣成市海宇渔业有限公司、山东蓝越远洋渔业有限公司、荣成市连海渔业有限公司、石岛集团有限公司、山东水产外经总公司、威海世源远洋渔业有限公司、荣成市永进水产有限公司等9家企业2012年度农业部远洋渔业企业资格（第五批），并核发《农业部远洋渔业企业资格证书》。请你局收到上述《农业部远洋渔业企业资格证书》后，及时发放到有关远洋渔业企业。

特此通知。

二○一二年七月六日
