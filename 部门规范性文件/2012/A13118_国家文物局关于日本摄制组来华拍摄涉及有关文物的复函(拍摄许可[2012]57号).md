# 国家文物局关于日本摄制组来华拍摄涉及有关文物的复函(拍摄许可[2012]57号)

## 国家文物局关于日本摄制组来华拍摄涉及有关文物的复函（拍摄许可〔2012〕57号）

国家广播电影电视总局国际合作司：

你司关于日本电视台（NTV）卫星频道《BS日视》摄制组来华拍摄专题片涉及文物的函（外字[2012]617号）收悉。经研究，我局同意该摄制组于2012年7月30日至8月10日拍摄上海鲁迅故居、豫园、课植园，江苏狮子林、拙政园、留园、沧浪亭、太平天国忠王府、苏州云岩寺塔（俗称虎丘塔）、盘门、玉燕堂有关外景镜头。具体拍摄内容及拍摄方式等事宜请与当地文物部门协商确定。在拍摄过程中，请该摄制组严格服从文物管理人员安排，务必确保文物安全。

国家文物局　　

二〇一二年七月十九日
