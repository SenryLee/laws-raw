# 国家质量监督检验检疫总局计量司关于上报2012年计量工作总结、基本情况统计表和2013年工作要点的通知

各省、自治区、直辖市计量科学（测试技术）研究院（所），中国测试技术研究院：

为了全面了解全国省级以上法定计量检定机构2012年各项工作情况，总结经验，明确2013年计量技术机构的工作目标，现请各单位于2013年1月10日前将2012年计量工作总结、基本情况统计表和2013年计量工作要点（均以电子档形式）报送总局计量司。材料应当包括以下内容：

1、工作总结和工作要点：2012年基本情况，取得的成绩和经验（包括发生的重大事件）；工作中存在的问题和不足以及2013年的工作目标、重点任务和具体措施；

2、对今后法定计量检定机构改革和发展的意见和建议；

3、如实、认真填报2012年法定计量检定机构基本情况统计表（格式见附件，表格下载网址：http：//jls.aqsiq.gov.cn/kxjlxxzh/201212/t20121221_335228.htm）。

各单位对2012年各项工作进行全面总结时，要做到条理清晰、内容真实、数据准确。谋划2013的工作重点时，要做到切合实际、重点突出。
