# 国家质量监督检验检疫总局公告2012年第84号――关于公布2012年4类儿童用品质量国家监督抽查结果的公告

## 国家质量监督检验检疫总局公告（2012年第84号）

关于公布2012年4类儿童用品质量国家监督抽查结果的公告

根据《中华人民共和国产品质量法》和《产品质量监督抽查管理办法》的规定，国家质检总局对国内生产的童车、童鞋、儿童及婴幼儿服装、玩具等4类儿童用品质量进行了国家监督抽查，现将抽查结果予以公布。

国家质检总局已责成相关省、直辖市质量技术监督部门按照有关法律法规，对本次抽查中不合格的产品及其生产企业依法进行处理。

特此公告。

附件：1．童车产品质量国家监督抽查结果

2．童鞋产品质量国家监督抽查结果

3．儿童及婴幼儿服装产品质量国家监督抽查结果

4．玩具产品质量国家监督抽查结果

二〇一二年五月三十日

附件1：

童车产品质量国家监督抽查结果

本次共抽查了天津、河北、江苏、浙江、福建、广东等6个省、直辖市116家企业生产的116种童车产品，包括：儿童自行车、儿童三轮车、儿童推车、婴儿学步车、其它玩具车辆等5个种类。

本次抽查依据《儿童自行车安全要求》GB14746-2006、《儿童三轮车安全要求》GB14747-2006、《儿童推车安全要求》GB14748-2006、《婴儿学步车安全要求》GB14749-2006、《国家玩具安全技术规范》GB6675-2003等标准的要求，对童车产品的机械物理性能、燃烧性能、迁移元素、产品标识等4大类118个项目进行了检验。

抽查发现有23种产品不符合标准的规定，涉及到可触及的锐利尖端、制动装置、动态强度、防撞间距、危险夹缝、小零件、闸把尺寸等项目。具体抽查结果见附件。
