# 国家质量监督检验检疫总局公告2012年第191号――关于公布第四批锅炉能效测试机构的公告

## 国家质量监督检验检疫总局公告（2012年第191号）

关于公布第四批锅炉能效测试机构的公告

根据国家质量监督检验检疫总局《锅炉节能技术监督管理规程》规定，为进一步推动锅炉能效测试工作，促进节能监管，质检总局对有关单位报送的锅炉能效测试机构申报资料进行了核查，现将确定的第四批在用工业锅炉能效测试机构名单（详见附件）予以公布。

附件：第四批在用工业锅炉能效测试机构名单

国家质量监督检验检疫总局

2012年12月3日
