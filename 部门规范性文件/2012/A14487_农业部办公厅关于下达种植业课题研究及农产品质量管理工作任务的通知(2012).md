# 农业部办公厅关于下达种植业课题研究及农产品质量管理工作任务的通知(2012)

## 农业部办公厅关于下达种植业课题研究及农产品质量管理工作任务的通知（农办农〔2012〕44号）

各有关单位：

根据种植业课题研究及农产品质量管理工作需要，现将2012年“农业法制建设与政策调研”及“农产品质量安全监管”项目任务下达你们。请各单位根据下达的任务和预算控制资金，在前期工作基础上，尽快完善工作方案，编制项目任务书（如前期已提交实施方案的可不编制任务书）。研究工作要立足实际，深入调研；成果报告要内容翔实、分析科学、条理清晰、图文并茂；政策措施和建议要符合实际，具有较强的可操作性。请于6月18日前将任务书一式四份报送我部种植业管理司审核，并于12月底前提交成果报告。

**十一、**共同条款

签约各方共同遵守以下条款：

1、所拨中央财政经费，承担单位要专款专用，不得挪作它用。若经费超支，由承担单位自筹解决，但不得因此影响本项目的执行。

2、执行过程中，需修改或调整任务的，必需经双方共同商定。

3、执行完成后，承担单位必须按规定的内容向委托单位提交执行情况总结报告、经费结算表和完整的技术资料、文件，并经委托单位验收。

4、承担单位因故中止任务时，应视实际情况追回全部或部分资金。

5、本任务书一式4份，委托单位和承担单位各存2份。

6、执行过程中如发生争议、纠纷，由双方协商解决。
