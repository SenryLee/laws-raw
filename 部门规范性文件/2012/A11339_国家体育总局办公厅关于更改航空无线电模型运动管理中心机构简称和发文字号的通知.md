# 国家体育总局办公厅关于更改航空无线电模型运动管理中心机构简称和发文字号的通知

各司、局，各直属单位：

根据工作需要，现将体育总局航空无线电模型运动管理中心的机构简称更改为“航管中心”；发文字号更改为“航管字〔年份〕×号”。原来的机构简称“航电模中心”和发文字号“航电模字〔年份〕×号”停止使用。

特此通知。

体育总局办公厅

2012年9月4日
