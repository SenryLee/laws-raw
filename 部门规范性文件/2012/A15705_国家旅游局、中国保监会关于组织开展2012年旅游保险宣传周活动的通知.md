# 国家旅游局、中国保监会关于组织开展2012年旅游保险宣传周活动的通知

## 国家旅游局、中国保监会关于组织开展2012年旅游保险宣传周活动的通知（旅办发〔2012〕242号）

各省、自治区、直辖市旅游局（委），各保监局：

为加大旅游保险宣传，强化旅游保险意识，深化“旅保合作”机制，国家旅游局、中国保监会决定开展2012年“旅游保险宣传周”（以下简称“宣传周”）活动。现就组织开展2012年“宣传周”活动的有关事项通知如下：

**一、**活动目标

深入贯彻《国务院关于加快发展旅游业的意见》和《国务院关于保险业改革发展的若干意见》精神，强化旅游者和旅游企业的风险意识，推动旅游保险合作，提升旅游保险服务水平，进一步发挥保险的经济补偿和社会管理功能，提升旅游业的风险管理水平和安全保障能力，把旅游业培育成为国民经济战略性支柱产业和人民群众更加满意的现代服务业。

**二、**活动时间

2012年6月25日-7月1日

**三、**活动主题

快乐出游，保险相伴

**四、**有关要求

（一）高度重视活动重要性，加强组织领导和部门联合。各地要将“宣传周”活动纳入行业安全生产月活动的总体安排之中，把开展“宣传周”活动作为安全生产工作的一项重要内容、作为政府部门履行公共服务职能的一项重要工作、作为推动提升行业诚信服务水平的一个重要手段来抓。各地旅游部门和保险监管部门要加强组织领导和部门协作，结合各地实际，联合制订工作方案，及早谋划，统筹安排，共同组织好“宣传周”各项活动。

（二）充分调动各方积极性，广泛开展宣传咨询活动。在“宣传周”期间及前后，要多方调动相关企业、专家、学者、公众等各方面的积极性，利用报纸、广播、电视、网络等多种媒体，采取案例分析、知识竞赛、征文比赛等多种形式，广泛宣传旅游保险的作用。要充分发挥旅游、保险两个行业的企业主体作用，鼓励保险机构和旅游企业在社区、商业中心、旅游景区、旅行社门市、保险机构网站等游客和公众集中区域，设专台或专栏开展咨询和宣传活动，形成浓厚的宣传氛围，扩大宣传覆盖面。

（三）倡导企业诚信经营，大力开展优质惠民活动。要发挥旅游和保险行业协会的作用，倡导企业诚信经营、提升旅游保险服务水平。鼓励保险机构深入旅游市场，研究旅游企业和旅游者的需求，不断开发并推出贴近市场的旅游保险产品。鼓励旅游企业与保险机构合作，获取保险代理资质，为旅游者提供便利的保险咨询、产品购买等服务。在“宣传周”及前后，鼓励保险机构对现有旅游保险产品加大推广，给予消费者切实优惠，惠及民众。

（四）加强理论和实践研究，形成长效宣传机制。要鼓励科研机构、高等院校、保险机构、旅游企业利用“宣传周”的有利契机，共同开展研讨，深化旅游保险产品和市场研究，形成产学研联动机制，充分借鉴国外的先进经验，推动我国旅游保险产品的丰富和市场的不断成熟。同时各地要注重交流总结开展“宣传周”活动的经验，及时报送好的经验和做法，探索建立长效机制，深入持续地开展旅游保险宣传，推动旅游者和旅游企业的旅游保险意识不断提升、旅游保险市场不断成熟完善。
