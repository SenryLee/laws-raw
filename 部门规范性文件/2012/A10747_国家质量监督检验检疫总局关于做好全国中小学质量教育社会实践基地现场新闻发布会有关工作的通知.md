# 国家质量监督检验检疫总局关于做好全国中小学质量教育社会实践基地现场新闻发布会有关工作的通知

浙江省质量技术监督局、宁波出入境检验检疫局、宁波市质量技术监督局：

按照2012年全国“质量月”主要活动安排，总局计划召开全国中小学质量教育社会实践基地现场新闻发布会，现将有关情况通知如下：

**一、**发布会时间

2012年9月27日上午9：30-11：00

**二、**发布会地点

雅戈尔集团股份有限责任公司

**三、**主办单位

主办单位：国家质检总局 教育部

协办单位：浙江省质监局、浙江省教育厅、宁波出入境检验检疫局、宁波市质监局、宁波市教委、雅戈尔集团股份有限公司

**四、**参会代表

1.荣获“2012年全国中小学质量教育社会实践基地”的浙江省5家单位代表，共5人；

2.中央媒体、质检媒体、地方媒体约30人；

3.宁波出入境检验检疫局、宁波市质量技术监督局共30人；

4.宁波重点企业代表30人（宁波市）；

5.雅戈尔集团股份有限公司员工40人（宁波市）；

6.参加现场质量教育的中小学生20-30人（宁波市）。

**五、**出席会议领导

教育部基础一司、总局质量司、办公厅及宁波市相关领导。

**六、**现场新闻发布会议议程

1.宁波市政府领导致辞；

2.教育部基础一司领导宣读关于命名2012年“全国中小学质量教育社会实践基地”的决定；

3.对荣获“2012年全国中小学质量教育社会实践基地”的浙江代表授牌；

4.质检总局质量司田司长发布开展中小学质量教育基地建设情况的通报；

5.雅戈尔集团股份有限公司代表2012年“全国中小学质量教育社会实践基地”作公开承诺；

6.现场观摩开展中小学质量教育活动；

7.赴宁波检验检疫局生物安全检测分中心基地观摩。

**七、**有关工作分工

请浙江省质监局负责协调省级主要媒体出席发布会报道，宁波市质监局负责主会场布置、各部门人员协调及接待工作，宁波出入境检验检疫局负责生物安全检测分中心基地观摩的会场布置、采访协调及相关接待工作。

请各相关单位按职责沟通协作，认真做好现场新闻发布会有关工作，确保新闻发布会圆满成功。
