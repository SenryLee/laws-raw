# 国家减灾委办公室、民政部国家减灾中心2012年防灾减灾政策理论研究课题立项公告

国家减灾委办公室、民政部国家减灾中心于2012年1月11日发布了《2012年防灾减灾政策理论研究课题指南》。截止3月15日，共收到社会各界提交的有效课题申报书101份。经组织国家减灾委专家委等单位专家评审，确定8个单位承担2012年防灾减灾政策理论研究课题研究任务，现予公告。请承担单位按照《课题指南》的有关要求办理相关手续，并尽快启动课题研究工作。

衷心感谢社会各界对国家防灾减灾政策理论研究的关注和支持。
