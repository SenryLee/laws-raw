# 国家安全监管总局办公厅关于召开全国安全社区建设工作会议的通知(2012)

## 国家安全监管总局办公厅关于召开全国安全社区建设工作会议的通知（安监总厅政法函〔2012〕172号）

各省、自治区、直辖市、计划单列市及新疆生产建设兵团安全生产监督管理局，各有关单位：

为进一步深入推动全国安全社区建设，提高全民安全意识和安全行为能力，最大限度地降低和减少各类事故与人员伤亡，促进全国安全生产形势持续稳定好转，经研究，定于2012年11月下旬在陕西省西安市召开全国安全社区建设工作会议。现将有关事项通知如下：

**一、**会议内容

通报全国安全社区建设工作的进展情况，部署明年工作，命名全国安全社区，表彰安全社区建设先进单位和先进工作者，交流安全社区建设工作经验。

**二、**会议时间和地点

时间：11月21日至22日，20日报到。

地点：西安宾馆（地址：西安市长安路北段58号）。

**三、**参加会议人员

各省、自治区、直辖市、计划单列市及新疆生产建设兵团安全生产监督管理局分管负责人（限1人），国家安全监管总局有关司局负责人。

本次被命名的安全社区代表，被表彰的安全社区建设先进单位和先进工作者。

已命名的全国安全社区和即将命名的国际安全社区代表，正在创建安全社区的社区代表，省级以下安全监管部门代表，全国安全社区地区支持中心代表。

**四、**其他事项

（一）请各单位于11月12日前将报名回执（见附件）传真至中国职业安全健康协会安全社区办公室（联系人及电话：李东方、刘岩，010-64464565＜带传真＞、64463918）。

（二）会议不安排接机（站），请代表自行前往会场（距西安咸阳国际机场约45公里，乘坐机场大巴1号线或出租车，约50分钟；距西安火车站约10公里，可由火车站乘坐14路、239路、603路公交车到草场坡站下车，步行100米即到，或乘坐出租车，约25分钟）。

附件：报名回执

国家安全监管总局办公厅
