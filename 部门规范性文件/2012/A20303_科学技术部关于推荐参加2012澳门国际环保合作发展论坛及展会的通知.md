# 科学技术部关于推荐参加2012澳门国际环保合作发展论坛及展会的通知

## 科学技术部关于推荐参加2012澳门国际环保合作发展论坛及展会的通知（国科社函[2012]19号）

各有关单位：

由澳门特区政府主办的“2012澳门国际环保合作发展论坛及展览”将于3月29至31日在澳门举行，我部是本届会议的支持单位之一，将推荐在国家科技计划支持下取得的成果参展。该展览自2008年至今已成功举办了四届，有效发挥了澳门的“绿色通道”作用，带动了内地先进环保技术和设备向欧洲和葡语系国家的推广转移。

请“十一五”期间承担国家科技计划环保方面任务的单位，积极组织科研成果参展。有关参展事宜，请与澳门环境保护局联络，也可浏览大会网页www.macaomiecf.com查询相关资料。

联系人：澳门特区环境保护局　冯女士

电邮：mhvong@dspa.gov.mo

科学技术部
