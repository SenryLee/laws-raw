# 农业部办公厅关于召开2012年种子执法年工作总结会的通知

## 农业部办公厅关于召开2012年种子执法年工作总结会的通知（农办种[2012]34号）

各省、自治区、直辖市农业（农村经济、农牧）厅（委、局），新疆生产建设兵团农业局，黑龙江省农垦总局，国家南繁工作领导小组办公室：

为总结交流2012年种子执法年工作，研究部署2013年种子执法监管工作重点，我部定于12月上旬召开种子执法年工作总结会，现将有关事宜通知如下：

**一、**会议内容

（一）总结2012年种子执法年工作情况，交流2013年工作重点；

（二）部署2013年种子执法监管工作；

（三）安排冬季种子企业监督抽查行动。

**二、**时间地点

（一）时间：12月4日报到，5日开会，会期一天；

（二）地点：北京河南大厦（北京市朝阳区潘家园华威里28号）。

**三、**参加人员

北京、河北、辽宁、江西、广东、四川等省（市）种子管理局（站）负责人及相关科室负责人，其他省（区、市）、新疆生产建设兵团种子管理总站、黑龙江省农垦总局种子管理局分管市场监管工作的局（站）长和相关科室负责人。

**四、**有关事宜

（一）请于12月3日前将参会人员回执单（见附件）发送至种子管理局市场监管处（邮箱：zzjscjgc@agri.gov.cn；传真：010-59193195）；

（二）会议不安排接送站，请参会人员自行前往；

（三）联系方式

种子管理局市场监管处　杜郁，电话：010-59193249；

河南大厦电话：010-67751188。
