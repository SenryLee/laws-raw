# 国家核安全局关于颁发2012年第二批民用核安全设备焊工焊接操作工资格证书的通知

## 国家核安全局关于颁发2012年第二批民用核安全设备焊工焊接操作工资格证书的通知（国核安发[2012]50号）

各相关聘用单位：

中国核工业二四建设有限公司等5家民用核安全设备焊工焊接操作工考核中心组织的焊工项目考试已经结束（考试编号见附件一）。根据《民用核安全设备焊工焊接操作工资格管理规定》（HAF603），我局组织有关单位进行了审查，现批准向中国核工业二四建设有限公司等10家聘用单位、马星等168位民用核安全设备焊工焊接操作工，颁发民用核安全设备焊工焊接操作工资格证书（见附件二），共计270项合格项目。
