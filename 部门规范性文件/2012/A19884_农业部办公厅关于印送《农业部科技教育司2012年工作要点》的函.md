# 农业部办公厅关于印送《农业部科技教育司2012年工作要点》的函

## 农业部办公厅关于印送《农业部科技教育司2012年工作要点》的函（农办科函[2012]34号）

各省、自治区、直辖市及计划单列市农业、农机、畜牧、兽医、农垦、乡镇企业、渔业厅（局、委、办），新疆生产建设兵团农业局，中国农业科学院、中国水产科学研究院、中国热带农业科学院，各省农科院，中央和地方部分农业大学：

为贯彻落实中央一号文件、中央农村工作会议和全国农业工作会议精神，深入推进农业科技促进年各项工作，按照农业部党组的工作部署和有关工作要求，经认真研究，提出《农业部科技教育司2012年工作要点》，现印送你们，请结合本地、本单位实际，加强衔接，共同推进提升农业科技创新与推广能力，为实现“两个千方百计、两个努力确保”目标任务做出新的贡献。

附件：农业部科技教育司2012年工作要点

二〇一二年三月一日

农业部科技教育司2012年工作要点

为贯彻落实党的十七大和十七届六中全会以及中央农村工作会议、全国农业工作会议、2012年中央一号文件精神，根据农业部党组的工作部署和科技教育司的职能要求，结合《农业部办公厅关于贯彻落实2012年农业农村经济工作重要举措分工的通知》（农办办〔2012〕1号）和《农业部关于印发〈全国农业科技促进年活动方案〉的通知》（农科教发[2012]2号）文件精神，2012年农业科教环能工作要以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，以促进农业发展方式转变为主线，全力组织实施全国农业科技促进年各项活动，以创新的精神和务实的作风推进农业科技体制机制创新，提高农业科技的保障能力、支撑能力和引领能力，加强资源环境保护和农村能源建设，为实现“两个千方百计、两个努力确保”目标任务做出新的贡献。

**一、**强力支撑增产增收

（一）继续开展科技大会战。组织全国100万名农业科技人员、农业企业及合作社技术人员、农业干部，进村、入户、到场、到田，实施全年全程科技服务，实现对农业大县、重点乡村全覆盖。组织专家和农技人员制订技术方案，组织科技人员参与高产创建，因地制宜遴选和推广主导品种、主推技术，筛选轻简实用、节本增效等田间管理技术。确保“县县有科教单位联络、基地有专家指导、村村有农技人员服务”，全面提高技术的入户率和到位率。加强农业科研、教学单位与粮食主产县的对接，每个县重点建设2-3个农业科技推广示范基地，使其成为科研与推广对接的展示基地、新品种新技术试验示范基地、农技人员和种植大户的培训基地。广泛开展农民科技培训和职业技能培训，提高农业从业人员素质。

（二）继续实施超级稻“双增一百”科技行动。在17个水稻主产省（区、市）全年推广超级稻1亿亩以上，实现亩增产100斤、节本增效100元的目标。在品种选育上，长江中下游稻区重点突破超级早、晚稻和粳稻品种的选育，同时选育适宜轻简种植的超级稻品种；长江上游稻区重点选育广适型超级一季稻品种；华南稻区重点选育抗病、广适型超级早、晚稻和适宜抛秧种植的超级稻品种；北方稻区重点选育早熟、耐寒与抗倒型超级粳稻。在技术创新上，探索新的选育方法和途径，创制出早熟、优质、广适、高配合力的不育系与恢复系，以及对低温钝感的两系不育系。在技术配套上，重点根据超级稻品种特点、不同生态区域条件和技术发展水平，分区域、分品种组装集成超级稻栽培技术体系。在示范推广上，进一步加强高产示范区建设，尤其是万亩示范片建设，加大技术培训、技术指导力度，切实提高技术的应用率和到位率。

（三）实施东北地区玉米“双增二百”科技行动。以栽培、种业、机械三大技术融合为技术保障，以干部、专家、技术员、农民（合作社）四方面力量为人力保障，整合现有科技资源和项目，在东北三省和内蒙东四盟（市）大力实施玉米“双增二百”科技行动，在具备条件的区域实现亩增产200斤，节本增效200元的目标。制订具体实施方案，将任务落实到县、责任落实到人。结合北方春耕，现场启动科技行动。组织专家分区域、分品种印发技术指导方案、田间技术操作手册、科普挂图和技术明白纸。组织测产和总结宣传工作。

（四）扩大农村劳动力阳光工程培训规模，提高补助标准。对种养大户，科技示范户，从事农业产前、产中和产后服务，以及从事农业经营和农村社会管理的农民开展职业技能培训，促进农业标准化、规模化发展，推动新农村建设。联合共青团中央，对在农业领域有创业意愿的农民，特别是农村初中高中毕业后未能升学的学生、复转军人，开展系统培训，促进农村劳动力创业就业。2012年阳光工程培训与全国粮棉油糖高产创建工作进行全面衔接，对实施区域内的从业农民和合作社成员开展专项技术培训，每方培训骨干农民200人。

**二、**大力推进自主创新

（一）继续组织实施转基因生物新品种培育重大专项。对转基因重大专项2009年立项重点课题进行财务验收和任务验收，系统总结研究成果。及时组织2012年课题承担单位签订合同，落实课题任务。按照专项“十二五”规划，统筹部署重大课题、重点课题和条件能力建设任务，发布申报指南，组织专家评审，编制经费预算，确定2013年立项计划。充分发挥转基因专项技术管理体系的作用，加强监督检查和评估工作。做好课题牵头单位生物安全监督检查工作。组织转基因重大专项相关科研教学单位及企业推荐2012年度“千人计划”人选，积极引进海外高水平人才。

（二）继续实施公益性行业（农业）科研专项。组织有关行业司局、地方农业部门围绕产业发展重大问题研究、补充和完善“十二五”行业科技重点项目计划。积极协调科技和财政部门，着重设立一批区域发展重大项目和农村能源、农产品加工、农业机械等产业共性技术项目。加大对186个在研行业科技项目监督检查力度，继续深入实施体系重大事项报告制度、信用评价制度、执行专家组集体决策制度、科技研发和经费使用月报制度等，会同财务司修订印发《公益性行业（农业）科研专项实施细则》。

（三）深入推进现代农业产业技术体系建设。全面实施体系“十二五”454项重点任务、950项产业基础平台数据库以及10000个现代农业产业技术示范基地建设任务。组织签订2012年度50个体系任务书、任务委托协议。探索建立现代农业产业技术体系与地方创新团队联合协作长效机制，推进地方创新团队的建设步伐，进一步形成贯通农业科研、成果转化与技术扩散的完整科技链条。积极推动体系内各学科间的联合协作，围绕重点任务开展联合研究，合力解决产业发展的关键技术问题，推动体系纵深发展。

（四）扎实推进按照“学科群”布局建设农业部重点实验室。强化机制建设，通过农业部重点实验室管理办法、学科群工作规则和重点实验室章程三个层次的制度建设，努力把分工协作、学术交流、资源共享和动态考核等核心机制落到实处。通过广泛交流和深入研究，凝练各学科领域的基础性、前沿性课题以及制约产业发展的关键共性技术问题。明确各学科群“十二五”的建设目标，查找差距，形成共识，千方百计争取条件，推动建设目标的实现。

（五）深入实施948计划。引进动植物、微生物种质资源及优良品种3000份，各类先进及实用技术150项，关键仪器设备80台（套）。派出400名专家赴国外学习考察或开展合作研究，请进300名专家开展农业技术交流与培训。遴选20项引进消化吸收再创新技术，加以推广应用。

（六）持续开展转基因科普宣传和监管工作。为转基因生物新品种培育重大专项实施创造良好的舆论环境，进一步拓展转基因宣传渠道和途径，让公众认清事实真相，理解政府决策，支持生物技术产业发展。扩大培训面，将培训对象扩展到所有研发单位，特别是承担转基因重大专项的单位。加强农业转基因生物安全管理，强化转基因生物研究试验和产品加工等重要环节的监管，保障生态环境安全和人体健康。加大产品标识监管力度，维护消费者的知情权和选择权。

**三、**深化体制机制创新

（一）进一步完善乡镇农业公共服务机构管理体制，全面实行人员聘用制度，推进各地切实提高基层农技人员待遇水平。对健全乡镇或区域性农技推广机构管理体制改革完成情况进行总结，对未完成改革任务的地方提出明确要求，并指导抓紧组织验收。强化基层农技推广机构的公益性定位，推动实行岗位管理，尽快制订下发基层农技推广机构岗位管理的指导意见，推行三方考评。积极争取财政和人事部门支持，督促地方抓紧落实有关政策，保障乡镇农技人员的工资待遇与当地事业单位人员的平均水平相衔接。

（二）推进乡镇农技推广机构条件建设项目实施，开展农技推广服务特岗计划试点。配合发展计划司争取国家发改委的支持，落实中央支持资金。督促地方落实配套资金。跟踪地方建设动态，做好情况调度，强化技术指导和服务。争取有关部门的支持，制定出台文件，落实项目资金，启动实施好农技推广服务特岗计划试点。

（三）推进基层农技推广体系改革与建设示范县项目基本覆盖农业县。组织遴选主导品种，集成主推技术，形成技术操作规范。实施农技推广责任制，组织农技人员包村联户，制定示范户技术指导方案，开展技术指导和培训工作。每个县围绕3-5个主导产业，遴选培育1000个具有一定文化程度、种养水平较高、乐于助人的农户作为科技示范户。按照10：1的比例选聘农业技术指导员指导科技示范户应用、推广新品种、新技术，提高科学种养水平。按照一业为主、多种示范的原则，每县重点建设2-3个试验示范基地。推动出台项目管理办法，建立科学的绩效评价机制，调动农技人员下乡服务的积极性。

（四）开展基层农技推广人员分层分类定期培训。在每个全国农技推广示范县，由各省统一编制分类别、分产业培训计划，分批次选派100名基层骨干农技人员，到国家或省级农业技术培训基地开展5天以上的集中培训。在有条件的地方探索跨省培训模式，进一步开阔基层农技人员眼界。充分利用“农业科技网络书屋”，组织农技人员加强学习，逐步提高业务能力。

（五）不断完善科研机制，深入推进部属“三院”改革。继续积极开展科研立项、评价及相关政策、机制研究，努力建设更加完善的立项、评价机制及大协作机制。组织部属“三院”开展调研，推进部属“三院”深化改革。加强与有关部门的沟通协调，跟踪事业单位分类改革，争取农业科研单位的公益性定位，落实有关保障政策。加强农业科研管理宏观政策调研。按照中央一号文件对于农业科研管理机制改革的要求和国家创新体系建设的总体部署，组织力量深入调查研究，提出完善农业科研管理机制的政策建议和工作措施。

**四、**加强农村能源建设和农业资源环境保护

（一）推进农村沼气建设。2012年新增沼气用户120万户，建设大中型沼气工程200处以上，继续加强沼气服务体系建设，完善沼气后续服务管理，着力提高沼气使用率和“三沼”利用率。按照“因地制宜、农户自愿、保证质量、强化服务”的原则稳步实施户用沼气项目，把资金安排与项目完成、使用情况挂钩；对农户相对集中的村庄，以农村居民为用气对象，支持建设以畜禽粪便或秸秆为原料的小型沼气，沼渣沼液用于还田；在具有稳定原料来源的规模化养殖场、养殖专业合作社或行政村等，建设以畜禽粪便或秸秆为原料的大中型沼气，中央投资主要支持向农户集中供气的大中型沼气项目；研究制定超大型沼气工程中央补贴标准，利用多种原料发展超大型沼气工程，鼓励高值利用。在河南、广西、江苏等省区整省启动大中型沼气工程先建后补试点，探索更加有效的项目管理方式。编制2012年农村沼气投资计划，与国家发改委联合发文下达，由各省农村能源主管部门负责组织实施。

（二）启动秸秆综合利用等重点工程和项目，深入推进生态农业和生态家园建设。按照《“十二五”农作物秸秆综合利用实施方案》，因地制宜启动秸秆“五料”为主要内容的秸秆综合利用示范项目，加快秸秆转化利用。实施农村沼气、农村清洁工程等项目，开展沼渣、沼液综合利用，推进农作物秸秆、人畜粪便、农村生活垃圾、生活污水等废弃物利用，改善农村生产生活环境，深入推进生态家园和生态农业建设。制定并颁布生态农业建设标准，引导和规范各地生态农业建设。开展沼渣、沼液综合利用调研，编制《全国沼肥综合利用规划》，争取把沼肥利用补贴纳入土壤有机质提升项目补贴范围，把沼肥设备购置纳入农机购置补贴范围。按照《绿色能源示范县建设技术管理暂行办法》的有关要求，做好绿色能源示范县实施方案技术审查、投资计划下达、技术服务专家咨询团等工作。

（三）推动中德沼气合作等国际合作交流。落实中德两国《关于加强农业合作的共同声明》有关内容，按照2011年“中德沼气合作战略研讨会”明确的思路，积极推动中德沼气合作。成立联合筹建小组，以部属有关科研和事业单位为依托，组织筹建中德沼气合作研发中心。与德方联合建设大型秸秆沼气集中供气、干发酵提纯罐装集中供气、大型车用沼气等示范工程，发挥不同技术、不同原料、不同用途工程的示范带动作用，示范工程纳入中央预算内沼气基本建设投资计划。筹备2012年秋季在我国举办的第31次中日农业科技交流工作组会议。继续推进国际马铃薯中心亚太中心的筹建工作。

（四）扎实推进农业环境污染防治。切实加强农产品产地环境保护，全面启动全国农产品产地土壤重金属污染防治工作。进一步组织编制完成《全国农业面源污染防治规划（送审稿）》。继续实施好“三河三湖”、三峡库区以及北方集约化农区等重点区域的农业面源污染定点监测，开展农业生态补偿试点，建立农业面源污染综合防治示范区。重点支持10个循环农业示范市开展农业清洁生产技术、节能减排技术和循环农业模式试点示范。会同有关部门启动实施农业清洁生产示范建设项目，先期在全国8省区开展废旧地膜回收利用、生猪清洁养殖、尾菜资源化利用等方面农业清洁生产示范建设。推进《中国应对气候变化国家方案》有关农业适应气候变化措施的落实，加强《气候变化公约》和《全球农业温室气体研究联盟》等有关国际公约或组织中有关农业履约的谈判工作。

（五）切实加强农业生物资源保护。加快实施《全国农业生物资源保护工程建设规划》，支持新建一批野生植物原生境保护区（点），启动农业生物资源监测及鉴定评价项目。继续开展重要野生植物资源调查、抢救性收集和动态监测，完善数据库。加快组织编制《国家重点防控外来入侵生物名录（第一批）》，力争年内颁布。继续开展主要危险性外来入侵生物的调查和监测预警，提出预警报告，完善控制预案。组织好外来入侵生物突发事件应急响应，开展重点外来入侵物种集中灭除，建立防治示范区，推行建设阻截带、天敌保育基地等综合防控措施。加强外来入侵生物防治技术研究与开发，建设开发利用示范基地。加强政策研究，组织制定《外来入侵物种管理办法》。继续做好《生物多样性公约》履约工作。

**五、**强化机关建设

（一）着力提高干部队伍素质。加强学习型司局建设，围绕中国特色社会主义理论体系、农业农村工作重点和农业科教环能工作的热点难点问题，加强学习，提高理论素养，营造良好学风。鼓励干部职工深入基层、进村入户开展工作调研，深入了解科技人员和广大农民的实际需求，为科学决策提供依据。积极参加农业部“百乡万户调查”活动，及时交流应用调研成果。积极参加农业部中青年干部学习论坛。立足农业科教行业特色和系统资源，创新“四季论坛”形式，组织开展院士、专家和青年学者专题讲座，开展农业科技知识学习系列活动，提高干部业务工作能力。

（二）深入开展创先争优活动。组织全国农业科教系统开展创先争优活动，围绕中心，服务大局，把创先争优要求落实到农业生产全年全程科技服务工作之中。结合全国农业科技促进年各项活动，组织开展送温暖科技服务活动。大力开展先进党支部、文明司局创建活动，落实党建工作要求，发挥好党支部的战斗堡垒作用。坚持党员领导干部民主生活会制度，加强党内监督。加强对干部职工的人文关怀，做好党员干部思想政治工作。发挥工会、共青团、妇委会的桥梁纽带作用，组织开展各种文体活动，增强干部职工身心健康。

（三）扎实推进党风廉政建设。落实中央和部党组关于党风廉政建设的有关要求，加强廉政教育，增强全司党员干部廉政意识。深入开展“廉政建设进课题下乡村活动”，通过完善工作制度，规范工作程序，增强工作透明度，强化实施监督，进一步加强农业科技项目选题、立项、实施、验收评估和农民培训、农村沼气建设、行政审批工作的监督管理，提高项目管理效能和资金使用效率，搞好行风政风建设，促进农业科教工作持续健康发展。

（四）强化机关作风建设。认真落实部党组关于加强作风建设、抓好工作落实的有关要求，引导全司干部把思想和工作统一到部党组的中心工作上，统一到支撑和促进农业发展方式转变上，统一到创新农业科技体系、形成强大科技合力上，服务大局抓落实。加强调查研究和制度建设，切实提高工作的准确性、时效性和科学性，确保每一项举措符合国情特色、产业特点和发展需求，科学严谨抓落实。弘扬求真务实精神，学透中央精神，掌握业务知识，善于发现和分析问题，提出及时、对路的政策建议和工作措施，务实高效，坚决服从和服务于大局，务实高效。坚决克服慵懒散现象，反对工作“低标准、慢半拍”，严肃处理不作为、乱作为等行为。大力提倡恪尽职守、锐意进取、攻坚克难、毫不懈怠的精神。

（五）全面加强农业科教工作宣传。完善农业科教工作新闻宣传和政务信息报送制度，建立长效工作机制。大力宣传全国农业科技促进年各项活动，充分利用主流媒体的引导作用，加强与网络媒体的协同配合，全面反映全国农业科教工作的最新进展、政策举措和经验做法。结合各地实际，积极宣传产业技术体系、转基因重大专项、公益性行业科研等进展成效，为构建新型农业科技创新体系创造条件。积极宣传基层农技推广体系、阳光工程、沼气工程、秸秆综合利用、农村清洁工程等工作的进展成效，为加快科技成果转化应用、推进现代农业建设和社会主义新农村建设营造良好的舆论氛围。
