# 国家煤矿安监局办公室关于召开中央企业煤矿安全生产工作座谈会的通知(2012)

## 国家煤矿安监局办公室关于召开中央企业煤矿安全生产工作座谈会的通知（煤安监司办〔2012〕25号）

各有关单位：

为进一步贯彻落实全国煤矿安全生产经验交流现场会精神，扎实推进安全生产领域“打非治违”专项行动，进一步提升中央企业煤矿安全生产水平，有效防范和坚决遏制重特大事故，促进全国煤矿安全生产形势持续稳定好转，国家煤矿安监局定于2012年8月31日在重庆市召开中央企业煤矿安全生产工作座谈会，会期1天。国家煤矿安监局领导同志将出席会议并讲话。现将有关事项通知如下：

**一、**会议主要内容

1.听取中央企业煤矿安全生产工作以及“打非治违”专项行动开展情况、隐患排查体系建设及信息化管理系统建设等情况汇报。

2.座谈分析今年以来中央企业煤矿安全生产形势，交流中央企业煤矿安全生产工作，安排部署下一步重点工作。

3.探讨加强中央企业煤矿安全监察监管工作的有效措施。

4.参观中国煤炭科工集团公司重庆研究院瓦斯灾害监控与应急技术国家重点实验室。

**二、**参加会议人员

1.有关中央企业集团总部分管煤矿安全生产工作负责人、煤矿安全生产管理部门主要负责人和生产技术负责人各1人。

2.山西省煤炭工业厅、内蒙古煤矿安全监察局主要负责人。

3.国家煤矿安监局机关各司室主要负责人。

邀请国务院国资委有关负责人出席会议。邀请中国安全生产报（中国煤炭报）和国家安全监管总局政府网站记者到会报道。

**三、**会议报到时间和会议地点

报到时间： 8月30日全天报到。

会议地点：重庆申基索菲特大酒店（地址：重庆市九龙坡区科园二路137号）。

**四、**其他事项

1.请各单位认真准备会议书面发言材料，并打印60份带至会场。

2.请各单位按要求派员出席会议，并于8月23日12：00前将会议代表回执（见附件）传真至国家煤矿安监局行管司。

3.8月30日全天在重庆机场和火车站安排接站。需要接站的代表，请在回执中注明所乘航班（或车次）和人数，并提前电话告知会务联系人。
