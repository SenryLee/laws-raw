# 住房和城乡建设部公告第1453号――关于2012年度第十四批绿色建筑评价标识项目的公告

## 住房和城乡建设部公告（第1453号）

关于2012年度第十四批绿色建筑评价标识项目的公告

根据《绿色建筑评价标识管理办法》（建科[2007]206号）、《绿色建筑评价标准》（GB/T50378-2006）、《绿色建筑评价技术细则》（建科[2007]205号）和《绿色建筑评价技术细则补充说明（规划设计部分）》（建科[2008]113号），我部组织开展了2012年度第十四批绿色建筑评价标识项目评价工作。经审定，威海望海名居（A1～A4、B1～B12号楼）等7个项目获得绿色建筑评价标识。

现予公布。

住房城乡建设部
