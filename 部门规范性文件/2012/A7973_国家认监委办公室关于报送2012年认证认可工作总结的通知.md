# 国家认监委办公室关于报送2012年认证认可工作总结的通知

各直属检验检疫局，各省、自治区、直辖市、新疆生产建设兵团质量技术监督局：

2012年，各地认证监管部门按照质检总局和认监委的工作部署，认真贯彻落实《质量发展纲要》，围绕“抓质量，保安全，促发展，强质检”工作方针和“五个创新”的总体要求，严格履行监管职责，扎实推进认证认可工作，切实发挥了认证认可“传递信任，服务发展”作用，为服务经济社会发展做出了新贡献。为了深入学习贯彻十八大精神，总结成绩经验，努力开创明年工作的新局面，请各局认真做好2012年度认证认可工作总结，及时报送总结材料。现将有关事项通知如下：

**一、**报送内容

围绕质检总局和认监委关于认证认可工作的部署要求，全面总结一年来的工作成效、经验、做法，深入分析存在的问题和薄弱环节，提出2013年认证认可工作思路，以及对于学习贯彻“十八大”精神、推进中国特色认证认可事业发展的思考与探索。

**二、**报送要求

总结材料要实事求是、突出重点、简明扼要，不超过5000字。材料中的数据，截至2012年12月10日。

请各单位于12月15日前将书面总结报送认监委办公室，同时报送电子版。
