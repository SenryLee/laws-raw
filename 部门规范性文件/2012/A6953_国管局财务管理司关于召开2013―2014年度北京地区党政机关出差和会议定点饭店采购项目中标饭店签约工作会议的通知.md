# 国管局财务管理司关于召开2013―2014年度北京地区党政机关出差和会议定点饭店采购项目中标饭店签约工作会议的通知

## 国管局财务管理司关于召开2013-2014年度北京地区党政机关出差和会议定点饭店采购项目中标饭店签约工作会议的通知

有关饭店：

为做好2013-2014年度北京地区党政机关出差和会议定点饭店（以下简称定点饭店）采购项目中标饭店（中标人）签约工作和后续管理工作，请各中标饭店准时参加定点饭店采购项目中标饭店签约工作会议。

会议时间：2012年12月26日（星期三）下午2：00

会议地点：中国职工之家C座1层百味和厅（西城区真武庙路1号，南礼士路地铁站西南口向西500米）

参会范围：本次新中标的饭店参加，续签饭店不必参加

参会人员：请每家饭店安排1名副总经理以上级别的负责人参加会议，可安排1名工作人员陪同，参会总人数不应超过2人
