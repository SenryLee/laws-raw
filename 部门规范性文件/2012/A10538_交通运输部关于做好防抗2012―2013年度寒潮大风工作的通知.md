# 交通运输部关于做好防抗2012―2013年度寒潮大风工作的通知

## 交通运输部关于做好防抗2012-2013年度寒潮大风工作的通知（交应急明电〔2012〕0935号）

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、 委），天漳市市政公路管理局，天津、上海市交通运输和港口管理局，各省级海（水）上搜救中心，长江、珠江航务管理局， 各直属海事局、救助局、打捞局：

冬季即将来临，寒潮和强冷空气将陆续影响我国沿海和内陆地区，由此带来的大风、低溫雨雪冰冻恶劣天气等自然灾害 对公路运输.海上船舶航行与作业、交通建设施工和港口生产将产生不同程度的影响.为做好2012-2013年度寒潮大风的防 抗工作，最大限度地减少和避免各类交通运输和交通建设施工事故的发生，确保交通运输行业安全形势的稳定，为人民群众 提供安全、畅通、便捷的交通运输服务，现将有关事项通知如下：

**一、**提高认识，加强组织领导。

各单位要深刻领会、认真贯彻落实国发〔2012〕30号文件精抻和8月28日国务院安委会召开的交通安全紧急电视电话会议精神，按照交通运输部9月18日召开的全国交通运输安全电视电话会议的工作部署，进一步提高认识，加强组织领导，以更加务实的态度、更加严格的管理、更加有力的措施、更加完善的制度，把防抗寒潮大风工作作为冬季安全工作的重点，坚持不懈地抓好安全生产工作，坚决遏制重特大事故发生，确保交通运输安全形势持续好转，为十八大的胜利召开创造安全、畅通、稳定的交通运输环境。

**二、**高度重视寒潮大风天气的预防预警工作。

各单位要按照《交通部防抗台风等极端天气应急预案》要求，加强与气象、海洋等部门的协间SL合，进一步完善寒湖大风等极埔天气预防、 预警机制。利用各种手段，及时获取、有效发布极端天气预警信息和道路通行情况信息，为公众出行和船舶航行、汽车行驶、 交通建设施工作业提供预防预警信息保障。

**三、**切实强化安全管理，落实各项防范措施。

各单位要牢固树立安全意识，强化安全管理，落实安全措施，切实地履行好安全监管职责，督促企业和生产经营者落实安全生产主体责任。遇有大风、低温雨雪冰冻等恶劣天气时，各级公路和道路运输主管部门要加强公路巡查和执勤，加大对长途客运和危险品运输的安全管理，采取各种有效措施，最大限度地减少各类安全隐患，保证道路畅通、运输安全；各级海（水）上搜救中心和各应急管理部门要加强应急值守，实行领导带班，充分做好应对各种突发事件的准备；各级海事部门、搜救中心要强化水上客货运输和渡运的安全管理，继续把"四客一危"运输船舶和"四区一线"水域作为重点，加强隐患排査和整治，同时协助渔业部门做好渔船防抗寒潮大风的工作；各级港口管理机构要重点强化对港区危化品的安全监管职责，制定和宪善大风、低溫雨雪冰冻等恶劣天气下的危化品运输预警和应急保障机制；各救助局、救助飞行队要提前做好防抗寒潮大风的各项准备工作，加强值班待命，确保险情得到及时有效救助。

**四、**深入总结分析，做好防抗寒潮大风的信患上报工作。

各单位要妥善处理寒潮大风引起的各类突发事件，发生重、特大事故要及时总结上报。年度防抗寒湖大风工作结束后，认其分析，总结经验，汲取教训，进一步完善防抗寒湖大风工作的长效管理机制。

2012年9月26日
