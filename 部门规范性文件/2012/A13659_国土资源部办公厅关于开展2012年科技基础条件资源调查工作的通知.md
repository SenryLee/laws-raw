# 国土资源部办公厅关于开展2012年科技基础条件资源调查工作的通知

## 国土资源部办公厅关于开展2012年科技基础条件资源调查工作的通知（国土资厅函〔2012〕654号）

各有关单位：

按照科技部、财政部《关于开展2012年科技基础条件资源调查工作的通知》（国科发计〔2012〕706号）要求，部将组织开展2012年科技基础条件资源调查工作（以下简称“科技资源调查”）。现将有关事项通知如下：

**一、**科技资源调查的主要内容

科技资源调查的主要内容包括以下2方面：

1．法人单位情况调查。重点调查法人单位的机构概况和各类科技条件资源（人、财、物等）拥有情况，包括科研仪器设备概况、大型科学仪器设备基本信息、人员概况、高层次科技人员基本信息和财务概况（见附件3-表1）、公益类科研机构改革与发展情况（见附件3-表3）。原值在50万元以上的单台或成套科学仪器设备，应逐一填报大型科学仪器设备基本信息。

2．研究实验基地情况调查。重点调查研究试验基地的机构概况及科研仪器设备、人员、财务等情况（见附件3-表2）。调查所称科研基地专指经各级政府部门批准并依托法人单位建立或设立的从事各类科技活动的机构，包括重点实验室、工程中心、分析测试中心、大型科研设施、野外台站等。一个法人单位有多个研究试验基地的，应逐一填报研究试验基地基本信息。

调查的标准时点为2011年12月31日，时期资料为2011年度。

**二、**科技资源调查的对象

按照科技部、财政部相关要求，调查对象分2部分。

1．科研院所。自2008年以来一直参加科技资源调查的部属23家科研院所（名单见附件1），填报法人单位情况、研究试验基地情况、改革与发展情况。

2．研究试验基地。部系统国家重点实验室、工程技术中心等研究试验基地；部级重点实验室、质量监督检测中心、野外科学研究观测基地等（名单见附件2），只填报研究试验基地情况。

**三、**调查工作安排

调查工作由部科技合作司、财务司共同组织，中国地质调查局协助组织所属科研院所的调查工作，中国地质科学院承担具体调查工作，部信息中心协助更新科技基础条件资源数据库。调查工作安排如下：

1．科研院所调查工作安排：（1）调查单位通过“国家科技基础条件资源调查管理信息系统”（www.nstic.gov.cn或www.escience.gov.cn）网上在线填报、审核和上报数据。（2）部对各单位填报的数据进行网上审核。（3）各单位打印通过部审核的《国家重点科技基础条件资源调查汇总表》、《研究试验基地基本信息汇总表》、《公益类科研机构改革与发展情况调查表》，于2012年8月20日前加盖单位公章一式3份报部科技合作司。（4）部统一汇交科技部、财政部。已参加调查的单位沿用已有的用户名和密码，登录系统并按照流程进行数据更新。

2．研究试验基地调查工作安排：调查单位从“国土资源部网站（www.mlr.gov.cn）-科技管理”下载并填报“研究试验基地情况调查表”，经依托单位审核加盖公章后，于2012年8月20日前一式2份报部科技合作司，同时通过光盘报送电子版1份。

依托科研院所建设的研究试验基地统一通过国家科技基础条件资源调查网站填报数据。
