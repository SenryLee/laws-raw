# 国务院国有资产监督管理委员会关于开展“在管理提升活动中创先争优”主题党日活动的通知

各厅局、直属单位、直管协会、部分京外企业在京单位党委（总支、支部）：

在中国共产党成立91周年之际，为进一步激发直属机关各级党组织生机活力，引导广大党员认真履行职责、争创一流业绩，推动直属机关党的建设更好地服务国资委中心工作，经研究，决定在直属机关范围内，结合正在开展的机关管理提升活动，组织开展一次“在管理提升活动中创先争优”主题党日活动。现结合国资委直属机关实际，就开展主题党日活动有关事项通知如下：

**一、**活动主题

以“在管理提升活动中创先争优”为主题，组织广大党员围绕我委管理提升活动方案，总结梳理日常工作中取得的成绩、经验和存在的问题，引导党员干部带头自查自摆、走访调研、征求意见，在全面深入查找日常管理中的不足之处与薄弱环节的同时，查找党建工作体制机制、制度措施、队伍素质等方面存在的不足之处和薄弱环节，理清工作重点和工作思路，制定具体举措，切实改进提高，并建立长效机制。

**二、**活动内容和方式

（一）主题党日活动以各基层党组织为主，根据本厅局、本单位的实际情况，组织广大党员认真学习王勇同志在委机关管理提升活动动员会上的讲话、黄丹华同志在委机关局处级干部管理提升培训班上的动员讲话和国资委机关管理提升活动工作方案，深刻领会开展管理提升活动的必要性、指导思想和工作原则，准确把握开展管理提升活动的总体目标、重点工作和阶段性工作安排，自觉按照国资委党委开展管理提升活动的要求，扎实做好各项工作。

（二）主题党日活动可采取专题组织生活会、调研考察等形式，请进来、走出去，学习借鉴中央企业或其他部委机关的先进经验和有效做法，促进自身工作效能和服务质量的提升，塑造机关良好形象。

（三）主题党日活动要与直属机关基层组织建设年活动有机衔接起来，总结基层党组织加强组织建设、健全体制机制、充分发挥作用的典型经验，形成学习先进、崇尚先进、争当先进的热潮，以实际行动和优异成绩迎接党的十八大胜利召开。

（四）直属机关党委将于近期按每位党员200元的标准向直属党支部（总支）返还党费，供各基层党组织开展活动使用（具体数额见附件）。经济出版社、研究中心、管理局系统、各直管协会、京外企业在京单位党委可根据实际情况参照执行。

**三、**工作要求

各基层党组织要把开展主题党日活动与落实委机关管理提升活动第一阶段、第二阶段的工作任务结合起来，坚持以基层党支部为重点，以党员为主体，充分发挥党支部书记第一责任人的作用，保证每一个党支部和绝大多数党员都能参与到主题党日活动中来。

要注意发现、收集、宣传好经验、好做法，通过网络、报刊等载体，加强宣传，形成良好氛围。直属机关党委将以网络、宣传展板等形式报道主题党日活动的有关情况。请各基层党组织于7月15日前将组织开展主题党日活动情况（400-500字，并附照片3-4张）报直属机关党委。联系人：苏明扬、赵玮；电话：63193950、63193731；传真：63193795；邮箱：zuzhi-dw＠sasac.gov.cn。
