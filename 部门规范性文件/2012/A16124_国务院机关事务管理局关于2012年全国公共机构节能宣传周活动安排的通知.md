# 国务院机关事务管理局关于2012年全国公共机构节能宣传周活动安排的通知

## 国务院机关事务管理局关于2012年全国公共机构节能宣传周活动安排的通知（国管节能〔2012〕125号）

各省、自治区、直辖市和新疆生产建设兵团机关事务管理局，北京市、贵州省、西藏自治区发展改革委、广东省经信委、青海省经委，中央国家机关各部门、各单位：

为贯彻落实发展改革委等17部委《关于印发节能减排全民行动实施方案的通知》（发改环资〔2012〕194号），深入推动公共机构节能工作，定于6月11日至17日开展2012年全国公共机构节能宣传周活动。现就活动安排通知如下：

**一、**活动主题

今年全国公共机构节能宣传周的主题是“珍惜生命之源，人人节水护水”。当前，我国水资源面临的形势十分严峻，水资源短缺、水污染严重、水生态环境恶化等问题日益突出，已成为制约经济社会可持续发展的主要瓶颈之一。公共机构节能作为全社会节能减排的重点领域，率先做好工作，发挥示范作用，对于引领全社会节水护水具有重要意义。

**二、**主要内容

（一）各级公共机构组织以下活动：

1.开展形式多样的主题日活动。6月11日为2012年公共机构节能宣传周主题活动日。各地区、各部门通过组织开展节水形势报告会、节约用水大家行、节水新技术新产品推介等丰富多彩、形式多样的活动，深入开展水资源国情教育，普及节水知识技术，营造珍惜爱护水资源、公共机构做表率的良好氛围。

2.开展能源紧缺体验活动。各级公共机构通过停开空调和公共区域照明、停开或隔层停开电梯等方式进行能源紧缺体验。公共机构工作人员践行“135”出行方案（即1公里内步行，3公里内骑自行车，5公里内乘坐公共交通工具），以绿色低碳的出行方式支持节能减排。

3.开展废旧商品回收利用宣传活动。各级公共机构采取再生产品展览展示、以旧（废）换新、知识宣讲等形式，组织开展废旧商品回收利用宣传活动。积极宣传“资源有限、再生无限”的理念，引导干部职工形成绿色环保、循环利用的办公和生活方式。

4.开展“科技助力公共机构节能”科普巡展活动。国管局与中国科协联合开展以“科技助力公共机构节能”为主题的全国公共机构科普巡展活动，制作电子刊物在公共机构节能网上进行网络展示，并印发《巡展特刊》。

5.制作印发节能宣传画。国管局与中央美术学院设计制作节能宣传画，向中央国家机关发放，各地区公共机构节能管理部门登录公共机构节能网下载印发。各级公共机构要在办公区、公共场所及职工住宅区张贴宣传画。

（二）国管局组织中央国家机关等单位开展以下活动：

1.举办首都水形势报告会。会同中直管理局举办首都水形势报告会，开展国情水情教育，宣讲首都水资源现状以及面临形势，引导广大干部职工践行节水理念。

2.召开节约型办公区建设试点项目现场会。在住房城乡建设部召开节约型办公区建设试点项目现场会，介绍节约型办公区建设进展情况，展示太阳能光伏发电、雨水收集和中水处理系统、餐厨垃圾利用等示范项目节能效果，加快推动中央国家机关节约型办公区建设。

3.组织创建节约型校园、节约型医院宣传活动。分别与教育部、卫生部联合举办创建节约型校园、节约型医院宣传活动，倡导全国高校师生和广大医务工作者广泛参与节能节水实践，努力建设节约型校园和节约型医院。

**三、**有关要求

各级公共机构节能管理部门要加强组织协调，利用电视、广播、报刊、网络等媒体，广泛宣传公共机构节能工作进展和取得的成效，推动全社会节能减排深入开展。节能宣传周活动结束后，各地区、各部门要认真总结活动情况，于6月30日前将图片资料及总结材料电子版发送到公共机构节能管理司的公务邮箱jns@ggj.gov.cn。
