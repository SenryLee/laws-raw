# 住房和城乡建设部建筑节能与科技司关于举办绿色建筑评价标识专家培训会的通知(建科综函[2012]191号)

## 住房和城乡建设部建筑节能与科技司关于举办绿色建筑评价标识专家培训会的通知（建科综函[2012]191号）

各有关省、自治区住房城乡建设厅，直辖市、计划单列市建委（建设局），新疆生产建设兵团建设局：

为使绿色建筑评价标识专家委员会成员深入理解准确把握《绿色建筑评价标准》和相关技术要求，统一绿色建筑评价尺度，推进各地一二星级绿色建筑评价标识工作健康开展，根据《2012年住房和城乡建设部机关培训计划》安排，定于2012年10月28日至29日，在天津举办培训会，经培训且考试合格的专家方可参与绿色建筑评价标识的评审工作。现将有关事项通知如下：

**一、**培训内容

1、详细讲解《绿色建筑评价标准》及评价技术细则

2、分析绿色建筑案例

3、分析项目申报和评审要点

**二、**培训对象

从事绿色建筑标识评价、开发、设计、咨询、管理等与绿色建筑相关的人员。

**三、**培训时间和地点

培训时间：2012年10月28日至29日，10月27日全天报到。

报到地点：天津鑫茂天财酒店（天津市华苑新技术产业园区榕苑路1号）

**四、**培训费用

培训费1000元/人（含教材等费用），食宿费用自理。

**五、**联系人

**六、**其它事项

1、培训会由我司主办，天津市城乡建设和交通委员会具体承办。

2、对考试合格者将颁发住房城乡建设部继续教育证书，请参加培训的专家自带一寸彩色照片两张。

3、请各省、自治区住房城乡建设厅，直辖市、计划单列市建委（建交委、建设局）统一组织参加培训的专家与会，并将参会回执（见附件）于2012年10月20日前传真或发电子邮件至天津市城乡建设和交通委员会。
