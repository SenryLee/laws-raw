# 商务部财务司关于填报2012年度会议费管理和使用具体情况调查表等材料的通知

三类会议是指商务部及其所属内设机构召开的，要求省、自治区、直辖市、计划单列市有关厅（局）或本系统在各地机构有关人员参加的会议。
