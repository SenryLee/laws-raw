# 国家文物局关于开展“数字博物馆元数据规范研究”课题申报工作的通知

## 国家文物局关于开展“数字博物馆元数据规范研究”课题申报工作的通知（办博函〔2012〕560号）

各有关单位：

为贯彻落实《国家文物保护科学和技术发展“十二五”规划（2011-2015年）》，稳步推进我国数字博物馆建设，根据2012年度文化遗产保护科学和技术研究重点课题计划，我局决定组织实施“数字博物馆元数据规范研究”课题。根据《文物保护科学和技术研究课题管理办法》及相关规定，将采取公开申报、专家评审、择优委托的方式确定课题承担单位与负责人。现将有关事项通知如下：

**一、**课题申报要求

（一）课题负责人应具有中华人民共和国国籍，年龄在60岁以下，副高级以上职称，具有较高的学术水平、优秀的科研业绩和开拓创新能力，具有较强的组织协调能力，无不良科研行为，从事博物馆信息化相关研究或技术开发3年以上，且具有博物馆或其相关领域元数据规范研究经验。

（二）课题负责人用于本课题研究时间不少于本人工作时间的60%。

（三）课题申报单位认真阅读课题申报指南（详见附件），填写《文化遗产保护领域科学和技术研究课题申请书》（申请书请登陆文化遗产保护科技平台下载，网址kj.sach.gov.cn或www.chst.cn）。

（四）课题申报起止日期为2012年6月21日-7月10日。课题申报时需提交书面申请材料一式7份和电子文档。书面文件请采用A4纸印刷，普通纸质材料作为封面，不采用胶圈、文件夹等带有突出棱边的装订方式。

**二、**申报受理方式

国家文物局科研课题管理办公室（以下简称课题办）负责课题的申报受理工作。

课题申报单位务必于2012年7月10日前将申报材料寄至课题办（以邮戳时间为准）；电子文档于7月10日16：00前发送至ktb@sach.gov.cn。逾期将不予受理。

“数字博物馆元数据规范研究”课题申报指南

**一、**指南说明

随着网络与信息技术的发展，近年来全国各地博物馆数字化建设进展迅速，数字博物馆日益受到各方面的关注。建立科学合理的元数据规范是加强数字博物馆数字资源管理、开发与利用的基础，元数据规范的通用性、开放性与标准化对于数字博物馆的长远可持续发展至关重要。

数字博物馆元数据是用来描述数字博物馆数字资源内容、结构及背景特征的数据，具有：著录功能，描述藏品信息的内容、结构及背景特征；检索功能，提供方便快捷、多层次、多途径的检索体系；选择功能，支持用户在不浏览藏品本体的情况下，对藏品有基本了解并进行选择；定位功能，提供藏品本体及其信息资源所在位置；管理功能，保存藏品日常使用、管理方面的信息，便于藏品的数字化和网络化管理。

数字博物馆元数据规范研究将对博物馆藏品数字资源进行组织、管理、发现、识别、选择、定位、开发、利用和评价，追踪藏品在博物馆管理和使用过程中的变化，有助于实现藏品数字资源的虚拟展现、集成整合与长期保存，进一步规范我国数字博物馆系统建设，形成网络化、标准化和国际化的数字博物馆体系。

**二、**研究内容

（一）调研国内外相关元数据规范研究与应用现状

调研与数字博物馆相关并在国内外研究与应用较广泛的几类元数据规范：都柏林核心元素集（Dublin Core Element Set，简称DC）、艺术作品描述类目（CDWA）、编码文档描述（EAD）、VRA核心类目（VRA core）、FGDC、GILS，以及基于本体的概念参考模型CIDOC CRM、开放档案信息系统参考模型OAIS（Open Archival Information System）和FRBR模型。结合国家文物局制订的《馆藏文物信息指标体系规范》以及国内部分博物馆和相关机构关于藏品信息指标体系研究和应用现状进行深入研究，形成调研报告。

（二）研究基于空间信息的数字博物馆元数据规范体系

以传统的数字博物馆元数据规范研究为基础，引入空间地理信息描述手段，参考国内外较有影响的FGDC《数字地理元数据内容标准》（CSDGM）、ISO/TC211元数据体系和ISO15046-15《地理信息-元数据》国际标准工作草案，以及中国可持续发展信息共享元数据标准、NFGIS和NSII元数据规范等，研究能处理与空间地理数据相关的数字博物馆数字资源的元数据规范框架；根据该框架，研究数字博物馆核心元数据规范、专门元数据构成和元数据扩展规则，以及对应的数字博物馆元数据管理系统和元数据著录系统，形成完整的数字博物馆元数据规范体系。

（三）研究数字博物馆核心元数据规范、专门元数据构成和元数据扩展规则

研究数字博物馆数字资源通用的描述元素和规范，给出完整的数字博物馆核心元数据规范，用以描述数字博物馆数字资源的核心内容属性、管理属性和形式属性，为数字博物馆数字资源的检索、整合、交换及其它应用提供支持。分析现有数字博物馆数字资源的专业分类特征，研究提出数字博物馆专门元数据基本构成，以及针对不同类型的数字博物馆数字资源给出相应的元数据描述方法。选择两类有代表意义的可移动文物和两类不可移动文物示范，研究形成数字博物馆专门元数据规范。根据数字博物馆的实际需求变化，提出数字博物馆元数据扩展规则和实现方法，指导用户对数字博物馆元数据元素进行个性化定制。

（四）研究提出数字博物馆元数据管理与元数据著录系统建设需求

研究数字博物馆元数据管理与元数据著录系统的基本架构和功能设计要求，实现对数字博物馆元数据著录、元数据浏览以及相关编码体系等的管理。

**三、**成果与考核指标

（一）完成国内外数字博物馆元数据规范现状调研，形成调研报告；

（二）完成我国数字博物馆元数据规范体系及其核心元数据、专门元数据构成和扩展元数据研究，形成数字博物馆元数据规范研究报告；

（三）完成数字博物馆核心元数据规范研究，形成数字博物馆核心元数据规范；

（四）完成数字博物馆专门元数据规范构成研究。选择两类可移动文物和两类不可移动文物作为示范，分别起草数字博物馆专门元数据规范；

（五）完成数字博物馆元数据扩展方法及其应用研究，形成数字博物馆元数据扩展原则与应用指南；

（六）研究提出数字博物馆元数据管理系统和元数据著录系统基本建设需求。
