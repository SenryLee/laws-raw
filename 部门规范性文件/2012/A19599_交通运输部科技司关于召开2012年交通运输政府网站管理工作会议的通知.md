# 交通运输部科技司关于召开2012年交通运输政府网站管理工作会议的通知

## 交通运输部科技司关于召开2012年交通运输政府网站管理工作会议的通知（科技信息函[2012]59号）

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），天津市、上海市交通运输和港口管理局，天津市市政公路管理局，部海事局、救捞局，长江、珠江航务管理局，中国船级社，工程质量监督局，职业资格中心，各直属海事机构，部机关各司局：

为贯彻落实全国交通运输工作会议与全国交通运输信息化工作会议精神，进一步加强交通运输部门政府网站建设和管理工作，提升交通运输行业政府网站管理和服务水平，现定于3月29日在云南省昆明市召开2012年交通运输政府网站管理工作会议，有关事宜通知如下：

**一、**会议内容

总结2011年交通运输政府网站建设发展情况，研究部署2012年网站管理工作，分析政府网站绩效评估和网站共建考评结果，表彰2011年度部政府网站共建工作先进单位和先进个人、优秀行业政府网站等，交流网站建设管理经验，邀请有关网站建设专家、优秀政府网站主管领导做专题报告等（详见附件1）。

**二、**参加人员

各单位网站主管部门领导和部政府网站共建工作信息保障联络员各1名。

**三、**时间及地点

时间：3月28日报到，3月29日至30日开会，会期1天半。

地点：云南省昆明市佳路达酒店（环城南路266号）。

本次会议会务工作委托云南省交通运输厅承担。会议代表住宿统一安排，交通、食宿费用自理。为做好会议接机（站）工作，请各单位将参会回执表（见附件2）于3月13日前传真至云南省交通运输厅信息中心。
