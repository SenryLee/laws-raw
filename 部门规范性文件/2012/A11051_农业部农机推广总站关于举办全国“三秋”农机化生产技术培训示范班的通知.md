# 农业部农机推广总站关于举办全国“三秋”农机化生产技术培训示范班的通知

各有关省（区、市）农机管理局、农机推广站：

“三秋”生产在即，为深入开展“全国农机化科技创新与推广行动”，扎实做好“三秋”农机化技术推广工作，推进农机化生产，受农业部农业机械化管理司委托，我站定于9月下旬在内蒙古举办全国“三秋”农机化生产技术培训示范班。现将有关事项通知如下：

**一、**培训内容

（一）玉米机械化收获技术；

（二）农机农艺融合思路与措施；

（三）饲草料机械化收获加工技术；

（四）部署“三秋”农机化技术推广工作；

（五）参观玉米与饲料收获加工机械展示演示现场。

**二、**时间地点

时间： 9月20～21日，9月20日报到

地点：包头市兰亭酒店（内蒙古包头市稀土高新区创业园内稀土大厦东50米，0472-6961888）

**三、**参加人员

（一）北京、天津、河北、山西、辽宁、吉林、黑龙江、山东、河南、陕西、甘肃、青海、宁夏、新疆等省（区、市）农机局或农机推广站负责技术推广的人员1人。

（二）内蒙古自治区玉米主产盟（市）旗 （县）农机局、推广站分管领导，农机（粮食生产）专业合作社等服务组织的技术人员。

**四、**有关事项

（一）报到当天，包头市火车站、机场全天接站。

（二）为便于安排住宿与接站，请各省参加培训的人员于9月17日前将报名回执（见附件）发送传真至0471-4300269，或电子邮件至nmnjwz@126.com。
