# 农业部关于核发2012年度第三批农业部远洋渔业企业资格证书的通知

## 农业部关于核发2012年度第三批农业部远洋渔业企业资格证书的通知（农渔发[2012]9号）

宁波市海洋与渔业局：

根据《远洋渔业管理规定》，我部同意授予宁波欧亚远洋渔业有限公司2012年度农业部远洋渔业企业资格（第三批），并核发《农业部远洋渔业企业资格证书》。请你局收到上述《农业部远洋渔业企业资格证书》后，及时发放到有关远洋渔业企业。

特此通知。

2012年3月23日
