# 农业部办公厅关于举办全国农垦现代农业示范区建设培训班暨水稻智能化育秧观摩活动的通知

## 农业部办公厅关于举办全国农垦现代农业示范区建设培训班暨水稻智能化育秧观摩活动的通知（农办垦[2012]32号）

各省、自治区、直辖市农垦主管部门，新疆生产建设兵团农业局：

为加快推进农垦现代农业建设，进一步发挥示范带动作用，按照《农垦现代农业示范提升活动方案》（农办垦［2012］23号）的要求，我部决定于5月上旬在黑龙江垦区开展全国农垦现代农业示范区建设培训暨水稻智能化育秧观摩活动。现将有关事项通知如下：

**一、**培训内容

一是专家讲座，包括现代农业建设和现代农业示范区创建、现代农业产业体系建设和发展、农业标准化生产和管理、信息化技术在现代农业建设中的应用、水稻智能化育秧和全程机械化生产等专题；二是农垦现代农业示范区创建经验交流；三是部署农垦现代农业示范提升工作；四是参观现代农业示范区和水稻智能化育秧现场。

**二、**参加人员

各省（自治区、直辖市）农垦主管部门、新疆生产建设兵团农业局、100个全国农垦现代农业示范区负责同志各1人，请按分配名额（附件1）确定参加培训人员，严禁超员。

**三、**时间地点

2012年5月7日报到，5月8日-10日培训。地点在黑龙江垦区建三江管理局七星宾馆，总机：（0454）5791350。

**四、**有关要求

（一）准备交流材料。请安徽农垦事业管理局、黑龙江省农垦总局建三江管理局、广东农垦湛江分局、江苏农垦新洋农场和甘肃农垦黄羊河农场准备交流材料。主要内容包括现代农业和现代农业示范区建设成效、主要经验以及下一步现代农业示范提升的思路、目标和具体措施，形成书面材料，字数在3000字以内，于4月20日前将电子文档发送到农业部农垦局农业处电子邮箱（nkjnych@agri.gov.cn）。

（二）做好报名工作。请各省（自治区、直辖市）农垦主管部门通知并组织本垦区现代农业示范区单位参加培训活动，填写报名回执表（附件2），统一汇总后于4月30日前分别传真至农业部农垦局农业处和黑龙江省农垦总局农业局。

（三）接送站安排。培训班人员在黑龙江省佳木斯市进行中转，5月7日全天在佳木斯飞机场和火车站接站，统一在佳木斯市农垦宾馆集中后送至建三江；5月10日下午由建三江统一送至佳木斯市。各省参加培训同志可购飞机票或火车票到佳木斯市。7日之前或10日之后需要在佳木斯市停留的，可住在佳木斯市农垦宾馆，总机：（0454）8192822。

（四）培训期间免收培训、资料费和食宿费；交通费和中转期间食宿费自理。
