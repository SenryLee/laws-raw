# 国家测绘地理信息局法规与行业管理司关于报送2012年测绘地理信息行政执法工作总结的通知

## 国家测绘地理信息局法规与行业管理司关于报送2012年测绘地理信息行政执法工作总结的通知（测管函〔2012〕68号）

各省、自治区、直辖市测绘地理信息行政主管部门：

2012年，国家局先后印发了《关于做好2012年测绘地理信息行政执法工作的通知》（国测法发〔2012〕1号）（以下简称《通知》）和《关于加强测绘地理信息行政执法工作的意见》（国测法发〔2012〕4号）（以下简称《意见》），对贯彻落实《意见》和做好2012年测绘地理信息行政执法工作进行了全面部署。为全面了解掌握各地贯彻落实《通知》和《意见》情况，加强对测绘地理信息行政执法工作的监督指导，进一步做好各地行政执法在贯彻落实科学发展观年度考评中的考核工作，各级测绘地理信息行政主管部门要对2012年测绘地理信息行政执法工作进行全面总结，深入分析存在的问题，提出进一步加强测绘地理信息行政执法工作的意见或建议。

现就报送2012年测绘地理信息行政执法工作总结及有关材料事宜通知如下：

**一、**各级测绘地理信息行政主管部门组织开展测绘地理信息行政执法依据梳理和执法职权分解工作情况。省级测绘地理信息行政主管部门在督促、检查、考核市、县分解测绘地理信息行政执法职权和落实执法职责方面所采取的有效措施。

**二、**各级测绘地理信息行政主管部门机构建设情况，如何抓住增设机构、机构更名等机遇与当地政府和有关部门沟通协调，解决机构设置、执法人员编制、执法经费、执法装备等行政执法工作中的突出问题。为全面了解掌握执法机构、编制、岗位设置等情况，请省级测绘地理信息行政主管部门组织好《测绘地理信息行政管理机构统计表》（附件1）的填写工作。

**三、**各级测绘地理信息行政主管部门与有关部门建立执法协作工作机制以及开展测绘地理信息市场专项检查、查处测绘违法案件情况。请省级测绘行政主管部门组织好《测绘行政执法情况统计表》（附件2）的填写工作，并将2012年审结的所有测绘地理信息行政处罚案件备案材料一并报我司执法监督处。

参照历年十大典型案件通报的体例，请选取2－3个典型案例编写成通报材料，与备案材料一并提交我司。我司将从中选出2012年度十大测绘地理信息违法典型案例并予以通报。

**四、**各级测绘地理信息行政主管部门组织学习、宣传、贯彻《意见》情况，配合国家局做好行政处罚案卷评查、执法人员培训、开展测绘法宣传日活动等情况。

以上各项材料请于2012年11月25日前以书面形式报送我司，并同时报送电子版（电子信箱：zhifa@sbsm.gov.cn）。
