# 农业部办公厅关于做好《中国畜牧业年鉴》2012卷有关工作的通知

## 农业部办公厅关于做好《中国畜牧业年鉴》2012卷有关工作的通知（农办牧[2012]21号）

各省、自治区、直辖市、计划单列市畜牧兽医（农牧、农业）厅（局、委、办）、饲料工作（工业）办公室，新疆生产建设兵团畜牧兽医局，中国畜牧业协会：

《中国畜牧业年鉴》（以下简称《年鉴》）是全面反映我国畜牧业生产和兽医事业年度发展情况的工具性资料书，是宣传畜牧业发展的政策措施、战略地位、法律法规和科学技术的重要窗口，是交流畜牧业信息的平台。2011年11月份，我部畜牧业司、兽医局在广西北海召开了《年鉴》特约编辑会议，专门研究了2012卷《年鉴》编撰大纲，会后征求了有关部门意见。现将《年鉴》编纂大纲印发给你们，请认真组织稿件的编写工作，于5月30日前将稿件及相关资料报送全国畜牧总站和中国农业出版社。

**一、**稿件要求

（一）“各地畜牧业”栏目，各省、自治区、直辖市的篇幅不宜超过8000字，计划单列市的篇幅不宜超过5000字。“大事记”栏目，各省、自治区、直辖市以记载10-20项大事为宜。

（二）年鉴稿件需附有每位撰稿人姓名与身份证号码（以单位名称署名的稿件也需提供撰稿人的上述信息）。
