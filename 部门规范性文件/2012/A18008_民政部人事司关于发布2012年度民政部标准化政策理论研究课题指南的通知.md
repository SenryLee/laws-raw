# 民政部人事司关于发布2012年度民政部标准化政策理论研究课题指南的通知

各有关单位：

为加快实施《全国民政标准化“十二五”发展规划》，及时研究解决民政标准化建设面临的政策理论和现实问题，现发布2012年度民政部标准化政策理论研究课题指南，请做好课题申报有关工作。

附件：《2012年度民政部标准化政策理论研究课题指南》

民政部人事司　

二○一二年四月五日

附件：

2012年度民政部标准化政策理论研究课题指南

为加快实施《全国民政标准化“十二五”发展规划》，及时研究解决民政标准化建设面临的政策理论和现实问题，现发布2012年度民政部标准化政策理论研究课题指南。

**一、**课题方向

2012年度民政标准化政策理论研究课题分为招标课题和自选课题两类。

（一）招标课题

以服务现代民政发展转型、推进民政范围管理和服务标准化建设为主线，设立以下招标课题方向：

1.现代民政绩效评价指标体系研究

主要任务：结合现代化理论和十三次全国民政工作会议精神，分析现代民政的基本内涵、基本特征、主要内容和发展趋势，确立评价现代民政事业发展的总体思路、关键指标、权重系数和技术路线，建立民政事业现代化指标体系和评价模型，提出评价现代民政绩效的政策建议。

2.标准化在加强和创新社会管理中的功能作用研究

主要任务：结合民政工作职能，梳理境内外实施社会管理标准化的政策措施和实践经验，调查了解社会管理领域标准化需求，明确社会管理领域标准化建设的基本特性、主要作用、重点方向、关键标准和运行方式，提出加强和创新民政范围社会管理标准化的政策建议。

3.标准化在建构现代民政中的功能作用研究

主要任务：结合实际，梳理民政标准化在加强制度建设、健全发展机制、提升服务效能等方面的成效，分析标准化促进现代民政发展的作用机理，明确标准化在建构现代民政中的发展方位，提出加强民政标准化体制机制建设的政策建议。

4.标准化与民政管理规制关系研究

主要任务：结合民政制度体系建构，梳理标准与法律、法规、规章、规范性文件以及行业规范之间的关系，研究标准在依法行政、促进民政管理规范运行中的角色、作用和优势，提出标准化对提升民政工作制度化水平的政策建议。

5.标准化与民政类社会服务规范化关系研究

主要任务：结合基本社会服务均等化的推进，梳理民政类社会服务领域标准化实践经验，明晰标准化在民政类社会服务领域的功能作用，厘清服务标准化与服务规范化之间的关系，提出加强民政类社会服务标准化建设的政策建议。

6.民政行政机关管理标准体系与运行机制研究

主要任务：围绕民政机关规范化建设，系统梳理民政机关运行的主要流程、关键环节和重点部位，有针对性地研究不同层级民政机关管理标准化的关键部位、重点领域、实现方式、评价指标和运行机制，提出推进民政行政管理标准化建设的政策建议。

7.民政事业单位管理标准体系与运行机制研究

主要任务：围绕管理和服务效能提升，分领域梳理民政事业单位管理的主要流程、关键环节和重点部位，研究不同类型民政事业单位管理标准化的实现方式、评价指标和运行机制，提出推进民政事业单位管理标准化建设的政策建议。

8.民政主体业务标准体系与运行机制研究

主要任务：围绕社会组织、优抚安置、减灾救灾、社会救助、社区建设、公共地名、社会福利、社会事务、社会工作等领域标准体系建构需求，选取1-2个领域开展相关标准体系和运行机制研究，探索简化、统一化等标准化方法的具体应用，提出推进民政主体业务标准化建设的政策建议。

9.民办社会工作机构标准体系与运行机制研究

主要任务：围绕培育和促进民办社会工作机构发展，借鉴境内外社会工作服务机构标准化实践经验，研究民办社会工作机构急需紧缺标准的领域、类型和实现方式，建构我国民办社会工作机构标准体系框架，提出推进民办社会工作机构标准化建设的政策建议。

10.民政标准化绩效评估指标体系研究

主要任务：围绕民政范围管理标准化建设试点评估，研究分领域分行业分类型的标准化绩效评估指标，探索建立民政标准化绩效评估指标体系，提出推进民政标准化绩效评估长效开展的政策建议。

（二）自选课题

围绕民政标准化发展战略、民政管理与服务标准化运行规律与模式、民政标准化等级评定、合格评定、认证认可等方面问题，研究人员可自选角度，自拟题目，向民政部申请备案，开展课题研究。鼓励民政范围管理标准化建设试点地区和单位结合试点开展自选课题研究。

**二、**申报规程

（一）申报资格和条件

2012年度民政部标准化政策理论研究课题申报者应为从事与课题相关工作，具有一定研究基础的单位和个人，包括科研机构、高等院校、党政机关、企事业单位、社会组织等。

优先支持从事标准化研究的单位、个人联合相关民政部门及民政范围管理标准化建设试点地区和单位共同申报。

（二）申报材料和时间

申报招标课题的，填写《民政部招标课题申请书》（附件1）；申报自选课题的，填写《民政部自选课题申请书》（附件2）。申报截止日期为2012年4月20日。请于规定日期前将申报材料的书面文件（一式三份，加盖单位公章）和电子文件报送民政部人事司。

（三）课题确定

民政部组织专家对课题申报材料进行评审，确定并公布招标课题承担单位及自选课题备案情况。

中标的招标课题，由民政部人事司与中标单位签订《民政部科研任务书》。每项研究课题给予一定研究经费支持，签订《民政部科研任务书》后付70%，余款待课题成果验收合格后拨付。没有完成研究任务或课题成果验收不合格的课题，余款不再拨付。

通过审核的自选课题，民政部人事司将统一备案，并告知课题承担人。对优秀研究成果将予以部级课题立项。

**三、**研究要求及成果形式

（一）研究要求

1.课题研究应综合运用标准化理论与方法，紧紧围绕当前民政标准化工作面临的前沿、重点、难点、突出矛盾和主要问题，收集资料数据，深入开展政策理论研究，深入剖析现状特征、问题成因和发展趋势，提出切实可行的政策建议。研究成果要求观点明确，内容翔实，文风严谨，行文规范，招标课题报告应有4000字以上的政策建议。

2.课题研究应坚持理论联系实际，提倡研究人员在民政范围管理标准化建设试点地区和单位开展蹲点调研。课题报告应有案例分析和实证调研数据，或有相关境内外经验总结和剖析。

3.支持和鼓励课题承担单位筹集配套资金开展研究。课题研究应由课题组独立研究完成，无任何违法、违纪和违反学术道德的内容。研究成果要求未公开发表，力求原创性和可操作性。

4.课题研究应于2012年10月15日前完成。课题研究成果形成纸质版一式三份和电子版报至民政部人事司，并做好评审答辩准备。

（二）成果形式

1.研究课题的最终成果为书面研究报告，一般应为总报告形式。

2.招标课题研究总报告不少于3万字，若有专题调研、重大问题研究、相关研究资料等分报告，原则上每篇不超过8000字，不计入总报告字数。

3.课题报告的编排格式：题目为宋体三号居中；文内标题及正文为宋体四号；文字间距为固定值25磅；文中注释采用页面下方脚注形式。参考文献以宋体五号附于文后。

4.课题研究成果发表、发行、改变、汇编等相关著作权利由民政部人事司享有。未经民政部人事司同意，不得公开发表。
