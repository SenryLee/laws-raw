# 国家测绘地理信息局关于开展2012年度全国省级测绘地理信息行政主管部门贯彻落实科学发展观测绘地理信息工作考评的通知

## 国家测绘地理信息局关于开展2012年度全国省级测绘地理信息行政主管部门贯彻落实科学发展观测绘地理信息工作考评的通知（国测人发〔2012〕60号）

各省、自治区、直辖市测绘地理信息行政主管部门：

为推动测绘地理信息系统全面贯彻落实科学发展观，客观、准确地了解和掌握省级测绘地理信息行政主管部门（以下简称“省级部门”）年度测绘地理信息工作开展情况，根据《全国省级测绘行政主管部门贯彻落实科学发展观年度测绘工作考评办法（试行）》（国测人发〔2009〕39号，以下简称《考评办法》），现就做好2012年度考评工作有关事项通知如下：

**一、**考评内容

根据实际工作需要，在广泛征求各省级部门意见的基础上，经国家测绘地理信息局党组审定，2012年度考评内容包括对测绘地理信息工作的组织领导、法规政策建设和依法行政、基础测绘规划实施与经费管理、基础测绘管理、科技与国际合作管理、地理信息与地图管理、测绘与地理信息服务及市场监管、测绘文化、人才队伍及廉政建设情况等，共8大项41小项。具体考评内容与标准见附件1。

**二、**考评方式

考评工作在国家测绘地理信息局考评领导小组（以下简称“考评领导小组”）领导下，由考评领导小组办公室负责组织实施，采取自评、抽查和核评相结合的方式进行。

自评：各省级部门逐项对照年度具体考评内容和标准，对本部门年度测绘地理信息工作进行深入总结，并在总结基础上进行自评打分。自评得分作为核实评分的参考。

抽查：考评领导小组组成若干抽查小组，实地抽查部分省级部门的年度测绘地理信息工作。

核评：国家测绘地理信息局各司局按照职责分工，根据各省级部门提交的书面总结报告及抽查情况，对各部门相应考评内容进行核实评分。

**三、**考评步骤

（一）启动阶段（8月）

1．考评领导小组制定印发《关于开展2012年度全国省级测绘地理信息行政主管部门贯彻落实科学发展观测绘地理信息工作考评的通知》。

2．考评领导小组组织相关部门在国家测绘地理信息局政府网站开辟考评专题。

（二）自评和总结阶段（9月－12月上旬）

1．各省级部门逐项对照年度具体考评内容和标准，对本部门年度测绘地理信息工作进行深入总结，并进行自评打分。

2．各省级部门向考评领导小组提交按要求准备的书面总结报告和自评打分结果。经考评领导小组审核后，在国家测绘地理信息局政府网站登载各部门提交的书面总结报告。

（三）抽查阶段（12月上中旬）

1．在各省级部门自评和总结的基础上，考评领导小组组成若干抽查小组，对部分省级部门的年度测绘地理信息工作情况进行实地抽查。

2．抽查主要采取听取工作汇报、查阅档案材料、召开座谈会、组织评估和测评等多种方式进行。

（四）核实评分和结果确定阶段（12月下旬）

1．考评领导小组组织机关各司局按照职责分工，根据各省级部门提交的书面总结报告、自评分及实地抽查情况，对各部门相应考评内容进行核实评分，由考评领导小组办公室负责汇总。

2．考评领导小组根据各省级部门的书面报告、实地抽查情况和最后核实评分，综合确定考评结果建议，报国家测绘地理信息局党组审定。

（五）表彰和反馈阶段（2013年1月－2月）

1．综合考虑各地区的发展基础差异，为充分调动各省级部门的积极性，经国家测绘地理信息局党组研究决定，在继续设置“2012年度考评优秀单位”奖项的基础上，设置“2012年度突出进步单位”和“2012年度特色工作创新单位”单项奖。在全国测绘地理信息局长会议上，通报各省级部门考评结果，并对获奖的省级部门分别给予表彰。

2、国家测绘地理信息局采取适当方式，向各省级部门所在省（区、市）政府反馈考评结果。

**四、**材料准备

（一）提交材料及报送时间

各省级部门暂定于12月10日前（届时根据全国测绘地理信息局长会议召开时间调整），以正式文件向考评领导小组提交本部门年度测绘地理信息工作书面总结（纸质件10份，附电子版）和自评打分结果。同时，各部门需另提交1份可公开登载到国家测绘地理信息局政府网考评专题的总结报告（首页右上角注明“可公开”字样，附电子版）。

（二）书面总结报告撰写要求

1．为便于国家测绘地理信息局机关司局对各部门年度测绘地理信息工作的对应考评项目进行核实打分，各省级部门必须按照国家测绘地理信息局党组确定的8大项41小项考评内容、标准及其顺序，逐项撰写书面总结报告，不应遗漏。总结报告的各级标题可以自定。

书面总结报告中，应单列一部分报送本年度本地区开展的有特色有创新并取得较大社会影响的重点工作落实情况，作为综合加分项目和评审“2012年度特色工作创新单位”单项奖的参考。

2．书面总结报告要实事求是地反映本地区年度测绘地理信息工作情况，文字简洁明晰、重点突出、数字准确。其中对考评内容与标准要求提供数字的，必须要准确提供。

3．对本部门本年度发生的重特大安全生产事故、重特大质量事故、重大泄密事件、重大版图问题、重大群体性事件或廉政建设方面发生的严重问题，要如实报告，不得隐瞒。

4．书面总结报告的格式要符合规定要求，具体格式要求详见总结报告格式说明（附件2）。

**五、**有关要求

（一）各省级部门要高度重视考评工作，切实加强领导，明确专人负责，确保考评工作顺利开展。请各部门于9月17日前，将本部门考评工作的联系人相关信息（详见附件3）报考评工作领导小组办公室。

（二）各省级部门要对照考评内容与标准，认真总结本地区年度测绘地理信息工作，按照要求如实报送年度测绘地理信息工作总结及相关情况，并认真做好接受考评的各项准备工作。对在考评工作中弄虚作假的单位，国家测绘地理信息局将给予严肃处理。

（三）各省级部门要通过年度测绘地理信息工作考评，认真总结本地区年度测绘地理信息工作的成绩和经验，深入分析存在的主要问题和薄弱环节，推进本地区测绘地理信息工作又好又快科学发展。

（四）各省级部门要按照《考评办法》要求，结合本地区实际，切实做好对市（地、州）、县测绘地理信息行政主管部门贯彻落实科学发展观年度测绘地理信息工作的考评，并将考评结果报考评领导小组备案。

（五）各省级部门开展贯彻落实科学发展观年度测绘地理信息工作考评工作的情况，要及时在国家测绘地理信息局政府网站登载。

各省级部门在考评工作中遇有问题，请及时联系考评工作领导小组办公室。
