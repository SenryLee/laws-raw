# 环境保护部2012年在京部属单位统一招录应届毕业生面试公告

根据我部2012年在京部属单位统一招考应届毕业生工作方案和招考公告，现就面试有关事项公告如下：

**一、**面试人员

按照报考岗位综合测试成绩（可登录招考专题网页查询）从高到低排序，根据统一招考公告提出的1：8面试比例确定进入面试的人员名单。招聘岗位参加考试人数不足1：8比例的，按实际人数确定面试名单，或从报考其它专业相近岗位而未能进入面试的考生中按笔试成绩由高到低择优调剂。要求北京生源的岗位仅限北京生源调剂。面试比例末位考生成绩相同的，一并进入面试。

面试人员名单详见附件。
