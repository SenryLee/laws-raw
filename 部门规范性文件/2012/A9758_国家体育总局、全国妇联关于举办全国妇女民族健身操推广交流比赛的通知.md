# 国家体育总局、全国妇联关于举办全国妇女民族健身操推广交流比赛的通知

## 国家体育总局、全国妇联关于举办全国妇女民族健身操推广交流比赛的通知（体群字[2012]181号）

各省、自治区、直辖市体育局、妇联，新疆生产建设兵团体育局、妇联：

为进一步贯彻落实《全民健身计划（2011--2015年）》，用妇女群众喜闻乐见的形式和丰富多彩的载体推广普及科学健身方法，提高广大妇女科学健身水平，全国妇联委托北京体育大学创编了《民族健身操》，并在近年的全国妇女健身骨干示范培训班中进行培训推广，受到广大妇女健身骨干的好评和各地妇女群众的喜爱。为展示交流本套健身操的培训推广成果，推动妇女健身活动并带动基层群众健身活动的开展，国家体育总局、全国妇联拟于2012年11月下旬在天津市举办全国妇女民族健身操推广交流比赛。现将比赛总规程及比赛规则印发给你们，希望按照要求，积极组队参赛。

全国妇女民族健身操推广交流比赛规则

## 第一章　总　 则

**一、**比赛目的

民族健身操是在民族音乐伴奏下进行以民族舞蹈语汇操化动作为主体的身体练习。它将民间传统健身活动中最具有民族特色的技术动作融入健身操中，创新和丰富了广大妇女群众体育健身活动的内容和形式，使其成为一项增进健康、改善气质、塑造形体、娱乐身心的运动项目。展示多元的健身文化形式，弘扬传统的民族文化精神，提供科学的健身指导依据，全方位提高广大妇女群众健康水平。

**二、**比赛内容

民族健身操规定动作。

**三、**成套动作时间

成套动作时间按《民族健身操规定动作》的时间执行。

**四、**参赛人员

1、每队参赛人数为10人，参赛人员必须是年龄在35-55岁之间身体健康的中华人民共和国女性公民。

2、如有特殊情况更换参赛人员时，需持有效证明，在比赛开始前，经组委会同意方可更换。

**五、**比赛方式

比赛采取两轮制进行。两轮比赛的出场顺序由组委会指定人员抽签决定。根据抽签结果确定出场顺序，各参赛队按照出场顺序进行比赛。

**六、**比赛服饰

参赛者着民族服装和运动服均可。若穿着民族服装，则应在保持民族特色的基础上进行改良，使之便于运动；可以佩戴表现本民族特色的饰物，饰物的材质、形状必须是安全的，饰物不能散落；发型要整洁，化妆要适度。

**七、**比赛场地

比赛场地为12米×12米的木质地板、地毯或其它材质平整地面。场地四周设标志线清楚地标出比赛区域，线宽均为5厘米，标志线属于比赛场地的一部分。

**八、**计分方法

民族健身操规定动作满分为100分。裁判委员会设裁判长1名、裁判员5名。每位裁判员的评分最小单位精确到个位，参赛队的得分和最后得分均精确到小数点后2位。

裁判员根据参赛队两轮比赛的表现进行综合评判，参赛队最后得分为两轮比赛的平均分。每轮比赛中，裁判员的评分去掉一个最高分和一个最低分，所剩分数的平均分为得分，再减去裁判长减分为参赛队该轮比赛的最后得分。分数高者，名次列前；若最后得分相等，则名次并列。

每轮比赛最后得分 ＝ 平均分 - 裁判长减分

最后得分 ＝（第一轮比赛最后得分 ＋ 第二轮比赛最后得分）

## 第二章　规定动作评分

民族健身操规定动作的评分因素包括动作完成、精神面貌、进退场情况。

**一、**动作完成（90分）

包括预备节10分，四节动作各20分，共计90分。

1、动作的准确性：基本姿态和基本技术正确规范，动作清晰有控制。

2、动作的流畅性：动作之间的连接自然、流畅，动作的转换及方向的变化干净利落，无多余动作。

3、动作的协调性：全身协调运动、动作轻松、有弹性，不过分松弛或过分紧张。

4、动作的节奏感：动作和音乐节奏的配合要协调一致。

5、动作的一致性：集体动作整齐划一，完成动作幅度、速度、轨迹、合拍以及表现能力整体一致。

6、队形运用：成套动作至少清晰展示3个不同的队形变化。

动作完成减分标准参照表：

|  |  |  |
| --- | --- | --- |
| 错 误 程 度 | 减 分 程 度 | 减 分 内 容 |
| 小错误 | 减1分 | 与正确动作、姿势和节拍有微小偏差。 |
| 中错误 | 减2分 | 与正确动作、姿势和节拍有明显偏差。 |
| 大错误 | 减3分 | 与正确动作、姿势和节拍有严重偏差。 |
| 失误 | 减5分 | 失去平衡（跌倒）。 |
| 其它 | 减3-5分 | 每漏做或附加部分动作。 |
| 减该节分值 | 每漏做一节动作。 |
| 减2分 | 每少一个队形变化。 |

**二、**精神面貌（5分）

参赛者动作要表现内心的激情，体现健康向上的精神风貌，至始至终表现出充沛的精力，充满自信，以自身的活力和激情完成动作并感染观众。

30%以下的人欠缺上述精神面貌减1分，30%-50%之间减2分，50%以上减3分。

**三、**进退场（5分）

所有参赛队员进退场应保持整齐一致，动作协调统一、组织有序。

30%以下的人动作不齐减1分，30%-50%之间减2分，50%以上减3分。

**四、**裁判长减分

裁判长对比赛过程进行监控，并对出现的以下情况给予减分：

1、裁判长示意后30秒内未出场，减2分；60秒内未出场，减5分；超过90秒未出场视为弃权，取消比赛资格。

2、参赛人数多于或少于规定人数，减2分/人。

3、着装不符合规定，减2分。

4、比赛过程装束掉落，减2分。

5、参赛者比赛时触及标志线以外地面，减1分/人/次。

## 第三章　特殊情况处理

参赛者遇到以下特殊情况时，应立即停止做动作并向裁判长反映，在问题解决后重做，成套动作结束后提出的要求将不被接受。

**一、**播放错音乐。

**二、**因设备等问题而出现的干扰。

**三、**参赛者责任外的情况而引起的比赛中断或终止。
