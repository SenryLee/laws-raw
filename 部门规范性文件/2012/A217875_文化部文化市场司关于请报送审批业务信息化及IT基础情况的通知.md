# 文化部文化市场司关于请报送审批业务信息化及IT基础情况的通知

各省、自治区、直辖市文化厅（局）市场处：

为推进全国文化市场技术监管系统与服务平台项目建设，根据全国文化市场技术监管系统建设进度安排，现需对各省审批业务信息化情况以及IT基础情况进行调查。现将《各省审批业务信息化及IT基础情况调查表》下发，请各单位填写，并于2012年11月5日前发送至zhzfbgs@sina.com。

本通知及其附件可以在文化市场网（www.ccm.gov.cn）查询、下载。

特此通知。
