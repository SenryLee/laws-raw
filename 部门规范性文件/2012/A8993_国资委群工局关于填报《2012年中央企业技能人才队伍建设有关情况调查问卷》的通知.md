# 国资委群工局关于填报《2012年中央企业技能人才队伍建设有关情况调查问卷》的通知

各中央企业：

为准确掌握中央企业技能人才队伍建设工作情况，进一步做好中央企业高技能人才队伍建设工作，现将《2012年中央企业技能人才队伍建设有关情况调查问卷》印发给你们，请认真填写，并将调查问卷通过邮件、传真或邮寄的方式于2013年1月15日前报国资委群工局。

同时，为便于统计，请各集团公司登陆国务院国资委网站首页（www.sasac.gov.cn）“委内厅局-群众工作局-通知公告”本通知的附件中下载统一格式的EXCEL电子表，并按此表汇总上报（电子版）。
