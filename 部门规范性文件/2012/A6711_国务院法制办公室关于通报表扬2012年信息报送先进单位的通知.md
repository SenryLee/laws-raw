# 国务院法制办公室关于通报表扬2012年信息报送先进单位的通知

各省、自治区、直辖市人民政府法制办公室：

2012年中国政府法制信息网共刊登全国各省、自治区、直辖市人民政府法制办公室报送的政府法制信息6776篇。这些信息紧紧围绕依法治国的基本方略和建设法治政府的要求，全面及时地反映了各地推进依法行政、加快法治政府建设的新思路、新举措、新经验和新成绩，客观、准确地反映了政府法制工作的实际情况，在宣传政府法制工作、弘扬法制精神、提高全民法制意识等方面做出了重要贡献。

为了贯彻落实党的十八关于全面推进依法治国、建设法治政府的要求，加强政府法制宣传，激励地方各级人民政府法制机构做好政府法制信息报送工作，国务院法制办公室决定对在2012年信息报送工作中表现突出的省、自治区、直辖市、设区的市和州人民政府法制办公室给予通报表扬。希望受到表扬的单位戒骄戒躁，继续努力，为政府法制信息工作向深层次、高质量发展做出新的贡献。
