# 国家工商总局商标局关于中国商标网发布《商标注册用商品和服务国际分类》(第十版)的通知

## 国家工商总局商标局关于中国商标网发布《商标注册用商品和服务国际分类》（第十版）的通知

为方便商标申请人浏览和查询，现已将《商标注册用商品和服务国际分类》（第十版）在中国商标网商标申请栏目下的商品和服务分类版块里进行发布，附件可供下载。

国家工商总局商标局　

二〇一二年六月二十七日
