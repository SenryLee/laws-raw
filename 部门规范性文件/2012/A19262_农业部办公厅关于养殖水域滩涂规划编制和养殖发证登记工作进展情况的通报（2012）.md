# 农业部办公厅关于养殖水域滩涂规划编制和养殖发证登记工作进展情况的通报（2012）

## 农业部办公厅关于养殖水域滩涂规划编制和养殖发证登记工作进展情况的通报（农办渔【2012】27号　2012年3月13日）

各省、自治区、直辖市及计划单列市渔业主管厅（局），新疆生产建设兵团水产局：

2011年以来，各级渔业主管部门认真贯彻党中央关于稳定渔民水域滩涂养殖使用权有关精神，按照我部《关于稳定水域滩涂养殖使用权推进水域滩涂养殖发证登记工作的意见》（农渔发[2010]25号，以下简称《意见》），加强养殖权制度建设，积极推进养殖水域滩涂规划编制以及养殖发证登记工作，取得显著成效。现将各地工作进展情况通报如下：

截至2011年12月底，全国已有11个省级、118个地市级和1292个区县级人民政府，正式颁布实施本行政区域《养殖水域滩涂规划》；全国核发《水域滩涂养殖证》40.5万多本，其中核发新版养殖证3.2万本。全国水域滩涂养殖发证登记面积549万公顷，发证登记率达到79%，比上一年提高11个百分点。各地录入旧版养殖证数据23.4万本，比上年增加0.7万本。

区县级规划编制颁布出台率在75%以上的有广西、江西、湖北、江苏、上海、安徽、内蒙古等7个省（区、市）和青岛市。江苏省正式出台了省级规划，广西区、市、县（区）三级养殖水域滩涂规划于2011年统一重新修编。水域滩涂养殖发证登记率在75%上的有黑龙江、山西、天津、湖北、青海、吉林、江西、上海、浙江、河南、湖南、陕西、山东等13个省（市）和深圳、大连、宁波等3个市。（具体统计数据见附件）

截至目前，各地养殖水域滩涂规划编制和养殖发证登记工作进展仍不平衡，重点县（市、区）完成涂规划编制以及规划内发证登记率达到95%以上的工作目标仍未达到。从我部调查和统计数据情况看，仍有个别地区对此项工作重视程度不够，忽视渔民权益保护，暂缓出台规划，暂停核发养殖证或核发非正规证件。同时，部分地区对已过期规划未及时修编，对已失效养殖证未提醒渔民延期或换证，旧版养殖证数据库录入和新版养殖发证登记系统培训工作进度缓慢，对全局工作影响较大。当前，各地养殖权制度建设进入攻坚克难的关键阶段，希望各级渔业主管部门认真贯彻实施《水域滩涂养殖发证登记办法》，按照我部《意见》有关要求，进一步加强组织领导，加大工作力度，健全奖惩机制，强化工作督查，加快养殖水域滩涂规划编制和养殖发证登记工作。

专此通报。
