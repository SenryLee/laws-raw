# 国家文物局关于美国摄制组来华拍摄涉及有关文物的复函(拍摄许可[2012]75号)

## 国家文物局关于美国摄制组来华拍摄涉及有关文物的复函（拍摄许可〔2012〕75号）

国务院新闻办公室三局：

你局关于美国彩虹电视台《探访古都西安》摄制组来华拍摄专题片涉及文物的函（国新办三局发函[2012]65号）收悉。经研究，我局同意该摄制组于2012年9月16日至26日拍摄陕西半坡遗址、西安城墙、西安碑林、西安钟楼、大雁塔、大明宫遗址、乾陵、法门寺遗址、秦始皇陵、秦始皇兵马俑（坑上拍摄）有关镜头。具体拍摄内容及拍摄方式等事宜请与当地文物部门协商确定。在拍摄过程中，请该摄制组严格服从文物管理人员安排，务必确保文物安全。

国家文物局　　　

二〇一二年八月二十八日
