# 国家旅游局公告2012年3号――关于旅行社质量保证金存储业务情况公告

## 国家旅游局公告（2012年3号）

旅行社质量保证金存储业务情况公告

依据《旅行社条例》及《旅行社质量保证金存取管理办法》，现将截至2011年12月31日，我局指定的11家旅行社质量保证金存储银行存储旅行社质量保证金业务（以下称存储业务）情况公告如下（因中国工商银行数据不完整，以下不含其数据）：

中国银行、中信银行、交通银行、上海浦东发展银行、招商银行、中国邮政储蓄银行、中国建设银行、中国光大银行、中国农业银行、中国民生银行等10家指定银行存储业务覆盖全国（不含港澳台地区），共有旅行社质量保证金存储专户24918家，比2011年6月30日前增加5712家；存储（担保）金额合计人民币48.09亿元，比2011年6月30日前增加人民币6.37亿元。其中，中国银行为37家旅行社提供质量保证金担保1592万元，中国农业银行为68家旅行社提供质量保证金担保1303.7万元，中国光大银行为37家旅行社提供质量保证金担保1100万元，中信银行为2家旅行社提供质量保证金担保209万元。
