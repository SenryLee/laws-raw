# 国家体育总局办公厅、教育部办公厅关于召开全国体育传统项目学校体育师资培训(2008―2012年)总结大会的通知

## 国家体育总局办公厅、教育部办公厅关于召开全国体育传统项目学校体育师资培训（2008-2012年）总结大会的通知

各省、自治区、直辖市体育局、教育厅（教委）：

为了总结全国体育传统项目学校体育师资培训（2008-2012年）工作的经验与成果，经国家体育总局和教育部研究决定，将于12月初在北京召开全国体育传统项目学校体育师资培训（2008-2012年）总结大会。现将有关事宜通知如下：

**一、**会议时间和地点

时间：2012年12月4日报到，5日至6日开会，7日离会。

地点：国家奥林匹克体育中心运动员公寓（北京市朝阳区定安路1号）

**二、**参加人员

1、国家体育总局、教育部领导；

2、国家体育总局、教育部相关部门领导；

3、各省（区、市）体育局分管体育传统项目学校工作的局领导1人；

4、各省（区、市）教育厅（教委）分管学校体育工作的厅领导1人；

5、各省（区、市）体育局分管体育传统项目学校工作的处领导1人；

6、各省（区、市）开展体育传统项目学校师资培训的培训基地负责人1人；

7、全国体育传统项目学校培训中心负责人及师资培训国家讲师团主要成员；

8、相关媒体和工作人员。

**三、**会议内容

1、总结五年来（2008-2012年）开展全国体育传统项目学校体育师资培训工作的经验与成果；

2、教育部领导讲话；

3、体育总局领导讲话；

4、大会经验发言；

5、部署下一周期（2013-2015）全国体育传统项目学校培训工作的基本思路与安排；

6、各培训基地培训经验展板展示。

**四、**食宿及交通

参会代表食宿由大会负责，往返交通费用自理。

**五、**各省（区、市）相关准备工作

（一）在总结五年培训工作的基础上，设计准备培训工作展板一幅（展板规格：长：120cm宽：90cm ），内容包括：五年来培训的基本情况、特色、成果和主要做法。以文字、图片、数据图表等形式综合反映。材料要求真实可靠，版面设计美观、新颖、整洁。请将电子稿于11月26日前发送至全国体育传统项目学校培训中心邮箱zhoudengsong@cupes.edu.cn，届时由大会统一打印制作。

（二）需做大会发言的单位与个人将另行通知。
