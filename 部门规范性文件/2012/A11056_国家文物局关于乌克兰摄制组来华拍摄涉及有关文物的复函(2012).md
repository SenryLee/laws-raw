# 国家文物局关于乌克兰摄制组来华拍摄涉及有关文物的复函(2012)

## 国家文物局关于乌克兰摄制组来华拍摄涉及有关文物的复函（拍摄许可〔2012〕81号）

国家广播电影电视总局国际合作司：

你司关于乌克兰国家电视一台摄制组来华拍摄专题片涉及文物的函（外字[2012]781号）收悉。经研究，我局同意该摄制组于2012年10月20日至11月2日期间拍摄北京故宫、八达岭长城、居庸关长城有关镜头。具体拍摄内容及拍摄方式等事宜请与当地文物部门协商确定。在拍摄过程中，请该摄制组严格服从文物管理人员安排，务必确保文物安全。

国家文物局　　

二〇一二年九月十二日
