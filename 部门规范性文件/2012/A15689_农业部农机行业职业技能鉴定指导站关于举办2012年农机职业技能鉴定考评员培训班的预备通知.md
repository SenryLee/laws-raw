# 农业部农机行业职业技能鉴定指导站关于举办2012年农机职业技能鉴定考评员培训班的预备通知

## 农业部农机行业职业技能鉴定指导站关于举办2012年农机职业技能鉴定考评员培训班的预备通知（农机职鉴[2012]3号）

各农机职业技能鉴定站：

为加深基层人员对职业技能鉴定工作的认识，增强工作的责任感，进一步稳定和扩大考评人员队伍，根据2012年农机职业技能开发工作安排，我站拟于2012年7月至8月分别在江西、宁夏和四川组织举办三期农机职业技能鉴定考评员培训班。现将有关事项通知如下：

**一、**培训班内容

（一）培训职业技能鉴定的有关法律、法规、政策及基本理论，宣贯农机行业职业技能鉴定工作程序和质量管理规则，培训国家职业资格证书制度的有关内容。

（二）宣贯农机行业职业标准，培训考评员职责任务和工作要求，研讨农机职业技能鉴定题库开发及考评技术技巧等。

（三）介绍农机行业职业技能鉴定工作发展情况，以及各地取得的工作经验。

**二、**参加人员及要求

各级农机主管部门和各农机职业技能鉴定站、工作站从事农机职业技能鉴定考评管理和考评工作的人员均可报名参加。

报名人员需具备以下资格条件：考评员应具有二级（技师）以上职业资格或者中级专业技术职务（工程师）以上的资格；高级考评员应具有一级职业资格或副高级以上专业技术职务资格。

**三、**培训班时间、地点安排

江西培训班计划7月中旬在南昌举办，宁夏培训班计划7月下旬在银川举办，四川培训班计划8月中旬在成都举办，每期培训班预计需要4天时间。培训班本着节约的原则，培训期间的差旅费、食宿费自理，另收取适量会务、培训、考试和教材费。每期培训班的具体时间、地点和收费标准待预报名结束汇总后，在每期培训班举办前会另行通知。

**四、**其他事项

（一）请各单位接到通知后，及时向本省（区、市）农机主管部门汇报、协商，结合培训班时间、地点安排，按照每个县有1-3名考评员的工作要求，统一组织，尽早确定参加培训人员，并填写《农机职业技能鉴定考评员培训班报名表》（附件1），于6月15日前，把报名表电子版发送至农业部农机行业职业技能鉴定指导站电子邮箱zhdch@camtc.net，以便承担单位联系住宿、培训地点等。

（二）请参加培训人员提前填写《农业职业技能鉴定考评人员审批登记表》（见附件2），务必按要求加盖单位及省级行政主管部门公章，报到时须交此表。

（三）农业职业技能鉴定考评员实行资格认证制度，经培训考核成绩合格者可获得考评员资格证卡。
