# 国家文物局关于拨付2012年中国文化遗产保护无锡论坛筹备工作补助经费的函

## 国家文物局关于拨付2012年中国文化遗产保护无锡论坛筹备工作补助经费的函（文物保函〔2012〕203号）

无锡市文物管理委员会办公室：

为推动我国世界文化遗产保护管理，经研究，我局委托你办承办2012年中国文化遗产保护无锡论坛，主题为“世界遗产：可持续发展”。现随函拨付无锡论坛筹备工作补助经费40万元，请加强经费管理，做好会务筹备、材料准备、论文收集与出版等会议各项准备工作，确保专款专用。

专此。

国家文物局　　

二〇一二年二月十日
