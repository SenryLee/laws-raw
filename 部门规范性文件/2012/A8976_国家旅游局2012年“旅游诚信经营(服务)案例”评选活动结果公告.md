# 国家旅游局2012年“旅游诚信经营(服务)案例”评选活动结果公告

## 国家旅游局2012年“旅游诚信经营（服务）案例”评选活动结果公告（国家旅游局公告2012年19号）

为做好规范旅游市场秩序、提高旅游服务质量工作，引导旅游企业及旅游从业者树立“诚信光荣、失信可耻”的理念，在旅游全行业形成讲诚信氛围，引导诚信经营、优质服务，国家旅游局在全国范围内组织开展了2012年“旅游诚信经营（服务）案例”评选活动。现将评选结果公告如下（按得票数排序）：

----贵州荔波三力酒店
