# 国家质量监督检验检疫总局公告2012年第170号――关于公布2012年26类产品质量国家监督抽查结果的公告(三)

## （续二）

附件14：

方便面产品质量国家监督抽查结果

本次共抽查了北京、天津、河北、山西、辽宁、吉林、黑龙江、江苏、安徽、福建、山东、河南、广东、陕西等14个省、直辖市100家企业生产的100种方便面产品。

本次抽查依据《方便面卫生标准》GB 17400-2003、《食品安全国家标准 食品添加剂使用标准》GB 2760-2011等标准的要求，对方便面产品的酸价、过氧化值、羰基价、铅、总砷、菌落总数、大肠菌群、沙门氏菌、志贺氏菌、金黄色葡萄球菌、抗氧化剂（BHA、BHT、TBHQ）、苯甲酸、山梨酸、柠檬黄、日落黄、胭脂红、苋菜红、亮蓝、诱惑红等21个项目进行了检验。

抽查发现有3种产品不符合标准的规定，涉及到菌落总数、大肠菌群项目。具体抽查结果见附件。
