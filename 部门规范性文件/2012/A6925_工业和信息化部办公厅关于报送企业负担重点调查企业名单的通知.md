# 工业和信息化部办公厅关于报送企业负担重点调查企业名单的通知

各省、自治区、直辖市减轻企业负担领导小组（联席会议）：

按照《企业减负专项行动方案》安排，决定开展企业负担调查体系 建设工作。现就有关事项通知如下：

**一、**请各省（自治区、直辖市）分别选择100家代表本地区特点的企业作为企业负担调查点，选择时以中小微企业为主，兼顾各方。

**二、**我部拟于2013年3月对各地减负机构填报企业负担调查表事宜进行培训。请对企业负担调查表（将发你单位负责减负工作同志邮箱）阅提意见。

**三、**请于2013年1月31日前将企业汇总名单（见附件）及意见反馈我部（运行监测协调局）。
