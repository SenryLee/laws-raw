# 工业和信息化部核定发布2012年(第十一届)中国软件业务收入前百家企业和中国自主品牌软件产品收入前十家企业名单

## 工业和信息化部核定发布2012年（第十一届）中国软件业务收入前百家企业和中国自主品牌软件产品收入前十家企业名单

根据国家统计局与工业和信息化部联合统计的2011年全国软件产业统计年报数据，经地方工业和信息化主管部门初审，工业和信息化部最终审定，现将“2012年（第十一届）中国软件业务收入前百家企业”和“2012年中国自主品牌软件产品收入前十家企业”名单予以公布（名单见附件）。

附件：

1.2012年（第十一届）中国软件业务收入前百家企业名单

2.2012年中国自主品牌软件产品收入前十家企业名单

二〇一二年七月五日
