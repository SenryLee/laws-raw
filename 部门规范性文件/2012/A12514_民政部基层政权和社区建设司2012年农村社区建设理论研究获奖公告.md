# 民政部基层政权和社区建设司2012年农村社区建设理论研究获奖公告

民政部于2012年3月向社会发布了《2012年农村社区建设理论研究课题指南》后，得到了全国各地许多实际工作者和专家学者积极响应和参与。截止到2012年4月底，共收到符合要求的论文275篇，通过初审、专家评审、终审等环节，共评选出获奖论文63篇，其中一等奖3篇，二等奖6篇，三等奖18篇，优秀奖36篇（获奖名单见附件）。

本次活动征集到的论文选题广泛，理论研究深入，总体水平较高，具有较强的前瞻性、创新性和决策参考价值，对于加强农村社区建设的理论指导，强化农村基层组织建设和社会管理创新和推动农村社区建设工作具有积极作用，希望实际工作者、专家学者和社会各界继续关注支持乡镇基层政权建设和农村社区建设的理论研究工作，为理顺农村社区建设管理和服务中的体制机制问题，进一步加强和创新农村基层社会管理创新做出积极贡献。

民政部基层政权和社区建设司
