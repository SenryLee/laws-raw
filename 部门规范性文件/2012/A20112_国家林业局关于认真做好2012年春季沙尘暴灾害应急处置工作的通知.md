# 国家林业局关于认真做好2012年春季沙尘暴灾害应急处置工作的通知

## 国家林业局关于认真做好2012年春季沙尘暴灾害应急处置工作的通知（林沙发[2012]40号）

各有关省、自治区、直辖市林业厅（局），新疆生产建设兵团林业局：

当前，我国北方地区已进入沙尘暴多发季节，为切实做好2012年春季沙尘暴灾害应急处置工作，减轻沙尘暴危害程度，减少沙尘暴造成的损失，为党的十八大胜利召开营造一个良好的氛围。按照《重大沙尘暴灾害应急预案》要求，现就有关事项通知如下：

**一、**把握灾害动态，周密制定应急处置方案。1月初，我局与中国气象局联合组织召开2012年春季沙尘天气趋势预测分析会。据专家会商意见，2012年春季我国北方地区沙尘天气过程数可能多于2011年同期，不排除局地出现强沙尘暴的可能。因此，2012年春季我国北方地区沙尘暴灾害形势依然不容乐观，应急处置工作仍较为艰巨。各地要充分认清今春沙尘暴灾害形势，进一步提高应急处置工作重要性的认识，在认真总结往年沙尘暴灾害处置工作经验的基础上，深入查找灾害隐患和应急工作薄弱环节，有针对性地制订和完善应对与处置工作方案，专题进行研究部署和落实。

**二、**依靠科技支撑，科学开展沙尘暴灾害监测预警工作。各级林业主管部门要与气象、农业、环保、民政等部门加强协作，实现沙尘暴灾害信息互通共享。在沙尘暴灾害重点预警期，要强化应急值守，落实岗位职责，节假日主要领导也要亲自带班，专人值班。各地要加强地面监测站和短信平台等现有监测资源管理，定期对应急管理和技术人员开展继续教育，提高应急管理和技术水平，确保高效运转。要努力创造条件，积极协调，借助本地区、本部门现有的监测设施，开展监测预警工作，及时、准确掌握沙尘暴发生源地、强度、路径、影响范围等，确保灾情及时发现、及时处置、有效应对。

**三、**强化信息报送，确保灾害信息报送及时、准确。各地要完善沙尘暴灾害信息报告制度，健全信息传输渠道，加强信息员队伍建设。搞好灾情信息报送工作，安排专人负责沙尘暴灾害信息收集和上报工作，实现各类应急信息的及时、快速、准确传递。在沙尘暴重点预警期内，要严格实行日报和零报告制度，对于出现人员伤亡、较大经济损失、有主要领导批示的沙尘暴信息，必须按要求及时上报，我局将适时对各地报送沙尘暴灾害信息情况进行通报。各地要加强对短信平台和地面站等各类信息员进行培训，确保信息员熟练掌握监测仪器和相关软件使用，提高业务水平。

**四、**搞好灾害评估，指导抗灾救灾和灾后重建工作。灾情评估是沙尘暴灾害应急处置工作的重要环节，是开展灾后重建的基础。各地要不断完善灾害评估办法，充实沙尘暴灾害评估专家队伍，发挥专家咨询决策作用。一旦发生重大沙尘暴，造成人员伤亡和重大财产损失的，各地要按照规定迅速派出工作组到现场查看灾情，指导抢险救灾，检查督促突发灾害应急措施的落实，并对当地沙尘暴灾害情况进行调研，分析造成灾害损失的原因，提出沙尘暴灾后重建对策措施，积极协助受灾地区争取多方面支持，尽快恢复灾区人民群众正常生产生活。

**五、**抓好宣传教育，提高全社会防灾减灾意识。各地要做好舆情监测和舆论引导，充分利用现有的媒体，积极开展《防沙治沙法》和沙尘暴灾害有关知识的宣传教育，宣传科学防灾理念，提高广大人民群众沙尘暴灾害的预防意识和能力。沙尘暴灾害多发区要制定详细宣传教育方案，有针对性地提出防灾减灾措施。对可能发生沙尘暴，要及时发布预警信息，对交通不便，信息闭塞的地方要采取多种方式将预警信息通知到人。一旦发生沙尘暴，要及时、准确公布灾情，正确引导社会舆情。通过宣传，正确引导公众理性认识沙尘暴，增强全社会防沙治沙的责任意识。

**六、**加强组织领导，确保各项应急措施落到实处。各级林业主管部门要加强组织领导，健全应急处置机构和队伍，在经费和人员上予以支持，确保沙尘暴灾害应急处置工作顺利开展。在2月底前，要组织开展一次沙尘暴灾害应急措施和工作制度落实情况大检查，重点对今春工作方案、机构队伍、信息报送及宣教方案等落实情况进行督促检查，查找问题和不足，提出改进措施，确保各项应急措施落实到位。

请各地对照《重大沙尘暴灾害应急预案》，从组织领导、预案管理、队伍建设、资金投入、物资保障、监测预警、信息报送、现场处置、恢复重建和科普宣教等方面，对近年来沙尘暴灾害应急处置工作进行全面总结，制定好今春沙尘暴灾害应急处置工作方案，并于3月5日前报送国家林业局防沙治沙办公室。
