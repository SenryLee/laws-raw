# 国家质量监督检验检疫总局公告2012年第198号――关于公布2012年高耗能特种设备节能技术与产品推广目录的公告

## 国家质量监督检验检疫总局公告（2012年第198号）

关于公布2012年高耗能特种设备节能技术与产品推广目录的公告

根据《特种设备安全监察条例》的有关规定，为进一步推动高耗能特种设备节能工作，加大特种设备节能技术和产品推广力度，国家质检总局组织专家对有关单位2012年报送的高耗能特种设备节能技术与产品进行了遴选，确定了3项技术和产品予以推广。

附件：2012年高耗能特种设备节能技术与产品推广目录

国家质量监督检验检疫总局

2012年12月10日
