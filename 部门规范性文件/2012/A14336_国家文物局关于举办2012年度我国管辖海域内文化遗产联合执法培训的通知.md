# 国家文物局关于举办2012年度我国管辖海域内文化遗产联合执法培训的通知

## 国家文物局关于举办2012年度我国管辖海域内文化遗产联合执法培训的通知（文物督函〔2012〕1425号）

沿海各省、自治区、直辖市文物局，天津、上海市文化市场行政执法总队：

为进一步提高文物部门和海洋执法机构的水下文物联合执法能力和水平，深化合作机制，现决定举办2012年度我国管辖海域内文化遗产联合执法培训。具体事项通知如下：

**一、**培训时间和地点

培训时间：2012年7月16日至20日，15日报到，21日疏散。

培训地点：福建省漳州市芗江酒店。

**二、**文物部门参加人员

沿海各省级文物行政执法机构和沿海各重点省辖市文物行政执法机构负责同志。（具体名额分配见附件1）

**三、**培训内容

（一）文物执法

1．水下文物保护和法规体系

2．文物行政执法与文物安全形势

3．水下文物的辨识与认定

4．水下文物巡查和水下文物联合执法经验介绍

（二）海洋执法

1．中国海洋维权形势

2．海监执法与海洋维权

（三）现场观摩

水下文化遗产联合执法应急预案演练

**四、**工作要求

（一）有关省级文物行政执法机构负责本地区参加培训人员的汇总、报名工作。

（二）请于7月12日前将参训人员名单、抵达航班（车次）和抵达时间报会务组。请各地尽量组织统一出行，方便会务组接站。

（三）各地要充分认识我国管辖海域内文化遗产联合执法培训工作的重要性和必要性，精心组织，按时报到，认真学习。

**五、**其他事项

（一）各地正式报名参加培训人员的食宿费由培训班承担，往返交通费自理。

（二）培训期间严格遵守纪律，不得请假。

（三）参加培训的海监执法人员由中国海监总队另行通知。
