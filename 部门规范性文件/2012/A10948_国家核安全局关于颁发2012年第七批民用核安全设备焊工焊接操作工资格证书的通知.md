# 国家核安全局关于颁发2012年第七批民用核安全设备焊工焊接操作工资格证书的通知

## 国家核安全局关于颁发2012年第七批民用核安全设备焊工焊接操作工资格证书的通知（国核安发[2012]176号）

中国核工业第二二建设有限公司，东方电气集团东方锅炉股份有限公司，上海电气电站设备有限公司，中国核工业第五建设有限公司，中国核工业二三建设有限公司，中国核工业第二四建设有限公司，中国第一重型机械股份公司：

中国核工业第二二建设有限公司等7家民用核安全设备焊工焊接操作工考核中心组织的焊工项目考试已经结束（考试编号见附件1）。根据《民用核安全设备焊工焊接操作工资格管理规定》（HAF603），我局组织有关单位进行了审查，现批准向中国核工业第二二建设有限公司等13家聘用单位、金福飞等50位民用核安全设备焊工焊接操作工，颁发民用核安全设备焊工焊接操作工资格证书（基本信息表见附件2），共计89项合格项目。
