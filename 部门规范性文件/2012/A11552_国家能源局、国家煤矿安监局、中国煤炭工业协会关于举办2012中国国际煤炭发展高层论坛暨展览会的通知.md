# 国家能源局、国家煤矿安监局、中国煤炭工业协会关于举办2012中国国际煤炭发展高层论坛暨展览会的通知

## 国家能源局、国家煤矿安监局、中国煤炭工业协会关于举办2012中国国际煤炭发展高层论坛暨展览会的通知（国能煤炭[2012]268号）

各省、自治区、直辖市、新疆生产建设兵团、计划单列市发展改革委（能源局）、煤炭行业管理部门，各省级煤矿安全监察机构，中国煤炭工业协会各成员单位：

由国家能源局、国家煤矿安全监察局、中国煤炭工业协会共同主办，国家安全监管总局国际交流合作中心承办的2012中国国际煤炭发展高层论坛暨展览会，定于2012年10月10日至10月12日在北京举行。现将有关事项通知如下：

**一、**论坛和展览会的主要任务

本届论坛暨展览会的主题是“布局‘十二五’，谋划煤炭工业新发展”，旨在深入贯彻落实科学发展观，大力实施安全发展战略，加快煤炭产业结构优化升级，加速推进大基地、大集团、大煤矿发展战略，促进煤炭循环经济发展，努力实现煤矿安全生产形势持续稳定好转，使我国煤炭工业走上一条健康可持续发展的新型工业化道路。

**二、**论坛和展览会的主要内容

（一）论坛

本届论坛采取大会主旨发言与高层对话相结合的形式进行，邀请国内外40余位嘉宾参与主旨发言和高层对话。大会主旨发言围绕世界煤炭工业与企业可持续发展这一议题展开。高层对话围绕煤矿企业兼并重组、煤炭企业国际化发展、煤炭生产方式变革、煤炭利用方式变革进行讨论。

（二）展览会

展览围绕“布局‘十二五’，谋划煤炭工业新发展”，主要展示三个方面的内容：一是集中展示转变煤炭工业发展方式取得的新成就，主要包括煤炭产业结构调整、煤炭工业循环经济发展和煤炭企业资源整合等；二是展示煤炭企业最新科技成果，主要有煤矿瓦斯综合治理、乏风瓦斯发电、安全高效通风系统、洁净煤技术新发展、直接煤制油技术、间接煤制油技术等；三是展示矿用装备与技术，包括煤炭生产装备及技术、煤炭洗选及加工设备及技术、煤矿运输设备、煤矿安全装备、煤化工装备及技术、矿用防爆产品、矿用仪器仪表等。这些技术与设备既先进又实用，代表了当今国内外煤炭工业科技先进水平。参展的科研机构和企业来自中国、美国、英国、德国、澳大利亚、捷克、波兰等10余个国家和地区，展览面积约30000平方米。

**三、**时间和地点

（一）论坛

时间：2012年10月11日，其中开幕式于10月11日上午9：00举行。

地点：北京昆仑饭店二层昆仑堂（北京朝阳区新源南路2号）。

报到：10月10日14：00-18：00（昆仑饭店二层）。

（二）展览会

时间：2012年10月10-12日，其中开幕式于10月10日上午9：30举行。

参观时间：10月10-11日，9：00-16：30；10月12日，9：00-14：00。

地点：北京全国农业展览馆（北京市朝阳区东三环北路16号）。

**四、**参加人员

（一）参加论坛人员

各省级发展改革委（能源局）、煤炭行业管理部门、煤矿安全监察机构负责人及相关处室负责人；各大中型煤炭企业负责人及相关部门负责人。另请各省级发展改革委（能源局）、煤矿安全监察机构（会同省级煤炭行业管理部门）分别按照附件三的名额组织相关人员参加论坛。

（二）参观展览人员

为充分发挥展览会作为科普教育、科技装备推广和先进发展理念展示平台的积极作用，请各省级发展改革委（能源局）、煤炭行业管理部门、煤矿安全监察局和各大中型煤炭企业积极组织相关人员参观展览。具体安排如下：

1.请各省级发展改革委（能源局）、煤矿安全监察机构（会同省级煤炭行业管理部门）分别按照附件三的名额分配和时间安排，组织本辖区内煤炭企业人员、煤机装备制造企业人员、科研机构和高等院校相关科研人员参观展览会，有关负责同志带队，并指定专门联系人。

2.请各大中型煤炭企业按照附件四的名额分配和时间安排，组织下属各矿、机电处、装备处、通风处、采购中心、安全监察局等相关部门负责人员、科研人员、优秀班组长等参观展览会，企业有关负责人带队，并指定专门联系人。

请各单位于2012年9月20日前将参加论坛报名表、展览会参观回执传真至组委会秘书处（国家安全监管总局国际交流合作中心，地址：北京市东城区和平里北街21号D409房间，邮编：100713）。
