# 国家质量监督检验检疫总局公告2012年第173号——关于防止毛里塔利亚裂谷热传入我国的公告

## 国家质量监督检验检疫总局公告（2012年第173号）

关于防止毛里塔利亚裂谷热传入我国的公告

据世界卫生组织(WHO)11月2日报告，毛里塔利亚暴发裂谷热疫情。今年9月16日至10月30日，共报告裂谷热病例34例，其中死亡17例(病死率50％)。为防止裂谷热疫情传入我国，保护前往毛里塔利亚人员的健康安全，根据《中华人民共和国国境卫生检疫法》及其实施细则的有关规定，现公告如下：

**一、**来自毛里塔利亚的人员，如有寒战、发热、头痛、肌肉痛等症状，出入境时应当主动向出入境检验检疫机构口头申报。入境后1周内出现上述症状者，应当立即就医，并向医生说明近期旅行史，以便及时得到诊断和治疗。

**二、**检验检疫机构应当加强对来自毛里塔利亚人员的体温监测、医学巡查等工作，对申报或者现场查验发现有上述症状的人员应当仔细排查，及时发现可疑病例，严格做好个人防护，按照规定程序采取医学措施。对发现的感染者或者感染嫌疑者，及时通报卫生部门做好疫情调查和处置。

**三、**检验检疫机构应当对来自毛里塔利亚的交通工具、集装箱、货物、行李、邮包实施严格的卫生检疫查验措施，对可能被裂谷热病毒污染的检疫查验对象严格进行除虫、消毒处理。

**四、**检验检疫机构应当加强宣传，增强出入境人员防病意识。前往毛里塔利亚的人员，可以向出入境检验检疫机构及其国际旅行卫生保健中心咨询或登陆国家质检总局网站(http：／／www．aqsiq．gov．cn)卫生检疫与旅行健康专栏，了解该地区的疫情和有关预防方法，特别要注意白天防蚊。旅行中或旅行后发现有相关症状者，应当立即就医。

**五、**裂谷热是人畜共患疾病，人主要是通过接触死于该病动物的血液、器官和组织而感染，其次为蚊子传播。潜伏期约2至6天，症状表现为突然发病，寒战、发热、肌痛，尤其以背部、关节痛和头痛明显。病程后期可并发视网膜炎、脑炎。致死原因多为出血，特别是消化道出血。前往裂谷热病流行区旅行时必须注意防蚊、灭蚊，避免被蚊虫叮咬，避免接触感染动物或病畜尸体。一旦发现上述症状，应当立即就医。

本公告自发布之日起生效。有效期3个月。

2012年11月13日
