# 国家工商行政管理总局关于开展农资市场监管信息化建设的指导意见

## 国家工商行政管理总局关于开展农资市场监管信息化建设的指导意见（工商市字〔2012〕156号）

各省、自治区、直辖市工商行政管理局：

为推进全国工商行政管理机关农资市场监管信息化建设，提高农资市场监管效能，切实维护农资市场秩序，现提出以下意见。

**一、**农资市场监管信息化建设的必要性和原则

农资市场监管信息化建设是加强农资市场监管的重要手段。将农资市场监管与信息技术融合，不断提升信息化建设水平和应用能力，能够有效整合行政执法资源和管理要素，形成监管合力，增强农资市场监管执法的针对性、有效性和预见性，进一步完善农资市场长效监管机制，切实提高农资市场监管的效能和水平。各级工商行政管理机关要充分认识农资市场监管信息化建设的重要性和必要性，进一步增强责任感和紧迫感，统一思想、精心组织，积极采取有力措施推进该项工作。

开展农资市场监管信息化建设必须把握信息化建设的发展规律和农资市场监管的特点，坚持以下原则：一是统筹规划，遵循标准。农资市场监管信息化建设必须要按照总局部署要求，认真研究落实总局制定的《农资市场监管信息化功能指南（试行）》和《农资市场监管数据标准（试行）》（以下简称《指南》和《标准》），明确农资市场监管信息化的指导思想和整体要求，统筹规划，分步实施，开发完善符合总局规范要求的农资市场监管信息化系统，确保农资监管信息化建设的标准统一、功能完善。二是注重整合，资源共享。农资市场监管信息化建设是工商信息化建设的重要组成部分，要注意与已有业务系统的集成与整合，在统一的平台上进行设计开发，避免重复建设，有效发挥工商整体职能作用。三是深化应用，注重实效。要牢固树立建设服从需求，系统重在运用的指导思想，正确处理统一性与实用性的关系，认真分析本地信息化建设情况和农资市场特点，从实际应用和需求出发，开发和完善既符合总局标准规范，又适应当地农资市场监管和信息化建设实际的信息化系统，注意加强该系统的实用性、便捷性和可操作性。

**二、**总体目标

实现全国工商行政管理机关农资市场监管信息化。建立农资市场经营主体数据库；通过农资经营主体、农资商品、市场巡查、案件查处等信息的汇总查询、统计分析，为农资监管提供决策支持；建立健全农资监管政务信息上传下达、横向互通的体系，提高农资监管业务协同联动能力；整合农资市场经营主体准入、农资商品质量检测和经营行为规范等监管信息，提高监管的针对性，加大可追溯监管力度，提升农资市场监管执法效能；利用网站发布农资市场监管动态信息，实现农资市场监管预警。

**三、**主要任务

（一） 农资市场监管信息化系统的开发和完善

各地要按照总局的《指南》和《标准》要求，结合当地实际情况，认真研究提出本地业务需求，开发既具有农资经营主体查询统计、问题商品追溯、农资市场监管预警发布等基本功能，又符合当地农资市场监管和信息化建设实际的农资市场监管信息系统。已建成农资监管信息化系统的要按照总局的《指南》和《标准》的要求进行相应地调整、完善，以符合农资市场监管信息化建设的总体思路和要求。计划单列市、副省级市农资市场监管信息化系统纳入本省的统一建设范畴。

（二）加强数据建设，夯实信息化基础

农资监管数据是农资监管信息化的基础，数据质量是业务应用的保障，要切实加强数据建设。一是加强标准建设。标准是保障互联互通、信息共享的基础和前提，因此根据总局下发的《标准》要求，加大标准执行力度，强化标准在农资监管信息化建设中实施、验收、运维等各个环节的应用，为实现全系统互联互通、资源共享、监管协同、执法联动夯实基础。二是加强数据库建设。数据库建设要紧密依托金信工程，避免重复采集信息和重复建库。要及时采集、更新、汇总数据，加强整合和转换等数据建设环节的技术设计能力。三是加强制度建设。建立健全数据质量责任制度、数据质量监督检查制度、数据质量监测和纠错工作机制，从数据采集的源头抓起，规范数据采集行为，保障数据建设和应用各个方面统一、协调、顺畅、有序地推进。

（三）做好整合对接，保障联网应用工作的顺利开展

农资市场监管信息化建设就是要通过信息共享和协同互动，科学配置行政执法资源，优化管理要素，因此要做好整合对接，保障联网应用。一是加强信息资源整合。农资市场监管信息化建设要充分利用综合业务平台，实现与登记管理、执法办案、企业信用分类监管等业务整合、数据关联，加强信息化整体应用程度，发挥信息化的整体效益。二是要加大业务应用系统整合。按照总局的统一标准要求，加快各地内部应用系统的整合对接，在各地市汇总数据的基础上，实现农资市场监管省级内联网应用，推进跨区域信息查询及联网应用机制，加快应用一体化的发展进程。三是利用总局数据中心的数据交换系统，建成全国农资市场监管信息数据库，逐步实现全国农资市场监管信息资源共享，有效发挥工商系统的整体优势。

**四、**实施步骤

（一）系统开发阶段。省级工商局农资市场监管机构要认真分析本地业务需求、数据来源、用户对象，于2013年1月15日前提出满足本省农资市场监管需要的《需求任务书》，提供给信息化管理机构。省级信息化管理机构要根据农资管理机构提出的《需求任务书》，组织完成需求分析、概要设计，与农资市场监管机构共同完成项目申报，在2013年4月1日前组织完成系统开发。

（二）信息采集阶段。省级工商局下发有关农资市场信息化应用推进工作要求的文件，明确市、县工商局及工商所在该项工作中的任务，于2013年11月底前，完成主要数据、信息的采集、录入工作，并汇总到总局数据中心。

（三）检查调整推进阶段。2013年11月至12月要进行应用系统开发检查和农资监管数据质量检查工作，不断修改完善系统功能、工作流程和工作制度。省级工商局要采取随机抽查、实地考察等方式对各地录入的农资经营主体、质量检测、监管预警等共享信息进行搜索，观摩交流，交叉检查。省级工商局要积极组织推进农资市场监管信息系统应用工作，使之正常应用。

**五、**保障措施

（一）加强组织领导。省级工商局要成立由一把手负总责、分管局长亲自抓、市场监管监管机构牵头负责、信息化管理机构等部门共同参与的农资市场监管信息化建设领导小组，制定周密工作计划，明确各部门分工，协调推进，在资金、技术、人员等方面提供充分组织保障。

（二）加强基层执法人员培训。信息化队伍建设是加强信息化建设的关键，要强化基层工商干部信息化应用培训工作，通过岗位培训和实地指导等多种方式，将信息化知识和技能作为教育培训的重要内容，不断提高干部队伍的信息化素质、工作技能和运用信息技术解决实际问题的能力。

（三）加强监督检查。要建立督导检查机制，制定科学、具体、操作性强的考评指标，定期检查分工职责和目标任务落实情况。采取重点督查、交叉检查等方式，适时派出督导组对农资市场监管信息化建设的完成情况进行检查，确保组织领导、工作任务、工作措施、人员经费等落实到位，农资市场监管信息化建设工作有序开展。

## 第一章　概述

2009年9月，国家工商行政管理总局公布了《农业生产资料市场监督管理办法》（国家工商总局令第45号，以下简称《45号令》），明确了工商机关农资市场职责及有关工作制度。各地工商机关高度重视，按照大力加强“四化建设”，积极推进“四个转变”，牢牢把握“四个只有”，全面实现“四高目标”、努力做到“五个更加”的工作要求，积极开展农资市场监管工作。

据统计，目前全国农资经营户已达40多万户，数量大、分布广、监管任务重，特别是对农资质量问题需要“追踪溯源”十分困难。因此，部分省、市工商机关积极探索以信息化为手段提高农资市场监管水平和履职尽责能力，取得较好的成效。为规范和指导全国工商机关农资市场监管信息化建设和应用工作，根据各地的实践经验和《金信工程总体技术方案》，特制定该指南。

## 第二章　业务需求

**（一）**总局需求

1．行政指导

有关组织、指导文件及工作要求（包括临时统计报表）下发到有关省、自治区、直辖市工商行政管理局（以下简称“省级工商局”），并接收省级工商局的反馈及情况报送；经审查后，总局有关文件及地方局的材料在全国工商系统内部共享，或在相关网站上发布。

2.查询统计分析

总局通过数据中心汇总全国农资市场主体的基本信息和有关监管信息。一是提供查询服务；二是实现全国农资经营主体情况、农资质量监测情况、农资市场专项整治情况、农资案件情况、农资市场监管预警情况的统计汇总；三是为农资市场监管决策提供支持。

**（二）**地方局需求

1.行政指导

省级工商局接收总局文件及工作要求，并反馈办理结果或报送有关情况；省级工商局将有关文件及工作要求逐级下发，并逐级接收办理结果或报送有关情况。

2.查询统计

能够查询本辖区农资经营主体的基本信息，包括主体名称、注册号、主体类型、法定代表人、登记机关、联系电话、地址/住所、经营范围；经营商品的信息，包括所经营农资种类、生产厂家、名称、商标；供货商信息，包括名称、注册号、联系电话、地址/住所等。

实现对辖区内农资经营主体有关情况的统计；实现对辖区内农资经营主体的基本情况、农资市场专项整治情况、农资案件情况、农资市场监管预警情况的统计、汇总、分析。

3.追溯监管

实现在特定区域对任一农资生产厂家、任一商标农资销售网络的全面掌握。

当发现某种农资产品出现质量问题（检测报告列出厂名、商品名称、商标），农资市场监管人员在系统中输入该产品的商标，系统能自动按地域列出辖区内经营该产品的市场主体的分布情况及明细。

4.农资商品质量监测

工商部门依法、依职责对流通环节农资商品质量进行监督检查，对于农资商品质量检测结果，由送检单位或检验机构根据检验报告录入数据。系统应提供数据录入、修改、查询、汇总功能。

5.农资市场巡查

制定、下发巡查任务并记录巡查情况；按照总局《45号令》的要求，检查辖区内农资经营户是否履行有关责任，并记录巡查情况。

## 第三章　建设目标任务及原则

**（一）** 目标

依据相关法律法规，以信息化手段，整合农资经营主体、农资商品和工商部门市场监管等相关信息，提高农资市场监管信息化水平，加强可追溯监管，提升农资市场监管效能。

**（二）** 任务

总局下发《指导意见》（含《功能指南》和《数据规范》），指导地方工商局开展农资市场信息化建设和应用工作；各地按照总局的《指导意见》开展信息化建设，并结合落实属地监管责任，按照“管住批发、规范零售”的原则组织开展农资商品经营信息采集，进一步强化农资市场可追溯监管。

基于综合业务系统建立健全全国农资市场监管政务信息上传下达体系，提高农资市场监管业务协同能力。

基于数据中心实现以农资经营者为主体，关联农资市场主体登记、监管、案件、信用等信息的数据汇总，并实现在此基础上的查询统计分析功能，为决策支持服务。

基于网站发布农资市场监管信息，实现政务公开，为广大消费者服务。

**（三）** 建设原则

1.统筹规划、遵循标准

在《金信工程总体技术方案》的指导下，依托现有的网络环境和支撑平台，遵循全国统一的农资市场监管数据标准，落实总局的工作部署和安排，实现农资市场监管信息化，提高监管效率。

2.注重整合、资源共享

农资市场监管与登记管理、案件查处等系统关系密切，农资市场监管信息化在设计阶段应充分考虑实现本地应用整合、数据关联，将农资市场监管有机整合到本地的综合业务系统中，以便于基层工商部门按照总局《45号令》中要求对辖区内农资经营主体和行为、商品进行监督管理。

3．先易后难，分步实施

在不同类型的经营者经营条件差异较大情况下，先以批发商、连锁经营者为信息采集和监管的重点，实行商品流通信息采集；对处于流通领域终端环节的零售商可分步实施信息采集。

**（一）** 农资市场监管总体功能架构

根据任务要求，全国农资市场监管信息系统由总局系统和省级工商局系统构成，主要功能架构如下图所示：

图1：农资市场监管总体功能架构图（略）

1.总局的应用系统功能

1.1　基于总局综合业务系统建立全国农资市场监管上传下达系统

总局综合业务系统提供了包括通知、公告、专项任务、汇报、报表统计等在内的各类上传下达与业务协同功能，初步形成了全国范围的业务协同机制。总局农资市场监管要以此为基础，实现全国农资市场监管政务信息上传下达和信息发布，包括向下级工商局有关部门部署工作、汇总报表数据，接收下级局报送的任务执行结果和请示、汇报、经验材料等文件，向全国工商系统发布农资市场监管的文件、工作动态（工作研究）、经验材料等。

1.2　基于总局数据中心实现全国农资市场监管数据情况汇总

基于总局数据中心实现以农资经营者为主体，关联农资注册、监管、案件、信用监管等信息，实现在此基础上的查询统计分析功能，为总局领导决策支持服务。

可按照农资经营者主体名称、注册号查询某农资企业的基本情况，所经营的农资品种、以及供货商关联情况；统计某一地区经营所监管的五类农资的经营户数量和名录等

1.3 基于总局网站发布农资市场监管信息

总局有关农资市场监管的文件、宣传材料等，按照政府信息公开有关要求，在总局政府网站上发布。

2.地方局的应用功能

2.1 使用总局综合业务系统中农资市场监管上传下达系统

按照工作要求，指定专人负责总局综合业务系统中农资市场监管上传下达系统，接收总局下发的各类文件、统计报表等，并向总局反馈。

可以使用本省（区、市）综合业务系统向辖区内农资市场监管部门下发文件、统计报表等材料并接收反馈。

2.2 完善本地登记系统，规范农资经营主体的市场准入

根据总局《45号令》的有关规定，目前由工商部门监管的农业生产资料为：“种子、农药、肥料、农业机械及零配件、农用薄膜”五种与农业生产密切相关的农资商品。

在农资市场监管系统设计中，农资经营主体的信息应当包括基本登记信息，所经营农资类别，所经营农资的生产商名称（注册号）、商品名称、商标，供货商名称（注册号）。为了保证数据准确、有效，应充分利用已经建成的市场主体数据库成果，避免重复录入。其中，农资市场主体的基本登记注册信息，生产商名称、注册号，供货商名称、注册号应从现有的数据库中调用，所经营农资类别从代码中选择确定，所经营农资的商品名称、商标由辖区监管人员组织录入。对于数据录入功能的设计，应采用Ajax技术，对于所经营农资商品名称、商标在数据库中已经存在时，以最小的输入量调出结果，确认后入库。主要数据录入界面可参考设计如下：

2.3　完善本地巡查系统，实现农资市场巡查信息化

各地要按照总局的有关要求和规定，在巡查系统中突出重点，完善农资市场巡查的内容，加快实现农资市场巡查的信息化：（1）查经营主体资格；（2）查进货票证；（3）查农资商品；（4）查农资商品包装标识；（5）查农资商品商标广告；（6）查农资商品经营账目。

2.4　采集农资经营者和商品信息，实现农资流向的可追溯

为保证能够及时、有效采集数据，增加农资商品可追溯的可行性，除了在办理注册登记环节标注农资主体信息外，还需要采取由基层工商人员在巡查过程中补充流通环节农资市场监管信息等手段，由基层工商监管人员进一步核实农资市场主体信息并采集农资商品信息，明确该农资经营者的基本信息，包括注册号、名称、所属农资专业市场；连锁经营类型；经营农资类别；所经营农资商品的相关信息，包括名称、商标、生产企业名称、供货商名称。

农资经营的追溯思路是一旦发现有问题农资，在农资市场监管系统的追溯功能中选择该商品的“商标”作为检索条件，检索出经营该商标的经营户基本情况和分布情况，包括经营主体名称、经营场所、法定代表人、联系电话、属地监管工商所、商品名称等，然后到实地了解具体情况，以提高追溯的效率。

2.5　完善本地案件管理系统，实现案件系统和农资市场监管系统的业务联动

目前种子、农药和农业机械及零配件监管已有相应的专门法律和行政法规予以规范，并对监督管理部门及其查处权限予以明确。工商行政管理部门对流通领域农资商品质量违法行为的查处依据：

（1）对违反《种子法》第五十九条和第六十二条规定销售假、劣种等违法行为的，可依据《种子法》的有关规定予以查处。

（2）违法销售假冒伪劣肥料的，依据《产品质量法》的有关规定予以查处。

（3）销售假冒伪劣农药违法的，依据《产品质量法》和《农药管理条例》的有关规定予以查处。

（4）销售不符合国家技术规范强制性要求的农业机械及零配件的，依据《产品质量法》的有关规定予以查处。

工商行政管理部门监督管理农资市场，依据《行政处罚法》、《产品质量法》、《反不正当竞争法》、《无照经营查处取缔办法》、总局45号令等法律、法规和规章的有关规定行使相关的职权、办理案件，办理案件的过程或结果应当纳入案件管理系统。

2.6　完善本地对外发布系统内容，增加农资市场监管信息

按照政府信息公开有关要求，有关农资市场监管的文件、宣传材料等，在本局政府网站上发布。

通过农资市场监管系统的建设使用，形成以省为单位的农资市场监管有关数据库，通过省局数据中心汇总到总局数据中心，供总局和全国工商系统监管人员使用。

## 第五章　总局统计报表要求

3.2.1 CA15 注册号

版本：V1.1

说明：企业登记注册时由登记机关赋予的注册号码。

表示：C15

编码方法：采用GS 15-2006《工商行政管理注册号编制规则》。

3.2.2 CA89 营业执照注册号

版本：V1.0

说明：登记机关赋予农民专业合作社或者农民专业合作社分支机构的注册号码。

表示：C15

编码方法：农民专业合作社营业执照注册号由15位码组成。其中第1位至第6位为登记机关所在地的行政区划代码；第7、8位为识别码，农民专业合作社法人的识别码为NA，农民专业合作社分支机构的识别码为NB；第9位至第14位为数字顺序码，即登记机关赋予农民专业合作社或者农民专业合作社分支机构的顺序号；第15位为固定字母码X。具体编码结构如下：
