# 国家文物局关于瑞士摄制组来华拍摄涉及有关文物的复函(拍摄许可[2012]66号)

## 国家文物局关于瑞士摄制组来华拍摄涉及有关文物的复函（拍摄许可〔2012〕66号）

中华广播影视交流协会：

你协会关于瑞士国家公共电视台（SRF）《新丝绸之路》摄制组来华拍摄专题片涉及文物的函（协字[2012]46号）收悉。经研究，我局同意该摄制组于2012年8月22日拍摄陕西秦始皇兵马俑（坑上拍摄）有关镜头。具体拍摄内容及拍摄方式等事宜请与当地文物部门协商确定。在拍摄过程中，请该摄制组严格服从文物管理人员安排，务必确保文物安全。

国家文物局　　

二〇一二年八月十五日
