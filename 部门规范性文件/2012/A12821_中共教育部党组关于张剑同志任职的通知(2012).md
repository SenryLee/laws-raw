# 中共教育部党组关于张剑同志任职的通知(2012)

## 中共教育部党组关于张剑同志任职的通知（教党任[2012]82号）

中国教育电视台党委：

经中共教育部党组2012年7月16日研究决定，任命张剑同志为中国教育电视台党委书记（试用期一年）。

中国共产党教育部党组

二○一二年七月二十七日
