# 住房和城乡建设部公告第1436号――关于2012年度第十一批绿色建筑评价标识项目的公告

## 住房和城乡建设部公告（第1436号）

关于2012年度第十一批绿色建筑评价标识项目的公告

根据《绿色建筑评价标识管理办法》（建科[2007]206号）、《绿色建筑评价标准》（GB/T50378-2006）、《绿色建筑评价技术细则》（建科[2007]205号）和《绿色建筑评价技术细则补充说明（规划设计部分）》（建科[2008]113号）和《绿色建筑评价技术细则补充说明（运行使用部分）》（建科[2009]235号），我部组织开展了2012年度第十一批绿色建筑评价标识项目评价工作。经审定，福州金融街万达广场（购物中心）等4个项目获得绿色建筑评价标识。

现予公布。

附件：2012年度第十一批绿色建筑评价标识项目

住房城乡建设部
