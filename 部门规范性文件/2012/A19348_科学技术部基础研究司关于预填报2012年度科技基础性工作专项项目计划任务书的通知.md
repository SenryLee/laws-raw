# 科学技术部基础研究司关于预填报2012年度科技基础性工作专项项目计划任务书的通知

## 科学技术部基础研究司关于预填报2012年度科技基础性工作专项项目计划任务书的通知（国科基函[2012]5号）

教育部科学技术司、国土资源部科技与国际合作司、水利部国际合作与科技司、农业部科技教育司、国家林业局科技司、中国科学院计划财务局、国家海洋局海洋科学技术司、国家中医药管理局科技司、总后勤部卫生部科技训练局：

2012年度科技基础性工作专项立项工作已结束，现将拟启动项目及项目经费预算结果反馈给你们，并请你们组织项目承担单位预填报项目计划任务书，有关事项通知如下：

1. 请按照经费预算评审结果调整经费预算，具体要求请参照科技部科研条件与财务司关于经费预算填报的通知。

2. 项目计划任务书的总体目标和考核指标、主要研究内容等必须与项目申报时填写的《项目申请书》内容保持一致，项目预期成果是项目总体目标和考核指标的细化，应具体、明确、可考核。任务书格式见附件。

3. 数据共享应作为考核目标之一写入任务书，内容包括项目结题时要将所取得的科学数据按照科技部要求汇交到指定地点，项目结题验收1年后向科技界无条件开放共享。

4. 重点项目执行期为5年，一般项目执行期为3年，项目起始时间为2012年4月。

5．项目计划任务书格式电子版可从www.most.cn网站“通知通告”专栏下载。

6．请仔细阅读编写说明。

7．请于2012年3月31日前将项目计划任务书报国家科技基础条件平台中心，纸质版一式三份。

编　写　说　明

项目计划任务书必须依据通过综合咨询论证的项目申请书和反馈意见如实填写，不得随意变更内容。

**一、**项目基本信息

1. 项目名称、项目编号以科技部批复的名称为准；

2.执行期限：重点项目为5年，一般项目为3年；

3. 经费预算额为在科技部给定的经费预算额度内所做的实际经费预算额；

4. 第一承担单位为项目的依托单位，是专项经费的拨款单位，应为项目负责人所在单位；

5. 项目主要研究人员是指参与项目组织运行的骨干队伍，不包括博士生和硕士生。

**二、**立项背景、目的和意义

综述国内外研究现状和发展趋势，面临的主要国家需求和问题，简述项目的目的、意义。

**三、**考核指标

必须说明项目任务期内将完成哪些研究任务、所要达到的指标。应提出具体、明确的可考核的指标，避免目标空泛。应将数据共享作为考核目标之一，内容包括项目结题时要将所取得的科学数据按科技部要求汇交指定地点，项目结题验收1年后向科技界无条件共享。

**四、**主要工作内容

根据项目的总体设想，分层次、有条理地具体列出项目的研究内容。

**五、**项目运行机制

项目各参与单位及人员的组织管理形式，保障项目顺利实施并取得最优成果。

**六、**年度计划及考核指标

1. 研究内容要具体说明当年需完成的研究任务。

2. 预期目标要说明所能解决的问题或进展程度，应提出明确的考核指标。

3. 每年将根据上年度考核情况及当年财政情况决定年度拨款或中止拨款。

**七、**项目预期成果

包括项目预期成果及成果提供形式。

**八、**参加人员

1. 即参加项目的所有人员数（包括博士、硕士研究生）。

2. 项目参加人员同期参与承担的国家科技计划项目/课题不得超过两项，其中作为项目/课题负责人只能有1项。

3. 每年工作时间为本人每年参加本项目研究工作的月数。主要研究人员在其它科技计划中承担的年工作量与参加本项目的年工作量的总和不得大于12个月。有些学术骨干的工作时间必须考虑本人所承担的行政领导工作、社会活动等因素，实事求是地填报。

4. 承担单位：单位名称要规范；其承担的主要任务要简述，但必须体现该单位在项目中的作用。

**九．**经费预算

要与《国家科技计划项目预算书》填报的内容一致。

**十、**项目负责人签字

项目负责人应在所有上报的项目计划任务书中亲笔签字。

**十一、**项目依托部门意见

如有两个（或以上）依托部门，要分别签字盖章。
