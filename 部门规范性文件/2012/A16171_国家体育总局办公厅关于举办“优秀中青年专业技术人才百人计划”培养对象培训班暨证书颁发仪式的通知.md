# 国家体育总局办公厅关于举办“优秀中青年专业技术人才百人计划”培养对象培训班暨证书颁发仪式的通知

各省、自治区、直辖市、新疆生产建设兵团体育局，各有关直属单位，各共建体育院校：

为做好国家体育总局“优秀中青年专业技术人才百人计划”培养对象首批人选培养工作，根据年度工作计划安排，定于6月上旬在京举办“优秀中青年专业技术人才百人计划”培养对象培训班暨证书颁发仪式，现就有关事宜通知如下：

**一、**培训时间、地点

时间：6月4日至7日

地点：北京体育大学训练基地

**二、**培训对象

“优秀中青年专业技术人才百人计划”培养对象。

**三、**培训形式和培训内容

证书颁发、领导或专家授课、学员研讨等。培训内容及日程安排请见附件1。

**四、**培训经费

培训期间的培训费、食宿费、资料费等由体育总局负担，交通费由各单位自理。

**五、**报名和报到

请各单位于5月25日前将参加培训人员报名表（附件2）传真至体育总局干部培训中心。

请参训人员于6月4日前往北京体育大学运动员公寓B座签到处报到。京内单位参训人员如在6月5日报到，请在当天上午9：00前到达北京体育大学运动员公寓B座签到处报到。

地　址：北京市海淀区中关村北大街信息路48号
