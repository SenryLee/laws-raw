# 国家林业局关于举办中央组织部委托的2012年地方党政领导干部林业产业发展专题研究班的通知

## 国家林业局关于举办中央组织部委托的2012年地方党政领导干部林业产业发展专题研究班的通知（林人发〔2012〕66号）

有关省、自治区、直辖市林业厅（局）：

为推进林业产业与生态建设协调发展，促进林业产业结构调整和转型升级，带动农民实现增收致富，根据中共中央组织部《关于印发〈2012年中央和国家机关有关部委抽调地方党政领导干部参加专题研究班计划〉的通知》（组通字〔2012〕9号）精神，我局定于2012年4月举办林业产业发展专题研究班，现将有关事项通知如下：

**一、**参加人员

有关省（自治区、直辖市）县（市、区、旗）政府分管林业工作的县级领导（名额分配详见附件1）。

**二、**培训内容和方式

培训内容主要为：生态建设理论、“十二五”规划与林业产业发展、林业产业现状与潜力、林业产业政策与趋势、林业产业结构调整和科技创新、林产品市场培育与品牌建设，以及林业安全生产、突发事件应对与危机管理等。

研究班综合采取专题讲座、研讨交流等方式，并组织学员进行林业产业建设现场参观考察。

**三、**培训时间和地点

专题研究班于2012年4月17日至4月26日在江西省南昌市举办，共10天。

**四、**其他事项

（一）参训学员应按要求选派，不能由他人代替。

（二）请参训学员于4月17日8：00至21：00持本人身份证、两张近期2寸免冠照片到江西省南昌市赣江宾馆报到，地址：江西省南昌市八一大道138号，电话：0791-8856888。

（三）如因特殊原因不能参加培训的，须提前向本省省委组织部门提出申请，说明情况，并在开班前3天将省委组织部门同意不参训的函电传我局。

（四）参训学员报到时，请结合本地区林业产业发展工作实际，提出一个较难解决的问题或解决某个困难问题的成功经验，形成1000字以内的交流材料，要求详见附件2。

（五）考核合格的参训学员结业时颁发由我局验印的《培训证书》，学习情况反馈省委组织部。
