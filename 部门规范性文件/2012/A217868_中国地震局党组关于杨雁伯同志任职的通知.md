# 中国地震局党组关于杨雁伯同志任职的通知

中国地震局党组关于杨雁伯同志任职的通知

（中震党发〔2012〕123号）

中共内蒙古自治区地震局党组：

2012年9月11日中国地震局党组决定，并征得中共内蒙古自治区委同意，任命杨雁伯同志为内蒙古自治区地震局副巡视员。

特此通知

中国地震局党组

2012年11月6日
