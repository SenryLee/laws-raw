# 农业部办公厅关于下达2012年农技推广与体系建设专项经费课题研究任务的通知

## 农业部办公厅关于下达2012年农技推广与体系建设专项经费课题研究任务的通知（农办机[2012]39号）

各有关单位：

根据农机化重点技术推广工作的需要，现将2012年农技推广与体系建设专项经费课题研究任务下达给你们，请结合本地区、本单位实际，认真组织开展课题研究。具体要求如下：

**一、**请各单位根据下达的课题任务（见附件1），尽快研究制定出具体方案和项目任务书，并于9月14日前将课题项目任务书（格式见附件2）一式三份报我部审核。

**二、**为使课题成果充分发挥效益，请各单位于12月10日前将研究报告报送我部。研究报告要立足实际，深入调研，内容翔实，分析科学，条理清晰，提出的建议要具有较强的针对性和可操作性。

**三、**请各单位严格按照财政资金使用相关规定支出课题经费。在课题结题时，请及时向我部报送课题经费决算和具体使用情况。

联系人：农业部农机化管理司　　李伟（010-59193310）

附件1： 1. 2012年农技推广与体系建设专项经费课题研究任务表（略）

2. 2012年农技推广与体系建设专项经费项目任务书（略）
