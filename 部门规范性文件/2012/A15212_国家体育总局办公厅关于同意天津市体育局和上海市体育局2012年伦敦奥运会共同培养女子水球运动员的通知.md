# 国家体育总局办公厅关于同意天津市体育局和上海市体育局2012年伦敦奥运会共同培养女子水球运动员的通知

## 国家体育总局办公厅关于同意天津市体育局和上海市体育局2012年伦敦奥运会共同培养女子水球运动员的通知（体竞字[2012]76号）

各省、自治区、直辖市、新疆生产建设兵团体育局，总参军训和兵种部体育局、总政宣传部文体局，有关行业体协：

根据体育总局鼓励和支持有条件的地方体育局承接或与项目管理中心共建部分项目国家队的要求，从2006年起，体育总局游泳运动管理中心委托天津市体育局组建了国家女子水球队，该队在游泳运动管理中心的领导管理下，在天津市体育局具体的组织与保障下，在上海市体育局等全国相关省市的大力支持下，水平有了很大提高。为进一步鼓励相关省市积极支持和配合国家女子水球队做好伦敦奥运会的管理和服务保障工作，争取优异成绩。经研究，同意天津市体育局和上海市体育局2012年伦敦奥运会共同培养女子水球运动员高翱和刘萍。

高翱、刘萍如参加2012年伦敦奥运会女子水球比赛并取得前三名的成绩，其成绩按照各50%分别计入天津市和上海市的奥运会成绩统计中。但两人的奥运会成绩按照第十二届全运会竞赛规程总则相关规定带入第十二届全运会成绩统计时，则只计入两人全运会的注册单位天津市体育代表团，不再计入上海市体育代表团。

特此通知。

国家体育总局办公厅

二○一二年五月三十日
