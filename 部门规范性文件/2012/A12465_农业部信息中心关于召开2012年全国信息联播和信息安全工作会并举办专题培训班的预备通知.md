# 农业部信息中心关于召开2012年全国信息联播和信息安全工作会并举办专题培训班的预备通知

各省、自治区、直辖市农业（农牧、农林）厅（局、委、办）信息中心、新疆生产建设兵团农业局信息中心：

为总结交流全国农业网站信息联播工作经验，探索和完善部省信息联播工作机制，提升农业网络新闻宣传能力；同时，为更好地贯彻落实国家信息安全政策，进一步做好农业行业信息安全等级保护工作，提高信息安全防护能力，经研究，我中心拟于9月中上旬召开2012年全国信息联播和信息安全工作会，并举办专题培训班。现就有关事项通知如下：

**一、**主要内容

1、总结2011-2012年度全国信息联播工作，部署下一步工作；表彰全国信息联播工作先进集体和先进个人；交流省站信息联播工作经验；研讨中国农业信息网部省信息资源共享机制。

2、发布2011年度省级农业行政主管部门网站绩效评估结果和征求2012年度评估指标意见。

3、信息安全等级保护培训，内容包括国家信息安全等级保护有关政策及要求、信息安全等级保护有关标准与规范、信息安全技术培训等。

4、信息员培训，主要包括农业新闻宣传工作培训、农业农村信息化发展培训、网站信息采编和WCM平台运维技术培训等。

**二、**地点

具体地点另行通知。

**三、**日程

9月中上旬，具体时间另行通知。

**四、**参会人员

各省、自治区、直辖市农业（农牧、农林）厅（局、委、办）信息中心和新疆生产建设兵团农业局信息中心分管信息联播工作的领导、信息联播信息员和技术人员、信息安全等级保护联络员各一名；农业部办公厅、市场与经济信息司、信息中心有关领导，受邀专家等。

**五、**经费

差旅费自理。
