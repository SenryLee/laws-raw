# 工业和信息化部关于许继金等3名同志职务任免的通知

## 工业和信息化部关于许继金等3名同志职务任免的通知（工信部任[2012]27号）

江苏省通信管理局：

工业和信息化部党组决定：

许继金任江苏省通信管理局副局长，免去其国家计算机网络应急技术处理协调中心江苏分中心主任职务，任职时间自2012年3月1日党组会决定之日起计算。

免去许二宁、郑亚的江苏省通信管理局巡视员职务，办理退休。

工业和信息化部　

二〇一二年三月三十日
