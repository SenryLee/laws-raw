# 国家测绘地理信息局关于认真学习贯彻十七届中央纪委第七次全会精神的通知

## 国家测绘地理信息局关于认真学习贯彻十七届中央纪委第七次全会精神的通知（国测党发〔2012〕3号）

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司局：

中国共产党第十七届中央纪律检查委员会第七次全体会议于2012年1月8日至10日在北京举行。会议全面贯彻党的十七大和十七届三中、四中、五中、六中全会精神，高举中国特色社会主义伟大旗帜，以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，回顾总结2011年党风廉政建设和反腐败工作，分析当前反腐败斗争形势，研究部署2012年任务。胡锦涛总书记出席全会并发表了重要讲话。中央纪委书记贺国强作了题为《统一思想认识，加大工作力度，坚定不移将党风廉政建设和反腐败斗争引向深入》的工作报告。全会审议通过了《中国共产党第十七届中央纪律检查委员会第七次全体会议公报》（以下简称《会议公报》）。现就学习贯彻十七届中央纪委第七次全会精神通知如下：

**一、**充分认识十七届中央纪委第七次全会的重要意义

十七届中央纪委第七次全会是在全面实施“十二五”规划，深入推进惩治和预防腐败体系建设之际召开的一次重要会议。胡锦涛总书记的重要讲话，从党和国家事业发展全局和战略的高度，全面总结了党风廉政建设和反腐败斗争取得的新成效新经验，科学分析了当前反腐倡廉形势，明确提出了今年党风廉政建设和反腐败工作的总体要求和主要任务，深刻阐述了保持党的纯洁性的极端重要性、紧迫性以及总体要求、工作重点，是对马克思主义党的建设理论的创新和发展，对于指导当前和今后一个时期党风廉政建设和反腐败斗争、全面推进党的建设新的伟大工程、保持党的先进性和纯洁性，对于推动全面做好党和国家各项工作、夺取全面建设小康社会新胜利、开创中国特色社会主义事业新局面，具有重大而深远的意义。各单位各部门要高度重视十七届中央纪委第七次全会会议精神的传达学习和贯彻工作，把广大测绘地理信息党员干部的思想和行动统一到中央的决策部署上来。

**二、**深刻学习领会十七届中央纪委第七次全会精神实质，坚定反腐败斗争必胜信心

学习贯彻十七届中央纪委第七次全会精神，要重点学习胡锦涛总书记的重要讲话精神、贺国强同志所作的工作报告和《会议公报》，正确认识当前党风廉政建设和反腐败斗争呈现出成效明显和问题突出并存，防治力度加大和腐败现象易发多发并存，群众对反腐败期望值不断上升和腐败现象短期内难以根治并存的总体态势；深刻认识我们党反对腐败的坚强意志和坚定决心，充分认识党风廉政建设和反腐败斗争取得的明显成效；深刻认识当前反腐败斗争面临的严峻形势，切实增强忧患意识、危机意识和责任意识；深刻认识中国特色社会主义的政治优势，进一步坚定反腐败斗争必胜的信心；深刻理解、全面把握和认真贯彻胡锦涛总书记关于保持党的纯洁性、建设坚强有力的马克思主义执政党的要求。各单位各部门要深入贯彻落实以人为本、执政为民理念，坚持党要管党、从严治党，充分认识保持党的先进性和纯洁性的极端重要性、紧迫性，突出工作重点，加大工作力度，采取有力措施，确保党风廉政建设和反腐败重点工作抓紧抓好抓出成效。

**三、**以十七届中央纪委第七次全会精神为指导，大力推进测绘地理信息系统党风廉政建设工作

2012年，是实施“十二五”规划承上启下的重要一年，是全面实施测绘地理信息事业发展新战略的落实年、执行年、实干年。做好新形势下测绘地理信息系统的党风廉政建设和反腐败工作，任务艰巨，责任重大。各单位各部门要切实加强领导，精心组织，以十七届中央纪委第七次全会精神为指导，紧紧围绕测绘地理信息事业的中心任务，大力推进测绘地理信息系统党风廉政建设工作。

（一）严明政治纪律，切实加强对中央重大决策、国家局党组部署要求落实情况的监督检查。严格执行党的政治纪律，加强政治纪律教育，引导和督促测绘地理信息系统广大党员、干部讲政治、顾大局、守纪律，自觉同以胡锦涛同志为总书记的党中央在思想上政治上行动上保持高度一致。严格执行组织人事工作纪律，加强对拟提拔干部的廉政考察，加强对干部选拔任用全过程的监督，坚决整治跑官要官、买官卖官等问题。重点对全国测绘地理信息局长会议确定的“服务大局、服务社会、服务民生”方面重大决策部署落实情况的监督检查，坚决纠正有令不行、有禁不止的现象，确保测绘地理信息系统政令畅通。

（二）加强作风建设，进一步密切党群干群关系。切实加强领导机关和领导干部作风建设，通过加强教育、完善制度、强化监督，促使各级领导干部加强党性修养，弘扬良好作风，保持清正廉洁。各级领导干部要认真贯彻党的群众路线，做到立身不忘做人之本、为政不移公仆之心、用权不谋一己之私。加大作风整顿力度，坚决纠正少数党员干部脱离群众、特权观念严重等不良倾向。继续执行中央有关厉行节约、反对铺张浪费的规定，严格“三公”经费预算管理。坚持和发扬党的优良传统，大力弘扬理论联系实际、密切联系群众、批评与自我批评的优良作风，树立和强化群众观点，维护群众利益，密切干群关系，牢固树立以人为本、执政为民的理念。

（三）建立健全制度，大力推进惩治和预防腐败体系建设。深入推进制度建设，进一步深化行政审批、干部人事、国有资产管理等方面的制度改革和创新。要在2011年深入开展廉政风险点排查工作的基础上，坚持标本兼治、综合治理、惩防并举、注重预防，从权力运行的重点环节入手，针对内部管理的薄弱点和问题易发的风险点，构筑制度防线，形成以积极防范为核心、以强化管理为手段的科学防控机制，建立健全符合测绘地理信息工作实际的惩治和预防腐败体系。

（四）突出专项治理，切实解决反腐倡廉建设中群众反映强烈的突出问题。继续深化庆典、研讨会、论坛过多过滥问题专项治理；深化公务用车问题专项治理，切实加强日常监管，积极稳妥推进公务用车制度改革。对已经取得阶段性成果的公款出国（境）旅游、“小金库”等专项治理，抓好巩固成果、建章立制等工作。深入治理党员领导干部在廉洁自律方面存在的突出问题，全面落实廉政准则，认真执行领导干部报告个人有关事项等两项制度，继续整治领导干部违规收受礼金、有价证券、支付凭证、商业预付卡以及违规建房或多占住房、买卖和出租保障性住房等问题。着力解决发生在群众身边的腐败问题，坚决防治侵害群众合法权益问题。

（五）强化监督制约，不断加大查办违纪违法案件工作力度。进一步加大反腐倡廉制度落实力度，提高制度执行力。继续抓好党务公开，深化政务公开，强化对领导干部的监督。认真执行党内监督条例，深化和拓展巡视工作。严肃查处领导干部中以权谋私、贪污贿赂、腐化堕落、失职渎职案件和发生在重点领域和关键环节中的案件，违反政治纪律和组织人事纪律的案件，重大责任事故和群体性事件涉及的腐败案件，测绘地理信息领域商业贿赂案件，违反财经纪律私设“小金库”案件，以及其它严重损害群众利益、政治权益、人身权利的案件。

（六）深化廉政教育，有效提升领导干部廉洁自律和廉洁从政意识。紧紧抓住社会主义核心价值体系这个兴国之魂，认真开展理想信念教育、党性党风党纪教育和从政道德教育，大力加强政治品质和道德品行教育。通过内容丰富、主题鲜明、形式多样的教育活动，引导党员干部讲党性、重品行、作表率，提高党员干部遵纪守法和拒腐防变的意识，增强党员干部廉洁从政的自觉性。认真贯彻落实中纪委等六部门《关于加强廉政文化建设的意见》，将廉政文化建设融入到测绘地理信息文化建设和学习型党组织建设中，使干部职工在廉政文化的熏陶中不断增强自律意识。

（七）重视队伍建设，不断提高纪检监察机关履职能力和服务水平。把加强纪检监察队伍建设作为一项基础工程抓好，建立与测绘地理信息事业迅猛发展相适应的纪检监察组织机构，配齐配强干部队伍，把保持党的纯洁性贯彻落实到纪检监察机关自身建设全过程和各方面，以思想政治建设为重点、以强化内部管理为保障，全面提高纪检监察干部队伍的政治素质、理论水平和业务能力，为落实测绘地理信息系统反腐倡廉各项任务提供组织保障。

（八）召开测绘地理信息系统党风廉政建设工作会议。全面贯彻中纪委七次全会精神和国务院第六次廉政工作会议精神，按照国家测绘地理信息局党组“突出重点，有的放矢，解决问题，讲求实效”的要求，认真总结测绘地理信息系统2011年党风廉政建设和反腐败工作，全面部署2012年目标任务，推动全系统的反腐倡廉建设取得新成效，迈上新台阶。

各单位各部门要把学习贯彻落实胡锦涛总书记重要讲话和十七届中央纪委第七次全会精神作为当前和今后一个时期的重要政治任务，结合学习贯彻中共中央书记处书记、中央纪委副书记何勇同志视察国家测绘地理信息局时重要讲话精神，周密部署、精心组织，统一思想、提高认识，振奋精神、开拓进取，进一步紧密结合测绘地理信息工作实际，以党风廉政建设和反腐败工作的新成效迎接党的十八大胜利召开。

国家测绘地理信息局
