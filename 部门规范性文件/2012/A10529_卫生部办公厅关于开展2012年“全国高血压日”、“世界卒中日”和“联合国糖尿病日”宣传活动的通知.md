# 卫生部办公厅关于开展2012年“全国高血压日”、“世界卒中日”和“联合国糖尿病日”宣传活动的通知

## 卫生部办公厅关于开展2012年“全国高血压日”、“世界卒中日”和“联合国糖尿病日”宣传活动的通知（卫办疾控函〔2012〕867号）

各省、自治区、直辖市卫生厅局，新疆生产建设兵团及计划单列市卫生局：

2012年10月8日是“全国高血压日”，主题是“健康生活方式，健康血压”；10月29日是“世界卒中日”，主题是“关注脑卒中，立即行动”，口号是“认识卒中，倡导关爱；高危筛查，合理干预”；11月14日是“联合国糖尿病日”，主题是“糖尿病教育与预防”，口号是“保护我们的未来”。为提高公众主动防控心脑血管疾病和糖尿病的意识，自觉养成良好的健康行为和生活方式，现就做好“全国高血压日”、“世界卒中日”和“联合国糖尿病日”的宣传活动通知如下：

**一、**各级卫生行政部门要充分认识当前心脑血管病和糖尿病快速增长所带来的严重危害，坚持政府主导，以宣传日活动为契机，主动加强与教育、广电、新闻出版、体育等部门的联系与沟通，充分发挥各级工会、共青团、妇联、科协和各类社会学术团体的优势，有组织地开展公益宣传和社会动员，科学传递高血压、脑卒中和糖尿病防治知识，营造有利于慢性病防治的社会环境。

**二、**各地要根据实际情况，围绕活动主题，制订切实可行的宣传活动方案，扎实地开展集中宣传活动。要将集中宣传与日常宣传相结合，充分发挥获得“国家慢性病综合防控示范区”称号的县（市、区）的示范作用，依托正在开展的“全民健康生活方式行动”，策划和设计好“全国高血压日”、“世界卒中日”和“联合国糖尿病日”的宣传内容，广泛动员全社会主动预防和控制心脑血管疾病和糖尿病。

**三、**各地要充分利用广播、电视、网络、短信、微博等各种媒介，同时深入社区、公园、学校等人员集中场所，通过公益广告、专题节目、集中采访、在线访谈等形式以及开展张贴宣传材料、健康展览、专家讲座、巡回义诊、知识竞赛等多种活动，以群众喜闻乐见的形式广泛宣传心脑血管疾病和糖尿病防控知识，提高居民防控心脑血管疾病和糖尿病的意识和能力，大力倡导和践行健康生活方式。

请及时总结宣传活动情况，于2012年12月15日前将书面总结报我部疾病预防控制局。
