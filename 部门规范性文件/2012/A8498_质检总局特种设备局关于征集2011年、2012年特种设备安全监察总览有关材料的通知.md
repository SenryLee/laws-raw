# 质检总局特种设备局关于征集2011年、2012年特种设备安全监察总览有关材料的通知

## 质检总局特种设备局关于征集2011年、2012年特种设备安全监察总览有关材料的通知（质检特函〔2012〕65号）

各省、自治区、直辖市质量技术监督局，中国特种设备检测研究院，中国特种设备安全与节能促进会，国家客运架空索道安全监督检验中心，总局事故调查处理中心，各有关协会及标委会：

为了翔实记录我国特种设备安全监察工作的发展历史，自1998年开始，我局编撰安全监察工作的史料性年鉴，已出版十一卷《特种设备安全监察总览》。为继续做好此项工作，现开始征集2011年、2012年总览材料。

**一、**上报时间

2012年12月21日前，上报2011年总览材料；2013年3月31日前，上报2012年总览材料。总览材料以书面形式和电子文档同时上报，内容较多的电子文档可分成多个文件夹以邮件形式上报或寄送光盘。

**二、**上报内容

（一）各省、自治区、直辖市质量技术监督局上报材料

1．2011年、2012年特种设备基本情况、主要工作完成情况、应急救援工作情况（2500字左右）。

（1）2011年、2012年在用设备数量（附五年趋势图）；

（2）2011年、2012年安全监察机构、检验机构数量及人员数量；

（3）2011年、2012年一般以上事故起数、死亡和受伤人数，事故起数、死亡人数与上一年相比较增减率，万台事故起数、万台事故死亡人数（附五年趋势图）；

（4）2011年、2012年各类特种设备定检率；

（5）2011年、2012年开展监督抽查、日常安全监察和专项执法检查情况（包括出动人次、检查企业家数、发出安全监察指令书数、行政处罚等内容）；

（6）2011年、2012年主要工作完成情况（突出重点、亮点工作）；

（7）2011年、2012年应急救援工作情况。

2. 正在实施的副省级以上特种设备安全方面的地方法规、规章（表式见附件1），附原件（复印件）及电子文档。

3．2011年、2012年省部级以上领导参加的重大活动、重要批示和题词，附照片及文字说明，题词、批示可用复印件。

4．2011年、2012年省部级以上表彰的先进集体、先进个人（表式见附件2），并附事迹材料、表彰文件、奖状复印件和照片。

5．2011年、2012年重要活动保障情况和突发公共事件及应对措施，提供文字材料并附照片。

6．2011年、2012年开展监督检查、执法检查及重要检验现场照片及文字说明。

7．2011年、2012年科研开展情况及获奖情况（表式见附件3）。

8．2011年、2012年省级安全监察机构、检验机构设置及领导任职名单（表式见附件4）。

9．2011年、2012年重要的国际交流情况。

（二）中国特种设备检测研究院和国家客运架空索道安全监督检验中心上报材料

1．2011年、2012年省部级以上领导参加的重大活动、重要批示和题词，附照片及文字说明，题词、批示可用复印件。

2．2011年、2012年省部级以上表彰的先进集体、先进个人等（表式见附件2），并附事迹材料、表彰文件、奖状复印件和照片。

3．2011年、2012年重要活动保障情况和突发公共事件及应对措施，提供文字材料并附照片。

4．2011年、2012年重要检验现场照片及文字说明。

5．2011年、2012年科研开展情况及获奖情况（表式见附件3）。

6．2011年、2012年机构设置及领导任职名单（表式见附件4）。

7．2011年、2012年重要的国际交流情况。

（三）总局事故调查处理中心上报材料

1．2011年、2012年发生的较大以上事故案例，并附照片。

2．2011年、2012年全国特种设备事故总体情况、原因分析和典型事故案例。

（四）中国特种设备安全与节能促进会、各相关协会及标委会（名单见附件5）上报材料

2011年、2012年工作总结（包括基本情况和重要工作开展情况）。
