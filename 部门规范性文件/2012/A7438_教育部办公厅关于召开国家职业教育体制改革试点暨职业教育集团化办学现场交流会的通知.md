# 教育部办公厅关于召开国家职业教育体制改革试点暨职业教育集团化办学现场交流会的通知

## 教育部办公厅关于召开国家职业教育体制改革试点暨职业教育集团化办学现场交流会的通知（教职成厅函[2012]43号）

各省、自治区、直辖市教育厅（教委），计划单列市教育局，新疆生产建设兵团教育局，有关单位：

我部定于2012年12月18日至19日在河南郑州召开国家职业教育体制改革试点暨职业教育集团化办学现场交流会（会期两天）。现将有关事项通知如下：

**一、**主要任务

深入学习贯彻党的十八大精神，全面落实教育规划纲要，总结交流职业教育体制改革试点和试验区建设工作，研究部署深入推进职业教育改革试点和试验区建设，引导和支持职业教育集团化办学持续健康发展。

**二、**参会人员

1. 各省（区、市）、计划单列市和新疆生产建设兵团教育行政部门分管职业教育（含中等、高等职业教育）、成人继续教育（社会教育、终身教育）工作的负责人及处长；

2. 职业教育教学指导委员会代表；

3. 中等和高等职业院校校长代表；

4. 试点单位代表；

5. 中国职业技术教育学会、中国成人教育协会、中华职业教育社有关负责人；

6. 部分行业、企业、研究机构代表。

**三、**其他事项

1. 各省级教育行政部门确定本单位参会人员的同时，请通知本地区承担职业教育体制改革试点任务的单位代表，遴选开展集团化办学成效较好的中职或高职校长1人与会，并统一填写会议回执，于12月13日前通过电子邮件或传真报至河南省教育厅。

2. 请与会人员于12月17日到河南郑州黄河迎宾馆10号楼（河南郑州迎宾路1号，电话：0371-66778088）报到。如需接站，请在会议回执中注明。
