# 国家质量监督检验检疫总局关于印发《口岸核与辐射监测设备配置及技术功能规范》的通知

## 国家质量监督检验检疫总局关于印发《口岸核与辐射监测设备配置及技术功能规范》的通知（2012年6月6日　国质检卫[2012]288号）

各直属检验检疫局：

现将《口岸核与辐射设备配置及技术功能规范》印发给你们，请遵照执行。《口岸核与辐射设备配置及技术功能规范(试行)》(质检反恐办[2011]6号)同时废止。

附件：口岸核与辐射监测设备配置及技术功能规范

附件：

口岸核与辐射监测设备配置及技术功能规范

## 第一部分　总则

**一、**目的

为加强口岸入境人员、交通工具、货物、集装箱、行李、邮包、快件等核与辐射监测工作，防范放射性物质经口岸非法输入，有效预防、控制和减少放射性物质对国家安全、人员健康、环境保护造成危害和破坏，规范国境口岸核与辐射监测设备的配置、管理、使用和维护，特制定本规范。

**二、**适用范围

本规范适用于口岸核与辐射监测仪器设备的配置、管理、使用和维护。检验检疫机构配置的核与辐射监测仪器设备技术指标应不低于本规范技术要求。

## 第二部分　口岸核与辐射监测设备配置和使用要求

**一、**原则

口岸核与辐射监测仪器设备的配置和使用应遵循：合理配置，规范使用，有效维护的原则。

**二、**仪器设备的种类

(一)个人剂量计(Personal radiation detectors，PRDs)。

是用于佩带在人体躯干用来测定佩带者所受 X或γ辐射外照射个人剂量当量和个人剂量当量率的检测仪器，主要用于核与辐射工作人员的个人防护。

(二)便携式核与辐射监测仪(Hand-held Radiation detectors instruments)。

便携式核与辐射监测仪种类较多，目前常用有以下几种：

1．便携式X和γ剂量率仪(Hand held X and gamma dose rate meter)：用于X和γ辐射剂量率测定的便携式仪器。

2．便携式γ能谱仪(Hand held radionuclide identification devices，RIDs)：有较好的能量响应，可测γ能谱，具有核素识别和定性功能。

3．α、β表面污染检测仪(Alpha／beta surface contamination monitors)：用于物体表面有无放射性物质污染以及污染水平的测量。

4．中子检测仪(Hand held neutron search detectors，NSDs)：用于测量现场中子计数或剂量。

因设计制造不同，以上几种仪器的功能可能会集成在一台便携式放射性监测仪上。

(三)通道式核与辐射监测系统(Fixed radia tion portal monitors，RPMs)：

通道式核与辐射监测系统主要用于车辆(含集装箱)、人员、行李、邮包、快件、货物的放射性监测。通常设置报警阈值实施自动监测，用于初筛检测。根据口岸监测需要，通道式核与辐射监测系统必要时可选配检测中子射线的探测器。

**三、**配置要求

在口岸检验检疫查验场所，应安装通道式核与辐射监测系统，并结合口岸功能和业务实际，还应配备以下仪器设备：

(一)便携式剂量率仪，用于具体剂量率的测量和确定可能的放射性危害程度，

(二)便携式γ能谱仪，用于放射性核素定性：

(三)α、β表面污染检测仪，用于物体表面放射性物质污染的测量：

(四)放射性物质屏蔽箱(收储箱)、隔离栏、隔离带和警示标志等，

(五)个人剂量计、防护用品(包括防护服、眼镜、口罩、塑料台布、可密封的黄色塑胶袋、长柄工具等)。

## 第三部分　仪器设备技术功能的要求

**一、**个人剂量计

个人剂量计应满足如下基本条件：小巧、轻便、坚固耐用，操作简便，适于任何类型的人员使用，连续工作时间长，有单独的声、光、振动报警和静音指示，可给出γ剂量率和累积剂量。

要求报警阈值在全量程范围内可设置，仪器报警时会发出声光或振动报警，并按下表进行设置：

```
┌──────────┬────────────┬──────────┐

│　报警级别　　　　　│　　剂量率　　　　　　　│　累计剂量　　　　　│

├──────────┼────────────┼──────────┤

│　异常报警　　　　　│　当地本底3倍值　　│　　1mSv　　　　　　│

└──────────┴────────────┴──────────┘
```

具体技术参数需满足如下条件：

(一)当量剂量率测量范围：0．01μSv／h～10m Sv／h；

当量剂量测量范围：0．01μSv～9．9 Sv，在量程范围内连续可设；

(二)能量响应：50 keV～2MeV；

(三)电源：满足工作需要。

(四)工作环境温度：-25℃～40℃；湿度0～95％；压力84-106．7kPa。

(五)防护水平：IP54。

(六)重量和尺寸：适合佩戴。

**二、**便携式核与辐射监测仪

便携式X和γ剂量率仪、γ能谱仪的剂量率报警值可参照个人剂量计设置。

根据不同测量功能和对象，应分别满足相应的技术参数。

(一)便携式X和γ剂量率仪。

1．具有剂量率测量功能；

2．能量探测范围：30keV～3 MeV；

3．剂量率量程为10nSv／h～10mSv／h；

4．灵敏度技术指标达到IEC62327、IAEA核安保丛书IAEA Nuclear Security Series No．1《Technical and Functional Specifications for Border Monitoring Equipment》中相关的要求；

5．具有报警提示功能，声响频率与计数率呈正比，具有静音功能；

6．报警阈值可以调节；

7．具有最大剂量率锁定功能；

8．具有储存报警记录功能；

9．提供工业级别接口；

10．可进行软件升级；

11．电池满足工作需要；

12．工作环境温度：-25℃～40℃：湿度： 0～95％，不结露；

13．设备防护等级：IP53。

(二)便携式γ能谱仪。

1．采用高灵敏度、具备能量分辨功能的探测器，具有核素识别和能谱分析功能；

2．探测器的分辨率，对于137Cs(662keV)，能量分辨率≤8％；

3．能量探测范围覆盖30keV～3MeV；

4．至少采用1024道MCA软件平台；

5．内置核素库，包括工业、医用、天然和特殊核材料，可对核素种类进行鉴别；

6．用户可自定义核素库；

7．灵敏度技术指标达到IEC62327或IAEA核安保丛书IAEA Nuclear Security Series No．1《Technical and Functional Specifications for Border Monitoring Equipment》中相关的要求；

8．有自稳谱功能；

9．提供工业级别接口；

10．可进行软件升级；

11．电池满足工作需要；

12．工作环境温度：-25℃～45℃，湿度： 0～95％，不结露；

13．防护等级：IP53。

(三)α、β表面污染仪。

1．探测器类型：半导体、塑料闪烁体或气体探测器，可实现α、β同时测量，或α、β单独测量；

2．探测器探测面积：不小于100c㎡；

3．探测效率：14C大于10％，90Sr／Y-90大于 30％；Am-24α大于15％；

4．本底：α不得高于0．1cps，β／γ不得高于30cps；

5．计数率测量范围：α：0～100000cps；β：0～100000CpS；

6．具有储存报警记录功能；

7．提供工业级别接口；

8．单位：cps、Bq或Bq／c㎡；

9．电池满足工作需要，

10．工作环境温度：-25℃～45℃，湿度：0～95％，不结露。

(四)中子检测仪。

1．采用3He正比计数器或其他中子探测器，具有对中子射线计数测量功能，

2．灵敏度技术指标达到IAEA核安保丛书 IAEA Nuclear Security Series No．1《Technical and Functional Specifications for Border Monitoring Equipment》中相关的要求；

3．具有报警功能；

4．具有储存报警记录功能；

5．提供工业级别接口；

6．电池满足工作需要；

7．工作环境温度：-10℃～45℃，湿度： 0～95％，不结露；

8．防护等级：IP53。

**三、**通道式核与辐射监测系统

通道式核与辐射监测系统报警阈值在全量程范围内可设置，仪器报警时会发出声光或振动报警，并按下表进行设置：

```
┌─────────┬───────────────┬───────────────┐

│报警级别　　　　　│国质检卫[2010]424号　　　│　IAEA安全丛书　　　　　　　　│

├─────────┼───────────────┼───────────────┤

│　　　　　　　　　│　　　　　　　　　　　　　　　│增加本底4σ(标准方　　　　　　│

│报警域值　　　　　│3倍当地本底　　　　　　　│　　　　　　　　　　　　　　　│

│　　　　　　　　　│　　　　　　　　　　　　　　　│差)值　　　　　　　　　　│

└─────────┴───────────────┴───────────────┘
```

检验检疫机构应根据不同监测功能和对象，配置相应的通道式核与辐射监测系统，配置的监测系统应分别满足相应的技术参数。

(一)行人通道式核与辐射监测系统。

主要用途：安装在海港、空港、陆港等口岸旅客入境通道上，探测行人及其随身携带行李物品中是否携带放射性物质。对放射性超标而报警的旅客进行拍照取证，具有核与辐射监测初筛功能。

功能环境(例如温度、湿度、电源电压等)：抗干扰能力强，能够在一般的自然环境工作。

1．工作环境温度：-25℃～40℃；

2．供电：220V／50Hz交流电；

3．相对湿度：0～95％，不结露；

4．防护等级：IP53。

技术与性能要求：

1．应符合国家标准《放射性物质与特殊核材料监测系统》GB／T 24246-2009或IEC 62484或IAEA核安保丛书IAEA Nuclear Security Series No，1《Technical and Functional Specifications for Border Monitoring Equipment》；

2．能量响应范围：30keV～3MeV；

3．中子能量响应范围：热中子～14MeV；

4．伽玛探测灵敏度：在当地平均本底水平下，报警时间设置为1秒，行人通过速度为1．2m／s，计数增加本底水平的4倍σ(标准方差)时能稳定探测；

5．中子探测灵敏度：对发射率为12000 n／s的252Cf中子源，在距中子监测仪表面参考点1．5m处时，3He正比计数管探测器给出的净计数不应小于12计数／秒；

6．误报率：报警阈值设置在3倍当地本底时，非放射性物质或非特殊核材料引起的监测系统报警在10000次测试中不应大于5次；

7．监测区域高度0～2m，宽度不小于1．2m；

8．标准通过速度1．2m／s；

9．具有报警功能；

10．报警阈值用户可调；

11．支持数据动态链接；

12．模块化设计，方便拆装，易于扩展、定制和维护；

13．有本地声光报警和数据存储，可实现实时无人值守自动监测。

仪器硬件：

1．γ探测器。

(1)γ探测器类型：高探测效率的塑料闪烁体或等效探测器；

(2)塑料闪烁体总体积：≥15L；碘化钠闪烁体总体积≥5L；

(3)非探测面需使用屏蔽技术(不低于8mm铅屏蔽或等效措施)以保证对本底的有效屏蔽；

(4)具备γ探测器自检功能。

2．中子探测器。

(1)中子探测器类型：3He正比计数管或其它中子探测器；

(2)中子探测器数量：≥1个。

3．抓拍摄像系统。

(1)像素≥640×480；

(2)最大帧率≥30帧／秒。

4．远程监控平台。

具有远程监控平台，通过运行其上的专用软件，数据库等实现对本地核与辐射监测系统进行远程监测，测量结果显示，数据同步、存储、备份，数据统计分析，系统控制及维护，远程参数设置，故障诊断等；

专用软件要求：

1．需有全中文应用软件及配套的用户手册；

2．可实时显示数据曲线与阈值曲线；

3．应有历史记录统计分析能力，可根据不同的条件(如是否监测，是否报警等条件)进行记录的查询，统计，图表分析等。

(二)行李、邮包、快件通道式核与辐射监测系统。

主要用途：安装在海港、空港、陆港等口岸行李、邮包、快件入境通道上，监测行李、邮包、快件是否携带放射性物品。对因放射性超标而报警的行李、邮包、快件进行拍照取证，具有核与辐射监测初筛功能。

功能环境(例如温度、湿度、电源电压等)：抗干扰能力强，能够在一般的自然环境工作(室外条件恶劣的扩展到与当地极限气候相一致)：

1．工作环境温度：-25℃～40℃；

2．供电：220V／50Hz交流电；

3．相对湿度：0～95％，不结露；

4．防护等级：IP55。

技术与性能要求：

1．应符合国家标准《放射性物质与特殊核材料监测系统》GB／T 24246-2009或IEC62484或 IAEA核安保丛书IAEA Nuclear Security Series No．1 《Technical and Functional Specifications for Border Monitoring Equipment》；

2．伽玛能量响应范围：30kev～3MeV；

3．中子能量响应范围：热中子～14MeV；

4．中子探测灵敏度：对发射率为12000n／s的 252Cf中子源，在距中子监测仪表面参考点1．5m处时，中子探测器给出的净计数不应小于12计数／秒；

5．误报率：报警阈值设置在3倍当地本底时，非放射性物质或非特殊核材料引起的监测系统报警在10000次测试中不应大于5次；

6．监测区域高度：0．1m～1m；宽度：不小于1m；

7．标准通过速度1m／s；

8．具有报警功能；

9．报警阈值用户可调；

10．支持数据动态链接；

11．有本地声光报警和数据存储，可实现实时无人值守自动监测。

仪器硬件：

1．γ探测器。

(1)γ探测器类型：高探测效率的塑料闪烁体或等效探测器；

(2)塑料闪烁体总体积：≥15L；碘化钠闪烁体总体积≥5L；

(3)非探测面需使用屏蔽技术(不低于8mm铅屏蔽或等效措施)以保证对本底的有效屏蔽；

(4)具备γ探测器自检功能。

2．中子探测器。

(1)中子探测器类型：正比计数管或其它中子探测器；

(2)中子探测器数量：≥1个。

3．抓拍摄像系统。

(1)像素≥640×480；

(2)最大帧率≥30帧／秒。

4．远程监控平台(可选择)。

具有远程监控平台，通过运行其上的专用软件，数据库等实现对本地核与辐射监测系统进行远程监控，测量结果显示，数据同步、存储、备份，数据统计分析，系统控制及维护，远程参数设置，故障诊断等，监测设备与远程监控平台的历史数据应为自动同步，可即时的存储本地核与辐射监测系统的监测数据，数据库应能备份年度历史数据，保证查询效率，备份后用户仍可以方便的查询已备份的历史数据。

专用软件要求：

1．需有全中文应用软件及配套的用户手册；

2．可实时显示数据曲线与阈值曲线；

3．应有历史记录统计分析能力，可根据不同的条件(如是否监测，是否报警等条件)进行记录的查询，统计，图表分析等。

(三)汽车、火车和集装箱通道式核与辐射监测系统。

主要用途：安装在海港、空港、陆港等口岸汽车、火车和集装箱入境通道上，监测汽车、火车和集装箱中是否携带放射性物品。对放射性超标而报警的汽车、火车和集装箱进行拍照取证，具有核与辐射监测初筛功能。

功能环境(例如温度、湿度、电源电压等)：抗干扰能力强，能够在一般的自然环境工作(室外条件恶劣的扩展到与当地极限气候相一致)：

1．工作温度：-25℃～40℃；

2．供电：220V／50Hz交流电；

3．相对湿度：0～95％，不结露；

4．防护等级：IP65。

技术与性能要求：

1．应符合国家标准《放射性物质与特殊核材料监测系统》GB／T 24246-2009或IEC62484或IAEA核安保丛书IAEA Nuclear Security Series No．1 《Technical and Functional Specifications for Border Monitoring Equipment》：

2．伽玛能量响应范围：50kev～3MeV；

3．中子能量响应范围：热中子～14MeV；

4．中子探测灵敏度：对发射率为12000n／s的 252Cf中子源，在距中子监测仪表面参考点1．5m处时，正比计数管探测器给出的净计数不应小于 12计数／秒；

5．误报率：报警阈值设置在3倍当地本底时，非放射性物质或非特殊核材料引起的监测系统报警在10000次测试中不应大于5次；

6．监测区域高度：0．1m～4．5m：汽车宽度不小于5m，火车宽度不小于6m；

7．车辆、火车标准通过车速不小于8km／h；

8．具有报警功能；

9．报警阈值用户可调；

10．支持数据动态链接；

11．有本地声光报警和数据存储，可实现实时无人值守自动监测。

仪器硬件：

1．γ探测器。

(1)γ探测器类型：高探测效率的塑料闪烁体或等效探测器；

(2)塑料闪烁体总体积：≥100L；碘化钠闪烁体总体积≥50L；

(3)非探测面需使用屏蔽技术(不低于8mm铅屏蔽或等效措施)以保证对本底的有效屏蔽；

(4)具备γ探测器自检功能。

2．中子探测器。

(1)中子探测器类型：正比计数管或其它中子探测器；

(2)中子探测器数量：≥2个。

3．抓拍摄像系统。

(1)像素≥640×480，

(2)最大帧率≥30帧／秒。

4．远程监控平台(可选择)。

具有远程监控平台，通过运行其上的专用软件，数据库等实现对本地核与辐射监测系统进行远程监测，测量结果显示，数据同步、存储、备份，数据统计分析，系统控制及维护，远程参数设置，故障诊断等；监测设备与远程监控平台的历史数据应为自动同步，可即时的存储本地核与辐射监测系统的监测数据，数据库应能备份年度历史数据，保证查询效率，备份后用户仍可以方便的查询已备份的历史数据。

专用软件：

1．需有全中文应用软件及配套的用户手册；

2．可实时显示数据曲线与阈值曲线；

3．可即时显示当前通过车辆的编号及通过速度；

4．若车辆速度超过设定的最大通过速度，软件需有超速报警提示，最大通过速度的参数可根据用户需要调整；

5．若通过的车辆产生了报警，还应在探测记录的基础上额外的增加报警类型和放射性物质在车厢的位置记录；

6．应有历史记录统计分析能力，可根据不同的条件(如是否探测，是否报警等条件)进行记录的查询，统计，图表分析等。

以上所有仪器设备使用要求可按照《关于印发＜口岸核生化有害因子监测技术方案＞的通知》 (国质检卫[2010]424号)执行。

(四)核与辐射监测设备的售后服务与培训基本要求。

1．应免费提供理论和操作技术培训1次，主要内容为设备的基本结构、性能、主要部件的构造及修理，日常使用操作、保养与管理、常见故障的排除，紧急情况的处理等；

2．购买的仪器必须配置中文使用和安装说明，并有权威检测机构出具的仪器鉴定合格报告。

3．保修期至少为1年，保修期过后，按双方协议的优惠价格进行收费。免费质保期内维修人员接到维修通知2个工作日到场实施维护；

4．保修期过后，供货商仍负责仪器维修，如仪器发生故障，接电话通知，工程师3个工作日内到达现场处理，按供货商承诺优惠价格收费。

5．进行精确测量的核与辐射监测设备应该按校准证书有效期进行校准：大型通道式检测设备，应按厂家规定时间进行维护。

**二、**流程描述

(一)利用现场配置的通道式(固定式)核与辐射检测系统对出入境人员、货、行李、邮包、交通工具及集装箱实施放射性监测，暂未配备通道式(固定式)核与辐射检测系统的，应利用便携式核与辐射检测仪器进行监测；

(二)通道式(固定式)核与辐射检测系统报警或利用便携式放射性检测仪器，待检物剂量当量率不小于当地本底3倍应进入排查程序，剂量率剂量率水平如达到危险级别1m距离高于 100μSv／h，或有中子发现，立即启动安全应急响应程序。

(三)首先应利用便携式核与辐射检测仪器进行复测γ辐射剂量当量率值，距待检物表面0．1m处任一点的剂量当量率不小于1μSv／h的，为放射性超标，根据需要再进行放射源定位查找。

(四)利用α／β表面污染仪进行表面污染的测量；

(五)利用γ能谱仪进行核素分析与识别，有条件的进行实验室核素分析实验；

(六)根据剂量率、表面污染、核素识别情况，并通过现场调查等结果确定放射性危害性质，并根据《口岸核生化有害因子监测技术方案》的规定进行处置和报告。

(七)按要求对报警结果做好原始监测记录。
