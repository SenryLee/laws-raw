# 交通运输部、国家质量监督检验检疫总局关于开展交通质检信息共享共用窗口建设和电子闸口推广示范项目的通知

## 交通运输部、国家质量监督检验检疫总局关于开展交通质检信息共享共用窗口建设和电子闸口推广示范项目的通知（交水发【2012】795号）

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），上海市、天津市交通运输和港口管理局，长江、珠江航务管理局，各直属海事局，各直属检验检疫局：

为更好地贯彻落实交通运输部与质检总局签署的《关于加强进出口监管提高口岸工作效率合作备忘录》（以下简称《备忘录》），进一步提升两部门物流信患化水平，加强信患互通共享，提高口岸工作效率，促进综合交通运输体系建设和现代物流业发展，交通运输部和质检总局决定联合开展交通质检信息共享共用窗口（以下简称“共享窗口”）建设和电子闸口推广示范项目。现将有关事项通知如下：

**一、**主要原则及目标

坚持“统筹协调、共建共享、监管有力、服务高效”的原则，开展共享窗口建设和电子闸口推广示范项目，推进交通运输和质检系统信息共享，促进交通运输和物流标准体系建设。用2年的时间，在示范港口率先建成交通质检信息共享共用窗口系统；用3年时间，在主要港口全面推广应用一体化、集约化的电子闸口监管模式，实现信息资源集聚和一站式电子放行管理。

在示范项目取得阶段性成果后，逐步扩大合作规模和范围，进一步深化与其他相关部门的信息交换。同时，适时在部分公路口岸（如友谊关、河口、绥芬河、霍尔果斯等）试点开展国际道路运输口岸管理信息化合作。

**二、**主要任务

综合考虑港口信息化基础、合作情况等因素，首批选取天津、大连、连云港、青岛、上海、宁波、厦门、深圳港8个港口作为共享窗口建设和电子闸口推广项目示范点。主要在以下两个方面开展示范建设工作：

（一）示范建设共享窗口。

优先选择各港口交通电子口岸信息平台（港航EDI中心），并充分利用现有的建设基础，开展共享窗口建设。各相关单位间采用“一点接入”的方式进行数据交换，保证各部门基础交换数据的一致性和完整性。在此基础上建立电子数据交换协议规则，探索以电子单证替代纸面单证，加快进行电子报文格式的国内转化和标准化工作；统一交通运输（海事、港口、引航等）部门与检验检疫部门的申报窗口，搭建部门间的信息传输通道，使企业可基于网络等多种申报方式，实现入境船舶抵港、卫生检疫、引航、港口作业等船舶业务信息的一站式申报和船舶、货物数据在部门间的互通共享；规范业务流程，建立符合各部门审核要求的操作模式，以服务企业和简化手续为原则，认真履行国际公约，实现企业一次录入多个部门共享共用的功能。

（二）示范推广电子闸口监管模式。

参照示范港口的电子闸口放行管理模式建设经验，全面推广电子闸口监管模式。各地应根据业务特点进行货物进出口监管流程的优化和梳理，加快建设港口码头、场站与检验检疫部门间的数据传输通道，通过电子数据的交换和共享实现进出口舱单、电子放行指令、运抵报告、允许入港指令等报文的传输。通过建立和统一业务管理制度、实行电子数据交换、共享信息等措施以实现检验检疫电子闸口管理。具备条件的沿海主要港口，可联合建设和使用检验检疫、危险品等监管场地，充分利用现有的场地资源，促进监管资源的共享和高效利用，避免重复建设。

**三、**工作要求

推进示范项目建设是交通运输和质检两系统紧密合作，进一步增强口岸竞争力的重要举措，是落实国家关于促进物流业健康发展政策措施的具体行动，也是加快建设服务型部门的重要抓手。共享窗口建设和电子闸口推广工作涉及部门多、环节多，任务艰巨，各单位、各部门要高度重视，强化措施，务实高效推进示范项目。

（一）完善保障措施。

各单位、各部门要提高认识，进一步增强责任感、使命感，着力抓好和推动示范项目建设。要加强组织领导，建立由示范港口所在地的交通运输（港口）主管部门、海事管理机构、出入境检验检疫机构、港口企业集团、交通电子口岸分中心（港航EDI中心）及相关部门组成的联合办公机制，明确各部门职责和任务，及时协调解决建设中的难点和重点问题。地方交通运输主管部门要积极争取本级财政的支持，安排专项财政资金支持示范项目建设。

（二）推进数据交换标准体系建设。

交通运输部和质检总局将联合制定发布交通运输质检系统数据交换数据元、货运和集拼汇总报文（电子舱单）交换标准。各地应据此严格采用和执行货物、运输工具、集装箱、旅客相关电子报文标准规范，根据国际海事组织（IMO）便利运输和检验检疫监管的要求，加快制修订货运和集拼汇总报文（电子舱单）、查验指令、检疫处理指令、放行指令等，确保示范项目顺利实施。

（三）加强经验交流和宣传。

各单位、各部门要紧密结合本地实际，加强经验、技术交流。各地要相互学习借鉴成熟、先进的电子闸口和共享窗口建设模式和技术，互相促进，共同发展。加大建设模式、经验、成果和效益的宣传力度，充分调动各方面积极性，为示范项目的实施创造良好的氛围和条件。

各地要主动借鉴示范项目建设成果和经验，根据各自实际情况，积极推进本辖区水路、公路口岸共享窗口和电子闸口建设。
