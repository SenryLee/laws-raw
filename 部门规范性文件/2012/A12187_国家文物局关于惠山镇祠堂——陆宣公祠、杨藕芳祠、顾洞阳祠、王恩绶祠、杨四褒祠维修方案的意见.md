# 国家文物局关于惠山镇祠堂——陆宣公祠、杨藕芳祠、顾洞阳祠、王恩绶祠、杨四褒祠维修方案的意见

## 国家文物局关于惠山镇祠堂--陆宣公祠、杨藕芳祠、顾洞阳祠、王恩绶祠、杨四褒祠维修方案的意见（办保函〔2012〕938号）

江苏省文物局：

你局《关于审批惠山镇祠堂--陆宣公祠、杨藕芳祠、顾洞阳祠、王恩绶祠、杨四褒祠维修方案的请示》（苏文物保[2012]69号）收悉。经研究，我局意见如下：

**一、**工程性质定性为保养维修不准确，应为修缮工程。设计单位不符合相应资质要求。

**二、**方案未达到文物修缮工程应有设计深度，不具备可实施性。应深化完善现状勘察，如补充建筑残损现状实测图，补充建筑传统做法说明及考证等，并依据勘察结果进行有针对性的维修设计。同时应规范文本格式，将现状残损与维修设计内容分开叙述。

请你局组织指导具有相应资质的设计单位编制维修方案，经你局审核后，另行报批。

国家文物局　　

二〇一二年八月十四日
