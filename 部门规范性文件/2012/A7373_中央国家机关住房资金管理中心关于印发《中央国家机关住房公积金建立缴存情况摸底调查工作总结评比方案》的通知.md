# 中央国家机关住房资金管理中心关于印发《中央国家机关住房公积金建立缴存情况摸底调查工作总结评比方案》的通知

资金中心各处（室）：

《中央国家机关住房公积金建立缴存情况摸底调查工作总结评比方案》已经2012年12月6日资金中心办公会议审定通过，现予印发。

2012年12月11日

中央国家机关住房公积金建立缴存情况

摸底调查工作总结评比方案

今年以来，中央国家机关住房资金管理中心（以下简称资金中心）在中央国家机关范围内组织开展了住房公积金建立缴存情况摸底调查工作（以下简称摸底调查工作）。为总结工作成效，表彰先进、鞭策后进，推动中央国家机关一级住房公积金缴存单位（以下简称一级单位）更好地履行职责，实现住房公积金制度全覆盖，根据《关于开展中央国家机关住房公积金建立缴存情况摸底调查的通知》（国管办发〔2012〕20号，以下简称《通知》），拟对摸底调查工作进行总结评比。现结合实际情况，制定本方案。

**一、**评比范围及名额

本次摸底调查工作评比范围为中央国家机关各部门、各中央企业（集团公司）一级单位。重点考评一级单位摸底调查工作的开展和完成情况。拟评选20家优秀单位、30家通报表扬单位。另外，对应评比内容中每一个基本项目分别评选5名专项表扬单位，共20家单位。

**二、**评比内容及方法

评比主要从工作完成情况和主动性发挥情况两个方面进行，具体包括以下5项：

（一）摸底调查工作组织落实情况；

（二）摸底调查工作开展的及时性；

（三）报送资料数据的准确性；

（四）报送材料的全面性和完整性；

（五）主动宣传住房公积金政策，配合资金中心做好住房公积金管理工作，提出合理化意见和建议情况。

其中（一）至（四）项侧重于客观方面为基本项目，分值100分；第（五）项侧重主观方面为加分项目，分值10分。对上述5项分别设定考评指标评分，按照5项综合得分情况进行排名，并对各基本项目得分情况进行单独排名。

**三、**评比标准及分值

（一）基本项目（满分100分）

1. 一级单位组织有力、措施得力、落实到位（分值20分）

（1）指定负责摸底调查工作的专门机构和人员；

（2）按照资金中心要求提交《中央国家机关住房公积金摸底调查专项工作联系表》；

（3）及时向下属单位转发《通知》；

（4）组织协调下属单位举办有关摸底调查工作会议，使各单位明确职责、任务和工作要求；

（5）组织下属单位举办专项培训，系统讲解统计指标内容，培训报表的填报方法和报送程序；

（6）向资金中心告知本单位组织摸底调查工作会议或培训的有关事宜；

（7）积极参加中央国家机关住房公积金摸底调查专项工作会议；

（8）积极参加中央国家机关住房公积金摸底调查专项工作座谈会；

（9）其他工作措施。

2. 及时开展摸底调查工作，按时报送相关数据（分值25分）

（1）及时布置落实摸底调查工作；

（2）及时督促检查下属单位摸底调查工作开展和完成情况；

（3）及时传达摸底调查工作相关会议精神，层层布置落实；

（4）按要求及时汇总数据，并于2012年10月10日前向资金中心报送本单位及下属单位摸底调查数据；

（5）其他及时性要求。

3. 报送数据质量高，数据准确，报送格式正确（分值25分）

（1）报送数据全面、准确、真实、可靠，保证摸底调查工作的真实性和有效性，未出现瞒报、漏报、虚报等情况；

（2）按规定渠道及格式报送数据；

（3）其他准确性要求。

4. 摸底调查报送材料完整，单位范围全面（分值30分）

（1）报送《中央国家机关在京单位住房公积金建立缴存情况统计表》完整；

（2）报送《中央国家机关在京单位人员分类统计表》完整；

（3）报送《中央国家机关在京单位未建立住房公积金人员分类统计表》完整；

（4）报送《中央国家机关在京单位住房公积金缴存基数构成统计表》完整；

（5）存在应建未建、应缴未缴情形的，同时报送单位住房公积金补建补缴方案；

（6）单位报送材料如有表格不能明确反映的情况，同时提交其他相关情况说明；

（7）各一级单位报送的范围包含本单位及下属各级在京单位，做到报送单位范围全面；

（8）其他完整性要求。

（二）加分项目（满分10分）

1. 领导重视，牵头开展工作，及时总结情况（分值6分）

（1）中央国家机关各部门有分管部级领导，中央企业（集团公司）有企业分管领导批示部署工作；

（2）各单位有明确司局级领导牵头开展工作；

（3）及时了解总结本单位及下属单位开展摸底调查工作的相关情况，并向资金中心提交相关情况的书面材料。

2. 主动采取各种措施，正面宣传和报道住房公积金政策（分值2分）

各一级单位除召开摸底调查专项工作的培训会、下发转发相关文件之外，采用多种形式向本单位职工或下属单位正面宣传介绍住房公积金政策。

3. 积极配合资金中心开展住房公积金管理工作，提出合理化意见和建议（分值2分）

积极配合资金中心做好住房公积金管理工作，积极参加资金中心组织的摸底调查征求意见讨论会，介绍本单位住房公积金管理工作的好经验、好做法，主动提出合理化意见和建议。

**四、**组织领导

资金中心成立摸底调查工作评比领导小组，资金中心党委书记王永凤任组长，归集处处长任副组长，综合处、风险处、会计处、信息处处长为小组成员。摸底调查工作评比领导小组办公室（以下简称评比办公室）设立在归集处，负责组织总结评比工作。相关处室抽调人员参加，承担评比打分、汇总、排序等日常工作。

**五、**时间安排

1. 2013年1月31日前，评比办公室组织对一级单位进行评比打分并排序（综合排序和专项排序）；

2. 2013年2月20日前，评比办公室提出各项评比建议名单，由评比工作领导小组拟定候选名单后，报资金中心领导审定；

3. 2013年2月28日前，评比办公室将审定通过的各项评比候选名单在资金中心门户网站进行为期一周的公示；

4. 2013年3月15日前，结合公示反馈意见，评比领导小组将各项评比单位候选名单报资金中心主任办公会议审定，确定最终名单。在住房资金年度工作会议上，对有关单位进行表彰，并给予适当奖励。
