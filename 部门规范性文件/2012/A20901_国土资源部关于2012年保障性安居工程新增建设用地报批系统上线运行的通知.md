# 国土资源部关于2012年保障性安居工程新增建设用地报批系统上线运行的通知

各省、自治区、直辖市国土资源主管部门，新疆生产建设兵团国土资源局：

为贯彻落实党中央、国务院关于2012年度建设700万套保障性住房的部署和全国国土资源工作会议精神，提高2012年保障性安居工程用地报批效率，及时为保障性安居工程提供用地，部完善了建设用地报批相关系统，增加了保障性安居工程用地报批功能，现系统正式发布使用，请各地到国土资源部网站（http：//www.mlr.gov.cn）办事服务 / 下载服务 / 软件下载/ 建设用地软件栏目下载“建设用地电子报盘系统35”软件制作电子报件（软件版本号为2.5.1.16），并登录国土资源部远程申报系统进行申报。
