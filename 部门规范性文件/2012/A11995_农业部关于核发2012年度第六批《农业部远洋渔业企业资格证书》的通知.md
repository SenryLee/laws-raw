# 农业部关于核发2012年度第六批《农业部远洋渔业企业资格证书》的通知

## 农业部关于核发2012年度第六批《农业部远洋渔业企业资格证书》的通知（农渔发[2012]21号）

根据《远洋渔业管理规定》，我部同意授予大连格利特渔业有限公司、大连黄海渔业总公司、宁波大禾远洋渔业有限公司3家企业2012年度农业部远洋渔业企业资格（第六批），并核发《农业部远洋渔业企业资格证书》。请你局收到上述《农业部远洋渔业企业资格证书》后，及时发放到有关远洋渔业企业。

特此通知

农业部

2012年8月20日
