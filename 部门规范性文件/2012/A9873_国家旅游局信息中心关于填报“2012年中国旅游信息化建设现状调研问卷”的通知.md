# 国家旅游局信息中心关于填报“2012年中国旅游信息化建设现状调研问卷”的通知

各省、自治区、直辖市旅游局（委），新疆生产建设兵团旅游局信息中心：

为积极贯彻落实《国务院关于加快发展旅游业的意见》中提出的两大战略目标，更好地推进旅游信息化发展，结合旅游基础数据库项目建设，国家旅游局信息中心拟对国内旅游信息化建设现状进行调研。现下发“2012年中国旅游信息化建设现状调研问卷”（调研问卷的电子版可从国家旅游局官方网站“通知公告”栏中下载），请各旅游行政管理机构信息中心将调研问卷转发至所辖各相关单位（包括地市县旅游局、旅行社、饭店、景区（点）等），并于2012年10月31日前将收集的调研问卷以电子邮件形式上报到国家旅游局信息中心。

望各单位积极配合，共同作好此项工作。
