# 国家质量监督检验检疫总局公告2012年第139号――关于公布伪造变造买卖检验检疫证书企业名单的公告

## 国家质量监督检验检疫总局公告（2012年第139号）

关于公布伪造变造买卖检验检疫证书企业名单的公告

根据《国务院关于进一步做好打击侵犯知识产权和制售假冒伪劣商品工作的意见》（国发〔2011〕37号）要求，结合出入境检验检疫企业诚信管理有关规定，质检总局决定公布第一批严重失信企业（伪造变造买卖检验检疫证书企业）名单。名单如下：

1．莒南县振华工艺包装厂

2．瑞立集团瑞安汽车零部件有限公司

3．温州市金佰克国际贸易有限公司

4．乐清市鑫众进出口有限公司

5．温州安联进出口有限公司

6．绍兴县宏锦来贸易有限公司

7．绍兴县维赛尔纺织品有限公司

8．江门市灏燊贸易有限公司

9．汕头市惠诚酒业有限公司

10．日照恒宝食品有限公司

11．江门波威音响器材有限公司

附件：行政处罚决定书（略）

质检总局　

2012年9月19日
