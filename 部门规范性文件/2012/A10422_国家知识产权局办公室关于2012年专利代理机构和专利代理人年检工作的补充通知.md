# 国家知识产权局办公室关于2012年专利代理机构和专利代理人年检工作的补充通知

各有关地方知识产权局：

在各单位的积极配合下，2012年专利代理人和专利代理机构网上年检工作进展顺利。根据《国家知识产权局办公室关于开展2012年专利代理机构和专利代理人年检工作的通知》（国知办发法字〔2012〕71号）要求，2012年专利代理机构及专利代理人年检的网上申报工作将于9月30日截止。为了确保下一阶段的年检工作顺利完成，请认真做好以下工作：

**一、**对本辖区内专利代理机构的网上申报情况进行检查监督，对于10月1日前尚未提交网上年检申报材料的专利代理机构发出限期整改通知，要求其在10月15日至25日期间登录“专利代理管理系统”（网址http：//dlgl.sipo.gov.cn）填报和提交年检材料，并告知其逾期不改正的结果。对于逾期仍不提交网上申报的专利代理机构我局将给予2012年度年检不合格结论。

**二、**请于10月31日前完成本辖区内全部专利代理机构的年检网上审核工作，并将年检工作总结和专利代理机构初步审核结果汇总表纸件报送我局条法司。

特此通知。

国家知识产权局办公室

2012年9月28日
