# 国家质量监督检验检疫总局关于印发特种设备有关软件评审意见的通知

质检锅函[2003]61号

各省、自治区、直辖市质量技术监督局：

为推动特种设备动态监督管理机制的建立，我局组织专家对江苏等地在用的特种设备安全监察、检验和压力管道普查登记软件进行了评审。现将专家评审意见印发给你们。各地在建立特种设备动态监督管理机制的过程中，按照国家特种设备数据库的要求，可以根据实际工作需要从以上软件中自主选择使用。选用的软件必须确保向国家数据库完整、准确地传输数据。国家数据库的接口规则见附件2。

根据国家质检总局信息系统建设的总体规划，总局正积极开发质量监督综合业务管理系统软件，其中包括特种设备安全监察管理子系统软件。该系统软件开发完成后，可供各地使用。由于目前已有多个软件可供选用，各地不宜再组织开发新的软件，以造成不必要的资源浪费。

各地如有意见和建议，请及时告我局。

附件：1. 专家对各地在用软件的评审意见

2. 特种设备安全监察数据库接口规范

3．特种设备安全监察数据库数据项目基本要求

二00三年九月十九日

## 专家对各地在用软件的评审意见

**一、**江苏省《特种设备综合管理系统》软件的专家评审意见

由江苏省质量技术监督局、苏州市质量技术监督局、苏州市锅炉压力容器检验研究所和上海荣恒信息技术开发公司于1999年开始联合开发的《特种设备综合管理系统》，经软件评审专家组评定，意见如下：

该软件包括了特种设备安全监察与检验两大部分，适用于省、市、县特种设备安全监察管理和检验单位检验业务的管理。监察软件功能基本满足当前对特种设备安全监察管理要求，利用Delphi编程，可采用MSSQL，Sybase Adaptive Server Anywhere7.0数据库平台。该软件具有事故隐患数据设定及搜索预警功能；功能扩展采用插件方式；监察软件覆盖面较广；检验报告书可以由软件用户自定义修改等突出特点。但还需根据新的相关法规、技术规范和国家特种设备数据库的要求，以及公布的数据交换接口规则，进一步修改完善；同时该软件在绘图功能方面存在不足，需进一步完善。

软件目前已有苏州市质量技术监督局、南京市特种设备监督检验所、北京市特种设备检验中心等多家用户。综合各用户意见如下：该软件界面友好简洁，使用方便灵活，系统功能齐全，业务管理贴切，具有智能化的自动评估和出证、多功能的报表打印系统、强大的查询统计、安全的权限管理等功能。软件能够将监察机构和检验机构紧密结合，系统可靠性好，售后服务好。

**二、**福建省《特种设备安全监察检验综合管理系统》软件的专家评审意见

由福建省质量技术监督局和福州创达电子有限公司于2001年3月开始联合开发的《特种设备安全监察检验综合管理系统》，经软件评审专家组评定，意见如下：

该软件包括了特种设备安全监察、检验与企业设备管理三大部分，适用于省、市、县特种设备安全监察管理、检验单位检验业务管理和有关企业设备管理。软件基本满足当前特种设备安全监察及检验管理工作的需要，利用Borland Delphi5.0编程，采用Oracle数据库平台。该系列软件还配套开发了企业版软件，便于数据采集；软件流程控制严格，具有工作进度查询功能等突出特点。但软件还需根据新的相关法规、技术规范和国家特种设备数据库的要求，以及公布的数据交换接口规则，进一步修改完善；同时软件需扩大管理覆盖面，实现各版本基础公用数据共享。

软件目前已有福建省质量技术监督局、福建省特种设备监督检验所和福建9个地市的锅炉科、检验所等用户。综合各用户意见如下：该软件操作简便，系统投入使用后运行正常，能满足监察机构和检验检测单位的管理工作需要。现准备升级增加压力管道、气瓶的普查登记管理内容。

**三、**武汉市《特种设备监察检验信息管理系统》软件的专家评审意见

由武汉市质量技术监督局和武汉瑞得软件产业有限公司于2001年6月开始联合开发的《特种设备监察检验信息管理系统》，经软件评审专家组评定，意见如下：

该软件包括了特种设备安全监察与检验两大部分，适用于一定行政区域内的特种设备安全监察与检验管理。该软件功能基本满足目前对监察与检验管理的要求，利用Delphi7和Cell5.01编程，可采用PowerDesign9.5、DBArtisan7.1数据库平台。该软件具有重大危险源提示，设备状态管理功能深入；图视化显示管理对象效果较好；检验业务采用电子黑板功能等突出特点。但还需根据新的相关法规、技术规范和国家特种设备数据库的要求，以及公布的数据交换接口规则，进一步修改完善；同时，软件需要扩大管理覆盖面，管理流程也有待改进。

软件目前已有武汉市质量技术监督局、宜昌市质量技术监督局、海南省所、吉林省特检中心等多家用户。综合各用户意见如下：软件的使用提高了特种设备安全检验的检验水平和管理水平，规范了特种设备电子台帐，实现了对特种设备检验的动态管理和检验业务局域网内联合办公的目标。

**四、**沈阳市《锅炉压力容器检验管理系统》软件的专家评审意见

由沈阳市锅炉压力容器监督检验所和辽宁星火计算机软件工程有限公司于2000年4月开始联合开发的《锅炉压力容器检验管理系统》软件，经软件评审专家组评定，意见如下：

该软件功能能够满足锅炉压力容器检验单位要求，软件利用PowerBuilder5.0和6.0版编程，可采用MS-SQLserver、sybase、oracle数据库平台，该软件基本包括锅炉压力容器检验单位管理的全部管理内容，绘图功能实用；并具有锅炉压力容器使用单位电子地图等特点。但还需根据新的相关法规、技术规范和国家特种设备数据库的要求，进一步修改完善，扩大管理覆盖面；同时该软件初始化设计也需进一步完善。

软件目前已有沈阳市锅检所、天津市锅检所、山东省锅检所等30多家用户。综合各用户意见如下：软件面向局域网进行设计，具有可扩充性，可以和监察部门的普查登记数据库进行数据交流，是一个全面的信息化管理平台。报告门类齐全并将各种报告在同一框架内进行统一管理，检验报告由微机出具，提高了质量。开发了专用的设备简图程序，实现了通过密码或指纹进行电子签名。

**五、**吉林市《压力管道普查登记管理系统》软件的专家评审意见

由吉林市锅炉压力容器检验研究所于2003年开始开发的《压力管道普查登记管理系统》，经软件评审专家组评定，意见如下：

该软件适用范围为省、市、县压力管道普查登记与检验管理。监察管理方面适用于压力管道设计、制造、安装、修理、改造等单位管理和压力管道普查、使用登记管理及远程动态管理。检验方面适用于工业管道的定期检验及在线检验管理。

软件功能基本满足各级监察机构对压力管道普查与登记方面的管理要求。工作流程能清晰体现，提供了必要的压力管道统计分析功能。可为省级及省级以下监察及检验管理工作提供信息支持。软件利用PowerBuilder7.0编程，采用Access2000数据库平台。但该软件还需根据国家特种设备数据库的要求，以及公布的数据交换接口规则，进一步修改完善；同时该软件查询和公制英寸转换功能有待完善，另外，该软件绘图功能需采用第三方工具完成。

软件目前已有吉林、湖南、陕西、山西等用户。综合各用户意见如下：该软件通过分布式应用和WEB应用使各相关单位的业务交流更加方便快捷。将普查与检验紧密结合，实现数据共享及动态更新，并为管理者提供尽可能丰富的设备信息。通过全字段的自动记忆、数据维护及灵活的数据整理、复制等功能大大提高了录入效率及质量。丰富的统计功能及简洁清晰的导航界面便于使用者对数据的分析和漫游。

**六、**广州市《特种设备安全监察管理系统》软件介绍

由广州市质量技术监督局和万户网络资讯有限公司开发的《特种设备安全监察管理系统》，包括了特种设备安全监察与检验两大部分，该软件系统采用B/S结构设计，JAVA开发，采用ORACLE数据库平台。具有技术体系先进，无需安装客户端，实施费用低，内外网统一规划、通过统一门户提供互联网公众信息发布，支持多媒体信息发布等特点。同时，具有错误数据的过滤、筛选功能。但该系统还需根据新的相关法规、技术规范和国家特种设备数据库的要求，以及公布的数据交换接口规则，进一步修改完善，扩大管理覆盖面；同时，由于该系统开发时间较短，软件部分功能还需扩展完善。

目前《特种设备安全监察管理系统》已经在广州市质量技术监督局以及十三个分局和广州市锅检所使用。综合各用户意见如下：该系统界面美观、操作简单，系统结构及设计先进合理，功能多样，较好满足实际工作需要，特别是查询功能齐全，保密性能好，使用方便实用，提高了工作效率。
