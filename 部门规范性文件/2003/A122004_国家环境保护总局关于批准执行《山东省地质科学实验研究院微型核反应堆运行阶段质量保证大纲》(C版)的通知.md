# 国家环境保护总局关于批准执行《山东省地质科学实验研究院微型核反应堆运行阶段质量保证大纲》(C版)的通知

山东省地质科学实验研究院：

我局组织有关单位对你院提交的《山东省地质科学实验研究院微型核反应堆运行阶段质量保证大纲》(C版)[以下简称“质保大纲(C版)”]进行了审查，经过审查你院于2003年8月提交了依审评意见修订后的质保大纲(C版)最终稿，我局认为该质保大纲(C版)是可以接受的，要求你单位在所有涉及微堆核与辐射安全的物项和活动中认真执行该质保大纲(C版)并保证其有效性。

二00三年九月十二日
