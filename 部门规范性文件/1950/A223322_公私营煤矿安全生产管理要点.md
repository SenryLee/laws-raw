# 公私营煤矿安全生产管理要点

公私营煤矿安全生产管理要点

（一九五○年十月二十日政务院财政经济委员会批准　一九五○年十二月一日燃料工业部公布）

**一、**各矿必须指定具有采煤技术经验的员工，依照范围大小及现地情形，组织安全生产委员会或检查小组，负责沼气、煤塵之检查处理，通风管制，水火预防以及一切有关安全生产执行检查事宜，并应经常在井上下巡祖检查，严格执行安全生产之规定。

**二、**各矿井口至少须开两个，绝对禁用独眼井；用立井者，在可能条件下，争取设一斜井作为保安井；所有井口均应安置栏杆或栅栏门。

**三、**新进工人应予短期训练，初次下井，应由有经验的工人带领，在未熟悉井下情形前不准单独工作。

**四、**每班下井工作人员，应有详细登记。

**五、**每井必须设主要入风、出风巷道，整理通风系统，消除漏风、顶风现象，以经常保持供给每人每分钟三立方公尺之风量为原则。

**六、**井内气温须经常保持摄氏二十五度以下，最高不得超过二十八度；沼气（火气）含有率以不超过百分之一点五为原则。

**七、**井下主要通风分流区域及危险地方，应设置太平门；并为防备火灾，应随地准备注水与充填材料。

**八、**地面积水区或洼下处，须建排水沟、防水堤，防备地面之水浸入井下。

**九、**接近断层及老窑发巷等积水区之巷道，应钻探掘进；钻深最少须保持在煤头前十公尺以上，以防透水；在可能情形下，应建筑防水闸及安全门，-并设置水仓，修筑水沟及备用排水设备。

**十、**水患严重之矿，应进行分区採掘，并尽可能先采下山煤。

**十一、**检查人员在放炮前后，应进行缜密之检查，有沼气、有煤尘爆炸之危险处，不得放炮；除历史及试验证明为无沼气、无煤座爆炸危险的矿外，绝对禁用明火灯。

**十二、**无专设人行道之井下楼车运输道，每隔二十公尺须设置避身洞，煤车与天棚须有三十公分以上之问隔，兴侧壁之间，须有五十公分以上之间隔；双轨运输者，车缘与车缘之间隔，不得少于二十公分。

**十三、**斜井及水平巷道内，一概不准坐车，在换班上下工人时，并应停止行车。

**十四、**使用畜力运输者，应于入风井下，建筑马廐，单独通风，保持清洁卫生。

**十五、**坑内各区，应分置便桶，避免随地便溺。

**十六、**罐笼捲扬机须装置罐道绷绳及运输转、制动机等之安全设备，绞车大绳及金属连结物，均须定期检查。

**十七、**卷扬运转速度，不得超过所定之最大速度。

**十八、**为防止冒顶及片帮，应施以适当之支柱或镶砌，保证顶帮之稳固；支柱之式样应视顶底及煤石性质、地层斜度，按照规格制定；如过层落或松流之顶帮，必须在两棚之间，镶顶棍或木板于樑上及腿后。

**十九、**巷道掘进必须跟随煤头架棚子，棚子距工作面不得超过一公尺；并规定木柱小头直径不得小于十二公分。

**二十、**巷道规格暂定如表：

|  |  |  |  |
| --- | --- | --- | --- |
| 風道及上下山 | 單軌巷道 | 雙軌巷道 | 巷道種類 |
| 一·八 | 二 | 二 | 高（公尺） |
| 一·三 | 一·八 | 二 | 上宽（公尺） |
| 一·七 | 二·五 | 三 | 下宽（公尺） |

附注：

（1）上表数字全指外口。

（2）大巷坡度以千分之三至千分之五为原则。

（3）上下山支柱按底板斜度将柱头上耕由一度至九度。

（4）因设备和采煤方法不同，各矿得根据具体情况斟酌修改，但须呈报主管机关备案。

**二十一、**并上下电线应随时检修。

**二十二、**井下应经常准备适当急救药品。

**二十三、**井下腥设置电铃或电话及其他特别信号，以便发生事故时，迅速与井上联系。

**二十四、**地面火药库应与其它建筑物隔离相当距离，并须指派专人负责保管。

**二十五、**各矿应绘制井上下平面圈（注明老窑及废井区）。地面及井下对照图，通风系统图，排水系统图等报主管机关备查。

**二十六、**各矿如有技术问题不能解决时，应请求当地矿业主管机关指导及帮助。

**二十七、**行政、工会共同负责教育职工认识提高保安工作的重要性，切实改进保安设施，严格遵守保安制度。

**二十八、**各矿应根据本要点参考矿上实际情况制定安全计划，并将执行情形按月报告各省、市矿业主管机开。

**二十九、**有关井下须知另订之。

井下须知

**一、**非井下工作人员，不得随便下井。

**二、**下井时不得播带发火的器具及容易引火之物品，如有沼气、煤塵，不得用明火灯。

**三、**禁止光头、赤足、裸体下井。

**四、**禁止进入遮断交通的地方。

**五、**在巷道中行走应注意脚下，并留心顶板，发现危险时，须急速报告关系人员。

**六、**发现稍有火油气陕或其他异状时，须急速报告关系人员。

**七、**除负责员工外，不要触动井下机电设备和其他一切工具。

**八、**在井下工作，须服从监工人员之指导，不准喧哗，不得睡觉。

**九、**进入煤头时，须先叫顶问帮。

**十、**凡大场顶之前多有先兆，即小粒或小块煤落下或大声音；若有此种现象，赶紧避难，滴水煤颐不易辨别，尤应注意。

**十一、**在回采煤头内，场顶的地方，如太危险，可原样不动充填之。

**十二、**对有煤尘而干燥的煤头，要充分喷水。

**十三、**夹石应堆置在一定地方，挖出的煤应全部装车，工具不许散置巷道内。

**十四、**坚守自己工作岗位，不准乱挖。

**十五、**发生灾变时，井内工作人员应沉着遵守监督人员及保安人员之指挥，勿惊慌乱逃。

**十六、**如有发水象征，应就味道、响声及该地顶盘、底板、煤质软硬和附近老窰情况等，仔细分析判断，报告关系人员作适当之处理。

**十七、**沼气爆炸时，井内空气发生反覆震动，其震动渐次加强，音响渐大者，爆炸程度亦大；判断空气震动的由来与方向，暂时可躲入煤柱或水槽之水内，但须注意：

甲、将安全灯心缩小。

乙、将风帘或个人衣服捆好堵塞入风巷道，以防爆炸沼气侵入。

丙、身体伏下，头部下垂。

丁、静待保安人员的处置，或考察情况，选择安全通路出井。

**十八、**井下巷道过有温度增高或有火油臭味须详细检查，如有发火可能时，应密闭或充填之，务使其区域缩小，并注入粘土，彻底消灭之；如火势不大，以砂土或注水消灭之。

**十九、**有自然发火或发水的危险区域，应揭示警标。

**二十、**装填火药时，应严密检查在该处二十公尺以内之沼气量及煤麈状况；重复放炮时尤须注意检查，沼气达百分之一以上时，不得用普通导火线放炮；含有率超过百分之一时，完全禁止放炮；于有煤麈之煤头，须在二十公尺范围以内，充分洒水或撒岩粉，如不除去危险，不得放炮。

**二十一、**放炮时须特别注意通风。

**二十二、**装药用木棒，堵眼用粘土，　一次限两炮，装药要适量。

**二十三、**点火前须告知附近工人躲避于巷道弯曲处，放炮后如不将放炮处清理检查，不准行近。

**二十四、**所有火药、雷管或导火线等，放炮人员须亲自携带，不得委托他人。

**二十五、**不响的炮须进行适当的搜取处理；本班放炮本班清理，不得遗留至下班。

**二十六、**使用煤车时，不可争夺。

**二十七、**推车时于煤车之前挂灯，行进中应时时呼叫，以免碰人撞车。

**二十八、**推车接近风门或惫倾斜之处，应特别留意。

**二十九、**装煤不要太高，禁止随便坐车，煤车掉道应互相帮助抬上，煤斤如有散落，应再行装上。

**三十、**大绳、钩具、链子、插楔等，颇派专人时时检查。

**三十一、**循环式钢绳搬运，前后煤车须采取适当间隔，并注意将煤车与钢绳钦好。

**三十二、**斜井运输不准超过规定车数，不准超过规定速度。
