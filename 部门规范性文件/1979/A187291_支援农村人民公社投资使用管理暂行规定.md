# 支援农村人民公社投资使用管理暂行规定

（一九七九年五月二十一日财政部、农业部发布）

根据党的十一届三中全会原则通过的　《中共中央关于加快农业发展若干问题的决定（草案）》和《农村人民公社工作条例（试行草案）》的精神，为了进一步提高支援农村人民公社投资的使用效果，特制定本规定。

**一、**支援农村人民公社投资是国家安排用于扶持穷社穷队发展生产、增加收入、改变面貌的专项投资,必须专款专用，任何部门和个人都不得截留挪用。

**二、**支援农村人民公社投资的使用范围如下：（１）扶持经济困难的公社、大队，按照党的方针政策和本地资源条件，发展社队企业。（２）扶持穷队（基本核算单位），因地制宜地解决促进增产增收，改变面貌的关键问题，如帮助开展多种经营，增添为改善生产条件提高生产能力所必需的小型农机具和耕畜等。　用于社队企业的资金以不少于一半为宜，用于直接帮助穷生产队的投资也必须切实保证，具体数额由各省、市、自治区革委会按照当地情况研究决定。

**三、**扶持穷社穷队，一定要贯彻集中力量打歼灭战的方针和讲求实效的原则。农业和财政部门对本地区内穷社穷队的支援，要作出全面规划，有计划、 有重点、

分期分批地扶持。在同等条件下，对那些领导有力，奋发图强精神强的穷社穷队，要优先支援。坚决纠正那种撒胡椒面、平均分配资金和其他不讲实效的做法。

**四、**支援农村人民公社投资，目前国家仍作为无偿性质的财政投资。有些地方在扶持发展社队企业方面，对收益较快较大的项目已试行有偿支援， 应进一步总结

经验， 加强管理；收回的投资，一定要作为扶持穷社、穷队办企业的专项资金，

继续周转使用，不得挪作他用。试行有偿支援的具体办法，由各省、市、自治区拟定。

**五、**在各级党委的统一领导下，各有关部门和受援社队都要建立健全经济责任制，狠抓投资效果。各级农业、社队企业部门是支援农村人民公社投资的主管部门，要对资金使用效果负主要责任。各级财政部门应发挥促进和监督作用，积极协助主管部门管好用好这项投资。

穷社穷队应当发杨自力更生精神，资金确有困难，要求国家支援时，必须自下而上申请，提出发展项目和措施，以及达到的经济目标，由公社审查汇总上报县级主管部门和财政部门审核批准。各级主管部门除调查研究、提出方案，协同财政部门合理分配资金外，要共同及时检查投资使用效果， 交流经验， 解决存在问题。基层主管部门年终要编报决算，说明成效，逐级上报。对受援社、队，凡资金使用效果好的，应予表杨，并可继续给予必要的支援；效果不好的，要查明原因，帮助改正；经帮助仍无转变的，应酌情减少或停止扶持，并追究责任。

**六、**支援社队的投资，要贯彻＂确有物资，物资适用，群众欢迎＂的原则。社队需要的物资，要让他们自己选购，不准以＂国家支援和＂钱物结合＂为名，强行推销和分配残次产品或不适用的产品。县财政和主管部门，公社财政或财务部门，要帮助受援单位管好用好国家支援的资金和物资。受援的机具、设备等不经主管部门和财政部门批准，不得变卖或转让。

**七、**必须严肃财经纪律。对于违犯统一的政策规定，截留、挪用国家支援农村人民公社投资资的，必须坚决制止。财政部门和有关主管部门应立即收回和扣回投资指标，银行应停止付款，并应追究责任，严肃处理。对于因计划不周、管理不善造成严重损失浪费和贪污盗窃的，有关人员要负经济和法律责任。

**八、**各省、市自治区财政和主管部门可根据本规定精神， 制订具体实施办法，

经省、市、自治区革命委员会批准后实行，并抄报财政部、农业部、中国农业银行备案。

**九、**本规定自下达之日起执行。过去有关支援农村人民公社投资的规定，凡与本规定有抵触的，以本规定为准。
