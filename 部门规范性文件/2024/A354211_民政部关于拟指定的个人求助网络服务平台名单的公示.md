# 民政部关于拟指定的个人求助网络服务平台名单的公示

根据《中华人民共和国慈善法》、《个人求助网络服务平台管理办法》有关规定，民政部发布了《关于遴选个人求助网络服务平台的公告》，组织开展了个人求助网络服务平台遴选工作。由各有关方面代表组成的评审委员会，依据评审标准，进行了评议，并确定了拟指定的个人求助网络服务平台名单。现公示如下：

|  |  |
| --- | --- |
| **平台名称** | **运营主体** |
| 水滴筹 | 北京水滴互保科技有限公司 |
| 轻松筹 | 北京众意互联网络科技有限公司 |
| 暖心惠民 | 北京暖心惠民科技有限公司 |

公示时间：2024年12月17日至2024年12月23日。

联系电话：（010）58123134。

传　　真：（010）58123110。

公示期间，如对拟指定名单有异议，可通过电话、传真等方式如实反映。反映者须告知或签署本人真实姓名，告知工作单位、联系方式，以便了解核实和反馈情况。
