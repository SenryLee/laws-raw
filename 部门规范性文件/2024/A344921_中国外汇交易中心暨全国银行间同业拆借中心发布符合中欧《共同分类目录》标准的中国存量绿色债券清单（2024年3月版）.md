# 中国外汇交易中心暨全国银行间同业拆借中心发布符合中欧《共同分类目录》标准的中国存量绿色债券清单（2024年3月版）

## 符合中欧《共同分类目录》标准的中国存量绿色债券清单（2024年3月版）

为持续提升中欧《可持续金融共同分类目录》（以下简称《共同分类目录》）在支持绿色金融市场发展、尤其是绿色资本跨境流动中的作用，专家组按《共同分类目录》开展了对2024年2月银行间市场新发行绿债的贴标工作。

本次贴标工作共筛选出4只（支持减缓气候变化活动）绿色债券，总规模45亿元人民币，其中有3只在发行时已认证符合《共同分类目录》。相应的技术标准符合《共同分类目录》中“实质性贡献”技术界定标准。具体情况如下：

表1新增贴标绿债清单

|  |  |  |
| --- | --- | --- |
| **序号** | **债券简称** | **发行规模（亿人民币）** |
| 1 | 24通威GN002(科创票据) | 5.00 |
| 2 | 24南电GN001(碳中和债) | 10.00 |
| 3 | 24三峡新能GN001(碳中和债) | 20.00 |
| 4 | 24重庆轨交GN001(碳中和债) | 10.00 |

2024年2月符合中欧《共同分类目录》的中国存量绿色债券到期4只。具体情况如下：

表2 到期贴标绿债清单

|  |  |  |
| --- | --- | --- |
| **序号** | **债券简称** | **发行规模（亿人民币）** |
| 1 | 21南电GN001 | 20.00 |
| 2 | 21华能GN001 | 10.00 |
| 3 | 21雅砻江GN001 | 3.00 |
| 4 | 21三峡GN001 | 20.00 |

截至2024年2月29日，经专家组认证的银行间市场发行的符合中欧《共同分类目录》的中国存量绿色债券共268只，其中221只在存续期。
