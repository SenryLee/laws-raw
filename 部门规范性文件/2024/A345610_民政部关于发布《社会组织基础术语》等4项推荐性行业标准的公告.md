# 民政部关于发布《社会组织基础术语》等4项推荐性行业标准的公告

## 民政部公告

第567号

## 关于发布《社会组织基础术语》等4项推荐性行业标准的公告

《社会组织基础术语》、《行业协会商会自身建设指南》、《社会服务机构自身建设指南》和《学术类社会团体自身建设指南》4项推荐性行业标准已经民政部批准，现予以发布，自2024年5月1日起实施。

|  |  |  |
| --- | --- | --- |
| **序号** | **标准号** | **标准名称** |
| 1 | MZ/T211—2024 | [社会组织基础术语](https://www.mca.gov.cn/n152/n165/c1662004999979998890/part/18570.pdf) |
| 2 | MZ/T212—2024 | [行业协会商会自身建设指南](https://www.mca.gov.cn/n152/n165/c1662004999979998890/part/18574.pdf) |
| 3 | MZ/T213—2024 | [社会服务机构自身建设指南](https://www.mca.gov.cn/n152/n165/c1662004999979998890/part/18572.pdf) |
| 4 | MZ/T214—2024 | [学术类社会团体自身建设指南](https://www.mca.gov.cn/n152/n165/c1662004999979998890/part/18573.pdf) |

民政部

2024年4月3日
