# 国家遥感中心关于SKAO国际组织职员招聘（2024年第3批）的通知

## 关于SKAO国际组织职员招聘（2024年第3批）的通知

国际大科学工程——平方公里阵列射电望远镜（以下简称SKA）是由全球多国合资建造和运行的世界最大规模综合孔径射电望远镜，其接收面积达一平方公里，为人类认知宇宙提供重大机遇。SKA由政府间国际组织平方公里阵列天文台（以下简称SKAO）负责建设运行，由澳大利亚、中国、意大利、荷兰、葡萄牙、南非、英国、加拿大、法国、德国、印度、日本、韩国、西班牙、瑞典、瑞士等国家参与建设，中国是创始成员国之一。SKAO总部设在英国，台址分设在南非和澳大利亚。

为保证SKA项目的全面开展与顺利实施，SKAO总部近日面向全球招聘相关职位，现将有关事项通知如下：

一、招聘岗位

1.基础设施合同项目经理，Project Manager - Infrastructure Contracts(10293)

根据相关立法、政策和框架，管理SKA中频望远镜基础设施合同和工作包的交付。在矩阵和敏捷开发框架内领导和管理一个中型团队，监督和整合多项活动。为高级管理层或高级项目负责人提供专业建议。将业务目标转化为明确的项目计划，以支持实现项目效益和望远镜交付能力。负责在SKAO和承包商之间建立联系。

项目管理或建筑环境专业的大学学历，或具备同等经验。具备专业的项目或计划管理相关的证书，对相关项目或计划管理的理论原理有深刻的理解。具备在复杂项目中调试和管理产品/服务的经验。具备合同及相关程序和流程管理的经验，能够根据特定项目环境达成一致意见并制定标准。

工作地：南非，开普敦

合同类型：为期3年的固定期限劳动合同

薪酬：约1,000,000 - 1,200,000 南非兰特/年

岗位截止日期：2024年4月8日

2.数据处理软件工程师，Data Processing Software Engineer (10247)

与SKAO软件团队合作，建立和维护射电天文学基本算法库。利用易于理解的科学与计算性能特征构建复杂的分布式管线。在与数据处理架构师协商一致的情况下，作为敏捷软件开发团队的一员工作，与SKAO成员国其他软件开发团队合作。

具备在高性能计算环境中进行分布式数据密集型处理和算法开发的经验，最好是从设计和应用程序开发的角度。具备基准测试、分析和优化技术的经验，尤其是如何构建高性能的I/O和重叠处理管线方面。能够与世界各地的敏捷开发团队合作，实现SKA数据处理的共同愿景。

工作地：英国，柴郡

合同类型：无固定期限劳动合同

薪酬：约60,000 英镑/年

岗位截止日期：2024年4月19日

二、应聘人员登陆SKAO官方网站招聘专栏进行申报：https://recruitment.skao.int/vacancies.html，并同步将个人简历（中、英文）发送至我中心邮箱ska-china@nrscc.gov.cn，邮件主题注明应聘职位编号。
