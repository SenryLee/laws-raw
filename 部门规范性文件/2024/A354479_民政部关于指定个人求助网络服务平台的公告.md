# 民政部关于指定个人求助网络服务平台的公告

## 民政部公告

第576号

## 关于指定个人求助网络服务平台的公告

根据《中华人民共和国慈善法》、《个人求助网络服务平台管理办法》有关规定，民政部按照“自愿申请、依法依规、公平公正”原则，组织开展了个人求助网络服务平台遴选工作。经评审委员会评审和社会公示，指定下列平台为个人求助网络服务平台，现予以公告。

|  |  |
| --- | --- |
| 平台名称 | 运营主体 |
| 水滴筹 | 北京水滴互保科技有限公司 |
| 轻松筹 | 北京众意互联网络科技有限公司 |
| 暖心惠民 | 北京暖心惠民科技有限公司 |

民政部
