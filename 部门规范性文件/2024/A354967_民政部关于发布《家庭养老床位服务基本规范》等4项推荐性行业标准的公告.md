# 民政部关于发布《家庭养老床位服务基本规范》等4项推荐性行业标准的公告

## 民政部公告

第577号

## 关于发布《家庭养老床位服务基本规范》等4项推荐性行业标准的公告

《家庭养老床位服务基本规范》、《养老机构文娱服务安全规范》、《养老机构委托服务规范》和《老年人探访关爱服务规范》等4项推荐性行业标准已经民政部批准，现予以发布，自2025年2月1日起实施。

|  |  |  |
| --- | --- | --- |
| 序号 | 标准号 | 标准名称 |
| 1 | MZ/T 234—2024 | [家庭养老床位服务基本规范](http://www.mca.gov.cn/n2445/n2575/n2578/c1662004999980003053/part/20230.pdf) |
| 2 | MZ/T 235—2024 | [养老机构文娱服务安全规范](http://www.mca.gov.cn/n2445/n2575/n2578/c1662004999980003053/part/20231.pdf) |
| 3 | MZ/T 236—2024 | [养老机构委托服务规范](http://www.mca.gov.cn/n2445/n2575/n2578/c1662004999980003053/part/20232.pdf) |
| 4 | MZ/T 237—2024 | [老年人探访关爱服务规范](http://www.mca.gov.cn/n2445/n2575/n2578/c1662004999980003053/part/20233.pdf) |
