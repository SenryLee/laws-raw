# 商务部公告2005年第113号——2006年重要工业品出口配额总量

## 商务部公告（2005年第113号）

根据《中华人民共和国货物进出口管理条例》的有关规定，现公布2006年重要工业品（原油、成品油、焦炭、稀土）一般贸易出口配额总量。

```
┌──────────┬───────────┬──────────┐

│商品名称　　　　　　│单位　　　　　　　　　│配额总量　　　　　　│

├──────────┼───────────┼──────────┤

│　原油　　　　　　　│万吨　　　　　　　　　│　100　　　　　│

├──────────┼───────────┼──────────┤

│ 成品油　　　　│万吨　　　　　　　　　│　900　　　　　│

├──────────┼───────────┼──────────┤

│　焦炭　　　　　　　│万吨　　　　　　　　　│　1400　　　　　　　│

├──────────┼───────────┼──────────┤

│　稀土　　　　　　　│万吨　　　　　　　　　│　4.5　　　　　│

└──────────┴───────────┴──────────┘
```
