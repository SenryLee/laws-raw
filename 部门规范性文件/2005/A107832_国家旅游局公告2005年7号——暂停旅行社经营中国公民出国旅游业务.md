# 国家旅游局公告2005年7号——暂停旅行社经营中国公民出国旅游业务

## 国家旅游局公告（2005年7号）

招商局国际旅行社有限责任公司、北京神舟国际旅行社集团有限公司、中商国际旅行社、中国民间国际旅游公司、上海商务国际旅行社有限公司等5家旅行社在经营出境旅游业务中，违反《中国公民出国旅游管理办法》的有关规定，造成严重后果。经研究，从即日起暂停以下3家旅行社经营中国公民出国旅游业务：

```
旅行社名称　　　　　　　　　　组团社序号　　　　　许可证号

1、招商局国际旅行社有限责任公司　　　06　　　　　　L-ZY-GJ00011

2、北京神舟国际旅行社集团有限公司　　22　　　　　　L-BJ-GJ00068

3、中商国际旅行社　　　　　　　　　　35　　　　　　L-ZY-GJ00039
```

暂停以下2家旅行社经营中国公民出国旅游业务3个月：

```
旅行社名称　　　　　　　　　　组团社序号　　　　　许可证号

1、中国民间国际旅游公司　　　　　09　　　L-ZY-GJ00004

2、上海商务国际旅行社有限公司　　80　　　L-SH-GJ00023
```

特此公告。
