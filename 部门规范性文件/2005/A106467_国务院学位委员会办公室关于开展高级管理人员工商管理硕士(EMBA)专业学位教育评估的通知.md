# 国务院学位委员会办公室关于开展高级管理人员工商管理硕士(EMBA)专业学位教育评估的通知

## 国务院学位委员会办公室关于开展高级管理人员工商管理硕士（EMBA）专业学位教育评估的通知（学位办[2005]64号）

有关高校：

2002年8月，国务院学位委员会办公室批准北京大学等30所院校开始试办高级管理人员工商管理硕士（EMBA）专业学位教育。为了加强对EMBA教育的规范管理，了解办学情况，总结办学经验，推动EMBA教育水平的不断提高，我办委托教育部学位与研究生教育发展中心开展高级管理人员工商管理硕士（EMBA）专业学位教育评估工作。现就有关事项通知如下：

**一、**评估对象：北京大学等30所试办高级管理人员工商管理硕士（EMBA）专业学位教育的院校。

**二、**评估性质：合格评估。

**三、**评估方式：被评估学校提交试点工作总结报告及相关评估材料；专家组实地考评。

**四、**评估内容：详见《中国高校高级管理人员工商管理硕士（EMBA）专业学位教育评估指标》（见附件一）。

**五、**评估时间：在2005年10月31日前，将试点工作总结报告及相关评估材料报到全国工商管理硕士（MBA）专业学位指导委员会秘书处。从2005年11月开始，专家组实地考评。专家组实地考评具体时间另行安排。

附件一：中国高校高级管理人员工商管理硕士（EMBA）专业学位教育评估指标

|  |  |  |
| --- | --- | --- |
| 序号 | 评估指标 | 评估内容 |
| 1 | 制度建设 | （1） 按要求成立了EMBA领导小组、EMBA教育学术委员会和EMBA招生委员会，并切实发挥了对项目的领导、学术指导和监督作用。 　　（2） EMBA教育目标明确，制定了符合学位办文件要求的EMBA培养方案，培养方案符合EMBA教育目标，能反映EMBA教育的特点。  　　（3） 建立了EMBA项目的管理机构并有效运作。 　　（4） 形成了有效的教学质量保障体系，包括：学生考勤制度；授予学位的学术标准；教学管理规定；教学质量评估制度；学位论文指导、评审与答辩制度；保证教育质量持续改进的反馈机制和激励机制等。 |
| 2 | 招生管理 | （5） 制定了规范的招生考试和录取办法，并严格执行；申请人资格审查、笔试、面试、录取过程严谨、规范、公平。 　　（6） 申请人提交的申请材料完备（报名表、学历证明、专家或单位主管的推荐信、反映本人工作经历或管理经验的相关材料）；笔试试卷、答卷、面试评分表等真实、齐备。 　　（7） 被录取学生的工龄、学历等资格符合学位办文件要求。 |
| 3 | 培养过  程管理 | （8） 教学文件齐备（包括培养方案、课程计划、教学日历、课程教学大纲、相关管理制度文件等）；教学档案完整（包括：学生学籍材料、学生考勤记录、教学质量评估记录、学生考卷、学位论文答辩材料决议等）。 　　（9） 严格执行培养方案、教学计划及有关教学管理规定。教学方案和计划的变动遵循规定的程序。 　　（10）课程教学大纲编写规范，并及时发给学生；课程教学内容体现EMBA教学的要求（内容新颖、联系实际、决策导向、国际视野、课程整合等）；课件完备，教材适用。 　　（11）学位论文指导落实，答辩程序规范，论文要求严格。 　　（12）项目管理机构与学生间沟通渠道通畅，沟通机制有效；学生间交流活跃。 |
| 4 | 师资队伍 | （13）制定了EMBA项目的师资选聘标准和选聘程序，并严格执行。  　　（14）师资队伍的学历结构、实践经验、外聘教师的比例符合国务院学位办文件要求（具有博士学位的教师达到授课教师总数的50%以上；具有企业实践经验的教师达到授课教师总数的80%以上；国外或境外有较好教学声誉的教师达到授课教师总数的30%以上）。 　　（15） EMBA项目授课教师中有一定数量的本校教师，制定了师资队伍建设计划并有相应措施，本校EMBA师资队伍建设卓有成效。 |
| 5 | 教学效果 | （16）学生对课程安排、教学水平和教学效果满意。 　　（17）教学方式得到EMBA学生认可（互动式、学生参与、案例教学）。 　　（18）学位论文格式规范、内容充实、联系实际。 |
| 6 | 教育环境 | （19）学校重视EMBA项目，为EMBA项目发展提供较好的政策环境。 　　（17）教学设施、条件适合于EMBA教育。 |
| 7 | 办学特色 | （21）在教学方式、教学组织、课程体系、教学内容、教学管理、国际合作、学生活动等方面有所创新，项目独具特色。 |
