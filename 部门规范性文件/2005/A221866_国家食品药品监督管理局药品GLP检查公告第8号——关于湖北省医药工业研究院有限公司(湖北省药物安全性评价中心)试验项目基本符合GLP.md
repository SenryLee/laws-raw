# 国家食品药品监督管理局药品GLP检查公告第8号——关于湖北省医药工业研究院有限公司(湖北省药物安全性评价中心)试验项目基本符合GLP要求的公告

国家食品药品监督管理局药品GLP检查公告（第8号）

（国食药监安[2005]28号）

根据《中华人民共和国药品管理法》的有关规定，依据《药物非临床研究质量管理规范》（GLP）及《药物非临床研究质量管理规范检查办法》，国家食品药品监督管理局组织有关专家对湖北省医药工业研究院有限公司（湖北省药物安全性评价中心）实施GLP情况进行了检查。经检查，该机构以下试验项目基本符合GLP要求，现予公告。

```
机 构 名 称　　　　　　　　　　　　　试 验 项 目

湖北省医药工业研究院有限公司　　1．单次给药毒性试验（啮齿类、非啮齿类）；

（湖北省药物安全性评价中心）

2．反复给药毒性试验（啮齿类、非啮齿类）；

3．生殖毒性试验；

4．遗传毒性试验（Ames、微核、染色体畸变）；

5．局部毒性试验；

6．免疫原性试验；

7．安全性药理试验。
```

国家食品药品监督管理局

二○○五年一月二十四日
