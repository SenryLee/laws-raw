# 公开市场业务公告2005[2号]－－关于春节前开展短期逆回购交易的通知

## 公开市场业务公告(2005[2号])

关于春节前开展短期逆回购交易的通知

为保持春节前银行体系流动性平稳，人民银行决定从2月1日起，在公开市场业务交易日，根据实际需求，面向存款类机构一级交易商开展短期逆回购交易。另将2月8日（周二，大年三十）的操作移至2月6日（周日）进行。具体安排如下：

```
┌──────┬────────┬───────────┬───────┬──────┐

│　交易日期　│　　招标时间　　│　招标方式　│　逆回购期限　│　清算方式　│

├──────┼────────┼───────────┼───────┼──────┤

│　 2月1日　 │　13:30－14:30　│　 固定利率数量招标　 │21天│DVP　　│

├──────┼────────┼───────────┼───────┼──────┤

│　 2月3日　 │　13:30－14:30　│　 固定利率数量招标　 │21天│　　DVP│

├──────┼────────┼───────────┼───────┼──────┤

│　 2月6日　 │　13:30－14:30　│　 固定利率数量招标　 │14天│　　DVP│

└──────┴────────┴───────────┴───────┴──────┘
```

请有逆回购需求的存款类机构一级交易商于各交易日9：00－11：00向公开市场业务操作室报告相关信息。

另外，上述三个交易日无央行票据发行和正回购操作。
