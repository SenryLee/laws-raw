# 卫生部通告(卫通[2005]3号)－－发布《X射线计算机断层摄影放射卫生防护标准》等3项标准为强制性国家标准

根据《国家卫生健康委关于发布＜职业性皮肤放射性污染个人监测标准＞等6项标准的通告》，本法规中GBZ 166—2005自2025年6月1日起废止。

## 卫生部通告（卫通[2005]3号）

现发布《X射线计算机断层摄影放射卫生防护标准》等3项标准为强制性国家标准，其编号和名称如下：

GBZ 165-2005　X射线计算机断层摄影放射卫生防护标准

GBZ 166-2005　职业性皮肤放射性污染个人监测规范

GBZ 167-2005　放射性污染的物料解控和场址开放的基本要求

以上标准于2005年10月1日起实施。

特此通告。

二○○五年三月十七日
