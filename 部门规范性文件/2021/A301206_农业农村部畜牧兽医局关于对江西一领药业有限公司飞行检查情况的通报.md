# 农业农村部畜牧兽医局关于对江西一领药业有限公司飞行检查情况的通报

| **事由** | 群众举报 | | |
| **检查发现的问题** | | | |
| 1.消毒剂（液体）/杀虫剂（液体）生产车间已于2020年底拆除，但未及时申请注销相关产品生产范围许可。  2.原料库乳酸环丙沙星、地美硝唑、磺胺间甲氧嘧啶钠、磺胺二甲嘧啶钠4个原料药货位卡显示1月份有出库记录，但没有相关成品的生产记录。  3.黄芪多糖注射液（批号01201201），违规使用外购的黄芪多糖提取物进行生产。  4.右旋糖酐铁注射液（批号01201201），批生产记录显示使用的原料为“20%右旋糖酐铁”，与批准使用的原料药不一致。  5.在液体库发现存放的“10%右旋糖酐铁”（批号为20201010），没有标注生产企业信息。  6.粉剂/散剂/预混剂车间内自动分装机已于2019年1月因故障停用，但停用期间相关产品仍有生产，现场未发现其他分装设备。  7.注射液车间的洗瓶间、灌封间，以及中药仓库等区域管理混乱，现场存放水杯、工作服等物品。  8.飞行检查组现场抽取了该企业生产的乳酸环丙沙星注射液、硫酸镁注射液、复方磺胺间甲氧嘧啶钠注射液、硫酸卡那霉素注射液、对乙酰氨基酚注射液、安乃近注射液、氟苯尼考注射液、氟尼辛葡甲胺注射液、延胡索酸泰妙菌素可溶性粉、右旋糖酐铁注射液、地美硝唑预混剂粉、阿莫西林可溶性粉等12个产品，经中国兽医药品监察所检验，硫酸镁注射液（批号01201101）、复方磺胺间甲氧嘧啶钠注射液（批号01201101）、硫酸卡那霉素注射液（批号01201103）、对乙酰氨基酚注射液（批号01201201）、安乃近注射液（批号01201201）等5个产品可见异物、含量测定等项目不符合规定，判定为不合格产品。 | | | |
| **处理措施** | | | |
| 江西省畜牧兽医主管部门依据《兽药管理条例》，对该公司违法行为进行罚款，没收库存不合格产品，责令该公司召回已销售的不合格产品并对违规生产行为进行限期整改。目前，该企业消毒剂（液体）/杀虫剂（液体）类产品生产许可已注销，并完成了不合格产品召回和违规生产行为整改工作，整改情况已经江西省畜牧兽医主管部门和飞行检查组审核通过。 | | | |
