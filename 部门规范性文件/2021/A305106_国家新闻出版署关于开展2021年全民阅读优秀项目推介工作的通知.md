# 国家新闻出版署关于开展2021年全民阅读优秀项目推介工作的通知

国新出发函〔2021〕198号

各省、自治区、直辖市和新疆生产建设兵团新闻出版局，中央和国家机关各部委、各人民团体出版单位主管部门，中央军委政治工作部宣传局，中央各重点出版集团：

贯彻落实习近平总书记关于推动全民阅读、建设书香社会的重要指示精神，根据《关于促进全民阅读工作的意见》和《关于做好2021年全民阅读工作的通知》有关安排，为总结推广全民阅读活动中涌现的新鲜经验、典型事迹及优秀组织形式，进一步在全社会营造爱读书、读好书、善读书的良好氛围，国家新闻出版署决定开展2021年全民阅读优秀项目推介工作。现就有关申报事项通知如下。

一、申报重点

1. 主题阅读类项目。深入推进习近平新时代中国特色社会主义思想读物的学习阅读，引导广大群众感悟思想力量，感受领袖风范和人格魅力。围绕中国共产党成立100周年，突出爱党爱国爱社会主义主题，以丰富形式、多样手段推动党史学习教育相关阅读工作，推广党史、新中国史、改革开放史、社会主义发展史等重点出版物，使广大群众在阅读中重温百年奋斗历程，汲取伟大精神力量，进一步坚定信仰信念信心。

2. 公共服务类项目。面向基层、深入群众，优化阅读设施配置，改进阅读场所条件，开辟公共阅读空间，整合文化服务资源，有效推进全民阅读进农村、进社区、进家庭、进学校、进机关、进企业、进军营。积极筹措文化惠民、阅读补贴等便民利民措施，切实保障重点和特殊人群的阅读权益，为少年儿童创造良好阅读环境，更好满足农村留守儿童、城市务工人员随迁子女等群体的阅读需求，改进面向残障人士、务工人员等群体的阅读服务，增强人民群众的幸福感和获得感。

3. 社会推广类项目。调动社会各界积极性、主动性、创造性，积极组织社会力量共同参与阅读推广，引导人民群众提升阅读兴趣、养成阅读习惯、提高阅读能力。立足本地特色，挖掘区域资源，强化品牌建设，打造符合当地特点和需求的各类阅读活动，扩大全民阅读覆盖面和传播力，增强全民阅读吸引力和影响力。

4. 数字传播类项目。适应信息技术条件下数据化、移动化、智能化的阅读趋势，主动应用阅读新技术新模式，打造阅读新场景新体验，推进全民阅读的多媒体、多平台融合。探索读者阅读行为和阅读习惯的数字化转型，改善数字内容消费服务方式，为人民群众提供更便捷、更人性化的数字阅读服务。

5. 组织协调类项目。加强全民阅读工作的研究部署、统筹指导和督促落实，精心设计和实施全民阅读活动的各项工作，成果实效显著。着眼长效机制建设，改进全民阅读活动的领导方式和管理方式，探索项目负责制等各种新型管理手段，凝聚各部门各行业全民阅读工作合力。建立全民阅读智库，开展全民阅读理论研究，为深入开展全民阅读提供更多智力支持。

二、申报材料

1.　填写完整并加盖公章的《2021年全民阅读优秀项目申报表》（附件）2份，表格可在国家新闻出版署网站下载。

2.　申报项目材料光盘或U盘1份，内含《2021年全民阅读优秀项目申报表》Word文档及反映申报项目现场效果、特色特点、社会影响等的必要音视频资料。

3.　申报单位近3年无违反新闻出版相关法规的声明1份。

三、申报要求

1.　申报项目应围绕申报重点，大力唱响主旋律、传播正能量，在本地区或本系统具有典型示范意义，具有较好的传播力、影响力。

2.　申报项目须持续开展2年以上，且2021年成效突出。

3.　各省（自治区、直辖市）新闻出版局申报项目不超过3个，其中至少1个应为针对县及县以下读者开展的全民阅读项目。中央和国家机关各部委、各人民团体出版单位主管部门，中央军委政治工作部宣传局，中央各重点出版集团及新疆生产建设兵团新闻出版局申报项目为1个。

4.　申报工作自本通知印发之日起开始，截止日期为2021年10月11日。

四、申报程序

申报单位备齐申报材料后，请送所在地省级新闻出版主管部门，由其筛选把关、出具审核意见后报送至：北京市西城区宣武门外大街40号，中宣部出版局音像电子处（联系人：郭瑞宏、王艺云，联系电话：010-83138421，010-83138866），邮编：100041。中央在京单位、军队系统单位由主管部门、中央军委政治工作部宣传局审核同意后报送至以上地址。

国家新闻出版署将组织专家对申报项目进行评审，对入选项目进行资助，同时对入选项目加大宣传推广，充分发挥其示范作用。
