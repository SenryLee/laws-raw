# 司法部关于发布实施《社区矫正中心建设规范》等3项行业标准的公告

为规范全国司法行政信息化建设，加强对全国司法行政业务工作的指导，司法部制定了《社区矫正中心建设规范（SF/T 0087-2021）》《公证书制作规范（SF/T 0038-2021）》（修订）和《监狱信息化运行维护规范（SF/T 0088-2021）》等3项标准。现予以发布，自发布之日起实施。标准实施中的问题和建议，请及时报司法部。

附件：

SFT 0087-2021 社区矫正中心建设规范

SFT 0038-2021 公证书制作规范

SFT 0088-2021 监狱信息化运行维护规范
