# 农业农村部对十三届全国人大四次会议第5643号建议的答复

农办议〔2021〕240号

阎美蓉代表：

您提出的关于提升农民群众科学素质助力乡村振兴的建议收悉。现答复如下。

一、关于建立稳定的农民教育培训资金投入机制

我部会同有关部门积极推动建立农民教育培训经费保障机制。在职业教育方面，2011年，我部与教育部等九部门联合印发的《关于加快发展面向农村的职业教育的意见》明确提出，要督促各级人民政府增加对农村、农业职业教育投入，推动各省（自治区、直辖市）研究制定农村、农业职业教育生均经费标准。2019年，我部联合教育部印发《关于做好高职扩招培养高素质农民有关工作的通知》，强调各地要落实高职扩招相关经费、生均拨款制度，支持农民学员按照现行规定享受奖助学金以及相关资助政策。国家乡村振兴局实施雨露计划，为有子女接受职业教育的建档立卡脱贫家庭提供补贴，2015—2020年雨露计划共发放补助资金152.9亿元。在农民培训方面，我部联合财政部实施高素质农民培育计划，为农民提供了免费的系统培训。2020年中央财政资金投入达到23亿元，带动省级配套资金4.64亿元。国家乡村振兴局开展脱贫劳动力技能培训，2015—2020年各级财政累计投入713.12亿元。中国科协联合财政部实施“基层科普行动计划”，支持各地科普组织和社会各方力量广泛开展基层科普公共服务，2017—2019年中央财政累计投入12亿元，带动地方财政投入5.42亿元。

我部鼓励引导社会资本投资农业农村人才培养，印发《社会资本投资农业农村指引（2021年）》，支持社会资本参与农业生产经营人才、农村二三产业发展人才、乡村公共服务人才、乡村治理人才、农业农村科技人才、乡村基础设施建设和管护人才等培养。

下一步，我们将继续积极争取财政资金，推动建立较为稳定的投入保障机制，同时鼓励引导社会资本投资，为农民接受教育培训提供经费保障。

二、关于加强农村重点人群科学素质培训培育

2019年我部联合中国科协印发《乡村振兴农民科学素质提升行动实施方案（2019—2022年）》，明确提出要加强农村重点人群科学素质培训培育。一是开展高素质农民培育。实施高素质农民培育计划，重点对种养大户、家庭农场经营者、农民合作社带头人等群体开展系统培训，将绿色发展、耕地保护、防灾减灾、移风易俗等纳入培训内容，通过线上线下相结合的方式，提升农民技术技能水平和综合素质。统筹用好农广校、涉农院校、农业科研院所等教育培训资源，引导农业企业、农民合作社等积极参与培育工作。2020年培育高素质农民超过65万人。启动“百万高素质农民学历提升行动计划”，2019—2020年累计完成高职扩招录取高素质农民6.6万人。开展乡村振兴人才培养优质校推介，引导涉农院校积极开展面向农民的职业教育。二是开展农村实用人才培养。开展农村实用人才带头人和大学生村官示范培训，提升农村基层组织负责人、新型农业经营和服务主体带头人、大学生村官等各类人才的脱贫致富带动能力，为农村培养了一大批留得住、用得上、干得好的农村实用人才带头人。截至2020年底，累计举办示范培训班1600余期，培训16万余人。开展贫困村创业致富带头人培训，截至2020年底，累计培育创业致富带头人57.9万人。启动实施乡村文化和旅游能人支持项目，培养了一批思想政治素质好、扎根乡村、乐于奉献、服务群众的乡村能人。三是开展农村妇女培训。全国妇联充分发挥妇干校和妇女之家等阵地作用，面向农业生产一线妇女、农村妇女富余劳动力、具备一定创业基础的农村妇女开展针对性培训。截至目前，累计举办培训班15.2万期，培训农村妇女1600万人次。我部联合全国妇联开展高素质女农民培训，2020年共举办培训班500余期，培训女农民4.4万人。

下一步，我部将继续会同有关部门加强高素质农民培训，发展面向农民的职业教育，开展农村实用人才带头人、农村妇女、乡村文化和旅游能人等培养，夯实乡村振兴人才基础。

三、关于加快提升农民群众科普信息化服务水平

2015年起，我部在全国范围内启动农民手机应用技能培训。2017年起，将农民手机应用技能培训作为我部为农民办实事的一项重要内容，举办全国农民手机应用技能培训周活动，编写系列培训资料，组织各地农业农村部门和有关企业，采取线上线下相结合的形式开展培训，切实提高广大农民运用手机查询信息、网络营销、获取服务、便捷生活的能力。截至目前，累计培训农民超过6000万人次。2020年，我部会同中国科协举办全国农民科学素质网络知识竞赛活动，参赛人次近5000万。中国科协深入实施科普信息化工程，围绕“科普中国”大品牌大平台强化资源供给，联合新媒体平台共建科学求真话题，建立“科学辟谣”高效识谣辟谣机制，精准推送至不同类型受众。截至2020年12月，科普中国累计开发原创视频2万多个、图文20余万篇。

下一步，我部将继续开展农民手机应用技能培训，举办全国农民手机应用技能培训周活动，会同中国科协深化科普中国落地应用，加大优质内容开发和传播渠道的统筹力度，建好用好“科普中国”服务云平台，提升农民群众科普信息化服务水平。

四、关于加强农村科普阵地机制建设

中国科协大力组织开展科技志愿服务，推动科普工作融入新时代文明实践中心和党群服务中心，目前已推动500个新时代文明实践中心试点县成立并注册487个科技志愿服务组织。建设中国农技协科技小院联盟，在15个省份成立141个中国农技协科技小院，近千名师生长期扎根乡村开展服务，把农村科普与技术推广、产业发展等紧密结合，提升乡村科普公共服务水平。此外，中国科协不断打造中国特色现代科技馆体系，在加强中国科技馆实体馆建设的基础上，着重加强主要面向县城尤其是广大农村地区的流动科技馆、科普大篷车、农村中学科技馆等建设。2020年，中国科技馆实体馆在新冠肺炎疫情防控常态化下安全平稳运行，累计服务公众51万人次。流动科技馆巡展新增站点347站，其中贫困县95站，服务公众约641万人次。广泛开展科普大篷车20周年主题年活动，科普大篷车开展活动达2万次，行驶里程约273.4万公里，服务公众1786万人次。新建农村中学科技馆258所，服务公众230.8万人次。文化和旅游部加强基层综合性公共文化设施和场所建设，截至2020年底，全国累计建成村级文化中心57万多个。

下一步，中国科协将依托新时代文明实践中心、党群服务中心等开展科技志愿服务，建设好中国农技协科技小院联盟等阵地，继续加强中国特色现代科技馆体系建设，建立流动科普展览资源库和科普大篷车区域资源共享中心，集聚科普资源和服务向农村倾斜。文化和旅游部将加强对基层综合性文化服务中心的指导，通过举办科普周、科普公益课堂、科普知识竞赛等活动，切实提高农民科学素质。

感谢您对我部工作的关心，希望继续对三农工作给予支持。

农业农村部

2021年7月22日
