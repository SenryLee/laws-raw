## 关于发布相关课题承担单位的公告

6月上旬，国家医疗保障局办公室发布《国家医疗保障局办公室关于公开征选课题承担单位的公告》。截至6月底，共收到14份申报表。经专家组匿名投票评审，现将有关课题承担单位基本情况公布如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 课题名称 | 课题负责人 | 课题承担单位 |

感谢社会各界积极参与！
