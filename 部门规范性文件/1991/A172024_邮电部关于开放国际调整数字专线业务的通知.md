# 邮电部关于开放国际调整数字专线业务的通知

## 邮电部关于开放国际高速数字专线业务的通知（１９９１年７月３日）

我部与美国ＡＴＴ、日本ＫＤＤ公司合作建设的数字卫星通信网（ＩＢＳ），将于今年底分别在北京和上海建成投产。现将开放国际高速数字专线业务的有关问题及暂行资费标准通知如下：

**一、**设站申请

ＩＢＳ卫星地球站已分别选定在北京国际通信大楼和上海电信大楼顶部。京沪两局要切实作好频率干扰测试和分析，并抓紧将设站申请报国家无委审批。卫星地球站进入国际卫星空间段的申请也应及早办理。ＬＤＲ小微波中继系统报当地无委批准。

**二、**名称

传输速率在５６／６４ＫＢＰＳ以上的称“高速数字专线”业务，英文名暂定为“ＨＩ－－ＤＩＧＩＮＥＴ”。

**三、**基本电路单元

本期ＩＢＳ卫星通信系统工程将提供最低速率为５６ｋｂｐｓ的电路，作为收费的基本单元。５６ＫＢＰＳ以下速率的分路设备（ＭＯＤＥＭ）属于“用户终端设备”。

**四、**用户终端设备的提供

用户终端设备（包括ＭＯＤＥＭ和其他设备）可由用户自备，也可由我电信部门提供（向我购买或租用）。初期阶段可由用户自备为主，但要积极创造条件发展成以我电信部门提供为主，以便加强对用户终端设备的统一管理。

**五、**用户终端设备的批准和安装

用户终端设备的使用，必须按照邮电部的规定，经邮电管理局批准后方可接入高速数字专线网；并由我电信部门负责安装和测试开通。

**六、**用户申请手续

根据电联建议和ＡＴＴ／ＫＤＤ要求，为方便用户，可采用“一次性”申请办法，即由一端用户向本端电信部门办理申请和结算。具体实施方案，由京、沪两局与ＡＴＴ／ＫＤＤ商定。

**七、**暂行资费标准

参照电联建议和ＡＴＴ／ＫＤＤ的标准，并根据我国现有业务的资费情况，拟定我国一端的租费标准如下：

（一）国际卫星电路段（ＩＢＳ或ＩＤＲ）月租费标准，详见附表。

（二）不满一个月的临时租用，按现行规定办理。即第１－２天，每天为月租费的１０％；第３－１０天，每天为月租费的５％；第１１－２０天，每天为月租费的４％。

（三）为了鼓励用户长期租用，对连续正式使用三年以上者（自十八个月试用期结束后的第一天算起），可办理“长期约定”申请，并对租费优惠如下：

３年约定　５％

５年约定　１０％

１５年约定　１５％

（四）根据我方与ＡＴＴ和ＫＤＤ签订的协议备忘录（ＭＯＡ），在十八个月的试运行期间要采用优惠资费，以鼓励用户积极使用。因此，在十八个月试运行期间，租费优惠５０％。

（五）市内微波中继电路（ＬＤＲ）的月租费见附表（无上述优惠）。

（六）用户终端设备的有关费用一次性收取，作为本局的业务收入：

```
联接费安装费

用户自备设备　４０００元　３５０元

我方提供设备　１０００元　２００元
```

（七）国际高速数字专线业务收入列在电报收入——国际及港澳电报收入科目内核算。

（八）用户终端设备的联接费、安装费列在业务收入——电报其它收入科目内核算。
