# 国家核安全局关于批准高温气冷堆核电站示范工程维修大纲（C版，报批版）的通知

## 关于批准高温气冷堆核电站示范工程维修大纲（C版，报批版）的通知

国核安发〔2023〕186号

华能山东石岛湾核电有限公司：

你公司《关于升版高温气冷堆核电站示范工程维修大纲的请示》（华能石核执〔2022〕152号）、《关于报送高温气冷堆核电站示范工程维修大纲（C版，报批版）的请示》（华能石核执〔2023〕133号）收悉。

根据《中华人民共和国核安全法》《中华人民共和国民用核设施安全监督管理条例》的有关要求，我局对你公司提交的申请文件进行了技术审评，认为《华能山东石岛湾核电厂高温气冷堆核电站示范工程维修大纲（C版，报批版）》是可以接受的，现予批准。

你公司应严格遵守我局批准的维修大纲，确保高温气冷堆核电站示范工程反应堆运行安全。

国家核安全局

2023年9月27日
