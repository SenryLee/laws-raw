# 水利部办公厅关于召开水库移民统计汇审会的通知

办移民函〔2023〕317号

各省、自治区、直辖市和新疆生产建设兵团水利水电工程移民行政管理机构：

为进一步加强水库移民统计工作，提升统计报表数据质量，经研究，水利部决定召开水库移民统计汇审会。现将有关事项通知如下：

**一、**会议内容

总结水库移民统计工作成绩，交流经验，分析问题，组织对各省填报的2022年度报表进行审核。

**二、**会议时间

2023年4月23日报到，24日-25日开会，会期1.5天。

**三、**会议地点北京市易尚诺林大酒店（地址：北京市西城区菜园北里29号，电话010-63540399）。

**四、**参加人员

各省级移民管理机构负责统计工作的分管领导或业务骨干，中华人民共和国水利部办公厅每省1人；长江委网络信息中心负责统计工作的技术人员2人；水利部移民管理咨询中心1人。

**五、**有关要求

（一）请各省采取有力措施，切实加快2022年度统计报表工作进度，4月15日前将数据录入全国大中型水库移民管理信息系统。

（二）会议严格落实中央八项规定及其实施细则，厉行节约，一切从简。

（三）请各省于4月20日前将会议报名回执（见附件）传真至水利部移民司。

（四）联系人

水利部移民司：李锡泽　010-63203344，3336（传真）

易尚诺林大酒店：关兵　13701153723

水利部办公厅
