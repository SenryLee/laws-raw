# 国务院第五次全国经济普查领导小组办公室关于第五次全国经济普查宣传标语口号征集评选结果的通告

为做好第五次全国经济普查宣传工作，动员社会各界支持配合经济普查，日前国务院第五次全国经济普查领导小组办公室开展了第五次全国经济普查宣传标语口号征集活动。此项活动得到社会各界的大力支持和积极参与，共收到投稿6500余条。经认真筛选、评审，共评选出8条优秀作品，将用于全国经济普查宣传活动。现将评选结果通告如下：

|  |  |
| --- | --- |
| **序号** | **宣传标语口号** |
| 1 | 经济大普查 数说新时代 |
| 2 | 摸清国之大数 服务国之大者 |
| 3 | 查实新时代家底 服务高质量发展 |
| 4 | 普查摸清经济家底 数据服务发展决策 |
| 5 | 依法普查 服务发展 |
| 6 | 经济普查惠万家 如实填报促发展 |
| 7 | 如实填报普查资料 真实反映经济全貌 |
| 8 | 把脉经济摸家底 普查成果共受益 |

感谢各位投稿者对此次活动的大力支持。欢迎社会各界继续关注和支持第五次全国经济普查。

国务院第五次全国经济普查

领导小组办公室
