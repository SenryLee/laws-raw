# 民政部关于喀什机场更名为喀什徕宁国际机场的公告

|  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
| **原名称** | **更名后的标准名称** | **罗马字母拼写** | **所属政区** | **位置描述** | **批准机关** | **批准时间** |
| 喀什机场 | 喀什徕宁国际机场 | Kāshí Láiníng Guójìjīchǎng | 新疆维吾尔自治区喀什地区喀什市 | 位于喀什市机场路，东至乃则尔巴格镇徕宁村5、6、7组，西至迎宾大道街道科创社区，南至乃则尔巴格镇徕宁村1组，北至迎宾大道街道空港社区 | 中国民用航空局 | 2023年6月22日 |

经中国民用航空局批准，喀什机场更名为喀什徕宁国际机场。根据《地名管理条例》规定，现予以公告。
