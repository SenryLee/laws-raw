# 文化和旅游部市场管理司关于2022年全国导游资格考试部分考区延期安排有关事项的通知

相关省、自治区、直辖市文化和旅游厅（局），新疆生产建设兵团文化体育广电和旅游局：

为切实保障广大考生应试权益，经审慎研究，现就2022年全国导游资格考试部分考区延期安排通知如下：

**一、**举办日期

2022年全国导游资格考试延期考区的统一笔试时间为2023年3月25日（周六），相关省级文化和旅游行政部门须于2023年4月14日前完成现场考试（面试）工作并报送成绩。

**二、**参考人员

2022年9月23日17:00前已通过报名审核并交费，且仍未申请退费的延期考区考生。延期考区考生决定不再参考的，可于2023年1月12日9:00—1月16日17:00前申请退费。

**三、**考试科目及时间

|  |  |  |
| --- | --- | --- |
| 笔试 | 科目一、二 | 2023年3月25日9:00—10:30 |
| 科目三、四 | 2023年3月25日10:30—12:00 |
| 现场考试  （面试） | 科目五 | 由各省级文化和旅游行政部门于2023年4月14日前组织完成 |

**四、**准考证打印

2023年3月20日9:00起，考生可通过全国导游资格考试网上报名系统下载准考证并自行打印。报名信息审核未通过、未交费或已申请退费考生，无法下载、打印准考证。

**五、**考试结果公布

考生的考试结果以笔试成绩、现场考试（面试）成绩和总成绩均满足划线要求为合格。加试考生的考试结果以现场考试（面试）成绩满足划线要求为合格。考生的考试成绩仅当次考试有效。

2023年5月19日9:00起，延期考区考生可登录全国导游资格考试网上报名系统查询考试结果。

**六、**其他事项要求

考试其他有关事项工作要求参照《文化和旅游部市场管理司关于组织实施2022年全国导游资格考试的通知》（市场函〔2022〕43号）执行。

特此通知。

文化和旅游部市场管理司
