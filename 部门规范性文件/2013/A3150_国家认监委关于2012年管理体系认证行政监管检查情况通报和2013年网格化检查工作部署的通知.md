# 国家认监委关于2012年管理体系认证行政监管检查情况通报和2013年网格化检查工作部署的通知

各直属检验检疫局，各省、自治区、直辖市质量技术监督局、新疆生产建设兵团质量技术监督局：

2012年，国家认监委和地方认证监管部门紧紧围绕“十二字方针”及“传递信任、服务发展”工作要求，继续组织管理体系认证监管检查模式创新，各地方认证监管部门以管理体系认证行政监管检查为抓手，加强了对认证市场的监管工作。现对2012年管理体系认证行政监管检查情况进行通报，并就2013年管理体系认证行政监管检查（简称：网格化检查）工作部署提出要求：

**一、**2012年管理体系认证行政监管检查情况通报

（一）地方认证监管基本情况。

2012年初，有55个地方两局（其中：直属检验检疫局31个，省级质监局24个）上报了管理体系认证监管检查实施方案；年底，有49个地方两局（其中：直属检验检疫局30个，省级质监局19个）上报了管理体系认证行政监管检查工作总结。详见《2012年各局计划总结上报情况》（附件1）实施检查的地方两局共对11350家获证企业实施了检查，派出认证监管人员27659人次，检查了质量管理体系、环境管理体系、职业健康安全管理体系认证情况；对管理体系运行存在问题的获证组织及相关认证机构发出1062份整改通知书，对其中49件违反认证认可法规的，进行了立案和处罚。

（二）认监委2012年专项检查基本情况。

1.坚持整体部署，分类指导。2012年认监委部署的管理体系认证行政监管检查，是在2011年工作基础上继续推进。年初发出通知，提出2012年网格化检查工作任务，下发工作文件，明确工作要求。对各局不同情况加强分类指导，提高地方局开展网格化检查活动的实效。

一是组织天津、河北、辽宁、江苏、广东等5个直属检验检疫局和黑龙江、浙江、江西、河南、广东、西藏、新疆等7个省（自治区）质监局共12个地方局实施网格化检查，检查获证组织1127家。认监委认可监管部对这些局的网格化检查工作进行整体部署，协助地方局进行方案策划，根据需要从其他省区抽调专家提供技术支持，并直接派员参与实施，进行现场指导，对地方认证监管人员783人进行了现场培训。

二是支持2011年实施网格化检查试点的地方局自主开展检查工作。2012年，河北、江苏两省质监局在总结2011年试点经验基础上继续开展检查，组织本省各市局或分支机构对1079家获证组织实施了检查。

三是积极推动更多地方两局自主开展网格化检查工作。山西、上海、浙江、宁波、安徽、福建、厦门、江西、湖南、海南、重庆、甘肃、宁夏13个直属检验检疫局和上海、山东、云南、陕西等4个省质监局共17个地方局开展了检查工作。各地方局结合本地管理体系认证工作实际制定了网格化检查工作方案，注重创新认证监管模式，破解认证监管难题，把网格化检查作为地方日常监管的主要抓手，做到主动策划、主动实施、主动分析、进一步强化监管职能、完善监管检查体系、转变监管检查方式、加大监管力度，实现了依法、科学、高效监管。认监委认可监管部在整个过程中与地方局密切联系，根据地方局需求提供各种支持，有力地推动了网格化检查工作在各局的开展。

2012年网格化检查获证企业共计5317家，涉及认证机构120家。检查结果表明，获证企业的管理体系运行合格率（≥3分）为 96%，体系运行状态评价平均得分为3.8667分。

2.坚持突出重点，把握关键。认监委根据2011年网格化检查试点经验，对工作文件进行了调整，进一步突出了重点。各地局通过开展网格化检查，以提高获证企业质量管理水平和责任意识为目的，突出了对认证全过程中“关键点”的检查。包括：（1）咨询合同及发票、认证合同及发票、审核计划、审核组构成、首末次会议签到、审核记录、不符合项报告、认证决定、认证证书标志使用、监督审核记录等；（2）现场贯穿获证组织体系运行情况，包括获证目的、体系文件、质量方针目标、内审管理评审、各种记录、现场生产情况，对体系运行有效性进行综合评价；（3）现场向获证组织了解认证机构在审核过程中是否存在违规违法行为、获证组织自身是否存在问题等。上述工作为后续对认证机构的监督检查做好铺垫，使认证监管工作有的放矢。

3.重视收集问题，汇总分析。综合2011年和2012年两年网格化检查发现的问题，影响认证有效性的因素仍然来源于认证机构、咨询机构、培训机构、审核人员、获证组织等5个方面，任何一方出现问题都会导致体系运行无效。这5个方面因素中，认证机构和获证组织的两方面更为突出。

一是认证机构方面的问题。经济利益（收费）至上，无论什么样的企业，能给认证费用、申请了就发证；现场审核时间安排方面审核人天数不足，企业实际人数与企业和认证机构签订的合同中的人数不一致，现场审核人员与审核计划中的人员不一致；审核人员的专业能力不足，且未派出相应的技术专家；审核实施不按计划实施，减少审核覆盖范围，现场审核质量不高；对获证企业监督力度不够，重发证轻监督、后续监管走过场；部分认证机构超范围实施认证活动。

二是获证组织方面的问题。取得认证证书的动因是市场竞争的压力、政府采购的需要以及招投标的要求等，企业主动借认证提升管理水平不是主要动因；最高管理者和管代的质量意思相对淡薄，默许体系运行无效，对质量体系认证知识了解甚少；获证组织人员素质不高，不能很好理解和自觉执行体系认证的相关要求和标准，人员流动频繁，管代（或管理体系运行负责人）离职率高，离职时也不做交接；体系文件方面修改不及时，文件控制存在不足，体系文件不完整；内审、管理评审走过场，或效果不理想，多年的内审和管理评审的输入输出内容相似，未体现出差异性，无实质的改进措施；获证组织生产现场比较混乱，成品仓库内混有半成品或者废弃物，危险品仓库没有相应的标识，缺少设备管理台帐和日常维护、保养记录；认证证书和标志使用方面涉嫌混淆使用认证标志。

**二、**2013年管理体系认证行政监管检查（网格化检查）工作部署

（一）完善制度，凸显作用。

2013年认证认可监管工作的首要任务，是落实质检总局党组书记、局长支树平同志对认监委和地方两局提出的“完善制度、凸显作用”的工作要求，认真贯彻总局副局长、认监委党组书记、主任孙大伟同志部署的主要工作任务，实现各级认证监管部门“能管、易管、好管”的目标。两年实践证明，网格化检查是地方日常认证监管的有效手段，通过网格化检查可以充分了解一个地区管理体系认证的总体情况，以服务于地方经济发展。同时，这一检查方式可促使广大获证组织转变观念，逐步改变为了认证而认证、重视认证证书轻视有效运行的现象。2013年，认监委将继续在全国推动网格化检查工作，各局要把网格化检查工作制度化、常态化。

（二）突出重点，注重实效。

请各地方两局结合本地情况和职责分工，自主选择下列一项或两项重点内容开展网格化检查，并力求做实。

一是突出指定区域内获证企业的全覆盖，不要有遗漏。2013年，各局要选择获证组织密集、涉及认证机构多、未开展过网格化检查的一个市区、县（县级市）、工业园区或工业型乡镇，对全部获证企业实施全覆盖式检查。直属检验检疫局可选择上述区域内的全部获证的外向型企业进行全覆盖式检查。网格化检查也是“拉网检查”，各局切勿搞抽样检查。

二是突出对重点商品的全覆盖，落实《质量发展纲要》明确的国家重点监管产品目录。各局可根据总局和本省（直辖市、自治区）确定的产品质量专项监督或重点出口商品监管检查工作等，对上述监督抽查的重点产品中的获证企业实施全覆盖式检查。

三是突出对往年检查中发现的突出问题全覆盖，重点整治“反弹”和拒不整改问题。突出问题：（1）对照本通知第一部分中的“认证全过程中关键点”、“获证组织方面的问题”和“认证机构方面的问题”，进行重点检查；（2）对照认证机构对获证组织开具的不符合项，进行追溯检查；（3）对照获证组织2012年度发生的质量投诉、举报、召回事件及被被工商、消协、质监等处罚情况，进行整改检查。

四是网格化检查与其他工作相结合，完成双重任务。今年认监委在部分省区组织“ISO9000认证实施效果获证企业现场访问”活动，各相关局可根据上述情况，将“现场访问”与网格化检查工作结合在一起进行；各局也可以将网格化检查与本局其他重点工作结合在一起开展，以达到相互促进的目的。

（三）全面分析，按时上报。

各局要根据上述要求，制定检查方案，请于4月底前报认监委认可监管部。

在具体实施时，要按照本通知附件《2013年度管理体系认证行政监管（网格化检查）记录表》（附件2）要求填写检查情况。要做好网格化检查工作总结，于2013年10底前上报认监委认可监管部。请同时填报电子版的《2013年获证组织检查电子汇总表》（附件3）以及《案例分析汇总表》（附件4）。
