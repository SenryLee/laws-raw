# 全国导游人员等级考核评定委员会关于调整2013年全国中、高级导游员等级考试时间的通知

## 全国导游人员等级考核评定委员会关于调整2013年全国中、高级导游员等级考试时间的通知（导考发[2013]2号）

各省（自治区、直辖市）导游人员等级考核评定办公室：

为满足广大导游员的愿望，经全国导游人员等级考核评定委员会研究决定，调整2013年中、高级导游员等级考试时间，调整后的考试时间为：

|  |  |  |  |
| --- | --- | --- | --- |
| 中级导游员等级考试 | 11月9日 | 9：00-11：00 | 导游知识专题 |
| 14：00-16：00 | 汉语言文学知识/外语 |
| 高级导游员等级考试 | 11月9日 | 9：00-11：00 | 导游综合知识 |
| 14：00-16：30 | 导游能力测试 |

调整后，考试方式、考试科目、评卷、发证等事项仍依照《关于组织实施2013年全国中、高级导游员等级考试工作的意见》（导考发［2013］1号）不变。全国导游人员等级考核评定委员会将于2014年1月17日前委托各省级到考办对外发布考试结果。

请各省导游人员等级考核评定办公室尽快通知各位考生，并相应组织实施好考务工作。如遇有关情况，可及时向全国导游考核评定委员会反应。
