# 国家体育总局外联司关于召开总局系统外事工作会议的通知

各厅、司、局，各直属单位：

近期，中央就外事和外事管理工作提出了一系列新的要求，出台了一系列新的规定。结合总局开展的党的群众路线教育实践活动，为贯彻落实中央关于外事工作的新精神新要求，拟召开体育总局系统外事工作会议。现将有关事宜通知如下：

**一、**会议时间

2013年11月14日上午9：00，会期半天。

（请参会人员8：50前入场）

**二、**会议地点

体育总局机关办公楼102会议室。

**三、**出席人员

（一）总局领导；

（二）各厅、司、局，京内各直属单位主要负责同志、分管负责同志及1位负责本单位外事工作的部门负责人。

**四、**会议内容

传达学习中共中央办公厅、国务院办公厅转发的《外交部、中央外办、中央组织部、财政部关于进一步规范省部级以下国家工作人员因公出国的意见》（中办发[2013]16号）精神，对总局2013年外事工作进行总结，并结合中央八项规定、总局党组24条措施以及党的群众路线教育实践活动，对进一步做好总局外事工作进行布置并提出要求。

**五、**报名

请各部门、各单位填写报名表（详见附件），并于2013年11月6日前将报名表报送外联司。

**六、**参加会议时，请持本通知入场。
