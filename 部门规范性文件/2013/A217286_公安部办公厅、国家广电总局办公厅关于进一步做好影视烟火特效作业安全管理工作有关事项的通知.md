# 公安部办公厅、国家广电总局办公厅关于进一步做好影视烟火特效作业安全管理工作有关事项的通知

## 公安部办公厅、国家广电总局办公厅关于进一步做好影视烟火特效作业安全管理工作有关事项的通知（公治〔2013〕99号）

各省、自治区、直辖市公安厅、局，广播影视局，新疆生产建设兵团公安局、广播电视局：

为落实公安部、国家广电总局联合印发的《关于进一步加强影视烟火特效作业安全管理工作的通知》（公通字〔2012〕64 号）要求，切实做好影视烟火特效作业安全管理工作，现就有关事项通知如下：

**一、**认真做好影视烟火特效作业单位审查许可工作。省级公安机关要对照《民用爆炸物品安全管理条例》和《爆破作业单位资质条件和管理要求》（GA990-2012）的规定，认真审查影视烟火特效作业单位提交的《爆破作业单位许可证》（营业性）申请表和专用仓库、注册资金、净资产、技术负责人、工程技术人员、爆破员、安全员、保管员的相关证明材料。对符合条件的，核发《爆破作业单位许可证》（营业性），并在从业范围中注明仅限影视烟火特效作业；对不符合条件的，书面向申请人说明理由。影视烟火特效作业单位要在取得《爆破作业单位许可证》（营业性）后30日内，向所在地省级广播影视行政部门备案（备案表见附件1）。

**二、**加强影视烟火特效作业人员安全管理。影视烟火特效作业人员包括爆破员、安全员、保管员和爆破工程技术人员。爆破员、安全员、保管员应由所在地设区的市级公安机关考核合格后，核发《爆破作业人员许可证》。爆破工程技术人员应如实填写并提交《爆破工程技术人员安全作业证审批表》（具体资格条件见附件2）及其他相关证明材料，经公安部治安管理局会同国家广电总局人事司组织考核合格后，核发《爆破工程技术人员安全作业证》，并在作业范围中注明仅限影视烟火特效作业。影视烟火特效作业单位的技术负责人、承接影视烟火特效作业项目的技术负责人应当取得《爆破工程技术人员安全作业证》。

**三、**强化影视烟火特效作业安全管理和监督检查。影视烟火特效作业单位要加强安全管理，完善影视烟火安全操作规程等各项规章制度，落实影视烟火特效作业人员持证上岗制度，确保安全管理、技术装备、教育培训和职业危害治理等措施落实到位。影视制作单位要提高安全意识，建立健全内部规章制度，严格按要求委托有资质的单位实施影视烟火特效作业，并督促其依据影视烟火安全操作规程实施作业。各地公安机关、广播影视行政部门要密切协作配合，按照职责权限强化影视烟火特效作业安全监管。公安机关负责影视烟火特效作业单位资质和影视烟火特效作业人员资格认定；广播影视行政部门负责协助公安机关组织影视烟火特效作业人员考核，接受影视烟火特效作业单位备案。公安机关、广播影视行政部门要强化影视烟火特效作业安全监督检查，及时发现查处违法违规行为，督促落实安全管理措施和责任，严防发生涉爆事故、案件，确保公共安全。

各地接此通知后，请即传达至基层单位，抓好贯彻落实。

附件2

影视烟火爆破工程技术人员资格条件要求

1、申请爆破工程技术人员安全作业证（高级，仅限影视烟火特效作业），必须具有理学或工学学科范围高级技术职称，有8年以上从事影视烟火特效作业的经历，无重大责任事故。

2、申请爆破工程技术人员安全作业证（中级，仅限影视烟火特效作业），必须具有理学或工学学科范围中级技术职称，有5年以上从事影视烟火特效作业的经历，无重大责任事故。

3、申请爆破工程技术人员安全作业证（初级，仅限影视烟火特效作业），必须具有理学或工学学科范围大专以上学历或助理工程师技术职称，有从事影视烟火特效作业的经历，无重大责任事故。

附件3

影视烟火爆破工程技术人员考核大纲

1. 考核目标

要求申请初、中、高级技术级别的考生通过考试检验以下知识和能力：

（1）应掌握的影视烟火爆破作业相关安全法律法规知识；

（2）应掌握的影视烟火基础知识、影视烟火爆破常用药剂的理化基础知识和电工基础知识；

（3）应掌握的各种影视烟火爆破作业标准及操作规程；

（4）应具备的人身及环境安全意识和处置紧急突发事件的应变能力；

（5）应具备的与本级别对应的影视烟火专业知识和影视烟火特效场景设计策划能力、组织管理能力。

2.1.1 《中华人民共和国刑法》

2.1.2 《中华人民共和国治安管理处罚法》

2.1.3 《中华人民共和国安全生产法》

2.1.4 《中华人民共和国消防法》

2.1.5 《中华人民共和国枪支管理法》

2.1.6 《民用爆炸品安全管理条例》

2.1.7 《烟花爆竹安全管理条例》

2.1.8 《危险化学品安全管理条例》

2.1.9 《森林防火条例》

2.2 基础知识

2.2.1 影视烟火与安全基础知识

2.2.1 .1点火具

电桥（点火药头）、电效管、拉火管、电雷管、导火索、导爆索、延期雷管。

2.2.1 .2炸药

硝铵炸药、梯恩梯炸药（块状、粉状）、黑色有烟炸药、岩石乳化炸药（铵油炸药）。

2.2.1 .3发烟器具

白烟罐、白烟片、黑烟棒、散黑烟、彩色烟、烟油、干冰、液氮。

2.2.1 .4燃烧材料

炭粉、汽油、柴油、无烟油、甲烷、丁烷、凝固油、酒精、煤气、液化石油气、硫磺。

2.2.1 .5火药

铝制火药（雷子药）、闪光剂、高氯合金粉火药、氯酸盐合金粉火药、硝酸盐合金粉火药、照明剂、引火药、多次闪光剂、黑色爆炸火药、黑色发射火药。

2.2.1 .6静电防护

（1）静电防护方法：增湿法、接地法；

（2）静电防护装备：防静电服装（鞋帽）、防静电表、防静电板、防静电圈、防静电塑料袋、防静电箱、其他防静电装置。

2.2.1 .7殉爆预防

2.2.1 .8电磁辐射防护

2.2.1 .9振动和冲击防护

2.2.1 .10影视烟火爆炸基本原理

（1）爆炸的定义

（2）炸药化学反应的四种基本形式

（3）氧平衡

（4）爆炸三要素

2.2.2 影视烟火常用药剂的理化性能

2.2.2 .1氧化剂

重点掌握硝酸钾、氯酸钾、高氯酸钾、硝酸钡。

2.2.2 .2可燃物

重点掌握炭、硫、镁粉、铝粉及镁铝合金粉。

2.2.2 .3火焰着色的物质

重点掌握锶、锂、钡、铜。

2.2.2 .4有色发烟剂中的成烟物

重点掌握蒽醌材料。

2.2.2 .5黑、白烟幕剂中的成烟物

重点掌握氯化铵、精萘、粗蒽等物质。

2.2.3 电工知识

欧姆定律、静电感应、线路的串并联、常用器材（万用表、欧姆表）、干电池、乙电池。

3. 考试形式与试卷结构

3.1 笔试

3.1.1 考试方式及考试时间

笔试形式为闭卷，考试时间为150分钟。

3.1.2 出题方式

随机抽取，密封试卷。

3.1.3 试题及格线

3.1.3 .1初级

试卷满分为100分，分为“应掌握部分”知识50分和“必须熟练掌握部分”知识50分。及格线应同时满足以下两个条件：

（1）试卷总分大于等于60分；

（2）“必须熟练掌握部分”试题每题得分必须大于等于本题满分的60%。

3.1.3 .2中级

试卷满分为120分，分为“应掌握部分”知识50分、“必须熟练掌握部分”知识50分和“设计与案例分析”20分。及格线应同时满足以下两个条件：

（1）试卷总分大于等于72分；

（2）“必须熟练掌握部分”试题每题得分必须大于等于本题满分的60%。

3.1.3 .3高级

试卷满分为150分，分为“应掌握部分”知识50分、“必须熟练掌握部分”知识50分和“设计与案例分析”50分。及格线应同时满足以下两个条件：

（1）试卷总分大于等于90分；

（2）“必须熟练掌握部分”试题每题得分必须大于等于本题满分的60%。

3.1.4 试卷题型结构

（1）“应掌握部分”题型以填空题、选择题、判断题为主；

（2）“必须熟练掌握部分”与“设计与案例分析”题型以简答题、问答题为主。

3.2面试

初级、中级、高级考生必须在笔试考试及格后方可参加面试。

3.2.1 面试时间

面试时间为每人20-30分钟。具体时间由面试专家酌情掌控。

3.2.2 考题来源

由考生在面试现场自行从题库中随机抽取试题，试题内容以设计与案例分析为主。

3.2.3 评分标准

面试经考核专家组集体讨论后评分给出合格或不合格结论。
