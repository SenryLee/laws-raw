# 国家卫生和计划生育委员会办公厅关于做好雅安7.0级地震抗震救灾卫生应急工作的紧急通知

四川省卫生厅，四川省人口和计划生育委员会：

2013年4月20日上午，四川省雅安市芦山县发生7.0级地震，造成了人员伤亡和财产损失，国务院已启动了抗震救灾一级响应。灾情发生后，国家卫生和计划生育委员会高度重视，李斌主任亲自致电四川卫生计生部门表示慰问，并了解有关情况。目前我委已紧急动员，派出国家卫生应急队伍赶赴灾区开展卫生应急处置工作。为做好卫生计生系统地震灾害卫生应急工作，现对你单位抗震救灾工作提出以下几点要求：

**一、**高度重视，全面动员

本次抗震救灾工作任务艰巨、责任重大，四川省卫生计生系统要在党中央、国务院和当地党委、政府的领导下，以对人民生命和健康高度负责的态度，把抗震救灾作为当前卫生计生工作的重要任务，紧急动员起来，全力做好受伤群众和被困群众的医疗救治工作，尽最大努力保障灾区群众的生命安全。

**二、**落实责任，有效救灾

四川省各级各类医疗卫生机构和计划生育服务机构要切实履行防灾救灾责任，落实抗震救灾工作各项措施。灾区卫生计生服务机构要停止使用危房，确保病人安全和医疗救援工作的有序、有效开展。灾区卫生部门要结合伤病人员救治工作实际，在灾民集中安置点设立医疗点，组织医护人员开展巡回和定点医疗，并统筹安排重症伤病员的转运和住院治疗；要针对震灾导致人员伤害的特点，有效配置国家卫生应急队伍，集中优势医疗专业力量，同时充分发挥基层卫生计生服务机构的优势，组建医疗卫生救援梯队派到救灾一线，保证灾区的医疗救治工作，最大限度地减少死亡率和致残率，全力挽救伤员生命。

各级卫生计生部门要切实加强灾后卫生防疫和卫生监督工作，落实各项卫生防疫工作措施，开展爱国卫生运动，加强食品卫生、饮用水卫生的监督检测和环境卫生整治，防止灾后传染病疫情和突发公共卫生事件的发生，确保大灾之后无大疫。要高度重视灾害引发的受灾群众和应急救援人员的心理应激障碍反应，及时组织开展心理危机干预，有力保障相关人员身心健康，保障抗灾救灾工作的顺利开展。要充分利用基层卫生计生服务网络的优势，做好群众灾后卫生防疫宣传教育和动员工作。

受灾地区的卫生计生部门要针对震后可能发生的次生、衍生灾害和突发事件按照有关预案及时启动卫生应急处置工作。

**三、**密切沟通，加强协调

卫生计生系统要加强应急值守，落实责任，确保信息通畅和准确。四川省卫生厅、四川省人口和计划生育委员会要落实信息报告责任，要每日上报人员伤亡、疫情和突发公共卫生事件等情况，以及伤员救治等各项医疗卫生救援工作开展情况。并将上述情况及时汇总报国家卫生和计划生育委员会。在抗震救灾过程中，我委将根据实际工作需要和四川卫生计生部门的请求，及时提供支持和援助。

国家卫生和计划生育委员会办公厅

2013年4月20日
