# 中国地震局关于批准北京市东坝商贸国际中心区地震小区划的通知

中国地震局关于批准北京市东坝商贸国际中心区地震小区划的通知

北京市地震局：

北京市东坝商贸国际中心区地震小区划已经通过国家地震安全性评定委员会评审，现予以批准。

北京市东坝商贸国际中心区地震小区划符合国家标准GB18306－2001《中国地震动参数区划图》的规定，给出了考虑具体场地条件的地震动参数和地震地质灾害评价结果，该结果为北京市东坝商贸国际中心区一般建设工程的抗震设防要求，也可作为城市发展和土地利用规划的依据。请认真组织实施并加强监督检查。

附件：北京市东坝商贸国际中心区地震小区划报告评审意见

中国地震局

2013年9月6日

北京市东坝国际商贸中心区地震小区划报告评审意见

国家地震安全性评定委员会和北京市地震安全性评定委员会联合组成评审专家组于2013年8月24日在北京召开评审会，对北京赛斯米克地震科技发展中心承担完成的《北京市东坝国际商贸中心区地震小区划报告》进行了评审。评审专家组在认真审阅报告的基础上，听取了项目组的汇报。经过质询和讨论，并通过复审过程，形成评审意见如下：

1．系统收集了区域范围内的地震地质、地震活动性、地球物理等资料，对区域地震构造环境和地震活动性进行了分析评价。

2．通过野外地震地质调查，结合地球物理勘探，对近场的南口-孙河断裂等8条主要活动断裂的活动性进行了鉴定。评价了近场区地震构造环境和地震活动性。

3．通过概率地震危险性分析，计算了小区划场地各控制点50年超越概率63%、10%、2%的基岩水平峰值加速度及反应谱。

4．通过场地地震工程地质条件勘察等工作，完成了7个钻孔的钻探及波速测量和4个典型土样的动力学特征试验。

5．通过场地地震反应计算，编制了50年超越概率63%、10%、2%的地震动参数小区划图（参数详见附件）和相应说明书。

6．通过收集相关资料，地质地貌调查和地球物理勘探，结合地震工程地质条件勘察结果，进行了场地地震地质灾害评价。

该报告技术思路正确，资料翔实，论述充分，结论可信，符合国家标准GB17741-2005《工程场地地震安全性评价》的要求，专家组同意该报告通过评审。

国家地震安全性评定委员会
