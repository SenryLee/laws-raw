# 国家文物局关于撤拍西泠印社拍卖有限公司“西泠印社二0一三年春季拍卖会”有关标的的函

## 国家文物局关于撤拍西泠印社拍卖有限公司“西泠印社二〇一三年春季拍卖会”有关标的的函（办博函〔2013〕616号）

浙江省文物局：

你局《文物拍卖标的审核意见》（受理编号：20130018）收悉。

经复核，西泠印社拍卖有限公司“西泠印社二〇一三年春季拍卖会”报审标的中，“中国明清御窑金砖专场”第jz001号-jz090号标的，“中国历代庭园艺术石雕专场”第ty034号-ty038号、ty048号、ty049号、ty057号、ty059号、ty060号、ty061号、ty063号、ty069号、ty070号、ty074号、ty111号标的，因不符合相关规定要求，不得作为拍卖标的。

请你局通知西泠印社拍卖有限公司公司立即撤拍上述拍卖标的。

此函。

国家文物局

2013年6月25日
