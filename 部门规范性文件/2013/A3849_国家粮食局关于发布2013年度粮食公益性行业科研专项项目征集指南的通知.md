# 国家粮食局关于发布2013年度粮食公益性行业科研专项项目征集指南的通知

## 国家粮食局关于发布2013年度粮食公益性行业科研专项项目征集指南的通知（司便函发展﹝2013﹞41号）

根据财政部科技部《公益性行业科研专项经费管理试行办法》和《粮食公益性行业科研专项经费管理暂行办法》有关要求，国家粮食局启动2013年度粮食公益性行业科研承担单位申报指南，现公开征集项目承担单位并将有关事项通知如下：

**一、**承担单位和参加单位选择

按照公平、公正的原则，以“公开申报、评审择优”的方式确定项目承担单位。鼓励粮食科技创新体系、创新平台、省级科研单位、粮食企业联合申报项目。

**二、**申报资格和要求

（一）申报单位的条件

1、一般为中国大陆境内具有独立法人资格的科研院所、高等院校和内资或内资控股企业等；

2、具有项目实施必须的科研设施条件，优先支持国家和国家粮食局重点实验室、工程（技术）中心等建设依托单位；

3、具有较强的研发优势，拥有相关领域国内知名的学科带头人和相对稳定的学术团队；

4、具有丰富的项目组织管理经验，优先支持承担过国家相关研究项目的单位。

（二）项目负责人的条件

1、年龄原则上不超过55周岁，院士不超过65岁，具有高级（含副研究员）及以上专业技术职称，有固定工作单位（原则上应在承担单位工作），具有较高的学术水平和开拓创新能力，具有较强的组织协调能力，诚信记录良好，主持或参加过国家级科技计划项目；

2、粮食科技公益专项项目负责人同期只能承担1项，并最多只能以参加者或合作者的身份再参加1项。参加项目的人员同期参加不得超过3项，若同期主持其他国家级科技项目则参加项目也不能超过1项（包括院所专项、转化项目等）。

**三、**申报文件的编制与递交

（一）申报文件编写应要求语言精炼，数据真实、可靠。

（二）申报文件由申报函、项目申报书和附件等三部分组成。

（三）申报文件以邮寄方式报送，不接受直接到办公室报送的申报材料。申报文件一式8份，由申报函、项目申报书和附件等三部分合订在一起，用A4纸、3号仿宋字体打印、双面印刷，统一采用羊皮纸（皮纹纸）封皮进行胶订，请勿用塑料封皮等其它装订方法。

（四）报送申报文件的截止日期：请于2013年3月15日17：00点前，将纸质申报文件及电子版报送国家粮食局流通与科技发展司科技处，逾期不再受理。

## 第一部分　申报须知

**一、**前言

2000年以来，随着三批国债投资建库和粮食储备“四合一”新技术的大范围推广应用，我国粮食储藏技术水平得到极大提升。同时，粮食储藏科技创新能力不断增强。粮食储运国家工程实验室正式组建，气调储粮、高效生物杀虫剂、智能通风、成品粮储备、粮食储运监管物联网示范等一批粮食储运保质减损新技术不断取得新突破。粮食储藏技术的进步，为保证我国粮食产后储运安全、保证农民增产增收提供了强有力的支撑。

但是，目前我国粮食产后收购、储藏、运输等环节仍然存在许多问题：农户家庭储粮数量大、设施简陋、技术落后，造成粮食数量和质量损失巨大；粮食储藏保质保鲜技术研究刚刚起步，满足不了人民对食品质量安全的新需求；粮食储藏过程智能控制基础研究薄弱，基础数据库和控制模型尚未建立；粮食仓储企业安全生产事故预防和应急救援技术缺乏，事故时有发生；节能降耗与绿色环保新技术研发和推广还不能满足行业需求；粮食储藏技术标准系统有待完善。同时，随着社会经济发展和人民生活水平的提高，粮食储藏不仅要担负起保障粮食数量安全的责任，更要通过技术创新与装备升级保障粮食质量安全，实现安全生态绿色储粮，这给粮食储藏科技创新提出了更高的要求。

为了解决我国粮食储藏领域存在的问题，实现“粮安工程”，保障粮食质量安全，为消费者的健康服务，提升粮食科技自主创新能力，进一步贯彻落实《行业规划》、《“十二五”粮食科技发展规划》，结合粮食行业《公益专项管理办法》，针对粮食行业发展需求，制定本粮食行业公益性专项储藏领域项目择优指南。

本指南分6个择优项目。

**二、**择优项目内容

课题01：大农户农村粮食物流及综合技术研究

1. 研究目标

针对我国农村粮食信息化技术落后的问题，通过本项目的研究，逐步建立我国农户储粮信息服务系统，解决长期以来我国农村粮食信息匮乏、信息不对称的问题，为农户提供全面、快捷、方便的技术等服务信息。

通过对农村粮食物流和节点设备进行研究开发，开发出具有物流功能的农村粮食物流节点设备及大农户粮仓设备和配套设备，建设农村粮食物流信息平台。

通过大农户综合示范建设，将科技成果引入全国农户科学储粮专项进行转化，全面促进我国农户储粮技术的全面提升，有效减少农户储粮损失，保证储粮安全，保障农户增收。

2. 研究内容

该研究内容以制约我国农户储粮技术瓶颈的农户储粮与粮食物流关键节点为重点开展研究，结合全国农户科学储粮专项的实施，对现有技术进行技术升级，开展大农户综合示范，有效减少农户储粮损失，全面提升我国农户储粮技术和水平。主要研究内容：

（1）农村粮食物流和节点关键设备研发。开发兼顾农户粮食储藏与物流相结合的新型厢式、适合农户短距离运输的集装式、组合式的农户粮食物流设备；开发或筛选适用于农村粮食物流节点或农村粮食经纪人应用的小型粮食清理设备、小型输送设备及其相关配套设备。

（2）农村粮食物流信息平台。针对农户实际需求，建立农户储粮信息服务技术服务平台，构建远程信息查询、咨询服务等技术网络各平台。在示范点的相应省级粮食科研院所建立信息服务节点。

（3）规模化农户储粮技术模式研究。针对我国不同地域规模化种植情况、农户规模储藏遇到的技术瓶颈问题，研究储粮害虫防治技术、鼠害防治技术，提出农户规模化储粮技术模式，解决规模化农户储粮共性的技术问题。

（4）农户安全储粮技术升级及农户储粮综合减损示范。集成“十五”、“十一五”、“十二五”粮食丰产科技工程在粮食产后领域取得成果以及本项目取得的成果，在中国南方建设2个核心示范基地。

3. 考核指标

（1）研制出2-3种兼顾农户粮食储藏与物流相结合的适合农户储藏与短距离运输的农户储粮新装具，成本低于2000元/套。

（2）建立1套农村粮食物流信息系统，实现远程技术服务；建设2个规模化农户储粮示范点，示范户农户储粮损失率低于2%。

（3）完成2套农村储粮装具标准设计图。

（4）申报1～2项专利或具有自主知识产权的成果。

4. 经费额度

项目国拨经费控制额度为375万元，研究周期3年，定向择优。

课题02：吉林地区种粮大户玉米储藏设施研究及应用示范

1.研究目标

针对东北（吉林）地区玉米储粮生态特点以及玉米收获后储藏特性，开展东北地区大农户玉米储藏技术相关研究；制订大农户储粮仓操作技术规程，制订大农户储粮仓、配套设备和相关技术标准；建立大农户储粮仓及装卸设备和相关技术示范基地，对大农户储粮仓集成技术进行示范、推广和培训。

2.研究内容

（1） 大农户储粮仓、进出仓设备和配套技术的设计研发。

（2） 大农户储粮仓的应用技术研究。

（3） 大农户储粮仓、配套设备和技术的标准化研究。

（4） 对“大农户储粮仓、配套设备和技术”进行集成示范。

第（1）项任务建议由粮仓生产企业完成，第（2）、（3）项由当地粮食科研院组织粮仓生产企业完成。第（4）项由企业和当地粮食科研院所共同完成。

3.考核指标

（1）开发适合东北地区大农户（玉米）储存仓20t（275m3）、40t（550m3）、100t（1370m3）的样品仓。

（2）完成大农户储粮仓标准图和技术标准。

（3）建成不低于10户的示范农户，损失率低于2％，实现大农户安全储粮6-8个月。

4.经费额度

国拨经费控制额度为175万元，研究周期2年，定向择优。

（1）由粮仓或设备生产企业牵头申请，并与当地省粮食科研院所签定技术合作协议。企业负责产品的研发与示范户建设，国拨经费控制额度100万，企业配套资金不少于国拨资金。

（2）当地省粮食科研院所负责当地技术服务体系建设，并为示范户的建设提供技术支持，负责当地储粮模式、工艺、技术及标准研究。

（3）粮仓或设备生产企业信誉良好，资产规模在500万元以上，并提供证明材料。

课题03：辽宁地区种粮大户高水分粮食储藏自然通风工艺技术及工艺研究

1. 研究目标

通过对东北（辽宁）地区大农户高水分粮食储藏生态特点的研究，系统掌握储粮过程中粮食的水分变化和品质变化规律；确定东北地区大农户科学储粮仓安全储藏水分标准；储藏工艺参数和期限；制定东北地区大农户安全储粮通风技术规范。重点研发适用于东北地区防霉、防鼠、防虫、保质干燥关键技术，为东北地区高水分粮食储藏提供基础数据支撑。

2. 研究内容

（1）开展东北地区大农户高水分粮食储藏生态特点、安全储藏水分标准、工艺参数和储藏期限研究。

（2）研究东北地区高水分粮食通风干燥技术。

（3）研发自动通风、控温、粮情监测稻谷保质储粮仓；构建东北地区农村绿色粮食储备体系。

（4）开展相关参数的验证。

（5）制定东北地区大农户安全储粮通风技术规范。

3. 考核指标

（1）提出东北地区大农户粮仓通风干燥水分转移规律。

（2）制定东北地区大农户安全储粮通风技术规范。

（3）大农户粮仓自动通风、粮情监测技术。

（4）验证规模不低于10户。

4. 经费额度

国拨经费控制额度为150万元，研究周期3年，定向择优。

课题04：黑龙江地区种粮大户稻谷和大豆储藏设施研究及应用示范

1. 研究目标

针对东北地区（黑龙江）稻谷、大豆储粮生态特点以及稻谷、大豆收获后储藏特点，开展东北地区开展大农户稻谷、大豆储藏相关研究；制订大农户储粮仓操作技术规程，制订大农户储粮仓、配套设备和相关技术标准；建立大农户储粮仓及装卸设备和相关技术示范基地，为大农户（包括农业生产合作社）提供技术服务，对大农户储粮仓集成技术进行示范、推广和培训。

2. 研究内容

（1）适用于稻谷、大豆穗储、粒储20-200m3系列仓型研发。

（2）相关基础科学的集成与实验研究，农户科学储粮工艺研究，应用操作手册编写，起草相关技术标准。

（3）配套清选设备，入仓、出仓机械设备的选型与研制。

（4）优选仓内粮食温、湿度监控技术。

（5）进行集成示范。

第（1）项内容由粮仓生产企业完成，第（2）、（3）、（4）、（5）项由当地粮食科研院所组织粮仓生产企业完成。

3. 考核指标

（1）开发东北地区大农户（稻谷、大豆）储存仓20m3、30m3、50m3、130m3、200m3五种规格的样品仓。

（2）完成农户储粮仓标准图和技术标准。

（3）建成5-8个示范点，示范农户不低于10户，损失率低于2％，实现大农户安全储粮6-8个月。

4. 经费额度

国拨经费控制额度为150万元，研究周期2年，定向择优。

（1）由粮仓或设备生产企业牵头申请，并与当地省粮食科研院所签定技术合作协议。企业负责产品的研发与示范户建设，国拨经费控制额度100万，企业配套资金不少于国拨资金。

（2）当地省粮食科研院所负责当地技术服务，并为示范户的建设提供技术支持，负责当地储粮模式、工艺、技术及标准研究。

（3）粮仓或设备生产企业信誉良好，资产规模500万元以上，并提供相关证明。

课题05：湖南地区种粮大户粮食储藏技术研究及应用示范

1. 研究目标

针对我国南方地区（湖南）规模化农户稻谷储藏技术及设施缺乏的现状，通过对稻谷的整理技术与装备、种粮大户新仓型设计、稻谷动态干燥技术、生物储粮防护剂、绿色防鼠技术、种粮大户稻谷储藏综合技术集成等的研究，为我国南方种粮大户粮食减损提供有效技术支撑。

2. 研究内容

（1）研究开发1到2种仓容在30-100吨新仓型，制定设计规范与标准图纸。

（2）筛选大农户适用的新型成套整理设备与技术。

粮食公益性行业科研专项

“粮食储藏领域”项目承担单位征集指南

（2013年度）

## 第一部分　 申报须知

## 一、前言

2000年以来，随着三批国债投资建库和粮食储备“四合一”新技术的大范围推广应用，我国粮食储藏技术水平得到极大提升。同时，粮食储藏科技创新能力不断增强。粮食储运国家工程实验室正式组建，气调储粮、高效生物杀虫剂、智能通风、成品粮储备、粮食储运监管物联网示范等一批粮食储运保质减损新技术不断取得新突破。粮食储藏技术的进步，为保证我国粮食产后储运安全、保证农民增产增收提供了强有力的支撑。

但是，目前我国粮食产后收购、储藏、运输等环节仍然存在许多问题：农户家庭储粮数量大、设施简陋、技术落后，造成粮食数量和质量损失巨大；粮食储藏保质保鲜技术研究刚刚起步，满足不了人民对食品质量安全的新需求；粮食储藏过程智能控制基础研究薄弱，基础数据库和控制模型尚未建立；粮食仓储企业安全生产事故预防和应急救援技术缺乏，事故时有发生；节能降耗与绿色环保新技术研发和推广还不能满足行业需求；粮食储藏技术标准系统有待完善。同时，随着社会经济发展和人民生活水平的提高，粮食储藏不仅要担负起保障粮食数量安全的责任，更要通过技术创新与装备升级保障粮食质量安全，实现安全生态绿色储粮，这给粮食储藏科技创新提出了更高的要求。

为了解决我国粮食储藏领域存在的问题，实现“粮安工程”，保障粮食质量安全，为消费者的健康服务，提升粮食科技自主创新能力，进一步贯彻落实《行业规划》、《“十二五”粮食科技发展规划》，结合粮食行业《公益专项管理办法》，针对粮食行业发展需求，制定本粮食行业公益性专项储藏领域项目择优指南。

本指南分6个择优项目。

课题01：大农户农村粮食物流及综合技术研究

1. 研究目标

（1）农村粮食物流和节点关键设备研发。开发兼顾农户粮食储藏与物流相结合的新型厢式、适合农户短距离运输的集装式、组合式的农户粮食物流设备；开发或筛选适用于农村粮食物流节点或农村粮食经纪人应用的小型粮食清理设备、小型输送设备及其相关配套设备。

（2）农村粮食物流信息平台。针对农户实际需求，建立农户储粮信息服务技术服务平台，构建远程信息查询、咨询服务等技术网络各平台。在示范点的相应省级粮食科研院所建立信息服务节点。

（3）规模化农户储粮技术模式研究。针对我国不同地域规模化种植情况、农户规模储藏遇到的技术瓶颈问题，研究储粮害虫防治技术、鼠害防治技术，提出农户规模化储粮技术模式，解决规模化农户储粮共性的技术问题。

（4）农户安全储粮技术升级及农户储粮综合减损示范。集成“十五”、“十一五”、“十二五”粮食丰产科技工程在粮食产后领域取得成果以及本项目取得的成果，在中国南方建设2个核心示范基地。

3. 考核指标

（1）研制出2-3种兼顾农户粮食储藏与物流相结合的适合农户储藏与短距离运输的农户储粮新装具，成本低于2000元/套。

项目国拨经费控制额度为375万元，研究周期3年，定向择优。

智能化包括信息管理系统和自动控制系统。信息管理系统是指应用数字化设备、计算机网络和各类应用软件，通过智能粮库管理平台对粮库业务信息适时准确采集、收集、整理、统计、分析和反馈，实现信息的存储、管理和共享，用数字化技术反应粮食的入库、质检、称重、入库、保管、出库以及粮库管理的全过程信息处理。自动控制系统是指在数据分析决策的基础上，根据有关数学模型或工艺流程，计算机控制相关设备自动或半自动完成仓储作业，如储粮通风、制冷、气调、就仓干燥等作业。建立监控中心和远程移动测控终端，实现有关作业可视化监控和相关信息网络化传输，制定智能粮库设计规范。

2. 研究内容

（1）开发智能化粮库管理软件平台。包括：粮库基础数据管理系统；粮食收购管理系统；粮情检测系统；卡簿信息管理系统；出入库管理系统；自动化作业管理系统；开发触摸屏信息查询系统。

（2）开发仓储作业自动化专用测控硬件平台（或装置）。包括：通用控制模块；通用通信模块；数据采集模块；智能通风专用自动化执行机构。

（3）仓储管理及作业移动终端测控系统开发。包括：基于Android系统的移动终端管理软件；基于智能手机或平板电脑的通风作业异地远程控制系统；基于智能手机或平板电脑的气调作业异地远程控制系统。

（4）建立应用示范点。

3. 考核指标

开发兼容不同语言、不同操作系统的面向对象的智能粮库管理平台软件1套。开发粮情检测、出入库管理、质量管理、卡薄管理、安防监控、仓储作业管理系列子软件1套。开发基于Android系统的智能粮库移动终端管理软件1套。2-3项软件著作权登记注册。开发3-4种智能粮库专用测控模块，申报专利2-3项。建立示范点2-3个。

4. 经费额度

本项目国拨经费控制额度为150万元，研究周期2年，定向择优，配套资金不少于国拨资金。
