# 农业部农机化技术开发推广总站、中国农业机械流通协会关于开展深松机作业竞赛活动的预备通知

## 农业部农机化技术开发推广总站、中国农业机械流通协会关于开展深松机作业竞赛活动的预备通知（农机推（体）发[2013]61号）

深松机生产企业及有关单位：

为加大深松技术的宣传和推广应用力度，指导农民选购机型，促进深松机技术进步，提升深松机的综合使用效能，农业部农业机械化技术开发推广总站和中国农业机械流通协会决定于2013年中国国际农业机械展览会期间，举办深松机作业竞赛活动。有关事项通知如下：

**一、**组织与实施

1. 本次竞赛活动由农业部农业机械化技术开发推广总站和中国农业机械流通协会联合组织实施，设一等奖、二等奖、三等奖各一名，颁发奖牌和证书。竞赛结果在新闻媒体公布。

2. 企业自愿报名参加竞赛活动。

3. 竞赛依据：《深松机作业竞赛活动测评打分办法》。该办法由主办方提出并由参赛企业集体讨论修改通过后执行。

4. 测评工作由鉴定、推广部门的专业人员进行，测评过程参赛企业可派代表全程监督。

5. 竞赛活动主办方将邀请农机系统有关领导、专家、学者，有关农机推广机构负责人及技术人员，农机经销商，农机合作组织骨干及农机大户，有关农机科研院所，大专院校技术人员及2013中国国际农业机械展览会观众参观竞赛活动现场。

**二、**参赛深松作业机组及选手要求

1. 深松机应通过省级以上农机鉴定部门鉴定，取得推广鉴定证书，且在有效期内。

2. 参赛深松机包括单一深松作业功能的机型和含深松作业功能的联合作业机型。要求：1）深松作业深度在35厘米以上；2）对牵引形式、深松铲结构、行数和行距不作限制；3）联合作业机型经调整或简单拆卸后可进行单项深松作业，作业结果不影响对测评指标的检测。

3. 深松机由参赛企业提供，配套动力由参赛企业提出马力数范围，主办单位统一提供（含燃油）。

4. 作业机组操作选手由参赛企业选定，人员可以是企业职工，也可以聘请社会农机操作人员。操作选手须有拖拉机驾驶证。

**三、**竞赛内容与测评指标

竞赛内容：深松机作业机组综合使用效果

测评指标：

1. 深松机挂接时间

2. 经济性：主要有机具纯工作小时幅宽生产率、主燃油公顷消耗量。

3. 作业质量：主要有深松深度合格率、碎土率、有效深松度、衔接行距合格率、幅宽漏松面积。

4. 可靠性：主要有机具首次出现故障幅宽作业量、总故障时间。

**四、**竞赛时间、地点及日程安排

时间：2013年10月26下午14：00～16：00

地点：山东省青岛即墨市

日程安排：26日上午测评人员集中培训，厂家现场调试机具；26下午深松机作业竞赛和测评。

具体报到时间、地点另行通知。

**五、**报名及其它事项

1. 参加竞赛活动的企业人员（含操作选手）食宿自理。

2. 参加作业竞赛活动的企业需向主办方提交《深松机作业竞赛活动报名表》（见附件），提供在有效期内的推广鉴定证书（复印件），并于9月1日前报送至中国农业机械流通协会。
