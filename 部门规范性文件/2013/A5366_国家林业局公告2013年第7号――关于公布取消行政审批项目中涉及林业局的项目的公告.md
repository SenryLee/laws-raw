# 国家林业局公告2013年第7号――关于公布取消行政审批项目中涉及林业局的项目的公告

## 国家林业局公告（2013年第7号）

根据国务院审改办《关于取消有关行政审批项目的函》（监函〔2012〕85号）的要求，现将取消行政审批项目中涉及我局的项目（4项）予以公告。

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 项目名称 | 设定依据 | 实施机关 |
| 1 | 天保工程省级实施方案调整审批 | 《国家林业局关于印发〈天然林资源保护工程管理办法〉和〈天然林资源保护工程核查验收办法〉的通知》（林天发〔2001〕180号） | 省级以上林业主管部门 |
| 2 | 天保工程区木材加工等企业关闭破产审核 | 《关于做好天然林保护工程区木材加工等企业关闭破产工作的通知》（林计发〔2006〕159号） | 国家林业局 |
| 3 | 全国性及跨省区域性林产品交易会审批 | 《国家林业局关于加强林产品交易会管理的通知》（林行发〔2003〕29号） | 国家林业局 |
| 4 | 地方举办的林产品交易会审批 | 《国家林业局关于加强林产品交易会管理的通知》（林行发〔2003〕29号） | 县级以上地方林业主管部门 |
