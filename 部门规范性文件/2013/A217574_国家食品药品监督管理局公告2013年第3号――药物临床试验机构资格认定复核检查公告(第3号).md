# 国家食品药品监督管理局公告2013年第3号――药物临床试验机构资格认定复核检查公告(第3号)

国家食品药品监督管理局公告

（2013年第3号）

药物临床试验机构资格认定复核检查公告（第3号）

根据《中华人民共和国药品管理法》、《药物临床试验机构资格认定办法（试行）》以及《药物临床试验机构资格认定复核检查工作方案》的有关规定，经资料审查、现场检查、技术审核以及会审，山东大学第二医院等63家医疗机构及所列专业通过药物临床试验机构资格认定复核检查，继续具备药物临床试验资格。

特此公告。
