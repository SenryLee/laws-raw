# 国土资源部关于2012年全国矿业权评估师执业资格考试合格人员名单公告

| 科目名称 | 试卷满分 | 合格标准 |
| 财务与法律 | 100 | 60 |
| 地质与矿业工程 | 150 | 90 |
| 矿业权评估实务 | 150 | 90 |
| 矿业权评估案例 | 100 | 60 |
