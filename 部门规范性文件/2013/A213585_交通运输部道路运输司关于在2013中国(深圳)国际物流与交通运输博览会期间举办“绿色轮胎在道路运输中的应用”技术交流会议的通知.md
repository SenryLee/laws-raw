# 交通运输部道路运输司关于在2013中国(深圳)国际物流与交通运输博览会期间举办“绿色轮胎在道路运输中的应用”技术交流会议的通知

## 交通运输部道路运输司关于在2013中国（深圳）国际物流与交通运输博览会期间举办“绿色轮胎在道路运输中的应用”技术交流会议的通知（交运便字[2013]194号）

各省、自治区、直辖市道路运输管理局（处）：

为加快推进绿色循环低碳交通运输发展，大力推广“绿色轮胎”等先进技术在道路运输车辆和城市公交车辆上的应用，推动道路运输业和城市公交绿色、可持续发展，经研究，定于今年10月“2013中国（深圳）国际物流与交通运输博览会”期间，在深圳市举办“绿色轮胎在道路运输中的应用”技术交流会议。现将有关事项通知如下：

**一、**会议时间

报到时间：10月14日；

会议时间：10月15日一天。

**二、**会议主要内容

会议的主要内容有：

1. 介绍世界轮胎前沿技术与发展趋势；

2. 介绍欧盟轮胎标签管理法规；

3. 介绍国内外运输企业轮胎科学合理使用经验；

4. 介绍我国轮胎翻新技术及发展趋势。

**三、**参加人员

会议参加人员有：

1. 各地道路运输管理局（处）分管车辆技术与节能减排工作的负责同志，以及车辆技术管理处（科）室负责同志；

2. 部一至三批甩挂运输试点企业车辆技术（机务）管理负责人，部第一批公交都市创建城市骨干公交企业分管车辆技术（机务工作）的负责人。以上甩挂运输试点企业和公交企业由省级运管部门代为通知；

3. 有关客、0.货汽车生产企业及轮胎生产企业技术部门负责人。以上企业分别由中国公路学会客车分会、部节能服务中心和中国橡胶工业协会代为通知；

4. 其他有关单位人员：中国道路运输行业协会、中国汽车维修行业协会、中国橡胶工业协会、中国轮胎翻修与循环利用协会、中国公路学会客车分会。

**四、**会议报到及开会地点

会议报到及住宿地点为：深圳市马哥孛罗好日子酒店，酒店地址：深圳市福田区福华一路28号，酒店电话：0755-82989888。

开会地点为：深圳会展中心六楼桂花厅，地址：深圳市福田区福华三路深圳会展中心，距离住宿酒店约一千米。

**五、**会议相关事项

1. 本次会议由部道路运输司和德国国际合作机构（GIZ）联合主办，由深圳市交通运输委员会和部公路科学研究院共同承办；

2. 报名方式：为便于会议组织安排，请参会人员填写《参加会议回执表》（见附件）并于9月25日前传真至深圳市交通运输委员会港航货运局，联系人：赵晓君，电话：13510113777，传真：0755-25266300；

3. 会议接站安排：10月14日全天，会议承办方将在深圳市机场、火车站安排专人接站；

4. 会议食宿安排：会议代表的食宿统一安排，费用自理。不另收取会务费。
