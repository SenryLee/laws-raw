# 国家安全监管总局办公厅关于举办第一届中国国际化工过程安全研讨会暨石油化工安全新技术新产品展览会的通知

国家安全监管总局办公厅关于举办第一届中国国际化工过程安全研讨会暨石油化工安全新技术新产品展览会的通知

（安监总厅国际〔2013〕115号）

各省、自治区、直辖市、计划单列市及新疆生产建设兵团安全生产监督管理局，有关中央企业：

为强化化工企业安全生产基础建设，促进化工过程安全管理方法的推广与应用，定于2013年9月3日至9月5日在山东青岛举办第一届中国国际化工过程安全研讨会暨石油化工安全新技术新产品展览会（以下简称研讨会暨展览会）。现将有关事项通知如下：

**一、**研讨会暨展览会的主题

化工过程安全在中国。

**二、**研讨会暨展览会的主要内容

（一）研讨会将组织国内外专家介绍化工过程安全管理理论、技术与方法，分享过程安全管理各要素实践经验，并进行广泛交流与研讨，主要内容包括：过程安全文化；过程安全法律、法规、规章制度；风险分析和基于风险的决策；变更管理；设备完整性；应急响应和规划；过程安全指标；化工安全技术；事故调查与事故教训分享；过程安全管理审核；过程安全管理展望等。

（二）展览会将重点展示国内外石油化工企业过程安全管理进展与绩效；采用新技术、新工艺、新材料、新设计，促进改善劳动条件、保证安全生产、防止职业病危害，提高本质安全水平的成果；在改进安全管理方法、强化安全管理手段、加强安全培训等软科学方面的创新成果；各类化工安全新技术新装备，包括监测、监控、报警、防毒、防腐、阻燃、阻火、防雷、防静电、防火防爆、急救、救护、应急等技术与装备。

研讨会暨展览会的详细安排请浏览以下网址：http：//qdpsm.chemicalsafety.org.cn， http：//ccps.coal-china.org.cn。

**三、**时间和地点

（一）研讨会。

1.时间：9月4日至5日。

2.地点：山东青岛凯宾斯基酒店（地址：山东省青岛市黄岛经济技术开发区银沙滩路178号）。

3.注册报到：9月3日全天。

4.报到地点：山东青岛凯宾斯基酒店一层。

（二）展览会。

1.展览时间：9月3日至5日。

2.参观时间：9月3日至4日，9：00-16：00；

9月5日，9：00-14：00。

3.地点：山东青岛凯宾斯基酒店一层。

**四、**国内参加人员和参展单位

（一）参加研讨会人员。

请各省级安全监管局，计划单列市安全监管局相关负责人参会，并组织辖区内企业安全管理人员参会；请各有关中央企业相关负责人参会，并组织所属企业安全管理人员参会。（参会代表名额分配表见附件1）

（二）参展单位。

1.请中石油、中石化、中海油、中国中化、中国化工、中国化学工程、神华集团、大唐能源化工等企业参展，展示近年来安全管理工作取得的成就和安全科技新成果。

2.邀请美国陶氏、德国巴斯夫股份公司、美国杜邦公司、德国拜耳集团、塞拉尼斯公司等国外化工企业展示化工安全科技。

3.请各省级安全监管局推荐辖区内企业参展，展示石油化工安全新产品、新技术。

（三）参观展览人员。

1.请各省级安全监管局、有关中央企业按照要求（见附件1）组织人员参观展览会。参观人员由各单位有关负责同志带队，并指定联络人。

2.请山东省安全监管局、青岛市安全监管局协助组委会做好观众组织工作。

（四）媒体报道。

邀请新华社、中央电视台、中国安全生产报社、国家安全监管总局政府网站、中国化工报社等新闻单位记者参加会议。
