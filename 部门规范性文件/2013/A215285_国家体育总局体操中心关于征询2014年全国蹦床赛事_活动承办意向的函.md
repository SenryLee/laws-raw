# 国家体育总局体操中心关于征询2014年全国蹦床赛事/活动承办意向的函

有关单位：

蹦床项目具有很好的艺术性、观赏性、竞技性和娱乐性，广受青少年的喜爱。近几年我国蹦床运动取得了长足进步。2005年以来，我国运动员在奥运会、世界锦标赛、世界杯总决赛上连续包揽男子个人和女子个人项目金牌，涌现出黄珊汕、何雯娜、董栋、陆春龙等一批国际顶尖选手及十余名世界冠军，蹦床项目的社会关注度和影响力也日益提高。

为推动我国蹦床运动的发展，经研究决定，2014年由国家体育总局体操中心主办的全国性蹦床赛事/活动安排如下：

|  |  |  |
| --- | --- | --- |
| 序号 | 赛 事 名 称 | 比赛时间 |
| 1 | 全国蹦床锦标赛 | 4月或5月 |
| 2 | 全国蹦床冠军赛 | 9月或10月 |
| 3 | 全国青少年蹦床锦标赛 | 10月或11月 |
| 4 | 全国蹦床系列赛第一站 | 待定 |
| 5 | 全国蹦床系列赛第二站 | 待定 |
| 6 | 全国蹦床年龄组比赛 | 4月或5月 |
| 7 | 全国蹦床青少年夏（冬）令营 | 7月或12月 |
| 8 | 全国蹦床青少年训练营 | 待定 |
| 9 | 2015年蹦床世界杯系列赛＊ | 4-6月 |

注＊：根据国际体操联合会的规程规定，须在2014年6月前申办2015年蹦床世界杯系列赛。

承办赛事/活动单位应当具备下列条件：

1. 有与竞赛/活动规模相当的组织机构和管理人员，具有一定的办赛/办活动能力经验；

2. 制定比赛/活动组织实施方案；

3. 能够确保比赛/活动所需的经费；

4. 能够确保赛事/活动所需的场地、设施和器材；

5. 组委会可利用承办的赛事/活动和明星运动员进行相应的市场开发，具体内容与方式可与体操中心详细商议。

6. 承办单位一经签署协议不得将赛事/活动承办权移交到第三方，如确需移交须经国家体育总局体操运动管理中心重新审批。

请对上述赛事/活动有承办意向的单位于2013年10月1日之前回函。我中心将在2013年11月1日前决定赛事承办单位。
