# 国家外国专家局关于报送2014年度外国文教专家聘请计划的通知

国务院各有关部委、直属机构， 中央各有关单位外国文教专家工作主管部门，新疆生产建设兵团外专局：

为进一步落实《国家外国专家局 财政部关于进一步加强外国文教专家聘请计划和经费管理的通知》（外专发〔2011〕128号），鼓励和支持聘请单位通过引进外国专家，提高科研、教学水平，提升学科实力和国际影响力，国家外国专家局将制定2014年度外国文教专家聘请计划。

请各外国文教专家工作主管部门按照本通知要求，组织所属外国文教专家聘请单位于2013年9月1日前向国家外国专家局申报本单位2014年度外专聘请计划，同时报送2013年度聘请计划执行情况。国家外国专家局将综合聘请单位的申报材料和主管部门的调整建议，研究制订2014年度外国文教专家聘请计划。具体要求如下：

**一、**各部门、各单位要立足“以我为主、按需引进、突出重点、讲求实效”的原则，落实“高端引领、整体推进”的要求，围绕国家急需紧缺领域和自身重点发展方向，在基础优势学科、新兴交叉学科、前沿研究领域等方面着力引进高层次外国专家和专家团队，不断调整外国专家队伍的结构和层次，努力在人才培养、科学研究、社会服务和文化传承创新上实现新突破。

**二、**各部门、各单位要在国家外国专家局下达的2013年度外专聘请计划的基础上，科学布局、合理规划，实事求是地做好2014年度的聘请计划申报工作。

**三、**申报材料要包含以下内容：

1、外国文教专家聘请2013年度工作总结和2014年度工作计划

2、2014年度外国文教专家聘请计划申报表（附表1）

3、2014年度国家重点引智项目申报材料（按各项目相关文件通知的要求执行）

4、2014年度聘请单位重点引智项目申报表（附表2）

5、2013年度外国文教专家聘请计划执行情况汇总表（附表3）

6、2013年度国家重点引智项目年度总结报告（按各项目相关文件通知的要求执行）

7、2013年度聘请单位重点引智项目成果报告表（附表4）

其中国家重点引智项目指：“111计划”、“引进海外高层次文教专家重点支持计划”、“海外名师计划”等。申报材料和年度总结按各项目相关文件通知的要求执行。

聘请单位重点引智项目指：围绕重点学科、重点发展领域、重大人才培养计划等引进高层次外国专家的引智项目。

**四、**聘请单位要高度重视计划申报和成果总结工作，国家外国专家局将以此作为调整和制定2014年度外专聘请计划的主要依据，对外专工作出色、聘请成效明显的单位将进行重点支持。

**五、**聘请单位将申报材料报送主管部门的同时，需将书面材料和数据光盘各一份同时报送国家外国专家局教科文卫专家司。请将2014年度项目申报表和2013年度项目成果报告表分别装订成册。

**六、**本通知及相关表格可从国家外专局网站（www.safea.gov.cn）下载。
