# 中华全国供销合作总社科技教育部关于2013年全国供销合作社系统职教本科师资班招生考试时间地点的通知

## 中华全国供销合作总社科技教育部关于2013年全国供销合作社系统职教本科师资班招生考试时间地点的通知（供销科教函字〔2013〕5号）

各省、自治区、直辖市供销合作社教育主管部门，山西财经大学、安徽财经大学、山西大学商务学院招生办公室：

根据《中华全国供销合作总社办公厅关于做好2013年全国供销合作社系统职教本科师资班招生工作的通知》（供销厅科字〔2012〕96号）规定，2013年全国供销合作社系统职教本科师资班招生考试于2013年5月14日-16日在河北省石家庄市进行，现将有关事项通知如下：

**一、**考生报到：考生于2012年5月13日下午3：00至6：00在北方大厦大堂报到，报到时考生需携带身份证、学生证领取《准考证》。

**二、**招生院校负责人与考生见面会时间、地点：

5月13日19：30在北方大厦召开招生院校负责人与考生见面会。参加人员：全体考生、带队老师、家长及相关人员等。

**三、**考试时间、地点：

|  |  |  |  |
| --- | --- | --- | --- |
| 时　 间 | 5月14日 | 5月 15日 | 5月16日 |
| 上午9：00-11：00 | 语文 | 外语 | 面试 |
| 下午2：30- 4：30 | 数学 | 面试 | 面试 |

笔试、面试地点：北方大厦

**四、**考生注意事项：

考生必须携带《身份证》、《学生证》和《准考证》提前十五分钟进入考场。

**五、**考生住宿安排及联系方式：

考生住宿点：北方大厦（石家庄市胜利北街309号）

房间价格： 150元/普通2人间

160元/商务2人间

180元/3人间

房间预定电话：0311-86839896、85918899

北方大厦联系人：韩经理18031850011

河北商贸学校联系人：闫老师13933883351

考生凭本《通知》复印件或下载件自行预定房间享受此优惠价格，费用自理。

**六、**北方大厦乘车路线：

1.乘坐火车：

⑴石家庄火车站下车（西广场出站）：乘148路公交车到省胸科医院站下车，北行300米路东即到。直接打车大约35元。

⑵石家庄火车北站下车：乘164路到省胸科医院站下车，北行300米路东即到。直接打车大约20元。

2.乘坐高客：

⑴客运总站下车：下车后从自强路东口乘131路、132路公交车到省胸科医院站下车，北行300米路东即到，直接打车大约20元。

⑵石家庄火车北站客运站下车：乘164路到省胸科医院站下车，北行300米路东即到。直接打车大约20元。

3.乘坐飞机：从机场乘开往市区旅客班车到河北大戏院下车后，沿建设大街北行50米换乘2路公交车到省胸科医院站下车，北行300米路东即到，打车大约20元；从机场直接打车大约100元，车程30分钟。

4.自带车辆：从石太高速公路石家庄北出口（西古城）下高速，南行1公里路东即到。

请各省级供销合作社教育主管部门负责通知考生学校做好组织衔接工作。
