# 交通运输部财务司关于编报2014年度中央行政事业单位国有资产配置计划的通知

## 交通运输部财务司关于编报2014年度中央行政事业单位国有资产配置计划的通知（财资便字〔2013〕232号）

部属各单位：

根据国家机关事务管理局《关于编报2014年度中央行政事业单位国有资产配置计划的通知》（国管资〔2013〕409号）的要求，为做好国有资产配置计划的编报工作，现将有关事项通知如下：

**一、**请各单位在2013年12月23日前以正式公文报送部门资产年度配置计划汇总表、部门资产年度配置计划明细表、编报说明等纸质材料，并附相关电子数据。

**二、**请各单位登录国管局网站（http：//www.ggj.gov.cn），在“下载中心”栏目下的“2014年度资产配置计划填报注意事项”中下载程序与参数。
