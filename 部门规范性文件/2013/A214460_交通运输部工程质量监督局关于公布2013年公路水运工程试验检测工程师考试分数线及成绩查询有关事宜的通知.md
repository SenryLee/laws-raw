# 交通运输部工程质量监督局关于公布2013年公路水运工程试验检测工程师考试分数线及成绩查询有关事宜的通知

**一、**经部考试委员会研究，综合考虑各科目试题难易程度及通过率，2013年公路水运工程试验检测工程师考试各科目分数线如下：

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 公路科目 | 公共基础 | 材料 | 交安 | 公路 | 隧道 | 桥梁 | 机电 |
| 合格线 | 45 | 72 | 72 | 90 | 83 | 72 | 72 |
| 水运科目 | 公共基础 | 材料 | | 结构 | | 地基与基础 | |
| 合格线 | 45 | 65 | | 80 | | 90 | |

**二、**2013年公路水运工程试验检测考试检测工程师成绩查询时间：2013.8.3～2013.8.16。

本年度考试阅卷采用“扫描识别”方式，对答题卡分别进行二次的图像识别与比对，以保证考试成绩客观准确。

考生若对成绩仍有疑义的，应在规定时间内向受理报名的省级交通运输（公路、水运）质监机构提出成绩查询申请，并提供个人姓名、身份证号、准考证号、查询的科目名称、考场号和现有成绩。

省级交通运输（公路、水运）质监机构受理查询申请时间：2013.8.3～2013.8.20。逾期不予受理。

请各省级质监机构对所受理的信息进行汇总，于2013年8月23日下午17：00前报部质监局综合处。

交通运输部工程质量监督局

2013年8月1日
