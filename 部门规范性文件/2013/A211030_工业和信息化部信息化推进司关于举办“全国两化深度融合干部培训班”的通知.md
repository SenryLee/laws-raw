# 工业和信息化部信息化推进司关于举办“全国两化深度融合干部培训班”的通知

各省、自治区、直辖市及计划单列市、副省级省会城市、新疆生产建设兵团及工业和信息化主管部门，有关单位：

根据工作计划安排，为适应当前的形势发展要求，打造高素质的推进两化深度融合干部队伍，更好胜任两化深度融合推进任务，我司定于11月上旬在北京理工大学举办全国两化深度融合干部培训班。现将有关事宜通知如下：

**一、**培训时间地点

时间：11月4日-11月8日，为期四天半。

地点：北京理工大学研究生楼101教室（地址：北京海淀区中关村南大街5号，北京理工大学校内）。

**二、**培训师资及承办单位

此次培训由部、司级领导、专家学者和典型企业主要领导为学员授课。北京理工大学两化融合发展研究院具体承办。

**三、**参加培训人员

全国副省级以上工业和信息化主管部门、各地大中型企业副总裁以上领导及各行业协会的相关负责人参加培训。

**四、**培训主要内容

1. 国家信息化方针路线。

2. 工业转型升级的政策措施

3、两化深度融合政策措施。

4. 新一代信息技术发展的趋势。

5. 重点行业两化融合推进重点及发展方向。

6. 重点企业两化融合的典型案例剖析。

7. 我国电子商务、物流信息化的发展思路、主要目标及重点任务。

**五、**培训形式

培训将采取专家授课、讲学互动、典型案例分析及经验交流等多种形式。

**六、**相关说明

1.每个单位2个名额，至少一名公务员参加（副处级以上干部），也可选派大中型企业高管参加。参加培训人员无特殊原因必须参加，不得缺席。

2. 请于10月30日（周三）17：00之前，将填写好的报名回执电子版或传真发至会务组（相关信息及报名回执可在我部网站信息化司栏目查看并下载）。

3. 本次培训不收取任何费用，并协助解决住宿问题，住宿及其他费用由参加培训的单位自理。

4. 报到时请带近期免冠一寸照片2张（同底），身份证复印件一张（用于培训合格证书）。

5. 报到地点：11月3日（周日）12：00以后在北京神舟国际酒店报到，地址：北京市海淀区中关村南大街31号（毗邻北京国家图书馆北侧）。
