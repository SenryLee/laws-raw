# 海关总署关于广东省行政审批制度改革中涉及海关保税监管业务有关问题的通知

## 海关总署关于广东省行政审批制度改革中涉及海关保税监管业务有关问题的通知（2013年9月2日　署加发〔2013〕91号）

广东分署、各直属海关：

为落实《国务院关于执行〈全国人民代表大会常务委员会关于授权国务院在广东省暂时调整部分法律规定的行政审批的决定〉的通知》（国函〔2013〕9号），加快转变政府职能，支持广东省建设全国加工贸易转型升级示范区，现就广东省行政审批制度改革中涉及海关保税监管业务事项的相关问题明确如下：

**一、**加工贸易备案（变更）、内销申请审核

广东省内经营企业办理加工贸易备案（变更）、内销申请等手续时，主管海关按以下规定办理：

（一）加工贸易备案（变更）

1. 经营企业向海关申请加工贸易备案和变更的，主管海关不再收取《加工贸易业务批准证》、《联网监管企业加工贸易业务批准证》和变更证明；

2. 经营企业申请加工贸易合同备案，主管海关应向企业收取由商务主管部门签发的《加工贸易加工企业生产能力证明》，另有规定的除外；

3. 加工贸易合同所对应的料件、成品及单耗等有关情况，由企业直接向海关申报，主管海关根据有关规定进行审核；

4. 开展加工贸易涉及贸易管制商品，按照现行规定需在备案（变更）环节提交相关批准文件的，主管海关应在备案（变更）时向企业收取相关批准文件；

5. 加强手册有效期管理，主管海关原则上按照经营企业出口合同有效期确定手册有效期，手册有效期原则上不得超过一年，经主管海关批准可予以延期，有效期最长不得超过两年。对开展飞机、船舶等大型装备制造业加工贸易业务的企业，经主管海关批准，可按实际出口合同有效期设定手册有效期。

（二）异地加工贸易管理

经营企业和加工企业均属于广东省内企业的，主管海关不再收取《加工贸易业务批准证》，其他事项按照《中华人民共和国海关关于异地加工贸易的管理办法》（海关总署令第74号）办理；经营企业或加工企业有一方不属于广东省内企业的，按照署令第74号办理。

（三）加工贸易内销管理

广东省内的经营企业申请加工贸易货物内销的，主管海关不再收取《加工贸易保税进口料件内销批准证》。

（四）规范信息化系统录入

经营企业和加工企业均属于广东省内企业的，主管海关应要求企业通过“纸质手册电子化系统（企业端）” 、“电子账册系统（企业端）”和“加工贸易内销管理系统（企业端）”录入申报备案（变更）、内销申请表等数据时，在“批准文号”栏目统一填写“1111” ；其他情况按照原有规定要求录入。

**二、**加强实际监管和风险防范

（一）加强对涉及特殊加工贸易商品的审核工作

按照现行规定需在备案（变更）环节提交相关批准文件的，主管海关要加强对有关商品的备案（变更）审核。

（二）加强单耗管理工作

各关要加强对申报单耗的审核，并进行后续监控分析，对发现单耗异常、存在风险的，应实施重点核查或稽查。

（三）加强风险监控分析

各关要充分利用保税业务监控分析系统和HL2008等信息化系统，积极开展高风险企业和特殊商品信息分析；加强加工贸易监管风险节点控制，有效防范和化解监管风险。

（四）加强海关各部门联系配合

保税监管部门应加强与稽查、缉私等部门的联系配合，及时移交风险和案件线索，提请稽查、缉私部门处置；稽查、缉私部门要将处置结果及时反馈保税监管部门。

**三、**加强外部联系配合

广东分署要加强与广东省编办和外经贸厅等相关部门的联系沟通，及时了解改革内容和工作进度。对涉及海关的改革项目及时研究应对措施和衔接方案，制发操作指引，保证海关业务正常运作和监管到位，确保执法统一。

广东省内各直属海关要指导基层海关加强与所在市、县（区）政府行政审批改革主管部门的联系配合和情况交流，及时了解当地行政审批改革进度，加强与当地政府和各相关管理部门的沟通协调。

**四、**暂停执行相关规定

《中华人民共和国海关对加工贸易监管办法》（署令第113号发布，署令第168号、第195号修订）、《中华人民共和国海关关于加工贸易边角料、剩余料件、残次品、副产品和受灾保税货物的管理办法》（署令第111号）、《中华人民共和国海关关于异地加工贸易的管理办法》（署令第74号）、海关总署公告2007年第1号、《海关总署关于执行〈中华人民共和国海关加工贸易企业联网监管办法〉（署令第150号）有关问题的通知》（署加发〔2007〕10号）、《海关总署关于印发〈海关加工贸易监管业务操作规程〉的通知》（署加发〔2005〕73号）的相关条款，与本通知存在冲突的，暂停执行。

在执行本通知过程中如遇问题，请及时向总署加贸司反馈。

特此通知。
