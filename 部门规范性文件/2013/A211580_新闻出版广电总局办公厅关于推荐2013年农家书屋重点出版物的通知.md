# 新闻出版广电总局办公厅关于推荐2013年农家书屋重点出版物的通知

新闻出版广电总局办公厅关于推荐2013年农家书屋重点出版物的通知

（新出厅字〔2013〕356号）

各省、自治区、直辖市新闻出版局，新疆生产建设兵团新闻出版局，解放军总政治部宣传部新闻出版局，中国出版集团公司、中国教育出版传媒集团有限公司、中国科技出版传媒集团有限公司，中央在京出版单位：

农家书屋工程提前完成后，已进入巩固、完善、提高的新阶段。在新的形势下做好农家书屋工作，要认真落实党的群众路线教育实践活动要求，切实把满足农民群众实际需求放在首要位置，通过更为有效的方式实现农家书屋出版物的补充更新。为指导各地做好2013年度农家书屋出版物补充工作，国家新闻出版广电总局决定制定《2013年农家书屋重点出版物推荐目录》。现将有关事项通知如下：

**一、**组织工作

《2013年农家书屋重点出版物推荐目录》按照分级组织选评的原则，由各省（区、市）、各有关部门和出版单位组织推荐，总局相关部门组织评审确定。

（一）各省（区、市）新闻出版局、新疆生产建设兵团新闻出版局农家书屋办公室负责推荐本地区出版单位的出版物；解放军总政治部宣传部新闻出版局负责推荐部队系统出版单位的出版物；中国出版集团公司、中国教育出版传媒集团有限公司、中国科技出版传媒集团有限公司负责推荐本集团所属出版单位的出版物；其他中央在京出版单位直接向总局推荐本出版单位的出版物。

（二）总局将在各地区、各部门、各单位推荐出版物的基础上，经专家评审，确定《2013年农家书屋重点出版物推荐目录》。

**二、**推荐原则

（一）推荐出版物的内容要求

1.传播社会主义核心价值观。突出“中国梦”的宣传教育，弘扬中国精神，凝聚中国力量，展现中华民族的奋斗历程，激发广大农民群众追梦圆梦的热情和干劲。

2.满足农民群众实际需求。一是要体现内容的科学性，把对农民群众科学观念的普及、文化意识的启蒙、精神世界的改造作为重点，有利于塑造具有新思想、新观念的新型农民；二是要体现内容的知识性，更好地满足农村青少年儿童学知识受教育的需要，开阔农民群众的眼界，提高农民群众的知识水平；三是要体现内容的实用性，侧重与农民群众切身利益相关的卫生保健、权益保障、增收致富等方面，帮助农民群众解决实际问题；四是要体现内容的丰富性，多推荐故事性强、可读性强的通俗作品，满足农民群众农闲时消遣娱乐的需要。

（二）推荐出版物的品种要求

1.图书

（1）推荐图书以2012年以来出版的新书为主，并符合“内容要求”。中央在京出版单位平均每家报送图书品种数量5－8种，解放军总政治部宣传部新闻出版局、中国出版集团公司、中国教育出版传媒集团有限公司、中国科技出版传媒集团有限公司可根据本系统出版单位的实际情况统筹调配；各地方出版单位平均每家报送图书品种数量不超过5种，各省（区、市）新闻出版局、新疆生产建设兵团新闻出版局可根据本地区出版单位实际情况统筹调配。

（2）中宣部、教育部、团中央向全国青少年推荐的“100种优秀图书”、原新闻出版总署向全国推荐的“2012年度大众喜爱的50种图书”、“2013年总局向全国青少年推荐百种优秀图书”可直接参与评审，不占用出版单位的申报名额。

（3）对少数民族文字图书（蒙古文、藏文、维吾尔文、哈萨克文、朝鲜文等5种民族文字出版物）的推荐，由各省（区、市）新闻出版局根据各少数民族聚居区的分布情况酌定，鼓励报送双语图书。

（4）港澳台地区出版的适合农家书屋的图书可适量推荐，由中国图书进出口（集团）总公司具体负责并按照有关规定办理手续。

（5）品种界定：一种书籍、图片，作为一个品种；属多卷本分册定价的（分别使用书号的），每一分册作为一个品种；多卷本统一定价的（使用一个书号的），作为一个品种（每一种卷本册数不超过3册，且为同一作品），修订本选择最新版。

2.音像制品和电子出版物

推荐范围为2013年9月底前已经出版，且在市场上继续销售的音像制品和电子出版物。平均每家出版单位报送品种数量不超过5种（每个品种光盘数量一般控制在5张以内），各省（区、市）新闻出版局可根据本地区出版单位实际情况进行统筹调配。“2013年总局向全国青少年推荐的50种优秀音像电子出版物”，可直接参与评审，不占用出版单位的申报名额。

3.报刊

考虑到农家书屋报刊订阅的延续性，2013年农家书屋重点推荐报刊仅在2012年报刊推荐目录的基础上略做调整。

对于列入目录的报刊，还可通过数字报刊的形式进入卫星数字农家书屋、网络数字农家书屋等。

**三、**具体要求

（一）各地区、各部门要认真负责、精心组织出版物推荐工作。要组织必要的讨论和研究，广泛听取意见，制订严谨科学的方案。对所属所辖出版单位要结合出书范围和特色，统筹调配，把更多的优秀出版物推荐上来。同时，对推荐出版物要进行严格把关、认真审核，确保推荐出版物内容、编校、装帧、印制的质量。

（二）凡推荐的出版物必须由本单位正式出版，并拥有出版权，能提供样书（样盘）。未正式出版的出版物不得推荐；有版权纠纷的出版物不得推荐。

（三）推荐出版物必须保证质量，为农家书屋所提供的出版物绝不能因为政府采购而在内容、编校、装帧、印制等方面降低质量标准，要与提供的样书（样盘）一致。

（四）推荐出版物一旦入选《2013年农家书屋重点出版物推荐目录》，必须向采购方保质并按时按量供货，不得以任何理由拒绝供货。

（五）对音像制品和电子出版物限定采购价格：VCD每张价格不超过6.5元；CD和CD－ROM每张价格不超过8元；DVD和DVD－ROM每张价格不超过10元。

（六）在农家书屋工程建设过程中，经举报查实，有个别出版单位为农家书屋供书时存在故意提高价格、删减内容、彩色印刷变黑白印刷等问题，总局已对此作出严肃处理。今后出版单位在为农家书屋提供出版物时，有涨价、不供货、降低质量标准等行为的，一经举报核实，将按规定处理并通报批评，同时取消其下一年度申报农家书屋重点出版物的资格；情况严重的，将取消其今后申报农家书屋重点出版物的资格。

各出版单位在推荐出版物的同时，须提交一份承诺书，对遵守上述版权、质量、供货、价格等规定做出承诺，由本出版单位负责人签字并加盖单位公章。

（七）农家书屋出版物的推荐始终秉承公开、公平、公正的原则进行。为落实好党的群众路线教育实践活动要求和中央“八项规定”，强化出版物推荐工作的纪律性和严肃性，各地区、各部门要严格把关，杜绝出版单位通过找关系、走后门、托请等手段，使劣质出版物进入推荐目录。对违反规定的出版单位，总局将视情况予以处理。

**四、**程序和时限

（一）各出版单位提交的申报材料，包括：

1．《农家书屋重点图书推荐汇总表》或《农家书屋重点音像制品和电子出版物推荐汇总表》1式2份（附件1、2），同时提供推荐图书的封面、版权页、目录、试读1-2页的图片1份；

2. 样书（样盘）1册（张、套）；

3. 出版单位发行部门联系表1式2份（附件3）；

4. 承诺书1份。

相关表格等可在中国农家书屋网（www.zgnjsw.gov.cn）下载。

（二）各地区、各部门要对申报材料进行汇总审核，并务必于2013年11月7日前将申报材料及电子版（光盘或电子邮件）报送总局。中央在京出版单位务必于2013年10月31日前将申报材料及电子版（光盘或电子邮件）报送总局。各地区、各部门和各单位要对申报的材料认真核对，确保准确无误。逾期不报视作自动放弃。
