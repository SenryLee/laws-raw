# 中国保险监督管理委员会关于征集第二代偿付能力监管制度体系研究项目承办单位的公告

## 中国保险监督管理委员会关于征集第二代偿付能力监管制度体系研究项目承办单位的公告（2013年5月8日）

2012年3月，中国保监会正式启动了第二代偿付能力监管制度体系建设，并于4月开展了第一批次6个项目研究工作。目前，部分项目已完成，其余项目工作也已取得阶段性成果。为了全面推进第二代偿付能力监管制度体系建设，我会现决定启动第二批“其他风险与风险相关性项目”等7个研究项目（见附件），并公开征集项目的承办单位，欢迎社会各界有意向、有能力的单位积极申请。现将有关事项公告如下：

**一、**项目任务

对第二代偿付能力监管建设有关问题进行理论研究，并结合我国保险行业实际，提出有关偿付能力监管政策和标准的建议方案。（各项目具体任务详见附件）

**二、**资质要求

申请单位应具备以下条件：

（一） 具备较强的偿付能力研究能力；

（二） 熟悉国际偿付能力监管改革和发展；

（三） 熟悉中国保险行业实际；

（四） 能够投入足够的资源，确保项目质量。

**三、**申请材料

请申请单位于2013年5月14日前向我会递交申请材料，具体包括：

（一）项目申请书；

（二）承办项目的可行性分析（包括申请单位基本情况、专业能力、既往研究和项目成果、参与中国保险市场情况、拟投入本次项目的资源等）；

（三）项目工作方案（包括研究目的、项目组人员构成、总体思路、任务分解、时间进度等）。

附件：

第二代偿付能力监管制度体系研究项目

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 项目名称 | 主要任务 | 完成  时间 |
| 1 | 第一支柱项目：其他风险与风险相关性项目 | 研究拟订第一支柱最低资本要求中除承保风险、利率风险和资产风险以外的其他风险的计量方法和资本要求标准； 　　研究拟订最低资本各风险之间相关性的计量方法和标准。 | 12月 |
| 2 | 第一支柱项目：动态偿付能力测试 | 研究拟订保险公司动态偿付能力测试标准。 | 12月 |
| 3 | 第一支柱项目：实际资本和资本分级 | 分析比较国际保险业和银行业的资本分级方法，研究拟订保险公司实际资本和资本分类方法、分级标准。 | 12月 |
| 4 | 第二支柱项目：保险公司风险管理要求与评估 | 研究保险公司风险管理监管要求的国际主流标准和最佳实践，拟订我国保险公司风险管理最低标准及评估要求。 | 12月 |
| 5 | 第二支柱项目：流动性风险 | 研究流动性风险的风险特征和计量方法，拟订保险公司流动性风险监管标准。 | 12月 |
| 6 | 第三支柱项目：公开信息披露要求 | 研究保险公司偿付能力信息公开披露的国际经验，拟订我国保险业偿付能力公开信息披露标准。 | 12月 |
| 7 | 保险集团偿付能力监管 | 对保险集团偿付能力监管进行国际比较研究，拟订我国保险集团偿付能力监管标准。 | 12月 |
