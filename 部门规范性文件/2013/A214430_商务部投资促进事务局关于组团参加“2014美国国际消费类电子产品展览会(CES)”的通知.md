# 商务部投资促进事务局关于组团参加“2014美国国际消费类电子产品展览会(CES)”的通知

## 商务部投资促进事务局关于组团参加“2014美国国际消费类电子产品展览会（CES）”的通知(商投促函[2013]188号)

各有关单位：

为进一步拓展与深化我国与美国、墨西哥两国在信息技术领域的投资经贸往来，促进我国信息技术产业与相关行业协会和企业的交流与务实合作，搭建电子信息产业洽谈与观摩平台，我局拟于2014年1月6日至1月13日组团赴美国、墨西哥开展信息技术产业投资促进活动，并参加2014美国国际消费电子产品展览会。

**一、**主要活动

1、参加美国国际消费类电子产品展览会（CES）

展览会概况：美国CES展览会是世界最大的消费类电子产品和技术的年度展会，每年1月在美国内华达州拉斯维加斯举行。参展产品包括音频技术、数码影像、新兴技术、游戏、高清家庭娛乐技术、家庭网络、家庭影院与录像、汽车内部技术与无线设备等。目前该展览会已成为全球规模最大并最具影响力的消费类电子专业展览会，是选择贸易伙伴及世界知名品牌新品发布首选平台，也是消费类电子技术和产品发展潮流的风向标。

2、举办中国-墨西哥信息技术产业投资合作说明会

拟在墨西哥举办中国-墨西哥信息技术产业投资合作说明会，与墨西哥相关产业机构和企业开展交流对接活动，并参观墨西哥信息技术产业园区。

墨西哥信息技术产业概况：据墨西哥信息技术、电信和电子工业全国商会预计，2012年墨西哥IT业市场价值将达170亿美元，增长幅度为12%。墨西哥在全球IT业出口方面居第四位，电信业是墨西哥的优势产业之一。墨政府近年以来已出台多项措施吸引外资进入电信业。

**二、**参团要求

为使此次出访活动务实有效，现邀请有意赴上述两国参展参会的有关单位选派业务主管人员（可携带助手）参团。

**三、**报名事项

请参团单位于2013年8月23日前将报名表填好盖章后反馈我局，并将身份证（正反两面）及护照（如有）首页、签字页扫描并发至邮箱 wangziqiang@fdi.gov.cn。

**四、**费用

各参团单位费用自理，相关费用由中国国际投资促进中心负责统一结算，费用标准另行通知。
