# 国家认监委关于开展2013年实验室资质认定专项监督检查工作的通知

各直属检验检疫局，各省、自治区、直辖市质量技术监督局，各国家资质认定行业评审组：

为了进一步培育和规范检测市场，促进检验检测服务业的有序发展，不断提升实验室资质认定工作的质量和水平，国家认监委拟组织开展2013年度实验室资质认定专项监督检查工作，现将有关事项通知如下：

**一、**指导思想

高举中国特色社会主义伟大旗帜，深入贯彻科学发展观，围绕“抓质量，保安全，促发展，强质检”十二字工作方针，持续加强对资质认定工作和资质认定获证实验室的监督管理，培育规范、有序运行的检测市场，不断提升我国检验检测服务业为国民经济和社会发展提供支撑和服务的效能。

**二、**主要工作安排

2013年实验室资质认定专项监督检查工作任务包括三方面：一是组织对资质认定获证实验室进行监督检查，重点就其遵守法律法规和资质认定管理制度，规范、诚信开展检验检测工作的情况进行核查；二是通过对获证实验室的现场检查，查找资质认定行政审批和技术评审环节存在的问题和不足，以便今后的改进；三是对省级质量技术监督局进行督查，督促其不断提升资质认定工作的规范性和有效性。

（一）对资质认定获证实验室的监督检查

各省（自治区、直辖市）质量技术监督局，各直属出入境检验检疫局，各国家资质认定行业评审组根据本通知的要求，制定本辖区（行业）的监督检查方案并组织实施。相关监督检查方案应要求本辖区（行业）资质认定获证实验室100%进行自查（资质认定获证实验室自查表见附表1）。在自查基础上，各单位可另行安排其他监督检查方式，提升资质认定监督检查效果。

中国计量科学研究院，中国检验检疫科学研究院，中国特种设备检测研究院，中国纤维检验局检验中心等单位按本通知要求组织进行自查，并按时向国家认监委报告自查情况。

在组织全国资质认定获证实验室自查的基础上，国家认监委将从山东、山西、辽宁、江西、江苏、河南、湖北、四川、贵州、陕西等10个省份的资质认定获证实验室中抽取150家实验室进行现场检查，重点抽取从事食品、妇女儿童用品、农资、建材、机动车及零部件等产品领域检验检测的获证实验室。上述10个省质量技术监督局应于4月30日前向国家认监委实验室部上报辖区内已获得资质认定的（1）食品、（2）妇女儿童用品、（3）农资、（4）建筑材料、（5）机动车及零部件等五个检验检测领域的实验室名录（见附件2）。

现场监督检查从5月开始，9月结束。国家认监委派出的现场检查组的全部费用由国家认监委承担。

（二）对省级质量技术监督局资质认定工作的督查

各省（自治区、直辖市）质量技术监督局根据本通知的要求，组织对本省实验室资质认定工作进行自查（省级质量技术监督局自查表见附件3），并形成自查报告。

国家认监委将组成检查组，结合对资质认定获证实验室的现场检查，对山东、山西、辽宁、江西、江苏、河南、湖北、四川、贵州、陕西等10个省质量技术监督局的实验室资质认定工作进行现场督查。

**三、**工作要求

（一）高度重视，认真部署落实

各省（自治区、直辖市）质量技术监督局，各直属出入境检验检疫局，各国家资质认定行业评审组应高度重视实验室资质认定专项监督检查工作，及时根据国家认监委文件的部署，制定本辖区（行业）的实验室资质认定监督检查方案并组织实施。监督检查结束后，应及时对监督检查和自查情况进行总结，分析存在的问题，提炼好的经验，及时组织整改，对发现存在违法违规情况的实验室及时进行处理，并按时向国家认监委提交监督检查情况报告。

（二）严肃认真开展现场检查

国家认监委组成检查组，对选取的10省份相关实验室和省级质量技术监督局进行现场监督检查和督查。检查组长应与相关省份质量技术监督局充分沟通，编制检查日程和检查路线。有关检查日程安排及路线经国家认监委实验室部审核后方可实施。

检查组应严肃、认真、客观地实施监督检查。检查组发现被检查实验室存在严重违法违规情况的，应立即报告国家认监委，由国家认监委根据行政处理程序进行处理，不得隐匿不报或越权处置。现场检查结束后，检查组应编写检查报告，并于10月15日前报送国家认监委实验室部。

检查组应严格遵守中央八项规定，轻车简从、厉行节约，不得由被检查实验室承担任何费用，不得收取实验室给予的劳务费、礼金或礼品，不得参加实验室组织的任何参观或宴请。检查组和被检查省份的质量技术监督局应对检查日程、路线和被检查实验室名单严格保密。对违反公正性和保密性要求者，国家认监委将严肃处理。

（三）按时上报监督检查和自查结果

各省（自治区、直辖市）质量技术监督局，各直属出入境检验检疫局，各国家资质认定行业评审组应于9月30日前将资质认定监督检查总结报告上报国家认监委，各省（自治区、直辖市）质量技术监督局还需同时上报资质认定工作自查报告（包括自查表）。

中国计量科学研究院，中国检验检疫科学研究院，中国特种设备检测研究院，中国纤维检验局检验中心等单位应于9月30日前将相关自查报告直接上报国家认监委。

上述各部门和检测机构未按要求组织开展自查活动，或未按时提交相关检查（自查）情况报告的，国家认监委将予以通报批评，并在今后的监督管理中重点进行督查。

（四）总结和回头看

国家认监委拟于11月底前完成实验室资质认定专项监督检查情况的总结，并通报专项监督检查结果。同时，根据各省检查情况，抽取一定比例的实验室和省级质量技术监督局进行“回头看”，核查监督检查及整改效果。

实验室资质认定专项监督检查工作过程中的相关事项和问题，各相关单位可向国家认监委实验室部联系问询。

| 3.2 | 根据工作需要，有效组织开展有关项目检测的能力验证、测量审核或实验室比对，并通报结果、对不能保证数据准确的实验室提出处理意见。 |  |
| 3.3 | 有效办理实验室名称、地址、人员或标准变更的有关手续，保证信息准确。 |  |
| 3.4 | 组织受理涉及相关检测机构和检测活动的信访、申投诉等举报，并及时组织调查和处理。 |  |
| 3.5 | 及时、准确向国家认监委报送资质认定获证实验室名录、能力验证情况等相关工作信息。 |  |
| （四）食品检验机构和司法鉴定机构资质认定工作有序开展 | 4.1 | 建立起与实际情况相适应的食品检验机构资质认定评审员和司法鉴定机构资质认定评审员队伍。 |  |
| 4.2 | 按照国家认监委要求，及时组织辖区内的食品检验机构进行资质认定。 |  |
| 4.3 | 按照国家认监委和司法部联合发文要求，与当地司法机关建立有效的沟通机制，逐步推动司法鉴定机构开展资质认定工作。 |  |
