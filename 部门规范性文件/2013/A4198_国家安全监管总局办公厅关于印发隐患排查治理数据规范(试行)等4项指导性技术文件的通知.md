## 3　定义


下列术语和定义适用于本文件。


**3.1**数据元 data element


一种数据单元，在某个上下文中视为不可分，通过一组属性描述其定义、标识、表示和允许值。


[GB/T 5271.4-2000 术语和定义 04.07.01]


**3.2**代码 code


表示特定事物（或概念）的一个或一组字符。若干个同类的代码为一个方面的内容而服务组成在一起形成代码表。


[GB/T 5271.4-2000 定义 04.02.03]


**3.3**值域范围 code set


代码元素集


将一种代码应用于编码集中的所有元素所产生的结果。


[GB/T 5271.4-2000 术语和定义 04.02.05]


**3.4**隐患


安全生产事故隐患（以下简称事故隐患），是指生产经营单位违反安全生产法律、法规、规章、标准、规程和安全生产管理制度的规定，或者因其他因素在生产经营活动中存在可能导致事故发生的物的危险状态、人的不安全行为和管理上的缺陷。


事故隐患分为两类，一类是“违反”型隐患，所有违法、违标、违规等行为和状态均视为事故隐患，另一类是由于某些因素而引起的三种现实表现：物的危险状态、人的不安全行为和管理上的缺陷。三种表现中的物是指生产过程或生产区域内的物质条件（如材料、工具、机器设备、成品、半成品），行为是指人在工作过程中的操作、指示或其他具体行为，管理是指各种生产活动的开展所必须的各种组织、协调等行动。 “安全生产事故隐患”可以简称“隐患”，与“安全生产事故隐患”、“事故隐患”、“安全隐患”同义。

## 4　数据元

**4.1**概述


数据元，又称数据类型，是一个通过一组属性描述其定义、标识、表示和允许值的数据单元。


本文件规范的数据元是业务应用系统涉及的基础数据单元。是通用数据元的一个子集。它的概念和结构遵循一般数据元的概念和结构，并具有自身的特点。


**4.2**数据元的描述规范


4.2.1 中文名称


定义：赋予数据元的单个或多个中文字词的指称。


约束：必选


数据类型：字符串


说明：命名应明确的表达数据元的含义，尽量减少冗余，增加精确度；在同一环境下的所有名称应该是唯一的。


4.2.2 同义名称


定义：一个数据元在应用环境下的不同称谓。如国家安全生产监督管理总局的同义名为国家安全监管总局。


约束：可选


数据类型：字符串


说明：一个数据元可以有多个同义词，第一个同义词应该是统一的约定名称。


4.2.3 表示符号


定义：数据元的表示符号，可用于数据交换时的交换名称。


约束：可选


数据类型：字符串


4.2.4 定义


定义：数据元的含义的描述，表达一个数据元的本质特性并使其区别于所有其他数据元的陈述。（特别明确的可省略。）


约束：可选


数据类型：字符串


对数据元定义应注意：


（1）每个定义必须区别于目录中的任何其他定义，以保证专一性。定义中所表述的一个或多个特性必须使被定义的概念与其他概念相区别。


（2）用描述性的短语或句子阐述，阐述必须简练、准确而不含糊，避免跟其他数据元定义互相依存。


（3）定义中仅可使用人们普遍理解的缩略语。


（4）所有简称在第一次出现时，必须予以说明。


4.2.5 数据元的数据类型


定义：表示数据元值的不同值的集合。


约束：必选


数据类型：字符串


说明：可能的实例为：“字符”、“序数”、“实数”、“比例数”、“二进制数”、“有理数”。


4.2.6 表示格式


定义：从应用的角度规定的数据元值的格式需求，包括所允许的最大或最小字符长度，数据元值的类型和表示格式等。

数据类型：字符串

## 4　数据元

**4.1**概述


数据元，又称数据类型，是一个通过一组属性描述其定义、标识、表示和允许值的数据单元。


本文件规范的数据元是业务应用系统涉及的基础数据单元。是通用数据元的一个子集。它的概念和结构遵循一般数据元的概念和结构，并具有自身的特点。


**4.2**数据元的描述规范


4.2.1 中文名称


定义：赋予数据元的单个或多个中文字词的指称。


约束：必选


数据类型：字符串


备注：命名应明确的表达数据元的含义，尽量减少冗余，增加精确度；在同一环境下的


所有名称应该是唯一的。


4.2.2 同义名称


定义：一个数据元在应用环境下的不同称谓。如国家安全生产监督管理总局的同义名为国家安全监管总局。


约束：可选


数据类型：字符串


备注：一个数据元可以有多个同义词，第一个同义词应该是统一的约定名称。


4.2.3 表示符号


定义：数据元的表示符号，可用于数据交换时的交换名称。


约束：可选


数据类型：字符串


4.2.4 定义


定义：数据元的含义的描述，表达一个数据元的本质特性并使其区别于所有其他数据元的陈述。（特别明确的可省略。）


约束：可选


数据类型：字符串


备注：对数据元的定义应注意以下几点：


（1）每个定义必须区别于目录中的任何其他定义，以保证专一性。定义中所表述的一个或多个特性必须使被定义的概念与其他概念相区别。


（2）用描述性的短语或句子阐述，阐述必须简练、准确而不含糊，避免跟其他数据元定义互相依存。


（3）定义中仅可使用人们普遍理解的缩略语。


（4）所有简称在第一次出现时，必须予以说明。


4.2.5 数据元的数据类型


定义：表示数据元值的不同值的集合。


约束：必选


数据类型：字符串


备注：可能的实例为：“字符”、“序数”、“实数”、“比例数”、“二进制数”、“有理数”。


4.2.6 表示格式


定义：从应用的角度规定的数据元值的格式需求，包括所允许的最大或最小字符长度，数据元值的类型和表示格式等。


约束：必选


数据类型：字符串

约束：可选


数据类型：字符串


说明：当值域范围是编码表示的枚举形式时，每一个数据元值及其实例都应当成对表示。

定义：根据对象的来源特性，在数据采集时，从应用角度规定该数据元是否为必选或可选

## 4　数据元

**4.1**概述


数据元，又称数据类型，是一个通过一组属性描述其定义、标识、表示和允许值的数据单元。


本文件的数据元是业务应用系统涉及的基础数据单元。是通用数据元的一个子集。它的概念和结构遵循一般数据元的概念和结构，并具有自身的特点。


**4.2**数据元的描述规范


4.2.1 中文名称


定义：赋予数据元的单个或多个中文字词的指称。


约束：必选


数据类型：字符串


说明：命名应明确的表达数据元的含义，尽量减少冗余，增加精确度；在同一环境下的所有名称应该是唯一的。


4.2.2 同义名称


定义：一个数据元在应用环境下的不同称谓。如国家安全生产监督管理总局的同义名为国家安全监管总局。


约束：可选


数据类型：字符串


说明：一个数据元可以有多个同义词，第一个同义词应该是统一的约定名称。


4.2.3 表示符号


定义：数据元的表示符号，可用于数据交换时的交换名称。


约束：可选


数据类型：字符串


4.2.4 定义


定义：数据元的含义的描述，表达一个数据元的本质特性并使其区别于所有其他数据元的陈述。（特别明确的可省略。）


约束：可选


数据类型：字符串


对数据元定义应注意：


（1）每个定义必须区别于目录中的任何其他定义，以保证专一性。定义中所表述的一个或多个特性必须使被定义的概念与其他概念相区别。


（2）用描述性的短语或句子阐述，阐述必须简练、准确而不含糊，避免跟其他数据元定义互相依存。


（3）定义中仅可使用人们普遍理解的缩略语。


（4）所有简称在第一次出现时，必须予以说明。


4.2.5 数据元的数据类型


定义：表示数据元值的不同值的集合。


约束：必选


数据类型：字符串

## 3　代码的编码原则和结构

**3.1**编制原则


本文件用14位字符分为三段，表示全国各级安全生产监管监察及应急救援机构，代码组成规则如下：


X X　 XX XX XX 　 XXX XXX




第三段：9到14位，内设机构、直属单位、派出单位机构代码


第一层：9到11位，内设机构、直属单位、派出单位


第二层：12到14位，内设机构、直属单位、派出单位下设一级单位




第二段：3到8位，各级部门机构代码


第一段：2位，类别标识符


第一段：类别标识符，用2位数字表示，01表示安全生产监督管理部门；02表示安委会成员单位部门；03表示煤矿安全监察机构；04表示煤矿安全监管部门；05表示安全生产应急救援机构。


第二段：各级部门机构代码，用6位数字表示表示县级（含）以上安全监管机关机构代码，有行政区划代码的则采用GB/T 2260规定的行政区划代码表示，其他不能用行政区划代码表示的用规定的编码表示。


第三段：各级部门机构内设机构、直属单位以及派出单位（乡镇、街道安全监管机构）代码，用6位数字表示，其中1～3位表示各级部门机构内设机构、直属单位、派出单位，4～6位表示各级部门机构内设机构、直属单位、派出单位的下设一级单位。


**3.2**编码方法


3.2.1　国家安全监管总局机构编码方法


第一段：01


第二段：（3～8位）010000


第三段第一层：（9～11位）表示国家安全生产监督管理总局内设机构及直属单位，001～199表示内设机构，200～299表示直属单位。


第三段第二层：（12～14位）表示国家安全生产监督管理总局内设机构及直属单位的下设一级单位


例如：


国家安全生产监督管理总局的14位编码为： 01010000000000


国家安全生产监督管理总局办公厅（国际合作司、财务司）的14位编码为：01010000001000


国家安全生产监督管理总局调度中心的14位编码为：01010000200000


国家安全生产监督管理总局和省级安全生产监督管理局机构代码见附录A1。国家安全生产监督管理总局内设机构代码表见附录A2。国家安全生产监督管理总局直属单位代码表见附录A3。


3.2.2　省级及以下安全监管部门编码方法


第一段：A


第二段：用行政区划代码表示各级机构代码（3～8位），其中前6位有行政区划的县局以上机构采用GB/T 2260编码，其他不能用行政区划代码表示的用规定的编码表示。


例如：


浙江省安全生产监督管理局的前8位编码： 01330000


杭州市安全生产监督管理局的前8位编码： 01330100


杭州市下城区安全生产监督管理局的前7位编码：01330103


不能用行政区划代码表示的安全监管部门（如开发区安全生产监督管理局、高新区安全生产监督管理局等），前5位取其上级安全监管机关机构编码的前5位，6、7位从99开始往前顺排。


例如：


宁波市高新区安全生产监督管理局的前8位编码为：01330299


宁波市保税区安全生产监督管理局的前8位编码为：01330298
