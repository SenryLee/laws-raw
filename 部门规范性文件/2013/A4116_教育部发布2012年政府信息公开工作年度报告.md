# 教育部发布2012年政府信息公开工作年度报告

## 教育部发布2012年政府信息公开工作年度报告（2013年3月）

本年度报告是根据《中华人民共和国政府信息公开条例》（以下简称《条例》）要求，由中华人民共和国教育部编制。全文内容包括概述、政府信息主动公开情况、政府信息依申请公开情况、政府信息公开咨询情况、政府信息公开的收费及减免情况、因政府信息公开申请行政复议和提起行政诉讼的情况、存在的主要问题和改进措施等七个部分。本报告的电子版可以从教育部门户网站（http：// www.moe.gov.cn）下载。如对本报告有任何疑问，请联系教育部政务公开办公室（电话：010-66096825）。

**一、**概述

2012年，教育部深入学习贯彻党的十八大精神和《条例》，在国务院办公厅的指导下，以全面落实教育规划纲要为契机，进一步转变职能和工作作风，积极回应社会关切，着力加强重点领域信息公开，深化直属单位办事公开，推动学校信息公开，教育系统信息公开工作取得新进展。

1. 着力增强教育系统信息公开意识。一是领导重视。部党组对全系统信息公开工作一直给予高度重视，袁贵仁部长多次批示，要求切实提高思想认识，牢固树立“以公开为原则，不公开为例外”的理念，确保教育系统信息公开工作走在前列。二是强化工作规划和指导。在全系统传达《中共中央办公厅国务院办公厅关于深化政务公开加强政务服务的意见》和全国政府信息公开工作电视电话会议精神，按照《2012年政府信息公开重点工作安排》要求，进行重点任务分解，指导各单位全面做好公开工作。三是加强机构和队伍建设。搭建交流平台，加强对一线工作人员培训，提高对信息公开重要性认识，增强服务意识，提升业务工作能力。

2. 不断健全教育信息公开制度。在不断完善教育部机关信息公开实施办法的基础上，推动健全教育系统信息公开制度。一是出台高校财务信息公开制度，要求各高校于财务预算、决算批复后10个工作日内主动公开财务预决算信息；联合中宣部、国家发展改革委等15部门印发了《农村义务教育学生营养改善计划信息公开公示暂行办法》等5个营养改善计划配套文件。二是完善高校信息公开年度报告制度，对高校编制和发布信息公开工作年度报告提出具体要求，强调高校要将年度报告在门户网站或信息公开专栏对全社会公布。目前，75所部直属高校年报编制和发布率已达到了100%，安徽、重庆等省市高校年报编制和发布率也已达到100%。三是完善信息公开保密审查制度。进一步建立健全保密审查制度和审查工作督促检查机制，严密防范信息公开中发生泄密事件。

3. 积极推动教育重大决策信息公开。2012年，教育部制定的《全面推进依法治校实施纲要》《学位论文作假行为处理办法》《〈教学成果奖励条例〉实施办法》《中小学财务制度》等11项重要规章和规范性文件草案均在门户网站公开征求意见，规章草案还在政府法制信息网上同步公开征求意见。其中，6项规章和规范性文件经修改完善后发布。在编制起草《国家教育事业第十二个五年规划》《教育部关于“十二五”期间高等学校设置工作的意见》《教学名师遴选支持办法》和《研究生国家奖学金管理暂行办法》等重要文件时，广泛听取了社会各方意见建议。

4. 着力推动教育政策执行情况公开。一是公开教育规划纲要落实情况。以10个教改典型、10大改革进展和10大工程成效为重点，公开推动协调发展、推进改革开放、提高教育质量、促进教育公平等方面成就。二是公开重大项目进展情况。在门户网站设立“全国农村义务教育学生营养改善计划”“中小学校舍安全工程”“农村义务教育经费保障新机制”等专栏，开设了高校学风建设专项教育和治理行动专题。三是公开执行检查情况。公开发布教育部对直属高校国家教育体制改革试点项目及“三重一大”决策制度执行情况的集中检查报告。

5. 进一步加强财务和干部人事信息公开。分别于2012年4月和7月公开了2012年部门预算、2011年度部门决算、2012年“三公经费”预算、2011年“三公经费”决算和2011年行政经费支出情况，并发布了《2011年全国教育经费执行情况统计公告》。公开选拔北京科技大学、北京中医药大学、中国药科大学三所高校校长和东南大学、山东大学、华中科技大学、中央戏剧学院、东北大学、中国海洋大学6所高校总会计师，在门户网站和新闻媒体刊发公选公告，对面试人选、考察人选和拟任职人选均进行公示，确保选拔工作公开透明。在“长江学者奖励计划”和推荐享受政府特殊津贴人选等工作中，均通过网站向社会公示，接受公众监督。

**二、**政府信息主动公开情况

1. 通过政府信息公开专栏公开公文类信息情况。

2012年，通过政府信息公开专栏公开公文类信息514条。其中位于前5位的信息是：干部人事人才类167条，占32.5%；教育综合管理类85条，占16.5%；发展规划类62条，占12.1%；高等教育类55条，占10.7%；职业教育与成人教育类39条，占7.6%。信息公开专栏全年访问量达62万次，日均点击率近1630人次，较2011年的1500人次略有上升。

2. 通过门户网站发布信息情况。

2012年，教育部强化门户网站首页建设，调整优化网页栏目，充分发挥门户网站作为政府信息公开第一平台作用。策划发布《学习宣传贯彻落实党的十八大精神》《全面提高高等教育质量》《最美女教师张丽莉》等专题专栏106个，通过文字、视频、图表等多种形式发布政策文件、进展情况、政策解读等各类信息3000余篇次。通过英文版门户网站发布各类信息91篇次。网站全年访问量达1457万余人次，处理网民各类政策咨询达14300余人次，处理网民邮件3200余封，答复网民留言191条。

3. 通过新闻发布会、新闻通气会发布信息情况。

2012年，教育部在国务院新闻办召开新闻发布会1场、部内召开新闻通气会25场；组织网络集体访谈5次；组织中央新闻单位采访团14次；中央主要媒体刊播教育新闻报道1万余篇。围绕两会、教育规划纲要实施两周年、教师节、十八大等重大节点，通过新闻通气会、媒体访谈、专家文章、网络互动等多种方式，及时发布教育改革发展的重大决策和重要举措，大力宣传显著成效和典型经验。针对社会关注的教育热点和突发事件，加强主动公开，实时监测舆情，及时研判应对，引导公众更加理性、客观、公正地看待教育问题。

4. 通过《教育部公报》《中国教育年鉴》公开信息情况。

2012年，教育部共刊发《教育部公报》12期，公开政府信息140条。出版发行了《中国教育年鉴（2011年卷）》，发布上一年党和国家领导人出席重要教育活动的报道或综述，教育部领导关于教育工作的重要讲话或专文，年度教育工作要点，教育发展统计，教育综合管理，教育人事管理，教育财务与统计等重要文件和统计信息。出版发行了《中国教育概况》系列丛书，介绍中国各级各类教育发展情况和政策。

**三、**政府信息依申请公开情况

1. 申请情况。

2012年1月1日至2012年12月31日，教育部共收到公民、法人和其他组织通过各种形式提出的信息公开申请202件，其中有效申请186件。在受理186件有效申请中，从申请的主体看，公民个人提出的申请185件、外国驻华使馆提出的申请1件。从申请方式看，当面申请34件，占18.28%；以电子邮件方式申请118件，占63.44%；以信函方式申请31件，占16.67%；以传真方式申请3件，占1.61%。从申请的内容看，涉及教育综合管理的34件，占18.28%；涉及招生就业的25件，占13.44%；涉及历史信息的24件，占12.9%；涉及教育统计信息的22件，占11.83%；涉及教育机构设置的21件，占11.29%；涉及教师待遇的14件，占7.53%；涉及中外合作办学的7件，占3.76%；涉及基础教育的7件，占3.76%；涉及教育财政经费的7件，占3.76%；涉及工龄计算的6件，占3.23%；涉及考试管理的4件，占2.15%；涉及少数民族教育政策的4件，占2.15%；涉及教育收费的3件，占1.61%；其他8件，占4.31%。申请内容涉及教育部18个业务司局。

2. 答复情况。

受理的186件申请已全部按时答复申请人。其中“同意公开”的124件，占申请总数的66.67%；“部分公开”的2件，占申请总数的1.1%；“不予公开”的11件，占申请总数的5.91%；“不属于本行政机关公开”的26件，占申请总数的13.98%；“信息不存在”的23件，占申请总数的12.37%。

**四、**政府信息公开咨询情况

2012年，教育部政府信息公开受理中心共接待500余人次电话及当面咨询，处理门户网站政府信息公开意见箱中与信息公开有关的信件50余件。

**五、**政府信息公开的收费及减免情况

2012年，没有因依申请公开信息收取或减免费用情况。

**六、**因政府信息公开申请行政复议和提起行政诉讼的情况

2012年，收到因政府信息公开的行政复议申请5份。没有因政府信息公开提起行政诉讼的情况。

**七、**存在的主要问题和改进措施

在扎实推进教育系统信息公开工作的同时，必须清醒看到各单位（学校）信息公开工作进展还不平衡，公众对教育信息公开的新要求还需深入研究，信息公开工作保障有待进一步加强。

2013年，教育部将深入学习贯彻党的十八大精神，认真落实《条例》规定，以更加强烈的责任感、使命感和紧迫感，求真务实，锐意进取，全力推进教育信息公开工作，保障公民、法人和其他组织依法获取教育信息，提高教育工作透明度，接受社会和群众监督。

一要深化思想认识。深入研究新任务新要求，进一步细化教育部落实中央“八项规定”的20条实施办法中关于“畅通意见渠道”和“推进政务公开”的要求。

二要突出公开重点。按照中央要求加大财政预决算、“三公经费”、重大项目建设等领域的公开力度。积极回应群众关心的热点难点问题，推动各级各类学校加大学生招生信息、收费信息等公开公示力度。加强公开载体建设，进一步加大教育重要政策、重大部署、进展成效、先进典型的信息发布。

三要强化服务意识。继续提高依申请公开事项办理效率和质量，切实满足群众知情权。整合教育系统公共企事业单位办事公开平台和资源，提供高效便民服务。

四要推动制度落实。采用广泛调研、实地抽查、群众评议等多种形式定期开展自查和督查，指导推动全系统落实各项公开制度。开展课题研究，逐步建立任务具体、责任明确、评价科学的高校信息公开检查评估机制。
