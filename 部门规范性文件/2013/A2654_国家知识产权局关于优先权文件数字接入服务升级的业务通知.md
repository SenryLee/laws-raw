# 国家知识产权局关于优先权文件数字接入服务升级的业务通知

为方便申请人办理专利申请优先权文件副本相关手续，国家知识产权局根据与世界知识产权组织达成的协议已于2012年3月1日开通了优先权文件的数字接入服务（Digital Access Service，简称DAS）。

基于世界知识产权组织对于优先权文件数字接入服务总体架构的调整，为进一步减轻申请人负担，提高专利申请审批效率，国家知识产权局对此项服务进行了升级，并将于2013年4月15日启用升级后的优先权文件数字接入服务（简称DAS2.0），同时停用旧版服务。现将此次升级的相关事项通知如下：

1. 适用范围

本服务升级后的适用范围如下：

交存范围为：由国家知识产权局受理的发明、实用新型和外观设计专利申请，以及由国家知识产权局作为PCT受理局受理的PCT国际申请。

查询范围为：由参与DAS的其它专利局交存的各类优先权文件（如发明、实用新型、外观设计以及PCT国际申请），其在后申请应当为向国家知识产权局提出并写明外国优先权信息的发明、实用新型和外观设计专利申请。

2. 手续办理方式的变更

升级后的服务仅适用于电子申请用户，不再接受通过面交或邮寄方式提交的纸件《优先权文件数字接入服务（DAS）请求书》。

3. PCT申请的交存

由国家知识产权局作为PCT受理局受理的PCT国际申请可通过国家知识产权局优先权文件数字接入服务（DAS2.0）进行交存；用户需使用其电子申请用户注册代码及密码登陆中国专利流程服务系统网站（http：//cpservice.sipo.gov.cn），提交优先权文件数字接入服务（DAS）请求。

4. 向外国申请专利前的保密审查

申请人请求使用此项服务交存优先权文件时，应当遵守专利法第二十条第一款的相关规定。
