# 国家标准公告2013年第13号——关于批准发布GB/T 27958-2011《海上大风预警等级》国家标准第1号修改单的公告

## 国家标准公告（2013年第13号）

关于批准发布GB/T 27958-2011《海上大风预警等级》国家标准第1号修改单的公告

国家标准化管理委员会批准GB/T 27958-2011《海上大风预警等级》国家标准第1号修改单，自2013年9月1日起实施，现予以公布（见附件）。

国家标准委

2013年7月30日

附件

GB/T 27958-2011《海上大风预警等级》国家标准第1号修改单

第3章“海上大风预警等级”表1中的“警报”修改为“预警”，具体如下：

表1：“海上大风预警等级”对应风力等级表

|  |  |  |
| --- | --- | --- |
| 海上大风预警等级 | 风力（级） | 阵风风力（级） |
| 海上大风蓝色预警 | 7～8 | 9～10 |
| 海上大风黄色预警 | 9～10 | 11～12 |
| 海上大风橙色预警 | ≥11 | ≥13 |
