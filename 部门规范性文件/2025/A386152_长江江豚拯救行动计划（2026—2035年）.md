# 长江江豚拯救行动计划（2026—2035年）

长江江豚是国家一级重点保护水生野生动物，我国现存唯一的淡水鲸类动物、长江生态系统的旗舰物种，其生存状况直接反映长江生态系统的整体健康状况和长江十年禁渔成效。为加强长江江豚保护工作，改变物种极度濒危的状况，农业农村部会同国家发展改革委、公安部、生态环境部、交通运输部、水利部、国家林草局、中国科学院制定了《长江江豚拯救行动计划（2026—2035年）》（以下简称《行动计划》）。《行动计划》明确了2026—2035年长江江豚保护工作总体目标，部署了涉水活动规范监管、重要栖息生境修复、人工繁育技术攻关等10大行动。现印发给你们，请结合工作实际推进实施。

## 长江江豚拯救行动计划（2026—2035年）

一、总体要求

以习近平生态文明思想为指导，深入贯彻党的二十大和二十届历次全会精神，坚持“共抓大保护，不搞大开发”和“生态优先、绿色发展”理念，以保护长江江豚及其栖息地为核心，以迁地保护和人工繁育为辅助，以系统治理思维贯穿“就地保护—迁地保护—人工繁育保护—遗传资源保护”工作闭环，实现种群数量稳定增长和栖息地有效保护，充分发挥长江江豚作为旗舰物种的伞护作用，推动长江水域生态整体保护和系统修复，促进人与自然和谐共生。

到2030年，长江江豚自然种群增长态势得到巩固，自然种群数量恢复至1700头以上。长江江豚重要栖息地适宜性有所提升、斑块化趋势初步缓解；流域应急救护网络和救护机制健全，年非正常死亡比例降至死亡长江江豚总数的50%以下；智慧监测预警网络初步建成，监测监管体系逐步完善。迁地保护群体规模持续扩大，数量达到220头左右；遗传多样性水平稳步提升，试验性野化放归技术体系初步构建。人工保种群体自然繁殖成功率和幼豚存活率显著提升，精液采集冻存复苏技术体系初步建立，人工授精和“试管江豚”胚胎移植技术取得突破。

到2035年，长江江豚自然种群数量增长至2000头以上，种群保持稳定。优化长江江豚自然保护区布局，重要栖息地适宜性显著增强，斑块化趋势进一步缓解；流域智慧监测预警网络、应急救护网络和机制高效运行，年非正常死亡比例降至死亡长江江豚总数的40%以下。建成具备应对极端气候变化能力的迁地保护水域，迁地保护群体数量达到300头左右。科研监测、风险防控、遗传管理、诊疗救护、野化放归技术体系完备，“人工授精—‘试管江豚’—诱导多功能干细胞”的人工繁育全链条技术取得突破。

二、具体行动

（一）涉水活动规范监管行动

明确长江江豚重要栖息地范围，严格落实涉水工程及涉水活动的全流程监管，维持栖息地功能完整。

1.严格规范监管涉水工程和活动。分批次划定长江江豚重要栖息地，在长江江豚重要栖息地依法专题论证大型水利枢纽工程、航道整治、港口码头等涉水工程规划建设，严格工程监管和采取保护措施，减缓工程对长江江豚及其栖息地的不利影响；加强河道采砂监管，科学制定采砂规划，降低采砂活动对长江江豚自然种群及其栖息地影响，保持对非法采砂高压严打态势；落实生态补偿措施，统筹资金用于长江江豚保护。

2.加强长江江豚重要栖息地水上交通管理。推动实现长江江豚智慧监测网络与船舶交通信息互联互通，提升长江江豚风险预警效能；研究船舶在长江江豚重要栖息地禁限航措施。按照《船舶制造业绿色发展行动纲要（2024—2030年）》要求，推动船舶绿色发展，有效降低船舶所致水下噪声。

（二）重要栖息生境修复行动

通过主动修复措施，全面提升栖息地的生境质量，扩大长江江豚活动区域。

3.实施自然河漫滩等重要栖息地生态修复。采取自然恢复和人工修复相结合的方式，在湖北荆州和安徽安庆等江段开展河漫滩修复试点，适时开展成效评估。通过将违法和已不具备防洪功能的子堤拆除、硬化河滨带生态再造等修复手段，提升栖息地质量，扩大适宜栖息范围，促进长江江豚自然种群恢复。

4.畅通长江江豚迁移通道。在科学评估基础上，对不具备通航条件的沙洲支汊水域探索实施船舶限航、禁航等措施，恢复生态廊道和庇护所；实施过江通道减振降噪措施，促进长江江豚江湖迁移；持续开展湖区砂坑和支流监测，依法依规实施易搁浅水域生态疏浚，恢复长江江豚迁移通道。

5.开展基于长江江豚生存需求的生态调度。开展兼顾鱼类繁殖索饵、长江江豚繁殖抚幼等需求的生活史关键期生态调度研究，推动形成生态保护、航运发展和防洪需求相协同的多目标调度体系。

6.实施长江江豚重要栖息地饵料鱼资源增殖。评估长江江豚重要栖息地饵料鱼资源及生境状况，开展鱼类产卵场与索饵场修复，促进长江江豚饵料鱼资源可持续增长；针对部分长江江豚重要栖息地适口饵料鱼类不足等问题，适时开展饵料鱼资源增殖，为长江江豚种群提供食物保障。

（三）风险隐患专项清理行动

全面清除残留废弃网具钓具等水下杂物，消除缠绕伤害风险，降低长江江豚意外伤亡率。

7.开展残存网具钓具清理。部署开展水下杂物专项排查清理，全面清除沉积在水底和淤泥中的历史残存网具钓具、各种线状垃圾；在长江江豚重要栖息地、垂钓人员聚集区、非法捕捞高发区等重点水域，加强巡逻和排查；加强宣传教育，引导垂钓人员、沿岸居民提高保护意识，规范处置废弃物。

8.打击整治非法捕捞。加大长江江豚重要栖息地巡护及执法力度，依法严厉打击各类非法捕捞活动；紧盯非法捕捞频发时段、高发水域，加强部门执法联动，常态化开展禁渔执法专项行动，最大限度挤压非法捕捞作案空间。

9.加强违规垂钓执法监管。强化日常巡护，发挥渔政执法人员、护渔员、志愿者作用，运用视频监控、无人机等现代监控技术，采取“岸线巡、水上查、空中侦”的立体巡护模式，实行不间断巡逻；强化规范监管，加大对违规垂钓的打击整治力度。

（四）智慧监测评估预警行动

掌握长江江豚自然种群动态，系统评估关键生态需求及生存威胁，为制定和实施精准高效的保护策略提供支撑。

10.建设智慧监测预警网络体系。融合岸基视频监控、无人机巡飞、被动声学实时监测技术，构建流域长江江豚智慧监测管理技术体系；建立长江江豚智慧监测预警网络，加强高风险水域的预测预警，以及种群数量、结构及健康状况的动态追踪。

11.开展全流域长江江豚专项监测及动态评估。利用监测预警网络，开展长江江豚种群年度普查，全面掌握种群数量、社群结构、分布特征、迁移活动规律和健康状况；监测重要栖息地特征，掌握河漫滩、水质、饵料鱼等生境要素，以及船舶通航、水下噪声等人类涉水活动的影响，动态跟踪长江江豚风险胁迫。

（五）应急救护体系建设行动

建立“分级响应+智慧赋能”长江江豚应急救护体系，提高救护响应时效和救治成功率。

12.构建应急救护网络。每100—150千米设置1个野外救护点，用于长江江豚简单救护处置；统筹利用科研院所和水族馆等场所设置救护站，用于长江江豚伤病救治，形成“就地快速处置+就近诊疗康复”的1小时响应救护网络；建设救护设施，提升收容救护能力。

13.建立应急救护机制。依托地方农业农村部门、保护区管理机构，充分利用科研院所、水族馆等技术力量，建立跨区域、跨部门的长江江豚应急救护机制；规范常规救护及应急救护流程，构建标准化救护体系；组建专业救护技术队伍，提升整体救护处置能力；制定应急救护预案，做好应急救护及时响应，实现全流域救护设施统一调度。

（六）迁地保护能力提升行动

扩大迁地保护群体规模，提升迁地水域生境质量和管理水平，实现迁地保护群体可持续健康发展。

14.新建迁地保护群体。综合迁地水域总体布局，加快建设江西湖口长江江豚迁地保护基地，推动在适合水域新建3处迁地保护水域，引入现有的长江江豚迁地保护群体、人工繁育群体和救护成功的野外个体。

15.提升迁地水域生境质量。采取水体连通、生态补水、岸坡软化等措施，恢复迁地水域与长江连通，改善水质，修复河岸带植物群落；根据需要采取大型及凶猛肉食性鱼类调控、饵料鱼类增殖放流等措施，提高小型适口鱼类资源量，提升迁地水域长江江豚容纳量。

16.提升迁地水域管理能力。综合运用现代科技手段，建设迁地水域智能管理系统，实现对迁地水域的全方位实时监控预警和潜在风险处置；加强迁地水域管护人员培训，提升专业化水平，提高长江江豚管护救护能力。

（七）人工繁育技术攻关行动

聚焦突破长江江豚人工繁育全链条技术，扩大人工保种群体规模，为种群恢复提供可持续支撑。

17.构建完善的人工繁育保种体系。充分利用科研单位、大型水族馆等科技人才和平台设备条件，构建长江江豚人工繁育体系。改扩建现有研究基地基础设施，在长江下游、洞庭湖新建2处长江江豚保护中心；建立30—50头长江江豚人工保种群体，实现年繁殖不少于5头，形成稳定、健康的人工保种群体。

18.突破全人工繁育技术。分步突破全人工繁育技术，2028年底前攻克长江江豚人工授精技术，实现全人工授精繁殖和幼豚人工哺育；2030年底前攻克“试管江豚”胚胎移植，实现长江江豚人工群体稳定保种；2035年底前攻克长江江豚多功能干细胞诱导技术，建立濒危水生哺乳动物保护全新技术体系。

19.开展多维遗传资源普查和管理。每3至5年对自然、迁地和人工保种群体开展遗传监测，建立群体遗传谱系；综合年龄与性别结构、健康与繁育状况、遗传多样性关系，科学制定个体交流方案，避免近亲繁殖，保障群体健康发展；系统采集并保存各类遗传样本，构建多温区样本储存体系。

（八）科学规范野化放归行动

新建野化训练水域，科学有序开展长江江豚野化放归，持续补充长江江豚自然种群数量。

20.稳步推进野化放归。建立迁地保护长江江豚野化放归技术规范，建设3处野化适应性训练水域，结合迁地保护群体发展状况、流域长江江豚种群动态及遗传多样性和生境质量，逐步扩大长江江豚野化放归数量，补充自然种群，促进自然种群恢复和遗传多样性提升。

（九）平台创新能力提升行动

整合科研力量，强化协同攻关，创新保护技术，突破保护难点，为长江江豚保护提供科技支撑。

21.建立国家长江江豚保护研究创新平台。充分吸收长江江豚保护研究力量，整合就地保护、迁地保护、人工繁育等相关设施条件，建立1个研究创新平台和3个研究分中心，统筹推动长江江豚保护研究工作，突破关键技术难点，推进保护技术创新。

22.推动平台条件提升建设。积极引进和培养高水平科研团队，推动在农业科技重大项目布局中研究部署长江江豚人工繁育等科研任务；配备先进科研设备，建设完善实验室、人工繁育操作平台、动物饲养设备、数据中心等基础设施，为科研工作顺利开展提供保障。

（十）科普教育宣传引领行动

积极引导社会力量参与长江江豚保护，形成全社会共同保护的良好局面。宣传我国长江江豚保护经验，提升在全球生物多样性保护领域的影响力与话语权。

23.打造长江江豚科普宣教平台。依托长江江豚保护中心、海洋馆、水族馆等科研科普平台，开展形式多样的宣传活动，提升长江江豚保护展示度和知晓度；借鉴大熊猫等成熟的宣传推广模式，科学制定长江江豚入馆科普宣传方案，让海洋馆、水族馆成为全社会了解和参与长江江豚保护的重要窗口。

24.主动引导社会力量参与。发挥长江江豚名片作用，促进科学研究、生态保护与文旅产业融合，打造兼具生态与文化价值的文旅品牌；推进长江江豚宣传教育进校园，推动社会组织等民间力量参与长江江豚保护；加强“国际淡水豚日”等重要节点的宣传活动，形成全社会关心长江江豚保护的舆论氛围。

25.推广长江江豚保护的中国经验。开展多元对外交流活动，积极与南亚、东南亚及南美合作，全方位总结梳理长江江豚保护经验，为全球濒危鲸豚类保护提供中国方案，提升国际合作水平与全球生态保护影响力。

三、支撑保障

（一）健全法治保障

强化长江江豚保护的法治建设，引导鼓励地方立法保护。借鉴安徽安庆制定的《安庆市长江江豚保护条例》以及江苏南京、镇江、安徽马鞍山三市人大常委会协同制定的《关于加强长江江豚保护的决定》等成功实践，推动形成多部门联合执法、跨区域协同共护的长江江豚保护管理新模式。

（二）加强组织领导

农业农村、发展改革、公安、生态环境、交通运输、水利、林草等部门要加强联动保护，完善长江江豚保护管理协作机制，指导各地高效组织实施拯救行动。地方相关部门应切实承担保护责任，将落实行动计划作为推进长江大保护和长江十年禁渔的重要内容，确保各项任务落到实处。相关科研单位要聚焦突破长江江豚保护技术瓶颈，为长江江豚保护提供技术支撑。构建社会化保护新格局，广泛动员企业、社会组织及公众参与长江江豚保护，营造全民共建共护的良好氛围。

（三）强化投入保障

拓宽资金筹措渠道，持续加大长江江豚保护投入，提供人工保种、科研攻关、巡护救护、栖息地修复等资金保障。积极引导和吸纳社会资金参与，探索构建政府投入、企业资助、社会捐赠等多元化资金保障机制，统筹实施重大水生生物资源保护和生态修复。推动将重点工程、长江江豚保护研究创新平台和研究分中心列入“十五五”相关能力建设规划。依托农业农村部、生态环境部、国家林草局、中国科学院等部门单位和地方的科技攻关项目，开展跨学科联合攻关，推动保护技术创新。

## 长江江豚拯救行动重点实施内容

|  |
| --- |
| 拯救行动1：涉水活动规范监管行动 |
| （1）政策管理类  　　科学开展涉水工程对长江江豚等水生生物影响专题评价；研究船舶在长江江豚重要栖息地禁限航措施；科学制定采砂规划，降低采砂活动对长江江豚自然种群及其栖息地影响。  　　（2）工程建设类  　　在长江江豚重要栖息地加强基础设施、监管设备建设，切实提升重要栖息地基础设施建设和管理水平。  　　（3）运行保障类  　　保障巡护监测、科普宣教以及保护区总体规划、资源本底调查等资金需求。 |
| 拯救行动2：重要栖息生境修复行动 |
| （1）工程建设类  　　长江江豚重要栖息地修复项目。在长江干流、鄱阳湖、洞庭湖等水域选择4处重要栖息地实施生态修复及智能化监测。  　　（2）科学研究类  　　河漫滩丧失等对长江江豚栖息地影响及修复研究。从长江江豚分布格局、社群关系、行为模式等角度解析其对胁迫的响应机制，制定针对性修复策略，强化长江江豚就地保护。  　　河漫滩等重要栖息地修复技术研究。通过突破水文连通恢复、地貌重塑、植被重建和底质改良等技术难关，建立“调查评估—目标设定—工程设计—施工实施—跟踪监测与适应性管理”技术流程，持续监测水文、水质和生物群落变化，并根据反馈进行水位调整、植物补种等，建立河漫滩等重要栖息地修复技术体系。 |
| 拯救行动3：风险隐患专项清理行动 |
| （1）执法监管类  　　开展禁渔执法专项行动，依法严厉查处非法捕捞行为；强化规范监管，加大对违规垂钓的打击整治力度。 |
| 拯救行动4：智慧监测跟踪评估行动 |
| （1）工程建设类  　　长江江豚智慧监测预警网络建设项目。在长江中下游干流、洞庭湖、鄱阳湖及主要支流等长江江豚重要分布水域建设智慧监测预警网络，包含长江江豚定点实时声学监测分析系统、无人机及基站、数据处理平台等内容，为长江江豚自然种群风险预警和应急救护提供精准支撑。  　　（2）科学研究类  　　长江江豚及其栖息地动态监测预警技术研究。构建栖息地选择模型，耦合水文、气象、航运等数据，实现对长江江豚高风险水域的精准预测预警，研究针对性保护措施，降低意外死亡风险。  　　长江江豚自然种群年龄结构和死亡率研究。研究长江江豚种群数量、社群结构、分布特征及迁移活动规律，以及重要栖息地特征、人类扰动变化趋势；开展死亡时间精确反演和死亡地精准溯源，建立死亡样本收集处置、尸检技术规范。 |
| 拯救行动5：应急救护体系建设行动 |
| （1）工程建设类  　　长江江豚应急救护基地建设项目。谋划建设约30个野外救护点，在现有的部分救护站新建3—5处室内诊疗护理中心。 |
| 拯救行动6：迁地保护能力提升行动 |
| （1）工程建设类  　　长江江豚迁地保护水域新建项目。在鄱阳湖珠湖、南京梅子洲夹江、芜湖黑沙洲和三峡库区汊湾等备选水域，评估水域适宜度并筛选3处建设迁地水域。  　　现有迁地保护水域提质优化项目。针对湖北石首天鹅洲、湖北老湾故道、湖北监利何王庙/湖南华容集成、安徽安庆西江、安徽铜陵夹江5个已建长江江豚迁地保护水域，实施生境修复，更新监测、保护和救助设施设备，提升迁地群体的管护能力。  　　（2）科学研究类  　　长江江豚迁地群体行为生态适应性研究。全面评估长江江豚迁地群体的行为生态适应性，并深入探讨其动态和健康与迁地水域生境状况的互作关系及环境驱动机制，为长江江豚的迁地保护和栖息地管理提供科学依据。 |
| 拯救行动7：人工繁育技术攻关行动 |
| （1）工程建设类  　　长江江豚繁育中心建设项目。改扩建武汉白鱀豚馆长江江豚保护研究基地基础设施，推动在江苏无锡、湖南岳阳等地新建1—2处长江江豚繁育保种中心，布局涵盖长江中下游和两湖的长江江豚繁育保种支撑体系。  　　长江江豚多维遗传资源库建设项目。整合涵盖遗传、生理、病理、行为、生态等全维度关联信息，构建长江江豚多维遗传资源库，实现遗传资源系统采集、规范管理和协同共享。  　　长江江豚干细胞遗传资源库建设项目。建立长江江豚生殖干细胞鉴定、分离、纯化、冻存以及复苏技术，构建不同种群长江江豚细胞系，实现长江江豚生殖干细胞和诱导多功能干细胞的永久保藏。  　　（2）运行保障类  　　长江江豚繁育中心运维项目。通过专项经费等渠道支持长江江豚繁育保种中心的运行维护。  　　（3）科学研究类  　　长江江豚人工授精技术攻关。重点突破长江江豚精液冷冻复苏、排卵预测、人工输精操作等技术难关，实现长江江豚母体受孕、妊娠、生产和幼豚人工哺育。  　　“试管江豚”胚胎移植技术攻关。在突破长江江豚人工授精技术的基础上，会同人类医学研究机构联合攻关，重点突破雌性长江江豚超促排卵、超声引导活体取卵、体外授精与胚胎培养、胚胎冷冻复苏和移植等技术难关，实现长江江豚人工群体稳定保种。  　　长江江豚多功能干细胞诱导技术攻关。会同畜牧兽医学研究机构（已克隆出猴、牛、羊、猫等）联合攻关，重点突破长江江豚皮肤成纤维细胞系构建、多功能干细胞诱导等技术难关，确保极端情况下的长江江豚物种安全。 |
| 拯救行动8：科学规范野化放归行动 |
| （1）工程建设类  　　长江江豚野化放归水域建设项目。在长江夹江建设3个长江江豚野化放归水域，用于长江江豚适应性野化放归。  　　（2）科学研究类  　　迁地保护长江江豚野化放归技术研究。研究人工繁育个体和迁地群体的水体适应性、捕食适应性和社群关系适应性等特征，制定迁地保护长江江豚野化放归技术规范。 |
| 拯救行动9：平台创新能力提升行动 |
| （1）工程建设类  　　科研创新平台能力提升项目。优化现有科研创新平台设备设施，提升平台能力；建立1个长江江豚保护研究创新平台和3个研究分中心。  　　（2）科技保障类  　　推动在农业科技重大项目布局中研究部署长江江豚人工繁育等科研任务，保障科研经费等需求。围绕国家长江江豚保护研究创新平台及分中心建设管理的需求，开展种群与生物多样性监测技术、栖息地修复、小种群保护、繁育技术、疫病防控等研究，培养一批学科带头人。 |
| 拯救行动10：科普教育宣传引领行动 |
| （1）科普宣传类  　　长江江豚常态化科普宣传活动。培育长江江豚专业保护的科普宣传人才队伍，构建良好的运行体系，积极发动社会力量参与长江江豚保护工作。出版1套长江水生生物保护科普作品，培育“全民爱豚月”等活动品牌。  　　（2）社会保护和国际合作类  　　长江江豚形象塑造。打造国家级长江江豚IP，发挥长江江豚在展现中国国家形象中的名片作用，探索数字化保护及展示路径，开展“数字江豚”国际合作。  　　世界大河流域鲸豚物种保护合作。研究世界大河流域在生态治理、物种保护、文化传承等方面的经验，发起“国际小型鲸类保护研究计划”，协同攻克保护难点。 |
