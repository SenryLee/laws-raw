# 农业农村部对十四届全国人大三次会议第1559号建议的答复摘要

## 对十四届全国人大三次会议第1559号建议的答复摘要

农办议〔2025〕29号

王连增代表：

您提出的关于打造城乡融合发展“人才雁阵”赋能乡村全面振兴的建议收悉。经商中央组织部、国家发展改革委、教育部、人力资源社会保障部，现答复如下：

近年来，农业农村部会同有关部门，认真贯彻落实中共中央办公厅、国务院办公厅《关于加快推进乡村人才振兴的意见》部署，通过“引育留用”协同发力，不断强化推进乡村全面振兴、建设农业强国的人才支撑。

**一、**关于构建“雁阵”格局

农业农村部立足职能，加强与相关部门协同配合，通过实施人才工程项目、加强政策扶持、健全培养体系，推动壮大乡村人才队伍。一是培育“头雁”促进联农带农。2022年，农业农村部会同财政部启动实施乡村产业振兴带头人培育“头雁”项目，重点面向农民合作社理事长、家庭农场主、农村集体经济组织负责人、社会化服务组织负责人、农业产业化龙头企业负责人等带头人，组织到优质高校进行系统培育，强化导师帮带、金融支持和激励保障等，把带头人培养成“领头雁”，带动全国新型农业经营主体形成“雁阵”。在培育中，注重强化“头雁”联农带农意识，引导“头雁”积极主动发挥联农带农作用。截至2024年底，已累计为全国各省份培育“头雁”5.43万名。二是引导人才返乡干事创业。为增强乡村对人才的吸引力，农业农村部采取多种方式宣传解读农村创业政策，组织全国农村创业优秀带头人典型案例推介活动，举办农村创业项目大赛，开展农村创业带头人典型经验推广进校园活动。围绕引导城市专业人才下乡服务，会同有关部门向160个国家乡村振兴重点帮扶县选派科技特派团，通过结对帮带、技术培训、带动参与等方式，培养乡村本土人才，助力乡村产业振兴。引导各地选派不同领域科技特派员赴县乡一线，宣传党的政策、传播先进技术、培育富民产业、带动农民增收。三是提升农民能力素质水平。农业农村部深入开展高素质农民培育计划，围绕提升农民技术技能水平、产业发展能力、综合素质素养开展培训。截至2024年底，全国已累计培育近900万人次。会同中央组织部举办农村实用人才带头人培训，面向乡村产业发展、乡村建设、乡村治理领域带头人，按照“村庄是教室、村官是教师、现场是教材”模式开展培训，帮助其拓宽视野、更新理念、锻造素质和提高解决农村实际问题的能力。截至2024年底，全国已累计培训25万余人。在部级人才项目的带动下，各地纷纷加大乡村人才培养力度，例如浙江实施现代“新农人”培育行动，打造千名“浙农英才”、万名乡村产业振兴“头雁”、十万农创客、百万现代“新农人”组成的乡村人才矩阵。

**二、**关于优化留才环境

农业农村部会同教育部、人力资源社会保障部等部门，着力改善提升农村软硬件条件，规范开展乡村人才评比表彰和宣传选树，帮助各类人才在乡村安居乐业。一是着力提升乡村建设水平。农业农村部会同有关部门深入实施乡村建设行动，持续完善推动农村公共服务发展的政策体系，开展全国农村公共服务典型案例征集活动，促进提升乡村基础设施完备度、公共服务便利度和人居环境舒适度。教育部会同国家发展改革委、财政部等部门，推动改善乡村学校办学条件、提高办学水平、加强师资队伍建设。二是营造重农爱才的社会氛围。农业农村部协调组织中央及部属媒体，聚焦乡村人才振兴，持续推出重点报道和专题节目，展现优秀乡村人才扎根乡村发展产业、带领村民增收致富的典型事迹。2014年启动以来，已累计开展10次，其中，2018年中国农民丰收节设立后，5次评选结果在中国农民丰收节主场活动宣传推介，推动在全社会营造重视、关心、支持乡村人才的良好氛围。三是完善乡村人才激励机制。农业农村部会同人力资源社会保障部持续推动完善乡村人才评价体系，深化农业技术人员职称制度改革，突出评价业绩水平和实际贡献，对长期扎根基层一线、贡献突出的适当放宽学历等要求，激励优秀农业人才向基层流动。组织开展全国农业农村劳动模范和先进工作者评选表彰工作，2023年共表彰478名全国农业农村劳动模范和293名全国农业农村先进工作者。联合人力资源社会保障部、中华全国总工会举办全国农业行业职业技能大赛，2024年第四届、第五届大赛9个赛项的第一名选手荣获全国五一劳动奖章，有效激励了广大乡村人才奋发有为、干事创业。

**三、**关于创新用才机制

围绕帮助各类人才在乡村大施所能、大展才华、大显身手，多部门协同搭建平台、畅通渠道，助力乡村人才发展。一是搭建拓展干事创业平台。农业农村部通过编制产业发展规划、印发指导文件，会同财政部安排中央财政资金建设农业产业强镇，组织实施休闲农业精品工程，支持引导各地挖掘优势特色资源，做大做强农产品加工业，发展乡村特色产业和休闲农业，不断拓宽乡村创业领域、扩大乡村就业容量。农业农村部面向社会各界推介承载力强、功能全面、服务优质的农村创业园区，组织农村创业园区观摩交流活动，提高园区服务人才创业发展能力。二是健全乡村人才培养体系。农业农村部依托“头雁”项目、农村实用人才带头人培训、高素质农民培育等，构建梯次衔接、各有侧重的乡村人才培养体系，示范带动各地创设实施地方人才培训项目。推动“定向招生、定向培养、定向就业”的新型农科生培养，与北京师范大学联合开展基层干部人才强基赋能行动，引导带动高等院校参与乡村人才培养。

下一步，农业农村部将会同有关部门，围绕加快推进乡村人才振兴，进一步加大乡村本土人才培育力度，健全引导城市各类专业技术人才下乡服务机制，促进乡村产业提质增效、转型升级，推动补齐农村基础设施和公共服务短板，持续改善人居环境，着力打造规模宏大、结构合理、素质优良的农业农村人才队伍，为推进乡村全面振兴提供有力人才支撑。

感谢您对农业农村部工作的关心，希望继续对“三农”工作给予支持。
