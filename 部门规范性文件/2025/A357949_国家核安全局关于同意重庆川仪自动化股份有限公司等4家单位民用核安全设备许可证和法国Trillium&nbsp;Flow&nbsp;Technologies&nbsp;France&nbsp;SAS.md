# 国家核安全局关于同意重庆川仪自动化股份有限公司等4家单位民用核安全设备许可证和法国Trillium&nbsp;Flow&nbsp;Technologies&nbsp;France&nbsp;SAS等2家境外单位注册登记确认书信息变更的通知

## 关于同意重庆川仪自动化股份有限公司等4家单位民用核安全设备许可证和法国Trillium Flow Technologies France SAS等2家境外单位注册登记确认书信息变更的通知

国核安函〔2025〕40号

重庆川仪自动化股份有限公司、大连大高阀门股份有限公司、无锡市新峰管业有限公司、上海阀门厂股份有限公司、法国Trillium Flow Technologies France SAS、俄罗斯JSC“Zavod “Znamya truda”：

根据《民用核安全设备监督管理条例》及其配套规章的要求，我局对相关单位民用核安全设备许可证及境外单位注册登记确认书信息变更的申请进行了审查。经研究，同意重庆川仪自动化股份有限公司、大连大高阀门股份有限公司、无锡市新峰管业有限公司、上海阀门厂股份有限公司等4家单位民用核安全设备许可证信息变更（见附件1）和法国Trillium Flow Technologies France SAS、俄罗斯JSC“Zavod“Znamya truda”等2家境外单位注册登记确认书信息变更（见附件2）。

附件：

1.民用核安全设备许可证变更信息

2.境外单位注册登记确认书变更信息

国家核安全局

2025年5月1日
