# 全国统计专业技术资格考试办公室关于2024年度统计专业技术资格考试单独划线地区合格标准的通告

## 关于2024年度统计专业技术资格考试单独划线地区合格标准的通告

根据《人力资源社会保障部办公厅关于单独划定部分专业技术人员职业资格考试合格标准有关事项的通知》（人社厅发﹝2022﹞25号），经有关部门授权，现将2024年度初级、中级、高级统计专业技术资格考试单独划线地区合格标准通告如下：

|  |  |
| --- | --- |
| **级别** | **合格标准** |
| 初级 | 各科目均为69分 |
| 中级 | 各科目均为66分 |
| 高级 | 各科目均为86分 |

全国统计专业技术资格考试办公室

2025年5月14日
