# 农业农村部关于批准天津市中升挑战生物科技有限公司等3家单位的盐酸聚六亚甲基双胍溶液等3种兽药产品为新兽药、批准四川恒通动保生物科技有限公司等9家单位的三氯异氰脲酸粉（II）等2种兽药产品变更注册的公告

## 中华人民共和国农业农村部公告

第961号

## 关于批准天津市中升挑战生物科技有限公司等3家单位的盐酸聚六亚甲基双胍溶液等3种兽药产品为新兽药、批准四川恒通动保生物科技有限公司等9家单位的三氯异氰脲酸粉（II）等2种兽药产品变更注册的公告

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准天津市中升挑战生物科技有限公司等3家单位申报的盐酸聚六亚甲基双胍溶液等3种兽药产品为新兽药，核发《新兽药注册证书》，发布产品质量标准、工艺规程、说明书和标签，自发布之日起执行。

批准四川恒通动保生物科技有限公司等9家单位申报的三氯异氰脲酸粉（II）等2种兽药产品变更注册，申请人按照农业农村部批准的变更事项，自行修改原批准的说明书和标签对应内容，并印制、使用。

特此公告。

4.工艺规程（略）
