# 国家核安全局关于印发《浙江金七门核电厂1号机组核岛基础浇筑第一罐混凝土前准备情况核安全检查报告》的函

## 关于印发《浙江金七门核电厂1号机组核岛基础浇筑第一罐混凝土前准备情况核安全检查报告》的函

国核安函〔2025〕61号

中核浙能能源有限公司：

根据《中华人民共和国核安全法》和《中华人民共和国民用核设施安全监督管理条例》的有关规定，我局组织检查组于2025年6月23日至26日对你公司浙江金七门核电厂1号机组核岛基础浇筑第一罐混凝土前准备情况进行了例行核安全检查。

现将检查报告印发给你公司，请采取有效措施，落实检查报告中提出的各项核安全管理要求，确保浙江金七门核电厂1号机组建造质量。

国家核安全局

2025年7月5日

## 浙江金七门核电厂1号机组核岛基础浇筑第一罐混凝土前准备情况核安全检查报告

检查单位：国家核安全局

受检单位：中核浙能能源有限公司

检查日期：2025年6月23日至26日

**一、**检查依据

（一）《中华人民共和国核安全法》；

（二）《中华人民共和国民用核设施安全监督管理条例》及其实施细则；

（三）《核动力厂、研究堆、核燃料循环设施安全许可程序规定》；

（四）《核动力厂厂址评价安全规定》；

（五）《核动力厂设计安全规定》；

（六）《核电厂质量保证安全规定》；

（七）国家核安全局批准或认可的文件。

**二、**检查内容

（一）建造阶段质量保证大纲实施情况；

（二）核岛施工组织、施工计划等施工管理条件准备情况；

（三）设计文件、施工方案等技术条件准备情况；

（四）前期施工监督检查遗留问题处理情况；

（五）核岛基础浇筑第一罐混凝土（FCD）前现场准备情况；

（六）经验反馈体系的建立和运转情况。

**三、**检查活动

2025年6月23日至26日，国家核安全局组织检查组对浙江金七门核电厂1号机组核岛FCD前准备情况进行了例行核安全检查。检查组听取了中核浙能能源有限公司（以下简称营运单位）关于浙江金七门核电厂整体情况、质量保证体系建设及责任制落实情况、经验反馈体系运转情况、1号机组核岛FCD前准备情况、核安全监督管理要求落实情况等方面的汇报。

在听取汇报的基础上，检查组对1号机组施工管理条件准备情况、技术条件准备情况、前期施工监督检查遗留问题处理情况、质量保证体系运转情况、经验反馈体系建立和运转情况等进行了文件检查，对1号机组核岛筏基、原材料存储场地、混凝土实验室、混凝土搅拌站等场所进行了现场检查，并与有关管理和技术人员进行了访谈。营运单位及相关单位对检查给予了积极配合，检查达到了预期目的。

**四、**检查情况

（一）建造阶段质量保证大纲实施情况

营运单位针对1号机组的建造建立了质量保证体系，涵盖营运单位、监理单位、工程总承包单位等相关方，施工相关组织机构健全，职责分工明确，接口关系清晰。营运单位组织监理单位、工程总承包单位等相关方建立了防造假体系。

（二）核岛施工组织、施工计划等施工管理条件准备情况

营运单位批准发布了1号机组核岛及其配套土建工程施工组织设计等文件，开展了施工组织和部署、进度计划安排等，各项施工准备工作正按照计划进行。

（三）设计文件、施工方案等技术条件准备情况

营运单位组织发布了1号机组核岛筏基施工方案，制定了施工过程控制措施和应急预案。设计图纸和技术规格书满足1号机组核岛FCD需要。

（四）前期施工监督检查遗留问题处理情况

针对华东核与辐射安全监督站前期开展的1号机组核岛基坑验槽核安全检查中发现的问题，营运单位已按计划整改完成。

（五）核岛FCD前现场准备情况

营运单位已组织完成1号机组核岛厂房筏基钢筋绑扎、模板支设、预埋件安装等工作，混凝土生产和浇筑所需设施设备、工器具和原材料等正在按计划准备。

（六）经验反馈体系的建立和运转情况

营运单位及各相关方均已建立经验反馈体系并正常运转。

**五、**整改要求

结合本次检查情况，检查组共提出四项整改要求。

（一） 针对到场的砂石骨料等原材料总量尚不完全满足1号机组核岛FCD需求、部分混凝土罐车等施工设备未全部到位等问题，营运单位应全面梳理1号机组FCD施工准备情况，确保施工设备和原材料及时到位，满足1号机组核岛FCD施工需要。

（二）针对开展混凝土配合比抗压强度、混凝土抗渗等级等试验的检测单位不具备中国计量认证（CMA）相关资质的问题，营运单位应按要求委托具有相关资质的检测机构开展相关工作并对前期相关试验结果进行检测确认，确保混凝土配合比满足设计要求。

（三）针对《1RX反应堆厂房基础底板混凝土浇筑专项方案》《浙江金七门核电工程混凝土裂缝控制、处置工作程序》等文件部分描述不严谨、内容不完善、技术指标不自洽的问题，营运单位应完善技术要求，加强施工文件控制，确保文件质量。

（四）针对已安装筏基钢筋的取样检测内容未完全涵盖内径实测数据、横肋间距和横肋末端最大间隙等国家标准要求的问题，营运单位应对相关钢筋开展补充检测，确保钢筋质量满足要求。

对检查组提出的整改要求，营运单位应在1号机组核岛FCD前完成整改，将改进措施和落实情况按要求提交国家核安全局和华东核与辐射安全监督站。
