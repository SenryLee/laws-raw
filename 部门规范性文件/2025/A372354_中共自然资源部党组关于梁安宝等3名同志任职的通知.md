# 中共自然资源部党组关于梁安宝等3名同志任职的通知

自然资党任〔2025〕103号

国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

中共自然资源部党组2025年11月17日研究决定：

梁安宝任黑龙江测绘地理信息局副局长（试用期一年）、党组成员；

钱秀丽任自然资源部宣传教育中心副主任（试用期一年）；

伊日和任中国自然资源报社副社长（试用期一年）。

中共自然资源部党组

2025年12月1日
