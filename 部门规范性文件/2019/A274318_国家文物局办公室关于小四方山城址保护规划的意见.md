# 国家文物局办公室关于小四方山城址保护规划的意见

办保函〔2019〕78号

黑龙江省文物管理局：

你局《关于小四方山城保护规划的请示》（黑文管字〔2018〕38号）收悉。经研究，我局暂不同意所报规划。

一、所报规划应做以下修改和完善：

（一）应切实加强考古工作，系统梳理史料和考古成果，开展必要的补充考古调查、勘探，进一步明确遗址分布范围和格局，在此基础上明确保护对象，凝练文物价值。同时，应客观评价自然因素和人为因素对遗址安全的影响，归纳评估结论。

（二）应根据地形或标志物划定保护区划具体边界，建议建设控制地带边界可扩展至山脚坡地；高峰村等周边村落可纳入环境风貌控制区。应明确建设控制地带和环境风貌控制区的具体管理要求，制定新建建筑高度、体量、外观样式等具体控制指标，增强可操作性。

（三）本体保护措施应坚持最小干预原则，严格控制工程范围和强度，论证植被清理、石墙补配补砌、崖体保护加固、退耕停耕、围栏建设的必要性和可行性。

（四）进一步明确地质灾害区域，冲沟治理应制定必要的导流措施；梳理火灾隐患和防护重点，建议结合地方森林防火的整体部署，统筹考虑遗址所在山体防火问题，充分论证配备小型消防车辆及防雷系统的必要性。

（五）应根据遗址保存现状、区位条件、当地经济发展水平，综合确定展示利用方式和强度，论证建设考古遗址公园的必要性和可行性。建议现阶段应以考古和保护为主，不宜大规模建设展示服务设施。不同意城址修复、考古现场展示等设计内容。

（六）明确遗址管理运营机构的组织架构、职责等；进一步加强与城市总体规划修编工作的衔接。

（七）规范图文表达，统一图例。

二、请你局指导有关单位，根据上述意见对小四方山城保护规划进行修改完善，按程序另行报批。

专此函复。

国家文物局办公室

2019年2月11日
