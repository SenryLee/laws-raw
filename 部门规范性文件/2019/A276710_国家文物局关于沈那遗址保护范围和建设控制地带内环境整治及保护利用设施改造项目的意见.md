# 国家文物局关于沈那遗址保护范围和建设控制地带内环境整治及保护利用设施改造项目的意见

文物保函〔2019〕367号

青海省文物局：

你局《关于沈那遗址保护范围和建设控制地带内进行环境整治及保护利用设施改造项目的请示》（青文物局〔2019〕59号）收悉。经研究，我局原则同意在沈那遗址保护范围和建设控制地带内实施环境整治及保护利用设施改造项目。

一、所报方案尚需做以下必要的修改和完善：

（一）进一步深化设计，核减照明、景观小品、环卫等人工设施规模和数量；调整道路设计，园区内道路建议均采用砂石路面，并禁止机动车辆通行；明确活土坑性质和意义，增强铺砖与植被展示的可识别性，充分论证展示所有遗迹的必要性；植被应选取当地浅根系耐寒品种，避免城市公园化设计倾向。

（二）严格控制工程范围和施工强度，不应大范围改变遗址区域内地形地貌，管线铺设不得破坏文化层和重要遗迹，做好施工中的文物保护工作，确保文物安全。

（三）规范图文表达，完善概算说明，补充保护棚改建技术图纸、等高线图。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年4月18日
