# 国家文物局关于政协十三届全国委员会第二次会议第3672号（文化宣传类304号）提案答复的函

文物保函〔2019〕880号

朱奕龙委员：

您提出的《关于加强侨乡地区特色村镇街区文化遗产保护的提案》已交由我局会同住房城乡建设部办理，现答复如下：

广东、福建、海南因历史上旅居海外的华侨较多被称为三大侨乡。这些侨乡地区含有丰富的历史文化遗产，包括全国重点文物保护单位273处，中国历史文化街区7处，中国历史文化名镇36处，中国历史文化名村85处，中国传统村落821处。保护好这些丰富的历史文化遗产，对于团结海外侨胞情系故土、热爱祖国，凝心聚力推进中华民族伟大复兴中国梦具有重要意义。

国家高度重视侨乡地区特色村镇街区文化遗产保护工作。国家文物局指导侨乡地区的开平碉楼及古村落、福建土楼，厦门鼓浪屿成功申报世界遗产项目；将包括培田村、吉山村等在内的5个侨乡地区的传统村落纳入首批51个全国重点文物保护单位和省级文物保护单位集中成片传统村落整体保护利用项目，并安排专项资金给予支持。2019年，国家文物局联合中宣部等部门将侨乡地区的101个县列入第一批革命文物保护利用片区的原中央苏区片区、海陆丰片区、琼崖片区和闽浙赣片区分县名单，积极推进侨乡地区革命文物工作。住房城乡建设部会同国家文物局等部门将侨乡地区39个中国传统村落列入2019年度中央财政支持范围。同时，住房城乡建设部、国家文物局还配合中央宣传部成功拍摄了5季《记住乡愁》纪录片，有效传播了乡村优秀传统文化，展现了乡村价值和乡村精神。目前，正在开展的第八批全国重点文物保护单位申报遴选工作中，我局也积极支持侨乡地区国保申报项目。

下一阶段，为进一步加强侨乡地区特色村镇街区文化遗产保护工作，国家文物局将会同有关部门重点做好以下工作：

一是继续加强侨乡地区文化遗产保护基础工作。督促地方政府深入开展侨乡地区不可移动文物和历史建筑普查、认定和登记工作，厘清文物建筑和历史建筑双重身份，健全档案，摸清侨乡地区的历史建筑和文物建筑家底、保存状况；建立文物数据库，打造侨乡地区文化遗产保护和利用数字化信息共享平台；将具有重要历史和文化价值的华侨相关文物点及时公布为相应级别的文物保护单位，依法纳入保护范畴。我局积极支持符合第八批全国重点文物保护单位申报条件的侨乡地区文物点列入候选名单报请国务院予以公布，为侨乡地区特色村镇街区保护利用提供丰富的文物支撑和文化内涵。

二是深入推进侨乡地区文化遗产保护规划编制审批和实施工作。指导侨乡地区地方政府继续做好历史文化名镇名村保护规划、中国传统村落保护发展规划及文物保护利用规划编制、审批和实施工作，持续推进侨乡地区全国重点文物保护单位和省级文物保护单位集中成片传统村落整体保护利用工作，不断加强侨乡地区历史文化名镇名村、传统村落的建设管理和文物保护单位的日常管理和修缮维护，注重保持侨乡地区的文物特色和侨乡风貌。国家将继续加大对侨乡地区特色村镇街区文化遗产保护工作的政策和资金支持力度。

三是健全侨乡地区特色村镇建设的法律法规和制度机制。住房城乡建设部将加快《历史文化名城名镇名村保护条例》修订研究工作，加强传统村落保护法规制度建设，强化传统村落文化遗产保护监管机制，并建立“一年一检查，五年一评估”的历史文化名镇名村保护检查评估制度，加强对侨乡地区历史文化名镇名村和传统村落保护管理。

四是加强侨乡地区文化遗产保护传承利用工作。继续加大宣传培训力度，组织特色村镇街区、历史建筑、传统建筑保护发展培训，不断强化文化传承理念。深入挖掘总结各地区优秀案例，持续开展乡村遗产酒店示范项目推介活动和历史建筑保护利用省级试点、传统建筑解析、建造技术调查研究工作，积极开发建设中国传统村落数字化博物馆，用数字化技术全方位展示侨乡地区的历史文化、环境格局、传统建筑和民族文化。大力发展侨乡地区特色文化旅游，开发具有侨乡地区特色的旅游品牌和文化创意产品，推进侨乡地区文化的传承创新，有效促进侨乡地区经济社会发展。

感谢您对文物事业的关心与支持！

国家文物局

2019年8月27日
