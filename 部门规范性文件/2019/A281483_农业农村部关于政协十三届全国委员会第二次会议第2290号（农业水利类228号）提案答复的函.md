# 农业农村部关于政协十三届全国委员会第二次会议第2290号（农业水利类228号）提案答复的函

## 关于政协十三届全国委员会第二次会议第2290号（农业水利类228号）提案答复的函

农办案〔2019〕169号

王晶委员：

您提出的关于"创新社会治理，建设数字乡村"的提案收悉。经商财政部，现答复如下。

一、关于明确"信息进村入户工程"在数字乡村发展战略中的地位和作用

党中央、国务院对信息进村入户工作作出了全面部署安排。2014—2017年中央一号文件连续四年对信息进村入户工程作出部署安排，2016年印发的《"十三五"国家信息化规划》《关于积极推进"互联网+"行动的指导意见》提出把信息进村入户工程作为农业农村信息化的重点工程，深入推进信息进村入户试点，全面提升农业信息综合服务能力。2019年中央一号文件明确提出要全面推进信息进村入户，依托"互联网+"推动公共服务向农村延伸。中共中央办公厅、国务院办公厅印发《数字乡村发展战略纲要》，提出加快乡村信息基础设施建设等重点任务，要求全面实施信息进村入户工程，构建为农综合服务平台，为丰富和发展"信息进村入户工程"的服务内容提供了目标和方向。我部贯彻落实党中央、国务院决策部署，制定了《农业部关于开展信息进村入户试点工作的通知》《农业部关于全面推进信息进村入户工程的实施意见》《农业部办公厅关于开展信息进村入户工程整省推进示范的通知》等系列文件，把信息进村入户工程作为提高农业农村信息化服务水平，提升乡村治理能力的重要抓手，对信息进村入户工作进行具体部署安排，推动信息技术与农业农村全面深度融合，加快农村信息化服务普及。

二、关于推进益农信息社建设，打造数字乡村生态体系

2014年起，我部在全面系统总结12316"三农"综合信息服务基础上，启动信息进村入户试点工作，2017年在全国范围全面实施信息进村入户工程，并开展整省推进示范，2018年整省推进示范范围扩大到18个省份。信息进村入户工程以村级益农信息社建设为着力点，以满足农民生产生活信息需求为出发点和落脚点，为农民提供农技推广等公益服务、水电缴费等便民服务、农产品出村等电商服务以及新技术新品种培训体验服务，实现让农民进一个门办百样事。

从实践情况看，益农信息社已经在农业农村生产生活中发挥了重要作用，成为实施数字乡村战略的重要抓手。一是深化信息化服务，成为农业农村信息流动的新渠道。益农信息社严格按照"有场所、有人员、有设备、有宽带、有网页、有持续运营能力"的"六有"标准，充分利用农业技术推广服务、农村党员远程教育等设施条件、场所设备，以及市场化的金融服务、通信、电商等现有服务网点，开展改建或新建，初步形成了纵向联结从省到村、横向覆盖政府、农民、企业的信息服务网络体系。依托信息进村入户，探索创新村情农情民情收集手段，把益农信息社作为农业农村大数据的重要来源，为农户、信息员、政府提供信息服务。二是整合涉农资源，成为开展便民服务的重要窗口。通过把农资代销、生活用品代购、远程医疗、取款缴费、就业务工等便民服务向益农信息社集中，农民足不出户即可享受便捷的生活服务，部分地区还探索通过益农信息社组织文化活动，提升农村精神文明水平，各类便民服务已陆续延伸到村、服务到户。三是延伸公益服务，成为农民生产生活的可靠依托。信息进村入户与基层农业服务体系相融合，在12316公益服务热线基础上，不断升级服务功能，为农民和新型农业经营主体提供机耕机收、统防统治、代耕代种、土地托管等多种农业服务，还承担社保、医保、公积金、救助等与农民生活密切相关的公益服务功能，真正成为农民生产生活的可靠依托。四是构建农产品上行渠道，带动农民脱贫增收。依托信息进村入户，通过在线平台发布、交流优质农产品信息，强化益农信息社仓储、物流、包装、储运等基础设施建设，培训村级信息员带动农民提高网上销售技能，为优质特色农产品网络销售和农民增收致富提供新手段。五是创新运营机制，形成多种模式并存发展的新格局。信息进村入户工程坚持市场化的运营机制，建立权责利明晰的利益联结机制，已初步构建起"政府+运营商+服务商"三位一体的推进模式，形成了以先进带后进、以典型带普遍、多种模式并存的推进格局，基本实现了政府得民心、企业得市场、农民享实惠的共赢局面。截至2018年底，全国共建成运营27.2万个益农信息社，覆盖全国近一半行政村，累计培训村级信息员78.6万人次，为农民和新型农业经营主体提供公益服务9579万人次，开展便民服务3.14亿人次，实现电子商务交易额244亿元。

三、关于加强顶层设计和资金保障

我部坚持"政府主导、市场主体"的推进思路，强化顶层设计和资金保障，加强指导益农信息社建设。各省党委、政府高度重视信息进村入户工作，整省推进示范省成立了由省政府分管负责同志或主要负责同志任组长、各省级涉农部门全面参与的信息进村入户工程领导小组，遴选省级运营主体，并加强监督考核，对信息进村入户在内的农业信息化发展开展延伸绩效考核，推动信息进村入户工作落地实施。财政部高度重视信息进村入户工作，从2017年起，中央财政通过农业生产发展资金支持信息进村入户整省推进示范相关工作，对符合条件的益农信息社予以适当奖补，截至目前，累计支持资金达16亿元，形成了上下齐心协力、部门协作协同的推进机制，为全面推进信息进村入户工程营造了良好的政策环境。

下一步，农业农村部将继续扎实推进信息进村入户工程，把它作为实施数字乡村战略的重要抓手，进一步集聚资源、完善服务内容、创新服务手段、强化日常管理。在工作推进中，将指导各地认真总结好经验好做法，并注重各类社会主体参与，共同推进信息进村入户深入发展。

感谢您对相关工作的关心和重视，希望继续对我部工作给予支持。

农业农村部

2019年8月30日
