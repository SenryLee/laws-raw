# 农业农村部对十三届全国人大二次会议第1934号建议的答复

## 对十三届全国人大二次会议第1934号建议的答复

农办议〔2019〕458号

曹清尧代表：

您提出的关于加强非洲猪瘟诊断技术与疫苗研究推广的建议收悉。经我部认真研究，现答复如下。

我部高度重视非洲猪瘟防控科研攻关工作。非洲猪瘟传入我国之前，我部和科技部已立项支持非洲猪瘟储备性研究。我国发生非洲猪瘟疫情以来，我部会同科技部启动应急项目，支持科研机构开展非洲猪瘟相关研究。目前，非洲猪瘟诊断技术与疫苗研究推广等各项工作均进展顺利。

一、关于加快诊断技术的研发，提高疫情发现能力。非洲猪瘟科研工作启动以来，有关科研单位已经构建了多种血清学和病原学诊断方法，这些方法在一年多的非洲猪瘟防控工作中得到了充分检验。目前，全国大部分市县一级动物疫病预防控制机构均能够采用国际组织推荐方法对非洲猪瘟作出初步诊断。同时，国内很多科研院所、第三方检测机构也具备非洲猪瘟检测能力。我国有关法律法规规定，重大动物疫情由省级以上兽医主管部门认定并发布，开展高致病性病原微生物实验活动需要经过审批，但并未禁止其他任何单位或个人，包括养殖场（户）自行开展检测。为确保疫情"早发现、早报告、早处置",降低运输、屠宰、生产加工等下游环节疫情传播风险，我部于今年1月印发公告，明确要求实施屠宰环节非洲猪瘟自检。4月，我部联合市场监管总局、工业和信息化部联合印发公告，明确要求猪肉制品加工企业开展非洲猪瘟检测。同时，我部印发通知，鼓励规模猪场、种猪场配置检测仪器设备，规范使用经我部批准或经中国动物疫病预防控制中心比对符合要求的检测方法，自行开展非洲猪瘟检测。鼓励养猪场户委托兽医社会化服务机构开展检测工作，提高监测排查的针对性和有效性。

二、关于加大对非洲猪瘟病毒病原学、病毒与猪体相互作用的基础科研投入。去年8月以来，我部和科技部安排多个应急科研项目，支持有关科研机构和大专院校等单位开展"非洲猪瘟病毒感染、致病与免疫分子机制研究""非洲猪瘟疫苗创制""非洲猪瘟病毒流行病学与检测技术研究""非洲猪瘟病毒重要蛋白结构与功能、免疫应答与疫苗策略、抗性基因挖掘研究"等防控技术研发。我部还安排专项经费，组织开展非洲猪瘟疫苗研制和防控技术集成。中国农业科学院安排创新工程经费，成立非洲猪瘟防控技术攻关项目组开展"非洲猪瘟病毒免疫抑制机制研究""基因缺失疫苗和活载体疫苗创制"等技术攻关。总的看，国内科研优势力量已从多种技术路线进行探索，为尽快取得技术突破奠定基础。

三、关于不限定疫苗研发单位。我部积极支持、鼓励各科研机构或企业开展非洲猪瘟研究，支持符合条件的单位开展非洲猪瘟病毒有关实验活动。开展兽用疫苗研发，应遵守《病原微生物实验室生物安全管理条例》《兽药管理条例》等法规规章相关规定，确保生物安全。在注册评审方面，我部对非洲猪瘟疫苗和诊断制品给予优先评审，第一时间安排评审和检验工作，促进新产品早日投入生产使用。2019年1月，我部印发《农业农村部办公厅关于进一步加强非洲猪瘟综合防控技术科研攻关的通知》，明确鼓励各级各类农业科研单位与相关高校、科研院所联合开展技术攻关。

四、关于开展国际合作。我部始终遵循"及时、公开、透明"的原则，及时向国际社会通报非洲猪瘟疫情及防控工作情况。积极加强多双边交流合作，与联合国粮农组织（FAO）、世界动物卫生组织（OIE）等国际组织在非洲猪瘟检测、流行病学调查等方面取得了一系列合作成果。在华主办非洲猪瘟防控国际研讨会、中老缅越联防联控会议等国际会议，积极派人参加国际组织或区域组织会议，介绍中国防控情况，分享防控经验，共同应对疫情风险。我部积极推动建立了亚洲非洲猪瘟防控工作组，协调完善区域联防联控机制。越南发生疫情后，我部应邀派出专家协助开展疫情调查和处置。FAO、OIE等国际组织和多个国家专家充分肯定我国防控成效。

下一步，我部将继续坚持开放态度，鼓励国内外有关机构开展合作，积极支持具备条件的单位依法依规开展研究工作，支持开展国际合作。

感谢您对畜牧兽医工作的关心，希望继续对我部的工作予以支持。
