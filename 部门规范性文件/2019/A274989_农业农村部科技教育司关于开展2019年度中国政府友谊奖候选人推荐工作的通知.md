# 农业农村部科技教育司关于开展2019年度中国政府友谊奖候选人推荐工作的通知

## 关于开展2019年度中国政府友谊奖候选人推荐工作的通知

农科（综合）函〔2019〕第54号

部属各单位：

按照科技部《关于2019年度中国政府友谊奖申报工作的通知》（国科发智〔2019〕70号）要求，现就做好我部申报人选推荐工作通知如下。

一、申报条件

（一）对我国经济建设和社会发展作出重要贡献、为促进中外交流合作和人才培养等各项事业发挥重要作用的外国专家，重点向具有重大原始创新能力的科学家、重大技术革新能力的科技领军人才、具有世界眼光和战略开拓能力的企业家以及我国经济社会发展急需的各类人才倾斜。

（二）重点推荐在贯彻“五大发展理念”、推动经济转型升级、加快高质量发展，助力科教兴国战略、人才强国战略、创新驱动发展战略、乡村振兴战略、区域协调发展战略、可持续发展战略、军民融合发展战略实施，推进“一带一路”建设、“中国制造2025”、扶贫脱贫、生态文明建设、传播中国声音等领域作出贡献的外国专家。

（三）对华友好，在我国边疆、贫困地区克服困难无私奉献，具有良好声誉和较大社会影响的外国专家。

（四）原则上为获得省、部级表彰奖项的外国专家，且未获得过中国政府友谊奖。

二、申报要求

（一）请填写《2019年度中国政府友谊奖申报要素表》（附件1）并按照相关要求准备申报材料。

（二）申报材料内容须翔实、表达准确、说服力强。推荐候选专家主要贡献（重点是在华期间所作贡献）应客观真实、重点突出、数据准确，参照主要贡献编写要求和相关模板编写（附件2），字数300至800字。

（三）除准备《2019年度中国政府友谊奖申报要素表》中外国专家主要贡献外，申报单位需提供主要贡献补充说明，将主要贡献涉及的专业词汇、行业词汇等作必要解释说明，同时补充说明外国专家从事的领域、课题、项目概况、外国专家来华后解决的问题等，作为附件并提供扫描件。

（四）外国专家工作的领域、课题和项目已列入国家、省、自治区、直辖市、副省级城市行业或部门发展规划的，应提供有关报告及批件扫描件。

（五）中国农业科学院、中国水产科学研究院、中国热带农业科学院推荐名额不限，如推荐2名及以上，请按推荐次序排序；其他单位原则上最多推荐1名候选专家。

（六）《2019年度中国政府友谊奖申报签章页》（附件3）“聘请单位意见”栏由专家聘请单位领导签署审批意见并加盖公章。

三、其他事项

（一）为按时完成我部推荐工作，请申报单位务必于4月1日前将以下材料各一式一份（电子版刻录光盘）报送人力资源开发中心：

1.《2019年度中国政府友谊奖申报要素表》；

2.《2019年度中国政府友谊奖申报签章页》；

3.主要贡献补充说明文档；

4.有关报告及批件扫描件。

（二）各单位填报准确性和申报材料文字质量将直接影响评审结果。请务必高度重视，认真填报申报材料。
