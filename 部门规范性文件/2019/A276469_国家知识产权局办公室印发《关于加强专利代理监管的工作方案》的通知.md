# 国家知识产权局办公室印发《关于加强专利代理监管的工作方案》的通知

国知办发运字〔2019〕13号

各省、自治区、直辖市、新疆生产建设兵团知识产权局（知识产权管理部门）；局机关有关部门，专利局有关部门，局有关直属单位、有关社会团体：

为深入贯彻党中央、国务院“放管服”改革部署，认真落实新修订的《专利代理条例》和《专利代理管理办法》，全面加强专利代理监管工作，促进专利代理行业健康发展，建设知识产权强国，推进经济高质量发展，制定《关于加强专利代理监管的工作方案》，现予印发，请认真贯彻执行。

国家知识产权局办公室

2019年4月22日
