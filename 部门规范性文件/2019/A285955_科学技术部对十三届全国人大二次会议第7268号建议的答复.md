# 科学技术部对十三届全国人大二次会议第7268号建议的答复

## 对十三届全国人大二次会议第7268号建议的答复

国科建议资〔2019〕56号

您提出的建议收悉。经认真研究，现答复如下。

一直以来，中央高度重视香港经济社会稳定发展，出台了系列政策措施支持香港融入国家发展大局。习近平总书记高度重视香港科技创新发展，特别是2017年对在港两院院士来信做出重要指示并强调，要促进香港同内地加强科技合作，支持香港成为国际科技创新中心，支持香港科技界为建设科技强国、为实现中华民族伟大复兴贡献力量。为贯彻落实习近平总书记的重要指示，科技部积极配合协调，稳步构建畅通的跨境科研经费管理机制。

在有关方面的共同努力下，打通了科研经费过境渠道。国家科技计划直接资助港澳科研活动试点工作顺利完成。2018年，科技部、财政部印发《关于鼓励香港特别行政区、澳门特别行政区高等院校和科研机构参与中央财政科技计划（专项、基金等）组织实施的若干规定（试行）的通知》（国科发资〔2018〕43号），通过作出总体制度安排，构建了中央财政科技计划资助港澳特区科研活动的长效机制。

感谢您对科技工作的支持！

科技部

2019年7月6日
