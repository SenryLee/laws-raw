# 中华人民共和国住房和城乡建设部公告2019年第218号——住房和城乡建设部关于2019年第十四批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第218号

## 住房和城乡建设部关于2019年第十四批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，刘振华等158名申请注册土木工程师（岩土）初始注册人员、吴敏莉等207名申请一级注册结构工程师初始注册人员、XXX林等364名申请注册公用设备工程师初始注册人员、徐永健等143名申请注册电气工程师初始注册人员、韩旭等47名申请注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予刘振华等158名注册土木工程师（岩土）初始注册人员名单

2.准予吴敏莉等207名一级注册结构工程师初始注册人员名单

3.准予XXX林等364名注册公用设备工程师初始注册人员名单

4.准予徐永健等143名注册电气工程师初始注册人员名单

5.准予韩旭等47名注册化工工程师初始注册人员名单

住房和城乡建设部

2019年8月19日
