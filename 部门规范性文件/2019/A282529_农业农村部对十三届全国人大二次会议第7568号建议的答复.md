# 农业农村部对十三届全国人大二次会议第7568号建议的答复

## 对十三届全国人大二次会议第7568号建议的答复

孙丰源代表：

您提出的关于振兴农村、建设美丽乡村的建议收悉。经商发展改革委、自然资源部，现答复如下。

一、关于做好国家层面顶层设计

习近平总书记强调，实施乡村振兴战略，要坚持规划先行、有序推进，做到注重质量、从容建设，打造各具特色的现代版“富春山居图”。去年，党中央、国务院印发的《乡村振兴战略规划（2018—2022年）》明确提出，顺应村庄发展规律和演变趋势，根据不同村庄的发展现状、区位条件、资源禀赋等，按照集聚提升、城郊融合、特色保护、搬迁撤并的思路，分类推进乡村振兴。今年中央一号文件提出，强化乡村规划引领，把加强规划管理作为乡村振兴的基础性工作。为贯彻落实中央决策部署，中央农办、农业农村部、自然资源部等五部门联合印发了《关于统筹推进村庄规划工作的意见》，要求各地建立县级党委政府主要领导负责的乡村规划编制委员会，切实加强村庄规划编制工作的领导；加快推进村庄规划编制实施，统筹谋划村庄发展定位、主导产业选择、用地布局、人居环境整治、生态保护、建设项目安排等。力争到2019年底，基本明确集聚提升类、城郊融合类、特色保护类等村庄分类；到2020年底，有条件的村可结合实际单独编制村庄规划，做到应编尽编。

下一步，我们将会同有关部门，加快推动各地建立健全县级党委政府负责的乡村规划工作机制，逐村研究村庄人口变化、区位条件和发展趋势，合理划分县域村庄类型，科学编制县域村庄布局规划和“多规合一”实用性村庄规划，努力做到不规划不建设、不规划不投入。

二、关于严格规划设计审核把关

村庄规划是开展国土空间开发保护活动、实施国土空间用途管制、核发乡村建设项目规划许可、进行各种建设的法定依据。今年，中央农办、农业农村部、自然资源部等五部门联合印发的《关于统筹推进村庄规划工作的意见》明确提出，由乡镇党委政府、县（市）政府有关部门、规划设计单位、村民代表共同组成村庄规划编制工作组，深入开展驻村调研、逐户走访，详细了解村庄发展历史脉络、文化背景和人文风情，充分听取村民诉求，获取村民支持。规划文本形成后，应组织村民充分发表意见，参与集体决策。规划报送审批前，应经村民会议或者村民代表会议审议，并在村庄内公示，确保规划符合村民意愿。自然资源部印发的《关于加强村庄规划促进乡村振兴的通知》，明确村庄规划由乡镇政府组织编制，报上一级政府审批；规划在报送审批前应在村内公示30日，报送审批时应附村民委员会审议意见和村民会议或村民代表会议讨论通过的决议。

下一步，我们将会同自然资源部等有关部门，加大对各地村庄规划编制审批管理的指导力度，严格落实有关程序要求，切实提高规划的科学性和可操作性，避免出现混乱无序、不可持续的建设情况。

三、关于因地制宜、循序渐进改善农村生活环境

改善农村人居环境，建设美丽宜居乡村，事关全面建成小康社会，事关广大农民根本福祉，事关农村社会文明和谐。以习近平同志为核心的党中央高度重视改善农村人居环境。2018年1月，中共中央办公厅、国务院办公厅印发了《农村人居环境整治三年行动方案》，明确到2020年实现农村人居环境明显改善、村庄环境基本干净整洁有序、村民环境与健康意识普遍增强的目标，提出了村容村貌整治提升、农村生活垃圾治理、农村生活污水治理、农村“厕所革命”、农业生产废弃物资源化利用、完善建设和管护机制、村庄规划管理等7方面任务。一是深入学习推广浙江“千万工程”经验。去年，中共中央办公厅、国务院办公厅转发了《深入学习浙江“千村示范、万村整治”工程经验扎实推进农村人居环境整治工作的报告》，对学习浙江经验作了全面阐述，强调在工作中要学习借鉴浙江省始终坚持以人民为中心的发展思想，把绿色发展和“绿水青山就是金山银山”的理念真正转化为引领推动农村人居环境综合治理的具体实践。二是推进农村“厕所革命”。农业农村部会同财政部等6部门印发了《关于推进农村“厕所革命”专项行动的指导意见》，这项工作主要包括农村户用卫生厕所改造、农村公共厕所建设、厕所粪污处理等3项任务。今明两年目标是在东部地区、中西部城市近郊区等有基础、有条件的地区，基本完成农村户用厕所无害化改造，厕所粪污基本得到处理或资源化利用；中西部有较好基础、基本具备条件的地区，力争实现卫生厕所普及率达到85%左右。三是推进农村生活污水治理。今明两年目标是加强人口聚集区、中心集镇、生态功能区等区域的处理设施和管道建设，根据区域位置、人口居住聚集程度等实际情况，因地制宜推广纳入城镇污水管网治理模式、联户治理模式、单户治理模式、人工湿地污水处理模式等四种模式。四是推进农村生活垃圾治理。重点是农村长年积存垃圾治理和日常生活垃圾处理。对农村长年积存垃圾治理，以解决垃圾山、垃圾围村、垃圾围坝、工业污染“上山下乡”等为重点，进行集中清理整治，到2020年底基本完成全国农村2.7万个非正规垃圾堆放点的清理整治。对农村日常生活垃圾处理，关键是推进源头分类，建立健全生活垃圾收运处置体系，加强资源化利用，构建村庄保洁长效机制。去年底中央农办、农业农村部等18个部委联合启动实施了以“三清一改”为重点的村庄清洁行动，清理农村生活垃圾、清理村内塘沟、清理畜禽粪污等农业生产废弃物，改变影响农村人居环境的不良习惯。据不完全统计，全国80%左右的村庄已开展了行动，累计清理垃圾3000多万吨，清理残垣断壁近300万处。

下一步，我部将继续发挥好牵头抓总作用，会同有关部门加大工作力度，完善支持政策，指导各地坚持可持续发展原则，因地制宜、有力有序推进包括农村改厕和农村生活垃圾污水治理在内的各项重点任务，确保如期完成农村人居环境整治三年行动目标任务。

四、关于建立强有力的检查监督、检查问责机制

《乡村振兴战略规划（2018-2022年）》明确，要加强乡村振兴战略规划实施考核监督和激励约束。将规划实施成效纳入地方各级党委和政府及有关部门的年度绩效考评内容，考核结果作为有关领导干部年度考核、选拔任用的重要依据。2019年中央一号文件指出，要强化五级书记抓乡村振兴的制度保障，实行中央统筹、省负总责、市县抓落实的农村工作机制，制定落实五级书记抓乡村振兴责任的实施细则，严格督查考核。今年中央一号文件贯彻落实情况督查（含推进乡村振兴战略实绩考核督查）已经中央批准，并列入中共中央办公厅、国务院办公厅印发的《2019年中央和国家机关督查考核检查计划》，明确重点督查乡村振兴规划先行落实情况、“三农”工作各项硬任务完成情况等内容。

下一步，我们将按照中央要求，加强对各地乡村振兴战略实施情况的检查和督导，着力将五级书记抓乡村振兴的要求落实到制度上、行动上，确保中央各项政策措施落实落地。

感谢您对推进乡村振兴战略实施工作的关心，希望继续对我部的工作给予支持。

农业农村部

2019年9月20日
