# 国家文物局关于在南山造像保护范围和建设控制地带内进行南山公园提升项目的意见

文物保函〔2019〕143号

浙江省文物局：

你局《关于全国重点文物保护单位南山造像保护区划内实施南山公园提升工程的请示》（浙文物发〔2018〕282号）收悉。经研究，我局原则同意在南山造像保护范围和建设控制地带内进行南山公园提升项目。

一、所报方案尚需做以下必要的修改和完善：

（一）建议以保护自然风貌、凸显文物价值为主要目的，适当弱化宗教氛围，不宜采用枯山水等景观手法。

（二）保护现有地形地貌，压缩硬化广场面积；应基本保持拟改造道路的原有路线和宽度，严格控制新增游步道宽度；减少绿化工程量，立足现有植被条件并适度优化，避免人工化、园林化倾向；不宜将水塘改造为跌水景观。

（三）补充拟改造建筑的现状描述，改建及新建建筑总高不得超过10米，并结合附近制高点景观视线分析，采取有效措施进一步弱化其对景观环境的影响。

（四）宜严格控制景观亭、廊架、禅意小品、标志、标牌等景观设施的数量和形式感，弱化照明工程。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月11日
