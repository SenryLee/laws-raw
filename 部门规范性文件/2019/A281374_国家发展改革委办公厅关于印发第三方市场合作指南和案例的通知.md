# 国家发展改革委办公厅关于印发第三方市场合作指南和案例的通知

各省、自治区、直辖市及计划单列市、新疆生产建设兵团发展改革委，有关企业：

近年来，我国企业（含金融企业，下同）以共建"一带一路"为引领，深化国际产能合作，联合外方企业共同开展第三方市场合作，取得各施所长、优势互补、多方共赢的积极成效。为更好服务企业开展第三方市场合作，现将《第三方市场合作指南和案例》印发给你们，供工作中参考。请结合实际推动第三方市场合作取得更多互利共赢成果。

附件：第三方市场合作指南和案例
