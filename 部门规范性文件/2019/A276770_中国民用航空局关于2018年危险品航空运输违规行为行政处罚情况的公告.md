# 中国民用航空局关于2018年危险品航空运输违规行为行政处罚情况的公告

## 关于2018年危险品航空运输违规行为行政处罚情况的公告

为进一步加强危险品航空运输管理，规范危险品航空运输秩序，充分发挥舆论监督作用，保障危险品航空运输安全，依据《民用航空危险品运输管理规定》第一百三十条的规定，现将2018年民航行业管理部门对违规航空运输危险品责任单位的行政处罚情况予以公告。

中国民用航空局

2019年4月30日

附件：2018年危险品航空运输违规行为行政处罚一览表
