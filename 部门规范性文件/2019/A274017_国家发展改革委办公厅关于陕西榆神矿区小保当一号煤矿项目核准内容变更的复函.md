# 国家发展改革委办公厅关于陕西榆神矿区小保当一号煤矿项目核准内容变更的复函

发改办能源〔2019〕142号

陕西省发展改革委：

报来《关于申请榆神矿区小保当一号煤矿项目核准变更的请示》（陕发改煤电〔2018〕1466号）及相关材料收悉。经委托咨询机构评估，现函复如下。

一、为加快优质产能释放，优化煤炭产业结构，同意小保当一号煤矿项目核准内容变更。煤矿建设规模1500万吨/年，一次建成投产，投产时布置1个大采高综采工作面，达到1500万吨/年生产能力。煤矿正式生产后，要根据煤层赋存情况适时增加薄煤层综采工作面进行配采，提高煤炭资源回收率。

二、建设方案调整后，小保当一号煤矿项目总投资为100.17亿元（不含矿业权费用）。其中，资本金31.10亿元，占总投资的31%，由项目单位以企业自有资金出资；资本金以外的69.07亿元，申请银行贷款。

三、项目按照1500万吨/年进行生产能力登记公告，不得批小建大、超能力生产。

四、除作上述调整外，其余事项仍按我委发改能源〔2017〕724号文核准的内容执行。

国家发展改革委办公厅
