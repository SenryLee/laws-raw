# 工业和信息化部对十三届全国人大二次会议第9311号建议的答复

## 对十三届全国人大二次会议第9311号建议的答复

陈锦石代表：

您提出的关于重点扶持新一代信息技术、智能制造为代表的高科技、战略新兴产业的建议收悉。经商国家发展改革委、科技部，现答复如下。

近年来，按照党中央、国务院决策部署，工业和信息化部、国家发展改革委、科技部等部门采取一系列举措，加快推进新一代信息技术产业发展，促进新一代信息技术与制造业的深度融合。

一、加强顶层设计

一是统筹部署新一代信息技术产业及其重点领域发展。落实按照党中央国务院有关决策，制定《关于推进物联网有序健康发展的指导意见》（国发〔2013〕7号）、《国家集成电路产业发展推进纲要》、《关于促进云计算创新发展培育信息产业新业态的意见》（国发〔2015〕5号）、《促进大数据发展行动纲要》（国发〔2015〕50号）、《信息产业发展指南》（工信部联规〔2016〕453号）、《新一代人工智能发展规划》（（国发〔2017〕35号）等，培育新技术新业态新模式，促进新一代信息技术产业加快发展。二是制定新一代信息技术与实体经济融合发展的指导性文件。贯彻党的十九大报告关于“推动互联网、大数据、人工智能和实体经济深度融合”的精神，以制造业为重点，研究制定《关于推进“互联网+”行动的指导意见》（国发〔2015〕40号）、《关于深化制造业与互联网融合发展的指导意见》（国发〔2016〕28号）、《关于深化“互联网+先进制造业”发展工业互联网的指导意见》（国发〔2017〕50号）等文件，加快推进新一代信息技术与制造业深度融合，促进制造业数字化转型升级。

二、加快推进新一代信息技术产业创新发展

一是加强关键核心技术创新突破。充分发挥新型举国体制作用，研究制定并落实优惠政策，推进制造业创新中心建设，积极支持科研院所、企业开展集成电路、软件、新一代移动通信、人工智能、云计算、大数据等领域技术研发，突破一批关键核心技术。二是培育产业发展新业态。实施制造业数字化转型升级，支撑工业互联网关键技术研发，推动5G和工业互联网的融合创新发展，培育智慧能源、智慧交通等新模式新业态。三是加快推动传统电子产品智能化升级。持续推进新一代信息技术与传统电子产品融合，推动智能电视、智能音箱、智能可穿戴、虚拟现实等智能联网终端设备发展，为社会提供更加丰富的新型智能化产品和服务。四是推动新一代信息技术产业集群化发展。聚焦集成电路、新型显示器件、下一代信息网络、信息技术服务、人工智能等新一代信息技术领域，培育和发展一批具有国际影响力或具有国内比较优势的新兴产业集群，打造区域济发展重要增长极，推动质量变革、效益变革、动力变革。

三、以智能制造为重点推进工业化和信息化深度融合

一是深入推进智能制造试点示范。组织实施智能制造试点示范专项行动，推动关键技术装备、工业互联网、工业软件、智能制造边准、制造成套装备等在典型行业的集成应用，在轻工、纺织、装备、航空、汽车等领域催生出一批智能制造新模式。二是完善智能制造标准体系。印发《国家智能制造标准体系建设指南》（2015年版、2018年版），成立国家智能制造标准化协调推进组、总体组和专家咨询组，加强开展智能制造标准规范的研究，四年来在基础共性、关键技术、重点行业等方面累计发布230多项国家标准。三是持续推进两化融合。引导企业加快数字化转型步伐，围绕工业大数据、工业电子商务、工业企业上云等组织遴选一批制造业与互联网融合试点示范项目，实施制造业“双创”专项。加快建设推广两化融合管理体系，累计贯标企业超过1.3万家。四是推进智慧健康养老产业发展。贯彻《国务院办公厅关于推进养老服务发展的意见》《智慧健康养老产业发展行动计划（2017-2020年）》，开展智慧健康养老应用试点示范、智慧健康养老产品及服务推广目录制定等工作，推进智慧健康养老标准体系建设。

四、营造有利于产业创新发展的政策环境

一是进一步扩大对外开放。以开放促改革促创新促发展，全面放开一般制造业，扩大鼓励外商投资范围，支持外资投向新一代信息技术、高端装备、绿色制造等先进制造领域，不断优化营商环境。二是加快推进知识产权保护工作。实施2019年知识产权推进计划，支持地方、行业开展知识产权工作，出台《制造业知识产权行动计划（2018-2020年）》，强化行业知识产权保护，组织开展企业知识产权运用试点培育工作，提升企业知识产权能力。三是促进创新成果产业化。推动落实促进科技成果转移转化的相关法律法规及配套政策，支持高校联合地方开展科技成果转化，建设制造业重点领域创新成果产业化公告服务平台。

五、以创新为引领，加快新一代信息技术产业发展，推进信息技术与实体经济深度融合

我们赞同您提出的支持推动新一代信息技术发展和应用、促进战略性新兴产业发展的有关建议。当今世界正在进入以新一代信息技术为引领的数字经济发展时期，加快新一代信息技术创新突破和融合应用，已经成为世界各国抢抓历史机遇、赢得发展主动的共同选择。我国经济已由高速增长阶段转向高质量发展阶段，正处在转变发展方式、优化经济结构、转换增长动力的攻关期。加快新一代信息技术攻关研发，推动新一代信息技术与制造业等实体经济融合发展，对促进经济高质量发展、提升产业链水平、实现新旧动能转换具有重要意义。

下一步，工业和信息化部等部门将认真贯彻党中央、国务院各项决策部署，持续推动新一代信息技术创新发展，加快推进互联网、大数据、人工智能等新一代信息技术与实体经济深度融合。一是突破关键核心技术。以应用为导向，以企业为主体，集中力量补短板、强弱项，开展信息技术领域“十四五”规划研究，布局前沿关键技术，拓展新一代信息技术新兴领域，提升产业链水平，推动我国新一代信息技术产业创新发展。二是加快新型基础设施建设。持续加强5G关键技术研发，加快工业互联网平台建设推广，推动人工智能、物联网、区块链等新型基础设施前瞻布局，实施制造业数字化转型行动，培育新模式新业态。三是大力发展智能制造。按照制造强国战略的总体部署，构建完备适用的智能制造标准体系，打造先进适用的智能制造系统，推动互联网、大数据、人工智能等技术与制造技术加快融合。四是加强开放合作。深化制造业对外开放，进一步扩大鼓励外商投资范围，支持跨国公司在华设立研发机构，支持国内企业与国际优势企业加强合作。深化与国际组织、相关国家在标准制定、知识产权等方面的交流与合作。

感谢您对工业和信息化工作的关心和支持。
