# 国家核安全局关于批准《华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（设计与建造阶段）E2版》《华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（调试阶段）C2版》的函

## 关于批准《华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（设计与建造阶段）E2版》《华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（调试阶段）C2版》的函

国核安发〔2019〕79号

华能山东石岛湾核电有限公司：

你公司《关于报送华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（设计与建造阶段）E版的请示》（华能石核安〔2018〕282号）、《关于报送华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（调试阶段）C版的请示》（华能石核安〔2018〕284号）、《关于审查华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（设计与建造阶段）E2版及质量保证大纲（调试阶段）C2版的请示》（华能石核安〔2019〕57号）收悉。

根据《中华人民共和国核安全法》《中华人民共和国民用核设施安全监督管理条例》的有关要求，我局对你公司提交的申请文件进行了审评，认为你公司提交的《华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（设计与建造阶段）E2版》《华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（调试阶段）C2版》是可以接受的，现予以批准。

你公司应严格遵守上述批准的质量保证大纲，并按照法规要求和所作承诺加强关键岗位人员任职资格考核和技能培训，确保核电厂设计、建造及调试质量。

国家核安全局

2019年4月2日
