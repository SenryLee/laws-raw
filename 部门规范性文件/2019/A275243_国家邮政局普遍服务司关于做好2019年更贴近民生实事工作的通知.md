# 国家邮政局普遍服务司关于做好2019年更贴近民生实事工作的通知

局普函〔2019〕8号

各省、自治区、直辖市邮政管理局：

为贯彻落实《国家邮政局关于印发2019年邮政业更贴近民生七件实事的通知》（国邮发﹝2019﹞2号）精神，做好2019年邮政业更贴近民生实事工作，确保兑现对人民群众的承诺，现将工作要点和有关要求通知如下：

一、 推进建制村直接通邮

新增直接通邮建制村5000个，基本实现全国建制村直接通邮。

工作要点：

1.四川、贵州、云南、甘肃、新疆等5个省、自治区邮政管理局（以下简称“相关省局”）要组织市（地）邮政管理局（以下简称“市（地）局”）对辖区内未通邮建制村开展实地调研，比例不低于30%，掌握未通邮建制村实际情况。

2.相关省局政企之间要密切配合，形成合力，一村一策，确保年底完成基本通邮工作任务。

3.相关省局、市（地）局政企之间每月要进行对接沟通，双方核准数据，并及时维护更新建制村信息系统，确保数据真实准确。国家局每月根据信息系统数据发布工作简报。

4.各省、自治区、直辖市邮政管理局（以下简称“各省局”）要组织对已实现直接通邮建制村的通邮情况开展检查，原则上每个省份实地检查建制村不低于总数的10%。发现违法问题要责令限期改正，情节严重或逾期不改的要严肃处理。

5.各省局要严格控制交通不便边远地区建制村的数量，不得以划定交通不便边远地区为由降低现有服务水平。对于划定的交通不便边远地区，省局要进行实地核实，核查报告于2019年10月底前报国家局。

6.各省局要根据国家局安排部署，推动运用信息化手段对建制村直接通邮情况进行监督。

二、改善末端投递服务

推广智能投递设施，箱投占比达到10%。

工作要点：

1.研究制定本地区推广智能信包箱建设应用实施意见，探索出台智能信包箱地方标准。

2.争取政策、资金支持，将智能信包箱建设纳入地方民生实事，争取智能信包箱进社区等配套政策。

3.加强与规划、住建等部门的联动，健全完善协同工作机制，将智能信包箱建设纳入建设工程总体方案，与主体工程同步设计、同步施工、同步验收。

4. 各省局分别于6月底和11月底书面报告本地区推广智能信包箱建设情况。

三、服务乡村振兴和精准脱贫

继续推进“邮政在乡”工程，培育“一市一品”精品项目，新建具备信息化功能的邮乐购站点3万个，提升邮政服务农村电商能力。

工作要点：

1.继续实施“一市一品”农特产品进城精品项目，实施分类管理，发展精品项目，总结本地区好的经验做法。

2.加快推广“农产品+大同城”寄递服务模式，将服务链条从单一寄递环节向包装、存储、运输、销售等一体化服务延伸。

3.支持本地邮政企业参与涉农电子商务平台建设，培育“电商+寄递”扶贫项目，重点扶持老少边穷地区培育特色地方农产品品牌。

4.协调争取 “电子商务进农村”综合示范资金、地方农村电商发展基金等政策、资金支持。

四、推动邮政综合服务平台建设

深入开展警邮合作，全面推行邮政营业场所代办公交交管业务，拓展税务代理业务。支持邮政企业进驻各地政务服务大厅，进一步推广“网上办事+线下寄递”模式，助力“不见面”审批。

工作要点：

1.制定本省加快邮政综合服务平台建设工作方案，跟踪督导抓好落实。

2.按照公安部、国家局、邮政集团公司联合发文要求，全面推行邮政营业场所代办公安交管业务。

3.鼓励支持邮政企业积极拓展税务代理业务内容和合作方式，确保取得良好社会效果。

4.学习贵州模式，指导邮政企业进驻各地政务服务大厅，推广“网上办理+网下寄递”模式，实现审批文件、营业执照、社保卡等制证寄证一体化服务。

5.因地制宜推动邮政与快递、交通、电商等企业共享运输资源、末端投递资源，提升邮政网点效能，实现共赢发展。

五、实施“放心安全消费工程”

加大对主要市场主体服务满意度、时限、申诉率及侵害消费者权益行为等重要指标和信息的披露力度，力争全年消费者申诉处理满意率达到98%以上。强化收寄验视、实名收寄、过机安检三项安全管理制度落实。

1.各省局继续推进“双随机、一公开”，开展省内邮政普遍服务达标检查。一是开展营业服务达标检查，重点检查乡镇普遍服务营业场所、城市委代办和不提供金融服务的普遍服务营业场所。二是开展农村投递服务达标检查。

2. 各省局组织开展省内、同城邮件时限监测，对监测中发现的问题要追溯检查，加大执法力度。加强对平常邮件收寄、投递、无着邮件处理等环节的检查，检验邮政企业寄递服务质量提升行动的措施和目标落实情况。

3.加强对不执行收寄验视、实名收寄、过机安检制度的监督检查。加强对邮政企业应用实名收寄信息系统的督导力度。

六、提高行业绿色发展水平

推动在城市建成区新增和更新的邮政快递车辆使用新能源或清洁能源汽车，支持甩挂运输、多式联运和绿色递送。

工作要点：

1.督促当地邮政企业建立健全生态环保组织机构和工作体系，落实“绿色邮政”行动计划。

2.指导邮政企业加快智能自助设备布放，推广应用新能源车辆，推广高品质绿色包装箱，全面提升电子面单使用率。

七、加强快递员（投递员）权益保护

加强从业人员权益保护和从业青年联系服务工作，改善工作环境。

工作要点：

1. 继续落实西部和农村地区局所改造工程，主动与发改部门衔接沟通，建立协调联动机制，履行行业监管责任，加大监督检查力度，做到项目审查到现场、建设到现场、竣工验收到现场，确保项目实施质量和进度。认真执行《邮政基础设施项目中央预算内投资管理暂行办法》，加强投资项目监管，要求邮政企业按月报送信息，及时掌握投资项目实施情况。

2.鼓励支持邮政企业加强“职工小家”建设，改善职工工作环境。

八、工作要求

（一）高度重视。各级邮政管理部门要坚持“人民邮政为人民”的宗旨意识，充分认识落实邮政业更贴近民生实事的重要政治意义，将落实民生实事作为重点工作、一把手工程来抓，兑现邮政管理部门对人民群众的庄严承诺。

（二）狠抓落实。对标工作要点，细化目标任务，落实责任分工，把更贴近民生实事办理与年度重点工作结合起来统筹谋划、协调推进，真抓实干、务求实效。

（三）及时总结通报。各省局要及时总结工作情况，将民生实事工作的进展情况、亮点成效以及存在问题作为本省份邮政普遍服务季度通报的重要内容进行通报。普遍服务司将在全国邮政普遍服务季度通报中进行体现，并将视情况派出督导组开展督导检查。
