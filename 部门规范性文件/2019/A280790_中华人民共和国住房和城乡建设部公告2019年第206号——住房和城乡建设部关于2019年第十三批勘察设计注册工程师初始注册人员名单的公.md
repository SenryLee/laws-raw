# 中华人民共和国住房和城乡建设部公告2019年第206号——住房和城乡建设部关于2019年第十三批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第206号

## 住房和城乡建设部关于2019年第十三批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，张顶锋等242名申请注册土木工程师（岩土）初始注册人员、李保宽等349名申请一级注册结构工程师初始注册人员、朱广远等491名申请注册公用设备工程师初始注册人员、方培培等128名申请注册电气工程师初始注册人员、黄龙等80名申请注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予张顶锋等242名注册土木工程师（岩土）初始注册人员名单

2.准予李保宽等349名一级注册结构工程师初始注册人员名单

3.准予朱广远等491名注册公用设备工程师初始注册人员名单

4.准予方培培等128名注册电气工程师初始注册人员名单

5.准予黄龙等80名注册化工工程师初始注册人员名单

住房和城乡建设部

2019年7月26日
