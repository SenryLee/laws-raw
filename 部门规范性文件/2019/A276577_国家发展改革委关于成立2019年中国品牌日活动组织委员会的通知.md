# 国家发展改革委关于成立2019年中国品牌日活动组织委员会的通知

发改产业〔2019〕677号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团发展改革委，中国轻工业联合会、中国纺织工业联合会、中国电子信息行业联合会、中国汽车工业协会，中国自行车协会、中国钟表协会、中国家用电器协会、中国陶瓷工业协会、中国香料香精化妆品工业协会、中国洗涤用品工业协会、中国口腔清洁护理用品工业协会、中国文教体育用品协会、中国乐器协会、中国皮革协会、中轻食品工业管理中心、中国食品科学技术学会、中国国际工程咨询有限公司，中国质量协会，中国广告主协会、中国专利技术开发公司、上海外经贸商务展览有限公司：

为深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，全面落实中央经济工作会议要求和党中央、国务院关于品牌发展的决策部署，深化供给侧结构性改革，推动高质量发展，促进形成强大国内市场，办好2019年中国品牌日活动，经国家发展改革委、中宣部、工业和信息化部、农业农村部、商务部、市场监管总局、知识产权局、上海市人民政府研究决定，成立2019年中国品牌日活动组织委员会（以下简称“组委会”）。现将有关事项通知如下。

一、组委会主要职责及组成人员

（一）主要职责

审议确定2019年中国品牌日活动重大事项，协调解决筹办工作中的重大问题。

二、组委会办公室主要职责及组成

（一）主要职责

组委会办公室设在国家发展改革委产业司。主要职责：一是落实组委会的相关决定；二是策划、编制活动总体方案，指导各地开展活动，审查确定有关活动方案；三是督办各工作组相关工作，协调解决有关问题。

（三）工作机构

1.综合协调组

由国家发展改革委产业司轻纺处负责，其他联合主办单位各派1名处级人员参加。主要职责：一是组织拟定2019年中国品牌日活动总体方案；二是邀请国家领导人出席，组织国内有关单位参加；三是协调活动筹备事务，衔接各地活动开展工作；四是推进活动宣传工作；五是向组委会办公室汇报有关情况。

2.组织实施组

由联合主办单位指导，上海市政府负责，承办单位具体实施。主要职责：一是活动总体规划设计；二是协调体验区设置具体事务；三是活动场地布置、现场管理、会务服务、材料制作等；四是志愿者服务人员招募与培训等；五是专题网站及新媒体平台更新维护；六是落实好当地活动宣传工作；七是中外方嘉宾信息收集、参会接待以及会议组织服务等。

3.安全保障组

由各地政府相关部门负责，特别是上海市政府要专门成立安全保障组，主要负责做好活动安全保卫、治安管理、医疗卫生、食品安全、消防、交通、水电、通讯等保障工作。

三、组委会时效

鉴于组委会因举办2019年中国品牌日活动设立，待活动结束后，组委会自行撤销。
