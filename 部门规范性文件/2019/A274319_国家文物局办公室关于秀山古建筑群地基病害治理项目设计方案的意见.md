# 国家文物局办公室关于秀山古建筑群地基病害治理项目设计方案的意见

办保函〔2019〕83号

云南省文物局：

你局《关于请求对秀山古建筑群地基病害治理工程设计方案进行审核的请示》（云文物〔2018〕208号）收悉。经研究，我局暂不同意所报方案。

一、所报方案尚需做以下必要的修改和完善：

（一）应注意区分地基和基础，明晰地基基础病害的具体内容，进一步明确本次病害治理的对象。

（二）坚持最小干预的原则，以现状加固为主、消除安全隐患为前提，减小工程范围和工程量。

（三）进一步完善对回填土的勘察，明确回填的年代及物理力学指标，评价地基承载力，计算主动土压力，校核现有挡墙的结构强度和稳定性。

（四）深入评估虎豹九天——登瀛桥处边坡的稳定性，准确判定滑移面，合理选择计算参数，调查分析滑塌特征及产生滑塌的地质条件；补充探坑平面分布图。

（五）拟采用的加固措施干预力度过大，应予调整。论证部分区域同时采用袖阀注浆、微型桩等多种加固措施的必要性；论证虎豹九天——登瀛桥处发生较大规模滑坡的可能性，不建议采用嵌入式锚索框架进行加固。

（六）进一步论证非边坡边沿大范围沉降区域采取注浆加固的必要性，查清地面沉降的原因和发展趋势。如因填土二次固结引起沉降且已趋于稳定，建议填土压实地面找平处理；如确为地震震裂地基土或地基承载力不足，则可进行注浆。

（七）进一步完善保护措施。细化注浆、加制微型桩的施工工艺，针对潜在险情制定应急预案，建议采用对称分区和小范围施工，防止集中扰动诱发新的险情；补充场地排水设计。

（八）加强与文物建筑修缮项目的衔接，合理安排工序，避免二次扰动。

二、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改和完善后，按程序另行报批。地基病害特别严重的区域，可采取临时性抢险加固防护措施，确保文物建筑安全。

专此函复。

国家文物局办公室
