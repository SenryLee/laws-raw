# 国务院国有资产监督管理委员会关于政协十三届全国委员会第二次会议第4110号提案的答复

## 关于政协十三届全国委员会第二次会议第4110号提案的答复

中国国际时装周（以下简称时装周）创立于1997年，由中国服装设计师协会主办，每年3月、10月份春夏和秋冬两季在北京举办时装展览展示活动。迄今为止，已有近2000家（位）中外品牌和设计师参与了时装发布和展览展示活动。目前，每年时装周举办近200场时装秀，现场专业观众超10万人，电视观众超5亿人次，吸引来自国内外媒体近300家（其中境外媒体占20%）。多年来，时装周在推动我国纺织服装产业结构调整、转型升级、供给侧改革以及中国服装由加工大国不断向品牌强国转变过程中发挥着越来越重要的作用；促使服装设计师群体的专业水平及其在社会和产业中的地位不断加强；在全国的影响力和权威性不断提升。据不完全统计，在时装周的示范引领下，全国近30个城市相继举办了时装周。时装周在推动时尚生活方式的转变、满足人民群众对美好生活向往方面发挥着积极的引导作用。

为落实习近平总书记关于建设人类命运共同体的号召，时装周利用时装和时尚生活方式“润物细无声”的表现形式，达到与世界沟通、交流、传播的目的，为推动中外设计师交流、展现中国设计力量、传播中国优秀文化、讲好中国服饰文化故事、与世界文化交互融合不懈努力。

时装周经过二十多年的发展，取得了一些成绩，但距离国际四大时装周仍有较大差距，还存在许多不足。一是时装周对品牌的市场影响力和商业价值提升作用尚显不足。二是在推动中外文化共融和交流互鉴方面作用发挥不充分。三是在绿色、健康、时尚生活方式的传播推广方面还有待进一步提升。四是在不断转变观念，加快和提升时装周服务升级上有待加强。

您提出的如何把时装周打造成为有国际影响力的时尚文化平台方面的四条建议，涉及我委工作的有三条。

一、关于“建议参照意大利、法国等国家的做法，国家成立时尚产业专项基金”的问题。时装周先后与法国、意大利、美国、俄罗斯、阿拉伯联合酋长国等众多国家的时装周及时尚机构建立起良好合作关系并开展互动和交流活动，迄今已有来自日本、法国、意大利、澳大利亚等20多个国家和地区的设计师和品牌参与时装周。二十多年的发展，使得时装周在参展品牌数量、时装发布数量、国际知名品牌参与度等方面不断增加，已成为比肩巴黎、米兰、伦敦、纽约等国际知名时装周的专业展会，是“中国文化走出去”倡议的重要平台和工具。我们认为，时装周是市场自发组织的时装展览展示活动，来自世界各地的参展商、设计师、买家、游客是时装周发挥活力和影响力的决定因素，活动本身属于市场行为，不应由国家进行干预。而应该采取市场化方式，由有关方面牵头成立诸如“时尚产业专项基金”等对产业进行引领和推动，政府有关部门则需要提供引导和支持。对此，我们将积极协调有关部门进行研究、论证和推动。

二、关于“建议把服装设计师培训列入文旅部、商务部、国资委、科技部、外专局出国培训计划”的问题。从纽约、伦敦、巴黎、米兰等各大国际知名时装周经验来看，时装周在拉动经济消费、提高文化软实力、促进世界文化交流互鉴方面作用显著，并且都发挥了优秀设计师的关键作用。我们认为，支持年轻设计师培育和中国设计师走出去十分必要，但我委出国培训主要针对中央企业领导人员、科技人才与技能人才，且团组数量、主题十分有限，并无适合服装设计师参与的境外培训团组。可考虑的方式是，由中国服装设计师协会建立渠道邀请境外优秀人才在国内组织对服装设计师进行培训。

三、关于“建议国家文旅部门、纺织工业协会、中国服装设计师协会协同推动我国服装服饰历史文化研究，研究机构以立项方式开展工作”的问题。此建议是希望国家成立研究机构，以立项方式开展工作。聚焦传统工艺，支持服装设计师对非物质文化遗产进行发掘，培育自主品牌，体现文化自信。这对于纺织服装业的高质量发展很有意义。当前，我国正在推进事业单位改革，正在巩固和深化党和国家机构改革，也正在努力推进“放管服”改革。改革的目的是深化转职能、转方式、转作风，提高效率效能，积极构建系统完备、科学规范、运行高效的职能体系，不断提升服务意识和能力，不断增强人民群众获得感。在此改革背景下，不应再由国家设立研究机构。确有必要的，还需按程序研究、论证并设立。我们鼓励和支持中国纺织工业联合会、中国服装设计师协会积极开展我国服装服饰历史文化研究，引导中国时尚产业聚焦传统工艺，更加深入全面挖掘和培育有灵感、有激情、有才华的设计师，创新管理、服务方式，为设计师提供精准的个性化支持和渠道对接等有效帮助，支持设计师对非物质文化遗产的继承和发掘，培育自主品牌，提升中国时尚文化全球影响力，不断树立我国的时尚文化自信。
