# 人力资源社会保障部办公厅关于进一步支持"三区三州"等深度贫困地区技工教育发展的通知

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）：

为贯彻党中央、国务院关于支持深度贫困地区脱贫攻坚的部署要求，落实《人力资源社会保障部　财政部关于进一步支持"三区三州"等深度贫困地区人力资源社会保障扶贫攻坚工作的通知》（人社部发〔2019〕51号），现就支持"三区三州"等深度贫困地区（以下简称"深贫地区"）技工教育发展有关事项通知如下。

一、指导做好技工院校建设和对口帮扶，加强公共实训基地建设。支持生源数量较充足、具备发展技工教育条件的深贫地区新建技工院校，支持四川、云南、西藏、甘肃、青海、新疆及新疆生产建设兵团大力发展技工教育，明确建设任务，协调开展省内外对口帮扶。鼓励生源数量较少或自然条件艰苦的深贫地区，依托本省份优质技工院校资源开设分校（教学点）或依托本省职教资源开展技能扶贫工作。指导做好公共实训基地建设，推动公共实训基地积极承担技能扶贫各项任务。各级人力资源社会保障部门要按照深贫地区建设技工院校对口帮扶计划表（附件1）和深贫地区现有技工院校对口帮扶计划表（附件2），抓好工作落实。

二、做好专业建设和师资培养，加强技能实训。坚持面上指导与重点帮扶相结合，各帮扶院校重点帮扶1至2个专业。各帮扶院校与受援院校联合成立专业建设委员会，在受援院校设立专家流动站，确保每个专业定期有1名帮扶院校专家驻站，加强对专业建设方案、人才培养方案、专业课程建设、专业教材编撰的指导。各帮扶院校利用企业资源优势，至少联系引进1家技术先进、专业对口的较大规模企业与定点帮扶的专业开展深度合作。采取双向挂职、两地培训、委托培养和支教等方式，定期选派技能专家、优秀教师到对口支援院校支教；接纳对口支援院校选派管理人员及教师到校培训、跟岗学习等方式培养培训教师，加快高技能、高素质师资队伍建设。帮扶院校采取到校指导、接纳培训等方式，帮助受援院校参加技能大赛的学生进行专业技能强化训练。支持对口帮扶院校通过联合培养等方式招收深贫地区学生到本校就读。

三、强化校企合作，鼓励社会各方参与。各级人力资源社会保障部门要广泛发动社会力量积极参与技工院校技能扶贫工作，鼓励各级各类企业、职业培训机构举办或参与举办技工院校，校企双制共同培养技能人才。鼓励企业根据用工需求，与"三区三州"技工院校签订技能扶贫合作协议，共同确定技能人才培养方式，做好培训后就业安置。积极引导企业和社会组织面向深贫地区开展助学援助，给予生活费补贴，提供爱心奖（助）学金等。鼓励企业提供实习岗位，优先录用符合条件的建档立卡贫困家庭学生。

四、落实政策，加大支持力度。各级人力资源社会保障部门要按照《人力资源社会保障部 国务院扶贫办关于深入推进技能脱贫千校行动的实施意见》（人社部发〔2019〕2号）要求，落实各项资助政策。"三区三州"人力资源社会保障部门要主动与帮扶省市对接，制定帮扶贫困家庭就读子女给予生活费补助实施细则。技工院校绩效工资分配要向参与扶贫工作的教师加大倾斜力度。参加对口帮扶的专家、教师等支教服务期可作为基层工作经历，在评优评先、职级晋升、职称评审、岗位聘用等方面优先考虑。各对口支援省市要积极协调有关部门加大对深贫地区技工院校资金投入力度，支持其改善硬件设施，强化设备投入，改善办学条件。我部协调相关部门在高技能人才振兴计划、产教融合发展工程、校长培训、一体化师资培训、创业师资培训等项目对深贫地区予以倾斜和大力支持。

五、建立完善对口帮扶机制，压实工作责任。各省级人力资源社会保障部门要主动担责，积极作为，动员优质资源参与帮扶工作，同时做好各项工作的督导落实。重点督导新建技工院校（分校或教学点）建设进度和对口帮扶协议落实执行进度，研究解决突出问题。对贡献突出、成效显著的予以通报；对工作不到位、措施不得力、政策不落实、工作进展缓慢的地方，要及时予以纠正。各帮扶院校要将对口帮扶工作作为重要任务予以落实，选派骨干力量、调动各方面积极性，认真制定帮扶工作方案，按照时间节点，推动帮扶工作取得实效。受援技工院校要承担建设主体责任，立足自身条件，合理确定发展规划和帮扶需求，为支教人员提供必要的工作生活条件保障。

请各省级人力资源社会保障部门于每年12月底前报送本年度技能扶贫工作总结。
