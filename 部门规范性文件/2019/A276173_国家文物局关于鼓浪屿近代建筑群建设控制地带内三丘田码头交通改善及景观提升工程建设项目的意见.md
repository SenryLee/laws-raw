# 国家文物局关于鼓浪屿近代建筑群建设控制地带内三丘田码头交通改善及景观提升工程建设项目的意见

文物保函〔2019〕304号

福建省文物局：

你局《关于报送鼓浪屿近代建筑群建设控制地带内三丘田码头交通改善及景观提升工程设计方案的请示》（闽文物字〔2018〕570号）收悉。经研究，我局原则同意在鼓浪屿近代建筑群建设控制地带内实施三丘田码头交通改善及景观提升工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应在妥善维护历史环境、保持现有规模的前提下，将有关鼓浪屿建筑特色和文化内涵、三丘田区域历史文脉和时代创新的展示阐释内容，有机融入建筑和场地设计中。

（二）进一步完善施工方案和施工组织设计，强化施工管理措施，做好围挡，制定应急预案，切实防范施工产生的粉尘、噪声等污染对周边景观环境造成不利影响。

（三）做好施工期间的游客管理、疏导和解释说明工作，减缓对游客参观游览的影响。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强项目实施的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月26日
