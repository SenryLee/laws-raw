# 商务部市场秩序司关于印发《2019年市场秩序工作要点》等文件的通知

## 关于印发《2019年市场秩序工作要点》等文件的通知

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门：

为打造良好营商环境和消费环境，按照全国商务工作会议部署，我们制定了《2019年市场秩序工作要点》《2019年商务信用建设工作要点》和《2019年重要产品追溯体系建设工作要点》，现印发给你们，请结合实际认真贯彻执行。

附件：1.《2019年市场秩序工作要点》

2.《2019年商务信用建设工作要点》

3.《2019年重要产品追溯体系建设工作要点》

商务部市场秩序司

2019年4月9日
