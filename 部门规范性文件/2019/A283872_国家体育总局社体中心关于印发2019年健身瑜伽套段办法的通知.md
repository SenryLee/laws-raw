# 国家体育总局社体中心关于印发2019年健身瑜伽套段办法的通知

## 体育总局社体中心关于印发2019年健身瑜伽套段办法的通知

各有关单位：

为全面落实健康中国战略目标，扎实推进健身瑜伽标准化项目建设，根据《中国健身瑜伽段位制（试行）》相关规定，结合健身瑜伽项目发展现状，我中心将一次性授予多年从事瑜伽运动并取得一定成绩者健身瑜伽段位称号，作为段位制推行的启动者。现将《2019年健身瑜伽套段办法》印发给你们，请相关单位及个人踊跃报名，积极参与推广健身瑜伽运动。

特此通知。

附件：2019年健身瑜伽套段办法

体育总局社体中心

2019年11月11日
