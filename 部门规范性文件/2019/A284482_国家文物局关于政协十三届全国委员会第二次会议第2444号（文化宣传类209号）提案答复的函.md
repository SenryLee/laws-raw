# 国家文物局关于政协十三届全国委员会第二次会议第2444号（文化宣传类209号）提案答复的函

文物政函〔2019〕837号

叶洲委员：

您提出的《关于尽快对樊锦诗等文化老人予以抢救性的“口述实录”的提案》已收悉。现答复如下。

国家文物局高度重视文博系统老专家的记忆保存和经验传承，加强政策引导和资金支持，力求将先生们携带的文化记忆和历史细节记录在册，以“口述实录”形式留存民族记忆、传承优秀传统文化。目前，文物出版社已抢救性出版了90多岁高龄的著名文物专家谢辰生先生的口述实录。

敦煌研究院已于2009年启动“口述历史”项目，实地采访在莫高窟工作生活过的老专家、老学者及其亲属，收集整理相关老照片、手稿及实物等，以文字、音像形式记录保存他们的文物保护工作历程。截至目前，已陆续采访30余名老专家及其亲属，累计超过3000多小时，整理文稿28.6万余字，收集700多张老照片以及部分手稿、工作生活用品等；在敦煌研究院网站陆续发表相关文章11篇；编撰形成《敦煌回忆录丛书》，已完成万庚育、孙儒僩、关友惠等3名老专家回忆录的编辑工作。

樊锦诗先生毕生致力于石窟考古、石窟科学保护与管理工作，开创了敦煌莫高窟开放管理新模式，为世界文化遗产和大遗址保护传承与利用作出了突出贡献，对樊锦诗先生进行抢救性“口述实录”十分必要。2016年，由樊锦诗先生口述、北京大学教授顾春芳执笔的《我心归处是敦煌——樊锦诗口述自传》启动，已于近期完稿，入选中宣部2019年主题出版重点出版物选题，将于年内出版。此外，敦煌研究院李云鹤等其他老专家的回忆录，也将陆续编撰出版。

下一步，国家文物局将继续加大对文化老人的宣传力度，实施中华文物全媒体传播计划，借助局属媒体和相关合作媒体平台，专题采访、广泛传播文博系统老专家的典型事迹和宝贵经验；支持引导各地文物部门、相关文博单位开展口述历史工作，留存保护好文化老人弥足珍贵的历史记忆。

感谢您对文物事业的关心和支持！

国家文物局

2019年8月19日
