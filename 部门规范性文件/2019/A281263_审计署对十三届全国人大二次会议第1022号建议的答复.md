# 审计署对十三届全国人大二次会议第1022号建议的答复

## 对十三届全国人大二次会议第1022号建议的答复

审函〔2019〕52号

郭艳玲代表：

您提出的关于将草原自然资源资产核算方法应用到领导干部离任审计的建议收悉，我署会同林业和草原局进行了认真研究，现答复如下：

一、近年来领导干部自然资源资产离任审计及自然资源资产负债表编制相关工作开展情况

党的十八大以来，党中央国务院高度重视生态文明建设，加快推进生态文明顶层设计，做出了一系列重大部署和制度性安排。2013年11月，党的十八届三中全会通过的《中共中央关于全面深化改革若干重大问题的决定》，首次对编制自然资源资产负债表和实行领导干部自然资源资产离任审计作出明确部署。2015年以来，在中央加快推进生态文明建设和生态文明体制改革等重要文件中，多次强调探索编制自然资源资产负债表，对领导干部实行自然资源资产离任审计，并将其纳入完善生态文明绩效评价考核和责任追究制度中。

在开展领导干部自然资源资产离任审计方面。审计署党组高度重视、积极推进，将开展领导干部自然资源资产离任审计作为落实党中央国务院决策部署，推动生态文明建设的重要举措，按照中央部署的路线图、时间表，积极进行理论研究和审计实践，已初步完成阶段性工作任务。2014年至2017年，全国各级审计机关共实施审计试点项目827个，涉及被审计领导干部1210人，对领导干部自然资源资产离任审计"审什么、怎么审、怎么评价"等进行了积极探索，形成了可复制、可推广的经验。在总结试点经验做法基础上，2017年9月，中共中央办公厅、国务院办公厅正式印发《领导干部自然资源资产离任审计规定（试行）》，领导干部自然资源资产离任审计工作全面推开，向制度化、规范化、科学化迈出了坚实的一步。2018年，全国各级审计机关共实施领导干部自然资源资产离任（任中）审计项目2500余个，涉及被审计领导干部3500余人。领导干部自然资源资产离任审计作为一项经常性的审计制度已基本建立。全国审计机关坚持边实践、边探索，对包括草原资源在内的自然资源资产的审计内容、评价指标、审计程序、审计方法等进行了系统的实践和研究。如内蒙古自治区审计厅近年来在开展领导干部自然资源资产离任审计时，根据当地自然资源禀赋特点，将草原资源的开发利用管理和草原生态系统的维护修复作为重点审计内容，在草原自然资源实物量核算、量化评价指标选取等方面开展了积极的探索和研究工作，取得了较好的成效。

在探索编制自然资源资产负债表方面。近年来，国家统计局会同自然资源部、农业农村部等有关部门在8个试点地区开展自然资源资产负债表试编工作，联合8个部委印发了《自然资源资产负债表编制制度（试行）》，在内蒙古自治区呼伦贝尔市鄂温克旗、浙江省湖州市安吉县、贵州省遵义市赤水市和陕西省延安市富县等地启动了县级自然资源资产负债表编制试点。目前包括草原资源资产在内的相关资产负债表试编工作已取得初步进展。

二、对相关建议拟采取的措施

审计署和相关部委十分重视您关于草原自然资源资产核算方法的意见。草原是我国面积最大的陆地生态系统，将草原资源纳入自然资源资产负债表编制，并在领导干部自然资源资产离任审计中加以重点关注，是落实中央生态文明建设决策部署的必然要求。您关于将草原自然资源资产核算方法应用于领导干部自然资源资产离任审计的建议，以及中科院内蒙古草业研究中心落实习近平总书记指示要求，大胆先行先试，建立草原自然资源资产评估体系的经验，为我们提供了重要的工作思路。

在目前的领导干部自然资源资产离任审计实践中，包括草原在内的自然资源资产实物量和质量变化情况分析是工作的难点之一。在今后的工作中，我们将充分借鉴您提出的草原自然资源资产核算经验和技术方法，在相关地区的领导干部自然资源资产离任审计中加大对草原资源资产的审计监督力度，进一步创新审计技术方法，关注其实物量和质量的增减变化，准确客观评价领导干部履行草原资源资产管理和保护责任的情况。

感谢您对审计工作的关注和支持！
