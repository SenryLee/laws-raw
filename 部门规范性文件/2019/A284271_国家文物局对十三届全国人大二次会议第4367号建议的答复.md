# 国家文物局对十三届全国人大二次会议第4367号建议的答复

文物保函〔2019〕611号

庞永辉代表：

您提出的“关于加强定窑遗址保护传承定瓷非遗文化的建议”收悉，经商国家发展和改革委员会，现答复如下：

定窑遗址是中国制瓷发展史的历史见证，具有重要的历史、艺术和科学价值，1988年被国务院公布为全国重点文物保护单位。国家文物局、国家发展和改革委员会历来高度重视定窑遗址保护利用工作。“十一五”以来，定窑遗址一直被列入国家大遗址保护项目库；“十三五”期间，国家发展和改革委员会将河北省包括定窑遗址在内的56个项目纳入文化旅游提升工程项目储备库，给予国家重点支持。

您提出的将定窑遗址评定为国家考古遗址公园、将定瓷特色小镇纳入“国家级特色小镇”、加大定窑遗址考古公园、定瓷艺术博物馆资金支持力度等建议，对于进一步推进定窑遗址保护利用具有重要意义。下一步，国家文物局将会同有关部门继续做好如下工作：

第一，指导地方专业考古机构积极推进定窑遗址考古和研究工作，明确遗址的分布范围，深入挖掘定窑遗址内涵，抓紧开展考古资料整理、报告出版和出土文物移交工作，为定窑遗址的保护利用提供坚实的学术支撑。

第二，督促地方人民政府落实文物保护的主体责任，抓紧编制、实施《定窑遗址总体保护规划》，建立健全管理机构，加强遗址的日常巡查与看护工作，切实改善定窑遗址保护管理现状，妥善处理遗址保护和城乡发展之间的关系。

第三，引导地方人民政府深入研究定窑遗址保护利用方式，合理确定建设考古遗址公园的必要性和可行性，明确博物馆、游客服务中心等新建设施的功能定位、展示主题、运营方式和投入维护成本等，避免贪大求多。我局将在定窑遗址的考古发掘、本体保护、遗址展示等方面给予积极支持。

目前，国家发展和改革委员会尚未开展国家级特色小镇命名或创建工作，其组织实施的文化旅游提升工程经费支持范围不包括博物馆建设等内容。因此，建议地方人民政府发挥主观能动性，整合现有资源，注重非遗传承，积极推进定瓷特色小镇建设工作。

感谢您对文物事业的关心和支持。

国家文物局

2019年7月1日
