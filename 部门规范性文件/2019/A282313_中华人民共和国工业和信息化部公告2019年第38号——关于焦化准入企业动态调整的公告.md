# 中华人民共和国工业和信息化部公告2019年第38号——关于焦化准入企业动态调整的公告

## 中华人民共和国工业和信息化部公告

2019年第38号

根据《焦化行业准入条件（2014年修订）》和《焦化生产企业公告管理办法》，我部开展了焦化准入企业动态调整工作。经企业自查申报、地方工业主管部门初审、专家核实和网上公示等程序，现将符合《焦化行业准入条件》的企业名单（含焦炭、甲醇、煤焦油、苯精制）、准入企业变更装备（含增加、减少）的企业名单、准入企业变更名称的企业名单、撤销焦化行业准入公告的企业名单予以公告。

附件：

1.新申请符合焦化准入条件的企业名单-焦炭（第十二批）

2.新申请符合焦化准入条件的企业名单-甲醇（第三批）

3.新申请符合焦化准入条件的企业名单-煤焦油（第二批）

4.新申请符合焦化准入条件的企业名单-苯精制（第二批）

5.准入企业变更增加装备的企业名单

6.准入企业变更减少装备的企业名单

7.准入企业变更名称的企业名单

8.撤销焦化准入公告的企业名单

工业和信息化部

2019年10月9日
