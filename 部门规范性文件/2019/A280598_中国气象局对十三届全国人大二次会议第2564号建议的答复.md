# 中国气象局对十三届全国人大二次会议第2564号建议的答复

中气议字〔2019〕7号

韩秋香代表：

您提出的《关于加强气象服务精准农业的建议》（第2564号）收悉。经商财政部，答复如下：

您的建议有很强的针对性，对气象为农服务工作有积极的促进作用。气象部门高度重视气象为农服务工作，认真贯彻落实党中央、国务院部署，在各级财政部门的大力支持下，坚持把服务“三农”作为气象部门的基本职责，作为气象工作的重中之重，积极为乡村振兴战略提供气象服务保障。

一、关于充实基层人员队伍问题

近年来，我局在坚决执行中央严格机构编制管理有关要求的同时，采取多种措施缓解基层气象部门人员紧缺问题。一是加强气象现代化建设，大力推进气象观测自动化，优化基层台站人员结构，提升基层台站工作效率；二是加强基层人才队伍建设，出台《中共中国气象局党组关于增强气象人才科技创新活力的若干意见》（中气党发〔2017〕25号）、《中国气象局关于进一步做好基层气象部门人员招录工作的意见》（气发〔2017〕44号）等文件，对基层人员予以政策倾斜，并加强相关业务、技能培训，不断提升基层人员能力；三是深化气象职称制度改革，不断完善分类评价机制，对长期在基层工作的专业技术人才，在评审过程中单独分组、单独设置通过率，提升基层人才成长内生动力。同时，鼓励基层气象部门加强与地方政府共建，积极服务地方经济社会发展，争取地方政府相关支持，取得了显著成效。

下一步，我局将进一步加强基层人才政策落实，完善基层人才帮扶协作机制，优化基层岗位管理，加强基层人员在岗培训，按照要求对艰苦边远地区基层台站人才招聘的学历和专业进行适当放宽，促进优秀人才向基层流动，同时积极探索基层人员待遇政策，为基层气象人员队伍建设做好保障。

二、关于加大财政投入力度问题

党的十八大以来，按照中央有关文件提出的“加强农业气象服务体系和农村气象灾害防御体系建设”(以下简称“两个体系”)、“发展智慧气象，提高气象灾害监测预报预警水平”等要求，中央财政积极支持气象服务“三农”工作。2013-2019年，中央财政通过中国气象局部门预算安排“三农”服务专项资金累计约21亿元，带动地方财政投入累计约12亿元，在全国2083个县实施“两个体系”建设。“三农”专项的实施，显著提升了基层气象为农服务能力。

（一）基层气象防灾减灾服务能力显著提升。“三农”专项实施县（以下简称实施县）建立了涵盖启动、实施、策略、留痕管理等环节的基层气象灾害预警服务规范；县政府出台实施了气象灾害应急专项预案，27884个乡镇制定了气象灾害专项预案，22.46万个村屯制定了气象灾害应急行动计划，5.75万个重点单位或村屯通过了气象灾害应急准备评估；建成标准化农村气象灾害防御乡（镇）1159个。开展了暴雨洪涝气象灾害风险普查，普查中小河流2298条、山洪沟5023条和泥石流、滑坡隐患点11530个；基层气象灾害突发预警信息发布系统覆盖气象灾害责任人超过25万人；自建和共建气象信息服务站19549个，发展气象信息员25.74万名，实现气象信息员村屯覆盖率100%，气象信息员培训率达63.9%；。

（二）基层农业气象服务不断强化。通过“三农”专项，实施县在“三区三园”建设农业气象示范田1914块、安装农田小气候观测仪1618套、农田实景观测仪1028套。其中，已有628个农田小气候观测站、207个实景观测仪的数据实时上传至农业气象大数据平台。面向近百万新型农业经营主体开展“直通式”服务，在“农业天气通”等智慧农业气象手机终端注册的新型农业经营主体达43万；累计制作关键农时气象服务专报、农用天气预报、农业气象灾害预警等产品22万余期，派出气象服务人员深入田间调查4万余次；制作完成县级精细化农业气候区划4627项、县级精细化农业气象灾害风险区划5524项，共建成标准化现代农业气象服务县143个。

（三）基层气象事业得到创新发展。在“三农”专项支持下，基层气象为农服务工作持续推进，各地开拓创新，涌现出“德清模式”“永川模式”等一批防灾减灾好做法，也涌现了安徽“众包模式”“江西微农”“重庆智慧农业气象服务”等新手段和气象助力精准扶贫“突泉模式”，并初步探索了气象为农服务社会化新模式。随着基层气象事业的快速发展，基层气象部门更加关注经济社会对气象的需求，更加注重发挥党委领导、政府主导的作用和部门合作机制建设，有效推动气象工作融合于政府工作大局。

（四）辽宁省“三农”专项建设进展。2011-2019年，中央财政“三农”服务专项累计投入7361万元，实现辽宁省51个有为农服务需求县的建设全覆盖，每县建设周期为2-3年，建设内容以基层气象防灾减灾标准化和直通式智慧化农业气象服务为主。共建成朝阳市喀喇沁左翼蒙古族自治县、鞍山市台安县、盘锦市大洼县、大连市庄河市、大连市瓦房店市、抚顺市清原满族自治县、朝阳县、建平县、普兰店区等9个标准化现代农业气象服务县，建成52个标准化气象灾害防御乡（镇）。

2018年，我局召开了全国气象为农服务工作会议，印发了《中共中国气象局党组关于贯彻落实乡村振兴战略的意见》，明确提出要建设与农业农村现代化发展、农村综合防灾减灾救灾、农村生态文明、精准扶贫相适应的现代气象为农服务体系，推进气象为农服务更高质量发展。同时，制定《智慧农业气象服务行动计划（2018-2020年）》和《农业气象大数据建设方案（2018-2020年）》，推进完善农业气象大数据平台、国省级农业气象业务支撑平台、农业气象服务平台、农业气象业务体系建设和现代农业气象业务核心技术应用能力的提升，并据此实现农业气象业务产品的定量化、客观化、精准化、多样化。下一步，我局将按照以上战略布局，进一步优化气象服务“三农”专项结构，努力争取各级财政继续支持气象服务“三农”工作，切实发挥气象监测预报预警在防灾减灾工作中“四两拨千斤”的作用，着力提高气象为农服务核心能力，更好地为乡村振兴战略服务。

三、关于推进政府购买服务问题

实行政府购买服务，将政府适宜通过市场化方式提供的服务事项交由符合条件的社会力量和事业单位承担，有利于转变政府职能、改善公共服务供给。我局将根据《国务院办公厅关于政府向社会力量购买服务的指导意见》（国办发〔2013〕96号）、财政部《政府购买服务管理办法（暂行）》（财综〔2014〕96号）等文件精神，结合正在推进的气象领域财政事权和支出责任划分工作，考虑将精细化气象监测、农村应急广播系统等公共服务设备的运行维护服务中属于政府职责范围、适合采取市场化方式提供的事项，纳入政府购买服务范围，引导社会力量参与提供。

感谢您对气象工作的支持！
