# 交通运输部办公厅关于公布第三届职业技能考评专家委员会成员名单的通知

交办人教〔2019〕61号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），有关交通运输企事业单位，部属各单位，部内各司局：

交通运输部职业技能考评专家委员会（以下简称考评委员会）是为交通运输行业技能人才培养、考核、评价提供指导、咨询和服务工作的专家组织，主要承担行业技师和高级技师综合评审、有关职业技能标准开发审定、全国交通技术能手评选等工作。第二届考评委员会任期届满，根据相关要求，在有关部门、单位推荐的基础上，经遴选、审核和公示等程序，经交通运输部同意，决定成立第三届考评委员会。第三届考评委员会由王韬等104名同志组成，设公路、水路、道路运输、机动车检测维修、城市轨道交通和邮政等6个专业组，任期至2021年12月31日，具体名单如下：
