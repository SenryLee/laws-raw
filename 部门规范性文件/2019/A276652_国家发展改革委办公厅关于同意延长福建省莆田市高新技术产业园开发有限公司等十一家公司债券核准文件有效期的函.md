# 国家发展改革委办公厅关于同意延长福建省莆田市高新技术产业园开发有限公司等十一家公司债券核准文件有效期的函

发改办财金〔2019〕459号

福建省、江西省、河南省、湖北省、湖南省、广西壮族自治区、重庆市、四川省、贵州省发展改革委：

报来《关于莆田市高新技术产业园开发有限公司延长企业债券核准文件有效期的请示》（闽发改股证〔2019〕198号）、《关于福鼎市城市建设投资有限公司延长企业债券核准文件有效期的请示》（闽发改股证〔2019〕222号）、《关于江西和济投资有限公司小微企业增信集合债券延期发行的请示》（赣发改财金〔2019〕255号）、《关于报送牧原食品股份有限公司申请延期发行绿色债券的请示》（豫发改财金〔2019〕209号）、《关于报送栾川县天业投资有限公司申请延期发行公司债券的请示》（豫发改财金〔2019〕210号）、《关于武汉地铁集团有限公司申请延长绿色债券核准文件有效期的请示》（鄂发改财贸〔2019〕97号）、《关于申请延长湖南省岳阳市君山区城市建设投资有限公司债券核准文件有效期的请示》（湘发改〔2019〕80号）、《关于宁明惠宁建设投资有限责任公司发行公司债券核准批复延期的请示》（桂发改财金报〔2019〕141号）、《关于转报重庆两江新区开发投资集团有限公司延长2018年双创孵化专项债券核准发行期限申请的请示》（渝发改财金〔2019〕366号）、《关于转报达州市国有资产经营管理有限公司延期发行企业债券申请的请示》（川发改〔2019〕103号）、《关于转报贵州金凤凰产业投资有限公司延长企业债券核准文件有效期的请示》（黔发改财金〔2019〕209号）收悉。经研究，现函复如下。

一、同意将《国家发展改革委关于福建省莆田市高新技术产业园开发有限公司发行公司债券核准的批复》（发改企业债券〔2018〕78号）文件有效期延长12个月至2020年5月9日。

同意将《国家发展改革委关于福建省福鼎市城市建设投资有限公司发行公司债券核准的批复》（发改企业债券〔2018〕64号）文件有效期延长12个月至2020年4月24日。

同意将《国家发展改革委关于江西和济投资有限公司发行小微企业增信集合债券核准的批复》（发改企业债券〔2018〕62号）文件有效期延长12个月至2020年4月24日。

同意将《国家发展改革委关于河南省牧原食品股份有限公司发行绿色债券核准的批复》（发改企业债券〔2018〕106号）文件有效期延长12个月至2020年5月22日。

同意将《国家发展改革委关于河南省栾川县天业投资有限公司发行公司债券核准的批复》（发改企业债券〔2018〕85号）文件有效期延长12个月至2020年5月11日。

同意将《国家发展改革委关于湖北省武汉地铁集团有限公司发行绿色债券核准的批复》（发改企业债券〔2018〕77号）文件有效期延长12个月至2020年5月8日。

同意将《国家发展改革委关于湖南省岳阳市君山区城市建设投资有限公司发行公司债券核准的批复》（发改企业债券〔2018〕69号）文件有效期延长12个月至2020年5月2日。

同意将《国家发展改革委关于广西壮族自治区宁明惠宁建设投资有限责任公司发行公司债券核准的批复》（发改企业债券〔2018〕92号）文件有效期延长12个月至2020年5月14日。

同意将《国家发展改革委关于重庆两江新区开发投资集团有限公司发行双创孵化专项债券核准的批复》（发改企业债券〔2018〕67号）文件有效期延长12个月至2020年5月2日。

同意将《国家发展改革委关于四川省达州市国有资产经营管理公司发行企业债券核准的批复》（发改企业债券〔2018〕94号）文件有效期延长12个月至2020年5月14日。

同意将《国家发展改革委关于贵州金凤凰产业投资有限公司发行公司债券核准的批复》（发改企业债券〔2018〕65号）文件有效期延长12个月至2020年4月24日。

二、请你委督促发行人按照《公司法》《证券法》《企业债券管理条例》和有关规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

三、请你委督促发行人按要求及时做好信息披露及债券资金管理，按照核准的募集资金投向合规使用债券资金，认真落实偿债保障措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委

2019年4月16日
