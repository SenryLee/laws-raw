# 国家煤矿安监局办公室关于转发《山西省煤矿班组安全建设规定》的通知

各产煤省、自治区、直辖市及新疆生产建设兵团煤矿安全监管部门、煤炭行业管理部门，各省级煤矿安全监察局，有关中央企业：

为进一步落实煤矿企业安全生产主体责任，强化煤矿班组建设工作，提高班组安全管理水平，现将山西煤矿安全监察局、 山西省应急管理厅、山西省总工会印发的《山西省煤矿班组安全建设规定》（晋煤监政法〔2019〕6号）转发给你们，供学习借鉴。

国家煤矿安监局办公室

2019年2月18日
