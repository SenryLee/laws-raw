# 文化和旅游部办公厅关于印发《2019年全国基层文化和旅游公共服务队伍培训工作计划》的通知

办公共发〔2019〕51号

各省、自治区、直辖市文化和旅游厅（局），新疆生产建设兵团文化体育新闻出版广电局（文物局）、商务局（旅游局），国家图书馆、中央文化和旅游管理干部学院、文化和旅游部全国公共文化发展中心：

为适应新形势下文化和旅游事业发展需要，切实提高基层文化和旅游公共服务队伍素质能力，进一步加强基层文化和旅游公共服务队伍培训工作，根据《文化和旅游部2019年干部培训计划》（文人发〔2019〕4号），结合文化和旅游部2019年重点工作，文化和旅游部制定了《2019年全国基层文化和旅游公共服务队伍培训工作计划》，现予印发，请认真贯彻执行。

各地文化和旅游行政部门和各培训实施单位要坚持政治导向，始终将政治理论学习摆在突出位置，将深入学习贯彻习近平新时代中国特色社会主义思想融入到培训全过程。一要统筹安排，精心组织。各地要根据本地实际，制定本地2019年基层文化和旅游公共服务队伍培训工作计划，各培训实施单位要对承接的培训任务认真组织实施，保证培训质量。案例分析、现场教学、学员论坛等实践类课程原则上应占所有课程安排的60%。授课讲师中一线优秀文化工作者原则上应占50%。“创新连线”班次在此基础上适当提高所占比率。二要改革创新，学用结合。紧密围绕文化和旅游领域中央重点改革任务和重要法律的贯彻落实，紧跟文化和旅游事业发展新形势，结合年度重点工作，积极探索新的培训理念、内容方式和运行机制，促进学习与思考、运用、创新相结合，注重培训成果转化，不断增强培训针对性和精准性。三要强化考评，注重宣传。各相关单位要重视培训过程和效果评估，及时跟踪统计培训开展情况和学员反馈，强化需求调研，为进一步提升培训工作绩效提供依据和支撑，以工作简报、媒体新闻等形式展示培训特色和成果，积极营造浓厚的宣传氛围。四要遵规守纪，从严管理。相关培训经费管理严格按照《中央和国家机关培训费管理办法》执行，严格贯彻落实中央八项规定精神，严格执行中组部《关于在干部教育培训中进一步加强学员管理的规定》，严肃培训纪律，培育良好班风学风教风。

## 2019年全国基层文化和旅游公共服务队伍培训工作计划

为深入学习贯彻落实习近平新时代中国特色社会主义思想和党的十九大及十九届二中、三中全会精神，适应文化和旅游融合发展新形势，切实加强基层文化和旅游公共服务队伍建设，2019年全国基层文化和旅游公共服务队伍培训工作将着力转变思路、改革创新，以提高政治能力为根本，以增强专业本领为关键，聚焦发展前沿，坚持分级分类、精准培训、学用结合、从严管理，进一步提高培训的针对性和有效性。本年度全国基层文化和旅游公共服务队伍培训总体上分为三大类：示范性培训、巡讲和远程培训。重点培训内容为文化和旅游公共服务领域重点改革任务和重要法律的学习贯彻落实、文化和旅游融合发展等，重点培训对象为基层文化和旅游公共服务管理干部、业务骨干和各类群众文化专业技术人才。具体计划安排如下：

一、示范性培训

2019年示范性培训在总结研究往年培训情况的基础上，进一步优化分类、突出主题、创新模式，针对不同对象的岗位特点、现实需求和面对的突出问题，精细化、有针对性地设置政策理论、实务研习、案例交流等授课形式，充分发挥示范作用。

（一）主题分类。本年度示范性培训分为5个主题类目：改革前沿、创新连线、群星璀璨、区域发展和基础建设。

——改革前沿。主要面向文化和旅游公共服务一线管理人员，聚焦公共文化服务重点改革任务、新时代文明实践中心建设、文化和旅游融合发展、公共文化服务社会化、数字文化建设等重点工作，通过研习推进中央精神的贯彻落实，培养改革思维，开拓宏观视野，把握大局方向，提升管理干部的决策力、领导力。

——创新连线。重点开展各地文化和旅游公共服务创新案例的交流研习，让一线干部当专家、做讲师，分享在制度设计、运行机制、服务模式等方面的创新做法和先进经验，充分调动学员边学边讲、互学互鉴，通过思维碰撞、实例研习和实务培训，提升基层干部的创新力、执行力和行动力。

——群星璀璨。重点开展群众文艺创作培训，结合群众文艺特点，围绕不同门类，开设美术、曲艺、戏剧、广场舞的专题类培训和综合类培训，通过优秀获奖作品创作体会分享、学员带作品入班进修等形式，强化创作交流，提高作品质量，为繁荣基层群众文化创作提供智力支持。

——区域发展。聚焦各地特别是中西部地区和少数民族地区的文化和旅游公共服务工作，紧密围绕区域发展实践重点工作任务和实际情况，按需设课，将解决区域发展重点问题、推动区域因地制宜改革发展作为培训主要目标。

——基础建设。主要面向基层文化和旅游公共服务培训基地负责人、各省（区、市）（包括新疆生产建设兵团，下同）培训工作联络人员等相关工作人员，重点研习研究基地建设、各省（区、市）培训工作的整体协调等内容，开展师资培训，加强师资队伍建设与管理，储备培养一批优秀师资队伍和工作队伍。

（二）整体安排。示范性培训班在中央文化和旅游管理干部学院和全国基层文化队伍培训基地举办。根据文化和旅游公共服务工作重点和各地申报情况，2019年共计划举办49期示范性培训班，其中改革前沿、创新连线、群星璀璨主题各11期、区域发展主题13期、基础建设主题3期（见附件1）。区域发展主题研习班根据各地的申报情况和各培训实施单位的承担情况统筹兼顾、均衡安排，对中西部地区予以适当倾斜，重点扶持符合精准扶贫、乡村振兴等国家重大战略要求的班次，以及培训主题具有创新性实用性、符合文化和旅游公共服务发展方向的班次等，原则上每省（区、市）支持不超过1个班次。整体班次安排可根据实际工作情况微调，视情追加少量班次。

（三）培训组织。各省（区、市）文化和旅游厅（局）和各培训实施单位按照《全国基层文化队伍示范性培训工作规范》（公共函〔2016〕65号）要求统筹组织好培训工作，按照本计划做好示范性培训学员选派及相关组织工作。

（四）经费安排。示范性培训班的经费补贴方式分为全额补助和定向补贴，改革前沿、创新连线、群星璀璨和基础建设主题中的全部培训班次以及区域发展主题中的1期班次为全额补助班，共计37期；区域发展主题中其余12期班次为定向拨款班。全额拨款班由文化和旅游部承担培训费用（公共数字文化重点工程培训班相应经费由国家图书馆和文化和旅游部全国公共文化发展中心分别承担），学员差旅费自行解决。定向补贴班采取合作办班方式由申报单位承担主要培训费用，文化和旅游部给予每班5万元经费补贴。

二、巡讲

巡讲活动按照供需对接原则，采取“菜单式”选课模式，各地根据巡讲课程目录按需申报。根据各地申报和对接情况，经过研究梳理，确定了2019年全国基层文化和旅游公共服务巡讲安排。具体事项如下：

（一）整体安排。2019年全国文化和旅游公共服务巡讲活动计划举办20期（见附件2），重点围绕现代公共文化服务体系建设理念与实践、公共文化服务政策法规与基层实践、国家公共文化服务体系示范项目创建、新时代文化和旅游融合发展、馆站建设等主题，计划巡讲地点覆盖17省（区、市）。

（二）工作分工。文化和旅游部公共服务司负责统筹指导和监督管理；中央文化和旅游管理干部学院负责组织实施送课巡讲活动，协调师资和安排巡讲场次。

（三）经费安排。送课巡讲活动由各地申报单位承担主要经费，文化和旅游部对巡讲予以适当补贴，主要用于补贴巡讲师资讲课费和差旅费、工作人员差旅费等。

三、远程培训

2019年全国基层文化和旅游公共服务队伍远程培训工作由中央文化和旅游管理干部学院组织实施。具体事项如下：

（一）整体安排。2019年共安排远程培训6期（见附件3），每期两门课程，各2小时。

（二）培训组织。各省（区、市）文化和旅游厅（局）应指定专人负责做好远程培训工作，充分挖掘本地区基层文化队伍培训力量和资源，发动各级图书馆、文化馆（站）、文化信息资源共享工程各级分中心、各培训机构参与全国基层文化和旅游公共服务队伍远程培训，做好本地区远程培训的动员和组织工作，确保培训效果，并做好远程培训情况统计和报送工作。

（三）教学接收点设置。远程教学接收点可根据使用需求进一步增加和下沉，符合播出条件的基层公共文化单位均可向中央文化和旅游管理干部学院提出申请，鼓励和支持各级图书馆、文化馆和有条件的乡镇文化站申报教学接收点。
