# 国家卫生健康委人口家庭司关于免费提供促进3岁以下婴幼儿照护服务发展主题海报电子版的通知

## 关于免费提供促进3岁以下婴幼儿照护服务发展主题海报电子版的通知

为深入学习宣传贯彻《国务院办公厅关于促进3岁以下婴幼儿照护服务发展的指导意见》精神，我们制作了婴幼儿照护服务主题系列海报（共4张），请你们从我委网站直接下载，自行印刷，用于开展婴幼儿照护服务及相关宣传活动。

附件：婴幼儿照护服务主题系列海报4张：婴幼儿照护海报1

婴幼儿照护海报2

婴幼儿照护海报3

婴幼儿照护海报4

国家卫生健康委人口家庭司

2019年6月13日
