# 教育部办公厅关于组织2019年高校思想政治理论课骨干教师研修的通知

教社科厅函〔2019〕5号

各省、自治区、直辖市党委教育工作部门、教育厅（教委），新疆生产建设兵团教育局，中央军委政治工作部宣传局：

为深入学习贯彻习近平新时代中国特色社会主义思想，全面贯彻党的十九大和十九届二中、三中全会精神，深入落实全国教育大会精神、全国宣传思想工作会议和全国高校思想政治工作会议，继续打好提高高校思想政治理论课（以下简称思政课）质量和水平攻坚战，努力建设一支政治素质过硬、业务能力精湛、育人水平高超的高素质专业化思政课教师队伍，全面推动习近平新时代中国特色社会主义思想进教材进课堂进学生头脑，2019年中央宣传部、教育部决定继续安排高校思政课骨干教师研修。现将有关事宜通知如下。

一、研修班期次安排

第1、2期（总第97、98期）：2019年3月3日至3月23日，对象为本科“马克思主义基本原理概论”“思想道德修养与法律基础”两门课的骨干教师。各举办1期，每期培训100人，培训规模为200人。

第3、4期（总第99、100期）：2019年5月26日至6月15日，对象为研究生思政课骨干教师和高职高专思政课教学机构负责人。各举办1期，每期培训100人，培训规模为200人。

第5期（总第101期）：2019年6月22日至7月12日，对象为全国高校新入职思政课教师。举办1期，培训规模为100人。

第6、7期（总第102、103期）：2019年6月23日至7月13日，对象为西部12省（区、市）高校思政课骨干教师。各举办1期，每期培训100人，培训规模为200人。

第8期（总第104期）：2019年7月15日至8月4日，对象为全国高校新入职思政课教师。举办1期，培训规模为100人。

第9、10期（总第105、106期）：2019年10月13日至11月2日，对象为高职高专“毛泽东思想和中国特色社会主义理论体系概论”“思想道德修养与法律基础”两门课的骨干教师。各举办1期，每期培训100人，培训规模为200人。

第11、12期（总第107、108期）：2019年11月10日至11月30日，对象为本科“毛泽东思想和中国特色社会主义理论体系概论”“中国近现代史纲要”两门课的骨干教师。各举办1期，每期培训100人，培训规模为200人。

二、选送学员要求

（一）学员不超过55周岁（1964年1月1日以后出生），思想政治素质好，热爱思政课教学工作，业务能力较强，育人水平较高，工作业绩较好，身体健康，能够完成研修培训任务。同一所高校全年最多选派2名学员。

（二）普通高校选派学员必须是2018年在“高校思想政治理论课教师信息库”更新过个人信息的高校思政课专兼职教师。

（三）自2015年以来，参加过中央宣传部、教育部举办的“高校思政课骨干教师研修班”第49—96期任一班次培训的学员，2019年不再参训。

（四）各地教育工作部门要对属地的普通高校参加中央宣传部、教育部举办的思政课骨干教师研修情况进行全面摸排，梳理掌握未参训普通高校名单，根据2019年研修班次、研修内容和分配名额，统筹考虑属地的中央部委属高校和地方高校思政课教师培训需求，培训名额向新建本科院校、民办高校、中外合作办学高校、高职高专院校倾斜，民办高校较多的地方须将全年培训名额的20%安排给民办高校，不断扩大优质培训资源覆盖面，确保5年内全国普通高校均有教师参训。

（五）学员研修期间，不承担所在单位安排的教学科研、会议、出国访问、考察及其他工作任务。

（六）学员须按本通知规定的时间准时报到，原则上不得请假。因特殊原因确需请假的，须至少在开班前5个工作日，由学员所在单位出具请假单，经省级教育工作部门审核同意后，报教育部社科司备案，记入本人培训档案。无故或请假未获批准擅自不参加培训的学员，今后3年不得选派参加中央宣传部、教育部举办的各类思政课教师培训。2019年各研修班次全程采用电子考勤，学员出勤情况将向相关部门反馈，并与下年度培训名额分配挂钩。

（七）学员研修期间就医应交纳现金，医疗费用凭收据回所在单位报销。

（八）学员学习期间，食宿费用由中央财政统一支付。学员所在单位按相关规定承担往返交通等费用。

三、学员报名流程

（一）除军队院校学员外，2019年高校思政课骨干教师研修采用网络报名。

（二）各省级教育工作部门在2019年2月26日前，凭单位账号、密码登录报名平台http://sks.bjcipt.com，统一录入本地选派学员的姓名、手机号码等信息。报名平台对学员基本信息进行审核后，对具备报名资格的学员，将短信通知学员在2月28日前凭个人账号、密码登录报名平台填报个人信息。学员个人信息填报完整后，平台将生成学员登记表，请学员自行打印登记表，交单位盖章。

（三）未通过平台审核、无法报名的学员所空出的名额，由省级教育工作部门按上述流程补报。

（四）中央军委政治工作部宣传局统一组织军队院校学员报名，2019年2月26日前将名单报教育部社科司。

四、研修要求

（一）普通高校选派学员须于研修结束后40个工作日内，通过报名平台提交学习成果。学习成果要紧扣研修主题和内容，根据中央马克思主义理论研究和建设工程高校思政课2018年版教材，任选一个教学重点、难点问题，紧密结合学生关注热点，撰写一篇不少于6000字的思政课教学重难点问题解析。学习成果择优推荐高校马克思主义理论类期刊发表并在“全国高校思政课教师网络集体备课平台”发布。

（二）各实践研修基地须于研修结束后20个工作日内，通过报名平台向教育部社科司提交研修班工作报告。工作报告要紧扣研修主题和内容，突出理论联系实际的学风，通过学员的视角、学员的话语、学员的行动，以生动鲜活的文字总结本组学员参与研修的收获，集中凝练学员对进一步办好高校思政课特别是进一步办好思政课骨干教师研修的意见建议等。

（三）研修期间要严格执行研修计划，严格落实中央八项规定精神。
