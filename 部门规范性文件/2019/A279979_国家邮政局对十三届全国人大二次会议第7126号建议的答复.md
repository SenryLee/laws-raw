# 国家邮政局对十三届全国人大二次会议第7126号建议的答复

## 对十三届全国人大二次会议第7126号建议的答复

国邮函〔2019〕68号

柴闪闪代表：

您提出的“关于快递外卖行业中农民工更好融入城市的建议”（第7126号）收悉。经商人力资源社会保障部，现答复如下：

随着我国快递业的蓬勃发展，快递从业人员总体规模不断扩大，以快递员为主体的一线操作人员已成为支撑快递业发展的基石和保证。但快递从业人员就业质量仍然不高，存在工作负荷重、权益保障难、职业发展难等突出问题，受到广泛关注。

一、关于强化劳动权益保障

近年来，各级人力资源社会保障行政部门认真履行劳动保障监察职能职责，加强对违法行为的事前预防和执法检查，切实维护劳动者合法权益和社会稳定。2018年，全国各级劳动保障监察机枃共査处各类劳动保障违法案件13.9万件，主动检査用人单位138.1万户次，督促用人单位与106.3万名劳动者补签劳动合同，为168.9万名劳动者追发工资等待遇160.4亿元，督促0.9万户用人单位办理社保登记，督促缴纳社会保险费9.3亿元。贯彻国务院决策部署，大规模开展就业技能培训、岗位技能提升培训和创业培训，大力开展农民工职业技能提升等计划。

国家邮政局深入学习贯彻习近平总书记联系服务“快递小哥”的重要指示精神，扎实推进从业人员权益保障各项工作。一是与共青团中央成立邮政行业团指委，构建“1+3+N”合作框架，联合开展“快递业从业青年权益维护服务月”等活动。二是出台《关于加强和改进快递末端服务管理工作的指导意见》，连续三年将快递从业人员职业保障工作纳入“邮政业更贴近民生七件实事”，指导各地邮政管理部门加强从业人员权益保护和从业青年联系服务工作，改善工作环境。三是支持国防邮电工会和地方工会推动非公快递企业组建工会，吸引快递员入会，稳妥推进“会站家”一体化试点建设，努力改善快递员工作环境。四是推广北京、吉林、河北、上海等省（直辖市）针对快递员开展的提供租赁房、集体协商、依法参保、爱心驿站、健康体检、互助基金、春运专列等先进做法。五是推动寄递企业规范内部管理，转变“重业务轻管理、重业绩轻权益、重发展轻培训、重考核轻保障”做法，督促企业总部改善对于基层网点的运行管护，着力解决多重罚款等问题，有效遏制“以罚代管”。六是对企业贯彻落实《快递暂行条例》第十三条、第二十条，依法保护其从业人员合法权益情况开展检查，特别是对从业人员相关教育和培训情况，主要包括职业操守、服务规范、作业规范、安全生产、车辆安全驾驶、道路交通安全等方面的教育培训。七是强化企业主体责任，改善从业环境，推动规范劳动用工管理，推进工资集体协商，切实保障从业人员休息休假、社会保险等基本权益，严禁超负荷劳动。八是鼓励和引导经营快递业务的企业建立一线岗位从业人员强制休息、健康体检等制度，提高从业人员职业病防治能力。

下一步，人力资源社会保障部将开展以下工作：一是鼓励更多有条件的地区开展行业集体协商、定期发布快递员等不同职业从业人员工资报酬信息，加强指导和指引。二是抓紧研究起草关于新业态企业劳动用工的文件，兜住包括快递、外卖员在内的新业态劳动者劳动权益保障底线。三是进一步研究针对快递员等新业态从业人员参保问题的政策建议，启动新业态从业人员职业伤害保障试点工作。四是进一步强化地方政府工作职责，健全工作机制，推进职业技能培训与评价有机衔接，推进扩大培训规模，提升培训质量和层次。五是不断强化劳动保障监察的职能作用，进一步加大对劳动保障违法行为的查处力度，切实维护包括快递、外卖行业劳动者的合法权益。

国家邮政局将继续加强快递员权益保护，推进快递员关爱工程，遏制企业内部“以罚代管”行为，引导企业强化人文关怀，让一线快递员共享企业发展成果；对查处的劳动保障违法问题严重的快递企业，将实施联合惩戒管理。继续推动全国总工会探索建立行业工会组织，联合共青团中央共同开展12355维权热线服务等工作。

二、关于规范经营主体责任

贯彻落实《快递暂行条例》《快递市场管理办法》规定，依法规范经营主体责任。对以加盟方式经营快递业务的，要求被加盟人与加盟人均应当取得快递业务经营许可，加盟不得超越被加盟人的经营许可范围。被加盟人与加盟人应当签订书面协议约定双方的权利义务，明确用户合法权益发生损害后的赔偿责任；两个以上经营快递业务的企业用统一的商标、字号或者快递运单经营快递业务的，要求其签订书面协议明确各自的权利义务，遵守共同的服务约定，在服务质量、安全保障、业务流程等方面实行统一管理，为用户提供统一的快件跟踪查询和投诉处理服务；取得快递业务经营许可的企业不得以任何方式将快递业务委托给未取得快递业务经营许可的企业经营，不得以任何方式超越经营许可范围委托经营。推动企业落实《快递暂行条例》第十三条，快递从业人员因执行工作任务造成他人损害的，由快递从业人员所属的经营快递业务的企业依照民事侵权责任相关法律的规定承担侵权责任。

三、关于加强对快递外卖行业的管理

贯彻落实《国务院关于促进快递业发展的若干意见》精神，多措并举保障快递末端服务车辆依法通行。出台《国家邮政局关于规范快递末端服务车辆管理和使用工作的指导意见》，依法保障了末端快递服务车辆通行权利。截止2019年5月，全国已有221个市（地）出台了快递末端服务车辆通行管理政策。目前，大部分已出台车辆通行政策的城市均对当地快递末端服务车辆进行了规范化统一管理，通过对车辆实施“统一编号”、“统一标识”、“统一保险”，破解末端投递车辆“安全”和“通行”两大难题。督促指导快递企业做好快递末端服务车辆依法依规、文明出行，协助开展非法拼改装车辆、逆向行驶、闯红灯、骑行斑马线、乱停乱放等违法违规行为整治。

四、关于加大宣传力度，突出典型引领

国家邮政局与共青团中央成立邮政行业团指委，构建“1+3+N”合作框架，联合开展“快递业从业青年权益维护服务月”，接受咨询服务1.6万人次，组织关爱慰问3255场次，覆盖快递从业青年27万余人，受到广大快递员欢迎；组织开展快递从业青年与人大代表、政协委员“面对面”等活动，其中北京主场“面对面”活动，吸引200多万网民参与直播互动，社会反响良好。组织开展关爱快递员系列工程，持续推进寻找“最美快递员”“关爱快递员周”等活动。发挥行业媒体资源优势，大力宣传其美多吉、最美快递员等行业先进典型，在行业内外掀起了寻找“最美”，发现“最美”，学习“最美”的热潮，积极营造关心、关注基层快递员的良好社会氛围。

下一步， 国家邮政局将积极争取国家和地方表彰奖励政策，做好邮政行业表彰奖励工作，把成绩卓著、贡献突出、事迹感人的先进集体、劳动模范推荐出来，让大家学有榜样，追有标杆。继续开展“寻找最美快递员”活动，大力挖掘宣传“小蜜蜂”精神的实践典型。持续优化从业人员工作环境，拓展从业人员职业发展空间，推动各级人大、政协选举、推荐基层快递从业人员担任代表、委员，提高快递从业人员的职业荣誉感和社会认可度。继续推动全国总工会探索建立行业工会组织，选树五一劳动奖章等行业典型；联合共青团中央共同开展青年文明号创建、青年安全生产示范岗创建、12355维权热线服务等工作。加大媒体宣传力度，深入宣传典型事迹，增强社会公众对行业和快递员的理解认同，弘扬行业正能量。

感谢您对快递业发展的关心和支持！
