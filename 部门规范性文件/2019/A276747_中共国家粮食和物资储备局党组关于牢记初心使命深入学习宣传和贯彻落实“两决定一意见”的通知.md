# 中共国家粮食和物资储备局党组关于牢记初心使命深入学习宣传和贯彻落实“两决定一意见”的通知

国粮党字〔2019〕29号

各省、自治区、直辖市及新疆生产建设兵团粮食和物资储备局（粮食局），国家粮食和物资储备局各司局、直属单位、联系单位，各垂直管理局：

习近平总书记在党的十九大报告中，明确提出在全党开展“不忘初心、牢记使命”主题教育。2019年是全国粮食和物资储备系统“加快推进深化改革转型发展年”，推动粮食和物资储备改革发展的使命光荣、任务艰巨。为进一步凝聚共识行动，引导激励全系统广大干部职工敢于担当、善谋实干、锐意进取，国家局党组研究确定，将深入学习宣传和贯彻落实“两决定一意见”作为全国粮食和物资储备系统认真践行“不忘初心、牢记使命”的自选动作和实践载体，聚焦主题，纵深推进，务求取得实效。现就有关事项通知如下。

一、总体要求

（一）明确目的意义。立足新时代新职能新形势，国家局党组坚持以习近平新时代中国特色社会主义思想为指导，围绕贯彻落实党的十九大和十九届二中、三中全会精神，研究出台“两决定一意见”。以“深化改革转型发展的决定”明确方向、理清路径，以“加强安全稳定廉政的决定”压实责任、划定底线，以“激励干部新时代新担当新作为的意见”树立导向、提供保障，在全系统形成了高度共识和良好反响，激发了热情干劲，推动了改革发展。将学习宣传和贯彻落实“两决定一意见”引向深入，是学懂弄通做实习近平新时代中国特色社会主义思想，认真落实党中央、国务院决策部署的重要举措；是增强“四个意识”、坚定“四个自信”、做到“两个维护”的重要体现；是贯彻落实总体国家安全观，坚持底线思维，维护国家粮食安全和战略应急物资储备安全的重要方式。

（二）担当使命责任。认真践行“不忘初心、牢记使命”，深入学习宣传和贯彻落实“两决定一意见”，就是要聚焦国家储备安全核心职能，着力增强防范化解重大风险能力；加快推进深化改革、转型发展，坚守安全稳定廉政“三条底线”，着力构建更高质量的粮食安全保障体系和统一的国家物资储备体系；永葆斗争精神，增强斗争本领，着力造就一支忠诚干净担当的高素质干部队伍，以实际行动履行新时代粮食和物资储备的职责使命，保障国家粮食和物资储备安全。

（三）把握实践要求。坚持正确导向、一以贯之，把国家局党组关于“讲政治、顾大局，抓重点、出亮点，争主动、真落实，高标准、严要求，多添彩、不添乱”总体要求贯穿始终，体现到全过程各方面。坚持正面激励、创新创优，巩固放大“深化改革、转型发展”大讨论成果，搭建载体平台、培树先进典型、选好用好优秀干部，提振精气神，凝聚正能量。坚持求真务实、真抓实干，与打好全国政策性粮食库存数量和质量大清查、重要战略物资收储轮换“硬仗”，与粮食储备管理体制机制改革、垂管局机构及事业单位改革，与推动立法修规、开展“两项考核”、实施“优质粮食工程”、建设粮食产业强国等紧密结合，谋实事、出实招、求实效，全力推动粮食和物资储备改革发展。

二、加强学习，深入宣传

（四）深化学习研讨。充分发挥党组理论学习中心组学习的示范带动作用，有效运用“三会一课”、主题党日等载体，创新方式方法，深入学习领会习近平总书记关于粮食安全和战略应急物资储备安全的重要论述，持续开展“两决定一意见”学习研讨，引导全系统广大干部职工在学思践悟中牢记初心使命，做到知行合一、学以致用。

（五）举办知识竞赛。国家局组织开展学习“两决定一意见”知识竞赛，以赛促学、以学促用，引导全系统广大干部职工提高政治理论素养，熟悉相关法律法规和政策文件，掌握业务知识和专业技能。各地各单位要认真组织参加竞赛，掀起学习热潮。

（六）开展演讲比赛。在全系统举办“牢记初心使命、推动改革发展”主题演讲比赛，引导广大干部职工将深入学习贯彻“两决定一意见”与立足本职岗位建功立业紧密结合，鼓励开拓创新，为发展建言、为改革献策；激励担当作为，分享实干经验、展现实绩亮点。

（七）广泛宣传报道。组织开展“牢记初心使命、推动改革发展”系列报道，运用文字、图片、音频、视频等多种形式，深入解读“两决定一意见”精神；通过中央媒体和地方媒体，统筹报刊杂志、政府网站、微博微信等媒体平台，加强国家局和各地各单位的协同联动，对各地贯彻落实“两决定一意见”情况开展全方位、多形式的宣传报道。

三、培树典型，示范引领

（八）挖掘培树典型。各地各单位围绕深化改革转型发展、加强安全稳定廉政、担当作为干事创业等方面，多角度发现工作亮点、成功经验，向国家局推荐肯实干、有实绩的典型。国家局组织筛选、调研复核、好中选优，挖掘总结一批可借鉴、可复制、可推广的先进经验做法，培养选树一批示范效应明显、带动作用显著的典型单位和个人。

（九）组织宣讲报告。组成学习贯彻“两决定一意见”先进典型宣讲团，在国家局进行汇报宣讲，分赴地方粮食和物资储备局（粮食局）、垂直管理局和基层单位深入宣讲，谈体会认识、讲经验做法、展精神风貌。编制典型事例和经验材料，制作宣讲视频光盘，扩大宣讲的覆盖面和影响力。

（十）开展比学赶超。引导全系统广大干部职工进行“四比四看”，即：比学习、看政治素养，切实增强对党忠诚、为党分忧、为党尽职、为民造福的思想自觉和行动自觉；比担当、看进取精神，确保把“两决定一意见”部署要求不折不扣落到实处；比贡献、看工作实绩，在攻坚克难、开拓创新中出成效出亮点出特色；比操守、看廉洁自律，坚守安全稳定廉政“三条底线”。

四、强化激励，担当作为

（十一）倡导正向激励。国家局研究制定表彰奖励管理办法，健全常态化激励机制。将贯彻落实“两决定一意见”情况作为重要评选内容，与人力资源社会保障部联合开展全国粮食和物资储备系统先进集体、先进工作者和劳动模范评选，认真组织评选“干事创业好团队”和“担当作为好干部”，在2020年全国粮食和物资储备工作会议上予以表彰。

（十二）选拔担当作为好干部。坚持新时期好干部标准，坚持事业为上，树立重实干重实绩的鲜明导向。大力选拔使用一批在贯彻落实“两决定一意见”中勇于担当、善于作为，在政策性粮食库存大清查、战略物资收储轮换等急难险重任务中挺身而出、攻坚克难，在平凡岗位上勤于实践、锐意创新的干部，让想干事的有机会、能干事的有舞台、干成事的有地位。

（十三）培养优秀年轻干部。国家局研究制定适应新时代要求大力培养选拔优秀年轻干部的实施意见，建立持续发现、分批调研、动态管理的长效机制。抓好年轻干部“选育管用”，拓宽选人视野渠道、增强培养锻炼实效，建设一支适应改革发展要求、忠诚干净担当、充满活力的高素质专业化年轻干部队伍。同时，坚持老中青结合，用好各年龄段干部。

（十四）搭建干事创业平台。坚持有为才有位，人岗相适、以事择人，紧紧围绕充分履行职能、推动改革发展需要，统筹用好全系统干部资源。国家局研究制定引进优秀人才和干部交流管理等办法，打破单位、地域界限，加强系统内外、机关和事业单位之间干部交流，充分释放干事创业活力。

（十五）积极营造良好环境。建立完善容错纠错机制，旗帜鲜明为敢于担当、勇于创新的干部加油鼓劲、撑腰壮胆；对在急难险重任务和探索创新中出现失误的，区分主观故意犯错和客观无意过失，不求全责备。建立澄清保护机制，及时为受到诬告的干部澄清正名、消除顾虑，保护干部担当作为、干事创业的积极性。

五、精心组织，确保实效

（十六）加强组织领导。各地各单位要把深入学习宣传和贯彻落实“两决定一意见”作为引领推动工作的有力抓手，认真研究、精心部署，主要领导同志要亲自抓，明确分管负责同志和具体工作人员，广泛深入动员，鼓励全员参与。国家局办公室、机关党委要及时调度情况，加强指导。对行动快、措施实、效果好的，给予通报表扬；对进展慢的，及时敦促提醒；对工作落实不力、严重滞后的，予以通报批评。

（十七）注重统筹协调。妥善处理好学习宣传和贯彻落实“两决定一意见”与政策性粮食库存大清查、战略物资收储轮换等重点任务的关系，在时间、人员和经费等方面统筹兼顾、合理安排，做到有机结合，实现“两不误、两促进”。

（十八）强化协同联动。各地各单位在贯彻落实“两决定一意见”中采取的创新举措、总结的典型经验、提出的措施建议，要及时报告国家局。国家局相关司局单位要畅通渠道、掌握动态，及时研判新情况和新问题，用好调研、座谈和信息、简报、通讯等方式，沟通情况、上下联动，凝聚共识行动。

（十九）务求好事办好。坚持高标准严要求，开展系列活动要围绕主题、做实内容，创新举措要符合实际、行之有效，新闻宣传要实事求是，先进典型要经得起检验。坚决反对“四风”，力戒形式主义、官僚主义，不搞花架子，不做表面文章。从严掌握要求基层报送材料、配合调研等事项，避免增加基层负担。

中国共产党国家粮食和物资储备局党组

2019年4月25日
