# 国家煤矿安全监察局关于将山西岚县昌恒焦煤有限公司等2处煤矿一级安全生产标准化等级降为三级的通知

## 关于将山西岚县昌恒焦煤有限公司等2处煤矿一级安全生产标准化等级降为三级的通知

2019年1月17日，山西岚县昌恒焦煤有限公司发生生产安全事故，造成2人死亡；2019年1月18日，山东滕州郭庄矿业有限公司锦丘煤矿发生生产安全事故，造成1人死亡。按照《煤矿安全生产标准化考核定级办法（试行）》（煤安监行管﹝2017﹞5号）有关规定，国家煤矿安监局决定，将山西岚县昌恒焦煤有限公司一级安全生产标准化等级自2019年1月17日起降为三级；将山东滕州郭庄矿业有限公司锦丘煤矿一级安全生产标准化等级自2019年1月18日起降为三级。

2019年1月29日
