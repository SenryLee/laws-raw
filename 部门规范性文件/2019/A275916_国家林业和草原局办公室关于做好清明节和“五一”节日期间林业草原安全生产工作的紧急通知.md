# 国家林业和草原局办公室关于做好清明节和“五一”节日期间林业草原安全生产工作的紧急通知

办安字〔2019〕75号

各省、自治区、直辖市林业和草原主管部门，内蒙古、大兴安岭森工（林业）集团公司，新疆生产建设兵团林业和草原主管部门，国家林业和草原局各司局、各派出机构、各直属单位：

清明节和“五一”劳动节期间，群众集中出行频繁，多数地区进入生产旺季，安全生产任务繁重。为认真贯彻落实党中央、国务院关于加强安全生产工作的各项决策部署，切实做好林业草原安全生产工作，有效防范林业草原行业发生重特大生产安全事故，现将有关要求通知如下：

一、增强安全意识，严格落实责任

各地区各有关单位要认真贯彻党中央、国务院关于加强安全生产工作的一系列重要指示批示精神，充分认识当前安全生产形势的严峻性和做好林业草原安全生产工作的重要性，按照“党政同责、一岗双责、失职追责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，切实增强安全生产“红线”意识、底线思维和责任担当，进一步加强组织领导。要结合节日特点和林业草原生产经营工作特点，有针对性地制定工作方案，细化相关工作措施，确保防范措施到人到岗，严防发生各类重特大生产安全事故。

二、加强安全检查，切实消除安全隐患

各地区各有关单位要牢固树立“隐患就是事故”的理念，针对林业草原行业安全生产特点，提前组织开展安全生产检查，不断加强隐患排查和治理。营林造林、国有林区、国有林场、国家公园、自然保护区、森林公园、沙漠公园、湿地公园等业务主管司局要按照“谁主管、谁负责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，切实履行好行业安全生产工作指导职责。要重点关注林区交通、森林旅游和人员密集场所的安全问题，着力防范拥挤踩踏等群死群伤事故发生。要关注危险化学品和易燃易爆物品的安全问题，强化对林区矿山、油气管道、科研院所实验室等重点领域和重点部位的管理，确保不留死角和风险隐患。要针对森林防火特点，进一步加强宣传教育、防火巡护、火源管理、督导检查等工作，及时排查消除各类火灾隐患。各森工（林业）集团公司要进一步落实好企业安全生产主体责任，自觉接受属地监管。

三、强化应急管理，妥善处置突发情况

各地区各有关单位要及时完善安全生产应急预案，强化应急演练和人财物保障。要指导和督促林业草原生产经营单位加强应急准备，强化对一线职工化解险情和自救互救的教育培训。要加强应急值守，落实领导干部带班、关键岗位24小时值班和事故信息报告制度。一旦发生事故险情，要及时报告并启动预案，妥善应对处置，将林业草原生产安全事故造成的损失和影响降到最低。对玩忽职守、疏于管理、责任不落实、人员不到位而造成重大伤亡事故的，要依法依规严肃追究有关负责人的责任。

各地区各单位要紧密结合自身工作实际，进一步安排部署清明节和“五一”节日期间林业草原安全生产工作并抓好贯彻落实。

特此通知。
