# 国家烟草专卖局关于印发《烟草行业扶贫工作先进集体和先进个人评选办法》的通知

国烟计〔2019〕97号

行业各直属单位，国家局、总公司机关各部门、各单位：

为了表彰先进、鼓舞士气、凝聚烟草行业合力做好扶贫工作，国家局将在今年开展全行业扶贫工作先进集体和先进个人评选活动。现将《烟草行业扶贫工作先进集体和先进个人评选办法》印发给你们，请认真执行。

附件：《烟草行业扶贫工作先进集体和先进个人评选办法》

国家烟草专卖局

2019年4月16日
