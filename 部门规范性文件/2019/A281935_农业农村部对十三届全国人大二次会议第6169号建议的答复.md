# 农业农村部对十三届全国人大二次会议第6169号建议的答复

## 对十三届全国人大二次会议第6169号建议的答复

农办议〔2019〕360号

王学斌等14名代表：

你们提出的关于鼓励和支持农村大学生返乡创业的建议收悉。经商人力资源社会保障部、教育部、工业和信息化部、财政部、发展改革委和自然资源部，现答复如下。

一、关于建立和完善高校创新创业教育

党中央、国务院高度重视大学生就业创业工作。2015年，国务院办公厅印发《关于发展众创空间推进大众创新创业的指导意见》（国办发〔2015〕9号），教育部门认真贯彻党中央部署，鼓励和支持农村大学生返乡创业。一是落实大学生创业优惠政策。教育部印发了《关于贯彻落实中央文件精神进一步引导和鼓励高校毕业生到基层工作的通知》（教学〔2017〕3号）和《关于做好2019届全国普通高等学校毕业生就业创业工作的通知》（教学〔2018〕8号），会同有关部门实施高校毕业生基层成长计划，服务乡村振兴战略，引导毕业生结合自身优势和特长到现代农业、农产品加工流通、乡村旅游业、农村电子商务等一二三产业就业创业。修订《普通高等学校学生管理规定》，实施弹性学制，允许保留学籍休学创新创业，支持创业学生复学后转入相关专业学习。中央财政设立中央高校教育教学改革专项资金，专项资金的分配因素可根据高校创新创业开展情况，支持学生创业。二是完善高校创新创业课程体系和师资队伍建设。教育部发布了本科专业类教学质量国家标准，明确了各专业类创新创业教育目标要求及课程要求。推动高校面向全体学生开好创新创业教育专门课程，目前全国高校已普遍开设创新创业教育课程，开课数量2.8万余门，已上线的在线开放课程4185门。依托国家级精品在线开放课程建设工作，推出了52门国家级创新创业教育精品慕课。推动高校聘请各行业优秀人才担任创新创业教育专兼职教师，在各地各高校推荐的基础上，组建了全国万名优秀创新创业导师人才库。三是加强高校学生实践训练。建设了大批创新创业实践平台，截至2018年底，全国高校建设校内创新创业教育实践平台近1.3万个，与行业企业共建校外创业实习基地4.1万个。深入实施"国家级大学生创新创业训练计划",2018年，118所部属高校、912所地方高校共有3.96万个项目，参与学生人数共计16.7万人，项目经费达7.5亿元。连续4届举办中国"互联网+"大学生创新创业大赛，累计490万大学生、199万个团队参赛。四是强化大学生创业指导服务。建立健全国家、省级、高校大学生创业服务网络平台，聘请行业专家、创业校友等担任创新创业导师队伍，通过举办讲座、论坛、沙龙等活动，针对创新创业大学生不同阶段和不同需求，对准备创业的学生，提供开业指导、政策咨询、创业培训等；对正在创业的学生，给予项目孵化、管理运营、项目对接、市场开拓等指导。

下一步，我部将会同有关部门继续深入贯彻落实党中央、国务院决策部署，出台相关政策措施，进一步鼓励和支持返乡大学生创新创业，促进乡村振兴。

二、关于优化创新创业政策措施营造创业氛围

为支持大学生等群体返乡入乡创业，党中央、国务院出台了一系列扶持政策措施，营造良好创新创业氛围。一是完善大学生返乡创业政策。2015年，国务院办公厅印发《关于支持农民工等人员返乡创业的意见》（国办发〔2015〕47号），降低创业门槛，完善大学生等人员返乡创业支持政策。2016年，国务院办公厅印发《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》（国办发〔2016〕84号），进一步完善支持大学生返乡下乡创业政策措施。2018年，国务院印发《关于推动创新创业高质量发展打造"双创"升级版的意见》（国发〔2018〕32号），进一步提出深入推进大学生等返乡创业试点、发挥创业担保贷款的作用、安排一定比例年度土地利用计划专项支持等措施，支持大学生等人员返乡创业。二是加大大学生返乡创业财政支持。为强化对高校毕业生创业担保贷款贴息支持，切实减轻创业者负担，财政部印发《普惠金融发展专项资金管理办法》（财金〔2016〕85号），对高校毕业生等符合规定条件的个人和小微企业创业担保贷款给予财政贴息支持。2018年，财政部会同人力资源社会保障部和人民银行联合印发了《关于进一步做好创业担保贷款财政贴息工作的通知》（财金〔2018〕22号），进一步加大了创业担保贷款财政贴息支持力度，降低贷款申请条件。2019年，财政部印发《关于做好2019年中央财政普惠金融发展专项资金管理工作的通知》（财金函〔2019〕8号），明确自2018年11月16日起，中央财政创业担保贷款贴息的个人创业担保贷款，最高额度由10万元提高至15万元。一系列普惠财税政策，有力地激发了大学生返乡创新创业热情，增强了乡村经济发展新动能。

下一步，我部将会同有关部门进一步研究完善相关政策措施，持续加大返乡创新创业扶持力度，为返乡创新创业提供更为宽松有力的政策措施，营造良好的创新创业氛围。

三、关于加大创业平台和基础保障建设

近年来，我部会同国务院相关部门推进大学生创新创业，打造了乡村经济发展新引擎，增强乡村经济发展新动能。一是搭建农村大学生创新创业平台。我部坚持把农村创新创业与高素质农民、新型经营主体培育结合起来，扎实推进新型职业农民培育工程，组织开展农民创业培训和手机应用技能培训，加强创业指导，搭建多种形式服务平台，建设了1096个具有区域特色的农村创业创新园区（基地）；联合12个部门印发《关于促进农村创业创新园区（基地）建设的指导意见》，对园区和基地建设作出了全面部署；认定100个返乡下乡创新创业典型县，入库登记管理了172个创业孵化基地；连续3年举办全国农村创新创业大赛，共吸引来自全国31个省（区、市）的1800多个项目，2100多名选手参与比赛，影响和带动的农村"双创"人员达10万人以上。工业和信息化部连续3年举办"创客中国"创新创业大赛，大学生创客踊跃参赛。发展改革委会同教育部、人力资源社会保障部等有关部门加强大学生创业教育，推动建设了清华大学、河北农业大学等19个高校双创示范基地，提升农村大学生返乡创业能力。二是完善农村大学生创新创业保障。财政部会同有关部门出台了一系列支持和促进重点群体创业就业税收优惠政策，农村大学生返乡创业人员中符合条件的，可按规定享受政策优惠。符合小微企业条件的，可享受相关税费减免政策。同时，返乡创业大学生可按规定参加城乡居民基本养老保险和城乡居民基本医疗保险，或以灵活就业人员身份参加企业职工基本养老保险和城镇职工基本医疗保险。

下一步，我部将会同发展改革委、人力资源社会保障部、教育部等相关部门，继续大力支持农村创新创业平台建设，认定一批创新创业孵化基地、国家农村创新创业园区、全国农村创新创业典型县，继续举办全国农村创新创业大赛，支持工业和信息化部举办"创客中国"创新创业大赛，促进农村大学生返乡创新创业，推动乡村振兴。

感谢您对"三农"事业发展的关心，希望继续对我部工作给予支持。
