# 中共国家文物局党组关于在全国文物系统开展向第九届全国“人民满意的公务员集体”国家文物局督察司安全监管处学习活动的决定

文物党发〔2019〕21号

各省、自治区、直辖市文物局（文化和旅游厅/局），新疆生产建设兵团文物局，国家文物局各直属单位：

为充分发挥“人民满意的公务员集体”正向激励、示范引领作用，进一步激励和引导全国文物系统广大公务员新时代新担当新作为，建设忠诚干净担当的高素质专业化公务员队伍，中共国家文物局党组决定，在全国文物系统开展向荣获第九届全国“人民满意的公务员集体”称号的国家文物局督察司安全监管处学习的活动。

国家文物局督察司安全监管处承担全国文物安全监管工作。近年来，该处以习近平新时代中国特色社会主义思想为指引，坚定不移贯彻落实习近平总书记关于文物安全工作重要指示批示精神，聚焦法人违法、盗窃盗掘和火灾事故三大风险，内强基础、外聚合力，督察督办文物大案要案，严打文物犯罪，督促落实安全责任，推动构建文物安全长效机制，取得了显著成绩。

国家文物局督察司安全监管处是广大公务员集体的优秀代表，彰显着新时代忠诚干净担当的公仆本色，是全国文物系统学习的榜样。全国文物系统广大干部职工要学习他们对人民负责、为人民服务、让人民满意的时代风采和公仆本色，学习他们不忘初心、牢记使命、甘于奉献的使命意识和奉献精神，学习他们对党忠诚、敢于担当、攻坚克难的责任意识和奋斗精神。国家文物局党组号召全国文物系统以习近平新时代中国特色社会主义思想为指导，增强“四个意识”，坚定“四个自信”，做到“两个维护”，把学习国家文物局督察司安全监管处先进事迹与深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神结合起来，与深入开展“不忘初心、牢记使命”主题教育结合起来，与推进文物保护利用改革结合起来，与加强文物系统干部队伍建设结合起来，切实做好文物保护利用各项工作。各地文物部门要高度重视，精心组织，加大宣传力度，掀起向国家文物局督察司安全监管处学习的热潮，忠诚担当、求实创新，把学习成果转化为做好本职工作的实际行动，不断为新时代文物事业的改革发展作出新的贡献。

中共国家文物局党组
