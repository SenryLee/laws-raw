# 国家移民管理局对十三届全国人大二次会议第7811号建议的答复

刘艺良等2名代表：

你们提出的关于跟进港澳居民来往内地通行证更充分享受国民待遇的建议收悉，经征求公安部、司法部意见，现答复如下：

一、关于尽快推动以立法形式确认回乡证作为港澳居民于内地身份证明的法律效力。我们认为现行港澳居民来往内地通行证（以下称“回乡证”）既是港澳居民来往内地的法定出入境证件，又是其在内地的身份证明。关于回乡证在内地作为身份证明的便利化使用问题，我局将主动会同有关部门大力推进，积极落实。

二、关于同步推动回乡证和居住证的社会化应用，为港澳居民在内地享受公共服务提供更多便利。近年来，针对港澳居民持用回乡证办理个人事务不够便利的问题，我局大力推进出入境证件便利化应用工作。目前，我局已经搭建起全国统一的出入境证件身份认证服务平台，并将回乡证纳入认证服务范围。有关政务、服务部门完成与出入境证件身份认证服务平台的对接并提供相应服务后，港澳居民持回乡证可享受与内地居民持用身份证同样的网上和自助服务便利。根据工作部署，从2019年10月份起，港澳居民持用回乡证将在交通运输、金融、通讯、教育、医疗、社保、工商、税务、住宿等9个领域享受30余项公共民生服务便利。下一步，我局将会同有关部门不断拓展回乡证便利化应用领域和服务范围，为港澳居民持证办理政务、服务事项提供更多便利和更好服务，不断提升港澳居民的获得感、幸福感、安全感。

2018年8月6日，国务院办公厅印发《港澳台居民居住证申领发放办法》（以下简称《办法》）。自2018年9月1日正式实施以来，公安部会同国务院港澳办、国务院台办等有关部门认真抓好《办法》贯彻落实工作，推动各地区各有关部门全面落实《办法》规定的港澳台居民居住证持有人依法享有的3项权利、6项基本公共服务和9项便利，确保港澳台居民居住证承载的各项公共服务和权利待遇落地生效。目前，港澳台居民持居住证可以顺利办理金融业务、乘坐飞机火车、住宿旅馆等《办法》规定的相关事务，但随着证件应用的不断深化，各项配套措施还需要进一步完善。下一步，公安部将会同有关部门深入跟踪调查，全面了解港澳台居民在使用居住证时遇到的困难和问题，积极完善措施，切实让在内地（大陆）工作学习生活的港澳台同胞感受到居住证带来的便利和实惠。

感谢你们对移民管理工作的关心和支持。
