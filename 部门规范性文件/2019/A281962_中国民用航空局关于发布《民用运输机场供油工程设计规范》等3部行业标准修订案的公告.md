# 中国民用航空局关于发布《民用运输机场供油工程设计规范》等3部行业标准修订案的公告

现发布《民用运输机场供油工程设计规范》（MH 5008-2017）第一修订案、《小型民用运输机场供油工程设计规范》（MH 5029-2014）第一修订案和《通用航空供油工程建设规范》（MH/T 5030-2014）第一修订案，自2019年10月1日起施行。

上述3部标准修订案由中国民用航空局机场司负责管理和解释。

中国民用航空局

2019年9月9日

附件：

《民用运输机场供油工程设计规范》（MH 5008-2017）第一修订案

《小型民用运输机场供油工程设计规范》（MH 5029-2014）第一修订案

《通用航空供油工程建设规范》（MH/T 5030-2014）第一修订案
