# 中宣部办公厅、文化和旅游部办公厅关于举办2019年全国基层院团戏曲会演的通知

## 中宣部办公厅　文化和旅游部办公厅关于举办2019年全国基层院团戏曲会演的通知

办艺发〔2019〕26号

各省、自治区、直辖市党委宣传部、文化和旅游厅（局），新疆生产建设兵团党委宣传部、文化体育新闻出版广电局：

为深入贯彻落实习近平新时代中国特色社会主义思想和党的十九大精神，自觉承担举旗帜、聚民心、育新人、兴文化、展形象的使命任务，展示基层院团传承发展戏曲艺术的优秀创作成果和服务人民群众的良好精神风貌，以优异成绩迎接新中国成立70周年，中宣部、文化和旅游部定于2019年6月底至8月在北京继续举办全国基层院团戏曲会演。现将有关事项通知如下：

一、会演主要内容

组织全国32台优秀戏曲剧节目（含小戏组台）参加会演，每台剧节目演出2场。会演不设奖项，由主办单位为参演单位颁发参演纪念牌和纪念证书。

会演期间将组织观摩交流，开展剧目导赏和艺术评论，引导创作方向。

二、参演剧节目申报事项

（一）参演单位

以全国地市级、县级专业戏曲艺术表演团体（含民营院团）为主，鼓励仅有一个国办团体支撑的戏曲剧种所属院团（“天下第一团”）参加。

（二）申报数量及程序

省级文化和旅游行政部门在遴选基础上，经征求同级党委宣传部门意见并公示后，向文化和旅游部推荐1台大戏或1台小戏组台（小戏组台由省级文化和旅游行政部门自行组合后申报）。

（三）申报条件

申报作品应坚持以人民为中心的创作导向，聚焦“中国梦”时代主题，以反映中华人民共和国成立70周年题材为重点，培育和弘扬社会主义核心价值观，唱响爱国主义主旋律，传承和弘扬中华优秀传统文化，坚持创造性转化、创新性发展，坚持思想精深、艺术精湛、制作精良相统一，讴歌党、讴歌祖国、讴歌人民、讴歌英雄。鼓励简朴舞美、回归艺术本体。

申报作品题材不限，可以是整理改编的优秀经典传统戏、新编历史剧和现代戏；鼓励革命历史题材和现实题材剧目申报。已参加过全国基层院团戏曲会演的剧节目不得再次申报。

原则上大戏（或小戏组台）时长在90至120分钟以内。

（四）申报材料

申报推荐函1份（主送：文化和旅游部艺术司）；申报推荐表（附后）1份；申报剧节目演出录像（用U盘存储，小戏组台节目存在1个U盘中）、剧本及节目单各1份。

申报截止日期为2019年4月10日，以寄出地邮戳为准，逾期不报视为自动放弃（请使用邮政快递EMS）。

三、经费安排

参演单位的往返交通、在京食宿等费用自理，主办单位将给予适当补贴。在此基础上，请省级党委宣传部门、文化和旅游行政部门给予参演单位不低于文化和旅游部补贴标准数额的相应演出补贴。

四、其他事项

各地应高度重视，认真组织剧节目申报和遴选工作，对所申报的剧节目严把政治关、思想关和艺术质量关。

文化和旅游部艺术司对各地申报的作品进行审核并公示后，发布入选通知。

五、联系方式

申报材料请寄：北京市东城区朝阳门北大街10号文化和旅游部艺术司戏剧曲艺处，邮编：100020。

联系人及电话：陈珺，010-59881766

特此通知。
