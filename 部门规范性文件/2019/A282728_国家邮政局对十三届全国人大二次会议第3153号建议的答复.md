# 国家邮政局对十三届全国人大二次会议第3153号建议的答复

## 对十三届全国人大二次会议第3153号建议的答复

国邮函〔2019〕63号

张近东代表：

您提出的《关于制定循环包装国家标准，建成绿色包装回收体系的建议》（第3153号）收悉。经商中国邮政集团公司，答复如下：

党的十八大以来，我国快递业保持快速发展，快递业务量从57亿件增长到2018年的500亿件，连续4年稳居世界第一，不仅成为推动流通方式转型，促进消费升级的先导性产业，在稳增长、调结构、惠民生等方面发挥了重要作用，而且成为现代服务业的重要组成部分，国民经济的一匹黑马。快递包装使用量的剧增，由此带来的资源消耗和环境污染等问题受到社会各界的高度关注。

一、关于推进可循环包装国家标准和绿色包装回收体系建设问题

国家邮政局高度重视快递包装标准体系建设，切实加大绿色包装相关标准的制修订工作。一是组织完成《快递封装用品》系列国家标准的修订，组织起草并发布《邮政业封装用胶带》《邮件快件包装填充物技术要求》《快件集装容器 第2部分：集装袋》等行业标准，在标准中明确绿色环保、减量化及循环利用等相关技术指标，有效引导企业设计、生产、使用绿色包装产品。及时开展标准的宣贯、解读与培训工作，推动标准落地实施。二是组织制定《邮件快件包装基本要求》行业标准，对包装行为提出规范性要求，指导企业简约包装、科学包装，避免过度包装。目前，正积极推进《快递绿色包装评价》国家标准的出台。

此外，我局结合行业实际，稳步推进快递包装回收循环利用。印发了《邮件快件包装废弃物回收箱应用参考》，推动在邮政快递网点设置回收箱，引导寄递企业通过在高校和社区网点设立回收装置等方式开展包装物回收。大力实施“9571”工程，今年将在全国1万个邮政快递营业网点设置包装废弃物回收装置。鼓励快递企业通过与包装生产企业合作等方式探索建立包装回收再利用闭环管理模式。大力推广可循环快递盒、快递箱。推动各地撬动社会资源，逐步实现快递业与地方回收社会体系有机衔接，实现包装物最大限度再利用和无害处理，不断提高包装材料循环利用率。积极参与垃圾分类有关部门协作机制，加强与有关职能部门的沟通协调，推动完善社会回收体系。

二、关于建立绿色包装奖惩机制，出台相关配套政策的问题

我局注重绿色政策供给，积极协调争取相关政策支持。推动《国务院办公厅关于推进电子商务与快递物流协同发展的意见》（国办发〔2018〕1号）和国家邮政局、国家发展改革委等十部门《关于协同推进快递业绿色包装工作的指导意见》（国邮发〔2017〕86号）落地实施。通过强化政策扶持，落实国家鼓励节能减排、循环利用资源、绿色制造、绿色金融、绿色消费、绿色采购等优惠政策。研究制定包装分类回收利用支持政策，提高包装循环利用率，推动各地加大对快递包装回收利用的财政支持力度。推动各地研究出台针对快递、电商企业绿色包装的税收、信贷等扶持政策，支持有关企业申报地方节能减排、技术改造、中小企业、信息化等专项资金。引导和推动寄递企业探索建立消费者激励机制，为消费者提供多样化的绿色产品选择。

我局注重在行业推进创新应用，提升行业发展质效。引导企业广泛使用大数据、云计算，大力推广应用人工智能技术和北斗导航系统，无人仓、无人机投入使用，推进库存前置、智能分仓、科学配载、线路优化，在提高效率的同时大幅降低包装物料和能耗。大力推广快递服务制造业以及其他产业的经验做法，通过向上游嵌入前置，提供包装、收寄一体化服务，逐步减少二次包装。

此外，将生态环境保护作为对市场主体监管的重要内容，加强对包装物重金属及特定物质检测，针对企业内控体系建设、生态环境保护教育培训、电子运单应用、循环中转袋使用、按照《快递业绿色包装指南（试行）》进行包装操作等情况进行督导检查。加大工作督导力度，综合运用定期通报、督导检查、接受举报、信用约束等方式，指导寄递企业开展绿色行动计划，督促企业完善内控体系、强化教育培训、规范文明作业、提升绿色包装产品使用率等，推进企业生态环保主体责任落实。今年4月份，我局组织开展了主要品牌寄递企业生态环保主体责任落实情况专项调研检查，根据调研检查发现的问题，对企业进行了通报，并提出整改要求。

三、关于制定冷链包装耗材标准，鼓励企业探索使用新型可回收冷链包装的问题。

国家邮政局已经启动《冷链快递包装箱技术要求》行业标准的研制，研究以可循环保温箱替代一次性非环保箱，保障全程冷链运输，提高资源利用效率。同时，鼓励企业加强与相关领域高校、科研机构合作，在教育、科研、人才培养等方面形成合力，健全产学研一体化创新机制，加大在快递绿色包装方面的研发和技术创新，逐步降低快递绿色包装产品成本，逐步探索使用新型可回收冷链包装。加强对生态产业化的研究，充分发挥要素市场的支撑作用，引导和推动邮政用品生产企业做大做强，增加绿色供给。

目前，在绿色包装使用和回收过程中确实尚存在诸多问题亟待解决，例如，过度包装仍然普遍存在，绿色包装产品和技术的推广仍面临成本高等难题，包装循环利用和回收体系尚不健全，需要相关部门以及社会相关方面共同努力解决。您提出的建议，我们予以采纳并结合工作实际抓好落实。

下一步，国家邮政局将继续深入学习贯彻落实习近平生态文明思想，坚持生态优先、绿色发展，强化系统治理、综合施策，着力推进包装绿色治理，为全国生态文明建设和我国经济高质量发展做出应有的贡献。

感谢您对快递业发展的关心和支持。
