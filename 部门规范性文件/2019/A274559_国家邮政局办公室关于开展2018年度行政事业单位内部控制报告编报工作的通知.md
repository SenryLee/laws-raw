# 国家邮政局办公室关于开展2018年度行政事业单位内部控制报告编报工作的通知

国邮办函〔2019〕86号

各省、自治区、直辖市邮政管理局，国家邮政局机关服务中心、发展研究中心、邮政业安全中心，北京邮电疗养院，中华全国集邮联合会：

为掌握邮政管理系统行政事业单位内部控制建立与实施情况，全面加强系统内各单位内部控制建设，根据《财政部关于全面推进行政事业单位内部控制建设的指导意见》（财会﹝2015﹞24号）、《行政事业单位内部控制报告管理制度（试行）》（财会﹝2017﹞1号）和《财政部关于开展2018年度行政事业单位内部控制报告编报工作的通知》（财会函﹝2018﹞11号）的有关要求，现就2018年度行政事业单位内部控制报告（以下简称内控报告）编报工作，通知如下：

一、总体要求

（一）提高思想认识，充分发挥领导小组作用。内控报告编报工作是固化全系统内部控制机制的重要手段，各单位务必要提高思想认识，加强组织协调。尚未成立内部控制工作领导小组的要抓紧成立。要充分发挥各单位内部控制工作领导小组的作用，强化业务与财务协同，提升内控报告编报水平。

（二）及时准确编报，搭建建立合理的汇总审核机制。要严格按照国家局规定的时间节点，层层落实责任，做好编制、审核、汇总、报送、分析和利用等工作……协调做好内控报告编报与部门决算、政府采购、固有资产报告等协调工作，确保同口径数据的一致性，确保编报内容的准确性。

（三）加强分析应用，拓宽报告的成果的使用思路和渠道。各单位要坚持需求导向和问题导向相结合，认真分析本单位在各业务环节的风险点，挖掘内控报告使用价值，并与本单位廉政风险防控体系建设有机结合，积极开展内控报告的专题分析和评价结果的应用工作。

二、报送要求

（一）报送时间。各单位应于4月12日前完成本单位及所属单位内控报告的审核和汇总工作，报送国家局办公室。

（二）报送方式。各省（区、市）邮政管理局除报送局本级报告外，还应当编报含所属单位的汇总报告。电子数据通过“财政部统一报表系统”（https://tybb.mof.gov.cn/）报送，正式文件通过OA报送。
