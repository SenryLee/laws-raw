# 中共教育部党组关于田慧生等同志职务任免的通知

教党任〔2019〕85号

部内各司局、各直属单位：

中共教育部党组2019年4月26日决定，任命田慧生同志为教材局局长（试用期一年），免去郑富芝同志的教材局局长职务；任命何光彩同志为巡视工作办公室主任（试用期一年）。

中共教育部党组

2019年4月30日
