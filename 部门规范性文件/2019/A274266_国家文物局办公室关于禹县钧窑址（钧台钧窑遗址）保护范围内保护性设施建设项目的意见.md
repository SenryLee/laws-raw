# 国家文物局办公室关于禹县钧窑址（钧台钧窑遗址）保护范围内保护性设施建设项目的意见

办保函〔2019〕33号

河南省文物局：

你局《关于再次报批禹县钧窑址（钧台钧窑遗址）保护性设施建设项目设计方案的请示》（豫文物〔2018〕174号）收悉。经研究，我局暂不同意在禹县钧窑址（钧台钧窑遗址）保护范围内实施保护性设施建设项目。

一、所报方案应进一步核减拟建场馆规模、减低建筑高度，调整场馆外观设计，与周边博物馆建筑和遗址文化特色相协调。同时，应完善广场铺装设计，结合遗存分布及窑址特点，统筹考虑广场铺装方式。补充拟建建筑立面、剖面图等技术图纸。

二、请你局按照我局《关于禹县钧窑址（钧台钧窑遗址）保护性设施建设项目的意见》（办保函〔2018〕414号）要求和上述意见，指导有关单位认真修改完善设计文本，进一步研提保护性设施的外观比选方案，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月16日
