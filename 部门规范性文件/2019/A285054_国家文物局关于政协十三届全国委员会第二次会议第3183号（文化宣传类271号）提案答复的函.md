# 国家文物局关于政协十三届全国委员会第二次会议第3183号（文化宣传类271号）提案答复的函

文物保函〔2019〕777号

安来顺等10位委员：

你们提出的“关于加快出台政策，统一规范基本建设考古前置工作的提案”收悉。经商财政部、自然资源部，现答复如下：

我国是文物大国。根据第三次全国文物普查，全国地下文物约33万处，做好经济建设中的地下文物保护工作是各地文物考古机构的重要任务，国家文物局每年批准的基本建设考古发掘项目达到800余项。2018年，中共中央办公厅、国务院办公厅印发《关于加强文物保护利用改革的若干意见》，将“完善基本建设考古制度”作为一项重要任务，明确要求“地方政府在土地储备时，对于可能存在文物遗存的土地，在依法完成考古调查、勘探、发掘前不得入库”。国家文物局积极落实《意见》要求，加强顶层设计，委托中国地质大学承担土储考古前置研究课题，并于2019年3月会同自然资源部在郑州召开土地储备考古前置专题会议，研讨土地储备考古前置制度设计。

你们提出规范基本建设考古前置工作的建议非常重要。下一步，国家文物局将积极协同财政部、自然资源部等部门，重点推进以下工作：

第一，关于出台土地储备考古前置专门文件。国家文物局将加强与自然资源部沟通，依托土储考古前置研究课题，做好基础数据搜集、案例分析和现状调研，进一步理清当前基本建设考古工作量、发现文物量、工作成本等问题，适时推动多部门联合发文，促进城市发展与文物保护的协调发展。同时，鼓励有条件的城市开展试点工作，探索适合各地特点的文物、自然资源、规划、建设各部门协调机制，落实文物保护主体责任，及时总结经验，推广成功案例。

第二，关于明确基本建设考古经费及其性质。目前，财政部认为基本建设考古费用纳入土地成本并作为非税收入管理，不宜再设立相关行政事业性收费或政府性基金。自然资源部认为土地储备资金支出不包括考古调查、勘探、发掘等内容，土地储备考古前置工作经费不宜直接通过土地出让收入安排解决。我局将与财政部、自然资源部继续沟通，积极探讨将基本建设考古费用纳入土地成本并作为非税收入管理的可行性，统筹考虑基本建设考古费用性质、取费标准、管理方式等问题，保障基本建设考古取费和经费使用依法合规。

第三，关于修订《中华人民共和国文物保护法》相关条文。根据国家“放管服”改革要求，国家文物局将会同财政部、自然资源部等部门积极探讨各级财政承担基本建设考古相关费用的可行性和法律依据。在《中华人民共和国文物保护法》的修订工作中，重点研究文物调查勘探项目界定、考古前置条件等，确保法条表述的严密性和可操作性，依法保障基本建设考古工作前置的顺利开展。

感谢你们对文物事业的关心和支持！

国家文物局

2019年8月5日
