# 国家体育总局关于开展2019年全国广播体操、工间操展演活动的通知

## 体育总局关于开展2019年全国广播体操、工间操展演活动的通知

体群字〔2019〕49号

各省、自治区、直辖市、新疆生产建设兵团体育局，各行业体协：

为落实《国家体育总局、中央和国家机关工委、教育部、卫生健康委、全国总工会、共青团中央、中央广播电视总台关于广泛推广普及广播体操的通知》，加大力度推广普及广播体操、工间操，带动全国各地举办多种形式的活动，吸引广大群众积极参与，决定在全国开展2019年全国广播体操、工间操展演活动，现将有关事宜通知如下：

一、活动原则

（一）坚持正确引导

坚持积极引导与尊重群众健身需求相结合，大力推广普及简单易学、科学有效的广播体操健身方法。同时充分尊重广大群众多样化的健身的需求，在推广工作中将传统和创新相结合，日常活动和集体展演相结合，为群众参加广播体操、工间操提供便利条件，创造良好活动环境。

（二）重在广泛参与

以展演活动为主线，创新推广模式，分类、分别施策开展推广普及工作，推动广播体操、工间操活动常态化。以机关、事业单位职工为重点对象，动员全社会力量参加，吸引更广泛的群众积极参与，形成“人人参与，人人享有；人人健身，人人快乐；人人健康，人人幸福”的全民健身新时尚。

（三）突出示范带动

各级体育部门带头普遍开展广播体操、工间操活动，并组织开展各类培训、展示、展演和比赛活动，推动各级各类机关、企事业单位、学校和社会组织开展广播体操、工间操展示、展演活动。

（四）抓好统筹协调

体育部门主动协调相关部门，整合资源，形成工作合力，加强对推广普及广播体操、工间操工作的统筹协调。鼓励各地因地制宜，结合当地体育资源和特点，开展富有地方特色、符合群众品位的广播体操、工间操活动。

二、活动形式

（一）各地区、各行业全年持续广泛开展形式多样的广播体操、工间操培训、展示、展演和比赛等推广普及活动；

（二）2019年8月在陕西省举办2019年全国广播体操、工间操集中展演活动（集中展演活动通知另发）。

三、工作要求

（一）各地区、各部门、各行业要切实提高对推广普及广播体操、工间操工作意义的认识，重视举办广播体操、工间操展演活动工作，扎实推动广播体操、工间操推广普及，在“持续”上下功夫，促进职工群众养成做广播体操、工间操的良好习惯。

（二）要将广播体操、健身操、毽球、跳绳、太极拳、健身气功、《科学健身十八法》等作为开展“6·10”、“全民健身日”和冬季运动推广普及活动的主要内容，创新活动形式，丰富活动内涵，切实体现成效。

（三）充分发挥社会体育指导员的骨干带头作用，鼓励他们掌握广播体操指导技能，指导和带动身边群众做广播体操。动员体育院校师生、体育志愿者等力量，组织广播体操培训队伍，为广播体操、工间操推广普及工作服务。

（四）组织线上线下等多种形式的广播体操、工间操展演、展示和比赛，加强习练者之间的互动。有条件的地方与网络平台合作举办广播体操、工间操视频评比和挑战等活动。

（五）各省（区、市）体育局按照2019年全国广播体操、工间操集中展演活动的要求，组织本省（区、市）队伍参加集中展演活动。

（六）创新宣传方式，发动各类媒体对推广普及广播体操、工间操工作和展演活动进行广泛深入宣传。特别是对广播体操、工间操的发展历程、健身特点、文化积淀等方面加强宣传，激发群众的参与热情。举办展演活动应当使用全民健身标志，有体育彩票公益金资助的活动应当使用体育彩票公益金标志。

（七）牢固树立安全发展理念，切实加强安全防范工作。开展人群集中的活动时，要根据活动规模、参与人群特点等，与公安、应急管理、卫生、旅游等相关部门密切配合，制定切实可行的安全预案，周密组织，确保广播操、工间操活动安全顺利举行。

（八）各省（区、市）体育部门可使用中央集中彩票公益金转移支付地方的全民健身赛事活动经费开展广播体操、工间操展演活动。同时，注意收集开展广播体操、工间操展演活动的视频、图片和数据等资料。
