# 国家体育总局职鉴指导中心关于印发《2019年体育行业职业技能鉴定工作要点》的通知

## 体育总局职鉴指导中心关于印发《2019年体育行业职业技能鉴定工作要点》的通知

体职鉴字〔2019〕7号

各省、区、市体育行业职业技能鉴定站：

现将《2019年体育行业职业技能鉴定工作要点》印发给你们，请结合各地实际，认真做好2019年度本省区市有关体育职业技能鉴定工作的计划安排与实施。
