# 国家体育总局办公厅关于印发《2019年群众体育工作要点》的通知

## 体育总局办公厅关于印发《2019年群众体育工作要点》的通知

各省、自治区、直辖市、计划单列市、新疆生产建设兵团体育局，中央军委训练管理部军事体育训练中心，各行业体协，各司、局，各直属单位，中国足协，中国篮协，各改革试点项目协会：

现将《2019年群众体育工作要点》印发给你们，请各地区、各行业、各单位结合实际，参照执行。

体育总局办公厅

2019年2月14日

## 2019年群众体育工作要点

2019年群众体育工作要以习近平新时代中国特色社会主义思想为指导，认真贯彻落实习近平总书记关于体育工作的重要指示批示和党中央、国务院的决策部署，坚持以人民为中心的发展思想，根据《“健康中国2030”规划纲要》和《全民健身计划（2016-2020年）》所列的任务和目标，不断完善各项制度，推进全民健身公共服务体系建设。坚持深化改革，夯实基础，推进建设，开展活动，强化公共服务体系、体育健身设施、科学健身指导等方面的建设，推动各类群众体育活动广泛开展，使人民群众有更多的获得感、幸福感、安全感。全年重点做好以下工作：

一、强化职责，建设使用好全民健身场地设施

（一）研究制定关于全民健身公共服务体系建设的指导意见及基本公共体育服务指导标准，加强全民健身场地设施建设管理政策研究。推动《城市居住区规划设计标准》有关体育健身设施的规划落地。支持配合有关部门修订印发《城市公共服务设施规划标准》，进一步细化公共体育设施配置标准和内容。支持有关部门修订《室外健身器材的安全 通用要求》国家标准，下大力气推动解决群众“去哪儿健身”难题。

（二）继续会同中央有关部门利用中央资金支持地方建设完善群众身边的健身设施。按照中央关于打赢脱贫攻坚战的总体部署，将体育健身设施中央资金资助建设项目、资金投入重点向贫困地区倾斜。中央转移支付彩票公益金用于资助建设社区健身中心、体育公园、健身步道等；公共文化服务体系建设专项资金用于资助建设农民体育健身工程；中央预算内投资用于实施“十三五”公共体育普及工程，资助建设足球场等项目。利用中央集中彩票公益金采购配发一批智能化室外室内健身器材，支持地方建设体育公园和社区健身中心。推广一些地方利用老城区存量资源、利用社会资本和市场机制改建便民利民全民健身场地设施的做法。

（三）持续推进大型体育场馆信息化监管系统和智慧社区健身中心建设试点。组织研制大型体育场馆信息化系统建设技术规范、室内智能健身器材通用要求、智慧健身场所通信协议。推动落实二代室外健身器材、智慧化健身场所等技术规范，将信息技术手段运用到大型体育场馆、社区健身中心等公共健身场所，提升其运营管理和服务水平。

（四）推进大型体育场馆免费或低收费开放。会同财政部修改完成并组织实施《大型体育场馆免费低收费开放补助资金管理办法》。采取公开场馆开放信息、委托第三方评估和明察暗访等方式，督导推动大型公共体育场馆更好地向社会免费或低收费开放，提升管理服务水平。

二、调动力量，组织开展好全民健身赛事活动

（一）深化“放管服”改革，研制《彩票公益金资助开展全民健身赛事和活动办法》和《向社会力量购买全民健身赛事和活动的办法》，推动制定体育赛事活动办赛参赛指南，推动社会力量参与全民健身赛事活动的组织举办。

（二）持续开展推广普及广播体操、工间操工作。会同相关部委共同印发《关于广泛推广普及广播体操的通知》，推动机关、企事业单位开展广播体操和工间操活动，加大宣传力度，在全国掀起参与广播体操和工间操活动高潮。组织开展2019年全国广播体操及工间操展演活动，在“全民健身日”前后举办工间操全国展演活动。

（三）推动全国群众冰雪运动开展。落实《群众冬季运动推广普及计划（2016-2020年）》，大力发展群众冰雪运动。开展参与度高、普及面广、影响力大、带动力强的冬季项目品牌赛事和活动。鼓励举办冰雪旅游节、冰雪文化节、冰雪嘉年华、赏冰乐雪季、冰雪马拉松等活动。发掘推广滑雪橇、冰上自行车、冰上龙舟、雪地拔河、雪地足球等群众喜闻乐见的民间民俗冰雪娱乐项目。推广普及旱地冰球、旱地冰壶等项目，推动冬季项目“南展西扩东进”，不断拓展冰雪运动的时空范围。

（四）公开征集全民健身示范性赛事活动。探索组织举办全民健身赛事活动的新模式，做强老品牌和培育新品牌相结合，激发市场活力，打造体育总局全民健身赛事活动品牌，构建全民健身赛事活动体系。继续发挥各运动项目中心、协会的专业及品牌优势，做强原有的品牌赛事活动，创办新的群众赛事活动或向社会公开征集一批全国群众赛事活动。鼓励各省（区、市）自下而上层层举办赛事活动，带动起各地赛事活动的开展，使广大群众均有机会参加。

（五）组织开展全民健身主题示范活动。精心组织全国新年登高、610纪念毛泽东题词、全民健身日、重阳节、丰收节、群众冬季运动推广普及和广场舞展演活动。推动各项活动主会场和特色示范活动办出特色，创出亮点。开展好相关宣传工作，不断提高群众的健身意识和“全民健身日”等全民健身重要时间节点的知晓度。会同国家民委、中国残疾人联合会做好第十一届全国少数民族运动会、全国第十届残疾人运动会暨第七届特奥会筹办工作。

三、整合资源，统筹利用好科学健身指导标准

（一）开展第五次国民体质监测。印发《国民体质监测工作方案》，向国家统计局申报统计文号，进行测试器材招标采购和配发，制作工作手册和数据登录书，举办全国监测技术培训，做好监测队伍的组建，从6月份开始在全国范围内开展数据采集工作。

（二）推行国家体育锻炼标准和运动水平等级标准。设计制作国家体育锻炼标准标识和奖章证书，印发《关于广泛开展国家体育锻炼标准测试活动的通知》、《国家体育锻炼标准测试器材配置和要求》、《国家体育锻炼标准达标测试指导手册》。向全社会公开招募能在全国开展国家体育锻炼标准达标测验活动的执行机构，在全国80%以上的省（区、市）共开展150站体育总局支持的、示范性的国家体育锻炼标准达标测验活动。各省（区、市）体育部门要在本地区80%以上的地市开展本地体育行政部门支持的、引导性的国家体育锻炼标准达标测验活动。按照面向全体人民、打通大众锻炼标准与运动员技术等级标准之间制度藩篱的思路，在尊重项目规律、尊重历史形成、尊重国际惯例的前提下，探索推广各项目运动水平等级标准。

（三）开展全民健身活动状况调查。设计编写全民健身活动状况调查工作技术手册、调查问卷、数据录入软件和质量控制方法，培训各级调研组和调查队技术骨干并在年底前指导各抽样地市（县）开展样本的抽取工作。2020年初汇总全国各省（区、市）抽样数据，统计分析后形成《国家全民健身活动状况调查公报》和各省（区、市）经常参加体育锻炼人数比例数据。

四、统筹规划，推进实施好全民健身基本制度

（一）启动《全民健身（实施）计划（2016-2020年）》实施效果评估和《全民健身计划（2021-2025年）》研制工作。开展好《全民健身计划》评估和研制工作，《计划》实施效果评估将结合国民体质监测、全民健身活动状况调查、全民健身公共服务体系标准化研究成果、第四次经济普查中与全民健身相关的数据等作为公共数据一并开展。指导各级体育部门做好各级《全民健身实施计划》的效果评估工作。新周期《计划》研制工作将于今年下半年启动，结合评估工作进展和结果，2020年中形成初稿，经过各项程序后，2021年初报国务院审定后印发。

（二）做好全民运动健身模范市、县创建工作。围绕坚持标准、严格要求、规范程序、注重质量的工作原则，坚持宽进严出的创建工作思路，在深入调研和开展预评摸清底数的基础上，科学合理确定初评的考核指标和标准，制定评选程序，运用第三方评估和暗访等方式和手段，评出少数各方公认的、具有影响力和辐射价值的模范市、县样板，起到推动工作和示范带动作用。在此基础上进一步完善评选办法、标准和程序，成熟之后再推广，为明后年的创建和评估提供依据。

（三）统筹推进社会体育指导员工作。修改完善《社会体育指导员协会章程》，逐步推进各级社会体育指导员协会改革，推动公益社会体育指导员在《志愿服务条例》框架下开展工作并逐步纳入国家志愿服务体系，使公益社会体育指导员拥有更大平台，享受相应的激励和保障。在职业社会体育指导员方面，以2019年全国体育行业职业技能大赛为抓手，推进职业社会体育指导员队伍稳步发展。
