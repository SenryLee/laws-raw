# 农业农村部对十三届全国人大二次会议第5151号建议的答复

## 对十三届全国人大二次会议第5151号建议的答复

您提出的关于加大环洞庭湖流域畜禽养殖粪污资源化利用力度的建议收悉。经商财政部、自然资源部、国家电网有限公司，现答复如下。

一、关于加大项目支持

国家高度重视畜禽粪污资源化利用工作。近年来，中央财政和中央预算内投资积极整合优化资金，加大支持力度，以畜牧大县为重点整县推进畜禽粪污资源化利用，支持提升畜禽粪污处理利用能力，探索有效治理模式。截至目前，全国585个畜牧大县整县治理已实现全覆盖。各地可以根据本地区实际，在项目实施中对必要的畜禽粪污收储运各环节进行支持。此外，中央财政农业生产发展资金还支持非畜牧大县规模养殖场开展畜禽粪污治理，改造完善畜禽粪污收集、存贮、处理、利用等设施装备，提升处理利用能力。下一步，中央财政将会同有关部门认真研究，秉承创新发展、绿色发展、协调发展理念，进一步完善畜禽粪污资源化利用相关政策措施，为畜禽粪污资源化利用提供政策保障。

二、关于批准相关用地指标

自然资源部认真贯彻落实党中央、国务院关于坚决打好污染防治攻坚战和改善农村人居环境的决策部署，积极做好畜禽粪污资源化利用等工作的用地保障，在用地指标方面给予积极支持。在编制下达年度土地利用计划时，明确提出坚持农业农村优先发展，加大农业农村发展用地安排，保障农村人居环境整治等用地需求。按照《国务院关于深化改革严格土地管理的决定》《土地利用年度计划管理办法》的有关规定，土地利用计划实行分级管理，国家预留国务院及有关部门批准的独立选址建设项目用地指标，其余用地指标全部下达到地方，由各省（区、市）统筹安排。湖南省可统筹安排好年度土地利用计划指标，分年度、分时序做好环洞庭湖流域畜禽粪污资源化利用用地指标保障。下一步，自然资源部在编制下达全国土地利用计划时，将充分考虑畜禽粪污资源化利用用地需求，加大用地计划指标支持。

三、关于出台使用有机肥补贴政策

我部认真落实习近平总书记在中央财经领导小组第十四次会议上关于加快推进畜禽养殖废弃物处理和资源化的重要讲话精神，坚持以就地就近用于农村能源和农用有机肥为主要使用方向，加大有机肥推广使用力度。2017年以来，开展果菜茶有机肥替代化肥行动，大力推进有机肥替代，引领种植业绿色发展。在优势产区选择100个既是果菜茶生产大县，又是畜牧大县的示范县（市），开展果菜茶有机肥替代化肥试点。2018年，试点范围扩大到150个县。行动实施后，初步探索建立起有效的组织方式，初步集成了一套绿色高效技术模式，创建起一批绿色优质产品生产基地。中央财政农业生产发展资金、农业资源及生态保护补助资金实行“大专项+任务清单”的管理方式，资金采取因素法测算，按照大专项整体切块下达地方，同时将任务清单分为约束性任务和指导性任务。湖南省可以在完成约束性任务的基础上，在大专项支持方向范围内，结合当地实际，统筹利用中央和地方资金支持有机肥推广和利用。下一步，我部将会同有关部门认真研究完善有机肥推广应用相关政策措施，继续开展果菜茶有机肥替代化肥行动，并扩大试点规模和范围，2019年在全国选择175个重点县开展有机肥替代化肥示范，支持农民和新型经营主体等使用以畜禽粪污为原料的有机肥，减少化肥用量，实现节本增效、提质增效。

四、关于出台畜禽废水深度处理补贴

畜禽粪污具有较强的资源属性，是生产畜禽粪肥改良土壤地力、生产沼气改善农村能源结构的重要基础，《国务院办公厅关于加快推进畜禽养殖废弃物资源化利用的意见》明确提出“源头减量、过程控制、末端利用”的治理路径。由于畜禽养殖废水中养分含量高，对其进行深度处理，一方面增加处理成本，另一方面也造成了资源的浪费。各地应坚持以资源化利用为根本思路，充分发挥畜禽养殖废水等畜禽粪污的资源特性。对于部分因环境承载力受限确实无法利用的，自2008年开始，中央财政出台农村环保“以奖促治”政策，支持地方开展农村生活污水和垃圾处理、畜禽养殖污染治理等综合整治工作。2018年，中央采取切块下达方式实施农村环境整治专项，湖南省资金量居全国前列，可统筹使用，加大对畜禽养殖废水深度处理的投入。同时，根据“谁污染谁治理”和“污染者付费”原则，建议地方政府因地制宜，逐步通过市场化方式，建立合理的收费制度，保障农村环保设施正常运行。下一步，中央财政将针对您的建议，不断总结经验，进一步完善相关政策措施。

五、关于沼气发电并网并享受相关优惠政策

“十三五”以来，湖南省生物质发电实现快速发展，装机规模不断扩大。截至2018年底，全省生物质发电装机70.3万千瓦，同比增长46%，其中农林生物质直燃或气化发电、沼气发电装机分别为41.8和4.8万千瓦。国网湖南电力认真贯彻国家工作部署，积极服务生物质发电发展。加快配套接网工程建设，“十三五”以来保障了包括沼气发电在内的32万千瓦新增项目及时并网。优化调度运行，优先保障生物质发电，实现了生物质发电的全额消纳零弃电。下一步，国家电网有限公司将加快推进“三型两网”建设，持续提高生物质发电并网运行服务水平，积极促进产业发展。

感谢您对畜牧兽医工作的关心，希望今后继续对我部工作给予支持。

农业农村部
