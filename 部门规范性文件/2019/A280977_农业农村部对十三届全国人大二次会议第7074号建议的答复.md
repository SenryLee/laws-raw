# 农业农村部对十三届全国人大二次会议第7074号建议的答复

## 对十三届全国人大二次会议第7074号建议的答复

廖长江、谭志源代表：

你们提出的关于"加强香港与内地合作，推动马术运动及相关产业发展"的建议收悉。经商体育总局，现答复如下。

一、关于提供便利措施以致从香港进入大湾区其它城市的马匹可使用进口兽药、饲料等产品

我部批准同意香港赛马会从化无疫区马场在满足以下要求的前提下，可直接进口香港批准使用的兽药、兽医器械、营养饲料添加剂、饲料及饲草，专供从化无疫区赛马自用。一是所有进口产品的使用对象仅限于从化无疫区中的香港赛马会马匹，使用地点仅限于从化无疫区内和往返广州从化及香港的运输途中。二是每次进口前，将拟进口的饲料和饲料添加剂产品名称、生产厂家及地址、进口数量和进口时间等相关信息报农业农村部畜牧兽医局以及广东省饲料管理部门备案。三是按照《农业部办公厅关于香港马会赛马训练有限公司畜牧兽医香港行政许可和监管问题意见的函》（农办医函[2012]47号）意见办理兽药进口事宜，并按要求做好兽药保存和使用管理。四是每季度末，将本季度实际进口产 品及其使用基本情况报我部畜牧兽医局。下一步，我部将根据工作需要，进一步完善相关马匹使用进口兽药、饲料等产品的政策，促进相关产业健康发展。

二、关于内地查验单位和职能部门的对接

我部会同海关总署开展了赛马往返两地检疫模式研究等工作，对进境香港赛马会马匹实行"一次审批、多次往返".内地与香港相关部门联合制定香港赛马马病年度监测计划，统一监测项目、统一抽样时间、统一监测方法、互认监测结果，统一处置程序，形成统一的监测报告。通过联合监测代替常规的出境前和进境后的批批检测，为便捷顺畅通关创造了条件。

三、关于马匹跨境运输

我部高度重视香港马匹跨境运输风险管理工作。2016年，组织全国动物卫生风险评估委员会专家组，对香港与从化无疫区的马属动物卫生状况进行了等效性评估，结果表明，香港马属动物卫生状况等效于从化无疫区，为进一步做好跨境马匹运输工作打下了良好基础。此外，我部建议香港进入内地马匹应纳入中国"纯血马登记管理系统",尤其是停留时间较长（如3个月以上）的马匹，由国际登记机构认可的"中国纯血马登记管理委员会"进行进境、出境登记，并对马匹免疫情况进行记录，这将为马匹身份认定及跨境运输检疫许可证的签发提供有效依据，达到简便、快捷的跨境运输。

四、关于大湾区内马匹兴奋剂检测及样本运输

目前，体育总局兴奋剂检测中心对运动员进行检测，对于参赛马匹违禁物质检测送至香港马会赛事化验所（国际马匹运动联合会认可的第三方检测实验室）。下一步，我部将会同有关部门，加强调研，推动建立更为便捷的测试样本运输和检测流程。

五、关于兽医及相关专业人员在大湾区执业

根据2017年6月12日颁布的《港澳台居民参加全国执业兽医资格考试及执业管理规定》（中华人民共和国农业部公告第2539号），符合报考要求的港澳台居民可在内地（大陆）任一考区报名参加全国执业兽医资格考试，考试成绩合格取得执业兽医资格的，可以申请按照和国家有关规定《执业兽医管理办法》在内地（大陆）执业。

六、关于兽医专业资格互认

内地与港澳执业兽医资格互认是未来兽医事业发展大方向，有利于促进两地兽医交流、行业发展、与国际接轨以及提升我国兽医行业整体水平。但从目前情况来看，两地资格互认还存在一些技术性难点，针对这些问题国家有关部门正在积极着手研究，做好相关准备，待时机成熟时，大力推进，争取早日实现兽医执业资格互认。

七、关于充分利用从化无疫区促进国际间马匹运送，从而在大湾区发展马产业价值链

按照中央推进粤港澳大湾区建设工作部署要求，各相关部委正在认真贯彻落实《粤港澳大湾区发展规划纲要》，研究出台支持建设的政策措施。下一步，我部将会同有关部门充分利用现有从化无疫区优势，根据工作实际，研究相关政策措施，推动实现大湾区马产业价值链发展。
