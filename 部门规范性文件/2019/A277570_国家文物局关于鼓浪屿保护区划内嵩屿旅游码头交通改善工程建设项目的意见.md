# 国家文物局关于鼓浪屿保护区划内嵩屿旅游码头交通改善工程建设项目的意见

文物保函〔2019〕466号

福建省文物局：

你局《关于鼓浪屿世界遗产地缓冲区嵩屿旅游码头交通改善工程设计方案的请示》（闽文物字〔2019〕58号）收悉。经研究，我局对在鼓浪屿保护区划内实施嵩屿旅游码头交通改善工程建设项目提出以下意见：

一、所报方案尚需作以下必要的修改和完善：

（一）进一步深化遗产影响评估，补充拟建项目对世界遗产鼓浪屿遗产区与嵩屿码头、厦门岛之间的视线影响分析及相关图纸，为完善项目设计方案提供科学依据。

（二）进一步完善拟建项目设计方案，弱化拟建候船厅屋面形式和色彩，避免采用高反光的材料；在满足功能需求和设计规范前提下，尽量压缩趸船探出距离，简化趸船形态。

（三）细化拟建项目项目施工方案，明确施工过程中的水域生态环境保护相关要求，避免对鼓浪屿周边生态环境造成破坏。

（四）补充游客容量控制要求和具体措施，以及游客和通勤人员数量监测方案，将相关数据纳入鼓浪屿世界文化遗产监测预警系统。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，按照相关法律法规的规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月21日
