# 全国爱卫会关于调整部分组成人员的通知

全爱卫发〔2019〕3号

全国爱卫会各成员单位：

根据人员变动情况和工作需要，经国务院领导同志批准，全国爱国卫生运动委员会部分委员调整如下：

国家卫生健康委副主任于学军、国家体育总局副局长李建明、全国妇联书记处书记、党组成员蔡淑敏任全国爱国卫生运动委员会委员，国家卫生健康委副主任曾益新、国家体育总局副局长高志丹、全国妇联副主席邓丽不再担任全国爱国卫生运动委员会委员。

全国爱国卫生运动委员会办公室主任由国家卫生健康委副主任于学军兼任，国家卫生健康委副主任曾益新不再兼任。

全国爱卫会
