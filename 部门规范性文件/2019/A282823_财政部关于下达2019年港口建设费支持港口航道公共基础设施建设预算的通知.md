# 财政部关于下达2019年港口建设费支持港口航道公共基础设施建设预算的通知

财建〔2019〕329号

有关省、自治区、直辖市、计划单列市财政厅（局）：

根据《港口建设费征收使用管理办法》（财综〔2011〕29号）等有关规定，以及《交通运输部关于申请下达2019年第二批港口建设费安排地方建设项目支出预算的函》（交财审函〔2019〕226号），经审核，现下达你省（区、市）2019年港口建设费用于港口建设费支持港口航道公共基础设施建设资金项目支出预算。具体项目（项目代码：Z165060000001）、金额、政府收支分类科目及绩效目标详见附件。

请尽快将资金拨付有关单位，切实加强对资金的管理和监督，提高资金使用效益。为进一步加强预算绩效管理，请在组织预算执行中对照你省（区、市）区域绩效目标做好绩效监控，确保年度绩效目标如期实现。同时，请参照中央做法，做好省（区、市）内预算绩效管理工作，将你省（区、市）绩效目标及时分解至具体项目，每个项目都要填报绩效目标及指标，作为绩效执行监控和绩效评价的依据。分项目绩效目标请抄送财政部当地监管局。

附件：1. 2019年港口建设费支持港口航道公共基础设施建设资金项目支出预算表

2. 2019年度港口建设费支持港口航道公共基础设施建设资金整体绩效目标表

3. 2019年度港口建设费支持港口航道公共基础设施建设分省绩效目标表

财政部

2019年6月13日
