# 交通运输部关于授予师睿鑫等130名同志交通运输青年科技英才称号的决定

交人教发〔2019〕8号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），中国远洋海运集团、招商局集团、中国交通建设集团，有关高等院校，交通运输职业教育教学指导委员会，部属各单位：

根据《交通运输青年科技英才评选与管理办法》（交人教发〔2016〕190号），2018年部组织开展了评选工作。在申报推荐、专家评审和公示基础上，经部党组审议，决定授予师睿鑫等130名同志交通运输青年科技英才称号。
