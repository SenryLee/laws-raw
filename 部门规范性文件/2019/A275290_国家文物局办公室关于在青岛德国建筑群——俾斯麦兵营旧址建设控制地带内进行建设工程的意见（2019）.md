# 国家文物局办公室关于在青岛德国建筑群——俾斯麦兵营旧址建设控制地带内进行建设工程的意见（2019）

## 国家文物局办公室关于在青岛德国建筑群——俾斯麦兵营旧址建设控制地带内进行建设工程的意见

办保函〔2019〕167号

山东省文物局：

你局《关于青岛德国建筑群——俾斯麦兵营旧址建设控制地带内进行建设工程的请示》（鲁文发〔2019〕9号）收悉。经研究，我局暂不同意在青岛德国建筑群——俾斯麦兵营旧址建设控制地带内进行中国海洋大学鱼山校区生命科技中心大楼建设工程。

一、对所报方案提出以下修改完善意见：

（一）进一步补充说明在俾斯麦兵营旧址建设控制地带内选址建设中国海洋大学鱼山校区生命科技中心大楼建设的必要性，并严格控制建筑高度、体量和密度，优化建筑外观设计，尽量减少对文物本体及其景观环境的影响。同时，应根据拟建项目所处区域的历史环境特点合理调整建筑总体布局，建筑风貌应与文物建筑及周边历史建筑相协调。

（二）补充该建设项目涉及的全国重点文物保护单位、省级文物保护单位及历史风貌建筑名单以及相应的保护范围、建设控制地带、历史风貌建筑保护区等图纸资料。进一步校核设计方案，统一图文表达。

（三）进一步完善文物影响评估报告，补充新建建筑与原有建筑在外观、形制和经济技术指标等方面的对比分析，并开展合规性审查；补充新建建筑区域内建筑密度和容积率等指标与相关规划适应性评估。客观、准确评估新建建筑对文物本体和环境的影响，并提出具有针对性及可操作性的保减缓措施。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年3月7日
