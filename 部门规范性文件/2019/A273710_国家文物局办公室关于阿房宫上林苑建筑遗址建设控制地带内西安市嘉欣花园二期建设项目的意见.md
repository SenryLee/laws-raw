# 国家文物局办公室关于阿房宫上林苑建筑遗址建设控制地带内西安市嘉欣花园二期建设项目的意见

办保函〔2019〕27号

陕西省文物局：

你局《关于西安市嘉欣花园二期项目涉及阿房宫上林苑建筑遗址建设控制地带的请示》（陕文物字〔2018〕190号）收悉。经研究，我局暂不同意在阿房宫上林苑建筑遗址建设控制地带内实施嘉欣花园二期建设项目。

一、所报方案应按照《阿房宫遗址保护规划》要求，进一步调整设计，核减拟建酒店建筑高度，提升项目用地绿化率，降低对文物和周边景观环境的影响。

二、进一步深化文物影响评估，认真、科学、严肃编制文物影响评估报告，校核文物影响评估报告中编制单位前后不一等错误。

三、请你局组织专业考古研究单位，在项目拟建区域开展全面的考古工作，明确该区域的文物分布和保存情况；组织相关单位认真并根据最新考古成果对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月15日
