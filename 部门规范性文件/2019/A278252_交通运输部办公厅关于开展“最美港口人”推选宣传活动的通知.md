# 交通运输部办公厅关于开展“最美港口人”推选宣传活动的通知

交办政研函〔2019〕793号

党的十八大以来，习近平总书记关于港口发展作出系列重要指示，要求“建设‘四个一流’港口”“要志在万里，努力打造世界一流的智慧港口、绿色港口”等等，充分体现了党中央对港口业的高度重视、充分肯定和殷切期望，为我国港口发展指明了方向、提供了遵循。为深入学习宣传贯彻习近平总书记关于港口发展的重要指示精神，大力培育践行社会主义核心价值观，充分展示新时期港口职工投身交通强国建设的风采，经交通运输部同意，现组织开展“最美港口人”推选宣传活动。有关事项通知如下：

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大和十九届二中、三中全会精神，大力弘扬新时期交通精神，寻找、挖掘港口一线职工先进人物，展示新时代中国港口职工风采，讲好中国港口故事，激励广大港口人新时代新担当新作为，积极投身交通强国建设，为实现中华民族伟大复兴的中国梦提供坚强的保障。

二、组织领导

“最美港口人”推选宣传活动由交通运输部政策研究室、水运局主办，中国港口协会承办。成立活动组委会，办公室设在《中国港口》杂志社。

三、推选范围和标准

面向全国港口系统一线干部职工，推选出10名“最美港口人”。

参选人物的先进事迹原则上应发生在党的十八大以来，推选人物应具备如下条件：

（一）为推动港口事业发展作出突出贡献或有重大表现，获得较大荣誉并引起社会广泛关注，以及省部级重大研究项目主要贡献者；

（二）在港口改革发展实践中，勤于思考，善于创新，不断取得工作领域的重大进展与突破；

（三）恪尽职守、爱岗敬业，在平凡的岗位上作出了不平凡的业绩；

（四）个人的经历或行为代表了社会主义核心价值观取向及时代精神，展现了港口人良好的职业素养和精神追求；

（五）在行业内外具有较好较大影响，得到社会舆论广泛好评，能够切实感动身边的群众，在培育践行社会主义核心价值观中发挥了表率作用。

四、推选方式

推选活动采用“自下而上、上下结合”的方式。省级交通运输（港口）管理部门、港口企业集团及地方港口协会、有关中央航运企业均可作为推荐单位。各推荐单位将推荐的候选人物材料报送至“最美港口人”活动组委会办公室，经由活动组委会评选，并报交通运输部精神文明建设指导委员会审定，确定入围人选和最终名单。

五、评选程序

推选宣传活动从2019年6月开始，至2019年9月结束，分四个阶段。

（一）行业广泛推荐。

2019年6月—7月31日，各单位根据活动要求宣传发动，广泛遴选，按照有关标准确定候选人，填写“最美港口人推荐表（2019）”（见附件），推荐单位要提供纸质材料原件并加盖单位公章，邮寄至活动组委会办公室。相关文字、图片、视频电子版发送至指定邮箱。

材料具体要求如下：

1.图片：候选人物工作场景照片（不超过5张），采用jpg或tif格式，分辨率不低于800万像素（3264×2448），以横图为主（其中一张图片比例为4:3），须提供推荐人物正脸照一张，图片均需提供文字说明。

2.文字：文字材料篇幅在1500字左右，并有描述性题目。

3.视频：为便于全媒体宣传，须提供不同角度介绍候选人物事迹的短视频（不超过3个），视频比例为16：9，单个视频时长1—3分钟为宜，视频格式需采用标准视频格式（MPEG/AVI/MP4/MOV），分辨率为全高清（1920×1080）。

（二）社会公示。

2019年8月1日—8月10日，组委会对各单位上报材料进行初审，并在交通运输部政务微信以及中国水运报、“中国港口协会”及“中国港口杂志”官方微信上进行公示，公示时间5个工作日。

（三）专家组评审。

2019年8月11日—8月20日，组委会组织评委专家组评审并参考社会公示结果，遴选出10名“最美港口人”。

（四）发布和宣传。

2019年9月，按程序审定后，正式向社会发布“最美港口人”名单，在《中国港口》、中国水运报等行业媒体开展系列宣传报道。

六、工作要求

（一）高度重视，精心组织。要充分认识推选宣传活动对提升行业软实力、树立港口好形象、推动交通强国建设的重要作用，加强组织领导，明确专门负责同志，健全工作机制，提供工作保障。

（二）创新手段，广泛发动。要引导参选单位充分发掘宣传身边典型，汇聚强大正能量。充分运用传统媒体、新兴媒体以及组织宣传手段做好动员，把推选宣传活动作为宣传展示港口行业良好形象的重要契机，提升推选宣传活动的传播力、引导力、影响力、公信力。

（三）依法合规，加强统筹。要坚持公开、公正、客观、真实的原则，严格遵守推选标准和流程，确保推选宣传活动权威。
