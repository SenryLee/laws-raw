# 农业农村部对十三届全国人大二次会议第9028号建议的答复

## 对十三届全国人大二次会议第9028号建议的答复

你们提出的关于加强边疆民族地区农业专业人才队伍建设的建议收悉。经商发展改革委、教育部、科技部、国家民委、财政部、人力资源社会保障部，现答复如下。

乡村振兴，关键在人。助力产业脱贫、带动小农户发展、加快推进农业农村现代化，迫切需要培养和造就一支高素质的农业专业人才队伍。当前，我国农业专业人才队伍总体还相对薄弱，这一问题在边疆民族地区尤为突出。因此，采取切实措施支持边疆民族地区加强农业专业人才队伍建设，就显得十分必要且非常迫切。

一、关于支持边疆民族地区加强农业专业人才队伍建设

党中央、国务院高度重视边疆民族地区发展，把支持边疆民族地区人才队伍建设作为一项重要工作，予以统筹部署。各有关部门采取一系列政策措施，支持边疆民族地区加强人才队伍建设。农业农村部会同中央组织部开展农村实用人才带头人和大学生村官示范培训，会同财政部深入实施新型职业农民培育工程，支持边疆民族地区大力培养农村实用人才。科技部组织实施"三区"人才支持计划科技人员专项计划，在创新人才推进计划中专门对边疆民族地区给予倾斜支持，支持广西等省区建立国际科技合作基地，优化国际创新资源配置。教育部整合设立"支持地方高校改革发展资金",加大了对边疆民族地区的支持力度，推动"长江学者奖励计划"向边疆民族地区倾斜，支持广西等省区提升现代职业教育质量，开展"1+X"证书制度试点等。

下一步，各部门将认真贯彻落实中央决策部署，进一步加大对边疆民族地区农业专业人才队伍建设的支持力度。一是继续加强对边疆民族地区农业专业人才培养的政策支持。加强分类指导，继续在资金、项目、政策等方面加大对边疆民族地区的倾斜支持。二是加大边疆民族地区农村实用人才培养力度。面向包括边疆民族地区在内的贫困地区，开展农村实用人才带头人和大学生村官示范培训。三是引导农业科技人才向边疆民族地区流动。深化农业技术人员职称制度改革，鼓励农业科技人才向艰苦边远地区和基层一线流动。

二、关于开展农业专业人才队伍建设专题调研

人才振兴是乡村振兴的基础。农业专业人才队伍建设是一项系统工程，基础薄弱，涉及面广，需要加强政策措施的相互衔接和各方面的协同配合。因此，有必要从国家层面予以高度重视和统筹协调，推动各有关部门加强协作，着力解决农业专业人才队伍建设中存在的突出问题。下一步，我们将择机专门向国务院汇报，建议适时组织相关部门开展联合专题调研，深入了解当前全国特别是边疆民族地区农业专业人才队伍建设的现状与问题，结合新时代对农业专业人才提出的新要求，推动构建包括教育支持、就业倾斜、人才激励、创业扶持等方面相互衔接、系统配套的政策体系，并明确相关部门的责任，切实加大农业专业人才队伍建设力度。

三、关于支持边疆民族地区加强科技合作平台建设

加强科技合作平台建设，是促进边疆民族地区农业专业人才培养的有效抓手。下一步，我们将继续加大对边疆民族地区科技合作平台建设的支持力度。一是统筹考虑相关国家重点实验室建设。在开展重组国家重点实验室体系相关工作中，统筹考虑代表们提出的支持建设甘蔗生物学国家重点实验室、亚热带农业生物资源保护与利用国家重点实验室的建议。二是支持广西加强国际科技创新平台建设。充分发挥广西桥头堡作用，继续支持广西推进中国—东盟技术转移中心建设，将中国—东盟技术转移与创新合作大会打造成品牌活动，为中国与东盟国家开展技术合作与交流搭建全方位平台。三是提升中国—东盟科技伙伴计划合作水平。支持广西大学等单位与东盟开展科技人文交流，共建联合实验室、科技园区，加强技术转移等方面的合作。四是支持技术和产品面向发展中国家走出去。通过科技外交官的渠道和信息优势，结合地方举办的各类活动，组织科技外交官服务行动，为包括广西在内的边疆民族地区企业、研究机构和大学开展技术引进、联合研究和设立海外研发中心提供服务。

四、关于支持边疆民族地区发展高等教育和职业教育

百年大计，教育为本。大力发展边疆民族地区农业高等教育和职业教育，是加强农业专业人才队伍建设的重要基础性工作。下一步，我们将继续加大对广西等边疆民族地区高等教育和职业教育的支持力度。一是支持高校农林专业建设和教育教学改革。支持边疆民族地区高校结合农业农村发展人才需求，服务新产业新业态发展，优化调整专业设置。在延续前期政策倾斜举措的基础上，持续加大"长江学者奖励计划"对边疆民族地区的支持力度。二是支持边疆民族地区发展高质量职业教育。推动教育部与广西签订《国家职业教育改革实施方案》备忘录，指导和支持广西先行先试，深化职业教育综合改革，不断提升职业教育现代化水平。指导广西落实开展职业教育综合改革试点探索的职责，全面提升职业教育服务产业发展和扶贫富民能力水平，为边疆民族地区加快发展职业教育提供有益的经验借鉴。三是加大项目资金支持力度。在地方高校学生资助补助经费、支持地方高校发展专项资金等财政专项中，继续对边疆民族地区高校予以倾斜支持。在实施产教融合工程、现代职业教育质量提升计划、中国特色高水平高职学校和专业建设、公共实训基地建设等重大项目中，对广西等边疆民族地区予以指导。

感谢你们对"三农"工作的关心，希望今后继续对我部工作予以支持。
