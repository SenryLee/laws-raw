# 生态环境部办公厅关于解除北京市丰台区污水处理设施管理所挂牌督办的通知

## 关于解除北京市丰台区污水处理设施管理所挂牌督办的通知

环办执法函〔2019〕675号

北京市生态环境局：

2019年2月1日，我部印发《关于对5家重点排污单位主要污染物排放严重超标问题挂牌督办的通知》（环办执法函〔2019〕137号），对北京市丰台区污水处理设施管理所进行挂牌督办。按照督办要求，你局督促相关地方和排污单位积极整改，并向我部提交了解除该排污单位挂牌督办的申请。

经现场核查整改情况并核实排污单位自动监测数据，北京市丰台区污水处理设施管理所基本达到了督办要求，同意对其解除挂牌督办。请你局继续加强监督管理，督促排污单位认真履行环境保护主体责任，确保污染物稳定达标排放。

生态环境部办公厅

2019年8月5日
