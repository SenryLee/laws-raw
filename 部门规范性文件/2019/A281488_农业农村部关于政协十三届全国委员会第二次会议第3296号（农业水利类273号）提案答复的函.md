# 农业农村部关于政协十三届全国委员会第二次会议第3296号（农业水利类273号）提案答复的函

## 关于政协十三届全国委员会第二次会议第3296号（农业水利类273号）提案答复的函

农办案〔2019〕60号

毕飞宇委员：

您提出的关于加快实施江豚等长江珍稀动物保护拯救工程的提案收悉。经商生态环境部、国家林业和草原局，现答复如下。

一、相关工作开展情况

按照党的十九大"实施重要生态系统保护和修复重大工程，优化生态安全屏障体系，构建生态廊道和生物多样性保护网络，提升生态系统质量和稳定性"的决策部署，我部坚持把以长江为重点的水生生物保护行动作为农业绿色发展五大行动计划之一和农业农村部重点工作，积极探索、科学谋划、狠抓落实，会同有关部门全力推进落实长江江豚、中华鲟等珍稀濒危物种保护工作。

（一）强化水生生物栖息地保护。我部积极推动出台《国务院办公厅关于加强长江水生生物保护工作的意见》（以下简称《意见》），明确要求"在重要水生生物栖息地和关键生境建立自然保护区、水产种质资源保护区或其他保护地，实行严格的保护和管理".会同生态环境部、水利部共同发布了《重点流域水生生物多样性保护方案》，重点保护中华鲟、长江江豚、白鲟、达氏鲟、胭脂鱼等鱼类及其栖息地。国家林草局在全国范围内开展自然保护地检查，掌握各类自然保护地现状，加强自然保护地管理，新建和调整了一批自然保护区，包括两处涉及中华鲟的自然保护区，研究提出新建和整合优化相关保护区的意见。推进安徽铜陵、芜湖等地在野生动物重要栖息地建立自然保护区。

（二）加强珍稀濒危物种保护。我部发布长江江豚、中华鲟、长江鲟等拯救行动计划，联合环境保护部、有关地方政府在湖北天鹅洲白鱀豚国家级自然保护区、铜陵淡水豚国家级自然保护区、湖北何王庙（湖南集成垸）江豚省级自然保护区、安庆市江豚自然保护区等地推进长江江豚迁地保护工作，不断扩大迁地种群规模。2018年起，推动在珠海长隆海洋公园建立长江江豚人工驯养繁育和科普教育基地，加大科普宣教力度。每年组织开展中华鲟增殖放流活动，补充中华鲟野外资源，推动在三峡库区、长江口建设中华鲟接力保种基地，开展中华鲟生活史关键环节生境保护和分段驯养繁育。依托有基因保存条件的科研院所、企业等单位，建立中华鲟、长江江豚等珍稀濒危物种遗传家谱和个体信息库，建设长江水域重要鱼类物种活体样本库和标本库。依托上海海洋大学成立长江水域生态保护战略研究中心，凝聚国内外高层次专业力量和各类资源，多学科交叉研究长江大保护需求下的长江水生生物资源保护、水域生态环境保护及修复的法规、政策、制度、规划和措施，推进研究成果转化，为长江水生生物保护工作提供智力支撑。探索建立以中国科学院水生生物研究所、中国水产科学研究院淡水渔业研究中心为首的长江江豚保护科学研究体系，以中国水产科学研究院长江水产研究所为首的中华鲟保护科学研究体系，深化长江江豚、中华鲟等长江珍稀濒危物种的生物学保护研究，加快人工驯养和繁育技术攻关，推动建立中华鲟等珍稀濒危物种保护长效机制。

（三）加大水生生物保护宣传教育力度。我部积极推动成立长江江豚、中华鲟拯救联盟，充分发挥长江珍稀濒危物种保护主管部门、保护区、科研院所、社会组织作用，构建信息共享、社会化参与协作的保护工作平台。推动建立江西鄱阳湖湖口、湖北何王庙江豚迁地保护区、湖南洞庭湖、安徽安庆江豚保护区等协助巡护示范点，组织社会力量参与长江江豚协助巡护工作。2014年，我部联合环境保护部、水利部主办"十大河流水生生物名片征集活动",全国共计25万人次参与投票，覆盖全国22个省市地区，长江江豚被评为长江水生生物名片，提升了公众对水生生物资源的认识，激发了公众保护水生生物的自觉性和主动性。2015年，环境保护部联合中科院发布《中国生物多样性红色名录—脊椎动物卷》，江豚、中华鲟、白鲟等物种被评为极危等级，提升了公众对上述物种的关注程度和保护意识。今年，我部联合交通运输部、水利部及世界自然基金会组织开展了以"行走长江母亲河，谱写保护新篇章"为主题的长江水生生物保护宣传系列活动，活动贯穿长江全流域江段2800多公里，历时23天，组织落地活动20余场。通过长江大保护专题研讨、公众开放日活动、大型水生生物保护知识展、科普讲座、实地走访和渔民座谈、增殖放流等活动，广泛宣传长江水生生物濒危现状和保护政策措施，号召社会各界共同参与长江大保护。宣传活动被包括中央人民政府网在内的国内外媒体争相报道和转载，覆盖人群6000余万，大大提升公众对长江江豚等珍稀濒危物种的保护意识。

（四）大力推进长江流域重点水域禁捕和非法捕捞集中整治。我部发布《农业部关于公布长江流域率先全面禁捕的水生生物保护区名录的通告》（农业部通告〔2017〕6号），推进长江流域332个水生生物保护区逐步施行全面禁捕。联合财政部、人力资源和社会保障部出台《长江流域重点水域禁捕和建立补偿制度实施方案》，推进长江流域捕捞渔民退捕上岸，努力实现2019年长江水生生物保护区禁捕、2020年长江流域重点水域全面禁捕的目标，促进水生生物资源休养生息。生态环境部编制了《重点流域水污染防治规划（2016—2020）》，加强水污染治理，并指导长江经济带11省市将长江流域重点湿地水域等生物物种栖息地划为不可逾越的生态保护红线，划定红线面积51.84万平方公里，约占11省市国土面积的25%.生态环境部联合我部、水利部等7部委开展"绿盾2017""绿盾2018"专项监督检查行动，对长江经济带各类突出环境问题进行查处，公开约谈了重庆石柱县水磨溪湿地自然保护区、镇江长江豚类省级自然保护区和安徽扬子鳄国家级自然保护区有关负责人，发挥了震慑及警示教育作用。

二、下一步工作打算

下一步，我部将会同有关部门继续深入贯彻落实习近平生态文明思想和党的十九大精神，坚持以严格执法监管和水生生物保护为抓手，进一步加强以中华鲟、长江江豚、长江鲟为重点的长江珍稀濒危水生生物保护工作。

（一）进一步强化栖息地保护工作。国家林草局将认真贯彻落实《关于建立以国家公园为主体的自然保护地体系指导意见》，推进建立以国家公园为主题的自然保护地体系；推动出台《自然保护地法》，修订《自然保护区条例》，整合优化各类保护区，推动各地在水生野生动物重要栖息地新建自然保护区；加强保护地管理，对长江流域自然保护地开展遥感监测、红外相机布设和视频直播等工作，提升监测监督和保护宣传力度。

（二）进一步加强珍稀濒危物种保护。我部将编制《长江珍稀水生生物保护工程建设规划》，加快实施长江江豚、中华鲟、长江鲟等拯救行动计划；创新中华鲟等珍稀濒危物种保护管理体制，借鉴大熊猫保护管理模式，推进建立以中华鲟、长江江豚为重点的长江水生珍稀濒危物种保护管理机构；推动国家财政设立长江水生珍稀濒危物种保护专项，加大对中华鲟、长江江豚等珍稀濒危物种保护的经费投入；开展中华鲟保护与可持续利用研究，加快推进长江江豚进入水族馆，在有条件的科研单位和水族馆建设长江珍稀濒危物种人工驯养繁育和科普教育基地，加大长江江豚、中华鲟增殖放流力度，进一步推动长江珍稀濒危物种野生种群恢复重建。

（三）加大执法监管和生态修复力度。我部将联合相关部门共同推动实施《重点流域水生生物多样性保护方案》，坚守生态保护红线，持续加强水污染防治，继续开展"绿盾"系列专项督查行动，坚决查处破坏自然保护区的违法违规行为；继续推进落实长江流域重点水域禁捕工作，加快实施增殖放流、栖息地修复、生态调度、灌江纳苗、河湖连通等生态保护修复措施，努力修复长江上游鱼类原有生态功能，保护长江水生生物资源。

（四）进一步营造全社会参与长江大保护的良好氛围。我部将会同有关部门建立健全长江流域上下游横向生态保护补偿机制，推动设立长江水生生物保护基金，努力争取有关企业、社会公众的支持资助，重点加大对长江上游、重要支流、鄱阳湖、洞庭湖、干流和河口等重点生态功能区的生态补偿支持力度；生态环境部将积极用好2020年在我国举办《生物多样性公约》第十五次缔约方大会契机，全面宣传我国生物多样性保护工作。

感谢您对长江水生生物资源保护工作的重视和关注，希望您继续关心和支持农业农村部工作。

农业农村部

2019年8月30日
