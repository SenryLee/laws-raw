# 国家煤矿安监局办公室关于印发煤矿建设项目安全设施设计审查、竣工验收报告书规范文本的通知

煤安监司办〔2019〕30号

各省级煤矿安全监察局：

为进一步规范煤矿建设项目安全设施设计审查工作，指导煤矿企业开展安全设施竣工验收活动，结合职业卫生监督职责调整，根据修订后的《煤矿建设项目安全设施设计审查和竣工验收规范》（AQ1055-2018），国家煤矿安监局组织对煤矿建设项目安全设施设计审查、竣工验收报告书规范文本（见附件1、4）及有关表格（见附件2、3、5、6）进行了修改，现印发给你们，请遵照执行，并转发有关煤矿企业（电子版可在国家煤矿安监局网站下载）。

国家煤矿安全监察局《关于印发<煤矿建设项目安全设施设计审查与竣工验收报告书>规范文本的通知》（煤安监监察〔2009〕9号）和《关于修改增加<煤矿建设项目安全设施设计审查与竣工验收报告书>部分内容的通知》（煤安监监察〔2012〕32号）同时废止。

附件：

1.××（项目名称）安全设施设计审查报告书

2.井工煤矿安全设施设计审查表格

3.露天煤矿安全设施设计审查表格

4.××（项目名称）安全设施竣工验收报告书

5.井工煤矿安全设施竣工验收表格

6.露天煤矿安全设施竣工验收表格

国家煤矿安全监察局办公室
