# 国家民委办公厅、共青团中央办公厅关于公布“建设伟大祖国建设美丽家乡”主题征文活动推荐展示作品和优秀组织单位的通知

## 国家民委办公厅　共青团中央办公厅关于公布“建设伟大祖国　建设美丽家乡”主题征文活动推荐展示作品和优秀组织单位的通知

民办发〔2019〕44号

各省、自治区、直辖市及新疆生产建设兵团民（宗）委（厅、局）、团委：

为深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，深化民族团结进步教育，铸牢中华民族共同体意识，推动“建设伟大祖国 建设美丽家乡”主题教育活动继续深入开展，国家民委、共青团中央于2018年联合组织开展了“建设伟大祖国　建设美丽家乡”主题征文活动。活动启动以来，各地精心组织，民族地区各级各类学校、民族院校、内地民族班（学校）积极参与，经省级遴选、专家审读以及工作组复核，确定《祖国处处是家乡》等100篇作品进入全国展示，将于近期在新华网进行集中展示。

同时，综合考虑各地活动组织和推荐作品入围情况，确定安徽省民委、省教育厅、共青团省委等12个省市的有关单位为优秀组织单位。

希望各地在今后的工作中，进一步推动“建设伟大祖国　建设美丽家乡”主题教育活动更加深入广泛开展，引导广大青少年学生珍惜美好时光，砥砺品德，陶冶情操，刻苦学习，全面发展，掌握真才实学，努力成为建设伟大祖国、建设美丽家乡的有用之才、栋梁之材，为促进民族团结进步、实现共同繁荣发展做出应有贡献。

附件：１.建设伟大祖国　建设美丽家乡主题征文活动推荐展示作品汇总表

２.“建设伟大祖国 建设美丽家乡”主题征文活动优秀组织单位

国家民委办公厅　共青团中央办公厅
