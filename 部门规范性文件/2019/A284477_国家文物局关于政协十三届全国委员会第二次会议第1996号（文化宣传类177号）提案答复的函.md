# 国家文物局关于政协十三届全国委员会第二次会议第1996号（文化宣传类177号）提案答复的函

文物保函〔2019〕882号

许瑞生委员：

您提出的《关于设立完善文化遗产建筑“岁修”制度的提案》已交由我局会同财政部、中央宣传部办理，现答复如下：

自古以来，遍布我国各地的文物建筑一般都有固定的保养维护、岁修制度，其中以故宫、皇家陵寝等皇家建筑为代表，在《大清会典》、故宫修缮档案等文献中都可以找到皇家建筑岁修的大量例证。中华人民共和国成立后，各地重要的文物建筑也基本承袭了这一传统，为延续文物的真实性、完整性发挥了重要作用。1982年颁布的《中华人民共和国文物保护法》明确把保养与修缮作为文物保护的基本手段之一。

国家一直高度重视文物建筑的岁修工作。《国家文物事业发展“十三五”规划》提出，“十三五”时期，国家文物局将推动文物保护实现“两个转变”：由注重抢救性保护向抢救性与预防性保护并重转变，由注重文物本体保护向文物本体与周边环境、文化生态的整体保护转变，确保文物安全。2018年，中共中央办公厅、国务院办公厅印发的《关于加强文物保护利用改革的若干意见》中明确指出，“完善文物保护投入机制。支持文物保护由抢救性保护向抢救性与预防性保护并重……转变。”

国家文物局于2015年3月印发了《古建筑保养维护操作规程》，2017年组织编制完成《古建筑结构健康监测技术导则》，2019年组织开展了不可移动文物预防性保护的国际理念及实践课题研究，文物建筑保养岁修工作的技术支撑不断强化。2018年，财政部、国家文物局印发了《国家文物保护专项资金管理办法》（财文〔2018〕178号），首次确立了对不可移动文物预防性保护项目的资金支持渠道。

下一步，国家文物局将会同财政部、中央宣传部等部门从以下几个方面支持做好文物建筑的岁修工作：

一、督促地方人民政府切实履行文物建筑管理职责。根据《中华人民共和国文物保护法》《国务院关于进一步加强文物工作的指导意见》《国务院办公厅关于进一步加强文物安全工作的实施意见》，县级以上人民政府具有文物保护主体责任，负责辖区内各级不可移动文物的日常保护管理经费。国家文物局将会同相关部门，进一步督促、指导地方各级人民政府切实履行职责，配备充足的机构、人员、经费用于文物建筑的日常管理和保养维护，健全完善相关工作制度。

二、探索建立文物建筑的预防性保护制度。根据我国文物建筑岁修实践，参照国际上较为通行的“专业检修巡查小组”模式，国家文物局将结合不可移动文物预防性保护工作的推进，选取部分较为成熟的区域作为试点，重点开展文物建筑构件粘补、门窗整修、抹灰油饰修缮等内容，明确预防性保护项目编制、立项、实施、监管等环节，探索建立符合我国国情的文物建筑预防性保护制度，进一步完善文物建筑的岁修保护工作。

三、推动完善文物建筑岁修的技术支撑体系。国家文物局将在《古建筑保养维护操作规程》的基础上，研究编制细化的文物建筑专业检修技术导则，引进国际上较为成熟的细分工种技术手册，并推动各地编制适用于自身特点的相关技术文件，确保文物建筑岁修工作的科学开展。

衷心感谢您对文物事业的关心与支持！

国家文物局
