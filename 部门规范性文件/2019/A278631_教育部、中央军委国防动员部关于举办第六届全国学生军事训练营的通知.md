# 教育部、中央军委国防动员部关于举办第六届全国学生军事训练营的通知

## 教育部　中央军委国防动员部关于举办第六届全国学生军事训练营的通知

教体艺函〔2019〕3号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局，各军兵种、武警部队参谋部，各省军区（卫戍区、警备区）：

为贯彻落实《国务院办公厅 中央军委办公厅关于深化学生军事训练改革的意见》关于“定期举办学生军事训练营”的明确要求，按照每年依托一个军种、聚焦一个主题的总体安排，教育部、中央军委国防动员部定于2019年第三季度依托火箭军举办第六届全国学生军事训练营（以下简称军事训练营）。现将有关事项通知如下。

一、指导思想

本届军事训练营以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大精神，全面贯彻全国教育大会精神，围绕落实立德树人根本任务和强军目标根本要求，着力学习掌握火箭军知识，传承火箭军优良传统，弘扬火箭军特色文化，坚持军事理论与军事技能相结合、实地见学与训练体验相结合，不断引领学生军事训练创新发展，充分发挥学生军训综合育人功能，切实加强国家安全和国防形势教育，全面激发学生献身国防、报效国家的热情，扎实做好高素质后备兵员训练储备工作，推动形成全社会关心国防、热爱国防、建设国防、保卫国防的思想共识和自觉行动。

二、时间和地点

时间：2019年7月29日—8月9日。

地点：火箭军工程大学。

三、主题和内容

本届军事训练营以“御剑东风·激扬青春”为主题，包含以下五个方面内容：

（一）军事理论教学。组织以习近平强军思想、我国国防安全、火箭军发展史、火箭军武器装备等为重点的军事理论教学。

（二）军事技能训练。组织以轻武器射击、格斗术、行军拉练、识图用图、电磁频谱监测、核生化防护、战场医疗救护、心理行为训练等为重点的军事技能训练。

（三）观摩体验。组织参观火箭军装备展、部队“四个秩序”，观摩武器装备实装操作演示，现场讲解武器装备知识。

（四）实地见学。赴习仲勋故居和纪念馆进行革命传统教育，赴秦始皇兵马俑博物馆进行军事历史文化教育。

（五）军营文化活动。组织教唱军营歌曲、观看军事题材影视片和教育片，举行升旗仪式、开展主题班会、举办军营联欢会和军体运动会等。

教学训练结果由教育部国防教育办公室和全军学生军训工作办公室予以公布。

四、参加单位和人员

各地在组织本省份学生开展军事训练营基础上，选拔普通高等学校和高中阶段学校学生参加本届军事训练营。各省级教育行政部门体卫艺处、省军区学生军训工作办公室各1名负责同志带队，各军兵种、武警部队各1名负责学生军训工作同志参加。

（一）普通高等学校。从省域内2所普通高等学校选拔已修完军事课的二年级在校学生8人，每校4人（男女生各半，须为非国防生，非体育、公安等专业的学生），在学生选拔上重点向“双一流”建设高等学校、部属高等学校、部省合建高等学校倾斜，向涉军专业院校倾斜，向学生干部倾斜。

（二）高中阶段学校。从省域内2所办学水平高，积极发展素质教育的高中阶段学校选拔已接受过军事训练的二年级在校学生8人，每校4人（男女生各半）。

五、有关要求

（一）各参加单位要把军事训练营作为检验学生军事训练效果、增强学生国防观念、推进学生军事训练工作创新发展的重要抓手，切实加强组织领导，科学筹划，周密安排，确保安全圆满顺利。

（二）本届军事训练营由火箭军承办，陕西省教育厅、陕西省军区战备建设局协办，火箭军工程大学负责组织军事训练营教学训练、日常管理、食宿被装等相关保障工作。

（三）各参加单位要切实把学生安全管理教育工作摆上重要位置，严格按照有关规定做好实弹射击、人员输送、饮食卫生等方面的安全保障工作，入营报到前要进行例行体检，统一为学生购买人身意外伤害保险。

（四）请各参加单位于2019年7月15日前将报名表（见附件）的电子版和盖章扫描件发至电子邮件（sxtwyc@126.com），联系人及电话：陕西省教育厅台炳龙，029-88668891，18991800199。于2019年7月25日前将参训人员抵达西安的车次、航班报火箭军工程大学，于2019年7月29日到火箭军工程大学报到，届时将组织接站，联系人及电话：陶海军，029-84742044,15802999262。报到地址：陕西省西安市灞桥区同心路2号。

（五）本届军事训练营费用由组委会承担，往返交通费由各单位自理。

军事训练营实施方案和工作规程等有关事宜另行通知。
