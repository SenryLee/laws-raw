# 农业农村部关于政协十三届全国委员会第二次会议第1203号（教育类140号）提案答复的函

## 关于政协十三届全国委员会第二次会议第1203号（教育类140号）提案答复的函

农办案〔2019〕112号

民进中央：

“关于发展涉农职业教育，培养新型职业农民的提案”收悉。经商教育部、财政部，现答复如下。

一、关于理顺涉农职业教育与农民培训的关系

技能培训是提升农民综合素质和生产技能的重要途径，职业教育是培养高素质农民的重要载体，具有系统性培养优势。我部和有关部门十分重视，坚持技能培训和职业教育两条腿走路，培养具备现代生产技能和经营能力的复合型农业农村人才。

一是促进教育与培训相结合。我部积极推进职业培训与职业教育衔接贯通培养，实行农学结合、弹性学制、送教下乡等培养模式，就地就近定向培养具有中高等学历的高素质农民。今年我部联合教育部印发的《关于做好高职扩招培养高素质农民有关工作的通知》明确要求，对农民学员学习培训经历、职业技术技能、从业经历等，按地方或学校有关规定和程序认定为学历教育相关课程学分。2017年，中央农业广播电视学校（简称“农广校”）印发了《关于推进中职教育与职业培训衔接培养新型职业农民的指导意见》，充分发挥农广校体系的作用优势，从培养对象、课程内容、教学过程、学习成果、路径方式等五个方面推进中职教育和职业培训有效衔接，系统培养高素质农民。同时，我部鼓励参加过培训的农业经理人和从事专业技能与服务工作的农民继续参加职业技能鉴定，提升专业技能素质。二是引导多方资源参与农民培训。我部加快建立开放的农民教育培训体系，统筹用好农广校、涉农院校、县级职教中心、农村成人文化技术学校、农业科研院所、农技推广机构等教育培训资源，引导鼓励农业龙头企业、农民合作社、农民专业技术协会等发挥自身优势参与教育培训工作，采取政府购买服务等方式给予相应补助。其中，涉农院校充分发挥了科技研究、人才培养、示范推广、服务平台等优势，承担大量农民培训任务，提供了实践场所和教学资源，受到农民广泛欢迎。三是开展分层培训。我部加快构建立体化培训格局，部级层面负责组织杰出农民和师资培训，各省着力抓好农业龙头企业及示范性合作社带头人、农业经理人、培训师资等拓展培训，县级重点抓好实用型、技能型农民培训。

下一步，我部联合有关部门将进一步推进农业职业教育和农民培训有效衔接，研究出台相关文件，支持农业院校等教育资源参与农民培训，共同培养高素质农业生产经营者队伍。

二、关于设定不同目标分类培养

我部联合有关部门注重围绕乡村振兴需求和农民学习特点，改进内容、创新方式、强化服务，通过教育培训提升农民综合素质能力。

2014年，我部联合教育部印发《中等职业学校新型职业农民培养方案（试行）》，50岁以下、具有初中毕业以上学历（或具有同等学力）、主要从事农业生产的务农农民以及农村新增劳动力，可以报名国家承认的涉农中、高等职业学校，完成学业后获得国家承认的中等职业教育学历。今年，高职扩招培养高素质农民重点培养现职农村“两委”班子成员、新型农业经营主体、乡村社会服务组织带头人、农业技术人员、乡村致富带头人、退役军人、返乡农民工等，培养院校针对高素质农民学习需要，制定切实可行的人才培养方案。

2016年，教育部联合全国总工会印发《农民工学历与能力提升行动计划—“求学圆梦行动”实施方案》，通过建立学历与非学历教育并重，产教融合、校企合作、工学结合的农民工继续教育新模式，实施“求学圆梦行动”，提升农民工学历层次和技术技能水平。截至目前，据不完全统计，有21个省市近300所高校参与其中，学历继续教育招生总数逾100万人，非学历继续教育培训共计61万人次。

关于设立农民创业基金，中央财政已有相关政策措施，通过就业补助资金、中小企业发展专项资金、普惠金融发展专项资金中的创业担保贷款贴息等渠道，加大对农民创业就业的支持投入力度，符合条件的农民可按程序申请予以支持。鼓励有条件的地方结合本地区产业实际，研究制定相关产业支持政策，促进农民创业就业。

下一步，我部将以培育对象为中心，遵循农民需求、遵循客观规律，精心组织实施教育和培训，抓实落细关键环节，不断发展壮大适应乡村振兴战略和现代农业发展需求的高素质农民队伍。

三、关于培养内容

农民教育培训工作紧紧围绕促进产业兴旺目标任务，坚持面向产业、融入产业、服务产业，根据产业需求调整年度工作任务和培养目标，统筹谋划培养内容，促进农民在挖掘产业特色、推进产业融合、强化主体协作、运用先进农业科技等方面发挥辐射带动作用。按照我部今年印发的《关于做好2019年农民教育培训工作的通知》要求，农民培训内容重点围绕推动农业结构调整和提升乡村产业水平开展教育培训，涵盖“一村一品、一乡一业”、特色农产品品牌创建、农业信息进村入户、一二三产业融合发展、农村人居环境改善等重点工作和领域。今年高职扩招培养高素质农民重点围绕现代农业生产、经营、管理、服务等先进知识、先进技术，以及专业化、标准化、规模化农业生产经营管理设置教学内容。

下一步，我部联合教育部将继续围绕现代农业发展需求设置农民教育培训课程和师资，培养适应乡村振兴战略的高水平人才。

四、关于加大经费投入和管理力度

党的十八大以来，中央财政支持农民培训工作的资金持续增长，从每年11亿元增长到20亿元，累计投入达到90.9亿元。在中央财政带动下，各部门加大资金和政策支持力度，每年配套投入资金在5亿元左右，在教育培训、条件能力、跟踪服务等方面支持农民全面发展。同时，各地按照“谁使用、谁负责”的原则强化项目资金监管，确保资金使用效益。

为引导支持各地职业教育改革发展，中央财政设立现代职业教育质量提升计划专项资金，支持各地巩固提高高等职业院校生均拨款水平，改善中等职业学校办学条件，实施职业院校教师素质提高计划，落实职业教育改革相关任务等。在中等职业教育阶段，积极支持改善办学条件，促进中职服务乡村振兴战略，为广大农村培养技术技能型人才。在高等职业教育阶段，积极落实今年高职扩招任务，针对农民工、高素质农民等群体单列计划。在学生资助政策体系方面，近年来财政部会同教育部等部门不断完善各教育阶段的家庭经济困难学生资助政策，已经建立起了覆盖所有教育阶段、形式多样、功能完备的学生资助政策体系，符合条件的农村学生可按规定享受相应的资助政策。

下一步，中央财政将继续支持农民培训和农业职业教育发展，为乡村振兴提供坚实人才保障。

感谢对农民教育培训工作的关心，希望今后继续对我部工作给予支持。

农业农村部

2019年8月30日
