# 公开市场业务交易公告[2019]第91号——关于2019年5月14日人民银行开展中期借贷便利（MLF）操作2000亿元的公告

## 公开市场业务交易公告

[2019]第91号

为对冲税期等因素的影响，2019年5月14日人民银行开展中期借贷便利（MLF）操作2000亿元，比当日到期量多440亿元。今日不开展逆回购操作。

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 1年 | 2000亿元 | 3.30% |

中国人民银行公开市场业务操作室

二〇一九年五月十四日
