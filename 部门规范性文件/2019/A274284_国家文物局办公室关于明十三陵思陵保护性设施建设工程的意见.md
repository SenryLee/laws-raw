# 国家文物局办公室关于明十三陵思陵保护性设施建设工程的意见

办保函〔2019〕56号

北京市文物局：

你局《关于明十三陵思陵保护设施工程方案的请示》（京文物〔2018〕1680号）。经研究，我局暂不同意在明十三陵思陵保护范围内实施保护性设施建设项目。

一、对所报方案提出以下修改完善意见：

（一）补充文物病害勘查，客观全面分析评估御碑和祾恩门遗址保存状态和面临的问题，研究提出有针对性的保护措施。进一步论证大规模开展保护性设施建设的必要性，如御碑防风雨问题可考虑采用玻璃罩方式解决。

（二）所报方案含大量文物原址重建内容，应进一步明确项目定位。重建祾恩门对建筑台明的保护作用有限，建议重点做好台明遗址的归安保护。

（三）进一步研究论证在基址上铺设木栈道做法的必要性。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。同时应按照《古建筑保养维护操作规程》，做好明十三陵思陵的日常保养维护工作。

专此函复。

国家文物局办公室

2019年1月23日
