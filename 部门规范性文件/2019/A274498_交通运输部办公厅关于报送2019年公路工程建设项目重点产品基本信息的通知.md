# 交通运输部办公厅关于报送2019年公路工程建设项目重点产品基本信息的通知

交办科技函〔2019〕253号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

为加强交通运输重点产品质量监督管理，提升工程建设质量和安全水平，促进行业高质量发展，部将组织开展2019年度产品质量行业监督抽查，现将有关事项通知如下：

一、抽查产品

抽查产品包括路面标线涂料、路面标线用玻璃珠、公路桥梁支座、高密度聚乙烯硅芯塑料管、公路波形梁钢护栏、玻璃钢管箱、公路隧道LED照明灯具、预应力混凝土用钢绞线等8种公路工程用产品。

二、有关要求

请你单位根据本地区重点公路工程建设项目实施安排，认真组织填报《2019年公路工程建设项目重点产品基本信息表》（见附件），并于3月10日前反馈。

联 系 人：交通运输部科技司 赵晓辉，联系方式：010-65292199、65292100（兼传真），电子邮箱：zhaoxh@mot.gov.cn
