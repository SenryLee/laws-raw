# 全国爱卫会关于印发2019年全国爱国卫生工作要点的通知

全爱卫发〔2019〕4号

全国爱卫会各成员单位：

为全面贯彻党的十九大和十九届二中、三中全会精神，有效落实全国卫生与健康大会精神和《“健康中国2030”规划纲要》要求，完成爱国卫生各项重点任务，推进健康中国建设，根据各成员单位提出的年度爱国卫生工作计划，全国爱卫办制定了《2019年全国爱国卫生工作要点》。现印发给你们，请结合各单位职责分工，认真贯彻执行。

全国爱国卫生运动委员会

2019年4月30日

## 2019年全国爱国卫生工作要点

2019年爱国卫生工作的总体要求是：以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，有效落实全国卫生与健康大会精神和《“健康中国2030”规划纲要》要求，完成爱国卫生各项重点任务，推进健康中国建设，以优异成绩迎接中华人民共和国成立70周年。

一、研究制定的文件

（一）修订印发全国爱卫会工作规则和成员单位职责分工（全国爱卫办牵头，各成员单位参与）。

（二）制定印发健康企业、健康社区建设规范（全国爱卫办牵头，有关成员单位参与）。

（三）研究起草健康村镇、健康学校建设规范（全国爱卫办牵头，有关成员单位参与）。

（四）加快修订《学校卫生工作条例》、《中小学健康教育指导纲要》等文件（教育部负责）。

二、推动落实的重点工作

（一）显著改善城乡环境卫生状况。

1.组织各地对城乡环境卫生整洁行动开展情况和目标任务完成情况进行自查，8-10月对部分地方进行抽查（全国爱卫办牵头，有关成员单位参与）。指导各地开展集中卫生清理，清除卫生死角，落实以环境治理为主的病媒生物预防控制措施，消除病媒生物孳生地，有效防控传染病（全国爱卫办、卫生健康委负责）。推进农村人居环境整治，实施村庄清洁行动，发动农村群众对村庄脏乱差问题进行集中整治。围绕农村生活污水治理、生活垃圾治理、农村改厕等，召开现场会（农业农村部牵头，生态环境部、住房城乡建设部、国家卫生健康委参与）。重点支持贫困地区做好农村饮水安全巩固提升工程，继续推进生态清洁小流域建设（水利部负责）。

2.启动医疗卫生机构厕所整洁专项行动，完善基础设施和环境卫生长效管理机制，有效改善医疗卫生机构厕所环境（卫生健康委、中医药局负责）。落实《全国旅游厕所建设管理新三年行动计划（2018-2020）》，2019年完成建设旅游厕所2.1万座（文化和旅游部负责）。通过卫生城镇创建、健康城市健康村镇建设等工作，稳步推进城镇公共厕所及学校、铁路站车、高速公路服务区、港口客运站等场所的公共厕所建设管理（全国爱卫办牵头，教育部、住房城乡建设部、交通运输部、铁路总公司参与）。

（二）积极推进健康中国战略实施。

3.研究建立健康中国战略实施的组织架构和管理机制。建立实施健康中国战略监测与评估体系，动态监测各类健康相关指标，对各地各有关部门的实施进度和效果进行年度评估（全国爱卫办牵头，各成员单位参与）。

4.健全完善卫生城镇创建工作机制。对90个城市、980个县城（乡镇）开展国家卫生城镇复审工作。新创建一批国家卫生县城（乡镇）。制订卫生城镇创建评审专家管理办法，组织对专家进行培训（全国爱卫办牵头，有关成员单位参与）。总结38个全国健康城市试点市及各地健康村镇建设试点工作经验，编写优秀案例集，研究启动健康城市建设示范市评选工作，全面推动健康“细胞”建设（全国爱卫办牵头，有关成员单位参与）。

（三）努力营造全民共建共享的良好氛围。

5.以“共推厕所革命　共促卫生健康”为主题，组织开展第31个爱国卫生月活动（全国爱卫办负责）。

6.组织开展第32个世界无烟日系列宣传活动，倡导健康文明生活方式（全国爱卫办、卫生健康委负责）。

7.对爱国卫生工作典型经验及成效进行宣传报道（全国爱卫办牵头，中央宣传部、广电总局、新华社、人民日报社参与）。组织举办好各项全民健身主题示范活动（体育总局负责）。广泛开展“健康中国”志愿服务工作和生态文明教育实践活动（共青团中央负责）。实施“巾帼健康行动”，聚焦“三区三州”深度贫困地区，引导妇女带动家庭成员养成健康的生活方式和行为习惯（全国妇联负责）。
