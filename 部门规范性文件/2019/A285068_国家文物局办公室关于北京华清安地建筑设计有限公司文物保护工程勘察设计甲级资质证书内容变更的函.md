# 国家文物局办公室关于北京华清安地建筑设计有限公司文物保护工程勘察设计甲级资质证书内容变更的函

办保函〔2019〕1000号

北京市文物局：

你局《关于北京华清安地建筑设计有限公司文物保护工程勘察设计甲级资质证书注册资本变更的请示》（京文物〔2019〕1537号）收悉。

经研究，我局同意北京华清安地建筑设计有限公司文物保护工程勘察设计甲级资质证书中的注册资金由“300万元”变更为“1000万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年11月19日
