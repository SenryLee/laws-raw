# 农业农村部对十三届全国人大二次会议第6841号建议的答复

## 对十三届全国人大二次会议第6841号建议的答复

农办议〔2019〕392号

您提出的关于切实提升西藏耕地质量的建议收悉。经商财政部、自然资源部，现答复如下。

一、关于合理利用有机肥源，增施有机肥

2018年，中央财政采取系列措施，支持开展畜禽粪污资源化利用，推进果菜茶有机肥替代化肥试点。一是安排20亿元，开展畜禽粪污资源化利用试点，采取以奖代补方式，选择部分省市县推进整建制治理，重点支持以农用有机肥和农村能源为重点的第三方处理主体相关设施建设，以及规模养殖场节水养殖工艺和设备改进、粪污资源化利用配套设施建设等，加快推进畜禽粪污治理。二是安排10亿元推进果菜茶有机肥替代化肥试点，支持农民和新型经营主体使用畜禽粪污资源化利用生产的有机肥，集中推广堆肥还田、商品有机肥施用、沼渣沼液还田、自然生草覆盖等技术模式，配套设施设备，集中连片推进实施。鼓励采取政府购买服务等方式，开展有机肥统供统施等社会化服务，探索一批"果—沼—畜""菜—沼—畜""茶—沼—畜"等生产运营模式，促进果菜茶提质增效和资源利用。

对于"财政给予西藏农民高温堆肥所需的物资、菌剂的补贴"相关建议，中央财政鼓励各地坚持以绿色生态为导向，利用现有渠道，强化政策衔接配合，将畜禽粪污资源化利用、果菜茶有机肥替代化肥等农业生态环境防治与资源循环利用政策统筹实施，在一个区域相对集中、整体推进，形成政策集聚效应，提高资金使用效益。

二、关于利用豆科作物合理轮作间作，用地养地相结合

为贯彻党中央、国务院决策部署要求，促进农业可持续发展，自2016年起，农业农村部会同财政部等10部门联合启动了耕地轮作休耕制度试点工作。2016年，中央财政安排资金14.36亿元、任务面积616万亩，支持河北等9省区实施耕地轮作休耕制度试点工作。2016—2018年，中央财政不断加大支持力度，累计投入资金98.36亿元，试点省份增加到15个省份，试点任务扩大到2900万亩。2019年，中央财政进一步加大投入力度，安排资金63.1亿元、比上年增加4.7亿元，试点面积扩大到3000万亩、比上年增加100万亩，试点省份增加至17个省份。其中轮作区域主要包括东北冷凉区、北方农牧交错区、黄淮海地区、长江流域；休耕区域主要包括地下水漏斗区、重金属污染区、西南石漠化区、西北生态严重退化区。此外，中央财政还安排13亿元，实施绿色高产高效创建项目，积极拓展农业多种功能，发展综合种养、复合种植、休闲观光、农事体验、文化传承等新产业、新业态，提升附加值。

对于"合理轮作换茬、建立科学的耕作制度、用养结合是西藏耕地土壤越种越肥的有效途径，建议国家财政给予支持西藏建立豆科绿肥种子繁育基地建设和固氮菌剂等生物有机肥补贴"相关建议，符合条件的地区可按照规定，统筹中央财政和地方财政资金，支持开展轮作休耕试点。同时，结合绿色高产高效创建项目，推广"一主多辅"的轮作模式、"一田多用"的复合种植模式，支持绿肥种植，促进农业绿色生态发展。

三、关于合理耕作改土，加速土壤熟化

一是实施耕地质量保护与提升行动。2015年以来，按照《耕地质量保护与提升行动方案》（农农发〔2015〕5号）要求，我部大力开展耕地质量保护与提升工作。据初步统计，2015—2018年实施项目县总数1537个，投入资金15.54亿元，实施质量保护与提升的耕地面积6389万亩。主要通过集成推广土壤改良、地力培肥、治理修复和化肥减量增效技术模式，引导农民应用缓释肥料、水溶肥料、生物肥料等高效、新型肥料，依托新型农业经营主体和社会化服务组织开展化肥减量增效服务。二是开展耕地轮作休耕制度试点。2016年以来，中央安排专项资金，在部分地区开展轮作试点；在地下水漏斗区、重金属污染区和生态严重退化地区开展休耕试点。通过试点，初步形成了一套有效的组织方式、技术模式和政策框架。2019年，进一步扩大轮作休耕试点范围，试点面积达3000万亩。

下一步，农业农村部将会同财政部等有关部门，扎实推进耕地轮作休耕制度试点。引导西藏结合自身实际自主开展轮作休耕，鼓励引导地方探索创新，统筹粮食安全与绿色发展，构建有中国特色的绿色种植制度，促进农业全面转型升级和高质量发展。

四、关于利用农业新材料代替有机肥数量不足

（一）开展果菜茶有机肥替代化肥行动。果菜茶有机肥替代化肥行动是我部推进农业绿色发展"五大行动"之一。2017年以来，通过开展果菜茶有机肥替代化肥行动，大力推进有机肥替代，引领种植业绿色发展。在优势产区选择100个既是果菜茶生产大县，又是畜牧养殖大县的示范县（市），开展果菜茶有机肥替代化肥试点。2018年，试点范围扩大到150个县。一是初步探索建立有效的组织方式。选择果菜茶优势区域、核心区域，集中连片打造，形成规模效应。其中，苹果、柑橘园都超过1万亩，茶园超过5000亩，设施蔬菜基地超过1000亩。充分发挥新型经营主体的引领作用，通过竞争性遴选的方式，让一批有意愿、有技术、有实力的种植大户、专业合作社、龙头企业承担试点任务。二是初步集成一套绿色高效技术模式。结合各地肥源条件和果菜茶需肥特点，集成组装类型多样的有机肥替代化肥技术模式。包括"有机肥+配方肥"模式、"果（菜）—沼—畜"模式、"有机肥+水肥一体化"模式、"有机肥+机械深施"模式等。三是初步创建一批绿色优质产品生产基地。结合推进质量兴农、品牌强农，以有机肥替代化肥为抓手，加快建设绿色优质产品基地，着力创响有影响力的知名品牌。四是初步构建有机肥利用的政策框架。采取政府购买服务方式，与有机肥企业、规模化养殖场、种植大户、服务组织签订协议，统一开展专业化服务。对一些有机肥肥源较远、积造不便的山区果园茶园和城市近郊菜园，对农民施用商品有机肥、生物有机肥予以适当补助，调动了农民增施有机肥的积极性。

下一步，农业农村部将继续开展果菜茶有机肥替代化肥行动，并扩大试点规模和范围，2019年在全国选择175个重点县开展有机肥替代化肥示范，打造一批绿色优质产品生产基地。强化农牧结合，将果菜茶有机肥替代化肥试点县与畜禽养殖废弃物资源化整建制推进县对接，以果定畜、以畜定沼、以沼促果，推动种养业在布局上相协调、在生产上相衔接。根据不同区域、不同作物的用肥需求和有机肥资源情况，因地制宜推广符合生产实际的有机肥替代化肥技术模式，配套相应的有机肥施用设施。支持农民和新型经营主体等使用畜禽养殖废弃物资源化产生的有机肥，鼓励农民采取秸秆还田、生草覆盖等措施，减少化肥用量，实现节本增效、提质增效。

（二）高度重视减肥增效等绿色兴农技术的试验示范推广工作。除国家农业科技创新与集成示范基地外，农业农村部还围绕优势农产品和特色产业发展的需求，通过自建、租用、合作等多种方式打造地方农业科技示范基地。近年来，依托基层农技推广体系改革与建设补助项目，2017—2019年累计投入5746万元支持西藏自治区加强基层农技推广体系改革建设，健全公益性农技推广服务网络，提升农技推广人员能力素质，建设长期稳定的农业科技实验示范基地，培育农业科技示范主体，加快新技术、新成果的试验示范和转化推广。

下一步，农业农村部将继续深入贯彻落实中央要求，通过基层农技推广体系改革与建设补助项目继续加强西藏自治区先进适用成果的试验示范和转化推广工作。对于"微蜜"等新材料推广，加强试验示范，明确产品成分与作用机理后，按照《肥料登记管理办法》的相关规定办理登记，因地制宜加以推广应用。

感谢您对提升西藏耕地质量工作的关心，希望继续对我部工作予以支持。
