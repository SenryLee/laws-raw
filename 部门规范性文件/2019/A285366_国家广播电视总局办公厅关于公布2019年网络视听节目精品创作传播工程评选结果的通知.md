# 国家广播电视总局办公厅关于公布2019年网络视听节目精品创作传播工程评选结果的通知

## 广电总局办公厅关于公布2019年网络视听节目精品创作传播工程评选结果的通知

广电办发〔2019〕320号

各省、自治区、直辖市广播电视局，中央直属单位《信息网络传播视听节目许可证》持证机构：

为进一步加强网络视听精品创作生产，促进网络视听节目提质升级，2019年广电总局继续实施网络视听节目精品创作传播工程征选推广工作，得到社会各界的积极响应。

按照广电总局党组关于加强重大题材创作的工作部署，2019年网络视听节目精品创作传播工程在征选中，着力发掘反映国家经济社会民生、国防军事科技等领域重大进展，反映当代中国各项事业发生历史性变化和取得历史性成就，反映新时代奋斗者昂扬向上、砥砺奋进精神面貌的重大现实题材作品。

经各中央直属单位和省级广电行政部门推荐，广电总局组织专家进行多轮评审，最终评选出11部优秀网络视听作品作为2019年网络视听节目精品创作传播工程重点扶持作品。广电总局将对重点扶持作品提供资金补助，并对其创作播出进行全方位指导扶持。扶持资金由广电总局下拨至各省局，各省局负责将资金分发至所属获扶持的单位并负责监督使用。扶持资金须严格按照有关规定专款专用，各省局应当做好跟踪问效工作，将有关情况及时报送广电总局，并在作品完成创作后向广电总局提交“绩效评估报告”。

现将评选结果予以公示，相关内容同时可在国家广播电视总局政府网站（网址：http://www.nrta.gov.cn）公告公示区中查询。请各省级广电行政部门立即向所辖有关单位通报公示内容。有关单位可就公示内容存在的问题，于12月24日前向国家广播电视总局网络视听节目管理司反映。
