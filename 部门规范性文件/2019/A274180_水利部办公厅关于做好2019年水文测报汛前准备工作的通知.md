# 水利部办公厅关于做好2019年水文测报汛前准备工作的通知

办水文〔2019〕25号

各省、自治区、直辖市水利（水务）厅（局），新疆生产建设兵团水利局，各流域管理机构：

为贯彻落实全国水利工作会议精神，切实做好2019年防汛水文测报工作，现就水文测报汛前准备工作有关要求通知如下。

一、高度重视，加强领导

2019年是新中国成立70周年，是全面建成小康社会的关键之年，也是党和国家机构改革后水文测报服务水旱灾害防御第一年。各省、自治区、直辖市水行政主管部门，各流域管理机构要充分认识水文测报汛前准备工作重要性、必要性，加强领导，认真研究解决水文测报工作存在的问题，确保水文测报汛前各项准备工作落实到位。各级水文部门要强化责任意识，精心组织，细化实化各项措施，超前部署，全力做好水文测报准备工作，为守住水旱灾害防御底线提供坚强支撑。

二、落实资金，抓好水毁水文测报设施修复

各省、自治区、直辖市水行政主管部门，各流域管理机构要把水毁水文测报设施设备的修复，作为汛前准备的一项重要任务抓紧抓实，优先安排，积极落实水毁修复资金。各级水文部门要抓紧排查水毁水文测报设施设备，及时制定水毁修复方案，务必确保汛前保质保量完成修复任务。

三、强化管理，精心维护

要深入推进测站精细化管理，汛前做好水文计量器具检定校准、水文测报设施设备维护保养和安全测试工作，建立健全水文计量器具和运行维护管理台账，抓紧对各类水文测报设施、仪器设备、通信线路、供电系统、安全防护装备等运行状况进行全面检查、维护修复和保养，备齐备足备品备件。要加强对设施设备运行情况的监控，发现运行异常的测站立即排查、尽快解决，确保汛期能够测得到、测得准、报得出、报得及时。

四、完善测报方案，加强应急演练

要认真分析今年的雨水情形势，明确水文测报工作重点，针对区域洪水特点、测洪薄弱环节和测站水文特性等修订完善各项水文测报方案预案，特别是高洪测验方案和北方江河洪水预报方案。有针对性开展测报业务培训。及时组织开展水文应急监测和洪水预报模拟演练，要以提升检验方案预案的可操作性和适用性，提升检验水文新仪器新设备应用的熟悉程度和精确度，提升检验预报人员的洪水预报业务素质和能力为重点。

五、强化安全意识，确保安全生产

要牢固树立安全生产红线意识，进一步加强事故隐患排查整治力度。要强化水文安全生产措施，生产一线必须配置完备的安全警示标识和安防救生设备，涉水和上船测流时必须穿救生衣，要特别加强测验设备防雷和测船、缆道、巡测车等易发生危险设施和危化物品的安全防护，坚决排除安全隐患；要加强水文测报人员的安全生产和自我防范意识，克服麻痹大意和侥幸心理，加大安全生产宣传教育培训力度，紧绷安全这根弦，筑牢安全生产红线。各级水文部门要按照通知要求，结合本单位实际，制定汛前准备工作方案，加强组织领导，加强监督检查，认真做好2019年水文测报汛前准备工作。
