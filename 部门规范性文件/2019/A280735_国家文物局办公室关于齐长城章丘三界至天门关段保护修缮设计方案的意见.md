# 国家文物局办公室关于齐长城章丘三界至天门关段保护修缮设计方案的意见

办保函〔2019〕711号

山东省文物局：

你局《关于呈报齐长城章丘三界首至天门关段修缮保护方案的请示》（鲁文发〔2019〕29号）收悉。经研究，我局暂不同意所报方案。

一、所报方案尚需做以下必要的修改和完善：

（一）深化现状勘察，有针对性地分析该段长城特点，评估其在齐长城总体组成中的价值和重要性，厘清石包墙、单体墙、单面石墙等不同墙体的样式、建造材料、形制、工艺等，明确各类墙体的保存现状、病害因素和发展趋势等，补充专项岩土勘察和必要的考古工作，增强方案可操作性。

（二）细化方案设计，明确砖石归安原则、各重要点段归安高度和宽度等具体设计内容和依据，墙体完全坍塌且砖石散落的段落建议采取现状保护。石包墙坍塌或松散墙芯应明确填充材料和补夯做法，较高的墙体段落应进行断面加固，确保稳定性。补充墙体坡脚排水做法、新旧墙体交接部分拉结措施。

（三）严格控制项目范围和强度，仅对存在结构稳定问题的段落进行重点修缮，避免过度干预。充分论证大范围清理深根系植被的必要性与可行性。

（四）深化图文表达，平面图、立面图应明确修缮范围和工程量，并与标注内容一致；剖面图应详细说明使用材料及工程做法，补充重要点段的构造详图。

二、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改和完善后，按程序另行报批。

三、请你局切实加强管理，督促、指导相关单位做好日常养护和巡查工作，及时发现、排除安全隐患，处理文物险情。同时，注意妥善处理齐长城保护与农民生产生活之间的关系，确保文物安全。

四、请你局加强管理，按照《文物保护工程设计文件编制深度要求（试行）》等，指导有关单位认真做好齐长城保护维修项目方案编制工作，保证上报方案文本的科学性、规范性和可操作性。

专此函复。

国家文物局办公室

2019年8月7日
