# 国家邮政局关于政协十三届全国委员会第二次会议第1935号提案答复的函

## 关于政协十三届全国委员会第二次会议第1935号提案答复的函

国邮函〔2019〕 88号

孔维克委员：

您提出的《关于做好智能快递柜快件箱布局解决快递寄送最后一公里的提案》（第1935号）收悉。经商住房城乡建设部，现答复如下：

正如您所关注到的，随着近年来互联网电商的发展，人们的传统购物模式发生了较大的转变，网购变得更加普及和便捷。随着快递业务的高速增长，传统快递的“最后一公里”投递服务问题逐渐成为发展瓶颈。智能快件箱寄递服务是快递市场涌现出的末端服务创新，以其时间配置灵活、时效性高、私密性强等特点，已经逐步成为我国城市末端投递服务的重要组成部分。截止2019年6月，全国布放投入使用的智能快件箱已超过31.1万组，通过智能快件箱收寄和投递的快递件量累计分别超过1500万件和20亿件，箱递率达11%。

对于您提出的出台定向配套支撑政策的建议，我们深表赞同。近年来，国家邮政局开展了大量工作，先后于2013年和2016年出台了《智能快件箱》行业标准（YZ/T 0133-2013）和《智能快件箱投递服务管理规定（暂行）》，从技术标准和服务要求两方面加以规范引导。2018年6月，国家邮政局研究制定了《智能快件箱寄递服务管理办法》（以下简称《办法》），《办法》针对智能快件箱寄递服务涉及的寄递流程较为复杂，操作环节较多等情况，明晰了市场主体的定位、进一步规范了收投服务、加大了对用户合法权益的保护力度。《办法》已由交通运输部以部令形式发布，并将于2019年10月1日起正式施行。

对于您提出的赋予“国家队”智能快递柜企业普惠服务职能的建议，我局将对承担国家邮政普遍服务的邮政企业在现有补贴政策的基础上，进一步引导企业享受国家减税降费相关政策，对提供邮政普遍服务的智能信包箱参照《智能快件箱寄递服务管理办法》进行管理。此外，将积极鼓励邮政企业智能信包箱向快递企业开放，采取商业化运作，拓宽企业盈利渠道，切实帮助企业减轻经营负担。

对于您提出的丰富智能快递柜功能及增加智能快递柜VIP客户属性的建议，我们将及时向智能快件箱运营企业进行反馈，鼓励企业根据市场需求进一步完善智能快件箱功能设计，不断丰富业务类型，拓宽营收渠道，为客户提供更加便捷多样的服务。

住房与城乡建设部对您提出的建议表示赞同，主要开展了以下工作：一是规范配置要求。发布《城市居住区规划设计标准》（GB50180-2018），明确提出宜在十五分钟生活圈、十分钟生活圈居住区中布置邮政营业场所及其他快递营业设施，并规定居住街坊配套设施应配建邮件和快递送达设施。二是推进设施建设。会同国家发展发改改革委、财政部印发《住房和城乡建设部办公厅 国家发展改革委办公厅 财政部办公厅 关于做好2019年老旧小区改造工作的通知》（建办城函〔2019〕243号），将老旧小区改造纳入城镇保障性安居工程，给予中央补助资金支持，其中，明确小区内配套服务设施的建设、改造为老旧小区改造内容，属于中央补助支持范围。三是提供合作服务。支持物业服务企业在为快递企业进入小区配送提供便利之外，进一步加强与快递企业合作，通过设立快递代收点，配建快递免费寄存箱等形式，满足业主的多样化需求。四是完善政策环境。将编制完整社区设施配套导则，指导地方因地制宜将智能快件箱作为服务设施，纳入地方制定的老旧小区改造内容清单。指导物业服务企业在尊重业主共同意愿、不影响小区秩序管理的前提下，努力为快递配送提供便利。

下一步，我局将加大对《智能快件箱寄递服务管理办法》宣贯力度，研究出台推进《智能快件箱（信包箱）相关建设指导意见》。会同相关部门开展联合调研，推动将智能快件箱纳入城市公共服务基础设施相关规划和老旧小区改造项目建设清单内容。通过政策引导，积极推动智能快件箱运营企业向经济欠发达、智能快递柜投放空白或较少的三四线城市加大布局力度，满足人民群众日益增长的寄递服务需求。

感谢您对快递业发展的关心和支持！
