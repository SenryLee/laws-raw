# 人力资源社会保障部办公厅、农业农村部办公厅、粮食和储备局办公室关于颁布农产品食品检验员国家职业技能标准的通知

## 人力资源社会保障部办公厅　农业农村部办公厅　粮食和储备局办公室关于颁布农产品食品检验员国家职业技能标准的通知

人社厅发〔2019〕11号

各省、自治区、直辖市人力资源社会保障厅（局），农业农村（农牧）、畜牧兽医、渔业、农垦厅（局、委），粮食局（粮食和物资储备局），新疆生产建设兵团人力资源社会保障局、农业局，中国储备粮管理集团有限公司、中粮集团有限公司、中国供销集团有限公司：

根据《中华人民共和国劳动法》有关规定，人力资源社会保障部、农业农村部、粮食和储备局共同制定了农产品食品检验员国家职业技能标准，现予颁布施行。原相应国家职业技能标准同时废止。

附件：农产品食品检验员国家职业技能标准目录
