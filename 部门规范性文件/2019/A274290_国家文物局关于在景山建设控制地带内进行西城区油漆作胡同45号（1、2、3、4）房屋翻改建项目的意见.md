# 国家文物局关于在景山建设控制地带内进行西城区油漆作胡同45号（1、2、3、4）房屋翻改建项目的意见

文物保函〔2019〕104号

北京市文物局：

你局《关于景山建控地带内西城区油漆作胡同45号（1、2、3、4）房屋翻改建工程的请示》（京文物〔2018〕1786号）收悉。经研究，我局原则同意在景山建设控制地带内进行西城区油漆作胡同45号（1、2、3、4）房屋翻改建项目。

一、建议补充勘察研究1、2号房的传统构造做法、材料和工艺特征，并在项目实施中尽量予以保留；补充明确强弱电相关材料要求和必要的防火措施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月25日
