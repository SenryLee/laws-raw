# 国家文物局关于战国秦长城遗址瓦社村段保护区划内定汉线吴起至华池（陕甘界）公路建设项目的意见

文物保函〔2019〕467号

陕西省文物局：

你局《关于定汉线吴起至华池（陕甘界）公路项目涉及战国秦长城遗址的请示》（陕文物字〔2019〕16号）收悉。经研究，我局原则同意在战国秦长城遗址瓦社村段保护区划内实施定汉线吴起至华池（陕甘界）公路建设项目的K线方案。

一、所报方案尚需作以下必要的修改和完善：

（一）组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘，如有长城墙体遗存等重要考古发现，应对设计方案做出必要调整，确保文物安全。

（二）进一步完善项目设计方案，适当增加桥墩间距，尽可能避让长城遗存分布范围，同时严格控制非必要的现有地貌形态改造相关工程内容。

（三）进一步完善项目施工方案，明确振动控制、施工组织及监测预警措施，避免工程施工对周边长城相关遗存造成破坏。

（四）补充项目施工期间的长城本体临时性保护措施、应急预案以及施工后期的环境修复措施，并应结合项目实施适当设置长城保护标志、保护界桩和警示标识。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月21日
