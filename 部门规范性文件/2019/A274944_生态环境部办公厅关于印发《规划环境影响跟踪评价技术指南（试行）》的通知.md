# 生态环境部办公厅关于印发《规划环境影响跟踪评价技术指南（试行）》的通知

## 关于印发《规划环境影响跟踪评价技术指南（试行）》的通知

环办环评〔2019〕20号

各省、自治区、直辖市生态环境厅（局），新疆生产建设兵团生态环境局，各有关单位：

为贯彻落实《中华人民共和国环境影响评价法》和《规划环境影响评价条例》，规范并指导规划环境影响跟踪评价工作，我部组织制定了《规划环境影响跟踪评价技术指南（试行）》。现印发给你们，请参考执行。

生态环境部办公厅

2019年3月8日
