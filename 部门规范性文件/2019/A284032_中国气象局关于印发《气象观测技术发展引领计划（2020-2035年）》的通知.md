# 中国气象局关于印发《气象观测技术发展引领计划（2020-2035年）》的通知

气发〔2019〕90号

各省（区、市）气象局，各直属单位，各内设机构，各有关单位：

为深入实施创新驱动发展战略，推动气象观测技术发展，进一步提升我国综合气象观测现代化水平，中国气象局制定了《气象观测技术发展引领计划（2020-2035年）》，现印发实施。

附件：气象观测技术发展引领计划（2020-2035年）

中国气象局

2019年11月4日
