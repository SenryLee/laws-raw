# 国家药监局综合司关于公布第一批国家化妆品风险监测工作组成员单位的通知

药监综妆〔2019〕53号

各省、自治区、直辖市药品监督管理局：

为进一步规范和加强化妆品风险监测工作，提高化妆品监管工作的主动性和针对性，经组织专家评审及现场检查，遴选确定中国食品药品检定研究院、上海市食品药品检验所等6家机构作为第一批国家化妆品风险监测工作组成员单位，现予公布。

附件：第一批国家化妆品风险监测工作组成员单位名单

药监局综合司

2019年6月24日
