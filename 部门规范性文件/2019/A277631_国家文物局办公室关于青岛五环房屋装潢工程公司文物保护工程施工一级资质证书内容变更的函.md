# 国家文物局办公室关于青岛五环房屋装潢工程公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕382号

山东省文物局：

你局《关于青岛五环房屋装潢工程公司变更文物保护工程资质证书有关事项的请示》（鲁文发〔2019〕31号）收悉。

经研究，我局同意青岛五环房屋装潢工程公司文物保护工程施工一级资质证书中的法定代表人由“宋修维”变更为“刘方佩”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年5月16日
