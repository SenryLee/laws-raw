# 国家文物局办公室关于河北中原工程项目管理有限公司文物保护工程监理甲级资质证书内容变更的函

办保函〔2019〕379号

河北省文物局：

你局《关于河北中原工程项目管理有限公司文物保护工程监理甲级资质证书内容变更的请示》（冀文物字〔2019〕14号）收悉。

经研究，我局同意河北中原工程项目管理有限公司文物保护工程监理甲级资质证书中的注册资金由“3057.5万元”变更为“5100万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年5月16日
