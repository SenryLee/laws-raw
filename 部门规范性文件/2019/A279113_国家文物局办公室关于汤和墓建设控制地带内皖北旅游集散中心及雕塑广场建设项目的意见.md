# 国家文物局办公室关于汤和墓建设控制地带内皖北旅游集散中心及雕塑广场建设项目的意见

办保函〔2019〕539号

安徽省文物局：

你局《关于汤和墓建设控制地带内皖北旅游集散中心及雕塑广场建设项目的请示》（皖文物保〔2019〕15号）收悉。经研究，我局暂不同意在汤和墓建设控制地带内实施皖北旅游集散中心及雕塑广场建设项目。

一、所报方案应按照《汤和墓保护规划》关于建设控制地带管理规定要求，核减建筑高度至9米以下。同时，应结合视线分析、地形高差等因素，进一步评估拟建项目对汤和墓历史氛围和周边景观的影响，建议尽量远离遗址、简化外观样式、深化景观设计，可通过树木遮挡等降低文物影响。

二、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年6月17日
