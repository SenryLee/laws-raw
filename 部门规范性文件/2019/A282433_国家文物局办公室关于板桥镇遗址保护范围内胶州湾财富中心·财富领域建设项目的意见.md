# 国家文物局办公室关于板桥镇遗址保护范围内胶州湾财富中心·财富领域建设项目的意见

办保函〔2019〕723号

山东省文物局：

你局《关于板桥镇遗址保护范围内建设胶州湾财富中心·财富领域项目的请示》（鲁文发〔2019〕37号）收悉。经研究，我局暂不同意在板桥镇遗址保护范围内实施胶州湾财富中心·财富领域建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）拟建项目位于板桥镇遗址保护范围内，应充分论证项目实施的必要性和可行性，建议在文物保护范围外另行选址。

（二）在项目区域进一步开展全面的考古工作，厘清该区域历史沿革、明确文物埋藏情况，在此基础上调整项目设计方案、完善文物影响评估报告。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年8月15日
