# 农业农村部对十三届全国人大二次会议第2186号建议的答复

## 对十三届全国人大二次会议第2186号建议的答复

张继新代表：

您提出的关于加大河套平原建设绿色有机农畜产品生产加工输出基地扶持力度的建议收悉。经商财政部，现答复如下。

内蒙古农牧业发展资源条件好，是我国重要的农畜产品生产基地。近年来，我部会同财政部采取系列措施，积极支持内蒙古绿色生态农牧业发展。一是为促进我国农业绿色发展，财政部和农业农村部印发了《建立以绿色生态为导向的农业补贴制度改革方案》，明确建成以绿色生态为导向、促进农业资源合理利用与生态环境保护的农业补贴政策体系和激励约束机制，进一步提高农业补贴政策的精准性、指向性和实效性。二是实施山水林田湖草生态保护修复工程，2018年，财政部会同自然资源部、生态环境部通过竞争性评审，将内蒙古“乌梁素海流域山水林田湖草生态保护修复工程”纳入第三批山水林田湖草生态保护与修复工程试点范围，并下达奖补资金10亿元，工程实施区域主要是河套平原地区。三是启动实施了绿色发展重大政策，主要包括耕地地力保护补贴、耕地轮作休耕试点、有机肥替代化肥、绿色循环农业高效项目、秸秆综合利用、畜禽粪污资源化利用等促进政策，坚持质量兴农、绿色兴农，深入推进农业绿色化、优质化、特色化、品牌化，调整优化农业产品结构、产业结构和布局结构，促进实现农业生产环节绿色化，提升农产品质量安全水平，增加绿色优质农产品供给。这些项目采取“大专项+任务清单”管理方式，中央财政支农资金切块下达地方，鼓励各地在任务清单范围内统筹使用相关项目资金，内蒙古可结合实际，加强对绿色有机畜产品等方面的支持。

下一步，我部将会同有关部门进一步完善相关政策措施，统筹整合支农惠农资金，支持内蒙古及各地发展以绿色生态为导向的现代农业。

感谢您对农业农村经济工作的关心，希望继续对我部工作给予支持。

农业农村部

2019年9月19日
