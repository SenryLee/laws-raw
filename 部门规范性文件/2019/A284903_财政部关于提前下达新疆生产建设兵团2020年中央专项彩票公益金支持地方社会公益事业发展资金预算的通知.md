# 财政部关于提前下达新疆生产建设兵团2020年中央专项彩票公益金支持地方社会公益事业发展资金预算的通知

财综〔2019〕48号

新疆生产建设兵团财政局：

为提高预算完整性，加快支出进度，按照预算管理有关规定，经研究，现提前下达你兵团2020年中央专项彩票公益金支持地方社会公益事业（项目代码：Z185010030001）预算指标11250万元，用于支持当地社会公益事业发展。该项资金安排使用时，应根据使用方向相应列入《2020年政府收支分类科目》第2296002项“用于社会福利的彩票公益金支出”至2296099项“用于其他社会公益事业的彩票公益金支出”，待2020年预算年度开始后，按程序拨付使用。

请你兵团尽快将资金分解下达至师团，由资金使用单位按照有关预算管理规定落实到支出功能分类项级科目，自下而上逐级汇总编列入2020年“二上”预算。

请你局根据提前下达的预算额度，科学合理确定区域绩效目标，于收到本通知60日内，按程序将区域绩效目标报财政部备案，同时抄送财政部新疆监管局。你局要严格按照《财政部关于“十三五”时期中央专项彩票公益金支持地方社会公益事业发展安排以及下达2017年资金的通知》（财综〔2017〕47号）、《财政部关于印发<中央专项彩票公益金支持地方社会公益事业发展资金管理办法>的通知》（财综〔2019〕21号）和《中共中央 国务院关于全面实施预算绩效管理的意见》等规定，加强预算绩效目标管理，做好绩效运行监控和绩效评价、强化评价结果应用，切实提高财政资金使用效益。

附件：彩票公益金中央对地方政府性基金转移支付绩效目标表

财政部

2019年10月29日
