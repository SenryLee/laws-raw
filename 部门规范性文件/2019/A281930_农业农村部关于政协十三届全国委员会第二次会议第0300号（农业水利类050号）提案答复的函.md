# 农业农村部关于政协十三届全国委员会第二次会议第0300号（农业水利类050号）提案答复的函

## 关于政协十三届全国委员会第二次会议第0300号（农业水利类050号）提案答复的函

农办案〔2019〕35号

民革中央：

关于进一步支持返乡下乡创业的提案收悉。经商商务部、发展改革委、人力资源社会保障部、交通运输部，现答复如下。

一、关于加快推进涉农要素资源制度改革

近年来，我部积极促进涉农要素资源制度改革，增强资源要素的流动性，激发返乡入乡在乡人员创新创业。一是激活土地要素。引导建设用地指标、农村集体经营性建设用地重点向农村创新创业倾斜，积极鼓励创新创业人员利用农村闲置宅基地、复垦土地、"四荒地"发展新产业新业态。二是完善农产品税收政策。扩大农产品初加工免税范围，进一步扩大农产品增值税进项税额核定扣除试点范围。三是增加农村资源要素权能。扩大农村担保物范围，推动将创新创业贷款需求纳入全国农业信贷担保体系和创业担保贷款支持范围，建立多层次创业融资基金，为创新创业主体提供风险缓释和风险分担。

二、关于扎实补足乡村物流短板

近年来，我部和相关部门积极加强乡村物流设施和条件建设，开展了一些工作，取得了积极成效。一是强化物流设施建设。我部联合交通运输部、供销总社、邮政局印发《关于协同推进农村物流健康发展加快服务农业现代化的若干意见》，全面加强农业、交通运输、供销、邮政快递等资源统筹布局、资源互补、共同开发，推动形成"场站共享、服务同网、货源集中、信息互通"的农村物流发展新格局。二是提升农村物流服务水平。近期，交通运输部印发《关于推进乡镇运输服务站建设加快完善农村物流网络节点体系的意见》，对全国集客运、物流、邮政、快递、供销等多种服务功能于一体的乡镇运输服务站。三是建设物流配送网点。国家发展改革委会同有关部门印发《关于推动物流高质量发展促进形成强大国内市场的意见》，建设城乡双向物流配送网络、快递公共取送点和冷链物流体系，不断补齐乡村物流体系短板。

三、关于建设完善涉农智力技术服务体系

近年来，我部积极建设完善涉农智力技术服务体系，加强农业社会化服务体系建设。一是完善农村服务网点。引导各地整合各类智力技术服务事项，打通部门间信息查询互认通道，探索在村庄建立网上服务站点，将服务农村创新创业纳入服务平台和网点，推广网上办、马上办、全程帮办、少跑快办等服务，为创业者提供贴身式、一站式服务。二是搭建农村创新创业平台。引导各地农村创新创业园区（基地）梳理政策信息，形成政策明白纸，帮助经营主体了解政策和获取政策支持。简便经营主体入园登记注册，营造便利化、法制化的营商环境。组织开展银企对接、银团合作、投资对接等活动，引导各类金融机构加大对园区（基地）经营主体的金融支持。三是积极引导公共服务下沉农村。通过财政奖补，改造扩容提质现有创业园区、孵化基地，优先布局农村创新创业集中的县乡，将路水电气、仓储、物流、通信、宽带等配套设施和教育、医疗、文化、商业等公共服务配套下沉，为农村创新创业人员提供低成本、全要素、便利化的创业服务。

四、关于切实增加创业人才人力资源供给

近年来，我部创造各种优惠条件，不断增加创业人才人力资源供给。一是鼓励各类人才入乡投资兴业。积极破除城市人才下乡的制度障碍，建立城市专业人才定期服务乡村机制，搭建乡村建设志愿服务平台，鼓励城市各类人才投身乡村振兴。二是培育农村创新创业导师。依托现有渠道，加强农村创新创业主体和导师培育，组织实施"百千万"农村创新创业导师培训计划，培养100名国家级、1000名省级、1万名市县级农村创新创业导师。三是大力发展"互联网+"创新创业。重视激发农业农村专业技术人才、高技能人才等的创造潜能，加速科技成果向现实生产力转化，结合"互联网+"、大数据等信息化新技术，引导其以创新带动创业。四是引导返乡农民工在创业地参加各项社会保险。鼓励有条件的地方将返乡农民工纳入住房公积金缴存范围，按规定将其子女纳入城镇（城乡）居民基本医疗保险参保范围，为返乡创业提供更有力的支持。

五、关于鼓励推广基层有益探索创新

我部支持大众创业、万众创新向农村延伸拓展，鼓励推广基层有益探索创新。一是鼓励发展创新创业新模式。鼓励各地培育发展网络化、智能化、精细化现代乡村产业新模式。二是大力发展新产业新业态。积极发展"生鲜电商+冷链宅配""中央厨房+食材冷链配送"等业态，推行智能生产、经营平台、物流终端、产业联盟和资源共享等新平台。三是开展创新创业典型推介。连续举办三届农村创新创业项目创意大赛，宣传推介农村创新创业带头人和典型县。办好全国新农民新技术创业创新博览会。宣传推进农村创新创业经验做法，营造农村创新创业浓厚氛围。

感谢对农业发展的关心，希望继续对我部工作给予支持。

农业农村部

2019年8月30日
