# 国家发展改革委办公厅关于同意调整广东省珠海港控股集团有限公司等两家公司债券期限的函

发改办财金〔2019〕877号

广东省发展改革委、青岛市发展改革委：

报来《关于调整珠海港控股集团有限公司绿色可续期企业债券发行期限和发行条款的请示》（粤发改财金〔2019〕244号）、《关于转报<青岛地铁集团有限公司关于申请调整绿色可续期公司债券发行期限的请示>的请示》（青发改服务〔2019〕163号）收悉。经研究，现函复如下。

一、2019年6月3日，我委以发改企业债券〔2019〕98号文件核准珠海港控股集团有限公司发行10亿元绿色债券。经研究，同意本期债券期限调整为以3年为一个重定价周期，附设续期选择权和延期支付利息权。如果发行人选择延长本期债券期限，则在第2个重定价周期内的票面利率调整为前3个计息年度票面利率加上300个基点，此后发行人若继续延长本期债券期限，票面利率保持为第1个重定价周期票面利率加上300个基点。如果发行人在某一计息年度末递延支付利息，本期债券票面利率将在上一计息年度基础上上调300个基点，此后发行人将已递延利息及其孳息再次递延时票面利率不变，直至已递延利息及其孳息全部清偿完毕。其余批复要素不变。

二、2018年4月2日，我委以发改企业债券〔2018〕45号文件核准青岛地铁集团有限公司发行30亿元绿色债券。经研究，同意将尚未发行的20亿元本期债券期限调整为以5年为一个重定价周期，附设续期选择权。如果发行人选择延长本期债券期限，则从第2个重定价周期开始，每个重定价周期适用的票面利率为当期基准利率加上基本利差再加上300个基点。其余批复要素不变。

三、请你委督促发行人按照《公司法》《证券法》《企业债券管理条例》和有关规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

四、请你委督促发行人按要求及时做好信息披露及债券资金管理，按照核准的募集资金投向合规使用债券资金，认真落实偿债保障措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅
