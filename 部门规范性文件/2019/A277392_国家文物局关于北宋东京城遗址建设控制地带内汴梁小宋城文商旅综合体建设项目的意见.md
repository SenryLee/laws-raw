# 国家文物局关于北宋东京城遗址建设控制地带内汴梁小宋城文商旅综合体建设项目的意见

文物保函〔2019〕411号

河南省文物局：

你局《关于再次上报汴梁小宋城文商旅综合体项目涉及北宋东京城遗址建设控制地带方案的请示》（豫文物〔2019〕54号）收悉。经研究，我局原则同意在北宋东京城遗址建设控制地带内实施汴梁小宋城文商旅综合体建设项目。

一、所报方案尚需作以下必要的修改和完善

（一）进一步深化方案设计，拟建项目地上部分应进一步远离城墙遗址，核减建筑体量、降低建筑高度，统筹考虑新建建筑与顺天门遗址博物馆、开封市历史文化名城的风貌相协调。

（二）明确施工组织方案，桩基承台等施工不得占压遗址保护范围，严格控制工程范围和施工强度，做好施工中的文物保护工作，确保文物安全。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

五、请你局加强指导，督促开封市人民政府尽快编制北宋东京城遗址保护规划，合理安排北宋东京城遗址区划范围内新建项目，明确管理规定和具体建设控制指标，协调处理开封名城保护、文物保护利用与城市建设、民生改善的关系。

专此函复。

国家文物局

2019年5月5日
