# 国家林业和草原局办公室关于举办2019中国森林旅游节的通知

办场字〔2019〕136号

各省、自治区、直辖市林业和草原主管部门，内蒙古、大兴安岭森工（林业）集团公司，新疆生产建设兵团林业和草原主管部门，国家林业和草原局各司局、各派出机构、各直属单位：

经全国清理和规范庆典研讨会论坛活动工作领导小组批准，我局与文化和旅游部、江苏省人民政府定于2019年10月18—20日在江苏省南通市共同主办“2019中国森林旅游节”。现将有关事项通知如下：

一、高度重视

中国森林旅游节是国家林业和草原局举办的最重要的节庆活动，是森林旅游行业营造氛围、凝聚共识、聚合力量、推动发展的大平台，是促进森林旅游创新、融合、绿色、持续发展的重要抓手。举办好中国森林旅游节，对于进一步扩大林业草原社会影响、推动林业草原生态文明建设、发挥林业草原在乡村振兴中的独特作用、促进森林旅游更平衡更充分发展具有重要意义。各地要按照《中国森林旅游节管理办法》有关规定，加强对活动的组织领导，要围绕《2019中国森林旅游节总体方案》（见附件1），制定工作计划，落实人员、经费保障，周密部署、积极筹备，共同办好2019中国森林旅游节。

二、精心组织

（一）认真抓好本省（区、市）的整体展示工作。要围绕森林、草原、湿地、荒漠、野生动植物及民俗文化资源特点和利用情况，总结提炼本省（区、市）森林旅游发展的优势和特点，精心策划展示内容和形式，做到主题明确、主线分明、内容丰富、形式生动，努力提高展示效果。要增加互动性、趣味性、知识性活动内容，充分发挥新技术优势，增加观众的体验感、愉悦感和获得感。

（二）积极组织相关单位独立参展。鼓励在森林旅游发展中取得突出成效的市县、各类森林旅游地以及企业、社会团体、乡村等独立参展，进一步发挥中国森林旅游节在服务基层、服务社会中的巨大潜力。

（三）协助组织推介、签约事项。配合做好2019全国森林旅游推介会暨森林旅游合作签约仪式相关工作，积极推荐本省（区、市）特色森林旅游线路、新兴森林旅游地品牌、重要森林旅游合作签约事项等，并组织好相关材料。

（四）认真组织人员参会。按要求确定好正式参会代表，并鼓励各界人士积极参加2019中国森林旅游节。要加强人员管理，确保信息畅通，组织相关人员有序参加开幕式、推介会、论坛以及相关授牌、签约仪式等活动。

三、加强宣传

各省（区、市）要把宣传作为贯穿节前、节中、节后全过程的一项重要工作，多渠道、多形式地宣传中国森林旅游节以及本省（区、市）参与的相关活动情况。推动各类森林旅游地与2019中国森林旅游节进行互动，推出有针对性的宣传和促销活动，以提高中国森林旅游节的品牌影响力。

请各省（区、市）抓紧部署，并于2019年8月26日前将本单位负责2019中国森林旅游节工作的负责人和联系人名单（见附件2）报我局。
