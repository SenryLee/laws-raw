# 国家体育总局社体中心、中国大学生体协、中国中学生体协关于印发2019年全国柔力球校园大赛竞赛规程的通知

## 体育总局社体中心　中国大学生体协　中国中学生体协关于印发2019年全国柔力球校园大赛竞赛规程的通知

各省、自治区、直辖市、计划单列市、新疆生产建设兵团体育局社体中心（群体处、体总秘书处），各行业体协秘书处，教育厅（教委）体卫艺处、学生体协，各高等院校及有关单位：

为贯彻落实党的十九大精神，广泛开展全民健身活动，进一步推动柔力球运动可持续发展，决定于2019年10月11-13日在四川省成都市举办2019年全国柔力球校园大赛。

现将竞赛规程印发给你们，请积极组队参加比赛。

体育总局社体中心　中国大学生体协　中国中学生体协

2019年5月27日

附件1：2019年全国柔力球校园大赛竞赛规程

附件2：2019年全国柔力球校园大赛报名表

附件3：2019年全国柔力球校园大赛自愿参赛责任书
