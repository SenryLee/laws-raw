# 教育部关于同意阜阳师范学院更名为阜阳师范大学的函

教发函〔2019〕56号

安徽省人民政府：

《安徽省人民政府关于请批准阜阳师范学院更名为阜阳师范大学的函》（皖政秘〔2019〕42号）收悉。

根据《中华人民共和国高等教育法》《普通高等学校设置暂行条例》《普通本科学校设置暂行规定》有关规定以及第七届全国高等学校设置评议委员会评议结果，经教育部党组会议研究决定，同意阜阳师范学院更名为阜阳师范大学，学校标识码为4134010371；同时撤销阜阳师范学院的建制。现将有关事项函告如下：

一、阜阳师范大学系多科性本科学校，以本科教育为主，同时承担研究生培养任务，由你省领导和管理。

二、学校要切实加强党的建设，全面贯彻党的教育方针，坚持社会主义办学方向，落实立德树人根本任务，培养德智体美劳全面发展的社会主义建设者和接班人。

三、学校要围绕教师教育体系建设，进一步突出传统优势学科专业，加强教师教育理论研究和实践探索，建设特色鲜明的高水平师范大学。

四、学校全日制在校生发展规模为18000人。

望你省加强对学校的指导和支持，加大资源投入力度，引导学校科学定位、内涵发展，加大高层次人才引进力度，不断提升教学科研水平，培养更多区域经济社会发展特别是基础教育发展所需要的应用型、复合型人才，更好地为地方经济社会发展服务。

该校参与举办的独立学院阜阳师范学院信息工程学院，同时更名为阜阳师范大学信息工程学院。

教育部

2019年6月10日
