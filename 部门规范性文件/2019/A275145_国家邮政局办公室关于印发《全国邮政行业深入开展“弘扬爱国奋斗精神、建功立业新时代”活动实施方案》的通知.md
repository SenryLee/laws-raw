# 国家邮政局办公室关于印发《全国邮政行业深入开展“弘扬爱国奋斗精神、建功立业新时代”活动实施方案》的通知

国邮办函〔2019〕83号

各省、自治区、直辖市邮政管理局，国家局直属各单位机关各司室、机关各司室直属各单位，中国邮政集团公司办公室、各主要快递企业：

现将《全国邮政行业深入开展“弘扬爱国奋斗精神、建功立业新时代”活动实施方案》印发给你们，请认真贯彻落实。

国家邮政局办公室

2019年2月21日

## 全国邮政行业深入开展“弘扬爱国奋斗精神、建功立业新时代”活动实施方案

为贯彻落实习近平总书记关于爱国奋斗精神的重要指示精神，加强团结引领服务知识分子，推动全行业广大知识分子树立牢固的家国情怀，建设一支矢志爱国奉献、勇于创新创造的优秀人才队伍，根据《中共中央组织部 中共中央宣传部关于在广大知识分子中深入开展“弘扬爱国奋斗精神、建功立业新时代”活动的通知》（中组发〔2018〕11号）要求，结合邮政行业工作实际，现就在全国邮政行业知识分子中深入开展“弘扬爱国奋斗精神、建功立业新时代”活动，制定本实施方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届二中、三中全会精神，深入贯彻落实习近平总书记关于人才工作、知识分子工作重要指示批示精神，牢记“人民邮政为人民”的服务宗旨，弘扬“传邮万里，国脉所系”的邮政精神，树创“小蜜蜂”精神，紧密结合“不忘初心、牢记使命”主题教育，注重政治引领、凝心聚力，引导邮政行业广大知识分子在新时代自觉弘扬践行爱国奋斗精神，把自己的理想同祖国的前途、把自己的人生同民族的命运紧密联系在一起，在本职岗位上担当作为讲奉献，在建设邮政强国的事业中建功立业，争做新时代的奋斗者、创造者、引领者。

二、重点任务

（一）加强宣传解读。

1.加强宣传阐释。组织行业媒体特别是行业新媒体，开展全方位、立体化宣传解读，营造学习弘扬爱国奋斗精神的浓厚氛围。

2.加强研究诠释。鼓励行业研究机构和共建院校等发挥专业优势，对邮政行业弘扬爱国奋斗精神进行挖掘整理、课题研究和理论阐释。

（二）组织学习研讨。

3.组织集中学习。把爱国奋斗精神学习教育和“不忘初心、牢记使命”主题教育紧密结合，通过多种形式组织集中学习习近平总书记关于爱国奋斗精神的重要指示和爱国奋斗精神学习读本，切实增强对新时代爱国奋斗精神的认同。

4.开展学习讨论。把爱国奋斗精神学习教育纳入党支部“三会一课”和主题党日活动，发挥党员知识分子的先锋模范作用，凝聚广大干部职工最广泛的思想共识。

（三）开展专题培训。

5.列入素质培养计划。把爱国奋斗精神融入素质培养体系，列入各级各类干部教育培养计划，切实把爱国奋斗精神学深学透、入脑入心。

6.开设专题研修课程。在专业技术人才知识更新工程等研修班中开设“弘扬爱国奋斗精神、建功立业新时代”课程，引导行业知识分子树立爱国奋斗、建功立业目标。

（四）坚持示范引领。

7.讲好爱国奋斗故事。深入挖掘邮政行业知识分子群体和个人践行爱国奋斗精神的典型，宣传好他们的先进事迹和崇高精神，用身边事教育身边人。

8.组织开展口述历史活动。组织行业媒体对邮政行业老领导、老专家、老科技工作者开展口述历史活动。

（五）开展岗位建功。

9.倡导岗位建功。结合主责主业开展岗位创新、岗位建功、岗位奉献等创先争优活动和主题实践活动，把爱国奋斗精神融入岗位职责和具体工作，引导行业知识分子从本职岗位做起，自觉践行爱国奋斗精神。

三、工作要求

（一）加强组织领导。要强化政治意识，把开展“弘扬爱国奋斗精神、建功立业新时代”活动作为一项重要政治任务，加强统一领导，明确责任分工，精心做好组织实施。

（二）注重分类指导。要结合实际，按照精准科学的要求，尊重不同层次知识分子群体特殊性，因类制宜、因人施教，提高活动针对性和实效性。要及时广泛宣传活动情况，及时总结推广活动中创造的好经验好做法。

（三）构建长效机制。要严格责任落实，加强对活动组织实施情况的督促检查，坚决克服形式主义，确保活动取得实效。要落实党组联系服务专家制度，加强对知识分子的思想联系、感情交流和服务保障，以尊重关心服务凝心聚力，激励支持行业广大知识分子发挥作用、创新奉献。
