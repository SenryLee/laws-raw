# 国家药品监督管理局公告2019年第105号——国家药监局关于注销一次性使用麻醉穿刺包医疗器械注册证书的公告

## 国家药监局关于注销一次性使用麻醉穿刺包医疗器械注册证书的公告

2019年第105号

按照《医疗器械注册管理办法》规定，根据企业申请，现注销江苏佰润医疗科技有限公司以下1个产品的医疗器械注册证书：

一次性使用麻醉穿刺包，注册证号：国械注准20173661042。

特此公告。

国家药监局

2019年12月9日
