# 国家邮政局关于发布《快件处理场所基础数据元》邮政行业标准的通知

国邮发〔2019〕78号

各省、自治区、直辖市邮政管理局，中国邮政集团公司，各主要快递企业：

现发布YZ/T 0168-2019《快件处理场所基础数据元》推荐性邮政行业标准。该项标准自2019年12月1日起施行，由人民交通出版社负责出版发行。《快件处理场所基础数据元》标准的发布与实施，对于加强快件处理场所数据资源规划管理，促进基础信息交换共享，提高数字化运营管理能力具有重要意义。请各单位认真组织标准的宣贯工作，采取有力措施推动标准实施，促进邮政行业持续健康发展。
