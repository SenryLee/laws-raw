# 国家卫生健康委关于下达甘肃省武威肿瘤医院重离子放射治疗系统配置许可的通知

国卫财务函〔2019〕265号

甘肃省武威肿瘤医院：

根据甲类大型医用设备配置管理有关规定和专家现场评审论证结果，经研究，决定同意你单位配置重离子放射治疗系统—碳离子治疗系统。请根据《质子和重离子加速器放射治疗技术管理规范（2017年版）》及《质子和重离子加速器放射治疗技术临床应用质量控制指标（2017年版）》等管理规定要求，规范开展诊疗活动，确保临床应用质量和安全。

国家卫生健康委

2019年11月29日
