# 国家档案局关于发布《满文档案著录名词与术语汉译规则》等7项行业标准的通知

各省、自治区、直辖市档案局、馆，河北省委办公厅、江苏省委办公厅，各计划单列市档案局、馆，新疆生产建设兵团档案局、馆，中央和国家机关各部委档案部门，中央军委办公厅保密和档案局，各人民团体档案部门，各中央企业档案部门，中国人民大学档案学院：

经全国档案工作标准化技术委员会审查通过，并经国家档案局批准，以下7项行业标准予以发布，自2019年9月1日起实施（标准电子版将在我局网站上登载）。

1.DA/T30—2019《满文档案著录名词与术语汉译规则》

（代替DA/T30—2002）

2.DA/T34—2019《国家档案馆爱国主义教育基地工作规范》

（代替DA/T34—2005）

3.DA/T72—2019《岩心档案管理规范》

4.DA/T73—2019《档案移动服务平台建设指南》

5.DA/T74—2019《电子档案存储用可录类蓝光光盘（BD-R）技术要求和应用规范》

6.DA/T75—2019《档案数据硬磁盘离线存储管理规范》

7.DA/T76—2019《绿色档案馆建筑评价标准》

国家档案局

2019年3月4日
