# 中国气象局对十三届全国人大二次会议第0176号、第0180号议案的办理意见

中气议字〔2019〕1号

全国人大环资委：

你委转来的武志永等30名代表和刘怀平等30名代表《关于修改大气污染防治法的议案》（第0176号、第0180号）收悉。我局高度重视议案提出的建议，组织相关职能司对议案内容进行了认真研究。有关意见反馈如下：

对于第0176号议案提出的对挥发性有机物和产生气态污染物的环节进行防治，增加落实重污染天气应急减排措施违法行为的处罚等建议和第0180号议案中提出的增加第三方治理的建议，我局完全同意，建议在修改《大气污染防治法》时予以考虑。

自《大气污染防治法》实施以来，气象部门依据大气污染防治法赋予的职责，全力做好大气污染防治气象保障工作。一是加强组织实施。印发《环境气象业务发展指导意见》《气象部门贯彻落实大气污染防治行动计划实施方案》；制定《全面加强生态环境保护 坚决打好污染防治攻坚战的意见》方案，强化重点区域秋冬季大气污染防治气象服务能力建设。二是加强环境气象监测预报预警。气象部门已建立了地空天一体化的气象综合观测网络，形成了国、省、市、县四级环境气象监测预报业务，组建了京津冀、长三角、珠三角、汾渭平原环境气象预报预警中心，预报产品的精准度和预见期不断提高。三是强化重大活动环境气象服务保障。在2014年APEC会议、2015年“9.3阅兵”纪念活动、杭州G20峰会、厦门金砖会议，上合峰会、中非论坛、进博会等重大活动中，提前分析研判大气污染气象条件，为精准高效防治污染提供决策支撑。四是深化部门合作，做好重污染天气应对。气象部门与生态环境部门不断深化合作，建立了常态化的空气质量和重污染天气会商机制，定期联合会商。当预测到即将发生重污染天气过程时，两部门联合开展加密会商，确保“一个声音说话”。

以上意见，供你委组织修改《大气污染防治法》时参考。

中国气象局

2019年5月27日
