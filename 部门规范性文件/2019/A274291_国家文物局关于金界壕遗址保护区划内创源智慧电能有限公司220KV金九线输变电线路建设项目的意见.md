# 国家文物局关于金界壕遗址保护区划内创源智慧电能有限公司220KV金九线输变电线路建设项目的意见

文物保函〔2019〕86号

内蒙古自治区文物局：

你局《关于创源智慧电能有限公司220KV金九线输变电线路项目在金界壕建控地带送线的请示》（内文物字〔2018〕100号）收悉。经研究，我局原则同意在金界壕遗址保护范围和建设控制地带内实施创源智慧电能有限公司220KV金九线输变电线路建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建项目相关区域做考古调查勘探和必要的考古发掘，明确地下文物遗存分布情况，为优化拟建项目选线提供科学依据。

（二）应综合考虑遗址本体和环境景观保护需要，适当增加拟建杆塔与金界壕遗址之间的距离，避让保护范围。同时，应确保施工质量，提高杆塔抵抗自然灾害能力，避免突发事故损害遗址。

（三）应细化施工方案，补充施工期间金界壕遗址临时防护措施，明确场地布置、施工组织、生态保护、景观控制等要求和污染物处置措施，完善监测措施和应急预案。

（四）应补充工程竣工后的地形地貌修复措施，完善金界壕遗址标识措施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月23日
