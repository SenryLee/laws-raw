# 国家卫生健康委办公厅关于印发大骨节病等重点地方病监测方案（2019版）的通知

国卫办疾控函〔2019〕478号

各省、自治区、直辖市及新疆生产建设兵团卫生健康委，中国疾病预防控制中心：

为贯彻落实党中央、国务院领导同志对地方病防治工作的重要指示批示精神，按照《地方病防治专项三年攻坚行动方案（2018—2020年）》中“疾病监测全覆盖行动”的有关要求，进一步强化监测与防治干预措施的有机结合，及时掌握病情变化趋势，更好地推进重点地方病控制和消除工作，我们组织专家对大骨节病、克山病、地方性氟中毒和地方性砷中毒监测方案进行了修订。现印发给你们，请结合本地实际情况组织实施。碘缺乏病和水源性高碘危害监测工作继续按照原监测方案执行。

附件：1.大骨节病监测方案（2019年版）

2.克山病监测方案（2019年版）

3.燃煤污染型地方性氟中毒监测方案（2019年版）

4.饮水型地方性氟中毒监测方案（2019年版）

5.饮茶型地氟病监测方案（2019年版）

6.燃煤污染型地方性砷中毒监测方案（2019年版）

7.饮水型地方性砷中毒监测方案（2019年版）

国家卫生健康委办公厅

2019年5月20日
