# 农业农村部对十三届全国人大二次会议第5522号建议的答复

## 对十三届全国人大二次会议第5522号建议的答复

你们提出的"关于实施乡村振兴战略的建议"收悉。经商自然资源部、税务总局、财政部、银保监会，现答复如下。

实施乡村振兴战略是党的十九大作出的重大决策部署，是决胜全面建成小康社会、全面建设社会主义现代化国家的重大历史任务，是新时代做好"三农"工作的总抓手。近年来，各部门围绕各自职责任务，出台了一系列政策措施，为推进乡村振兴提供了制度保障。

一、关于加大乡村振兴人才扶持力度

习近平总书记强调，乡村振兴，人才是关键。近年来，农业农村部等有关部门坚持培育本土人才与吸引外来人才"两条腿走路",不断强化乡村振兴的人才支撑。特别是在吸引留住人才方面，出台了一系列政策措施。一是加大政策支持力度，鼓励和吸引各类人才返乡下乡创业创新。为鼓励人才投身乡村，国务院办公厅印发《关于支持返乡下乡人员创业创新 促进农村一二三产业融合发展的意见》，完善各类扶持政策。其中，明确返乡下乡人员可在创业地按规定参加各项社会保险，有条件的地方要将其纳入住房公积金缴存范围，按规定将其子女纳入城镇（城乡）居民基本医疗保险参保范围。持有居住证的返乡下乡人员的子女可在创业地接受义务教育，依地方相关规定接收普惠性学前教育等政策措施。农业农村部联合发展改革委等13个部门组建"农村创业创新工作推进协调机制",联合各部门力量，统筹推进全国农业农村就业创业工作。在全国建设1000多个农村创业创新园区和孵化实训基地，举办全国新农民新技术创业创新博览会、全国农村创业创新大赛等，搭建了创业创新平台。二是深化农村土地改革，为吸引人才投身乡村建设创造条件。按照中央要求，目前正在深化农村土地制度改革，探索推进农村宅基地制度改革试点。2015年以来，33个试点县（市、区）按照"依法公平取得、节约集约使用、自愿有偿退出"目标要求，围绕保障农民住有所居、建立宅基地有偿使用和退出机制、盘活闲置房地资源、探索宅基地"三权分置"等进行了有益探索。例如，湖南浏阳允许符合宅基地申请条件的农民跨村组、乡镇申请宅基地，拓宽了宅基地供地渠道；浙江德清探索统筹城乡住房保障体系，允许自愿退出宅基地的农民申请城镇经济适用房、廉租房；试点地区还利用闲置宅基地发展乡村旅游、民宿等，探索支持闲置宅基地有序开发、合理利用、规范发展的措施。三是完善科技人才评价机制，引导鼓励科技人才到乡村工作。推进农业技术人员职称制度改革，人力资源社会保障部、农业农村部正在起草《关于深化农业技术人员职称制度改革的指导意见》，明确对长期扎根基层一线、作出突出贡献的农业技术人员适当放宽标准条件，引导科技人才向农业农村基层流动。

下一步，我们将会同各部门继续做好相关政策的研究，进一步加大对返乡创业人员的支持力度，稳慎推进宅基地制度改革，尽快推动出台农业技术人员职称评审的改革指导文件，鼓励支持各类人才到农村广阔天地大显身手。

二、关于创新乡村振兴的投入机制

贯彻落实中央关于乡村振兴战略部署，各部门加大了投入力度，积极构建多元投入保障机制，完善财政支持实施乡村振兴战略政策体系。一是加大资金投入力度。财政部印发《贯彻落实实施乡村振兴战略的意见》，对农业农村投入优先保障、多渠道资金筹集做了制度安排。关于土地出让金安排更大比例用于乡村建设，2018年中央一号文件明确提出，调整完善土地出让收入使用范围，进一步提高农业农村投入比例。目前，中央农办、自然资源部、财政部等部门正在研究改革土地出让收入使用的相关政策，拟进一步提高土地出让收益用于农业农村投入比例，集中用于"三农"重点领域和关键环节。二是加大村级集体经济组织的扶持力度。党中央国务院高度重视发展壮大农村集体经济。党的十八大以来的中央决定和1号文件，都对此提出明确要求。农业农村部会同财政部等相关部门，认真贯彻落实中央决策部署，做了大量工作。在税收优惠方面，2017 年，财政部会同税务总局印发《关于支持农村集体产权制度改革有关税收政策的通知》，明确在农村集体产权制度改革中免征有关契税、印花税。三是加大对乡村投资的工商企业税收支持力度。为支持"三农"发展，国家出台了一系列税费支持政策。在企业所得税方面，企业从事种植业、养殖业和农产品初加工等农业项目的所得免征企业所得税。在增值税方面，对农业生产者销售自产农产品，免征增值税，纳税人生产销售和批发、零售有机肥产品，免征增值税；批发和零售的种子、种苗、农机等，免征增值税等。近两年我国持续下调增值税税率，农产品税率已由13%下调至9%,降幅高达30%,农业深加工产品税率由17%下调至13%,降幅23.5%,有效降低了涉农纳税人增值税税负。在城镇土地使用税方面，对直接用于农、林、牧、渔业的生产用地，免征城镇土地使用税。在契税方面，对承受荒山、荒沟、荒丘、荒滩土地使用权用于农、林、牧、渔业生产的免征契税。农业企业和农村集体经济组织从事农业生产等相关经营活动符合条件的即可按规定享受税收优惠政策。

下一步，农业农村部将积极会同相关部门，继续加大对乡村振兴的投入力度，推动提高土地出让收入用于农业农村投入比例政策落地，继续指导各地稳步推进农村集体产权制度改革，确保各项改革落到实处。

三、关于推动产业向乡村布局

产业振兴是乡村振兴的基础。中央高度乡村产业发展，近日，国务院印发《关于促进乡村产业振兴的指导意见》，进一步明确了乡村产业的内涵特征、发展思路、实现路径和政策措施。各部门也围绕各自职能，加大了对乡村产业发展的支持力度。一是健全财政投入机制。加强一般公共预算投入保障，推动涉农资金统筹。2017年，国务院印发《关于探索建立涉农资金统筹整合长效机制的意见》（国发〔2017〕54号），提出加强行业内涉农资金整合与行业间涉农资金统筹衔接配合的改革思路，要求进一步下放审批权限，赋予地方必要的涉农资金统筹权，在预算编制环节加强涉农资金源头整合，在预算执行环节加强性质相同、用途相近的涉农资金统筹使用，促进功能互补、用途衔接的涉农资金集中投入。地方可按规定实施涉农资金统筹整合，因地制宜支持当地乡村建设和产业发展。二是完善用地保障政策。在安排土地利用计划时，加大对乡村产业发展用地的倾斜支持力度。自然资源部正研究起草《关于加强村庄规划促进乡村振兴的指导意见》，明确提出允许村庄规划在不改变县级国土空间规划主要控制指标情况下，优化调整村庄各类用地布局。同时，各地可在乡镇国土空间规划和村庄规划中预留不超过5%的建设用地机动指标，村民居住、农村公共公益设施、零星分散的乡村文旅设施及农村新产业新业态等用地可申请使用。对一时难以明确具体用途的建设用地，可暂不明确规划用地性质。三是加大金融支持产业力度。2019年2月，银保监会印发《关于做好2019年银行业保险业服务乡村振兴和助力脱贫攻坚工作的通知》，进一步加大了金融支农力度。2019年各银行业金融机构保持涉农贷款持续增长，并实现普惠型涉农贷款增速总体高于各项贷款平均增速。同时，做好各类现代农业主体金融服务。在产品创新方面，积极发展产业链金融，研发额度小、频度高、季节时限性较强、适合新型农业经营主体的特色贷款产品，探索农业保险保单质押贷款、农户信用保证保险贷款等银保合作产品。在服务方式创新方面，运用互联网、物联网、大数据、人工智能等技术，与农业企业、农产品交易平台系统对接，探索全流程在线操作的网络融资服务。

下一步，农业农村部将会同有关部门抓好政策贯彻落实，加快建立涉农资金统筹整合长效机制，提高涉农资金使用效益；指导各地科学有序推进村庄规划编制，切实做好乡村振兴产业发展的用地保障；继续引导金融机构加大金融产品方式创新力度，促进各类农业生产经营主体发展壮大。

感谢你们对"三农"工作的关心，希望今后继续对我部工作予以支持。
