# 中华人民共和国国家发展和改革委员会公告2019年第5号——国际“双十佳”最佳节能技术和实践清单、中国“双十佳”最佳节能技术和实践清单、实践说明

## 中华人民共和国国家发展和改革委员会公告

2019年第5号

为推广普及先进节能技术和实践，推动全球能效提升，国际能效合作伙伴关系（IPEEC）发起了评选和推广第二批国际“最佳节能技术和最佳节能实践”项目（简称“双十佳”）。

国家发展改革委根据IPEEC《最佳节能技术和最佳节能实践评价方法和评选指南》，评选出了中国“双十佳”，并会同美国能源部、日本经济产业省、法国生态转型和团结部从IPEEC成员国提交的节能技术和实践中评选了国际“双十佳”，现予以公告。

附件：1.国际“双十佳”最佳节能技术和实践清单

2.中国“双十佳”最佳节能技术和实践清单

3.中国“双十佳”最佳节能技术和实践说明

国家发展改革委

2019年6月11日
