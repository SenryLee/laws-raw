# 司法部关于印发中国委托公证人（香港）名单的通知

司发通〔2019〕74号

各省、自治区、直辖市司法厅（局），新疆生产建设兵团司法局：

第十二批中国委托公证人（香港）新增委托工作已完成，现将司法部自1981年以来陆续委托并仍履行职务的中国委托公证人（香港）名单（共457人）印发给你们。请你们转发各市、县（区）司法局及各公证处，作为受理涉港公证文书的核验依据。

附件：中国委托公证人（香港）名单

司法部
