# 国家文物局关于在南京城墙建设控制地带内进行中华门越城天地地块建设项目的意见

文物保函〔2019〕144号

江苏省文物局：

你局《关于审批南京市秦淮区中华门越城天地地块项目方案修改稿的请示（南京城墙）》（苏文物保〔2018〕326号）收悉。经研究，我局原则同意在南京城墙建设控制地带内进行中华门越城天地地块建设项目。

一、所报方案尚需做以下必要的修改和完善：

（一）建议建筑组群布局适当错落，避免过于规整的行列式布局，部分建筑外观宜控制、切分整体玻璃幕墙的面积。

（二）明代窑址保护棚应进一步弱化形式，增加场地排水设计和遗址后期日常保养等措施；宜取消窑址保护房中间栈道。

（三）鉴于拟建项目位于南京市地下文物重点保护区，应进一步完善、细化施工方案。补充施工期间对南京城墙和两处明代窑址的临时性保护方案；评估各类振动对文物本体的影响，补充必要的监测措施，审慎开展地基、基础、基坑等工程，确保文物安全，及时排除安全隐患。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月11日
