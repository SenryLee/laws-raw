# 国家档案局关于下达《2019年度国家档案局科技项目计划》的通知

经国家档案局科技项目立项评议委员会评议和国家档案局批准，确定列入2019年度国家档案局科技项目计划87项，所有项目在国家档案局网站进行了公示，均无异议。现将《2019年度国家档案局科技项目计划》下达给你们，请及时通知项目承担单位，加强项目实施情况管理，并于每年10月底前将项目进展情况报我局。

联系部门：技术部科技处

联系电话：010-63093016、55605255

电子信箱：kjc@saac.gov.cn
