# 国家文物局对十三届全国人大二次会议第6068号建议的答复

文物保函〔2019〕634号

黄艳代表：

您提出的“关于践行文化自信加快推进殷墟国家考古遗址公园建设的建议”收悉。经商国家发展和改革委员会、财政部、自然资源部、文化和旅游部，现答复如下。

殷墟是商代后期都城遗址，是中国近代考古学诞生和成长的摇篮，文化遗产丰富，历史底蕴深厚。1961年被国务院公布为首批全国重点文物保护单位，2006年被联合国教科文组织列入世界文化遗产名录。国家历来高度重视殷墟保护工作。“十一五”以来，殷墟一直被列入国家大遗址保护项目库，中央财政在考古研究、规划编制、本体监测、保护展示等方面给予重点支持。2010年，国家文物局公布殷墟为第一批国家考古遗址公园。2017年，国家发展和改革委员会联合7部门印发《“十三五”时期文化旅游提升工程实施方案》，将殷墟宫殿宗庙遗址项目列入“十三五”时期文化旅游提升工程实施方案项目库。2019年，《殷墟国家考古遗址公园规划》由国家文物局批复，为科学开展殷墟文物保护利用工作提供了指引和依据。

您提出的关于在文物保护展示项目审批和资金方面给予大力支持等四项建议，对于进一步推动殷墟遗址保护利用具有重要意义。下一步，国家文物局将会同相关部门继续做好如下工作。

第一，积极支持河南省、安阳市人民政府做好殷墟国家考古遗址公园建设。按照《殷墟国家考古遗址公园规划》，抓紧明确殷墟宫殿宗庙区展示提升项目、王陵区展示提升项目、殷墟核心区环境整治项目实施方案；结合安阳市建设发展，统筹推进殷墟遗址博物馆建设、环境整治及老工业区改造等项目实施。国家有关部门将在项目审批和经费方面继续予以重点倾斜。

第二，保障殷墟考古遗址公园的合理空间需求。根据《国务院关于深化改革严格土地管理的决定》（国发〔2004〕28号），土地利用计划实行分级管理，殷墟遗址保护范围约23平方公里的建设用地指标由地方统筹安排。自然资源部将指导、督促河南省加强土地利用计划管理，保障项目落地；同时，指导地方按照《中共中央 国务院关于建立国土空间规划体系并监督实施的若干意见》要求，因地制宜开展国土空间规划编制工作，在资源环境承载能力和国土空间开发适宜性评价的基础上，充分考虑《殷墟国家考古遗址公园规划》确定的规划任务目标。

第三，关于殷墟列入国家文化公园名单。建设国家文化公园是《国民经济和社会发展第十三个五年规划纲要》提出的重大文化工程。目前，中共中央宣传部正在制定上报《长城、大运河、长征国家文化公园试点建设方案》，待正式方案出台后，文化和旅游部将按照中央的统一要求，强化顶层设计，制定国家文化公园保护利用标准体系，届时将研究殷墟列入国家文化公园名单事宜。

感谢您对文物事业的关注和支持！

国家文物局

2019年7月5日
