# 国家体育总局办公厅关于进一步做好体育系统解决形式主义突出问题为基层减负有关工作的通知

## 体育总局办公厅关于进一步做好体育系统解决形式主义突出问题为基层减负有关工作的通知

各厅、司、局：

今年3月，中共中央办公厅印发《关于解决形式主义突出问题为基层减负的通知》（以下简称《通知》），决定将2019年作为“基层减负年”，强调要解决一些困扰基层的形式主义问题，切实为基层减负。根据中央通知精神，总局党组专题研究，深刻认识到《通知》围绕习近平总书记强调要为基层减负这一根本要求，本身就是解决形式主义突出问题的文件范本，目标明确、措施具体，对如何解决形式主义做出了具体指导。对照《通知》中强调要着力解决的四个问题，总局制定了由职能部门牵头负责的任务分工方案。

为进一步做好体育系统解决形式主义突出问题为基层减负工作，现将有关要求通知如下：

一、总局机关各厅司局要深入学习领会《通知》精神，按照总局有关牵头部门具体要求，切实解决工作中存在的“党性不纯、政绩观错位”“文山会海反弹回潮”“督查检查考核过多过频、过度留痕”及“干部不敢担当作为”等形式主义突出问题。

二、总局不再专门召开贯彻落实《通知》动员部署会，不再另行制定贯彻落实《通知》实施意见，也不再要求层层制定相关工作方案。各厅司局要按照《通知》精神，结合自身工作实际，实事求是地在业务工作中解决形式主义，切实为基层减负。请各厅司局将《通知》印发以来本部门有效经验做法和下阶段工作考虑于5月17日前报送至办公厅，相关材料应简明扼要，篇幅控制在600字以内。

三、原则上不再要求各厅司局报送贯彻落实《通知》的阶段性工作情况、总结报告等材料。总局党组将以巡视、督查等为抓手，会同驻总局纪检监察组及时通报曝光典型问题，总结推广先进做法，实打实地发现问题、解决问题，真正做到轻留痕、重实效。

当前，“三大任务”备战形势紧迫，体育事业改革扎实推进，切实转变工作作风，解决形式主义突出问题是加快推进体育强国建设，推动体育事业发展再上新台阶的重要手段。总局党组将严格履行整治形式主义为基层减负主体责任，一把手负总责。各厅司局要把力戒形式主义、官僚主义作为日常工作的重要任务，主要负责同志亲自抓，拿出有效管用的整治措施，狠抓贯彻落实。

以上情况，特此通知。

办公厅

2019年4月30日

## 体育总局贯彻落实《中共中央办公厅关于解决形式主义突出问题为基层减负的通知》任务分工方案

一、以党的政治建设为统领加强思想教育，着力解决党性不纯、政绩观错位的问题

总体要求：将力戒形式主义、官僚主义作为总局开展的“不忘初心、牢记使命”主题教育重要内容；从总局党组做起，开展作风建设专项整治行动，坚决防止和纠正落实党中央决策部署不用心、不务实、不尽力，口号喊得震天响、行动起来轻飘飘的问题，真正把树牢“四个意识”、做到“两个维护”的要求落到实处。

责任分工：机关党委牵头，按照中央统一部署，在下一步开展的“不忘初心、牢记使命”主题教育中，将力戒形式主义、官僚主义作为重要内容。根据《通知》精神，进一步修改完善《体育总局党组关于集中整治形式主义、官僚主义工作方案》，报总局党组审定后组织实施。

二、严格控制层层发文、层层开会，着力解决文山会海反弹回潮的问题

总体要求：认真贯彻落实中央八项规定及其实施细则精神，大幅度精简总局有关文件和会议，确保可以重点精简的文件、召开的会议减少30%－50%。发扬“短实新”文风，总局印发的政策性文件原则上不超过10页，从严掌握。贯彻落实中央和上级文件，结合总局工作实际制定贯彻落实意见和实施细则。总局会议原则上只开到省级体育部门，严禁随意拔高会议规格、扩大会议规模，未经批准不得要求省（区、市）党委和政府负责同志以及体育局一把手参会，减少陪会。提倡合并开会、套开会议，提高会议实效，不搞照本宣科，不搞泛泛表态，不刻意搞传达不过夜，坚决防止同一事项议而不决、反复开会。

责任分工：办公厅牵头，各司局配合，制定2019年度精简文件和会议工作方案，对总局印发文件数量、篇幅提出明确要求，严格执行会议计划管理，严控各类会议规格、规模，切实提高会议实效。

三、加强计划管理和监督实施，着力解决督查检查考核过多过频、过度留痕的问题

总体要求：贯彻落实《中共中央办公厅关于统筹规范督查检查考核工作的通知》，实行年度计划和审批报备制度，总局原则上每年搞不超过1次综合性督查检查考核，对基层体育部门、体育场馆、学校等的督查检查考核事项减少50%以上。强化结果导向，坚决纠正机械式做法，不得随意要求基层填表报数、层层报材料，严格控制“一票否决”事项，不能动辄签“责任状”，变相向地方和基层推卸责任。对涉及城市评选评比表彰的各类创建活动进行集中清理，该撤销的撤销，该合并的合并。

责任分工：办公厅、人事司牵头，严格实施《体育总局督促检查工作实施办法》，研究制定总局层面的评比表彰实施办法；充分发挥总局每周通气会制度作用，提高督查督办实效；科学制定考核评价机制，坚决纠正层层填表报数、层层转嫁责任的机械式做法。各部门积极配合人事司，集中清理合并总局涉及城市评选评比表彰的各类创建活动。

四、完善问责制度和激励关怀机制，着力解决干部不敢担当作为的问题

总体要求：有效解决问责不力和问责泛化简单化等问题。正确对待被问责的干部，对影响期满、表现好的干部，符合有关条件的，该使用的要使用。保障党员权利，及时为干部澄清正名，严肃查处诬告陷害行为。改进谈话和函询工作方法，有效减轻干部不必要的心理负担。把"三个区分开来"的要求具体化，正确把握干部在工作中出现失误错误的性质和影响，切实保护干部干事创业的积极性，对勇于创新、敢于担当的基层干部，对奋战在总局“三大任务”备战工作第一线的干部，对援藏援疆、援助革命老根据地、扶贫攻坚地区的干部，给予更多理解和支持，在政策、待遇等方面给予倾斜。

责任分工：人事司牵头，机关纪委配合，商请驻总局纪检监察组支持，按照《中国共产党问责条例》制定的处理检举控告工作规则有关要求，制定总局工作方案。按照《关于进一步激励广大干部新时代新担当新作为的意见》精神，对勇于创新、敢于担当的基层干部，对奋战在总局“三大任务”备战工作第一线的干部，对援藏援疆、援助革命老根据地、扶贫攻坚地区的干部，给予政策、待遇倾斜保障。
