# 国家文物局关于政协十三届全国委员会第二次会议第2142号（文化宣传类185号）提案答复的函

文物政函〔2019〕897号

徐立全等10位委员：

您提出的“关于加强大别山区革命文物保护利用的提案”收悉。经商国家发展改革委、文化和旅游部、交通运输部，现答复如下。

党和国家高度重视大别山区革命文物保护利用工作。中央宣传部、财政部、文化和旅游部、国家文物局公布了第一批革命文物保护利用片区分县名单，其中位于大别山区的鄂豫皖片区覆盖湖北、河南、安徽3个省41个县。国家发展改革委通过文化旅游提升工程，累计安排中央预算内投资2.5亿元，支持大别山区旅游基础设施建设，重点打造大别山区红色旅游品牌。交通运输部制定《大别山集中连片特困地区交通建设扶贫规划》，“十三五”期间重点支持G42S岳西至无为段、G106麻城上畈至彭店段、G318罗田县城关至三里畈段等重点公路项目建设，安排车购税资金约6.3亿元支持红安县大别山抗日军政学校旧址、刘邓大军挺进大别山指挥部旧址、黄冈革命烈士陵园对外连接公路等红色旅游公路建设。文化和旅游部将大别山区14处景区列入《全国红色旅游经典景区名录》，通过国家红色旅游专项建设资金提升景区红色资源保护和旅游基础设施建设水平，将大别山区纳入红色旅游人才培训计划。国家文物局支持湖北、河南、安徽编制《大别山区革命文物保护利用战略规划》，实施一批大别山区革命文物保护展示项目。

下一步，中央相关部门将以深入贯彻落实中共中央办公厅、国务院办公厅《关于实施革命文物保护利用工程（2018-2022年）的意见》为重要抓手，加强组织协调，加大支持力度，进一步做好大别山区革命文物保护利用工作。

一是统筹推进大别山区革命文物集中连片保护。以鄂豫皖革命文物保护利用片区为重点，支持编制分省分市片区革命文物保护行动计划，支持建立大别山区革命文物保护利用跨省协作机制，推动资源共享、协同保护。四部门正在研究编制第二批革命文物保护利用片区分县名单，统筹考虑鄂豫皖抗日根据地革命史实，将有关市县纳入片区范围。

二是统筹加大对大别山区革命文物保护支持力度。《国家文物保护专项资金管理办法》明确提出国家文物保护专项资金适当向革命老区倾斜，向党中央、国务院确定的重点支持方向革命文物保护倾斜，将省级及省级以下文物保护单位保护纳入支持范围，支持革命文物保护利用片区整体陈列展示。国家文物保护专项资金支持大别山区实施一批、完工一批、储备一批革命文物保护项目，筑牢革命文物安全底线，切实改善革命文物保存状况和环境风貌，有效提升革命文物展示陈列水平。

三是继续支持大别山区交通基础设施建设。按照《大别山区集中连片特困地区交通建设扶贫规划》《全国红色旅游公路规划（2017-2020年）》，提升大别山区国家高速公路和普通国省干线公路的保障能力和服务水平，部省合力推动“大别山区红色旅游公路”建设，为发展红色旅游、实现脱贫攻坚提供有力支撑。

四是打造大别山区红色文旅品牌。深入挖掘红色资源的价值内涵和文化元素，提升革命旧址和革命博物馆纪念馆的展陈水平和服务质量，增强互动性体验性。支持大别山区走优质旅游景区建设之路，突出自身特色、保持红色本色，强化品牌建设、扩大宣传推广，推介红色旅游精品线路，通过红色旅游的示范作用推动文旅融合发展。邀请知名旅行商和媒体实地采风踩线，提供全国性旅游展会免费展示平台。支持安徽省金寨县创建两源两地国家5A级旅游景区。湖北省、河南省相关景区如有创建国家5A级旅游景区需求，可向省文化和旅游部门提出初检申请，文化和旅游部将按程序组织开展相关工作，并酌情对创建工作予以指导。

感谢您对革命文物工作的关心和支持。

国家文物局

2019年8月29日
