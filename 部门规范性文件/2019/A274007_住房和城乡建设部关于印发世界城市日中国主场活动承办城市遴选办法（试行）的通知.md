# 住房和城乡建设部关于印发世界城市日中国主场活动承办城市遴选办法（试行）的通知

建外〔2019〕1号

各省、自治区住房和城乡建设厅，直辖市住房和城乡建设（管）委，新疆生产建设兵团住房和城乡建设局：

为贯彻落实《中共中央国务院关于进一步加强城市规划建设管理工作的若干意见》的要求，办好世界城市日中国主场活动，我部制定了《世界城市日中国主场活动承办城市遴选办法（试行）》。现印发给你们，请遵照执行。

中华人民共和国住房和城乡建设部

2019年1月3日

附件：世界城市日中国主场活动承办城市遴选办法（试行）
