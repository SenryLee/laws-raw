# 国家森林草原防灭火指挥部办公室关于发布森林火险黄色和橙色预警的通知

国森防办发明电〔2019〕50号

北京市、河北省、安徽省、江西省、湖北省、湖南省、广东省、广西壮族自治区森林（草原）防（灭）火指挥部：

9月以来，北京东北部、河北北部、安徽西南部、江西大部、湖北东部、湖南北部和东南部、广东北部、广西东北部气温较常年同期偏高1-2℃，局部地区偏高2-4℃，降水较常年同期偏少5成以上，森林火险等级明显偏高。预计未来7天，上述地区仍无明显降水，旱情持续。

经综合研判气象条件、林区物候、卫星监测热点及火灾发生情况，预计国庆期间（10月1日至7日），北京东北部、河北北部的部分地区森林火险等级将维持在中度危险级别，安徽西南部、江西大部、湖北东部、湖南北部和东南部、广东北部、广西东北部的部分地区森林火险等级将维持在高度危险级别，森林防火形势严峻，特向北京市、河北省发布森林火险黄色预警，向安徽、江西、湖北、湖南、广东、广西等省（区）发布高森林火险橙色预警。

望你们高度重视，及时关注天气和森林火险变化趋势，严格落实责任，确保各项高森林火险应急响应措施落实到位，严防森林火灾发生。

国家森林草原防灭火指挥部办公室

2019年9月30日
