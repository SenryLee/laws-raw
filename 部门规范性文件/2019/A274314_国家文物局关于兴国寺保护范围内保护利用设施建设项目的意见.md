# 国家文物局关于兴国寺保护范围内保护利用设施建设项目的意见

文物保函〔2019〕129号

甘肃省文物局：

你局《关于呈报兴国寺保护利用设施建设项目设计方案的请示》（甘文局发[2018]177号）收悉。经研究，我局原则同意兴国寺保护范围内保护利用设施建设项目。

一、对所报方案提出以下修改完善意见：

（一）进一步论证新建厕所的必要性及其选址的合理性，补充分析新建厕所与兴国寺建筑院落、建筑及整体空间的关系。

（二）优化新建厕所选址及外观设计，可不限于仿古样式，材料、尺度等方面与周边环境协调即可，宜进一步压缩其体量，避免对寺院格局产生干扰。

（三）补充市政管网的有关资料，确保新建给水、排水、电力等管线与既有管网的有序衔接。

（四）补充对文物建筑的监测要求和措施，确保文物安全。

（五）不同意整体翻新寺内步道、绿化及院落围墙，基于现状进行局部整理即可。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月31日
