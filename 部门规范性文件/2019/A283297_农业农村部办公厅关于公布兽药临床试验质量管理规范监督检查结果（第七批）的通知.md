# 农业农村部办公厅关于公布兽药临床试验质量管理规范监督检查结果（第七批）的通知

农办牧〔2019〕68号

为规范兽药研究活动，根据《兽药管理条例》《兽药临床试验质量管理规范》《兽药非临床研究与临床试验质量管理规范监督检查办法》以及监督检查标准，我部组织专家对中国水产科学研究院长江水产研究所等7家单位进行了监督检查。经监督检查，中国水产科学研究院长江水产研究所等7家单位的20个试验项目符合兽药临床试验质量管理规范（以下简称“兽药GCP”）要求。现公布监督检查结果（附后）。详细信息见中国兽药信息网“兽药GLP\GCP监督检查”专栏。

请各省级畜牧兽医行政管理部门切实做好日常监督管理工作，督促相关单位按照兽药GCP要求开展兽药研究活动。

附件：符合兽药临床试验质量管理规范要求的单位和试验项目

农业农村部办公厅

2019年10月18日
