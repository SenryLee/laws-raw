# 中华人民共和国海关总署对全国政协十三届二次会议第0011号(科学技术001号)提案的答复

孙毅彪委员：

您提出的《关于有效应对知识产权边境保护新挑战的提案》（第0011号）收悉。经会同国家知识产权局研究，现答复如下：

一、关于完善法律法规，提高执法效率

2018年8月31日，十三届全国人大常委会第五次会议表决通过《电子商务法》，自2019年1月1日起施行。该法明确规定了电子商务经营者的义务，特别是第四十一条至第四十五条及第八十四条分别规定了知识产权保护方面的义务及法律责任。为有效实施《知识产权海关保护条例》及有关法律法规，规范知识产权海关保护执法，保障当事人和知识产权权利人合法权益，进一步推进知识产权海关保护执法统一性，规范自由裁量权行使，厘清海关执法权的边界，简化海关执法程序，提高案件办理效率，海关总署先后制定了《海关对进出口侵犯知识产权货物违法行为行政处罚幅度参照标准（暂行）》《知识产权海关保护工作规程》等规范性文件，就知识产权海关保护行政处罚案件减轻处罚情节、从轻处罚情节、从重处罚情节及确定案值等情形予以进一步明确，对知识产权海关保护执法过程中案件线索举报处置、依申请保护程序、依职权保护程序、行政处罚的执行、侵权物品的处理程序、罚没侵权货物处置等问题予以了进一步细化。

二、关于加强国内外、部门间合作

知识产权海关保护合作是海关国际合作的重要内容。目前，中国海关已与美、欧、日、韩等国家/地区海关建立了专门的知识产权合作机制，把知识产权海关保护合作机制化、常态化。中国海关也积极参与世界海关组织、世界知识产权组织、国际刑警组织、上海合作组织等主要多边合作框架下的知识产权事务，积极参与全球治理，同时加强与“一带一路”沿线国家海关在知识产权保护方面的交流与合作。

国内负责知识产权保护工作的各部门也不断拓展跨部门执法协作，加快形成协同打击侵权假冒行为的合力。海关总署深入推进“两法衔接”工作，会同公安部对重大侵权案件进行联合督办。海关总署与原国家工商总局、国家知识产权局都建立了合作机制。2018年深化党和国家机构改革后，海关总署与国家知识产权局的相关合作也得到进一步加强，一是积极推进各地知识产权系统建立与当地海关的专利执法维权协作机制，由当地知识产权局为当地海关在认定专利侵权方面提供协助，依申请快速出具侵权判定咨询意见书；二是推进建立专利违法信息分析与共享机制，海关可根据共享信息针对侵权嫌疑货物进行布控，及时告知权利人并引导其依法维权；三是国家知识产权局与海关总署建立进出口货物专利违法产品行业分析机制，聚焦重点行业组织开展专项检查。此外，国家知识产权局于2019年3月印发《2019年度全国知识产权系统执法保护专项行动方案》，要求外向型经济发达、进出口贸易量大的地区进一步强化与海关等部门的联系和信息沟通，履行好业务指导职责，协助做好商标专利侵权认定等专业工作，切实做好商标专利行政执法与海关知识产权保护措施的衔接，坚决遏制知识产权侵权货物进出口。

三、关于加强政府部门与企业行业间合作

海关总署与权利人及企业长期以来都保持良好的合作关系，通过提供培训、送法上门、走访企业等方式，及时了解企业在知识产权海关保护方面遇到的困难，为企业答疑解惑。海关总署与中国机电产品进出口商会、中国摩托车商会、中国制笔协会、中国外商投资企业协会优质品牌保护委员会、国际商标协会等有关行业组织建立了知识产权合作机制。各地海关也立足关区实际，探索关企合作新途径，协助企业梳理知识产权状况，结合企业实际提出知识产权保护综合策略建议。海关总署还以杭州海关为试点，与阿里巴巴签署合作备忘录，就跨境电商平台打假开展线上线下综合治理。海关总署坚持打击侵权和促进创新相结合，把为企业提供优质知识产权保护服务作为转变职能、简政放权的重要抓手。着力提升企业维权能力，降低维权成本，促进行业自律，构建“亲”“清”新型政企关系。

国家知识产权局进一步加强电商平台专利行政执法保护力度。2016年组织成立了中国电子商务领域专利执法维权协作调度（浙江）中心，加强对全国网络电子商务领域专利执法维权工作的统筹协调，合理配置全系统优质执法资源，确保该领域专利执法维权工作取得扎实成效。目前参与协作调度的省份已拓展至25个。同时，推进电子商务比较发达的浙江、北京、江苏等地在该领域专利执法保护工作中先行先试，分别与大型电子商务企业建立合作机制，组织执法人员进驻电商平台，现场处理侵权假冒投诉，大幅提升办理电子商务领域专利案件的力度与效率，有效维护权利人合法权益。2018年共查处电商领域专利侵权假冒案件33025件，同比增长66.4%。不断提升对网络商标侵权假冒违法行为的打击力度，共查处利用互联网实施商标侵权假冒案件643件，同比增长73.78%，案值2318.05万元。

四、关于加强执法能力建设

海关树立科技兴关理念，充分利用科技手段开展知识产权保护。海关总署在全国海关推广“知识产权海关保护备案移动查询系统”，提高查获侵权货物时效性与准确性；加快“知识产权海关保护执法系统”升级改造，推进知识产权海关保护案件办理无纸化进程。海关总署运用大数据思维加强海关知识产权保护，借助互联网企业在日常运营中生成、累积的网络交易数据，实现各领域打击侵权假冒执法联动，成立了全国海关知识产权风险分析专家组，以及全国海关快件与跨境电商渠道涉侵权风险防控工作小组，加强对寄递和跨境电商零售渠道侵权风险的防控工作。

国家知识产权局大力实施知识产权行政执法能力提升工程，建立课程规范、考试严格的培训机制。组建执法培训师资库与执法办案骨干库。组织编写执法培训系列教材，分层次、分区域组织举办上岗培训班和能力提升班。完成专利侵权判定咨询专家库建设，推进专利侵权判定咨询工作，为知识产权保护工作提供专家人才支撑。开展“一带一路”沿线省（区、市）等区域执法协作交流活动，提升执法能力和执法水平。2019年计划举办4期全国知识产权保护能力提升培训班，第一期已于5月在江苏省南京市顺利举办，就专利商标法律制度、确权与侵权判定、执法保护程序与实体等内容对执法一线业务骨干进行系统培训。

五、关于加强宣传

保护知识产权离不开公众意识的提升。围绕世界知识产权日，国家知识产权局与18个部委联合举办2019年全国知识产权宣传周活动。宣传周期间，全国各地共开展活动逾万项，相关信息总量超1.3万篇，较2018年增长超65%。同时，注重提升重点群体知识产权意识。针对创新主体开展政策宣讲，帮助企业了解包括海关知识产权保护在内的知识产权工作。通过报道企业在知识产权工作中的典型做法和优秀经验，鼓励和引导创新主体积极寻求知识产权保护。针对中小学生群体，联合教育部开展全国中小学知识产权教育试点示范工作。截至2019年3月，已评定首批25所全国中小学知识产权教育示范学校，4批次共165所试点学校。每年组织举办4期知识产权教师培训，累计培训中小学教师近1200人次。

感谢您对知识产权边境保护工作的关心与支持，并欢迎继续对我们的工作提出宝贵的意见和建议。

海关总署

2019年6月11日
