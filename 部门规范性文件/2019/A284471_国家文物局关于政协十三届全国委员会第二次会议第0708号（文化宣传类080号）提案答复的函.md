# 国家文物局关于政协十三届全国委员会第二次会议第0708号（文化宣传类080号）提案答复的函

文物保函〔2019〕778号

袁靖委员：

您提出的《关于做好国家考古遗址公园建设的提案》（第0708号）收悉。经商国家发展和改革委员会、自然资源部，现答复如下：

2009年，国家文物局印发《国家考古遗址公园管理办法（试行）》，全面推动国家考古遗址公园建设工作。迄今为止，国家文物局已评定公布36处国家考古遗址公园和67处国家考古遗址公园立项单位，国家考古遗址公园在学术研究、经费投入、管理运行、文化普及等方面都取得了显著成绩，有效协调了遗址保护与地方经济社会发展之间的关系，为丰富我国文物保护管理体系、建立文化自信做出了重要贡献。

您提出的建立国家考古遗址公园体系、明确大型古遗址土地政策、做好遗址公园建设发展、加大经费支持力度等建议非常重要。国家文物局将与有关部门一起，重点推进如下工作：

第一，继续完善国家考古遗址公园体系。国家文物局将积极贯彻落实《关于加强文物保护利用改革的若干意见》，不断完善国家考古遗址公园的顶层设计和法律法规体系，与国家发展和改革委员会、自然资源部等部门积极沟通，参照国家公园模式，探索国家考古遗址公园相关制度设计，积极创新文物资源资产管理机制，不断提升考古遗址公园的保护管理能力和公共文化服务水平，促进中华优秀传统文化创造性转化和创新性发展。

第二，进一步明确考古遗址公园土地政策。目前，《土地利用现状分类》（GB/T 21010-2017）中未单列“文物古迹用地”。自然资源部门认为，国家考古遗址公园可根据实际情况参照“风景名胜设施用地”予以认定，目前无需专门增加“文物古迹用地”类型。国家文物局将与自然资源部门密切沟通，指导、鼓励地方人民政府结合“多规合一”，明确公园边界、加强空间管控，通过土地确权、租赁等方式，统筹考虑遗址保护、公园建设用地，缓解文物保护压力。

第三，进一步指导做好国家考古遗址公园建设发展。国家文物局将以36处国家考古遗址公园和67处国家考古遗址公园立项单位为重点，指导开展考古研究、本体保护、环境整治、展示利用、运行管理等各项工作，充分发挥公园在构建公共文化服务体系、满足人民群众日益增长的美好生活需要、增强文化自信心和民族凝聚力等方面的重要作用，走出一条具有中国特色的大型古遗址保护利用之路。

第四，多渠道加大经费支持力度。国家文物局将根据《国家文物保护专项资金管理办法》，继续支持地方开展考古发掘、文物本体保护与展示、环境整治等工作，给予经费保障。同时，将与国家发展和改革委员会等部门密切沟通，指导地方继续推进文化旅游提升工程，促进文物保护与经济社会的协调发展。国家文物局将继续引导地方人民政府丰富资金渠道、用活现有政策，依法统筹各项资金支持国家考古遗址公园的建设与运行工作，鼓励社会资本依法投入国家考古遗址公园建设。

感谢您对文物工作的关心和支持！

国家文物局

2019年8月5日
