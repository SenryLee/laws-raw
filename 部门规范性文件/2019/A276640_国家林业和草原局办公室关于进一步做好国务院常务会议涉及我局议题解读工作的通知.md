# 国家林业和草原局办公室关于进一步做好国务院常务会议涉及我局议题解读工作的通知

办发字〔2019〕93号

国家林业和草原局各司局、各派出机构、各直属单位：

近日，国务院办公厅信息公开办印发了《关于进一步健全国务院常务会议解读机制的实施意见》（以下简称《实施意见》），对进一步健全国务院常务会议解读机制提出了明确要求。为进一步做好国务院常务会议涉及我局议题的解读工作，按照《实施意见》有关精神和局领导批示要求，现将有关事项通知如下：

一、深化思想认识

加大政策发布解读力度，引导社会预期，及时回应社会关切、接受人民监督，对于发展社会主义民主政治，提升国家治理能力，增强政府公信力，保障人民群众知情权、参与权、表达权、监督权，具有十分重要的意义。国务院常务会议解读是全面贯彻落实党中央、国务院决策部署的重要途径和手段。各司局、各派出机构、各直属单位要立足于新时代林草事业改革发展大局，进一步深化对国务院常务会议解读工作重要性的认识，统一思想，按照“解读是常态、不解读是例外，谁起草、谁解读，发布与解读同步”的原则，丰富内容，创新方式，提升质量，注重效果，向市场主体和社会公众全面、及时、精准、深入阐释国务院常务会议涉及我局业务的林草重大决策及重要文件精神，积极回应社会关切，更好服务林业和草原改革发展大局。

二、突出重点议题

围绕国务院常务会议涉及我局业务的可公开议题，具体包括我局拟出台的重大决策及重要文件，重点解读政策措施的背景依据、目标任务、主要内容、实施范围、执行标准，以及关键词、注意事项、惠民利民举措等，使市场主体、社会公众充分了解政策意图和内涵。

（一）经济类议题。要注重阐释政策措施在激发林草产品市场主体活力、优化公平营商环境、培育壮大新动能、释放内需潜力、推动高质量发展等方面的积极作用，回应市场主体关心的热点问题，加强市场预期管理。

（二）民生类议题。要充分考虑社会各界关注重点，有针对性地拟订解读口径，系统阐释破解民生痛点、难点、堵点的林草政策措施，着力回应民生关切，阐明林草政策在保障和改善民生方面的价值取向，促进形成合理预期。

（三）行政法规类议题。要深入阐释林草立法目的、主要制度、权利义务、法律责任等，让相关各方充分知晓各自权利、义务，促进平稳实施、落地见效。

相关议题曾面向社会征求意见的，还要说明通过公众参与、专家论证、听证座谈、咨询协商等广泛听取意见、反复研究论证、最大限度凝聚共识的情况。对群众、企业切身利益或权利义务有重大影响的林草政策举措，除依法应当保密的外，政策出台前应通过多种方式广泛听取社会公众和市场主体的意见，并以便于公众知晓的方式公布意见收集和采纳情况。

政策发布后，要密切跟踪舆情动态，针对市场主体和社会公众关切事项，及时解疑释惑。跟进政策落实进展和实施效果，及时发布典型案例、经验做法和积极进展，进一步增强市场和社会信心。

三、丰富解读方式

（一）依托国务院政策例行吹风会平台权威解读。要紧紧围绕林草政策措施中新闻性强、媒体关注度高的内容设置议题和问题，将主动释放、公众关心、媒体关注的内容有机结合起来，提升媒体参与度。要充分运用数字、图表等简洁明快的方式，提升吹风会效果。局宣传办要牵头协调议题承办单位积极围绕相关议题准备材料，同时协调国务院办公厅相关部门，为局领导参加吹风会做好充分准备。

（二）议题承办单位负责同志主动发声解读。议题承办单位负责同志要围绕相关议题、重大决策及重要文件，通过撰写解读文章、接受媒体和政府网站采访、答记者问、参加会议论坛宣讲等多种形式，全面深入介绍相关政策背景、主要内容、落实措施、工作进展等。要会同局宣传办主动联系主流媒体，同时发挥我局所属媒体作用，提升解读效果，扩大解读覆盖面。

（三）权威专家精准深度解读。充分发挥专家解读专业性强、信息量大、受公众欢迎的优势，议题承办单位要及时推荐掌握相关政策、熟悉相关领域业务的权威专家接受采访。同时，根据议题审议情况，邀请专家、智库及时撰写有深度、有分量的解读文章。

（四）做好市场主体和社会公众解读。可商请中央宣传部（国务院新闻办）安排中央和地方媒体，围绕林草重大决策及重要文件，采访市场主体和社会公众，宣传政策执行落实的典型案例，全面客观展现利企便民实效。

（五）充分发挥中央主要媒体作用。可商请中央宣传部（国务院新闻办）安排人民日报、新华社、中央广播电视总台等主要媒体及所属新闻网站、新媒体平台，对国务院涉林草政策例行吹风会、相关政策解读等内容进行报道，提升宣传解读效果。

（六）重视发挥政府网站优势和新媒体作用。充分发挥政府网站的独特优势，集中展示国务院涉林草政策例行吹风会、相关政策解读、市场主体反响等内容，及时推出适合大众传播的解读产品，转载推送中国政府网刊载的国务院常务会议解读稿件等。议题承办单位同期制作1个原创新媒体产品配合解读，并做好负面舆情处置应对工作。

议题承办单位要结合国际社会关注热点，密切监测境外媒体报道内容及倾向，对误解误读要及时澄清，有针对性回应，对积极正面的解读信息要组织做好二次传播，对境外媒体问询要及时稳妥回应。

关于行政法规类议题，可根据实际情况，由议题承办单位会同局办公室进行解读。

四、明确责任分工

议题承办单位：议题承办单位是解读工作的责任主体，要通过媒体、网站及新媒体，利用一切可以利用的手段，积极做好解读工作。议题承办单位负责同志要带头解读，主动发声。

信息公开办：负责解读工作的统筹协调和监督指导，督促议题承办单位制定解读工作方案，深入开展解读工作。向国务院办公厅信息公开办报送相关落实情况。

宣传办：负责协调举办涉林草政策例行吹风会、开展精准吹风，统筹网上网下、对内对外宣传报道和解读，负责办好国家林业和草原局官方微博。牵头做好相关舆情监测和收集工作。

信息办：负责通过我局政府网站发布和转载相关新闻通稿和解读稿件，协助议题承办单位制作原创新媒体产品，办好“中国林业网微信”平台，加强信息发布审查，及时处置我局网站有关曲解误读会议精神、重大决策及重要文件的不实信息。

五、优化工作流程

（一）提出解读工作考虑。拟提请国务院常务会议审议的议题，承办单位在报送相关请示时，应对可公开议题的解读工作提出原则考虑。认为议题内容不宜公开解读的，应在请示中说明理由。议题不公开但会后出台公开政策文件的，待公开发布时，同步做好解读工作。

（二）组织实施。解读工作应与国务院常务会议新闻发布同步开展，原则上应于一周内完成。需与文件发布统筹考虑的解读工作，原则上应于国务院办公厅信息公开办发布文件后一周内完成。通过国务院政策例行吹风会解读的，局宣传办、议题承办单位商国务院办公厅信息公开办，确定吹风会时间，做好相关准备工作。

（三）情况报告。议题承办单位要于国务院常务会议新闻通稿发布后7个工作日内，以局文或局办文的形式向国务院办公厅信息公开办报送解读情况。解读工作与文件发布统筹考虑的，要于文件发布后7个工作日内报送解读情况。同时抄报局信息公开办。

我局出台的其他可公开重大决策及重要文件，也要参照上述做法，加强解读和宣传。
