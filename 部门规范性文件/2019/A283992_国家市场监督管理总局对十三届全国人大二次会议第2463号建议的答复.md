# 国家市场监督管理总局对十三届全国人大二次会议第2463号建议的答复

## 对十三届全国人大二次会议第2463号建议的答复

国市监议〔2019〕134号

张建国代表：

您提出的关于取消“中国学生饮用奶”标志认证的建议收悉，现答复如下：

市场监管部门负责乳制品食品安全监管工作。近年来，市场监管总局严格落实“四个最严”要求，持续加强乳制品（含学生饮用奶）食品安全监管，乳制品质量安全水平大幅提升。

一、乳制品监管情况

市场监管总局将乳制品作为食品安全监管的重点，坚持“产”出来、“管”出来两手抓。一是不断完善乳制品食品安全监管制度。依据《中华人民共和国食品安全法》，制定了涵盖原料把控、过程监管、检验检测、追溯体系等“从牧场到餐桌”的全过程监管制度。二是严格食品生产许可。对乳制品生产企业许可申请材料严格审查，强化对生产场所、设备设施、设备布局和工艺流程、人员管理、管理制度等的核查，保证乳制品生产企业满足食品生产许可条件。三是加强监督检查。将乳制品生产企业列为高风险食品的生产企业，确保每年日常监督检查全覆盖，并根据问题导向，适时开展飞行检查、体系检查，持续提高乳制品生产企业生产过程合规性。四是加强监督抽检。将乳制品列入国家食品安全监督抽检的重点品种，抽检项目覆盖食品安全国家标准所有项目，抽检区域统筹考虑城市、农村、城乡结合部等销售区域，抽检对象兼顾大、中、小乳制品生产企业产品。

二、乳制品质量安全情况

近3年，国家食品安全监督抽检结果显示，乳制品合格率均在99%以上。2018年，共监督抽检2634批次乳制品，合格率为99.7%，比上年提高0.5个百分点。2018年，市场监管总局开展学校配送乳制品专项抽检工作，在内蒙古、黑龙江、河南等10个省份的中小学和幼儿园、学生奶集中配送站及定点生产企业共抽取样品177批次，包括灭菌乳、发酵乳、调制乳，以及含乳饮料等4种学生饮用奶主要配送品种，未发现不合格产品。

三、关于“中国学生饮用奶”标志

学生奶包括灭菌乳、发酵乳、调制乳等乳制品。目前，“中国学生饮用奶”标志由中国奶业协会所有并使用。根据《食品生产许可管理办法》《食品生产许可分类目录》等规范性文件，市场监管部门未将学生奶作为一个发证类别，也未规定企业要在其产品上标注“中国学生饮用奶”标志。依法取得乳制品生产许可资质的食品生产企业，生产的符合食品安全国家标准的乳制品，包括学生在内的广大消费者均可放心消费。

四、关于日处理生鲜乳能力

工业和信息化部、国家发展改革委发布的《乳制品工业产业政策（2009年修订）》（工联产业〔2009〕第48号）规定，“新建液态乳项目日处理生鲜乳能力（两班）须达到200吨及以上，改（扩）建液态乳项目日处理生鲜乳能力（两班）须达到100吨及以上。”据了解，工业和信息化部正在修订乳制品工业产业政策，计划放宽对乳制品加工布局半径限制。

感谢您对乳制品质量安全监管工作的关注。市场监管部门将继续加强乳制品质量安全监管，积极配合相关部门不断规范学生饮用奶相关规定、完善乳制品工业产业政策，推动乳制品行业健康发展。希望您今后继续对市场监管工作给予支持。
