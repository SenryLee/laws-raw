# 国家文物局对十三届全国人大二次会议第7975号建议的答复

文物博函〔2019〕626号

刘蕾代表：

您提出的《关于加大少数民族基础设施投入建立赫哲族博物馆的建议》已交由我局主办，文化和旅游部、黑龙江省人民政府、国家发改委、国家民委协办，现答复如下：

丰富多彩、特色鲜明的少数民族文化遗产，是中华民族优秀传统文化的重要组成部分，是国家重要的精神财富。国家文物局一直高度重视少数民族特别是人口较少民族的文化遗产保护工作，人口较少民族地区博物馆事业得到迅速发展，据统计，28个人口较少民族，有20个建有专门的民族博物馆，人口较少民族聚居村所在161个县中有82个县建有91家博物馆，其中74家纳入免费开放中央财政补助范围。国家文物局会同国家发改委、财政部、国家民委等有关部门，不断加大投入，组织实施了少数民族聚居区国保省保集中成片传统村落整体保护利用项目，加大少数民族非遗传承人支持力度，建立一批少数民族文化生态保护实验区、非遗生产性保护示范基地和非遗传习基地，探索非遗产业化保护发展模式。

赫哲族作为人口较少少数民族的重要成员，文化底蕴深厚，资源丰富，特色鲜明。截至目前，在赫哲族聚居区已建立同江市赫哲族博物馆、街津口博物馆、佳木斯郊区敖其镇赫哲族文博馆、抚远县博物馆等多个博物馆，以及具有一定规模、系统保护展示赫哲族民族历史文化的赫哲族文化中心。赫哲族伊玛堪、赫哲族鱼皮制作技艺等多个项目被分别列入国家级非遗代表性项目名录、联合国教科文组织急需保护的非遗名录、第一批国家传统工艺振兴目录服饰制作类项目，赫哲族特伦古等18项被列入省级非遗代表性项目名录，吴明新等3人被认定为赫哲族国家级非遗代表性传承人，设立省级赫哲族非遗传习基地3个、非遗生产性保护示范基地赫哲族技艺基地2个、赫哲族文化生态保护实验区1个，同江市渔业村等3个赫哲族村寨被命名为“中国少数民族特色村寨”，支持赫哲族鱼皮制作传习展示用房等4个非遗基础设施建设项目，打造《拉哈苏苏》等品牌剧目并以“非遗＋旅游”方式进行巡演，有力推动赫哲族传统文化的传承与发展。

通过建设博物馆的方式，保护传承少数民族特别是赫哲族等人口较少少数民族珍贵民族文化遗产，开展爱国主义教育，促进民族团结和经济社会发展，具有重要意义。根据现行管理体制，您所提的“在黑龙江建立成规模的赫哲族博物馆”属地方基本建设项目，我局建议由地方人民政府统筹已有赫哲族博物馆资源和非遗资源，立足实际需求和地方财力，对拟新建的赫哲族博物馆的必要性、可行性及选址、规模、展示内容等进行科学论证、合理规划，并按规定向上级发展改革部门申请立项支持。

下一步，我局将密切关注有关工作进展，积极会同文化和旅游部等国家相关职能部门和省级人民政府，并协调有关省级文物行政部门，进一步加大对少数民族文化建设政策和资金的支持力度，加强对赫哲族等人口较少民族博物馆建设的支持和业务指导，不断提升民族地区博物馆服务社会的能力和水平，发挥文化遗产保护和传统工艺振兴在助力精准扶贫方面的独特优势，推动民族文化繁荣发展和民族团结进步，促进民族地区文旅融合和经济社会高质量发展。

感谢您对文化遗产保护和博物馆事业的关心和支持！

国家文物局

2019年7月5日
