# 国家核安全局关于颁发2019年第二批民用核设施核反应堆（研究堆）操纵人员执照的通知

## 关于颁发2019年第二批民用核设施核反应堆（研究堆）操纵人员执照的通知

国核安发〔2019〕105号

中国原子能科学研究院：

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的有关规定，我局对中国原子能科学研究院民用核设施核反应堆操纵人员执照考核进行了监督，对执照申请文件进行了审核，认为蔡光博等8人满足取照相关要求，路英昊等12人满足换发执照相关要求，批准向上述20人颁发民用核设施核反应堆操纵人员执照（基本信息见附件）。

特此通知。

附件：民用核设施核反应堆（研究堆）操纵人员执照基本信息

国家核安全局

2019年4月28日
