# 农业农村部对十三届全国人大二次会议第7170号建议的答复摘要

## 对十三届全国人大二次会议第7170号建议的答复摘要

农办议〔2019〕369号

（一）关于将贵港市富硒农产品博览会纳入国家部委农产品相关博览会。发展特色产业，包括富硒产品，既要推进科技创新、提升质量，又要加强宣传推介、扩大影响。一是产品特色宣传。积极引导开发营养健康功能性食品，加强公众营养膳食科普宣传，积极发掘乡村独特资源优势、景观优势和文化底蕴，开发富硒产品等独有的食药同源的种质资源，培育独有的品种，打造独有的特色品牌，二是展会宣传。组织贵港市富硒农产品等乡村特色产品参加中国国际农产品交易会、中国农产品加工业投资贸易洽谈会、全国农业产业化交易会、全国新农民新技术创业创新博览会等全国性、专业性展会，加强富硒农产品宣传，打造国内有影响力、有竞争力的知名品牌。三是电商推介。按照“有标采标、无标创标、全程贯标”要求，制定不同区域不同产品的技术规程和产品标准，开展生产标准化、特征标示化、营销电商化行动，以良好的外观、适宜的包装展现在消费者面前，实现质量可追溯、去向可追踪、责任可追究，把质量和信誉凝结在产品中，打造一批“独一份”“特别特”“好中优”的“乡字号”“土字号”品牌。

（二）关于富硒农产品示范基地建设纳入优势特色产业发展项目。近年来，我部会同财政部实施绿色循环优质高效特色农业促进项目，着力打造一批优势特色产品基地。目前，这一项目实施范围较小，每年安排10个省、每个省选择3个县开展示范创建。贵港市根据富硒产品优势可向广西自治区农业农村厅和财政厅申报。此外，我部每年认定一批全国“一村一品”示范村镇，将对符合条件的贵港市富硒产品给予倾斜。

下一步，我部将贯彻落实《国务院关于促进乡村产业振兴的指导意见》，以实施乡村振兴战略为总抓手，以农业供给侧结构性改革为主线，围绕农村一二三产业融合发展，聚集资源要素，强化创新引领，加快构建乡村产业体系，着力推动乡村产业高质量发展。

农业农村部

2019年9月19日
