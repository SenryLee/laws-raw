# 自然资源部办公厅关于印发《海洋灾害应急预案》的通知

自然资办函〔2019〕2382号

沿海各省、自治区、直辖市自然资源主管部门，山东省海洋局、上海市海洋局、福建省海洋与渔业局、广西区海洋局、海南省应急管理厅，国家海洋环境预报中心，国家卫星海洋应用中心，自然资源部海洋减灾中心,自然资源部各海区局，部机关有关司局:

为进一步提高海洋灾害应对工作的科学性和可操作性，我部在现行的《风暴潮、海浪、海啸和海冰灾害应急预案》基础上修订形成了《海洋灾害应急预案》，现印发你们，请遵照执行。

自然资源部办公厅

2019年12月31日
