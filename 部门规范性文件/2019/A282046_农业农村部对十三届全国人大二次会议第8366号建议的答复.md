# 农业农村部对十三届全国人大二次会议第8366号建议的答复

## 对十三届全国人大二次会议第8366号建议的答复

农办议〔2019〕527号

车秀兰代表：

您提出的关于加强新型职业农民培育的建议收悉。经我部认真研究，现答复如下。

一、关于构建农业职教体系

职业教育是培养高素质农民的重要载体，具有系统性培养优势。农业农村部十分重视，将此作为一项长期性基础性工作加以推进。一是强化农业职教顶层设计。2014年，我部联合教育部印发《中等职业学校新型职业农民培养方案（试行）》，支持中等职业学校培养农民学员，分为种植、畜禽养殖、水产养殖、农业工程和经济管理五个专业类，每个专业类包含若干专业方向，并可根据实际需求动态调整；实行弹性学制，允许学生采用半农半读、农学交替等方式，分阶段完成学业；实行学分制，以学时数考核学习量，以学分认定学习成果。2019年，我部联合教育部印发《关于做好高职扩招培养高素质农民有关工作的通知》，启动实施“百万高素质农民学历提升行动计划”，全面完成2019年高职扩招培养高素质农民任务，计划在此基础上经过5年的努力，培养100万名接受学历职业教育、具备市场开拓意识、能推动农业农村发展、带领农民增收致富的高素质农民，打造100所乡村振兴人才培养优质校。各地根据实际情况，制定专门规划和切实可行的具体政策，极大促进了多形式农民职业教育的开展。二是促进农业职教发展。农业农村部充分发挥全国农业职业教育教学指导委员会作用，抓好基础研究，组织编写全国农业职业教育年度发展报告，加强涉农人才需求分析；加强专业建设，参与中等职业院校专业目录设置优化调整，制定高职、中职农业专业人才培养方案；支持涉农职业院校发展，支持有条件的涉农职业院校加入中国特色高水平高职学校和专业建设计划。三是推进农业职教集团化办学。农业农村部联合教育部组建并发挥中国现代农业、现代畜牧业、现代渔业、现代农业装备和都市农业五大农业职教集团作用，通过产教融合、校企合作，加强实训基地、技术研发平台等建设，对职业院校学生开展创业教育，提升创业能力。

下一步，农业农村部将联合有关部门继续通过涉农职业教育培养高素质农民，做好行业教育指导工作，充分发挥农业职教集团在人才培养中的优势，构建高素质现代农业生产经营者队伍。

二、关于统筹推进农业“职成”教育和农民培训

我部加快建立开放的农民教育培训体系，统筹用好农广校、涉农院校、县级职教中心、农村成人文化技术学校、农业科研院所、农技推广机构等教育培训资源，引导鼓励农业龙头企业、农民合作社、农民专业技术协会等发挥自身优势参与教育培训工作，建设农民田间学校和实训基地，坚持激励约束并重，采取政府购买服务等方式给予相应补助。

我部积极推进职业培训与职业教育衔接贯通培养，实行农学结合、弹性学制、送教下乡等培养模式，就地就近定向培养具有中高等学历的高素质农民。今年印发的《关于做好高职扩招培养高素质农民有关工作的通知》明确要求，培养院校要针对高素质农民学习需要，制定切实可行的人才培养方案，合理设置课程体系；通过高职扩招培养的高素质农民，对其学习培训经历、职业技术技能、从业经历等，按地方或学校有关规定和程序认定为学历教育相关课程学分；探索实现职业技能等级证书与学历证书互通衔接。

下一步，我部将进一步推进农业职成教育和农民培训有效衔接，引导各地强化共建共享意识，支持农业院校等教育资源参与农民培训，形成农民教育培训强大合力。

三、关于采用信息化手段开展农民在线教育培训

为了让农技推广插上信息化的翅膀，让广大农民搭乘“互联网+”的快车，2017年开始，我部开展农民教育培训信息化工作，设计开发了全国农业科教云平台，包括管理平台（网页端，各级农业科教管理人员用）、中国农技推广手机应用程序（专家、农技推广人员用）和云上智农手机应用程序（农民用）。全国农业科教云平台基于大数据、云计算和移动互联技术，聚集各类农业科技教育资源，为各级农业农村管理部门、农业专家、农技推广人员和广大农民提供在线学习、互动交流、成果速递和服务对接。我部加强内容资源开发建设，支持各地组织农民在线学习，探索线上线下融合培训模式，以从事生产经营的农民为主要对象，利用云平台开展在线学习，不断提升在线课程比重，通过政府购买服务方式支付在线学习费用。

下一步，我部将抓好农民教育培训信息化工作，不断完善全国农业科教云平台体系，加强内容资源建设，推动各级各类专家线上线下联动，全面提升农技推广服务效能和农民教育培训效果。

四、关于农民教育培训发展规划

为进一步强化农民教育培训工作指导，推动“十四五”期间农民教育培训有序开展，我部正在谋划编制《“十四五”农民教育培训发展规划》（以下简称《规划》）。《规划》将立足构建高素质农民队伍，为乡村振兴提供人力支撑，在全面总结吸收近年农民教育培训工作经验基础上，突出前瞻性、系统性、可行性，从发展形势、总体要求、主要任务、重点工程和保障措施等方面，对“十四五”期间农民教育培训工作作出系统设计。

下一步，我部将抓好《规划》编制前期工作，为加快构建高素质农民队伍、强化农业现代化建设人才支撑提供依据。

感谢您对农民教育培训工作的关心，希望今后继续对我部工作给予支持。
