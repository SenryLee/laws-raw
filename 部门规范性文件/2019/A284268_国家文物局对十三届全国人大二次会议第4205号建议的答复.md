# 国家文物局对十三届全国人大二次会议第4205号建议的答复

文物保函〔2019〕666号

薛占海代表：

您提出的“关于支持延安革命旧址群保护利用的建议”收悉，经商财政部、发展改革委，现答复如下。

延安是中国革命圣地。弥足珍贵的延安革命历史文物，是我们党和人民的宝贵财富。做好延安革命旧址群保护利用工作，对于弘扬延安精神，传承红色基因，开展爱国主义教育，培育和践行社会主义核心价值观，实现伟大复兴中国梦具有重要作用。

国家高度重视延安革命旧址群保护利用工作。“十一五”期间，国家投入资金5.7亿元实施延安革命纪念馆全国爱国主义教育示范基地“一号工程”建设项目，对延安13处革命旧址全国重点文物保护单位维修保护，建成延安革命纪念馆新馆。2007年以来，中央财政投入2.72亿元用于延安革命纪念馆的免费开放、陈列展览、宣传教育和馆藏文物保护工作，并支持其他70余处革命旧址/纪念馆免费开放。“十二五”以来，国家文物局批复了全国重点文物保护单位枣园、杨家岭、西北局、桥儿沟、清凉山、王家坪、吴起、陕甘宁边区政府、岭山寺塔等革命旧址国保单位的保护和展示利用工程方案，并启动延安革命遗址“互联网+”保护利用项目，中央财政安排文物保护经费3亿多元。2018年，我局指导陕西省文物局和延安市人民政府编制完成并公布实施《延安革命纪念地旧址总体保护规划》。2019年，我局联合中宣部等将延安13个县区列入首批革命文物保护利用片区分县名单，在延安举行了主题为“保护革命文物 传承红色基因” 的2019年文化和自然遗产日主场城市活动，进一步推动了延安革命遗址保护利用工作。

下一步，我局和有关部门将积极贯彻《关于加强文物保护利用改革的若干意见》和《关于实施革命文物保护利用工程（2018—2022年）的意见》，继续支持延安革命文物保护利用管理水平提升，着力做好以下工作。

一是督促加强对延安现有革命旧址资源的梳理、分析，做好革命旧址文物的评估、认定、登记和建档等工作，进一步摸清革命旧址文物家底和保存状况。同时，督促地方政府将具有重要价值的革命旧址文物点及时公布为相应级别的文物保护单位，依法纳入保护范畴。我局会积极支持将延安申报的具有全国性代表意义和重大价值的文物保护单位列入国保单位推荐名单，报请国务院予以公布。

二是积极指导做好延安革命旧址群各片区保护规划和维修方案的制定、审批，以及延安革命旧址群周边环境整治和基础设施建设。按照《国家文物保护专项资金管理办法》有关规定，继续加大对延安市革命文物修缮、规划制定等重点文物保护项目资金补助，同时充分考虑重点文物本体保护范围内的环境整治以及展示利用项目的经费投入。

三是积极指导加强延安革命旧址的革命文物史料征集，深化革命历史研究，深入挖掘革命文物的价值内涵和文化元素，创新革命旧址和纪念馆文物的传播方式，丰富展览的内容形式手段，打造红色旅游品牌，推出一批研学旅行和体验旅游精品线路，运用市场机制开发更多文化创意产品，促进文化消费，切实提高延安革命旧址的保护利用水平，有力助推革命老区振兴发展。

感谢您对文物事业的关心与支持！

国家文物局

2019年7月10日
