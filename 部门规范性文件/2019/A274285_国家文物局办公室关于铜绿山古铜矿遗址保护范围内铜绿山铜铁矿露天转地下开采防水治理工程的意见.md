# 国家文物局办公室关于铜绿山古铜矿遗址保护范围内铜绿山铜铁矿露天转地下开采防水治理工程的意见

办保函〔2019〕57号

湖北省文化和旅游厅：

你厅《关于大冶有色金属有限责任公司铜绿山铜铁矿露天转地下开采防水治理工程涉及铜绿山古铜矿遗址保护范围的请示》（鄂文旅文〔2018〕3号）收悉。经研究，我局暂不同意在铜绿山古铜矿遗址保护范围内实施绿山铜铁矿露天转地下开采防水治理工程。

一、对所报方案提出以下修改完善意见：

（一）应加强前期勘察和专项评估，说明矿区的地层岩性、构造、开采方式、采空区规模和充水特征等，进一步明确遗址赋存山体和工程区域的水文地质条件，论证、校核铜铁矿复合开采、采坑和采空区充填、长期水浸泡等文物影响。同时，应根据岩石的软化系数、抗剪强度等物理力学性质及边坡形态，预测地下开采方式对边坡的影响程度，补充专项研究报告。

（二）应按照《铜绿山古铜矿遗址保护规划》要求，进一步评估矿坑封底、新建排水系统、充填拦挡堤等措施的景观风貌影响。

（三）充分论证铜铁矿露天开采转为地下开采的必要性，评估地下开采方式对遗址和遗址博物馆安全的影响，补充监测、防治措施和相关部门文件。

二、请你厅指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室
