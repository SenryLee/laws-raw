# 国家文物局办公室关于无极甄氏墓群5号墓建设控制地带内河北潘成机械设备制造有限公司二期建设项目的意见

办保函〔2019〕118号

河北省文物局：

你局《关于呈报河北潘成机械设备制造有限公司二期项目涉及无极甄氏墓群5号墓建设控制地带设计方案（修改稿）的请示》（冀文物字〔2019〕5号）收悉。经研究，我局暂不同意在无极甄氏墓群5号墓建设控制地带内实施河北潘成机械设备制造有限公司二期建设项目。

一、所报方案应按照我局《关于在无极甄氏墓群5号墓建设控制地带内进行河北潘成机械设备制造有限公司二期建设项目的意见》（办保函〔2018〕1080号）要求，评估工程建设对甄氏墓群本体和周边环境影响，充分论证项目选址的必要性，补充文物保护内容。

二、请你局认真指导有关单位切实加强项目文本编制，根据上述意见对方案进行修改完善，按程序另行报批。

三、请你局督促地方人民政府，切实落实主体责任，统筹考虑文物保护与经济建设、美丽乡村建设之间的协调发展，明确保护区划和建设控制要求，妥善处理文物保护和发展需求的关系。

专此函复。

国家文物局办公室

2019年2月19日
