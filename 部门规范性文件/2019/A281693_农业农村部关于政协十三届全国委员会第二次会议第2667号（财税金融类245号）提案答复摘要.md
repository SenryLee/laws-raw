# 农业农村部关于政协十三届全国委员会第二次会议第2667号（财税金融类245号）提案答复摘要

## 政协十三届全国委员会第二次会议第2667号（财税金融类245号）提案答复摘要

民进中央：

关于解决发展农村集体经济突出问题的提案收悉。经商中央组织部、中央农办，现答复如下。

发展壮大集体经济，是巩固党在农村的执政基础、实现共同富裕的重要举措，党中央、国务院对此高度重视。2016年，中共中央、国务院印发《关于稳步推进农村集体产权制度改革的意见》（以下简称《意见》），明确要求多种形式发展壮大集体经济。十九大报告再次提出实施乡村振兴战略，深化农村集体产权制度改革，保障农民财产权益，壮大集体经济。2019年中央1号文件进一步明确，深入推进农村集体产权制度改革，总结推广资源变资产、资金变股金、农民变股东的做法经验。

关于因地制宜创新集体经济发展路径

《意见》明确提出，从实际出发探索发展集体经济有效途径，农村集体经济组织可以利用未承包到户的集体"四荒"地、果园、养殖水面等资源，集中开发或者通过公开招投标等方式发展现代农业项目；可以利用生态环境和人文历史等资源发展休闲农业和乡村旅游；可以在符合规划的前提下，探索利用闲置的各类房产设施、集体建设用地等，以自主开发、合资合作等方式发展相应产业。鼓励整合利用集体积累资金、政府帮扶资金等，通过入股或者参股农业产业化龙头企业、村与村合作、村企联手共建、扶贫开发等多种形式发展集体经济。我部指导各地因地制宜发展集体经济，赴重庆、江西等地调研，总结各地发展路径。2019年6月，印发《关于进一步做好贫困地区集体经济薄弱村发展提升工作的通知》，提出多项支持薄弱村发展集体经济的政策措施，引导基层盘活集体资源，挖掘增收潜力，提高资源利用效率。实践中，贵州、安徽、陕西等地区，积极探索资源变资产、资金变股金、农民变股东，将"四荒"地等资源入股新型农业经营主体，将财政项目资金、扶贫资金等转变为集体成员股份，使农民群众更多地分享产业增值收益。江苏、浙江、广东等发达地区，通过物业经营、抱团联合等多种方式壮大集体经济实力。

关于加大扶持政策提高村级集体经济发展活力

《意见》明确要求加大政策支持力度，营造有利于推动农村集体产权制度改革的政策环境。2018年11月，中央组织部、财政部、农业农村部联合下发《关于坚持和加强农村基层党组织领导扶持壮大集体经济的通知》，计划用5年的时间，在全国范围内扶持10万个左右行政村，中央财政按每村10—50万元的标准给予补助，地方财政也要安排一定的补助资金，示范带动各地进一步发展壮大村级集体经济。中央农办、农业农村部支持农业适度规模经营、高标准农田建设、农业产业发展扶持政策及资金项目向村集体经济组织倾斜。2017年，财政部、税务总局出台《关于支持农村集体产权制度改革有关税收政策的通知》，明确免征农村集体产权制度改革过程中的契税和印花税，减轻村级负担，激发村集体发展活力。浙江省实施消除集体经济薄弱村三年行动计划，要求农村集体土地依法被征收为国有土地的，应按被征收土地面积的一定比例，为被征收村安排集体经济发展留用地，或以留用地指标折算为集体经济发展资金等形式予以补偿。重庆市2019年出台发展壮大村级集体经济的指导意见，鼓励村级集体经济组织通过承担小微型农田水利、机耕道路、土地整治、环境整治等基础设施建设、运营和管护工作增加收入。

关于推进农村集体产权制度改革

我部积极贯彻落实中央决策部署，稳步推进农村集体产权制度改革。2015年至2019年，在全国范围内组织开展了四批农村集体产权制度改革试点，共有15个省、89个地市、442个县整建制开展试点。2018年，联合人民银行、市场监管总局印发《关于开展农村集体经济组织登记赋码工作的通知》，启动登记赋码工作，赋予农村集体经济组织市场主体地位，截至2019年6月底，全国共有超过7万个农村集体经济组织完成登记赋码，并领取登记证。指导各地全面开展农村集体资产清产核资，摸清集体家底，健全管理制度；明确集体资产所有权，把农村集体资产所有权确权到相应层级的农村集体经济组织成员集体。指导地方建立符合农村实际需要的产权流转交易市场，江苏、安徽等21个省（区、市）出台引导农村产权流转交易市场健康发展的实施意见，全国共建立11个省级及省会城市农村产权交易市场。

下一步，我村部将会同有关部门，贯彻落实中央有关文件精神，深入推进农村集体产权制度改革，强化村党组织对村级集体经济的领导，提高村党组织引领发展集体经济的水平；指导地方因地制宜多种形式发展壮大大集体经济；加大政策扶持，营造支持村级集体经济发展的良好环境；加强集体经济发展问题研究，指导各地在实践中解决存在的突出问题。

感谢您对农业农村工作的关心，希望继续支持我部工作。

农业农村部

2019年9月3日
