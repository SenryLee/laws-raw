# 财政部关于提前下达新疆生产建设兵团2020年支持地方高校改革发展资金预算的通知

财教〔2019〕197号

新疆生产建设兵团财政局：

根据《支持地方高校改革发展资金管理办法》（财科教〔2016〕72号）精神，按照预算管理有关规定，经研究，现提前下达你兵团2020年支持地方高校改革发展资金预算（项目代码：Z175050020001），收入列1100245“教育共同财政事权转移支付收入”，支出列205“教育支出”相关项。待2020年预算年度开始后，按程序拨付使用。

此次提前下达资金预算15500万元，为你兵团2019年预算执行数的100%，包含支持地方推进一流大学和一流学科建设、支持中西部部省合建高校相关经费。请根据高等教育改革发展实际情况，加大统筹力度，突出支持重点，强化政策导向，合理分解下达预算指标。同时，进一步健全全过程预算绩效管理机制，切实加强资金管理，防止出现挤占、挪用、虚列、套取补助资金等行为，确保财政资金安全有效。

财政部

2019年10月31日
