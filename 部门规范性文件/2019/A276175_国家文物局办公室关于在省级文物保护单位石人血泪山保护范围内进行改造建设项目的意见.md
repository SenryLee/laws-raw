# 国家文物局办公室关于在省级文物保护单位石人血泪山保护范围内进行改造建设项目的意见

办保函〔2019〕219号

吉林省文物局：

你局《关于白山市江源区在省级文物保护单位石人血泪山保护范围内改造项目的请示》（吉文物发〔2019〕9号）收悉。经研究，我局暂不同意在石人血泪山保护范围内进行纪念馆、接待中心、第二展览馆和停车场改造等建设项目。

一、所报建设项目尚需作以下必要的修改和完善：

（一）进一步说明改造建设项目的必要性，特别是第二展馆建设的必要性，补充现状勘查图纸、照片和必要说明，及改造项目与文物本体关系图、保护区划图、保护区划管理要求等内容。

（二）补充改建新建项目的规模指标、游览线路等内容及相关设计图纸，并严格控制建筑高度、体量，优化建设外观设计，淡化仿古牌楼的形式设计，尽量减少对文物本体及景观环境的影响。

（三）规范并深化设计文本，应将石人血泪山施工方案设计名称改为石人血泪山改造设计方案。

（四）完善文物影响评估报告，评估内容应与设计方案中的建设内容一致，并客观、准确评估改造项目的合规性及对文物本体和环境的影响，明确评估结论，提出具有针对性和可操作性的保护措施。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年3月26日
