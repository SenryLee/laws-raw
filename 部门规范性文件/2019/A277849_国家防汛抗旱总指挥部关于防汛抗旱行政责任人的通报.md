# 国家防汛抗旱总指挥部关于防汛抗旱行政责任人的通报

国汛〔2019〕2号

各省、自治区、直辖市防汛抗旱指挥部，新疆生产建设兵团防汛抗旱指挥部：

据预测，今年气象年景总体偏差，旱涝灾害较重，防汛抗旱防台风形势严峻。为切实做好2019年防汛抗旱工作，根据《中华人民共和国防洪法》《中华人民共和国防汛条例》《中华人民共和国抗旱条例》关于防汛抗旱工作实行各级人民政府行政首长负责制的规定，现将全国防汛抗旱行政责任人，大江大河、大型及防洪重点中型水库、主要蓄滞洪区、重点防洪城市、南水北调东线及中线工程沿线防汛行政责任人和沿海地区防台风行政责任人名单予以通报。

请各级行政责任人坚持底线思维，强化风险和责任意识，立足于防大汛、抗大旱、防强台、抢大险、救大灾，切实履行工作职责，督促落实措施，扎实做好防汛抗旱防台风各项工作。对因失职渎职造成严重后果的，依法依纪追究责任。

附件：

1.全国防汛抗旱行政责任人名单

2.全国大江大河防汛行政责任人名单

3.全国大型及防洪重点中型水库防汛行政责任人名单

4.全国主要蓄滞洪区防汛行政责任人名单

5.全国重点防洪城市防汛行政责任人名单

6.南水北调东线及中线工程沿线防汛行政责任人名单

7.沿海地区防台风行政责任人名单

国家防汛抗旱总指挥部
