# 住房和城乡建设部对十三届全国人大二次会议第8727号建议的答复

## 对十三届全国人大二次会议第8727号建议的答复

建建复字〔2019〕114号

黄河代表：

您提出的关于推进老旧小区改造和管理的建议收悉，现答复如下：

加快改造城镇老旧小区，群众愿望强烈，是重大民生工程和发展工程。据各地初步摸查，目前全国需改造的城镇老旧小区涉及居民上亿人，量大面广，情况各异，任务繁重。党中央、国务院高度重视城镇老旧小区改造工作。

我部会同有关部门认真贯彻落实党中央、国务院决策部署，扎实推进城镇老旧小区改造工作。2017年底，在厦门、广州等15个城市启动城镇老旧小区改造试点。试点城市的实践证明，城镇老旧小区改造花钱不多，惠及面广，不仅帮助居民改善基本居住条件，切实增强人民群众的幸福感、获得感、安全感，也是扩大投资激发内需的重要举措。

2019年4月，我部会同发展改革委、财政部印发《关于做好2019年老旧小区改造工作的通知》（建办城函〔2019〕243号），自2019年起将老旧小区改造纳入城镇保障性安居工程，给予中央补助资金支持，同时，指导各地按照“业主主体、社区主导、政府引领、各方支持”的方式，统筹推进城镇老旧小区改造。

一、关于发挥业主主体作用

居民是城镇老旧小区改造的主体。我部指导各地坚持“美好环境与幸福生活共同缔造”的理念和方法，在尊重居民意愿前提下，激发居民支持改造、参与改造的热情，实现决策共谋、发展共建、建设共管、效果共评、成果共享。发动小区业主共同谋划改造方案，投工投劳共同参与小区改造，共同评价和反馈小区改造效果，共享整洁、舒适、安全、美丽的小区环境。

下一步，我部将继续强化宣传引导，指导各地采取群众喜闻乐见的方式宣传动员，发动群众参与老旧小区改造，共享改造成果。

二、关于坚持社区主导地位

城乡社区是社会治理的基本单元。我部指导各地在城镇老旧小区改造中坚持以社区为主导，创新社区治理模式，促进构建“纵向到底、横向到边、协商共治”的治理体系，打造共建共治共享社会治理格局。

下一步，我部将重点推动各地建立小区后续长效管理机制。发挥社区的组织协调作用，积极引导居民根据小区实际情况合理选择管理方式，对于具备专业化物业管理条件的，引导业主选聘市场化的物业服务企业，提高物业服务在老旧小区的覆盖率；对于尚未具备专业化物业管理条件的，可在街道办事处、居民委员会指导下，实行业主自我管理或政府指定服务机构管理。

三、关于政府引领组织实施

城镇老旧小区改造坚持“省级负总责、市县抓落实”原则。我部会同国家发展改革委、财政部指导各省级住房和城乡建设部门会同发展改革、财政等相关部门加强统筹协调，有针对性地督促指导本地区市、县大力推进老旧小区改造工作。指导市、县住房和城乡建设部门会同发展改革、财政等相关部门，在同级党委和政府的领导下，加强协作配合，建立健全多元筹资、组织实施、项目推进等工作机制。

下一步，我部将进一步加强政府引导，压实地方责任，深入了解居民改造意愿和诉求，明确城镇老旧小区改造标准和对象范围，逐步健全城镇老旧小区改造政策支持体系。

四、关于引导各方支持改造

城镇老旧小区改造是一个系统工程，重点改造对象是小区水电气路及光纤等配套设施，有条件的可以加装电梯，配建停车设施。在小区改造的基础上，还要引导发展社区养老、托幼、医疗、助餐、保洁等服务。因此，在统筹和组织实施方面，我部指导各地因势利导，鼓励社会力量积极参与，特别是要调动小区相关联单位的积极性，形成各方力量共同参与老旧小区改造的良好氛围。

下一步，我部将指导各地采取“居民出一点、社会支持一点、财政补助一点”的方式筹集改造资金，进一步发挥住宅专项维修资金在老旧小区和电梯更新改造中的支持作用。鼓励金融机构和地方积极探索，以可持续方式加大金融对老旧小区改造的支持。运用市场化方式吸引社会力量参与，落实小区水电气路及光纤等配套设施运营企业责任，引导开展配套设施改造提升。
