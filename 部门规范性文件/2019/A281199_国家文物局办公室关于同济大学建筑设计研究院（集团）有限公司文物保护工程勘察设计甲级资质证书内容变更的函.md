# 国家文物局办公室关于同济大学建筑设计研究院（集团）有限公司文物保护工程勘察设计甲级资质证书内容变更的函

办保函〔2019〕720号

上海市文物局：

你局《关于申请变更同济大学建筑设计研究院（集团）有限公司文物保护工程勘察设计甲级资质证书的请示》（沪文物〔2019〕59号）收悉。

经研究，我局同意同济大学建筑设计研究院（集团）有限公司文物保护工程勘察设计甲级资质证书中的法定代表人由"丁洁民"变更为"王健",经济性质由"有限责任制"变更为"其他有限责任公司".请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年8月15日
