# 科技部关于通报表扬一批科技特派员及组织实施单位的通知

国科发农〔2019〕353号

各省、自治区、直辖市及计划单列市科技厅（委、局），新疆生产建设兵团科技局，科技特派员农村科技创业行动协调指导小组成员单位：

科技特派员制度是习近平总书记在福建、浙江工作期间亲切关心指导、总结提升的农村工作机制重大创新。20年来，各地各部门积极探索创新管理机制和服务模式，组织动员科技特派员深入农业农村一线，倾情服务“三农”，为推动我国农业强、农村美、农民富提供了有力科技支撑和智力支持。广大科技特派员认真履行工作职责，宣传党的“三农”政策、传播农业科学技术、引领创新创业、带动乡村脱贫致富，把论文写在大地上，涌现出一大批扎根农村、心系群众、奋发有为、无私奉献的先进典型。

近日，习近平总书记对科技特派员工作作出重要批示，为深入学习贯彻习近平新时代中国特色社会主义思想和习近平总书记关于科技特派员工作的重要批示精神，激励和引导广大科技特派员新时代新担当新作为，科技部决定对刘华贵等92名科技特派员、北京市科委农村发展中心等43个科技特派员组织实施单位予以通报表扬。

希望受表扬的单位和个人珍惜荣誉，再接再厉，再创佳绩，进一步发挥好示范引领作用。各级科技管理部门要切实把习近平总书记重要批示精神落实落地，深入实施创新驱动发展战略和乡村振兴战略，深入推行科技特派员制度，完善管理服务机制和支持激励政策，营造良好舆论环境，壮大科技特派员队伍。选派单位要加大支持力度，强化工作保障，创新工作方式，坚决落实好激励政策和服务措施。广大科技特派员要不忘初心、牢记使命，扎根基层、苦干实干，弘扬担当精神，立足岗位奉献，投身脱贫攻坚，助力乡村振兴，为实现“两个一百年”奋斗目标和实现中华民族伟大复兴的中国梦作出新的更大贡献。
