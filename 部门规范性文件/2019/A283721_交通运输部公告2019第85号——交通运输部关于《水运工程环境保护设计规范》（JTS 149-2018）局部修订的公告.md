# 交通运输部公告2019第85号——交通运输部关于《水运工程环境保护设计规范》（JTS 149-2018）局部修订的公告

## 交通运输部公告

2019第85号

## 交通运输部关于《水运工程环境保护设计规范》（JTS 149-2018）局部修订的公告

为深入贯彻落实《中华人民共和国大气污染防治法》《中华人民共和国水污染防治法》《中华人民共和国海洋环境保护法》《中华人民共和国固体废物污染防治法》和《船舶水污染物排放控制标准》（GB3552—2018）等法律、国家标准的相关要求，进一步提高水运工程环境保护水平，我部组织中交第二航务工程勘察设计院有限公司对《水运工程环境保护设计规范》（JTS 149—2018）（以下简称《规范》）进行了局部修订，现予发布，自发布之日起施行。

本次局部修订对《规范》的第3.1.9.1款、第4.1.6条、第4.5.1.5款、第7.0.1条、第7.0.6条、第7.0.7条的内容进行了修改，删除第3.1.9.2款，第3.1.9.3款调整为第3.1.9.2款，并对相应条款的条文说明进行了修改（详见附件）。

特此公告。

交通运输部

2019年10月28日
