# 国家移民管理局关于对政协十三届全国委员会第二次会议第3151号意见的答复

苏志刚委员：

您提出的《关于进一步放宽珠海横琴口岸人员出入境签证政策的提案》收悉，经征求国务院港澳事务办公室意见，现答复如下：

一、关于前往澳门的内地游客，在通行签注的7天有效期内，能够多次自由往返横琴口岸与澳门。近年来，随着“个人游”政策的实施，内地居民赴澳门旅游人数快速增长，有力促进了两地人员交流和澳门旅游业发展。但是，内地旅客大量赴澳也给当地的旅游承载力带来了很大挑战，特别是港珠澳大桥开通后，内地赴澳游客进一步增长。据统计，2018年，内地居民申请办理往来澳门签注3934.1万人次，与2017年相比增长20.4%。关于允许内地游客在签注有效期内多次往返澳门与横琴，我局将会同国务院港澳办等部门，综合考虑澳门经济发展和旅游承载力等因素，予以统筹研究。

二、关于内地旅客到达横琴后，可以凭有效的港澳通行证在当地公安出入境管理部门办理赴澳旅游签注。我局自去年成立以来，不断推进移民和出入境领域“放管服”改革，推出了一系列便利内地居民办证出行政策措施。自2018年9月1日起，内地居民可在全国范围内任一公安出入境管理机构异地申请换补发往来港澳通行证以及申请往来港澳团队旅游签注。今年4月1日起实施的“全国通办”政策中，异地办证申请扩大到首次申请，并允许在自助签注机上异地申办赴港澳团队旅游签注，立等可取。目前，内地旅客到达横琴后，可凭有效的往来港澳通行证在当地公安机关出入境管理部门的窗口或自助机上申请办理赴澳门团队旅游签注。下一步，我局将继续推进科技信息运用，提升办证效率和质量，为群众提供更多更好的优质服务。

感谢您对移民管理工作的关心和支持。

国家移民管理局

2019年7月2日
