# 住房和城乡建设部关于印发中国国际园林博览会管理办法的通知

建城〔2019〕79号

各省、自治区住房和城乡建设厅，直辖市住房和城乡建设（管）委，园林绿化主管部门，新疆生产建设兵团住房和城乡建设局：

为进一步规范中国国际园林博览会申办、组织实施及园博园维护管理，我部组织修订了《中国国际园林博览会管理办法》（建城〔2015〕89号）。现将修订后的《中国国际园林博览会管理办法》印发给你们，请遵照执行。

中华人民共和国住房和城乡建设部

2019年7月18日

附件：中国国际园林博览会管理办法
