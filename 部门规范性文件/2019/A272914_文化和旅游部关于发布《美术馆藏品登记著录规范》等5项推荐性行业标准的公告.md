# 文化和旅游部关于发布《美术馆藏品登记著录规范》等5项推荐性行业标准的公告

《美术馆藏品登记著录规范》（WH/T 80-2019）、《美术馆藏品二维影像采集规范》（WH/T 81-2019）、《演出安全 第8部分：舞台监督及通讯安全》（WH/T 78.8-2019）、《演出用专业音响设备音质主观评价方法》（WH/T 82-2019）、《演出场所电脑灯具通用技术要求》（WH/T 83-2019）5项推荐性文化行业标准已经文化和旅游部批准，现予以公布。上述5项推荐性文化行业标准自2019年6月1日起实施。

特此公告。

文化和旅游部

2019年1月2日
