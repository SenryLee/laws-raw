# 审计署关于政协第十三届全国委员会第二次会议第1362号（资源环境类066号）提案答复的函

## 关于政协第十三届全国委员会第二次会议第1362号（资源环境类066号）提案答复的函

审函〔2019〕59号

余国东委员：

您提出的《关于加强长江经济带环境审计的提案》收悉，我署相关司局进行了认真研究，生态环境部作为会办单位，也提出了意见。您提出的目前环境审计存在的问题和建议，对我们完善资源环境审计理论体系和审计制度，更好地开展相关审计工作，具有很强的参考意义。现就您的建议答复如下：

一、关于"完善环境审计理论方法，加强对长江经济带重要自然资源资产保护及开发情况的审计"和"明确环境审计范围，建立绩效评价指标体系，加强对长江经济带污染排放和行政执法情况的审计"两条建议

我署高度重视领导干部自然资源资产离任审计工作，2015年试点工作启动后，注重总结各级审计机关实践经验和充分征求各方面意见，对自然资源资产离任审计制度及理论方法进行了不断完善。2017年9月中央办公厅、国务院办公厅出台的《领导干部自然资源资产离任审计规定（试行）》（以下简称《规定》），标志着领导干部自然资源资产离任审计由试点进入到全面推开阶段。《规定》明确的领导干部自然资源资产离任审计7方面审计内容（分别是：贯彻执行中央生态文明建设方针政策和决策部署情况；遵守自然资源资产管理和生态环境保护法律法规情况；自然资源资产管理和生态环境保护重大决策情况；完成自然资源资产管理和生态环境保护目标情况；履行自然资源资产管理和生态环境保护监督责任情况；组织自然资源资产和生态环境保护相关资金征管用和项目建设运行情况；履行其他相关责任情况），基本涵盖了建议提到的自然资源资产政策执行和决策，环境保护相关规划建设、资金投入、综合效益等重点审计内容。

2018年审计署还组织开展了长江经济带生态环境保护审计，重点审计了11个省本级及59个市，主要以检查长江经济带生态环境保护规划落实情况为主线，审计了5方面内容：一是中央重大方针政策和决策部署贯彻落实情况，主要检查河长制、生态保护红线等生态文明体制相关改革任务推进情况，资源环境等相关约束性指标和阶段性目标任务完成情况；二是水资源水生态保护情况，主要检查相关地方执行主体功能区、最严格水资源管理、岸线开发利用管理，湿地等生态保护制度情况；三是水、土壤污染防控情况，主要检查"水十条"、"土十条"的落实情况；四是产业结构和工业布局优化调整情况；五是生态环境保护治理项目实施和相关资金管理使用情况，主要检查用于天然林资源保护、退耕还林还草、石漠化综合治理、湿地保护、水污染防治和土壤污染防治等方面的专项资金的投入及效益情况。发现和揭示了一些地方开发管控不够到位，生态修复未达预期，污染治理存在薄弱环节，部分生态环境保护资金和项目绩效不高等问题。

在开展上述审计工作过程中，审计署及各地审计机关积极探索聘用社会机构等相关领域专家参与审计，多方面收集运用资源环境数据、资料开展审计评价，部分地方已建立了较为完整的绩效评价指标体系。

二、关于"完善环境审计制度，加强长江经济带领导干部自然资源资产离任审计"的建议

为推动长江经济带相关区域建立健全党政领导干部自然资源资产离任审计制度，促进长江经济带相关地方政府扎实推进共抓大保护和长江沿线污染治理，我署2017年9月发布了《审计署办公厅关于在自然资源资产离任审计中突出做好长江经济带生态环境保护相关审计工作的指导意见》，要求11省市地方审计机关在2017年自然资源资产离任审计试点项目中重点关注长江经济带生态环境保护问题，在安排2018年及以后年度审计项目时，优先考虑对沿长江干流和重要支流的市县开展审计，并将长江生态环境保护情况作为首要内容。截至2018年底，长江经济带11省市地方政府均已制定或印发了《规定》配套实施意见或实施办法，完善了审计机构设置和相关配套制度，11省市地方审计机关已经全面推开领导干部自然资源资产离任审计工作，长江经济带经常性、常态化的环境审计制度已经建立。2018年，11省市地方审计机关共开展领导干部自然资源资产离任（任中）审计项目1300余个、审计领导干部1900余人。

今后，我署将继续扎实推进领导干部自然资源资产离任审计，持续加强对长江经济带重要自然资源资产保护及开发、污染排放和行政执法等情况的审计，带动11省市地方审计机关不断完善审计理论方法，健全规范绩效评价指标体系，力求具体、客观的评价领导干部履职尽责情况；积极与组织、纪检监察、生态环境保护等部门沟通协商，完善审计结果运用机制，提高审计结果运用水平。

感谢您对审计工作的关心和支持！

审计署

2019年7月24日
