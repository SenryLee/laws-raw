# 中共教育部党组关于王继平、陈子季同志职务任免的通知

教党任〔2019〕143号

部内各司局、各直属单位：

中共教育部党组2019年6月19日决定，任命王继平同志为教育部副总督学，免去其职业教育与成人教育司司长职务；任命陈子季同志为职业教育与成人教育司司长（试用期一年）。

中共教育部党组

2019年6月20日
