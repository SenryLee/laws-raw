# 农业农村部对十三届全国人大二次会议第6840号建议的答复

## 对十三届全国人大二次会议第6840号建议的答复

农办议〔2019〕252号

您提出的关于开展农业节肥节药行动打赢污染防治攻坚战在河南建立先行先试的建议收悉。经我部认真研究，现答复如下。

2015年以来，我部紧紧围绕农业供给侧结构性改革这一主线，深入开展化肥农药使用量零增长行动，促进化肥农药减量增效。2017年，三大粮食作物化肥利用率37.8%、比2015年提高2.6个百分点，化肥用量实现负增长。农药利用率38.8%、提高2.2个百分点，农药用量实现连续三年负增长。一是新产品新技术加快推广。重点推广作物专用配方肥、缓释肥、生物有机肥，和一批高效、低毒、低残留农药和生物农药。2018年测土配方施肥技术推广面积达18.5亿亩，技术覆盖率达85%，配方肥已占三大粮食作物施用总量的60%以上，生物农药应用面积超过10%。二是替代技术加快推进。重点推广有机肥替代化肥、绿色防控替代化学防治，在150个果菜茶重点县开展有机肥替代化肥试点和病虫全程绿色防控试点。2018年，全国有机肥施用面积超过5亿亩次，有机肥用量增加近700万吨，病虫害绿色防控覆盖率达到29.4%、比2015年提高了6.3个百分点。三是专业化服务加快发展。培育了一批有技术、有装备、有规模的新型社会化服务组织，统防统治、统配统施面积不断扩大。2018年农作物病虫害统防统治覆盖率达到39.2%、比2015年提高6.5个百分点。

下一步，我部将会同有关部门，总结经验做法，进一步完善政策措施，继续对化肥农药使用量零增长行动予以支持。2017年以来，中央财政将支持农业生产的相关资金合并为农业生产发展资金，创新和完善资金管理使用机制，资金采取因素法分配，并切块下达到省。河南省可以在大专项支持方向范围内，结合本地实际，在完成既定清单任务基础上，按照有关规定统筹中央和地方财政资金，重点对节肥节药行动予以支持，解决制约农业农村经济发展的瓶颈问题。

感谢您对农业农村工作的关心，希望今后对我部工作继续给予支持。
