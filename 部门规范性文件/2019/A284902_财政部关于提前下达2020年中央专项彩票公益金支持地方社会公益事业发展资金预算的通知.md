# 财政部关于提前下达2020年中央专项彩票公益金支持地方社会公益事业发展资金预算的通知

财综〔2019〕47号

有关省、自治区、直辖市财政厅（局）：

为提高预算编制的完整性，加快支出进度，按照预算管理有关规定，经研究，现提前下达2020年中央专项彩票公益金支持地方社会公益事业发展（项目代码：Z185010030001）预算，待2020年预算年度开始后按程序拨付使用，用于支持当地社会公益事业发展，具体预算分配见附件。该项预算安排使用时，应根据使用方向相应列入《2020年政府收支分类科目》第2296002项“用于社会福利的彩票公益金支出”至2296099项“用于其他社会公益事业的彩票公益金支出”。

省级财政部门应根据提前下达的预算额度，科学合理确定区域绩效目标，于收到本通知60日内，按程序将区域绩效目标报财政部备案，同时抄送财政部当地监管局。财政部门要严格按照《中共中央 国务院关于全面实施预算绩效管理的意见》、《财政部关于“十三五”时期中央专项彩票公益金支持地方社会公益事业发展安排以及下达2017年资金的通知》（财综〔2017〕47号）、《财政部关于印发<中央专项彩票公益金支持地方社会公益事业发展资金管理办法>的通知》（财综〔2019〕21号）等规定，加强预算绩效目标管理，做好绩效运行监控和绩效评价、强化评价结果应用，切实提高财政资金使用效益。

附件：1.2020年中央专项彩票公益金支持地方社会公益事业发展资金预算分配表

2.彩票公益金中央对地方政府性基金转移支付绩效目标表

财政部
