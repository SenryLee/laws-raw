# 中共自然资源部党组关于马家龙等4名同志任职的通知

自然资党任〔2019〕58号

中国地质调查局及部直属其他单位，各派出机构，部机关各司局：

部党组2019年4月2日研究决定：

马家龙同志挂职任国土空间生态修复司副司长；

张启元同志挂职任矿产资源保护监督司副司长；

苏建旗同志挂职任自然资源确权登记局局长助理；

玛依利·夏尔甫汗同志挂职任自然资源开发利用司市场监管处副处长。

挂职时间至2020年春节前。

中共自然资源部党组

2019年4月4日
