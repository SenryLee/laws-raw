# 水利部办公厅关于全力做好2020年春节前保障农民工工资支付专项工作的通知

办建设函〔2019〕1314号

各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局，部直属各单位，部直属重点工程项目法人：

农民工工资按时足额支付工作事关广大群众切身利益，事关社会公平正义和社会和谐稳定。党中央、国务院历来高度重视农民工工资支付工作，先后出台了一系列政策措施，就根治欠薪作出重大决策部署。近期，国务院根治拖欠农民工工资工作领导小组办公室专门召开会议，就2020年春节前解决政府工程拖欠农民工工资工作作出安排，组织开展2019年度根治欠薪冬季攻坚行动。水利部党组高度重视水利建设领域根治欠薪工作，多次就做好2020年春节前保障农民工工资支付工作作出批示指示。为做好相关工作，切实保障农民工劳动报酬权益，现就有关工作通知如下：

一、进一步提高政治站位，逐级夯实责任。按时足额支付农民工工资是坚持以人民为中心发展思想的重要体现，各级水行政主管部门要充分认识农民工工资支付工作的极端重要性，要以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平总书记关于保障农民工工资支付的重要指示批示精神，进一步提高政治站位，从讲政治的高度，层层夯实责任，逐级抓好落实，确保工作有人抓、问题有人管、事情有人办，坚决打赢根治欠薪攻坚战。

二、紧盯重点领域和关键环节，全面加强监督管理。水利建设领域工程项目多、分布广、用工需求大，随着元旦、春节两节临近，将迎来工程款、工资款结算高峰，农民工工资支付工作时间紧、任务重。各级水行政主管部门要紧盯重点领域和关键环节，强化工作措施，全面排查欠薪隐患，及时整改发现的问题，确保农民工春节前拿到工资，舒心过年。一是查清政府投资工程和国企项目审批监管、资金落实和工程款按期结算情况，坚持源头治理，加强源头管控；二是摸清水利建设领域落实农民工实名制管理、农民工工资专用账户、工资保证金、银行代发工资等4项保障工资支付制度落实情况，建立健全机制，确保制度落地见效；三是切实整改2018年度保障农民工工资支付工作考核发现的管理中存在的薄弱环节，坚持问题导向，推动问题整改到位； 四是全力实现2019年10月底前发生的政府投资工程和国企项目欠薪案件在2019年底前全部清零，其他欠薪案件在2020年春节前及时动态清零的目标。

三、畅通投诉维权渠道，加大惩处力度。各级水行政主管部门要畅通农民工维权投诉渠道，认真调查处理投诉举报，迅速解决问题。要紧盯欠薪治理工作中的突出矛盾，加强工作调度和过程跟踪，强化督查问责，对责任不落实、工作不到位的，依法依规严肃问责。对欠薪数额和涉及人数较多的欠薪事件，要挂牌督办，限时解决。要保持对欠薪违法行为的高压震慑态势，对恶意拖欠农民工工资的单位和责任人，依法依规，严厉查处，并在“全国水利建设市场监管服务平台”上进行失信曝光，对其进行动态信用评价，符合列入“重点关注名单”和“黑名单”标准的，应列即列，联合相关部门实施联合惩戒。

四、高度重视信息报送，确保及时通畅。一是各级水行政主管部门要建立健全信息报送制度，采取定期和不定期相结合的方式，逐级完善信息报送机制，并明确专人负责；二是对于排查发现的欠薪问题，第一时间逐级上报，确保欠薪问题就地限时解决，并报告解决情况。对于信息报送不及时、瞒报的，我部将采取通报、约谈、建议处理意见等措施追究责任。

请各单位及时梳理问题，分析原因，总结经验，提出进一步根治欠薪对策建议，于2020年1月6日前，将2020年春节前保障农民工工资支付工作情况总结报告和附表（含电子版）上报我部。
