# 农业农村部对十三届全国人大二次会议第4704号建议的答复

## 对十三届全国人大二次会议第4704号建议的答复

顾想平代表：

您提出的关于进一步扶持监利县建设江汉平原实施乡村振兴战略示范区的建议收悉。经商财政部、国家铁路局，现答复如下。

一、关于扶持监利县建设江汉平原实施乡村振兴战略示范区

去年，党中央、国务院印发了《乡村振兴战略规划(2018-2022年)》(以下简称《规划》）。《规划》明确提出，要科学把握我国乡村区域差异，尊重并发挥基层首创精神，发掘和总结典型经验，推动不同地区、不同发展阶段的乡村有序实现农业农村现代化。为探索乡村振兴战略实施路径，我部已先后与浙江省签订共建乡村振兴示范省合作框架协议、与广东省签订共同推进乡村振兴战略实施合作框架协议，支持两省在合作框架协议下开展乡村振兴工作先行先试，努力形成一批可看、可学、可借鉴、可复制的典型样板，带动面上乡村振兴整体提升。监利县可根据中央的决策部署和上级党委政府的工作要求，结合本县实际，选择工作突破口，大胆探索、先行先试。我部将会同省级农业农村部门及时发掘和总结成功经验，发挥典型示范作用，指导各地有序实现乡村振兴。

二、关于将监利县纳入国家级现代农业产业园

建设现代农业产业园，是新时期中央推进农业供给侧结构性改革、加快农业农村现代化的重大举措，是培育农业农村经济发展新动能和推进乡村产业兴旺的重要载体。2017年以来，我部和财政部按照中央的部署要求，大力推进现代农业产业园建设工作，先后批准创建114个国家现代农业产业园、首批认定20个。各地也积极行动，创建了1000多个省级产业园和一大批市县级产业园，初步建立了梯次推进的工作格局，在引领带动各地农业转型升级方面发挥了重要作用。从2019年开始，国家现代农业产业园创建评审工作由省级农业农村和财政部门组织，报农业农村部、财政部备案。建议监利县按照创建申请程序，依据创建申请条件，认真做好国家现代农业产业园创建前期准备工作，并与湖北省主管部门加强沟通衔接。如符合创建条件和要求，我们将予以支持。

三、关于将监利县纳入全国铁路网规划

财政部、国家铁路局等部门积极支持江汉平原铁路基础设施建设。目前，荆州至岳阳铁路作为规划研究项目已纳入《中长期铁路网规划》。下一步，国家铁路局将会同有关单位和地方政府，在统筹经济社会发展、路网布局、运输需求的基础上，深入研究论证项目建设时机，条件成熟时纳入五年规划。同时，支持地方政府结合区域经济社会发展需要，积极开展江汉平原铁路规划建设。

四、关于加大对监利县生态补偿扶持力度

党中央、国务院高度重视生态保护工作，通过相关专项资金对湖北省给予倾斜支持。主要开展了以下几方面工作：一是支持实施山水林田湖草生态保护修复工程试点。2018年，财政部会同有关部门经过竞争性评审，将湖北“长江三峡地区山水林田湖生态保护修复工程”纳入第三批山水林田湖草生态修复工程试点范围，并下达基础奖补资金10亿元。二是支持建立流域横向生态补偿机制。2018年，出台长江经济带生态保护奖励政策，并先行安排湖北省奖补资金4.5亿元，支持建立省际、省内流域横向生态补偿机制，改善流域水环境治理。三是通过其他环保专项资金予以支持。2018年，中央财政安排湖北省水污染防治专项资金9.26亿元（含长江经济带生态保护奖励资金4.5亿元）、土壤污染防治专项资金3.04亿元、农村环境整治资金1.9亿元。为调动地方积极性，中央财政在分配转移支付增量资金时，不再划定享受转移支付的具体县域范围，而是将资金切块下达到省（区、市），由省级财政统筹研究用于相关重点地区的生态环境保护工作。

下一步，中央财政将结合代表所提建议，统筹完善重点生态功能区转移支付办法，研究加大对湖北的转移支持力度，支持湖北生态文明建设。同时，也建议监利县积极与省级有关部门沟通联系，争取相关支持。

五、关于支持产粮大县

2005年以来，中央财政积极加大对产粮大县的奖励力度，每年根据粮食商品量、产量、播种面积、绩效评价结果等因素测算分配资金，对产粮大县等给予奖励。2018年，中央财政安排监利县产量大县奖励资金8325万元，有力地促进了监利县粮食产业发展。同时，中央财政通过产粮大县奖励资金渠道支持地方实施“优质粮食工程”，奖励资金由中央财政测算分配到省，由各省结合当地实际情况统筹用于支持本省实施“优质粮食工程”。2017—2018年，中央财政累计安排湖北省“优质粮食工程”奖励资金10.92亿元，监利县可按有关程序组织申报，争取相关支持。

感谢您对推进乡村振兴战略工作的关心，希望继续对我部的工作给予支持。

农业农村部
