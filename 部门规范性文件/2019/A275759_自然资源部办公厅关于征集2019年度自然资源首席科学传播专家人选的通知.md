# 自然资源部办公厅关于征集2019年度自然资源首席科学传播专家人选的通知

自然资办函〔2019〕489号

各省、自治区、直辖市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中国地质调查局及部其他直属单位，各派出机构：

为贯彻落实《全民科学素质行动计划纲要实施方案（2016-2020）》精神，根据《自然资源部关于印发自然资源科技创新发展规划纲要的通知》（自然资发〔2018〕117号）的部署，现组织开展2019年度自然资源首席科学传播专家人选征集工作，有关事项通知如下：

一、条件与方式

（一） 基本条件

1. 拥护党的领导，遵守国家法律法规，具备良好的科学道德和学风。

2. 在自然资源学科领域具有较高的学术造诣，具有正高级以上专业职称，能够正确把握和引领学科和科普工作发展方向，具有较好的语言表达和科普演讲能力。

3. 热爱科普工作，乐于奉献，在科普传播、科普创作、科普活动等方面经验丰富，连续从事公益性科普工作3年以上，科普成果丰富、成效显著。

4.身体健康，能够积极参与自然资源部组织开展的各项科学传播活动，完成相关科学传播任务。

（二）征集方式

本着专家自愿、单位推荐为主的方式，由符合基本条件的专家自愿填写《自然资源首席科学传播专家推荐表》，专家所在单位提出推荐意见后，经各省级自然资源主管部门，中国地质调查局及部其他直属单位，各派出机构报出。

（三）聘任方式

根据推荐情况，部将择优确定自然资源首席科学传播专家人选，正式聘为自然资源部2019年度首席科学传播专家，聘期5年。聘期满后，经双方确认，可续聘。

二、充分发挥首席科学传播专家作用

（一）主要任务

自然资源首席科学传播专家应以弘扬自然资源科学知识、宣传自然资源国情国策国法为己任，每年牵头开展不少于2次科普活动。特别是在地球日、土地日、海洋日、科普日、测绘法宣传日、科技活动周等科普活动期间，开展科普传播示范活动，发挥科学传播表率作用；在与自然资源领域有关的重大科技事件和突发公共事件中，以公众易于理解的方式主动传播地球科学知识，权威解读科学现象，正确引导社会舆论。

（二）支持和保障

部将积极为自然资源首席科学传播专家开展工作搭建平台、提供条件。部统筹安排自然资源首席科学传播专家参与地球日、土地日、海洋日、测绘法宣传日等重大科普活动；邀请参加自然资源优秀科普作品评选、科普基地命名和评估等工作。首席科学传播专家领衔开展公益性科普活动时，可以“自然资源首席科学传播专家”名义进行宣传和介绍。科普基地管理办公室将为自然资源首席科学传播专家深入科普基地，开展科学传播和科普培训工作提供平台和条件保障。

有关推荐部门和单位应创新机制，为培养、用好自然资源首席科学传播专家提供充分保障。自然资源首席科学传播专家所在单位要对其开展科学传播活动给予必要的时间、人员和经费保障。

三、有关要求

请各有关部门、单位认真组织做好自然资源首席科学传播专家征集工作，积极发现符合条件的专家，鼓励他们进入自然资源首席科学传播专家队伍，支持他们开展科学传播工作。请于2019年4月6日前，将《自然资源首席科学传播专家推荐表》及电子文档报部。

本次推荐，中国地质调查局推荐专家人数不超过10人，各省级自然资源主管部门、部其他直属单位、派出机构推荐专家人数不超过1人。原国土资源部首席科学传播专家不需再推荐。如无合适人选，本次可暂不推荐，部将长期开展自然资源首席科学传播专家队伍建设工作。
