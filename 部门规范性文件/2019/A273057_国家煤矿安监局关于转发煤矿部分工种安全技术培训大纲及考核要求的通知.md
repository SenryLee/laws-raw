# 国家煤矿安监局关于转发煤矿部分工种安全技术培训大纲及考核要求的通知

煤安监函〔2019〕2号

各产煤省、自治区、直辖市及新疆生产建设兵团煤矿安全培训主管部门：

国家煤矿安监局指导河北省应急管理厅编制了煤矿20个岗位工种的安全技术培训大纲及考核要求，现予以转发（可在国家煤矿安监局政府网站“通知公告”栏目下载），供参考。

请各省级煤矿安全培训主管部门按照《煤矿安全培训规定》（原安全监管总局令第92号）要求，结合本地区实际及时制定煤矿企业其他从业人员安全培训大纲和考核标准。

附件：煤矿部分工种安全技术培训大纲及考核要求

国家煤矿安全监察局

2019年1月4日
