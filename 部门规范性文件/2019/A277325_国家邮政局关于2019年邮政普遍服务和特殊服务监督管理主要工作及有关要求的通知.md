# 国家邮政局关于2019年邮政普遍服务和特殊服务监督管理主要工作及有关要求的通知

国邮发〔2019〕22号

中国邮政集团公司：

根据《中华人民共和国邮政法》《邮政普遍服务监督管理办法》等有关规定，邮政管理部门负责对邮政普遍服务实施监督管理。为了更好地促进邮政企业履行邮政普遍服务义务，保护用户合法用邮权益，巩固巡视成果，现将做好2019年邮政普遍服务和特殊服务主要工作的有关要求通知如下：

一、实现建制村直接通邮

邮政企业要打好建制村直接通邮攻坚战，2019年新增直接通邮建制村5000个以上，基本实现全国建制村直接通邮。一是加强对目前尚未实现直接通邮建制村的实地调研，厘清尚未实现直接通邮建制村名录，一村一策，销号管理，有通邮任务的市（地）邮政分公司每月最后一天向当地管理部门报送当月进展情况。二是加强对农村地区投递服务质量的管控，巩固现有通邮成果，确保已实现直接通邮地区服务水平不下降。加大实地检查力度，进一步确保农村地区投递服务质量。三是邮政管理部门将继续协调争取支持政策，推行利用信息化手段开展建制村投递服务质量监督，各级邮政企业要支持配合，做好基础信息采集报送和监督程序应用推广。

二、贯彻落实普遍服务标准，提升平信寄递质量

邮政企业要继续认真贯彻落实《邮政普遍服务》标准，做好寄递服务质量提升行动，查漏补缺，加强薄弱地区、薄弱环节服务质量的管控和提升。一是做好民族地区、农村地区、边远地区、边境地区的服务保障，确保这些地区服务水平达到标准要求。二是进一步提升乡镇局所、委代办局所、纯普遍服务局所服务水平，所有普遍服务局所全面实现电子化。三是继续加强对平信寄递服务质量的管控，推广平信条码化。国家邮政局将组织开展跨省际的普遍服务达标检查，加强对服务满意度、邮件时限、申诉率等重要指标信息的公开。

三、巩固提升党报党刊投递服务水平

邮政企业要进一步优化邮路作业组织，总结推广利用客运班车、高铁和航空等运输方式代运党报党刊的经验， 2019年全国县级城市《人民日报》当日见报率达到84%。尚未实现《人民日报》当日见报的省份，要进一步提升当日见报的县市数量，逐步减少三日及以上见报的情况。国家邮政局将继续组织开展国家规定报刊投递服务质量调查。

四、严守两条红线，做好邮政普遍服务局所管理

邮政企业要严格按照邮政企业撤销邮政普遍服务营业场所、停止办理或者限制办理普遍服务和特殊服务审批的规定向邮政管理部门申请办理相关审批，坚决杜绝未经审批擅自撤销普服局所和擅自停限办业务的问题。

五、做好“一市一品”农特产品进城精品项目

邮政企业要积极组织参与国家邮政局组织开展的“一市一品”农特产品进城精品项目。要加快推广“农产品+大同城”寄递服务模式，将服务链条从单一寄递环节向包装、存储、运输、销售等一体化服务延伸。要积极参与涉农电子商务平台建设，培育“电商+寄递”扶贫项目，重点扶持老少边穷地区培育特色地方农产品品牌，带动贫困人口增收致富。要深入推进邮政服务网点延伸到村，争取新增邮乐购站点3万个，提升邮政服务农村电商能力。

六、推动邮政综合服务平台建设

邮政企业要发挥网络优势、平台优势、功能优势，加快建设以寄递服务为核心，叠加普惠金融、政务、电商、便民等服务的多功能邮政综合服务平台。要积极实施警邮合作项目，年内每个地市应至少实现1个邮政营业场所或网点代办公安交管业务。要积极实施税邮合作项目，力争实现31个省份全覆盖。要积极推动邮政服务进驻各地综合性政务大厅，推广“网上办理+网下寄递”模式，提供审批文件、营业执照、社保卡等制证寄证一体化服务。

七、做强做优做大寄递主业

邮政企业要深化公司制改革，增加经营活力，打造快速稳定的邮政寄递网，做强做优做大寄递主业。发挥行业“国家队”带头作用，建立健全生态环保组织机构和工作体系，实施“绿色邮政”行动计划，完善绿色运输、绿色包装、节能减排等管控体系，年底电子运单使用率达到95%以上。配合建设邮政普遍服务补贴资金管理系统，逐步完善监管机制。

八、依法开展仿印邮票图案及其制品业务

邮政企业要进一步提高依法经营意识，按照《国家邮政局关于规范仿印邮票图案管理工作的通知》（国邮发〔2015〕88号）以及国家邮政局网站公布的仿印邮票图案及其制品审批事项服务指南和工作流程图等有关要求，依法开展仿印邮票图案及其制品业务。国家邮政局将在全国范围内组织开展仿印邮票图案管理省际交叉执法检查，加强对仿印邮票图案及其制品市场的检查力度，对发现的违法违规行为依法进行处理。

九、认真履行安全生产主体责任

邮政企业要做好邮政渠道安全生产工作，落实安全生产主体责任。一是认真落实邮件收寄验视、实名收寄、过机安检“三项制度”，巩固实名收寄信息化全覆盖成果。二是加大安全生产设备配置力度，普遍服务服务营业场所、邮件处理场所等要按照《邮政业安全生产设备配置规范》的要求，视频监控设备等在今年内要全部配置到位。三是继续做好重大活动和业务旺季期间寄递渠道安全保障工作。

十、加强信息报送与系统联网

邮政企业要按照《邮政普遍服务监督管理办法》的相关要求，及时、准确的向邮政管理部门提供邮政普遍服务相关数据资料。一是按照国家邮政局“绿盾”工程安排部署，推动以市（地）为单位将邮政普遍服务局所视频监控信息和一二级邮区处理中心局安检信息接入邮政管理部门。二是邮政集团公司要继续以总对总的方式向国家邮政局提供邮件实名信息数据，不断提升数据质量，继续按月提供所有给据邮件时限信息数据。

请各省（区、市）邮政分公司于2019年7月和2020年1月，将本地区邮政普遍服务和特殊服务质量自查报告报送所在地省级邮政管理部门，中国邮政集团公司于2020年1月3日前书面报告党报党刊收订情况，2020年3月前报送2019年全国邮政普遍服务和特殊服务质量自查报告。
