# 住房和城乡建设部村镇建设司关于印发县域统筹推进农村生活污水治理案例的通知

建村水函〔2019〕60号

各省、自治区、直辖市住房和城乡建设厅（建委）村镇建设处，北京市水务局污水处理与再生水管理处、上海市水务局农村水利处：

为贯彻落实《水污染防治行动计划》和《农村人居环境整治三年行动方案》，推动以县级行政区域为单元的农村污水处理统一规划、统一建设、统一管理，结合我部组织开展的全国农村污水治理百县示范工作，我们筛选了部分在县域统筹推进农村生活污水治理方面值得借鉴的案例。现将案例印发给你们，供工作中参考。

附：县域统筹推进农村生活污水治理案例（可在住房和城乡建设部网站下载）

中华人民共和国住房和城乡建设部村镇建设司

2019年9月16日
