# 国家文物局办公室关于悬泉置遗址保护区划内保护利用项目的意见

办保函〔2019〕781号

甘肃省文物局：

你局《关于在悬泉置遗址保护范围和建设控制地带内实施保护利用项目的请示》（甘文局发〔2019〕100号）收悉。经研究，我局暂不同意在悬泉置遗址保护区划内实施所报保护利用项目。

一、对所报项目方案提出以下修改完善意见：

（一）对照悬泉置遗址保护管理规划，全面核查方案各部分内容及设计的合规性，对突破规划要求的部分，应严格予以纠正或剔除。

（二）应在妥善保护遗址及其历史环境的前提下，科学开展遗址展示利用项目，最大限度保持遗址区原始景观风貌，减少人为干预。将各类建筑、设施选址尽可能移至保护范围以外，避免地下管线工程对遗址造成大规模扰动甚至破坏。

（三）应根据遗址游客承载力和历年游客量统计数据，重新测算未来游客流量，校核项目建设的功能需求和方案设计依据。

（四）优化公厕和游客服务用房等设施设计，压缩建筑体量，简化建筑形式，淡化建筑外观色彩。调整公共设施及标识系统设计，以满足基本使用功能为限，造型宜简洁朴素，避免喧宾夺主。此外应充分考虑到各类设施建筑在非旅游季节的维护问题。

（五）在方案三的基础上进一步完善道路设计，压缩道路宽度，进入保护范围内的道路应采用泥结碎石或砂石路面，色调应与周边环境相协调。进一步论证建设人行木栈道的必要性，如确需建设，应尽可能贴地铺设，取消栏杆扶手；取消保护范围内的木栈道。

（六）强化雨水污水排放设计，确保实际效果。补充说明在山沟两侧修建“排水沟”的必要性；取消沿山沟两侧建造的悬泉置服务点设计。进一步论证建设观景台的必要性，如确需建设，应压缩面积，并在重点保护区外另行选址。

（七）进一步规范方案文本及图纸，如补充悬泉置遗址保存现状评估及照片；补全设计图纸，补充标注每项工程在遗址保护区划中的位置等。

（八）针对修改后的方案更新遗产影响评估报告。

二、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年9月3日
