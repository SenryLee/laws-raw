# 农业农村部对十三届全国人大二次会议第5600号建议的答复

## 对十三届全国人大二次会议第5600号建议的答复

农办议〔2019〕546号

朝勒孟代表：

您提出的关于对基础母畜给予补贴的建议收悉。经商财政部，现答复如下。

国家高度重视畜禽种业发展，通过实施遗传改良计划、现代种业提升工程、畜禽种质资源保护等政策措施，积极推动畜禽种业创新与发展。为加快畜禽良种推广步伐，2018年，中央财政通过农业生产发展资金安排10亿元，支持畜禽标准化养殖和畜牧良种推广应用。在内蒙古、四川等8个省份实施畜牧良种补贴项目，对项目区内使用良种精液开展人工授精的肉牛养殖场（小区、户），以及存栏能繁母羊30只以上、牦牛能繁母牛25头以上的养殖户进行适当补助。通过项目实施，牛羊品种改良进程加快，生产性能不断提高，基础母畜的数量得到稳固、质量得到提升。下一步，我部将结合您提的建议，会同财政部进一步完善相关政策措施，提升制种供种能力，促进畜牧业高质量发展。

感谢您对畜牧业发展的关心，希望继续对我部工作给予支持。
