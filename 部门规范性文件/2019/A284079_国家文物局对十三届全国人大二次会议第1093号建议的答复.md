# 国家文物局对十三届全国人大二次会议第1093号建议的答复

文物政函〔2019〕686号

叶露中代表：

您提出的“关于加强大别山地区革命文物保护与利用的建议”收悉。经商国家发展改革委、文化和旅游部，现答复如下。

大别山革命老区（包括六安市）是中国革命的重要策源地、人民军队的重要发源地，革命文物资源得天独厚、分布广泛、类型丰富。加强大别山地区革命文物保护利用，对于传承红色基因、发展红色旅游、促进革命老区脱贫攻坚和振兴发展具有重要意义。

国家高度重视大别山地区革命文物工作。中央宣传部、财政部、文化和旅游部、国家文物局公布了第一批革命文物保护利用片区分县名单，其中鄂豫皖片区覆盖湖北、河南、安徽3个省41个县（包括六安市6个县）。国家文物局支持湖北、河南、安徽编制《大别山区革命文物保护利用战略规划》，实施一批大别山区革命文物保护展示项目，开展金寨革命文物保护传承工程。“十三五”期间，国家发展改革委通过文化旅游提升工程，累计安排中央预算内投资2.5亿元，支持大别山地区旅游基础设施建设，积极发展红色旅游。

下一步，中央相关部门将以中共中央办公厅、国务院办公厅《关于实施革命文物保护利用工程（2018-2022年）的意见》为指导，进一步做好大别山地区革命文物保护利用工作。

一是统筹推进大别山地区革命文物集中连片保护。以鄂豫皖革命文物保护利用片区为重点，支持地方编制实施《大别山区革命文物保护利用战略规划》，支持编制分省片区革命文物保护行动计划，支持建立大别山地区革命文物保护利用的跨省协作机制。国家文物保护专项资金支持大别山地区实施一批、完工一批、储备一批革命文物保护项目，改善革命文物保存状况和环境风貌，助力革命老区脱贫攻坚、乡村振兴。

二是支持金寨县创建两源两地国家5A级旅游景区。大别山地区红色旅游资源丰富，具有打造精品文化和旅游产品的良好基础。文化和旅游部将在安徽省文化和旅游厅对金寨县创建两源两地国家5A级旅游景区初检的基础上，按程序组织开展相关工作，并酌情对创建工作予以指导。

三是支持大别山地区红色文化旅游融合发展。深入挖掘大别山红色文化内涵和价值，提升革命旧址和革命博物馆纪念馆的展陈水平和服务质量，推出红色旅游精品线路、文创产品、演艺剧目，通过红色旅游的带动作用，形成红色+绿色、红色+文创、红色+研学等多业态融合发展模式，打造独具特色的红色旅游品牌。争取将第九届全国大学生红色旅游创意策划大赛落地金寨县。继续通过文化旅游提升工程积极支持大别山地区发展红色旅游，对符合旅游发展基金支持方向的项目给予积极支持。

感谢您对革命文物保护的关心和支持。

国家文物局

2019年7月10日
