# 司法部办公厅关于向中国农业发展集团有限公司吴刚等11名同志颁发公司律师证书的函

司办函〔2019〕254号

中国农业发展集团有限公司：

你公司《关于报送中国农发集团第一批公司律师申请材料的函》（中农法律函〔2018〕76号）收悉。我部经审查，同意向以下11名同志颁发公司律师证书：

吴刚、臧亚利、张德永、高莫娇、贾欣、李佳、李思奕、赵景超、张军伟、李娜、方媛。

司法部办公厅
