# 国家邮政局对十三届全国人大二次会议第2247号建议的答复

## 对十三届全国人大二次会议第2247号建议的答复

国邮函〔2019〕70号

杨金龙代表：

您提出的“关于支持快递末端共享服务平台进社区的建议”（第2247号）收悉。经商自然资源部、住房和和城乡建设部，现答复如下：

您在建议中所提快递“最后一公里”问题符合行业实际，加强政策支持保障快递末端共享模式发展的建议具有较强的针对性。

国家邮政局一直高度重视快递“最后一公里”问题的解决，开展了大量的工作。

一是健全配套政策。我局2013年出台的《关于提升快递末端投递服务水平的指导意见》和2017年出台的《关于加强和改进快递末端服务管理工作的指导意见》，均对平台化的快递业末端公共服务场所建设给予了明确支持。2018年初，我局联合商务部推动国务院办公厅出台《关于推动电子商务与快递物流协同发展的指导意见》，要求创新公共服务设施管理方式，明确智能快件箱、快递末端综合服务场所的公共属性，为专业化、公共化、平台化、集约化的快递末端网点提供用地保障等配套政策。

二是完善配套法律制度。2018年初，我局推动国务院出台《快递暂行条例》，鼓励多个经营快递业务的企业共享末端服务设施，为用户提供便捷的快递末端服务。2018年5月，印发《快递末端网点备案暂行规定》。快递末端网点按规定进行属地的事后备案，无需办理营业执照，有效减轻了企业布局末端网络的负担。末端网点备案实现全流程在线办理，企业享受到“一次不用跑”的政务服务。快递末端公共服务场所作为末端网点的重要形式之一，得到了有力的支持。

三是持续推进快递末端综合服务场所建设。我局连续多年将实施“快递入区”工程，进而解决“最后一公里问题”列入工作重点，持续推进快递末端公共服务场所建设。截至2019年5月底，全国已建成快递末端公共服务站超过8万个，布放智能快件箱31万组。

自然资源部、住房和城乡建设部也开展了相关工作。自然资源部表示，近日印发的《中共中央 国务院关于建立国土空间规划体系并监督实施的若干意见》明确提出，将主体功能区规划、土地利用规划、城乡规划等空间融合为统一的国土空间规划，实现“多规合一”。快递末端共享服务平台属于邮政设施，也是社区必要的公共服务设施之一。自然资源部将指导和督促地方政府在编制和实施各层次规划时，做好邮政设施的用地和布局安排。住房和城乡建设部表示，已于2018年修订发布《城市居住区规划设计标准》（GB50180-2018），明确要求居住街坊中配置邮件和快递送达设施。其开展的城市体检试点工作，已将快递等社区服务纳入城市体检内容。

下一步，国家邮政局将继续大力推动快递末端公共服务场所建设，努力推动“最后一公里”问题有效解决。自然资源部将指导和督促地方政府在编制和实施各层次规划时，做好邮政设施的用地和布局安排，配合邮政管理部门做好快递末端共享服务平台的设施和管理。住房和城乡建设部将编制完善社区设施配套导则，进一步明确社区内快递服务设施的设置要求和建设标准，指导物业服务企业努力为快递配送提供便利和合作。

感谢您们对快递业发展的关心和支持！

国家邮政局

2019年7月2日
