# 农业农村部对十三届全国人大二次会议第6769号建议答复摘要

## 对十三届全国人大二次会议第6769号建议答复摘要

农办议〔2019〕84号

种业是国家基础性、战略性核心产业，党中央、国务院高度重视种业发展。2011年以来，先后发布了《国务院关于加快推进现代农作物种业发展的意见》（国发〔2011〕8号）、《全国现代农作物种业发展规划（2012－2020年）》（国办发〔2012〕59号）及《国务院办公厅关于深化种业体制改革 提高创新能力的意见》（国办发〔2013〕109号），对推进科企合作，加快商业化育种进行了安排部署。

一是加快品种管理制度改革，推动商业化育种体系建立。为符合要求的育繁推一体化企业开通绿色通道试验，具有试验能力的企业、科研单位可联合开展试验，对特殊类型的品种育种者可自行开展试验，以此拓宽品种试验渠道，确立企业品种创新主体地位；建立非主要农作物品种登记制度，激发特色作物品种创新活力，为特色产业发展和农业供给侧结构性改革提供重要的品种保障。企业作为品种市场销售的主体，品种登记积极性很高；扩大植物新品种保护范围，2019年，农业农村部发布第十一批植物新品种保护名录，保护范围扩大到191个植物属种，有效地调动了育种者的积极性，有效保护品种权所有人权益，促进了优良品种创新和推广应用。

二是推进科研体制改革，为商业化育种提供人才支撑。国家高度重视人才发展体制机制改革，推动出台了多项政策措施，持续推进科研体制改革。

三是组织开展良种联合攻关，深入推进科企合作。2014年以来，我部陆续启动实施了4大作物、11种特色作物良种重大科研联合攻关，通过机制创新推动理论创新、技术创新和品种创新，提高了育种效率，取得了育种科研创新和科技体制改革的新成效；在农作物育种科学研究方面积极支持生物育种领域创新能力建设，构建现代种业创新体系。

农业农村部

2019年7月24日
