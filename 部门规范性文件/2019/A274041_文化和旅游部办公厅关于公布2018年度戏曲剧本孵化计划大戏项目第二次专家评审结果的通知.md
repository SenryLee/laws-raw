# 文化和旅游部办公厅关于公布2018年度戏曲剧本孵化计划大戏项目第二次专家评审结果的通知

办艺发〔2019〕21号

各省、自治区、直辖市文化和旅游厅（局），新疆生产建设兵团文化体育新闻出版广电局：

根据《文化和旅游部办公厅关于开展2018年度戏曲剧本孵化计划项目申报工作的通知》（办艺发〔2018〕34号）精神，戏曲剧本孵化计划项目主办方组织专家评审，在公示后确定了大戏项目一类和二类作品各8部。现将结果予以公布，并就有关事项通知如下：

一、项目主办方对入选一类作品的8个项目给予每部25万元的资助经费，对入选二类作品的8个项目给予每部20万元的资助经费。

二、2018年度戏曲剧本孵化计划第一次专家评审结果已于2018年11月6日公布。为加强项目管理，请承担原创大戏孵化任务的单位于2019年2月28日前，将本单位与项目编剧签订的委托创作协议书报项目主办方。

三、戏曲剧本孵化计划提倡剧作者创作剧本时深入生活、采风创作、精益求精。请承担原创大戏一类、二类作品孵化任务的单位于2019年2月28日前，向项目主办方提交项目编剧深入生活采风和加工修改提高的生活札记和创作笔记（书面材料，不少于5000字，要求编剧本人签字、单位盖章，同时报送电子版）。

项目主办方联系人：中国数字文化集团有限公司　张淼

联系地址：北京市朝阳区吉祥里103号中国工艺集团大厦一层中国数字文化集团有限公司（邮编100020）

电话：010-85306017-843

本通知及附件可在文化和旅游部政府门户网站（www.mct.gov.cn）“通知公告”栏查询、下载。
