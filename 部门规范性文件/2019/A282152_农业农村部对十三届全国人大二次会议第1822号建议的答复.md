# 农业农村部对十三届全国人大二次会议第1822号建议的答复

## 对十三届全国人大二次会议第1822号建议的答复

农办议〔2019〕198号

魏洪义代表：

您提出的关于加强产业规划和技术指导降低脱贫攻坚工作中农业产业风险的建议收悉。现答复如下。

党中央、国务院高度重视产业扶贫工作，明确把产业扶贫摆在“五个一批”的首位。各地各部门认真学习贯彻习近平总书记关于扶贫工作的重要论述和中央脱贫攻坚决策部署，按照精准扶贫、精准脱贫的基本方略，加快推进产业发展、加强主体培育、创新利益联结、促进产销对接、强化科技支撑和人才培育，产业扶贫工作取得了显著成效。

一、关于指导制定产业发展规划，引领产业发展

（一）加强产业规划指导。2014年，我部印发《特色农产品区域布局规划（2013—2020年）》，将贫困地区96个品种纳入规划范围，明确发展方向、目标和优势区域，对贫困地区发挥资源比较优势、优化特色产业布局、引导多方资金投入、促进农民增收致富提出具体要求。2017年，我部会同发展改革委、林业局印发《特色农产品优势区建设规划纲要》，明确国家、省两级特色农产品优势区（以下简称“特优区”）架构，围绕5大类29个重点品种（类）创建特优区，认定国家级特优区，加快培育特色产业，促进农民增收，推动地区经济发展。截至目前，已经创建国家级特优区146个，其中贫困地区创建特优区46个。

为推进产业扶贫工作，根据中央的部署要求，2016年，我部联合发展改革委等8部门印发《贫困地区发展特色产业促进精准脱贫指导意见》，指导22个扶贫任务重的省（区、市），综合考虑资源禀赋、产业现状、市场空间、环境容量以及产业覆盖面，编制完成省、县两级产业扶贫规划，推动当地科学确定产业，精准设计项目，确保产业对人、人对产业。2019年，我部把贫困地区特色产业优先纳入《全国乡村特色产业目录》，进一步加强宣传推介，培育壮大贫困地区特色产业，助推脱贫攻坚。

（二）利用大数据分析指导农业生产。我部高度重视农业农村信息化建设工作，通过编制农业农村经济信息体系、全国大宗农产品市场体系建设规划，布局全国农业农村信息化网络建设。组织开展农产品和农业生产资料供求、价格分析和市场预警，发布农业农村经济信息等，供各地政府主管部门和农业生产者参考，指导发展生产。我部通过全国农产品批发市场价格信息系统，为包括贫困地区在内的广大农业生产经营者提供及时、客观、真实的市场信息，指导生产者合理调整种养殖品种结构和规模，健康发展产业。为进一步做好贫困地区农产品产销对接工作，2019年，我部开通运行贫困地区农产品产销对接公益服务平台，发布贫困地区农产品供求信息，提供实时有效的农产品市场需求情况，引导贫困地区特色农产品销售。目前，平台已注册供应商近3000家、采购商近800家，达成交易意向近亿元。

下一步，我部将根据《关于打赢脱贫攻坚战三年行动的指导意见》要求，指导各地调整完善产业扶贫规划，编制乡村振兴规划，支持贫困地区走绿色化、优质化、特色化、品牌化路子，推进农产品加工升级转化，提升农产品附加值。加快构建农业综合信息服务平台，深入开展贫困地区特色农产品摸底调查，加强贫困地区信息监测，逐步将贫困地区批发市场纳入全国农产品批发市场价格信息采集系统，供各地政府部门和种养殖户参考。指导各地对扶贫产业面临的技术、市场和保险等风险进行评估，制定防范和处置风险的应对措施，为贫困群众脱贫增收，巩固现有脱贫成果和防止返贫提供坚实支撑。

二、关于加强农业科技服务支撑，保障产业健康发展

为切实提升产业扶贫质量，我部积极发挥行业部门优势，针对贫困地区农业特色产业技术需求，不断强化科技精准帮扶。依托国家现代农业产业技术体系专家团队，调动全国农业科技系统力量为贫困地区产业扶贫提供技术服务支撑。组织相关省份组建贫困县产业扶贫技术专家组，开展精准决策咨询和生产技术指导。继续加强贫困地区基层农技推广体系建设，在22个脱贫任务重的省份全面实施农技推广服务特聘计划，在621个贫困县招募特聘农技人员3000多名，切实提升产业扶贫技术支撑保障水平。依托国家现代农业产业技术体系专家团队，组建6个科技服务团、544个产业扶贫技术专家组，对口“三区三州”科技帮扶工作，覆盖“三区三州”165个贫困县。面向贫困地区开展农村实用人才带头人和高素质农民培训，分片区举办农业农村系统产业扶贫培训班，累计培训3万多人次，有效提高了各地推进产业扶贫的能力和水平。2018年，我部印发《关于组建贫困县产业扶贫技术专家组的通知》，进一步推动贫困地区加快组建产业扶贫技术专家组，着力开展到村到户精准决策咨询和生产技术指导。截至目前，已经组建各类产业技术专家组4100余个。

下一步，我部将会同相关部门加强农业扶贫科技支撑，充分调动基层农技推广人员力量，发挥现代农业产业技术体系专家作用，提升特色产业扶贫专家组服务能力。强化人才培训工作，加快贫困地区高素质农民和农村实用人才带头人培养，增强脱贫带动能力。同时，不断提升农业农村部门干部带领群众脱贫致富、推动经济发展的能力，着力培养造就一支懂农业、爱农村、爱农民的“三农”干部队伍。

感谢您对农业农村工作的关心和重视，希望今后继续对我部工作予以支持。
