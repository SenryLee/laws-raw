# 交通运输部职业资格中心通告第37号——关于公布2019年度公路水运工程试验检测专业技术人员职业资格考试合格标准的通告

## 交通运输部职业资格中心通告

第37号

## 关于公布2019年度公路水运工程试验检测专业技术人员职业资格考试合格标准的通告

根据公路水运工程试验检测专业技术人员职业资格制度规定，经人力资源和社会保障部批准，2019年度公路水运工程助理试验检测师和试验检测师《公共基础》科目考试合格标准为72分（试卷满分为120分），其他专业科目考试合格标准均为90分（试卷满分均为150分）。

特此通告。

交通运输部职业资格中心

2019年12月25日
