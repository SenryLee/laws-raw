# 国家移民管理局关于对十三届全国人大二次会议第4369号建议的答复

车耶等4名代表：

你们提出的关于加大支持勐腊（磨憨）重点开发开放试验区和中国老挝磨憨—磨丁经济合作区（以下简称勐腊“两区”）的建议收悉，现答复如下：

近年来，我局高度重视、认真落实《国务院关于支持沿边重点地区开发开放若干政策措施的意见》（国发〔2015〕72号）精神，积极支持勐腊“两区”建设。一是在磨憨口岸常态落实中国公民通关排队候检不超过30分钟、鲜活产品优先验放、旅游团队预约通关等通关便利化举措，倾力服务跨境人员和贸易往来。二是在磨憨口岸边检现场设置“一带一路”专用通道，为执行“一带一路”建设重点工程、重要合作、重大项目或参加“一带一路”有关会议、活动的中外人员和车辆快捷办理边检手续。三是主动跟进关累港对外开放码头边检设施建设，推行国际航行船舶网上报检措施，实现出入境船舶无纸化通关。四是积极加强与老挝移民部门国际执法合作，共同维护中老口岸边境安全稳定、服务双边人员往来。

对于你们提出的涉及出入境边防检查的建议，我们进行了认真研究。一是关于加大人员往来便利化政策支持力度。我局将继续落实《国务院关于支持沿边重点地区开发开放若干政策措施的意见》，指导云南出入境边防检查总站加强边检管理模式创新。二是关于建立中老双方联合工作组会晤机制。目前，驻勐腊边检机关均与对应老挝移民部门建立了执法合作机制，定期举行会谈会晤，共同研究口岸管控和通关工作。我局支持在勐腊“两区”合作区管委会层面建立中老双方联合工作组会晤机制，并将立足职能，积极解决口岸、互市点建设和边贸发展中出现的人员、车辆通关问题。三是关于赋予勐腊“两区”开展跨境合作更大权力。为服务勐腊“两区”开放发展，我局将指导云南出入境边防检查总站和驻勐腊边检机关积极跟进支持中老跨境经济合作区建设，提高口岸通关效率，最大限度为跨境贸易和人员往来提供便利。

感谢你们对移民管理工作的关心和支持。
