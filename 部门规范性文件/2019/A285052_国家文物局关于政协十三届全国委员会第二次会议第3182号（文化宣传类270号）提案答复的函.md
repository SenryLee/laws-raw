# 国家文物局关于政协十三届全国委员会第二次会议第3182号（文化宣传类270号）提案答复的函

文物博函〔2019〕906号

登巴大吉委员：

您提出的《关于加大喜马拉雅文化保护研究，创建“一带一路”人文交流平台的提案》已交由我局会同文化和旅游部办理，现答复如下。

文化和旅游部、国家文物局一直高度重视环喜马拉雅山脉区域文化遗产保护和融入“一带一路”工作，先后印发了《“一带一路”文化发展行动计划（2016-2020年）》《国家文物事业发展“十三五”规划》，实施“一带一路”文化遗产长廊建设工程和“中华文物走出去精品工程”。一是加强文物保护和博物馆建设。西藏博物馆、四川博物院、甘肃省博物馆等一批博物馆被评为国家一级博物馆，组织完成了第一次全国可移动文物普查等重大项目，实施了以纺织品、青铜器、经卷文献为重点的一系列可移动文物保护项目和预防性保护项目，推出“唐蕃古道·丝绸之路沿线省市（区）文物联展”等一批藏文化特色专题展览和出境展览，开展文物科技保护交流合作。二是积极支持开展非遗发掘、保护和传承。2013年以来，对西藏和四省藏区非物质文化遗产代表性项目累计投入国家非遗保护专项资金约1.18亿元，同时，用数字多媒体等现代化手段对西藏自治区40名国家级非遗代表性传承人开展记录和研究。特别是重点支持唐卡的保护与研究。西藏及四省藏区现有唐卡国家级非遗代表性项目8个，其中，以唐卡为代表的热贡艺术被列入联合国教科文组织人类非遗代表作名录。2013年以来，国家级非遗代表性项目藏族唐卡（伽玛嘎孜画派）的有关项目单位被命名为国家级非遗生产性保护示范基地、国家级非遗保护研究基地。

经向四川省文物局了解，2018年申请设立的“大吉喜马拉雅文化艺术博物馆”，尚未获批准备案，您提出的依托大吉喜马拉雅文化艺术博物馆建立具有国际影响力的地标性喜马拉雅文化博物馆，搭建国际交流互动平台，整合资源，组建“唐卡国家实验室”的建议，暂不具备条件。我局将会同文化和旅游部，并积极协调有关省级文物行政部门，进一步加大对相关非国有博物馆的引导、规范和支持力度，不断提升公共服务能力和专业化水平；继续推动非遗保护研究，鼓励相关科研院所及文化遗产保护展示场馆，整合各类资源，实施非遗记录工程、中国传统工艺振兴计划；加强展览交流，积极参与“一带一路”国际人文交流合作。

感谢您对博物馆事业的关心和支持！

国家文物局

2019年8月30日
