# 国家文物局办公室关于秦咸阳城遗址建设控制地带内春城十八里（二期）建设项目的意见

办保函〔2019〕128号

陕西省文物局：

你局《关于春城十八里（二期）项目选址涉及秦咸阳城遗址建设控制地带的请示》（陕文物字〔2018〕219号）收悉。经研究，我局暂不同意在秦咸阳城遗址建设控制地带内实施春城十八里（二期）建设项目。

一、拟建项目紧邻秦咸阳城遗址保护范围，应按照《秦咸阳城遗址保护总体规划》（2011-2030）要求，进一步核减建设体量、降低建筑高度和密度；建筑外观样式应与遗址景观风貌相协调。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，根据考古发掘成果和上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年2月26日
