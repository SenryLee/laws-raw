# 交通运输部公告2019年第32号——交通运输部关于发布《邮轮码头设计规范》（JTS 170-2015）英文版的公告

## 交通运输部公告

2019年第32号

## 交通运输部关于发布《邮轮码头设计规范》（JTS 170-2015）英文版的公告

为加强水运工程行业标准对外交流，现发布《邮轮码头设计规范》（JTS 170-2015）英文版，由交通运输部水运局负责管理和解释。英文版与中文版相关内容含义不一致的，以中文版为准。

请将使用过程中发现的问题和修改意见建议反馈至中交第三航务工程勘察设计院有限公司（地址：上海市徐汇区肇嘉浜路831号，邮政编码：200032，电子邮箱：cad@theidi.com），以便修订时参考。

特此公告。

交通运输部

2019年5月13日
