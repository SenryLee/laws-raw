# 农业农村部办公厅关于切实做好农药包装废弃物回收工作的通知

农办农〔2019〕14号

各省、自治区、直辖市农业农村（农牧）厅（局、委），新疆生产建设兵团农业农村局，黑龙江省农垦总局：

为贯彻《土壤污染防治法》的规定，落实农药生产者、销售者和使用者对农药包装废弃物回收工作责任，总结推广各地农药包装废弃物回收试点经验，加快推进农药包装废弃物回收，现将有关事项通知如下。

一、全面加强农药包装废弃物监测调查

各省（区、市）农业农村部门要加强田间监测，尽快组织人员开展本行政区域内农药包装废弃物情况调查，摸清农药包装废弃物数量及分布区域，测算并统计田间遗弃和回收数量，以县为单位上报监测调查结果。各省（区、市）农业农村部门要在2019年9月30日前，将本省份农药包装废弃物摸底调查情况报送我部农药管理司。同时，自2019年第三季度起，每季度由省级农业农村部门汇总上报农药包装废弃物回收情况，并协调省级生态环境部门汇总上报农药包装废弃物处置情况。

二、加快构建农药包装废弃物回收体系

农业农村部今年在5个省10个重点县组织开展农药包装废弃物回收试点。各省（区、市）要落实《土壤污染防治行动计划》要求，结合当地实际，选择产粮（油）大县和蔬菜产业重点县，积极开展农药包装废弃物回收试点工作。要切实增强农药生产企业、农药经营单位和农药使用者自觉回收意识和科学回收能力，加快构建农药包装废弃物回收、储存站点，探索建立政府补贴、农药生产经营使用者积极参与、专业机构主动配合的农药包装废弃物回收处置机制。

三、大力推进病虫害专业化统防统治

各级农业农村部门要加强病虫害监测防控能力建设，及时准确发布病虫信息，指导科学防控，大力扶持发展规范化病虫专业防治组织。要加强技术培训与指导，改变一些农民盲目打药和随意丢弃农药包装物的习惯，提升农药科学使用水平。要结合开展“统防统治百县”创建活动，加强对统防统治组织的指导与管理，鼓励和引导专业化统防统治组织在农药生产企业定制大包装、可回收再利用的包装物贮运农药，有效减少农药包装废弃物。

四、督促各类主体落实农药包装废弃物回收义务

农药生产企业、农药经营单位和农药使用者是农药包装废弃物回收的主体。各地要因地制宜探索农药包装废弃物回收模式，合理划分农药生产企业、农药经营单位和农药使用者的回收义务，鼓励使用者自发回收农药包装废弃物，探索农药生产企业有偿回收机制。要加大政策创设，整合相关涉农资金重点支持农药包装废弃物回收工作，积极引导社会资本参与农药包装废弃物回收。

五、加强宣传引导和监督指导

各省（区、市）农业农村部门要加大宣传力度，让广大农民群众、新型经营主体、农药生产企业、农药经营单位和农药使用者了解农药包装废弃物回收处置的重要意义，为农药包装废弃物回收工作营造良好氛围。要及时向社会公开农药包装废弃物回收处置实施情况等相关信息，做到公开透明。要依法加强对农药包装废弃物回收工作的日常监督与管理，及时了解和掌握工作进展情况，适时组织监督检查和现场指导，及时发现和解决存在的问题。要依法查处一批随意丢弃农药包装废弃物的典型违法案件，切实增强守法意识。

农业农村部办公厅
