# 公开市场业务交易公告[2019]第245号——关于今日不开展逆回购操作的公告

## 公开市场业务交易公告

[2019]第245号

2019年12月16日，人民银行开展中期借贷便利（MLF）操作3000亿元，比当日到期量多140亿元。今日不开展逆回购操作。

MLF操作情况

|  |  |  |
| --- | --- | --- |
| **期限** | **操作量** | **中标利率** |
| 1年 | 3000亿元 | 3.25% |

二〇一九年十二月十六日
