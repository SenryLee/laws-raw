# 国家文物局办公室关于开展2019年度中外联合考古项目评估工作的通知

办保函〔2019〕995号

各有关省、自治区、直辖市文物局（文化和旅游厅/局）、各有关单位：

为贯彻落实习近平总书记在“推进‘一带一路’建设工作5周年座谈会”上的重要指示和中办、国办《关于加强文物保护利用改革的若干意见》要求，推进中国考古国际交流合作，提升中外联合考古工作水平，我局拟组织开展2019年度中外联合考古项目评估工作。现就具体事宜通知如下：

一、评估对象

2019年度在中国境内开展的涉外考古调查、发掘和合作研究项目，以及中国科研机构和高等院校赴外考古项目。

二、评估形式

本次评估工作由国家文物局组织，委托中国科技出版传媒股份有限公司具体实施。评估工作将采取资料收集、专家评议等方式，综合评价2019年度各项目实施情况、研究成果和社会效益等。

三、材料要求

请各有关省、自治区、直辖市文物局（文化和旅游厅/局）组织辖区内承担或参与中外联合考古项目的考古机构、高等院校填报《2019年度涉外考古项目报告》（附件1）、《2019年度赴外考古项目调查表》（附件2）、《2019年度赴外考古项目报告》（附件3）。请认真审核材料，汇总后于2019年11月30日前将评估材料电子文件、纸质材料（一份）提交至中国科技出版传媒股份有限公司。附件1-4可在国家文物局网站（www.sach.gov.cn）的通知公告栏中下载。
