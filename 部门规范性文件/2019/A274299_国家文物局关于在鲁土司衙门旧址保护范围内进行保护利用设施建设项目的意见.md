# 国家文物局关于在鲁土司衙门旧址保护范围内进行保护利用设施建设项目的意见

文物保函〔2019〕93号

甘肃省文物局：

你局《关于呈报鲁土司衙门旧址保护利用设施建设项目设计方案的请示》（甘文局发〔2018〕176号）收悉。经研究，我局原则同意在鲁土司衙门旧址保护范围内进行保护利用设施建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）对项目所涉区域补充必要的考古工作，了解地下遗存分布情况以指导项目实施。

（二）结合对建筑群历史格局的分析，补充论证新建管理用房选址的依据；新建建筑外观设计可不限于仿古样式，应严格控制其体量、颜色和尺度，与周边环境相协调即可；补充施工期间对项目周边文物建筑的保护、监测要求和措施，确保文物安全。

（三）进一步论证校场铺装材质，建议考虑固化土或泥结石等方式，并优化景观设计，适当弱化其空间连续性。

（四）应补充市政管网资料，做好新设管线与已有管线的衔接。

（五）结合文物影响评估报告的结论和建议，进一步深化完善设计方案。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月23日
