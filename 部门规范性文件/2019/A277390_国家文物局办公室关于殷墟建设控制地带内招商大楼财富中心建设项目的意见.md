# 国家文物局办公室关于殷墟建设控制地带内招商大楼财富中心建设项目的意见

办保函〔2019〕352号

河南省文物局：

你局《关于上报安阳市殷都区招商大楼财富中心建设项目涉及全国重点文物保护单位殷墟建设控制地带设计方案的请示》（豫文物〔2019〕45号）收悉。经研究，我局暂不同意在殷墟建设控制地带内进行招商大楼财富中心建设项目。

一、对所报方案提出以下修改完善意见：

（一）严格按照《殷墟遗址保护规划（2012-2025年）》建设控制地带管理规定，修改完善拟建项目设计方案，降低建筑高度，压缩建筑体量，优化建筑外观设计，避免对殷墟遗产环境景观造成破坏。

（二）应对该拟建项目地块进行全面考古调查、勘探和必要的考古发掘，如遇重要文物遗存，应组织中国社会科学院考古研究所进行评估，并对项目选址和设计方案作出必要调整。

（三）进一步规范并深化遗产影响评估，应将《殷墟遗址保护规划（2012-2025年）》作为评估依据，判断方案设计的依法合规性。此外应补充考古勘探图等资料，明确项目选址与相关文物遗存的位置关系，在此基础上分析项目建设对遗产的影响。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。同时进一步加强对殷墟保护区划范围内建设项目的管控，严格按照《殷墟遗址保护规划（2012-2025年）》要求，进一步加大监管力度，坚决杜绝未批先建、突击建设等违法违规行为。

专此函复。

国家文物局办公室

2019年5月7日
