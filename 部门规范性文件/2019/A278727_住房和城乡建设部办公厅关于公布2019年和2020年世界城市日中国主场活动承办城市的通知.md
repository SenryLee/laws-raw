# 住房和城乡建设部办公厅关于公布2019年和2020年世界城市日中国主场活动承办城市的通知

建办外函〔2019〕387号

各省、自治区住房和城乡建设厅，直辖市住房和城乡建设（管）委，新疆生产建设兵团住房和城乡建设局：

根据《住房和城乡建设部关于印发世界城市日中国主场活动承办城市遴选办法（试行）的通知》（建外〔2019〕1号）和《住房和城乡建设部办公厅关于开展2019年和2020年世界城市日中国主场活动承办城市遴选工作的通知》（建办外函〔2019〕133号），在各地推荐基础上，经评审委员会评审和我部常务会审议，决定由河北省唐山市承办2019年世界城市日中国主场活动，福建省福州市承办2020年世界城市日中国主场活动，浙江省衢州市作为备选城市。

中华人民共和国住房和城乡建设部办公厅

2019年6月26日
