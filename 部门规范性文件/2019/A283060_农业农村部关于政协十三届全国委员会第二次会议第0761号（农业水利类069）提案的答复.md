# 农业农村部关于政协十三届全国委员会第二次会议第0761号（农业水利类069）提案的答复

## 关于政协十三届全国委员会第二次会议第0761号（农业水利类069）提案的答复

尚勋武委员：

您提出的“关于构建中华蜂养殖和产业集聚核心区，助推秦岭山区农户稳定脱贫的提案”收悉。经商国家林业和草原局，现答复如下。

中华蜂是我国本土宝贵的蜂种资源，能够充分适应我国不同地区的环境条件。中华蜂饲养历史悠久，具有广泛的群众基础，在生态环境保护和采花授粉促进农业增产增收方面发挥了显著作用。中华蜂养殖作为特色畜牧产业，也是推进精准扶贫的重要选择。目前，中华蜂饲养多集中于边远山区，饲养技术水平总体偏低，进一步提升贫困山区蜂业发展水平，对有效帮助贫困群众脱贫增收，如期实现全面小康具有十分重要的意义。我部高度重视中华蜂产业发展工作，将积极采取措施，为包括秦岭山区在内的有关地区通过中华蜂养殖实现脱贫提供保障支持。

一、关于组织协调甘肃、陕西、四川等省制定《秦岭山区中华蜂产业发展规划》

目前，我部正在启动全国蜂产业“十四五”规划编制有关工作，甘肃、陕西、四川等省可根据国家总体发展规划的精神和发展布局制定本地区的中华蜂产业发展规划。国家高度重视中华蜂产业持续健康发展，采取相关措施限制农林业农药使用。目前，我部已对67种高毒高风险农药实施了禁限用措施，对其余10种高毒农药也采取三方面的监管措施。一是定点经营，严格按照《农药管理条例》规定，对高毒农药实行专柜销售、实名购买、购销台账、溯源管理，实现从生产、流通到使用的全程监管。同时，禁止通过互联网销售高毒农药。二是限制使用，严格采取限用措施，不得用于果菜茶等作物生产。三是加快淘汰，按照“循序渐进、分步实施、多措并举”的原则，依据高毒农药的风险大小、替代产品生产使用情况，逐步推进，加快淘汰，力争5年分期分批淘汰现有的高毒农药。国家林草局深入贯彻落实《国务院办公厅关于进一步加强林业有害生物防治工作的意见》，制定印发了《林用药剂安全使用准则》《林用农药安全使用综合治理实施方案》，加大低毒低残留农药和生物农药的推广应用，全面开展了包括秦岭山区在内的林用农药使用安全隐患排查，对提升秦岭蜜源区病虫害防治水平，促进中华蜂产业健康安全发展起到了很好的作用。

二、关于支持甘肃省养蜂技术研究所提高科技创新和技术服务能力

2008年，我部设立国家蜂产业技术体系，用于组织指导全国蜂产业科技研发推广工作。体系设立天水综合试验站，由甘肃省养蜂技术研究所负责运转，每年安排经费50万元。近年来，该所承担了甘肃省及青海、西藏部分区域蜂业技术研发和技术示范工作，在蜜蜂授粉试验研究、抗螨高产优良蜂种的试验示范、地方优良蜂种评价、规模化高效养殖、蜂业发展观测调研、蜜蜂资源动态监控、基地建设、蜂农培训、支撑产业发展、扶贫攻坚等方面取得了良好成绩。有力促进了甘肃等省蜂业健康发展，先后取得16项国家发明专利和实用新型专利，以及省市级多项科技进步奖励。今后，我部将继续支持有关科研单位加强中华蜂遗传育种、病虫害防治以及产品保鲜加工方面的科技研发工作。

三、关于在甘肃省陇南市构建中华蜂养殖和产业集聚核心区，创建中华蜂产业示范园区

2018年起，中央财政通过农业生产发展资金，在黑龙江、江苏等10个蜂业主产省实施蜂业质量提升行动，支持地方建设高效优质蜂产业发展示范区，用于开展蜜源植物保护利用、蜜蜂遗传资源保护利用、良种繁育推广、现代化养殖加工技术及设施推广应用、蜂产品质量管控体系建设等工作。我部将积极与有关部门沟通协调，争取扩大项目实施范围，覆盖更多贫困山区。

四、关于支持三省农牧部门构建中华蜂产业技术体系

目前，国家蜂产业技术体系除依托甘肃省养蜂技术研究所设立天水综合试验站以外，还设有宁夏固原综合试验站和陕西延安综合试验站，西北地区中华蜂产业科技服务力量较为雄厚。今后，我部将积极支持国家蜂产业技术体系协助秦岭山区周边地区有关单位开展地方中华蜂遗传资源保护和地方良种培育，为农户科学养殖提供技术支持，推动科技成果应用。同时，积极帮助地方开拓中华蜂优质蜂蜜市场，提高中华蜂产业的经济效益，为打赢脱贫攻坚战发挥应有作用。

感谢您长期以来对畜牧业工作的关心和支持，希望今后继续对我部的工作予以支持。

农业农村部

2019年8月30日
