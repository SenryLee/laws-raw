# 交通运输部公告2019年第61号——交通运输部关于公路工程监理资质许可和定期检验结论的公告

## 交通运输部公告

2019年第61号

## 交通运输部关于公路工程监理资质许可和定期检验结论的公告

根据《中华人民共和国行政许可法》《公路水运工程监理企业资质管理规定》有关规定，交通运输部对近期申请公路工程监理资质许可和定期检验的企业进行了审查。现将准予许可决定和定期检验结论予以公布。

特此公告。

交通运输部

2019年8月14日
