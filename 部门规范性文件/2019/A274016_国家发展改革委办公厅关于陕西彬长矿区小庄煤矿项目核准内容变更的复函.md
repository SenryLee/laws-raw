# 国家发展改革委办公厅关于陕西彬长矿区小庄煤矿项目核准内容变更的复函

发改办能源〔2019〕139号

陕西省发展改革委：

报来《关于申请彬长矿区小庄煤矿项目核准变更的请示》（陕发改煤电〔2018〕1469号）及相关材料收悉。经委托咨询机构评估，现函复如下。

一、为加快优质产能释放，优化煤炭产业结构，同意小庄煤矿项目核准内容变更。煤矿建设规模600万吨/年，一次建成投产，投产时布置1个放顶煤综采工作面，达到600万吨/年生产能力。

二、建设方案调整后，小庄煤矿项目总投资为55.98亿元（不含矿业权费用）。其中，资本金16.79亿元，占总投资的30%，由项目单位以企业自有资金出资；资本金以外的39.19亿元，申请银行贷款。

三、项目按照600万吨/年进行生产能力登记公告，不得批小建大、超能力生产。

四、除作上述调整外，其余事项仍按我委发改能源〔2017〕507号文核准的内容执行。

国家发展改革委办公厅

2019年1月25日
