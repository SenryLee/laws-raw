# 国家体育总局办公厅关于春节期间丰富赛事活动促进体育消费的通知

## 体育总局办公厅关于春节期间丰富赛事活动　促进体育消费的通知

各省、自治区、直辖市及计划单列市体育局，新疆生产建设兵团体育局，各司、局，各直属单位，中国足协、中国篮协，各改革试点项目协会：

2019年春节将至，按照中共中央办公厅、国务院办公厅《关于做好2019年元旦春节期间有关工作的通知》要求，为进一步丰富群众节日体育文化生活，弘扬时代新风，倡导文明健康的生活方式，发挥体育惠民生、扬正气、促消费的积极作用，营造欢乐祥和、健康向上的节日气氛，现就做好春节期间体育赛事活动有关事项通知如下：

一、丰富体育赛事和活动供给

坚持以人民为中心，因地制宜，便民惠民，鼓励各地在春节期间组织具有地域特点、民族特色、面向大众、丰富多彩的体育赛事活动。借助春节期间举家团圆的契机，举办体育庙会、健身拜年、家庭运动会、冰雪嘉年华等有影响力的、群众喜闻乐见的体育赛事活动。及时发布体育赛事和活动日程，吸引群众积极参与。特别是要结合冰雪运动，加大对体育主题冬令营活动组织力度，培育青少年体育运动技能和消费习惯。

二、提升体育赛事和活动品质

充分发挥体育赛事活动多元功能，丰富体育赛事活动的爱国主义精神和体育精神内涵，弘扬和展现中华优秀传统文化。重点打造集竞技比赛、文艺表演、群众参与、娱乐消费等多功能的精品赛事活动，让广大群众可参与、能观看，增加人民群众的获得感和幸福感，更好地促进体育消费，繁荣假日经济。

三、做好体育赛事和活动的监管、指导及服务

体育赛事活动主办单位要精心策划、周密部署，切实保障赛事活动的安全有序开展。各级体育部门对地方和社会团体、企事业单位主办的大型体育商业赛事活动和大型群众性体育赛事活动，要做好监管、指导和服务，确保赛事活动的安全、顺利。

四、宣传体育赛事和活动成效

积极与各新闻媒体合作，通过电视、广播、报刊、网络等多渠道报导春节期间的体育赛事活动，弘扬主旋律，提倡多样化，传播正能量，进一步引导人民群众树立健康文明的生活方式，积极展示全国人民团结一致，昂扬向上，奋发进取的精神风貌。
