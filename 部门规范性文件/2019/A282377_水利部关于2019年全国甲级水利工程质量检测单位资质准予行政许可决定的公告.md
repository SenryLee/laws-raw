# 水利部关于2019年全国甲级水利工程质量检测单位资质准予行政许可决定的公告

水许可决〔2019〕76号

根据《水利工程质量检测管理规定》（水利部令第36号），现作出全国甲级水利工程质量检测单位资质行政许可决定：批准岩土工程类湖北鼎信工程质量检测有限公司等14个单位、混凝土工程类甘肃信创水利水电工程质量检测有限公司等7个单位、金属结构类福建省闽之星水利水电工程检测有限公司等2个单位、量测类重庆弘洋建筑工程质量检测有限公司等2个单位水利工程质量检测甲级资质延续（名单见附件1），批准金属结构类重庆弘洋建筑工程质量检测有限公司、机械电气类重庆弘洋建筑工程质量检测有限公司、量测类宝鸡金渭水利工程质量检测有限公司等2个单位水利工程质量检测资质升级为甲级（名单见附件2）。

特此公告。

水利部

2019年9月30日

附件：1.批准延续甲级水利工程质量检测资质的单位名单

2.批准升级甲级水利工程质量检测资质的单位名单
