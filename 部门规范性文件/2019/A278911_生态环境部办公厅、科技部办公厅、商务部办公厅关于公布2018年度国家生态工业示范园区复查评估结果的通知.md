# 生态环境部办公厅、科技部办公厅、商务部办公厅关于公布2018年度国家生态工业示范园区复查评估结果的通知

## 关于公布2018年度国家生态工业示范园区复查评估结果的通知

环办科财函〔2019〕587号

沈阳经济技术开发区、上海张江高科技园区、上海闵行经济技术开发区、南京高新技术产业开发区、徐州经济技术开发区、常州国家高新技术产业开发区、常熟经济技术开发区、南通经济技术开发区、宁波经济技术开发区、合肥高新技术产业开发区、青岛高新技术产业开发区：

根据《国家生态工业示范园区管理办法》和《关于开展2018年度国家生态工业示范园区复查评估的通知》（环办科技函〔2018〕50号）要求，本着公开、公平、公正的原则，国家生态工业示范园区建设协调领导小组办公室组织专家开展了2018年国家生态工业示范园区复查评估工作，现将评估结果通知如下。

一、本次复查评估的常州国家高新技术产业开发区等11家园区自命名以来，持续推进园区绿色、低碳、循环发展，生态工业体系不断优化，精细化管理水平不断提高，资源和能源利用效率持续提升，污染物排放持续下降，国家生态工业示范园区建设的示范效应显著增强。11家园区全部通过复查评估（评估结果见附件）。

二、复查评估结果为“优秀”等级的园区，持续推进国家生态工业示范园区建设成效显著。园区实施产业高端、低碳循环发展战略，通过开展企业、园区合力科技创新，引领产业转型升级。园区不断创新环境管理，健全环境风险评估与管理体系，开展了园区环保管家试点、环境保护和节能减排专项扶持等多项举措，生态工业示范园区建设指标持续优化，推动了区域绿色发展。这些成功做法值得其他园区学习借鉴。

三、复查评估中也发现个别园区存在一些问题。有的园区持续推进国家生态工业示范园区建设力度较弱，缺乏顶层设计的持续优化，生态产业链构建薄弱，部分建设指标变差甚至不达标。有的园区档案管理体系不健全，生态工业信息平台的相关信息发布与更新较少。存在上述问题的园区，应科学制定整改方案，切实完成整改任务，并将相关落实情况纳入后续年度评价报告。

请各园区认真研究专家组意见，进一步提升园区绿色发展水平，充分发挥国家生态工业示范园区的引领和示范作用。
