# 农业农村部对政协十三届全国委员会第二次会议第3523号（农业水利类298号）提案答复

## 对政协十三届全国委员会第二次会议第3523号（农业水利类298号）提案答复

杨莉珊委员：

您提出的“关于从‘三农’现状入手，谈乡村振兴战略的提案”收悉。现答复如下。

一、关于拓展农业的多功能性

习近平总书记指出，产业兴旺，是解决农村一切问题的前提。近年来，党中央、国务院高度重视乡村产业发展，着力在做大做强农业的基础上，大力发展依托种养和林特产品的加工流通业，依托农村自然和人文环境的乡村旅游,依托乡土文化和传统工艺的乡村手工业等现代新型业态，向农业的广度和深度进军，拓展农业多种功能，切实把农业产业链延伸的增值收益和就业创业机会尽量留给农民。一是强化产业发展指导。国务院印发《关于促进乡村产业发展的指导意见》，明确了促进乡村产业振兴的总体要求，提出了乡村产业发展重点任务和政策措施。农业农村部、财政部等相关部门制定了促进农产品加工业发展、休闲农业和乡村旅游发展、返乡下乡人员创新创业等政策文件，出台了一系列减免税收、金融信贷、科技支撑、用地用电等务实管用的扶持政策，为推动乡村产业发展提供政策保障。二是大力发展农产品加工业。深入推进农产品加工业提升行动，建设了15.6万座农产品初加工设施，新增初加工能力1000万吨，果蔬等农产品产后损失率从15%降至6%。2018年，规模以上农产品加工企业7.9万家、营业收入14.9万亿元，农产品加工业和农业总产值比达到2.3∶1。三是不断丰富乡村产业类型。实施休闲农业和乡村旅游精品工程，推介一批休闲农业和乡村旅游精品品牌，2018年休闲农业和乡村旅游接待游客30亿人次、营业收入超过8000亿元。大力发展农产品电子商务，农村网络销售额突破1.3万亿元，其中，农产品网络销售额达3000亿元。创新发展乡村服务业，支持开展农资供应、代耕代种、统防统治、烘干收储等生产性服务业，农村生产性服务业营业收入超过2000亿元。四是打造产业发展平台载体。支持建设了国家现代农业产业园114个、国家农业科技园32个、农产品加工园1600个，创建农村产业融合示范园148个、农业产业强镇254个，推广农业内部循环融合、产业延伸融合、功能拓展融合、新技术渗透融合、产村融合和复合型融合等多种融合模式。

下一步，我部将会同有关部门认真贯彻落实中央部署要求，大力培育植根于县域，以农业农村资源为依托，以农民为主体，以农村一二三产业融合发展为路径，地域特色鲜明、创新创业活跃、业态类型丰富、利益联结紧密的乡村产业，促进农民就地就近就业增收。

二、关于吸引培育人才资源

推进实施乡村振兴战略，人才是关键。近年来，中央有关部门注重加强顶层设计，选派优秀干部和吸引优秀人才回村任职。一是吸引优秀人才担任党组织带头人。2018年新修订的《中国共产党农村基层组织工作条例》明确规定，村党组织书记应当注意从本村致富能手、外出务工经商返乡人员、本乡本土大学毕业生、退役军人中的党员中培养选拔，目前全国54.3万名村党组织书记大专学历以上的占20.6%，致富带头人占60%。四川省从外出务工经商人员等群体中回引万余名优秀党员担任党组织书记。青海省以村“两委”换届为契机，从县乡机关事业单位选派优秀年轻干部到村任党支部书记。二是鼓励退休和退居二线老同志返乡任职。2009年，中共中央办公厅、国务院办公厅《关于加强和改进村民委员会选举工作的通知》提出，鼓励县乡机关和企业事业单位提前离岗或退休干部职工等通过法定程序参与选举村民委员会成员的竞争。一些地方市县党委组织部门选派退居二线的老同志到贫困村和党支部软弱涣散村任职。比如，山东枣庄市、陕西安康市等地专门发通知部署，湖南郴州市公开选聘退出领导岗位干部到村任职。三是加强高素质农民培养。农业农村部办公厅、教育部办公厅印发《关于做好高职扩招培养高素质农民有关工作的通知》，启动“百万高素质农民学历提升行动计划”，用实用好入学免试文化课、单独编班定制培养、农学结合分段教学的优惠政策，鼓励更多农民通过这种创新性灵活学制的全日制学习形式，获取高等教育专科学历证书。四是支持人才创新创业。2016年，国务院办公厅《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》，为农村创新创业送出了政策“大礼包”。各级农业农村部门联合有关部门实施农村创新创业促进行动，加强创业培训指导，搭建服务平台，建设了1000多个农村创新创业园区，引导人才返乡创业兴业，带动大量当地农民就地就近就业。目前，全国返乡下乡人员累计超过780万人。

下一步，中央有关部门将推动各地认真贯彻落实《中国共产党农村基层组织工作条例》，深入抓好农村致富带头人队伍建设，指导各地认真落实村干部轮训要求，提升能力素质，建立选派第一书记工作长效机制，并向乡村振兴任务重的村拓展。同时健全激励机制，加大从优秀村党组织书记中选拔乡镇领导干部、考录乡镇公务员、招聘乡镇事业编制人员力度，进一步提高村干部待遇水平，大力宣传表彰“三农”基层干部的先进典型，畅通城乡间人才要素双向流动的制度性安排，留下、吸引、储备更多高素质劳动者投身农业。

三、关于强化规划支撑

今年中央一号文件提出，强化乡村规划引领，把加强规划管理作为乡村振兴的基础性工作。一是推动出台乡村振兴战略规划。去年，中共中央、国务院印发《乡村振兴战略规划（2018—2022年）》（以下简称《规划》），明确了今后五年的思路目标和重点任务，将村庄划分为集聚提升、城郊融合、特色保护、搬迁撤并四类村庄。各地结合本地实际，均已编制出台了实施乡村振兴战略地方规划，针对重点领域和关键环节，出台了一批专项规划、重大行动计划和具体实施方案。二是建立《规划》落实部门协调推进机制。为推动《规划》各项目标任务落实落地，发展改革委、农业农村部会同有关部门建立了《规划》实施协调推进机制，中央组织部、中央宣传部等27个部门参加。通过加强部门沟通协商和联合协作，增强了相关政策衔接和工作协调，推动《规划》各项任务落实落地。同时，积极推动各省成立相应机制，层层推动《规划》任务落实。三是加快推动村庄布局和村庄规划编制。今年年初，中央农办、农业农村部、自然资源部等5部门联合印发《关于统筹推进村庄规划工作的意见》（以下简称《意见》），明确提出要加快编制村庄布局规划和村庄规划，力争到2019年底，基本明确集聚提升类、城郊融合类、特色保护类等村庄分类；到2020年底，结合国土空间规划编制在县域层面基本完成村庄布局工作。对于搬迁撤并类村庄，《意见》明确要求保持历史耐心，保障基本公共服务。

下一步，我部将会同有关部门加快推进《规划》在村域层面落实落地，指导各地以县为单位，加快编制或修编县域村庄布局规划，分类明确集聚提升、城郊融合、特色保护、搬迁撤并四类村庄分类，引导村庄依规有序发展。

感谢您对推进乡村振兴战略实施工作的关心，希望继续对我部的工作给予支持。

农业农村部

2019年8月29日
