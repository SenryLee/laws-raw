# 农业农村部对十三届全国人大二次会议第7704号建议的答复

## 对十三届全国人大二次会议第7704号建议的答复

农办议〔2019〕44号

陈春平代表：

您提出的关于支持宁夏开展主要农作物秸秆机械化还田离田综合利用的建议收悉。经商财政部，现答复如下。

一、关于水稻秸秆还田、玉米秸秆离田补贴问题

2019年，为推进秸秆还田离田和综合利用，中央财政通过农业资源及生态保护补助资金安排19.5亿元，支持全国各地开展农作物秸秆综合利用工作。鼓励各地探索建立“谁受益谁处理”“秸秆换有机肥”等机制，通过政府培育环境、政策引导，激发秸秆还田离田、加工利用等各环节市场主体活力，引导撬动社会资本和金融资本支持农作物秸秆综合利用工作，形成工作合力，探索可推广、可持续的农作物秸秆综合利用模式，建立秸秆综合利用稳定运行机制。据统计，2018年全国新增秸秆还田面积2600万亩、捡拾打捆面积3000万亩，秸秆还田、捡拾打捆面积分别达到7.69亿亩、1.18亿亩。

下一步，我们将进一步加大农作物秸秆还田离田综合利用的支持力度，不断提升农业生产技术装备水平，促进我国农业可持续发展。

二、关于秸秆生物制肥等机械补贴问题

中央财政于2004年设立农机购置补贴专项，一直将秸秆综合利用机械纳入补贴重点。为适应农业结构调整和农业绿色发展的需要，从2017年开始，对支持农业绿色发展的秸秆还田离田等机具实行敞开补贴。2018年，国家补贴购置秸秆粉碎还田机3.98万台、捡拾打捆机3.31万台，补贴资金共11.1亿元。同时，鼓励农民购买大型拖拉机、带有秸秆还田装置的联合收割机，带有旋耕灭茬、秸秆粉碎、免耕播种、镇压等装置的联合整地播种机，开展复式作业。

农业农村部、财政部印发的《2018—2020年农机购置补贴实施指导意见》中明确补贴机具种类范围为15个大类42个小类137个品目。地方特色农业发展所需机具，可列入地方各级财政安排资金的补贴范围，具体补贴机具品目和补贴标准由地方自定。关于秸秆生物制肥装备等纳入农机补贴产品范围问题，由各地按照以上文件要求，确定是否纳入农机购置补贴或地方财政安排资金的补贴范围。

今后，我们将进一步完善农机购置补贴政策，继续争取扩大补贴规模，鼓励种粮大户、农机大户、农机合作社购买和使用适用农机具，调动广大农民开展秸秆还田离田综合利用等机械化作业的积极性和主动性。

感谢您对农业机械化工作的关心，希望今后继续对我部工作给予支持。
