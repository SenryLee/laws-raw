# 司法部关于发布实施《全国民事行政法律援助服务规范》等3项行业标准的公告

本法规中关于《SFT 0058 全国民事行政法律援助服务规范》的相关规定已被《司法部关于发布实施<行政执法综合管理监督信息系统数据元和代码集>等5项行业标准的公告》自2023年11月16日起修改。

## 司法部关于发布实施《全国民事行政法律援助服务规范》等3项行业标准的公告

为规范全国司法行政信息化建设，加强对全国司法行政业务工作的指导，司法部制定了《全国民事行政法律援助服务规范（SF/T 0058-2019）》《全国仲裁工作管理信息系统技术规范（SF/T 0059-2019）》《全国人民陪审员选任管理系统技术规范（SF/T 0060-2019）》等3项标准。现予以发布，自发布之日起实施。标准实施中的问题和建议，请及时报司法部。

附件：

SFT 0058 全国民事行政法律援助服务规范

SFT 0059 全国仲裁工作管理信息系统技术规范

SFT 0060 全国人民陪审员选任管理系统技术规范
