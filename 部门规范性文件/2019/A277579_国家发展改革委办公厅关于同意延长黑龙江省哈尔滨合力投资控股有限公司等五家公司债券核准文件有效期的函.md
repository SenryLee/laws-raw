# 国家发展改革委办公厅关于同意延长黑龙江省哈尔滨合力投资控股有限公司等五家公司债券核准文件有效期的函

发改办财金〔2019〕523号

黑龙江省、浙江省、重庆市、云南省、陕西省发展改革委：

报来《关于申请延长<国家发展改革委关于黑龙江省哈尔滨合力投资控股有限公司发行公司债券核准的批复>有效期的请示》（黑发改财金〔2019〕204号）、《关于转报玉环市国有资产投资经营集团有限公司延长公司债券核准文件有效期申请的请示》（浙发改财金〔2019〕167号）、《关于转报丰都县国有资产经营投资集团有限公司延长2018年社会领域产业专项债券核准发行期限申请的请示》（渝发改财金〔2019〕477号）、《关于转报大理海东开发投资集团有限公司延长绿色债券核准有效期的请示》（云发改财金〔2019〕288号）、《关于申请延长渭南市产业投资开发集团有限公司批文有效期的请示》（陕发改财金〔2019〕433号）收悉。经研究，现函复如下。

一、同意将《国家发展改革委关于黑龙江省哈尔滨合力投资控股有限公司发行公司债券核准的批复》（发改企业债券〔2018〕72号）文件有效期延长12个月至2020年5月8日。

同意将《国家发展改革委关于浙江省玉环市国有资产投资经营集团有限公司发行公司债券核准的批复》（发改企业债券〔2018〕90号）文件有效期延长12个月至2020年5月14日。

同意将《国家发展改革委关于重庆市丰都县国有资产经营投资集团有限公司发行社会领域产业专项债券核准的批复》（发改企业债券〔2018〕113号）文件有效期延长12个月至2020年5月22日。

同意将《国家发展改革委关于云南省大理海东开发投资集团有限公司非公开发行绿色债券核准的批复》（发改企业债券〔2018〕81号）文件有效期延长12个月至2020年5月10日。

同意将《国家发展改革委关于陕西省渭南市产业投资开发集团有限公司发行公司债券核准的批复》（发改企业债券〔2018〕93号）文件有效期延长12个月至2020年5月14日。

二、请你委督促发行人按照《公司法》《证券法》《企业债券管理条例》和有关规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

三、请你委督促发行人按要求及时做好信息披露及债券资金管理，按照核准的募集资金投向合规使用债券资金，认真落实偿债保障措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅

2019年4月29日
