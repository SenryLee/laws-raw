# 国家知识产权局关于政协十三届全国委员会第二次会议第3121号（科学技术194号）提案答复的函

国知发保函字〔2019〕161号

南存辉委员：

您提出的关于防范商标在海外被恶意抢注的提案收悉。结合财政部、国家移民管理局意见，现答复如下：

在全球经济深度调整和我国发展进入新常态的大背景下，我国企业不断加快“走出去”步伐过程中遭遇的知识产权摩擦与争端也愈加复杂。就商标而言，近年来我国企业商标在海外被抢注、商标权益在海外受侵犯等情形持续增多。为了帮助我国企业商标更好地走向世界，我局与相关部门目前已开展多方面工作。

一、不断完善马德里商标注册体系

一是加大对马德里商标国际注册体系的宣传推广力度。2017年7月组织召开全国工商和市场监管部门运用马德里体系现场经验交流会，总结推广山东东营、青岛等地方典型经验。每年赴全国各地举办多场马德里商标国际注册体系推广培训，为当地企业讲授马德里国际注册知识，并利用各种平台宣传马德里体系，及时更新中国商标网的国际注册栏目，做好信息发布业务宣传。

二是积极推进商标国际注册便利化改革。2018年6月实现马德里商标国际注册申请的全程电子化，开辟了国际注册“绿色通道”。先后发布《关于简化马德里商标国际注册申请材料和手续的通知》《关于简化申请材料、优化工作流程和缩短审查周期的公告》，进一步简化材料优化流程，减轻企业负担。积极拓宽马德里国际注册受理渠道，开放京商标审查协作中心及地方窗口马德里国际商标收文权限，同时加强对收文人员培训，让申请人可以就近进行咨询及交文。据世界知识产权组织统计，2017年，我国申请人提交马德里国际注册申请4810件，同比增长59.6%，2018年我国申请人提交马德里国际注册申请6594件，同比增长37.1%，连续两年位居马德里联盟第三。

三是鼓励各地完善资助奖励政策。目前，中央财政没有直接针对专利、商标的申请维持等相关资助奖励政策，但是各地方根据实际陆续出台专利支持政策，较大程度上可以缓解中小企业知识产权申请、维持、维权援助的压力。中小企业可按当地规定的条件和程序申请并享受相应的政策待遇。

二、完善企业商标海外维权沟通协调机制

大力加强与其他国家商标主管机构的交流合作，进一步完善企业商标海外维权沟通协调机制，对有关企业海外维权提供官方协助。圆满解决“HUAWEI”在非洲知识产权组织被抢注、“镇江香醋”在韩国被抢注、“孔子学院”商标在哥斯达黎加被抢注、“恒顺”在秘鲁被抢注、大批玩具企业厂名及商标在智利被抢注等多个重要案件。

三、持续加强海外知识产权维权援助机制

一是探索建立企业商标海外维权工作机制，制定《关于建立和完善商标海外维权体系的工作方案》，在中国商标网建立海外维权信息平台，发布主要国家商标法律及我国企业典型案例，及时发布预警信息。连续两年在中国国际商标品牌节上举办中国企业商标海外维权论坛，分享典型案例，探讨研究如何更好地为我国企业在海外维护商标合法权益提供支持。多次派员赴广东、福建、山东进行海外维权调研，了解我国企业海外维权现状及面临问题，为下一步工作提出建议。

二是自2015年起建设海外知识产权信息平台（“智南针”）并推出微信公众号服务，向社会公众提供主要贸易国家和地区的知识产权法律法规、制度环境、实务指引、服务机构等基础信息。目前汇集189个国家或地区1400余部知识产权法律法规，20多个重点国家知识知识产权环境概览，近30本知识产权实务指引等信息，提供350多家海外知识产权服务机构和40余位专家名录。截至2018年底，累计1万家企业注册海外知识产权信息平台，累计访问量超过1341万次，为企业拓展海外业务提供有效的信息支持。

三是成立国家海外知识产权纠纷应对指导中心，不断完善海外知识产权纠纷反馈渠道，指导企业应对涉外纠纷。通过建设海外知识产权纠纷指导专家库和公益律师团队等帮助企业提高海外知识产权纠纷的解决效率和质量；通过建设海外知识产权纠纷数据库和数据分析机制等向“走出去”的企业提供知识产权纠纷防控和风险预警。

四、下一步工作安排

今后，我局将继续会同相关部门，加大对“走出去”企业商标等知识产权服务和支撑力度，加强对马德里商标国际注册体系的宣传推广，进一步优化工作流程，提升审查效率，不断完善知识产权海外维权援助机制，深入开展知识产权保护国际合作，持续提升中国企业的海外知识产权维权意识和能力，着力做好以下工作：

一是完善海外知识产权信息平台，更新完善并扩充海外信息范围，编制重点国家或地区的商标注册和维权指南，持续为中国企业“走出去”提供信息服务支撑。二是加强海外纠纷风险防控，通过宣传、培训、研讨交流等活动，切实提升企业海外布局、纠纷应对、主动维权的意识和能力。三是依托国家海外知识产权纠纷应对指导中心组建专家队伍和公益律师团队，切实指导企业开展国际知识产权维权，应对海外商标被抢注、被侵犯等知识产权纠纷。

衷心感谢您对知识产权工作的关注，希望继续关心知识产权事业发展，对我们的工作提出宝贵的意见建议。

国家知识产权局

2019年8月19日
