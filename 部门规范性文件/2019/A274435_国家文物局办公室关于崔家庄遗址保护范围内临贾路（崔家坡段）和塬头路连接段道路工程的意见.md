# 国家文物局办公室关于崔家庄遗址保护范围内临贾路（崔家坡段）和塬头路连接段道路工程的意见

办保函〔2019〕116号

甘肃省文物局：

你局《关于呈报临夏县临贾路（崔家坡段）和塬头路连接段道路工程涉及崔家庄遗址保护范围设计方案修改稿的请示》（甘文局发〔2019〕11号）收悉。经研究，我局暂不同意在崔家庄遗址保护范围内实施临贾路（崔家坡段）和塬头路连接段道路工程。

一、崔家庄遗址是甘青地区已知规模较大的齐家文化遗址，具有重要历史、艺术、科学价值。拟改扩建公路直接影响遗址安全和环境风貌，且前期考古勘探工作不规范、勘探结论前后矛盾，未说明所报方案选线的必要性和可行性。

二、所报方案应认真按照我局《关于在省级文物保护单位崔家庄遗址保护范围内进行临贾路（崔家坡段）和塬头路连接段道路工程项目的意见》（办保函〔2018〕941号）要求，明确文物分布范围和保存情况，说明拟建道路与各遗址点之间的位置关系，道路选线应优先避让文物保护范围。

三、请你局组织专业考古单位，在项目范围内进一步开展全面的考古工作，核实项目区域的文化堆积性质、范围等，并规范、完善考古工作报告。

四、请你局切实加强项目文本审核，指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

五、请你局督促地方人民政府，切实落实主体责任，统筹考虑文物保护与基础设施建设之间的协调发展，明确保护区划和建设控制要求，妥善处理文物保护和发展需求的关系。

专此函复。

国家文物局办公室

2019年2月19日
