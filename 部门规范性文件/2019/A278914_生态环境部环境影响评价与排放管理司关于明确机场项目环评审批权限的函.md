# 生态环境部环境影响评价与排放管理司关于明确机场项目环评审批权限的函

## 关于明确机场项目环评审批权限的函

环评函〔2019〕50号

江西省生态环境厅：

你厅《关于明确机场项目审批权限的请示》（赣环环评〔2019〕31号）收悉。经研究，答复如下。

根据我部2019年2月印发的《生态环境部审批环境影响评价文件的建设项目目录（2019年本）》（生态环境部公告 2019年第8号），运输机场项目环境影响评价文件审批权限已经下放，不属于我部审批环境影响评价文件的建设项目。

特此函复。

生态环境部环境影响评价与排放管理司

2019年6月28日
