# 国家知识产权局对十三届全国人大二次会议第1843号建议答复的函

国知发保函字〔2019〕89号

张婧婧代表：

您提出的《关于加强陶瓷企业知识产权保护，助力景德镇国家陶瓷文化传承创新试验区建设的建议》收悉，结合中编办、财政部的意见，现答复如下：

我们十分赞同您关于加强陶瓷企业知识产权保护，助力景德镇国家陶瓷文化传承创新试验区建设的建议。加强知识产权保护，对营造良好的营商环境和创新环境意义重大。近年来，党中央、国务院对知识产权保护工作高度重视，我局会同相关部门积极落实党中央国务院决策部署，推动完善法律制度，加强知识产权保护体系建设，强化执法手段，拓展维权渠道，知识产权保护工作取得一定成效。但不可否认，目前工作实践中依然存在立法协调性不够、综合管理和统一执法机制尚待健全、行政执法和司法保护衔接不畅、知识产权大保护格局尚未建立等问题，需要加以重视并予以改进。结合您的建议，具体答复如下：

一、关于建立国家级知识产权统一维权机构

我局2016年印发《关于开展知识产权快速协同保护工作的通知》（国知发管字〔2016〕92号），决定在有条件地方的优势产业集聚区，依托一批重点产业知识产权保护中心，开展集快速审查、快速确权、快速维权于一体，审查确权、行政执法、维权援助、仲裁调解、司法衔接相联动的产业知识产权快速协同保护工作。截至2019年6月，已批设知识产权保护中心24家，其中省级保护中心5家，地市级19家， 可面向各地创新主体、市场主体提供“一站式”知识产权综合服务，有效支撑重点产业发展。为进一步完善快速协同保护机制，我局将适时研究建设国家级知识产权保护中心，进一步加强全面的知识产权保护。

二、关于建立知识产权维权专项基金

目前，我局已投入大量人力、财力，通过知识产权保护中心、知识产权维权援助中心加强产业知识产权保护工作，不宜重复出资设立产业知识产权维权基金，相关社会资本可以联合设立陶瓷产业维权基金，共同应对产业知识产权纠纷，维护自身合法权益。而且，我局在全国批设的知识产权保护中心、快速维权中心均是公益性事业单位，可以为相关产业创新主体提供公益性的知识产权审查确权、行政执法、维权援助、仲裁调解、司法衔接等服务。

三、关于加大知识产权侵权惩罚力度

我局积极推动修改知识产权相关法律，完善惩罚性赔偿制度，提高侵权成本。2019年4月23日，全国人大常委会审议通过关于修改《中华人民共和国反不正当竞争法》的决定，新增惩罚性赔偿制度，将恶意侵犯商业秘密的赔偿额确定为一倍以上五倍以下，并将法院酌定赔偿的上限从三百万元提升到五百万元，同时降低举证难度。同日，全国人大常委会审议通过《中华人民共和国商标法修正案（草案）》，进一步将恶意侵犯商标专用权的赔偿额由一倍以上三倍以下提高到一倍以上五倍以下，并将法定赔偿额上限从三百万元提高到五百万元。

实行严格的专利保护制度，保护创新者合法权益、促进专利实施与应用也是《专利法》第四次修改的指导思想。2018年12月5日，《中华人民共和国专利法修正案（草案）》通过国务院常务会议审议，12月23至29日由第十三届全国人大常委会第七次会议进行第一次审议。该草案对故意侵犯专利权的行为规定了一到五倍的惩罚性赔偿，并将法定赔偿额从一万元以上一百万元以下提高到十万元以上五百万元以下。同时，还增加了举证妨碍相关内容，规定为确定赔偿数额，在权利人已经尽力举证，而侵权人不提供或者虚假提供由其掌握的相关证据的情况下，法院可以参考权利人的主张和提供的证据判定赔偿额，以利于查明损害赔偿的事实，保护权利人合法权益。全国人大常委会已于2019年1月3日至2月3日将草案面向社会公开征求意见。后续我局将全力配合审议工作。

此外，2018年12月，包括我局在内的38个部委和单位联合签署《关于对知识产权（专利）领域严重失信主体开展联合惩戒的合作备忘录》，将执法于重复专利侵权行为、不依法执行处罚的行为定性为知识产权（专利）领域严重失信行为，并将被实施联合惩戒措施。今后，我局将努力加大侵权惩罚力度，提高侵权违法成本，加强知识产权保护，切实维护市场竞争秩序。

四、关于跨区域陶瓷知识产权维权联盟

2015年4月，我局印发《产业知识产权联盟建设指南》，鼓励企业以知识产权为纽带成立产业知识产权联盟。目前已有105家知识产权联盟正式备案，其中包括淄博高新区先进陶瓷产业知识产权联盟。联盟的职责主要包括建立产业知识产权风险应对机制，即通过主动采取知识产权联合布局、防御性知识产权收购、知识产权许可谈判和启动专利权无效程序等措施，帮助成员单位共同有效应对可能发生的产业重大知识产权纠纷与争端。下一步，我局将按照民政部门对联盟类组织的管理要求，进一步加强产业知识产权联盟监督管理和业务指导工作，促进产业知识产权联盟有序健康发展。

五、关于加强行业自治与自律

行业协会作为会员企业共同利益的代表，职责之一就是提供信息服务，包括行业专利、商标信息、技术创新和产业发展趋势信息等等。行业协会对本行业本领域情况掌握的更全面、更深入、更专业，在知识产权保护工作中，行业协会可发挥其优势，协助执法机关开展相关工作，有针对性地提出合理的意见建议，有利于执法机关做出正确判断，提高执法效率。我局将以知识产权保护中心、快速维权中心、维权援助中心为依托和支撑，加强与各产业、行业协会组织的合作，强化对企业创新的引导与指导，促进全行业自主创新的积极性与主动性，切实加强知识产权保护力度，鼓励创新、打击知识产权侵权假冒行为，构建良好的产业创业环境。

衷心感谢您对知识产权工作的关心，希望继续关注知识产权事业发展，对我们的工作提出宝贵的意见建议。

国家知识产权局

2019年6月27日
