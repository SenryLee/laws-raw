# 国家文物局办公室关于万荣后土庙保护范围及建设控制地带内环境整治项目的意见

办保函〔2019〕95号

山西省文物局：

你局《关于审批万荣后土庙环境整治工程设计方案的请示》（晋文物〔2018〕114号）收悉。经研究，我局暂不同意万荣后土庙保护范围及建设控制地带内环境整治项目。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步补充已按我局批复意见修改的《万荣后土庙文物保护规划》相关内容，尤其是建设控制要求、环境整治措施和展示利用规划等条文和图纸，作为所报方案的基本依据。

（二）拟建庙前广场和“后土文化长廊”必要性论证不足，对万荣后土庙所在的历史环境将造成较大程度改变，应予调整。

（三）补充论证在后土庙西侧、西南侧新建大量较大尺度安置民居的合理性，客观评估其对“后土庙——黄河”景观视线关联的影响。

（四）优化完善后土庙东侧区域的改造设计。配套管理展陈用房应尽量使用现存非文物建筑，新增配套管理用房面积过大，必要性不足，应予调整；现存非文物建筑整治改造可不限于仿古样式，建议适当保留不同时代的建筑风格特征。

（五）古驿道边坡防护加固不宜使用青砖，建议外观处理与周边黄土基本一致。

（六）拟建后土祭坛依据不足，且位于省级文物保护单位“汾阴古城址及墓地”保护范围，应进一步论证其选址，调整祭坛设计方案，简要标识祭坛空间及历史功能即可。

（七）补充论证对区域内其他村落民居统一实施仿古立面改造的必要性和合理性。

（八）补充项目总平面图以及消防、给排水、电力管线布局总图。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年2月14日
