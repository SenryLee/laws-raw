# 国家能源局对十三届全国人大二次会议第1042号建议的答复复文摘要

## 对十三届全国人大二次会议第1042号建议的答复复文摘要

你们提出的支持江西省补齐电力建设短板的建议收悉，现答复如下。

我局高度重视江西省的电力供应保障工作，支持江西省按需有序推动电力建设补短板工作。

一、关于新余电厂二期项目规划建设

2018年底，江西省报来《江西省平价上网光伏发电和清洁煤电协同发展试点方案》（简称《方案》）后，我局即按程序委托国家电力规划研究中心对《方案》进行了评估。国家电力规划研究中心已报来评估报告。

下一步，待相关政策文件正式出台后，我局将按照文件要求，结合国家电力规划研究中心结论等，指导江西省进一步修改完善《方案》，推动新余电厂二期项目规划建设。

二、关于信丰电厂核准

根据我局今年3月发布的2022年煤电规划建设风险预警，江西省风险预警等级为绿色，可按需有序核准、开工建设省内自用煤电项目。据此，江西省发展改革委已核准了信丰电厂。

三、关于在“十四五”电力规划中支持江西省电力项目

我们支持江西省通过充分利用当地新能源资源发电以及外来电、优化电网网架结构和运行方式、发挥现有电源项目作用、并采取需求侧管理等措施，减少对新增煤电装机的需求。对于采取上述措施后仍不能满足需求的，我们将结合电力“十四五”规划工作，统筹研究江西省内自用煤电项目的规划建设。

感谢你们对国家能源工作的关心和理解，希望今后能得到你们更多的支持和指导。

国家能源局

2019年9月23日
