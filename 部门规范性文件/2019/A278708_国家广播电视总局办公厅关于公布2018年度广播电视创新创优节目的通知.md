# 国家广播电视总局办公厅关于公布2018年度广播电视创新创优节目的通知

## 总局办公厅关于公布2018年度广播电视创新创优节目的通知

广电办发〔2019〕161号

各省、自治区、直辖市广播电视局，新疆生产建设兵团文化体育广电和旅游局，中央广播电视总台办公厅：

2018年，全国广播电视机构深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，坚定文化自信，坚持以人民为中心的创作导向，坚持为人民服务、为社会主义服务，坚持“小成本、大情怀、正能量”，制作播出了一批传承中华优秀传统文化、弘扬社会主义核心价值观、贴近时代、群众喜爱的优秀节目，受到广泛好评。为了发挥优秀广播电视节目的示范引领作用，经评议，确定中央广播电视总台《见证》、四川广播电视台《撤离》等6个广播节目，中央广播电视总台《经典咏流传》、北京广播电视台《向前一步》等20个电视节目为“2018年度广播电视创新创优节目”，并给予每个广播节目15万元、每个电视节目20万元的资金扶持。

各广播电视机构要认真学习这些优秀节目的好做法、好经验，坚持讲品位、讲格调、讲责任，不断增强“脚力、眼力、脑力、笔力”，创作生产更多思想精深、艺术精湛、制作精良的好节目，为庆祝新中国成立70周年营造良好氛围。

扶持资金将由总局下拨至各省广播电视局和中央广播电视总台，各省局负责将扶持资金分发至所属相关广播电视机构。请各省局和中央广播电视总台于6月28日前，将收款收据和账户信息（收款单位、开户银行、账号）用邮政特快专递（EMS）邮寄至总局宣传司（地址：北京市西城区复兴门外大街2号，邮政编码：100866）。

附件：2018年度广播电视创新创优节目名单

国家广播电视总局办公厅

2019年6月20日
