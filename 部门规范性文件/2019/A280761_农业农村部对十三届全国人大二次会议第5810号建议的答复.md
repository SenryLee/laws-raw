# 农业农村部对十三届全国人大二次会议第5810号建议的答复

## 对十三届全国人大二次会议第5810号建议的答复

农办议〔2019〕288号

马传先代表：

您提出的“关于破解‘品牌、人才’建设瓶颈，提升乡村产业振兴新动能的建议”收悉。经商财政部，现答复如下。

党中央、国务院高度重视农业品牌建设。习近平总书记指出“要大力培育食品品牌，用品牌保证人们对产品质量的信心。”2018年中央1号文件要求“深入推进农业品牌化”“培育农产品品牌”“打造区域公用品牌”。当前，质量兴农、品牌强农已经成为转变农业发展方式、加快脱贫攻坚、提升农业竞争力和实现乡村振兴的战略选择。

一、关于在提升品牌影响力上多用力，解决农产品优质优价问题

近年来，我部积极推动农业品牌建设，多措并举，取得积极成效。一是强化顶层设计。我部将2017年确定为“农业品牌推进年”，召开了全国农业品牌推进大会，部署了新时期农业品牌工作重点，为农业品牌建设指明了方向。2018年深入实施农业品牌提升行动，全面推进农业品牌建设。针对区域公用品牌建设、品牌营销服务体系建设等方面开展了基础性研究，并以水果、大米、茶叶、水产品为重点加强品牌建设。二是夯实品牌基础。经过多年发展，我国绿色、有机农产品和地理标志农产品工作取得了明显成效，规模总量稳步增长，产品质量稳定可靠，品牌影响力日益增强。截至2018年底，全国绿色食品、有机农产品、农产品地理标志产品获证单位超过1.6万家，产品总数达3.8万余个，并通过绿色食品宣传月、中国绿色食品博览会和中国国际有机食品博览会等活动，培育了一批优质绿色农产品知名品牌。三是创新营销推介。充分利用中国国际农产品交易会、中国国际茶叶博览会（以下简称“茶博会”）等农业展会和产销对接活动，以农产品区域公用品牌为重点，创新开展了“省部长推介品牌农产品专场”、“家乡的味道—我为品牌农产品代言”、“乡人乡味—全国品牌农产品推介活动”等全国性农业品牌专场推介，举办了首届中国国际品牌农业发展高峰论坛等10余场活动，精彩展示了我国农业品牌的建设成果。第二届、第三届茶博会分别举办了76场、82场品牌推荐主题活动。2017年推选了中国十大茶叶区域公用品牌、2017百强农产品区域公用品牌等，提升了中国农业品牌知名度和影响力。四是加大宣传推广。组织各类媒体对农业品牌进行宣传报道。2015—2016年，连续两年开展百个合作社百个农产品品牌公益宣传活动。2018年，在农民日报、农产品市场周刊、农业影视频道等传统媒体，在中国农业农村市场信息微信公众号等新媒体上集中开展农业品牌宣传推介，编印《中国特色农产品精萃》口袋书，涵盖600多种品牌农产品，2019年出版《百强品牌故事》，生动讲述农业品牌故事。

下一步，我部将继续推动农业品牌建设，创新形式、拓展平台，利用线上线下资源、国内国际市场，重点打造一批“中国第一、世界有名”的农业品牌。

二、关于在乡村人才队伍建设上要有新举措

我部和财政部等部门高度重视农民教育培训和涉农人才培养工作，积极推动涉农教育教学改革，创新涉农人才培养模式，以此作为实施乡村振兴战略的基础性长期性工程，为推进农业农村现代化提供了有力人才支撑。一是健全完善教育培训体系。多年来，我部通过发挥各级农广校的主体支撑作用，凝聚了农业院校、科研院所、农民合作社、农业企业、农业园区等多种力量，推动形成了党委政府主导，农业农村部门牵头、公益性培训机构为主体、市场力量和多方资源共同参与的农民教育培训体系。2014年，我部联合财政部以提高生产经营能力和专业技能为目标，重点面向种养大户、家庭农场、农民合作社、农业社会化服务组织等新型经营主体开展全产业链培训，促进农民创业兴业。截至目前，中央财政累计安排90.9亿元支持农民教育培训工作。其中，2018年、2019年每年达到20亿元，每年约100万农民受益。二是创新培养模式。2018年，我部组织开展了全国职业院校技能大赛，对农业职业院校推进校企合作、产教融合、深化教育教学改革起到了良好的示范带动作用。2018年，我部联合教育部、国家林业和草原局印发《关于加强农科教结合实施卓越农林人才教育培养计划2.0的意见》（教高〔2018〕5号），实施“卓越农林人才教育培养计划2.0”，吸引优质生源报考涉农专业，培养复合应用型农林人才。2019年，《农业农村部办公厅关于做好2019年农民教育培训工作的通知》（农办科〔2019〕26号）提出，推进职业培训与职业教育衔接贯通培养，实行农学结合、弹性学制等培养模式，培养具有中高等学历的高素质农民。同时多年来，坚持执行涉农中职专业学生免学费政策，大力培养高技能人才。三是大力推进农民学历提升。2018年，我部组织修订了《中等职业学校专业目录》，规范引领农业中职学校专业建设，增强学生的职业适应能力。2019年，我部和教育部等联合印发《高职扩招专项工作实施方案》（教职成〔2019〕12号），面向退役军人、下岗失业人员、农民工等群体开展高职扩招专项工作。四是加强农业品牌电商等人才队伍建设。指导农业农村部管理干部学院，在广西百色、上海、贵州都匀等地围绕农产品市场营销、农业品牌营销与推广、区域公用品牌创建与培育等，组织开展农业品牌专题培训，提升各级农业农村部门品牌建设能力。

下一步，我部等部门将聚焦乡村振兴人才需求，统筹利用各类教育培训资源，加快构建“专门机构+多方资源+市场主体”的多元化培育体系，鼓励农民参加职业技能鉴定，推进职业培训与职业教育衔接贯通，就地就近定向培养具有中高等学历的高素质农民，助推乡村振兴战略实施。

三、关于创新涉农项目工作运行机制

近年来，我部积极推进涉农资金统筹整合，充分发挥财政资金的引导和杠杆作用，拓宽融资渠道，采用政府购买服务、担保贴息、以奖代补等措施，带动金融和社会资本投向农业农村。经国务院批准，财政部会同我部于2015年启动农业“三项补贴”改革，推动全国农业信贷担保体系建设。目前，全国农担体系政策框架已经基本搭建，农担惠农政策目标逐步实现，截至2018年底，33个省级农担公司累计担保金额1144.2亿元，担保项目32万个。将农业保险作为支持农业发展的重要手段，不断扩大农业保险覆盖面、增加保险品种、提高风险保障水平，开展了农业大灾保险试点、三大粮食作物完全成本和收入保险试点，将三大粮食作物制种保险纳入中央财政补贴范围，满足新型农业经营主体多层次高保障的农业保险需求。同时，综合采用直接补贴、政府购买服务、定向委托、以奖代补、税收优惠等方式，增强新型农业经营主体生产经营能力，进一步提升新型经营主体生产积极性。

下一步，我部将继续强化财政支农资金管理，深入实行“大专项+任务清单”管理方式，强化预算绩效管理，进一步提升财政支农项目实效。

四、关于探索建立支持品牌农产品提升计划

根据《农业农村部关于加快推进品牌强农的意见》（农市发〔2018〕3号），我部坚持市场引领、政府主导、企业主体、多元参与的原则，以中国农业品牌目录制度建设为抓手，强化品牌标准体系和制度建设，指导各地加强农业品牌创建，塑强一批在全国乃至世界影响力大、竞争力强、文化底蕴深厚的国家级农业品牌。一是加快推动中国农业品牌目录制度建设工作。指导中国农产品市场协会，开展中国农业品牌目录制度建设，2019年建立完成中国农产品区域公用品牌子目录，对进入目录的品牌实行动态管理。二是开展评价标准和制度体系建设。制定并完善品牌培育、发展和保护的相关标准体系和制度规范，建立科学评估机制，推动农业品牌规范有序发展。三是创新品牌营销推介。讲好中国农业品牌故事，充分利用农业展会、产销对接、电子商务等平台和传播渠道，开展宣传推介，增强农业品牌知名度、美誉度和影响力。以区域公用品牌为重点，创新开展全国性农业品牌专场推介。四是加强农业品牌培训。加强农业品牌人才队伍建设，强化品牌建设、电商服务、市场营销等方面的专业培训，强化经验交流，推进协同合作，进一步提升农业品牌建设能力和水平。

感谢您对“三农”工作的关心，希望今后继续支持我部工作。
