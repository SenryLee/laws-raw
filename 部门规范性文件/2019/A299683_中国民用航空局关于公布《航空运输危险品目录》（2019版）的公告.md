# 中国民用航空局关于公布《航空运输危险品目录》（2019版）的公告

## 关于公布《航空运输危险品目录》（2019版）的公告

依据《中华人民共和国民用航空法》第一百零一条“危险品品名由国务院民用航空主管部门规定并公布”的规定，在以往发布的《航空运输危险品目录》基础上，按照国际民航组织的相关文件要求，民航局制定了《航空运输危险品目录》（2019版），现予公布。

该目录自2019年1月3日起施行，民航局2016年12月30日发布的《关于公布航空运输危险品目录2017版的公告》同时废止。

民航局

2019年1月3日
