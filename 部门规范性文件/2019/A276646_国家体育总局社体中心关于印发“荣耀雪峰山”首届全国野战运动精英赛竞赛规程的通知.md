# 国家体育总局社体中心关于印发“荣耀雪峰山”首届全国野战运动精英赛竞赛规程的通知

## 体育总局社体中心关于印发“荣耀雪峰山”首届全国野战运动精英赛竞赛规程的通知

社体字〔2019〕194号

各有关单位：

为贯彻党的十九大精神和习近平主席关于“青年强中国强，体育强中国强”的讲话精神，落实《中华人民共和国国防教育法》和《“健康中国2030”规划纲要》，提高全民身体素质，增强全民国防意识，积极发挥野战运动项目作用，我中心决定于5月25日至26日在湖南省怀化市举办“荣耀雪峰山”首届全国野战运动精英赛。

现将竞赛规程印发给你们，请按要求积极做好组队参赛工作。

特此通知。

附件：竞赛规程

体育总局社体中心
