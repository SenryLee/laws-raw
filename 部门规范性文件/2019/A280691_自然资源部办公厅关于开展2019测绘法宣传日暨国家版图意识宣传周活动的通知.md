# 自然资源部办公厅关于开展2019测绘法宣传日暨国家版图意识宣传周活动的通知

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局，有关社会团体：

2019年8月29日是第16个全国测绘法宣传日，自然资源部将组织开展全国测绘法宣传日暨国家版图意识宣传周活动。为做好宣传周各项工作，现将有关事项通知如下。

一、活动主题

规范使用地图 一点都不能错

二、活动时间

2019年8月29日至9月5日，主场活动时间为8月29日上午。

三、活动安排

（一）制播公益宣传片

以地图绘制完成过程为主线制作国家版图意识公益宣传片，向社会传达国家版图必须规范完整、一点都不能错的理念。公益宣传片将在部门户网站、部官方微信和微博发布，请各单位关注并积极转发。

（二）制作公益宣传电子海报

部宣教中心将围绕宣传周活动主题，设计制作宣传海报，电子版将在部门户网站发布，请各单位积极下载使用。

（三）主场活动

今年的主场活动设在四川省成都市。内容主要包括：

1.播放国家版图意识公益宣传片；

2.讲述祖国版图的故事；

3.讲述孩子眼中的中国地图（第四届少儿手绘地图大赛部分获奖作品推介）；

4.颁发“国家版图意识宣传大使”聘书；

5.举行版图意识“进校园、进媒体、进社区”赠书仪式；

6.“2019版标准地图”上线；

7.主题展览展示。

（四）系列活动

1.组织国家版图意识“进校园”活动。组织开展“开学第一课”活动，邀请审图和制图专家、“国家版图意识宣传大使”走进北京市第四中学、都江堰中小学，为中小学生讲一堂“国家版图意识教育”课。

2.推出手机H5互动游戏。将国家版图知识融入游戏，与央视、腾讯公司合作推出《我是小小升旗手》手机H5互动游戏，在 9月1日央视《开学第一课》中推出。

3.举办科普基地公众开放日活动。中国测绘科技馆等科普基地在宣传周期间举办公众开放日活动，面向社会公众开展科普宣传。

（五）各地活动

1.各单位要积极联合当地教育部门，举办国家版图意识“进校园、进媒体、进社区”活动，通过“开学第一课”等形式请地图专家为中小学生上一堂国家版图知识课。

2.各单位要结合本地区实际，联合有关单位和社会团体，根据各自工作特点，积极组织开展国家版图知识竞赛、知识讲座等形式多样的宣传活动，各地测绘科普基地及相关展览场馆要积极举办公众开放日活动。

四、工作要求

各单位要进一步加强与各类新闻媒体的合作，充分发挥新媒体作用，积极创新宣传形式和内容，进一步提升社会公众尤其是中小学生的国家版图意识。各项宣传活动要严格遵守中央八项规定精神，力戒形式主义、官僚主义，厉行勤俭节约，坚决杜绝铺张浪费。

各省级自然资源主管部门要及时总结整理本地区宣传活动的照片、视频、文字及其他资料，并搜集本地区主要媒体对活动的宣传报道，于9月20日前统一以电子邮件形式反馈至自然资源部宣教中心。
