# 教育部办公厅关于开展2019年全国青少年校园网球特色学校遴选工作的通知

教体艺厅函〔2019〕20号

上海市、江苏省、江西省、山东省、河南省、广东省、重庆市、四川省、云南省教育厅（教委）：

为深入贯彻落实全国教育大会精神和《国务院办公厅关于强化学校体育促进学生身心健康全面发展的意见》（国办发〔2016〕27号）部署，推进学校体育综合改革，大力提升青少年校园网球教学、课外活动、师资培养培训、训练竞赛等质量与水平，推动校园网球项目发展，决定在前期校园网球试点工作的基础上，组织开展2019年全国青少年校园网球特色学校（以下简称特色学校）遴选工作。现将有关事项通知如下。

一、工作目标

通过遴选特色学校，进一步推动校园网球运动普及，帮助学生在体育锻炼中享受乐趣、增强体质、健全人格、锤炼意志。到2021年，全国青少年校园网球项目扎实推进，网球运动基本技能和体质健康水平明显提升，学生体育锻炼习惯基本养成，规则意识、合作精神和意志品质显著增强。

二、遴选内容与范围

（一）内容。进行校园网球场地建设与改造、体育教师网球授课技能培训，开展班级、年级、校际间网球训练与竞赛。

（二）范围。面向试点省（市）中小学遴选特色学校，每个试点省（市）不超过100所。

三、申报条件与遴选程序

（一）申报条件。凡符合《全国青少年校园网球特色学校基本标准（试行）》（见附件1）条件的全日制普通中小学均可申报。

（二）遴选程序。特色学校遴选程序由学校自主申报、教育行政部门逐级审核推荐、教育部综合认定组成。

1.学校自主申报。申报学校填写《全国青少年校园网球特色学校申报表》（见附件2），并将申请表和相应支撑材料报上一级教育行政部门审核。

2.审核推荐。试点省（市）教育行政部门根据《全国青少年校园网球特色学校基本标准（试行）》，组织专家审核本地学校申请材料，择优向上级教育行政部门推荐。试点省（市）省级教育行政部门要在向社会公示审核结果的基础上，填写《全国青少年校园网球特色学校申报汇总表》（见附件3）向教育部推荐。

3.综合认定。教育部在各地审核推荐的基础上，委托全国学校体育教育教学联盟（网球项目）牵头单位上海体育学院组织专家进行复核，经公示无异议后，发文公布2019年全国青少年校园网球特色学校名单。

四、有关要求

1.申报学校要严格按照本通知要求，认真准备申报材料。申报材料要真实可靠，有案可查。对于申报材料弄虚作假的学校，实行“一票否决”。

2.试点省（市）各级教育行政部门要高度重视，认真组织，严格把关，确保把有条件、有基础、有意愿的学校遴选出来作为特色学校。

3.教育部将在特色学校遴选的基础上，适时开展特色学校专项调研、师资培训和校园网球竞赛活动。

4.试点省（市）要加强组织领导，明确责任人，落实相应的政策、制度、资金等保障条件，做好本地特色学校遴选的组织协调、指导、监督和检查工作。有关试点工作进展情况请及时报告教育部体育卫生与艺术教育司。

5.请各试点省（市）省级教育行政部门于2019年5月31日前将申报表、申报汇总表电子版和申报汇总表加盖公章的原件报送至教育部体育卫生与艺术教育司体育与卫生教育处，北京市西城区西单大木仓胡同35号，邮编：100816。
