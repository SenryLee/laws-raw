# 农业农村部对十三届全国人大二次会议第3852号建议的答复

## 对十三届全国人大二次会议第3852号建议的答复

农办议〔2019〕232号

郑连生等11名代表：

你们提出的关于支持忻州创建“中国杂粮产地交易市场”的建议收悉，经商财政部、粮食和物资储备局，现答复如下。

农产品产地市场是我国现代农业产业体系和农产品市场体系的重要组成部分，是在农业市场化改革不断深入和农产品专业化、区域化、规模化生产不断发展基础上兴起的。经过多年的建设和发展，我国已初步形成专业性与综合性相结合，产地、集散地与销地相衔接的农产品批发市场体系。目前，我国农产品批发市场已近4500家，其中产地市场约占70%，在推进农业供给侧结构性改革、促进农产品市场流通、保持农民收入稳定增长等方面，发挥了重要作用。

一、关于忻州市杂粮产地市场交易中心纳入全国性农产品产地市场建设项目

我部高度重视农产品产地市场体系建设，2011年与陕西省人民政府共同启动了首个全国性农产品产地市场建设，2015年印发了《全国农产品产地市场发展纲要》，并与发展改革委、商务部、交通运输部等部委联合印发了10余个文件推动完善农产品产地市场体系。截至目前，我部已启动建设了洛川苹果、牡丹江木耳、舟山水产、赣南脐橙、重庆生猪、斗南花卉、眉县猕猴桃、荆州水产、定西马铃薯等13个全国性农产品产地市场，推动集货、储藏、商品化处理等基础设施建设，辐射带动周边的产业发展。总的看，全国性农产品产地市场建设得到了有关省市人民政府的高度重视，市场建设取得了积极进展，部分市场发挥了全国性农产品产地市场的价格形成中心、产业信息中心、物流集散中心、科技交流中心、会展贸易中心“五大功能”，在带动相关产业发展、推动品牌建设等方面发挥了积极作用。

山西杂粮生产历史悠久、品种丰富、品质优良，素有“杂粮王国”之称。近年来，山西省委、省政府认真贯彻落实党中央、国务院决策部署，紧紧围绕“打好特色优势牌，走好绿色生态路”的要求，立足资源禀赋，以推进农业供给侧结构性改革为主线，以农业增效和农民增收为目标，大力实施杂粮产业振兴工程，取得了明显成效。山西忻州市地处华北黄土高原东缘，四季分明，非常适合杂粮生产，是山西杂粮的主产地和核心区，杂粮生产已形成比较稳定的优势区域和生产基地，培育了一批优质特色杂粮品种，集成推广了一批绿色高效技术，发展了一批加工企业及合作社。目前，忻州市杂粮种植面积已达350万亩，总产量达到12亿斤，获得杂粮类中国“地理标志农产品”认证13个，获得“三品”认证398个，全市有杂粮类合作社1550余家、购销实体80余家、加工企业110余家，各类杂粮加工精装产品800余个，杂粮商品率达到70%以上，销售量达到40万吨，销售额达到25亿元。忻州建立杂粮产地交易中心，对于扩大杂粮市场交易规模，推进产品走出本省、走向全国具有重要作用，有利于提升当地乃至全省优质杂粮的市场影响力。

2018年1月，山西省人民政府发函商请我部在忻州共同创建全国杂粮产地交易市场。我部高度重视，认真研究，组织专家先后2次赴忻州调研，评估建设全国性杂粮产地市场条件。经过调研分析，专家组认为，忻州市杂粮产业发展基础较好、体系较完整，品牌效益明显，市场功能较完善，山西作为全国性杂粮产地市场建设主体，具备建设全国性杂粮市场的物流经验，市场建设地点符合相关技术标准和设计规范，建设规模适度，功能较为齐全，信息流物流安排合理，具备了创建全国性农产品产地市场的一定条件。但专家组也指出，根据《全国农产品产地市场发展纲要》，全国性农产品产地市场是农产品产业体系的“航空母舰”和引领国内产业发展的龙头，重点是打造两个平台，一是国家级产销平台，重点建设价格形成、产业信息服务、物流集散、科技交流和会展贸易中心；二是国家级品牌培育平台，按照“定位、塑造、宣传、监管、保护”思路，提升农产品市场影响力和竞争力，打造区域公用品牌。忻州市杂粮产地交易中心尚未建成，与全国性农产品产地市场所应具备的功能还存在差距，建议进一步加强杂粮产业发展的顶层设计，明确全国性杂粮市场建设内容和实现目标，统筹规划发展路径，按照全国性市场“五大中心、两大平台”要求，提高建设标准，加快建设步伐，待时机成熟时考虑纳入全国性农产品产地市场建设。

下一步，我部将加强对忻州市杂粮产地市场交易中心建设工作的指导，立足区域资源优势和区位优势，按照全国性农产品产地市场建设标准，推动忻州市加大对杂粮产业发展的支持力度，完善杂粮市场流通体系建设，做强做亮杂粮品牌，提升忻州在杂粮产业价格形成、信息服务、科技交流、物流集散和会展贸易等方面作用，为创建全国性杂粮产地市场奠定坚实基础。

二、关于忻州市杂粮产地交易中心纳入“优质粮食工程”项目及国家级粮食交易中心体系

2005年起，中央财政出台产粮大县奖励政策，并不断加大奖励力度，完善奖励政策，已形成包括常规产粮大县、超级产粮大县、“优质粮食工程”等内容的综合奖励政策体系。2019年，中央财政拨付山西省产粮大县奖励资金5.25亿元，将忻州市忻府区、原平市等县（市、区）纳入常规产粮大县奖励范围，其中忻府区获得资金1433万元，原平市获得奖励资金1556万元，资金可统筹用于本地杂粮产业发展。 2017—2019年，中央财政累计拨付山西省“优质粮食工程”奖励资金3.29亿元。忻州市已纳入山西省“中国好粮油”示范县，建议将“忻州市杂粮产地交易中心”建设与“中国好粮油”示范县建设相结合，放大实施成效。

下一步，我部将支持忻州市杂粮产地交易中心纳入国家粮食交易中心体系，推动忻州市成为具有一定规模和影响的全国杂粮交易中心、集散中心、仓储物流中心，在培育杂粮特色品牌、优质杂粮示范区、粮食产销协作，以及杂粮产地市场建设、技术研发、人才培养等方面，予以大力扶持，全面支持山西省粮食产业高质量发展。

感谢你们对“三农”工作的关心，希望今后继续给予我部工作支持。

农业农村部

2019年8月1日
