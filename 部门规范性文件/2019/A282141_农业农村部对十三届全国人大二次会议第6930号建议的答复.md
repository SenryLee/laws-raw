# 农业农村部对十三届全国人大二次会议第6930号建议的答复

## 对十三届全国人大二次会议第6930号建议的答复

农办议〔2019〕196号

何敏代表：

您提出的关于落实央企及民营企业对口支援川陕革命老区（核心区）建设的建议收悉。现就涉及我部职能的部分答复如下。

我部高度重视革命老区脱贫攻坚工作，坚持把产业扶贫作为支持革命老区脱贫增收、助力乡村振兴战略实施的根本性长效措施，积极发挥行业优势，突出产业提升、产销对接、龙头带动、人才培养、技术服务和机制创新，不断强化政策支持和工作指导，切实帮助贫困革命老区加快发展特色产业，取得了积极成效。

一、关于拓宽农产品加工销售渠道

在龙头企业引进培育方面，我部近年来积极支持贫困地区培育农业企业、农民合作社等新型经营主体，并在具体工作中对巴中市等革命老区进行了倾斜。今年以来，在认定第六批农业产业化国家重点龙头企业时明确向脱贫任务重的省（区、市）倾斜，并优先支持贫困地区推荐的龙头企业；农业产业强镇示范项目也明确优先支持有条件的贫困地区。目前，已确定支持巴中市建设农业产业强镇项目，并将巴中市南江县现代农业产业园纳入了国家现代农业产业园创建管理体系，支持相关市县以园区为载体，引进培育龙头企业，做优做强特色产业，促进一二三产业融合发展。在帮助贫困地区拓展市场方面，我部已连续两年制定贫困地区农产品产销对接实施方案，每年组织多场贫困地区农产品产销对接活动，帮助贫困地区生产经营主体与批发市场、大型超市、电商等建立稳定购销关系，促进产品卖得出、卖得好。2018年，连续举办7场产销对接活动，全国四分之三以上贫困县参加了对接活动。今年计划举办10场以上，力争覆盖所有的深度贫困县和革命老区县。与此同时，还积极通过农交会、茶博会等各类展会，专门设立扶贫展区，帮助贫困地区宣传推介特色扶贫产品；开通运行贫困产区农产品产销对接公益服务平台，发布贫困地区农产品供求信息，引导贫困地区特色农产品销售。此外，还与发展改革委、国务院扶贫办等部门一道，印发了《“互联网+”现代农业三年行动实施方案》《关于促进电商精准扶贫的指导意见》，积极推进贫困地区农业农村电子商务发展。

下一步，我部将进一步聚焦川陕革命老区等深度贫困地区和集中连片贫困地区，指导地方加强龙头企业培育，组织当地带贫主体参与系列产销对接活动和有关展会，进一步提升农产品加工营销能力；开展川陕革命老区优势特色农产品摸底调查，及时发布农产品价格和供求信息，促进信息对接；进一步完善产地市场、推进“互联网+”、提升初级农产品产销对接公益服务平台，不断健全有形市场与无形市场并重的农产品流通体系，不断提升川陕革命老区茶叶、核桃、芦笋、银耳、黄羊等特色产业发展的质量和效益。

二、关于培育发展道地中药材产业

近年来，我部紧紧围绕农业供给侧结构性改革主线，坚持质量兴农、绿色兴农，把中药材发展纳入农业结构调整之中，统筹谋划，强化指导，有序推进，努力提升中药材质量，积极引导各地推进中药材规模化种植和标准化生产。按照《中医药发展战略规划纲要（2016—2030年）》《全国农业现代化规划（2016—2020年）》要求，2018年12月，我部会同中医药局、药监局等单位，制定印发了《全国道地药材生产基地建设规划（2018—2025年）》，对扶持一批中药材种植大户、农民合作社和龙头企业，培育新型社会化服务主体，建设标准化生产基地，加快优良品种选育，推广绿色生产技术，加强地理标志管理和品牌创建，推进绿色食品、有机农产品认证等工作进行了系统部署安排，其中明确要加大对贫困地区中药材产业发展的指导和支持力度。

下一步，我部将积极通过贫困地区龙头企业引进培育、产销对接、技术服务等帮扶举措，依托现代农业产业园等平台，帮助巴中市加快推进中药材产业基地建设、新产品研发和品牌培育，构建全程可追溯体系，提升中药材特色产业发展质量和水平，进一步发挥产业带贫增收能力，促进产业不断做大做强。

感谢您对农业农村工作的关心和重视，希望今后继续对我部工作予以支持。
