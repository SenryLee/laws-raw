# 农业农村部关于政协十三届全国委员会第二次会议第1774号（农业水利167号）提案答复的函

## 关于政协十三届全国委员会第二次会议第1774号（农业水利167号）提案答复的函

柴强委员：

您提出的关于对绿色种植模式给予生态补偿的提案收悉。经商财政部，现答复如下。

为贯彻党中央决策部署要求，促进农业可持续发展，自2016年起，我部会同财政部等10部门联合启动了耕地轮作休耕制度试点工作。2016年，中央财政安排资金14.36亿元、任务面积616万亩，支持河北等9省区实施耕地轮作休耕制度试点工作。2016—2018年，中央财政不断加大支持力度，累计投入资金98.36亿元，试点省份增加到15个，试点任务扩大到2900万亩。2019年，中央财政进一步加大投入力度，安排资金63.1亿元、比上年增加4.7亿元，试点面积扩大到3000万亩、比上年增加100万亩，试点省份增加至17个。其中轮作区域主要包括东北冷凉区、北方农牧交错区、黄淮海地区、长江流域；休耕区域主要包括地下水漏斗区、重金属污染区、西南石漠化区、西北生态严重退化区。

对于您提出的“对南方稻区‘水稻+绿肥’、北方旱地‘小麦+绿肥’等典型绿色种植模式分别给予180元／亩和150元／亩的生态补偿，采用后补偿方式落实”建议，目前，中央财政主要支持在长江流域小麦稻谷低质低效区实行稻油、稻菜、稻肥等轮作。从2017年起，中央财政上述资金实行“大专项+任务清单”的管理方式，各地可在任务清单规定范围内，按规定统筹中央财政和地方资金，因地制宜开展轮作试点。同时，结合实施绿色高产高效创建，积极拓展农业多种功能，发展“一季多收”的复合种植模式、“一主多辅”的轮作模式，支持绿肥种植，保护耕地地力，提高产出效益。

下一步，我部将会同财政部全面贯彻落实党的十九大精神，坚持质量兴农、绿色兴农战略，结合您的提案，指导督促各级财政部门加快落实以绿色生态为导向的农业补贴制度，完善“大专项+任务清单”实施机制，坚持走产出高效、产品安全、资源节约、环境友好的农业现代化道路。

感谢您对农业农村经济工作的关心，希望继续对我部工作给予支持。

农业农村部

2019年8月29日
