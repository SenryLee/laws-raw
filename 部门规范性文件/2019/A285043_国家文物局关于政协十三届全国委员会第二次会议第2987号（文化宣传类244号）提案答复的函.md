# 国家文物局关于政协十三届全国委员会第二次会议第2987号（文化宣传类244号）提案答复的函

文物保函〔2019〕870号

马立群委员：

您提出的《关于进一步加强中东铁路历史建筑保护和利用的提案》已交由我局会同文化和旅游部、财政部办理，现答复如下：

中东铁路建筑群涉及黑龙江省、吉林省、辽宁省和内蒙古自治区，沿线分布的文物建筑约2000余栋，是重要的大尺度、跨区域的线性分布文化遗产，文物数量巨大。切实加强中东铁路建筑群的保护和利用工作，对于带动东北三省一区文物工作的健康发展，充分发挥文物在东北振兴中的积极作用具有重要意义。

国家十分重视中东铁路建筑群的保护利用工作。国务院先后于2006年和2013年两次将中东铁路建筑群的28处文物点核定公布为全国重点文物保护单位。2011年以来，我局先后批准中东铁路建筑群保护规划编制、本体保护、安全消防等文物保护项目30余项，累计安排中央财政专项资金逾1.2亿元。2018年，国家文物局组织专业机构启动《中东铁路建筑群保护规划纲要》编制研究。2019年，国家文物局在第八批全国重点文物保护单位申报遴选工作中，对各省申报的涉及中东铁路建筑群的增补项目予以重点关注，安排专家进行现场复核，并将其中价值重大的列入第八批全国重点文物保护单位推荐名单。与此同时，文化和旅游部研究制定了《工业旅游示范基地规范与评价》等相关行业标准，推出了一批工业遗产旅游示范基地，引导文化遗产与旅游融合发展，推动文化遗产旅游发展模式创新和业态创新。内蒙古自治区、辽宁、吉林和黑龙江省文物行政部门建立联席会议制度，定期召开会议，专题研究中东铁路建筑群保护利用工作。

下一阶段，为进一步加强中东铁路文物建筑保护和利用工作，国家文物局将会同有关部门重点做好以下工作：

一是进一步加强统筹规划和顶层设计。加快推进中东铁路建筑群保护总体规划纲要编制研究项目，在做好中东铁路建筑群的价值研究和现状评估的基础上，建立中东铁路建筑群保护工作总框架，确定分层级保护任务，并梳理文物整体保护与区域经济发展的关系，确定文物利用发展途径，为三省一区切实推动中东铁路建筑群保护利用与地方经济社会协调发展提供依据。

二是加大保护利用力度，充分发挥社会效益。国家文物局将进一步加大对中东铁路建筑群文物本体修缮、陈列展示与环境整治等工作的支持力度，在政策、技术上给予必要的支持，并指导相关地方人民政府在确保文物安全的基础上，统筹考虑文物建筑的使用和文物展示利用等问题，最大化发挥文物建筑的社会效益。同时，我局将会同财政部，督促县级以上地方人民政府切实落实主体责任，统筹安排中央补助资金和自有财力，把文物保护经费纳入本级财政预算，采取有效措施，做好文物保护利用相关工作。

三是加强中东铁路建筑群的文化生态保护。文化和旅游部将积极指导黑龙江省、吉林省、辽宁省、内蒙古自治区等四个省区文化和旅游行政部门在充分调研的基础上，对照《国家级文化生态保护区管理办法》中关于国家级文化生态保护试验区的申报条件和要求，对中东铁路建筑群设立国家级文化生态保护试验区的必要性和可行性进行充分研究和论证，切实加强对重点区域的历史风貌和文化生态保护。

四是积极激发中东铁路建筑群的保护利用活力。鼓励地方政府在确保文物安全的基础上，加强中东铁路沿线地区的协调合作，深入挖掘中东铁路的历史文化资源，将文化遗产与中东铁路沿线生态、农业等优质旅游资源进行有效整合，不断拓展旅游发展空间，打造丰富的中东铁路建筑群旅游产品和高质量的旅游品牌，实现中东铁路建筑群保护利用的经济效益、社会效益和生态效益的综合提升，有效助推东北振兴。

感谢您对文物事业的关心与支持！

国家文物局

2019年8月23日
