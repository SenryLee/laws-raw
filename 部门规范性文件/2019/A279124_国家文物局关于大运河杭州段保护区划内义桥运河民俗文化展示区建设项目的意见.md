# 国家文物局关于大运河杭州段保护区划内义桥运河民俗文化展示区建设项目的意见

文物保函〔2019〕584号

浙江省文物局：

你局《关于要求在全国重点文物保护单位大运河杭州段保护区划内实施义桥运河民俗文化展示区建设项目的请示》（浙文物发〔2019〕83号）收悉。经研究，我局原则同意在全国重点文物保护单位大运河杭州段保护区划内实施义桥运河民俗文化展示区建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘。如有大运河河堤等水工设施以及沉船、建筑遗存等重要发现，应调整设计方案加以避让，确保文物安全。

（二）细化驳岸改建/新建设计方案，保持原有岸线走向不变，并对具有历史价值的驳岸进行现状保护。对于确需新建的部分，应采用当地驳岸砌筑的传统材料、工艺和形制。简化栏杆形制设计。

（三）细化宝积寺改建方案，不得新建任何建筑物或构筑物。明确原有建筑外立面色彩调整的具体方案，应以灰色调为主，确保与大运河周边整体环境风貌相协调，并适当增加周边区域绿化面积。

（四）细化拟建项目中义桥民俗文化展示区的建筑设计方案，适当降低建筑高度和密度，明确公共文化服务空间的具体功能，适当增加大运河文化遗产及周边民俗展示内容。

（五）细化项目施工方案，明确施工期间的大运河水质、生态环境保护措施、监测措施和应急预案，以及施工后期恢复郊野环境风貌措施，同时应积极考虑设置大运河保护、展示标识。

（六）深化项目设计图纸，补充“运河新城运河景观带（康桥路——宣杭铁路段）工程”总图，并在总图及“1.2 拱宸桥至塘栖镇段运河保护规划”相关图纸上明确标注拟建项目位置。

（七）应注意做好大运河及周边区域的生态环境、景观风貌变化情况记录，并将相应数据、记录等提交相关大运河遗产监测系统平台存档。

（八）应编制拟建码头、景观廊亭设计方案并另行报批。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年6月21日
