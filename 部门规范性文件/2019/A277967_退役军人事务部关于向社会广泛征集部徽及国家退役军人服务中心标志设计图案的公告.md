# 退役军人事务部关于向社会广泛征集部徽及国家退役军人服务中心标志设计图案的公告

为做好新组建的退役军人事务部部徽及国家退役军人服务中心标志的设计工作，兹在全国范围内开展设计图案征集活动，现将有关事项和要求通知如下：

一、情况介绍

退役军人事务部2018年组建，是国务院组成部门，主要职责是，拟订退役军人思想政治、管理保障等工作政策法规并组织实施，褒扬彰显退役军人为党、国家和人民牺牲奉献的精神风范和价值导向，负责军队转业干部、复员干部、退役士兵的移交安置工作和自主择业退役军人服务管理、待遇保障工作，组织开展退役军人教育培训、优待抚恤等，指导全国拥军优属工作，负责烈士及退役军人荣誉奖励、军人公墓维护以及纪念活动等。英文缩写为“MVA”。

国家退役军人服务中心2019年组建，是退役军人事务部直属公益一类事业单位，主要承担退役军人就业创业扶持、优抚帮扶、走访慰问、信访接待、权益保障等事务性工作。

二、标志要求

（一）能够体现部门特点。

1.退役军人事务部部徽设计力求体现，坚持党的领导，坚持服务国防和军队建设的使命，建设树牢“四个意识”、坚定“四个自信”、坚决做到“两个维护”的政治机关，坚决落实党中央、国务院决策部署的行政机关，有力维护退役军人和优抚对象合法权益的服务机关，努力做到让退役军人和其他优抚对象满意，让他们成为全社会尊崇的对象。

2.国家退役军人服务中心标志的设计要体现，坚持服务宗旨，全心全意为退役军人和其他优抚对象服务；坚持改革创新，解放思想、勇于探索，以改革的勇气和担当破解难题；坚持军的特色，体现党对退役军人的关心关爱，彰显退役军人为党、国家和人民牺牲奉献的精神风范和价值导向，不断增强退役军人荣誉感、归属感、获得感。

（二）构图简洁、醒目，具有较强的视觉感染力和亲和力。

（三）构思新颖、寓意深刻。

三、作品要求

（一）作品应由设计图稿、设计和创意文字说明、作者情况简介三部分组成。

（二）设计图稿必须是电子格式的彩色文稿，分辨率大于800×600，JPG格式。

（三）以个人名义投稿的作者应提供姓名、单位、身份证号、联系电话、通讯地址等；以单位名义投稿的作者应注明单位名称、注册地址、通讯地址、联系人及电话。

（四）作品必须为原创设计，并且无抄袭、仿冒或侵害他人知识产权；此前未以任何形式发表过，也未以任何方式为公众所知。

四、方案提交和评选

本次征集活动截止时间为2019年7月10日17时，超过上述时间将不再接收，作品请通过电子邮件方式提交。邮箱：yuankf@mva.gov.cn。

作品征集截止后，将成立评审委员会，对所有征集作品从主题呈现、创意表现、视觉美感3个方面进行评审，确定部徽和标志各5名向社会公布并颁发荣誉证书。

联系电话：010-87933620

五、著作权转让说明

入围的作者应与退役军人事务部签订《标志征集活动应征作者承诺书》。

六、其他事项

本次活动适用中华人民共和国法律。与本次活动有关的任何争议，均提请北京仲裁委员会仲裁。退役军人事务部对本次活动具有解释权。

此次征集活动意义重大，影响深远，希望社会各界人士踊跃参加，献计献策。
