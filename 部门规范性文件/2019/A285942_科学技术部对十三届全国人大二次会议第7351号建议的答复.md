# 科学技术部对十三届全国人大二次会议第7351号建议的答复

## 对十三届全国人大二次会议第7351号建议的答复

国科建议高〔2019〕68号

你们提出的《关于推行散煤清洁高效燃烧技术，解决我国北方地区冬季清洁供暖的建议》收悉。经认真研究，现答复如下。

做好煤炭的清洁高效利用，不仅有利于推动煤炭供给侧结构性改革，服务于我国的能源安全、经济社会发展，也是打赢污染防治攻坚战和蓝天保卫战的重要支撑。科技部高度重视煤炭清洁高效利用技术发展，给予了持续支持。“十二五”期间，组织实施了“洁净煤技术科技发展”“蓝天科技工程”“清洁空气研究计划”和“大气灰霾追因与控制”等科技专项，部署了高效洁净燃煤发电、煤基清洁燃料、污染物控制等方向关键技术的研发与示范。

“十三五”期间，科技部会同有关部门启动实施了国家重点研发计划“煤炭清洁高效利用和新型节能技术”重点专项。围绕煤炭高效发电、煤炭清洁转化、燃煤污染控制、工业余能回收利用、工业流程及装备节能等技术方向进行任务部署。2016—2018年已发布三批项目申报指南，启动了包括燃煤PM2.5及Hg控制技术，燃煤锅炉污染物（SO2、NOx、PM）一体化控制技术研究及工程示范，燃煤过程中砷、硒、铅等重金属的控制技术，燃煤过程有机污染物排放控制技术，富氧燃烧高效低成本运行关键技术与示范，燃煤电厂新型高效除尘技术及工程示范等多个项目。

同时，科技部启动实施了“大气污染成因与控制技术研究”重点专项，一是支持居民燃煤污染控制技术及应用示范，研究散煤洁净化前处理技术、清洁燃烧装置与灶具等，建立居民燃煤关键大气污染物排放的检测方法及污染控制效果的综合评价方法，构建居民燃煤污染控制整体技术方案，在京津冀等冬季取暖散煤燃烧污染严重区域开展应用示范居民燃煤。二是支持珠三角、长三角和京津冀及周边地区等重点区域大气污染联防联控及重污染应急技术与集成示范，将针对包括燃煤散烧在内的小散乱排放等开展减排技术的筛选与综合评估，构建应对秋冬季重污染的精细化区域调控方案及快速实施机制，开展精细化预警的技术示范，建设区域一体化空气质量精细化立体监测预警业务化平台和空气质量管理技术体系，提出区域大气污染联防联控的机制体制和实施方案。三是支持燃煤烟气污染物治理核心关键技术研发及示范应用。针对燃煤污染治理从达标到超低的高效率、复杂煤质的高适应、系统运行的高可靠和低成本等国际性难题，通过专项支持，浙江大学研发的多污染物高效协同脱除超低排放系统，实现复杂煤质和复杂工况下多污染物低成本超低排放，累计装机容量超1亿千瓦，大幅削减燃煤污染物，全面提升燃煤污染治理技术水平，推动和支撑国家燃煤电厂超低排放战略实施，近三年（截至2016年底）新增销售109.6亿元，新增利润11.9亿元，带动全国65%左右的燃煤电厂实现超低排放。该重点专项在2016—2019年已发布四批项目申报指南。

此外，科技部会同有关部门正在研究部署面向2030年的煤炭清洁高效利用重大项目，拟面向煤炭绿色开发、煤炭清洁燃烧与高效发电、煤炭清洁转化、碳捕集利用与封存（CCUS）、煤炭清洁高效利用决策支持等五大方向进行任务部署，与重点专项任务形成远近结合、梯次接续的系统布局。后续科技部将继续推进煤炭清洁高效利用技术发展，为应对气候变化提供有力支撑。

感谢你们对科技工作的支持！

科技部

2019年7月9日
