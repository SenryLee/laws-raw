# 国家文物局办公室关于四川文博工程监理有限公司文物保护工程监理甲级资质证书内容变更的函

办保函〔2019〕685号

四川省文物局：

你局《关于四川文博工程监理有限公司变更文物保护工程监理资质证书的请示》（川文物〔2019〕66号）收悉。

经研究，我局同意四川文博工程监理有限公司文物保护工程监理甲级资质证书中的法定代表人由“王燕”变更为“钟昆”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年8月5日
