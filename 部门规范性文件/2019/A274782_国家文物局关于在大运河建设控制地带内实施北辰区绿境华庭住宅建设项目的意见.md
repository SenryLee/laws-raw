# 国家文物局关于在大运河建设控制地带内实施北辰区绿境华庭住宅建设项目的意见

文物保函〔2019〕223号

天津市文物局：

你局《关于上报大运河建设控制地带内实施北辰区绿境华庭住宅项目的请示》（津文旅发〔2018〕39号）收悉。经研究，我局原则同意在大运河建设控制地带内实施北辰区绿境华庭住宅建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建项目区域进一步开展考古调查勘探和必要的考古发掘。如有地下文物遗存等重要发现，应做好原址、原状保护工作，并对拟建项目方案进行相应调整，合理避让。

（二）进一步优化项目建设方案。应将位于保护区划内的拟建建筑尽可能向远离大运河的方向调整；同时完善建筑外观设计，建议整体采用柔和淡雅的色彩，减少浅驼色的使用范围；此外应增加沿河区域绿化高度和绿化面积，并设置半通透景观墙。

（三）应细化施工和运营期间的水环境、声环境、空气环境、生态环境、固体垃圾等环境影响监测措施，制订应急预案，明确施工期间的场地布置、施工组织、生态保护、景观控制等要求和污染物处置措施。

（四）应结合项目建设，在临近大运河区域设置慢行系统和生态绿廊，并适当增设大运河世界文化遗产价值及内涵展示阐释设施。

（五）应注意做好大运河及周边区域的生态环境、景观风貌变化情况记录，并将相应数据、记录等提交相关大运河遗产监测系统平台存档。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月1日
