# 国家文物局关于在云南省文物保护单位普华寺保护范围内新建南北厢房项目意见的函

文物保函〔2019〕1222号

云南省文物局：

你局《关于请求对普华寺保护范围内新建活佛住房南北厢房工程进行审批的请示》（云文物〔2019〕88号）收悉。经研究，我局原则同意在云南省文物保护单位普华寺保护范围内新建南北厢房项目。

一、对所报方案提出以下修改意见：

（一）补充普华寺的历史格局沿革和现状文物建筑分布情况说明；补充反映普华寺现存文物建筑高度、风貌特征等照片和图纸；补充保护区划管理规定。

（二）加强现状勘察，开展必要的考古工作，明确项目区域内地下文物的分布状况。

（三）补充拟建生活用房与文物建筑之间基础安全、体量对比、视线关系、建筑风貌等的影响情况分析；方案应依据影响评估结论做出调整、深化，避免对文物建筑及其周边环境造成影响。

（四）细化建筑防火设计和水电等专业设计，进一步校核结构安全。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年11月21日
