# 中华人民共和国农业农村部公告第143号——农药登记试验单位及试验范围

## 中华人民共和国农业农村部公告

第143号

根据《农药管理条例》《农药登记管理办法》《农药登记试验管理办法》等有关规定，经资料审查、现场检查和综合评审，批准中国疾病预防控制中心寄生虫预防控制所等18家单位为农药登记试验单位，有效期五年。

特此公告。

附件：农药登记试验单位及试验范围

农业农村部

2019年3月4日
