# 国家文物局对十三届全国人大二次会议第7626号建议的答复

文物政函〔2019〕688号

孙继业代表：

您提出的“关于弘扬沂蒙精神、传承红色基因的建议”交由中央宣传部、中央组织部、中央党史和文献研究院、文化和旅游部、山东省人民政府和国家文物局分办。现将我局办理意见答复如下。

习近平总书记指出：“沂蒙精神与延安精神、井冈山精神、西柏坡精神一样，是党和国家的宝贵精神财富，要不断结合新的时代条件发扬光大。”这一论断深刻揭示了沂蒙精神是中国共产党革命精神谱系的重要组成部分，保护传承好沂蒙精神具有特殊重要的意义和价值。

国家文物局将深入贯彻落实中共中央办公厅、国务院办公厅《关于实施革命文物保护利用工程（2018-2022年）的意见》，切实加强对沂蒙地区革命文物保护利用的指导和支持，更好促进沂蒙革命老区脱贫攻坚和振兴发展。

一是支持实施沂蒙地区革命文物集中连片保护利用工程。国家文物局与相关部门将在第二批革命文物保护利用片区分县名单的研究确定中，依托山东抗日根据地的革命史实，设立山东革命文物保护利用片区，涵盖沂蒙革命老区的相关市县。按照财政部、国家文物局出台的《国家文物保护专项资金管理办法》，以山东革命文物保护利用片区为重点，支持沂蒙地区实施一批、完工一批、储备一批革命文物保护项目。

二是加强沂蒙精神传播传承，推动沂蒙精神绽放新光彩。深入挖掘沂蒙精神的价值内涵和文化元素，结合庆祝中华人民共和国成立70周年和中国共产党成立100周年的重要时点，支持地方整合现有展陈资源，打造反映沂蒙精神全貌的革命文物基本陈列展览精品，开展弘扬沂蒙精神的文物联展、巡展，创新互联网+沂蒙精神传播方式，研究论证山东抗战纪念馆建设的可行性。推动将沂蒙精神纳入革命文物宣传传播工程“三个百集”（即百集革命文物故事微视频、百集革命旧址短片、百集革命人物纪录片）拍摄计划，支持地方制作传播沂蒙精神的短片视频。

三是发挥沂蒙精神的党性教育功能。紧密结合“不忘初心、牢记使命”主题教育活动，充分发挥沂蒙精神在党性教育中的独特优势和重要作用，支持建立沂蒙地区革命旧址、革命博物馆纪念馆与周边学校、党政机关、企事业单位、驻地部队、城乡社区的共建共享机制，支持党校（行政学院）、干部学校到革命旧址、革命博物馆纪念馆开展现场教学，讲好沂蒙故事，弘扬沂蒙精神，传承红色基因。

感谢您对革命文物保护的关心和支持。

国家文物局

2019年7月10日
