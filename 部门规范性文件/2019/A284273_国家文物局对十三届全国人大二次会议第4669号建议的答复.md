# 国家文物局对十三届全国人大二次会议第4669号建议的答复

文物保函〔2019〕633号

庞永辉代表：

您提出的“关于支持建立定窑遗址博物馆的建议”收悉，经商国家发展改革委、财政部，现答复如下。

定窑创烧于唐，衰止于元，是宋代五大名窑之一。定窑遗址是中国陶瓷史发展的历史见证，具有重要的历史、艺术和科学价值，1988年被国务院公布为全国重点文物保护单位。国家文物局高度重视定窑遗址的保护利用问题，“十一五”以来，一直将定窑遗址列入国家大遗址保护项目库，并在考古发掘、本体保护、规划编制等方面予以专门支持。“十三五”期间，国家发展和改革委员会与相关部门共同组织实施了包括定窑遗址在内的文化旅游提升工程，对公共服务设施、国家级自然文化遗产保护利用设施、旅游基础设施和公共服务设施建设等予以积极支持。

对于建立定窑遗址博物馆的建议，下一步国家文物局将会同国家发展和改革委员会、财政部做好如下工作。

第一，督促地方人民政府落实文物保护的主体责任，抓紧编制、实施《定窑遗址总体保护规划》，系统开展考古工作，深入发掘遗址文化内涵，进一步提升遗址影响力，切实改善定窑遗址保护管理现状，确保遗址安全。

第二，指导地方人民政府及有关部门加快定窑遗址保护利用和服务设施项目储备，并按程序申报。有关部门将在年度安排中央预算内投资时予以统筹研究和积极支持，进一步完善遗址保护利用的基础设施。

第三，文化旅游提升工程支持范围暂不包括博物馆等内容，建议河北省优先考虑利用现有展陈空间，发挥相关文物保护和展示展览功能。确有必要新建博物馆的，应发挥地方责任主体的主观能动性，充分整合利用现有资源；要合理确定建设规模和内容，注重软件建设和提升展陈开放水平。

感谢您对文物事业的关心和支持。

国家文物局

2019年7月5日
