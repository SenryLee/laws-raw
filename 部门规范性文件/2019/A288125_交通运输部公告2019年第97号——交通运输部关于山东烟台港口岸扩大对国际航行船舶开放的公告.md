# 交通运输部公告2019年第97号——交通运输部关于山东烟台港口岸扩大对国际航行船舶开放的公告

## 交通运输部公告

2019年第97号

## 交通运输部关于山东烟台港口岸扩大对国际航行船舶开放的公告

中央编办，国务院办公厅，国家发展改革委，公安部，财政部，商务部，海关总署，移民局，军委联合参谋部，山东省人民政府，山东省口岸办，山东海事局，中国水运报社、中国交通报社:

根据《国务院关于同意山东烟台港口岸扩大开放的批复》（国函〔2014〕104号）和《海关总署关于印送山东烟台港口岸扩大开放验收纪要的函》（署岸函〔2019〕448号），交通运输部决定自本公告之日起，山东烟台港口岸扩大对国际航行船舶开放。具体开放范围由山东海事局按程序对外公布。

特此公告。

交通运输部

2019年12月29日
