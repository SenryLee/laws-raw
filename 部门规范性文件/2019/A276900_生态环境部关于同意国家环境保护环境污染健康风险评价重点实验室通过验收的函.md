# 生态环境部关于同意国家环境保护环境污染健康风险评价重点实验室通过验收的函

## 关于同意国家环境保护环境污染健康风险评价重点实验室通过验收的函

环科财函〔2019〕63号

生态环境部华南环境科学研究所：

按照《国家环境保护重点实验室管理办法》（环发〔2004〕138号）有关规定，你所向我部报送了《国家环境保护环境污染健康风险评价重点实验室建设总结报告》。2019年3月，我部对依托你所建设的国家环境保护环境污染健康风险评价重点实验室（以下简称重点实验室）进行了验收。

我部认为，重点实验室完成了《国家环境保护环境污染健康风险评价重点实验室建设计划任务书》确定的建设任务。建设期内，围绕环境污染危害识别与暴露评估技术、环境污染物剂量-反应关系构建技术和环境健康风险评价技术等研究方向开展了研究，在区域环境污染人群健康风险防控技术及其应用、新型有机污染物/大气颗粒物毒性效应、环境健康风险评价等方面取得了一批创新性的科研成果，为完成环境污染物人群暴露评估技术指南、民用建筑环境空气颗粒物渗透系数调查技术规范等3项国家环境保护行业标准制定等提供了技术支持。同时，重点实验室软硬件设施进一步完善，形成了结构合理、稳定高效的科研团队，管理制度不断健全，达到了验收要求。我部同意重点实验室通过验收。

请按照《国家环境保护重点实验室管理办法》有关规定，在已有工作基础上，继续围绕国家生态环境保护重点任务，加强合作交流，注重科学研究与环境管理的结合，进一步为我国环境健康风险管理提供科技支撑。

附件：重点实验室名称、主任和依托单位

生态环境部
