# 中共教育部党组关于曾天山同志职务任免的通知

教党任〔2019〕34号

教育部职业技术教育中心研究所，中国教育科学研究院党委：

中共教育部党组2019年2月1日决定，任命曾天山同志为教育部职业技术教育中心研究所副所长，免去其中国教育科学研究院副院长职务。

中共教育部党组

2019年2月12日
