# 教育部办公厅关于公布2018年度工程和材料领域教育部重点实验室评估结果的通知

教技厅函〔2019〕13号

有关省、自治区、直辖市教育厅（教委），有关部门（单位）教育司（局），部属有关高等学校、部省合建有关高等学校：

根据《教育部重点实验室建设与管理办法》和《教育部重点实验室评估规则（2015年修订）》，2018年9月至12月，我部组织对工程和材料领域的教育部重点实验室开展了五年定期评估。现将评估结果及有关事项通知如下：

1.材料领域49个参评实验室中，纳米器件物理与化学教育部重点实验室等8个实验室评估结果为优秀；功能分子固体教育部重点实验室等36个实验室评估结果为良好；其余实验室评估结果为整改或未通过定期评估。

2.工程领域96个参评实验室中，水沙科学教育部重点实验室等17个实验室评估结果为优秀；煤矿安全高效开采教育部重点实验室等69个实验室评估结果为良好；其余实验室评估结果为整改或未通过定期评估。

3.评估结果为优秀的实验室可由我部优先推荐申报国家科技创新基地。

4.请有关学校和参评实验室认真总结，以评促建，采取措施加大支持，切实加强实验室的建设与管理，促进实验室建设水平和创新能力的不断提高。

附件：2018年度工程和材料领域教育部重点实验室评估结果

教育部办公厅

2019年1月24日
