# 国家文物局关于明长城天镇县化皮庙段保护区划内天镇县环翠山风电场220kV送出工程线路建设项目的意见

文物保函〔2019〕894号

山西省文物局：

你局《关于天镇县环翠山风电场220kV送出工程线路跨越明长城天镇县化皮庙段的请示》（晋文物〔2019〕98号）收悉。经研究，我局原则同意在明长城天镇县化皮庙段保护区划内实施天镇县环翠山风电场220kV送出工程线路建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）补充项目采取地下管线方式通过明长城保护区划的比选方案，同时细化文物影响评估，评估各方案可行性以及对长城本体及其周边环境景观的影响情况，并提出缓解措施和方案优化建议。

（二）补充项目方案一中T13、T14号铁塔选址区域的考古勘探、发掘资料，确保地下文物安全；同时完善铁塔设计方案，尽可能弱化其对长城环境景观的负面影响。

（三）补充项目施工期间明长城本体临时性保护措施，细化施工后期生态环境修复措施，补充极端天气条件下防范项目威胁明长城本体安全的保护措施和应急预案。

（四）补充在适当区域设置长城保护标志、保护界桩、展示说明牌等标识、展示设施等相关措施。

二、请你局组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年8月27日
