# 国家体育总局小球中心关于印发《2019年全国青少年壁球个人锦标赛竞赛规程》的通知

## 小球中心关于印发《2019年全国青少年壁球个人锦标赛竞赛规程》的通知

小球字〔2019〕159号

各有关单位：

根据总局小球中心2019年赛事计划安排，全国青少年壁球个人锦标赛将于2019年6月1日至2日在上海盛力瑛才壁球中心举办。

现将竞赛规程印发给你们，请积极组织参加比赛。

附件：2019全国青少年壁球个人锦标赛竞赛规程-2019.5.20

体育总局小球中心

2019年5月23日
