# 国家核安全局关于批准NPC运输容器在中华人民共和国境内使用的通知

## 关于批准NPC运输容器在中华人民共和国境内使用的通知

国核安发〔2019〕126号

全球核燃料有限责任公司-美国：

你公司《请求批准关于使用新核燃料容器（NPC）A型货包-一类放射性物质，易裂变的，非特殊形式的申请》收悉。

你公司NPC运输容器已取得美国核能管理委员会设计批准，设计批准编号：USA/9294/AF-96（Rev.8）。根据《中华人民共和国放射性物品运输安全管理条例》的要求，我局核查了NPC运输容器在原设计批准国取证的相关资料，批复如下。

一、同意NPC运输容器在中国境内使用，设计批准编号为CN/066/AF -96（NNSA），允许在中国境内使用的运输容器编码见附件。

二、运输容器的使用应满足原设计批准中相应的限值和条件要求。

三、本批准有效期至2024年5月31日。运输容器原设计批准是本批准的前提，你公司应保持原设计批准有效，如原设计批准失效，本批准自动失效。

附件：NPC运输容器编码

国家核安全局

2019年6月11日
