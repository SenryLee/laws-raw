# 国家文物局关于明长城靖边段保护区划内靖边县延929井区地面集输管线工程（靖边段）延948、913和靖65三条输气管线建设项目的意见

文物保函〔2019〕461号

陕西省文物局：

你局《关于靖边县延929井区地面集输管线工程（靖边段）延948、913和靖65三条输气管线穿越长城遗址的请示》（陕文物字〔2019〕61号）收悉。经研究，我局原则同意在明长城靖边段保护区划内实施靖边县延929井区地面集输管线工程（靖边段）延948、913和靖65三条输气管线建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建项目相关区域进行深入的考古调查勘探和必要的考古发掘。如有文物遗存等重要发现，应做好现状保护，并对项目方案进行必要调整，避让考古发现分布区域。

（二）应完善项目施工方案，重点细化开挖施工方案及控制要求，补充针对施工区域长城下部载体必要的加固、保护或支护措施，避免因项目施工导致载体出现沉降、位移等地质问题，威胁长城文物本体安全。

（三）应适当加大拟建管道埋设深度，并通过调整线路角度等措施，尽可能拉大拟建管道与长城之间的距离，完善施工和运营期间的监测措施、应急预案和长城文物本体临时保护措施。

（四）应进一步明确场地布置、施工组织、生态保护等要求，细化施工期间的垃圾、粉尘等污染物处置要求。施工完成后，应做好场地清理和环境恢复工作，并在长城周边适当设置标识及展示设施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月20日
