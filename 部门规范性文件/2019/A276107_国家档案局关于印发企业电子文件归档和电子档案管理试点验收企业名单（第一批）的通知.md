# 国家档案局关于印发企业电子文件归档和电子档案管理试点验收企业名单（第一批）的通知

各省、自治区、直辖市档案局，河北省委办公厅、江苏省委办公厅，各计划单列市档案局，新疆生产建设兵团档案局，各中央企业档案部门：

为推进企业电子文件归档和电子档案管理工作，推行电子文件单套制归档管理，2016年国家档案局联合国家发展改革委遴选了33家单位开展企业电子文件归档和电子档案管理试点工作。2017年至2018年，共有13家企业完成了所选业务系统的电子文件归档和电子档案管理试点工作，通过了我局组织的验收，形成了典型经验，可向全国推广。现将通过验收的企业名单下发，以方便各单位联系学习。

国家档案局

2019年3月8日
