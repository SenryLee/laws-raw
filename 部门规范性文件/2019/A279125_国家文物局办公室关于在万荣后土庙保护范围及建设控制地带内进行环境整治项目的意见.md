# 国家文物局办公室关于在万荣后土庙保护范围及建设控制地带内进行环境整治项目的意见

办保函〔2019〕553号

山西省文物局：

你局《关于审批万荣后土庙环境整治方案的请示》（晋文物〔2019〕66号）收悉。经研究，我局暂不同意在万荣后土庙保护范围及建设控制地带内进行环境整治项目。

一、该项目已多次报审，所报方案仍未按照《国家文物局办公室关于万荣后土庙保护范围及建设控制地带内环境整治项目的意见》（办保函〔2019〕95号）进行修改完善。应对后土庙周边现有建筑进行客观准确评估，避免大拆大建和扩建广场，尽可能保留文物历史环境风貌。

二、护坡加固设计应验算稳定性，并比选加固技术措施。

三、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年6月21日
