# 国家文物局办公室关于福建土楼永定初溪土楼群保护区划内实施初溪村重点提升项目的意见

办保函〔2019〕200号

福建省文物局：

你局《关于报送福建土楼集庆楼所在中国传统村落永定初溪村重点提升项目设计方案（修改）的请示》（闽文物字〔2019〕38号）。经研究，我局暂不同意所报涉及福建土楼集庆楼保护区划的初溪村重点提升项目设计方案。

一、对所报方案提出以下修改完善意见：

（一）进一步明确工程内容和工程范围，深化方案设计，明确各项工程的具体位置、现状及提升措施等具体内容，包括公厕的翻修改造设计。道路改造工程应补充说明外部道路和护坡现状及改造方案设计；内部村道应改造注意尽可能恢复历史路面，不得改变原有巷道尺度。

（二）应弱化景观设计，加强该区域的历史风貌保护。亮化工程应以满足道路基本照明需求为主，不宜设置过多景观照明灯；绿化工程中不宜大量栽种多品类景观植被，避免园林化、景观化设计倾向；简化垃圾池外观造型设计，不宜刻意仿照土楼建筑。

（三）补充古法造纸厂建设项目设计依据，并在现存遗址价值评估基础上，提出遗址保护措施。调查收集有关造纸工艺流程的历史资料，考证造纸厂原始建筑形式；如无确凿历史依据，不得建造景观性水车。

（四）结合消防工程、安技防工程，统一编制给排水方案及电力系统设计方案。

（五）进一步深化、完善文物影响评估报告，科学分析拟实施项目对遗产及其周边景观环境的影响，并就完善方案提出合理化建议。

二、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室
