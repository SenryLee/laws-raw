# 国家文物局关于在大运河江南运河苏州段山塘历史文化街区保护区划内实施新民桥——彩云桥段风貌整治项目的意见

文物保函〔2019〕255号

江苏省文物局：

你局《关于审批大运河苏州段山塘历史文化街区（新民桥——彩云桥）风貌整治工程方案的请示》（苏文物保〔2018〕325号）收悉。经研究，我局原则同意在大运河江南运河苏州段山塘历史文化街区保护区划内实施新民桥——彩云桥段风貌整治项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应深化文物影响评估，补充相关图纸，明确标注拟实施整治项目与大运河苏州段遗产区、缓冲区和保护范围、建设控制地带的关系，并就项目方案与保护区划管理规定的符合性作出详细说明。

（二）应详细列出该区域内各级文物保护单位和登记的其他不可移动文物清单，并按照真实性、完整性原则，严格实施现状保护；对其他具备一定价值的历史建筑，应做好外观风貌保护。

（三）应深入开展街区现状勘察、评估，明确整治措施的范围和具体部位，按照最小干预原则，保留不同历史阶段有机更新、自然渐进的典型特征，针对不同类型建筑分别制定科学合理的整治措施，明确工程量并绘制设计大样图。

（四）对彩钢板、塑胶板、棚帆布、混凝土遮雨棚，以及门、窗、裙板、栏杆、挂落等装饰构件，应根据实际情况适度整治，严控整治范围，避免“一刀切”式大面积新设雀宿檐、装折。

（五）除为保证结构安全而采取加固措施的建筑局部外，原则上不得大面积实施房屋外墙更新、粉刷及油漆处理，避免对山塘历史文化街区的真实性、完整性和历史风貌造成无法逆转的破坏。

（六）路面整治应以现状加固、归位为主，充分回收利用老旧材料。对损坏较为严重的区域，可按原材料、形制和工艺进行局部补配，不得大面积更换现有路面铺装。

（七）应细化管线、安防施工方案，明确具体施工要求，避免对文物建筑物本体造成扰动。相关设施建设应尽可能选址在隐蔽部位，维护街区整体风貌协调。

（八）应重点调整节点设计方案，取消栗壳色防腐木平台、公共服务游廊（苏式小青瓦木构游廊），不得改变地面铺装式样和材质，可适当设置分散式、小体量休憩设施和文化遗产价值阐释设施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月12日
