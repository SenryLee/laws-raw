# 中共自然资源部党组关于梁凤奎、熊志强同志任职的通知

自然资党任〔2019〕68号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中央军委后勤保障部军事设施建设局，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

部党组2019年5月13日研究决定：

梁凤奎任国际合作司（海洋权益司）副巡视员；

熊志强任离退休干部局副巡视员。

中共自然资源部党组

2019年5月27日
