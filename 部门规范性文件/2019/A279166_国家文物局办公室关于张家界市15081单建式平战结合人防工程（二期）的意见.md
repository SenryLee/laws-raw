# 国家文物局办公室关于张家界市15081单建式平战结合人防工程（二期）的意见

办保函〔2019〕562号

湖南省文物局：

你局《关于审批张家界市15081单建式平战结合人防工程（二期）的请示》（湘文物报〔2019〕57号）收悉。经研究，我局暂不同意在湘鄂川黔革命根据地旧址、普光禅寺保护范围内进行张家界市15081单建式平战结合人防工程（二期）建设项目。

一、所报方案尚需作以下必要的修改和完善

（一）进一步核定湘鄂川黔革命根据地旧址、普光禅寺的法定保护范围与建设控制地带，优化建设项目选址，避让上述两处文物保护单位的保护范围，并尽量远离文物本体，以确保文物安全。

（二）补充评估文物建筑的现状稳定性，评估建设项目地下工程部分及施工过程对文物建筑所造成的不良影响。

（三）完善建设方案设计，优化施工方案设计，补充必要的文物保护措施及应急预案，确保文物安全。

二、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年6月25日
