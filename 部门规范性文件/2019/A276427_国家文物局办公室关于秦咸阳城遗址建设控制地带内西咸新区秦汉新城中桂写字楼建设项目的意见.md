# 国家文物局办公室关于秦咸阳城遗址建设控制地带内西咸新区秦汉新城中桂写字楼建设项目的意见

办保函〔2019〕277号

陕西省文物局：

你局《关于西咸新区秦汉新城中桂写字楼选址涉及秦咸阳城遗址建设控制地带的请示》（陕文物字〔2019〕24号）收悉。经研究，我局暂不同意在秦咸阳城遗址建设控制地带内实施西咸新区秦汉新城中桂写字楼建设项目。

一、对所报方案提出以下修改完善意见：

（一）该项目选址紧邻秦咸阳宫遗址保护范围和制陶作坊遗址，应按照《秦咸阳城遗址保护总体规划（2011-2030）》中一类建设控制地带的控制要求，科学核减建筑高度。

（二）论证大面积玻璃幕墙设计的必要性和文物景观影响，建筑外立面形式、色彩应与遗址景观风貌相协调。

（三）应充分评估建设施工、市政管线铺埋等文物影响，研提施工中的文物保护预案，确保文物安全。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

三、请你局指导地方人民政府，依据《西咸新区总体规划》《秦咸阳城遗址保护总体规划（2011-2030）》，进一步明确、调整公布建设控制地带的具体建设控制要求和指标，统筹考虑城市建设发展和秦咸阳城遗址保护利用之间的关系。

专此函复。

国家文物局办公室

2019年4月12日
