# 国务院国有资产监督管理委员会对十三届全国人大二次会议第7359号建议的答复

## 对十三届全国人大二次会议第7359号建议的答复

袁俊洲等16位代表：

你们提出的《关于中石化济宁油库退城进园的建议》（第7359号）收悉，经商中国石油化工集团有限公司（以下简称中国石化），现答复如下：

中石化济宁油库搬迁作为济宁市优化城市发展空间、完善城市功能、加快城市核心区建设的重要项目，国资委高度重视，对有关情况进行了认真研究，并督促中国石化积极配合地方政府落实好城市发展规划要求，加快推进济宁油库搬迁工作。

中国石化反映，按照济宁市政府搬迁济宁油库的要求，2018年6月集团公司批复开展了前期工作。目前，中国石化销售公司及山东分公司已就油库搬迁位置及迁建油库用地与地方政府达成一致意见，完成一期160亩土地的招拍挂。中国石化所属的曲阜分输泵站和济宁末站是鲁皖成品油管道曲阜-济宁支线两端的输油站，分别位于山东石油分公司曲阜油库、济宁油库内，油库的搬迁将导致上述相关站场及管线的迁建，中国石化已组织开展了油库配套管线迁改的安评、环评、职业卫生等前期评价工作，并已完成可研方案。同时，中国石化也反映，由于新建油库及迁建管道投资额大，企业负担较重。济宁市政府要求迁建油库全部成本由原油库土地净收益抵顶，不再给予现金补偿。但土地净收益不确定性较大，希望地方政府给予进一步支持。

国资委坚决支持中央企业落实国家区域发展战略和产业政策要求，配合地方发展规划的实施，依法依规实施退城进园，带动地方经济发展，保障人民群众良好生活环境。我们将督促指导中国石化与地方政府进一步加强沟通协调，按照市场化商业化原则，共同推进济宁油库搬迁工作顺利进行。

衷心感谢对我委工作的关心和支持，欢迎继续提出宝贵的意见和建议。
