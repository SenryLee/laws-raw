# 国家标准化管理委员会关于开展2019年世界标准日活动的通知

国标委发〔2019〕27号

各省、自治区、直辖市及计划单列市、副省级城市、新疆生产建设兵团市场监管局（厅、委），各有关单位：

2019年10月14日是第50届世界标准日。国际电工委员会（IEC）、国际标准化组织（ISO）、国际电信联盟（ITU）将2019年世界标准日的主题确定为“视频标准创造全球舞台（Video standards create a global stage）”，联合发出世界标准日祝词（见附件）。为开展好2019年世界标准日系列活动，标准委将在世界标准日当天举办2019年世界标准日主题宣传活动。世界标准日前后，标准委还将会同有关单位集中发布一批重要标准、开展“走进国家标准馆”、全国标准化学科建设与人才培养研讨会等一系列活动。

为广泛凝聚社会共识，营造全社会关心支持标准化工作的良好氛围，切实做好2019年世界标准日宣传工作，现将有关事项通知如下：

一、各有关单位要围绕世界标准日主题，结合工作实际，总结工作成效，特别是要提炼视频标准助推视频技术创新、视频标准助推文化传播、视频技术助推标准宣传等方面的好经验、好做法，进一步加大宣传力度，广泛传播标准化知识和方法理念。

二、相关国家技术标准创新基地、区域标准化研究中心、标准化示范区和试点单位，要结合本地区、本行业实际，因地制宜地开展形式多样的宣传活动，积极营造各方面共同关注标准化、积极参与标准化的良好氛围。

三、各有关单位要深入贯彻落实中央八项规定精神，提倡勤俭节约，反对铺张浪费，突出群众参与，扎实组织开展好各项活动。对于好的做法和经验，可以及时向标准委报送活动开展情况，标准委将及时进行总结推广。
