# 国家文物局对十三届全国人大二次会议第8457号建议的答复

文物保函〔2019〕561号

安际衡代表：

您提出的“关于支持邺城考古遗址公园建设并验收挂牌的建议”收悉，现答复如下：

邺城遗址位于河北省邯郸市，始建于东周，自三国时期开始先后成为曹魏、后赵、冉魏、前燕、东魏、北齐六朝都城，是中国都城发展史上的里程碑，具有重要的历史、科学和艺术价值。经过30余年的考古工作，邺城遗址已初步探明宫城区、陵墓区、手工业区、佛教遗迹区等功能布局，体现出单一宫城制度、中轴对称城市格局及明确的功能分区等特点。1988年，邺城遗址被国务院公布为全国重点文物保护单位。国家文物局非常重视邺城遗址的考古研究与保护利用工作，“十一五”以来，邺城遗址一直被列入国家大遗址项目库。中央财政投入专项经费支持开展考古发掘、环境整治、保护展示与安全防护等工作，有力提升了邺城遗址的研究、保护和展示利用水平。

您提出的支持邺南城宫城区漳河段南堤北移工程和邺城考古遗址公园建设的建议非常重要。国家文物局将指导河北省文物局和地方人民政府从以下几个方面继续推动各项工作。

第一，支持中国社会科学院考古研究所按照大遗址考古要求持续开展邺城考古工作，加快考古资料的整理与出版，着力推进邺城遗址综合研究，科学阐述其在中国都城发展史上承前启后的重要地位，为进一步加强邺城遗址的保护利用奠定良好的学术基础。

第二，督促地方人民政府落实文物保护的主体责任，统筹考虑文物保护、防洪减灾、城乡发展间的关系，科学评估漳河对邺城遗址的影响，充分论证邺南城宫城区漳河段南堤北移等工程必要性和可行性。相关工程报批后，我局将积极会同水利部门协商研究。

第三，督促地方人民政府按照《国家考古遗址公园管理办法（试行）》《国家考古遗址公园创建及运行管理指南（试行）》等文件要求，抓紧编制邺城考古遗址公园规划，科学有序开展遗址本体保护、环境整治、文物展示等各项工作。国家文物局将积极指导邺城遗址保护和国家考古遗址公园建设工作。

感谢您对文物事业的关心和支持。

国家文物局

2019年6月18日
