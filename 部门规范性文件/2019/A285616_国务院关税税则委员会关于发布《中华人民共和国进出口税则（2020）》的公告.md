# 国务院关税税则委员会关于发布《中华人民共和国进出口税则（2020）》的公告

税委会公告〔2019〕9号

根据《中华人民共和国进出口关税条例》及相关规定，现公布《中华人民共和国进出口税则（2020）》，自2020年1月1日起实施。法律、行政法规等对进出口关税税目、税率调整另有规定的，从其规定。

附件：中华人民共和国进出口税则（2020）

国务院关税税则委员会

2019年12月26日
