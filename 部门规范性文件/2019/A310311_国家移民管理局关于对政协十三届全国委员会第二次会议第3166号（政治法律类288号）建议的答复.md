# 国家移民管理局关于对政协十三届全国委员会第二次会议第3166号（政治法律类288号）建议的答复

杨志红委员：

您提出的《关于两地部门联手打击跨境“假结婚”的提案》收悉，经商国务院港澳事务办公室和民政部，现答复如下：

依照《中国公民因私事往来香港地区或者澳门地区的暂行管理办法》（以下简称《管理办法》）有关规定，夫妻一方定居香港，分居多年的，经交验户口簿或者其他户籍证明，提交合法婚姻证明以及配偶在香港有永久居住资格的证明等，可以申请前往香港定居；经公安机关出入境管理部门批准的，申请人持前往港澳通行证赴港定居。同时《管理办法》和《中华人民共和国出境入境管理法》对通过伪造、骗取证件等方式骗取前往港澳通行证行为的法律责任做出了明确规定。多年来，公安机关出入境管理部门严格按照相关法律、法规开展受理、审批工作，为分居内地与香港两地的夫妻实现家庭团聚、促进社会和谐稳定发挥了积极作用。

我局对弄虚作假骗取前往港澳通行证问题始终高度关注，依法实施面见询问申请人及香港配偶、申请时提交家庭团聚申请材料、存疑申请实行集体审批以及审批结果公示等一系列管理措施。内地民政部门加强对涉港澳婚姻登记当事人证件审核和材料审查，并开展婚姻登记领域信用体系建设，加大对弄虚作假骗取婚姻登记的严重失信当事人的信用约束和联合惩戒。为有效防范和共同查处弄虚作假行为，公安机关出入境管理部门充分利用与内地民政部门涉港澳结（离）婚登记信息共享机制、与香港入境事务处协作核查机制，加强对人员身份信息、亲属关系、婚姻登记等情况的全面核查和动态监管。2018年，公安机关出入境管理部门向香港入境事务处函送婚姻关系存疑的申请个案1万余起，并加强与香港有关部门在涉案信息协查、跨境调查取证、法律文书转送和重点个案合作侦办等方面的协作，成功破获多起骗取出境证件及协助他人偷越国（边）境案件，依法查处涉案的香港和内地人员及非法中介，取得明显成效。

下一步，我们将进一步加强与内地和香港有关部门在打击弄虚作假骗取前往港澳通行证问题的协作配合，依法维护往来港澳地区良好出入境秩序。您提出的关于加强与香港有关部门情报交流和联合行动、打击非法中介、修改相关法律加大惩处力度等建议，对我们的工作具有很好的参考价值，我局将会同有关部门进一步统筹研究。

感谢您对移民管理工作的关心和支持。

国家移民管理局

2019年7月2日
