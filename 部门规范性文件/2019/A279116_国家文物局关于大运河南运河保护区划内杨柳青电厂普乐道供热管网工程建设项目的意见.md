# 国家文物局关于大运河南运河保护区划内杨柳青电厂普乐道供热管网工程建设项目的意见

文物保函〔2019〕559号

天津市文物局：

你局《关于上报在大运河（南运河）建设控制地带内实施杨柳青电厂普乐道供热管网工程的请示》（津文物发〔2019〕4号）收悉。经研究，我局原则同意在大运河南运河保护区划内实施杨柳青电厂普乐道供热管网工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构在项目实施前以及“拦河打坝”过程中，对相关区域做进一步的考古调查、勘探和必要的考古发掘，如有大运河河堤等水工设施以及沉船等重要发现，应调整设计方案，合理避让大运河文物遗存。

（二）施工过程中如遇有水工设施或沉船等大运河文物遗存，应将“开挖沟槽”的施工方式调整为非开挖顶管施工或盾构施工等施工方式，避免对文物遗存造成破坏。

（三）应细化项目施工方案，尽可能减少河道、河堤开挖范围，补充施工和运营期间的监测措施和应急预案，大运河遗存、水质和生态环境保护措施，施工后期恢复郊野环境风貌措施，以及设置大运河保护、展示标识等措施。

（四）应做好拟建项目施工前后大运河及周边区域的生态环境、景观风貌变化情况记录，并将相应数据、记录等提交相关大运河遗产监测系统平台存档。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年6月17日
