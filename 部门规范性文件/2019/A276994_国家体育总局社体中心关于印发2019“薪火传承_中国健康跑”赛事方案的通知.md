# 国家体育总局社体中心关于印发2019“薪火传承?中国健康跑”赛事方案的通知

## 关于印发2019“薪火传承?中国健康跑”赛事方案的通知

各省、自治区、直辖市、计划单列市、新疆生产建设兵团体育局社体中心（群体处、体总秘书处），各行业体育协会及有关单位：

由国家体育总局社体中心、湖南省体育局联合发起，有关省（区、市）政府及体育部门共同主办的2019“薪火传承?中国健康跑”系列赛，定于2019年4月至12月期间举办，现将赛事方案印发给你们，请遵照执行。

国家体育总局社体中心

2019年4月10日
