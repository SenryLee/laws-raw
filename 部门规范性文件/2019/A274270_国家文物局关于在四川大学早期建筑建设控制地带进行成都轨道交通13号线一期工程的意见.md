# 国家文物局关于在四川大学早期建筑建设控制地带进行成都轨道交通13号线一期工程的意见

文物保函〔2019〕77号

四川省文物局：

你局《关于在四川大学早期建筑建设控制地带进行成都轨道交通13号线一期工程建设的请示》（川文物〔2018〕109号）收悉。经研究，我局原则同意在四川大学早期建筑建设控制地带内进行成都轨道交通13号线一期工程建设。

一、所报方案尚需作以下必要的修改和完善：

（一）复核区间隧道盾构法施工边界与文物本体距离，补充分析工程项目与文物建筑之间的结构关系（含深度参数），并在此基础上进一步校核相应的计算结果。

（二）补充施工中文物建筑及周边地质条件稳定性监测方案，重点做好施工降水引起的建筑物及周边沉降的实时监测，并提出应对建筑物较大沉降的预案。相关经费应纳入工程预算。

（三）完善地铁运营期间震动减缓措施，补充相应的震动及文物稳定性监测方案，并落实责任单位和经费来源。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月22日
