# 国家文物局关于在新化北塔保护范围和建设控制地带内进行北塔公园建设项目的意见

文物保函〔2019〕911号

湖南省文物局：

你局《关于审批新化县北塔公园建设工程的请示》（湘文物报〔2019〕62号）收悉。经研究，我局原则同意在新化北塔保护范围和建设控制地带内进行北塔公园建设工程。

一、所报方案尚需作以下必要的修改和完善：

（一）加强对新化北塔营造观念和历史环境的研究，科学论证现有护卫堤坝对塔体原有空间格局的影响；不宜以城墙形式防护塔体。

（二）方案应尽量减小新建建筑和场地环境对北塔周边环境真实性的影响；保护范围内应尽量保留原始地貌，新建公园管理用房和游客服务中心建议降为一层，屋檐和山墙形式应加以弱化。

（三）补充完善塔体周围排水措施。

（四）文物影响评估应从塔体和空间格局保护方面补充相应评估内容。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年8月30日
