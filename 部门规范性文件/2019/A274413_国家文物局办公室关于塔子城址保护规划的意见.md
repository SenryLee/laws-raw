# 国家文物局办公室关于塔子城址保护规划的意见

办保函〔2019〕101号

黑龙江省文物局：

你局《关于重新上报塔子城址保护规划的请示》（黑文管字〔2018〕31号）收悉。经研究，我局暂不同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）加强已有考古资料的梳理和研究，科学确定保护对象、文物构成，馆藏文物保护不宜纳入本规划内容。明确塔子城的历史沿革及其在辽金时期城市体系中的价值，说明历史河道与护城河、辽塔与城址的关系，补充“城防遗址”、“民族迁徙”的依据，客观归纳文物的艺术价值、社会价值。

（二）进一步分析城址与周边环境的保存现状，明确城内建筑遗址、街道格局、周边辽金墓葬等分布、保存情况，针对不同病害类型分级分类进行评估，并归纳评估结论。客观评价城址开放利用前景、塔子城镇建设情况和文物保护管理现状，补充塔子城镇人口数量、规划范围内用地性质和规模、建设发展强度等，为制定规划措施提供依据。

（三）应根据文物分布和保存现状，进一步调整保护区划，重视城内道路、水系和重要建筑遗址的整体保护，城址西北部已发掘区域应纳入保护范围。应综合考虑塔子城镇建设发展需要，尽量引导村镇在城址外建设发展，细化建设控制地带的具体建设控制指标，合理调控城址内居民生产生活和基础设施建设，增强可操作性。

（四）调整保护措施，坚持最小干预原则，不宜过度强调城墙保护，补充城址内重要建筑遗址等保护措施，充分论证设置隔离防护网的必要性和可行性。

（五）深化考古工作规划，以城市考古思路明确近期考古工作任务，重点明确城址布局和古代衙署的具体位置，不宜仅关注城墙、城门遗址。

（六）完善专项规划内容。应补充社会居民调控、基础设施调整等专项规划，结合塔子城镇建设发展定位，明确城址内现有居民、建构筑物、产业、基础设施等管理和调控措施，统筹处理遗址保护与城镇建设、居民生产生活之间的关系。

（七）加强塔子城址保护规划与塔子镇总体规划、历史名城保护规划等的衔接。核定所引用相关法规的适用范围及时效性。

（八）应进一步简化文本，凝练规划策略、任务等，描述性内容应纳入规划说明。文本内容应简洁、严谨、客观，避免单纯罗列数据资料。补充考古剖面图、辽塔实测图、塔子城历史格局研究图、防洪专项规划等。

二、请你局指导有关单位根据上述意见对塔子城址保护规划进行修改完善，按程序另行报批。

专此函复。

国家文物局办公室

2019年2月19日
