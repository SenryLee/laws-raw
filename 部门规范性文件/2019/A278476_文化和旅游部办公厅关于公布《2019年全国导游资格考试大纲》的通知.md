# 文化和旅游部办公厅关于公布《2019年全国导游资格考试大纲》的通知

办市场发〔2019〕94号

各省、自治区、直辖市文化和旅游厅（局），新疆生产建设兵团文化体育广电和旅游局：

为做好2019年全国导游资格考试工作，现将《2019年全国导游资格考试大纲》予以公布。《2019年全国导游资格考试大纲》电子版可通过文化和旅游部门户网站（www.mct.gov.cn）查看、下载。

特此通知。
