# 农业农村部关于印发2019年国际会议（国际论坛）计划的通知

农外发〔2019〕2号

机关有关司局、派出机构、有关直属单位：

农业农村部2019年外宾30人以上国际会议（国际论坛）计划已经2019年第1次部常务会议审议通过，外宾30人以下国际会议（国际论坛）计划已经计划财务司和国际合作司审核通过，现予印发，请遵照执行。

各单位要按照部党组关于认真贯彻落实中央八项规定精神、大力精简会议论坛活动的要求，严格规范会议经费使用，切实改进会风，提升会议质量和效果。

原则上没有列入计划的会议、论坛一律不得举办。各单位要严格执行会议计划，国际会议（国际论坛）结束后，在2个月内将会议总结报送部国际合作司。

附件：1. 2019年国际会议（国际论坛）计划（需报国务院审批）

2. 2019年国际会议（国际论坛）计划（部常务会审议通过后即可召开）

3. 2019年国际会议（国际论坛）计划（外宾30人以下）

农业农村部

2019年1月30日
