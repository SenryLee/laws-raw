# 交通运输部办公厅关于印发2019年“我的公交我的城”重大主题宣传活动方案的通知

交办政研函〔2019〕1175号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），中国交通报社有限公司，部内各司局：

经交通运输部同意，现将《2019年“我的公交我的城”重大主题宣传活动方案》印发你们，请认真抓好落实，精心组织好各项宣传工作，为新中国成立70周年营造良好的舆论氛围。

交通运输部办公厅

2019年8月14日

## 2019年“我的公交我的城”重大主题宣传活动方案

为深入贯彻落实党的十九大关于开展绿色出行行动的决策部署，按照我部等十二部门和单位联合制定的《绿色出行行动计划（2019—2022年）》中“开展绿色出行宣传”的有关要求，根据我部《2019年全国交通运输行业宣传思想和精神文明建设工作要点》，决定开展2019年“我的公交我的城”重大主题宣传活动。具体内容如下：

一、宣传主题

以习近平新时代中国特色社会主义思想为指导，贯彻落实党中央、国务院决策部署，切实推进绿色出行发展，坚持公共交通优先发展，增加绿色出行方式吸引力，增强公众绿色出行意识，进一步提高城市绿色出行水平。大力宣传新中国成立70年来交通运输行业在推进公交优先、创建公交都市、提升公交服务等方面取得的成就与经验，积极推广公交优先战略的新理念和新举措。结合2019年“绿色出行宣传月和公交出行宣传周”“最美公交司机推选宣传”等主题活动，在全社会广泛倡导“文明交通，绿色出行”良好习惯，为决胜全面建成小康社会、开启全面建设社会主义现代化国家新征程提供更好更优的运输服务保障。

二、总体要求

（一）高度重视，加强组织协调。活动由部政策研究室和运输服务司共同主办，中国交通报社有限公司（以下简称中国交通报社）承办。政策研究室负责制定宣传方案，邀请和组织媒体；运输服务司负责提供相关宣传素材；政策研究室和运输服务司相关负责同志带队采访。中国交通报社负责采访具体组织工作，并通过报纸、新媒体等平台，开设专栏专题，全方位做好宣传工作。地方交通运输部门协助做好相关工作。

（二）明确责任，做好支持保障。各地交通运输部门根据部统一安排，进一步细化实施方案，确保相关宣传活动落到实处。涉及现场采访的地方交通运输部门要高度重视，明确专门机构、安排专人负责，为宣传采访活动提供必要的支持和保障。

（三）创新方式，全方位做好宣传。用好主流媒体、网络媒体，并充分发挥行业媒体舆论宣传主渠道的作用。通过报纸、广播、电视、网站、微博、微信、手机客户端、短视频等全媒体平台，扩大宣传覆盖面和影响力，提高宣传质量。

三、具体安排

（一）组织媒体现场采访并拍摄视频宣传片。综合考虑城市区域、行业规模、发展成就等因素，在全国范围选取3-6座城市，组织中央媒体、行业媒体、地方媒体等组成采访团开展实地采访，挖掘生动人物故事、优秀发展典型等。在采访过程中，拍摄反映各城市公交发展成就、展示活动采访过程的视频宣传片，中国交通报社配合做好相关工作。

（二）组织主题展览，推出活动报道集。活动尾声举办主题展览，宣传展示各地公交发展成就，带动各地公交企业相互交流学习。汇集活动相关报道，图文并茂地展示传播活动成果，进一步宣传“文明交通，绿色出行”理念。

（三）组织“新能源公交高品质线路”推选宣传。活动结束后，在各地选取成熟度高、运营效果显著的新能源公交线路，以推选宣传展示和经验研讨等形式，探寻新能源公交发展成功经验，形成宣传热度不冷却、舆论影响不退场的良好效果。

（四）举办公交发展经验分享会。活动结束后，组织召开公交发展经验分享会，研究推广公交发展的优秀案例和经验成果，探索未来公共交通发展的科学路径。

四、进度安排

（一）准备阶段（2019年9月初）。

1.召开活动协调会，确定采访城市和活动路线，同时举办2018年度“新能源公交高品质线路”推选宣传总结会。

2.相关城市做好准备工作，确定采访点、采访人员、日程安排等，制作采访工作手册。

（二）活动阶段（2019年9月中旬至11月底）。

9月中旬至11月底，组织媒体采访团开展实地采访，从城市形象、政府支持发展公共交通、公交都市创建、新能源公交推广应用等方面进行深入挖掘采访。

（三）公交成就展（2019年10月下旬至2020年5月下旬）。

汇集相关报道，集结成册，图文并茂宣介活动成果。总结历年活动情况，举办主题展览，展示各地公交发展成就。

（四）2019年度“新能源公交高品质线路”推选宣传（2019年10月下旬至2020年5月下旬）。

组织各地推选成熟度高、运营效果显著的新能源公交线路，以推选宣传展示和经验研讨等形式，探寻新能源公交发展成功经验。

（五）公交发展经验分享会（2019年11月下旬至2020年5月下旬）。

组织召开公交发展经验分享会，围绕公交优先发展战略、公交都市创建、新能源汽车推广应用等主题，邀请有关部门同志、专家学者、企事业单位代表与媒体记者共同参与，研究公交发展的优秀案例，推广公交都市创建经验成果，探索未来公共交通发展的科学路径。
