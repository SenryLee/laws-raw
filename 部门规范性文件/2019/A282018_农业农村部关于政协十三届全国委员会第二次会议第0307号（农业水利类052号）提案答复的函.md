# 农业农村部关于政协十三届全国委员会第二次会议第0307号（农业水利类052号）提案答复的函

## 关于政协十三届全国委员会第二次会议第0307号（农业水利类052号）提案答复的函

农办案〔2019〕38号

孙诚谊委员：

您提出的关于加大支持农村劳动力返乡创业创新力度的提案收悉。经商发展改革委、教育部、银保监会和自然资源部，现答复如下。

一、关于营造农村劳动力发展所需人才的良好氛围

近年来，我部积极营造农村所需人才良好氛围，着力加强农民教育培训和农村人才培育。一是开展农民教育培训培育。2014年开始，我部联合财政部，累计安排中央财政资金70.9亿元，以提高生产经营能力和专业技能为目标，重点培训种养大户、家庭农场主、农民合作社骨干、农业社会化服务组织负责人。二是健全教育培训体系。已基本形成公益性培训机构为主体、市场力量和多方资源共同参与的教育培训体系。不断强化各级农广校的主体支撑作用，凝聚农业院校、科研院所、农民合作社、农业企业、农业园区等多种资源，合力推动农民教育培训。三是加大政策扶持力度。我部积极支持高素质农民对接新型农业经营主体扶持政策、享受创新创业扶持政策，鼓励高素质农民带头创办家庭农场、农民合作社等各类新型农业经营主体，发展多种形式的适度规模经营，通过土地流转、产业扶持、财政补贴、金融保险、社会保障、人才奖励激励等政策措施，推进高素质农民和新型农业经营主体“两新”融合、一体化发展。支持高素质农民对接城镇社保政策，在有条件的地方，支持高素质农民参加城镇职工养老、医疗等社会保障，解决农民长远发展的后顾之忧。四是创新教育培训机制。2016年以来，我部会同人力资源社会保障部等部门实施《农民工等人员返乡创业培训五年行动计划（2016—2020年）》，实施“卓越农林人才教育培养计划2.0”，吸引优质生源报考涉农专业，加快推进复合应用型农林人才培养；大力支持高素质农民采取“弹性学制、农学交替”的方式，接受中高等职业教育。对涉农中职专业学生免学费，着力培养高技能人才。五是开展高职扩招专项工作。2019年，我部联合教育部等部门印发《高职扩招专项工作实施方案》，面向退役军人、下岗失业人员、农民工和新型职业农民等群体，大力推进农民学历提升。六是增强培训实效性。不断完善“村庄是教室、村官是教师、现场是教材”的培训模式，注重案例教学，发挥用身边人教育引导身边人的作用。七是支持各类人才到农村投资兴业。2018年，实施《乡村就业创业促进行动》（农加发〔2018〕4号），大力推进培育主体、打造园区、发展特色产业、推动产业融合等重点任务，组织开展“春风行动”“农创客行动”“三乡工程”（市民下乡、能人回乡、企业兴乡）“头雁工程”。

二、关于加快农村土地制度改革

近年来，我部会同自然资源部等部门加快农村土地制度改革，盘活土地资源要素。一是启动农村土地制度改革三项试点。自2012年以来，我部会同有关部门稳步推进农村宅基地管理制度、集体经营性建设用地入市、土地征收制度等改革。2015年，引导33个试点县（市、区）按照“依法公平取得、节约集约使用、自愿有偿退出”的目标要求，围绕盘活闲置房地资源、探索宅基地“三权分置”等开展了探索，形成一批可复制、可推广、利修法的制度创新成果。二是积极促进土地管理法律条款修改。2018年12月，十三届全国人大常委会第七次会议审议了在总结试点经验基础上形成的《土地管理法（修正案草案）》。2019年，在修法基础上全面推开土地征收制度改革和农村集体经营性建设用地入市改革。三是加强乡村产业用地保障。2019年6月，国务院印发了《关于促进乡村产业振兴的指导意见》， 要求在安排土地利用年度计划时，加大对乡村产业发展用地的倾斜支持力度。探索针对乡村产业的省市县联动“点供”用地。目前，我部正会同自然资源部等部门制定《关于促进乡村产业振兴做好农村产业融合发展用地保障的意见》，进一步明确各业各类用地标准和用地保障方式，满足农村产业融合发展用地需求，促进乡村产业振兴。

三、关于进一步培育新产业新业态

近年来，我部高度重视休闲农业、乡村旅游等，不断培育新产业、新业态。一是支持休闲农业发展。2016年，我部联合发展改革委等14部门印发《关于大力发展休闲农业的指导意见》（农加发〔2016〕3号）。2017年，我部印发《关于推动落实休闲农业和乡村旅游发展政策的通知》（农加发〔2017〕15号），要求在用地、财政、金融、服务、品牌、宣传等方面尽快制定实施含金量高，指向性、精准性、操作性强的政策。二是开展休闲农业升级行动。2018年，我部印发《关于开展休闲农业和乡村旅游升级行动的通知》（农加发〔2018〕3号），明确休闲农业和乡村旅游业态、设施、服务、文化、管理升级五项任务，创建全国休闲农业和乡村旅游示范县（市、区）388个，推介中国美丽休闲乡村710个。三是围绕“农业+”做文章。积极推进“农业+”林牧渔，创办林下养鸡、稻田养鱼养虾养蟹等循环农业；推进“农业+”加工流通，创办储藏保鲜、中央厨房、共享农庄等分享型农业；围绕“农业+”文化教育、旅游康养，创办休闲农业、创意农业、教育农园、健康养生等体验式农业；围绕“农业+”特色工艺，发展特色编织、特色手工业等乡土特色产业。四是大力推进农村创新创业。引导农村创新创业在生产两端、农业内外、城乡两头多处发力，带动引领重塑乡村产业形态、推进乡村产业链从低端到高端提升。举办全国农村创新创业项目创意大赛，引导和鼓励返乡下乡人员创办新业态、新模式。

四、关于完善金融扶持方式

近年来，我部和相关部门推动完善金融扶持方式，切实解决融资难、融资贵问题。一是加大返乡下乡创业金融支持。积极协调金融机构创新金融产品、扩大金融供给，着力促进创业就业。2016年，人民银行会同财政部、人力资源社会保障部印发《关于实施创业担保贷款支持创业就业工作的通知》，明确将返乡创业农民工纳入贷款对象范围。2018年，财政部会同人力资源社会保障部、人民银行印发《关于进一步做好创业担保贷款财政贴息工作的通知》，将农村自主创业农民纳入担保贴息政策支持对象范围。二是大力促进返乡创业。2015年，国务院办公厅印发《关于支持农民工等人员返乡创业的意见》，农民工等人员返乡创业，符合政策规定条件的，享受减征企业所得税政策。引导金融机构基于归集的公共信用信息和市场信用信息开发“信易租”等产品，为符合条件的民营企业和小微企业提供无抵押、无担保的纯信用贷款，支持减免租赁办公设备和办公空间租金、押金。三是加强返乡创业与金融对接。国家开发银行、中国农业发展银行设立返乡创业专项贷款。2018年，我部向农业发展银行总行推荐了136个农村创新创业优质项目。

感谢您对“三农”事业发展的关心，希望继续对我部工作给予支持。

农业农村部

2019年8月30日
