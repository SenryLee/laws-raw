# 人力资源社会保障部办公厅关于确定2019年专家服务脱贫攻坚工作项目和国家级专家服务基地的通知

人社厅函〔2019〕64号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局），北京市人才工作局、中共海南省委人才发展局：

为深入贯彻落实中央打赢脱贫攻坚战的重大决策部署，号召组织各类专家助力脱贫攻坚，在各地申报基础上，今年我部遴选确定了60个专家服务团项目和第五批20家国家级专家服务基地（名单附后）。现就有关事项通知如下。

一、围绕脱贫攻坚组织实施好服务团项目。各地要严格按照确定的主题组织实施服务团活动。要围绕脱贫需求，精心设计活动内容，组织邀请对口专家。要认真细致做好专家与基层单位的对接，为专家助力脱贫攻坚提供必要的工作生活保障。要结合当地特点，丰富服务形式，提升扶贫的针对性、精准性，确保活动质量。要发挥桥梁纽带作用，促进贫困地区群众和专业技术人员与专家建立长期联系，发挥服务团的长效作用。

二、进一步加强国家级专家服务基地建设。各地要及时通知基地依托单位，按照申报的建设方案，尽快启动国家级专家服务基地建设工作。人社部门、人才管理部门要加强工作指导和管理监督，不断健全完善基地各项管理办法和运行机制，充分发挥基地在承载服务活动、助力脱贫攻坚中的重要依托作用。基地作为平台纽带，在组织好服务活动的同时，要有计划地联系一批当地脱贫攻坚急需的专家，储备人才资源，发挥平台效应。

三、严格按照财务规定用好活动经费。人社部对每个服务团项目和每家基地分别给予10万元和20万元经费支持。各地要认真贯彻落实中央有关要求，按照批准的计划开展工作，确保经费专款专用，提高资金使用效益。经费执行中，要严守财政资金相关管理规定。资金未使用完的，要做出专项说明，并将结余经费退回我部。

四、加大宣传力度营造良好氛围。我部在《中国组织人事报》设立专栏，宣传奋战在脱贫一线的专家。各地要及时发现总结工作中的好经验好做法、专家中的先进典型，掌握贫困地区脱贫的新进展，体察贫困地区群众的新风貌。通过多种形式宣传专家助力脱贫攻坚工作的成效经验，宣传广大专家无私奉献的先进事迹，宣传贫困地区的崭新面貌，营造良好舆论氛围，不断提高专家服务活动的社会影响力，号召组织更多专家助力脱贫攻坚。

各单位要充分认识专家人才对于打赢脱贫攻坚战的特殊重要性，提高政治站位，增强责任担当，切实组织实施好今年的服务团项目，建设好国家级专家服务基地。活动结束或基地建设初步完成后，请即报送工作总结，2019年12月1日前，请将活动开展和基地建设工作总结及经费决算报告报我部留学人员和专家服务中心。
