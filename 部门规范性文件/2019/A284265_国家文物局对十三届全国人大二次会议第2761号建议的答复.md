# 国家文物局对十三届全国人大二次会议第2761号建议的答复

文物保函〔2019〕579号

孙维代表：

您提出的“关于将西安建设成为世界城市遗址之都的建议”收悉，现答复如下：

西安历史文化遗产丰富，是1982年国务院批准的首批历史文化名城，有“天然历史博物馆”之称。全市有各级文物保护单位近四百处，秦始皇陵兵马俑、汉长安城未央宫遗址、唐长安城大明宫遗址、大雁塔、小雁塔、兴教寺塔等六处遗产被列入《世界遗产名录》，是我国重要的遗产分布密集区域之一。

国家文物局高度重视西安文化遗产的保护利用工作。自“十一五”国家设立大遗址保护专项以来，西安片区作为大遗址保护的重点区域，对其支持力度不断加大。2010年，国家文物局与陕西省人民政府签署《合作共建彰显华夏文明历史文化基地框架协议》。2011年、2013年，国家文物局与陕西省人民政府联合召开了两次合作共建汉长安城国家大遗址保护特区工作会议。党的十八大以来，国家文物局积极支持西安市人民政府结合大西安发展规划实施，持续推进西安市文化遗产保护工作，取得显著成效。汉阳陵、秦始皇陵、大明宫、汉长安城未央宫等4处大遗址被国家文物局评定为国家考古遗址公园；陕西历史博物馆、秦始皇兵马俑博物馆、西安碑林博物馆、西安博物院、西安大唐西市博物馆被评定为国家一级博物馆，西安的文化遗产已经成为城市对外宣传的重要窗口和展示平台。

您提出的关于将西安建设成为“世界城市遗址之都”的建议对西安文化遗产保护工作具有重要的参考意义。国家文物局将与陕西省、西安市人民政府及有关部门一起，继续做好如下工作：

第一，指导西安市人民政府按照中办、国办《关于加强文物保护利用改革的若干意见》的要求，创新文物资源管理机制，建立文物安全长效机制，严格落实文物保护的主体责任。同时，切实加强文物基础工作，加强机构队伍建设，结合推进“多规合一”和全域旅游示范市创建工作，将文物保护要求纳入大西安建设发展战略，充分发挥文物资源在“一带一路”建设和大西安发展中的重要作用。

第二，支持西安市人民政府继续做好西安片区大遗址保护和汉阳陵、秦始皇陵、大明宫、汉长安城未央宫等国家考古遗址公园的运营管理工作，继续推动丰镐遗址、阿房宫遗址等大遗址保护项目，支持社会力量依法依规合理利用文物资源，提供多样化多层次的文化产品与服务，让大遗址和国家考古遗址公园成为西安市最具文化特色和吸引力的城市公共文化活动空间。

第三，引导地方人民政府研究明确“世界城市遗址之都”的概念和内涵，科学论证将西安建设成为“世界城市遗址之都”的必要性与可行性，特别是要结合西安市文物分布面积大、类型多、整体管理难度较大的具体特点，精准定位，积极促进文化遗产保护与城市社会经济的协调发展。

感谢您对文物事业的关心和支持。

国家文物局

2019年6月21日
