# 海关总署公告2019年第123号——关于扩大俄罗斯小麦输华产区的公告

## 海关总署公告

2019年第123号

## 关于扩大俄罗斯小麦输华产区的公告

根据我国相关法律法规和《中华人民共和国海关总署与俄罗斯联邦农业部关于〈俄罗斯小麦输华植物检疫要求议定书〉补充条款》规定，增加俄罗斯库尔干州小麦输华，有关检验检疫要求按原质检总局2018年第25号公告执行。

本公告自发布之日起实施。

海关总署

2019年7月25日
