# 国家药品监督管理局公告2019年第40号——关于批准注册97个医疗器械产品公告

## 国家药品监督管理局公告

2019年第40号

## 关于批准注册97个医疗器械产品公告

2019年4月，国家药品监督管理局共批准注册医疗器械产品97个。其中，境内第三类医疗器械产品52个，进口第三类医疗器械产品26个，进口第二类医疗器械产品18个，港澳台1个（具体产品见附件）。

特此公告。

附件：2019年4月批准注册医疗器械产品目录

国家药监局

2019年5月20日
