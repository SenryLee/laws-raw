# 应急管理部办公厅关于注销云南安科安全技术有限公司安全评价机构甲级资质的复函

应急厅函〔2019〕432号

云南省应急管理厅：

你厅《关于申请注销云南安科安全技术有限公司评价资质的请示》（云应急函〔2019〕193号）收悉。经研究，现函复如下：

依据《安全评价检测检验机构管理办法》（应急管理部令第1号）第十四条规定和《应急管理部办公厅关于加快推进安全监管监察系统所属安全评价机构转企改制或脱钩的通知》（应急厅函〔2018〕208号）要求，同意注销云南安科安全技术有限公司的安全评价机构甲级资质。

请你厅做好收回该单位安全评价机构甲级资质证书（证书编号：APJ-（国）-350）等工作。

应急管理部办公厅

2019年7月11日
