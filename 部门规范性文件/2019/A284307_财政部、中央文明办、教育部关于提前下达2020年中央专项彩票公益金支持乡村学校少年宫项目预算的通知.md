# 财政部、中央文明办、教育部关于提前下达2020年中央专项彩票公益金支持乡村学校少年宫项目预算的通知

## 财政部　中央文明办　教育部关于提前下达2020年中央专项彩票公益金支持乡村学校少年宫项目预算的通知

财教〔2019〕171号

各省、自治区、直辖市财政厅（局）：

为支持各地加强乡村学校少年宫项目，现提前下达2020年中央专项彩票公益金支持乡村学校少年宫项目预算，用于修缮装备补助和运转经费补助（政府收支分类科目：2296004 用于教育事业的彩票公益金支出，项目代码：Z175050040001）。具体项目名称及金额详见附件，请会同同级文明办和教育部门根据中央财政下达的项目预算补助额度确定分配方案。修缮装备补助，根据乡村学校少年宫的建设规模、服务学生数量等，在纳入当年新建乡村学校少年宫名单范围内统筹安排；运转经费补助，根据乡村学校少年宫的工作实绩和管理水平确定分配方案。资助的设备、社会公益活动等应加上“彩票公益金—中国福利彩票和中国体育彩票”标识。请按照《财政部关于印发<中央对地方专项转移支付管理办法>的通知》（财预〔2015〕230号）要求，做好预算编制、指标安排等相关工作，加强资金监督管理。

经审核，原则同意你省（自治区、直辖市）报送的区域绩效目标。如需对绩效目标进行调整的，请将调整文件报送财政部、中央文明办、教育部备案并抄送财政部各地监管局。为进一步加强全过程预算绩效管理，切实提高财政资金使用效益，请在组织预算执行中对照你省（自治区、直辖市）区域绩效目标做好绩效运行监控和绩效评价，确保年度绩效目标如期实现。同时，请参照中央做法，将绩效目标及时对下分解，做好绩效管理工作。
