# 国家药品监督管理局公告2019年第35号——国家药监局关于注销医疗器械证书的公告

## 国家药品监督管理局公告

2019年第35号

## 国家药监局关于注销医疗器械证书的公告

按照《医疗器械注册管理办法》的规定，根据企业申请，现注销Thermo Fisher Scientific Oy公司的国械注进20152401925的洗板机、国械注进20152401926的酶标仪；上海澳华光电内窥镜有限公司的国食药监械（准）字2014第3221659号的上消化道电子内窥镜、国食药监械（准）字2014第3221660号的结肠电子内窥镜；上海金塔医用器材有限公司的国械注准20153660220的一次性使用输血器 带针的医疗器械注册证书。

特此公告。

国家药监局

2019年4月28日
