# 国家文物局关于北齐长城东大云疃山险保护区划内张北——雄安1000KV特高压交流输变电工程包3段建设项目的意见

文物保函〔2019〕457号

河北省文物局：

你局《关于呈报张北——雄安1000KV特高压交流输变电工程包3段跨越长城设计方案的请示》（冀文物字〔2019〕37号）收悉。经研究，我局原则同意在北齐长城东大云疃山险保护区划内实施张北——雄安1000KV特高压交流输变电工程包3段建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘，如遇有城墙遗存等重要发现，应调整设计方案，确保文物安全。

（二）应优化拟建铁塔选址，尽可能将3S071号铁塔选址移至东大云疃山险建设控制地带以外，以降低其对长城景观风貌的负面影响。

（三）应补充拟建项目施工方案，细化3S070、3S071号铁塔基础开挖施工要求，明确振动控制、施工组织及监测预警措施，施工区域应尽量远离长城遗存。

（四）应补充拟建项目施工期间的长城本体临时性保护措施、应急预案，以及极端天气条件下防止输电线路威胁长城安全的保护措施。

（五）应补充施工后期的环境修复措施，并结合项目实施适当设置长城保护标志、保护界桩和警示标识。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月17日
