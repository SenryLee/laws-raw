# 水利部办公厅关于印发生产建设项目水土保持方案审批等4项政务服务事项服务指南和工作细则的通知

办政法〔2019〕222号

部机关有关司局，信息中心，各流域管理机构：

为落实《中共水利部党组关于在“不忘初心、牢记使命”主题教育中开展专项整治的工作方案》和《水利部办公厅关于开展“不忘初心、牢记使命”主题教育行政审批和行政执法专项整治的通知》要求，我部对生产建设项目水土保持方案审批、国家基本水文测站设立和调整审批、河道管理范围内建设项目工程建设方案审批、河道管理范围内有关活动（不含河道采砂）审批4项政务事项的服务指南和工作细则重新梳理，现予以印发，并于2019年11月1日起执行，《水利部办公厅关于印发水利部政务服务事项服务指南和工作细则的通知》（办政法[2019]135号）中上述4项有关内容废止。

2019年10月31日前，请信息中心、各流域管理机构分别完成部机关和本流域政务服务事项的服务指南和工作细则更新工作，印制新的服务指南投放实体服务大厅；信息中心配合做好服务指南、工作细则在水利部在线政务服务平台的更新工作；有关司局、信息中心、各流域管理机构做好更新后相关准备工作。

水利部办公厅

2019年10月30日
