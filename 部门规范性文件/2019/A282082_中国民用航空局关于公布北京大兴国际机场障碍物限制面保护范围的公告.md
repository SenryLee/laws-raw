# 中国民用航空局关于公布北京大兴国际机场障碍物限制面保护范围的公告

## 关于公布北京大兴国际机场障碍物限制面保护范围的公告

为了预防无人机等升空物体侵入民用机场障碍物限制面区域，降低无人机对机场飞行安全和运行效率的影响，促进电子围栏系统及类似技术的应用，现公布北京大兴国际机场障碍物限制面保护范围（见附件）。

各类飞行活动应当遵守国家相关法律法规和民航规章规范要求，遵守相关禁限飞通告要求，未经特殊批准不得进入民用机场障碍物限制面保护范围，在障碍物限制面保护范围外的飞行亦不得影响民航运行的安全与效率。

附件：北京大兴国际机场障碍物限制面保护范围

中国民用航空局

2019年9月20日
