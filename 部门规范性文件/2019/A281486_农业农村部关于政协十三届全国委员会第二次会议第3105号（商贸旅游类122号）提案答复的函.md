# 农业农村部关于政协十三届全国委员会第二次会议第3105号（商贸旅游类122号）提案答复的函

## 关于政协十三届全国委员会第二次会议第3105号（商贸旅游类122号）提案答复的函

农办案〔2019〕100号

杨建平委员、王侠委员：

你们提出的关于建设全国电商扶贫一体化服务平台的提案收悉。现就涉及我部职能的部分答复如下。

2018年，中共中央办公厅、国务院办公厅印发《乡村振兴战略规划（2018—2022年）》，提出要把打好精准脱贫攻坚战作为实施乡村振兴战略的优先任务，深入实施精准扶贫精准脱贫，重点攻克深度贫困，巩固脱贫攻坚成果。2019年中央一号文件提出"聚焦精准施策，决战决胜脱贫攻坚"的目标任务，为坚决打赢脱贫攻坚战、全面推进乡村振兴指明了方向。近年来，农业农村部贯彻落实党中央、国务院部署要求，会同有关部门积极推动贫困地区农业特色产业发展，产业扶贫取得了明显进展和成效，与你们提出的建立长期稳定的供销关系、提升贫困地区农产品供给水平等建议十分契合。

一、关于提升贫困地区农产品供给水平

我部会同国务院扶贫办、发展改革委、财政部等有关部门坚持大扶贫格局，贯彻精准扶贫方略，强化产业扶贫，探索建立稳定脱贫长效机制。印发《关于加大贫困地区项目资金倾斜支持力度促进特色产业精准扶贫的意见》《支持深度贫困地区农业产业扶贫精准脱贫方案》等文件，加大农业项目资金向贫困地区倾斜支持力度，加大农业生产基础设施建设，强化科技服务和人才培训，促进农业生产标准化、规模化、产业化发展，引导建立贫困地区特色产业体系。今年我部将出台《乡村特色产业发展规划（2019—2025年）》，进一步明确乡村特色产业的内涵，提出当前推进乡村特色产业发展的重点任务、区域布局等。特别是对于贫困地区，通过培育壮大适宜且能带动贫困户长期稳定增收的优势特色产业，加大对贫困地区特色产业生产、加工、流通设施装备条件建设支持力度，推进贫困地区特色产业融合发展。通过加强规划引导，指导包括贫困地区在内的各地有序开发特色优势资源，做大做强乡村特色产业，助力乡村振兴。

下一步，我部将会同有关部门继续落实党中央、国务院决策部署，制定和完善扶贫产业发展规划，因地制宜加快发展对贫困地区增收带动作用明显的农业特色优势产业，助力乡村振兴战略实施。

二、关于建立长期稳定的供销关系

我部相继印发《贫困地区农产品产销对接实施方案》《关于做好2019年贫困地区农产品产销对接工作的通知》，与中央和国家机关工委等10部门发出《贫困地区农产品产销对接行动倡议书》，组织开展了全国贫困地区农产品产销对接行动等系列活动。2018年我部牵头举办了7场产销对接活动，全国四分之三以上贫困县参与，现场签约金额超过190亿元。大力支持电商企业积极参与贫困地区农产品产销对接行动，组织实施"庆丰收全民购物节",采取了电商直播等新模式，直接带动贫困地区在内的农村优质特色农产品上网销售额超过200亿元。组织开展"110"网络扶贫创新活动，通过自愿申报、专家遴选等方式，确定10个核心示范县，辐射带动100个县，围绕贫困地区特色产业和特色资源，利用电商直播等新模式，促进贫困地区特色农产品销售，宣传当地乡村旅游、文化资源，打造特色品牌。

下一步，我部将会同有关部门，组织电商企业等各类市场主体，拓展网络销售新渠道，创新探索网络销售新模式，让农产品产销顺畅衔接，实现优质优价。

三、关于规划贫困地区农特产品流通渠道

一是组织开展"互联网+"农产品出村进城工程。为贯彻落实2019年中央1号文件和国务院常务会议精神，我部正在推动实施"互联网+"农产品出村进城工程， 积极引导涉农电商企业、龙头企业、农民合作社等社会主体参与，建立完善适应农产品网络销售的供应链体系、运营服务体系和支撑保障体系，推动构建以市场为导向的现代农业产业体系、生产体系、经营体系，促进农产品顺畅衔接、优质优价。二是加强农产品产地市场体系建设。我部高度重视农产品产地市场体系建设，先后印发了《全国农产品产地市场发展纲要》《关于进一步加强农产品市场体系建设的指导意见》《全国农产品市场体系发展规划》等系列文件，开展田头市场示范点建设，推动加强集货、储藏、商品化处理等基础设施建设，辐射带动产业发展，初步形成产地、集散地与销售地相衔接的农产品产地市场体系。截至目前，已在河北、海南、云南等省份支持建设了53个田头市场示范点，启动建设了洛川苹果、舟山水产、赣南脐橙、重庆生猪、斗南花卉、眉县猕猴桃等13个全国性农产品产地市场。

下一步，我部将会同有关部门，积极推动"互联网+"农产品出村进城工程加快落地实施，指导做好农产品产地市场体系建设，加快补齐农村流通设施短板，完善农村电商公共服务体系，助力乡村振兴。

四、关于加强市场研究和监测

我部高度重视农业农村大数据、农业信息监测预警工作，强化信息资源整合，加快推动用数据决策指挥、用数据管理服务、用数据引导产销。积极推进粮、棉、油、糖、畜禽产品、水产品、蔬菜、水果8大类15个重点农产品全产业链大数据试点，以重点品种全产业链数据的采集、分析、发布、服务为主线，形成了数据采集、数据分析和数据服务机制，建立"一网打尽"式市场信息发布服务窗口，为农业生产经营主体和公众提供权威、全面、及时、有效的市场信息服务。创新完善农业监测预警体系，每日发布农产品批发价格200指数，每月发布19种重点农产品市场供需报告和5种重点农产品供需平衡表，每年举办农业展望大会并发布展望报告。初步建成国家农业数据平台，整合建立农产品质量安全追溯、农兽药基础数据、重点农产品市场信息、新型农业经营主体信息直报等"四平台",提高了农业生产管理、指挥调度等数据支撑能力，提高了生产经营的科学决策能力。

下一步，我部将继续推动数字农业农村发展，加快农业农村大数据建设，用信息技术助力农业转型升级、增产增收，为电商扶贫提供更好更全面支撑。

五、关于农村电商人才培育

党中央、国务院一直高度重视农业农村人才队伍建设，我部会同有关部门大力推动农民职业教育和专业人才队伍建设。一是完善实用人才培养机制，提升信息化应用水平。我部会同中共中央组织部大力开展农村实用人才带头人和大学生村官示范培训，将示范培训重点面向贫困地区，重点聚焦"三区三州"等深度贫困地区产业发展带头人和农村基层组织负责人，并将电子商务培训纳入农村实用人才培训计划，用精准培训支撑精准扶贫。截至目前，累计举办示范培训班1000余期，共培训11.5万余人，培养了100万名具有中专学历的农村实用人才。我部专门举办了五期农业农村电子商务专题培训班，来自20个省份的新型农业经营主体负责人、益农信息社信息员、返乡下乡创业人员参加了培训。二是大力开展手机应用技能培训。2015年我部在全国启动农民手机应用技能培训，组织各地农业农村部门和有关企业，线上线下相结合，采用农民喜闻乐见的方式，切实提高广大农民运用手机查询信息、网络营销、获取服务、便捷生活的能力。每年举办全国农民手机应用技能培训周活动，同时上线运行培训平台和APP,聚合各类培训资源，让农民通过手机轻松学习。2018年农民手机培训受众人次超过1000万。

下一步，我部将继续坚定不移地推进人才强农战略，指导各地统筹加强本土人才培育和鼓励引导各类人才下乡，加大农业电子商务等信息化应用技能的培训力度，为乡村振兴和脱贫攻坚提供人才支撑。

感谢对电商扶贫工作的关心，希望今后继续对我部工作给予支持。

农业农村部

2019年8月30日
