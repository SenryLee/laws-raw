# 国家文物局办公室关于省级文物保护单位碧村遗址保护范围内山西静乐丰润至兴县黑峪口高速公路建设项目的意见

办保函〔2019〕245号

山西省文物局：

你局《关于山西静乐丰润至兴县黑峪口高速公路建设项目以隧道形式穿越省级文物保护单位碧村遗址的请示》（晋文物〔2019〕15号）收悉。经研究，我局暂不同意在省级文物保护单位碧村遗址保护范围内实施山西静乐丰润至兴县黑峪口高速公路建设项目。

碧村遗址已申报第八批全国重点文物保护单位，且已纳入“考古中国”重大研究项目，具有重要的历史、艺术和科学价值。请你局组织有关单位进一步明确项目建设穿越碧村遗址保护范围的必要性，调整项目选线，避让遗址保护范围。

专此函复。

国家文物局办公室

2019年4月3日
