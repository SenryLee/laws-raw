# 中华人民共和国海关总署对十三届全国人大二次会议第6768号建议的答复

林毅代表：

您提出的《关于继续加大支持力度推动“义新欧”中欧班列高质量发展的建议》（第6768号）收悉。就“（五）建议海关总署支持的事项”，经研究，现答复如下：

一、支持义乌探索内陆新型海关监管模式，研究设立适应国际陆港发展和贸易新业态新模式的内陆新型口岸，并赋予相关管理权限和职能

关于设立内陆新型口岸问题，根据《国务院关于口岸开放管理工作有关问题的批复》（国函〔2002〕14号）规定，口岸是供人员、货物、物品和交通工具直接出入国（关、边）境的港口、机场、车站、跨境通道等。义乌铁路货运集装箱场站不是直接进出境的场所，目前不能作为口岸对外开放。为支持内陆地区开放型经济发展、推进“一带一路”建设，2015年印发的《国务院关于改进口岸工作支持外贸发展的若干意见》（国发〔2015〕16号）明确提出了“支持在国际铁路货物运输沿线主要站点和重要内河港口合理设立直接办理货物进出境手续的查验场所”。“直接办理货物进出境手续的查验场所”为内陆地区货物进出境提供了较大通关便利，建议地方政府充分利用这一政策以满足国际贸易发展需要。

关于支持义乌“市场采购”贸易新业态监管模式，2014年以来，我署即积极采取多项措施支持义乌贸易新业态发展：一是发布《关于市场采购贸易监管办法及其监管方式有关事项的公告》（海关总署公告2014年第54号），指导杭州海关出台《杭州海关义乌市场采购贸易海关监管办法实施细则(试行)》(杭关监发〔2014〕277号)等文件，为义乌小商品出口量身定制“市场采购（0139）”海关通关监管模式；二是根据市场采购贸易商品小批量、多品种、低价值的特点，创新实施简化申报以及分类管理等制度，提升对义乌小商品出口监管的有效性；三是积极支持参与地方政府管理，共同促进义乌小商品出口的规范发展。2018年，义乌市场采购出口50.3万票、95.6万标箱、311亿美元，同比分别增长15.5%、15.9%、10.7%。下一步，围绕义乌开放发展的新需求，我署将加强对市场采购贸易新业态的调研，进一步完善市场采购海关监管规章制度，支持义乌国际贸易综合改革试验区建设和发展。

二、支持义乌探索“保税+陆港+多平台”的新型区港联动开发模式，建设业态高端多元、功能布局完善、服务优质高效的内陆示范引领型保税港区

我署一直重视和支持浙江省开放型经济发展，积极支持浙江省利用海关特殊监管区域作为推动对外开放的重要抓手。关于建议中提出的新型区港联动开发模式，我署原则支持，具体问题将积极配合地方进一步研究论证。

根据《国务院关于促进海关特殊监管区域科学发展的指导意见》（国发〔2012〕58号）要求，新设海关特殊监管区域统一为综合保税区，且应符合有利于实施国家区域发展战略规划、有利于中西部地区承接产业转移、有利于海关特殊监管区域整合优化以及确实有外向型大项目亟待进驻的原则。同时，国务院已不再新设保税港区。如确有必要新设综合保税区，建议请浙江省政府按照《综合保税区审核设立指导意见》的有关要求，做好规划论证和申建基础工作，待条件成熟时请示国务院，我署将会同相关部门予以积极支持。

2019年1月，国务院印发了《关于促进综合保税区高水平开放高质量发展的若干意见》（国发〔2019〕3号），从完善政策、创新监管、拓展功能等方面提出21项促进综合保税区升级发展的改革任务和政策举措，并提出将综合保税区建设成为新时代全面深化改革开放的新高地。希望当地政府重视现有综合保税区的建设和发展，进一步提升发展质量，在开放型经济中发挥更大作用。我署将积极支持地方探索，指导当地海关做好监管和服务工作。

感谢对海关工作的关心与支持，并欢迎继续对我们的工作提出宝贵的意见和建议。

海关总署

2019年6月10日
