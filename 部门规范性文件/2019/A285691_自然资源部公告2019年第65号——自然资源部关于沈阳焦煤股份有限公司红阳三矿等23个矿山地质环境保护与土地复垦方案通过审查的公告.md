# 自然资源部公告2019年第65号——自然资源部关于沈阳焦煤股份有限公司红阳三矿等23个矿山地质环境保护与土地复垦方案通过审查的公告

## 自然资源部公告

2019年第65号

## 自然资源部关于沈阳焦煤股份有限公司红阳三矿等23个矿山地质环境保护与土地复垦方案通过审查的公告

自然资源部

2019年12月31日
