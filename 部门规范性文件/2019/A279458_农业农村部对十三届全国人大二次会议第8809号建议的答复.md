# 农业农村部对十三届全国人大二次会议第8809号建议的答复

## 对十三届全国人大二次会议第8809号建议的答复

农办议〔2019〕33号

吴端华等5名代表：

你们提出的关于加快大唐华银株洲发电有限公司2×100万千瓦煤电项目搬迁发展的建议收悉。现就涉及我部职能的部分答复如下。

大唐华银株洲发电有限公司2×100万千瓦煤电项目配套码头和取水工程项目涉及湘江株洲段鲴鱼国家级水产种质资源保护区（以下简称“保护区”）实验区。保护区位于湘江干流王十万至渌口象石段和支流渌水仙井乡至渌口镇关口，主要保护对象为细鳞斜颌鲴、黄尾鲴、鳊鱼等。

根据《水产种质资源保护区管理暂行办法》，我部已组织专家对《大唐华银株洲发电有限公司2×100万千瓦煤电项目配套码头和取水工程项目涉及湘江株洲段鲴鱼国家级水产种质资源保护区影响专题论证报告》（以下简称《论证报告》）进行审查。专家审查认为该项目占用保护区岸线500余米，影响保护区实验区水域面积超过8000平方米。该项目的施工及后续运营会改变工程附近水域的水文、水温、水质，产生的振动、噪声以及悬浮物扩散将对保护区水生生物资源产生负面影响。专家建议补充完善该项目的立项依据和必要性以及项目与生态保护红线的相符性分析。

目前，报告编制单位正在根据专家意见抓紧修改完善《论证报告》。我部将严格按规定做好相关工作，履行好水生生物保护职责。

感谢对长江水生生物保护工作的长期关心和重视，希望今后继续对我部工作予以支持。
