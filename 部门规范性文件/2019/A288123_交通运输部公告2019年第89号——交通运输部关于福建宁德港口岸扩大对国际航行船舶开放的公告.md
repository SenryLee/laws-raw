# 交通运输部公告2019年第89号——交通运输部关于福建宁德港口岸扩大对国际航行船舶开放的公告

## 交通运输部公告

2019年第89号

## 交通运输部关于福建宁德港口岸扩大对国际航行船舶开放的公告

中央编办，国务院办公厅，发展改革委，公安部，财政部，商务部，海关总署，移民局，军委联合参谋部，福建省人民政府，福建省口岸办，福建海事局，中国交通报，中国水运报:

根据《国务院关于同意福建宁德港口岸扩大开放的批复》(国函〔2016〕139号)和《海关总署关于印送福建宁德港口岸扩大开放验收纪要的函》（署岸函〔2019〕418号），交通运输部决定自本公告之日起，福建宁德港口岸扩大对国际航行船舶开放。具体开放范围由福建海事局按程序对外公布。

特此公告。

交通运输部

2019年12月6日
