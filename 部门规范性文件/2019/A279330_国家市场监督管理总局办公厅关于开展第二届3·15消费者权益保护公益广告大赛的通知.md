# 国家市场监督管理总局办公厅关于开展第二届3·15消费者权益保护公益广告大赛的通知

## 市场监管总局办公厅关于开展第二届3·15消费者权益保护公益广告大赛的通知

各省、自治区、直辖市及计划单列市、副省级城市、新疆生产建设兵团市场监管局（厅、委）：

为深入贯彻党的十九大和十九届二中、三中全会精神，结合“不忘初心、牢记使命”主题教育活动，围绕传播消费维权理念、提振消费信心、促进消费升级的总体目标，进一步提升消费者科学消费、依法维权能力，增强经营者诚信守法履约意识，强化市场监管部门为民服务宗旨，营造全社会共同保护消费者合法权益的良好氛围，市场监管总局决定面向全国市场监管部门和社会各界开展“第二届3·15消费者权益保护公益广告大赛”。

各地市场监管部门要高度重视，积极组织本地区的作品报送，抓住活动契机加大消费教育引导宣传力度，提升消费维权工作的社会知晓度、参与度和认可度。鼓励各地市场监管部门自行或者与放心消费创建示范单位、广告影视公司、广播电视台、高等院校等联合创作新作品，也可以报送现有的作品。

市场监管总局联系人：李希盛，联系电话：010-88650735。

中国广告协会联系人：储方圆，联系电话：010-59725149。

## 活动方案

一、活动名称

市场监管总局第二届3·15消费者权益保护公益广告大赛

二、组织机构

主办单位：国家市场监督管理总局

承办单位：网络交易监督管理司

执行承办：中国广告协会

三、活动目的

宣传普及《消费者权益保护法》《市场监管投诉举报处理办法》等法律法规，提升消费者知法、懂法、用法能力；宣传市场监管部门投诉举报“五线合一”工作，打造12315品牌；培育经营者提升商品服务品质的意识，不断优化消费环境，推动消费升级；披露侵害消费者权益的典型行为和新问题，开展消费提示警示，提高消费者防范风险能力；加强消费教育引导，倡导消费者科学消费、理性消费、绿色消费、健康消费的理念与习惯；展现各地消费维权工作成果和良好形象，激发市场监管干部职业自豪感和荣誉感；推进社会共治，进一步营造全社会共同保护消费者合法权益的氛围。

四、创作方向

1. 五线合一 守护您身边

2. 投诉举报 就打“12315”

3. 品质消费 信用护航

4. “12315” 天天315

5. 您身边的消费陷阱

6. 您手中的维权利器

7. 消费投诉公示 擦亮您的双眼

8. 放心消费创建 共享美好生活

五、活动赛程

（一）作品征集

时间：2019年6月31日—2019年8月15日。

（二）作品评审

初审时间：2019年8月中旬。

终审时间：2019年8月下旬。

评审形式：初审线上评审、终审线下现场集中评审。

（三）颁奖仪式

颁奖时间：2019年10月下旬“中国国际广告节”

颁奖地点：江西南昌

传播效果：1. 中央电视台新闻联播报道；省级、市级电视台新闻报道（如：广东卫视、江西卫视、南昌市电视台等）。2. 腾讯、网易等知名互联网平台全程网络直播。

六、参赛对象

全国市场监管部门（单位及个人）；高等院校学生及社团；企业（广告主）；广告经营单位（媒体公司、设计公司、广告公司等）；广播电视台；热心公益的社会组织及个人。

参与本次大赛评选的工作人员，不得参加比赛。

七、参赛作品分类

A 影视类：适合各类视频终端播放的短片、动漫等。

B 平面类：适合报纸、宣传栏、宣传画、电子屏等静态展示的作品。

C 广播类：适合广播电台等音频终端播报的作品。

D 移动交互类：主要指APP、H5等在移动客户端或互联网传播的作品。

八、报送作品要求与程序

（一）作品格式要求

|  |  |
| --- | --- |
| 影视类  （A） | 影视类作品格式为MP4，h.264编码，时长不超过120秒（微电影项时长限2-20分钟）；两条影片以上视为系列（含两条），系列作品请按逻辑顺序上传，系统将自动按上传顺序默认排序；同一个作品，可报送不同类项；请务必提供媒体发布证明，参考模板详见报送系统。 |
| 平面类  （B） | 平面类作品格式为JPG，PNG等，不得低于300像素，CMYK色彩模式，5MB以下；两幅以上视为系列（含两幅），系列作品请按逻辑顺序上传，系统将自动按上传顺序默认排序；同一个作品，可报送不同类项；请务必提供媒体发布证明，参考模板详见报送系统 |
| 广播类  （C） | 广播类作品格式为MP3，时长不限；两条音频以上视为系列（含两条），系列作品请按逻辑顺序上传，系统将自动按上传顺序默认排序；请务必提供媒体发布证明，参考模板详见报送系统。 |
| 移动交互类  （D） | 通过视频或者ppt的方式呈现具体的移动交互案例，最好体现出通过互动后所获得的效果，视频文件格式为mp4，h.264编码，大小控制在500M以内，ppt文件务必保存为pdf或者视频文件，系列文件按顺序上传。  可上传作品文件，作品体验链接或者二维码（请保证在评审及展示期间有效） |

（二）报送流程与提交说明

登陆中国国际广告节官网（http://www.china-caa.org/）点击大赛引导标识进入大赛主页面，了解大赛信息，下载活动征稿启事，点击“报名入口”按钮报送作品。（提交作品信息后，系统将自动生成唯一性的报名编号。）

（三）参赛作品要求及说明

1. 参赛作品须符合三方面要求：一是主题鲜明、导向正确、创意独特、语言文字规范、艺术表达得当、文化品位良好；二是制作精良、表现力强、易于传播；三是不违背社会主义核心价值观，不侵犯民族宗教信仰，遵守相关法律法规政策。

2. 参赛作品必须为参赛者原创，作品涉及的名誉权、肖像权、著作权、商标权、名称权等法律问题，均由参赛单位负责承担，参赛作品不得侵犯第三方著作权。

3. 每件参赛作品仅限由一个单位报送，原则上由作品版权单位报送。如其他广告代理公司、制作公司或其他授权单位报名参赛，必须事先征得作品版权单位的同意，若发生版权纠纷，责任由报送单位自负，所获奖项将给予撤销。

4. 凡经组委会审查核实、确认具有抄袭行为的参赛单位或个人，将取消其参赛资格。

5. 不得在报送的广告作品中出现任何参赛单位的相关信息。

6. 活动不收参赛费，曾刊播或获奖作品均可参加本次大赛。每位参赛者报送作品数量不限。但是曾经在首届3·15消费者权益保护公益广告大赛获奖的作品不再接受报送。

（四）注意事项

1. 超大作品需通过ftp客户端上传，参赛者需激活ftp权限。

2. 提交作品前需认真核对，作品确认提交后不可修改。

3. 收到作品恕不送回。市场监管总局、中国广告协会有权对参赛作品进行宣传、展览、编辑、出版、发行并供各地下载使用，不再另行支付稿费。
