# 国家体育总局社体中心关于印发《全国无极球运动教练员等级管理办法（试行）》的通知

## 体育总局社体中心关于印发《全国无极球运动教练员等级管理办法（试行）》的通知

各省、自治区、直辖市、新疆生产建设兵团体育局社体中心（群体处、体总秘书处），各有关单位：

为推动中国无极球运动发展，加强教练员队伍建设和管理，规范教练员行为，评定教练员专业水平，现印发《全国无极球运动教练员等级管理办法（试行）》，请遵照实施。

附件：全国无极球运动教练员等级管理办法（试行）

体育总局社体中心

2019年9月29日
