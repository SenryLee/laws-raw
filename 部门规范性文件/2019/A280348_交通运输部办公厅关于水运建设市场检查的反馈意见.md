# 交通运输部办公厅关于水运建设市场检查的反馈意见

交办水函〔2019〕1071号

云南省交通运输厅、长江航务管理局：

为加强全国水运建设市场监管工作，维护统一开放、竞争有序的市场秩序，推动水运高质量发展，按照《水运建设市场监督管理办法》（交通运输部令2016年第74号）要求以及《2019年交通运输部市场秩序与服务质量检查工作方案》（交办公路函〔2019〕547号）有关安排，2019年6月，部组织检查组分别对云南省、长江航务管理局水运建设市场监管情况以及部分水运工程建设情况进行了抽查。

经交通运输部同意，现将检查意见反馈给你们，请你厅（局）认真对照自查，举一反三、全面整改，整改情况于2019年8月31日前报部。

交通运输部办公厅

2019年7月25日
