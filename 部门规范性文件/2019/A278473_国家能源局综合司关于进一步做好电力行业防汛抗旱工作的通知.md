# 国家能源局综合司关于进一步做好电力行业防汛抗旱工作的通知

国能综通安全〔2019〕47号

各省、自治区、直辖市及新疆生产建设兵团发展改革委（能源局）、经信委（工信委），北京市城管委，国家能源局各派出能源监管机构，大坝中心，全国电力安委会各企业成员单位，各有关单位：

目前，我国已全面入汛，其中南方部分地区发生洪涝灾害，造成大量财产损失和人员伤亡，防汛抗洪进入关健阶段。5月31日，李克强总理就今年防汛抗洪工作作出重要批示，要求加强协调配合，落实责任，防患未然，确保人民生命财产安全。6月5日召开的国务院常务会议再次对全国防汛抗旱工作进行了部署。为深入贯彻落实李克强总理重要批示精神和国务院决策部署，进一步做好电力行业防汛抗旱工作，现就有关事项通知如下。

一、高度重视，认真贯彻党中央、国务院工作要求

各单位要始终坚持以习近平总书记“两个坚持、三个转变”的新时期防灾减灾新理念为指导，深入贯彻落实李克强总理重要批示精神，切实增强“四个意识”，保持思想警觉，看清今年防汛抗旱工作的严峻形势，充分认识抓好汛期电力安全生产的极端重要性，以高度的责任感和使命感，打好防灾减灾这场硬仗，确保电力安全生产形势持续平稳和电力稳定可靠供应。

二、多举并措，扎实做好防汛防洪工作

各单位要严格按照国家防汛抗旱总指挥部和国家能源局工作要求，立足防大汛、抗大旱，切实做好电力行业防汛抗旱和抢险救灾各项工作。一是夯实防汛抗旱责任，加强组织领导，压紧压实各部门、各岗位防汛抗旱责任，细化责任分解，真正将责任落实到具体人员。二是加强相互协调配合，健全与当地政府及相关部门的协调联动，积极主动与抗灾抢险机构队伍联络对接，形成抢险救援合力。三是做细防汛抗洪准备。对前期已发现问题的整改情况进行“回头看”，确保闭环，并进一步排查新形势下防汛安全隐患；储备充足防汛抢险物资设备，确保抗洪抢险应急需要；进一步加强抢险教援实战演练和业务培训，努力提高防汛抢险实战能力和水平。四是强化抗洪应对响应，加强监测预报预警，严格执行经批准的调度运用方案，坚决服从防汛指挥机构的调度指令，严禁超汛限水位运行，严防溃坝、漫坝、水淹厂房等事故，严防山洪、滑坡、泥石流等地质灾害造成的次生灾害。五是细化群众保安措施，要坚持以人为本，时刻把人民群众生命安全放在第一位。针对台风灾害威胁区、山洪灾害易发区、洪涝灾害易淹区等进一步核查和细化人员转移避险方案与安置预案。六是加强值守和信息报送，严格执行领导带班和24小时值班制度，切实增强值班值守力量，严肃值班纪律，保持信息畅通，及时报告电力受灾及应急处置有关情况。

三、严阵以待，切实做好灾害有效应对

各单位要认真做好雨水情影响研判，根据汛情变化及时组织加强巡查，一旦出现险情，立即启动应急响应预案，确保及时高效、科学处置突发情况。加强人身安全防护，严禁极端天气条件下冒险作业，对因责任不落实、工作不到位造成重大险情灾情和人员伤亡的，要严肃追责。各单位要全面提高灾情险情应对成效，筑牢安全防线，全力保障2019年电力行业安全度汛。

国家能源局综合司
