# 自然资源部公告2019年第29号——自然资源部关于河南金源黄金矿业有限责任公司祁雨沟公峪金矿等3个矿山地质环境保护与土地复垦方案通过审查的公告

## 自然资源部公告

2019年第29号

## 自然资源部关于河南金源黄金矿业有限责任公司祁雨沟公峪金矿等3个矿山地质环境保护与土地复垦方案通过审查的公告

根据《土地复垦条例》《矿山地质环境保护规定》等有关规定，河南金源黄金矿业有限责任公司祁雨沟公峪金矿等3个矿山地质环境保护与土地复垦方案通过审查，现予公告。

2019年6月20日

附件：3个通过审查的矿山地质环境保护与土地复垦方案名单
