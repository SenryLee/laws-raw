# 国家邮政局办公室关于十三届全国人大二次会议第4037号建议协办意见的函

## 关于十三届全国人大二次会议第4037号建议协办意见的函

国邮办函〔2019〕196号

教育部办公厅：

现就赵明枝代表提出的“关于建设快递综合服务中心规范高校快递市场的建议”提出如下协办意见：

一直以来，我局高度重视快递服务进校园工作，积极推动快递企业向广大师生提供便捷、高效、优质的校园快递服务。2014年，我局发布了《关于提升快递末端投递服务水平的指导意见》，鼓励企业因地制宜，与连锁商业机构、便民服务设施、社区服务组织、机关学校管理部门以及专业第三方企业开展多种形式的投递服务合作；与学校管理部门合作开展投递服务的快递企业，应当遵守校方关于校园安全管理的有关要求，并确认校方能够提供符合快件投递服务要求的场所。2017年，我局发布了《国家邮政局关于加强和改进快递末端服务管理工作的指导意见》，提出“争取将智能快件箱和末端投递服务中心等设施列入城市基础设施规划，推动党政机关、社区、学校为末端设施安置和末端投递作业提供便利”。

近年来，我局连续将推动快递服务进校园工作列入邮政市场监管工作重点，积极推广各地的先进经验。据各地报送的情况，全国快递服务进校园工作进展良好，但是距离规范化还有很大差距。赵明枝代表提出的“推进建设高校快递综合服务中心，促进快递服务管理集中化、智能化、规范化”“在更多地区、更多校园试点，进一步总结、完善和推广建设校园快递综合服务中心模式”“出台相关政策，并加强行业指导、细化服务标准、规范服务流程”等建议，我局认为是合理可行的。

在今后的工作中，我局将积极配合教育部，继续推进快递服务进校园工作，完善顶层设计，加强行业指导，合力解决高校快递服务工作中遇到的问题，努力为广大师生提供满意的快递服务。
