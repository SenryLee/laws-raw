# 国家文物局关于你区文物行政执法案件入选第三批全国文物行政执法指导性案例的函

文物督函〔2019〕1337号

内蒙古自治区人民政府：

党的十八大以来，习近平总书记高度重视文物工作，多次就文物保护利用、文物安全管理作出重要指示批示。中共中央办公厅、国务院办公厅《关于加强文物保护利用改革的若干意见》和国务院办公厅《关于进一步加强文物安全工作的实施意见》，对新时代文物保护利用和文物安全管理作出全面部署。各地文物行政部门和执法机构忠于职责、担当作为，涌现出一批文物行政执法先进典型。

2019年，我局组织遴选第三批全国文物行政执法指导性案例，公布指导性案例14个，你区锡林郭勒盟元上都文化遗产管理局办理的“某旅游服务有限公司擅自在内蒙古自治区世界文化遗产元上都遗址保护范围内违法建设案”入选。我局已将该指导性案例印发全国文物系统，供各地学习参考，同时给予通报表扬。

为全面贯彻落实习近平总书记关于文物工作重要论述精神，落实党中央、国务院关于文物保护利用和安全管理的决策部署，请你府继续督促属地各级政府和有关部门牢固树立保护文物也是政绩的科学理念，切实落实文物保护主体责任，充分发挥指导性案例的示范和警示作用，提高文物保护法治意识，加强文物行政执法规范化建设，提升文物治理体系和治理能力现代化水平。

专此函。

国家文物局

2019年12月27日
