# 农业农村部办公厅关于公布第二届农业农村部捕捞渔具专家委员会名单的通知

农办渔〔2019〕4号

为加强渔业资源和生态环境保护，强化渔具管理，加快推进渔具管理制度建设，农业部于2011年成立了捕捞渔具专家委员会（以下简称“委员会”）。委员会成立以来，积极开展渔具管理制度和技术标准研究，开展渔具对资源影响试验，制定准用渔具目录，为管理和执法提供技术支持，在渔具管理和制度建设等相关工作中发挥了重要作用。目前，原委员会任期已到，加之机构改革、人员变动等原因，我部决定对委员会组成和人员进行调整。经各省（区、市）渔业主管厅（局）及有关部门推荐，现公布第二届农业农村部捕捞渔具专家委员会人员名单（名单见附件），委员会委员聘期五年。

请各有关单位高度重视，充分发挥委员会作用，促进相关工作开展，同时支持各位委员的工作，尽力为其开展工作创造条件。委员会各委员要充分认识专家咨询和技术支撑的重要性，切实增强责任感和使命感，以认真的态度和扎实的作风履职尽责，打造高水平、专业化、有担当的中国渔具管理智库，为渔具管理提供强有力的智力支撑。

附件：第二届农业农村部捕捞渔具专家委员会人员名单

农业农村部办公厅

2019年1月30日
