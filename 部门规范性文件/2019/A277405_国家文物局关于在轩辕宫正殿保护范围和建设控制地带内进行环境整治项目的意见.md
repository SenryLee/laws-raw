# 国家文物局关于在轩辕宫正殿保护范围和建设控制地带内进行环境整治项目的意见

文物保函〔2019〕429号

江苏省文物局：

你局《关于审批轩辕宫正殿环境整治工程设计方案的请示》（苏文物保〔2019〕80号）收悉。经研究，我局原则同意在轩辕宫正殿保护范围和建设控制地带内进行环境整治工程。

一、所报方案尚需作较大的修改和完善：

（一）加强研究，补充设计依据。补充轩辕宫正殿的保护对象、历史格局内容；补充说明轩辕宫正殿与城隍庙及周边环境的关系；补充保护范围和建设控制地带的管理规定。

（二）进一步优化正殿海墁铺装、高差变化处理、围墙形式等设计，尽可能延续历史风貌和自然氛围。

（三）上山步道应结合现有山形和植物环境，采取蜿蜒曲折路线。场地建议采用当地自然块石铺地。

（四）补充场地排水设计内容。

（五）绿化植栽应以当地树种为主，并考虑成材后的高度控制。

（六）进一步论证卫生间选址，配套设施建设和管线埋地应避让正殿和建筑遗址，确保文物安全。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月7日
