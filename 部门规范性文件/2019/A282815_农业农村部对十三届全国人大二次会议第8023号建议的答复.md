# 农业农村部对十三届全国人大二次会议第8023号建议的答复

## 对十三届全国人大二次会议第8023号建议的答复

您提出的关于加大对黑龙江农田基础设施建设支持力度的建议收悉。现答复如下：

近年来，中央各部门通过中央预算内投资中新增千亿斤粮食工程、农业综合开发、农田整治、农田水利建设等项目渠道支持高标准农田建设，改善农业生产基本条件，不断提升粮食综合生产能力。机构改革后，农业农村部切实履行农田建设统一管理职责，积极发挥牵头抓总作用，加强督导协调，压实地方建设责任，推动建设任务落实，2018年各地新增高标准农田8200多万亩。2019年，财政部会同农业农村部整合农业综合开发专项资金、土地整治工作专项资金和水利发展资金中用于农田水利建设部分，设立农田建设补助资金，用于支持高标准农田及农田水利建设。同时，农业农村部会同发展改革委利用中央预算内投资支持高标准农田建设。目前，2019年农田建设补助资金和中央预算内投资高标准农田建设项目资金已全部下达。

对于您提出的“加大资金保障力度”建议，黑龙江省作为我国重要的粮食生产大省，一直以来都是高标准农田建设的重点地区。2019年，我部会同中央有关部门，充分考虑黑龙江省在保障粮食安全中的重要作用和工程建设需要，在任务分配和资金测算过程中对黑龙江予以倾斜支持，共安排黑龙江省中央财政资金73.19亿元，支持新增高标准农田630万亩，同步发展高效节水灌溉100万亩，资金和任务安排规模均处于全国首位。同时，还安排资金15.66亿元支持黑龙江农垦建设高标准农田150万亩，高效节水灌溉15万亩。下一步，农业农村部将会同相关部门，视中央财政资金增长情况，继续加大对黑龙江省高标准农田建设的支持力度，保障农田建设资金投入，努力确保黑龙江省高标准农田建设任务顺利完成。在积极争取加大财政资金投入的同时，我部将积极支持黑龙江省探索先建后补、以奖代补、政府和社会资本合作、充分利用高标准农田建设新增耕地调剂收益等方式，引导市场主体参与高标准农田建设，有效提高建设标准。

关于您提出的“取消地方资金匹配”建议，按照《国务院关于改革和完善中央对地方转移支付制度的意见》（国发〔2014〕71号）有关规定:“由中央和地方共同承担的事项，要依据公益性、外部性等因素明确分担标准或比例。”财政部、农业农村部联合印发的《农田建设补助资金管理办法》（财农〔2019〕46号）中明确：“农田建设补助资金是指中央财政为支持稳定和优化农田布局，全面提升农田质量而安排用于农田相关工程建设的共同财政事权转移支付资金。”“中央财政与地方财政共同承担农田建设支出责任，地方各级财政应当安排必要的资金投入农田建设，列入本级政府预算。”农业农村部将会同中央有关部门，完善粮食主产区利益补偿机制，保护和调动地方政府抓粮积极性，依据公益性、外部性等因素，推动出台不同区域农田建设资金中央和地方分担比例。

感谢您对高标准农田建设工作的关心和支持！

农业农村部
