# 商务部办公厅关于公布2019年绿色商场创建单位名单的通知

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门：

为深入贯彻党的十九大精神，践行习近平生态文明思想，积极培育绿色流通主体，努力推进流通领域绿色发展，商务部组织开展了2019年绿色商场创建工作。本着公平公正、公开透明的原则，确定北京超市发连锁股份有限公司（双榆树店）等74家企业（详见附件）为商务部2019年绿色商场创建单位，现予以公布。

各地商务主管部门要高度重视，将绿色商场创建工作作为流通领域实践新发展理念、推进生态文明建设和实现商务领域高质量发展的重要措施。一方面，要继续加强对绿色商场创建单位的业务指导，主动施策，引导和鼓励绿色商场进一步应用绿色低碳技术，宣传绿色环保理念，提升绿色消费水平；另一方面，要及时梳理、总结本地绿色商场创建工作中的先进经验做法，树立优秀典型，开展形式多样的宣传推广活动，营造简约适度、节能低碳的良好社会氛围。
