# 国家文物局办公室关于中铁西北科学研究院有限公司文物保护工程勘察设计甲级资质证书内容变更的函

办保函〔2019〕527号

甘肃省文物局：

你局《关于变更中铁西北科学研究院有限公司文物保护工程勘察设计甲级资质证书相关信息的请示》（甘文局发〔2019〕91号）收悉。

经研究，我局同意中铁西北科学研究院有限公司文物保护工程勘察设计甲级资质证书中的法定代表人由“方建生”变更为“郑静”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年6月12日
