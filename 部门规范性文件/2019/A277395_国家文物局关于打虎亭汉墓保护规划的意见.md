# 国家文物局关于打虎亭汉墓保护规划的意见

文物保函〔2019〕414号

河南省文物局：

你局《关于报批新密打虎亭汉墓文物保护规划的请示》（豫文物〔2018〕272号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）加强考古资料梳理和历史文献研究，开展必要的考古调查、勘探，厘清墓园的整体布局、重要遗迹分布和历史风貌，在此基础上科学确定文物构成和保护对象。

（二）深化价值评估和现状评估，进一步明确画像石与壁画保存现状、病害类型与发展趋势，补充必要的画像石、壁画照片、图示说明。

（三）应根据文物分布、保护管理需要等，合理调整保护区划，增强可操作性和针对性。应合理缩减保护范围和建设控制地带，进一步论证建设控制地带北部边界划定依据及合理性；补充保护区划边界的具体坐标位置，兼顾村庄、道路红线分布情况，不宜使用现状建筑边墙标识；应根据视线分析评估调整建设控制地带的具体指标，补充建设控制地带内已有建/构筑物整治要求。

（四）完善专项规划内容，制定有针对性的保护措施，植被清理、墓冢封土回填、石质文物和壁画保护等措施应明确具体要求。现阶段应重点做好文物本体保护、场地排水、植被调整等方面工作；客观评估墓葬展示效果和开放展示的必要性、文物影响等，进一步调整展示思路，重点做好现有展厅提升和环境整治，不宜新建游客服务中心、停车场等设施。细化场地排水、考古研究等专项规划内容。

（五）规范图文表达，文本前后内容应对应一致，校核错别字。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将打虎亭汉墓保护规划报请河南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好打虎亭汉墓各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年5月5日
