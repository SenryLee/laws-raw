# 国家文物局关于政协十三届全国委员会第二次会议第0480号、第B270号（文化宣传类029号）提案答复的函

文物保函〔2019〕865号

凌友诗、龙子明委员：

你们提出的《关于落实调查广州南石头日军细菌战试验遗址的提案》和《关于以南石头难民营史料加强大湾区共同价值的建设的提案》已交由我局会同广东省人民政府合并办理，现答复如下：

广州南石头侵华日军史迹是日军侵华罪行的重要证据，是对国人特别是对粤、港青少年进行爱国主义教育的重要题材，充分做好遗址保护利用，对实现中华民族伟大复兴具有重要的社会意义。2002年，原广州市文化广电新闻出版局将侵华日军华南防疫给水部遗址以“粤海港检疫所旧址 ”名称公布为广州市登记文物保护单位，2012年广州市珠海区政府在第三次全国文物普查中，将该“粤海港检疫所旧址”改名为“侵华日军华南防疫给水部遗址”，并列入了不可移动文物名录。

在国家文物局和广东省人民政府的指导下，广东省文物部门组织考古、近代史、文献研究等方面专家，多次到现场实地调研并召开专题会议深入细致研究；广州市安排专项经费，委派广州市文物考古研究院开展“南石头惨案保护研究”项目，重点围绕文献资料收集研究、相关史迹测绘、考古调查与骨骸清理检测等内容开展工作；市、区文物部门组织编制了侵华日军华南防疫给水部遗址修缮设计方案，目前已通过专家评审，并落实了维修资金。与此同时，广州市人民政府还及时调查、研究、处理了涉嫌拆除与南石头日军侵华史迹相关建筑事宜，确保了相关史迹的安全，并对“难民营围墙”进行了加固保护。目前，广州市已将南石街发现的相关遗迹纳入重点关注对象，积极加强遗址及周边地区的日常掌控、消防安全监督工作，防止遗址文物遭受盗窃和人为破坏，确保安全。

根据有关规定，建立纪念设施需要收集大量确凿史料和实物并报党中央、国务院审批。当前，南石头日军侵华史迹研究和保护工作面临着历史资料极其匮乏的困难。一是在考古调查中未发现“万人坑”等遗迹，缺乏直接考古依据；二是由于城市建设及变迁等原因，未能发现更多遗迹、遗存；三是由于时代久远，相关幸存人员基本已经去世，难以找到亲身经历者，缺乏有力的人证。四是缺乏第一手文献资料，目前所见文字记载存在相互引用、互相转载的现象，真实性和可信度都不够。“广州南石头日军细菌战实验遗址”还处于史料研究和进一步厘清事实的阶段，需进一步搜集有关历史事件的确凿证据。

下一步，国家文物局将会同广东省人民政府，指导广东省文物行政部门和地方人民政府在当前工作的基础上，积极做好以下工作：

一是加强历史资料收集。鼓励社会各界、学者进一步研究相关历史资料，继续开展“南石头惨案”研究，深入挖掘相关事实证据。积极收集侵华日军在粤侵占期间的相关活动（如细菌战、毒气战）、南石头难民收容所、广州波字第8604部队等档案资料。同时寻找“南石头惨案”知情者，收集与南石头粤港难民、南石头难民收容所有关的资料。

二是利用现有的文物建筑进行展览展示。督促管理使用单位尽快开展对侵华日军华南防疫给水部遗址的保护工作，待修缮完成后，合理规划利用现有的建筑物或文化遗存进行日军侵华相关的历史资料展览。

三是继续做好“南石头惨案”现存遗址的考古调查勘探工作。在遗址范围内相关拆迁和地面清障工作完成后，指导地方文物部门组织开展考古调查、勘探，以查找相关遗存。根据已完成的研究阶段性成果，做好骨骸的保护与安置工作，对难民营围墙、厨房、化骨池、所长住宅、检疫所医务人员食堂、宿舍等进一步研究论证，由规划部门在片区规划中予以保留。

四是关于建立纪念设施问题，待深入调查发掘认证细菌战试验遗址后，结合遗址情况对纪念设施选址进行论证，制定规划方案，按程序报批。

感谢你们对文物事业的关心与支持！

国家文物局

2019年8月22日
