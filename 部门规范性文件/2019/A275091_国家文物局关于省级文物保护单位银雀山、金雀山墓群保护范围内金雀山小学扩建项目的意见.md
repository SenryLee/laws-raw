# 国家文物局关于省级文物保护单位银雀山、金雀山墓群保护范围内金雀山小学扩建项目的意见

文物保函〔2019〕244号

山东省文物局：

你局《关于临沂金雀山小学在银雀山、金雀山墓群保护范围内进行扩建的请示》（鲁文发〔2019〕12号）收悉。经研究，我局原则同意在省级文物保护单位银雀山、金雀山墓群保护范围内实施金雀山小学扩建项目。

一、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，考古发掘项目需另行填报考古发掘申请书。

二、应根据考古成果调整设计方案，明确文物保护措施，拟建建筑的体量、高度、外立面形式应与遗址景观风貌和临沂城市肌理相协调。同时，制定详细的施工组织方案，严格控制工程范围和施工强度，确保文物安全。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月8日
