# 国家核安全局关于颁发中国原子能科学研究院TK-C57新燃料运输容器使用批准书的通知

## 关于颁发中国原子能科学研究院TK-C57新燃料运输容器使用批准书的通知

国核安发〔2019〕122号

中国原子能科学研究院：

你院《关于申请进口一类放射性物品运输容器TK-C57使用批准书取证的请示》（原安发〔2019〕68号）收悉。

根据《放射性物品运输安全管理条例》的有关规定，我局对你院提交的《中国原子能科学研究院TK-C57新燃料运输容器使用申请报告》进行了审查，认为由俄罗斯开放式股份公司机器制造厂设计和制造的TK-C57运输容器能够满足《放射性物品运输安全管理条例》的相关要求，批准你院使用TK-C57运输容器用于实验快堆新燃料运输，有效期至2024年5月31日。

你院在使用TK-C57新燃料运输容器实施运输过程中，必须严格遵循TK-C57新燃料运输容器使用批准书规定的各项条件，确保运输安全。

附件：TK-C57新燃料运输容器使用批准书

国家核安全局

2019年6月11日
