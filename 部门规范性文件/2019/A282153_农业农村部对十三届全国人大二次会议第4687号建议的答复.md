# 农业农村部对十三届全国人大二次会议第4687号建议的答复

## 对十三届全国人大二次会议第4687号建议的答复

农办议〔2019〕201号

邱丽新代表：

您提出的关于支持黄冈地标优品“五进一出”工程的建议收悉。经商发展改革委、商务部、国务院扶贫办、知识产权局，现答复如下。

党中央、国务院高度重视产业扶贫工作，明确把产业扶贫摆在“五个一批”的首位。各地各部门认真学习贯彻习近平总书记关于扶贫工作的重要论述和中央脱贫攻坚决策部署，按照精准扶贫、精准脱贫的基本方略，加快推进产业发展、加强主体培育、创新利益联结、促进产销对接、强化科技支撑和人才培育，产业扶贫工作取得了显著成效。

一、关于产业项目与资金支持

国家高度重视大别山地区在内的革命老区脱贫攻坚工作，持续加大工作力度，推动老区人民与全国一道进入全面小康社会。2015年，出台《大别山革命老区振兴发展规划》（2015—2020年），重点围绕现代农业发展、产业结构优化升级、优化城乡建设布局等7个方面，全面支持革命老区产业发展、开发建设及脱贫攻坚。2016年，我部联合发展改革委等8部门印发《贫困地区发展特色产业促进精准脱贫指导意见》，指导22个扶贫任务重的省（区、市）编制完成省、县两级产业扶贫规划，其中大别山革命老区3省36县也编制完成产业扶贫规划。根据中央的决策部署和省委省政府的工作要求，2019年初，黄冈市编制出台《黄冈市乡村振兴战略规划》（2018—2022年），为当地深入实施乡村振兴战略提供了重要支撑。

近年来，按照中央“大专项+任务清单”的项目资金管理方式，经县市申请、省级推荐、专家评审等程序，国家支持湖北省创建了6个中国特色农产品优势区、3个现代农业产业园、5个农村产业融合发展示范园和10个农业产业强镇，其中支持黄冈市创建1个产业强镇。2019年，中央财政在测算分配农业生产发展资金时，已将国家扶贫开发工作重点县数量纳入资金分配因素，加大对扶贫任务重省份的支持。在《农业农村部、财政部关于做好2019年农业生产发展资金等项目实施工作的通知》中，明确要求各地在项目资金安排上进一步向贫困地区、贫困县倾斜。黄冈市可充分利用国家脱贫攻坚的倾斜政策，结合发展实际，积极申请创建中国特色农产品优势区、现代农业产业园、农村产业融合发展示范园、农业产业强镇等项目。

下一步，我们将指导和督促地方有关部门认真落实《大别山革命老区振兴发展规划》《黄冈市乡村振兴战略规划》提出的目标任务，支持产业发展，促进产业兴旺。我部将会同相关部门，指导和督促湖北省和黄冈市落实贫困地区的倾斜支持政策，支持贫困县申报“五进一出”工程相关产业项目，并可以在申报材料编写、建设规划起草等方面提供指导和帮助，促进申报项目顺利通过评审。

二、关于品牌建设支持

（一）关于支持培育“黄冈地标优品”重点区域品牌。我部始终重视品牌培育工作，指导贫困地区实施品牌提升行动，立足资源禀赋和产业基础，做好品牌规划，打造区域公用品牌，保护地理标志农产品，加强品牌宣传。支持贫困地区开展绿色、有机、地理标志农产品认证，今年以来已经减免绿色有机农产品认证和标志使用费近380万元。在中国国际农产品交易会、中国国际茶叶博览会等农业展会以及产销对接等活动中，开展“省部长推介品牌农产品专场”“我为品牌农产品代言” “乡人乡味——全国品牌农产品推介活动”等，大力推介农产品品牌。在近3届中国国际农产品交易会上，专门设置扶贫展区，推介具有地方特色的农产品区域公用品牌。此外，通过总结提炼产业扶贫典型范例，推出了洛川苹果、赣南脐橙和定西马铃薯等贫困地区区域公用品牌，为贫困地区产业发展、贫困群众增收提供了有力支撑。

（二）关于支持区域性展会品牌。黄冈市充分发挥产业优势和区位优势，举办“大别山（黄冈）地标优品博览会暨文化美食节”，是推进农业转型升级和一二三产业融合、促进城乡协同发展的重要抓手。在我部联合8部委印发的《关于实施产业扶贫三年攻坚行动的意见》中，对贫困地区原料生产加工、特色农产品品牌创建等方面提出了扶持措施。商务部也大力支持地方依托品牌展会平台，整合各方资源优势，积极培育区域特色显著、引领作用突出的交流合作平台，推动当地特色经济发展。

下一步，我们将进一步加强对革命老区的支持，指导黄冈市创建农产品品牌，打造区域公用品牌，举办各类专业化、市场化、国际化、信息化的地标优品展会，提升展会品牌的竞争力和美誉度，为农业转型升级、提质增效提供重要支撑和持久动力。

感谢您对农业农村工作的关心和重视，希望今后继续对我部工作予以支持。
