# 国家文物局关于在黄花岗七十二烈士墓建设控制地带内进行永泰东约49号住宅楼加建电梯项目的意见

文物保函〔2019〕188号

广东省文物局：

你局《关于在全国重点文物保护单位黄花岗七十二烈士墓建设控制地带内永泰东约49号加建电梯项目的请示》（粤文物审〔2018〕164号）收悉。经研究，我局原则同意在黄花岗七十二烈士墓建设控制地带内进行永泰东约49号住宅楼加建电梯项目。

一、请你局指导相关单位进一步优化设计方案，注意建筑立面风貌与文物环境相协调，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

二、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

三、今后，涉及在全国重点文物保护单位黄花岗七十二烈士墓保护范围和建设控制地带内实施老旧建筑（文物建筑除外）加装电梯工程的，相关建设方案由你局直接审批，并报我局备案。请你局在审批中妥善处理好文物保护与城市建设、民生改善之间的关系，确保文物安全。

专此函复。

国家文物局

2019年2月20日
