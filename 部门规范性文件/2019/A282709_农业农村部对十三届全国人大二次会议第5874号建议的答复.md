# 农业农村部对十三届全国人大二次会议第5874号建议的答复

## 对十三届全国人大二次会议第5874号建议的答复

您提出的关于“加大农村基础建设，促进精准脱贫”的建议收悉。经认真研究，现就涉及我部职能“关于加大农村沟河疏浚、水泥渠修建投入力度”的有关内容，答复如下。

农田水利设施是提高农业综合生产能力和改善农村生活条件的基础，对保障国家粮食安全、支撑农村经济社会发展具有重要作用。近年来，国家通过农业综合开发、土地整治工作专项、新增千亿斤粮食工程、农田水利设施建设等涉及农田建设的项目、资金支持各地农田水利基础设施建设。

2018年中央机构改革，明确将发展改革委农业投资项目、财政部农业综合开发项目、国土资源部农田整治项目、水利部农田水利建设项目等农田建设项目管理职责整合划入农业农村部，由农业农村部统一承担农田建设管理职能。这次机构改革解决了过去多年想解决而没有解决的老问题，农田建设管理体制进一步理顺，农田建设资金整合力度进一步加大，彻底改变了农田建设“五牛下田”、“分散管理”的局面。

目前，2019年中央财政农田建设补助资金已全部下达，支持各地开展8000万亩高标准农田建设，同步发展高效节水灌溉面积2000万亩，为保障国家粮食安全打下坚实基础。其中，安排江苏省2019年农田建设补助资金34.98亿元，支持江苏新建高标准农田330万亩。江苏省可以因地制宜，根据当地实际需求，在集中力量开展以土地平整、土壤改良、灌排设施、田间道路、生态防护、输配电设施等为主要内容的高标准农田建设的同时，统筹使用好中央和地方资金，加大对农村沟渠的建设、疏浚力度。

尽管目前高标准农田建设工作取得了明显成效，但是当前农业基础设施短板问题还比较突出，抗灾能力弱的状况还未根本改观。下一步，我们将结合您的建议，积极与发展改革委、财政部等有关部门沟通协调，继续将高标准农田建设作为中央财政重点投入领域，重点做好以下工作：一是发挥规划统筹引领作用。加快编制《全国高标准农田建设规划（2019—2022年）》，明确今后4年重点建设内容、分区域布局和保障措施。二是完善制度标准体系。推动出台《关于切实加强高标准农田建设提升国家粮食安全基础保障能力的意见》，加快农田建设法规和标准制修订工作。三是强化项目组织实施。完善定期调度和激励评价机制，逐级压实责任，推动年度建设任务落实。优先在“两区”和永久基本农田保护区开展高标准农田建设，优先安排干部群众积极性高的地区开展高标准农田建设，积极支持新型经营主体建设高标准农田。

感谢您对农业农村工作的关心，希望继续支持我部工作。

农业农村部

2019年8月19日
