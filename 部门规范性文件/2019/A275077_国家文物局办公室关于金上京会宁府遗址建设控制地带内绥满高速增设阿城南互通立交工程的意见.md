# 国家文物局办公室关于金上京会宁府遗址建设控制地带内绥满高速增设阿城南互通立交工程的意见

办保函〔2019〕155号

黑龙江省文物管理局：

你局《关于绥满高速增设阿城南互通立交工程涉及金上京会宁府遗址建设控制地带的请示》（黑文管字〔2019〕3号）收悉。经研究，我局暂不同意在金上京会宁府遗址建设控制地带内实施绥满高速增设阿城南互通立交工程。

一、拟建高速立交工程体量巨大，紧邻金上京城墙遗址，项目实施和运营将对遗址及环境产生较大负面影响。请你局组织有关单位按照《金上京会宁府遗址保护规划》（2013-2030）关于建设控制地带的管理规定，充分评估哈尔滨市道路交通建设现状和需求，进一步论证项目实施的必要性，建议通过改造原阿城南互通立交满足公路交通需要。

二、请你局督促地方人民政府统筹考虑金上京会宁府遗址保护、基础设施建设的关系，合理安排建设项目，确保文物安全。

专此函复。

国家文物局办公室

2019年3月8日
