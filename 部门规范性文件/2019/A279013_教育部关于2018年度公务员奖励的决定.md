# 教育部关于2018年度公务员奖励的决定

教人〔2019〕11号

按照《公务员奖励规定（试行）》和《教育部机关年度考核实施办法》，根据年度考核结果，决定对魏士强等16名同志记三等功，对刘自成等94名同志给予嘉奖。

一、2018年度给予记三等功奖励人员（16人）：

魏士强、许高勇、陈星、张雪、青格勒图、王磊（人事司）、吕东伟、李伟、朱东斌、李静波、宋磊、黄小华、葛元杰、安延、赵磊、付先锋

二、2018年度给予嘉奖奖励人员（94人）：

刘自成、王猛、宋德民、苏大林、王秀荣、宫贤鹏、王绍磊、蔡明才、陈延哲、邓传淮、王大泉、黄浩淼、张晓彬、刘昌亚、田福元、王云霏、韩劲红、周天明、顾然、吴延磊、王鹏、张东刚、廖舒力、潘逴、吴强、李雪明、卢波辉、方永生、周胜斌、李旭丽、郭鹏、陈淑梅、王俊、陈舒、赵丹、申继亮、韩春勇、吕玉刚、俞伟跃、陈东升、黄伟（基教司）、郝雅梅、宁锐、黄辉、任占营、范海林、吴爱华、张庆国、刘永强、朱蓓蓓、郭佳、马杰、杨宇、陈磊、朱小杰、张志飞、黄伟（教师司）、王克杰、陈蓓蓓、徐艳国、梅红、邹晖、李渝红、孙海波、唐小平、蔺为民、徐忠波、栾宗涛、郝彤亮、朱瑞、周道娟、李强（语信司）、徐永吉、李旭东、毛冬敏、刘力、刘晓、关欣、王义、朱立城、樊桔贝、牛燕冰、吴一、王日春、李智发、刘炳来、李海瑞、刘晶玉、王亮、袁磊（离退休干部局）、贺晓萌、肖峰、贾楠、魏侠

注：1.《公务员奖励规定（试行）》第十条规定：“年度考核被确定为优秀等次的，予以嘉奖，连续三年被确定为优秀等次的，记三等功。”

2. 连续三年优秀已记三等功的，该年度不再给予嘉奖。

3. 连续三年优秀已记三等功的，优秀等次连续年数重新计算。
