# 国家文物局办公室关于杜陵建设控制地带内曲江玫瑰公馆建设项目的意见

办保函〔2019〕725号

陕西省文物局：

你局《关于曲江·玫瑰公馆项目选址涉及杜陵建设控制地带的请示》（陕文物字〔2019〕101号）收悉。经研究，我局暂不同意在杜陵建设控制地带内实施曲江玫瑰公馆建设项目。

一、拟建项目紧邻杜陵保护范围，应组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，明确已探明墓葬、夯土基址、灰坑等遗迹的性质和分布范围，厘清项目建设区域与杜陵陵园、陪葬墓、陵邑的空间位置关系。考古发掘项目需另行填报考古发掘申请书。

二、杜陵已作为西汉帝陵的重要组成部分列入《中国世界文化遗产预备名单》。应按照世界文化遗产申报要求，以及《杜陵文物保护规划》和我局《关于在杜陵建设控制地带内进行曲江玫瑰公馆售楼部建设项目的意见》（办保函〔2018〕864号），进一步论证项目选址的必要性和可行性，避免给今后世界遗产申报工作带来负面影响。

专此函复。

国家文物局办公室

2019年8月15日
