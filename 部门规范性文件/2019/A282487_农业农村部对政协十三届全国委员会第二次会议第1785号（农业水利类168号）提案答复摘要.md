# 农业农村部对政协十三届全国委员会第二次会议第1785号（农业水利类168号）提案答复摘要

## 政协十三届全国委员会第二次会议第1785号（农业水利类168号）提案答复摘要

2019年中央1号文件明确提出“实施大豆振兴计划，多途径扩大种植面积”。今年3月，农业农村部印发《大豆振兴计划实施方案》，并会同财政部制定印发《关于做好2019年耕地轮作休耕制度试点工作的通知》，财政部联合发展改革委继续在东北三省和内蒙古自治区实行大豆生产者补贴制度，加大对大豆支持，引导农民扩大大豆种植。2018年起，中央财政将区域性大豆良种繁育基地纳入制种大县奖励范围，2019年安排资金 8000万元，对8个区域性大豆良种繁育基地县（农场）进行奖励。2017年财政部、国家粮食局开始在粮食流通领域实施“优质粮食工程”，通过完善粮食产后服务功能、构建新型粮食流通体系，引导绿色优质粮食生产和加工，提升大豆加工转化能力，进一步拓宽国内大豆销售渠道。
