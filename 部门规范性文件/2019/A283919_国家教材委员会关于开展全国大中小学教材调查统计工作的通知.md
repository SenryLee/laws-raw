# 国家教材委员会关于开展全国大中小学教材调查统计工作的通知

## 关于开展全国大中小学教材调查统计工作的通知

国教材办〔2019〕44号

各有关出版单位：

为全面了解大中小学教材基本情况，更好地指导推动教材建设，科学服务教材决策， 做好教材奖励制度实施基础工作，国家教材委办公室组织开展全国大中小学教材调查统计工作。现就有关事项通知如下。

一、教材调查统计要求

1.统计范围。2006年1月至2019年10月期间，国内正式出版的（以版权页的版次日期为准）、供我国各级各类学历教育教学正在使用的教材（不含教学参考书、教辅用书，版权页CIP数据标识须为教材）。

2.统计分类。基础教育教材（包括义务教育、高中教学使用的教材），职业教育教材（包括中等职业学校、高等职业院校教学使用的教材），高等教育教材（包括本科、研究生教学使用的教材）。

继续教育、特殊教育、民族文字教材分别纳入上述相应学段教材统计。

二、教材统计信息填报

1.工作组织。由各出版单位按照要求统计本单位所有相关教材信息，并在教材信息管理系统填报。请务必认真统计、准确填写，确保信息全面、无误。如有虚假或错误，责任自负。

2.网络填报。请各出版单位登录全国大中小学教材调查统计平台（http://ncct.moe.edu.cn/jiaocai），根据填报指南填报教材信息，于2019年11月30日前完成填报工作。填报信息要素见附件1。出版单位需同时提供教材填写承诺书（附件2）和联系人证明文件（附件3），上传至全国大中小学教材调查统计平台。

三、联系方式
