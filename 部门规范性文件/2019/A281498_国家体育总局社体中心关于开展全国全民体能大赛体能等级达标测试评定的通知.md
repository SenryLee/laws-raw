# 国家体育总局社体中心关于开展全国全民体能大赛体能等级达标测试评定的通知

## 体育总局社体中心关于开展全国全民体能大赛体能等级达标测试评定的通知

各省、自治区、直辖市、计划单列市、新疆生产建设兵团体育局社体中心（群体处、体总秘书处），各行业体育协会及有关单位：

体育总局社体中心于2019年5月21日印发了《关于开展全国全民体能大赛有关事宜的通知》。为深入贯彻落实党的十九大、十九届二中、三中全会精神和《全民健身计划（2016-2020年）》，大力推广高水平全民健身赛事，积极践行全民健身国家战略，推动健身运动的普及与提高，体育总局社体中心会同相关单位将结合全国全民体能大赛于2019年9月起在天津、北京、杭州、重庆、成都、武汉等城市开展全国全民体能大赛体能等级达标测试评定，现将《全国全民体能大赛体能等级达标标准实施办法（试行）》印发，望积极组织人员参与测试评定。

特此通知。

附件：1.全国全民体能大赛体能等级标准实施办法（试行）

2.全国全民体能大赛体能等级标准测试细则

体育总局社体中心

2019年9月5日
