# 自然资源部办公厅关于大牛地气田建设项目压覆重要矿产资源的复函

自然资办函〔2019〕684号

中国石油化工股份有限公司华北油气分公司：

《中石化华北油气分公司关于大牛地气田（286口气井、11个集气站含放空区和进站道路、1个值班点和1个塔榆阀室）项目压覆重要矿产资源请示》（华北油气〔2019〕31号）及相关材料收悉。经审查，同意大牛地气田（286口气井、11个集气站含放空区和进站道路、1个值班点和1个塔榆阀室）项目压覆已查明煤炭资源储量21596万吨。

请你单位收到本函后45个工作日内到陕西省自然资源厅办理压覆矿产资源储量登记等相关手续。

自然资源部办公厅

2019年4月25日
