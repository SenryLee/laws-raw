# 中华人民共和国应急管理部公告2019年第22号——2019年第三批安全生产失信联合惩戒"黑名单"单位及人员名单

## 中华人民共和国应急管理部公告

2019年第22号

根据《对安全生产领域失信行为开展联合惩戒的实施办法》（安监总办〔2017〕49号）的规定，经审核，将天津市博爱制药有限公司等101家生产经营单位及其有关人员纳入安全生产失信联合惩戒 "黑名单",现予公告。

附件：2019年第三批安全生产失信联合惩戒"黑名单"单位及人员名单

应急管理部

2019年12月31日
