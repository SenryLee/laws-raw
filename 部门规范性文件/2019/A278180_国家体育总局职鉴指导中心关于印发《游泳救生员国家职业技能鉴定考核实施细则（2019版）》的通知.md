# 国家体育总局职鉴指导中心关于印发《游泳救生员国家职业技能鉴定考核实施细则（2019版）》的通知

## 体育总局职鉴指导中心关于印发《游泳救生员国家职业技能鉴定考核实施细则（2019版）》的通知

体职鉴字〔2019〕20号

各省、自治区、直辖市体育行业特有工种职业技能鉴定站：

依据《游泳救生员国家职业标准》，国家体育总局职业技能鉴定指导中心（以下简称“总局职鉴指导中心”）于2012年发布了《游泳救生员国家职业技能鉴定考核实施细则》。为适应经济社会发展的需要，客观反映现阶段游泳救生员职业能力的要求，总局职鉴指导中心组织专家对游泳救生员国家职业标准、教材等进行了修订，在此基础上制定了《游泳救生员国家职业技能鉴定考核实施细则（2019版）》（以下简称“《细则（2019版）》”）。《细则（2019版）》作为今后一段时期全国体育行业开展游泳救生员职业技能鉴定操作技能考核的依据，予以印发施行。现将有关事项通知如下：

一、《细则（2019版）》从2019年7月1日起正式施行。《游泳救生员国家职业技能鉴定考核实施细则》（2012年）相应废止。

二、各体育行业职业技能鉴定站要切实组织好本地区考评人员、考务人员等专业人员的培训和学习，重点要加强考评员的业务培训，使考评员尽快熟悉、掌握新标准的考评要求，做好新、老标准下鉴定工作的顺利衔接和过渡。

三、游泳救生员作为准入类职业资格，操作技能考核是该职业认证的核心和关键环节。各鉴定站务必要依据标准和《细则》，规范程序，严格考评，严肃纪律，保证游泳救生员鉴定工作质量，确保资格证书的权威性。

附件：游泳救生员国家职业技能鉴定考核实施细则（2019版）
