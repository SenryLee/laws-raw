# 国家文物局办公室关于福建省建科工程技术有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕555号

福建省文物局：

你局《关于福建省建科工程技术有限公司申请资质证书内容变更的请示》（闽文物字〔2019〕217号）收悉。

经研究，我局同意福建省建科工程技术有限公司文物保护工程施工一级资质证书中的单位地址由“福州市杨桥中路162号”变更为“福建省福州市闽侯县上街镇科技东路8号创业大厦附属楼3楼304—A105”，法定代表人由“潘耀民”变更为“林振中”，请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年6月24日
