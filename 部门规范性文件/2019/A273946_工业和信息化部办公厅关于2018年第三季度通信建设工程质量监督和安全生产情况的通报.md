# 工业和信息化部办公厅关于2018年第三季度通信建设工程质量监督和安全生产情况的通报

工信厅通信函〔2019〕11号

现将2018年第三季度全国通信建设工程质量和安全生产情况通报如下：

一、基本情况

（一）质量监督情况。本季度共申报质量监督项目66172项，办理竣工验收备案项目30651项（附件1）。通信工程质量监督机构开展工程实体抽查项目2360项，抽查发现问题的项目77项（附件2）。

（二）安全生产情况。本季度发生两起一般生产安全事故，共造成3人死亡。

2018年7月22日，西安汇诚电信有限责任公司在浙江省绍兴市越城区，将承建中国联通浙江省绍兴市分公司室分光缆接入工程分包给绍兴宏发通信工程有限公司，工程作业时发生触电事故，造成1名施工人员死亡。目前相关单位已依法对事故责任单位作出处罚，并责成事故责任单位对相关责任人进行处理。

2018年7月28日，湖南省通信建设有限公司在宁夏回族自治区银川市金凤区承建中国移动通信集团宁夏有限公司银川分公司光缆管线工程时，作业人员违规进入氧气含量远低于最小允许值的井内作业，造成2名施工人员死亡。目前银川市人民政府已对事故调查报告进行了批复，对事故责任和处理建议进行了认定。

二、存在的主要问题

从本季度情况看，抽查发现的问题主要包括：

（一）工程质量问题。一是电源柜保护地排、交流电源线金属外护层未采取接地保护措施；二是蓄电池架未采取抗震加固措施；三是光缆与电力电缆交越处未采取保护措施；四是天线馈线绑扎在楼顶避雷带上。

（二）相关企业的问题。一是部分电信企业未严格履行基本建设程序，未按规定要求办理工程质量监督申报手续，将工程发包给不具有相应资质条件的承包单位，工程合同中未明确安全生产费数额和支付方式；二是部分设计企业设计文件未对涉及施工安全的重点部位和环节进行说明，未对高压线危险范围内作业的安全措施进行说明，设计交底未对有限空间作业和高处作业的安全措施提出详细要求；三是部分施工单位未取得相应等级的施工资质等级证书，项目负责人和专职安全生产管理人员未通过相应的安全生产考核，有限空间作业未配备有害气体探测仪等防护装备，施工单位项目管理人员未就有关安全施工的要求向全体施工作业班组和人员作出详细说明；四是部分监理企业未督促施工单位对存在的问题及时进行整改，未严格审查施工组织设计，未提供有限空间作业和高处作业等施工安全重点环节的旁站记录。

三、2018年第二季度通报问题的整改情况

中国电信集团有限公司要求存在问题的7个省分公司进行整改，21个工程项目及6项材料和设备检测存在的问题均已逐项整改落实，对涉及参建单位内部管理的问题已督促其整改落实。对检测存在问题的材料和设备进行换货整改，责成供应商加强产品质量管控，并就产品质量违约进行处罚。同时，督促设计单位按规定履行安全生产职责，督促施工单位、监理单位加强施工现场安全管理和员工安全生产相关培训教育。要求各单位高度重视质量和安全管理工作，严格按规定履行建设程序，加大对工程现场的检查力度，深入开展自查和整改，确保通信建设工程质量和安全。

中国移动通信集团有限公司督促存在问题的7个省公司进行整改，19个工程项目及1项材料和设备检测存在的问题已全部整改完成。对检测存在问题的材料，对其供应商进行约谈，依照合同进行责任追究。相关省公司加强基本建设程序合规性管理，对相关分公司及设计单位负责人通报批评、扣除业务绩效。要求设计单位开展全面自查，并对相关设计单位进行约谈、扣款、通报批评等处理；要求施工单位强化施工现场安全管理，对相关施工单位依据合同进行违约处理；要求监理单位切实履行监理职责，对相关监理单位进行约谈和服务考核成绩扣分处理等。同时，通过定期通报合作单位严重违约情况，强化内部管理，加大对产品的质量检测力度等手段，持续提升质量安全管理水平。

中国联合网络通信集团有限公司督促存在问题的6个省分公司进行整改，19个工程项目及4项材料和设备检测存在的问题已全部整改完成。对通报中存在问题的材料和设备，已采取暂停采购、要求厂家进行全面整改等措施。同时，通过完善安全生产管理制度、规范项目过程管理以及加强对服务商的管理，进一步提高安全生产和工程质量管理水平。

中国铁塔股份有限公司要求存在问题的8个省分公司对问题项目逐项进行整改，16个工程项目以及1项材料存在的问题已全部整改完毕。对提供问题材料的相关单位，公司已发文通报处罚。要求设计单位对涉及施工安全的重点部位和环节在设计交底中注明；要求施工单位针对项目特点编制安全交底方案，专职安全员通过考核上岗；要求监理单位严格审查施工组织设计。同时，通过对公司项目经理、质量管理人员进行定期培训，对设计、施工、监理等合作单位人员采取穿透式管理，利用互联网手段对在建工程进行全过程管控等手段，进一步提高工程管理水平。

四、相关要求

各通信管理局要加强信息化管理，督促电信企业做好质量监督申报和竣工验收备案工作。要强化对工程质量和安全生产的检查，按季度报送实体工程抽查情况，做好问题项目的后续跟踪和督促整改工作。要严格落实生产安全事故报告制度，按要求在2小时内将较大及以上生产安全事故基本情况报部，并按季度定期报送本地区发生的一般生产安全事故情况。

各电信企业要按要求开展质量监督申报和竣工验收备案工作，严格落实工程质量和安全生产管理要求，对通报的问题要认真整改落实，避免同类问题反复发生。从完善制度流程、强化责任落实、加大检查力度等多方面提升工程建设管理水平。要强化对工程中使用材料、设备的到货检测，加强对供货企业的违约失信考核。各电信企业总部应于2019年3月1日前将《2018年第三季度抽查工程项目发现主要问题汇总表》（附件2）所列问题的整改情况书面报部（信息通信发展司），我部将在下季度通报整改情况。
