# 国家广播电视总局办公厅关于发布《2019年度国家广播电视总局部级社科研究项目立项名单》的通知

## 总局办公厅关于发布《2019年度国家广播电视总局部级社科研究项目立项名单》的通知

广电办发〔2019〕230号

各省、自治区、直辖市广播电视局，新疆生产建设兵团文化体育广电和旅游局，总局机关各部门、直属各单位，中央广播电视总台办公厅，各有关单位：

按照国家广播电视总局部级社科研究项目管理有关规定，总局办公厅组织专家进行了2019年度部级社科研究项目评审工作。经专家评审并经总局领导审定，现将立项项目予以发布。请立项项目负责人查收邮箱通知（申报人在申报书中填写的邮箱），并严格按邮箱要求办理相关立项和拨付首款手续。

特此通知。
