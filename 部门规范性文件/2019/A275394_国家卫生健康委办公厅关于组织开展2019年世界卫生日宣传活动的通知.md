# 国家卫生健康委办公厅关于组织开展2019年世界卫生日宣传活动的通知

国卫办宣传函〔2019〕303号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团卫生健康委：

世界卫生组织将2019年4月7日世界卫生日的主题确定为“全民健康覆盖”，旨在帮助人们更好地了解全民健康覆盖的含义——应该提供哪些服务和支持，以及在哪里提供。为做好2019年世界卫生日宣传工作，现将有关事项通知如下：

一、我委将中国宣传主题定为“维护人人健康，迈向全面小康”。各地要围绕卫生服务体系建设、改善医疗服务、健康扶贫、药品供应保障、人才队伍建设等宣传主题，结合新中国成立70周年和全面建成小康社会目标，宣传70年来特别是党的十八大以来，中国卫生健康事业取得的长足进步、保障全民健康覆盖的特色举措和成功经验、参与全球卫生治理的工作和成果。

二、请各地结合落实健康扶贫三年攻坚行动任务，进一步组织动员基层健康扶贫干部向贫困人口宣传健康扶贫政策，提高政策知晓度；组织面向患病困难群众的义诊、咨询、健康宣教等服务。

三、请各援外医疗队积极参加所在国的世界卫生日活动，开展宣传和交流，介绍中国保障全民覆盖的成果和经验。请注意收集和总结中国帮助受援国实现全民健康覆盖的举措、成效，以及受援国媒体对相关工作的报道，及时报送我委宣传司。

四、请各省（区、市）卫生健康委宣传处汇总本地世界卫生日宣传工作情况，于5月1日前将活动总结和宣传材料、音像资料等报送我委宣传司。
