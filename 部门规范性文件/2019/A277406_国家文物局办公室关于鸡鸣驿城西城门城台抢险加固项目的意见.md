# 国家文物局办公室关于鸡鸣驿城西城门城台抢险加固项目的意见

办保函〔2019〕370号

河北省文物局：

你局《关于呈报鸡鸣驿城西城门城台抢险加固工程设计方案的请示》（冀文物字〔2019〕43号）收悉。经研究，我局暂不同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步完善勘察工作。补充所在区域必要的工程地质和水文地质勘察资料，补充勘察地下水深度及变化情况；应结合历史维修记录，补充外侧包砖砌体、底部包砌条石、散水和顶部海墁、垫层的构造说明；进一步说明此前设置集水井的具体做法；建议采取有效的物探措施，探查包砖砌体内部夯土、填料等隐蔽部位，明确材料类型及松散程度等。

（二）补充相关试验数据，核实夯土的力学性能以及地基土是否存在湿陷性；补充一定时间段内的裂缝变形监测数据，以判断裂缝的性质；进一步加强包括砌体开裂、以往加固技术措施、内部夯土及填料的保存情况、各部位裂缝及变形情况、城台顶部排水不畅等各方面因素的相关性研究，选取恰当的结构计算方法，深入分析病害原因，审慎论证内部夯土变形、地基不均匀沉降等潜在可能性。

（三）深入研究加固技术路线，细化技术措施。应审慎论证树根桩、锚杆、地基注浆加固的必要性和合理性；如确需加固，应严格控制干预程度并优化设计，完善树根桩施工中对城台基础的保护措施，补充校核锚杆垫板及墙体抗冲切强度，完善锚固注浆配比和工艺，明确城墙基础外侧包砌位置和散水做法，细化城墙顶部防排水措施，并补充相应详图。城砖风化碎裂尚不危及结构稳定性的，暂缓剔补。

（四）进一步明确是否需对城墙进行预加固，补充施工中的防护、监测和应急预案。

二、请你局指导方案设计单位根据上述意见对所报方案做进一步修改和完善后，按《关于进一步优化文物保护项目审批的通知》的有关程序另行报批。

三、请你局督促、指导当地人民政府及文物管理单位，尽快开展必要的临时支护工作，确保文物安全。

专此函复。

国家文物局办公室

2019年5月10日
