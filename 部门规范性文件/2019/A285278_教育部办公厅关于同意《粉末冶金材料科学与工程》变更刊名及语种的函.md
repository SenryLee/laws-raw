# 教育部办公厅关于同意《粉末冶金材料科学与工程》变更刊名及语种的函

中南大学：

《中南大学关于〈粉末冶金材料科学与工程〉更名及变更语种的请示》（中大经字〔2019〕21号）收悉。经研究，同意《粉末冶金材料科学与工程》刊名变更为《先进粉体材料（英文）》（英文刊名：《Advanced Powder Materials》），期刊语种变更为英文。请按程序到新闻出版管理部门办理相关手续。

教育部办公厅

2019年12月16日
