# 中华人民共和国交通运输部公告2019年第7号——交通运输部关于调整2019年全国引航员登离轮水域的公告

## 中华人民共和国交通运输部公告

2019年第7号

## 交通运输部关于调整2019年全国引航员登离轮水域的公告

为了更好地规范船舶引航行为，保障水上交通安全畅通，交通运输部根据实际情况，对全国主要港口已有的部分引航员登离轮水域进行了增补、调整和撤除（详见附件），现予公布。

本公告自发布之日起施行。

附件：2019年新增和调整引航员登离轮水域修订表

交通运输部

2019年2月13日
