# 农业农村部关于政协十三届全国委员会第二次会议第0293号（农业水利类045号）提案答复的函

## 关于政协十三届全国委员会第二次会议第0293号（农业水利类045号）提案答复的函

关于推动两岸合作共建田园综合体的提案收悉。经商中央台办，现答复如下。

一、 关于搭建沟通交流平台，建立长期合作机制

为加强两岸农业合作，我部会同中央台办等单位，积极采取多项措施构建交流平台。一是通过举办海峡两岸农业论坛、海峡两岸农业成果展览、两岸乡村座谈、两岸农业合作研讨会等大型论坛活动，开展多种形式的交流互访，建立交流合作机制和定期会晤机制，推动两岸休闲农业交流与合作。二是积极开展多层次的人员交流活动。重点邀请台湾基层农民、农学院青年来访，鼓励农业领域的学术团体、民间组织主办或与台湾相关单位合办学科性或专题研讨会，组织专业性考察团互访，开展学术交流，积极支持台湾各类、各级农业合作经济组织、农业企业和农民参与大陆农业建设，实现两岸农业的优势互补和合作双赢。下一步，我部将继续会同有关部门，积极搭建各类沟通交流平台，逐步建立两岸农业交流合作长效机制。

二、 关于加大政策支持力度，强化政府服务功能

为深入开展对台农业工作，我部会同中央台办等单位，不断加大政策支持力度。一是支持海峡两岸农业合作试验区（以下简称“试验区”）和台湾农民创业园（以下简称“台创园”）建设。目前，大陆已在9个省（区、市）设立了试验区，在14个省（区）设立了29个台创园。多年来，试验区和台创园作为两岸农业高效合作平台，不断丰富和优化服务功能，吸引大批台资农业企业、农业合作组织、农业专家、学者、技术人员等，广泛引进台湾农业先进技术、优良品种和管理经验，实现了两岸资源共享和优势互补。二是广泛开展两岸休闲农业合作试点。目前，我部与岛内农业界先后在福建、山东、四川、浙江、广西、上海、江苏、云南等地开展了众多合作项目，并在部门预算中设立了财政专项资金，支持台湾农民创业园发展两岸休闲农业合作项目。三是积极为涉台农业园区拓展新空间。争取国家现代农业产业园向涉台园区覆盖。目前，已有浙江慈溪、山东栖霞、江苏锡山、安徽和县4个台湾农民创业园成功入选2017年国家现代农业产业园创建名单。另外，浙江仙居、四川新津、福建漳浦、安徽庐江4个台湾农民创业园也进入了首批国家农村产业融合发展示范园创建名单。四是拓展合作新领域。在浙江、吉林、海南等地分别设立海峡两岸渔业交流示范基地、海峡两岸生态农业合作先行实验区、海峡两岸农业合作试验区澄迈示范基地等产业创新合作平台；支持四川新津、大邑等对台交流基础好的乡镇和乡村设立基地，邀请两岸专家学者深度参与乡村振兴，在农村文创、品牌打造推广、社区资源挖掘利用等方面培育新典型、新亮点。

为贯彻落实2017年中央一号文件关于“开展田园综合体建设试点”要求，2017年5月，财政部印发《关于开展田园综合体建设试点工作的通知》（财办〔2017〕29号）（以下简称《通知》），明确在全国18个省份开展田园综合体建设试点。《通知》对试点基本原则、重点建设内容、立项条件、扶持政策等都作出了具体要求。田园综合体试点项目作为解决“三农”问题、推进农村经济社会全面发展的一次全新探索，综合考虑了地方发展条件、开展试点意愿、试点代表性等多种因素，与乡村振兴战略的总要求高度契合。目前，主要工作重点是抓好已安排试点项目建设和总结验收工作，暂不安排新试点项目。下一步，我部将结合实施乡村振兴战略，对田园综合体试点情况进行调研总结，不断完善试点相关政策。

三、 关于创新金融支持手段，吸纳社会资本融入

我部高度重视两岸农业合作发展，会同有关部门加强政策创新，强化资金统筹。一是加强对两岸农业合作的资金支持。2013年以来，累计安排13737.07万元用于台创园建设，着力打造园内企业品牌和产品品牌，积极推动台湾农业“五新”科技成果的引进、示范、集成和推广。二是创新金融支持方式，积极参与中国农业产业发展基金等多个中央层面农业产业投资基金的组建工作。2017年5月，财政部会同农业部印发《关于深入推进农业领域政府和社会资本合作的实施意见》（财金〔2017〕50号），提出重点引导和鼓励社会资本参与现代农业产业园等多个领域，积极推动农业领域政府与社会资本合作。三是中央台办对福建省部分台资农业企业给予贷款贴息支持，并在福建试点拓展抵质押物范围，创新开展大型农机具抵押、林权抵押等多种信贷业务，惠及当地台农及台资农业企业。

此外，《通知》中明确提出，鼓励各类金融机构加大对田园综合体试点建设支持力度，创新财政投入使用方式，探索多元投入机制，推动田园综合体试点建设。试点项目实施以来，各地统筹整合财政资金用于建设高标准农田、灌排渠系等基础设施。同时，发挥财政资金杠杆作用，吸引金融、工商和社会资金投入建设，破解乡村振兴资金困境。下一步，我部将会同有关部门，继续采取多种方式撬动金融和社会资本投入农业农村建设以及两岸农业合作交流领域。

四、 关于突出区域特色品牌，强化创意营销和产业融合

多年来，我部会同中央台办等部门，积极打造两岸特色品牌，培育了福建仙游甜柿、漳平高山茶、清流鲜切花以及四川攀枝花芒果、江苏淮阴蝴蝶兰等两岸农业产业合作基地，并将发展休闲农业作为两岸农业合作的有效模式和途径。利用试验区和台创园等高效平台，引进技术人才，引入台湾观光休闲农业新模式，为台湾农业企业和农民投资大陆、岛内优势产业转移大陆提供了保障。

田园综合体试点项目实施以来，各地依托当地优势资源，突出特色，着力培育现代农业产业。将农业生产与乡村旅游、文化创意、康体养生、科普教育深度融合，大力培育创意农业、民宿度假、文创交流等新业态，着力打造现代农业的新窗口、三产融合的新典范。下一步，我部将继续指导和鼓励有条件的地区开展两岸农业交流活动，加强农业合作，共同推动乡村振兴。

感谢对两岸农业合作的关心，希望继续支持“三农”工作。

农业农村部

2019年8月30日
