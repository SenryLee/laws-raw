# 国家邮政局关于报送2018年度邮政普遍服务监管报告的函

国邮函〔2019〕50号

交通运输部、财政部：

国家邮政局承担邮政监管责任，持续推动建立覆盖城乡的邮政普遍服务体系，依法监督邮政企业按照国家规定承担提供邮政普遍服务的义务。在各有关部门的大力支持下，2018年我国邮政普遍服务水平进一步提升，乡镇一级邮政普遍服务局所全覆盖，建制村直接通邮率超过98.9%，全国80.7%的县市实现《人民日报》当日见报。为了全面、客观反映我国邮政普遍服务能力、水平及发展趋势，国家邮政局编制了《2018年度邮政普遍服务监管报告》，现随文报送，请予审阅。

附件：2018年度邮政普遍服务监管报告

国家邮政局

2019年5月31日
