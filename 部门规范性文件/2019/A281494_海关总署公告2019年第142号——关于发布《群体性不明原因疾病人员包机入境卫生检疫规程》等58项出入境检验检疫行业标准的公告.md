# 海关总署公告2019年第142号——关于发布《群体性不明原因疾病人员包机入境卫生检疫规程》等58项出入境检验检疫行业标准的公告

## 海关总署公告

2019年第142号

## 关于发布《群体性不明原因疾病人员包机入境卫生检疫规程》等58项出入境检验检疫行业标准的公告

现发布《群体性不明原因疾病人员包机入境卫生检疫规程》等58项出入境检验检疫行业标准（标准目录见附件）。《大家白蚁检疫鉴定方法》（SN/T 1105-2014）等8项被代替标准自本批标准实施之日起废止。

本批发布的标准文本可通过中国技术性贸易措施网站（http://www.tbtsps.cn）标准栏目查阅。

特此公告。
