# 国家广播电视总局关于2018年度优秀国产纪录片及创作人才扶持项目申报事项的通知

## 总局关于2018年度优秀国产纪录片及创作人才扶持项目申报事项的通知

广电发〔2019〕28号

各省、自治区、直辖市广播电视局，新疆生产建设兵团文化体育广电和旅游局，中央广播电视总台办公厅，电影频道节目中心，中央新影集团，中国农业电影电视中心，中国教育电视台，国务院国资委办公厅，中央军委政治工作部宣传局：

为表彰奖励优秀国产纪录片作品、人才及制作、播出机构，加快推动中国纪录片产业繁荣发展，国家广播电视总局拟于近期开展2018年度优秀国产纪录片及创作人才扶持项目评审工作。

各省级广播电视行政部门接到此通知后，请立即向所辖（属）纪录片制作机构、播出机构传达本通知精神，并严格按照新修订的《国家广播电视总局年度优秀国产纪录片及创作人才扶持项目评审办法》（附件1）的要求，认真做好本地区、本单位2018年度优秀国产纪录片及创作人才扶持项目的材料审核和申报工作。

扶持项目的申报材料请于2019年4月10日前寄至国家广播电视总局宣传司新闻处（地址：北京复兴门外大街2号 邮编：100866）。

特此通知。

附件：1.国家广播电视总局年度优秀国产纪录片及创作人才扶持项目评审办法

2.优秀国产纪录片短片类申报表

3.优秀国产纪录片长片类申报表

4.优秀国产纪录片系列片类申报表

5.优秀国产纪录片理论文献片类申报表

6.优秀国产纪录片国际传播类申报表

7.优秀国产纪录片导演申报表

8.优秀国产纪录片撰稿申报表

9.优秀国产纪录片摄像申报表

10.优秀国产纪录片栏目申报表

11.优秀国产纪录片播出机构申报表

12.优秀国产纪录片制作机构申报表

国家广播电视总局

2019年3月7日
