# 水利部办公厅关于印发2019年水利政策法规工作要点的通知

部直属各单位，各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团：

为深入贯彻落实中央和水利部党组决策部署，扎实做好水利政策法规各项工作，现将《2019年水利政策法规工作要点》印发给你们，请结合实际做好相关工作。

水利部办公厅

2019年2月14日

## 2019年水利政策法规工作要点

2019年，水利政策法规工作要以习近平新时代中国特色社会主义思想为指导，按照全国水利工作会议部署，聚焦“水利工程补短板、水利行业强监管”总基调，以法规制度定规矩，以监督执法作保障，加快推进水法规制度建设，大力实施水政执法提档升级，加强水法治宣传教育，不断深化水利“放管服”改革，协调推进依法行政、水事纠纷调处、政策研究等工作，不断夯实水利改革发展政策法治基础。

1.加快推进重大立法项目。配合全国人大环资委推进《长江保护法》立法进程。配合司法部做好《地下水管理条例》的审查修改工作，争取2019年颁布实施。抓好《节约用水条例》《河道管理条例》《珠江水量调度条例》立法协调、草案起草（修订）和上报工作，力争列入2020年国务院立法工作计划。

2.抓紧做好机构改革涉水法律法规修改工作。根据机构改革要求及职责调整情况，开展《水法》《防洪法》《水库大坝安全管理条例》《南水北调工程供用水管理条例》等10部法律法规修改前期研究工作，落实国务院第五次大督查整改要求，配合司法部完成《大中型水利水电工程建设征地补偿和移民安置条例》有关条款修改工作。

3.研究修订水法规体系规划。针对水法规制度建设与水利改革发展实践特别是与水利工作总基调不相适应的问题，分门别类、拾遗补缺，梳理立法需求，修订《水法规体系总体规划》，明确立法目标任务，区分轻重缓急，有计划分步骤实施。根据需求和草案成熟度制定修改颁布水利部规章。

4.创新完善水行政执法体制机制。印发加强水利综合执法的通知，总结推广和创新完善地方党委政府主导、水利部门牵头、公安等相关部门参与配合的河湖综合执法、联合执法机制。制定印发《水利部关于全面推行水行政执法公示制度执法全过程记录制度重大执法决定法制审核制度的实施方案》，指导水利系统全面推行“三项制度”。

5.加大水行政执法工作力度。继续实施河湖执法3年工作方案，健全河湖执法日常巡查排查、违法案件查处、大案挂牌督办、动态信息通报等工作制度，落实“两高”司法解释，完善“两法”衔接，加大对涉河湖水事违法案件查处力度。抓好长江经济带生产建设项目水土保持监督执法专项行动。统筹推进水资源管理、水利建设市场、水工程管理、水利安全生产等领域监督执法工作。

6.推进水行政执法能力建设。加强流域管理机构和地方水行政部门水政监察队伍建设，落实执法人员持证上岗和资格管理制度。提前完成《全国水政监察队伍执法能力建设规划（2013—2020年）》目标任务，以提升信息化水平、配套完善装备设施和提高监管能力为重点，编制新一轮规划。

7.扎实开展水利领域扫黑除恶专项斗争。将中央扫黑除恶专项斗争决策部署贯穿于水行政执法全过程，深挖彻查河湖执法以及相关行业监管中发现的涉黑涉恶线索及“关系网”“保护伞”问题，及时向公安等部门移交线索，并配合做好调查取证以及后续查处等工作，组织指导制定河道砂石价值认定和河道非法采砂危害防洪安全鉴定等规范性文件。

8.加强政策研究顶层设计。坚持问题导向和目标导向，根据水利改革发展的新形势新要求新任务和部党组部署，厘清综合性和重大水利政策的内涵、外延和管理方式，建立项目库。修订《水利部政策研究项目管理暂行办法》。围绕健全水法规制度体系，突出政策研究重点，前瞻性、灵活性、有效性开展政策研究，为加快立法奠定基础。

9.进一步精简行政许可事项。按照中央深化“放管服”改革决策部署，“应放尽放”，做好现有水利行政许可事项的清理论证及取消或下放工作，2019年底前再取消“不同行政区域边界水工程批准”许可事项，推进“证照分离”改革工作，防范各类变相审批和许可。

10.进一步加强事中事后监管和提升服务质量。做好水利部政务服务和监管事项目录梳理和流程设计，依托水利部在线政务服务平台，加快实施《水利部“互联网+监管”系统建设和对接实施方案》。创新监管方式，推行“双随机、一公开”监管。加强行政许可标准化建设，进一步优化流程、精简环节，压缩办理时间、材料，取消没有法律法规设定依据的证明，提高审批效率和群众便利度。

11.持续开展水利法治普法宣传教育。坚持“谁执法谁普法”，继续实施“七五”普法规划。举办“第四期全国水利系统司局级领导干部法治专题培训班”，利用“宪法宣传周”“世界水日”“中国水周”等重要时间节点，开展水法规宣传教育工作。

12.扎实做好水事矛盾纠纷调处化解工作。落实水事纠纷调处责任制，健全和完善属地为主、条块结合的水事纠纷调处机制。开展水事矛盾纠纷排查化解活动，确保全年全国水事稳定。

13.依法依规办好行政复议与诉讼。贯彻落实复议诉讼类法律法规和最高人民法院有关司法解释，全面开展行政规范性文件、法律文书的合法性审查和公平竞争审查，加强和改进内部协作、信息公开、行政许可等工作，提高依法行政水平。

14.不断加强工作作风和队伍建设。持续深入学习贯彻习近平新时代中国特色社会主义思想，坚定“四个自信”，增强“四个意识”，坚决做到“两个维护”，坚决贯彻落实部党组各项决策部署。牢固树立抓业务也是抓政治的思想，全面落实全面从严管党治党要求，持之以恒反对“四风”，突出解决形式主义和官僚主义问题。修订和落实水行政执法廉政风险防控手册。加强干部队伍建设，打造“忠诚、干净、担当，科学、求实、创新”的水利政策法规干部队伍。
