# 国家体育总局办公厅关于2019年选派部分优秀运动员及体育管理人员赴境外攻读硕士有关事宜的通知

## 体育总局办公厅关于2019年选派部分优秀运动员及体育管理人员赴境外攻读硕士有关事宜的通知

体科字〔2019〕52号

各省、自治区、直辖市、新疆生产建设兵团体育局，中央军委训练管理部军事体育训练中心，有关运动项目管理中心，中国足球协会，中国篮球协会，有关改革试点项目协会，有关高校：

优秀运动员是我国体育事业发展的宝贵人才，为了更好地发挥优秀运动员的影响力和作用，解决运动员更高层次的教育需求，发挥他们在运动项目方面的特长，为国家培养更多具有国际视野、懂专业、善管理的高层次复合型体育人才，经总局批准，拟选拔一批优秀运动员和体育管理人员赴美国加州浸会大学攻读硕士研究生。现将有关事宜通知如下：

一、选派计划

（一）2019年计划选派20名优秀运动员、2名体育管理人员赴美国浸会大学攻读运动学硕士学位研究生。

（二）2019年5-6月全国公开选拔符合条件的人员。

（三）留学期限为24个月，具体以试点高校学制为准。

（四）为留学人员提供一次往返国际旅费和资助金，包括学费、住宿费、注册费、医疗保险费等。

二、选派条件

（一）具备良好的政治素质和思想品德，爱党爱国，成绩优异，身心健康，无违法违纪记录，有学成回国为中国体育事业发展服务的事业心和责任感。

（二）具有中华人民共和国国籍，不具有国外永久居留权。

（三）2019年（含）之前大学本科毕业并取得相应学位，具备一定英语水平能力。

（四）选派对象：

运动员：须获得奥运项目的亚运会前三名、世锦赛前六名和奥运会前八名的运动员，且无严重兴奋剂违规记录；

体育管理人员：在总局各项目管理中心或协会工作，表现优秀，经单位同意推荐留学人员。

（五）选拔对象不包含已获得硕士及以上学位人员。

三、选派办法

（一）遵循“公开、公平、公正”的原则，采取“个人申请，单位推荐，组织评审，择优录取”的方式进行选派。

（二）2019年公派留学申请受理时间为5月1日--31日。申请人登陆中国运动文化教育网或“体教联盟”app提交《2019年体育总局公派留学推荐表》等相关资料。所有申请材料须确保齐全、真实有效。

（三）推荐单位应对申请人的资格、思想政治表现、综合素质、发展潜力、品德修养及身心健康情况等方面进行审核后，在推荐表上填写推荐意见并盖章后，统一提交至中华体育基金会。

（四）6月上旬，体育总局将对申请人材料进行审核，组织评审，确定拟选派人员，并进行公示。

四、派出与管理

（一）对选派人员的管理实行“签约派出、违约赔偿”的办法。派出前，选派人员须签订《体育总局公派留学协议书》，如选派人员违反协议，将收回资助并予以一定处罚；

（二）经选拔派出人员，将于6月-8月期间组织为期2个月的外语强化培训，并按照要求参加浸会大学组织的面试，具体事宜另行通知；

（三）选派人员须配合中华体育基金会和浸会大学办理出国留学相关手续，并统一于8月下旬赴美入学；

（四）留学期间，浸会大学安排专门生活辅导员，为选派人员提供生活咨询和服务。

（五）选派人员在国外留学期间，应遵守所在国法律法规及学校有关规定及《体育总局公派留学协议书》的有关约定，自觉接受推选单位及驻外使（领）馆的管理。

五、培养方案（具体要求见附件《学校招生简章》）

（一）学制专业：运动学硕士学制2年，专业方向包含运动科学、体育管理和体育教育等。实行弹性学制，采取完全学分制的教学管理制度。

（二）课程设置：依据硕士培养计划，完成运动科学、体育管理和体育教育相关的理论课程，根据选题和相关体育组织实践工作完成硕士论文。

（三）教学组织：学生可依据自身情况进行选择，包含有面授课程、网络课程及混合教学课程，学校尽可能安排当地体育组织和俱乐部进行实习。

（四）论文指导：浸会大学为每位学生选配资历或经验丰富的教师作为学术顾问，辅导其毕业论文写作和答辩。

（五）学籍管理：该项目中的学生按照美国高校留学生规定进行学籍登记注册，相关手续须符合教育部留学基金委的要求。

六、相关费用

将资助选派人员学费、签证费、注册费、医疗保险费、住宿费、书本费和一次往返旅费等约5万美金；

留学期间餐费和杂费等约每年5000-8000美金（按照校方预估统计）由个人承担。
