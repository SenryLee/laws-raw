# 中国气象局关于十三届全国人大二次会议第7710号建议会办意见的函

中气议字〔2019〕2号

国家发展和改革委员会：

宁夏代表团《关于为建设项目区域评估改革提供法律支持的建议》（第7710号建议）收悉。经研究，提出以下会办意见：

我局积极贯彻落实《中央办公厅 国务院办公厅关于印发深入推进审批服务便民化的指导意见的通知》（厅字〔2018〕22号）精神，推动开发区、工业园区的区域性气候可行性论证相关工作规范开展。一是积极推进“开发区、工业园区的区域性气候可行性论证”相关规范编制；二是印发《中国气象局办公室关于加强涉及安全的气候可行性论证工作的通知》（气办函〔2018〕331号），要求各省（区、市）气象局积极推进气候可行性论证纳入地方政府统一推行的“区域评估”或“多评合一”事项。

对于代表们在7710号建议中提出的“关于为建设项目区域评估改革提供法律支持的建议”，我局目前已组织开展《气象法》修订讨论，将积极推进将“工业园区等特定区域范围内”的区域性气候可行性论证有关内容纳入。

以上意见，供你委答复代表时参考。

中国气象局

2019年5月27日
