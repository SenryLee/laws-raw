# 国家文物局关于在大运河浙东运河绍兴段保护区划内实施绍兴市新三江闸排涝配套河道拓浚工程建设项目的意见

文物保函〔2019〕387号

浙江省文物局：

你局《关于上报全国重点文物保护单位大运河之浙东运河绍兴段保护区划内实施绍兴市新三江闸排涝配套河道拓浚工程项目的请示》（浙文物发〔2019〕42号）收悉。经研究，我局原则同意在大运河浙东运河绍兴段保护区划内实施绍兴市新三江闸排涝配套河道拓浚工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应在满足防洪排涝需要的前提下，尽可能控制华顺江、大树江的拓宽尺度，保持浙东运河杭州萧山-绍兴段遗产区边界处（江河交汇口除外）的岸线形态。

（二）应优化工程方案设计，尽可能将华顺江与浙东运河交汇口南移，并根据河道行洪断面要求，在转弯处向南拓宽河道，并适当减少大树江向西拓宽的尺度。

（三）改建、新建堤岸应采用传统堤岸建造材料和工艺做法，沿河绿化应保持原有郊野风貌，景观整体突出自然生态野趣，力求延续浙东运河周边历史环境风貌。

（四）应细化工程施工和运营期间的监测措施、应急预案，以及施工过程中的生态环境、景观风貌等保护要求以及各类污染物处置要求，避免污染大运河及周边环境。

（五）应做好施工结束后的场地清理和周边环境修复工作，采用当地植被对周围区域进行必要的延伸绿化，并设立大运河标识设施和大运河历史文化价值展示设施。

（六）应注意做好大运河及周边区域的生态环境、景观风貌变化情况记录，并将相应数据、记录等提交相关大运河遗产监测系统平台。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年4月24日
