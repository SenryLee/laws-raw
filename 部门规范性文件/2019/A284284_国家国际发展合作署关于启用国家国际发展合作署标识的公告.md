# 国家国际发展合作署关于启用国家国际发展合作署标识的公告

## 关于启用国家国际发展合作署标识的公告

国家国际发展合作署于2018年4月18日正式成立。为使我署在国内国际交流合作中有统一的形象标识，经批准，即日起启用国家国际发展合作署标识。

标识图案如下：

![](https://zk-img.faxin.cn//Uedit_Upload/2019-11-27-11-27-20_8095099_1210368568_15746638372961n.jpg)

国家国际发展合作署标识代表我署的部门形象，任何单位和个人未经许可，均不得擅自使用，否则我署将依法追究其法律责任。

特此公告。

国家国际发展合作署
