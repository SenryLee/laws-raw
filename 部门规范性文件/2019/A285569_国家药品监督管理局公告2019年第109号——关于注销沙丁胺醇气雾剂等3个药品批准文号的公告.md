# 国家药品监督管理局公告2019年第109号——关于注销沙丁胺醇气雾剂等3个药品批准文号的公告

## 国家药品监督管理局公告

2019年第109号

## 关于注销沙丁胺醇气雾剂等3个药品批准文号的公告

根据《中华人民共和国药品管理法实施条例》和《药品注册管理办法》的有关规定，国家药品监督管理局决定注销沙丁胺醇气雾剂等3个药品批准文号。

特此公告。

附件：注销药品批准文号目录

国家药监局

2019年12月23日
