# 商务部办公厅关于印发《推动步行街改造提升工作方案》的通知

商流通字〔2019〕8号

各省、自治区、直辖市、计划单列市及新疆建设兵团商务主管部门：

为贯彻落实党中央、国务院决策部署，加快推动步行街改造提升工作，我们制定了《推动步行街改造提升工作方案》，现印发给你们，请结合本地实际，认真贯彻执行。

商务部办公厅

2019年8月30日
