# 国家文物局办公室关于圆明园遗址蓬岛瑶台中岛扎彩展示项目的意见

办保函〔2019〕65号

北京市文物局：

你局《关于圆明园蓬岛瑶台中岛扎彩展示项目的请示》（京文物〔2018〕1701号）收悉。经研究，我局不同意在圆明园保护范围内实施蓬岛瑶台中岛扎彩展示项目。

一、圆明园遗址是大型皇家宫苑遗址和爱国主义教育基地，具有重要的历史、艺术和科学价值。圆明园遗址展示利用和国家考古遗址公园建设，应注重展现圆明园在中国古代园林艺术中的重要地位，充分发挥其爱国主义教育和警示作用，合理确定展示方式和节点设计。

二、请你局指导有关单位，按照《圆明园遗址公园规划》要求，合理安排近期工作重点，尽快推进大宫门、如园、舍卫城、紫碧山房等遗址的考古和保护展示工作，并加强日常管理和巡护，确保文物安全。

专此函复。

国家文物局办公室

2019年1月25日
