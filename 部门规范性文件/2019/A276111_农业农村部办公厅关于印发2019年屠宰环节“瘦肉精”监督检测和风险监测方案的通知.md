# 农业农村部办公厅关于印发2019年屠宰环节“瘦肉精”监督检测和风险监测方案的通知

农办牧〔2019〕36号

为加强屠宰环节“瘦肉精”监管，强化屠宰环节风险物质监测，有效维护屠宰环节肉品质量安全，我部组织制定了《2019年屠宰环节“瘦肉精”监督检测方案》和《2019年屠宰环节“瘦肉精”等风险监测方案》。现印发给你们，请认真组织开展工作。

农业农村部办公厅

2019年4月8日

附件：2019年屠宰环节“瘦肉精”监督检测和风险监测方案
