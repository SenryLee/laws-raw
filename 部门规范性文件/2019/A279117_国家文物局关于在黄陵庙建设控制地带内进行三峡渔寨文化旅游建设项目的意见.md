# 国家文物局关于在黄陵庙建设控制地带内进行三峡渔寨文化旅游建设项目的意见

文物保函〔2019〕565号

湖北省文化和旅游厅：

你厅《关于申报三峡渔寨文化旅游项目涉及黄陵庙建设控制地带设计方案的请示》（鄂文旅文〔2019〕64号）收悉。经研究，我局原则同意在黄陵庙建设控制地带内进行三峡渔寨文化旅游建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）建议适当降低黄陵庙一侧新建筑高度。建筑形式应注意尊重地方传统，并与文物环境风貌相协调。

（二）进一步缩减硬质铺装面积。

（三）优化沿河栏杆设计，避免过于生硬的界面处理。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》等相关法规，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年6月17日
