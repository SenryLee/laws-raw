# 国家粮食和物资储备局关于在河南湖北四川三省启动2019年中晚稻最低收购价执行预案的通知

国粮粮〔2019〕300号

中国储备粮管理集团有限公司：

你公司《关于在部分地区启动2019年中晚稻最低收购价执行预案的请示》（中储粮〔2019〕233号）收悉。根据国家发展和改革委员会、国家粮食和物资储备局等部门《关于印发小麦和稻谷最低收购价执行预案的通知》（国粮发〔2018〕99号）有关规定，经研究，同意自11月4日起在河南、湖北、四川三省省内符合条件的相关地区启动2019年中晚稻最低收购价执行预案。

国家粮食和物资储备局

2019年10月31日
