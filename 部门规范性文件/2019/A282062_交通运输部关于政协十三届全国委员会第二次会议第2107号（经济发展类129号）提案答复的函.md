# 交通运输部关于政协十三届全国委员会第二次会议第2107号（经济发展类129号）提案答复的函

## 关于政协十三届全国委员会第二次会议第2107号（经济发展类129号）提案答复的函

交海提字〔2019〕28号

何猷龙委员：

您提出的关于加快建设粤港澳大湾区基础设施互联互通的提案收悉。现答复如下：

基础设施互联互通对于粤港澳大湾区发展具有重要的基础性、先导性、全局性作用，而交通基础设施互联互通，是粤港澳大湾区发展的一个重要基础支撑。《粤港澳大湾区发展规划纲要》发布以来，我部组建了推进粤港澳大湾区交通运输发展工作组，统筹推进粤港澳大湾区建设涉及交通运输领域的有关工作，目前正在积极研究制定支持粤港澳大湾区交通运输发展的相关政策文件，全力支持粤港澳大湾区交通基础设施建设，加快构筑具有全球竞争力和影响力的现代化综合交通运输体系。

一、关于粤港澳游艇自由行

随着《粤港澳大湾区发展规划纲要》的推进，粤港澳游艇产业将会进一步发展，也必将对粤港澳游艇自由行提出更高需求，《粤港澳大湾区发展规划纲要》提出了研究简化游艇出入境手续、探索建设国际游艇旅游自由港等措施。珠江口水域航道繁忙，船舶流量大，通航环境复杂，增设自由行口岸涉及面较广，需妥善处理好航运经济和游艇行业发展之间的关系。建议地方政府从长远计，按照法律法规要求，整体考虑粤港澳游艇自由行增设口岸的规划和正式开放事宜，我部将配合国家口岸有关部门，认真做好粤港澳游艇自由行增设口岸开放或扩大开放工作，推动粤港澳游艇产业安全、健康、有序发展。

我部所属广东海事局按照《中国（广东）自由贸易试验区粤港澳游艇自由行实施方案》要求，组织制定海事相关配套实施制度，与澳门海事及水务局多次磋商，共同拟订《中国（广东）自由贸易试验区粤澳游艇自由行海事实施细则》，并在粤澳水上交通安全及航道管理第三次联席会议上就文本内容达成一致意见。下一步我部将支持和指导广东海事局按照《中国（广东）自由贸易试验区粤澳游艇自由行海事实施细则》要求，在优化服务、促进航行安全上下功夫，全力支持粤港澳游艇自由行，服务游艇产业和水运经济发展。

二、关于陆路大联通

按照国务院的总体部署，2019年底将基本取消全国高速公路省界收费站，高速公路进入全网一体化收费运营的新时代，粤港澳大湾区“9+2”高速公路省界收费站的问题将得以解决。至于取消粤港澳大湾区“9+2”高速公路所有收费站，因涉及高速公路债务偿还、建设和养护运营资金筹集等问题，建议由各地政府结合自身财政能力等相关情况，统筹研究决定，确保高速公路健康可持续发展，我部将按照相关法规规定做好指导协调工作。

三、关于城际大联通

《粤港澳大湾区发展规划纲要》提出了“构建现代化的综合交通运输体系”，并就大湾区构建对外综合运输通道、城际快速交通网络、建设世界级港口群、机场群等提出了明确任务要求，提案所提“60分钟城际快速交通网”也已写入规划纲要中。我部将配合国家发展改革委等部门做好城际铁路的规划建设工作。

感谢您对交通运输和粤港澳大湾区基础设施建设的关心和支持。
