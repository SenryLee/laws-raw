# 农业农村部关于政协十三届全国委员会第二次会议第2817号（农业水利类262号）提案答复

## 关于政协十三届全国委员会第二次会议第2817号（农业水利类262号）提案答复

农办案〔2019〕193号

高洁委员：

您提出的关于加大绿色农产品认证建设的提案收悉，经认真研究，现答复如下。

一、关于我国绿色农产品认证现状

增加绿色优质农产品供给是当前农业农村部门的一项重要任务。加强绿色农产品认证是增加绿色优质农产品供给的重要手段。近年来，我部积极发展绿色食品、有机农产品和地理标志农产品等绿色优质农产品公共品牌，取得了显著成效。截至目前，我部认证绿色食品、有机农产品数量分别达34418个、4366个，登记农产品地理标志2638个，建成绿色食品原料标准化生产基地680个，总面积达1.65亿亩。为提高认证水平和产品质量，我部重点加强了两方面工作。一是严格审核把关和证后监管。先后出台了绿色食品地方工作机构许可审查职责等系列规定，建立健全专家评审、问题发现、核查通报等制度。组织开展绿色食品企业年检、产品抽检、市场监察、风险预警等监管工作，及时发现和处理质量不合格和不规范用标的产品和生产主体。二是加大产业技术支撑体系建设。加快标准制修订，累计发布绿色食品标准141项，区域性生产操作规程400多项。组织重大课题研究，开展定点检测机构能力提升行动，加强开展绿色食品、有机农产品和农产品地理标志信息化平台建设，为优质绿色农产品认证提供技术支撑保障。

下一步，我部将贯彻落实新发展理念，立足当地资源禀赋和环境优势，按照增加绿色优质安全农产品有效供给的要求，坚持“稳中求进、保证质量”的原则，突出抓好重点地区、重点企业和重点产品的发展。建立健全审查制度和通报反馈机制，实施“部—省—市”三级审查，落实分段审查责任，提高准入门槛，有效防范审查与认证风险，切实提高审查认证登记的质量和效率。加强绿色优质农产品在国家农产品质量安全追溯平台的推广应用，落实追溯管理、创建认定、产品认证等挂钩制度，建立准入准出衔接机制，着力保障产品质量安全。

二、关于加大宣传推介，提升绿色农产品品牌效益

我部高度重视绿色农产品品牌宣传工作，举办全国绿色食品和有机食品博览会、区城性绿色农产品展会与产销对接等活动，积极培育绿色农产品消费市场。组织和支持企业参加国际食品行业博览会，开展国际交流与贸易合作，扩大绿色品牌国际影响力。持续开展“春风万里，绿食有你”宣传月行动。仅2018年，我部在23个省区市115个市（县）共举办了256场活动，展出了1500余家绿色食品企业1万多个产品，接待了消费者12.8万人次，发放了知识手册3.5万册。利用中央和地方权威媒体开展多种形式公益宣传，组织拍摄的大型系列纪录片《源味中国》第一季，受到社会广泛关注和好评，绿色优质农产品品牌知名度显著提升。

下一步，我部将继续组织开展品牌公益宣传活动，讲好绿色优质农产品品牌故事，创响一批“土字号”“乡字号”特色农产品品牌，增加产业发展内生动力。引导营销机构建立专营模式，搭建线上线下交易平台，推动传统和现代营销模式相融合，开展国际交流与双边或多边互认合作，提高我国绿色优质农产品的国际竞争力。

三、关于加大农业技术指导和培训力度

我部高度重视农业农村技术人才培训，每年安排专项资金开展农业技术指导和农产品质量安全、投入品管理、信息化服务等培训活动，结合绿色食品认证，在绿色食品企业全面建立内检员制度，将内检员作为绿色食品申报的前置条件。通过培训，在全国已经形成一支素质高、能力强的技术和管理人员，有效提升绿色有机农产品质量安全管控水平。截至2018年底，全国绿色食品检查员2944人，监管员1995人，企业内检员25614人，有机产品注册检查员266人，企业内检员5000人。

下一步，我部将继续加强对绿色农产品生产经营主体的技术培训与指导力度，全面实施绿色食品生产标准和技术规程，加强农业投入品管理，建立农产品质量安全追溯制度，从源头提升农产品质量安全水平。

四、关于加大政策支持力度

目前，我国多数地区都将绿色食品和有机农产品纳入了当地经济发展考核体系，因地制宜地建立考核指标，促进地方政府对优质绿色农产品的政策创设和资金扶持，在绿色食品和有机农产品的申报、检测、评审等环节实施补贴政策，基本抵消申报和认证成本，全国绿色食品申报呈现快速增长态势。2019年5月1日起，我部对绿色食品申报主体认证审核费和标志使用费统一下调20％，对国家级贫困县在减免部分标志使用费用的基础上，自2019年5月1日至2021年1月1日，全部实施免收绿色食品认证审核费和标志使用费，进一步加大了对贫困地区的费用减免力度。

下一步，我部将继续加大对优质绿色农产品生产的政策支持和费用减免力度，利用农业展会和产销对接平台，加强绿色优质农产品宣传推介，实现品牌溢价和优质优价。

感谢您对绿色农产品认证建设的关注，希望今后继续支持我部工作。

农业农村部

2019年8月30日
