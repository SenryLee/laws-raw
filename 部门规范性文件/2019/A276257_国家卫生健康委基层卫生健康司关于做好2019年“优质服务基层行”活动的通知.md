# 国家卫生健康委基层卫生健康司关于做好2019年“优质服务基层行”活动的通知

## 关于做好2019年“优质服务基层行”活动的通知

国卫基层运行便函〔2019〕9号

各省、自治区、直辖市及新疆生产建设兵团卫生健康委基层卫生处：

为确保“优质服务基层行”活动（以下简称活动）取得实效，根据《关于开展“优质服务基层行”活动的通知》（国卫基层函〔2018〕195号）和《关于印发2019年卫生健康重点工作任务及分工方案的通知》（国卫办函〔2019〕34号）精神，现就做好2019年活动有关工作通知如下：

一、加强组织领导，确保活动质量

（一）提高工作认识。活动是新时期提升基层服务能力？和改善服务质量的重要抓手，是建立优质高效医疗卫生服务体系的重要内容。各地要进一步提高思想认识，做好动员部署，积极主动开展工作，2019年遴选一批达到乡镇卫生院和社区卫生服务中心（以下简称基层机构）服务能力基本标准或推荐标准的基层机构，确保活动取得预期效果。

（二）加强组织领导。各级地方卫生健康行政部门要建立健全工作制度，成立本级活动领导小组，建立工作机制；要组建相应的专门组织或第三方机构，负责活动的技术指导、抽查复核等工作。

（三）组建专家队伍。省、市级卫生健康行政部门要及时组建本级专家队伍，严格专家准入资格，做好做实复核工作。请各省（区、市）于2019年4月30日前推荐4名专家作为我委专家组候选人（专家信息表见附件1），原则上应具有正高级专业技术职称，熟悉基层医疗卫生机构情况，其中推荐管理类专家1名，医疗、护理、中医药、医院感染等其他领域专家3名。

二、严格评价标准，把握活动节奏

（四）用好评价指南。各级地方卫生健康行政部门要加强对《乡镇卫生院服务能力评价指南（2019年版）》和《社区卫生服务中心服务能力评价指南（2019年版）》（国卫办基层函〔2019〕287号，以下简称《评价指南》）的培训和使用，县级卫生健康行政部门要组织基层机构对照《评价指南》进行整改提升。各地在开展中央转移地方“基层卫生人才能力提升培训项目”中，应将《评价指南》作为基层医疗卫生机构管理人员的培训重点。在《评价指南》应用中发现的问题和意见建议，请及时向我司反馈。

（五）统筹活动安排。各级地方卫生健康行政部门要把握工作节奏，杜绝出现“赶进度”“重数量”等情况。基层机构应按要求制定活动方案、召开活动启动会并对照《评价指南》开展自评自查和整改提升，不断提升服务能力，改善服务质量。对于参加医联体或医共体的基层机构，其《医疗机构执业许可证》的机构名称为“卫生院”或“社区卫生服务中心”的均应参加活动。

三、规范评价流程，强化结果应用

（六）建立申报平台。为做好自评和复核工作，我司组织中国医学科学院医学信息研究所开发了“优质服务基层行活动”申报信息系统（登录http://www.nbphsp.org.cn/，进入“优质服务基层行”申报栏目），拟于2019年5月20日正式运行。基层机构原则上均应通过该信息系统进行自评，达到基本标准或推荐标准的基层机构可以将自评结果上报并由市级或省级卫生健康行政部门组织开展复核。在使用信息系统过程中遇到任何问题，请向中国医学科学院医学信息研究所反馈。

（七）规范复核流程。省、市级卫生健康行政部门组织开展的复核应采取信息系统上报资料复核和现场复核相结合的方式进行。对于复核后未达到基本标准或推荐标准的基层机构，应通过信息系统逐级退回，再次申请复核的时间间隔不少于6个月。我司将适时组织开展活动一致性评价。

（八）强化结果应用。各级地方卫生健康行政部门应积极协调有关部门，对达到推荐标准的基层机构在评优评先等方面予以倾斜。达到推荐标准的乡镇卫生院，符合相关条件的可参加二级医院评审；达到推荐标准的社区卫生服务中心，优先作为社区医院试点。

四、遴选典型经验，加强宣传培训

（九）宣传典型经验。各地应注重经验总结和典型宣传，包括组织开展活动的工作经验和基层机构提高服务能力、优化诊疗流程、改进服务质量、改善群众就医体验等方面的创新做法和举措等，并适时在报纸、微信平台等媒体上宣传。我司委托健康报社开展优质服务基层行宣传推广活动，各地可向健康报社报送相关宣传资料（登录http://www.jkb.com.cn，进入“聚焦基层，传播亮点”栏目）。

（十）报送工作总结。省级卫生健康行政部门应于2019年10月31日前将活动开展的年度总结报告、达到推荐标准的基层机构名单（名单样式见附件3）报送我司。为做好这项工作，请你处确定一名具体负责该项工作的联系人，于2019年4月30日前报送我司（见附件2）。
