# 国家文物局关于来安半塔保卫战旧址保护规划的意见

文物保函〔2019〕38号

安徽省文化和旅游厅：

原安徽省文物局《关于上报〈来安半塔保卫战旧址保护规划〉的请示》（皖文物保〔2018〕49号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）进一步梳理半塔保卫战历史事件与各物质要素的关联关系，明确文物本体。

（二）根据文物本体类型差异，分类评估现存主要问题，明确评估结论，并补充对周边历史建筑的调查评估。

（三）对应评估结论，增强保护措施针对性。应在考古调查基础上研提二师师部遗址保护措施，不宜在依据不充分的情况下提出将之复原至柱础。

（四）细化保护范围管理规定，提出具体管控要求；补充保护区划四至坐标。

（五）突出展示重点，建议将半塔保卫战与相关重要革命领袖、军事家生平事迹相结合，丰富展示主题及内容；对供给所、兵工厂和大会堂进行基址展示的必要性不足，可考虑采用树立标识牌、室内影像辅助等手段阐释相关价值。

（六）校核、规范图文表达；补充环境整治措施图等必要图纸。

二、请你厅指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善，经你厅核准后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，报请安徽省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你厅指导和协调地方人民政府在保护规划的指导下，进一步做好来安半塔保卫战旧址的各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年1月9日
