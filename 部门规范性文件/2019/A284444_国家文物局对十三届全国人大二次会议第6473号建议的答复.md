# 国家文物局对十三届全国人大二次会议第6473号建议的答复

文物保函〔2019〕632号

江吉村等6名代表：

您提出的“关于推进德格印经院申报世界文化遗产工作的建议”收悉，现答复如下。

德格印经院位于四川省甘孜藏族自治州德格县，清雍正七年（1729年）由德格第十二代土司却吉登巴泽仁创建，占地1565平方米，为藏式密梁平顶的土木结构建筑。经院现保存桦木所刻藏文典籍书版21.7万余块（两面刻字，43万多页）和少量藏画版，内容主要有各种佛教、传记、医学、哲学、天文历算等，共八十二部，五百八十六册，其中著名的有《甘珠经》《萨迦全书》《四部医典》《西藏王统明鉴》《唐东王传》等文献。

1996年，国务院将“德格印经院”公布为第四批全国重点文物保护单位。自2004年以来，国家文物局对德格印经院的保护修缮、安防和消防工程等，给予了460余万元的经费支持。

近年来，世界遗产申报工作的难度逐渐加大。根据世界遗产委员会新施行的“限额制”，一个缔约国每年最多只能申报一项世界遗产。同时，世界遗产委员会不断推进世界遗产均衡性的全球战略，明确向没有世界遗产或世界遗产较少的国家，以及遗产类型较少的类别倾斜，而对世界遗产大国的限制则不断增多。

我国是世界遗产大国，目前拥有世界遗产53项，其中文化遗产36项，居世界第二。世界遗产中心和国际古迹遗址理事会等专业咨询机构对我国等世界遗产大国的申报项目，往往提出更高的标准。按照《保护世界文化和自然遗产公约》及其《操作指南》的规定，申报世界文化遗产的项目，应该具有全世界范围内的突出普遍价值，较好的保存现状，真实性和完整性较高，扎实的保护管理基础，以及利益相关者对遗产保护的积极态度。这都要求我国的申报项目要在各方面做好充分的准备。

德格印经院申报世界遗产工作基础相对薄弱。国家文物局将指导当地政府和文物行政部门，深化对德格印经院的突出普遍价值的研究和提炼，明确遗产定位，清晰阐述其符合的世界文化遗产标准，并与国内外同类型遗产进行深入对比分析；加强保护管理机构建设和管理能力提高，制订颁行切实有效的法律法规，妥善保护遗产本体，并注重与利益相关者的沟通协调。

国家文物局将按照《国家文物保护专项资金管理办法》的规定，在文物修缮、环境整治等方面，继续对德格印经院的保护给予尽可能的资金支持。在条件成熟后，可根据当地政府申请，考虑将德格印经院列入《中国世界文化遗产预备名单》。

感谢您对祖国文物事业的关注和支持！

国家文物局

2019年7月5日
