# 国家体育总局社体中心关于印发《飞盘观察员选派与监督实施细则（试行）》的通知

## 体育总局社体中心关于印发《飞盘观察员选派与监督实施细则（试行）》的通知

各相关单位：

为加强团队飞盘项目观察员队伍的建设，严肃赛风赛纪，确保全国各级团队飞盘比赛观察员选派工作的公平公正进行，保证观察员任务的顺利完成，现印发《飞盘观察员选派与监督实施细则（试行）》，请遵照执行。

附件：飞盘观察员选派与监督实施细则（试行）

体育总局社体中心

2019年10月21日
