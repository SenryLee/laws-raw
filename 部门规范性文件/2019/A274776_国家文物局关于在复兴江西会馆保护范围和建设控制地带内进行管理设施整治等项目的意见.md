# 国家文物局关于在复兴江西会馆保护范围和建设控制地带内进行管理设施整治等项目的意见

文物保函〔2019〕208号

贵州省文化和旅游厅：

原贵州省文物局《关于审批全国重点文物保护单位复兴江西会馆保护范围和建设控制地带内管理设施等工程的请示》（黔文物呈〔2018〕55号）收悉。经研究，我局原则同意在复兴江西会馆保护范围和建设控制地带内进行管理设施整治等项目。

一、所报方案尚需作以下必要的修改和完善：

（一）补充分析文物建筑与周边建筑格局的演变过程，细化文物建筑与临近周边建筑结构关系的勘察，作为文物库房改造依据。

（二）文物库房的改造，应完善深化后檐墙与文物建筑山墙及东西山墙的改造措施，确保文物建筑安全。

（三）文物库房后墙北移后，补充完善文物建筑北侧区域的散水和排水设计，避免积水等诱发病害的发生。

（四）不建议将公共卫生间安置于文物库房内，可利用现有其他建筑改造为卫生间。

二、请你厅指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你厅会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月28日
