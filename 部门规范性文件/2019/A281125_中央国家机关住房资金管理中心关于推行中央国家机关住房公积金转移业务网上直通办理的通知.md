# 中央国家机关住房资金管理中心关于推行中央国家机关住房公积金转移业务网上直通办理的通知

## 关于推行中央国家机关住房公积金转移业务网上直通办理的通知

国机房资〔2019〕3号

中央国家机关各部门、各单位住房公积金管理机构：

为深入贯彻落实住房公积金"放管服"改革要求，进一步优化住房公积金转移业务，不断提升缴存单位和职工的满意度，定于2019年8月28日起，全面推行住房公积金转移业务网上直通办理，现将有关事项通知如下：

一、中央国家机关住房公积金转移业务网上直通办理，是面向中央国家机关住房资金管理中心（以下简称资金中心）缴存单位，推出的网上办理住房公积金转移业务的便捷方式，业务范围为缴存职工住房公积金个人账户在资金中心归口管理单位之间的转移业务。

二、单位可通过登录资金中心住房资金管理系统单位版（以下简称单位版），进入住房公积金"内部转移查询"页面，自助开通住房公积金转移业务网上直通办理。开通后，单位在单位版"内部转移录入"页面，准确录入转出职工住房公积金账户相关信息，保存并提交后即可将职工住房公积金个人账户实时转出至新单位，不需到经办网点办理。

三、单位务必认真核实转出职工姓名、身份证号、转入单位名称及住房公积金单位账号等重要信息，确保信息准确无误。

中央国家机关住房资金管理中心
