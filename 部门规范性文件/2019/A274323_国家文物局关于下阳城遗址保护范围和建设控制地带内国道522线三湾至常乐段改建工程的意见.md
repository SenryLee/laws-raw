# 国家文物局关于下阳城遗址保护范围和建设控制地带内国道522线三湾至常乐段改建工程的意见

文物保函〔2019〕137号

山西省文物局：

你局《关于国道522线三湾至常乐段改建工程穿越全国重点文物保护单位下阳城遗址的请示》（晋文物〔2018〕140号）收悉。经研究，我局原则同意在下阳城遗址保护范围和建设控制地带内实施国道522线三湾至常乐段改建工程。

一、所报方案尚需做以下必要的修改和完善：

（一）根据文物保护需求调整、明确线路穿越下阳城遗址的具体形式、路基布设情况等，补充线路穿越遗址的剖面图和相关结构图。

（二）完善该区段具体施工方案，严格控制工程范围和施工强度，划定必要的安全距离，降低施工振动影响，不得在文物保护范围内随意开挖动土，做好施工中的文物保护工作，确保文物安全。

（三）明确施工后的植被恢复和环境整治措施，降低工程建设对下阳城遗址及其环境的影响。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古调查和发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月11日
