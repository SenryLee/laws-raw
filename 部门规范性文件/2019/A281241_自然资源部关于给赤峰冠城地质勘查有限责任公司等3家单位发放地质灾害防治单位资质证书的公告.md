# 自然资源部关于给赤峰冠城地质勘查有限责任公司等3家单位发放地质灾害防治单位资质证书的公告

## 关于给赤峰冠城地质勘查有限责任公司等3家单位发放地质灾害防治单位资质证书的公告

根据《行政许可法》《地质灾害防治条例》（国务院令第394号）和《地质灾害危险性评估单位资质管理办法》（国土资源部令第29号）、《地质灾害治理工程勘查设计施工单位资质管理办法》（国土资源部令第30号）、《地质灾害治理工程监理单位资质管理办法》（国土资源部令第31号）的规定，我部对2019年第一批、第二批地质灾害防治单位甲级资质申请审查中被举报单位、材料存疑单位进行核查。

经核查，赤峰冠城地质勘查有限责任公司、宁波宁大地基处理技术有限公司、四川兴水岩土工程有限责任公司等3家单位被举报、存疑事项未发现问题，根据资质审查专家组审查意见，赤峰冠城地质勘查有限责任公司申请的地质灾害防治单位危险性评估、设计甲级资质予以通过，宁波宁大地基处理技术有限公司申请的地质灾害防治单位危险性评估、监理甲级资质予以通过，四川兴水岩土工程有限责任公司申请的地质灾害防治单位勘查、施工甲级资质予以通过。

请以上3家单位从即日起到自然资源部政务大厅办理领证事宜。领取新资质证书，请携带领取人身份证原件和复印件、单位介绍信（委托书）、乙级资质证书原件（新设）、原甲级资质证书原件（延续）。
