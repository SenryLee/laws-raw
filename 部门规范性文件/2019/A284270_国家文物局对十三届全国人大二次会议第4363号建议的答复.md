# 国家文物局对十三届全国人大二次会议第4363号建议的答复

文物保函〔2019〕562号

侯华梅代表：

您提出的“关于支持赵王城国家考古遗址公园建设并验收挂牌的建议”收悉，现答复如下：

赵王城遗址位于河北省邯郸市，是我国战国时期列国都城遗址中保存较为完整的典型标本，对研究先秦史、都城发展史等具有重要意义，1961年被国务院公布为全国重点文物保护单位。国家文物局高度重视、长期支持赵王城遗址的考古研究与保护展示工作。“十一五”以来，将赵邯郸故城遗址（含赵王城）列入国家大遗址保护项目库；2013年，赵王城遗址列入第二批国家考古遗址公园立项名单。

您提出在资金安排、考古计划审批、遗址博物馆提升改造等方面加大支持力度的建议非常重要。国家文物局将继续指导河北省、邯郸市人民政府和文物部门，做好以下工作。

第一，督促河北省文物局组织考古专业机构尽快实施赵王城遗址考古工作计划，进一步了解赵王城遗址的总体布局、遗迹分布特点和保存现状，积极开展多学科综合研究，深入挖掘赵王城遗址的重要价值和深刻内涵。同时，督促考古单位加快资料整理、报告出版进度，为赵王城遗址保护利用提供科学依据。

第二，督促地方人民政府落实文物保护的主体责任，按照《国家考古遗址公园管理办法（试行）》《国家考古遗址公园建设及运行管理指南（试行）》等文件要求，编制赵王城考古遗址公园规划，明确公园的功能定位、建设规模、展示主题和运营管理模式，做好节点设计，稳步推进项目实施。涉及遗址博物馆建设项目，应尽快编制遗址博物馆设计方案，并履行报批程序。

第三，指导地方人民政府强化机构建设和日常管理，提升赵王城遗址的保护管理能力和展示服务水平。国家文物局将在以后的国家考古遗址公园评定工作中，结合赵王城考古遗址公园建设进度和效果予以综合考虑。

感谢您对文物事业的关心和支持。

国家文物局

2019年6月18日
