# 国家民族事务委员会关于废止部分规范性文件的通知

## 国家民委关于废止部分规范性文件的通知

各省、自治区、直辖市及新疆生产建设兵团民（宗）委（厅、局），委机关各部门、直属各单位：

为加强法治政府建设，国家民委对现行的规范性文件进行了清理，决定废止19件规范性文件。

国家民委
