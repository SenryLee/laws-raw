# 人力资源社会保障部办公厅、财政部办公厅关于2019年国家级高技能人才培训基地和国家级技能大师工作室项目单位备案的通知

## 人力资源社会保障部办公厅　财政部办公厅关于2019年国家级高技能人才培训基地和国家级技能大师工作室项目单位备案的通知

人社厅函〔2019〕197号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）、财政厅（局），各计划单列市人力资源社会保障局、财政局：

为进一步加强高技能人才队伍建设工作，2016年人力资源社会保障部、财政部印发了《关于深入推进国家高技能人才振兴计划的通知》（人社部发〔2016〕74号），明确“十三五”期间继续组织开展国家级高技能人才培训基地和国家级技能大师工作室项目建设工作。各省、自治区、直辖市及新疆生产建设兵团，计划单列市（以下简称各地）人力资源社会保障、财政部门认真履行工作职责，积极组织开展项目评审工作，并报送了2019年项目建设单位备案材料。北京市工贸技师学院等127家单位为2019年国家级高技能人才培训基地项目单位。陶建伟技能大师工作室等161家单位为2019年国家级技能大师工作室项目单位。

按照有关文件要求，人力资源社会保障部、财政部现对2019年项目单位正式予以备案。请各地严格按照有关要求，认真执行上报项目确定的项目目标和任务，确保项目各项工作有序、规范、高效完成。项目建设周期结束后，要按规定将项目总结报告和绩效考评意见报送财政部、人力资源社会保障部，两部将适时对各地项目资金使用情况进行检查。

请各地人力资源社会保障厅（局）、财政厅（局）继续开展2020年项目工作，自行组织开展项目评审，并按时做好备案工作，截止日期为2020年7月30日。

附件：1.2019年国家级高技能人才培训基地项目单位

2.2019年国家级技能大师工作室项目单位

人力资源社会保障部办公厅　财政部办公厅

2019年12月11日
