# 中国气象局办公室关于公布2019年全国气象科普讲解大赛获奖名单的通知

气办函〔2019〕128号

各省（区、市）气象局，各直属单位，行业相关单位：

为深入宣传贯彻习近平新时代中国特色社会主义思想和党的十九大精神，深入实施创新驱动发展战略，弘扬科学精神，普及气象知识，提高气象科学技术传播能力，作为2019年气象科技活动周的一项重点活动，中国气象局联合中国气象学会，以“科技强国 气象万千”为主题举办了2019年全国气象科普讲解大赛。

本次大赛于4月18—19日在四川成都举行，得到了各级气象部门和行业相关单位的高度重视与积极响应，来自全国的102名选手参加了比赛。经过预赛和决赛两轮角逐，韩文斐等3位选手获得一等奖，于宙等6位选手获得二等奖，周晨等15位选手获得三等奖，王维等21位选手获得优秀奖，具体名单详见附件。

现将获奖名单予以公布，希望广大气象科普讲解人员向获奖选手学习，进一步提升气象科学传播能力，在全社会广泛普及气象知识，弘扬科学精神，传播科学思想，倡导科学方法，为气象事业发展作出更大贡献。

附件：2019年全国气象科普讲解大赛获奖名单

中国气象局办公室

2019年6月5日
