# 全国继续医学教育委员会关于扩大国家级继续医学教育项目电子学分证书使用范围的通知

## 关于扩大国家级继续医学教育项目电子学分证书使用范围的通知

全继委办发〔2019〕09号

各有关单位：

按照国家卫健委科教司关于加强继续医学教育信息化建设的总体要求，为进一步提升继续医学教育信息化管理与服务水平，方便参加国家级继续医学教育项目的学员查询所获学分情况，“国家级CME项目网上申报及信息反馈系统”（http://cmegsb.cma.org.cn）于2018年11月起，在辽宁省、甘肃省、河南省3个省份和中国医学科学院、中华预防医学会、中华护理学会3家单位开展了试点工作。该试点工作为国家级继续医学教育项目学员和继续医学教育工作人员提供了便利，受到试点单位的广泛认可和学员好评。

为进一步扩大国家级继续医学教育项目电子学分证书使用与服务范围，该功能将于2019年8月1日起，在向我办直接申报项目的委直属联系单位和学协会（含行业学术团体）范围内启用。各项目申办单位须在系统首页的“举办项目时，请下载此Excel模板建学员通讯录”处下载Excel模板并按模板要求建立学员通讯录，在项目举办结束后的2周内认真填报学员通讯录等执行情况；具有审核职能的行政用户收到申办单位报送的项目执行情况数据后，应在2周内完成对所报数据的审核确认相关工作。项目执行情况经审核通过后，在系统首页“学分查询”处，输入相应的学员姓名、项目编号（或项目名称），便可查询打印国家级继续医学教育项目学员学分证书。

本通知在国家卫生健康委科教司网站（http://www.nhc.gov.cn/qjjys）、中华医学会网站（http://www.cma.org.cn/）公布。

附件：国家级继续医学教育项目电子学分证书样式

全国继续医学教育委员会办公室

（中华医学会代章）
