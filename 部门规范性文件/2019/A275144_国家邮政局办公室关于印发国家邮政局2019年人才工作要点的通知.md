# 国家邮政局办公室关于印发国家邮政局2019年人才工作要点的通知

各省、自治区、直辖市邮政管理局，国家局直属各单位、机关各司室：

现将《国家邮政局2019年人才工作要点》印发给你们，请认真贯彻落实。

国家邮政局办公室

2019年2月21日

## 国家邮政局2019年人才工作要点

2019年是新中国成立70周年，是决胜全面建成小康社会的关键之年。全国邮政行业人才工作的总体思路是：以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，深入落实新时代党的组织路线，坚持党管人才原则，加快实施“人才强邮”战略，着力培养造就高素质优秀人才队伍，为邮政业高质量发展和邮政强国建设提供坚实的人才保障和智力支持。

一、加强人才工作组织领导

1.系统谋划人才工作。组织召开首次全国邮政行业人才工作会议，系统总结邮政体制改革以来特别是党的十八大以来的行业人才工作，启动邮政业“十四五”规划邮政行业人才队伍建设预研，全面谋划未来一段时期的工作安排。（领导小组办公室）

2.完善人才工作格局。定期召开全国邮政行业人才工作领导小组会议，制定2019年人才工作要点并抓好督办落实。推动省级邮政管理部门全部成立人才工作领导小组。（领导小组办公室）

3.强化人才工作政治引领。制定印发实施方案，深入开展“弘扬爱国奋斗精神、建功立业新时代”活动，在邮政行业知识分子中大力弘扬爱国奉献精神，激励广大行业人才建功立业新时代。（领导小组办公室）

二、加强专业技术人才队伍建设

4.全面推开快递工程技术人员职称评审。深入推进职称制度改革，总结快递工程技术人员职称评审试点工作经验，在全国范围内全面推开，力争评审总量突破1万人次。（人事司、市场监管司、职业技能鉴定指导中心）

5.实施邮政行业科技英才推进计划。加强和改进优秀专业技术人才培养工作，实施邮政行业科技英才推进计划，制定管理办法，遴选出一批邮政行业科技英才，集中各方力量加大支持，努力造就一批科技领军人才。（人事司、政策法规司、市场监管司、普遍服务司、职业技能鉴定指导中心）

6.办好高层次人才示范培训。继续申办国家专业技术人才知识更新工程高级研修项目，充分发挥高层次培训的示范引领作用。（人事司、职业技能鉴定指导中心）

7.做好优秀专业技术人才选拔推荐。组织推荐优秀行业专业技术人才参加交通运输部和国家有关评选表彰活动。（人事司、政策法规司、市场监管司、普遍服务司、职业技能鉴定指导中心）

三、推进技能人才队伍建设

8.推进职业技能等级评定。根据国家职业资格制度改革精神和政策，推进建立快递从业人员技能等级认定制度，协调做好快递员、快件处理员职业标准审定颁布工作，组织开展相对应的大纲、教材、题库建设工作。（人事司、职业技能鉴定指导中心）

9.实施邮政行业技术能手推进计划。加强和改进优秀高技能人才培养工作，实施邮政行业技术能手推进计划，制定管理办法，遴选出一批邮政行业技术能手，集中各方力量加大支持，推动行业紧缺急需高技能人才队伍发展。（人事司、政策法规司、市场监管司、普遍服务司、职业技能鉴定指导中心）

10.办好2019年职业技能竞赛。完善行业职业技能竞赛制度，筹备办好2019年全国邮政行业职业技能竞赛。（人事司、市场监管司、职业技能鉴定指导中心、中国邮政快递报社、中国快递协会，江西省邮政管理局）

11.开展高技能人才选拔推荐。组织推荐优秀行业技能人才参加“全国交通技术能手”等部委和国家有关评选表彰活动。（人事司、政策法规司、市场监管司、普遍服务司、职业技能鉴定指导中心）

四、加强管理人才队伍选拔培养

12.抓好干部选任工作。突出政治标准，拓宽选人用人视野，注重选拔敢于负责、勇于担当、善于作为、工作实绩突出的干部。加强优秀年轻干部队伍建设。（人事司）

13.加大干部交流锻炼力度。健全干部交流机制，优化干部成长路径。坚持基层导向，强化实践锻炼。（人事司）

14.强化干部教育培训管理。研究制定《全国邮政管理系统干部教育培训规划（2018-2022）》，推进干部教育培训基地建设，强化培训计划管理，启动局管干部轮训，抓好干部调训，推进干部在线学习全覆盖。（人事司）

15.开展干部专业化能力培训。围绕国家局重大决策部署，突出问题导向、实践导向，组织开展务实管用的专业化培训，提升干部的专业能力专业水平。（人事司、办公室、政策法规司、普遍服务司、市场监管司、机关党委）

16.注重干部考核监督。强化干部日常考核和结果运用，研究制定容错纠错实施办法，激励干部担当作为。推动干部监督工作向纵深发展。（人事司）

17.做好国际化人才培养。做好亚太邮联有关培训人员选派、出国境培训组织管理工作。加大国际组织后备人才培养、储备和推送。推进高端引智工作。（办公室、人事司）

五、推动现代邮政教育发展

18.完善人才教育培养体系。支持共建学院和研究院发展，推进行业人才培养基地建设，协调做好学科专业建设、教材建设和师资队伍建设，支持共建学院申报行业内外课题科研项目和国家级重点实验室，积极协调落实经费，将共建学院优秀人才纳入行业优秀人才推进计划选拔范围。（人事司、办公室、政策法规司、普遍服务司、市场监管司、机关党委、职业技能鉴定指导中心）

19.深化产教融合校企合作。指导办好“强邮论坛”、现代邮政学院院长联席会等活动，搭建供需对接、协同育人平台。（人事司、中国邮政快递报社、中国快递协会）

20.充分发挥全国邮政职业教育教学指导委员会作用。指导召开年度工作会议、快递专业建设研讨会，协调办好职业活动周，推进职业院校邮政快递专业示范点建设，推动扩大专业人才培养规模。（人事司、职业技能鉴定指导中心）

21.办好全国“互联网+”快递大学生创新创业大赛。总结经验，提升质量，筹备办好第四届全国“互联网+”快递大学生创新创业大赛。（人事司、职业技能鉴定指导中心、中国邮政快递报社、中国快递协会，陕西省邮政管理局）

六、营造人才发展良好环境

22.推进快递员关爱工程。加强从业人员权益保护和从业青年联系服务工作，开通12355维权热线，开展快递从业青年服务月活动，组织快递员参与各级共青团与人大代表、政协委员“面对面”活动。开展快递员职业满意度调查，改善工作环境，继续办好寻找“最美快递员”活动。（人事司、机关党委、市场监管司、职业技能鉴定指导中心、中国邮政快递报社、中国快递协会）

23.提升从业人员素质。落实《国家邮政局关于提升快递从业人员素质的指导意见》，进一步提升快递从业人员职业素质、职业地位和职业荣誉，提高服务能力和水平。（人事司、政策法规司、市场监管司、机关党委、职业技能鉴定指导中心、中国邮政快递报社、中国快递协会）

24.加强专家联系服务。发挥交通运输部专家咨询委员会邮政组、邮政业标准化技术委员会、邮票选题咨询委员会等邮政业智库作用，为专家参与邮政强国战略实施创造条件。（人事司、政策法规司、普遍服务司）

25.强化行业人才宣传。发挥行业媒体优势，注重行业人才政策解读、经验介绍和先进典型宣传，扩大行业人才工作的影响力。（人事司、职业技能鉴定指导中心、中国邮政快递报社）
