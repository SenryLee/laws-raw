# 农业农村部对十三届全国人大二次会议第2873号建议的答复

## 对十三届全国人大二次会议第2873号建议的答复

农办议〔2019〕199号

您提出的关于生物质资源替代化石资源的建议收悉。经商财政部、能源局，现答复如下。

一、关于扶持生物质炼制产业发展

生物质炼制是农作物秸秆综合利用的有效途径。我部对此高度重视，近年来秸秆综合利用水平和能力稳步提高，2017年全国秸秆综合利用率达到83.68%。一是强化规划引领。2016年，我部会同发展改革委印发了《关于编制“十三五”秸秆综合利用实施方案的指导意见》，要求各地因地制宜，合理安排秸秆肥料化、饲料化、燃料化、原料化和基料化“五料化”利用，鼓励推广保护性耕作、秸秆青贮、氨化、生物气化、热解气化、沼气发酵、固化成型等技术。二是强化试点示范。2016—2018年，我部会同财政部安排中央财政资金38亿元，支持12个省200多个县整县推进秸秆综合利用，带动地方和社会投资近百亿，秸秆还田能力显著提升。今年，中央财政继续安排19.5亿元资金，支持各地开展秸秆“五料化”利用和收储运体系建设。三是强化模式推广。我部先后遴选19项秸秆利用技术，发布了东北高寒区玉米秸秆深翻养地模式、秸–饲–肥种养结合模式、秸–沼–肥能源生态模式等秸秆农用十大模式，印发了《区域农作物秸秆全量化利用技术导则》，有效加强了成熟适用的技术模式推广应用。

下一步，农业农村部将以秸秆肥料化、饲料化、燃料化利用作为三大主推利用方向，重点完成四项重点任务。一是提升秸秆还田水平，提高还田质量。二是提升秸秆饲料化，推广秸秆青（黄）贮、秸秆膨化、裹包微贮、压块（颗粒）等技术。三是提升秸秆市场化利用水平，采取政府购买服务、政府与社会资本合作等方式，培育一批秸秆收储运社会化服务组织，发展一批生物质供热供汽、颗粒燃料、食用菌等可市场化运行的新型经营主体。四是提升秸秆综合利用标准化水平，发挥玉米秸秆综合利用协同创新联盟和现代农业产业技术体系两大创新平台的作用，熟化一批新技术、新工艺和新装备，形成一批技术规范和装备标准。

二、关于有机肥补贴

2017年以来，我部组织开展了果菜茶有机肥替代化肥行动，大力推进有机肥替代，引领种植业绿色发展。在优势产区选择100个既是果菜茶生产大县，又是畜牧养殖大县的示范县（市），开展果菜茶有机肥替代化肥试点。2018年，试点范围扩大到150个县（市）。一是初步探索建立有效的组织方式。选择果菜茶优势区域、核心区域，集中连片打造，形成规模效应。其中，苹果、柑橘园超过1万亩，茶园超过5000亩，设施蔬菜基地超过1000亩。充分发挥新型经营主体的引领作用，通过竞争性遴选的方式，让一批有意愿、有技术、有实力的种植大户、专业合作社、龙头企业承担试点任务。二是初步集成一套绿色高效技术模式。结合各地肥源条件和果菜茶需肥特点，集成组装类型多样的有机肥替代化肥技术模式。包括“有机肥+配方肥”模式、“果（菜）–沼–畜”模式、“有机肥+水肥一体化”、“有机肥+机械深施”模式等。三是初步创建一批绿色优质产品生产基地。结合推进质量兴农、品牌强农，以有机肥替代化肥为抓手，加快建设绿色优质产品基地，着力创响有影响力的知名品牌。四是初步构建有机肥利用的政策框架。采取政府购买服务方式，与有机肥企业、规模化养殖场、种植大户、服务组织签订协议，统一开展专业化服务。对一些有机肥肥源较远、积造不便的山区果园茶园和城市近郊菜园，对农民施用商品有机肥、生物有机肥予以适当补助，调动了农民增施有机肥的积极性。

下一步，农业农村部将继续开展果菜茶有机肥替代化肥行动，并扩大试点规模和范围，2019年在全国选择175个重点县开展有机肥替代化肥示范，支持农民和新型经营主体等使用以农作物秸秆、畜禽养殖等农业废弃物为原料产生的有机肥，减少化肥用量，推动农业绿色发展。

三、关于建立产学研联盟

2016年，我部成立了国家化肥减量增效科技创新联盟和高效复合肥国家农业科技创新联盟。通过联合行业内专家、大型肥料生产企业和推广部门，打造科企合作平台，推动化肥减量增效新产品及新技术研发、转化和推广。以秸秆为原料生产新型肥料，是创新联盟工作的内容之一，有关方面可积极参与联盟相关活动。

感谢您对农业农村工作的关心，希望今后对我部工作继续给予支持。
