# 文化和旅游部办公厅关于公布第十八届群星奖评奖结果的通知

办公共发（2019）91号

各省、自治区、直辖市文化和旅游厅（局），新疆生产建设兵团文化体育广电和旅游局：

根据《群星奖评奖办法》和第十二届中国艺术节总体安排，文化和旅游部于2019年组织开展了第十八届群星奖评奖工作。经过初选、复赛和决赛，评选出20个获奖作品，现予公布。

各省（区、市）文化和旅游厅（局）和有关单位要以习近平新时代中国特色社会主义思想为指导，深入贯彻落实习近平总书记关于文艺工作系列重要讲话精神，激励广大群众文艺工作者坚持与时代同步伐、坚持以人民为中心、坚持以精品奉献人民、坚持用明德引领风尚，创作出更多有信仰、有情怀、有担当的优秀作品；要充分发挥群星奖的示范引领作用，组织群星奖获奖作品和决赛入围作品深入基层进行演出，运用云上群星奖创新公共文化传播模式，为繁荣社会主义文艺和提升公共文化服务效能做出新的贡献。

特此通知。

附件：第十八届群星奖获奖作品名单

文化和旅游部办公厅
