# 水利部关于全国河道采砂管理重点河段、敏感水域相关责任人名单的公告

## 关于全国河道采砂管理重点河段、敏感水域相关责任人名单的公告

为加强河道采砂管理，落实责任制，按照《水利部关于河道采砂管理工作的指导意见》要求，现将各地确定的河道采砂管理重点河段、敏感水域河长责任人、行政主管部门责任人、现场监管责任人和行政执法责任人名单（见附件）予以公布。
