# 自然资源部关于开展海洋公益性行业科研专项项目2019年验收工作的通知

## 关于开展海洋公益性行业科研专项项目2019年验收工作的通知

自然资科函〔2019〕20号

各有关单位：

按照项目实施期限，截至2019年底，2007-2015年立项尚未验收的122项海洋公益性行业科研专项项目将进入验收阶段。为做好验收组织工作，现将2019年海洋公益性行业科研专项项目验收工作有关事宜通知如下：

一、验收依据

1.《中共中央办公厅、国务院办公厅关于深化项目评审、人才评价、机构评估改革的意见》（中办发〔2018〕37号）。

2.《国务院关于优化科研管理提升科研绩效若干措施的通知》（国发〔2018〕25号）、《国务院关于改进加强中央财政科研项目和资金管理的若干意见》（国发〔2014〕11号），《中共中央办公厅、国务院办公厅印发<关于进一步完善中央财政科研项目资金管理等政策的若干意见>的通知》（中办发〔2016〕50号）。

3.《公益性行业科研专项经费管理试行办法》（财教〔2006〕219号）、《关于调整国家科技计划和公益性行业科研专项经费管理办法若干规定的通知》（财教〔2011〕434号）、《关于中央财政科技计划管理改革过渡期资金管理有关问题的通知》（财教〔2015〕154号）。

4.《海洋公益性行业科研专项经费项目管理暂行办法》（国海财字〔2007〕305号）、《海洋公益性行业科研专项经费项目管理实施细则》（国海科字〔2011〕113号）、《海洋公益性行业科研专项项目验收细则》（国海科字〔2011〕114号）。

5.项目任务书、预算书、实施方案、调整事项批复件及中期检查意见等。

二、组织方式、主要任务和时间安排

（一）组织方式

验收工作由自然资源部科技发展司会同财务与资金运用司分批次组织。对于前期未开展财务验收的项目，合并财务验收与技术验收，对项目进行一次正式验收；对于前期已经开展财务验收的项目，按要求整改完成后进行正式验收。

（二）主要任务和时间安排

1.前期已经开展财务验收工作的项目（附件1），项目承担单位应按照财务验收意见和《自然资源部科技发展司 财务与资金运用司关于加快完成海洋公益性行业科研专项项目财务审计整改的通知》（自然资科函〔2018〕19号）要求按期完成整改。依据《海洋公益性行业科研专项项目验收细则》（国海科字〔2011〕113号），对照任务书、子任务考核指标以及中期检查意见对项目完成情况和完成质量进行自查，准备好各类验收文件及资料。验收文件格式电子版可在自然资源部网站下载。验收工作将于2019年4月开展。

2.已完成自验收、尚未开展财务审计的项目（附件2），按照《国务院关于优化科研管理提升科研绩效若干措施的通知》（国发〔2018〕25号）要求，由项目承担单位自主选择具有资质的第三方中介机构进行结题财务审计，对审计发现的问题，应在2019年5月底前严肃认真整改到位，并向科技发展司报送项目和子任务验收申请表。验收工作将于2019年6月开展。

3.尚未开展自验收工作的项目（附件3），应在项目实施期限结束后一个月内，按照《海洋公益性行业科研专项项目验收细则》（国海科字〔2011〕113号）中“自验收组织程序”组织开展自验收。自验收完成后，按照《国务院关于优化科研管理提升科研绩效若干措施的通知》（国发〔2018〕25号）要求，由项目承担单位自主选择具有资质的第三方中介机构进行结题财务审计，对审计发现的问题，应在2019年10月底前严肃认真整改到位，并向科技发展司报送项目和子任务验收申请表和自验收报告。验收工作将于2019年11月开展。

4.项目验收后，项目承担单位应及时组织总结、推广重大成果。对项目成果取得的重大科技进展及其在实际工作中发挥的作用等进行总结宣传。项目承担单位于验收后一个月内在本单位完成归档后，登陆自然资源部科技成果登记系统（部官方网站-服务-网上办事-自然资源部科技成果登记）完成成果登记，登记后一周内到国家海洋信息中心完成资料汇交工作。
