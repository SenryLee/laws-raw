# 国家知识产权局关于政府网站域名清理工作情况

国知发办函字〔2019〕67号

按照《国务院办公厅关于加强政府网站域名管理的通知》（国办函〔2018〕55号）和国务院办公厅政府信息和政务公开办公室有关通知要求，我局认真开展了政府网站域名清理工作。有关情况如下：

一、全面开展域名清理工作

我局领导高度重视域名清理工作，多次作出批示要求全局各部门单位严格落实党中央、国务院关于域名清理工作的决策部署，促进政府网站健康有序发展。办公室与相关部门充分沟通后印发通知，对域名清理工作作出具体安排，明确工作要求、工作方法、完成时限，及时指导督促域名清理工作。局各部门单位严格按照域名清理工作相关规定，全面梳理本级持有的域名，重点清理后缀为“。gov.cn”的英文域名，对不合规的域名、网站已关停但仍未注销的域名、闲置的域名，以及被用于非政府网站的域名进行了全面清理。

经统计，共清理出7个需注销的政府网站域名，并均已按程序提交注销申请。其中，网站已关停但仍未注销的3个，闲置的2个，网站整合后需注销的2个。

二、积极推进政府网站集约化建设

结合域名清理工作，积极推进政府网站集约化建设。经调整，目前我局在全国政府网站信息报送系统中注册的4个政府网站中，只有政府门户网站仍作为一级域名网站继续注册运行；其余3个网站均已按要求整合或下线，其中，专利检索与服务系统、原专利复审委员会网站整合至政府门户网站（本次机构改革专利复审委员会已并入专利局设置为内设机构复审和无效审理部），作为二级域名网站运行，已申请不再作为政府网站管理，TRIPO（中日韩三局）网站已作下线处理。

按照机构改革工作部署，原工商总局商标局、商标评审委员会、商标审查协作中心整合为国家知识产权局商标局。相应机构划转后，由原商标局管理的中国商标网已整合为我局政府门户网站二级域名网站，并将申请调整其隶属关系；同时划转的原商标评审委员会网站拟将内容迁移至中国商标网后作下线处理。

三、持续加强政府网站管理

通过此次域名清理工作，全面规范了政府网站和非政府网站的域名管理，政府网站的集约化建设水平明显提升。下一步，我局将按照国办关于政府网站发展的一系列通知要求，认真做好政府网站域名结构规范工作，健全域名协调管理机制，优化域名注销注册流程，加强域名安全防护及监测处置工作，理顺转隶网站管理方式，巩固域名清理工作和政府网站集约化建设成果。
