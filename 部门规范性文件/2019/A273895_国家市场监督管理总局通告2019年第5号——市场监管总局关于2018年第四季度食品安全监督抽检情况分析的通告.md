# 国家市场监督管理总局通告2019年第5号——市场监管总局关于2018年第四季度食品安全监督抽检情况分析的通告

## 国家市场监督管理总局通告

2019年第5号

## 市场监管总局关于2018年第四季度食品安全监督抽检情况分析的通告

2018年第四季度，全国共完成并公布1432188批次食品（含保健食品和食品添加剂）样品监督抽检结果，检验项目全部合格的1398054批次，不合格的34134批次，总体合格率为97.6%，不合格率为2.4%，比2017年同期下降0.2个百分点。大宗食品的合格率保持基本稳定，其中粮食加工品，肉制品，蛋制品，乳制品，食用油、油脂及其制品的合格率分别为98.7%、98.1%、99.5%、99.8%、97.8%，均高于总体合格率（各类食品监督抽检结果见附件）。

从检验不合格的项目看，仍以超范围超限量使用食品添加剂、农兽药残留超标和微生物污染等三类问题为主，分别占不合格总数的27.1%、25.2%、24.1%。同时，质量指标不达标占不合格总数的比率，较2017年同期低1.2个百分点；检出非食用物质、重金属等元素污染问题、生物毒素污染问题占不合格总数的比率，较2017年同期高0.6、0.3和0.2个百分点。针对抽检不合格食品，各地食品安全监管部门已督促企业下架、召回，控制了产品风险，并对违法违规企业立案调查、依法处置。

各级市场监管部门已公布具体抽检信息，可在其政府网站或通过其他有效途径查询。其中，市场监管总局公布的抽检信息可在市场监管总局政府网站查询，各省级市场监管部门公布的抽检信息可在原国家食品药品监督管理总局政府网站“食品抽检信息”专栏（http://samr.cfda.gov.cn/WS01/CL1689/）查询。

特此通告。
