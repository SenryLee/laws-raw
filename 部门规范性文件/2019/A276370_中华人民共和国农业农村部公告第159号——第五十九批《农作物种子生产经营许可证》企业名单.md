# 中华人民共和国农业农村部公告第159号——第五十九批《农作物种子生产经营许可证》企业名单

## 中华人民共和国农业农村部公告

第159号

根据《中华人民共和国种子法》《植物新品种保护条例》《农作物种子生产经营许可管理办法》等法律法规的规定，批准发放北京圣华德丰种子有限公司等14家企业《农作物种子生产经营许可证》（详见附件）。

特此公告。

附件：第五十九批《农作物种子生产经营许可证》企业名单

农业农村部

2019年04月12日
