# 国家文物局关于在船帮会馆保护区划内进行丹凤县花庙路片区二期棚户区改造建设项目的意见

文物保函〔2019〕845号

陕西省文物局：

你局《关于丹凤县花庙路片区二期棚户区改造项目选址涉及船帮会馆保护范围的请示》（陕文物字〔2019〕60号）收悉。经研究，我局原则同意在船帮会馆保护范围和建设控制地带内进行丹凤县花庙路片区二期棚户区改造建设项目。

一、所报设计方案尚需做以下必要的修改和完善：

（一）在充分尊重现有城市格局、街巷尺度和建筑肌理的基础上，进行有针对性的改造设计，提升公共空间品质。

（二）尽量保留续用区域内现有的传统民居，补充会馆周围建筑单体设计方案，细化建筑立面设计，新建建筑应与船帮会馆的环境风貌相协调。

（三）绿化景观环境设计不宜过于现代，应体现传统园林风格。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》等相关法规，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年8月20日
