# 国家邮政局关于将国际快递业务经营许可审批权下放海南省邮政管理局有关工作的通知

国邮发〔2019〕33号

海南省邮政管理局：

为贯彻落实《中国（海南）自由贸易试验区总体方案》有关要求，有序做好下放国际快递业务经营许可审批权工作，现就有关事项通知如下：

一、将国际快递业务经营许可审批权下放至海南省邮政管理局。

二、要切实加强组织领导，完善工作机制，按照《海南省邮政管理局承接国家邮政局国际快递业务经营许可审批权的工作方案》，抓紧落实有关工作，如遇问题及时报告。

三、国家邮政局将根据深化“放管服”改革有关要求，加强对承接实施工作的跟踪了解和督促检查，适时组织开展许可审批权下放落实情况和实施效果的评估。

附件：海南省邮政管理局承接国家邮政局国际快递业务经营许可审批权的工作方案（略）

国家邮政局

2019年4月8日
