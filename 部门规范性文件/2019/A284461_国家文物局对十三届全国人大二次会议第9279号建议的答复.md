# 国家文物局对十三届全国人大二次会议第9279号建议的答复

文物博函〔2019〕867号

凯赛尔·阿不都克热木代表：

您提出的关于对新疆新辉红色记忆博物馆给予支持帮助的建议收悉，现答复如下：

非国有博物馆是我国博物馆体系的重要组成部分，发展非国有博物馆，对于优化我国博物馆体系、填补门类空白；丰富公共文化服务供给方式，构建和完善现代公共文化服务体系；激发社会活力，保护和传承中华优秀传统文化，具有积极意义。

国家文物局高度重视非国有博物馆的发展，通过制定出台相关政策文件、组织国有博物馆对口帮扶非国有博物馆、将非国有博物馆纳入质量评价体系、推进非国有博物馆理事会制度建设、举办非国有博物馆馆长培训班等多种方式，帮助非国有博物馆切实提升专业化水平。据统计，截至2018年底，全国登记备案的博物馆5354家，其中非国有博物馆1606家，占全国博物馆总数近30%，已成为我国博物馆体系的重要组成部分。

新疆各民族是中华民族血脉相连的家庭成员，新疆各民族文化扎根于中华文明沃土，是中华文化不可分割的一部分。新疆文物博物馆工作，事关新疆意识形态领域安全、社会稳定和长治久安的大局。我局历来高度重视新疆文物博物馆工作，在博物馆免费开放资金安排、文物藏品科技保护项目申报、业务人员培养等方面，予以倾斜和支持。目前，新疆有各级各类博物馆87家，均向社会免费开放，每年举办陈列展览400余个，接待观众800余万人次，为传承中华文化、维护新疆社会稳定、民族团结、祖国统一、促进经济发展等发挥了重要作用。

您提到的关于新疆新辉红色记忆博物馆面临的有关困难，希望给予该馆展厅建设、文物保（管）护经费支持帮助的建议。根据《博物馆条例》规定，设立博物馆应当具备的条件包括“必要的办馆资金和稳定的运行经费来源”（第十条），“非国有博物馆举办者应当保障博物馆的正常运行经费”（第五条），目前政府有关部门尚无非国有博物馆基础设施建设、馆藏文物日常保护（管）经费等方面经费渠道。近年来，财政部通过中央补助地方公共文化服务体系建设专项资金，对于基本公共文化服务绩效评价结果优良的地方安排奖励资金，用于支持地方提升公共文化服务质量和服务效果。对于纳入地方公共文化服务体系、提供基本公共文化服务的非国有博物馆，可以由所在地方结合其绩效情况等，给予奖励资金统筹支持。根据国务院办公厅转发文化部等部门《关于做好政府向社会力量购买公共文化服务工作的意见》（国办发〔2015〕37号），民办文化体育机构提供的免费或低收费服务等内容已纳入了《政府向社会力量购买公共文化服务指导性目录》，可以通过政府购买服务形式予以支持。下一步，中央财政将继续通过中央补助地方公共文化服务体系建设专项资金，以及支持和推动政府向社会力量购买公共文化服务等方式，支持非国有博物馆发展。我局也将积极指导新疆维吾尔自治区文物行政部门，加大对新疆新辉红色记忆博物馆等非国有博物馆的业务指导力度，为在现有政策范围内申请有关项目、经费支持创造条件，并鼓励多渠道筹措资金，以提高该博物馆专业化运营管理水平，更好地发挥社会效益。

您提到的关于通过地方立法，加大对民营非国有博物馆的保障力度的建议。鉴于新疆目前仅备案新疆新辉红色记忆博物馆、天山博古苑、新疆历代和阗玉博物馆、春秋艺术博物馆等4家非国有博物馆，全区非国有博物馆尚处于探索发展阶段，建议按程序提请新疆维吾尔自治区立法部门对非国有博物馆开展前期调研，结合实际，做好开展地方性立法必要性的研究论证。

感谢您对博物馆事业的关心和支持！

国家文物局

2019年8月26日
