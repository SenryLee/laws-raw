# 中国气象局综合观测司关于印发气象观测装备类别码（2019年）的通知

## 观测司关于印发气象观测装备类别码（2019年）的通知

气测函〔2019〕14号

各省（区、市）气象局，计划单列市气象局，各直属单位，相关企业：

为加快推进气象观测装备信息化管理，根据《气象观测装备类别码（2016年）》的实际使用情况和业务发展的需要，我司组织对编码表进行了补充修订，形成了《气象观测装备类别码（2019年）》（见附件）。现予以印发，请你单位遵照执行。

各单位在使用《气象观测装备类别码（2019年）》的过程中如有问题和建议，请及时将书面意见反馈至中国气象局气象探测中心（联系人：李欣，NOTES：李欣/气象装备保障室/气象探测中心/CMA，电话：010-58995986/13718785307）。

附件： 气象观测装备类别码（2019年）
