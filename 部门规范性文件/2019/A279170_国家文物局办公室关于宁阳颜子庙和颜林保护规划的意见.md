# 国家文物局办公室关于宁阳颜子庙和颜林保护规划的意见

办保函〔2019〕568号

山东省文物局：

你局《关于呈报宁阳颜子庙和颜林文物保护规划的请示》（鲁文发〔2018〕99号）收悉。经研究，我局暂不同意所报规划。

一、所报规划应作以下必要修改和完善：

（一）深化完善历史研究。进一步梳理颜子庙和颜林的历史沿革；明确颜子庙与长川书院的关系，影壁和复圣殿的建设年代，颜林的历史分布范围与现存范围，墓葬的具体位置等；补充颜子庙、颜林与周边村落历史格局的关系；补充颜回对儒家文化的影响以及礼仪、祭祀制度等方面的研究内容。

（二）进一步完善价值评估和保护对象认定。补充颜子庙建筑、颜林选址等相关评估内容；补充在地方文化发展中的历史见证和文化载体价值，客观评估社会价值；细化、核实文物本体和历史环境要素认定。

（三）按照“保护、展示、管理、考古研究”等分类，进一步梳理各专项评估内容。补充对近期已实施修缮工程效果评估；客观评估展示利用情况，重点考虑服务当地社区；综合评估周边建成环境对文物本体和景观环境的影响，客观评估对停车场和道路的需求。

（四）合理调整保护区划。进一步论证长川书院遗址、颜子庙围墙外围及神道、颜子庙与颜林间的视觉通廊等区域的区划设置；细化说明颜林保护范围边界的相关依据；增强管理规定的针对性，补充对拟保留非文物建筑的使用功能要求，拆除、整治等具体措施内容不宜列入管理规定。

（五）进一步细化保护措施。加强保护措施与文物结构特点、现存问题的对应性，细化保养维护、监测等内容，提高石刻、墙垣遗址保护措施的专业性和准确性，补充对地面铺装、排水系统、长川书院遗址等的保护措施。

（六）调整环境整治思路。基于村落现有格局有序开展整治工作，提升空间品质，服务于文物价值展示和社区生活；原则上不应复建东庑和西庑；不得大规模拆除搬迁民居、建设庙前广场、停车场等，不得整齐划一地对现有建筑进行立面改造。

（七）进一步完善其他各专项规划，部分专项规划应适当合并。补充与相关规划衔接内容；合理设置旅游配套设施；调整展示利用规划目标及相关内容；进一步明确管理机构和制度，确保可行性；补充考古研究计划。

（八）进一步校核文字，规范图纸，注意图文、前后对应。

二、请你局指导有关单位，根据上述意见对宁阳颜子庙和颜林保护规划进行修改完善，按程序另行报批。

专此函复。

国家文物局办公室

2019年6月25日
