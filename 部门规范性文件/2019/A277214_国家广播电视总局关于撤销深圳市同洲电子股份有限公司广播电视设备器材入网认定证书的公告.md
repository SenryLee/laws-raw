# 国家广播电视总局关于撤销深圳市同洲电子股份有限公司广播电视设备器材入网认定证书的公告

## 总局关于撤销深圳市同洲电子股份有限公司广播电视设备器材入网认定证书的公告

根据《中华人民共和国行政许可法》《广播电视设备器材入网认定管理办法》（国家广播电视总局令第1号），因生产企业采用不正当手段取得广播电视设备器材入网认定证书，国家广播电视总局决定撤销深圳市同洲电子股份有限公司编号为044190518166的入网认定证书（产品名称及型号：卫星数字电视接收机（专业型）、P5000型）。
