# 公开市场业务交易公告[2019]第226号——关于以利率招标方式开展了1200亿元逆回购操作的公告

## 公开市场业务交易公告

[2019]第226号

2019年11月19日，人民银行在开展中央国库现金管理商业银行定期存款操作500亿元的基础上，以利率招标方式开展了1200亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 1200亿元 | 2.50% |

中国人民银行公开市场业务操作室

二〇一九年十一月十九日
