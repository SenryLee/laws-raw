# 国家烟草专卖局关于印发2019年定点扶贫地区工作计划的通知

行业各直属单位，国家局、总公司机关各部门、各单位：

2019年，是国家局定点扶贫的湖北省竹山县、竹溪县，宁夏回族自治区红寺堡区完成脱贫“摘帽”的关键一年。根据国务院扶贫开发领导小组对国家局的考核要求和国家局的扶贫工作实际，现将《国家烟草专卖局2019年定点扶贫地区工作计划》印发给你们，请认真贯彻落实。

附件：国家烟草专卖局2019年定点扶贫地区工作计划

2019年10月30日
