# 国家林业和草原局关于公布第二批全国林业和草原教学名师遴选结果的通知

林人发〔2019〕86号

各省、自治区、直辖市林业和草原主管部门，内蒙古、大兴安岭森工（林业）集团公司，新疆生产建设兵团林业和草原主管部门，国家林业和草原局各司局、各派出机构、各直属单位，各有关普通高等院校、中高等职业院校：

为深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，落实《中共中央 国务院关于全面深化新时代教师队伍建设改革的意见》，进一步加强林业和草原高素质创新型教师队伍建设，选树林业和草原优秀教师典型，引导和激励全国广大林业和草原教育工作者增强使命感和职业荣誉感，不断提升教育教学本领，着力提高人才培养质量，在各相关单位认真推荐的基础上，经资格初审、专家评审和社会公示，确定董丽等30名同志为第二批"全国林业和草原教学名师",现将遴选结果（见附件）予以公布。

教育是国之大计、党之大计。教育大计，教师为本。希望入选全国林业和草原教学名师的教师们深入落实"四有好老师"、"四个引路人"、"四个相统一"要求，不忘教育报国初心，牢记立德树人使命，发挥名师潜心教书育人的示范引领作用，在今后的教育教学工作中不断取得新的更大成绩。

希望相关人才培养单位深入学习宣传教学名师典型经验，组织广大教师强化使命担当，积极投身林业和草原教育教学改革创新实践，不断推动我国林业和草原教育事业更好发展。

全国林业和草原系统广大干部职工要大力营造尊师重教的良好风尚，共同努力为林业和草原事业高质量发展、生态文明和美丽中国建设培养更多德智体美劳全面发展的高素质建设者和优秀后备人才。

特此通知。
