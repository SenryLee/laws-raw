# 农业农村部对十三届全国人大二次会议第4087号建议的答复

## 对十三届全国人大二次会议第4087号建议的答复

农办议〔2019〕230号

邹文辉代表：

您提出的"关于支持湖南汝城建设中国特色农产品‘朝天椒’优势区的建议"收悉，经认真研究，现答复如下。

一、关于支持汝城县做大做强朝天椒产业

湖南汝城县自然资源优势明显，特色农产品丰富，朝天椒种植面积达10万亩，总产量15万吨，总产值9亿元。近年来，我部以特色农产品优势区、国家现代农业产业园为抓手，加快推动特色产业发展。一是开展特色农产品优势区创建工作。为深入贯彻落实中央有关要求，我部会同国家发展改革委、财政部、国家林业和草原局等部门积极推进特色农产品优势区创建工作，先后印发了《关于开展特色农产品优势区创建工作的通知》《推进特色农产品优势区建设工作方案》《特色农产品优势区建设规划纲要》。鼓励各地做大做强优势特色产业，争创国家级、省级特色农产品优势区。2017年以来，我部联合中央农办、国家发展改革委等9部门认定了146个中国特色农产品优势区，汝城县被认定为汝城朝天椒中国特色农产品优势区。二是开展现代农业产业园创建工作。2017年以来，我部和财政部认真贯彻中央关于实施乡村振兴战略、建设现代农业的部署要求，大力推进国家现代农业产业园建设工作，先后批准创建114个，首批认定20个国家产业园。其中，湖南省有靖州县、宁乡县、安化县、常德市鼎城区和长沙市芙蓉区5个产业园获批创建国家产业园。靖州县产业园因创建绩效突出，通过了2018年底农业农村部、财政部组织的绩效评价，被认定为国家现代农业产业园。根据2019年国家现代农业产业园创建通知要求，国家产业园创建批准工作由省级农业农村和财政部门组织实施，农业农村部、财政部不再组织创建评审，各省在农业农村部、财政部下达的创建指标数内，按照县级政府申请、省级农财部门择优遴选提出创建名单报分管省领导审定、农业农村部和财政部审查备案并公布的程序开展申请创建工作。汝城县可以按照国家现代农业产业园创建条件和要求，认真做好国家现代农业产业园创建前期工作，同时加强与湖南省农业农村和财政部门的沟通衔接。如符合国家现代农业产业园的创建条件和要求，我们将予以支持。三是加强高标准农田建设。农田是保障国家粮食安全、实施乡村振兴战略的物质基础。党中央、国务院高度重视农田建设工作，就深入实施藏粮于地、藏粮于技战略，作出了系列重要部署。2018年，农业农村部新设立农田建设管理司，承担农田建设、发展高效节水灌溉、耕地质量监测保护提升等方面的工作职责。2019年将完成8000万亩高标准农田建设的"硬任务",为保障国家粮食安全以及特色产业发展发挥积极促进作用。四是积极开展数字农业建设试点。2017和2018年，聚焦大田种植、园艺作物、畜禽养殖和水产养殖等农业生产领域开展了精准作业、精准控制试点示范，在促进各地提高数字农业认识水平、加大数字农业支持力度、推进数字技术集成创新应用、探索数字农业发展模式等方面取得了积极成效。2019年，重点支持开展数字农业试点县、重要农产品全产业链大数据和数字农业创新中心建设试点，示范引领农业产业数字化和数字产业化。

下一步，我部将继续加强与发展改革委、财政部的协同配合，多渠道谋划特色产业和特优区财政资金支持渠道，同时，利用中国特色农产品优势区专刊、中国农业农村市场信息公众号等形式，宣传湖南汝城特色农产品优势产业发展中的好经验、好做法。按照数字乡村和数字农业农村发展规划的部署要求，我部将加大数字农业农村建设项目支持力度，汝城县可以做好项目前期准备工作，并加强与省级农业农村部门沟通，如符合条件，我们将予以支持。加快完善农田建设统一管理机制，积极支持包括湖南汝城在内的全国各省份高标准农田建设，改善当地农业基础设施条件，为当地加强现代农业建设，发展优势特色产业发挥支撑作用。

二、关于支持汝城县朝天椒农业龙头企业

根据中央关于"在全国选择一批有基础、有优势、有特色、有前景的龙头企业作为国家支持的重点"的要求，为进一步规范农业产业化国家重点龙头企业的认定和运行监测工作，加强对国家重点龙头企业的服务与扶持，培育壮大龙头企业，增强辐射带动能力，经国务院批准，由我部牵头，国家发改委、财政部、商务部、中国人民银行、国家税务总局等8部门组成的全国农业产业化联席会议制度，制定了《农业产业化国家重点龙头企业认定和运行监测管理办法》，规定了国家重点龙头企业认定监测的标准和程序。截至到2018年底，全国经县级以上农业产业化主管部门认定的龙头企业近9万家，其中省级以上重点龙头企业1.8万家、国家重点龙头企业1243家。目前湖南省农业产业化国家重点龙头企业47家。欢迎繁华食品有限公司在启动认定工作时，按照要求积极申报农业产业化国家重点龙头企业。

三、关于支持汝城县开展朝天椒精深加工技术攻关

依托现代农业产业技术体系，我部国家特色蔬菜产业技术体系在朝天椒精深加工方面对朝天椒辣椒籽进行了营养品质分析、综合利用研究以及辣椒素提取技术研究，成功开发了超高压辅助提取技术，获得辣椒籽深加工产品3个，包括辣椒籽油、辣椒籽膳食纤维和辣椒籽分离蛋白以及辣椒精产品。针对汝城朝天椒产业技术发展，国家特色蔬菜产业技术体系组织湖南农业大学和湖南省蔬菜研究所专家在对汝城经济、自然条件及辣椒产业现状深入调研、认真分析、科学论证的基础上，结合汝城县实际，帮助汝城县政府制定了《汝城县辣椒产业发展规划（2019-2025）》。在精深加工方面，组织加工岗位专家与汝城县鑫利食品有限公司签订协议，共建国家新农村发展研究院辣椒特色产品汝城基地，利用精深加工制作辣椒油、辣椒精、红色素等，利用科学分离精制辣椒油，有机溶剂萃取辣椒红色素，指导企业年产辣椒酱7000万吨，提炼辣椒精100万吨。

根据《优势农产品区域布局规划》等规划要求，我部建立了农产品加工技术研发体系，开展农产品加工重大共性关键技术研究与集成、农产品加工科技成果转化与推广，推动农产品加工企业提高技术水平。汝城县朝天椒加工企业可以与农产品加工业技术研发体系联系，获取相应的技术支持，开展联合技术攻关，提高精深加工能力，技术研发体系秘书处设在中国农科院农产品加工研究所。

感谢您对"三农"工作的关心，希望今后继续给予我部工作支持。
