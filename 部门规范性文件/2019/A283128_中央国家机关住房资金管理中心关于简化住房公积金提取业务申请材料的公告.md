# 中央国家机关住房资金管理中心关于简化住房公积金提取业务申请材料的公告

## 关于简化住房公积金提取业务申请材料的公告

为贯彻落实党中央、国务院关于减证便民、优化服务的部署要求，即日起，职工办理住房公积金提取业务时，不再提交纸质提取申请书。职工应当按照中央国家机关住房公积金提取告知承诺制有关规定，承诺申报的信息准确、完整、有效，对提取适用事项真实性负责。

中央国家机关住房资金管理中心

2019年10月23日
