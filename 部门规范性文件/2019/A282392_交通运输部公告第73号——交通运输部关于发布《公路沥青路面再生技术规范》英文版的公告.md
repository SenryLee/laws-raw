# 交通运输部公告第73号——交通运输部关于发布《公路沥青路面再生技术规范》英文版的公告

## 交通运输部公告

第73号

## 交通运输部关于发布《公路沥青路面再生技术规范》英文版的公告

为促进公路工程行业标准的对外交流，现发布《公路沥青路面再生技术规范》英文版〔JTG/T 5521—2019（EN）〕。

本规范英文版的管理权和解释权归中华人民共和国交通运输部，日常解释和管理工作由英文版编译单位交通运输部公路科学研究院负责。

本规范英文版与中文版如发生异议，以中文版为准。

如在执行过程中发现问题或有修改建议，请函告交通运输部公路科学研究院（地址：北京市海淀区西土城路8号，邮编：100088，电子邮箱：yc.qin@rioh.cn），以便修订时研用。

特此公告。

交通运输部

2019年9月25日
