# 交通运输部办公厅关于组织2019年度公路水运工程试验检测机构比对试验的通知

交办安监函〔2019〕556号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），长江航务管理局：

为推动公路水运工程试验检测行业高质量发展，提升试验检测机构的技术水平，服务保障公路水运工程建设质量。部决定组织2019年公路水运工程试验检测机构比对试验。现将有关事项通知如下，见附件。

附件：《交通运输部办公厅关于组织2019年度公路水运工程试验检测机构比对试验的通知》。

交通运输部办公厅

2019年4月19日
