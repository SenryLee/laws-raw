# 国家文物局办公室关于西康留遗址保护范围内京台高速公路改扩建项目设计方案调整的意见

办保函〔2018〕1269号

山东省文物局：

你局《关于报送京台高速公路改扩建工程穿越西康留遗址设计方案修改稿的请示》（鲁文发〔2018〕105号）收悉。经研究，我局暂不同意所报项目调整设计方案。

所报方案拟采用双侧拼宽方式进行道路改扩建的必要性不足，请你局指导项目单位按照我局《关于在山东省文物保护单位西康留遗址保护范围内进行京台高速公路改扩建项目的意见》（文物保函〔2018〕1126号）要求，采取现状道路东侧单侧拼宽方式进行改扩建工程，做好前期考古工作，加强项目实施过程的全程监管，确保文物安全。

专此函复。

国家文物局办公室

2019年1月2日
