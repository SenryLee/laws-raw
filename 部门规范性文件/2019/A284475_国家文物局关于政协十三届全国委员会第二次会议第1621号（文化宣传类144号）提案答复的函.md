# 国家文物局关于政协十三届全国委员会第二次会议第1621号（文化宣传类144号）提案答复的函

文物博函〔2019〕809号

万捷委员：

您提出的“关于运用新技术助力提升博物馆数字化标准和水平的提案”已交由我局会同科技部办理。现答复如下：

近年来，我国博物馆行业信息化发展迅速，引发了博物馆收藏、研究、保护、展示等功能在实现途径和手段上的重大变革。博物馆的工作从实体领域扩展到数字领域，形成了实体、虚拟和虚实结合并存的全新工作局面。

在推动博物馆行业信息化发展过程中，国家文物局重点从政策、标准、技术等方面予以引导和支持。一是引导博物馆行业建立有限目标导向、分类协同推进和迭代演进的发展模式，稳步推进信息化工作。二是加快推进适用标准研制，在科技部的支持下，组织开展了“文物数字化保护标准及关键技术研究与示范”等项目。三是强化应用技术创新，依托“十二五”国家科技支撑计划，部署了一批文物保护利用数字化关键技术应用研究任务，为实现高品质的行业信息化提供技术支持。

数字采集是博物馆行业信息化的基础，其发展需要统筹兼顾社会经济效益和阶段性投入能力。文物数字化成果的应用需求分为非营利性的保管、研究和展示教育等工作以及各种营利性活动。文物数字采集工作需要区分不同应用需求下的数字化目标，依托博物馆机构的资源条件，分类协同推进，并优先保障文物数字化保护任务。随着信息技术的进步，文物数据的采集、存储、管理、传输以及展示方式将不断更新，文物数字化工作也将随之进行迭代演进。

您在提案中提出的关于打造相关国家级数据库大平台的建议，我们将支持对前沿科学技术的应用创新研究，为有关平台建设提供技术支撑。

感谢您对文物博物馆事业的关心与支持。

国家文物局

2019年7月23日
