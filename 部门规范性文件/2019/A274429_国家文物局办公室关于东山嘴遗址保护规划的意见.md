# 国家文物局办公室关于东山嘴遗址保护规划的意见

办保函〔2019〕103号

辽宁省文物局：

你局《关于上报〈东山嘴遗址保护规划〉》的请示（辽文物〔2018〕38号）收悉。经研究，我局暂不同意所报规划。

一、所报规划应作以下必要修改和完善：

（一）加强考古资料梳理和勘察研究，进一步明确东山嘴遗址与东山嘴东、小南梁等6处遗址的关系，合理确定保护对象、规划范围、规划目标等，增强可操作性。

（二）深化价值评估和现状评估，厘清东山嘴遗址的范围、布局和内涵，完善区域建设现状、遗址周边水系灾害情况分析，明确遗址保护面临问题、保护管理需求、建设目标等，加强规划措施针对性和适用性。

（三）应综合考虑东山嘴及周边相关遗址分布、地形地貌特点和保护管理需要，合理确定保护区划。应结合岗地自然形态，将东山嘴屯西南侧相关红山文化遗址划入保护范围，确定边界；建设控制范围边界线建议东扩至大凌河西河岸。

（四）调整建设控制地带分类和管理措施，细化不同区域的建设管控强度，增强可操作性。充分论证东山嘴屯整体搬迁的必要性，明确村庄发展的引导措施，相关管理规定不应影响村民正常生产生活。量化建筑高度、建设密度、下挖深度等建设控制要求。

（五）应与考古专业机构合作制定东山嘴遗址中长期考古工作规划，近期应重点做好遗址周边区域的系统考古调查，进一步确定红山文化遗址群分布范围、文化特征、各遗址的关系等，列表说明调查、勘探、测绘和发掘等工作内容、目标。

（六）结合考古成果、文物价值、遗址区位条件等，综合确定遗址展示目标和思路。近期应以现有展示设施提升为主，降低展示强度，不宜进行现场虚拟展示。

（七）调整专项规划内容。不同意全部移除柏木林，应逐步调整遗址周边植物景观风貌；根据区域道路体系、大凌河水灾等评估结论，制定道路调整、防灾专项规划；结合周边遗址点和旅游点分布，统筹考虑区域展示路线和服务设施建设，避免过度建设。

（八）加强保护管理机构建设，将完善“四有工作”、改进保护标志和记录档案管理、加强专业人员培训作为保护管理规划的重要内容。

（九）进一步规范图文表达，深化图纸内容，细化保护措施位置和范围的图示标注。补充大范围影像图和高精度地形图、大比例对外交通现状评估图。

二、请你局指导有关单位根据上述意见对东山嘴遗址保护规划进行修改完善，按程序另行报批。

专此函复。

国家文物局办公室

2019年2月19日
