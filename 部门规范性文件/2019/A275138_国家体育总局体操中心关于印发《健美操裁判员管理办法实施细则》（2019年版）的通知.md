# 国家体育总局体操中心关于印发《健美操裁判员管理办法实施细则》（2019年版）的通知

## 体育总局体操中心关于印发《健美操裁判员管理办法实施细则》（2019年版）的通知

各有关单位：

《健美操裁判员管理办法实施细则》自2015年实施以来收到了良好的效果，但随着项目的发展，在执行过程中发现需要增加或修订个别条款予以完善。经广泛征求意见，进行了修订。

现将《健美操裁判员管理办法实施细则》（2019年版）印发你们，请遵照执行。

2.健美操裁判员管理办法实施细则2019年修订说明
