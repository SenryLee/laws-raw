# 国务院国有资产监督管理委员会公告2019年第2号——国资委关于组建国家石油天然气管网集团有限公司的公告

## 国务院国有资产监督管理委员会公告

2019年第2号

## 国资委关于组建国家石油天然气管网集团有限公司的公告

经国务院批准，新组建的国家石油天然气管网集团有限公司由国务院国有资产监督管理委员会代表国务院履行出资人职责，列入国务院国有资产监督管理委员会履行出资人职责的企业名单。

国资委

2019年12月6日
