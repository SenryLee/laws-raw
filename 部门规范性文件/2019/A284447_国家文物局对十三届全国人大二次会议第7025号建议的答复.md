# 国家文物局对十三届全国人大二次会议第7025号建议的答复

文物政函〔2019〕685号

谢广祥代表：

您提出的“关于加强革命文物保护利用的建议”收悉。经商财政部，现答复如下。

党的十八大以来，以习近平同志为核心的党中央高度重视革命文物工作，全国革命文物工作整体呈现向好态势。2018年7月，中共中央办公厅、国务院办公厅印发《关于实施革命文物保护利用工程（2018-2022年）的意见》，对新时代革命文物工作进行了全面部署。十几个省份颁布了实施革命文物保护利用工程措施文件。中宣部、财政部、文化和旅游部、国家文物局公布第一批革命文物保护利用片区分县名单，15个片区涉及20个省份的110个市、645个县。财政部、国家文物局修订印发《国家文物保护专项资金管理办法》，明确提出中央财政文物保护专项资金对革命文物保护予以倾斜支持。国家文物局基本摸清全国革命文物家底，其中不可移动革命文物约3.5万处，可移动革命文物藏品100万余件/套；发布《革命旧址保护利用导则》，实施赣南等原中央苏区革命遗址保护利用工程和延安革命旧址群保护工程，加强抗战文物、长征文物保护展示，推介一批革命文物陈列展览精品。

您在建议中提出的关于革命文物家底摸清有盲点、保护措施有缺位、经费分配待优化、环境风貌待改善、展示利用待提升等问题，具有较强的现实性和针对性。中央相关部门和地方政府将深入贯彻落实《关于实施革命文物保护利用工程（2018-2022年）的意见》，坚持问题导向，加强组织指导，加大支持力度，建立协作机制，形成整体合力，不断提升革命文物保护利用水平，更好发挥革命文物资源在弘扬革命精神、传承红色基因、助力经济社会发展中的重要作用。

一是统筹推进革命文物保护利用政策落地见效。落实好《国家文物保护专项资金管理办法》，中央财政文物保护专项资金适当向革命老区、民族地区、边疆地区、贫困地区倾斜，向党中央、国务院确定的重点支持方向革命文物保护倾斜，将省级及省级以下文物保护单位保护纳入支持范围，支持革命文物保护利用片区整体陈列展示，发挥国家文物保护专项资金对社会参与的引领作用。贯彻好人力资源社会保障部、财政部《关于乡镇机关事业单位工作人员实行乡镇工作补贴的通知》相关精神，为提高基层文物保护人员待遇用好用足相关政策。按照国务院办公厅《关于进一步加强文物安全工作的实施意见》，鼓励地方通过政府购买服务的方式健全文物保护员制度，督促地方落实文物安全经费，筑牢革命文物安全底线。

二是扎实开展革命文物集中连片保护利用工程。四部门继续确定公布第二批革命文物保护利用片区分县名单。以革命文物保护利用片区为重点，支持地方实施一批、完工一批、储备一批革命文物保护项目，切实改善革命文物保存状况。指导公布全国革命文物名录，支持地方将革命旧址核定公布为相应级别的文物保护单位。推进革命文物保护利用与红色旅游发展、脱贫攻坚、乡村振兴相结合，与生产生活、相关产业深度融合，助力革命老区全面建成小康社会。

三是更好展现中国共产党革命精神谱系。紧密结合“不忘初心、牢记使命”主题教育活动，充分发挥革命文物资源在党性教育中的独特优势和重要作用。加强革命史实研究和革命文物价值挖掘，支持各地结合重大历史事件和重要历史人物纪念活动、重要节庆活动，策划举办高质量高水平的革命文物主题展览，提升社会教育和公共服务水平。开展革命文物宣传传播工程“三个百集”（即百集革命文物故事微视频、百集革命旧址短片、百集革命人物纪录片）拍摄和红色文物数字展厅线上展示传播工作，创新“互联网+革命文物”传播方式，讲好革命故事，传承红色基因，让革命精神绽放新光彩。

感谢您对革命文物工作的关心和支持。

国家文物局

2019年7月10日
