# 水利部办公厅关于印发山洪灾害防治非工程措施运行维护指南和山洪灾害监测预警设施设备运行维护管理要求的通知

办防〔2019〕102号

有关省、自治区、直辖市水利（水务）厅（局），新疆生产建设兵团水利局，各流域管理机构：

为贯彻落实“水利工程补短板、水利行业强监管”水利改革发展总基调，进一步加强山洪灾害防治非工程措施运行维护管理，根据近年来技术手段进步、各地实践探索取得的经验和实际工作需要，我部组织对《山洪灾害防治非工程措施运行维护指南》和《山洪灾害监测预警设施设备运行维护管理要求》进行了修订，现予以印发。

请根据修订后的文件要求，进一步明确管理职责，积极协调落实运行维护经费，强化设施设备维护和人员技术培训等，建立健全山洪灾害防治非工程措施运行维护管理机制，确保防治体系长期稳定发挥效益。

水利部办公厅

2019年5月22日
