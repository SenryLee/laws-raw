# 农业农村部关于政协十三届全国委员会第二次会议第2129号（农业水利类203号）提案答复的函

## 关于政协十三届全国委员会第二次会议第2129号（农业水利类203号）提案答复的函

农办案〔2019〕118号

雷鸣强委员：

您提出的关于加强和改进新型职业农民培育工作的提案收悉。经商教育部、人力资源社会保障部，现答复如下。

一、关于健全农民教育培训主体和平台

技能培训是提升农民综合素质和生产技能的重要途径，职业教育是培养高素质农民的重要载体，具有系统性培养优势。我部十分重视，坚持技能培训和职业教育两条腿走路，培养具备现代生产技能和经营能力的复合型农业农村人才。

一是整合农民培育资源。各级农业农村部门负责农民培训项目的组织实施，在发挥好政府引领作用的同时，各地注重统筹利用涉农单位、农业院校、科研院所、专业技术协会、农业龙头企业、农民专业合作社等培训资源，通过政府购买服务、市场化运作等方式，进一步健全完善“专门机构+多方资源+市场主体”的农民培育体系，充分激发各方参与积极性。二是抓好农民职业教育。2014年，我部联合教育部印发《中等职业学校新型职业农民培养方案（试行）》，支持中等职业学校通过弹性学制、半农半读、农学交替等方式培养农民学员；2019年，我部联合教育部印发《关于做好高职扩招培养高素质农民有关工作的通知》，启动实施“百万高素质农民学历提升行动计划”，全面完成2019年高职扩招培养高素质农民任务，针对农民单列计划，取消文化素质考试，鼓励以“注册制”形式免试录取拔尖实用人才，单独编班、单独教学，根据农村实际和农民特点开展分段式脱产学习。三是推进线上线下融合培训。为了让农技推广插上信息化的翅膀，让广大农民搭乘“互联网+”的快车，2017年开始，我部开展农民教育培训信息化工作，设计开发了全国农业科教云平台，包括管理平台（网页端，各级农业科教管理人员用）、中国农技推广手机应用程序（专家、农技推广人员用）和云上智农手机应用程序（农民用）。全国农业科教云平台基于大数据、云计算和移动互联技术，聚集各类农业科技教育资源，为各级农业农村管理部门、农业专家、农技推广人员和广大农民提供在线学习、互动交流、成果速递和服务对接。我部加强内容资源开发建设，支持各地组织农民在线学习，探索线上线下融合培训模式，以从事生产经营的农民为主要对象，利用云平台开展在线学习，不断提升在线课程比重，通过政府购买服务方式支付在线学习费用。

下一步，我部将联合有关部门继续做好农民教育培训工作，利用职业教育提升农民素质，促进线上线下培训融合加快发展，为乡村振兴培养数量足、质量高的农业人才。

二、关于完善农民扶持政策

我部注重通过职业教育和培训衔接一体化培养，提升参训农民的价值观、职业素养、经营管理能力和生产技术水平；加强参训农民跟踪服务，探索实行参训农民登记注册管理，为后续跟踪扶持、配套产业政策和金融保险服务提供科学依据。部分学员通过帮扶和引导，成为了各级人大代表、政协委员、劳动模范以及村两委班子成员，发挥了示范引领作用。

关于农民职称评审问题，1986年，原中央职称改革领导小组转发《农业技术人员职务试行条例》，建立了农业技术人员职务聘任制度，分设农业、畜牧、兽医3个类别。1994年，农业部、人事部印发《农业技术推广研究员任职资格评审实施办法》，在农业系列开展正高级职称农技推广研究员评审，每两年评审一次。截至2016年，全国共有11300人取得农业技术推广研究员资格。这两项制度实施以来，对调动农业技术人员积极性、加强农业技术人员队伍建设发挥了重要作用。2018年中央1号文件提出，鼓励各地开展农民职称评定试点，目前已有浙江、湖南、山西、山东等地积极探索，坚持“干什么、评什么”，打破学历、所学专业、论文等限制，取得了较好成效，受到农村一线专业技术人员的普遍欢迎。

关于出台跟踪服务管理办法，目前，我部正在研究制订农民教育培训工作管理办法，对培育条件、组织培训、跟踪服务、资金使用、监督检查和绩效评价等环节进行规范，确保农民教育培训取得良好效果。

关于出台农民社会保障办法，按照国家政策规定，与用人单位签订劳动合同的农民应该参加城镇职工基本养老保险、失业保险，灵活就业的农民可选择以灵活就业人员身份参加城镇职工基本养老保险，也可以参加城乡居民基本养老保险，部分地区对于农村户籍人员以灵活就业人员参保条件进行了限制，人力资源社会保障部正在积极研究解决。

关于政策扶持，我部会同有关部委注重引导各地整合资源，积极创造有利于农民成长发展的政策环境。中央财政鼓励各地利用现有资金渠道，强化政策衔接配合，将支持农民教育培训、农民合作社及家庭农民发展等培育壮大新型农业经营主体政策统筹实施，支持强农惠农富农政策向参训农民倾斜支持。我部积极做好土地经营权流转管理和服务，要求各地建立工商资本租赁农户承包地上限控制、分级备案、审查审核、风险保障金和事中事后监管等“五项制度”，印发了《农村土地经营权流转交易市场运行规范（试行）》；积极指导各地健全土地经营权流转市场，规范市场运行机制，引导土地流转双方签订书面流转合同；积极配合全国人大等做好农村土地承包法修改工作，修改后的农村土地承包法于2019年1月1日起施行。

下一步，我部将继续梳理各类强农惠农富农政策，引导其落实到参训农民头上，加强跟踪服务，不断提升务农兴业含金量。

感谢您对农民教育培训工作的关心，希望今后继续对我部工作给予支持。

农业农村部

2019年8月29日
