# 国家核安全局关于批准《福建福清核电厂3、4号机组化学和放射化学技术规范（C版）》的通知

## 关于批准《福建福清核电厂3、4号机组化学和放射化学技术规范（C版）》的通知

国核安发〔2019〕46号

福建福清核电有限公司：

你公司《关于恳请批准福建福清核电厂3、4号机组化学和放射化学技术规范（C版 报批稿）的请示》（福核发〔2018〕415号）收悉。

根据《中华人民共和国核安全法》《中华人民共和国民用核设施安全监督管理条例》的有关要求，我局对你公司提交的申请文件进行了技术审评，认为“补充硼-锂协调图说明”等14项修改是可以接受的，现予批准《福建福清核电厂3、4号机组化学和放射化学技术规范（C版）》。

你公司应严格遵守我局批准的化学和放射性化学技术规范，确保福建福清核电厂3、4号机组运行安全。

国家核安全局

2019年3月15日
