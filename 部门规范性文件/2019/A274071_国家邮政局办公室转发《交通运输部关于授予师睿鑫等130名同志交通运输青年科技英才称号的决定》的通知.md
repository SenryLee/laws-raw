# 国家邮政局办公室转发《交通运输部关于授予师睿鑫等130名同志交通运输青年科技英才称号的决定》的通知

国邮办函〔2019〕66号

国家邮政局发展研究中心、邮政业安全中心，中国邮政集团公司办公室，顺丰速运集团有限公司、圆通速递有限公司，北京邮电大学、南京邮电大学、重庆邮电大学、西安邮电大学，青岛酒店管理职业技术学院：

经国家邮政局组织申报推荐、交通运输部评审决定，授予邮政行业张德虎等12名同志交通运输青年科技英才称号。现将《交通运输部关于授予师睿鑫等130名同志交通运输青年科技英才称号的决定》（交人教发〔2019〕8号）转发给你们，请做好宣传等有关工作，切实发挥交通运输青年科技英才对行业人才队伍建设的引领示范作用。

国家邮政局办公室

2019年2月1日

附件：交通运输部关于授予师睿鑫等130名同志交通运输青年科技英才称号的决定
