# 自然资源部办公厅关于做好2019年度自然资源数据统计的通知

自然资办函〔2019〕2324号

各省、自治区、直辖市自然资源主管部门，新疆生产建设兵团自然资源主管部门，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关有关司局：

为做好2019年度自然资源数据统计和年鉴编制等工作，根据《自然资源统计调查制度》（自然资办函〔2019〕1235号，自然资源部门户网站发布）要求和分工，请国家林草局、中国地调局、部相关司（局）抓紧组织开展2019年度统计数据采集、审核、汇交工作。各省（区、市）自然资源主管部门按照上级业务指导部门要求，组织相关业务处室按时上报数据。有关事业单位做好技术支撑。数据要按照《自然资源统计调查制度》规定时间上报汇交。

请各单位高度重视，提前安排部署，开展统计培训，加强业务指导，严格数据审核，确保统计数据的真实性和时效性，不断提升数据质量。
