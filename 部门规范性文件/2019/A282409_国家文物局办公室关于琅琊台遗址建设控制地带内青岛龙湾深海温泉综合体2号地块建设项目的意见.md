# 国家文物局办公室关于琅琊台遗址建设控制地带内青岛龙湾深海温泉综合体2号地块建设项目的意见

办保函〔2019〕772号

山东省文化和旅游厅：

你厅《关于青岛龙湾深海温泉综合体2号地块在琅琊台遗址建设控制地带内选址的请示》（鲁文旅呈〔2019〕76号）收悉。经研究，我局暂不同意在琅琊台遗址建设控制地带内实施青岛龙湾深海温泉综合体2号地块建设项目。

一、应进一步明确拟建项目与琅琊台遗址、琅琊古城的位置关系，科学分析项目建设对遗址景观及视廊的影响，充分论证项目实施的必要性和可行性。

二、请你厅指导有关单位，在项目拟建区域进一步开展全面考古调查和勘探工作，明确地下文物分布情况，并根据上述意见和考古工作成果对方案进行修改完善后，按程序另行报批。

三、请你厅指导地方人民政府落实主体责任，明确保护区划管理规定和新建建筑性质、体量、高度、外观样式和工程下挖深度等具体控制指标，合理规划遗址周边区域的产业布局和建设项目，统筹考虑琅琊台遗址保护和城乡发展之间的关系。

专此函复。

国家文物局办公室

2019年8月30日
