# 农业农村部对十三届全国人大二次会议第2286号建议的答复

## 对十三届全国人大二次会议第2286号建议的答复

张继新代表：

您提出的关于加大内蒙古畜牧养殖业补贴的建议收悉。经商财政部，现答复如下。

内蒙古生态环境优良，饲草和牛羊养殖资源丰富，是国家重要的绿色畜产品供应基地。畜牧业作为农业农村经济的重要支柱产业，为保障国家绿色畜产品供给，增加农牧民收入，保护和改善草原生态环境，做出了重要贡献。近年来，国家高度重视内蒙古现代畜牧业建设，不断加强政策指导和扶持力度，通过实施一系列强农惠农政策与财政项目，有力地促进了内蒙古畜牧养殖业的健康发展。

一、关于加大对内蒙古畜牧养殖业补贴的建议

2015年起，国家在内蒙古自治区等牧区省份实施畜牧良种补贴项目，对项目区内使用良种精液开展人工授精的肉牛养殖场（小区、户），以及存栏能繁母羊30只以上、牦牛能繁母牛25头以上的养殖户进行适当补助，通过使用优质冻精和优秀种公畜配种，提高能繁母牛母羊的繁殖率，提升后代的生产性能及产品质量。2018年，中央财政在内蒙古实施畜牧良种补贴项目，安排资金7620万元对养殖场户购买优质肉牛精液及种公羊进行补贴。2019年，将继续实施畜牧良种补贴项目，减少养殖户人工授精配种的成本支出，降低生产成本，增加农牧民收益。我部将在资金测算和资金安排上，继续对牧区良种推广、农作物的良种补贴等方面予以扶持。

下一步，中央财政将积极做好相关政策贯彻落实工作，坚持绿色引领，加快促进农业生产方式由粗放经营向集约高效循环转变。我部将会同财政部等相关部门研究基础母畜补贴等扶持政策，充分调动养殖户饲养基础母畜的积极性，促进农牧民增收。

二、关于加大蛋白类饲料原料种植补贴力度，扩大种植面积的建议

大豆是重要的食用植物油和蛋白饲料来源，在农业生产中占有重要地位。2016年以来，中央财政共安排21亿元资金，支持内蒙古自治区开展耕地轮作制度试点，试点累计面积1400万亩，推广以玉米与大豆为主的轮作种植模式，鼓励农民扩种市场短缺的大豆，调减非优势区籽粒玉米面积，发挥大豆根瘤固氮养地作用，促进种地养地相结合和农业可持续发展。初步统计，在耕地轮作制度试点及相关扶持政策带动下，近几年全区大豆播种面积增加500万亩左右，大豆扩种趋势明显。

下一步，我部将按照中央决策部署，大力推进大豆振兴计划，中央财政继续实施东北地区大豆生产者补贴政策，调动农民种豆积极性，扩大耕地轮作试点规模，支持主产区实行玉米与大豆合理轮作；加大大豆制种大县奖励力度，促进大豆生产恢复发展，提升国产大豆自给水平。

感谢您对畜牧业工作的关心，希望今后继续对我部的工作予以支持。

农业农村部

2019年8月22日
