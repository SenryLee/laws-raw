# 国家文物局关于燕园建设控制地带内环境整治项目的意见

文物保函〔2019〕383号

江苏省文物局：

你局《关于审批全国重点文物保护单位燕园建设控制地带内环境整治工程项目方案的请示》（苏文物保〔2019〕45号）收悉。经研究，我局原则同意燕园建设控制地带内环境整治项目。

一、所报方案尚需作以下必要的修改和完善：

（一）深化历史研究，补充相关历史资料，完善环境整治依据。

（二）遵循“最小干预”原则，充分利用原有建筑材料、构件，尽可能保留相关历史信息，减少环境整治工程量，并做好工程记录。

（三）深化文物建筑周边建筑拆除、整治、修复的具体施工方案，细化街巷、庭院、基础设施等整治方案，补充各项措施的详细说明和图纸，补充拆除建筑现状图。

（四）保护范围内以步行道和小型参观游览路为主，不得大规模扩建硬化道路，道路铺装应参考原有做法，铺装面层与两侧传统民居风格相协调。

（五）充分考虑施工对文物安全的影响，补充必要的文物保护措施和应急预案。基础设施管线埋地应与文物建筑保留一定距离，确保文物安全。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》等相关法规，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年4月24日
