# 国家邮政局人事司转发《中共中央组织部、中共中央宣传部关于认真学习贯彻习近平总书记为第五批全国干部学习培训教材所作<序言>精神的通知》的通知

## 国家邮政局人事司转发《中共中央组织部　中共中央宣传部关于认真学习贯彻习近平总书记为第五批全国干部学习培训教材所作<序言>精神的通知》的通知

各省（区、市）邮政管理局，国家局直属各单位、机关各司室：

现将《中共中央组织部 中共中央宣传部关于认真学习贯彻习近平总书记为第五批全国干部学习培训教材所作<序言>精神的通知》（中组发〔2019〕5号）转发给你们，请认真学习，做好落实。

请各省（区、市）邮政管理局、国家局直属单位对干部学习用书作出具体安排，保证厅局级、县处级领导干部学习用书，其他人员用书也要做好统筹安排。国家局机关各司室的学习用书由人事司统一安排。

各省（区、市）局学习贯彻习近平总书记为第五批全国干部学习培训教材所作《序言》精神情况及学习用书安排情况，请在报送2019年干部教育培训工作总结和2020年培训计划时一并报送人事司。

附件：中共中央组织部 中共中央宣传部关于认真学习贯彻习近平总书记为第五批全国干部学习培训教材所作《序言》精神的通知
