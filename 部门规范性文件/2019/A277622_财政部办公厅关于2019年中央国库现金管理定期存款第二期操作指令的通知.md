# 财政部办公厅关于2019年中央国库现金管理定期存款第二期操作指令的通知

财办库〔2019〕145号

中国人民银行货币政策司、国库局：

现决定实施2019年中央国库现金管理定期存款第二期操作。

本期存款期限3个月，计划存款量800亿元，存款起息日为2019年5月30日，到期日为2019年8月29日。本期存款定于5月30日上午9点至9点30分，通过中央国库现金管理商业银行定期存款业务招投标系统，面向中央国库现金管理商业银行定期存款业务参与银行，按照《中央国库现金管理商业银行定期存款招投标规则》（财库[2018]11号）进行招投标。

请你司（局）按照有关规定，做好相关工作。

特此通知。

财政部办公厅

2019年5月27日
