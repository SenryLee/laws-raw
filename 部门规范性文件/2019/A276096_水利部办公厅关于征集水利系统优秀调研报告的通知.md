# 水利部办公厅关于征集水利系统优秀调研报告的通知

办政法函〔2019〕410号

部机关各司局，部直属各单位，各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局：

《水利系统优秀调研报告》至今已累计出版十六辑，收录了近800篇优秀调研成果，为推动水利改革发展提供了有益借鉴和政策支撑。为进一步激发广大水利工作者深入基层开展调查研究的工作热情，拟选编出版《水利系统优秀调研报告》（第十七辑）。请各单位认真组织，做好2019年度优秀调研报告的推荐工作。现将相关要求通知如下：

一、各省、自治区、直辖市水利（水务）厅（局）推荐2~3篇，部机关司局，部直属单位、计划单列市水利（水务）（局）、新疆生产建设兵团水利局推荐1~2篇。推荐的调研报告文稿控制在5000字以内。

二、各单位推荐的调研报告需为2018年围绕水利改革发展的重点、难点、热点、亮点问题开展调研活动所形成的调研报告。领导讲话、工作总结、科研论文等不在推荐之列。

三、调研报告的作者应留详细通讯地址、联系电话及电子邮箱；以调研组方式形成的调研报告，请指定1人作为联系人并注明联系方式。

四、推荐的调研报告纸质文稿请寄水利部政策法规司政策处，地址：北京市西城区白广路二条2号，邮政编码：100053，信封请注明“推荐调研报告”字样，同时将文稿的电子版发送至zhengcechu@mwr.gov.cn。

五、投稿截止时间为2019年5月24日。
