# 交通运输部办公厅关于组织做好2019年度交通运输科技统计调查工作的通知

交办科技函〔2019〕1693号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），有关交通运输企业、高等院校，部属有关单位，各有关单位：

根据《交通运输部办公厅关于印发公路水路行业2019年年度和2020年定期统计调查制度的通知》（交办规划函〔2019〕1454号），决定组织实施2019年度交通运输科技统计调查工作，现将有关事项通知如下：

一、统计调查工作要严格按照国家统计局批准的《交通运输科技统计调查制度》（国统制〔2018〕136号）执行，统计期为2019年1月1日—12月31日。《交通运输科技统计调查制度》可登陆交通运输部网站http://xxgk.mot.gov.cn/jigou/zhghs/201910/t20191021_3286603.html下载。

二、各单位要筑牢法治意识，坚持强化依法统计、依法治统，切实提高政治站位，增强责任意识，深入贯彻执行党中央、国务院关于统计工作的决策部署，坚决防范和惩治统计造假、弄虚作假，确保统计数据的质量。

各单位要全面夯实数据质量责任，真实、准确、完整、及时填报统计资料，不得迟报、虚报、瞒报、漏报。统计报表须经本单位负责人确认后于2020年2月15日前发送至交通运输部科技统计专用邮箱jtkjtj@catsic.com。

三、请各单位要高度重视，精心谋划，加大投入，确保2019年度交通运输科技统计调查工作按期、高质量完成。提早布置本单位的报送工作，确保统计人员的相对稳定，如有人员变动，及时报备。
