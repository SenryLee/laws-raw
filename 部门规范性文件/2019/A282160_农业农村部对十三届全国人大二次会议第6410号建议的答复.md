# 农业农村部对十三届全国人大二次会议第6410号建议的答复

## 对十三届全国人大二次会议第6410号建议的答复

农办议〔2019〕536号

陶勋花代表：

您提出的关于支持四川生猪产业转型升级发展的建议收悉。经商财政部，现答复如下。

一、关于支持发展生猪生产

为调动地方发展生猪生产的积极性，2007年，中央财政设立生猪调出大县奖励资金，对生猪调出大县给予奖励。2017—2019年，生猪调出大县奖励资金分别安排四川省3亿元、3亿元、2.5亿元，由生猪调出大县统筹用于生猪生产流通和产业发展，支持范围包括：生猪（牛羊）生产环节的圈舍改造、良种引进、粪污处理、防疫、保险、牛羊饲草料基地建设，以及流通加工环节的冷链物流、仓储、加工设施设备等方面的支出。

二、关于支持四川现代生猪种业体系建设

2009年，国家启动实施生猪遗传改良计划，加快生猪引进品种的本土化选育进程。通过畜禽良种工程、畜禽种质资源保护等项目，支持包括四川省在内的各省（区、市）不断完善畜禽遗传资源保护体系、育种创新体系和良种繁育体系。截至2018年底，遴选出以企业为主体的国家级生猪核心育种场98个，其中四川省有7个。目前，我部正会同发展改革委，编制《现代种业提升工程建设规划（2019—2025年）》，将畜禽种业作为规划重要内容，统筹考虑包括四川省在内的种猪产业布局，从提高畜禽遗传资源保护能力、育种创新能力、性能测试能力和良种繁育能力四个方面，加大基础设施建设支持力度，提升支撑保障能力。

三、关于支持标准化健康养殖和粪污资源化利用

财政部会同我部启动畜禽粪污资源化利用试点。采取以奖代补方式，重点支持以农用有机肥和农村能源为重点的第三方处理主体相关设施建设，以及规模养殖场节水养殖工艺和设备改进、粪污资源化利用配套设施建设等，加快推进畜禽粪污治理。2017—2018年，中央财政累计安排资金40亿元，支持畜牧大县实施整县推进。截至目前，中央财政和中央预算内投资共计支持585个畜牧大县整县推进粪污资源化利用，实现了畜牧大县粪污治理全覆盖。

四、关于加强动物疫病防控工作

为保障动物疫病防控工作开展，2018年中央财政安排动物防疫等补助经费68.28亿元。具体包括四个方面：一是强制免疫补助，主要用于国家重点动物疫病开展强制免疫、免疫效果监测评价、人员防护等相关防控措施，以及实施强制免疫计划、购买防疫服务等方面。二是强制扑杀补助，主要用于预防、控制和扑灭国家重点动物疫病过程中被强制扑杀动物的补助等方面。三是养殖环节无害化处理补助，主要用于养殖环节病死猪无害化处理等方面。四是应对非洲猪瘟疫情防控，中央财政专门下达非洲猪瘟疫情防控工作专项经费7.48亿元，支持地方统筹用于加强生猪产地检疫、屠宰检疫和运输车辆监管等非洲猪瘟防控相关工作。

您提出的“支持四川现代生猪种业体系建设、标准化健康养殖体系建设、粪污资源化利用水平提升”等相关建议，中央财政在以上政策中均有体现。下一步，我们将结合您的建议，继续完善相关政策措施，进一步支持包括四川在内的生猪产业转型升级。

感谢您对畜牧业发展的关心，希望继续对我部工作给予支持。
