# 农业农村部对十三届全国人大二次会议第8656号建议的答复

## 对十三届全国人大二次会议第8656号建议的答复

农办议〔2019〕493号

李金东代表：

您提出的关于积极应对农民老龄化的建议收悉。经商财政部，现答复如下。

一、关于深化土地流转制度改革、集体资产股份制“三变”改革、发展现代农业

关于深化土地流转制度改革。党中央、国务院高度重视放活农村土地经营权。2014年，中共中央办公厅、国务院办公厅《关于引导农村土地经营权有序流转发展农业适度规模经营的意见》，明确要求严格规范土地流转行为，土地承包经营权属于农民家庭，土地是否流转、价格如何确定、形式如何选择，应由承包农户自主决定，流转收益应归承包农户所有。2016年，中共中央办公厅、国务院办公厅印发《关于完善农村土地所有权承包权经营权分置办法的意见》，明确提出承包农户有权通过转让、互换、出租（转包）、入股或其他方式流转承包地并获得收益，任何组织和个人不得强迫或限制其流转土地。《农村土地承包法》也明确规定，国家保护承包方依法、自愿、有偿流转土地经营权。按照中央要求，农业农村部着力加强土地经营权流转管理和服务，印发了《农村土地经营权流转交易市场运行规范（试行）》等文件。下一步，我部将进一步指导各地健全土地经营权流转市场，规范市场运行机制，引导土地流转双方签订书面流转合同。

关于农村集体资产股份制“三变”改革。农村“三变”的主要内容是推动农村资源变资产、资金变股金、农民变股东，其实质是通过推进农村集体产权制度改革，发展多种形式股份合作，壮大集体经济实力，增加农民财产性收入。2016年，《中共中央、国务院关于稳步推进农村集体产权制度改革的意见》提出，“将农村集体经营性资产以股份或者份额形式量化到本集体成员，作为其参加集体收益分配的基本依据”“对政府拨款、减免税费等形成的资产归农村集体经济组织所有，可以量化为集体成员持有的股份”“鼓励整合利用集体积累资金、政府帮扶资金等，通过入股或者参股农业产业化龙头企业、村与村合作、村企联手共建、扶贫开发等多种形式发展集体经济”。我部高度重视农村“三变”工作，将各地一些成熟做法吸收到农村集体产权制度改革相关政策文件中。下一步，我部将在推进农村集体产权制度改革工作中，指导和支持各地积极发展农民股份合作，探索“三变”等发展壮大集体经济的有效路径，不断增加农民的财产性收入。

关于鼓励“一村一品”和一二三产业融合发展。2011年开展全国“一村一品”示范村镇创建工作以来，共认定2409个全国“一村一品”示范村镇。2018年，我部公布了300个全国“一村一品”示范村镇。同时，我部高度重视农村一二三产业融合发展，2016年，会同财政部等14部门印发《关于大力发展休闲农业的指导意见》。2018年以来，我部又印发《关于实施农村一二三产业融合发展推进行动的通知》《关于印发全国农村一二三产业融合发展先导区创建名单的通知》等文件，进一步引导农村一二三产业跨界融合、紧密相连、一体推进，形成农业与其他产业深度融合格局，继续催动新产业新业态新模式发展。下一步，我部将会同有关部门，加快推动农村一二三产业融合发展，不断壮大农业农村发展新动能，提升乡村产业发展质量。

二、关于大力推动农业产业集聚发展

党中央、国务院一直高度重视农业产业化。2017年，中共中央办公厅、国务院办公厅印发《关于加快构建政策体系培育新型农业经营主体的意见》，在完善财政税收政策、加强基础设施建设、改善金融信贷服务、支持人才培养引进等方面，提出了一系列扶持新型农业经营主体发展的政策措施。中央财政通过支持建立健全全国农业信贷担保体系、直接支持等多种方式加大对新型农业经营主体支持力度，着力解决新型农业经营主体在适度规模经营中的“融资难”“融资贵”问题。我部认真贯彻落实中央要求，积极支持新型农业经营主体发展。严格落实《中华人民共和国农民专业合作社法》，开展农民专业合作社质量提升整县推进试点工作。深入推进示范社创建，会同有关部门联合开展了示范社建设行动。2019年，我部会同财政部印发《关于做好2019年农业生产发展等项目实施工作的通知》，支持龙头企业为主体的农业产业化联合体发展，通过支持发展产业化联合体， 推动龙头企业与农民合作社、家庭农场以及农户建立利益联结。下一步，我部将会同有关部门，进一步完善相关政策措施，加大新型农业经营主体支持力度。

三、关于加大农机购置补贴力度

为进一步支持引导农业机械化全程全面高质高效发展， 2018年，中央财政安排资金186亿元，稳步实施农机购置补贴。同时，财政部会同我部制定出台了《2018—2020年农机购置补贴实施指导意见》，明确补贴范围为15大类42个小类137个品目机具种类，补贴对象为从事农业生产的个人和农业生产经营组织。各省可以根据农业生产实际需要和补贴资金规模，对纳入中央财政全国农机购置补贴机具种类范围的机具应补尽补。此外，可选择不超过3个品目的产品开展农机新产品购置补贴试点，重点支持绿色生态导向和丘陵山区特色产业适用机具。2019年4月，我部印发《关于加快推进农业机械化转型升级的通知》，明确提出要推进农业生产机械化全面发展，推进农机服务模式与农业适度规模经营相适应，推进机械化生产与农田建设相适应，稳定实施农机购置补贴政策。下一步，我部将会同有关部门，加快推进农业机械化转型升级发展，不断提高农业机械化水平，助力农业农村现代化。

四、关于实施乡村人才振兴战略

中央财政高度重视支持高素质农民培育工作，着力实施新型农业经营主体带头人轮训计划和现代青年农场主培养计划，开展农村实用人才带头人培训，培育“爱农业、懂技术、善经营”的高素质农民。我部高度重视农民教育培训工作，一是大力开展农民培训。2014年开始，我部联合财政部重点面向新型农业经营主体带头人和返乡涉农创业者，以提高生产经营能力和专业技能为目标，开展农业全产业链培训，促进农民创业兴业。二是积极开展农民职业教育。我部联合教育部成立中国现代农业校企联盟，积极培养农业技术技能人才和高素质农民，加快构建现代农业职业教育体系。我部联合教育部等部门印发《高职扩招专项工作实施方案》，2019年面向退役军人、下岗失业人员、农民工和高素质农民等群体开展高职扩招专项工作。三是充分利用信息化手段。整合构建全国农业科教云平台，为高素质农民提供在线学习、在线咨询、成果速递和线上考核等服务。四是大力培养农村实用人才。会同中央组织部大力开展农村实用人才带头人和大学生村官示范培训，不断完善“村庄是教室、村官是教师、现场是教材”的培训模式，示范带动各地大规模开展农村实用人才培训。下一步，我部将继续大力推进农民教育培训工作，聚焦乡村振兴人才需求，推动高素质农民培育转型升级，全面提升质量效能，服务乡村振兴战略实施。

五、关于引导青年到农村进行“乡创”

2016年，国务院办公厅印发《关于支持返乡下乡人员创业创新 促进农村一二三产业融合发展的意见》，提出了支持返乡下乡人员创业创新的政策措施。近年来，我部不断推动落实乡村就业创业扶持政策，引导各类人才返乡入乡创业创新，拓展乡村就业创业空间。一是不断强化政策扶持，优化乡村就业创业公共服务。牵头成立了13个部委参与的农村创业创新推进协调机制。印发《农业农村部关于大力实施乡村就业创业促进行动的通知》，部署培育主体、打造园区、发展特色产业、推动产业融合等重点任务。二是大力推动农村双创，引领更多农村劳动者充分就业。截至2018年，各类返乡入乡创业创新人员达780万人，其中返乡农民工占70%。下一步，我部将会同有关部门，进一步优化发展环境，积极引导各类人才到农村创业创新。

感谢您对“三农”工作的关心，希望今后继续支持我们的工作。
