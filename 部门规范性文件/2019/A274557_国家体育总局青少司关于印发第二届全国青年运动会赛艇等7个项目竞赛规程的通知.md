# 国家体育总局青少司关于印发第二届全国青年运动会赛艇等7个项目竞赛规程的通知

## 体育总局青少司关于印发第二届全国青年运动会赛艇等7个项目竞赛规程的通知

各省、自治区、直辖市、新疆生产建设兵团体育局，有关运动项目管理中心（协会）：

现将第二届全国青年运动会赛艇等7个项目单项竞赛规程印发给你们，请遵照执行。

体育总局青少司

2019年2月28日

附件：1.第二届全国青年运动会赛艇竞赛规程

2.第二届全国青年运动会皮划艇静水竞赛规程

3.第二届全国青年运动会皮划艇激流回旋竞赛规程

4.第二届全国青年运动会中国式摔跤竞赛规程

5.第二届全国青年运动会橄榄球竞赛规程

6.第二届全国青年运动会高尔夫球竞赛规程

7.第二届全国青年运动会龙舟竞赛规程
