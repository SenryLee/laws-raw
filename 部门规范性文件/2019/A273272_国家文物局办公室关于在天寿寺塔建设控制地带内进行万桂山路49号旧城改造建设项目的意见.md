# 国家文物局办公室关于在天寿寺塔建设控制地带内进行万桂山路49号旧城改造建设项目的意见

办保函〔2019〕5号

安徽省文物局：

你局《关于广德县万桂山路旧城改造49号楼涉及设计天寿寺塔建设控制地带的请示》（皖文物保〔2019〕74号）收悉。经研究，我局暂不同意在天寿寺塔建设控制地带内进行万桂山路49号旧城改造建设项目。

一、对所报方案尚需作做提出以下必要的修改和完善意见：

（一）应进一步核实天寿寺塔现行的法定保护区划和管理规定，严格按照其建设控制要求调整方案设计。

（二）所报设计图纸、说明及文物影响评估较为粗略，对建设项目及周边情况反映不足，应予认真补充完善。

（三）严格控制建筑高度，进一步调减建筑体量。

二、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月3日
