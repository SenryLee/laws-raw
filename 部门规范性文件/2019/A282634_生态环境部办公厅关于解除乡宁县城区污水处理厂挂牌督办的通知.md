# 生态环境部办公厅关于解除乡宁县城区污水处理厂挂牌督办的通知

## 关于解除乡宁县城区污水处理厂挂牌督办的通知

环办执法函〔2019〕785号

山西省生态环境厅：

2018年11月13日，我部印发《关于对28家重点排污单位主要污染物排放严重超标问题挂牌督办的通知》（环办执法函〔2018〕1295号），对乡宁县城区污水处理厂进行挂牌督办。按照督办要求，你厅督促相关地方和排污单位积极整改，并向我部提交了解除该排污单位挂牌督办的申请。

经现场核查整改情况并核实排污单位自动监测数据，乡宁县城区污水处理厂基本达到了督办要求，同意对其解除挂牌督办。请你厅继续加强监督管理，督促排污单位认真履行环境保护主体责任，确保污染物稳定达标排放。

生态环境部办公厅

2019年10月11日
