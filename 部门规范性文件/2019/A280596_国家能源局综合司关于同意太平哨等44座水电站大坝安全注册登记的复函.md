# 国家能源局综合司关于同意太平哨等44座水电站大坝安全注册登记的复函

国能综函安全〔2019〕186号

国家能源局大坝安全监察中心:

报来《关于太平哨等44座水电站大坝安全注册登记检查意见的请示》(坝监安监[2019]61号)收悉。经研究，函复如下。

一、同意江苏溧阳上库坝、溧阳下库坝，湖北小漩，四川溪洛渡、春堂坝共5座水电站大坝安全初始注册,注册登记等级为甲级。

二、同意四川玉林桥、贵州泥猪河共2座水电站大坝安全初始注册，注册登记等级为乙级。

三、同意辽宁太平哨，新疆吉林台一级、温泉，青海直岗拉卡，重庆石板水、酉酬、盖下坝，湖北葛洲坝、清水塘,湖南铜湾，江西江口，四川大兴、映秀湾、耿达、渔子溪、柳洪、坪头、瀑布沟、深溪沟、铜街子，广东流溪河，广西岩滩、平班，云南徐村、景洪、腾龙桥二级、崖羊山、石门坎、龙马、居甫渡、戈兰滩、土卡河，贵州东风、响水共34座水电站大坝安全换证注册,注册登记等级均为甲级。

四、同意四川杨村、云南达开、重庆鱼跳共3座水电站大坝安全换证注册，注册登记等级为乙级。

请你中心继续做好以上水电站大坝安全注册登记及技术监督管理相关工作，配合有关派出能源监管机构督促各水电站大坝安全责任主体单位按照检查意见限期完成整改工作。

国家能源局综合司

2019年8月9日
