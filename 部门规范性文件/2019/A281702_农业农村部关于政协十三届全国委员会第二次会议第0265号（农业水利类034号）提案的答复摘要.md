# 农业农村部关于政协十三届全国委员会第二次会议第0265号（农业水利类034号）提案的答复摘要

## 关于政协十三届全国委员会第二次会议第0265号（农业水利类034号）提案的答复摘要

关于加强农村实用人才队伍建设的提案收悉。经商教育部、银保监会、财政部，现答复如下。

一、关于制定相关政策

2010年，中共中央、国务院印发《国家中长期人才发展规划纲要（2010—2020年）》，提出推进农村实用人才队伍建设。2011年，中央组织部、农业部等五部门联合印发《农村实用人才和农业科技人才队伍建设中长期规划（2010—2020年）》。我部从2012年起组织开展农村实用人才评价认定工作。下一步，我部拟会同有关部门谋划下一阶段农村实用人才队伍建设的总体目标和主要任务，完善农村实用人才培养政策。完善农村实用人才评价方法，为农村实用人才精准培养提供支撑。

二、关于完善相关激励机制

近年来，农业农村部、财政部、银保监会等部门在财政税收、金融信贷、农业保险等方面不断加大政策扶持力度，为包括农村实用人才在内的各类人才创办新型农业经营主体制定优惠政策，健全激励机制。下一步，我部将会同有关部门进一步探索完善针对农村实用人才的支持政策，推动有关农业项目向农村实用人才倾斜。

三、关于强化培训体系建设

近年来，我部会同中央组织部开展农村实用人才带头人示范培训，带动各地大规模培养农村实用人才。会同财政部实施新型职业农民培育工程，加强农民教育培训体系建设，已形成党委政府主导、农业农村部门牵头、农业广播电视学校等公益性培训机构为主体、市场力量和多方资源共同参与的农民教育培训网络。下一步，我部将会同有关部门进一步优化教育培训体系，丰富教育培训内容，加大农村实用人才培养力度。

四、关于构建人才培育机制

2013年以来，教育部会同我部和国家林草局先后印发《关于推进高等农林教育综合改革的若干意见》《关于加强农科教结合实施卓越农林人才教育培养计划2.0的意见》，强化涉农专业招生和就业政策支持。支持农林高校根据产业发展需要动态调整专业设置。今年，教育部等六部门印发《高职扩招专项工作实施方案》，将农民列入扩招主要群体。下一步，我部将会同教育部等有关部门进一步构建完善人才培育机制，拓宽农村人才培育渠道，提升农村人才队伍整体素质。

五、关于引导各类人才向农村流动

2019年，中办印发《关于鼓励人才向艰苦边远地区和基层一线流动的意见》，鼓励引导更多优秀人才到艰苦边远地区和基层一线贡献才智、建功立业。农业农村部联合有关部门实施农村创业创新促进行动，引导各类人才返乡下乡创业兴业，带动当地人才就地就近就业。下一步，我部将认真贯彻落实中央部署要求，鼓励引导各类人才向农村流动。

农业农村部
