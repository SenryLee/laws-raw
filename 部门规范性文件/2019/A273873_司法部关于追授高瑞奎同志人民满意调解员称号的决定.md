# 司法部关于追授高瑞奎同志人民满意调解员称号的决定

各省、自治区、直辖市司法厅（局），新疆生产建设兵团司法局：

高瑞奎，男，汉族，1948年5月出生，中共党员，河北省正定县人，生前担任河北电视台农民频道《非常帮助》栏目“帮大哥”、正定县“帮大哥”高瑞奎调解室主任、正定县“帮大哥、帮大姐”人民调解员协会会长。2019年1月3日，高瑞奎同志在上午成功调解一起纠纷，下午送达调解书时，因突发心脏病抢救无效去世，享年71岁。

高瑞奎同志1970年5月加入中国共产党，自1976年从事人民调解工作以来，43年如一日，长期扎根基层，奋战在矛盾纠纷化解的第一线，哪里有矛盾纠纷，哪里就有他的身影。他坚持发展“枫桥经验”，努力实现矛盾不上交，先后调解各类矛盾纠纷近万件，调解成功率达98%，在调解工作实践中总结出耐心、真心、热心、恒心、决心“五心”调解法，是河北省“帮大哥”“帮大姐”调解品牌的带头人。他经常为基层调解员授课，将自己的调解经验和技巧传授给大家，带出了一批明星调解员。他积极参加电视调解栏目，注重通过调解开展法治宣传教育，取得了“调解一案、教育一片”的社会效果和法律效果，扩大了人民调解工作的社会影响力。他被中宣部、司法部授予“全国法治宣传教育模范个人”，被司法部授予“全国模范人民调解员”等称号，被评为河北省“十大法治人物”、石家庄市“优秀共产党员”和“感动省城十大人物”等。

高瑞奎同志将自己的一生奉献给了人民调解事业，在人民调解工作岗位上作出了突出贡献，司法部决定追授高瑞奎同志人民满意调解员称号。

司法部号召全国各级司法行政机关和广大人民调解组织、人民调解员向高瑞奎同志学习。学习他对党忠诚、信念坚定，全心全意为人民服务的政治品格；学习他恪尽职守、勤勉务实，一心扑在调解工作上的敬业精神；学习他廉洁自律、无私奉献，不计较个人得失的高尚情怀。全国司法行政系统要坚持以习近平新时代中国特色社会主义思想为指导，认真落实以人民为中心的发展思想，坚持以人民满意为标准，深入推进坚持发展“枫桥经验”实现矛盾不上交三年行动，全力排查化解矛盾纠纷，努力维护社会和谐稳定，以优异的成绩迎接中华人民共和国成立70周年。

司法部
