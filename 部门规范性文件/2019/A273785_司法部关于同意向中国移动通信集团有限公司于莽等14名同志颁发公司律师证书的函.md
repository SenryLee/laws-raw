# 司法部关于同意向中国移动通信集团有限公司于莽等14名同志颁发公司律师证书的函

司发函〔2019〕5号

中国移动通信集团有限公司：

你公司《关于开展公司律师队伍建设的请示》(中移法〔2018〕240号)收悉。经审核，同意向以下14名同志颁发公司律师证书：

于莽、董宇、孙本静、李溯、张亚、尹芳、薄勇、乔枫、于雷、乔敏、王广、张薇、易小珍、冯靓。

司法部
