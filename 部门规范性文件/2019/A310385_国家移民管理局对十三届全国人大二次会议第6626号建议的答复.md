# 国家移民管理局对十三届全国人大二次会议第6626号建议的答复

林毅等6名代表：

你们提出的关于支持义乌国际贸易综合改革试验区的建议收悉，现答复如下：

近年来，国家移民管理局高度重视“放管服”改革工作，立足职能任务，主动对接国家重点发展战略，出台了服务京津冀、长三角、粤港澳大湾区、雄安新区、海南自贸区建设的一系列移民和出入境便利举措。2016年1月30日，经报国务院批准，江浙沪对53个国家人员实施144小时过境免签，由上海、杭州、南京有关口岸入境的53国人员可在上海、江苏、浙江三省行政区域内停留144小时，其中包括义乌市。

关于你们提出的“允许义乌试验区同步试验各自贸试验区及全面创新改革示范区实施的出入境便利政策措施，支持义乌试验区探索建立既方便外国人居留经商又能实施有效监管的新型模式”的建议。目前，我局正在研究深化“放管服”改革的意见，拟对支持自贸区等国家重点发展区域实施的出入境便利措施进行总结评估、优化整合，向全国其他地区复制推广。同时，正在研究“长三角”区域出入境政策措施一体化工作意见，通过规则机制共建、数据信息共享、区域监管共治等方式，进一步创新规范“长三角”地区外国人签证和停居留便利政策措施，广泛吸引集聚外籍高端人才和急需紧缺人才，支持服务“长三角”区域一体化发展。下步，我局将充分考虑义乌国际贸易综合改革试验区的政策需求，积极支持义乌国际贸易综合改革试验区建设。

感谢你们对移民管理工作的关心和支持。
