# 司法部办公厅关于向中国中钢集团有限公司傅婧英等2名同志颁发公司律师证书的函

司办函〔2019〕619号

中国中钢集团有限公司：

你公司《关于申请开展公司律师工作的函》（中钢集团法〔2019〕68号）收悉。我部经审查，同意向傅婧英、陈志湘等2名同志颁发公司律师证书。

司法部办公厅

2019年5月29日
