# 人力资源社会保障部办公厅、民政部办公厅关于颁布孤残儿童护理员等3个国家职业技能标准的通知

## 人力资源社会保障部办公厅　民政部办公厅关于颁布孤残儿童护理员等3个国家职业技能标准的通知

人社厅发〔2019〕58号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）、民政厅（局）：

根据《中华人民共和国劳动法》有关规定，人力资源社会保障部、民政部共同制定了孤残儿童护理员等3个国家职业技能标准，现予颁布施行。原相应国家职业技能标准同时废止。
