# 财政部关于提前下达新疆生产建设兵团2020年文化人才专项经费预算的通知

财教〔2019〕181号

新疆生产建设兵团财政局：

为提高预算完整性，加快支出进度，经研究，现提前下达你兵团2020年文化人才专项经费预算281万元，列入“1100208结算补助收入”预算科目（项目代码：Z135050009064），支持选派文化工作者108人，培养文化工作者30人。待2020年预算年度开始后，按程序拨付使用。

请你兵团尽快将资金分解下达至师团，由资金使用单位按照有关预算管理规定落实到支出功能分类项级科目，自下而上逐级汇总编列入2020年“二上”预算。

财政部

2019年10月31日
