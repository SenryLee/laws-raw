# 农业农村部关于十三届全国人大二次会议第1141号建议答复摘要

## 十三届全国人大二次会议第1141号建议答复摘要

党中央、国务院高度重视包括大别山在内的革命老区发展，先后出台了一系列加快老区振兴发展的方针政策，其中，《大别山革命老区振兴发展规划》对大别山革命老区振兴发展作了全面部署，我部和有关部门认真贯彻落实国家有关决策部署，推进政策落地，加大支持力度，助力包括六安市在内的革命老区打赢脱贫攻坚战，接续推进乡村振兴。

支持大别山等革命老区争取更多的产业发展机遇。积极支持优势特色产业发展，支持涉农资金整合，推进"一村一品"发展，加强产业规划指导，推进农村资源变资产、资金变股金、农民变股东"三变"改革，促进村集体经济发展。推进一二三产业融合发展，出台专门政策措施，着力解决农村融合发展贷款难、用地难问题，促进农产品精深加工业发展，支持建设农业产业强镇，培育发展新产业、新业态，鼓励创建国家现代农业产业园，示范引导现代农业发展。积极推进休闲农业和乡村旅游发展，支持乡村旅游设施建设，吸引景区周边乡村提供旅游服务。 积极推进农业电商发展，支持农产品流通基础设施建设，积极推动出台支持农业电商发展的政策措施。同时，大力推动电商产销衔接，促进农产品生产经营单位与涉农电子商务企业对接。支持秸秆和畜禽粪污综合利用，支持大别山革命老区整县推进粪污资源化利用，实现了大别山革命老区畜牧大县粪污治理全覆盖。

给予大别山革命老区特色产业发展主体培育、项目资金和认证支持。积极支持主体培育，在农民合作社国家示范社评定和农业产业化国家重点龙头企业认定时，对革命老区予以倾斜，并适当降低评定标准。积极推动龙头企业与贫困地区合作对接，一批扶贫"龙头"成长壮大、落地生根，成为带动脱贫的"火车头".此外，引导各地积极推广订单帮扶、股份合作、生产托管等龙头企业带贫模式，让包括六安市在内的广大贫困群众分享更多产业发展红利。加强绿色有机农产品认证，建立"绿色通道",实施"五优先"措施，加大费用减免力度。支持农业品牌发展，建设中国农业品牌目录制度，创新开展省部长推介、名人公益推介以及"乡人乡味"农民推介等农业品牌专场推介活动，促进区域公用品牌、企业品牌、产品品牌协同发展。 加强高标准农田建设，在高标准农田建设任务分配时积极向贫困县多的革命老区省倾斜，同时，允许各省根据实际情况适当提高贫困地区高标准农田建设投资标准，适当降低单个项目建设规模。统筹推进乡村规划，召开协调推进机制会议，邀请中央组织部等27个部门参加，形成部门协调机制。加强村庄规划培训，召开统筹推进村庄规划现场观摩会，实地观摩村庄规划典型案例。

加大对发展特色主导产业金融支持力度。加大银行信贷支持力度，支持农业信贷担保体系建设，鼓励各银行业金融机构创新信贷产品服务，明确提出完善金融支持产业发展与带动贫困户脱贫的挂钩机制和扶持政策，促进扶贫小额信贷规范健康发展。支持涉农企业上市和融资，国家积极支持符合条件的革命老区涉农企业通过发行上市等方式进行融资和再融资，积极推动私募股权、创业投资基金投资农业相关企业和大型合作社等，支持包括六安市在内的革命老区实施乡村振兴战略。扩大涉农保险保障范围，国家积极支持保险机构扩大涉农保险，鼓励保险机构与地方探索开展特色农业保险，建立多层次的农业保险体系，满足贫困户多样化的农业保险需求。

下一步，国家将进一步聚焦贫困地区地方特色主导产业，综合发挥财政、信贷、债券和上市等多种融资渠道作用，创新特色农业保险服务，助力包括六安市在内的大别山革命老区早日打赢脱贫攻坚战。

2019年09月03日
