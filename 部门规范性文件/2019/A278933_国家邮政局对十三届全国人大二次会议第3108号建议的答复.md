# 国家邮政局对十三届全国人大二次会议第3108号建议的答复

## 对十三届全国人大二次会议第3108号建议的答复

国邮函〔2019〕60号

张近东代表：

您提出的“关于发展多层次配送网络，推进物流末端配送智慧化建设的建议”（第3108号）收悉。经商自然资源部、工业和信息化部、公安部，现答复如下：

您所分析的问题基本与末端物流配送环境存在的问题一致，所提建议紧跟我国物流发展趋势，具有非常好的参考价值。

作为快递业务主管部门，国家邮政局一直致力于推动优化快递业发展环境。尤其在推动快递末端配送车辆通行问题解决方面，我们开展了大量工作。2018年初，我局会同商务部推动国务院办公厅出台《关于推动电子商务与快递物流协同发展的指导意见》，鼓励各地对快递服务车辆实施统一编号和标识管理，要求指导各地完善城市配送车辆通行管理政策，合理确定通行区域和时段，对快递服务车辆等城市配送车辆给予通行便利。之后，我局又推动国务院出台《快递暂行条例》，鼓励和引导经营快递业务的企业采用先进技术，促进能末端服务设施的推广应用；要求县级以上地方人民政府公安、交通运输等部门和邮政管理部门应当加强协调配合，建立健全快递运输保障机制，依法保障快递服务车辆通行和临时停靠的权利，不得禁止快递服务车辆依法通行。11月，我局出台《国家邮政局关于规范快递末端服务车辆管理和使用工作的指导意见》，加强对各地邮政管理部门工作指导，督促各地积极推广北京电动三轮车统一车辆外观标识、统一车辆编码、统一购买保险、统一车辆车型、统一人员培训的“五统一”模式，推动地方政府出台相关政策或出台行业自律性管理文件。截至目前，全国已有221个地市出台相关政策或文件，保障快递末端车辆通行便利。

自然资源部对“将智慧物流纳入智慧城市顶层设计，统一规划、统一推进，规划物流无人车通行区及充电桩布局，并将物流自提点作为城市基础设施统一规划”等建议表示赞同，将在国土空间规划编制和实施监督、相关专项规划协同和衔接工作中发挥好智慧规划的作用，鼓励研究机构、企业、社会和相关专业人士参与探索利用新的数据生态支撑国土空间规划相关工作的实施路径。

工业和信息化部表示，在新能源车辆推广方面，近年来已单独或推动有关部门就普及发展新能源车辆、规划充电桩发展先后出台《关于新能源汽车充电设施建设奖励的通知》《关于加快电动汽车充电基础设施建设的指导意见》《电动汽车充电基础设施发展指南（2015-2020年）》《汽车产业中长期发展规划》《关于调整完善新能源汽车推广应用财政补贴政策的通知》等一系列政策。下一步，将与国家能源局等部门加强协作，推进充电桩基础设施建设，提升用户体验。在末端物流配送车辆标准制定方面，工信工业和信息化部已先后制修订《机动车安全运行技术条件》《电动自行车安全技术规范》等国家强制性标准，《电动摩托车和电动轻便摩托车安全要求》标准修订工作已在报批中。对于摩托车（含电动三轮摩托车），工业和信息化部一直是按照机动车的相关要求进行管理。下一步，将分别按照电动自行车和电动摩托车的相关技术标准，进行分类管理，并继续支持物流产业发展相关重点领域标准制定。

公安部表示，在新能源配送车辆推广方面，正在全国推广应用新能源车专用号牌，指导地方实行单独分类登记管理，落实“不限行”等便利通行措施。2018年10月公安部交通管理局专门下发《关于进一步规范和优化城市配送车辆通行管理的通知》，要求各地落实新能源车差别化通行管理政策，对纯电动轻型货车少限行甚至不限行。在推动快递电动三轮车规范管理方面，指导各地公安交管部门深入调研，积极会同有关部门探索推进快递电动三轮车规范管理，推广北京“五统一”模式。对于末端配送无人车问题，公安部支持在自动驾驶汽车上路测试相对成熟的基础上，研究无人车上路测试条件、测试权限等管理政策，助力末端配送无人车安全有序规范发展。

感谢您们对快递业发展的关心和支持！

国家邮政局

2019年6月27日
