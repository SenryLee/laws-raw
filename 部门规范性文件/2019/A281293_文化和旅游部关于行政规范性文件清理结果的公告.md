# 文化和旅游部关于行政规范性文件清理结果的公告

根据《国务院办公厅关于加强行政规范性文件制定和监督管理工作的通知》（国办发〔2018〕37号）要求，文化和旅游部对行政规范性文件进行了全面清理，现将现行有效的行政规范性文件目录和废止的行政规范性文件目录予以公告。

附件：1.文化和旅游部现行有效行政规范性文件目录

2.文化和旅游部废止的行政规范性文件目录

文化和旅游部

2019年8月19日
