# 财政部关于下达2019年车辆购置税收入补助地方资金（第三批）预算的通知

财建〔2019〕361号

四川、青海省财政厅：

鉴于你省部分地区公路灾损情况严重，根据《车辆购置税收入补助地方资金管理暂行办法》（财建〔2014〕654号）、《财政部 交通运输部关于<车辆购置税收入补助地方资金管理暂行办法>的补充通知》（财建〔2016〕722号）、《财政部 交通运输部关于印发<车辆购置税收入补助地方资金管理暂行办法>的补充通知》（财建〔2019〕272号）和《财政部 交通运输部关于进一步明确车辆购置税收入补助地方资金补助标准及责任追究有关事项的通知》（财建〔2016〕879号）等有关规定，现下达你省2019年车辆购置税收入补助地方资金用于公路灾损抢修保通项目支出预算，专项用于你省公路灾损抢修保通支出。项目代码：Z135060000035，收入列入2019年“1100253交通运输共同财政事权转移支出收入”科目，支出列2019年政府收支分类科目“214 交通运输支出”，具体金额详见附件。如果相关转移支付办法有调整或变化，将再行清算。

请按照有关文件规定安排使用，加强资金管理。

附件：财政部关于下达2019年车辆购置税收入补助地方资金预算（第三批）明细表

财政部

2019年6月25日
