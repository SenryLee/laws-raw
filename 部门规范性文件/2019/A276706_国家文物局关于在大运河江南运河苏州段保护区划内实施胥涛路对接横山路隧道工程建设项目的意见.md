# 国家文物局关于在大运河江南运河苏州段保护区划内实施胥涛路对接横山路隧道工程建设项目的意见

文物保函〔2019〕363号

江苏省文物局：

你局《关于审批大运河苏州段胥涛路对接横山路隧道工程方案的请示》（苏文物保〔2019〕40号）收悉。经研究，我局原则同意在大运河江南运河苏州段保护区划内实施胥涛路对接横山路隧道工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应细化拟建顶管结构顶部至大运河河道底部垂直距离的设计依据和安全性验算，确保拟建项目不会对大运河河道及堤岸结构安全造成负面影响。

（二）应细化拟建项目施工方案，完善施工和运营期间的监测措施及应急预案，加强施工监测和管理，采取必要措施避免出现河道及堤岸变形及沉降等情况。

（三）应进一步明确拟建项目顶管施工中始发井、接收井的“施工开挖面”的边界线与大运河保护区划的关系，其选址应避让大运河苏州段的保护范围和遗产区。

（四）应细化拟建项目施工后期的环境修复措施，确保相关区域风貌与大运河苏州段整体风貌相协调。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年4月18日
