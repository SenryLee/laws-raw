# 国家文物局关于毘山遗址建设控制地带内毘山中学建设项目的意见

文物保函〔2019〕410号

浙江省文物局：

你局《关于上报全国重点文物保护单位毘山遗址建设控制地带内实施毘山中学项目的请示》（浙文物发〔2019〕46号）收悉。经研究，我局原则同意在毘山遗址建设控制地带内实施毘山中学建设项目。

一、应进一步优化毘山中学建筑和景观设计方案，新建建筑体量、高度等应符合相关控制标准，并充分考虑遗址周边景观环境影响。同时，严格控制施工范围，细化施工过程中的文物保护措施，确保文物安全。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

五、请你局加强指导，督促湖州市人民政府尽快编制毘山遗址保护规划，综合考虑毘山遗址保护展示、湖州历史文化名城保护和城市建设等，明确管理规定和具体建设控制指标，妥善处理文物保护利用和城市建设发展之间的关系。

专此函复。

国家文物局

2019年5月5日
