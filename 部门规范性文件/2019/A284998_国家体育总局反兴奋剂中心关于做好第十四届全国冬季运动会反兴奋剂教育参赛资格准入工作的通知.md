# 国家体育总局反兴奋剂中心关于做好第十四届全国冬季运动会反兴奋剂教育参赛资格准入工作的通知

## 反兴奋剂中心关于做好第十四届全国冬季运动会反兴奋剂教育参赛资格准入工作的通知

体反兴奋剂字〔2019〕515号

各省、自治区、直辖市、新疆生产建设兵团体育局，有关运动项目管理中心（协会）：

为深入推进全覆盖、全周期、常态化、制度化的反兴奋剂教育，做好第十四届全国冬季运动会（以下简称“十四冬”）反兴奋剂宣传教育工作，反兴奋剂中心决定对参加十四冬的运动员及辅助人员实施反兴奋剂教育参赛资格准入工作（以下简称“准入工作”）。现将有关事宜通知如下：

一、总体要求

十四冬准入工作的实施对象为所有参加十四冬的运动员及辅助人员。

所有准入工作的实施对象必须接受系统的反兴奋剂教育，通过反兴奋剂准入考试，宣誓并签署反兴奋剂承诺书，经参赛单位审批后方能获得十四冬的参赛资格。

二、职责分工

反兴奋剂中心负责制定十四冬准入工作方案；开发线上教育准入平台，反兴奋剂教育准入手册、课件、讲座视频；指导并跟进各参赛单位准入工作；开展监督检查工作；汇总准入工作实施情况。

参赛单位负责按照本通知要求组织实施本单位准入工作；进行反兴奋剂准入资格审批；配合开展监督检查工作。

三、工作流程

（一）各参赛单位应成立准入工作领导小组，指定专人负责准入工作的实施。全部工作应在1月17日前完成。

（二）十四冬准入工作实行“六步走”，具体操作说明如下：

1.现场学习

准入对象须接受由纯洁体育教育讲师讲授的“十四冬-反兴奋剂教育准入”课程。

2.线上学习和考试

准入对象须登陆中国反兴奋剂教育平台（cleanmedal.chinada.cn），自行完成账号注册，并在“反兴奋剂教育准入”-“反兴奋剂教育准入通用入口”-“十四冬反兴奋剂教育准入入口”完成规定课程学习。各参赛单位须指定CADEP管理员对准入对象进行监督管理。

准入对象须在完成学习内容后进行准入考试。满分100分，80分为及格，每人仅有3次考试机会。

3.承诺和宣誓

准入对象须签署“反兴奋剂承诺书”并进行反兴奋剂宣誓。

4.现场督查

各参赛单位须对准入工作开展情况进行监督检查，对准入对象学习考试情况进行抽查。

5.调研评估

各参赛单位须调研准入对象受教情况，评估准入工作实效性。

6.资格审批

各参赛单位对准入对象进行资格审批。

（三）参赛单位可在“反兴奋剂中心官网-十四冬专区”的“技术支持”下载准入手册、课件、视频等资料开展集体学习、宣誓等形式多样的反兴奋剂教育准入工作。

（四）各参赛单位应在全部准入工作结束一周之内将工作总结，连同准入工作实施过程中的图片、视频等材料报送反兴奋剂中心。

四、监督检查

各参赛单位应对准入过程和准入结果进行监督检查。如在监督检查过程中，发现准入对象存在未完成准入工作、弄虚作假、抽查考试不合格的情况，将视情节给予相关当事人和责任人处罚。

反兴奋剂中心将组成专门工作组调研和监督各参赛单位准入开展情况。
