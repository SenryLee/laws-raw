# 生态环境部办公厅关于同意中国国际货运航空有限公司辐射安全许可证注销的函

## 关于同意中国国际货运航空有限公司辐射安全许可证注销的函

环办辐射函〔2019〕374号

中国国际货运航空有限公司：

你公司《关于注销我公司〈辐射安全许可证〉的申请》（国货航函〔2019〕1号）收悉。根据《放射性同位素与射线装置安全和防护条例》及《关于进一步明确放射性物品航空运输临时存放安全监管有关问题的通知》（环办辐射〔2018〕44号）有关规定，我部同意你公司申请，注销你公司辐射安全许可证（国环辐证［00407］）。

生态环境部办公厅

2019年4月11日
