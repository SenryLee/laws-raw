# 农业农村部对十三届全国人大二次会议第3092号建议的答复

## 对十三届全国人大二次会议第3092号建议的答复

农办议〔2019〕40号

聂永平代表：

您提出的“关于大力提高油菜机械化种植水平，保障我国食用油供给安全的建议”收悉。经商财政部，现答复如下。

国家高度重视油菜生产机械化发展，国务院2010年、2018年分别发布了《关于促进农业机械化和农机工业又好又快发展的意见》（国发〔2010〕22号）《国务院关于加快推进农业机械化和农机装备产业转型升级的指导意见》（国发〔2018〕42号），都对油菜种植、收获机械化发展提出目标要求。近年来，油菜薄弱环节机械化快速发展，2017年种植、收获环节机械化率分别为27.22%、36.92%，综合机械化率达到51.55%，有力推动了油菜生产节本增效和油菜产业稳定发展。近年来，我们主要采取了以下几个方面的措施支持发展油菜机械化。一是加强政策扶持。对油菜在内的粮棉油糖九大作物全程机械化关键薄弱环节机具实行补贴。2018年2月，农业部办公厅、财政部办公厅联合印发《2018—2020年农机购置补贴实施指导意见》，将油菜栽植机、油菜籽收获机等机具纳入全国农机购置补贴机具范围，有需求的省份均可对其实行敞开补贴、应补尽补。二是加强科研及技术支撑。通过国家重点研发计划“智能农机装备”专项，支持油菜生产关键装备和技术研究，并依托华中农业大学建设了油菜全程机械化科研基地。我部2016年成立了油菜全程机械化专家指导组，每年均召开工作推进会，农机农艺专家协同研究提出突破瓶颈难题的方向性思路，引导机具和技术改进。三是加强社会化服务支持。《国务院关于加快推进农业机械化和农机装备产业转型升级的指导意见》明确要求，按规定对新型农业经营主体开展深耕深松、机播机收等生产服务给予补助，大力推进产前产中产后全程机械化。近年来，中央财政通过农业生产发展资金，支持农业服务组织、服务型农民合作社等具有一定能力、可提供有效稳定服务的主体，针对粮食等主导产业和农民急需的关键环节，为从事粮棉油糖等重要农产品生产的农户提供社会化服务。同时鼓励各地采取政府购买服务或先服务后补助等方式，提升农业生产社会化服务的专业化、规模化水平。各地可结合实际，在政策规定范围内，统筹考虑社会化服务补助内容。四是加强试验示范。实施全程机械化示范服务项目，连续安排资金支持油菜生产县开展油菜全程机械化技术集成推广。通过组织不同地区开展对比试验、技术示范，优化形成适宜当地的油菜全程机械化技术路线；组织专家分区域研究提出了油菜品种、种植制度、经营规模、装备技术等要素集成配套的全程机械化解决方案。我部将油菜毯状苗机械化高效移栽技术列入2018年10大引领技术、将油菜机械化播栽与收获技术列入2019年农业主推技术。

下一步，我部将会同财政部，结合您所提建议，不断总结经验，进一步研究完善农机购置补贴等相关政策措施，最大限度地发挥补贴政策效应，调动农业经营主体积极性，加快提高油菜种收机械化水平，推动油菜生产持续健康发展。同时，以各项先进适用机械化种植、收获技术为重点，加大示范推广力度，依托种植大户和专业合作社等开展油菜生产全程机械化试验示范；完善良种农艺农机协同推广机制，组织多方面的专家总结不同地区的油菜全程机械化生产模式进行推介。

感谢您对农业机械化工作的关心，希望您继续支持我部工作。
