# 国家文物局对十三届全国人大二次会议第5398号建议的答复

文物保函〔2019〕678号

李海燕代表：

您提出的“关于继续支持红旗渠申报世界文化遗产的建议”收悉，经商财政部，现答复如下。

红旗渠位于河南省林州市、山西省平顺县，全长1525千米。红旗渠沿渠一、二类水库共有48座，塘堰346座，提水站45座，小型水力发电站45座，渡槽152个，隧洞211个。红旗渠年引水量2.8亿立方米，有效灌溉面积54万平方米。红旗渠于1967年7月竣工，被称为“生命渠”、“幸福渠”。红旗渠科学利用地形地貌，采用自然落差，使引水、蓄水、排水、灌溉的综合效益得到全面发挥，实现了吃水、灌溉、发电一水三用的目的，是我国水利工程史上的一个光辉典范。同时，又是当地人民自力更生、艰苦创业、改造自然奋斗精神的具体体现。

2006年，国务院将红旗渠公布为第六批全国重点文物保护单位。国家文物局指导当地文物部门，编制完成了重要点段的保护管理规划。

近年来，世界遗产申报工作的难度逐渐加大。根据世界遗产委员会新施行的“限额制”，一个缔约国每年最多只能申报一项世界遗产。同时，世界遗产委员会不断推进世界遗产均衡性的全球战略，明确向没有世界遗产或世界遗产较少的国家，以及遗产类型较少的类别倾斜，而对世界遗产大国的限制则不断增多。

我国是世界遗产大国，目前拥有世界遗产55项，其中文化遗产37项，居世界第一。世界遗产中心和国际古迹遗址理事会等专业咨询机构对我国等世界遗产大国的申报项目，往往提出更高的标准。按照《保护世界文化和自然遗产公约》及其《操作指南》的规定，申报世界文化遗产的项目，应该具有全世界范围内的突出普遍价值，较好的保存现状，真实性和完整性较高，扎实的保护管理基础，以及利益相关者对遗产保护的积极态度。这都要求我国的申报项目要在各方面做好充分的准备。

2019年6月20日，我局举行中国世界文化遗产申报项目评审会议，对包括红旗渠在内的多处申遗项目进行评审。经过讨论，专家们认为红旗渠具有一定的历史、艺术和科学价值，具备申报世界文化遗产的潜力，但各项基础工作还比较薄弱：相关研究开展不充分，遗产价值提炼比较欠缺，没有明晰的价值表述，也缺乏对比分析和研究。

下一步，我局将督促、指导地方有关部门，重点开展以下工作。

一是完善修改《红旗渠保护规划》，并报请河南省、山西省人民政府公布实施，统筹开展红旗渠保护管理工作。

二是将文物日常保养维护与必要的修缮工程相结合，同时逐步提升文物展示水平，在此基础上严格控制保护区划内的建设活动，切实维护好遗产的真实性和完整性。

三是深化红旗渠价值和申遗策略研究，总结提炼遗产自身特点，突出其20世纪遗产属性，强化同类型遗产的比较研究，在此基础上完善申遗文本。

四是针对红旗渠保护管理实际需要，建立相关部门间的沟通协调机制，推进成立跨省保护申遗协调机制。

国家文物局愿意继续给予积极的帮助和支持，通过有关专家和专业咨询机构，指导地方文物部门，完善有关申请材料，并组织专家评审，适时考虑将其纳入《中国世界文化遗产预备名单》。

财政部将会进一步优化完善资金管理机制，持续加大支持力度，推动文物保护工作。按《中华人民共和国预算法》和目前中央与地方财政事权和支出责任划分，世界文化遗产申报工作经费应由地方统筹安排。

衷心感谢您对我国世界文化遗产工作的关注和支持！

国家文物局

2019年7月10日
