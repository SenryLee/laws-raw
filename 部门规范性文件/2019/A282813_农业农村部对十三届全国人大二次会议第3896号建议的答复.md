# 农业农村部对十三届全国人大二次会议第3896号建议的答复

## 对十三届全国人大二次会议第3896号建议的答复

您提出的关于支持内蒙古巴彦淖尔市484万亩盐碱化耕地治理的建议收悉。经商发展改革委，现答复如下。

盐碱地是我国重要的后备耕地战略资源。改良盐碱地和治理盐碱化耕地对于保障国家粮食安全、保护生态环境和促进乡村振兴具有重要意义。“十二五”以来，中央各部门大力支持各地开展高标准农田建设，因地制宜推进盐碱化耕地治理，2011－2018年全国累计建设高标准农田6.4亿亩，进一步夯实了国家粮食安全基础。2014年，发展改革委会同我部等9部门印发了《关于加强盐碱地治理的指导意见》（发改农经〔2014〕594号），明确了推进盐碱地治理的总体思路和政策措施。

2018年，党和国家机构改革方案明确农业农村部统一履行农田建设管理职责。2019年，我们充分考虑内蒙古自治区在保障粮食安全中的重要作用、特殊自然条件和工程建设需求，在任务分配和资金测算时对自治区予以倾斜支持，共安排高标准农田建设任务500万亩，同步发展高效节水灌溉面积215万亩，各项任务安排规模均处于全国前列。为深入推进涉农领域“放管服”改革，农业农村部按照“大专项+任务清单”的方式统筹部署农田建设工作，把高标准农田建设项目立项、审批、实施和验收等权限下放到地方，每年向各省（区、市）下达高标准农田建设年度任务清单，指导和督促地方按时完成建设任务。内蒙古自治区可根据当前农田建设项目管理方式，在完成约束性任务的基础上，在大专项支持方向范围内，结合当地实际，按照有关规定统筹中央和地方资金对盐碱地治理工作予以重点支持。

下一步，农业农村部、发展改革委将会同相关部门，结合实施高标准农田建设、灌区续建配套与节水改造、林业生态建设等规划和项目，进一步加大对盐碱地治理的投入力度，支持盐碱地治理和改善。巴彦淖尔市可积极争取相关渠道支持，因地制宜推进当地盐碱地治理工作。

感谢您对农业农村部工作的关心，希望今后继续支持我部工作！

农业农村部

2019年9月19日
