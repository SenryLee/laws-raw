# 国家文物局关于在大运河苏州段保护区划内实施西郭桥泵站改（扩）建项目的意见

文物保函〔2019〕254号

江苏省文物局：

你局《关于审批大运河苏州段西郭桥泵站改（扩）建工程方案（修改稿）的请示》（苏文物保〔2019〕10号）收悉。经研究，我局原则同意在大运河苏州段保护范围和建设控制地带内实施西郭桥泵站改（扩）建项目。

一、上述方案尚需作以下必要的修改和完善：

（一）应进一步对拟建项目相关区域开展全面的考古调查勘探和必要的考古发掘，明确地下文物埋藏情况。如有大运河水工遗存等重要发现，应组织研究、评估和专家论证，并根据评估结论，调整项目设计方案。

（二）应在满足泵站基本功能需求的前提下，严格控制拟建项目占用运河河道、驳岸的范围和面积，原则上不得超出现有泵站的范围和面积，以妥善保护运河河道、岸线形态。

（三）应在满足泵站基本功能需求的前提下，尽可能降低拟建建筑的高度，并采用分散式布局方式，确保视廊通透。同时，应根据大运河周边环境景观和当地传统建筑特征，完善拟建建筑外观设计，力求其形制、色调与周边环境相协调。

（四）应细化拟建项目施工和运营期间的监测措施、应急预案，并进一步明确施工过程中的生态环境、景观风貌等保护要求以及各类污染物处置要求，避免污染大运河水体及周边生态环境。

（五）项目施工完成后，应做好场地清理和周边环境修复工作，采用当地植被对项目周边进行绿化，适当加大绿化面积，并设立大运河标识设施和大运河历史文化价值展示设施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月12日
