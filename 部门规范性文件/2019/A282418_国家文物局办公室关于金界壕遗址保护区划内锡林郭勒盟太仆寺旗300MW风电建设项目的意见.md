# 国家文物局办公室关于金界壕遗址保护区划内锡林郭勒盟太仆寺旗300MW风电建设项目的意见

办保函〔2019〕736号

内蒙古自治区文物局：

你局《内蒙古自治区文物局关于锡林郭勒盟太仆寺旗300MW风电项目跨越金界壕的请示》（内文物字〔2019〕44号）收悉。经研究，我局暂不同意在金界壕遗址保护区划内实施锡林郭勒盟太仆寺旗300MW风电建设项目。

一、对所报方案提出以下修改完善意见：

（一）结合图纸进一步说明风电场、风机和升压站选址与金界壕遗址保护区划的空间位置关系，制订项目选址比选方案，研究论证拟建集电线路、道路及拟扩建道路避让金界壕遗址的可行性。

（二）组织专业考古机构对拟建项目所在区域的金界壕遗址分布进行考古调查勘探，明确其分布范围及周边相关遗存分布情况。

（三）细化项目建设方案，明确各项建设内容的具体位置、方案设计和线网垂直高度，补充详细图纸和遗产影响评估。拟新建、扩建道路应避让金界壕保护范围。

（四）细化拟建项目施工方案，补充施工和运营期间的监测措施和应急预案，明确施工场地布置、施工组织管理要求，补充施工后期生态环境修复措施和文物本体标识措施。

二、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年8月20日
