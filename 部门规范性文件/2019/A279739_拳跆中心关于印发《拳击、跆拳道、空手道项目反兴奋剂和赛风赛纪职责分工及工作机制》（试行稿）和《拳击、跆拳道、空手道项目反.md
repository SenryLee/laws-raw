# 拳跆中心关于印发《拳击、跆拳道、空手道项目反兴奋剂和赛风赛纪职责分工及工作机制》（试行稿）和《拳击、跆拳道、空手道项目反兴奋剂和赛风赛纪工作细则》（试行稿）的通知

各省、自治区、直辖市、新疆生产建设兵团体育局训练处；总参军训部体育局；各行业体协：

为落实国家体育总局备战2020年东京奥运会反兴奋剂和赛风赛纪工作的相关要求，切实做好拳击、跆拳道和空手道项目的反兴奋剂和赛风赛纪工作，进一步查找工作隐患与薄弱环节，建立健全“拿干净金牌”的长效机制。经国家体育总局批准，我中心在征求协会、各省市意见的基础上，制定了《拳击、跆拳道、空手道项目反兴奋剂和赛风赛纪职责分工及工作机制》（试行稿）和《拳击、跆拳道、空手道项目反兴奋剂和赛风赛纪工作细则》（试行稿），现印发你们遵照执行。

附件1：拳击、跆拳道、空手道项目反兴奋剂和赛风赛纪职责分工及工作机制（试行稿）

附件2：拳击、跆拳道、空手道项目反兴奋剂和赛风赛纪工作细则（试行稿）
