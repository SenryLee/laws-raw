# 农业农村部对十三届全国人大二次会议第5024号建议的答复

## 对十三届全国人大二次会议第5024号建议的答复

农办议〔2019〕205号

魏德东代表：

您提出的关于加大耕地轮作休耕制度试点工作扶持力度的建议收悉。经商财政部，现答复如下。

一、关于适时扩大耕地轮作休耕制度试点规模

探索实行耕地轮作休耕制度试点是中央作出的一项重大部署，也是农村改革的一项重大政治任务。自2016年启动试点以来，我部会同财政部等部门，以绿色发展理念为引领，以资源约束紧和生态保护压力大的地区为重点，以促进农业可持续发展和平衡粮食供求矛盾为目标，稳妥有序推进耕地轮作休耕制度试点。试点面积不断扩大，由2016年的616万亩，增加到2019年的3000万亩，增长了近4倍。实施省份不断增加，由2016年的9个试点省份，增加到2019年的17个试点省份，翻了近一番。补贴力度不断加大，中央财政支持资金由2016年的14.36亿元，增加到2019年的63.1亿元，增幅达340%。覆盖区域不断拓展，由东北冷凉区、北方农牧交错区、河北地下水漏斗区、湖南重金属污染区、西南西北生态严重退化地区，又拓展扩充了黑龙江寒地井灌稻区、长江流域稻谷小麦低质低效区、黄淮海玉米大豆轮作区、新疆塔里木河流域地下水超采区。下一步，我部将会同财政部等部门，结合国家战略性农业结构调整需要、主要粮食品种供求状况，以及国际农产品贸易形势变化等情况，研究确定未来年度实施规模和试点区域。

二、关于加大对耕地轮作休耕制度试点农户的补贴力度

为充分调动农民参与耕地轮作休耕制度试点积极性，我部会同财政部等部门，根据不同作物种植收益变化，合理测算试点补助标准，让农民参与试点有账算、不吃亏。在轮作上，注重比较效益。根据现有的单产水平和种植效益，轮作模式中的玉米大豆轮作，按照1︰3的效益平衡点来测算。其他轮作模式，根据上一年的收益情况，结合市场变化动态调整，每亩补助150元左右。在休耕上，注重收入保障。休耕试点补助标准以农民种植收益不减为前提，大体上一熟区的休耕和两熟区的一季休耕，每亩补助500元左右；两熟区的全年休耕，每亩补助800元左右，略高于土地流转费用。针对去年下半年以来东北地区玉米市场价格走高、收益明显好于大豆，影响农户种植大豆积极性的情况，我部将加强与财政部沟通，争取适当提高轮作补助标准。同时，鼓励地方根据中央拨付的农业生产发展资金，按照“大专项+任务清单”的管理方式，统筹用好其他相关项目资金，因地制宜调整不同地区、不同作物间的补助标准，做到资金精准发放、收益合理补偿。

三、关于加大农业科技投入

我部统筹利用现有项目，加大对农业生产的科技投入，提升耕地轮作休耕制度试点技术水平，确保耕地轮作休耕制度试点顺利实施。一是开展技术指导。在耕地轮作休耕制度试点实施的关键农时季节，组织农业农村部玉米、大豆、薯类、油料、小宗粮豆等专家指导组，分区域制定发布生产技术指导意见，同时派出工作组和专家指导组赴耕地轮作休耕制度试点任务重的区域开展技术指导服务，提高轮作休耕技术入户到位率。二是开展技术推广。以绿色高质高效行动为抓手，在东北、黄淮海、西南地区等耕地轮作休耕制度试点区域，建立大豆、油料等作物绿色高质高效示范基地，应用高产优质新品种，推广增产增效新技术，推进农机农艺融合、良种良法配套，扩大轮作休耕技术示范效应。三是开展技术研发。以国家现代农业产业技术体系为平台，支持轮作休耕改种作物方面的专家，重点围绕遗传改良、栽培与土肥、病虫草害防控、机械化、加工、产业经济等领域开展联合攻关，突破耕地轮作休耕制度试点技术瓶颈。下一步，我部将聚焦耕地轮作休耕制度试点的科技需求，进一步加强技术研发和推广应用，为耕地轮作休耕制度试点提供强有力的科技支撑。

感谢您对农业农村工作的关心，希望今后继续对我部工作予以支持。
