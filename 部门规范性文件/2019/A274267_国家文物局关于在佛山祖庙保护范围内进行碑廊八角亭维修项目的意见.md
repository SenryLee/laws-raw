# 国家文物局关于在佛山祖庙保护范围内进行碑廊八角亭维修项目的意见

文物保函〔2019〕62号

广东省文物局：

你局《关于在全国重点文物保护单位佛山祖庙保护范围内八角亭维修工程的请示》（粤文物审〔2018〕148号）收悉。经研究，我局原则同意在佛山祖庙保护范围内实施碑廊八角亭维修项目。

一、所报方案应符合广东省人民政府关于佛山祖庙保护范围的管理规定和相关控制要求。

二、进一步规范、细化设计方案及图纸，现状测绘图、设计图、总平面图应准确反映工程与文物本体的关系，补充工程实施过程中对文物本体的保护措施。

三、进一步完善文物影响评估报告，准确、客观评估该项目对佛山祖庙文物安全和景观环境的影响。

四、请你局指导有关单位，根据上述意见对方案进行修改完善后，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

五、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月16日
