# 国家卫生健康委关于颁发委预算单位第二期经济管理后备领军人才证书的通知

国卫财务函〔2019〕251号

委预算单位：

按照《卫生计生经济管理队伍建设方案（2014—2020年）》（国卫办财务函〔2014〕882号）要求，我委顺利组织完成委预算单位第二期经济管理后备领军人才培养工作。经考核合格，雷勇恒等45名同志（名单详见附件）准予毕业，“委预算单位经济管理后备领军人才”证书将由上海国家会计学院统一寄出。

各单位要坚持培养与使用相结合的原则，积极培养和锻炼委预算单位经济管理后备领军人才。后备领军人才要立足本职岗位，紧扣卫生健康事业改革发展目标任务，充分发挥辐射带动作用，为助力实施健康中国战略作出应有贡献。

附件：委预算单位第二期经济管理后备领军人才毕业人员名单

国家卫生健康委

2019年11月7日
