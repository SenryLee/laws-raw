# 教育部办公厅关于继续开展全国青少年校园足球师资国家级专项培训的通知

教体艺厅函〔2019〕5号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

为深入贯彻落实全国教育大会精神，按照《教育部等6部门关于加快发展青少年校园足球的实施意见》（教体艺〔2015〕6号）要求，经研究，教育部决定继续开展全国青少年校园足球师资国家级专项培训工作。

培训项目包括骨干教师培训和管理干部（校长）培训两种类型，培训总体目标、培训内容与方式、培训要求等参照《教育部办公厅关于组织开展全国青少年校园足球师资国家级专项培训的通知》（教体艺厅函〔2018〕36号）执行。名额分配见附件，其中，阿拉尔市第21期和北屯市第22期骨干教师培训由教育部统一安排送培上门。回执表（见附件4）请于2019年2月28日前以传真和电子文档格式提交至中国教育科学研究院，联系人及联系方式：教育部体育卫生与艺术教育司 刘诗尧 010-66096474；中国教育科学研究院 周誉、李旭龙010-62003868，62003389（传真），13520715627，17685571116；邮箱：zhouy@nies.net.cn。报到等有关事宜由中国教育科学研究院另行通知。

附件：1.全国青少年校园足球师资国家级专项培训骨干教师培训名额分配表

2.全国青少年校园足球师资国家级专项培训管理干部（校长）培训名额分配表

3.全国青少年校园足球师资国家级专项培训参训学员网上报名须知

4.全国青少年校园足球师资国家级专项培训推荐名单（回执表）

教育部办公厅
