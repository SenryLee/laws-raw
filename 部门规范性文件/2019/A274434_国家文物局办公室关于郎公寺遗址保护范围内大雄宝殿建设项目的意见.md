# 国家文物局办公室关于郎公寺遗址保护范围内大雄宝殿建设项目的意见

办保函〔2019〕114号

山东省文物局：

你局《关于在郎公寺遗址保护范围内建设大雄宝殿的请示》（鲁文发〔2019〕4号）收悉。经研究，我局不同意在郎公寺遗址保护范围内进行大雄宝殿建设项目。

一、对所报项目提出以下意见：

（一）加强考古资料的梳理和历史文献研究，明确郎公寺遗址的历史沿革、规划布局、建筑形制等，厘清遗址保存和利用现状，进一步论证项目实施的必要性。

（二）进一步明确新建建筑与郎公寺遗址的位置关系，充分评估新建大雄宝殿、广场等对文物的影响，综合考虑郎公寺遗址与大宗山环境保护的需要，另行选址建设。

二、请你局督促地方人民政府统筹考虑文物保护、宗教事务、文化旅游、城乡建设的关系，合理安排建设项目，确保文物安全。

三、请你局尽快核查2014年郎公寺遗址保护范围内未批先建问题，研提处理意见，并将有关情况和处理结果报送我局。

专此函复。

国家文物局办公室

2019年2月19日
