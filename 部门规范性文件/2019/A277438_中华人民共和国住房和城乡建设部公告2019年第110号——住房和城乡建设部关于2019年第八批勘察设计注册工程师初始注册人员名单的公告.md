# 中华人民共和国住房和城乡建设部公告2019年第110号——住房和城乡建设部关于2019年第八批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第110号

## 住房和城乡建设部关于2019年第八批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，李光强等51名申请注册土木工程师（岩土）初始注册人员、张智乐等33名申请一级注册结构工程师初始注册人员、张英杰等65名申请注册公用设备工程师初始注册人员、魏星等21名申请注册电气工程师初始注册人员、刘斌等6名申请注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予李光强等51名注册土木工程师（岩土）初始注册人员名单

2.准予张智乐等33名一级注册结构工程师初始注册人员名单

3.准予张英杰等65名注册公用设备工程师初始注册人员名单

4.准予魏星等21名注册电气工程师初始注册人员名单

5.准予刘斌等6名注册化工工程师初始注册人员名单

住房和城乡建设部

2019年5月14日
