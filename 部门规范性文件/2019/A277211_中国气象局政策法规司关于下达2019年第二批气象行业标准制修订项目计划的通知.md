# 中国气象局政策法规司关于下达2019年第二批气象行业标准制修订项目计划的通知

## 法规司关于下达2019年第二批气象行业标准制修订项目计划的通知

气法函〔2019〕25号

北京、天津、河北、上海、江苏、安徽、山东、河南、福建、陕西省（市）气象局，气象中心、信息中心、卫星中心、探测中心：

为推动气象事业高质量发展，结合气象信息化、气象观测质量管理体系建设等实际工作需求，将《气象数据元　卫星气象》等46项标准项目纳入2019年第二批气象行业标准制修订计划（见附件），现下达给你们，请按照相关要求认真组织实施。

附件： 2019年第二批气象行业标准制修订项目计划

中国气象局政策法规司

2019年4月22日
