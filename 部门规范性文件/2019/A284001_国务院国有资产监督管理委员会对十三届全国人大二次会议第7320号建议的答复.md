# 国务院国有资产监督管理委员会对十三届全国人大二次会议第7320号建议的答复

## 对十三届全国人大二次会议第7320号建议的答复

“中国首饰玉器百花奖”（以下简称“百花奖”），是由原国家经委、原国家轻工业部于1981年批准设立的，是中国工艺美术界的最高奖项。2010年经原监察部等九部门组成的联席会议批准，是目前中央国家机关评比达标保留项目之一，每两年开展一届。“百花奖”活动开展多年来，主办方中国轻工珠宝首饰中心一直积极组织各省、自治区、直辖市开展“百花奖”评选及相关活动，坚决贯彻落实习近平总书记关于传承弘扬中华文化系列重要指示批示精神，在调动和激发从业者创作积极性、培育和弘扬精益求精的工匠精神方面作出了积极贡献。为确保评选的客观性、公正性和权威性，“百花奖”主办单位按照国家评比达标表彰管理有关规定，承担全部费用，不以任何形式向参评单位和个人收取费用。中国轻工珠宝首饰中心开展“百花奖”评选无资金来源，对进一步推广和有效开展“百花奖”评选活动，充分发挥其在非物质文化遗产保护方面的积极作用带来了一定困难。

近年来，财政部、工业和信息化部、文化和旅游部等部门在非物质文化遗产保护方面做了大量工作。财政部通过国家非物质文化遗产专项资金，积极支持实施传统工艺类国家级非物质文化遗产代表性项目、国家级代表性传承人记录等。仅2019年，中央财政通过文化和旅游部部门预算和转移支付安排资金7.8亿元，支持实施854个国家级非遗代表性项目，支持2559位国家级代表性传承人进行记录，开展非物质文化遗产传承人群研培174期，补助21个国家级文化生态保护区建设，推动开展非物质文化遗产相关宣传活动。上述支持内容包括已经列入国家级非物质文化遗产名录的金银细工制作技艺、玉雕等传统工艺类代表性项目和代表性传承人。工业和信息化部推动出台了一系列政策措施，包括印发《关于工艺美术行业发展的指导意见》（工信部消费〔2014〕192号），组织举办工艺美术行业培训班等，也在传统工艺特色产业集群培育上作了积极引导，推动“中国玉都—广东省揭阳市”“中国黄金珠宝首饰之乡—福建省莆田市北高镇”“中国琥珀之城—云南省腾冲市”等珠宝首饰行业特色产业集群朝着规模化、聚集化、品牌化不断发展。文化和旅游部、工业和信息化部公布了国家传统工艺振兴目录，重点选取了一批具备一定传承基础和发展前景，传承人群较多，有助于发挥示范带动作用，形成国家或地方品牌的传统工艺项目。现行国家政策对传统工艺类国家级非物质文化遗产代表性项目、国家级代表性传承人已有专项资金支持，在工艺美术行业职业技能培训和支持“特色区域”品牌方面也做了许多工作，且卓有成效。

您提出的“请有关部门能针对‘百花奖’相关活动，给予长期资金支持，培育国家品牌的可持续发展”的建议对“百花奖”评选活动的开展很有帮助。但由中央财政给予长期资金支持存在以下问题：一是缺乏政策依据；二是没有资金来源，且“百花奖”自2010年以来，一直没有纳入部门预算，由主办单位自行解决经费问题；三是容易引起其他有评比达标表彰项目活动又没有纳入部门预算单位的攀比。因此，不宜由财政部或工业和信息化部安排专门资金并长期支持。当前，我们支持中国轻工珠宝首饰中心立足行业特点，通过多种途径、多种方式筹措资金，妥善解决资金短缺问题，在评选过程中践行公开、公平、公正理念，进一步提升“百花奖”评选权威性和公信力，使之成为工艺美术行业的荣誉标杆，并通过现有渠道完善对非物质文化遗产的保护工作。

下一步，财政部将根据您所提建议，继续通过现有渠道，研究进一步完善支持机制，推动做好传统工艺等非物质文化遗产保护的各项工作。工业和信息化部将与相关部门，在充分论证的情况下，对财政资金支持开展相关评选工作给予统筹考虑，并认真贯彻落实有关产业政策的要求，加强政策协调和信息沟通，推动珠宝首饰行业高质量发展。我们也将积极配合有关部门工作，共同推动珠宝首饰行业实现高质量发展。

衷心感谢您对“百花奖”项目的关心、理解和支持，欢迎继续提出宝贵意见和建议。
