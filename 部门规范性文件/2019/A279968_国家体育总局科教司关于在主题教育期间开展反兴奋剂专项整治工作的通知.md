# 国家体育总局科教司关于在主题教育期间开展反兴奋剂专项整治工作的通知

## 体育总局科教司关于在主题教育期间开展反兴奋剂专项整治工作的通知

体科字〔2019〕113号

各运动项目管理中心、有关直属单位、中国足球协会、中国篮球协会、各改革试点协会：

按照总局《关于在主题教育期间集中开展突出问题专项整治的通知》要求，经研究决定开展反兴奋剂专项整治工作，有关事宜通知如下：

一、工作任务

（一）对2019年反兴奋剂专项治理工作自查过程中发现的问题和总局内部巡视指出的问题，进行认真梳理，列出问题清单，制定整改措施。（附件1）

（二）全面细致梳理和排查国家队备战参赛2020东京奥运会和2022北京冬奥会反兴奋剂工作风险点，列出详细清单，制定具体防控措施。（附件2）

二、工作要求

（一）各单位要以习近平总书记对体育工作和反兴奋剂工作的重要指示、批示精神为遵循，牢固树立“拿干净金牌”理念，结合“不忘初心、牢记使命”主题教育活动，全面做好反兴奋剂工作，确保中国代表团干干净净参加2020东京奥运会和2022北京冬奥会。

（二）各单位要高度重视反兴奋剂专项整治工作，认真研究项目特点和反兴奋剂工作规律，总结经验教训，全面细致梳理和排查2020东京奥运会和2022北京冬奥会备战参赛反兴奋剂工作风险点，列出详细清单，制定针对性强、行之有效的防控措施，切实抓好风险防控，确保各项防控措施落实到位、落实到人。

（三）各单位专项整治工作报告和排查的问题、风险点及措施，经领导班子集体研究后，专题报送总局。各单位请将有关材料于8月15日17：00前，加盖公章报送至总局科教司，电子版发至838482572@qq.com。

联系人：程谦，冯菲

联系电话：87182705，87182332

2.反兴奋剂工作风险点清单及防控措施表
