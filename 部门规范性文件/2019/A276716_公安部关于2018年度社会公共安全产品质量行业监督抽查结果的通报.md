# 公安部关于2018年度社会公共安全产品质量行业监督抽查结果的通报

公通字〔2019〕19号

各省、自治区、直辖市公安厅、局，新疆生产建设兵团公安局：

为深入实施“质量强国”战略，提升公安装备器材和社会公共安全产品质量，更好地为公安业务工作和平安中国建设服务，经商国家市场监督管理总局同意，依据相关国家标准和公共安全行业标准，公安部于2018年10月至2019年1月对部分社会公共安全产品质量实施了行业监督抽查（以下简称“行抽”）。现将主要情况通报如下：

一、抽检产品类别及承检机构

本次共抽查4大类5种产品，其中，微剂量X射线安全检查设备由公安部安全与警用电子产品质量检测中心承检，警用防刺服由公安部特种警用装备质量监督检验中心承检，Web应用防火墙和网络隔离产品由公安部计算机信息系统安全产品质量监督检验中心承检，道路交通信号控制机由公安部交通安全产品质量监督检测中心承检。

二、抽检依据和结果

微剂量X射线安全检查设备计划抽检15家企业的15个型号，实际抽检11家企业的11个型号，上海英迈吉东影图像设备有限公司等4家企业因以销定产无库存等原因，未能按计划进行抽检。依据国家标准《微剂量X射线安全检查设备 第1部分 通用技术要求》（GB 15208.1-2005），经检验，10家企业的10个型号产品合格，合格率为90.9%。深圳市安尔通科技有限公司K6550C型微剂量X射线安全检查设备不合格，原因为混合物分辨性能不达标。

警用防刺服计划抽检29家企业的40个型号，实际抽检20家企业25个型号，北京安龙科技集团有限公司等9家企业因以销定产无库存等原因，未能按计划进行抽检。依据公共安全行业标准《警用防刺服》（GA 68-2008），经检验，17家企业的21个型号产品合格，4家企业的4个型号产品不合格，合格率为84%。河北安泰富源安全设备制造有限公司FCF-F-AT01型警用防刺服不合格，原因为高温防刺性能不达标；江苏金安警用器材制造有限公司FCF-H-JSJ02型警用防刺服不合格，原因为高温、低温防刺穿透性能不达标；靖江市国润警用器材制造有限公司FCF-J-GR08型警用防刺服不合格，原因为密封性能不达标；广东守门神科技集团有限公司FCF-J-SMS01型警用防刺服不合格，原因为高温、低温防刺穿透性能不达标。

Web应用防火墙计划抽检23家企业的23个型号，实际抽检18家企业的18个型号，四川长虹佳华信息产品有限责任公司等5家企业因无库存或抽样基数不足等原因，未能按计划进行抽检。依据公共安全行业标准《信息安全技术 web应用防火墙技术要求》（GA/T 1140-2014），经检验，产品全部合格，合格率为100%。

网络隔离产品计划抽检21家企业的21个型号，实际抽检15家企业的15个型号，北京中科网威信息技术有限公司等6家企业因以销定产无库存等原因，未能按计划进行抽检。依据国家标准《信息安全技术 网络和终端隔离产品安全技术要求》（GB/T 20279-2015），经检验，产品全部合格，合格率为100%。

道路交通信号控制机计划抽检22家企业的22个型号，实际抽检17家企业的17个型号，天津易华录信息技术有限公司等5家企业因以销定产无库存等原因，未能按计划进行抽检。依据国家标准《道路交通信号控制机》（GB 25280-2016），经检验，16家企业的16个型号产品合格，合格率为93.8%。山东星志智能交通科技有限公司XHJ-CW-GA-XZ2100型道路交通信号控制机不合格，原因为故障监控功能不达标。

各地接此通报后，要高度重视，认真落实有关要求。一是要及时将通报转发至本省各级公安机关、本地省级市场监督管理部门以及被抽查企业。二是要求各级公安机关不得采购、装备、使用本次行抽结果不合格的产品（不含经整改后复查合格的产品），慎重采购未抽到样品企业生产的产品。三是各地公安科信部门要严格按照《社会公共安全产品质量行业监督抽查项目管理暂行办法》（公科质〔2001〕45号）的有关规定，积极协调相关业务主管部门，认真督促产品质量不合格的企业于本通报印发之日起4个月内完成整改工作，并将整改情况上报部科技信息化局。
