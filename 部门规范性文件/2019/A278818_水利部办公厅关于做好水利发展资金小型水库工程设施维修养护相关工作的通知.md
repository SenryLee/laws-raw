# 水利部办公厅关于做好水利发展资金小型水库工程设施维修养护相关工作的通知

办运管〔2019〕139号

有关省、自治区、直辖市水利（水务）厅（局），新疆生产建设兵团水利局：

为做好水利发展资金小型水库工程设施维修养护相关工作，现就有关要求通知如下。

一、水利发展资金小型水库工程设施维修养护经费（以下简称中央补助资金）使用范围为：中西部地区及东部中央苏区、深度贫困地区的公益性小型水库。各地要建立中央补助资金与小型水库管护主体和责任、人员和经费，安全鉴定等管理制度落实情况挂钩激励机制；要发挥中央补助资金“四两拨千斤”的撬动作用，积极争取加大省、市、县各级资金投入，做好小型水库维修养护，确保小型水库运行安全。

二、各地要切实做好小型水库维修养护组织实施，抓紧制订完善本地区小型水库维修养护定额标准、巡查管护人员补助标准。省级水行政主管部门要加强组织领导，加强与财政部门的沟通协调，精心组织制定年度实施方案，加快完善维修养护资金安排使用管理制度，逐级落实责任；要指导市县尽快确定具体项目、编制市县年度实施计划并组织实施，市县年度计划应明确具体工程、实施进度和预期成果等；要组织市县做好项目前期工作，加快项目实施和预算执行进度，确保资金安全和实施成效。涉及连片特困地区县和国家扶贫开发工作重点县（以下简称国家级贫困县）的按照贫困县涉农资金统筹整合相关规定执行。

三、水利部将建立小型水库维修养护实施进度报告制度，及时总结工作进度和资金使用情况。省级水行政主管部门要在中央补助资金指标下达后3个月内，将年度投资计划和实施计划，按照附件1格式，报运行管理司；在每季度末，将投资计划完成进度，按照附件2格式，报运行管理司；于次年1月底前，将年度资金使用情况，按照附件3格式，以邮件形式（电子版），报送运行管理司。国家级贫困县报送时间按照有关规定执行。
