# 国家体育总局科教司关于在运动员保送项目中增加部分冰雪项目有关事宜的通知

## 体育总局科教司关于在运动员保送项目中增加部分冰雪项目有关事宜的通知

体科字〔2019〕192号

各省、自治区、直辖市、新疆生产建设兵团体育局，中央军委训练管理部军事体育训练中心，各运动项目管理中心，各项目协会，有关高等院校：

为进一步贯彻落实国务院关于运动员奖励政策，拓宽冰雪项目运动员的升学渠道，为2022年北京冬奥会备战工作提供有力保障。2020年优秀运动员保送增加越野滑雪、跳台滑雪、高山滑雪、北欧两项、钢架雪车和雪橇6个冬奥会项目，具体赛事条件见附件。保送办理程序按照《体育总局科教司关于做好2020年高校保送录取运动员有关事宜的通知》（体科字〔2019〕137号）执行。

附件：2020年新增优秀运动员保送项目及赛事表

体育总局科教司

2019年12月9日
