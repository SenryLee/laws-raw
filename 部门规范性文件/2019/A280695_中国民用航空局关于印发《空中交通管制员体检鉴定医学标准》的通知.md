# 中国民用航空局关于印发《空中交通管制员体检鉴定医学标准》的通知

## 关于印发《空中交通管制员体检鉴定医学标准》的通知

民航规〔2019〕42号

民航各地区管理局，各机场公司，民航局空管局：

为落实“放管服”要求，进一步提升空中交通管制员体检鉴定工作质量和服务水平，民航局审阅通过了《空中交通管制员体检鉴定医学标准》。现予以印发，请遵照执行。

中国民用航空局

2019年8月12日

附件：空中交通管制员体检鉴定医学标准
