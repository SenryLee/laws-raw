# 国家移民管理局对十三届全国人大第二次会议第3535号建议的答复

谭平川代表：

您提出的关于在重庆市航空口岸实行144小时过境免签政策的建议收悉。经商重庆市、四川省人民政府，现答复如下：

公安部、国家移民管理局高度重视并积极支持地方经济发展和对外交流合作，不断为便利人员往来提供政策支持。为配合地方发展需要，结合当地国际化水平、国际航班航线情况及外国人管理工作基础，经报国务院批准，全国22个城市相关口岸陆续实施72小时或144小时过境免签政策，为外国人短期来华旅游和临时商务访问提供了便利，为促进当地经济社会发展发挥了积极作用。其中，重庆江北国际机场自2013年12月30日起实施外国人72小时过境免签政策，免签停留区域为重庆市。

今年4月，国办批转重庆市人民政府向国务院呈报的《关于在重庆口岸对部分外国人实施144小时过境免签政策的请示》，我局正在研究办理中。您在建议中对重庆发展战略、出入境便利措施的需求等进行了深入阐述和客观分析，对我局研究延长重庆过境免签停留期具有参考作用。重庆江北国际机场共有84条国际航线，据统计，2018年，该口岸入境外国人 37万人次，其中利用72小时过境免签政策外国人仅为128人次。在重庆、成都之间联动实施144小时外国人过境免签政策将进一步评估，我局将根据重庆开放发展的实际，积极研究提出跟进服务保障的意见。

感谢您对移民管理局工作的关心和支持。
