# 农业农村部办公厅关于编纂《中国饲料工业年鉴（2019）》有关事项的通知

农办牧〔2019〕26号

《中国饲料工业年鉴》是反映我国饲料工业发展全貌的资料性工具书，是记载和宣传饲料行业法律法规、政策措施、发展成就、科研成果和经验做法的载体。为做好《中国饲料工业年鉴（2019）》（以下简称《年鉴》）编纂工作，现将有关事项通知如下。

一、主要内容

（一）综合篇：2018年各地饲料行业大事记、重要文件、中央及省市领导关于饲料工业的题词讲话等文字和图片；国际饲料行业重要友人交流访问的文字和图片。

（二）地方篇：包括2018年各地饲料工业发展概况、组织机构、主要工作内容、存在问题和下一步工作思路，年度重要活动图片2—4张。

（三）企业篇：介绍各地优秀企业经营和发展的典型经验，每省（区、市）推荐企业2—3个，计划单列市推荐企业1—2个；介绍各地重点企业概况，每省推荐3—5个，计划单列市推荐企业2—3个；每个企业图片2张。

二、撰写要求

（一）选取资料应具有现实和历史价值，使用当年数据，文字准确全面，可完整反映本年度历史事实的全貌和全过程。重点可包括当年工作、改革措施或其他突出成果、需要连续记载的资料、当年新事物和新问题、其他重要的信息资料等。

（二）选取的优秀和重点饲料企业涵盖饲料生产企业、饲料添加剂企业、单一饲料企业及饲料机械设备企业，应具备诚信守法、质量安全意识、产量产值权重高、对“三农”贡献大等特点。

（三）地方篇稿件字数控制在3000字以内。企业篇中优秀企业稿件字数控制在3000字以内，重点企业稿件字数控制在500字以内。

（四）图片需提供原始照片，不小于3MB；长宽等比（最长边）不低于2000像素；分辨率不低于300像素每英寸；图片需注明时间、地点、活动主题、重要人物需位置标识等文字说明。

（五）稿件需注明撰稿人姓名、电话、邮政编码、通讯地址、电子邮箱。

三、工作组织

请各地明确人员分工，落实编纂责任，认真组织《年鉴》相关材料编写和报送工作，严把稿件政治关、事实关、文字关和保密关。

四、有关要求

稿件材料请于2019年4月20日前发送至《年鉴》编辑办公室，同时报送编委会委员和联络员各1名，并注明单位名称、通讯地址、邮政编码、电话、电子邮件等联络信息。
