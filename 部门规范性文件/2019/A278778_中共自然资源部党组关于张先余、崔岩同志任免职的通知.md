# 中共自然资源部党组关于张先余、崔岩同志任免职的通知

自然资党任〔2019〕74号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中央军委后勤保障部军事设施建设局，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

部党组2019年5月13日研究决定：

张先余任国家自然资源督察武汉局局长（试用期一年），免去其国家自然资源督察上海局副局长职务；

崔岩任国家自然资源督察广州局巡视员，免去其国家自然资源督察武汉局局长职务。

中共自然资源部党组

2019年6月11日
