# 国家文物局办公室关于大运河浙东运河萧山段保护区划内通城大道道路工程建设项目的意见

办保函〔2019〕717号

浙江省文物局：

你局《关于要求在全国重点文物保护单位大运河之浙东运河萧山段保护区划内实施通城大道道路工程的请示》（浙文物发〔2019〕149号）收悉。经研究，我局暂不同意在大运河浙东运河萧山段保护区划内实施通城大道道路工程建设项目。

一、对所报方案提出以下修改完善意见：

（一）应组织专业考古机构对拟建项目相关区域进行先期考古调查勘探和必要的考古发掘，明确该区域是否存在大运河文物遗存。

（二）应结合保护区划图纸，进一步明确拟建项目与大运河浙东运河萧山段保护范围、建设控制地带的空间位置关系，并就拟建项目与保护区划管理规定的符合性作出说明。

（三）应补充遗产影响评估报告，补充项目设计效果图、景观视线分析图等相关图纸，详细说明拟建项目对大运河环境风貌的影响。

二、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年8月13日
