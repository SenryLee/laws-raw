# 国家发展改革委办公厅关于陕西榆神矿区小保当二号煤矿项目核准内容变更的复函

发改办能源〔2019〕144号

陕西省发展改革委：

报来《关于申请榆神矿区小保当二号煤矿项目核准变更的请示》（陕发改煤电〔2018〕1467号）及相关材料收悉。经研究，现就有关事项函复如下。

一、为加快优质产能释放，优化煤炭产业结构，同意小保当二号煤矿项目核准内容变更，矿井建设规模1300万吨/年，一次建成投产。

二、建设方案调整后，项目总投资为99.55亿元（不含矿业权费用）。其中，资本金30.99亿元，占总投资的31.13%，由项目单位以企业自有资金出资；资本金以外的68.56亿元，申请银行贷款。

三、项目按照1300万吨/年进行煤矿产能登记公告，不得批小建大、超能力生产。

四、除作上述调整外，其余事项仍按我委发改能源〔2017〕2089号文核准的内容执行。

国家发展改革委办公厅

2019年1月25日
