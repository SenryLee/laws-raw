# 民政部办公厅关于印发《民政部2019年立法工作计划》的通知

民办函〔2019〕87号

各司（局），各直属单位：

《民政部2019年立法工作计划》已经2019年第11次部长办公会议审议通过，现印发你们，请认真贯彻执行。

民政部办公厅

2019年7月3日

## 民政部2019年立法工作计划

2019年民政部立法工作的总体要求是：以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届二中、三中全会精神，认真贯彻习近平总书记全面依法治国新理念新思想新战略，贯彻习近平总书记关于民政工作的重要指示和第十四次全国民政会议精神，紧紧围绕民政部中心工作和重点任务，充分发挥法治引领和推动作用，以优异成绩庆祝中华人民共和国成立70周年。具体安排如下：

一、法律（2件）

1.《中华人民共和国社会救助法》（制定）。（草案送审稿拟报送国务院，责任单位：社会救助司、政策法规司）

2.《中华人民共和国城市居民委员会组织法》（修订）。（修订草案送审稿拟报送国务院，责任单位：基层政权建设和社区治理司、政策法规司）

二、行政法规（6件）

1.《社会组织登记管理条例》（制定）。（拟提请国务院审议，责任单位：政策法规司、社会组织管理局）

2.《街道办事处工作条例》（制定）。（需要抓紧研究论证的项目，责任单位：基层政权建设和社区治理司）

3.《地名管理条例》（修订）。（修订草案送审稿拟报送国务院审议，责任单位：区划地名司、政策法规司）

4.《殡葬管理条例》（修订）。（继续配合司法部审查，责任单位：政策法规司、社会事务司）

5.《城市生活无着的流浪乞讨人员救助管理办法》（修订）。（需要抓紧研究论证的项目，责任单位：社会事务司）

6.《中国公民收养子女登记办法》（修订）。（继续配合司法部审查，责任单位：政策法规司、儿童福利司）

三、部门规章（3件）

1.《行政区划管理条例实施办法》（制定）。（力争年内完成，责任单位：区划地名司、政策法规司）

2.《养老机构管理办法》（修订）。（力争年内完成，责任单位：养老服务司、政策法规司）

3.《志愿服务记录与证明出具办法》（制定）。（力争年内完成，责任单位：政策法规司、慈善事业促进和社会工作司）

各单位要把执行立法工作计划作为一项重要任务，加强组织领导，严格执行《民政部立法工作规定》（民政部令第51号），按照任务、时间、组织、责任四落实的要求，切实履职尽责，确保按时完成各项立法任务。

未列入计划的项目，如确有社会高度关注、实践急需、条件相对成熟的项目，可以不受计划限制，经研究论证并按程序报部长同意后，追加列入计划。

本计划由政策法规司协调实施。
