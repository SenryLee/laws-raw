# 国家体育总局办公厅关于印发《国家体育总局贯彻落实行政执法公示制度执法全过程记录制度重大执法决定法制审核制度实施方案》的通知

## 体育总局办公厅关于印发《国家体育总局贯彻落实行政执法公示制度执法全过程记录制度重大执法决定法制审核制度实施方案》的通知

各司、局：

2018年12月，国务院办公厅印发了《关于全面推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度的指导意见》，聚焦行政执法的源头、过程、结果等关键环节，对“三项制度”作出了具体部署，提出了明确要求，对促进严格规范公正文明执法具有基础性、整体性、突破性作用。按照3月19日司法部规范行政执法工作会议要求，现将总局全面推行“三项制度”的实施方案印发，请各部门予以贯彻落实。

特此通知。

附件：

1.国家体育总局贯彻落实行政执法公示制度执法全过程记录制度重大执法决定法制审核制度实施方案

2.国家体育总局重大行政执法决定法制审核目录

办公厅

2019年3月26日
