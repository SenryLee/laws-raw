# 国家信访局对十三届全国人大二次会议第4605号建议的答复

您提出的关于全面推进“阳光信访”，打造“一站式”群众信访自助平台的建议收悉，现答复如下：

党的十八届三中全会决定指出：改革信访工作制度，实行网上受理信访制度，健全及时就地解决群众合理诉求机制。国家信访局党组认真落实党中央决策部署，不断创新和深化网上受理信访制度，持续畅通拓宽网上信访渠道，健全完善“阳光信访”新模式，推动及时就地快捷高效解决问题，较好实现了让数据多跑路、群众少跑腿，网上信访已经成为群众信访“主渠道”。您关于网上信访工作的建议，对于我们正在推进实施的工作措施很有借鉴意义。

一、关于畅通拓宽网上信访主渠道

您提出的“充分运用现代网络信息化手段大力开展网上信访，发挥网上信访主渠道作用”等建议，是我们坚持深化推进的一项重要工作。近年来，全国信访系统全力打造网上信访主渠道，方便群众服务群众优势不断显现。一是网上诉求表达新平台基本

覆盖。2015年1月1日国家信访信息系统建成运行以来，纵向联通国家、省、市、县、乡五级，横向覆盖有权处理信访问题的责任部门，实现全国“一网通”。依托信访信息系统，搭建起集投诉、办理、查询、跟踪、监督、评价于一体的全国网上信访综合应用工作平台，群众足不出户随时随地就可方便快捷反映诉求。二是网上信访向“掌上”延伸更加便捷。国家信访局2016年7月1日和9月1日相继开通手机信访、微信信访，目前移动端信访占国家信访局网上信访量七成以上。除个别省份外，各省都开通了移动端信访，进一步为群众网上信访提供方便。三是网上信访服务不断优化。各地结合实际提升服务群众水平，有的在县乡设立网上信访自助服务设施，有效减轻群众信访成本；有的把分散的网上信访“小窗口”整合到一个网上投诉大厅，减少群众重复投诉、部门重复交转；有的围绕优化界面、简化操作改善网上信访体验，为群众提供更加便捷人文的服务。

二、关于打造“阳光信访”新模式

您提出的“将信访事项办理过程、方式和处理结果‘晒’在阳光下，督促及时就地快捷高效解决群众诉求”等建议，是我们打造“阳光信访”新模式的重要内容。近年来，全国信访系统着力打造公开透明的工作机制，形成了“信访网上投、事项网上办、结果网上评、问题网上督、形势网上判”的阳光信访新模式，将信访事项办理过程和结果在网上公开，实现了业务全覆盖、信息全录入、数据全生成、办理全公开，群众可查询、可跟踪、可督办、可评价，充分发挥公开透明、快捷高效、便于监督优势，以公开促公正、用透明赢信任，提升了网上信访公信力。一是办理情况向群众全过程公开。依托国家信访信息系统，将信访事项办理流程、方式和结果在网上公开，并通过手机短信等形式进行推送，群众可实时查询，做到件件有回音，提高工作透明度。二是办理过程受群众多渠道监督。国家信访局通过门户网站及时向社会公开实地督查情况，发布典型案例等，把信访工作情况“晒”在阳光下。各地也采取公开听证、民主评议、媒体曝光、网站公开等形式向公众公开信访工作情况，接受群众监督。三是办理结果让群众全方位评价。国家信访局出台并完善信访事项群众满意度评价办法，依托国家信访信息系统把评价权交给群众，群众可就信访事项的办理情况和处理结果等，分别对信访部门和责任单位作出评价，让群众做信访工作的“监督员”和“裁判员”，倒逼信访事项得到及时有效解决。特别是今年国家信访局积极推进让群众“最多访一次”，进一步加强与群众互动沟通，加大电话回复和回访力度，及时回应群众关切，推动解决群众诉求。

您提出的“探索‘信访效能阳光考核’机制”等建议，也是我们积极推进的一项工作。目前，信访事项的及时受理率、按期办结率、群众满意率，全部由国家信访信息系统自动生成，国家信访局定期对各地“三率”情况进行考核，主要目的是推动各地及时回应、妥善解决群众诉求。各省也不断完善考核评分体系，有的地方定期公开职能部门网上信访事项“三率”考核情况，主动接受群众监督，推动提升解决问题的质量效率。

三、关于推广应用“一站式”信访自助平台

您提出的“推广应用集信访投诉、查询、监督、评价等功能为一体的自助信访服务终端”等建议，在一些省份已经得到了推进实施，如，黑龙江省自主研发“信访通”网上信访自助终端机、江西省在网上信访自助服务专区安装“信访灵通”自助服务系统、湖北省在县乡设立网上信访自助服务设施等，为群众提供更加便捷高效的网上信访服务，得到了群众的认可。对这些经验做法，我们在网上信访工作推进会议上进行了推广，并通过国家信访局微信公众号进行系列宣传推介，为各地开展工作树立了鲜明导向。今后，我们将继续鼓励支持地方创新工作模式，并及时总结推广。

下一步，我局将充分吸收您提出的意见建议，进一步推动网上信访工作高质量发展，持续畅通拓宽网上信访主渠道，不断完善“阳光信访”新模式，推动及时就地快捷高效解决群众诉求，树立网上信访好用管用导向，真正把网上信访平台打造成“网上群众之家”。

感谢您对信访工作的关心支持，希望您继续对我们的工作多提宝贵意见。
