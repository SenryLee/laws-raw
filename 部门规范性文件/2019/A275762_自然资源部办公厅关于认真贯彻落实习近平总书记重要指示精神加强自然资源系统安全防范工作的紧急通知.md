# 自然资源部办公厅关于认真贯彻落实习近平总书记重要指示精神加强自然资源系统安全防范工作的紧急通知

自然资电发〔2019〕12号

各省、自治区、直辖市自然资源主管部门，中国地质调查局及部其他直属单位，各派出机构：

最近，各地发生多起重特大生产全事故，给人民群众生命财产安全造成严重损失。特别是3月21日江苏响水天嘉宜化工有限公司发生特别重大爆炸事故，已造成78人死亡、117人重伤，损失十分惨重、影响十分恶劣、教训十分深刻。3月21日，习近平总书记作出重要指示，要求各地和有关部门深刻吸取教训，加强安全隐患排查，严格落实安全生产责任制，坚决防范重特大事故发生，确保人民群众生命和财产安全。李克强总理等中央领导同志作出重要批示，要求各地深刻吸取教训，进一步排查并消除危化品等重点行业安全隐患，夯实各环节责任，坚决防范重特大事故发生。为认真贯彻落实习近平总书记重要指示和李克强总理等中央领导同志重要批示要求，进一步加强当前自然资源领域安全防范工作，根据中央领导同志指示批示要求和国务院安委会部署要求，现就有关事项通知如下。

一、勇于担当负责，切实担负起保安全、护稳定的政治责任

自然资源系统各级领导干部要把思想和行动统一到习近平总书记重要指示精神上来，充分认识当前安全生产形势的严峻复杂性和抓好安全生产工作的极端重要性，始终坚持底线思维，切实增强忧患意识，决不能有丝毫松懈、半点马虎，力戒形式主义、官僚主义，有效防范和坚决杜绝自然资源系统内部出现重特大生产安全事故。要严格落实《党政领导干部安全生产责任制规定》，按照“党政同责、一岗双责、齐抓共管、失职追责”和“三个必须”的要求，层层压紧压实各部门各单位安全生产责任，切实担负起“促一方发展、保一方平安”的政治责任，下大决心、下大力气防范化解安全风险，解决实实在在的问题，切实把自然资源系统安全生产工作推向新水平，以有效防范和坚决遏制重特大事故的实际成效践行“四个意识”、坚决做到“两个维护”。

二、深刻吸取教训，全面开展危险化学品安全隐患排查整治

要深刻认识到危险化学品安全已成为影响经济高质量发展和社会稳定的重要因素，深刻汲取事故教训，切实加强危险化学品安全管理和隐患排查治理。中国地质调查局及部其他直属单位要结合本单位实际，深入开展安全隐患排查整治。特别要针对春季火灾事故规律特点，加强火灾风险隐患排查治理，严格整治“三合一”“多合一”场所和违规使用易燃装修装饰材料、消防设施缺失损坏、电动车违规充电、疏散通道堵塞、电气线路老化破损等问题，有效管控火灾风险，及时消除火灾隐患，严防火灾事故发生。

储存使用危险化学品单位要对今年年初开展的危险化学品专项检查实施“回头看”，对尚未完成整改的安全隐患，要作为重点倒排时间、严格落实整改措施，确保完成整改任务。要组织专人对本单位危爆化学品情况进行专题研判，进行系统排查和全面评估，提升整体工作水平；开展固体危险废物安全专项治理，集中排查收集贮存的数量、方式、场所和处置方法等环节，建立使用台账，形成管理闭环，确保所有废弃物得到安全处理；涉及硝化物的单位，要对使用、储存、生产等环节进行全面排查摸底，不漏掉一个盲区、不放过一个环节，对存在的问题要限期整改到位。

对独立办公单位，重点开展水、电、气、暖，各重点部位，消防、安防系统，各类应急预案制定、演练等方面的安全检查，及时发现问题，堵塞管理漏洞。

地方各级自然资源主管部门按照地方人民政府的统一部署和职责分工，积极配合开展危险化学品安全管理有关工作，支持有关部门开展化工园区风险评估和园区内外安全距离排查等工作，及时消除重大隐患，严防风险外溢。

三、切实做好土地、矿产、海洋及地勘和测绘行业安全监管，坚决杜绝“带病”操作

对于油气钻井、海上作业、空中调查、大型设备、野外项目，要依据国标、行标及单位安全规范，逐一排查各类隐患，坚决杜绝“带病”操作，操作人员严格落实安全使用规范，防止发生野外、空中、海上安全事故。

做好地质勘查行业安全管理。加强野外和实验室易燃易爆危险化学品的安全管理，落实有毒有害样品及试验物质、易燃易爆危险化学品的专项保管和人员安全使用防护，深入开展安全隐患排查整治；加强野外和实验室安全生产综合管理，强化人身安全防护措施，增强安全培训教育，关注气象、地形等环境情况合理安排作业，重视交通安全管理，严防事故发生。

做好海洋观测、监测和科学调查的安全管理。加强海上和野外作业的安全管理和风险防范，及时关注气象、海况等预警报信息，严格防范人员伤亡和船舶碰撞、失火及倾覆等重大事故发生。

强化测绘作业安全管理。加强在高原、荒漠、海上等困难区域和城市人员车辆密集区域测绘作业管理与安全防范。野外测绘单位（队伍）要根据气象条件、灾害性天气发展趋势等合理安排工作任务，防止在暴雨、大风等恶劣气候条件下作业，严防出现人员伤亡和重大财产损失。加强内业规模化生产中的用电、消防管理，确保电路设施符合国家安全标准，各类消防器材齐全有效。加强测绘队伍交通安全管理，避免发生交通事故。加强安全基础保障能力建设。加大安全投入力度，提高安全科技支撑水平和事故应对处置能力。充分利用北斗终端等设备对外业车辆、测绘小组进行远程监控，提升安全监管水平。根据作业特点，加强生产交通、通讯、后勤保障、急救和劳动保护等装备的配备，改善外业生产条件，保障测绘职工的人身财产安全。

确保“三调”工作安全开展。针对第三次全国国土调查的各个工作环节，包括高山密林、沼泽湿地、沙漠戈壁等区域外业中的调查人员安全，以及冰冻雨雪等恶劣天气下的人员和交通安全，内业生产中防火、防电等环节开展安全隐患排查。对各类隐患提出应对解决措施，做到早发现、早排除。

地方各级自然资源主管部门要认真落实行业安全管理职责，结合实际组织开展地质勘查、测绘行业安全隐患排查整治，严防发生事故。

四、积极配合开展其他重点行业领域安全治理

地方各级自然资源主管部门要在地方人民政府的统一领导下，积极配合有关部门开展其他重点行业领域安全治理，督促企业全面排查管控安全风险、及时治理安全隐患。要配合有关部门突出抓好煤矿和非煤矿山安全工作，切实推进不符合安全生产条件矿山整顿关闭工作，加大对矿山违法行为的查处力度，对卫片检查、群众举报、媒体反映等渠道发现的矿山违法案件及时立案查处，防范违法勘查开采造成的安全生产责任事故。继续配合公安部门开展打击整治枪支爆炸物品违法犯罪专项行动，严防违法违规勘查开采矿产资源引发安全事故。

五、加强应急准备，及时有效应对事故及灾害

地方各级自然资源主管部门要强化部门联动，加强灾害性天气监测预警，切实抓好地质灾害监测预警、海洋预警预报和风险提示。严格落实防灾避险措施，集中开展地质灾害风险隐患排查治理，督促配合相关部门切实落实地质灾害防治责任，强化人类工程活动管理，严防群死群伤事件。要配合有关部门进一步健全完善安全生产应急预案，进一步强化值班值守和应急联动，确保一旦发生事故险情能协助有关部门及时科学有效应对和处置。

中国地质调查局及部其他直属单位、各派出机构要制订完善应急预案，针对发现的安全风险隐患，采取切实可行的防范应急措施，做好必要充分准备，落实救援队伍、装备、物资等应急资源，强化应急演练；严格执行领导干部带班、关键岗位24小时值班制度和事故信息报告制度；建立安全工作联络员制度，确保关键时间快速连动响应、高效处置；加强对用火用电用气、消防、交通等安全知识和逃生自救等常识宣传，加强全员安全培训，进一步增强干部职工安全意识，提高管控风险和避险减灾技能，有效应对初起险情，避免人员伤亡。

自然资源部办公厅
