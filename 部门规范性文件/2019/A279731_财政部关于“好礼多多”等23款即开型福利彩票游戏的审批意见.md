# 财政部关于“好礼多多”等23款即开型福利彩票游戏的审批意见

财综〔2019〕24号

中国福利彩票发行管理中心：

你中心报来《关于申报“好礼多多”等23款即开型福利彩票新游戏的请示》（中彩发字〔2019〕88号）收悉。为促进彩票市场健康发展，根据《彩票管理条例》、《彩票管理条例实施细则》和《彩票发行销售管理办法》（财综〔2018〕67号）等相关规定，同意你中心印制发行“好礼多多”等23款即开型福利彩票游戏，具体游戏规则见附件。现就有关事项通知如下：

一、“好礼多多”等23款即开型福利彩票游戏按其销售总额的65%、15%和20%分别计提彩票奖金、彩票发行费和彩票公益金。

二、“好礼多多”等23款即开型福利彩票游戏上市销售前，你中心应及时向社会发布公告，并在公告中注明财政部批准的文件名称、文号、上市销售日期以及《“好礼多多”等23款即开型福利彩票游戏规则》等。

三、即开型福利彩票游戏的兑奖工作应当严格按现行有关规定进行。其中，彩票中奖奖金应当以人民币现金或者现金支票形式一次性兑付，彩票中奖者应当自开奖之日起60个自然日内，持中奖彩票到指定的地点兑奖。

附件：“好礼多多”等23款即开型福利彩票游戏规则

财政部

2019年7月4日
