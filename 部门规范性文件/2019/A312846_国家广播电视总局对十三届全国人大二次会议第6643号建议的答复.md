# 国家广播电视总局对十三届全国人大二次会议第6643号建议的答复

## 对十三届全国人大二次会议第6643号建议的答复

广电建议〔2019〕11号

耿福能代表：

您提出的《关于严格审查动画片，保护儿童健康成长的建议》收悉，现答复如下：

我们赞同您的建议。国家广播电视总局一贯高度重视动画片的审查工作，保护未成年人身心健康，为未成年人健康成长营造良好的环境。

一是在法律层面对动画片的制作播出进行规范。与动画片相关的法律法规有《广播电视管理条例》、《电视剧内容管理规定》（含动画片）、《未成年人节目管理规定》等，这些法律法规在节目规范、传播规范、监督管理和法律责任等方面对包括动画片在内的未成年人节目的制作播出予以严格规定，为保护未成年人的身心健康提供了法律保障。如《未成年人节目管理规定》第八条规定了培育和弘扬社会主义核心价值观，弘扬中华优秀传统文化、革命文化和社会主义先进文化等九项内容；第九条规定了不得含有渲染暴力、血腥、恐怖、教唆犯罪或者传授犯罪方法等十六项内容。

二是持续推进动画片推优工作。国家广播电视总局自2005年以来，持续推进国产电视动画片的年度、季度评优工作。如2018年度评出了《可爱的中国》《丝路传奇大海图》《京剧猫之乘风破浪》等20部优秀作品，这些作品坚持价值引领，融入中国元素，弘扬中华优秀传统文化，具有较高艺术水准和制作水平。为发挥优秀国产电视动画片的示范带动作用，总局向全国各级电视台特别是上星综合频道、动画少儿频道、地面少儿频道予以推荐，优先安排播出。

下一步，国家广播电视总局将进一步加强动画片管理和创作生产引导，扩大优秀动画片的传播力、影响力、感染力，为未成年人健康成长营造良好环境。

感谢您对广播电视工作的关心和支持！

国家广播电视总局

2019年7月29日
