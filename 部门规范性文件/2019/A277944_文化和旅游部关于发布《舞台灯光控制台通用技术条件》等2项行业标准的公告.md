# 文化和旅游部关于发布《舞台灯光控制台通用技术条件》等2项行业标准的公告

文化行业标准《舞台灯光控制台通用技术条件》（WH/T 86-2019）、旅游行业标准《旅游规划设计单位等级划分与评定条件》（LB/T 076-2019），已经文化和旅游部批准，现予以公布。上述2项行业标准自2019年10月1日起实施。

特此公告。

文化和旅游部

2019年6月4日
