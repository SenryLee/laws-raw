# 国家林业和草原局公告2019年第3号——国家沙化土地封禁保护区名单

## 国家林业和草原局公告

2019年第3号

根据《国家沙化土地封禁保护区管理办法》有关规定，现将甘肃省金塔县石梁子国家沙化土地封禁保护区等10个国家沙化土地封禁保护区（见附件）予以公布。

特此公告。

国家林业和草原局
