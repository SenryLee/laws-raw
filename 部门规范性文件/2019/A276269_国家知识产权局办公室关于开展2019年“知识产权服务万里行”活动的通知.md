# 国家知识产权局办公室关于开展2019年“知识产权服务万里行”活动的通知

国知办函运字〔2019〕315号

各省、自治区、直辖市知识产权局（管理部门），计划单列市、副省级城市知识产权局（知识产权管理部门），新疆生产建设兵团知识产权局；局机关各部门，专利局各部门，商标局，局其他直属单位、各社会团体，各有关单位：

为优化知识产权服务，提升知识产权综合能力，推进经济高质量发展，今年，我局将在创新融合的基础上，组织“知识产权服务万里行”活动，现将有关事项通知如下：

一、总体要求

2019年“知识产权服务万里行”活动要以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党中央、国务院关于知识产权工作的新部署新要求，坚持新发展理念，推进深化知识产权领域“放管服”改革，促进提升知识产权综合能力，加快营造规范化、市场化、国际化的营商环境，支撑经济高质量发展和产业转型升级。

活动要增强协调性，聚焦地方和创新主体需求，释放改革效能，充分发挥专利、商标、原产地地理标志的组合效应；要强化实效性，关注企业创新短板，传授知识产权实务技能，促进高价值知识产权的创造与运用；要突出服务性，引导知识产权服务资源对接企业、对接创新主体，创新知识产权服务机制，提升知识产权服务能力。

二、主要内容

（一）知识产权政策宣讲和意识培养模块。

1.宏观形势和政策宣讲。围绕知识产权工作面临的国内外形势、产业政策发展变化、知识产权法律法规修订、知识产权管理改革创新进行宣讲，帮助创新主体、市场主体了解与知识产权有关的新形势、新规则、新政策、新机制。

2.知识产权文化传播。向有关各界系统介绍专利、商标、原产地地理标志专业知识，宣传知识产权事业发展成就；以生动有趣的方式，讲解知识产权创造、保护、运用等方面的事例和案例，引导创新主体、市场主体加深对知识产权的认知，营造尊重知识产权的文化氛围。

（二）知识产权服务供需对接模块。

1.知识产权审查员走企业、进高校活动。组织专利、商标审查员深入企业、高校，解答专利申请、商标注册相关问题，提高创新主体、市场主体知识产权事务处理能力，促进提升知识产权质量。

2. 巡回审查和审理。组织相关领域发明专利审查员开展发明专利巡回审查和业务辅导活动，组织复审部门审查员开展专利巡回审理。

3.知识产权服务公益咨询和供需对接。组织知识产权服务机构负责人、资深代理师、咨询师深入活动现场、产业园区和重点企业，开展知识产权公益咨询，与创新主体、市场主体对接洽谈。

（三）知识产权实操技能传授模块。

1.知识产权实务培训。根据地方和企业需求，开展知识产权许可、金融服务、产业知识产权联盟建设和高价值专利培育等运营知识培训，以及知识产权分析评议、区域布局、专利导航技能培训。围绕企业、高校、科研院所知识产权管理规范贯彻等主题，进行实务操作技能培训。围绕精准扶贫，开展地理标志申请、运用促进实务培训。

2.产业专利态势发布解读。结合地方重点产业需求，选取有关项目，发布、解读产业知识产权竞争态势信息，帮助产业界深入了解产业知识产权发展趋势、技术发展脉络，预警和防范知识产权风险。

（四）知识产权服务业研讨模块。

1.知识产权服务机构交流研讨。知识产权服务品牌机构进行经验分享，围绕新形势下知识产权服务业发展等主题，与当地知识产权服务机构交流研讨。

2.专利代理相关法规与政策解读。对修订后的《专利代理条例》《专利代理管理办法》及专利代理监管政策措施进行解读，提升专利代理机构、专利代理师依法依规执业的能力和水平。

三、活动安排

（一）站点安排。

1.广东站。

时 间：4月（知识产权宣传周期间）

地 点：广州市、深圳市

主协调：专利审查协作广东中心、知识产权出版社有限责任公司

承 办：广州市开发区管委会，深圳市市场监督管理局、深圳市南山区人民政府

2.四川站。

时 间：6月

地 点：成都市、绵阳市

主协调：国家知识产权运营公共服务平台

承 办：四川省知识产权服务促进中心

3.黑龙江站。

时 间：8月或9月

地 点：齐齐哈尔市

主协调：中国专利技术开发公司

承 办：黑龙江省知识产权局

4.湖北站。

时 间：10月或11月

地 点：武汉东湖高新区

主协调：专利审查协作湖北中心

承 办：湖北省知识产权局

（二）职责分工。

1.牵头部门。运用促进司负责年度活动总体方案的设计和统筹指导。

2.主协调单位。审协广东中心、出版社、运营平台、开发公司、审协湖北中心分别负责各站活动具体方案设计和组织实施，对接承办单位和其他参与部门。

3.参与部门与单位。电学部、光电部、新型部、外观部、复审和无效审理部、信息中心等部门和单位视地方产业需求，参与相应站点活动，开展专项业务活动的具体组织协调。

4.承办地方。四川省、湖北省、黑龙江省有关部门，深圳市市场监督管理局、深圳市南山区人民政府、广州市开发区管委会负责配合主协调部门，做好活动的组织保障。

5.有关媒体。负责宣传方案的策划实施，活动资料的设计编印等。

四、工作保障

（一）强化责任机制。各相关部门单位要根据任务分工，确保责任到人，按时间节点，确保高水平完成任务。牵头部门要发挥好统筹谋划作用，建立工作推进机制，整体推进各项工作任务落实。主协调部门应充分发挥组织协调作用，加强对接协调，做好相应站点活动的协同实施。各地方以及局内参与部门应认真落实工作任务，加强沟通、强化配合，共同提升活动的水平和质量。活动结束时，将对各有关部门单位任务完成情况进行总结分析，肯定成绩、查找不足，为今后相关任务安排与委托提供依据。

（二）细化活动方案。应着眼粤港澳大湾区发展、东北老工业基地振兴等国家战略，结合当地实际需求，合理、精准安排各站主题和具体内容。主协调部门牵头，地方及局内各参与部门参与，及时认真细化活动方案，积极谋划提升活动的精准度和影响力。

（三）合理配置资源。各主协调部门应根据活动细化方案，做好资源梳理和调配，各参与部门做好业务资源支持，各地方根据活动细化方案提供配套资金支持，落实条件保障。

（四）强化宣传引导。各地方、各部门单位应密切跟踪活动组织开展情况，充分利用各类媒体加强宣传引导，及时总结推广成熟经验和先进事例，扩大活动影响，提升活动成效。
