# 国家药品监督管理局关于药物临床试验机构资格认定检查的公告（第3号）

## 关于药物临床试验机构资格认定检查的公告（第3号）

2019年第19号

根据《中华人民共和国药品管理法》《药物临床试验机构资格认定办法（试行）》，经资料审查和现场检查，认定大同市第三人民医院等4家医疗机构具有药物临床试验机构资格，发给《药物临床试验机构资格认定证书》。

特此公告。

附件：具备药物临床试验机构资格的医疗机构及认定专业

国家药监局

2019年3月12日
