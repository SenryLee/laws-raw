# 工业和信息化部关于印发《重点新材料首批次应用示范指导目录（2019年版）》的通告

工信部原〔2019〕254号

为进一步做好重点新材料首批次应用保险补偿试点工作，现发布《重点新材料首批次应用示范指导目录（2019年版）》，自2020年1月1日起施行。《重点新材料首批次应用示范指导目录（2018年版）》（工信部原〔2018〕262号）同时废止。

特此通告。
