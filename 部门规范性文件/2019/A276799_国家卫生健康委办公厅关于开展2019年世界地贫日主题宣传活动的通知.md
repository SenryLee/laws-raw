# 国家卫生健康委办公厅关于开展2019年世界地贫日主题宣传活动的通知

国卫办妇幼函〔2019〕411号

福建省、江西省、湖南省、广东省、广西壮族自治区、海南省、重庆市、四川省、贵州省、云南省卫生健康委：

2019年5月8日是第26个“世界地贫日”。为进一步加强地中海贫血（以下简称地贫）防治宣传教育，营造全社会关注和支持地贫防控工作的良好氛围，我委定于2019年5月8日在福建等10个省（区、市）开展“世界地贫日”主题宣传活动，并在广东同期举办现场主题宣传活动。现将有关事宜通知如下：

一、活动主题

今年的活动主题是：“防治地贫，认知先行”，旨在倡导全社会行动起来，聚焦地贫防治，广泛开展宣传倡导和健康教育，让群众在获取知识、普遍认知的基础上，积极转变观念、增强意识，身体力行支持参与地贫防治工作，实现知行合一、共建共享良好局面。

二、有关要求

（一）各地要围绕主题，通过知识普及、政策宣传、专家义诊、技术培训、患儿救助等多种形式，广泛进行内容丰富、群众喜闻乐见的宣传教育。组织开展优生科普知识进校园、进课堂活动，推动优生宣传教育关口前移。积极统筹院内院外两个阵地，开展线上线下、针对性强的宣传教育活动，营造地贫群防群控的良好氛围。

（二）我委组织编写了地贫防治宣传教育材料（见附件1、2，可从国家卫生健康委网站“妇幼健康司”栏目下载），拟定了相关宣传标语口号（见附件3），方便各地参考使用。各地可根据实际制作图文并茂、易于接受的宣传教育材料及文化产品，配合整体宣传活动的开展。

（三）请各省（区、市）于5月25日前将主题宣传活动总结及编印制作的地贫防治宣传教育材料报送我委妇幼司。
