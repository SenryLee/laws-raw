# 中共自然资源部党组关于吴海洋同志任职的通知

自然资党任〔2019〕54号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中央军委后勤保障部军事设施建设局，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

经中共中央组织部批准，吴海洋同志任自然资源部党组机要秘书，任职时间自2019年3月起算。

中共自然资源部党组

2019年3月29日
