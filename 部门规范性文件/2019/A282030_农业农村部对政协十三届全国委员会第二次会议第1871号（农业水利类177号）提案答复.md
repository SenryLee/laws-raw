# 农业农村部对政协十三届全国委员会第二次会议第1871号（农业水利类177号）提案答复

## 对政协十三届全国委员会第二次会议第1871号（农业水利类177号）提案答复

农办案〔2019〕174号

您提出的“关于实施乡村振兴战略，提升城乡一体化发展水平提案”收悉。经商科技部、住房城乡建设部，现答复如下。

一、关于强化规划支撑

实施乡村振兴战略，要坚持规划先行、有序推进。今年中央一号文件提出，强化乡村规划引领，把加强规划管理作为乡村振兴的基础性工作。一是出台乡村振兴战略规划。2018年，中共中央、国务院印发《乡村振兴战略规划（2018—2022年）》（以下简称《规划》），明确了今后五年的思路目标和重点任务，将村庄划分为集聚提升、城郊融合、特色保护、搬迁撤并四类村庄。各地结合本地实际，均已编制出台了实施乡村振兴战略地方规划，针对重点领域和关键环节，出台了一批专项规划、重大行动计划和具体实施方案。二是建立《规划》落实部门协调推进机制。为推动《规划》各项目标任务落实落地，发展改革委、农业农村部会同有关部门建立了《规划》实施协调推进机制，中央组织部、中央宣传部等27个部门参加。通过加强部门沟通协商和联合协作，增强了相关政策衔接和工作协调，推动《规划》各项任务落实落地。同时，积极推动各省成立相应机制，层层推动《规划》任务落实。三是加快推动村庄布局和村庄规划编制。今年初，中央农办、农业农村部、自然资源部等5部门联合印发《关于统筹推进村庄规划工作的意见》，明确提出要加快编制村庄布局规划和村庄规划，力争到2019年底，基本明确集聚提升类、城郊融合类、特色保护类等村庄分类；到2020年底，结合国土空间规划编制在县域层面基本完成村庄布局工作，有条件乡村可结合实际单独编制村庄规划，做到应编尽编。

下一步，我部将会同有关部门加快推进《规划》在村域层面落实落地，指导各地以县为单位，加快编制或修编县域村庄布局规划，分类明确集聚提升、城郊融合、特色保护、搬迁撤并四类村庄分类，引导村庄依规有序发展。

二、关于推进农业绿色发展

推进农业绿色发展是农业发展观的一场深刻革命。近年来，在实施乡村振兴战略中，相关部门不断推动农业绿色发展取得新进展。一是强化技术支撑。2018年，我部印发了《农业绿色发展技术导则（2018—2030年）》和《乡村振兴科技支撑行动实施方案》，调整科技创新方向与重点，部署前沿基础研究、关键核心攻关、长期性基础性工作；深化农业科研体制改革，完善创新联盟和科创中心的产学研融合机制，探索建立研究创新度、产业关联度、发展贡献度的科研评价导向；提升农业技术推广服务整体效能，组织集成示范小麦节水保优生产技术、蔬菜全程绿色高效生产技术、水稻机插秧同步侧深施肥技术等10项引领性技术，开展重大技术协同推广。二是推进绿色发展。推进农业投入品使用减量增效，果菜茶有机肥替代化肥试点扩大到150个县，主要农作物绿色防控覆盖率稳步提升，河北、黑龙江、新疆地下水超采治理力度进一步加大。抓好农业废弃物资源化利用，新增204个县整县推进畜禽粪污资源化利用，支持168个县整县推进秸秆综合利用。研究起草了《农膜管理办法》《关于加快推进农用地膜污染防治的意见》，建设100个农膜回收行动示范县。加强农业资源养护，耕地轮作休耕试点超过3000万亩，推进东北黑土地保护试点和耕地土壤污染管控与修复，启动长江水生生物保护区禁捕和黄河禁渔，清理取缔“三无”船舶9000余艘、违规渔具50余万张。启动40个农业绿色发展先行区建设。三是推动农村实用技术应用。科技部启动实施“绿色宜居村镇技术创新”重点专项，以农村人居环境整治为主线，统筹城乡发展，统筹生产生活生态，针对不同规模不同特点的村镇，以建设绿色宜居村镇为导向，重点突破乡村清洁、村镇规划、宜居住宅、绿色建材、清洁能源等方面关键技术，构建基础研究平台、智慧乡村平台、生态建设平台，大力培育农村环保产业、新能源产业、住宅产业、传统文化产业等发展新动能，推进厕所革命与乡村绿色技术银行建设，促进绿色宜居村镇建设与发展。

下一步，我们将会同相关部门，围绕转变农业发展方式，强化农业科技支撑，发展多种形式的农业适度规模经营，推进农业农村绿色发展，加快构建现代农业产业体系。

三、关于构建高素质农民队伍

我部高度重视高素质农民培育工作，将此作为推动现代农业发展、实现乡村振兴的基础性长期性工程加以推进，不断强化顶层设计，加大政策扶持力度。一是实施高素质农民培育工程。农业农村部办公厅、教育部办公厅印发《关于做好高职扩招培养高素质农民有关工作的通知》，启动“百万高素质农民学历提升行动计划”，用实用好入学免试文化课、单独编班定制培养、农学结合分段教学的优惠政策，鼓励更多农民通过这种创新性灵活学制的全日制学习形式，获取高等教育专科学历证书。二是加强高等农林教育。教育部等部门印发《关于推进高等农林教育综合改革的若干意见》，明确提出要进一步提升高等农林院校为农输送人才和服务能力，引导高校面向农林业生产一线以及现代农业和新农村建设需要，构建以大学为依托、农科教相结合的综合服务新模式，培养数以万计下得去、留得住、用得上、懂经营、善管理的实用技能型人才。印发《关于加强农科教结合实施卓越农林人才教育培养计划2.0的意见》，要求高校充分发挥人才智力优势，加强乡村振兴战略研究的智库建设，支持高校成立乡村振兴研究院，深入研究乡村振兴的重大理论和实践问题，为乡村振兴贡献智慧和方案。

下一步，我部将会同相关部门，认真落实中央要求，坚持农业农村优先发展，不断优化完善促进高素质农民成长发展的政策环境，加快构建高素质农民队伍。

四、关于改善农村人居环境

改善农村居住环境是广大农民最迫切的需求。近年来，我部会同中央有关部门，加快推进农村人居环境整治，持续改善居住环境。在农村人居环境整治方面，2018年，中共中央办公厅、国务院办公厅印发实施《农村人居环境整治三年行动方案》，明确了农村人居环境整治三年行动的指导思想、基本原则和重点任务，对不同类型地区分别提出行动目标。同时，通过多项政策不断加大资金支持力度。农村污水治理累计安排专项资金495亿元，农村改厕已明确中央财政专门安排资金，计划用5年左右的时间，通过以奖补方式支持和引导各地推动有条件的农村普及卫生厕所。2019年3月，发展改革委会同我部印发《关于报送农村人居环境整治专项2019年中央预算内投资建议计划的通知》（发改办农经〔2019〕332号），安排中央预算内投资支持中西部省份以县为单位开展农村人居环境基础设施建设，重点支持农村生活垃圾、生活污水、厕所粪污治理等重点任务，加快补齐农村人居环境设施短板。在加强历史文化名镇名村保护方面，住房城乡建设部于2012年和2014年先后公布了《历史文化名城名镇名村保护规划编制要求（试行）》和《历史文化名城名镇名村街区保护规划编制审批办法》，指导各地依法依规编制保护规划。同时，国家对历史特色突出、保护规划编制符合国家要求的镇村，予以专项资金补助。“十二五”以来，已累计下拨中央补助资金约9.7亿元，支持了一大批中国历史文化名镇名村的基础设施建设项目。截至目前，住房城乡建设部会同国家文物局先后公布了7批共计312个中国历史文化名镇和487个中国历史文化名村。在加强传统村落保护方面，2012年以来，住房城乡建设部会同相关部门启动传统村落保护工作，印发《关于切实加强中国传统村落保护的指导意见》等文件，建立了传统村落认定保护、发展、监督、警示等机制，保护和利用文化遗产，保持传统村落的完整性、真实性、延续性。截至目前，住房城乡建设部会同相关部门分四批将4153个具有保护价值的村落列入中国传统村落名录。

下一步，我部将会同有关部门加大不同地区指导工作力度，支持地方用好各项政策，多渠道筹集建设资金，加快农村人居环境整治基础设施建设步伐，不断提升农民群众的获得感和幸福感。

五、关于支持回乡创业

近年来，我部按照中央部署要求，大力实施乡村就业创业促进行动，吸引各类人才到农村创新创业。一是不断丰富乡村产业类型。实施休闲农业和乡村旅游精品工程，推介一批休闲农业和乡村旅游精品品牌，2018年休闲农业和乡村旅游接待游客30亿人次、营业收入超过8000亿元。大力发展农产品电子商务，农村网络销售额突破1.3万亿元，其中农产品网络销售额达3000亿元。创新发展乡村服务业，支持开展农资供应、代耕代种、统防统治、烘干收储等生产性服务业，农村生产性服务业营业收入超过2000亿元。二是注重平台建设。我部联合12个部门，搭建了1096家标准高、服务优、示范带动作用强的农村创新创业示范园区（基地），集成整合政策、资源和要素，为农村创新创业提供场所和高效便捷的服务。三是积极支持农村创新创业。认定农村创新创业园区和实训孵化基地1096个，制定并落实支持返乡下乡人员创新创业政策，吸引农民工、大中专毕业生、退役军人、科技人员等到乡村创新创业。截至2018年，各类返乡下乡创新创业人员累计达780万，“田秀才”“土专家”“乡创客”等本乡创新创业人员达3100多万。

下一步，我部将会同有关部门，继续实施乡村就业创业促进行动，加强主体培育和平台建设，为农村创新创业提供场所和高效便捷的服务，吸引各类人才到农村创新创业。

感谢您对推进乡村振兴战略实施工作的关心，希望继续对我部的工作给予支持。

农业农村部

2019年8月30日
