# 国家能源局2019年核电行业管理课题申报公告

根据核电行业管理工作需要，为服务核电安全高效发展，依据有关规定，拟开展2019年度核电行业管理课题申报工作。现将有关事项通知如下：

一、课题申报有关要求

（一）申报主体

中华人民共和国境内（港澳台除外）的大专院校、科研院所、企业、行业协会等经审查符合申报资格的单位。

（二）申报人资格

1、申报人应具有良好的商业信誉，具有圆满履行研究任务能力，在近5年内任何合同中不存在违约、诉讼等现象。

2、申报人应具备课题项目要求的相关资质、经验和工作业绩，并提供证明材料。

（三）课题工作基本要求

课题工作内容要对行业安全健康、可持续、高质量发展起到促进作用。课题经费主要由财政拨款资助，工作成果中形成的知识产权归国家能源局所有。课题工作内容不得侵犯任何第三方的知识产权和其他权力，符合国家有关保密规定和有关行业政策。

（四）申报时间和方式

1、申报截止时间：2019年7月16日（以邮戳和电子邮件日期为准），请选择可在7月16日前送达的邮递方式，晚到恕不受理。

2、申报方式：申报主体如实填写《国家能源局核电行业管理项目任务申报书》，提出课题工作内容、工作方法、工作进度安排、项目实施条件、项目绩效目标、经费预算及测算说明、主要参与人员情况等。

3、申报材料寄送：申请书一式三份加盖申报单位公章后，随同申报主体与申报人的相关资质证明材料复印件一份，在申报截止时间前邮寄至国家能源局（北京市西城区三里河南四巷1号），并将加盖公章的申报书扫描版发送电子邮件至hediansi@163.com，联系人：国家能源局核电司010-68555872，68555493。

二、课题工作内容及有关要求

详见附件，申报主体、申报材料不符合要求的将视为无效申报。

三、课题执行时间

（一）课题执行时间为2019年7月至2019年12月。

（二）我局将在7月底左右发布入选公告，请关注国家能源局门户网站。

四、其他事项

（一）申报材料寄出或发邮件后，可与联系人确认。

（二）关于本次课题申报工作其他未尽事宜，请关注国家能源局门户网站。
