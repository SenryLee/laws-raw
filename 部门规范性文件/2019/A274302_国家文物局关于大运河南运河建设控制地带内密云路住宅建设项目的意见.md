# 国家文物局关于大运河南运河建设控制地带内密云路住宅建设项目的意见

文物保函〔2019〕101号

天津市文物局：

你局《关于上报大运河南运河建设控制地带内实施密云路住宅建设项目的请示》（津文旅发〔2018〕19号）。经研究，我局原则同意在大运河南运河建设控制地带内实施密云路住宅建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步优化运河沿河景观设计，利用本地植被对高层住宅和配套公共建筑周边进行遮挡，弱化建筑体量感。

（二）建议进一步调整建筑总图布局，将高层建筑尽可能安排在远离运河的北侧区域，以优化运河和拟建项目之间的景观环境。

（三）补充考古勘探发现的16座清代墓葬的后续保护处置措施，同时完善遗产保护、监测措施和相关应急预案，避免施工过程对遗产及其环境造成损害。

（四）进一步规范和完善方案文本，应将世界文化遗产大运河保护管理相关文件作为设计评估依据，补充保护区划和建设控制地带管理规定；应明确说明每栋建筑的地上、地下建筑面积和建筑高度等经济技术指标等内容。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月25日
