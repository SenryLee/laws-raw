# 国家文物局办公室关于帽儿山墓地建设控制地带内长春伊通河石油经销公司拟建汽车加油加气站建设项目的意见

办保函〔2019〕267号

吉林省文物局：

你局《关于长春伊通河石油经销公司拟建汽车加油加气站项目涉及帽儿山墓地建设控制地带的请示》（吉文物发〔2019〕85号）收悉。经研究，我局不同意在帽儿山墓地建设控制地带内实施长春伊通河石油经销公司汽车加油加气站建设项目。

一、拟建项目区域紧邻遗址保护范围，经过考古工作已发现重要遗迹，建议项目另行选址。

二、请你局组织有关单位进一步明确该区域文物分布和保存现状，明确新发现遗迹与帽儿山墓地的关系和性质、年代、价值等，并尽快研提后续保护建议，确保文物安全。

专此函复。

国家文物局办公室

2019年4月8日
