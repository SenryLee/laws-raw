# 国家文物局关于朱悦燫墓保护规划的意见

文物保函〔2019〕227号

四川省文物局：

你局《关于报送〈朱悦燫墓保护规划〉的请示》（川文物〔2018〕14号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）进一步加强考古工作和历史文献研究，厘清朱悦燫墓墓园范围、布局、历史沿革等，明确墓葬选址与周边自然地理环境要素的关系。

（二）深化价值评估和现状评估，加强朱悦燫墓与明代藩王墓的对比研究，进一步总结、提炼文物价值。补充规划范围内现状评估内容，评估凤凰陵园对朱悦燫墓及其周边环境的影响。

（三）优化保护区划范围和边界，重视保护墓葬相关地理要素，协调规划范围内相关遗存与朱悦燫墓保护的关系，进一步细化建设控制地带管控要求。

（四）优化展示利用规划，统筹考虑朱悦燫墓展示利用与凤凰山公园开放运营的关系，协调参观流线，合理规划主入口、停车场和管理用房，加强地面遗迹展示设计，不宜原址展示出土文物。

（五）新建游览道路不应横穿朱悦燫陵园，慎重考虑西侧两处商业金融项目的文物影响，合理确定建设控制地带内的产业布局。

（六）细化考古工作规划，开展凤凰山区域的全面考古调查，明确朱悦燫墓墓道、陵园和其他相关墓葬等遗迹的分布和保存现状，为后续保护展示提供依据。

（七）完善管理规划，明确责权关系，做好文物保护工作与凤凰山公园管理之间的衔接；补充防洪防灾规划。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将朱悦燫墓保护规划报请四川省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好朱悦燫墓各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年3月1日
