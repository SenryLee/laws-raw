# 国家广播电视总局办公厅关于公布2018年度国产纪录片及创作人才扶持项目评选结果的通知

## 广电总局办公厅关于公布2018年度国产纪录片及创作人才扶持项目评选结果的通知

广电办发〔2019〕163号

各省、自治区、直辖市广播电视局，新疆生产建设兵团文化体育广电和旅游局，中央广播电视总台办公厅，电影频道节目中心，中央新影集团，中国农业电影电视中心，中国教育电视台，国务院国资委办公厅，中央军委政治工作部宣传局：

2018年，国产纪录片蓬勃发展，涌现出一批思想性、艺术性、观赏性相统一的精品力作，社会影响力、美誉度不断提升。为了进一步从制作、播出、产业、人才等多个环节加大对国产纪录片的扶持引导力度，发挥优秀作品、制作机构、播出机构和创作人才的引领示范作用，国家广播电视总局坚持客观公正、优中选优的原则，经评审委员会评审，并通过总局政府网站公示，最终确定12类79个优秀作品、人才、栏目和机构等获评2018年度国产纪录片及创作人才扶持项目，现予以公布。

评选结果可在国家广播电视总局政府网站（http://www.nrta.gov.cn/）公告公示区中查询，同时可在中国纪录片网（http://www.docuchina.cn/）平台上查询。

优秀国产纪录片扶持项目获评作品由总局安排，在中国纪录片网平台展播。中国纪录片网须按国家法律规定确保总局扶持项目版权不因展播受到侵犯。

总局以专项资金扶持鼓励获评2018年度国产纪录片及创作人才扶持项目。扶持资金由总局拨付至相关报送单位，由报送单位严格按照国家有关政策规定，分发至入选扶持项目的单位和个人。

请相关选送单位于2018年6月30日前将发票、收款单位、开户银行账号加盖公章后报送至总局宣传司。

特此通知。

附件：2018年度国产纪录片及创作人才扶持项目评选结果
