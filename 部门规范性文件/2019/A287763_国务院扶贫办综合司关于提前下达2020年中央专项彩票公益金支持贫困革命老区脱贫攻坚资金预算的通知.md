# 国务院扶贫办综合司关于提前下达2020年中央专项彩票公益金支持贫困革命老区脱贫攻坚资金预算的通知

国开办司发〔2019〕14号

有关省（自治区、直辖市）扶贫办（局）：

为改善贫困革命老区生产条件，促进贫困人口脱贫增收，2020年将继续安排中央专项彩票公益金支持贫困革命老区县实施扶贫项目。现将有关工作要求通知如下：

一、合理选择项目县

2020年中央专项彩票公益金要向贫困程度深、脱贫任务重的革命老区县倾斜。要加大力度支持“三区三州”内的革命老区县和仍未脱贫摘帽的深度贫困革命老区县，支持中西部深度贫困革命老区县，建档立卡贫困人口数量多、巩固脱贫成果任务重的革命老区县。各省确定项目县后尽快报国务院扶贫办备案。

二、及时下达资金

请各省根据财政部《关于提前下达2020年中央专项彩票公益金支持贫困革命老区脱贫攻坚资金预算的通知》（财农〔2019〕114号）和《2020年提前下达中央专项彩票公益金支持贫困革命老区脱贫攻坚资金分省情况表》（见附件）要求，及时将资金指标分解下达到项目县。

三、认真编制实施方案

按照《国务院办公厅关于支持贫困县开展统筹整合使用财政涉农资金试点的意见》（国办发〔2016〕22号）有关要求，请各项目县根据脱贫攻坚规划统筹安排使用中央专项彩票公益金，聚焦项目和区域集中支持，避免分散使用，以便社会宣传和绩效评估。项目县要认真编制项目实施方案，并报项目省（区、市）备案。

四、加强项目资金管理

我办继续委托中国扶贫发展中心承担彩票公益金扶贫项目管理工作。省级扶贫部门要加强对项目的监督和检查，并于每年1月15日前会同财政部门将上一年工作情况和资金使用情况等以正式文件形式分别报送国务院扶贫办和财政部，每年6月底前会同财政部门向社会公告上一年度项目资金分配使用情况。请在本通知下发后30个工作日内，将2020年中央专项彩票公益金分配情况报送国务院扶贫办和财政部备案。
