# 交通运输部办公厅关于河南省水运建设市场的检查意见

交办水函〔2019〕1231号

为加强全国水运建设市场监管工作，维护统一开放、竞争有序的市场秩序，推动水运高质量发展，按照《水运建设市场监督管理办法》（交通运输部令2016年第74号）要求以及《2019年交通运输部市场秩序与服务质量检查工作方案》（交办公路函〔2019〕547号）有关安排，部组织检查组对河南省水运建设市场监管情况以及沙河漯河至平顶山航运工程和周口港区港口中作业区二期码头工程（6个港池）两个项目建设情况进行了检查。经交通运输部同意，现将检查意见反馈如下：

一、省级交通运输主管部门市场监管情况

根据本次检查要求，检查组重点对省级交通运输主管部门履行水运建设市场监管职责、水运建设领域交通扶贫、农民工工资支付保障等专项工作开展情况进行抽查。总体来看，河南省交通运输主管部门较好地开展了水运建设市场监管工作，同时，积极做好水运建设领域交通扶贫工作，通过贫困地区重点水运建设项目带动沿江贫困地区社会经济发展，服务贫困地区群众出行。抽查中发现的主要问题如下：

（一）水运工程建设管理有待加强。省厅对水运工程项目建设管理重视不够，对《水运建设市场监督管理办法》《港口工程建设管理规定》等宣贯落实不够。

（二）基本建设程序管理不严格。未按照《港口工程建设管理规定》的要求履行初步设计审批职能；施工图设计第三方审查费用由建设单位承担；设计变更管理不规范；水运工程项目施工招标投标采用的固定标价随机抽取法不符合《中华人民共和国招标投标法》及其实施条例和有关文件要求。

（三）项目监督管理有待加强。对重点水运建设项目质量安全督促指导不够，对发现的问题特别是部分基本建设程序问题的跟踪整改不到位，对推动项目顺利实施缺少有效机制措施，部分项目工期拖延较多。

（四）信用评价工作不规范。未能做到评价范围全覆盖，个别重点水运建设项目无信用评价结果；信用档案不完善，信用评价依据材料缺失。

（五）专项治理工作开展力度不足。未落实农民工工资保证金差异化缴存、工资与工程款分账等管理制度；未制定清理拖欠民营企业中小企业欠款专项治理工作方案，未对各相关单位的自查结果进行抽查并建立台账。

二、项目检查情况

根据本次检查要求，检查组通过查阅工程档案资料、现场检查、与从业单位沟通问询等形式，重点对基建程序执行、招标投标、安全质量、合同履约、从业行为以及农民工工资发放等情况进行了检查，发现的主要问题如下：

（一）项目基本建设程序履行不规范。沙河漯河至平顶山航运工程未履行港口岸线审批、航道通航条件影响评价等手续；漯河、马湾船闸开工备案时间晚于工程实际开工时间。周口港区港口中作业区二期码头工程（6个港池）未履行港口岸线审批、施工图设计审批、质监登记等手续；实际开工时间早于初步设计批复时间。

（二）项目单位招标投标管理不规范。沙河漯河至平顶山航运工程中标结果异议处理不规范。周口港区港口中作业区二期码头工程（6个港池）招标投标的项目名称与工可、初设批复名称不一致，监理、检测招标存在未批先招行为。

（三）项目单位工程管理不到位。沙河漯河至平顶山航运工程项目单位管理人员配备不足，部分管理工作未形成闭环，现场安全、质量、进度管控弱。周口港区港口中作业区二期码头工程（6个港池）未对施工、监理单位开展平安工地考核评价工作，未报送年度信用评价结果。

（四）施工单位安全质量管控能力不足。两个项目的混凝土配合比设计不符合水运工程混凝土施工规范的要求。沙河漯河至平顶山航运工程施工单位江苏淮阴水利建设有限公司现场管理混乱，安全防护措施较差，原材料控制不严，混凝土、钢筋施工作业不规范，质量问题和安全隐患较多。周口市周口港区港口中作业区二期码头工程（6个港池）施工分包未履行审批手续，安全生产专项经费使用不规范，土方填筑未见检测报告。

（五）监理单位履职不到位。沙河漯河至平顶山航运工程监理单位对现场质量安全管理不到位，对施工重点环节把控不严。周口港区港口中作业区二期码头工程（6个港池）监理单位监理规划和监理实施细则针对性不强。

两个水运建设项目的市场检查意见详见附件1和附件2.

三、工作要求

请你厅认真研究检查发现的问题，抓紧组织整改，整改情况于2019年9月30日前报部，并举一反三，强化监管措施，进一步提高监管能力和服务水平。

（一）加强《水运建设市场监督管理办法》《港口工程建设管理规定》等规章制度的宣贯落实；依照上位法修改水运工程招标管理有关规定；加强对市级交通运输主管部门的工作督查和指导，全面提高河南省水运建设市场事中事后监管水平。

（二）加强建设项目规范化管理。按照《航道建设管理规定》《港口工程建设管理规定》等有关要求，依法依规做好初步设计审批、施工图审批等工作，加强重大设计变更管理；积极落实第三方设计咨询纳入财政预算保障。

（三）切实做好建设项目监督管理。合理制定年度监督检查计划，加强对检查发现问题的跟踪落实，形成检查工作闭环；采取有效措施推动重点水运建设项目顺利实施。

（四）认真开展信用评价工作。组织做好年度信用评价工作，确保评价项目全覆盖，提高从业主体诚信履约意识，加强信用评价档案管理。

（五）强化专项治理工作。按照部相关要求进一步做好清理拖欠民营企业中小企业欠款专项治理工作。切实落实农民工工资银行代发、分账管理等制度，做好农民工工资支付保障工作。

（六）高度重视水运建设管理。认真贯彻落实国家和交通运输部有关文件规定和工作部署，加强技术力量配置，提高履职能力，保障水运建设健康有序发展。

（七）加快推动实施《河南省交通运输脱贫专项方案》中沙颍河、淮河、唐白河等内河水运工程建设项目，积极推进民生水运工程建设，充分发挥其对贫困地区社会经济发展的支撑保障作用。

交通运输部办公厅

2019年8月26日
