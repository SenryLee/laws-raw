# 公开市场业务交易公告[2019]第183号——关于2019年9月18日人民银行以利率招标方式开展了300亿元逆回购操作的公告

## 公开市场业务交易公告

[2019]第183号

为对冲稅期高峰等因素的影响，2019年9月18日人民银行以利率招标方式开展了300亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 300亿元 | 2.55% |

中国人民银行公开市场业务操作室

二〇一九年九月十八日
