# 教育部办公厅关于成立提升高校自主创新能力专项工作领导小组的通知

教技厅函〔2019〕23号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局，有关部门（单位）教育司（局），部属各高等学校、部省合建各高等学校：

为贯彻落实习近平总书记关于提升自主创新能力的系列重要讲话精神，加强统筹领导，进一步提升高校关键领域高层次人才培养能力、强化关键核心技术集成攻关，加快提升高校自主创新能力，教育部决定成立提升高校自主创新能力专项工作领导小组（以下简称领导小组）。现将有关事项通知如下。

一、主要职责

审议提升高校自主创新能力工作的总体部署、重要规划，统筹研究重大政策和重要工作安排，协调解决重点难点问题，指导有关地方、高校开展工作。

三、工作机构

领导小组下设办公室，办公室设在教育部科学技术司。办公室主任由钟登华同志兼任，办公室副主任由科学技术司司长雷朝滋、财务司司长郭鹏、发展规划司司长刘昌亚兼任。
