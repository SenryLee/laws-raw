# 中华人民共和国工业和信息化部、住房和城乡建设部公告2019年第11号——符合《建筑垃圾资源化利用行业规范条件》企业名单（第二批）

## 中华人民共和国工业和信息化部　住房和城乡建设部公告

2019年第11号

根据《建筑垃圾资源化利用行业规范条件》《建筑垃圾资源化利用行业规范条件公告管理暂行办法》，经企业自愿申报、省级主管部门审核、专家评审、网上公示等程序，现将符合《建筑垃圾资源化利用行业规范条件》企业名单（第二批）予以公告。

附件：符合《建筑垃圾资源化利用行业规范条件》企业名单（第二批）

工业和信息化部

住房和城乡建设部

2019年2月27日
