# 中国登山协会关于2019年度全国登山户外运动俱乐部注册及等级评定工作的通知

## 关于2019年度全国登山户外运动俱乐部注册及等级评定工作的通知

各登山户外运动俱乐部、有关大专院校及相关从业机构：

2019年度第一次全国登山户外运动俱乐部注册及等级评定工作即将开始，现将本次注册工作的相关事宜通知如下：

一、随着我国山地户外运动的迅速发展，为了更好的适应项目发展需要，经征求相关部门和人员意见后，我协会对原管理办法进行了修订，现将《中国登山协会户外运动俱乐部管理办法（修订版）》进行发布。

二、本次注册及等级评定工作材料递交的时间为2019年7月10日至2019年7月31日。

三、请各俱乐部按照《中国登山协会户外运动俱乐部管理办法（修订版）》的具体要求提交注册和等级评定的相关材料，并于2019年7月31日前将登记表及其它申请材料，邮寄至中国登山协会户外部（北京市东城区体育馆路9号420室，邮编100763）。另外，请申请等级评定的俱乐部按照申请材料的要求准备PPT一份并将电子版发至shiyun1120@126.com。

三、中国登山协会将对各俱乐部提交的申请材料进行审核，并通知资料和手续齐备的单位参加本次注册及等级评定。
