# 国家文物局办公室关于隆昌石牌坊建设控制地带内白塔森林公园建设项目的意见

办保函〔2019〕86号

四川省文物局：

你局《关于隆昌石牌坊建设控制地带内建设白塔森林公园的请示》（川文物〔2018〕111号）收悉。经研究，我局暂不同意在隆昌石牌坊建设控制地带内进行白塔森林公园建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）所报项目涉及隆昌石牌坊的文物构成郭王氏功德坊，以及其附属文物云峰塔、古驿道、云峰关、摩崖石刻等保护修缮工作应编制文物保护勘察设计方案，另行报批，不得纳入所报建设方案中。不同意对摩崖造像进行恢复。

（二）补充《隆昌石牌坊文物保护规划》中保护区划、管理规定及保护措施的具体内容，明确建设项目在保护区划中的位置。

（三）加强对历史环境的整体保护，不宜添加过多具象的人造景观设施；尽可能压缩硬化地面的面积；如无确切复原依据，应改造续用“提名处”建筑及区域内部分较为协调的乡土建筑，保留各个时代有价值的历史遗存。

（四）制定文物防护措施和应急预案，确保文物安全。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年2月13日
