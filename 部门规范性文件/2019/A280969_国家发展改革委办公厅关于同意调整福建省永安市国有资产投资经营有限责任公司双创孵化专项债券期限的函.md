# 国家发展改革委办公厅关于同意调整福建省永安市国有资产投资经营有限责任公司双创孵化专项债券期限的函

发改办财金〔2019〕807号

福建省发展改革委：

报来《关于转请调整永安市国有资产投资经营有限责任公司双创孵化专项债券发行要素的请示》（闽发改营商〔2019〕400号）收悉。经研究，现函复如下。

一、2018年2月14日，我委以发改企业债券〔2018〕27号文件核准永安市国有资产投资经营有限责任公司发行不超过18亿元双创孵化专项债券，债券期限为7年，每年付息一次，附设提前还本条款，即自债券存续期第3年起，逐年分别按照债券发行总额20%的比例偿还债券本金。截至目前，本期债券已发行9亿元，剩余9亿元尚未发行。经研究，同意尚未发行的9亿元本期债券设置发行人调整票面利率选择权和投资者回售选择权，在债券存续期的第3年末发行人可选择在原债券票面年利率基础上上调或下调0-300个基点，投资者有权将持有的本期债券部分或全部回售给发行人。其余批复要素不变。

二、请你委督促永安市国有资产投资经营有限责任公司按照《公司法》《证券法》《企业债券管理条例》和有关规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

三、请你委督促永安市国有资产投资经营有限责任公司按要求及时做好信息披露及债券资金管理，按照核准的募集资金投向合规使用债券资金，认真落实偿债保障措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅

2019年7月19日
