# 国家文物局关于政协十三届全国委员会第二次会议第2519号（文化宣传类215号）提案答复的函

文物督函〔2019〕839号

张自成委员：

您提出的《关于利用遥感卫星技术等科技手段全面提升不可移动文物的监测保护水平的提案》收悉。现答复如下。

您的建议指出当前文物安全工作面临的严峻形势，提出充分运用遥感卫星技术等科技手段，推动文物安全保护与现代科技融合创新，提升文物监管能力，这与近些年国家文物局开展的相关工作相契合。为贯彻落实习近平总书记关于加强文物安全工作的重要指示批示精神，落实《中共中央办公厅 国务院办公厅关于加强文物保护利用改革的若干意见》《国务院办公厅关于进一步加强文物安全工作的实施意见》的部署和要求，针对基层文物安全监管和执法力量薄弱、地方政府文物保护主体责任履行不到位等突出问题，国家文物局主动作为，积极探索卫星遥感、无人机等技术在文物行政执法督察中的试点应用，切实提升不可移动文物的监测保护水平。根据您提出的有关建议，国家文物局将继续加强新技术在文物监测保护中的应用。

一、持续开展不可移动文物执法监测工作。自2017年起，国家文物局每年抽选5市70处全国重点文物保护单位及部分重点长城段落，利用卫星遥感、无人机开展执法监测，主动督办违法违规问题，取得明显成效。2017-2018年，对140处全国重点文物保护单位进行抽样监测，依法立案查处文物违法案件60起，责令整改118起。2019年，为进一步提升文物监管督察能力，在前期试点和工作实践的基础上，探索建立不可移动文物遥感监测数据管理系统，将遥感监测数据、现场核查资料和问题督察督办等内容进行网上管理，建立“天上看+网上管+地上查”的工作模式，提高工作效率，提升督察能力。

二、加大文物违法问题督察督办力度。国家文物局对遥感监测发现的违法问题逐一核查，直接督察督办，目前督办遥感发现的案件已占国家文物局每年督办案件的一半。同时，对重大文物违法案件进行现场督察，重点督办了河南省安阳市世界文化遗产殷墟保护范围内违法建设案、上海市全国重点文物保护单位兴圣教寺塔建设控制地带内违法建设案、重庆市全国重点文物保护单位八路军重庆办事处旧址重点保护区内违规建设案等。2018年12月，国家文物局印发《国家文物局文物督察约谈办法（试行）》，对严重违法、社会影响恶劣的案件，约谈地方政府负责人，适时向社会曝光。

三、督促地方依法加强文物保护基础工作。文物保护单位保护范围和建设控制地带（以下简称“两线范围”）划定等工作，是文物行政执法有效开展的重要基础工作，也是开展执法监测的前提。2019年，国家文物局将督促各地文物部门尽快完善文物保护基础工作，下大力气补齐工作短板。目前，海南省人民政府首次划定公布了205处省级及以上文物保护单位“两线范围”；上海市已完成10处全国重点文物保护单位和85处市级文物保护单位的“两线范围”划定工作，待由上海市人民政府审定后公布。
