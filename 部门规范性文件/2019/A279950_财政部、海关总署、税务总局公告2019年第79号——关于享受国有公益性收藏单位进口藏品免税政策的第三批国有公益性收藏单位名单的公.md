# 财政部、海关总署、税务总局公告2019年第79号——关于享受国有公益性收藏单位进口藏品免税政策的第三批国有公益性收藏单位名单的公告

## 财政部　海关总署　税务总局公告

2019年第79号

## 关于享受国有公益性收藏单位进口藏品免税政策的第三批国有公益性收藏单位名单的公告

根据《国有公益性收藏单位进口藏品免税暂行规定》（财政部 海关总署 国家税务总局公告2009年第2号）的规定，现将享受该项税收优惠政策的第三批国有公益性收藏单位名单予以公告。

本名单自公告之日起执行。

附件：第三批国有公益性收藏单位名单

财政部　海关总署　税务总局

2019年7月8日
