# 住房和城乡建设部工程质量安全监管司关于印送《建筑施工安全事故案例分析》的函

建质安函〔2019〕24号

各省、自治区住房和城乡建设厅，直辖市住房和城乡建设（管）委，新疆生产建设兵团住房和城乡建设局：

为充分发挥事故警示教育作用，切实加强建筑施工安全管理工作，有效防范和减少事故发生，我们组织编写了《建筑施工安全事故案例分析》。现印送给你们，供参考使用。
