# 国家文物局办公室关于颐和园探海灯杆更换项目意见的函

办保函〔2019〕184号

北京市文物局：

你局《关于颐和园探海灯杆修缮工程方案的请示》（京文物〔2019〕209号）收悉。经研究，我局对颐和园探海灯杆更换项目提出如下意见：

一、进一步论证灯杆表面油饰及装饰做法，补充灯杆上部直径尺寸，明确灯杆收分比例。

二、灯杆材质建议采用南方产老杉木，并做好灯杆的防腐处理。

三、在拆解夹杆石过程中完善对台基的现状勘察，探讨恢复台基的可行性。

四、可结合灯杆更换分析研究挂灯的样式、荷载、加挂方式等，探讨恢复挂灯的可行性。

专此函复。

国家文物局办公室

2019年3月12日
