# 交通运输部办公厅关于公布2018年度交通运输产品质量行业监督抽查复查结果的通知

交办科技函〔2019〕567号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

根据《交通运输产品质量行业监督抽查管理办法（试行）》（交科技发〔2012〕32号），交通运输部组织对2018年交通运输产品质量行业监督抽查中发现的不合格产品生产企业整改情况进行了复查，现将复查结果予以公布，并将有关事项通知如下：

一、各单位要及时将复查结果反馈给相关产品生产企业和工程建设、施工、监理等单位，督促有关企业和单位举一反三，进一步查找问题，完善企业内部质量管理控制体系，严格按照有关标准组织生产和原材料采购，切实维护产品质量安全，严把行业准入关。

二、各单位要强化质量意识，紧紧围绕建设交通强国，推动行业高质量发展的目标要求，加大路面标线涂料等重点产品质量监管力度，提升行业发展质量，有关工作推进中的问题和建议要及时反馈交通运输部。

联系人及方式：交通运输部科技司 赵晓辉，010-65292199。010-65292100（兼传真）

附件：1.交通运输产品（路面标线涂料）质量行业监督抽查复查结果汇总表

2.交通运输产品（公路波形梁钢护栏板）质量行业监督抽查复查结果汇总表

3.交通运输产品（公路波形梁钢护栏立柱）质量行业监督抽查复查结果汇总表

4.交通运输产品（公路波形梁钢护栏防阻块）质量行业监督抽查复查结果汇总表

5.交通运输产品（公路波形梁钢护栏拼接螺栓）质量行业监督抽查复查结果汇总表

6.交通运输产品（高密度聚乙烯硅芯塑料管）质量行业监督抽查复查结果汇总表

7.交通运输产品（玻璃钢管箱）质量行业监督抽查复查结果汇总表

8.交通运输产品（道路运输车辆北斗导航车载终端）质量行业监督复查结果汇总表
