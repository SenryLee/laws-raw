# 国家移民管理局关于对十三届全国人大二次会议第8015号建议的答复

周红波代表：

您提出的关于加快国际道路运输便利化发展的建议收悉，现答复如下：

我局积极支持推进国际道路运输便利化工作，主动服务国家“一带一路”倡议，立足边境地区经济社会发展需求，会同交通运输部、海关总署等部门认真落实国家便利运输工作总体部署，创新服务国际道路运输便利化各项措施，积极参与推进口岸联合检查与信息共享，不断完善查验配套设施，助推国际道路运输便利化发展。同时，加强对各地出入境边防检查机关的指导，要求严格执行跨境运输相关协定，在全国旅检口岸实施中国公民出入境通关候检时间不超过30分钟便利举措，在友谊关、东兴等6个与“一带一路”沿线重点国家毗邻的边境口岸设置“一带一路”通道，在边境口岸推出备案中国籍车辆免填《机动车辆查验卡》新举措。广西边检总站及所属东兴、友谊关、龙邦边检站结合实际，先后推出鲜活农产品绿色通道、出入境货车延时通关等多项便利措施，有效提高通关效率；积极跟进跨境自驾游试点、中欧班列等涉及出入境有关工作，提供优质通关服务。

我局就您的建议专门征求了公安部交通管理局意见，对您关注的广西自治区国际道路运输车辆备案管理、多边协定落实、跨境自驾游、车辆出入境信息共享等问题及有关意见进行了认真研究。一是关于国际道路运输车辆备案管理。据核实，2017年12月起，所有在广西从事国际道路运输的企业及车辆均由广西国际道路运输管理办公室（广西自治区交通运管局）集中通报广西边检总站转发所属边检站掌握，企业无需向边检机关报备国际道路运输车辆。二是关于车辆出入境信息共享。2018年4月，国家口岸办牵头拟制国际贸易“单一窗口”标准版公路交通运输工具申报模块，进一步明确了边检、海关、交通等部门需要共享的数据信息，现正在进行功能完善，下一步协调对接各部委业务系统后，将可实现数据共享。三是关于推进中越跨境自驾游试点工作。公安交管部门推出“两个互认、三个前置”服务措施，为临时入境车辆和驾驶人提供便利。“两个互认”，即：经海关或公安交管部门对入境车辆的唯一性出具结论的，双方互认；对越方出具的、在有效期内的《越南机动车安全技术检验合格证明》，中方公安交管部门予以互认。“三个前置”即：推行服务前置，将临时入境机动车牌证业务下放至县级车管所，并组织县级车管所工作人员到边境口岸现场为跨境自驾游车队办牌办证；推行教育前置，专门开设入境外籍驾驶员交通安全知识培训班，宣讲我国法律法规和安全文明驾驶知识；推行审核前置，入境前由旅行社代理提交自驾游车辆材料，车管所审核合格后提前制作临时入境机动车牌证，入境查验车辆后现场核发，减少等待时间。

下一步，我局、公安部交通管理局将继续加强对广西边检机关和公安交管部门的指导，紧密结合自治区实际，积极开展跨境运输车辆自助通关可行性研究，推动出入境车辆快速查验系统建设和应用，结合国家“单一窗口”公路版的推广应用，研究推行出入境车辆相关信息“网上预报，一单多报”，进一步便利国际道路运输车辆出入境；进一步简化临时入境机动车牌证办理手续和程序，放宽临时入境机动车牌使用条件，积极推进临时入境机动车牌证业务向县级下放、向入境站点延伸，方便境外人员来华驾车出行。

感谢您对移民管理工作的关心和支持。
