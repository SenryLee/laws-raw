# 国家文物局关于中山古城遗址保护范围和建设控制地带内道路改造提升工程的意见

文物保函〔2019〕368号

河北省文物局：

你局《关于呈报中山古城考古遗址公园北部主园路改造提升工程涉及中山古城遗址保护范围设计方案的请示》（冀文物字〔2019〕35号）收悉。经研究，我局原则同意在中山古城遗址保护范围和建设控制地带内实施道路改造提升工程。

一、所报方案尚需作以下必要的修改和完善：

（一）应按照《中山古城遗址保护规划》和中山古城考古遗址公园建设相关要求，进一步明确道路性质和功能，论证K4-K6标段道路横穿桓公墓遗址区和城墙遗址的必要性与可行性，进行该区域道路选线的多方案比选，避让重要遗址。

（二）统筹考虑考古遗址公园建设和周边区域居民生活需要，合理进行现状道路改造提升，不得拓宽；深化人车分流、重要节点停车和疏散设计内容，满足消防、园内交通需求。

（三）补充道路全套施工图、环境协调方案，严格控制工程范围和施工强度，不得大范围改造文物保护区划范围内地形地貌，并做好施工中的文物保护工作，确保文物安全。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

五、请你局按照督促地方人民政府抓紧修改完善《中山古城考古遗址公园规划》，明确公园定位、建设思路、重要节点设计等，按程序征求我局意见。

专此函复。

国家文物局

2019年4月18日
