# 国家能源局综合司关于同意调整石油工业标准化技术委员会部分委员的复函

国能综函科技〔2019〕56号

石油工业标准化技术委员会：

报来《关于调整石油工业标准化技术委员会主任委员、副秘书长和部分委员的请示》（油标委字〔2018〕25号）收悉。经研究，同意增补焦方正同志担任石油工业标准化技术委员会（以下简称“标委会”）主任委员，调整陈效红同志为标委会副秘书长，增补郑新权、林长海、周建良同志担任标委会委员，喻宝才等4名同志不再担任标委会委员（具体见附件）。

附件：标委会调整委员名单

国家能源局综合司

2019年2月1日
