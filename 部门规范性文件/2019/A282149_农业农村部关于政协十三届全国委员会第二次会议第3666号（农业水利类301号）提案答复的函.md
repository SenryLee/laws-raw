# 农业农村部关于政协十三届全国委员会第二次会议第3666号（农业水利类301号）提案答复的函

## 关于政协十三届全国委员会第二次会议第3666号（农业水利类301号）提案答复的函

农办案〔2019〕97号

潘碧灵委员：

您提出的关于在乡村振兴亟待重视优化新型职业农民培育的提案收悉。经商财政部、人力资源社会保障部，现答复如下。

一、关于健全培育体系

技能培训是提升农民综合素质和生产技能的重要途径，职业教育是培养高素质农民的重要载体，具有系统性培养优势。我部十分重视，坚持技能培训和职业教育两条腿走路，培养具备现代生产技能和经营能力的复合型农业农村人才。

一是优化农民培育体系。各级农业农村部门负责农民培训项目的组织实施，在发挥好政府引领作用的同时，各地注重统筹利用涉农单位、农业院校、科研院所、专业技术协会、农业龙头企业、农民专业合作社等培训资源，通过政府购买服务、市场化运作等方式，进一步健全完善“专门机构+多方资源+市场主体”的农民培育体系，充分激发各方参与积极性。二是抓好农民职业教育。2014年，我部联合教育部印发《中等职业学校新型职业农民培养方案（试行）》，支持中等职业学校通过弹性学制、半农半读、农学交替等方式培养农民学员；2019年，我部联合教育部印发《关于做好高职扩招培养高素质农民有关工作的通知》，启动实施“百万高素质农民学历提升行动计划”，全面完成2019年高职扩招培养高素质农民任务，针对农民单列计划，取消文化素质考试，鼓励以“注册制”形式免试录取拔尖实用人才，单独编班、单独教学，根据农村实际和农民特点开展分段式脱产学习。三是推进线上线下融合培训。为了让农技推广插上信息化的翅膀，让广大农民搭乘“互联网+”的快车，2017年开始，我部开展了农民教育培训信息化工作，设计开发了全国农业科教云平台，包括管理平台（网页端，各级农业科教管理人员用）、中国农技推广手机应用程序（专家、农技推广人员用）和云上智农手机应用程序（农民用）。全国农业科教云平台基于大数据、云计算和移动互联技术，聚集各类农业科技教育资源，为各级农业农村管理部门、农业专家、农技推广人员和广大农民提供在线学习、互动交流、成果速递和服务对接。我部加强内容资源开发建设，支持各地组织农民在线学习，探索线上线下融合培训模式，以从事生产经营的农民为主要对象，利用云平台开展在线学习，不断提升在线课程比重，通过政府购买服务方式支付在线学习费用。

下一步，我部将联合有关部门继续做好农民教育培训工作，利用职业教育提升农民素质，促进线上线下培训融合加快发展，为乡村振兴培养数量足、质量高的农业人才。

二、关于优化培育机制

我部注重通过职业教育和培训衔接一体化培养，提升参训农民的价值观、职业素养、经营管理能力和生产技术水平。加强参训农民跟踪服务，探索实行参训农民登记注册管理，为后续跟踪扶持、配套产业政策和金融保险服务提供科学依据。部分学员通过帮扶和引导成为了各级人大代表、政协委员、劳动模范以及村两委班子成员，发挥了示范引领作用。

关于农民职称评审问题，1986年，原中央职称改革领导小组转发《农业技术人员职务试行条例》，建立了农业技术人员职务聘任制度，分设农业、畜牧、兽医3个类别。1994年，农业部、人事部印发《农业技术推广研究员任职资格评审实施办法》，在农业系列开展正高级职称农技推广研究员评审，每两年评审一次。截至2016年，全国共有11300人取得农业技术推广研究员资格。这两项制度实施以来，对调动农业技术人员积极性、加强农业技术人员队伍建设发挥了重要作用。2018年中央1号文件提出，鼓励各地开展农民职称评定试点，目前已有浙江、湖南、山西、山东等地积极探索，坚持“干什么、评什么”，打破学历、所学专业、论文等限制，取得了较好成效，受到农村一线专业技术人员的普遍欢迎。

关于通过奖励扶持农民创业就业，中央财政已有相关政策措施，通过就业补助资金、中小企业发展专项资金、普惠金融发展专项资金中的创业担保贷款贴息等渠道，加大对农民创业就业的支持投入力度，符合条件的农民可按程序申请予以支持。鼓励有条件的地方结合本地区产业实际，研究制定相关产业支持政策，促进农民创业就业。

关于评价考核，我部积极推动各地将农民教育培训作为实施乡村振兴战略的重要抓手，摆上各地党委政府“三农”工作重要日程。开展中央对省、省对市县的农民培训绩效考核，鼓励开展第三方考核，促进教育培训质量提升。

下一步，我部将会同有关部门健全完善工作机制，强化绩效考核，加大对参训农民扶持力度，开展农业系列职称制度改革，进一步完善农业技术人员评价制度，为乡村振兴提供人才支撑。

三、关于完善培育制度

我部会同有关部委注重引导各地整合资源，积极创造有利于农民成长发展的政策环境。

一是整合政策资源。中央财政鼓励各地利用现有资金渠道，强化政策衔接配合，将支持农民教育培训、农民合作社及家庭农场发展等培育壮大新型农业经营主体政策统筹实施，支持强农惠农富农政策向参训农民倾斜支持。二是做好土地经营权流转管理和服务。我部要求各地建立工商资本租赁农户承包地上限控制、分级备案、审查审核、风险保障金和事中事后监管等“五项制度”，印发了《农村土地经营权流转交易市场运行规范（试行）》；积极指导各地健全土地经营权流转市场，规范市场运行机制，引导土地流转双方签订书面流转合同；积极配合全国人大等部门做好农村土地承包法修改工作，修改后的农村土地承包法于2019年1月1日起施行。三是合理测算分配资金。中央财政根据各地农业发展情况、农民教育培训效果等因素测算分配资金，各省可利用现有中央财政资金，统筹地方资金开展农民教育培训工作。四是引导农民参加社会保险。引导符合条件的农民参加城镇职工基本养老保险、职工基本医疗保险等社会保险。五是研究出台管理办法。目前，我部正在研究制定农民教育培训工作管理办法，对培育条件、组织培训、跟踪服务、资金使用、监督检查和绩效评价等环节进行规范，确保农民教育培训取得良好效果。六是探索农民教育培训立法。推动地方先行先试，天津市、甘肃省分别出台《天津市农民教育培训条例》《甘肃省农民教育培训条例》，为促进和规范农民教育培训工作，提高农民科学文化素质和从业能力提供了法律保障。

下一步，我部将继续梳理各类强农惠农富农政策，引导其落实到参训农民头上，不断提升务农兴业含金量；积极配合全国人大常委会、国务院法制办等相关部门工作，深入研究立法的必要性、可行性及具体内容，争取早日通过立法保障农民教育培训和队伍管理工作。

感谢您对农民教育培训工作的关心，希望今后继续对我部工作给予支持。

农业农村部

2019年8月30日
