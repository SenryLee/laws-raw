# 中华人民共和国工业和信息化部公告2019年第65号——符合《锂离子电池行业规范条件》企业名单（第四批）的公告

## 中华人民共和国工业和信息化部公告

2019年第65号

根据《锂离子电池行业规范条件》及《锂离子电池行业规范公告管理暂行办法》的规定，经企业申报、省级工业和信息化主管部门推荐、专家评审、网上公示、现场核实等程序，确定符合《锂离子电池行业规范条件》企业名单（第四批），现予以公告。

附件：符合《锂离子电池行业规范条件》企业名单（第四批）

工业和信息化部

2019年12月31日
