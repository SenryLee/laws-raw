# 国家森林草原防灭火指挥部办公室关于学习借鉴黑龙江省做法全力做好春季森林草原防灭火工作的通知

国森防办发明电〔2019〕13号

各省、自治区、直辖市森林（草原）防（灭）火指挥部，新疆生产建设兵团森林（草原）防火指挥部：

去冬今春以来，黑龙江省重点林区普遍降雪偏少，大部分地区“干封冻”，近期气温迅速回暖，大风天气明显增多，森林草原高火险期大幅提前。受厄尔尼诺事件影响，当前气象条件与发生大兴安岭“5?6”大火的1987年相似，且同期降水、气温等条件更为不利，森林草原防灭火形势异常严峻。黑龙江省委省政府对此高度重视，树立底线思维，超前谋划运作，专门召开省政府常务会议分析研判、安排部署春季森林草原防灭火工作，决定将今年春防启动日期由3月15日提前至3月1日，并努力做到五个到位：一是思想认识到位。牢固树立特殊年份高风险意识，坚持防范在先，工作提前，省委副书记、省长王文涛带队深入伊春等市县检查森林防火工作准备情况；二是责任落实到位。层层压实落靠领导责任，确保防火资金、物资、人员和各项工作部署落实到位；三是风险隐患排查到位。林区内林缘附近农作物秸秆抓紧离地、离林，持续开展清山、清林、清河套的“三清”行动，对重点部位死看死守，切实做到“封住山、看住人、管住火”；四是宣传教育到位。充分利用各种媒体，营造全社会管住防火、参与防火、支持防火的良好氛围；五是应急处置到位。高火险地区靠前驻防，扑救人员枕戈待旦，一旦发生森林草原火灾，坚持“重兵扑救，打歼灭战”原则，优先使用扑火专业力量，确保“打早、打小、打了”。

春防期间，历来是我国重特大森林草原火灾高发时段，1987年以来，全国共发生71起特大森林火灾，60%集中在这一时段；是境外火灾威胁边境地区重点时段，近5年来，蒙古国和俄罗斯火灾3次越境烧入我国引发重特大森林火灾，中朝、中越、中缅等边境地区外方野外用火十分频繁，并多次烧入我方境内引发森林火灾；是野外火源管控最难时段，传统民俗用火、祭祀用火、春耕生产用火交织，进山踏青旅游、采摘山货、驴友穿越等活动频繁，90%以上的森林草原火灾系人为原因引发。特别是今年，受厄尔尼诺现象影响，局地高温、干旱、干雷暴等极端天气可能增加，川滇干热河谷地区以及东北内蒙古等地已明显呈现出气温高、降水少的特点，气象条件十分不利；随着国土绿化全面提速，天然林商业性采伐全面停止，我国森林覆盖率、草原植被盖度明显增加，林区牧区可燃物载量明显增多，一些地方远超重特大森林草原火灾临界值，物候条件十分不利；浅山区林农交错、林草相间现象十分普遍，田在山上、村在山间不同程度存在，加之当地民居木结构较多，存在“家火上山”和“山火入户”形成火烧连营的风险，基础条件十分不利。同时，春季防火期叠加全国“两会”、清明节、“五一”等关键节点，市县两级应急管理部门组建、林草部门调整、森林公安改革下的森林草原防灭火工作体制调整，以及大部分林区牧区防灭火基础设施薄弱、防扑火力量不足等因素，今年我国春季森林草原防灭火工作形势异常严峻，具备发生重特大森林草原火灾的条件，火灾防控工作面临重大考验。

各地区要清醒认识春季森林草原防灭火工作的艰巨性、严峻性和复杂性，深刻学习领会习近平总书记在省部级主要领导干部坚持底线思维着力防范化解重大风险专题研讨班上的重要讲话精神，充分认识新时期森林草原防灭火工作面临的新形势、新任务、新要求，学习借鉴黑龙江省树立底线思维、抢前抓早、主动防范化解森林草原火灾风险的做法，学习借鉴吉林省38年无重大森林火灾的经验，将春季森林草原防灭火工作作为防范化解重大安全风险的大事来抓，把春防这根弦绷得更紧，提高政治站位，保持斗争精神，强化责任担当，专题研究、压实责任、精准施策，扎实做好森林草原火灾防控工作，严防人为原因引发森林草原火灾，严防重特大森林草原火灾和人员伤亡事故，为新中国成立70周年创造安全和谐稳定的社会环境。
