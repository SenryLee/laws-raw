# 交通运输部公告2019年第68号——交通运输部关于发布《危险货物港口建设项目安全预评价规范》的公告

## 交通运输部公告

2019年第68号

## 交通运输部关于发布《危险货物港口建设项目安全预评价规范》的公告

《危险货物港口建设项目安全预评价规范》为水运工程推荐性行业标准，标准代码为JTS/T 108-1—2019，自2019年12月1日起施行，由交通运输部水运局负责管理和解释。《港口建设项目安全预评价规范》（JTS/T 170-2—2012）同时废止。

特此公告。

交通运输部

2019年9月12日
