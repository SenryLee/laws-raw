# 商务部关于对原产于澳大利亚的进口大麦反补贴调查的延期公告

根据《中华人民共和国反补贴条例》的规定，2018年12月21日，商务部发布2018年第99号公告，决定对原产于澳大利亚的进口大麦进行反补贴立案调查。

鉴于本案情况复杂，根据《中华人民共和国反补贴条例》第二十七条的规定，商务部决定将本案的调查期限延长6个月，即截止日期为2020年6月21日。
