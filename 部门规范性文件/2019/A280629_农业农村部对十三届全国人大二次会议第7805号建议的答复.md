# 农业农村部对十三届全国人大二次会议第7805号建议的答复

## 对十三届全国人大二次会议第7805号建议的答复

农办议〔2019〕65号

刘志宏代表：

您提出的关于支持运城建设国家级优质水果基地的建议收悉。经商发展改革委，现答复如下。

一、关于支持运城果业标准化园区提档升级

我部认真贯彻落实中央的决策部署，高度重视果业建设和发展，把发展果业作为推动现代农业发展、增加农民收入、实现农村脱贫致富的一项重要举措，积极会同有关部门，认真贯彻落实中央的部署，推动水果产业健康发展。一是加强规划引导。2003年和2008年，我部两次发布《全国苹果优势区域布局规划》，将运城所处的晋南地区划入“黄土高原优势区”，明确功能定位、发展目标和主攻方向，引导苹果产业向优势区域聚集，提升产业整体竞争力。二是创建特色农产品优势区。2017年，我部会同发展改革委、林业局编制印发了《特色农产品优势区建设规划纲要》，提出到2020年，创建并认定300个左右国家级特优区，重点建设标准化生产基地、加工基地、仓储物流基地、科技支撑体系、品牌建设与市场营销体系、质量控制体系等。国家级特优区聚焦发展特色粮经作物、特色园艺产品、特色畜产品、特色水产品、林特产品五大类29个品种，目前已认定2批共146个国家级特优区。2019年5月，我部联合有关部门启动第三批特优区申报，山西运城等地可积极申报创建国家级特优区，我部将在提高特优区申报材料质量、编制特优区建设规划等方面给予指导和帮助。三是加强标准化示范基地建设。2009—2016年，我部每年安排中央财政资金支持开展蔬菜、水果、茶叶等园艺作物标准园创建，大力推进规模化种植、标准化生产、商品化处理、品牌化销售、产业化经营，有效推动科技应用，带动产业提档升级。2017—2018年，我部每年安排中央财政资金支持开展绿色高质高效整建制创建，集成推广主要经济作物高产高效、资源节约、生态环保技术模式，引领农业发展方式转变。2019年，中央财政继续安排资金支持开展绿色高质高效行动，集成“全环节”绿色高效技术，构建“全过程”社会化服务体系，打造“全链条”产业融合模式，引领“全县域”农业绿色发展，示范带动大面积提质增效。

下一步，我部将继续会同发展改革委等有关部门，着力抓好特色农产品优势区创建，深入开展绿色高质高效行动，支持地方打造特色农产品生产优势区和产业发展集聚区，推进农村一二三产业融合发展，促进农业提质增效和农民增收。

二、关于支持运城农产品出口平台建设

我部认真贯彻落实党中央、国务院关于实施乡村振兴战略的决策部署，强化顶层设计，培育市场主体，促进优质优价，带动农民增收。一是加强政策指导。推进《国务院办公厅关于进一步促进农产品加工业发展的意见》（国办发〔2016〕93号）贯彻落实；会同发展改革委等14个部门印发《关于促进农产品精深加工高质量发展若干政策措施的通知》，指导各地加强行业标准制修订、国际标准跟踪和官方评议；培育创建国际农产品加工园区，支持新型经营主体建设保鲜、储藏、分级、包装等初加工设施；开展外经人员能力培训，推进加工企业“走出去”。二是加强农产品批发市场建设。2015年，我部印发《全国农产品产地市场发展纲要》，并会同发展改革委、商务部、交通运输部等部委联合印发了10余个文件推动完善农产品产地市场体系。截至目前，我部已启动建设了洛川苹果等13个全国性农产品产地市场，亿元以上农产品专业批发市场发展到937家，年成交额19346.7亿元，在带动相关产业发展、提升产品影响力等方面起到积极效果。三是扶持壮大龙头企业。通过举办龙头企业负责人培训等活动，宣传龙头企业扶持政策，帮助龙头企业提升经营管理水平；通过搭建农业产业化交易会等产销对接平台，帮助龙头企业拓展产品销路，打造知名品牌；研究完善相关政策措施，推动龙头企业转型升级。目前，全国经县级以上农业产业化主管部门认定的龙头企业达8.7万家，其中省级以上重点龙头企业1.7万家、国家级重点龙头企业1243家，农业产业化龙头企业已成为促进现代农业建设、推动农业供给侧结构性改革、促进乡村产业振兴的重要力量。

下一步，我部将继续会同有关部门和单位，指导各地把加强市场建设作为促进农产品销售、引导农业结构调整和增加农民收入的重要措施，加强产地批发市场和田头市场建设，增强农户营销能力，提高农产品附加值，减少流通损失，促进产业健康发展。

三、关于将运城国际果品交易博览会上升到国家层面进行打造

近年来，我部积极利用各类农业展会、品牌大会等平台开展了一系列产销衔接活动，取得积极成效。一是开展品牌推选工作。2016年，推选了100个名优果品区域公用品牌、“2016中国最有影响力的十大苹果区域公用品牌”；2017年，推选了“2017年中国百强农产品区域公用品牌”；2018年，推动中国农产品市场协会开展“中国农业品牌目录制度”工作，为做强贫困地区农业品牌发挥了积极作用。二是加强品牌产品营销推介。借助中国国际农产品交易会、中国国际茶叶博览会等农业展会以及产销对接等活动，推介贫困地区品牌农产品。在第十四届、十五届、十六届中国国际农产品交易会期间分别举办“省部长推介品牌农产品专场”“我为品牌农产品代言”“乡人乡味——全国品牌农产品推介活动”等大型公益活动，倾情推介具有地方特色的农产品区域公用品牌，为促进产业发展、农民增收提供了有力支撑。

运城国际果品交易博览会举办以来，示范性强，引领作用突出，对推动当地水果产业发展发挥了重要作用。《国务院关于进一步促进展览业改革发展的若干意见》明确要求，严格规范各级政府办展行为，减少财政出资和行政干预，逐步加大政府向社会购买服务的力度，建立政府办展退出机制。运城国际果品交易会应遵循市场经济规律，以市场为导向，按照“市场化、专业化、国际化、品牌化、信息化”的办展理念，统筹利用好国内国际两个市场两种资源，逐步塑强展会品牌，以会展经济带动产业发展。下一步，我部将继续发挥各类农业展会、农产品产销对接活动的作用，充分借助各地展览会、展销会、博览会等展会平台，积极开展品牌营销推介活动，利用传统媒体和新媒体强化品牌宣传推广，提升当地农业品牌影响力和知名度。

感谢您对农业农村工作的关心，希望对我部工作继续给予支持。
