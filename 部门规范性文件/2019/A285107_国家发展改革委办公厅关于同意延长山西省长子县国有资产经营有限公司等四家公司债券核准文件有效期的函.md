# 国家发展改革委办公厅关于同意延长山西省长子县国有资产经营有限公司等四家公司债券核准文件有效期的函

发改办财金〔2019〕1095号

山西省、福建省、河南省、湖北省发展改革委：

报来《关于转报长治市长子县国有资产经营有限公司申请发行公司债券核准有效期延期的请示》（晋发改财金字〔2019〕321号）、《关于宁德市交通投资集团有限公司债券延长核准批复文件有效期的请示》（闽发改营商〔2019〕595号）、《关于报送郏县产业集聚区投资发展有限公司申请延期发行公司债券的请示》（豫发改财金〔2019〕658号）、《关于荆州海子湖投资有限公司发行公司债券延长债券核准文件有效期的请示》（鄂发改财贸〔2019〕376号）收悉。经研究，现函复如下。

一、同意将《国家发展改革委关于山西省长子县国有资产经营有限公司发行公司债券核准的批复》（发改企业债券〔2018〕194号）文件有效期延长12个月至2020年12月19日。

同意将《国家发展改革委关于福建省宁德市交通投资集团有限公司发行公司债券核准的批复》（发改企业债券〔2018〕182号）文件有效期延长12个月至2020年12月8日。

同意将《国家发展改革委关于河南省郏县产业集聚区投资发展有限公司发行公司债券核准的批复》（发改企业债券〔2018〕191号）文件有效期延长12个月至2020年12月18日。

同意将《国家发展改革委关于湖北省荆州海子湖投资有限公司发行公司债券核准的批复》（发改企业债券〔2018〕188号）文件有效期延长12个月至2020年12月14日。

二、请你委督促发行人按照《公司法》《证券法》《企业债券管理条例》和有关规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

三、请你委督促发行人按要求及时做好信息披露及债券资金管理，按照核准的募集资金投向合规使用债券资金，认真落实偿债保障措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅

2019年11月25日
