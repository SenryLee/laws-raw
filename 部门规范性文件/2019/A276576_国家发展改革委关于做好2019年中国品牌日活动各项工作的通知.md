# 国家发展改革委关于做好2019年中国品牌日活动各项工作的通知

发改产业〔2019〕672号

上海市发展改革委，中国轻工业联合会、中国纺织工业联合会、中国电子信息行业联合会、中国汽车工业协会、中国自行车协会、中国钟表协会、中国家用电器协会、中国陶瓷工业协会、中国香料香精化妆品工业协会、中国洗涤用品工业协会、中国口腔清洁护理用品工业协会、中国文教体育用品协会、中国乐器协会、中国皮革协会、中国国际工程咨询有限公司、中轻食品工业管理中心、中国食品科学技术学会、中国质量协会、中国广告主协会、中国专利技术开发公司、上海外经贸商务展览有限公司：

为深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，全面落实中央经济工作会议要求和党中央、国务院关于品牌发展的决策部署，深化供给侧结构性改革，推动高质量发展，促进形成强大国内市场，经国务院批准同意，国家发展改革委联合中宣部、工业和信息化部、农业农村部、商务部、市场监管总局、知识产权局、上海市人民政府定于2019年5月10日至12日在上海举办中国品牌发展国际论坛，论坛期间设置自主品牌消费品体验区宣传推介国货精品，同时引导地方组织开展品牌日特色活动。

目前，我们研究制定了2019年中国品牌日系列活动总体方案，现印发你们（各地组织开展品牌日特色活动已另行通知）。请你们根据进度安排和工作要求，认真组织、精心策划，做好活动各项工作。
