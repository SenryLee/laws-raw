# 国债业务公告2019年第56号——决定发行2019年记账式贴现（三十六期）国债的公告

## 国债业务公告

2019年第56号

根据国家国债发行的有关规定，财政部决定发行2019年记账式贴现（三十六期）国债（以下称本期国债），已完成招标工作。现将有关事项公告如下：

一、本期国债计划发行100亿元，实际发行面值金额100亿元。

二、本期国债期限91天，经招标确定的发行价格为99.417元，折合年收益率为2.36%，2019年8月26日开始计息，招标结束后至8月26日进行分销，8月28日起上市交易。

三、本期国债低于票面面值贴现发行，2019年11月25日（节假日顺延）按面值偿还。

其他事宜按《中华人民共和国财政部公告》（2018年第174号）规定执行。

特此公告。

中华人民共和国财政部

2019年8月23日
