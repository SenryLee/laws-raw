# 国家文物局关于武当山古建筑群保护区划内元和观乡村环境整治及危房加固建设项目的意见

文物保函〔2019〕815号

湖北省文化和旅游厅：

你厅《关于呈报元和观乡村环境整治及危房加固项目涉及武当山建筑群保护范围和建设控制地带的请示》（鄂文旅文〔2019〕95号）收悉。经研究，我局原则同意在武当山古建筑群保护区划内进行元和观乡村环境整治及危房加固建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应深入研究元和观村历史文化内涵，归纳村落特征，补充元和观旅游潜力和游客量预期的相关分析评估，明确整治目标定位和功能需求。

（二）应力求延续村落传统风貌、业态和文化氛围，弱化城市园林街景设计倾向，保证当地居民正常社区生活，鼓励居民适当参与旅游服务，但须避免过度旅游和商业开发，不得建设仿古商业街。

（三）应依照《武当山建筑群总体保护与管理规划纲要》关于回龙观、中观缓冲区新建项目“不得超过2层，檐口高度不得高于7米”的管理规定，修改方案中不符合规定的建筑设计。

（四）应进一步完善设计方案，补充给排水设施、供电设施、通讯设施等设计内容。

二、请你厅指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你厅会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年8月13日
