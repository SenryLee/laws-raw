# 国家能源局综合司关于同意注销福建良浅等5座水电站大坝安全注册登记证的复函

国能综函安全〔2019〕113号

大坝安全监察中心：

你中心《关于注销福建良浅、大言、孔头、范厝水电站大坝安全注册登记证的请示》（坝监安监〔2019〕12号）、《关于注销福建西门水电站大坝安全注册登记证的请示》（坝监安监〔2019〕 19号）收悉。经研究，函复如下。

一、福建良浅、大言、孔头、范厝、西门水电站的总装机容量均小于5万千瓦，属于小水电。经对大坝运行单位、主管单位、福建能源监管办相关文件和福建省三明市水利局颁发的大坝注册登记证进行审查，并根据《国家能源局综合司关于小水电大坝办理注册登记注销手续有关事宜的复函》（国能综安全[2016]154号），同意注销上述5座水电站大坝安全注册登记证。

二、请你中心及时办理5座水电站大坝安全注册登记证注销手续，并将注销情况书面告知大坝运行单位、主管单位、福建能源监管办和地方政府水行政主管部门。

三、自福建良浅、大言、孔头、范厝、西门水电站大坝安全注册登记证注销手续办理完毕之日起，我局不再承担其大坝安全监管责任。

国家能源局综合司

2019年3月25日
