# 国家文物局对十三届全国人大二次会议第7386号建议的答复

文物保函〔2019〕673号

于安玲等3名代表：

您提出的“关于把济宁‘大运河总督署博物馆’纳入国家重点文化项目建设的建议”收悉。经商国家发展和改革委员会，现答复如下。

济宁市是我国大运河重要节点城市。大运河济宁段具有特殊性和重要性，是大运河水脊所在地，拥有南旺枢纽等一大批重要的大运河文化遗产。为保障运河运道漕运畅通，元明清三朝建立了一整套运河管理制度与漕运制度，并在济宁设立了治运最高机构——河道总督衙门或河道都察院之类高层治理机构，即“河督建节，宿兵于此”。2013年，“济宁河道总督府遗址”作为大运河组成部分被国务院公布为全国重点文物保护单位。

中共中央办公厅、国务院办公厅联合印发的《大运河文化保护传承利用规划纲要》已将“山东济宁运河博物馆”列为大运河博物馆体系建设的重要内容。国家发展和改革委员会表示，“将积极鼓励地方结合实际，加快推进落实”山东济宁运河博物馆等各具特色的运河主题博物馆报批新建工作。

我局认为，应在做好占压“济宁河道总督府遗址”的现有建筑腾退清理基础上，对该遗址可能分布区域进行全面考古勘探、发掘，摸清济宁河道总督府地下遗存分布情况，结合历史文献的挖掘、整理，进一步明确其历史格局、历史沿革和形制作法，按照考古遗址公园建设要求，对该遗址进行原址保护、全面展示和价值阐释，不宜进行遗址复原或重建；可结合遗址展示，在遗址临近区域择址建设“山东济宁运河博物馆”，对大运河济宁段的特点、价值、文化以及河道总督府进行系统展示。

感谢您对文物事业的关注和支持！

国家文物局

2019年7月10日
