# 中共自然资源部党组关于夏木清、赵久田同志免职退休的通知

自然资党任〔2019〕2号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中央军委后勤保障部军事设施建设局，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

部党组2018年12月17日研究决定：

免去夏木清矿产资源保护监督司副司长职务，退休；

免去赵久田自然资源确权登记局巡视员职务，退休。

中共自然资源部党组

2019年1月9日
