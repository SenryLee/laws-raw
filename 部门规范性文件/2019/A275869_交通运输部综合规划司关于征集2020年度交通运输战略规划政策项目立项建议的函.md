# 交通运输部综合规划司关于征集2020年度交通运输战略规划政策项目立项建议的函

## 关于征集2020年度交通运输战略规划政策项目立项建议的函

规函综〔2019〕22号

各有关单位：

根据《交通运输科研项目管理暂行办法》第七条的规定，现就2020年度交通运输战略规划政策项目立项工作有关事项通知如下：

一、请部内各司局会同相关科研单位研究提出项目立项建议，并于6月2日前提交《2020年度交通运输战略规划政策项目立项建议表》和《2020年度交通运输战略规划政策项目申请书》（格式参见《交通运输科研项目管理暂行办法》附件1-1、1-2，可自行在交通运输部网站下载）。

二、鉴于预算紧张，请各司局突出重点，紧紧围绕“十四五”规划、综合立体交通网规划编制等开展选题，原则上各司局2020年项目数量不超过2019年，并应按照附件1-1要求，就项目优先次序做好排序。

三、根据财政部预算审核要求，拟提交的2020年度立项建议应对照2016-2019年度已完成和正在开展的战略规划政策项目，确保不重复。

四、各科研单位应与部内各司局密切沟通联系，协助提出立项建议和撰写项目申请书。

五、下一步，我司将组织部内各司局、有关专家对立项建议进行评审，择优遴选确定立项项目。
