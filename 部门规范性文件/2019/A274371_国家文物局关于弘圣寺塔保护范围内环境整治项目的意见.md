# 国家文物局关于弘圣寺塔保护范围内环境整治项目的意见

文物保函〔2019〕149号

云南省文物局：

你局《关于请求对弘圣寺塔环境整治方案进行审核的请示》（云文物〔2018〕174号）收悉。经研究，我局原则同意弘圣寺塔保护范围内环境整治项目。

一、所报方案尚需作以下必要的修改和完善：

（一）加强弘圣寺塔及其历史环境研究，深化文物环境现状评估，明确文物保护区划管理要求，为项目实施提供依据。

（二）新建参拜道、广场及地面平整对历史环境造成较大改变，应予调整。应延续现状周边地形的自然变化，最大限度缩减硬化地面面积，不宜设置扶手栏板，弱化城市公园化倾向。

（三）进一步弱化绿化系统、灯光照明、景观雕塑等景观要素设置；建议现状保留石牌坊；碑亭建设依据不足，暂不同意实施。

（四）项目实施前，应开展必要的考古调查勘探工作，对重要的遗存应进行原址保护。

（五）弘圣寺塔塔体及基座修缮应编制文物保护勘察设计方案，另行报批。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月13日
