# 国家文物局对十三届全国人大二次会议第7979号建议的答复

文物政函〔2019〕683号

郭建仁代表：

您提出的《关于确认河北涿鹿桥山黄帝陵和设立涿鹿桥山黄帝陵国家公祭的建议》收悉，经商财政部、文化和旅游部、中国社会科学院、中央广播电视总台等单位，现答复如下。

涿鹿故城（黄帝城）遗址位于河北省涿鹿县矾山镇三堡村北，为省级文物保护单位。文物部门曾对此遗址进行多次调查、试掘，河北省文物研究所、吉林大学边疆考古研究中心和涿鹿县文物局于2014年组织的联合发掘情况表明，涿鹿故城的始建年代可能不会早于战国时期，在涿鹿故城的周边地区则发现了新石器时代晚期的遗存。涿鹿故城遗址的性质与归属问题还需要深入的学术研究，尚不能从考古学角度对涿鹿黄帝陵进行确认，目前不宜与黄帝研究建立直接联系。

对于您所提意见，国家文物局会同相关部门进行了认真研究，将会在今后工作中给予关注和推进。

关于“重视研究挖掘、保护遗址遗迹、加强考古发掘、科学规划设计”的建议，我局高度重视考古和遗址保护利用工作，持续加大政策支持和经费投入。在河北省进一步做好涿鹿故城及其周边地区考古工作计划和遗址保护规划的基础上，各有关部门将加强考古发掘、价值阐释、遗址保护、园区建设等工作的对接和指导，保护好故城遗址，传承好华夏文明。

关于“恢复对涿鹿桥山黄帝陵的国家公祭”建议，按照《节庆活动管理办法实施细则》（国清组发〔2015〕1号）规定，各级党政机关原则上不再举办新的各类节庆活动。经党中央、国务院批准，目前保留的黄帝公祭活动，均为省级或省级以下党政机关举办，并非“国家公祭”，暂不宜设立涿鹿桥山黄帝陵国家公祭。如有关部门或单位经研究认为确有必要举办公祭活动，建议按程序履行审批手续。

关于“广泛宣传，为中华振兴凝聚共识”建议，中华文物全媒体传播计划已列入中央关于加强文物保护利用改革文件，支持对包括涿鹿故城遗址考古、保护、研究等在内的文物工作成果给予宣传，为加强文物保护、传承中华优秀传统文化营造良好舆论氛围。

衷心感谢您对文物工作的关注和支持！

国家文物局

2019年7月10日
