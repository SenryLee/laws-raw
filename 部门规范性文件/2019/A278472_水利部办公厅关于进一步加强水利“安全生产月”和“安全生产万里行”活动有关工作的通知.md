# 水利部办公厅关于进一步加强水利“安全生产月”和“安全生产万里行”活动有关工作的通知

办监督函〔2019〕716号

部直属各单位，各省、自治区、直辖市水利（水务）厅（局），新疆生产建设兵团水利局：

根据《国务院安委会办公室关于进一步加强全国“安全生产月”和“安全生产万里行”活动有关工作的补充通知》（安委办函〔2019〕32号，见附件）的要求，结合《水利部办公厅关于开展2019年水利“安全生产月”和“安全生产万里行”活动的通知》（办监督〔2019〕101号）部署，为进一步调动水利职工参与积极性，扩大全国“安全生产月”和“安全生产万里行”活动影响力和覆盖面，确保活动既有声势又有实效，现就有关事项补充通知如下。

一、深入开展“查找身边的隐患”活动

各地各单位要围绕“防风险、除隐患、遏事故──从身边做起”，深入推动安全宣传教育走进水利行业各个角落，教育引导水利一线从业人员严守法律法规，遵守操作规程，杜绝不安全行为，做自身安全的主人。要结合正在开展的水利工程建设安全生产专项整治（办监督函〔2019〕457号）要求，组织水利生产经营单位全面深入开展隐患排查治理工作，要广泛发动水利职工尤其是一线职工全面查找身边的安全隐患，积极举报风险隐患，勇于同不安全行为作斗争，在保护自身安全的同时维护公众安全，筑牢防范化解安全风险的第一道防线。

二、进一步加强行业宣传

各地各单位要紧密结合工作实际，充分发挥水利行业优势，调动所属媒介资源，特别是要充分发挥微信、微博等新媒体的传播速度快、效率高的特点，加大行业宣传力度，推动全行业关心安全生产、参与安全发展。要组织做好“6.16”全国安全宣传咨询日活动，在水利单位办公区、宿舍区和水利工程现场等区域的醒目位置，广泛张贴、悬挂安全标语横幅、安全提示、安全警示挂图和公益宣传画，充分发挥电子显示屏的公益传播作用，持续滚动播放安全公益广告、警示教育片和科普短视频。要面向水利一线从业人员定期推送通俗易懂、知识性强的安全生产公益信息，让安全生产知识触手可及。

三、加强调研和督促指导

各地各单位要深入水利生产经营单位和水利工程一线调研督导，指导开展宣传教育活动，有效解决存在问题，及时评估活动成效，抓好活动跟踪落实，推动“安全生产月”和“安全生产万里行”活动走深、走细、走实。我部将结合《水利部办公厅关于开展2019年度水利工程建设安全监督专项巡查工作的通知》（办监督〔2019〕109号）安排，深入基层单位和水利工程进行调研，对“安全生产月”活动进行指导评估，及时推广有关经验做法。
