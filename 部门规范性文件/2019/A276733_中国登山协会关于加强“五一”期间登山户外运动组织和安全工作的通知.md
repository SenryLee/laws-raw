# 中国登山协会关于加强“五一”期间登山户外运动组织和安全工作的通知

## 关于加强“五一”期间登山户外运动组织和安全工作的通知

各登山协会、俱乐部及其他相关机构：

“五一”假期即将来临，登山户外运动赛事和活动数量、参与的人数将有显著增加，登山户外运动安全问题应引起高度重视。为避免发生登山户外运动安全事故，切实做好“五一”期间登山户外运动的组织和安全工作，现通知如下：

一、攀登西藏自治区海拔5000米以上和其他省区市海拔3500米以上的独立山峰，要严格按照《国内登山管理办法》中的相关规定进行申报和审批，尊重生命、尊重自然，遵守循序渐进、量力而行的原则。

二、按照政府和体育、旅游行政部门的相关规定，切实加强组织管理工作，尤其是高技术、高风险的登山户外运动赛事、活动。认真做好各环节工作，活动的主办、承办机构要建立活动风险管理体系，具有充足的技术力量和齐备的物资保障。在各类活动中，切实保障交通行车安全、食品卫生安全、财产物资安全、技术操作安全等。

三、正视登山户外运动与普通旅游的关系，积极与体育行政部门、旅游行政部门协调，把活动控制在风险已知、便于救援的范围内。

四、认真建立和执行各种登山户外运动中突发事件的应急预案，严格各项安全管理措施，落实突发山难紧急救援工作。一旦发生险情，要立即向当地主管部门报备，积极组织救援。

五、活动赛事组织者要切实承担起安全责任，“谁主办，谁负责”。

六、增强登山户外运动参与人员的安全防范意识，加强登山户外运动安全知识的宣传教育，聘请具有资质的教练和向导，使用合格的装备和器材，树立“科学、文明、安全、环保”的登山户外运动理念。

中国登山协会

2019年4月28日
