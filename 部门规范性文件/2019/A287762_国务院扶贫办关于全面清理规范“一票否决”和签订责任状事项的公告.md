# 国务院扶贫办关于全面清理规范“一票否决”和签订责任状事项的公告

根据全面清理规范“一票否决”和签订责任状事项的有关要求，国务院扶贫办认真研究、逐项清理，现公告如下。

（一）国务院扶贫办未设立“一票否决”事项。

（二）2020年不再组织签订《脱贫责任书》。

（三）2020年继续组织签订《扶贫协作协议》和《定点扶贫责任书》。

国务院扶贫办

2019年11月26日
