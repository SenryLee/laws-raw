# 国家知识产权局关于印发《集成电路布图设计审查与执法指南（试行）》的通知

国知发保字〔2019〕22号

各省、自治区、直辖市、新疆生产建设兵团知识产权局，局机关有关部门，专利局有关部门：

为贯彻落实党中央、国务院关于严格知识产权保护的决策部署，切实维护创新者、专有权人和社会公众的合法权益，加强集成电路布图设计专有权保护，提高集成电路布图设计审查、执法工作的效率与水平，根据《集成电路布图设计保护条例》以及相关部门规章，制定《集成电路布图设计审查与执法指南（试行）》，现予以印发，请遵照执行。

在执行中遇到的新情况、新问题和有关建议请及时报告。我局此前发布的其他有关规定与本通知相抵触的，依照本通知执行。

特此通知。

国家知识产权局

2019年4月8日
