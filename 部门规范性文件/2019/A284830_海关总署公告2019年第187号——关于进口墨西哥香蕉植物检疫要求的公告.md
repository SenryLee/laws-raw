# 海关总署公告2019年第187号——关于进口墨西哥香蕉植物检疫要求的公告

## 海关总署公告

2019年第187号

## 关于进口墨西哥香蕉植物检疫要求的公告

根据我国相关法律法规和《中华人民共和国海关总署与墨西哥合众国农业和农村发展部关于墨西哥香蕉输华植物检疫要求的议定书》规定，自本公告自发布之日起，允许符合相关要求的墨西哥香蕉进口。现将进口墨西哥香蕉植物检疫要求予以公布（见附件）。

特此公告。

附件：进口墨西哥香蕉植物检疫要求

海关总署

2019年12月9日
