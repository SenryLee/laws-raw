# 中国气象局科技与气候变化司关于进一步加强气象科技前沿动态研究工作的通知

气科函〔2019〕9号

各省（区、市）气象局，各直属单位：

为深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，落实创新驱动发展战略，加快气象科技强国建设，现就进一步加强气象科技前沿动态研究工作通知如下。

一、充分认识加强气象科技前沿动态研究的重要意义

党的十八大以来，习近平总书记关于科技创新的重要论述不断丰富和发展。我们要深刻理解习近平总书记关于科技是国之利器、关键核心技术必须自主可控、抢占事关长远和全局的科技战略制高点等一系列重要论断，坚定不移走中国特色自主创新道路，坚持把科技创新作为引领发展的第一动力和推进气象事业高质量发展的战略支撑。加快建设世界气象科技强国，着力突破气象关键核心技术，牢牢掌握科技创新主动权，必须瞄准世界科技前沿，抓住气象科技发展大趋势，把准主攻方向，选准技术路径，必须持续开展科技前沿动态研究，跟踪了解国内外相关领域的科技发展动态、发展战略和科技政策，对标国际先进找差距，着力提升气象核心竞争力。

二、有关工作要求

请各单位积极支持开展气象科技前沿动态研究工作，围绕本单位的核心科技领域和学科主攻方向，深入开展动态调研，围绕创新目标、技术路线、人才与资源配置和攻关组织机制等方面提出对策建议，形成研究报告。请国家级业务科研培训单位、各专业气象科研院所、省部级及以上重点实验室于2019年9月15日前报送研究报告1—2篇，请其他单位根据工作需要积极报送。有中国气象局重点实验室的国家级业务单位可统筹安排本单位和重点实验室的科技前沿动态研究工作。我司将组织遴选2019年度优秀气象科技前沿动态研究报告。
