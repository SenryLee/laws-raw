# 国家广播电视总局关于政协十三届全国委员会第二次会议第2431号（文化宣传类第206号）提案答复的函

## 关于政协十三届全国委员会第二次会议第2431号（文化宣传类第206号）提案答复的函

广电提案〔2019〕42号

邰丽华委员：

您提出的《关于为听障人士加配CC字幕（隐藏式字幕）的无障碍服务的提案》收悉，现答复如下：

2012年，国务院颁布《无障碍环境建设条例》，其中第二十一条规定：设区的市级以上人民政府设立的电视台应当创造条件，在播出电视节目时配备字幕，每周播放至少一次配播手语的新闻节目。《条例》实施后，全国各地电视台基本按照条例要求，尽可能地为电视节目配备字幕。字幕展现方式主要为对白字幕，即字幕在电视节目播出前或者播出时渲染在视频图像上，作为视频图像的一部分播出，字幕不可隐藏，所有人均可见。

关于您提出的“为听障人士加配隐藏式字幕”，2013年，我局组织编制广播电视行业标准《GY/T 270-2013 数字电视隐藏字幕系统规范》，该标准主要以美国EIA708B标准为基础，但在字库方面引入了中文字库。从近几年的推广实施情况来看，提供隐藏式字幕服务，对技术系统和节目类型均有一定的要求。一方面，在现有传输通道中，需额外增加字幕数据传输通道，确保字幕与视频同步传输；终端也要支持隐藏字幕渲染/叠加到图像，保证字幕与图像同步。另一方面，字幕也是节目的一部分，重要活动、重要会议、时政专题等直播类电视节目，对准确度的要求极高，配备字幕会受到一定限制。

因此，提供隐藏式字幕服务必须在制作域、播出域、传输域和终端接收等环节，增加相应的制作、嵌入等流程，对技术系统、网络和终端的软硬件设备进行升级改造，实现难度和成本高于对白字幕。从目前来看，我国各地电视台基本没有选择隐藏式字幕方式。

关于您提到的“国际上其他国家已制定强制性法律法规”，以美国为例：美国1996年通信法案虽然强制要求视频节目通过隐藏字幕实现无障碍服务，但同时也考虑实现成本、电视频道盈利情况、节目播出时段、节目时长、节目类型等因素，制定了豁免规则，在豁免规则内的电视节目可以不设置隐藏字幕。

下一步，我局将与中国残联加强合作沟通，尽可能地丰富提供字幕服务的节目类型，增加节目的字幕服务时长，加强对隐藏式字幕相关实现技术的跟踪研究工作，更好满足听力残疾人士的收看需要。

非常感谢您对广播电视工作的支持。

国家广播电视总局

2019年8月22日
