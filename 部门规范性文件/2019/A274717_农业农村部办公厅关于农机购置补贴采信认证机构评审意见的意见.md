# 农业农村部办公厅关于农机购置补贴采信认证机构评审意见的意见

农办机函〔2019〕2号

《市场监管总局办公厅关于征求农机购置补贴采信认证机构评审意见的函》（市监认证函〔2019〕273号）收悉。经研究，我部原则同意你局评审意见，将北京东方凯姆质量认证中心、南京赛姆认证科技发展有限公司的农机产品认证结果，用于农机购置补贴机具资质采信工作。其中，强制性产品认证结果直接采信，自愿性产品认证结果采信的产品种类范围包括100马力以下轮式拖拉机、甘蔗收获机、旋耕机和微耕机。

特此函复。

农业农村部办公厅

2019年2月25日
