# 关于解除法国禽流感疫情禁令的公告

## 海关总署　农业农村部公告

2019年第55号

## 关于解除法国禽流感疫情禁令的公告

根据风险分析结果，自本公告发布之日起，认可法国为禽流感无疫国家，原质检总局、原农业部2009年联合发布的第15号和第122号、2015年第150号公告对法国的禽流感疫情禁令同时终止。

本公告自发布之日起实施。

特此公告。

海关总署　农业农村部

2019年3月27日
