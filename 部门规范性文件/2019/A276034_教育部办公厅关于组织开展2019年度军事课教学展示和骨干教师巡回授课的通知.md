# 教育部办公厅关于组织开展2019年度军事课教学展示和骨干教师巡回授课的通知

教体艺厅函〔2019〕27号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局，部属各高等学校、部省合建各高等学校：

为深入贯彻全国教育大会精神，落实立德树人根本任务，进一步深化军事课教学改革，提高军事课教学质量，强化青少年学生国防观念和提升综合国防素质，培养德智体美劳全面发展的社会主义建设者和接班人，根据《教育部2019年工作要点》，教育部决定2019年度继续组织开展军事课教学展示和骨干教师巡回授课。请根据2019年度军事课教学展示和骨干教师巡回授课方案，精心组织、周密部署，认真抓好贯彻落实。

联系人及电话：教育部国防教育办公室，李钦鹏，010-66096474；教育部全国普通高等学校军事教学指导委员会，王沙骋，15010272353。

附件：1.2019年度军事课教学展示方案

2.2019年度军事课骨干教师巡回授课方案

3.2019年度军事课教学展示工作计划

4.2019年度军事课教学展示报名表

5.2019年度军事课骨干教师巡回授课计划

6.军事课骨干教师巡回授课推荐表

7.结对子义务“讲故事”推荐表

教育部办公厅

2019年3月27日
