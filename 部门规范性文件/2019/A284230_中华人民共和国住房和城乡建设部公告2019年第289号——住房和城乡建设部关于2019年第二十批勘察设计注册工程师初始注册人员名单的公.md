# 中华人民共和国住房和城乡建设部公告2019年第289号——住房和城乡建设部关于2019年第二十批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第289号

## 住房和城乡建设部关于2019年第二十批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，赵文涛等56名申请注册土木工程师（岩土）初始注册人员、杨利等48名申请一级注册结构工程师初始注册人员、李灿华等94名申请注册公用设备工程师初始注册人员、李洪波等44名申请注册电气工程师初始注册人员、邵华伟等8名申请注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予赵文涛等56名注册土木工程师（岩土）初始注册人员名单

2.准予杨利等48名一级注册结构工程师初始注册人员名单

3.准予李灿华等94名注册公用设备工程师初始注册人员名单

4.准予李洪波等44名注册电气工程师初始注册人员名单

5.准予邵华伟等8名注册化工工程师初始注册人员名单

住房和城乡建设部

2019年11月8日
