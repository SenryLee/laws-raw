# 农业农村部对十三届全国人大二次会议第6515号建议的答复

## 对十三届全国人大二次会议第6515号建议的答复

张清海代表：

您提出的关于尽快出台乡村振兴相关规定指导乡村规范、有序、科学发展的建议收悉。经商生态环境部，现答复如下。

一、关于加强村庄规划工作

习近平总书记强调，实施乡村振兴战略，要科学规划、注重质量、从容建设。去年，党中央、国务院印发的《乡村振兴战略规划（2018—2022年）》明确提出，顺应村庄发展规律和演变趋势，根据不同村庄的发展现状、区位条件、资源禀赋等，按照集聚提升、融入城镇、特色保护、搬迁撤并的思路，分类推进乡村振兴。今年中央一号文件提出，强化乡村规划引领，把加强规划管理作为乡村振兴的基础性工作。贯彻落实中央决策部署，中央农办、农业农村部、自然资源部等五部门联合印发了《关于统筹推进村庄规划工作的意见》，要求各地建立县级党委政府主要领导负责的乡村规划编制委员会，切实加强村庄规划编制工作的领导；逐村研究村庄人口变化、区位条件和发展趋势，合理划分村庄类型；加快推进村庄规划编制实施，统筹谋划村庄发展定位、主导产业选择、用地布局、人居环境整治、生态保护、建设项目安排等。力争到2019年底，基本明确集聚提升类、城郊融合类、特色保护类等村庄分类；到2020年底，有条件的村可结合实际单独编制村庄规划，做到应编尽编。

下一步，我们将会同有关部门，加快推动各地建立健全县级党委政府负责的乡村规划工作机制，逐村研究村庄人口变化、区位条件和发展趋势，合理划分县域村庄类型，科学编制县域村庄布局规划和“多规合一”实用性村庄规划，努力做到不规划不建设、不规划不投入。

二、关于加快推进乡村产业振兴

习近平总书记强调，产业兴旺是解决农村一切问题的前提。近年来，党中央、国务院高度重视乡村产业发展，不断强化顶层设计，加大支持力度，促进乡村产业持续健康发展。一是强化产业发展发展指导。近日，国务院专门印发了《关于促进乡村产业发展的指导意见》，明确了促进乡村产业振兴的总体要求，提出了乡村产业发展重点任务和政策措施，制定了促进农产品加工业发展、休闲农业和乡村旅游发展、返乡下乡人员创业创新等政策文件，出台了一系列减免税收、金融信贷、科技支撑、用地用电等务实管用的扶持政策，为推进乡村产业发展提供政策保障。二是大力发展农产品加工业。深入推进农产品加工业提升行动，建设了15.6万座初加工设施，新增初加工能力1000万吨，果蔬等农产品产后损失率从15%降至6%，农产品精深加工快速发展。2018年，规模以上农产品加工企业7.9万家、营业收入14.9万亿元，农产品加工业和农业总产值比达到2.3：1。三是不断丰富乡村产业类型。实施休闲农业和乡村旅游精品工程，推介一批休闲农业和乡村旅游精品品牌，2018年休闲农业和乡村旅游接待游客30亿人次、营业收入超过8000亿元。大力发展农产品电子商务，农村网络销售额突破1.3万亿元，其中农产品网络销售额达3000亿元。创新发展乡村服务业，支持开展农资供应、代耕代种、统防统治、烘干收储等生产性和生活性服务业，农村生产性服务业营业收入超过2000亿元。四是打造产业发展平台载体。支持建设国家现代农业产业园114个、国家农业科技园32个、农产品加工园1600个，创建农村产业融合示范园148个、农业产业强镇254个，推广农业内部循环融合、产业延伸融合、功能拓展融合、新技术渗透融合、产村融合和复合型融合等多种融合模式。五是积极支持农村创业创新。认定农村创新创业园区和实训孵化基地1096个，制定并落实支持返乡下乡人员创新创业政策，吸引农民工、大中专毕业生、退役军人、科技人员等到乡村创新创业。截止2018年，各类返乡下乡创新创业人员累计达780万，“田秀才”“土专家”“乡创客”等本乡创新创业人员达3100多万。

下一步，我部将会同有关部门认真贯彻落实中央部署要求，优化产业空间布局，发展壮大新型经营主体，强化乡村产业发展用地、资金、人才等要素保障，着力打造现代农业产业园、产业融合示范区等产业发展载体，大力推进农村一二三产融合发展，加快构建彰显地域特色、体现乡村气息、承载乡村价值、适应现代需要的乡村产业体系。

三、关于健康有序推进乡村振兴

习近平总书记强调，实施乡村振兴战略，首先要按规律办事。在我们这样一个拥有13亿多人口的大国，实现乡村振兴是前无古人、后无来者的伟大创举，没有现成的、可照抄照搬的经验。我国乡村振兴道路怎么走，只能靠我们自己去探索。《乡村振兴战略规划（2018—2022年）》细化实化了乡村振兴各项工作，是各级各部门推进乡村振兴战略实施的总蓝图。一是在发展目标上，规划明确了未来五年乡村振兴的阶段性目标，既要在农村全面实现小康，又要为基本实现农业农村现代化开好局、起好步、打好基础。提出到2020年，乡村振兴制度框架和政策体系基本形成；到2022年，乡村振兴制度框架和政策体系初步健全。同时，规划还对到本世纪中叶的乡村振兴目标，分两个阶段作了远景谋划，即到2035年，乡村振兴取得决定性进展，农业农村现代化基本实现；到2050年，乡村全面振兴，农业强、农村美、农民富全面实现。二是在空间布局上，规划提出要构建乡村振兴新格局，对统筹城乡发展空间、优化乡村发展布局、分类推进乡村发展、打好精准脱贫攻坚战作出了安排。其中，统筹城乡发展空间就是要按照主体功能定位，对国土空间的开发、保护和整治进行总体规划，完善城乡布局结构，加快形成城乡融合发展的空间格局。优化乡村发展布局就是要打造集约高效生产空间，营造宜居适度生活空间，保护山青水秀生态空间。分类推进乡村发展就是要根据不同村庄的发展现状、区位条件、资源禀赋等，将村庄划分为集聚提升、城郊融合、特色保护、搬迁撤并4种类型，分类推进乡村振兴，防止大拆大建、千村一面。三是在区域重点上，规划提出要梯次推动乡村振兴，东部沿海发达地区、人口净流入城市的郊区、集体经济实力强以及其他具备条件的乡村，到2022年率先基本实现农业农村现代化；中小城市和小城镇周边以及广大平原、丘陵地区的乡村，到2035年基本实现农业农村现代化；革命老区、民族地区、边疆地区、集中连片特困地区的乡村，到2050年如期实现农业农村现代化。

您提出的城乡一体化、新型城市化等与乡村振兴的关系问题，习近平总书记多次强调，要坚持工业农业一起抓，城市农村一起抓，把农业农村优先发展的要求落到实处，并明确提出“四个优先”。今年5月，中央出台了建立健全城乡融合发展体制机制和政策体系的意见，明确推动城乡融合发展“三步走”战略目标，强调以完善产权制度和要素市场化配置为重点，加快建立健全要素合理配置、公共服务普惠共享、基础设施一体化等5方面体制机制。我们学习理解，推进乡村振兴，核心是重塑工农城乡关系，扭转长期以来“重工轻农、重城轻乡”的思维定势，打破城乡二元分割的体制藩篱，做到以工促农、以城带乡，推动城乡要素平等交换、公共资源均衡配置，真正建立起向农村倾斜的城乡融合发展体制机制。

四、关于农村污水处理

农村生活污水治理作为农村人居环境整治的重要基础性工作，不仅直接决定着农村改厕、垃圾治理、村容村貌提升等方面的进度和成效，而且需要建设大量基础设施、综合运用工程和生化技术、协调多方关系。《农村人居环境整治三年行动方案》提出，今明两年目标是加强人口聚集区、中心集镇、生态功能区等区域的处理设施和管道建设，根据区域位置、人口居住聚集程度等实际情况，因地制宜推广四种模式：一是纳入城镇污水管网治理模式，主要针对人口分布相对集中、管网建设较为完善的建制镇，通过延伸排污管道，将集镇周边距离较近的村庄生活污水纳入管网统一处理。二是联户治理模式，主要针对人口相对较多且集中分布、距离集镇较远的村组，以整村、整组或数十户农户为单元，铺设区域排污管道，通过污水处理一体化设备等方式，处理农村生活污水。三是单户治理模式，主要针对人口相对较少且分布较为分散的偏远村庄，建设污水处理设施处理单一农户生活污水。四是人工湿地污水处理模式，结合农田灌溉、生态保护修复和环境景观建设，推进污水资源化利用，实现生活污水治理与生态农业发展、农村生态文明建设的多赢。

目前，生态环保部已印发《关于加快制定地方农村生活污水处理排放标准的通知》《农村生活污水处理设施水污染物排放控制规范编制工作指南（试行）》，要求各地根据农村自然条件、经济发展水平、村庄人口聚焦程度、污水产生规模、排放去向和环境质量改善需求，按照“分区分类、宽严相济、回用优先、注重实效、便于监管”原则，科学合理确定控制指标和排放限值，并针对地方农村生活污水处理排放标准控制指标选取不合理、排放限值过宽等重点问题，对排放标准控制指标确定、污染物排放限值、尾水利用要求、采样监测要求等作了明确细化。

下一步，我们将会同生态环境部等有关部门，加快制定农村生活污水处理排放标准；探索将高标准农田、农田水利建设与农村生活污水治理相结合，统一规划、一体设计；合理确定投融资模式和运行管护方式，探索规模化、专业化、社会化运营机制。

五、关于推进农村厕所革命

习近平总书记指出，厕所问题不是小事情，要把这项工作作为乡村振兴战略的一项具体工作来推进。2018年12月，中央农办、农业农村部、财政部等8部委印发《关于推进农村“厕所革命”专项行动的指导意见》，具体部署农村户用卫生厕所改造、农村公共厕所建设、厕所粪污处理等3项任务。2019年4月，财政部、农业农村部联合印发《关于开展农村“厕所革命”整村推进财政奖补工作的通知》，明确中央财政专门安排资金，计划用5年左右的时间，通过以奖补方式支持和引导各地推动有条件的农村普及卫生厕所，实现厕所粪污基本得到处理和资源化利用；中央财政统筹考虑不同区域经济发展水平、财力状况、基础条件，结合阶段性改厕工作计划，实行东中西部差别化奖补标准，并向中西部地区倾斜。

今明两年目标是在东部地区、中西部城市近郊区等有基础、有条件的地区，基本完成农村户用厕所无害化改造，厕所粪污基本得到处理或资源化利用；中西部有较好基础、基本具备条件的地区，力争实现卫生厕所普及率达到85%左右。技术模式重点推广三格式粪池厕所、双瓮漏斗式厕所、三联沼气式厕所、粪尿分集式生态厕所、双坑交替式厕所、具有完整下水道的水冲式厕所等6种模式，有条件的农户可增加盥洗、淋浴、粪污无害化处理等设施。2019年度中央财政将安排70亿奖补资金，采取整村推进模式，整村规划设计，整体组织发动。

下一步，我们将会同有关部门，对标三年行动目标要求，注重提高改厕质量，突出抓好粪污治理，强化督查问责，逐级压实责任、层层传导压力，确保完成农村“厕所革命”目标任务。

感谢您对推进乡村振兴战略实施工作的关心，希望继续对我部的工作给予支持。
