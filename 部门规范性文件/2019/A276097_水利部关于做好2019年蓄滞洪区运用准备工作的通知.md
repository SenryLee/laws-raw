# 水利部关于做好2019年蓄滞洪区运用准备工作的通知

水防〔2019〕106号

北京、天津、河北、吉林、黑龙江、江苏、安徽、江西、山东、河南、湖北、湖南、广东省，（直辖市）水利（水务）厅（局），有关流域管理机构：

据预测，今年汛期我国气候状况总体偏差，极端天气气候事件偏多，部分流域可能发生较大洪水，防汛形势严峻。请你们立足于防大汛、抗大洪、按照水利部“水利工程补短板、水利行业强监管”的水利改革发展总基调要求，坚持底线思维，强化风险意识，全面做好2019年蓄滞洪区运用准备工作。

一、切实落实责任

蓄滞洪区分洪运用事关人民生命财产安全，涉及部门多。要强化蓄滞洪区防汛行政首长负责制，加强各部门之间的协作配合，将责任落实到监测预警、指挥调度、分洪运用、巡查值守、转移安置等各个环节。尤其要落实好预报与预警责任人，做好监测预报和预警发布工作；落实好工程运用责任人，做好进退洪闸的启闭或进退洪口门的爆破、扒口等指挥协调工作；逐级落实好人员转移责任人，做好人员转移的组织协调工作，确保蓄滞洪区能够及时安全有效运用。

二、修订运用预案

要根据蓄滞洪区社会经济发展情况、人口情况和工程变化情况，按照《蓄滞洪区运用预案编制导则》的有关规定，组织修订完善蓄滞洪区运用预案，细化落实组织与保障、预报与预警、工程调度与运用、人员转移与安置等各项具体措施，切实提高预案的时效性、实用性和可操作性，并抓紧完成审批工作。按照《蓄滞洪区运用补偿暂行办法》等有关规定，做实做细蓄滞洪区居民财产登记及变更登记工作。要视情组织蓄滞洪区运用预案演练，重点演练预报与预警、工程调度与运用、人员转移与安置等内容，以模拟演练为主，辅以宣传教育，强化应急准备，提高应急响应能力。请有关省（直辖市）水利（水务）厅（局）于5月15日前将辖区内国家蓄滞洪区的运用预案和居民财产登记报有关流域管理机构，流域管理机构汇总后于5月底前将运用预案报水利部备案。

三、开展隐患排查

要根据重要蓄滞洪区、一般蓄滞洪区和蓄滞洪保留区的特点，分类排查蓄滞洪区分洪运用隐患。要在5月底前完成汛前检查，重点检查通讯预警设施是否完善，围堤、分区运用隔堤和安全设施等工程运行状况是否良好，进（退）洪闸启闭是否灵活、供电设备是否可靠，爆破扒口分洪位置、作业人员和机械是否落实，人员转移预案是否落实，运用预案修订和演练是否到位，财产登记是否完成等。要全面排查蓄滞洪区内缺乏防洪保护措施的县级及以上城市（经济开发区、科技园）、国家重要的大型基础设施、大型骨干企业和全国重点文物保护单位，以及区内是否有污染严重的化工工厂和储仓等隐患。要针对排查出的各个隐患，逐个蓄滞洪区下发整改清单，明确任务，落实责任，力争汛前完成隐患整改。对于汛前确实难以整改完成的隐患，要督促落实应急度汛措施或应急预案，确保防洪安全。

四、加强监测预警

要修订完善涉及蓄滞洪区运用的江河主要断面洪水预报方案，做好有关断面水位、流量的监测预报工作。落实预警发布机构和发布方式，检修通讯预警设施，畅通预警信息传递渠道。根据防洪调度决策，提前发布预警信息。充分发挥“县包乡、乡包村、村包组、党员干部包群众”的包保责任作用，利用广播电视、铜锣、报警器等传统方式和新媒体、短信平台、微信公众号等现代化手段，做到预警信息传递横向到边、纵向到底，确保“不落一户、不漏一人”。

五、落实人员转移

蓄滞洪区所在地要根据蓄滞洪区运用预案，按照就近原则，逐户落实转移路线、安置地点、责任人、联系人、转移交通工具等。根据流域防洪实际，重点做好国家重要蓄滞洪区和运用频率高、分洪预见期短的一般蓄滞洪区，以及京津冀等重要地区的蓄滞洪区人员转移工作。对防洪调度决策即将运用的蓄滞洪区，要采取交通、治安管制等措施，实行拉网式排查，确保区内人员全部安全转移。

六、做好工程运用准备

请有关省（直辖市）水利（水务）厅（局）组织于5月底前做好蓄滞洪区围堤、分区运用隔堤、安全设施和进（退）洪闸等工程运用准备。对于建闸控制分洪的蓄滞洪区，认真落实进（退）洪闸启闭和供电设备保障措施，保证闸门可以根据需要合理控制开度、适时适量分洪。对于采取爆破扒口分洪的蓄滞洪区，要督促当地和有关单位提前落实爆破扒口分洪准备，明确分洪位置、实施队伍、联络方式、责任人等，确保分洪安全。
