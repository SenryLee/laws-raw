# 自然资源部办公厅关于启用自然资源部政务服务专用章的通知

自然资办函〔2018〕2033号

各省、自治区、直辖市自然资源主管部门，新疆生产建设兵团自然资源主管部门，国家林业和草原局，中国地质调查局，部机关各司局、各相关单位：

根据工作要求， “自然资源部政务服务专用章”自2019年1月1日起生效，原“中华人民共和国国土资源部政务服务专用章”（主章1枚，分章1枚）、“国土资源部政务大厅业务专用章”“国家海洋局政务服务专用章”“国家海洋局行政许可专用章”“国家测绘地理信息局行政许可专用章（1）”“国家测绘地理信息局行政许可专用章（2）”“国家测绘地理信息局行政许可专用章（3）”“国家测绘地理信息局地图审核专用章”废止。
