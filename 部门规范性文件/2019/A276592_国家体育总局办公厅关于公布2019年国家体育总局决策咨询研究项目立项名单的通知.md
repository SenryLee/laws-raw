# 国家体育总局办公厅关于公布2019年国家体育总局决策咨询研究项目立项名单的通知

## 体育总局办公厅关于公布2019年国家体育总局决策咨询研究项目立项名单的通知

有关大专院校、科研院所，有关单位，有关专家学者：

根据《国家体育总局决策咨询研究项目管理办法》，经专家评审、社会公示，最终确定了2019年国家体育总局决策咨询研究立项项目72项（其中重大项目12项，重点项目31项，一般项目29项）。现将立项名单（见附件）正式公布。

请各立项项目负责人，登录国家体育总局决策咨询项目管理系统（http://zfs-system.sports.cn/），下载并填写《计划任务书》，经所在单位科研管理部门审核盖章后，于5月5日前通过挂号信或邮政快递（EMS）将材料报送至国家体育总局政策法规司理论处。《计划任务书》经政策法规司审定后，即作为国家体育总局决策咨询研究项目的正式协议。
