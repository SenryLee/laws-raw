# 商务部关于印发《2019年度甘草及其制品出口配额第一次招标中标企业名单及其中标额度表》的通知

商贸批〔2019〕第5号

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门：

根据《出口商品配额招标办法》及《工业品出口招标实施细则》的有关规定，出口商品配额招标委员会对2019年度甘草及甘草制品出口配额进行了第一次招标，并确定了中标企业及其中标数量。现将《2019年度甘草及甘草制品出口配额第一次招标中标企业名单及其中标额度表》印发给你们，请各中标企业凭商务部下达的中标企业、中标数量及招标委员会下发的《申领配额招标商品出口许可证证明书》申领出口许可证，请各有关发证机关严格按照相关规定核发出口许可证。

附件：2019年度甘草及甘草制品出口配额第一次招标中标企业名单及其中标额度表

商务部

2019年1月3日
