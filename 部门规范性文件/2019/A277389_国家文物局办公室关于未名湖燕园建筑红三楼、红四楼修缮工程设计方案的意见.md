# 国家文物局办公室关于未名湖燕园建筑红三楼、红四楼修缮工程设计方案的意见

办保函〔2019〕346号

北京市文物局：

你局《关于未名湖燕园建筑红三楼、红四楼修缮工程设计方案的请示》（京文物〔2019〕62号）收悉。经研究，我局暂不同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步深化现状勘查，补充历次修缮加固资料及屋面、脊饰及“通风屋脊”等的现状勘查情况。同时，进一步研究外立面油饰、彩画的原工艺、原做法，并明确油漆类型、成分、颜色等内容。

（二）应加强研究，分析历次修缮工程和历史资料，考证建筑屋面原始做法，重新制定保护措施。应以现有梁架加固补强为主，尽量保持原有结构体系及构件，减小屋面荷载，确保文物建筑价值、真实性及文物建筑安全。

（三）细化油饰和彩画的具体工艺做法。

（四）建议对建筑基础形式、埋深和地基持力层、土体现状进行勘察评价，确保文物建筑安全。

二、请你局指导方案设计单位，根据上述意见对所报方案作进一步修改和完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年5月5日
