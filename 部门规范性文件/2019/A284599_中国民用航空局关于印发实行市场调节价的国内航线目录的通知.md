# 中国民用航空局关于印发实行市场调节价的国内航线目录的通知

## 关于印发实行市场调节价的国内航线目录的通知

民航综计发〔2019〕3号

各运输航空公司：

根据《民航国内航空运输价格改革方案》（国家发展改革委、民航总局公告2004年18号）、《关于深化民航国内航空旅客运输票价改革有关问题的通知》（民航发[2016]110号）、《关于进一步推进民航国内航空旅客运输价格改革有关问题的通知》（民航发[2017]146号）的有关规定，经商国家发展改革委，现将实行市场调节价的国内航线目录印发给你们，请认真遵照执行。

附件：实行市场调节价的国内航线目录

民航局综合司

2019年11月26日
