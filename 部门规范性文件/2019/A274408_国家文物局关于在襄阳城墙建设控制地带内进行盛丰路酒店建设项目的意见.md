# 国家文物局关于在襄阳城墙建设控制地带内进行盛丰路酒店建设项目的意见

文物保函〔2019〕155号

湖北省文化和旅游厅：

原湖北省文物局《关于报送襄阳城墙建设控制地带内盛丰路酒店项目建筑设计及文物影响评估报告的请示》（鄂文物〔2018〕41号）收悉。经研究，我局原则同意在襄阳城墙建设控制地带内进行盛丰路酒店建设项目。

一、建议所报方案适当调整建筑总平面布局，避免尺度过大的连续体量。实施前应对北部拟建区域进行全面的考古调查勘探。

二、请你厅指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你厅会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月14日
