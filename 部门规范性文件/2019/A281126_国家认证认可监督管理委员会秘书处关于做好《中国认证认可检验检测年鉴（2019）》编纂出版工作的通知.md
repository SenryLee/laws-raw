# 国家认证认可监督管理委员会秘书处关于做好《中国认证认可检验检测年鉴（2019）》编纂出版工作的通知

## 认监委秘书处关于做好《中国认证认可检验检测年鉴（2019）》编纂出版工作的通知

认秘函〔2019〕8号

各省、自治区、直辖市及新疆生产建设兵团市场监管局（厅、委），各认证认可检验检测机构，各相关单位：

2018年，全国认证认可检验检测战线认真贯彻落实党中央、国务院的决策部署和市场监管总局的工作要求，以服务供给侧结构性改革和"放管服"改革为主线，切实发挥认证认可"传递信任，服务发展"的本质属性，在提高供给质量、深化改革创新、完善工作机制、加强自身建设等方面取得新的成绩，为加强市场监管、优化营商环境、建设质量强国做出了新贡献。为了全面反映我国认证认可检验检测事业发展所取得的成就和经验，请各单位在总结工作的基础上，认真做好《中国认证认可检验检测年鉴（2019）》（以下简称《年鉴（2019）》）的组织编纂工作。现将有关事项通知如下：

一、编纂任务

请各单位按照《年鉴（2019）》大纲和编写体例（见附件1和附件2），指定人员撰写文稿并提供资料，按时完成供稿任务。各单位要本着实事求是、对历史负责的精神，认真撰写本单位、本部门工作情况的文字材料。同时提供1-2幅反映本单位重点工作的彩色新闻图片（配相应的文字说明）。

二、工作要求

（一）年鉴的编纂出版是一项公益事业，对我国认证认可事业的长远发展具有积极意义。各单位要高度重视，明确专人负责，认真组织部署，对《年鉴（2019）》的编纂出版以及图文专栏资料征集方面予以积极支持配合。

（二）请于9月30日前将以上稿件资料报送年鉴编辑部，并注明撰稿人和审稿人姓名。
