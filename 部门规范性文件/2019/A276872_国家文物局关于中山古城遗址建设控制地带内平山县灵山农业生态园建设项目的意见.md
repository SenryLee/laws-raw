# 国家文物局关于中山古城遗址建设控制地带内平山县灵山农业生态园建设项目的意见

文物保函〔2019〕403号

河北省文物局：

你局《关于呈报平山县灵山农业生态园项目涉及中山古城遗址建设控制地带设计方案的请示》（冀文物字〔2019〕7号）收悉。经研究，我局原则同意在中山古城遗址建设控制地带内实施平山县灵山农业生态园建设项目。

一、拟建项目应统筹考虑与中山古城考古遗址公园的关系，补充农业生态园与中山古城考古遗址公园在价值阐释、功能分区和设计理念等方面的关系；注意保持西灵山与中山古城的景观廊道，细化林山四号窟周边区域设计内容；研提项目建设运营对考古遗址公园的回馈机制。应严格控制工程范围和施工强度，做好施工中的文物保护工作，确保文物安全。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年4月28日
