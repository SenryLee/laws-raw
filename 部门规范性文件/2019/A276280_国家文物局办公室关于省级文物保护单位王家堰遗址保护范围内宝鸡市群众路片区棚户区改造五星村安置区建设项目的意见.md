# 国家文物局办公室关于省级文物保护单位王家堰遗址保护范围内宝鸡市群众路片区棚户区改造五星村安置区建设项目的意见

办保函〔2019〕268号

陕西省文物局：

你局《关于宝鸡市群众路片区棚户区改造五星村安置区项目选址涉及王家堰遗址保护范围的请示》（陕文物字〔2019〕44号）收悉。经研究，我局意见如下：

一、暂不同意在省级文物保护单位王家堰遗址保护范围内实施宝鸡市群众路片区棚户区改造五星村安置区建设项目。

二、请你局督促地方政府落实主体责任，进一步核实文物保护区划与拟建项目的关系，明确相应管理规定，充分论证项目实施的必要性与可行性，保护范围内原则上不得进行其他建设工程。

专此函复。

国家文物局办公室

2019年4月8日
