# 国家文物局办公室关于同意福建景翔建设工程有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕967号

福建省文物局：

你局《关于福建景翔建设工程有限公司申请资质证书内容变更的请示》（闽文物字〔2019〕395号）收悉。

经研究，我局同意福建景翔建设工程有限公司文物保护工程施工一级资质证书中的单位地址由“福州市晋安区新店镇西庄支路健康村综合楼2号楼5-6层”变更为“福建省福州市晋安区新店镇西庄1号福州金城民营工业集中区配套设施项目1#综合楼5层”，法定代表人由“林卓群”变更为“高长坚”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年11月8日
