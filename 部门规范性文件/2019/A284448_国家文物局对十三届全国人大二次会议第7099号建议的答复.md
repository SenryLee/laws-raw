# 国家文物局对十三届全国人大二次会议第7099号建议的答复

文物政函〔2019〕687号

汪其德代表：

您提出的“关于加强川陕苏区红色资源保护推动红色旅游融合发展助力脱贫攻坚的建议”收悉。经商文化和旅游部、财政部、国家发展改革委，现答复如下。

川陕苏区的革命文物类型丰富、特色鲜明，是中国共产党光荣历史的实物见证，是传承红色基因、发展红色旅游、助力川陕地区脱贫攻坚、促进革命老区振兴发展的重要资源。中央相关部门将以深入贯彻落实中共中央办公厅、国务院办公厅《关于实施革命文物保护利用工程（2018-2022年）的意见》为重要抓手，统筹推进川陕苏区的革命文物保护利用，加强组织指导，加大支持力度。

关于您提出的加大政策支持力度建议，2019年3月，中央宣传部、财政部、文化和旅游部、国家文物局公布了第一批革命文物保护利用片区分县名单，确定了川陕革命文物保护利用片区，其中涉及四川省巴中、达州、南充、广元、绵阳5个市34个县。四部门正在研究编制第二批革命文物保护利用片区分县名单，将统筹考虑川陕地区红军长征革命史实，将有关市县纳入红军长征革命文物保护利用片区。巴中市红色旅游资源丰富，具有打造精品文化和旅游产品的良好基础。文化和旅游部鼓励巴中市参照5A级景区相关标准要求提升服务质量、突出自身特色、保持红色风貌、弘扬革命精神，重点在软件服务要素填充方面下功夫，走优质旅游景区建设之路；支持王坪景区创建国家5A级旅游景区，将在四川省文化和旅游厅初检的基础上，按程序组织开展相关工作，并酌情对创建工作予以指导。

关于您提出的加大资金支持力度建议，国家文物保护专项资金统筹加大对革命文物保护支持力度，中央财政不再设立专项资金。2018年12月，财政部、国家文物局修订公布了《国家文物保护专项资金管理办法》，明确提出国家文物保护专项资金适当向革命老区倾斜，向党中央、国务院确定的重点支持方向革命文物保护倾斜，将省级及省级以下文物保护单位保护纳入支持范围。2019年，中央财政安排的国家文物保护专项资金中，有专门资金支持实施一批革命文物保护项目，通过一般性转移支付对革命老区予以补助。中央财政积极支持红色旅游扶贫工作，释放旅游扶贫富民效能。2016年，巴中市、达州市、广元市、南充市14处红色旅游景区被列入《全国红色旅游经典景区名录》。“十三五”期间，国家发展改革委通过文化旅游提升工程，安排中央预算内投资近亿元支持川陕地区9个红色旅游景区项目。财政部、文化和旅游部通过国家红色旅游专项建设资金、全国红色旅游公路专项资金，支持川陕革命老区的红色旅游和旅游扶贫相关项目。下一步，中央财政将继续通过现有资金渠道，支持革命老区的红色旅游和旅游扶贫工作，推进红色旅游与经济社会融合发展，为坚决打赢精准脱贫攻坚战作出积极贡献。

关于您提出的加大项目支持力度建议，财政部、国家文物局支持以川陕革命文物保护利用片区为工作重点，加强统筹规划，把握实施重点，实施一批、完工一批、储备一批革命文物保护利用项目，切实改善革命文物保存状况，有效提升革命文物展示陈列和传播传承水平。国家发展改革委支持将川陕革命根据地红军烈士陵园、川陕革命根据地博物馆、宣达战役纪念馆、红军攻克剑门关遗址、黄猫垭战役遗址等项目列入《全国红色旅游经典景区三期总体建设方案》。文化和旅游部支持开发川陕苏区旅游资源，推出红色旅游精品线路，打造红色文旅品牌项目，将川陕革命老区纳入红色旅游人才培训计划，提供全国性旅游展会及推广活动的免费展示平台。

感谢您对革命文物工作的关心和支持。

国家文物局

2019年7月10日
