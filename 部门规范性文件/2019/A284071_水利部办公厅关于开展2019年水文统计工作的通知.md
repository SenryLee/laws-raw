# 水利部办公厅关于开展2019年水文统计工作的通知

办水文函〔2019〕1201号

各流域管理机构，各省、自治区、直辖市水利（水务）厅（局），新疆生产建设兵团水利局：

水文统计是水文行业管理的一项重要基础工作。统计成果将为制定水文行业政策、开展行业管理等提供基础信息和科学依据。根据国家有关统计管理规定，为切实做好2019年水文统计工作，现将有关事项通知如下：

1. 各单位要高度重视、依法开展水文统计工作，认真组织部署，明确牵头部门和负责人员，做好内部分工协调，严格规范统计行为，切实提高统计质量。

2. 各单位要组织统计人员认真学习《全国水文情况统计调查制度》（见附件，以下简称调查制度），对照填报说明，按要求及时填报11张综合表；要组织对统计信息进行全面审核，杜绝错报漏报，确保统计成果的真实、准确和完整。

3. 请各单位于2020年1月31日前，按以下两种方式报送统计成果：

（1）调查制度经单位负责人审定后，通过水利政务外网登录“全国水文站网管理系统”，在“水文统计年报”模块中进行录入（网址：http://10.1.7.101:81/）。

（2）同时，填报完成的调查制度以公文形式报送我部。
