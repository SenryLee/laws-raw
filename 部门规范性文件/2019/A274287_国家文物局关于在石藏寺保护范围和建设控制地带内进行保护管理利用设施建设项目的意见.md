# 国家文物局关于在石藏寺保护范围和建设控制地带内进行保护管理利用设施建设项目的意见

文物保函〔2019〕88号

青海省文物管理局：

你局《关于石藏寺建设项目工程设计方案的请示》（青文物局〔2018〕167号）收悉。经研究，我局原则同意石藏寺保护范围和建设控制地带内巡护道路、旱厕、排水管道、界桩等建设项目，暂不同意新建业务用房。

一、所报方案尚需作以下必要的修改和完善：

（一）补充论证巡护道路设置防腐木栏杆的必要性。根据周围环境和地质条件分段分类设计巡护道路，尽量压缩巡护道路的宽度，减少带有木制栏杆的木栈道长度。可选择自然块石路面等方式，尽量减小对石藏寺环境的扰动。

（二）新建业务用房选址依据不足，暂不同意在寺院内新建业务用房，建议优先考虑利用寺院现有非文物建筑。

（三）合理设置保护界桩的数量和位置，明确标识文物保护范围。

（四）施工期间应做好对文物本体的防护措施，控制粉尘及施工垃圾等对文物本体及环境的污染。

（五）进一步细化方案设计，校核文本，避免前后矛盾。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月23日
