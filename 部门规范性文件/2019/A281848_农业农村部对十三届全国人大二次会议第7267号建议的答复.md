# 农业农村部对十三届全国人大二次会议第7267号建议的答复

## 对十三届全国人大二次会议第7267号建议的答复

农办议〔2019〕274号

万连步等14名代表：

你们提出的关于支持减肥增效技术创新，推动农业绿色发展的建议收悉。经商财政部，现答复如下。

一、关于突出企业创新主体地位，加快绿色投入品关键技术突破

一直以来，中央高度重视企业创新并积极支持农业领域的科研工作。一是加强顶层设计。财政部会同科技部等通过中央财政科技计划（专项、基金等）对符合条件的科研活动进行支持。如支持实施国家重点研发计划"化学肥料和农药减施增效综合技术研发"等重点专项，开展农业领域相关的科学研究，符合条件的科研院所、企业等可按程序申报相关项目并开展研发工作。二是改善科研条件。中央财政通过基本运行经费、基本科研业务费、中央级科学事业单位修缮购置专项资金、国家重点实验室专项经费等，加大对农业领域中央级科研院所、国家重点实验室稳定支持力度，支持其改善科研基础条件、自主开展研究等，相关企业和单位可根据工作实际，开展农业领域相关科研工作。三是加快技术创新。2016年，我部成立国家化肥减量增效科技创新联盟和高效复合肥国家农业科技创新联盟。通过联合行业内专家、大型肥料生产企业和推广部门，打造科企合作平台，推动相关新产品、新技术的研发、转化和推广应用。四是深化农企合作。2016年以来，我部推动各级农业农村部门通过农企合作等方式，加强与相关肥料企业的协作，在不同区域、不同作物上开展化肥减量增效技术示范和推广，促进了新型高效肥料的应用。

下一步，农业农村部将积极配合有关部门，开展以下工作。一是结合"化学肥料和农药减施增效综合技术研发"国家重点研发计划试点专项，支持企业和科研机构开展新型高效肥料技术研发、成果转化和推广应用工作。二是推进集成创新，结合化肥使用量零增长行动和果菜茶有机肥替代化肥行动，推广应用新型肥料产品，集成组装一批可复制、易推广的技术模式。三是财政部门也将积极发挥财政职能作用，继续做好对农业领域相关科研工作的支持。

二、关于建立示范基地，通过试点作用带动农业绿色投入品的推广

中央财政通过农业生产发展资金、农业资源及生态保护补助资金，推广应用新型肥料，促进农业绿色发展。一是加快政策引导。2015年，我部印发《到2020年化肥使用量零增长行动方案》，明确要求适应现代农业发展需要，引导肥料产品升级，优化氮、磷、钾配比，促进大量元素与中微量元素配合，大力推广缓释肥料、水溶性肥料、液体肥料、叶面肥、生物肥料等高效新型肥料。二是加强示范基地建设。突出东北和黄淮海玉米产区、北方设施蔬菜集中产区、南菜北运基地、黄土高原和渤海湾苹果优势产区，创建300个化肥减量增效示范县（市），每个县补助200万元，集中展示化肥减量增效集成技术，带动大面积推广应用。三是加大资金支持力度。2015年以来，每年安排资金开展化肥使用量零增长行动。2017年以来，每年安排10亿元资金推进果菜茶有机肥替代化肥试点，支持农民和新型经营主体使用畜禽粪污资源化利用产生的有机肥，集中推广堆肥还田、商品有机肥施用、沼渣沼液还田、自然生草覆盖等技术模式。

下一步，农业农村部将会同财政部等部门，秉承创新发展、绿色发展、协调发展理念，进一步完善相关政策措施，促进生态农业发展。重点开展以下几项工作：一是推进产品创新。依托国家农业科技创新联盟，支持相关企业研发绿色投入品，完善产品技术标准，推动产业健康发展。二是加大推广力度。积极争取政策，加强化肥减量增效示范县建设，结合实施化肥使用量零增长、果菜茶有机肥替代化肥试点等项目，支持企业在适宜地区、适宜作物上推广应用新型高效肥料。三是推动企业开展农化服务。采取政府购买服务等方式，支持企业与新型农业经营主体合作，加快培育一批有技术、有实力的社会化服务组织，开展统配统施等生产性服务。

三、关于将减肥增效技术纳入新型职业农民培训，在国家重点项目中优先采用

近年来，我部高度重视新型职业农民培训，开展了一系列工作。一是加强农村实用人才队伍建设。我部每年面向全国遴选村组干部、种养大户、家庭农场主、农民合作社骨干等农村实用人才带头人和大学生村官，到我部农村实用人才培训基地考察参观、学习交流，帮助他们转变发展理念，掌握现代化种养殖技术，提升创业兴业、致富带富的能力。二是培育新型职业农民队伍。2018年，中央财政通过农业生产发展资金安排20亿元，支持新型职业农民培育。大力实施新型农业经营主体带头人轮训计划和现代青年农场主培养计划，开展农村实用人才带头人培训，加快培育一批"爱农业、懂技术、善经营"的新型职业农民，变"全面开花"为"重点推进".三是建立培育对象数据库。支持各地加强师资队伍建设，遴选一批培育示范基地、实训基地和田间学校，建立农业行政主管部门负责管理，农民科技教育培训中心、农民合作社、农业龙头企业、农业科研院所等各类市场主体参与的多元培育机制，变"政府培训"为"多元竞争".

下一步，我部将会同相关部门按照"科教兴农、人才强农、职业农民固农"的要求，整合教育培训资源，强化农村科技人才队伍建设，加快构建新型职业农民培养、认定、扶持相互衔接配套的新型职业农民培育制度，为现代农业发展提供人力支撑。进一步完善相关政策措施，继续开展新型职业农民培育工作，提高就业创业技能，助力乡村振兴和农业农村现代化。

感谢你们对农业农村工作的关心，希望今后对我部工作继续给予支持。
