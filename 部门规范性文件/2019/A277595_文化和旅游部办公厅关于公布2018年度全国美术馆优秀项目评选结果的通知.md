# 文化和旅游部办公厅关于公布2018年度全国美术馆优秀项目评选结果的通知

办艺发〔2019〕84号

各省、自治区、直辖市文化和旅游厅（局），新疆生产建设兵团文化体育广电和旅游局，中央军委政治工作部宣传局，中国美术馆、中国国家画院：

2018年度全国美术馆优秀项目评选工作已经顺利完成。经过专家小组认真评审，并经文化和旅游部审核与公示，共评选出优秀展览项目10个，优秀公共教育项目10个，优秀展览提名项目17个，优秀公共教育提名项目16个。现将上述项目名单予以公布。江苏省文化和旅游厅、山东省文化和旅游厅和广东省文化和旅游厅3家单位在此次活动的组织工作方面表现突出，被评为优秀组织单位。

特此通知。

附件：2018年度全国美术馆优秀项目名单

文化和旅游部办公厅

2019年5月24日
