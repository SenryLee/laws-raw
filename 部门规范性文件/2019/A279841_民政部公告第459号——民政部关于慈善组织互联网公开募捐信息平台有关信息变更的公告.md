# 民政部公告第459号——民政部关于慈善组织互联网公开募捐信息平台有关信息变更的公告

## 民政部公告

第459号

## 民政部关于慈善组织互联网公开募捐信息平台有关信息变更的公告

经审核，同意“阿里巴巴公益”平台的运营主体由浙江淘宝网络有限公司变更为阿里巴巴公益基金会，“蚂蚁金服公益”平台名称变更为“支付宝公益”。

特此公告。

民政部

2019年7月18日
