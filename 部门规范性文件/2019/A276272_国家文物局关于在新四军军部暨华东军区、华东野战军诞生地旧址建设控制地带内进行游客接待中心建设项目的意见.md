# 国家文物局关于在新四军军部暨华东军区、华东野战军诞生地旧址建设控制地带内进行游客接待中心建设项目的意见

文物保函〔2019〕320号

山东省文物局：

你局《关于新四军军部暨华东军区、华东野战军诞生地旧址建设控制地带内建设游客接待中心的请示》（鲁文发〔2019〕18号）收悉。经研究，我局原则同意在新四军军部暨华东军区、华东野战军诞生地旧址建设控制地带内进行游客接待中心建设项目。

一、所报项目方案尚需进一步优化完善：补充保护区划图及标明管理规定；在测算游客量并评估实际需求的基础上，进一步严格控制游客接待中心的建设规模；优化外观设计，补充必要的景观遮挡措施，避免对旧址及其周边环境产生不良影响；修改文物影响评估报告，应与设计方案工程内容一致。

二、请你局指导相关单位根据以上意见对所报项目方案进行修改，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。另，请督促地方人民政府抓紧落实相关保护规划的编制、报批工作，统筹协调文物保护、环境整治、展示利用及相关建设等工作内容。

专此函复。

国家文物局

2019年4月1日
