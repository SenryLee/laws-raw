# 生态环境部办公厅、商务部办公厅、科技部办公厅关于开展2019年度国家生态工业示范园区验收的通知

## 生态环境部办公厅　商务部办公厅　科技部办公厅关于开展2019年度国家生态工业示范园区验收的通知

环办科财函〔2019〕797号

天津子牙经济技术开发区、昆山高新技术产业开发区、嘉兴港区、芜湖经济技术开发区、潍坊经济开发区、鲁北集团公司、青岛经济技术开发区、珠海高新技术产业开发区、贵阳经济技术开发区、昆明经济技术开发区：

根据《国家生态工业示范园区管理办法》（环发〔2015〕167号）的有关要求，国家生态工业示范园区建设协调领导小组办公室（以下简称领导小组办公室）对你单位报送的申请验收材料进行了初审，拟于2019年10月起开展验收前的技术核查工作，并对通过技术核查的工业园区进行验收评审。

请各单位做好验收准备工作，对技术核查中发现的问题，抓紧整改，并及时向领导小组办公室提交整改后的验收材料及整改内容说明。请工业园区所在省（直辖市）生态环境、商务和科技行政主管部门指导园区做好验收各项准备，并参与验收工作。技术核查和验收评审具体时间另行通知。
