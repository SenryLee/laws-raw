# 国家能源局综合司关于同意十三陵上库坝等42座水电站大坝安全注册登记的复函

国能综函安全〔2019〕152号

大坝安全监察中心：

报来《关于十三陵上库坝等42座水电站大坝安全注册登记检查意见的请示》（坝监安监〔2019〕38号）收悉。经研究，函复如下。

一、同意四川周公河沙坪，贵州冗各、上尖坡等3座水电站大坝安全初始注册，注册登记等级均为甲级。

ニ、同意北京十三陵上库，河北张河湾上库、张河湾下库，山东泰安上库，青海苏只，甘肃盐锅峡、八盘峡，浙江桐柏上库、桐柏下库、紧水滩、石塘，重庆狮子滩、上硐、回龙寨、下硐、大洪河，四川瓦屋山、水津关、洛古、联补、地洛、江边，广东南水，广西洛东、叶茂，海南大广坝，云南大寨、鲁布革、漫湾、金汉拉扎，贵州红枫、百花、修文、窄巷口、红林、红岩、天生桥二级、团坡共38座水电站大坝安全换证注册，注册登记等级均为甲级。

三、同意广西麻石水电站大坝安全换证注册，注册登记等级为乙级。

请你中心继续做好以上水电站大坝安全注册登记及技术监督管理相关工作，配合有关派出能源监管机构督促各水电站大坝安全责任主体单位按照检査意见限期完成整改工作。

国家能源局综合司

2019年5月28日
