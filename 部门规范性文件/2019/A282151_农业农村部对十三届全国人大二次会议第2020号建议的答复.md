# 农业农村部对十三届全国人大二次会议第2020号建议的答复

## 对十三届全国人大二次会议第2020号建议的答复

农办议〔2019〕511号

郭建仁代表：

您提出的关于推进“净土行动”减少农田白色污染的建议收悉。经商财政部、工业和信息化部，现答复如下。

一、关于强化农膜源头监管

2017年，工业和信息化部会同我部、国家标准委等部门修订发布了《聚乙烯吹塑农用地面覆盖薄膜》强制性国家标准，2018年起正式实施，新标准提高了地膜厚度、拉伸强度和断裂伸长率，要求在产品合格证明显位置标有“使用后请回收利用，减少环境污染”的字样，从源头上提升了地膜的可回收性。2018年起我部将农膜列入全国农资打假专项治理行动重点工作，要求各地农业农村部门配合市场监管部门，依法打击非标地膜生产和销售，规范地膜销售市场。目前，我部正在起草制定《农用薄膜管理办法》，强化农膜生产、销售、使用、回收等环节的监管，建立全程监管体系，加强农膜回收利用的制度保障。下一步，我部将加快出台《农用薄膜管理办法》，强化新国标宣传贯彻，配合市场监管部门开展专项治理行动，依法打击非标地膜生产和销售。

二、关于对农膜原料成本给予补贴

我部高度重视农膜污染治理工作。从2017年起，实施农膜回收行动，以源头减量、回收利用和替代使用为重点，以加厚地膜应用、机械化捡拾、专业化回收、资源化利用为主攻方向，完善政策扶持，强化科技支撑，创新回收机制，加快推进农膜污染治理。在西北地区3个省区，建立了100个地膜治理示范县，整县推进、连片实施，落实以绿色生态为导向的补贴政策，推动补贴资金由补使用向补回收转变，建立健全地膜回收利用体系。对生产资料进行补贴是世界贸易组织的“黄箱”政策，而目前主要实行生态绿色补贴政策，重点要扶持农膜回收环节。2017年，我部开展“谁生产、谁回收”的地膜生产者责任延伸机制试点，选择在新疆、甘肃的4个县率先开展试点工作，探索将地膜回收责任由使用者转到生产者，农民由买产品转为买服务，推动将地膜回收与地膜使用成本联动，把以前由农户承担的回收责任由企业一并担起，实现“一条龙”服务，逐步建立基于市场主体的地膜回收利用长效机制。下一步，我部将深入实施农膜回收行动，加大地膜污染治理力度，继续开展生产者责任延伸机制试点，完善农膜回收利用补贴政策，推动农膜回收再利用工作。

三、关于对农膜回收企业加大补贴力度

我部高度重视地膜回收工作。2012—2015年，会同发展改革委、财政部在西北、华北、东北地区实施农业清洁生产示范项目，建设了近300个地膜清洁生产示范县，扶持建设废旧地膜回收加工企业400余家、回收网点近3000个。2017年，印发《农膜回收行动方案》，提出全国农膜回收网络不断完善，资源化利用水平不断提升，到2020年农膜回收利用率达到80%以上，“白色污染”得到有效防控的目标。从2017年起，选择100个覆膜面积10万亩以上的县，推动建立经营主体上交、专业化组织回收、加工企业回收、以旧换新等多种方式的回收利用机制，大力培育市场化、专业化的回收主体，加大对废旧农膜资源化再利用企业的扶持力度，不断完善废旧农膜回收利用体系，形成技术可推广、运营可持续、政策可落地、机制可复制的示范样板。2019年，中央财政安排10亿元，支持河北等省（区）开展旱作农业技术推广工作，要求各有关省份加强残膜回收，积极探索残膜污染防治方法，推行先回收利用后补助政策，杜绝超薄地膜进入农资市场。下一步，我部将继续落实《农膜回收行动方案》，做好试点工作，总结成功经验，加强对农膜回收利用企业的政策扶持，推动农膜污染防治工作。

四、关于政府支持农膜再利用产品推广

近年来，工业和信息部化积极推动废塑料资源化，会同相关部门编制发布了《关于加快推进再生资源产业发展的指导意见》，提出“十三五”时期废塑料资源化利用发展重点和发展目标，引导行业开展废塑料高值高质利用示范，提升塑料再生产品质量。制定发布《废塑料综合利用行业规范条件》，公布了34家符合规范条件的企业名单，培育废塑料综合利用骨干企业，发挥标杆企业引领示范作用，促进产业健康持续发展。发布废塑料等再生资源综合利用先进适用技术目录，鼓励企业加大废塑料资源化研发创新力度。下一步，将积极培育废塑料综合利用骨干企业，加强先进适用技术装备推广应用，推动废塑料综合利用产业绿色可持续发展。

五、关于大力鼓励支持地膜生产回收企业与科研机构合作

2017年起，我部推动建立了国家农业废弃物循环利用创新联盟，成立了农膜污染防控重点实验室，将农膜生产企业、废旧农膜回收利用企业、全生物降解地膜研发企业、有关科研院所、推广机构等纳入其中，开展联合科技攻关、技术示范和服务对接，重点解决废旧农膜回收和资源化再利用问题。依托我部现代农业产业技术体系，组建了地膜回收专家指导团队，对各地农膜回收网络建设和废旧农膜再利用工作给予技术指导。通过国家重点研发计划安排实施了残膜污染农田综合治理项目，加大残膜回收机具、地膜无害化处理技术等研发力度。下一步，我部将继续加大对农膜回收工作的支持力度，强化科技支撑，发挥产业技术体系优势，服务农膜回收与再利用行业发展。

感谢您对地膜污染治理工作的关心，希望继续对我部工作给予支持。
