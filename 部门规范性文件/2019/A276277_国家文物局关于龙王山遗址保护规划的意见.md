# 国家文物局关于龙王山遗址保护规划的意见

文物保函〔2019〕329号

湖北省文化和旅游厅：

原湖北省文物局《关于呈报龙王山遗址保护规划的请示》（鄂文物〔2018〕66号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下修改和完善：

（一）应进一步明确规划目标和主要思路，近期重点控制遗址整体环境风貌和生产、建设活动，为长期、有效开展保护管理和考古研究工作奠定基础。

（二）加强考古资料的梳理和研究，明确遗址的文化性质、遗存分布范围、文物构成等，深化现状评估和价值评估。补充遗址周边地形地貌分析、农林用地构成等内容。

（三）应说明保护区划调整依据，注意文物本体与历史环境的整体保护，明确保护范围与遗存分布范围的关系，合理确定保护范围南部边界，增强可操作性；应结合历史与自然地理要素，综合划定建设控制地带边界；根据遗址文化层埋深，科学确定扰土深度控制指标。

（四）细化保护措施，补充遗址防洪及水土治理要求，评估西侧主要道路改道的可行性。

（五）加强龙王山遗址保护规划与城乡规划等规划的衔接，统筹考虑居民搬迁、变电站迁出、退耕还草、道路改道等措施，论证大规模调整现有产业和人口规模的可行性、必要性。

（六）加强与考古研究单位的沟通，明确近期遗址考古研究工作的主要目标、任务，重点厘清遗址范围、布局和重要遗迹位置等，为科学阐释和展示遗址价值提供依据。

（七）客观评估遗址展示利用潜力，现阶段应以现状保护为主，不宜大规模开展旅游服务设施建设，严格控制、核减各类新建设施的数量、规模，论证新建展示道路等的必要性和可行性。

（八）进一步规范图文表达，应在图纸中准确表达各类环境影响因素、保护措施、设施分布的位置和范围。

二、请你厅指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将龙王山遗址保护规划报请湖北省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你厅指导和协调地方人民政府在保护规划的指导下，进一步做好龙王山遗址各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年4月3日
