# 国家文物局办公室关于殷墟保护范围内乙二十组基址保护性设施建设项目的意见

办保函〔2019〕716号

河南省文物局：

你局《关于报批殷墟乙二十组基址保护性设施建设工程方案的请示》（豫文物〔2019〕136号）收悉。经研究，我局暂不同意实施殷墟宫殿区乙二十组基址保护性设施建设项目。

一、请你局组织中国社会科学院考古研究所，在项目拟建区域进一步开展全面的考古发掘工作，明确该区域地下文物分布范围、性质和价值，为乙二十组基址保护利用工作提供依据。考古发掘项目需另行填报考古发掘申请书。

二、应根据考古文献研究和考古工作成果，厘清乙二十组建筑的形制、规模、平面布局、外观样式等，统筹考虑遗址考古发掘和展示利用需求，明确项目定位及性质，在此基础上深化建筑设计，科学阐释遗址价值，避免对游客产生误导。现阶段建议以满足考古工作需求为主，可搭建必要的临时性保护设施，确保考古工作顺利开展和遗址安全。

三、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年8月13日
