# 农业农村部关于政协十三届全国委员会第二次会议第2111号（农业水利类190号）提案答复

## 关于政协十三届全国委员会第二次会议第2111号（农业水利类190号）提案答复

农办案〔2019〕190号

何一心委员：

您提出的关于加大地理标志产品保护力度，助推特色农业产业化进程的提案收悉。经商国家知识产权局，现答复如下。

近年来，党中央国务院高度重视绿色、优质、特色、品牌农产品发展。2019年《政府工作报告》提出“实施地理标志农产品保护工程”。2019年中央1号文件明确要求“强化农产品地理标志和商标保护，创响一批‘土字号’‘乡字号’特色产品品牌”。《乡村振兴战略规划（2018—2022年）》强调“加强农产品商标及地理标志商标的注册和保护，构建我国农产品品牌保护体系”。《国家质量兴农战略规划（2018—2022年）》将农产品地理标志列入质量兴农主要指标，要求年均增长6%。当前，我国地理标志农产品在农业农村经济工作中发挥着越来越重要的作用，发展地理标志农产品，对打造特色农业产业、推进农业高质量发展、助力实施乡村振兴战略意义重大。

一、关于加大农产品品牌化管理，提升地理标志产品的品牌竞争力

自开展地理标志农产品保护工作以来，农业农村部一直高度重视地理标志农产品品牌培育工作。一是全面开展了特色农产品资源普查，形成《全国地域特色农产品普查备案名录》，收录特色产品6839个；二是制定了2638个具有地方特色农产品的质量控制技术规范；三是依托农业系统建立了部省地市县贯通的农产品地理标志工作体系，省级工作机构51家，组建了141人的农产品地理标志审查专家队伍，2300多人的核查员队伍；四是建设了109家农产品地理标志产品品质检测机构，对获证产品进行安全指标和品质特性指标的跟踪监测。通过以上工作，形成了一套地理标志农产品的特定技术规范，传承了一批独特的农业文化遗产，培育了一批知名农产品区域公用品牌，开创了农产品地理标志保护工作的新局面。国家知识产权局研究制定了推动知识产权高质量发展工作指引，将地理标志作为重点任务之一，明确部署推广地理标志产品、培育地理标志品牌、发展地理标志优势产业等一系列工作。2019年4月，出台《关于进一步加强地理标志保护与运用工作的方案》，明确实施地理标志运用促进工程，探索地理标志“产品－品牌－产业”发展路径，将地理标志品牌建设纳入知识产权强国建设支撑体系和知识产权运营服务体系。在知识产权强省、强市、强县工程试点示范中突出地理标志品牌建设相关任务。

下一步，我部与国家知识产权局将进一步加大对各级工作机构人员、登记证书持有人和标志使用人的培训力度。通过培训引导，提升各级工作机构管理服务能力，强化登记证书持有人授权用标和指导服务意识，增强生产经营主体严格落实质量控制技术规范的自觉性。支持改善生产设施条件，保护特定产地环境，促进适度规模发展；大力推进改造升级传统加工技术，强化利用加工、贮藏、运输与保鲜等新工艺和新设备，积极推进标准化生产，确保地理标志农产品特色品质和质量安全，进一步提升地理标志农产品品牌竞争力。

二、关于加快完善地理标志保护的市场监管体系，保障地理标志产品质量

2010年以来，我部每年开展地理标志农产品标志使用专项检查、综合检查和跟踪监测，规范标志授权使用，保证产品质量。2019年，国家知识产权局先后启动了春节期间地理标志使用专项整治、春茶地理标志保护等工作，印发了《2019年知识产权执法“铁拳”行动方案》，严格保护地理标志品牌，严厉查处地理标志侵权违法行为。2018年，农业农村部印发了《关于农产品质量安全追溯与农业农村重大创建认定、农产品优质品牌推选、农产品认证、农业展会等工作挂钩的意见》，将地理标志农产品及相关生产经营主体纳入国家农产品质量安全追溯管理信息平台，作为申报审批的前置条件。

下一步，我部将积极配合国家知识产权局进一步完善地理标志制度体系，实现统一专用标志、统一监管保护。加快地理标志标准体系、评价体系建设。以地理标志农产品生产集中地、销售集散地为重点，加强线上线下、区域内外协同执法，加大对地理标志侵权假冒案件的查办力度，严厉查处擅自使用专用标志或近似标志，以及伪造、冒用或未按规定印制专用标志等行为，在有效保护的前提下做好地理标志产品挖掘和开发，切实维护地理标志产品的声誉和品牌价值。

三、关于加大对地理标志品牌的培育和宣传，助力乡村振兴

2015年以来，我部连续4年举办地理标志农产品专展和全国地理标志农产品品牌推介会，全面展示和推介地方特色产品。先后推荐近400个地理标志农产品参加由央视财经频道直播的全国区域品牌价值评价，组织拍摄大型地理标志农产品纪录片《源味中国》，直观展现地理标志农产品。编写《中国农产品地理标志丛书》《农产品地理标志50问》等科普丛书，普及地理标志知识。利用世界知识产权日集中宣传地理标志农产品，提升社会认知度。2019年，我部举办了“地理标志农产品保护在行动”暨地理标志农产品保护工程启动仪式，国家知识产权局举办了“知识产权服务万里行”、“数说地理标志的中国故事”、2019年中国品牌发展国际论坛“商标、地理标志与品牌”分论坛等一批有影响力的宣传推介活动。同时，组织和指导地方加强地理标志农产品资源的挖掘和培育，建立地理标志农产品保护基地，提升地理标志农产品附加值和市场竞争力，促进绿色发展和农民增收，助力乡村振兴和脱贫攻坚。

下一步，我部和国家知识产权局将按照2019年《政府工作报告》关于实施地理标志农产品保护工程的部署，深入挖掘地理标志农产品历史文化内涵，充分利用央视、新华网等主流媒体以及各地农业门户网站等多种传播渠道，讲好中国地理标志农产品品牌故事。充分利用中国国际农产品交易会、中国绿色食品博览会、知识产权大型展会以及京东、天猫等多种产销对接平台，借助现代信息技术，加强地理标志农产品市场营销，提升市场占有率，促进优质优价。

四、关于加快推动地理标志保护产品在国际上的互认互通，鼓励我国地理标志产品“走出去”，打造全球竞争力的地理标志农产品品牌

我部和国家知识产权局高度重视地理标志国际合作工作，不断加强与世界知识产权组织及其成员国以及欧盟等地区的交流与合作，积极开展与欧盟在地理标志和知识产权等方面的谈判与对话，以推动国际互认互通。世界知识产权组织分别于2007年和2017年两次在我国举办世界地理标志大会，有力推进了我国地理标志国际合作与交流。中欧双方于2006年共同发起“中国－欧盟10+10地理标志保护双边互认”项目。2011年3月，《中欧地理标志保护合作协定》第一轮谈判正式启动。2017年6月，中欧双方签署了《关于地理标志合作与保护协定谈判的备忘录》，并启动中欧“100+100”互认受理工作，截至目前已完成21轮谈判。

下一步，我部将和国家知识产权局等部门继续深入推进与世界知识产权组织及其成员国在地理标志领域的交流合作，加强对地理标志知识产权国际规则的前瞻性研究，稳步提升我国在多边平台的规则引导力和话语权，推动相关国际规则朝着开放包容、平衡有效的方向发展，为我国地理标志农产品“走出去”提供有力的国际环境。同时，进一步加强地理标志领域的工作交流，积极推动地理标志保护的国际合作，为我国地理标志农产品“走出去”提供有力支持。

感谢您对地理标志农产品培育与保护工作的关心，希望今后继续支持关注我们的工作。

农业农村部

2019年8月30日
