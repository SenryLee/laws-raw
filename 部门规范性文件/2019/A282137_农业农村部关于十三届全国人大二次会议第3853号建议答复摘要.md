# 农业农村部关于十三届全国人大二次会议第3853号建议答复摘要

## 十三届全国人大二次会议第3853号建议答复摘要

农办议〔2019〕509号

栗翠田等4名代表：

您提出的关于推广全生物降解渗水地膜的建议收悉。经商科技部，现答复如下。

一、关于采购推广符合标准的全生物降解地膜

2017年，我部印发《农膜回收行动方案》，实施农膜回收绿色发展行动，以源头减量、回收利用和替代使用为重点，以加厚地膜应用、机械化捡拾、专业化回收、资源化利用为主攻方向，加快推进农膜污染治理。当前，地膜污染治理主要以回收利用为重点，建立健全回收加工体系，提升资源化利用水平。我部也积极推进全生物降解地膜对比评价试验，2015年起，通过部门预算安排专项资金支持全国13省（区、市）开展全生物降解地膜大田对比试验示范，印发《全生物降解地膜对比示范技术方案》，探索全生物降解地膜大田应用适宜性，筛选适宜区域栽培的全生物降解地膜产品，总结全生物降解地膜农田应用技术规范，先后建立了17个千亩全生物降解地膜试验示范区。目前，全生物降解地膜仍处于试验示范阶段，需要进一步验证其大规模应用的可行性，评价其环境安全性。下一步，我们将继续深入开展全生物降解地膜农田试验，完善全生物降解地膜评价标准体系，在适宜区域和作物上谨慎推广全生物降解地膜。

二、关于控制全生物降解地膜的采购成本

目前，全生物降解地膜仍处于农田试验和对比评价阶段，还需要进一步完善评价技术规程，验证农田应用的安全性，还没有到大规模采购推广的阶段。我部也积极推动全生物降解地膜试验应用工作，为贯彻落实2017年中央1号文件关于“探索实行‘大专项+任务清单’管理方式”的要求，中央财政支持农业生产的相关资金合并为农业生产发展资金，进一步推进专项转移支付预算编制环节源头整合改革，创新和完善资金管理使用机制，资金采取因素法分配，并切块下达到省。各省可以在完成约束性任务的基础上，在大专项支持方向范围内，结合当地实际，按照有关规定统筹中央和地方资金，支持适宜农用地膜推广和应用，在有条件的地区集中开展适宜作物全生物可降解地膜替代。下一步，我们将组织开展全生物降解地膜推广补贴机制研究，完善以绿色生态为导向的补贴政策，推动适宜作物上的全生物降解地膜应用。

三、关于防范降解地膜应用技术风险问题

2015年以来，我部通过部门预算安排专项资金支持可降解地膜研发、示范推广、监测评估等工作，在新疆等13个重点用膜省份开展全生物可降解地膜和非降解地膜对比试验，对20多家企业生产的可降解地膜田间应用效果进行对比分析，筛选应用效果好的可降解地膜。通过几年试验示范，基本摸清了全生物降解地膜产品特性，探索总结了全生物降解地膜不同区域不同环境下应用的技术规程，初步建立降解地膜农田使用评价技术体系，提高了全生物降解地膜产品稳定性和功能性，完善了全生物降解地膜试验示范的技术规范。下一步，我部将继续推进地膜污染治理工作，做好可降解地膜的田间筛选工作，鼓励科研院所和企业加快生物可降解地膜的研发和应用，在适宜区域和作物上谨慎推广全生物降解地膜应用。

感谢您对全生物降解地膜示范推广工作的关心，希望继续对我部工作给予支持。
