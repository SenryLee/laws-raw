# 国资委关于通报表扬2016-2018年任期业绩优秀企业和突出贡献企业的决定

国资发考分〔2019〕73号

各中央企业：

2016-2018年任期，国内外经济形势严峻复杂，国有企业改革发展任务艰巨繁重。中央企业在以习近平同志为核心的党中央坚强领导下，坚决贯彻党中央、国务院决策部署，认真落实国资委工作要求，坚持稳中求进工作总基调，大力推进供给侧结构性改革，不断做强做优做大国有资本，经济效益和发展质量明显提升，经营业绩持续向好，科技创新硕果累累，节能减排成效显著，市场竞争能力和可持续发展能力稳步提高，为国民经济持续稳定健康发展作出了积极贡献。

为激励先进，鼓舞士气，经研究决定，授予招商局集团有限公司等42家企业为“业绩优秀企业”，中国核工业集团有限公司等28家企业为“科技创新突出贡献企业”，中国宝武钢铁集团有限公司等20家企业为“节能减排突出贡献企业”。希望上述企业珍惜荣誉，再接再厉，再创佳绩。各中央企业要认真贯彻习近平新时代中国特色社会主义思想，以此次通报表扬的企业为榜样，牢固树立和践行新发展理念，坚持质量第一效益优先，坚持以供给侧结构性改革为主线，强化创新驱动，优化布局结构，稳健开展国际化经营，防范化解重大风险，创新体制机制，实现质量更高、效益更好、结构更优的发展，加快培育具有全球竞争力的世界一流企业。

附件：2016-2018年任期业绩优秀企业和突出贡献企业名单
