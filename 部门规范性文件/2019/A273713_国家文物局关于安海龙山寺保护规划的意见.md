# 国家文物局关于安海龙山寺保护规划的意见

文物保函〔2019〕48号

福建省文物局：

你局《关于全国重点文物保护单位安海龙山寺文物保护规划（第二稿）的请示》（闽文物字〔2018〕403号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）进一步梳理、完善价值和现状评估。文物描述中应注意区分非文物建筑；科学价值评估应补充建造技术相关内容；按照文物建筑、附属文物、寺庙格局、非文物建筑、周边环境等开展评估；明确建筑质量、风貌评估标准；补充对藏经阁、地藏殿、城隍殿、禅堂等寺内非文物建筑的评估；补充对古树、自然灾害的评估；补充中轴线视域分析等内容。

（二）合理调整保护区划及管理规定。结合历史文化名城规划和寺庙格局研究，进一步优化保护范围边界；寺庙东路和西路配套服务区未统一纳入保护范围，应予以说明；保护范围南、北侧边界应适当扩展；进一步细化管控指标，如格局、建筑体量、高度、色彩、造型、容积率、功能等，并结合肌理、高度、视线分析，论证各项指标的设定依据。

（三）进一步加强保护措施与现状评估的对应性，注意区分保护措施与管理工作。

（四）进一步审慎论证环境整治措施。所报规划拟对寺庙格局进行较大规模的调整，拆除现存非文物建筑、新建传统样式建筑的总量较大，如新建山门、连廊、文物保护研究展示中心及部分周边附属建筑等，其必要性和规划依据论证尚不充分；考虑到民间信仰活动的实际需求，建议在梳理区域空间的过程中，尊重各个历史时期叠加形成的空间形态和文化信息，尽可能保留、改造、续用外观协调的既有非文物建筑，减少新建建筑总量，尤其应避免建设体量较大的新建筑；科学论证功能布局，不应以恢复某一特定时期的“历史原貌”为规划目标；不宜设置所谓“寺庙发展预留区”，应明确规划内容，如涉及其他扩建活动，建议另行选址。

（五）应细化管理规划，明确龙山寺管委会的机构性质，细化文物管理部门、龙山寺管委会和宗教团体等各方责权关系。

（六）进一步深化研究规划，明确研究目标、技术路线、工作计划、保障条件等，加强历史格局、建筑形制、考古研究等相关工作。建议将大雄宝殿原址考古工作纳入规划内容。

（七）展示利用规划应惠及当地社区和民众，并考虑与台湾相关寺院的交流互动。

（八）补充安海龙山寺列入全国重点文物保护单位前编制的相关规划的衔接内容。

（九）进一步校核、精炼规划文本，完善规划图纸。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见对规划进行必要修改和完善后，依照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将安海龙山寺保护规划报请福建省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好安海龙山寺各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年1月14日
