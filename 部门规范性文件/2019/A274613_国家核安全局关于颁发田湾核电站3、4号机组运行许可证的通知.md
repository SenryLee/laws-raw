# 国家核安全局关于颁发田湾核电站3、4号机组运行许可证的通知

## 关于颁发田湾核电站3、4号机组运行许可证的通知

国核安发〔2019〕35号

江苏核电有限公司：

你公司《关于颁发田湾核电站3、4号机组运行许可证的请示》（苏核发〔2018〕697号）收悉。

根据《中华人民共和国核安全法》《中华人民共和国民用核设施安全监督管理条例》的有关要求，我局对你公司提交的田湾核电站3、4号机组运行许可证申请书及其相关文件进行了审查，认为该申请是可以接受的，决定颁发田湾核电站3、4号机组运行许可证。

你公司在田湾核电站3、4号机组管理中必须遵循确保安全的方针，坚持安全第一的原则，遵守其运行许可证的规定，确保田湾核电站3、4号机组运行安全。

附件：1.田湾核电站3号机组运行许可证

2.田湾核电站4号机组运行许可证

国家核安全局

2019年2月27日
