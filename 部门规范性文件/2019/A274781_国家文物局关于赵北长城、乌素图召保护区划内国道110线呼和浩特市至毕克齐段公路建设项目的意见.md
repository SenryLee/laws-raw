# 国家文物局关于赵北长城、乌素图召保护区划内国道110线呼和浩特市至毕克齐段公路建设项目的意见

文物保函〔2019〕222号

内蒙古自治区文物局：

你局《关于国道110线呼和浩特市至毕克齐段公路涉及国家级保护单位赵北长城和乌素图召建设控制地带方案的请示》（内文物字〔2019〕4号）收悉。经研究，我局原则同意在赵北长城和乌素图召文物保护区划范围内实施国道110线呼和浩特市至毕克齐段公路建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建公路途经区域，特别是涉及小瓦窑长城4段部分，进行深入的考古调查勘探和必要的考古发掘。如有赵北长城相关遗存等重要发现，应做好原址、原状保护工作，并依法调整项目方案进行避让。

（二）优化调整公路选线及建设方案，尽可能降低对文物本体的影响。应将拟通过讨合气长城2段的公路选线，连同公路收费站管理办公区及其他相关设施选址全部移至赵北长城保护范围以外；途经小瓦窑长城4段的公路应优先采取挖掘地下通道或架设桥梁的方式通过。补充拟建公路避让乌素图召保护范围或以隧道形式下穿保护范围的比选方案，充分论证各方案的可行性和利弊，为科学决策提供依据。

（三）应细化拟建公路排水措施，避免因积水对长城本体安全造成威胁；细化施工期间的垃圾、粉尘等污染物处置要求，以及后期环境修复措施，做好场地清理和施工区域生态环境恢复工作。同时应补充长城标识及展示措施。

（四）应完善拟建公路施工、运营期间的文物本体监测措施，细化隔振、减振措施，避免各类振动对长城本体造成负面影响。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

四、请你局指导、督促相关地方人民政府和有关部门，加强对赵北长城相关段落日常巡查和保养维护，组织专业机构对文物本体保存现状以及周边环境现状进行调查评估，对于存在险情的部位应抓紧做好临时性支护，同时酌情编制文物保护方案并履行报批手续后，尽快组织实施，确保长城本体安全。

专此函复。

国家文物局

2019年3月1日
