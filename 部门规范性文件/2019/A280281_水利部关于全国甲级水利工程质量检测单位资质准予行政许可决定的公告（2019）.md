# 水利部关于全国甲级水利工程质量检测单位资质准予行政许可决定的公告（2019）

## 水利部关于全国甲级水利工程质量检测单位资质准予行政许可决定的公告

水许可决〔2019〕59号

根据《水利工程质量检测管理规定》（水利部令第36号），经评审和公示，现作出全国甲级水利工程质量检测单位资质行政许可决定：批准岩土工程类北京碧波立业技术检测有限公司等71个单位、混凝土工程类合肥市天秤水利工程质量检测有限公司等78个单位、金属结构类安徽金源工程检测有限公司等17个单位、机械电气类东营市汇科工程质量检测有限公司等10个单位、量测类北京市水科学技术研究院等33个单位水利工程质量检测甲级资质延续，批准岩土工程类吉林省达兴工程检测有限公司等14个单位、混凝土工程类喀什锦源水利水电工程有限责任公司等6个单位、金属结构类福建省永正工程质量检测有限公司等5个单位、机械电气类安徽金源工程检测有限公司等11个单位、量测类安徽华水工程检测有限公司等9个单位水利工程质量检测资质升级为甲级（名单附后）。

特此公告。
