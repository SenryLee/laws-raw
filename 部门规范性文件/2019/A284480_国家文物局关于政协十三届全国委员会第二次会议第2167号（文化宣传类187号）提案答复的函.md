# 国家文物局关于政协十三届全国委员会第二次会议第2167号（文化宣传类187号）提案答复的函

文物政函〔2019〕884号

关峡委员：

您提出的“关于开展中华文明标识保护发展工程的提案”收悉。经商北京市人民政府，现答复如下。

习近平总书记强调要坚持创造性转化、创新性发展，把中华优秀传统文化的精神标识提炼出来、展示出来。2018年10月，中共中央办公厅、国务院办公厅《关于加强文物保护利用改革的若干意见》明确提出构建中华文明标识体系，依托价值突出、内涵丰厚的珍贵文物，推介一批国家文化地标和精神标识。

中央有关部门将按照有利于突出中华文明历史文化价值、有利于体现中华民族精神追求、有利于向世人展示全面真实的古代中国和现代中国的要求，深入贯彻落实党中央、国务院决策部署，认真学习贯彻习近平总书记重要指示批示精神，坚持保护优先，研究弘扬优秀历史文化，逐步构建中华文明标识体系，坚定文化自信、讲好中国故事，增强中华民族的自豪感和凝聚力。

关于研究中华文明标识保护发展工程实施方案建议。文物保护利用改革部门协调机制现已建立，国家文物局正会同有关部门、有关地方调研并制订构建中华文明标识体系的实施方案，适时公布一批国家文化地标和精神标识。实施好中华文物全媒体传播计划，广泛传播文物蕴含的文化精髓和时代价值。

关于健全社会参与机制建议。国家文物局支持各级文物博物馆单位广泛调动社会力量参与文物保护利用的积极性和创造性，共同推进中华文明标识体系构建工作；试行《博物馆馆藏资源著作权、商标权和品牌授权操作指引》，引导各级文物博物馆单位盘活用好文物资源，规范文化创意产品开发授权工作；继续实施“互联网+中华文明”行动计划，加强对文物展示利用方式的融合创新。

关于在北京开展中华文明标识保护发展工程试点建议。北京市具有大运河文化保护传承的良好基础和丰富经验，支持以北京大运河文化带建设为中华文明标识保护发展工程的试点项目，梳理提炼大运河的文化脉络和精神内涵，搭建大运河文化数据平台，加强大运河文物、非遗和历史风貌保护，充分展示大运河文化魅力。

感谢您对文物事业的关心和支持。

国家文物局

2019年8月27日
