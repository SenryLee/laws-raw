# 国家文物局关于印山越国王陵保护规划的意见

文物保函〔2019〕135号

浙江省文物局：

你局《关于上报全国重点文物保护单位印山越国王陵保护规划的请示》（浙文物发〔2018〕207号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需做以下必要的修改和完善：

（一）深化价值评估，根据考古研究成果，分析墓葬选址、墓室营造、丧葬仪式等方面的特殊性，凝练印山越国王陵的文物价值。

（二）深化现状评估内容，根据遗存类型细化保存现状描述，分析南方地区潮湿环境下文物病害类型与发展程度，归纳影响文物安全的主要因素，客观评价各类建设工程对文物及周边环境的影响。补充日常管理、开放展示和基础设施建设、安防设施情况。

（三）应补充说明保护范围调整和一般保护区划定依据，综合考虑印山越国王陵保护区划与徐渭墓保护区划的关系，北侧边界划定应统筹考虑土地利用现状。建设控制地带应明确屋脊高度控制要求。

（四）针对现状评估结论，制定具体的文物保护策略，明确保护措施的实施范围、位置和强度等内容。椁室、木炭堆积层等遗存应制定专项保护措施。

（五）应根据文物保存现状、区位条件和地方经济社会发展水平，综合确定展示利用方式，慎重论证建设考古遗址公园的必要性和可行性。结合考古工作成果确定具体的展示节点，完善墓室、葬具及墓道展示方式，隍壕及其外围遗存应纳入展示范围。明确新建越国文化主题展示馆的建设规模和要求，进一步论证景区内全部使用电瓶车的必要性。

（六）管理规划应提出文物保护机构的工作职责、管理模式和人员队伍建设要求，加强日常管理和巡护工作。

（七）进一步完善考古工作规划内容，应在分区、分片调查的基础上，进一步研究印山越国王陵与周边越国贵族墓葬的关系，深入探讨东周越国丧葬制度在我国古代帝王陵墓制度、丧葬文化形成中的作用。考古工作站建设应作为近期规划内容。

（八）加强印山越国王陵保护规划与相关规划的衔接，并规范图文表达。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将印山越国王陵保护规划报请浙江省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好印山越国王陵保护规划的各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年2月11日
