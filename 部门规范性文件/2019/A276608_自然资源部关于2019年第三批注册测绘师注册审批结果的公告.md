# 自然资源部关于2019年第三批注册测绘师注册审批结果的公告

根据《注册测绘师制度暂行规定》（国人部发〔2007〕14号）和《注册测绘师执业管理办法（试行）》（国测人发〔2014〕8号），经审核，刘忠卿等294人符合初始注册条件，准予初始注册；张元元等30人符合延续注册条件，准予延续注册；何波等48人符合变更注册条件，准予变更注册；李汪等24人符合注销注册条件，准予注销注册。

特此公告。

自然资源部

2019年4月25日

1. 准予变更注册人员名单

2. 准予初始注册人员名单

3. 准予延续注册人员名单

4. 准予注销注册人员名单
