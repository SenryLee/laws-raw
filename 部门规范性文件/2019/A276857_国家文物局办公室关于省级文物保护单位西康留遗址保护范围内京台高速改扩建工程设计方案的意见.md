# 国家文物局办公室关于省级文物保护单位西康留遗址保护范围内京台高速改扩建工程设计方案的意见

办保函〔2019〕327号

山东省文物局：

你局《关于再次报送京台高速公路改扩建工程穿越西康留遗址设计方案的请示》（鲁文发〔2019〕24号）收悉。经研究，我局暂不同意所报项目调整设计方案。

西康留遗址为山东省文物保护单位，具有重要的历史、艺术和科学价值。所报方案未充分说明采用双侧拼宽方式的必要性和唯一性，请你局指导有关单位，按照我局《关于在山东省文物保护单位西康留遗址保护范围内进行京台高速改扩建项目的意见》（文物保函〔2018〕1126号）和《关于西康留遗址保护范围内京台高速改扩建项目设计方案调整的意见》（办保函〔2018〕1269号）要求，采取现状道路东侧单侧拼宽方式进行京台高速公路改扩建工程，并核报有关部门和山东省人民政府同意后实施。

专此函复。

国家文物局办公室

2019年4月28日
