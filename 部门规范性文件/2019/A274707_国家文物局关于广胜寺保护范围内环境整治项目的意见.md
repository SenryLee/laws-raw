# 国家文物局关于广胜寺保护范围内环境整治项目的意见

文物保函〔2019〕196号

山西省文物局：

你局《关于审批洪洞县广胜寺重点保护区环境整治初步设计方案的请示》（晋文物〔2019〕2号）收悉。经研究，我局原则同意广胜寺保护范围内环境整治项目。

一、所报方案尚需作以下必要的修改和完善：

（一）深化院落地面现状勘察，尽量保留历史铺装，不宜一次性全部更换现有铺装。

（二）应充分考虑院落地坪降低后院落排水方式，明确围墙内排水系统与院外排水系统的关系。

（三）完善绿化景观设计。可选择必要节点进行绿化，不宜大面积重新绿化，避免园林化和人工化倾向。

（四）补充建筑围墙、排水设施的考古调查勘探，为项目实施提供科学依据。

（五）补充说明围墙重砌部分的修建依据、具体做法、使用材料，并注意与现有围墙部分的衔接。

（六）应制定实施过程中必要的文物防护和应急措施，尽量减少对文物本体和周边环境的影响。

（七）涉及文物建筑的安防工程、消防工程、防雷工程应按程序另行申报。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月21日
