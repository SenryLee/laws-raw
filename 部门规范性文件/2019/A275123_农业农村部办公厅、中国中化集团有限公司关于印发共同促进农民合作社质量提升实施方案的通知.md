# 农业农村部办公厅、中国中化集团有限公司关于印发共同促进农民合作社质量提升实施方案的通知

## 农业农村部办公厅　中国中化集团有限公司关于印发共同促进农民合作社质量提升实施方案的通知

农办经〔2019〕3号

各省、自治区、直辖市农业农村（农牧）厅（委、局），新疆生产建设兵团农业局，中化集团农业事业部各单位：

为推进农民合作社高质量发展，我部会同中国中化集团有限公司联合制定了《农业农村部办公厅中国中化集团有限公司共同促进农民合作社质量提升实施方案》（附后），发挥双方各自优势，为农民合作社提供服务。现印发给你们，请结合工作实际，认真贯彻落实。

农业农村部办公厅　中国中化集团有限公司

2019年3月11日

附件：农业农村部办公厅中国中化集团有限公司关于印发全国农民合作社质量提升实施方案的通知
