# 国家文物局关于在恭王府保护范围内进行恭王府及花园管理中心热力、给排水室外管线系统改造项目的意见

文物保函〔2019〕80号

北京市文物局：

你局《关于文化部恭王府及花园管理中心热力、给排水室外管线系统改造工程设计方案的请示》（京文物〔2018〕1722号）收悉。经研究，我局原则同意在恭王府保护范围内进行恭王府及花园管理中心热力、给排水室外管线系统改造项目。

一、所报方案尚需做以下必要的修改和完善：

（一）进一步细化对原管沟的勘察，明确原给排水管道等的走向，尽可能保留、利用原管沟，减少新开挖线路和面积。新线路应最大限度避让原有老地面铺装。

（二）补充施工中对假山、水池及古建筑的具体防护措施，明确施工中安全监测的数据指标，确保文物安全。加强施工管理，不得采用机械开挖沟槽，细化安全文明施工措施。

（三）细化开挖后地面铺装恢复的具体方案和实施要求。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月21日
