# 国家药监局关于报送全面清理政府采购领域妨碍公平竞争的规定和做法的函

国药监综函〔2019〕118号

财政部：

按照你部《关于促进政府采购公平竞争优化营商环境的通知》（财库〔2019〕38号）要求，我局认真组织开展政府采购领域妨碍公平竞争规定和做法相关清理工作。经查，我局不存在上述情况。

国家药监局

2019年10月30日
