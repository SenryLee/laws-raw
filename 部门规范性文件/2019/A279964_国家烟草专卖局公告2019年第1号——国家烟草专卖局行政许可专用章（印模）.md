# 国家烟草专卖局公告2019年第1号——国家烟草专卖局行政许可专用章（印模）

## 国家烟草专卖局公告

2019年第1号

根据《中华人民共和国行政许可法》的有关规定，我局决定自即日起启用国家烟草专卖局行政许可专用章。该印章的使用范围是：加盖于烟草专卖生产企业许可证、烟草专卖批发企业许可证、烟草专卖品准运证及相关行政许可文书。

附件：国家烟草专卖局行政许可专用章（印模）

国家烟草专卖局

2019年7月29日
