# 国家煤矿安监局关于进一步加强煤矿防汛应急工作的通知

各产煤省、自治区、直辖市及新疆生产建设兵团煤矿安全监管部门、煤炭行业管理部门， 各省级煤矿安全监察局，有关中央企业：

今年入汛以来，我国多地出现强降雨，给人民群众生命财产安全带来严重威胁。7月23日，贵州省六盘水市水城县鸡场镇发生特大山体滑坡灾害，截至目前，已造成15人死亡，30人失联。习近平总书记作出重要指示，要求全力搜救被困人员，做好险情监测，防范次生灾害，并强调，今年汛期防汛形势严峻，要本着对人民极端负责的精神，认真排查险情隐患，加强预报预警，强化灾害预防，保护好人民群众生命财产安全。李克强总理作出批示，要求各地举一反三，切实加强山洪、滑坡、泥石流等灾害防御，保障人民群众生命财产安全。王勇国务委员对汛期各类灾害隐患排查和防治工作提出明确要求。为认真贯彻落实习近平总书记、李克强总理等党中央国务院领导同志重要指示批示精神，进一步加强煤矿防汛应急工作，现将有关要求通知如下：

一、充分认识做好当前防汛应急工作的极端重要性

汛期是煤矿水害事故易发期。降雨对地表水体、井下含水层和老空区进行补给，易导致煤矿水压升高、涌水量增大；持续强降雨可能导致地表水从井口灌入井下，造成淹井事故。目前正值“七下八上”主汛期的关键阶段，防汛形势十分严峻。各有关部门和煤矿企业要充分认识做好煤矿防汛应急工作的极端重要性，提高政治站位，增强红线意识，认真贯彻落实习近平总书记等中央领导同志重要指示批示精神，克服松懈麻痹思想和侥幸心理，严防暴雨洪水引发煤矿生产安全事故和滑坡、泥石流造成的次生事故。

二、全面开展汛期安全隐患排查治理

煤矿企业要切实履行好安全生产主体责任，强化汛期隐患排查治理。煤矿及集团公司的主要负责人、总工程师、防治水副总工程师要认真落实水害防治责任，结合煤矿实际，认真组织会商，分析暴雨、洪水等对煤矿安全生产带来的风险，组织开展汛期拉网式安全排查，有针对性地开展各类水害防治工作。受老空水威胁的矿井，要重点调查井田范围内及周边已关闭小煤矿、老窑的采空区范围，分析暴雨后水位抬升、积水量增加而形成的安全风险。对排查出的隐患，要落实治理措施，保障治理效果。

三、建立灾害性天气预警联动机制

煤矿安全监管部门、行业管理部门要加强煤矿防汛应急工作的组织领导。要高度重视灾害天气预报预警，主动与气象、水利、防汛、国土等部门联系，建立灾害性天气预警和协调联动机制，及时向当地煤矿发送暴雨洪水灾害信息，做到信息共享、协同应对、处置及时。要认真分析本地区煤矿汛期安全生产特点，深入重点矿区、重点煤矿企业，开展汛期水害巡查和专项执法检查，检查督促煤矿企业切实加强雨季“三防”工作，及时消除水害隐患。

煤矿企业要密切关注天气变化，接到预报预警信息后，认真研判自然灾害引发煤矿生产安全事故的风险。要制定并严格执行暴雨期间停产撤人措施，一旦发现极端天气可能导致淹井等重大险情，要第一时间采取停产撤人措施。要加强与周边相邻矿井信息沟通，发现矿井水害可能影响相邻矿井时，立即向周边相邻矿井发出预警。

四、切实加强汛期煤矿安全监察工作

各级煤矿安全监察机构要对产煤市（地）、县（区）有关部门及煤矿企业灾害性天气预警联动机制建立和执行情况进行监督检查。要以雨季“三防”工作和“三专两探一撤”措施落实情况等为重点，深入开展明查暗访。要结合本辖区煤矿特点，有针对性地对受老空水或者地表水威胁的水文地质类型复杂、极复杂矿井开展精准监察执法，发现受地表水倒灌威胁矿井在强降雨天气或受上游洪水威胁未实施停产撤人的，一律依法依规严厉处罚，发现重大隐患的，一律落实停产整顿措施。

五、强化汛期值班值守和应急处置

各煤矿企业要进一步加强应急值班值守，严格执行领导干部到岗带班和关键岗位24小时值班制度，接到暴雨灾害预警信息和警报后，要快速响应、迅速处置。要组织开展应急演练，储备足够的救灾物资，发现重大水患险情立即启动应急预案，迅速组织抢险救灾，力争将事故损失降到最低。

煤矿安全监管、行业管理部门和煤矿安全监察机构要以对人民极端负责的精神，将应急值班值守工作作为一项重要职责和纪律要求，切实做好汛期重大险情的应急处置工作。

请各省级煤矿安全监察局将本通知精神迅速传达至辖区各煤矿企业集团和煤矿。
