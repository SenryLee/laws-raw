# 国家林业和草原局科技司关于开展林草科技创新人才推荐选拔工作的公告

## 关于开展林草科技创新人才推荐选拔工作的公告

为适应新形势对林草科技人才工作的要求，充分发挥高层次创新人才在林草科技创新发展中的引领和示范作用，加快建立一支规模可观、结构合理、素质优良的林草科技创新人才队伍，经国家林业和草原局研究决定，现组织开展林草科技创新人才推荐选拔工作。有关安排通知如下。

一、选拔范围

林业和草原系统内高校和科研机构以及承担我局科技平台任务的科研院所和高校中的人才和团队。

二、推荐方式

1.各省林业和草原主管部门组织推荐本地区系统内高校和科研机构中的人才或团队。

2.中国科学院、中国工程院院士提名推荐，每人可推荐人才不超过2名，团队不超过1个。

三、目标任务

根据《林草科技创新人才建设计划实施方案》的部署，2019年遴选青年拔尖人才、科技创新领军人才、创新团队各10个。

四、条件要求

推荐人才和团队成员应热爱祖国，甘于奉献，具有科学精神，严守学术道德和职业操守。

（一）林业和草原青年拔尖人才应具备以下条件

——在林业和草原重点领域研究方面已取得突出学术成果，获得国内较高学术成就，具有较好发展潜力，有一定社会影响，有望进入世界科技前沿。

——一般应有承担国家自然科学基金课题或者省部级以上重大科研项目的经历。

——年龄不超过35周岁（1984年3月1日及以后出生）。

（二）林业和草原科技创新领军人才应具备以下条件

——在科研一线从事研究开发工作，学术水平高，研究方向符合林业和草原科技前沿发展趋势，具有承担重大研究课题的经历，取得国内外同行公认的重要创新成果；具有带领本学科（或相关学科）赶超或引领国际先进水平的能力。

——工作认真负责，责任心强，具有较强的科研领军才能和团队组织管理能力。

——一般应具有副高级以上专业技术职务，年龄不超过45周岁（1974年3月1日及以后出生）。

（三）林业和草原科技创新团队应具备以下条件

——有稳定的研究方向，符合我国林业和草原重点发展需求，属于国家和行业中长期科学和技术发展规划的重点领域或国际重大科技前沿热点问题。

——团队承担重大科研项目或重点工程或重大建设项目的重点研发任务。

——团队创新业绩突出，研发水平居我国林业和草原领域前列，并具有持续创新能力和较好的发展前景。

——团队结构稳定、合理，核心成员一般不少于5人、不超过15人。

——团队负责人责任心强，在团队中有较强的凝聚作用和威信。

五、有关要求

1.各推荐单位要高度重视，严格标准，规范程序，认真把关，坚持优中选优，质量第一，研究提出推荐人选，确保人选质量。坚持破除“四唯”和摒弃繁缛程序，尽量简化。

2.各推荐单位于2019年3月25日前将推荐表审核后加盖公章（一式1份），以公文形式报送国家林业和草原局科技司。院士提名推荐者，经院士签名后将推荐表寄至国家林业和草原局科技司。同时推荐表电子版请发送至kjsjhc@126.com。

3.对推荐的人选，科技司将采取一定形式进行了解、论证和咨询，提出建议名单，按照相关程序予以公布。

4.建立退出机制，对违反政治纪律和政治规矩、违法违纪、违反社会公德和学术道德，学术行为不端等情形的，发现后即强制退出。对违背科研诚信要求的行为，严格按照国家关于加强科研诚信建设的有关规定追究责任。
