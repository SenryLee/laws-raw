# 国家体育总局人力中心关于实施为国家队送课项目的通知

## 体育总局人力中心关于实施为国家队送课项目的通知

体人力字〔2019〕55号

有关运动项目管理中心，中国足球协会、中国篮球协会，有关项目协会：

为帮助国家队运动员提升综合素质，促进运动员在役期间职业发展，经征求相关单位意见，结合工作实际，现将实施2019年为国家队送课入队项目相关事项通知如下：

一、实施方式

项目采用专家面授、利用现有资源综合送课等方式开展。

（一）专家面授。

为保证送课效果，在此前一个月的25号至月底，请队伍报名确认准确送课时间，一般为月报名靠前的3支队伍送课。原则上为奥运项目队伍送课；同等条件下，将向冬季项目倾斜。

（二）网上课程。

总局MOOC（即慕课）平台（网站：“中国运动员职业发展？驿站”，网址：http://acdchina.org.cn/）中有往年为国家队送课项目录制的面授课程视频等众多课程，可供运动员自主学习。

（三）为国家队赠送学习资料。

根据国家队需求，我们可提供2017年为国家队送课项目录课光盘、国际奥委会《运动员成长工具包》、运动员职业发展读本等资料。

二、注意事项

（一）面授课正式报名从2月底开始，请各项目中心自行掌握报名时间，后续每月报名不再另行通知。

（二）面授课报名时请务必明确送课主题（附件2）、送课时间地点、参与人员及人数、联系人等信息；为提高送课效率，送课队伍负责授课场地协调、授课专家接待等事宜，相关经费由我中心负担。

（三）2017年为国家队送课项目录课光盘已在前期需求统计时推广给各单位，如有额外需求可与我中心联系。相关学习资料数量有限，材料发完即止。
