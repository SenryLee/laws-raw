# 国家文物局关于长城建设控制地带内延庆华坤文化旅游庄园建设项目的意见

文物保函〔2019〕596号

北京市文物局：

你局《关于长城建设控制地带内延庆华坤文化旅游庄园建设项目的请示》（京文物〔2019〕769号）收悉。经研究，我局原则同意在长城建设控制地带内进行延庆华坤文化旅游庄园建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘。如有长城墙体及附属设施遗存等重要发现，应调整设计方案，确保文物安全。

（二）应严格控制建筑体量，相关设计应符合长城三类建设控制地带管理规定，确保所有建筑物的总高度均不得超过9米，建筑密度不得大于35%。

（三）应适当控制C区北端与延庆区258号敌台存在局部通视关系区域的建筑规模，加强该区域靠近长城一侧的绿化遮挡，减少项目对长城景观风貌的影响。

（四）应细化拟建项目施工方案，补充施工和运营期间的监测措施、应急预案，施工场地布置、施工组织管理要求，以及施工后期的生态环境修复措施和文物标识与展示措施。

（五）应就涉及南寨坡遗址V类建设控制地带的建设事项依法报北京市文物局征求意见，并补充南寨坡遗址保护措施，拟建建筑不得侵占遗址所在山体。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年6月25日
