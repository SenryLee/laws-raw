# 国家卫生健康委办公厅关于印发麻醉科医疗服务能力建设指南（试行）的通知

国卫办医函〔2019〕884号

各省、自治区、直辖市及新疆生产建设兵团卫生健康委：

为进一步贯彻落实《关于印发加强和完善麻醉医疗服务意见的通知》（国卫医发〔2018〕21号），加强麻醉学科建设，推动麻醉医疗服务高质量发展，我委组织制定了《麻醉科医疗服务能力建设指南（试行）》（可从国家卫生健康委网站下载）。现印发给你们，供各地、各医疗机构加强麻醉医疗服务能力建设时使用。

附件：麻醉科医疗服务能力建设指南（试行）

国家卫生健康委办公厅

2019年12月9日
