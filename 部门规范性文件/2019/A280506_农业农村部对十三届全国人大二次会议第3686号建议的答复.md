# 农业农村部对十三届全国人大二次会议第3686号建议的答复

## 对十三届全国人大二次会议第3686号建议的答复

农办议〔2019〕143号

胡建文等5名代表：

你们提出的关于支持将安仁县申报为“中国特色中药材基地”的建议收悉。现答复如下。

中药材是中医药事业传承和发展的物质基础，加快道地药材基地建设，对促进特色农业发展和农民持续增收，加快发展现代中医药产业、实现乡村振兴具有重要意义。我部高度重视中药材产业发展，会同有关部门和单位，加强规划引导，加大支持力度，促进中药材产业健康发展。一是创建特色农产品优势区。2017年，我部会同国家发展改革委、国家林业局编制印发了《特色农产品优势区建设规划纲要》，提出到2020年，创建并认定300个左右国家级特优区，重点支持标准化生产基地、加工基地、仓储物流基地、科技支撑体系、品牌建设与市场营销体系、质量控制体系等建设。国家级特优区聚焦发展特色粮经作物、特色园艺产品、特色畜产品、特色水产品、林特产品等五大类29个品种，目前已认定2批共146个国家级特优区，其中中药材特优区14个。湖南省安仁县可积极申报创建中药材国家级特优区，我部将加强调研指导，在提高特优区申报材料质量、编制特优区建设规划等方面给予指导和帮助。二是加强规划引导。按照《中医药发展战略规划纲要（2016—2030年）》和《全国农业现代化规划（2016—2020年）》要求，2018年12月，我部会同国家中医药管理局、国家药品监督管理局等单位，制定印发《全国道地药材生产基地建设规划（2018—2025年）》，引导各地优化道地药材生产布局，推进中药材规模化种植和标准化生产，提高道地药材供应能力；加强质量规范管理，推进技术集成创新，推广绿色标准化生产技术模式，提升产品质量。三是加大政策扶持力度。2017—2018年，我部每年安排中央财政资金支持开展绿色高质高效整建制创建，集成推广经济作物高产高效、资源节约、生态环保的技术模式，引领农业发展方式转变。2019年，继续安排中央财政资金支持开展绿色高质高效行动，集成“全环节”绿色高效技术，构建“全过程”社会化服务体系，打造“全链条”产业融合模式，引领“全县域”农业绿色发展，示范带动大面积提质增效。项目实行“大专项+任务清单”管理方式，资金切块下达到省，各地可结合本地农业发展规划和优势特色农业产业布局，按照相关规定统筹利用中央财政和地方资金对中药材产业发展予以支持。

下一步，我部将会同有关部门按照绿色兴农、质量兴农、品牌强农的要求，进一步加大扶持力度，支持安仁县等贫困地区中药材产业发展，着力打造一批标准化生产基地、培育一批规模经营主体、搭建一批服务平台，扎实推进精准扶贫、精准脱贫，为加快推进乡村振兴战略实施、决胜全面建成小康社会提供有力支撑。

感谢你们对农业农村工作的关心，希望对我部工作继续给予支持。
