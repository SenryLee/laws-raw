# 国家文物局办公室关于江苏天开古建筑设计有限公司文物保护工程勘察设计甲级资质证书内容变更的函

办保函〔2019〕855号

江苏省文物局：

你局《关于江苏天开古建筑设计有限公司文物保护工程勘察设计资质证书地址信息变更的请示》（苏文物保〔2019〕132号）收悉。

经研究，我局同意江苏天开古建筑设计有限公司文物保护工程勘察设计甲级资质证书中的单位地址由“武进区嘉泽镇成章街人民北路65号”变更为“武进区嘉泽镇成章人民北路68号”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年9月29日
