# 海关总署公告2019年第90号——关于全面实施TIR公约的公告

## 海关总署公告

2019年第90号

## 关于全面实施TIR公约的公告

为推动落实《国际道路运输公约》（TIR公约），海关总署决定在前期试点的基础上，全面实施TIR公约。其他事项按照海关总署公告2018年第30号、2018年第42号、2019年第41号施行。

本公告内容自2019年6月25日起施行。

特此公告。

海关总署

2019年5月15日
