# 公开市场业务交易公告[2019]第29号——关于人民银行以利率招标方式发行了2019年第一期和第二期央行票据的公告

## 公开市场业务交易公告

[2019]第29号

人民银行于本周三（2月13日）通过香港金融管理局债务工具中央结算系统（CMU）债券投标平台，以利率招标方式发行了2019年第一期和第二期央行票据。具体情况如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 发行量  （人民币） | 期限 | 中标利率 |
| 2019年第一期央行票据（香港） | 100亿元 | 3个月  （91天） | 2.45% |
| 2019年第二期央行票据（香港） | 100亿元 | 1年 | 2.80% |

中国人民银行公开市场业务操作室

二〇一九年二月十三日
