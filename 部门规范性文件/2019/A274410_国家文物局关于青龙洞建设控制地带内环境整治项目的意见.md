# 国家文物局关于青龙洞建设控制地带内环境整治项目的意见

文物保函〔2019〕158号

贵州省文物局：

你局《关于审批全国重点文物保护单位青龙洞建设控制地带内环境整治工程的请示》（黔文物呈〔2018〕64号）收悉。经研究，我局原则同意青龙洞建设控制地带内环境整治项目。

一、所报方案尚需作以下必要的修改和完善：

（一）优化建筑设计，管理用房正殿建议采用坡屋面，支摘窗类装修，青灰色调。公共厕所二应按照公共厕所一的风貌进行设计，不宜采用马头墙造型。

（二）防护网设置应尽量减小对山体的扰动。建议防护网只设置在游客经过的区域，游客未到达区域可暂不设置防护网。

（三）古驿道整治应注意保留原有路面铺装、宽度等历史信息，保护原有历史风貌。河堤加固、河道清理、绿化整治、标识设置等项目，应注意保护原有环境风貌。

（四）进一步完善设计图纸。总平面图应明确标出古驿道环境整治的位置及范围。

（五）施工期间应做好对文物本体的防护措施，控制粉尘及施工垃圾等对文物本体及环境的污染。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月14日
