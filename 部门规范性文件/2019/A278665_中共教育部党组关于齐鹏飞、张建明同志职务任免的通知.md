# 中共教育部党组关于齐鹏飞、张建明同志职务任免的通知

教党任〔2019〕138号

中共中国人民大学委员会：

经与中共北京市委商得一致，2019年5月17日研究决定：

齐鹏飞同志任中共中国人民大学委员会常委、副书记，免去张建明同志的中共中国人民大学委员会常务副书记、常委职务。

中共教育部党组

2019年6月11日
