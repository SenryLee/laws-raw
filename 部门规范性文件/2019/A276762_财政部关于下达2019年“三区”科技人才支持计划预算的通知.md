# 财政部关于下达2019年“三区”科技人才支持计划预算的通知

财科教〔2019〕23号

有关省、自治区、直辖市财政厅（局）：

为进一步加快边远贫困地区、边疆民族地区和革命老区（以下称“三区”）科技人才队伍建设，根据《科技部中组部 财政部 人力资源社会保障部 国务院扶贫办关于印发<边远贫困地区、边疆民族地区和革命老区人才支持计划科技人员专项计划实施方案>的通知》（国科发农〔2014〕105号），经研究，现下达你省（区、市）“三区”科技人才支持计划预算（项目代码：Z145050030001，详见附件），用于组织开展科技工作者选派和培养工作。上述资金列入“1100208结算补助收入”科目。

各地要按照规定落实地方应承担的经费，切实加强经费使用管理，做好此项工作组织实施。在安排使用经费时，要进一步向“三区三州”及“三区三州”之外贫困人口多、贫困程度深、脱贫难度大的其他深度贫困地区倾斜。

附件：2019年“三区”科技人才支持计划预算表

财政部
