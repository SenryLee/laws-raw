# 教育部等七部门关于组织开展“奋斗的我最美的国”新时代先进人物进校园工作的通知

教思政函〔2019〕5号

各省、自治区、直辖市党委宣传部、教育厅（教委）、国资委、工会、团委、妇联、科协，新疆生产建设兵团党委宣传部、教育局、国资委、工会、团委、妇联、科协，部属各高等学校、部省合建各高等学校：

为深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，全面落实习近平总书记在全国教育大会、全国高校思想政治工作会议、学校思想政治理论课教师座谈会上的重要讲话精神，发挥新时代先进人物的榜样示范作用，营造全社会共同关心支持高校育人工作的氛围，教育引导广大学生坚定理想信念、坚定“四个自信”、坚定爱国奋斗，中央宣传部、教育部、国资委、全国总工会、共青团中央、全国妇联、中国科协决定，组织开展“奋斗的我 最美的国”新时代先进人物进校园工作。现将有关事项通知如下。

一、总体目标

广泛宣传国家勋章、国家荣誉称号获得者，最美奋斗者、改革先锋、时代楷模等新时代先进人物的感人事迹，激励广大学生崇尚先进、学习先进、争做先进。整合社会资源服务高校育人，形成校内校外育人工作联动的长效机制，教育引领广大学生听党话、跟党走，努力成为德智体美劳全面发展的社会主义建设者和接班人。

二、工作内容

以“奋斗的我 最美的国”为主题，广泛邀请国家勋章、国家荣誉称号获得者，最美奋斗者、改革先锋、时代楷模、道德模范、劳动模范、青年五四奖章获得者、三八红旗手、大国工匠、最美人物、教书育人楷模、优秀教育工作者、优秀教师等新时代先进人物进入高校开展思想政治工作，主要包括以下内容。

（一）开展先进事迹报告会。中央宣传部、教育部、国务院国资委、全国总工会、共青团中央、全国妇联、中国科协等部门联合举办全国性示范报告会，各地各高校积极动员、广泛邀请各类先进人物代表上讲台作报告，开展党史、新中国史、改革开放史教育，为高校学生讲述革命战争故事、建设发展故事、改革开放故事、科研报国故事、创新创业故事、教书育人故事、青春奋斗故事等，以丰富阅历和家国情怀感染学生、引领学生，教育引导学生把学习奋斗的具体目标同民族复兴的伟大目标结合起来，将小我融入大我，立志作出新时代大学生的历史贡献。

（二）担任校外辅导员。深入学生群体，将工作阵地前移到课堂、实验室、宿舍、食堂，深度参与学生主题党日、主题团日、主题班会等活动，与学生开展个别谈心和集体谈话，充分利用网上网下多种途径与学生交流，围绕学生、关爱学生、帮助学生，做好学生的人生导师和知心朋友。

（三）指导实习实践。指导学生实习实训，带领学生赴企业、工厂、工地、乡村、学校等地观摩学习，帮助学生锻炼一线操作，丰富基层体验。带领学生参加社会实践，结合科学技术指导、人文艺术交流、支教志愿服务、乡村振兴行动等内容，使学生在亲身经历中锤炼本领能力，体察社情民意，在实习实践中受锻炼、增知识、长才干。

三、建立长效工作机制

（一）建立先进人物资源库。各地宣传部门、教育部门、国资委、团委、工会、妇联、科协要做好本地区本系统国家级先进人物和省级先进人物的梳理统计，在认真研究后将适合进校园开展思政工作的先进人物建议名单汇总给教育部门，建立“新时代先进人物进校园”资源库。

（二）推动双方结对。各地教育部门要根据不同类型先进人物的具体情况，结合高校实际，根据“同城就近”“双向选择”的原则，统筹做好先进人物与高校的对接，每所高校对接不少于3人。

（三）组织开展活动。各高校要迅速行动起来，积极争取相关部门指导，与先进人物联系，以报告、访谈、座谈等多种形式开展先进人物故事讲述、事迹宣讲等活动，在2020年1月底前至少开展3场。各高校要进一步结合课堂教学、校园文化、社会实践、网络文化等载体以“周讲月讲”形成工作常态化，实现师生全覆盖。

（四）纳入学生培养方案。要将此项工作纳入人才培养计划，作为学生培养方案的重要内容，将此项工作与学校人文创新学分、社会实践学分、形势与政策课或其他必修学分结合起来。要加强与先进人物工作单位的交流合作，共建教育实践基地、产学研一体化基地等，为高校师生增长才干、服务社会创造更多机会，搭建更广阔的平台。

四、工作要求

（一）加强组织领导。各地各高校要高度重视，提高政治站位，深刻认识新时代先进人物进校园工作的重要意义，把此项工作与加快构建高校思想政治工作体系、推进“三全育人”综合改革结合起来，抓好统筹规划，强化责任落实，进一步形成全员全过程全方位育人合力。

（二）加强协同联动。各地教育部门要发挥牵头作用，加强统筹谋划、系统部署。宣传部门、国资委、工会、团委、妇联、科协等单位要大力支持，协助做好先进人物信息统计、联络对接等工作。广泛充分做好动员，调动各类先进人物的积极性。各高校要明确牵头部门和责任人，增强工作主动性，主动与相关部门联络对接，努力形成上下联动、整体推进的工作格局。

（三）加强成果转化。各地各高校要系统梳理总结，凝练出可复制可推广的经验，并将工作中形成的学习成果、实践成果巩固上升为理论成果、制度成果。注重把宣讲内容转化为课堂教学和日常思政工作的丰富素材，注重通过聘请担任校外辅导员、思政课兼职教师、社会实践指导教师等方式强化与先进人物的日常互动，注重把先进人物进校园的经典案例转化为原创文化作品、网络文化作品、辅助教材讲义等，在更大范围内传播正能量。

（四）加强宣传推广。各地各高校要积极协调相关媒体，加大宣传力度，通过纸质媒体刊发专栏、专题文章，电视媒体播出专题节目、深度访谈，网络媒体发布微博微信、文章、短视频等多种形式，营造良好氛围。要及时总结工作开展情况，注重推广好经验好做法，不断推动相关工作深入持续。各地教育部门每半年要将相关情况报送教育部思想政治工作司。
