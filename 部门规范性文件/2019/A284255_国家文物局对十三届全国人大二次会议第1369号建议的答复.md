# 国家文物局对十三届全国人大二次会议第1369号建议的答复

文物保函〔2019〕677号

王怀军代表：

您提出的“关于继续支持湖南石门县万里茶道申遗工作的建议”收悉，现答复如下。

万里茶道（茶叶之路）主要指的是兴盛于17世纪至20世纪初的自中国福建等东南产茶区，途径江西、湖南、湖北、河南、河北、山西、内蒙古等省、自治区，以及蒙古、西伯利亚，西抵俄国莫斯科和圣彼得堡的以茶叶贸易为主导的欧亚商贸通道。

2012年以来，福建、江西、湖北、湖南、河南、山西、河北、内蒙古等8省、自治区每年召开“万里茶道”文化遗产保护会议，多次形成倡议和共识，目前已确定湖北省和武汉市为申遗联络省份和城市，并由其牵头成立了“万里茶道”申遗办公室，推进“万里茶道”遗产点调查认定册、清单筛选，申遗文本编制和开展相关主题研究。

我局一直高度关注万里茶道的保护和申遗工作，2019年3月已将万里茶道列入《中国世界文化遗产预备名单》。

下一步，我局将指导万里茶道沿线文物部门，开展以下工作。

一是进一步深化“万里茶道”申报世界文化遗产的基础研究，充分挖掘遗产突出普遍价值，深化比较分析，强化真实性、完整性论证，为准确选择并充分论证适用标准提供有力支撑。

二是进一步推动“万里茶道”保护管理体系建设，强化跨区域、跨部门协调合作和统筹规划，从文化线路整体保护的角度，按照统一的原则和标准，加强基础工作，针对沿途相关各级文物保护单位开展必要的保护修缮工程，提升阐释和展示水平，严格控制周边建设活动，切实维护好遗产的真实性和完整性。在第八批全国重点文物保护单位的评选过程中，我局将对万里茶道遗产点给予重点关注。

三是进一步加强“万里茶道”保护和申遗的国际合作，通过与蒙古、俄罗斯两国文物保护管理部门、考古科研机构和相关协会的交流与合作，积极推进跨国联合申遗行动，深化与两国间的文明交流互鉴。

目前，湖南省常德市石门县壶瓶山镇茶号建筑群、石门古茶道水南渡段、夹山寺，已被确认为“一般推荐申报”遗产点，列入万里茶道申遗文本。我局将指导当地有关部门，妥善做好文物本体保护修缮工作，按世界遗产的标准，保护好遗产周边环境，深入挖掘与万里茶道突出普遍价值的关联度和支撑点，有序开展各项保护和前期申遗工作。

我局将按《国家文物保护专项资金管理办法》的规定，对万里茶道遗产点的规划编制、保护修缮、阐释展示等项目，给予尽可能的资金支持。

衷心感谢您对我国世界文化遗产工作的关注和支持！

国家文物局

2019年7月10日
