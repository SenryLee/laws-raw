# 国家铁路局关于发布铁路工程造价标准的公告（2019年第1批）

国铁科法〔2019〕46号

现公布《铁路工程估算定额 （第一册 通信工程）》（TZJ 2201-2019）等8项铁路工程造价标准（详见附件1），自2020年4月1日起实施。《铁路工程概算指标 （第一册 通信工程）》（铁建〔1998〕42号）等10项铁路工程造价标准（详见附件2）同时废止。

以上标准由中国铁道出版社出版发行。

附件：1. 新发布标准目录

2. 废止标准目录
