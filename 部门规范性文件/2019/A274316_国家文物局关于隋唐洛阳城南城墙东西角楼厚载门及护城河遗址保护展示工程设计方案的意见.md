# 国家文物局关于隋唐洛阳城南城墙东西角楼厚载门及护城河遗址保护展示工程设计方案的意见

文物保函〔2019〕133号

河南省文物局：

你局《关于报批隋唐洛阳城南城墙东西角楼厚载门及护城河遗址保护展示工程设计方案的请示》（豫文物〔2018〕313号）收悉。经研究，我局原则同意厚载门遗址地面模拟和护城河遗址展示方案，暂不同意东角楼遗址、西角楼遗址展示方案。

一、所报方案尚需做以下必要的修改和完善：

（一）应明确东西角楼、厚载门遗址展示设计的考古依据，厘清遗址的范围、布局、形制、历史沿革，补充相关考古勘探和发掘资料。

（二）厚载门遗址展示应在方案二地面模拟展示的基础上，进一步完善设计，综合考虑视觉效果和安全维护需要，合理确定厚载门门道墩台规模、高度和工艺材料；同时，建议根据考古工作成果，进一步明确厚载门的建筑形制，标识展现城门遗址的整体规模、构造等，不宜完全仿效定鼎门和长厦门的建筑尺度。

（三）细化护城河展示设计内容，进行照明、防排水、道路、停车场、公共卫生间等设施建设和场地铺装过程中，严格控制施工范围，注意文物安全。

（四）充分考虑东角楼遗址、西角楼遗址的保存现状和隋唐洛阳城遗址展示需要，研提多种展示比选方案，加强保护性设施功能布局、外观样式、文物影响等方面研究，增强科学性和可操作性。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古调查和发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

五、近日，有群众举报隋唐洛阳城南城墙角楼遗址存在未批先建问题。请你局尽快调查核实，研提处理意见，并将有关情况报送我局。

专此函复。

国家文物局

2019年1月31日
