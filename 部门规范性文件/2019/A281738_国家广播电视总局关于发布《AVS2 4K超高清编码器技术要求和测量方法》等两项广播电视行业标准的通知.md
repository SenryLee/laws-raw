# 国家广播电视总局关于发布《AVS2 4K超高清编码器技术要求和测量方法》等两项广播电视行业标准的通知

## 总局关于发布《AVS2 4K超高清编码器技术要求和测量方法》等两项广播电视行业标准的通知

广电发〔2019〕77号

各省、自治区、直辖市广播电视局，新疆生产建设兵团文化体育广电和旅游局，总局国网公司、无线局、监管中心、卫星直播中心、广科院、规划院、设计院，中央广播电视总台办公厅，电影频道节目中心：

国家广播电视总局组织审查了《AVS2 4K超高清编码器技术要求和测量方法》《AVS2 4K超高清专业卫星综合接收解码器技术要求和测量方法》，现批准为中华人民共和国广播电视推荐性行业标准，予以发布。

标准编号为：

GY/T 323-2019 《AVS2 4K超高清编码器技术要求和测量方法》；

GY/T 324-2019 《AVS2 4K超高清专业卫星综合接收解码器技术要求和测量方法》。

上述两项标准自发布之日起实施，标准内容在国家广播电视总局门户网站（http://www.nrta.gov.cn）公开。

附件：1.AVS2 4K超高清编码器技术要求和测量方法

2.AVS2 4K超高清专业卫星综合接收解码器技术要求和测量方法

国家广播电视总局

2019年9月5日
