# 反兴奋剂中心关于做好第二届全国青年运动会反兴奋剂教育参赛资格准入工作的通知

体反兴奋剂字〔2019〕232号

各省、自治区、直辖市、新疆生产建设兵团体育局，有关运动项目管理中心（协会）：

为深入推进全覆盖、全周期、常态化、制度化的反兴奋剂教育，做好第二届全国青年运动会（以下简称“二青会”）反兴奋剂宣传教育工作，反兴奋剂中心决定对参加二青会的运动员及辅助人员实施反兴奋剂教育参赛资格准入工作（以下简称“准入工作”）。现将有关事宜通知如下：

一、总体要求

二青会准入工作的实施对象为所有参加二青会的运动员及辅助人员。

所有准入工作的实施对象必须接受系统的反兴奋剂教育，通过反兴奋剂准入考试，宣誓并签署反兴奋剂承诺书，经参赛单位审批后方能获得二青会的参赛资格。

二、职责分工

反兴奋剂中心负责制定二青会准入工作方案；开发反兴奋剂教育准入手册、课件、讲座视频；指导并跟进各参赛单位准入工作；开展监督检查工作；汇总准入工作实施情况。

参赛单位负责按照本通知要求组织实施本单位准入工作；进行反兴奋剂准入资格审批；配合开展监督检查工作。

三、工作流程

（一）各参赛单位应成立准入工作领导小组，指定专人负责准入工作的实施。

（二）准入对象应完成准入工作五项环节，具体操作说明如下：

1.学习

准入对象须接受标准课件《反兴奋剂工作六项规定》的学习。

2.考试

准入对象须在完成学习内容后进行准入考试。满分100分，80分为及格。

3.承诺

准入对象须签署“反兴奋剂承诺书”。

4.宣誓

准入对象须进行反兴奋剂宣誓。

5.审批

各参赛单位对准入对象进行资格审批。

（三）参赛单位可在“反兴奋剂中心官网-二青会专区”的“技术支持”下载准入手册、课件、视频等资料开展集体学习、宣誓等形式多样的反兴奋剂教育准入工作。

（四）各参赛单位应在全部准入工作结束一周之内将工作总结，连同准入工作实施过程中的图片、视频等材料报送反兴奋剂中心。

四、监督检查

各参赛单位应对准入过程和准入结果进行监督检查。如在监督检查过程中，发现准入对象存在未完成准入工作、弄虚作假、抽查考试不合格的情况，将视情节给予相关当事人和责任人处罚。

反兴奋剂中心将组成专门工作组调研和监督各参赛单位准入开展情况。
