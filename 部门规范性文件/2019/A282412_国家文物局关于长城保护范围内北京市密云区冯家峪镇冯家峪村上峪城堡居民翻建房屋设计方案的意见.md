# 国家文物局关于长城保护范围内北京市密云区冯家峪镇冯家峪村上峪城堡居民翻建房屋设计方案的意见

文物保函〔2019〕935号

北京市文物局：

你局《关于长城保护范围内北京市密云区冯家峪镇冯家峪村上峪城堡居民翻建房屋设计方案的请示》（京文物〔2019〕1138号）收悉。经研究，我局原则同意在长城保护范围内实施北京市密云区冯家峪镇冯家峪村上峪城堡居民翻建房屋建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）补充完善实测设计图纸，明确拟建项目与长城保护区划的空间关系，并对照保护区划管理规定，就拟建项目的符合性作出说明。

（二）补充开展上峪城堡平面布局调查，评估堡墙及现状建筑，明确其历史价值，记录其材料、形制及工艺，并在翻建工程中尽可能加以沿用。

（三）深化拟建项目设计方案，适当调整、增大拟翻建的建筑与堡墙之间的距离，补充空气源热泵选址及安装技术要求，补充上峪城堡环境整治措施。

二、请你局组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年9月5日
