# 中共教育部党组关于林东伟、国亚萍同志职务任免的通知

教党任〔2019〕56号

中共中山大学委员会：

经与中共广东省委商得一致，2019年2月1日研究决定：

林东伟同志任中共中山大学委员会委员、常委、副书记，免去国亚萍同志的中共中山大学纪律检查委员会书记职务。

中共教育部党组

2019年3月6日
