# 国家文物局关于明长城部分墙体及敌台保护区划内中马铁路至兰州方向联络线工程建设项目的意见

文物保函〔2019〕418号

甘肃省文物局：

你局《关于呈报中马铁路至兰州方向联络线工程通过长城遗址设计方案的请示》（甘文局发〔2019〕58号）收悉。经研究，我局原则同意按照所报方案二在明长城部分墙体及敌台保护区划内实施中马铁路至兰州方向联络线工程建设项目。

一、所报方案二尚需作以下必要的修改和完善

（一）应组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘，明确地下遗存分布情况。如有长城墙体、壕堑等重要遗迹发现，应调整设计方案，确保文物安全。

（二）应完善项目施工方案，明确振动控制、施工组织及监测预警措施，严格防范施工对长城本体及其周边环境造成破坏。

（三）应补充项目施工期间的长城本体临时性保护措施、应急预案以及完工后的环境修复措施，并结合项目实施设置长城保护标志、保护界桩和警示标识。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月5日
