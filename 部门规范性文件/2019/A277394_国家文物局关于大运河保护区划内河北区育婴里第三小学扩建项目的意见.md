# 国家文物局关于大运河保护区划内河北区育婴里第三小学扩建项目的意见

文物保函〔2019〕413号

天津市文物局：

你局《关于上报大运河建设控制地带内实施河北区育婴里第三小学扩建项目的请示》（津文物发〔2019〕1号）收悉。经研究，我局原则同意在大运河保护区划内实施河北区育婴里第三小学扩建项目。

一、所报方案尚需作以下必要的修改和完善

（一）应组织专业考古机构对拟建项目相关区域做进一步考古调查、勘探和必要的考古发掘，明确地下文物埋藏情况。如有大运河水工遗存等重要发现，应调整设计方案，确保文物安全。

（二）应优化项目选址，将其适当北移，确保施工开挖面避让保护范围，并尽可能扩大拟建建筑与龙关南路之间的绿化带范围。

（三）应进一步明确地上建筑面积、地下建筑面积、建筑高度等经济技术指标，并在满足教学需要的情况下，尽可能压缩建筑体量、高度，尽可能降低该项目对大运河环境景观的影响。

（四）应补充拟建建筑与龙关南路之间的绿化带设计方案，适当扩大绿化面积，缩小硬化地面的面积。

（五）应补充施工期间的管理规定、监测措施和应急预案，加强施工期间的监督管理，确保项目施工和运行期间的文物本体安全和环境风貌协调。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月5日
