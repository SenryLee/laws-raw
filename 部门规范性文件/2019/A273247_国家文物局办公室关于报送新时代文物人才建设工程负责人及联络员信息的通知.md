# 国家文物局办公室关于报送新时代文物人才建设工程负责人及联络员信息的通知

办人函〔2018〕1274号

各省、自治区、直辖市文物局（文化和旅游厅/局），新疆生产建设兵团文物局，各直属单位：

2014年以来，在各单位的支持下、各位联络员的辛勤努力下，国家文物局实施的文博人才培养金鼎工程取得了丰硕成果，培训数量逐步扩大，培训质量日益提高，已经形成专业培训与学历教育相结合、线下培训与线上学习相结合，人才培养形式多样、梯次结构合理的良好发展态势。

为贯彻落实中办、国办《关于加强文物保护利用改革的若干意见》关于新时代文物人才建设的要求，我局决定在顺利推进金鼎工程的基础上实施新时代文物人才建设工程，我局正在研究制订有关实施方案。该人才工程将更具有针对性、时代性，将有效提升文物行业从业者的专业技能和管理水平，大力推动我国文博事业健康发展。

为确保新时代文物人才建设工程顺利实施，现就联络员有关工作通知如下：

一、请各省级文物行政部门、各直属单位确定新时代文物人才建设工程负责人及联络员，原金鼎工程联络员可继续担任新时代文物人才建设工程联络员。

二、联络员确定后请勿随意更换，如确需更换的，请妥善做好交接工作，并及时将变更信息报送我局。

三、联络员要做好人才调研工作，根据人才队伍状况和行业发展趋势，分析存在的问题，提出本辖区、本单位文博人才培养和队伍建设的需求，不断提高人才培养质量和水平。

四、联络员要认真学习贯彻国家人才工作的方针政策，及时传达国家文物局人才工作的要求，协调督促完成本辖区、本单位各项人才工作任务。

五、请各省级文物行政部门、各直属单位高度重视，按照要求填写《新时代文物人才建设工程负责人及联络员信息表》，于2019年1月11日前报送我局（电子版请通过Email同时报送）。
