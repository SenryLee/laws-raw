# 国家文物局关于关陵保护范围和建设控制地带内关陵片区保护利用项目的意见

文物保函〔2019〕449号

湖北省文化和旅游厅：

你厅《关于呈报关陵片区保护利用方案涉及关陵保护范围和建设控制地带的请示》（鄂文旅文〔2019〕32号）收悉。经研究，我局原则同意在关陵保护范围和建设控制地带内实施关陵片区保护利用项目。

一、所报方案尚需作以下必要的修改和完善

（一）进一步梳理和研究关陵与其周边村庄的历史空间关系，逐一评估拟拆迁范围内建筑现状和价值，综合考虑关陵保护利用的实际需要和现有建筑改造利用的可能性，避免大拆大建，尽可能延续关陵历史景观风貌的完整性。

（二）严格控制工程范围和施工强度，做好施工中的文物保护工作，确保文物安全。

二、请你厅组织专业考古研究单位，在项目拟建区域进一步开展必要的考古工作，考古发掘项目需另行填报考古发掘申请书。

三、请你厅指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你厅会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

五、请你厅加强指导，督促当阳市人民政府合理安排关陵保护区划范围内的新建项目，协调处理文物保护利用与城市建设、民生改善的关系。

专此函复。

国家文物局

2019年5月15日
