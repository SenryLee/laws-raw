# 农业农村部对十三届全国人大二次会议第2416号建议的答复

## 对十三届全国人大二次会议第2416号建议的答复

农办议〔2019〕29号

郭凤莲等8名代表：

你们提出的“关于国家设立专项研发资金，解决特色农作物无机可用，有机难用的问题的建议”收悉。经商财政部，现答复如下。

农业机械化是农业现代化的重要标志。近几年，为推进农机化科技创新，促进科技成果转化和推广应用，解决特色农作物无机可用、有机难用问题，国家不断加大科研投入力度。一是实施了“十三五”国家重点研发计划“智能农机装备”专项，其中设立“特色杂粮收获技术与装备研发”“农特产品收获技术与装备研发”等项目，支持高等院校、科研单位、农机制造企业联合攻关，推进特色农作物机械化生产关键技术与装备研发；二是在国家现代农业产业技术体系中，设立了谷子、高粱、燕麦、食用豆等机械化岗位专家和机械装备研究室，开展特色农作物农机化共性关键技术研究，充分发挥技术创新、试验示范、辐射带动的积极作用；三是在《农业科技创新能力条件建设规划（2016—2020年）》中，加大对“现代农业装备”学科群和农业机械化科学实验基地建设的支持力度，推进包括特色农作物机械化在内的技术基础与关键部件、主要生产环节的机械化技术与装备、农机性能质量评价等研究；四是通过基本运行经费、基本科研业务费、中央级科学试验单位修缮购置专项资金、国家重点实验室专项经费等，加大对农业机械化相关领域中央级科研院所、国家重点实验室稳定支持力度，支持其改善科研基础条件、自主开展研究等。

今后，我们将积极争取有关部门支持，科学谋划未来5至10年农机化科研的重点任务和重点课题，通过组织重大科技攻关，加快急需的农业机械化技术研究、示范和推广应用，重点解决好山西等地区特色农作物无机可用、有机难用问题，加快现代农业建设步伐。

感谢你们对农业机械化工作的关心，希望继续对我部工作给予支持。
