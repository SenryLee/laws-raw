# 国家文物局关于吴越国王陵钱鏐墓、康陵、钱宽水邱氏墓保护规划的意见

文物保函〔2019〕422号

浙江省文物局：

你局《关于再次上报全国重点文物保护单位吴越国王陵钱鏐墓、康陵、钱宽水邱氏墓保护规划的请示》（浙文物发〔2019〕14号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）加强考古资料和历史文献研究，明确吴越国王陵总体布局、选址特点，以及钱鏐墓、康陵、钱宽和水邱氏墓之间的空间位置关系，在此基础上科学确定文物构成和环境要素等，科学凝练价值评估内容，客观评价吴越国王陵的陵寝制度特点和营建技术。

（二）深化现状评估，科学分析保护区划范围内村庄、仿古建筑、现状道路等的文物影响，统一评价标准。应研究文物历史环境特点，在此基础上评价现有景观绿化和建构筑物的科学性、合理性。

（三）进一步明确保护区划调整依据，康陵东南部山体仍应划入建设控制地带。结合视线分析结果，细化钱鏐墓与石镜山和功臣山、康陵与朝山等环境要素之间的视廊宽度、建设控制高度等具体指标，明确城市交通、桥梁、隧道等基础设施建设管理规定；建设控制地带II区内村庄建筑应加强管控力度。

（四）深化展示利用规划，重点展现吴越国历史和文化特色，建议近期以现有展示提升为主，不宜大规模新建展示服务设施、新增展示项目。不同意恢复康陵、钱宽和水邱氏墓神道，建议标识展示；明确康陵出入口区域的环境整治措施；充分评估陵园展示前景、游客量和现有设施承载力，控制展示范围和设施建设强度，避免过度展示。

（五）联合专业考古机构完善考古工作计划，明确考古工作目标、主要任务及近期工作重点。应根据文物保护展示需要，进一步调整考古工作重点，尽快摸清重要遗存的分布与保存现状，梳理陵园整体格局，为科学阐释和展示吴越国的陵寝制度和社会面貌提供依据。

（六）完善专项规划。明确穿越钱宽和水邱氏墓的城市道路调整措施，并根据文物保护展示需要调整内部道路设计，注意展现陵园整体格局；应考虑分期拆除钱鏐墓周边各类影响文物景观的建构筑物，尽量恢复原有景观风貌；加大界桩间距；明确近期保护工程实施计划。

（七）加强与临安市城乡总体规划等规划的衔接，系统梳理各类规划的区域控制要求，增强可操作性。规范图文表达，校核文本内容，做到先后一致，补充现状展示利用图。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将吴越国王陵钱鏐墓、康陵、钱宽水邱氏墓保护规划报请浙江省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府，在保护规划的指导下，进一步做好吴越国王陵的各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年5月5日
