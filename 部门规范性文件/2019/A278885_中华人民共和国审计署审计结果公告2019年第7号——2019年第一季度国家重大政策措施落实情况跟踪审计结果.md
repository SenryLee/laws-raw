# 中华人民共和国审计署审计结果公告2019年第7号——2019年第一季度国家重大政策措施落实情况跟踪审计结果

## 中华人民共和国审计署审计结果公告

2019年第7号

## 2019年第一季度国家重大政策措施落实情况跟踪审计结果

2019年第一季度，审计署组织对31个省（自治区、直辖市，以下统称省）、新疆生产建设兵团和35个中央部门、15家中央金融机构、10户中央企业进行审计，围绕推动经济高质量发展和供给侧结构性改革，聚焦减税降费政策实施、三大攻坚战推进以及稳就业、稳金融、稳外贸、稳外资、稳投资、稳预期等政策措施落实情况，抽查了1728个单位、3643个项目，涉及资金4449.15亿元，并对以往审计查出问题整改情况进行了跟踪检查。从审计情况看，有关地区和部门认真贯彻落实党中央、国务院决策部署，坚持稳中求进工作总基调，按照高质量发展要求，结合实际主动作为，着力推进供给侧结构性改革，激发微观主体活力，创新和完善宏观调控，推动经济持续健康发展。但一些地区和部门在落实减税降费政策措施，贯彻稳就业、稳金融、稳外贸、稳外资、稳投资、稳预期要求，深化“放管服”改革，推进三大攻坚战等方面还存在一些问题。

**一、**部分地区和部门降费减负不到位，甚至违规收费

审计重点关注了减税降费政策落实情况，重点抽查了有关地区和部门落实税收优惠政策、执行涉企收费目录清单制度、清理规范行政审批中介服务、依托行政资源或权力收费等事项。被审计地区和部门不断加大减税降费政策措施贯彻落实力度，提升企业和群众的获得感，但仍发现4个省的6个部门或单位通过征收已停征的行政事业性收费、向企业转嫁应由财政资金承担的费用、依托行政职权及影响力垄断经营等方式违规收费，或未及时退还企业多缴纳的社会保险费等共计3.18亿元；6个省的8家单位在未转企改制或未与主管部门脱钩的情况下，依托主管部门的行政审批事项开展中介服务并收取费用3113.91万元；12个省和3个中央部门的26家单位违规收取或未及时清退12类保证金9.07亿元。

**二、**部分地区和部门落实“六个稳”相关工作有待进一步加强

审计重点关注了中央就业补助资金管理使用、政府服务外贸外资企业、纳入国家“十三五”规划及获得中央财政投资的重大项目进展等“六个稳”相关政策措施落实情况。被审计地区和部门积极采取措施扎实做好稳定和扩大就业、改善外商投资服务、推进重大项目建设等工作，取得一定成效，但仍发现4个省相关地区的4项就业创业政策落实不到位；4个省部分地区的创业担保贷款贴息、稳岗补贴等财政资金使用不规范，涉及金额1661.92万元；2个省商务备案与工商登记“一口办理”工作推进不力；20个省和1户央企的7个国家“十三五”规划重大工程项目以及96个基础设施、民生等项目存在逾期未开（完）工、长期停工、闲置及未达到预期效果等问题，涉及投资459.1亿元。

**三、**部分地区和部门简政放权不到位

审计重点关注了规范行政审批行为、改进行政审批工作、清理违规设置不合理限制条件等政策措施落实情况。被审计地区和部门能够不断推进简化审批事项、优化审批服务、探索创新监管理念和方式，但仍发现2个省的相关单位和1个中央部门扩大行政审批范围、未按规定规范行政审批中介服务事项或办理行政审批事项不及时；2个省相关部门和单位在工程项目招标等活动中设置地域、注册资本等不合理限制条件。

**四、**部分县区扶贫政策落实不到位，一些扶贫资金和项目管理能力有待进一步提升

重点抽查了32个贫困县，其中国家扶贫开发工作重点县（含集中连片特殊困难地区县）22个，抽审资金90.45亿元，涉及2491个项目、262个乡镇、590个行政村，入户走访1327个贫困家庭。被审计地区持续落实各项扶贫政策，加大民生投入，加大对残疾、重病等特殊贫困群体的救助力度，发挥产业扶贫对贫困人口的带动作用，但仍发现25个县落实产业、健康、教育等扶贫政策不到位；11个县存在违规将扶贫资金用于非扶贫领域，重复发放补贴资金及扶贫资金被套取等问题，涉及金额7881.36万元；17个县的401个扶贫项目存在进展缓慢、项目建成后闲置或无法使用、管理不规范、项目资金闲置甚至形成损失浪费等问题，涉及金额13.48亿元。

**五、**部分地区污染防治目标任务未完成，重点区域生态保护不到位

审计重点关注了污染防治目标任务完成、自然保护区等重点区域生态保护等情况，重点抽查了污染物处理、生态修复等污染防治工程项目的实施情况。被审计地区和部门深入实施国家污染防治行动计划，加大生态系统保护和修复工程支持力度，但仍发现9个省部分地区和1户央企下属单位的4项污染防治目标任务未按要求完成；7个省部分地区的自然保护区和饮用水水源地生态保护不到位；10个省相关地区的23个污染防治工程项目未按期开（完）工，涉及投资34.56亿元，4个省部分地区污染物未有效处理。

此外，对2019年第一季度跟踪审计反映的问题，25个省和部门的相关单位在审计过程中积极开展整改工作，落实责任主体，压实整改责任，通过清退税款和违规收费、清偿拖欠民营企业账款、归还原资金使用渠道等方式，整改问题金额2.04亿元，推动优化审批事项4项，完善相关规章制度3项。如杭州萧山国际机场有限公司1477.28万元逾期投标保证金已全部清退；甘肃省发展改革委于2019年3月印发通知，取消了省外售电公司参与甘肃地区电力市场交易的政策限制。
