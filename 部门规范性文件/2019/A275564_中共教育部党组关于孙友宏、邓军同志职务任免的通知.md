# 中共教育部党组关于孙友宏、邓军同志职务任免的通知

教党任〔2019〕63号

中共中国地质大学（北京）委员会：

经与中共北京市委商得一致，2019年3月6日研究决定：

孙友宏同志任中共中国地质大学（北京）委员会委员、常委、副书记，免去邓军同志的中共中国地质大学（北京）委员会副书记、常委职务。

中共教育部党组

2019年3月14日
