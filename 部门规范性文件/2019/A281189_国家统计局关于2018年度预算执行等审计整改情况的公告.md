# 国家统计局关于2018年度预算执行等审计整改情况的公告

2018年11月至2019年3月，审计署对国家统计局2018年度预算执行等情况进行了审计。根据《审计报告》要求，国家统计局认真组织开展了整改工作，现将有关情况公告如下：

一、预算执行中存在的主要问题及整改情况

1.2018年，统计局批准11个团组在国（境）外超期停留，共超规定57人·天。

整改情况：已整改完成。国家统计局进一步加强制度建设，对今后的出国团组严格按照要求审核，已向全局印发《进一步重申和加强我局因公临时出国（境）团组管理的通知》，加强对因公出国团组管理。

2.2018年，统计局本级6个四类会议人数超规定标准共168人。

整改情况：已整改完成。2019年严格执行会议管理办法，未出现会议超标现象。

3.统计局本级预算编制不完整，其他收入1000万元未纳入当年预算管理。

整改情况：已整改完成。将此类收入全部纳入预算管理，编制预算时充分预计、准确反映其他收入。

4.统计局本级未及时清理中央一般公共预算结余资金122.08万元。

整改情况：已整改完成。已将需要交回的结余资金向财政部申请退回，待批复后上缴。

5.部分所属事业单位采购办公设备等未按规定执行政府采购，涉及金额20.92万元。

整改情况：已整改完成。信息景气中心今后将按照政府采购相关规定，严格执行政府采购规定，制定配套管理制度，规范办公设备采购等工作。

二、决算草案存在的主要问题及整改情况

1.统计局本级及部分所属事业单位资产账实不符，涉及金额12079.37万元。

整改情况：已整改完成。已按要求，将资产纳入会计账目核算，并登记相应资产卡片，信息已全部录入行政事业单位资产管理信息系统中，修订了资产管理办法，进一步加强制度建设和执行监督。

2.部分所属事业单位少计收入2327.4万元，少计支出1583.85万元，导致决算报表不完整。

整改情况：已整改完成。完成经费科目调整，将收入和支出纳入相应科目核算。

三、2019年第一季度贯彻落实国家重大政策措施情况跟踪审计存在的主要问题及整改情况

1.数管中心拖欠企业账款559.5万元，其中拖欠民营企业账款349.8万元。

整改情况：已整改完成。数管中心采取补签合同解决欠款问题的方式，已完成所有合同签订及款项支付。

2.统计局对下属32家调查总队及其1180家三级预算单位开展清理拖欠民营企业账款工作不及时。

整改情况：已整改完成。在审计期间立行立改，当即向各调查总队下发通知，在全系统开展了清理拖欠账款工作。

3.统计局个别内部管理制度不符合现行相关法律规定，导致2018年部分调查队从地方政府取得的4817.04万元资金未纳入中央账表。

整改情况：已整改完成。已修订相关经费管理办法，严格按照现行法律规定，要求调查队将从地方取得的资金纳入中央账表。

4.科研所未有效管理全国统计科学研究项目课题结项工作，203项重大或重点研究项目未按时结项，涉及资金430.3万元。

整改情况：已整改完成。科研所已认真清理未结项目，并及时联系项目负责人，将项目办结或者办理延期结项手续。

四、其他主要问题及整改情况

1.统计局项目支出绩效自评工作未做到全覆盖。

整改情况：已整改完成。将在2019年绩效自评工作中，要求有项目支出预算的所有单位开展绩效自评，严格按照全面实施绩效管理的规定，实现统计部门绩效管理全覆盖。

2. 统计局2017年个别项目绩效自评结果与实际实施情况差异较大。

整改情况：已整改完成。统计局在开展2018年绩效评价中，按照《财政支出绩效评价管理暂行办法》相关规定，严格把关、实事求是，确保绩效评价结果的真实完整、客观公正。

3.中国信息报社少计收入966.74万元。

整改情况：已整改完成。中国信息报社及时清理往来账款，将应调整会计科目的款项予以调整，应确认收入的款项予以确认收入。

特此公告。
