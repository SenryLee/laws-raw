# 生态环境部宣传教育司关于报送2019年图书质量专项检查结果的函

## 关于报送2019年图书质量专项检查结果的函

宣教函〔2019〕7号

国家新闻出版署：

按照你署《关于开展图书“质量管理2019”专项工作的通知》（国新出发〔2019〕7号）要求，我部积极组织中国环境出版集团有限公司（以下简称出版公司）开展公司质量自查，并按要求完成抽查工作，现将检查结果函告如下：

出版公司2018年1月至12月（以图书版权页出版时间为准）出版教辅、科普、少儿类图书共计62种，其中教辅类图书25种，科普类图书24种，少儿类图书13种，未出版文艺类、教材类图书。自查阶段，出版公司随机抽查图书12种，差错率均在零至万分之零点六二之间，符合《通知》10 ％检查比例以及《图书质量管理规定》对差错率不超过万分之一的要求。

在出版公司自检的基础上，按照《通知》关于主管部门对出版单位不少于5种图书的内容和编校质量进行检查的要求，我们抽取了《环境教育（新疆版）高中一年级（下）》《环境保护与生态文明教育：澄迈县地方教材·八年级》《农村环保知识问答》《农村污染防治知识问答》《农村环境与健康知识读本》《农村妇女健康知识读本》《中学生消防安全知识读本（第二版）》《凹凸触感摸摸书·生活》8种图书，抽检结果均符合《图书质量管理规定》要求。

经检查，出版公司出版的教辅类、科普类、少儿类图书内容及编校质量全部合格，现将所检图书和2019年出版物质量专项检查结果汇总表（见附件1）、图书编校质量检查结果记录表（见附件2）、2019年出版物质量专项检查分析报告（见附件3）报送你署，请审核。
