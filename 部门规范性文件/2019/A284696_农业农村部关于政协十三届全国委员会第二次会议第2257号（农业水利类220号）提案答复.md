# 农业农村部关于政协十三届全国委员会第二次会议第2257号（农业水利类220号）提案答复

## 关于政协十三届全国委员会第二次会议第2257号（农业水利类220号）提案答复

农办案〔2019〕191号

张周平委员：

您提出的关于支持青海打造高原绿色有机农产品示范省的提案收悉。经商商务部、科技部、生态环境部，现答复如下。

青海打造高原绿色有机农产品示范省，是贯彻落实习近平总书记“青海最大的价值在生态、最大的责任在生态、最大的潜力也在生态”指示精神的重要举措。2019年3月1日，农业农村部与青海省人民政府签署了《农业农村部青海省人民政府共建青海绿色有机农畜产品示范省合作框架协议》，内容包括：应用绿色防控技术，支持有机肥替代化肥，协同推进化肥农药减量增效行动；创建现代农业产业园，建设产业化联合体，协同培育高原特色绿色有机农畜产品；完善各级质量安全监测监管体系，协同推进特色农畜产品追溯体系建设；完善特色农畜产品标准体系，协同创建农畜产品特色品牌；支持农作物秸秆和畜禽粪污循环利用，协同推进农业废弃物资源化利用；强化种养业良种及生产管控体系建设，促进青海省与国家有关科研单位的合作，协同推进农牧业科技服务体系和智力支撑。您提出的建议，对青海打造高原绿色有机农畜产品示范省工作具有重要的参考价值。

一、关于帮助青海省建立全域农业资源环境管控体系

根据《土壤污染防治法》和《国家质量兴农战略规划（2018—2022年）》有关要求，我部会同生态环境部先后开展塑料污染防治和国家有机食品生产基地建设与考核等工作。我部支持青海省开展农产品产地土壤污染调查监测与治理修复，强化农产品产地环境管控能力，建立健全水、土、气一体化、网络化、智能化的监控体系，开展残膜回收相关标准的制修订和残膜与农兽药包装废弃物回收处理等工作。

下一步，我部将围绕《土壤污染防治行动计划》中“到2020年，全国土壤污染加重趋势得到初步遏制，土壤环境质量总体保持稳定，农用地和建设用地土壤环境安全得到基本保障，土壤环境风险得到基本管控等”目标任务，支持青海省做好对大气和水域的调查监测与预警工作，会同有关部门对农田灌溉水检测与净化治理，确保水源符合农田灌溉水质标准。支持青海省对土壤已污染区域采取测土配方施肥、种植结构调整、生物与物理防治等举措进行治理。支持青海省对农兽药包装废弃物回收，引导生产企业和广大群众使用绿色包装和减量包装。

二、关于协助青海省建立科技支撑体系

“十三五”期间，科技部启动了“现代食品加工及粮食收储运技术与装备”重点专项，支持青海威思顿薯业集团有限责任公司参与“薯类主食化加工关键新技术装备研发及示范”项目研发工作，在薯条精深加工方面开展联合科技攻关，实施了“主要食品全产业链品质质量控制关键技术开发研究”和“果蔬冷链物流技术及装备研发示范”2个项目。我部已拨付中央财政资金2800万元，支持青海省组建牦牛、藏羊、青稞、冷水鱼等10个农牧业科技推广三级平台，组织实施农业有害生物监测站（点）建设，土壤和网格点监测工作。

下一步，我部将积极指导青海省组建农牧业科技推广三级平台，完善有害生物监测站、网络平台和省市（州）县三级动物疫病防控体系，加强农业有害生物监测与防控。会同科技部等部门按照《关于深化中央财政科技计划（专项、基金等）管理改革方案》（国发〔2014〕64号）文件精神，促进青海有关单位与国内外科研院所、企事业单位的合作交流，加大对青稞、马铃薯等高原绿色有机农产品科技创新支持力度。同时，强化科学技术集成与创新，搭建全方位合作交流平台，研发适合青海实际的高端大型智能农机，示范推广节水、节肥、节药等绿色高产高效关键技术，为青海全域绿色有机农产品基地建设提供技术支持。

三、关于帮助青海省开展化肥农药使用减量行动

2015年我部制定印发了《到2020年化肥使用量零增长行动方案》和《到2020年农药使用量零增长行动方案》，结合2017年印发的《耕地质量保护与提升行动方案》，支持青海省47家有机肥生产销售企业成立了有机肥产业联盟，现已拨付中央财政资金500万元支持青海开展有机肥替代化肥行动，637万元支持秸秆综合利用工作。生态环境部将国家有机食品生产基地建设作为转变农业生产方式、减少农业面源污染防治的重要举措，指导青海省开展农作物病虫害绿色防控面积达45.17万亩，实现年度主要农作物化肥农药使用量零增长。

下一步，我部继续支持青海省完善农户种植收益补偿机制，开展化肥、农药使用减量行动，支持青海省发展规模化生态养殖、生态种植和循环农牧业，协同生态环境部支持青海做好生态环境改善和有机食品基地建设等工作。

四、关于建立全省统一的农产品质量安全追溯管理体系

按照《国务院办公厅关于加快推进重要产品追溯体系建设的意见》要求，我部印发实施了《农业部关于加快推进农产品质量安全追溯体系建设的意见》等6项配套制度，制定《农产品质量安全追溯数据格式规范》《农产品质量安全追溯管理专用术语》等11项追溯技术标准。我部已拨付中央财政资金2000万元支持青海省开展牦牛藏羊追溯工作。商务部和财政部分别于2012年和2014年将青海省西宁市、海东市纳入肉菜追溯试点城市。

下一步，我部将会同有关部门，指导支持青海省建立统一的农产品质量安全追溯管理体系，逐步实现青海省级追溯平台与国家追溯平台的有效对接和融合。鼓励青海企业建立智能化农产品生产基地，推进农产品质量安全监管精准化和可视化。

五、关于造好叫响青海省全域绿色有机农产品品牌

我部积极支持青海省绿色有机农畜产品品牌建设工作，依托中国国际农产品交易会、农博会、农展会、世博会、展销会和各类推介会等平台，推介牦牛、青稞、冷水鱼等优势特色优质农畜产品。培育青海绿色有机农畜产品公共品牌、企业品牌和农畜产品品牌200多个，打造知名商标50多个。支持青海省创建特色农产品优势区2个。

下一步，我部将会同财政部、商务部积极扶持青海省优势特色农牧业发展与品牌建设工作，支持青海省依托当地资源优势和特色产业，培育打造一批有影响力的区域公用品牌、企业品牌和产品品牌。

六、关于支持青海省建立高原特色有机农产品物流园和冷链配送体系

2016—2017年，商务部会同财政部连续两年将青海省列入中央财政支持冷链物流发展地区，推动青海牦牛、藏羊等特色优势农产品冷链物流体系建设。累计安排中央财政资金2亿元，支持青海省40余个农产品冷链物流项目建设，对完善青海省农产品冷链设施结构与布局，提高标准化和信息化水平起到积极作用。

下一步，我部将会同商务部等部门，继续完善冷链配送体系建设，发展具有集中加工、跨区域配送能力的现代化配送中心和物流园。支持青海强化冷链物流基础设施建设，提升农产品冷链物流现代化水平，促进高原绿色有机农产品产业发展。

感谢您对青海高原绿色有机农产品示范省建设工作的关心，希望继续对我部工作给予支持。

农业农村部

2019年8月30日
