# 农业农村部对十三届全国人大二次会议第3901号建议的答复

## 对十三届全国人大二次会议第3901号建议的答复

吴云波代表：

您提出的关于在少数民族聚居区着力实施乡村振兴战略的建议收悉。少数民族聚居区的乡村振兴是实施乡村振兴战略的重要内容。您的建议，对我们的工作很有借鉴意义。经商教育部、公安部、财政部、银保监会，现答复如下。

一、关于促进农牧民专业合作组织发展

发展农民专业合作社是组织带领农牧民“抱团”参与市场竞争、提高农业生产和农牧民进入市场组织化程度的重要手段。我部会同有关部门高度重视农民专业合作社发展，重点推动了三方面工作。一是开展规范化建设。2018年7月，新修订的《农民专业合作社法》对规范合作社的组织和行为，鼓励、支持、引导农民合作社的发展作出了明确规定。从2018年起，我部开展了农民专业合作社质量提升整县推进试点工作，将发展壮大单体合作社、培育发展联合社、提升县域指导服务能力等三方面作为试点任务。为深入推进示范社创建，我部会同国家发展改革委、财政部等有关部门联合开展了示范社建设行动，以制度健全、管理规范、带动力强作为国家级示范社评定标准，目前，国家级示范社超过8000家，县级以上各级示范社超过18万家。二是强化政策支持。在财政项目上，2018年，中央财政继续通过生产发展资金，安排14亿元支持农民合作社发展。重点支持制度健全、管理规范、带动力强的国家农民合作社示范社及农民合作社联合社，适当兼顾贫困地区省级农民合作社示范社，发展绿色生态农业，开展标准化生产、专业化服务。在税收政策上，2008年，财政部、国家税务总局下发《关于农民专业合作社有关税收政策的通知》，明确了合作社增值税、印花税的税收优惠政策。在金融支持上，农业农村部和银监会制定了对合作社的信用评定、信贷支持、信用合作、创新产品和服务方式等金融支持措施。在产销衔接上，组织合作社参加“农社对接”“农超对接”“农校对接”等多种类型的产销对接活动，帮助合作社拓宽了销售渠道。三是加快人才培养。我部高度注重合作社人才培训，每年支持包括农牧区合作社带头人在内的上千人参加培训，培训内容涵盖政策法规、合作理念、规范化建设、市场营销、品牌创建等。2018年，我部举办6期合作社带头人培训班，培训600余人，全方位培育合作社成员生产能力和营销能力，进一步提高了市场意识和发展能力。

下一步，我部将继续开展合作社规范提升行动，发展壮大以农牧民为主体的专业合作组织，加大政策支持力度，完善服务保障体系，积极指导农牧民专业合作组织建立健全运行机制，注重示范带动，促进合作社高质量发展。

二、关于农牧区人才队伍建设

近年来，中央及国务院有关部门高度重视农村人才队伍建设，先后出台了一系列强有力的政策举措，培养了一大批乡土人才，为乡村发展注入了生机活力。一是完善农村实用人才培养机制。大力开展农村实用人才带头人和大学生村官示范培训，圆满完成农村实用人才培养“百万中专生计划”。围绕中央脱贫攻坚决策部署，组织环京津贫困地区、定点扶贫和联系地区贫困村带头人轮训，带动各地不断加大农村实用人才培养力度，为实施乡村振兴战略、打好精准脱贫攻坚战发挥了骨干引领作用。二是强化农业科技人才队伍建设。实施农业科研杰出人才培养计划，依托现代农业产业技术体系、国家农业科技创新联盟、国家现代农业产业科技创新中心等，构建创新人才协同培养机制。以种业人才为突破口，推进农业科研成果权益改革。实施万名农技推广骨干人才培养计划，加强基层农技推广人员知识更新培训。启动农技推广服务特聘计划，健全完善“一主多元”的农业技术推广体系。目前，全国农业科技人才总体规模超过110万人，为加快我国农业科技创新提供了重要支撑。三是支持各类人才返乡下乡创业创新。2016年国务院办公厅印发《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》，为农村创业创新送出了政策“大礼包”。各级农业农村部门联合有关部门实施农村创业创新促进行动，加强创业培训指导，搭建服务平台，建设了1000多个农村创业创新园区，引导人才返乡创业兴业，带动大量当地农民就地就近就业。各地也因地制宜出台了一系列促进返乡下乡创业的政策措施。目前，全国返乡下乡人员累计超过780万人，为农业农村发展注入了新要素新活力，有力推动了城乡融合发展。

下一步，我部将继续大力推进少数民族聚居区高素质农民队伍建设，培育更多懂农业、爱农村、爱农民的“三农”工作队伍；落实各项创业就业扶持政策、解决用地用电、信贷保险等难题，引导更多有意愿的人留在农村、扎根基层，为“三农”事业发展提供智力支持。

三、关于提升农牧区金融信贷保障水平

金融是农村经济发展的重要要素。近年来，中央有关部门加大对农村牧区中长期信贷支持力度，降低信贷服务门槛和贷款利率，重点开展了两方面工作。一是推动农村中小银行回归本源，银保监会印发的《关于做好2019年银行业保险业服务乡村振兴和助力脱贫攻坚工作的通知》要求，农村中小银行机构要保持县域法人金融机构地位和数量总体稳定，各银行业金融机构要进一步加大涉农贷款投放力度，切实减少涉农贷款中间环节费用，降低普惠型涉农贷款利率。截至2019年一季度末，涉农贷款余额为33. 7万亿， 较年初增长 3.7%，其中，普惠型涉农贷款余额为5.9万亿，较年初增长4.2%。二是建立健全全国农业信贷担保体系，指导各地采取财政担保费率补助和以奖代补等方式，切实提高新型农业经营主体从事农业生产经营的贷款可能性。截至2019年1月，全国农业担保体系累计新增担保项目34.2万个，金额1216.5亿元，10万元至300万元的小额贷款担保占比80%以上。积极推进国家融资担保基金设立运作，促进基金、担保机构、银行“利益融合”，有效减轻商业银行和担保机构支农支小的后顾之忧，改善“三农”融资环境。

下一步，我部将会同有关部门认真研究和吸收采纳代表所提建议，继续推动银行业金融机构重点加大对农牧区的中长期信贷支持，进一步完善普惠金融发展专项资金政策，提升资金使用效能，构建有利于“三农”发展的良好环境，助力乡村振兴。

四、关于农牧业品牌化发展

农牧业品牌化是农牧业产业化升级的必由之路。我部高度重视农业品牌建设，积极培育特色鲜明、质量过硬、信誉可靠的农业品牌。一是强化工作推动。贯彻落实《国务院办公厅关于发挥品牌引领作用推动供需结构升级的意见》，将2017年确定为农业品牌推进年，召开全国农产品加工业发展和农业品牌创建推进工作会，部署品牌建设重点工作，指导各地大力推进品牌建设。二是开展品牌推选。利用各类农业展会、品牌大会等平台开展品牌推选。2016年，推选出100个名优果品区域公用品牌，2017年推选出“中国十大茶叶区域公用品牌”“中国优秀茶叶区域公用品牌”“中国百强农产品区域公用品牌”。支持中国农产品市场协会建立“中国农业品牌目录制度”。三是加强品牌宣传。借助中国国际农产品交易会、中国国际茶叶博览会等农业展会，举办“省部长推介品牌农产品专场”“我为品牌农产品代言”“乡人乡味—全国品牌农产品推介活动”等大型公益活动，宣传推介地方特色农产品区域公用品牌。四是建设农业品牌队伍。指导农业部管理干部学院，在广西百色、上海等地围绕农产品市场营销、农业品牌营销与推广、区域公用品牌创建与培育等，组织开展农业品牌专题培训，来自31个省（区、市）的农业品牌负责同志参加了培训。五是加大奖补力度。2013年以来，中央财政累计安排内蒙古自治区4.7亿元，主要用于畜牧良种推广培育，支持自治区每年对42万头肉牛和9万只公羊实施补贴，有力推动了自治区农牧业品牌的创建和发展。

下一步，我部将结合代表所提建议，进一步加大政策支持力度，积极培育、发展和打造一批农牧业品牌，推动少数民族聚居区农牧业品牌做大做强。

感谢您对推进乡村振兴战略实施工作的关心，希望继续对我部的工作给予支持。

农业农村部

2019年9月20日
