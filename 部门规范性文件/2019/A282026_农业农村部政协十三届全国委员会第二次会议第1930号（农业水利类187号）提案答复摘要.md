# 农业农村部政协十三届全国委员会第二次会议第1930号（农业水利类187号）提案答复摘要

## 政协十三届全国委员会第二次会议第1930号（农业水利类187号）提案答复摘要

您提出的《关于支持江汉平原农业高质量发展的提案》收悉。经商科技部、工业和信息化部、水利部、财政部、交通运输部和生态环境部，现答复如下。

一、关于支持江汉平原现代农业发展

实施乡村振兴战略，产业兴旺是关键。近年来，国家高度重视江汉平原现代农业发展，出台了一系列政策措施，加大投入力度，加快推进农业农村现代化。一是建设江汉平原水产、油菜等特色农产品优势区。近两年，我部与发展改革委、财政部等九部门联合认定并公布了两批146个中国特色农产品优势区，其中湖北省恩施自治州恩施硒茶、武汉市蔡甸区莲藕、潜江市潜江小龙虾、随州市随州香菇、十堰市武当道茶、宜昌市宜昌蜜桔成功入选。2019年5月，我部联合有关部门，继续推进特优区创建工作，启动第三批特优区申报。二是推进以农产品加工转化为重点的全产业链发展。农业农村部等14个部门联合出台《关于促进农产品精深加工高质量发展若干政策措施的通知》，实施农产品产地初加工补助项目，支持新型农业经营主体发展初加工设施，开展主食加工业示范企业申创活动，实施农产品及加工副产物综合利用试点，宣传推介一批农产品加工业发展典型模式。三是加强区域公共品牌建设。农业农村部召开全国农产品加工业发展和农业品牌创建推进工作会，印发《农业农村部关于加快推进品牌强农的意见》，部署新时期品牌重点工作。推选“中国十大茶叶区域公用品牌”“中国优秀茶叶区域公用品牌”等一批区域公共品牌，培育潜江龙虾、宜昌蜜桔、监利黄鳝等一批知名品牌，探索建立了中国农业品牌目录制度。四是创新农业生产经营体系。发展家庭农场，到2018年底全国认定或备案家庭农场近60万户。规范提升农民合作社，到2018年底全国依法登记的农民合作社达217.3万家，近一半农户加入农民合作社。创新龙头企业联农带农机制，全国各类农业产业化组织辐射带动农户1.27亿户。加快发展面向小农户的农业生产性服务业，创新生产托管服务模式，提升服务质量。五是开展智慧农业技术创新研究与示范。科技部在农业绿色发展、农作物数字化育种、智能农机装备等方面，加强农业科技创新，推动农科教、产学研大联合大协作，拓展成果展示示范和转化推广，充分发挥农业科技引领驱动作用。六是加大对粮食主产区、种粮大县的扶持力度。2018年，中央财政通过产粮大县奖励资金安排湖北省26.89亿元，支持包括江汉平原在内地区粮油产业发展。2017—2018年，中央财政累计安排湖北省实施“优质粮食工程”奖励资金10.92亿元。从2018年起用3年时间在湖北等6省（区）的24个产粮大县，面向规模经营农户和小农户开展创新和完善农业保险政策试点。下一步，我部将按照党中央、国务院关于实施乡村振兴战略的部署要求，会同有关部门，进一步完善相关政策措施，支持江汉平原现代农业加快发展，助力江汉平原探索以产业高质量发展带动乡村振兴新模式。

二、关于支持江汉平原现代农业基础设施建设

近年来，国家高度重视江汉平原农业基础设施建设，不断加大投入和建设力度，为加快推进农业农村现代化建设奠定坚实基础。一是支持高标准农田建设。中央财政通过农业综合开发、土地整治工作专项资金等支持高标准农田建设，改善农业生产条件。2019年，中央财政安排27.11亿元，重点用于包括江汉平原在内的湖北省高标准农田及农田水利建设。二是支持交通基础设施建设。交通运输部全面完成农村道路畅通工程，到明年全面完成具备条件的剩余乡镇、建制村通硬化路任务；按照建制村通客车的要求，改善农村客运通行条件；有序完善农村公路网络，实施一批旅游路、资源路、产业路和新型村镇出口路等县乡道改造和联网路工程。2019年，中央财政已安排湖北省农村公路建设资金45.18亿元，较2018年增长约60%。三是加快完善城乡物流配送网络。实施“交通+电商快递”扶贫工程，整合交通、供销、商贸、电商、邮政、快递等资源，推进县、乡、村三级农村物流配送网络建设，畅通农产品进城、工业品和生活消费品下乡的物流服务体系。下一步，我部将会同财政部、交通运输部，进一步加强资金整合投入，不断完善相关政策措施，支持江汉平原现代农业基础设施建设，努力补齐农业农村建设短板，为乡村振兴提供坚实支撑。

三、关于支持江汉平原农业装备现代化建设

江汉平原是我国重要的粮食主产区，加强农业装备现代化建设，对保障国家粮食安全具有重要意义。近年来，有关部门认真贯彻落实中央有关决策部署，推动农机装备产业转型升级。一是加强顶层设计。2018年国务院印发《关于加快推进农业机械化和农机装备产业转型升级的指导意见》，对农机装备产业作出部署。二是加大资金支持力度。2018年，中央财政安排湖北省农机购置补贴资金7.09亿元。制定出台《2018—2020年农机购置补贴实施指导意见》，明确补贴范围为15大类42个小类137个品目机具种类。其中，您提出的“支持秸秆还田等符合绿色农业发展需要的农业优先发展”建议，在农机购置补贴实施指导意见中，秸秆粉碎还田机、搂草机、压捆机等秸秆处理机械已纳入农机购置补贴范围。三是积极支持江汉平原农业机械研发。中央财政通过智能农机装备等科技专项对符合条件的科研活动进行支持。加大对农业领域中央级科研院所、国家重点实验室稳定支持力度，支持其改善科研基础条件、自主开展研究。安排现代农业产业技术体系建设专项资金，支持包括农机装备产业在内的农业产业发展研发。实施国家科技成果转化引导基金，支持农业装备产业等相关领域的科技成果转化。

下一步，我部将深入贯彻落实党中央、国务院决策部署，会同有关部门，认真研究和吸纳您所提意见和建议，坚持问题导向和目标导向，完善农机装备产业支持政策，创新协同机制，补短板、强弱项、促协调，推动农机装备产业加快实现高质量发展。同时，鼓励江汉平原农机制造企业、通用航空企业切实加大技术研发和装备能力建设，积极参与农机购置补贴、植保无人机购置补贴试点等扶持政策的实施，巩固和提升自身发展能力，为推进农业机械化和农机装备产业转型升级作出积极贡献。

四、关于支持江汉平原生态修复与建设

生态修复与建设是实施乡村振兴战略的重要任务，事关全面建成小康社会和农村生态文明建设。近年来，我部和有关部门采取有力措施，积极支持江汉平原生态修复与治理。一是开展畜禽粪污资源化利用和面源污染治理。近年来，国家按照整县治理的思路，不断加大投入力度，支持畜禽粪污资源化利用设施建设。截至目前，中央财政共计支持江汉平原11个畜牧大县整县推进粪污资源化利用，实现江汉平原畜牧大县粪污治理全覆盖。2018年，中央财政安排1.92亿元，大力支持江汉平原开展畜禽水产养殖污染治理、面源污染治理和水土修复。二是加强山水林田湖草生态保护修复。2018年，财政部会同自然资源部、生态环境部，将湖北“长江三峡地区山水林田湖草生态保护修复工程”纳入第三批山水林田湖草生态修复工程试点范围，并下达基础奖补资金10亿元。中央财政安排湖北省水污染和土壤防治专项资金12.3亿元，资金量在全国位居前列，安排农村环境整治资金1.9亿元。三是支持江汉平原水利工程建设。2019年，中央财政通过水利发展资金切块下达湖北省27.04亿元，统筹支持开展中小河流治理、小型病险水库除险加固等中小型水利设施建设。水利部大力支持“四湖”流域（长湖、三湖、白鹭湖、洪湖）水利建设，将洪湖分蓄洪区东分块蓄洪、安全建设工程列入172项节水供水重大水利工程，已累计安排中央投资22.3亿元用于蓄洪工程建设；开展全国河湖“清四乱”专项行动（含江汉平原相关河湖），集中整治乱占、乱采、乱堆、乱放等河湖顽疾。下一步，我部将会同关于部门，贯彻落实中央有关加快生态文明体制改革、建设美丽中国的部署要求，结合您所提意见建议，不断总结经验，认真研究完善相关政策措施，继续加大江汉平原生态修复与建设支持力度，助力江汉平原改善生态环境、构筑乡村振兴绿色生态屏障。

感谢您对农业农村工作的关心，希望继续对我部工作予以支持。
