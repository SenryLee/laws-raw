# 国家文物局关于榜罗镇会议旧址保护规划的意见

文物保函〔2019〕13号

甘肃省文物局：

你局《关于呈报榜罗镇会议旧址文物保护规划的请示》（甘文局发〔2018〕110号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）价值评估应加强党史研究内容，突出榜罗镇会议旧址在长征文化线路中的价值，同时对旧址群所呈现的整体特色及价值进行进一步挖掘。

（二）结合价值评估结论，明确旧址各遗存要素与榜罗镇会议相关事件、活动的历史关联，补充保护对象认定标准，进一步梳理保护对象，明确文物本体。

（三）现状评估应根据各文物建筑的结构特点合理选择残损评估标准，客观评估残损现状；归纳保护、管理等方面的具体问题，并加强对产权、社会参与、利用方式等方面的评估，明确评估结论。

（四）保护区划应加强与历史文化名镇保护规划等相关规划协调衔接。建议适当缩小建设控制地带范围，取消二类建设控制地带。

（五）根据建筑病害原因、使用现状、展示利用需求等，制定有针对性的保护措施。

（六）细化明确各院落内非文物建筑的具体环境整治要求；强化对历史环境风貌及地域特色景观的整体保护，明确相关措施。

（七）展示利用规划应进一步梳理展示资源，明确展示重点，优化展示方式及游线设计，合理确定主出入口及停车场选址；补充功能分区规划，明确可开放文物点；注意防止过度景区化、商业化，不建议新建游客服务中心。

（八）安全防护及基础设施问题应结合城镇规划统一协调解决；管理规划应加强可操作性，针对不同产权的文物建筑，分类研提管理要求，明确文物部门管理权责，提出协同管理机制改善建议。

（九）规范、完善图文表达。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善，经你局核准后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将榜罗镇会议旧址保护规划报请甘肃省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好榜罗镇会议旧址的各项保护、管理工作，妥善解决环境整治等问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年1月3日
