# 农业农村部对十三届全国人大二次会议第1935号建议的答复

## 对十三届全国人大二次会议第1935号建议的答复

农办议〔2019〕364号

曹清尧代表：

您提出的“关于建设国家猪种质资源库的建议”收悉。经研究，现答复如下。

畜禽等农业遗传资源是种业发展的“芯片”，是保障农畜产品有效供给、维护国家农业安全、建设生态文明的重要战略资源，是人类赖以生存和发展的物质基础。“十二五”以来，特别是党的十八大以来，我部通过强化法律制度建设，加大支持力度，扎实推进畜禽遗传资源保护工作，取得阶段性成效。目前，我国已逐步建立了国家级保种场167个、保护区26个、基因库6个，省级保种场（区、库）458个，形成了原产地与异地保护相结合、活体与遗传材料保存相补充、国家级和省级相衔接的畜禽遗传资源保护体系。其中，国家级地方猪保种场55个、保护区7个、家畜基因库1个，省级地方猪保种场（区、库）80余个。国家级家畜基因库保存了63个地方猪血样组织、14个地方猪精液和体细胞等遗传材料，地方猪品种得到有效保护。

为有效应对非洲猪瘟疫情对地方猪遗传资源的潜在威胁，农业农村部高度重视，迅速行动，于2018年12月印发了《关于加强地方猪遗传资源保护工作的通知》，要求各地加大支持力度，切实落实各项保护措施，确保地方猪遗传资源安全。2019年6月，启动了国家级地方猪遗传材料采集保存工作，充分应用现代生物技术，全面采集地方猪精液、体细胞等遗传材料，及时入国家级家畜基因库长期保存。

下一步，农业农村部将会同发展改革委，抓紧出台《现代种业提升工程建设规划（2019-2025年）》（以下简称《规划》），统筹布局建设一批国家级畜禽遗传资源保种场、保护区和基因库，加快提升保护利用能力，保障地方猪等畜禽遗传资源安全。其中，已将在重庆市建设畜禽遗传资源基因库纳入《规划》，重庆畜牧科学院等相关单位可按照《规划》及相关工作要求，启动国家级地方猪种质资源库项目建议书、可行性研究报告编制及项目申报工作。

感谢您对畜禽遗传资源保护工作的关心，希望您继续支持我部工作。
