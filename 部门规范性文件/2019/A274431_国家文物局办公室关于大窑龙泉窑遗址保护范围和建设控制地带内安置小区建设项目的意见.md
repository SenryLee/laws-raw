# 国家文物局办公室关于大窑龙泉窑遗址保护范围和建设控制地带内安置小区建设项目的意见

办保函〔2019〕115号

浙江省文物局：

你局《关于上报全国重点文物保护单位大窑龙泉窑遗址保护区划内进行安置小区建设的请示》（浙文物发〔2019〕17号）收悉。经研究，我局暂不同意所报大窑龙泉窑遗址保护范围和建设控制地带内安置小区建设方案。

一、对所报方案提出以下修改意见：

（一）应按照《大窑龙泉窑遗址保护总体规划》关于遗址保护范围和建设控制地带的管理规定，充分评估小梅镇和大窑村土地利用现状，综合考虑大窑龙泉窑遗址保护、“海上丝绸之路”申遗、国家考古遗址公园建设、村民外迁安置等需求，进一步说明在遗址保护范围内进行安置小区建设的必要性，补充建设项目选址的比选方案。

（二）进一步优化安置小区建设方案，其布局设计应充分与周边的地形、地貌、水系等相结合，与遗址周边景观环境相协调，避免整齐划一的设计，尽可能降低工程建设对遗址及其周边环境的影响。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年2月19日
