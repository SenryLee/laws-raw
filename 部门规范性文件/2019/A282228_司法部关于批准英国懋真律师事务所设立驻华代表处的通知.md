# 司法部关于批准英国懋真律师事务所设立驻华代表处的通知

司发通〔2019〕95号

广东省司法厅：

根据《外国律师事务所驻华代表机构管理条例》的规定，我部批准英国懋真律师事务所（MAUCHER JENKINS）在深圳设立代表处。具体情况如下：

英国懋真律师事务所驻深圳代表处，英文名称为MAUCHER JENKINS SHENZHEN REPRESENTATIVE OFFICE（UK），首席代表为冉寒冬（Handong Ran），代表为爱德华·威廉·兰斯福德（Edward William RAINSFORD）。

请予办理登记注册手续。

司法部

2019年9月20日
