# 国家核安全局关于同意安徽时代辐化有限公司辐射安全许可证注销的复函

## 关于同意安徽时代辐化有限公司辐射安全许可证注销的复函

环办辐射函〔2019〕884号

安徽时代辐化有限公司：

你公司《关于注销辐射安全许可证的申请》（时代辐化综［2019］1号）收悉。鉴于你公司已按规定完成钴源辐照装置的退役手续，并将辐射安全许可证交还我部，根据《放射性同位素与射线装置安全和防护条例》有关规定，我部同意注销你公司辐射安全许可证（国环辐证［00108］）。

特此函复。

生态环境部办公厅

2019年12月3日
