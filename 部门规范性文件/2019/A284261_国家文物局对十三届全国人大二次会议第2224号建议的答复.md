# 国家文物局对十三届全国人大二次会议第2224号建议的答复

文物博函〔2019〕660号

宋亚平代表：

您提出的“关于加强博物馆建设的建议”收悉，现答复如下。

博物馆是保护和传承人类文明的重要殿堂，是连接过去、现在、未来的桥梁，在构建公共文化服务体系、提升国民文化素质、传承中华优秀传统文化、弘扬社会主义核心价值观、建设社会主义文化强国，促进人类文明交流互鉴，具有重要意义。

对您提出的从加强统筹规划、落实相关扶持政策、推动数字博物馆建设、加强近现代文物征集等方面加强博物馆建设的建议，我局认为具有积极意义，予以采纳并在即将出台的《关于推进博物馆改革发展的实施意见》中体现。

您提出的关于依托博物馆做好宋伯鲁先生相关文物资料研究、陈列、宣传工作的建议，根据博物馆属地管理原则，我局已转告陕西省文物局，请其依托陕西省内现有博物馆资源情况，依据相关政策及程序，予以积极关注和推动。

感谢您对博物馆事业的关心和支持！

国家文物局

2019年7月9日
