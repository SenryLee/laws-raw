# 国家卫生健康委办公厅关于开展2019年全国阿尔茨海默病预防与干预宣传活动的通知

国卫办老龄函〔2019〕739号

各省、自治区、直辖市及新疆生产建设兵团卫生健康委：

2019年9月21日是第26个世界阿尔茨海默病日。为贯彻落实健康中国行动（2019-2030年）提出的“到2022年和2030年，65岁及以上人群老年期痴呆患病率增速下降”的目标要求，增强全社会的老年期痴呆预防意识，推动预防关口前移，我委近期印发了《阿尔茨海默病预防与干预核心信息》，并将组织开展2019年全国阿尔茨海默病预防与干预宣传活动，现将有关事项通知如下：

一、活动主题

2019年的活动主题是：“积极预防干预，守护爱的记忆”，旨在引导全社会共同参与，广泛宣传阿尔茨海默病预防与干预核心信息，提高公众预防知识水平，营造全社会关心关爱老年人的良好氛围，推动落实健康中国行动和老年健康促进专项行动。

二、活动形式

（一）依托互联网、大数据技术手段，充分发挥传统媒体和新媒体的优势，开展语言生动、图文并茂、互动性强的宣传活动。

（二）采取现场专家咨询、展板展示宣传、张贴海报标语、发放科普读物等方式，广泛宣传阿尔茨海默病的预防与干预知识。

（三）在落实老年人健康管理等国家基本公共卫生服务项目过程中，加强对阿尔茨海默病预防与干预知识的宣传，送知识、送服务进社区、进家庭。

三、工作要求

（一）各地要高度重视，从维护老年人健康出发，认真制订方案，精心组织活动。我委组织制作了宣传活动工具包（可从国家卫生健康委网站“老龄健康司”栏目下载），供各地参考使用。各地可根据当地实际情况制作宣传教育材料及文创产品，配合宣传活动开展。

（二）各地要将本次活动作为落实健康中国行动的重要举措和有效载体，进一步贯彻预防为主的卫生健康工作方针，开展丰富多彩、针对性强的宣传教育活动，广泛宣传阿尔茨海默病预防与干预核心信息，营造关爱阿尔茨海默病老人及其家庭的友好氛围和社会支持环境。

（三）各省级卫生健康行政部门要将地方活动亮点以政务信息的形式报送我委老龄司。鼓励各地积极报送优秀宣传教育材料，我委将择优在官方网站和健康中国新媒体平台展播。
