# 国家文物局关于政协十三届全国委员会第二次会议第2787号（文化宣传类226号）提案答复的函

文物保函〔2019〕836号

黄玲等5位委员：

您提出的《关于充分发掘活化祠堂文化资源，助力乡村振兴战略的提案》收悉。现答复如下。

祠堂是我国古代建筑中的礼制性建筑，其起源可远溯至上古的祖先崇拜。祠堂既是纪念先人的纪念馆、展示家族历史的博物馆，也是调解民事纠纷、维系家族情感的重要场所，在历史上发挥了重要作用，已成为我国文化遗产的重要组成部分。据初步统计，仅全国重点文物保护单位中祠堂类建筑就有72处。

文物、文化和旅游部门高度重视祠堂类文物的保护工作。一是将一批具有重要价值的祠堂纳入依法保护范畴，由各级人民政府公布为文物保护单位。二是组织实施了一批文物保护维修工程和安全防护工程，有效改善了祠堂类文物的保存状况。据初步统计，近年来中央财政累计投入国家文物保护专项资金近2亿元，支持各地开展了祠堂类文物的抢险加固、保护修缮、展示利用、规划编制以及安防消防等项目。三是注重发挥祠堂类文物的展示、宣传和教育功能。通过合理引导，将祠堂类文物的保护展示与传承弘扬中华优秀传统文化相结合，充分发挥了这些文物在培育良好家风、传承重要家训、发扬中华民族优良传统和美好品德等方面的重要作用。四是加强与祠堂密切相关的非遗项目保护，将安徽省祭祖习俗（徽州祠祭）列入国家级非遗代表性项目目录，并先后拨付经费65万元支持开展相关保护工作。

您提出对祠堂要加强保护、适度开发、活化利用、传承文化以及拓宽筹资渠道等建议非常重要。国家文物局、文化和旅游部将与相关部门加强协作，全面落实中共中央办公厅、国务院办公厅《关于加强文物保护利用改革的若干意见》，督促、指导地方人民政府做好祠堂类文物的保护利用，重点推进以下工作。

第一，全面加强祠堂类文物的保护修缮。国家文物局将指导地方文物行政部门对保存现状堪忧和存在险情的祠堂类文物及时抢救保护，制定科学可行的保护措施，切实改善文物保存状况。同时，指导相关文物管理使用单位按照文物保护的基本原则和要求，运用当地传统工艺、材料和做法开展祠堂日常保养维护和修缮工作，纠正不当维修和改造，切实保护好文物的真实性。

第二，合理引导祠堂类文物的开放利用。国家文物局2017年印发《文物建筑开放导则（试行）》，为包括祠堂在内的文物建筑开放利用工作提供指导和依据，引导地方有关部门根据文物的保存现状和价值特征，科学确定展示利用的主题、内容、方式和强度，将祠堂类文物展示利用与家风培育、家教传承、非物质文化遗产保护、传统文化传承发展等相结合，避免商业化倾向、不当使用和过度利用。

第三，统筹推进祠堂类文物的环境整治工作。国家文物局将督促地方政府严格按照《文物保护法》等文物法律法规的要求，加强文物保护单位管理，不断完善“四有”建设，严格控制文物周边建设活动，妥善开展环境整治，保护好文物及周边景观风貌。

第四，加强对祭祖习俗及相关载体的整体性保护。文化和旅游部门将会同国家发展改革委发布全国乡村旅游重点村名录，实施创意下乡行动，深入挖掘、科学提炼祠堂文化，鼓励祠堂文化创意产品，通过非遗与旅游融合发展的方式助力乡村振兴。

第五，鼓励地方人民政府加大文物保护投入，多方筹措保护资金。督促地方人民政府严格落实文物保护主体责任，加大文物保护资金投入力度，并积极落实国务院办公厅《关于进一步激发社会领域投资活力的意见》（国办发〔2017〕21号）中“支持社会资本对文物保护单位和传统村落的保护利用”要求，出台相关政策，引导社会力量积极参与文物保护，探索特许经营、认领认养、PPP模式、公益基金参与、社会捐赠等模式，多种渠道筹集文物保护资金，更好地规范和引导社会资金参与祠堂类文物保护。

感谢您对国家文物事业的关心与支持。

国家文物局

2019年8月19日
