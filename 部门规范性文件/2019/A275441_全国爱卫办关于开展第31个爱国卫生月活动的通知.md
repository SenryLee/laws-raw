# 全国爱卫办关于开展第31个爱国卫生月活动的通知

全爱卫办发〔2019〕2号

各省、自治区、直辖市及新疆生产建设兵团爱卫办：

2019年4月是第31个爱国卫生月，今年的活动主题是“共推‘厕所革命’共促卫生健康”。现就做好爱国卫生月组织工作通知如下：

一、深刻领会宣传主题内涵

各地要深入学习贯彻党中央、国务院关于乡村振兴战略和农村人居环境整治工作的决策部署，落实习近平总书记关于“厕所革命”的重要批示指示精神，以爱国卫生月活动为契机，将推进“厕所革命”作为落实农村人居环境整治行动的重要抓手，充分发挥爱国卫生运动委员会组织协调和社会动员优势，进一步宣传引导群众养成健康文明的生活习惯，改善环境卫生状况，以崭新面貌迎接新中国成立70周年。

二、组织开展各类专题活动

各地要结合本次爱国卫生月主题，因地制宜地开展通俗易懂、针对性强、形式多样和特色鲜明的爱国卫生月专题活动。要充分利用爱国卫生月，有计划、有重点、有步骤地组织开展持续有效的宣传活动。要以基层医疗卫生机构和广大群众为主要宣传对象，以关注卫生厕所日常管护、倡导文明如厕、传播卫生防病知识等为主要内容，广泛宣传清洁卫生厕所对于公众健康和社会文明的重要意义，努力营造全社会共同关心、大力支持和积极参与“厕所革命”的良好氛围。

三、不断创新宣传方式方法

各地要在充分发挥电视、广播、报纸等传统媒体作用基础上，积极拓展官方公众号、微信、微博等新媒体合作平台，结合爱国卫生月宣传要点（附件1），开发能够灵活、便捷、快速展示的可视化新媒体传播作品（如宣传海报、公益短片等），组织有奖问答、话题互动、“清洁妙招”视频等网络活动，多角度、全方位普及文明健康知识，提高群众健康素养和防病意识。

四、工作要求

（一）各省（区、市）爱卫办要会同爱卫会成员部门制订切实可行的活动计划，组织开展好本地区的宣传活动，并于3月28日前报送专题活动计划统计表（附件2）。全国爱卫办委托中国卫生画报社届时开展专题报道，各地爱卫办可与其联系开展实地报道。

（二）全国爱卫办组织制作的宣传海报（电子模板）将于近期在国家卫生健康委网站发布，请各地根据模板自行印制，以配合整体宣传活动的开展。

（三）各地要及时总结爱国卫生月活动开展情况，提炼活动中的典型经验和亮点，并将活动书面总结、活动图片（要求清晰、精度大于1MB，采用jpg格式，并配有简明扼要、内容真实、数据详实的说明）、视频等材料，于5月31日前报全国爱卫办和中国卫生画报社。
