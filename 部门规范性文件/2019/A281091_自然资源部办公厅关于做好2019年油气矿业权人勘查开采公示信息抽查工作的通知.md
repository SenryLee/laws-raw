# 自然资源部办公厅关于做好2019年油气矿业权人勘查开采公示信息抽查工作的通知

有关省、自治区、直辖市自然资源主管部门，有关油气矿业权人：

根据《矿业权人勘查开采信息公示办法（试行）》（国土资规〔2015〕6号，以下简称《办法》）的"双随机"和专项抽查有关要求，部确定了2019年油气矿业权人勘查开采公示信息抽查名单，现将有关事项通知如下。

一、随机选派抽查人员

按照"双随机"要求，从油气督察员库和专家库中抽取核查人员，组建检查组，每组核查人员不少于3人。核查人员原则上具备高级职称或处级职务，并具有相应的油气勘查开采实践或管理经验。项目多的省份，可分组开展检查。根据需要，部将派员参加部分省（区、市）的抽查工作。

二、抽查时间

请有关省（区、市）自然资源主管部门于2019年10月底前完成抽查工作，并将检查结果通过公示系统报部；11月15日前以厅函形式将抽查工作报告报部。

三、检查内容

对于勘查项目，重点是勘查投入等公示信息的准确性和真实性、法定义务履行情况、勘查进展及成果等。对于开采项目，重点是油气资源开发利用情况、共伴生矿综合利用情况以及绿色矿山建设等情况。

四、其他有关要求

（一）山西、福建、江西、湖北、贵州、新疆等6省（区）自然资源主管部门负责本行政区域内煤层气矿业权勘查开采公示信息抽查工作，于2019年11月15日前将抽查工作报告报部。

（二）有关省（区、市）自然资源主管部门可以结合本地实际情况，委托有关专业机构开展实地核查等相关工作。

（三）开展抽查检查时要严格遵守中央八项规定精神和相关规定，轻车简从，不得影响正常生产作业，不得提出与抽查检查工作无关的要求。

（四）有关油气矿业权人要高度重视监督检查工作，主动配合，按要求提供有关资料。
