# 农业农村部对十三届全国人大二次会议第6117号建议的答复

## 对十三届全国人大二次会议第6117号建议的答复

农办议〔2019〕323号

孔怡代表：

您提出的关于建设"绿肥+"产业创新示范基地及其保障机制的建议收悉，现答复如下。

一、关于开展"绿肥+"产业创新示范基地建设行动

近年来，我部采取有力措施，加强绿肥试验示范、推广种植和示范基地建设工作。一是加大资金支持。2008年以来，结合实施土壤有机质提升、耕地保护与质量提升、果菜茶有机肥替代化肥试点等项目，在绿肥种植适宜省区安排专项资金，引导有条件的地方种植绿肥。江苏、湖南、江西等省也出台地方性补贴政策，扶持发展绿肥生产。二是强化试验示范。为引导和鼓励农民多种绿肥、种好绿肥，各级农业农村部门集中资源、重点打造一批示范基地，充分发挥成果展示、现场观摩、示范引领作用。广西建立百亩以上绿肥示范片500个，示范面积近28万亩，湖南在108个农业县开展绿肥生产示范，示范面积23.5万亩。三是加强技术培训。采取各种形式，举办技术培训班，重点培训县（乡）农技人员和新型农业经营主体的技术骨干。在绿肥播种、开沟、施肥和防治病虫等关键农时季节，举办现场观摩会，让农民一看就懂、一学就会。四是加强宣传引导。各地充分利用电视、广播、报纸、网络等媒体，广泛宣传恢复发展绿肥生产的重大意义，提高农民对种植绿肥的认识，为规模化种植绿肥创造条件。通过科技小报、墙报、科技赶集和发放资料等形式普及绿肥生产与高效利用技术。

下一步，农业农村部将会同有关部门，结合果菜茶有机肥替代化肥试点、耕地轮作休耕制度试点等项目，开展不同生态类型绿肥种植试验示范，分区域集成组装一批绿肥高效生产技术模式，加快推广应用，推动各地加大绿肥示范基地建设。同时，加大宣传培训力度，普及绿肥知识，让社会公众充分认识绿肥在保护生态环境、推进农业绿色发展中的重要作用，营造推动绿肥发展的良好舆论氛围。

二、关于中央财政对绿肥生产给予专项补贴

近年来，我部会同有关部门，结合实施化肥减量增效、果菜茶有机肥替代化肥试点、耕地轮作休耕制度试点等项目，加大政策扶持力度，积极推动绿肥发展。一是实施化肥减量增效项目。根据不同土壤类型和种植制度，开展耕地质量提升和化肥减量增效示范，推广秸秆还田、种植绿肥等技术。江苏、湖南、江西等省也出台地方性补贴政策，扶持发展绿肥生产。二是开展果菜茶有机肥替代化肥试点。2019年，中央财政继续安排资金，在前两年试点的基础上，推动175个县（市）开展果菜茶有机肥替代化肥试点，集成推广一批典型生产技术和生产运营模式，逐步构建果菜茶有机肥替代化肥长效机制。其中一项重要技术是，在适宜地区集成推广"自然生草+绿肥"等有机肥替代化肥技术模式，支持农民在菜园、果园、茶园种植绿肥，改良土壤、培肥地力。三是开展耕地轮作休耕制度试点。2019年，我部会同财政部推动3000万亩耕地轮作休耕试点任务的落实，明确要求试点省份引导农民在休耕期间种植绿肥，减少地表裸露，提升土壤有机质含量，改善土壤理化性状，培肥地力。为保障种植绿肥等措施落实到位，允许耕地轮作休耕试点补助资金对绿肥播种、机械开沟和翻压还田等予以适当补助，调动了农民种植绿肥的积极性。四是加大农机购置补贴政策支持力度。立足绿肥生产关键环节机械化，推动绿肥播种、开沟、翻压和种子收获等农机装备研究。指导各地依照程序，将取得资质条件的绿肥专用机械纳入农机购置补贴范围，提升绿肥作业机械化水平。

下一步，农业农村部、财政部将会同有关部门，结合实施化肥减量增效、果菜茶有机肥替代化肥试点、耕地轮作休耕制度试点等项目，加大财政支持力度，完善绿肥种植补贴政策。

三、关于建立绿肥品种审（认）定和种子市场管理制度

近年来，我部会同有关部门，围绕品种创新、种子供应、质量提升等环节，加大对绿肥种业发展的支持力度。一是推进种子基地建设。组织专家开展绿肥种子基地建设调研，提出绿肥种子基地建设布局、主要内容和建设标准，指导湖南、贵州、江西、安徽等省开展紫云英、苕子、箭筈豌豆等绿肥品种留种基地建设。湖南省安排专项资金支持绿肥良种繁育体系建设；贵州省计划建设绿肥留种基地20万亩，生产能力2400万公斤，建成后能满足600万亩耕地专用绿肥用种的需要。二是强化品种管理。目前，我国对水稻、小麦、玉米、棉花和大豆五种主要农作物实行品种审定制度，对列入登记目录的非主要农作物实行品种登记制度。大豆作为豆科绿肥之一，可以固氮肥田，目前实行品种审定制度。2017年，我部发布了第一批《非主要农作物品种登记目录》，花生、蚕豆等豆科绿肥作物品种列入登记目录，紫云英、苜蓿、绿豆、草木樨等绿肥作物品种暂未列入。三是加强绿肥品种权保护。目前，农业农村部共发布了十一批植物新品种保护名录，包含191个植物属（种）。已发布的名录中，紫花苜蓿、白车轴草（白三叶）、红车轴草（红三叶）、黑麦草等10个牧草属（种），以及绿豆、荞麦、芝麻等大田作物，可作为绿肥使用。截至2019年5月31日，共有43件绿豆申请品种权保护，13件已授予植物新品种权。

下一步，农业农村部将会同有关部门，根据绿肥发展布局，完善规划，创新机制，加大绿肥种子补贴力度，加快建设一批绿肥良种繁育基地，提升绿肥种子供给能力。

感谢您对农业农村工作的关心，希望今后对我部工作继续给予支持。
