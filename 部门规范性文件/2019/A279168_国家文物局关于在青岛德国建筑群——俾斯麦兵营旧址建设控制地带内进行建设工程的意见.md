# 国家文物局关于在青岛德国建筑群——俾斯麦兵营旧址建设控制地带内进行建设工程的意见

文物保函〔2019〕587号

山东省文物局：

你局《关于青岛德国建筑群——俾斯麦兵营旧址建设控制地带内进行建设工程的请示》（鲁文发〔2019〕35号）收悉。经研究，我局原则同意在青岛德国建筑群——俾斯麦兵营旧址建设控制地带内进行中国海洋大学鱼山校区生命科技中心大楼建设工程。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步说明在俾斯麦兵营旧址建设控制地带内选址建设该项目的必要性，并进一步严格控制拟建建筑的高度、体量和密度，将拟建A楼的地上部分由四层减至三层，优化建筑外观设计，以与文物建筑及其周边环境相协调。

（二）进一步验算分析基坑开挖期间产生振动、沉降对文物建筑的影响，补充施工期间基坑支护方案，以及对文物建筑、景观环境的保护措施，制定应急预案、监测方案，确保文物建筑和景观环境安全。

（三）进一步优化拟建建筑周边的景观绿化，尽量减小该建设项目对文物及其周边环境的影响。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。涉及法定历史文化街区的部分，应依法按程序履行相应的审批手续。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年6月25日
