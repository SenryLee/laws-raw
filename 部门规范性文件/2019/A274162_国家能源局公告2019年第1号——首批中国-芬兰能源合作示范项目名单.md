# 国家能源局公告2019年第1号——首批中国-芬兰能源合作示范项目名单

## 国家能源局公告

2019年第1号

根据中国和芬兰两国政府发布的《关于建立和推进面向未来的新型合作伙伴关系的联合声明》以及国家能源局与芬兰经济事务与就业部签署的《关于中芬能源领域合作的谅解备忘录》，并按照《国家能源局综合司关于征集中国-芬兰能源合作示范项目有关事项的通知》有关要求，经中芬联合专家评审和项目实地调研，国家能源局与芬兰经济事务与就业部确定了首批中国-芬兰能源合作示范项目名单。现予以发布。

附件：首批中国-芬兰能源合作示范项目名单

国家能源局

2019年1月23日
