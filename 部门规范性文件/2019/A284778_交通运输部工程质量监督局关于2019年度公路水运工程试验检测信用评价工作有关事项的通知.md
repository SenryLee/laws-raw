# 交通运输部工程质量监督局关于2019年度公路水运工程试验检测信用评价工作有关事项的通知

## 关于2019年度公路水运工程试验检测信用评价工作有关事项的通知

各省交通运输质监机构：

为做好2019年度公路水运工程试验检测信用评价工作，依据《交通运输部关于印发〈公路水运工程试验检测信用评价办法〉的通知》（交安监发（2018）78号）（以下简称《办法》）有关规定，现就2019年度信用评价工作有关事项通知如下。具体事项见附件。

交通运输部工程质量监督局
