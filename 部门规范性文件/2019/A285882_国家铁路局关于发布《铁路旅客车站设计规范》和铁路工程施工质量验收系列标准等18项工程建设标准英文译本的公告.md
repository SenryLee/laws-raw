# 国家铁路局关于发布《铁路旅客车站设计规范》和铁路工程施工质量验收系列标准等18项工程建设标准英文译本的公告

本篇法规中关于《铁路旅客车站设计规范》（TB 10100-2018）的相关规定已经被《国家铁路局关于发布铁道行业标准的公告（工程建设标准2022年第3批）》（国家铁路局公告2022年第8号）自2022年10月14日起修改。
