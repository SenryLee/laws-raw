# 自然资源部办公厅关于开展矿产资源节约和综合利用先进适用技术目录更新工作的通知

自然资办函〔2019〕1081号

各省、自治区、直辖市自然资源主管部门，有关中央企业、行业协会及产业联盟，中国地质调查局：

为加快矿产资源节约与综合利用技术创新和推广应用，按照《国土资源部关于推广先进适用技术提高矿产资源节约与综合利用水平的通知》（国土资发〔2012〕154号）和《国土资源部关于推进矿产资源全面节约和高效利用的意见》（国土资发〔2016〕187号）要求，自然资源部将开展矿产资源节约与综合利用先进适用技术更新工作。现将有关事项通知如下：

一、征集先进适用技术

（一）技术范围。矿产勘查、采矿及选矿新技术、新工艺和新装备，综合利用尾矿、废石（煤矸石）、矿山废水等新技术和新工艺，数字化、自动化、信息化及智能化矿山新技术。已入选前六批先进技术推广目录的不在推荐范围。

（二）技术条件。推荐技术应符合国家产业发展方向，已在矿山或勘查项目得到应用，成效显著，推广潜力大。能够反映勘查、开采、选矿、综合利用技术工艺或装备的最新进展，能够有效提高工效、节能降耗、节约和高效利用矿产资源；综合运用数字化、自动化、信息化及智能化技术，明显提高劳动生产率和资源利用效率。

（三）工作程序。

1.组织推荐。请省级自然资源主管部门组织本行政区域内矿山企业和科研单位进行先进技术申报并遴选推荐。请中国地质调查局、有关中央企业组织所属单位进行先进技术申报并遴选推荐。请有关行业协会及产业联盟在行业内进行先进技术遴选推荐。

2.评选发布。自然资源部组织专家对各单位征集推荐的先进技术进行评选。拟纳入目录的先进适用技术在自然资源部门户网站公示后向社会发布。

（四）报送内容。请各推荐单位按要求组织编制申请报告并填写推荐表（详见附件1、附件2），把好申报材料审查关。

二、更新先进适用技术目录

请各推荐单位组织申报单位根据技术发展最新情况，对第一批至第六批矿产资源节约与综合利用先进适用技术目录提出更新的意见建议。已被更先进适用技术工艺替代的，组织编制申请报告并填写推荐表、技术更新情况表（详见附件1、附件2、附件3）。对适用范围窄、推广潜力小的技术工艺，提出调出目录的建议。

三、有关要求

（一）请各推荐单位高度重视，加强组织领导，充分调动矿山企业和科研单位的积极性，做好矿产资源节约和综合利用先进适用技术征集推荐和更新工作。

（二）各省级自然资源主管部门、中国地质调查局、有关行业协会及产业联盟推荐技术数量不超过10项，有关中央企业推荐技术数量不超过5项。

（三）请各推荐单位于2019年9月20日前将有关材料纸质版（1式3份）和电子版（word版，需刻制光盘）报自然资源部。材料具体包括：先进适用技术申请报告、先进适用技术推荐表、先进适用技术更新情况表；有关证明材料和展示先进技术成效的照片等。
