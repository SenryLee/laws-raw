# 文化和旅游部办公厅关于公布“时代交响——中国交响音乐作品创作扶持计划”2018—2019年度扶持作品名单的通知

办艺发〔2019〕127号

各省、自治区、直辖市文化和旅游厅（局），新疆生产建设兵团文化体育广电和旅游局，广电总局办公厅，中央军委政治工作部宣传局，中国歌剧舞剧院、中国东方演艺集团有限公司、中国交响乐团、中央歌剧院、中央芭蕾舞团、中央民族乐团、中国煤矿文工团：

2018年9月和2019年4月，文化和旅游部先后两次印发关于开展“时代交响——中国交响音乐作品创作扶持计划”扶持作品申报工作的通知，共收到全国各地报送的作品539部。经专家认真评审，遴选出25部作品进行扶持。现将扶持作品名单予以公布，并将相关事项通知如下：

一、文化和旅游部艺术司将给予2018—2019年度扶持作品一定的经费支持，专项用于作品的修改打磨。

二、文化和旅游部艺术司将组织专家，对扶持作品的修改打磨工作进行跟踪指导，以进一步提升作品艺术质量。

三、作曲家须虚心听取专家指导建议，聚力凝神，对扶持作品进行认真修改打磨，按要求完成规定时间节点内的各项工作。

四、修改打磨工作完成后，文化和旅游部艺术司将组织专家进行验收和再次遴选，从扶持作品中遴选出重点扶持作品，通过举办专场音乐会、录制出版总谱及音像制品等方式，进行宣传推广。

特此通知。
