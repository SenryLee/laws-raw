# 国家铁路局关于发布《交流传动电力机车》等5项铁道行业技术标准英文译本的公告

国铁科法〔2019〕 44号

现发布《交流传动电力机车》（TB/T 3487-2017）等5项铁道行业技术标准英文译本。英文译本与中文版铁路技术标准在技术上出现异议时， 以中文版为准。

以上英文译本由中国铁道出版社有限公司组织出版发行。
