# 生态环境部办公厅关于开展2019年生态环境公众科学活动的通知

## 关于开展2019年生态环境公众科学活动的通知

环办科财函〔2019〕309号

各省、自治区、直辖市生态环境厅（局），生态环境部各直属单位，各国家环保科普基地：

为贯彻落实习近平生态文明思想，大力弘扬科学精神，普及科学知识，助力打好污染防治攻坚战，根据《关于进一步加强环境保护科学技术普及工作的意见》（环发〔2015〕66号）和《科技部 中央宣传部 中国科协关于举办2019年全国科技活动周的通知》（国科发智〔2019〕80号）的有关要求，我部定于2019年科技活动周至环境日期间组织开展生态环境公众科学活动。现将有关事项通知如下。

一、参与单位

我部直属单位、国家环保科普基地和具备活动条件的生态环境科研院所、环境监测中心（站）、高等学校等。

二、活动时间

全国科技活动周至环境日期间（2019年5月19日至6月5日），各单位自行安排具体活动时间。

三、主要活动

生态环境公众开放活动、生态环境讲解员活动，以及各单位自行开展的其他活动等。引导公众体验生态环境科技，了解探索过程背后的故事，激发创新创造热情，自觉践行生态环境保护理念。

各单位自行开展的其他活动应围绕社会关注的生态环境热点，结合单位自身特色和专长，开展通俗易懂、互动性强的科普活动。

四、工作要求

（一）各省、自治区、直辖市生态环境厅（局）要高度重视，加强统筹协调和资源共享，组织有条件的科研院所、环境监测中心（站）等机构积极参与。

（二）各参与单位要精心谋划，尽快制定活动方案，请于2019年3月28日前在线填报《2019年生态环境公众科学活动备案表》（见附件，网站链接：https://www.wjx.top/jq/35774563.aspx，也可手机扫描附件中二维码）。

（三）各参与单位在组织实施中应确保活动成效和安全，加强媒体宣传，并将有关报道通过电子邮件及时反馈中国环境科学学会。
