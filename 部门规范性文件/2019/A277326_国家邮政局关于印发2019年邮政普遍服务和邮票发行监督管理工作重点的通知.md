# 国家邮政局关于印发2019年邮政普遍服务和邮票发行监督管理工作重点的通知

国邮发〔2019〕20号

各省、自治区、直辖市邮政管理局：

2019年邮政普遍服务和邮票发行监督管理工作的总体要求是：以习近平新时代中国特色社会主义思想为指导，全面贯彻落实全国邮政管理工作会议精神，践行人民邮政为人民的宗旨，履行普遍服务政治责任，巩固深化巡视整改成果，积极服务国家重大战略，扎实推进邮政业服务民生实事，不断提升邮政普遍服务水平，为全面建成与小康社会相适应的现代邮政业做出积极贡献。重点工作如下：

一、着力打好建制村直接通邮攻坚战

实施“乡村服务升级”行动计划，2019年新增直接通邮建制村5000个以上，基本实现全国建制村直接通邮的任务目标。四川、贵州、云南、甘肃、新疆等5个尚未实现直接通邮的省份，要继续协调争取支持政策，建立有力的政企协同推进机制，通过季度沟通协商、联合开展调研督查等措施，压实企业主体责任，督促企业用好中央专项补助资金，一村一策，精准施策，攻坚拔寨，确保完成任务。国家局将召开推进会，总结工作，推广经验。已经实现了全部建制村直通邮的省份，要继续加大抽查核查力度，保持服务的稳定性和持续性。国家局每月通报进展情况并纳入年度考核。

二、全力服务中央重大战略部署

一是服务乡村振兴和脱贫攻坚。支持邮政企业深入实施 “邮政在乡”工程，年内新增邮乐购站点3万个。国家局协同商务部联合建设农村电子商务站点，进一步完善邮政农村物流服务体系。省局和市（地）局要主动加强与财政、发改、农业、交通、扶贫、供销等部门的横向协调沟通，进行政策对接，形成政策合力，为邮政发展提供政策红利。要依托现代农业产业园、农产品加工龙头企业促进邮政和现代农业融合发展，推广“农产品+大同城”寄递服务模式，培育“一市一品”精品项目，提升邮政服务“三农”能力，带动农民增收致富，在助力精准脱贫、服务乡村振兴中发挥邮政主力军的作用。

二是服务“一带一路”建设。实施“丝路传邮”行动计划，提升邮政跨境寄递服务能力。国家局与商务部、海关总署将研究出台促进跨境电子商务寄递服务高质量发展的若干意见。支持跨境电子商务综合试验区、自由贸易试验区、中欧班列途经内陆省会城市、主要边境贸易口岸布局建设国际邮件互换局（交换站），促进跨境电子商务贸易发展。今年开展无锡、南昌、石家庄等国际邮件互换局设置审查工作，协调推进贵阳国际邮件互换局，有关省局要主动开展工作。引导邮政企业共建共享，在国际重点地区设置海外仓，增强邮政跨境服务能力。

三是加强邮政业军民融合和国防交通战备工作。贯彻军民融合战略，充分利用邮政快递高效便捷的物流网络体系，与军方深度交流合作，为军队后勤服务保障，特别是为部队被装配送提供全流程解决方案，扩大配送规模和范围，拓展行业新的发展领域。积极创造条件，搭建平台，组建完成顺丰国防交通专业保障队伍。协调推动邮政集团公司和具备条件的快递企业成立交通战备机构。联合军方开展调研，启动邮政业军民融合和交通战备规划编制研究工作。

四是加快绿色发展。贯彻落实习近平总书记在全国生态环境保护大会上的指示精神，推动邮政集团公司建立健全企业生态环保组织机构和工作体系，加快“绿色邮政”建设，推进生产作业节能降耗，促进邮件包装绿色化、减量化、可循环，全面应用新标准箱、免胶带箱，减少营业环节胶带使用量，年底循环中转袋使用率达到70%，电子运单使用率达到95%。升级运输装备，推广甩挂运输，城市新增投递用车全部使用新能源或清洁能源汽车。塑造绿色邮政品牌形象，发挥好国有企业的引领带动作用。

三、支持邮政企业做强做优做大

鼓励邮政企业推进公司制改制，巩固和发展国有经济，做强做大寄递主业，增强国有企业的经营活力、社会影响力和抗风险能力，把中国邮政打造成为我国邮政行业的主力军。

一是推动邮政综合服务平台建设。制定出台邮政综合服务平台建设指导意见，推进“邮政在乡”与“快递下乡”相结合，共建城乡双向流通渠道，适应服务乡村振兴和新型城镇化建设，推动邮政、快递、交通、电商融合发展；深入推进“放管服”改革，支持邮政企业拓展“邮政+政务服务”领域，在继续扩大警邮合作成果的同时，国家局将加强与税务总局的协商，共同推进税邮合作；各地管理部门要主动与当地税务部门联系，扩大合作范围和覆盖面。总结推广贵州等地政务服务经验，各地管理部门要鼓励邮政企业进驻政务服务大厅，开展“线上办理+线下寄递”服务，助力“不见面”审批。

二是加强基础能力建设。推进邮政设施强基工程，实施2019年西部和农村地区邮政基础设施建设项目，完成网点改造382处，购置运输和投递车辆590辆。各级管理部门要积极主动与发改部门衔接沟通，建立协调联动机制，履行行业监管责任，加大监督检查力度，做到项目审查到现场、建设到现场、验收到现场，确保项目实施质量和进度。实施“末端转型升级”行动计划，推动修订《住宅信报箱》国家标准，制定推广智能信包箱建设指导意见。各级管理部门要加强与地方政府联系，主动与住建、规划部门沟通，出台“一个文件”，争取将新建住宅小区配套建设智能信包箱纳入建筑工程总体方案，统一规划、统一设计、统一建设、统一验收；制定“一个标准”，推动出台智能信包箱建设的地方标准；办好“一件实事”，争取将智能信包箱建设纳入地方民生实事。

四、加强邮政普遍服务监督

一是开展普遍服务达标检查。巩固深化巡视整改成果，重点解决邮政管理部门对企业履行普遍服务义务的督促引导不够，在履行监督管理职责中失之于宽的问题。推进 “双随机、一公开”，完善“两库一清单”，国家局将抽选8个省份16个市（地）组织开展2次普遍服务达标专项大检查，重点检查农村服务达标和严守“两条红线”情况。各省局要制定方案，组织力量，有力有效开展普遍服务达标检查，切实履行监管责任，督促企业充分落实普遍服务义务。

二是开展平信寄递服务质量提升行动。各省局要将平信丢损和服务质量作为达标检查的一项重要任务，开展省内、同城平信全过程跟踪监测，发现的问题抓住不放，追溯整改，确保平信服务质量有一个大的提升，保障人民群众用邮权益。

三是加强仿印邮票图案管理。进一步明确职责，规范流程，国家局统一组织，加大工作力度，选取 16个省开展仿印邮票图案管理省际交叉执法检查。各省局要按照国家局部署，采取有力措施，加强对仿印邮票图案及其制品审批管理工作。

五、全面提升监管信息化水平

国家局升级改造普遍服务监督管理信息系统，优化现有监督管理系统和行政审批系统各项功能，运用信息化大数据手段对农村地区投递情况开展监督，审批事项网上办理。结合“绿盾工程”，推进普遍服务局所视频监控信息接入工作，逐步实现乡镇局所营业情况的信息化监督。畅通各个信息系统间的数据对接，优化使用体验，全面提升普遍服务监督管理信息化水平。各省局要配合信息系统升级改造和“绿盾工程”的实施，督促市（地）局加强信息系统应用，协调邮政企业做好普遍服务局所视频信息的接入和农村地区投递监督功能的推广应用，建设信息化监管平台。

国家局将继续做好邮政普遍服务季度通报和监管报告的编制和公开工作，将各省季度通报、监管报告的报送时间和质量情况纳入考核。各省局要做好本省季度通报和监管报告的编制和公开工作。季度通报要体现重点工作推进情况，附表数据要详实准确，与普遍服务监督管理信息系统报送数据一致。第四季度通报要对照本通知各项工作，汇总各项数据，逐一说明完成情况。各季度通报应于每季度结束后的下月10日前以正式文件抄报国家局。督促地方邮政企业按要求报送邮政普遍服务质量自查报告。

各级邮政管理部门要加强组织领导，统筹安排、强化措施，落实责任，保质保量完成全年各项任务。
