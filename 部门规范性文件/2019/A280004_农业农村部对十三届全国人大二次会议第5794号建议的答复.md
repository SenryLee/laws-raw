# 农业农村部对十三届全国人大二次会议第5794号建议的答复

## 对十三届全国人大二次会议第5794号建议的答复

农办议〔2019〕161号

张海波代表：

您提出的关于加快建设现代化海洋牧场的建议收悉。经商自然资源部，现答复如下。

一、关于突出生态绿色发展，促进产业多元融合

海洋牧场，是指基于海洋生态系统原理，在特定海域，通过人工鱼礁、增殖放流等措施，构建或修复海洋生物繁殖、生长、索饵或避敌所需的场所，增殖养护渔业资源，改善海域生态环境，实现渔业资源可持续利用的一种渔业模式。2006年国务院发布的《中国水生生物资源养护行动纲要》明确将海洋牧场作为渔业资源增殖与保护的行动之一。我部在国家级海洋牧场示范区创建的要求中，明确提出示范区应对渔业生态环境和渔业资源养护具有重要作用，在我部发布的《国家级海洋牧场示范区建设规划（2017—2025年）中要求，我国今后一段时期海洋牧场的发展，将以贯彻“创新、协调、绿色、开放、共享”五大发展理念为引领，从渔业资源可持续利用角度出发，以国家级海洋牧场示范区为抓手，以人工鱼礁和海藻场建设为载体，以增殖放流为补充，大力推进以海洋牧场为主要形式的渔业资源生态修复和区域性渔业综合开发。

同时，我部还积极支持海洋牧场拓展功能，在海洋牧场建设中积极推进一二三产业融合发展。2018年，我部指导中国水产学会、中国水产品流通加工协会、国家海洋牧场科技创新联盟等单位共同主办中国国际海洋牧场大会。大会以“生态、资源、绿色、共享”为主题，集中展示包括海洋精深加工利用、海洋牧场产品流通、休闲渔业、海洋牧场产业金融、第三方评估机构和海洋牧场成果在内的一系列新技术、新方法、新成果。通过大会的展示、推广、交易、对接功能，有效增强行业间的沟通交流、促进产业间的优势互补、推进我国海洋牧场建设中一二三产业的融合发展。今年8月，我部还将继续指导开展第二届中国国际海洋牧场大会。下一步，我部将继续推动海洋牧场中一二三产业的融合发展，支持建设集生产、观光、垂钓、餐饮、娱乐、文化、科普等一体的现代化渔业综合体。

二、关于强化科技支撑，推广深远海养殖

发展深远海养殖是调减近海过密网箱养殖、保护生态环境、提升养殖质量、拓展养殖空间的重要举措，近年来我部采取了一系列措施支持各地发展深远海养殖。一是实施深远海抗风浪网箱养殖项目，从2016年起，4年来中央渔业油价补贴政策调整专项转移支付资金深水抗风浪网箱项目共补助资金7.9亿元，在12个沿海省（区、市）建设5262个深水抗风浪网箱，有效缓解了近海养殖环境压力。二是推进深远海大型智能网箱养殖装备试验示范。2018年，“深蓝1号”“德海1号”深远海大型智能养殖装备相继成功建造并下水，标志我国在深远海智能养殖装备设计建造方面取得了重大突破，有效推动水产养殖从近海向深海养殖转变，从普通网箱养殖向大型装备养殖转变，从传统人工养殖向自动化智能化养殖转变。

今年初，经国务院同意，农业农村部、生态环境部、自然资源部等十部委联合印发《关于加快推进水产养殖业绿色发展的若干意见》，明确提出“支持发展深远海养殖，鼓励深远海大型智能化养殖渔场建设”。下一步，我部将加强与有关部门的沟通合作，继续推进深水抗风浪网箱养殖项目，加大深远海大型智能养殖装备示范支持力度，拓展深远海养殖面积，进一步优化海水养殖空间布局。

三、关于加大支持力度，完善海洋牧场建设配套政策

从2016年开始，中央财政每年安排专项资金，重点支持在国家级海洋牧场示范区开展人工鱼礁和海藻场、海草床建设，至今全国已落实资金22.6亿元，支持93个海洋牧场建设。该资金补助的主体为海洋牧场建设者，企业作为建设主体的只要符合相关条件就可以参与申报。2018年，相关部门联合印发《关于农业政策性金融促进海洋经济发展的实施意见》，明确提出支持人工鱼礁和海洋牧场建设，推动海洋渔业现代化发展。

下一步，我部将研究继续创新海洋牧场建设和管理模式，在确保渔业资源得到有效保护和可持续利用的前提下，按照“谁投资、谁管理、谁受益”的原则，合理确定投资者、经营者和管理者的投资比例、利益分配和责任分工。积极探索海洋牧场的渔区渔民参与及受益机制，以及有效监管和惠益分享机制，促进海洋牧场的生态、经济和社会效益更好地融合。

四、关于规范标准体系，明确监管职责

近年来，休闲海钓船、海洋牧场平台、大型深水智能网箱、养殖工船等新兴渔业设备不断涌现，面对新问题新情况，我部加强跟踪调研，深入开展研究，不断总结经验，适时组织制定相关标准、出台政策性文件，加强规范管理。2010年以来，我部发布了《水生生物增殖放流技术规程》《人工鱼礁建设技术规范》和《海洋牧场分类》等20余项海洋水产行业标准，2019年组织海洋牧场建设专家咨询委员会启动了海洋牧场相关技术规范编制工作，目前已着手开展16项标准编制工作，涉及海洋牧场建设和监管的各个方面。我部还着手起草《休闲渔船管理规定》，对养殖工船现状进行了调研。您提出的对海区实施空间规划，明确各品种养殖的空间范围和作业规范，我们在《海洋牧场资源增殖技术指南》和相关技术规范中已予以考虑。下一步，我部将积极推动海洋牧场相关技术规范编制发布，研究强化休闲渔船管理，不断规范海洋牧场建设、运营和管理，更好地指导休闲渔业规范有序发展。

感谢您对海洋牧场工作的关心，希望继续对我部的工作给予支持。
