# 中华人民共和国农业农村部公告第177号——对“深两优973”等水稻、玉米、普通小麦、大豆、甘蓝型油菜、大麦属、棉属、甘蔗属、马铃薯、蝴蝶兰属、梨属、桃、荔枝、苹果属、香蕉、猕猴桃属、葡萄属、李、橡胶树、茶组、三七等21个植物种类318个品种授予植物新品种权的公告

## 中华人民共和国农业农村部公告

第177号

“深两优973”等水稻、玉米、普通小麦、大豆、甘蓝型油菜、大麦属、棉属、甘蔗属、马铃薯、蝴蝶兰属、梨属、桃、荔枝、苹果属、香蕉、猕猴桃属、葡萄属、李、橡胶树、茶组、三七等21个植物种类318个品种，经农业农村部科技发展中心审查，农业农村部植物新品种保护办公室复核，符合《植物新品种保护条例》和《植物新品种保护条例实施细则（农业部分）》的要求，现对其授予植物新品种权并予公告。

农业农村部

2019年5月24日

附件：农业农村部公告第177号
