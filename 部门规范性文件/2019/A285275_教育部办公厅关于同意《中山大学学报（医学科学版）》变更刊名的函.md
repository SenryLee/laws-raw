# 教育部办公厅关于同意《中山大学学报（医学科学版）》变更刊名的函

中山大学：

《中山大学关于商请〈中山大学学报（医学科学版）〉刊名微调为〈中山大学学报（医学版）〉的函》（中大函〔2019〕698号）收悉。经研究，同意《中山大学学报（医学科学版）》刊名变更为《中山大学学报（医学版）》。请按程序到新闻出版管理部门办理相关手续。

教育部办公厅

2019年12月16日
