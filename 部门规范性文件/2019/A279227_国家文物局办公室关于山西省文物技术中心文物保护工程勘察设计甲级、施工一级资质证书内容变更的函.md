# 国家文物局办公室关于山西省文物技术中心文物保护工程勘察设计甲级、施工一级资质证书内容变更的函

办保函〔2019〕589号

山西省文物局：

你局《关于山西省彩塑壁画保护研究中心变更设计资质证书内容的请示》（晋文物〔2019〕54号）、《关于山西省彩塑壁画保护研究中心变更施工资质证书内容的请示》（晋文物〔2019〕55号）收悉。

经研究，我局同意山西省文物技术中心文物保护工程勘察设计甲级资质证书、施工一级资质证书中的单位名称由“山西省文物技术中心”变更为“山西省彩塑壁画保护研究中心”，法定代表人由“杨海军”变更为“李润成”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局办公室

2019年7月3日
