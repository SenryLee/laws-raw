# 交通运输部办公厅关于组织申报交通运输行业高层次人才培养项目的通知

交办人教函〔2019〕1299号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），中国远洋海运、招商局、中国交通建设集团，有关高等院校，国家铁路局、中国民用航空局、国家邮政局，部属各单位：

为加大对交通运输行业高层次人才培养力度，我部在"十三五"期间设立人才培养专项经费，重点用于资助部评选的优秀人才。根据《交通运输教育培训与人才培养资金管理暂行办法》等有关规定，现将开展交通运输高层次人才培养项目的申报工作有关事宜通知如下：

一、资助对象。包括：交通运输部评选的"交通运输青年科技英才"和入选交通运输行业科技创新人才推进计划的"中青年科技创新领军人才" "全国水运工程勘察设计建造大师"等；部属单位设聘的"首席研究员" "卓越创新团队带头人"等。凡曾当选为 "交通运输青年科技英才""中青年科技创新领军人才" "全国水运工程勘察设计建造大师" "首席研究员""卓越创新团队带头人"等高层次人才，未获得过资助的或已完成"人才培养项目"的当选人才均可申请。优先资助依托重大建设工程、重点科研项目、重点科研基地等从事专业技术工作、业绩突出、潜力较大的人才。

二、资助内容。主要资助当选人才出版论文专著、参加学术交流、参加知识更新，每个项目每人每年资助不超过8万元。不资助当选人才出国考察、培训、交流；不资助当选人才参与学历学位教育；不资助当选人才参加社会化高收费培训。

三、申报要求。各省级交通运输主管部门、中央管理的交通运输企业、有关高等院校、国家铁路局、中国民用航空局、国家邮政局，部属各单位作为人才培养项目的组织推荐单位，按照本通知要求组织开展申报工作，受理申请人所在单位提交的申请材料（见附件1），负责审查申请人资格，审查资助的必要性、项目实施的可行性、信息填报的完整性，并负责人才培养项目的管理等。推荐申报所需相关表格可在交通运输部政府网站—机构—人事教育司—资料下载栏目中下载。

请各组织推荐单位于2019年10月10日前将《交通运输行业高层次人才培养项目申请书》和《交通运输行业高层次人才培养项目汇总表》（含纸质版和电子版）反馈我部。

四、项目审查。我部将组织专家进行评审，对申报项目的主要内容、预期成果、完成期限、资助额度、经费用途等进行审查后，发布"交通运输行业高层次人才培养项目资助计划",并予以资助。

五、项目总结。受资助人应在项目周期结束后三个月内向所在单位报送《交通运输行业高层次人才培养项目总结报告》（见附件3,以下简称《总结报告》）和《交通运输行业高层次人才培养项目经费使用情况表》（见附件4,以下简称《经费使用情况表》），由组织推荐单位汇总后反馈我部。

组织推荐单位要对2018年以前资助的项目进行全面梳理，对尚未提交《总结报告》的项目，督促各单位报送《总结报告》和《经费使用情况表》，并于2019年12月31日前汇总后反馈我部。

交通运输部科学研究院受委托承担报送我部材料的受理工作。请用中国邮政EMS快递寄送纸质材料。联系人：徐婧，联系电话：010-58278540,电子邮箱：jtrc123@163.com,通讯地址：北京市朝阳区惠新里240号 交通运输部科学研究院交通发展研究中心，邮政编码：100029.
