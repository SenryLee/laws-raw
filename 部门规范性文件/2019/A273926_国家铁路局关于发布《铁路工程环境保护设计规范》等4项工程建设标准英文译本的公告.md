# 国家铁路局关于发布《铁路工程环境保护设计规范》等4项工程建设标准英文译本的公告

国铁科法〔2019〕6号

现发布《铁路工程环境保护设计规范》（TB 10501-2016）、《铁路工程节能设计规范》（TB 10016-2016）、《铁路工程设计防火规范》（TB 10063-2016）和《铁路桥涵混凝土结构设计规范》（TB 10092-2017）等4项铁路工程建设标准英文译本。英文译本与中文版标准在技术上出现异议时，以中文版为准。

以上英文译本由中国铁道出版社组织出版发行。

国家铁路局

2019年1月28日
