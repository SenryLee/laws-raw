# 国家文物局办公室关于山西长治鑫通古建筑工程有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕616号

山西省文物局：

你局《关于山西长治鑫通古建筑工程有限公司变更施工资质证书内容的请示》（晋文物〔2019〕62号）收悉。

经研究，我局同意山西长治鑫通古建筑工程有限公司文物保护工程施工一级资质证书中的单位名称由“山西长治鑫通古建筑工程有限公司”变更为“山西长治鑫通古建工程有限公司”，注册资金由“400万元”变更为“3500万元”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局办公室

2019年7月11日
