# 国家文物局办公室关于在张学良旧居保护范围内进行红楼群西、南围墙翻建及正门建设项目的意见

办保函〔2019〕24号

辽宁省文物局：

你局《关于翻建张学良旧居红楼群西、南围墙及正门的请示》（辽文物〔2018〕41号）收悉。经研究，我局暂不同意在张学良旧居保护范围内进行红楼群西、南围墙翻建及正门建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步加强研究，搜集历史照片、历史设计图等有关资料，为张学良旧居红楼群西、南围墙翻建及正门建设提供确凿的历史依据。同时对围墙及红楼建筑的砌筑材料、方法进行分析研究，进一步明确现有围墙的修建时间。

（二）补充墙体结构稳定检测报告。根据最小干预的原则，应按现有形式维修，不宜改变装饰线脚、铁艺围栏和大门式样。

（三）重新编制文物影响评估报告，补充相关保护管理规定等必要内容。文物影响评估报告和设计方案不得由同一单位编制。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月14日
