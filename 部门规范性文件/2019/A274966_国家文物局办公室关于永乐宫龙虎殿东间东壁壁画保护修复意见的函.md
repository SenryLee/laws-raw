# 国家文物局办公室关于永乐宫龙虎殿东间东壁壁画保护修复意见的函

办保函〔2019〕160号

山西省文物局：

你局《关于审批芮城永乐宫壁画保护修复方案的请示》（晋文物〔2018〕142号）收悉。经研究，我局意见如下：

一、建议选取永乐宫龙虎殿东间东壁壁画开展试验性保护修复。根据壁画保护修复实践效果及相关经验总结，再行确定永乐宫壁画保护修复方案。

二、坚持“文物最小干预”原则，严格控制项目实施范围，强化具体病害保护处理措施的针对性，不得干预、扰动壁画较为稳定及无病害部位。

三、深化现状勘察，深入研究整体搬迁时的修复历程，分析揭取和保护的工艺、材料，明晰病害肌理，为制定保护措施和后续预防性保护措施提供依据。

四、进一步明晰丙烯酸乳液、有机硅改性丙烯酸乳液的加固肌理，补充其在壁画地仗层、颜料层和同类壁画模拟样品上的附着力、柔韧性及加速老化等系统评价数据，建议增加明胶等传统材料在材料筛选过程中的权重。

五、拼接缝填补应遵循少量、多次、循序渐进的方法，待底部填补材料水分收定、不再干缩后再进行第二次填补。填补材料的强度不应超过壁画地仗原材料，慎重添加有机硅改性丙烯酸乳液，并应进行材料强度测试。

六、注重永乐宫壁画的预防性保护，管理人员应全过程参与，增强管理机构的日常保养和监测能力。

专此函复。

国家文物局办公室

2019年3月6日
