# 国家文物局关于公刘墓保护范围内泾河东庄水利枢纽工程建设项目的意见

文物保函〔2019〕9号

陕西省文物局：

你局《关于陕西省泾河东庄水利枢纽工程淹没区涉及公刘墓保护范围的请示》（陕文物字〔2018〕185号）收悉。经研究，我局原则同意在公刘墓保护范围内实施泾河东庄水利枢纽工程建设项目。

一、所报方案尚需进行水库淹没区文物赋存山体的地质变化监测、地质灾害预防、库水冲刷区域边坡突发垮塌应急预案等专项设计；完善水库运营期间文物影响评估报告和保护方案；补充考古勘探结果与文物保护范围、工程水位线叠加图等。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古调查和发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

五、请你局指导有关单位，进一步明确泾河东庄水利枢纽工程涉及陕西省文物保护单位断泾遗址的设计思路，及时编制相关方案并履行报批程序。

专此函复。

国家文物局

2019年1月2日
