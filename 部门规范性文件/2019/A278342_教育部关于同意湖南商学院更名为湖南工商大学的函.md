# 教育部关于同意湖南商学院更名为湖南工商大学的函

教发函〔2019〕60号

湖南省人民政府：

《湖南省人民政府关于申请将湖南商学院更名为湖南工商大学的函》（湘政函〔2019〕17号）收悉。

根据《中华人民共和国高等教育法》《普通高等学校设置暂行条例》《普通本科学校设置暂行规定》有关规定以及第七届全国高等学校设置评议委员会评议结果，经教育部党组会议研究决定，同意湖南商学院更名为湖南工商大学，学校标识码为4143010554；同时撤销湖南商学院的建制。现将有关事项函告如下：

一、湖南工商大学系多科性本科学校，以本科教育为主，同时承担研究生培养任务，由你省领导和管理。

二、学校要切实加强党的建设，全面贯彻党的教育方针，坚持社会主义办学方向，落实立德树人根本任务，培养德智体美劳全面发展的社会主义建设者和接班人。

三、学校要积极融入国家“一带一路”建设和长江经济带发展战略，培养创新型、创业型、应用型工商类人才，建设特色鲜明的高水平工商大学。

四、学校全日制在校生发展规模为20000人。

望你省加强对学校的指导和支持，加大资源投入力度，引导学校科学定位、内涵发展，强化传统优势学科特色，促进各学科交叉融合，加强教师队伍建设，加大高层次人才引进力度，不断提高教学科研水平，提升服务区域经济社会发展的能力。

该校参与举办的独立学院湖南商学院北津学院，同时更名为湖南工商大学北津学院。

教育部

2019年6月10日
