# 自然资源部办公厅关于组织开展第50个世界地球日主题宣传活动周的通知

自然资办函〔2019〕453号

各省、自治区、直辖市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中国地质调查局及部其他直属单位，各派出机构，部机关各司局，有关学会、协会和基金会：

今年4月22日是第50个世界地球日（以下简称“地球日”）。地球日主题宣传活动是宣传我国自然资源国情国策国法、引导社会公众树立生态文明理念、建立正确的自然资源观和普及地球科学知识的重要平台。现将活动周有关事宜通知如下：

一、活动主题

第50个世界地球日活动将以“珍爱美丽地球 守护自然资源”为主题，引导社会公众树立“绿水青山就是金山银山”和“人与自然和谐共生”的理念，动员自然资源工作者积极投身“建设生态文明是中华民族永续发展的千年大计”的伟大实践，激发青少年形成亲近自然、了解自然、保护自然的生态意识。各地各单位举办活动时，可以使用统一主题，也可根据实际情况丰富或细化主题内容。

二、活动时间

第50个世界地球日主题宣传活动周从4月22日（星期一）开始，至4月28日（星期日）结束。

三、活动要求

（一） 组织做好宣传活动

部将围绕今年地球日主题，组织开展一系列可供各地共同参与的示范活动，进一步发挥自然资源特色科普活动的引导带动作用。各承办单位要按照部的统一要求，做好具体策划和筹备工作，确保各项示范活动顺利开展。示范活动信息将陆续在部门户网站地球日专栏公布，请各地积极参与。

各级自然资源主管部门、中国地质调查局及部其他直属单位，要围绕活动周主题，充分调动首席科学传播专家、自然资源工作者及地学爱好者的积极性，策划开展系列主题科普活动，宣传自然资源国情国策国法，普及自然资源新理念、新方法和新技术，引导全社会节约集约利用自然资源，增强对山水林田湖草生命共同体的认识。鼓励各单位通过动画、短视频、动漫片等通俗易懂、公众喜闻乐见，且便于传播的形式，开展地球日主题宣传和自然资源科学普及活动。

各国土、海洋、测绘科普基地在活动周期间要免费或优惠向社会公众或青少年开放，要围绕地球日主题继续做好“三个一”活动，即一场专题展览、一场科普报告会、一个青少年互动活动。

各自然资源部重点实验室、工程技术创新中心、野外科学观测研究基地要在活动周期间举办开放日活动，以专题讲座、实验室参观体验、重大科技成果展览等形式，向社会公众特别是青少年普及地球科学知识，宣传最新科技成果，营造良好的创新氛围。

各单位要严格按照中央、部的有关要求，厉行节约，不举办没有实质内容的仪式性庆祝活动，活动场面尽可能简朴，活动内容尽可能充实。加强对宣传内容的把关，确保数据来源权威，不含涉密内容，保障信息安全。

（二） 加强组织协调和媒体宣传

加强与教育、科技、科协等部门合作，充分发挥各级地质、土地、海洋和测绘学会、协会作用，联合有关高校、中小学校、“节约资源、保护环境，做保护地球小主人”活动组委会以及相关企业，开展集知识性、趣味性、传播性于一体的宣传活动。

要认真细致做好组织协调工作，加强安全保卫措施，制订预案，严防在活动期间发生安全事故及群体性事件。地球日前后免费开放的单位，要做好充分准备，根据需要适当控制、疏导人流。

要在充分利用电视、广播、报刊、网络等媒体渠道的同时，进一步探索与微博、微信、视频直播、短视频发布等新媒体平台的合作模式，积极采取短视频、动画、实时交流互动等宣传形式，切实提高地球日活动的社会关注度、参与度和传播力度。

部将免费提供系列宣传海报电子版和宣传视频，4月上旬可通过部门户网站地球日专栏下载使用。

（三） 加强信息反馈和总结

请各单位填写活动备案表（附件1），于3月31日前报部宣教中心。相关活动情况我们将通过部门户网站进行宣传展示。

请各科普基地做好免费或优惠开放和“三个一”活动安排，于3月31日前报送科普基地管理办公室。我们将通过部门户网站统一发布，相关情况将作为科普基地评估依据。

活动周结束后，请各省（区、市）自然资源主管部门及部直属有关单位及时统计本地区或单位活动情况，5月10日前将活动情况总结，统计表（附件2），短视频、动画等宣传资料及典型活动照片（5-8张），反馈部宣教中心。我们将挑选形式新颖、宣传效果显著、可推广复制性强的活动，通过部门户网站给予展示，供各地交流学习。
