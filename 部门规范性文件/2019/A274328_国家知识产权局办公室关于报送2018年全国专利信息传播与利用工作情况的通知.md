# 国家知识产权局办公室关于报送2018年全国专利信息传播与利用工作情况的通知

## 关于报送2018年全国专利信息传播与利用工作情况的通知

国知办函办字〔2019〕54号

各省、自治区、直辖市、计划单列市、副省级城市、新疆生产建设兵团知识产权局：

为深入贯彻《国务院关于新形势下加快知识产权强国建设的若干意见》（国发〔2015〕71号），全面了解各地落实《深入实施国家知识产权战略行动计划（2014—2020年）》、推动专利信息传播与利用工作的进展，深入分析新形势下做好专利信息传播与利用工作服务于知识产权强国建设的新思路、新举措，请各地方知识产权局于1月31日前将2018年专利信息传播利用工作情况总结电子件报送至我局专利局专利文献部。报送内容及要求如下：

一、2018年专利信息传播利用工作情况表（见附件）。包括专利信息传播利用工作基本情况、政策规划、工作体系、利用促进工作、信息服务、人才工作、基础工作、宣传推广及其他9方面工作以及上述专利信息传播利用相关工作在服务创新驱动发展战略、知识产权战略、知识产权强国强省建设中的作用和影响。

二、专利信息传播利用工作2018年度报告，内容包括：

（一）总结2018年专利信息传播利用工作的有益经验，分析存在的问题，并提出改进措施。

（二）典型案例。在2018年开展的专利信息传播利用工作中，选择1—2个有一定经济社会影响的实际案例，简要叙述工作过程、效果和意义。

（三）需求与建议。在专利信息传播利用工作中，希望我局给予的帮助或和相关工作建议。

三、专利信息传播与利用工作的联系人及联系方式。

特此通知。

附件：2018年专利信息传播利用工作情况表

国家知识产权局办公室

2019年1月24日
