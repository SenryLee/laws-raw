# 自然资源部公告2019年第44号——自然资源部关于中国石油天然气股份有限公司长庆油田分公司甘陕鄂尔多斯盆地华庆油田开采等8个矿山地质环境保护与土地复垦方案通过审查的公告

## 自然资源部公告

2019年第44号

## 自然资源部关于中国石油天然气股份有限公司长庆油田分公司甘陕鄂尔多斯盆地华庆油田开采等8个矿山地质环境保护与土地复垦方案通过审查的公告

根据《土地复垦条例》《矿山地质环境保护规定》等有关规定，中国石油天然气股份有限公司长庆油田分公司甘陕鄂尔多斯盆地华庆油田开采等8个矿山地质环境保护与土地复垦方案通过审查，现予公告。

附件：8个通过审查的矿山地质环境保护与土地复垦方案名单

2019年9月26日
