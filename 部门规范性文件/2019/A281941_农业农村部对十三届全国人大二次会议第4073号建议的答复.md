# 农业农村部对十三届全国人大二次会议第4073号建议的答复

## 对十三届全国人大二次会议第4073号建议的答复

农办议〔2019〕395号

您提出的关于切实从严保护基本农田确保粮食安全的建议收悉。经商财政部、自然资源部，现答复如下。

一、关于基本农田保护相关法律法规修改情况

为保障农民的土地权益，提高农村土地使用效率，近期由自然资源部牵头对《土地管理法》进行了修改。目前，《土地管理法》（修正案草案）已由自然资源部报全国人大常委会审议。《土地管理法》修改完成后，自然资源部将积极推进《基本农田保护条例》的修订工作，进一步加强土地执法追责，严肃查处违法占用耕地特别是永久基本农田的行为，并充分利用卫星遥感影像，发现违法违规用地线索，建立台账，逐一核实整改。综合运用立案调查、联合查处、挂牌督办、公开通报、加强行政执法与刑事司法衔接等方法手段，加大查处力度严厉打击违法占用耕地特别是永久基本农田案件，督促地方按照既处理事又处理人的原则，严肃处理。从2019年开始，实行"增违挂钩",根据一个地区年度内仍处于违法状态的违法用地数量，对土地利用年度计划指标按照一定比例暂扣，根据违法行为整改到位情况再按比例退还。

二、关于加强基本农田保护规划设计

（一）关于永久基本农田划定。2017年6月，我部会同自然资源部完成了全域范围内永久基本农田划定工作，全部实现了上图入库、落到实地，全国永久基本农田图斑总数4540多万个，共划定基本农田15.5亿亩。永久基本农田是耕地中的精华，全面划定永久基本农田并实行特殊保护是落实国家"藏粮于地、藏粮于技"战略的重要举措。2019年中央一号文件从巩固永久基本农田划定成果、严控建设占用、统筹生态建设和永久基本农田保护、加强永久基本农田建设、健全保护监管机制等方面明确了有关要求，以确保国家粮食安全和农产品质量安全为目标，进一步构建保护有力、集约高效、监管严格的永久基本农田特殊保护格局，牢牢守住耕地红线。

下一步，农业农村部将加强规划指导，建立国家、省、县三级规划体系，按照统筹整合资金、衔接建设布局的要求，确保各类项目落实到地块；指导各级地方政府编制好年度建设实施方案，做好土地利用总体规划与节水灌溉、土地整治、平原绿化等相关规划的衔接，避免出现规划冲突和投资浪费。同时，会同财政部等有关部门，进一步健全完善产粮大县利益补偿机制，促进地方粮食生产与财力同步增长。

（二）关于国土空间规划。2019年5月9日，中共中央、国务院印发《关于建立国土空间规划体系并监督实施的若干意见》，明确"将主体功能区划、土地利用规划、城乡规划等融合为统一的国土空间规划，实现‘多规合一’。"目前，按照党中央、国务院决策部署，自然资源部正在抓紧建立国土空间规划体系并监督实施。一是结合时代要求优化主体功能区战略格局，提出优化调整农产品主产区布局方案，纳入国土空间规划编制实施。二是提出配套政策优化策略，会同相关部门共同编制实施，着力考虑对重点生态功能区、农产品主产区的政策支持。

三、关于加大对粮食主产区的转移支付力度

粮食主产区是保障粮食安全的关键，党中央、国务院历来高度重视粮食主产区利益补偿机制。为促进粮食稳产增产，缓解主产区财政困难，调动地方政府重农抓粮积极性，2005年，中央财政出台产粮大县奖励政策，对粮食生产达到一定规模的产粮大县进行奖励。奖励政策设立以来，中央财政不断加大奖励力度，完善奖励政策，目前已经形成了包括常规产粮大县、超级产粮大县、产油大县、商品粮大省、特种大县和"优质粮食工程"等内容的综合奖励政策体系。其中，常规产粮大县奖励资金是一般性财力补助，其他奖励资金均由地方统筹用于粮食生产和发展。奖励资金规模由初期的55亿元增加到2019年的449.56亿元，累计安排4017亿元。2019年奖励资金较上年增加21.14亿元，增幅4.9%.实践表明，产粮大县奖励政策已成为调动地方政府重农抓粮积极性、稳定粮食生产供应最为重要的政策，支持提升了粮食综合生产能力，很好地体现了对粮食主产区的补偿和扶持，有效夯实了国家粮食安全基础。

下一步，中央财政将继续按照党中央、国务院决策部署，不断完善粮食主产区利益补偿机制，根据中央财力可能，加大产粮大县奖励资金投入，保障产粮大县重农抓粮得实惠、有发展。

感谢您对基本农田保护工作的关心，希望继续对我部工作予以支持。
