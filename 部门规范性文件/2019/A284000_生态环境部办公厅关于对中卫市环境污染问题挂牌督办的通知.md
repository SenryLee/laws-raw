# 生态环境部办公厅关于对中卫市环境污染问题挂牌督办的通知

## 关于对中卫市环境污染问题挂牌督办的通知

环办执法函〔2019〕840号

宁夏回族自治区生态环境厅：

2019年11月，生态环境部派出工作组对媒体反映的中卫市美利林区发现大面积污染物问题进行了现场调查。经查，媒体反映的污染问题系原宁夏美利纸业集团有限责任公司（现为中冶纸业集团有限公司）倾倒的造纸黑液所致。目前，你厅按照自治区党委、政府部署，指导中卫市人民政府采取了初步处置措施。

为消除环境安全隐患，严厉打击环境违法行为，我部决定对中卫市环境污染问题进行挂牌督办，并请你厅督促中卫市人民政府做好以下工作：

一、持续清污，科学处置。继续抓紧组织对现场污染物进行清理；加快污染物属性鉴定，严格按照污染物属性鉴定结论及专家意见，制定科学合理的污染物处置措施、土壤风险管控和修复措施；立即对污染场地地下水进行调查评估，尽快布设监测点位，及时掌握污染情况，并根据调查评估结果制定修复措施。

二、全面调查，严肃处理。深入调查此次环境污染问题，查明涉事企业造纸黑液去向及倾倒地等情况；严厉查处涉事企业的环境违法行为，依法依纪追究相关责任人的责任，对涉嫌犯罪的依法移送公安机关处理；调查核实相关监管责任，对责任人依法依纪进行严肃处理；依法依规开展生态环境损害赔偿工作。

三、举一反三，排查隐患。深刻汲取教训，开展腾格里沙漠及周边地区环境污染问题全面排查，坚决依法打击环境污染违法行为，切实保障生态环境安全。

督办任务完成后，由你厅向我部提出解除挂牌督办的书面申请并附相关材料。
