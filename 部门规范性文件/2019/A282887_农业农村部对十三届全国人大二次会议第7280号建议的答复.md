# 农业农村部对十三届全国人大二次会议第7280号建议的答复

## 对十三届全国人大二次会议第7280号建议的答复

您提出的关于加强农田水利基础设施建设和汛期蓄水的建议收悉，经商水利部、财政部，现答复如下。

一、关于废弃水库重新修复使用

全国已建各类水库近10万座，大部分建于上世纪50至70年代，限于当时条件，经过几十年运行，老化失修严重。为解决水库病险问题，我国先后规划实施多批病险水库除险加固项目，对6.5万余座水库进行了除险加固。通过实施水库除险加固工作，极大消除了水库安全隐患，有效降低了下游洪水风险，供水保证率和地表水资源利用率得到增强，取得了良好的经济、社会效益。

近年来，中央财政不断加大对农田水利设施建设的支持力度，通过水利发展资金支持高效节水灌溉、小型病险水库除险加固、水利工程设施维修养护等；通过农业综合开发、土地整治工作专项等资金支持高标准农田建设，改善农业生产基本条件，提高耕地质量，改善农村生产生活条件和生态环境。2019年，根据国务院机构改革精神，农田水利建设项目管理职责由水利部划转农业农村部，农业综合开发专项资金、土地整治工作专项资金和水利发展资金农田水利建设支出整合纳入农田建设补助资金，集中支持开展高标准农田及农田水利建设。农田建设补助资金、水利发展资金均按照因素法进行分配，实行“大专项+任务清单”管理方式。

关于您提出的“整合项目资金，把农村现有的废弃的水库重新修复使用”建议，各地可以在完成约束性任务的基础上，在大专项支持方向范围内，结合当地实际，按照有关规定统筹中央和地方资金予以支持。我部将认真贯彻落实党中央、国务院决策部署，充分发挥高标准农田基础平台作用，进一步推动农田建设与农村水利建设衔接，指导和协调山东省农业农村部门加大对农田水利设施改造的支持力度。水利部将继续开展水库除险加固相关工作，确保水库功能和效益正常发挥。对确有需要重新修复使用的废弃水库，积极指导和督促各地根据实际情况，扎实做好前期工作，制定合理可行的建设方案，按程序报批，由地方筹措资金统筹推进。

二、关于科学布局主河道上的拦水闸，利用河道蓄水

科学布局和调度水利工程，对于确保防洪安全和供水安全意义重大。我国降水时空分布严重不均，特别是近年来极端天气频发，涝旱急转、持续干旱等情况时有发生。为确保供水安全，水利部已要求基层水利部门加强汛期特别是汛末蓄水调度研究，制定完善调整方案，进一步加强工程调度，在确保防洪安全的前提下，充分利用雨洪资源，统筹考虑防洪、抗旱需求，努力增加库坝河道蓄水，同时，对一些重要河段合理修建设置拦河闸，保障农业灌溉用水需求，为粮食丰收提供有力保障。

感谢您对农业农村部工作的关心，希望继续支持我部工作！

农业农村部

2019年8月19日
