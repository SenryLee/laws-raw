# 住房和城乡建设部办公厅关于成立部科学技术委员会历史文化保护与传承专业委员会的通知

建办人〔2019〕32号

各省、自治区住房和城乡建设厅，直辖市住房和城乡建设（管）委、规划和自然资源委（局），新疆生产建设兵团住房和城乡建设局：

为进一步加强住房和城乡建设领域历史文化保护与传承工作，提升历史文化名城名镇名村保护与管理水平，充分发挥专家智库作用，根据我部科学技术委员会相关管理规定，决定成立住房和城乡建设部科学技术委员会历史文化保护与传承专业委员会。现将专业委员会名单予以公布。

附件：住房和城乡建设部科学技术委员会历史文化保护与传承专业委员会名单

中华人民共和国住房和城乡建设部办公厅

2019年4月29日
