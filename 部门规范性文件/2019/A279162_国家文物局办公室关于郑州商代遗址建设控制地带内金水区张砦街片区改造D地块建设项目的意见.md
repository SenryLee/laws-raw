# 国家文物局办公室关于郑州商代遗址建设控制地带内金水区张砦街片区改造D地块建设项目的意见

办保函〔2019〕561号

河南省文物局：

你局《关于再次上报郑州市金水区张砦街片区改造项目D地块设计方案的请示》（豫文物〔2019〕76号）收悉。经研究，我局暂不同意在郑州商代遗址建设控制地带内实施金水区张砦街片区改造D地块建设项目。

一、所报方案应按照我局《关于在郑州商代遗址建设控制地带内进行郑州绿地金水区张砦街建设项目的意见》（办保函〔2018〕1109号）要求，综合考虑郑州市城市总体规划和历史文化名城保护规划等规定，进一步降低建筑高度和容积率；深化文物影响评估，客观、合理分析建筑高度、外观样式等对郑州商代遗址及郑州市城市形象的影响，建议考虑将部分安置面积分散至其他项目地块。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，明确该区域地下文物分布范围、性质、时代和价值，为评估建设项目影响提供依据。考古发掘项目需另行填报考古发掘申请书。

二、请你局指导有关单位，根据考古发掘结果和上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年6月25日
