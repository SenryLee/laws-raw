# 国家林业和草原局办公室关于认真做好2019年上半年工作总结和下半年工作安排的通知

各省、自治区、直辖市林业和草原主管部门，内蒙古、大兴安岭森工（林业）集团公司，新疆生产建设兵团林业和草原主管部门，各计划单列市林业和草原主管部门，国家林业和草原局各司局、各派出机构、各直属单位：

为全面掌握2019年上半年全国林业和草原工作进展情况，请各地各单位对照年初全国林业和草原工作会议的安排部署，认真总结上半年重点工作进展情况，研究提出下半年工作计划，形成1800字以内的文字材料（一式2份），经本单位主要负责同志审核后，于2019年7月1日前连同电子文本报送我局办公室。

特此通知。
