# 国家药品监督管理局公告2019年第51号——国家药监局关于注销缝合用夹线器械医疗器械注册证书的公告

## 国家药品监督管理局公告

2019年第51号

## 国家药监局关于注销缝合用夹线器械医疗器械注册证书的公告

按照《医疗器械注册管理办法》的规定，根据企业申请，现注销波士顿科学公司（Boston Scientific Corporation）以下1个产品的医疗器械注册证书：缝合用夹线器械，注册证号：国械注进20152014187。

特此公告。

国家药监局

2019年6月26日
