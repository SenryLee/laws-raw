# 全国会计专业技术资格考试领导小组办公室发布2019年全国会计专业技术中高级资格考试大纲

为明确2019年全国会计专业技术中高级资格考试评价标准，全国会计专业技术资格考试领导小组办公室制定了2019年全国会计专业技术中高级资格考试大纲，现予发布。

附件：1.2019年中级会计实务考试大纲

2.2019年财务管理考试大纲

3.2019年经济法考试大纲

4.2019年高级会计实务考试大纲

全国会计专业技术资格考试领导小组办公室

2019年3月29日
