# 国家文物局办公室关于成都市文物考古工作队（成都文物考古研究所）文物保护工程勘察设计甲级、监理甲级资质证书内容变更的函

办保函〔2019〕684号

四川省文物局：

你局《关于成都市文物考古工作队（成都文物考古研究院）变更文物保护工程勘察设计资质证书的请示》（川文物〔2019〕62号）、《关于成都市文物考古工作队（成都文物考古研究院）变更文物保护工程监理资质证书的请示》（川文物〔2019〕64号）收悉。

经研究，我局同意成都市文物考古工作队（成都文物考古研究所）文物保护工程勘察设计甲级资质证书、监理甲级资质证书中的单位名称由“成都市文物考古工作队（成都文物考古研究所）”变更为“成都市文物考古工作队（成都文物考古研究院）”，法定代表人由“王毅”变更为“颜劲松”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局办公室

2019年8月5日
