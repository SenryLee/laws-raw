# 国家药品监督管理局公告2019年第73号——国家药监局关于批准注册161个医疗器械产品的公告

## 国家药品监督管理局公告

2019年第73号

## 国家药监局关于批准注册161个医疗器械产品的公告

2019年7月，国家药品监督管理局共批准注册医疗器械产品161个。其中，境内第三类医疗器械产品101个，进口第三类医疗器械产品28个，进口第二类医疗器械产品31个，港澳台1个（具体产品见附件）。

特此公告。

附件：2019年7月批准注册医疗器械产品目录

国家药监局

2019年9月2日
