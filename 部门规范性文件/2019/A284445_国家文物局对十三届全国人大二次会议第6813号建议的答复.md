# 国家文物局对十三届全国人大二次会议第6813号建议的答复

文物政函〔2019〕625号

刘锋代表：

您提出的“关于允许古民居产权流转的建议”，交由农业农村部和国家文物局分办。现将我局办理意见答复如下。

太行古堡群是晋城历史上形成的独具特色的具有防御和生产生活等功能的古堡建筑群，具有重要的历史、艺术和科学价值，其中柳氏民居、湘峪古堡、郭壁村古建筑群、窦庄古建筑群、郭峪村古建筑群、陈廷敬故居等被国务院公布为全国重点文物保护单位。近年来，国家文物局指导山西省文物局做好相关全国重点文物保护单位保护规划编制，并立项支持了一批古建筑修缮项目。

您在建议中指出太行古堡群保护利用工作面临着一些困境，特别是产权流转方面的问题，具有较强的现实性。我们注意到，晋城市于2019年1月1日正式颁布实施了《晋城市太行古堡群保护条例》，提出鼓励古堡所有权人以古堡入股，企业或者个人采用出资、租用等方式，参与古堡的开发利用，并依法享受收益权。可以说，已经在这方面作出了解决实践问题的重要探索。2018年，中办国办印发的《关于加强文物保护利用改革的若干意见》明确提出，鼓励依法通过流转、征收等方式取得属于文物建筑的农民房屋及其宅基地。

对于您提出的加大对太行古堡群保护利用政策研究和支持力度，配套相应的保护经费，国家文物局一方面将结合《中华人民共和国文物保护法》修订，把太行古堡群保护利用实践作为重要调研案例，并充分借鉴广东开平碉楼、安徽宏村西递等产权类型相近文化遗产的保护利用实践，研究提出具有针对性、可操作性的制度举措，为加强产权类型复杂不可移动文物的保护利用提供更加完善的法律保障；另一方面，将继续指导山西省文物局做好太行古堡群中全国重点文物保护单位保护修缮项目储备和申报，对于符合条件的给予经费补助，探索建立完善以各级财政经费为示范引领、以社会资本投入为主体支撑的保护投入模式。

感谢您对文物工作的关注和支持！

国家文物局

2019年7月3日
