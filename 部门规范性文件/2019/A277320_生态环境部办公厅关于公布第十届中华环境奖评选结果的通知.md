# 生态环境部办公厅关于公布第十届中华环境奖评选结果的通知

## 关于公布第十届中华环境奖评选结果的通知

环办科财函〔2019〕487号

全国人大环境与资源保护委员会、全国政协人口资源环境委员会、国务院各有关部门、中华全国总工会、共青团中央、全国妇联办公厅（室），各省、自治区、直辖市和计划单列市生态环境厅（局）：

为深入贯彻党的十八大、十九大以来，以习近平同志为核心的党中央关于生态文明建设的一系列重要部署，坚持绿色发展理念，弘扬新时代的环保典范，由全国人大环资委、全国政协人资环委、生态环境部等11家部委和单位组成中华环境奖组委会，开展了第十届中华环境奖评选表彰活动。

第十届中华环境奖评选围绕“生态兴则文明兴”主题，在城镇环境、环境管理、企业环保、生态保护和环保宣教五方面评选出中华环境奖5名、中华环境优秀奖18名。

现将第十届中华环境奖组织委员会公告（见附件）印发给你们，感谢你单位对该项工作的关心，并请继续给予支持。

## 第十届中华环境奖组织委员会公告

为贯彻落实习近平生态文明思想和全国生态环境保护大会精神，促进我国环境保护事业的发展，表彰和奖励在我国环境保护事业中事迹突出、具有时代感和代表性的新时代环保典范，依据《中华环境奖评选与奖励办法》，以“生态兴则文明兴”为评选主题，本着公开、公正、公平原则，在各有关部委、各级生态环境部门和社会各界的推荐基础上，经中华环境奖评选委员会严格评选，中华环境奖组织委员会审查批准，评选出第十届中华环境奖5名，中华环境优秀奖18名，现予公布。
