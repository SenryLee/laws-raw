# 农业农村部对十三届全国人大二次会议第8080号建议的答复

## 对十三届全国人大二次会议第8080号建议的答复

农办议〔2019〕273号

唐慧娟代表：

您提出的关于防范猪遗传资源丢失风险的建议收悉。经商发展改革委、财政部，现答复如下。

我国是世界上猪遗传资源最为丰富的国家之一，经过长期驯化和人工选育，形成了各具特点的地方品种，目前共有地方猪品种83个。我部高度重视包括地方猪在内的畜禽遗传资源保护，将42个地方猪品种列入国家级畜禽遗传资源保护名录重点保护。我部和发展改革委、财政部安排专项资金，实施种养业良种工程和畜禽种质资源保护项目，提升畜禽遗传资源保护和利用能力。截止2019年6月，已建成国家级地方猪遗传资源保种场55个、保护区7个、国家家畜基因库1个，各地也建设省级地方猪保种场（区、库）80余个，地方猪遗传资源保护能力和保护水平有了较大提高。

2018年爆发的非洲猪瘟疫情，对地方猪遗传资源安全造成重大威胁。我部高度重视、积极应对，印发《农业农村部办公厅关于加强地方猪遗传资源保护工作的通知》（农办种〔2018〕12号）等文件，督促指导各地各有关单位加大支持力度，切实落实各项保护措施，确保地方猪遗传资源安全。

一、关于紧急划定资源保种场、保护区3公里红线

目前，中央财政主要按照《农业农村部办公厅 财政部办公厅关于做好种猪场和规模猪场流动资金贷款贴息工作的通知》要求，通过贷款贴息等方式对包括地方猪保种场在内的种猪场进行资金支持。《农业农村部办公厅关于加强地方猪遗传资源保护工作的通知》明确要求，各地在指导地方猪保种场做好自身非洲猪瘟防控工作的同时，对其周边3公里范围内现有养猪场（户）进行全面排查，帮助中小规模养猪场（户）落实生物安全措施，消除风险隐患，净化地方猪保种场和保护区周边养殖环境。结合当地实际，鼓励和指导保种场、保护区创新防控机制，构建周边地区生物安全屏障。

二、关于立即启用猪遗传资源现代保护手段

采用超低温冷冻技术等现代保护手段，采集保存地方猪品种的DNA、精液、体细胞等遗传材料，是应对非洲猪瘟疫情威胁，丰富地方猪品种保护手段，完善遗传资源保护体系的重要途径。我部高度重视遗传材料保种工作，截止2019年6月，国家家畜基因库已保存了14个地方猪品种的精液和体细胞、63个猪品种的血样组织等遗传材料。2019年6月，我部制定实施《国家级地方猪遗传材料采集保存工作实施方案》，组织有关高校、科研院所、国家级地方猪保种场、保护区等单位，加快国家级地方猪品种遗传材料采集制作，并将其纳入国家家畜基因库长期保存。同时，指导各地利用地方基因库加快采集地方猪遗传材料，予以妥善保存。

三、关于分批建设畜禽遗传资源备份场

建设畜禽遗传资源备份场，可有效减少资源灭失风险。我部正加快推进异地建设地方猪备份保种场和区域性活体基因库，科学合理分散资源，提升保护能力。目前，我部正会同发展改革委，编制《现代种业提升工程建设规划（2019-2025年）》，将畜禽种质资源保护利用能力提升工程作为规划重要内容，统筹布局建设一批畜禽遗传资源保种场。一些省（区、市）迅速行动，安排专项资金支持保种场建设，如四川省2019年已安排超过1700万元资金用于7个备份场建设，浙江省2019年已基本建成备份保种场3个。

感谢您对畜禽遗传资源保护工作的关心，希望继续支持我部工作。
