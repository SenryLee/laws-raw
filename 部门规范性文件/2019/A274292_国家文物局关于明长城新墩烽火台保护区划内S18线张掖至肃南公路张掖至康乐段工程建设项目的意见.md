# 国家文物局关于明长城新墩烽火台保护区划内S18线张掖至肃南公路张掖至康乐段工程建设项目的意见

文物保函〔2019〕87号

甘肃省文物局：

你局《关于呈报S18线张掖至肃南公路张掖至康乐段工程涉及明长城新墩烽火台设计方案的请示》（甘文局发〔2018〕204号）。经研究，我局原则同意在明长城新墩烽火台保护区划内实施S18线张掖至肃南公路张掖至康乐段工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步研究首选采取北线方案通过的可能性，如确难实现，应进一步调整完善中线方案，利用现313省道南侧的道路通过巴吉滩产业园，避让明长城新墩烽火台保护范围。

（二）进一步完善文物影响评估报告。针对夯土烽火台结构强度极弱，受长期微振动影响破坏极大的特点，应以零振动为基准进行振动影响分析。

（三）应根据评估结论，对新墩烽火台本体采取必要的预加固措施，对通过此区域的车辆进行必要的限速措施，同时补充完善相关监测和监督管理措施。

（四）施工期间应加强管理，避免对长城造成损害；工程结束后应做好场地清理，恢复公路两侧原有地表形态等。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月23日
