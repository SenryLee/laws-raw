# 国家文物局关于南京南朝陵墓石刻保护范围和建设控制地带内仙新路过江通道建设项目的意见

文物保函〔2019〕63号

江苏省文物局：

你局《关于审批南京南朝陵墓石刻保护范围和建设控制地带内仙新路过江通道建设项目修改方案的请示》（苏文物保〔2018〕315号）收悉。经研究，我局原则同意在南京南朝陵墓石刻保护范围和建设控制地带内实施仙新路过江通道建设项目。

一、所报方案尚需做以下必要的修改和完善：

（一）进一步论证道路运行阶段产生的振动、污染等对文物的影响，制定文物及周边环境的长期监测和保护措施。

（二）应结合项目实施，提升文物周边环境，综合考虑文物展示和道路景观设计，妥善解决文物保护展示与城市道路体系改善之间的关系。

（三）细化施工中的文物保护方案，严格控制工程范围和施工强度，确保文物安全。

二、请你局组织专业考古研究单位，在项目拟建区域开展全面的考古发掘，进一步明确拟建区域内的文物分布和保存现状。考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

五、请你局督促地方人民政府落实主体责任，抓紧编制《南京南朝陵墓石刻保护总体规划》，切实加强南京南朝陵墓石刻的整体保护展示工作，并以北家边失考墓为重点，开展南朝陵墓群考古工作，明确文物分布范围和文物构成，统筹考虑文物保护管理与地方基础设施建设、城市发展的关系。

专此函复。

国家文物局

2019年1月16日
