# 农业农村部对十三届全国人大二次会议第1064号建议的答复

## 对十三届全国人大二次会议第1064号建议的答复

农办议〔2019〕265号

肖又香代表：

您提出的关于支持贫困县实施乡村振兴战略的建议收悉。经商发展改革委、财政部、商务部、人民银行和自然资源部，现答复如下。

一、关于发展乡村产业解决农村空心化的问题

近年来，我部引导各地大力发展乡村产业，拓展农民就业增收渠道，让更多的农民在乡"立得住".一是把乡村产业更多留在乡村。今年6月，国务院印发了《关于促进乡村产业振兴的指导意见》（国发〔2019〕12号），提出要突出资源优势，重点发展现代种养业、乡土特色产业、农产品加工流通业、乡村休闲旅游业、乡村新型服务业、乡村信息产业等。2018—2019年，我部通过中央财政农业生产发展资金安排108.19亿元，用于支持一二三产业融合和优势特色主导产业发展，开展农村一二三产业融合发展试点，通过延伸产业链、提升价值链、打造供应链，把立农、为农、兴农的产业都留在乡村，改变过去农村搞种养，城市搞加工流通的局面。二是把就业岗位更多留给农民。《国务院关于促进乡村产业振兴的指导意见》（国发〔2019〕12号）提出，要充分发掘乡村功能价值，引导加工流通企业重心下沉，向有条件的中心镇和物流节点集中。2014年起，商务部会同财政部等，开展电子商务进农村综合示范，建设农村电商公共服务体系和物流配送体系，已累计支持建设示范县1016个。农业农村部门支持各地建设了1600多个农产品加工园区（基地）。2018—2019年，共安排中央财政资金60亿元，建设552个集标准原料基地、集约加工转化、紧密利益联结于一体的农业产业强镇，把更多的就业岗位留给农民，吸引青壮年劳动力返乡创业就业。三是把产业链增值收益留给农民。2018年，中共中央、国务院印发了《乡村振兴战略规划（2018—2022年）》，提出"加快培育农商产业联盟、农业产业化联合体等新型产业链主体".2018年，我部已在全国10个省开展联农带农紧密的农业产业化联合体示范创建，认定省级产业化联合体近1000个，通过融合发展等多种方式，让农民有业就、有活干、有钱挣，促进农民增收。2019年，我部会同财政部继续支持农业产业化联合体建设，并纳入农业生产发展资金项目支持范围。下一步，我部将积极落实《国务院关于促进乡村产业振兴的指导意见》，积极发展乡村产业，吸引更多人员返乡入乡创新创业，促进乡村振兴。

二、关于支持质量兴农推进乡村振兴

农业农村部门坚持质量兴农，促进农业发展取得巨大进步，推动农业进入高质量发展阶段。一是推进安全县创建。湖南省安化县积极推进监管体系建设，所辖乡镇监管站实现机构队伍、职责职能、制度机制、设施装备、标识档案"五个规范化",监管执法全覆盖，标准化生产全推进，农产品质量安全工作成效显著。安化县于2017年被纳入第二批国家农产品质量安全县创建试点单位，2018年通过核查验收，目前正面向社会公示征求意见，无异议后即可命名为"国家农产品质量安全县".二是落实监管体系建设。我部高度重视农产品质量安全监管体系建设，加大对基层农产品质量安全监管体系建设力度，先后编制出台了《"十三五"全国农产品质量安全能力建设规划》和《全国农业执法监管能力建设规划（2016—2020年）》，提出了"十三五"期间监管能力建设的目标、方向和措施。下一步，我部将联合发展改革委，共同谋划加强基层农产品质量安全监管能力建设的投资点，积极争取项目支持。同时，在农产品质量安全监管体系建设中，对贫困地区给予重点支持，在监管能力建设方面优先向贫困地区倾斜。三是建设追溯平台。建立农产品质量安全追溯体系，是创新农产品质量安全监管方式的重要举措。2017年7月，国家追溯平台建成并上线试运行，在山东、广东、四川三省试运行基础上，不断进行优化升级。2018年，我部印发《关于全面推广应用国家农产品质量安全追溯管理信息平台的通知》和《国家追溯平台运行技术指南（试行）》，加强国家追溯平台推广应用。截至2019年4月底，全国共有10417家生产经营主体、2129家监管机构、625家检测机构、661家执法机构注册使用国家追溯平台，上传数据5.3万条。国家追溯平台具备延伸到县一级的功能。

下一步，我部将指导安化县根据自身需要，积极利用国家追溯平台，进一步强化农产品质量安全追溯管理。

三、关于推进体制机制创新促进乡村振兴

实施乡村振兴战略，必须大力推进体制机制创新，推动金融和财税制度创新，强化乡村振兴制度性供给，促进乡村振兴。一是健全农村金融体系。2019年，人民银行等5部门出台《关于金融服务乡村振兴的指导意见》，鼓励开发性、政策性金融机构在业务范围内为乡村振兴提供中长期信贷支持，要求农业银行在县域贷款增速持续高于全行平均水平，邮政储蓄银行加大对县域地区的信贷投放，逐步提高县域存贷比并保持在合理范围。二是创新金融产品和服务。推动金融机构开展厂房和大型农机具抵押、动产质押、仓单和应收账款质押等信贷业务，推广农村承包土地的经营权抵押贷款业务，积极稳妥开展林权抵押贷款，探索创新抵押贷款模式。截至2019年3月末，全口径涉农贷款余额达33.71万亿元，同比增长6.8%.三是拓宽直接融资渠道。支持涉农企业根据自身经营财务特点和融资需求，自主选择发行超短期融资券、短期融资券、扶贫票据等债务融资工具，优化融资结构。截至2019年4月末，累计支持17个省（区、市）23家企业发行扶贫票据31期349亿元，募集资金主要用于贫困地区产业发展和基础设施建设等精准扶贫项目，带动近100个贫困县的扶贫工作。四是改善农村金融环境。深入推进农村信用体系建设，联合相关部门、涉农金融机构开展 "信用户""信用村""信用乡镇"创建，为改善农村地区金融服务提供信息支持。截至2019年1月末，累计建立信用档案农户数1.88亿户，累计有9714万农户获得银行贷款，贷款余额达3.4万亿元。在农村和贫困地区不断推进支付服务环境建设，普及银行卡和结算账户，推广非现金支付，不断优化银行卡助农取款服务，截至2019年3月末，农村地区、贫困地区分别设置助农取款服务点达84.75万个和40.53万个，行政村覆盖率分别达98.32%和97.33%,显著提升了农村和贫困地区金融服务覆盖面和可得性。

下一步，相关部门继续加强协调配合，切实做好金融支持脱贫攻坚与乡村振兴的政策衔接、机制配合和工作统筹，着力提高金融服务的效率和水平。

感谢您对"三农"事业发展的关心，希望继续对我部工作给予支持。
