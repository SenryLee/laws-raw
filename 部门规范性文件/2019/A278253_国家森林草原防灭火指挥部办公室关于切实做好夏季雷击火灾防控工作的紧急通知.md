# 国家森林草原防灭火指挥部办公室关于切实做好夏季雷击火灾防控工作的紧急通知

国森防办发明电〔2019〕39号

内蒙古自治区、吉林省、黑龙江省、重庆市、四川省、云南省、新疆维吾尔自治区森林草原防灭火指挥部：

春防中后期，我国华北、东北、西部、西南等部分地区气温持续升高、降水不足，干雷暴活动频繁，森林草原火险等级居高不下。据东北重点林区三维雷电监测网探测，6月1日至11日东北重点林区共发生雷电2.4万次。据国家森防指办公室值班调度，6月以来共接报发生雷击森林火灾15起，其中内蒙古8起、黑龙江6起、四川1起。由于监测及时，反应快速，处置得当，在较短时间内将雷击森林火灾全部扑灭，没有酿成大灾。据会商预测，今年夏季（6-8月），我国降水呈“南多北少”分布，极端天气气候事件偏多，内蒙古、黑龙江和吉林大部、重庆东北部、四川南部、云南大部和新疆的部分地区气温偏高、降水偏少，雷暴大风等强对流天气发生频繁，森林草原火险等级偏高，防灭火形势十分严峻。为有效防控夏季雷击森林草原火灾，现紧急通知如下：

一、提高防控意识，切实增强责任感和紧迫性。近几年来，大兴安岭地区发生多起因雷击火引发的重特大森林火灾，各地要高度重视夏季雷击火防控工作。要深入学习贯彻习近平总书记关于做好森林草原防灭火工作重要指示精神，认真落实李克强总理和韩正副总理、王勇国务委员等领导同志批示要求，清醒认识近期部分地区森林草原火险等级偏高、雷击火灾频繁发生的严峻形势，切实增强责任感和使命感，坚决消除麻痹思想和侥幸心理，时刻紧绷森林草原防灭火安全这根弦，高度戒备，警钟长鸣，加强领导，落实责任，全力打好雷击火灾防控工作攻坚战。

二、认真统计分析，全面落实雷击火防控责任。要对历年来雷击火灾的发生时间、地点等进行倒查，认真统计分析，科学划分雷击火灾多发时间段和多发地域，有针对性地制定雷击防控工作方案和应急预案，层层分解任务、落实责任，全面排查整治火灾风险隐患，扎扎实实做好雷击森林草原火灾各项防控工作。

三、加强监测预警，确保雷击火情早发现。要充分利用雷电监测预警、雷电定位等技术手段，重点做好对雷电高发时段和多发地区的监控，及时提供雷电预警和火险趋势信息，各检查站、巡护队和管护瞭望人员全部上岗到位，切实加强高空瞭望和地面巡察，增加瞭望频率、延长瞭望时间，做到早发现、早报告、早处置。

四、强化应急处置，确保雷击火灾早扑灭。要加强应急值守和火情核查处置，落实专人在重点时段和重点部位进行严防死守，各航空护林站要做好飞机巡护和灭火准备，国家森林消防队伍和地方专业扑火队伍要加强战备值班，靠前驻防，发生火情要快速出击，做到精准研判、科学处置，将雷击火灾扑灭在萌芽阶段，确保打早、打小、打了。
