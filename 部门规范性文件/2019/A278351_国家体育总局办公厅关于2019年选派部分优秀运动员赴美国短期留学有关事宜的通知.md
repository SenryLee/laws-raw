# 国家体育总局办公厅关于2019年选派部分优秀运动员赴美国短期留学有关事宜的通知

## 体育总局办公厅关于2019年选派部分优秀运动员赴美国短期留学有关事宜的通知

体人字〔2019〕249号

各省、自治区、直辖市、新疆生产建设兵团体育局，有关运动项目管理中心，中国足球协会，中国篮球协会，有关改革试点项目协会，有关高校：

优秀运动员是我国体育事业发展的宝贵人才，为了更好地发挥优秀运动员的影响力和作用，全力备战东京奥运会、北京冬奥会和卡塔尔世界杯预选赛，强化优秀体育人才培养，经批准，体育总局将选派一批优秀运动员赴美国公派留学。现将有关事宜通知如下：

一、时间地点

（一）留学地点：美国东密歇根大学

（二）留学时间：2019年9月中下旬-12月中下旬（3个月），具体时间另行通知。

二、学习内容

理论知识和现场教学相结合，针对运动员特点及知识层次，重点讲授专项训练理论与实践、体能训练理论与实践、美国体育发展现状等课程，组织美国高校高水平运动队训练观摩等。

三、选派条件

（一）具有良好的政治素质和思想品德，拥护党的领导，热爱祖国，有学成回国为中国体育事业发展服务的事业心和责任感。

（二）具有中华人民共和国国籍，不具有国外永久居留权。

（三）2019年（含）之前大学本科毕业并取得相应学位，具备一定的英语水平能力。

（四）无故意使用兴奋剂违规记录。

（五）年龄在50周岁以下。

（六）未获得国家公派留学资格，或经国家留学基金委批准放弃留学资格满2年，或曾享受国家留学基金资助出国留学、回国后工作满5年。

（七）身体健康，能够正常完成留学任务。

（八）优秀的现役、退役运动员均可报名。报名运动员须获得奥运项目的亚运会前三名、世锦赛前六名、世界杯（总决赛）前六名或奥运会前八名。

四、选派程序

（一）遵循“公开、公平、公正”的原则，采取“个人申请，单位推荐，择优选拔”的方式进行选派。

（二）申请人应填报《2019年国家体育总局优秀运动员公派留学报名表》，内容真实准确。

（三）申请人应提请工作单位（或当地各级体育部门）对申请人的思想政治表现进行审核，审核合格后在推荐表上填写“同意推荐”并盖章，签署《公派出国留学承诺书》。

（四）将《2019年国家体育总局优秀运动员公派留学报名表》和《公派出国留学承诺书》报送至体育总局干部培训中心。申请受理时间截至2019年7月1日。

（五）体育总局人事司将对申请人材料进行审核，择优确定选派人员。

五、留学管理

（一）工作（推荐）单位应配合做好公派留学人员组织管理和教育工作，协助办理外事手续。

（二）按照留学工作规定，留学基金委与留学人员签订相关协议。

（三）正式出国前，体育总局对留学人员开展外事、安全等方面的行前教育。

（四）留学期间留学人员要自觉维护国家利益，遵守外事工作纪律，遵守所在国家法律规定、总局留学工作要求，以及留学学校规定，自觉接受驻外使（领）馆的管理。

六、相关费用

体育总局和国家留学基金委负担留学所需学费、国际机票、奖学金（用于食、宿及学习等开支）。
