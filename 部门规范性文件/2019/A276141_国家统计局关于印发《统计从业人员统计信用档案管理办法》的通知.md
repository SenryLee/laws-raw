# 国家统计局关于印发《统计从业人员统计信用档案管理办法》的通知

国统字〔2019〕34号

各省、自治区、直辖市统计局，新疆生产建设兵团统计局，国家统计局各调查总队，各司级行政单位、在京直属事业单位、出版社：
