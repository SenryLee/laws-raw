# 国家体育总局科教司关于提交“科技冬奥”重点专项2019年度定向项目申报材料的通知

## 体育总局科教司关于提交“科技冬奥”重点专项2019年度定向项目申报材料的通知

体科字〔2019〕86号

有关单位：

为做好“科技冬奥”重点专项2019年度定向项目推荐申报工作，请拟通过体育总局推荐的项目申报单位按照指南要求认真组织申报工作，并于2019年6月20日前将申报书纸质版1份报送至体育总局科教司，申报书需加盖申报单位公章，法人及申报人签字。我司将根据申报情况，开展专家论证工作（时间另行通知），对所推荐的项目申报材料进行审核把关并提出修改完善意见。
