# 国家文物局关于省级文物保护单位五虎山山城遗址保护范围内五虎山旅游景区建设项目的意见

文物保函〔2019〕398号

吉林省文物局：

你局《关于安图县石门镇五虎山旅游景区建设项目涉及五虎山山城遗址保护范围和建设控制地带的请示》（吉文物发〔2019〕101号）收悉。经研究，我局原则同意在省级文物保护单位五虎山山城遗址保护范围内实施五虎山旅游景区建设项目。

一、应加强与专业考古机构的沟通，核实木栈道、凉亭与城址的位置关系。同时，严格控制工程范围和施工强度，做好施工中的文物保护工作，确保文物安全。

二、进一步核减凉亭数量，简化外观设计，可通过设置多种形式的公共休息设施满足游客需求，以减少对遗址影响。补充凉亭设计技术图纸。

三、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古调查和发掘工作，考古发项目需另行填报考古发掘申请书。

四、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

五、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年4月28日
