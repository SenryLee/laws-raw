# 自然资源部公告2019年第63号——自然资源部关于第一批绿色勘查示范项目的公告

## 自然资源部公告

2019年第63号

## 自然资源部关于第一批绿色勘查示范项目的公告

按照原国土资源部、财政部等六部门《关于加快建设绿色矿山的实施意见》（国土资规〔2017〕4号）和《自然资源部办公厅关于开展绿色勘查项目示范工作的通知》（自然资办函〔2019〕815号）要求，经省级自然资源主管部门评选申报，专家评审，我部决定将内蒙古自治区阿鲁科尔沁旗双山子铜多金属矿普查等18个项目，作为第一批绿色勘查示范项目，现予以公告。

自然资源部

2019年12月30日
