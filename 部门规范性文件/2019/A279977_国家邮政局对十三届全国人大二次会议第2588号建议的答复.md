# 国家邮政局对十三届全国人大二次会议第2588号建议的答复

## 对十三届全国人大二次会议第2588号建议的答复

国邮函〔2019〕69号

殷勇代表：

您提出的“关于促进快递配送从业人员职业保障的建议”（第2588号）收悉。经商人力资源社会保障部，现答复如下：

近年来，随着我国快递业快递发展，快递从业人员队伍不断壮大，劳动者权益保障等问题也受到了社会的广泛关注。

一、关于强化劳动保障

人力资源社会保障部陆续开展了相关专题研究，赴部分地区和企业开展调研，组织了美团、饿了么、达达、顺丰及三通一达等快递配送企业和快递员、外卖员等劳动者群体座谈，深入研究新业态劳动用工现状，听取专家学者、新业态企业和劳动者的意见和建议。国家邮政局深入学习贯彻习近平总书记联系服务“快递小哥”的重要指示精神，连续三年将快递从业人员职业保障工作纳入“邮政业更贴近民生七件实事”，联合团中央开展“快递业从业青年权益维护服务月”活动。推动寄递企业规范内部管理，督促企业总部改善对于基层网点的运行管护，着力解决多重罚款等问题，有效遏制“以罚代管”。

下一步，人力资源社会保障部将做好以下工作，一是研究起草关于新业态劳动用工的文件，拟对新业态劳动用工类型进行分类规范，兜住包括快递、外卖员等在内的新业态劳动者劳动权益保障底线。二是继续加强快递行业用工指导，推动快递行业协会制定行业规范，指导快递配送企业科学合理确定劳动定额标准，在快递业发达的地区探索推进快递业集体协商，增强行业自律。三是加大劳动争议调解仲裁办案指导力度，指导基层调解组织妥善处理涉及快递配送员与快递配送企业间的争议，指导各地劳动人事争议仲裁机构妥善处理快递配送员劳动争议案件。四是不断强化劳动保障监察的职能作用。继续推进劳动保障监察体制机制改革，推动构建源头预防、动态监管和失信惩戒相结合的监察执法体系。国家邮政局将继续加强快递员权益保护，推进快递员关爱工程，遏制企业内部“以罚代管”行为，引导企业强化人文关怀，让一线快递员共享企业发展成果；对查处的劳动保障违法问题严重的快递企业，将实施联合惩戒管理。

二、关于完善社会保险政策体系

人力资源社会保障部正在推动各地积极降低养老保险费率，落实调整社保缴费基数政策，扩大灵活就业人员缴费基数的选择范围；结合课题研究，对新业态从业人员职业伤害保障问题开展了专题研究和调研，听取了相关企业和地方的意见建议，初步形成新业态从业人员职业伤害保障试点工作政策框架；委托科研单位开展将灵活就业人员和新就业形态人员纳入失业保险制度体系的研究，提出了初步政策建议，并召开专家座谈会，专题论证灵活就业人员参保的可能性。

下一步，一是结合逐步规范新业态劳动用工方式、明确企业责任，进一步研究适应新业态特点的参保缴费政策。同时结合户籍制度改革，鼓励地方逐步打破参保户籍限制，进一步完善灵活就业人员参保缴费办法。二是尽快启动新业态从业人员职业伤害保障试点工作，在政策制定、制度设计、实现路径等方面创新保障方式方法，选取部分工作基础好、基金结余多的地方，结合实际开展试点。三是加强失业保险信息化建设，着力推进失业保险经办“网上办”，结合快递从业人员特点，为参保职工获得失业保障提供便利。

三、关于建立多层次社会保障体系

国家高度重视多层次养老保险制度体系建设。《国务院关于企业职工养老保险制度改革的决定》（国发〔1991〕33号）提出，随着经济的发展，逐步建立起基本养老保险、补充养老保险和个人储蓄性养老保险相结合的制度。近年来，不断改革完善基本养老保险制度，大力推动企业（职业）年金发展。同时，鼓励有条件的用人单位为职工建立企业年金，提高职工退休后的养老保险待遇。第三支柱个人储蓄性养老保险和商业保险方面，自2018年5月1日起，在上海、福建和苏州工业园区开展个人税收递延型商业养老保险试点，作为养老保险第三支柱的有益探索和尝试，同时，不断完善税收优惠政策，稳步发展第三支柱。

下一步，将按照党中央、国务院部署，改革完善基本养老保险制度。落实好企业（职业）年金制度，扩大企业（职业）年金覆盖面。会同相关部门深入研究论证第三支柱重难点问题，加快建立第三支柱。

四、关于推进社会保险关系转移接续平台建设

近年来，人力资源社会保障部积极推进社会保险关系转移接续平台建设。截至目前，除西藏外的全部省份均已接入全国社会保险关系转移系统，系统覆盖376个地市，3179个社保经办机构，全国地市级社保经办机构入网率达97.6%。2018年以来，电子化转移业务量平稳增长，已入网省份通过转移系统办理业务35.9万笔，同比增长30%，联系函发出和信息表回复率增幅较大。同时，社会保险关系转移的进度查询功能已开发完毕，移动端口正在开发，待全国社会保险公共服务平台上线后，支持参保人通过互联网和手机APP查询本人转移接续业务办理进度和全国社保经办机构信息。

下一步，将推动养老保险关系转移业务全面通过部转移系统办理，研究建立转移基金定期清算制度，缩短业务办理周期。待全国社会保险公共服务平台上线后，支持转移业务办理进度网上查询，逐步实现支持参保人员通过互联网和手机APP提出转移业务申请。建立转移业务异地协同、督办提醒、仲裁调解机制，进一步优化社会保险关系转移接续平台建设，提升转移持续服务的便利化和智能化水平。

五、关于促进社会认同

国家邮政局与共青团中央成立邮政行业团指委，构建“1+3+N”合作框架，联合开展快递从业青年与人大代表、政协委员“面对面”等活动。支持国防邮电工会和地方工会推动非公快递企业组建工会，吸引快递员入会，稳妥推进“会站家”一体化试点建设，努力改善快递员工作环境。推广北京、吉林、河北、上海等省（市）针对快递员开展的提供租赁房、集体协商、依法参保、爱心驿站、健康体检、互助基金、春运专列等先进做法。组织开展关爱快递员系列工程，持续推进寻找“最美快递员”“关爱快递员周”等活动。发挥行业媒体资源优势，大力宣传其美多吉、最美快递员等行业先进典型，在行业内外掀起了寻找“最美”，发现“最美”，学习“最美”的热潮，积极营造关心、关注基层快递员的良好社会氛围。

下一步， 国家邮政局将继续开展“寻找最美快递员”活动，大力挖掘宣传“小蜜蜂”精神的实践典型。积极争取国家和地方表彰奖励政策，做好邮政行业表彰奖励工作。继续推动全国总工会探索建立行业工会组织，选树五一劳动奖章等行业典型。继续联合共青团中央共同开展青年文明号创建、青年安全生产示范岗创建、12355维权热线服务等工作。加大媒体宣传力度，深入宣传典型事迹，增强社会公众对行业和快递员的理解认同，弘扬行业正能量。

六、关于完善配套设施

国家邮政局多措并举保障快递末端服务车辆依法通行。一是优化政策环境。出台《国家邮政局关于规范快递末端服务车辆管理和使用工作的指导意见》（国邮发〔2018〕100号），依法保障末端快递服务车辆通行权利。截止2019年5月，全国已有221个市（地）出台了快递末端服务车辆通行管理政策，出台文件数量共计286份，全国政策覆盖率达65%。北京、河北、福建、上海、重庆、宁夏、甘肃等地实现车辆通行政策100%全覆盖。二是加强部门协作。协调公安机关交通管理部门建立快递末端服务车辆统一登记管理制度。目前，大部分已出台车辆通行政策的城市均对当地快递末端服务车辆进行了规范化统一管理，通过对车辆实施“统一编号”“统一标识”“统一保险”。三是督导规范通行。督促指导快递企业做好快递末端服务车辆依法依规、文明出行，协助开展非法拼改装车辆、逆向行驶、闯红灯等违法违规行为整治。推动建立快递协会行业自律、公安机关交通管理部门路面管理、邮政管理部门行业管理相协同的事前事中事后管理模式和快递车辆违法情况通报机制。

开展《智能快件箱寄递服务管理办法》制定工作。2019年6月12日，交通运输部部务会议审议通过《智能快件箱寄递服务管理办法》，并将于近期发布，第五条明确提出：“支持将智能快件箱纳入公共服务设施相关规划和便民服务、民生工程等项目，在住宅小区、高等院校、商业中心、交通枢纽等区域布局智能快件箱。”

下一步，将继续做好快递末端服务车辆依法通行，认真做好《智能快件箱寄递服务管理办法》宣贯工作，促进快递末端服务持续健康发展。

感谢您对快递业发展的关心和支持！
