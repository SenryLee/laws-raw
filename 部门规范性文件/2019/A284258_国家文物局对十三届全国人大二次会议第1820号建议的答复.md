# 国家文物局对十三届全国人大二次会议第1820号建议的答复

文物政函〔2019〕656号

张婧婧代表：

您提出的《关于美丽乡村建设中的文化遗产保护的建议》，已交由国家文物局会同文化和旅游部、住房和城乡建设部、农业农村部办理，现答复如下。

在广大乡村加强文化遗产保护，留存历史记忆，延续传统文脉，是文化遗产保护工作的历史使命和重要职责。近年来，在党中央、国务院的坚强领导下，各有关部门履职尽责、真抓实干，加大乡村文化遗产保护力度，推进优秀传统文化传承发展，取得了积极成果。

一是加强政策引导，推动形成乡村文化遗产保护共识。国务院颁布《历史文化名城名镇名村保护条例》，印发《关于进一步加强文物工作的指导意见》。住房和城乡建设部、原文化部、国家文物局、财政部印发《关于切实加强中国传统村落保护的指导意见》，文化和旅游部出台《国家级文化生态保护区管理办法》，国家文物局印发国保省保集中成片传统村落乡土建筑保护利用导则（试行），开展传统村落文物保护专项督察，乡村文化遗产保护政策措施日益完备，科学规划、严格保护、留住乡愁的理念逐渐深入人心。

二是完善工作体系，有效提升乡村文化遗产保护水平。6819个具有重要保护价值的村落被列入中国传统村落名录，3750个中国传统村落编制保护发展规划，国务院设立21个国家级文化生态保护试验区，实施270个全国重点文物保护单位和省级文物保护单位集中成片传统村落保护工程和近现代代表性建筑保护展示提升工程，认定91项重要农业文化遗产，由传统村落名录保护、乡村地区文物保护和非物质文化遗产保护、农业遗产保护等构成的乡村文化遗产保护工作体系逐渐建立健全。

三是助力乡村发展，更多惠及乡村居民生产生活。落实中央财政补助政策，按照中国传统村落每村300万元的标准，累计支持3750个中国传统村落保护发展，传统村落的基础设施条件、公共环境卫生有了较大改观。国家文物局会同财政部推动传统村落文物保护与延续使用功能、改善居住条件相统一，近五年中央财政累计投入12亿元。各地、各部门拓展传统村落休闲旅游、民宿等发展模式，增加地方收入、扩大居民就业、推动美丽乡村发展。

四是加强价值挖掘阐释，扩大乡村文化遗产影响力。积极推介、有效展示、广泛传播乡村文化遗产价值，建设中国传统村落数字博物馆，165个典型传统村落入馆；中宣部、住房和城乡建设部等联合发起拍摄5季《记住乡愁》纪录片，展现乡村风貌和生存状态，传播乡村文化和乡村精神；国家文物局指导开展乡村遗产酒店示范项目推介活动，支持开展“拯救老屋行动”，遴选推介优秀乡村题材展览，推进流动博物馆展览进乡村，让传统村落焕发生机，让乡村文明展现活力。

正如建议所提，当前美丽乡村建设中的文化遗产保护存在过度开发、拆真建假等问题。对于您提出的改进建议，国家文物局会同文化和旅游部、住房和城乡建设部、农业农村部认真研究、积极采纳，并将在下一步工作中扎实推进。

一、强化法治建设，夯实保护基础。加快修订《文物保护法》，将加强乡村文化遗产保护相关内容纳入修订范围；推动落实《文物保护法》《非物质文化遗产保护法》《历史文化名城名镇名村保护条例》等相关法律法规，明确主体责任，加强督察监管，对乡村文化遗产保护不力、不当的行为依法予以惩处。指导各地摸清具体情况、找准存在问题，出台地方性法规，上下联动，形成合力，共同完善乡村文化遗产法治保障体系。

二、部门协同推进，细化保护措施。因地制宜、因势利导，对传统村落保护提出分区分类保护原则，加强对传统村落、民居的建筑解析和建造技术研究，科学有效提升传统村落保护整体水平。加强农业遗产创造性转化、创新性发展，研究提出重要农业文化遗产传承发展指导意见。做好乡村文化遗产征藏与展示教育，推动将体现农耕文化、乡村经济社会变迁物证纳入博物馆重点征集范围，依托美丽乡村建设生态博物馆、户外博物馆，引导开展农村学生博物馆研学实践。完善国家级文化生态保护区建设管理机制，支持做好展示、教育等工作，助力文化遗产保护与美丽乡村建设。

三、加强宣传引导，优化保护环境。利用文化和自然遗产日等重要宣传活动节点，运用电视、网络等媒体融合渠道，总结各地乡村文化遗产保护利用优秀案例，传播保护理念，推广典型经验。加大教育培训力度，针对传统村落和传统建筑保护、文物保护等开展培训，提升各地乡村文物遗产保护管理水平。

感谢您对文化遗产保护工作的关心和支持。

国家文物局

2019年7月9日
