# 司法部关于发布实施《社区矫正电子定位腕带技术规范》等3项行业标准的公告

为规范全国司法行政信息化建设，加强对全国司法行政信息化工作的指导，司法部制定了《社区矫正术语（SF/T 0055-2019）》《社区矫正电子定位腕带技术规范（SF/T 0056-2019）》《智慧矫正移动应用技术规范（SF/T 0057-2019）》等3项标准。现予以发布，自发布之日起实施。标准实施中的问题和建议，请及时报司法部。

附件：社区矫正术语

社区矫正电子定位腕带技术规范

智慧矫正移动应用技术规范
