# 国家文物局关于长城保护区划内陕北风电定靖-榆横750千伏线路工程（衡山段）建设项目的意见

文物保函〔2019〕200号

陕西省文物局：

你局《关于陕北风电定靖-榆横750千伏线路工程（衡山段）跨越长城遗址的请示》（陕文物字〔2018〕208号）收悉。经研究，我局原则同意在榆林市横山区程家沟村一刘家洼村秦长城（长城编码： 610823382301020017）、杨窑则村明长城2段（长城编码：610823382101170030）、边墙梁村明长城（长城编号610823382101170031）保护范围和建设控制地带内实施陕北风电定靖-榆横750千伏线路工程（衡山段）建设项目。

一、上述方案尚需作以下必要的修改和完善：

（一）应在地形图上明确标示拟建项目与所涉长城保护范围和建设控制地带的位置关系。拟建项目选址应妥善避让考古调查勘探发现的重要遗址、遗迹。

（二）应明确拟建线塔建筑形式，在满足功能需求的前提下，合理控制线塔体量，弱化外观设计，确保线塔与长城及其周边环境相协调。

（三）应完善施工方案，严格控制施工振动和人员活动对长城本体及其周边环境造成的扰动，补充相关监测措施和应急预案。

（四）应补充施工期间长城本体临时性防护措施、竣工后的环境修复措施以及极端天气条件下防止输电线路威胁长城安全的保护措施及应急预案。

（五）应补充相关设计，结合工程实施在长城周边设立保护标志、保护界桩和警示标识。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月25日
