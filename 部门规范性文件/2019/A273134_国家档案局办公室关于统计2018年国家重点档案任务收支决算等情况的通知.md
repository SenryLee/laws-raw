# 国家档案局办公室关于统计2018年国家重点档案任务收支决算等情况的通知

各省、自治区、直辖市档案局、馆，有关计划单列市档案局、馆：

为全面了解、准确把握2018年国家重点档案任务预算执行情况及有关财务状况，有序开展任务绩效自评，需统计2018年国家重点档案任务收支决算等情况，现将有关事项通知如下。

一、统计内容

请各局、馆按要求填报《2018年国家重点档案任务收入支出决算表》（附件1）、《2018年国家重点档案任务固定资产情况表》（附件2）、《2018年国家重点档案任务支出绩效自评表》（附件3）和《2017年国家重点档案任务2018年期间收入支出决算表》（附件4）。附件的电子版可在国家档案局官方网站（网址www.saac.gov.cn）“通知公告”中查看并下载。

二、填报要求

请省级档案局和有关计划单列市档案局、馆财务部门牵头负责此项工作，相关业务处室配合，确保填报数据真实准确完整。省级档案馆本馆的数据直接报送国家档案局。附件1和附件2的统计范围为2018年当年批复各任务单位的资金，附件4的统计范围为2017年当年批复及2017年年末追加的资金，请严格区分不同年度的资金。各任务单位应提供附件1、附件2相关各项支出对应的会计凭证及其附件的电子扫描件。

附件4涉及国家档案局冲销2017年国家重点档案专项资金的“预付账款”，请各任务单位务必按附件4的要求，填报国家档案局批复的2017年国家重点档案专项资金在2018年当年发生的各项支出，同时提供与支出相关的会计凭证及其附件的电子扫描件和支出明细账电子表格（导不出电子表格的，应提供清晰图片）；图片数据应当进行适当整理，按“会计凭证号－图片序号”命名；2018年支出的2017年批复的资金数额加上2018年退回国家档案局的资金数额，应与《2017年国家重点档案任务收入支出决算表》中的“结转”数额一致，不一致的，要更正并作出说明。

三、报送时间

1.请于1月16日前将附件1、附件2和附件4电子版发送至邮箱，1月21日前将纸质版（加盖单位公章）报送国家档案局行财司计财处。

2.请于1月21日前将附件3电子版发送至邮箱，纸质版（加盖单位公章）报送国家档案局行财司计财处。
