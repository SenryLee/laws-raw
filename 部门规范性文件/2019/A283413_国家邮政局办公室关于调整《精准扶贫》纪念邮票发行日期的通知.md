# 国家邮政局办公室关于调整《精准扶贫》纪念邮票发行日期的通知

国邮办函〔2019〕317号

中国邮政集团公司办公厅；

经研究，我局决定对2019年纪特邮票发行计划中《精准扶贫》纪念邮票的发行日期进行调整，由原定的2019年11月3日调整为2019年11月29日。

请你公司据此抓紧做好相关工作。

国家邮政局办公室

2019年10月29日
