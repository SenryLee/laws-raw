# 国家煤矿安全监察局关于全国煤矿安全培训整治和专项监察发现问题的通报

各产煤省、自治区、直辖市煤矿安全培训主管部门，各省级煤矿安全监察局，有关中央企业：

按照《国家煤矿安监局关于开展煤矿安全培训整治推进煤矿从业人员素质提升的通知》（煤安监行管〔2018〕6号）和《国家煤矿安全监察局关于印发2018年“一通三防”等5个专项监察方案的通知》（煤安监监察〔2018〕3号）要求，各地煤矿安全培训主管部门和驻地煤矿安全监察机构对煤矿安全培训工作进行了监督检查，国家煤矿安监局组织开展了培训督查。现将有关情况通报如下：

一、基本情况

2018年，全国煤矿安全培训整治和专项监察共检查煤矿3873处、煤矿上一级公司133个、培训机构538个，抽考煤矿矿长、安全生产管理人员14326人、其他从业人员11497人，查处安全培训违法违规行为147022条，责令停产整顿煤矿14处，责令停业整顿的培训机构18个，行政罚款2394万元，调整岗位的矿长181人、安全生产管理人员702人。

二、存在的突出问题

（一）部分煤矿培训整治图形式、走过场，不落实问题突出。部分煤矿企业主要负责人对培训整治工作重视不够，对国家煤矿安监局工作部署落实不力，反映出一些煤矿企业领导形仿宋楷体式主义、官僚主义作风严重。一是有的煤矿培训整治工作不安排、不部署。如国家能源集团新疆能源公司昌吉屯宝煤矿，山西省晋能集团炭窑峪煤业公司，四川川煤集团石洞沟煤业公司、旺苍白水兴旺煤业公司、广元市市中区从容煤矿，云南小龙潭矿务局布沼坝露天煤矿，江西煤业集团安源煤矿，山东兖矿集团新疆矿业公司硫磺沟煤矿主要负责人未对煤矿安全培训整治工作作出安排，敷衍了事。二是有的煤矿将培训整治文件“一批了之”。如内蒙古伊金霍洛旗石场湾煤矿、伊泰煤炭公司宏景一矿，贵州黔西能源开发公司青龙煤矿、林华矿业公司，云南宣威市宝山镇宝达煤矿，陕西冯家塔矿业有限公司，新疆四棵树煤炭公司七号平硐的主要负责人及分管副矿长层层转批文件，对整治工作内容、要求不清楚、不了解；三是有的煤矿培训整治工作走过场。国家能源集团新疆能源公司碱沟煤矿，山西西山煤电股份公司西曲矿、榆次北山煤业公司，陕西煤化集团铜川矿业公司玉华煤矿、延长石油集团衡山魏墙煤业公司，贵州盘江精煤股份公司月亮田煤矿，新疆伊梨新矿煤业公司培训整治工作只做简单安排，但无工作方案、无责任分工、无自查自改记录，整治工作无实质效果；江西省国营萍乡市鸡冠山垦殖场煤矿、内蒙古鄂尔多斯永煤矿业公司马泰壕煤矿自查自改情况统计和自查记录造假。

（二）部分煤矿领导能力不足、部分人员无证上岗问题突出。一是部分煤矿领导安全生产知识和管理能力不足。有的煤矿矿长和副矿长不具备安全生产知识和管理能力，2018年，吉林省蛟河市三井煤矿公司胡启岩等28名矿长、副矿长因安全生仿宋产知识和管理能力考核不合格被调离岗位（名单见附件1），江西省横峰县铺前煤矿二井刘金明等21名矿长、副矿长因不符合准入条件被调离岗位（名单见附件2）；有的煤矿矿长、副矿长不能持续保持相应水平和能力，培训整治检查和专项监察对6575名矿长、副矿长了进行随机抽考发现，共有435名矿长、副矿长抽考不合格、占抽考总数的7%，其中47名矿长、副矿长被责令调离岗位（名单见附件3）。国家能源集团新疆能源公司碱沟煤矿4名矿领导有3人抽考不合格，山西榆次北山煤业公司5名矿领导中矿长、总工程师及2名副总工程师4人抽考不合格，平均仅53.5分。二是有的矿长和安全生产管理人员未按规定参加安全知识和能力考核。《煤矿安全培训规定》要求“煤矿企业主要负责人和安全生产管理人员应当自任职之日起六个月内通过考核部门组织的安全生产知识和管理能力考核”，检查发现，748名矿长和安全生产管理人员上岗后，未在6个月内参加安全生产知识和管理能力考核，违规上岗。如山西西山煤电股份公司西曲矿122名安全生产管理人员，未经安全生产知识和管理能力考核上岗；山西凯嘉能源集团义棠煤业公司采煤副总工程师等7名安全生产管理人员考核合格证到期未按要求换证，继续从事本岗位工作。三是有的特种作业人员无证上岗。国家能源集团神东煤炭公司锦界煤矿、包头能源公司万利一矿，中国华能集团华亭煤业新柏煤矿公司、马蹄沟煤矿，河北省冀中能源公司大社矿、新三矿、陶二矿，河北省开滦集团单侯矿，山西煤炭运销集团保安煤业公司、孟县恒泰皇后煤业公司，黑龙江省龙煤集团城山煤矿、正阳煤矿，江西省煤业集团安源煤仿宋楷体矿，山东省新汶集团孙村煤矿等154处煤矿（名单见附件4）、726名特种作业人员无证上岗。四是部分煤矿从业人员未培训合格上岗作业。国家能源集团内蒙古大雁矿业扎尼河露天矿、安徽省淮南矿业集团潘集第二煤矿、山东泰丰集团王家寨煤矿、甘肃崇信百贯沟煤矿公司等58个煤矿从业人员未经培训合格上岗（名单见附件5）。

（三）培训造假等违规行为仍然存在。一是有的煤矿企业安全培训档案造假。检查发现，国家能源集团神东煤炭公司锦界煤矿，河北省开滦集团唐山矿业分公司，冀中能源邯郸陶二矿、郭二庄矿，吉林通化矿业集团道清矿，黑龙江省龙煤集团新建煤矿、新铁煤矿，河南郑兴永祥煤业公司，江西丰城曲江煤炭开发公司，重庆中源煤业集团笔山煤矿，陕西煤业化工集团铜川矿业公司玉华煤矿等144处煤矿安全培训档案造假。如内蒙古伊金霍洛旗石场湾煤矿2018年7月26日进行脱产培训，培训当天有106人下井作业，但培训档案显示全矿职工参加培训；贵州林华矿业公司2018年3月22日～30日进行脱产培训，但档案中记载103名参加培训人员都在井下作业。二是有的煤矿企业从业人员学历造假。国家能源集团神东煤炭公司锦界煤矿部分从业人员高中毕业证造假；陕西榆神煤电榆树湾煤矿部分从业人员初中、高中毕业证造假；新疆昌吉市菏泽腾达矿业公司部分本科函授文凭、高中毕业证、初中毕业证造假。三是有的煤矿企业和培训机构违规培训。国家能源集团哈尔乌素分公司哈尔乌素露天煤矿，山西汾西矿业集团水峪公司，黑龙江省龙煤集团双阳煤矿、杏花煤矿，山东能源临矿集团鲁西煤矿，陕西煤化工集团黄陵矿业公司一号煤矿，青海省能源发展集团鱼仿宋楷体卡公司等34处煤矿从业人员未脱产再培训（名单见附件6）。内蒙古伊泰煤炭股份有限公司宏景一矿新招聘135名特种作业人员，于2018年3月19日—27日委托鄂尔多斯市煤炭技工学校到矿培训，培训学时只有72学时，未达到90学时的规定要求；四川广元工程技术学校举办的煤矿井下监测监控特种作业人员培训班中，有3人仅参训3天。四是有的煤矿企业考试流于形式。山西梗阳实业集团麦地掌煤矿乱打分，一名从业人员问答题扣40分，总分仍得89分；山西汾西矿业集团水峪公司乱判卷，两人答案相同，分数却不同；山西凯嘉能源集团义棠煤业公司没有组织判卷，却有考试成绩；四川川煤集团石洞沟煤业公司组织了《煤矿安全培训规定》培训考试，但考试内容与从业人员应掌握的知识不相关。

（四）安全培训方法陈旧、条件落后问题突出。检查发现，部分煤矿安全培训师资力量薄弱，培训内容缺乏针对性，培训基础设施陈旧老化，只满足“形式有”，不求“效果实”，培训质量远不能适应新时代煤矿安全工作需要。一是培训方法单一。多数煤矿企业仍然采用传统教学方法，老师教学照本宣科，职工学习缺少兴趣，没有充分运用互联网技术，没有调动职工自觉学习的积极性，培训学习的效果不好。二是培训内容陈旧。陕西延安职业技术学院技术技能培训中心培训教案仍然使用不再适用的法律法规；贵州黔西南州普安县恒泰煤矿、丰联矿业公司安福煤矿各专业均使用同一培训内容，缺少针对性，没有实用性。三是培训教师不合格。国家能源集团哈尔乌素分公司哈尔乌素露天煤矿、新疆阿克苏地区煤矿安全技术服务中心、贵州盘江精煤公司安全培训中心等，部分教师缺乏实践工作经仿宋楷体验，任职条件不符合《安全培训机构基本条件》要求。四是实操培训差距较大。黑龙江省龙煤集团七台河公司新建煤矿安全培训中心、鸡西矿业公司安全技术培训中心，山西西山煤电公司教育中心部分实操教师对实操教学流程、操作标准不熟悉、不掌握；贵州盘江精煤股份公司月亮田矿培训中心多数实操设备不能正常使用，四川广元市矿山安全培训中心（川北煤矿安全培训中心）、云南宣威市煤矿安全技术培训中心未配备实操设备。

（五）有些部门推动工作不力问题突出。一是工作推动缓慢。煤矿特种作业实操考核标准2016年下发，内蒙古煤炭工业局对部分内容到2018年下半年才贯彻执行，其设立的内蒙古安全技术培训中心考试点纪律形同虚设，监考不认真、不负责，考生随意走动、交头接耳、打电话、手机拍照等一直未整改；四川省安监局至今未按要求建成一家达到国家标准的实操考试点，且设立的广元工程技工学校考试点无任何煤矿瓦斯抽采作业实操考试设备，人为编造实操考试成绩。二是考核发证把关不严。内蒙古、江西、山东、广西、重庆、贵州、甘肃、青海、新疆、新疆兵团等培训主管部门均存在为不符合准入条件的三项岗位人员发证问题。三是监督检查不到位。吉林省安监局专项整治仅查处1条违法违规行为；安徽、广西煤矿安监局专项监察查出问题为0；辽宁省煤矿安全监管局、黑龙江省煤炭生产安全管理局、安徽省经信委、山东省煤炭工业局、湖南省安监局、甘肃省安监局等6省安全培训主管部门未进行行政处罚，福建、广西煤矿安监局安全培训专项监察行政处罚为0。四是抽仿宋考力度不够。山东省煤炭工业局、湖南省安监局监督检查时未进行抽考；黑龙江省煤炭生产安全管理局安全生产管理人员抽考人数为0，辽宁煤矿安监局仅抽考矿长、副矿长4人；新疆煤矿安监局监督检查仅抽考6人。

煤矿企业要对照检查发现的问题，结合自身实际，举一反三，进行整改，要强化对培训工作的组织领导，努力提升全员素质。各省煤矿安全培训主管部门要严格监督管理，加大安全培训违法违规行为处罚力度，要建立抽查抽考制度，坚持“逢查必考”“逢查必问”，对培训造假、无证上岗、培训整治工作一批了之，未按要求进行脱产再培训的煤矿，要组织煤矿企业主要负责人和安全生产管理人员进行集中抽考，并强化抽考结果应用，通过约谈、督办、通报、公开曝光等手段，形成有力震慑，坚决杜绝安全培训违法违规行为，促进煤矿安全生产形势进一步稳定好转。

请各省级煤矿安全培训主管部门将本通报精神传达至辖区内所有煤矿企业、煤矿安全培训机构及考试机构。
