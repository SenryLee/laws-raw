# 中华人民共和国海关总署对十三届全国人大二次会议第8187号建议的答复

刘远代表：

您在十三届全国人大二次会议上提出的《关于设立漳州古雷港综合保税区的建议》（流通、旅游和服务类第8187号）收悉。经认真研究，现答复如下：

我署一直重视和支持福建省开放型经济发展，积极支持福建省利用综合保税区作为推动对外开放和自贸试验区发展的重要抓手。截至目前，我署已支持福建省设立了厦门海沧保税港区、福建泉州综合保税区等7个海关特殊监管区域。

2015年2月，国务院办公厅将福建省人民政府关于设立漳州古雷综合保税区的请示文件转我署商有关部门研究办理。我署原则支持设立漳州古雷综合保税区，建议福建省人民政府按照《综合保税区审核设立指导意见》，对设立漳州古雷综合保税区做好规划，切实加大招商力度，以大项目落地作为申报设立区域的基础，条件成熟时我署将会同相关部门予以积极支持。

2019年1月，国务院印发了《关于促进综合保税区高水平开放高质量发展的若干意见》（国发〔2019〕3号），从完善政策、创新监管、拓展功能等方面提出21项促进综合保税区升级发展的改革任务和政策举措，并提出将综合保税区建设成为新时代全面深化改革开放的新高地。请福建省人民政府按照国务院文件要求，切实做好落实工作，高度重视现有综合保税区的建设和发展，进一步提升发展质量，在开放型经济中发挥更大作用。

感谢您对海关工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2019年7月2日
