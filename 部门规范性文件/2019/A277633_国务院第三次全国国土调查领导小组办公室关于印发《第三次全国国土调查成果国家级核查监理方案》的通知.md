# 国务院第三次全国国土调查领导小组办公室关于印发《第三次全国国土调查成果国家级核查监理方案》的通知

国土调查办发〔2019〕14号

各国家级核查任务承担单位：

根据《第三次全国国土调查实施方案》（国土调查办发〔2018〕18号）和《第三次全国国土调查成果国家级核查方案》（国土调查办发〔2019〕4号），国务院第三次全国国土调查领导小组办公室制定了《第三次全国国土调查成果国家级核查监理方案》，现予以印发，请在具体工作中遵照执行。

国务院第三次全国国土调查领导小组办公室

2019年5月23日
