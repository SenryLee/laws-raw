# 司法部关于发布实施《行政执法综合管理监督信息系统数据元和代码集》等4项行业标准的公告

本法规中关于《行政执法综合管理监督信息系统数据元和代码集（SF/T 0052-2019）》的相关规定已被《司法部关于发布实施<行政执法综合管理监督信息系统数据元和代码集>等5项行业标准的公告》自2023年11月16日起修改。

## 司法部关于发布实施《行政执法综合管理监督信息系统数据元和代码集》等4项行业标准的公告

为规范全国司法行政信息化建设，加强对全国司法行政信息化工作的指导，司法部制定了《行政执法综合管理监督信息系统数据元和代码集（SF/T 0052-2019）》《远程视频会见帮教平台技术规范（SF/T 0053-2019）》及修订了《监狱罪犯基础数据元和代码集（SF/T 0054-2019代替SF 03001-2012）》《全国人民调解管理信息系统技术规范（SF/T 0018-2019代替SF/T 0018-2017）》等4项标准。现予以发布，自2019年8月28日起实施。标准实施中的问题和建议，请及时报司法部。

司法部

2019年8月28日
