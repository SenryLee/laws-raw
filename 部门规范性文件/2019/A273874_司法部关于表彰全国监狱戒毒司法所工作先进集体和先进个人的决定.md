# 司法部关于表彰全国监狱戒毒司法所工作先进集体和先进个人的决定

各省、自治区、直辖市司法厅（局），新疆生产建设兵团司法局、监狱管理局：

近年来，全国司法行政机关和广大司法行政干警坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻党的十九大和十九届二中、三中全会精神，认真贯彻落实习近平总书记全面依法治国新理念新思想新战略和党中央各项决策部署，坚持以人民为中心的发展思想，紧紧围绕党和国家工作大局，忠诚履行党和人民赋予的职责，为维护社会和谐稳定、促进社会公平正义、服务经济社会发展、保障人民安居乐业作出了积极贡献，涌现出一大批先进集体、先进个人。

为表彰先进，激励全国司法行政机关和广大司法行政干警不忘初心、牢记使命，提振精神、奋发进取，司法部决定，表彰北京市女子监狱等80个集体为“全国监狱工作先进集体”、北京市监狱管理局清河分局柳林监狱监狱长姚洪学等1095名同志为“全国监狱工作先进个人”；表彰北京市戒毒管理局沐林教育矫治所等40个集体为“全国戒毒工作先进集体”、北京市天堂河强制隔离戒毒所副所长马振军等230名同志为“全国戒毒工作先进个人”；表彰北京市东城区司法局北新桥司法所等230个司法所为“全国模范司法所”、北京市丰台区司法局花乡司法所等430个司法所为“全国先进司法所”、北京市东城区司法局天坛司法所所长罗胤等659名同志为“全国模范司法所长”。希望受到表彰的集体和个人珍惜荣誉，再接再厉，为推动新时代司法行政事业改革发展再立新功！

全国司法行政机关和广大司法行政干警要向受到表彰的先进集体和先进个人学习，坚持以习近平新时代中国特色社会主义思想为指导，树牢“四个意识”，坚定“四个自信”，坚决做到“两个维护”，深入贯彻落实习近平总书记在中央政法工作会议上的重要讲话和会议精神，按照全国司法厅（局）长会议要求，坚持政治引领、党建先行，紧紧围绕“一个统筹、四项职能”，锐意进取，扎实工作，奋力推进新时代司法行政事业改革发展，为决胜全面建成小康社会、夺取新时代中国特色社会主义伟大胜利，实现“两个一百年”奋斗目标和中华民族伟大复兴的中国梦作出新的贡献。
