# 农业农村部关于十三届全国人大第二次会议第2152号建议答复摘要

## 十三届全国人大第二次会议第2152号建议答复摘要

农办议〔2019〕524号

一、关于形成农民教育培训合力

教育培训是提升农民综合素质和生产技能的重要途径，国家高度重视农民教育培训工作，多举措促进农民素质能力提升。

我部联合财政部组织实施农民培育工程，中央财政累计安排资金90.9亿元支持农民教育培训工作，围绕产业发展需求和农民学习特点，改进内容、创新方式、强化服务，培养造就高素质农民队伍。联合教育部印发通知做好高职扩招培养高素质农民有关工作，实施“百万高素质农民学历提升行动计划”，培养接受学历职业教育、具备市场开拓意识、能推动农业农村发展、带领农民增收致富的高素质农民。人力资源社会保障部会同我部、国务院扶贫办、共青团中央和全国妇联组织实施农民工等人员返乡创业培训五年行动计划（2016—2020年），指导各地进一步推进农民工、建档立卡贫困人口、大学生和退役军人等人员返乡创业培训工作。同时，推动县级层面成立多部门协作的工作领导小组，细化目标任务、工作措施和资金使用；持续开展农民教育培训绩效考核，并纳入各地粮食安全省长责任制考核内容，考核结果与资金任务分配挂钩，促进教育培训质量提升。

下一步，我部将继续抓好农民教育培训组织实施，汇聚多部门合力，共同办好农民满意的教育培训。

二、关于加强政策整合支持力度

我部注重加强参训农民的跟踪服务，引导各地整合资源，积极创造有利于农民成长发展的政策环境。

一是整合政策资源。中央财政鼓励各地利用现有资金渠道，强化政策衔接配合，将支持农民教育培训、农民合作社及家庭农场发展等培育壮大新型农业经营主体政策统筹实施，支持强农惠农富农政策向参训农民倾斜，形成政策集聚效应，提高资金使用效益。二是推动乡村创新创业政策落实。印发了《农业农村部关于大力实施乡村就业创业促进行动的通知》，部署培育主体、打造园区、发展特色产业、推动产业融合等重点任务，督促各地落实返乡下乡人员创新创业政策；扎实组织开展农民创新创业培训，十八大以来，我部共组织创业富民主题培训、农业农村电子商务专题培训等培训500余班次，培训各类返乡下乡创业人员50000余人次，在全国组织遴选了1000名农村创业创新带头人并重点宣传推介了200名优秀带头人；搭建公共服务平台，我部公布了涵盖1096家各具区域特色的农村创业创新园区（基地）目录，其中有7家国家创业创新示范基地。三是支持农业科研院所开展农技推广工作。加快科技成果转化落地，鼓励农业科研教学人员以兼职、合作、交流等多种形式开展农技推广服务。

下一步，我部将继续会同有关部门梳理各类强农惠农富农政策，进一步加大农民教育培训扶持力度，不断提升务农兴业含金量，让农民真正成为有吸引力的职业。

三、关于加大金融扶持力度

我部联合有关部门共同加大金融扶持力度，促进农民全面发展，分别与中国中信集团、中国建设银行等单位签署了金融服务乡村振兴战略合作协议，进一步提高农村金融服务水平，支持新型农业经营主体和农民发展。银保监会今年印发了《关于做好2019年银行业保险业服务乡村振兴和助力脱贫攻坚工作的通知》，明确提出要做好各类现代农业主体金融服务。在产品创新方面，积极发展产业链金融，研发额度小、频度高、季节时限性较强、适合新型农业经营主体的特色贷款产品，探索农业保险保单质押贷款、农户信用保证保险贷款等银保合作产品。在服务方式创新方面，运用互联网、物联网、大数据、人工智能等技术，与农业企业、农产品交易平台系统对接，探索全流程在线操作的网络融资服务。

关于由龙头企业为家庭农场、农民专业合作社提供贷款担保，由于融资担保业务的金融属性，按照《融资担保公司监督管理条例》的要求，龙头企业的担保行为需要甄别，龙头企业不能开展具有“经营”性质的融资担保行为，确有需要的可以成立融资担保公司，向监督管理部门申领许可牌照后开展融资担保业务。

关于采用多种抵质押形式解决有关主体融资难问题，2016年以来，财政部会同有关部门大力推进全国农业信贷担保体系建设，成立国家农业信贷担保联盟有限责任公司，逐步向省市县延伸分支机构，开展实质性运营，服务对象聚焦农民合作社、家庭农场等农业适度规模经营主体。全国农业信贷担保体系建立以来，累计新增担保项目32万个，新增担保额1144.2亿元，通过为农业贷款提供信用担保和风险补偿，有效克服农业贷款无抵押、成本高、风险大等问题。我部与国家农业信贷担保联盟有限责任公司联合印发通知，积极构建金融支持政策体系，为农民提供专业化、精细化的融资担保服务。

关于扩大政策性农业保险覆盖范围，进一步降低保险理赔门槛，2018年，银保监会会同财政部将三大主粮作物制种纳入中央财政保费补贴目录，农业保险覆盖面进一步拓宽。对于农业保险的理赔，明确各保险公司要做好农业保险理赔工作。对农业保险估损理赔信息密切跟踪进展，对进展缓慢的公司实施窗口指导或监管质询，对于虚假理赔、平均赔付等违规行为，以及惜赔、拖赔等侵害农民利益行为，依法查处，严肃处理。

下一步，我部将联合有关部门继续引导金融机构加大金融产品方式创新力度，进一步做好农业保险承保理赔的监管工作，切实保护好农民利益，促进各类新型农业经营主体发展壮大。

农业农村部
