# 国家卫生健康委办公厅关于印发全国医院数据上报管理方案（试行）的通知

国卫办规划函〔2019〕380号

各省、自治区、直辖市及新疆生产建设兵团卫生健康委，委机关各司局，委直属和联系单位：

为加强和规范全国医院数据报送管理，保证上报全民健康信息平台的数据及时、完整、准确，我委制定了《全国医院数据上报管理方案（试行）》，具体包括医疗业务、运营业务、接口技术规范、医疗数据字典、运营数据字典等五项内容（可从国家卫生健康委网站下载）。现印发给你们，请遵照执行。

联系人：规划司 郑晓渊、沈剑峰

联系电话：010—68791492、68791911

附件：1.全国医院数据上报管理方案-医疗业务（试行）

2.全国医院数据上报管理方案-运营业务（试行）

3.全国医院数据上报管理方案-接口技术规范（试行）

4.全国医院数据上报管理方案-医疗数据字典（试行）

5.全国医院数据上报管理方案-运营数据字典（试行）

国家卫生健康委办公厅

2019年4月19日
