# 农业农村部关于政协十三届全国委员会第二次会议第2182号（农业水利类209号）、B108提案答复摘要

## 政协十三届全国委员会第二次会议第2182号（农业水利类209号）、B108提案答复摘要

农办案〔2019〕196号

李惠东、李生龙委员：

关于"三治融合"乡村治理体系建设的提案和关于促进"三治"融合健全乡村治理体系的提案收悉。经商民政部、司法部、中央宣传部、中央组织部，现答复如下。

实现乡村有效治理是乡村振兴的重要内容。习近平总书记强调，要加强和创新乡村治理，建立健全党委领导、政府负责、社会协同、公众参与、法治保障的现代乡村社会治理体制，健全自治、法治、德治相结合的乡村治理体系，让农村社会既充满活力又和谐有序。2019年，中共中央办公厅、国务院办公厅印发了《关于加强和改进乡村治理的指导意见》（以下简称《指导意见》），明确了加强和改进乡村治理的指导思想和总体目标，提出十七项主要任务和四项保障要求。中央农办、农业农村部、中央组织部、中央宣传部、民政部、司法部联合召开全国加强乡村治理体系建设工作会议，全面部署乡村治理体系建设工作。中央农办、农业农村部推介了首批20个全国乡村治理典型案例，深入挖掘各地提升乡村治理能力和水平的实践经验。中央农办、农业农村部会同中央组织部、中央宣传部、民政部、司法部联合印发了《关于开展乡村治理体系建设试点示范工作的通知》和《关于开展乡村治理示范村镇创建活动的通知》，在县级层面开展为期三年的试点示范工作，探索自治、法治、德治相结合的乡村治理路径方法；在村和乡镇层面开展示范创建工作，引领全国乡村治理体系建设。

一、关于加强基层党建

《指导意见》明确提出完善党组织领导乡村治理的体制机制，发挥党员在乡村治理中的先锋模范作用。2018年，中共中央修订印发的《中国共产党农村基层组织工作条例》，专门就"乡村治理"增写一章，明确了党组织领导乡村治理的目标、机制、任务等。中央组织部认真抓好加强村党组织对各类组织的统一领导工作，推行村党组织书记通过法定程序担任村委会主任，健全村"两委"成员候选人资格联审机制，选优配强第一书记。

二、关于健全村民自治

《指导意见》明确提出要增强村民自治组织能力，丰富村民议事协商形式，全面实施村级事务阳光工程等。民政部每年联合有关部门召开村"两委"换届工作座谈会，指导各地进一步明确和规范村委会选举的各项程序要求。2018年12月，民政部、中央组织部、农业农村部等7部门联合印发了《关于做好村规民约和居民公约工作的指导意见》，明确村规民约的主要内容和制定程序，提出要健全完善奖惩机制，针对违反情形，一般应提出相应惩戒措施。

三、关于深化法治保障

《指导意见》明确提出要推进法治乡村建设、健全乡村矛盾纠纷调处化解机制、加强农村法律服务供给等。司法部会同民政部开展民主法治示范村创建活动，先后表彰了7批共3365个全国民主法治示范村。各地积极引导社会组织参与人民调解工作，指导社会组织成立人民调解委员会，利用社会力量开展矛盾纠纷化解工作。中央文明办着眼提高法治意识，开展法治教育，增强涉农部门和农村基层干部的法治思维和方式，培养广大农民群众学法尊法守法用法意识，通过合法途径维权。

四、关于强化德治支撑

《指导意见》明确提出积极培育和践行社会主义核心价值观，实施乡风文明培育行动，发挥道德模范引领作用，加强农村文化引领等。中央文明办组织开展党员联系农户、党员户挂牌、承诺践诺、志愿服务等活动。同时，在农村大力开展文明村镇、星级文明户、文明家庭等创建活动，广泛开展农村道德模范、最美邻里、身边好人、好媳妇好婆婆等选树活动。

感谢你们对"三农"工作的关心，希望继续对我部工作予以支持。

农业农村部

2019年9月6日
