# 农业农村部对十三届全国人大二次会议第2463号建议的答复

## 对十三届全国人大二次会议第2463号建议的答复

农办议〔2019〕140号

您提出的关于取消“中国学生饮用奶”标志认证的建议收悉。经研究，现答复如下。

为推动我国乳品消费和奶业发展，提高青少年营养健康水平，2000年8月29日，农业部、国家发展计划委员会、教育部、财政部、卫生部、国家质量技术监督局、国家轻工业局等7部委局联合启动实施了国家学生饮用奶计划。2013年9月5日，农业部等七部门联合发出《关于调整学生饮用奶计划推广工作方式的通知》，将学生饮用奶计划推广工作整体移交给中国奶业协会。2018年6月，《国务院办公厅关于推进奶业振兴保障乳品质量安全的意见》（国办发〔2018〕43号）（以下简称《意见》）印发，明确提出：大力推广国家学生饮用奶计划，增加产品种类，保障质量安全，扩大覆盖范围。19年来，学生饮用奶从无到有，推广范围不断扩大，截至2018年底，学生饮用奶日均供应量1800万份以上，惠及中小学生2200万人，覆盖全国31个省、自治区、直辖市的6万所学校。学生饮用奶计划的推广是一项利国利民的公益性工作，目前世界上已有美国、日本和泰国等70多个国家实施了此类计划，并在政策和资金上给予大力支持。国家学生饮用奶计划的顺利实施，对改善和提高我国中小学生营养健康水平、促进乳品消费和奶业振兴都起到了积极作用。

为推动国家学生饮用奶计划在全国推广，由农业部、国家发展计划委员会、教育部、财政部、卫生部、国家质量技术监督局、国家轻工业局组成的国家学生饮用奶计划部际协调小组审定，农业部发布了“中国学生饮用奶”标志（现已移交给中国奶业协会），用以标识在学校推广的学生饮用奶安全、营养的专用标志。“中国学生饮用奶”标志依法在国家版权局登记，中国奶业协会是“中国学生饮用奶”标志的所有者，依法拥有标志的许可使用权。根据中国奶业协会《国家“学生饮用奶计划”推广管理办法》，“中国学生饮用奶”标志由乳品企业自愿申请使用，经中国奶业协会许可后免费使用。乳品企业向中国奶业协会申请使用“中国学生饮用奶”标志，需经政府主管部门生产许可、第三方质量管理体系认证、省级学生饮用奶工作机构推荐和中国奶业协会考核的综合评定，中国奶业协会对符合条件的企业实行注册，许可使用“中国学生饮用奶”标志，授予“中国学生饮用奶生产企业”证书、标牌。

一、关于学生饮用奶生产企业日处理生牛乳能力（两班）须达到200吨以上

根据《乳制品工业产业政策》要求，乳制品工业的行业准入条件中，除南方产业区要求新建液态乳项目日处理生鲜乳能力（两班）须达到200吨及以上外，其他各产业区均要求新建液态乳项目日处理生鲜乳能力（两班）达到500吨及以上。因此，学生饮用奶生产企业要求日处理生牛乳能力（两班）须达到200吨以上是基本准入条件，并非设置的较高门槛，符合国家对于乳制品工业发展要实现规模经济的政策要求。

二、关于学生饮用奶产品品类不包含巴氏杀菌乳

现阶段推广的学生饮用奶产品品类包括两类：以生牛乳为原料加工，不使用、不添加复原乳的超高温灭菌乳和以生牛乳为主要原料加工，不使用、不添加复原乳及营养强化剂的灭菌调制乳。考虑到保证巴氏杀菌乳等低温乳制品进校园的质量安全，需要完善的冷链物流保障和更高要求的校内操作规范，中国奶业协会正在对这些情况进行前期摸底调研。学生饮用奶计划根据学生营养改善需要和奶业发展阶段，将适时增加学生饮用奶产品种类。实施调整前需进行营养评价和风险评估，先行试点，稳妥推进，总结经验后制订规范，方可正式推广。

三、关于取消“中国学生饮用奶”标志认证

学生饮用奶是中小学生在校集体、集中饮用，其群体、场合的特殊性，不同于一般乳制品的消费。学生饮用奶生产企业是学生饮用奶的供应方，承担食品安全主体责任。因此，中国奶业协会承接国家学生饮用奶计划推广工作以来，遵循“安全第一、质量至上、严格准入、有序竞争、规范管理、稳妥推进”的原则，坚持把食品安全放在推广工作首位，对学生饮用奶生产企业的要求高于一般乳品企业。申请使用“中国学生饮用奶”标志的乳品企业，在必须具备《中华人民共和国食品安全法》《乳品质量安全监督管理条例》及相关法律法规和国家食品安全标准规定的生产场所、设施设备、设备布局、工艺流程、规章制度、技术管理人员和质量保证体系等基本条件的前提下，同时还在加工能力、质量管理、奶源基地、配送系统、管理制度等方面提出更高要求，从而保障学生饮用奶质量安全。为了给学生提供安全、营养的优质牛奶，中国奶业协会根据我国目前较高生产水平的规模奶牛场标准，对接奶业发达国家的先进标准，颁布了学生饮用奶系列团体标准，包括《学生饮用奶生牛乳》《学生饮用奶 纯牛奶》《学生饮用奶 灭菌调制乳》《学生饮用奶 中国学生饮用奶标志》，以及保障原料奶生产供应的《学生饮用奶 奶源基地管理规范》。根据中国奶业协会《国家“学生饮用奶计划”推广管理办法》，学生饮用奶奶源基地和学生饮用奶产品必须符合以上团体标准。这一系列标准是在执行国家标准的基础上，对接国际先进标准，提出的更高要求，有别于市场销售的一般乳制品。“中国学生饮用奶”标志的使用，有利于树立中国学生饮用奶品牌形象，打造学生饮用奶高标准、高品质和优质服务的品牌形象，促进国家学生饮用奶计划的推广实施。

感谢您对学生饮用奶工作的关注，希望今后继续对我部工作给予支持。
