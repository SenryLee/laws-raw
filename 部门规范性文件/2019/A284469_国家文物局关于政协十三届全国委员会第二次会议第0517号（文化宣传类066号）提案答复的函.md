# 国家文物局关于政协十三届全国委员会第二次会议第0517号（文化宣传类066号）提案答复的函

文物政函〔2019〕853号

周锋委员：

您提出的《关于加强文化遗产社会功能体系建设，完善文化遗产保护与活化利用相关政策法规的提案》收悉，现答复如下。

党的十九大报告指出，加强文物保护利用和文化遗产保护传承。2018年，中办、国办印发《关于加强文物保护利用改革的若干意见》，对统筹推进文物保护利用传承、走出一条符合国情的文物保护利用之路作出全面部署。

您在提案中提出，加强文化遗产社会功能体系建设与政策研究，建立文化遗产分级分类评估指标体系，特别是从点、线、面、体系等多个维度研究制定文化遗产分级分类保护利用导则，对于加强文物保护利用具有重要启发意义。近年来，国家文物局在不断加大文物保护力度的基础上，高度重视文物合理利用，推动让文物活起来。

在“点”的方面，国家文物局要求将文物合理利用作为全国重点文物保护单位保护规划一项重要内容，凡是开展保护修缮的都要同步考虑展示利用；在“线”的方面，将文化线路作为重要文化遗产类型加以保护利用，长城、大运河、丝绸之路、长征、茶马古道、万里茶道等一批文化线路遗产进入管理视野，成为文物保护利用热点，大运河、丝绸之路列入《世界遗产名录》，海上丝绸之路、万里茶道等项目申遗准备扎实推进，主要以文物资源为依托的长城、大运河、长征文化公园建设方案获中央批准；在“面”的方面，探索推进文物资源密集区、文物保护利用示范区、革命文物保护利用片区等，开展名录公布、规划编制、试点探索等工作，提高文物保护利用整体水平；在“体系”的方面，召开推进文物合理利用座谈会，开展探索符合国情的文物保护利用之路国家社科基金重大项目研究，印发《全国重点文物保护单位和省级文物保护单位集中成片传统村落乡土建筑保护利用导则（试行）》《文物建筑开放导则（试行）》等文件，完善顶层设计，推动形成全社会广泛共识。

下一步，国家文物局将从以下方面继续推动文物保护利用，不断完善相关政策法规。一是加强文物保护利用法制保障。在《中华人民共和国文物保护法》修订过程中，研究增加文物保护利用和文化遗产保护传承的内容，既增加鼓励社会各界参与文物合理利用的条款，也修改现行法律中不利于文物合理利用的条款。二是加大文物保护利用政策研究。深入开展调查研究，根据不同文物类别、属性和地域，通过开展课题研究等形式，加强文物保护利用政策研究，为顶层设计提供理论支撑，增强针对性和有效性。三是加快制定文物保护利用标准规范，探讨文物保护利用“一处一策”可行性，推动建设系统完备、科学规范、运行有效的文物保护利用标准体系。

感谢您对文物工作的关心与支持！

国家文物局

2019年8月20日
