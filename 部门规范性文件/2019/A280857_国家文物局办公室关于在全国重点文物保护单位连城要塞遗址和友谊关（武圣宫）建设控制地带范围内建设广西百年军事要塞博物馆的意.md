# 国家文物局办公室关于在全国重点文物保护单位连城要塞遗址和友谊关（武圣宫）建设控制地带范围内建设广西百年军事要塞博物馆的意见

办保函〔2019〕707号

广西壮族自治区文化和旅游厅：

你厅《关于请求在全国重点文物保护单位连城要塞遗址和友谊关（武圣宫）建设控制地带范围内建设广西百年军事要塞博物馆的请示》（桂文物报〔2019〕11号）收悉。经研究，我局暂不同意在全国重点文物保护单位连城要塞遗址和友谊关（武圣宫）建设控制地带内建设广西百年军事要塞博物馆。

一、对所报方案提出以下修改完善意见：

（一）应依据连城要塞遗址和友谊关保护规划，补充保护范围与建控地带图纸和相关分析内容，并结合文物的实际保护、展示利用需求，充分论证广西百年军事要塞博物馆建设的必要性和可行性，特别是在拟建位置选址的必要性和可行性。

（二）如经评估确需在现址建设博物馆，则应根据连城要塞遗址和友谊关实际的保护、展示利用需求，以及《广西百年军事要塞博物馆建设项目文物评估影响报告》提出的“控制调整建议”，科学确定博物馆的规模、体量、高度以及建筑形式，严格落实相关保护措施，尽量减少对文物本体、遗址及历史环境的影响。

三、请你厅指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年8月7日
