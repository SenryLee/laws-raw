# 中华人民共和国海关总署对十三届全国人大二次会议第1964号建议的答复

邓桂芳代表、翟京宋代表、覃建宁代表：

您提出的《关于调整国际贸易数据统计方式的建议》（发展规划、建设项目和综合经济类第1964号）收悉。针对您提出的关于分别按照“实际发生地”和“口岸通关数据”两种口径进行统计的建议，经研究，现答复如下：

一、 根据《中华人民共和国海关统计条例》，海关统计的任务是编制、管理和公布海关统计资料。海关发布的统计资料不作为考核外贸业绩的依据。

二、海关根据联合国推荐的国际货物贸易统计标准，制定海关统计制度，编制海关统计资料，供国家有关部门和社会各界使用。为全面反映我国各地对外贸易情况，发布的海关统计资料除按“进出口商品收发货人所在地”口径编制外，还包括“境内目的地／境内货源地”和“进出口海关关别”等口径编制的统计报表，并定期对全社会公开发布，可以满足您的建议要求。具体内容见《海关统计》月报表9“进出口商品境内目的地/货源地总值表”、月报表10“进出口商品关别总值表”。

三、如需要了解具体信息，请通过登陆海关总署政府网站（www.customs.gov.cn）的“海关统计”栏目，或阅览《海关统计》（月刊）等方式查询获得。

感谢您对海关工作的关心和支持。

海关总署

2019年7月3日
