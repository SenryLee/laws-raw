# 财政部关于下达2019年科技馆免费开放补助资金预算的通知

财科教〔2019〕33号

有关省、自治区、直辖市、计划单列市财政厅（局）：

根据《中国科协 中宣部 财政部关于全国科技馆免费开放的通知》（科协发普字〔2015〕20号，以下称20号文）精神，为保证免费开放科技馆正常运转，经研究，现下达2019年科技馆免费开放补助资金预算（项目代码：Z135050009061，具体详见附件），统筹用于你省（区、市）纳入2018年免费开放范围的科技馆门票减收补助、运行保障增量补助及展品更新补助等方面。上述资金列入“1100208结算补助收入”科目。

请严格按照20号文有关要求，并商本级科协，抓紧落实你省（区、市）应负担的科技馆免费开放资金，与中央财政补助资金统筹安排，保障科技馆免费开放工作顺利实施。

附件：2019年科技馆免费开放补助资金预算表（略）
