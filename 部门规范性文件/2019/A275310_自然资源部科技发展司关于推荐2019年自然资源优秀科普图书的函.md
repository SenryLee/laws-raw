# 自然资源部科技发展司关于推荐2019年自然资源优秀科普图书的函

## 关于推荐2019年自然资源优秀科普图书的函

自然资科函〔2019〕26号

各有关单位：

为贯彻落实《全民科学素质行动纲要》，在全社会大力普及科学知识、弘扬科学精神，提高全民科学素养，现组织开展2019年自然资源优秀科普图书推介活动。有关事项通知如下：

一、活动内容

向全社会征集优秀自然资源科普图书，通过单位（或个人）推荐、形式审查、专家遴选和公示后，产生“2019年自然资源优秀科普图书”。在第50个世界地球日主题宣传活动周，发布2019年自然资源优秀科普图书名单，并向全社会推介阅读。在此基础上推荐全国优秀科普作品。

二、推荐要求

此次推荐的科普图书应是在新闻出版机构登记、正式出版发行（含译著和再版图书）的书籍，且符合下列要求：

1.具有普及科学技术知识、倡导科学方法、传播科学思想、弘扬科学精神的深厚内涵；

2.思想性、科学性较强，符合普及自然资源领域科学技术知识要求，能够激励人们爱科学、学科学、用科学；

3.具有较高的艺术性和趣味性，语言生动流畅、形式活泼、内容丰富、通俗易懂，为公众所喜闻乐见；

4.属于原创性作品，选题构思新颖、创作手法和表现形式独特；

5.作品文字应为简体中文。

三、推荐方式

此次推荐工作面向社会，推荐方式包括：

1.各省级自然资源主管部门、中国地质调查局及部其他直属单位、各派出机构、相关学会等单位推荐；

2.相关领域的专家推荐；

3.出版机构、作者自我推荐。

推荐图书没有数量限制，但均需填写推荐表（附件1）并加盖公章或签字（专家或作者个人推荐的，还需附个人身份证件复印件等身份证明材料），随同科普图书一式5套以及宣传展示相关信息（附件2）电子版光盘1张，于4月5日前报送至中国地质博物馆。提交图书不再退还。曾被评选为国土资源优秀科普作品（图书）的不再做推荐。
