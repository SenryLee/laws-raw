# 商务部公告2019年第42号——2020年食糖、羊毛、毛条进口关税配额实施细则

## 商务部公告

2019年第42号

## 2020年食糖、羊毛、毛条进口关税配额实施细则

根据《农产品进口关税配额管理暂行办法》（商务部、发展改革委令2003年第4号），商务部制定了《2020年食糖进口关税配额申请和分配细则》和《2020年羊毛、毛条进口关税配额管理实施细则》，现予以公告。

附件：1.2020年食糖进口关税配额申请和分配细则

2.2020年羊毛、毛条进口关税配额管理实施细则

商务部

2019年10月13日
