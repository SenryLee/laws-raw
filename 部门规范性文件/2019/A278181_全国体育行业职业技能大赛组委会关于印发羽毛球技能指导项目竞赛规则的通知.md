# 全国体育行业职业技能大赛组委会关于印发羽毛球技能指导项目竞赛规则的通知

体人力字〔2019〕142号

各省、自治区、直辖市体育局、教科文卫体工会，新疆生产建设兵团体育局、工会，体育总局直属机关工会：

为贯彻落实《国家体育总局 中华全国总工会关于举办2019年全国体育行业职业技能大赛的通知》（体群字〔2019〕40号）要求，切实做好竞赛活动的组织工作，确保竞赛活动顺利进行，现将《2019年全国体育行业职业技能大赛羽毛球技能指导项目竞赛规则》印发给你们，请遵照执行。
