# 海关总署公告2019年第53号——关于变更金伯利进程管理系统访问地址的公告

## 海关总署公告

2019年第53号

## 关于变更金伯利进程管理系统访问地址的公告

海关总署决定自2019年3月27日起，将金伯利进程管理系统的访问地址变更为http:// chinakp.customs.gov.cn，通过访问该地址可以办理金伯利进程业务，原访问地址将于2019年5月1日零点停止使用。

特此公告。

海关总署

2019年3月26日
