# 国家文物局关于大运河（杭州段）建设控制地带内杭政储出〔2018〕43号地块商品住宅建设项目的意见

文物保函〔2019〕937号

浙江省文物局：

你局《关于要求在全国重点文物保护单位大运河（杭州段）建设控制地带内实施杭政储出〔2018〕43号地块商品住宅建设项目的请示》（浙文物发〔2019〕136号）收悉。经研究，我局原则同意在大运河杭州段建设控制地带内实施杭政储出〔2018〕43号地块商品住宅建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）完善地下停车场施工方案，细化防止水土流失、地基垮塌等风险的保障措施，并补充相应的监控措施和应急预案。

（二）调整1#、4#、5#、8#、11#、13#、14#楼的建筑设计方案，进一步降低设计高度，可考虑采用东低西高的退台式设计，并适当淡化外观色彩，使之与大运河整体环境相协调。

（三）优化项目用地范围内的功能布局，增加靠近大运河一侧的绿化带高度和厚度，弱化内部车辆交通功能，建议将地块东侧出入口调整为南侧或北侧出入口。

（四）细化施工过程中的运河生态环境、景观风貌保护要求和废弃物处置要求，以及施工结束后的场地清理、环境修复措施，并在适当位置设置大运河标识及展示阐释设施。

二、请你局组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年9月5日
