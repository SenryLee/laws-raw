# 国家档案局关于2019年度国家档案局优秀科技成果奖励的通知

各省、自治区、直辖市档案局，河北省委办公厅、江苏省委办公厅，各计划单列市档案局、新疆生产建设兵团档案局，中央和国家机关各部委档案部门，中央军委办公厅保密和档案局，各人民团体档案部门，各中央企业档案部门，中国人民大学档案学院：

为鼓励在推动档案科学技术发展中作出重要贡献的集体和个人，促进档案管理现代化水平的提高，根据《国家档案局优秀科技成果奖励办法》，经2019年度国家档案局优秀科技成果评审委员会评审和国家档案局批准，授予《综合档案馆档案开放鉴定工作机制研究》等6项成果国家档案局优秀科技成果二等奖，授予《新型保温材料在档案库房环境管理中的应用研究》等19项成果国家档案局优秀科技成果三等奖。

附件：2019年度国家档案局优秀科技成果奖励项目
