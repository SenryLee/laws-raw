# 农业农村部关于政协十三届全国委员会第二次会议第1548号（农业水利类149号）提案答复摘要

## 关于政协十三届全国委员会第二次会议第1548号（农业水利类149号）提案答复摘要

农办案〔2019〕22号

关于支持修订《渔业法》加强打击非法捕捞问题的提案收悉。经商国务院港澳事务办公室，现答复如下。

一、关于提高《渔业法》的震慑力

现行《渔业法》中的罚则是依据上世纪末国家经济社会发展水平和渔业管理实际情况所确定。与违法捕捞所获利润相比，一些罚则的确已不能对违法行为形成有效震慑。目前，我部正在着力推进《渔业法》修订工作，拟在统筹地域差异、可操作性等因素基础上，全面增补禁止性行为的处罚条款，提高对违法捕捞行为的处罚标准，对违法情节严重的，还规定可以没收涉案渔船及工具。此外，各地渔业渔政部门积极推动渔政执法与刑事司法衔接，依法追究构成犯罪人员的刑事责任，2017年以来已累计向公安机关移送涉嫌犯罪人员1.1万名。下一步，我部将配合立法部门做好《渔业法》修订。

二、关于建立执法数据库与执法信息公开

近年来，许多地方渔业渔政部门都建立了本地区违法捕捞执法数据库。目前，我部正在研究将各地执法数据库进行整合优化，形成全国性的违法捕捞执法数据库。

各级渔业渔政部门持续加大渔政执法信息的公开力度。2017年以来，我部通过中国渔政微信公众号、渔政执法行动新闻发布会等形式，向社会通报执法行动情况，适时发布违法捕捞典型案例，展现渔业渔政部门打击违法捕捞的决心；许多地方渔业渔政部门积极推动涉嫌犯罪案件在渔区的公开宣判，均取得了不错的效果。

三、关于打击跨境非法捕捞

粤港两地执法部门强化了执法合作，每年违法捕捞高发季节在粤港交界水域开展联合执法行动。此外，粤港两地执法部门建立了联络员制度，对联合执法、应急通报等工作定期联络。下一步，我部将在国务院港澳事务办公室统一部署下，指导有关地方渔业渔政部门进一步加强与香港特区政府的执法合作，提高跨境违法捕捞打击效果。

四、关于群众举报受理

多数地区渔业渔政部门已经公布了违法举报电话，开展了举报受理工作。但由于执法条件不足、执法区域远、信息传递环节多等因素，部分案件查处效果不佳。目前，我部正在研究建立全国统一的违法捕捞群众举报受理平台，提高举报信息传递效率和查处效能，不断提升渔民群众的满意度。

感谢你们对渔业法制和渔政执法工作的关心，希望继续对我部的工作给予支持。

农业农村部

2019年8月26日
