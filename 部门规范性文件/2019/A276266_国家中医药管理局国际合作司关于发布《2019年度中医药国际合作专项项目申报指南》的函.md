# 国家中医药管理局国际合作司关于发布《2019年度中医药国际合作专项项目申报指南》的函

## 关于发布《2019年度中医药国际合作专项项目申报指南》的函

国中医药国际亚美便函〔2019〕26号

各省（自治区、直辖市）中医药管理部门，局各直属单位：

为贯彻党的十九大精神，根据2019年全国中医药工作重点任务安排，落实《中医药“一带一路”发展规划（2016-2020）》，规范做好2019年度中医药国际合作专项有关工作，依据有关文件精神，经广泛征求意见，我司制定了《2019年度中医药国际合作专项项目申报指南》。

请各单位根据《申报指南》要求，做好2019年度中医药国际合作专项项目申报工作。

附件：2019年度中医药国际合作专项项目申报指南

国家中医药管理局国际合作司

2019年3月20日
