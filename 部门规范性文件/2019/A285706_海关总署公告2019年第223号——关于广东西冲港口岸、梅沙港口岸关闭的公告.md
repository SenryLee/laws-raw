# 海关总署公告2019年第223号——关于广东西冲港口岸、梅沙港口岸关闭的公告

## 海关总署公告

2019年第223号

## 关于广东西冲港口岸、梅沙港口岸关闭的公告

2019年12月20日，国务院批准关闭广东西冲港口岸、梅沙港口岸。自本公告发布之日起，上述两个口岸关闭。

特此公告。

海关总署

2019年12月27日
