# 农业农村部关于政协十三届全国委员会第二次会议第0295号（农业水利类047号）提案答复

## 关于政协十三届全国委员会第二次会议第0295号（农业水利类047号）提案答复

农办案〔2019〕69号

民革中央：

“关于应用大数据手段和互联网技术，保障食用农产品安全供给的提案”收悉，经商商务部、市场监管总局、科技部、自然资源部，现答复如下。

一、关于强化食用农产品质量安全宣传和社会监督

为保障农产品质量安全，形成全社会关心、关注、支持农产品质量安全良好氛围，我部坚持正面引导，积极发挥媒体和行业协会等社会力量的作用，通过多种形式加大优质安全农产品宣传推介力度，树立我国农产品安全优质放心的形象。目前，我部已开设“中国农产品质量安全”公众号和“农安天地”科普订阅号并正式运行，累计推送文章一百余篇，阅读量超过三十万。组织开展了优秀科普作品征集和展播活动，引导鼓励科研教学机构广泛开展科普解读，积极回应社会关切。组织制作的《速生鸡用了激素和抗生素吗？》和《你还在误解国产牛奶吗？》2个微视频被中国科协评为全国优秀科普微视频作品。基于风险评估科学数据和研究成果，以国家农产品质量安全风险评估团队名义发布质量安全防控技术指南，指导生产经营者加强过程控制，防范质量安全风险，提升产品质量。多渠道开展风险交流，会同相关部门、新闻媒体等机构，加大谣言治理，针对茶叶农残、鸡蛋长斑、黑木耳打药等社会关注度高的农产品质量安全问题，组织专家撰写科普解读文章，进行权威发布，消除不实传言，正面引导舆论。

下一步，我部将全面强化科普宣传，树立公众消费信心。一是组织编制科普丛书。启动农产品质量安全科普百科丛书编制工作，开展农产品质量安全优秀科普作品征集评选活动。二是开展公益科普宣传。发挥我部官方网站、“中国农产品质量安全”微信公众号和“农安天地”科普订阅号宣传作用，通过视频、动画、短片等方式，传播普及农产品质量安全科学知识。三是做好谣言治理。完善谣言举报机制，发挥“中国食品辟谣联盟”作用，依法严惩恶意造谣传谣者，积极营造风清气正、安心放心的舆论环境。

二、关于加强新型职业农民培育

我部始终高度重视对农民的教育培训工作。一是开展农民教育培训。2014年开始，我部联合财政部重点面向种养大户、家庭农场主、农民合作社骨干、农业社会化服务组织负责人等新型农业经营主体带头人和返乡涉农创业者，开展农业全产业链培训，促进农民创业兴业。截至2018年，中央财政累计安排70.9亿元支持农民教育培训工作。二是健全完善教育培训体系。目前已基本形成党委政府主导，农业农村部门牵头、公益性培训机构为主体、市场力量和多方资源共同参与的教育培训体系。不断强化农广校支撑作用，凝聚农业院校、科研院所、农民合作社、农业企业、农业园区等资源，广泛开展农民教育培训工作。三是着眼平台建设。完善全国农业科教云平台建设，让广大农民搭乘“互联网+”的快车。截至2018年底，云平台注册用户数达200万，其中上线专家和农技人员33万人，以职业农民为主体的农民用户167万人，上线农民培育课程和农业技术视频4639个，累计在线解答问题200万条，发布服务日志317.5万条、有效农情20.9万条。

下一步，我部将紧紧围绕促进产业兴旺目标任务，分层分类实施农业经理人培养、新型农业经营主体带头人等培育计划。鼓励农民参加职业技能鉴定，推进职业培训与职业教育衔接贯通，就地就近定向培养具有中高等学历的高素质农民，助推乡村振兴战略实施。

三、关于大力推进农业产供销标准化建设

一是开展耕地质量监测网络建设。会同生态环境部印发《国家土壤环境监测网农产品产地土壤环境监测工作方案（试行）》。目前，已建立国家级耕地质量长期定位监测点1052个、省级监测点3000多个、地级监测点2000多个、县级监测点9000多个，初步形成了国家、省、市、县四级耕地质量监测网络。定期发布耕地质量监测报告，为各级政府制定耕地质量保护政策提供了重要的技术支撑。同时，将耕地轮作休耕制度试点区域作为耕地质量监测的重点，科学设置监测站（点），跟踪耕地质量变化，为评价耕地轮作休耕效果提供科学依据。二是深入实施农业物联网试验工程。支持天津、上海、安徽等省份开展农业物联网区域试验工程，加强对北京、黑龙江农垦、内蒙古等国家物联网应用示范工程实施的指导。召开全国农业物联网工作会议，总结推广426项节本增效农业物联网软硬件产品、技术和模式，推介10种物联网应用模式宣传片，编制了《全国农业物联网发展报告》。三是推进农业大数据和智能化应用。目前，我部初步建成农产品质量安全追溯、农兽药基础数据、重点农产品市场信息、新型农业经营主体信息直报等“四平台”， 提高了农业生产管理和指挥调度能力，促进了农业物联网加快推广应用。四是开展食品品质质量智能化追溯技术研究。2016年，国家启动“主要食品全产业链品质质量控制关键技术开发研究”项目，中央财政投入经费3400万元。项目下设“食品品质质量智能化追溯技术”课题，开发和建立从农产品基地、生产加工到流通消费全过程的电子追踪溯源系统技术。通过项目实施，开发和构建了国家食品品质质量与营养智能化监测与溯源体系和云服务示范平台2套，食品品质实时监测平台和智能化质量溯源与网络监控系统5个。

下一步，我们将加快推进农业农村大数据应用，深入实施农业物联网试验示范，努力争取在重点农产品全产业链大数据建设方面取得突破。同时，持续重视质量安全控制科技创新，为保障食用农产品安全供给提供有效的科技支撑。

四、关于大力推进农产品信息资源数据库建设和农产品信息资源共享平台

一是全面推进农产品追溯体系建设。2017年7月，我部建成国家追溯平台并上线试运行。2018年9月，印发《农业农村部关于全面推广应用国家农产品质量安全追溯管理信息平台的通知》，举办推广应用培训班9期。截至2019年7月底，全国共有31386家生产经营主体、2947家监管机构、851家检测机构、850家执法机构已注册使用国家追溯平台。另外，商务部会同财政部累计投入23.56亿元，支持76个地区开展肉菜、中药材流通追溯体系建设试点。截至2018年底，重要产品追溯体系覆盖34个省（区、市）的102个城市，涉及8.6万家企业、覆盖52万商户，累计接收追溯信息66.6亿条。二是建成农业应急管理信息系统。我部建成农业应急管理信息系统，“农产品质量安全”模块是其中一个子系统。建立部省地县四级农产品质量安全事件接报体制，对接国家农产品质量安全追溯管理信息平台、三农舆情监测管理平台，实现了农产品质量安全风险可视化、决策定量化。三是积极做好农产品质量安全风险评估工作。2018年，投入财政资金7200余万元，开展了粮油、蔬菜、果品、畜禽、水产品等15个专项农产品质量安全风险评估。对评估中发现的问题，我部及时与相关部委及地方政府沟通交流，督促地方政府加强农产品质量安全风险管控。

下一步，我部将积极推动农业应急管理信息系统纳入国家公共安全信息化工程考虑范围，努力在农产品质量安全领域建立数据共享和业务协同机制。在农产品质量安全追溯体系建设上，要全面推广应用国家追溯平台，打造一批追溯标杆企业，积极向财政部争取设立追溯补贴项目，对生产者、产地收购者、批发市场进行补助，用于追溯设备采购和示范创建，推动营造全社会关注农产品追溯的舆论氛围。

感谢对农产品质量安全工作的关心，希望今后继续对我部工作予以支持。

农业农村部

2019年8月30日
