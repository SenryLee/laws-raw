# 农业农村部对十三届全国人大二次会议第8702号建议答复摘要

## 十三届全国人大二次会议第8702号建议答复摘要

一、关于设置乡村振兴科技平台重大专项

我部高度重视加强科技创新对乡村振兴的支撑引领作用，2018年制定印发了《乡村振兴科技支撑行动实施方案》，按照乡村振兴战略总要求，聚集科技、产业、金融、资本等各类创新要素，围绕解决制约乡村振兴的重大技术瓶颈问题，着力创新一批关键核心技术，集成应用一批先进实用科技成果，示范推广一批农业可持续发展模式，打造一批科技引领示范村（镇），培育壮大一批新型农业生产经营主体，建立健全科技支撑乡村振兴的制度政策，基本满足乡村振兴和农业农村现代化对新品种、新装备、新产品、新技术和新模式等科技成果有效供给的需求。

在国家科技计划项目支持方面，根据中央财政科技计划管理改革部署，已启动实施了国家重点研发计划“化学肥料和农药减施增效综合技术研发”“粮食丰产增效科技创新”“农业面源和重金属污染农田综合防治与修复技术研发”“绿色宜居村镇技术创新”等重点专项，对乡村振兴科技创新进行部署。相关专项按照“全链条设计、一体化实施”的思路，汇聚国内优势科研力量开展联合攻关，为农村人居环境改善、农业绿色发展和产业提质增效提供了强有力的科技支撑。

下一步，我部将继续大力实施乡村振兴科技支撑行动，围绕产业需求，坚持问题导向，统筹利用好中央和地方科技资源与专项资金，合力推动乡村振兴科技支撑行动落地见效。同时，我部将按照中央财政科技计划管理改革的统一部署，会同科技部等部门积极推动农业农村领域相关国家科技计划的立项实施，根据实际需要凝练新的专项及有关项目，为扎实推进乡村振兴战略、促进农业可持续发展提供高质量的科技供给。

二、关于建设农业高科技园

为推动农业供给侧结构性改革，培育农业发展新动能，切实解决科技与经济“两张皮”问题，我部深入贯彻中央文件精神，2016年起大力推进国家现代农业产业科技创新中心建设，打造区域经济增长极。按照“建一个、成一个”“先建、后认、再挂牌”的原则，目前已启动建设的南京、太谷、成都、广州四地产业科技创新中心结合区域农业产业发展实际需求，在体制机制创新、资源要素聚集、市场作用发挥、推动产业发展等方面积极探索，科技与产业、企业、人才、金融等要素加速融合，不断推动主体集合、技术集成、企业集群、产业集中，有力促进了智慧农业、功能农业、生物农业等新兴产业快速发展。

为加快适用技术落地应用，近期我部组织开展国家农业科技示范展示基地遴选工作，在全国范围内围绕粮油、园艺、畜禽、水产等农业主导产业或地方优势特色产业，遴选不超过100个有一定面积规模、有引领性综合配套技术、有较强的科技支撑团队、有可持续的运行发展机制的基地，打造农业优质品种和绿色高效技术的展示窗口，构建农技指导服务和农民教育培训的高效平台，充分发挥基地对推动农业转型升级和高质量发展的引领作用，为加快农业农村现代化和推进乡村振兴提供更有力的科技平台支撑。

下一步，我部将会同科技部等有关部门，进一步优化整合现有园区和平台，促进各类科技资源有效融合集聚，加强科技与产业对接和先进适用技术落地，打通农业科技应用最后一公里。引导现有农业科技园区、产业科技创新中心和示范类基地紧密围绕当地农业主导产业，强化适用技术供给，延伸科技创新链条，鼓励国家重点研发计划等农业农村领域国家科技计划项目优先在园区开展研发试验、科技示范，打造具有多元化现代农业科技研发试验和示范功能的科技创新和推广平台。
