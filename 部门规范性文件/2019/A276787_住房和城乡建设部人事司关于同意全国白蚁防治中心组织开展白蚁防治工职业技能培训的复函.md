# 住房和城乡建设部人事司关于同意全国白蚁防治中心组织开展白蚁防治工职业技能培训的复函

建人才函〔2019〕10号

全国白蚁防治中心：

《关于开展白蚁防治工职业培训的请示》（全蚁〔2019〕16号）收悉。经研究，现函复如下：

一、同意你中心组织开展全国白蚁防治工职业技能培训工作。

二、要加强领导，精心组织。按照《国务院关于推行终身职业技能培训制度的意见》（国发〔2018〕11号）精神和《住房城乡建设部关于加强建筑工人职业培训工作的指导意见》（建人〔2015〕43号）有关要求，健全工作机制，扎实稳妥推进全国白蚁防治人员职业技能培训工作，不断提升从业人员职业道德和职业技能水平。

三、要依据职业技能标准，指导相关机构开展白蚁防治工职业技能培训，确保培训质量。不断完善职业培训大纲，组织编写、开发培训教材、课件等，加强培训工作基础条件建设。

四、要充分运用信息化技术手段，加强培训管理服务和监管力度。要按照部住房城乡建设行业从业人员培训管理信息系统关于技能人员培训合格证电子化管理有关要求和下列编码规则，为培训合格人员编码，实现培训机构或个人可查询、下载、打印电子证书。

![](https://zk-img.faxin.cn//Uedit_Upload/2019-05-05-17-18-09_9846050_W020190505041127.png)

五、工作开展中有关情况和问题，请及时报告。

中华人民共和国住房和城乡建设部人事司

2019年4月17日
