# 国家文物局办公室关于西汉安陵保护范围和建设控制地带内咸阳市天然气输配三期秦汉调压站建设项目的意见

办保函〔2018〕1271号

陕西省文物局：

你局《关于咸阳市天然气输配三期——秦汉调压站工程选址涉及西汉帝陵——安陵建设控制地带的请示》（陕文物字〔2018〕153号）收悉。经研究，我局暂不同意在西汉帝陵——安陵保护范围和建设控制地带内实施咸阳市天然气输配三期秦汉调压站建设项目。

一、对所报方案提出以下修改完善意见：

（一）应根据近年来考古的成果，核定安陵保护范围和建设控制地带坐标，进一步明确项目选址与文物保护范围和建设控制地带的空间位置关系。

（二）充分论证项目选址占压安陵陵邑区域的必要性，进行多方案比选，尽量避让遗址保护范围和重要遗迹分布区。

（三）补充项目绿化设计方案，建筑外观、形式、色调应与遗址景观风貌相协调。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月2日
