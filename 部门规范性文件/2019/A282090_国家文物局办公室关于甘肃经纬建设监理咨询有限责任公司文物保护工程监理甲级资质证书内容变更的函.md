# 国家文物局办公室关于甘肃经纬建设监理咨询有限责任公司文物保护工程监理甲级资质证书内容变更的函

办保函〔2019〕797号

甘肃省文物局：

你局《关于变更甘肃经纬建设监理咨询有限公司文物保护工程监理甲级资质证书相关信息的请示》（甘文局发〔2019〕111号）收悉。

经研究，我局同意甘肃经纬建设监理咨询有限责任公司文物保护工程监理甲级资质证书中的单位地址由“甘肃省兰州市城关区定西路518号长城山海苑1号56”变更为“甘肃省兰州市城关区红星巷64号昶荣城市印象2512号”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年9月10日
