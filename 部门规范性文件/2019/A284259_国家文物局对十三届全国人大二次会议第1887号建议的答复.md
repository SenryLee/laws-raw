# 国家文物局对十三届全国人大二次会议第1887号建议的答复

文物政函〔2019〕684号

章国强等2名代表：

您提出的“关于重视历史文化资源（遗存）保护利用助力建设社会主义文化强国的建议”收悉。经商住房城乡建设部、财政部、国家发展改革委、文化和旅游部，现答复如下。

党的十八大以来，以习近平同志为核心的党中央站在实现中华民族伟大复兴中国梦的战略高度，对中华优秀传统文化保护传承、文物保护利用进行战略谋划和整体部署；党的十九大明确要求“建设社会主义文化强国”，“深入挖掘中华优秀传统文化蕴含的思想观念、人文精神、道德规范，让中华文化展现出永久魅力和时代风采”，“加强文物保护利用和文化遗产保护传承”；中共中央办公厅、国务院办公厅出台《关于实施中华优秀传统文化传承发展工程的意见》《关于加强文物保护利用改革的若干意见》《关于实施革命文物保护利用工程（2018-2022年）的意见》，为加强历史文化资源保护利用、推进新时代文物事业发展指明了方向、提供了遵循。

我们将深入贯彻落实党中央、国务院的战略部署，加强历史文化资源保护利用，加强文物保护利用和文化遗产保护传承，让中华文化绽放出永久魅力和时代风采，更好助力社会主义文化强国建设。

关于进一步提高站位、增强全社会保护意识建议，目前12个省份将文物工作纳入地市级党政领导班子综合考核评价体系，16个省份将文物安全纳入地方政府绩效考核评价体系。2019年文化和自然遗产日前夕，黄坤明同志主持召开推进文化和自然遗产保护工作座谈会，推动掀起学习宣传贯彻习近平总书记关心文化和自然遗产保护重要论述的新高潮。我们将持续贯彻习近平总书记关于文化遗产保护重要论述精神，积极引导各级党委、政府树立保护文物也是政绩的科学理念，面向广大公众特别是年轻受众鲜活讲述历史文化资源的价值和故事，推动形成全社会高度关注、共同参与的良好局面。

关于进一步提升保护利用水平、让历史文化资源重现生机和活力建议，中央相关部门坚持在保护中发展、在发展中保护，多措并举让文化遗产活起来，有效推动历史文化资源保护利用更好融入经济社会发展大局。下一步，中央相关部门和各地将坚持以人民为中心的工作导向，把保护利用历史文化资源与满足人民对美好生活新期待相结合，盘活用好历史文化资源，建设中华文明标识体系，提升博物馆公共文化服务质量，促进非物质文化遗产保护传承“见人见物见生活”。充分利用文化旅游融合发展契机，统筹推进将更多历史文化资源纳入旅游精品线路，依托重要历史文化资源建设国家文化公园。更好发挥全国文物安全工作部际联席会议制度的协调功能，研究建立历史文化名城名镇名村保护跨部门协商机制。

关于进一步加大支持力度、切实提高全社会保护利用历史文化资源积极性建议，《关于加强文物保护利用改革的若干意见》对新时代文物保护利用进行了全面部署。近四年，中央财政累计安排中央预算内投资超过210亿元，支持公共文化服务设施建设、国家级自然文化遗产保护设施、旅游基础设施和公共服务设施建设，为各地加强历史文化资源保护利用提供了有力支撑。下一步，中央相关部门将继续加大政策和资金支持力度，中央财政支持和鼓励金融机构对历史文化保护领域给予贷款支持，具体信贷条件由金融机构结合国家有关政策、行业发展情况、自身业务需求、项目风险水平等因素，按市场化原则确定。鼓励和支持市场主体参与历史文化资源的开发利用，符合相关要求的文化产业项目可按照《社会领域产业专项债券发行指引》有关要求，研究探索用好专项债券这一新型融资工具并按程序申请发行，国家发展改革委将按照有关要求积极做好审核工作。健全社会力量参与历史文化资源保护利用机制，建立健全多元化的历史建筑保护利用资金筹措机制，鼓励地方探索社会力量参与国有不可移动文物的使用、运营、管理。

感谢您对文化遗产事业的关心和支持。

国家文物局

2019年7月10日
