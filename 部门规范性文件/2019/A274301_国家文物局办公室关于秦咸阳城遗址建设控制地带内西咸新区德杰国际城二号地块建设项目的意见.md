# 国家文物局办公室关于秦咸阳城遗址建设控制地带内西咸新区德杰国际城二号地块建设项目的意见

办保函〔2019〕66号

陕西省文物局：

你局《关于西咸新区德杰国际城二号地块项目选址涉及秦咸阳城遗址建设控制地带的请示》（陕文物字〔2018〕226号）收悉。经研究，我局暂不同意在秦咸阳城遗址建设控制地带内实施西咸新区德杰国际城二号地块建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）项目位于秦咸阳城遗址建设控制地带内，1号、2号、7号楼选址紧邻已发现制陶作坊遗址，应按照《咸阳城遗址保护规划（2011-2030）》中一类建设控制地带的控制要求，综合考虑地形地貌特点和高度差，合理核减新建建筑整体高度。

（二）建议综合考虑遗址保护影响，论证大面积水面设计的必要性；建筑外立面形式、色彩应与遗址景观风貌相协调。

（三）应充分评估建设施工、市政管线铺埋等文物影响，研提施工中的文物保护预案，确保文物安全。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

三、请你局指导地方人民政府，依据《西咸新区总体规划》《秦咸阳城遗址保护总体规划（2011-2030）》等，进一步明确、公布建设控制地带的具体建设控制要求和指标，统筹考虑城市建设发展和秦咸阳城遗址保护利用之间的关系。

专此函复。

国家文物局办公室

2019年1月25日
