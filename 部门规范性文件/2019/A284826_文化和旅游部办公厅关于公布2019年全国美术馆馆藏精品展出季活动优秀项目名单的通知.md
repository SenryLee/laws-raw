# 文化和旅游部办公厅关于公布2019年全国美术馆馆藏精品展出季活动优秀项目名单的通知

办艺发〔2019〕155号

各省、自治区、直辖市文化和旅游厅（局），新疆生产建设兵团文化体育广电和旅游局，中央军委政治工作部宣传局，中国美术馆、中国国家画院：

根据《文化和旅游部办公厅关于印发〈2019年全国美术馆馆藏精品展出季活动方案〉的通知》（办艺发〔2019〕49号）要求，2019年全国美术馆馆藏精品展出季活动验收工作已经顺利完成，经专家小组认真评审，并经文化和旅游部审核，共评选出优秀项目10个。

在此次活动中，江苏省文化和旅游厅、湖北省文化和旅游厅、广东省文化和旅游厅组织工作表现突出，被评为优秀组织单位。

现将优秀项目名单予以公布。

特此通知。
