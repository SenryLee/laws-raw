# 农业农村部对十三届全国人大二次会议第3905号建议的答复

## 对十三届全国人大二次会议第3905号建议的答复

农办议〔2019〕517号

张磊代表：

您提出的关于支持内蒙古自治区开展地方优势特色牧区牛羊灾害保险的建议收悉。经商银保监会，现答复如下。

根据党中央、国务院有关要求，结合当前“三农”工作需要、农业保险发展阶段和各级财力状况等，我国农业保险按照“中央保大宗、保成本，地方保特色、保产量”的原则运作。目前，中央财政保费补贴已经覆盖种、养、林三大类16个品种，基本包括了主要大宗农产品。对畜牧业保险发展，国家高度重视，鼓励保险机构和地方根据各地实际，探索开展相关业务，既包括传统的养殖业保险，也包括价格指数、天气指数等相关创新型保险，以建立多层次的农业保险体系。2018年，我国养殖业保险保费收入180.01亿元，同比增长36.22%，占农业保险总保费收入的31.5%；赔付支出140.46亿元，同比增长46.76%，占总赔款的33.29%；受益农户831万户次。

近日，财政部印发《关于开展中央财政对地方优势特色农产品保险奖补试点的通知》（财金〔2019〕55号，以下简称《通知》），自2019年1月1日起施行，期限暂定一年。《通知》明确，在内蒙古、海南、甘肃等10个省（区）开展试点，各试点省（区）申请奖补的保险标的或保险产品不超过两种，应覆盖至少2个地市，且未纳入中央财政农业保险保费补贴的16个品种。《通知》要求，在地方财政至少补贴35%的基础上，中央财政对中西部地区补贴30%，对东部地区补贴25%，并要求原则上国家扶贫开发工作重点县和集中连片特困地区县的县级财政补贴比例不超过保费的5%。下一步，我部将配合财政部、银保监会等相关部门，推动试点工作平稳有序开展，切实发挥支持特色农业产业发展、完善农业保险保费补贴品种体系、助力农民增收和脱贫攻坚战略实施等作用，并鼓励保险公司深入研究农户需求，加快包括天气指数保险在内的相关产品创新，不断满足广大养殖户尤其是内蒙古等少数民族地区农户的风险保障需求。

感谢您对农业农村经济工作的关心，希望继续对我部工作给予支持。
