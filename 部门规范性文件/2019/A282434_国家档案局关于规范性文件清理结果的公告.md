# 国家档案局关于规范性文件清理结果的公告

按照《国务院办公厅关于加强行政规范性文件制定和监督管理工作的通知》（国办发〔2018〕37号）要求，我局对截至2018年12月底印发的规范性文件进行了集中清理。2019年8月29日国家档案局局长办公会审议并通过了清理结果。

经清理，现行有效规范性文件共59件，废止失效规范性文件共56件。现行有效规范性文件将在我局官网（http://www.saac.gov.cn）全文公布。

附件：1.现行有效规范性文件目录

2.废止失效规范性文件目录

国家档案局

2019年9月6日
