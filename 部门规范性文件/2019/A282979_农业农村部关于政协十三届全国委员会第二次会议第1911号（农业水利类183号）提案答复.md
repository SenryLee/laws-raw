# 农业农村部关于政协十三届全国委员会第二次会议第1911号（农业水利类183号）提案答复

## 关于政协十三届全国委员会第二次会议第1911号（农业水利类183号）提案答复

米恩华委员：

您提出的关于推进新疆畜牧产业发展的提案收悉。经商教育部、银保监会，现答复如下。

一、关于加强行业供应链管理能力

我部高度重视一二三产业融合发展，加强行业全产业链管理。一是开展田头市场示范。田头市场是农畜产品产地市场体系的重要组成部分，是农牧民走向市场的第一窗口、销售农产品的第一场所、获取市场信息的第一渠道和农产品流通的第一环节，能有效降低农畜产品流通损失，实现农产品生产出来以后“存得住、运得出、卖得掉、赚得到”，具有明显的公益职能，在促进农业稳定发展、推动农民持续增收、满足城乡消费需求方面发挥着不可替代的作用。2014年以来，我部启动了田头市场示范工作，旨在改善基础设施，规范建设标准，强化分等分级和商品化处理，重点支持信息采集发布、电子化交易等公益性设施建设，提高了田头市场流通效率，减少流通损耗，推进农产品上行，培育发展了一批专业性强、辐射范围广、带动一方产业发展的田头市场。二是利用信息化手段加强行业供应链管理。目前，我部已开展畜牧业生产和市场监测工作，围绕主要畜禽品种开展全产业链监测，实现了生猪、蛋鸡、肉鸡、奶牛、肉牛、肉羊6大品种全覆盖，形成了涵盖监测村、养殖户、集贸市场、奶站、企业、种畜禽场在内的完整体系，建立了畜牧业生产监测系统、手机数据采集上报系统、智能数据分析系统、畜牧业灾情调度评估系统等软件平台。进行生猪存栏、能繁母猪存栏等数据的实时监测预警，对异常数据进行分析和上报，并定期向社会公众发布相关数据，促进了行业稳定发展。三是开展畜禽养殖标准化示范创建活动。2010年起，我部组织开展了畜禽养殖标准化示范创建活动。示范创建以“畜禽良种化、养殖设施化、生产规范化、防疫制度化、粪污无害化”为主要内容，通过开展宣传动员、加强技术支撑、强化创建培训等工作，优中选优确定示范场名单，注重发挥示范场的引领带动作用，以点带面提升畜禽养殖标准化水平。2018年起，在总结近年示范创建活动成效和经验的基础上，进一步突出“现代化”这一创建主题，提高创建标准，新创建一批生产高效、环境友好、产品安全、管理先进的示范场，示范引领畜牧业现代化发展。2018年，新疆（含兵团）共创建4个示范场，带动全区畜禽养殖场开展规模化、标准化生产。下一步，我部将继续做好相关工作。一是将进一步聚焦产业需求，加强机制创新，争取扩大田头市场创建实施范围，使其更好地发挥促进农畜产品销售、引导农业结构调整和增加农民收入的重要作用。二是在做好监测体系建设的基础上，建设用好畜禽养殖场直联直报信息平台，加快监管监测一体化和畜牧兽医业务协同，形成畜牧兽医互联互通的信息平台，及时发布形势分析预警信息，加强信息引导。同时，将结合您所提建议，会同有关部门认真研究开发供应链管理综合服务平台。三是将继续深入开展示范创建活动，加强先进养殖工艺、技术和装备推广力度，带动提升畜牧业发展水平。

二、关于加大金融支持力度，增加普惠性涉农金融贷款的产品种类，开发生物资产可抵押的金融产品

一是探索开展生物资产可抵押金融产品。原银监会印发的《商业银行押品管理指引》（银监发〔2017〕16号）文件要求，商业银行接受的押品应符合法律法规规定或国家政策要求，押品管理要遵循有效性原则，即抵质押担保手续完备，押品估值合理并易于处置变现，具有较好的债权保障作用。企业订单和非现金类保单等不易变现，不建议单独作为押品申请贷款。但东部发达地区和部分研究机构正在对此积极开展研究和探索。2019年，部分区域性商业银行和社会资本已在生物资产可抵押金融产品方面进行了开创性的尝试。二是中央财政转移支付资金继续支持完善农业信贷担保体系建设。2019年，财政补助后的综合担保费率（担保公司向贷款主体收取费用和财政补助之和）不超过3%的情况下，农业贷款主体实际承担的综合信贷成本（贷款利率、贷款主体承担的担保费率、增值服务费率等各项之和）原则上不超过8%。为稳定生猪生产，鼓励农业信贷担保机构在政策规定和风险可控的前提下，向种猪场和存栏5000头以上的生猪规模养殖场提供信贷担保，并允许各地利用适度规模经营资金，对一定期间内实际发生的贷款给予贴息。下一步，我部将会同有关部门在农业信贷担保体系建设的过程中予以关注，并争取对生物资产抵押的农业生产社会化服务等前置环节予以专项支持。

三、关于以农牧民培训学校为载体，推动畜牧业综合服务体系建设

一是培育高素质农民。2014年开始，我部联合财政部重点面向种养大户、家庭农场主、农民合作社骨干、农业社会化服务组织负责人等新型农业经营主体带头人和返乡涉农创业者，以提高生产经营能力和专业技能为目标，开展农业全产业链培训，促进农民创业兴业。截至2019年，中央财政累计安排90.9亿元支持农民教育培训工作。仅2018年、2019年每年就达到20亿元，用于补助农民免费接受教育培训，每年约100万农民受益。二是强化信息化手段应用。为全面提升农技推广和农民教育培训服务效能，我部建立了全国农业科教云平台，开发了云上智农APP。平台基于大数据、云计算和移动互联技术，聚集各类农业科技教育资源，为各级农业农村管理部门、农业专家、农技推广人员和广大农民提供在线学习、互动问答、成果速递、服务对接和管理考核。截至2018年底，云平台注册用户数达200万，其中上线专家和农技人员26.3万人，农民用户157万人，上线农民培育课程和农业技术视频4639个，累计在线解答农民问题150万条，发布服务日志317.5万条、有效农情20.9万条。在2018年首届“助农APP榜样”评选活动中，云上智农APP获得最受农民欢迎的文化教育类APP大奖。三是加强农牧民职业教育培训资源库建设。从2010年起，教育部建立了职业教育专业教学资源库，利用信息技术为社会学习者提供资源和服务，增强职业教育社会服务能力，初步形成职业教育优质教学资源建设体系，覆盖了农林牧渔等19个高职专业大类。截至目前，共有1000所院校、3094家行业企业参与资源库建设；共建成各类多媒体资源190万余条，资源总量30.2TB；注册用户达134万余人。下一步，我们将从两方面继续推动相关工作。一是我部将聚焦乡村振兴人才需求，紧紧围绕促进产业兴旺目标任务，坚持面向产业、融入产业、服务产业，统筹利用各类教育培训资源，加快构建“专门机构+多方资源+市场主体”的多元化培育体系，科学设置教学环节，分层分类实施农业经理人培养、新型农业经营主体带头人（现代青年农场主）、现代创业创新青年培养和农业产业精准扶贫培训等培育计划。继续完善全国农业科教云平台，加强“云上智农”APP内容资源开发建设，以职业素养、农业绿色发展、农产品质量安全和农村生态环保等主题为学员量身打造一批精品课程。二是教育部将会同相关部门研究起草《关于服务乡村振兴战略进一步办好农村职业教育和培训的意见》，推动新疆职业院校、县级职教中心等围绕乡村振兴需求，强化在实施涉农学历教育、农村社区教育、农村人力资源开发等方面的职能。加强畜牧兽医、“物联网和互联网＋农业”等专业建设，增强服务乡村振兴的能力，推进新疆畜牧业发展。建立以县级职教中心、农业广播电视学校为龙头，有关职业院校、农村成人文化技术学校（教学点）、供销合作社、农业企业、农民合作社参与的县域农村职业教育培训网络，实现农牧民网络培训基本覆盖。

感谢您长期以来对畜牧业工作的关心和支持，希望今后继续对我部的工作予以支持。

农业农村部

2019年8月30日
