# 国家文物局对十三届全国人大二次会议第4739号建议的答复

文物博函〔2019〕623号

安际衡代表：

您提出的《关于加强对民间博物馆支持力度的建议》收悉。经商人力资源和社会保障部，现答复如下。

非国有博物馆是博物馆公共文化服务体系的重要组成部分，截至2018年底，在各省级文物部门登记备案的非国有博物馆超过1600家，占全国博物馆总数的近三分之一。有16家非国有博物馆进入国家一、二、三级博物馆序列，其中一级博物馆1家、二级博物馆4家、三级博物馆11家。

国家高度重视并积极支持非国有博物馆发展。《博物馆条例》规定“国家在博物馆的设立条件、提供社会服务、规范管理、专业技术职称评定、财税扶持政策等方面，公平对待国有和非国有博物馆”，为非国有博物馆发展营造了良好的法制环境。2010年，国家文物局等七部门联合印发《关于促进民办博物馆发展的意见》，就扶持非国有博物馆提出了明确指导意见。中央财政通过中央补助地方公共文化服务体系建设专项资金安排奖励，鼓励非国有博物馆免费或低票价开放并不断提升公共服务能力。国家文物局开展“国有博物馆对口帮扶民办博物馆”试点，印发《关于推进国有博物馆对口支援民办博物馆工作的意见》，每年举办非国有博物馆馆长培训班，提高非国有博物馆的专业化水平。2017年，国家文物局印发《关于进一步推动非国有博物馆发展的意见》，继续推动非国有博物馆规范化和科学化管理运行，进一步促进非国有博物馆科学健康发展。2017年底，国家文物局启动全国非国有博物馆藏品备案工作，旨在帮助非国有博物馆摸清家底，初步建立藏品数据库，为下一步做好非国有博物馆藏品资源的活化利用和网上展示、探索建立共建共享机制奠定基础。2016年中办、国办印发的《关于深化职称制度改革的意见》，明确要畅通社会组织专业人才职称申报通道，人力资源社会保障部积极支持非国有博物馆从事文博、档案等专业技术工作的人员，符合条件的可根据属地原则、按照规定的程序申报职称评审，参与职称评价。这些措施有力提升了我国非国有博物馆的发展速度和质量。

对于您提出的“建立民办博物馆藏品艺术品金融化体系，尽快建立、完善文化艺术品市场交易规则和标准体系”的建议，《博物馆条例》明确规定“博物馆不得从事文物等藏品的商业经营活动”。下一步，我局将继续指导各地加大博物馆改革力度，创新博物馆体制机制，增强博物馆法人自主权，激发博物馆发展活力，进一步明确鼓励社会力量参与博物馆建设发展的渠道和支持方式，提升非国有博物馆办馆质量和服务水平，共同推动我国博物馆事业全面进步。

感谢您对博物馆事业的关心和支持！

国家文物局

2019年7月3日
