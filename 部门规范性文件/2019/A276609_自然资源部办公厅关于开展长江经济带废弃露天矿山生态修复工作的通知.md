# 自然资源部办公厅关于开展长江经济带废弃露天矿山生态修复工作的通知

上海、江苏、浙江、安徽、江西、湖北、湖南、重庆、四川、贵州、云南省（市）自然资源主管部门：

为全面贯彻落实习近平总书记在深入推动长江经济带发展座谈会上的重要讲话精神，按照“共抓大保护，不搞大开发”的部署要求，部决定开展长江经济带废弃露天矿山生态修复工作。现将工作方案印发给你们，请认真组织实施。
