# 中华人民共和国农业农村部公告第232号——关于批准法国维克有限公司生产的乙酸地洛瑞林植入剂在我国注册等的公告

## 中华人民共和国农业农村部公告

第232号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准法国维克有限公司生产的乙酸地洛瑞林植入剂在我国注册，核发《进口兽药注册证书》，并发布产品质量标准、说明书和标签，自发布之日起执行。

批准澳大利亚生物资源公司生产的鸡毒支原体活疫苗（TS-11）株在我国再注册，核发《进口兽药注册证书》，并发布修订后的产品质量标准、说明书和标签，自发布之日起执行。此前发布的该产品兽药质量标准、说明书和标签同时废止。

批准美国礼蓝动物保健有限公司英国生产厂生产的阿维拉霉素预混剂在我国再注册，核发《进口兽药注册证书》，并发布修订后的产品质量标准、说明书和标签以及最高残留限量（试行）和残留检测方法标准（试行），自发布之日起执行。此前发布的该产品兽药质量标准、说明书和标签同时废止。

批准英特威国际有限公司德国厂等3家公司生产的盐酸土霉素注射液等共11种兽药产品在我国变更注册。

特此公告。

附件：1.进口兽药注册目录

2.质量标准（略）

3.说明书和标签

4. 阿维拉霉素最高残留限量（试行）和残留检测方法标准（试行）

农业农村部
