# 国家文物局关于伪满洲国哈尔滨警察厅旧址保护规划的意见

文物保函〔2019〕49号

黑龙江省文物管理局：

你局《关于<伪满洲国哈尔滨警察厅旧址保护规划>的请示》（黑文管字〔2018〕6号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）加强对旧址不同历史时期功能特征要素的研究梳理，补充评估1998年维修改造工程对文物建筑的影响，进一步判别有必要且可恢复的历史原状。补充必要的视线分析、文物本体沉降情况分析。

（二）适当扩大建设控制地带范围并优化边界，宜将现有主干道交叉路网自然围合所形成的空间作为建设控制地带。应基于场地高差关系，明确建筑控高的参考基准。

（三）应加强保护措施与评估结论的对应性，细化措施具体范围和内容。

（四）展示规划应加强与东北抗联博物馆的协调统筹；补充场地交通流线规划。

（五）补充与相关规划的衔接内容。

（六）校核、规范图文表达。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见对规划进行必要修改和完善，经你局核准后，依照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，报请黑龙江省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好伪满洲国哈尔滨警察厅旧址的各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年1月14日
