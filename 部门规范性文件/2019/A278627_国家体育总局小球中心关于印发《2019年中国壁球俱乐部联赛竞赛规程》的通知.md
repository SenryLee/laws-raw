# 国家体育总局小球中心关于印发《2019年中国壁球俱乐部联赛竞赛规程》的通知

## 小球中心关于印发《2019年中国壁球俱乐部联赛竞赛规程》的通知

小球字〔2019〕207号

各有关单位：

为促进壁球运动的普及和发展，提高壁球项目竞技水平，体育总局小球中心、中国壁球协会将于2019年7月12日至14日、8月2日至4日、11月1日至3日分别在北京市、上海市、山东省青岛市举办2019年中国壁球俱乐部联赛北区、南区比赛及全国总决赛。

现将竞赛规程印发，请积极组织参加比赛。

附件：2019中国壁球俱乐部联赛竞赛规程

体育总局小球中心

2019年6月25日
