# 中国气象局关于政协十三届全国委员会第二次会议第1099号（经济发展类077号)提案答复的函

中气提字〔2019〕2号

朱定真委员 ：

您提出的《关于聚力精准施策开展第三次全国农业气候区划的提案》（第1099号）收悉。经商农业部，现答复如下：

农业气候区划对实现农业气候资源的合理利用、因地制宜地安排农业生产、优化农业产业结构、提高资源开发的总体效益等方面具有重要的借鉴意义。我国在20世纪60年代中期和80年代初期先后完成了第一次和第二次全国农业气候区划，对合理利用全国气候资源、优化农业生产布局与结构、保护生态环境等作出了重要贡献。但随着我国农业产业结构的不断调整以及气候条件、气候资源本身的变化，原有农业气候区划已不能反映客观情况，不能满足当前农业发展的需要。您建议开展新一轮农业气候区划工作很有必要，我局将联合农业等有关部门深入研究，积极推进。

近年来，各级气象部门围绕种植结构调整、“一县一品、一乡一业”等需求，积极开展农业气候区划及相关气象服务保障工作，服务农业农村发展，为乡村振兴、精准脱贫国家战略提供系列化气象服务保障。一是强化顶层设计，规范技术支撑。《中共中国气象局党组关于贯彻落实乡村振兴战略的意见》（中气党发〔2018〕94号）明确提出“结合农业优化发展区和农业现代化先行区建设，明确不同区域发展重点，优化全国农业气象服务布局。开展精细化农业气候资源、农业气象灾害区划、气候变化对农业结构定量化分析评估”。2018年，中国气象局减灾司制定《精细化农业气候区划产品制作基本规程》，明确了精细化农业气候区划产品技术要求、制作流程和常用方法。同时，逐步推进农业气象大数据平台建设和新技术应用，为动态精细化农业气候区划提供技术支撑。二是强化对下指导，发挥各省积极性。国家气象中心利用1981-2010年农业气候资源要素资料，牵头完成《中国精细化农业气候资源图集》，有效指导了各省农业气候资源区划工作。同时，各省因地制宜，积极开展本地农业气候资源区划，并取得了显著的社会效益和经济效益。目前，累计制作省市县三级精细化农业气候区划、农业气象灾害风险区划3564项、5297项，涵盖大宗作物、经济林果、特色农产品等，充分发挥气象为农服务“趋利避害”作用，为当地种植结构调整、引种等提供科学依据。三是强化农业应对气候变化工作。已完成《中国农业应对气候变化评估报告》，出版两版《农业应对气候变化蓝皮书》，分析了我国农业气候资源变化、农业气象灾害变化、农业病虫害变化、农业种植制度变化及其对粮食的影响。此外，气候变化背景下东北主产区粮食安全影响评估、玉米北扩风险评价等研究为地方政府农业发展提供了科技支撑。气候变化对西藏冬虫夏草、宁夏马铃薯、西北区域春小麦、富士苹果等作物气候适应性研究取得了显著的社会经济效益。

下一步，我局将积极争取相关部门经费支持，联合农业等部门，力争全面、系统地开展第三次全国农业气候区划，为农业供给侧改革、“三区”划定等提供科学依据；进一步完善精细化农业气候区划技术，逐步发展和应用动态化精细化农业气候区划技术；依托科研项目支持，持续开展农业应对气候变化关键技术科研能力和基础能力建设。
