# 国家邮政局关于政协十三届全国委员会第二次会议第0769号（工交邮电类029号）提案答复的函

## 关于政协十三届全国委员会第二次会议第0769号（工交邮电类029号）提案答复的函

国邮函〔2019〕119号

张占斌委员：

您提出的《关于促进我国快递业健康发展的提案》（第0769号）收悉。经商国家发展改革委、中央编办、财政部，现答复如下：

一、关于扩大国家邮政局的监管范围和监管责任

根据“三定”规定和法律法规，国家邮政局主要负责邮政普遍服务和快递行业监管等工作。物流、大件货品配送等，根据职责分工由相关部门负责监管。近年来，新产业、新业态、新商业模式不断涌现，我局将积极适应新形势工作需要，按照“三定”规定和相关法律法规，认真做好行业监管工作，同时坚持稳中求进的原则逐步将符合条件的新业态企业纳入行业管理范畴。关于将国家邮政局更名为国家邮政寄递业监督管理局的建议，中央编办将结合深化机构改革工作统筹研究。

二、关于按竞争中性原则启动中国邮政集团改革

（一）关于邮政普遍服务采取外包方式、短期通过“政府购买服务”方式，改革其财政补贴方式与规模

根据《中华人民共和国邮政法》《邮政普遍服务标准》等相关法律法规，中国邮政集团公司承担提供邮政普遍服务的义务，中央财政对其提供邮政普遍服务、特殊服务给予补贴。在中央财政的支持和邮政集团公司的努力下，截至目前，邮政普遍服务和特殊服务业务量已达200亿件/年，实现全国建制村直接通邮率99%以上，有力地保障了该项工作的顺利开展。我们赞同委员提出的进一步提高邮政普遍服务和特殊服务质量的建议，将加强对补贴资金使用的监督，强化预算绩效管理，确保邮政集团公司做好“最后一公里”的投递。

（二）关于邮政集团实行混合所有制改革

支持中国邮政集团公司按照中央深化国有企业改革的精神、《国务院关于国有企业发展混合所有制经济的意见》（国发〔2015〕54号）等文件要求，实施混合所有制改革，推动中国邮政集团公司建立有效制衡的公司法人治理结构和灵活高效的市场化经营机制，加快产业布局优化、业务结构调整和战略性重组，提高运行效率，提升综合实力，促进国有资产保值增值。目前，有关部门正在推进该项工作。

三、关于发挥邮政的基层网络优势，支持“三农”发展，服务乡村振兴战略

我局联合有关部门主要做了以下工作：一是加快基础设施建设，完成空白乡镇邮政营业场所补建8440个，推进西部和农村地区邮政设施改造。二是联合国家发展改革委等7部门印发了《关于推进邮政业服务乡村振兴的意见》，对持续提升邮政业服务“三农”能力，加快推进农业农村现代化提出了具体指导意见。三是实施“邮政在乡”工程，支持邮政企业建设县乡村三级物流配送体系，服务农村电商发展，助力乡村振兴。2018年邮政企业带动农特产品进城配送量29.5万吨，实现交易额47.6亿元，惠及贫困人口18万户，电商分销达到110.9亿元。四是推动农村地区邮乐购站点加快布局，运用线上线下双网，打通城市到村一级农产品上行和工业品下乡渠道，实现“互联网+”信息化进村服务，助力健全农村消费市场。目前，全国已运营邮乐购站点达45.6万个。

四、关于“培育具有全球竞争力的跨境物流企业集团”

跨境寄递是邮政业发展的重点。与美国、德国等欧美发达国家相比，我国缺乏大型国际寄递物流企业，跨境寄递服务能力弱，国际寄递范围窄。我们赞同委员提出的培育具有全球竞争力的跨境物流企业集团的建议。近年来我局在支持邮政、快递企业提升跨境寄递服务能力等方面开展了多项工作：一是支持邮政企业发挥全球通达性强的优势，加强跨境物流通道布局。会同海关总署开展国际邮件互换局（交换站）审批和设立，先后批复12个国际邮件互换局（交换站），使全国总数达到70个。二是推动邮政企业完善跨境寄递供应链服务，加强重点区域的国际多边和双边合作，创新丰富寄递产品，服务跨境电商企业能力逐步提升。目前，邮政寄递范围覆盖200多个国家和地区。三是会同商务部、海关总署联合印发了《关于促进跨境电子商务寄递服务高质量发展的若干意见(暂行)》，提出加快完善跨境寄递国际航空运输网络、提升跨境寄递服务全程通关便利等任务，为推动提案内容落地提供了解决方案。四是推进邮政业服务“一带一路”建设，与万国邮联签署“一带一路”合作框架意向书，推动万国邮联制定铁路运邮指南。中欧班列邮件可运达欧洲23国，新增义乌、东莞、郑州3个试点城市，重庆实现进口邮件零突破，完成从义乌到莫斯科首次快件运输试点。

下一阶段，我们将加快供给侧结构性改革，着力培育行业国际品牌。一是将聚焦国际化，支持邮政、快递企业加快跨境寄递基础设施建设。鼓励加强国际航空运能建设，加快推动中欧班列运输邮件常态化运行。二是开展邮政、快递领域双多边交流合作，为跨境寄递企业拓展渠道、优化网络、完善通关和协调机制，提高跨境服务能力搭建国际交流合作平台。三是积极参与万国邮联规则制定，稳妥推进万国邮联在服务产品、终端费等关键领域改革，维护多边机制，维护我国正当权益和跨境企业合法权益。

五、关于推进快递业从管理到治理的现代化

一是安全监管方面。对于委员提出的“现阶段宜守住安全、环保、公平竞争等普适性原则，谨慎立法，底线监管”的建议，我们高度赞同。近年来，我局持续加强寄递渠道安全监管，狠抓“三项制度”落实，出台《邮件快件实名收寄管理办法》，开展实名信息数据安全防护评估，全行业实名率达到98.9%，安检机配置累计超过1.3万台。试点安全风险分级分类监管。加快“绿盾”工程建设，加强行业数据资源整合，更好支撑智慧监管。开展涉枪涉爆隐患集中整治专项行动。加强寄递渠道非洲猪瘟疫情防控，配合做好反恐、禁毒、扫黄打非、打击侵权假冒、濒危野生动植物保护等工作。下一阶段，我局将推动修订《邮政行业安全监督管理办法》，细化安全监管、环境保护有关制度，力争2019年内出台。此外，我局将深入贯彻《快递暂行条例》有关规定，与公安、国家安全、海关、工商行政管理等有关部门相互配合，建立健全快递安全监管机制，强化快递业协同治理。

二是在绿色发展方面。联合国家发展改革委等9部门出台关于协同推进快递业绿色包装工作的指导意见，制修订《快递封装用品》系列国标和《邮件快件包装填充物技术要求》等2项行业标准，出台《快递业绿色包装指南（试行）》。行业电子运单使用率达到92%，组织申通等6家品牌企业开展可循环中转袋应用试点，举办快递绿色包装产业联盟、快递绿色包装进校园等活动。推广应用新能源和清洁能源车辆、甩挂运输和多式联运，行业新能源汽车保有量超过1.2万辆。下一阶段，我局将采取措施进一步加快绿色邮政建设进程，重点研究推进邮件快件包装绿色认证和绿色采购，推广应用循环中转袋、循环快递盒；研究设立邮政业绿色发展统计指标，将绿色发展作为对市场主体监管重要内容；在部分城市开展行业绿色发展试点。

三是在标准建设和引入大数据治理和区块链技术方面。近年来，我局先后组织制定并出台《快递服务》等国家标准和《快递专用电动三轮车技术要求系列》等多项行业标准，引导行业企业规范服务行为，提升服务质量。同时，实施创新驱动发展战略，系统部署邮政业科技创新工作。印发《国家邮政局关于促进邮政行业科技创新工作的指导意见》《邮政业应用技术研发指南》等文件，组织开展首批行业研发中心认定和首届行业科技成果评选，着力推动大数据、区块链、人工智能等新技术新成果转化应用。下一步，我局将进一步完善邮政业标准体系，加强对标准实施情况的监督指导，推动标准有效实施；加强科技创新引导，鼓励联合攻关，促进人工智能、大数据、云计算等先进科技与邮政业实际密切结合，推动邮政业实现高质量发展。

感谢您长期以来对邮政快递工作的关心和支持！
