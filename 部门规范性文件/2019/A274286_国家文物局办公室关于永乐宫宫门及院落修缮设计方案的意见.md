# 国家文物局办公室关于永乐宫宫门及院落修缮设计方案的意见

办保函〔2019〕64号

山西省文物局：

你局《关于审批芮城县永乐宫宫门及院落修缮设计方案的请示》（晋文物〔2018〕127号）收悉。经研究，所报方案经过多次论证，仍未按照我局历次审批意见的要求进行认真修改、完善，我局暂不同意所报方案。

请你局指导地方政府和有关单位，按照我局《关于芮城永乐宫（宫门、院落、消防通道、泄洪渠）修缮工程设计方案的意见》（办保函〔2018〕331号）各项要求，对所报方案切实加强审核，认真进行修改、调整，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月23日
