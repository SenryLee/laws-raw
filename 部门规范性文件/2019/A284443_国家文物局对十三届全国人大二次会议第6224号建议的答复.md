# 国家文物局对十三届全国人大二次会议第6224号建议的答复

文物保函〔2019〕637号

徐启方代表：

您提出的《关于将周原、雍城国家考古遗址公园纳入世界文化遗产申报规划的建议》收悉，现答复如下。

周原遗址位于陕西岐山脚下，南临渭河，是西周青铜器的重要出土地点。多年来，通过在岐山凤雏村和扶风召陈村发掘西周时期的大型宫室建筑基址，在扶风庄白和岐山董家发现大量有重要历史价值的青铜器，在岐山凤雏和扶风齐家出土一批有刻辞的甲骨，证实这里是周人“岐周”所在，也是西周王朝的政治中心，使该地成为探索和研究西周社会政治、经济、文化最重要的遗址。1982年国务院将周原遗址公布为第二批全国重点文物保护单位。国家文物局先后安排国家重点文物保护专项补助资金2700余万元，用于周原遗址考古发掘、保护修缮、环境整治、规划编制等工作。

秦雍城遗址位于陕西省凤翔县南，是春秋至战国中期秦国早期都城。城址总面积占地11平方公里。经勘探，发现城内道路纵横交错，布局严整，已发现宫殿区三处。城西南为秦公陵区，有大型墓葬和车马坑四十三座，分为十三座陵园，最大一座面积为40多万平方米。1988年国务院将秦雍城遗址公布为第三批全国重点文物保护单位。国家文物局先后安排国家重点文物保护专项补助资金5400余万元，用于考古发掘、保护修缮、环境整治、规划编制等工作。

近年来，世界遗产申报工作的难度逐渐加大。根据世界遗产委员会新施行的“限额制”，一个缔约国每年最多只能申报一项世界遗产。同时，世界遗产委员会不断推进世界遗产均衡性的全球战略，明确向没有世界遗产或世界遗产较少的国家，以及遗产类型较少的类别倾斜；而对世界遗产大国的限制则不断增多。

我国是世界遗产大国，目前拥有世界遗产53项，其中文化遗产36项，居世界第二。联合国教科文组织世界遗产中心和国际古迹遗址理事会等专业咨询机构对我国等世界遗产大国的申报项目，往往提出更高的标准。按照《保护世界文化和自然遗产公约》及其《操作指南》的规定，申报世界文化遗产的项目，应该具有全世界范围内的突出普遍价值，较好的保存现状，真实性和完整性较高，扎实的保护管理基础，以及利益相关者对遗产保护的积极态度。这都要求我国的申报项目要在各方面做好充分的准备。

周原遗址、秦雍城遗址申报世界遗产工作基础相对薄弱。国家文物局将指导当地政府和文物行政部门，深化对周原遗址、秦雍城遗址的突出普遍价值的研究和提炼，明确遗产定位，清晰阐述其符合的世界文化遗产标准，并与国内外同类型遗产进行深入对比分析；进一步促进保护管理机构建设和管理能力提高，制订颁行切实有效的法律法规，妥善保护遗产本体，并注重与利益相关者的沟通协调。

国家文物局将按照《国家文物保护专项资金管理办法》的规定，在文物修缮、环境整治等方面，继续对周原遗址、秦雍城遗址保护给予尽可能的资金支持。在条件成熟后，可根据当地政府申请，考虑将周原遗址、秦雍城遗址列入《中国世界文化遗产预备名单》。

衷心感谢您对我国世界文化遗产工作的关注和支持！

此函。

国家文物局
