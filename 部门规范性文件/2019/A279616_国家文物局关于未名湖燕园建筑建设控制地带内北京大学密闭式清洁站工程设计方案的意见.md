# 国家文物局关于未名湖燕园建筑建设控制地带内北京大学密闭式清洁站工程设计方案的意见

文物保函〔2019〕712号

北京市文物局：

你局《关于未名湖燕园建筑建设控制地带内北京大学密闭式清洁站工程的请示》（京文物〔2019〕905号）收悉。经研究，我局原则同意未名湖燕园建筑建设控制地带内北京大学密闭式清洁站工程建设方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步优化设计方案，补充说明密闭式清洁站和燕园建筑群的关系，详细说明密闭式清洁站设计和燕园建筑群建筑特色的关系，合理规划垃圾转运站与小车停车场之间的空间距离，确保留出足够的垃圾车转换空间。

（二）进一步完善文物影响评估报告，补充说明旧垃圾转运站在图示上的位置、建筑形制及现状照片，补充新旧垃圾转运站与文物建筑的距离及对文物环境风貌的影响。

（三）新建垃圾转运站建筑风格应保持与周围建筑相一致，不建议对垃圾转运站外墙面进行垂直绿化，并充分考虑屋顶绿化的日后管理。

（四）进一步校核方案图文，做到前后一致，科学严谨。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年7月15日
