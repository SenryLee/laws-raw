# 国家文物局办公室关于中兴文物建筑装饰工程有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕296号

北京市文物局：

你局《关于中兴文物建筑装饰工程有限公司申请文物保护工程施工资质证书单位名称变更的请示》（京文物〔2019〕434号）收悉。

经研究，我局同意中兴文物建筑装饰工程有限公司文物保护工程施工一级资质证书中的单位名称由“中兴文物建筑装饰工程有限公司”变更为“中兴文物建筑装饰工程集团有限公司”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局办公室

2019年4月18日
