# 交通运输部办公厅关于做好航道管理与养护统计调查工作的通知

交办水函〔2019〕1764号

各省、自治区、直辖市交通运输厅（局、委），长江航务管理局：

《航道管理与养护统计调查制度》已经国家统计局重新备案（备案号为国统办函〔2019〕334号），为切实做好航道管理与养护统计调查工作，现将有关事项通知如下：

一、各省、自治区、直辖市交通运输厅（局、委）和长江航务管理局确定本单位统计数据报送的负责部门、人员，填写《航道管理与养护统计调查工作联系表》（见附件）并加盖公章，于2019年12月20日前传真至部水运局。

二、严格落实《航道管理与养护统计调查制度》（可登陆http://xxgk.mot.gov.cn/jigou/zhghs/201910/t20191021_3286603.html下载），每年1月31日前将上年度各项航道管理与养护统计表、数据变动情况说明、数据分析和建议等报送部水运局。

三、各单位要高度重视，依法履职，严把数据质量关，坚决杜绝统计造假、弄虚作假。统计调查工作中如遇问题，及时报部。
