# 国家文物局关于长城保护区划内北京市延庆区昌赤路（王家山-白河堡段）道路工程建设项目的意见

文物保函〔2019〕848号

北京市文物局：

你局《关于长城保护范围及建控地带内北京市延庆区昌赤路（王家山-白河堡段）道路工程设计方案的请示》（京文物〔2019〕1075号）收悉。经研究，我局原则同意在长城保护区划内实施北京市延庆区昌赤路（王家山-白河堡段）道路工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）细化拟建隧道、桥梁、道路设计方案及施工方案，补充施工期间的长城临时性保护和监测措施，以及相关应急预案。

（二）在满足设备安装需求的前提下，尽可能降低隧道管理站监控大厅及辅助用房的设计高度，严格控制建筑规模和体量。

（三）强化道路及建筑周边绿化等相关措施，缓解项目对长城本体及其环境景观的负面影响。

（四）在适当区域设置长城保护标志、保护界桩、展示说明牌等标识、展示设施。

二、请你局组织专业考古机构对拟建项目相关区域做全面的考古调查、勘探和必要的考古发掘，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年8月20日
