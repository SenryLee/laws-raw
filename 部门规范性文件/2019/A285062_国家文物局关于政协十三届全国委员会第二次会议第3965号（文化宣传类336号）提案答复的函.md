# 国家文物局关于政协十三届全国委员会第二次会议第3965号（文化宣传类336号）提案答复的函

文物博函〔2019〕890号

耿东升委员：

您提出的《关于博物馆应配备多语种展览文字说明的提案》收悉，现答复如下。

博物馆是以教育、研究和欣赏为目的的非营利性组织。加强博物馆规范管理，提升博物馆社会服务水平，对于构建公共文化服务体系、提升国民素质、传承中华优秀传统文化具有重要意义。近年来，我国博物馆事业蓬勃发展。截至2018年底，全国博物馆达5354家，年举办展览2.6万个，年举办各类教育活动20余万次，参观数达到11.26亿人次。博物馆已成为人民对美好生活向往的重要部分。

我局高度重视博物馆陈列展览质量管理，近年来先后出台了多个相关政策文件、标准规范。您提出的相应增加展览说明文字语种的建议，对于博物馆通过展览展示更好地发挥社会教育功能具有重要参考价值，相关内容在《文物展品标牌》《博物馆开放服务规范》等标准中已包含相关内容。《文物展品标牌》中明确要求：展品标牌设计应简洁明了，便于观众阅读，不影响展品内容的表达和展示；说明文字较多的标牌，可根据需要制作成背板形式；展品标牌语言文字应使用汉语、外国语言和少数民族语言，英语一般情况下作为第一外国语种使用，其他外国语言可根据陈列展览需要自定；非特殊内容或行业的常设陈列均应使用英语作为展品说明的第二语言文字，临时展览可根据需要使用英语。各地博物馆按照相关标准要求，加强展示说明的规范性管理，不断提升观众观展体验。部分博物馆在展览介绍及展品说明中探索增加出借展品国家母语、少数民族地区民族语言、无障碍盲文等。

下一步，国家文物局将继续加强博物馆展览有关政策与标准的制定和落实工作，指导各级博物馆贯彻《文物展品标牌》《博物馆开放服务规范》等相关推荐性国家标准，鼓励通过二维码、蓝牙语音、多媒体展示等辅助手段拓展展品标牌表现形式，为观众带来更好的观展体验。

感谢您对博物馆事业的关心和支持。

国家文物局

2019年8月27日
