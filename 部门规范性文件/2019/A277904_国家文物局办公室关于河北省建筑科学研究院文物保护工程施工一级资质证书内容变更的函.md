# 国家文物局办公室关于河北省建筑科学研究院文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕404号

河北省文物局：

你局《关于河北省建筑科学研究院文物保护工程施工一级资质证书内容变更的请示》（冀文物字〔2019〕10号）收悉。

经研究，我局同意河北省建筑科学研究院文物保护工程施工一级资质证书中单位名称由“河北省建筑科学研究院”变更为“河北省建筑科学研究院有限公司”，经济性质由“全民所有制”变更为“有限责任公司（国有独资）”，注册资金由“605万元”变更为“23900万元”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局办公室

2019年5月27日
