# 自然资源部公告2019年第58号——自然资源部关于2019年国家测绘成果质量监督抽查结果的公告

## 自然资源部公告

2019年第58号

## 自然资源部关于2019年国家测绘成果质量监督抽查结果的公告

为深入贯彻落实《中共中央 国务院关于开展质量提升行动的指导意见》（中发〔2017〕24号），提升测绘成果质量和自然资源管理水平，自然资源部于2019年3月至11月组织开展了2019年国家测绘成果质量监督抽查工作。现将抽查结果公布如下：

抽查对象包括三类：一是甲级测绘资质单位2018年完成的规划测量项目成果；二是2018年测绘成果质量监督抽查中不合格项目单位的二次抽查项目；三是2018年未通过抽检单位的二次抽查项目。

2018年完成的规划测量项目成果抽查了40个，成果质量批合格39个，批不合格1个。对不合格项目单位的第二次抽查项目4个，批合格2个，批不合格2个。对未通过抽检单位的第二次抽查项目3个，均合格。

对2019年测绘成果质量批不合格项目，将向受检单位下达限期整改通知书，在全国测绘行业信用管理中记为不良信息。对2019年二次抽查不合格项目，在全国测绘行业信用管理中再次记为不良信息，约谈受检单位，下达限期整改通知书，并予以通报。

特此公告。

附件：2019年国家测绘质量监督抽查结果一览表
