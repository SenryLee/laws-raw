# 国家文物局关于京杭运河故道保护区划内董家口至梁山公路宁阳至梁山段建设项目的意见

文物保函〔2019〕183号

山东省文物局：

你局《关于报送董家口至梁山公路宁阳至梁山段跨越京杭运河故道保护设计方案修改稿的请示》（鲁文发〔2018〕106号）收悉。经研究，我局原则同意采取方案二在京杭运河故道保护范围和建设控制地带内实施董家口至梁山公路宁阳至梁山段建设项目。

一、方案尚需作以下必要的修改和完善：

（一）应在大比例尺地形图上准确标示拟建项目与京杭运河故道保护范围和建设控制地带的位置关系，并对照相关管理规定进一步调整方案相关设计。

（二）应充分考虑京杭运河故道的保护需求，进一步优化拟建桥梁设计方案，加大桥梁跨距，桥墩不得直接占压京杭运河故道的河堤以及经过考古调查、勘探和发掘工作确认的其他等重要遗址、遗迹。

（三）应细化拟建项目施工方案，补充施工和运营期间各类振动、沉降等对京杭运河故道影响监测措施、应急预案、临时性保护措施、环境保护要求、污染物处置要求，以及施工结束后的场地清理和环境修复措施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月19日
