# 国家体育总局科教司关于加强备战东京奥运会2019-2020年度冬训期间医疗保障工作的通知

## 体育总局科教司关于加强备战东京奥运会2019-2020年度冬训期间医疗保障工作的通知

体科字〔2019〕188号

有关运动项目管理中心、中国足球协会、中国篮球协会、各改革试点项目协会、各国家队：

为进一步做好备战东京奥运会医疗保障工作，按照总局办公厅《关于加强备战东京奥运会2019-2020年度冬训工作的指导意见》的要求，加大伤病防治力度，确保运动员以最佳身体状态参赛，经研究，制定了加强冬训期间医疗保障工作措施，现通知如下：

一、加大医疗与康复专家下队巡诊力度，加强伤病排查，确保重点项目国家队全覆盖。

运医所将组织医疗与康复专家，根据重点项目国家队的训练安排，逐一下队巡诊，协助排查伤病，并建立专家与重点项目国家队结对子的服务模式，帮助解决重点队员疑难伤病的诊断、治疗与康复等。请各国家队根据各自实际需求，填写专家下队巡诊需求表（附件1）。运医所随后将组织专家下队巡诊，并确保重点项目国家队全覆盖。

二、建立重点运动员健康档案，制定针对性的伤病防治方案，确保重点运动员一人一档，一人一案。

运动员健康档案是做好国家队医疗保障的基础，为此每年运医所组织开展国家队运动员健康体检工作。请今年尚未进行体检的国家队填写体检申请表（附件2）。运医所将根据需求安排运动员前往体育医院或选派专家下队查体，并个性化评估健康状态水平，确保重点运动员一人一档。

运动员伤病档案是做好国家队医疗保障的关键，国家队运动员医疗服务系统（http://yunyi.onsite.org.cn）已经于2018年4月正式上线运行。鉴于部分协会改革实体化，现请具体负责国家队医疗保障的各项目中心或协会重新填写用户申请表（附件3）。今后凡是需要预约指定医院绿色通道就诊、申请专家巡诊会诊、伤病报告和运动员健康体检等，均需通过此管理平台进行。运医所将指定医疗与康复专家对接，建立完善重点运动员伤病档案，配合国家队制定重点运动员针对性的伤病防治方案，确保重点运动员一人一案。

三、规范国家队医疗与康复工作的管理要求，确保医疗与康复工作有计划、有记录、可追溯、可追责。

冬训期间将强化伤病报告制度，一般伤病每周报告一次，每周六通过国家队医疗服务管理平台报告近一周重点运动员伤病情况；重大突发伤病以最快通讯方式及时报告，以便第一时间组织专家会诊和安排前往指定医院就诊。

请各国家队严格规范冬训期间各项医疗与康复工作，明确专人负责，制定具体工作计划与保障措施；重新梳理随队的各类医务人员，认真填写国家队医务人员信息登记表（附件4）；各国家队要务必加强医务人员队伍管理和教育培训，尤其是社会聘用和短期聘用人员（包括各省市选派到国家队的医务人员），明确各类人员职责范围，保证运动员用药合理安全，禁止超执业范围的医疗行为，对造成严重后果的医疗行为给予问责；严格执行各项核心医疗制度和管理规范，严格药品采购和使用管理，及时完整书写运动员伤病诊断、治疗和康复等各类医疗文书，确保有记录、可追溯。

四、加强冬训期间日常医务监督，做好伤病预防，降低伤病发生率。

强化科学训练、做好伤病预防是提高训练质量和效益的有效途径，建议各国家队加强运动性疲劳及其相关疾病的预警和早期诊治。冬训期间各国家队务必做好日常医务监督，加强冬训期间伤病防护，及时发现、正确处置运动性伤病，降低重大伤病发生率。对于新发伤病，如诊断不明确或治疗效果不好，应第一时间联系运医所，由运医所组织专家进行确诊，制定科学的处置方案，最大限度的做好医疗服务保障。

需各单位提交的有关材料（附件1-4），请于12月11日下午5：00前，提交运医所国家队医务管理处。
