# 农业农村部办公厅关于在全国遴选70个最具特色乡村庆丰收活动的通知

农办市〔2019〕11号

各省、自治区、直辖市农业农村（农牧）厅（局、委）：

设立中国农民丰收节是党中央、国务院作出的重大决策。2019年中国农民丰收节相关组织工作已经全面启动，丰收节庆祝活动将进一步下沉到县乡村，注重提高广大农民的参与度和基层覆盖率。根据工作部署，中国农民丰收节组织指导委员会将在全国遴选70个最具特色、最具代表性的乡村庆丰收活动，作为国家层面的重要系列活动之一，予以重点指导支持，在丰收节当天通过主流媒体进行全国同步直播，并制作多形态融媒体产品向国内外推送，形成热烈的舆论环境，为新中国成立70周年营造良好的氛围。

一、遴选方法

本次遴选工作采取申报与评选相结合的办法，每个省（区、市）申报3—4个本地区最具特色乡村庆丰收活动。丰收节组织指导委员会办公室将组织相关专家，从中评选出70个全国最具特色乡村庆丰收活动。

二、遴选标准

（一）下沉基层。庆祝活动原则上在县乡村举办，农民群众参与基础好。（二）代表性强。庆祝活动具有优秀传统农耕文明的典型意义，或者具有中国革命、建设、改革等历史时期的时代性特征，或者体现农业农村高质量发展的新成就、新面貌。（三）特色鲜明。庆祝活动能够充分展示农耕文化传承、多姿多彩的民俗风情、千姿百态的乡村美景、欣欣向荣的乡村产业，以及农民的幸福生活和时代风采，具有鲜明的地域或民族特色。（四）组织有力。必须具有一定的组织基础，具备相应的同步直播条件，积极配合全国直播工作。丰收节组织指导委员会办公室将组织各地成立全国直播团队，对70个直播点进行统筹协调、人员培训和现场指导。

三、其他事项

（一）请各省（区、市）农业农村部门高度重视，认真做好省级遴选把关和组织报送工作，填写《全国70个最具特色乡村庆丰收活动申请表》（附件1），并于6月20日前以省为单位，发送至农业农村部市场与信息化司（中国农民丰收节组织指导委员会办公室），并一同报送本省（区、市）《2019年丰收节组织工作省级联系人表》（附件2）。

（二）对各省（区、市）报送至我部但未纳入70个乡村庆丰收活动的，组织指导委员会将统筹考虑，择优作为国家层面其他相关活动予以指导支持。
