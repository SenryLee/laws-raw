# 中共自然资源部党组关于关凤峻、李平同志免职退休的通知

自然资党任〔2019〕53号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中央军委后勤保障部军事设施建设局，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

部党组2019年3月13日研究决定：

免去关凤峻地质勘查管理司巡视员职务，退休；

免去李平人事司巡视员职务，退休。

中共自然资源部党组

2019年3月28日
