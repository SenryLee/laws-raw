# 民政部办公厅关于公布第一批全国乡镇政府服务能力建设典型经验的通知

民办函〔2019〕131号

各省、自治区、直辖市民政厅（局），各计划单列市民政局，新疆生产建设兵团民政局：

2017年2月，中办、国办印发《关于加强乡镇政府服务能力建设的意见》，这是以习近平同志为核心的党中央从战略和全局的高度作出的重大决策部署。各地深入学习贯彻，扎实推进乡镇政府服务能力建设，探索形成了一批好经验好做法。为充分发挥典型示范作用，推动乡镇政府服务能力建设整体水平不断提升，民政部在各地推荐的基础上，遴选确定黑龙江省桦南县《创新模式“强四能”，打造乡镇政府服务能力建设升级版》等10个典型经验为第一批全国乡镇政府服务能力建设典型经验（相关经验材料将在民政部网站公布）。

各地要加强宣传推介，学习借鉴好这些典型经验，结合实际加大试点示范工作力度，因地制宜挖掘和培育一批本地典型，引领乡镇政府服务能力建设不断取得新进展。各地在实践中形成示范作用明显、可复制可推广的典型经验，要及时报送民政部基层政权建设和社区治理司。

附件：第一批全国乡镇政府服务能力建设典型经验

民政部办公厅

2019年11月21日

## 第一批全国乡镇政府服务能力建设典型经验

1.黑龙江省桦南县：创新模式“强四能”，打造乡镇政府服务能力建设升级版

2.江苏省江阴市：以民为本、服务为先，扎实推进乡镇政府服务能力建设

3.山东省龙口市：构建科学体系，强化保障落实，不断提升乡镇政府服务能力水平

4.甘肃省武威市凉州区：聚焦民生促发展，着力打造服务型乡镇政府

5.江西省乐安县：搭建“1134”平台，打通服务群众最后一公里

6.吉林省梨树县：整合机构、简政放权、执法下沉，为乡镇政府服务添活力

7.湖北省秭归县：聚焦服务职能，优化体系机制，全面提升乡镇政府服务能力

8.山东省临邑县：深化“放管服”改革，提升为民服务水平，着力加强乡镇政府服务能力建设

9.宁夏回族自治区吴忠市利通区：深化“3422”改革，乡镇政府服务能力建设谱写新篇章

10.广东省东莞市：大力推进简政强镇事权改革，着力提升乡镇政府服务能力
