# 农业农村部对十三届全国人大二次会议第6023号建议的答复

## 对十三届全国人大二次会议第6023号建议的答复

农办议〔2019〕341号

您提出的关于加大贫困地区产业后扶高质量发展政策供给的建议收悉。经商国务院扶贫办，现答复如下。

一、关于防止返贫的相关政策

近年来，我部会同国务院有关部门，按照中央打赢脱贫攻坚战的部署，聚焦“两不愁三保障”的目标，大力推进产业扶贫，巩固脱贫攻坚成果，坚决防止大面积返贫。一是严把退出关。始终把提高脱贫质量放在首位，瞄准脱贫目标，严把脱贫标准，规范退出程序，坚决防止急功近利、弄虚作假、搞突击脱贫，坚决防止出现数字脱贫、算账脱贫。二是建立防止返贫机制。重点扫清因病返贫这一农村减贫面临的最大障碍，通过完善大病保险、医疗救助等各方面制度，防止返贫。支持部分地区探索脱贫人口商业补充医疗保险，切实降低其医疗支出负担。三是坚持脱贫不脱政策。明确要求贫困人口退出后一段时间内，帮扶政策不变、力度不减，巩固脱贫效果，实现稳定脱贫，防止返贫。

二、关于发布农业农村产业发展规划和目录

2018年以来，我部认真贯彻落实《乡村振兴战略规划（2018—2022年）》部署，发掘农业农村资源，大力发展乡土特色产业。一是加强政策引导。近期，国务院印发了《关于促进乡村产业振兴的指导意见》，提出突出优势特色，培育壮大乡村产业。要在做强现代种养业、做精乡土特色产业、提升农产品加工流通业、优化乡村休闲旅游业、培育乡村新型服务业、发展乡村信息产业等方面下功夫，推进乡村产业振兴。二是加强规划引导。农业农村部正在组织编制《全国乡村特色产业发展规划（2019—2025年）》，进一步明确乡村特色产业发展思路目标、重点产品、区域布局、保障措施，引导更多资源、技术向优势区域集中，加快建设一批有特色、有规模、有品牌的乡村特色产业基地或产业集群。

三、关于信息服务与共享

近年来，我部积极推进农业大数据发展和应用，加大农业数据信息资源开放共享力度，运用信息化手段提升农业管理决策和为农服务的现代化水平。一是提供重点农产品市场信息服务。2017年11月，重点农产品市场信息平台正式开通运行，以重点品种全产业链数据的采集、分析、发布、服务为主线，建立“一网打尽”式市场信息发布服务窗口，为农业生产经营主体和公众提供权威、全面、及时、有效的市场信息服务。目前，平台上报每日价格数据230多万条，电子交易结算数据2923万条，接入各类数据约20亿条，每天新增数据10多万条。二是提供“三农”综合服务。从2006年电话咨询起步，12316不断开辟服务渠道、创新服务方式、丰富服务内容，已发展成为集热线电话、网站、电视节目、广播、手机短彩信、手机APP、微博、微信等服务于一体，面向全国、服务“三农”的权威综合信息服务平台。服务对象超过70万人，12316平台全年发送短彩信3000万条，监管平台累计知识库、案例库数据超过310万条。三是加快数据分析和可视化。逐步向移动端延伸，力争向广大农民和社会公众提供更加便捷高效的服务，为全国农业大数据的发展和应用探索路子、积累经验。

下一步，农业农村部将贯彻落实《国务院关于促进乡村产业振兴的指导意见》，以实施乡村振兴战略为总抓手，以农业供给侧结构性改革为主线，围绕农村一二三产业融合发展，聚集资源要素，强化创新引领，突出集群成链，培育发展新动能，加快构建现代农业产业体系、生产体系和经营体系，筑牢产业扶贫根基，推动形成城乡融合发展格局。

感谢您对农业农村工作的关心，希望继续对我部工作给予支持。
