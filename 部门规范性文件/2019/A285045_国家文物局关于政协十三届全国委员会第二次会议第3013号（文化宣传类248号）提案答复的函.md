# 国家文物局关于政协十三届全国委员会第二次会议第3013号（文化宣传类248号）提案答复的函

文物保函〔2019〕858号

刘佳义委员：

您提出的《关于加强抗战期间国民政府军事委员会政治部第三厅历史研究和旧址保护的提案》已交由我局会同国家档案局、中央党史和文献研究院办理，现答复如下：

1937年全民族抗战爆发后，国共两党在抗日民族统一战线的旗帜下，实现国共第二次合作联合抗日。1938年4月，国民政府军事委员会政治部第三厅成立于武汉，郭沫若任厅长。第三厅主要职司宣传。1938年10月武汉失守后，第三厅迁移至重庆。在周恩来、郭沫若领导下，第三厅团结了一大批致力于抗日民主运动的进步文化工作者，大规模地进行抗日宣传，并积极开展对敌人、对国际社会的宣传工作，成为国共双方尤其是中国共产党在国民党统治区开展抗日民族统一战线活动的重要阵地。加强对第三厅历史研究和旧址保护，对继承和弘扬中华优秀传统文化，加强爱国主义教育具有重要意义。

党和政府高度重视抗战期间国民政府军事委员会政治部第三厅的历史研究和旧址保护工作。中央党史和文献研究院在党史基本著作中，对第三厅的性质、地位和作用进行了权威概述和定性。原中央党史研究室也曾指导地方党史部门编撰出版了《抗日战争初期中共中央长江局史》《中共中央南方局的文化工作》《南方局党史资料·文化工作》等一系列涉及第三厅相关内容的研究成果。2013年，国务院将重庆国民政府军事委员会政治部第三厅暨文化工作委员会旧址核定公布为第七批全国重点文物保护单位。此后，国家文物局积极支持该旧址的文物本体修缮、安防、消防和雷防文物保护项目，中央财政累计下拨文物保护专项资金754万元。2008年，湖北省人民政府将武汉国民政府军事委员会政治部第三厅旧址公布为省级文物保护单位；2017年至2018年，湖北省文物局指导对旧址的历史和现状进行了调查，完成了现存文物保护工程勘察设计，文物维修完成后将作为国民政府军事委员会政治部第三厅展览馆和武汉市第十四中学校史馆使用。

为进一步加强抗战期间国民政府军事委员会政治部第三厅历史研究和旧址保护工作，下一步，国家文物局将会同有关部门重点做好以下工作。

一是加强文物学术研究。指导相关地方系统开展对第三厅历史资料的征集整理、利用和出版工作，系统梳理第三厅包括文化工作委员会发展的历史脉络和历史事实，深入阐述第三厅的历史价值和社会价值，为提升保护、展示和利用工作水平奠定基础。

二是加强文物保护维修。指导相关地方做好全国重点文物保护单位重庆国民政府军事委员会政治部第三厅暨文化工作委员会旧址、湖北省省级文物保护单位武汉国民政府军事委员会第三厅旧址的文物本体保护和周边环境的整治，加强日常监管和养护，国家文物局将在项目和技术上给予支持。

三是促进文物的合理利用。指导相关地方突出自身特色，加强文物资料的收集使用，充分吸收最新研究成果，优化展陈大纲，不断改进旧址原状展示和主题展览，积极研发推广有特色的革命文物文化创意产品。同时要加强馆际协作和资源共享 ，形成联动效应，更好发挥同一主题革命文物的社会教育作用。

感谢您对文物事业的关心和支持！

国家文物局
