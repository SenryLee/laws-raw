# 国家文物局对十三届全国人大二次会议第2037号建议的答复

文物保函〔2019〕612号

周少政代表：

您提出的《关于进一步加快推进白鹤梁题刻申报世界文化遗产工作的建议》收悉，现答复如下：

白鹤梁题刻位于重庆市涪陵区城北长江南岸大江中的天然石梁上。石梁自西向东，长约1600米，平均宽度约15米。其地势较低，夏秋之季没于水中。梁上刻有自唐广德二年（764年）至清代的题刻163段，石鱼14尾，记录了涪陵地区一千二百年间七十二个年份的历史枯水资料，具有很高的科学价值。

1988年，国务院将白鹤梁题刻公布为第四批全国重点文物保护单位。国家文物局一贯重视白鹤题题刻的保护管理工作，已先后安排国家重点文物保护专项补助资金四千余万元，用于文物本体保护修缮、保存环境监测，原址水下保护工程等。并先后于2006年、2012年，两次将“白鹤梁题刻”列入《中国世界文化遗产预备名单》，并向联合国教科文组织世界遗产中心进行了备案。

近年来，世界遗产申报工作的难度逐渐加大。根据世界遗产委员会新施行的“限额制”，一个缔约国每年最多只能申报一项世界遗产。同时，世界遗产委员会不断推进世界遗产均衡性的全球战略，明确向没有世界遗产或世界遗产较少的国家，以及遗产类型较少的类别倾斜；而对世界遗产大国的限制则不断增多。

我国是世界遗产大国，目前拥有世界遗产53项，其中文化遗产36项，居世界第二。世界遗产中心和国际古迹遗址理事会等专业咨询机构对我国等世界遗产大国的申报项目，往往提出更高的标准。按照《保护世界文化和自然遗产公约》及其《操作指南》的规定，申报世界文化遗产的项目，应该具有全世界范围内的突出普遍价值，较好的保存现状，真实性和完整性较高，扎实的保护管理基础，以及利益相关者对遗产保护的积极态度。这都要求我国的申报项目要在各方面做好充分的准备。

白鹤梁题刻具有一定的历史、艺术和科学价值，但各项基础工作仍还薄弱，相关研究开展不充分，遗产价值提炼不够清晰，遗产本体保护管理面临挑战。今后，我局将支持、指导地方人民政府和当地文物管理部门做好以下工作：

一、进一步加强基础研究工作，特别是深入开展突出普遍价值和比较研究，清晰阐述其符合的世界文化遗产标准，明确遗产定位，并与国内外同类型遗产进行深入对比分析。在此基础上编制保护管理规划、制订和完善有关保护管理法规，加强遗产的保护和管理，启动各项申遗前期基础工作。

二、白鹤梁题刻因长江水利枢纽工程建设，采取了无压覆室覆盖的“水下博物馆”保护和展示方式，实行原址保护。白鹤梁题刻的外部环境因此发生了根本性变化，而水中泥沙的淤积和侵蚀也给白鹤梁题刻的保护带来新的困难和挑战。建议当地政府密切关注国际世界遗产领域研究的新进展、新政策及新举措，探讨此类外部环境完全变化、已建成博物馆进行保护展示的遗产申遗的策略和路线。

我局将于近期组织世界遗产专家评审会议，对包括白鹤梁题刻在内的五处世界文化遗产预备项目进行评审，基于申遗文本对各项目的价值、适用标准和保护管理状况等进行考察，并研究提出评审意见，指导各地进一步完善申遗文本，继续做好后续申遗基础工作。

衷心感谢您对我国世界文化遗产工作的关注和支持！

此函。

国家文物局
