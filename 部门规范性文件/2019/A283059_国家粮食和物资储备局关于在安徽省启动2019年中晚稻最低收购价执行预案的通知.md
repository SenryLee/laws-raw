# 国家粮食和物资储备局关于在安徽省启动2019年中晚稻最低收购价执行预案的通知

国粮粮〔2019〕291号

中国储备粮管理集团有限公司：

你公司《关于在安徽省启动2019年中晚稻最低收购价执行预案的请示》（中储粮〔2019〕223号）收悉。根据国家发展和改革委员会、国家粮食和物资储备局等部门《关于印发小麦和稻谷最低收购价执行预案的通知》（国粮发〔2018〕99号）有关规定，经研究，同意自10月22日起在安徽省内符合条件的相关地区启动2019年中晚稻最低收购价执行预案。

国家粮食和物资储备局

2019年10月21日
