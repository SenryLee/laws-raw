# 国家卫生健康委员会办公厅关于开展2019年婚育新风进万家活动的通知

国卫办宣传函〔2019〕176号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团卫生健康委（卫生计生委）：

为全面贯彻落实习近平总书记关于加强老龄工作的重要论述，按照《关于“十三五”期间深入推进婚育新风进万家活动的意见》（国卫宣传发〔2016〕42号）有关要求，2019年婚育新风进万家活动将围绕倡导积极老龄观、健康老龄化、做快乐老年人开展有关宣传工作。2019年的活动主题为“健康快乐夕阳红”。现将具体要求通知如下：

一、活动内容

（一）围绕习近平总书记关于加强老龄工作的重要论述，倡导全社会形成尊老敬老的良好风尚，宣传爱老助老的典型经验和感人故事。

（二）围绕构建养老护理体系，宣传推广各地在解决照护谁、谁照护、在哪里照护、照护什么、谁出钱5个关键环节的好经验好做法。

（三）围绕健康扶贫工作，开展面向建档立卡贫困户中患病困难老人帮扶关爱活动，走进贫困地区开展义诊、健康咨询等活动。

（四）通过各种媒体向老年群众宣传健康知识，提高其健康素养。

二、活动方式

（一）开展卫生健康节日纪念日宣传活动。结合爱国卫生月面向老年人推广老年健康实用讲座，帮助老年人掌握健康技能、提高健康素养；结合国际劳动节集中宣传“银龄行动”中老年医务志愿者先进事迹；结合世界人口日宣传积极应对人口老龄化工作经验亮点；结合“敬老月”集中开展推进医养结合、完善老年健康服务体系系列报道和尊老敬老、传承家风系列宣传，组织面向建档立卡贫困户中患病困难老人的义诊服务活动；结合其他健康类节日纪念日围绕相关核心信息，开展线上线下宣传服务活动，送政策、送知识、送服务进社区、进乡村、进家庭。

（二）发挥典型带动作用，组织开展先进典型宣传活动。在全国范围内，充分运用传统和新兴媒体，开展构建养老护理体系和推进医养结合先进经验的推荐和展示，广泛发掘宣传退休医务工作者发光发热的典型人物事迹，并鼓励和引导相关文艺作品创作。

（三）做好日常健康教育和宣传活动。将婚育新风进万家活动与“银龄行动”等老龄品牌工作及常规健康教育工作相结合，倡导全社会关注老龄问题、关爱老年群体，引导老年群众学习健康知识、树立健康观念、提高健康素养、养成健康生活方式。

三、工作要求

（一）积极了解本地群众健康需求，密切结合工作实际，提前做好全年活动计划，分解落实各项工作任务，确保活动效果。

（二）充分发挥老年群众组织和工会、共青团、妇联、健康教育协会等群团组织的积极性，将婚育新风进万家活动列为全年重点工作任务，积极动员地方广播电视、报纸杂志、网站等媒体单位，协同开展宣传活动。

（三）请于2019年12月30日前报送活动情况总结及图片视频资料，由各省级卫生健康行政部门统一报送至我委宣传司。

## 2019年婚育新风进万家活动主题宣传核心信息

一、合理膳食，均衡营养。

二、适度运动，循序渐进。

三、及早戒烟，限量饮酒。

四、定期监测血压、血糖，做好慢病管理。

五、家居适老改造，预防跌倒。

六、保持良好心态，学会自我疏导。

七、每年至少参加一次体检。

八、严格按医嘱用药。

九、外出随身携带健康应急卡。

十、促进老年人参与社会活动。
