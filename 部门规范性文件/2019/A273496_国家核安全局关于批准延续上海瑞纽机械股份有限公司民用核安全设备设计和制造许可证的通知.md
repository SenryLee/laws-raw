# 国家核安全局关于批准延续上海瑞纽机械股份有限公司民用核安全设备设计和制造许可证的通知

## 关于批准延续上海瑞纽机械股份有限公司民用核安全设备设计和制造许可证的通知

国核安发〔2019〕7号

上海瑞纽机械股份有限公司：

你公司《关于申请办理民用核安全机械设备设计许可证延续的请示》（瑞纽股份［2017］（010）号）、《关于申请办理民用核安全机械设备制造许可证延续的请示》（瑞纽股份［2017］（011）号）、《关于上海瑞纽机械股份有限公司法人变更申请的报告》（瑞纽股份［2018］（007）号）收悉。经研究，通知如下。

根据《中华人民共和国核安全法》《民用核安全设备监督管理条例》及其配套规章的要求，我局审查了你公司提交的民用核安全设备设计和制造许可证延续及变更申请，结合你公司持证期间民用核安全设备设计和制造活动开展情况，认为你公司在所申请的民用核安全设备设计和制造方面保持了《民用核安全设备监督管理条例》第十三条及《民用核安全设备设计制造安装和无损检验监督管理规定》第八条所要求的各项能力，决定向你公司颁发《民用核安全设备设计许可证》（国核安证字S（19）01号，见附件1）和《民用核安全设备制造许可证》（国核安证字Z（19）02号，见附件2）。许可证有效期至2024年3月31日。

你公司应按照许可证规定的范围和条件，开展民用核安全设备设计和制造活动，确保民用核安全设备设计和制造质量。

特此通知。

附件：1.民用核安全设备设计许可证（国核安证字S（19）01号）

2.民用核安全设备制造许可证（国核安证字Z（19）02号）

国家核安全局

2019年1月14日
