# 交通运输部水运局关于请提供春运及“十一”黄金周水路客运信息报送有关情况的函

水运运行函〔2019 〕29号

各省、自治区、直辖市交通运输厅（局、委），长江航务管理局：

全国春运及“十一”黄金周水路客运信息报送工作机制运转良好，为领导决策提供了支撑。但也存在部分地方信息报送不全面、不够准确、不及时等问题。为进一步做好信息报送工作，现请你单位就基本情况、工作经验和做法、存在的问题和不足、意见建议等提供书面材料，填写春运及“十一”黄金周水路客运信息调查表（附件1），各重点水域报送单位填写重点水域春运及“十一”黄金周水路客运信息调查表（附件2），并于4月4日前反馈我局（电子版一并反馈）。有关附件请从交通运输部网站水运局子站下载。

我局将适时组织信息报送工作研讨，开展信息报送系统运用培训等工作。

联系人：交通运输部水运局崔彦博、赵帅，联系电话：010-65292677、010-65292636，传真：010-65292638，电子邮箱：sys637@mot.gov.cn。

附件：1.省（区、市）春运及“十一”黄金周水路客运信息调查表

2.重点水域春运及“十一”黄金周水路客运信息调查表

交通运输部水运局

2019年3月26日
