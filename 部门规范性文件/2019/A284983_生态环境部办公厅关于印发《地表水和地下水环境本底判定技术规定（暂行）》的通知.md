# 生态环境部办公厅关于印发《地表水和地下水环境本底判定技术规定（暂行）》的通知

## 关于印发《地表水和地下水环境本底判定技术规定（暂行）》的通知

环办监测函〔2019〕895号

各省、自治区、直辖市生态环境厅（局），新疆生产建设兵团生态环境局：

为客观准确反映水环境质量状况和水污染防治工作成效，进一步满足全国地表水、地下水环境质量评价、考核和排名等工作需求，我部组织制定了《地表水和地下水环境本底判定技术规定（暂行）》，现印发给你们，请遵照执行。
