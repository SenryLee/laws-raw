# 国家体育总局关于开展第五次国民体质监测的通知

各省、自治区、直辖市体育局，金融体协、煤矿体协、前卫体协、中建体协：

国民体质监测是国家为系统掌握国民体质状况，以抽样调查的方式，按照国家颁布的国民体质监测指标，在全国范围内定期对监测对象进行统一测试和对监测数据进行分析研究的工作。我国迄今已进行了4次覆盖全国31个省（区、市）的国民体质监测，建立了中国国民体质监测数据库，掌握了我国国民体质基本变化规律，为国家科学制定发展群众体育事业、增强国民体质的相关政策提供了重要依据，国民体质监测结果已经成为制定和评估全民健身计划实施效果、评价健康中国建设成效的重要指标和数据来源。

根据《全民健身计划（2016-2020年）》和《“健康中国2030”规划纲要》的有关规定，按照国民体质监测周期，今年将开展第五次国民体质监测。为做好本次监测工作，结合新时代的形势发展变化和群众健身需求，体育总局制定了《第五次国民体质监测工作方案（幼儿、成年人、老年人部分）》（附件1），现印发给你们。

请接此通知后，认真按照《工作方案》的规定，做好各项准备工作，确保本次监测工作的顺利实施。

为便于工作联系，保证监测工作顺利开展，请各省（区、市）体育局和相关体协于2019年2月28日前将第五次国民体质监测工作联络人信息（附件2）报送至国家国民体质监测中心（国家体育总局体育科学研究所，报送邮箱地址：chinafitness@ciss.cn）。
