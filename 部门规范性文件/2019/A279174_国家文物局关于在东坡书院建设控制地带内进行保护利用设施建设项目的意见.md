# 国家文物局关于在东坡书院建设控制地带内进行保护利用设施建设项目的意见

文物保函〔2019〕620号

海南省文物局：

你局《关于审定全国重点文物保护单位东坡书院保护利用设施建设项目设计方案的请示》（琼文物发〔2019〕14号）收悉。经研究，我局原则同意在东坡书院建设控制地带内进行保护利用设施项目。

一、所报方案尚需作以下必要的修改和完善：

（一）新建项目不得超过东坡书院大殿檐高，并根据文物影响评估降低湖心亭建筑高度。

（二）进一步加强儋州传统建筑形式的研究，南侧新建景观亭廊、牌门等仿古建构筑物设计应符合当地传统形式，注意核对各建筑屋顶翼角起翘样式；书院正门、次门前宜采用传统铺装形式。

（三）在环境整治过程中，应尽可能延续原有郊野环境，适当减少建设量，弱化城市公园倾向，建议结合绿化和沿湖铺装整治现有驳岸。

（四）夜景照明系统及水电线路设置应避让文物本体，照明应考虑对文物建筑展示及安全的不利影响。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年7月2日
