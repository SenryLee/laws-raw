# 海关总署公告2019年第231号——关于废止447项出入境检验检疫行业标准的公告

## 海关总署公告

2019年第231号

## 关于废止447项出入境检验检疫行业标准的公告

经复审，海关总署决定废止《检验检疫设备完好通用检查方法》（SN/T 1656—2005）等447项出入境检验检疫行业标准（废止的标准目录见附件）。

本批标准自公告发布之日起废止。

特此公告。

附件：2019年出入境检验检疫行业标准复审废止目录

海关总署

2019年12月31日
