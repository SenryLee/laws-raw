# 国家煤矿安全监察局关于将3处煤矿一级安全生产标准化等级降为三级的通知

## 关于将3处煤矿一级安全生产标准化等级降为三级的通知

2019年1月20日，铁法煤业（集团）有限责任公司大隆煤矿发生生产安全事故，造成1人死亡；2019年3月11日，开滦能源化工股份有限公司范各庄矿业分公司发生生产安全事故，造成1人死亡；2019年4月2日，淮南矿业集团张集煤矿发生生产安全事故，造成1人死亡。按照《煤矿安全生产标准化考核定级办法（试行）》（煤安监行管﹝2017﹞5号）有关规定，国家煤矿安监局决定，将铁法煤业（集团）有限责任公司大隆煤矿一级安全生产标准化等级自2019年1月20日起降为三级；将开滦能源化工股份有限公司范各庄分矿业公司一级安全生产标准化等级自2019年3月11日起降为三级；将淮南矿业集团张集煤矿一级安全生产标准化等级自2019年4月2日起降为三级。
