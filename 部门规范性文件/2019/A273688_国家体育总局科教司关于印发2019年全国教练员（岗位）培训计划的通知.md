# 国家体育总局科教司关于印发2019年全国教练员（岗位）培训计划的通知

## 体育总局科教司关于印发2019年全国教练员（岗位）培训计划的通知

体科字〔2019〕8号

各省（自治区、直辖市）体育局，新疆生产建设兵团体育部门，中央军委训练管理部军事体育训练中心，总局各运动项目管理中心、协会，有关体育院校：

现将2019年全国教练员（岗位）培训计划印发给你们，请各主办单位根据培训计划安排，按照《体育总局办公厅关于进一步加强教练员岗位培训工作有关事宜的通知》要求，做好相关报名和组织工作。

有关要求如下：

一、做好培训准备。按规定科学设计课程，精选培训师资，合理安排培训时间，至少提前两周在总局教练员岗位培训管理系统（以下简称管理系统）中提交办班申请，发布培训通知。因办班标准不符合岗培要求，未通过管理系统报名、审核的培训班不能申领岗位培训合格证书。

二、做好培训保障。要主动公布培训班联系人和联系方式，指导教练员获取培训信息，进行注册报名，查询成绩，申领合格证书；要积极为教练员参加培训创造良好条件，重点做好培训安全防范和保障工作。

三、做好培训管理。要严格规范管理，严肃培训纪律，开班首先要集中学习培训纪律和要求，对请假超过一天的不予颁发合格证书；抓实学风建设，积极营造好的学习氛围，注重培训质量，以更好的满足各项目各级别教练员岗位培训需求，帮助教练员不断提升素质和能力。

四、做好绩效评估。培训结束一个月内管理员要及时在系统上传培训成绩、出勤率和《国家体育总局培训项目结项审核表》，做好培训班的总结和评估工作。

教练员（岗位）培训管理系统服务电话：400-810-9966

附件：2019年全国教练员（岗位）培训计划

体育总局科教司
