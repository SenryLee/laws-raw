# 交通运输部公告2019年第92号——交通运输部关于湖北黄石港口岸对国际航行船舶扩大开放的公告

## 交通运输部公告

2019年第92号

## 交通运输部关于湖北黄石港口岸对国际航行船舶扩大开放的公告

中央编办，国务院办公厅，国家发展改革委，财政部，商务部，公安部，海关总署，国家移民管理局，军委联合参谋部，湖北省人民政府，湖北省口岸办，长江航务管理局，长江海事局，中国交通报，中国水运报:

根据《国务院关于同意湖北黄石港口岸扩大开放的批复》(国函〔2018〕167号)和《海关总署关于印送湖北黄石港口岸扩大开放验收纪要的函》（署岸函〔2019〕435号），交通运输部决定自本公告之日起，湖北黄石港口岸扩大对国际航行船舶开放。具体开放范围由长江海事局按程序对外公布。

特此公告。

交通运输部

2019年12月19日
