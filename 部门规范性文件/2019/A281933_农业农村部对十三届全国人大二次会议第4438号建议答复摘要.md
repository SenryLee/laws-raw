# 农业农村部对十三届全国人大二次会议第4438号建议答复摘要

## 对十三届全国人大二次会议第4438号建议答复摘要

农办议〔2019〕336号

黑土地保护是一项长期而艰巨的任务，需要统筹各方力量，加强规划引导，持续推进、久久为功。农业农村部、财政部、自然资源部、生态环境部、水利部在加强黑土地保护方面开展了以下工作。一是出台黑土地保护规划。2017年，经国务院同意，我部会同6部委编制印发了《东北黑土地保护规划纲要（2017—2030年）》。二是出台相关激励政策。通过农业支持保护补贴引导耕地质量保护和粮食适度规模经营。三是加大黑土地综合治理资金投入。2015—2017年，中央财政安排专项资金，在东北4省（区）17个县（市）开展东北黑土地保护利用试点。2018年起扩大了项目实施范围。四是实施东北秸秆处理行动。2017年，启动了"东北地区秸秆处理行动",支持东北4省（区）秸秆综合利用。五是开展轮作休耕制度试点。2016年启动实施耕地轮作休耕制度试点。2019年黑龙江省休耕面积达到200万亩，比上年增加60万亩。六是开展黑土地水土流失综合防治。安排中央财政水利发展资金支持黑龙江省黑土区侵蚀沟治理等工作。下一步，农业农村部将会同有关部门，继续加强黑土地保护工作。

农业农村部

2019年9月3日
