# 中华人民共和国农业农村部公告第223号——关于批准法国维克有限公司生产的烯丙孕素内服溶液在我国注册等的公告

根据《农业农村部关于批准爱尔兰Univet生产厂等5家公司生产的5种兽药在我国再注册、变更注册的公告》（农业农村部公告第782号），本法规中法国维克有限公司生产的复方咪康唑滴耳液的质量标准、说明书和标签失效。

## 中华人民共和国农业农村部公告

第223号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准法国维克有限公司生产的烯丙孕素内服溶液在我国注册，核发《进口兽药注册证书》，并发布产品质量标准、说明书和标签，自发布之日起执行。

批准法国维克有限公司生产的复方咪康唑滴耳液在我国再注册，核发《进口兽药注册证书》，并发布修订后的产品质量标准、说明书和标签，自发布之日起执行。此前发布的该产品兽药质量标准、说明书和标签同时废止。

批准KVP Kiel有限责任公司生产的托曲珠利混悬液在我国再注册，核发《进口兽药注册证书》，执行农业农村部公告第216号发布的同品种质量标准、说明书和标签。

特此公告。

2. 质量标准（略）
