# 国家市场监督管理总局、国家认证认可监督管理委员会关于开展2019年世界认可日活动的通知

## 国家市场监督管理总局　国家认证认可监督管理委员会关于开展2019年世界认可日活动的通知

国认监函〔2019〕7号

各省、自治区、直辖市及计划单列市、副省级城市、新疆生产建设兵团市场监管局（厅、委），认可中心、网安中心、认证认可技术研究中心、认证认可协会，各认证机构、检验检测机构：

2019年6月9日是第12个世界认可日，是世界各国宣传和推动认证认可检验检测工作的重要契机。为了贯彻落实党中央、国务院关于推进质量认证体系建设的决策部署，进一步发挥认证认可的作用，加强市场监管，促进质量提升，推动经济社会高质量发展，国家市场监督管理总局（国家认证认可监督管理委员会）将组织开展世界认可日活动。现将有关事项通知如下：

一、总体安排

6月8日-12日，国家市场监督管理总局（国家认证认可监督管理委员会）、浙江省人民政府将在首届中国-中东欧国家博览会暨国际消费品博览会上，联合主办以“认证认可促进供应链提升价值”为主题的2019年世界认可日主场活动，包括新闻发布、认证认可成果展示、消费者体验、中国-中东欧国家及“一带一路”国际合作交流对接等内容。

各地市场监管部门、从业机构及相关单位结合各自实际，围绕“认证认可促进供应链提升价值”主题组织开展系列活动。具体活动由各单位自主安排，面向市场主体和社会公众，通过开展宣传展示、培训交流、帮扶指导、公益服务、市场检查等多种形式的活动，大力宣传推动认证认可工作，提高认证认可的社会认知度和消费者获得感。

二、工作要求

（一）高度重视，精心组织。各单位要把组织开展世界认可日活动，作为贯彻落实《国务院关于加强质量认证体系建设 促进全面质量管理的意见》（国发〔2018〕3号）的实际行动，作为宣传推动认证认可检验检测工作、促进产品和服务等供应链质量提升的有力举措，作为展示认证认可检验检测行业形象、提高社会认知度和行业美誉度的重要契机，精心组织实施，确保活动取得预期效果。各地市场监管部门要发挥牵头作用，加强与相关地方政府部门和行业组织的联系，做好对检验检测认证机构的组织引导，形成工作合力。

（二）注重实效，推进工作。要围绕今年活动主题，结合各地方、各行业实际，制定切实可行的活动方案和工作举措，以产业经济发展的实际需求、市场主体面临的实际问题为关注点，推动认证认可在国计民生重点领域的实际应用，为企业和消费者办实事。要严格遵守中央八项规定及其实施细则精神，坚决反对“四风”，不搞花架子，不做表面文章，力戒形式主义和铺张浪费。

（三）加强宣传，扩大影响。充分借助新闻媒体、网络新媒体和社会资源，大力宣传认证认可检验检测在推进供给侧结构性改革、促进供给质量和供应链价值提升、激发市场活力、加强市场监管等方面的作用，深入挖掘认证认可检验检测在各地方、各行业应用的典型事例，积极推广工作成果突出的先进经验，形成示范带动效应。

三、有关事项

（一）请各省（区、市）和新疆生产建设兵团市场监管局（厅、委）制定世界认可日活动方案，及时报送活动开展情况和宣传报道素材，并加强对辖区内市、县（区）市场监管部门的工作指导，确保活动取得实效。

（二）认监委将组织编印制作世界认可日活动宣传海报、宣传片、宣传册等资料，宣传海报将由中国合格评定国家认可中心寄发各单位，其他宣传资料请登录认监委网站世界认可日专区下载。

## 世界认可日简介

2007年10月，国际认可论坛（IAF）和国际实验室认可合作组织（ILAC）在联合召开的年会上确定，每年的6月9日为“国际认可日”，旨在推动认证认可在全球的广泛发展。自2010年起，“国际认可日”更名为“世界认可日”。每年世界认可日，全球100多个IAF、ILAC成员方都将举行纪念活动。

我国每年的“世界认可日”主题活动紧密结合国家发展需求，组织动员各级政府部门、广大企业、从业机构和社会公众共同参与，展开宣传推广、交流研讨和分享体验，彼此建立和传递信任，共同推动认证认可的优良实践。中国的“世界认可日”形式多、范围广、影响大，富有中国特色，已经成为质量宣传的知名品牌。

今年6月9日是第十二个世界认可日。国际主题是“认可：促进供应链提升价值”，国内主题是“认证认可促进供应链提升价值”，重点关注供应链变得更加复杂的全球化时代，认证认可所发挥的积极作用。
