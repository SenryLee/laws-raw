# 国家药品监督管理局通告2019年第54号——国家药监局关于允许标准桃金娘油肠溶胶囊（儿童装）进口的通告

## 国家药品监督管理局通告

2019年第54号

## 国家药监局关于允许标准桃金娘油肠溶胶囊（儿童装）进口的通告

原国家食品药品监督管理总局于2015年8月17日发布《关于停止进口爱活胆通等3个品种的通告》（2015年第53号），决定停止进口德国保时佳大药厂生产的标准桃金娘油肠溶胶囊（儿童装）。

整改后，德国保时佳大药厂提出恢复进口的申请。经审查，国家药品监督管理局认为其整改符合相关要求，决定同意进口该品种。各口岸药品监督管理部门自通告发布之日允许德国保时佳大药厂生产的标准桃金娘油肠溶胶囊（儿童装）的通关备案。

特此通告。

国家药监局

2019年8月19日
