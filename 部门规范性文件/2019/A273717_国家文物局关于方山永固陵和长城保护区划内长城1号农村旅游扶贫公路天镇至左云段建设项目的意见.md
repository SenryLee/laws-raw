# 国家文物局关于方山永固陵和长城保护区划内长城1号农村旅游扶贫公路天镇至左云段建设项目的意见

文物保函〔2019〕52号

山西省文物局：

你局《关于长城1号农村旅游扶贫公路天镇至左云段建设工程穿越永固陵建设控制地带和部分明长城保护范围建设控制地带的请示》（晋文物〔2018〕139号）。经研究，我局原则同意方山永固陵、明长城保护范围、建设控制地带内长城1号农村旅游扶贫公路天镇至左云段建设项目，以及文物影响评估推荐的涉及方山永固陵的北线方案和涉及长城的推荐路线。

一、所报方案尚需作以下必要的修改和完善：

（一）应结合此段长城历史价值和景观价值的评估，进一步优化部分拟建公路路段选线，尽可能远离长城文物本体，重点调整白羊口支线以东一段、李二口支线以北一段、小龙王庙一段、镇边堡以东小二对营6号敌台左右区域、拒墙堡以西至助马堡段落和得胜堡以西一段选线。

（二）应进一步加大拟建公路与镇边堡、助马堡等长城沿线古堡的距离。建议积极考虑公路选线从威鲁堡南侧通过的方案；保安堡周边道路应以东侧线为主，并延伸西环线支线与主路连接；左云段立石村部分可考虑在南侧通过架桥、开通隧道等方式避让长城。

（三）针对部分贴近或穿过长城和烽火台、古堡之间地带的支线公路，应严格限制路面宽度，尽可能减少对长城景观环境的影响。

（四）工程实施过程中，应对相应长城点段进行适当围挡，确保施工不对长城造成损害。公路通行后，应加强管理和监测，避免因振动等威胁长城本体安全。

（五）应积极开展沿线长城、古堡的日常保养维护工作，消除病害风险，确保文物处于较为稳定的保存状态。

（六）应注意做好对长城周边景观环境的修复，并适当增加长城历史文化价值展示、阐释设施，充分发挥长城在推动经济社会发展中的积极作用。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月14日
