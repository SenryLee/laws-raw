# 国家卫生健康委员会、国家中医药管理局、国家药品监督管理局关于撤销金玉莲“全国医药卫生系统先进个人”称号的通知

## 关于撤销金玉莲“全国医药卫生系统先进个人”称号的通知

国卫人函〔2019〕117号

安徽省卫生健康委、中医药局、药监局：

经研究决定，撤销安徽省儿童医院原党委书记金玉莲“全国医药卫生系统先进个人”称号，收回其证书、奖章等，撤销因获得荣誉而享有的相应待遇，并追缴其所获奖金等物质奖励。

国家卫生健康委 国家中医药局

国家药监局

2019年5月10日
