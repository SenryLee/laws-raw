# 国家文物局关于武当山金殿危岩体监测项目的意见

文物保函〔2018〕1594号

湖北省文化和旅游厅：

原湖北省文物局《关于申报武当山金殿游客量与危岩体稳定性监测方案的请示》（鄂文物〔2018〕60号）收悉。经研究，我局原则同意武当山金殿危岩体稳定性监测方案；暂不同意武当山金殿游客量监测和监测预警平台建设方案。

一、所报方案尚需作以下必要的修改和完善：

（一）关于武当山金殿危岩体监测。

1. 应由岩土专业机构和人员参与，进一步深化现场勘察，补充细化具体区域的岩体稳定性勘察，明确危岩体分布范围和现状，明确现存病害，区分常态监测和重点监测，合理确定监测工作周期，并说明选定监测点位的依据。

2. 应详细说明各项监测的具体内容，补充岩体一定深度内湿度和温度变化情况监测，同时论证开展震动监测的必要性。

3.补充说明监测仪器的安装位置，补充监测点危岩体实测剖面图和仪器安装大样图。建议使用图像采集的方式进行危岩体小型崩塌破坏监测，取消一体化3G视频野外监控。补充说明铺设长距离光纤的必要性。

4.应由专业技术人员对采集到的多项内容、大量数据进行及时整理和系统分析，并用人工测量和检测方法对自动监测仪器采集的数据进行较核，在此基础上综合判定风险预警的时间节点。

5.调整监测设备外部防护栅栏设计，尽可能降低对遗产环境造成的扰动。应明确监控机房的选址和规模，避免对古建筑及其景观环境造成直接影响。在山体上设置桩基，应确保其施工和运维均不会对文物及其所处山体造成损坏。

6.应综合考虑对危岩体的治理，编制保护治理方案，并监测评估治理措施的有效性。应评估与监测相关的应急预案的有效性和针对性。

7.应补充确保监测系统建成后正常运行的保障条件和措施。根据世界文化遗产监测的规范要求，注意为其他监测工作提供预留空间。

8.进一步规范和完善方案文本和图纸。补充金殿文物保护区划图，并应明确标示相关设施在金殿保护范围和建设控制地带的具体位置。

（二）关于游客量监测

1.应深入研究金殿各组成部分在管理需求上的差异，明确游客密集区域的具体范围、界定游客容量限制条件，补充对游客行为的规律分析、影响评估和可控性分析，提出初步的游客承载量限定值，从而确定监测需求，制定监测指标，落实监测方法，支持管理决策。

2.适当简化管理操作进出口识别系统设计。在研究确定重要区域游客承载量的基础上，建立有效的管理和疏导系统，确保监测与服务和管理的有效衔接。

（三）关于武当山历史建筑群监测预警体系建设

1.应对武当山古建筑群现有各类监测监控系统应进行全面梳理，包括大气、降水、水质等生态环境监测，应尽量整合利用现有资源，加强协作和数据共享，避免重复建设。

2.应坚持问题和需求导向，进一步梳理武当山古建筑群的遗产构成，根据不同类型遗产的特点和保护监测需求，深化研究，有针对性地确立合理、适度、有效的监测内容和体系。

3.科学合理的编制经费预算需求。

二、请你厅组织有关单位，根据上述意见对武当山金殿危岩体稳定性监测方案进行修改和完善，经你厅核准后实施。实施过程中应加强监督指导，确保文物安全及项目建设取得实效。

三、请你厅指导有关单位，根据上述意见对武当山金殿游客量监测和监测预警平台建设方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局
