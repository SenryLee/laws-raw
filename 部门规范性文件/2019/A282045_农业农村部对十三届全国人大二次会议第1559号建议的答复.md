# 农业农村部对十三届全国人大二次会议第1559号建议的答复

## 对十三届全国人大二次会议第1559号建议的答复

农办议〔2019〕526号

裴春亮代表：

您提出的关于大力培育新型职业农民的建议收悉。现答复如下。

一、关于加大政策扶持

党的十八大以来，中央财政累计安排资金90.9亿元支持农民教育培训工作，我部加强顶层设计，强化管理服务和扶持，积极构建高素质农民队伍。

一是加强组织领导。指导各地积极推动将农民教育培训作为实施乡村振兴战略的重要抓手，摆上各地党委政府“三农”工作重要日程，推动县级层面成立多部门协作的工作领导小组，细化目标任务、工作措施和资金使用。二是加强参训农民管理服务。引导各地整合资源，积极创造有利于农民成长发展的政策环境，探索实行参训农民登记注册管理，为后续跟踪扶持、配套产业政策和金融保险服务提供科学依据。三是加强政策扶持。引导强农惠农富农政策向参训农民倾斜支持，鼓励其流转土地发展适度规模经营，优先承接进城落户农民退出的土地承包经营权；鼓励农业信贷担保公司面向农民开展符合规定的信用贷款担保业务，支持有条件的地区开展农民个人信用担保贷款；引导符合条件的农民参加城镇职工基本养老保险、职工基本医疗保险等社会保险。

下一步，我部将继续梳理各类强农惠农富农政策，进一步加大农民教育培训扶持力度，不断提升务农兴业含金量，让农民真正成为有吸引力的职业。

二、关于整合教育培训资源

乡村振兴人才是关键，新时代新任务需要培养一大批高素质农民，在保证国家粮食安全、促进绿色农业发展、带动农民增收致富等方面更好地发挥重要骨干引领作用。我部高度重视高素质农民培养，通过整合教育培训资源、丰富培训手段、引导农业专家发挥作用等方式促进农民全面发展。

一是整合各类教育培训资源。统筹用好农广校、涉农院校、职教中心、农村成人文化技术学校、农业科研院所、农技推广机构等教育培训资源，引导鼓励农业龙头企业、农民合作社、农民专业技术协会等发挥自身优势参与教育培训工作，鼓励市场主体建设农民田间学校和实训基地。二是推进线上线下融合培训。加强“全国农业科教云平台”推广应用，鼓励农业专家、农技推广人员、培训机构、培训教师利用云平台开展指导服务，探索线上线下融合培训模式，组织农民在线学习。三是支持农业科研院校和现代农业产业技术体系专家开展农技推广工作。鼓励农业科研教学人员以兼职、合作、交流等多种形式开展农技推广服务，鼓励现代农业产业技术体系专家走出实验室，走到田间地头，推广最新的研究成果。目前现代农业产业技术体系有1370位岗位专家、1252位综合试验站站长及其团队共同参与技术培训工作，示范专家队伍近万人，水稻、小麦、生猪等50个体系每年确定2—3项示范推广技术，制定技术规范，对基层技术人员、农民等进行不同层级的培训活动。

下一步，我部将继续抓好高素质农民培养工作，抓实落细关键环节，不断发展壮大适应乡村振兴战略和现代农业发展需求的高素质农民队伍。

三、关于明确培育对象开展针对性教育培训

技能培训是提升农民综合素质和生产技能的重要途径，职业教育是培养高素质农民的重要载体，具有系统性培养优势，我部十分重视，坚持技能培训和职业教育两条腿走路，培养具备现代生产技能和经营能力的复合型农业农村人才。

一是明确重点培训对象。农业经理人培养重点面向农业企业和新型经营主体的经营管理人员，新型农业经营主体带头人培养重点面向家庭农场、农民合作社、小微农企和农业社会化服务组织带头人开展轮训，现代创业创新青年培养重点面向返乡创业大学生、中高职毕业生、返乡农民工和退伍军人等农业后继者，农业产业精准扶贫培训重点面向有劳动能力的贫困户。二是按需实施精准培训。培训内容采取模块化设计，经营主体带头人主要强化品牌创建、市场营销、企业管理、融资担保等内容学习；创业创新人员主要强化职业素养、团队合作、科学发展等内容学习；专业大户等生产型农民主要强化新技术、新品种、新成果、新装备的推广应用；农业经理人的培训是以能力为导向的复合型人才培养，着力提高其管人的能力、管事的水平；培训结束后，引导农技人员根据农时季节开展上门跟踪服务，切实增强农民的获得感。三是培育农业科技示范主体。遴选技术能力较强、帮扶意愿较高的新型经营主体带头人、种养大户、乡土专家作为示范主体，通过指导服务、技术培训等方式提升其科学种养水平和自我发展能力，提高对周边农户，特别是贫困户的辐射带动能力。四是启动实施“百万高素质农民学历提升行动计划”。我部联合教育部印发《农业农村部办公厅、教育部办公厅关于做好高职扩招培养高素质农民有关工作的通知》，启动实施“百万高素质农民学历提升行动计划”，全面完成2019年高职扩招培养高素质农民任务，在此基础上经过5年的努力，培养100万名接受学历职业教育、具备市场开拓意识、能推动农业农村发展、带领农民增收致富的高素质农民，打造100所乡村振兴人才培养优质校。

下一步，我部将以培育对象为中心，遵循农民需求、遵循客观规律，精心组织实施教育培训，提升其生产、经营和管理本领，培养振兴乡村的主力军。

感谢您对农民教育培训工作的关心，希望继续对我部工作给予支持。
