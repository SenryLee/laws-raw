# 国家文物局对十三届全国人大二次会议第4282号建议的答复

文物保函〔2019〕636号

庞永辉代表：

您提出的“关于打造河北文化旅游品牌，振兴河北陶瓷文化产业的建议”收悉，经商国家发展改革委、财政部和河北省人民政府，现答复如下。

河北省陶瓷业历史悠久，陶瓷文化底蕴深厚。定窑、磁州窑、邢窑、井陉窑等在中国陶瓷史上具有重要地位，相关重要遗址被国务院公布为全国重点文物保护单位。多年来，国家有关部委和河北省人民政府积极推进河北省内重要瓷业遗址保护利用工作。定窑遗址、磁州窑遗址先后被列入国家文物局大遗址保护项目库、国家发展改革委文化旅游提升工程项目储备库，在考古发掘、本体保护、规划编制、政策和经费等方面不断获得支持。

您提出的设立遗址公园、建立省级博物馆、形成精品路线、促进校企合作和产业发展、加大文化专项资金支持等建议，对推动河北省内重要瓷业遗址保护利用工作，具有重要意义。下一步，国家文物局将与河北省人民政府、有关部门一起，继续做好如下工作。

第一，指导河北省考古专业机构制定长期考古计划，进一步搞清河北省内重要瓷业遗址的分布范围、烧造年代、延续时间和保存现状，及时整理考古资料和出版考古报告，全面研究河北省在古代中国瓷业生产史上的历史地位，为后续保护利用工作提供学术支持。

第二，引导地方人民政府合理确定各瓷业遗址的展示利用方式，科学论证建设考古遗址公园的必要性与可行性，明确功能定位、展示主题、运营方式和投入维护成本等，防止盲目建设。

第三，目前文化旅游提升工程支持范围暂不包括博物馆等内容，建议河北省优先考虑利用现有展陈空间，发挥文物保护和展示展览功能。若经研究确有必要新建博物馆，建议发挥地方政府的主体责任，充分整合利用现有资源，合理确定建设规模和内容。

第四，建议河北省人民政府创新管理方式，加大陶瓷文化价值挖掘力度，整合全省文化和文物资源，合理规划旅游线路，适时将定窑、磁州窑、邢窑、井陉窑等重要遗址串联打造为陶瓷文化精品旅游线路，加大宣传推广力度，创造更多广大民众喜闻乐见的文化产品，促进文物保护与区域经济社会协调发展。有关部门将在职能范围内给予大力支持。

第五，支持河北省人民政府有关部门，拓展人才培养的广度和深度，加强学生与市场需求的对接，探讨建立企业深度参与教学改革、学生对标企业实训联合培养机制的必要性和可行性，厚植人才根基，促进产业发展。

第六，根据国务院关于转变政府职能、积极发挥市场作用，以及财政资金应逐步取消对竞争性领域投入等有关精神，财政部将会同中央宣传部创新和改革文化产业发展专项资金使用管理方式，主要运用注入基金等市场化方式运作。下一步，财政部将主要通过基金等市场化方式，放大财政资金的撬动和引导作用，支持包括瓷业在内的特色文化产业发展。

感谢您对文物事业的关心和支持。

国家文物局

2019年7月5日
