# 财政部关于提前下达2020年港口建设费支持港口航道公共基础设施建设预算的通知

财建〔2019〕569号

有关省、自治区、直辖市、计划单列市财政厅（局）：

根据《财政部关于印发<中央对地方专项转移支付管理办法>的通知》（财预〔2015〕230号）以及《财政部、交通运输部关于印发<港口建设费征收使用管理办法>的通知》（财综〔2011〕29号）等有关规定，现提前下达你省（区、市）2020年港口建设费安排地方建设项目支出预算（项目代码：Z165060000001），具体项目及支出功能分类科目详见附件。请按照《中共中央国务院关于全面实施预算绩效管理的意见》的要求，完善绩效目标管理，做好绩效运行监控和绩效评价，确保财政资金安全有效。

上述支出列入2020年预算，请严格按照有关办法规定，做好预算编制工作。

附件：1.提前下达2020年港口建设费支持港口航道公共基础设施建设项目预算总表（不发地方）

2.提前下达2020年港口建设费支持港口航道公共基础设施建设项目预算表（发地方）

3.提前下达2020年港口建设费支持港口航道公共基础设施建设项目预算绩效目标总表

4.提前下达2020年港口建设费支持港口航道公共基础设施建设项目预算分省绩效目标表

财政部

2019年10月31日
