# 商务部市场运行和消费促进司关于开展2019年度原油成品油经营企业年度定期检查工作的通知

## 关于开展2019年度原油成品油经营企业年度定期检查工作的通知

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务（经信）主管部门：

原油成品油经营企业年度定期检查是加强原油成品油流通行业管理的重要工作手段，是严格市场准入、强化事中事后监管的重要举措。为做好2019年度原油成品油经营企业年度定期检查工作，现将有关事项通知如下：

一、请各地按照《原油市场管理办法》、《成品油市场管理办法》相关规定，在2019年5月底前，完成原油成品油经营企业年度定期检查工作。年度定期检查中，要认真查验企业上报的材料，重点关注企业安全、环保等方面证照和经营设施情况，对发现的新情况、新问题，要及时调查了解。

二、请各地进一步加强对年度定期检查工作的管理，及时通知具有原油成品油批发、仓储以及成品油零售经营资格的企业按时参加年度定期检查。对不配合检查或检查不合格的企业要下达整改通知书，责令其限期整改；整改仍不合格的，将企业名单、有关情况及处理意见报发证机关，由发证机关研究注销其原油、成品油经营资格证书。

三、请各地在2019年度定期检查基础上，填报2018年成品油批发企业、成品油仓储企业、成品油零售企业、加油站、外商投资成品油零售企业、原油经营企业基本情况表（附件1-6，表格电子版请从市场运行司子站下载），并于2019年6月15日前报我部（市场运行司）。
