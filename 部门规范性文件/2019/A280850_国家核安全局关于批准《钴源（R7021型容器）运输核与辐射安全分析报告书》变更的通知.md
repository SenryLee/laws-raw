# 国家核安全局关于批准《钴源（R7021型容器）运输核与辐射安全分析报告书》变更的通知

## 关于批准《钴源（R7021型容器）运输核与辐射安全分析报告书》变更的通知

国核安发〔2019〕172号

中核同兴（北京）核技术有限公司：

你公司《关于申请变更〈钴源（R7021型容器）运输核与辐射安全分析报告书〉的请示》（中核同兴发［2019］11号）收悉。

根据《放射性物品运输安全管理条例》的有关要求，我局审查了你公司提交的《关于〈钴源（R7021型容器）运输核与辐射安全分析报告书〉增加独家使用运输方式的补充分析》（以下简称《报告书补充分析》），批复如下。

一、你公司通过独家使用方式，采用R7021型运输容器运输钴源满足R7021型运输容器原设计要求，我局同意《报告书补充分析》。

二、独家运输时，单个R7021型运输容器最大装载量为7.4E+15Bq，单次最大运输量为3.7E+16Bq，年最大运输量为4.81E+17Bq。

三、原批准文件（国核安发〔2017〕319号）其余内容不变。

国家核安全局

2019年8月13日
