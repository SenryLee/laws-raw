# 农业农村部对十三届全国人大二次会议第2003号建议的答复

## 对十三届全国人大二次会议第2003号建议的答复

您提出的关于持续支持田园综合体发展的建议收悉。经商财政部，现答复如下。

一、关于持续推进项目建设、研究出台政策措施

开展田园综合体试点项目建设是推动“三农”工作一次有益探索和创新，为实施乡村振兴战略提供了一个新平台。您提出持续推进项目建设、研究出台政策措施等建议，对于田园综合体试点工作具有积极意义。

2017年中央一号文件提出：“支持有条件的乡村建设以农民合作社为主要载体、让农民充分参与和受益，集循环农业、创意农业、农事体验于一体的田园综合体，通过农业综合开发、农村综合改革转移支付等渠道开展试点示范。”同年，财政部印发《关于开展田园综合体建设试点工作的通知》（财办〔2017〕29号，以下简称《通知》），确定自2017年起，在河北、山西等18个省份开展田园综合体建设试点（以下简称“试点”），中央财政从农村综合改革转移支付资金、现代农业生产发展资金、农业综合开发补助资金中统筹安排。试点期限初定为3年，每个试点省份安排田园综合体试点1—2个，由试点省份有关部门统一组织以竞争立项的方式确定。同时，《通知》中明确了试点基本原则、重点建设内容、立项条件、扶持政策以及有关工作要求。要求地方政府部门要加强沟通协调，引导和鼓励地方积极搭建田园综合体基础设施和产业政策平台，因地制宜选择田园综合体建设模式，建立运行顺畅的建设管理机制，为项目建设创造良好环境。项目启动以来，试点省份稳步推进项目建设，试点工作取得了积极进展，产业融合不断加速，农民收入显著提高，乡村面貌得到明显改善，越来越多外出打工的村民返乡创业。下一步，我部将会同有关部门结合实施乡村振兴战略，在总结3年试点情况的基础上，统筹研究相关试点政策措施。

二、关于鼓励支持龙头企业参与试点建设

龙头企业等新型农业经营主体作为推进农业产业化经营的关键，是推动田园综合体建设的重要力量。为支持龙头企业参与试点建设，《通知》将“龙头企业带动力强”作为一项重要基础条件，要求“各地根据当地主导产业规划和新型经营主体发展培育水平，因地制宜探索田园综合体的建设规模和运营管理模式。可采用村集体组织、合作组织、龙头企业等共同参与建设田园综合体，盘活存量资源、调动各方积极性，通过创新机制激发田园综合体建设和运行内生动力”。

您提出“鼓励支持龙头企业参与田园综合体建设”的建议，在现有政策中已经得到体现。下一步，我部将会同有关部门继续积极支持地方引导包括龙头企业在内的新型农业经营主体共同参与田园综合体建设。

三、关于加大国家财政资金投入

按照2017年中央一号文件有关要求，中央财政积极完善扶持政策并安排资金支持地方开展试点工作，相关资金切块到省，在不违反现行相关政策规定的前提下，试点资金和项目管理具体政策由地方自行研究确定；同时，要求地方统筹使用好现有各项涉农财政支持政策，创新财政资金使用方式，采取资金整合、先建后补、以奖代补、政府与社会资本合作、政府引导基金等方式支持开展试点项目建设。

您提出“田园综合体需要全域升级改造‘田园+农村’路、水、电、气、讯等基础设施，需要不断夯实生产体系、产业体系、经营体系、生态体系、服务体系和运行体系‘六大体系’，需要构建文化、教育、医疗等公共配套网络，建议进一步加大试点项目的国家财政资金投入，加快试点探索步伐”的建议，《通知》已经明确六大支撑体系具体建设内容和扶持政策，且国家在支持农村文化、教育、医疗等方面也有专门的支持渠道，试点地方可按要求统筹使用好现有各项涉农财政支持政策，加快推进试点项目建设。

感谢您提出的宝贵建议，希望继续支持“三农”工作。

农业农村部

2019年9月19日
