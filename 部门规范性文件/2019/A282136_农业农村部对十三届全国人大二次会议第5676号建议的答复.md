# 农业农村部对十三届全国人大二次会议第5676号建议的答复

## 对十三届全国人大二次会议第5676号建议的答复

农办议〔2019〕508号

庄文忠代表：

你提出的关于加快农膜管理条例立法的建议收悉。经研究，现答复如下。

我国地膜覆盖面积大、应用范围广，在增加农作物产量、提高品质、丰富农产品供给结构等方面发挥了重要作用。但由于重使用、轻回收，部分地区农膜残留污染问题日益严重，已成为制约农业绿色发展的突出环境问题。近年来，中央高度重视农膜污染治理工作，对农膜污染防治立法工作提出了明确要求。2018年，《中华人民共和国土壤污染防治法》正式颁布，授权国务院农业农村主管部门会同国务院生态环境等主管部门制定农用薄膜回收具体办法。

我部认真贯彻落实中央决策部署，将农膜污染防治工作摆在突出位置，不断加大工作力度，全面推进农膜污染治理。一是推动出台《农用薄膜管理办法》（以下简称《办法》）。我部已将《办法》列入立法重点工作，2018年10月，通过实地调研、草案编制、研讨论证等，起草形成了《办法》（征求意见稿）。《办法》拟从农膜生产、回收、再利用等环节加强农膜管理，要求各环节的监管责任，建立全程监管体系，加强农膜污染防治的法制保障。2018年11-12月，我们先后征求了发展改革委、工业和信息化部、财政部、生态环境部、市场监管总局的意见，面向各省（区、市）农业农村部门征求了意见，对《办法》进行修改完善。二是印发《关于加快推进农用地膜污染防治的意见》（以下简称《意见》）。2019年6月，我部联合发展改革委、工业和信息化部、财政部、生态环境部、市场监管总局部等5部门印发了《意见》，推动多部门联合治理白色污染，明确下一步工作目标和任务，以回收利用、减量使用传统地膜和推广应用安全可控替代产品为主要治理方式，健全制度体系，强化责任落实，加强政策保障，并对农膜管理立法工作提出明确要求。

下一步，我们将按照立法工作有关规定，加快立法进度，联合有关部门尽快出台《办法》。

感谢您对农膜管理条例立法工作的关心，希望继续对我部工作给予支持。
