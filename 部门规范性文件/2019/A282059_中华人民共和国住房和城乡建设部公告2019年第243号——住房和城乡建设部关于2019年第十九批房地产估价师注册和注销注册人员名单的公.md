# 中华人民共和国住房和城乡建设部公告2019年第243号——住房和城乡建设部关于2019年第十九批房地产估价师注册和注销注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第243号

## 住房和城乡建设部关于2019年第十九批房地产估价师注册和注销注册人员名单的公告

根据《注册房地产估价师管理办法》（建设部令第151号）规定，经审核，申请房地产估价师初始注册、变更注册、延续注册的陈怀坤等505人，符合注册条件，准予注册；准予李永军等30人注销房地产估价师注册，其注册证书作废。未批准注册的人员，可通过房地产估价师注册系统查询不予注册原因。

附件：1.陈怀坤等505名房地产估价师注册人员名单

2.李永军等30名房地产估价师注销注册人员名单

住房和城乡建设部

2019年9月12日
