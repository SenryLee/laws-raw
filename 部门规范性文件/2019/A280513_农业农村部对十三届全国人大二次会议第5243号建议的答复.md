# 农业农村部对十三届全国人大二次会议第5243号建议的答复

## 对十三届全国人大二次会议第5243号建议的答复

农办议〔2019〕58号

郭小芹代表：

您提出的关于精准助力贫困地区产业发展的建议收悉。经商国务院扶贫办，现答复如下。

一、关于实地调研，论证贫困地区产业发展的需求

我部高度重视中药材产业扶贫工作，会同有关部门和单位多次开展实地调研，了解贫困地区产业发展需求，配合中医药局等单位持续推进第四次全国中药资源普查，推进野生资源合理利用。在全国31个省（区、市）1348个县开展中药资源调查工作，获得全国近1.4万种野生药用资源、500多种栽培药材、1600多种市场流通药材、563种《中国药典》收载药材的种类、分布、蕴藏量等信息，为中药材种植规范发展提供了科学支撑。

下一步，我部将继续会同有关部门，对贫困地区中药材产业发展开展调研和指导，有针对性地完善行业准入制度，在中药材生产质量管理规范（GAP）修订过程中，秉承中药材绿色发展理念，加强道地产区和道地药材的保护。鼓励企业按照规范组织中药材生产，加快推动中药材优良品种筛选和无公害规范种植，保护野生中药材资源和生态环境，促进中药材资源的可持续发展。

二、关于加大对中药材产业发展的政策支持，对贫困地区政策倾斜力度要更大

近年来，我部贯彻落实中央关于脱贫攻坚的决策部署，会同有关部门和单位，集聚资源，多措并举，扶持贫困地区中药材产业发展。一是加强规划引导。2016年，国务院办公厅颁布实施《关于促进医药产业健康发展的指导意见》（国办发〔2016〕11号），提出加强中医药领域地理标志产品保护，在适宜地区建设规范化种植养殖、规模化加工一体化基地等具体意见。2016年，中医药局印发《中医药发展“十三五”规划》，提出推进中药保护和发展，促进中药材种植养殖业绿色发展。2018年12月，我部会同中医药局、药监局等单位，制定印发《全国道地药材生产基地建设规划（2018—2025年）》，引导各地优化道地药材生产布局，推进中药材规模化种植和标准化生产，提高道地药材供应能力；加强质量规范管理，推进技术集成创新，推广绿色标准化生产技术模式，提升产品质量。二是加快中药材特优区建设。2017年，我部会同发展改革委、林业局编制印发了《特色农产品优势区建设规划纲要》，提出到2020年，创建并认定300个左右国家级特优区，重点支持标准化生产基地、加工基地、仓储物流基地、科技支撑体系、品牌建设与市场营销体系、质量控制体系等建设。国家级特优区聚焦发展特色粮经作物、特色园艺产品、特色畜产品、特色水产品、林特产品等五大类29个品种，目前已认定2批共146个国家级特优区，其中中药材特优区14个。三是加大扶贫资金支持。2017年，安排补助地方中央财政专项扶贫资金861亿元，2018年增加到1061亿元。按照现行管理要求，中央财政专项扶贫资金项目审批权限下放到县，县级可根据脱贫攻坚规划，统筹用于支持包括中药材在内的特色产业发展，带动贫困群众脱贫增收。

下一步，我部将会同有关部门，按照脱贫攻坚“中央统筹、省负总责、市县抓落实”的工作机制，支持中药材扶贫产业发展，带动农民脱贫致富。

三、关于推动成熟的大企业与贫困县企业的深度合作

我部会同有关部门认真贯彻落实党中央、国务院决策部署，按照绿色兴农、质量兴农、品牌强农的要求，加快大型企业与贫困地区对接，积极支持农村一二三产业融合发展。一是积极推进产业扶贫行动。2017年，中医药局会同我部等5个部门和单位联合印发了《关于开展中药材产业扶贫行动计划的通知》，组织中药企业和医疗机构在贫困地区建设“中药材产业扶贫示范基地”“定制药园”，建立原料药材供应基地，带动贫困户通过发展中药材获得稳定收益。二是扶持壮大龙头企业。通过举办龙头企业负责人培训等活动，宣传龙头企业扶持政策，帮助龙头企业提升经营管理水平；通过搭建农业产业化交易会等产销对接平台，帮助龙头企业拓展产品销路，打造知名品牌；研究完善相关政策措施，推动龙头企业转型升级。目前，全国经县级以上农业产业化主管部门认定的龙头企业达8.7万家，其中省级以上重点龙头企业1.7万家、国家级重点龙头企业1243家，农业产业化龙头企业已成为促进现代农业建设、加快农业供给侧结构性改革、推进乡村产业振兴的重要力量。三是促进产销衔接。在第十四届、十五届中国国际农产品交易会上，举办“省部长推介品牌农产品专场”“我为品牌农产品代言”等专场推介活动，创响道地中药材知名品牌。通过“互联网+”和电商扶贫，促进小农户和大市场有效衔接。

下一步，我部将会同有关部门和单位，因地制宜加快发展对贫困户增收带动作用明显的中药材产业等农业特色优势产业，加快制定和完善扶贫产业规划，建立对接机制推动产业落地，完善利益联结和带贫减贫机制，加强市场营销促进产销对接，强化金融支持，将扶贫工作与发展壮大村级集体经济相结合，为加快推进乡村振兴战略、决胜全面建成小康社会提供有力支撑。

感谢您对农业农村工作的关心，希望对我部工作继续给予支持。
