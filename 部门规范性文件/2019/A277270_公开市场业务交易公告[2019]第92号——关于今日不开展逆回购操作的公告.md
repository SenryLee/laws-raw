# 公开市场业务交易公告[2019]第92号——关于今日不开展逆回购操作的公告

## 公开市场业务交易公告

[2019]第92号

从2019年5月15日开始，人民银行对服务县域的农村商业银行实行较低存款准备金率，分三次实施到位。今日为实施该政策的首次存款准备金率调整，释放长期资金约1000亿元。银行体系流动性总量处于合理充裕水平，今日不开展逆回购操作。

中国人民银行公开市场业务操作室

二〇一九年五月十五日
