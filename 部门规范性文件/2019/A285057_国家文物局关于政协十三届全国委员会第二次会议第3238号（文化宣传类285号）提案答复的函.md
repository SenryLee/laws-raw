# 国家文物局关于政协十三届全国委员会第二次会议第3238号（文化宣传类285号）提案答复的函

文物政函〔2019〕854号

马萧林等4位委员：

您提出的《关于加快建设文物考古类外文版期刊，推动中华文化走出去》的提案收悉。经商中央宣传部、中国社会科学院等部门，现答复如下。

文物考古类外文版期刊对于宣传展示我国文物考古成果，促进中外文化交流，提升中华文化国际影响力传播力具有重要意义。目前我国公开发行30余种文物考古类期刊，得到有关部门的高度重视和支持。中宣部加大政策、资金扶持力度，拟印发《关于推动学术期刊繁荣发展的意见》；对《考古》《考古学报》《敦煌研究》等期刊给予每年40万元资金资助；在“中国出版政府奖·期刊奖”评选、“百强社科期刊”推荐活动中，予以奖励和推介；在2017年德国法兰克福书展上组织中国期刊展，向西方公众展示推介文物考古类期刊。中国社会科学院主编《CHINESE ARCHEOLOGY》（《中国考古》）年刊，受到国外学术界关注和好评。国家文物局每年给予资金补贴，支持《文物》《文物天地》期刊编纂，自2013年以来推动《文物》英文版对外出版发行，为传播传承中华优秀传统文化发挥了积极作用。

正如您所提及，文物考古类期刊面临着宣传推介不够、对外影响力不足的问题。下一步，有关部门将采取措施指导支持文物考古类外文版期刊建设，推动中华优秀传统文化走出去。

一是加强政策引导，优化资源配置。实施中华优秀传统文化传承发展工程，加大对文物考古类期刊扶持力度，加强中国出版物国际推广与传播，扶持海外出版机构翻译出版相关图书。实施《关于推动学术期刊繁荣发展的意见》，中宣部支持有条件有意愿的单位申办服务国家重点领域的学术期刊和外文期刊。将中国文物考古类期刊资源数据纳入国家哲学社会科学文献中心等公共知识库建设工程中统筹推进。

二是加大资金扶持，打造重点品牌。中国社会科学院加强对《CHINESE ARCHEOLOGY》（《中国考古》）年刊的管理与投入，将目前的年刊增改为半年刊；国家文物局继续加大对《文物》英文版期刊资金投入，努力打造具有国际影响力的期刊品牌。

三是重视人才培养，加强团队建设。实施《新闻出版广播影视“十三五”发展规划》、国家文物局文博人才培养“金鼎工程”等，支持科研机构、出版社、高校建设相关专业团队，培养专业人才，加强学术交流和对外合作，加快文物考古类外文版期刊建设。

四是加强对外宣传，提升国际影响。实施中华文物全媒体传播计划，借助传统媒体和新兴媒体融合发展平台，加大文物考古事业对外传播力度，宣传推介文物考古类学术研究成果，广泛传播中国文物事业改革发展成就，增强中华文化国际影响力。

感谢您对文物事业的大力支持！

国家文物局

2019年8月20日
