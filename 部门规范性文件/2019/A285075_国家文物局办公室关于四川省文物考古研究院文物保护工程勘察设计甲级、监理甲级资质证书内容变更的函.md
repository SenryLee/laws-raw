# 国家文物局办公室关于四川省文物考古研究院文物保护工程勘察设计甲级、监理甲级资质证书内容变更的函

办保函〔2019〕1003号

四川省文物局：

你局《关于四川省文物考古研究院变更文物保护工程勘察设计资质证书的请示》（川文物〔2019〕77号）、《关于四川省文物考古研究院变更文物保护工程监理资质证书的请示》（川文物〔2019〕78号）收悉。

经研究，我局同意四川省文物考古研究院文物保护工程勘察设计甲级资质证书的法定代表人由“高大伦”变更为“唐飞”；监理甲级资质证书中的法定代表人由“高大伦”变更为“唐飞”，注册资金由“150万元”变更为“600万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年11月19日
