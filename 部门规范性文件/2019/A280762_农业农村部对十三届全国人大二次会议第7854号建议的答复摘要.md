# 农业农村部对十三届全国人大二次会议第7854号建议的答复摘要

## 对十三届全国人大二次会议第7854号建议的答复摘要

农办议〔2019〕302号

兰平勇代表：

您提出的《关于充分利用他国人口红利，促进我国远洋渔业持续稳定发展的建议》收悉。经商外交部、人力资源社会保障部、移民局，现答复如下。

近年来，随着经济社会快速发展，越来越多的国内劳动力不再愿意从事艰苦的海洋捕捞行业，远洋渔业正面临“招工难”“用工荒”等劳务紧缺问题，行业发展亟需人力资源支撑。

一、关于引进外籍船员

为充分利用国外劳务市场为我远洋渔业发展服务，2013年和2014年，我部联合外交部、公安部和人力资源社会保障部两次印发通知，在浙江省舟山市开展远洋捕捞行业引进外籍船员试点工作。2017年4月，外专局、人力资源社会保障部、外交部、公安部在全国统一实施外国人来华工作许可制度，明确将从事远洋捕捞等特殊领域工作的外国人列为C类来华工作外国人员，舟山市按此要求继续开展试点。试点工作的开展，对远洋渔业企业中国籍远洋渔船雇用外籍船员的管理办法和办理程序等进行了有益探索，一定程度解决了劳动力紧缺的现实困难，为下一步健全完善相关机制积累了宝贵经验。

下一步，我部将会同外交部、人力资源社会保障部和移民局，在参照借鉴前期试点工作办法和有关国家经验做法基础上，研究制定有关政策措施和意见办法。

二、关于完善相关法律法规

引进外籍船员是顺应国际渔业发展形势、解决我国远洋渔业发展难题的有效举措。下一步，我部将会同有关部门进一步健全完善有关法律法规，以适应远洋渔业发展新需求。

三、关于强化社会组织在规范外籍船员行业管理方面的作用

远洋渔业社会组织作为连接远洋企业和渔业主管部门的桥梁纽带，在提供行业服务、反映行业诉求、规范行业管理等方面发挥了重要作用。引进外籍船员试点工作开展期间，有关社会组织积极参与其中，广泛开展调研，主动建言献策，为政策的研究制定和实施落地提供了经验依据。下一步，我部和地方渔业主管部门将继续指导有关社会组织，围绕国家远洋渔业发展目标和中心任务，积极发挥组织协调作用，研究制定配套标准，组织开展相关培训，严格规范外籍船员行业管理，切实维护远洋企业合法权益，保障远洋渔业持续健康有序发展。

感谢您对我国远洋渔业事业发展的关心，希望今后继续对我部工作给予支持。

农业农村部

2019年8月14日
