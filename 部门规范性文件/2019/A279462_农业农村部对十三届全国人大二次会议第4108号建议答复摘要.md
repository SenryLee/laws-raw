# 农业农村部对十三届全国人大二次会议第4108号建议答复摘要

## 十三届全国人大二次会议第4108号建议答复摘要

农办议〔2019〕45号

马文芳代表：

农业机械化和农机装备是转变农业发展方式、提高农村生产力的重要基础，是实施乡村振兴战略的重要支撑。近年来，国家高度重视农业机械化科技创新工作，将农机装备列入实施制造强国战略的重点发展领域，不断加大投入，推进关键技术与装备研发，着重解决农机科技创新能力不强、部分农机装备有效供给不足、农机农艺结合不够紧密等问题。

一是加强政策引领。2016年，工业和信息化部、农业部、发展改革委发文明确农机装备发展目标和重点任务，并布局河南、山东等地重点发展农机装备产业。二是建立协同推进机制。2016年有关部委成立农机装备推进工作组，共同研究提出推动农机装备发展的重点任务。2017年9月，在新疆召开全国农机装备发展现场推进会，全面部署产业转型升级发展工作。三是抓好统筹部署落实。2018年，推动河南、山东组建了省级智能农机创新中心。在今年3月召开的全国春季农业生产暨农业机械化转型升级工作会议上，对贯彻落实《国务院关于加快推进农业机械化和农机装备产业转型升级的指导意见》（国发〔2018〕42号）进行了全面部署。

下一步，我们将认真贯彻落实国发〔2018〕42号文件精神，一是完善协同创新机制，打造开放、协调、高效的国家级农机装备共性技术平台，支持符合条件的省级创新中心申请升级为国家级创新中心。二是加强农机农艺融合。加大农业机械化科学实验基地建设的支持力度，为农机化共性关键技术研究提供基础数据。推进农业机械试验鉴定改革，开展农机性能质量评价等研究，为农机装备新产品转化应用推广提供支撑。三是推进科技创新联盟建设，支持重点企业牵头构建产学研用联合体，按照市场化原则组织协同攻关，发展适合国情、农民急需、先进适用的农机装备。四是支持优势企业实施智能制造工程，推动现代化农机装备智能工厂建设，提升农机装备制造水平和质量管控能力，打造具备国际竞争力和品牌影响力的大型企业集团。五是积极争取有关部门支持，科学谋划未来5至10年农机化科研的重点任务和重点课题，加大科技创新投入，促进我国农业机械化全程全面、高质高效发展。

感谢您对农业机械化工作的关心，希望继续对我部工作给予支持。
