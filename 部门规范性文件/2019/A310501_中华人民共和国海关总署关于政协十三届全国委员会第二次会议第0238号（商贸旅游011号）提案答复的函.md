# 中华人民共和国海关总署关于政协十三届全国委员会第二次会议第0238号（商贸旅游011号）提案答复的函

台盟中央：

您提出的《关于推进跨境电商海关监管工作的提案》（第0238号）收悉。经会同商务部研究，现答复如下：

一、关于“明确各类参与B2B跨境电商主体的法律责任”的建议

在“互联网+”大背景下，跨境电子商务发展势头良好，同时也对相关监管制度提出了新的要求。市场主体运用互联网技术开展B2B跨境电商活动，既要符合《合同法》等规范平等交易关系的法律法规的要求，又要遵守《对外贸易法》《电子商务法》以及海关、税务、外汇等方面的管理规定。《电子商务法》是电子商务领域的基础性和综合性法律，其中第二十六条规定，电子商务经营者从事跨境电子商务，应当遵守进出口监督管理的法律、行政法规和国家有关规定。有关部门将深入研究B2B跨境电商相关问题，系统梳理不同法律相应的监管要求，并在此基础上明确相关主体法律责任。

二、关于“构建与B2B跨境电商未来发展趋势相适应的海关监管程序”“实施负面信息公开政策，建立B2B跨境电商商品负面清单”“海关和其他执法部门与企业联动，建立信息共享机制”的建议

现阶段，海关针对跨境电子商务零售进出口商品，即B2C跨境电商制定了专门的监管政策措施，设计开发了跨境电子商务通关管理系统，同时积极配合地方政府搭建电子商务监管服务平台，对B2C跨境电商进行监管。但针对B2B跨境电商，即跨境电子商务进出口货物，因现阶段还不能将其与一般贸易货物进行区分，所以海关仍按照一般贸易货物监管程序对B2B跨境电商进行监管。随着跨境电商的不断发展，根据企业需求，海关正在启动支持国内电子商务企业、外贸综合服务企业开展跨境电商B2B出口海外仓业务，探索建立相适应的监管制度，并研发信息化系统，在企业提供有效信息的前提下，研究解决跨境电商企业B2B出口海外仓商品退回境内等问题。您所提出的“构建与B2B跨境电商未来发展趋势相适应的海关监管程序”“实施负面信息公开政策，建立B2B跨境电商商品负面清单”“海关和其他执法部门与企业联动，建立信息共享机制”的建议，我们会在下一步制定针对B2B跨境电商的政策中给予积极考虑。

感谢您对海关工作的关心和支持，并欢迎继续对我们的工作提出宝贵的意见和建议。

海关总署

2019年9月13日
