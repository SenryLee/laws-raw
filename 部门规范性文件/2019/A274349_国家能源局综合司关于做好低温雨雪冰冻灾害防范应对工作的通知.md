# 国家能源局综合司关于做好低温雨雪冰冻灾害防范应对工作的通知

国能综通安全〔2019〕4号

各省（自治区、直辖市）、新疆生产建设兵团发展改革委（能源局）、经信委（工信委），各派出能源监管机构，全国电力安委会各企业成员单位，有关电力企业：

据气象部门预报，1月7日夜间起至11日，南方地区将有一次明显降水过程，其中，云南中南部、贵州、江南中西部、华南西部等地的部分地区有中到大雨，云南南部、广西西部和北部、贵州南部等地的部分地区有暴雨，局地有大暴雨。8日夜间至10日，西北地区东部、黄淮、江淮、江汉等地的部分地区有小到中雪或雨夹雪，局地有大到暴雪。为切实做好迎峰度冬期间低温雨雪冰冻灾害防范应对工作，确保电力系统安全稳定运行和电力可靠供应，现就有关要求通知如下。

一、高度重视低温雨雪冰冻灾害防范应对工作

低温雨雪冰冻灾害具有灾害链影响复杂、灾害处置难度大、对群众生活影响严重的特点。特别是2018年12月底以来，我国多地出现入冬后气温最低值，中东部地区持续低温，南方出现雨雪、冰冻、大风天气，造成电力设备覆冰覆雪，导致多条输电线路跳闸停运、部分居民供电受到影响。各单位要进一步提高思想认识，坚决克服麻痹思想，高度重视、切实抓好低温雨雪冰冻灾害防范应对工作。要加强组织领导，认真制定各项应对措施，层层落实责任，确保人员组织到位、防范措施到位、工作落实到位。

二、深入开展雨雪冰冻风险隐患排查治理

各单位要结合本地区冬季气象条件和电力（热力）生产特点，全面排查梳理雨雪冰冻风险隐患，重点对历史覆冰区、舞动区、微气象区以及重要电厂、重要输电通道、重要输变电设备、重要交叉跨越等进行排查，防止设备、导线覆冰。要对输电线路通道内各类危险源进行排查，及时治理危及线路安全的隐患，加固存在垮塌风险的杆塔基础。要对安装的覆冰、舞动监测装置以及加热装置、融冰装置等进行排查，确保随时可用。

三、加强电力设备运行维护和监测预警

发电企业要加强机组检修和运行维护管理，做好发电设备的防寒防冻工作，防止设备冻结损坏事故，提高发电设备运行可靠性水平；要强化燃料管理，做好燃料储运工作，杜绝燃料不足影响机组出力现象。电网企业要加强电网调度监控，强化电网运行管理，科学合理安排电网运行方式，统筹做好电力供需平衡。要加强电网设备运行监测巡视和安全保卫工作，增加对重要输电通道、重要输变电设备以及重点区域、地段的巡视检查密度，及时发现和解决异常情况，防止因线路覆冰、舞动、闪络、外力破坏等情况引发电力安全事故（事件）。要加强与气象部门的沟通联系，及时掌握天气变化趋勢，落实输变电设备防范应对雨雪冰冻等恶劣天气的各项措施，针对电网结构做好各种运行方式下的事故预想，防止大面积停电事故发生。

四、做好防范应对低温雨雪冰冻灾害的应急准备工作

各单位要坚持底线思维和问题导向，从最坏处着想、向最好处努力，结合各自职责，制定防范应对低温雨雪冰冻灾害综合预案， 细化各类专项预案，制作工作手册，加强应急演练，及早做好各项应急准备，提高应急工作的科学性、针对性和可操作性。要统筹做好救援力量、除冰除雪装备设施、应急供电装备、电网抢修物资和冬季生活保障物资供应等各项准备工作。

五、及时开展应急处置和抢修复电工作

各单位要加强应急值班值守和信息报送，遇到重大险情、灾情或发生电力安全事故（事件），要结合职责、按照预案立即启动应急响应，并按照规定及时报告。电网企业要迅速组织力量全力开展抢修复电工作，加大跨区跨省电力支援力度，最大限度挖掘电网输送能力；落实应急处置措施，果断处置运行故障，防止局部问题扩大为全局问题；密切关注险情发展，客观分析、评估电网设备设施受损情况，研究制定详细的电力抢修、临时安置点供电和恢复供电方案，加快受损电力设备设施抢修恢复。抢修复电过程中，要坚持安全第一的原则，妥善安排抢修力量，加强现场安全风险管控，全面落实防倒塔（杆）、防高坠、防滑、防冻等各项安全措施，确保人员安全、作业安全。
