# 国家文物局关于沈阳故宫建设控制地带内美达建设项目的意见

文物保函〔2019〕122号

辽宁省文物局：

你局《关于上报沈阳故宫建设控制地带内美达广场建设项目方案（修改）的请示》（辽文物〔2018〕139号）收悉。经研究，我局原则同意在沈阳故宫建设控制地带内实施美达广场建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应补充拟建项目对沈阳市保护单位利民商场旧址的文物影响评估内容，并对方案作相应完善。

（二）应考虑在适当区域开辟一定空间，对该地段的历史文化和出土文物进行展示。

（三）应落实施工过程中的围挡、防尘等保护措施和应急预案中所提出建立监测系统的承诺，切实做好施工过程中对地下水位、水土流失、振动及环境污染等文物影响因素的监控和管理。

（四）应补充必要的后续措施，防止项目建成运行后产生的废气，如餐饮业产生的油烟等对文物建筑造成污染。

（五）应加强新建建筑周边的景观绿化，确保项目整体与沈阳故宫及其周边环境的协调。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月30日
