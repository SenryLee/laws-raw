# 新闻出版署关于废止35件规范性文件的决定

国新出发〔2019〕38号

各省、自治区、直辖市新闻出版局，中央军委政治工作部宣传局：

为贯彻落实《法治政府建设实施纲要（2015-2020年）》，国家新闻出版署对现行新闻出版领域规范性文件进行了全面清理，决定废止35件，自公布之日起生效。
