# 国家知识产权局对十三届全国人大二次会议第8324号建议答复的函

国知发办函字〔2019〕109号

张桂平代表：

您提出的《关于实施专利扶贫工程，加快实现乡村振兴的建议》收悉，结合财政部、银保监会的意见，现答复如下：

财政部、银保监会和我局均高度重视扶贫工作，认真贯彻落实中央关于打赢精准脱贫攻坚战的部署要求。中央财政设有专门用于扶贫开发的资金。银保监会有针对性地出台银行业金融机构积极投入脱贫攻坚战的指导意见、做好三农和扶贫金融服务工作的通知、做好2019年银行业保险业服务乡村振兴和助力脱贫攻坚工作的通知等政策文件，并先后印发《关于商业银行知识产权质押贷款业务的指导意见》《关于大力推进体制机制创新扎实做好科技金融服务的意见》和《关于提升银行业服务实体经济质效的指导意见》，支持和鼓励包括邮储银行在内的商业银行开展知识产权质押融资业务。2016年8月，原银监会同意邮储银行设立三农金融事业部，充分发挥金融支农作用，积极加强农村金融服务创新，持续加大“三农”领域信贷投放。2015年至2019年3月，邮储银行累计投放金融精准扶贫贷款1194亿元。

我局遵循“真扶贫，扶真贫”的工作方针，突出知识产权特色，积极开展科技扶贫、教育扶贫、智力扶贫、技术扶贫。自1995年以来，持续24年定点扶贫桑植县，2007年起定点扶贫张家口市崇礼区，始终如一、坚持不懈地围绕贫困群众迫切需要解决的基础设施建设、教育、产业发展等方面问题开展扶贫项目，充分发挥知识产权优势，通过举办科技培训班、专利技术培训班、专利技术推广应用交流会、专利技术转化洽谈会和知识产权日宣传活动，促进定点扶贫县技术专利化、专利成果化。已指导桑植县申请专利47项，成功转化12项，其中“生物质制气炉”转化项目每年为企业实现纯利润200多万元，节约木材12万立方米。协调知识产权代理机构为残疾人贫困户创办的蜂传万里有限公司进行技术挖掘，并资助申请4项发明专利，为其养蜂技术提供知识产权保护，促进其扩展市场收益。在崇礼开展知识产权培训和知识产权进企业活动，不断增强全区企业和群众的知识产权申请和保护意识，促使崇礼实现发明专利授权量零的突破。研究制定《地理标志运用促进工程实施方案》，推动实施地理标志运用促进工程，充分发挥地理标志在促进农民增收、农业增效，特别是推动产业扶贫打赢攻坚战方面不可替代的作用。开展地理标志精准扶贫宣讲活动，介绍地方政府在运用地理标志精准扶贫和区域公共品牌建设推广中的成功经验，介绍相关部门在运用地理标志精准扶贫中的作用和经验，指导地理标志商标注册培训等，积极运用地理标志商标促进农民增收、农业产业结构调整和新农村建设，促进贫困地区通过生态农业开发实现可持续发展，切实推动精准扶贫。

同时，以专利密集型产业为主要对象，以专利数据为信息获取主体，于2013 年启动实施国家专利导航试点工程，如今已形成《产业规划类专利导航项目实施导则（暂行）》《企业运营类专利导航项目实施导则（暂行）》系列指导性文件，建立了专利导航园区产业发展及企业运营的工作模式。积极推动国家知识产权大数据中心和知识产权公共服务平台立项，指导支持地方建设有关知识产权公共服务平台及数据库，进一步推动知识产权信息公共服务便利化、集约化、高效化。

下一步，我局将全力配合扶贫办等部门，继续推动专利技术在贫困县的转化运用，在专利导航现有工作基础上，以专利数据为信息获取主体，综合运用专利信息分析和市场价值分析手段，实现专利信息和农业产业发展的紧密结合，明晰农业产业创新方向和重点，强化知识产权前瞻布局，支撑农业产业科学决策。在开展知识产权信息公共服务平台搭建及有关政策制定方面，将给予专利扶贫重点倾斜，根据不同需求，搭建有关专题数据库或信息专栏，开展有关专利信息帮扶、专利信息推送等服务，为扶贫工作提供必要的技术和信息支持。

银保监会将继续引导邮储银行在依法合规、风险可控、商业可持续的前提下，加大金融扶贫支持力度，发展知识产权质押贷款等创新金融模式，探索对采用专利技术的建档立卡贫困人口及其符合规定的主体发放精准扶贫贷款。

财政部表示，按照国务院关于严格控制新设专项，整合目标接近、资金投入方向类同、资金管理方式相近的转移支付项目的要求，不宜再新设专利扶贫专项资金，建议由地方按有关政策要求，结合当地实际情况，统筹现有资金渠道解决专利扶贫问题。

衷心感谢您对知识产权工作的关注，希望继续关心支持知识产权事业发展，对我们的工作提出宝贵意见和建议。

国家知识产权局

2019年7月5日
