# 国家卫生健康委员会关于发布《大气污染人群健康风险评估技术规范》推荐性标准的通告

## 关于发布《大气污染人群健康风险评估技术规范》推荐性标准的通告

国卫通〔2019〕9号

现发布推荐性标准《大气污染人群健康风险评估技术规范》，编号和名称如下：

WS/T 666—2019 大气污染人群健康风险评估技术规范该标准自2020年1月1日起施行。

特此通告。

国家卫生健康委员会

2019年7月22日
