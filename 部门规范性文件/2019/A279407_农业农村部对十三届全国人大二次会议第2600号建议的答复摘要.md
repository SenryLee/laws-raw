# 农业农村部对十三届全国人大二次会议第2600号建议的答复摘要

## 对十三届全国人大二次会议第2600号建议的答复摘要

一、关于加快出台农房抵押政策

2015年以来，根据党中央、国务院统一部署，人民银行牵头在天津市蓟州区等59个县（市、区）开展农民住房财产权抵押贷款试点，指导各试点地区完善确权登记颁证、交易流转平台搭建、价值评估体系、抵押物处置机制建设等配套措施，加强金融产品和服务方式创新，支持实现农民住房财产权。经全国人大常委会审议通过，2018年12月31日农民住房财产权抵押贷款试点的法律授权到期，有关试点工作将纳入农村宅基地制度改革统筹考虑。

下一步，我部将会同人民银行、自然资源部等部门，按照中央经济工作会议、中央农村工作会议和2019年中央1号文件精神，研究制定深化农村宅基地制度改革试点方案，拓展改革试点，丰富试点内容，完善制度设计。

二、关于建立宅基地使用权强制登记制度

目前，自然资源部已建立统一的不动产登记制度，农村宅基地使用权登记已纳入不动产统一登记工作中。2014年以来，全国开展了房地一体的宅基地使用权确权登记颁证工作，计划2020年基本完成。为服务和支持农村宅基地“三权分置”，自然资源部还组织开展了“三权分置”登记试点，探索完善宅基地“三权分置”确权登记模式，保护宅基地所有人、使用权人、抵押权人等主体合法的不动产权益。

下一步，我部将配合自然资源部，按照2019年中央1号文件的要求，加快工作力度，尽快完成房地一体的宅基地使用权确权登记颁证任务，为深化农村宅基地制度改革试点、完善农民住房财产权抵押贷款政策打好基础。
