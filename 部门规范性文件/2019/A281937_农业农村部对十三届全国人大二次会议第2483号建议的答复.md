# 农业农村部对十三届全国人大二次会议第2483号建议的答复

## 对十三届全国人大二次会议第2483号建议的答复

农办议〔2019〕390号

你们提出的关于支持甘肃中西部精准扶贫土地整治重大工程的建议收悉。经商自然资源部，现答复如下。

一、对甘肃中西部地区支持情况

（一）优先支持甘肃中西部地区在内的深度贫困地区开展高标准农田建设。甘肃省中西部地区是集"老、少、边、山、穷、库"于一体的深度贫困地区。其中，甘肃省临夏自治州、武威市天祝自治县等被纳入国家"三区三州"深度贫困地区重点支持范围。农业农村部高度重视贫困地区尤其是"三区三州"等深度贫困地区产业发展，认真贯彻落实习近平总书记在深度贫困地区脱贫攻坚座谈会上的重要讲话精神，制定了《支持深度贫困地区农业产业扶贫精准脱贫方案》和《"三区三州"等深度贫困地区特色农业扶贫行动工作方案》，发挥行业优势，大力帮扶"三区三州"等深度贫困地区发展特色产业。2019年，农业农村部制定了《农业农村部2019年"三区三州"等深度贫困地区农业扶贫实施方案》，优先支持深度贫困地区推进高标准农田建设，在安排建设任务和补助资金时予以倾斜。允许有关省份根据实际情况适度提高贫困地区高标准农田建设投入标准，适当降低单个项目建设规模。

根据国务院机构改革精神，发展改革委农业投资项目、财政部农业综合开发项目、国土资源部农田整治项目、水利部农田水利建设项目等农田建设项目管理职责整合划入农业农村部，集中支持开展高标准农田及农田水利建设。农田建设补助资金按照因素法进行分配，实行"大专项+任务清单"管理方式，各地可以在完成约束性任务的基础上，在大专项支持方向范围内，结合当地实际，按照有关规定统筹中央和地方资金予以支持。2019年，我部下达甘肃省高标准农田建设任务220万亩，安排中央财政资金25.19亿元。据统计，甘肃省中西部酒泉市、张掖市、金昌市、武威市、兰州市、白银市、定西市、临夏自治州等8个市（州）拟建设高标准农田143.1万亩，安排中央财政资金16.39亿元，在任务和资金安排上均体现了对甘肃中西部地区的支持。

（二）大力推进甘肃省开展农村土地综合整治。2013年，财政部和国土资源部共同支持甘肃东部百万亩土地整治重大工程项目建设，下达中央财政资金21.76亿元。2016年，财政部、国土资源部和环境保护部共同支持了甘肃祁连山山水林田湖生态保护修复试点工程（北部），下达中央财政基础奖补资金20亿元支持建设。合计下达土地整治重大工程中央财政资金41.76亿元。

目前，自然资源部为贯彻落实习近平总书记对浙江"千村示范、万村整治"重要批示精神，助推乡村振兴战略实施，促进农村生态文明建设，按照《乡村振兴战略规划（2018—2022年）》关于"加快国土综合整治，实施农村土地综合整治重大行动"的要求，正在研究起草开展土地综合整治示范村镇建设相关文件，重点开展农用地整理、农村建设用地整理和乡村生态保护修复等内容，坚持节约优先、保护优先、自然恢复为主的方针，着力解决国土空间低效利用等问题，逐步形成可复制、可推广的农村土地综合整治制度体系。

二、下一步工作安排

我部将根据《中共中央、国务院关于坚持农业农村优先发展做好"三农"工作的若干意见》和《中共中央、国务院关于打赢脱贫攻坚战三年行动的指导意见》要求，进一步加大对甘肃省特别是甘肃中西部地区高标准农田和农田水利建设支持力度，夯实农业基础。扎实实施产业扶贫三年攻坚行动，从产业规划、主体培育、产销对接、技术服务等关键环节，强化产业帮扶。同时，深入推进"三区三州"等深度贫困地区整合资金，改善深度贫困地区生产条件，推进农业特色产业发展，助推"三区三州"等深度贫困地区特色产业转型升级。

感谢你们对甘肃中西部精准扶贫和土地综合整治工作的关心，希望继续对我部工作予以支持。
