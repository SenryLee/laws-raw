# 国家文物局关于大运河扬州段保护区划内运河南北路改造工程夫差桥建设项目的意见

文物保函〔2019〕555号

江苏省文物局：

你局《关于审批大运河扬州段保护区划内运河南北路改造工程夫差桥设计方案的请示》（苏文物保〔2019〕103号）收悉。经研究，我局原则同意在大运河扬州段保护区划内实施运河南北路改造工程夫差桥建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘。如发现大运河河堤等水工设施遗迹，应调整设计方案，确保文物安全。

（二）应细化拟建桥梁平面图，在大比例尺地形图上明确标注桥墩与河道、河堤的空间关系，以及现状河道实测面宽和水位、河道底部及河堤标高以及堤岸形态。

（三）应在确保车辆行驶安全的情况下，尽可能降低桥梁高度，简化桥梁形式设计，取消与桥梁功能无关的装饰构件，桥梁外观应以灰色调为主。

（四）应细化项目施工方案，严格控制施工开挖范围，明确施工期间的大运河水质及生态环境保护措施，以及施工后期的环境修复措施、大运河标识和展示措施。

（五）应补充项目施工和运营期间的监测措施、应急预案，避免施工破坏河道、岸线形态、水质及生态环境。相关监测数据应及时提交大运河遗产监测系统平台存档。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年6月14日
