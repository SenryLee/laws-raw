# 农业农村部对十三届全国人大二次会议第1222号建议的答复摘要

## 十三届全国人大二次会议第1222号建议的答复摘要

按照国务院印发的《关于建立粮食生产功能区和重要农产品生产保护区的指导意见》，国家积极支持在重要农产品生产保护区范围内，按照集中连片、旱涝保收、稳产高产、生态友好的要求，强化综合生产能力建设。各地可结合国家有关高标准农田建设等具体支持政策，大力推进油菜籽生产保护区建设，积极发展绿色高产高效生产，不断提高油菜籽综合产能和生产效益。同时，通过开展油菜绿色高质高效行动，集成推广绿色高效、资源节约、生态环保的技术模式，推进规模化种植、标准化生产、产业化经营，带动提升“双低”优质油菜生产水平和发展质量。

农业农村部

2019年8月29日
