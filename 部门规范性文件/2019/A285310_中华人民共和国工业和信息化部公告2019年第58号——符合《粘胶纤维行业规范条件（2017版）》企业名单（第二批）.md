# 中华人民共和国工业和信息化部公告2019年第58号——符合《粘胶纤维行业规范条件（2017版）》企业名单（第二批）

## 中华人民共和国工业和信息化部公告

2019年第58号

根据《粘胶纤维行业规范条件（2017版）》和《粘胶纤维行业规范条件公告管理暂行办法》，经企业自主申报、省级工业主管部门核实推荐、专家组复核及现场走访、征求生态环境部意见、网上公示等程序，现将符合《粘胶纤维行业规范条件（2017版）》企业名单（第二批）予以公告。

工业和信息化部

2019年12月13日
