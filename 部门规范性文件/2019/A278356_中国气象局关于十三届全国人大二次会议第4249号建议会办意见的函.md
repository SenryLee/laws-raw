# 中国气象局关于十三届全国人大二次会议第4249号建议会办意见的函

中气议字〔2019〕6号

生态环境部：

现就杨长亚代表《关于加大汾渭平原大气污染防治工作支持力度的建议》（第4249号建议）中关于“加强气象检测能力建设”的建议提出如下会办意见。

气象部门高度重视汾渭平原气象观测设备设施建设，持续提升气象监测能力。截至目前，在汾渭平原共建设有各类地面气象观测站1814个，高空气象观测站3个，天气雷达站8个，西安、郑州、太原3个省会城市建设有极轨气象卫星和静止气象卫星直收站，部分地面气象观测站建设有微波辐射计、激光雷达、辐射、太阳光度、空气颗粒物质量浓度、空气颗粒径谱观测等环境气象观测设备。

与此同时，围绕汾渭平原大气污染防治工作，气象部门加强组织实施，发挥气象监测预报技术优势，助力打赢“蓝天保卫战”。积极推进区域联防联动，建立和完善部门内外污染天气会商机制，组织成立汾渭平原环境气象预报预警中心，汾渭平原三省联合规范大气污染气象条件预报产品，及时向政府部门报送大气污染防治决策气象服务材料。加强环境气象服务能力建设，针对汾渭平原特殊地形研究预报概念模型，开展4—10天雾、霾预报预警和11—20天空气污染气象条件预报业务，预报产品的精准度和预见期不断提高。

但总体来看，该地区仍存在高空风场观测能力不足，专业环境气象观测设备设施覆盖面不够、分布不均等问题。下一步，气象部门将加大汾渭平原大气污染防治工作的支持力度，组织相关单位科学评估汾渭平原气象观测需求，加强气象观测基础设施建设；进一步加强大气污染防治气象服务能力建设，深化重污染天气成因的基础研究，着力提高重污染天气过程的精准度和预见期，完善大气污染气象条件影响的定量化评估和预评估业务；不断深化和拓展部门间合作，进一步强化信息资料共享、大气污染气象条件预报和评估、协同信息发布和联合科技攻关等工作，形成污染防治合力。

以上意见供你部答复代表时参考。

中国气象局
