# 农业农村部关于政协十三届全国委员会第二次会议第1834号（农业水利类172号）提案答复的函

## 关于政协十三届全国委员会第二次会议第1834号（农业水利类172号）提案答复的函

农办案〔2019〕185号

关于加快推广农村土地托管经营的提案收悉，经商银保监会、财政部，现答复如下。

随着我国农村劳动力大量转移和老龄化、兼业化日益加剧，普通农户办不了、办不好、办了不划算的事越来越多，对农业生产性服务需求迫切。发展土地托管等农业生产性服务，有利于引领普通农户参与农业现代化进程，有利于促进服务规模经营发展，有利于促进农业节本增效，有利于推进农业绿色生产发展，是把小农户引入现代农业发展轨道的重要措施。

我部一直高度重视农业生产性服务业发展。近年来，各地在积极探索推进服务规模经营、解决"谁来种地""如何种地"问题的过程中，形成了土地托管、联耕联种、代耕代种等新型农业生产性服务模式。为便于行业管理，我部统称为"农业生产托管",并将其作为推进农业生产性服务业发展、带动普通农户发展服务规模经营的主推服务方式和重要工作抓手，采取政策扶持、典型引领、项目推动等措施，持续加大支持推进力度，取得了良好成效。

一是积极出台扶持政策。为推进农业生产托管加快发展，我部会同国家发展改革委、财政部，先后印发《关于加快发展农业生产性服务业的指导意见》（农经发〔2017〕6号）、《关于大力推进农业生产托管的指导意见》（农办经〔2017〕19号）以及《关于认真做好〈农业部、国家发展改革委、财政部关于加快发展农业生产性服务业的指导意见〉宣传和贯彻工作的通知》（农办经〔2018〕8号），明确农业生产托管的发展思路、重点任务和具体措施，对加快发展农业生产托管进行了全面部署，并要求各地进一步宣传贯彻相关文件精神，为推动农业生产托管和农业生产性服务业发展营造良好氛围。2019年2月，中办、国办印发了《关于促进小农户和现代农业有机衔接的意见》，要求各地加快推进农业生产托管服务，不断提升生产托管对小农户服务的覆盖率，促进农业生产托管规范发展。各地积极贯彻文件精神，根据当地现代农业建设短板和农民的生产需求，研究出台具体实施意见，积极支持村两委、集体经济组织、农民专业合作社发挥作用，通过组织和经营模式创新，组织小农户实现耕地集中连片，统一开展农业生产托管；支持家庭农场、合作社等新型经营主体，通过"流转+托管"等方式，广泛接受农业生产性服务。同时，要求各地加大政策落实力度，积极推动高标准农田建设、土地整治、农业综合开发等重点项目，向开展生产托管的小农户和村庄倾斜，支持服务主体参与集中育秧、粮食烘干、农机作业、预冷贮藏等配套服务设施建设。

二是推动设立财政专项。2017年，农业部、财政部推动设立以支持农业生产托管为主的社会化服务专项，联合印发《关于支持农业生产社会化服务工作的通知》（农办财〔2017〕41号），三年来累计安排中央财政资金110亿元，支持小农户通过农业生产托管接受农业生产性服务，带动小农户发展服务规模经营。2017—2018年，农业生产托管项目在30个省（区、市）877个试点县实施，服务农户近700万户。通过试点带动，截至2018年底，全国以综合托管系数计算的托管面积达3.64亿亩，农业生产托管服务组织37万个，服务对象4630多万个（户），在带动小农户发展现代农业、推动服务规模经营、发展壮大集体经济、实现质量兴农绿色兴农等方面发挥了显著作用，呈现出旺盛的生命力。近日，我部联合财政部印发了《关于进一步做好农业生产社会化服务工作的通知》（农办财〔2019〕54号），再次强调要进一步聚焦农业生产托管为主的社会化服务方式，进一步聚焦服务小农户和关系国计民生的重要农产品生产，鼓励地方统筹安排支持适度规模经营的资金用于项目实施。

三是加强金融保险服务。在信贷担保方面，推动农业信贷担保体系发挥政策性担保的信用优势，引导调动金融机构发放农业贷款、增加农业投入的积极性和主动性。近年来，中央财政每年通过农业生产发展资金安排约200亿元，重点支持全国农业信贷担保体系建设；成立国家农业信贷担保联盟有限责任公司，支持农业生产及与农业生产密切相关的产业融合项目；鼓励地方探索农业保险与银行信贷相结合的"银保模式",缓解农户贷款难题。在涉农保险方面，按照"中央保大宗，保成本；地方保特色，保产量"的原则，不断拓宽涉农保险的覆盖面，基本覆盖了种、养、林等关系国计民生和粮食安全的主要大宗农产品，全国各地区和各经营主体，均可自主申请中央财政补贴，补贴比例也在逐步提高。为充分发挥农业生产保险、价格保险的作用，2017年，银保监会、财政部启动大灾保险试点，将新型农业经营主体三大主粮作物保障水平由保物化成本提升至覆盖土地流转成本；2018年起，我部会同财政部、银保监会，在6个省份选择24个产粮大县，开展三大粮食作物完全成本保险和收入保险试点，推动农业保险转型升级，提高农业生产抗风险能力。2018年，中央财政共拨付保费补贴资金199.34亿元，为1.95亿户次农户提供风险保障3.46万亿元。

下一步，我部将继续认真贯彻落实好党中央、国务院的决策部署，结合实施乡村振兴战略， 会同相关部门加强政策创设，加大项目扶持，营造良好氛围，大力推广面向小农户的农业生产托管，促进农业生产性服务业健康快速发展。一是加大宣传推广力度。指导各地按照文件精神，立足本地实际，确定发展目标，细化支持政策，不断创新托管服务方式，引导小农户由单环节托管、多环节托管、关键环节综合托管逐步走上全程托管，不断提升生产托管对小农户的覆盖率。二是做好项目组织实施。指导地方及时破解项目实施中的重点难点问题，因地制宜确定资金补助方式和重点支持托管的环节、领域、重要农产品，不断完善项目实施制度。三是积极拓展服务领域。以农业生产需求导向，推动服务产业从粮棉油糖等大宗农作物逐步向经济作物、畜牧水产养殖等拓展，服务环节由耕种防收等产中环节逐步向产前、产后环节延伸，逐步实现农业全产业链覆盖。四是加强行业规范管理。切实保护小农户利益，推动建立县级生产托管服务管理平台，加强服务标准建设、服务价格指导、服务合同管理和服务组织动态监测，指导有条件的地方成立区域性托管联盟或协会，加强行业自律管理，推动生产托管服务高质量发展。五是加大政策落实力度。积极推动出台财政扶持、信贷支持、税费减免等措施，不断创新财政补贴方式、完善金融支持政策、畅通人才流通渠道。

感谢贵单位对"三农"工作的关心，希望今后继续支持我们的工作。
