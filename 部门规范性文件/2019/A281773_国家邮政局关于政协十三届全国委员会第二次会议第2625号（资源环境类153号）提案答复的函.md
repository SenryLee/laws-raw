# 国家邮政局关于政协十三届全国委员会第二次会议第2625号（资源环境类153号）提案答复的函

## 关于政协十三届全国委员会第二次会议第2625号（资源环境类153号）提案答复的函

国邮函〔2019〕106号

梁志祥等2名委员：

您们提出的《关于推进绿色中国建设，进一步加强规管过度包装的提案》（第2625号）收悉。结合我局职责，现答复如下：

国家邮政局深入贯彻落实习近平生态文明思想，高度重视行业生态环保工作，坚持守土有责，系统治理，强化顶层设计和统筹部署，扎实推进，持续推动邮政业绿色发展。

一、关于完善相关法律法规和标准体系

国家邮政局推动在《中华人民共和国电子商务法》《快递暂行条例》中增加专门条款对绿色包装进行规定，明确了快递绿色包装治理的上位法依据。目前，我局正推动修订《邮政行业安全监督管理办法》，增设生态安全相关内容，进一步明确企业的生态环保主体责任，强化绿色治理法制保障。

我局高度重视快递包装标准体系建设，切实加大绿色包装相关标准的制修订工作。一是组织完成了《快递封装用品》系列国家标准的修订，组织起草并发布《邮政业封装用胶带》《邮件快件包装填充物技术要求》等行业标准，在标准中明确绿色环保、减量化及循环利用等相关技术指标，引导企业使用绿色包装产品。二是组织制定《邮件快件包装基本要求》行业标准，指导企业简约包装、科学包装，避免过度包装。三是加强与国家标准委和认监委协调沟通，积极推进《快递绿色包装评价》国家标准的制定。四是会同市场监督管理总局稳步推进快递包装绿色产品认证体系建设。

二、关于快递包装回收循环利用

国家邮政局立足自身职责稳步推进快递包装回收循环利用。今年初印发《2019年行业生态环保工作要点》，明确提出大力实施"9571"工程，年底前在全国1万个邮政快递营业网点实现包装废弃物回收箱设置。研究印发《邮件快件包装废弃物回收箱应用参考》，推动在邮政快递网点设置回收箱。引导快递企业通过在高校和社区网点回收、快递员上门回收即"逆向物流"开展包装物回收循环利用。推动建立快递包装生产者、使用者和消费者在内的多方回收体系，引导和推动寄递企业探索建立消费者激励机制，鼓励快递企业通过与包装生产企业合作等方式探索建立包装回收再利用闭环管理模式。大力推广可循环快递盒、快递箱。加强与有关部门的沟通协调，积极参与垃圾分类部门协作机制，推动完善社会回收体系，逐步实现包装物最大限度循环再利用和包装废弃物集中无害处理。

三、关于推进快递绿色包装技术和产品供给

国家邮政局鼓励寄递企业、邮政用品用具生产企业加强与相关领域高校、科研机构合作，在教育、科研、人才培养等方面形成合力，健全产学研一体化创新机制；鼓励支持企业、科研机构申请政府环保科技项目，就绿色包装技术申报邮政行业技术研发中心和研发奖项；发挥快递业绿色发展产学研协同创新示范基地平台作用，推动邮政行业产业发展的关键性技术研发、成果转化和系统集成；面向社会开展行业绿色产品、绿色技术和绿色模式公开征集，增加行业绿色供给。目前，行业在包装研发创新方面取得了一定成效。顺丰、京东、苏宁等企业建立了绿色包装实验室。菜鸟网络、顺丰研发使用生物基材料包装袋、无胶带纸箱等。中通与第三方合作生产了氧化和微生物双降解的绿色包装袋。申通与清华大学化学工程系合作研发可降解的塑料袋等。

四、关于加强监督管理

国家邮政局将行业生态环境保护纳入对市场主体监管的重要内容。加强行业信用体系建设，把快递绿色包装应用情况纳入行业信用评定指标。开设行业生态环保专用监督邮箱。组织开展寄递企业生态环保主体责任落实情况专项调研检查。坚持不懈督促和引导邮政企业和各品牌快递企业按照邮政管理部门的统一部署，持续加大投入，按照"绿色化、减量化和可循环"的目标原则稳步推进绿色包装治理。同时，加强《快递业绿色包装指南（试行）》贯彻落实，研究建立行业生态环境保护评价制度，强化信息报告和工作通报，建立统计监测制度等。

五、关于快递包装源头治理

我局加强邮政用品用具市场监管，指导和督促企业按照标准生产用品用具。委托第三方技术检测机构每年抽取部分样品进行质量检测，对检测结果不合格的，要求生产企业进行整改后重新送检。对多次抽检不合格的，由地方邮政管理部门实施约谈告诫甚至依法查处。各级邮政管理部门按照"双随机"的方式对用品用具生产企业开展监督检查，对检查中发现的问题及时予以处理。此外，针对电商件占快件总量60%以上现实情况，我局加强与商务部的沟通，联合开展调研，组织电商企业、快递企业召开座谈会推进电商快递协同治理，督促相应企业共同落实环保责任。就寄递渠道而言，收寄是源头。各级邮政管理部门引导寄递企业加强与上游用户的沟通，通过向上游嵌入前置，提供包装、收寄一体化服务，逐步实现一次包装达到寄递封装要求，大幅减少二次包装。

六、关于加强宣传教育

近期，国家邮政局印发了《2019年"邮来已久、绿动未来"主题宣传活动工作方案》，组织全行业开展"邮来已久、绿动未来"主题宣传活动。要求全行业加大宣传力度，积极开展"绿色寄递"进社区、进校园活动，开展形式多样宣传活动。同时，要求行业加大培训学习力度，进一步抓规范、提素质、强能力、树形象，切实提升从业人员的环保意识，从源头主动进行包装的减量化和可循环，带动引导消费者践行绿色低碳的用邮生活方式，增强行动自觉，营造"绿色用邮，人人有为"的良好氛围。

目前，国家邮政局正大力实施"9571"工程，即年底电子运单使用率95%、50%以上电商快件不再二次包装，循环中转袋使用率达到70%、在1万个邮政快递营业网点设置包装废弃物回收装置，全面加强邮政行业绿色治理工作。您们在提案中提出的建议，我们予以采纳，并将结合行业实际抓好落实。

下一步，国家邮政局将继续深入学习贯彻落实习近平生态文明思想，着力推进包装绿色治理，为全国生态文明建设和我国经济高质量发展做出应有的贡献。

感谢对快递业绿色发展的关心和支持！
