# 中共教育部党组关于张建华等同志职务任免的通知

教党任〔2019〕140号

中共北京邮电大学委员会：

经与中共北京市委商得一致，2019年5月29日研究决定：

张建华、徐坤同志任中共北京邮电大学委员会委员、常委，孙洪祥同志任中共北京邮电大学委员会常委；免去温向明同志的中共北京邮电大学委员会常委职务。

中共教育部党组

2019年6月11日
