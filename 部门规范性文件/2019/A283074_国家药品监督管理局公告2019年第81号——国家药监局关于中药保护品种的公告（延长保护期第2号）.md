# 国家药品监督管理局公告2019年第81号——国家药监局关于中药保护品种的公告（延长保护期第2号）

## 国家药品监督管理局公告

2019年第81号

## 国家药监局关于中药保护品种的公告（延长保护期第2号）

根据《中药品种保护条例》第十六条及有关规定，经国家中药品种保护审评委员会组织的委员审评、国家药品监督管理局核准，对山东凤凰制药股份有限公司生产的天丹通络胶囊、武汉联合药业有限责任公司生产的生血宁片共2个中药保护品种继续给予2级保护，其保护期限、保护品种号分别为2019年10月09日—2024年11月05日、ZYB20720190040以及2019年10月09日—2026年03月20日、ZYB20720190050。

特此公告。

国家药监局

2019年10月9日
