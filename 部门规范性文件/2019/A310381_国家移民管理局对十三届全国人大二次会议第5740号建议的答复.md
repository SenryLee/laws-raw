# 国家移民管理局对十三届全国人大二次会议第5740号建议的答复

霍震寰代表：

您提出的关于粤港澳共谋游艇经济，开辟湾区融合新天地的建议收悉，现答复如下：

内地游艇业发展起步较晚，基础比较薄弱，产业结构尚不完整，配套政策有待调整优化。为支持和促进游艇产业发展，服务广东自由贸易试验区建设，2017年6月，交通运输部、公安部、海关总署、原质检总局联合复函广东省人民政府，原则同意广东省人民政府《中国（广东）自由贸易试验区粤港澳游艇自由行实施方案》（以下简称《实施方案》）。《实施方案》提出粤港澳自由行游艇实行“定点停靠、就近联检”的管理模式，港澳游艇在口岸办理入境手续后，可停泊至就近的指定游艇会码头，在指定出入境口岸之间航行或前往规定水域游览可简化出入港手续，同时依托国际贸易“单一窗口”，建立电子通关平台，实现数据一次申报、监管部门共享共用。

我局根据《实施方案》部署广州、深圳、珠海出入境边防检查总站积极宣传政策措施，充分解读法律规定，依法履行监管责任，并在游艇可视可控、游艇会积极履行自管义务的前提下为粤港澳自由行游艇提供以下出入境（港）便利：一是游艇出入境时，对通过国际贸易“单一窗口”向边检机关申报游艇及其载运人员电子信息的，免予收取纸质申报单证。二是港澳游艇在游艇会码头停靠期间，登艇人员免办登轮证件，游艇之间搭靠免办搭靠手续。三是对离港前往划定水域活动并返回原码头的港澳游艇，凭游艇负责人或其出入境业务代理单位提交的《游艇离港活动申报表》免办出港、入港手续，游艇载运人员免办登轮证件。四是港澳游艇在指定的游艇会码头之间移泊的，凭游艇负责人或其出入境业务代理单位提交的《游艇离港活动申报表》，免办出港、入港手续。

对于您提出的涉及出入境边防检查工作的建议，我局积极支持。一是关于指定专责部门全权负责游艇出入境申报的建议，考虑相关工作具有专业性和法定要求，依据《中华人民共和国出境入境管理法》第五十一条规定，建议由出入境业务代理单位向边检机关申报并办理游艇进出口岸相关手续，代理单位可通过国际贸易“单一窗口”或国家移民管理局政务服务平台向边检机关报备港澳游艇出入港，申请登轮许可、船舶搭靠许可等。二是为支持举办游艇国际性赛事和活动，便利境外游艇出入境，边检机关在相关赛事和活动期间可临时派员前往游艇集中入出境的游艇会现场办理边检手续。三是关于港澳游艇在大湾区内“多点停靠”和沿珠江内河延伸航线等建议，涉及港澳游艇停泊点、游览水域调整，由广东省人民政府研究确定。四是关于游艇码头对外开放标准、适游水域等建议，涉及国家口岸管理办公室、交通运输部等部门主管事项，我局将配合做好相关研究工作。

感谢您对移民管理工作的关心和支持。
