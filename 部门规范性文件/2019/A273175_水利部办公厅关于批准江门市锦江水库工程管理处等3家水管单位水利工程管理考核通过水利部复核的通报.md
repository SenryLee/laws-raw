# 水利部办公厅关于批准江门市锦江水库工程管理处等3家水管单位水利工程管理考核通过水利部复核的通报

办运管〔2019〕2号

各流域管理机构，各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局，各有关单位：

根据珠江水利委员会、淮河水利委员会申报，依据《水利工程管理考核办法》（水建管﹝2016﹞361号）规定，2018年11月，水利部运行管理司组织专家对江门市锦江水库工程管理处、广东粤港供水有限公司、骆马湖水利管理局嶂山闸管理局等3家水管单位水利工程管理考核进行了复核。根据复核结果，经审查和公示，批准上述3家单位水利工程管理考核通过水利部复核，现予以通报。

水利部办公厅

2019年1月4日
