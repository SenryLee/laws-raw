# 公开市场业务交易公告[2019]第144号——关于今日不开展逆回购操作的公告

## 公开市场业务交易公告

[2019]第144号

2019年7月25日，金融机构法定存款准备金退缴可对冲央行逆回购到期等因素的影响，银行体系流动性总量处于合理充裕水平。今日不开展逆回购操作。

中国人民银行公开市场业务操作室

二〇一九年七月二十五日
