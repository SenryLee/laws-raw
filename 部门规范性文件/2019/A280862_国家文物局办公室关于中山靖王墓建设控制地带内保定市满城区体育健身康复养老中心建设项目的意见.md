# 国家文物局办公室关于中山靖王墓建设控制地带内保定市满城区体育健身康复养老中心建设项目的意见

办保函〔2019〕708号

河北省文物局：

你局《关于呈报保定市满城区体育健身康复养老中心项目涉及中山靖王墓建设控制地带设计方案的请示》（冀文物字〔2019〕94号）收悉。经研究，我局暂不同意在中山靖王墓建设控制地带内实施保定市满城区体育健身康复养老中心建设项目。

一、对所报方案提出以下修改完善意见：

（一）明确拟建项目与中山靖王墓主神道的空间位置关系，按照《中山靖王墓保护规划》关于一类建设控制地带的管理要求，论证项目建设的必要性与可行性和另行选址的可能性。

（二）深化建筑设计，屋面不宜铺设太阳能集热器，建筑外观样式、色彩应与遗址整体环境和区域城市建设风格相协调。

（三）深化文物影响评估报告，科学评价中山靖王墓价值，分析项目建设对中山靖王墓园格局的景观影响，补充体育馆现状说明、项目选址遥感照片等。

二、请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年8月7日
