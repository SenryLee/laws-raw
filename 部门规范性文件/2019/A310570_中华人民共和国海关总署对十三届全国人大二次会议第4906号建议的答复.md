# 中华人民共和国海关总署对十三届全国人大二次会议第4906号建议的答复

林水栖、姜建军、赵建社、XXX斌、张传卫、佘丹青、吴惜伟、吴翔、廖贵平、宁凌、刘小权等11名代表：

你们在十三届全国人大二次会议上提出的《关于构建湛江安全高效开放型现代农业经济新平台支持海南自由贸易区（港）和粤港澳大湾区发展的建议》（第4906号）收悉。经商财政部、农业农村部、广东省人民政府，现就有关建议答复如下：

一、关于“加快湛江综合保税区设立审批”

我署原则支持设立湛江综合保税区，财政部和广东省人民政府也表示原则支持湛江在条件具备时按现有程序设立综合保税区。为规范综合保税区的审核设立，我署会同相关部门研究制定了《综合保税区审核设立指导意见》，规定新设综合保税区需具备相应的标准。据测算，目前申请的湛江综合保税区尚未达到设立标准。请地方政府继续做好申建准备工作，特别是加大招商力度，吸引适合入区的项目落地发展，有计划地培育本地产业与引进项目间的配套对接，待条件成熟后我署将会同相关部门予以积极支持。

二、关于“打造农产品贸易综合服务平台”

农业农村部高度重视农产品批发市场体系建设，2018年4月，指导广东、海南对所属区域内批发市场进行复查，认定广东省35家市场为农业农村部定点市场，进一步完善健全了农产品信息采集系统，规范和引导全国批发市场建设。下一步，农业农村部将加大对海南和粤港澳大湾区的支持力度，加大国家级批发市场和田头市场支持力度，推动当地农产品流通体系建设。

广东省着力打造农产品贸易平台，推动全省各市区农产品产销对接工作快速发展。一是办好广东-东盟农产品交易博览会。二是大力推广“12221”农产品产销对接模式。三是加快湛江农产品贸易服务平台的建设步伐。目前，湛江市大中型农产品批发交易市场有21家，农产品批发市场年交易量307万吨，年交易额达208亿元。下一步，湛江市将依托具有成熟产业链的农业、渔业等特色产业的强大基础，推动农海产品与其他产品的商贸流通业跨界融合发展。为大力支持农产品贸易综合服务平台及交易中心等建设，广东省2019年省级预算安排的乡村振兴战略专项资金中，25亿元用于现代农业产业园建设，4.9亿元用于发展“一村一品一镇一业”，1亿元用于培育新型农业经营主体和构建新型乡村助农服务体系。

三、关于“建设高水平快速检验检测防控体系”

我署高度重视国门安全能力建设，将支持湛江海关提升国门安全保障能力，助力湛江农业农村发展，保障大湾区农产品供给安全。湛江海关正在编制国门安全能力建设规划，力争用3年时间打造3个国家重点实验室（包括国家海洋生物重点实验室、国家精细化工重点实验室、国家粮食安全检测重点实验室），重点建设6个区域中心实验室（包括动物检疫、植物检疫、卫生检疫、机电轻纺、石油化工和水产品检验实验室）和8个常规实验室。以此构建完善检验检测技术服务体系，提升专业检测技术能力，满足执法把关检验检测需要，服务国家和区域发展战略实施。

广东省坚持“四个最严”要求，切实保障人民群众“舌尖上的安全”，开展了以下工作：一是加大农产品监测力度。支持湛江市引进人才，加强检测技术培训，完善农产品质量检测体系。目前，市、县、乡镇三级农产品质量检测体系已基本形成，已建立1个市级农检机构，6个县级农检机构，70个乡镇农产品质量检测站。二是持续提升农产品检测水平。湛江市农检中心已具备对农残、重金属、畜产品和种子等检测能力，2017年被原农业部认定为国家农产品质量安全风险评估实验室。三是完善食品质量安全控制体系建设。湛江市依托湛江海关对出口港澳食品生产企业实施备案管理，要求企业建立和实施以危害分析和预防控制措施为核心的食品安全卫生控制体系，确保出口食品的生产、加工、储存过程符合进口地区相关法律法规要求，目前出口食品生产企业均建立完善可追溯的质量安全控制体系，全面保障供应港澳的食品优质、安全、顺畅、稳定。

四、关于“推进现代农业经济高质量发展”

中央财政和广东财政高度重视并积极支持农业领域的科技创新工作，通过中央引导地方科技发展专项资金，支持包括海南在内的地方政府围绕国家科技发展战略和地方经济社会发展目标开展改善科研基础条件、优化科技创新环境、促进科技成果转移转化工作。中央财政将继续积极发挥职能作用，通过现行资金渠道支持相关领域科研工作。广东省级涉农专项资金采取“大专项＋任务清单”模式，并按规定分类整体下达，资金额度不细化至具体项目，由市县尤其是县自主确认具体项目，同时，县级在完成上级约束性任务后，可将剩余资金调剂用于其他涉农项目，赋予了市县更大的自主权。2019年广东省已下达湛江市市县统筹实施项目部分涉农资金共104972万元。根据《广东省人民政府关于印发广东省省级财政专项资金管理办法（试行）的通知》，不宜每开展一项工作都设立一项专项资金，可统筹安排相关资金。

农业农村部从国家战略规划角度，一方面聚焦构建安全高效开放型农业经济的顶层设计，制定扶持政策，于去年11月印发了《农业农村部关于贯彻落实〈中共中央国务院关于支持海南全面深化改革开放的指导意见〉的实施方案》，就编制南繁硅谷建设规划、加快南繁科研育种基地及其配套服务区建设、谋划建设国家热带农业科学中心、推进南海渔业资源开发保护等方面与海南省进行深入的合作交流。另一方面，聚焦农业科技发展领域，充分利用海南自由贸易试验区（港）、粤港澳大湾区科研成果和人才优势，把握政策溢出效应，设立专项科研资金，推进产学研深度融合，推动与海南全球动植物种质资源引进中转基地合作，建设繁育种质资源科技发展平台，实施科技创新驱动，促进农业经济转型升级高质量发展。近年来，农业农村部启动了国家现代农业产业科技创新中心（以下简称“科创中心”）建设工作，通过创新体制机制，推动农业产学研深度融合。推进科技与产业、企业、人才、金融在科创中心融合发展，打造科研中心、转化中心、研发中心、人才中心和科技体制机制模式创新中心，着眼全产业链、全要素、全过程打造主导产业和优势特色，着力促进创新要素集聚、关键技术集成、关联企业集中、优势产业集群，努力打造科技与产业深度融合的“农业硅谷”和区域经济增长极。已批复广州科创中心围绕“一核两带四区多园”总体布局，发展现代种业、功能农业、智慧农业三大产业。下一步，将争取把构建湛江安全高效开放型现代农业经济新平台纳入部省“十四五”规划重点工作，谋划实施一批标志性重大工程项目，继续加强政策创设，在“两区”建设等方面加大倾斜力度，推动国家质量兴农战略规划落实落地，为助力湛江市农业经济转型升级和高质量发展作出积极贡献。

广东省积极贯彻落实乡村振兴战略部署，大力加强农业科技力量建设，推进全省农业科技创新与推广应用，助力全省现代农业高质量发展。一是扎实推进农业科技创新与成果转化。农业科技创新联盟基本覆盖全省涉农科研单位，农业科研成果项目库以及成果转化信息平台在全省21个地级市同步推广应用，广州国家现代农业产业科技创新中心正在创建中。截至目前，广东省建设现代农业产业技术体系创新团队51个，将紧紧围绕主导农业产业转型升级和提质增效，依托国家在粤和我省科技创新资源，打造农渔产业技术体系创新团队、共性关键技术研发创新团队，按照农产品从生产到餐桌的关键环节和共性技术，建设“环环相扣”布局创新链、产业链和资金链的广东省现代农业产业技术体系，努力提升科技创新整体合力和产业竞争力。二是广东省高度重视区域农业合作机制。目前，湛江市与其他城市政府间签订的农业合作协议包括《海口湛江两市农产品产销合作框架协议》、《北部湾城市菜篮子协作框架协议》等。湛江、海口两市企业间签订了《蔬菜供销合同》，下一步，将依托湛江市霞山水产品批发市场、徐闻县农产品交易市场及湛江南方水产市场经营管理有限公司（广东省农业农村厅定点市场）等湛江本地相关流通基础设施，提升服务开放型农业经济的功能。
