# 国家文物局关于政协十三届全国委员会第二次会议第0506号（文化宣传类055号）提案答复的函

文物保函〔2019〕736号

郭天康等2位委员：

您提出的《关于进一步加大对甘肃长城保护利用支持力度的提案》收悉，现答复如下：

长城是我国现存规模最大的文化遗产，是中华民族的精神象征，在中华文明史和中华传统文化发展史上具有不可替代的重要价值与地位。1987年，长城被列入联合国教科文组织《世界遗产名录》。党中央、国务院历来高度重视长城保护工作。2006年，国务院批准通过了《长城保护条例》。2019年，文化和旅游部、国家文物局印发《长城保护总体规划》，推动建立长城保护传承利用长效工作机制，督促各地将长城保护作为一项长期任务持之以恒地抓下去。

甘肃省境内长城分布于38个县、市、区，包括战国、汉、明等历史时期修筑或使用的长城墙体与附属设施，以及与长城防御体系相关的遗址遗迹，具有分布广、类型多、时代跨度大的特点。国家文物局积极支持甘肃省开展长城保护工作，重点指导做好省级长城保护规划编制、长城本体保护修缮、抢险加固，以及涉及长城的基本建设考古与保护项目，有效保护了长城本体及其周边环境的安全。

你们提出的利用长城文物构建中华文明标识、加大对甘肃省长城保护项目的支持力度、建设国家级古代壁画与土遗址重点实验室等建议非常重要。国家文物局将与甘肃省人民政府共同做好如下工作：

第一，指导甘肃省文物局贯彻落实《关于加强文物保护利用改革的若干意见》和《长城保护总体规划》要求， 在甘肃省长城资源调查成果基础上，进一步加强长城价值体系研究，深入阐述长城作为国家文化地标和精神标识的深刻内涵，明晰其在甘肃省文化建设中的突出地位，为开展长城保护利用工作提供依据。

第二，督促地方人民政府及有关部门做好省级长城保护利用规划编制，明确甘肃省境内长城保护的总体目标、主要任务和重点项目，科学遴选、公布长城重要点段，并结合生态保护、文化旅游、扶贫等方面工作统筹考虑保护利用措施、方式和强度等，注重展现长城整体风貌和文化内涵，依法、有序开展长城保护利用工作。

第三，继续加大对甘肃省长城保护利用工作的支持力度。指导地方人民政府、文物部门夯实管理责任，强化预防性保护和研究性修缮理念，根据长城本体保存现状和病害情况，区分轻重缓急，有计划地开展长城保护维修项目，确保项目质量和长城安全。督促地方人民政府切实加强日常巡查、监测和养护工作，落实长城保护员制度，并积极探索社会力量参与长城保护利用工作的途径，营造社会各界广泛参与的良好氛围。

第四，继续支持敦煌研究院等单位发挥资源、技术和人才优势，加强与国内外科研机构和高校的合作，开展跨学科、多学科合作研发和攻关，积极探索、创新西北地区石窟寺保护、土遗址保护、壁画修复等方面新技术，建设一支具有特色和技术特长的专业团队。我局将在相关科研基地、重点实验室评审中对这些单位予以统筹考虑。

感谢你们对长城保护利用工作的关心。

国家文物局

2019年7月26日
