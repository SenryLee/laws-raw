# 中华人民共和国工业和信息化部公告2019年第54号——关于确定纺织服装创意设计试点园区（平台）名单（第四批）和纺织服装创意设计试点园区（平台）（第一批）通过复核名单的公告

## 中华人民共和国工业和信息化部公告

2019年第54号

根据《工业和信息化部关于印发<纺织服装创意设计试点示范园区（平台）管理办法（试行）>的通知》（工信部消费〔2016〕396号）要求，经园区（平台）自愿申报、省级工业和信息化主管部门推荐、专家评审和网上公示等程序，确定纺织服装创意设计试点园区（平台）名单（第四批）和纺织服装创意设计试点园区（平台）（第一批）通过复核名单。现予公告。

附件：

1.纺织服装创意设计试点园区（平台）名单（第四批）

2.纺织服装创意设计试点园区（平台）（第一批）通过复核名单

工业和信息化部

2019年11月19日
