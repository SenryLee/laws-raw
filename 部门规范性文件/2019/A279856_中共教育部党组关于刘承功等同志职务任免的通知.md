# 中共教育部党组关于刘承功等同志职务任免的通知

教党任〔2019〕161号

中共东华大学委员会：

经与中共上海市委商得一致，2019年6月19日研究决定：

刘承功同志任中共东华大学委员会委员、常委、书记；免去朱民同志的中共东华大学委员会书记、常委、委员，蒋昌俊同志的中共东华大学委员会副书记、常委、委员职务。

中共教育部党组

2019年7月2日
