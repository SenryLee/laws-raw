# 交通运输部办公厅关于公布2019年度公路波形梁钢护栏等八类交通运输产品质量行业监督抽查结果的通知

交办科技函〔2019〕1069号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）:

为提升交通运输产品质量，促进交通运输高质量发展，依据《交通运输产品质量行业监督抽查管理办法（试行）》（交科技发〔2012〕32号），我部组织实施了公路波形梁钢护栏、路面标线涂料、路面标线用玻璃珠、高密度聚乙烯硅芯塑料管、玻璃钢管箱、公路隧道LED照明灯具、桥梁支座、预应力混凝土用钢绞线等8类产品质量行业监督抽查，现将抽查结果公布如下：

一、基本情况

按“双随机、一公开”的原则，我部根据各省（区、市）交通运输主管部门报送的公路工程建设项目重点产品基本信息，组建监督抽查对象信息库，随机抽取确定抽查对象，并在部监督抽查检验机构库中随机选取了国家交通安全设施质量监督检验中心等22个检验机构负责指定地区和工程项目使用产品的监督抽查工作。部公路科学研究院为牵头技术机构，负责组织协调和监督检查等工作。各检验机构随机选派抽查人员，严格按照部有关文件要求和相关标准规范开展监督抽查工作。

二、抽查结果

本次监督抽查随机选取了28个省（区、市）的111个路段，涉及169家生产企业的453个批次产品，抽样样品总数6513组（件），总体抽样合格率为92.9%，共发现34家企业、37个批次产品不合格，其中18家企业、19个批次已完成整改，经复查确认合格，此外有5个工程项目更换了产品供货企业。

（一）公路波形梁钢护栏。

在23个省份抽查了45个路段、43家生产企业的225个批次、5216个样品，总体抽样合格率为93.3%。

其中，公路波形梁钢护栏板抽取了22家生产企业、56个批次、1120片样品，抽样合格率为98.2%，主要不合格指标为定尺长度、防腐层外观、防腐层厚度（见附件1）。

公路波形梁钢护栏立柱抽取了23家生产企业、57个批次、1140根样品，抽样合格率为93.0%，主要不合格指标为定尺长度、防腐层外观、防腐层厚度、防腐层附着性、立柱壁厚（见附件2）。

公路波形梁钢护栏防阻块抽取了23家生产企业、55个批次、1100个样品，抽样合格率为94.5%，主要不合格指标为防腐层外观、防腐层厚度（见附件3）。

公路波形梁钢护栏拼接螺栓抽取了32家生产企业、57个批次、1856套样品，抽样合格率为87.7%，主要不合格指标为防腐层外观、防腐层厚度、整体抗拉荷载（见附件4）。

（二）路面标线涂料。

在18个省份抽查了29个路段、22家生产企业43个批次、589组样品，总体抽样合格率为97.7%，主要不合格指标为玻璃珠含量（见附件5）。

（三）路面标线用玻璃珠。

在8个省份抽查了9个路段、7家生产企业、11个批次、48组样品，总体抽样合格率为63.6%，主要不合格指标为粒径分布、成圆率（见附件6）。

（四）高密度聚乙烯硅芯塑料管。

在13个省份抽查了21个路段、20家生产企业、32个批次、100组样品，总体抽样合格率为84.4%，主要不合格指标为结构尺寸、拉伸屈服强度、耐落锤冲击性能（见附件7）。

（五）玻璃钢管箱。

在5个省份抽查了10个路段、10家生产企业、16个批次、16组样品，总体抽样合格率为56.3%，不合格指标为拉伸强度、弯曲强度、氧指数、巴柯尔硬度（详见附件8）。

（六）公路隧道LED照明灯具。

在2个省份抽查了2个路段、3家生产企业、7个批次、7套样品，样品总体抽样合格率为100%（详见附件9）。

（七）桥梁支座。

在18个省份抽查了37个路段、29家生产企业、57个批次、342组样品，总体抽样合格率为89.5%，不合格指标为尺寸偏差、抗压弹性模量、抗剪弹性摸量、内在质量（详见附件10）。

（八）预应力混凝土用钢绞线。

在20个省份抽查了45个路段、36家生产企业、62个批次、195组样品，总体抽样合格率为100%（详见附件11）。

三、有关要求

各级交通运输主管部门要高度重视产品质量，积极配合部开展好监督抽查工作，认真对待监督抽查结果，加强标准宣贯和实施监督，切实加强产品质量监管，为加快建设交通强国，推动交通运输高质量发展奠定坚实基础。

（一）要将本次抽查不合格产品信息通报相关部门，加大对相关企业和单位的跟踪检查力度。督促不合格产品生产企业尽快开展整改，及时提交复查申请和整改报告，配合有关检验机构做好复查工作。

（二）要切实加强交通运输产品质量监管。对于此次监督抽查发现产品质量出现下降的公路波形梁钢护栏拼接螺栓、高密度聚乙烯硅芯塑料管、玻璃钢管箱，抽样合格率较低的路面标线用玻璃珠，以及已取消生产许可证的桥梁支座等产品，要密切关注本地区产品质量变化，综合运用进场抽查、过程监督、监督抽查、竣工验收等多种手段，进一步加强产品质量监督管理，确保符合标准的产品进入交通运输市场。

（三）要持续加强国家和行业标准宣贯和实施监督。结合本地区工作实际，特别是对新发布的国家和行业标准及时组织宣贯和实施，督促业主单位和工程建设单位及时修订工程建设项目设计文件，严格选用符合标准的产品。
