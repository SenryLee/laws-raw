# 国家邮政局办公室关于取消《中华全国集邮联合会第八次代表大会》纪念邮票发行计划的通知

国邮办函〔2019〕378号

中国邮政集团公司办公厅：

根据实际工作情况，我局决定将2019年纪特邮票发行计划中《中华全国集邮联合会第八次代表大会》纪念邮票一套1枚（小型张）的发行计划予以取消。

特此通知。

国家邮政局办公室

2019年12月17日
