# 农业农村部关于政协十三届全国委员会第二次会议第3298号（农业水利类274号）提案答复的函

## 关于政协十三届全国委员会第二次会议第3298号（农业水利类274号）提案答复的函

您提出的关于加快压减干旱半干旱地区地下水开采量的提案收悉。经商水利部，现答复如下。

一、关于对内蒙古地下水超采严重地区给予大力支持

近年来，针对地下水超采的严峻形势，水利部会同有关部门重点开展了以下几项工作：一是2017年会同国土资源部印发了《全国地下水利用与保护规划（2016—2030年）》，明确地下水开发利用布局和压采目标。其中，到2020年，全国地下水开采总量控制在1004亿立方米以内，地下水超采得到严格控制，华北等重点超采区治理取得明显成效；到2030年，全国地下水开采总量控制在922亿立方米以内，地下水超采区得到全面治理，基本实现采补平衡。二是划定地下水禁限采范围。将存在超采问题的21个省（区、市）全部划定并公布地下水禁采和限采范围，落实禁限采管理措施。三是以京津冀为重点开展地下水超采综合治理。充分利用南水北调东中线工程调水，置换城区地下水开采。同时，试点开展地下水超采综合治理和地下水超采区综合治理河湖地下水回补工作，并会同财政部、发展改革委、农业农村部开展华北地区地下水超采综合治理行动，综合采取“一减、一增”措施，到2022年大部分超采区可以实现采补平衡；到2035年，逐步实现采补平衡和填补亏空水量。四是开展国家地下水监测工作。从2015年起，联合国土资源部对年取用地下水20万立方米以上的工业及生活取水大户实行在线计量监控，新建改建20401个地下水监测站点，目前已基本建成国家、流域、省三级地下水监测网络体系。五是推进地下水管理制度建设及监督考核。推动《地下水管理条例》列入国务院2019年立法工作计划，并将地下水管理制度、措施落实内容纳入最严格水资源管理制度考核范围。

此外，针对内蒙古干旱半干旱地区水资源不足问题，水利部已将引绰济辽、赤峰市东台子水库等水资源配置工程纳入全国水利改革发展“十三五”规划并加快推动实施。目前，引绰济辽、赤峰市东台子水库工程已经开工建设。

二、关于支持内蒙古实施高效节水改造

2018年，中央财政通过水利发展资金安排内蒙古19.83亿元，支持开展高效节水灌溉等农田水利建设，在同步下达的任务清单中，要求内蒙古完成发展高效节水灌溉面积190万亩。2019年，根据国务院机构改革方案，原分散在发展改革委、财政部、国土资源部和水利部的农田水利建设项目管理职责已统一并入农业农村部。农业农村部明确将高效节水灌溉纳入高标准农田建设内容，在推进高标准农田建设中统筹规划、同步实施，因地制宜发展微灌、喷灌、管灌，推广农业节水新技术应用；在安排2019年全国高标准农田建设任务时，按照因素法科学测算各省农田建设任务，其中已充分考虑内蒙古自治区的特殊自然条件和工程建设需求，支持建设高标准农田500万亩，并支持同步开展高效节水灌溉建设215万亩，各项任务安排规模均处于全国前列。

下一步，农业农村部将视中央财政预算安排情况，继续加大对内蒙古自治区支持力度，加快建设高标准农田，同步推进高效节水灌溉，推动内蒙古自治区农业基础设施建设更上新台阶。

感谢您对农业农村工作的关心，希望继续对我部工作给予支持。

农业农村部
