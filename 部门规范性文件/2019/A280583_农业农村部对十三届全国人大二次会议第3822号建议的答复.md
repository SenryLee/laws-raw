# 农业农村部对十三届全国人大二次会议第3822号建议的答复

## 对十三届全国人大二次会议第3822号建议的答复

农办议〔2019〕260号

您提出的“关于推动化肥减量，防治农业面源污染的建议”收悉。经商财政部，现答复如下。

一、关于制定肥料配方与施肥方案

我部注重创新服务方式，运用信息化手段，科学制定肥料配方与施肥方案。一是支持智能配肥网络建设。2013年，我部会同工业和信息化部、质检总局联合印发《关于加快配方肥推广的意见》，引导大中型肥料企业建立智能化配肥供肥服务网点，开展现场智能化混配服务，满足农民个性化、小批量用肥需求。二是开展测土配方施肥信息服务。各级农业农村部门切实加强测土配方施肥专家系统建设，通过网络、手机短信、触摸屏查询等信息化技术，将测土配方施肥形成的海量数据转化为具体的肥料配方和指导意见，采用农民听得懂的语言、看得懂的信息、收得到的方式，指导农民科学施肥。三是完善肥料配方发布机制。组织专家制定发布小麦、玉米、水稻三大粮食作物的32个区域大配方，方便肥料企业批量化生产供应配方肥。指导县级农业农村部门制定县域内作物施肥方案，依托智能配肥服务网点开展有针对性的施肥服务。下一步，农业农村部将会同有关部门，创新体制机制，积极探索农企合作、智能配肥网络建设、测土配方施肥信息服务等新方法、新途径，引导企业、新型农业经营主体和社会化服务组织参与化肥减量增效，推动农业绿色发展。

二、关于提高化肥农药利用率

推进农业绿色发展是农业供给侧结构性改革的主攻方向，加快化肥、农药减量增效是促进农业绿色发展的重要措施。2015年以来，我部按照中央部署，紧紧围绕农业供给侧结构性改革这一主线，坚持“一控两减三基本”目标，强化绿色引领，依靠科技进步，主攻质量效益，深入开展化肥、农药使用量零增长行动，促进化肥、农药减量增效，取得了明显成效。为掌握化肥、农药利用率，农业农村部依托全国各级土壤肥料和植保技术推广单位，分区域、分作物安排2000多个化肥、农药利用率田间试验，随机调查近2万户农户和6000多个专业化服务组织，整理汇总大量试验测试数据。在数据分析的基础上，利用数学模型进行测算，并将测算结果与长期定位监测数据进行对比分析。经科学测算，2017年我国水稻、玉米、小麦三大粮食作物化肥利用率为37.8%，比2015年提高2.6个百分点；农药利用率为38.8%，比2015年提高2.2个百分点。下一步，农业农村部将加大工作力度，强化措施落实，深入推进化肥、农药使用量零增长行动，实现化肥、农药减量增效，进一步提高化肥、农药利用率。

三、关于开展化肥减量增效工作

近年来，按照中央的部署要求，我部会同有关部门，强化绿色引领，聚焦重点发力，扎实推进化肥减量增效，促进农业可持续发展。一是开展测土配方施肥。2005年开始，在全国组织实施测土配方施肥补贴项目，基本覆盖全国所有县级农业行政区。通过测土配方施肥工作的开展，基本摸清了土壤养分状况，普及了科学施肥技术，增强了农民科学施肥意识，促进了农业增产增收和节能减排。二是开展化肥使用量零增长行动。2015年，印发《到2020年化肥使用量零增长行动方案》，选择300个重点县（市）开展化肥减量增效示范，分区域、分作物推广一批化肥减量增效技术模式，加快技术集成创新，探索有效服务机制，促进化肥减量增效。三是开展果菜茶有机肥替代化肥试点。2017年，我部会同财政部，在果菜茶种植优势突出、有机肥资源有保障、有机肥施用技术模式成熟、产业发展有一定基础的地方选择一批重点县（市、区）开展有机肥替代化肥试点，集成推广有机肥替代化肥的生产技术模式，构建果菜茶有机肥替代化肥长效机制。据统计局统计， 2017年全国农用化肥使用量5859.4万吨（折纯），比2016年减少124.7万吨。下一步，农业农村部将会同有关部门，以实施乡村振兴战略为抓手，深入推进化肥减量增效，努力保持主要农作物化肥使用量负增长。

四、关于加大科学施肥宣传培训力度

为加大科学施肥宣传应用力度，各级农业农村部门广泛利用广播、电视、报刊、互联网等媒体，结合基层农技推广体系改革建设、农民田间学校等载体，全方位、多角度宣传科学施肥。2018年全国开展测土配方施肥等科学施肥技术培训5万余场次，组织现场观摩1万余场次，组织宣传活动2万多次，营造了政府引导、全民参与的良好氛围，有力推进了科学施肥工作开展。下一步，农业农村部将充分挖掘各地在科学施肥工作中的好做法、好经验、好典型，组织主流媒体开展系列宣传报道，营造全社会关心支持科学施肥的良好氛围。

感谢您对农业农村工作的关心，希望今后对我部工作继续给予支持。
