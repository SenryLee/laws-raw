# 农业农村部关于政协十三届全国委员会第二次会议第1492号（经济发展类099号）提案答复摘要

## 政协十三届全国委员会第二次会议第1492号（经济发展类099号）提案答复摘要

农办案〔2019〕162号

马露委员：

您提出的关于在新形势下加强基层农村经营管理体系建设提案收悉。经商中央编办、财政部，现答复如下。

您在提案中详细阐述了基层农村经营管理体系建设中存在的问题，提出了有关建议，对新形势下加强相关工作具有积极意义。党中央、国务院一直高度重视基层农经体系建设和农村经营管理工作。党的十九大报告、2018年和2019年中央一号文件从巩固和完善农村基本经营制度、深化农村土地制度改革、深入推进农村集体产权制度改革等方面，对加强农村经营管理工作提出了明确要求。中共中央、国务院印发的《关于稳步推进农村集体产权制度改革的意见》，中办、国办印发的《关于引导农村土地经营权有序流转发展农业适度规模经营的意见》《关于加强乡镇政府服务能力建设的意见》《关于加快构建政策体系培育新型农业经营主体的意见》等多份中央文件都对加强农村经营管理体系建设提出了明确要求。

一、关于健全基层农村经营管理机构，充实人员力量

《中共中央关于深化党和国家机构改革的决定》提出，"精干设置各级政府部门及其内设机构，科学配置权力，减少机构数量；赋予省级及以下机构更多自主权，除中央有明确规定外，允许地方因地制宜设置机构和配置职能".中办、国办印发的《关于推进基层整合审批服务执法力量的实施意见》提出，"统筹优化和综合设置乡镇和街道党政机构、事业单位，强化乡镇和街道党（工）委领导核心作用，构建更好服务群众、简约精干的基层组织架构".对您提出的加强基层农村经营管理机构设置、人员配备等建议，应由地方党委政府按照机构编制管理有关规定，遵循精简、统一、效能的原则，结合经济社会全面协调可持续发展需要和工作实际，在现有机构编制总量内统筹研究确定，以保证基层有资源、有力量做好农村经营管理工作。

二、关于抓好中农发〔2019〕2号文件精神落实

文件下发后，各地高度重视贯彻落实工作，出台加强基层农经体系建设文件，广泛开展调研，全面了解掌握当前农经体系建设情况。在机构改革中，各级农业农村部门积极加强与当地党委政府、编办、人事等相关部门的沟通协调，努力争取推动农经体系建设落到实处，通过召开专题研讨会、组织业务培训会等方式不断提高对基层农经体系建设重要性的认识，不断提升基层农经干部队伍的能力素质，切实加强基层农村经营管理队伍的能力建设。截至6月底，已有22个省（区、市）对《意见》进行了转发，11个省（区、市）印发了省级加强农经体系建设的有关文件，河北、山西、福建、湖南、重庆、广西等6省（区、市）就加强农经体系建设举办了培训班。

下一步，我们将在前期工作的基础上，及时掌握全国农经机构队伍情况，进一步督促各地贯彻落实中农发〔2019〕2号文件精神，不断总结各地好经验、好做法，积极推动基层农经体系建设进一步加强。

感谢您对"三农"工作的关心，希望今后继续支持关注我们的工作。

农业农村部

2019年8月30日
