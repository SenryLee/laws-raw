# 国家文物局办公室关于北京国电水利电力工程有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕324号

北京市文物局：

你局《关于北京国电水利电力工程有限公司申请文物保护工程施工一级资质证书法人变更的请示》（京文物〔2019〕72号）收悉。

经研究，我局同意北京国电水利电力工程有限公司文物保护工程施工一级资质证书中的法定代表人由“郝荣国”变更为“张志修”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年4月28日
