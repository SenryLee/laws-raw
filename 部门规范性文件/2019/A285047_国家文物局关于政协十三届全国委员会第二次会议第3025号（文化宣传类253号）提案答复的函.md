# 国家文物局关于政协十三届全国委员会第二次会议第3025号（文化宣传类253号）提案答复的函

文物保函〔2019〕872号

李光富委员：

您提出的《关于抢险维修武当山道家古建筑群的提案》已交由我局办理，现答复如下：

武当山是我国著名的道教圣地，道教宫观唐、宋、元各朝均有不同规模的修建。明永乐十年（1412年），明成祖组织数十万之众历13年建成规模极为宏大的皇家道教建筑群，嘉靖三十一年（1552年）又曾增修扩建。武当山建筑群是明代皇家建筑在我国南方最大规模的实物遗存，是研究明初政治、宗教和经济的重要例证。

国家文物局一直高度重视武当山建筑群的保护管理工作。1961年，武当山金殿列入第一批全国重点文物保护单位，此后，紫霄宫（1982年第二批）、“治世玄岳”牌坊（1988年第三批）、南岩宫（1996年第四批）、玉虚宫遗址（2001年第五批）、武当山建筑群（2006年第六批）分别增补列入。1994年，“武当山古建筑群”列入《世界遗产名录》。近年来，国家文物局加大了对武当山建筑群抢险修缮的支持力度，仅2018年就批复同意太和宫、五龙宫、紫霄宫等11个保护项目，中央财政拨付专项资金近4200万元。

下一步，国家文物局将会同相关部门和湖北省、十堰市、武当山旅游经济特区等各级政府和文物行政部门，从以下几个方面继续推进武当山建筑群的保护管理工作：

一、抓紧抢修存在险情的文物建筑。武当山建筑群目前部分文物建筑存在不同程度的险情，由于文物数量众多，需要按照“保护为主，抢救第一”的方针，根据险情的轻重缓急逐步抓紧开展抢修，如太和宫的皇经堂、四大天门，五龙宫的一字影壁、小天门，复真观的九曲黄河墙及老君堂、妙化岩等，国家文物局已批复同意进行抢修，2019年拟继续支持开展清微宫的焚帛炉、竹笆桥等抢险项目，并进一步加强对相关项目的事中事后监管，争取尽快消除文物建筑的现存险情。

二、有序开展考古发掘和遗址保护展示。武当山建筑群在清、民国时期有不同程度的损毁，不少建筑群周边存在较大规模的皇家古建筑基址，目前，回龙观建筑基址考古工作取得了较好的成效，五龙宫部分区域也将陆续开展考古清理。我们将继续支持对重点区域开展考古工作，充分了解、展示文物价值，为后续遗址保护展示工作做好支撑。

三、改造提升各宫观的整体空间品质。武当山建筑群部分宫观由道众使用、管理，国家文物局支持其依法开展宗教活动。为提升太和宫、五龙宫等宫观的空间品质，满足日常功能需求，国家文物局已陆续批复同意五龙宫北道院修缮和太和宫丹房改造项目。我们将继续指导、推动湖北省文物部门会同当地人民政府做好相关项目实施工作，并给予专业技术支持。

四、协调各方推进保护总体规划的编制和实施。国家文物局将继续加强对武当山古建筑群世界遗产保护管理规划、文物保护总体规划的指导和支持，充分考虑武当山的文化景观、活态遗产等属性，尊重各方利益相关者诉求，统筹做好武当山建筑群的保护利用和管理工作。同时，将配合文化和旅游部门，开展非物质文化遗产的研究、展示和传承工作。

感谢您对文物事业的关心与支持！

国家文物局
