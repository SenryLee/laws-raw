# 国家文物局关于山东沂南北寨墓群保护规划的意见

文物保函〔2019〕164号

山东省文物局：

你局《关于呈报〈山东沂南北寨墓群文物保护规划〉的请示》（鲁文发〔2018〕82号）收悉。经研究，我局原则同意所报规划。

一、所报规划应作以下必要修改和完善：

（一）进一步梳理考古工作成果，明确保护对象和文物构成。

（二）完善现状评估，应重点分析影响文物安全的各类因素，归纳评估结论，做到简洁、严谨、客观。展示现状评估应说明现有游客量及游客参观的文物影响，环境质量评估、调查发掘与研究概况等内容应纳入规划说明。

（三）应根据文物分布范围、保护管理需要等综合确定保护区划及其具体边界，明确保护范围、建设控制地带的具体控制点坐标。同时，应调整建设控制地带北侧、西侧范围，不宜将汶河河道纳入建设控制地带。进一步细化保护范围管理规定，补充北寨村建设控制和居民日常生产生活的具体要求，增强可操作性。

（四）应调整“保护与整治措施”章节内容，针对文物本体病害研提保护措施，明确保护措施类型、保护对象、技术要求等，补充河岸边缘扰动严重墓葬的保护措施。居民搬迁、河堤修筑、公布保护区划与界标、安防、调整用地性质等内容，应纳入其他章节。

（五）调整展示规划内容，合理确定展示定位和目标，明确具体展示节点。建议现阶段以1号墓、2号墓周边区域为重点，做好保护展示设施改造提升工作，不宜盲目新建陈列馆、停车场、游客服务中心等大型设施。

（六）完善专项规划内容，应分析、评估北寨村现有民居的价值，保留部分具有地方民居特点的传统建筑，适当改造利用，不宜全部拆除。河堤修筑、道路设施规划、基础设施改造等应充分考虑文物影响，进一步细化要求。

（七）应调整、简化文本内容，凝练文字，图纸应符合相关标准。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将北寨墓群保护规划报请山东省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好北寨墓群的各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年2月19日
