# 国家文物局关于南京明故宫遗址保护范围和建设控制地带内蓝旗片区雨污分流改造工程的意见

文物保函〔2019〕97号

江苏省文物局：

你局《关于审批全国重点文物保护单位南京明故宫遗址保护范围内及建设控制地带内蓝旗片区雨污分流改造工程方案设计的请示》（苏文物保〔2018〕280号）收悉。经研究，我局原则同意在南京明故宫遗址保护范围和建设控制地带内实施蓝旗片区雨污分流改造工程。

一、所报方案尚需作以下必要的修改和完善：

（一）加强现场勘察，进一步明确拟建工程各点段文物分布和保存现状，组织专业考古研究单位在项目拟建区域进一步开展全面的考古工作，并根据考古工作成果及时调整方案。考古发掘项目需另行填报考古发掘申请书。

（二）明确施工开挖深度，尽量沿用现有管道位置，充分考虑管网埋深和管网上方覆土层厚度，明确新建管线与市政管网的接驳措施。同时，完善管道施工方案，降低施工振动影响，深化文物保护措施和应急预案，确保文物安全。

（三）应根据明故宫遗址整体保护展示需要，科学确定绿植种类和绿化方式，降低对景观影响。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

四、请你局指导地方人民政府，按照《南京明故宫遗址保护总体规划》要求，统筹考虑城市基础设施建设改造、道路建设、老城区改造等与遗址保护之间的关系，确保文物安全。

专此函复。

国家文物局

2019年1月25日
