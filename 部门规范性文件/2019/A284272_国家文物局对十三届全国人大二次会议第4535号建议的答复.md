# 国家文物局对十三届全国人大二次会议第4535号建议的答复

文物保函〔2019〕635号

曹庆华等5名代表：

您提出的“关于给予将普洱景迈山古茶林列为国家2020年申报世界文化遗产项目的建议”收悉，现答复如下。

普洱景迈山古茶林位于云南省普洱市澜沧拉祜族自治县，由景迈村、芒景村下辖的景迈、童蚌、南卓、班改、勐本、芒埂、老酒房、糯干、芒洪、翁基、上寨、下寨、翁洼、那乃等村寨茶林组成。茶林种植始于傣历57年（公元695年），距今已有一千三百多年的历史，是已知迄今为止国内面积最大、保存最完整的栽培型古茶林，是研究我国茶叶发展史、茶树种植、茶叶贸易、茶艺与民族文化的关系的宝贵实物资料，具有很高的历史、科学、艺术价值。2012年，普洱景迈山古茶园入选《中国世界文化遗产预备名单》。2013年，国务院将“景迈古茶园”公布为第七批全国重点文物保护单位。2014年以来，云南省人民政府和文物行政部门连续致函国家文物局，申请将普洱景迈山古茶林作为我国政府申报世界文化遗产项目。

我局一贯重视普洱景迈山古茶林的保护和申遗工作。近年来，积极指导地方文物行政部门开展普洱景迈山古茶林的保护、环境整治以及管理和申遗等项工作，支持国际古迹遗址理事会开展亚洲茶树景观的主题研究并委派专家共同参与研究，为景迈山古茶林申遗奠定基础。2019年6月20日，我局举行中国世界文化遗产申报项目评审会议，对包括普洱景迈山古茶林在内的多处申遗项目进行了评审。

近年来，世界遗产申报工作的难度逐渐加大。根据世界遗产委员会新施行的“限额制”，一个缔约国每年最多只能申报一项世界遗产。同时，世界遗产委员会不断推进世界遗产均衡性的全球战略，明确向没有世界遗产或世界遗产较少的国家，以及遗产类型较少的类别倾斜；而对世界遗产大国的限制则不断增多。

我国是世界遗产大国，目前拥有世界遗产53项，其中文化遗产36项，居世界第二。世界遗产中心和国际古迹遗址理事会等专业咨询机构对我国等世界遗产大国的申报项目，往往提出更高的标准。按照《保护世界文化和自然遗产公约》及其《操作指南》的规定，申报世界文化遗产的项目，应该具有全世界范围内的突出普遍价值，较好的保存现状，真实性和完整性较高，扎实的保护管理基础，以及利益相关者对遗产保护的积极态度。这都要求我国的申报项目要在各方面做好充分的准备。

根据整体工作安排和《保护世界文化和自然遗产公约》及其《操作指南》的程序规定，我国已确定推荐“古泉州（刺桐）史迹”（暂名）作为我国2020年的世界文化遗产申报项目，国家文物局正在多措并举，开展各项准备工作。此后的申报项目，还需要根据新限额制，与国家林业和草原局、中国联合国教科文组织全国委员会进行协调和沟通。

普洱景迈山古茶林作为《中国世界文化遗产预备名单》项目，具备较高的突出普遍价值和申遗潜力，应该在以下几个方面进一步完善世界文化遗产申报的各项前期准备工作：第一，加强普洱景迈山古茶林的调查和研究等基础工作，特别是深入开展古茶林突出普遍价值和比较分析研究，清晰阐述其符合的世界文化遗产标准，并与国内外同类型遗产进行对比。第二，加强普洱景迈山古茶林的保护、管理和展示工作。重点做好普洱景迈山古茶林文化景观、周边传统村落及其采茶传统工艺、传统文化风俗的整体保护；制定普洱景迈山古茶林保护管理规划；重视普洱景迈山古茶林的展示工作，探索以多种形式，向公众充分阐释、展示遗产的价值。第三，加强与利益相关者的沟通，使得文化遗产及其周边环境的保护得到社会各界的广泛支持，成为遗产所在地社区和居民的共识。第四，密切关注国际世界遗产领域研究的新进展、新政策及新举措，为普洱景迈山古茶林申遗，确定与时俱进的新策略和新路线。

普洱景迈山古茶林作为各方面条件比较成熟的世界文化遗产申报项目，国家文物局将给予重点培育和指导，积极支持普洱景迈山古茶林在保护管理、阐释展示和环境整治等方面工作提升，并按照文物保护专项补助经费管理的有关规定，给予尽可能的支持。

衷心感谢您对我国世界文化遗产工作的关注和支持！

国家文物局

2019年7月5日
