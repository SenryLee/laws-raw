# 国家药监局关于表扬参与查处吴某某等人制售假冒化妆品案等两起案件有关单位和人员的通报

国药监妆〔2019〕55号

各省、自治区、直辖市药品监督管理局，新疆生产建设兵团药品监督管理局：

近期，广东省药品监管部门会同公安机关接连依法查处了吴某某等人制售假冒化妆品案、“4·12”制售假冒化妆品案两起典型案件，捣毁生产销售窝点4个，查获大量违法产品及包装材料，抓获犯罪嫌疑人16人，涉案总金额逾2000万元。

在案件查处中，广东省药品监督管理局党组成员苏盛锋高度重视上述案件查办工作，对办案工作提出明确要求，亲赴现场督导协调案件查处工作，指派专人负责开展化妆品“线上净网线下清源”风险排查处置及相关案件查处工作。广东省药品监督管理局执法监督处处长邱楠带领该处刘国光、江伟豪同志多次组织召开由相关部门参加的专案协调推进会，研究确定案件联合查办方向，并牵头落实重要线索筛查研判、涉案产品鉴别认定等工作。

办案期间，清远市市场监督管理局四级调研员邵华带领该局执法科张德虎、曹历同志，肇庆市市场监督管理局党组成员肖骐龙带领该局执法科周小露、李继明同志多次组织专题会议研究案情，并协调解决具体办案困难。清远市佛冈县市场监督管理局副局长陈永胜带领该局执法大队赖立峰、陈铭浩同志，肇庆市鼎湖区市场监督管理局经检大队大队长李杰球带领区稽查局陈曙东同志、经检大队黄家舜同志、鼎湖区广利市场监督管理所傅杰波同志具体承担案件的前期调查取证工作，并与公安机关通力合作，为案件最终成功告破付出艰苦努力。

吴某某等人制售假冒化妆品案等两起案件是典型的利用网络生产销售假冒化妆品案件。佛冈县市场监督管理局、鼎湖区市场监督管理局接到群众举报后深入调查，与公安机关通力协作，深挖案件线索，对违法产品持续追根溯源。广东省药品监督管理局、清远市市场监督管理局、肇庆市市场监督管理局从化妆品稽查执法的角度对案件调查取证、行刑衔接等工作给予具体指导和有力支持，保证办案工作有序推进。上述两起案件的成功查处，有力打击了不法分子利用网络违法生产销售化妆品的嚣张气焰，体现了省级药品监管部门与地市级、县级市场监管部门在新一轮机构改革的关键时期，协调一致、主动出击、积极作为、严惩违法的坚定决心。现对广东省药品监督管理局、清远市市场监督管理局、肇庆市市场监督管理局、佛冈县市场监督管理局、鼎湖区市场监督管理局五家单位和苏盛锋、邱楠、刘国光、江伟豪、邵华、张德虎、曹历、陈永胜、赖立锋、陈铭浩、肖骐龙、周小露、李继明、李杰球、陈曙东、黄家舜、傅杰波等同志予以通报表扬。

希望各级药品监管部门深入贯彻落实习近平总书记关于药品安全工作的一系列重要指示精神，进一步增强责任感和使命感，特别是始终保持主动出击、勇于担当的工作作风，继续加大案件查处力度，严厉打击药品、医疗器械、化妆品违法行为，为保障公众健康安全做出新的更大的贡献。
