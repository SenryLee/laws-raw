# 交通运输部人事教育司关于做好2018年度人事统计工作的通知

## 关于做好2018年度人事统计工作的通知

人教综合〔2019〕9号

部属有关单位：

根据人力资源和社会保障部通知要求，现就做好我部2018年度人事统计工作有关事项通知如下：

一、 统计区间和人员范围

2018年度人事统计区间为2018年1月1日至12月31日，统计范围包括部属事业和企业单位工作人员。

二、 数据软件

2018年度人事统计仍在“人力资源社会保障统计报表系统SMIS2012”软件平台上进行数据填报、校核和上报汇总。统计系统安装程序、升级程序及报表结构下载路径为：交通运输部政府网站（www.mot.gov.cn）->人事教育司子站->通知公告栏。自行下载后按照软件操作说明和填报说明完成统计上报工作。

三、 要求

（一）各单位要切实加强组织领导，层层审核把关，防止迟报、错报和漏报问题发生。

（二）具体负责统计工作的人员要强化责任意识、严格按照统计口径确保基础数据真实可靠。今年部分报表变化较大，务必认真阅读填报说明，加强统计业务和软件操作学习，切实掌握指标解释、校核关系和软件操作要领，认真核准各项数据。对软件不能自动校核的数据要人工校核准确，确保各表之间相关数据相互对应一致。

（三）请各单位3月1日前，将A4打印版统计报表和系统生成的。rdt格式上报数据各1份报送人教司综合处。

长航、海事、救捞和船级社四大系统单位要对所属单位数据做好汇总、审核、把关。我司将视情对各单位统计工作完成情况进行通报。
