# 农业农村部办公厅关于调整资江油溪河拟尖头鲌蒙古鲌等3处国家级水产种质资源保护区面积范围和功能分区的通知

农办长渔〔2019〕1号

江苏省农业农村厅、湖南省农业农村厅：

资江油溪河拟尖头鲌蒙古鲌国家级水产种质资源保护区、浏阳河特有鱼类国家级水产种质资源保护区、滆湖鲌类国家级水产种质资源保护区调整申请已经审核通过，现将调整后的面积范围和功能分区予以公布。

请根据《水产种质资源保护区管理暂行办法》（中华人民共和国农业部令2011年第1号）的有关要求，加强对水产种质资源保护区工作的组织领导和协调管理，加快建立管理机构，落实工作经费，切实强化管护，加大水产种质资源保护力度，采取积极有效措施发挥保护区作用。

附件：1.资江油溪河拟尖头鲌蒙古鲌国家级水产种质资源保护区面积范围和功能分区

2.浏阳河特有鱼类国家级水产种质资源保护区面积范围和功能分区

3.滆湖鲌类国家级水产种质资源保护区面积范围和功能分区

农业农村部办公厅

2019年7月17日
