# 中共教育部党组关于石鹏建同志试用期满正式任职的通知

教党任〔2019〕126号

全国高等学校学生信息咨询与就业指导中心：

石鹏建同志任全国高等学校学生信息咨询与就业指导中心主任，试用期满，考核合格，经研究决定正式任职。任职时间从试用之日起计算。

2019年5月31日
