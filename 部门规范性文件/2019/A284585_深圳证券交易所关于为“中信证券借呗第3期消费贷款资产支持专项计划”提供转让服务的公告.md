# 深圳证券交易所关于为“中信证券借呗第3期消费贷款资产支持专项计划”提供转让服务的公告

## 关于为“中信证券借呗第3期消费贷款资产支持专项计划”提供转让服务的公告

各相关单位：

根据中信证券股份有限公司申请，本所将自2019年12月2日起在综合协议交易平台为“中信证券借呗第3期消费贷款资产支持专项计划”（以下简称“中信借呗3期”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“中信借呗3期”的转让业务。

二、“中信借呗3期”设立日期为2019年11月12日。优先级资产支持证券如下：证券简称“信借03A”，证券代码为“138117”，到期日为2020年11月23日，还本付息方式为预计到期一次性还本付息。次优先级资产支持证券如下：证券简称“信借03B”，证券代码为“138118”，到期日为2020年11月23日，还本付息方式为预计到期一次性还本付息。次级资产支持证券如下：证券简称“信借03C”，证券代码为“138119”，到期日为2020年11月23日，还本付息方式为优先级及次优先级资产支持证券本金偿付完毕后获得剩余收益。

三、“信借03A”的单笔成交申报最低数量为10000份，“信借03B”的单笔成交申报最低数量为10000份，“信借03C”的单笔成交申报最低数量为10000份。

四、对首次参加“中信借呗3期”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“中信借呗3期”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
