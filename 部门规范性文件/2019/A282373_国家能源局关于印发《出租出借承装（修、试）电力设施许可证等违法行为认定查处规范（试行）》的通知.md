# 国家能源局关于印发《出租出借承装（修、试）电力设施许可证等违法行为认定查处规范（试行）》的通知

国能发资质〔2019〕74号

各派出能源监管机构：

为切实加强承装（修、试）电力设施许可监管，打击遏制出租出借承装（修、试）电力设施许可证等违法行为，维护市场秩序，根据《电力供应与使用条例》《承装（修、试）电力设施许可证管理办法》等法规规章，国家能源局制定了《出租出借承装（修、试）电力设施许可证等违法行为认定查处规范（试行）》，现印发给你们，请结合许可监管工作予以执行。如在执行过程中遇到有关问题，请及时函告国家能源局电力业务资质管理中心。

附件：出租出借承装（修、试）电力设施许可证等违法行为认定查处规范（试行）

国家能源局

2019年9月12日
