# 农业农村部对十三届全国人大二次会议第7365号建议的答复

## 对十三届全国人大二次会议第7365号建议的答复

农办议〔2019〕192号

韦朝晖等5位代表：

你们提出的关于支持深度贫困都安瑶族自治县发展“贷牛还牛”扶贫产业的建议收悉。经商国务院扶贫办、财政部，现答复如下。

一、关于加大“粮改饲”倾斜支持力度

自2015年起，财政部会同我部启动“粮改饲”试点工作，重点选择具有奶牛肉牛等养殖基础、耕地集中连片适于青贮玉米等饲料作物种植的县，通过青贮饲料收贮补助、青贮窖建设和大型专用收获机械购置贷款贴息等方式，鼓励发展青贮玉米等饲料作物，收获加工后以饲草料产品形式就地转化。2017年以来，“粮改饲”试点转移支付资金实行“大专项+任务清单”管理方式（资金采取因素法分配切块下达地方，同时将任务清单区分为约束性任务和指导性任务），“粮改饲”试点面积属于约束性任务，具体补助内容、对象、标准等由各省结合本地实际自主确定。广西从2016年开始实施“粮改饲”试点，截至2018年中央财政累计安排3957万元，用于支持开展“粮改饲”工作。2019年，中央财政继续加大支持力度，已经切块下达1500万元支持广西“粮改饲”工作，鼓励开展“粮改饲”品种适应性筛选推广，因地制宜扩大全株青贮玉米、苜蓿、燕麦、黑麦草、甜高粱等优质饲草种植面积，推动种植结构向粮经饲统筹方向转变。《农业农村部、财政部关于做好2019年农业生产发展资金等项目实施工作的通知》（农计财发〔2019〕6号）已明确要求项目资金安排进一步向贫困地区、贫困县倾斜，“三区三州”等深度贫困地区符合实施条件的要优先予以支持。

下一步，农业农村部、财政部将指导广西壮族自治区根据农业生产发展和脱贫攻坚实际需要，统筹安排相关资金，支持河池市大力培育发展社会化专业收贮服务组织，探索建立优质饲草料机械化收割、规模化加工和商品化销售模式，加快推进饲草产业化发展。

二、关于批准创建国家级都安县现代农业产业园

自2017年开始，中央财政专门安排资金支持各地立足优势特色产业，创建国家现代农业产业园。《农业农村部办公厅、财政部办公厅关于开展2019年国家现代农业产业园创建工作的通知》（农办规〔2019〕3号）明确，重点支持创建优质粮油、现代种业、健康养殖（牛羊、水产）、中药材等产业园，优先支持符合条件的贫困县申请创建国家现代农业产业园。经省级择优遴选和农业农村部、财政部备案审查，广西壮族自治区都安县正式获批创建国家现代农业产业园。

下一步，农业农村部、财政部将会同省级部门，指导和支持都安县加快创建国家现代农业产业园，进一步提升肉牛产业发展水平，打造全国乡村产业兴旺的示范样板。同时，充分发挥产业园带贫作用，创建扶贫产业园典型范例，助力脱贫攻坚，为提升当地脱贫质量、巩固脱贫成果提供支撑。

三、关于能繁母牛养殖补贴政策

2018年，中央财政通过农业生产发展资金安排10亿元，支持健康养殖和畜牧良种推广。2019年，相关资金主要分配用于奶业振兴和畜牧业转型升级项目。其中，在内蒙古、四川等8个省份，对使用良种精液开展人工授精的肉牛养殖场（小区、户），以及存栏能繁母羊30只以上、牦牛能繁母牛25头以上的养殖户进行适当补助；在其他部分地区，对年出栏500头以上的生猪养殖场，兼顾奶牛、肉牛规模养殖场，支持建设和升级改造畜禽粪污收集、贮存、处理设施。目前，2019年项目资金已经切块下达广西等省份，地方可结合农业重点工作和贫困地区倾斜支持需求，统筹安排工作任务和资金，推进畜牧良种繁育、健康养殖和畜禽粪污资源化利用。

下一步，农业农村部、财政部将指导各地落实好“大专项+任务清单”管理方式，根据当地实际需求，统筹安排相关资金，支持贫困地区畜禽良种引进和扩繁，培育专业化生产经营主体，提升带贫能力和效益，探索建立可持续的畜禽品种改良和繁育体系，加快推进肉牛产业现代化。

四、关于出台深度贫困地区农产品冷链仓储企业用电补贴政策

2018年12月，农业农村部联合发展改革委、财政部等8部门出台了《关于实施产业扶贫三年攻坚行动的意见》，明确提出“贫困地区要创设扶持政策，在项目安排、资金扶持、示范评定、融资贷款、保险保费、用地用电等方面加大对带贫能力强的新型经营主体的支持力度。”下一步，农业农村部将会同相关部门指导督促贫困地区进一步落实《关于实施产业扶贫三年攻坚行动的意见》要求，用好统筹整合扶贫资金，创设扶持政策、优化政策供给、推进政策落地，促进带贫主体降本增效，提高冷链仓储设施装备水平，不断壮大新型经营主体，完善农产品产地市场体系，做优做强扶贫特色产业，提升产业扶贫、精准脱贫质量。

感谢您对农业农村工作的关心，希望今后继续对我部工作予以支持。
