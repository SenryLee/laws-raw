# 公开市场业务交易公告[2019]第160号——关于2019年8月15日人民银行开展中期借贷便利（MLF）操作4000亿元比当日到期量多170亿元同时开展逆回购操作300亿元的公告

## 公开市场业务交易公告

[2019]第160号

为对冲税期高峰、MLF到期等因素的影响，维护银行体系流动性合理充裕，2019年8月15日人民银行开展中期借贷便利（MLF）操作4000亿元，比当日到期量多170亿元，同时开展逆回购操作300亿元。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 300亿元 | 2.55% |

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 1年 | 4000亿元 | 3.30% |

中国人民银行公开市场业务操作室

二〇一九年八月十五日
