# 国家文物局关于张骞墓建设控制地带内实施张骞墓展示利用项目的意见

文物保函〔2019〕305号

陕西省文物局：

你局《关于张骞墓展示利用项目涉及张骞墓建设控制地带的请示》（陕文物字〔2019〕33号）收悉。经研究，我局原则同意在张骞墓建设控制地带内实施张骞墓展示利用建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应科学测算展示、参观、游客服务和管理等方面的实际需求，进一步削减建设规模。

（二）应补充景观绿化设计方案。可考虑在拟建展示馆东侧种植当地特色乔木进行遮挡，降低该项目对张骞墓环境景观的影响。

（三）建议加强统筹协调，进一步明确拟建展示馆与原展示馆的互补关系，相关设计应突出各自的侧重点，同时进一步优化完善参观路线设计。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批后实施。

三、请你局会同相关部门加强项目实施的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月26日
