# 国家文物局关于政协十三届全国委员会第二次会议第0926号（文化宣传类094号）提案答复的函

文物博函〔2019〕905号

吉平委员：

您提出的《关于鼓励收藏家到乡村开办收藏展馆助力乡村振兴的提案》已交由我局会同文化和旅游部办理，现答复如下。

实施乡村振兴战略，是党的十九大作出的重大决策部署，是决胜全面建成小康社会、全面建设社会主义现代化国家的重大历史任务。文化振兴是推进乡村振兴系统工程中的重要内容。加强乡村地区博物馆、收藏馆、展示馆等公共文化设施建设，对于保护传承中华优秀传统文化，挖掘乡村文化潜力，培育文明乡风，缩小城乡差别，助力乡村振兴，具有重要意义。

文化和旅游部、国家文物局高度重视乡村文化建设和乡村振兴工作，指导各地不断完善文化和旅游公共服务设施，制定乡村旅游优惠政策，吸引社会力量参与乡村振兴。一是加强农村公共文化设施建设。2015年以来，积极推动农村综合性文化服务中心建设和县级文化馆图书馆总分馆制建设，促进农村公共文化资源共建共享。截至2019年3月底，全国已建成基层综合性文化服务中心48335个，1522个、1630个县已分别完成文化馆总分馆制、图书馆总分馆制建设。二是合理利用文物资源，引导社会力量投入乡村旅游发展。出台《关于促进乡村旅游可持续发展的指导意见》《促进乡村旅游发展提质升级行动方案》等文件，加强乡村文物保护利用和文化遗产保护传承，鼓励专业人士参与乡村景观设计、乡村旅游策划等活动，努力解决制约乡村旅游发展的政策环境问题，引导更多社会资源投入乡村旅游发展。三是吸引人才返乡创业，参与乡村旅游建设。深入推进乡村旅游创客行动，先后推出100家“中国乡村旅游创客示范基地”，推动乡村旅游转型升级、提质增效。四是打造“全国乡村旅游重点村”，发挥示范带动作用。在“全国乡村旅游重点村”遴选标准中，强调对传统村落、历史文化、民族文化等资源的保护，注重文化挖掘和传承，建筑风貌具有地域特征、民族特色。

您在提案中提到的收藏家在乡村开办的收藏馆，属非国有博物馆范畴。国家文物局高度重视非国有博物馆的发展，近年来，通过制定出台相关政策文件、组织国有博物馆对口帮扶非国有博物馆、将非国有博物馆纳入质量评价体系、推进非国有博物馆理事会制度建设、举办非国有博物馆馆长培训班等多种方式，帮助非国有博物馆切实提升专业化水平。据统计，截至2018年底，全国登记备案的博物馆达5354家，其中非国有博物馆达1606家，占全国博物馆总数近30%，已日益成为我国博物馆体系的重要组成部分。

下一步，我局将会同文化和旅游部，充分发挥部门职能，并协调各省级文化文物行政部门，进一步加大乡村文化建设和文化遗产保护的支持力度，加强对乡村收藏展馆等非国有博物馆建设的业务指导，统筹资源，突出特色，重点指导做好乡村收藏展馆选址、规模等前期论证、政策宣传和后期运营评估，并在设施场地、资源共建共享方面为乡村收藏展馆提供便利，鼓励将有意愿、符合条件的乡村收藏展馆纳入县级公共文化服务体系，吸引社会力量参与农村公共文化建设，不断提升社会服务能力和规范化管理水平，为广大农民提供更加丰富的精神文化产品，培育打造地域特色文化品牌，促进文旅融合，助力乡村振兴战略实施。

感谢您对乡村文化振兴和博物馆事业的关心和支持。

国家文物局

2019年8月30日
