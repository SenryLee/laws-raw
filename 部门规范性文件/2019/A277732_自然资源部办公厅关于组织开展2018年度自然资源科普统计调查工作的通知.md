# 自然资源部办公厅关于组织开展2018年度自然资源科普统计调查工作的通知

自然资办函〔2019〕833号

国家林业和草原局，中国地质调查局及部其他相关直属单位、各派出机构，有关单位：

根据《科技部关于开展2018年度全国科普统计调查工作的通知》（国科发智〔2019〕131号）要求，为全面掌握自然资源科普资源，了解科普活动开展情况，现组织开展2018年度自然资源科普统计调查工作。有关事项通知如下。

一、调查内容

调查国家科普资源投入情况，具体包括科普人员、科普场地、科普经费、科普传媒、科普活动以及创新创业中的科普等，共6大类124个指标，监测国家科普工作运行状况。

二、统计范围

2018年度开展了科普工作的有关单位，名单详见附件1。国家林业和草原局、中国地质调查局、各派出机构负责下属单位的统计调查工作。

三、有关要求

1.请各单位高度重视自然资源科普统计工作，加强领导，指定专人负责，保质保量，并于5月26日前将联系人信息发送邮箱。为方便沟通交流，请自行添加QQ群，群号为560322414。

2. 2018年度全国科普统计工作实行数据在线填报，网址为中国科技情报网（http://kptj.chinainfo.prg.cn）。可在上述网址下载培训教材。

3.请于6月4日前完成在线填报，确保数据真实、准确，并将加盖单位公章的科普统计调查表提交科技发展司。
