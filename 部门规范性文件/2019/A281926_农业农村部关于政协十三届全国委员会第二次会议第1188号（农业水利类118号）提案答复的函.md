# 农业农村部关于政协十三届全国委员会第二次会议第1188号（农业水利类118号）提案答复的函

## 关于政协十三届全国委员会第二次会议第1188号（农业水利类118号）提案答复的函

农办案〔2019〕176号

温思美委员：

您提出的关于进一步加强和完善农村财务会计管理工作的提案收悉。经商财政部，现答复如下。

一、关于加强农村财务会计管理顶层制度设计

制度设计是农村财务会计管理的基础。随着我国农村经济社会的快速发展、集体经济规模不断壮大、财政支持"三农"的资金投入进一步增加，现行财务会计制度已不能适应现实的需要，亟待修改和完善。2016年，中共中央、国务院印发了《关于稳步推进农村集体产权制度改革的意见》（以下简称《意见》），明确提出修订完善农村集体经济组织财务会计制度。

我部会同财政部认真贯彻落实中央的决策部署，按照要求及时启动了制度修订工作。一是积极开展调查研究。2018年，我部联合财政部赴北京、山东、四川、江西等地开展村集体经济组织会计制度专题调研，2019年组织有关专家再次赴北京、江苏、吉林、福建、上海、湖北等地开展村集体经济组织会计制度和财务制度专题调研。由于各地农村集体经济组织差异很大，沿海发达地区比较富裕的村收入来源多、经济业务较为复杂，而中西部多数村集体经济组织的收入来源单一、社会管理职能多、经济发展职能少，造成对相关制度诉求不同，需要在修订过程中继续深入研究。二是及时启动修订起草工作。2019年全国农村集体产权制度改革部际联席会议第二次全体会议明确将启动农村集体经济组织财务会计制度配套修订工作作为本年度重点工作内容。并组织有关专家在了解目前制度执行情况的基础上，开展制度修订工作。三是广泛征求意见。组织开展农村集体经济组织会计制度与财务制度修订征文活动，并通过《中国农村财务会计》公众号，面向全国各级农业农村部门、政策研究机构、科研院所，特别是长期具体从事农村财务管理的各级工作人员公开征集修订意见。举办农村财务会计专题培训班，组织各级农村财务会计管理人员围绕两个制度的修订进行专题研讨。

下一步，财政部、农业农村部将深入开展调查研究，结合农村集体产权制度改革相关工作的进展，积极修订完善农村集体经济组织财务管理和会计制度，更好地服务村集体经济组织的发展。

二、关于加大乡镇相关机构和人员保障力度

稳定的机构队伍是做好农村财务管理工作的基础和保障。《意见》强调，要加强乡镇农村经营管理体系建设，稳定农村财会队伍。《乡村振兴战略规划（2018—2022年）》提出，要实施乡村财会管理"双基"提升计划，以乡村基础财务会计制度建设、基本财会人员选配和专业技术培训为重点，提升农村集体经济组织、农民合作社、自治组织的财务会计管理水平和开展各类基本经济活动的规范管理能力。

近年来，我部会同相关部门围绕保障乡镇机构和人员力量采取了积极措施。2010年，中纪委、财政部、农业部、民政部联合印发《关于进一步加强村级会计委托代理服务工作指导意见的通知》，明确要求各地要根据工作需要，充实会计委托代理机构工作人员，提供必要的办公场所和设施。2013年，农业部、财政部、民政部、审计署联合印发了《关于进一步加强和规范村级财务管理工作的意见》，明确要求建立完善财务人员定期培训和继续教育机制，组织做好对乡村会计委托代理服务中心工作人员和民主理财人员的培训和继续教育工作，不断提高他们的业务素质和政策理论水平。各级农业农村部门每年分批组织开展业务培训，重点就财务管理规范化建设、财务公开民主理财、农村审计监督、农村会计核算和财务管理等内容进行师资培训，切实提高各地农村财会人员政策水平和业务能力。截至2018年底，全国乡镇有村会计委托代理聘用人员3.2万人，县乡两级共配备专兼职农经审计人员4.4万人，其中持有审计资格证书人员2.9万人，占审计人员总数的65.6%.

下一步，农业农村部将继续会同有关部门，加强队伍建设，强化人员培训，为进一步加强和完善农村财务会计工作提供组织保证。

三、关于完善村级会计委托代理服务工作

村级会计委托代理服务是规范农村集体财务管理，强化村集体经济组织会计核算的重要抓手。为规范农村会计工作，严肃农村财经纪律，围绕村级会计委托代理服务工作，财政部先后印发了《关于开展村级会计委托代理服务工作的指导意见》《关于进一步加强村级会计委托代理服务工作指导意见》，为规范村级会计委托代理搭建了制度框架。村级会计委托代理服务工作实行"属地化"管理，财政部负责全国代理服务工作的统筹管理，具体负责制定全国代理服务工作指导意见，协调、督促、指导各地开展代理服务工作等；省级财政部门负责本地区代理服务工作开展的具体实施办法，加强代理服务的规章制度建设，协调、督促、指导本地区开展代理服务工作，组织对本地区各乡、镇开展代理服务工作实施检查等。

下一步，财政部将根据有关指导意见的精神和要求，进一步督促各地财政部门，建立健全村级会计委托代理制度，规范农村集体财务管理工作；加强对村级会计委托代理服务机构的监管，纠正和查处违反财政纪律的行为；加强对农村财会人员、村干部、代理服务机构人员的财政知识、会计业务培训，督促农村财会人员、代理服务机构会计人员按要求参加会计继续教育，提升会计人员能力素质，提高农村财务会计管理水平。

四、关于提升农村财务会计监管信息化水平

信息化是加强农村财务会计监管的有效手段。《意见》明确要求，全面加强农村集体资产管理，开展集体资产清产核资，强化农村集体资产财务管理。2019年中央一号文件对此再次强调。为贯彻中央精神，农业农村部大力推进各地提升信息化水平，增强农村财务会计监管能力。一是推动全国平台建设。建设全国农村集体资产监督管理平台，建立全国集体资产清产核资管理系统和集体经济组织登记赋码系统。先后赴山东、北京、安徽、广东等地专题了解集体资产监管平台建设和需求情况。二是鼓励地方积极实践。北京、上海、天津等全面建立集体资产监管系统，一些市县也进行了积极探索，如南京开发了基于地理信息一张图的集体资产管理信息系统，把清产核资与建章立制、与加强集体的资源、资产、资金和财务管理结合起来。三是宣传典型经验。今年7月，农业农村部专门邀请广东省佛山市南海区在全国乡村治理（农村财务会计管理）专题培训班上，介绍了农村财务监管平台模式。截至2018年底，全国实现村集体"三资"计算机管理的市级、县级、乡级机构数分别为78家、1560家、20058家，自主建立农村集体"三资"监管系统的市、县、乡级数量分别为53家、540家、2374家，实现村级财务网上审计和网上公开的乡级机构数分别为4569家、18423家。

下一步，农业农村部将继续指导各地巩固清产核资成效，健全管理制度，在清产核资报送、集体经济组织登记赋码两个现有子系统的基础上，逐步将农村集体财务会计核算、农村产权制度改革等相关内容纳入平台管理，尽快建成各级农业农村部门及相关部门共享的农村集体资产大数据，增强集体资产监管能力，进一步提高农村财务管理信息化水平。

感谢您对农业农村工作的关心，希望今后继续支持我们的工作。

农业农村部

2019年9月3日
