# 国家文物局关于在天寿寺塔建设控制地带内进行尚城江南府建设项目的意见

文物保函〔2018〕1596号

安徽省文物局：

你局《关于广德县尚城江南府项目涉及天寿寺塔建设控制地带的请示》（皖文物保〔2018〕87号）收悉。经研究，我局意见如下：

一、应进一步核实天寿寺塔现行的法定保护区划和管理规定，严格按照其建设控制要求调整方案设计。

二、应细化设计内容及说明，在鸟瞰图或体块分析图中叠加比对天寿寺塔保护区划范围；剖面分析图未据实绘制，难以反映实际空间关系，应予调整。

三、严格控制建筑高度，进一步调减建筑体量，优化建筑布局、尺度和色彩等外形设计，使之与文物景观环境相协调。

四、请你局指导方案设计单位根据上述意见对所报方案做进一步修改和完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

五、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月2日
