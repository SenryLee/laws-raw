# 国家文物局办公室关于月坛坛墙修缮项目的意见

办保函〔2018〕1263号

北京市文物局：

你局《关于月坛修缮工程——坛墙修缮方案的请示》（文号）收悉。经研究，我局暂不同意所报方案。

一、所报方案尚需做以下必要的修改和完善：

（一）应加强现状勘察。进一步明确各段坛墙的年代和价值；细化对病害损伤部位、程度和范围的描述，补充量化数据；如实反映各段墙体的保存情况，现状照片应与平面图逐段对应；深化对原材料、做法、工艺的勘察记录。

（二）进一步提高保护措施的针对性。补充各段不同样式墙体间的交接面节点设计；补充说明坛墙散水采用两步150毫米厚三七灰土垫层的依据；补充油饰、散水铺墁方式、砖缝宽度等的技术要求；逐段核实说明屋面局部挑顶的必要性。

（三）应注意按照“最小干预”原则，严格控制存在早期墙体遗存段落的修缮力度和工程量，现状保存总体完好的段落不应纳入修缮范围。

（四）进一步规范图纸及文本。校核文字错误，补充图纸标注，补充必要的修缮图和节点详图。完善现状勘测图纸。补充完整的平面图、屋顶平面图、立面图等，准确标示残损、病害现象及程度、范围等，补充现状照片。

二、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改和完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月3日
