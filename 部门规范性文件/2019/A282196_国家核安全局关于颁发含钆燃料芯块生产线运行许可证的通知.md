# 国家核安全局关于颁发含钆燃料芯块生产线运行许可证的通知

## 关于颁发含钆燃料芯块生产线运行许可证的通知

国核安发〔2019〕210号

中核北方核燃料元件有限公司：

你公司《关于含钆燃料芯块生产线运行许可的请示》（公司安字〔2019〕137号）收悉。

根据《中华人民共和国核安全法》《中华人民共和国民用核设施安全监督管理条例》的有关要求，我局审查了你公司提交的含钆燃料芯块生产线运行许可证申请文件，认为该生产线的运行以及与核安全相关的活动满足核安全基本要求，已具备运行条件。我局决定向你公司颁发《含钆燃料芯块生产线运行许可证》（见附件）。

你公司应按照《含钆燃料芯块生产线运行许可证》规定的条件，开展含钆燃料芯块生产线的运行活动，加强质量管理，确保核设施运行安全。

附件：含钆燃料芯块生产线运行许可证

国家核安全局

2019年9月24日
