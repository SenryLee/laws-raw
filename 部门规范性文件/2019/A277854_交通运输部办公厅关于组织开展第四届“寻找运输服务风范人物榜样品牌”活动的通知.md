# 交通运输部办公厅关于组织开展第四届“寻找运输服务风范人物榜样品牌”活动的通知

交办运函〔2019〕751号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

为进一步发挥运输服务先进人物的示范、引领和带动作用，传承弘扬新时代交通精神，不断增强行业正能量、提升行业软实力，按照部关于行业精神文明建设和新闻宣传工作的部署安排，部委托中国交通报社承办第四届“寻找运输服务风范人物榜样品牌”主题宣传活动。

请各地交通运输主管部门根据第四届“寻找运输服务风范人物榜样品牌”活动方案安排，积极组织开展本地区道路客运、货运物流、城市交通、机动车维修、驾驶员培训、快递、车辆装备、“运输服务+互联网”新业态等领域的个人和企业参与评选活动。要充分发挥各级行业协会的组织协调和龙头企业的带动作用，积极配合活动组委会做好材料申报、宣传展示、评选、媒体采访等各项工作。要充分借助本次活动，主动联系中央、行业和地方媒体，掀起运输服务领域新闻宣传和典型培树的新高潮。

本次活动不得以评选为由向任何个人和企业收取费用。

联系人：中国交通报社王珍珍、张梦怡，电话：010-65293641、64250631、64252614（传真），邮箱：ysfw@zgjtb.com。
