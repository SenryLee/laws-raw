# 自然资源部公告2019年第20号——自然资源部关于聘任2019年度自然资源首席科学传播专家的公告

## 自然资源部公告

2019年第20号

## 自然资源部关于聘任2019年度自然资源首席科学传播专家的公告

根据《全民科学素质行动计划纲要实施方案（2016-2020年）》和《自然资源部关于印发〈自然资源科技创新发展规划纲要〉的通知》（自然资发〔2018〕117号）要求，为进一步加强自然资源科普人才队伍建设，充分发挥高层次专家在科普工作中的作用，自然资源部组织开展了2019年度自然资源首席科学传播专家人选征集工作。经各单位推荐和专家咨询评议，决定聘任张洪涛等33位专家为2019年度自然资源首席科学传播专家，李廷栋、刘嘉麒等院士为特邀科学传播专家，现予以公布。

希望首席科学传播专家以身作则，开拓创新，大力开展科普创作和科普示范活动，发挥科学传播表率作用，推动拓展自然资源科普工作，为提升全民科学素质，实施创新驱动发展战略，实现中华民族伟大复兴的中国梦作出新的更大贡献。

自然资源部

2019年4月19日
