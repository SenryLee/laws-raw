# 国家新闻出版署关于组织实施数字出版精品遴选推荐计划2019年度项目申报工作的通知

国新出发〔2019〕19号

各省、自治区、直辖市和新疆生产建设兵团新闻出版局，中央和国家机关各部委、各人民团体出版单位主管部门，中央各重点出版集团：

党的十八大以来，传统出版与新兴出版相融合的数字出版产业蓬勃快速发展，规模实力不断壮大，产品形态日益丰富，服务模式更加多元，涌现出一批导向正确、内容优质、创新突出、双效俱佳的数字出版产品和服务项目。建立数字出版精品遴选推荐机制，发挥精品示范带动作用，对推动出版深度融合和出版业高质量发展，具有重要意义。国家新闻出版署自2019年起组织实施数字出版精品遴选推荐计划，每年集中评选奖励一批优秀数字出版产品和服务项目。现就有关事项通知如下。

一、总体要求

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，贯彻落实习近平总书记关于宣传思想工作的重要思想特别是关于媒体融合发展的重要论述，增强“四个意识”，坚定“四个自信”，做到“两个维护”，紧紧围绕庆祝新中国成立70周年这条主线，组织评选一批导向正确、内容优质、创新突出、双效俱佳的数字出版产品和服务，按照主题出版、大众出版、专业出版、教育出版、少儿出版5类推出具有示范推广价值的精品项目，引导出版企业培育产品新形态、探索服务新模式，努力构建品位高端、品质优良、品类丰富的数字出版产业生态。

数字出版精品遴选推荐计划坚持正确导向，把内容质量、社会效益放在首位，自觉践行社会主义核心价值观，讲品位、讲格调、讲责任，弘扬主旋律，传播正能量；坚持创新为要，把握全媒体时代信息传播规律，适应移动化、知识化、数据化、碎片化、音视频化的信息传播趋势，运用大数据、云计算、人工智能等技术，体现产品和服务在内容表达、呈现方式、服务模式等方面的突破与创新；坚持科学评价，社会价值与市场价值相结合，自主创新与协同创新相结合，稳定性与成长性相结合，实用性与先进性相结合，满足用户与引导用户相结合，全面准确反映数字出版项目价值与作用，注重挖掘推荐反映数字出版发展前沿趋势的产品与服务；坚持示范引领，在品质上追求专业权威、传播上注重精准快捷、服务上注重分众互动，树立行业产品与服务标杆，推动引领行业融合发展。

二、申报范围

各单位按照产品、服务2个序列和主题出版、大众出版、专业出版、教育出版、少儿出版5个类别进行申报。网络游戏、网络文学类数字出版精品的遴选推荐已另有安排，暂不纳入本计划申报范围。

1. 主题出版类数字出版项目。主要包括研究阐释习近平新时代中国特色社会主义思想、深化中国特色社会主义和中国梦宣传教育、宣传阐释中央精神和重大决策部署、宣传阐释社会主义核心价值观、展示真实立体全面的中国等主题产品或服务，重点申报围绕庆祝新中国成立70周年，礼赞新中国、讴歌新时代的项目。

2. 大众出版类数字出版项目。主要包括面向大众读者的政治、理论、文学、文艺、社科、历史、财经、生活、科普等题材的数字出版项目，包括但不限于电子书、电子杂志、有声读物、知识库、应用程序、功能性新媒体公众号等形态的数字产品。

3. 专业出版类数字出版项目。主要包括围绕国民经济各领域重大工程、重点项目，利用已有的专业出版存量或新增内容资源开发的专业知识库；利用语义分析、大数据等信息技术推动传统出版向数据库出版或在线服务转型的产品。

4. 教育出版类数字出版项目。主要包括学前教育、基础教育、职业教育、高等教育、继续教育等的数字课程、数字教材、题库、教育资源库和利用人工智能、大数据等先进技术建设的新型教学系统等产品或服务。

5. 少儿出版类数字出版项目。主要包括以少年儿童为主要对象，满足少儿素质教育、健康成长、休闲娱乐等需求的数字出版产品与服务，包括少儿主题出版类、原创或改编少儿文学类、少儿科普绘本类等产品或服务。

与出版业务联系紧密，对出版业转型升级、提质增效有积极影响的其他数字内容、数字阅读新产品新服务，也属于申报范围。

三、申报条件

1. 申报主体。经出版管理部门批准设立的图书、期刊、音像电子出版单位和网络出版服务单位，以及从事数字阅读、数字内容相关服务业务的文化科技企业。

2. 项目要求。申报项目应为2019年5月31日前上线且持续、稳定、有效运营的数字出版产品和服务。申报项目不得含有违反《出版管理条例》《网络出版服务管理规定》的内容。申报主体应对项目拥有完全知识产权或有明确授权。

3. 申报材料。包括《2019年度数字出版精品遴选推荐计划项目申报表》、营业执照复印件（加盖公章）、产品使用说明、网络服务地址及可供测试的账号密码，可附专家推荐意见以及《2019年度数字出版精品遴选推荐计划申报项目信息采集表》等支撑项目的其他材料。

四、项目评审及相关安排

各地新闻出版局或出版单位主管部门负责对所辖所管单位的申报材料进行审核、遴选，按本地区本部门可申报的项目数量整理汇总后，于2019年7月1日前统一报送国家新闻出版署。国家新闻出版署组织专家对申报项目从内容质量、创新意义、社会效益和经济效益等方面进行综合考察、集中评审，对遴选出的精品项目给予奖励，并组织宣传推介。对入选精品项目的出版单位，在社会效益评价考核时予以适当加分。同时，建立数字出版精品项目库，为相关奖项和项目资助提供参考。

各地新闻出版局或出版单位主管部门向国家新闻出版署报送的项目材料，应包括纸质版一式三份并加盖公章，寄送至北京市西城区宣武门外大街40号613室，贾洪彬、梁振东收，邮编：100052（寄件外包装请注明“2019年数字出版精品材料”）。同时报送电子版到指定邮箱：SZCBJP2019@126.com。本通知电子版可在指定网站下载。咨询电话：010—82061318、13436623310。
