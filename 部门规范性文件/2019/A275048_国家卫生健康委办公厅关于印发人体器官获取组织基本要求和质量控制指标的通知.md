# 国家卫生健康委办公厅关于印发人体器官获取组织基本要求和质量控制指标的通知

国卫办医函〔2019〕197号

各省、自治区、直辖市及新疆生产建设兵团卫生健康委（卫生计生委）：

为加强人体器官获取组织管理，建立完善人体器官获取组织质量管理与控制体系，规范人体器官获取工作，我委组织制定了《人体器官获取组织基本要求》和《人体器官获取组织质量控制指标》。现印发给你们，请遵照执行。

附件：1.人体器官获取组织基本要求

2.人体器官获取组织质量控制指标

国家卫生健康委办公厅

2019年2月26日
