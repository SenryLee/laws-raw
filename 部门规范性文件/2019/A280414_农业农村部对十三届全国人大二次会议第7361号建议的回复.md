# 农业农村部对十三届全国人大二次会议第7361号建议的回复

## 对十三届全国人大二次会议第7361号建议的回复

农办议〔2019〕245号

王华生等5名代表：

你们提出的关于加大支持广西柑橘黄龙病防控工作的建议收悉。经商发展改革委、财政部和商务部，现答复如下。

一、关于加大对柑橘等鲜活农产品冷链物流的投资

2015年以来，商务部会同财政部将广西壮族自治区列入全国农产品流通骨干网建设省份，安排中央财政资金3.4亿元，支持广西加强跨区域农产品流通基础设施建设。其中，重点支持具有集中采购和跨区域配送能力的农产品冷链物流集散中心，建立覆盖农产品生产、加工、运输、储存、销售等环节的全程冷链物流体系。同时，会同中国农业发展银行开展农产品冷链流通标准化试点工作，广西中国—东盟（钦州）农产品大市场项目已获得8000万元项目贷款。截至目前，包括广西—北方绿色果蔬冷藏集装箱专列、广西百色一号果蔬绿色专列跨区域产品流通基础设施建设等全部9个农产品冷链项目已经建设完成并发挥作用，显著提高了广西农产品冷链物流的效率和水平。下一步，财政部将会同商务部开展推动农商互联工作，进一步完善农产品供应链建设。广西可按程序参加竞争性评审，纳入支持范围后，可按规定统筹使用中央财政资金支持本地冷链物流体系建设。

二、关于支持开展柑橘黄龙病基础研究

一直以来，中央财政高度重视并积极支持农业基础研究领域的科技创新工作。一是通过中央财政科技计划（专项、基金等）对相关领域的科研工作进行支持。先后安排了“柑橘黄龙病和溃疡病综合防控技术研究与示范”（公益性行业科研专项）、“柑橘黄龙病综合防控技术集成研究与示范”（化学肥料和农药减施增效综合技术研发）等专项课题，支持开展柑橘黄龙病综合防控技术领域相关科学研究。二是通过基本运行经费、基本科研业务费、中央级科学事业单位修缮购置专项资金、国家（重点）实验室专项经费等，加大对农业领域中央级科研院所、国家重点实验室稳定支持力度，支持其改善科研基础条件、自主开展研究等，激发相关科研单位自主创新活力。三是中央财政高度重视地方科技创新工作，2016年，为改善地方科研基础条件，提升区域科技创新能力，中央财政调整设立了“中央引导地方科技发展专项资金”，中央财政不指定具体项目，广西可结合实际，按规定统筹安排用于包括柑橘黄龙病致病机理、田间快速检测技术、木虱传毒规律和机制等农业基础研究在内的科技创新相关工作。下一步，中央财政将积极发挥财政支农作用，继续做好对农业基础研究领域相关科研工作的支持。

三、关于加强检查确保无病毒苗木质量

2015年以来，我部连续五年组织开展柑橘苗木检疫专项联合执法检查，组派专家组赴柑橘主产省区调查柑橘黄龙病发生情况，督导黄龙病防控工作。2019年，又组织开展了以柑橘黄龙病等13种检疫对象为重点的农作物种子种苗检疫专项执法检查，严格引种检疫审批、产地检疫、调运检疫制度落实，强化种子种苗生产经营单位的守法意识，提升植物检疫监督管理水平。各地也加大检疫执法力度，查处了一批违法调运种苗的经营企业，销毁了一批高风险种苗，从源头上防止染疫种苗流入生产环节。据统计，近年来各地累计销毁违法调运种苗2000多万株。中央财政已设立了农业生产救灾资金，地方可按规定申请和使用，因地制宜保障柑橘黄龙病可持续治理。下一步，我部将组织开展2020年植物健康年和种子种苗专项检疫检查行动，进一步规范种子种苗产地检疫，大力宣传植物检疫法规和相关知识，防止染病种苗出圃，切实提高种子种苗生产经营主体的植物检疫意识。

四、关于加大省际间柑橘黄龙病统一防控的协调指挥

柑橘黄龙病防控事关柑橘产业健康发展和山区橘农脱贫增收。农业农村部高度重视，采取有效措施，推进省际间联防联控，遏制黄龙病扩散蔓延。一是强化工作部署推动。连续五年组织召开全国柑橘黄龙病防控工作推进会或现场会，提出“苗、虫、铲、检”的防控技术路径，制定柑橘黄龙病阻截及防控方案，指导各地开展分类防控。二是加大资金支持带动。连续五年安排中央财政资金，支持广西、浙江、福建、江西、湖南、广东、四川等7个省（区）开展柑橘黄龙病统防统治和联防联控，全力遏制病害流行态势。2015—2018年，累计安排资金3.67亿元。三是推进区域协作联动。在柑橘黄龙病联合监测与防控协作组基础上，专门成立了华中、华南及西南片区协作组，组织分片区召开协作组工作会议，强化跨区域重大疫情信息交流与联防联控。各级农业农村部门狠抓落实，多措并举，柑橘黄龙病防控取得明显成效，遏制了柑橘黄龙病暴发势头。据监测，2018年柑橘黄龙病发生面积比发病高峰期的2014年下降28.5%。下一步，农业农村部将会同有关部门积极探索加强区域间协作防控的工作机制，加强柑橘黄龙病可持续治理，促进柑橘产业健康发展。

五、关于制定柑橘种苗专门办法和黄龙病防控国家技术标准

我部高度重视柑橘产业发展，采取有效措施推动种苗管理工作。一是加强品种登记。2017年，先后发布了《非主要农作物品种登记指南》《非主要农作物品种登记办法》，启动了柑橘品种登记工作。二是强化法律制度保障。《农作物种子生产经营许可管理办法》第二十一条明确规定，农民个人出售、串换的种子数量不应超过其家庭联产承包土地的年度用种量。违反本规定出售、串换种子的，视为无证生产经营种子。三是加强质量控制体系建设。2017年以来，全面推动包括柑橘种苗在内的种子质量控制体系建设，将柑橘种苗质量认证纳入试点。下一步，农业农村部将会同有关部门尽快出台《农作物种苗管理办法》，修订《植物检疫条例（农业实施细则）》，进一步健全管理制度。同时，完善《柑橘黄龙病防控方案》，加快制定发布相关标准，持续推进综合治理，全力保障柑橘生产安全和农民持续增收。

感谢对农业农村工作的关心，希望今后对我部工作继续给予支持。
