# 农业农村部对十三届全国人大二次会议第1017号建议的答复摘要

## 十三届全国人大二次会议第1017号建议的答复摘要

为加大马铃薯主粮化扶持力度，2019年中央财政进一步完善玉米大豆生产者补贴政策，将东北“镰刀弯”地区马铃薯种植纳入补贴范围。东北四省（区）可统筹研究对“镰刀弯”地区改种马铃薯给予补贴，使马铃薯种植享受生产者补贴政策，具体马铃薯种植补贴标准、补贴范围等由东北四省（区）自主确定。同时，将“镰刀弯”地区马铃薯种薯基地县纳入制种大县奖励范围，择优对内蒙古自治区察右前旗等10个马铃薯种薯基地县给予奖励，支持用于制种基地基础设施建设、制种监管、新品种科技试验示范、仪器设备购置等马铃薯制种产业发展的相关支出，促进马铃薯脱毒种薯及优良品种推广使用，提高马铃薯种植效益和产业发展质量。乌兰察布市可按照国家现代农业产业园创建条件和要求，选择产业基础好、发展潜力大的旗县，指导其积极做好国家现代农业产业园创建前期工作，按程序积极申报。

农业农村部

2019年7月23日
