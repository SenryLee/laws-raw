# 国家能源局综合司关于下达2019年能源领域行业标准制修订增补、调整计划项目的通知

各能源行业标准化管理机构、标准化技术委员会：

经研究，现将2019年能源领域行业标准制修订增补和调整计划下达给你们，请认真组织各有关标准化技术委员会、标准起草单位抓好落实，按时完成任务。

附件：1.2019年能源领域行业标准制修订增补计划项目汇总表

2.2019年能源领域行业标准制修订调整计划项目汇总表

国家能源局综合司

2019年11月22日
