# 国家文物局关于邛窑遗址建设控制地带内成都临邛文博创意产业示范区（一期）建设项目的意见

文物保函〔2019〕912号

四川省文物局：

你局《关于在邛窑遗址建设控制地带实施成都临邛文博创意产业示范区（一期）配套建设项目的请示》（川文物〔2019〕28号）收悉。经研究，我局原则同意在邛窑遗址建设控制地带内实施成都临邛文博创意产业示范区（一期）建设项目。

一、所报方案尚需做以下必要的修改和完善：

（一）组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，明确该区域的文物埋藏情况，并根据考古工作成果，优化方案设计。建议在博物馆与16号台地间设置景观带，尽可能降低新建建筑的文物影响。考古发掘项目需另行填报考古发掘申请书。

（二）严格控制工程范围和施工强度，做好施工中的文物保护工作，确保文物安全。

（三）认真校核文物影响评估报告中图文不一致等错误，确保评估报告的科学性、严肃性。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

四、请你局指导地方人民政府，合理规划邛窑遗址周边区域的产业布局和建设项目，统筹考虑邛窑遗址保护、考古遗址公园建设和城乡发展之间的关系。

专此函复。

国家文物局

2019年8月30日
