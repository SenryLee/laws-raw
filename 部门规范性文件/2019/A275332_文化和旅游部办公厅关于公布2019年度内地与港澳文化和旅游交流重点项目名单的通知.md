# 文化和旅游部办公厅关于公布2019年度内地与港澳文化和旅游交流重点项目名单的通知

办港澳台发〔2019〕45号

各省、自治区、直辖市文化和旅游厅（局），中国宋庆龄基金会办公室，中央人民政府驻香港特别行政区联络办公室办公厅、中央人民政府驻澳门特别行政区联络办公室办公厅，本部各直属单位：

根据《文化和旅游部办公厅关于启动2019年度内地与港澳文化和旅游交流重点项目申报工作的通知》，经评审和公示，共有来自北京、山西、上海、江苏、江西、广东、重庆、甘肃等省（市）、港澳特区以及文化和旅游部直属单位、全国性人民团体申报的26个项目被评为“2019年度内地与港澳文化和旅游交流重点项目”，现将重点项目名单及资助金额予以公布（见附件1）。

为落实好重点项目，现就有关要求通知如下：

一、请相关省（市）文化和旅游厅（局）对本地区，中央人民政府驻香港特别行政区联络办公室、中央人民政府驻澳门特别行政区联络办公室对香港、澳门入选项目的组织实施、经费使用进行指导、监督和检查，督促入选项目申报主体于规定时限内，通过内地与港澳文化和旅游交流重点项目申报管理系统提交验收材料，对验收材料提出本单位意见；请文化和旅游部直属单位、中国宋庆龄基金会、中国京剧艺术基金会认真做好项目的实施和结项工作。（重点项目资助经费的划拨、验收流程等详细要求见附件2）

二、请入选项目申报主体认真开展项目的组织实施和宣传，并在项目组织实施和宣传过程中注明该项目为“2019年度内地与港澳文化和旅游交流重点项目”，突出项目影响和实效，并按要求履行结项验收程序。

三、文化和旅游部港澳台办将派人或委托专业机构在项目实施过程中进行监督检查，在项目完成后进行验收和评估。

本通知及附件可在文化和旅游部政府门户网站（www.mct.gov.cn）、中国文化网（www.chinaculture.org）及其微信公众号、文旅中国微信公众号，以及内地与港澳文化和旅游交流重点项目申报管理系统（访问路径：文化和旅游部政府门户网站首页—在线办事—办事大厅—内地与港澳文化和旅游交流重点项目申报管理系统）查询、下载。

特此通知。
