# 国家体育总局社体中心、中国大学生体协、中国中学生体协关于印发2019年全国柔力球培训计划的通知

## 体育总局社体中心　中国大学生体协　中国中学生体协关于印发2019年全国柔力球培训计划的通知

社体字〔2019〕79号

各有关单位：

为贯彻落实“广泛开展全民健身活动，加快推进体育强国建设”的指示精神，进一步推动柔力球运动蓬勃发展，2019年继续举办全国柔力球系列培训班，现将有关事宜通知如下：

一、主办单位

国家体育总局社会体育指导中心

中国大学生体育协会

中国中学生体育协会

二、协办单位

中国教育网络电视台文体台（wt.centv.cn）

三、承办单位

全国柔力球运动推广委员会

各举办地体育部门、教育部门及有关单位

奥博隆（北京）体育发展有限公司

四、举办时间、地点（见附件1）

五、培训对象

（一）各省、自治区、直辖市、计划单列市、新疆生产建设兵团体育局社体中心（群体处、体总秘书处），教育厅（教委）体卫艺处选派业务主管人员或技术人员。

（二）各行业体协及各省市大学生、中学生体育协会选派人员。

（三）各大专院校及中小学体育教师。

（四）接受个人报名。凡从事健身项目指导、培训、推广的体育机构及人员均可报名参加。

六、培训内容

（一）柔力球教学与训练理论

（二）第七套柔力球规定套路

（三）网式柔力球技战术

七、结业及等级申请

（一）向参加培训的学员颁发体育总局社体中心结业证书。

（二）通过专项考核，符合《柔力球教练员技术等级制度》要求，经所在地业务主管部门推荐的学员，可申请柔力球项目大众等级教练员。

八、培训费用

（一）参加培训人员差旅费自理，自行安排食宿。需承办单位统一安排的学员直接与承办单位联系，食宿费用依举办地实际情况确定。

（二）培训收费

培训费每人600元（含器材、资料等费用）。

九、参加培训人员要求身体健康，并自行办理培训期间人身意外事故、伤害保险。

十、报名和报到

（一）有意向报名参加培训人员可根据情况，自行选择办班地点。

（二）请于各期培训班开班前15天报名，可通过传真、电子邮件以及网络在线报名。

（三）各期培训班具体报到时间、地点另行通知。

十一、日程安排

第一天：全体学员报到

第二天：开班典礼、理论及技术教学

第三天：技术教学

第四天：技术教学、考核（交流展示）及结业仪式

注：有意向参加结业仪式交流展示的学员及团队请自备音乐，每期培训班优选5人（队）。
