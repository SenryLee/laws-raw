# 国家文物局办公室关于江西省文物保护中心文物保护工程勘察设计及监理甲级资质证书内容变更的函

办保函〔2019〕534号

江西省文化和旅游厅：

你厅《关于申请变更江西省文物保护中心文物保护工程勘察设计及监理甲级资质证书的请示》（赣文旅文〔2019〕96号）收悉。

经研究，我局同意江西省文物保护中心文物保护工程勘察设计甲级资质证书、监理甲级资质证书中的单位地址由“江西省南昌市新洲路2号”变更为“南昌市西湖区煌盛外滩国际B座901-903,916-923室”，注册资金由“143万元”变更为“2157.3万元”。请你厅通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年6月17日
