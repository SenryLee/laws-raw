# 退役军人事务部关于学习贯彻党的十九届四中全会精神的通知

退役军人部发〔2019〕68号

各省、自治区、直辖市退役军人事务厅（局），新疆生产建设兵团退役军人事务局：

为深入学习贯彻党的十九届四中全会精神，切实做好退役军人事务领域各项工作，通知如下：

一、切实把思想行动统一到全会决策部署上来

（一）充分认识全会的重大意义。党的十九届四中全会是我们党站在“两个一百年”奋斗目标历史交汇点上召开的一次十分重要的会议，是在新中国成立70周年之际、我国处于中华民族伟大复兴关键时期召开的一次具有开创性、里程碑意义的会议。全会重点研究坚持和完善中国特色社会主义制度、推进国家治理体系和治理能力现代化问题并作出决定，充分体现了以习近平同志为核心的党中央高瞻远瞩的战略眼光和强烈的历史担当，对推动中国特色社会主义制度更加成熟更加定型、把我国制度优势更好转化为国家治理效能，对决胜全面建成小康社会、全面建设社会主义现代化国家，对巩固党的执政地位、确保党和国家长治久安，具有重大而深远的意义。

（二）深刻领会全会精神。要深入学习习近平总书记在全会上的重要讲话和《中共中央关于坚持和完善中国特色社会主义制度、推进国家治理体系和治理能力现代化若干重大问题的决定》（以下简称《决定》），坚持总结历史和面向未来相统一、保持定力和改革创新相统一、问题导向和目标指引相统一，认真领会习近平总书记重要讲话精神实质，全面掌握全会关于坚持和完善中国特色社会主义制度、推进国家治理体系和治理能力现代化的重大决策部署，准确把握我国国家制度和治理体系的演进方向和规律，学深悟透“坚持和巩固什么、完善和发展什么”这个重大政治问题，牢牢坚持中国特色社会主义的各项重大制度和原则，全力推进制度建设各项重大任务和举措落实落地。

（三）全面掌握全会关于退役军人工作的部署要求。《决定》明确要求，“统筹完善社会救助、社会福利、慈善事业、优抚安置等制度”，“健全退役军人工作体系和保障制度”，“完善双拥工作和军民共建机制，加强军政军民团结”。组建退役军人事务系统、做好退役军人工作是推进国家治理体系和治理能力现代化的必然要求和重要内容，事关巩固党的执政根基，事关改革发展稳定大局，事关国防军队建设全局，事关广大退役军人切身利益。要增强“四个意识”、坚定“四个自信”、做到“两个维护”，团结拼搏、锐意进取，全面推进退役军人事务领域治理体系和治理能力现代化，以实际行动把全会精神落到实处。

二、全力推进退役军人事务领域治理体系和治理能力现代化

退役军人事务系统组建以来，攻坚克难、扎实工作，起步平稳、开局良好。但面对新形势新任务新要求，退役军人工作还存在一些体制性障碍、结构性矛盾、政策性问题，迫切需要推进治理体系和治理能力现代化。

（一）全面加强党的领导，提高政治领导能力。坚决维护习近平总书记党中央的核心、全党的核心地位，坚决维护党中央权威和集中统一领导，坚决把党的领导落实到退役军人事务领域各方面各环节。坚持思想政治引领，严格遵守党章，恪守党的性质和宗旨，不忘初心、牢记使命，坚持用习近平新时代中国特色社会主义思想武装头脑，深入学习领悟习近平总书记关于退役军人工作的重要论述精神，始终保持退役军人工作的正确政治方向。坚持党的全面领导，全面贯彻党的基本理论、基本路线、基本方略，坚决贯彻党中央关于退役军人工作的决策部署；推动地方党委健全对退役军人工作的领导体制，强化决策议事协调机制，将退役军人工作纳入各级党政领导班子和有关领导干部综合考核评价内容，完善重大决策督查制度，更好发挥把方向、谋大局、定政策、促改革的职能作用；健全本单位党组织工作制度，把党的领导贯穿履行职责全过程，努力建成宣传党的主张、贯彻党的决定、服务退役军人、推进事业发展的坚强战斗堡垒。坚持立党为公、执政为民，贯彻党的群众路线，完善党员干部联系退役军人工作制度，加强思想政治工作，把广大退役军人紧密团结在党的周围，使其成为党执政兴国的重要依靠力量。坚持全面从严治党，以党的政治建设为统领，全面推进党的各方面建设，严明政治纪律和政治规矩，完善全面从严治党责任制，力戒形式主义、官僚主义，全力配合派驻纪检监察组工作，主动接受各方面监督，保证退役军人事业持续规范健康发展。

（二）健全组织管理体系，提高科学发展能力。在党的坚强领导下，尽快打造行政机构、事业单位、社会力量“三驾马车”齐头并进的工作格局。加强行政机构自身建设，进一步科学设置内部机构，健全工作制度，规范运转机制，优化决策程序，创新行政方式，提高行政效能，发挥好决策参谋官、政策执行者、部门联络员等功能。强化事业单位能力提升，加快涉退役军人工作事业单位转隶步伐，开展退役军人服务中心（站）提升治理能力和服务水平行动，推进优抚医院、光荣院等事业单位改革，转变思路、盘活资源，探索集团化管理、市场化运作，全面提升服务保障水平，努力打造成提供服务、搞好保障的“桥头堡”，解决问题、化解矛盾的“稳定器”，联系对象、凝聚人心的“吸铁石”。鼓励社会力量广泛参与，建立健全支持社会力量参与退役军人工作的制度机制，加大政策支持力度，优化政府购买服务，推进社会专项服务，倡导志愿服务，规范引导更多社会力量支持、参与、推动退役军人工作。

（三）完善工作运行体系，提高管理保障能力。抓好就业安置、优待褒扬、权益维护、服务管理等方面的制度机制建设，以“四轮驱动”牵引整体工作水平提升。健全就业安置机制，改进机关事业单位接收安置办法，建立归集专项岗位制度，完善“直通车”式安置办法，提高安置质量、促进人岗相适；健全学历教育与职业技能培训并行并举的教育培训体系，建立扶持就业和支持创业机制，促进自主就业退役军人更高质量就业创业；改进军休人员和伤病残人员移交安置办法，加快移交安置步伐，服务部队聚焦强军、专谋打赢。健全优待褒扬机制，进一步完善双拥工作和军民共建机制，不断巩固军政军民团结；健全待遇保障制度，推动建立抚恤优待量化标准体系，完善保障经费动态增长机制，加大社会优待力度；健全烈士祭扫制度，规范祭扫礼仪，加强烈士纪念设施规划建设修缮管理维护，完善弘扬英烈精神红色教育基地体系，大力弘扬英烈精神，依法保护英烈荣誉。健全权益维护机制，畅通和规范服务对象诉求表达、利益协调、权益保障通道，坚持高标准办理信访事项，落实首办责任制和核查督办机制，切实维护服务对象合法权益。健全服务管理机制，建立退役军人作用发挥激励机制，常态化做好思想引领、宣传表彰、走访慰问、帮扶援助、关心关爱等工作，充分调动他们干事创业的积极性、主动性、创造性；建立教育管理制度，严格退役军人党员管理，切实履行党员义务；构建“互联网+退役军人服务”平台和综合管理平台，借助信息技术和大数据提供便捷、精准服务，以信息化促进退役军人工作现代化。

（四）重塑政策制度体系，提高依法行政能力。强化法治意识、运用法治思维，紧跟军地改革步伐，积极稳妥出台政策，严格规范执行制度，切实提高系统依法行政能力。坚持科学立法，立改废释并举，逐步搭建以《退役军人保障法》为主干、以《退役军人安置条例》《军人抚恤优待条例》《烈士褒扬条例》等法规为支撑、以相关部门规章和规范性文件为配套的系统完备的政策制度体系，建立政策文件定期清理机制，做好政策制度释义解读，确保与时俱进、科学权威。坚决依法行政，坚持有法必依、执法必严、违法必究，依法依规、公平公正安置退役军人，规范优抚对象身份认定，落实各项政策待遇；建立冒领待遇追偿追责机制，杜绝办理假证、乱发补助，对有关违法行为依法进行处罚；建立健全工作指导、督查、考核机制，确保政策精准实施、落实到位。促进尊法守法，加强法治宣传教育，建立退役军人待遇保障与现实表现挂钩的诚信机制，引导广大退役军人增强法治观念，依法表达利益诉求、依法维护权益，做社会主义法治的忠实崇尚者、自觉遵守者、坚定捍卫者。

三、迅速掀起学习宣传贯彻全会精神的热潮

（一）强化组织领导。要把学习宣传贯彻全会精神作为退役军人事务系统当前和今后一个时期的重大政治任务，切实摆上重要议事日程，精心策划方案，抓好组织实施，将学习宣传贯彻引向深入，实现全员覆盖。要坚持领导干部带头学、普通党员自觉学、线上线下互动学、结合工作对照学，通过领导宣讲、专家辅导、专题会议、全员轮训、研讨交流等多种方式，认真学习领会全会精神，努力做到学以致用、学用结合。要充分利用系统各类媒体资源，集中宣传阐释全会精神，全面展示退役军人工作改革发展成果，大力宣传落实全会精神、推进退役军人事务领域治理体系和治理能力现代化的成功经验，不断营造学习宣传贯彻全会精神的浓厚氛围。

（二）狠抓贯彻落实。要把学习贯彻全会精神与贯彻落实习近平总书记关于退役军人工作重要论述精神结合起来，与贯彻落实党中央关于退役军人工作重要决策部署结合起来，与做好当前重点工作结合起来，深入贯彻全国退役军人工作会议部署要求，高质量完成年度接收安置任务，加快部分退役士兵社会保险接续工作，坚决按照“五有”要求完成服务中心（站）建设任务，尽快实体运转、发挥实效。要深入开展调查研究，认真梳理退役军人事务领域治理体系和治理能力现代化的重点任务，编制好“十四五”发展规划，制定好明年工作计划，做到谋划在先、行动赶早。要落实固根基、扬优势、补短板、强弱项的要求，一手抓基层建设、强基固本，一手抓转变观念、改革创新，力求工作提质增速。

（三）加强自身建设。要把学习贯彻全会精神与“不忘初心、牢记使命”主题教育结合起来，把旗帜鲜明讲政治作为根本要求，把严格制度执行作为基本操守，把提升能力素质作为紧迫任务，把锤炼过硬作风作为重要保障，努力造就一支忠诚干净担当的高素质干部队伍。加强政治建设，经常开展宗旨教育、理想信念教育、理论学习教育等活动，持续用习近平新时代中国特色社会主义思想武装头脑、推进工作，以张富清、胡兆富等先进典型激励系统干部职工见贤思齐、矢志奉献。加强制度建设，完善各项规章，教育引导干部职工强化制度意识，自觉尊崇制度、严格执行制度、坚决维护制度，严禁做选择、搞变通、打折扣。加强能力建设，建立绩效考核、轮岗交流制度，编印培训标准教材，建立培训师资库，实施全系统三年教育培训规划，全面提高干部职工综合素质和业务能力。加强作风建设，完善担当作为的激励机制，鼓励干部职工敢啃“硬骨头”，敢立“军令状”；发扬斗争精神、增强斗争本领，敢于较真碰硬、善于攻坚克难；坚持只争朝夕、夙夜在公，带着感情和温度做工作，尽心尽力服务好保障好退役军人，努力让他们成为全社会尊重的人，让军人成为全社会尊崇的职业。

关于进一步深入贯彻落实党的十九届四中全会精神的具体意见还将在退役军人工作政策制度改革方案中予以明确。各地要不等不靠，立即行动起来，根据当地实际情况，主动担当、积极作为，创造性抓好贯彻落实，请及时将好的经验做法报部。

退役军人事务部
