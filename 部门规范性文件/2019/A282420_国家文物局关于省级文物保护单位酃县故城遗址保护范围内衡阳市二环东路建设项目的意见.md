# 国家文物局关于省级文物保护单位酃县故城遗址保护范围内衡阳市二环东路建设项目的意见

文物保函〔2019〕918号

湖南省文物局：

你局《关于在省级文物保护单位酃县故城遗址保护范围内进行衡阳市二环东路工程建设项目的请示》（湘文物报〔2019〕68号）收悉。经研究，我局原则同意在省级文物保护单位酃县故城遗址保护范围内实施衡阳市二环东路建设项目。

一、所报方案尚需做以下必要的修改和完善：

（一）进一步优化道路选线和交通管理，建议通过压缩绿化带、减少单侧车道宽度、降低设计时速、减小转弯半径等措施，尽可能避让遗址保护范围。

（二）深化道路景观设计方案，明确拟建道路与遗址的空间位置和高度关系，道路绿化、标识系统设计应统筹考虑酃县故城遗址展示工作需要，细化植被种类、施工方式、标识样式等，增加文化元素。

（三）严格控制工程范围和施工强度，明确施工期间水土保持、环境维护、施工后场地清理措施，做好施工中的文物保护工作，确保文物安全。

（四）应长期监测、评估道路使用期间的振动影响，明确减振或隔振措施。同时，建立健全责任监督机制，及时发现和处理安全隐患，确保文物安全。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古调查和发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

五、请你局指导地方人民政府落实主体责任，有序开展酃县故城遗址考古研究、规划编制、日常巡护等工作，妥善处理文物保护和社会发展之间的关系。

专此函复。

国家文物局

2019年8月30日
