# 国家核安全局关于颁发2019年第二批民用核设施核反应堆（核动力厂）操纵人员执照的通知

## 关于颁发2019年第二批民用核设施核反应堆（核动力厂）操纵人员执照的通知

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的有关规定，我局对大亚湾核电运营管理有限责任公司等9家营运单位民用核设施核反应堆操纵人员执照考核进行了监督，对执照申请文件进行了审核，认为赵子毅等135人满足首次取照相关要求，张涛等10人满足转移执照相关要求，牟小磊等253人满足换发执照相关要求，批准向上述398人颁发民用核设施核反应堆操纵人员执照（基本信息见附件）。

国家核安全局

2019年5月28日
