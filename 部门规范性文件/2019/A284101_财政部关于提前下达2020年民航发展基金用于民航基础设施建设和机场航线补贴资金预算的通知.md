# 财政部关于提前下达2020年民航发展基金用于民航基础设施建设和机场航线补贴资金预算的通知

财建〔2019〕576号

有关省、自治区、直辖市、计划单列市财政厅（局）：

根据《财政部民航局关于民航发展基金预算管理有关问题的通知》（财建〔2016〕362号）等有关规定和中国民用航空局《关于报送2020年民航发展基金转移支付提前下达资金方案的函》（民航函〔2019〕867号），现下达你省（自治区、直辖市、计划单列市，以下称省）2020年民航发展基金用于民航基础设施建设和机场航线补贴资金项目预算（项目代码：Z165060100005；投资补助项目列政府收支分类科目：2146901民航机场建设，中小机场补贴项目列政府收支分类科目：2146904航线和机场补贴，基建贷款贴息项目列政府收支分类科目：2146999其他民航发展基金支出，支线航空补贴项目列政府收支分类科目：2146904航线和机场补贴，通用航空发展项目列政府收支分类科目：2146907通用航空发展，特殊国际航线补贴项目列政府收支分类科目：2146904航线和机场补贴，安全能力项目列政府收支分类科目：2146903民航安全，教育培训项目列政府收支分类科目：2146999其他民航发展基金支出），具体详见附件，此次预算下达的同时一并下达绩效目标。

上述支出列入2020年预算，请严格按照有关办法规定，做好预算编制工作。
