# 农业农村部办公厅关于加强热带作物农情调度工作的通知

农办垦〔2019〕1号

广东、海南、云南、广西、福建、四川、贵州、湖南、西藏省（自治区）农业农村厅，广东、海南、云南、广西省（自治区）农垦主管部门，中国热带农业科学院，中国农垦经济发展中心：

为及时了解掌握热带、南亚热带作物生产情况，更加科学高效地提供信息支持和指导服务，现就进一步加强热带作物农情调度工作通知如下。

一、加强组织领导，确保调度顺利开展。要把热带作物农情调度工作作为热区发展农业生产和建设现代农业的一项重要工作来抓，健全工作机制，改善工作条件，充实人员队伍，明确工作职责。完善各级农情信息体系，做到农情信息专人负责、专人报送、渠道畅通，切实保障农情信息工作顺利进行。请省级主管部门于2019年1月20日前，将热带作物农情调度员名单和联系方式，函告我部农垦局热带作物处。

二、加大报送力度，提高信息报送时效。加强主要作物、重点地区、关键农时的动态信息调度，增加天然橡胶等9种主要热带作物产销情况月报表和年终预报，适当调整天然橡胶种植业生产、从业人员、橡胶树种植品种、橡胶树树龄和天然橡胶初加工等情况，以及其他主要热带作物生产、农业保险情况等年度报表指标。各级信息员要严格按照热带作物农情报送要求，在各报表（详见附件）规定的时限内，认真完成报表及文字信息的报送工作。

三、确保报送质量，全面反映真实情况。上报的农情统计数据必须真实、可靠、完整。要注意数据单位的一致性、动态数据的可比性，同一指标数据前后要相互衔接。重要信息（如面积、产量、价格等）应会商核实，并经主管领导审核批准后上报，确保上报的各项数据一致、符合逻辑。

四、强化体系建设，提升调度工作水平。积极争取资金投入，改善农情调度条件，完善农情调度体系。定期组织业务培训和经验交流活动，提高农情信息工作人员的政策水平和业务能力。根据新形势新要求，不断拓展农情信息工作内容，加强对热带作物生产形势、农工种植意向、市场价格等方面综合分析，提供翔实、准确的信息内容，更好地为热带作物产业高质量发展提供全方位的信息服务。

农业农村部办公厅

2019年1月2日
