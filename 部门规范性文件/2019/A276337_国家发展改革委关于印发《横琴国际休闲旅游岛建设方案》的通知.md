# 国家发展改革委关于印发《横琴国际休闲旅游岛建设方案》的通知

发改社会〔2019〕662号

《横琴国际休闲旅游岛建设方案》已经国务院同意，现印发你们，请按照《国务院关于横琴国际休闲旅游岛建设方案的批复》精神，认真组织实施。
