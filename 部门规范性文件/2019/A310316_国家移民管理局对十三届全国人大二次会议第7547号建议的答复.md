# 国家移民管理局对十三届全国人大二次会议第7547号建议的答复

田北辰代表：

您提出的关于便利港人往来香港内地倡即日补发临时回乡证的建议收悉，现答复如下：

年国务院颁布实施的《中国公民因私事往来香港地区或者澳门地区的暂行管理办法》第14条规定：“港澳同胞来内地，须申请领取港澳同胞回乡证，港澳同胞回乡证由广东省公安厅签发”。根据法律法规规定和实际工作需要，公安部委托香港中旅集团、澳门中国旅行社分别在港澳地区受理定居香港、澳门中国公民的港澳居民来往内地通行证（以下简称“回乡证”）申请，授权广东省公安厅审批签发。港澳居民在内地期间回乡证遗失、损毁或者失效需要返回港澳地区的，公安机关出入境管理部门为其办理三个月一次出境有效的出入境通行证；遇紧急、突发情况，急需返回港澳地区的，公安机关出入境管理部门将开通办证“绿色通道”，提供加急办理出入境通行证服务。

对于您提出由内地口岸人员为遗失回乡证的香港居民即日补发临时回乡证的建议，涉及出入境证件受理审批、制作管理及香港居民身份信息核查等工作。我局将综合考虑现实需要、口岸实际和服务管理要求等因素，抓紧调研论证，积极解决。

感谢您对移民管理工作的关心和支持。
