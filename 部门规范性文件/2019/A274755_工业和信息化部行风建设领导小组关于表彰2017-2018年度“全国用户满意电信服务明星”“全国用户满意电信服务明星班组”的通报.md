# 工业和信息化部行风建设领导小组关于表彰2017-2018年度“全国用户满意电信服务明星”“全国用户满意电信服务明星班组”的通报

## 关于表彰2017-2018年度“全国用户满意电信服务明星”“全国用户满意电信服务明星班组”的通报

工信行建〔2019〕1号

各省、自治区、直辖市通信管理局，各相关电信业务经营者：

2018年，按照《关于开展2017-2018年度电信服务评比表彰活动的通知》（工信行建〔2018〕1号）相关工作要求，工业和信息化部行风建设领导小组在通信行业组织了“全国用户满意电信服务明星”和“全国用户满意电信服务明星班组”的评选工作。

通过各相关企业基层单位申报，各通信管理局审核推荐，专家评审和社会公示，工业和信息化部行风建设领导小组决定授予张娜等98名个人“全国用户满意电信服务明星”称号，授予中国联合网络通信有限公司北京市分公司客服呼叫中心集中处理专席等31个班组“全国用户满意电信服务明星班组”称号（名单详见附件），并分别颁发荣誉证书和奖牌以资鼓励。

各单位要积极开展学习宣传全国用户满意电信服务明星、明星班组的先进典型事迹活动，引导企业员工进一步深化用户满意理念，不断进取，创新服务，努力提高电信服务水平，为我国信息通信事业的发展作出新的贡献。

附件：1.2017-2018年度“全国用户满意电信服务明星”名单

2.2017-2018年度“全国用户满意电信服务明星班组”名单

工业和信息化部行风建设领导小组

2019年3月4日
