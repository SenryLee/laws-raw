# 交通运输部办公厅关于公布2018年交通运输行业研发中心评估结果的通知

交办科技函〔2019〕155号

根据《交通运输行业研发中心管理办法》（交科技发〔2018〕114号），2018年9月至12月，部对认定满5年的交通运输行业研发中心组织开展了评估工作，评估结果经公示无异议。现予公布并就有关事项通知如下：

一、智能交通技术和设备行业研发中心（中设设计集团股份有限公司）等2个研发中心评估结果为优秀，山地交通安全与应急保障技术行业研发中心等4个研发中心评估结果为合格，应急救助与抢险打捞行业研发中心等2个研发中心评估认为需整改。

二、评估结果为优秀的研发中心，部将优先推荐申报国家级科技创新基地，并采取多种措施予以支持激励。

三、有关单位要认真总结经验，针对评估反映出的问题，研究落实改进措施，切实加强研发中心的建设与管理，促进研发中心建设水平和创新能力不断提高。

交通运输部办公厅

2019年1月29日
