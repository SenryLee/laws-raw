# 国家文物局办公室关于平遥县古建筑工程有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕600号

山西省文物局：

你局《关于平遥县古建筑工程有限公司变更施工一级资质经济性质和注册资金的请示》（晋文物〔2019〕25号）收悉。

经研究，我局同意平遥县古建筑工程有限公司文物保护工程施工一级资质证书中的经济性质由“股份合作制”变更为“有限责任公司（自然人投资或控股）”，注册资金由“3320万元”变更为“1亿元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年7月10日
