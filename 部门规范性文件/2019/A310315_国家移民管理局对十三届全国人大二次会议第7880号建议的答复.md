# 国家移民管理局对十三届全国人大二次会议第7880号建议的答复

吴秋北代表：

您提出的关于容许港人在内地直接更换、补领回乡证的建议收悉，现答复如下：

年国务院颁布实施的《中国公民因私事往来香港地区或者澳门地区的暂行管理办法》第14条规定：“港澳同胞来内地，须申请领取港澳同胞回乡证，港澳同胞回乡证由广东省公安厅签发”。根据法律法规规定和工作需要，公安部委托香港中旅集团、澳门中国旅行社分别在港澳地区受理定居香港、澳门中国公民的港澳居民来往内地通行证（以下称“回乡证”）申请，授权广东省公安厅审批签发。

为便利港澳居民申办出入境证件，近年来，我局先后启用新版电子卡式回乡证并延长证件有效期，指导香港中旅集团、澳门中国旅行社增设回乡证申请受理点，优化受理流程，推出网上预约办证、自助办理、缩短办证时限等服务举措。对于在内地期间回乡证遗失、损毁或者失效需要返回港澳地区的港澳居民，公安机关出入境管理部门为其办理三个月一次出境有效的出入境通行证；遇有紧急、突发情况，港澳居民急需返回港澳地区的，公安机关出入境管理部门开通办证“绿色通道”，提供加急办证服务。

为更好地服务和便利港澳居民在内地工作、生活和发展，我局正在积极研究在内地开展为港澳居民补发、换发回乡证工作。

感谢您对移民管理工作的关心和支持。
