# 国债业务公告2019年第17号——决定发行2019年记账式附息（七期）国债的公告

## 国债业务公告

2019年第17号

根据国家国债发行的有关规定，财政部决定发行2019年记账式附息（七期）国债（以下称本期国债），已完成招标工作。现将有关事项公告如下：

一、本期国债计划发行480亿元，实际发行面值金额480亿元。

二、本期国债期限7年，经招标确定的票面年利率为3.25%，2019年6月6日开始计息，招标结束后至6月6日进行分销，6月11日起上市交易。

三、本期国债为固定利率附息债，利息按年支付，利息支付日为每年的6月6日（节假日顺延，下同），2026年6月6日偿还本金并支付最后一次利息。

其他事宜按《中华人民共和国财政部公告》（2018年第174号）规定执行。

特此公告。

中华人民共和国财政部

2019年6月5日
