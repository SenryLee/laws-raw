# 农业农村部对政协十三届全国委员会第二次会议第2265号（农业水利类223号）提案答复

## 对政协十三届全国委员会第二次会议第2265号（农业水利类223号）提案答复

马廷礼委员：

您提出的关于以生态文明示范村建设为抓手大力推进脱贫攻坚和乡村振兴有机结合的提案收悉，经商住房城乡建设部，现答复如下。

一、关于顶层设计，做好规划编制工作

习近平总书记强调，实施乡村振兴战略，要坚持规划先行、有序推进，做到注重质量、从容建设，打造各具特色的现代版“富春山居图”。去年，党中央、国务院印发的《乡村振兴战略规划（2018—2022年）》明确提出，顺应村庄发展规律和演变趋势，根据不同村庄的发展现状、区位条件、资源禀赋等，按照集聚提升、融入城镇、特色保护、搬迁撤并的思路，分类推进乡村振兴。今年中央一号文件提出，强化乡村规划引领，把加强规划管理作为乡村振兴的基础性工作。贯彻落实中央决策部署，中央农办、农业农村部、自然资源部等5部门联合印发了《关于统筹推进村庄规划工作的意见》，要求深入学习浙江实施“千村示范、万村整治”工程以规划先行的经验，坚持县域一盘棋，推动各类规划在村域层面“多规合一”。以多样化为美，突出地方特色、文化特色和时代特征，保留村庄特有的民居风貌、农业景观、乡土文化，防止“千村一面”。

下一步，我部将会同有关部门加快推进《乡村振兴战略规划（2018—2022年）》在村域层面落实落地，指导各地以县为单位，加快编制或修编县域村庄布局规划，分类明确集聚提升、城郊融合、特色保护、搬迁撤并四类村庄分类，引导村庄依规有序发展。

二、关于加强历史文化保护，打造幸福家园

传统村落蕴含着中华文明的内在基因，传承着中华民族的历史记忆，寄托着中华儿女的乡愁情思。住房城乡建设部于2012年和2014年先后公布了《历史文化名城名镇名村保护规划编制要求（试行）》和《历史文化名城名镇名村街区保护规划编制审批办法》，指导各地依法依规编制保护规划。同时，国家对历史特色突出、保护规划编制符合国家要求的镇村，予以专项资金补助。“十二五”以来，已累计下拨中央补助资金约9.7亿元，支持了一大批中国历史文化名镇名村的基础设施建设项目。截至目前，住房城乡建设部会同国家文物局先后公布了7批共计312各中国历史文化名镇和487各中国历史文化名村。在加强传统村落保护方面，2012年以来，住房城乡建设部会同相关部门启动传统村落保护工作，印发《关于切实加强中国传统村落保护的指导意见》等文件，建立了传统村落认定保护、发展、监督、警示等机制，保护和利用文化遗产，保持传统村落的完整性、真实性、延续性。截至目前，住房城乡建设部会同相关部门分四批将4153个具有保护价值的村落列入中国传统村落名录。

下一步，相关部门将按照实施乡村振兴战略的总体要求，坚持共建共治共享的发展理念，紧紧围绕保护、利用和传承三个环节，健全传统村落保护政策体系，提升传统村落可持续发展能力，继承发扬优秀传统乡土文化，让我国历史悠久的农耕文明在新时代展现新魅力、新风采。

三、关于人居环境整治，营造生态宜居环境

改善农村人居环境，建设美丽宜居乡村，是实施乡村振兴战略的重要任务。2018年初，中共中央办公厅、国务院办公厅印发了《农村人居环境整治三年行动方案》，明确了总体要求和行动目标，把农村生活垃圾治理、生活污水治理、厕所革命等列为重点任务。在农村改厕方面，我部联合8部位印发了推进农村“厕所革命”专项行动的指导意见，强调统筹推进农村厕所粪污资源化利用；坚持建管并重，充分发挥村级组织和农民主体作用，鼓励采取政府购买服务等方式，建立政府引导与市场运作相结合的后续管护机制。同时，在山东淄博召开全国农村改厕工作推进现场会，举办全国农村卫生厕所新技术新产品展示交流活动。会同财政部落实70亿元中央财政资金，支持农村厕所革命整村推进奖补。在农村污水治理方面，2019年1月，我部会同生态环境部在安徽巢湖召开了全国农村生活污水治理工作现场会，指导各地坚持走符合农村经济社会发展实际的污水治理路子。2019年，生态环境部先后印发《关于进一步加强农业农村生态环境工作的指导意见》《农村生活污水处理设施水污染物排放控制规范编制工作指南（试行）》，指导各地统筹农村生活污水治理和厕所革命，坚持从实际出发，强化农村环境整治组织实施和监督管理，优化整治集聚提升类、城郊融合类、特色保护类村庄，因地制宜采用技术可行、经济合理、维护简便、务实管用的农村污水治理技术和模式，建立健全农村污染治理设施长效运行管理机制。在农村生活垃圾治理方面，住房和城乡建设部于2014年启动农村生活垃圾治理专项行动。2015年11月，中央10部门印发《关于全面推进农村垃圾治理的指导意见》，提出到2020年90%行政村生活垃圾得到有效处理的目标，确立农村生活垃圾全面治理的逐省（区、市）验收制度。2019年，农业农村部联合16个中央部门实施农村人居环境整治村庄清洁行动，把清理农村生活垃圾、清理村内塘沟作为主要任务，发动农民群众力量，通过春节战役、春季战役、夏季战役，建立健全村庄公共环境保洁制度，推动形成民建、民管、民享的长效机制，

下一步，我部将继续发挥好牵头抓总作用，会同有关部门加大工作力度，完善支持政策，指导各地有力有序推进包括农村厕所革命、农村生活垃圾污水治理在内的各项重点任务，确保如期完成农村人居环境整治三年行动目标。

四、关于产业支撑，构建现代农业产业体系

习近平总书记指出，产业兴旺，是解决农村一切问题的前提。近年来，党中央、国务院高度重视乡村产业发展，不断强化顶层设计，加大支持力度，为村庄发展注入了强大动力。一是强化产业发展指导。国务院印发了《关于促进乡村产业发展的指导意见》，明确了促进乡村产业振兴的总体要求，提出了乡村产业发展重点任务和政策措施。制定了促进农产品加工业发展、休闲农业和乡村旅游发展、返乡下乡人员创新创业等政策文件，出台了一系列减免税收、金融信贷、科技支撑、用地用电等务实管用的扶持政策，为推动乡村产业发展提供政策保障。二是大力发展农产品加工业。深入推进农产品加工业提升行动，建设了15.6万座农产品初加工设施，新增初加工能力1000万吨，果蔬等农产品产后损失率从15%降至6%。2018年，规模以上农产品加工企业7.9万家、营业收入14.9万亿元，农产品加工业和农业总产值比达到2.3﹕1。三是不断丰富乡村产业类型。实施休闲农业和乡村旅游精品工程，推介一批休闲农业和乡村旅游精品品牌，2018年休闲农业和乡村旅游接待游客30亿人次、营业收入超过8000亿元。大力发展农产品电子商务，农村网络销售额突破1.3万亿元，其中，农产品网络销售额达3000亿元。创新发展乡村服务业，支持开展农资供应、代耕代种、统防统治、烘干收储等生产性服务业，农村生产性服务业营业收入超过2000亿元。四是打造产业发展平台载体。支持建设了国家现代农业产业园114个、国家农业科技园32个、农产品加工园1600个，创建农村产业融合示范园148个、农业产业强镇254个，推广农业内部循环融合、产业延伸融合、功能拓展融合、新技术渗透融合、产村融合和复合型融合等多种融合模式。五是积极支持农村创新创业。认定农村创新创业园区和实训孵化基地1096个，制定并落实支持返乡下乡人员创新创业政策，吸引农民工、大中专毕业生、退役军人、科技人员等到乡村创新创业。截至2018年，各类返乡下乡创新创业人员累计达780万，“田秀才”“土专家”“乡创客”等本乡创新创业人员达3100多万。

下一步，我部将会同有关部门认真贯彻落实中央部署要求，大力培育植根于县域，以农业农村资源为依托，以农民为主体，以农村一二三产业融合发展为路径，地域特色鲜明、创新创业活跃、业态类型丰富、利益连接紧密的乡村产业，引导各地因地制宜发展特色产业，把产业链尽可能留在县乡村，促进农民就地就近就业增收。

五、关于美丽宜居示范村建设

建设美丽乡村既要注重乡村内部整治，更要坚持示范村的带动引领作用。近年来，党和国家高度重视美丽宜居示范村建设工作。先后下发《国务院办公厅关于改善农村人居环境的指导意见》，召开全国改善农村人居环境工作会议，部署美丽宜居示范村建设工作。2016年，国家启动改善农村人居环境示范村创建工作，东部地区重点申报美丽宜居示范村，中西部地区重点申报环境整治示范村，保障基本示范村仅限集中连片特殊困难地区和国家级贫困县申报。经各省（区、市）相关部门推荐和专家评审，2017年公布了第一批295各示范村名单，其中保障基本示范村99各，环境整治示范村97个，美丽乡村示范村99个，中央财政对示范村各补助100万元。

下一步，我部将会同相关部门进一步做好示范村建设工作，鼓励各地结合实际开展示范创建，总结一批可复制推广的典型范例，发挥示范引导作用，以点带面，连线连片，带动区域美丽乡村建设。

感谢您对推进乡村振兴战略实施工作的关心，希望继续对我部的工作给予支持。

农业农村部

2019年8月30日
