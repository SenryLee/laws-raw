# 国家文物局关于金界壕遗址内国道331线阿尔诺尔布敦至乌里雅斯太段公路建设项目的意见

文物保函〔2019〕895号

内蒙古自治区文物局：

你局《关于国道331线阿尔诺尔布敦至乌里雅斯太段公路穿越金界壕遗址的请示》（内文物字〔2019〕55号）收悉。经研究，我局原则同意在金界壕遗址保护区划内实施国道331线阿尔诺尔布敦至乌里雅斯太段公路建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）完善拟建项目设计及施工方案，压缩路面宽度，并注意不得采取开挖施工，避免对金界壕遗址，特别是对其基础部分造成直接破坏。

（二）细化拟建项目施工和运营期间的监测措施，密切关注各类振动对金界壕遗址本体的影响情况，补充必要的减振和车速控制措施，并制定相应的应急预案。

（三）明确施工期间的场地布置、施工组织、生态保护等要求，制定施工垃圾及污染物处置措施，以及施工结束后的场地清理、环境恢复措施。

（四）补充在适当区域设置长城保护标志、保护界桩、展示说明牌等标识、展示设施等相关措施。

二、请你局组织专业考古机构对拟建项目相关区域做全面的考古调查、勘探和必要的考古发掘，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年8月27日
