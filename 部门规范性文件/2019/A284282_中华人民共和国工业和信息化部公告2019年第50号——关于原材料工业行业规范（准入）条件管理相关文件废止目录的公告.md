# 中华人民共和国工业和信息化部公告2019年第50号——关于原材料工业行业规范（准入）条件管理相关文件废止目录的公告

## 中华人民共和国工业和信息化部公告

2019年第50号

为贯彻落实党中央、国务院关于转变政府职能和深化“放管服”改革的精神，经研究，我部决定自公告发布之日起废止《磷铵行业准入条件》（工业和信息化部公告2011年第31号）、《合成氨行业准入条件》（工业和信息化部公告2012年第64号）、《电石行业准入条件》（工业和信息化部公告2014年第8号）等26个原材料工业行业规范（准入）条件管理相关文件（详见附件）。

行业相关组织要充分发挥作用，加强行业自律建设，维护市场公平秩序，引导监督企业规范发展。

特此公告。

附件：原材料工业行业规范（准入）条件管理相关文件废止目录

工业和信息化部
