# 农业农村部对十三届全国人大二次会议第3639号建议的答复摘要

## 对十三届全国人大二次会议第3639号建议的答复摘要

农办议〔2019〕405号

近年来，为响应国家供给侧结构性改革要求，我部及相关部门高度重视新型肥料产业发展，采取多种措施积极推进肥料产业转型升级。一是加快政策引导。2015年，我部印发《到2020年化肥使用量零增长行动方案》，明确要求适应现代农业发展需要，引导肥料产品升级，优化氮、磷、钾配比，促进大量元素与中微量元素配合。二是强化基础研究。"十三五"期间，我部会同相关部门组织实施了国家重点研发计划"化学肥料和农药减施增效综合技术研发"重点专项，通过化学肥料和农药高效利用机理与限量标准研究、肥料农药技术创新与装备研发、化肥农药减施增效技术集成与示范应用，构建化肥农药减施增效与高效利用的理论、方法和技术体系。三是加快技术创新。2016年，我部成立国家化肥减量增效科技创新联盟和高效复合肥国家农业科技创新联盟。通过联合行业内专家、大型肥料生产企业和推广部门，打造科企合作平台，推动相关新产品、新技术的研发、转化和推广应用。四是搞好示范推广。我部结合实施化肥减量增效、果菜茶有机肥替代化肥等项目，分区域、分作物集成推广一批新型高效肥料和高产、绿色的化肥减量增效技术模式。五是加强示范基地建设。突出东北和黄淮海玉米产区、北方设施蔬菜集中产区、南菜北运基地、黄土高原和渤海湾苹果优势产区，创建300个化肥减量增效示范县（市），集中展示化肥减量增效集成技术，带动大面积推广应用。
