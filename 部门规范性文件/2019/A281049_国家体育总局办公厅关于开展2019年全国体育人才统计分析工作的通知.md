# 国家体育总局办公厅关于开展2019年全国体育人才统计分析工作的通知

## 体育总局办公厅关于开展2019年全国体育人才统计分析工作的通知

各省、自治区、直辖市、新疆生产建设兵团体育局，各直属单位，各相关全国性体育社会组织：

为全面准确收集整理全国体育人才数据，分析研究全国人才队伍情况和相关问题，提出体育人才发展对策和建议，并为制定《体育人才十四五规划》提供支撑，体育总局在全国范围组织开展体育人才统计分析工作，现将有关工作通知如下：

一、工作原则

深入贯彻习近平总书记关于人才工作和体育工作的重要指示批示精神，体现时代趋势，彰显体育特色，坚持求真务实，着眼体育工作的实际需要，按照简便易行、全面准确、实用有效的原则，切实摸清体育系统人才底数，深入分析人才发展状况，把握人才发展趋势，为人才队伍建设提供重要基础和科学依据。

二、统计调查方法

为了全面掌握全国体育人才队伍现状，采用全面统计调查法和抽样调查法，相互结合与补充。

（一）全面统计调查

面向全国范围体育系统内人才进行统计，根据"《全国体育人才统计调查表》操作说明"（附件1），组织填报《全国体育系统人才统计调查表》（附件2），掌握系统内体育人才的数量、结构、分布、培训和奖励等情况。由各省、自治区、直辖市的各级体育行政主管部门组织实施，统计后反馈上报。

（二）抽样调查

1.问卷调查

在辽宁（东北地区）、青海（西北地区）、河北（华北地区）、湖南（华中地区）、广东（华南地区）、浙江（华东地区）、贵州（西南地区）7个省份对体育人才发展情况进行抽样调查，掌握体育人才的职业结构、职业发展状况、职业主观感受等。相关省份体育行政主管部门组织人员，通过开放网络调查平台完成线上问卷调查，每个省份需要填写1600份问卷。参与人员登录https://www.wjx.cn/jq/43933679.aspx网址或扫描二维码，在线填写《全国体育领域人才发展状况抽样调查问卷》（附件3）。

![](https://zk-img.faxin.cn//Uedit_Upload/2019-08-29-10-09-17_7053216_569962.jpg)

2.现场访谈

2019年全国体育人才统计分析项目组到上海（东部地区）、湖北（中部地区）、宁夏（西部地区）3个省市，与当地的省、市、县各级体育主管部门、事业单位、有关协会和企业的相关人员座谈；到体育总局部分厅、司、局、各直属单位，全国性体育社会组织，有关企业，进行现场访谈。了解体育人才发展取得成就，存在的问题。访谈提纲见《"全国体育人才统计"访谈提纲》（附件4）。

三、统计调查范围

（一）全面统计调查范围仅限于体育系统。体育系统具体指体育行政部门及其主管、指导的事业单位、企业、社会组织，不包含教育系统、军队系统等其他系统中的体育人才、非公有制经济主体人才或自由职业者。

问卷调查统计范围为部分地区体育领域从业人员。包括体育、教育、军队和其他系统的体育从业人员，以及体育相关的非公有制经济主体人才、自由职业者等。抽样调查要覆盖省、市、县、乡各层级，尽量涵盖不同系统的体育管理人才、体育专业人才、体育技能人才。

现场访谈以实际调查情况为准。

（二）同时具备以下两个条件的人员应纳入人才统计调查范围：一是具有管理职务或职级的人员；或具有国家承认的专业技术职称的人员；或取得技工、技师等各种国家认可的技能等级、职业资格的人员。二是正式在编人员或签订1年以上合同关系的人才，不统计1年以下合同关系和劳务派遣人员。

（三）人才情况数据截止时间为2019年7月30日。

四、组织实施

各省、自治区、直辖市、新疆生产建设兵团体育行政主管部门，按照全国体育人才统计分析工作相关要求，制定本地区工作方案，统一部署并组织开展本地区统计工作。各级体育行政主管部门按照分级部署、层层深入、逐级分解的方式，负责组织下级部门开展统计工作，由省级直至市、县、乡各级，并指导本级所属企事业单位等完成统计任务。体育总局各直属单位，各相关全国性体育社会组织，按照要求组织开展本单位统计工作。

各基层单位要将统计工作落实到每位符合条件的体育人才。各级单位汇总个人填写的电子版材料，逐级反馈上级负责单位。省级体育行政主管部门，体育总局各直属单位、相关全国性体育社会组织完成本地区（单位）统计工作后，结合本地区（单位）工作实际，初步分析体育人才队伍发展情况，总结人才队伍建设的成功经验和存在问题，提出针对性意见，并于2019年10月31前形成报告（附相关材料）报送体育总局人事司人才工作处，电子版发送至rssrcc@sport.gov.cn.

各级体育行政主管部门、体育总局各直属单位、全国性体育社会组织，要从体育事业发展全局的高度，认识2019年全国体育人才统计分析工作的重要性和必要性，要高度重视、认真部署、精心组织、责任到岗、统计到人。各单位要指定1名分管领导和1名联络人负责组织和具体协调工作，抓好落实、摸清底数，积极主动推进工作，按时、按质完成工作任务。
