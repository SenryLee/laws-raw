# 国家文物局关于在清华大学早期建筑保护范围及圆明园遗址建设控制地带内新建化学馆工程的意见

文物保函〔2019〕600号

北京市文物局：

你局《关于清华大学早期建筑保护范围内新化学馆扩建工程方案的请示》（京文物〔2019〕710号）收悉。经研究，我局原则同意在清华大学早期建筑保护范围及圆明园遗址建设控制地带内新建化学馆工程设计方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步补充紧邻文物建筑选址的必要性和唯一性分析。同时，应在满足基本教学功能需求的前提下，进一步严格控制拟建建筑的规模、体量和高度，建议降低建筑高度，以不高于周边的何添楼与人环楼的建筑高度为宜。

（二）补充开展新建化学楼后，老化学馆及其所在区域的消防安全评估，并对相关设计做进一步调整完善，确保符合消防安全等相关要求。

（三）建议对新化学楼基坑支护进行专项设计，提高支护安全系数。在施工过程中要做好全程监测，制定相关的应急预案，确保文物安全。

（四）明确新建化学楼后老化学楼的具体功能定位，建议对老化学馆外立面的原设施管道、空调机及周边环境进行清理整治，并补充新建建筑西侧及北侧的景观设计内容，以与圆明园遗址及其周边环境相协调。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。场地条件具备后，应尽快开展考古工作，注意发现与熙春园遗址相关遗迹。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年6月25日
