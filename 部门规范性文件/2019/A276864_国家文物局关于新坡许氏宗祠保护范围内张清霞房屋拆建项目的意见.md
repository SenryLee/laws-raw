# 国家文物局关于新坡许氏宗祠保护范围内张清霞房屋拆建项目的意见

文物保函〔2019〕384号

广东省文物局：

你局《关于在广东省文物保护单位新坡许氏宗祠保护范围内居民张清霞房屋拆建工程方案的请示》（粤文物审〔2019〕12号）收悉。经研究，我局原则同意新坡许氏宗祠保护范围内张清霞房屋拆建项目。

一、所报方案尚需作以下必要的修改和完善：

（一）明确新坡许氏宗祠保护范围的管理规定，严格控制新建建筑的面积和高度，建筑占地面积不应超过原有面积。

（二）新建建筑的外观风貌应与许氏宗祠相协调，并尽量体现当地传统建筑风格。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》等相关法规，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年4月24日
