# 国家文物局办公室关于在邙山陵墓群及东周王城遗址保护区划内进行洛阳王城大道快速路建设项目的意见

办保函〔2019〕4号

河南省文物局：

你局《关于上报洛阳王城大道快速路项目选址方案的请示》（豫文物〔2018〕281号）收悉。经研究，我局暂不同意在邙山陵墓群及东周王城遗址保护范围和建设控制地带内进行洛阳王城大道快速路建设项目。

一、所报项目拟穿越全国重点文物保护单位邙山陵墓群、东周王城遗址的保护范围和建设控制地带，现有道路选线涉及多处重要遗迹，严重影响文物安全。应进一步论证洛阳王城大道快速路改扩建的必要性与可行性，结合洛阳城市发展规划、大遗址保护洛阳片区建设和邙山陵墓群、东周王城遗址保护需要，统筹考虑城市道路系统规划设计，进行多方案比选，尽量避让遗址保护范围。

二、请你局切实加强管理，督促地方人民政府和有关单位落实主体责任，尽快公布《邙山陵墓群保护总体规划纲要》，为文物保护和城市建设发展提供依据。

专此函复。

国家文物局办公室

2019年1月3日
