# 国家文物局关于申鸣城遗址保护规划的意见

文物保函〔2019〕228号

湖南省文物局：

你局《关于请求审批〈全国重点文物保护单位申鸣城遗址文物保护规划（2018-2035）〉的请示》（湘文物报〔2018〕120号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）应进一步加强考古研究和现场勘查，掌握申鸣城遗址分布范围、整体格局、历史沿革、保存现状等，在此基础上提炼遗址价值，明确保护对象与规划目标。

（二）综合分析遗址区位条件和土地、人口、建设、保护管理等方面现状，梳理相关规划要求，统筹考虑申鸣城遗址保护规划与九里楚墓群、城址内28处相关遗迹保护的关系，增强可操作性。

（三）应根据文物分布和保护管理需要，细化建设控制地带分类；明确保护区划与新安镇城镇重合区域，以及建设用地、工业用地的协调措施。细化保护范围和建设控制地带的管控要求，统筹考虑村庄建设、农业生产、环境整治、道路调整、基础设施建设和产业布局的关系。

（四）应加强与专业考古机构合作，完善考古研究规划内容，建议将澧水以南、望夫台楚墓群西侧区域纳入考古工作重点范围。合理确定工作内容和工作量，进一步明确具体考古工作分期计划、实施安排、以往考古资料整理计划等。

（五）合理测算游客量，深入分析遗址的展示利用条件，进一步论证遗址博物馆建设的必要性与可行性。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将申鸣城遗址保护规划报请湖南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好申鸣城遗址各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年3月1日
