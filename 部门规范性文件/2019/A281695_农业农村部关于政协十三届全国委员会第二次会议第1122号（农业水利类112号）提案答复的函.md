# 农业农村部关于政协十三届全国委员会第二次会议第1122号（农业水利类112号）提案答复的函

## 关于政协十三届全国委员会第二次会议第1122号（农业水利类112号）提案答复的函

农办案〔2019〕177号

刘凤之、李天来委员：

你们提出的"关于限制活畜禽长途调运，降低疫情传播风险的提案收悉".经商交通运输部，现答复如下。

随着社会经济的发展，全国大市场、大流通的格局逐步形成，活畜禽跨省长途调运现象愈来愈普遍。从动物疫病防控的角度，采取措施限制活畜禽大范围流通，可以有效降低动物疫病传播风险，降低动物疫情发生的几率，保障动物及动物产品卫生安全。我部正在积极推行"集中屠宰、冷链运输、冷鲜上市"的畜禽产品生产经营模式。

2018年10月份以来，我部和交通运输部等部门认真贯彻落实《国务院办公厅关于进一步做好非洲猪瘟防控工作的通知》（国办发明电〔2018〕12号）要求，完善活畜禽长途调运监管措施，加强调运监管，调整鲜活农产品运输"绿色通道"政策，加快推动畜禽产品冷链运输、冷鲜上市。

目前，我部正在推动有关部门进一步细化鲜活农产品运输"绿色通道"政策，逐步减少活猪长距离跨省调运，努力实现"运猪"向"运肉"转变。下一步，我部将积极配合有关部门，研究推动限制活畜禽长途调运的相关政策措施。

感谢你们对活畜禽长途调运的关注，希望继续对我部工作给予支持。

农业农村部

2019年8月30日
