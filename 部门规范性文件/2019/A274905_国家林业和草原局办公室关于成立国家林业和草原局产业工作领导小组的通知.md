# 国家林业和草原局办公室关于成立国家林业和草原局产业工作领导小组的通知

办改字〔2019〕49号

各省、自治区、直辖市林业和草原主管部门，内蒙古、大兴安岭森工（林业）集团公司，新疆生产建设兵团林业和草原主管部门，国家林业和草原局各司局、各派出机构、各直属单位：

为加强对林草产业工作的领导，进一步推动林草产业高质量发展，经研究，我局决定成立“国家林业和草原局产业工作领导小组”（以下简称“领导小组”），现将有关事项通知如下：

领导小组主要负责组织指导全国林草产业发展工作，研究拟定产业方针政策，协调解决产业发展中的重大问题，审议产业发展规划等重大事项。

领导小组下设办公室，办公室设在局发改司，承担领导小组日常工作，主要负责督促落实领导小组议定事项，协调推进产业发展相关工作，承办领导小组交办的有关事项。办公室主任由刘拓同志兼任，副主任由发改司刘家顺、李玉印、王俊中同志担任。
