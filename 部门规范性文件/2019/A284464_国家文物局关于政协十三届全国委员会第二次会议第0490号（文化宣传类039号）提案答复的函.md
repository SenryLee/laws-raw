# 国家文物局关于政协十三届全国委员会第二次会议第0490号（文化宣传类039号）提案答复的函

文物博函〔2019〕780号

董玉海委员：

您提出的《关于建设中国大运河博物馆的提案》收悉，现答复如下：

大运河是传承中华民族悠久历史和文明、展现我国劳动人民伟大智慧和勇气的伟大工程，体现了沿线地区生产和生活方式的变迁，是活化的历史文化遗产。加强大运河文化遗产保护传承利用，对于展示中华文明、彰显文化自信，促进大运河沿线区域经济社会高质量发展，具有重要意义。

党和国家高度重视大运河文化保护传承工作。习近平总书记多次作出重要指示批示，要求保护好、传承好、利用好大运河这一祖先留给我们的宝贵遗产，古为今用，深入挖掘以大运河为核心的历史文化资源。2019年2月，中共中央办公厅、国务院办公厅印发《大运河文化保护传承利用规划纲要》，对做好大运河保护传承利用工作，作出决策部署。

我局始终重视大运河文化带遗产保护和博物馆建设工作。2014年6月，我局指导申报的“中国大运河”项目被联合国教科文组织批准列入《世界遗产名录》，成为我国第32处世界文化遗产。近年来，我局指导大运河沿线各省，加强博物馆馆际协作，推进资源整合与开放共享，实现优势互补，在大运河文化遗产保护、展示与利用方面取得显著成效。截至2018年底，大运河沿线8省（市）共登记备案聊城中国运河文化博物馆、淮安运河博物馆、中国京杭大运河博物馆、洛阳隋唐大运河博物馆等10家运河专题类博物馆，全年参观总人数近400万人次。

按照现行管理体制，博物馆建设涉及的机构设置、项目审批、资金安排等事项，需由地方编制、发改、财政等部门批准解决。国家发展和改革委员会表示，中办、国办印发的《大运河文化保护传承利用规划纲要》中明确提出，要推进文化遗产保护展示工程，推进大运河博物馆体系建设，科学谋划并按程序报批新建各具特色的运河主题博物馆，下一步，国家发展和改革委员会将鼓励地方结合实际，加快推进落实。我局将充分发挥部门职能，协调大运河沿线有关省级文物行政部门加强相关业务指导，支持建设体系完整的中国大运河博物馆体系，让大运河在新时代焕发新的生机和活力，充分发挥爱国主义教育基地、科普基地作用，为服务经济社会高质量发展做出贡献。

此外，根据国家有关规定，国有博物馆名称因特殊情况确需冠以“中国”“中华”“国家”等字样的，需报请国务院审核同意。

感谢您对博物馆事业的关心和支持！

国家文物局
