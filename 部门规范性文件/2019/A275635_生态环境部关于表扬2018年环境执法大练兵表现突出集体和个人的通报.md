# 生态环境部关于表扬2018年环境执法大练兵表现突出集体和个人的通报

## 关于表扬2018年环境执法大练兵表现突出集体和个人的通报

环执法函〔2019〕42号

各省、自治区、直辖市人民政府，新疆生产建设兵团：

为加强全国环境执法队伍建设，进一步提高执法规范化和专业化水平，2018年，我部继续组织开展环境执法大练兵活动，采用案卷系统内部交叉评审和外部专家评审相结合、行政处罚表现和强化监督表现相结合等方式，并委托第三方机构对各地大练兵情况进行评估，评选出表现突出组织单位、进步明显单位、表现突出集体和表现突出个人。同时，对所有候选集体和个人事迹材料在我部网站、微信、微博、中国环境报网站和APP进行网上公示，接受公众监督。

在大练兵过程中，各地生态环境部门加强组织领导，创新机制，有效提升了大练兵实效。河北、山西、辽宁、河南、江苏、浙江、江西、山东、福建、重庆、广西、湖北、贵州、甘肃、西藏等省（区、市）成立以生态环境厅（局）主要领导为组长的领导小组。山东、安徽、重庆、广西等省（区、市）和新疆生产建设兵团通过大比武、知识竞赛等活动，营造“比学赶帮超”的氛围。浙江、江苏、福建等省生态环境厅联合省人社厅、公务员局给予上一年大练兵表现突出集体和个人记功奖励。山西、辽宁、海南、四川等省将大练兵督导与执法稽查紧密结合，督促基层推进执法规范化。新疆维吾尔自治区在《新疆日报》等主流媒体上刊发光荣榜。

通过大练兵，各地环境执法力度持续加大，2018年，全国环境行政处罚金额152.8亿元，比上年增加32%，有力遏制了违法高发态势。执法规范化程度明显提升，环境行政处罚文书制作更加标准、事实认定更加客观、法律适用更加准确、执法程序更加规范，树立了环境执法队伍的良好形象。

为充分发挥先进典型的示范带动作用，经研究决定，对2018年环境执法大练兵中，10个省级表现突出组织单位（见附件1）、4个省级进步明显单位（见附件2）、30个市级表现突出集体、60个县级表现突出集体（见附件3）和100名表现突出个人（见附件4）予以通报表扬。其中，福建、浙江、重庆、江苏等4省（市）保持练兵高水平，连续2年名列前茅。

生态环境保护队伍建设离不开各级党委和政府的关心、支持，请继续重视生态环境执法工作，对大练兵表现突出的集体和个人给予充分肯定和鼓励，引导和激励行政区域内生态环境执法机构和生态环境执法人员以他们为榜样，锐意进取、攻坚克难，为打好污染防治攻坚战作出新的贡献。
