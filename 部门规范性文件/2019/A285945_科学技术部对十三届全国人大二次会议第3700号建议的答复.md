# 科学技术部对十三届全国人大二次会议第3700号建议的答复

## 对十三届全国人大二次会议第3700号建议的答复

国科建议高〔2019〕33号

您提出的《关于加快审批科技创新2030—“煤炭清洁高效利用”重大项目实施方案的建议》收悉。经认真研究，现答复如下。

在煤炭消费总量下降的过程中加速以清洁、低碳、安全、高效为核心的煤炭生产和消费的革命，突破煤炭清洁高效利用的瓶颈技术，占领世界煤炭科技制高点意义重大。根据党中央、国务院科技创新2030—重大项目的统一部署，科技部依据中央批准的立项建议，于2017年启动“煤炭清洁高效利用”重大项目实施方案的编制工作。该重大项目围绕国家经济社会发展战略需求，针对我国煤炭开发利用中关键技术瓶颈，重点突破一批煤炭清洁高效利用基础研究的短板，实现一批核心关键技术创新，构建我国煤炭清洁高效可持续开发利用技术和管理体系，开展工程技术验证，实现技术集成创新，大幅度提高我国煤炭开发利用自主创新水平和综合技术能力。通过重大项目的实施，支撑煤炭由主体能源向基础能源战略转变，实现煤炭供给、消费和技术革命。

2017年8月至今，根据国家需求，对实施方案研究内容进行了反复凝练，编制过程召开了多次专家咨询会、专项委员会会议，征求了各部委的意见。2018年2月实施方案通过了战略咨询与综合评审特邀委员会咨询评议专题会议审议。中兴事件后，根据统一要求，对实施方案内容进一步凝练，并按要求征集科改领导小组成员单位及专项委员会成员单位意见。2019年5月，根据收到的意见，对实施方案做了进一步修改，现已形成《煤炭清洁高效利用实施方案（送审稿）》。

科技部将会同有关部门，按照重大项目的报批程序积极推进重大项目的启动实施，同时在重大项目后续实施过程中也将按照公平竞争、开放共享的原则，鼓励社会广泛参与。

感谢您对科技工作的支持！

科技部

2019年7月3日
