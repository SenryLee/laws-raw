# 文化和旅游部关于印发2019年度国家文化和旅游科技创新工程项目储备库出库名单的通知

文旅科教发〔2019〕89号

北京市、山西省、黑龙江省、上海市、浙江省、福建省、湖北省、广东省、广西壮族自治区、四川省文化和旅游厅（局），西藏自治区旅游发展厅，国家图书馆、中国国家博物馆、中国动漫集团有限公司，中央戏剧学院、中国音乐学院、上海音乐学院：

2019年度国家文化和旅游科技创新工程项目评审入库工作已经完成，现将国家文化和旅游科技创新工程项目储备库出库名单印发给你们，并就有关工作通知如下：

一、国家文化和旅游科技创新工程项目的评审、入库和出库实施是我部一项重要工作，请各单位予以高度重视，凡出库项目须切实纳入工作计划，提供各种必要条件，确保项目顺利实施，按期保质保量完成。

二、请你单位组织相关项目申报单位依据评审意见认真填写《国家文化和旅游科技创新工程项目合同书》。合同书模版请至“文化和旅游部政府门户网站—信息发布—工作动态—科技教育司”一栏下载。

三、请申报单位于2019年7月12日前将合同书电子版发送至电子邮箱。经审核通过后，于2019年7月19日前将加盖申报单位和推荐单位公章的合同书纸质版（一式三份）寄送文化和旅游部科技教育司。
