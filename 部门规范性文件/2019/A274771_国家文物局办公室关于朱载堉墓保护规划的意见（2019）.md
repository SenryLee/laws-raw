# 国家文物局办公室关于朱载堉墓保护规划的意见（2019）

## 国家文物局办公室关于朱载堉墓保护规划的意见

办保函〔2019〕140号

河南省文物局：

你局《关于再次上报朱载堉墓文物保护规划的请示》（豫文物〔2018〕286号）收悉。经研究，我局暂不同意所报规划。

一、所报规划应作以下必要修改和完善：

（一）加强前期考古研究和历史文献梳理，明确朱载堉墓的范围、布局和相关建筑、道路、石像生等遗迹情况，进一步明确文物构成、保护对象和环境要素，论证九峰寺旧址作为文物构成的可行性。

（二）完善价值评估，全面评价朱载堉在律学、历学、音乐等方面的贡献，说明朱载堉墓在明代藩王丧葬制度研究中的价值和意义。

（三）深化现状评估内容，分析墓园风水格局、墓园至九峰山间的视廊保护价值，以及现有道路、铁路等建设影响，补充张坡村居民活动、建构筑物现状评估内容，合理预估展示利用前景。简化保护管理现状评估，保护对象阐述内容应纳入规划说明。

（四）应根据文物分布、保护管理需要和村镇发展现状，重新确定保护区划及其具体边界，增强可操作性。建议适当缩小保护范围，将墓园北侧环境协调区局部纳入建设控制地带，强化墓园与九峰山之间的视廊控制力度。细化建设控制地带分类，墓园南北轴线和东西两侧村镇控制力度应有所区别；进一步完善建设控制地带管理规定，明确建筑屋顶形式、体量、色彩等具体控制指标。

（五）应重新调整文物保护措施、环境综合整治规划和展示规划内容，补充考古研究规划，根据现状评估结论和保护管理需要，研提具有针对性和可操作性的规划措施。建议近期应重点做好朱载堉墓园考古调查勘探，全面搞清墓园格局和重要遗址保存现状，不宜盲目拆改现有展示服务设施，进行村庄环境整治。

（六）进一步精简、核对文字，做到简洁、严谨、准确；加强图文对应。

二、请你局认真指导有关单位，根据上述意见和我局《关于朱载堉墓保护规划的意见》（办保函〔2018〕197号）对朱载堉墓文物保护规划进行修改完善，按程序另行报批。

专此函复。

国家文物局办公室

2019年2月28日
