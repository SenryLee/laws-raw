# 民航局机场司关于发布《民用机场飞行区技术标准（第一修订案）》的通知

民航各地区管理局，各机场公司，各机场建设指挥部，中国民航机场建设集团有限公司、中国民航工程咨询公司、上海民航新时代机场设计研究院有限公司、西安西北民航项目管理有限公司，其他有关咨询设计单位：

国际民用航空组织对公约附件14第I卷中的跑道道肩宽度、升降带宽度、滑行道宽度、滑行道最小间距、滑行道道肩宽度、进近面的内边长度等有关物理特性和障碍物等内容进行了修改并发布实施，经广泛征求意见并研究决定，发布《民用机场飞行区技术标准（第一修订案）》，修订内容详见附件。该修订案电子文本可在“民航专业工程建设项目招标投标管理系统”中下载，网址：https://zbtb.caac.gov.cn。

附件：《民用机场飞行区技术标准（第一修订案）》

民航局机场司

2019年3月26日
