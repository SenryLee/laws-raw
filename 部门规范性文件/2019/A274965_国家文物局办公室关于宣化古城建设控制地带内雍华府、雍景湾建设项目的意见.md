# 国家文物局办公室关于宣化古城建设控制地带内雍华府、雍景湾建设项目的意见

办保函〔2019〕152号

河北省文物局：

你局《关于呈报宣化古城建设控制地带内建设雍华府、雍景湾建设项目设计方案的请示》（冀文物字〔2019〕4号）收悉。经研究，我局暂不同意在宣化古城建设控制地带内实施雍华府、雍景湾建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应补充说明我局2017年原则同意的《宣化古城保护规划》修改完善和报请公布实施情况，并依据最终调整的《宣化古城保护规划》就该建设项目做出符合性说明。

（二）应根据《宣化古城保护规划》，校核并完善拟建项目选址及设计方案，拟建建筑地面和地下部分均不得进入宣化古城保护范围，位于I类建设控制地带内的建筑高度不得超过9.7米，位于Ⅱ类建设控制地带内的建筑檐口高度控制在13.2米以下（屋脊高度不超过15米）。

（三）应进一步深化文物影响评估，全面分析拟建项目对宣化古城价值及整体风貌的影响，并根据评估结论，适当降低位于古城保护区划以外的拟建建筑设计高度，优化项目整体布局，增加绿化面积。

（四）应进一步完善建筑外观设计，淡化外立面色彩，确保与宣化古城整体风貌相协调，并在拟建项目北侧、东侧设置通透围墙，增加垂直绿化，尽可能减缓项目对古城景观风貌的负面影响。

（五）应细化施工和运营期间的文物保护措施、生态环境监测措施、各类污染物处置措施，进一步明确施工场地布置、施工组织、生态保护、景观控制要求，并相应补充应急预案。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年3月5日
