# 教育部办公厅关于推荐第二届中国生态文明奖候选先进集体和候选先进个人的通知

教发厅函〔2019〕14号

部属有关高等学校：

根据生态环境部办公厅《关于开展第二届中国生态文明奖评选表彰工作的通知》（环办生态函〔2019〕33号）要求，由我部推荐一个中国生态文明奖候选先进集体、一个中国生态文明奖候选先进个人。现将通知转发给你们，请按照通知要求组织推荐一个中国生态文明奖候选先进集体、一个中国生态文明奖候选先进个人，并于2019年2月18日前将推荐表报送到教育部发展规划司，逾期视为不推荐。我部拟在2月下旬组织遴选。
