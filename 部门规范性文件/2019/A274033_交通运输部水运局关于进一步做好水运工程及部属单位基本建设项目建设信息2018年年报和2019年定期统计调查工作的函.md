# 交通运输部水运局关于进一步做好水运工程及部属单位基本建设项目建设信息2018年年报和2019年定期统计调查工作的函

水运工管函〔2019〕9号

各省、自治区、直辖市交通运输厅（局、委），长江航务管理局、珠江航务管理局，各有关统计数据报送单位：

根据《水运及交通运输支持系统建设项目统计调查制度》（国统制〔2018〕136号）和《交通运输部办公厅关于印发公路水路行业2018年年度和2019年定期统计调查制度的通知》（交办规划函〔2018〕1809号），为进一步掌握水运工程及部属单位基本建设项目具体情况，做好水运工程及部属单位基本建设项目信息2018年年报及2019年定期统计调查工作，现将有关事宜通知如下：

一、2018年统计报送工作开展情况总体较好，大多数单位能够按要求开展信息统计工作，报送信息及时。各有关单位要进一步提高对建设信息统计工作的认识，加强领导，安排专人负责，保障工作经费，认真组织实施，确保2018年年报及2019年定期统计调查工作顺利完成。

二、各有关单位应按照《水运及交通运输支持系统建设项目统计调查制度》要求，通过“水运及交通运输支持系统建设项目管理平台”统计软件如实填报资料，不得虚报、瞒报、漏报，确保统计数据的真实性和准确性。各单位需及时将统计填报人员信息报备。

三、统计调查制度中沿海水运工程建设信息统计工作由各省级交通运输主管部门负责组织实施；内河水运工程建设信息统计工作分别由各省级交通运输主管部门、长江航务管理局、长江南京以下深水航道建设工程指挥部负责组织实施；部属单位基本建设项目建设信息统计工作由部属单位及其他有关单位负责组织实施。

四、统计调查制度中定期调查（月报）统计期为上月26日至本月25日，要求于月后2日以电子邮件方式上报；年报统计期为1月1日至12月31日，要求于次年1月31日前以电子邮件方式上报（接收数据邮箱：syjstj@catsic.com）。

五、水运及交通运输支持系统建设项目统计工作由部水运局负责管理，日常统计与技术支持工作委托交通运输部科学研究院交通信息中心负责。《水运及交通运输支持系统建设项目统计调查制度》可登陆交通运输部网站（http://xxgk.mot.gov.cn/jigou/zhghs/201811/t20181126_3132536.html）下载。
