# 农业农村部对十三届全国人大二次会议第6846号建议的答复

## 对十三届全国人大二次会议第6846号建议的答复

张冬云代表：

您提出的关于加强基层基础工作促进乡村振兴战略的建议收悉。经商财政部，现答复如下。

一、关于继续加大“三农”投入力度

党的十九大部署推动乡村振兴战略，明确要坚持农业农村优先发展的总方针，建立完善农业支持保护制度，加快形成财政优先保障、金融重点倾斜、社会资本积极参与的农业农村多元化投入格局。近年来，各级财政不断加大对农业农村发展的投入力度，2018年，全国一般公共预算农林水支出迈上2万亿元的新台阶，增幅达9.9%。2019年，全国一般公共预算农林水支出安排2.22万亿元，同比增长7%，继续保持较快增长。按照简政放权的要求，相关涉农资金审批权限都下放到省，资金切块下达，地方可按规定统筹相关资金支持当地乡村产业、农技推广、集体经济发展、环境整治和农村基础设施建设等。同时，为突出加大高标准农田建设，根据党和国家机构改革有关精神，2019年我部会同财政部等部门整合农业综合开发、土地整治、农田水利建设等相关支出，加上中央预算内投资安排的农田建设资金，全部用于支持加快高标准农田建设，提高农业水土资源利用效率，确保到2020年建成8亿亩、2022年建成10亿亩高产稳产、旱涝保收、生态友好的高标准农田，保障国家粮食安全和重要农产品有效供给。

二、关于加强基层农经、农技体系和队伍建设

近年来，我部持续加大基层农技推广体系等方面建设投入，建设了一批国家农业科技示范展示基地，推广应用了一批符合优质安全、节本增效、绿色发展的重大技术模式。2019年通过中央财政安排基层农技推广体系改革与建设补助资金26亿元，重点支持实施农业重大技术协同推广计划、建设农业科技示范展示基地、加快农技推广信息化建设步伐、加大科技扶贫力度等。同时，2019年通过中央财政安排高素质农民培育资金20亿元，以农业职业经理人、现代青年农场主、农村实用人才带头人、新型农业经营主体骨干、农业产业扶贫对象作为重点培育对象，提升其生产技能和经营管理水平。此外，会同财政部安排资金加强对农业生产社会化服务支持，支持农村集体经济组织、专业化农业服务组织等具有一定能力、可提供有效稳定服务的主体，为从事粮棉油糖等重要农产品生产的农户提供农技推广、土地托管、代耕代种、统防统治、烘干收储等农业生产性服务。财政给予适当补助，降低农户的服务价格，促进农业技术扩大应用。

三、引导工商资本投资农业农村领域

近年来，我部会同有关部门积极推动体制机制改革创新，发挥财政资金“四两拨千斤”作用，引导更多社会资本投入“三农”。一是加强全国农业信贷担保体系建设。近年来，为着力解决农业适度规模经营主体“融资难”“融资贵”问题，中央财政安排资金支持全国农业信贷担保体系建设，指导各地采取财政担保费率补助和以奖代补等方式，提高新型农业经营主体农业生产经营贷款的可得性。二是落实普惠金融发展专项资金政策，综合运用费用补贴、贷款贴息等多种方式，降低创业担保贷款申请条件，放宽担保和贴息要求，提升“三农”等普惠金融重点服务对象的基础金融服务质量，鼓励支持社会工商资本和各类经营主体进入“三农”领域创新创业。三是会同财政部探索通过政府与社会资本合作（PPP）方式，引导和撬动金融社会资本加大农业投资。2017年5月，财政部和农业部联合印发《关于深入推进农业领域政府和社会资本合作的实施意见》（财金﹝2017﹞50号），明确将农业绿色发展、高标准农田建设、现代农业产业园、农产品物流与交易平台、互联网+现代农业等作为农业领域推广PPP的重点领域，提出要优化财政资金投入方式，探索农业领域推广PPP模式的实施路径、成熟模式和长效机制。目前，全国PPP综合信息管理平台管理库中已有70多个农业PPP项目、投资总额700余亿元。

下一步，我部将认真贯彻落实党中央、国务院决策部署，会同有关部门进一步完善相关政策措施，支持和引导更多社会资本和经营主体投入“三农”建设，推动乡村振兴战略顺利实施，加快推进农业农村现代化。

感谢您对农业农村工作的关心，希望继续对我部工作给予支持。

农业农村部

2019年9月19日
