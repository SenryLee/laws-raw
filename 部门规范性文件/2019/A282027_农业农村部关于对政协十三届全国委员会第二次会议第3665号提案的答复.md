# 农业农村部关于对政协十三届全国委员会第二次会议第3665号提案的答复

## 关于对政协十三届全国委员会第二次会议第3665号提案的答复

农办案〔2019〕85号

张劲委员：

您提出的“关于创新企业扶贫模式，确保长期稳定脱贫的提案”收悉。经商国务院扶贫办、财政部，现答复如下。

产业是贫困地区发展的根基，是实现脱贫的主要依托。党中央、国务院高度重视产业扶贫工作，明确把产业扶贫摆在“五个一批”的首位。我部认真贯彻习近平总书记关于脱贫攻坚的重要论述和中央脱贫攻坚决策部署，积极支持市场主体参与产业扶贫，创新完善利益联结机制，带动贫困户脱贫增收，一批扶贫龙头企业成长壮大、落地生根，成为当地带动脱贫的“火车头”，为脱贫攻坚工作做出了积极贡献。

一、关于推进贫困地区特色产业发展

为推进产业扶贫工作，根据中央部署要求，2016年，我部联合国务院扶贫办、发展改革委等8部门印发《贫困地区发展特色产业促进精准脱贫指导意见》，明确产业扶贫的思路重点、政策措施、贫困户受益机制等，指导贫困地区科学有序推进产业扶贫工作。指导22个扶贫任务重的省（区、市），综合考虑资源禀赋、产业现状、市场空间、环境容量以及产业覆盖面，组织编制完成省、县两级产业扶贫规划，推动贫困地区科学确定产业，精准设计项目，努力实现产业对人、人对产业。2017年，我部会同发展改革委、林草局印发《特色农产品优势区建设规划纲要》，围绕5大类29个重点品种（类）创建特色农产品优势区，加快培育特色产业，截至目前，已在贫困地区创建国家级特色农产品优势区46个。2018年，为贯彻中央打赢脱贫攻坚战三年行动的指导意见，我部会同国务院扶贫办、发展改革委等8部门专门印发《关于实施产业扶贫三年攻坚行动的意见》，明确提出新时期产业扶贫的目标和任务，进一步落实到村到户到人精准帮扶举措。同时，我部注重产业扶贫风险防范，积极开展农产品市场信息监测和分析预警工作，开通运行贫困地区农产品产销对接公益服务平台，及时发布农产品供求信息，实时提供农产品市场需求情况，有效应对市场波动风险。积极推动贫困地区特色农业保险发展，2019年我部配合财政部出台了中央财政对地方优势特色农产品保险奖补政策，引导各地对贫困地区特色产业保险给予优先支持。各地也积极探索保险扶贫的有效模式，扩大特色保险品种覆盖面，防范化解生产风险。

下一步，我部将会同财政部、国务院扶贫办等部门进一步落实产业扶贫三年攻坚行动，加强统筹协调，加快贫困地区扶贫特色产业发展。印发产业扶贫风险防范文件，指导各地落实产业扶贫风险防范措施，提高产业扶贫质量，增强产业带贫能力，巩固脱贫攻坚成果。

二、关于推进一二三产业融合发展

我部会同有关部门积极推进贫困地区一二三产业融合发展，积极支持贫困地区加强农产品品牌打造，强化产销衔接，促进产业可持续发展。一是促进一二三产业融合发展。大力推进贫困地区农产品产地初加工设施建设，2016年以来，共支持209个贫困县8224个合作社、家庭农场或农业企业建设马铃薯贮藏窖、果蔬贮藏库等初加工设施。2017—2018年，采取以奖代补方式，在贫困地区推动创建11个国家现代农业产业园，带动各地创建一大批省级和市县级产业园，推动生产、加工、营销、科技、品牌全产业链发展。2019年，支持贫困地区建设83个农业产业强镇，加快培育发展新产业、新业态。此外，我部还积极支持贫困地区休闲农业和乡村旅游发展，截至目前，认定贫困地区45个贫困县为全国休闲农业和乡村旅游示范县、111个村为中国美丽休闲乡村、22个旅游点为全国休闲农业与乡村旅游示范点。二是积极推动农产品品牌发展。2018年，我部印发了《农业农村部关于加快推进品牌强农的意见》，部署新时期农业品牌工作重点，为做好贫困地区农业品牌创建工作提供遵循。推动中国农产品市场协会建立中国农业品牌目录制度，优先将贫困地区农业品牌纳入其中。今年，我部为贫困地区绿色、有机食品和地理标志产品认证建立了“绿色通道”，实施优先受理、优先检查、优先审核、优先评审、优先颁证“五优先”政策，加大费用减免力度，支持贫困地区发展名优特新农产品。积极开展区域品牌推选工作，先后推选出中国十大苹果和十大茶叶区域公用品牌以及中国百强农产品区域公用品牌等，促进贫困地区区域公用品牌、企业品牌、产品品牌协同发展。三是大力促进农产品产销衔接。我部2018年举办了7场贫困地区农产品产销对接活动，为全国600多个贫困县提供营销推介服务，现场签约超过190亿元。2019年计划举办10场以上产销对接活动，进一步促进贫困地区农产品出村进城。目前，已在北京、云南等地举办4场对接活动，现场签约超过80亿元，取得了很好的效果。同时，连续在最近三届中国国际农产品交易会和茶产业博览会上设立扶贫展区，组织贫困地区农产品免费展销。

下一步，我部将会同相关部门继续大力支持贫困地区加快发展扶贫特色产业，大力发展农产品加工业、休闲农业和乡村旅游等，促进产业融合发展。积极指导和推动贫困地区加快扶贫产业园创建和“一村一品”发展，打造一批名特优新农产品品牌。同时，继续开展产销对接活动，加大对贫困地区农产品品牌推介力度，帮助贫困地区扩大品牌影响力。

三、关于提高贫困人口参与机会和增收空间

我部会同有关部门通过加强带贫主体培育、加强人才培养、创新和完善利益联结机制等措施，增强贫困人口内生发展能力，帮助贫困户分享更多产业收益。一是提高新型主体带贫能力。我部始终重视贫困地区培育壮大龙头企业、专业合作社等新型经营主体，带动贫困户发展产业。在农业产业化国家重点龙头企业认定时对贫困地区予以倾斜，积极支持贫困地区创建国家农民合作社示范社，发挥龙头带动作用，带领贫困户参与市场竞争。目前，全国832个贫困县已发展市级以上龙头企业1.4万家，农民专业合作社61万多家。此外，积极牵线搭桥，组织龙头企业与西藏、新疆南疆、环京津贫困县、大兴安岭南麓片区、武陵山区等贫困地区进行合作对接，为促进当地加快脱贫攻坚步伐注入了新的活力。国家有关部门注重强化特惠金融支持，对带动贫困户脱贫的行业龙头企业和合作组织给予扶贫再贷款政策。国务院扶贫办专门印发关于完善扶贫龙头企业认定和管理制度的通知，明确要求扶贫龙头企业认定和管理要以建立精准带贫减贫机制为导向，以贫困人口参与共享为基本标准，提升扶贫龙头企业的带贫作用。二是增强贫困群众自我发展能力。我部积极通过多种方式提升贫困群众自我发展能力。截至2018年底，依托高素质农民培育工程，已培训贫困地区专业大户、家庭农场经营者、农民合作社带头人、农业社会化服务人员等39.1万人。依托农村实用人才带头人和大学生村官示范培训项目，2018年培训贫困地区种养大户、合作社负责人、村“两委”成员、大学生村官等2.51万，帮助他们提升创业兴业、致富带贫能力。三是完善利益联结机制。我部立足贫困地区实际，总结推广订单帮扶、股份合作、园区带动、生产托管、资产收益等带贫模式，指导贫困地区创新和完善利益联结机制，让贫困群众从产业发展中获得实实在在的好处。积极支持龙头企业与贫困户签订购销合同，保障农户合理收益，引导贫困户以土地经营权等资源要素入股龙头企业，以股东身份直接获得经营收益，鼓励龙头企业就近吸纳贫困户务工就业，增加贫困户工资性收入。2017年，总结遴选13个产业扶贫范例，积极推广“企业+合作社+贫困户”等多种带贫模式，有效发挥了示范引导作用。

下一步，我部将进一步加大对贫困地区龙头企业、合作社等带贫主体培育力度，进一步完善农民培训体系，提高培训的针对性，增强贫困群众自我发展能力。继续完善利益联结机制，再总结一批产业扶贫范例在全国宣传推广，发挥典型引路作用。积极推动贫困地区农村资源变资产、资金变股金、农民变股东改革，让贫困户在产业发展中获得更多收益。

感谢您对农业农村工作的关心，希望继续对我部工作予以支持。

农业农村部

2019年8月29日
