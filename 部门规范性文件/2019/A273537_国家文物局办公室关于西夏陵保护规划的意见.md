# 国家文物局办公室关于西夏陵保护规划的意见

办保函〔2019〕14号

宁夏回族自治区文物局：

你局《关于报审〈西夏陵保护规划（2015—2030）〉》的请示（宁文物发〔2018〕65号）收悉。经研究，我局暂不同意所报规划。

一、所报规划应作以下必要修改和完善：

（一）应全面评估原规划执行情况，分析影响规划实施的主要原因、修编拟解决的主要问题，论证修编的必要性。同时应从申报世界文化遗产工作的需要出发，将相关国际文件列为规划修编的重要依据。

（二）加强现状评估内容，分析部队设施、村庄和建成区现状，补充冲积扇台地的河水水文数据、冲刷灾害情况和考古工作历史、成果和问题评估内容，补充文物真实性、完整性分析。

（三）应评估区分重点保护区和一般保护区的必要性。结合国家级风景名胜区管理规定，调整一类建设控制地带划定范围，梳理相关管理控制措施；进一步论证二类建设控制地带18米高度的合理性，评估控制要求对区域景观的影响；明确建筑密度要求；建议取消二类环境风貌控制区。

（四）应优先解决土遗址保护问题，细化冲积扇台地防洪、墓葬安防、游客数量控制等要求，加强遗址安防规划内容，明确增加开放区域比例的数据和测算依据。

（五）细化考古工作规划，与考古专业机构协商制定中长期的考古研究内容，应开展西夏陵与辽金及北宋帝陵的比较研究，以及与西夏都城兴庆府关系的研究，深化价值认识，优先开展城市发展迫近区域的考古工作。

（六）加强规划协调，明确环境控制区与所在区域的自然保护区、风景名胜区等管理要求的衔接措施。明确建设控制、搬迁或改造的对象和规模。

（七）应按照《全国重点文物保护单位保护规划编制要求》，进一步规范文本体例，补充文本内容。

二、请你局指导有关单位根据上述意见对西夏陵保护规划进行修改完善，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月10日
