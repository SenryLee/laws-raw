# 国家中医药管理局党组关于向共和国勋章获得者屠呦呦同志学习的决定

各省、自治区、直辖市中医药管理局，新疆生产建设兵团卫生健康委，局机关各部门、直属各单位：

2019年9月29日，中共中央总书记、国家主席、中央军委主席习近平同志向屠呦呦同志颁授“共和国勋章”。

为深入学习习近平总书记在国家勋章和国家荣誉称号颁授仪式上的重要讲话精神，深入宣传屠呦呦同志的先进事迹和忠诚、执着、朴实的鲜明品格，推动中医药行业敬仰英雄、学习英雄，激励广大干部职工在促进中医药传承创新发展中像英雄模范那样坚守、像英雄模范那样奋斗，同题共答中医药高质量发展的时代大考，局党组决定在全国中医药行业向屠呦呦同志学习。

屠呦呦，女，汉族，中共党员，1930年12月出生，浙江宁波人，现任中国中医科学院终身研究员、青蒿素研究中心主任。她60多年致力于中医药研究实践，带领团队攻坚克难，研究发现了青蒿素，解决了抗疟治疗失效难题，为中药科技创新和人类健康事业作出了巨大贡献，先后荣获2015年诺贝尔生理学或医学奖、2016年度国家最高科学技术奖和全国优秀共产党员、改革先锋等称号。

屠呦呦同志在抗疟疾药物研发道路上锲而不舍、默默耕耘，永葆初心和使命，让来自中药青蒿的青蒿素成为中国送给世界的礼物。1969年1月，她担任中药抗疟科研组组长，勇担国家抗疟药物研究重任，以执着、坚韧的品格，从中医药这一伟大宝库中寻找创新源泉，从浩瀚的古代医籍中汲取创新灵感，从现代科学技术中吸收创新手段，不畏艰辛、无私奉献，研究发现了青蒿素，为人类带来了一种全新结构的抗疟新药，解决了抗疟治疗失效难题，标志着人类抗疟步入新纪元。以青蒿素类药物为基础的联合疗法（ACT疗法）成为世界卫生组织（WHO）推荐的疟疾治疗最佳方法，挽救了全球特别是发展中国家数百万人的生命。接踵而来的荣誉并没有让屠呦呦同志止步，年近九旬的她仍在抗疟领域孜孜以求，带领团队在深化“青蒿素抗疟机理研究”、解决青蒿素“抗药性”难题等方面不断取得新进展，提出新方案。

学习屠呦呦同志，就是要胸怀祖国、敢于担当，秉承科学报国的家国情怀，坚持国家利益和人民利益至上，始终把“以国家需求为己任”作为人生追求，以舍我其谁、勇于献身的精神，不忘初心、牢记使命，充分发挥中医药独特优势，为建设健康中国和实现“两个一百年”奋斗目标贡献力量；就是要团结协作、传承创新，大力弘扬协同精神，强化集体观念，厚植团队意识，集智攻关、跨界合作，深入发掘中医药宝库中的精华，将中医药理论和现代科学技术相结合，为推动我国生命科学实现创新突破、构建人类命运共同体贡献中国智慧；就是要情系苍生、淡泊名利，静心笃志、力戒浮躁，耐得住寂寞、甘坐冷板凳，肯下“数十年磨一剑”的苦功夫，大力弘扬“大医精诚、博极医源”的优良传统和“敬佑生命、救死扶伤、甘于奉献、大爱无疆”的卫生健康职业精神，不断满足人民群众对美好生活向往的中医药需求，努力实现百姓方便看中医、放心用中药；就是要增强自信、勇攀高峰，坚定民族自信、文化自信，勇攀医学高峰，勇担历史使命，勇创时代业绩，推进中医药科技创新，推进中医药现代化，推动中医药走向世界，促进中医药与西医药相互补充、协调发展，切实把中医药这一祖先留给我们的财富继承好、发展好、利用好，不断提出新理论、开辟新领域、实现新突破。

国家功勋彪炳史册，英雄精神激励人心。全国中医药行业广大干部职工要以习近平新时代中国特色社会主义思想和党的十九大精神为指导，深入学习贯彻习近平总书记关于中医药的重要论述，把开展向屠呦呦同志学习与巩固拓展“不忘初心、牢记使命”主题教育成果结合起来，与贯彻落实《关于促进中医药传承创新发展的意见》结合起来，与各自的本职工作结合起来，学习先进、崇尚先进、争当先进，弘扬忠诚、执着、朴实的鲜明品格，积极投身到新时代中医药事业高质量发展的伟大实践中，在平凡的岗位上深耕不辍、建功立业，为建设健康中国、实现中华民族伟大复兴的中国梦作出新的更大贡献。

中共国家中医药管理局党组

2019年9月29日
