# 中国证券监督管理委员会对十三届全国人大二次会议第4439号建议的答复

## 对十三届全国人大二次会议第4439号建议的答复

《关于解禁〈清理整顿各类交易场所〉“五停止”措施的建议》收悉。经认真研究，现就有关问题答复如下：

**一、**清理整顿各类交易场所工作推进情况

交易场所的基本功能是为市场参与者提供平等、透明的交易机会，促进要素和商品的有序流转和公平交易，具有较强的社会性和公开性，需要依法规范管理，确保安全运行。清理整顿各类交易场所是整治金融乱象、防控金融风险的一项重要工作。

2011年以来，根据《国务院关于清理整顿各类交易场所切实防范金融风险的决定》（国发〔2011〕38号）《国务院办公厅关于清理整顿各类交易场所的实施意见》（国办发〔2012〕37号）部署和要求，清理整顿各类交易场所部际联席会议（以下简称联席会议，由我会牵头）统筹协调，有关部门共同督导，各省级人民政府积极推进清理整顿工作。尤其是2017年初联席会议第三次会议部署开展“回头看”工作以来，在党中央、国务院坚强领导下，各地区各部门积极采取措施，集中开展清理整顿工作，有效遏制了交易场所无序扩张、风险蔓延势头，市场秩序明显好转。针对前期违规交易场所遗留问题和风险隐患亟待化解，交易场所过多过滥、脱实向虚问题尚未根本得到扭转，违法违规活动滋生的条件仍然存在等问题，2018年3月、9月，联席会议分别召开清理整顿各类交易场所“回头看”后续工作会议和交易场所清理整顿工作专题会议，研商部署清理整顿工作的重点任务和工作措施。同时，联席会议陆续印发有关政策文件，重申和明确相关政策要求，部署稳妥开展交易场所清理整顿和风险处置工作。今年以来，我会认真履行联席会议牵头单位职责，会同有关部门，督导各地区积极有序推进清理整顿工作，全力打好清理整顿各类交易场所攻坚战。

**二、**整治违规交易场所相关政策要求

根据中央经济工作会议和全国金融工作会议精神、国发〔2011〕38号和国办发〔2012〕37号文件有关规定及有关政策规定，清理整顿各类交易场所的政策要求标准一致、全国统一。

清理整顿各类交易场所“五停止”工作措施，是针对违规交易场所问题不断蔓延扩张，而采取的风险控制政策要求。当违规交易场所问题得到整治规范、风险得到有效处置后，省级人民政府清理整顿交易场所领导机构可按照相关规定和程序解除“五停止”限制措施，同意已停业交易场所恢复交易。

各地区应按照相关政策要求，针对辖内交易场所实际情况，结合辖内交易场所的总体规划、整合进展以及违规交易场所整改规范情况，稳妥有序推进交易场所遗留问题和风险的处置工作，完善监管机制，推动各类交易场所走上规范发展道路。

**三、**交易场所监管制度逐步健全完善

近年来，国内金融快速发展，金融改革不断深化，各类新型金融业态不断涌现，对金融监管工作提出了新要求。在此背景下，完善包括地方交易场所在内的地方金融监管相关法律依据，对完善地方金融领域监管、防范化解金融风险具有重大意义。根据国发〔2011〕38号、国办发〔2012〕37号文件规定，联席会议负责统筹协调、督促、指导省级人民政府开展各类交易场所清理整顿工作，督导有关部门和省级人民政府建立对交易场所和交易产品的规范管理制度。目前，部分类别交易场所已有国家层面的规定（如区域性股权市场、农村产权交易市场、公共资源交易平台），国家有关部门对碳排放、电力等部分交易场所也发布了具体规定，全国已有28个省（区、市）出台了交易场所管理规则，有关交易场所的监管制度不断完善。

目前，地方各类交易场所类别多样，交易品种众多，情况比较复杂。地方交易场所管理制度既要兼顾统分关系，做好统一的交易场所管理制度与具体类别交易场所行业监管制度协调衔接，也要兼顾地方金融领域同非金融领域的监管适配，在地方事权范围内进一步研究论证，以保持交易场所监管规则体系的完整性、协调性和统一性。

下一步，我会作为联席会议牵头单位，将坚决贯彻落实党中央、国务院决策部署，推动有关部门和地方政府认真总结清理整顿和规范发展各类交易场所的实践经验，完善各类交易场所监管规则和长效监管机制，切实发挥其服务实体经济功能。
