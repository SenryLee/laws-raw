# 中共国家税务总局委员会关于在“不忘初心、牢记使命”主题教育中开展向施星灿等同志学习活动的通知

为进一步发挥先进典型引领作用，引导广大税务干部牢记初心使命，忠诚履职尽责，推动“不忘初心、牢记使命”主题教育取得扎实成果，税务总局党委号召全国税务系统开展向施星灿等同志学习活动。现就有关事项通知如下：

近年来特别是党的十八大以来，全国税务系统党员、干部以习近平新时代中国特色社会主义思想为指导，坚决贯彻落实党中央、国务院的部署和要求，为国聚财、为民收税，在推进税收各项工作特别是国税地税征管体制改革、落实减税降费政策等重点工作中，不计个人得失，倾力投入、奋力拼搏，攻坚克难、无私奉献，展现了忠诚干净担当的高素质专业化税务铁军形象，涌现出一大批以施星灿、王俊华、李玉斌同志为代表的先进典型。

施星灿同志是原湖北省利川市国税局离休干部，1928年出生，1950年参加抗美援朝，先后12次立功受奖，荣获“金日成勋章”。1966年转业，他放弃在北京工作的机会，主动申请到当时偏远的湖北省恩施州利川市，从事基层财税工作直至离休，2014年去世。施星灿同志长年奔波在条件艰苦的偏僻高寒山区，不厌其烦地宣传税收政策，不辞辛苦地组织税收收入，不遗余力地支持发展税源，助力当地经济税收事业稳步健康发展；他时刻不忘为人民服务的宗旨，通过“高山种植烟叶、平坝发展果园”等思路举措，帮助群众脱贫致富；他始终保持艰苦朴素的生活作风，主动把单位分的大房子让给其他同志，面对淮河大水、长江洪灾、汶川地震、玉树地震等自然灾害，他慷慨解囊、倾力相助，各类捐款和缴纳的特殊党费累计超过10万元。2019年5月，以纪实手法再现施星灿同志平凡而伟大一生的影片《武陵山上的星光》在全国公映，引起社会强烈反响。施星灿同志始终坚守初心、坚定信仰，牢记为人民服务宗旨，时刻保持共产党员本色，经受住了时间和历史的考验，用自己的行动回答了共产党员是“先进一阵子”还是“先进一辈子”的问题，被誉为“信念老人”。他几十年如一日吃苦在前、享乐在后，爱岗敬业、无私奉献，充分展现了“忠诚担当、崇法守纪、兴税强国”的中国税务精神，给税务系统留下了宝贵的精神财富。

王俊华同志是原国家税务总局菏泽市牡丹区税务局人事教育科临时负责人，1962年出生，1979年入伍，1982年转业到基层税务局，1985年后从事人事相关工作，先后获得山东省五一劳动奖章、荣立2次三等功、连年受到单位嘉奖。2018年8月突发心梗去世。王俊华在长期的基层工作中，始终保持严谨认真的态度、一丝不苟的作风、公道正派的品格，清廉自守、埋头苦干，用公正去对待每一个人，用热情去温暖每一个人，用真诚去感动每一个人，成为税务干部信任、依赖和敬佩的贴心人。在国税地税征管体制改革期间，面对合到一起的大队伍和大量前期重要工作，王俊华经常加班到次日凌晨，他桌上的干部花名册不到一周的时间就翻得卷了边，包括离退休人员在内的854人，每个同志年龄多大、哪年任职、工资多少、家住哪里、电话号码等等，他张口就来。就是凭借着这股劲，他成了机构人员方面的“点读机”“活字典”，为单位“三定”方案的制订落实作出重要贡献。

李玉斌同志是原国家税务总局河北省税务局征管和科技发展处处长，1973年出生，1996年参加税收工作，先后4次荣立二等功、3次三等功、10次被省市局评为优秀共产党员。2019年4月突发疾病去世。李玉斌是一位攻坚克难、精益求精的税收工匠。他挚爱税收事业，始终在工作上保持着一股不屈不挠的拼劲、钻劲、韧劲，在许多急难险重的任务面前，勇挑重担，冲锋在前，攻坚克难。在“金三”系统上线运行中，他着力破解系统卡顿、排队拥堵等难题，创造性地提出了“放宽纳税人网上客户端申报范围”和办税厅按事项人员分流的办法，为纳税人减少了95%以上的人工办税事项。在减税降费工作中，他把海量基础性数据技术筛查工作扛在肩上，短时间内和同事们一道编写了近2万行的后台语句提取数据，实现了系统内代开发票业务和“六税两费”申报业务的全覆盖，实现减税降费政策落实精准高效。

为进一步深入扎实开展好主题教育，税务总局党委决定：在全国税务系统开展向施星灿、王俊华、李玉斌同志学习的活动。学习他们笃定信念、矢志奋斗的政治品格，坚持“革命理想高于天”，坚定不移跟党走，真正做到“党需要我到哪里，我就到哪里去”；学习他们恪尽职守、担当有为的务实作风，干一行爱一行，勇挑最重的担子，敢啃最硬的骨头，把理想信念时时处处体现为行动的力量；学习他们甘于奉献、勇于牺牲的崇高境界，在平凡的岗位上艰苦奋斗、苦干实干，在关键时刻和危机关头豁得出、顶得上、打得赢；学习他们廉洁自律、无私奉献的道德情操，不计较个人得失，清清白白做人、干干净净干事，自觉践行共产党人价值观，真心实意为人民群众谋幸福。

税务系统各级党组织在开展“不忘初心、牢记使命”主题教育中，要紧紧围绕学习贯彻习近平新时代中国特色社会主义思想这条主线，把施星灿、王俊华、李玉斌同志先进事迹作为鲜活教材，教育激励广大税务干部坚定理想信念，增强“四个意识”，坚定“四个自信”，做到“两个维护”，大力弘扬和践行中国税务精神，真抓实干，开拓进取，攻坚克难，努力做合格党员、当时代先锋、创优秀业绩、为人民造福。

各级税务机关党委（党组）理论学习中心组要带头学习施星灿、王俊华、李玉斌同志的先进事迹，领导干部要主动把自己摆进去，把职责摆进去，联系思想实际，检视自身差距，不断提高党性修养，改进工作作风，用担当诠释忠诚，用作为彰显价值，扎实做好落实减税降费政策、依法组织税费收入、优化税收营商环境等各项税收工作。基层党组织要依托“三会一课”、主题党日等，组织党员干部开展专题学习交流，教育引导党员干部以先进典型为标杆，学习先进、争当先进，牢记初心使命，忠诚履职尽责，干好本职工作，服务奉献社会，始终保持党组织和党员干部的先进性、纯洁性，奋力谱写高质量推进新时代税收现代化新篇章，以实际行动向新中国成立70周年献礼！
