# 国家核安全局关于同意瓦卢瑞克核电管材（广州）有限公司民用核安全设备制造许可证主要分包项目变更的通知

## 关于同意瓦卢瑞克核电管材（广州）有限公司民用核安全设备制造许可证主要分包项目变更的通知

国核安函〔2019〕40号

瓦卢瑞克核电管材（广州）有限公司：

你公司《关于修改民用核安全制造许可证主要分包项目微量元素含量测试的申请》（VNG-ED-2018-016）收悉。经研究，通知如下。

根据《中华人民共和国核安全法》《民用核安全设备监督管理条例》及其配套规章的要求，我局对你公司民用核安全设备制造许可证主要分包项目变更申请进行了审查，同意取消你公司《民用核安全设备制造许可证》（国核安证Z（15）30号）许可活动范围表中主要分包项目中的“微量元素含量测试”。

你公司应按照许可证规定的范围和条件，开展民用核安全设备制造活动，确保民用核安全设备制造质量。

国家核安全局

2019年5月30日
