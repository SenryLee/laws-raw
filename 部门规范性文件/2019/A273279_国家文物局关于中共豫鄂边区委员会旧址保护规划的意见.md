# 国家文物局关于中共豫鄂边区委员会旧址保护规划的意见

文物保函〔2019〕4号

湖北省文化和旅游厅：

湖北省文物局《关于申报豫鄂边区委员会旧址保护规划的请示》（鄂文物〔2017〕48号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）完善现状评估，归纳现存问题，明确评估结论，特别应补充对已完成保护项目的评估内容。

（二）建议将建设控制地带向北扩大至山顶，加强对主要视廊的控制。

（三）增强本体保护措施的针对性和适用性，明确保护工程性质；补充白蚁、木蜂防治策略。

（四）防灾规划补充山体排水系统相关内容，河道整治应与吴河湾河道整体整治工程相衔接。

（五）环境规划应注重保护旧址周边环境历史风貌及乡野特色。旧址前不宜大面积增设硬质铺地广场；停车场应尽可能靠近现有公路，远离旧址，并严格控制规模。

（六）展示利用规划应加强对旧址周边其他革命文物点进行系统梳理，明确其与豫鄂边区委员会旧址之间的历史关联，并将之纳入整体展示体系中。

（七）规范、完善图文表达。

二、请你厅指导地方人民政府组织规划编制单位，按照上述意见对规划进行必要修改和完善，经你厅核准后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将豫鄂边区委员会旧址保护规划报请湖北省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你厅指导和协调地方人民政府在保护规划的指导下，进一步做好豫鄂边区委员会旧址的各项保护、管理工作，妥善解决土地用途调整、环境整治等问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年1月3日

附件：鄂豫边区专家评审意见
