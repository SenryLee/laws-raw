# 中华人民共和国住房和城乡建设部公告2019年第277号——住房和城乡建设部关于2019年第十九批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第277号

## 住房和城乡建设部关于2019年第十九批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，汤斌峰等55名申请注册土木工程师（岩土）初始注册人员、王玉华等78名申请一级注册结构工程师初始注册人员、高飞等132名申请注册公用设备工程师初始注册人员、杨春宇等44名申请注册电气工程师初始注册人员、郜闯等9名申请注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予汤斌峰等55名注册土木工程师（岩土）初始注册人员名单

2.准予王玉华等78名一级注册结构工程师初始注册人员名单

3.准予高飞等132名注册公用设备工程师初始注册人员名单

4.准予杨春宇等44名注册电气工程师初始注册人员名单

5.准予郜闯等9名注册化工工程师初始注册人员名单

住房和城乡建设部

2019年10月29日
