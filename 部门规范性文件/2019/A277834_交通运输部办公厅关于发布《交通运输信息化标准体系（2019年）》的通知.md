# 交通运输部办公厅关于发布《交通运输信息化标准体系（2019年）》的通知

交办科技〔2019〕49号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），部管各社团，交通运输各专业标准化技术委员会，部属各单位，部内各司局：

经交通运输部同意，现将《交通运输信息化标准体系（2019年）》印发给你们。各单位要高度重视交通运输信息化标准制修订工作，及时反馈标准体系实施过程中的意见建议。

《交通运输部办公厅关于发布交通运输信息化标准体系表（2013年）的通知》（厅科技字〔2013〕111号）自本文件发布之日起废止。

交通运输部办公厅

2019年4月22日
