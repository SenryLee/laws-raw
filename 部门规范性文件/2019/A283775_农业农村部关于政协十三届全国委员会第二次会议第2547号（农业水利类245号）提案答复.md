# 农业农村部关于政协十三届全国委员会第二次会议第2547号（农业水利类245号）提案答复

## 关于政协十三届全国委员会第二次会议第2547号（农业水利类245号）提案答复

农办案〔2019〕70号

李武委员：

您提出的“关于加强蔬菜质量安全工作，增强人民群众幸福感安全感的提案”收悉。经我部认真研究，现答复如下。

一、关于加强蔬菜质量安全工作的领导

蔬菜作为“菜篮子”产品重要组成部分，与人民群众日常生活密切相关，其质量安全状况备受社会和公众关注。我部始终把确保包括蔬菜在内的“菜篮子”产品质量安全放在突出位置，采取有力措施夯实地方属地管理责任。一是以“菜篮子”产品大县为主要对象开展国家农产品质量安全县创建活动，提出“菜篮子”产品大县全覆盖的目标，其中落实地方政府属地管理责任、提升农产品质量安全水平等是重要考核内容。二是在将质量安全水平纳入国务院办公厅组织的“菜篮子”市长负责制考核内容，督促指导各地提高对蔬菜等“菜篮子”产品质量安全工作的重视，加大支持力度。

下一步，我部将严格按照《中共中央、国务院关于深化改革加强食品安全工作的意见》和中共中央办公厅、国务院办公厅印发的《地方党政领导干部食品安全责任制规定》要求，继续深入开展国家农产品质量安全县创建，落实好“菜篮子”市长负责制考核要求，不断加强对蔬菜等农产品质量安全工作的领导，确保农产品质量安全。

二、关于加强蔬菜抽查检测结果的应用

我部每年开展的例行监测均把蔬菜作为重要的监测品类，2019年上半年共监测31个省（区、市）和5个计划单列市，共235个大中城市的1027个蔬菜生产基地、828辆蔬菜运输车和2069个农产品批发（农贸）市场，抽检蔬菜9223个样品，抽检总体合格率为97.3%。从监测品种看，抽检的82种蔬菜中瓜类、甘蓝类、食用菌和根菜类蔬菜监测合格率较高。对于监测数据及结果，我部每年召开四次分析会商会，组织专家认真分析和总结蔬菜中农药残留的风险问题，包括不合格率较高的蔬菜种类、种植地域、风险的引入途径等，并将监测结果及风险情况通报各地，对监测发现的突出问题进行督办，要求地方农业农村主管部门有针对性地跟进开展监督抽查，依法查处不合格产品及其生产单位。同时，针对突出的风险隐患，组织专家开展有针对性的科技攻关，加强病虫害预测预报和科学用药指导，推广先进的病虫害防控模式。

下一步，我部将继续更加科学有效地组织实施农产品质量安全例行监测，进一步扩大监测范围，做好蔬菜农药残留监测结果的分析、会商、研判工作，以监测会商研判结果指导蔬菜安全生产。

三、关于加强蔬菜生产技术培训和技术服务

近年来，各级农业农村主管部门大力推进绿色防控和科学用药技术应用推广。一是开展技术培训。2015年以来，我部连续开展“百县万名新型农民科学用药培训行动”，以各类示范基地、农民专业合作社技术骨干为重点，开展农药识别、农药使用和绿色防控等技术培训。据统计，全国农业技术推广部门每年培训各类人员400多万人次。二是推进农药减量增效。2015年，我部组织实施《到2020年农药使用量零增长行动方案》，提出农药减量增效的思路目标、技术路径、总体任务和保障措施。各地制定具体实施方案，聚焦重点，加大力度，狠抓措施落实。重点是推行生态控制、理化诱控、生物防治等措施，控制病虫害发生。三是积极推进病虫害防控社会化服务。扶持培育植保社会化服务组织，大力推进病虫害统防统治，统防统治、统配统施面积不断扩大。2018年农作物病虫害统防统治覆盖率达到39.2%。

下一步，我部将继续加大农产品，特别是蔬菜质量安全生产技术培训和病虫害防控社会化服务，提高蔬菜生产的病虫害防控和安全用药能力水平。

四、关于加强蔬菜质量安全监管

蔬菜的质量安全既是产出来的，也是管出来的。我部在加大绿色防控和科学用药技术推广应用、推行绿色生产方式的同时，不断加大农产品质量安全监管力度。一是开展农药残留专项整治。近年来，农业农村主管部门持续开展农药残留专项整治行动，对农药市场和蔬菜生产基地进行重点检查，集中整治农药隐形添加、蔬菜生产使用禁用农药和非法混配农药等违法违规行为。二是探索农药使用记录制度。落实《农产品质量安全法》《农药管理条例》规定，要求农产品生产企业、专业化病虫害防治服务组织和从事农产品生产的农民专业合作社等建立农药使用记录，并定期检查。同时，加快高毒农药退出和农药残留标准制定，统筹推进农药残留管控。三是加强乡镇监管队伍建设。我部高度重视基层农产品质量安全监管体系建设，目前97%的涉农乡镇已经建立了农产品质量安全监管机构，落实监管人员11.7万人，积极推行农产品质量安全村级协管员制度，充分发挥他们贴近生产、了解情况、便于指导的优势，加强了农产品质量安全监管。

下一步，我部将继续加强基层农产品质量安全监管队伍建设，提升监管能力，加大对蔬菜等农产品的质量安全监管，全面推进村级协管员队伍建设，同时积极开展农产品质量安全专项整治，坚决杜绝蔬菜生产使用禁用农药和非法混配农药等违法违规行为，确保蔬菜质量安全。

感谢您对农产品质量安全工作的关心，希望今后继续对我部工作予以支持。

农业农村部

2019年8月30日
