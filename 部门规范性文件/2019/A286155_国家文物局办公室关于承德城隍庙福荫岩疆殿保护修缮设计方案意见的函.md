# 国家文物局办公室关于承德城隍庙福荫岩疆殿保护修缮设计方案意见的函

办保函〔2019〕1021号

河北省文物局：

你局《关于呈报承德城隍庙福荫岩疆殿保护修缮设计方案的请示》（冀文物字〔2019〕115号）收悉。经研究，我局暂不同意所报方案。

一、对方案提出以下修改意见：

（一）进一步勘察屋面部分残损情况。准确核查并分别统计檐椽、飞椽、望板等构件的病害情况、范围和残损比例；细化评估瓦面“脱釉”程度；补充大殿现状天沟材料的构造做法。补充能准确反映病害范围及程度的照片。

（二）校核完善修缮措施。严格控制工程量和工程范围，修缮工程做法、工程量应与调查残损情况相匹配；进一步明确屋面的翻修范围和天沟修复做法，不得更换未糟朽檐椽、飞椽、望板等构件；应考虑继续使用“脱釉”程度较轻且不影响防水的瓦件。

（三）补充细化所涉工程对原有彩画的保护措施；补充说明屋面卸瓦时对大木构架的防护要求。

（四）进一步完善、校核文本说明和图纸内容。建筑主要形制内容应描述绘制准确；文本与图纸残损部位情况的标注信息和修缮做法应一致；修改剖面图中天沟部位的图纸，并补绘天沟俯视图。

二、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改和完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年11月21日
