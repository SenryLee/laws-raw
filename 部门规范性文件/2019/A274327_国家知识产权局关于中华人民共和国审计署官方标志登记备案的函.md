# 国家知识产权局关于中华人民共和国审计署官方标志登记备案的函

## 关于中华人民共和国审计署官方标志登记备案的函

国知发保函字〔2019〕26号

审计署：

《审计署关于申请标示（徽标）登记备案的函》（审函〔2018〕121号）收悉。根据《中华人民共和国商标法》《中华人民共和国专利法》等有关规定，国家知识产权局予以登记备案（见附件），并纳入官方标志保护。

特此复函。

附件：审计署标示图案和说明

国家知识产权局

2019年2月13日
