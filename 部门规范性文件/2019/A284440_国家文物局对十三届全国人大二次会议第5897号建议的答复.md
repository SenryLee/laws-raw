# 国家文物局对十三届全国人大二次会议第5897号建议的答复

文物保函〔2019〕681号

阳海玲等3名代表：

您提出的“关于支持以紫鹊界梯田为代表的国家自然与文化双遗产可持续发展的建议”已交由自然资源部、农业农村部和我局分办。现将涉及文化遗产保护传承利用相关事宜答复如下。

紫鹊界古梯田位于湖南省娄底市新化县西南部雪峰山的东南麓奉家山系水车镇境内，核心连片梯田达1300多公顷。紫鹊界梯田具有适应当地独特的地质构造的自流灌溉系统，其所在村落传统民居保存较为完整而又集中连片的主要是楼下村和正龙村。我局指导湖南省开展了古梯田等活态特征突出的农业文化遗产调查、认定、登录和保护工作。2011年，湖南省人民政府将紫鹊界古梯田公布为湖南省第九批省级文物保护单位。

目前，古梯田保护普遍面临传统农业经济效益低下、劳动力匮乏导致梯田荒芜，生态环境恶化、植被和水资源枯竭导致水利设施和灌溉系统毁损等问题，在面对现代化的冲击和盲目的旅游开发方面也缺乏积极应对措施。近年来，我局结合世界遗产申报工作，指导云南省开展了红河哈尼梯田文化景观保护试点，在古梯田保护理念、管理机制、保护措施以及如何处理保护与可持续发展的关系等方面进行了探索。这些探索为紫鹊界古梯田保护提供了可资借鉴的宝贵经验。

下一步，我局将积极推动农业文化遗产保护利用，指导湖南省加强探索实践，创新古梯田保护发展理念，坚持“以人为本”的全面、可持续发展观，妥善保护古梯田物质形态与传统知识体系，保护并发展传统特色农业经济，提高当地居民的生活水平。同时，我局也将根据《国家文物保护专项资金管理办法》（财文〔2018〕178号）确定的专项资金“适当向革命老区、民族地区、边疆地区、贫困地区倾斜”的原则，对包括湖南省紫鹊界梯田在内的农业文化遗产文物保护单位所需维修保护、预防性保护、数字化保护、文物陈列展示、管理体系建设等专项工作予以大力支持。

感谢您对文物事业的关注和支持！

国家文物局

2019年7月11日
