# 国家文物局办公室关于组织开展2019年“文化和自然遗产日”活动的通知

办政函〔2019〕289号

各省、自治区、直辖市文物局（文化和旅游厅/委），新疆生产建设兵团文物局，各计划单列市文物局（文化和旅游局），国家文物局各直属单位：

今年是新中国成立70周年，6月8日恰逢我国文化和自然遗产日，为切实做好2019年文化和自然遗产日宣教活动，现就有关事项通知如下。

一、主题及口号

活动主题：保护革命文物 传承红色基因

宣传口号：1. 保护文物人人有责　传承文明美美与共

2. 弘扬革命精神　汇聚发展动力

3. 讲好文物故事 展现中国形象

4. 文物活起来　生活美起来

5. 确认过眼神　我是文物保护人

二、活动主旨

（一）集中宣传贯彻习近平总书记关于文物工作，尤其是关于革命文化传承的重要指示精神，宣传贯彻中办、国办《关于加强文物保护利用改革的若干意见》《关于实施革命文物保护利用工程（2018—2022年）的意见》，加强文物保护利用和文化遗产保护传承，促进革命文物保护利用，推进文物事业改革发展。

（二）结合中华人民共和国成立70周年，在文化和自然遗产日活动期间，通过举办系列展示宣教活动，充分展现文化遗产在坚定文化自信、传承中华文明方面起到的独特作用。

（三）以革命文物保护利用片区分县名单（第一批）为重点，依托革命文物资源开展相关活动，弘扬革命精神、传承红色基因、促进经济社会发展。

三、活动安排

（一）2019年文化和自然遗产日主场城市活动确定在陕西省延安市举办，由国家文物局、陕西省人民政府主办。期间，将举办主场城市活动开幕式、“新时代革命文物保护利用和革命文化传承”论坛、文化遗产公开课、第十一届全国青少年文化遗产知识大赛、“丹青记忆 守望家园”美术展等活动。

（二）倡导各地文物部门开展相关宣教惠民活动。各地文物部门，尤其是革命文物资源集中地区的文物部门应结合活动主题，因地制宜组织开展相关宣教活动。在确保文物和人员安全前提下，适当延长革命文物纪念地等在内的文物博物馆场所开放时间，策划举办主题宣传活动，提供免费或优惠门票及公益讲解等惠民服务。

（三）严格落实中央八项规定，注重实际、讲究实效，坚决杜绝铺张浪费。认真做好各项安全保障和服务工作，确保活动有序开展。

（四）国家文物局将通过门户网站、官方微博、微信和中国文物报等媒体，对各地开展的具有特色的文化和自然遗产日活动、革命文物主题宣传、文物惠民服务予以宣传和推介。

请各地于5月10日前提交2019年文化和自然遗产日活动计划（重点为革命文物主题宣传及文物惠民服务项目）。在活动开展期间，可同步上传有关图片和文字材料（文字不超过600字，图片像素不低于2M），国家文物局门户网站、微博、微信和中国文物报以及中央主要新闻单位将择优登载。

特此通知。
