# 国家文物局关于授予咸阳市文物考古研究所等3家单位考古发掘资质的通知

文物保函〔2019〕220号

各省、自治区、直辖市文物局（文化和旅游厅/局）：

根据《中华人民共和国文物保护法》、《考古发掘管理办法》的有关规定，经研究，我局决定授予咸阳市文物考古研究所、复旦大学、中央民族大学3家单位考古发掘资质。

特此通知。

国家文物局

2019年3月1日
