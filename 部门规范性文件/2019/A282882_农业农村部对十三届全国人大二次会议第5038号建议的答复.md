# 农业农村部对十三届全国人大二次会议第5038号建议的答复

## 对十三届全国人大二次会议第5038号建议的答复

周绍军代表：

您提出的关于加大对贵州省铜仁市乡村振兴战略财政支持力度的建议收悉。经商财政部，现答复如下。

一、关于建立乡村振兴多渠道资金筹集机制

中央一号文件明确提出，要坚持农业农村优先发展的总方针，建立完善农业支持保护制度，加快形成财政优先保障、金融重点倾斜、社会资本积极参与的农业农村多元化投入格局。近年来，各级财政不断加大对农业农村发展的投入力度， 2018年，全国一般公共预算农林水支出迈上2万亿元的新台阶，增幅达9.9%。2019年，全国一般公共预算农林水支出安排2.22万亿元，同比增长7%，继续保持较快增长。

在持续加大财政一般公共预算支持的同时，我部会同有关部门高度重视拓宽资金渠道，多方筹集资金支持乡村振兴。2018年，《国务院办公厅关于印发跨省域补充耕地国家统筹管理办法和城乡建设用地增减挂钩节余指标跨省域调剂管理办法的通知》（国办发〔2018〕16号）印发，建立了跨省域补充耕地国家统筹和城乡建设用地增减挂钩节余指标跨省域调剂机制，中央财政设立了相关专项，筹集资金支持脱贫攻坚和农村人居环境整治等工作。目前，我部正在配合中央农办、自然资源部、财政部等有关部门，按照中央提出的提高土地出让收入用于农业农村比例的要求，深入各地调研，研究细化改革措施，努力争取进一步盘活用好土地资源，实现土地增值收益“取之于农，主要用之于农”，加大对乡村振兴的支持力度。

二、关于创新财政涉农资金使用方式

我部高度重视充分发挥财政资金的撬动引导作用，鼓励创新投融资模式，探索通过政府与社会资本合作（PPP）等方式，引导和撬动金融社会资本加大农业投资。2017年5月，财政部和农业部联合印发《关于深入推进农业领域政府和社会资本合作的实施意见》（财金〔2017〕50号），明确将农业绿色发展、高标准农田建设、现代农业产业园、农产品物流与交易平台、互联网+现代农业等作为农业领域推广PPP的重点领域，提出要优化财政资金投入方式，探索农业领域推广PPP模式的实施路径、成熟模式和长效机制。截至2019年3月，全国PPP综合信息管理平台管理库中有72个农业PPP项目、投资额769亿元。

2019年中央一号文件明确要求，地方政府债券资金要安排一定比例支持发行乡村振兴专项债，用于农村人居环境、村庄基础设施建设等农业农村重点领域。我部高度重视推动地方发行乡村振兴专项债支持乡村振兴。2019年，全国人大批准地方政府专项债务限额2.15万亿元，比去年增加8000亿元。目前，四川、江西、山东、河北等地已经进行了成功探索。2018年8月，四川发行了全国首单“四川省泸县乡村振兴专项债券”5亿元，支持农村宅基地整治、农村基础设施建设等；2019年7月，江西发行了第一期乡村振兴专项债券29.41亿元支持高标准农田建设；山东、河北、辽宁、福建、新疆等省区也发行了乡村振兴专项债，市场反响良好。相关评估报告表明，此类项目的融资和收益能够实现自平衡，市场认购踊跃。下一步，我部将会同财政部等部门，深入总结推广各地实践经验，加快推动地方发行一批乡村振兴专项债，集中支持高标准农田建设、农村人居环境整治、村庄基础设施建设等重点领域。

三、关于进一步加大乡村人才振兴的支持力度

我部高度重视乡村人才振兴工作，采取多种方式积极支持培育新型农业经营主体。一是采取直接支持等多种方式，2019年安排贵州约9870万元，支持农民合作社、家庭农场、农业生产社会化服务组织等新型农业经营主体发展，并带动小农户与现代农业有效衔接。二是切实加强高素质农民培育，以农业职业经理人、现代青年农场主、农村实用人才带头人、新型农业经营主体骨干、农业产业扶贫对象作为重点培育对象，提升其生产技能和经营管理水平。2019年，安排贵州高素质农民培育资金8634万元，其中着力实施新型农业经营主体带头人轮训计划和现代青年农场主培养计划，开展农村实用人才带头人培训，培育“爱农业、懂技术、善经营”的高素质农民。同时，充分发挥全国农业信贷担保体系作用，着力解决新型农业经营主体在适度规模经营中的“融资难”“融资贵”问题。三是加强乡村基层组织运转经费保障和提升乡村财会管理水平，2018年9月，财政部印发了《财政部贯彻落实实施乡村振兴战略的意见》（财办〔2018〕34号），提出实施乡村基层组织运转经费保障计划和乡村财会管理“双基”提升计划，鼓励地方探索支持提升乡村自治组织、集体经济组织、合作组织的财务会计管理水平和开展各类基本经济活动的规范管理能力。

贵州铜仁市是我部重点支持的脱贫攻坚地区，我部将按照党中央、国务院脱贫攻坚战略部署，会同财政部等相关部门进一步加大对贵州省的支持力度，进一步完善相关政策措施，加强对贵州省铜仁市乡村振兴战略支持。

感谢您对农业农村经济工作的关心，希望继续对我部工作给予支持。

农业农村部

2019年9月19日
