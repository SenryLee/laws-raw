# 交通运输部办公厅、中华全国总工会办公厅关于公布“司机之家”建设试点项目名单的通知

## 交通运输部办公厅　中华全国总工会办公厅关于公布“司机之家”建设试点项目名单的通知

交办运函〔2019〕1105号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）、总工会：

为切实改善货车司机的工作休息环境，2018年交通运输部、中华全国总工会在全国10个省份启动了“司机之家”建设试点工作，在高速公路服务区、普通国省干线公路服务站（点）、骨干物流通道货物集散地、物流园区等地试点建设“司机之家”。在各方面的共同努力下，目前，各省份试点“司机之家”已陆续建成。按照《交通运输部办公厅 中华全国总工会办公厅关于进一步做好“司机之家”建设和验收工作的通知》（交办运函〔2019〕552号）的部署安排，各试点省份交通运输主管部门、工会组织联合对“司机之家”建设试点项目进行验收，并已向社会公示，确定河北省邢台好望角物流园区“司机之家”等76个试点项目符合“司机之家”建设要求，经交通运输部、中华全国总工会同意，现予以公布。

附件：“司机之家”建设试点项目名单
