# 国家邮政局办公室关于印发《国家邮政局2019年政务公开工作要点》的通知

国邮办函 〔2019〕146号

各省、自治区、直辖市邮政管理局，国家局直属各单位、机关各司室：

2018年，全国邮政管理系统紧紧围绕党中央国务院重大决策部署、人民群众关注关切和国家邮政局重点工作，按照国家邮政局2018年政府信息公开工作要点，持续加大政务公开工作力度，以公开促落实，以公开促规范，以公开促服务，在助力邮政管理工作中发挥了积极作用。但与社会公众日益增长的邮政管理信息公开需求相比，在主动公开广度深度、政策解读回应效果、政务服务质量水平、政务公开制度化规范化等方面还存在一些差距。为促进政务公开工作补短板、强弱项，不断提升政务公开的质量和实效，按照国务院办公厅2019年政务公开要点要求，结合邮政管理工作实际，现印发《国家邮政局2019年政务公开工作要点》，请认真贯彻落实。

国家邮政局办公室

2019年4月17日
