# 国家移民管理局关于对十三届全国委员会第二次会议第1346号（社会管理类125号）提案答复的函

李友祥委员：

您提出的《关于解决缅籍婚嫁妇女国籍及户口问题的提案》收悉，现答复如下：

我国是统一的多民族国家，在与有关国家陆地毗邻的9个省区中，有30多个民族与周边国家同一民族毗邻而居。我国边民与毗邻国家边境地区居民间通婚现象长期存在，在西南边境地区则更数量尤多，部分毗邻国家女性非法入境后与我国公民通婚并生育子女，这些人员因无合法身份，从而衍生出一系列问题。为解决这些跨国婚姻移民问题，2012年10月1日，民政部颁布实施《中国边民与毗邻国家边民婚姻登记办法》，为持合法证件通婚外籍边民的婚姻登记提供便捷的服务；对无合法身份证件的通婚外籍人员，公安机关从人道主义和家庭团聚原则出发，不采取强制遣返措施，并纳入当地实有人口进行登记管理。

为研究解决我国边境地区婚姻类非法移民合法身份问题，近年来，国家移民管理局和地方公安机关出入境管理部门开展了一系列工作：一是加强与毗邻国家相关部门的双边合作，敦促其核查确认有关人员真实身份，协助办理身份证件。二是加强法律宣传，引导跨国通婚外籍人员自行向国籍国驻华机构申请补办身份证件。目前，已有4000多名毗邻国家妇女通过补办护照实现在华合法停居留。三是会同民政部、卫生健康委等相关部门在全国部署开展了滞留境内外籍妇女专项排查，并根据排查调研情况，研究提出了解决此类人员婚姻、停居留问题的意见。四是对身份难以核实的外籍人员，国家移民管理局正在研究相关办法将此类人员纳入管理。

下一步，国家移民管理局将积极会同有关部门，进一步加强对边境地区双方边民跨国通婚和外籍人员合法停留问题的调查研究，加强双边合作，重点推进解决边境地区跨国通婚外籍人员面临的身份认定和合法停居留问题，保障其本人及其家庭的合法权益，维护我国边境地区的安全稳定和发展利益。

感谢您对移民管理工作的关心和支持。

国家移民管理局

2019年6月30日
