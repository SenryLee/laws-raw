# 教育部办公厅关于开展2019年“一师一优课、一课一名师”活动的通知

教基厅函〔2019〕12号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

为深入贯彻全国教育大会精神，扎实推进基础教育信息化应用，按照教育部2019年工作安排，决定继续组织开展“一师一优课、一课一名师”活动。

请你们在认真总结前期工作经验的基础上，精心策划、周密部署、加强指导，将活动作为推进信息技术与教育教学深度融合、扩大优质教育资源覆盖面、深化基础教育教学改革的重要抓手，切实做好活动的各项组织实施工作。

附件：2019年“一师一优课、一课一名师”活动方案

教育部办公厅

2019年2月28日
