# 中国气象局综合观测司关于印发《天气现象视频智能观测仪技术要求》（试行）的通知

## 观测司关于印发《天气现象视频智能观测仪技术要求》（试行）的通知

气测函〔2019〕49号

各省（区、市）气象局，相关企业：

天气现象视频智能观测仪是一种应用计算机视觉和深度学习技术，对视频采集器拍摄的天气现象（或气象要素）实现自动观测识别的仪器设备。为更好地规范该类装备的研发生产，我司组织编制了《天气现象视频智能观测仪技术要求》（试行）（见附件），现予以印发。

附件： 天气现象视频智能观测仪技术要求（试行）
