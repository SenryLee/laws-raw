# 中共教育部党组关于查显友、郑晓静同志职务任免的通知

教党任〔2019〕36号

中共西安电子科技大学委员会：

经与中共陕西省委商得一致，2019年2月1日研究决定：

查显友同志任中共西安电子科技大学委员会委员、常委、书记；免去郑晓静同志的中共西安电子科技大学委员会书记、常委、委员职务。

中共教育部党组

2019年2月15日
