# 农业农村部对十三届全国人大二次会议第3753号建议的答复

## 对十三届全国人大二次会议第3753号建议的答复

农办议〔2019〕382号

左香云代表：

您提出的关于实施乡村振兴战略的建议收悉。经商发展改革委、财政部、自然资源部，现答复如下。

一、关于将项目和资金整合，全力推进乡村振兴战略

中共中央、国务院印发实施的《乡村振兴战略规划（2018-2022年）》（以下简称《规划》）提出分类推进乡村振兴，并根据不同村庄的发展现状、区位条件、资源禀赋等，将现有村庄大致分为聚集提升、城郊融合、特色保护、搬迁撤并4类，明确了振兴重点和路径。《规划》还提出充分发挥规划的引领作用，推进行业内资金整合与行业间资金统筹相互衔接配合，加快建立涉农资金统筹整合长效机制，健全乡村振兴多元投入保障制度。财政部认真贯彻党中央、国务院决策部署，会同有关部门积极推进涉农资金统筹整合。2017年，国务院印发了《关于探索建立涉农资金统筹整合长效机制的意见》（以下简称《意见》），提出了加强行业内涉农资金整合与行业间涉农资金统筹衔接配合的改革思路。《意见》要求进一步下放审批权限，赋予地方必要的涉农资金资助统筹权，支持各地紧紧围绕实施乡村振兴战略，在预算编制环节加强涉农资金源头整合，在预算执行环节加强性质相同、用途相近的涉农资金统筹使用，促进功能互补、用途衔接的涉农资金集中投入，为支持乡村振兴提供有力支撑。各地可按照《规划》和《意见》的要求，因地制宜明确重点支持的村庄，实施涉农资金统筹整合，加大项目投入力度，支持当地乡村建设和产业发展，有序推进乡村振兴。

二、关于灵活使用农村土地，发展乡村旅游

为促进乡村振兴战略实施，根据中共中央、国务院有关文件精神，自然资源部办公厅近日出台了《关于加强村庄规划促进乡村振兴的通知》（自然资办〔2019〕35号）明确，统筹产业发展空间，合理保障农村新产业新业态发展用地，并提出两项支持政策：一是允许村庄规划在不改变县级国土空间规划主要控制指标情况下，优化调整村庄各类用地布局。涉及永久基本农田和生态红线调整的，严格按国家有关规定执行，调整结果依法落实到村庄规划中。二是各地可在乡镇国土空间规划和村庄规划中预留不超过5%的建设用地机动指标，村民居住、农村公共公益设施、零星分散的乡村文旅设施及农村新产业新业态等用地可申请使用。对一时难以明确具体用途的建设用地，可暂不明确规划用地性质。建设项目规划审批时落地机动指标、明确规划用地性质，项目批准后更新数据库。机动指标使用不得占用永久基本农田和生态保护红线。

下一步，各部门将贯彻落实中共中央、国务院的要求，在政策制定、投资安排、项目审批、用地保障等方面加大支持力度，推动实施乡村振兴战略。
