# 国家文物局关于皖南古村落—西递宏村建设控制地带内G530焦村至东亭公路建设项目的意见

文物保函〔2019〕276号

安徽省文物局：

你局《关于世界文化遗产地西递村古建筑群缓冲区实施G530焦村至东亭公路建设工程的请示》（皖文物保〔2019〕3号）经研究，我局原则同意在西递村古建筑群建设控制地带内实施G530焦村至东亭公路建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步强化道路景观设计，对护坡挡墙表面进行绿化和生态处理，尽可能恢复原有自然风貌；在道路两侧种植高大乔木进行遮蔽，以降低该项目对西递村古建筑群环境景观的负面影响。

（二）进一步完善施工方案和施工组织设计，强化施工管理措施，做好施工围挡，制定文物保护应急预案，切实防范施工产生的粉尘、噪声、化工废弃物等污染对西递宏村的遗产环境，同时避免施工活动对周围山林植被等自然环境造成破坏。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月19日
