# 国家邮政局关于政协十三届全国委员会第二次会议第1412号（工交邮电类081号）提案答复的函

## 关于政协十三届全国委员会第二次会议第1412号（工交邮电类081号）提案答复的函

国邮函〔2019〕96号

马旭林委员：

您提出的“关于推动先进制造业和快递业深度融合的提案”（第1412号）收悉。经商工业和信息化部，现答复如下：

您在提案中提到的山东邮政速递物流济南市第二分公司（海重事业部）服务重汽济南卡车股份有限公司项目为快递业拓展产业链提供了很好的范例参考，所提推动先进制造业和快递业深度融合的建议具有较强的参考意义。

国家邮政局高度重视先进制造业与快递业融合发展。近年来，我们开展了一系列工作。一是强化制度设计。2013年，会同工业和信息化部出台《关于推进快递服务制造业工作的指导意见》。2015年，推动国务院出台《关于促进快递业发展的若干意见》，提出“发挥供应链管理优势，积极融入智能制造、个性化定制等制造业新领域”。二是加强沟通协调。通过与工业和信息化部直接联系，参加相关部际联席会议等形式，探讨政策、资金支持，积极参与制造业供应链标准的制定。三是加强市场引导。通过专题研究，总结形成入厂物流、“仓储+配送”一体化、“订单末端”配送、“区域性供应链”服务、“嵌入式电子商务”快递等5种主要服务模式。开展主要快递企业培训，传播快递服务制造业的主要模式、典型经验和先进案例。建立全国快递服务制造业项目库，定期更新，跟踪快递服务制造业推进情况。截至2018年底，全国共形成快递服务先进制造业重点项目318个，直接服务制造业年产值达到2172亿元。

工业和信息化部高度重视包括快递业在内的现代服务业与先进制造业深度融合，通过推动服务型制造发展，引导制造业企业开展供应链管理，提高供应链服务实体经济的能力。一是制定政策文件。2016年，与国家发展改革委、中国工程院联合印发《发展服务型制造专项行动指南》，在“制造效能提升行动”中提出“优化供应链管理”。二是开展示范遴选。2017年和2018年，开展了两批服务型制造示范遴选工作。通过推广优秀案例和发展经验，带动制造业企业提升供应链管理水平。三是加强培训指导。组织开展“服务型制造万里行”活动，指导召开服务型制造大会，并组织企业赴德国培训学习先进经验。

下一步，国家邮政局将在前期工作的基础上，继续与工业和信息化部加强协作，加强对快递业企业拓展服务领域的政府指导，努力争取有关政策支持，积极推动先进制造业和快递业更深度融合。工业和信息化部将总结《发展服务型制造专项行动指南》实施情况，评估工作成果，提出推动先进制造业和现代服务业融合发展的新举措，并拟于今年制定发布新一轮推动服务型制造的政策文件。同时，继续开展“服务型制造万里行”活动，指导召开服务型制造大会，开展服务型制造示范遴选，深入挖掘典型案例和转型经验，持续提高社会认知水平。

感谢您对快递业发展的关心和支持！

国家邮政局

2019年7月22日
