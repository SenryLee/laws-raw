# 文化和旅游部办公厅关于开展2019年“时代交响——中国交响音乐作品创作扶持计划”作品申报工作的通知

办艺发〔2019〕68号

各省、自治区、直辖市文化和旅游厅（局），新疆生产建设兵团文化体育广电和旅游局，广电总局办公厅，中央军委政治工作部宣传局，中国歌剧舞剧院、中国东方演艺集团有限公司、中国交响乐团、中央歌剧院、中央芭蕾舞团、中央民族乐团、中国煤矿文工团：

为推动优秀音乐作品和人才不断涌现，促进音乐事业繁荣发展，文化和旅游部于2018年开始实施“时代交响——中国交响音乐作品创作扶持计划”。2019年，文化和旅游部将围绕庆祝中华人民共和国成立70周年和2020年全面建成小康社会、2021年庆祝中国共产党成立100周年等重要时间节点，继续遴选和扶持一批重点交响乐、民族管弦乐作品。现将有关事项通知如下：

一、指导思想

以习近平新时代中国特色社会主义思想为指导，贯彻落实党的十九大和十九届二中、三中全会精神，坚持“二为”方向和“双百”方针，创造性转化、创新性发展。坚定文化自信，坚持与时代同步伐，以人民为中心，以精品奉献人民，用明德引领风尚。坚守中华文化立场，不忘本来，吸收外来，面向未来。不断推出思想精深、艺术精湛、制作精良，为人民群众喜闻乐听的优秀交响乐、民族管弦乐作品。

二、申报范围

2018年9月1日至2019年12月31日期间创作演出的交响乐、民族管弦乐作品均可申报。体裁包括交响曲、管弦乐组曲和套曲、协奏曲、交响诗、交响音画以及适合管弦乐队演奏的中、小型作品等。

三、作品要求

（一）围绕庆祝中华人民共和国成立70周年和2020年全面建成小康社会、2021年庆祝中国共产党成立100周年等重要时间节点开展创作，坚持以人民为中心的创作导向，反映时代精神和现实生活，弘扬社会主义核心价值观。

（二）注重汲取中华优秀传统文化尤其是民族音乐文化的宝贵养料，努力进行创造性转化、创新性发展。

（三）思想性与艺术性相统一，旋律性、可听性与专业性并重，满足人民群众多样化、多层次的审美需求。

四、扶持方式

（一）文化和旅游部将组织专家对申报作品进行遴选。入选作品将被列为2019年“时代交响——中国交响音乐作品创作扶持计划”扶持作品。

（二）文化和旅游部将给予扶持作品一定的资金支持，并组织专家对扶持作品进行跟踪指导，帮助其提升艺术质量。

（三）文化和旅游部将组织专家，从扶持作品中遴选出“时代交响——中国交响音乐作品创作扶持计划”重点扶持作品，组织举办专场音乐会并进行宣传推广，配套出版总谱及音像制品等。

五、申报要求

（一）各省（区、市）文化和旅游厅（局）、新疆生产建设兵团文化体育广电和旅游局、中央军委政治工作部宣传局统一组织开展申报工作。文化和旅游部直属艺术院团、中央和国家机关有关部委所属艺术院团，专业音乐院校，香港、澳门特别行政区以及台湾地区的音乐艺术团体和个人可直接申报。申报作品数量不限。

（二）请于2019年5月24日前将以下材料寄至文化和旅游部艺术司，逾期不予接收，申报材料不予退还。

1.2019年“时代交响——中国交响音乐作品创作扶持计划”作品申报表1份。

2.已有作品总谱的，报送总谱2份，要求谱面清晰，标明速度、时间长度，谱面不得出现作者姓名；已有作品录音的，同时报送录音1份，存储在U盘里。正在创作中，还没有总谱和录音的，须报送作品详细报告1份，含作品主题、架构、艺术特点等。

3.作者近期2寸彩色免冠照片1张。

4.作者身份证（居住证）、军官证或学生证等有效身份证件复印件1份。

5.申报表、作品总谱（PDF格式）、作者照片及作品报告须同时报送电子版，与录音一并存储在U盘中报送。

六、其他事项

（一）文化和旅游部有权组织开展“时代交响——中国交响音乐作品创作扶持计划”扶持作品，特别是重点扶持作品的演出、推广和乐谱出版、音像录制工作。

（二）有版权方面争议的作品不得申报。
