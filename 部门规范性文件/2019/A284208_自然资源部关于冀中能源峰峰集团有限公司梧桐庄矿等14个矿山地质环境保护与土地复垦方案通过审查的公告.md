# 自然资源部关于冀中能源峰峰集团有限公司梧桐庄矿等14个矿山地质环境保护与土地复垦方案通过审查的公告

根据《土地复垦条例》《矿山地质环境保护规定》等有关规定，冀中能源峰峰集团有限公司梧桐庄矿等14个矿山地质环境保护与土地复垦方案通过审查，现予公告。

自然资源部

2019年11月25日

附件：

14个通过审查的矿山地质环境保护与土地复垦方案名单
