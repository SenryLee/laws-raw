# 中共自然资源部党组关于刘国洪等8名同志职务任免的通知

自然资党任〔2019〕43号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中央军委后勤保障部军事设施建设局，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

部党组2019年1月25日研究决定：

刘国洪任国土空间规划局局长，免去其耕地保护监督司司长职务；

王瑞幺（援疆）任国土测绘司副司长（试用期一年）；

夏俊任自然资源部宣传教育中心主任（试用期一年）、党委副书记，免去其办公厅副主任职务；

孙习稳（援青）任自然资源部人力资源开发中心副主任（正局级）；

薄志平任自然资源部矿产资源储量评审中心主任（试用期一年），免去其矿业权管理司副司长职务；

徐志军（援藏）任中国自然资源报社党委书记、副社长；

姚义川任中国地质博物馆馆长（试用期一年）、党委书记，免去其法规司副司长职务。

免去庄少勤国土空间规划局局长职务。

中共自然资源部党组

2019年2月15日
