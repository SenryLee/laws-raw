# 国家发展改革委办公厅关于同意延长山东省利津县城市投资发展建设有限公司等三家公司债券核准文件有效期的函

发改办财金〔2019〕391号

山东省、宁夏回族自治区、青岛市发展改革委：

报来《关于延长利津县城市投资发展建设有限公司债券核准文件有效期的请示》（鲁发改财金〔2019〕208号）、《关于贺兰县融晟投资运营有限公司发行企业债券延期的请示》（宁发改经财〔2019〕159号）、《关于转报<青岛地铁集团有限公司关于延长绿色可续期公司债券核准批复有效期的请示>的请示》（青发改服务〔2019〕38号）收悉。经研究，现函复如下。

一、同意将《国家发展改革委关于山东省利津县城市投资发展建设有限公司发行公司债券核准的批复》（发改企业债券〔2018〕48号）文件有效期延长12个月至2020年4月9日。

同意将《国家发展改革委关于宁夏回族自治区贺兰县融晟投资运营有限公司发行公司债券核准的批复》（发改企业债券〔2018〕55号）文件有效期延长12个月至2020年4月18日。

同意将《国家发展改革委关于青岛地铁集团有限公司发行绿色债券核准的批复》（发改企业债券〔2018〕45号）文件有效期延长12个月至2020年4月2日。

二、请你委督促发行人按照《公司法》《证券法》《企业债券管理条例》和有关规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

三、请你委督促发行人按要求及时做好信息披露及债券资金管理，按照核准的募集资金投向合规使用债券资金，认真落实偿债保障措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅

2019年3月27日
