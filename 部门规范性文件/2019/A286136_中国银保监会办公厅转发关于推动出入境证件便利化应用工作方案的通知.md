# 中国银保监会办公厅转发关于推动出入境证件便利化应用工作方案的通知

银保监办发〔2019〕150号

现将国家移民管理局等十六个部门联合印发的《关于印发<关于推动出入境证件便利化应用的工作方案>的通知》（国移民发〔2019〕16号）转发给你们，请结合本单位实际，认真贯彻落实。如遇重大问题，请及时报告银保监会。

特此通知。

中国银保监会办公厅

2019年7月1日
