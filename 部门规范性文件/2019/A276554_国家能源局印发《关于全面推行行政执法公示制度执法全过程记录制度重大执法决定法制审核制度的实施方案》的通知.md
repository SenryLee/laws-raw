# 国家能源局印发《关于全面推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度的实施方案》的通知

国能发法改〔2019〕34号

各司，各派出能源监管机构，各直属事业单位：

为贯彻《国务院办公厅关于全面推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度的指导意见》（国办发〔2018〕118号），我局制定了《关于全面推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度的实施方案》及任务分工表，现印发你们，请遵照执行。

国家能源局

2019年4月8日
