# 农业农村部对十三届全国人大二次会议第8362号建议的答复

## 对十三届全国人大二次会议第8362号建议的答复

您提出的关于加大扶持西部民族地区农业科技人才队伍建设的建议收悉。经商财政部、科技部，现答复如下。

近年来，国家高度重视西部地区科技人才队伍建设，各部门紧紧围绕自身职责，不断加大对西部地区，尤其是民族地区支持力度，在政策、资金、项目方面予以倾斜，积极营造引导广大科技人才到西部地区尤其是民族地区流动的良好氛围。

一、关于加强农业科技人才的培养

（一）关于增加高层次人才培养数量。近年来，国家加大了对西部地区科技人才尤其是农业科技人才的培养力度。一是加强高层次人才培养。在各部门实施的人才培养计划中，注重选拔西部地区科技人才。例如，创新人才推进计划暨国家"万人计划"科技创新领军人才和科技创业领军人才选拔推荐工作中，每年分配给西部十二省（区）名额占比将近三分之一，并且从2018年起，对西部欠发达地区作出突出贡献的科技创新人才和团队给予特殊支持，申报人年龄放宽2年。农业农村部牵头的农业科研杰出人才培养计划中，也注重向人才薄弱的西部地区倾斜，各学科保证其有人才入选。二是依托产业培育农业科技人才。2018年，农业农村部现代农业产业技术体系在西部地区高校科研院所共聘任首席科学家5位，岗位科学家247位，综合试验站站长460位，涉及水稻、玉米、马铃薯、大宗蔬菜、生猪、大宗淡水鱼等40个主要农产品，中央财政投入4.04亿元。体系专家围绕西部各省份种养殖业特色和需求，开展全产业链技术研发和技术示范应用等工作，为当地相关产业发展提供了科技支撑。三是培养西部科研院所管理人才。为加强科研院所创新能力建设，培养具有现代管理素质的高层次科研院所管理人才，2001年起，科技部每年会同中组部、国资委举办科研院所领导者高级研修班。近三年，加大了对西部农林科研院所负责人培训力度，对提高西部农林科研院所负责人管理水平和创新能力发挥了重要作用。

（二）关于提升农业专业技术人才队伍整体素质。近年来，各部门依托人才项目，不断加大对西部地区科技人才培养、帮扶力度。一是加大科技人才"派出去"力度。2004年以来，中央组织部牵头实施"西部之光"访问学者培养计划，每年选派200名西部地区中青年科研骨干到中央国家机关所属高等院校和科研院所进行为期一年的研修，不仅提高了他们的知识水平，同时也搭建了与东部地区互相交流的平台。二是加大科技人才培训力度。为进一步提高西部地区农技人员业务水平，农业农村部大力开展农技人员培训工作。在业务能力提升方面，完善农技人员分级分类培训机制，采取异地研修、集中办班、现场实训、网络培训等方式，提升基层农技推广队伍知识技能。在学历层次提升方面，继续支持基层农技推广队伍中非专业人员、低学历人员等，通过脱产进修、在职研修等方式进行学历提升教育，补齐专业知识短板。三是大力选派农业科技人才投身西部建设。由中央组织部、共青团中央联合开展的"博士服务团"选派工作，每年从中央有关单位和东部有关省市选派优秀人才到西部等地区服务锻炼。党的十八大以来，累计选派1353名博士服务团成员赴西部服务锻炼，其中，农业农村部共选派74人。科技部通过实施"三区"人才支持计划科技人员专项计划，加大西部民族地区科技人才队伍建设支持力度。一方面按"一县一团""一业一团"组团方式，向"三区三州"214个县选派科技特派团，为"三区三州"提供公益专业技术服务，带动农民创新创业，培养本土科技人才。另一方面鼓励东部发达地区通过人才培养协作、对接科技成果和建立科技精准帮扶结对，对口帮扶深度贫困地区，为深度贫困地区注入优质创新资源。截至目前，累计向西部贫困地区选派科技人员64624名，培养本土科技人员11715名，其中支持贵州省累计选派科技人员7587名，培养本土科技人员1068名。

下一步，各有关部门将围绕实施乡村振兴战略的新任务和农业高质量发展的新要求，进一步加大对西部地区科技人员培养支持力度，不断提升农业科技创新能力，促进西部地区经济社会发展。

二、关于从政策上对西部农业科技人才给予适当倾斜

为支持艰苦边远地区和基层加快发展，2019年1月，中办印发《关于鼓励引导人才向艰苦边远地区和基层一线流动的意见》，提出完善编制管理、职称评审、人才招录和柔性流动等各项人才管理政策，畅通人才向艰苦边远地区和基层一线流动渠道。关于您提出的几方面政策建议，有关情况说明如下。一是在人员编制上向西部欠发达地区的省、市级农业科研部门倾斜。《中共中央关于深化党和国家机构改革的决定》规定，赋予省级及以下机构更多自主权，除中央有明确规定外，允许地方因地制宜设置机构和配置职能。国务院令第486号《地方各级人民政府机构设置和编制管理条例》第四条规定，地方各级人民政府的机构编制工作，实行中央统一领导、地方分级管理的体制。编制的调整，可由地方政府按照规定，结合经济社会全面协调可持续发展的需要，在现有机构编制总量内统筹研究。二是适当放宽职称评聘和高端人才评选条件等。农业农村部、人力资源社会保障部目前正在研究出台《关于深化农业技术人员职称制度改革的指导意见》。该文件拟明确，适当增加艰苦边远地区和基层一线农业农村领域高级专业技术岗位，为农业技术人员参评高级职称创造条件。对长期扎根基层一线、作出突出贡献的农业技术人员，可适当放宽学历和任职年限要求。在艰苦边远地区和基层一线可采取"定向评价、定向使用"的方式，吸引和稳定优秀农业技术人员扎根基层、建功立业。三是对有特殊贡献的农业专业技术人员，应给予重奖激励。一方面，在收益分配上，对作出突出成绩的工作人员进行倾斜。2016年11月，中办、国办印发《关于实行以增加知识价值为导向分配政策的若干意见》明确，通过稳定提高基本工资、加大绩效工资分配激励力度、落实科技成果转化奖励等激励措施，使科研人员收入与岗位职责、工作业绩、实际贡献紧密联系。对从事基础性研究、农业和社会公益研究等研发周期较长的人员，加大对重大科技创新成果的绩效奖励力度，使科研人才能够潜心研究。另一方面，在表彰资助上，注重营造关心"三农"、重视人才的氛围。例如，农业农村部开展中华农业英才奖、神农中华农业科技奖、全国农牧渔业丰收奖等评选表彰，实施全国十佳农技推广标兵、杰出青年农业科学家等资助遴选，汪洋、胡春华等中央领导同志多次接见获奖代表，树立了全社会尊重人才、崇尚创新的导向，为促进农业科技人才成长营造了良好氛围。

下一步，我们将继续完善相关政策，推动《关于深化农业技术人员职称制度改革的指导意见》尽快出台，同时进一步加大对西部地区优秀农业农村科技人才选拔支持力度，积极发现和选树人才典型，激励带动广大农业农村科技人才见贤思齐、奋发有为。

三、关于从资金和项目上加大西部农业科技人才投入力度

中央财政历来高度重视并积极支持包括西部地区在内的农业领域的科研工作，通过中央财政科技计划（专项、基金）、基本运行经费、基本科研业务费、国家重点实验室专项经费等，加大对西部地区的支持力度。例如，国家重点研发计划自2016年组织实施以来，贵州等西部地区积极承担科研任务。目前，由西部地区牵头承担的重点研发计划417项，涉及农业、资源、环境等多个领域的56个重点专项，国拨经费69.4亿元。其中，农业科研院所等相关单位牵头承担农业领域项目29项、课题293个，获得中央财政经费支持分别为6.6亿元和12.65亿元。农业农村部依托有关农业科研单位、高校、科技型企业等在西部地区12省（市、自治区）布局建有农业农村部重点实验室（站）157家，占总数的24.3%,涉及32个学科领域。其中，综合性重点实验室4家，专业性/区域性重点实验室58家，科学观测实验站95家。截至目前，已累计投入中央财政经费5.1亿元，有力提升了西部地区农业科研装备条件和科技创新能力。

关于您提到的设立基金的问题。目前，各级财政部门已经在相关领域设立了较多数量的产业引导基金，其中，国家层面已设立中国农业产业发展基金、贫困地区产业发展基金、中国农垦产业发展基金等，为包括西部地区在内的农业领域发展提供了资金支持。同时，积极实施国家科技成果转化引导基金，综合运用设立创业投资子基金等方式，吸引社会资金、金融资本进入创新领域，支持相关领域的科技成果转移转化。

下一步，我们将继续加大对西部科研院所和科研活动的支持力度，统筹用好现有资金、基金、政策，支持西部地区农业科技创新和农业农村科技人才队伍建设。

感谢您对"三农"工作的关心，希望今后继续对我部工作予以支持。
