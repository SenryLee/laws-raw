# 国家知识产权局关于政协十三届全国委员会第二次会议第2912号（商贸旅游类106号）提案答复的函

国知发保函字〔2019〕150号

高燕委员：

您与徐念沙、宁高宁委员联名提出的关于充分发挥贸促机构作用，加快推进贸易强国建设的提案收悉，我局结合工作职能，现就提案中知识产权相关内容答复如下：

随着全球经济一体化不断深入，国际贸易摩擦与争端愈加繁杂，关键核心技术的重要性深刻凸显，知识产权已成为国家重要的战略资源和国际间抢占科技战略制高点的必争之地。当前，受制度不清楚、程序不了解、信息不畅通、语言不方便、专业服务机构不熟悉等因素影响，我国企业知识产权全球化布局程度低、核心专利数量少，海外维权成本高、难度大，企业“走出去”形势严峻，面临着亟待突破的知识产权保护壁垒。为有针对性地解决这些问题，目前我局已开展以下几方面工作。

一、建设完善海外知识产权信息服务平台

自2015年起，建设海外知识产权信息平台（“智南针”）并推出微信公众号服务，向社会公众提供主要贸易国家和地区的知识产权法律法规、制度环境、实务指引、服务机构等基础信息。目前汇集189个国家或地区1400余部知识产权法律法规，20多个重点国家知识知识产权环境概览，近30本知识产权实务指引等信息，提供350多家海外知识产权服务机构和40余位专家名录。截至2018年底，累计1万家企业注册海外知识产权信息平台，累计访问量超过1341万次，为企业拓展海外业务提供了有效的信息支持。

二、不断加强海外知识产权维权援助机制

成立国家海外知识产权纠纷应对指导中心，不断完善海外知识产权纠纷反馈渠道，指导企业应对涉外纠纷。通过建设海外知识产权纠纷专家库和公益律师团队等帮助企业提高海外知识产权纠纷的解决效率和质量；通过建设海外知识产权纠纷数据库和数据分析机制等向“走出去”企业提供知识产权纠纷防控和风险预警。

三、提升企业知识产权海外纠纷应对能力

支持企业进行知识产权海外布局，发布美国、日本、巴西、印度、西班牙、加拿大等多国专利申请实务指引，支持行业协会和专业机构研究发布重点产业知识产权信息和竞争动态，举办相关培训活动，着力提升知识产权服务机构专业水平。

四、积极拓展知识产权纠纷多元化解决渠道

自2014年起，启动知识产权纠纷调解工作，充分发挥各类仲裁机构、调解组织、行业协会等在解决知识产权纠纷中的重要作用，为权利人提供更多替代性争议解决途径和维权选择。目前，已先后在全国16个省（区、市）部署开展试点，共培育85家知识产权纠纷调解组织、11家知识产权仲裁机构，成功调解案件7600余件，受理仲裁案件680余件。工作中，注重发挥仲裁调解高效、便捷、低成本且无地域管辖限制的优势，对国内外权利人及市场主体提供一视同仁的高效保护。

五、下一步工作安排

我局将继续加大对“走出去”企业知识产权服务和支撑力度。一是完善海外知识产权信息平台，更新并扩充海外信息范围，持续为中国企业“走出去”提供信息服务支撑。二是加强海外纠纷风险防控，通过宣传、培训、研讨交流等活动，切实提升企业海外布局、纠纷应对、主动维权的意识和能力。三是依托国家海外知识产权纠纷应对指导中心组建专家队伍和公益律师团队，切实指导企业开展国际知识产权维权，应对海外知识产权诉讼。期间，注重充分发挥贸易促进机构的作用，善用其亦官亦民的特点和优势。四是持续拓展知识产权纠纷多元化解决渠道，继续加强快速协同保护工作。

衷心感谢您对知识产权工作的关心，希望继续关注知识产权事业发展，对我们的工作提出宝贵的意见建议。

国家知识产权局

2019年8月14日
