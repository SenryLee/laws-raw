# 国家文物局关于明故宫遗址建设控制地带内南京中航科技城小学、幼儿园建设项目的意见

文物保函〔2019〕427号

江苏省文物局：

你局《关于审批南京中航科技城小学、幼儿园建筑方案设计的请示》（苏文物保〔2019〕83号）收悉。经研究，我局原则同意在明故宫遗址建设控制地带内实施中航科技城小学、幼儿园建设项目。

一、深化建筑设计方案，小学教学楼西山墙应进一步退让宫墙遗址，并考虑与遗址展示的协调；应充分考虑植被选择、日常维护对宫墙遗址的影响，科学确定展示方式；严格控制工程范围和施工强度，桩基承台施工范围不得占压城墙遗址，做好施工中的文物保护工作，确保文物安全。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月7日
