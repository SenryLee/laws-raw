# 国家广播电视总局科技司关于对拟提名2019年度国家科学技术进步奖项目进行公示的通知

技科字〔2019〕1号

各省、自治区、直辖市广播电视局，新疆生产建设兵团广播电视局、直属相关单位：

根据国家奖励办公室文件要求，总局拟提名《多中波天线共场辐射场形优化及单塔定向中波天线系统》项目参加国家科学技术进步奖评审。现对拟提名项目进行公示，公示内容见附件，公示期自公示之日到2019年1月18日为止。

如对公示项目有异议，请各单位和个人在公示期间向总局科技司反映。以单位名义提出异议的，请加盖单位公章，以个人名义提出异议，要在书面异议材料上签署真实姓名和联系方式。

科技司联系人：彭志敏

联系电话：010-86092769
