# 国家林业和草原局公告2019年第31号——2019年第二批授予植物新品种权名单

## 国家林业和草原局公告

2019年第31号

## 2019年第二批授予植物新品种权名单

根据《中华人民共和国植物新品种保护条例》、《中华人民共和国植物新品种保护条例实施细则（林业部分）》规定，经国家林业和草原局植物新品种保护办公室审查，“霞光”等225项植物新品种权申请符合授权条件，现决定授予植物新品种权（名单见附件），并颁发《植物新品种权证书》。

特此公告。
