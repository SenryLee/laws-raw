# 农业农村部对十三届全国人大二次会议第5445号建议的答复

## 对十三届全国人大二次会议第5445号建议的答复

农办议〔2019〕202号

史秉锐代表：

您提出的关于加大对贫困地区产业发展政策支持的建议收悉。经商财政部、国务院扶贫办，现答复如下。

党中央、国务院高度重视产业扶贫工作，明确把产业扶贫摆在“五个一批”的首位。各地各部门认真学习贯彻习近平总书记关于扶贫工作的重要论述和中央脱贫攻坚决策部署，按照精准扶贫、精准脱贫的基本方略，加快推进产业发展、加强主体培育、创新利益联结、促进产销对接、强化科技支撑和人才培育，产业扶贫工作取得了显著成效。

一、关于加大中央财政产业扶贫资金投入力度

国家高度重视贫困地区扶贫开发投入，积极完善相关政策体系，不断加大资金投入力度。2019年下达中央财政专项扶贫资金1261亿元，连续四年保持200亿元增量，新增资金重点支持“三区三州”及“三区三州”之外贫困人口多、贫困程度深、脱贫难度大的其他深度贫困地区脱贫攻坚。财政专项扶贫资金审批权限下放到县级，地方可根据脱贫攻坚规划，结合本地实际，围绕培育和壮大贫困地区特色产业、改善小型公益性生产生活设施条件等方面因地制宜确定中央财政专项扶贫资金使用范围。同时，深入推进贫困县涉农资金整合。2016—2018年，整合涉农资金超过9000亿元，整合资金重点用于发展产业和基础设施建设，支持贫困地区打赢脱贫攻坚战。

下一步，中央财政将继续完善贫困县涉农资金统筹整合政策和“大专项+任务清单”的管理方式，进一步加大资金投入支持力度。各地可按照脱贫攻坚实际需求，统筹安排涉农整合资金，落实向贫困地区倾斜支持的政策，不断加大对贫困地区产业发展的扶持力度，促进贫困人口增收致富。

二、关于制定贫困地区特色产业发展规划

2014年，我部专门编制印发《特色农产品区域布局规划（2013—2020年）》，将贫困地区96个品种纳入规划范围，明确发展方向、目标和优势区域，对贫困地区发挥资源比较优势、优化特色产业布局、引导多方资金投入、促进农民增收致富提出具体要求。2017年，我部会同发展改革委、林业局印发《特色农产品优势区建设规划纲要》，明确国家、省两级特色农产品优势区（以下简称“特优区”）架构，围绕5大类29个重点品种（类）创建特色农产品优势区，认定国家级特优区，加快培育特色产业，促进农民增收，推动地区经济发展。截至目前，已经创建国家级特优区146个，其中贫困地区创建特优区46个。

为推进产业扶贫工作，根据中央的部署要求，2016年，我部联合发展改革委等8部门印发《贫困地区发展特色产业促进精准脱贫指导意见》，指导22个扶贫任务重的省（区、市），综合考虑资源禀赋、产业现状、市场空间、环境容量以及产业覆盖面，编制完成省、县两级产业扶贫规划，推动各地科学确定产业，精准设计项目，确保产业对人、人对产业。2019年，我部把贫困地区特色产业优先纳入《全国乡村特色产业目录》，进一步加强宣传推介，培育壮大贫困地区特色产业，助推脱贫攻坚。

下一步，我部将根据《关于打赢脱贫攻坚战三年行动的指导意见》要求，指导各地调整完善产业扶贫规划，编制乡村振兴规划，推动产业扶贫与乡村振兴衔接。支持贫困地区走绿色化、优质化、特色化、品牌化路子，提升特色产业发展水平，推进农产品加工升级转化，提升农产品附加值，为提高脱贫质量、巩固脱贫成果提供坚实支撑。

三、关于进一步加大扶贫产业政策倾斜支持力度

为落实《中共中央、国务院关于打赢脱贫攻坚战三年行动的指导意见》，我部进一步优化政策供给，推动政策落地，统筹各方资源要素，努力提升产业扶贫质量。指导地方优先支持贫困地区建设高标准农田，开展农民合作社质量提升试点，开展农产品产销对接等工作。通过组织洽谈活动、举办推进会等，激励龙头企业到贫困地区以共建合作基地等方式支持特色产业发展。支持有条件的贫困地区开展美丽休闲乡村创建、农村创业创新示范园区和基地创建、绿色食品原料标准化生产基地和有机农业生产基地创建等。对贫困地区绿色食品、有机食品认证实行费用减免优惠政策。将农村实用人才带头人和大学生村官示范培训项目，全部调整为面向贫困地区实施，培训对象覆盖所有贫困县。同时，国家西部大开发政策已经覆盖重庆市、四川省等13个西部省（区、市，含新疆生产建设兵团），并把湖南省湘西自治州、湖北省恩施自治州、吉林省延边自治州和江西省赣州市纳入政策范围。代表提出的将西部大开发各项优惠政策扩展至全部贫困县同等享受的建议，中央有关部门将认真研究。

下一步，我们将认真贯彻中央脱贫攻坚决策部署，坚持问题导向，精准施策，进一步推动贫困地区产业提升、产销对接、龙头带动、人才培养、技术服务和机制创新等方面的政策落地，提升产业扶贫、精准脱贫质量，为贫困地区脱贫攻坚和乡村振兴提供坚实的基础支撑。

感谢您对农业农村工作的关心，希望今后继续对我部工作予以支持。
