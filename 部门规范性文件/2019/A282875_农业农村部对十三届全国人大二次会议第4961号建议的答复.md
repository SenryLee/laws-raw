# 农业农村部对十三届全国人大二次会议第4961号建议的答复

## 对十三届全国人大二次会议第4961号建议的答复

您提出的关于加快畜禽养殖废弃物处理的建议收悉。经商财政部，现答复如下。

一、关于转变传统观念和发展方式

近年来，我部坚持畜禽粪污肥料化和能源化利用方向，积极促进种养循环发展。印发《畜禽粪污土地承载力测算技术指南》，指导各地按照以地定畜、种养平衡的原则，合理调整养殖规模，制定养殖业发展规划，保障畜牧业可持续发展。组织开展果菜茶有机肥替代化肥行动，推进有机肥替代化肥试点，支持重点县农民和新型经营主体使用有机肥，集中推广堆肥还田、商品有机肥施用、沼渣沼液还田等技术模式，配套设施设备，集中连片推进实施。鼓励采取政府购买服务等方式，开展有机肥统供统施等社会化服务，促进果菜茶提质增效和资源化循环利用。下一步，我部将持续推动种养结合、农牧循环发展，打通粪污肥料化利用路径，引导和支持种养业协调发展。

二、关于完善政策法规和加大奖补力度

近年来，中央不断加大支持力度，以畜牧大县为重点整建制推进畜禽粪污资源化利用。截至目前，585个畜牧大县已实现全覆盖。目前，中央财政农业生产发展资金实行“大专项+任务清单”管理方式，资金采取因素法测算，按照大专项整体切块下达到地方。各地可在完成约束性任务的基础上，结合本地农业发展规划，按照相关规定统筹利用中央财政和地方资金，支持非畜牧大县畜禽规模养殖场粪污治理工作。下一步，我部将会同财政部，不断总结经验，完善相关政策措施，将畜禽粪污资源化利用工作向纵深推进，进一步促进畜牧业绿色发展。

三、关于构建循环农业产业模式

我部依托国家畜禽养殖废弃物资源化利用科技创新联盟，组织开展源头减量、粪水还田等12项关键技术研究，总结提炼出粪污全量还田利用等9种典型技术模式，分区包片进行推广，指导地方科学设计治理路径，合理选择技术模式。成立全国农机化科技创新畜禽养殖工程专业组，开展畜禽养殖废弃物资源化利用农机示范推广，促进畜禽养殖装备系统优化升级。2019年出台小微企业普惠性减税措施，大幅放宽小型微利企业标准并加大优惠力度，符合条件的有机肥料厂均可依法享受有关优惠政策。下一步，我部将会同有关部门继续加大支持力度，围绕源头减量、过程控制、末端利用等关键环节，推广经济适用的综合配套技术，总结推广成本低、可复制、能推广的典型模式，打通种养循环发展链条。

四、关于创新技术与设备

我部高度重视农业领域科研工作，坚持问题导向，采取有效措施，加快推进畜禽粪污资源化利用技术装备研发及推广应用。注重强化农机购置补贴政策扶持引导，联合财政部印发《2018—2020年农机购置补贴实施指导意见》，将撒肥机、清粪机、粪污固液分离机、沼液沼渣抽排设备、病死畜禽无害化处理设备、沼气发电机组等畜禽粪污资源化利用机具列入全国补贴范围，并明确要求进行优先补贴。颁布《畜禽粪便堆肥技术规范》，为堆肥产品还田利用提供技术指导。组织畜禽粪污资源化利用项目培训和畜禽养殖废弃物资源化利用技术培训，全面解读畜禽粪污资源化利用法规、政策和技术，明确重点任务和工作要求。下一步，我部将会同有关部门进一步完善政策措施，加大畜禽粪污资源化利用技术装备的研发与推广应用力度，为畜禽粪污资源化利用提供技术和人才支撑。

感谢您对畜牧兽医工作的关心，希望继续对我部工作给予支持。

农业农村部

2019年8月30日
