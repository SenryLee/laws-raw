# 教育部关于发布教育行业标准《高等学校固定资产分类与代码》的通知

教高函〔2019〕2号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局，有关部门（单位）教育司（局），部属各高等学校、部省合建各高等学校，有关单位：

经全国教育装备标准化技术委员会审查通过，现发布以下教育行业标准：

JY/T 0624-2018 高等学校固定资产分类与代码

该标准自发布之日起实施。

教育部

2019年1月10日
