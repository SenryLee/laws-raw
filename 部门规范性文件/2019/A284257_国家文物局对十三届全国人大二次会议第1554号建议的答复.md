# 国家文物局对十三届全国人大二次会议第1554号建议的答复

文物保函〔2019〕564号

文正友代表：

您提出的“关于将可乐国家考古遗址公园项目列入国家级项目的建议”收悉，现答复如下：

可乐遗址位于贵州省赫章县，是战国至汉代夜郎国重要的文化遗存。可乐遗址对研究古夜郎民族的政治、经济和文化，以及西汉中央王朝经略西南地区的历史，都具有重要意义。2001年，可乐遗址被国务院公布为全国重点文物保护单位。国家文物局非常重视可乐遗址的考古研究与保护利用工作，2008年批复了《可乐遗址保护规划》，2018年批复了《贵州夜郎考古工作规划（2018-2022年）》，并支持地方人民政府重点开展考古、灾害防治、环境整治等工作，有效改善了文物保存现状。2010年可乐考古遗址公园被列入第一批国家考古遗址公园立项名单，2016年被列入“十三五”国家大遗址项目库。

下一步，国家文物局将继续高度重视和大力支持可乐考古遗址公园建设，积极与贵州省文物局、地方人民政府一起，重点推进以下工作：

第一，指导贵州省文物局组织专业考古单位，结合可乐考古遗址公园建设，系统推进考古和综合研究工作，注意吸纳环境考古、历史地理、冶金考古、民族学等领域专家，搞清可乐遗址的整体格局、文化内涵和夜郎文化的分布范围、特征，科学阐述其在中华文明多元一体格局中的重要地位，为遗址保护和国家考古遗址公园建设提供科学依据。

第二，督促地方人民政府落实文物保护的主体责任，按照《国家考古遗址公园管理办法（试行）》《国家考古遗址公园建设及运行管理指南（试行）》等文件有关要求，抓紧编制可乐考古遗址公园规划，明确建设规模、目标、功能定位、重要节点等，为文物保护展示和公园建设提供依据。国家文物局将继续在项目和经费方面加大支持力度。

第三，指导地方人民政府根据文物保护规划和公园建设需要，科学确定博物馆选址、建设规模、展陈设计、管理模式等，抓紧编制博物馆设计方案，并及时履行相关审批程序。国家文物局将在项目审批、业务指导上给予支持。

感谢您对文物事业的关心和支持。

国家文物局

2019年6月18日
