# 国家文物局对十三届全国人大二次会议第9031号建议的答复

文物保函〔2019〕661号

莫小峰代表：

您提出的“关于请求国家积极倡导推进‘海上丝绸之路·中国史迹’申遗的建议”收悉，经商财政部，现答复如下。

海上丝绸之路（以下简称“海丝”）是自公元前2世纪至19世纪中后期蒸汽动力取代风帆动力这一时段，古代人们借助季风与洋流等自然条件，利用传统航海技术沟通世界，开展多领域交流的海路网络，也是东、西方不同文明板块之间经济、文化、科技、宗教和思想相互传输的纽带。海丝涵盖了古代世界的所有海域，西至北非和南欧的地中海沿岸，东至东北亚的日本和东南亚地区，包括了地中海区域、阿拉伯半岛、东非、南亚次大陆、中南半岛、中国、以及日本和朝鲜半岛。

为落实“一带一路”的倡议，国家文物局继2014年联合哈萨克斯坦、吉尔吉斯斯坦成功申报“丝绸之路：长安—天山廊道的路网”后，将海丝保护和申报世界文化遗产作为一项重点工作予以推进。自2015年起，我局每年组织召开全国海丝保护和申遗工作会议，研究部署相关工作。

2017年，国务院领导召开专题协调会议，研究确定海丝保护和申遗工作要借鉴陆上丝绸之路申遗的成功经验，充分发挥国际组织在跨国统筹协调方面的优势和作用，在世界遗产中心协调下，推动我国与海丝沿线相关国家实现跨国联合申遗。

为此，我局对外开展了一系列的国际沟通协商，努力推动海丝跨国保护申遗工作。对内组织专业机构对海丝申遗潜力点现场考察、评估；指导各地结合实际，重点推动考古研究、规划编制、法规建设、维修展示、环境整治等重点、难点工作，严格控制建设、旅游等开发压力，做好与利益相关者的沟通协商，建立顺畅的利益协调机制。

2017年广州被推举为海丝申遗牵头城市，广州市人民政府成立了联合申遗办公室，定期召开联席协调会议。2018年4月，海丝保护和联合申报世界文化遗产城市联盟第一次联席会议在广州召开。广州、北海等26座城市签署了海丝保护和联合申报世界文化遗产城市联盟文件。2019年5月，我局指导在南京召开海丝保护和申报世界文化遗产城市联盟联席会议，通过了《海丝保护和联合申报世界文化遗产三年行动计划（2019-2021年）》，提出了海丝申遗潜力点名单。

应该看到，无论从目前全球的世界遗产申报形势，还是具体到海丝遗产点的保护管理状况、主题研究、国际协调，海丝保护和申遗的工作量与工作难度巨大：国际海丝主题研究进展缓慢，海丝申遗的概念性文件尚未最终形成；海丝申遗潜力点的调研和遴选是一个长期过程；海丝申遗的协调任务依然艰巨。

我局将继续加强与国际组织的沟通，积极推进对海丝概念文件、主题研究的深化，提出能得到各相关国家广泛认可的海丝申遗策略；同时，将科学动态管理海丝申遗潜力点名单，指导各遗产地按世界遗产的标准做好各项基础工作，充分培育和发挥海丝申遗的品牌效应。

我局高度关注和重视广西壮族自治区海丝保护和管理工作。2012年，将广西北海市作为海丝申遗城市列入《中国世界文化遗产预备名单》。2019年，广西壮族自治区防城港市的潭蓬运河、钦州市的西坑古运河、北海市的合浦汉墓群、大浪古城遗址、草鞋村遗址列入海丝申遗潜力点名单。

中央财政历年来对合浦汉墓群、大浪古城遗址、草鞋村遗址的规划编制、保护修缮、环境整治等项目给予了上亿元的经费支持，未来将继续对包括广西壮族自治区海丝遗产点在内的众多海丝相关遗产点的保护修缮、环境整治、阐释展示等项目，按《国家文物保护专项资金管理办法》的规定予以倾斜扶持。
