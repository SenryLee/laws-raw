# 国家文物局关于榆林卫城保护规划的意见

文物保函〔2019〕53号

陕西省文物局：

你局《关于上报榆林卫城保护规划的请示》（陕文物字〔2018〕129号）收悉。经研究，我局原则同意所报榆林卫城规划。

一、该规划尚需作以下必要的修改和完善：

（一）进一步确立规划目标，明确该区域未来发展方向、功能定位，确定近期及中长期工作重点。重新校核全国重点文物保护单位榆林卫城的文物构成，剔除重建建筑，并补充说明规划对象的确定标准和依据。

（二）进一步加强考古和历史文献研究，分析榆林卫城与周围山形水系、长城体系和凌霄塔的历史关联，补充对榆林卫城格局变迁和北侧军事防御设施的研究，厘清城市周边格局特征。

（三）深化价值评估，从榆林卫城作为长城重要组成部分，以及作为当地居民生产、生活场所等多角度分析其历史文化内涵和对当代社会的意义。

（四）强化遗产保存现状评估。系统梳理各类病害及残损，查找其产生根源，并结合历次修缮保护工程效果评估，综合分析榆林卫城价值及真实性、完整性延续情况；补充说明各处文物保护单位的保护区划及管理现状、产权归属；补充重要区域的景观视廊分析；为进一步修改完善保护规划提供科学依据。

（五）根据榆林卫城历史遗存及历史环境特征，合理调整保护区划，如应将北侧城墙遗址、部分历史街巷纳入保护范围，并基于城市现状评估和榆林卫城格局研究成果合理划定风貌协调区等。

（六）应针对现存大量民居明确整体保护思路，进一步细化保护区划管理规定，补充新建建筑风貌、体量、密度、功能定位等方面要求，增强针对性和可操作性。补充历史街巷保护措施和控制要求。应明确城墙保护以修整加固为主，慎用“包砖”等做法。

（七）进一步完善专项规划。补充考古工作计划；完善管理规划，明确相关管理部门等各利益相关方的权利和责任；展示利用规划应侧重对榆林卫城整体格局的全面展示，明确展示主题、展示对象、展示内容及展示路线，并加强与周边遗存的联动关联；完善环境整治规划，明确整治区域、对象及具体措施，并注意社区等利益相关者的参与。

（八）加强与相关城市总体规划、历史文化名城规划、长城保护总体规划等相关规划的衔接，并作出必要说明。

（九）进一步规范和完善规划文本和图纸。如补充长城防御体系图、明清两代历史地图等。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见对规划进行必要修改和完善后，依照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将榆林卫城保护规划报请陕西省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好榆林卫城各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年1月14日
