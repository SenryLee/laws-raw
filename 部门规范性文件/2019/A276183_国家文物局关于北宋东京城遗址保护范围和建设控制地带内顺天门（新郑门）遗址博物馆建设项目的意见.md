# 国家文物局关于北宋东京城遗址保护范围和建设控制地带内顺天门（新郑门）遗址博物馆建设项目的意见

文物保函〔2019〕310号

河南省文物局：

你局《关于再次报批北宋东京城顺天门（新郑门）遗址博物馆项目涉北宋东京城遗址保护范围和建设控制地带设计方案的请示》（豫文物〔2019〕15号）收悉。经研究，我局原则同意在北宋东京城遗址保护范围和建设控制地带内实施顺天门（新郑门）遗址博物馆建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应确保遗址本体安全，切实加强考古、保护和遗址博物馆建设的衔接，制定施工中的临时性文物保护措施，并确保考古人员全过程参与遗址博物馆建设项目。

（二）应进一步优化博物馆外观样式，采用现代化设计形式，调整遗址博物馆建筑的外观、规模、高度、出入口节点等设计内容，统筹考虑博物馆建筑与开封城市文脉传承、城市风貌、后续考古工作的关系。

（三）景观设计应注意营造历史氛围，合理布设服务设施，尽量降低对项目范围内地形地貌的改造强度，建议减小东侧草坡地形高差。

（四）充分考虑博物馆运营维护、管理使用等成本问题，确保项目的公益属性。优化博物馆内展陈体系，突出顺天门遗址历史格局、变迁及其与北宋东京城的关系。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织考古等专业机构参与项目全过程，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年4月2日
