# 国家邮政局办公室关于推广贵州经验进一步做好政邮合作有关工作的通知

国邮办函〔2019〕94号

各省、自治区、直辖市邮政管理局，中国邮政集团公司办公室：

国家邮政局“2019年邮政业更贴近民生七件实事”提出，支持邮政企业进驻各地政务服务大厅，进一步推广“网上办事+线下寄递”模式，助力“不见面”审批。贵州省邮政管理局、邮政分公司认真落实国家邮政局要求，积极探索，走出政邮合作新路子，取得了明显成效，形成了较为典型的经验。为推广贵州政邮合作经验，进一步推动政邮合作深入开展，现通知如下：

一、认真学习借鉴贵州经验做法

2018年6月，国务院办公厅印发《进一步深化“互联网+政务服务”推进政务服务“一网、一门、一次”改革实施方案的通知》，对加快推进政务服务“一网通办”和企业群众办事“只进一扇门”“最多跑一次”等做出部署。贵州局深入贯彻落实国家“放管服”改革要求，吃透政策精神，发挥行业优势，主动协调省政府及财政、政务中心等部门，指导省邮政分公司积极作为，采取邮政企业进驻方式提供证照寄递服务，为贵州“互联网+政务服务”改革、优化营商环境做出了行业应有的贡献。

在政企双方共同努力下，目前贵州省、市、县三级110个政务服务中心已经开展政邮合作的达104个，实现线上服务与线下服务相结合，实行“政府买单、免费邮寄”模式，有效提升了政务服务效率和人民群众满意度、获得感，得到了各级政府的充分肯定和社会各界、企事业单位、人民群众的认同。

二、深入推动政邮合作打造综合服务平台

实践证明，政邮合作是一项政府获益、企业获利、群众满意、多方共赢的好事实事。各省局、邮政集团公司要按照中央部署和国家邮政局的要求，从贯彻落实中央改革精神的高度充分认识推动“政邮合作”的重要意义，从立足行业本质、发挥网络优势着眼，深入推动政邮合作，助力“放管服”改革。

各省局要借鉴贵州经验，找准工作切入点，主动与地方政府部门对接，推动落实并跟踪抓好此项工作；邮政集团公司要部署并督促各省邮政分公司积极行动起来，制定工作方案，创新服务方式，通过上门揽收、专人驻点和政府代办等方式提供证照寄递服务，优化作业环节，提升工作效率，切实减轻人民群众的办事成本。

政企双方要统一思想、形成合力，充分发挥邮政网络优势、平台优势、功能优势，深入推动邮快交商合作、警邮合作、税邮合作、政邮合作等，打造邮政综合服务平台，实现共赢发展，确保取得良好社会效果。

各地推进政邮合作的主要做法、工作进展和成效，请于今年10月底前报国家邮政局普遍服务司。

国家邮政局办公室

2019年3月1日
