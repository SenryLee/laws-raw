# 住房和城乡建设部关于废止部分文件的决定

建法〔2019〕58号

各省、自治区住房和城乡建设厅，直辖市住房和城乡建设（管）委，新疆生产建设兵团住房和城乡建设局：

为贯彻落实党中央、国务院有关法规文件清理的工作部署，经清理，我部决定废止部分文件，现将废止的文件目录予以公布。本决定自印发之日起施行。

附件：住房和城乡建设部决定废止的文件目录

中华人民共和国住房和城乡建设部

2019年5月15日
