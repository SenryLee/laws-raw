# 国家文物局关于大运河小汶河段保护区划内董家口至梁山公路宁阳至梁山段建设项目的意见

文物保函〔2019〕47号

山东省文物局：

你局《关于报送董家口至梁山公路宁阳至梁山段跨越小汶河遗址保护设计方案修改稿的请示》（鲁文发〔2018〕107号）收悉。经研究，我局原则同意大运河小汶河段保护范围和建设控制地带内董家口至梁山公路宁阳至梁山段建设项目，以及所报选线方案三和桥梁设计方案二。

一、上述方案尚需作以下必要的修改和完善：

（一）应在大比例尺地形图上明确标示拟建项目与大运河小汶河段保护范围和建设控制地带的空间位置关系，对照保护区划管理规定作出符合性说明。

（二）应在项目实施前，在相关区域建设临时围堰并进行排水，同时组织专业机构开展进一步考古调查勘探和必要的考古发掘，摸清该区域地下遗存分布情况，为优化拟建项目方案设计提供依据。

（三）应充分考虑大运河小汶河段遗址的保护需求，优化拟建桥梁设计方案，加大桥梁跨距，桥墩不得直接占压河堤等重要遗迹。

（四）进一步评估架桥跨越小汶河防洪堤，其桥墩、桩基对防洪堤的影响，在此基础上对工程方案作出针对性调整，消除风险隐患。

（五）应细化拟建项目施工方案，补充施工和运营期间各类振动、沉降等对大运河小汶河段影响情况监测措施、应急预案、临时性保护措施、环境保护要求、污染物处置要求，以及施工结束后的场地清理和环境修复措施。

（六）应进一步校核方案文本和图纸，更正错误信息。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月14日
