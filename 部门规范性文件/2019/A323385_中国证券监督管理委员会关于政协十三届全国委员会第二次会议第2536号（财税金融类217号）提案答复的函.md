# 中国证券监督管理委员会关于政协十三届全国委员会第二次会议第2536号（财税金融类217号）提案答复的函

## 关于政协十三届全国委员会第二次会议第2536号（财税金融类217号）提案答复的函

《关于加强投资者教育和保护力度防范微观金融风险的提案》收悉。经认真研究并商教育部、银保监会，现就有关问题答复如下：

**一、**证券期货业和银行保险业金融宣传教育工作情况

中国证监会高度重视投资者教育保护工作，持续开展各类投资者教育活动，不断扩大证券期货知识普及力度，提高投资者风险防范意识和自我保护能力。一是围绕监管中心工作和投资者需求开展投资者教育专项活动和公益广告、知识竞赛等特色投教活动。相继开展了“明规则、识风险”、“理性投资，从我做起”、“走近科创，你我同行”等专项投教活动，并在证监会官网开设投资者教育、非法证券期货风险提示专栏，帮助投资者及时了解最新监管动态和理性投资知识；探索“股市投资路 理性每一步”公益广告、“股东来了”全国知识竞赛等喜闻乐见的理性投教方式，让投资者潜移默化地接受长期投资、理性投资、价值投资理念。二是推动各省、市、自治区试点将投资者教育纳入国民教育体系，500多所学校设置投教课程，惠及上百万学生。有的地区将投资者教育纳入中小学课程设置，编制了中小学普及金融知识教材；有的地区将投资者教育纳入高等教育、职业教育体系，作为选修课或必修课；还有的地区在继续教育、民族教育中进行了有效探索。今年3月，证监会与教育部联合印发《关于加强证券期货知识普及教育的合作备忘录》（证监发〔2019〕29号，以下简称《备忘录》），进一步加强对投教纳入国民教育体系工作的统筹规划和规范指导。三是指导建设实体和互联网投教基地，为广大中小投资者提供免费、便捷、专业的教育服务，老百姓只需“迈迈腿，动动手”，即可集中获取所需的知识和服务。目前，证监会及派出机构分别命名29家国家级基地和83家省级基地，覆盖29个省市自治区，在引导投资者树立理性投资意识、帮助投资者行权维权等方面发挥了重要作用。四是将每年5月15日设立为“全国投资者保护宣传日”，动员全国上下积极开展活动，在全社会倡导理性投资文化，建立起监管部门主导推动、相关部门联动、行业主动尽责、公众积极参与的投资者保护长效机制。

银保监会近年来也持续组织开展形式多样的金融消费者宣教活动。一是以“3·15国际消费者权益日”为契机，组织指导协调各派出机构和银行保险机构开展“3·15消费者保护教育宣传周”活动，针对非法集资、电信诈骗、银行卡盗刷、销售误导等违法违规金融活动，集中开展教育宣传，提升社会公众对金融产品和服务的认知、选择能力及风险责任意识。二是每年9月组织开展“金融知识进万家”活动，广泛开展金融知识“进社区、进学校、进农村”等，并积极对接人民日报、中央广播电视总台等新闻媒体，扩大宣传覆盖面。三是积极利用官方网站、微博、微信等互联网数字媒体传播方式，持续发布银行和保险知识，开展风险提示，普及与消费者保护有关的政策，丰富消费者教育形式。

**二、**关于提案的具体意见

（一）关于将投资者教育上升到国家战略层次，在主要城市开展试点，率先将投资者教育逐步纳入国民教育体系等建议。近年来，证监会与教育主管部门保持良好沟通，在义务教育课程标准修订工作中积极提出金融教育知识要点，科学合理地推动将金融知识融入相关学科课程中。下一步，证监会将继续与教育部加强沟通协调，进一步指导各地证券监管部门和教育行政部门落实《备忘录》有关要求，引导社会各界加大资源投入力度，不断强化投资者教育纳入国民教育工作，持续提升证券期货知识普及的深度、广度和力度。

（二）关于监管部门、协会组织及第三方机构依据标准对投资者进行分类，持续且有针对性的开展投资者教育和保护工作的建议。前期，证监会发布实施《证券期货投资者适当性管理办法》（证监会令第130号，以下简称《适当性办法》），明确将投资者区分为普通投资者和专业投资者，并且指导证券、基金、期货行业协会分别制定各行业投资者的具体分类标准，引导证券期货经营机构科学、合理操作。这是实现适当性销售的基础，尽管不同公司对于投资者分类的结果可能会有所不同，但投资者分类水平正是一家机构了解客户工作质量、以及公司整体适当性管理能力的集中体现。对于经营机构进行基础知识教育工作，由于证券期货等经营机构具有紧密联系广大投资者的特征，由其开展投资者教育工作，具有针对性强、有效性足的优势，是监管部门、行业协会等投教工作的有益补充。同时，通过证券经营机构的营业网点、网站，将投资者教育工作与证券业务有机结合在一起，也是证券经营机构进一步深化客户服务的良好契机。证监会将积极联合人民银行、银保监会等其他监管机构，围绕监管中心工作和投资者需求持续开展形式多样的教育宣传活动，同时将强化证券期货经营机构、银行保险机构主体责任，帮助不同类型投资者树立理性意识，提高自我保护能力。

（三）关于机构在销售金融理财产品时必须通过书面和口述的方式向用户解释风险和实际发生费用,保护投资者个人信息不泄露的建议。《适当性办法》要求证券期货经营机构应向客户充分揭示风险，有关内容应当真实、准确、完整，不存在虚假记载、误导性陈述或者重大遗漏，语言应当通俗易懂，并规定了针对普通投资者进行告知、警示的录音录像、留痕制度以及违反相关制度的处罚措施。同时，《银行业金融机构销售专区录音录像管理暂行规定的通知》（银监办发〔2017〕110号）、《保险销售行为可回溯管理暂行办法》（保监发〔2017〕54号）均要求银行保险机构通过录音录像等技术手段采集电子数据，对银行理财业务、代销业务的销售过程和保险销售行为实行录音录像管理，实现对销售行为的可回溯，防范和治理销售误导。

（四）关于从监管、行政机构、广告管理等层面做好投资者教育宣传和引导工作，以及增加投资者教育和保护工作的科学评价与检测体系的建议。证监会将继续强化投资者教育保护统筹协调，加大投资者教育普及力度，加强与新闻媒体合作，依托报纸、广播、电视等传统媒体，以及微博微信等新媒体渠道，紧密结合社会热点普及金融知识，发布风险提示，并联合有关部门做好对涉非网络信息的管理。同时，将广泛开展投资者调查，了解投资者的真实状况和需求，积极做好教育效果评估工作，建立投资者反馈机制，改进教育内容和方式，不断提高投资者教育保护效果。
