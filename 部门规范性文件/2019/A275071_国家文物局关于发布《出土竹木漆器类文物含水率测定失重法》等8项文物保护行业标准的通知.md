# 国家文物局关于发布《出土竹木漆器类文物含水率测定失重法》等8项文物保护行业标准的通知

文物博发〔2019〕9号

各省、自治区、直辖市文物局（文化和旅游厅/局），各直属单位，各国家文物局重点科研基地：

现将《出土竹木漆器类文物含水率测定 失重法》等8项推荐性文物保护行业标准（清单见附件）发布，自2019年6月1日起施行。

特此通知。

国家文物局

2019年3月6日

附件：8项推荐性文物保护行业标准清单
