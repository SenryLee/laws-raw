# 国家森林草原防灭火指挥部办公室关于森林草原防灭火督查工作情况的通报

国森防办发明电〔2019〕10号

各省、自治区、直辖市森林（草原）防（灭）火指挥部，新疆生产建设兵团森林（草原）防火指挥部：

为认真贯彻落实全国森林草原防灭火工作电视电话会议精神和全国应急管理工作会议精神，切实做好冬春季特别是春节期间森林草原防灭火工作，1月29日至2月16日，国家森林草原防灭火指挥部办公室组织对北京、河北、福建、江西、湖北、湖南、广东、广西、四川、云南等10省（区、市）森林草原防灭火工作进行了督查。现将有关情况通报如下：

一、基本情况

从整体上看，去冬今春以来，10省（区、市）高度重视森林草原防灭火工作，采取一系列措施防范火灾事故发生；火灾发生后，多数地区能迅速响应，及时扑救，把损失降低到最低程度，有效避免了重特大森林草原火灾和人员伤亡，确保了防灭火形势总体平稳。一是普遍提高了对重点时段森林草原防灭火工作的重视程度。各地党委政府通过主要负责同志一线督查、召开专题会议、下发紧急通知、制定专项方案等方式对春节期间森林草原火灾防控工作进行全面动员和周密部署。广东、湖南、福建、云南、四川等地党委政府主要负责同志就森林草原防灭火工作作出批示，北京、河北、江西、湖北、广西等地党委政府有关负责同志检查调研森林草原防灭火工作，河北省委办公厅、省政府办公厅联合下发通知要求把森林草原防火工作放在突出位置来抓。二是普遍强化了森林草原火灾防控责任落实。通过领导包片、定点督办、约谈有关责任单位等方式，进一步明确工作目标和防火责任，确保各项责任落实到位。北京市针对春节期间的烟花爆竹隐患，各级森林防火机构与林区经营单位签订了《烟花爆竹管理工作责任书》，严格履行主体单位管护责任。湖北省武汉市、湖南省常德市、江西省南昌市强化领导落实，分片包干推进火灾防控重点工作。三是普遍加大了野外火源管理力度。通过发布《禁火令》，落实重点人群监护责任，划定燃放区域，限定燃放种类，筑牢“用火审批、林区巡防、入山检查”三道防线等方式，严格管控野外火源。江西省规范炼山造林等生产性用火，做到“县区政府审批、林业部门指导、乡镇干部监督实施”。广东省先后派出178个工作组对“山边、林边、路边、山头、坟头”进行不间断、不留死角的巡查和督检。四是普遍开展了风险隐患排查整治工作。通过印发专项方案和对照标准，深入查找火灾风险隐患，并建立台账、限期整改。对林区通道、林缘地带、林农结合部等重点部位可燃物进行清理，有效减少火灾隐患，降低火险等级。江西省开展隐患排查整治“十查十看”活动和“平安春节行动”，四川省共排查输电线路1.6万公里、铲割隔离带1800余公里、消除林下林缘可燃物12.7万吨。五是普遍加强了应急准备。通过制定重点时段火灾防控专项预案、开展应急演练、充实扑火物资、实行专业队集中食宿、靠前驻防和联防联控等方式，提升快速反应和应急处置能力，切实做到打早打小打了。

二、主要问题

在检查期间，各工作组也发现了一些地方森林草原防灭火工作存在的薄弱环节和隐患问题。

一是对森林草原防灭火工作面临的新形势、新任务、新要求认识不到位，工作要求不够高。四川、云南两省一些地市对2月份以来火灾多发的不利局面没有引起高度重视，工作标准不高、要求不严，满足于没有发生重特大森林草原火灾和人员伤亡事故，仍然沿袭常规的工作思路和工作手段。江西省去冬今春降雨量较大，部分基层干部存在思想松懈苗头，防火责任和措施落实还不够到位。此外，大部分市县两级应急管理局正在组建，部分市县两级林业局撤销或者合并，森林公安体制改革已经全面启动，一些领导干部对森林草原防灭火工作业务衔接的紧迫性重视不够。

二是森林草原防灭火工作职责不明晰，部门职能未能完全落地。10省（区、市）省级林草部门森林草原防灭火工作人员转隶基本完成，但森林草原防灭火指挥部正在调整组建，组织、协调、指导职能存在一定“空转”现象。大部分省（区、市）应急管理部门和林草部门权责清单还不够清晰、分工还不够明确，部门之间“踢皮球”、“打太极”的现象还不同程度存在，分工合作机制亟待完善，行业管理责任亟需加强，部门职能事权划分应尽快落地。

三是火灾防控责任落实不到位，基层布控网络存在盲区死角。部分地区属地党政领导责任落实有漏洞，特别是县、乡两级责任尚未完全压实。福建省在下达禁火令的情况下，自宁德市蕉城区前往古田县公路沿线仍有零星烧荒烧垃圾等野外用火情况。广西壮族自治区东兰县神仙山附近村庄有村民燃放烟花爆竹、焚烧稻草现象，存在较大火灾隐患。四川省雅安市碧峰峡景区隐患整治工作不彻底。工作组在前往凉山州西昌市川兴镇“2·11”森林火灾现场途中发现农民烤火的火堆和随意丢弃的烟头烟盒，林区移民搬迁后废弃房屋没有得到及时处置，为人员随意入住擅自用火引发火灾埋下隐患。实地查看云南大理州大理市海东镇“2·9”森林火灾现场途中，发现村民在林内吸烟。

四是一些地区传统民俗、祭祀用火较多，火灾隐患比较突出。在南方林区牧区，丧葬、节令、祭祀、耕作等方面传统用火普遍存在。今年春节期间，云南、四川等地多起森林草原火灾系上坟烧纸、燃放烟花爆竹等民俗用火引发。在检查中发现，云南大理海东白族民舍外燃烧的香烛有一米高碗口粗，一旦突遇大风吹进附近山林，极易引发森林火灾。此外，由于少数民族民居木结构较多，存在“家火上山”和“山火入户”形成火烧连营的风险。

五是有些地方应急力量建设还比较薄弱，管理不够规范。河北省怀来县东花园镇森林防火预案针对性不强，缺乏操作性。江西省吉安市吉水县专业扑火队预案修订不及时。福建省宁德市蕉城区专业扑火队未能够保持24小时人员待命，灭火力量夜间未实施集中备勤，应急响应能力不足。湖南省常德市桃源县专业扑火队战备、训练不够规范，装备维护保养不到位，部分灭火机具无法启动；岳阳市平江县部分新灭火机具未进行磨合，达不到最佳性能状态。湖北省鄂州市鄂城区泽林、汀祖两个镇和泽林镇银山村扑火装备较为落后，风力灭火机数量少，缺乏水泵等高效灭火装备。广东省源城区、惠城区、惠东县防火物资摆放杂乱，物资管理规范化有待进一步加强。广西壮族自治区乡镇半专业队扑火装备不足，部分乡镇缺乏专用交通工具、防火设备薄弱。

六是个别森林草原火灾应急处置不及时，指挥决策有待加强。从值班调度情况分析，个别地方发生森林火灾后不按规定及时上报信息，没有及时调动森林消防队伍和灭火飞机参加扑火，贻误了“打早、打小、打了”的最佳战机，埋下了小火酿成大灾的隐患。四川省凉山州木里县“2·10”森林火灾在初发阶段没有及时调动森林消防队伍参战，最终投入1530人和3架直升机历时3天才将火灾完全扑灭，耗费了大量人力物力；扑救云南昭通巧家县“2·6”森林火灾时对困难估计不足，迟迟未调动直升机吊灭悬崖处火点，耗时2天才将烟点处置完毕。

三、工作要求

针对督查中发现的问题，10省（区、市）要对号入座、专题研究，压实责任、精准施策，建立长效机制、增强造血功能，及时整改到位、严防一查了之。其他地区也要引以为鉴，举一反三，切实做好当前特别是全国“两会”、清明节期间森林草原火灾防控工作，严防人为原因引发森林草原火灾，严防重特大森林草原火灾和人员伤亡事故。一要提高思想认识，深刻学习领悟习近平总书记在省部级主要领导干部坚持底线思维着力防范化解重大风险专题研讨班上的重要讲话精神，深入学习贯彻习近平总书记关于应急管理、防灾减灾救灾、安全生产的重要论述精神，充分认识新时期森林草原防灭火工作面临的新形势、新任务、新要求，清醒看到在应急管理部门组建、林草部门调整、森林公安体制改革背景下森林草原火灾防控工作的复杂性、艰巨性和严峻性，更新思想观念，创新工作方式，以更高标准更严要求做好森林草原防灭火工作，坚决扛起防范化解森林草原火灾重大风险的政治责任。二要明晰火灾防控职能，扎实推动落实各部门“三定”规定，细化具体措施和操作办法，及时调整成立各级森林草原防灭火指挥部，建立健全运行机制，切实加强地方应急力量建设，确保组织协调指导和监督管理各项工作落到实处，火灾防控绝不能出现空档、漏洞。三要压实火灾防控责任，严格落实党政同责、一岗双责，重点压实县、乡两级政府的主体责任，完善源头防范，健全防控网络，深入开展风险隐患排查整治，加强野外火源管理，强化重点人群管控，推进移风易俗，要让广大农牧民真正意识到，一把火就可能造成全家甚至是全村返贫。四要完善指挥体系建设，建立上下贯通的指挥扑救工作机制，及时修订完善森林草原火灾应急预案，及时上报火情信息，及时调动森林消防队伍和飞机实施扑救，切实做到打早打小打了，坚决避免小火酿成大灾。省、市两级要加强跟踪督导，做到早出手、早干预、早调配。同时，要加大火案查处力度，组织对一批案件集中督办，落实防范责任，落实执法责任，加强宣传教育，完善群防群治格局，健全火灾防控体系，严防森林草原防灭火工作开局不利、造成全局被动长期被动。

请北京、河北、福建、江西、湖北、湖南、广东、广西、四川、云南等10省（区、市）森林（草原）防火指挥部办公室于3月底前将整改落实情况报国家森林草原防灭火指挥部办公室。
