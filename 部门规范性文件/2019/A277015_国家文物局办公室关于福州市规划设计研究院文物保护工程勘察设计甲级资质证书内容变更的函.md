# 国家文物局办公室关于福州市规划设计研究院文物保护工程勘察设计甲级资质证书内容变更的函

办保函〔2019〕312号

福建省文物局：

你局《关于福州市规划设计研究院申请资质证书内容变更的请示》（闽文物字〔2019〕141号）收悉。

经研究，我局同意福州市规划设计研究院文物保护工程勘察设计甲级资质证书中的注册资金由“850万元”变更为“3000万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年4月25日
