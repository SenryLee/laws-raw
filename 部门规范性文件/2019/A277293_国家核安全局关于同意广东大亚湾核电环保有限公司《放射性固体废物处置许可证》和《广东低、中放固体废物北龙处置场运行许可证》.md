# 国家核安全局关于同意广东大亚湾核电环保有限公司《放射性固体废物处置许可证》和《广东低、中放固体废物北龙处置场运行许可证》法人信息变更的函

## 关于同意广东大亚湾核电环保有限公司《放射性固体废物处置许可证》和《广东低、中放固体废物北龙处置场运行许可证》法人信息变更的函

国核安函〔2019〕32号

广东大亚湾核电环保有限公司：

你公司《关于申请变更〈放射性固体废物处置许可证〉和〈广东低、中放固体废物北龙处置场运行许可证〉的函》（广核保函〔2019〕5号）收悉。根据《放射性废物安全管理条例》及相关规章的规定，经研究，同意你公司所持《放射性固体废物处置许可证》（国环放废处置证［第2号］）及《广东低、中放固体废物北龙处置场运行许可证》（国核安证字第1107号）中法定代表人信息变更为田延锋，其他许可内容不变。

你公司作为放射性废物处置设施营运单位，应严格遵守上述许可证规定的运行限值和条件，在许可范围内接收处置放射性固体废物，加强运行管理，确保处置设施运行安全。

国家核安全局

2019年5月13日
