# 国务院第三次全国国土调查领导小组办公室关于印发《第三次全国国土调查成果国家级核查监理人员管理规定》的通知

国土调查办发〔2019〕15号

各国家级核查任务承担单位：

为加强第三次全国国土调查成果国家级核查监理工作管理，国务院第三次全国国土调查领导小组办公室制定了《第三次全国国土调查成果国家级核查监理人员管理规定》，现予以印发，请在具体工作中遵照执行。

国务院第三次全国国土调查领导小组办公室

2019年5月22日

附件

## 第三次全国国土调查成果国家级核查监理人员管理规定

为顺利推进第三次全国国土调查成果国家级监理工作，加强监理人员管理，提高监理工作质量，制定本规定。

一、自觉遵守国家法律法规，严格执行全国三调办各项规章制度，服从工作统一安排，切实履行岗位职责，按时保质保量完成工作任务，不得无故拖延、拒绝或终止工作。

二、严格遵守工作纪律，不迟到、不早退，不得无故缺勤，严禁擅自离岗。迟到、早退、因事因病不能到岗或上班期间因私外出等，需向全国三调办核查组管理人员请假，未请假者按旷工处理。上班时间，禁止处理私人事务或做与工作无关的事情，禁止无故串岗。

三、严格执行请假制度。事假必须事前提出申请，经全国三调办核查组批准后方可休假；请假3天以上的需要监理人员所在单位负责人批准并由全国三调办核查组，报请全国三调办领导批准后方可休假；监理任务紧张时期，监理人员请假必须由所在单位派其他可以胜任监理任务的技术人员顶替，全国三调办核查组批准后方可休假。

四、自觉维护办公秩序和环境卫生，严禁在工作场所内吃东西和吸烟，或在办公区域大声喧哗、聊天、听音乐和广播等。保持工作场所卫生整洁，不随意丢弃杂物；保持个人办公桌面的清洁和整洁，不得放置香烟等物品。

五、自觉维护工作场所安全，严禁携带违禁品、危险品或与工作无关的物品进入工作场所，注意防火、防盗。未经批准，严禁将全国三调办、中国国土勘测规划院的资产和资料带出工作场所。无特殊需要，监理人员下班后应及时关闭本人计算机电源。每天最后离岗的监理人员，应检查工作场所的电器、门窗及照明的关闭情况。

六、所有监理人员应和谐相处，岗位间要相互协调配合。各监理小组内部成员间应团结协作，齐心协力完成全国三调办核查组安排的监理工作。

七、工作中必须坚持公平公正，以认真负责的态度完成所有监理任务，严禁弄虚作假、徇私舞弊，或私自隐瞒发现问题。

八、未经批准，严禁以任何形式与被监理单位联系，或以任何形式向其提供任何监理资料和其他非公开的内部资料，严禁向被监理单位索取钱物或项目，或接受其宴请、礼品、礼金或其他变相报酬。

九、除全国三调办核查组分配的工作任务外，监理人员严禁以全国三调办名义对外工作，或私自执行其他监理任务。

十、未经允许，严禁查阅监理资料、使用他人计算机，或随意翻阅他人的文件、表册、或函件等资料。

十一、未经允许，严禁带领其他无关人员进入监理工作场所，或私自进入全国三调办及其他监理工作场所。

十二、除技术交流外，各监理小组间严禁私下交流监理结果。监理人员不得私下打听监理结果和抽检情况。在监理过程中出现问题，应及时向全国三调办核查组反映，严禁私自隐瞒或自行处理。

十三、严格遵守保密制度。严禁泄露任何调查和核查成果以及未经公布的监理结果；严禁私自复制、留存和泄露监理数据资料，必须在规定时间内销毁或删除有关数据资料；未经许可，严禁改变电脑的软硬件设置，或更改电脑中储存的数据；禁止私自拆装电脑。电脑只能用于全国三调办核查组分配的工作，严禁在电脑上安装游戏、电影及其他与工作无关的程序软件。

十四、爱护公物，节约办公用品，注意节水节电，杜绝浪费。

十五、全国三调办定期或不定期地对监理结果进行抽查和公示，对工作不认真、监理错误较多的人员进行警告、通报以及退回所在单位等处罚；对表现突出的人员进行表扬，并建议所在单位给予适当奖励。

十六、对违反上述管理规定的监理人员，全国三调办将视情节轻重依据有关规定责成所在单位进行处罚，同时保留追究其本人及所在单位法律责任的权利。
