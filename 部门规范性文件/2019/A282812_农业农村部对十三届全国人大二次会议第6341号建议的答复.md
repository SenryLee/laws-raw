# 农业农村部对十三届全国人大二次会议第6341号建议的答复

## 对十三届全国人大二次会议第6341号建议的答复

您提出的关于支持六安大别山革命老区高标准农田建设助推乡村振兴的建议收悉。经我部认真研究，现答复如下。

一、关于加大投入力度，提高投资标准

近年来，中央各部门通过中央预算内投资中新增千亿斤粮食工程、农业综合开发、农田整治、农田水利建设等项目渠道支持高标准农田建设，改善农业生产基本条件，不断提升粮食综合生产能力。2018年，党和国家机构改革方案明确农业农村部统一履行农田建设管理职责。根据党和国家机构改革有关精神，财政部会同农业农村部整合农业综合开发专项资金、土地整治工作专项资金和水利发展资金中用于农田水利建设部分，设立农田建设补助资金，用于支持高标准农田及农田水利建设。同时，利用中央预算内投资，支持高标准农田建设。目前，2019年中央农田建设补助资金和中央预算内投资高标准农田建设项目资金已全部下达地方，计划新建高标准农田8000万亩。其中，安排安徽省高标准农田380万亩、补助资金40亿元。各地应按相关政策规定，结合实际和高标准农田建设相关规划，统筹中央各渠道和地方各级相关资金支持高标准农田建设，合理确定投资标准。

下一步，我们将推动相关部门建立健全中央财政支持农田建设投入的稳定增长机制，根据高标准农田建设标准和成本变化，合理保障财政资金投入。同时，将会同相关部门研究不同区域高标准农田建设地方财政共同投入比例，不断加大财政资金保障力度。鼓励地方通过整合涉农资金、创新投融资模式、充分利用新增耕地调剂收益等方式，进一步拓宽筹资渠道，有效提高建设标准。

二、关于分类别、分层次制定高标准农田投资标准2018年党和国家机构改革前，农田建设工作由发展改革委、财政部、国土资源部、水利部等部门通过各自渠道支持，各渠道建设标准不同，建设内容各有侧重，存在部分项目难以达到旱涝保收、高产稳产高标准农田要求的情况。同时，随着近年来农田建设物料和人工成本上涨，各地普遍反映目前1500元的亩均投资标准与高标准农田建设要求相比明显偏低，需要提高标准。

下一步，我部将会同相关部委，充分考虑东西南北区域差异和近年来建筑材料和人工等价格变动较大的实际情况，研究制定分区域、分类型的高标准农田投资标准，建立投资标准的动态调整机制，适时分阶段逐步提高投资标准。

三、关于将高标准农田建设项目向六安大别山革命老区倾斜支持

农业农村部一直以来高度重视贫困地区和革命老区的农田基础设施建设，不断加大对相关地区的倾斜力度。2019年，在安排高标准农田建设任务和资金时，我部把脱贫攻坚作为重要因素，在资金分配上予以倾斜支持。安徽省应根据农田建设项目相关规定，积极落实地方共同投入财政资金，在确保年度任务完成的基础上，在任务分解和资金安排中，可优先向包括六安大别山革命老区在内的贫困地区予以倾斜。

下一步，我们将结合支持脱贫攻坚工作，在已明确放宽贫困地区农田建设项目建设标准和立项规模，允许各省根据实际情况适当提高贫困地区高标准农田建设投资标准的基础上，结合中央财政资金增长情况，不断加大对革命老区的支持力度。

感谢您对农业农村部工作的关心，希望今后继续支持我部工作！

农业农村部

2019年9月19日
