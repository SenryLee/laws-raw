# 交通运输部办公厅关于公布2018年度交通运输标委会秘书处考评情况的通知

交办科技函〔2019〕365号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），交通运输各专业标准化技术委员会、计量技术委员会，部属各单位，部内各司局：

按照《交通运输标准化技术委员会秘书处考核评价办法》（交办科技〔2015〕185号）和《交通运输部办公厅关于开展2018年度交通运输标准化技术委员会秘书处考评工作的通知》（交办科技函〔2019〕81号）的有关要求，部组织对部管理的20个全国、行业专业标准化技术委员会、计量技术委员会（以下简称标委会）秘书处进行了考评，地方交通运输主管部门、部有关司局和标委会委员参加了考评工作。现将考评情况通报如下：

标委会秘书处考评成绩在90分以上的11个，80～89分的有8个，80分以下的1个。根据考评情况，评选出交通运输航测标准化技术委员会、交通运输救捞与水下工程标准化技术委员会和全国起重机械标准化技术委员会臂架起重机分技术委员会的秘书处为优秀，全国汽车标准化技术委员会挂车分技术委员会等17个标委会秘书处为合格（名单附后）。

希望有关单位特别是考评成绩下降的标委会，对照此次考评的结果，找出工作中存在的问题和差距，提出改进方案，进一步提高标准化工作效率，提升标准化服务能力和水平。

交通运输部办公厅

2019年3月14日
