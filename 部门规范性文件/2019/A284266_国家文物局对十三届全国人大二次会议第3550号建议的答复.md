# 国家文物局对十三届全国人大二次会议第3550号建议的答复

文物保函〔2019〕664号

郭永红代表：

您提出的“关于建设中国（随州）编钟音乐之都的建议”收悉，经商文化和旅游部、中国文联、中央广播电视总台、教育部，现答复如下。

一、关于支持随州文物保护与利用、支持创建国家考古遗址公园及申报世界文化遗产

擂鼓墩古墓群位于湖北省随州市曾都区，已探明古墓七十余座，1978年发掘的曾侯乙墓是其中最大的一座。该墓保存完好，出土文物七千多件，器类繁多，造型、工艺均很精妙。其中大批乐器，品类齐全，特别是六十四件青铜编钟，可演奏古今中外多种乐曲，音色优美。

安居遗址于1957年文物普查时发现。通过实地勘探验证确认，安居遗址的东部保存有一座小城，南北长190米、东西宽170米。城墙东、北、西三面保存较好，夯筑。城址高出地面约1米，城墙宽约10米，墙外有护城河，宽约10米，深度距地表约2米以上。根据遥感提供的情况及地形地貌推测，小城北有大城存在。安居遗址的发现，为确定古曾（随）国都城地望提供了重要信息，对解决曾（随）之迷有重要历史价值和学术价值。

我局积极支持擂鼓墩古墓群和安居遗址的保护工作，先后报请国务院公布为全国重点文物保护单位。历年来，通过国家重点文物专项补助资金，对擂鼓墩古墓群和安居遗址的考古发掘、规划编制、资料整理、文物保护、报告出版等给予了近四千万元的支持。

近年来，世界遗产申报工作的难度逐渐加大。根据世界遗产委员会新施行的“限额制”，一个缔约国每年最多只能申报一项世界遗产。同时，世界遗产委员会不断推进世界遗产均衡性的全球战略，明确向没有世界遗产或世界遗产较少的国家，以及遗产类型较少的类别倾斜，而对世界遗产大国的限制则不断增多。

我国是世界遗产大国，目前拥有世界遗产55项，其中文化遗产37项，居世界第一。世界遗产中心和国际古迹遗址理事会等专业咨询机构对我国等世界遗产大国的申报项目，往往提出更高的标准。按照《保护世界文化和自然遗产公约》及其《操作指南》的规定，申报世界文化遗产的项目，应该具有全世界范围内的突出普遍价值，较好的保存现状，真实性和完整性较高，扎实的保护管理基础，以及利益相关者对遗产保护的积极态度。这都要求我国的申报项目要在各方面做好充分的准备。

目前曾侯乙墓遗址申遗基础工作相对薄弱。我局将加强指导当地政府和文物行政部门，深化对曾侯乙墓遗址的突出普遍价值的研究和提炼，明确遗产定位，清晰阐述其符合的世界文化遗产标准，并与国内外同类型遗产进行深入对比分析；进一步促进保护管理机构建设和管理能力提高，制订颁行切实有效的法律法规，妥善保护遗产本体，并注重与利益相关者的沟通协调。

我局积极支持推进擂鼓墩考古遗址公园建设，并愿为随州市博物馆事业的发展提供指导和支持。

我局将按照《国家文物保护专项资金管理办法》的规定，在考古发掘、文物修缮、环境整治等方面，继续对擂鼓墩古墓群和安居遗址给予尽可能的资金支持。在条件成熟后，可根据当地政府申请，考虑将曾侯乙墓遗址列入《中国世界文化遗产预备名单》。

二、关于支持将中国（随州）编钟音乐之都纳入国家重点文化建设项目

文化和旅游部关注随州编钟音乐文化创意产业园建设，建议当地政府部门充分发挥主体作用，立足区域文化产业发展，高起点、高水平开展规划建设工作，并积极对接和用好用足各项已有政策，为园区建设创造更为有利的条件。关于中国（随州）编钟音乐节，因未在湖北省保留的节庆活动中，如确需举办，须按程序进行报批。

三、关于支持编钟文化传播及人才培养

教育部鼓励有条件的地方探索开展编钟文化教育，建议湖北省按照高校设置有关政策法规要求，对学校的性质、办学基础、组建路径和必要性进行认真研究论证，也可充分利用省内现有高等教育资源，通过设立二级学院、研究院等形式加强编钟文化传播人才培养。

中央广民广播电视总台央视音乐频道将积极挖掘随州编钟音乐节目资源，适时在频道播出；中央人民广播电台将加强与随州有关部门的沟通、合作，通过广播和新媒体平台，推出新闻报道、文艺专题等内容，支持编唱编钟主题歌曲、拍摄编钟主题电影、讲述编钟故事，弘扬编钟文化。

衷心感谢您对我国文化遗产工作的关注和支持！

国家文物局
