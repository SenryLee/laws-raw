# 中华人民共和国住房和城乡建设部公告2019年第21号——住房和城乡建设部关于2019年第二批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第21号

## 住房和城乡建设部关于2019年第二批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，王双等54名申请注册土木工程师（岩土）初始注册人员、陈敏等52名申请一级注册结构工程师初始注册人员、杨玉芳等88名申请注册公用设备工程师初始注册人员、刘艳等24名申请注册电气工程师初始注册人员、牛娅丽等12名申请注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予王双等54名注册土木工程师（岩土）初始注册人员名单

2.准予陈敏等52名一级注册结构工程师初始注册人员名单

3.准予杨玉芳等88名注册公用设备工程师初始注册人员名单

4.准予刘艳等24名注册电气工程师初始注册人员名单

5.准予牛娅丽等12名注册化工工程师初始注册人员名单

住房和城乡建设部

2019年2月11日
