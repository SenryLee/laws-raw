# 国家核安全局关于公布2018年注册核安全工程师执业资格全国统一考试合格人员名单的通知

## 关于公布2018年注册核安全工程师执业资格全国统一考试合格人员名单的通知

环办核设函〔2019〕428号

各有关单位：

根据《注册核安全工程师执业资格制度暂行规定》（人发〔2002〕106号）和人力资源社会保障部人事考试中心公布的2018年度注册核安全工程师资格考试合格标准，现将251名合格人员名单予以公布（见附件）。

附件：2018年注册核安全工程师执业资格全国统一考试合格人员名单

生态环境部办公厅

2019年4月26日
