# 农业农村部对十三届全国人大二次会议第8395号建议的答复

## 对十三届全国人大二次会议第8395号建议的答复

农办议〔2019〕350号

您提出的关于新形势下西部贫困地区脱贫攻坚农业产业发展的建议收悉。经商科技部、教育部、财政部和国务院扶贫办，现答复如下。

一、关于国家出台政策措施支持贵州打造全产业链系统

我部会同国务院相关部门，围绕农村产业融合发展，延长产业链、提升价值链、打造供应链，促进乡村产业高质量发展。一是加强政策引导。近几年中央一号文件聚焦“三农”工作，部署乡村振兴等重点工作。2018年，中共中央、国务院印发《乡村振兴战略规划（2018—2022年）》，近期，国务院印发《关于促进乡村产业振兴的指导意见》（国发〔2019〕12号），这些重要文件都对促进农村一二三产业融合作了具体安排。二是加强资金支持。2018年，中央财政通过农业生产发展资金，安排财政资金108.19亿元，支持地方发展有优势、有特色的农业主导产业，推动全产业链建设和农村产业融合发展。三是加强平台建设。2019年，全国创建153个农村一二三产业融合发展先导区，认定110个国家农村产业融合发展示范园，建设552个农业产业强镇，认定“一村一品”示范村镇300个。

二、关于重视和加强西部欠发达地区科技扶贫

聚焦打赢脱贫攻坚战，加大力度，强化措施，推进科技扶贫。一是加强人才培养。2014年，科技部等5部门共同启动“边远贫困地区、边疆民族地区和革命老区人才支持计划（科技人员专项）”，支持科技人员服务西部贫困地区农业产业发展。截至2019年，累计向西部贫困地区选派科技人员64624名，为西部贫困地区培养本土科技人员11715名，其中，累计向贵州省选派了7587名科技人员，培养本土科技人员1068名。二是共建科研机构。2012年以来，教育部联合科技部启动高校新农村发展研究院建设工作，分两批建设39所新农村发展研究院，其中西部地区有贵州大学等13所高校。推动清华大学、北京大学、浙江大学等一批部属院校与贵州省签订了省校合作协议，提升贵州省人才培养、教育合作等能力。三是健全技术体系。2018年，我部依托现代农业产业技术体系，选聘贵州科研院所、高校等单位岗位科学家2名，综合试验站站长33名，中央财政资金投入1790万元。涉及水稻、小麦等35个产业，形成了一批适合当地产业发展的新品种新技术新装备。四是推进成果转化。2018年，科技部围绕贫困地区产业发展面临的关键性技术瓶颈问题，向涉农院校和科研机构定向征集先进适用技术成果239项，引进推广新品种新技术64010项，有力支持了贫困地区扶贫产业发展。五是加强示范引导。2017年，科技部启动科技扶贫“百千万”工程。截至2018年底，贫困地区共建设国家农业科技园区61个，推动高校、院所、园区、企业等与贫困地区科技精准帮扶结对2252对，推广新成果9092个。有33969名科技特派员投身贫困地区的科技服务和创业带动，其中，贵州省建设7个国家农业科技园区，结对90对，选派1200余名省市级科技特派员。

三、关于进一步优化农业产业结构调整

我部大力推进农业供给侧结构性改革，提升农业质量效益和竞争力。一是推进种养结构优化。坚持以市场为导向，以融合发展为路径，加快发展粮经饲统筹、种养加一体、农牧渔结合的现代农业，增加紧缺和绿色优质农产品供给。近4年，已调减非优势区籽粒玉米5000万亩，扩大市场紧缺的大豆、杂粮、蔬菜、饲草等作物面积。二是发展特色优势产品。我部正在编制《全国乡村特色产业发展规划（2019—2025年）》，将进一步明确乡村特色产业发展思路目标、重点产品、区域布局、保障措施，引导更多资源、技术向优势区域集中，加快建设一批有特色、有规模、有品牌的乡村特色产业基地或产业集群。三是促进产销对接。今年，我部将在贵州剑河县、云南昭通市等4县市举办4场品牌农产品招商对接活动，促进科企、产企和企企合作，推动贫困地区特色农产品走出大山。

四、关于建立互联网+电商扶贫机制

我部积极推进农业大数据发展和应用，加大农业数据信息资源开放共享力度，推进“互联网+”现代农业。一是推进信息进村入户。先后遴选贵州等18个省（区、市）进行整省推进，为农民和新型农业经营主体提供生产生活信息服务，拉动农村信息消费。截至2018年底，全国共建成益农信息社27.2万个，累计培训村级信息员78.6万人次，提供公益服务9579万人次，便民服务3.14亿人次，实现电子商务交易额244亿元。二是加强产品信息发布。2017年11月，重点农产品市场信息平台正式开通运行，建立了“一网打尽”式市场信息发布服务窗口，为农业生产经营主体和公众提供权威、全面、及时、有效的市场信息服务。目前，平台上报每日价格数据230多万条，电子交易结算数据2923万条，接入各类数据约20亿条，每天新增数据10多万条。三是拓展12316“三农”综合服务。从2006年电话咨询起步，12316不断开辟服务渠道、创新服务方式、丰富服务内容，已发展成为集热线电话、网站、电视节目、广播、手机短彩信、手机APP、微博、微信等服务于一体，面向全国、服务“三农”的权威综合信息服务平台。目前，服务对象超过70万人，12316平台全年发送短彩信3000万条，监管平台累计知识库、案例库数据超过310万条。四是推介电商扶贫典型。近些年，征集编印《“互联网+”现代农业百佳实践案例》和《新农民创业创新百佳成果》，认定了两批210个全国农业农村信息化示范基地。

五、关于完善利益联结机制

我部按照中央部署，加快推进农村产业融合发展，健全利益联结机制，带动农民就业增收、脱贫攻坚。一是创新组织方式。推行“农户+家庭农场+合作社+公司”以及“公司+合作社+家庭农场+农户”等模式，发展龙头企业牵头、新型经营主体跟进、广大小农户参与的农业产业化联合体，实现小农户与现代农业发展有机衔接。二是完善利益联结机制。积极发展契约型、分红型、股权型合作模式，推介“保底收益+按股分红”等模式，鼓励将财政补助资金折股量化到农民专业合作社成员或农户，让农民更多分享产业链增值收益。

下一步，我部将贯彻落实《国务院关于促进乡村产业振兴的指导意见》，以实施乡村振兴战略为总抓手，以农业供给侧结构性改革为主线，围绕农村一二三产业融合发展，聚集资源要素，强化创新引领，加快构建乡村产业体系，为全面建成小康社会、打赢脱贫攻坚战做好有力支撑。

感谢您对农业农村工作的关心，希望继续对我部工作给予支持。
