# 国家市场监督管理总局办公厅关于公布2019年度第一批检验检测机构资质认定评审专家考核结果的通知

## 市场监管总局办公厅关于公布2019年度第一批检验检测机构资质认定评审专家考核结果的通知

市监检测函〔2019〕1805号

各省、自治区、直辖市及新疆生产建设兵团市场监管局（厅、委），各国家资质认定（计量认证）行业评审组，各有关单位：

根据《检验检测机构资质认定管理办法》《检验检测机构资质认定能力评价评审员管理要求》等规定，现将2019年度第一批考核合格的国家级检验检测机构资质认定评审专家名单（见附件）予以公布。

检验检测机构资质认定评审专家名单（含资格暂停、到期、失效），可登录市场监管总局网站（www.sarm.gov.cn）“服务”—“我要查”—“认证认可检验检测”栏目中的“国家级资质认定评审员名录”查询。

附件：2019年度第一批考核合格的国家级检验检测机构资质认定评审专家名单

市场监管总局办公厅

2019年9月18日
