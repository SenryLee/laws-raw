# 中华人民共和国农业农村部公告第206号——关于批准梅里亚有限公司（美国）等3家公司生产的鸡传染性法氏囊病病毒火鸡疱疹病毒载体活疫苗等3种兽药产品在我国再注册、批准台湾永光化学工业股份有限公司第二厂生产的氯前列醇钠在我国再注册的公告

根据《农业农村部关于批准爱尔兰Univet生产厂等5家公司生产的5种兽药在我国再注册、变更注册的公告》（农业农村部公告第782号），本法规中鸡传染性法氏囊病病毒火鸡疱疹病毒载体活疫苗（vHVT-013-69株）的质量标准、说明书和标签失效。

## 中华人民共和国农业农村部公告

第206号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准梅里亚有限公司（美国）等3家公司生产的鸡传染性法氏囊病病毒火鸡疱疹病毒载体活疫苗等3种兽药产品在我国再注册，核发《进口兽药注册证书》；批准台湾永光化学工业股份有限公司第二厂生产的氯前列醇钠在我国再注册，核发《兽药注册证书》，并发布修订后的产品质量标准、说明书和标签，自发布之日起执行。此前发布的上述产品兽药质量标准、说明书和标签同时废止。
