# 生态环境部办公厅关于做好全国碳排放权交易市场发电行业重点排放单位名单和相关材料报送工作的通知

## 关于做好全国碳排放权交易市场发电行业重点排放单位名单和相关材料报送工作的通知

环办气候函〔2019〕528号

各省、自治区、直辖市生态环境厅（局），新疆生产建设兵团生态环境局：

根据《中华人民共和国国民经济和社会发展第十三个五年规划纲要》和《生态文明体制改革总体方案》，为落实《全国碳排放权交易市场建设方案（发电行业）》有关要求，确定全国碳排放权交易市场发电行业重点排放单位名单，做好配额分配、系统开户和市场测试运行的准备工作，现组织开展全国碳排放权交易市场发电行业重点排放单位（以下简称发电行业重点排放单位）名单和相关材料报送工作。有关事项通知如下。

一、报送本地区发电行业重点排放单位名单

此次发电行业重点排放单位报送范围为发电行业2013至2018年任一年温室气体排放量达到2.6万吨二氧化碳当量（综合能源消费量约1万吨标准煤）及以上的企业或者其他经济组织，对应的国民经济行业分类代码（GB/T4754-2017）包括4411火力发电、4412热电联产、4417生物质能发电等。

2013至2018年任一年温室气体排放量达到2.6万吨二氧化碳当量及以上的自备电厂（参照上述年份历史碳排放核算报告与核查中自备电厂的划定范围）视同发电行业重点排放单位进行报送。

请梳理本地区符合条件的发电行业重点排放单位名单，填写并报送全国碳排放权交易市场发电行业重点排放单位名单省级汇总表（excel格式，参考附件1）。

二、确定全国碳排放权注册登记系统专责省级管理员并报送开户材料

请从你单位确定2名全国碳排放权注册登记系统的专责省级管理员，并按照开户申请表要求报送全国碳排放权注册登记系统开户申请表（省级主管部门）和省级管理员身份证明复印件等相关材料（纸质件和pdf格式，参考附件2）。

三、报送全国碳排放权注册登记系统和交易系统发电行业重点排放单位开户材料

请按照附件要求，组织本地区发电行业重点排放单位确定其在全国碳排放权注册登记系统和交易系统的账户代表人和联系人，并报送全国碳排放权注册登记系统开户申请表（重点排放单位）和全国碳排放权交易系统开户申请表（重点排放单位）及相关附件材料（纸质件和pdf格式，其中申请表各1份，附件材料各1套，参考附件3、4、5和6）。

请在完成本地区全部上述材料的收集后，按照附件7要求于2019年7月19日前将电子版材料报送我部应对气候变化司，纸质件材料寄送至国家应对气候变化战略研究和国际合作中心（以下简称国家气候战略中心）。

请将工作中存在的问题和建议及时反馈我部。
