# 国家文物局关于景风阁古建筑群保护范围和建设控制地带内保护利用设施建设项目的意见

文物保函〔2019〕153号

云南省文物局：

你局《关于请求对景风阁古建筑群保护利用设施建设项目设计方案进行再次审核的请示》（云文物〔2018〕205号）收悉。经研究，我局原则同意在景风阁古建筑群保护范围内进行保护利用设施建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）完善文物影响评估报告，进一步明确拟建项目与景风阁保护区划的位置关系。

（二）优化建筑设计，减小管理用房进深，缩小建筑体量，并降低厕所高度。

（三）补充地面铺装的设计依据，建议采用传统材质和形式。

（四）补充大门围墙的设计图纸及相关内容。

（五）施工期间应做好对文物本体的防护措施，控制粉尘及施工垃圾等对文物本体及环境的污染，确保文物安全。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月14日
