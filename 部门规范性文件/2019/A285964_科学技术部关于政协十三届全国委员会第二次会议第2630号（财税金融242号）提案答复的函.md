# 科学技术部关于政协十三届全国委员会第二次会议第2630号（财税金融242号）提案答复的函

## 关于政协十三届全国委员会第二次会议第2630号（财税金融242号）提案答复的函

国科提案资〔2019〕第54号

您提出的《关于进一步改进科研经费管理方式的提案》收悉。经认真研究，现答复如下。

一、关于简化预算编制与管理

您的建议十分中肯。科学合理的科研经费管理制度，对于鼓励科技创新，为科研人员创造更为宽松的科研环境起到了十分重要的作用。为贯彻落实《国务院关于优化科研管理提升科研绩效若干措施的通知》（国发〔2018〕25号，以下简称25号文）等文件精神，科技部会同财政部于2019年发布了《关于进一步优化国家重点研发计划项目和资金管理的通知》（国科发资〔2019〕45号，以下简称45号文）,提出了简化预算编制等改革要求，明确了会议费/差旅费/国际合作交流费预算低于10%的，无需提供测算依据；超过10%的，分类说明，但无需对每次会议、差旅做单独的测算和说明。针对预算调整，45号文进一步扩大预算调剂权限，对直接费用实行分类总额管理，在设备费之外分两类进行预算管理，其中，将材料费、测试化验加工费、燃料动力费、出版/文献/信息传播/知识产权事务费等四个科目按一类管理；将劳务费、专家咨询费、会议费/差旅费/国际合作交流费、其他支出等四个科目按一类管理。两类之间预算调剂由承担单位履行内部审批程序；同一类预算额度内，承担单位可结合实际情况进行审批或授权课题负责人自行调剂使用。这些改革要求已在2019年项目管理中实行。

此外，科技部会同财政部等部门正在开展简化预算编制“绿色通道”试点，在满足基本管理要求前提下，进一步简化、优化预算编制，2019年6月，已向专业机构发布了国家重点研发计划经费管理有关试点方案的通知，将尽快在2019年符合条件的项目申报中试行。

二、关于基础研究项目结余经费

2014年，财政部、科技部共同研究起草并由国务院印发了《关于改进加强中央财政科研项目和资金管理的若干意见》（国发〔2014〕11号，以下简称国发11号文）。文件首次提出，符合条件的结余资金可在一定时期内留归单位使用。此举改变了以往科技计划项目结余经费全额收回的“一刀切”管理模式。这一改革的总体思路，一是结余资金的留用应综合考虑项目任务目标完成情况和资金使用规范性等因素，建立激励与约束并重的管理机制；二是留用的结余资金应综合考虑使用效益。文件发布以后，现行的国家自然科学基金、国家科技重大专项、国家重点研发计划均按照新政策执行。

为进一步强化源头创新，加强基础研究，2019年《政府工作报告》中提出，“进一步提高基础研究项目间接经费占比，开展项目经费使用‘包干制’改革试点，不设科目比例限制，由科研团队自主决定使用”。这一重大改革，引起了社会高度关注、广泛热议，科技部会同财政部、自然科学基金委认真研究“包干制”的限定范围、实施条件、具体要求、预期目标等，拟在国家自然科学基金定额补助类项目中试点“包干制”，以信任为前提，以监督为保障，赋予创新团队和领军人才更大的人财物支配权和技术路线决策权。目前，自然科学基金委正在积极推进试点工作。

同时也要看到，通过对2010-2017年数据统计分析，结余资金有逐年增大的趋势。资金的沉淀、分散，不利于统筹用于国家急需资金支持的重点关键领域攻关，势必影响财政科技投入的时效性和整体使用效益；特别是在当前国家财政形势紧张的背景下尤为凸显。为此，对于科技计划特别是经费体量较大的科研经费，要更加关注资金使用效率问题。此外，为保证持续稳定支持创新活动，中央财政每年安排高校、科研院所一定规模稳定性科研经费（如基本科研业务费等），用以保障单位自主选题、长期研究、持续攻关等工作开展。下一步，科技部将会同财政部、教育部等部门深入研究，继续探索完善中央财政竞争性和稳定性科研经费相协调的机制，建立既有利于聚焦国家目标、发挥举国体制优势的资源配置机制、又兼顾构建稳定且充满活力的科研环境，为广大科研人员安心科研，创造更多的资源和条件。

三、关于下拨科研经费

您所提到的科研经费下拨滞后现象我们高度关注。2012年，财政部建立了科研经费预拨制度，即部门预算批复前，列入新年度部门预算的项目，可以按支出功能分类科目“一下”预算控制数的1/4左右编报用款计划，办理拨款手续。国发11号文进一步明确实行资金预拨机制，以满足科研单位年初经费需求，保障科研任务顺利实施。

同时，进一步完善科技经费管理信息化建设，加强与财政国库衔接，试点科技计划经费网上拨付，尽量缩短经费拨付时间，保障经费及时到位。但在落实过程中，确有一些项目由于种种原因，存在经费到账时间偏晚的情况。下一步，科技部将会同有关部门加强对相关工作的督促和检查，查找经费拨付中的堵点，进一步完善拨付机制，确保经费及时足额到位。

非常感谢您对科技工作的支持！科技部将会同有关部门，持续优化科技资源配置，不断完善科研项目资金管理，激励科研人员潜心研究、追求卓越、多出成果，在提升原始创新能力和攻坚克难方面作出更大贡献。
