# 国务院扶贫办关于进一步加强廉洁扶贫阳光扶贫的通知

各省、自治区、直辖市和新疆生产建设兵团扶贫办（局）：

近年来，各地陆续查处了一些扶贫干部甚至领导干部以权谋私、违纪违法的案件，有的情节恶劣、性质严重，侵害贫困群众利益，损害脱贫攻坚声誉，干扰脱贫攻坚大局，教训极其深刻。各级扶贫部门要引以为鉴、举一反三，采取坚决措施，持之以恒抓好扶贫系统反腐倡廉工作，进一步加强廉洁扶贫阳光扶贫，切实维护党和政府形象、维护脱贫攻坚的形象，为如期全面完成脱贫攻坚任务提供坚强保证。

一、旗帜鲜明反对腐败，坚决查处违纪违法行为。脱贫攻坚是光荣神圣的事业，是一项极其严肃、极其重大的政治任务。扶贫系统的任何腐败现象，都会影响脱贫攻坚质量，严重损害脱贫攻坚声誉，必须从讲政治的高度旗帜鲜明坚决反对。坚持无禁区、全覆盖、零容忍，对扶贫系统发生的违纪违法行为，要坚决严肃查处，绝不姑息。

二、切实加强权力管控，严防发生不正之风和腐败问题。要加强对权力运行的监督制约，深化行政改革，健全内控机制，完善制度规章，形成监管合力，把权力关进制度笼子，防止滥用权力。要紧盯扶贫资金项目监管、扶贫资产管理、产业扶贫、社会扶贫、考核评估等重点工作和关键环节，严格落实“三重一大”等各项制度，规范工作流程，查找廉洁风险，构筑制度防线，最大限度减少违纪违法问题的发生。

三、认真开展警示教育，充分发挥查处一案警示一片的作用。要结合扶贫系统发生的腐败案件，认真开展警示教育，用“身边事”教育“身边人”，以案示法、以案明理，防微杜渐、警钟长鸣，教育引导广大扶贫干部举一反三、自省自警，在行使权力上慎之又慎，在自我约束上严之又严，知敬畏、存戒惧、守底线，永葆为民务实清廉的政治本色，清清白白为官、干干净净做事、老老实实做人。

四、主动深刻检视问题，切实防范脱贫攻坚风险隐患。坚持问题导向，以刀刃向内的自我革命精神，认真检视在学习贯彻习近平总书记关于扶贫工作的重要论述和重要指示批示精神方面存在的差距，主动查找在脱贫攻坚责任落实、政策落实、工作落实中存在的问题，高标准严要求，把问题找全，把根源挖深。针对查找出来的问题和薄弱环节，研究提出改进工作、严格管理的有效措施，关口前移、抓早抓小，积极化解风险，坚决消除隐患，确保脱贫攻坚各项工作健康发展。

五、严格落实主体责任，把全面从严治党贯穿脱贫攻坚全过程各环节。各级扶贫部门党组织要切实担负起全面从严治党、推进党风廉政建设和反腐败斗争的主体责任，持续推进扶贫领域腐败和作风问题专项治理。坚持严字当头，把纪律挺在前面，深化运用监督执纪“四种形态”，严肃查处违纪违法行为，切实加强对党员干部全方位的管理监督。坚持预防在先，大力加强廉政文化建设，一体推进不敢腐、不能腐、不想腐，把全面从严治党贯穿脱贫攻坚全过程各环节，阳光扶贫、廉洁扶贫。

脱贫攻坚是“不忘初心、牢记使命”的生动体现，扶贫系统广大干部特别是领导干部要不断增强责任感、使命感、荣誉感，认真汲取扶贫系统腐败案件的教训，强化宗旨意识，坚守法纪底线，自觉筑牢拒腐防变的思想道德防线，谨慎用权、干净用权，创新担当、主动作为，在全面打赢脱贫攻坚战中不断作出新贡献。

国务院扶贫办

2019年7月11日
