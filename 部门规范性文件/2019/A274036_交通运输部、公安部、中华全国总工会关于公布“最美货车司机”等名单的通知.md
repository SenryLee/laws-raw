# 交通运输部、公安部、中华全国总工会关于公布“最美货车司机”等名单的通知

## 交通运输部　公安部　中华全国总工会关于公布“最美货车司机”等名单的通知

交运函〔2019〕60号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）、公安厅（局）、总工会：

为展现货车司机风采，营造关爱货车司机的社会舆论氛围，提升货车司机的职业归属感和荣誉感，促进道路货运行业健康稳定发展，交通运输部、公安部、中华全国总工会联合开展了“最美货车司机”推选宣传活动。经过报名推荐、专家初选、公示投票、专家终审等程序，确定丁志健等96名个人为“最美货车司机”，其中王喜军等10名个人为“十大最美货车司机”；确定浙江省交通运输厅等12家单位为“最美货车司机”推选宣传活动组织贡献单位。

我国道路货运行业从业人员约2100万，占交通运输从业人员总数的70%以上，长期以来为保障和改善民生、推动经济社会发展作出了重要贡献。各地交通运输主管部门、公安部门、工会组织要以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大精神，以此次活动为契机，进一步加强“最美货车司机”的宣传，加大对货车司机群体的关注与关爱，逐步形成全社会关爱货车司机群体的良好氛围。希望广大货车司机以“最美货车司机”为榜样，弘扬奋斗精神、奉献精神、创新精神，传递行业正能量，爱岗敬业，忠于职守，争当新时代“最美货车司机”，为建设交通强国、决胜全面建成小康社会、实现中华民族伟大复兴的中国梦贡献力量。

附件：1.“最美货车司机”名单

2.“十大最美货车司机”名单
