# 农业农村部对十三届全国人大二次会议第7431号建议的答复

## 对十三届全国人大二次会议第7431号建议的答复

农办议〔2019〕373号

龚定荣代表：

您提出的关于实施乡村振兴战略中把农民留在农村的建议收悉。经商银保监会、税务总局、自然资源部和教育部，现答复如下。

一、关于发展乡村产业留住乡村人才

近年来，我部引导各地大力发展乡村产业，拓展农民就业增收渠道，让更多的农民在乡"立得住".一是把乡村产业更多留在乡村。今年6月，国务院印发了《关于促进乡村产业振兴的指导意见》（以下简称《意见》），提出要突出资源优势，重点发展现代种养业、乡土特色产业、农产品加工流通业、乡村休闲旅游业、乡村新型服务业、乡村信息产业等。2018—2019年，我部通过中央财政安排农业生产发展资金108.19亿元，用于支持一二三产业融合和优势特色主导产业发展。二是把就业岗位更多留给农民。《意见》提出，要充分发掘乡村功能价值，引导加工流通企业重心下沉，向有条件的中心镇和物流节点集中。近年来，农业农村部门支持各地建设了1600多个农产品加工园区（基地）。2018—2019年，共安排中央财政资金60亿元，建设552个集标准原料基地、集约加工转化、紧密利益联结于一体的农业产业强镇，把更多的就业岗位留给农民，吸引青壮年劳动力返乡创业就业。三是把产业链增值收益留给农民。2018年，中共中央、国务院印发《乡村振兴战略规划（2018—2022年）》，提出"加快培育农商产业联盟、农业产业化联合体等新型产业链主体".2018年，我部已在全国10个省开展联农带农紧密的农业产业化联合体示范创建，认定省级产业化联合体近1000个，通过融合发展等多种方式，让农民有业就、有活干、有钱挣，促进农民增收。2019年，我部会同财政部继续支持农业产业化联合体建设，并纳入农业生产发展资金项目支持范围。

下一步，我部将以贯彻落实《意见》为抓手，延伸产业链、提升价值链、打造供应链，把立农、为农、兴农的产业都留在乡村，改变过去农村搞种养、城市搞加工流通的分工格局，促进乡村产业振兴。

二、关于培养高素质农民推进乡村振兴

近年来，我部会同国务院相关部门加强农民职业培育培训，为乡村振兴提供人才支撑。一是实施高素质农民培育工程，提高农业经营主体综合能力。教育部不断加强职业教育，推进中等职业教育和职业技能培训全覆盖，逐步实现免费中等职业教育。支持和鼓励职业院校和涉农部门合作，共同培养高素质农民，目前已有10余个省份出台了有关高素质农民培养的实施方案，8个省市已启动相关工作，今年将有就读职业院校农民学生毕业。2018年，中央财政通过农业生产发展资金安排20亿元，大力实施新型农业经营主体带头人轮训计划和现代青年农场主培养计划，开展农村实用人才带头人培训。建立农业行政主管部门负责管理，农民科技教育培训中心、农民合作社、农业产业化龙头企业、农业科研院校等各类市场主体参与的多元培育机制。二是开展创业培训，提升创业者创业能力。党中央、国务院高度重视返乡农民工创新创业，将培育返乡创业人才当作推动乡村振兴的重要抓手。强化创业导师培训，教育部积极推动高校聘请各行业优秀人才担任创新创业教育专、兼职教师，组建了全国万名优秀创新创业导师人才库。强化创业人员培训。2016年，人力资源社会保障部会同我部等有关部门下发《关于实施农民工等人员返乡创业培训五年行动计划（2016—2020年）的通知》（人社厅发〔2016〕90号），大力开展更具针对性和有效性的创业培训。2018年，国务院出台了《关于推行终身职业技能培训制度的意见》（国发〔2018〕11号）。2018年全国开展返乡创业培训67万人次，有力地服务了农民工等人员返乡创业。目前，人力资源社会保障部门认定扶持的以返乡创业农民工为主要服务对象的基地达1037个，已成为发挥创业孵化载体功能、集中提供创业服务的重要阵地。

下一步，我部将会同有关部门继续推进高素质农民培育工程及农村职业教育和成人教育示范县创建工作，进一步加大涉农专科高等职业院校培养适应科技进步和农业产业化需要的学生和高素质农民力度。

三、关于引进人才推进乡村振兴

近年来，我部加强返乡入乡创新创业人才培养，培育乡村产业振兴新动能。一是引进一批返乡创业人才。2015年，国务院办公厅印发《关于支持农民工等人员返乡创业的意见》，从降低创业门槛、落实定向减免和普遍性降费政策、加大财政支持力度、强化返乡创业金融服务、完善返乡创业支持政策等方面，支持农民工返乡创业。2016年，国务院办公厅印发《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》，进一步完善支持返乡下乡创业政策措施。2018年，国务院印发《关于推动创新创业高质量发展打造"双创"升级版的意见》，进一步提出深入推进农民工返乡创业试点、发挥创业担保贷款的作用、安排一定比例年度土地利用计划专项支持等措施，支持农民工等人员返乡创业。二是发掘一批乡土能工巧匠。遴选一批乡土特色人才、能工巧匠、传统技艺传承人、种养大户、高级技能人才、"土专家""田秀才"和种植养殖能手等，加大培育力度，开展广泛宣传推介，保护传统工艺，促进乡村特色文化产业发展。

下一步，我部将组织实施农村创新创业"百县千乡万名带头人"培育行动，计划到2020年底培训农村创新创业人员40万人；用3—5年时间，建立百名国家级、千名省级和万名市级农村创业导师专家指导团队，依托专家团队、孵化实训基地和农业产业化龙头企业等，加大创业培训和职业技能培训力度。

感谢您对"三农"事业发展的关心，希望继续对我部工作给予支持。
