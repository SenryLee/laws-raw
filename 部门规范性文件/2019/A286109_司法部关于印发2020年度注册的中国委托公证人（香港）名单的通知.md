# 司法部关于印发2020年度注册的中国委托公证人（香港）名单的通知

司发通〔2019〕125号

各省、自治区、直辖市司法厅（局），新疆生产建设兵团司法局：

根据《中国委托公证人（香港）管理办法》的规定，我部经审查，决定对林汉武等444名中国委托公证人（香港）予以2020年度注册。现将2020年度注册的中国委托公证人（香港）名单印发你们。请即转各地司法局、各公证处，作为受理中国委托公证人办理的涉港公证文书核验的依据。

附件：中国委托公证人（香港）2020年度注册名单（444名）

司法部

2019年12月27日
