# 国家文物局办公室关于重庆巴人文物建筑工程有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕535号

重庆市文物局：

你局《关于变更文物保护资质证书营业住所的请示》（渝文物〔2019〕104号）收悉。

经研究，我局同意重庆巴人文物建筑工程有限公司文物保护工程施工一级资质证书中的单位地址由“渝中区地母亭1-14-8号”变更为“重庆市渝中区枇杷山正街109号13-9”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年6月17日
