# 公开市场业务交易公告[2019]第250号——关于以利率招标方式发行了2019年第十二期央行票据的公告

## 公开市场业务交易公告

[2019]第250号

人民银行于本周五（12月20日）通过香港金融管理局债务工具中央结算系统（CMU）债券投标平台，以利率招标方式发行了2019年第十二期央行票据。具体情况如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 发行量  （人民币） | 期限 | 中标利率 |
| 2019年第十二期央行票据（香港） | 100亿元 | 6个月  （182天） | 2.90% |

中国人民银行公开市场业务操作室

二〇一九年十二月二十日
