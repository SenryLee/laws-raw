# 中华人民共和国海事局公告2019年第23号——中华人民共和国海事局关于发布《内河船舶法定检验技术规则（2019）》的公告

## 中华人民共和国海事局公告

2019年第23号

## 中华人民共和国海事局关于发布《内河船舶法定检验技术规则（2019）》的公告

《内河船舶法定检验技术规则（2019）》按规定程序已经交通运输部批准，现予公布，自2020年6月1日起实施。

《内河船舶法定检验技术规则（2019）》电子版可在中华人民共和国海事局网站（http://www.msa.gov.cn）通知公告栏目下载，纸质版将由人民交通出版社股份有限公司发行（联系电话：010-64981400）。

特此公告。

2019年11月13日
