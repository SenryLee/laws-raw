# 国家文物局关于古井贡酒酿造遗址保护规划的意见

文物保函〔2019〕210号

安徽省文化和旅游厅：

原安徽省文物局《关于再次上报<古井贡酒酿造遗址保护规划>的请示》（皖文物〔2018〕88号）收悉。经研究，我局原则同意所报规划。

一、所报规划应作以下必要修改和完善：

（一）深化考古资料梳理和历史沿革研究，明确不同时期遗存的传承关系，清代窖池群应列入文物构成。结合本地酿酒历史及古井贡酿造技艺研究，分析历史环境特征，明确历史环境要素与范围。

（二）应明确影响文物安全的主要因素，有针对性研提遗址保护措施，并兼顾酒厂生产和发展需要，慎重论证地下水治理的必要性和可行性。

（三）保护区划调整应统筹考虑文物分布、日常保护管理需要，保护范围应尽量确保传统酿酒生产活动空间的完整性；建设控制地带应强调与遗址的关联性、协调性和可操作性，补充说明限高9米的依据，补充其他建设控制指标。

（四）完善专项规划内容，文体馆、家属楼等紧邻文物本体的不协调建筑，应提出整治措施和要求；落实地方文物部门和酒厂的保护管理责任。

（五）调整规划分期，合理安排近期项目数量，避免内容重复。规范图文表达。

二、请你厅指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将古井贡酒酿造遗址保护规划报请安徽省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你厅指导和协调地方人民政府在保护规划的指导下，进一步做好古井贡酒酿造遗址文物保护的各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年2月28日
