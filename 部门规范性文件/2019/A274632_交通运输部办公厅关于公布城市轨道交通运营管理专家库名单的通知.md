# 交通运输部办公厅关于公布城市轨道交通运营管理专家库名单的通知

交办运〔2019〕25号

各省、自治区、直辖市交通运输厅（局、委），部属各单位，部内各司局：

为充分发挥专家队伍在城市轨道交通运营管理工作中的决策咨询和智力支撑作用，根据城市轨道交通系统专业性、技术性强的特点，经交通运输部同意，组织甄选有专业特长、经验丰富、在行业有影响力的42位专家，成立城市轨道交通运营管理专家库（以下简称专家库），现予以公布。

各级交通运输主管部门可在专家库选请专家，参与城市轨道交通发展研究、政策制定、安全评估监督、应急处置等运营安全管理相关工作。专家队伍要准确把握城市轨道交通发展新形势、新任务、新要求，认真履行职责，发挥专业优势和技术特长，积极参与有关工作，为推进城市轨道交通安全运营、优质服务、高质量发展贡献智慧和力量。专家所在单位应给予支持配合，为专家参与相关工作提供便利条件。
