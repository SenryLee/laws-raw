# 自然资源部办公厅关于开展第二批节地技术和节地模式案例征集工作的通知

自然资办函〔2019〕66号

各省、自治区、直辖市自然资源主管部门，新疆生产建设兵团自然资源主管部门：

为贯彻落实《中华人民共和国国民经济和社会发展第十三个五年规划纲要》明确提出的“推广应用节地技术和节地模式”要求，推进生态文明建设，推动高质量发展，拟在全国范围内组织开展第二批节地技术和节地模式案例征集工作。现将有关事项通知如下：

一、征集范围

有关规划设计和用地单位、企业在项目规划设计和建设中使用，节地效果明显，并具有先进性、示范性、代表性特征，具备良好应用前景和推广价值的节地技术和节地模式案例。重点聚焦在以下六个方面：一是支持教育、养老、医疗、文化、体育、现代服务业和公益设施等社会服务项目开发建设的典型案例；二是城镇低效用地再开发、存量建设用地盘活利用方面的典型案例；三是推动农村一二三产业融合发展、促进乡村振兴的典型案例；四是促进新产业、新业态发展的典型案例；五是规划和集中建设片区制冷设施等节约能源节约用地的典型案例；六是地上地下空间综合开发利用等方面的典型案例。

二、报送要求

为规范各地征集填报工作，部制订了《节地技术填报参考格式》和《节地模式填报参考格式》（见附件1、2），请按照格式要求规范填报。上报的节地技术和节地模式案例须是已经投入实践运用、项目建设已完工且不存在违法违规问题、在土地节约集约利用方面成效明显并具有一定的示范性、代表性和可推广性。2016年已上报案例如没有新的重要进展和经验做法，原则上不再重复上报。

请各省（区、市）自然资源主管部门抓紧组织征集工作，指导市、县自然资源主管部门和有关规划设计建设用地单位、企业提炼节地技术和节地模式案例，每个省（区、市）总结3-5个典型案例，于2019年3月31日前将有关材料（含电子版）报自然资源部自然资源开发利用司。
