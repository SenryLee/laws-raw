# 农业农村部关于政协十三届全国委员会第二次会议第1407号（农业水利类131号）提案答复的函

## 关于政协十三届全国委员会第二次会议第1407号（农业水利类131号）提案答复的函

农办案〔2019〕68号

蒙晓灵委员：

您提出的“关于加快完善农村产业利益联结机制，促进脱贫攻坚与实施乡村振兴战略有机衔接的提案”收悉。经商国务院扶贫办、财政部，现答复如下。

一、关于进一步完善扶贫资金投入农村产业发展的管理制度

2015年，财政部出台《关于印发〈扶持村级集体经济发展试点的指导意见〉的通知》，通过以奖代补的形式，支持部分省份开展扶持村级集体经济发展试点工作，探索资源有效利用、提供服务、物业管理、混合经营等多种集体经济实现形式，完善村集体内部管理制度，增强村集体自我发展、自我服务、自我管理能力和水平，有效促进了当地村集体经济发展。2016年，我部联合发展改革委等8部门印发《贫困地区发展特色产业促进精准脱贫指导意见》，明确提出有关财政资金在不改变用途的情况下，投入设施农业、养殖、光伏、水电、乡村旅游等项目形成的资产，具备条件的可折股量化到贫困村和贫困户，并建立健全收益分配机制，确保资产收益及时回馈持股贫困户。2018年，中央组织部、财政部、农业农村部联合印发《关于坚持和加强农村基层党组织领导扶持壮大村级集体经济的通知》，计划到2022年，中央财政在全国范围内扶持10万个左右行政村发展壮大集体经济，健全村党组织领导、村集体经济法人治理、经营运行、收益分配和监督管理等机制，示范带动各地进一步加大政策支持、资金扶持和统筹推进力度。

下一步，我部将积极会同相关部门，进一步强化扶贫财政资金的惠农保底收益，保障农民更多分享增值收益。

二、关于财政补贴贫困户扶贫资金的使用

根据《中共中央、国务院关于打赢脱贫攻坚战的决定》《中共中央、国务院关于打赢脱贫攻坚战三年行动的指导意见》等文件要求，扶贫开发要坚持群众主体，要激发贫困群众的内生动力，要注重培养贫困群众依靠自力更生实现脱贫致富的意识，不断提高贫困地区和贫困人口自我发展能力，避免出现简单的“一分了之”“一股了之”“一兜了之”等直接发钱发物式扶贫。2018年，我部联合发展改革委等8部门印发《关于实施产业扶贫三年攻坚行动的意见》，明确提出整合资金优先用于保障贫困人口直接受益的产业发展资金需求，由贫困县因地制宜确定支持的重点产业项目和重点环节。

下一步，我部将会同相关部门利用扶贫资金加快发展贫困地区特色产业，不断培育和引进龙头企业、农民合作社、家庭农场等带贫新型经营主体，引导带贫企业积极为贫困户提供就业岗位，优先安排贫困户就地就近务工就业，让贫困群众真正参与到产业发展之中，加快实现让贫困户“有收益”向“既有收益又有就业”转变。

三、关于构建农村产业联农带农机制

我部立足贫困地区实际，总结推广订单帮扶、股份合作、园区带动、生产托管、资产收益等带贫模式，指导贫困地区创新和完善利益联结机制，让贫困群众从产业发展中获得实实在在的好处。积极支持龙头企业与贫困户签订购销合同，保障农户合理收益，引导贫困户以土地经营权等资源要素入股龙头企业，以股东身份直接获得经营收益，鼓励龙头企业就近吸纳贫困户务工就业，增加贫困户工资性收入。2017年，总结遴选13个产业扶贫范例，积极推广“龙头企业+合作社+贫困户”等多种带贫模式，有效发挥了示范引导作用。

下一步，我部将会同相关部门进一步加大对龙头企业、合作社、家庭农场等新型经营主体培育力度，提升新型经营主体带动能力，继续创新完善利益联结机制，推动贫困地区农村资源变资产、资金变股金、农民变股东改革。制定实施贫困地区集体经济薄弱村发展提升计划，通过盘活集体资源、入股或参股、量化资产收益等渠道增加集体经济收入，让贫困户和村集体分享产业增值收益。

四、关于鼓励社会力量、社会资本投入农村产业

2016年9月，国家专门设立了全国脱贫攻坚奖，包括奋进奖、贡献奖、奉献奖和创新奖，对在脱贫攻坚中真抓实干、成效显著、群众认可、社会公认的组织和个人进行表彰，鼓励社会组织和个人参与脱贫攻坚。2016年以来，表彰了一大批投身农村产业发展的企业，充分调动了企业参与扶贫的积极性，激发了企业家对扶贫工作的责任感和使命感，营造出产业扶贫的良好社会氛围。2018年，我部联合发展改革委等8部门印发了《关于实施产业扶贫三年攻坚行动的意见》，鼓励贫困地区组织农业产业化龙头企业与贫困地区开展有效对接，引导龙头企业采取与贫困地区带贫经营主体合作、直接建基地等形式，在贫困地区投资兴业，带动贫困户发展产业。近年来，各电商平台也相继建立贫困县地方馆，利用网络优势帮助贫困地区销售当地农产品，促进贫困群众脱贫增收。

下一步，我部将会同相关部门指导贫困地区创设扶持政策，在项目安排、资金扶持、示范评定、融资贷款、保险保费、用地用电等方面加大对带贫能力强的新型经营主体的支持力度。加强对扶贫优秀企业的宣传推广、表彰奖励和政策扶持，为打赢脱贫攻坚战、全面建成小康社会进一步凝聚力量。

感谢您对农业农村工作的关心，希望继续对我部工作予以支持。

农业农村部

2019年8月29日
