# 国家文物局关于大运河江南运河苏州段保护区划内堤防加固工程项目的意见

文物保函〔2019〕416号

江苏省文物局：

你局《关于审批大运河苏州段堤防加固工程方案（修改稿）的请示》（苏文物保〔2019〕13号）收悉。经研究，我局原则同意在大运河江南运河苏州段保护区划内实施堤防加固工程以及部分相关设施建设；暂不同意其中潭湖闸站、西塘河枢纽、江枫洲南景观人行桥建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业机构对现状河堤做进一步的调查评估，明确具有历史价值的河堤位置及分布范围，并制定原址保护加固措施。确需改建或新建的河堤应尽可能延续原有形制，并采用传统材料和建造工艺。

（二）应进一步深化项目整体设计，针对“以往工程与周边城市环境严重不协调”的问题，提出有效解决途径，并补充相关设计，尽可能弱化拟建项目对大运河及环境景观的负面影响。

（三）应完善相关建筑设计，各口门建筑选址不得进入大运河遗产区和保护范围；在满足设施功能需求的前提下，应尽可能降低拟建建筑高度、体量，并采取分散式布局。各类建筑外部均以采用灰色调为宜。

（四）应弱化拟建窑浜闸站的建筑形象，控制建筑体量，避免对彩云桥周边景观视廊造成负面影响。应简化拟建沧浪新城景观人行桥建筑形制，淡化外观色彩，该桥整体色调亦以灰色调为宜。

（五）应细化环境整治工程方案设计。应根据不同河段原生景观特征进行分段设计，尽可能增加绿地面积，缩小地面硬化范围，采用本地植被和自然生态设计，保留自然野趣，避免城市园林化设计倾向。此外应考虑适当设置大运河价值内涵展示阐释设施。

（六）应补充拟建防洪设施管控措施，以及文物保护措施、应急预案，以确保在出现“防洪调度、应急调水及工程抢险需求的特殊情况”下，可以迅速有效应对，避免河水冲击破坏遗产本体，保证遗产安全。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

四、拟建潭湖闸站距宝带桥过近，西塘河枢纽、江枫洲南景观人行桥体量较大，相关项目选址及设计依据不充分。应补充拟建设施选址必要性及设计依据说明，大比例尺平面图和拟建设施设计详图，以及拟建江枫洲南景观人行桥简化设计比选方案后，另行报批。

专此函复。

国家文物局

2019年5月5日
