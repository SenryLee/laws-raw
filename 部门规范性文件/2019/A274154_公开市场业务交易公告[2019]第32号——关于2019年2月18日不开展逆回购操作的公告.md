# 公开市场业务交易公告[2019]第32号——关于2019年2月18日不开展逆回购操作的公告

## 公开市场业务交易公告

[2019]第32号

考虑到现金回笼等因素推动流动性总量上升，为维护银行体系流动性合理充裕，2019年2月18日不开展逆回购操作。

中国人民银行公开市场业务操作室

二〇一九年二月十八日
