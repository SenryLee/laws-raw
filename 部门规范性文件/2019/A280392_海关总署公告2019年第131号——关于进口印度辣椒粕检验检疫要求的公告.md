# 海关总署公告2019年第131号——关于进口印度辣椒粕检验检疫要求的公告

## 海关总署公告

2019年第131号

## 关于进口印度辣椒粕检验检疫要求的公告

根据我国相关法律法规和《中华人民共和国海关总署与印度共和国商业与工业部出口检验委员会关于印度辣椒粕输华卫生与植物卫生条件议定书》规定，自本公告发布之日起，允许符合相关检验检疫要求的印度辣椒粕进口。现将《进口印度辣椒粕检验检疫要求》（见附件）予以公布。

特此公告。

附件： 进口印度辣椒粕检验检疫要求

海关总署

2019年7月29日
