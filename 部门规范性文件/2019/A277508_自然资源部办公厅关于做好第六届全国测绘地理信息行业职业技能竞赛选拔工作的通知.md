# 自然资源部办公厅关于做好第六届全国测绘地理信息行业职业技能竞赛选拔工作的通知

自然资办函〔2019〕827号

各省、自治区、直辖市自然资源主管部门，新疆生产建设兵团自然资源主管部门，陕西测绘地理信息局、黑龙江测绘地理信息局、四川测绘地理信息局、海南测绘地理信息局：

为贯彻落实中央精神，推动高技能人才队伍建设，进一步提升测绘地理信息行业服务自然资源管理的能力水平，自然资源部决定联合人力资源和社会保障部、中华全国总工会、共青团中央举办2019年中国技能大赛“南方测绘杯”第六届全国测绘地理信息行业职业技能竞赛（以下简称“竞赛”）。现就做好竞赛选拔工作通知如下。

一、竞赛选拔工作的主要内容

为加强竞赛组织领导，自然资源部成立由自然资源部领导担任主任的竞赛组委会，成员由自然资源部、人力资源和社会保障部、中华全国总工会、共青团中央有关部门和单位的领导组成。竞赛组委会办公室设在自然资源部职业技能鉴定指导中心，具体负责竞赛的组织实施和日常管理工作，为各地开展省级选拔赛提供业务指导和技术支持。本届竞赛的全国决赛由四川测绘地理信息局负责承办，南方测绘集团冠名合作。

（一）竞赛时间安排

本届竞赛的全国决赛拟定于2019年11月举行。各地区应于2019年9月20日前完成全国决赛参赛选手的选拔工作。

（二）竞赛标准与内容

竞赛以国家职业技能标准（2019版）中不动产测绘员（国家职业资格三级）的知识和技能要求为基础，并结合高素质技术技能人才培养和生产岗位需求，适当增加新知识、新技术、新技能等内容。竞赛采取理论知识考试和技能操作考核相结合的方式，侧重于技能操作考核。竞赛内容以竞赛组委会印发的技术文件为准。

（三）参赛组队与选手选拔

参加全国决赛的选手，应通过各省级自然资源主管部门组织选拔赛的方式产生。各省、自治区、直辖市自然资源主管部门和新疆生产建设兵团自然资源主管部门应选派选手组队参赛。陕西省、黑龙江省、四川省、海南省的竞赛选拔工作由省级自然资源主管部门分别会同陕西测绘地理信息局、黑龙江测绘地理信息局、四川测绘地理信息局、海南测绘地理信息局联合举办。

（四）竞赛仪器设备及软件要求

为贯彻落实《国务院办公厅关于促进地理信息产业发展的意见》，振兴国产测绘地理信息装备制造，提高国产测绘地理信息软件研发和产业化水平，在各地区省级选拔赛和全国决赛组织实施过程中，参赛队应当使用具有自主知识产权的国产品牌仪器设备和软件。竞赛的主要仪器设备应选用行业内普遍使用、技术先进、通用性强的仪器设备；竞赛的主要软件应选用行业内普遍使用、具有代表性的软件。

二、竞赛选拔工作的组织领导

各省级自然资源主管部门要高度重视竞赛选拔工作，加强组织领导，成立工作机构，明确专人负责，切实做好本地区参赛选手选拔及相应组织协调工作，要积极创造条件与当地省级人力资源社会保障部门、总工会、团委等有关部门联合办赛。有条件的地市级自然资源主管部门应会同当地有关部门开展选拔赛。要周密安排，正确处理好竞赛活动与安全生产的关系。

（一）精心组织，扎实推进

各省级自然资源主管部门应坚持“勤俭办赛、务实办赛、高效办赛、和谐办赛”的原则，按照竞赛组委会印发的竞赛通知、技术纲要、评分标准等文件要求，制定本地区选拔赛的组织实施方案，提供必要的人、财、物力保障，督促各级自然资源主管部门认真组织，发动行业单位积极参与，鼓励从业人员踊跃报名，并着力提高竞赛品质，创新竞赛形式，丰富竞赛内容，推广竞赛成果，通过竞赛选拔的方式，遴选出水平高、素质好的优秀选手代表本地区参加全国竞赛。

（二）加强宣传，营造氛围

各有关部门和单位要利用好举办竞赛的契机，加强与新闻媒体的沟通联系，积极搭建平台、创新载体，为实现竞赛目标提供强大的文化牵引和精神动力。要策划宣传热点，加大宣传力度，及时报道优秀技能人才的先进事迹，营造“比、学、赶、帮、超”的浓厚竞赛氛围，引导广大职工树立“追求梦想、爱岗敬业、开拓创新、扎实奉献”的优秀品质。

（三）统筹协调，及时沟通

各有关部门和单位要按照“统一指挥、分级管理、分工协作、各尽其责”的原则，统筹协调，上下联动，形成规模效应。为便于了解各地区选拔情况，统筹推进竞赛活动有序开展，各省级自然资源主管部门和有关派出机构于2019年6月20日前将本地区竞赛联络员信息（含姓名、职务、联系方式及电子邮箱）报送竞赛组委会办公室（自然资源部职业技能鉴定指导中心）。组织实施中如有问题，请及时与竞赛组委会办公室联系。
