# 国家粮食和物资储备局关于举办2019年全国粮食科技活动周的通知

国粮仓〔2019〕96号

各省、自治区、直辖市及新疆生产建设兵团粮食和物资储备局（粮食局），各垂直管理局，中国储备粮管理集团有限公司、中粮集团有限公司、中国供销集团有限公司，各有关单位：

根据《科技部、中央宣传部、中国科协关于举办2019年全国科技活动周的通知》（国科发智〔2019〕80号）精神，国家粮食和物资储备局定于2019年5月19日～26日举办2019年全国粮食科技活动周。现就有关事项通知如下：

一、活动主题

2019年全国粮食科技活动周以“科技人才共支撑、兴粮兴储保安全”为主题。本次活动围绕落实科技、人才兴粮兴储的重点任务，聚焦人才与科技创新，积极宣传粮油科技创新成果、优质粮油营养健康知识，以及物资储备、能源储备、应急救灾等相关知识。同时，开展科技成果、科研团队、科研机构与企业“三对接”和人才供需对接等活动，进一步推动产学研用结合，加快科技成果转化，助力高质量发展，不断满足人民日益增长的绿色优质粮油产品需要，充分发挥粮食和战略应急物资储备在保障国家安全中的基础性作用。

二、活动组织

活动周期间，国家局在江苏南京设置主会场。

主办：国家粮食和物资储备局

承办：江苏省粮食和物资储备局、南京财经大学

协办：江苏省南京市仙林大学城管委会

三、时间和地点

2019年全国粮食科技活动周时间安排在2019年5月19日～26日。其中，5月21日～22日在江苏省南京市栖霞区仙林广场、南京财经大学等地举办国家粮食和物资储备局与江苏省政府战略合作协议签署仪式、开幕式暨科技“三对接”启动仪式、广场科普活动，以及科技“三对接”等系列活动。

四、内容和形式

（一）集中宣传活动

1.启动仪式及科普展览。在南京市栖霞区仙林广场宣布2019年全国粮食科技活动周开幕，启动科技“三对接”活动；向“粮食科技特派员”小分队（“百名博士服务粮企”小分队）授旗，向有关科研单位建设的创新中心授牌；参观广场科普展览。

2.召开座谈会及签署战略合作协议。召开“粮食和物资储备系统科技和人才工作座谈会”，总结交流粮食和物资储备科技创新和人才培养取得的成效、典型做法和先进经验；研究分析粮食和物资储备科技创新发展和人才队伍建设面临的形势和机遇；研究部署深化粮食和物资储备科技和人才发展体制机制改革的思路、任务和举措。同时，在南京财经大学举办国家粮食和物资储备局与江苏省政府战略合作协议签署仪式。

3.科技“三对接”及人才供需对接活动。在南京财经大学举办科技“三对接”暨全国粮食行业人才供需对接活动，展示和发布粮食公益性行业科研专项重大成果，举办科技成果签约仪式和主食营养等方面的科普讲座；举办全国粮食行业人才供需对接活动，展示行业人才队伍建设成果等。

（二）各地自主举办科普宣传活动

在活动周期间，各地粮食和物资储备部门可结合本地实际举办丰富多彩的科普活动，如“粮油健康营养”科普讲座、“爱粮节粮”大讲堂；鼓励会同当地有关部门开展粮油营养健康知识进社区、进家庭活动，还可组织进校园、进企业、进军营活动，以及参观现代化粮库、粮油加工企业等爱粮节粮教育基地。各地粮食科研机构可举办开放日活动，邀请中小学生和市民参观。

（三）发放科普宣传品

国家粮食和物资储备局围绕“优质粮食工程”编写面向城乡居民的营养健康等方面的科普宣传材料，并印送各地。各级粮食和物资储备部门可根据需要进行翻印，鼓励根据本地实际创新制作有特色的科普宣传品，并通过多种形式将宣传品发放给群众。

五、有关要求

（一）各地要高度重视科技人才兴粮兴储工作，把粮食科技活动周作为深入贯彻习近平新时代中国特色社会主义思想和党的十九大精神，大力宣传总体国家安全观、国家粮食安全战略的重要措施，按照通知要求认真组织实施。

（二）请各省粮食和物资储备部门、有关垂管局、有关央企积极组织相关人员参加粮食科技活动周活动，邀请有关科研机构、高校、企业代表参加科技“三对接”和人才供需对接等活动。请各省粮食和物资储备部门、有关垂管局负责同志及相关处室人员3人参加“粮食和物资储备系统科技和人才工作座谈会”等活动。仙林广场科普会场和科技“三对接”活动，每省代表名额20人（含科研机构、高校、企业代表），每家央企代表名额原则上不超过30人。具体活动情况见附件1。

参加活动代表统一安排食宿（超额人员除外），费用自理。参会人员名单由各省粮食和物资储备部门、有关央企于2019年4月30日前分别统一报送。报名回执表见附件2。

（三）各地组织粮食科技活动周，要严格执行中央八项规定及其实施细则精神，坚持勤俭节约、少花钱办好事的原则，杜绝奢靡浪费行为。要认真落实安全保障措施和安全责任，高度重视活动参与、参观人员的安全防护，确保活动顺利开展。

（四）请各省粮食和物资储备部门于2019年4月30日前报送2019年粮食科技活动周实施方案；活动结束后认真总结，于6月10日前报送总结报告及相关音像资料。
