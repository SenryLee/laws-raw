# 国家邮政局关于政协十三届全国委员会第二次会议第0211号（工交邮电类010号）提案答复的函

## 关于政协十三届全国委员会第二次会议第0211号（工交邮电类010号）提案答复的函

国邮函〔2019〕64号

邱小琪委员：

您提出的“关于健全制度，鼓励创新，加快推动快递业绿色发展的提案”（第0211号）收悉，我局高度重视，认真研究，现答复如下：

党的十八大以来，我国快递业保持快速发展，业务量从57亿件增长到2018年的500亿件，连续5年稳居世界第一，不仅成为推动流通方式转型，促进消费升级的先导性产业，在稳增长、调结构、惠民生等方面发挥了重要作用，而且成为现代服务业的重要组成部分、国民经济的“一匹黑马”。快递包装使用量随之剧增，由此带来的资源消耗和环境污染问题受到社会各界的高度关注。国家邮政局深入贯彻落实习近平生态文明思想，高度重视行业生态环保工作，坚持守土有责、守土尽责，采取系列措施推进推动快递业绿色高质量发展。

一、已开展的工作

（一）加强组织部署，完善法规标准。国家邮政局党组把行业生态环境保护作为重大的政治任务，多次专题研究部署。成立了邮政业生态环保工作领导小组，强化统筹协调和工作推进。局领导多次带队调研行业生态环保工作。将“绿色邮政”纳入“五个邮政”建设和邮政业发展“十三五”规划体系。联合九部门出台《关于协同推进快递业绿色包装工作的指导意见》。印发了《国家邮政局关于全面加强生态环境保护坚决打好污染防治攻坚战的实施意见》，明确了绿色发展指标和计划完成的时间节点。今年初，在市场监管司增设环境保护处，专门负责行业生态环境保护工作。印发《2019年行业生态环境保护工作要点》，聚焦包装治理和节能减排任务，量化目标并压实目标责任，提出实施“9571工程”。推动在《中华人民共和国电子商务法》《快递暂行条例》中增加专门条款对绿色包装进行规定，明确上位法依据。制修订《快递封装用品》系列国家标准和《快递电子运单》《邮政业封装用胶带》《邮件快件包装填充物技术要求》《快件集装容器》等多项行业标准。印发《快递业绿色包装指南（试行）》，从绿色采购、内部培训、作业操作等方面明确了相关要求。研究印发《邮件快件包装废弃物回收箱应用参考》，推动在邮政快递网点设置回收箱。

（二）强化政策导向，引导企业绿色发展。国家邮政局利用各种有利契机，组织主要品牌快递企业交流绿色发展经验，推动行业内信息共享和共进。坚持企业创新主体地位，更多运用市场化手段促进企业创新，鼓励企业加强与相关领域高校、科研机构合作，在教育、科研、人才培养等方面形成合力，健全产学研一体化创新机制。鼓励支持企业、科研机构申请政府环保科技项目，就绿色包装技术申报邮政行业技术研发中心和研发奖项。发挥快递业绿色发展产学研协同创新示范基地平台作用，推动邮政行业产业发展的关键性技术研发、成果转化和系统集成。面向社会开展行业绿色产品、绿色技术和绿色模式公开征集，增加行业绿色供给。

（三）加强监督管理，推动落实企业主体责任。各级邮政管理部门将行业生态环境保护纳入对市场主体监管的重要内容，加强常态化监管。印发《关于报送企业生态环境保护工作分管负责人和牵头部门的通知》，督促企业健全组织体系。组织召开寄递企业生态环保工作座谈会，对行业污染防治攻坚进行再动员、再部署。将快递绿色包装应用情况纳入行业信用评定指标体系。强化试点示范，加强快递与电商协同治理。组织开展寄递企业生态环保主体责任落实情况专项调研检查。积极开展快递包装产品绿色认证和企业绿色发展评价体系研究。邮政企业和各品牌快递企业按照邮政管理部门的统一部署，持续加大投入，按照“绿色化、减量化和可循环”的目标原则稳步推进绿色包装治理。

（四）促进创新应用，提升绿色治理成效。国家邮政局制定了邮政业应用技术研发指南，推动行业广泛使用大数据、云计算，大力推广应用人工智能技术和北斗导航系统，无人仓、无人机在多家企业投入使用，主要品牌企业骨干分拨中心基本实现自动化分拣，推进库存前置、智能分仓、科学配载、线路优化，在提高效率的同时大幅降低包装耗材用量。大力推广快递服务制造业以及其他产业的经验做法，通过向上游嵌入前置，提供包装、收寄一体化服务，逐步减少二次包装。推动和鼓励企业开展产品创新、技术创新和模式创新，不断为行业生态环保工作提供不竭动力。

（五）开展协同配合，注重共治共建。国家邮政局加强与其他部门协作，充分发挥部门合力作用。积极参与国家发展改革委牵头的塑料垃圾污染防治和落实禁止废纸进口相关工作机制。与商务部开展包装协同治理。积极参与垃圾分类有关部门协作机制，推动完善社会回收体系。充分发挥协会桥梁纽带作用。指导中国快递协会组建成立快递绿色包装产业联盟，举办中国快递绿色包装产业联盟高峰论坛，搭建快递业绿色发展产学研共促平台。加强宣传引导。利用3．15有利契机，制作行业生态环保宣传活页下发各地进行广泛宣传。连续3年发布《快递领域绿色包装发展现状及趋势报告》，与团中央等单位共同开展“绿色快递进校园”“小手拉大手．绿色绕地球”等系列活动。

二、意见采纳情况和下一步工作计划

您提出的关于加快推动快递业绿色发展的三条建议，我局予以采纳，并结合行业实际抓好贯彻落实。特别是关于国外相关经验做法，值得我们借鉴学习。下一步，邮政管理部门深入学习贯彻习近平生态文明思想，围绕“绿色化、减量化和可循环”目标，坚持系统治理和综合施策，强化统筹协调和任务落实，稳步推进行业绿色高质量发展。

（一）继续加强法规和标准体系建设。推动《中华人民共和国电子商务法》《快递暂行条例》相关规定在行业内落地实施。利用交通运输部部门规章《邮政行业安全监督管理办法》修订契机，明确邮件、快件包装物、填充物的环保要求，强化企业环保责任。研究制定《快递包装基本要求》行业标准，启动《冷链快递包装箱技术要求》行业标准的研制，健全快递业包装标准体系。加强与国家标准委和认监委协调沟通，编制《绿色产品评价快递封装用品》国标项目，引导支持寄递企业使用经绿色认证的包装产品。加强快递业能耗和污染物排放测算方法研究，建立绿色快递统计监测评估体系。

（二）强化监督管理。组织开展绿色采购试点，督促寄递企业实施绿色采购。建立统计监测制度。创新监督管理手段，综合运用定期通报、督导检查、考核评价、公众举报、信用约束等方式，督促寄递企业完善内控体系、强化教育培训、规范文明作业、应用绿色包装产品等，推进企业生态环保主体责任落实。

（三）强化政策有效供给。国家邮政局将加强与相关部门的沟通协同，推动出台针对行业生态环保的扶持政策。充分利用好国家和各地出台的减费降税政策，推动各地研究出台针对行业生态环境保护的税收、财政、金融等扶持政策。引导和推动地方各级邮政管理部门加强与所在地党委政府对接，主动汇报沟通协调，推动将邮政业绿色发展工作纳入地方生态文明建设和环境保护工作范畴；加强协调，争取将邮政行业纳入现有政策扶持对象，争取地方对使用符合标准的环保包装材料和开展邮件快件包装分类回收利用的寄递企业予以补贴。

（四）加大宣传教育力度。开展“邮来已久、绿动未来”主题宣传活动，营造良好工作氛围。通过绿色快递进社区、进校园、进机关等活动，加强对重点区域以及高校、中小学、社区等重点人群的宣传引导。开展“快递行业环保卫士”评选等活动，树立典型人物、典型事迹、典型案例，讲好行业绿色发展故事。推动企业探索建立消费者激励机制，积极引导消费者广泛参与快递绿色消费。强化教育培训，将行业生态环境保护相关知识纳入行业教育培训体系和干部教育培训规划（2018-2022）。
