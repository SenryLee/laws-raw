# 中共自然资源部党组关于王磊等3名同志职务任免的通知

自然资党任〔2019〕82号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中央军委后勤保障部军事设施建设局，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

部党组2019年8月20日研究决定：

王磊任国土空间生态修复司副司长，免去其国家自然资源总督察办公室副主任职务；

熊自力任地质勘查管理司副司长，免去其国土空间生态修复司副司长职务；

免去薛佩瑄地质勘查管理司副司长职务。

中共自然资源部党组

2019年8月27日
