# 国家体育总局科教司关于对国家队训练数据建设和信息规范管理工作进行调研的通知

## 体育总局科教司关于对国家队训练数据建设和信息规范管理工作进行调研的通知

体科字〔2019〕44号

各运动项目管理中心，中国足球协会、中国篮球协会，各改革试点项目协会，各国家队：

为了规范和加强国家队训练数据建设，帮助各国家队提高训练数据建设和信息规范管理工作水平（以下简称大数据建设工作），根据《体育总局科教司关于加强国家队训练数据和信息规范管理的通知》（体科字﹝2018﹞135号）等文件要求，科教司将对国家队大数据建设工作进行调研。现将有关事项通知如下：

一、调研重点内容

主要从大数据建设重视程度、大数据建设情况、大数据应用情况等三方面对国家队大数据建设工作进行调研，具体内容见附件1。

二、调研方式

采取问卷调查、现场观察、访谈座谈、查阅资料等方式进行实地调研。

三、有关要求

（一）请各国家队高度重视大数据建设工作，认真梳理大数据建设工作取得的成绩与不足，确保国家队大数据建设落到实处。

（二）请各国家队组织填写《国家队大数据建设工作调查问卷》（电子版请登录电子邮箱下载，邮箱号：kjskjc@163.com），并于4月25日前将调查问卷发送至科教司（电子版发送至邮箱：dyl@sport.gov.cn，纸质版发送或传真至科教司）。科教司将从4月25日起组织专家实地了解各国家队大数据建设情况。

（三）调研结束后将组织召开国家队大数据建设推进会，介绍相关国家队大数据建设的成功经验，进一步促进国家队大数据建设工作。
