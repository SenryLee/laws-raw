# 农业农村部对十三届全国人大二次会议第6303号建议的答复

## 对十三届全国人大二次会议第6303号建议的答复

纪清巨代表：

您提出的关于加大扶持小农户的建议收悉。经商市场监管总局和财政部,现答复如下。

党的十九大报告提出，发展多种形式适度规模经营，培育新型农业经营主体，健全农业社会化服务体系，实现小农户和现代农业发展有机衔接。2018年中央1号文件提出，促进小农户和现代农业发展有机衔接，研究制定扶持小农生产的政策意见。2019年，中共中央办公厅、国务院办公厅印发了《关于促进小农户和现代农业发展有机衔接的意见》，强调各级党委和政府要把贯彻落实扶持引导小农户政策和培育新型农业经营主体政策共同作为农村基层工作的重要方面，在政策制定、工作部署、财力投放等各个方面加大工作力度；要保护小农户生产经营自主权，激发小农户生产经营的积极性、主动性、创造性，使小农户成为发展现代农业的积极参与者和直接受益者。

一、关于对小农户标准化生产给予奖补政策支持和在各地建设小农户标准化生产园

《关于促进小农户和现代农业发展有机衔接的意见》提出，指导农户家庭农场开展标准化生产，建立可追溯生产记录，加强记账管理，提升经营管理水平；引导小农户发展高品质农业、绿色生态农业，开展标准化生产、专业化经营，推进种养循环、农牧结合，生产高附加值农产品；充分发挥财政杠杆作用，鼓励各地采取贴息、奖补、风险补偿等方式，撬动社会资本投入农业农村，带动小农户发展现代农业；稳定现有对小农户生产的普惠性补贴政策，创新补贴形式，提高补贴效率；健全小农户生产技术装备补贴机制，按规定加大对丘陵山区小型农机具购置补贴力度。

市场监管总局高度重视农业标准化工作。一是开展农业标准体系建设工作。截至目前，共制修订农业国家标准3436项，备案农业地方标准2119项，包含粮食、蔬菜、水果、畜禽、水产、茶叶等大宗农产品，覆盖农业产前、产中、产后全过程，初步建立了农产品安全标准体系，为小农户开展农业标准化生产提供了标准支撑。二是开展农业标准化示范区建设工作。多年来，市场监管总局与各涉农部门、各级地方政府共同推动，大力开展农业标准化示范推广工作，先后建设国家级农业标准化示范区九批4540个，覆盖了粮食、畜禽水产、蔬菜、水果等大宗农产品和各地优势特色农产品。各地通过开展农业标准化示范区建设，对引导小农户从事标准化生产发挥了重要作用。根据《国家农业标准化示范区管理办法(试行)》，农业标准化示范区鼓励农业龙头企业、行业（产业）协会和农民合作社积极承担建设工作，带领农民实施标准化生产，建立形式多样、富有实效的农业标准化推广体系。下一步，市场监管总局将联合有关部门进一步加大标准的制修订工作力度，着力构建从农田到餐桌全覆盖、全链条、多层次的现代农业全产业链标准体系，为小农户从事标准化生产提供标准支撑；深入推进国家农业标准化示范项目建设工作，进一步发挥示范项目的示范带动作用，引导小农户从事标准化生产。

二、关于扶持一批面向小农户的社会化企业

2014年国务院下发《关于加快发展生产性服务业促进产业结构调整升级的指导意见》，明确了农业生产性服务业的发展导向。2016年中央1号文件要求加快发展农业生产性服务业。为贯彻落实中央有关要求，2017年，农业部会同发展改革委、财政部印发《关于加快发展农业生产性服务业的指导意见》，强调以小农户为主的家庭经营是我国农业的基本经营方式，大力发展面向广大农户的农业生产性服务是推进现代农业建设的历史任务。同年，农业部印发《关于大力推进农业生产托管的指导意见》，并会同财政部印发《关于支持农业生产社会化服务工作的通知》。《关于促进小农户和现代农业发展有机衔接的意见》进一步提出，要健全面向小农户的社会化服务体系。

2018年，中央财政通过农业生产发展资金，安排40亿元支持土地托管等农业生产社会化服务。鼓励各地采取政府购买服务或先服务后补助等方式，对农村集体经济组织、专业化农业服务组织、服务型农民合作社等具有一定能力、可提供有效稳定服务的主体，为从事粮棉油糖等重要农产品生产的农户提供社会化服务给予补助，集中连片推广绿色生态高效现代农业生产方式，把小农户生产引入现代化农业发展轨道。截至2018年底，全国按照综合托管系数计算的托管面积达到3.64亿亩，开展农业生产托管服务的组织数量达到37万个。通过对辽宁、江苏、浙江、山东4省共23个服务组织的39个托管案例进行定量分析，农户采取全程托管，每年每亩可实现节本增收485.3元，户均节本增收2911.8元。

三、关于针对小农户产品组织成本和流通成本高的问题，给予小农户产品销售支持

当前，农村交通、物流等基础设施建设相对滞后，农产品往往因流通成本高而“运不出”。据统计，农产品从南疆四地州用卡车运往内地，市场费用为1100—1200元/吨，以每车30吨计算，成本高达3万多元。加上流通环节层层加码，零售价格与产地价格严重脱节，出现“原产地价格低到没人要、市场地价格居高不下”的尴尬局面。

近年来，我部以品牌建设为引领，以促进农产品产销对接工作为重点，加快推动产销双方建立长期稳定的购销关系，努力搭建城乡互动、要素融合的新渠道。

在品牌建设上，指导各地根据产业发展实际，加大资源整合，积极培育特色产业，做强农产品区域公用品牌和“小而美”的特色品牌，带动农户共享品牌溢价收益。并积极利用农交会、茶博会等重点农业展会开展品牌营销推介，进一步提高了农业品牌的知名度和影响力。目前洛川苹果、赣南脐橙、斗南花卉、定西马铃薯等强势品牌脱颖而出，有力带动了农户增收致富。

在田头市场建设方面，按照《全国农产品产地市场发展纲要》规划布局，我部自2014年起先后支持辽宁、山东、四川、云南等10个省份建设共53个田头市场示范试点，着力解决农产品流通“最初一公里”，改善基础设施，规范建设标准，强化分等分级和商品化处理。重点支持信息采集发布、电子化交易等公益性设施建设，提高了田头市场流通效率，减少流通损耗，推进农产品上行。在这些田头市场示范试点带动作用下，各地把田头市场建设作为促进农产品销售、引导农业结构调整和增加农民收入的重要措施，培育发展了一批专业性强、辐射范围广、带动一方产业发展的田头市场，对提高农户营销能力，强化农产品流通起到了重要推动作用。

在产销对接方面，以农产品产销对接为突破口，坚持市场导向、问题导向，整合全国优势产销资源，聚焦集中连片贫困地区和深度贫困地区，深入开展农产品产销对接行动，让小农户与采购商“零距离”接触。2018年，印发了《贫困地区农产品产销对接实施方案》，组织了7场专题对接活动，集中展示展销万余种农产品，全国四分之三以上贫困县参加，现场签约超过190亿元。据统计，在我部的牵头带动下，各级农业农村部门2018年农产品产销对接活动签约金额超过500亿元，实现了千家万户的小生产和千变万化的大市场有效对接，不仅缓解了贫困地区农产品卖难、卖贱问题，也降低了采购商采购、流通成本，密切了产销，惠及生产、消费各环节，形成了关心贫困地区、服务贫困农户、引导产业升级、争创知名品牌的氛围，提升了产业扶贫的综合效能。2019年，我部将深入开展产销对接工作，再举办10场对接活动，长短结合、标本兼治，强化机制创新，务求对接实效，努力提升产业扶贫和精准脱贫质量。4月3日，已举办了首场“三区三州”农产品产销对接会，现场签约额超过45亿元。

下一步，我部将会同相关部门认真落实中央要求，对小农户相关政策落实情况进行跟踪分析和评估，推动各项工作做实做细。

感谢您对“三农”工作的关心和支持，希望继续对我部工作给予支持。

农业农村部

2019年9月24日
