# 中共教育部党组关于廖济忠、李名家同志职务任免的通知

教党任〔2019〕22号

中共华中农业大学委员会：

经与中共湖北省委商得一致，2019年1月8日研究决定：

廖济忠同志任中共华中农业大学委员会委员、常委、副书记、纪律检查委员会书记；免去李名家同志的中共华中农业大学委员会副书记、常委、委员、纪律检查委员会书记职务。

中共教育部党组

2019年1月23日
