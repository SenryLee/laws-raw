# 自然资源部公告2019年第19号——自然资源部关于公布2019年优秀科普图书名单的公告

## 自然资源部公告

2019年第19号

## 自然资源部关于公布2019年优秀科普图书名单的公告

为贯彻落实《中华人民共和国科学技术普及法》和《全民科学素质行动计划纲要》，在全社会大力普及科学知识、弘扬科学精神，提高全民科学素养，自然资源部组织开展了2019年自然资源优秀科普图书推介活动。活动得到了各地各单位的积极响应，经专家咨询评议，评选出《跟地质学家去旅行》等36部优秀科普图书，现予以公布，并向全社会推荐阅读。

自然资源部

2019年4月19日

附件：2019年自然资源优秀科普图书名单
