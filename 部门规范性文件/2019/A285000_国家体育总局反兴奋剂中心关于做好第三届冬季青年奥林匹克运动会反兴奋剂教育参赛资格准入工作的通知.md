# 国家体育总局反兴奋剂中心关于做好第三届冬季青年奥林匹克运动会反兴奋剂教育参赛资格准入工作的通知

## 反兴奋剂中心关于做好第三届冬季青年奥林匹克运动会反兴奋剂教育参赛资格准入工作的通知

体反兴奋剂字〔2019〕516号

冬季运动管理中心，各有关运动项目管理中心（协会）：

为做好第三届冬季青年奥林匹克运动会（以下简称“冬青奥会”）中国体育代表团反兴奋剂宣传教育工作，提高运动员及辅助人员自觉抵制兴奋剂的意识和能力，保证代表团人员干干净净参加比赛，反兴奋剂中心负责组织实施冬青奥会中国体育代表团运动员及辅助人员反兴奋剂教育参赛资格准入制度（以下简称“准入工作”）。现将有关事宜通知如下：

一、总体要求

冬青奥会准入工作的实施对象为所有参加冬青奥会和冬青奥会选拔赛的运动员及辅助人员。

所有准入工作的实施对象必须接受系统的反兴奋剂教育，通过反兴奋剂准入考试，宣誓并签署反兴奋剂承诺书，经参赛单位审批后方能获得冬青奥会和冬青奥会选拔赛的参赛资格。

二、职责分工

反兴奋剂中心负责制定冬青奥会准入工作方案；开发线上教育准入平台，反兴奋剂教育准入手册、课件、讲座视频；指导并跟进具体准入工作；开展监督检查工作。

冬季运动管理中心，各有关运动项目管理中心（协会）（以下简称“各单位”）负责按照本通知要求组织实施本单位准入工作；进行反兴奋剂准入资格审批；配合开展监督检查工作。

三、工作流程

（一）各单位应成立准入工作领导小组，指定专人负责准入工作的实施。全部工作应在12月31日前完成。

（二）冬青奥会准入工作实行“六步走”，具体操作说明如下：

1.现场学习

准入对象须接受由纯洁体育教育讲师讲授的“冬青奥会-反兴奋剂教育准入”课程。

2.线上学习和考试

准入对象须登陆中国反兴奋剂教育平台（cleanmedal.chinada.cn），自行完成账号注册，并在“反兴奋剂教育准入”-“反兴奋剂教育准入通用入口”-“冬青奥会反兴奋剂教育准入入口”完成规定课程学习。

准入对象须在完成学习内容后进行准入考试。满分100分，80分为及格，每人仅有3次考试机会。

3.承诺和宣誓

准入对象须签署“反兴奋剂承诺书”并进行反兴奋剂宣誓。

4.现场督查

各单位须对准入工作开展情况进行监督检查，对准入对象学习考试情况进行抽查。

5.调研评估

各单位须调研准入对象受教情况，评估准入工作实效性。

6.资格审批

反兴奋剂中心将正式反馈准入工作情况和通过审核的参赛运动员及辅助人员名单，各单位负责对准入对象进行资格审批。

四、监督检查

反兴奋剂中心将成立监督组，将根据准入工作实施情况进行准入工作督查，督查形式为抽查考试。

此次准入工作要求“人人过关，无一遗漏”。对未参加准入工作、考试不合格及抽查考试不合格的个人，反兴奋剂中心将按照有关规定取消准入对象参赛资格。
