# 反兴奋剂中心关于印发2019年度兴奋剂注册检查库和检查库名单的通知

体反兴奋剂字〔2019〕59号

各省、自治区、直辖市、新疆生产建设兵团体育局，中央军委训练管理部军事体育训练中心，各运动项目管理单位、有关运动项目协会、各行业体协及有关单位：

根据《世界反兴奋剂条例》和国家体育总局《反兴奋剂管理办法》的有关规定，反兴奋剂中心现制定并印发2019年度兴奋剂注册检查库和检查库名单。以上两个检查库中的运动员应根据以下规定填报运动员行踪信息。收到该通知的运动员主管单位应立刻通知运动员本人，并告知相关要求。

一、填报要求

（一）2019年度兴奋剂注册检查库运动员应按照《运动员行踪信息管理规定》（体反兴奋剂字〔2016〕88号）中的相关要求，及时、准确、详细地申报运动员行踪信息，确保运动员能够在申报的行踪信息地点接受兴奋剂检查。

（二）2019年度兴奋剂检查库运动员应按照《反兴奋剂中心关于兴奋剂检查库运动员申报行踪信息的通知》（体反兴奋剂字〔2017〕201号）中的相关要求，及时、准确、详细地申报运动员行踪信息，确保运动员能够在申报的行踪信息地点接受兴奋剂检查。

二、填报方式

（一）运动员应使用个人帐号通过登录世界反兴奋剂机构的反兴奋剂运行管理系统（ADAMS）申报运动员行踪信息。

（二）运动员如已在其所属的国际单项体育联合会兴奋剂注册检查库中，请该运动员使用国际单项体育联合会提供的个人账号登录ADAMS申报行踪信息。

三、请各单位认真核对运动员的相关信息，如有任何错误（包括姓名、性别、项目、注册单位等），请于2月20日前向反兴奋剂中心提交加盖主管单位公章的书面说明，以便及时更新。如各运动项目管理单位、有关运动项目协会对名单有任何意见和建议，也请于2月20日前向反兴奋剂中心提交加盖主管单位公章的书面说明和具体理由。

四、请各单位在2月20日前将新增运动员的近期证件照发至whereabouts@chinada.cn。证件照名称请按“项目+注册单位+运动员姓名+性别”进行标注。反兴奋剂中心将在收到以上信息后为新增运动员设置个人帐号和初始登录密码，并反馈给各单位。因初始密码将于次日失效，所以请新增运动员务必在收到登录信息当日登录ADAMS进行密码修改，并于2月28日前完成申报行踪信息。
