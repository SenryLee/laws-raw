# 财政部关于提前下达云南省2020年政府还贷二级公路取消收费后补助资金预算的通知

财建〔2019〕564号

云南省财政厅：

根据《国务院关于实施成品油价格和税费改革的通知》（国发〔2008〕37号）和《国务院办公厅转发发展改革委 交通运输部 财政部逐步有序取消政府还贷二级公路收费实施方案的通知》（国办发〔2009〕10号）有关规定，为支持你省做好取消政府还贷二级公路收费工作，保证平稳过渡，现提前下达你省2020年取消政府还贷二级公路收费中央补助资金预算2600000万元（项目代码：Z135060000028），收入列2020年政府收支分类科目“1100253交通运输共同财政事权转移支出收入”，支出列2020年政府收支分类科目“214 交通运输支出”。

你省要按照《中共中央国务院关于全面实施预算绩效管理的意见》要求，完善绩效目标管理，做好绩效运行监控和绩效评价，确保财政资金安全有效。

请严格按照有关文件规定，合理安排，并保证资金使用规范安全。

附件：政府还贷二级公路取消收费后补助资金绩效目标表

财政部

2019年10月30日
