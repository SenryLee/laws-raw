# 国家文物局关于政协十三届全国委员会第二次会议第2720号（文化宣传类219号）提案答复的函

文物督函〔2019〕787号

贺云翱委员：

您提出的《关于加大文物行政执法力度的提案》已交由我局会同文化和旅游部、中央纪委国家监委机关办理。现答复如下：

文物行政执法是全面推进依法行政的重要内容，是保障文物安全的重要手段，是维护法律权威的重要举措。党中央、国务院高度重视文物行政执法工作，先后出台《国务院办公厅关于进一步加强文物安全工作的实施意见》《中共中央办公厅 国务院办公厅关于进一步加强文物保护利用改革的若干意见》《中共中央办公厅 国务院办公厅关于深化文化市场综合行政执法改革的指导意见》，对加强文物行政执法提出了明确要求。我局积极贯彻落实党中央决策部署，坚持问题导向，强化文物违法案件督察督办，推动落实文物行政执法责任，文物行政执法工作取得了一定成效。但当前文物安全形势依然严峻，文物法人违法等破坏文物现象屡屡发生。一些地区文物行政执法队伍不健全，执法责任落实不到位。您提出的关于加大文物行政执法力度的有关建议很有针对性，对进一步做好新时代文物行政执法工作具有一定的借鉴作用。

一、关于完善文物执法体系，逐级落实文物安全责任，推动各级政府落实文物保护主体责任。近年来，我局部署开展“文物法人违法案件专项整治行动（2016-2018年）”，完善执法巡查、案件报告、督办约谈、信息公开等四项制度，落实责令改正、行刑衔接、行政追责、信用惩戒等四项措施，不断完善文物执法体系。推动落实地方政府文物保护主体责任，目前已有16个省份明确将文物安全工作纳入地方政府年度考核评价体系。选取长春等地实施文物安全区域性网格化管理试点，建立文物部门、街道、社区为主体的文物网格管理体制。

二、关于充实文物行政执法人员队伍，提高文物行政执法科技水平。今年4月，我局联合文化和旅游部印发了《关于加强地方文物行政执法工作的通知》，重点针对市、县文物行政执法队伍不健全、执法责任落实不到位等突出问题，通过明确责任主体和职责分工、完善授权或委托方式，强化基层文化市场综合执法队伍和文物行政管理部门协同配合，确保地方文物行政执法“事有人干，责有人负”。同时，我局重视卫星遥感、无人机等新技术在文物执法中的应用。2017年以来，重点针对“管理单位隐瞒不报，主管部门毫不知情”问题，利用新技术手段对140处全国重点文物保护单位保护范围和建设控制地带内地物变化情况开展监测，对发现的违法违规线索进行督察督办，变被动受理为主动发现。

三、关于尽快研究推进全国性的文物行政处罚自由裁量基准制度。中共中央、国务院《法治政府建设实施纲要（2015-2020年）》提出了建立健全行政裁量权基准制度要求。目前，北京、辽宁、黑龙江、浙江、安徽、山东、陕西、甘肃等省份和部分地市已先后出台了文物行政处罚自由裁量权细化标准。由于各地文物资源和分布状况、文物保护地方性法规建设和经济社会发展水平不同，区域性的文物行政处罚自由裁量基准制度更符合当前执法实际。我局将继续指导各省不断建立完善文物行政处罚自由裁量基准制度。

四、关于加大文物法人违法案件查处力度和责任追究力度，将文物行政执法情况纳入中央巡视对象。我局开展的文物法人违法案件三年专项整治行动期间，全国共查处文物法人违法案件673起，实施行政处罚349起，责令改正408起，行政追责314人次，刑事追责74人次。我局直接督察督办313起，约谈地方人民政府及相关部门负责人20余次。涉及元上都遗址、殷墟遗址、平遥古城等世界文化遗产，湖北七里坪革命旧址、黑龙江刘亚楼旧居等革命文物，危害长城安全及环境风貌的一大批文物法人违法案件得到有力整治。关于将文物行政执法情况纳入中央巡视对象方面，经商中共中央纪律检查委员会，根据中央要求和《中国共产党巡视工作条例》等有关规定，巡视是政治巡视，不同于业务检查。下一步，各级巡视巡察机构将继续深化政治巡视巡察，紧盯文物保护主管部门职能责任开展监督，对于巡视巡察和日常工作中发现的贯彻落实党中央关于文物保护的决策部署不力等问题线索，各级纪检监察机关将依规依纪进行处置，严肃追究有关部门和人员责任。

五、关于加强宣传、广泛动员社会力量参与文物保护。近年来，我局积极发挥12359文物违法举报热线作用，在陕西、福建等地开展鼓励社会力量参与文物安全试点，开展寻找最美文化遗产守护人活动，畅通社会监督渠道，充分发挥志愿者作用，不断完善社会力量参与机制。

衷心感谢您对文物事业的关注和支持！

国家文物局
