# 工业和信息化部关于公布第三批产业技术基础公共服务平台（部省共建）名单的通告

工信部科函〔2019〕13号

为支撑制造强国建设，完善产业技术基础体系，依据《工业和信息化部办公厅关于做好2018年产业技术基础公共服务平台申报工作的通知》（工信厅科函〔2018〕251号），经评审和公示，确定将广州机械科学研究院有限公司等26家单位列入工业和信息化部第三批产业技术基础公共服务平台（部省共建）名单，现予以公布。

特此通告。

附件：工业和信息化部第三批产业技术基础公共服务平台（部省共建）名单

工业和信息化部
