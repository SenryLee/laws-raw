# 国家文物局关于肇庆古城墙建设控制地带内古城墙公园项目的意见

文物保函〔2019〕236号

广东省文物局：

你局《关于全国重点文物保护单位肇庆古城墙建设控制地带内古城墙公园景观设计方案的请示》（粤文物请〔2018〕11号）收悉。经研究，我局原则同意肇庆古城墙建设控制地带内古城墙公园项目。

一、所报方案尚需作以下必要的修改和完善：

（一）加强城墙历史格局和变迁研究，挖掘城墙历史价值，为景观设计提供依据。

（二）公园绿化应尽量远离城墙，留让城墙散水与排水设施空间，并注意地面高差变化，防止绿化带地表水和乔木根系影响城墙安全。

（三）公园服务设施应结合游客实际需求，尽量减少建设数量和规模，且应具备可逆性。

（四）合理安排工程实施计划，临近待修城墙的区段建议完成城墙修缮工程后再实施公园景观工程。

（五）施工期间应做好对文物本体的防护措施，控制粉尘及施工垃圾等对文物本体及环境的污染。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月8日
