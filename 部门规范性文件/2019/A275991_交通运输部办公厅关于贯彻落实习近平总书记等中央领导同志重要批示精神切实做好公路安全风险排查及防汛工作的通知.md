# 交通运输部办公厅关于贯彻落实习近平总书记等中央领导同志重要批示精神切实做好公路安全风险排查及防汛工作的通知

交办公路明电〔2019〕30号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

2019年3月21日，江苏盐城市响水县陈家港镇天嘉宜化工有限公司化学储罐发生爆炸事故，人民生命财产遭受严重损失。事故发生后，党中央、国务院高度重视。习近平总书记、李克强总理等中央领导同志作出重要批示，要求各地和有关部门要深刻吸取教训，加强安全隐患排查，严格落实安全生产责任制，坚决防范重特大事故发生，确保人民群众生命和财产安全。同时，据中央气象台预测，2019年汛期我国气候状况总体偏差，降雨呈“南多北少”分布，旱涝灾害较重，极端天气偏多，长江中下游梅汛期雨量较常年偏多2到5成，可能有较重汛情并发生阶段性洪涝灾害，预计全年登陆我国的台风数量多、强度高。为深入贯彻落实习近平总书记、李克强总理等中央领导同志重要批示精神，切实做好当前公路安全风险排查及防汛防台风工作，经交通运输部同意，现就有关事项通知如下：

一、提高政治站位，强化责任落实

要认真学习、深刻领会、坚决贯彻习近平总书记、李克强总理等中央领导同志重要批示精神，切实提高政治站位，牢固树立以人民为中心的思想，全力以赴保障人民群众生命财产安全和社会稳定。要充分认识当前公路安全工作的重要性和迫切性，充分认识今年汛期公路防汛保通的严峻形势，克服麻痹思想和侥幸心理，保持高度警醒，提高防范意识，立即组织公路安全风险排查。同时，按照防大灾的要求和“预防为主，防治结合”的原则，提前做好防汛抢险的各项准备工作；进一步健全各级防汛保通组织机构，建立一把手总负责、分管领导具体抓、各相关部门共同参与的组织体系，层层落实防汛保通工作责任制，精心部署落实措施，最大程度降低灾害损失。

二、加强安全排查，及时发现整改

要迅速行动，结合公路隧道提质升级、提升桥梁护栏及连续长陡下坡安全保障等专项行动，深入开展公路安全风险排查，制定工作清单和处治措施。同时，加强汛前和汛期公路基础设施排查整治工作。在暴雨、台风等极端天气来临之前，加大对公路、桥梁、隧道的巡查力度，特别是对临江、沿河、山区等灾害易发路段，要在汛前开展一次全面排查。一旦发现问题或隐患，要按照“安全第一，保障通行”的原则，立即采取有效措施进行处治，及时排险除患；一时难以整治的，要采取必要的防范措施，设立醒目的警示标志，并落实人员严密监控，防患于未然；对存在重大安全隐患的，要立即封闭交通或安排专人值守，尽量避免和减少灾害发生，降低灾害对公路通行的危害程度。

三、完善应急预案，做好应急保障

要完善应急预案及抢险方案，备齐备足各类公路交通防汛应急装备物资，加强与当地救援队伍合作联动。发生公路阻断时，第一时间到现场指挥调度处置，合理调配应急抢险队伍，全力抢通，确保公路畅通。要按照“先抢通，后修复”的原则，统筹安排，科学调度，集中力量先抢通主要干线公路。难以及时抢通的，要制定切实可行的绕行方案，并向社会公布。发生重大公路中断情况时，要迅速向当地人民政府和上级主管部门报告，并在当地人民政府和上级主管部门领导下，做好公路抢通保通工作。要密切关注灾区道路运输保障情况，加强组织协调和区域间的信息沟通与合作，千方百计组织充足运力，及时安全转移受灾群众及各种救灾物资，为抗灾救灾工作顺利进行提供有效保障。

四、加强沟通协调，确保信息畅通

要加强汛期重点地区路网运行监测，及时发布路况信息，服务群众安全出行。主汛期间，要加强值班值守，坚持执行24小时防汛值班制度，确保信息畅通。遇有台风、持续强降雨等重大灾情时，省级交通运输主管部门要及时汇总省域内交通阻断和抢险保通最新信息，于每日上午9时前通过“公路灾毁信息采集系统”上报。同时，要积极会同省级财政部门，根据本区域公路灾损抢修保通情况，按照《车辆购置税收入补助地方资金管理暂行办法》（财建〔2014〕654号）要求，及时向部申请公路灾毁抢修保通资金。

交通运输部办公厅
