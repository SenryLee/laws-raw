# 自然资源部办公厅关于印发《〈中国自然资源年鉴〉（2019年卷）框架结构》并组稿的通知

自然资办发〔2019〕41号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局，有关学会、协会：

《中国自然资源年鉴》是自然资源部组织编纂的反映我国自然资源事业发展全貌的专业性年鉴，是全面了解年度自然资源工作情况、科技成果和权威信息的重要工具书。部领导高度重视年鉴工作，同意成立中国自然资源年鉴编辑委员会，统筹协调领导中国自然资源年鉴编辑工作。陆昊部长担任编委会主任，库热西副部长任副主任，国家林业和草原局、中国地质调查局，部机关各司局、各直属单位，各省、自治区、直辖市及计划单列市自然资源主管部门负责同志，新疆生产建设兵团自然资源主管部门负责同志组成编委会。中国自然资源年鉴编辑部设在部宣教中心。

为做好反映2018年度自然资源工作的年鉴组稿、撰稿工作，现将《<中国自然资源年鉴>（2019年卷）框架结构》及《组稿细则》等印发给你们，并就有关事项通知如下：

一、各单位要高度重视年鉴编纂工作，加强组织领导，充分发挥组织协调作用，配备政治过硬、专业熟练的年鉴编纂人员。要认真做好稿件内容的审核工作，严把质量关，切实对所提供稿件的真实性、准确性、权威性、完整性负责，按时保质报送稿件。

二、各单位组稿供稿工作要严格按照年鉴框架结构、组稿细则、供稿样例（附件1、2、3）等要求报送，准确完整地填写审稿表（附件4），其中所注明的各单位主要（或分管）负责同志、办公室主任（综合处处长）和撰稿人，将分别作为编委、通讯编辑和撰稿人入书。

三、请各单位务必于9月30日前将稿件寄送中国自然资源年鉴编辑部，需提供纸质稿和电子稿（word格式）各1份。
