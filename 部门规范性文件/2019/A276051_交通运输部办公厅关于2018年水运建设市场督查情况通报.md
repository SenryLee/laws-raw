# 交通运输部办公厅关于2018年水运建设市场督查情况通报

为贯彻落实2018年全国交通运输工作会议精神，加强水运建设市场事中事后监管，促进水运建设市场健康有序发展，部于2018年组织了全国水运建设市场督查工作，经交通运输部同意，现将有关情况通报如下。

一、水运建设市场督查工作情况

2018年，水运建设市场督查工作按部、省、市三级分别组织开展。部水运局对广西、河北、安徽、江西、青海、陕西6省区进行了市场督查，部长航局、海事局、救捞局分别对系统内建设项目进行了督查；25个省级交通运输主管部门开展了督查，并指导市级交通运输主管部门开展督查工作。

据统计，全年省级以上督查共计92次，督查项目528个，发现问题2284个。其中，诚信履约方面214个，占比 9.4%；基建程序方面115个，占比5.0%；招标投标方面89个，占比3.9%；从业行为方面403个，占比17.6%；质量安全方面1194个，占比52.3%，其他方面269个，占比11.8%。

与2017年相比，2018年省级以上水运建设市场督查次数减少18%，督查项目总数基本持平，其中综合类督查占比提高5%，反映出省级以上水运建设市场督查已逐步按照中央有关要求，朝着精简次数与频率、加强综合督查、提高督查质量的方向发展。

从督查发现的问题来看，质量安全和从业行为2个方面问题数量较多、占比较大，说明市场从业主体在这两个方面还存在薄弱环节；基建程序和招标投标2个方面问题数量较少，反映出港口码头未批先建专项整治和工程围标串标等专项治理工作取得的实效得到有效巩固。

对于督查发现的问题，各级交通运输主管部门采取行政处罚、责令整改、录入信用记录、行业通报、约谈警示等多种方式进行处理，切实加强了事中事后监管，维护了市场秩序。

二、全国水运建设市场总体评价

2018年，各级交通运输主管部门、部属有关单位认真落实国家和部有关规定，在加快水运基础设施建设的同时，不断加强基本建设程序管理，规范招标投标行为，进一步完善相关规章制度，创新监管方式方法，水运建设市场信用管理体系逐步完善，市场监管水平稳步提升。

（一）“放管服”改革不断深化。

为进一步深化水运建设领域“放管服”改革，部修订印发了《港口工程建设管理规定》（交通运输部令2018第2号），优化了管理方式和程序，建立了协同监管机制；修订印发了《公路水运工程监理企业资质管理规定》（交通运输部令2018第7号），简化了监理企业资质行政审批事项和申报材料，优化了审查工作。吉林、广东分别印发了《优化交通运输行政审批工作举措清单》《关于修订政府投资普通公路和水运项目报批流程和分级审批权限的通知》，通过简化办理流程、减少申报材料等措施，提升行政许可办理效率。天津主动推行“以函代证”、告知承诺制，精简审批要件。福建完善了水运工程建设管理行政权力清单、责任清单和公共服务事项清单。珠航局在珠江水系开展了水运建设市场“双随机、一公开”抽查工作，建立了基础数据库。

（二）信用体系建设稳步推进。

部持续推进水运建设市场信用体系建设，印发《交通运输部办公厅关于界定和激励公路水运工程建设领域守信典型企业有关事项的通知》（交办水〔2018〕11号），公布2018年水运工程建设领域守信典型企业目录，建立了交通运输行业第一个信用“红名单”制度。广西、江西等多个省份制定了水运工程信用评价实施细则，开发了信用管理系统。

（三）电子招投标应用逐步扩大。

部分地方交通运输主管部门大力推进电子招标投标工作。福建编制印发了《公路水运工程电子招标投标示范文本》，并加强对电子招标投标的行政监督，实现招标投标全流程电子化、全过程留痕，提高公共资源交易公开透明度。江西建成水运工程施工电子化招标系统，积极推动电子招标投标工作，建立了“投标信息必采集，采集信息必公开、信息造假必严惩”的机制。

（四）贫困地区水运建设力度不断加强。

部高度重视贫困地区水运建设发展。2018年，先后赴江西、青海、陕西等省份贫困地区进行水运建设督导，提高贫困地区水运建设管理水平。江西加快推动赣江井冈山航电枢纽等贫困地区、革命老区水运基础设施建设，青海制定了《青海省海事水运脱贫攻坚三年行动计划（2018—2020）》，陕西制定了《陕西省交通扶贫行动计划》，加大资金、技术等方面的支持力度，改善贫困地区航道通航条件，助力贫困地区脱贫致富。

三、水运建设市场存在的主要问题

督查中发现的问题主要表现在以下几个方面。

（一）部分省份市场督查工作不到位。

部分省级交通运输主管部门未建立规范化、常态化的市场督查机制。如陕西未对督查中发现的问题整改情况进行有效跟踪落实；广西区级质监站监督检查力量较弱，人员配备不足，水运建设市场监督检查工作力度有待加强。

（二）部分省份基本建设程序不规范。

部分省、市级交通运输主管部门基本建设程序行政审批未严格执行有关规定，批复文件不规范。如安徽合肥港综合码头二期工程交工验收证书中码头等级与批复等级不符；广西西津二线船闸工程初步设计批复概算超出工可估算10%。

（三）部分市场从业单位履约情况较差。

部分从业单位诚信意识不强、履约意识较差，主要表现一是人员履约不到位，履约人员变更比例大、资格能力低于投标承诺，主要人员同时在多个工程从业等，如督查发现广西八桂工程监理咨询有限公司2名监理工程师同时在崇左港中心港区濑湍作业区工程和西江航运干线贵港航运枢纽二线船闸工程两个大型水运工程中从业；二是施工机械、设备履约不到位，未按投标承诺进场，如中铁建港航局在安徽水阳江航道整治工程中投标承诺中75%的船舶设备未到位。

（四）部分项目安全质量管理水平有待提高。

部分项目安全质量管理不到位，主要表现：一是工程细部环节质量控制不佳，如安徽水阳江航道整治工程部分钢筋机械连接接头丝扣外露数量超过规范要求，套丝扣前未对钢筋端部进行处理；二是施工现场安全防护措施不到位，如西江航运干线贵港航运枢纽二线船闸工程现场安全标志标牌不足，临边防护不完善，边坡防护不到位，临时用电管理存在安全隐患；三是施工企业对于各级督查发现的安全质量问题整改不到位，监理单位、建设单位监督力度不足。

（五）信用管理工作重视程度不足。

部分省级交通运输主管部门对于水运建设市场信用管理工作重视程度不足，如四川、福建报送2018年度信用评价结果严重滞后，河北信用评价档案较为混乱；部分项目单位未认真开展信用评价工作，信用评价基础材料不全，信用信息台账未建立，如唐山港口实业集团有限公司信用评价资料整理不规范、不完整。

四、工作要求

（一）强化2018年督查发现问题整改落实。

加强对2018年督查发现问题整改工作的跟踪和督促落实，实行问题清单销号管理，采用信用惩戒、约谈警示、行政处罚等多种手段，确保问题整改到位；同时，认真对照典型问题，举一反三，不断完善管理制度。部将适时开展抽查和“回头看”

（二）做好2019年水运建设市场督查工作。

按照各省份督查检查年度计划安排，增强督查检查工作的科学性、针对性、实效性，创新推进信用风险分类监管、“互联网+监管”等手段，健全以“双随机、一公开”监管为基本手段、以重点监管为补充、以信用监管为基础的新型监管机制。加强对贫困地区水运建设的指导和帮助，切实提高水运建设市场监管效能。

（三）不断提高依法行政能力。

加强水运建设有关法律法规的学习和宣贯，提高依法行政能力，严格按照《航道建设管理规定》（交通部令2007第3号）、《港口工程建设管理规定》（交通运输部令2018第2号）等规定，进一步做好初步设计、竣工验收等行政审批工作，规范批复文件。

（四）深化水运建设领域信用体系建设。

进一步加强信用体系建设，不断完善信用信息系统，及时开展信用评价工作，完善信用档案，采取切实措施不断提高从业主体的诚信履约意识。按照《交通运输部办公厅关于界定和激励公路水运工程建设领域守信典型企业有关事项的通知》（交办水〔2018〕11号）要求，研究实化具体措施，保证激励措施有效落实，形成浓厚的诚信激励氛围。

（五）继续夯实专项整治成果。

按照《交通运输部办公厅关于贯彻落实<国务院办公厅关于全面治理拖欠农民工工资问题的意见>和治理拖欠工程款问题的通知》（交办公路〔2016〕106号）、《交通运输部关于做好公路水运行业清理拖欠民营企业中小企业账款工作的通知》（交公路明电〔2018〕18号）要求，将拖欠农民工工资和民营企业中小企业账款问题作为水运建设市场监管的重要内容，加大监管力度，落实工作责任，建立长效机制；加大对水运工程建设领域专业技术人员职业资格“挂证”等违法违规行为的打击力度；开展“未批先建”港口码头整治工作“回头看”，建立监督长效机制，继续巩固夯实专项整治成果。
