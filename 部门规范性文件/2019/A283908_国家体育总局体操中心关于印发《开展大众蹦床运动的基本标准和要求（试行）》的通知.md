# 国家体育总局体操中心关于印发《开展大众蹦床运动的基本标准和要求（试行）》的通知

## 体育总局体操中心关于印发《开展大众蹦床运动的基本标准和要求（试行）》的通知

各有关单位：

近几年，大众蹦床运动在我国发展迅速。为规范管理，维护广大参与者的身心健康，促进项目的健康与可持续发展，现将《开展大众蹦床运动的基本标准和要求（试行）》印发你们，请遵照执行。

附件：开展大众蹦床运动的基本标准与要求（试行）
