# 国家文物局关于明十三陵建设控制地带内定陵、长陵环境整治项目的意见

文物保函〔2019〕819号

北京市文物局：

你局《关于明十三陵建设控制地带内定陵、长陵环境整治工程的请示》（京文物〔2019〕567号）收悉。经研究，我局原则同意在明十三陵建设控制地带内实施定陵、长陵环境整治项目。

一、所报方案尚需做以下必要的修改和完善：

（一）应充分利用既有线路进行管线改造，减少新的开挖，项目完成后要恢复地面铺装，局部管道架空部分，应提出景观处理要求。涉及新线路挖掘的，施工之前应开展考古工作，避让重要地下文物遗存；如需考古发掘，应另行填报考古发掘申请书。

（二）绿化设计应取消高大树木，以种植花草和少量浅根乔木为主；绿化范围不得靠近文物围墙散水，不得对墙体产生影响，以确保文物本体安全；应进一步确定牡丹与海棠等花卉树木的选用是否与保护规划、历史环境真实性保持一致，并应注意避免陵墓环境花园化的倾向。

（三）适当降低拟建铁艺栏杆高度。

（四）完善文物影响评估报告，补充对对绿化内容、种类、要求及与整体环境相协调的措施、停车场新换草坪砖的种类、要求等的评估。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

四、请你局督促地方人民政府加快推进明十三陵文物保护规划编制工作，统筹安排文物保护修缮和环境整治项目，进一步改善遗产保存现状及周边文物环境。

专此函复。

国家文物局

2019年8月15日
