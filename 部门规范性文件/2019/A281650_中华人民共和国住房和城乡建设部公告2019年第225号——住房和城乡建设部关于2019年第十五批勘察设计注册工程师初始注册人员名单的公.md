# 中华人民共和国住房和城乡建设部公告2019年第225号——住房和城乡建设部关于2019年第十五批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第225号

## 住房和城乡建设部关于2019年第十五批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，石朋飞等132名申请注册土木工程师（岩土）初始注册人员、孟庆东等168名申请一级注册结构工程师初始注册人员、张立柱等277名申请注册公用设备工程师初始注册人员、张斌等84名申请注册电气工程师初始注册人员、唐振邦等26名申请注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予石朋飞等132名注册土木工程师（岩土）初始注册人员名单

2.准予孟庆东等168名一级注册结构工程师初始注册人员名单

3.准予张立柱等277名注册公用设备工程师初始注册人员名单

4.准予张斌等84名注册电气工程师初始注册人员名单

5.准予唐振邦等26名注册化工工程师初始注册人员名单

住房和城乡建设部

2019年8月27日
