# 国家文物局关于牛角寨石窟保护范围和建设控制地带内保护利用设施项目的意见

文物保函〔2019〕293号

四川省文物局：

你局《关于报送〈牛角寨石窟保护利用设施设计方案>的请示》（川文物〔2019〕1号）收悉。经研究，我局原则同意牛角寨石窟保护范围和建设控制地带内保护利用设施项目。

一、对所报方案提出以下修改完善意见：

（一）补充保护规划中拟建项目的选址依据，明确保护范围和建设控制地带的建设控制要求。

（二）建设项目应考虑地形地貌、植被条件等因素，充分尊重文物历史环境风貌，避免过于现代化和园林化。大佛广场花坛建设必要性不足，建议取消；现有道路不宜过度扩宽；观景平台通向大佛龛的台阶建议随山势采取错落转折方式；防护栏杆建议选用护栏B的样式。

（三）根据保护规划和现场环境，充分论证围墙建设的必要性，提出比选选线和立面造型方案。

（四）进一步减小管理用房和公厕的体量、高度并优化外观设计，使其与文物及环境相协调。

（五）深化文物影响评估报告，科学、客观评估拟建设施对文物安全及景观的影响程度，从不同角度和点位进行景观视线分析，并提出相应的减缓措施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月22日
