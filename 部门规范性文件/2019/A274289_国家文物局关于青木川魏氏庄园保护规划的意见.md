# 国家文物局关于青木川魏氏庄园保护规划的意见

文物保函〔2019〕98号

陕西省文物局：

你局《关于上报青木川魏氏庄园保护规划的请示》（陕文物字〔2018〕52号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）进一步加强研究。补充魏氏庄园建成的历史背景，突出其文化意义；加强周边环境历史格局的研究，补充说明庄园与周边老街、建筑的关系，细化历史环境要素认定；依据规划涉及区域，合理划定规划范围。

（二）完善现状评估。应针对每栋文物建筑明确其现存主要问题，细化评估结论；补充现有保护区划评估；补充山洪、泥石流等自然灾害的评估内容；区分用地性质和土地使用功能。

（三）进一步明确保护区划调整的原则和依据，说明区划调整的必要性。梳理管理规定，保护范围内非文物建筑的高度以控制总高为宜，建议将非文物建筑的拆除或整饬等内容纳入环境整治章节。

（四）应细化保护措施，针对各处文物本体制定主要保护措施。

（五）梳理细化各专项规划。完善展示利用规划，依据周边旅游设施规划，进一步测算规划的年游客数量，补充对瞬时游客容量阈值的测算与控制；进一步论述将东北侧民居全部拆除的依据、必要性和可行性；细化防灾减灾规划措施，完善消防系统规划；加强与相关规划的衔接，为相关规划编修提出要求或建议，避免重复规划内容。

（六）进一步规范图文表达，补充规划分期图等图纸。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见对规划进行必要修改和完善，经你局核准后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将青木川魏氏庄园保护规划报请陕西省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

四、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

五、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好青木川魏氏庄园文物的各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年1月25日
