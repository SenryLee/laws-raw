# 中共教育部党组关于查明建、冯庆华同志职务任免的通知

教党任〔2019〕117号

中共上海外国语大学委员会：

经与中共上海市委商得一致，2019年5月17日研究决定：

查明建同志任中共上海外国语大学委员会委员、常委；免去冯庆华同志的中共上海外国语大学委员会常委职务。

中共教育部党组

2019年5月31日
