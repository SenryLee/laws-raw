# 国务院知识产权战略实施工作部际联席会议办公室关于公布2018年度知识产权战略信息工作先进个人及优秀知识产权战略信息评选结果的通知

国知战联办〔2018〕25号

国务院知识产权战略实施工作部际联席会议各成员单位、相关单位，各省、自治区、直辖市和新疆生产建设兵团知识产权局（知识产权管理部门）：

2018年，在国务院知识产权战略实施工作部际联席会议各成员单位、相关单位和各地方知识产权管理部门的共同努力下，知识产权战略信息工作取得了良好成绩，为知识产权战略实施和知识产权强国建设发挥了积极促进作用。为表彰先进，树立典型，根据《国家知识产权战略信息工作管理办法（试行）》（国知战联办〔2017〕18号），联席会议办公室组织开展了2018年度知识产权战略信息工作先进个人和优秀知识产权战略信息评选工作，共评出知识产权战略信息工作先进个人10名，优秀知识产权战略信息17篇，其中一等奖2篇、二等奖5篇、三等奖10篇。获奖名单如下：
