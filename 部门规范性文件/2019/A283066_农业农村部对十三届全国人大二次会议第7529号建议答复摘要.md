# 农业农村部对十三届全国人大二次会议第7529号建议答复摘要

## 十三届全国人大二次会议第7529号建议答复摘要

刘锦绣代表：

您提出的关于加强基层动物防疫体系建设的建议收悉。经商中央编办、财政部、教育部、现答复如下。

一、关于动物防疫财政支持政策

2018年，中央财政共安排动物防疫等补助经费68.28亿元，主要支持重点动物疫病国家强制免疫补助、强制扑杀补助、养殖环节无害化处理补助以及非洲猪瘟疫情防控等工作。考虑到动物防疫需要等实际情况，去年10月提前下达了2019年动物防疫补助经费54.96亿元。今年，中央财政又下达非洲猪瘟强制扑杀补助经费4.99亿元，有力支撑了非洲猪瘟疫情防控工作。为赋予地方政府更多自主权，进一步强化属地管理责任，2017年财政部、农业部联合印发《动物防疫等补助经费管理办法》，对强制免疫、无害化处理补助政策做出调整，实行“大专项+任务清单”管理方式，强制免疫和养殖环节无害化处理补助经费为指导性任务资金。各地可以在完成约束性任务的基础上，在大专项支持方向范围内，结合当地实际，按照有关规定统筹中央和地方资金，支持其他病死畜禽无害化处理等工作，进一步发挥财政资金补贴精准性和有效性，提高动物防疫工作效果。下一步，我们将进一步调整完善财政补助政策，继续支持各省动物疫病防控相关工作。

二、关于病原学实验室、动物防疫监督检查站、病死畜禽无害化处理场和畜牧兽医系统信息平台等动物防疫基础设施建设

国家发展改革委会同农业部、质检总局、国家林业局于2017年5月12日印发了《全国动植物保护能力提升工程建设规划（2017—2025年）》（以下简称《动植保工程规划》），明确提出重点加强动物疫病监测预警、动物防疫技术支撑、动物卫生监督、动物疫病预防控制、兽药质量监察等方面建设。其中，拟建设238个动物疫病病原学监测区域中心，对符合国家法规规定和省级政府已批准设立的303个动物及动物产品指定通道（公路动物防疫监督检查站）进行升级改造，在生猪调出大县和家禽饲养大县中条件具备的地区建设100个病死畜禽无害化收集处理场，整合建立国家动物疫病追溯监管平台。2017年和2018年，已安排中央预算内投资2.85亿元，用于相关项目建设工作。下一步，我们将按照《动植保工程规划》要求，根据地方申报情况和年度投资安排，加大动物防疫体系基础设施建设力度。

感谢您对动物防疫工作的关心，希望今后继续对我部工作给予支持。

农业农村部

2019年8月30日
