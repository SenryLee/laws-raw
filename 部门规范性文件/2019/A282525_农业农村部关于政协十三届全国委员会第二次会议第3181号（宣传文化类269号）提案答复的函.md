# 农业农村部关于政协十三届全国委员会第二次会议第3181号（宣传文化类269号）提案答复的函

## 关于政协十三届全国委员会第二次会议第3181号（宣传文化类269号）提案答复的函

你们提出的“关于打造工业，文旅并行的新普洱茶产业善用香港平台进军‘一带一路’市场”的提案收悉。现就涉及我部职能的部分答复如下。

一、 关于指导和扶持打造工业化普洱茶饮料产业

茶叶是我国重要的经济作物之一。近年来，我们在绿茶和红茶栽培、加工、推广等方面积极探索，积累了一些好经验，在普洱茶领域也已建立了相关标准，如国家标准“GB/TD22111-2008地理标志产品普洱茶”、农业行业标准“SN/T 4256-2015出口普洱茶良好生产规范”、地方标准“DB53/T216-2007普洱茶中茶多酚的测定方法”和“DB53/T236-2007普洱茶冲泡方法”等。为满足行业发展需求，我部成立了农产品加工标准化委员会，每年向行业征集农业行业标准制修订需求。2018年共征集154项立项建议，经专家评审，最终上报38项。2019年3月，我部根据《农业行业标准制定和修订项目任务指南》，组织农产品加工领域农业行业标准项目申报，相关单位按照程序，通过农产品加工标准化委员会进行标准申报。下一步，我部将梳理涉及茶产业各环节的相关标准，完善普洱茶生产加工标准体系，推动按标生产，提升茶产品质量安全水平，总结推广各地推动茶产业发展的成功经验，促进普洱茶饮料产业发展。

二、关于支持建立普洱茶工业+文化旅游一体化示范基地

为贯彻落实党中央、国务院关于开展田园综合体建设试点工作的决策和部署，2017年5月，财政部印发《关于开展田园综合体建设试点工作的通知》（财办〔2017〕29号），确定自2017年起，按照三年规划、分年实施的方式，在全国18个省份开展田园综合体建设试点。每个试点省份安排田园综合体试点1～2个，由试点省份有关部门统一组织以竞争立项的方式确定，各省可根据实际情况确定具体试点项目个数，鼓励有条件的省份开展省级田园综合体试点。各地从实际出发，遵循客观规律，因地制宜选择田园综合体建设模式和运营管理模式。你们提出的“关于在西双版纳自治州建设普洱茶工业+文化旅游一体化示范基地，打造新型田园综合体的建议”，是对田园综合体建设模式的积极探索。下一步，我部将会同有关部门，结合实施乡村振兴战略，在总结3年试点情况的基础上，统筹研究试点相关工作。在现有试点项目建设完成之前，暂不安排新的田园综合体试点。

三、关于善用香港国际化平台推广普洱茶，进军“一带一路”市场

2018年，我国茶叶出口37.7万吨，出口额19.1亿美元，出口额同比增长10.3%。其中普洱茶出口0.3吨，出口额2804万美元。我国普洱茶主要出口马来西亚、韩国、日本和中国香港等国家和地区。自2003年内地与香港更紧密经贸关系安排（CEPA）签署以来，内地对香港茶叶出口增长迅速。下一步，我部将积极推动普洱茶商协会和企业利用中国国际农产品交易会、中国国际茶叶博览会、香港“一带一路”国际食品展、香港国际茶展等国际化平台，建设普洱茶海外展示中心，加强宣传推介，提升普洱茶品牌的知名度、影响力和竞争力，积极开拓包括“一带一路”沿线国家和地区在内的国际市场，推动普洱茶“走出去”。

感谢你们对“三农”工作的关心，希望继续对我部工作给予支持。
