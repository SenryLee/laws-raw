# 国家文物局办公室关于云南锦锐古建筑园林有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕690号

云南省文物局：

你局《关于变更云南锦锐古建筑园林有限公司资质证书的请示》（云文物〔2019〕91号）收悉。

经研究，我局同意云南锦锐古建筑园林有限公司文物保护工程施工一级资质证书中的单位地址由“云南省昆明市北京路延长线江东花园南路附2号银座office公园6-7号”变更为“云南省昆明市金马寺大村6号金马街道办公楼五楼507室”，法定代表人由“阮家庆”变更为“何铸赟”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年8月5日
