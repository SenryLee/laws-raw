# 国家中医药管理局医政司关于报送部分深度贫困地区中医药工作有关情况的通知

## 关于报送部分深度贫困地区中医药工作有关情况的通知

国中医药医政基层便函〔2019〕3号

四川省、云南省、西藏自治区、甘肃省、青海省、新疆维吾尔自治区中医药管理局医政处：

为贯彻落实《中共中央办公厅 国务院办公厅关于支持深度贫困地区脱贫攻坚的实施意见》（厅字〔2017〕41号）和《关于实施健康扶贫工程指导意见》（国卫财务发〔2016〕26号）的要求，进一步加大“三区三州”深度贫困地区中医药健康扶贫工作力度，我局拟制定“三区三州”中医药健康扶贫工作方案，采取更加集中的支持、更加有效的举措、更加有力的工作，助力扶贫攻坚。现请你局组织有关部门、单位认真填报“三区三州”中医药工作有关情况调查表（详见附件），并于1月30日前经省级中医药主管部门汇总后，以纸质版（盖章）和电子版形式反馈我司基层服务管理处。
