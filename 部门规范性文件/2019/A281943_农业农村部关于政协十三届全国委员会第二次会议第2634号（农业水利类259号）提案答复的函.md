# 农业农村部关于政协十三届全国委员会第二次会议第2634号（农业水利类259号）提案答复的函

## 关于政协十三届全国委员会第二次会议第2634号（农业水利类259号）提案答复的函

农办案〔2019〕83号

谢尚果委员：

您提出的"关于深化我国糖业二次创业，推动传统糖业向全链条蔗业转型的提案"收悉。经商发展改革委、工业和信息化部，现答复如下。

一、关于传统"糖业"升级为全链条"蔗业"

我部会同发展改革委等部门，按照农村产业融合发展的思路，推动蔗业全产业链发展。一是培育融合主体。截至2018年底，认定广西农业产业化龙头企业31家，支持5家农业产业化龙头企业发展甘蔗纸浆、机制纸、生物有机肥、食用酒精等产业，引导广西培育一批农业产业化龙头企业带动、合作社和家庭农场跟进、广大小农户参与的农业产业联合体，推动传统"糖业"向全链条"蔗业"发展。二是搭建融合载体。支持广西建设农业产业强镇，引导甘蔗经营主体跨界配置农业和现代产业要素，促进产业交叉融合，推动"甘蔗+"多业态发展，健全利益联结机制，形成原料生产、精深加工、体验展示、物流销售有机衔接的全产业链发展格局。目前，支持广西建设农业产业强镇20个，其中3个强镇以甘蔗为主导产业，建设甘蔗种植基地、打造电商平台、培育品牌、发展甘蔗休闲旅游等。三是加大技术创新推广。2018年，我部新增国家甘蔗加工技术研发专业中心，支持广西农垦糖业集团开展产学研联合攻关，加快蔗业加工技术创新，推动形成蔗、糖、酒、浆、纸、生物肥等为一体的循环型全产业链。四是推进甘蔗生产全程机械化。支持广西等地探索完善甘蔗生产全程机械化生产运营机制，将甘蔗收获机、剥叶机、割铺机等纳入农机购置补贴范围，逐步提高甘蔗收获机的最高补贴限额，推进甘蔗收获机械化进程。

二、关于建设智慧蔗业中心

我部会同工业和信息化部，多举措布局推进甘蔗等智慧农业发展。一是强化政策引导。我部印发《关于推进农业农村大数据发展的实施意见》，支持广西农业生产智能化，推进物联网技术在蔗业中的应用，鼓励发展农机应用大数据。工业和信息化部印发《大数据产业发展规划（2016—2020年）》，推动农业大数据应用，推进农业经营管理方式变革和产业价值链体系重构。二是实施农业物联网区域试验工程。从2013年开始，我部先后在天津、上海、安徽、吉林、江苏实施农业物联网区域试验工程，推介可复制可推广的农业物联网技术310项、节本增效农业物联网应用模式116项、农业物联网应用多媒体宣传影片10部，为广西建设智慧蔗业中心提供借鉴。三是推进智慧农业工程建设。我部召开全国农业物联网工作会议，推进包括甘蔗在内的智慧农业工程建设。目前正在指导各地建设大田种植、设施园艺示范基地，熟化农业物联网关键技术和成套设备，推广节本增效农业物联网应用模式。

三、关于打造蔗业集群，建设智慧蔗业产业园

近年来，我部会同财政部等部门，以现代农业产业园、核心生产基地建设等为平台，大力延伸甘蔗产业链，拓宽甘蔗产业带，着力打造蔗业集群。一是支持建设核心原料生产基地，为蔗业集群发展打牢基础。发展改革委会同我部印发《糖料蔗主产区生产发展规划（2015-2020年）》，选定广西南宁等10个市的32个县（市、区）为糖料蔗核心基地，计划定额补助42亿元用于广西、云南700万亩糖料蔗核心区田间工程建设。二是支持建设现代农业产业园，打造蔗业全产业链发展平台。2017-2018年，我部会同财政部启动现代农业产业园建设，认定广西来宾市现代农业产业园为首批国家现代农业产业园，推动"生产+加工+科技+品牌"一体化发展，支持建设一二三产业融合发展区和新型主体创业孵化区，打造完整甘蔗全产业链，构建"二次连动+分红"富农利益联结机制。三是拓展农业功能，促进甘蔗产业延伸融合。2016年，我部会同发展改革委等14部门印发《关于大力发展休闲农业的指导意见》，指导广西建设甘蔗农业主题公园，推进甘蔗产业与文化、旅游有机深度融合。

下一步，我部将会同发展改革委等部门，研究支持政策，加大支持力度，促进甘蔗产业创新发展，推动传统糖业向全链条蔗业转型。

感谢您对农业农村工作的关注，希望继续对我部工作给予支持。

农业农村部

2019年8月29日
