# 国家体育总局反兴奋剂中心关于印发《大型赛事兴奋剂检查站相关工作规范（暂行）》的通知

体反兴奋剂字〔2019〕546号

各省、自治区、直辖市、新疆生产建设兵团体育局，中央军委训练管理部军事体育中心，体育总局各厅、司、局，各运动项目管理中心、有关直属单位，中国足球协会、中国篮球协会，有关运动项目协会，各大型赛事组织方，有关单位：

兴奋剂检查站是实施兴奋剂检查样本采集过程的重要场所,因此在大型赛事比赛场馆内及运动员集中住宿区域设置合理、规范的兴奋剂检查站是执行赛事兴奋剂检查的基本前提和必要保障。为了统一标准、规范操作，体育总局反兴奋剂中心根据世界反兴奋剂机构颁布的《检查和调查国际标准》的要求，并结合以往历次大型赛事的兴奋剂检查工作经验，起草了《大型赛事兴奋剂检查站相关工作规范（暂行）》，供大型赛事组织方参照执行。该工作规范中有关兴奋剂检查站布局、物资及人员配备等要求也同样适用于单项体育赛事。

体育总局反兴奋剂中心

## 大型赛事兴奋剂检查站相关工作规范（暂行）

在大型赛事比赛场馆以及运动员集中住宿区域设置标准、规范的兴奋剂检查站是执行赛事兴奋剂检查的基本前提和必要保障。为了统一标准、规范操作，体育总局反兴奋剂中心根据世界反兴奋剂机构颁布的《检查和调查国际标准》的要求，并结合以往历次大型赛事的兴奋剂检查工作经验，起草本工作规范（暂行），供大型赛事组织方参照执行。该工作规范中兴奋剂检查站布局、物资及人员配备等要求也同样适用于单项体育赛事。

一、兴奋剂检查站建设及布局要求

在大型赛事中，所有体育竞赛场馆以及运动员集中住宿区域（如运动员村）均应设立兴奋剂检查站。

为了在兴奋剂检查过程中保护运动员的隐私及安全，兴奋剂检查站应是完全独立、安全带锁、门窗密闭良好且玻璃窗配有窗帘的房间，该房间在赛事期间只能用于兴奋剂检查。

根据工作需要，兴奋剂检查站由候检室、工作室（含操作间和卫生间）、办公室、志愿者休息室和储藏室5部分组成，其中候检室和工作室原则上应房间相连。兴奋剂检查站位置和布局的具体要求详见附件1。

二、兴奋剂检查站物资配备要求

（一）兴奋剂检查站工作物资分为专用物资和通用物资，专用物资由反兴奋剂中心提供，通用物资由赛事组织方提供。候检室、工作室和卫生间内的通用物资为强制要求，具体清单详见附件2。

（二）赛事组织方应在赛事期间在兴奋剂检查站内摆放充足的饮料供受检运动员饮用。饮料提供的具体要求详见附件3。

（三）赛事组织方应制作兴奋剂检查站标牌和桌签张贴或摆放在兴奋剂检查站内，并制作兴奋剂检查站通行证供赛时使用。制作标牌、桌签及通行证的模板详见附件4。同时，应制作兴奋剂检查站位置指引标识摆放或张贴在竞赛场馆及运动员集中住宿区域。

三、兴奋剂检查站工作团队配备要求

（一） 兴奋剂检查站工作团队组成

兴奋剂检查站工作团队由兴奋剂检查站站长、陪护员协调主管、场馆协调主管（副站长）、检查官、志愿者陪护员、安保人员、样本传送员（如需）组成。以上岗位具体人员数量配置根据检查项目、检查数量、兴奋剂检查站规模等因素确定。其中，兴奋剂检查站站长、陪护员协调主管和检查官由反兴奋剂中心派出，场馆协调主管（副站长）、志愿者陪护员、安保人员和样本传送员由赛事组织方选派。

（二）反兴奋剂中心派出人员

1.兴奋剂检查站站长：负责全面管理兴奋剂检查站工作团队的工作。

2.陪护员协调主管：负责组织志愿者陪护员完成通知和陪护工作。

3.检查官：负责采集兴奋剂检查样本。

（三）赛事组织方配备人员要求

1.场馆协调主管（副站长）：负责承担兴奋剂检查站的相关后勤保障工作。赛事组织方应配备工作经验丰富、善于沟通交流且能尽早到岗的属地工作人员担任场馆协调主管（副站长），便于完成场站改建以及完成与业务相关部门的各项协调沟通工作。

2.志愿者陪护员：负责接受培训并配合完成兴奋剂检查通知和陪护工作。赛事组织方可招募年满18周岁的当地高等院校在校生作为志愿者。国际赛事中，志愿者陪护员还应熟练掌握英语。

3.安保人员：负责在检查工作期间对进站人员进行权限验证。赛事组织方应在兴奋剂检查站开站期间，在站外门口处设安保人员协助完成进站秩序的管控。

4.样本传送员：负责将兴奋剂检查样本传送至北京兴奋剂检测实验室。赛事组织方应根据工作需要安排责任心较强的工作人员或志愿者担任样本传送员。

四、兴奋剂检查站工作保障要求

（一）证件

兴奋剂检查站工作团队人员应持有赛事的身份注册卡，通行权限应包括赛场区域、新闻发布会区、颁奖区、放松区、赛后控制区、看台、运动员住宿房间等运动员可能到达的全部区域。其中，兴奋剂检查站站长的身份注册卡通行权限应为全部区域通行。

（二）交通和食宿

赛事期间应保障兴奋剂检查站工作团队人员往返驻地及场馆之间的交通安排。由于兴奋剂检查通常在比赛之后进行，还应解决受检运动员结束检查后送返驻地的交通安排。同时，赛事组织方还应负责兴奋剂检查工作人员将样本传送至北京实验室等工作的交通。

赛事期间应保障兴奋剂检查站工作团队人员的食宿安排，原则上相关费用由赛事组织方负担。

（三）工作待遇

兴奋剂检查站站长、陪护员协调主管和检查官应编入赛事秩序册中裁判员序列。其中，兴奋剂检查站站长的工作补助和待遇与国家级裁判长一致，陪护员协调主管、检查官的工作补助和待遇与国家级裁判员一致。
