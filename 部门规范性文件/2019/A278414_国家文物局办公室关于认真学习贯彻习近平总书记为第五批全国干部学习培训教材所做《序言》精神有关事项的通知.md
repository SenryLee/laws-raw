# 国家文物局办公室关于认真学习贯彻习近平总书记为第五批全国干部学习培训教材所做《序言》精神有关事项的通知

办人函〔2019〕528号

各司室，各直属单位：

按照中组部《关于认真学习贯彻习近平总书记为第五批全国干部学习培训教材所做〈序言〉精神的通知》（中组发〔2019〕5号）要求，现就局系统广大干部学习贯彻《序言》精神，学好用好教材事项通知如下：

《序言》站在党和国家全局高度，深刻阐述了新时代全党加强学习培训、用党的创新理论武装头脑的重大意义，强调善于学习就是善于进步，对加快推进马克思主义学习型政党、学习大国建设，加强干部教育培训提出了明确要求。局系统广大干部要结合学习贯彻习近平新时代中国特色社会主义思想，结合“不忘初心、牢记使命”主题教育，认真做好《序言》精神的学习，深刻领会《序言》精神，不断增强“四个意识”、坚定“四个自信”、做到“两个维护”。要注重结合工作实际学好用好第五批全国干部学习培训教材，坚持学习与思考、理论与实践相结合，深刻理解把握习近平新时代中国特色社会主义思想的时代意义、理论意义、实践意义。

各司室、各直属单位要加强《序言》精神学习的组织领导，明确学习要求，采取理论中心组学习、党支部学习等多种方式抓好学习任务落实。我局已为各司室、各直属单位分别购买2套学习用书，各司室、各直属单位主要负责同志要带头学习，带动本部门、本单位干部职工的学习，务求取得实实在在的效果。

特此通知。

国家文物局办公室

2019年6月12日
