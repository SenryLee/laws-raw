# 科学技术部对十三届全国人大二次会议第3606号建议的答复

## 对十三届全国人大二次会议第3606号建议的答复

国科建议资〔2019〕54号

您提出的《关于改革国家科技项目申报办法的建议》收悉。经认真研究，现答复如下。

您的建议十分中肯。近年来，党中央、国务院高度重视科研经费管理，促进中央财政科研项目资金管理改革向纵深推进，切实为科研人员“松绑”“减负”，激发科研创新活力。2018年国务院印发了《关于优化科研管理提升科研绩效若干措施的通知》（国发〔2018〕25号），提出了简化预算编制、合并财务与技术验收、开展“绿色通道”试点等一系列改革举措，科研资金管理领域“放管服”改革持续稳步推进。

为落实改革要求，2018年，科技部会同有关部门，开展了减轻科研人员负担专项行动，其中，“减表”行动系统梳理项目申报、立项、过程管理和综合绩效评价等环节，优化管理流程，整合项目申报书、任务书、年度报告、中期报告、综合绩效自评价报告等材料中的各类报表；将现有项目层面填报的表格，整合精简为6张；课题层面填报的表格，整合精简为8张，实现“一表多用、一表多能”，大大减少了科研人员在科研项目资金管理中填报的各类表格。

2019年，科技部、财政部发布了《关于进一步优化国家重点研发计划项目和资金管理的通知》（国科发资〔2019〕45号）,细化提出简化预算编制等要求，明确会议费/差旅费/国际合作交流费预算低于10%，无需提供测算依据；超过10%的，分类说明，但无需对每次会议、差旅做单独测算说明。此外，科技部会同财政部等部门正在推进国发〔2018〕25号文关于“绿色通道”改革试点，其中“简化项目预算编制”试点已经启动，将在2019年符合条件的新立项目中实行。

关于“包干制”的落实工作，科技部会同财政部、自然科学基金委等有关单位，综合考虑科研项目特点，科研领域差异，科研单位管理能力，项目团队规模和诚信记录等因素，目前，正积极探索在自然基金定额补助类项目中进行试点。

因2018年以来新的科研资金管理政策陆续出台，相关落实工作正在积极推进中。下一步，科技部将会同有关部门进一步加快政策落实进度，同时“双管齐下”，进一步加强对专业机构、会计师事务所等管理主体的培训和督导，针对科研经费管理中常出现的问题，进一步统一口径，明确政策要点，确保各项改革举措贯彻到位，切实让改革政策落地见效、让改革红利惠及科研工作者，最大限度的释放科研人员的创新创造活力。

感谢您对科技工作的支持！

科技部

2019年7月6日
