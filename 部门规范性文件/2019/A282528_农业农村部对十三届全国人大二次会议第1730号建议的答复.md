# 农业农村部对十三届全国人大二次会议第1730号建议的答复

## 对十三届全国人大二次会议第1730号建议的答复

王凌代表：

您提出的关于关注农村“空心化”现象的建议收悉。当前，农村人口大量外流，农村“空心化”问题是制约乡村振兴的重要因素。您针对破解“空心化”问题提出的强化“三个支撑”、做好“三篇文章”建议，很有借鉴意义。经商财政部，现答复如下。

一、关于强化规划支撑

习近平总书记强调，实施乡村振兴战略，要坚持规划先行、有序推进，做到注重质量、从容建设。今年中央一号文件提出，强化乡村规划引领，把加强规划管理作为乡村振兴的基础性工作。一是出台乡村振兴战略规划。去年，党中央、国务院印发《乡村振兴战略规划（2018—2022年）》（以下简称《规划》），明确了今后五年的思路目标和重点任务，将村庄划分为聚集提升、城郊融合、特色保护、搬迁撤并四类村庄。各地结合本地实际，均已编制出台了实施乡村振兴战略地方规划，针对重点领域和关键环节，出台了一批专项规划、重大行动计划和具体实施方案。二是建立《规划》落实部门协调推进机制。为推动《规划》各项目标任务落实落地，发展改革委、农业农村部会同有关部门建立了《规划》实施协调推进机制，中央组织部、中央宣传部等27个部门参加。通过加强部门沟通协商和联合协作，增强了相关政策衔接和工作协调，推动《规划》各项任务落实落地。同时，积极推动各省成立相应机制，层层推动《规划》任务落实。三是加快推动村庄布局和村庄规划编制。今年年初，中央农办、农业农村部、自然资源部等五部门联合印发《关于统筹推进村庄规划工作的意见》，明确提出要加快编制村庄布局规划和村庄规划，力争到2019年底，基本明确集聚提升类、城郊融合类、特色保护类等村庄分类；到2020年底，结合国土空间规划编制在县域层面基本完成村庄布局工作。

下一步，我部将会同有关部门加快推进《规划》在村域层面落实落地，指导各地以县为单位，加快编制或修编县域村庄布局规划，分类明确集聚提升、城郊融合、特色保护、搬迁撤并四类村庄分类，引导村庄依规有序发展。

二、关于强化产业支撑

习近平总书记指出，产业兴旺，是解决农村一切问题的前提。近年来，党中央、国务院高度重视乡村产业发展，不断强化顶层设计，加大支持力度，为村庄发展注入了强大动力。一是强化产业发展指导。国务院印发了《关于促进乡村产业发展的指导意见》，明确了促进乡村产业振兴的总体要求，提出了乡村产业发展重点任务和政策措施。制定了促进农产品加工业发展、休闲农业和乡村旅游发展、返乡下乡人员创新创业等政策文件，出台了一系列减免税收、金融信贷、科技支撑、用地用电等务实管用的扶持政策，为推动乡村产业发展提供政策保障。二是大力发展农产品加工业。深入推进农产品加工业提升行动，建设了15.6万座农产品初加工设施，新增初加工能力1000万吨，果蔬等农产品产后损失率从15%降至6%。2018年，规模以上农产品加工企业7.9万家、营业收入14.9万亿元，农产品加工业和农业总产值比达到2.3：1。三是不断丰富乡村产业类型。实施休闲农业和乡村旅游精品工程，推介一批休闲农业和乡村旅游精品品牌，2018年休闲农业和乡村旅游接待游客30亿人次、营业收入超过8000亿元。大力发展农产品电子商务，农村网络销售额突破1.3万亿元，其中，农产品网络销售额达3000亿元。创新发展乡村服务业，支持开展农资供应、代耕代种、统防统治、烘干收储等生产性服务业，农村生产性服务业营业收入超过2000亿元。四是打造产业发展平台载体。支持建设了国家现代农业产业园114个、国家农业科技园32个、农产品加工园1600个，创建农村产业融合示范园148个、农业产业强镇254个，推广农业内部循环融合、产业延伸融合、功能拓展融合、新技术渗透融合、产村融合和复合型融合等多种融合模式。五是积极支持农村创新创业。认定农村创新创业园区和实训孵化基地1096个，制定并落实支持返乡下乡人员创新创业政策，吸引农民工、大中专毕业生、退役军人、科技人员等到乡村创新创业。截至2018年，各类返乡下乡创新创业人员累计达780万，“田秀才”“土专家”“乡创客”等本乡创新创业人员达3100多万。

下一步，我部将会同有关部门认真贯彻落实中央部署要求，大力培育植根于县域，以农业农村资源为依托，以农民为主体，以农村一二三产业融合发展为路径，地域特色鲜明、创新创业活跃、业态类型丰富、利益连接紧密的乡村产业，引导各地因地制宜发展特色产业，把产业链尽可能留在县乡村，促进农民就地就近就业增收。

三、关于强化服务支撑

十九大报告提出要打造共建共治共享的社会治理格局，强调加强农村基层基础工作，健全自治、法治、德治相结合的乡村治理体系。今年6月，中共中央、国务院印发了《关于加强和改进乡村治理的指导意见》，提出抓实建强基层党组织、整顿软弱涣散的村党组织，选好配强农村党组织带头人，深化村民自治实践，发挥农民在乡村治理中的主体作用。我部认真贯彻中央部署要求，积极配合相关部门推进各类人才和组织在乡村治理中发挥作用，组织开展乡村治理体系建设试点，探索乡村组织协同发展的治理体系，发挥基层党组织和党员作用，拓展乡村组织人才来源，充分发挥各类人才在乡村治理中的积极作用。挖掘了一批创新治理方式，引导农民党员、基层人大代表、政协委员等参与乡村治理工作的案例。

下一步，我部将以树典型、抓创建、强示范、聚力量为工作抓手，会同相关部门进一步完善乡村治理体制、加强乡村治理体系建设、创新乡村治理方式、提升乡村治理能力，推进建设充满活力、和谐有序的乡村社会。

四、关于做好“人”的文章

习近平总书记强调，乡村振兴关键在人。近年来，中央及国务院有关部门高度重视农村人才队伍建设，先后出台了一系列强有力的政策举措，培养了一大批乡土人才，为乡村发展注入了生机活力。一是完善农村实用人才培养机制。大力开展农村实用人才带头人和大学生村官示范培训，扎实推进新型职业农民培育工程，圆满完成农村实用人才培养“百万中专生计划”。围绕中央脱贫攻坚决策部署，组织环京津贫困地区、定点扶贫和联系地区贫困村带头人轮训，带动各地不断加大农村实用人才培养力度，为实施乡村振兴战略、打好精准脱贫攻坚战发挥了骨干引领作用。二是强化农业科技人才队伍建设。实施农业科研杰出人才培养计划，依托现代农业产业技术体系、国家农业科技创新联盟、国家现代农业产业科技创新中心等，构建创新人才协同培养机制。以种业人才为突破口，推进农业科研成果权益改革。实施万名农技推广骨干人才培养计划，加强基层农技推广人员知识更新培训。启动农技推广服务特聘计划，健全完善“一主多元”的农业技术推广体系。目前，全国农业科技人才总体规模超过110万人，为加快我国农业科技创新提供了重要支撑。三是支持各类人才返乡下乡创业创新。2016年国务院办公厅印发《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》，为农村创业创新送出了政策“大礼包”。各级农业农村部门联合有关部门实施农村创业创新促进行动，加强创业培训指导，搭建服务平台，建设了1000多个农村创业创新园区，引导人才返乡创业兴业，带动大量当地农民就地就近就业。各地也因地制宜出台了一系列促进返乡下乡创业的政策措施，为农业农村发展注入了新要素新活力，有力推动了城乡融合发展。

下一步，我部将继续大力推进高素质农民队伍建设，培育更多懂农业、爱农村、爱农民的“三农”工作队伍，引导更多有意愿的人留在农村、扎根基层。

五、关于做好“地”的文章

土地是乡村最重要的生产要素，也是助力乡村振兴的重要资源。围绕代表提出放活宅基地和农房使用权问题，我部会同有关部门，指导各地通过推进宅基地改革试点工作，探索适度放活宅基地和农房使用权。一方面，积极盘活闲置宅基地和闲置农房资源。为解决农村宅基地和农房闲置浪费的问题，开展农村宅基地改革试点，主要通过闲置宅基地复垦，利用闲置农房发展乡村旅游、民宿，开展农民住房财产权抵押等方式盘活农村房地资源，增加农民收入。33个试点县（市、区）腾退出零星、闲置的宅基地约14万户、8.4万亩，办理农房抵押贷款5.8万宗、111亿元。安徽省六安市金寨县利用城乡建设用地增减挂钩政策，交易宅基地复垦指标2万亩，交易金额90多亿元。四川省泸州市泸县将宅基地复垦指标调整为集体经营性建设用地，用于集体建设或入市。江苏武进结合特色田园乡村创建，利用闲置农房开设农家乐和农事科普基地等。云南省大理州出台农民住房财产权抵押登记、抵押物处置、住房财产权评估等5个意见，农房抵押贷款余额达到13多亿元。另一方面，开展宅基地“三权分置”探索。为适度放活宅基地使用权，试点地区按照2018年中央一号文件的要求，在落实宅基地集体所有权，保障宅基地农户资格权的基础上，探索宅基地使用权放活的有效形式。浙江省金华市义乌市允许跨村转让一定期限的宅基地使用权，并明确集体作为使用权人可以收取一定的收益。河南省新乡市长垣县通过“按人确认、按户行使”的方式认定宅基地资格权，明确宅基地资格权可以退出和保留。湖南浏阳探索通过城乡居民合作建房的方式，适度放活宅基地使用权。

下一步，我部将会同有关部门，按照中央经济工作会议、中央农村工作会议和2019年中央一号文件精神，稳慎推进宅基地制度改革，在现有33个试点县（市、区）的基础上，再选择一批县（市、区）开展试点，研究提出支持闲置宅基地和闲置农房开发利用的政策措施，盘活乡村土地资源，更好服务乡村振兴。

六、关于做好“钱”的文章

乡村振兴需要真金白银的投入。正如代表所言，既需要增强“造血”能力，提高村集体经济收入；又需要加大“输血”力度，强化财政投入。党中央、国务院对此高度重视，出台了一系列的政策措施，积极拓宽乡村振兴投入渠道。一方面，发展壮大集体经济。财政部出台了《关于印发〈扶持村级集体经济发展试点的指导意见〉的通知》，自2016年起，中央财政通过以奖代补的形式，支持部分省份开展扶持村级集体经济发展试点工作，探索资源有效利用、提供服务、物业管理、混合经营等多种集体经济实现形式，完善村集体内部管理制度，增强村集体自我发展、自我服务、自我管理能力和水平，有效促进了当地村级集体经济发展。2018年，试点范围扩大至28个省份和4个计划单列市。在前期试点的基础上，2018年11月，我部会同中央组织部、财政部联合印发了《关于坚持和加强农村基层党组织领导扶持壮大村级集体经济的通知》，计划到2022年，中央财政在全国范围内扶持10万个左右行政村发展壮大集体经济，示范带动各地进一步加大政策支持、资金扶持和统筹推进力度。另一方面，加大财政投入力度。2018年全国一般公共预算农林水支出超过2万亿元，增长9.9%。2019年继续保持较高增长，高于全国一般公共预算支出平均增幅。同时，中央财政通过适度扩大财政赤字规模、盘活财政存量资金、调整优化财政支出结构等，加大对地方特别是老少边穷等财力困难地区的转移支付力度，支持各地更好推进乡村振兴工作。2019年安排中央对地方转移支付75399亿元，比上年增长9％。

下一步，我们将继续大力发展农村集体经济，持续深化农村集体产权制度改革，推动资源变资产、资金变股金、农民变股东，壮大集体经济组织；继续加大转移支付力度，不断增强基层财力保障能力，更好支持地方推进乡村振兴工作。

感谢您对推进乡村振兴战略实施工作的关心，希望继续对我部的工作给予支持。

农业农村部

2019年9月20日
