# 国家文物局关于在同盟国驻渝外交机构旧址群——法国领事馆旧址建设控制地带内进行十八梯片区道路工程建设项目的意见

文物保函〔2019〕156号

重庆市文物局：

你局《关于法国领事馆旧址建设控制地带内十八梯片区道路工程设计方案的请示》（渝文物〔2018〕373号）收悉。经研究，我局原则同意在法国领事馆旧址建设控制地带内进行十八梯片区道路工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）建议该道路工程位于建设控制地带以外的部分亦采用非爆破方式施工，且文物建筑结构顶点振速应按0.15mm/s控制；如确实需采用爆破方式施工，应制定专项施工方案，按照文物建筑最近点爆破安全振速0.1cm/s和距离不小于130米控制，以确保文物安全。

（二）补充施工期间以及运营期间对文物建筑震动和沉降影响的监测方案，落实责任单位，经费纳入工程预算。

（三）完善针对法国领事馆旧址的保护措施和应急预案。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月14日
