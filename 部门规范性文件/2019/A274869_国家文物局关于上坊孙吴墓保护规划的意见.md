# 国家文物局关于上坊孙吴墓保护规划的意见

文物保函〔2019〕229号

江苏省文物局：

你局《关于审批全国重点文物保护单位上坊孙吴墓保护规划的请示》（苏文物保〔2018〕310号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）应全面梳理考古研究成果，加强价值评估和现状评估，客观评价上坊孙吴墓的历史价值，明确保护棚保护展示方式的效果和文物病害问题，评估遗址周边工业污染的文物影响，为科学制定规划措施提供依据。

（二）细化文物保护措施，重点解决墓葬水害问题，评估墓葬原址展示的必要性和可行性，比选回填覆土保护、标识展示等多种方式，确保文物本体安全。

（三）完善环境整治规划，应补充场地竖向排水规划，采取有效措施疏导地表水流，回填水塘等环境整治措施应有利于场地排水；遗址东侧与上坊孙吴墓无关墓葬应进一步明确具体迁移选址和处理措施。

（四）简化展示利用规划内容，进一步明确考古遗址公园和遗址博物馆的功能定位；分析遗址博物馆建设的可行性和预期效果，科学确定博物馆建设规模、外观样式、高度等；主入口和遗址博物馆不宜在墓葬与黄龙山中轴线选址建设，建议调整至建设控制地带西侧。

（五）进一步完善文本、图纸，补充墓葬平剖面图、周边区域考古调查勘探图、现状道路网络图等。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将上坊孙吴墓保护规划报请江苏省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好上坊孙吴墓各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年3月1日
