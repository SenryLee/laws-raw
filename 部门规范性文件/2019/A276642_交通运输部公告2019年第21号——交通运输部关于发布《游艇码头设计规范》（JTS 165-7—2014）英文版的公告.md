# 交通运输部公告2019年第21号——交通运输部关于发布《游艇码头设计规范》（JTS 165-7—2014）英文版的公告

## 交通运输部公告

2019年第21号

## 交通运输部关于发布《游艇码头设计规范》（JTS 165-7—2014）英文版的公告

为加强水运工程行业标准对外交流，现发布《游艇码头设计规范》（JTS 165-7—2014），由交通运输部水运局负责管理和解释。英文版与中文版相关内容含义不一致的，以中文为准。

请将使用过程中发现的问题和修改意见建议反馈至中交第四航务工程勘察设计院有限公司（地址：广州市海珠区前进路161号，邮政编码：510230，电子邮箱：qinj@fhdigz.com），以便修订时参考。

特此公告。

交通运输部

2019年4月9日
