# 国家文物局关于殷墟保护区划内安钢第二炼轧厂炼钢区三次除尘及转炉二次除尘改造项目的意见

文物保函〔2019〕148号

河南省文物局：

你局《关于上报安钢第二炼轧厂炼钢区三次除尘及转炉二次除尘改造项目建设方案的请示》（豫文物〔2018〕296号）收悉。经研究，我局原则同意在殷墟保护区划内实施安钢第二炼轧厂炼钢区三次除尘及转炉二次除尘改造项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应按照《殷墟遗址保护总体规划（修编）》（2012-2025）要求，调整转炉三次除尘项目选址，避让殷墟遗址保护范围。

（二）应全面发掘已发现的两条宋代道路遗址，明确文物价值，并提出下一步处置方案。部分区域因水泥路面和覆盖钢渣无法开展考古勘探，应抓紧清理后补探。清理过程中如发现文物遗迹应立即停工，及时报请文物部门采取保护措施。

（三）应根据考古工作成果进一步深化、完善文物影响评估报告，并对方案提出完善建议。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

四、请你局指导当地政府，进一步加强世界文化遗产殷墟的保护，严格控制安阳钢铁股份有限公司在殷墟保护范围和建设控制地带内的征地扩建，并抓紧研究推进该企业整体迁离工作。

专此函复。

国家文物局

2019年2月13日
