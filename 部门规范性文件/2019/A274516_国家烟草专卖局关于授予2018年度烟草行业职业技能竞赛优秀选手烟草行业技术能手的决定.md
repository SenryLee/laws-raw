# 国家烟草专卖局关于授予2018年度烟草行业职业技能竞赛优秀选手烟草行业技术能手的决定

国烟人〔2019〕28号

行业各直属单位，国家局、总公司机关各部门、各单位：

根据《烟草行业职业技能竞赛管理办法》（国烟人〔2016〕323号）相关规定，为表彰在2018年行业职业（岗位）技能竞赛系列活动中取得优异成绩的选手，现决定：

授予王立山等166名同志“烟草行业技术能手”（名单见附件），颁发烟草行业技术能手证书并由所在省级局（公司）、工业公司颁发6000元奖金（税前）。

希望受到表彰的同志珍惜荣誉、再接再厉，进一步发挥模范带头作用，在各自工作岗位上再立新功。行业广大干部职工要以受到表彰的同志为榜样，学习先进、锐意进取，踏实工作、奋勇争先。各单位要高度重视技能人才队伍建设，积极开展各类职业技能培训、竞赛和岗位练兵活动，提升干部职工整体素质和技能水平，为推动行业持续健康发展做出更大的贡献。

附件：2018年度烟草行业职业（岗位）技能竞赛获得“烟草行业技术能手”人员名单

国家烟草专卖局

2019年1月30日
