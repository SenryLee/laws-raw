# 国家文物局办公室关于云中郡故城保护规划的意见

办保函〔2019〕94号

内蒙古自治区文物局：

你局《关于云中郡故城保护规划评审的请示》（内文物字〔2018〕59号）收悉。经研究，我局暂不同意所报规划。

一、所报规划应作以下必要修改和完善：

（一）应加强考古研究和历史文献梳理，科学确定城址范围、格局、历史沿革和保存现状等，客观评价云中郡故城在中国北方防御体系中的重要地位，进一步说明二道路墓群与城址的文化关系，为规划编制提供充分依据。

（二）应切实加强现状评估，全面评估已知文物遗存的保存现状、展示利用潜力和主要问题、保护管理现状，不应仅关注城墙、墓葬。

（三）应根据文物保存现状、保护管理需要和周边建设发展情况等因素，综合确定保护区划及其具体边界，增强可操作性。建议保护范围不再划分重点保护区、一般保护区，调整保护范围和建设控制地带范围，合理区分建设控制强度。保护范围管理规定应考虑用地性质全部调整为文物古迹用地、居民搬迁、禁耕、设置防护围栏等措施的合理性与可行性，补充现有建/构筑物管控要求；建设控制地带管理规定应进一步明确新建建筑体量、外观样式、色彩等要求。

（四）应针对文物病害制定针对性和可行性的保护措施，补充其他重要遗迹的保护措施，严格控制城墙本体维修范围、强度；猎杀破坏城墙和墓葬的动物、设置安全防护栏等措施应慎重考虑；环境整治、安防等措施应纳入相应章节。

（五）进一步评估遗址可视性和开放条件，近期应以现状保护为主，待考古和保护工作取得进展后，适时进行展示利用。简化展示规划内容，严格控制新建展示服务设施的数量、规模，不同意城墙、城门原址复建展示思路。

（六）应联合专业考古机构完善考古研究规划，明确考古工作目标、主要任务及近期重点项目，建设遗址地理信息系统，为后续保护展示提供学术支撑。近期应重点明确遗址分布范围、功能布局、道路和水系等；充分论证发掘城中大型建筑基址和二道路墓葬的必要性。

（七）应根据保护管理需要，统筹考虑规划范围内基础设施建设、道路系统、安防、消防、环境整治等专项规划内容，不宜面面俱到。

（八）应根据《全国重点文物保护单位保护规划编制要求》和相关规范，认真梳理文本结构和内容，规范图文表达，调整规划分期时限。

二、请你局指导规划编制单位联合专业考古研究单位，根据上述意见对云中郡故城保护规划进行修改完善，按程序另行报批。

专此函复。

国家文物局办公室

2019年2月15日
