# 国家文物局办公室关于扬州城遗址保护范围内扬州大学附属中学桃园校区改扩建项目的意见

办保函〔2019〕21号

江苏省文物局：

你局《关于审批扬州大学附属中学桃园校区改扩建项目方案的请示》（苏文物保〔2018〕357号）收悉。经研究，我局暂不同意在扬州城遗址保护范围内实施扬州大学附属中学桃园校区改扩建项目。

一、项目所在区域位于扬州城遗址保护范围和世界遗产中国大运河（扬州段）建设控制地带内，紧邻宋大城西门遗址和瘦西湖、二道河等自然景观，地理位置重要。应充分评估建设项目对宋大城西门遗址、大运河的环境影响，进一步论证项目实施的必要性。

二、请你局指导有关单位按照《扬州城遗址保护规划》、《大运河（扬州段）遗产保护规划》相关要求，研究扬州大学附属中学另行选址建设新校区的可行性，统筹考虑扬州城遗址保护利用与扬州市教育资源配置的关系。建议修缮、改造现有校舍建筑，满足全国中小学校舍安全工程标准，并与遗址景观风貌相协调。

专此函复。

国家文物局办公室

2019年1月14日
