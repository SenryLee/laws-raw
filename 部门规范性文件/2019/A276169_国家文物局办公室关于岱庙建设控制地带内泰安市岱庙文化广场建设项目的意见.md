# 国家文物局办公室关于岱庙建设控制地带内泰安市岱庙文化广场建设项目的意见

办保函〔2019〕213号

山东省文物局：

你局《关于报送岱庙保护区划内进行泰安市岱庙文化广场建设项目方案的请示》（鲁文发〔2019〕14号）。经研究，我局暂不同意在岱庙建设控制地带内实施泰安岱庙文化广场建设项目。

一、对所报方案提出以下修改完善意见：

（一）进一步评估拟建项目在岱庙与岱宗坊之间选址，以及建设方案采用与泰山自然古朴的历史风貌和文化氛围不相协调的人造景观化功能分区、排列历代帝王和名人塑像等设计手法，对于泰山的世界遗产突出普遍价值和真实性的影响。

（二）应在深入研究泰山历史、文化和遗产价值，全面开展项目所在区域考古工作的基础上，重新研究论证该区域的功能定位，并对项目方案做出整体调整。

（三）拟建项目所含御道、封祀坛、燎坛、曹公渠和凤凰台等大量复建内容，相关设计仅参考历史文献所记载的大致位置和形制，缺乏必要的考古依据和研究基础，不具科学性和可行性，应予去除。

（四）拟建管理用房设计不宜采用形制规格较高的古建筑外形设计，以免过于张扬，并对游客造成误导。

（五）补充泰山世界遗产区划图并标明拟建项目位置。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年3月26日
