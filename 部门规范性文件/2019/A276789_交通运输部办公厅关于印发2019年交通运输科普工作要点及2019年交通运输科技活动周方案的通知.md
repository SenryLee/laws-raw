# 交通运输部办公厅关于印发2019年交通运输科普工作要点及2019年交通运输科技活动周方案的通知

交办科技函〔2019〕628号

各省、自治区、直辖市交通运输厅（局、委），中国公路学会、中国航海学会，各共建高校，部属有关单位，部内各司局：

为贯彻科学技术普及法，结合落实《2019年全民科学素质行动工作要点》相关任务和《交通运输部关于加强交通运输科学技术普及工作的指导意见》（交科技发〔2019〕9号）要求，进一步加强交通运输科普工作，提升交通运输科普服务能力，在广泛组织申报的基础上，部研究制定了《2019年交通运输科普工作要点》和《2019年交通运输科技活动周方案》，现印发你们，请结合实际遵照执行。

附件：1.2019年交通运输科普工作要点

2.2019年交通运输科技活动周方案

交通运输部办公厅

2019年4月30日
