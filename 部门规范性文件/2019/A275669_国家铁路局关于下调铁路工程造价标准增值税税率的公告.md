# 国家铁路局关于下调铁路工程造价标准增值税税率的公告

国铁科法〔2019〕12号

按照《关于深化增值税改革有关政策的公告》（财政部 税务总局 海关总署公告2019年第39号）要求，现将《铁路基本建设工程设计概（预）算费用定额》（TZJ3001-2017）中第2.12条和《铁路基本建设工程投资估算预估算费用定额》（TZJ3002-2018）中第12条规定的“建筑安装工程费税金与设备购置费税金的税率”由“10%”调整为“9%”。

特此公告。

国家铁路局

2019年3月29日
