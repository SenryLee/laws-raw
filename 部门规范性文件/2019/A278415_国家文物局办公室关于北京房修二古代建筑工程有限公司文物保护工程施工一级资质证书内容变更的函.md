# 国家文物局办公室关于北京房修二古代建筑工程有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕469号

北京市文物局：

你局《关于北京房修二古代建筑工程有限公司资质证书单位地址变更的请示》（京文物〔2019〕655号）收悉。

经研究，我局同意北京房修二古代建筑工程有限公司文物保护工程施工一级资质证书中的单位地址由“北京市海淀区交大东路46号1号楼”变更为“北京市东城区东中街40号1号楼一层07号”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年5月31日
