# 农业农村部关于政协十三届全国委员会第二次会议第2593号（农业水利类254号）提案答复的函

## 关于政协十三届全国委员会第二次会议第2593号（农业水利类254号）提案答复的函

农办案〔2019〕96号

王召明委员：

您提出的"关于加快发展产业互联网，推动农业供给侧结构性改革的提案"收悉。经商商务部、发展改革委、工业和信息化部，现答复如下。

一、关于完善"互联网+农业"政策体系

党中央、国务院高度重视农业大数据创新应用和数字经济高质量发展。2019年中共中央办公厅、国务院办公厅印发的《数字乡村发展战略纲要》，提出"加快乡村信息基础设施建设、发展农村数字经济、强化农业农村科技创新供给、建设智慧绿色乡村"等重点任务，为推动互联网、大数据、人工智能和实体经济的深度融合指明战略目标和方向。我部及相关部门贯彻落实党中央、国务院决策部署，制定了《"十三五"全国农业农村信息化发展规划》《"互联网+"现代农业三年行动实施方案》《农业电子商务行动计划》《关于推进农业农村大数据发展的实施意见》等系列文件，近期正在起草《国家数字农业农村发展规划（2019—2025年）》，提出了当前和今后一段时期推进数字农业农村建设的发展目标、重点任务和支持政策，推动生产经营与数字技术深度融合、加快管理服务数字化转型，全面提升农业农村数字化、网络化、智能化水平，为发展产业互联网提供政策支撑。

二、关于"互联网+农业"基础设施建设

党中央、国务院高度重视农村地区信息化基础设施建设工作。工业和信息化部联合财政部开展了五批电信普遍服务试点，支持农村及偏远地区光纤建设和4G网络覆盖。中央财政和基础电信企业投资累计超过500亿元，支持全国13万个行政村光纤建设以及3.6万个基站建设。工业和信息化部联合发展改革委组织新一代信息基础设施工程，安排中央预算投资20亿元，着力提升中西部和东北地区农村和小城市宽带水平。截至2019年一季度，全国行政村通宽带的比例达到了98%,贫困村通宽带比例超过97%,农村互联网应用快速发展。

三、关于建设面向农业生产流通服务的工业互联网平台

一是建设推广工业互联网平台。工业和信息化部编制印发《工业互联网平台建设和推广指南》《工业互联网平台评价方法》等文件，初步形成了资源汇聚、协同发展的工业互联网平台体系，推动建立了50家具有一定行业区域影响力的平台。深入实施工业互联网平台培育、工业企业上云等工程，面向协同研发设计、产融合作创新等方向，打造10大平台解决方案，树立20个平台标杆案例，推动工业互联网平台进一步向农业领域拓展，向农产品的生产、流通、服务领域延伸，打造平台应用的新模式新业态，为推动一二三产业融合发展注入新的活力。二是大力发展数字农业。2013年我部启动了农业物联网区域示范工作，围绕农业特色产业和重点领域，6年多来先后在天津、上海、安徽、吉林、江苏实施农业物联网区域试验工程，并带动各省启动实施了一系列农业物联网项目。2017年起，实施数字农业建设试点项目，聚焦大田种植、园艺作物、畜禽养殖和水产养殖等农业生产领域开展了精准作业、精准控制试点示范。2019年，进一步开展数字农业试点、重要农产品全产业链大数据和数字农业创新中心建设试点，深化了大数据在农业生产、经营、管理和服务等方面的创新应用，为加快推进农业农村现代化建设提供有力支撑。

四、关于加强农村物流配送体系数字化建设

我部会同有关部门不断加强农村地区物流基础设施建设，完善与农村电子商务发展相适应的现代物流体系。2014年商务部、财政部、国务院扶贫办深入开展电子商务进农村综合示范，重点支持农村双向物流配送体系建设，推动整合农村物流服务网络和设施，建设完善县乡村三级物流节点和公共仓储配送体系，示范地区建成县级电商公共服务中心和物流配送中心1000多个，乡村电商服务站点8万多个，快递乡镇覆盖率超过90%.2019年，发展改革委、工业和信息化部、财政部、农业农村部等24个部门和单位印发《关于推动物流高质量发展促进形成强大国内市场的意见》，提出要发挥物流对农业的支撑带动作用，加强邮政、快递物流与特色农产品产地合作，畅通农产品上行通道，同时发展物流新服务模式，鼓励和支持云仓等共享物流模式、共同配送等现金物流组织方式。发展改革委通过组织开展京津冀农产品流通体系创新行动，加快研究京津冀农产品物流体系建设，为农产品电子商务的发展提供支撑，为其他地区探索可复制推广的经验。

下一步，我部将认真吸收借鉴您的建议，加快发展产业互联网，推动现代信息技术在农业农村的应用，推动农业全产业链改造升级，助力农业农村现代化建设。

感谢您对相关工作的关心和重视，希望继续对我部的工作给予支持。

农业农村部

2019年8月30日
