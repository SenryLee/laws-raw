# 财政部关于提前下达新疆生产建设兵团2020年“三区”科技人才支持计划预算的通知

财教〔2019〕163号

新疆生产建设兵团财政局：

为加快预算执行进度，提高预算编制的完整性，根据《科技部 中共中央组织部 财政部 人力资源社会保障部 国务院扶贫办关于印发〈边远贫困地区、边疆民族地区和革命老区人才支持计划科技人员专项计划实施方案〉的通知》（国科发农〔2014〕105号），经研究，现提前下达“三区”科技人才支持计划预算778万元（项目代码：Z145050030001），用于组织开展科技工作者选派和培养工作。收入列2020年政府收支分类科目1100208“结算补助收入”。

你单位要按照规定予以落实，切实加强经费使用管理，做好此项工作组织实施。

财政部

2019年10月28日
