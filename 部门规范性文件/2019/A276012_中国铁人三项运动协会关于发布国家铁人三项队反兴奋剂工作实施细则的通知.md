# 中国铁人三项运动协会关于发布国家铁人三项队反兴奋剂工作实施细则的通知

## 关于发布国家铁人三项队反兴奋剂工作实施细则的通知

有关单位：

为切实做好国家铁人三项队反兴奋剂工作，根据《反兴奋剂管理办法》、《体育运动中兴奋剂管制通则》等相关文件规定，结合国家铁人三项队实际情况，我协会制定了《国家铁人三项队反兴奋剂工作实施细则》，经征求国家队有关人员的意见，现予以发布实施。

特此通知。

附件：《国家铁人三项队反兴奋剂工作实施细则》

中国铁人三项运动协会

2019年4月8日
