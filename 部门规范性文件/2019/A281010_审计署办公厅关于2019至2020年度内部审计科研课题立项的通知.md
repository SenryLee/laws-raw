# 审计署办公厅关于2019至2020年度内部审计科研课题立项的通知

审办内审发〔2019〕75号

各省、自治区、直辖市和计划单列市、新疆生产建设兵团审计厅（局），署机关各单位、各派出审计局、各特派员办事处，南京审计大学，其他有关高等院校、单位：

受审计署委托，中国内部审计协会与内部审计指导监督司于2019年5月至6月组织实施了2019至2020年度内部审计科研课题公开招标和立项评审工作。经评审委员会研究，并报署领导批准，确定13个课题组为审计署2019至2020年度内部审计科研课题立项课题组（见附件）。

各课题组应尽快制定课题研究方案，组织开题。课题组所在单位应为课题研究提供必要的条件和支持，加强对课题研究过程中的管理。

各课题组应在2020年9月10日前将课题研究报告（一式10份）报中国内部审计协会。课题研究报告要观点明确，论据充分，论证严密、方法得当，引用资料、数据规范，不少于3万字。中国内部审计协会和内部审计指导监督司要认真组织对立项课题的过程管理、中期检查和结项评审工作，以保证课题研究成果的质量和水平。

附件：2019至2020年度内部审计科研课题立项表

审计署办公厅

2019年8月22日
