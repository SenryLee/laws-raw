# 中共教育部党组关于黄泰岩、曹国永同志职务任免的通知

教党任〔2019〕46号

中共北京交通大学委员会：

经与中共北京市委商得一致，2019年2月19日研究决定：

黄泰岩同志任中共北京交通大学委员会委员、常委、书记；免去曹国永同志的中共北京交通大学委员会书记、常委、委员职务。

中共教育部党组

2019年2月28日
