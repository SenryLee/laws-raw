# 国家发展改革委办公厅关于同意延长山西省长治市上党区国有资本投资有限公司等两家公司债券核准文件有效期的函

发改办财金〔2019〕1135号

山西省、黑龙江省发展改革委：

报来《关于转报长治市上党区国有资本投资有限公司申请发行公司债券核准有效期延期的请示》（晋发改财金字〔2019〕320号）、《关于申请延长双鸭山市大地城市建设开发投资有限公司企业债券发行期限的请示》（黑发改财金〔2019〕640号）收悉。经研究，现函复如下。

一、同意将《国家发展改革委关于山西省长治县黎都资产经营有限公司发行公司债券核准的批复》（发改企业债券〔2018〕196号）文件有效期延长12个月至2020年12月21日。

同意将《国家发展改革委关于黑龙江省双鸭山市大地城市建设开发投资有限公司发行公司债券核准的批复》（发改企业债券〔2018〕214号）文件有效期延长12个月至2020年12月29日。

二、请你委督促发行人按照《公司法》《证券法》《企业债券管理条例》和有关规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

三、请你委督促发行人按要求及时做好信息披露及债券资金管理，按照核准的募集资金投向合规使用债券资金，认真落实偿债保障措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅

2019年12月11日
