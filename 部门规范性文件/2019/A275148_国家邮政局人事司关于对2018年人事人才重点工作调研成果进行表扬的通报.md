# 国家邮政局人事司关于对2018年人事人才重点工作调研成果进行表扬的通报

局人函〔2019〕13号

各省、自治区、直辖市邮政管理局：

为贯彻落实习近平总书记关于大兴调查研究之风的重要批示精神和全国邮政管理工作会议部署，深入了解和掌握全系统人事人才工作现状，更好服务邮政业高质量发展和邮政强国建设，2018年，国家邮政局人事司部署安排了人事人才重点工作调研。各单位高度重视、精心组织，第一时间确定调研主题，制定调研实施方案，明确职责分工，细化落实到人。调研过程中，结合工作实际，解放思想、深入基层，采取多种方式开展调查研究，深入查找问题，认真分析原因，实事求是提出工作建议和解决思路，为推动全系统人事人才工作发展提供了有益参考。

本次人事人才重点工作调研，各单位共提交调研报告33篇，涉及人才队伍建设、公务员管理、年轻干部队伍研究、机构能力建设、干部教育培训等多方面内容。经组织评审，山西、内蒙古、上海、江苏、福建、江西、山东、河南、湖北、广东、广西、陕西、甘肃、宁夏等省（区、市）局提交的15篇调研报告获得优秀奖，其余18篇获得鼓励奖，现予以通报表扬（详见附件）。

希望各单位转变作风，再接再厉，坚持以问题为导向，深入群众、深入基层调查研究，多献创新务实之策，促进调研成果转化应用，不断提高调研辅政水平，为全面推进人事人才各项工作实现高质量发展提供支撑保障。

附件：2018年人事人才重点工作调研报告表扬名单

国家邮政局人事司

2019年2月28日
