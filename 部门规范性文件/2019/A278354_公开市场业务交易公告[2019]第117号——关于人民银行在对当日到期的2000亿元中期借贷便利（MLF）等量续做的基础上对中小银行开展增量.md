# 公开市场业务交易公告[2019]第117号——关于人民银行在对当日到期的2000亿元中期借贷便利（MLF）等量续做的基础上对中小银行开展增量操作等的公告

## 公开市场业务交易公告

[2019]第117号

为维护半年末流动性平稳，2019年6月19日，人民银行在对当日到期的2000亿元中期借贷便利（MLF）等量续做的基础上，对中小银行开展增量操作，总操作量2400亿元，同时开展14天期逆回购操作400亿元。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 14天 | 400亿元 | 2.70% |

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 1年 | 2400亿元 | 3.30% |

中国人民银行公开市场业务操作室

二〇一九年六月十九日
