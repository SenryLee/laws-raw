# 国家邮政局办公室关于企业运营智能快件箱经营快递业务许可试点工作的通知

国邮办函〔2019〕206号

各省、自治区、直辖市邮政管理局：

为深化快递领域“放管服”改革，引导快递新业态、新服务、新模式健康发展，国家局决定在前期开展企业开办服务站经营快递业务许可试点工作的基础上，继续优化许可领域管理措施。对同一市（地）范围内以运营智能快件箱的方式经营快递业务的企业（以下简称智能快件箱运营企业），依法保护和规范其经营活动。现选取江苏省、广东省和四川省作为试点，对企业运营智能快件箱经营快递业务实施许可。有关事项通知如下：

一、充分认识做好企业运营智能快件箱经营快递业务许可试点工作的重要意义

各级邮政管理部门要坚决贯彻落实中央经济工作会议精神，着力优化营商环境，深入推进快递领域“放管服”改革，积极促进新动能加快发展壮大。按照包容审慎原则，紧紧守住安全和质量底线，逐步将新业态纳入行业管理服务范畴，推动快递领域进一步优化发展环境、释放市场活力。智能快件箱寄递服务是当前快递末端服务的重要形式，智能快件箱网点是快递末端网点的类型之一，适应了人民群众便捷化、个性化的服务需求。企业运营智能快件箱经营快递业务许可试点工作是顺应行业发展需要，健全完善快递业务经营许可制度的重要举措，对于快递新业态、新服务、新模式纳入监督管理具有重要的示范意义。各地区要高度重视试点工作，把思想统一到认真贯彻落实全国邮政管理工作会议精神上来，按照国家邮政局统一部署，抓好组织实施。

二、工作目标

通过开展试点工作，总结对企业运营智能快件箱经营快递业务实施省内许可的工作经验，细化优化核定规则，畅通快递业务经营许可与快递末端网点备案的工作关联，为全国全面实施奠定基础。

三、基本原则

一要依法依规。试点省局依照《中华人民共和国邮政法》《快递暂行条例》以及《快递业务经营许可管理办法》的有关规定，根据本通知要求，开展许可试点工作。同时，要指导市（地）局依法做好快递末端网点备案工作。在具体落实中，应充分考虑快递服务发展区域实际，因地制宜细化实施方案和实地核查措施，确保工作成效。

二要包容审慎。充分考虑新型服务的发展规律和智能快件箱运营企业的经营特点，实事求是创新制度安排，用好用足政策红利。试点省局要联系智能快件箱运营企业，建立高效工作机制，研究提出本省政企对接方案，明确工作安排和时间进度，扎实推进试点有序进行。

三要守住质量、安全底线。严把准入关口，既鼓励创新服务主体通过新的管理、技术手段提升服务质量和安全保障水平，也审慎评估工作方案，发挥实地核查作用，坚决守住质量和安全底线。对于不符合寄递安全、生产安全或者快递服务质量要求的申请人依法不予核准。

四、工作要求

（一）加强业务指导。国家邮政局市场监管司建立专门工作机制，分阶段召开试点工作推进会议，细化业务指导，加强过程管理，同步优化快递业务经营许可管理信息系统。

（二）确保试点成效。试点省份注重发挥省、市两级联动优势，集中力量开展攻关，注重研究企业发展实际、主动听取企业诉求，加强对申请人的行政指导，统筹事前、事中和事后全过程管理，加强同市场监管司的业务会商和情况反馈。试点工作结束后一月内，试点省局要提交总结评估报告。

（三）鼓励借鉴探索。非试点省份可结合实际情况，参照本通知精神研究提出试点工作方案，依法对企业运营智能快件箱经营快递业务实施许可，工作进展情况及时报国家邮政局市场监管司。
