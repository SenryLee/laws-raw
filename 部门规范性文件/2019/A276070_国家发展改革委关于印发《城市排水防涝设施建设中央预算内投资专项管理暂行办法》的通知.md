# 国家发展改革委关于印发《城市排水防涝设施建设中央预算内投资专项管理暂行办法》的通知

发改投资规〔2019〕179号

各有关省、自治区、新疆生产建设兵团发展改革委：

为进一步加强和规范城市排水防涝设施建设中央预算内投资专项项目管理，提高资金使用效益，推进中央预算内投资管理制度化、规范化、科学化，我们研究制定了《城市排水防涝设施建设中央预算内投资专项管理暂行办法》，现印发你们，请按照执行。

国家发展改革委

2019年1月25日
