# 国家文物局办公室关于扬州城遗址保护范围和建设控制地带内玉带河桥梁建设项目的意见

办保函〔2019〕32号

江苏省文物局：

你局《关于审批扬州城遗址保护范围和建设控制地带内玉带河桥梁建设项目修改方案的请示》（苏文物保〔2018〕314号）收悉。经研究，我局暂不同意在扬州城遗址保护范围和建设控制地带内实施玉带河桥梁建设项目。

一、玉带河是扬州城遗址的重要组成部分，拟建项目将对河道及两侧古代护坡、驳岸等重要遗存造成严重影响，应按照《扬州城遗址保护规划》《大运河（扬州段）遗址保护规划》要求，进一步论证桥梁建设的必要性。

二、请你局按照我局《关于在扬州城遗址保护范围和建设控制地带内进行玉带河桥梁建设项目的意见》（办保函〔2018〕665号）要求，指导有关单位综合研究该区域道路系统调整、安消防设施建设和游客疏散问题，研提多种选址和设计比选方案，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月16日
