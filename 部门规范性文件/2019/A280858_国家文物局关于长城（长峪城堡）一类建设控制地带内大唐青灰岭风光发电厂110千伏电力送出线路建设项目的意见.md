# 国家文物局关于长城（长峪城堡）一类建设控制地带内大唐青灰岭风光发电厂110千伏电力送出线路建设项目的意见

文物保函〔2019〕794号

北京市文物局：

你局《关于大唐青灰岭风光发电厂110千伏电力送出线路工程设计方案的请示》（京文物〔2019〕1046号）收悉。经研究，我局原则同意在长城（长峪城堡）一类建设控制地带内实施大唐青灰岭风光发电厂110千伏电力送出线路工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建线塔选址区域做进一步的考古调查、勘探和必要的考古发掘。如有长城墙体及附属设施遗存等重要发现，应调整设计方案，充分避让。

（二）应深化拟建项目文物影响评估，完善景观视线分析，补充地形分析图纸，明确拟建设施对长城（长峪城堡）整体环境的影响。

（三）应细化拟建项目设计方案，进一步明确并尽可能压缩项目位于长城（长峪城堡）一类建设控制地带内的工程内容和占地面积，同时深化方案设计图，完善各类标注。

（四）应补充拟建项目施工期间长城本体临时性防护措施、应急预案及竣工后的环境修复措施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年8月7日
