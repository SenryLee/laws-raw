# 国家体育总局竞体司关于调整第十四届全国冬季运动会冰球和冰壶项目设置的通知

## 体育总局竞体司关于调整第十四届全国冬季运动会冰球和冰壶项目设置的通知

体竞字〔2019〕146号

各省、自治区、直辖市、新疆生产建设兵团体育局，中央军委训练管理部军事体育训练中心，冬运中心，中国冰球协会，有关单位，社会各界：

为确保第十四届全国冬季运动会服务于北京冬奥会备战工作，经研究，现对第十四届全国冬季运动会冰球和冰壶项目设置进行调整，有关事宜通知如下：

一、取消冰球成年组2个小项，设置男子、女子冰球青年组2个小项，参赛运动员年龄为2002年1月1日至2005年12月31日出生。

二、取消冰壶成年组3个小项，已设置的青年组调整为青年甲组和青年乙组，小项设置分别为男子冰壶、女子冰壶、混合双人冰壶。青年甲组参赛运动员年龄为1999年1月1日至2001年12月31日出生，青年乙组参赛运动员年龄为2002年1月1日至2005年12月31日出生。

三、相关单位可对已申报的冰球和冰壶项目联合培养协议进行调整，并于2019年9月30日前将调整后的联合培养运动员协议书报送体育总局竞技体育司审核。
