# 农业农村部对十三届全国人大二次会议第3547号建议的答复

## 对十三届全国人大二次会议第3547号建议的答复

农办议〔2019〕127号

赵剡水代表：

您提出的关于农机化信息统一管理的建议收悉，现答复如下。

加快推进农业机械化全程全面高质高效发展，必须强化信息化、智能化技术的支撑。近年来，围绕推进机械化信息化融合发展，我部会同有关部门开展了一系列创新性工作。一是强化顶层设计。2018年12月，国务院印发《关于加快推进农业机械化和农机装备产业转型升级的指导意见》（国发〔2018〕42号）（以下简称《意见》），将机械化信息化融合作为推动农业机械化向全程全面高质高效转型升级的主要路径之一，要求推动智慧农业示范应用，推进“互联网+农机作业”，加快推广应用农机作业监测、维修诊断、远程调度等信息化服务平台，实现数据信息互联共享，提高农机作业质量和效益。2019年4月，我部按照《意见》精神和要求，印发《关于加快推进农业机械化转型升级的通知》（农机发〔2019〕4号），要求各省在农业农村信息化的有关规划、项目中，把发展智能农业装备、推进农机作业服务和管理信息化作为重要内容；加快推进农机鉴定、农机监理、农机购置补贴、农机作业补助核定等管理服务工作信息化步伐，推进信息系统互联互通；全面运用农机购置补贴机具信息网络投送平台、推广使用农机购置补贴手机APP、农机深松整地作业补助物联网监测等应用软件，提升政策实施管理的精准性、便利性。二是加大政策投入支持。“十三五”以来，我部进一步加强信息化技术在农机化领域的应用示范。2017年以来，中央财政累计投入超过1亿元，重点实施了大田种植数字农业建设项目，旨在针对不同区域、不同作物探索构建农机精准作业系统、“天空地”一体化大田农情监测系统、农业生产精准管理决策系统和农业高效生产公共服务系统，促进农机大数据、智慧农机融合应用，形成可复制推广的大田种植数字农业生产模式。在现代农业装备学科群增补了22个重点实验室，加强了农作物系统分析与决策、农业物联网装备等方向的研究力量。开展全程机械化科研基地能力条件建设，累计投入中央财政资金近2亿元，有效提升了农机科研基础设施条件和协同创新能力。通过各类示范项目，试验推广了拖拉机自动驾驶、收割机精准测亩测产、机插秧自动驾驶、无人机精量施药、深松作业质量远程监控等智慧农机装备和技术。三是开展试点探索。2018年，我部结合新一轮农机购置补贴政策启动实施后出现的新需求、新动向，在总结有关省份利用信息化技术监测补贴资金流向工作经验基础上，提出了探索开展农机购置补贴机具加施物品识别唯一二维码及加装运行轨迹监测设施，并与机具补贴远程申请手机APP等联通运用试点（即“三合一”试点）工作思路方案。2019年，农业农村部、财政部联合印发《关于做好2019年农业生产发展等项目实施工作的通知》（农计财发〔2019〕6号），明确要推进补贴资金使用与管理方式创新，本着稳慎推进、试点先行原则，在北京、上海、江西等省（市）开展农机购置综合补贴试点，支出方向包括机具的购置补贴、贷款贴息、融资租赁承租补助等；在四川开展农机化发展综合奖补试点，支出方向包括机具的购置补贴、作业补贴、贷款贴息、融资租赁承租补助等，并支持上述4个试点省份以“三合一”信息化技术为支撑，探索更加安全、高效、便民的补贴机具核验与补贴资金申领模式。

下一步，我部将会同有关部门按照《意见》精神和要求，扎实做好农机化管理服务信息系统建设及运行管理工作。一是广聚信息化技术创新资源。针对信息化建设专业性强的特点，充分发挥高校、科研单位和科技创新企业的优势，合力促进全国性的农机化大数据平台建设，努力构建左右相连、上下贯通的农机化管理服务“一张网”。二是积极引导相关行业协会与企业等参与建设。广开言路，重点围绕“三合一”试点工作，充分征求相关行业协会和农机企业、信息技术专业机构、新型农业经营主体的意见，共同推进农机化管理服务信息化平台建设。三是注重数据采集使用安全规范。在推进农机化管理服务信息系统建设进程中，同步加强数据安全管理工作。指导北京等4省（市）稳慎开展农机购置补贴资金使用管理创新试点，及时组织评估“三合一”工作推进情况，深入研究技术规范标准、系统互联互通、数据安全管理等问题的解决方案，逐步完善后再行推广。

感谢您长期以来对农业机械化工作的关心，希望今后继续对我部工作给予支持。
