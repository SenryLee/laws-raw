# 教育部关于同意设置广西职业师范学院的函

教发函〔2019〕52号

广西壮族自治区人民政府：

《广西壮族自治区人民政府关于请求批准广西经济管理干部学院改制更名为广西职业师范学院的函》（桂政电〔2019〕11号）收悉。

根据《中华人民共和国高等教育法》《普通高等学校设置暂行条例》《普通本科学校设置暂行规定》有关规定以及第七届全国高等学校设置评议委员会评议结果，经教育部党组会议研究决定，同意在广西经济管理干部学院基础上设置广西职业师范学院，学校标识码为4145014684。现将有关事项函告如下：

一、广西职业师范学院系本科层次的普通高等学校，由你区领导和管理。

二、学校要切实加强党的建设，全面贯彻党的教育方针，坚持社会主义办学方向，落实立德树人根本任务，培养德智体美劳全面发展的社会主义建设者和接班人。

三、学校要坚持培养职业教育师资的办学定位，为职业教育发展提供有力的人才支撑。

四、学校全日制在校生发展规模为8000人。

五、学校本科专业设置按国家有关规定办理，首批设置财务会计教育、市场营销教育、旅游管理与服务教育、应用电子技术教育、信息管理与信息系统、物联网工程等6个本科专业。

六、我部将适时对学校办学定位、办学条件、办学行为和人才培养质量等情况进行检查。

望你区加强对学校的指导和支持，加大资金投入力度，引导学校科学定位、内涵发展，加强教师队伍建设，促进师范教育和职业教育的有机融合，不断深化产教融合、校企合作，强化实验实训条件建设，提高教学科研水平，培养区域经济社会发展所需要的高素质应用型、技术技能型人才和职业教育师资，更好地为地方经济社会发展服务。

教育部
