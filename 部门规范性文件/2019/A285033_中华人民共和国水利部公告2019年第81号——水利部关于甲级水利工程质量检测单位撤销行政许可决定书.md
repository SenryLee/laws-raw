# 中华人民共和国水利部公告2019年第81号——水利部关于甲级水利工程质量检测单位撤销行政许可决定书

## 中华人民共和国水利部公告

2019年第81号

## 水利部关于甲级水利工程质量检测单位撤销行政许可决定书

武汉楚衡建设工程检测有限公司：

本机关于2019年8月6日准予你单位提出的甲级水利工程质量检测单位资质混凝土工程类和量测类申请。现经调查核实：

2019年5月16日，湖北省市场监管局责令你单位“停业整顿”直至最终于2019年8月26日作出“撤销武汉楚衡建设工程检测有限公司检验检测机构资质认定证书（证书编号：18170108328）。自撤销之日起，三年内不得再次申请资质认定”的处理决定。2019年5月28日，你单位隐瞒接受有关行政机关查处的事实向本机关提交申请材料，并取得甲级水利工程质量检测单位资质。

根据《中华人民共和国行政许可法》第六十九条第一款和第二款、水利部《水利工程质量检测管理规定》第二十六条，本机关决定撤销原行政许可（证书编号：水质检资字第20090044号），三年内不得再次申请。

如对本决定不服，可自收到本决定之日起六十日内，依法向水利部申请行政复议，或者在六个月内向北京市第一中级人民法院提起行政诉讼。
