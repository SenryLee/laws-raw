# 国家文物局办公室关于延恩寺塔保护范围和建设控制地带内平凉供销德苑项目的意见

办保函〔2019〕225号

甘肃省文物局：

你局《关于平凉供销德苑住宅小区建设项目涉及延恩寺塔保护区划设计方案的请示》（甘文局发〔2019〕25号）收悉。经研究，我局暂不同意延恩寺塔保护范围和建设控制地带内平凉供销德苑项目。

一、对所报方案提出以下修改完善意见：

（一）建设项目应移至延恩寺塔保护范围外，并适当减少新建建筑体量，降低建筑高度。

（二）建议沿双拥路一侧增加绿化遮挡，减小建设项目对延恩寺塔的影响。

（三）制定必要的文物保护措施和应急预案，减小施工震动对延恩寺塔的影响。

（四）文物影响评估报告应准确、客观评估拟建项目对文物本体安全和景观的影响，补充说明拟建项目周边区域的建筑高度、体量等现状，测算数据应采用砖石古塔的相关指标。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

三、请你局按照我局《关于延恩寺塔保护规划编制立项的批复》（文物保函〔2015〕1367号）的相关要求，督促地方政府抓紧编制延恩寺塔保护规划，统筹考虑文物保护、环境整治、展示利用等工作，科学引导、依法合规开展周边开发建设活动。

专此函复。

国家文物局办公室

2019年3月28日
