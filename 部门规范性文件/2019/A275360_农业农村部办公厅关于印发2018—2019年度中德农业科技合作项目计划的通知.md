# 农业农村部办公厅关于印发2018—2019年度中德农业科技合作项目计划的通知

农办科〔2019〕11号

各有关单位：

根据中德农业科技工作组第24次会议磋商结果，2018—2019年度共安排中德农业科技合作项目21项（见附件），现将项目实施计划下达你单位，并就有关事项通知如下。

一、请项目承担单位尽快与德方合作单位和专家取得联系，按照“互惠互利、合作共赢”的原则，通过双方人员交流互访，开展学术研讨和合作研究等多种方式，切实开展合作，确保项目按计划执行。

二、根据此前中德农业科技工作组协商，专家国际旅费和食宿交通费均由派出国承担。

三、请各项目单位于2020年3月31日前向我部科技教育司报送项目总结，主要内容包括合作研究进展、合作成效以及人员互访情况等。
