# 中华人民共和国住房和城乡建设部公告2019年第141号——住房和城乡建设部关于2019年第九批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第141号

## 住房和城乡建设部关于2019年第九批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，安丰杰等32名申请注册土木工程师（岩土）初始注册人员、韦振飞等32名申请一级注册结构工程师初始注册人员、赵丙礼等41名申请注册公用设备工程师初始注册人员、李爱云等20名申请注册电气工程师初始注册人员、黄一烽等14名申请注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予安丰杰等32名注册土木工程师（岩土）初始注册人员名单

2.准予韦振飞等32名一级注册结构工程师初始注册人员名单

3.准予赵丙礼等41名注册公用设备工程师初始注册人员名单

4.准予李爱云等20名注册电气工程师初始注册人员名单

5.准予黄一烽等14名注册化工工程师初始注册人员名单

住房和城乡建设部

2019年6月3日
