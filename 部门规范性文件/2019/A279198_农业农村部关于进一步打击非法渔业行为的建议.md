# 农业农村部关于进一步打击非法渔业行为的建议

## 关于进一步打击非法渔业行为的建议

农办议〔2019〕24号

一、关于完善立法，健全制度，加大处罚力度

我部正在组织修订《渔业法》，修订草案已将打击非法渔业行为纳入法律调整范畴。

二、关于加强港口管理

目前，我部已会同有关部门积极加入并推动落实《港口国措施协定》。2018年，我部联合外交部、公安部、交通运输部、海关总署和国家市场监督管理总局等多个部门，将我国加入的7个区域渔业组织公布的247艘IUU（非法、不报告、无管制）渔船名单通报国内各口岸，将其列入布控范围，防止进入我国港口，并拒绝此类渔船在我国港口加油、补给、维修和上坞等，拒绝其所载渔获物在我国港口卸货、转运、包装、加工等。同时，我部还将上述渔船名单通报地方渔港监督管理部门，防止这些渔船进入我国渔港。

三、关于建立海上联合打击IUU专业队伍

武警部队将在相关涉外合作框架下，加强与相关国家在打击北太平洋非法渔业行为上的执法交流合作，继续组织北太平洋公海渔业执法巡航，加大对我国远洋渔船监管力度，严厉打击各种非法渔业行为。

2019年07月10日
