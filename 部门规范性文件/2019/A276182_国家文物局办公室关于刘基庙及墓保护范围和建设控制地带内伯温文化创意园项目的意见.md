# 国家文物局办公室关于刘基庙及墓保护范围和建设控制地带内伯温文化创意园项目的意见

办保函〔2019〕232号

浙江省文物局：

你局《关于要求在全国重点文物保护单位刘基庙保护范围和建设控制地带内实施伯温文化创意园建设项目的请示》（浙文物发〔2018〕260号）收悉。经研究，我局暂不同意刘基庙及墓保护范围和建设控制地带内伯温文化创意园项目。

一、对所报方案提出以下修改完善意见：

（一）1、2、3号建筑属于不可移动文物点，其保护修缮应按程序另行报批；进一步明确叁号苑建筑的保护级别，其修缮整饬应最大限度地保护历史信息。

（二）拆除保护范围内3号建筑西侧“加建建筑”，恢复刘基庙前历史格局。

（三）缩小壹号苑和伯温家宴馆等建筑体量，建设控制地带内新建建筑高度、层数、形制须符合保护规划相关要求。

（四）拟建项目开挖水面较多，必要性不足，应减少景观水体面积。

（五）补充施工期间文物本体的防护措施，明确管理要求和注意事项，控制粉尘及施工垃圾等对文物本体及环境的污染。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年4月1日
