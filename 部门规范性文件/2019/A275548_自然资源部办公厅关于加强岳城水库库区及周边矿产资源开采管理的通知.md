# 自然资源部办公厅关于加强岳城水库库区及周边矿产资源开采管理的通知

自然资办函〔2019〕395号

河北、河南省自然资源厅：

近日，部接到《水利部办公厅关于商请进一步加强岳城水库库区及周边采煤许可工作的函》（办运管函〔2019〕135号，附件1）。来函反映安阳市主焦煤业有限责任公司主焦煤矿采矿权（证号：C1000002011041120111552）矿区中2.91平方公里位于岳城水库限采区内，要求“有关单位加强对主焦煤矿的开采管理，在海委审查同意前暂不在限采区内开采煤矿”，同时要求“严禁在禁采区内进行矿产资源开采活动；在限采区内新批采矿许可证前，要开展对水库安全影响的论证工作，并经海委审查同意，切实保障水库运行安全和下游人民群众生命财产安全”。

请你厅在矿产资源勘查开采管理工作中严格落实上述禁采限采要求，配合水利等相关部门，切实保障水库安全。请你厅核查禁采区、限采区范围（附件2）内的矿业权设置情况，并对照水利部门相关要求做好矿产资源开采管理工作。

有关情况请及时报部。

自然资源部办公厅

2019年3月13日
