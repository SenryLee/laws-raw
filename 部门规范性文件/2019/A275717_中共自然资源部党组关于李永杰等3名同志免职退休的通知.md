# 中共自然资源部党组关于李永杰等3名同志免职退休的通知

自然资党任〔2019〕48号

各省、自治区、直辖市及计划单列市自然资源主管部门，新疆生产建设兵团自然资源主管部门，中央军委后勤保障部军事设施建设局，国家林业和草原局，中国地质调查局及部其他直属单位，各派出机构，部机关各司局：

部党组2019年2月19日研究决定：

免去李永杰总规划师职务，退休；

免去张陟国际合作司（海洋权益司）巡视员职务，退休；

免去魏国旗海洋战略规划与经济司副巡视员职务，退休。

中共自然资源部党组

2019年3月6日
