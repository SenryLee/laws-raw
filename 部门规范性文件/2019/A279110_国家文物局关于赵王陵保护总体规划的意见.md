# 国家文物局关于赵王陵保护总体规划的意见

文物保函〔2019〕541号

河北省文物局：

你局《关于呈报〈赵王陵文物保护总体规划〉的请示》（冀文物字〔2019〕46号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）加强考古资料梳理和历史文献研究，明确赵王陵对于研究古代陵寝制度、丧葬文化和赵国历史的重要意义，分析各单体墓葬形制和价值特点，厘清赵王陵选址及自然环境要素、山水格局等，在此基础上深化价值评估。

（二）完善保护区划和管理规定，建设控制地带西边界应结合紫山、洺河等自然景观保护需求适当外扩；一号陵和四号陵之间区域应结合空间及视廊分析调整为一类建设控制地带。细化保护区划范围内村庄建设界线、发展目标、管控措施等，规范管控标准表述；补充保护范围内现状建构筑物改造要求和控制性指标；进一步明确现状工业区调控措施和搬迁计划。

（三）完善专项规划，细化遗址保护措施和环境整治措施，严格控制施工范围和工程量，增强可操作性；调整管理规划内容，明确跨行政区域管理体制机制，研提具有可操作性的规划建议。

（四）调整展示思路，论证建设考古遗址公园的必要性和可行性，现阶段应以现状保护为主，重点做好已开放陵园区域的展示提升工作。不同意管理服务区设计内容，大规模核减服务区面积和建设规模，并进一步明确重要展示服务设施、基础设施、保护设施的选址、建筑规模、功能等内容。应结合实际情况测算游客量，明确展示开放区域游客量限定标准。

（五）进一步规范图文表达，补充土地利用现状图、地籍图、村庄调控图。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将赵王陵保护总体规划报请河北省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、请你局督促地方人民政府抓紧制定规划范围内居民调控专项规划，妥善处理村庄发展、人口控制和文物保护之间的关系。规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好赵王陵各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年6月11日
