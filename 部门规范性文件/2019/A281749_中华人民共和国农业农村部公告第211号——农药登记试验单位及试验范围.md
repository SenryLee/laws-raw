# 中华人民共和国农业农村部公告第211号——农药登记试验单位及试验范围

## 中华人民共和国农业农村部公告

第211号

根据《农药管理条例》《农药登记管理办法》《农药登记试验管理办法》等有关规定，经资料审查、现场检查和综合评审，批准安徽省化工产品质量监督检验站等7家单位为农药登记试验单位，有效期五年。

特此公告。

附件：农药登记试验单位及试验范围

农业农村部

2019年9月2日
