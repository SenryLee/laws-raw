# 国家文物局办公室关于苏州园林发展股份有限公司文物保护工程施工一级资质证书内容变更的函

办保函〔2019〕686号

江苏省文物局：

你局《关于苏州园林发展股份有限公司文物保护工程施工一级资质法人变更的请示》（苏文物保〔2019〕170号）收悉。

经研究，我局同意苏州园林发展股份有限公司文物保护工程施工一级资质证书中的法定代表人由“嵇存海”变更为“周益”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年8月5日
