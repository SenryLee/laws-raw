# 国家知识产权局对十三届全国人大二次会议第6951号建议答复的函

国知发法函字〔2019〕104号

耿福能代表：

您提出的《关于加大力度保护品牌驰名商标的建议》收悉，结合国家市场监督管理总局意见，现答复如下：

您结合具体案例，提出的关于完善立法、加强执法、全面普法的建议，具有较强的针对性和参考价值，我局对此深表赞同。近年来，我局开展大量工作，以进一步解决驰名商标保护中存在的问题。

一、关于商标立法

为有效规制恶意申请和囤积注册行为，加强对商标专用权的保护，营造良好的营商环境， 2019年4月23日，全国人大常委会审议通过《中华人民共和国商标法修正案（草案）》，围绕规制恶意申请、囤积注册等行为和加大对侵犯商标专用权行为惩罚力度两方面对商标法进行了个别条款的修改。修改条款将自2019年11月1日起施行，具体内容包括：一是增加规制恶意注册的内容。增强商标使用义务，增加“不以使用为目的的恶意商标注册申请，应当予以驳回”的规定，首先在审查阶段予以适用，实现打击恶意注册的关口前移，并将其作为提出异议和请求宣告无效的事由，直接适用于异议程序和无效宣告程序中；增加商标代理机构的义务，规定商标代理机构知道或者应当知道委托人存在恶意注册行为的不得接受委托，一经发现，依法追究责任；增加对申请人、商标代理机构恶意申请商标注册、恶意诉讼行为的处罚措施。二是加大对侵犯商标专用权行为惩罚力度。将恶意侵犯商标专用权的侵权赔偿数额计算倍数由一倍以上三倍以下提高到一倍以上五倍以下，并将法定赔偿数额上限从三百万元提高到五百万元，以给予权利人更加充分的补偿；对假冒注册商标的商品以及主要用于制造假冒注册商标的商品材料、工具加大处置力度。

此外，本次商标法修改为正在制定完善的《关于规范商标申请注册行为的若干规定》这一部门规章提供了上位法依据。该规章将对法律修改内容进行操作层面的细化，现已完成公开征求意见，将根据意见反馈进行完善，使商标法的修改内容切实落到实处。我局将通过对商标法实施情况进行评估、对社会关注重点问题开展专题论证等方式，广泛听取意见建议，继续推进商标法新一轮全面修改的准备工作，更好地服务我国经济社会发展。

二、关于商标执法

我国采取行政执法和司法保护两条途径并行运作的知识产权保护模式，这种模式有利于发挥行政与司法两种力量的优势，实现对知识产权的有效保护，符合我国现阶段国情。加强知识产权行政执法，运用行政手段查处商标侵权行为，不仅能够保护权利人利益，而且有利于维护社会公共利益。相比于知识产权司法保护，行政执法具有效率高、成本低、主动性强的特点，能够比较快捷地查处侵权违法行为，及时保护消费者和权利人的合法权益。

2018年机构改革以来，国家市场监督管理总局按照中央关于行政执法体制改革的精神，大力推动市场监管综合执法，切实履行知识产权执法职能，严厉打击知识产权违法行为。一是组织开展重点整治。制定印发《假冒伪劣重点领域治理工作方案（2019—2021）》，针对农村市场、电商平台等重点领域提出治理措施，严厉打击侵权假冒、虚假宣传、虚假促销、刷单炒信等违法行为。二是构建执法协作机制。会同公安部、农业农村部、海关总署、版权局、知识产权局等5部门印发《加强网购和进出口领域知识产权执法实施办法》，就依法加强执法监管、拓宽线索来源渠道、强化执法协调联动、大力推进行刑衔接、建立工作保障制度、完善社会共治机制等提出要求，着力提升知识产权执法水平。三是加强执法组织指导。组织开展驰名商标保护行动，指导地方集中查处侵犯“华为”“帅康”“鄂尔多斯”商标权等案件。2018年，全国市场监管部门共查处商标违法案件31194件，案值54573万元，罚没金额51421万元。上述相关案件行政处罚决定书全部在国家企业信用公示系统上对社会公示，充分发挥信用监管约束作用，推动实现商标侵权违法行为人“一处违法，处处受限”。

下一步，国家市场监督管理总局将深入开展知识产权执法“铁拳”行动，以互联网领域、农村市场、外商投资领域为重点，加大执法办案力度，抓好重点市场、重点领域的案件督办，完善联合惩戒机制，加强执法协作联动，加强执法队伍建设，严厉查处商标侵权违法行为。

三、关于全面普法

为加强商标法律制度和商标权保护成效宣传工作，2019年4月25日，我局向社会公众发布2018年度商标领域典型案例。这些典型案例体现了我局通过提前审查、并案集中审查、从严适用法律、公开评审裁定等有效措施，严厉打击“傍名牌”“搭便车”等商标攀附行为，严厉打击不以使用为目的的大量申请商标牟利行为，严厉打击滥用商标权利、恶意维权等商标投机行为，进一步彰显在规范商标注册秩序、净化竞争环境方面的力度和决心。

2019年5月28日，我局还向社会公众发布2018年度商标行政保护十大典型案例，例涉及我国对中外商标权利人合法权益的平等保护、商标行政保护全链条打击、商标行政司法高效顺畅衔接，从多方位展示了我国在加大商标专用权保护力度、严厉打击商标侵权违法行为，营造良好营商环境方面取得的显著成效。

我们非常重视您提出的相关建议，其中关于优化商标申请注册、使用和保护制度，坚决遏制恶意申请行为、大幅提高惩戒幅度等内容已在本次商标法特别修改中有所体现。其他关于强化驰名商标制度等问题的立法建议，我们将在商标法新一轮全面修改准备工作予以研究考虑；关于加强执法队伍建设、提高执法水平和全面普法等建议，我们将在今后工作中继续加强和完善，不断加大商标保护力度，营造良好的创新环境和营商环境。

衷心感谢您对知识产权工作的关心和帮助，希望持续关注知识产权事业发展，提出更多的宝贵意见和建议。

国家知识产权局

2019年7月3日
