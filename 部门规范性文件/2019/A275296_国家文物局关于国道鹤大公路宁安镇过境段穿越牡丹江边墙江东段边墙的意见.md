# 国家文物局关于国道鹤大公路宁安镇过境段穿越牡丹江边墙江东段边墙的意见

文物保函〔2019〕257号

黑龙江省文物管理局：

你局《关于国道鹤大公路宁安镇过境段穿行全国重点文物保护单位牡丹江边墙江东段边墙的请示》（黑文管字〔2018〕41号）收悉。经研究，我局原则同意在牡丹江边墙江东段保护范围和建设控制地带内进行国道鹤大公路穿越建设项目。

一、所报方案需作以下必要的修改和完善：

（一）建议道路选线向东侧或西侧进行适当调整，避让边墙遗址转角部位。

（二）选择低扰动施工方式，完善桥梁和跨越段边墙遗址区域的排水处理措施，避免在边墙及其周围形成雨水淤积。

（三）细化施工和运营期间对文物本体振动、变形的监测方案，明确监测周期和预警阈值。

（四）完善施工和运营期间边墙本体保护的应急预案。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月12日
