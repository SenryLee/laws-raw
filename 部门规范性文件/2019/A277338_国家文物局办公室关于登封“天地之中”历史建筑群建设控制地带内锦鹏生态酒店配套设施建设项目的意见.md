# 国家文物局办公室关于登封“天地之中”历史建筑群建设控制地带内锦鹏生态酒店配套设施建设项目的意见

办保函〔2019〕342号

河南省文物局：

你局《关于报批登封“天地之中”历史建筑群缓冲区内锦鹏生态酒店配套设施建设工程规划设计方案的请示》（豫文物〔2019〕57号）收悉。经研究，我局暂不同意在登封“天地之中”历史建筑群缓冲区内实施锦鹏生态酒店配套设施建设项目。

一、对所报方案提出以下修改完善意见

（一）对照世界文化遗产登封“天地之中”历史建筑群保护管理规划关于第三、四类缓冲区“禁止开展大体量的集中性建设项目”和“平屋顶建筑檐口高度不得超过4米，坡屋顶建筑屋脊高度不得超过6米”等管理规定，修改项目设计方案，大幅削减项目规模，降低建筑高度，避免对遗产环境景观造成破坏。

（二）针对修改后的项目设计方案重新编制遗产影响评估报告，客观分析拟建项目对世界文化遗产登封“天地之中”历史建筑群环境风貌及突出普遍价值的影响，并细化相应的减缓措施。补充拟建建筑与中岳庙之间的视线分析图。

（三）进一步规范和完善方案文本和图纸，如纠正各类表述错误，以及在总平面图中明确标注拟建建筑与中岳庙之间位置关系等。

二、请你局指导有关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2019年5月5日
