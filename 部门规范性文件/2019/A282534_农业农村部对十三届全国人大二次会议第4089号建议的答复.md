# 农业农村部对十三届全国人大二次会议第4089号建议的答复

## 对十三届全国人大二次会议第4089号建议的答复

刘志仁代表：

您提出的关于支持建设湘赣边区乡村振兴示范区的建议收悉。湘赣边区是革命老区，为我国革命事业作出了重大贡献，支持湘赣边区乡村振兴，对我们做好工作很有启发借鉴作用。经商发展改革委、财政部和湖南、江西省人民政府，现答复如下。

一、关于将郴州宜章县纳入示范创建范围

2018年9月，党中央、国务院印发的《乡村振兴战略规划(2018-2022年)》(以下简称《规划》），明确提出，要科学把握我国乡村区域差异，尊重并发挥基层首创精神，发掘和总结典型经验，推动不同地区、不同发展阶段的乡村有序实现农业农村现代化。按照党中央、国务院决策部署，湖南、江西两省正在推进湘赣边区乡村振兴示范区建设。目前，两省已签订协同推进湘赣边区乡村振兴合作框架协议，正在组织编制《湘赣边区域合作示范区发展规划》，已明确将宜章县纳入示范区，并在政策、资金、项目等方面给予倾斜和支持。

下一步，我部将会同相关部门，积极推动湘赣两省落实合作协议的事项内容，加快《湘赣边区域合作示范区发展规划》编制，加大包括宜章县在内的革命老区乡村振兴工作支持，通过示范引领、典型引路，积极探索乡村振兴地方实践，引领带动同类地区乡村振兴整体推动。

二、关于将湘赣边区乡村振兴示范区建设纳入国家层面给予支持

党中央、国务院一直高度重视湘赣边区发展，不断加大投入力度，持续提升湘赣边区基础设施和公共服务水平，取得了积极成效。一是强化顶层设计。印发《赣闽粤原中央苏区振兴发展规划》，提出要研究设立湘赣经贸合作试验区，全面加强扶贫开发合作共建，推进实施罗霄山片区区域发展与扶贫攻坚规划。在国务院批复的《长江中游城市群发展规划》中，提出依托湖南长沙、株洲、湘潭和江西新余、宜春、萍乡等地，共建湘赣开放合作试验区，加强产业分工协作，打造湘赣边界红色旅游带和跨省产业合作示范区。二是加大转移支付力度。2008年，中央财政设立重点生态功能区转移支付，通过提高重点生态功能区所在地政府基本公共服务保障能力，支持地方开展生态文明建设。湘赣边区已纳入重点生态功能区，2019年，中央财政下达湘赣两省重点生态功能区转移支付74.9亿元，支持包括湘赣边区在内的生态环境保护治理，湘赣边区生态环境持续改善。三是持续提升公共服务水平。2018年，中央财政相关教育转移支付80％以上用于湘赣两省在内的中西部地区，并向革命老区等贫困地区倾斜，支持和引导包括湘赣边区在内的西部地区，着力改善贫困地区薄弱学校基本办学条件，提高经费保障水平，建立健全学生资助体系，保障家庭经济困难学生顺利完成学业等。通过实施全民健康保障工程建设，累计安排中央预算内投资12.06亿元支持湘赣边区40余个医院卫生项目建设，将基本公共卫生服务人均财政补助标准由2018年的55元提高到2019年的69元。安排湘赣两省基本公共卫生服务补助资金535亿元，用于免费向当地城乡居民提供健康教育、重点人群健康管理、医养结合、卫生应急、孕前检查等基本公共卫生服务。四是大力发展红色旅游。积极推进包括湘赣边区在内的革命文物和遗存丰富地区大力发展红色旅游，2019年安排中央预算内投资1.85亿元，支持湘赣地区文化和旅游领域基础设施建设，为湘赣边区红色旅游发展创造了良好基础条件。

此外，在湘赣边区农业农村发展方面，我们会同有关部门持续加大力度，全力推进区域乡村振兴。2018年中央财政安排农业生产发展资金108.19亿元，支持各地一二三产业融合和优势特色主导产业发展。其中，安排湘赣两省资金8.3亿元，鼓励发挥资源禀赋特点，发展比较优势突出的特色产业。目前，湖南、江西两省已着手研究支持湘赣边区乡村振兴示范区建设的一揽子计划，正在征求有关方面的意见。下一步，我部将会同有关部门，结合相关规划方案编制实施、项目推进情况以及地方实际等，加强对湘赣边区乡村振兴示范区的指导，协助解决推进工作中的困难和问题。

三、关于建立部省联席会议制度

遵照党中央、国务院决策部署，为做好《规划》实施工作，加强部门沟通协商和联合协作，增强相关政策衔接和工作协调，发展改革委、农业农村部牵头会同有关部门建立了《规划》实施协调推进机制，主要负责协调、指导、督促落实《规划》各项目标任务和政策措施，研究协调重大问题，总结推广典型经验，研究提出考核监督建议。同时，湖南、江西两省已建立由两省省长、副省长任总召集人和副召集人，两省发展改革委、省农业农村厅、省交通运输厅、省水利厅、省文化和旅游厅等单位和相关地市政府为成员的推进湘赣边区域合作示范区建设联席制度，成立了乡村振兴、红色文化、生态文明、基础设施四个专项工作组，共同研究推进专项合作工作，积极推动湘赣边区各项工作。

下一步，我们将充分发挥《规划》实施协调机制作用，及时了解和掌握包括湘赣边区在内的各地乡村振兴战略规划实施情况，加强对推进湘赣边区域合作示范区建设联席会议常态化建设机制的工作指导，分析研判总体进展，统筹协调规划实施重大问题。同时，加强工作指导，及时了解湘赣边区乡村振兴工作中新情况、新问题，推动各项工作任务落实落地。

感谢您对推进乡村振兴战略实施工作的关心，希望继续对我部的工作给予支持。

农业农村部

2019年9月20日
