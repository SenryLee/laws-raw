# 国家邮政局办公室关于印发“证照分离”改革优化审批服务实施方案的通知

各省、自治区、直辖市邮政管理局：

为贯彻落实《国务院关于在自由贸易试验区开展“证照分离”改革全覆盖试点的通知》（国发〔2019〕25号）精神，进一步优化营商环境，激发市场活力和社会创造力，国家邮政局决定在上海、广东、天津、福建、辽宁、浙江、河南、湖北、重庆、四川、陕西、海南、山东、江苏、广西、河北、云南、黑龙江等自由贸易试验区开展经营邮政通信业务审批和快递业务经营许可优化审批服务工作，现将实施方案印发给你们，请遵照执行。

附件：1.经营邮政通信业务审批优化审批服务实施方案

2.快递业务经营许可优化审批服务实施方案

国家邮政局办公室

2019年11月29日
