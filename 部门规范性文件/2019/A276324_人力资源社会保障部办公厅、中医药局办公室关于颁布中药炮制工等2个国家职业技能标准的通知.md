# 人力资源社会保障部办公厅、中医药局办公室关于颁布中药炮制工等2个国家职业技能标准的通知

## 人力资源社会保障部办公厅　中医药局办公室关于颁布中药炮制工等2个国家职业技能标准的通知

人社厅发〔2019〕57号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局），卫生健康委（卫生计生委）、中医药管理局：

根据《中华人民共和国劳动法》有关规定，人力资源社会保障部、中医药局共同制定了中药炮制工等2个国家职业技能标准，现予颁布施行。原相应国家职业技能标准同时废止。

人力资源社会保障部办公厅　中医药局办公室

2019年4月11日
