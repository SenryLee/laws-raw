# 中国铁人三项运动协会关于修订《中国铁人三项运动协会运动员比赛服和装备细则》的通知

## 关于修订《中国铁人三项运动协会运动员比赛服和装备细则》的通知

各参赛单位、参赛人员：

为提升铁人三项运动的整体形象，规范运动员比赛服和装备，参照《国际铁人三项联盟比赛服与装备细则》，结合国内比赛实际，我协会修订了《中国铁人三项运动协会运动员比赛服和装备细则》，现予以发布实施。

修订主要内容如下：

（一）总则部分第（二）条，新增“参加优秀组和U系列组别比赛的运动员，比赛服必须符合本细则；参加分龄组等其他组别比赛的运动员，在符合本细则第十条说明的‘最低要求’的基础上，可参照本细则执行。”

（二）新增“八、护臂”的内容。

（三）新增“十一、分龄组等其他组别运动员比赛服最低要求”。

（四）本细则自2019年4月15日起开始执行。原《中国铁人三项运动协会专业运动员比赛服和装备细则》、原《中国铁人三项运动协会业余铁人三项运动管理办法》中的相关内容均同时废止。

特此通知。
