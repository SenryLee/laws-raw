# 反兴奋剂中心关于开展教练员相关信息收集工作的通知

体反兴奋剂字〔2019〕258号

各省、自治区、直辖市体育局、新疆生产建设兵团体育局，中央军委训练管理部军事体育训练中心，有关运动项目管理中心，有关运动项目协会：

2014年，反兴奋剂中心在全国范围内开展了重点项目教练员相关信息的收集工作，初步建立了重点项目教练员信息系统。当前，为了适应新时代、新形势下的反兴奋剂工作，构建“拿干净金牌”的反兴奋剂长效治理体系，维护我国体育事业的健康可持续发展，根据2020年东京奥运会、2022年北京冬奥会的备战要求，国家体育总局反兴奋剂中心（以下简称反兴奋剂中心）将在全国范围内再次开展教练员相关信息的收集工作。现将有关事宜通知如下：

一、信息收集的范围

（一）项目范围

田径、游泳、自行车、举重、铁人三项、摔跤、柔道、拳击、跆拳道、赛艇、静水皮划艇、皮划艇激流回旋、乒乓球、现代五项、羽毛球、击剑、跳水、花样游泳、体操、网球、速度滑冰、短道速滑、花样滑冰、自由式滑雪、单板滑雪、帆船帆板、高尔夫、沙滩排球、水球、冬季两项、越野滑雪、射击、射箭、蹦床、空手道、冰壶、雪车、钢架雪车、蹼泳、高山滑雪、跳台滑雪、北欧两项、冰球、雪橇44个项目。

（二）教练员范围（包括在职和退休返聘的教练员）

1.人事劳资关系在各省、自治区、直辖市、新疆生产建设兵团、行业体协、解放军体育主管部门的教练员；或人事劳资关系虽不在各省、自治区、直辖市、新疆生产建设兵团、行业体协、解放军体育主管部门，但与之签署了劳动合同或工作协议的教练员。

2.人事劳资关系在总局相关运动项目管理中心的教练员；或虽人事劳资关系不在总局相关运动项目管理中心，但与之签署了劳动合同或工作协议的教练员。

3.因兴奋剂违规行为，被终身取消教练员资格和尚处于禁赛期的教练员，由其人事劳资关系所在单位负责。

4.涉及跨界跨项的教练员，由其现人事劳资关系所在单位负责。

二、信息收集工作的组织实施及要求

（一）各单位应当高度重视，指定专人负责，认真组织实施，确保报送的信息准确无误。在接到本通知的1个月内（7月27日）前，将具体负责人员的信息发送至coach@chinada.cn，具体格式要求为单位名称+姓名+电话+电子邮箱+单位地址。

（二）鉴于新版教练员信息采集系统还在调试阶段，各单位应当提前摸排，整体把握本单位本项目重点教练员情况，待新版系统调试完毕，将另文通知相关填报工作。
