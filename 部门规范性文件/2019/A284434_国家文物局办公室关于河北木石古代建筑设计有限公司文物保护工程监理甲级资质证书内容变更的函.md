# 国家文物局办公室关于河北木石古代建筑设计有限公司文物保护工程监理甲级资质证书内容变更的函

办保函〔2019〕988号

河北省文物局：

你局《关于河北木石古代建筑设计有限公司文物保护工程监理甲级资质证书内容变更的请示》（冀文物字〔2019〕151号）收悉。

经研究，我局同意河北木石古代建筑设计有限公司文物保护工程监理甲级资质证书中的法定代表人由“刘东光”变更为“李国强”，经济性质由“有限责任公司”变更为“有限责任公司（自然人投资或控股）”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2019年11月15日
