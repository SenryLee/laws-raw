# 农业农村部关于批准大连海宝渔业有限公司为国家级裙带菜良种场的通知

农渔发〔2019〕2号

大连市海洋与渔业局：

按照《国家级水产原、良种场资格验收与复查办法》有关规定，经验收和审查，现批准大连海宝渔业有限公司为国家级裙带菜良种场（命名为“国家级大连旅顺口裙带菜良种场”），并颁发《验收合格证书》，有效期5年。

良种场的主要任务是：按照良种生产技术操作规程，运用完善的工程、技术措施和严格的管理措施，保存和选育种用遗传材料和亲本，为水产苗种繁育单位提供良种亲本。

请你局依法督促该场严格执行《渔业法》《水产苗种管理办法》《水产原良种场生产管理规范》等有关要求，完善保种制度，强化管理措施，进一步加强良种保种，为我国水产养殖业绿色高质量发展作出应有贡献。

农业农村部

2019年1月8日
