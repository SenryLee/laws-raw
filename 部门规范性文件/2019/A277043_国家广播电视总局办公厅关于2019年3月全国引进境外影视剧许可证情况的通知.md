# 国家广播电视总局办公厅关于2019年3月全国引进境外影视剧许可证情况的通知

## 总局办公厅关于2019年3月全国引进境外影视剧许可证情况的通知

广电办发〔2019〕126号

各省、自治区、直辖市广播电视局：

根据总局电视剧管理的有关规定，现将2019年3月全国引进境外影视剧的情况予以通知。

附件：国家广播电视总局2019年3月同意发行的境外影视剧目录

国家广播电视总局办公厅

2019年5月6日
