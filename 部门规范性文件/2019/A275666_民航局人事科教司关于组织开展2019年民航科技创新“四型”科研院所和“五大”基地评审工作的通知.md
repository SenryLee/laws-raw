# 民航局人事科教司关于组织开展2019年民航科技创新“四型”科研院所和“五大”基地评审工作的通知

## 关于组织开展2019年民航科技创新“四型”科研院所和“五大”基地评审工作的通知

民航各地区管理局，各运输（通用）航空、服务保障公司，各机场公司，直属各单位，各协会、基金会，有关单位：

为落实民航科教创新大会精神和民航局《关于推进民航科技教育创新发展的意见》，按照2019年全国民航工作会议要求，加强创新型行业建设，创建基础技术研究型、应用技术开发型、成果转化枢纽型和技术政策暨服务智库型科研院所（以下简称“四型”科研院所），打造民航基础技术研究基地、应用技术开发基地、核心技术产业基地、成果转化效益基地和创新人才发展基地（以下简称“五大”基地），构建更加高效的民航科研体系，推进民航科技创新示范区建设，提升民航整体科技创新能力，现组织开展2019年民航科技创新“四型”科研院所、“五大”基地评审工作，有关事项通知如下。

一、目标任务

根据全国民航工作会议工作报告2019年重点任务安排，按照“成熟一个，挂牌一个”的原则，组织开展民航科技创新“四型”科研院所、“五大”基地评审工作，年内完成第二批评审工作。

二、条件要求

民航科技创新“四型”科研院所、“五大”基地具体申报条件参照《民航科技创新“四型”科研院所评审办法》（附件1）和《民航科技创新“五大”基地评审办法》（附件3）中的评审标准。

三、推荐办法和工作要求

1.民航科技创新“四型”科研院所、“五大”基地面向民航行业内外进行组织推荐。民航行业内推荐单位为民航地区管理局、运输（通用）航空集团公司、服务保障集团公司、机场集团公司、民航局直属单位和行业协会、基金会，行业外推荐单位资格参照民航单位执行。

2.各推荐单位推荐名额不限。各申报单位可分别申报基础技术研究型科研院所、应用技术开发型科研院所、成果转化枢纽型科研院所、技术政策暨服务智库型科研院所、基础技术研究基地、应用技术开发基地、核心技术产业基地、成果转化效益基地、创新人才发展基地中的一个或多个，申报总数不超过3个；也可整体申报“四型”科研院所或“五大”基地。

3.各推荐单位要高度重视，积极动员，严格标准，规范程序，在广泛征求意见的基础上，经过申报单位集体研究、内部公示等程序，征求有关主管部门和纪检监察等部门意见后，集体研究提出推荐对象，确保推荐质量。

4.各推荐单位在组织推荐工作中要严格遵守工作纪律，不准事先内定推荐对象，不准弄虚作假；要组织指导如实填写申报材料，对材料真实性要严格把关；对违反组织原则和工作纪律的，要按有关规定严肃处理。

5.中国民航科学技术研究院和民航局第二研究所共同作为技术支持单位，负责申报材料受理、形式审查和评审组织等工作。

四、申报要求

1.申报单位和推荐单位要认真审核申报材料，按照各自职责对申报材料逐项确认，加盖公章，由推荐单位汇总报送。

2.申报材料于2019年7月31日前邮寄或送达至中国民航科学技术研究院科技处。逾期报送的，不予受理。

纸质材料：申报函1份（对推荐对象、推荐程序、公示情况等进行说明，加盖推荐单位公章）、推荐汇总表1份（模板见附件5，加盖推荐单位公章）、申报材料（模板见附件2和附件4）一式9份。

3.申报材料模板等5个附件从民航局网站（www.caac.gov.cn）“信息公开”栏本通知的附件下载。
