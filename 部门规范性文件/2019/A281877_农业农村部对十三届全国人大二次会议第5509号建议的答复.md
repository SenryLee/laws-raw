# 农业农村部对十三届全国人大二次会议第5509号建议的答复

## 对十三届全国人大二次会议第5509号建议的答复

农办议〔2019〕408号

你们提出的关于修订《高标准农田建设通则》的建议收悉。经商自然资源部、生态环境部，现答复如下。

一、关于明确生态或绿色高标准农田定义及充实农田防护与生态环境保持内容

长期以来，我部及生态环境、自然资源等部门高度重视绿色发展及生态环境保护理念的贯彻落实，强调农业农村发展的可持续性。2018年11月，我部与生态环境部联合印发《农业农村污染治理攻坚战行动计划》，指导各地加强包括农业面源污染防治在内的农业农村生态环保工作，计划到2020年实现"一保两治三减四提升",即：保护农村饮用水水源，农村饮水安全更有保障；治理农村生活垃圾和污水，实现村庄干净整洁有序；减少化肥、农药使用量和农业用水总量；提升超标水体水质、农业废弃物综合利用率、环境监管能力和农村居民参与度，加快解决农业农村突出环境问题。其中，明确要求通过加强畜禽养殖粪污资源化利用等措施解决养殖业污染，通过持续推进化肥农药减量增效、加强秸秆农膜废弃物资源化利用、大力推进种植产业模式生态化等措施有效防控种植业污染。坚持"一控两减三基本"目标，强化绿色引领，依靠科技进步，主攻质量效益，取得了明显成效。据国家统计局统计，2017年全国农用化肥使用量5859.4万吨（折纯），比2016年减少124.7万吨，水稻、玉米、小麦三大粮食作物化肥利用率为37.8%,比2015年提高2.6个百分点。

二、关于增加农产品质量安全要求

近年来，我部高度重视无公害农产品认证制度改革及农产品质量安全追溯体系建立工作，采取有力措施保障农产品质量安全。一是加强追溯管理制度建设。印发《农业部关于加快推进农产品质量安全追溯体系建设的意见》，出台《农产品质量安全追溯管理办法（试行）》等6项配套制度，指导全国农产品质量安全追溯体系建设。二是加强国家追溯平台建设。2017年7月，建成国家追溯平台并上线试运行，截至2019年4月底，全国共有10417家生产经营主体、2129家监管机构、625家检测机构、661家执法机构已注册使用国家追溯平台，上传数据5.3万条。三是加强追溯管理标准建设。制定《农产品质量安全追溯管理专用术语》《农产品质量安全追溯标识格式与编码规则》《农产品质量安全追溯数据格式规范》等11项追溯技术标准，初步形成覆盖基础数据、应用支撑、数据交换、网络安全、业务应用等类别的标准体系，为生产经营主体以及平台互联互通提供技术指南。四是推动实施追溯"四挂钩"机制。2018年10月，印发《农业农村部关于农产品质量安全追溯与农业农村重大创建认定、农业品牌推选、农产品认定、农业展会等挂钩的意见》，积极推进农业农村部本级创建、认定、推选等工作与追溯挂钩。

三、关于充实完善建设管护与利用内容

近年来，我部将农田保护及耕地质量监测保护工作摆在重要位置，先后制定颁发了《耕地地力调查与质量评价技术规程》《耕地质量验收技术规程》《耕地质量等级》（GB/T33469—2016）《耕地质量调查监测与评价方法》（农业部令2016年第2号）等一系列与耕地质量有关的国家和行业标准，提出了切实加强耕地质量建设管理的意见，明确了耕地保护目标和责任。同时，推动地方大力推进耕地质量管理法规建设，吉林、湖南、内蒙古、黑龙江、湖北、江苏等省份率先颁布实施了耕地质量管理地方法规，将耕地质量保护提升纳入法律轨道。此外，我们还注重信息手段的应用，拟构建"全国农田建设综合监测监管平台",采用遥感、物联网、大数据、云计算、人工智能等新技术新手段，将高标准农田项目建设、管护利用以及耕地质量等级评价和改良等信息数据全部"上图入库",实现农田建设与保护全程数字化动态监测和监管，增强农田建设监督监管能力，提升管理效率。

此次机构改革，将发展改革委的农业投资项目、财政部的农业综合开发项目、国土资源部的农田整治项目、水利部的农田水利建设项目等管理职责整合到农业农村部，明确由农业农村部负责农业投资管理。农业农村部的三定方案中明确设立农田建设管理司，承担农田建设项目管理工作，理顺了农田建设管理体制，解决了过去多年未能解决的农田建设"五牛下田"的难题。机构改革到位后，农田建设管理司即着手开展农田建设标准的制修订工作。通过全面梳理《高标准农田建设通则》《高标准农田建设标准》《高标准基本农田建设标准》《高标准农田建设总体规划》《国家农业综合开发高标准农田建设规划》《全国新增1000亿斤粮食生产能力规划》等系列标准和规划，赴重庆、广西、广东等地实地调研高标准农田建设，多次邀请各级政府有关部门、乡镇、村组、农户、企业及农田水利、工程建设、标准制定等相关领域专家参加座谈等方式，初步确定了分区域制定高标准农田建设标准及定额的思路和方案。综合考虑自然条件、地貌特征、农田道路、农机作业水平、田块规模、土壤肥力等因素，按照地域特征将全国划分为东北区、华北区、西北区、西南区、东南区等5个大区，并在大区的基础上，根据地形地貌进一步细分为15个二级类型区，根据二级类型区确定建设内容，制定建设标准。

按照《乡村振兴战略规划（2018—2022）》要求，到2020年全国建成8亿亩、2022年建成10亿亩高标准农田，农业农村部门每年必须完成高标准农田建设任务8000万亩以上，据初步测算的平原、丘陵、山区建设标准，现有的资金规模和建设任务无法匹配。为保证年度建设任务如期足额完成，拟先期实现"田成方、林成网、渠相通、路相连、旱能灌、涝能排、渍能降"的高标准农田建设基本要求，以工程建设为主，改善农业现代化发展的基础条件，等条件允许后再实现生态、绿色等建设目标。

下一步，我们将结合代表建议，积极协调有关部门共同推进农田防护及生态环境保护工作，加强农产品质量安全监管力度，全面提升农产品质量安全监管能力和水平，同时运用多种措施强化农田建设管护及耕地质量监测，进一步贯彻好绿色发展理念，为我国耕地可持续利用提供坚实保障。

感谢你们对高标准农田建设工作的关心，希望继续对我部工作予以支持。
