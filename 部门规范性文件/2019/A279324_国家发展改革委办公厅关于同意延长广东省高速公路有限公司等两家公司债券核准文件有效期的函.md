# 国家发展改革委办公厅关于同意延长广东省高速公路有限公司等两家公司债券核准文件有效期的函

发改办财金〔2019〕670号

广东省、新疆维吾尔自治区发展改革委：

报来《关于延长广东省高速公路有限公司债券批文有效期的请示》（粤发改财金〔2019〕154号）、《关于申请延长乌苏市兴融建设投资有限责任公司发行公司债券核准批文有效期的请示》（新发改财金〔2019〕444号）收悉。经研究，现函复如下。

一、同意将《国家发展改革委关于广东省高速公路有限公司发行公司债券核准的批复》（发改企业债券〔2018〕120号）文件有效期延长12个月至2020年6月13日。

同意将《国家发展改革委关于新疆维吾尔自治区乌苏市兴融建设投资有限责任公司发行公司债券核准的批复》（发改企业债券〔2018〕124号）文件有效期延长12个月至2020年6月23日。

二、请你委督促发行人按照《公司法》《证券法》《企业债券管理条例》和有关规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

三、请你委督促发行人按要求及时做好信息披露及债券资金管理，按照核准的募集资金投向合规使用债券资金，认真落实偿债保障措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅

2019年6月10日
