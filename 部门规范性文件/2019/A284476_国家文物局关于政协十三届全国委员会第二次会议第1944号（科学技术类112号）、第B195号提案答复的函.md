# 国家文物局关于政协十三届全国委员会第二次会议第1944号（科学技术类112号）、第B195号提案答复的函

文物博函〔2019〕843号

印红、赵进东等委员：

你们提出的《关于建立中国国家自然历史博物馆的提案》《关于设立国家自然博物馆的提案》收悉，现答复如下。

博物馆是保护和传承人类文明的重要殿堂，是连接过去、现在、未来的桥梁。中国历史悠久，文明璀璨，地大物博，山河壮丽，为各类博物馆特别是自然类博物馆的建立和发展，提供了得天独厚的基础条件。加强自然类博物馆的建设，保护、研究与展示生命演化过程中的自然遗物以及人类历史上具有历史、科学和艺术价值的自然遗产，对于普及科学知识、推进生态文明建设、增强文化自信、提升国家文化软实力，具有重要意义。

我局历来高度重视和积极支持自然类博物馆的建设发展。据统计，目前全国已建成自然类博物馆近180家，其中，中国地质博物馆、北京自然博物馆、天津自然博物馆（北疆博物院）、吉林省自然博物馆、浙江自然博物馆等重点自然类博物馆被评为国家一级博物馆，成为我国博物馆的重要组成部分。这些博物馆通过举办陈列展览、开展教育活动，向公众展示传播自然历史文化遗产，满足人民对美好生活的新期待，取得了良好的社会效益。

对于你们的建议，自然资源部认为，提案中提到中国国家自然历史博物馆建设包括“珍藏岩矿、古生物化石，动物、植物标本，引人入胜的自然生态系统场景……”，与中国地质博物馆关系紧密，目前该部已开展相关研究和论证工作。同时，中国国家自然历史博物馆的规划和建设涉及复杂的体制问题，有必要从国家层面组织相关部门进一步会商。国家发展改革委认为，北京自然博物馆经过多年建设已初具规模，虽然以北京命名，但无论从馆藏标本类型、开展的研究和工作，都并不仅代表北京地区。因此，是国家投资、择址新建中国国家自然历史博物馆，还是在北京自然博物馆的基础上整合资源、完善功能，需统筹考虑国家财力和实际需要作充分论证。北京市科学技术研究院介绍，北京市高度重视，目前正在北京自然博物馆的基础上积极筹建“国家自然博物馆”开展前期工作。我局积极支持在北京筹建国家自然博物馆，由局领导带队进行现场调研，与北京市领导会谈沟通，提出有关意见和建议，推进该项工作。

鉴于建立国家自然博物馆专业性强、涉及面广，需要国家有关主管部门加强指导，依托各地已有的重点自然类博物馆资源，对其选址、展示内容、功能、规模及建筑形式、主分馆制度等进行充分评估论证，统筹做好规划设计并立项实施。我局将积极关注工作进展，积极配合有关部门并协调有关省级文物行政部门加强相关业务指导，支持建设体系完整的中国自然类博物馆体系，充分发挥其应有的爱国主义教育基地、科普基地作用。

此外，根据国家有关规定，国有博物馆名称特殊情况确需冠以“中国”“中华”“国家”等字样的，需报请国务院审核同意。

感谢你们对博物馆事业的关心和支持！

国家文物局
