# 国家文物局关于色拉寺保护范围内新建和改建厕所项目的意见

文物保函〔2019〕140号

西藏自治区文物局：

你局《关于审核西藏拉萨市色拉寺新建、改建厕所工程设计方案的请示》（藏文物字〔2018〕366号）收悉。经研究，我局原则同意色拉寺保护范围内新建和改建厕所项目。

一、所报方案尚需做以下必要的修改和完善：

（一）补充色拉寺文物分布、保护区划和管理规定等内容，细化完善总平面图。

（二）补充文物影响评估报告，并据此调整优化设计方案。

（三）明确新建、改建厕所的具体位置；科学测算建设规模，严格控制新建建筑体量和高度。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月11日
