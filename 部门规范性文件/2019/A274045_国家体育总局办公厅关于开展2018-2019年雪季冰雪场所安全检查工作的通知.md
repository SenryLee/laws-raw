# 国家体育总局办公厅关于开展2018-2019年雪季冰雪场所安全检查工作的通知

## 体育总局办公厅关于开展2018-2019年雪季冰雪场所安全检查工作的通知

各省、自治区、直辖市、新疆生产建设兵团体育局：

根据《全民健身条例》及国务院有关安全生产工作系列指示精神，为贯彻落实《“带动三亿人参与冰雪运动”实施纲要（2018-2022年）》，保障群众冰雪运动安全，现就2018-2019年雪季冰雪场所安全检查工作有关事项通知如下：

一、检查范围

本次检查范围为全国所有向社会开放的滑冰场所和滑雪场所。在冰雪场所全面自查和地方体育部门安全检查的基础上，委托体育总局冬运中心组成工作组，赴部分省市了解工作开展情况，并委托体育总局科研所抽取部分冰雪场所进行技术检验。

二、检查安排

（一）2019年2月15日前，场所自查与属地检查阶段。各地体育部门落实本地区冰雪场所安全检查工作。

（三）2019年2月15日-3月10日，实地了解和技术检验阶段。工作组赴相关省市了解工作开展情况，并委托检验机构抽取部分冰雪场所进行技术检验。

（四）2019年3月11日-3月15日，督促整改阶段。工作组向各省（区、市）体育局反馈冰雪场所安全监督抽查情况，各地结合实际情况，进一步深入检查，督促整改。

（五）2019年3月16日-3月31日，全面总结阶段。在认真、深入检查的基础上，客观全面、实事求是地进行总结，形成有情况、有分析、有建议措施的检查报告，于3月31日前报送体育总局冬季运动管理中心。

三、工作要求

（一）提高认识，落实责任

牢固树立安全工作红线意识和底线思维，推动冰雪场所安全工作纳入同级党委、政府重要议事日程。落实体育部门的行业监管责任制度，加强监管机构和执法力量建设，明确各级分管领导、监管部门和监管人员。建立本地区冰雪场所名录库，督促冰雪场所经营单位落实安全生产主体责任，实施法定代表人安全生产承诺制。

（二）细化措施，全面排查

按照属地原则部署开展本地区冰雪场所企业自查和体育部门实地检查工作，强化安全风险防控和隐患排查治理。加强与相关部门的协同联动，加强联合检查。检查范围应覆盖本地区全部冰雪场所，检查内容应覆盖强制性国家标准的全部要求，实现全覆盖、无死角。

（三）加强宣传，提升服务

借助安全检查，加大对冰雪场所相关法律法规和标准的宣传，强化安全意识，普及安全知识。监督指导经营单位建立并落实安全培训制度，强化全员安全生产责任意识。

（四）狠抓整改，严格执法

严格贯彻关于经营高危险性体育项目行政许可和强制性标准实施的有关规定，对检查发现的问题，加大整改力度。对违法经营行为，联合相关部门依法严厉打击。严格执行《体育市场黑名单管理办法》，充分利用诚信约束手段，加大对失信经营主体和从业人员的惩戒力度。
