# 国家文物局关于政协十三届全国委员会第二次会议第0520号（文化宣传类069号）提案答复的函

文物保函〔2019〕863号

温立新委员：

您提出的《关于加强军工军事文物遗产保护与传承的提案》已交由我局会同教育部、文化和旅游部、退役军人事务部办理，现答复如下：

军工军事文物是我国文化遗产的重要组成部分，见证了重要革命事件的发生和军工技术的发展，承载着重要的历史记忆，具有重要的历史价值，同时对开展爱国主义教育、传承红色基因和培育社会主义核心价值观都具有重要的社会作用。

长期以来，国家文物局十分重视军工军事文物的保护和利用工作。组织编制了《长征文化线路保护总体规划》，开展了相关标识与展示体系建设指引研究，并积极推进长征文化线路整体保护利用示范段试点工作。在统筹开展赣南等原中央苏区、延安革命根据地片区等的革命旧址保护利用工作中，将军工军事文物作为重点予以积极支持。对重庆抗战兵器工业旧址群、青海第一个核武器研制基地旧址、红山核武器试爆指挥中心旧址、洛阳西工兵营等列入全国重点文物保护单位的军工军事文物给予重点支持，先后投入文物保护专项资金逾1亿元。2019年，国家文物局在第八批全国重点文物保护单位遴选中，大力支持中央军委后勤保障部、国防科工局和各省（区、市）文物部门申报军事军工文物项目，将具有重大价值的军工军事文物项目列入了推荐名单。

与此同时，文化和旅游部积极推进军事旅游发展。2017年与中国科学院共同评选出“首批十大科技旅游基地”，甘肃酒泉卫星发射基地、中国科学院遥感卫星接收站三亚站等军事旅游基地入选。2018年会同中宣部举办全国红色讲解员大赛，推出了一批感染人、教育人的红色故事；在志愿讲解员中有很多退休、退役军人，他们走进博物馆、纪念馆，结合亲身经历为广大观众讲述红色故事，取得了良好的社会反响。此外，教育部以职业院校军事和爱国主义教育工作为抓手，推动军工军事文化遗产的保护传承普及。退役军人事务部坚持将革命文物普查和保护工作作为烈士褒扬的一项重要业务，积极开展各地革命文物普查和保护工作的督导检查，并组织全国烈士纪念设施保护管理人员培训和文物普查鉴定工作培训，邀请革命文物保护利用、陈列展示等方面的专家对保护管理人员进行授课。目前，烈士纪念设施已逐步成为党和国家开展爱国主义教育的重要阵地，每年前往祭扫纪念的群众达1.5亿多人次，褒扬烈士、教育群众的作用日益凸显。

2018年7月，中办、国办印发了《关于实施革命文物保护利用工程（2018-2022年）的意见》，明确提出了加大军队系统革命文物展示利用力度，在做好安全保密工作的前提下，适时对外组织开展参观、瞻仰、纪念等活动；要统筹保护利用好军地革命文物资源，中央和地方组织实施的革命文物保护利用工程项目应将军队系统革命文物工作整体纳入和推进。下一步，国家文物局会同有关部门继续加强对军工军事文物的保护利用，重点做好以下工作：

一是做好军事军工文物基础工作。国家文物局将联合相关部门，指导各地文物部门继续加强对军工军事文物的普查、登记和建档工作，将具有价值的军工军事设施及时登记公布为不可移动文物并挂牌保护，将具有重大价值的军工军事文物核定公布为各级文物保护单位，积极完善“四有档案”，并系统评估军事军工文物保护管理现状，为提升文物保护利用水平奠定坚实基础。

二是切实加强对军事军工文物的保护。督促各地政府落实文物保护主体责任，加强与军队部门的协调沟通，指导各地编制军事军工文物的保护规划和方案，将保护规划纳入当地国民经济社会发展规划和城乡规划。对存在险情的军事军工文物尽快实施抢救性保护工程，加强环境整治，不断改善保存状况。并注重日常监测，及时发现问题，做好日常修缮维护。国家文物局将在项目和技术上给予支持。

三是积极开展军事军工文物的宣传利用。联合军事、军工和科技领域的专家充分挖掘军事军工文物的价值内涵和文化元素，积极推动革命博物馆和纪念馆举办高质量的军事军工文物展览、社会教育活动和流动展览进校园、部队、机关活动，提高全民军事军工文物保护意识。大力发展红色旅游，运用市场机制开发各种军事军工文物文化创意产品，形成创意品牌。

四是注重加强人才队伍建设。积极联合中央军委后勤保障部、国防科工局等相关部门，广泛联系军工军事文物研究方面的专家学者，定期组织军事军工文物考察和调研，推动保护、传承和利用。鼓励退休、退役军人参加各类革命军事博物馆、纪念馆的志愿者队伍，积极开展红色文化教育讲座和军事军工文物讲解。鼓励在各类军事装备和体验类项目中，吸纳具有专业技术和操作经验的退役军人再就业，实现退役军人再就业与军事军工文物保护传承相融合，传承与发扬军工军事文化与爱国主义精神。

感谢您对文物事业的关心与支持！

国家文物局

2019年8月22日
