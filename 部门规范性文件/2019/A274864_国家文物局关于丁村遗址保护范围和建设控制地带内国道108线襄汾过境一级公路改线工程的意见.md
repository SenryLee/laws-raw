# 国家文物局关于丁村遗址保护范围和建设控制地带内国道108线襄汾过境一级公路改线工程的意见

文物保函〔2019〕226号

山西省文物局：

你局《关于国道108线襄汾过境一级公路改线工程穿越丁村遗址的请示》（晋文物〔2018〕86号）收悉。经研究，我局原则同意在丁村遗址保护范围和建设控制地带内实施国道108线襄汾过境一级公路改线工程。

一、所报方案尚需进一步明确项目选线与丁村遗址的位置关系，并严格控制工程范围和施工强度，做好施工中的文物保护工作，明确工程竣工后原108国道运营管控具体措施，确保文物安全。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古调查和发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

五、请你局指导地方人民政府，依据《丁村遗址保护总体规划（2016-2030）》、丁村遗址最新考古工作成果等，抓紧编制丁村遗址保护区划调整方案，统筹考虑襄汾县城乡建设与遗址保护之间的关系，明确具体建设控制要求和指标。

专此函复。

国家文物局

2019年3月1日
