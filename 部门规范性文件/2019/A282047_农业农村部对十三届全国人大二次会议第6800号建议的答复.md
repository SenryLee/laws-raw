# 农业农村部对十三届全国人大二次会议第6800号建议的答复

## 对十三届全国人大二次会议第6800号建议的答复

农办议〔2019〕532号

马瑞燕、辛琰、王娟玲代表：

你们提出的关于支持山西农谷国家农业高新技术示范区建设的建议收悉。经认真研究，现就涉及我部职能有关内容答复如下。

一、关于举办农村改革论坛

2018年是我国改革开放40周年，在农村改革的重要推动者杜润生的故乡山西太谷县举办农村改革论坛意义重大。农业农村部门、科研机构、高等院校、金融机构等代表齐聚论坛，共商农村改革经验做法，取得了丰硕的成果。关于中央农办、农业农村部等相关部门继续支持举办一年一度农村改革论坛的建议，由于农村改革（太谷）论坛是特殊时间特殊节点举办的论坛，同时考虑到贯彻落实中央八项规定精神、大力精简会议论坛活动等有关要求，我部目前暂无相关计划。

二、关于开展农民教育培训工作

教育培训是提升农民综合素质和生产技能的重要途径，2019年，中央财政安排6100万元资金支持山西省农民教育培训工作，太谷县作为示范县承担了国家农民培训任务。为强化农民教育培训基础条件建设，加强教育培训基地分级分类管理，提升农民实习实训、创业孵化、跟踪服务等工作质量水平，2016年开始，我部组织开展农民教育培训基地遴选工作。农民教育培训基地包括实训基地、农民田间学校、创业孵化基地和综合类基地，由基地网上自愿填报或各级农业农村部门推荐填报，纳入基地信息库。我部支持山西农谷农民大学发挥自身优势，成为农民教育培训基地，承担农民教育培训任务，为农民教育培训提供学习和实训场所。同时，鼓励太谷县集聚各方资源，充分发挥山西农业大学等高等院校、科研院所实力，共同为山西农谷培养高层次农业人才。

下一步，我部将继续支持山西省农民教育培训工作，精心组织实施培训，抓实落细关键环节，不断发展壮大适应乡村振兴战略实施和现代农业发展需求的高素质农民队伍。

感谢你们对农民教育培训工作的关心，希望今后继续对我部工作给予支持。
