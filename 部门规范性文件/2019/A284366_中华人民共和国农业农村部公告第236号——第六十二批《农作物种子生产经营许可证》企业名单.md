# 中华人民共和国农业农村部公告第236号——第六十二批《农作物种子生产经营许可证》企业名单

## 中华人民共和国农业农村部公告

第236号

根据《中华人民共和国种子法》《农作物种子生产经营许可管理办法》等规定，批准发放四川神农大丰种业科技有限公司等16家企业《农作物种子生产经营许可证》（详见附件）。

特此公告。

附件：第六十二批《农作物种子生产经营许可证》企业名单

农业农村部

2019年11月25日
