# 国家文物局关于大运河南运河保护区划内华侨城运河水街建设项目的意见

文物保函〔2019〕157号

天津市文物局：

你局《关于上报大运河南运河建设控制地带内实施华侨城运河水街道建设项目（西青区中北镇卉锦道北侧商业项目）的请示》（津文旅发〔2018〕18号）收悉。经研究，我局原则同意在大运河南运河保护区划内实施华侨城运河水街道建设项目（西青区中北镇卉锦道北侧商业项目），暂不同意其中跨越运河本体的步行桥建设内容。

一、所报方案尚需作以下必要的修改和完善：

（一）补充考古调查勘探资料，明确拟建项目所处区域的地下文物遗存埋藏情况。

（二）补充拟建项目与世界文化遗产大运河南运河保护区划的位置关系图纸，并根据拟建项目选址所涉及保护区划的管理规定，校核、完善方案设计。

（三）进一步完善遗产影响评估报告，应充分考虑对大运河传统景观特征的保护，做到客观、严谨。部分建筑层数和高度过高，建议以运河河堤地坪为基准标高进一步完善方案设计。

（四）应将地块二西侧停车场入口、东侧地上停车位调整至保护范围之外，避免施工对运河河道、驳岸等遗产本体安全造成影响。

（五）地块一中河弯处建筑体量过大，屋顶形式与周边其他建筑差异明显，应进一步调整、优化设计，对大面积平屋顶进行切分，弱化建筑体量，确保沿河视域的通透性和滨河空间的开阔性，使拟建项目整体上与南运河景观环境相协调。

（六）建设项目不得破坏运河驳岸，宜取消亲水平台设计。有关跨越运河本体的步行桥建设，应进一步论证其必要性和可行性。如确需建设，应编制文物影响评估报告，按程序另行单独报批。

（七）应编制文物监测和应急预案，并确保相关措施落实到位。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月18日
