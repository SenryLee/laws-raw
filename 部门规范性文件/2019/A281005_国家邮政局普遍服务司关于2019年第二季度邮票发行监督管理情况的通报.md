# 国家邮政局普遍服务司关于2019年第二季度邮票发行监督管理情况的通报

局普函〔2019〕31号

各省、自治区、直辖市邮政管理局：

2019年二季度，各地邮政管理局按照国家局工作部署，依法开展邮票发行监督管理。现将有关情况通报如下：

一、邮票发行综合监管情况

（一）中国2019世界集邮展览成功举办。中国2019世界集邮展览于2019年6月11日至17日在湖北武汉举行。85个国家（地区）的集邮组织和邮政机构参展，共展出展品4683框（国际2468框、国内2215框），其中竞赛性展品3433框、非竞赛性展品1250框；另展出文献类展品145部。展览规模创世界邮展之最。本次邮展是中国继1999、2009年之后再次举办世界集邮展览，共评审产生国家大奖、国际大奖、荣誉大奖各1部，大金奖45部、金奖111部。我国有27部展品获奖，《中国1897年红印花加盖邮票》获国家大奖，《中国蒙古邮政史（1755-1921）》获荣誉大奖，《中国集邮史》等还获最佳文献奖、最佳青少年奖。

（二）举办2019年邮票发行监管培训班。国家局于4月23日-26日在贵州省遵义市举办2019年全国邮票发行监督管理培训班。培训就推进落实2019年邮票发行监督管理，全国仿印邮票图案管理省际交叉执法检查等工作进行了全面部署，并邀请贵州省高级人民法院法官进行行政执法案例讲解。学员通过培训进一步强化了监管部门的监督管理职责意识，增强了对做好邮票发行监督管理工作的信心，提高了依法行政的能力和水平，有效激发了工作积极性。贵州、辽宁、吉林、青海等局举办全省邮票发行监管工作培训班，加强全省邮票发行监督管理能力及水平，进一步夯实依法履职基础。

二、仿印邮票图案及其制品审批

二季度，国家局组织仿印邮票图案及其制品省际交叉执法检查，5月20日至6月21日， 4个专项检查组先后赴北京、江西、广西、云南、甘肃、宁夏、黑龙江、吉林等8个省份开展仿印执法检查，共检查省级邮政管理部门8个，地市级邮政管理部门14个，各级邮政企业31个，集邮交易市场3个，邮政企业集邮票品销售网点28个、邮品库房25个，做到省市县三级网络全覆盖。

各省市采取措施加强仿印邮票图案及其制品的监管，推动仿印审批工作落实。全国邮政管理部门共办理仿印邮票图案及其制品审批37件73例，分别由贵州、安徽、福建、山东、河北、上海、广东、北京、浙江、陕西、湖北、甘肃、江苏、西藏等局初审，国家局予以审批。山东、福建局审批并向国家局备案2件2例。

三、邮票印制与销售监督检查

（一）检查基本情况。二季度，各地相继开展了《中国古典文学名著——〈西游记〉（三）》《2019年中国北京世界园艺博览会》《"五四"运动一百周年》《芍药》《中国古镇（三）》《儿童游戏（二）》《中国2019世界集邮展览》《中欧班列（义乌—马德里）》等8套纪特邮票的销售监督，出动检查4998人/次，检查纪特邮票销售网点3564处/次，下发责令改正通知书6份，作出行政处罚3例。从检查结果来看，绝大多数网点能够在发行前公示销售服务信息、提供预订邮票领取和零售票服务，零售邮票数量也能够满足用户需求。各级邮政管理部门能够依法履行邮票发行监管职责，督促邮政企业提升邮票销售服务水平。

（二）纪特邮票销售日常监督检查。各级邮政管理部门能够依法履行邮票发行监管职责，督促邮政企业提升邮票销售服务水平。河南局开展二季度邮票印制监督检查。河南漯河局按照"突出重点、注重实效"的原则，启动"双随机"执法检查模式对辖区内3个邮票发行网点进行专项检查；天津局督促邮政企业做好《南开大学建校一百周年》纪念邮票图案设计、报审以及首发活动等工作；河北石家庄局结合邮票首发积极组织石家庄少年邮局策划风采展示活动；福建莆田局积极办理市政协委员关于发行《木兰陂》纪特邮票的相关政协提案；河北邯郸、湖南湘西、浙江义乌、安徽亳州等局分别举办《中国古镇（三）》《中欧班列（义乌—马德里）》《芍药》等邮票首发式；浙江、山东临沂等局加强邮票选题工作，积极开展"陈望道中文首译《共产党宣言》100周年"、"人民音乐家施光南诞辰80周年"、 "沂蒙精神"等选题的申报推荐工作；湖南、福建宁德等局积极配合地方政府做好《精准扶贫》邮票发行相关工作。

（三）存在问题及处理情况。广西崇左局就中国邮政集团公司龙州县分公司违反邮票销售规定，在发行日前提前销售《中国2019世界集邮展览》纪念邮票的违法行为立案调查，责令其立即改正违法行为，并处以3万元人民币罚款；山西太原局就邮政企业未在《中国2019世界集邮展览》纪念邮票发行日前公告新邮销售服务信息下发责令改正通知书；江苏宿迁局就邮政企业未按规定如实公告《马拉松》特种邮票新邮销售服务信息下发责令改正通知书；广东中山、黑龙江局就邮政企业未在《中欧班列（义乌-马德里）》特种邮票、《五四运动一百周年》纪念邮票发行日前向社会公告邮票销售信息下发责令改正通知书；青海果洛局就邮政企业未在《芍药》特种邮票发行日前向社会公告邮票发行信息和新邮销售服务信息下发责令改正通知书。

山西晋中局就榆次区安宁集邮营业厅未按规定如实公告《儿童游戏（二）》特种邮票新邮销售服务信息以及晋中市邮政分公司未如期如实向邮政管理部门报告新邮展销活动约谈企业、下发整改通知书。并针对以上违法行为对中国邮政集团晋中市分公司处予警告处罚；西藏那曲局就中国邮政集团公司那曲市分公司未在《中国古典文学名著-西游记（三）》纪特邮票发行之前向社会公告邮票信息作出警告行政处罚。

四、下阶段工作要求

三季度，各级邮政管理部门要按照国家局统一工作部署，扎实开展邮票发行监督管理工作。重点加强仿印邮票图案管理，着力开展本行政区域内的仿印邮票图案及其制品许可审批工作。做好中国人民政治协商会议成立七十周年等重点题材纪特邮票印制和销售监督检查。依法维护邮票市场秩序和消费者权益，力争高质量全面完成年度邮票发行监管工作目标。
