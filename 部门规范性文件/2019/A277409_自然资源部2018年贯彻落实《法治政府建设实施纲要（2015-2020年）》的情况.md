# 自然资源部2018年贯彻落实《法治政府建设实施纲要（2015-2020年）》的情况

2018年，新组建的自然资源部以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届二中、三中全会精神，牢固树立“四个意识”，不断增强“四个自信”，坚决做到“两个维护”，坚持把法治建设作为建部之初固根本、稳预期、利长远的保障措施，坚持用最严密的法治推进生态文明建设，切实落实《法治政府建设实施纲要（2015-2020年）》。

一、坚持政治统领，系统谋划自然资源法治建设工作

我部组建后第一次党组会议即组织学习习近平总书记关于生态文明建设和国土、海洋、测绘及林草工作的重要指示批示。2018年召开三次全体干部大会，部党组书记、部长陆昊同志先后就总书记对机构改革、生态文明建设、自然资源管理等方面的重要论述进行集中宣讲。部党组会议专题研究贯彻中央全面依法治国委员会第一次会议精神和今年的第二次会议精神，将习近平生态文明思想和党中央精神贯穿自然资源法治建设的去全过程，坚持政治统领，坚持国家立场、人民利益、权责对等和底线思维，大力弘扬讲认真的工作态度和抓落实的工作要求，扎实推进法治建设各项任务取得实效。

二、全力推进自然资源重大立法工作

（一）做好立法规划的落实。对列入十三届全国人大常委会立法规划的《土地管理法（修改）》《矿产资源法（修改）》《不动产登记法》《国土空间开发保护法》等重大立法项目，按照“任务、时间、组织、责任”四落实的要求，分解落实立法任务。

（二）推动自然资源重要立法工作取得积极进展。把《土地管理法》修改作为农村土地管理改革和自然资源审批制度改革的关键举措，推动该法进入全国人大常委会审议。提请全国人大常委会将农村土地三项制度改革试点的法律授权延长一年。积极做好《矿产资源法》修改研究工作。

（三）完善制度，加强自然资源规章规范性文件管理。出台《自然资源部立法工作程序规定》《自然资源规范性文件管理规定》。认真开展涉及军民融合发展、产权保护、生态环境保护法规文件清理工作。部署开展部组建后第一次规范性文件全面清理工作。

三、依法全面履行政府职能，深入推进“放管服”改革

（一）着力解决不动产登记耗时长、办理难问题。印发《自然资源部关于全面推进不动产登记便民利民工作的通知》（自然资发〔2018〕60号），在全国部署开展不动产登记窗口作风问题专项整治。到2018年底，一般登记由法定30个工作日压缩到15个工作日。全国720多个市县推出了“互联网+不动产登记”服务，推进不动产抵押登记“不见面”办理，在各类银行开放不动产抵押登记端口或者办理点4257个，在乡镇设立受理点6269个。分类绘制26种登记流程图。落实优化营商环境要求，推动我国财产登记指标2018年在世界银行评价排名由41位提升至27位。

（二）积极推进用地审批制度改革。向国务院报送《自然资源部关于用地审批制度“放管服”改革有关事宜的请示》（自然资发〔2018〕114号），针对中央一级审批范围较大、环节过多、审批周期长等主要问题，研究提出了改革建议，并纳入《土地管理法》修改。

（三）全面清理论证现有行政许可事项和证明事项。对我部现有行政许可事项进行了全面清理和评估，研究提出清理意见和事中事后监管措施。全部取消没有法律、行政法规规定的证明事项。持续推进“证照分离”改革，将“从事测绘活动单位资质许可”涉企行政审批事项纳入第一批全国推开“证照分离”改革清单。自然资源督察机构结合督察实践不断完善工作制度。

四、强化依法行政制度落实，严格规范公正文明执法

（一）坚持重大行政事项集体决策。2018年，共召开39次部党组会、1次部务会、17次部长办公会、15次建设用地会审会、12次探矿权采矿权会审会、3次海域海岛使用项目审核会，对制定部门规章、制发规范性文件、重要审批事项、重大项目安排等坚持实行集体讨论决策。

（二）开展重大执法决定法制审核实践。巩固国务院重大执法决定法制审核制度试点成果，探索完善部重大执法决定法制审核制度，针对实践中发现的多次审核衔接问题，进一步优化法制审核流程。

（三）完善行政执法公示制度。2018年通过召开新闻发布会方式4次公开通报42起违法案件查处结果，涉及土地、矿产、海洋、林业等多个领域。在部门户网站“行政执法公示（执法查处类）”栏对部执法证件持有人信息和部省两级自然资源主管部门立案查处情况进行公示。

（四）规范部法律顾问和公职律师队伍建设。探索法律顾问参与重大执法决定法制审核、法治宣传教育等非诉类事务的机制。完成部机关及派出机构持有公职律师证书人员的梳理工作，做好部公职律师队伍组建工作。

五、健全内外监督机制，强化对行政权力的监督制约

（一）认真办理人大代表建议和政协委员提案。2018年我部办理人大建议454件、政协提案214件，所有建议提案均按时办结，并将涉及公共利益、社会关注度高及需要社会广泛知晓的137件建议提案复文在部门户网站上主动公开，接受公众查询和监督。

（二）推进自然资源行政公益诉讼，自觉接受司法监督。2018年初，与最高法、最高检联合召开座谈会，推动地方各级自然资源主管部门与检察机关协同落实行政公益诉讼制度。与最高检等8个单位共同制发《关于在检察公益诉讼中加强协作配合依法打好污染防治攻坚战的意见》，协同配合推进自然资源领域公益诉讼工作。

（三）全面推进政务公开，主动接受社会监督。2018年共受理信息公开申请3029件，同比增长37.4%，全部按期办结。优化办理流程，通过办公自动化系统实现主动公开文件拟稿审批报送一站式电子化流程。加强政策解读与回应，2018年组织召开新闻发布会12次，媒体座谈会5次，开展政策解读7次，发布新闻通稿59篇。

六、畅通行政纠纷化解渠道，依法有效化解社会矛盾

（一）加强行政复议和行政诉讼工作。印发《关于进一步改进和加强行政复议行政应诉工作的通知》，坚持刀刃向内，从源头化解自然资源领域行政争议。2018年，收到行政复议申请1118件，同比减少27.6%。严格落实复议监督职责， 2018年复议纠错率达到29.8%。并废止了一批与农村土地制度改革精神不一致的文件。

（二）全面落实信访工作责任。针对重点领域、重点群体、重点问题、重点人员的信访积案深度攻坚工作取得积极成效。2018年全系统共排查积案10787件，化解9146件，化解率84.79%。积极推进视频接访与视频督查工作，在试点地区成功实现了四级视频接访。

（三）不断提升“12336”举报咨询电话服务水平。修改完善《12336举报咨询电话接听服务办法》，优化违法线索处理流程，落实举报咨询电话应急预案。开展“我是举报人，我想对你说”大讨论活动。推广应用微信举报平台。

七、创新方式开展法治宣传教育，全面提升法治能力

（一）建立部党组宪法法律学习制度。2018年9月30日，组织了第一次部党组中心组（扩大）宪法专题学习，部机关全体干部及直属单位领导班子成员近800人参加学习。

（二）建立国家工作人员宪法宣誓制度。部党组出台了《自然资源部国家工作人员宪法宣誓组织办法》（自然资党发〔2018〕8号）。9月30日，我部举行了第一次新任命干部宪法宣誓仪式，陆昊部长监誓，部党组成员全部出席，部机关新任命的492名司局级、处级干部参加了宪法宣誓。

（三）统筹安排，持续深化“七五”普法。落实“谁执法谁普法”普法责任制，向全国普法办报送部普法责任清单。组织自然资源系统“七五”普法中期检查评估，部署集中开展国家宪法日系列宣传活动；在“自然资源法治”普法微信举办法治知识竞赛，创新形式提升普法实效。
