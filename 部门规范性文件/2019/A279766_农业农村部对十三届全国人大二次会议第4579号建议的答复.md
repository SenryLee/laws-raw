# 农业农村部对十三届全国人大二次会议第4579号建议的答复

## 对十三届全国人大二次会议第4579号建议的答复

韩德洋代表：

您提出的关于明确农村集体经济组织成员认定标准的建议收悉。经商全国人大常委会法工委，现答复如下。

确认农村集体经济组织成员身份关系农民群众的切身利益，是农村集体产权制度改革的重要内容。党中央、国务院对此高度重视，2016年，出台《中共中央、国务院关于稳步推进农村集体产权制度改革的意见》，对农村集体经济组织成员身份确认作出专门部署，要求依据有关法律法规，按照尊重历史、兼顾现实、程序规范、群众认可的原则，统筹考虑户籍关系、农村土地承包关系、对集体积累的贡献等因素，探索在群众民主协商基础上确认农村集体经济组织成员的具体程序、标准和管理办法，建立健全农村集体经济组织成员登记备案机制。

近年来，农业农村部指导地方全面开展农村集体经济组织成员身份确认工作。2015年至2019年，在全国组织开展了四批农村集体产权制度改革试点，共有15个省份、89个地市、442个县整建制开展试点。各试点单位按照中央要求，在深入调查研究、反复征求干部群众意见的基础上，出台确认集体经济组织成员身份的指导意见，明确成员身份确认的基本条件、工作程序和原则。如山东省沂水县坚持成员身份唯一性原则，创设“研判建议、实名票决、沟通反馈、落空追认、多占退出”等五项机制，做到应确尽确，有效避免成员身份“两头空”和“两头占”的现象。浙江省海宁市东长社区以户籍关系为基础，采取依法认定和民主认定两种方式，有效解决了有争议群体的成员身份确认问题。目前，全国共有超过15万个村完成产权制度改革，确认成员3亿多人。通过确认成员身份，厘清了集体成员边界，集体成员与社区内其他居民之间的权利关系进一步明晰，成员的财产权利和民主权利进一步保障，得到试点地区群众的普遍认可。

正如建议中所提到的，农村集体经济组织成员身份的确认，涉及成员在获得征地补偿安置、土地承包经营权、宅基地申请和使用、参与集体资产管理和收益分配等方面的权利和义务，是对有关纠纷进行裁判的重要依据，宜采取有效措施在实务中统一裁判尺度，更好地维护农民特别是流动人口的集体成员权益。近年来，党中央就研究制定农村集体经济组织法提出明确要求，2018年修正的农村土地承包法也规定，确认农村集体经济组织成员身份的原则、程序等，由法律、法规规定；农村集体经济组织立法已列入十三届全国人大常委会立法规划，如何规范农村集体经济组织成员身份确认的原则、程序和具体办法，是立法研究的主要内容。

下一步，我们将会同有关部门，继续深入开展农村集体经济组织成员身份确认相关问题调研，总结各地试点经验，做好农村集体经济组织立法有关工作。对于您在建议中提出的有关原则，我们将在工作中认真研究和考虑。

感谢您对农业农村工作的关心，希望继续支持我部工作。
