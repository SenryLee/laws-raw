# 国家文物局关于宝山金银矿冶遗址保护规划的意见

文物保函〔2019〕339号

江西省文物局：

你局《关于呈报〈宝山金银矿冶遗址总体保护规划〉的请示》（赣文物局字〔2018〕27）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）深化价值评估，系统梳理、研究宝山金银矿冶遗址不同时期的开采、加工、冶炼、铸造等生产工艺和发展脉络，加强历史文献和专业研究成果分析，科学评价宝山金银矿在中国矿冶史上的价值和地位。

（二）开展全面探查，进一步确定文物构成，系统梳理墓葬群、居住遗址与宝山金银矿冶之间的关系，明确金窟山矿洞的时代和性质。细化现状评估，明确规划范围内交通、村庄、道路等基础设施建设状况，及其对文物本体与环境的影响，补充矿洞遗址赋存岩体评估内容。

（三）优化保护区划边界和管理规定。保护范围应明确为非建设区域，禁止采矿活动，建议将2号丘陵纳入建设控制地带；充分评估现有殡葬管理所和公墓影响，提出明确、合理的管控要求。补充保护区划范围的坐标数据。

（四）完善考古工作规划，进一步开展系统考古调查，明确古代矿山开采、原料加工、成品销售等生产链和社会组织方式等，明确重要遗迹位置、范围和性质，为后续保护展示工作提供依据。细化考古工作阶段目标、任务、工作范围和要求等。

（五）充分论证摩崖石刻防风化加固措施的必要性和风险，不宜大规模清除大型乔木。补充完善防排水措施；空气污染防治措施应以空气质量检测数据为依据。

（六）完善展示利用规划，结合最新考古研究成果，合理划定展示范围，科学确定展示措施和强度。完善基础服务设施，科学确定拟建场馆选址及规模，主出入口、停车场和管理用房不宜分置高速公路两侧；充分论证建设考古遗址公园的必要性与可行性；论证矿洞体验式开放的安全性和可行性。

（七）细化遗址保护规划与相关上位规划的衔接，明确文物部门、村委会及林场的管理责任，科学确定居民调控基数和措施，补充头亭村现状用地规模、规划发展控制规模等数据。

（八）完善图文表达，应前后一致。补充规划范围内建设现状、交通流线、考古计划、规划分期等图纸要件。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将宝山金银矿冶遗址保护规划报请江西省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好宝山金银矿冶遗址各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局
