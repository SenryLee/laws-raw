# 国家卫生健康委办公厅关于成立手术机器人临床应用管理专家委员会的通知

国卫办医函〔2019〕102号

各省、自治区、直辖市及新疆生产建设兵团卫生健康委（卫生计生委）：

为规范手术机器人临床应用，提高医疗质量，保障医疗安全，决定成立国家卫生健康委手术机器人临床应用管理专家委员会。专家委员会的主要职责包括：在国家卫生健康委领导下，组织制订手术机器人临床应用管理和技术规范，开展相关培训和技术指导，实施医疗质量控制和评价；承担国家卫生健康委交办的其他任务。我委将结合工作需要，适时对专家委员会成员进行调整。

附件：国家卫生健康委手术机器人临床应用管理专家委员会名单

国家卫生健康委办公厅

2019年1月25日
