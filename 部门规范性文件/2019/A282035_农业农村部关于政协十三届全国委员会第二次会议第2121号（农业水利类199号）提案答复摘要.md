# 农业农村部关于政协十三届全国委员会第二次会议第2121号（农业水利类199号）提案答复摘要

## 关于政协十三届全国委员会第二次会议第2121号（农业水利类199号）提案答复摘要

农办案〔2019〕121号

一、关于鼓励社会力量参与支持农民培训

我部高度重视发挥各类市场主体培训农民的重要作用，通过机制创新引导农业企业、家庭农场、农民合作社等社会资源共同推进农民培训工作。

一是积极推进校企联盟建设。联合教育部成立中国现代农业校企联盟，下设现代农业、现代畜牧业、都市农业、现代农业装备和现代渔业等5个农业职教集团，探索由农业龙头企业牵头，农业职业院校、农业大学、科研单位参与，在高技能人才培养、项目合作、基地建设、国际交流等方面开展校企合作。目前，五大农业职教集团吸纳涉农企业、职业院校、科研院所500余家，有效推动集团化办学，深化了产教融合、校企合作。二是大力引导社会资源参与。通过机制创新广泛调动社会资源参与农民培训工作，很多农业龙头企业积极履行社会责任，主动承担培训任务。如，新希望集团实施“十万绿领新农民培训计划”，先后在山东、江苏、四川、北京建立基地，在10多个省开展培训，农民增收致富；隆平高科积极开展农民教育培训和农业指导服务，实现基地基层联动、线上线下互补、育种育人一体发展；荃银高科在安徽农业大学设立“荃银班”，探索培养本科层次的青年农场主；中联重科承办了中国技能大赛—全国农业行业农机修理职业技能竞赛，覆盖基层农机维修人员5000多人，起到了以赛代训，锻炼基层农机维修人员技能的作用。农业企业参与农民教育培训，通过建设农民田间学校，提供农资、农技等服务，受到农民普遍欢迎。三是开展农民资助活动。近年来，我部组织开展了全国农业劳动模范、十佳农民、风鹏行动、农民教育培训百名优秀学员等资助奖励活动，包括新希望集团赞助的百名杰出农民评选活动，向全国推荐了一大批优秀的农民代表，发挥了很好的示范引领作用。

下一步，我部将继续健全完善工作机制，引导各类社会资源有序参与农民培训工作，促进农业职教集团发挥更大作用，挖掘更多农民典型，激发各方面积极性。

二、关于鼓励龙头企业带动农民创业

近年来，我部积极推动落实农村创新创业扶持政策，引导各地为返乡下乡各类人才到农村创新创业提供良好服务。一是推动乡村创新创业政策落实。印发了《农业农村部关于大力实施乡村就业创业促进行动的通知》，部署培育主体、打造园区、发展特色产业、推动产业融合等重点任务，督促各地落实返乡下乡人员创新创业政策，其中，支持企业发挥自身优势促进乡村就业。二是开展农民创业培训。引导各地根据乡村产业发展需求，结合“一村一品、一乡一业”、特色农产品品牌创建、农产品质量安全等重点工作和领域开展培训，全面提升乡村产业发展水平；实施现代创新创业青年培养计划，重点面向返乡创业大学生、中高职毕业生、返乡农民工和退伍军人等农业后继者开展针对性培训，强化学习职业素养、团队合作、科学发展等内容，补齐农业农村知识短板，增强创业兴业能力。三是引导农民对接市场。支持农民在产业发展、生产服务、营销促销等方面开展联合与合作，通过专业合作、资金合作、股份合作等形式发展多元化、多类型合作经济组织，开展各具特色的引领活动，搭建展示舞台和平台，引导农民与市场充分有效对接。

从2011年起，我部开展了全国“一村一品”示范村镇创建工作，截至目前，共认定全国“一村一品”示范村镇2409个，示范引导各地“一村一品”健康快速发展。一是产业特色鲜明。示范村镇紧紧依托当地资源禀赋，充分挖掘内在潜力，积极开发特色产品，形成了各具特色的主导产业，主要涵盖特色果蔬、特色经济作物、特种养殖等。二是产品品质优良。示范村镇主导产品获得无公害农产品、绿色食品或有机农产品认证的村镇达226个，100%拥有注册商标。三是市场开拓力强。有266个示范村镇成立了农民专业合作社，有243个村镇与龙头企业、专业批发市场实现了有效对接。四是带农增收效果显著。有69个村镇位于国家贫困县，西部地区许多专业村镇农民人均可支配收入都超过了1万元。

下一步，我部将继续开展全国“一村一品”示范村镇创建工作，完善政策措施，促进龙头企业在挖掘产业特色、推进产业融合、强化主体协作、帮助农民对接市场需求等方面发挥辐射带动作用。
