# 农业农村部对十三届全国人大二次会议第4187号建议的答复

## 对十三届全国人大二次会议第4187号建议的答复

农办议〔2019〕145号

沈艳芬等4名代表：

你们提出的关于将湖北恩施州重点道地药材品种补充纳入《全国道地药材生产基地建设规划（2018—2025年）》的建议收悉。经商国家药监局、国家中医药局，现答复如下。

中药材是中医药事业传承和发展的物质基础，加快道地药材基地建设，对促进特色农业发展和农民持续增收，加快发展现代中医药产业、实现乡村振兴具有重要意义。按照《中医药发展战略规划纲要（2016—2030年）》和《全国农业现代化规划（2016—2020年）》要求，2018年12月，我部会同国家中医药局、国家药监局等单位，制定印发《全国道地药材生产基地建设规划（2018—2025年）》，引导各地优化道地药材生产布局，推进中药材规模化种植和标准化生产，提高道地药材供应能力；加强质量规范管理，推进技术集成创新，推广绿色标准化生产技术模式，提升产品质量。

为推动《全国道地药材生产基地建设规划（2018—2025年）》落实，农业农村部正在会同有关部门和单位编制全国道地药材目录，在深入开展文献考证的基础上，统筹考虑中医药界熟知程度、界定清晰程度、特征明显程度等因素，深化道地药材品种、基原、产区等相关研究，稳步推进道地药材目录制定工作。目前，已将恩施州纳入藁本、党参、牡丹皮、黄连、厚朴、黄柏、杜仲、独活、重楼、大黄等中药材道地产区范围。下一步，农业农村部将会同有关部门和单位，进一步加强调查研究和科学论证，充分发挥恩施州中药材资源禀赋优势，推动中药材产业发展，助力脱贫攻坚。

感谢你们对农业农村工作的关心，希望对我部工作继续给予支持。
