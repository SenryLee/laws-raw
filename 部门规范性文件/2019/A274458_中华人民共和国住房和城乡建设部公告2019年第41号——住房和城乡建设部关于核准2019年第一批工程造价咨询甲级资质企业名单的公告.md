# 中华人民共和国住房和城乡建设部公告2019年第41号——住房和城乡建设部关于核准2019年第一批工程造价咨询甲级资质企业名单的公告

## 中华人民共和国住房和城乡建设部公告

2019年第41号

## 住房和城乡建设部关于核准2019年第一批工程造价咨询甲级资质企业名单的公告

根据《工程造价咨询企业管理办法》（建设部令第149号）的规定，我部组织对工程造价咨询企业晋升甲级资质进行了审核。现将核准的北京永拓国林工程造价咨询有限公司等86家工程造价咨询甲级资质企业名单予以公布。

特此公告。

附件：核准的工程造价咨询甲级资质企业名单

住房和城乡建设部

2019年2月19日
