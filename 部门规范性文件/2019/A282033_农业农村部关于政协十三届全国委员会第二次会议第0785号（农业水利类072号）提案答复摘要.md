# 农业农村部关于政协十三届全国委员会第二次会议第0785号（农业水利类072号）提案答复摘要

## 关于政协十三届全国委员会第二次会议第0785号（农业水利类072号）提案答复摘要

农办案〔2019〕119号

一、关于编制农民教育培训发展规划

为进一步强化农民教育培训工作指导，推动“十四五”期间农民教育培训有序开展，我部正在谋划编制《“十四五”农民教育培训发展规划》（以下简称《规划》）。《规划》将立足构建高素质农民队伍、为乡村振兴提供人才支撑，在全面总结吸收近年农民教育培训工作经验基础上，突出前瞻性、系统性、可行性，从发展形势、总体要求、主要任务、重点工程和保障措施等方面，对“十四五”期间农民教育培训工作作出系统设计。

下一步，我部将抓好《规划》编制前期工作，为加快构建高素质农民队伍和农业现代化建设人才支撑提供依据。

二、关于加强理论研究

技能培训是提升农民综合素质和生产技能的重要途径，职业教育是培养高素质农民的重要手段，具有系统性培养优势，我部十分重视，坚持技能培训和职业教育两条腿走路，培养具备现代生产技能和经营能力的复合型农业农村人才。

一是加强调查研究。我部组织调研组分赴各省开展调研，组织和参与了农民教育培养重大问题研究等一系列重点课题，形成了一批包括国家级教学成果奖在内的研究成果，为农民教育培训提供了理论参考。二是制定适合农民的职教方案。近年来，教育部会同我部组织100多名专家共同研究起草了适应现代农业产业发展、适合农民生产生活需要的职业教育方案，印发《中等职业学校新型职业农民培养方案（试行）》，通过弹性学制、半农半读、农学交替等方式培养农民学员。今年我部联合教育部印发《关于做好高职扩招培养高素质农民有关工作的通知》，明确要求培养院校要针对高素质农民学习需要，制定切实可行的人才培养方案，对其学习培训经历、职业技术技能、从业经历等，按地方或学校有关规定和程序认定为学历教育相关课程学分，推进职业培训与职业教育衔接贯通培养。三是编写发展报告。为全面系统反映全国高素质农民发展状况，自2016年开始，我部组织编写全国高素质农民发展年度报告，反映全国高素质农民发展的整体情况，充分展示农民生产经营特点，深入剖析农民发展环境、需求和趋势，为国家制定政策、开展研究提供参考，也为社会提供了一个了解农民发展状况的窗口。

下一步，我部将联合有关部门继续开展农民教育培训工作，加大研究力度，丰富完善理论体系，力争教育培训工作取得实效。

三、关于加大资金投入

党的十八大以来，中央财政累计安排资金90.9亿元支持农民教育培训工作。在中央财政带动下，各部门加大资金和政策支持力度，每年配套投入资金在5亿元左右，在教育培训、条件能力、跟踪服务等方面支持农民全面发展。

关于加强农村公共文化设施建设，“十一五”期间，原文化部和国家发展改革委联合制定并实施了《全国“十一五”乡镇综合文化站建设规划》，投入39.48亿元补助全国2.67万个乡镇综合文化站建设项目，在全国范围内实现“乡乡有文化站”的建设目标。2015年以来，原文化部会同中央宣传部等相关部门，相继实施了“贫困地区百县万村综合文化服务中心示范工程”和“贫困地区民族自治县、边境县村综合文化服务中心覆盖工程”，加大对贫困地区村文化活动室建设支持力度，共为贫困地区建设了约3.2万个村文化活动室。2016年以来，实施贫困地区村文化活动室设备购置项目，分5年为贫困地区的839个县已建成的村文化活动室购置设备，以保障其文化活动的正常开展。

下一步，我部将继续联合有关部门加大投入力度，完善农民扶持政策，夯实教育培训基础条件，不断提升农民教育培训保障能力；支持和引导地方落实城乡统一、重在农村的义务教育经费保障机制，推动农村义务教育均衡发展；完善基层公共文化设施设备，着力提升公共文化服务效能。

四、关于重视内容创新

我部会同有关部门通过构建学习平台，开发农民职业教育方案，发挥基层党组织作用等措施，促进农民知识能力有效提升。

一是丰富农村优质公共文化产品供给。2018年，全国艺术表演团体赴农村演出178.82万场，农村观众达7.79亿人次。2018年开展“戏曲进乡村”活动，为国家级贫困地区12984个乡镇配送7094场地方戏为主的文艺演出。举办面向城乡基层的全国广场舞展演活动，参演群众209.4万人，吸引超过4206万人次观看。在重大示范性文化活动带动下，乡村基层群众文化活动蓬勃发展，涌现出一批文化活动品牌。

二是构建农民学习平台。我部注重运用现代远程教育手段多形式、多层次、多渠道开展农民教育培训，面向全国提供广播、电视、网络等学习资源。加强“全国农业科教云平台”推广应用，组织发动各类专家、农技推广人员和广大农民下载使用云平台，鼓励农业专家、农技推广人员、培训机构、培训教师利用云平台开展指导服务，探索线上线下融合培训模式，组织农民在线学习。文化和旅游部建设国家公共文化云和国家数字化文化网平台，提供框架完善、内容丰富、种类多样的公共数字文化资源，促进农村基层地区艺术普及和繁荣发展。

三是开发适合农民特点的职业教育方案。近年来，我部会同教育部，依托全国农业职业教育教学指导委员会，组织全国各地职业院校、教育部职业技术教育中心研究所以及各级农业广播电视学校等总计20多所有关院校以及相关研究机构的100多名专家共同研究起草了适应现代农业产业发展、适合职业农民生产生活需要的农民职业教育方案，目前已在多个省份推动方案落实落地。

下一步，我部将会同有关部门完善政策措施，加强高质量公共文化产品供给，健全农民教育培训知识能力体系，培养现代高素质农民队伍。
