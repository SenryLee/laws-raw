# 国家铁路局关于发布铁道行业技术标准复审结果的公告

国铁科法〔2019〕36号

为加强铁道行业技术标准管理，国家铁路局组织对现行有效的1064项铁道行业技术标准进行了复审，现将复审结果予以公布。

一、保留作为铁路行业管理的铁道行业技术标准共970项（见附件1）。

二、不再作为铁路行业管理或已无存在必要的94项标准，确定为“废止”（见附件2）。

附件：1.现行有效的铁道行业技术标准目录

2.废止的铁道行业技术标准目录

国家铁路局

2019年9月16日
