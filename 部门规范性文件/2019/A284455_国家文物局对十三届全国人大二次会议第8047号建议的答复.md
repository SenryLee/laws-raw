# 国家文物局对十三届全国人大二次会议第8047号建议的答复

文物保函〔2019〕577号

郭建增代表：

您提出的“关于支持大名府故城国家考古遗址公园申报立项的建议”收悉，现答复如下：

大名府故城是北宋时期的陪都，为研究宋代历史、城市发展史提供了重要的实物资料，2006年被国务院公布为全国重点文物保护单位。国家文物局重视大名府故城的考古研究与文物保护工作。“十二五”以来，已批复《大名府故城保护规划（2013—2030）》和相关考古调查、发掘项目，为推进大名府故城文物保护利用工作奠定了良好的基础。

您提出的支持大名府故城国家考古遗址公园申报立项、加大资金安排和考古计划审批等方面的建议非常重要。国家文物局将积极支持河北省、邯郸市人民政府开展大名府故城考古研究与保护利用工作，指导河北省文物局、地方人民政府重点推进以下几个方面的工作：

第一，组织考古专业机构根据大名府故城的保存现状和工作条件，进一步明确工作目标、技术路线、实施步骤、预期成果，科学编制考古工作计划，有序开展大名府故城的考古调查、勘探、发掘与研究工作，为遗址的保护、利用等后续工作创造条件。

第二，督促地方人民政府认真落实《大名府故城保护规划（2013—2030）》，切实履行文物保护的主体责任，进一步明确保护区划和管理规定，加大机构建设和日常管理、巡护力度，确保文物安全。

第三，指导地方人民政府根据《国家考古遗址公园管理办法（试行）》，针对大名府故城的区位条件、资源禀赋与地方经济社会发展状况，科学论证建设国家考古遗址公园的必要性和可行性，明确投资渠道、运营方式和保证措施，避免盲目建设。

感谢您对文物事业的关心和支持。

国家文物局

2019年6月21日
