# 国家文物局关于在襄阳城墙保护范围内进行护城河清淤工程建设项目的意见

文物保函〔2019〕454号

湖北省文化和旅游厅：

你厅《关于呈报襄阳城墙护城河清淤工程实施方案的请示》（鄂文旅文〔2019〕31号）收悉。经研究，我局原则同意在襄阳城墙保护范围内进行护城河清淤工程建设项目。

一、所报方案尚需作以下必要的修改和完善

（一）补充历年清淤工程资料，在总结历次河道清淤经验、教训的基础上优化本次工程设计。补充说明拟实施的河道拓宽工程与本次清淤河道的关系。

（二）进一步核实河道淤泥厚度，严格控制河道清淤范围。应以清除现有淤泥为主，不宜改变岸基形态，不得为船只航行而深挖河道。

（三）严格控制河道清淤放坡，并明确对护城河挡墙、堤岸及河床底部的保护措施；补充施工监测方案和应急预案，确保文物和人员安全。

（四）补充开展必要的考古工作，核实水下是否存在重要考古遗存。

（五）进一步论证滚水坝、桥涵拆除、泄洪闸改造项目的相关设计，补充详细实施方案。完善拆除工程对河岸的影响评估和减缓措施说明；木栈桥设计应尽可能简洁、朴实，最大限度弱化其体量感。

二、请你厅指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你厅会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月16日
