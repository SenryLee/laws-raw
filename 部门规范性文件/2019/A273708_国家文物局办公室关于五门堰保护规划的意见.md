# 国家文物局办公室关于五门堰保护规划的意见

办保函〔2019〕23号

陕西省文物局：

你局《关于呈报五门堰保护规划的请示》（陕文物字〔2018〕47号）收悉。经研究，我局暂不同意所报规划。

一、所报规划应作以下必要修改和完善：

（一）进一步厘清文物构成，明晰文物分类标准。合理确定文物本体与附属文物、不可移动文物与可移动文物，并列出具体清单。

（二）完善现状评估。补充新堰坝的价值和现状评估；补充文物本体完整性、现行保护区划、建筑环境等评估内容。

（三）进一步明确保护区划调整依据，补充分析将桔园镇建成区以东的区域纳入建设控制地带的必要性和可行性。加强保护区划管理规定的针对性，明确禁建区和限建区，补充建筑高度、体量、色彩、密度、适建项目等控制要求。同时注意加强对历史景观风貌的整体控制要求。

（四）细化、完善环境规划。明确对规划范围内建筑风貌的整治措施，补充具体数据指标；明确环境景观控制要求，细化对历史农耕景观的风貌要求，避免现代园林化倾向。

（五）进一步加强保护措施的针对性。明确各保护对象的保护工程性质、内容和目标，慎重论证“恢复特定时代的彩妆”、“重新油饰彩绘”等措施的必要性；补充说明实施减震、防震措施的必要性。

（六）应完善相关专项规划。补充与相关规划的衔接内容，缩小或取消龙门寺旁的商业服务业设施用地，细化管理规定，避免商业化倾向；优化展示规划，梳理展示分区，突出展示主题，核实相关服务设施指标，明确各区环境容量；深化、完善管理规划； 完善管理规划，明确文物、水利等各方在文物保护管理方面的责任。

（七）进一步校核文字，规范图纸表达。

二、请你局指导有关单位根据上述意见对规划进行修改完善，按程序另行报批。

专此函复。

国家文物局办公室

2019年1月14日
