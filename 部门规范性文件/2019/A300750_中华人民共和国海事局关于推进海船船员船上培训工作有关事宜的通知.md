# 中华人民共和国海事局关于推进海船船员船上培训工作有关事宜的通知

海船员函〔2019〕429号

各直属海事局：

为做好将于2019年6月1起施行的《中华人民共和国船员培训管理规则》（交通运输部令2019年第5号）的宣贯工作，推进《中华人民共和国海船船员船上培训管理办法》（海船员〔2018〕545号）的有效实施，解决船员反映的“船上见习难”等问题，现将有关事宜通知如下：

一、进一步加强相关规定的宣贯工作。各单位应当尽快组织辖区航运公司和海员外派机构，对《中华人民共和国船员培训管理规则》《中华人民共和国海船船员船上培训管理办法》内容进行集中宣贯和解读。要对开展船上培训的积极意义进行宣传，使航运公司和海员外派机构进一步了解应当承担的责任和管理要求。

二、进一步做好开展船上培训的指导和服务工作。各单位要进一步提高主动服务意识，鼓励辖区航运公司和海员外派机构积极开展船上培训工作，认真指导和协助其在船员管理系统维护相关信息，并采取有效措施方便开展船上培训的航运公司、外派机构报送有关信息，尽快实现船员船上见习信息的网上报送，方便船员上船见习。

三、加强对相关人员的业务培训工作，建立相关管理制度和工作台账，不得以未报送船上见习信息为由妨碍船员按规定正常上船任职。

四、2020年1月20日前，在中国籍沿海航行船舶上见习的船员，因航运公司未按照《中华人民共和国海船船员船上培训管理办法》第九条的要求报送相关信息，导致其在船员管理信息系统中无船上见习信息的，船员可凭船上见习记录簿和其他相关材料，向负责其船上见习的航运公司所在辖区海事管理机构申请办理相应船员适任证书。

前款中船上见习记录簿须经负责其船上见习的航运公司出具鉴定意见。如其船上见习由2家以上航运公司负责完成的，船员应到最后负责完成其见习的航运公司所在辖区海事管理机构申请办理相应船员适任证书。

五、对于仅开展沿海三等船员船上见习的航运公司，持沿海三等船长、轮机长证书者可视为管理级船员担任公司培训师，公司培训师的其他管理要求不变。

请各单位于4月30日前将推进船上培训开展工作情况报部海事局。
