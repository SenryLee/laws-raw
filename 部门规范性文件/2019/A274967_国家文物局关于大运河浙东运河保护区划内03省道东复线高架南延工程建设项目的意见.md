# 国家文物局关于大运河浙东运河保护区划内03省道东复线高架南延工程建设项目的意见

办保函〔2019〕237号

浙江省文物局：

你局《关于上报全国重点文物保护单位大运河之浙东运河（萧山段）保护区划内实施03省道东复线高架南延工程的请示》（浙文物发〔2018〕309号）收悉。经研究，我局原则同意在大运河之浙东运河（萧山段）保护范围和建设控制地带内实施03省道东复线高架南延工程建设项目。

一、方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建项目区域进行考古调查勘探和必要的考古发掘，明确地下遗存分布情况；同时开展河道调查，摸清历史河堤、水工设施等相关遗迹保存现状。如遇重要发现，应及时依法上报并调整项目建设方案。

（二）应进一步优化拟建桥梁设计方案，桥墩不得直接占压经考古调查、勘探和发掘后确认的重要遗址、遗迹。补充桥梁外观设计，在满足基本功能需求的前提下，尽可能简化桥梁外观造型，降低桥梁对运河环境景观的视觉冲击。

（三）应在相关地形图上明确标示给水管改迁工程位置与大运河保护范围和建设控制地带的空间关系，并对照相关管理规定作出符合性说明。

（四）应细化施工及运营期间的文物保护措施，重点关注各类振动、沉降等对大运河文化遗产及其水质等生态环境的影响，补充监测措施及相关的应急预案。细化施工过程中生态环境、景观风貌等保护要求以及粉尘及废弃物等污染物处置要求，避免污染水体及运河周边环境。

（五）细化施工后期的场地清理和周边环境修复工作，适当设立大运河标识及必要的展示、阐释设施。做好工程完工后大运河及周边区域的生态环境、景观风貌变化情况记录，并将相应数据、资料等提交相关大运河遗产监测系统平台存档。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月5日
