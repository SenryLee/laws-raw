# 审计署关于政协十三届全国委员会第二次会议第1399号（财税金融类109号）提案答复的函

## 关于政协十三届全国委员会第二次会议第1399号（财税金融类109号）提案答复的函

审函〔2019〕61号

石文先委员：

您提出的《关于建立涉农财政资金项目全过程审计监督机制的提案》，现答复如下：

您反映的投放渠道多、违规使用突出、项目立项不科学、过程监管不力等问题，的确是涉农财政资金管理使用中存在的突出问题，我们在历年涉农、扶贫审计项目中积极关注，多次在审计报告中反映。您针对问题提出的合理化建议对提高涉农财政资金的管理水平很有帮助，相关部门已经或正在采取措施，积极推进。

农业农村农民问题是关系国计民生的根本性问题。党的十八大以来，以习近平同志为核心的党中央坚持把解决好"三农"问题作为全党工作重中之重，持续加大涉农财政资金投入和强农惠农政策力度，夯实农业农村基础设施，改善群众生产生活条件，加快推进农村经济和社会事业发展。审计署作为党和国家监督体系的重要组成部分，紧紧围绕党中央、国务院关于打赢脱贫攻坚战、实施乡村振兴战略的重大决策部署，认真贯彻落实习近平总书记关于加大对党中央重大政策措施贯彻落实情况跟踪审计力度，加大对经济社会运行中各类风险隐患揭示力度，加大对重点民生资金和项目审计力度的重要指示，持续开展扶贫审计和乡村振兴审计，不断加大审计力度，深入揭示影响政策落实、危害涉农资金安全、侵害群众利益的违法违规问题。针对问题，审计署通过审计报告、信息等向党中央、国务院提出完善相关体制机制的意见建议，加大审计结果公告力度，督促相关部门和单位整改落实，推动脱贫攻坚、乡村振兴相关政策落实落地，提高资金安全绩效，维护农民群众切身利益。尤其是针对扶贫和涉农资金投入渠道分散、缺乏统筹造成基层安排使用"碎片化"的问题，我们向党中央、国务院提出加强涉农资金统筹整合的意见建议。2015年国务院办公厅下发《关于支持贫困县开展统筹整合使用财政涉农资金试点的意见》，2017年国务院印发《关于探索建立涉农资金统筹整合长效机制的意见》，为打赢脱贫攻坚战、实施乡村振兴战略提供有力的投入保障。审计署在持续加大对扶贫和涉农领域群众身边腐败和作风问题查处力度的同时，加大对资金统筹整合使用相关政策措施落实情况的审计监督力度，对干扰统筹整合使用资金，继续以"打酱油的钱不能买醋"、"专款专用"等为借口，造成资金长期趴在账上难以发挥效果的问题，坚决查处、坚决曝光，促进各级各部门在资金统筹整合使用中积极作为、有效作为，促进国务院决策部署落地生根和不断完善。

据审计和日常工作了解，近年来，财政部等相关主管部门已经或正在制定完善相关政策，积极推进注册会计师审计制度，不断强化涉农财政资金绩效考评制度，在加强资金监管、提升绩效方面建立健全长效机制。

一是完善相关涉农资金绩效评价制度，建立健全绩效评价办法。按照中共中央、国务院《关于全面实施预算绩效管理的意见》，积极推进构建"预算编制有目标、预算执行有监控、预算完成有评价、评价结果有反馈、反馈结果有应用"的全过程预算绩效管理机制。在绩效评价指标设计上，将资金分配、社会效益、经济效益等相关因素纳入考核内容。充分发挥绩效评价"指挥棒"作用，对于评价结果不佳的项目，酌情取消或减少资金安排，督促地方提升资金使用效益。

二是不断完善注册会计师审计制度。财政等部门出台了《政府购买服务管理（暂行）》（财综〔2014〕96号），将"会计审计服务"列入适宜由社会力量承担的服务事项，并对购买方式及程序、资金来源及管理等作出了规范，为注册会计师通过市场化方式进行涉农财政资金审计服务提供了制度保障，营造了注册会计师在涉农资金审计上能参与、可监督的良好环境，保证其能充分发挥审计方面的专业性，助力涉农财政资金运行安全。

三是促进形成权责明确、有效制衡、齐抓共管的涉农资金监督格局。目前，相关涉农资金实现了每项资金都有对应的管理办法，明确涉农资金支出执行国库集中支付制度。持续强化涉农资金事前、事中、事后监管，不断提高预算编制的科学性和规范性，采取有效措施加快预算执行进度，对挪用、截留、滞留等违规行为进行严肃处理，加强追责问责，保障财政资金用在刀刃上。如为全面加强扶贫资金管理，探索建立了扶贫资金动态监控平台，实现各级各类扶贫资金全过程实时监控，促进涉农资金安全、高效使用。同时，大力推进信息公开，对涉农资金的资金规模、扶持范围、分配结果等，通过网络、媒体等进行公开，接受群众和社会监督。督促各地健全公告公示制度，明确不同层级公告公示的具体内容、时间要求和工作程序等，让涉农资金在阳光下运行。

下一步，审计署将在扶贫、乡村振兴审计中持续关注涉农财政资金管理使用情况，推动完善机制体制，堵塞管理漏洞，提高资金使用绩效，促进政策措施落实落地。

再次感谢您对审计工作的关心和支持！

审计署

2019年7月26日
