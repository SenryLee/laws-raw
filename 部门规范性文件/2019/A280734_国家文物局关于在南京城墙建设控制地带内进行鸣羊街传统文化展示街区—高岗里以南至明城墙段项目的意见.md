# 国家文物局关于在南京城墙建设控制地带内进行鸣羊街传统文化展示街区—高岗里以南至明城墙段项目的意见

文物保函〔2019〕798号

江苏省文物局：

你局《关于审批南京城墙保护区划内秦淮区鸣羊街传统文化展示街区项目—高岗里以南至明城墙段设计方案（修改稿）》（苏文物保〔2019〕145号）收悉。经研究，我局原则同意在南京城墙建设控制地带内进行鸣羊街传统文化展示街区项目-高岗里以南至明城墙段项目。

一、所报方案尚需作以下必要的修改和完善：

（一）深化鸣羊街历史街区肌理和格局风貌研究，进一步优化方案总体平面布局和建筑立面设计，使新建项目与当地传统民居风格和整体环境相协调。

（二）降低高岗里39号文物建筑旁新建建筑N1组建筑的高度，其高度不得超过39号文物建筑的高度。补充说明亭廊设计的依据。

（三）充分考虑施工对南京城墙及其他文物的影响，制定必要的文物保护措施、监测方案和应急预案，控制粉尘及施工垃圾等对文物本体及环境的污染。

（四）进一步校核设计说明和图纸，建筑总平面图及相关标注数据前后应一致。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年8月8日
