# 生态环境部办公厅关于解除贵州省打击固体废物环境违法行为专项行动中挂牌督办问题的通知

## 关于解除贵州省打击固体废物环境违法行为专项行动中挂牌督办问题的通知

环办执法函〔2019〕902号

贵州省生态环境厅：

按照《关于对打击固体废物环境违法行为专项行动中发现的突出问题挂牌督办的通知》（环办环监〔2018〕11号）要求，你厅督促相关地方及企业按照限期整治、溯源调查、依法查处、严肃问责四项标准要求进行整改，使贵州省务川县大坪街道废弃冶炼汞矿废渣堆存问题的整治基本达到督办要求，并向我部提交了解除挂牌督办的申请。

经现场核查，我部决定对上述问题解除挂牌督办。请你厅继续督促遵义市及务川县人民政府进一步落实生态环境保护职责，巩固整改成果，督促企业落实环境保护主体责任；同时举一反三，持续推进固体废物监管工作，并加大环境执法力度，严厉打击涉固体废物环境违法行为，积极防范环境风险，促进环境质量持续改善。

生态环境部办公厅

2019年12月5日
