# 农业农村部对十三届全国人大二次会议第6868号建议的答复

## 对十三届全国人大二次会议第6868号建议的答复

农办议〔2019〕193号

姜成英等3名代表：

你们提出的关于将优势特色经济林纳入现代农业产业技术体系的建议收悉。经商林草局、财政部，现答复如下。

经济林具有生态和经济双重属性，对维护国家粮油安全，实现林农脱贫致富、乡村振兴和全面建成小康社会意义重大，近年来，国家对优势特色经济林高度重视，不断加大研发投入，多措并举推动发展。

根据《国家林业和草原局职能配置、内设机构和人员编制规定》，林业科技工作是林草局主要职责之一。林业局、发展改革委、财政部联合制定的《全国优势特色经济林发展布局规划（2013—2020年）》，对涉及木本油料、木本粮油、特色鲜果、木本药材和木本调料的30多个优势特色经济林树种进行了科学布局，大大促进了经济林产业的发展。

2018年中央财政通过农业生产发展资金安排63.19亿元，支持优势特色主导产业发展。围绕具有区域优势、地方特色等条件的农业主导产业，聚焦发展中的瓶颈问题和薄弱环节，着力发展优势特色主导产业带和重点生产区域，通过标准化绿色化生产、全程化质量监管、全产业链经营、产业融合发展，做大做优做强优势特色产业，培育打造一批有影响力的区域公用品牌、产品品牌，示范引导走产出高效、产品安全、资源节约、环境友好的农业现代化道路。甘肃省可充分利用上述资金，支持经济林等优势特色产业发展，发挥生态效益和经济效益，助力贫困地区脱贫攻坚。

下一步，中央财政将根据党中央、国务院关于实施乡村振兴战略的总体部署，进一步统筹整合资源，支持各地优势特色产业发展，持续加强产业科技创新研究与试验推广，推动经济林产业提质增效，充分发挥经济林的增产增效潜力，更好地服务于脱贫攻坚和乡村振兴战略。我部将重点开展两项工作，一是与甘肃省农业农村厅沟通，推动将油橄榄等特色经济林树种纳入现代农业产业技术体系甘肃省地方创新团队建设。二是策划将油橄榄等特色经济林树种纳入现代农业产业技术体系"十四五"建设规划，并向财政部提出支持建议。

感谢你们对农业农村工作的关心，希望今后继续对我部工作予以支持。
