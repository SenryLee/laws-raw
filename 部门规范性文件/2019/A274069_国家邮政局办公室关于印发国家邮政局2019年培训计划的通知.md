# 国家邮政局办公室关于印发国家邮政局2019年培训计划的通知

国邮办发〔2019〕5号

机关各司室：

国家邮政局2019年培训计划已经2019年第1次局长办公会议审议通过，现予印发，请按照如下要求认真贯彻执行。

一要严格培训计划执行执行。各司室要认真学习和贯彻落实《干部教育培训工作条例》《2018-2022年全国干部教育培训规划》《中央和国家机关培训费管理办法》等文件精神，严格培训计划执行，不得随意变更培训内容、地点和对象，不得大幅度减少或增加参训人员，不得随意缩短或延长培训时间，力戒前松后紧和年底集中办班。

二要切实提高培训质量。严格培训班管理。各司室要精心设计培训课程，培训通知印发前送人事司会签，精品课程需留存视频资料。要要按照谁办班、谁负责的原则，严格培训纪律，切实加强学员管理，改进干部学风，注重考核学习效果。培训结束后，要在20个工作日内完成结算，及时向人事司报送培训课件、培训手册、培训考核情况等培训材料。同时，人事司要做好培训归口管理，根据需要组织开展培训质量评估。

三要提高培训质量。各司室要优选培训机构，原则上应选择党校（行政学院）、干部学院及干部教育培训管理部门认可的培训机构承办，其中党性教育培训班，必须选择党性教育基地目录内的培训机构承办。同时人事司要做好培训归口管理，根据需要组织开展培训质量评估。

附件：国家邮政局2019年培训计划

国家邮政局办公室

2019年1月30日
