# 国家核安全局关于印发《民用核安全设备焊工焊接操作工技能评定》的通知

## 关于印发《民用核安全设备焊工焊接操作工技能评定》的通知

国核安发〔2019〕267号

各相关单位：

为指导民用核安全设备制造、安装单位和民用核设施营运单位自行开展民用核安全设备焊工焊接操作工的技能评定工作，现批准《民用核安全设备焊工焊接操作工技能评定》为核与辐射安全法规技术文件，并予公布。
