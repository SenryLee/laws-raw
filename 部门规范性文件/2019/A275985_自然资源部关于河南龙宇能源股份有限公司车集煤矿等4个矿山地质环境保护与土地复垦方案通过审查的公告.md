# 自然资源部关于河南龙宇能源股份有限公司车集煤矿等4个矿山地质环境保护与土地复垦方案通过审查的公告

根据《土地复垦条例》《矿山地质环境保护规定》等有关规定，河南龙宇能源股份有限公司车集煤矿等4个矿山地质环境保护与土地复垦方案通过审查，现予公告。

2019年4月8日

附件：4个通过审查的矿山地质环境保护与土地复垦方案名单
