# 自然资源部公告2019年第17号——2019年第一批地质灾害防治单位甲级资质审批公告

## 自然资源部公告

2019年第17号

## 2019年第一批地质灾害防治单位甲级资质审批公告

根据《地质灾害防治条例》（国务院令第394号）和《地质灾害危险性评估单位资质管理办法》（国土资源部令第29号）、《地质灾害治理工程勘查设计施工单位资质管理办法》（国土资源部令第30号）、《地质灾害治理工程监理单位资质管理办法》（国土资源部令第31号）、《国土资源部关于修改〈地质灾害危险性评估单位资质管理办法〉等5部规章的决定》（国土资源部令第62号）的规定，经审查，共有159个地质灾害防治单位甲级资质新设申请和94个地质灾害防治单位甲级资质延续申请予以通过，现予公告。

请资质申请予以通过的单位从即日起到自然资源部政务大厅办理领证事宜。领取新资质证书，请携带领取人身份证原件和复印件、单位介绍信（委托书）、乙级资质证书原件（新设）、原甲级资质证书原件（延续）。

联系单位及电话：

自然资源部政务大厅 010-66558739

2019年4月12日

附件：

1. 地质灾害防治单位甲级资质新设申请予以通过名单

2. 地质灾害防治单位甲级资质延续申请予以通过名单
