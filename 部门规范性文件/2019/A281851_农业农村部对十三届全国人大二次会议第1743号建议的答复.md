# 农业农村部对十三届全国人大二次会议第1743号建议的答复

## 对十三届全国人大二次会议第1743号建议的答复

农办议〔2019〕361号

孙建博代表：

您提出的关于防范外来物种入侵立法的建议收悉。经商林草局、生态环境部，现答复如下。

一、外来入侵物种防控工作进展

目前，在全国层面尚缺乏一部专门用于外来物种管理的法律法规。作为外来物种牵头管理部门，我部高度重视，积极推动相关立法工作。早在2010年，已组织开展立法研究，梳理我国现有涉及外来物种管理的法律法规与政策措施，分析总结欧盟、美国、日本、澳大利亚等国家和地区防范外来物种入侵的法律政策。指导湖南省发布了《湖南省外来物种管理条例》，成为全国第一部专门用于外来物种管理的地方性法规，为制定国家外来物种管理法律法规提供了有益的借鉴经验。2016年以来，会同有关部门研究起草《外来物种管理条例》，拟对外来物种引入风险评估、监测预警等作出规定。目前，全国人大已启动生物安全立法工作，我部作为相关职能部门，积极推动将外来入侵物种管理纳入范畴。

此外，我部会同有关部门，推进外来物种管理制度建设，加强调查监测与综合防控，相关工作取得了积极进展。

一是推进管理机制建设。我部先后成立了"农业部外来入侵生物管理办公室""农业部外来入侵生物预防与控制研究中心",加强外来入侵生物防治工作日常管理与技术研究。2004年，会同环保、质检、林业、海洋等8部门成立了全国外来入侵生物防治协作组。制定了《农业重大有害生物及外来生物入侵突发事件应急预案》，成立外来生物入侵突发事件应急指挥部，发布了《国家重点管理外来入侵物种名录（第一批）》，针对长芒苋、刺萼龙葵、红火蚁等40余种重大入侵物种制定了专项应急防控预案和处置技术清单，初步建立了外来物种入侵应急处理机制。2011年，环境保护部牵头制定《中国生物多样性保护战略与行动计划（2011—2030年）》，将加强外来入侵物种管理作为优先领域，并将提高外来入侵物种早期预警、应急与监测能力作为优先行动之一。

二是推进调查监测。我部连续多年组织开展国家重点管理和区域性重大危害入侵物种调查，搜集掌握物种国内外分布、主要危害、传入途径、鉴别特征等信息，初步构建了"中国外来入侵物种数据库".在河北、辽宁、湖南、云南等地布设固定监测点位，对黄顶菊、豚草、薇甘菊等入侵物种开展监测。2013年起对南方11省（区、市）20处重点水域水葫芦、水花生、大薸实施遥感监测，定期发布监测结果，指导地方开展清除工作。2018年，在前期试点基础上，林草局在全国以省区市为单位开展林业外来物种调查与研究项目，力争用三年时间对全国林业外来物种进行摸底。生态环境部重点开展了国家级自然保护区外来入侵物种调查，初步掌握了我国国家级自然保护区外来入侵物种的本底数据。

三是推进综合防控与集中灭除。我部在江苏、湖北、湖南、广西等地建设水花生、水葫芦、豚草等入侵物种天敌繁育基地30余处，利用豚草卷蛾、莲草直胸跳甲等天敌开展生物防控。在内蒙古、贵州等地探索开展刺萼龙葵、紫茎泽兰生态控制，利用本地有益物种进行竞争替代，修复受损生态系统的抵御功能。针对扩散蔓延严重、已暴发成灾的外来入侵物种，2003年起，按照"广泛发动、防除并举、突出重点、注重实效"的方针，组织开展集中灭除活动，初步统计全国已开展各类灭除活动2000余次，灭除面积超过3000多万亩次。

二、下一步工作

下一步，我部将充分考虑您的建议，配合全国人大加快制定生物安全法，明确外来入侵物种防控要求，强化外来入侵物种管理法律依据，同时，会同有关部门，继续完善外来入侵物种管理政策制度，开展重点区域与物种调查监测，推进外来入侵物种综合防控，切实提升外来入侵物种防控水平。

感谢您对外来入侵物种防控工作的关心，希望继续对我部工作给予支持。
