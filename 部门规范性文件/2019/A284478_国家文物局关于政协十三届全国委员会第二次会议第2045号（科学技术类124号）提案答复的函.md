# 国家文物局关于政协十三届全国委员会第二次会议第2045号（科学技术类124号）提案答复的函

文物博函〔2019〕808号

潘路委员：

您提出的“关于建立文物领域国家科技创新基地，从文物大国向文物保护创新研究强国迈进的提案”已交由我局会同科技部办理。现答复如下：

“十一五”以来，在国家科技支撑计划的支持下，文物领域科技快速发展，一批优秀的文物科研人才和团队脱颖而出，科研机构不断壮大。但是，与文物事业的发展需求相比，我国的文物保护学科体系还有待完善，文物“材料科学”、文物“病理”、文物安全风险等方面的基础研究有待推进，科技创新体系有待进一步加强。

您在提案中提出的关于将文物保护利用科技纳入国家科技发展规划范畴的建议，以及将文物保护相关科学技术研究纳入国家重点实验室和国家技术创新中心的体系布局当中的建议，对于推动我国文物科技进步、支撑和引领文物事业发展至关重要。目前，科技部在2035科技战略研究工作部署中，已统一安排开展相关工作。国家文物局予以积极配合，正在抓紧组织开展面向2035年的文物科技中长期发展战略研究。在国家科技创新基地建设方面，国家文物局将进一步加强与科技部的沟通，以国家文物局重点科研基地为基础，培育并积极向科技部推荐建设文物领域的国家重点实验室和国家技术创新中心。

感谢您对文物博物馆事业的关心与支持。

国家文物局

2019年7月24日
