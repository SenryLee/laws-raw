# 国家文物局关于元上都遗址保护区划内游客接待中心建设项目的意见

文物保函〔2019〕275号

内蒙古自治区文物局：

你局《关于元上都遗址游客接待中心建筑设计方案的请示》（内文物字〔2019〕2号）收悉。经研究，我局原则同意在元上都遗址建设控制带内实施游客接待中心建设项目。

一、方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对项目选址区域做全面的考古调查勘探和必要的考古发掘，明确地下文物遗存分布情况。如有重要文物遗存发现，须对项目选址及方案进行调整，充分避让。

（二）应严格按照保护区划管理规定，降低拟建建筑高度至6米以下，并在科学测算游客容量，充分利用现有展示、服务和管理设施基础上，进一步压缩生态停车场、游客广场的面积。

（三）应简化建筑外观设计，取消仿岩石造型，外立面宜采用本地石材，其质感、色彩等应与遗址及周边环境相协调，并可辅之以建筑外部绿化，以减少项目对元上都遗址环境景观的影响。

（四）应强化项目所在区域的绿化设计，并注意选用当地传统植被，尽量保持原有自然生态景观风貌，避免园林化设计倾向。停车场、广场等应采用生态设计手法，严控硬化地面面积。

（五）应补充项目施工过程监管措施，明确施工过程中场地布置、施工组织、生态保护、景观控制等要求和污染物处置措施，完善监测措施和应急预案，避免工程建设对元上都遗址及周边环境造成不良影响。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续，并按照《实施〈世界遗产公约〉的操作指南》第172条的规定将所报项目方案及遗产影响评估报告英文版通过联合国教科文组织世界遗产中心报世界遗产委员会备案后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年3月19日
