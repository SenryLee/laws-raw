# 教育部关于发布《基础教育装备分类与代码》等22项教育行业标准的通知

教基函〔2019〕4号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

经全国教育装备标准化技术委员会审查通过，现发布以下22项教育行业标准：

JY/T 0595-2019　基础教育装备分类与代码

JY/T 0042-2019　教学用热敏温度计

JY/T 0044-2019　碰撞实验器

JY/T 0053-2019　透明塑料水槽

JY/T 0060-2019　计数器

JY/T 0061-2019　钟表模型

JY/T 0106-2019　帕斯卡球

JY/T 0130-2019　计数棒（棍）

JY/T 0221-2019　离心机械模型

JY/T 0226-2019　固体缩力演示器

JY/T 0229-2019　液体对器壁压强演示器

JY/T 0231-2019　量热器

JY/T 0308-2019　小学几何形体模型

JY/T 0344-2019　钉板及附件

JY/T 0509.1-2019　教学用尺第1部分：演示用直尺

JY/T 0509.2-2019　教学用尺第2部分：直尺

JY/T 0512-2019　运动和力实验器

JY/T 0515-2019　活塞式抽水机模型

JY/T 0516-2019　水轮机模型通用技术条件

JY/T 0518-2019　爆燃器

JY/T 0519-2019　毛细现象实验器

JY/T 0593-2019　中小学膜处理饮水设备技术要求和配备规范

以上标准自2019年9月1日起实施。
