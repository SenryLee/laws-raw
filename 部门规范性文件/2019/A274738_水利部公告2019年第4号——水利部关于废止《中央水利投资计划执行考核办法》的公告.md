# 水利部公告2019年第4号——水利部关于废止《中央水利投资计划执行考核办法》的公告

## 水利部公告

2019年第4号

## 水利部关于废止《中央水利投资计划执行考核办法》的公告

为贯彻落实党中央、国务院关于推进依法行政、建设法治政府的部署和要求，按照《中共中央办公厅关于统筹规范督查检查考核工作的通知》要求，我部决定不再开展中央水利投资计划执行考核工作，并废止《中央水利投资计划执行考核办法》（水规计[2017]402号）。对于年度中央水利投资计划执行，我部将进一步完善调度会商机制，指导督促各地做好相关工作。

特此公告。

水利部

2019年3月5日
