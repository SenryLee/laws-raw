# 农业农村部对十三届全国人大二次会议第5492号建议的答复

## 对十三届全国人大二次会议第5492号建议的答复

农办议〔2019〕311号

您提出的关于重农固本多措并举下大力解决农村土地荒芜问题的建议收悉。经商财政部，现答复如下。

一、关于加强基础设施建设、增强农业抗风险能力

机构改革以来，我部切实履行农田建设管理职责，稳步推进建设任务落实，加快完善农田建设统一管理机制，取得积极进展。一是加快实施中低产田改造，大力建设高标准农田。我部会同财政部统筹整合了千亿斤粮食生产能力工程、农业综合开发、农田整治、农田水利等农田建设类资金，设立农田建设补助资金，用于支持高标准农田及农田水利建设。农田建设补助资金切块下达地方，地方可结合本地实际和高标准农田建设相关规划，按照相关规定统筹中央和地方财政资金予以支持。目前，2019年农田建设补助资金已全部下达，各地应按相关政策规定抓紧实施。下一步，我部将会同财政部继续加大对中低产田改造的力度，通过高标准农田建设，加强基础设施建设，提升粮食产能，增强农业抗风险能力。二是鼓励农民推广机械化耕作。近年来，我国农机装备总量持续增长，农机作业水平快速提高，农业生产已从主要依靠人力畜力转向主要依靠机械动力，进入机械化为主导的新阶段。但受机具作业环境复杂等因素影响，一些地方农业机械化发展还相对滞后。下一步，我部将积极推进农业机械化转型升级，稳定实施农机购置补贴政策，加大农机化技术推广力度，积极发展农机社会化服务，加快农机化科技创新步伐，推动改善农机作业条件。

二、关于加大土地有效流转，提升农民种植土地的积极性

（一）关于加大土地有效流转的问题。党中央、国务院一直高度重视放活土地经营权。2014年，中办、国办印发了《关于引导土地经营权有序流转发展农业适度规模经营的意见》，明确要求规范引导农村土地经营权有序流转。2016年，中办、国办印发了《关于完善农村土地所有权承包权经营权分置办法的意见》，对“三权”分置作出系统全面的制度安排，明确提出加快放活土地经营权，建立健全土地流转规范管理制度。我部认真贯彻落实中央决策部署：一是配合修改完善农村土地经营权流转相关法律法规。为落实“三权”分置制度，平等保护土地经营权，我部积极配合全国人大等相关单位做好农村土地承包法修改工作，多次就有关内容提出意见建议。2018年12月29日第十三届全国人大常委会审议通过了关于修改农村土地承包法的决定。这次修改，明确了国家保护承包方依法、自愿、有偿流转土地经营权，保护土地经营权人的合法权益，任何组织和个人不得侵犯；承包方可以自主决定依法采取出租（转包）、入股或者其他方式向他人流转土地经营权，并向发包方备案；土地经营权流转，当事人双方应当签订书面流转合同；不得以退出土地承包经营权作为农户进城落户的条件等内容。同时，我部积极做好新修改的农村土地承包法宣传贯彻工作，会同有关部门编写解读材料，举办农村土地承包和流转工作培训班，向各地负责土地承包管理工作的干部解读新修改的农村土地承包法。二是加强农村土地经营权流转规范管理和服务。2015年，我部会同有关部门印发了《关于加强对工商资本租赁农地监管和风险防范的意见》，要求各地建立工商资本租赁农户承包地上限控制、分级备案、审查审核、风险保障金和事中事后监管等“五项制度”。2016年，我部印发了《农村土地经营权流转交易市场运行规范（试行）》，进一步明确了在流转交易市场进行交易的相关规程。同时，我部积极指导各地健全土地经营权流转市场，规范市场运行机制，引导土地流转双方签订书面流转合同。通过这些工作，有效遏制了一些地方盲目追求流转速度的行为，促进了土地流转的平稳有序发展，有效保障了承包农户合法权益。

（二）关于发展适度规模经营的问题。中央财政高度重视促进适度规模经营工作，通过农业生产发展资金加大对适度规模经营支持力度。一是支持建立健全全国农业信贷担保体系，着力解决新型农业经营主体在适度规模经营中“融资难”“融资贵”问题。二是采取直接支持等多种方式，促进农民合作社、家庭农场、农业生产社会化服务组织等新型农业经营主体加快发展，促进土地有序流转形成适度规模经营，支持土地股份合作、土地托管、龙头企业与农民或者合作社签订订单实现规模经营的方式，以及农业社会化服务组织提供专业的生产服务实现区域规模经营等其他形式的粮食适度规模经营。三是通过立法方式规范农民合作社发展。2017年底，十二届全国人民代表大会常务委员会第三十一次会议审议通过了《中华人民共和国农民专业合作社法》，并于2018年7月1日起施行。新修订的农民专业合作社法对规范农民合作社的组织和行为，鼓励、支持、引导农民合作社的发展作出了规定，明确提出农民合作社成员可以用货币出资，也可以用实物、知识产权、土地经营权、林权等可以用货币估计并可以依法转让的非货币财产，以及章程规定的其他方式作价出资。农民合作社通过整合土地、闲置农房、资金、技术等资源要素，形成了集聚效应。

三、关于采取有效措施保证惠农政策的落实

2016年，中央财政全面推开农业“三项补贴”改革工作，调整优化支出结构，将农作物良种补贴、种粮农民直接补贴和农资综合补贴合并为农业支持保护补贴，政策目标调整为支持耕地地力保护和粮食适度规模经营。2017—2018年，中央财政通过农业生产发展资金，每年安排耕地地力保护补贴资金1204.85亿元，支持对象原则上为拥有耕地承包权的种地农民，鼓励各地创新方式方法，以绿色生态为导向，提高农作物秸秆综合利用水平，引导农民综合采取秸秆还田、深松整地、减少化肥农药用量、施用有机肥等措施，切实加强农业生态资源保护，自觉提升耕地地力。同时，2018年，中央财政通过农业资源及生态保护补助资金，安排了33.78亿元，用于耕地质量提升、东北黑土地保护利用以及农作物秸秆综合利用。下一步，中央财政将结合所提建议，进一步完善相关政策措施，继续支持耕地地力保护。

四、关于加快退耕还林，解决土地荒芜

我部会同自然资源部积极支持退耕还林，统筹生态建设，协调安排生态建设项目。对不能实现水土保持的25度以上的陡坡耕地、重要水源地15－25度的坡耕地、严重沙漠化和石漠化耕地、严重污染耕地、移民搬迁后确实无法耕种的耕地等，综合考虑粮食生产实际情况，经国务院同意，结合生态退耕有序退出永久基本农田。下一步，我部将继续配合相关部门，在贫困地区扩大退耕还林规模。

感谢您对“三农”工作的关心，希望继续对我部工作给予支持。
