# 国家文物局办公室关于公布2019年“高层次文博行业人才提升计划”人员名单的通知

办人函〔2019〕429号

各省、自治区、直辖市文物局（文化和旅游厅/局），各直属单位：

为培养适应文博行业发展需要的高素质人才，我局继续开展2019年“高层次文博行业人才提升计划”（以下简称“提升计划”）。经个人申报、所在单位推荐、参加全国硕士研究生入学统一考试选拔等程序，福建博物院黄弘毅等5人（名单见附件）被合作培养院校录取。经审核，我局同意上述人员列入2019年“提升计划”。

入选“提升计划”人员要增强文物工作的使命感和责任感，认真完成培养任务，不断提高专业素质和业务能力。入选“提升计划”人员所在单位应当主动创造条件，为人才成长提供良好环境，配合完成“提升计划”的实施工作。

特此通知。

附件：2019年“高层次文博行业人才提升计划”人员名单

国家文物局办公室
