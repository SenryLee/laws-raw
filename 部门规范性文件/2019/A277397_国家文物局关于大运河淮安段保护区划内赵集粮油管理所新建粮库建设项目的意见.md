# 国家文物局关于大运河淮安段保护区划内赵集粮油管理所新建粮库建设项目的意见

文物保函〔2019〕417号

江苏省文物局：

你局《关于审批大运河淮安段赵集粮油管理所新建粮库项目方案的请示》（苏文物保〔2019〕41号）收悉。经研究，我局原则同意在大运河淮安段保护区划内实施赵集粮油管理所新建粮库建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应组织专业考古机构对拟建项目相关区域做进一步的考古调查、勘探和必要的考古发掘，明确地下文物埋藏情况。如有大运河水工遗存等重要发现，应调整设计方案，确保文物安全。

（二）应进一步深化文物影响评估，补充大比例尺平面图，明确标注拟建项目与大运河淮安段以及洪泽湖大堤、清口枢纽等大运河遗产保护区划的位置关系，并对照相关管理规定完善项目设计方案。

（三）应进一步论证拟建项目选址在张福路以西区域的可行性。如确需在现方案推荐区域选址，应调整拟建项目平面布局，压缩建筑间距，使项目整体尽可能远离张福河保护范围，同时将烘干房等较高建筑选址向西侧迁移。

（四）应尽可能压缩建筑及设施的设计高度，减小单体建筑体量并采用分散式布局，简化建筑外观形态，淡化建筑外部色彩，同时加强临河区域绿化，缓解项目对大运河周边环境风貌的影响。

（五）应细化施工期间的管理措施、监测措施和应急预案，切实保护好大运河及其生态环境、景观风貌。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有地下文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年5月5日
