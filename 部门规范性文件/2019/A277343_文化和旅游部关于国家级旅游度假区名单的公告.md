# 文化和旅游部关于国家级旅游度假区名单的公告

为满足人民日益增长的美好生活需要，积极发展休闲度假旅游，依据中华人民共和国国家标准《旅游度假区等级划分》（GB/T26358-2010），经评定和公示，四川成都天府青城康养休闲旅游度假区、广西桂林阳朔遇龙河旅游度假区、云南玉溪抚仙湖旅游度假区、广东河源巴伐利亚庄园4家旅游度假区，达到国家级旅游度假区标准要求，确定为国家级旅游度假区。

特此公告。

文化和旅游部

2019年5月14日
