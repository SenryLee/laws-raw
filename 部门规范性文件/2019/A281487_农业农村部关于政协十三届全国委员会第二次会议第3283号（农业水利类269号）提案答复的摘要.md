# 农业农村部关于政协十三届全国委员会第二次会议第3283号（农业水利类269号）提案答复的摘要

## 关于政协十三届全国委员会第二次会议第3283号（农业水利类269号）提案答复的摘要

农办案〔2019〕101号

九三界：

关于保护长江流域水生生物多样性的提案收悉。经商水利部、能源局和生态环境部，现答复如下。

一、 关于严格执行环评制度，严格规范水域开发

我部会同水利部、能源局、生态环境部等部门规范完善环评制度，严格落实环评管理，强化水域开发监管，开展"绿盾"专项行动，督促保护措施落实。下一步，我部将会同有关部门加强对"三线一单"的技术管理支撑，强化长江流域环评制度管理落实，严格把好环评准入关，采取最严格的生态环境保护措施，尽量减少项目实施给生态环境带来的不利影响。

二、 关于加快水生生物多样性三大体系建设

近年来，我部联合有关部门开展水生生物资源环境常规监测，实施长江流域专项调查，推进生物多样性监测评估和信息发布，着力构建完善监测网络体系。下一步，我部将会同有关部门加快推进长江流域水生生物多样性调查评估，掌握珍稀濒危物种现状和保护成效，发挥水量、水质、水生态等多要素同步监测优势，建设完善流域性水生生物多样性观测网络体系。推进《长江流域水生生物资源监测规划》落实，完善监测质量评价标准和技术规范，建立部际信息交流共享平台，统筹各方数据，出具更高层次的权威公报，推动其作为《长江保护法》中水生生物多样性考核指标数据的重要参考来源。

三、 关于加快实施四大修复建设和三大修复工程

做好顶层设计对保护水生生物具有重要指导和引领作用。我部积极推动出台《国务院办公厅关于加强长江水生生物保护工作的意见》，生态环境部联合我部、水利部发布《重点流域水生生物多样性保护方案》。我部实施增殖放流，积极补充水生生物资源；开展生态调度，大力推进栖息地保护修复。联合财政部、人力资源社会保障部印发《长江流域重点水域禁捕和建立补偿制度实施方案》，推进长江流域捕捞渔民退捕上岸，促进长江水生生物资源休养生息。下一步，我部将继续加强部门合作，推动实施《重点流域水生生物多样性保护方案》，加快落实长江上游珍稀特有鱼类栖息地修复重建示范工程。继续推进落实长江流域重点水域禁捕工作，加快实施增殖放流、栖息地修复、生态调度、灌江纳苗、河湖连通、过鱼通道等生态保护修复措施，努力保护长江水生生物资源，修复长江原有生态功能。

四、关于加快建立渔业资源保护与修复及水产种质资源库，加强水生生物多样性迁地保护

我部积极落实中华鲟、长江江豚、长江鲟等拯救行动计划，推动建设中华鲟接力保种基地，开展中华鲟生活史关键环节生境保护和分段驯养繁育。联合生态环境部、有关地方政府多次开展长江江豚迁地保护活动，不断扩大迁地种群规模。推动在珠海长隆海洋公园建立长江江豚人工驯养繁育和科普教育基地，提高科普宣教力度。推进建立中华鲟、长江江豚等珍稀濒危物种遗传家谱和个体信息库，建设长江水域重要鱼类物种活体样本库和标本库。下一步，我部将继续加快推进长江江豚进入水族馆，在有条件的科研单位和水族馆建设长江珍稀濒危物种人工驯养繁育和科普教育基地。加强就地和迁地保护力度，进一步推动长江珍稀濒危物种野生种群恢复重建。

五、关于推进长江流域梯级开发环境影响后评价及绿色水电评估制度

生态环境部制定《建设项目环境影响后评价管理办法（试行）》，将水利、水电、港口等涉水项目纳入后评价范围。组织开展环境影响后评价工作，对现有电站提出补建过鱼设施、开展生态调度等要求，进一步修复长江生态。发展改革委、能源局、生态环境部、水利部联合开展长江经济带小水电排查工作，印发《关于开展长江经济带小水电清理整改工作的意见》，提出分类整改的指导意见。水利部颁布《绿色小水电评价标准》，积极对包括长江经济带在内的相关省份以河流为单位实施农村水电增效扩容改造，持续改善厂坝间河段水资源条件，修复河流生态。下一步，我部将继续会同有关部门推动小水电整治工作，研究建立健全小水电绿色可持续评价管理制度，督促推动生态环境敏感的项目开展环境影响后评价，不断强化生态环境保护措施，减缓不利影响。

感谢对长江流域水生生物多样性保护工作的关心，希望今后继续支持我们工作。

农业农村部

2019年8月30日
