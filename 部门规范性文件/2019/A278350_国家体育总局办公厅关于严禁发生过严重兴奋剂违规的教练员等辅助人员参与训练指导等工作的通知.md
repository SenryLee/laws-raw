# 国家体育总局办公厅关于严禁发生过严重兴奋剂违规的教练员等辅助人员参与训练指导等工作的通知

## 体育总局办公厅关于严禁发生过严重兴奋剂违规的教练员等辅助人员参与训练指导等工作的通知

体科字〔2019〕84号

各省、自治区、直辖市、新疆生产建设兵团体育局，中央军委训练管理部军事体育训练中心，有关直属单位、中国足球协会、中国篮球协会、各改革试点协会：

为贯彻落实习近平总书记“拿干净金牌”的要求，确保中国代表团运动员干干净净参加2020年东京奥运会、2022北京冬奥会等国际综合性运动会，经研究决定严禁发生过严重兴奋剂违规的教练员等辅助人员参与运动员训练指导等工作，有关事宜通知如下：

一、严禁各中心（协会）聘用发生过严重兴奋剂违规的教练员等辅助人员参与国家队运动员训练指导等相关工作。如查实，启动问责程序，给予严肃处理。

二、严禁运动员擅自接受发生过严重兴奋剂违规的教练员等辅助人员指导训练。如查实，国家队运动员将被开除国家队，省区市运动员将不得入选国家队。

三、各省区市体育局必须严格落实《反兴奋剂条例》和体育总局各项反兴奋剂规定和要求，严禁各省区市体育局聘用发生过严重兴奋剂违规的教练员等辅助人员参与本单位运动员训练指导等相关工作。如查实，在体育系统进行通报，并抄送体育局所在省级人民政府。

体育总局办公厅

2019年6月5日
