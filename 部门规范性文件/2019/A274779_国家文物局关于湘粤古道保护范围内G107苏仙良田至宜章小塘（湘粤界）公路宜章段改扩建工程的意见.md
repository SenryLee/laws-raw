# 国家文物局关于湘粤古道保护范围内G107苏仙良田至宜章小塘（湘粤界）公路宜章段改扩建工程的意见

文物保函〔2019〕211号

湖南省文物局：

你局《关于在省级文物保护单位湘粤古道保护范围内进行G107苏仙良田至宜章小塘（湘粤界）公路宜章段改扩建工程项目的请示》（湘文物报〔2019〕1号）收悉。经研究，我局原则同意在湘粤古道保护范围内实施G107苏仙良田至宜章小塘（湘粤界）公路宜章段改扩建工程项目。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步优化YZ1、YZ6、YZ7、WM1、WM2、WM3段道路选线，拟扩建道路选址应尽量避免占压遗址保护范围，并充分评估道路施工、车辆运输、机械运行等振动影响，研提应对措施。

（二）明确施工组织方案、道路运营监测措施、施工后环境恢复措施等，补充绿化带、机电工程、排水工程、广告牌等配套设施建设方案。

（三）严格控制工程范围和施工强度，不得在湘粤古道保护区划范围内设置取土坑。同时，做好施工中的文物保护工作，确保文物安全。

二、请你局组织专业考古研究单位，在项目拟建区域进一步开展全面的考古调查和发掘工作，考古发掘项目需另行填报考古发掘申请书。

三、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

四、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年2月28日
