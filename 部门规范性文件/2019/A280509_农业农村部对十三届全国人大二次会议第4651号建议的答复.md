# 农业农村部对十三届全国人大二次会议第4651号建议的答复

## 对十三届全国人大二次会议第4651号建议的答复

农办议〔2019〕210号

李振国代表：

您提出的关于发展北药产业的建议收悉。经商财政部、银保监会、发展改革委、自然资源部、中医药局，现答复如下。

一、关于给予政策支持

我部认真贯彻落实中央的决策部署，会同有关部门和单位，强化顶层设计，加大政策扶持，促进中药材产业发展，带动农民增收。一是加大资金支持。2018年，中央财政通过农业生产发展资金，安排财政资金108.9亿元，支持优势特色主导产业和农村一二三产业融合发展。同时，实施绿色循环优质高效特色农业促进项目，采取以奖代补方式支持创建国家现代农业产业园；开展农村一二三产业融合发展试点，延伸农业产业链，提升价值链，拓展多功能性，发展休闲农业、农业文化产业，支持农业产业化，培育新产业、新业态、新模式。2018年中央财政安排黑龙江省上述资金4.61亿元，各地可结合本地农业发展规划，按照相关规定统筹利用中央财政和地方资金对中药材等特色产业给予支持。二是完善用地政策。《国务院办公厅关于推进农村一二三产业融合发展的指导意见》（国办发〔2015〕93号）提出，“在各省（区、市）年度建设用地指标中单列一定比例，专门用于新型农业经营主体进行农产品加工、仓储物流、产地批发市场等辅助设施建设”。今年5月，自然资源部出台了《产业用地政策实施工作指引（2019年版）》，对产业用地政策的适用情形、依据作了系统归纳。黑龙江在道地药材产业发展中可充分利用好现行相关用地政策，促进药材加工、仓储物流等发展。三是加强政策性保险支持。银保监会高度重视中药材等特色农业保险，鼓励保险机构和地方探索开展相关业务，以建立多层次的农业保险体系。2018年，药用作物保险实现保费收入2亿元，同比增长134.66%；提供风险保障37.1亿元，同比增长137.86%；发生赔付1.63亿元，同比增长104.3%；受益农户3.46万户次，同比增长25.08%。四是降低信贷门槛。2019年2月，银保监会印发了《关于做好2019年银行业保险业服务乡村振兴和助力脱贫攻坚工作的通知》（银保监办发〔2019〕38号），要求各银行业金融机构进一步加大涉农贷款投放力度，实现普惠型涉农贷款增速总体高于各项贷款平均增速。截至今年一季度末，涉农贷款余额为33.71万亿，较年初增长3.7%；普惠型涉农贷款余额为5.87万亿，较年初增长4.17%。五是加大担保支持力度。目前，全国农担体系初步建成，政策框架基本搭建，业务规模稳步扩大，取得了阶段性成效。2018年，各省级农担公司共新增担保项目19.19万个，金额640.6亿元。

下一步，我部将会同有关部门和单位，进一步争取政策支持，配合相关部门研究完善保费补贴政策和地方特色农产品保险以奖代补政策，指导全国农业信贷担保体系扩大相关业务规模，促进北药产业发展。

二、关于将黑龙江省纳入中药材试点省建设

近年来，我部会同有关部门和单位，贯彻落实中央的部署和要求，紧紧围绕质量兴农、绿色兴农、品牌强农，指导中药材规范化、规模化、集约化种植，有力促进中药材产业发展和农民持续增收。一是加强规划引导。2016年，国务院办公厅颁布实施《关于促进医药产业健康发展的指导意见》（国办发〔2016〕11号），提出加强中医药领域地理标志产品保护，在适宜地区建设规范化种植（养殖）、规模化加工一体化基地等具体意见。2016年，国家中医药局印发《中医药发展“十三五”规划》，提出推进中药保护和发展，促进中药材种植养殖业绿色发展。2018年12月，我部会同中医药局、药监局等单位，制定印发《全国道地药材生产基地建设规划（2018—2025年）》，引导各地优化道地药材生产布局，推进中药材规模化种植和标准化生产，提高道地药材供应能力；加强质量规范管理，推进技术集成创新，推广绿色标准化生产技术模式，提升产品质量。二是加快中药材特优区建设。2017年，我部会同发展改革委、国家林业局编制印发了《特色农产品优势区建设规划纲要》，提出到2020年，创建并认定300个左右国家级特优区，重点支持标准化生产基地、加工基地、仓储物流基地、科技支撑体系、品牌建设与市场营销体系、质量控制体系等建设。国家级特优区聚焦发展特色粮经作物、特色园艺产品、特色畜产品、特色水产品、林特产品等五大类29个品种，目前已认定2批共146个国家级特优区，其中中药材特优区14个。黑龙江省可积极组织有关地方申报创建中药材国家级特优区，我部将加强调研指导，在提高申报材料质量、编制特优区建设规划等方面给予指导和帮助。

下一步，我部将会同有关部门，进一步加强指导服务，支持黑龙江中药材产业发展，着力打造一批标准化生产基地、培育一批规模经营主体、搭建一批服务平台，为加快推进乡村振兴战略实施、决胜全面建成小康社会提供有力支撑。

三、关于支持建设中药材批发市场

我部认真贯彻落实党中央、国务院关于实施乡村振兴战略的决策部署，强化顶层设计，培育市场主体，促进优质优价，带动农民增收。一是加强政策指导。推进《国务院办公厅关于进一步促进农产品加工业发展的意见》（国办发〔2016〕93号）贯彻落实；会同发展改革委等14个部门印发《关于促进农产品精深加工高质量发展若干政策措施的通知》，指导各地加强行业标准制修订、国际标准跟踪和官方评议；培育创建国际农产品加工园区，支持新型经营主体建设保鲜、储藏、分级、包装等初加工设施；开展外经人员能力培训，推进加工企业“走出去”。二是加强农产品批发市场建设。2015年，我部印发《全国农产品产地市场发展纲要》，并会同发展改革委、商务部、交通运输部等部委联合印发了10余个文件推动完善农产品产地市场体系。截至目前，我部已启动建设了13个全国性农产品产地市场，亿元以上农产品专业批发市场发展到937家，年成交额19346.7亿元。三是促进产销衔接。在第十四届、十五届中国国际农产品交易会上，举办“省部长推介品牌农产品专场”“我为品牌农产品代言”等专场推介活动，创响农产品知名品牌。通过“互联网+”和电商扶贫，促进小农户和大市场有效衔接。

下一步，我部将继续加强对黑龙江中药材品牌建设指导，充分借助各类农业展会、农产品产销对接活动等平台开展品牌营销推介活动，利用传统媒体和新媒体强化品牌宣传推广，提高品牌影响力和知名度。

感谢您对农业农村工作的关心，希望今后对我部工作继续给予支持。
