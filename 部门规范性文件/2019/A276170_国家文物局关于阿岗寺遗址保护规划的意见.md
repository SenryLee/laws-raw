# 国家文物局关于阿岗寺遗址保护规划的意见

文物保函〔2019〕240号

河南省文物局：

你局《关于报批河南省舞阳县阿岗寺遗址文物保护规划的请示》（豫文物〔2018〕248号）收悉。经研究，我局原则同意所报规划。

一、所报规划尚需作以下必要的修改和完善：

（一）加强考古调查勘探和研究，科学确定阿岗寺遗址与周边古遗址的关系、遗址内涵，深化价值评估。现阶段应重点建立文物保护管理框架，协调文物保护与经济建设之间的关系。

（二）深化现状评估和病害分析。加强北侧河流流量监测，科学评估河流冲刷影响，制定地表水的控制、引导和疏解措施。根据各文化层埋深情况，限定不同区域扰土深度或作物种类。进一步明确遗址区现有寺庙建筑的始建年代、使用性质、建设许可等情况，评估文物和环境风貌影响。

（三）合理调整保护区划，将遗址南侧古河道区域纳入保护范围，尽量涵盖已探明遗存分布区域。同时，合理确定保护区划的具体边界，兼顾村庄、道路分布，提高规划管理的可操作性。

（四）加强与考古研究单位的沟通，制定切实可行的考古工作计划，明确阶段性工作目标与具体内容。现阶段应重点开展系统考古调查、勘探，搞清遗址分布范围、保存现状和格局等，为后续研究、保护工作提供依据。

（五）应根据遗址综合条件和地方经济社会发展状况，客观论证考古遗址公园、停车场、考古工作站等大量展示、服务设施建设的必要性，建议现阶段重点做好考古研究、环境整治、日常管理工作，不宜盲目实施展示项目。应与村庄建设相结合，统筹考虑道路提升、设施布局、环境整治工作，兼顾遗址文化内涵和村庄景观风貌，尽量改造利用闲置村舍。

（六）明确行政管理部门主体责任，充分研究将保护范围内土地性质全部调整为文物古迹用地的必要性与可行性。

（七）进一步规范图文表达，地形图应准确无误。

二、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将阿岗寺遗址保护规划报请河南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

三、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

四、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好阿岗寺遗址的各项保护、管理工作，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2019年3月8日
