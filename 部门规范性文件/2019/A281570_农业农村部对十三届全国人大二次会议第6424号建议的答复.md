# 农业农村部对十三届全国人大二次会议第6424号建议的答复

## 对十三届全国人大二次会议第6424号建议的答复

农办议〔2019〕163号

郭建华等5名代表：

您提出的关于加大对农产品深加工的政策扶持力度助推脱贫攻坚的建议收悉。现答复如下。

一、关于扶持花生精深加工

农业农村部认真贯彻落实中央一号文件精神，大力支持粮食主产区发展粮食精深加工。一是强化政策引导。我部会同发展改革委等14个部门制定印发《关于促进农产品精深加工高质量发展若干政策措施的通知》，支持各地优化结构布局、培育加工企业、提升技术装备、培养人才队伍、强化扶持政策，引导加工企业重心下沉到粮食生产功能区、重要农产品生产保护区、特色农产品优势区设立加工厂。二是壮大龙头企业。截至2018年底，认定省级以上农业产业化重点龙头企业1.8万家、国家重点龙头企业1243家，其中涉及花生加工的200余家。2019年，中央财政通过农业生产发展资金，支持培育农业产业化联合体，带动农民合作社和家庭农场发展。三是完善税收政策。国家税务总局下调增值税税率，农产品深加工产品税率由17%下调至13%,降幅达23.5%.随着增值税转型改革和营改增试点逐步推开，企业可抵扣进项税的项目将大幅增加。四是强化技术创新。2018年，国家农产品加工技术研发体系新增国家花生加工技术研发专业中心，组织科研单位和加工企业开展花生加工技术研究和设备改进，推动花生加工技术装备升级，提升花生精深加工水平。

二、关于选育推广花生良种

2018年，我部启动国家花生良种联合攻关，促进花生良种选育推广。一是开展联合攻关。组建6家企业和22家科研教学及推广单位参加的攻关联合体，建设4个花生品种检测鉴定平台，为我国花生育种材料筛选鉴定、种质创制提供条件。自2008年以来，中央财政每年投入2940万元，支持国家花生产业技术体系专家开展技术攻关和试验示范。二是培育花生新品种。在东北、黄淮北部、黄淮中南部、长江流域、南方设立5个品种适应性测试片区，2018年共测试品种90余个。2018年联合体育种单位登记花生新品种22个，发掘抗青枯病高油酸种质10份、低温种质资源10份、耐低氮种质资源2份。三是开展展示示范。开展花生新品种展示示范，筛选一批增产潜力大、推广价值高的品种，一些品种已被地方政府列为主推品种。

三、关于培育花生优势产业带

我部高度重视花生优势产业带建设。一是开展农产品地理标志登记。目前，全国已登记花生农产品地理标志33个，涉及全国14个省（区、市），其中河南有内黄花生、开封花生、正阳花生3个，山东有柘山花生、莒南花生、泗水花生、临沭花生、乳山大花生、文登大花生、沂源花生、荣成大花生、烟台大花生9个。二是建设国家现代农业产业园。2017年我部会同财政部启动国家现代农业产业园创建，其中河南省正阳县现代农业产业园，以花生为主导产业，形成了龙头企业带动、知名品牌集中、产品品类齐全的格局。三是引导建立农产品原料基地。2016年，我部印发《全国农产品加工业与农村一二三产业融合发展规划（2016-2020年）》，提出在东北农牧交错区及沿黄河花生主产区，重点建设花生优质原料基地，提高花生生产能力。

四、关于培育花生知名品牌

农业农村部高度重视农业品牌建设，不断加大规范认证、试点示范、展示展销、品牌传播等方面工作力度，培育特色鲜明、质量过硬、信誉可靠的农业品牌。一是强化工作推动。贯彻落实《国务院办公厅关于发挥品牌引领作用推动供需结构升级的意见》，将2017年确定为农业品牌推进年，召开全国农产品加工业发展和农业品牌创建推进工作会，部署品牌建设重点工作，指导各地大力推进品牌建设。二是开展品牌推选。积极利用各类农业展会、品牌大会等平台开展品牌推选工作。2017年推选出"中国百强农产品区域公用品牌",河南正阳花生入选。支持中国农产品市场协会建立"中国农业品牌目录制度",引导规范农业品牌发展。三是加强品牌宣传。在中国国际农产品交易会上，举办"家乡的味道—我为品牌农产品代言"等大型公益活动，宣传推介花生品牌。

下一步，农业农村部将继续加强国家花生良种选育推广应用，优化区域布局，推进精深加工，推动花生产业持续健康发展。

感谢您对农业农村工作的关注，希望今后继续关心和支持我部工作。
