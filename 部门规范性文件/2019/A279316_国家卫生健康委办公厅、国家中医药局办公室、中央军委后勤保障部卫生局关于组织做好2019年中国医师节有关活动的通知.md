# 国家卫生健康委办公厅、国家中医药局办公室、中央军委后勤保障部卫生局关于组织做好2019年中国医师节有关活动的通知

## 关于组织做好2019年中国医师节有关活动的通知

国卫办医函〔2019〕623号

各省、自治区、直辖市及新疆生产建设兵团卫生健康委、中医药局，军队各大单位卫生部门：

今年8月19日是第二个中国医师节，2019年中国医师节的主题是“弘扬崇高精神，聚力健康中国”。在新中国成立70周年之际，组织做好中国医师节有关活动，对于团结凝聚卫生健康系统力量，加强医师队伍建设，营造尊医重卫良好氛围，为决胜全面建成小康社会、实现中华民族伟大复兴中国梦作出新贡献，具有重要意义。现将有关事项通知如下：

一、大力弘扬崇高精神

各级卫生健康部门（含中医药管理部门、军队卫生部门，下同）和各级各类医疗机构要深刻学习领会习近平总书记关于卫生健康工作的重要论述，结合“不忘初心、牢记使命”主题教育活动，深入开展学习研讨，不断激发职业荣誉感和神圣使命感，引导广大医务人员切实践行“敬佑生命、救死扶伤、甘于奉献、大爱无疆”的崇高精神，为深化医药卫生体制改革、推动卫生健康事业发展作出更大贡献。

二、聚力实施健康中国战略

各级卫生健康部门和各级各类医疗机构要组织多种形式的宣传活动，全面展示新中国成立以来特别是党的十八大以来，在以习近平同志为核心的党中央的坚强领导下，以医师为代表的广大医务工作者为增进人民健康福祉作出的卓越贡献，号召全社会共同支持和参与卫生健康事业，为实施健康中国战略汇聚磅礴之力。

三、切实保障医师合法权益

各级卫生健康部门和各级各类医疗机构要切实关心爱护医务人员，在中国医师节期间，看望慰问医务工作者，重点走访慰问乡村医生、离退休老医生、有生活困难的医生、援疆援藏和援外医务人员及家属、因公殉职的医务人员家属，送去党和政府的关怀和温暖。要注重抓好各项惠医举措的贯彻落实，不断提高医师地位、保障医师待遇、维护医师权益，全力以赴解决好广大医师的后顾之忧。

四、推动尊医重卫蔚然成风

各级卫生健康部门和各级各类医疗机构要利用多种形式加大宣传力度，深入挖掘宣传优秀医师典型，特别是在扎根基层、援疆援藏和援外、抗击重大疫情和突发灾害等工作中作出突出贡献的医师团队和个人，弘扬崇高医德医风，展现可歌可泣、可敬可爱的良好形象。各有关行业组织和医疗机构可根据实际情况，表扬奖励一批优秀医师代表，号召全社会尊重医师、爱护医师，共同营造尊医重卫的良好氛围。

各级卫生健康部门要主动将中国医师节重大活动安排向同级党委、政府报告，加强与有关部门的沟通协调，争取有关方面的大力支持。各省级卫生健康委于8月30日前将节日活动的组织情况总结报送国家卫生健康委医政医管局。
