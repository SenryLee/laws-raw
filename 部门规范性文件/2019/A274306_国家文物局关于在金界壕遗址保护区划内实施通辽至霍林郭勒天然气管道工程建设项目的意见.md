# 国家文物局关于在金界壕遗址保护区划内实施通辽至霍林郭勒天然气管道工程建设项目的意见

文物保函〔2019〕99号

内蒙古自治区文物局：

你局《关于通辽至霍林郭勒天然气管道工程穿越金界壕遗址的请示》（内文物字〔2018〕112号）收悉。经研究，我局原则同意在金界壕遗址保护范围和建设控制地带内实施通辽至霍林郭勒天然气管道工程建设项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应在拟建项目施工前，组织专业考古机构对相关区域进行考古调查勘探和必要的考古发掘，明确地下遗存分布情况，避免项目建设对地下文物造成破坏。

（二）应适当加大拟建项目的管道埋深，确保顶管与遗址底面之间的安全距离，并细化顶管参数、顶进速度和相应控制措施，确保不超挖、少偏移。

（三）应重点细化拟建项目施工和运营期间的监测措施，关注各类振动因素对金界壕遗址本体的影响情况，并制定相应的应急预案，确保文物安全。

（四）应明确施工期间的场地布置、施工组织、生态保护等要求和施工污染物处置措施，以及施工完成后的场地清理和环境恢复措施。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》的有关规定，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年1月24日
