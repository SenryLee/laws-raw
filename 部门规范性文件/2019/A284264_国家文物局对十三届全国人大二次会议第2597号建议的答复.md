# 国家文物局对十三届全国人大二次会议第2597号建议的答复

文物政函〔2019〕655号

王文保代表：

您提出的“关于加强文物保护与利用的建议”收悉，现答复如下。

您关于对《中华人民共和国文物保护法》个别条款进行修改的建议，体现了对加强文物合理利用的关注，符合文物事业可持续发展的趋势。我局将在深入调研的基础上研究提出《中华人民共和国文物保护法》修订草案，考虑增加鼓励社会各界参与文物合理利用的条款，酌情修改现行法律中不利于文物合理利用的条款，同时做好与包括《旅游法》在内的相关法律的衔接。

您提出的对文物利用进行分级、加强试点示范等具体建议，认识到不同文物利用的复杂性，符合文物保护利用的客观规律，具有较高的参考价值。我局将通过制定标准、加强监管等方式，指导各级文物部门根据不同类型文物的特点，制定切实可行的文物合理利用对策，因地制宜地开展文物合理利用示范试点，进一步促进让文物活起来。

您提出的由国家建立田野调查、综合研究、技术创新、文化创意、文旅融合等专业人才机构的建议，我局将在职责范围内积极推进中国社会科学院考古研究所、中国文化遗产研究院等国家级研究机构发挥应有的作用。

感谢您对文物工作的关心和支持！

国家文物局

2019年7月9日
