# 国家文物局对十三届全国人大二次会议第6869号建议的答复

文物保函〔2019〕671号

罗佳明代表：

您提出的“关于进一步加强我国世界遗产保护利用可持续发展的建议”收悉。经商文化和旅游部、自然资源部、中央机构编制委员会办公室、国家发展和改革委员会，现答复如下：

自1972年联合国教科文组织通过《保护世界文化和自然遗产公约》（以下简称“《公约》”）以来，缔约国已增至193个，世界遗产达1092项。我国于1985年签署《公约》，1987年长城等首批6处遗产列入《世界遗产名录》。目前，我国已拥有世界遗产55项，总数位居世界第一位，其中文化遗产37项，自然遗产14项，文化和自然混合遗产4项。

我国世界文化遗产保护管理法规建设稳步进展，并辅以配套技术规范，对世界文化遗产的培育、申报、保护管理实施全程规范化操作。目前，我国现行世界文化遗产相关法律法规77部（件），其中法律1部，行政法规2件，部门规章2件，地方性法规、规章72件，初步实现了《世界遗产公约》与我国现行法律体系的有效衔接。

各遗产地相继建立起百余个世界文化遗产保护管理机构。大部分遗产地人民政府设立了管理委员会或领导小组，统筹协调指导各职能部门依法履行世界文化遗产保护管理职责。针对大型线性遗产还建立了跨部门、跨地区协调联动机制，如由13个部委和沿线8省（市）人民政府组成的大运河保护和申遗省部际会商小组，以及沿线35个城市成立的大运河沿线保护城市联盟，在大运河申遗和后续保护管理工作中发挥了重要作用。

在注重遗产申报的同时，近年来不断加大对已列入《世界遗产名录》遗产的保护和管理力度。我局实施了长城保护工程、“平安故宫”工程、西藏重点文物保护工程、承德避暑山庄及周围寺庙文化遗产保护工程、大足石刻千手观音造像抢救性保护工程等一批世界文化遗产重大文物保护工程，初步建立起世界文化遗产保护管理动态监测体系，不断提升预防性保护能力，消除重大隐患，改善遗产本体及周边环境的保护状况，有效维护了遗产的突出普遍价值和真实性、完整性。国家发展和改革委员会累计支持313个国家文化和自然遗产类项目，完善保护性基础设施，整治核心区域环境，引导地方科学建设必要的宣传、展示利用等设施，有力促进世界遗产保护利用的可持续发展。文化和旅游部不断加强对世界遗产地非遗资源的挖掘阐释，推动非遗与旅游融合发展。自然资源部充分考虑世界遗产保护需求，在城镇规划建设中，严格划定生态保护红线，将自然保护地全部划入生态保护红线，线内严格禁上开发性、生态性建设活动；在实施乡村振兴战略中，按照传承保护、突出特色的要求，提出村庄景观风貌控制性要求和历史文化景观保护措施。

通过30多年的不懈努力，我国世界文化遗产事业取得了令人注目的成绩，但也存在一些问题：世界文化遗产保护管理基础工作仍显薄弱，一线专业人才匮乏；部分地方政府缺乏科学的保护理念，未能妥善处理好遗产保护与地方经济社会发展的关系；部分遗产地提供社会文化服务的能力和水平亟待提升。

为解决工作中存在的问题，国家文物局深入贯彻学习党的十九大精神和习近平总书记关于世界文化遗产保护的一系列重要指示、批示精神，联合相关部门重点从以下三方面入手，继续做好世界文化遗产的申报、保护和管理工作，实现可持续发展。

一是按照习近平总书记“申报世界文化遗产工作要统筹安排，申报项目要有利于突出中华文明历史文化价值、有利于体现中华民族精神追求、有利于向世人展示全面真实的古代中国和现代中国”的要求，扎实推进最能体现中华文明历史文化价值和中华民族精神追求、最能全景展现全面真实的古代中国和现代中国、与国家发展战略关系密切、具有重大影响力的申报项目。

二是加强世界文化遗产申报预备项目培育，对世界文化遗产预备名单实施动态管理，建立警示和退出机制，调动地方政府积极性，落实属地管理责任，扎实开展申遗前期准备工作，提高申遗储备项目的整体质量。

三是以遗产监测为抓手持续强化保护管理。吸收国际成熟经验，继续实施中国世界文化遗产定期报告制度，定期、全面、系统地掌握世界遗产的保护管理状况。进一步完善中国世界文化遗产监测体系，强化世界遗产的反应性监测机制，落实巡视巡查机制，探索利用多种技术手段，科学监测遗产及其周边环境变化，发现问题尽早介入，防患于未然。继续开展世界文化遗产保护工程，提升遗产展示阐释和展示水平，强化遗产地公共服务能力。完善公众参与机制，形成全社会广泛参与世界文化遗产保护的新局面，带动国内文化遗产保护管理水平的整体提升。

衷心感谢您对我国世界文化遗产工作的关注和支持！

国家文物局
