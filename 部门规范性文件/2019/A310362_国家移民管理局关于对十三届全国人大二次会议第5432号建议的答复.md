# 国家移民管理局关于对十三届全国人大二次会议第5432号建议的答复

沙宝琴代表：

您提出的关于批准郑州新郑国际机场口岸外国人72小时或144小时过境免签的建议收悉。现答复如下：

公安部、国家移民管理局高度重视并支持地方经济发展和对外交流合作，积极为便利人员往来提供政策支持。2014年2月1日，国务院批准河南郑州航空口岸实施口岸签证政策，为因紧急事由来华来不及在我驻外使领馆办理签证的外国人以及国内旅行社组织、接待的外国旅游团办理口岸签证。

为配合地方发展需要，结合当地国际化水平、国际航班航线情况及外国人管理工作基础，经报国务院批准，全国22个城市相关口岸陆续实施72小时或144小时过境免签政策。据了解，郑州新郑机场口岸现有17条国际航线，2018年入境外国人4.6万人次，其中，办理口岸签证2484人次，24小时过境免签168人次。总体看，目前该政策措施能够适应外国人入境河南开展商务活动或旅游的需要。您在建议中对郑州发展战略、出入境便利措施需求等方面的研究，对我们今后进一步优化过境免签政策具有参考作用。下步，我局将根据河南发展情况和现实需要，不断优化出入境便利政策，积极为地方经济发展和人员往来提供支持。

感谢您对国家移民管理工作的关心和支持。
