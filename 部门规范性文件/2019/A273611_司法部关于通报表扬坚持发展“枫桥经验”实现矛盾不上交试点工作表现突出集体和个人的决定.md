# 司法部关于通报表扬坚持发展“枫桥经验”实现矛盾不上交试点工作表现突出集体和个人的决定

各省、自治区、直辖市司法厅（局），新疆生产建设兵团司法局：

2018年是毛泽东同志批示学习推广“枫桥经验”55周年，是习近平总书记指示坚持发展“枫桥经验”15周年。为贯彻落实习近平总书记重要指示精神，积极打造新时代人民调解工作升级版，5月至8月，司法部部署在北京、天津、黑龙江、江苏、浙江、安徽、四川、云南、宁夏等9省（区、市）开展坚持发展“枫桥经验”实现矛盾不上交试点工作。试点地区各级司法行政机关和广大人民调解组织、人民调解员，认真贯彻落实司法部决策部署，立足本地实际，采取有力措施，扎实推进试点工作，矛盾纠纷排查化解取得显著成效，人民调解组织和队伍建设进一步加强，形成了一批特色鲜明的工作机制和可推广可复制的工作模式，人民调解各项工作取得新成绩，实现新发展，涌现出一大批表现突出集体和个人，为维护人民群众合法权益、促进社会和谐稳定、服务经济社会发展作出了重要贡献。

为表扬先进，激励士气，充分发挥先进典型的模范带动和示范引领作用，推进新时代人民调解工作创新发展，司法部决定，对北京市朝阳区常营回族乡人民调解委员会等200个试点工作表现突出集体、北京市东城区北新桥街道人民调解委员会调解员徐立章等400名试点工作表现突出个人予以通报表扬。希望受到表扬的集体和个人珍惜荣誉、再接再厉，不断取得新的成绩。

中国特色社会主义进入新时代，人民群众对调解工作提出了新的更高要求。做好人民调解工作，责任更加重大，使命更加光荣。全系统要坚持以习近平新时代中国特色社会主义思想为指导，坚持以人民为中心的发展思想，以获得表扬的集体和个人为榜样，继续拼搏进取，努力工作，重整行装再出发，切实筑牢维护社会和谐稳定的“第一道防线”，为实现矛盾不上交的工作目标，为推进平安中国、法治中国建设作出新的更大贡献。

附件：

1.坚持发展“枫桥经验”实现矛盾不上交试点工作表现突出集体（200个）

2.坚持发展“枫桥经验”实现矛盾不上交试点工作表现突出个人（400名）

司法部
