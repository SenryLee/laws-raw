# 国家文物局关于郑义门古建筑群保护范围及建设控制地带内传统文化研学营地建设项目的意见

文物保函〔2019〕771号

浙江省文物局：

你局《关于上报全国重点文物保护单位郑义门古建筑群保护区划内实施传统文化研学营地建设项目的请示》（浙文物发〔2019〕157号）收悉。经研究，我局原则同意郑义门古建筑群保护范围及建设控制地带内传统文化研学营地建设项目。

一、所报方案尚需做以下必要的修改和完善：

（一）进一步深化设计方案，优化建筑屋顶坡度与脊饰设计；建筑入口及门楼应吸纳当地传统建筑形制，注意项目外围与村落环境有机融合。

（二）严格控制建筑规模、体量，建议拆建建筑进一步减小体量感。

（三）充分考虑施工对文物本体的影响，制定必要的文物保护措施、监测方案和应急预案，控制粉尘及施工垃圾等对文物本体及环境的污染。

二、请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》等有关法规，履行相应审批手续后实施。

三、请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并组织研究，提出调整方案。

专此函复。

国家文物局

2019年8月2日
