# 生态环境部办公厅关于解除天津创业环保股份有限公司咸阳路污水处理厂挂牌督办的通知

## 关于解除天津创业环保股份有限公司咸阳路污水处理厂挂牌督办的通知

环办执法函〔2019〕894号

天津市生态环境局：

2018年8月1日，我部印发《关于对26家排污单位主要污染物排放严重超标问题挂牌督办的通知》（环办环监函〔2018〕770号），对天津创业环保股份有限公司咸阳路污水处理厂进行挂牌督办。按照督办要求，你局督促相关地方和排污单位积极整改，并向我部提交了解除该单位挂牌督办的申请。

经现场核查整改情况并核实该单位自动监测数据，该单位基本达到了督办要求，同意解除挂牌督办。请你局继续加强监督管理，督促其认真履行生态环境保护主体责任，确保污染物稳定达标排放。

生态环境部办公厅

2019年12月5日

## 关于解除布尔津县津城供排水有限公司挂牌督办的通知

新疆维吾尔自治区生态环境厅：

2018年11月13日，我部印发《关于对28家重点排污单位主要污染物排放严重超标问题挂牌督办的通知》（环办执法函〔2018〕1295号），对布尔津县津城供排水有限公司进行挂牌督办。按照督办要求，你厅督促相关地方和排污单位积极整改，并向我部提交了解除对该单位挂牌督办的申请。

经现场核查整改情况并核实该单位自动监测数据，该单位基本达到了督办要求，同意解除挂牌督办。请你厅继续加强监督管理，督促其认真履行生态环境保护主体责任，确保污染物稳定达标排放。

生态环境部办公厅

2019年12月5日
