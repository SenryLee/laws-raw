# 财政部关于下达2019年中央集中彩票公益金支持地方体育事业专项资金预算的通知

财教〔2019〕13号

各省、自治区、直辖市、计划单列市财政厅（局）：

为推动全民健身活动开展，促进体育事业全面发展，经研究，现下达2019年中央集中彩票公益金支持地方体育事业专项资金预算（政府收支分类科目：2296003用于体育事业的彩票公益金支出，项目代码：Z175050040002），金额见附件。请按照《中央集中彩票公益金支持体育事业专项资金管理办法》（财教〔2013〕481号）等要求，加强资金管理，提高资金使用效益。

为进一步加强预算绩效管理，请按照《中共中央 国务院关于全面实施预算绩效管理的意见》和《中央对地方专项转移支付绩效目标管理暂行办法》（财预〔2015〕163号）相关要求，参照2019中央集中彩票公益金支持地方体育事业专项资金整体绩效目标和补助你省（区、市）资金额度，科学合理确定你省（区、市）区域或项目绩效目标，在收到本通知30日内报财政部、体育总局备案，并抄送财政部当地监管局。同时，请及时将你省（区、市）绩效目标对下分解，做好省（区、市）内预算绩效管理工作。请在组织预算执行中对照绩效目标做好绩效监控，确保年度绩效目标如期实现。

2. 2019年中央集中彩票公益金支持地方体育事业专项资金整体绩效目标表
