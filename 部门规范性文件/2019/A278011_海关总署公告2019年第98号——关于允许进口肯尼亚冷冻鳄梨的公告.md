# 海关总署公告2019年第98号——关于允许进口肯尼亚冷冻鳄梨的公告

## 海关总署公告

2019年第98号

## 关于允许进口肯尼亚冷冻鳄梨的公告

根据我国相关法律法规和《中华人民共和国海关总署与肯尼亚共和国国家植物健康监督局关于肯尼亚冷冻鳄梨输华检验检疫要求的议定书》规定，现允许符合相关检验检疫要求的肯尼亚冷冻鳄梨进口。具体要求可在海关总署网站（www.customs.gov.cn）查询。

本公告自发布之日起实施。

特此公告。

海关总署

2019年6月5日
