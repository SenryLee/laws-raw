# 国家发展改革委办公厅关于报送2018年度行政复议、行政诉讼案件情况的通知

发改办法规〔2019〕62号

各省、自治区、直辖市，新疆生产建设兵团发展改革委：

根据《国家发展改革委办公厅关于建立发展改革系统行政复议协作与联系制度的通知》（发改办法规〔2005〕324号）要求，我们拟对发展改革系统2018年度行政复议和行政诉讼情况进行统计分析。请汇总本单位相关情况，按要求认真填写相关统计表（附后），并于2019年1月23日前将上述材料报我委（法规司）。

联系人：吴玉凯 电话：010-68502547，68502513（传真）

联系邮箱：wuyk@ndrc.gov.cn

附件：1.案件统计表格填报说明

2.发展改革系统行政复议案件情况统计表（一）

3.发展改革系统行政复议案件情况统计表（二）

4.发展改革系统行政诉讼案件情况统计表

5.参考样表
