# 财政部关于调整重庆市时时彩电脑福利彩票附加玩法的通知

## 财政部关于调整重庆市时时彩电脑福利彩票附加玩法的通知（财办综[2006]99号）

中国福利彩票发行管理中心：

你中心报来的《关于调整重庆市电脑福利彩票“时时彩”游戏规则的请示》（中彩发字[2006]65号）收悉。经研究，现就有关事项通知如下：

**一、**为丰富时时彩附加玩法的趣味性，挖掘重庆市彩票市场潜力，根据《彩票发行与销售管理暂行规定》（财综[2002]13号）的规定，决定调整《重庆市电脑福利彩票游戏时时彩游戏附则》，调整后的游戏附则见附件。

**二、**重庆市福利彩票发行中心应将调整后时时彩附加玩法的广告宣传、上市销售日期、销售系统等方案报重庆市财政局审核，经批准后上市销售。

**三、**调整后的时时彩附加玩法上市销售前，重庆市福利彩票发行中心应及时向社会公告，并在公告中注明财政部、重庆市财政局的批准文件、核准文件名称及文号。

二00六年十一月二十八日

附件：

重庆市时时彩电脑福利彩票游戏附则

**第一条**　根据《彩票发行与销售管理暂行规定》，结合计算机网络技术和重庆市彩票市场的实际情况，参照《重庆市数字型电脑福利彩票时时彩游戏规则》之相关条款，制定本附则。

**第二条**　本附则是《重庆市时时彩电脑福利彩票游戏规则》之附加规则。《重庆市时时彩电脑福利彩票游戏规则》之有关规定均适用于本附则。

**第三条**　“猜大小、猜单双”附加玩法，是指投注者可对个位和十位的数字性质进行投注，投注者投注的号码位置、性质与开奖号码位置、性质相同即中奖。0－9十个自然数按“大”、“小”和“单”、“双”性质规定如下：0－4为小号，5－9为大号；1、3、5、7、9为单号，0、2、4、6、8为双号。

投注示例如下：

猜十位和个位为“大小”投注：---大小

猜十位和个位为“单双”投注：---单双

**第四条**　“二星组选”附加玩法，是指投注者可在0－9十个自然数中任意选择两个不同的数字对十位和个位进行投注，所选号码与当期开奖号码相同（顺序不限），即视为中奖。例如，开奖号码的十位、个位为34，二星组选的投注号码为34、43，均视为中奖。

投注示例如下：

对十位、个位进行“二星组选”投注：二星组选 34

**第五条**　“五星通选”附加玩法，是指投注者在00000-99999中选择一个五位数进行投注。如所选择的五位数与开奖号码数字全部相同且顺序一致，则中得“五星通选”一等奖；如所选择的五位数的首或尾连续三位数与开奖号码首或尾连续三位数数字相同且顺序一致则中得“五星通选”二等奖；如所选择的五位数的首或尾连续两位数与开奖号码首或尾连续两位数数字相同且顺序一致则中得“五星通选”三等奖。

投注示例如下：

“五星通选”投注：五星通选 12345

**第六条**　各附加玩法按“时时彩”销售期销售，并按“时时彩”期号编排。

**第七条**　各附加玩法可在全市开通“时时彩”销售的电脑福利彩票投注站进行投注。投注方法可分自选投注和机选投注；当期投注和多期投注；单倍投注和多倍投注。

**第八条**　“猜大小、猜单双”采用固定设奖，单注奖金为4元。当期每注投注只有一次中奖机会，不能兼中兼得，特别设奖除外。

示例：

投注“---大小”，开奖号码为87654 或 00092都中奖，奖金4元，开奖号码为87655 或 00099则未中奖；投注“---单双”，开奖号码为 87654 或 00092 都中奖，奖金为4元，开奖号码为87655或 00099则未中奖。

**第九条**　“二星组选”采用固定设奖，单注中奖金额为50元。当期每注投注号码只有一次中奖机会，不能兼中兼得，特别设奖除外。

示例：

投注“二星组选”34，开奖号码为15134，或15143均中奖，奖金为50元；开奖号码为34151，或15341则未中奖。

**第十条**　“五星通选”采用固定设奖，当期每注投注号码可兼中兼得，特别设奖除外。具体设奖情况如下：

一等奖：所投注的五位数与开奖号码全部相同且顺序一致，中奖金额20000元；

二等奖：所投注的五位数的首或尾连续三位数与开奖号码首或尾连续三位数相同且顺序一致，中奖金额200元；

三等奖：所投注的五位数的首或尾连续两位数与开奖号码首或尾连续两位数相同且顺序一致，中奖金额20元。

以开奖号码为12345为例：

一等奖，所投注的五位数与开奖号码全部相同且顺序一致，如12345；二等奖，所投注的五位数的首或尾连续三位数与开奖号码首或尾连续三位数相同且顺序一致，如12356，34345；三等奖，所投注的五位数的首或尾连续两位数与开奖号码首或尾连续两位数相同且顺序一致，如12456，34545。

**第十一条**　附加玩法的资金管理、兑奖时间、期限、方法均同“时时彩”游戏规则。

**第十二条**　本附则自批准之日起实施。
