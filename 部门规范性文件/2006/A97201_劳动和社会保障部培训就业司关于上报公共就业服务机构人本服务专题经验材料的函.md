# 劳动和社会保障部培训就业司关于上报公共就业服务机构人本服务专题经验材料的函

## 劳动和社会保障部培训就业司关于上报公共就业服务机构人本服务专题经验材料的函（劳社培就司函〔2006〕62号）

各省、自治区、直辖市劳动和社会保障厅（局）：

为进一步推进就业服务"新三化"建设，促进全国公共就业服务机构人本服务的水平，提高就业服务质量和效率，为今年10月召开的有关会议做准备，我们拟在近期收集各地关于公共就业服务机构开展人本服务的专题经验材料。现将有关事项通知如下：

**一、**上报材料的专题范围

（一）就业服务功能拓展

1. 综合性服务场所功能专题。市、区级公共就业服务机构综合性服务场所根据服务对象需求设置和完善服务功能的情况，以及按照人本服务要求进行服务功能拓展和服务方式优化等方面的情况。

2. 街道、社区平台服务专题。街道、社区劳动保障工作平台按照工作目标要求，针对服务对象特点，采取的能够充分体现服务的人性化、高效化的服务措施。

3. 为用人单位服务专题。公共就业服务机构针对用人单位需求提供高质量服务、拓展服务领域的做法和实效。

（二）就业服务制度规范

1. 公共就业服务制度专题。包括完善失业人员登记和免费就业服务制度、就业困难群体再就业援助制度、政府出资购买服务和培训制度、公共就业服务统筹管理制度建设方面的情况。

2. 公共就业服务规范专题。公共就业服务机构（包括综合性服务场所和街道社区平台）在提供各项服务活动过程中，为保证公共服务性质所确定的规定性或禁止性事项，如招聘广告不得出现歧视性内容的具体规定等；以及为保证服务质量、提高服务效率所确定的承诺性事项，如对所有求职人员实行免费职业介绍服务，以及各项服务活动的具体时限规定等。

（三）三类群体专项服务

1. 就业困难群体就业援助专题。公共就业服务机构对就业困难群体实施就业援助方面的人本服务措施和取得的实际成效。

2. 新成长劳动力就业服务专题。公共就业服务机构对新成长劳动力以及高校毕业生提供专项就业服务方面的人本服务措施和取得的成效。

3. 农村劳动力转移就业服务专题。农村劳动力输出地或输入地的公共就业服务机构为进城务工的农村劳动者提供专项就业服务方面的人本服务措施和取得的成效。

（四）其他专项服务

1. 职业指导专题。发挥职业指导为就业服务提供有效支持作用，为各类人员提供针对性指导帮助，建立职业指导长效机制和建立跟踪指导服务机制方面的情况。

2. 信息服务专题。为各类用人单位和求职者提供及时、可靠、完整、准确的就业信息服务以及开展网上就业服务的情况。

3. 创业服务专题。为扶持劳动者创业而提供相关配套服务方面的情况。

（五）工作体系建设

1. 公共就业服务机构体系建设专题。加强市、区、街道、社区就业服务体系的机构、队伍建设（包括机构性质、人员编制、工作职责）和落实工作经费保障方面的情况。

2. 公共就业服务人员队伍建设专题。公共就业服务机构（包括综合性服务场所和街道社区平台）在工作人员业务能力培养，以及职业指导人员、职业信息分析人员和劳动保障协理员的专业队伍建设方面的成功经验。

3. 公共就业服务信息技术应用专题。公共就业服务机构充分借助信息技术手段，提高就业服务质量和服务效率方面的成功经验。

4. 公共就业服务机构绩效管理专题。公共就业服务机构在加强内部管理，加强绩效考核，建立激励与约束机制方面的情况。

（六）工作中其他能够体现人本服务的做法和经验。

**二、**上报材料具体要求

（一）各省、自治区、直辖市劳动保障部门要组织本地区各级公共就业服务机构积极参与此次人本服务专题经验材料征集活动。

（二）每篇经验材料一般只包含一个主题。一个地区可以提供多个专题的经验材料。

（三）经验材料应紧紧围绕专题，结合工作实际，突出重点，力求有思路、有做法、有效果、有特色。

（四）每篇经验材料文字在3000字以内，简明扼要，重点突出。按照正文3号仿宋字、A4纸进行排版。

（五）请各省、自治区、直辖市劳动保障部门于9月25日前提交书面稿的电子版，以便汇总整理。
