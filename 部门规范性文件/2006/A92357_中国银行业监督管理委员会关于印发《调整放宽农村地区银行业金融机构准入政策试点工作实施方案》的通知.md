# 中国银行业监督管理委员会关于印发《调整放宽农村地区银行业金融机构准入政策试点工作实施方案》的通知

## 中国银行业监督管理委员会关于印发《调整放宽农村地区银行业金融机构准入政策试点工作实施方案》的通知（银监发〔2006〕98号）

内蒙古、吉林、湖北、四川、甘肃、青海银监局：

现将《调整放宽农村地区银行业金融机构准入政策试点工作实施方案》印发给你们，请遵照执行。

调整放宽农村地区银行业金融机构准入政策是支持社会主义新农村建设、改善农村地区金融服务落后状况的重大举措，各银监局在具体工作中要坚持“既要积极又要稳妥”的方针，要积极开展工作的同时，注意防止一哄而起和行政干预，加强监管，防范风险，使这项工作健康推进。在实施过程中如遇到问题，请及时报告银监会。

二○○六年十二月三十一日

调整放宽农村地区银行业金融机构准入政策试点

工作实施方案 为落实《中国银行业监督管理委员会关于调整放宽农村地区银行业金融机构准入政策更好支持社会主义新农村建设的若干意见》（银监发〔2006〕90号，以下简称《若干意见》） ，认真做好调整放宽农村地区银行业金融机构准入政策试点的组织实施工作，特制定本方案。

**一、**目标和原则

通过实施调整放宽农村地区银行业金融机构准入政策试点，促进农村地区形成投资多元、种类多样、覆盖全面、治理灵活、服务高效的银行业金融服务体系，从根本上解决农村地区银行业金融机构网点覆盖率低、金融供给不足、竞争不充分等问题，更好地改进和加强农村金融服务，支持构建和谐社会和社会主义新农村建设。

按照《若干意见》“先试点、后推开；先中西部、后内地；先努力解决服务空白问题、后解决竞争不充分问题”的原则，应选择在金融服务空白或不足的县（市）、乡（镇）和行政村试点，因地制宜确定试点机构类型，强化准入监管，在总结试点经验的基础上，完善办法，稳步推开。

**二、**组织领导

为要加强对调整放宽农村地区银行业金融机构准入政策试点工作的组织领导，各银监局要成立专门的领导组织和工作机构，主要领导亲自挂帅，有关部门负责人参加，抽调骨干力量具体负责组织实施。

（一）银监会成立调整放宽农村地区银行业金融机构准入政策试点工作领导小组（以下简称试点工作领导小组）。

试点工作领导小组下设办公室，工作人员由合作部银行机构市场准入处、农村信用社市场准入处和相关处人员，法规部负责行政许可政策的处长，银行一部、银行二部、银行三部、银行四部、非银部市场准入处处长，以及试点省（区）抽调人员组成。各监管部门市场准入处长、法规部负责行政许可政策的处长为试点工作领导小组办公室联络员。

试点工作领导小组的主要职责是：研究决定调整放宽农村地区银行业金融机构准入政策实施的重大事项；批准调整放宽农村地区银行业金融机构准入政策的工作方案、配套制度和办法；组织调查调整放宽农村地区银行业金融机构准入政策的实施情况，研究解决试点工作中的相关政策和制度问题；对调整放宽农村地区银行业金融机构准入政策的实施情况作出评价。

试点工作领导小组办公室的主要职责是：落实试点工作领导小组各项决定、政策和工作部署；制定实施工作方案、相关制度、办法和细则；受试点工作领导小组委托负责对外联系和协调事宜；组织指导相关省（区）的试点工作；编发专题简报，总结、交流各地试点经验；组织对外宣传工作等。

（二）各试点省（区）银监局、银监分局要成立试点工作领导小组及办公室，由局长任组长，分管副局长任副组长，合作处（科）及相关处（科）室负责人参加，负责协调地方政府和相关部门落实试点县（市）、乡（镇）和行政村，制定试点工作方案并具体组织实施。

**三、**步骤和时间

调整放宽农村地区银行业金融机构准入政策试点工作，要制定计划，明确实施步骤，严格、规范地按步骤和规定时间，精心组织，积极稳妥实施。具体步骤和时间安排如下：

（一）制定试点工作实施方案。对组织领导、相关制度设计、试点选择、准入工作实施作出具体安排，2006年12月31日前完成。

（二）开展快速调查。对各试点省（区）农村地区银行业金融机构设置和金融服务情况进行快速调查，提出试点县（市）、乡（镇）和行政村备选名单，为确定试点县（市）、乡（镇）和行政村做好准备，2007年1月20日前完成。

（三）制定管理规定和组建工作指引。组织人员集中时间分组起草各类试点机构的管理暂行规定和组建工作指引，争取2007年1月10日前完成初稿，1月20日前定稿并下发施行。各试点省（区）银监局负责制定本省（区）具体试点工作方案，在2007年1月31日前完成。

（四）组织培训。通过电视电话系统对6个试点省（区）的银监局、银监分局局长、主管副局长、相关部门负责人及具体工作人员进行培训，培训的内容为《若干意见》的各项政策、有关管理暂行规定和组建工作指引，2007年1月20日前完成。

（五）选择试点县（市）、乡（镇）和行政村。《若干意见》确定试点的机构类别包括：村镇银行、信用合作组织、商业银行和农村合作银行专营贷款业务的全资子公司、本地或异地商业银行和农村合作银行分支机构。首批试点的6个省（区）每省（区）可按机构类别原则上选择5-10个地方进行试点。选择试点县（市）、乡（镇）和行政村，由各试点省（区）银监局根据银监会农村地区银行业金融机构设置和服务充分性调查提出的备选名单，协商省（区）、县（市）两级政府和相关部门于2007年1月31日前确定。

（六）组织试点。首批6个省（区）试点工作分两个阶段进行：第一阶段从2007年2月上旬开始，到9月末结束，每个省（区）原则上可按机构类别选择3-6个地方进行试点；第二阶段从2007年10月初开始至年底结束，根据第一阶段试点情况适当扩大试点机构数量。2008年试点范围再扩大到15个省（区）左右。为确保试点工作顺利实施，各试点省（区）银监局负责组织推动试点工作并落实发起人，银监会试点工作领导小组办公室对试点工作进行具体指导。

（七）试点工作总结。2007年底前对首批试点工作进行总结，评估相关政策的合理性和科学性，网点覆盖和支农服务充分情况，以及政策实施效果，为下一步工作提供决策依据。

**四、**总体要求

（一）搞好宣传动员。一是各试点省（区）银监局要及时主动向本省（区）党委、政府汇报调整放宽农村地区银行业金融机构准入的相关政策，请求地方党委、政府帮助确定试点县（市）、乡（镇）和行政村，协调财政、税务、工商等部门给予适当政策支持。二是进行广泛宣传，协调宣传部门及相关媒体，充分利用电视、报刊等宣传工具，积极广泛地宣传调整放宽农村地区银行业金融机构准入政策的目的、必要性和重大意义；宣传银监会的各项重大部署以及调整放宽农村地区银行业金融机构准入政策试点的进展情况、经验做法和成效。各省（区）银监局还要协调试点县（市）、乡（镇）和行政村采取召开动员大会、增发报刊专刊、编发简报或开辟专栏、制作黑板报等多种方式面向社会广泛宣传，形成有利于调整放宽农村地区银行业金融机构准入政策实施的舆论氛围。

（二）加强制度建设。调整放宽农村地区银行业金融机构准入政策是银监会积极支持社会主义新农村建设的重大举措，旨在解决农村地区银行业金融机构网点空白和金融服务不充分等问题，银监会各部门要高度重视，密切配合，认真负责，及时制定相关管理规定和组建工作指引，各试点省（区）银监局要制定具体试点工作方案，对每个阶段工作都要提出具体要求，做到任务明确、重点突出、措施具体、责任落实，为实施试点工作奠定基础。

（三）注意保持稳定。调整放宽农村地区银行业金融机构准入政策涉及面广，敏感度高，情况复杂，在试点中，要注意方式方法，认真做好政策的宣传解释工作，避免炒作。各试点省（区）银监局要制定突发事件风险处置预案，及时解决试点工作中出现的各种问题，积极、稳妥地开展试点工作，保持当地金融、社会的和谐稳定。

（四）加强监督管理。试点省（区）的各级银行业监管部门务必把调整放宽农村地区银行业金融机构准入政策试点工作作为监管工作的重中之重，切实把思想和行动统一到银监会的总体部署和要求上来，积极主动协调省（区）、县（市）政府全力组织推动落实发起人，引导各国有商业银行、股份制商业银行等金融机构和各类资本投资农村地区银行业金融机构。要有效配置监管资源，县（市）监管办事处人员拟整合到地（市）分局的，整合后的人员原则上应主要配备到合作金融监管部门；根据准入政策调整后监管工作的实际，需要保留监管办事处的，应予以保留，稳定县（市）监管办事处队伍，加强对试点县（市）农村地区新设银行业金融机构的审慎、动态和持续监管，确保调整放宽农村地区银行业金融机构准入政策试点工作顺利平稳进行，取得成效。

（五）建立报告制度。各试点省（区）银监局要建立规范的信息交流和反馈制度，及时向银监会报送试点作法和经验，并按月报送试点工作进展情况，2007年底上报试点工作总结。银监会领导小组办公室要及时总结和组织交流各地开展试点工作的做法和经验。
