# 中国共产党国家民族事务委员会党组关于张春雨等3同志任职的通知

## 中国共产党国家民族事务委员会党组关于张春雨等3同志任职的通知（民党发〔2006〕21号）

西北第二民族学院：

经研究并商中共宁夏回族自治区党委同意，任命张春雨同志为西北第二民族学院党委副书记、院长；任命雷崇民同志为西北第二民族学院党委副书记、纪委书记；任命闵文义同志为西北第二民族学院副院长，增补为党委委员。以上3同志的任职时间2006年4月6日算起，试用期1年。

中国共产党国家民族事务委员会党组

二○○六年四月二十四日
