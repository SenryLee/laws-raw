# 民政部最低生活保障司关于低保软件2.0版实施有关问题的通知

民政部最低生活保障司关于低保软件2.0版实施有关问题的通知

各省、自治区、直辖市民政厅（局）低保处（局、中心），新疆生产建设兵团民政局救灾（低保）处：

为进一步加强低保软件2.0版实施的技术支持和服务工作，促进低保软件的顺利实施，现就有关问题通知如下：

**一、**低保软件2.0版和数据转换程序使用常见问题解答。为了加强低保软件技术支持和服务工作，应各地的要求，我们组织力量编写了低保软件2.0版和数据转换程序使用常见问题解答，于近期下发各省，请各省收到后，尽快下发街道以上各级低保软件操作人员（发放数量统计表附后）。

**二、**低保软件2.0版补丁问题。针对低保软件2.0版运行存在的问题，由软件技术人员作了软件程序补丁，单机版：一是数据检查，二是删除重复数据；网络版：一是增加了数据检查功能，二是修改数据备份功能，三是增加定制查询项目，四是删除重复数据。补丁的具体内容和使用请下载和查看补丁包。

**三、**低保数据录入和汇总问题。已完成低保数据录入的地方，要逐级检查，严格把关，确保数据质量。要运用软件的数据检查功能，认真清理跨地区重复领取低保金人员。没有完成低保数据录入的地方，要抓紧组织录入，今年底全部完成录入工作，明年2月底前，各省将低保汇总数据报民政部。

低保软件2.0版和数据转换程序使用常见问题解答（电子版）和软件补丁包，请各省登录民政部网站“业务工作”版块，点击进入“城市低保”栏目下载，或直接在民政部网站“公告板”栏目点击下载，并将单机版和网络版补丁分别下发各级低保软件操作人员。下载地址：
