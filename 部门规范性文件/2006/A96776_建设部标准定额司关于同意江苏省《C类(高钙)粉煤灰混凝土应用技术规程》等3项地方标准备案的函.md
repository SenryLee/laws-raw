# 建设部标准定额司关于同意江苏省《C类(高钙)粉煤灰混凝土应用技术规程》等3项地方标准备案的函

## 建设部标准定额司关于同意江苏省《C类（高钙）粉煤灰混凝土应用技术规程》等3项地方标准备案的函（建标标备便[2006]94号）

江苏省建设厅：

你厅关于报送工程建设地方标准备案的函收悉。经研究，同意《C类（高钙）粉煤灰混凝土应用技术规程》等3项地方标准作为“中华人民共和国工程建设地方标准”备案，备案号为：

《C类（高钙）粉煤灰混凝土应用技术规程》　J10865-2006

《江苏省建筑施工现场装配式轻钢结构活动板房技术规程》 J10866-2006

《江苏省建筑施工安全生产条件评价规范》　　J10867-2006

该项标准的备案公告，将刊登在近期出版的《工程建设标准化》刊物上。

二OO六年九月六日
