# 商务部西亚非洲司关于举行中国和肯尼亚经贸混委会会议的通知

中肯经济贸易混合委员会会议将于今年4月底在肯举行。届时，双方将全面回顾近年来双边经贸合作情况，磋商解决存在的问题，研究进一步深化经贸关系的举措。

为做好会议的准备工作，敬请有关部门、地方和企业将近年来在开展贸易、投资与合作等领域的双边合作中遇到的问题、项目情况以及有关合作要求和建议于3月12日前以网上留言或书面形式告商务部西亚非洲司。
