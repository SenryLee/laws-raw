# 中国银行业监督管理委员会关于批准华商银行修改章程的函

华商银行：

你行行长彭观贵先生2006年1月20日致我会的函收悉。

根据《中华人民共和国外资金融机构管理条例》（国务院令第340号）和《中华人民共和国外资金融机构管理条例实施细则》（中国银行业监督管理委员会令2004年第4号）的有关规定，兹批准你行对章程的修改。

修改后的章程（见附件）自本批文日期起生效。

附件：华商银行章程（略）

二00六年四月三日
