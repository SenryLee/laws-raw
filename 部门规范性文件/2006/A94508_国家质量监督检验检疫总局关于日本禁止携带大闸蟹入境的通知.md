# 国家质量监督检验检疫总局关于日本禁止携带大闸蟹入境的通知

## 国家质量监督检验检疫总局关于日本禁止携带大闸蟹入境的通知(国质检动函[2006]901号)

各直属检验检疫局：

近日，日本环境省通知，日本已于2006年2月将鲜活大闸蟹列为日本《外来生物法》控制对象，禁止旅客携带入境。但目前国内不少旅客不了解这一情况，将大闸蟹带往日本，在成田机场等口岸被查出，被日方作没收处理。

请各直属检验检疫局加大宣传力度，在出境口岸醒目处设置宣传标识，提醒广大出境旅客遵守日本方面的规定。

二〇〇六年十一月十四日
