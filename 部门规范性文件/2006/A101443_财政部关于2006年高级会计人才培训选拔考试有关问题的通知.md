# 财政部关于2006年高级会计人才培训选拔考试有关问题的通知

## 财政部关于2006年高级会计人才培训选拔考试有关问题的通知（财会便[2006]18号）

各省、自治区、直辖市财政厅（局）会计处，中共中央直属机关事务管理局会计资产处，国务院机关事务管理局财务管理司会计处，中国人民解放军总后勤部财务部会计局，中国人民武警部队财务部会计处，铁道部财务司会计处：

开展高级会计人才培养工作是实施人才强国战略的重要举措。为做好2006年企业类、行政事业类高级会计人才培训班学员选拔工作，现就有关事项通知如下：

**一、**切实做好考试的宣传及解答工作。今年是高级会计人才培训选拔考试的第二年，同时也是通过“海选”方式招收培训班学员的第一年，前来咨询、报名的考生较多，请你们根据《财政部关于开展高级会计人才（行政事业类）培训的通知》（财会[2006]5号）和《财政部关于开展2006年高级会计人才（企业类）培训的通知》（财会[2006]6号）以及《中国财经报》第3082期（2006年3月24日）《财政部会计司负责人就高级会计人才培养答记者问》的精神，做好有关培训的宣传及解答工作。

**二、**认真做好考试组织工作。人才培养的关键在于人才的选拔，选拔考试是选拔程序的重要环节。请你们提高对本次选拔考试的认识，组织好考生报名工作，做好考场安排及考试保密工作，确保考试顺利进行。

**三、**为保证试卷能够在规定时间内安全及时地送达各地，请你们认真填写附表一有关内容，并于5月9日前传真至我司会计人员管理处。

**四、**为便于掌握考试情况，请你们于6月4日上午考试结束后，认真填写附表二有关内容，及时传真至我司会计人员管理处。

**五、**考试结束后，请你们将试卷和申报材料整理好后，及时报送至北京国家会计学院。其中，北京、天津、河北、中直局、国管局、铁道部、解放军、武警的报送时间为6月4日16：00前，其他地区的报送时间为6月6日12：00前。如需接站，请提前将乘坐航班传真至北京国家会计学院。
