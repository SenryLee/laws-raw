# 建设部住宅产业化促进中心关于山东省济南山景·明珠花园等九个项目通过A级住宅性能预审的通知

山东省住宅产业化办公室：

我中心会同你办公室共同组成住宅性能评定专家组，对济南市市中区房地产开发（集团）总公司开发的济南山景·明珠花园，烟台山海花园投资开发有限公司开发的烟台天籁·山海花园生态居住区，烟台天安置业有限公司开发的烟台天安·山水龙城小区，山东嘉士德投资置业有限公司开发的烟台海天·四季花城一期工程，对威海五洲基业房地产开发有限公司开发的威海五洲·太阳城天琴园、天燕园、天龙园，对威海豪迈房地产开发有限公司开发的威海海韵华府，对兖矿集团日照圣园置业有限公司开发的日照四季圣园小区高层区，莱芜方兴置业有限公司开发的莱芜鲁能·方兴苑，对莱芜广厦集团有限公司开发的莱芜东海花园，进行了住宅性能认定预审。

经专家组听取汇报，审阅资料，提问答辩，打分评审，认为以下住宅通过建设部A级住宅预审：（1）济南山景·明珠花园1～6、9～11、14栋，共10栋住宅；（2）烟台天安·山水龙城小区第01－1～01－15，1～27栋，共42栋；（3）烟台天籁·山海花园生态居住区第A1～A6、B-8-1～B-8-3、D-1、J1～J12、J′1、J′2栋，共24栋；（4）烟台海天·四季花城小区一期工程第1～20栋，共20栋住宅；（5）威海五洲·太阳城天琴园第301～334栋，天燕园第201～215栋，共49栋住宅；威海五洲·太阳城天龙园第401～425栋，共25栋住宅；（6）威海海韵华府B区第4～26栋，共 23栋住宅；（7）日照四季圣园小区高层区第1-3栋， 共3栋住宅；（8）莱芜鲁能·方兴苑第 1～3、5～13、15～23、25～31栋， 共 28 栋；（9）莱芜东海花园第 1-38栋， 共 38 栋住宅。其中，烟台天安·山水龙城小区第01－1～01－15，1～27栋，共42栋住宅，预审评定等级为2A级；烟台天籁·山海花园生态居住区第A1～A6、B-8-1～B-8-3、D-1、J1～J12、J′1、J′2栋，共24栋住宅，预审评定等级为2A级；莱芜鲁能·方兴苑第 1～3、5～13、15～23、25～31栋，共 28 栋住宅；预审评定等级为2A级；威海五洲·太阳城天龙园第401～425栋，共25栋住宅，预审评定等级为3A级。以上项目均列入建设部A级住宅性能认定工作计划。

希望开发建设单位按照专家的意见，对照《住宅性能评定技术标准》GB/T50362的要求，完善设计方案，精心设计，精心施工，以便终审时达到预定的性能等级。

二○○六年四月十六日
