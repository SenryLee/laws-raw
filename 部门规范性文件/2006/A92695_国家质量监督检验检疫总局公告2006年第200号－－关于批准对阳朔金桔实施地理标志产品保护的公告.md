# 国家质量监督检验检疫总局公告2006年第200号－－关于批准对阳朔金桔实施地理标志产品保护的公告

## 国家质量监督检验检疫总局公告（2006年第200号）

关于批准对阳朔金桔实施地理标志产品保护的公告

根据《地理标志产品保护规定》，我局组织了对阳朔金桔地理标志产品保护申请的审查。经审查合格，现批准自即日起对阳朔金桔实施地理标志产品保护。

**一、**保护范围

阳朔金桔地理标志产品保护范围以广西壮族自治区阳朔县人民政府《关于划定阳朔金桔产品原产地域范围的通知》（朔政发［2005］28号）提出的范围为准，为广西壮族自治区阳朔县现辖行政区域。

**二、**质量技术要求

（一）品种。

金弹种（Fortunella　Crassifolia　Swingle）中的大金弹品种。

（二）立地条件。

海拔在750m以下，成土母质为硅质岩或砂页岩发育而成的沙壤土，有机质含量≥1.0%；相对地下水位大于1.0m，pH值5.0至6.5。

（三）栽培管理。

1. 苗木繁殖：采用实生繁殖和嫁接繁殖。

（1）实生苗：从无检疫性病虫害、品种纯正的优良单株上采集种子播种育苗。

（2）嫁接苗：选用枳壳砧或本砧，从无检疫性病虫害、品种纯正的优良母树上采集枝条作接穗，嫁接育苗。

2. 定植：每公顷种植密度≤1650株，定植时间为每年的2至3月。

3. 土壤管理及施肥：果园实行深翻改土和树盘覆盖。施肥以有机肥为主，化肥为辅。有机肥施肥量：每公顷≥30吨。

4. 整形整剪：整形采用多主枝半圆头形或自然圆柱形；修剪以疏剪为主，保证树冠通风透光。

5. 树冠盖膜，留树保鲜：在10月中下旬果实着色前期，用塑料膜覆盖树冠，进行避雨栽培，防止裂果落果，直至果实采收完毕。

（四）果实采收与分级。

果实采收自11月开始实行分批采收的方法，先成熟的果先采，采收后按如下标准进行分级。

（五）质量特色。

1. 感观特色：果皮光滑，油胞小而密生，果形为椭圆形或卵状椭圆形，果实色泽为橙黄色至橙红色，有特殊的金桔芳香味，果皮质脆爽口，果肉蜜甜化渣。

2. 理化指标：可溶性固形物含量≥13%，总酸量≤0.8%，固酸比≥15.0：1，可食率≥95%，优级单果重≥22克，一级单果重≥18克，二级单果重≥14克。

**三、**专用标志使用

阳朔金桔地理标志产品保护范围内的生产者，可向广西壮族自治区阳朔县质量技术监督局提出使用“地理标志产品专用标志”的申请，由国家质检总局公告批准。

自本公告发布之日起，各地质检部门开始对阳朔金桔实施地理标志产品保护措施。
