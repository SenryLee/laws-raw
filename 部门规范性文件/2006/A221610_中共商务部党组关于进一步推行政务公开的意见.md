# 中共商务部党组关于进一步推行政务公开的意见

为贯彻党的十六大和十六届四中、五中全会精神，提高我部依法行政水平，加强对行政权力的监督，根据中共中央办公厅、国务院办公厅《关于进一步推行政务公开的意见》（中办发［2005］12号） ，现就我部进一步推行政务公开提出如下意见。

**一、**充分认识政务公开的重要意义

推行政务公开，是实践“三个代表”重要思想，坚持立党为公、执政为民，加强党的执政能力建设的具体体现；是发展社会主义民主，建设社会主义政治文明，构建社会主义和谐社会的必然要求；是落实依法治国基本方略，推进依法行政的重要举措；是建立健全惩治和预防腐败体系，形成行为规范、运转协调、公正透明、廉洁高效的行政管理体制的重要内容。

推行政务公开是党中央、国务院部署的一项政治任务。党的十五大、十六大都明确提出，要推行政务公开。2000年12月，中共中央办公厅、国务院办公厅发出《关于在全国乡镇政权机关全面推行政务公开制度的通知》（中办发［2000］25号），对乡镇政务公开作出部署。2004年3月，国务院印发《全面推进依法行政实施纲要》（国发［2004］10号），把行政决策、行政管理和政府信息的公开，作为推进依法行政的重要内容。2005年1月，党中央印发《建立健全教育、制度、监督并重的惩治和预防腐败体系实施纲要》（中发［2005］3号），明确提出“健全政务公开、厂务公开、村务公开制度”。2005年3月24日，中共中央办公厅、国务院办公厅又下发了《关于进一步推行政务公开的意见》，对国务院各部门推行政务公开提出明确要求。大力推行政务公开，已经是箭在弦上，不得不发。

我部是全国商务工作的主管部门，承担的任务光荣而艰巨，需要极大地提高执政能力和管理水平。商务工作与经济利益密切相关，是利益、权力比较集中的领域，特别需要加强对权力运行的制约。积极推进政务公开，将行政权力的运作放在公开、透明的环境下，对于提高行政效能、方便群众办事、促进依法行政、保证干部队伍清正廉洁，具有十分重要的意义。全国政务公开领导小组已经把我部列为中央国家机关政务公开工作的试点单位。

我部历来对政务公开工作十分重视。近年来，先后下发了《商务部政务公开暂行办法》、《商务部办公厅关于进一步做好政务公开工作的通知》，采取措施积极推进政务公开，并取得了明显成效。在新的形势下，我部提出进一步推行政务公开，就是要按照中央的要求，扩大政务公开的广度，加大政务公开的深度，不但做到信息公开，还要做到对权力运行本身的公开；不但公开办事结果，还要公开办事过程。我部各单位党政领导班子、全体党员干部，要统一思想、端正认识，按照党中央、国务院的要求和部党组的部署，积极行动起来，全力以赴，真抓实干，务必使我部政务公开工作取得实效，保证和促进商务事业健康发展。

**二、**我部政务公开的指导思想、基本原则和工作目标

（一）我部政务公开的指导思想：

以邓小平理论和“三个代表”重要思想为指导，贯彻党的十六大、十六届四中全会和《全面推进依法行政实施纲要》、《关于进一步推行政务公开的意见》精神，以全心全意为人民服务为宗旨，以保障人民群众民主权利为出发点，以促进依法行政为标尺，大力开展“阳光政务工程”建设，提高办理行政事项的透明度和效率，加强对行政权力的监督，改进机关作风，更好地为商务事业健康发展服务。

（二）我部政务公开的基本原则：

坚持严格依法、全面真实的原则，严格按照法律法规和有关政策规定，对各类行政事项（除涉及国家秘密和依法受到保护的商业秘密、个人隐私之外）如实公开。

坚持及时便民的原则，对应该公开的事项，采用方便、快捷的方式，及时公开，方便群众办事。

坚持权力制衡的原则，逐步地将行政事项的决策（决定）权、执行权、监督权分离，相互制衡，保证权为民所用。

坚持统筹规划、稳步推进的原则，从我部实际情况出发，由点到面，稳步推进，成熟一批纳入一批。

坚持统一规范的原则，按照标准化要求，对我部现有的规章制度进行整合和规范，形成我部统一的行政管理体制和制度体系。

（三）我部政务公开的目标：

通过开展“阳光政务工程”建设，使政务公开成为我部办理各类行政事项的一项基本制度，形成我部行为规范、运转协调、公正透明、廉洁高效的行政管理体制，把我部建设成服务型、法治型的政府机关。

**三、**我部政务公开的主要内容

政务公开，就是政府办理各类行政事项（涉密除外），向社会或在一定范围内如实公开 。

我部推行政务公开，就是将我部办理的各类行政事项，除涉及国家秘密和依法受到保护的商业秘密、个人隐私之外，向社会或在部内如实公开 。

我部办理的各类行政事项，主要分为两个部分：

1、面向社会的行政事项，包括行政许可、行政监督管理、公共服务等事项；

2、部内行政事项，包括人事管理、财务管理、后勤管理等事项。

要通过开展“阳光政务工程”建设，将我部办理的各类行政事项的相关信息和行政权力运行的情况，包括行政决策、执行、监督的程序、方法、结果等，区分不同情况、在不同范围内公开。

**四、**我部政务公开的主要形式

我部面向社会的行政事项和部内行政事项，采取不同的公开形式。

（一）办理面向社会的行政事项，主要采取现场公开、网上公开、社会公开等方式。

1、现场公开。

根据《中华人民共和国行政许可法》的有关规定，建立统一对外的商务部行政事务服务中心，实行“一个窗口对外”。在商务部行政事务服务中心内，将办理行政许可、行政监督管理事项的法律依据、申请条件、办理程序、办理时限以及需要提交的全部材料的目录和申请书示范文本等，现场予以公开。

为适应政务公开的要求，我部办理对外的行政事项，实行“前统后分”的办理机制，即：统一受理行政事项的申请；然后由部内各个司局依照职责分别办理。

根据国务院关于《商务部主要职责内设机构和人员编制规定》和我部关于《商务部各司（厅、局）主要职能和内设机构》的规定，部各司（厅、局）对行政许可和行政监督管理事项的办理，其职责和权限保持不变。各司（厅、局）按照职责权限，分别办理行政事项。

在配额许可证事务局的基础上，组建商务部公共事务服务局，将配额许可证事务局的职能职责，平移入公共事务服务局，并由该局承担商务部行政事务服务中心的日常管理和各项事务。

在部行政事务服务中心办事窗口，有关职能司（厅、局）派驻工作人员，统一受理本单位承办事项的申请，统一送达本单位承办事项的结果，实行“一站式服务”。 也可委托商务部公共事务服务局工作人员办理。

实行“连锁办公方式”，即：需要我部两个或两个以上司（厅、局）共同办理的行政事项，由牵头司（厅、局）在其办事窗口负责受理；然后按照规定的程序，逐次流转；每个司（厅、局）按照承诺时限，限时办结；事项办理结果，由牵头司（厅、局）在其办事窗口送达行政相对人。

实行“即时办公方式”，即：对条件明确、手续简明、行政主体单一的行政事项如年检、年审、换领行政文书等，可视情况由商务部公共事务服务局或由主管司（厅、局）在办事窗口即时签发。

2、网上公开。

推进电子政务系统建设。配合现场公开，将我部办理行政许可和行政监督管理事项的依据、条件、程序、期限、要求以及结果等，在我部政府网站公开，方便行政相对人查询和下载。逐步创造条件，扩大网上查询、咨询、投诉、求助、审批、办证等服务项目和范围。

通过我部政府网站，将我部承担的公共服务类别的行政事项，诸如国内市场监测信息、进出口贸易预警信息、贸易政策和法律法规等，予以公开，充分发挥政府的服务职能。

3、社会公开。

完善部新闻发布制度，通过新闻发布会定期发布政务信息；通过公告、文告、政务公开栏、办事指南、报刊等形式，公开我部政务信息。

（二）部内行政事项，按照有关规定在部内或者社会一定范围内公开。

负责办理部内行政事项的各司局，要根据部政务公开工作的统一要求和有关政策规定，在现有工作的基础上，继续推行政务公开，扩大公开的内容和范围，完善和健全公开的形式和方法。

**五、**加强政务公开的制度建设

制度建设是保障政务公开规范运行的必要条件。

建立健全主动公开和依申请公开制度。对于应当让社会公众广泛知晓或参与的事项，要及时主动向社会公开。公开事项如变更、撤销或终止，要及时公布并作出说明。对于只涉及部分人和事的行政事项，要按照规定程序，向申请人公开。不宜公开或不能公开的，要做好解释工作。

建立健全办理各类行政事项的规章制度，把政务公开纳入制度化轨道。进一步健全行政许可、组织招标投标、“连锁办公方式”、“即时办公方式”等方面的规章制度，细化各项规则，严格各项纪律，形成我部规范化的行政制度体系，提高工作效率，规范行政行为，防止各种违规违纪行为。

建立健全政务公开评议制度。把政务公开纳入社会评议政风、行风的范围，请群众对政务公开的内容是否真实、准确、全面，时间是否及时，程序是否符合规定，制度是否落实到位等进行评议。

建立健全政务公开监督制度和责任追究制度，对办理行政事项实施监督。对工作不力、搞形式主义的，要严肃批评，限期整改；对弄虚作假、侵犯群众民主权利、损害群众合法利益、造成严重后果的，要严肃查处。

**六、**加强组织领导

为加强对政务公开工作的领导，成立商务部政务公开工作领导小组，统一领导和组织协调我部政务公开各项工作。

部党组书记、部长XXX任领导小组组长；部党组副书记、副部长于广洲，部党组成员、副部长廖晓淇，部党组成员、驻部纪检组组长徐敬业，任领导小组副组长。

领导小组成员单位有办公厅（含部保密委员会）、人事司、条法司、规财司、信息化司、机关党委、机关纪委、驻部监察局、许可证事务局、办公楼维修改造工程指挥部。领导小组下设办公室，挂靠办公厅，徐敬业同志兼任领导小组办公室主任。

我部各单位党政领导班子要从讲政治的高度，重视政务公开工作，切实加强领导。各单位“一把手”要亲自抓、负总责。要把政务公开列入本单位的重要议事日程，积极推进政务公开工作，及时解决工作中的问题。

我部各级党组织要加强宣传教育，提高广大党员干部的责任意识，营造推行政务公开的舆论氛围，调动党员干部投身改革、建功立业的积极性。

要加强对部机关工作人员的培训，为推行政务公开提供技术支持。财务部门要在资金上为政务公开工作提供必要的支持。 纪检监察部门要对政务公开工作实行监督。

部直属事业单位，各特派员办事处，各商会、协会、学会，参照执行。

中共商务部党组
