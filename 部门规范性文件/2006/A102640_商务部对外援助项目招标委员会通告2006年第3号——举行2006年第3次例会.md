# 商务部对外援助项目招标委员会通告2006年第3号——举行2006年第3次例会

## 商务部对外援助项目招标委员会通告（2006年第3号）

商务部对外援助项目招标委员会于2006年2月24日举行了2006年第3次例会。现将会议情况和决议通告如下：

**一、**审定了援几内亚比绍总统卫队宿舍等三项目施工任务的中标企业。该项目于2006年2月20日开标，江苏省建筑工程公司、广厦重庆第一建筑（集团）有限公司、威海国际经济技术合作股份有限公司、海南省建筑工程总公司、中铁二十三局集团有限公司、中国江苏国际经济技术合作公司、甘肃海外工程总公司、中国山东对外经济技术合作集团有限公司、中国重庆国际经济技术合作公司、广东新广国际集团有限公司、中铁五局（集团）有限公司和新疆国际经济合作公司12家投标单位均按时递交了投标书。中国上海外经（集团）有限公司和湖北省建筑工程集团有限公司弃权。根据商务部2005年修订试行的《对外援助成套项目施工任务评标原则》，在坚持“无标底竞争”方式和“合理低价中标”原则的基础上，经技术标定性评审和经济标定量综合评分等两阶段评标，招标委员会决定将该项目授标予海南省建筑工程总公司承担。

**二、**研究了援巴哈马体育场项目施工任务的招标方式。招标委员会决定采取有限邀请招标方式，邀请安徽省外经建设（集团）有限公司、齐鲁建设集团公司、山西建筑工程（集团）总公司、上海建工（集团）总公司、北京建工集团有限责任公司、青岛建设集团公司、湖南省建筑工程集团总公司、福建建工集团总公司、中国建筑工程总公司、烟台建设集团有限公司、中国土木工程集团公司、中国海外工程总公司、广东新广国际集团有限公司、广东省建筑工程集团有限公司、江苏省建设集团公司、中国有色金属工业第二十三冶金建设公司、重庆对外建设总公司、北京城建集团有限责任公司和浙江省电力建设总公司等19家企业参加该项目投标。有关发送招标文件等具体事宜另行通知。

**三、**研究了援厄瓜多尔集装箱检测设备项目的招标方式。招标委员会决定就该项目与清华同方威视技术股份有限公司进行议标。有关发送议标文件等具体事宜另行通知。

**四、**研究了援马达加斯加阿巴通德拉扎卡地区1：5万地球化学测量项目的招标方式。招标委员会决定就该项目与中国地震调查局进行议标。有关发送议标文件等具体事宜另行通知。
