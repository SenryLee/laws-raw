# 中国人民银行关于调整商业银行拆借资金限额的通知(2006)

## 中国人民银行关于调整商业银行拆借资金限额的通知（2006年2月15日　银发[2006]42号）

人民银行上海总部，各分行、营业管理部，各省会首府城市中心支行，全国银行间同业拆借中心，各国有商业银行、股份制商业银行：

根据各商业银行2005年12月末人民币存款余额，我行调整了同业拆借市场中113家商业银行的人民币同业拆借限额（见附表），请遵照执行。

请人民银行各分行、营业管理部，各省会（首府）城市中心支行将本通知转发至辖区内各城市商业银行。

全国银行间同业拆借中心应按照调整后的拆借限额重新设置电子交易系统中的相关要素。
