# 国家外汇管理局综合司关于新版国际收支统计监测系统并行试点后续有关工作安排的通知

*注：本篇法规已被：国家外汇管理局关于废止52件国际收支统计申报规范性文件的通知（发布日期：2010年8月9日，实施日期：2010年8月9日）废止

## 国家外汇管理局综合司关于新版国际收支统计监测系统并行试点后续有关工作安排的通知（汇综发[2006]117号）

国家外汇管理局江苏、浙江省分局，各中资外汇指定银行办公室：

新版国际收支统计监测系统（以下简称新版系统）经过国家外汇管理局江苏省分局、浙江省分局及其辖内有关银行10个月的试点，运行基本稳定，现就有关后续工作通知如下：

**一、** 部分银行结束并行试点的相关工作

（一） 本通知所指结束新旧系统并行、仅运行新版系统的银行是在浙江省和江苏省参加第一阶段和第二阶段新旧系统并行试点的中国建设银行、招商银行、杭州市商业银行、无锡市商业银行的网点。

（二） 对于2006年10月22日以前（含）发生的涉外收付款和贸易进出口核销所需的境内收付汇业务（以下统称“旧业务”）的处理。

1.对于2006年10月19日以前（含）发生的旧业务，上述4家银行的试点网点仍应当按照并行试点的要求，采取新旧系统并行的操作方式，并于2006年11月10日之前完成旧业务在旧版国际收支统计监测系统（以下简称“旧版系统”）中的处理工作。

2.对于2006年10月20日至10月22日期间（含）发生的旧业务，上述4家银行仅将旧业务数据录入旧版系统，不录入新版系统，并于2006年11月10日之前完成旧业务在旧版系统中的处理工作。

（三） 对于2006年10月23日以后（含）发生的涉外收付款和贸易进出口核销所需的境内收付汇业务（以下简称新业务），上述4家银行在浙江省和江苏省的试点网点不再执行新旧版系统并行操作，而仅运行新版系统，即通过新版系统向外汇局报送新业务数据。

（四） 上述4家银行应当于2006年10月20日至22日期间内按照《新版国际收支统计监测系统版本升级技术指引》（见附件）完成对新版系统的版本升级。新版系统所需安装介质及相关工作步骤等文档另行下发。

（五） 考虑到结束并行试点后可能发生的风险，上述4家银行在仅通过新版系统报送数据的同时，仍然应当保留旧版系统的正常运行，以便作为应急措施确保国际收支统计申报和进出口核销工作的正常进行。

（六） 上述4家银行应当于2006年11月13日之前将其旧业务在旧版系统中的处理情况和新业务在新版系统中的运行情况报告国家外汇管理局江苏省分局和浙江省分局（以下简称“试点分局”），试点分局应于11月15日之前进行汇总并报告国家外汇管理局。

**二、** 新版系统版本升级的有关工作

（一）试点分局和除上述4家银行以外的其他试点银行（以下简称其他试点银行）应当于2006年10月20日至10月22日期间内按照《新版国际收支统计监测系统版本升级技术指引》的要求完成新版系统版本升级工作。

（二）新版系统版本升级后，其他试点银行仍应按照第二阶段新版系统试点的要求进行新旧版系统并行操作。

（三）其他试点银行应于2006年11月10日前将第二阶段的试点情况及新版系统版本升级以后的试点运行情况以书面形式报国家外汇管理局。

**三、** 新版系统版本升级后，试点分局应针对申报子系统考核考评功能和分析子系统进行进一步测试，并将发现的问题及时反馈国家外汇管理局。

**四、** 试点分局在收到本通知后，应及时将其转发给辖内所有试点银行。

**五、** 试点银行应当按照《国家外汇管理局综合司关于开展新版国际收支统计监测系统培训工作的通知》（汇综发［2006］104号）的要求，按时保证质量完成其本系统内所有有关银行网点的新版系统培训工作。

**六、** 对于试点分局和试点银行在结束新旧系统并行，仅运行新版系统的过程中遇到的问题，应当及时反馈给国家外汇管理局。

附件：

新版国际收支统计监测系统版本升级技术指引

**一、** 概述

根据新版国际收支统计监测系统（以下简称新版系统）前期试点和问题反馈情况，国家外汇管理局对新版系统功能进行了优化和完善，并决定在2006年10月20日至22日进行新版系统版本升级。为了保持新版系统版本一致，试点分局和试点银行均应按照本技术指引开展版本升级工作。

**二、** 新版系统版本升级的主要内容

（一） 完善了银行版接口数据导入功能，加强了数据检查，解决了多任务并发可能带来的系统隐患；

（二） 完善了进/出口核销系统数据接口，解决了报关日期、结算方式、备案表号、付汇性质等有关问题；

（三） 完善了涉外收入限额申报有关功能；

（四） 完善了数据核查、考核、考评等有关功能；

（五） 丰富了数据交换平台功能，提高了数据传输的可靠性。

**三、** 任务描述

（一） 为减轻试点分局和试点银行（以下统称“试点单位”）的工作负担，前期试点的基础性工作（包括单位基本情况表、金融机构基本情况表等基础信息）在新版系统版本升级时将予以保留。

（二） 新版系统申报子系统服务器端版本由V1.0 20060515升级到V1.0 20060831，申报子系统客户端版本升级至V1.0.6831.17350（6831），数据交换平台由V1.11 20060515升级到V1.11 20060821，升级工作由各试点单位自行完成，国家外汇管理局提供技术支持。

（三） 新版系统分析子系统版本升级到V1.0，升级工作由国家外汇管理局统一实施。

（四） 新版系统版本升级完成后，国家外汇管理局江苏、浙江省分局正式运行生产系统，中国建设银行、招商银行、杭州市商业银行、无锡市商业银行（以下简称4家银行）向外汇局生产系统报送数据。其他试点银行继续保持新旧系统并行模式。

**四、** 时间安排

10月20日至22日，各试点单位暂停运行新版系统，期间发生的业务数据只录入旧版系统。

10月20日，各试点单位统一实施新版系统版本升级工作。新版系统版本升级所需安装介质及相关工作步骤等文档由国家外汇管理局统一制作，另行下发。

10月21日至22日，上述4家银行分别与国家外汇管理局及试点分局进行联调测试。联调测试完成后，应清理生产环境中测试数据。

从10月23日开始上述4家银行不再执行新旧系统并行操作，仅运行新版系统。其他试点银行继续保持新旧系统并行的模式。

**五、** 具体实施步骤

（一） 试点分局

1. 备份生产环境申报子系统、模拟环境申报子系统以及内、外网数据交换平台数据库。

2. 全量重新安装生产环境申报子系统。

3. 增量升级安装模拟环境申报子系统。

4. 将上述4家银行前期试点录入的数据，除申报单及用户日志以外，恢复到生产环境申报子系统。

5. 全量重新安装内、外网数据交换平台。

6. 联调测试完成后，删除内、外网数据交换平台中应用类型为“BOP”的交换数据，删除生产环境申报子系统申报单数据，删除文件系统中的进/出口核销系统接口数据文件。

（二） 上述4家银行

1. 备份银行版和数据交换平台数据库。

2. 全量重新安装银行版。

3. 恢复除申报单及用户日志以外的数据。

4. 全量重新安装数据交换平台。

5. 联合测试完成后，删除数据交换平台中应用类型为“BOP”的交换数据，删除银行版中申报单数据，删除文件系统中的银行业务系统接口数据文件。

（三） 其他试点银行

1. 备份银行版和交换平台数据库。

2. 增量升级银行版。

3. 全量重新安装交换平台。

4. 恢复银行版和交换平台数据库。
