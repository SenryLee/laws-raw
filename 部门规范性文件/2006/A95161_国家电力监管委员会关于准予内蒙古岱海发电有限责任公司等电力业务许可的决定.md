# 国家电力监管委员会关于准予内蒙古岱海发电有限责任公司等电力业务许可的决定

各被许可人：

根据《电力业务许可证管理规定》，经审查，决定准予以下发电企业发电类电力业务许可：

1． 内蒙古岱海发电有限责任公司

2． 石家庄诚峰热电有限公司

3． 山东时风（集团）有限责任公司

4． 山西鲁晋王曲发电有限责任公司

5． 鹤壁同力发电有限责任公司

6． 洛阳龙羽宜电有限公司

7． 驻马店市热电厂

8． 冕宁县宁源电力有限责任公司

二○○六年十月二十六日
