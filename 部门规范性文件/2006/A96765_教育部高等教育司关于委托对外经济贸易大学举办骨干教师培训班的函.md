# 教育部高等教育司关于委托对外经济贸易大学举办骨干教师培训班的函

## 教育部高等教育司关于委托对外经济贸易大学举办骨干教师培训班的函（教高司函[2006]168号）

对外经济贸易大学：

为进一步提高国际经济与贸易专业骨干教师的业务素质和教学水平，保证人才培养质量，经研究，我司委托你校举办全国高等学校国际经济与贸易专业骨干教师培训班。参加培训的学员将颁发“高等学校青年骨干教师高级研修班培训证书”。请你校认真做好准备，确保办班质量。

培训班的具体事宜由你校通知有关高等学校。培训班结束后，请将办班总结报告和参加培训的学员名单报我司财经政法与管理教育处。

教育部高等教育司

二〇〇六年九月六日
