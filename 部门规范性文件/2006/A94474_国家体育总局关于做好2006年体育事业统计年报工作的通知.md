# 国家体育总局关于做好2006年体育事业统计年报工作的通知

各省、自治区、直辖市体育局，各直属事业单位：

为做好本年度体育事业统计年报工作，根据年度工作计划，现将有关事宜通知如下：

**一、**体育统计工作是体育事业发展的一项基础性工作，要充分认识这项工作的重要性，加强领导，明确机构，专人负责，切实将本单位的年度统计工作做好。

**二、**提高统计数据的质量，做到不出假数。要采取措施，提高统计数据质量，加大审核力度。既要规范要求，加强工作责任心和奉献精神教育，同时，还要进行必要的业务培训工作，提高体育统计工作人员的政策和业务水平。

**三、**发挥统计工作的信息、咨询和监督职能作用，不仅要做好体育事业统计数据的收集、整理工作，还要深入研究和分析统计数据，为体育事业的发展服务。

**四、**2006年全国体育事业统计年报表式按照2003年以来的统计年报报表（试行本）表式执行，各单位按此表式（详见附件2）自行复印下发。重点指标口径及有关注意事项说明见附件1。本年度因故不再召开统计年报布置会。

**五、**2006年度全国统计会审汇总会将于2007年3月中旬左右召开，具体时间另行通知。请各省提前做好准备工作，并请于2007年2月28日之前将本省2006年度统计年报上报数据（含市县基层数据）和备份数据发送e－mail到xwq@sport.gov.cn。

**六、**总局本级直属事业单位2006年度统计年报按照上述规定表式填报，填报的内容为表1-表4，请于2007年2月28日前将本单位统计报表报体育经济司综合处。

附件：1.重点指标口径及有关注意事项说明

2.体育事业统计年报报表（试行本）（略）

二○○六年十一月十五日

附件1：

重点指标口径及有关注意事项说明

**一、**统计年报软件使用前首先确定“注册年度”为“2006年”，在更改注册年度前要做好上一年度的数据备份工作。

**二、**表1（基本信息表）中，“统计年份”填“2006年”，“上报时间”为“2007年”。

**三、**表1（基本信息表）中，“行政区划码”以国家统计局公布的2006年最新县级以上行政区划码填列。具体网址是：http：//www.stats.gov.cn。

**四、**表1（基本信息表）中，“隶属关系”要选择正确，否则影响汇总数据；“所属系统”统一填报“体育局系统”。

**五、**表3（专职教练员卡片）、表4（优秀运动员卡片）在录入时注意“出生年月”，超出逻辑范围会影响汇总数据。

**六、**表6（行政事业单位经费情况统计表）金额单位“万元”。市县体育局统计经费时可保留两位小数，省级汇总时将经费四舍五入取整数。

表6-2（行政事业单位经费支出情况统计表），填报口径暂作如下规定：

（一）第11栏“行政事业性支出”按2006年行政事业单位决算报表支出决算表 “基本支出”中的数据填列。

（二）第15栏“基本建设支出”按2006年行政事业单位决算报表支出决算表“项目支出”中的“基本建设项目支出”填列。

（三）第17栏“事业发展支出”按2006年行政事业单位决算报表支出决算表“项目支出”中的“行政事业性项目支出”和“其他项目支出”之和填列。

（四）其他支出科目数据按照规定填入相应的科目当中。

**七、**表7（等级运动员、裁判员发展情况统计表）按“谁发展谁统计”原则，“国家级”以上总局直接下达数据，由各省负责填报。

**八、**表8（大、中、小学校体育活动情况统计表）中，“大学”已改为“中专中技”；“传统项目布局情况”按“谁布局谁统计”原则填报。

**九、**表9（社会体育指导员情况统计表）按“谁发展谁统计”原则，“国家级”以上总局直接下达数据，由各省负责填报。

**十、**表10（全民健身活动设施情况统计表）填“累计数”。

**十一、**表13（补充资料）中“体育彩票发行额”、“体育彩票公益金提取额”均填 “本年发生数”。由省级负责填报。

**十二、**表13（补充资料）中“电脑体育彩票销售点个数”为“时点数”，填报截至年底的实际拥有数。

**十三、**一套人马，几块牌子的单位应选择一个主营业务单位，不重复填报。

**十四、**运动项目中，“自由式摔跤”和“古典式摔跤”在“国际式摔跤”中统计。

**十五、**填报本年度报表数据时，应注意与上年度有关数据衔接一致。

**十六、**统计数据备份前须注意计算机时间是否与实际时间一致，不符要予以调整，防止数据备份出错。

**十七、**2006年新增体育场地按照第五次体育场地普查软件和标准场地指标规定填报，只填报新增体育系统标准场地情况。提交电子版和报表各一份，提交纸制表为：2004、2005、2006年新增体育场地综合统计表（综合表一、综合表二、综合表三）一份。

**十八、**有关文件资料可在体育总局网站下载，网址：www.sport.gov.cn。
