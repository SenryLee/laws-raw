# 商务部市场运行调节司关于召开肉类市场形势分析暨中央储备肉计划会议的通知

各省、自治区、直辖市商务主管部门，中国华孚贸易发展集团公司，商务部屠宰技术鉴定中心：

为分析和总结肉类市场运行特点，把握肉类市场发展趋势，进一步加强中央储备肉管理，做好肉类市场宏观调控工作，定于2006年5月19日在北京召开肉类市场形势分析暨中央储备肉计划会议。现将有关事项通知如下：

**一、**会议主要内容

（一）分析2006年肉类市场运行特点及存在突出问题，预测2007年肉类发展趋势；探讨保持肉类产业健康发展和加强肉类市场调控的政策措施；

（二）下达2006年第二轮、第三轮及2007年第一轮中央储备肉活畜储备计划。

**二、**参会人员

请各省、自治区、直辖市商务主管部门派1人参加，承担储备任务的代储单位和基地场各派1人参加。参会人员食宿费用自理。

**三、**会议时间、地点

会期1天，5月18日报到，19日开会。

会议地点：北京燕京海航酒店（北京复兴门外大街19号，长安商场西侧）

请各地商务主管部门组织本地区承担国家储备任务的代储单位和基地场按时参会，并于5月16日下班前将会议回执传真至会务组。
