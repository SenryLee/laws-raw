# 中国证券监督管理委员会关于百科实业集团有限公司和本溪超越船板加工有限公司收购辽宁国能集团(控股)股份有限公司信息披露的意见

## 中国证券监督管理委员会关于百科实业集团有限公司和本溪超越船板加工有限公司收购辽宁国能集团（控股）股份有限公司信息披露的意见（证监公司字[2006]194号）

百科实业集团有限公司、本溪超越船板加工有限公司：

你们报送的《辽宁国能集团（控股）股份有限公司收购报告书》及相关文件收悉。经审核，我会对你们根据《上市公司收购管理办法》（证监会令第10号）公告收购报告书全文无异议，请按照有关规定及时履行信息披露义务。

二○○六年九月十二日
