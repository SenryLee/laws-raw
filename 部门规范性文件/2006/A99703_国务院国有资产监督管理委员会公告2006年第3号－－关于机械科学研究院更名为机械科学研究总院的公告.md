# 国务院国有资产监督管理委员会公告2006年第3号－－关于机械科学研究院更名为机械科学研究总院的公告

## 国务院国有资产监督管理委员会公告(2006年第3号)

关于机械科学研究院更名为机械科学研究总院的公告

经国务院国有资产监督管理委员会同意和国家工商行政管理总局核准，机械科学研究院自2006年4月27日起更名为机械科学研究总院，原名称同时终止。

特此公告。

国务院国有资产监督管理委员会

二〇〇六年六月十五日
