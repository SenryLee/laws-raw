# 建设部城市建设司关于印发《王凤武副司长在国家重点风景名胜区数字化建设工作交流座谈会上的讲话》的函

## 建设部城市建设司关于印发《王凤武副司长在国家重点风景名胜区数字化建设工作交流座谈会上的讲话》的函(建城景函[2006]52号)

各省、自治区建设厅，直辖市建委（园林局）：

为交流国家重点风景名胜区数字化建设经验，推进景区数字化建设试点工作，城建司近日在云南省昆明市召开了由24个数字化景区建设试点单位代表参加的“国家重点风景名胜区数字化建设工作交流座谈会”。现将王凤武副司长在会议上的讲话整理印发给你们，请转发各参会单位，抓好会议精神的贯彻落实。

建设部城市建设司　

二〇〇六年四月十八日

王凤武副司长在国家重点风景名胜区数字化建设工作交流座谈会上的讲话

（2006年4月8日　根据会议录音整理）

同志们：

为了进一步提高我国国家重点风景名胜区的科技管理水平，使景区的保护、管理和利用工作进入现代化，城建司根据建设部的统一部署，自2004年正式开展两个示范点的数字化景区建设并通过验收工作后，2005年开始，在全国的风景名胜区启动了数字化建设的试点工作。这次会议就是根据部里关于数字化建设的一系列方针、政策召开的，会议主要有以下几项内容：一是了解一下24个国家重点风景名胜区数字化建设试点工作进展情况，第二是交流下各个景区在数字化建设工作中的经验，三是对城建司委托监管处编制的《国家重点风景名胜区数字化景区建设指南》进行讨论、修改和完善，四是大家一起研究一下如何进一步推进数字化建设。下面我就这次会议的安排，谈几点意见。

**一、**数字化建设工作取得的成绩和存在的问题

数字化景区建设，自2004年由建设部和科技部共同启动这一项工作，选择的是黄山和九寨沟。2004年6月，建设部推荐黄山和九寨沟风景名胜区，纳入国家“十五”科技攻关项目--数字景区示范工程。2005年4月和6月，两个示范工程分别通过科技部一期工程验收。2005年10月，城建司在九寨沟组织召开了“国家重点风景名胜区监管信息系统暨数字化景区建设工作会议”，会上推广了九寨沟数字化景区建设的经验，与会代表实地考察了九寨沟数字建设景区信息化建设的有关工作。2005年11月，城建司下发《关于搞好国家重点风景名胜区数字化建设试点工作的通知》（建城景函[2005]143号），提出了数字化景区建设试点工作的目标和具体任务，并正式确定24个景区（包括2个示范）为数字化景区建设的试点单位。这项工作启动以来，成绩十分明显，主要体现在以下几个方面：

（一）建设部领导充分肯定了全国数字化景区建设工作所取得的成果。今年春节刚过，2月13日，曾培炎副总理在广州亲自组织召开了“全国风景名胜区工作座谈会”，与会的有省、市人民政府的负责同志和部分景区的代表，以及国家发改委、国家旅游局、国家环保局、国家林业局等相关部委的领导同志。在会上，汪部长向培炎副总理汇报全国风景名胜区数字化建设的相关工作时，强调指出：“为了进一步提高风景名胜区科技管理水平，建设部在全国开展了风景名胜区数字化建设工作，初步选定了18个基础条件较好的风景名胜区作为首批试点单位，稳步推进风景名胜区的信息化建设，改进风景名胜区的管理手段，提高风景名胜区的管理水平。九寨沟风景名胜区在数字化景区建设过程中提出了‘资源保护数字化、经营管理智能化、产业整合网络化’的目标，对景区安全秩序、行政管理、资源保护、服务经营等方面工作均实施了计算机管理，建立起全方位的电子监控系统，有效的保护了资源、提高了服务质量和管理水平、降低了运营成本、加强了防范能力、探索了风景名胜区现代化建设和管理的途径，世界遗产专家认为中国的风景名胜区数字化建设和监管信息系统已经走在了世界的前列。”数字化建设工作取得的成绩，得到部领导的肯定，说明这项工作方向是正确的，要持之以恒，下大力气，继续把这项工作推向新的高度。

（二）相关景区积极参与。根据景区的要求，这项工作逐步扩大试点范围，从2个示范点到18个试点单位 ，现在又扩充到24个景区。景区领导充分认识到，数字化建设是景区未来发展的方向，会带来巨大的环境效益、社会效益和经济效益，参与的积极性高，数字化建设工作扎扎实实，取得了明显的成效。从各个景区准备的经验介绍材料中可以看出，各景区对数字化建设工作投入了足够的人员和经费，数字化景区的作用业已显现。例如南京中山陵景区利用数字化管理模式加强景区的森林防火工作，遥感防火监测率已达到70%。最近，国务院下发通知，强调要加强森林防火工作，其中也包括风景名胜区的森林防火工作。为保护景区最重要的生态和景观资源，建设部也下发要求加强防火工作有关的文件。加强森林防火工作，重在预防，隐患险于明火，防范重于抢险，责任重于泰山。防火工作最重要的是做到早发现，把可能引发森林火灾的原因消灭在萌发的状态。一旦发现苗头，能够做到及时扑救。在这方面要采用先进的科技手段，不要总是单纯依靠巡山、人海战术进行传统监测，要注意引进新的技术。

（三）数字化景区在车辆调度和门禁系统等方面，发挥了重要作用。车辆调度系统，通过全球卫星定位技术，自动获取景区内车辆的地理位置，在景区指挥调度中心大屏幕上，直观显示交通车辆的运营分布状况，为车辆调度和安全营运提供即时在线的全程可视化管理。门禁系统对于防止票款的流失，解决多次进入景区这些系统也发挥了不可替代的作用，体现出了现代化的门票管理模式的强大优势。这些系统的建设都对我们数字化景区建设工作起到了很好的促进作用，成绩是十分明显的，我在这里就不多讲了。

在总结经验的同时，也要看到数字化景区建设工作中也还存在一些问题：

一是认识上还存在片面性。有的地方认为景区数字化建设可搞可不搞，不搞也照样管理，对这项工作的重要性、重要意义认识得还不够。数字化是我们今天所处的网络时代的必然发展趋势。在今年的政府工作报告中，国务院领导提出要“创新政府管理方式，寓管理于服务之中，更好地为基层、企业和社会公众服务。整合行政资源，降低行政成本，提高行政效率和服务水平”；要“大力推进政务公开，加强电子政务建设，增强政府工作透明度，提高政府公信力”。景区数字化建设虽然还处于起步阶段，但体现了先进生产力发展的方向，今天是24个单位，以后必然会推广和普及。数字化不是目的，而是工作手段的创新，最终目的是要提高景区的科技管理水平，更好地为景区的保护、开发、利用服务。

二是各个景区之间发展还不均衡。有的发展比较快，取得了明显的成效。有的还停留在命名初期阶段，至今还没有配备人员、设备和资金。存在等、靠、要的思想，工作不主动，没有取得任何实际成效。

三是省级主管部门的作用尚未很好发挥。搞好景区数字化建设工作，离不开省级主管部门的作用。我国国土辽阔，国家重点风景名胜区面积达到9.6万平方公里。如此广大地域，如果由建设部城建司一统到底，既不合理也不现实，应该首先由各省进行先期初步整合，然后再统一形成合力。目前，各省级主管部门尚未投入到这项工作之中，以后应逐步加强。

**二、**数字化景区建设的主要任务和要求

数字化景区建设工作，主要分成两个层面：第一个层面，是由景区按各自实际情况，参照“建设指南”自主建设的，这方面在各个景区经验交流时会具体涉及；第二个层面，是由建设部城建司和省级主管部门牵头，搞景区省内和全国协作，进行全省和全国的行业共建。当然这两个层面的工作是相互关联、相互促进的，缺一不可，没有景区自我建设的工作基础，就谈不上第二个层面的协作和共建。景区自我建设工作是基础，对这项工作各个景区要抓，各省要抓，部城建司也要抓。第一个层面，主要包括景区两个“中心”（数据和指挥调度）的建设，以及各业务应用信息系统建设。重点是创新管理机制，提升管理水平。在这个层面上，各地已经作了很多工作。第二个层面的工作，概况起来讲是“一个平台、两个系统”。 “一个平台”就是全国统一的国家重点风景名胜区管理信息系统网络平台。这项工作已经开展半年多了，监管处作了大量的工作，现在条件基本已经成熟了。管理平台界面，涉及景区管理的方方面面，实际上类似于一个电子期刊和一个政务数据中心，电子期刊涉及新闻、景区自荐、公众商务，网络推荐等。管理信息系统网络平台很快会在网络上推出，到时候，大家可以通过网络平台查阅建设部关于风景名胜区所有的政策法规，做到政务公开，同时景区之间也可以进行广泛的信息交流。同常规的期刊相比，电子期刊容量大，发表的自由度要高，景区的建议以及对信息的需求，都可以通过管理信息系统网络平台进行交流，做到资源共享。

“两个系统”指的是建立在平台基础上的景区电子商务系统和景区LED信息发布系统。这个层面的工作，主要解决景区资源的整合，打造行业统一品牌，形成团队规模效应的问题。

发展景区电子商务，实现景区门票、索道、酒店等相关旅游产品的网上预售，有利于促进景区旅游经济发展，增加创收；还可以通过网上预售实现景区客流量预报，一方面为景区管理机构合理安排相关资源提供依据，另一方面对游客选择旅游线路和行程安排起到了预先分流作用，从而减少管理资源的盲目投入，提高管理水平和服务质量，降低经营成本，支持科学管理与决策。电子商务，并不是什么新鲜事，其他行业都在做，我理解电子商务好比出售全国187个景区各种产品的网络超市，各个景区就是供货商，与读者可实地到任何一个超市一样，对超市内的商品进行采购，只不过这种参观和采购都是在网络上进行的。它的作用还不仅限于超市，同时也是网络交易会。同在展览馆里进行的交易会一样，网络推介也是推介，而且，网络的影响范围更广泛，成本更加低廉。网上浏览的人数远比实地去博览会的人数要多得多，网络空间非常大，展出的内容更多。其他行业在网上能卖电视机、电冰箱，同样，景区也能够在网络上营销门票和索道票等商品。应该把电子商务系统尽快建立起来，有的景区已经先行一步开展了电子商务工作，如果全国所有景区整合到一起，平均成本会更低，整体效益会更大。景区电子商务网建立之后，就要逐步提高网络的知名度。如果没有知名度，就很少有人去浏览，也难以发挥较大的作用。知名度也是价值，著名网站也是一笔巨大的无形资产。风景名胜区要讲保护，也要讲合理利用，风景名胜区的十六字方针里面就包括永续利用。利用就是要发挥景区的旅游展示功能。各级主管部门要转变理念，做好服务工作，引导组织景区共建电子商务系统。24个景区试点可作为第一批“网络超市”的供货商和销售商。具备条件的省份，也可以在全省先动起来，然后整体加入全国网络。这项工作在开始阶段就要想到今后的统一，标准化和规范化工作在开始就要做好。

关于LED大屏幕信息发布系统，去年由中央文明办、建设部、国家旅游局联合印发的《全国文明风景旅游区暂行标准》中曾提出过明确要求，同电子商务信息系统一样，也具有联网信息传播的特点。据统计全国风景名胜区的旅游人数，去年达到3亿人次，景区设立大屏幕信息发布系统，具有广泛的应用价值。有的景区建议，将大屏幕信息发布系统视为某种电视媒体，既可以由景区实行自播，也可以通过卫星进行全国景区的同步联播。景区大屏幕信息发布系统的联播，可起到整合全国风景名胜区资源的相互宣传、推广介绍的作用。景区之间相互播放景区推介，彼此之间优势互补，共同发展。各个景区因区位不同、资源条件不同，而存在着本质上的不同。每一个景区都是独特、唯一和不可替代的，景区之间只有互补关系，没有竞争关系。在九寨沟，游客看到丽江等景区的宣传广告，影响不了他是否选择到九寨沟游览，因为人已经到了九寨沟了，反过来也是这样。游客的心理和买电视机、电冰箱等其他商品的顾客心理是不一样的，买了某种品牌电视或洗衣机，一般就不会再买其它品牌的同种商品，但是游客去了某个景区还是有去其他景区的需求，景区之间完全不同，一个景区替代不了另外一个景区。大屏幕信息展示系统设置要注意选址，如果在强光直射下，大屏幕是看不见的；其次要选择人流驻足、停步地方，才能更好的发挥作用，同时也不应该有碍观瞻。

以上讲的“一个平台、两个系统”，是数字化景区建设核心工作，需要大家共同协作完成。对于数字化景区建设的基本要求和基本原则，在“建设指南”中已经写的很明确了，希望大家对这个原则进行讨论，建设原则概况起来就是“总体部署，分步实施；统一标准，保障共享；整合资源，集约发展；突出重点，先急后缓；实用可靠，适度先进；创新机制，市场运作”。“建设指南”目前还是个草稿，还不完善，希望大家认真讨论，结合实际工作多提意见和建议。

**三、**会后要落实的几项工作

有几项工作要尽快落实。一是对《国家重点风景名胜区数字化景区建设指南》讨论稿，监管项目组会后要将大家意见进行汇总，仔细进行修订，尽快印发试行，使大家在建设方面做到有章可循，做到统一规范；二是各景区要将数字化建设工作领导小组和专门工作班子的成员组成，尽快确定下来，要明确一名联系责任人，以便及时了解各地进展情况；三是对各景区数字化建设总体方案完成汇总，认真进行总结；第四，也是非常关键的，对于“一个平台，两个系统”的统筹建设，要尽快启动。

同志们，数字化景区建设，是新形势下风景名胜区事业发展到新阶段的必然选择。相信通过共同努力，大家一定能够实现数字化景区建设试点工作的预期目标，为全国187个国家重点风景名胜区数字化建设工作取得良好的先期建设经验。

这次会议，云南省建设厅和石林管理局提供了很好的条件和服务，我代表城建司和与会同志表示感谢！同时也感谢大家的到会！

谢谢大家！
