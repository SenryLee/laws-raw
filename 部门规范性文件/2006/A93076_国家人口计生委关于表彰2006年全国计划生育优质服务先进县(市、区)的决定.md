# 国家人口计生委关于表彰2006年全国计划生育优质服务先进县(市、区)的决定

各省、自治区、直辖市人口计生委，计划单列市、新疆生产建设兵团人口计生委，解放军、武警部队人口和计划生育领导小组办公室：

自2002年开展的计划生育优质服务先进县（市、区） 创建活动，是国家人口计生委在新时期落实"三个代表"重要思想，以人的全面发展为中心，以改进计划生育管理与服务为重点，以优质服务的理念和运作方式，全面提高基层计划生育工作水平的重要举措，是推进综合改革，建立人口和计划生育工作新机制的重要载体。

四年来，各级党委、政府和人口计划生育部门，认真贯彻落实科学发展观，坚持"以人为本"的服务理念，坚持以群众满意为目标，在改革中发展，在发展中创新，不断加强基层基础工作，努力提高管理服务水平，各项工作取得明显进展，创建活动得到基层和群众的积极响应和热烈拥护。

各地经过组织申报、民主评议，公开公示等程序，优中选优推荐了第四批全国计划生育优质服务先进县（市、区）。国家人口计生委经过资格审核与抽查评估，决定授予北京市西城区、河北省怀来县等105个县（市、区）"全国计划生育优质服务先进县（市、区）"荣誉称号，表彰他们在计划生育优质服务创建活动中取得的优异成绩，做出的突出贡献。

希望受到表彰的先进单位，继续保持奋发进取的精神状态，始终走在改革和发展的前列，努力探索计划生育优质服务的新思路、新方法，再接再厉，勇立新功。全国人口和计划生育系统广大工作者，要紧密团结在以胡锦涛同志为总书记的党中央周围，全面落实科学发展观，与时俱进，开拓创新，为构建社会主义和谐社会，全面建设小康社会，为稳定低生育水平，统筹解决人口问题，谱写计划生育优质服务新篇章，再创人口和计划生育事业新辉煌！
