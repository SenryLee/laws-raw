# 农业部办公厅关于公布家畜遗传材料生产许可评审专家库（第一批）专家名单的通知

农办牧〔2017〕24号

各省、自治区、直辖市及计划单列市畜牧（农牧、农业）局（厅、委、办），新疆生产建设兵团畜牧兽医局，黑龙江省农垦总局、广东省农垦总局，各有关单位：

根据农业部《家畜遗传材料生产许可评审专家库管理办法》规定，在部直属事业单位、各省级畜牧主管部门及有关科研教学机构推荐的基础上，我部经过遴选，确定了符合资格条件的54人作为家畜遗传材料生产许可评审专家库专家，现将专家名单予以公布。

农业部办公厅

2017年5月9日
