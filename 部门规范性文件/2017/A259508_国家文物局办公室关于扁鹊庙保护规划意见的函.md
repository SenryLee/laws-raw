# 国家文物局办公室关于扁鹊庙保护规划意见的函

办保函〔2017〕1428号

河北省文物局：

你局《关于呈报扁鹊庙文物保护规划的请示》（冀文物字〔2016〕272号）收悉。经研究，我局意见如下：

一、所报规划前期研究不足，体例和内容与《全国重点文物保护单位保护规划编制要求》存在一定差距，我局暂不同意扁鹊庙保护规划。

二、所报规划应做以下必要修改和完善：

（一）梳理保护对象认定。补充扁鹊庙历史沿革研究，明确建制格局，完善文物本体认定调整依据和历史环境构成要素。

（二）完善现状评估。补充对复建建筑的评估内容，明确是否对原有建筑基址的影响、建筑形制是否符合要求等；深化文物环境评估；补充特殊文化活动的评估内容，明确瞬时人流量、活动路线、对文物本体和环境的影响等内容。

（三）调整保护区划和管理规定。根据扁鹊庙历史沿革分析和文物本体认定内容，合理划定保护范围；完善建设控制地带分类，适当调整一类和二类建设控制地带，严格制定扁鹊庙周边的控制要求。

（四）梳理保护措施。补充原有建筑基址的调查、评估和保护措施；厘清文物与非文物建筑的保护措施。

（五）完善管理规划。明确扁鹊庙管理和使用单位的关系和责权，梳理保护管理和展示利用分工内容。

（六）进一步完善与传统村落保护规划和省级历史文化名村保护规划的衔接内容。

（七）规范并完善规划图纸和文字的表达，增强规划图纸和文本内容的对应。

三、请你局指导有关单位，根据上述意见对扁鹊庙保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月26日
