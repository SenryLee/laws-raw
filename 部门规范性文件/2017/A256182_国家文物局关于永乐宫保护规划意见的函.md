# 国家文物局关于永乐宫保护规划意见的函

文物保函〔2017〕1697号

山西省文物局：

你局《关于审批芮城县永乐宫文物保护规划的请示》（晋文物〔2016〕133号）收悉。经研究，我局批复如下：

一、原则同意所报规划。

二、对该规划提出以下修改意见：

（一）进一步提炼永乐宫价值评估内容，合理区分社会价值与文化价值。

（二）进一步细化保护对象现状评估。应深化对2014年保护修缮工程实施情况、效果的评估内容；进一步细化对永乐宫壁画的评估，明确其保存情况、出现损坏的部位、程度等。

（三）完善保护区划管理规定，应说明永乐宫周围建设活动按照古魏城遗址的保护范围管理规定执行，并在规划中引用其具体规定内容。

（四）完善环境整治规划。应加强历史研究，永乐宫内的环境整治工作应适度，避免过度铺装；加强永乐宫前轴线道路两侧环境整治，避免过于旅游商业化。

（五）加强与相关规划的衔接，并提高规划的可操作性。如，芮城县北环路位于原永乐宫建设控制地带内及古魏城遗址保护范围内，规划中应当明确其不再作为城市主干道，严格控制道路两边的建设；论证文物古迹用地向南扩展的必要性；应进一步补充本规划与《古魏城遗址保护规划》的具体衔接内容。

（六）进一步规范图文表达，加强图文对应，不应以效果图作为现状鸟瞰图。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的芮城县永乐宫保护规划报请山西省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好永乐宫的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年9月27日
