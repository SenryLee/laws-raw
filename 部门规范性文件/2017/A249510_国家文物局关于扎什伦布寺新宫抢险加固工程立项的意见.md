# 国家文物局关于扎什伦布寺新宫抢险加固工程立项的意见

## 关于扎什伦布寺新宫抢险加固工程立项的意见

办保函〔2017〕359号

西藏自治区文物局：

你局《关于扎什伦布寺新宫抢险加固工程立项的请示》（藏文物字〔2017〕26号）收悉。经研究，我局意见如下：

一、扎什伦布寺新宫不属于全国重点文物保护单位扎什伦布寺的文物构成，其抢险加固工程不属于我局行政审批事项。

二、请你局督促地方人民政府根据《关于扎什伦布寺保护规划编制立项的批复》（文物保函〔2014〕1198号）要求，抓紧编制扎什伦布寺保护规划,进一步明确保护对象，妥善处理文物保护和宗教活动的关系。同时，指导宗教部门和有关单位切实加强文物日常保养和岁修工作，落实管理维护责任，确保文物安全。

专此。

国家文物局

2017年3月31日
