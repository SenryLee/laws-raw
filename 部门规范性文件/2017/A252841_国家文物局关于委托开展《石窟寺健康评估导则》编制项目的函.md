# 国家文物局关于委托开展《石窟寺健康评估导则》编制项目的函

## 关于委托开展《石窟寺健康评估导则》编制项目的函

办保函〔2017〕496号

中国文化遗产研究院：

为进一步加强石质文物预防性保护和险情排查工作，我局拟委托你院开展《石窟寺健康评估导则》编制工作，按合同（附后）规定拨付你院第一期项目经费15万元（项目总经费20.9万元），并要求如下：

一、请你院督促项目组进一步细化工作方案，明确人员职责分工，注意工作进度安排。工作过程中应切实加强工作组内部协调组织，积极与相关文物管理单位沟通、联系，充分听取专家意见和建议，确保编制工作的科学性。

二、请你院加强管理，进一步细化项目经费预算，并保证资金的合理使用。项目结项报告和经费决算应在2017年11月20日前提交我局。

三、请项目组加强与相关各省（区、市）文物局的沟通，积极协调有关单位提供数据、资料，确保险情排查工作顺利进行。

国家文物局

2017年4月26日
