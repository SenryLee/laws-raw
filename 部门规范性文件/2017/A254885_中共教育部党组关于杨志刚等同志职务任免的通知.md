# 中共教育部党组关于杨志刚等同志职务任免的通知

教党任〔2017〕188号

部内各司局：

中共教育部党组2017年7月24日决定，任命杨志刚同志为政策法规司副司长，杨鸿同志为人事司副司长，徐维清同志为国务院学位委员会办公室副主任、教育部学位管理与研究生教育司副司长，试用期均为一年。以上同志原任职务自然免去。

中共教育部党组

2017年8月7日
