# 国家文物局办公室关于圆明园遗址西北部水系生态治理项目的意见

办保函〔2017〕1425号

北京市文物局：

你局《关于圆明园遗址西北部水系生态治理工程设计方案的请示》（京文物〔2017〕1281号）收悉。经研究，我局意见如下：

一、所报方案深度不足，未充分说明项目实施的必要性和可行性，及其对文物本体和生态环境的影响，缺乏必要的文物保护措施。我局暂不同意所报圆明园遗址西北部水系生态治理项目设计方案。

二、请你局指导圆明园管理处加强前期论证和专家咨询，充分分析、评估圆明园遗址西北部水系生态治理项目的必要性、可行性，广泛听取专家意见，补充开展必要的模拟实验和数据分析，在此基础上调整完善方案设计。

三、请你局指导圆明园管理处统筹考虑圆明园遗址考古、保护、水系治理、国家考古遗址公园建设运营等方面工作，结合北京市城市总体规划和“三山五园”整体保护利用项目，有序推进相关工作。圆明园遗址西北部水系生态治理项目应按照全国重点文物保护单位保护范围内涉建项目行政审批要求，完善相关资料，依法另行报批。

国家文物局办公室

2017年12月27日
