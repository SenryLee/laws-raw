# 国家发展改革委办公厅、国家体育总局办公厅关于请报送体育产业联系点典型案例的通知

## 国家发展改革委办公厅 国家体育总局办公厅关于请报送体育产业联系点典型案例的通知

发改办社会〔2017〕841号

各省、自治区、直辖市及计划单列市发展改革委、体育局，体育总局有关协会（中心），中国足球协会：

为贯彻落实《国务院关于加快发展体育产业促进体育消费的若干意见》，按照《关于做好体育产业联系点有关工作的通知》（发改办社会﹝2015﹞1916号）要求，为进一步总结体育产业联系点发展的有效做法，现征集一批典型案例，以形成一批可复制可推广的改成创新成果，为全国体育产业发展提供示范经验。现将有关事项通知如下。

一、案例要求

（一）紧密围绕加快发展体育产业促进体育消费等相关要求，典型案例可涉及但不局限于大力优化体育产业结构、积极支持社会力量进入、完善公共体育设施布局、丰富体育赛事活动、完善体育产业发展政策、推动产业融合发展、培育健身消费市场、打造良好市场环境等方面内容，以及政府和社会资本合作（PPP）、“互联网+”、体育+X（养老、健康、旅游等）、特色体育小镇、体育综合服务体、有特色的品牌赛事等创新模式内容。

（二）典型案例既要有实践内容，又要有理论剖析，文字要求重点突出、言简意赅、逻辑严密，具有较强的可读性，能从方法上启发思路，从模式上提供借鉴，从实践上引导创新，具有一定代表性和标志性。字数请控制在2500字左右，可配图说明。

（三）典型案例要确保真实性，模式清晰，数据准确，杜绝一切虚假案例。

二、报送要求

（一）请参照模板（见附件）要求编写案例材料。

（二）每个联系点城市选送2-3个典型案例，联系点单位选送1个典型案例。

（三）请各省（区、市）发展改革委、体育局、体育总局有关协会（中心）于5月31日前将案例材料报送至国家发展改革委（社会发展司）、体育总局（体育经济司），并同步报送电子版文件。电子邮件标题中需注明“体育产业联系点典型案例”字样。

三、其他事项

（一）请各联系点城市、联系点单位紧密结合工作实际，深入调查比较，遴选典型案例，认真做好选送工作。

（二）国家发展改革委、体育总局将组织有关专家对选送典型案例进行遴选，优秀案例将汇编成册，并通过各种方式在全国范围内宣传推广。

联系人及联系方式：南哲，nanzhe@ndrc.gov.cn
