# 国家文物局关于平定准噶尔勒铭碑文物保护利用设施建设项目的意见

文物保函〔2017〕1932号

新疆维吾尔自治区文物局：

你局《关于报送平定准噶尔勒铭碑文物保护利用设施建设项目初步设计的请示》（新文物保发〔2017〕68号）收悉。经研究，我局意见如下：

一、原则同意平定准噶尔勒铭碑文物保护设施建设项目和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）补充新疆维吾尔自治区人民政府对平定准噶尔勒铭碑保护范围和建设控制地带的管理规定。进一步论证建设控制地带内新建木栈道的必要性，建议取消上山新建木栈道，保持历史地形地貌。

（二）应尽可能保持勒铭碑的自然环境特点，避免园林化。如，围栏可采用与环境更加和谐的形式；进一步细化彩色沥青混泥土道路面层所用材料和工程做法，慎重考虑其选用颜色，建议选用土黄色面层，尽量减少对文物及其原有历史环境风貌的影响。

（三）进一步推敲管理展示用房、游客服务中心卡伦标志塔高度及女儿墙长城垛口的形制。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《文物保护法》第十七条、第十八条的有关规定分别报新疆维吾尔自治区人民政府和城乡建设规划部门批准后实施。请切实加强协调和工程监管，确保文物及其环境安全。

国家文物局

2017年12月1日
