# 中国保监会关于华农财产保险股份有限公司在甘肃省开展农业保险扶贫试点的复函

保监函〔2017〕86号

华农财产保险股份有限公司：

你公司《关于恳请支持在甘肃省开办农业保险精准扶贫试点的请示》（华农发〔2017〕172号）收悉。经研究，我会支持你公司在甘肃省开展农业保险扶贫试点。你公司要认真贯彻落实党中央国务院关于脱贫攻坚工作有关精神，围绕甘肃省贫困地区农业产业特色和保险服务需求，加大资源投入，创新保险产品和保险服务，积极探索保险助推脱贫攻坚新模式，为农户提供更多更好的保险服务。试点中遇到的新问题、新情况，应及时报告我会。

中国保监会

2017年7月12日
