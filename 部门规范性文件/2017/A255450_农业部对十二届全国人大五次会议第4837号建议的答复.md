# 农业部对十二届全国人大五次会议第4837号建议的答复

## 对十二届全国人大五次会议第4837号建议的答复

农办议〔2017〕248号

王勇代表：

您提出的“关于强化农产品加工龙头企业在农业供给侧改革与消费品工业升级中桥梁作用的建议”收悉。经商国家发展改革委、工业和信息化部，现答复如下。

一、关于对品种区域进行顶层设计和规划

党中央、国务院高度重视农产品加工业发展。2016年，国务院办公厅出台了《关于进一步促进农产品加工业发展的意见》（国办发〔2016〕93号），对优化结构布局提出明确要求：根据全国农业现代化规划和优势特色农产品产业带、粮食生产功能区、重要农产品生产保护区分布，合理布局原料基地和农产品加工业，形成生产与加工、科研与产业、企业与农户相衔接配套的上下游产业格局，促进农产品加工转化、增值增效。支持大宗农产品主产区重点发展粮棉油糖加工，着力建设优质专用原料基地和便捷智能的仓储物流体系；支持特色农产品优势区重点发展“菜篮子”产品等加工，着力推动销售物流平台、产业集聚带和综合利用园区建设；支持大中城市郊区重点发展主食、方便食品、休闲食品和净菜加工，形成产业园区和集聚带。同时，我部研究制定了《全国农产品加工业与农村一二三产业融合发展规划（2016-2020年）》，强调在粮食生产核心区，大力发展优质原料基地及加工专用品种生产，积极推动大宗粮食作物产地初加工、传统加工技术升级与装备创制，并分别针对不同区域明确了各自的发展方向，有助于引导龙头企业根据规划选择合适的区域投资兴业。

二、关于促进农产品加工消费品转型升级

近年来，围绕推动农业供给侧结构性改革，我部采取多种措施，引导龙头企业优化产品结构，不断提高产品附加值和市场竞争力，促进农产品加工消费品转型升级。一是推动科技成果产业化，提升企业加工技术水平。我部每年都举办全国农产品加工科技创新推广活动，开展精深加工技术研发和成果对接，促进科技成果产业化。同时，加强农产品加工技术集成基地建设，组织开展关键技术装备研发和推广，加强现代生物和营养强化技术研究，挖掘开发新食品原料和药食同源、养生保健等功能食品。二是实施农产品加工业质量品牌提升行动，推进质量品牌建设。开展质量品牌公益行活动，遴选区域公用品牌创建典型，推介一批农产品加工“老字号”品牌。深入开展主食加工业提升行动，推动优质原料基地建设和加工专用品种生产，开发传统面米、马铃薯及薯类、杂粮、预制菜肴等多元化主食产品。以大中城市为重点，推广“中央厨房”模式，引导企业发展符合市场需求的特色化、小众化、中高端、高附加值产品。下一步，我部将加大工作力度，推进农产品加工业转型升级，努力打造出更多高端农产品加工消费品，满足城乡居民不断升级的消费需求。

三、关于延伸完善农产品加工企业产业链

按照中央要求，我部会同有关部门，支持龙头企业围绕产业整体开发，促进农业产业链条延伸，强化产前、产中、产后衔接，密切生产、加工、销售等各环节连接，提高产加销一条龙、贸工农一体化程度。一方面，坚持把加强原料生产基地建设作为提升农业产业化经营水平的基础支撑来抓，明确要求各地结合优势农产品区域布局，以及龙头企业和消费市场的需求，建设专业化、标准化的原料生产基地；支持龙头企业加大技术投入力度，提高精深加工能力和水平，延伸拓展产业链条；引导大型连锁超市与农民合作社、龙头企业等直接对接，建立长期、稳定的购销关系，支持龙头企业建设配送中心、冷链物流等农产品流通基础设施，提高企业农产品贮藏、加工、运输和配送能力。通过以奖代补的方式支持龙头企业为农户提供贷款担保，带动农户发展规模化、标准化、专业化和集约化原料基地，参与农业全产业链发展。2014-2016年，共支持85家龙头企业为12.5万人次农户提供贷款担保，贷款总额超过61亿元。另一方面，依托当地优势产业，以各类农业园区为载体，以龙头企业为核心，吸引产业链上下游企业集群集聚发展，优化配置各类资源要素，创建一批主导产业链条完整、产品和产业附加值较高的国家农业产业化示范基地。目前，共认定3批209个国家农业产业化示范基地，集聚各类龙头企业9000余家，年销售收入超过1.7万亿元，辐射带动2000多万农户。今年，我部启动了农业产业化示范基地提质行动，提出了运行监测优胜劣汰、典型模式总结推介、创新完善跟进提升等方面的工作措施，并要求各级农业主管部门在政策创设、项目支持和宣传推介等方面，加大对农业产业化示范基地的支持力度。

下一步，我部将继续会同相关部门，以推进农业供给侧结构性改革为根本任务，支持和引导龙头企业延长产业链、提升价值链、共享利益链，打造集种养殖、冷链物流、精深加工、品牌营销等多环节于一体的全产业链和全流通体系，推动传统农业向现代农业转型升级。

四、关于对玉米深加工产能放宽审批政策

2015年，根据国务院关于简政放权和文件清理工作的要求，结合玉米产量逐渐大于消费量的情况，国家发展改革委废止了《关于促进玉米深加工业健康发展的指导意见》（发改工业〔2007〕2245号）。同时，为做好政策衔接、保持玉米供求关系稳定，国家发展改革委印发了《关于玉米深加工项目管理有关事项的通知》（发改办产业〔2015〕1017号），将玉米深加工项目由国家发展改革委核准调整为省级发展改革委备案，并要求新建玉米深加工项目备案遵循减量或等量淘汰的原则。

此外，为贯彻落实国务院印发的《企业投资项目核准和备案管理条例》（国务院令第673号）精神，推动项目备案统一管理，同时针对目前玉米供过于求的情况，放宽对新建玉米深加工项目的限制，适当扩大玉米深加工产能，消化玉米库存，今年4月，国家发展改革委印发了《关于废止〈玉米深加工项目管理有关事项的通知〉的通知》（发改办产业〔2017〕627号），取消了新建玉米深加工项目备案减量或等量淘汰的原则要求，进一步优化了玉米深加工产业发展环境。

下一步，我部将继续会同有关部门，改革完善玉米收储制度，完善玉米加工企业财税政策，加大玉米加工企业信贷支持，积极引导玉米加工企业转型升级。

感谢您对“三农”工作的关心，希望今后继续对我部工作予以支持。
