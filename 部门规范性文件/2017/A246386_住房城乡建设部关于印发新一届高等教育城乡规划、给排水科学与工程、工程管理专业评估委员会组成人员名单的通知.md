# 住房城乡建设部关于印发新一届高等教育城乡规划、给排水科学与工程、工程管理专业评估委员会组成人员名单的通知

建人函[2017]2号

各有关单位：

第四届住房和城乡建设部高等教育城乡规划专业评估委员会、第三届住房和城乡建设部高等教育给排水科学与工程专业评估委员会、第四届住房和城乡建设部高等教育工程管理专业评估委员会任期届满。根据评估委员会章程，我部组建了第五届住房和城乡建设部高等教育城乡规划专业评估委员会、第四届住房和城乡建设部高等教育给排水科学与工程专业评估委员会、第五届住房和城乡建设部高等教育工程管理专业评估委员会，任期四年。现将三个评估委员会组成人员名单印发给你们，请委员所在单位对委员开展工作提供必要的支持。

附件：1.第五届住房和城乡建设部高等教育城乡规划专业评估委员会组成人员名单

2.第四届住房和城乡建设部高等教育给排水科学与工程专业评估委员会组成人员名单

3.第五届住房和城乡建设部高等教育工程管理专业评估委员会组成人员名单

中华人民共和国住房和城乡建设部

2017年1月4日
