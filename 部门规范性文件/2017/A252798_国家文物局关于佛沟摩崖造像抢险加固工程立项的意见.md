# 国家文物局关于佛沟摩崖造像抢险加固工程立项的意见

## 关于佛沟摩崖造像抢险加固工程立项的意见

办保函〔2017〕415号

河南省文物局：

你局《关于方城县佛沟摩崖造像抢险加固工程立项的请示》（豫文物〔2017〕57号）收悉。经研究，我局意见如下：

一、暂不同意佛沟摩崖造像抢险加固工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）应开展专项地质勘察，明确佛沟摩崖造像赋存岩体的岩性、构造和裂隙发育情况，收集文物所在区域的光照、大气质量、降水量和地表径流等数据资料，客观评估赋存岩体稳定性、周边环境污染影响、文物风化劣变程度和发展趋势等，为制定有针对性的保护措施提供依据。

（二）应研提石刻加固、边坡加固、植被清理技术思路和措施，坚持最小干预原则，严格控制工程范围和规模，核实工程对象。岩体应以灌浆加固为主，严格控制锚固范围和数量。补充排水系统建设的必要性和可行性分析内容。

（三）应根据工程量合理编制经费预算，进一步细化各单项取费依据。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促地方人民政府根据《关于佛沟摩崖造像文物保护规划编制立项的批复》（文物保函〔2016〕1115号）要求，抓紧编制佛沟摩崖造像保护规划,统筹考虑石质文物保护、环境整治和日常管理工作，严格控制保护区划内基础设施建设，坚决制止影响文物安全的开山取石行为，确保文物安全。

专此函。

国家文物局

2017年4月12日
