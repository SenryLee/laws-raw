# 国家文物局关于青龙洞古建筑群展示利用工程立项的意见

## 关于青龙洞古建筑群展示利用工程立项的意见

办保函〔2017〕90号

贵州省文物局：

你局《关于送审〈贵州省镇远县青龙洞古建筑群展示利用工程立项报告〉的请示》（黔文物呈〔2016〕93号）收悉。经研究，我局意见如下：

一、所报工程立项的工程内容不明确，展示措施不当，文本深度不够，我局暂不同意青龙洞展示利用工程立项。

二、对该立项文本提出以下修改意见：

（一）应根据《青龙洞古建筑群保护规划》中展示利用的原则和要求，科学确定展示内容、方式和重点，增强展示设计的针对性，全面系统地展现青龙洞古建筑群的艺术价值、文化价值和整体格局，注意突出江南汉地建筑与西南少数民族山地建筑文化相结合的营造特色，以及儒、道、释多元思想相交融的文化特征。补充游客量、具体开放展示范围、面积等说明。

（二）应重点说明青龙洞古建筑群的整体展示设计思路，进一步明确展示主题、游线设计、各文物建筑的展示定位与功能，采用多种展示方式和科技手段，注意阐释内容通俗易懂。

（三）规范文本和图纸，补充必要的基础资料和展示设计图、效果图。

（四）应根据工程量合理编制经费预算，补充各单项费用取费依据。

三、请你局组织有关单位根据上述意见和《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，对所报方案进行修改、完善，按程序另行报批。

专此函。

国家文物局

2017年2月7日
