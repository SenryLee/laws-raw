# 国家文物局关于潼南大佛寺摩崖造像文物保护基础设施建设项目的意见

文物保函〔2017〕1716号

重庆市文物局：

你局《关于报送重庆市潼南大佛寺摩崖造像文物保护基础设施建设项目勘察设计方案的请示》（渝文物〔2017〕225号）收悉。经研究，我局意见如下：

一、原则同意潼南大佛寺摩崖造像文物保护基础设施建设项目和你局意见。

二、对所报方案提出具体修改意见如下：

(一)补充说明2009年以来潼南大佛寺摩崖造像西段山顶修建仿古建筑山门、正殿前河滩处修建佛缘广场及绿化、大佛寺摩崖造像西门、西门片区仿古管理用房及停车场、沿大桥河沟北侧修建河堤等现有建设项目的位置、建设情况及与潼南大佛寺摩崖造像的关系。

（二）应开展必要的考古工作，明确摩崖造像、文物建筑和附属文物的分布范围与空间格局，为科学整治大佛寺环境提供依据。结合历史研究与考古工作成果，调整、完善设计方案，充分保护文物本体、空间格局及历史风貌的真实性和完整性。

（三）应进一步细化保护范围内环境整治项目的内容与做法。道路、绿地、广场等设计应充分尊重大佛寺原有格局和道路组织，避免现代化和景观园林化设计倾向。减少保护范围内绿化整治工程量，减少人为绿化痕迹。道路铺装应遵循传统铺装图案，控制石材铺装规模，注意对历史道路的保护。

（四）补充新建停车场、游客服务中心对文物环境影响的评估。

（五）应单独编制河堤等防洪工程方案，经水利部门审核后另行报批。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并按照《文物保护法》第十七条的有关规定报重庆市人民政府批准后实施。请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

四、应按照我局办保函〔2015〕330号文件要求，尽快完成潼南大佛寺摩崖造像文物保护规划编制工作。

专此函复。

国家文物局

2017年10月9日
