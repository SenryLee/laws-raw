# 国家新闻出版广电总局办公厅关于开展2017年重点主题出版物百家书城联合展示展销活动的通知

## 关于开展2017年重点主题出版物百家书城联合展示展销活动的通知

新广出办发〔2017〕51号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，各出版集团、发行集团：

为进一步做好2017年主题出版工作，向广大读者推荐一批导向正确、质量优良的优秀主题出版物，国家新闻出版广电总局决定于2017年7月至11月组织全国百家书城联合开展2017年重点主题出版物展示展销活动。现就有关事项通知如下：

一、展示展销重点出版物

参加展示展销的2017年重点主题出版物主要包括：经中央宣传部和国家新闻出版广电总局确定的2017年主题出版重点出版物选题，共计97种（含77种图书和20种音像电子出版物，名单见附件1）；经国家新闻出版广电总局确定的2017年中国文艺原创精品出版工程（二期）项目（名单见附件2）。

二、展示展销活动内容

总局从各地中心书城中选出115家书城参加联合展示展销活动（名单见附件3）。参加活动的书城要统一悬挂“2017年重点主题出版物百家书城联合展示展销活动”的横幅，设立专门区域集中展示展销重点出版物，对读者购书给予优惠，并在八一建军节、国庆节和党的十九大召开前后等重要时间节点延长营业时间，组织形式多样的推广活动，重点宣传相应题材内容的主题出版物。其他实体书店、网络书店等也可以根据自身特点，参照百家书城的做法，开展展示展销活动。

三、展示展销工作要求

各地新闻出版广电局和出版集团、发行集团要高度重视2017年重点主题出版物展示展销活动，要在重要时间节点前督促有关出版单位和发行单位做好重点出版物的印制、发行和货源储备工作，为展示展销活动的顺利开展打好基础。

四、展示展销宣传推广

各地新闻出版广电局要积极组织广播、电视、报纸、期刊、网络等多种媒体对展示展销活动及重点主题出版物进行广泛宣传，协调安排重要频道、节目、版面、栏目，在主要时段和重要时间节点进行报道，切实扩大展示展销活动及重点主题出版物的社会影响，在全社会营造浓厚文化氛围。

特此通知。

附件：1.重点主题出版物目录

2.2017年中国文艺原创精品出版工程（二期）项目目录

3.百家书城名单

国家新闻出版广电总局办公厅
