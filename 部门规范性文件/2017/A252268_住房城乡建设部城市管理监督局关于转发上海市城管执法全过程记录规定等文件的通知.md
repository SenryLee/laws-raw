# 住房城乡建设部城市管理监督局关于转发上海市城管执法全过程记录规定等文件的通知

建督政函〔2017〕31号

各省、自治区住房城乡建设厅，北京市城市管理委员会、城市管理综合行政执法局，天津市市容和园林管理委员会，上海市住房城乡建设管理委员会，重庆市市政管理委员会，新疆生产建设兵团建设局：

现将《上海市城管执法全过程记录规定（试行）》《上海市城管执法调查取证规则（试行）》《上海市城管行政处罚案卷管理规定》《上海市城市管理行政执法监督办法》《上海市城市管理行政执法局上海市公安局关于进一步加强本市公安部门与城管执法部门执法协作的通知》转发给你们，供交流参考。

中华人民共和国住房和城乡建设部城市管理监督局

2017年6月28日

附件:

1、《上海市城管执法全过程记录规定（试行）》

2、《上海市城管执法调查取证规则（试行）》

3、《上海市城管行政处罚案卷管理规定》

4、《上海市城市管理行政执法监督办法》

5、上海市城市管理行政执法局上海市公安局关于进一步加强本市公安部门与城管执法部门执法协作的通知
