# 国家文物局关于南京城墙保护范围和建设控制地带内建设活动式公厕项目的意见

文物保函〔2017〕1998号

江苏省文物局：

你局《关于在南京城墙保护范围和建设控制地带内建设活动式公厕项目的请示》（苏文物保〔2017〕302号）收悉。经研究，我局意见如下：

一、原则同意在南京城墙保护范围和建设控制地带内建设活动式公厕项目和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）进一步评估和深化活动式公厕的外观设计，并严格按照《南京城墙保护规划（2008-2025）》和《南京城墙保护条例》（2015年）的相关要求进行风貌控制。

（二）部分活动式公厕需要管线铺设，涉及地面开挖，应补充施工中对城墙本体保护的措施，并进一步论证活动式公厕雨水排水对城墙本体的影响。

（三）补充项目建设地块内的考古勘探内容。注意控制新建项目对文物本体及其周边环境的干扰程度，处理好文物保护与当地城市建设的关系。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》第十七条、第十八条的有关规定分别报送江苏省人民政府和城乡建设规划部门批准后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局

2017年12月18日
