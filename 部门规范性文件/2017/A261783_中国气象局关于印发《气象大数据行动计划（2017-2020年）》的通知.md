# 中国气象局关于印发《气象大数据行动计划（2017-2020年）》的通知

气发〔2017〕78号

各省、自治区、直辖市气象局，各直属单位，各内设机构：

为全面对接《“十三五”国家信息化发展规划》、《促进大数据发展行动纲要》和《全国气象发展“十三五”规划》，加快推进气象大数据云平台建设和气象大数据的众智众创应用，明确2017-2020年重点任务，中国气象局组织制定了《气象大数据行动计划（2017-2020年）》，现予以印发，请认真组织实施。

中国气象局

2017年12月11日
