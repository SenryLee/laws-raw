# 国土资源部办公厅关于印发《全国国土资源标准化技术委员会章程》和《全国国土资源标准化技术委员会秘书处工作细则》的通知

国土资厅发〔2017〕39号

中国地质调查局及部有关直属单位，部机关有关司局，全国国土资源标准化技术委员会及各分技术委员会，全国国土资源标准化技术委员会及各分技术委员会秘书处挂靠单位：

为加强全国国土资源标准化技术委员会的管理，根据《中华人民共和国标准化法》《国土资源标准化管理办法》和《全国专业标准化技术委员会管理规定》的有关规定，部修订了《全国国土资源标准化技术委员会章程》和《全国国土资源标准化技术委员会秘书处工作细则》。现印发给你们，请遵照执行。

2017年11月16日

附件：

1.《全国国土资源标准化技术委员会章程》

2.全国国土资源标准化技术委员会秘书处工作细则
