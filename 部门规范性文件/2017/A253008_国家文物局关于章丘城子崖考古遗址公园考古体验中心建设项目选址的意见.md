# 国家文物局关于章丘城子崖考古遗址公园考古体验中心建设项目选址的意见

## 关于章丘城子崖考古遗址公园考古体验中心建设项目选址的意见

办保函〔2017〕474号

山东省文物局：

你局《关于章丘城子崖国家考古遗址公园考古体验中心项目选址的请示》（鲁文发〔2017〕36号）收悉。经研究，我局意见如下：

一、暂不同意章丘城子崖国家考古遗址公园考古体验中心建设项目涉及城子崖遗址保护范围的选址方案。

二、所报方案尚需做以下必要的修改和完善：

（一）补充说明保护规划对现选址区域及现有建筑物的相关规定和要求。

（二）进一步说明该区域及周边区域地下文物遗存的分布及保存情况，注意评价该区域在城子崖遗址空间格局上的价值和地位。

（三）进一步明确拟建考古体验中心的功能定位，并注意与已有的遗址博物馆相区分。

（四）进一步优化建设项目选址，建议开展必要的比选工作，提出推荐方案并说明理由。比选过程中，应充分考虑对城子崖遗址的影响、参观游线的合理性与便捷性、建设项目可行性等因素。

（五）补充评估拟建建筑规模、体量、高度和外观设计对城子崖遗址及其周边景观环境的影响，并提出有针对性的减缓措施。

三、请你局指导建设单位，根据上述意见对所报方案做进一步修改和完善，做好文物影响评估，经你局核准后按程序另行报批。

国家文物局

2017年4月21日
