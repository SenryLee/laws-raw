# 住房城乡建设部办公厅关于公布2016年县（市）域乡村建设规划和村庄规划示范名单的通知

建办村[2017]10号

各省、自治区住房城乡建设厅，北京市规划和国土资源管理委，天津市规划局，上海市规划和国土资源管理局，重庆市规划局，新疆生产建设兵团建设局：

按照《住房城乡建设部办公厅关于开展2016年县（市）域乡村建设规划和村庄规划试点工作的通知》（建办村函[2016]411号）要求，在各地推荐的基础上，经组织专家评审，确定河北省邢台市邢台县等37个县（市）、北京市门头沟区大台街道千军台村等87个村庄为2016年全国县（市）域乡村建设规划和村庄规划示范，现予公布。

本次公布的县（市）域乡村建设规划和村庄规划示范均按照《住房城乡建设部关于改革创新全面有效推进乡村规划工作的指导意见》（建村[2015]187号）要求，创新了规划编制方式和内容，实践了符合农村实际的规划理念和方法，大幅提升了乡村规划的实用性。县域乡村建设规划示范普遍建立了多部门协调的编制机制，确立了决策先行的规划理念，提出了垃圾、污水治理等农村人居环境薄弱环节的解决措施。村庄规划示范大多以村委会为编制主体，提出了农房建设管理、村庄整治安排等要求，规划成果简单易懂并纳入了村规民约。我部将择优编制示范案例集，并通过互联网等形式予以宣传展示。

各地要认真总结县（市）域乡村建设规划和村庄规划示范经验，大力开展宣传推广，加快推进县（市）域乡村建设规划编制和修编，不断提高村庄规划的覆盖率和实用性。

附件：2016年县（市）域乡村建设规划和村庄规划示范名单

中华人民共和国住房和城乡建设部办公厅

2017年2月22日
