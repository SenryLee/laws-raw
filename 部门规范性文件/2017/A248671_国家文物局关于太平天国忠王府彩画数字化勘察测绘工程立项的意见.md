# 国家文物局关于太平天国忠王府彩画数字化勘察测绘工程立项的意见

## 关于太平天国忠王府彩画数字化勘察测绘工程立项的意见

办保函〔2017〕248号

江苏省文物局：

你局《关于审批太平天国忠王府彩画数字化勘察测绘工程立项的请示》（苏文物保〔2017〕30号）收悉。经研究，我局意见如下：

一、立项报告关于项目实施的必要性和可行性论述不充分，暂不同意立项。

二、尚需从以下方面进一步完善立项报告：

（一）补充说明以往开展的壁画保护工作，包括内容、措施、后期效果，以及相关数据、研究成果等信息资料积累情况。在此基础上分析说明目前存在的问题，明确项目目标和具体内容，进一步论证项目实施的必要性和紧迫性。

（二）从技术和知识产权两方面进一步论证彩画数字化勘察测绘成果未来应用的前景及可操作性。

（三）应注意避免草率立项和重复投入。

三、请你局指导项目单位根据实际情况和上述意见重新梳理相关工作，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年3月16日
