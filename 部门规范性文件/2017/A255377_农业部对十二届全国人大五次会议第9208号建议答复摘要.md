# 农业部对十二届全国人大五次会议第9208号建议答复摘要

## 十二届全国人大五次会议第9208号建议答复摘要

农办议〔2017〕232号

为提高主要农作物薄弱环节机械化水平，农业部、财政部等相关部门采取了一系列措施加以推动。农业部印发了《关于开展主要农作物生产全程机械化推进行动的意见》，聚焦九大粮棉油糖作物、六个关键环节，进一步明确了目标任务、主要内容和保障措施。农机购置补贴政策围绕粮棉油糖等主要农作物生产薄弱环节所需机具，集中、连续地予以补贴支持，有力地提升了主要农作物生产薄弱环节农机装备水平。积极开展主要农作物生产全程机械化试验示范，把最薄弱的环节作为优先主攻方向。开展了农机深松整地作业补助试点，2015-2016年，全国各省（区、市）已累计使用深松作业补助资金35.5亿元，补助作业面积1.4亿亩（次）。部分省份还开展了机械化秸秆还田补助试点。

下一步，我部将会同财政部等相关部门从以下两方面加大工作力度：一是在试点基础上组织专家开展农机作业补贴政策研究，重点在农机作业补助的适宜范围、补助标准、操作办法、资金管理等方面开展研究，为进一步稳步推进农机作业补助奠定基础。二是指导、鼓励地方各级加大投入，积极开展农机作业补贴试点，探索经验，待试点成熟后逐步向全国推广。

农业部

2017年8月18日
