# 农业部对十二届全国人大五次会议第5742号建议的答复

## 对十二届全国人大五次会议第5742号建议的答复

农办议〔2017〕301号

谢辉等10名代表：

你们提出的关于将太阳能光伏水泵纳入国家支持推广的农机购置补贴产品目录的建议收悉。经商财政部、水利部，现答复如下。

为支持农田水利基础设施装备建设，农业部、财政部充分发挥中央财政农机购置补贴政策的引导作用，积极促进节水灌溉机械装备推广应用。目前，已将离心泵、潜水泵、喷灌机等品目列入补贴范围，对属于这些品目的且通过农机推广鉴定的产品，农民可自主购置并可按规定申请补贴。

随着我国农田水利基础设施装备建设的不断加快，特别是高效节水灌溉技术装备的创新应用，农田灌溉对能源的需求也不断加大，在一些电力配套不完善的地区，使用柴油机组驱动提供动力的方式确有不方便之处，且成本较高。近年来，依靠太阳能、风能等绿色能源驱动水泵应用的情形逐渐增多，一些地方在光伏水泵应用方面也取得了积极进展。但光伏水泵在应用中也存在一些运行维护难题，如光伏发电储存和设施野外维护成本高，不用蓄电池时水泵难以稳定出功以致影响喷灌、微灌技术的灌溉均匀性、可靠性，受地形和光伏资源限制影响使用范围等，现阶段常见的“光伏提水+蓄水池+自压灌溉系统”模式在土地一家一户经营方式下，因光伏面板和水池占地等影响，推广和应用在一定程度上受到制约。

下一步，我部将会同财政部、水利部等部门，加大光伏水泵的推广应用。一是做好光伏水泵产品的研发引导，促进光伏驱动灌溉设施的稳定性与可靠性提高。二是鼓励地方在提水灌溉、高效节水灌溉工程建设中，加大光伏水泵推广使用力度，积极探索经济实用、低耗高效的技术模式。三是进一步完善农机购置补贴政策，加强政策宣传，引导更多的光伏水泵生产企业积极申请开展产品补贴资质条件认定工作，尽早将符合要求的产品纳入农机购置补贴范围。

感谢你们对农业农村经济工作的关心，希望今后继续对我部工作给予支持。
