# 公开市场业务交易公告[2017]第74号——关于人民银行于2017年4月20日以利率招标方式开展了1000亿元逆回购操作的公告

## 公开市场业务交易公告

[2017]第74号

人民银行于2017年4月20日以利率招标方式开展了1000亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 7天 | 700亿元 | 2.45% |
| 14天 | 200亿元 | 2.60% |
| 28天 | 100亿元 | 2.75% |

中国人民银行公开市场业务操作室

二〇一七年四月二十日
