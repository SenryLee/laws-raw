# 农业部办公厅关于答复从蒙古国进口屠宰羊事宜的函

农办医函〔2017〕19号

质检总局办公厅：

《质检总局办公厅关于从蒙古国进口屠宰羊事宜的函》（质检办动函〔2017〕1046号）收悉。

经研究，我部同意你局关于按照云南试点模式推进内蒙古自治区从蒙古国进口屠宰羊的原则意见。建议先由内蒙古自治区人民政府报请国务院同意后，由农业部牵头会同你局等有关部门具体组织实施。

农业部办公厅

2017年8月21日
