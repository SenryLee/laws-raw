# 国家文物局办公室关于蒙城万佛塔保护规划意见的函

办保函〔2017〕1389号

安徽省文物局：

你局《关于批准蒙城万佛塔保护规划的请示》（皖文物保〔2016〕128号）收悉。经研究，我局意见如下：

一、所报规划价值评估和研究不足，保护区划不合理，规划深度不够，我局暂不同意胜蒙城万佛塔保护规划。

二、对该规划提出以下修改意见：

（一）应加强蒙城万佛塔和慈氏寺历史格局研究，全面搜集、整理文献史料，明确塔、寺院和周边历史街巷的关系。

（二）完善现状评估，加强地下水对塔基的影响评估内容。合理确定规划范围，深化环境影响分析内容。补充文物建筑稳定性评估、已实施的文物保护工程情况和视域分析内容。

（三）应根据现状评估结论和保护管理需要，科学调整保护区划边界，增强可操作性。进一步论证将拟建公园全部纳入保护范围的科学性，补充调整依据。完善保护区划管理规定，调整与细化建设控制地带的建筑高度、规模、体量和外观等控制指标。同时，应进一步论证环境控制区设置的必要性和可行性，建议将其纳入建设控制地带统筹考虑。

（四）针对现状评估结论，研提具体的文物保护措施。厘清文物本体保护、环境整治和专项措施。补充地下水的监测措施。

（五）根据文物保护需要合理制定专项规划。应从文物保护展示需求出发，进一步调整环境整治的内容和措施要求，协调处理好文物保护和公园建设之间的关系。科学定位蒙城万佛塔的展示利用目标，明确展示利用方式，重点关注文物的历史价值阐释；深化管理规划，明确管理机构的的具体责权。

（六）加强所报规划与城市总体规划、历史文化名城保护规划等相关规划的具体衔接内容。

三、请你局组织有关单位根据上述意见对所报保护规划进行修改、完善，按相关程序另行报批。

国家文物局办公室

2017年12月19日
