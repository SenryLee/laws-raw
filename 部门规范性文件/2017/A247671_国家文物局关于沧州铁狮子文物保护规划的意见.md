# 国家文物局关于沧州铁狮子文物保护规划的意见

## 关于沧州铁狮子文物保护规划的意见

办保函〔2017〕73号

河北省文物局：

你局《关于呈报沧州铁狮子文物保护规划的请示》（冀文物字〔2016〕64号）收悉。经研究，我局意见如下：

一、不同意所报沧州铁狮子文物保护规划。

二、请你局指导当地人民政府组织专业机构，按照《关于沧州旧城（含沧州铁狮子）保护规划编制立项的批复》（文物保函〔2014〕1542号）的要求，综合考虑沧州旧城和沧州铁狮子的整体保护和规划编制工作，明确沧州旧城和沧州铁狮子的保护区划和管理衔接问题，增强规划的可操作性。

三、请你局督促有关单位切实做好沧州铁狮子的日常监测和养护工作，及时发现文物病害险情，适时开展沧州铁狮子数字化专项勘察测绘，留取必要的数据资料，为开展文物本体保护和规划提供依据。

专此函。

国家文物局

2017年2月6日
