# 中国民用航空局关于修订印发《引进民用运输飞机管理办法》的通知

## 关于修订印发《引进民用运输飞机管理办法》的通知

民航发〔2017〕65号

民航各地区管理局,各运输航空公司：

为促进航空运输持续安全和民航行业健康发展，适应航空市场发展需要，按照国务院关于简政放权的要求，我局对《引进民用运输飞机管理暂行办法》（民航发[2012]113号）进行了修订，现印发你们，请遵照执行。原管理办法及相关配套文件即行废止。

中国民用航空局

2017年6月5日
