# 国家文物局关于大芦村古建筑群修缮工程三期立项的意见

## 关于大芦村古建筑群修缮工程三期立项的意见

办保函〔2017〕80号

广西壮族自治区文化厅：

你厅《关于报送灵山县大芦村古建筑群修缮工程三期立项报告的请示》（桂文物报〔2016〕59号）收悉。经研究，我局意见如下：

一、暂不同意大芦村古建筑群修缮工程三期立项。

二、立项报告尚需在以下方面做出修改：

（一）深化现状勘察，补充前两期维修的具体内容、完成情况和维修效果评估，为开展三期工程提供借鉴。

（二）进一步明确杉木园等6处文物建筑的产权归属。根据其各自特点制定针对性的修缮措施，细化工程做法，并统筹考虑文物建筑利用问题。

（三）加强文物建筑历史沿革研究，进一步论证拆除后加或后改墙体的必要性和可行性。

（四）补充各修缮对象的总平面图、工程对象图等图纸。

（五）细化工程经费预算。

三、请你厅根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此。

国家文物局
