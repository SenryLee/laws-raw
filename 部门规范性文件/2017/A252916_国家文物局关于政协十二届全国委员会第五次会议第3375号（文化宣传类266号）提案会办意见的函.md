# 国家文物局关于政协十二届全国委员会第五次会议第3375号（文化宣传类266号）提案会办意见的函

## 关于政协十二届全国委员会第五次会议第3375号（文化宣传类266号）提案会办意见的函

办保函〔2017〕630号

福建省人民政府办公厅：

现就张廷皓委员提出的“关于加强福建尤溪土堡文化遗产保护的提案”，提出以下会办意见：

土堡是我国古代村落防御性建筑的重要代表，福建尤溪境内土堡遗存丰富、特色鲜明，现存约100余处，多分布于盆地、台地及丘陵地带，以村落或家族为单位，以大型、超大型建筑为主，布局对称合理，具有高台阶、高台基、高落差等典型结构特征。土堡多具有堡墙、跑马道、角楼、射击孔等防御设施，建筑内部有木雕、灰塑、彩绘等精美装饰，具有重要的历史、艺术和科学价值，是研究我国特色民居和防御性乡土建筑的重要案例。

我局将积极配合你府，指导福建省文物部门进一步加大对尤溪土堡保护工作的支持力度，重点做好以下工作：

第一，积极开展尤溪土堡的调查研究等基础工作。指导福建省各级文物部门依托第三次全国文物普查有关成果，广泛吸收相关研究保护单位和专家学者，开展尤溪土堡调查研究工作，并根据其价值提请地方人民政府公布为相应级别的文物保护单位。对于其中价值特别重大的，可按程序组织申报全国重点文物保护单位。关于申报世界遗产，国家文物局将根据《保护世界文化和自然遗产公约》及其《操作指南》的规定，以及相关研究、保护等基础工作进展情况，在今后调整《中国世界文化遗产预备名单》工作中予以统筹考虑。

第二，重点做好尤溪土堡的日常保护管理工作。指导相关地方人民政府和有关部门加强尤溪土堡的日常管理，落实“四有”工作，明确管理人员及其保护责任，同时多渠道筹措资金，加大保护投入力度，对于保存现状堪忧和存在险情的土堡及时开展保护维修工作，制定科学可行的保护措施，确保文物安全，并进一步丰富和拓展尤溪土堡的展示利用和宣传教育手段，引导公众自觉参与文物保护，共同保护好历史留给我们的珍贵遗产。

以上意见供参考。

国家文物局

2017年5月22日
