# 国家文物局办公室关于北庭故城遗址西河坝防洪工程的意见

办保函〔2017〕1296号

新疆维吾尔自治区文物局：

你局《关于再次报审北庭故城遗址西河坝防洪工程设计方案（修改稿）的请示》（新文物字〔2017〕32号）收悉。经研究，我局意见如下：

一、所报方案拟采取防洪措施针对性不足，且存在过度干预倾向，我局暂不同意所报北庭故城遗址西河坝防洪工程设计方案（修改稿）。

二、所报方案尚需做以下必要的修改和完善：

（一）应进一步分析西河坝洪水对北庭故城遗址的安全影响，查明原因及影响程度，并在此基础上重新开展防洪工程设计，考虑堵排结合的设计思路，尽量采用传统、简单及环保的防洪措施，充分利用已有防洪设施及生态护坡等，避免过度干预。

（二）补充分析防洪工程建设对北庭故城遗址景观环境的影响，并提出相应的减缓措施。应在满足功能需求的前提下，尽量维持北庭故城遗址周边现有生态景观环境。

（三）补充拟建防洪工程与北庭故城遗址保护范围和建设控制地带的位置关系，并附相应的图纸。

三、请你局指导方案设计单位，根据上述意见进一步修改和完善所报防洪工程设计方案，做好文物影响评估，按照《中华人民共和国文物保护法》第十七条、十八条的规定和涉及北庭故城遗址保护范围或建设控制地带建设项目审批的相关要求，依法报我局审批。

国家文物局办公室
