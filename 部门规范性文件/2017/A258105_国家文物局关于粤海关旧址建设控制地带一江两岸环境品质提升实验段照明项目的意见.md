# 国家文物局关于粤海关旧址建设控制地带一江两岸环境品质提升实验段照明项目的意见

文物保函〔2017〕1901号

广东省文物局：

你局《关于在全国重点文物保护单位粤海关旧址建设控制地带内一江两岸环境品质提升试验段项目照明工程的请示》（粤文物请〔2017〕26号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、对所报项目提出以下修改完善意见：

（一）减弱局部灯光亮度，可适当增加屋顶女墙灯光照明。

（二）细化照明设施安装方案和工程措施。优先利用现有装置安装固定文物建筑本体上的灯具、线管；优先选用不锈钢箍固定新加设备。

（三）选取建筑隐蔽部位进行电路布线串管，电路布设及材料选择应阻燃防火。

（四）补充文物建筑外墙粉刷及建筑构件现状勘察，根据勘察情况，制定相应保护措施。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十八条规定，经城乡建设规划部门批准后实施。工程施工期间，你局应加强监管，确保文物安全。

国家文物局

2017年11月24日
