# 国家文物局关于重庆谈判旧址群——吴铁城官邸修缮工程立项的意见

## 关于重庆谈判旧址群——吴铁城官邸修缮工程立项的意见

办保函〔2017〕411号

重庆市文物局：

你局《关于审批全国重点文物保护单位重庆谈判旧址群——吴铁城官邸修缮工程立项报告的请示》（渝文物〔2017〕11号）收悉。经研究，我局意见如下：

一、暂不同意吴铁城官邸修缮工程立项。

二、请你局指导有关单位，强化现状勘察和文物保存现状评估，准确描述文物建筑形制、历史格局及病害、残损状况，结合文物今后的利用需求进一步明确修缮工程的对象、范围和措施，剔除绿化、基础设施建设及苏联大使馆维修等非文物本体修缮内容。在此基础上，根据我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）要求，另行报批。

国家文物局

2017年4月14日
