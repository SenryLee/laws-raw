# 农业部对十二届全国人大五次会议第9265号建议的答复

## 对十二届全国人大五次会议第9265号建议的答复

农办议〔2017〕137号

马瑞强代表：

您提出的“关于支持内蒙古以科技创新为动力，全力打造国家绿色农畜产品生产加工基地的建议”收悉。经认真研究,现答复如下。

一、关于统筹布局，优先支持内蒙古农牧业重点领域的关键技术的研发

国家一直高度重视内蒙古农牧业科技创新能力建设，支持绿色种植养殖技术的研究与应用。一是支持建设农业部重点实验室。农业部先后在内蒙古启动建设了饲草栽培、加工与高效利用等4个学科群专业性/区域性实验室和8个农业科学观测试验站，内蒙古农牧业重点领域科技创新条件能力建设水平明显提高。二是支持建设现代农业产业技术体系。农业部先后在内蒙古累计建立产业研发中心1个、功能研究室7个、综合试验站40个，遴选首席科学家2人、岗位科学家33人、站长40人。年均支持经费4370万元，立足开展肉羊、肉牛、奶牛、燕麦、向日葵、甜菜等绿色农产品研发与示范推广。三是支持建设畜产加工领域技术研发中心。在国家农产品加工技术研发体系框架内，农业部在全国范围先后认定了49个畜产加工领域技术研发中心，其中内蒙古自治区5个，开展了畜产加工关键共性技术的攻关、引进、集成和示范推广等工作，通过项目合作、政策支持和科企合作等方式，为畜产加工产业的健康、快速发展提供有力的技术支撑。

下一步，农业部将继续支持内蒙古农业科技创新工作，特别是将影响内蒙古绿色农畜产品生产加工领域的重大共性关键技术需求纳入国家农业科技创新联盟、现代农业产业科技创新中心、农业部重点实验室、现代农业产业技术体系建设统筹考虑，不断提升内蒙古农牧业重点领域关键技术研发水平，为内蒙古农牧业绿色发展提供强大的科技支撑。

二、关于加大农牧业科技成果的转化与推广力度

近年来，农业部着力推动内蒙古基层农技推广体系改革与建设、指导开展一系列专项行动和工作试点，有序推进优质草牧种植技术转移转化和示范推广。一是着力推动基层农技推广体系改革与建设。今年以来，农业部按照中央有关决策部署，有序推进基层农技推广体系改革建设，支持内蒙古88个农业县根据农业部发布的年度农业主推技术、地方农业主导产业发展要求和农业生产经营者的技术需求，遴选确定一批符合绿色增产、资源节约、生态环保、质量安全要求的农业主推技术，形成当地技术操作规范，落实到实验示范基地、农技人员和示范主体，促进先进适用技术快速转化应用。二是推动实施“振兴奶业苜蓿发展行动”。农业部从2012年以来每年安排3亿元在全国建设50万亩高产优质苜蓿生产基地。其中，为支持内蒙古建成高效苜蓿产业，2012年到2015年农业部在内蒙古实施“振兴奶业苜蓿发展行动”中累计投入支持资金达到22080万元，占“十二五”项目总投入的18.4%。2016年，继续支持内蒙古苜蓿产业发展，安排“振兴奶业苜蓿发展行动”资金5040万元，支持建设高产优质苜蓿示范基地8.4万亩。三是落实粮改饲试点。2016年中央安排补助资金1.5亿元，支持内蒙古自治区14个旗（县）开展粮改饲试点，推进草畜配套，加快建设现代饲草料生产体系，内蒙古畜牧优质饲料生产水平、供给能力稳步提升，农牧业提质增效、农民增收致富进程明显加快。四是推进草牧业试点。2015年，农业部在农区、牧区（包括半牧区）、垦区、农村改革试验区选择了37个草牧业试验试点区，主要围绕种养结合、草食畜牧业适度规模养殖、草牧业发展金融扶持支持、草原承包经营制度完善、草产业发展等开展试验，力图打通种养业协调发展的通道，建立粮饲兼顾、农牧结合的新型农业结构。内蒙古自治区作为重点区域被纳入支持范围，共有4个旗县和2个农牧场列入试点区域。

下一步，我部一是将继续指导推进内蒙古基层农技推广体系改革，促进先进实用技术成果快速转化落地，助推内蒙古农牧业发展转型升级。二是通过积极争取有关部门支持，加大内蒙古新型职业农民培育培训工作力度，进一步提高内蒙古农牧业从业者科技素质。三是指导推进内蒙古地区农业科教机构农业科技成果权益改革工作，激发广大科技人员多出成果、出好成果、出有用成果，提高农业科技供给质量水平和能力。

三、关于支持内蒙古构建特色产业发展技术支撑体系

一是加快企业科技创新能力与品牌建设。2016年，我部印发了《关于开展农产品加工业质量品牌提升行动的通知》（农加发〔2016〕1号），引导企业提升标准化生产能力、全程化质量控制能力、技术装备创新能力和品牌培育创建能力，加快培育一批知名企业，打造一批知名品牌。近期，我部还将组织全国农产品加工业科技创新和品牌创建宣传活动，利用信息化手段，集中推广、对接一批农牧加工科技成果，并将在全国组织遴选一批农产品加工知名品牌，有计划、有步骤、成规模地开展系列推介宣传，加快培育一批具有广泛影响力和持久生命力的国际、国内知名品牌。二是加强内蒙古畜禽粪污治理。2014—2015年，中央财政安排4000万元用于在内蒙古实施畜禽粪污资源化利用试点项目，主要用来探索适合内蒙古地区畜禽粪污等农业农村废弃物综合利用模式，引导形成布局合理、规模适度、农牧结合、循环发展的废弃物资源化利用机制。

下一步，农业部将继续加强农牧加工技术与装备研发示范、加工技术基地建设，提升畜产加工科技的集成创新与熟化应用能力，积极开展农牧加工技术推广与农牧加工业品牌创建活动。十三五期间，农业部计划在内蒙古建设一批生鲜猪肉加工、干乳制品加工、畜禽副产物加工等畜产加工技术集成基地，促成先进技术成果的集成应用。

感谢您对农业科技工作的关心，并希望继续支持我部工作。
