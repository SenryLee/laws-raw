# 国土资源部关于同意伦敦自然博物馆参展化石出境的函

国土资函〔2017〕65号

上海科技馆：

你馆关于英国伦敦自然博物馆来我国参加上海自然博物馆《灭绝：并非世界末日》展览的化石出境的申报材料收悉。经国家古生物化石专家委员会组织专家复核，出境化石共4件，其中，1件三叶虫（编号01）、1件菊石（编号03）、1件鲎（编号04、正负模）、1件银杏化石（编号05）。与英国伦敦自然博物馆2016年9月29日进境时由我部选派专家鉴定核查、拍照登记的化石一致。按照《古生物化石保护条例》第三十二条的有关规定，准予出境。

2017年2月8日
