# 国家文物局关于南京城墙监测预警平台建设的意见

## 关于南京城墙监测预警平台建设的意见

办保函〔2017〕478号

江苏省文物局：

你局《关于审批南京城墙监测预警平台建设方案的请示》（苏文物保〔2017〕25号）收悉。经研究，我局意见如下：

一、所报方案前期研究不足，设计思路不当，我局暂不同意在南京城墙保护范围和建设控制地带内进行南京城墙监测预警平台建设。

二、对所报方案提出以下修改意见：

（一）加强前期研究，系统梳理南京城墙已有保护工作成果，进一步分析文物保护管理面临的主要问题，科学论证建立监测预警平台的必要性和可行性。

（二）应开展南京城墙及周边环境的整体调查评估，分析城墙保存状况、主要病害、重点残损部位、周边建设项目及游客影响等，在此基础上明确监测需求，调整设计思路。建议现阶段应重点做好存在险情和安全隐患部位的城墙本体监测，为后续保护工作提供依据。

（三）应结合监测需求和现场条件重新构建监测指标体系，说明监测系统的功能与基本要求、测点与线路布置的原则与基本要求、设备选型的选择与基本要求以及监测设备作业环境所应满足的基本要求等，明确各监测项的具体监测方式、施工方法及所需满足的要求与规定、监测布点、频率和数据分析方法、预警值设置方式等，尽量减少在文物本体上安装设施设备。同时，应深化监测预警方案，明确监测工作与日常管理、安全巡护、游客控制、保养维护等工作的衔接措施，增强针对性、科学性和可操作性。

三、请你局根据所提意见，对项目方案进行修改完善后，按程序另行报批。

专此函。

国家文物局

2017年4月20日
