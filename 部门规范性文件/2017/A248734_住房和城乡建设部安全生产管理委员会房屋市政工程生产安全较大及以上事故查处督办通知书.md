# 住房和城乡建设部安全生产管理委员会房屋市政工程生产安全较大及以上事故查处督办通知书

## 房屋市政工程生产安全较大及以上事故查处督办通知书

建安[2017]7号

安徽省住房和城乡建设厅：

2017年3月27日12时54分，你省安庆市桐城市金色阳光城7号楼工程塔吊安装过程中发生倾覆，造成3名施工人员死亡。根据《房屋市政工程生产安全和质量事故查处督办暂行办法》（建质[2011]66号）的规定，现对该起事故查处工作启动督办程序。

请你厅依照有关规定，组织并督促当地住房城乡建设部门按照要求做好事故查处工作，2017年5月27日前将查处情况报告我部。

联系人及电话：王瑞胜，010-58933920。

中华人民共和国住房和城乡建设部安全生产管理委员会

2017年3月28日
