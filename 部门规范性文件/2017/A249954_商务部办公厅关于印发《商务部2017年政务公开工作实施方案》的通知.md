# 商务部办公厅关于印发《商务部2017年政务公开工作实施方案》的通知

商办厅函〔2017〕177号

部机关各单位、各直属事业单位：

为贯彻落实《国务院办公厅关于印发2017年政务公开工作要点的通知》（国办发〔2017〕24号），进一步提高政务公开工作的质量和效率，按照国务院办公厅具体部署要求，经商部内相关单位，办公厅制定了《商务部2017年政务公开工作实施方案》（以下简称《实施方案》）。《实施方案》已经部领导批准，现印发给你们，请结合实际认真贯彻落实。

商务部办公厅

2017年5月3日

## 商务部2017年政务公开工作实施方案

根据《中共中央办公厅 国务院办公厅印发〈关于全面推进政务公开工作的意见〉的通知》（中办发〔2016〕8号）及其实施细则和《中华人民共和国政府信息公开条例》（国务院第492号令），为贯彻落实《国务院办公厅关于印发2017年政务公开工作要点的通知》（国办发〔2017〕24号）有关要求，进一步推进政务公开工作，增强政府公信力、执行力，保障人民群众知情权、参与权、表达权、监督权，现结合商务部实际，制定本实施方案。

一、指导思想

全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，认真落实2017年《政府工作报告》有关部署，紧紧围绕经济社会发展和人民群众关注关切，全面推进商务领域决策、执行、管理、服务、结果公开（以下统称“五公开”），加强解读回应，扩大公众参与，增强公开实效，以供给侧结构性改革为主线，助力稳增长、促改革、调结构、惠民生、防风险，以优异成绩迎接党的十九大胜利召开。

二、主要目标

按照党中央、国务院关于全面推进政务公开工作的总体部署，综合利用商务部政府网站、主流媒体和新媒体平台，积极推进“放管服”改革、“互联网+政务服务”和“五公开”，扎实做好信息发布和政策解读工作，认真回应公众关切，进一步推进政务阳光透明。

三、主要任务

（一）全面推进“放管服”改革信息公开。

一是继续深化改革，减少优化行政审批事项，及时修订权力清单后对外公布。在国务院统一部署下，研究开展责任清单编制工作（牵头单位：办公厅）。二是推进主动公开目录体系建设，进一步明确商务领域“五公开”的主体、内容、时限、方式等，2017年底前制定商务部主动公开基本目录（牵头单位：办公厅）。三是推进政策执行公开和落实情况公开。围绕简政放权、放管结合、优化服务，细化公开执行措施、实施步骤等，公布进展和完成情况（牵头单位：市场秩序司、市场运行司、反垄断局、外贸司、服贸司、安全与管制局、外资司、援外司、合作司、台港澳司）。四是进一步扩大公开信息的范围。推进商务领域政策法规、重大新闻公开的同时，做好人事任免、公务员考录、部门预决算、政府采购信息公开（牵头单位：办公厅、人事司、财务司）。五是加强行政许可、行政处罚等信用信息公示。按照商务部行政处罚事项目录，规范、完整、清晰、准确地向社会公开行政处罚决定书、执法依据、处罚事由等信息（牵头单位：条法司、市场秩序司、市场运行司、反垄断局、外贸司、服贸司、安全与管制局、外资司、援外司、合作司）。

（二）全面提升商务重点工作政务公开的质量与实效。

一是加大外贸稳增长、调结构、转型升级等方面的政策措施和经验做法公开力度，及时回应企业、行业等各方关切，主动发布解读外贸运行动态等权威信息（牵头单位：外贸司）。二是加强对各自贸试验区建设进展情况公开力度，及时主动发布解读自贸试验区各项改革措施，回应社会关切，总结宣传自贸试验区试点经验（牵头单位：外资司）。三是加强我国对外投资政策的宣传解读，主动发布服务“一带一路”建设、推进国际产能合作、促进中国企业“走出去”等动态信息，及时提示对外投资风险（牵头单位：合作司）。四是加强内贸流通领域政务公开。围绕加快内贸流通创新推动供给侧结构性改革扩大消费专项行动，加强政策解读（牵头单位：市场秩序司、市场建设司、流通发展司、市场运行司）。完善消费市场运行情况公开机制，进一步加强统计监测信息发布（牵头单位：市场运行司）。推动公众参与，助力重要产品追溯体系建设（牵头单位：市场秩序司）。加大对侵权假冒行为的公开力度（牵头单位：打击侵权假冒办）。

（三）加快推进“互联网+政务服务” （牵头单位：电子商务司）。

一是梳理规范网上服务事项。编制政务服务事项目录，实行政务服务事项编码管理，规范事项名称、条件、材料、流程、时限等，做到“同一事项、同一标准、同一编码”。二是优化完善网上政务服务流程。大力推进行政许可事项办理全流程信息化工作，启动网上政务大厅试运行工作，将“企业奔波”变“信息跑腿”， 提升政务服务标准化、网络化、智慧化水平。三是做好公开信息服务。在商务部网站和实体政务大厅集中全面公开与政务服务事项相关的法律法规、政策文件、通知公告、办事指南、审查细则、常见问题、监督举报方式等。四是规范网上政务服务平台建设。继续优化商务部统一平台功能，加大信息系统整合力度，扩大整合范围，实现统一平台上各项应用服务全面互联互通。

（四）全方位打通商务信息获取渠道。

一是通过商务部网站信息公开申请在线提交系统、政务大厅信息公开咨询窗口，做好社会公众对政府信息公开的各类咨询和申请的答复工作。通过网站实时播报商务部新闻发布会，发布在线访谈，及时答复公众留言和邮件（牵头单位：电子商务司）。二是不断完善新闻发布制度，通过新闻发布会、媒体吹风会、网站日常新闻发布以及月度商务运行情况发布等多种渠道，向社会公众发布商务数据，宣传商务工作（牵头单位：办公厅）。三是通过《对外经济贸易文告》集中公开对外发布有关法律法规及其他政策措施，方便社会公众及时了解最新经贸政策动向（牵头单位：办公厅）。

（五）构建全方位商务领域宣传解读机制（牵头单位：办公厅）。

一是完善新闻工作机制建设。重点做好《商务部新闻宣传工作管理办法》和实施细则的修订工作，努力建立内外联动的工作机制，探索引入第三方机构，对商务部开展新闻舆论工作情况进行综合评估，进一步推动落实新闻舆论工作职责。二是做好商务领域重要工作宣传解读。在开展重大商务活动、出台重要政策措施前，组织召开专题发布会或媒体吹风会，由商务部相关司局负责同志进行介绍和解读。商务部负责同志主动出席国务院例行政策吹风会，做好商务部工作的宣传解读，回应社会关切。三是整合构建新媒体传播平台。顺应分众化、差异化的传播趋势，逐步推进商务系统微信公众号矩阵建设，与各地方商务主管部门的微信公众号协同联动，把商务部新媒体平台打造成权威商务新闻发布平台。

（六）研究完善政务公开管理考核制度（牵头单位：办公厅）。

一是建立健全政务公开制度。研究完善涵盖主动公开、依申请公开、保密、考核等方面政务公开工作的制度体系建设，修订《商务部政府信息公开指南》和《商务部政府信息公开目录编制规范》。二是加大考核评估力度。进一步完善《商务部政府信息公开工作考核办法（试行）》等制度规定，健全政务公开专项考核机制，提升考核工作的科学化和规范化水平。
