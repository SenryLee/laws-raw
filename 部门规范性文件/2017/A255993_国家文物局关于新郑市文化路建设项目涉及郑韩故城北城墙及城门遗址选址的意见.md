# 国家文物局关于新郑市文化路建设项目涉及郑韩故城北城墙及城门遗址选址的意见

文物保函〔2017〕1617号

河南省文物局：

你局《关于上报新郑市文化路项目涉及郑韩故城北城墙遗址段施工设计方案的请示》（豫文物〔2017〕256号）收悉。经研究，我局意见如下：

一、原则同意新郑市文化路改扩建项目涉及郑韩故城北城墙及城门遗址的选址及建设方案。

二、该建设项目应严格遵守现有方案一的设计思路，采用平交方式从瓮城遗址东侧穿越郑韩故城北城墙及城门遗址，并进一步缩小路幅，尽量远离地面文物遗存。同时，应进一步补充所涉及遗址的专项保护展示方案，做好遗址的加固回填以及必要的振动防护，并充分考虑遗址后续展示需要，补充设计必要的东西向人行通道，确保城墙遗址展示的连续性。

三、请你局组织专业考古研究单位，在该项目拟建区域进一步开展必要的考古调查和发掘工作。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

四、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，按照《中华人民共和国文物保护法》第十七条的规定，报河南省人民政府批准。所涉及遗址的专项保护展示方案经你局核准后实施。

五、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促工程部门切实做好工程施工过程中的文物保护工作，确保文物安全。

国家文物局

2017年9月11日
