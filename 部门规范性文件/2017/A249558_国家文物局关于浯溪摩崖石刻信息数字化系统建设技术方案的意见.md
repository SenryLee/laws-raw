# 国家文物局关于浯溪摩崖石刻信息数字化系统建设技术方案的意见

## 关于浯溪摩崖石刻信息数字化系统建设技术方案的意见

办保函〔2017〕374号

湖南省文物局：

你局《关于审批〈浯溪摩崖石刻信息数字化系统建设技术方案〉的请示》（湘文物报〔2016〕160号）收悉。经研究，我局意见如下：

一、所报方案与我局《关于浯溪摩崖石刻数字化勘察项目立项的批复》（文物保函〔2016〕1089号）要求不符，我局不同意所报浯溪摩崖石刻信息数字化系统建设技术方案。

二、对该方案提出以下修改意见：

（一）应以数字化勘察测绘为主要工作内容，进一步调整工作对象、工程性质和目标定位，增强方案的针对性和可操作性。应充分考虑自然灾害威胁和石刻安全问题，补充湘江水文信息，客观评估江水冲蚀影响，定量定位分析病害结果。

（二）数字化勘察工作应以加强文物保护为目标，与石刻保护和监测工作相结合，根据文物保护工程的需要科学采集、整理文物信息，突出数字化勘察的针对性，分类确定采集技术手段、精度要求。

（三）应基于国家或地方统一坐标高程系统建立控制网，保证勘察工作的连续性。

（四）补充题刻崖壁数字化记录内容，形成专业化数字线划图成果。

（五）石刻三维激光扫描和近景摄影测量前，应由专业人员清理遮挡石刻的植物和表面污染物，提高信息采集质量。

（六）不同意进行数字化系统建设。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，按程序另行报批。

专此函。

国家文物局

2017年4月5日
