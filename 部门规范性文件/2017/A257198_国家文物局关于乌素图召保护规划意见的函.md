# 国家文物局关于乌素图召保护规划意见的函

文物保函〔2017〕1811号

内蒙古自治区文物局：

你局《关于呼和浩特市乌素图召文物保护规划评审的请示》(内文物发〔2017〕140号)收悉。经研究，我局批复如下：

一、原则同意所报乌素图召保护规划。

二、对该规划提出以下修改意见：

（一）应进一步梳理文物建筑的年代、面积、修筑特点、所处位置、功能格局等，并总结分布特征和关联性，体现各寺庙之间的区域关系；补充说明壁画分布情况及保存状态；探明广寿寺大殿、西配殿遗址，以明确保护措施及场地整治措施。

（二）深化各项评估内容。

1. 应将历史环境作为完整性评估的考虑因素，重点研究地貌、水系、植被、庙产等。

2. 进一步深化文物历史、科学、艺术、社会文化等价值评估。

3. 现状评估中应明确已制定保护方案的实施对象。

4. 补充分析地质灾害、展示利用、管理措施等方面存在的问题。

（三）进一步完善保护区划，建议保护范围南侧、东侧以临近河流沟渠为界适当微调。

（四）在对南部广场的规模尺度是否合适进行评估的基础上，结合对历史上宗教仪轨活动场所的研究，制定寺庙内外公共空间场地的恢复计划，保持这些场所的历史环境特征。

（五）完善环境整治规划，根据历史环境研究成果合理控制文物周边环境整治相关内容。明确拆除搬迁后的场地清理问题、河道治理、西侧庙区库房整治等内容。不同意停车场的建设位置，建议向西移至建设控制地带以外。

（六）进一步完善管理机制，应在评估的基础上明确文物部门和宗教部门在保护管理、日常维护和安全防护等方面的责权，妥善处理好文物保护与宗教活动的关系。

（七）进一步规范、完善文本。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的乌素图召保护规划报请内蒙古自治区人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好乌素图召文物保护的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年11月2日
