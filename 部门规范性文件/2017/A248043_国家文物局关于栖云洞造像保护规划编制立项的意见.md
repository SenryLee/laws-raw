# 国家文物局关于栖云洞造像保护规划编制立项的意见

## 关于栖云洞造像保护规划编制立项的意见

办保函〔2017〕179号

福建省文物局：

你局《关于全国重点文物保护单位栖云洞造像保护规划立项的请示》（闽文物字〔2016〕594号）收悉。经研究，我局意见如下：

一、所报立项报告对规划编制的必要性和可行性论述不足，文本深度不够，我局暂不同意栖云洞造像保护规划编制立项。

二、请你局指导当地人民政府加强“四有”建设，完善栖云洞造像的保护区划、管理规定和具体保护管理措施，严格控制周边建设活动。加强日常保护管理，针对文物本体及栖云洞岩体的残损病害状况和发展趋势，适时开展相关保护工作，确保文物及周边环境安全。

专此函。

国家文物局

2017年2月24日
