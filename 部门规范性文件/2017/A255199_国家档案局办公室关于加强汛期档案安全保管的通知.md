# 国家档案局办公室关于加强汛期档案安全保管的通知

各省、自治区、直辖市档案局、馆，各计划单列市档案局、馆，新疆生产建设兵团档案局、馆，中央和国家机关各部委档案部门，中央军委办公厅保密和档案局，各人民团体档案部门，各中央企业档案部门：

当前全国已全面进入汛期，强降雨南北并发，降雨范围广、强度大，防汛抗洪工作面临严峻考验。北方地区暴雨洪灾突发性强、预见期短，南方地区近期已遭遇多轮暴雨，江南、华南部分地区遭受严重洪涝灾害。据气象部门预测，今年盛夏气候状况总体偏差，极端天气气候事件多发。同时，主汛期雨情汛情变化快，有可能出现旱涝急转，给人民群众生命财产带来严重损失。各级档案部门要深入贯彻2017年国家防总第一次全体会议和全国档案安全工作会议精神，贯彻落实国家档案局《关于进一步加强档案安全工作的意见》，高度重视汛期档案安全保管工作，提早做好各项准备，采取必要措施，确保档案绝对安全。现就有关事项通知如下：

一、各级档案部门要高度重视汛期的档案安全，严格落实防汛责任。洪涝、台风及其次生灾害是危害档案安全的重要因素，各地要高度重视，增强责任感、使命感和紧迫感，把汛期档案安全保管工作作为当前阶段的重要任务，抓紧抓实，不能有丝毫的松懈和麻痹。要健全工作机制，落实防汛责任，各级责任人要强化担当意识，履职尽责，确保安全防范工作指挥到位、职责明确、措施有效，确保安全。

二、各级档案部门要加强安全检查，消除各种隐患。收到本通知后，要对馆舍建筑和档案室防汛安全进行拉网式排查，发现危房、库房漏雨、防雷装置失效、排水设施不畅等不安全因素要立即向上级主管部门汇报，及时采取遮盖、加固、支顶、围挡、疏通、防渗以及维修更换防雷装置等有效措施进行补救与防范。收到极端天气预警，要组织专人对馆（室）重点部位进行安全检查，加强洪涝、泥石流等次生灾害的防范，确保各项工作准备就绪。要做好汛期档案保护工作，进一步加强相关设备的检修与维护，有效控制档案库房温湿度，避免档案受潮、发霉。

三、各级档案部门要积极做好应急准备，完善方案预案，提升保障能力。吸取往年经验教训，进一步提升预警能力，完善有关预案，组织应急演练，提高档案部门工作人员的防范意识。与气象、水利等相关部门保持紧密联系，高度关注气象、地质灾害预报和天气形势变化，储备必要的应急救援装备和物资。遇到紧急情况危及档案安全时，档案部门要迅速反应、主动应对，及时向党委、政府报告，及时转移或保护重要档案，确保档案安全，同时应注意做好工作人员的安全防护。要强化信息报送，加强应急值守，确保信息渠道畅通，遇紧急情况能及时启动应急预案，汛情易发地区应实行汛期24小时值班和领导带班制度。如发生档案因灾受损情况，要立即组织抢救并上报国家档案局。
