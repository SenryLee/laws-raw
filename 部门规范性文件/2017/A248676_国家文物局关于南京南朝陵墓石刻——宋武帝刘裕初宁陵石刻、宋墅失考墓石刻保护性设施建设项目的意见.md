# 国家文物局关于南京南朝陵墓石刻——宋武帝刘裕初宁陵石刻、宋墅失考墓石刻保护性设施建设项目的意见

## 关于南京南朝陵墓石刻——宋武帝刘裕初宁陵石刻、宋墅失考墓石刻保护性设施建设项目的意见

办保函〔2017〕241号

江苏省文物局：

你局《关于审批南京南朝陵墓石刻（宋武帝刘裕初宁陵石刻及宋墅失考墓石刻）保护构筑物设计方案的请示》（苏文物保〔2016〕309号）收悉。经研究，我局意见如下：

一、不同意所报南京南朝陵墓石刻——宋武帝刘裕初宁陵石刻、宋墅失考墓石刻保护性设施建设项目。

二、应加强考古研究，明确南京南朝陵墓石刻的分布范围、数量、与陵墓之间的空间位置关系，科学确定石刻原有位置和后期人为扰动情况。

三、进一步明确南京南朝陵墓石刻的保存现状、主要病害及周边历史环境保存情况，分析南朝陵墓石刻集中保护的可行性，研提迁移保护和原址保护的具体思路、设计方案。

四、请你局指导当地人民政府组织专业机构，按照《关于南京南朝陵墓石刻保护规划编制立项的批复》（文物保函〔2012〕1818号）的要求，抓紧编制保护规划，统筹考虑文物保护、展示利用、环境整治等方面工作。同时，应切实加强南京南朝陵墓石刻的日常巡查和监测工作，采取有效措施改善文物周边环境，确保文物安全。

专此函。

国家文物局

2017年3月14日
