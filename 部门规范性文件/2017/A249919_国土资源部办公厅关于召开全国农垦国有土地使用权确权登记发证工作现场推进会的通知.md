# 国土资源部办公厅关于召开全国农垦国有土地使用权确权登记发证工作现场推进会的通知

国土资厅函〔2017〕625号

各省、自治区、直辖市国土资源主管部门，新疆生产建设兵团国土资源局，中国土地勘测规划院、中国国土资源报社、国土资源部不动产登记中心：

为落实好《中共中央 国务院关于进一步推进农垦改革发展的意见》（中发〔2015〕33号）提出的“用3年左右时间基本完成农垦国有土地使用权确权登记发证任务”要求，加快推进全国农垦国有土地使用权确权登记发证工作，部决定于5月19-20日,在江西省鹰潭市召开全国农垦国有土地使用权确权登记发证工作现场推进会。现就有关事项通知如下：

一、会议内容

（一）交流典型地区农垦国有土地使用权确权登记发证工作经验和做法，现场察看国有农场土地确权登记发证工作。

（二）解读农垦国有土地使用权确权登记相关政策。

（三）培训农垦国有土地权籍调查技术方法等。

（四）研究部署下一阶段农垦国有土地使用权确权登记发证工作。

二、参会人员

（一）河北、内蒙古、辽宁、吉林、江西、湖北、湖南、福建、甘肃、青海、新疆、新疆生产建设兵团等农垦国有土地使用权确权登记任务较重省份国土资源主管部门负责同志（各1人），各省（区、市）国土资源主管部门、新疆生产建设兵团国土资源局地籍处（不动产登记局）处长（局长）（各1人）。

（二）部地籍管理司（不动产登记局）负责同志及相关人员。

（三）部不动产登记中心、规划院等负责同志，国土资源报社记者等相关工作人员。

三、时间与地点

会议时间：5月18日报到，5月19-20日开会。

会议地点：江西省鹰潭市。

报到地点：沁庐道苑酒店（江西省鹰潭市月湖区梅园大道103号）。

电 话：吴经理 15083672300,0701-6651666。

四、有关要求

（一）各省（区、市）及新疆生产建设兵团准备农垦国有土地使用权确权登记发证工作进展情况书面材料150份带到会上。

（二）请与会各单位根据本通知要求，将填好的“参会回执单”（见附件）于5月9日前传真至部地籍管理司（不动产登记局）和江西省鹰潭市国土资源局，并将电子版发送至部地籍管理司（不动产登记局）邮箱。
