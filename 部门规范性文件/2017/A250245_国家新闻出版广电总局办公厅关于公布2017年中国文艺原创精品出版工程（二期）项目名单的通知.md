# 国家新闻出版广电总局办公厅关于公布2017年中国文艺原创精品出版工程（二期）项目名单的通知

## 关于公布2017年中国文艺原创精品出版工程（二期）项目名单的通知

新广出办发[2017]28号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央和国家机关有关部委、民主党派、人民团体新闻出版主管部门，中央军委政治工作部宣传局，中央各重点出版集团，有关中央直属企业：

为深入贯彻习近平总书记系列重要讲话精神，全面落实《中共中央关于繁荣发展社会主义文艺的意见》，推出更多文艺原创精品出版物，2016年12月，国家新闻出版广电总局办公厅下发《关于申报中国文艺原创精品出版工程（二期）项目的通知》（新广出办发〔2016〕103号）。通知下发后，各地区各部门高度重视，精心组织，积极申报，全国各有关单位共申报、推荐选题896种，经过总局论证、筛选，最终确定2017年中国文艺原创精品出版工程（二期）项目32种（名单见附件）。现予以公布，并就有关事项通知如下：

一、各省、自治区、直辖市新闻出版广电局和有关出版单位主管部门要高度重视中国文艺原创精品出版工程项目的出版工作，加强领导，明确任务，提供保障，确保这些重点选题按申报计划完成出版。

二、承担项目出版任务的相关出版单位，要切实抓好选题的组稿、编辑、加工、印刷和发行等各环节工作，涉及重大选题备案范围的，要按照相关规定及时履行重大选题备案程序。

三、入选的精品出版物将与国家出版基金项目衔接，经国家出版基金规划管理办公室组织专家评审通过后予以资助。入选出版物不占出版单位当年国家出版基金项目申报名额。

四、国家新闻出版广电总局将组织新闻媒体加大对已出版的入选出版物的宣传报道，并集中宣传报道中国文艺原创精品出版工程（二期）项目的出版情况。各地区各部门要提前准备、制定宣传方案，组织相关出版、发行单位做好展示展销、宣传推广工作，扩大优秀作品的社会影响力，为党的十九大胜利召开营造良好的文化氛围。

特此通知。
