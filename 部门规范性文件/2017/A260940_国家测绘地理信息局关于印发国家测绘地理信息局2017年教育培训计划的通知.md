# 国家测绘地理信息局关于印发国家测绘地理信息局2017年教育培训计划的通知

## 关于印发国家测绘地理信息局2017年教育培训计划的通知

国测人发〔2017〕9号

各省、自治区、直辖市、计划单列市测绘地理信息行政主管部门，新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司室：

《国家测绘地理信息局2017年教育培训计划》已经国家测绘地理信息局党组会议审议通过，现予印发，请认真贯彻执行。

教育培训工作是深入贯彻实施科教兴测和人才强测战略、建设高素质测绘地理信息干部人才队伍的先导性、基础性、战略性工作，国家测绘地理信息局高度重视。现就贯彻落实好2017年教育培训计划提出如下要求：

一、突出理论武装。要以坚定理想信念为重点，突出党的理论教育和党性教育，重点学习习近平总书记系列重要讲话精神,党的十八大和十八届三中、四中、五中、六中全会精神和将于今年召开的党的十九大精神，要将上述内容纳入教学计划，贯穿教学始终。

二、突出业务能力建设。要以提高履职能力为重点，紧紧围绕国家测绘地理信息局中心工作及测绘地理信息事业发展产生的新情况、带来的新问题、需要的新知识，有针对性地开展教育培训，不断推进干部队伍知识更新。

三、确保培训质量。各培训承办单位要坚持需求导向、问题导向，科学设计教育培训内容，增强授课内容与培训需求的一致性，切实提高培训的针对性和实效性，并确保不出现政治性问题。每期培训结束后，要对课程设置、培训效果、组织管理等进行评估。

四、加强培训管理。各单位要高度重视教育培训工作，认真贯彻落实《干部教育培训工作条例》，统筹考虑工作需要、干部晋升等因素，积极选派学员参训，并为学员参训提供保障条件。各承办单位要严格执行计划，不得随意调整变更培训名称、地点、内容、对象和时间。要严格执行国家培训费管理办法，严禁以任何形式向参训人员收费。培训结束后1个月内将培训实施情况报国家测绘地理信息局人事司。
