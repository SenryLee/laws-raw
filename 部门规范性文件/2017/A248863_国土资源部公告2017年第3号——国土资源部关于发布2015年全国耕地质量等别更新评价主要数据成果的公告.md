# 国土资源部公告2017年第3号——国土资源部关于发布2015年全国耕地质量等别更新评价主要数据成果的公告

## 国土资源部公告

2017年第3号

## 国土资源部关于发布2015年全国耕地质量等别更新评价主要数据成果的公告

根据《中华人民共和国土地管理法》和《中华人民共和国土地管理法实施条例》相关规定，以及《国土资源部办公厅关于印发〈耕地质量等别调查评价与监测工作方案〉的通知》（国土资厅发〔2012〕60号）要求，国土资源部统一部署安排，自2014年开始，全面开展耕地质量等别年度更新评价工作，现将2015年全国耕地质量等别更新评价主要数据成果予以发布。

2017年1月17日

附件：2015年全国耕地质量等别更新评价主要数据成果
