# 国家食品药品监管总局办公厅关于印发保健食品备案工作指南(试行)的通知

食药监特食管〔2017〕37号

各省、自治区、直辖市食品药品监督管理局，总局保健食品审评中心、行政事项受理服务和投诉举报中心：

根据《中华人民共和国食品安全法》《保健食品注册与备案管理办法》有关规定，国家食品药品监督管理总局制定了《保健食品备案工作指南（试行）》。现予公布，自公布之日起施行。

食品药品监管总局

2017年5月2日
