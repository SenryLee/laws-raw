# 国家发展改革委关于印发《全国红色旅游经典景区三期总体建设方案》的通知

发改社会〔2017〕1881号

各有关省、自治区、直辖市及新疆生产建设兵团发展改革委：

现将《全国红色旅游经典景区三期总体建设方案》印发给你们，请严格按照方案提出的原则、要求，以及核定的建设内容、规模和投资总额，认真做好项目前期工作，落实好项目建设配套资金，严格工程建设管理，保证工程建设质量，切实发挥好红色旅游的理想信念教育功能和脱贫富民作用。

附件：1.全国红色旅游经典景区三期总体建设方案

2.全国红色旅游经典景区三期总体建设方案项目

国家发展改革委

2017年10月30日
