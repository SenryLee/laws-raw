# 交通运输部公告2017年第58号——交通运输部关于公布质量不合格道路运输车辆卫星定位系统车载终端的公告

## 交通运输部公告

2017年第58号

## 交通运输部关于公布质量不合格道路运输车辆卫星定位系统车载终端的公告

近日，交通运输部下发了《交通运输部办公厅关于2017年度道路运输车辆北斗导航车载终端产品质量行业监督抽查结果的通报》（交办科技函〔2017〕1721号），其中通报了南京天朗电子科技有限公司、启明信息技术股份有限公司生产的2个型号道路运输车辆卫星定位系统车载终端质量不合格，现予公告。自公告之日起，该2个型号车载终端从所属原公告批次目录中撤销。

附件：质量不合格道路运输车辆卫星定位系统车载终端

交通运输部

2017年12月12日
