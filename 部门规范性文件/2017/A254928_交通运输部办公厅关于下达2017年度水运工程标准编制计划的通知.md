# 交通运输部办公厅关于下达2017年度水运工程标准编制计划的通知

交办水函〔2017〕 1053号

各标准主编单位：

根据《关于转复2017年交通运输战略规划政策标准规范教育培训类项目支出预算的通知》（财审预函〔2017〕99号），现将2017年度水运工程标准编制计划下达给你们，请遵照执行。请按照《水运工程标准管理办法》（交水发〔2012〕665号）和合同要求尽快开展编制工作，延续项目应确保按照计划完成送审，新列项目应确保2017年底前完成工作大纲阶段工作。

请各主编单位加强标准编制的质量、进度管理，确保按所下达计划节点完成编写任务。确不能按期完成的，要提出延期和调整进度计划的申请，报部水运局批准。部水运局将定期对标准编制情况进行通报。

交通运输部办公厅

2017年7月25日

附件：2017年度水运工程标准编制计划
