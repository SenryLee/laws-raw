# 科技部关于公布2017年度国家级科技企业孵化器的通知

国科发火〔2017〕412号

各省、自治区、直辖市及计划单列市科技厅（委、局），新疆生产建设兵团科技局，各有关单位：

根据《科技企业孵化器认定和管理办法》（国科发高〔2010〕680号），经地方省级科技主管部门评审推荐，科技部审核并公示，现确定锋创科技发展（北京）有限公司等125家单位（详见附件）为国家级科技企业孵化器。

希望你们认真贯彻落实十九大精神，继续加强对辖区内科技企业孵化器的指导和支持，提供条件，创造环境，加快发展，为推动我国科技企业孵化器事业向更高水平迈进，助力大众创业、万众创新向纵深发展作出更大贡献。

附件：2017年度国家级科技企业孵化器名单

科技部

2017年12月25日
