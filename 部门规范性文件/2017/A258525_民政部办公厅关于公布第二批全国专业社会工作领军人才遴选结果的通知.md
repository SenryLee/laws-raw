# 民政部办公厅关于公布第二批全国专业社会工作领军人才遴选结果的通知

民办函〔2017〕313号

各省、自治区、直辖市民政厅（局），新疆生产建设兵团民政局：

为贯彻落实《国家中长期人才发展规划纲要（2010—2020年）》（中发〔2010〕6号）和《社会工作专业人才队伍建设中长期规划（2011—2020年）》（中组发〔2012〕7号），培养和造就一支在推动社会工作事业发展中发挥重要引领作用的专业社会工作领军人才队伍，根据《民政行业领军人才选拔培养办法》（民发〔2012〕223号），我部组织开展了第二批全国专业社会工作领军人才选拔活动。经各地推荐、资格初审、专家评审、社会公示等环节，现决定，认定席小华等42人为第二批全国专业社会工作领军人才（见附件）。希望全国专业社会工作领军人才以党的十九大精神为引领，牢固树立和践行社会主义核心价值观，遵循社会工作专业价值理念和道德指引，以更高的标准要求自己，以更加奋发有为的精神状态投入社会工作服务与管理，在本地区本领域切实发挥好示范引领和标杆作用。希望各地民政部门进一步关心关注专业社会工作领军人才，加大培养和使用力度，积极为专业社会工作领军人才发挥作用营造良好环境、提供坚实保障。

附件：第二批全国专业社会工作领军人才名单

民政部办公厅

2017年11月17日
