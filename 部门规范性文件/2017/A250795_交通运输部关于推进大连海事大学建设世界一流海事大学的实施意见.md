# 交通运输部关于推进大连海事大学建设世界一流海事大学的实施意见

交人教发〔2017〕77号

部属各单位，部内各司局：

海洋战略是实现中华民族伟大复兴中国梦的重大战略，建设海运强国是实现海洋强国的重要前提，海事教育和海事科技是建设海运强国的基本支撑。为贯彻落实党中央、国务院建设“世界一流大学和世界一流学科”的战略部署，进一步提高我国海事教育和海事科技发展水平，根据《国务院关于印发统筹推进世界一流大学和一流学科建设总体方案的通知》（国发〔2015〕64号）、《国务院关于促进海运业健康发展的若干意见》（国发〔2014〕32号）精神，现就推进大连海事大学建设世界一流海事大学提出以下意见。

一、总体要求

（一）指导思想。

全面贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神，深入学习贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，牢固树立创新、协调、绿色、开放、共享的发展理念，按照“建设世界一流大学和一流学科”的总体要求，以立德树人为根本，以服务国家战略为导向，以海事特色、世界一流为核心，推进大连海事大学加快建设世界一流海事大学，提升中国海事教育和海事科技的综合实力与国际竞争力，更好地服务国家海运强国和海洋强国建设，为实现“两个一百年”奋斗目标和中华民族伟大复兴的中国梦提供海事人才和智力支撑。

（二）基本原则。

——服务国家战略。服务和融入国家战略，引领世界海事教育发展，推动海事科技与文化进步，在国家战略实施中发挥重要作用。

——聚焦海事特色。坚持有所为有所不为，紧紧围绕海事特色优化学科专业布局，打造海事学科专业高峰，形成国际领先的海事学科专业优势。

——对标世界一流。瞄准世界一流海事学科专业，坚持对标发展，加大资源投入，按照世界一流标准强化目标管理，注重绩效考核，加快实现世界一流海事大学建设目标。

——深化改革创新。始终坚定不移地走改革创新之路，加快构建充满活力、富有效率、更加开放、有利于科学发展的体制机制，形成建设世界一流海事大学的强大动力。

（三）总体目标。

大连海事大学在人才培养、科学研究、社会服务、文化传承创新和国际交流合作等方面的水平整体跃升，成为培养海事拔尖创新人才的主要基地、海事科技创新的骨干力量、海事文化传承创新的重要源泉、国际海事交流合作的重要桥梁、提升海事领域国际话语权的国家智库，在服务国家战略和行业发展等方面发挥重要作用。

——到2020年，大连海事大学进入世界一流海事大学行列，2—3个具有海事特色的优先发展学科进入国内一流前列，若干学科方向进入世界一流行列；综合改革成效显著，治理能力与治理体系现代化全面推进；在国内海事教育领域的引领地位进一步巩固和强化，在世界海事教育领域的影响力进一步提升。

——到2030年，大连海事大学进入世界一流海事大学前列，2—3个具有海事特色的优先发展学科进入世界一流行列，且在世界海事院校中居于领先地位；3—5个重点培育学科进入国内一流前列，且进入世界海事院校前列；3—4个航海类专业居于世界领先地位；5—7个海事类专业进入世界一流前列。

——到本世纪中叶，大连海事大学成为具有海事特色的世界一流大学，拥有若干世界一流学科和一流专业，在世界海事教育领域发挥引领作用。

二、主要任务

（一）坚定办学政治方向，建设具有中国特色的世界一流海事大学。加强和改进党的领导，牢牢把握中国特色社会主义办学方向，切实增强“四个意识”。按照社会主义政治家、教育家的要求选好配强大连海事大学领导班子，不断提高班子办学治校的能力与水平。坚持党委领导下的校长负责制，充分发挥党委的领导核心作用。把全面从严治党的要求落实到世界一流海事大学建设全过程，加强党的思想建设、组织建设、作风建设、制度建设和反腐倡廉建设，充分发挥基层党组织战斗堡垒作用和党员先锋模范作用，为学校发展建设提供坚强政治保证。

（二）对标现代化大学治理体系，提升学校治理能力。进一步深化落实大连海事大学综合改革，激发内生动力和办学活力。充分借鉴世界一流大学管理模式，构建具有中国特色的现代大学制度。推进依法治校，完善以章程为统领的制度体系。提高管理效率，降低决策重心，推进院为实体的管理体制。加强学术组织建设，完善学术权力运行机制，健全以学术委员会为核心的学术治理体系。

（三）培养高素质海事人才，支撑海运业软实力建设。以立德树人为根本，强化人才培养的核心地位，树立以学生为中心的育人理念，深化教育教学改革，完善全过程全方位的协同育人体系，着力培养具有国际视野与民族精神、海洋意识与社会责任、广博知识与发展潜质、创新精神与实践能力、健全人格与健康体魄的高素质海事人才。深入实施“人才强交”战略，充分发挥大连海事大学人才支撑作用，实现海事人才培养与行业发展的结构性协同与时序性协同。聚焦海事人才培养目标，加强海事特色教材建设，建立具有示范性的专业课程体系。推进科教融合、产教融合，主动服务国家“大众创业、万众创新”战略，深化创新创业教育改革，构建有利于创新创业的政策环境和教育体系。

（四）提高科学研究水平，推动海事科技进步。科学判断世界科技发展趋势，准确把握国家和行业重大战略需求，整合创新资源和创新要素，致力于产生一批具有原创性的基础研究成果，形成一批具有标志性的应用研究成果，在行业重点建设和关键发展领域中发挥重要作用。依托大连海事大学打造具有海事特色和世界影响的新型智库，加强战略性、全局性、前瞻性问题的政策研究，为服务国家和行业科学决策、提升国家在世界海事领域的影响力提供智力支持。加快推进科研体制机制改革，支持大连海事大学在科研运行保障、组织模式、绩效评价等方面探索创新。遵循科研活动规律，赋予创新领军人才更宽松的创新环境、更大的学术决策权和人财物支配自主权，在政策上支持并鼓励科技人才勇于创新，服务海运业发展。

（五）建设世界领先的海事学科，汇聚优质海事人才与科技资源。以国家和行业重大发展战略为导向，瞄准国际学术前沿，加强顶层设计和战略规划，对标世界一流学科发展模式，进一步凝练学科方向、强化特色优势，建设若干世界一流的海事特色学科。优先发展交通运输工程、船舶与海洋工程等学科，重点培育法学、管理科学与工程、环境科学与工程、信息与通信工程、控制科学与工程等学科。面向未来发展，围绕智能船舶、航运金融保险等海运科技和海运经济发展的新趋势，培育新的特色学科方向。重点建设海事特色学科平台，促进学科建设与产业转型升级全面对接。建立学科分类评价和跟踪评估机制，强化动态管理和绩效考核，形成良好的学科生态，在海事领域创新体系建设中发挥重要作用。

（六）建设一流的师资队伍，构筑海事领域的人才高地。深入实施人才强校战略，以学科专业战略布局引领人才队伍建设，加快培养和引进一批海事领军人才和创新团队，建立一支以海事高层次专家学者为领军、以国家急需的海事高级专业技术人才为骨干、以中青年学术新秀为中坚、以优秀青年人才为生力军的高水平人才队伍，使大连海事大学成为海事领域的人才高地。坚持以重大建设工程、重点科研项目、重点科研基地为依托，采取倾斜政策，支持大连海事大学领军人才潜心开展基础研究和科技攻关，下大力气推动以院士、“千人计划”、“长江学者”为代表的领军人才队伍建设。加强师德师风建设，培养和造就一支有理想信念、有道德情操、有扎实学识、有仁爱之心的优秀教师队伍。充分利用社会优质资源，加强兼职教师队伍建设，建立灵活高效的用人机制。加快推进人事制度改革，完善编制总量管理、动态调整机制，实施师资队伍“阶梯双轨”制，完善人才发展配套支撑政策，增强人才队伍发展活力。

（七）加快国际化办学进程，提高中国海事教育的国际影响力。坚持“引进来”和“走出去”相结合的工作方针，强化国际化办学理念，加快大连海事大学的国际化发展进程。支持大连海事大学加强与世界一流大学和学术机构的实质性合作，支持学校专家学者积极参与国际学术交流活动，将国外优质教育资源有效融合到教学科研全过程。充分发挥大连海事大学人才优势，积极培养优秀人才到海事领域国际组织任职。服务“一带一路”战略，支持大连海事大学面向沿线国家开展海事教育与培训项目。支持大连海事大学深度参与国际交流和相关国际事务，参与制定国际海事公约和海事教育标准，参与国际海事重点热点问题研究，切实提高中国海事教育在国际领域的竞争力和话语权，提高对国家建设海运强国和参与全球治理的技术支撑能力。

（八）打造中国特色海洋文化传承创新平台，引领和传播蓝色海洋文化。坚持社会主义道路自信、理论自信、制度自信、文化自信，传承发扬大连海事大学百年名校、航海家摇篮的文化底蕴和办学传统，建设具有中国特色、海大风格的大学文化。坚持用价值观引领知识教育，将社会主义核心价值观融入教育教学全过程，引导广大教师和青年学生践行社会主义核心价值观，不断丰富和发展航海文化内涵，引领航海文化的前进方向。充分发挥大连海事大学在蓝色海洋文化传承创新中的辐射作用，打造中国特色海洋文化传承创新平台。

（九）推进科技成果转化，提升行业服务能力和水平。落实国家关于促进高校科技成果转化的有关规定，完善促进科技成果转化的支持政策，赋予大连海事大学科技成果使用、处置和收益管理自主权，进一步激发创新活力。整合海事科技创新资源，推进政产学研用协同创新，增强创新资源对经济社会和行业发展的驱动力。支持大连海事大学加强与行业企业的战略合作，实现互利共赢。推动海事科技军民融合发展，支持大连海事大学建立军民融合发展新模式。深入推进大连海事大学科技园建设，使其成为催化产业技术变革、加速创新驱动的策源地，提升对海事产业升级的贡献度。

（十）构建多方共建的长效机制，树立行业特色大学发展典范。进一步推动教育部等国家部委、辽宁省等地方政府以及企业实质性共建大连海事大学，建立有效的共建协调机制。推进大连海事大学建立理事会制度，充分发挥理事会在学校改革发展的咨询、协商、审议、监督等功能，引导社会各界共同支持海事教育与海事科技发展。充分发挥行业特色优势，推进建立统筹协调的大学与社会新型关系，鼓励相关企业积极参与世界一流海事大学建设。

（十一）强化政策和资金保障，提升学校的办学条件和发展环境。加大政策支持力度，进一步扩大大连海事大学的办学自主权，支持学校在核定的机构限额内自主设置教学科研机构，在国家政策框架内探索建立与世界一流海事大学目标相适应、激励与约束相结合的内部分配机制。加大资金投入力度，“十三五”期间多渠道筹集经费支持世界一流海事大学建设。加强资金统筹，强化人才队伍和海事特色学科平台建设。支持学校不断拓宽筹资渠道，积极吸引社会捐赠，多渠道汇聚资源，增强自我发展能力。

三、组织实施

（一）提高认识。各单位要切实将思想和行动统一到党中央、国务院决策部署上来，充分认识建设世界一流海事大学在服务国家战略中的重要作用，将其作为当前和今后一段时间的重点工作，科学谋划、精准发力、主动作为，切实推进提升我国海事教育与海事科技发展水平。

（二）统筹协调。各单位要按照职责分工，明确责任，积极配合，落实好建设世界一流海事大学的各项任务，在推进任务过程中要把握好整体推进和重点突破的关系，做到眼前与长远相统筹，局部与全局相配套，突破与渐进相衔接。

（三）强化落实。大连海事大学要切实履行主体责任，按照本意见要求，结合自身办学基础、学科特色、发展优势等，研究制定具体建设方案，强化担当意识，精心组织实施，层层分解任务，确保建设工作如期完成。
