# 国家测绘地理信息局关于做好2017年天地图建设与应用工作的通知

## 关于做好2017年天地图建设与应用工作的通知

国测信发〔2017〕4号

各省、自治区、直辖市测绘地理信息行政主管部门，局所属有关单位：

为贯彻落实全国测绘地理信息工作会议精神，做好2017年天地图建设与应用工作，现就有关事项通知如下：

一、认真履行法定职责，进一步理清天地图发展思路

经过多年发展，作为地理信息公共服务平台的天地图已进入了稳定发展的关键时期。各省局要深入贯彻落实《地图管理条例》精神，认真履行“通过地理信息公共服务平台向社会提供地理信息公共服务，实现地理信息数据开放共享”职责，保障天地图的持续投入。要把天地图作为测绘地理信息部门供给侧结构性改革的重要方向，以天地图为主体建立地理信息大数据平台，减少无效低效供给、扩大有效供给，更好地适应和引导地理信息需求。要按照《政务信息资源共享管理暂行办法》（国发〔2016〕51号）要求，在加强天地图建设与应用的同时，依托天地图为“自然资源和空间地理信息”基础信息项的无条件共享提供基础支撑，并逐步建立健全天地图投入、建设、运维、应用等管理机制，推动天地图长期稳定运行，为稳增长、促改革、调结构、惠民生、防风险作出贡献。

二、围绕提升天地图核心能力，持续推进数据融合与品牌建设

近年来开展的天地图数据融合工作，不仅实现了节点间数据资源的优势互补，而且形成了天地图的核心能力，必须持续深入推进。国家基础地理信息中心要进一步优化融合流程，完善融合技术要求，加大技术创新力度，开展技术培训，提高融合效率，努力实现各类数据当年融合、当年发布。鼓励各省局在每年4月底前提出数据融合申请，11月底前完成数据融合并上线发布。对于申请开展数据融合的省局，国家基础地理信息中心要及时为其提供最新的省级区域范围相关数据。融合后的成果数据主要用于天地图各级节点建设，提升天地图的公益性服务能力与水平。鼓励国家基础地理信息中心与各地在明确责权利的基础上，将融合后的成果数据用于天地图增值服务，使其应用于更多的领域、发挥更大的作用。“天地图”作为注册商标，国家基础地理信息中心要按照有关法律法规，规范“天地图”商标的使用和许可授权，联合各地共同打造“天地图”品牌。

三、适应大数据发展需要，完善天地图顶层设计

抓住国家电子政务内网即将开通的有利时机，进一步整合新型基础测绘、地理国情监测、航空航天遥感测绘、应急测绘、全球地理信息资源开发成果以及企业地理信息资源，完善天地图数据体系，加快推进天地图涉密版升级，着力将其打造成为“要素全、覆盖广、时相多、精度高”的地理信息大数据平台，积极为国家电子政务信息化和政府管理决策服务。国家基础地理信息中心要联合卫星测绘应用中心加强顶层技术设计，编制天地图涉密版总体技术方案，提升涉密版部门信息共享、综合信息集成、多源信息聚合的能力，满足国家电子政务内网用户的专业化应用需求。加强天地图公众版建设，丰富数据内容，完善服务功能，推出天地图2017版，并依托其向社会提供地理信息公共服务，及时发布行政区划、地名、交通、公共设施等变更情况。

四、重点面向公益性领域，推动天地图深层次应用

贯彻落实《国家突发事件应急体系建设“十三五”规划》要求，推进以天地图为基础的应急信息资源“一张图”建设。要加强与应急管理部门的联络沟通，主动对接相关工作，争取必要支持，做好保障服务工作，满足应急管理需求。同时，要通过座谈交流、跟踪走访、技术培训等多种方式，大力推动天地图在电子政务、精准扶贫、多规合一、不动产登记等领域的公益性应用。要采取多种方式，加大扶持力度，调动企业参与天地图行业应用的积极性，依托市场力量推进天地图多领域、多层次的应用。中国测绘科学研究院在推进政务地理信息应用工作中，要优先以天地图为基础开发各类系统，着力推动天地图在政府部门的公益性应用。继续编制《天地图典型应用案例汇编（2017版）》，完善典型应用案例展示系统，集中展示和宣传各级节点近年来典型应用成果。请各地、各部门组织收集天地图典型应用案例，于5月31日前将有关素材（格式及要求详见附件1）上报国家局。

五、高度重视运维工作，保障天地图安全稳定运行

天地图是提供测绘地理信息公共服务的重要窗口，关系到测绘地理信息主管部门的形象与声誉。各地要高度重视天地图公众版运维工作，明确专人负责，力争不发生重大安全事故。要按照国家网络安全有关规定，加强网络安全建设与日常监控，制定网络安全事件应急预案，必要时开展应急演练；发现黑客攻击事件，要妥善应对，并在第一时间向公安机关报案，重大安全事件应及时向国家局报告处置情况。要着力加强在线设备及服务的实时监控，实现故障自动报警与服务自动切换。省级节点服务变更或者服务中断的，各地要及时在天地图网站上发布公告并填写登记表（格式见附件2），通过电子邮件告知国家基础地理信息中心。省级节点数据更新后，各地要按照《地图管理条例》相关规定，履行地图审核程序，及时变更审图号，并定期在天地图网站上发布更新信息，扩大用户的知情权。国家局将加强省市级节点公众版运行的技术监测，并定期通报有关情况。

六、明确技术评估分工，建立正向激励机制

天地图技术评估分为接入技术评估、更新技术评估和综合技术评估。国家局不再承担市级节点的接入技术评估，只负责省级节点的更新技术评估和综合技术评估。各省局负责本地区市级节点的接入、更新和综合技术评估工作。市级节点（不含县级，省直管县除外，下同）通过接入或者更新技术评估后，各省局要向国家局提交备案表（格式见附件3），国家局组织对其进行基本测试后，符合条件的将直接接入主节点。优化省级节点综合技术评估体系，继续实施星级评价制度，建立正向激励机制。为体现公平原则，结合各地实际，综合技术评估按地域划分为一类地区、二类地区（部分西部地区）和三类地区（直辖市），评估指标各有侧重（具体要求另行通知）。各省局要加强对本地区市级节点的考核，每年12月底前完成市级节点综合技术评估工作，并将评估结果报国家局。
