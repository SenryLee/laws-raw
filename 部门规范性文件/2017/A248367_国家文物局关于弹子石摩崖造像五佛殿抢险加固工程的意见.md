# 国家文物局关于弹子石摩崖造像五佛殿抢险加固工程的意见

## 关于弹子石摩崖造像五佛殿抢险加固工程的意见

办保函〔2017〕257号

重庆市文物局：

你局《关于审批弹子石摩崖造像抢险加固工程五佛殿抢险加固方案的请示》（渝文物〔2017〕20号）收悉。经研究，我局意见如下：

一、所报工程方案前期勘察和研究不足，缺乏必要的基础资料，我局暂不同意弹子石摩崖造像五佛殿抢险加固工程方案。

二、对该方案提出以下修改完善意见：

（一）应进行详细的专项地质勘察，明确弹子石摩崖造像赋存岩体的地层岩性、构造和裂隙发育情况、降水量和地表径流情况等，客观评估赋存岩体稳定性。同时，分析五佛殿的原有建筑形制、构造特点等，全面梳理近年来维修情况，客观评估后期拆改和维修效果，为科学制定工程措施提供依据。

（二）应进一步查明病害原因，准确统计五佛殿各类构件残损数量和范围，研究和分析地方建造工艺、传统做法、建筑材料和构造特征等，确保在维修中使用原工艺和原材料。

（三）进一步补充设计依据，完善工程做法，细化修缮措施，严格控制工程量和工程强度。

1. 明确恢复地面方砖的尺寸及铺墁的具体要求和方法。

2. 进一步论证使用樟子松更换原木柱的可行性，细化木材防腐处理措施、拟更换糟朽椽、檩等木构件的具体数量、更换操作技术流程和要求等。

3. 屋面修缮应使用传统材料做法，不宜在望板上新作防水层和水泥砂浆结合层。

4. 不同意采用水泥砂浆修补柱础等石质构件。应补充石质构件保护措施的设计依据及前期试验资料，说明拟采用措施的科学性和可操作性；石质构件不宜进行防风化处理。

（四）补充屋顶脊饰、后期改造门窗等的设计依据，论证1997年设计图纸的科学性。

（五）进一步规范图纸，补充图纸尺寸标注和节点详图。

三、请你局根据上述意见，组织相关单位修改、完善设计方案，经你局审核后另行报批。

专此函。

国家文物局

2017年3月14日
