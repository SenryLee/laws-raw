# 农业部科技教育司关于做好2017年农业主推技术遴选推荐工作的通知

## 关于做好2017年农业主推技术遴选推荐工作的通知

农科（推广）函〔2017〕第36号

各省、自治区、直辖市农业（农牧、农村经济）、农机、畜牧、兽医、农垦、渔业厅（局、委、办），新疆生产建设兵团农业局，黑龙江省农垦总局、广东省农垦总局，各省级农科院、有关农业高校，部属有关单位，现代农业产业技术体系首席科学家：

为适应新时期农业技术推广工作要求，2017年起农业部不再推介发布农业主导品种，加大农业主推技术推介力度，围绕支撑农业供给侧结构性改革和农业绿色发展，遴选推介符合绿色增产、节本降耗、提质增效、防灾减灾、生态环保等要求的10项引领性农业技术模式、100项成熟适用的共性技术，组织全国农业科教系统分行业、分领域进行集成示范与推广应用。现就农业主推技术遴选推荐有关事项通知如下。

一、推荐范围

（一）引领性农业技术模式

1.水稻、小麦、玉米节本增效技术模式集成与示范。集成水稻育秧、种植、肥水调控、群体优化、综合防治、精确定量、全程机械化等关键技术并示范推广。集成土地深耕深松、秸秆粉碎还田、水肥一体化、优质高产小麦品种遴选、规范化播种、节水灌溉、病虫草害统防统治、全程机械化等技术并示范推广。集成玉米适宜品种遴选、农艺栽培技术、机械化玉米收获干燥仓储技术等并示范推广，提高生产效率。

2.农作物化肥农药减施技术模式集成与示范。集成测土配方施肥技术、水肥一体化技术、有机肥替代化肥技术等示范推广，实现农作物产量品质影响不大情况下降低肥料使用量。改进施肥方式，大力推广测土配方施肥，实现有机无机相结合，提升耕地基础地力。集成天敌控害技术、理化诱控技术、生物农药防控技术、生态调控技术、科学用药技术等并推广应用，实现农作物产量品质影响不大情况下降低农药施用量。

3.畜禽绿色养殖及废弃物处理资源化技术模式集成与示范。集成生猪、奶牛等畜种的饲料营养、饲养管理、高效繁育、疫病防控等关键技术，构建畜禽绿色健康养殖技术模式并示范推广。集成肉牛、肉羊良种繁育、规模养殖、快速育肥等技术，构建绿色健康养殖技术模式并示范推广。集成畜禽养殖粪污沼气能源生态利用技术、电化学处理等技术，构建畜禽养殖废弃物处理资源化技术模式并示范推广。

4.稻田绿色种养技术模式集成与示范。集成水产养殖和水稻种植品种选择技术、茬口衔接技术、投饵技术、施肥技术、捕捞技术等，形成稻-蟹、稻-虾、稻-鳖、稻-鱼（鳅）等类型稻田综合种养模式并示范推广，实现“以渔促稻、提质增效、生态环保、保渔增收”。

5.农业物联网技术模式集成与示范。集成物联网设备智能感知、高通量自组网传输、移动定位、大数据实时分析、生物识别、音频指纹提取、机器视觉系统、可适性云服务等技术，构建设施蔬菜病虫害快速诊断、环境智能调控、水肥管理决策、植物工厂机器人、畜禽养殖加工智能化管理等物联网技术模式并示范推广。

6.农产品质量安全全程控制技术模式集成与示范。集成小麦和花生产前抗性品种选择、产中病虫害防治农药安全使用技术与风险预警技术、产后安全储藏与绿色脱毒技术，以及配套赤霉菌素、黄曲霉毒素等生物毒素高灵敏检测技术、产品安全性评价技术与标准，构建小麦、花生等粮油生物毒素全程控制技术模式并示范推广。

7.秸秆综合利用技术模式集成与示范。集成秸秆还田、收储运、肥料化、饲料化、基料化、燃料化、原料化等成熟实用技术，构建适合不同区域特点的“还田主导型、种养结合型、多元循环型、产业带动型”等秸秆全量处理利用技术模式并示范推广。

8.果（菜、茶）沼畜循环农业技术模式集成与示范。集成沼肥生产施用技术、厌氧发酵技术等，推动区域粪污混合原料收集、高效厌氧发酵、有机肥沼肥生产施用、全流程智能化监测管理，实现沼肥高效利用，推进果（菜、茶）园化肥减施，减少农业面源污染，促进可持续发展。

9.农用地膜有效利用技术模式集成与示范。集成PE地膜减量化技术、生物降解地膜替代技术、地膜机械化回收技术、残膜处理再利用技术等，覆盖地膜使用、回收、处理、再利用等四大关键环节，推进地膜科学使用，减少残膜污染。

10.农产品产地污染修复技术模式集成与示范。集成低积累品种、土壤调理、土壤钝化、叶面阻控和农艺调控技术，形成农田重金属污染治理模式并示范推广，为中轻度污染农田的土壤修复和安全利用提供有力支撑。

（二）成熟适用的单项共性技术

1.有利于农业资源循环利用、节本增效和生态环境保护等可持续发展的成熟适用技术，以及先进高效适用农业机械化技术。

2.水稻、小麦、玉米、大豆、马铃薯、棉花、油菜、花生、果蔬等主要农作物播种、田间管理、收获等关键生产环节及植保、机械化等高效适用生产技术。

3.生猪、家禽、奶牛、肉羊、肉牛等主要畜牧品种饲养管理、设施建造、环境控制、饲料配制、繁殖培育、无害化处理等高效适用技术，饲料加工和饲料添加剂使用技术，畜牧场粪污转化利用与减排技术，疫病防治技术，牧草生产技术。

4.鱼、虾、贝、藻、蟹等大宗优势水产品的生态养殖及配套高效适用技术。

5.其它成熟适用的单项共性技术。

二、遴选与推荐程序

（一）推荐数量。各省农业行政主管部门、省级农科院、有关农业大学，向农业部推荐的引领性农业技术模式不超过3项，成熟适用的单项共性技术不超过5项；现代农业产业技术体系每个首席科学家推荐的引领性农业技术模式不超过1项，成熟适用的单项共性技术不超过3项。

近年农业部推介发布的农业主推技术（可在中国农业推广网http://www.farmers.org.cn/查阅）符合本次推荐要求的，可继续推荐报送。

（二）遴选与推荐。请各省、有关单位、现代农业产业技术体系有关首席科学家等，严格按照推荐范围、数量及要求，组织推荐符合要求的引领性农业技术模式和成熟适用的单项共性技术。

（三）论证与发布。农业部科技教育司在各省、有关单位、体系推荐材料基础上，组织专家论证，征求农业部相关行业司局等意见后面向社会推介发布并组织推广应用。

三、有关要求

（一）请认真填写主推技术推荐汇总表，撰写2017年农业主推技术推荐材料（格式见附件，请在中国农业推广网http://www.farmers.org.cn/下载），并于2017年3月7日前以书面形式报送中国农学会科普处，同时报送材料电子版。

（二）各省农业行政主管部门要在报送农业部的材料基础上，抓紧完善本省农业主推技术推介制度，组织本省和各农业县遴选发布农业主推技术，形成技术操作规范，加快主推技术进村入户。
