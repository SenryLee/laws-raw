# 国土资源部办公厅关于转发《亚洲开发银行知识服务技术援助项目操作规程（试行）》的函

国土资厅函〔2017〕1008号

各有关单位：

为进一步加强亚洲开发银行知识服务技术援助项目管理工作，完善知识服务技术援助项目管理制度，财政部印发了《亚洲开发银行知识服务技术援助项目操作规程（试行）》（财国合〔2017〕39号），现转发给你们，请遵照执行。

2017年6月30日

附件：财政部关于印发《亚洲开发银行知识服务技术援助项目操作规程（试行）》的通知
