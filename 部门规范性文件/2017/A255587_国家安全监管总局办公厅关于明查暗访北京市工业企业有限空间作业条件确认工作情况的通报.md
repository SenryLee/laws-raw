# 国家安全监管总局办公厅关于明查暗访北京市工业企业有限空间作业条件确认工作情况的通报

安监总厅管四函〔2017〕193号

北京市安全生产监督管理局：

按照全国安全生产大检查工作的统一部署，国家安全监管总局检查组于2017年8月14日至18日，对北京市工业企业有限空间作业条件确认工作进行了明查暗访。通过查阅资料、人员访谈、现场查验等方式，检查了北京经济技术开发区、顺义区和房山区工业企业有限空间作业条件确认工作情况，随机抽查了北京京东方显示技术有限公司、北京可口可乐饮料有限公司等6家工业企业。现将有关情况通报如下：

一、主要工作做法

（一）认真排查摸底，有效落实有限空间作业安全监管。北京市安全监管局按照国家安全监管总局工作部署，自2014年以来，组织各区安全监管部门认真摸排造纸、酱腌菜生产和有污水处理系统的企业底数，建立了基础台账。今年房山区又对建材、轻工行业企业进行了排查，摸排出55家企业，进一步健全有限空间企业基础台账。顺义区组织属地安全监管部门对全区所有工业企业全面摸排，采取政府购买技术服务方式，对排查出的286家涉及有限空间的工业企业逐家排查隐患，并进行风险辨识评估，将企业有限空间作业风险分为高、中、低三个等级。通过摸排和辨识评估工作，顺义区建立了清晰的有限空间企业基础台账，一企一档，掌握了企业的数量、作业形式（外包、自行、外包+自行作业）、有限空间数量、主要危险有害因素、风险等级、各项措施落实等情况，为有限空间作业分级监管提供支撑。检查组随机抽查的6家工业企业均按照《工贸企业有限空间参考目录》对本企业有限空间作业场所进行了辨识，并建立企业有限空间台账。

（二）建立标准制度，严格作业风险防控措施。一是制定了《地下有限空间作业安全技术规范》（DB11852）地方标准，分别从作业通则、气体检测与通风、防护设备设施配置3部分明确地下有限空间安全作业的具体要求。二是自2010年以来，北京市将地下有限空间作业现场监护人员作为管理重点，实行专业培训，严格考核。三是将有限空间作业安全管理作为企业安全生产标准化评审的否决项，推动企业加强有限空间作业条件确认工作。四是发布了有限空间作业场所安全风险告知牌统一模板，要求企业在有限空间作业场所的显著位置悬挂。五是北京经济技术开发区建立有限空间作业外包单位报告及发包单位作业现场旁站监督制度，要求企业将有限空间作业外包单位情况向行业主管部门报告，要求发包单位派专人赴作业现场进行旁站监督，对外包单位作业人员特种作业证件、班前安全交底、检测及通风设备使用、防护用具及应急救援设备等进行检查，并要如实填写《有限空间作业交底审查表》。从抽查的6家企业看，均建立了审批制度，设置了安全警示标识，开展了作业人员培训，配备了仪器和防护装备，进行了应急预案演练，有限空间作业管理规范。

（三）加强考核和执法，强化责任落实。一是北京市安委会办公室印发了《关于认真做好工贸行业有限空间作业条件确认专项检查工作的通知》（京安办发〔2017〕12号），明确将有限空间作业企业安全监管作为2017年度各区政府安全生产考核指标，细化考核标准，强化各级安全监管责任落实。二是北京市、区两级安全监管部门将有限空间作业条件确认工作纳入年度执法计划，用严执法、高处罚推动工业企业有限空间作业条件确认工作。截至7月底，北京市安全监管局共检查有限空间作业企业77家次，责令限期整改的企业24家，行政处罚企业6家。顺义区各属地安全监管部门检查企业186家，治理隐患1073项，均下达了检查文书和隐患整改验收检查文书；区安全监管局执法检查企业26家，发现隐患56项，下达执法文书26份，处罚企业5家，处罚6万元。

（四）加强宣教培训，提高员工意识。今年以来，北京市多次组织新闻媒体对部分企业有限空间作业违法违规问题进行曝光，组织开展市、区及街道乡镇300名安全监管干部培训，发放《工贸企业有限空间作业安全指导》光盘400套。结合“全面落实企业安全生产主体责任”主题“安全生产月”活动，北京市向监管部门、企业和社会公众发放了1万册《工贸企业有限空间作业安全宣传手册》，并利用“北京市安全生产监督管理局”官方微信号这一平台，联合“工贸安全”微信公众号开展了工贸行业有限空间作业条件确认工作有奖知识竞赛，组织各级安全监管人员和有关企业人员积极参与。将工贸企业有限空间作业安全宣讲纳入到“双百工程”（即百名安全监管干部与万家企业主要负责人对话谈心、百名安全生产专家服务万家企业）中，通过执法检查，对照问题现身说法，与企业负责人进行有限空间作业安全管理专题谈心对话，提高企业负责人思想认识。

二、检查发现的问题和隐患

（一）政府层面。

1.北京市安全监管局未按照要求将《国家安全监管总局办公厅关于明察暗访云南省昆明市工贸行业有限空间作业条件确认工作情况的通报》（安监总厅管四函〔2017〕56号）传达到辖区内各级安全监管部门和有关工业企业。

2.北京市各区及经济技术开发区开展有限空间作业条件确认工作进展不平衡，部分地区排查摸底不全面，建立的监管台账只覆盖了部分重点行业领域。

（二）企业层面。

1.部分被查企业制度不完善，落实不到位。北京京东方显示技术公司未签订有限空间外委作业安全协议，承包方的作业审批未落实。北京可口可乐饮料有限公司的有限空间作业安全生产制度和规程未纳入自身受控体系文件管理，作业记录显示部分现场监护人员未经过专业培训。北京光明健能乳业有限公司制定的应急预案和应急处置程序针对性和操作性不强，关于如何开展有限空间应急救援的具体细节描述不详细。北京长安汽车公司涂装车间有限空间作业指导书未分析存在易燃易爆气体发生爆炸的风险，未明确有毒和可燃气体浓度检测限值；同一作业场所《受限空间进入许可证》表单中有毒气体检测项目不一致，部分未检测有毒气体浓度。

2.部分被查企业现场安全警示标识不完善。北京京东方显示技术公司6号楼的T-11401污泥槽顶部人孔处、窨井等有限空间作业场所未设置安全警示标识。北京燕京啤酒股份有限公司一分公司部分有限空间作业场所安全警示标识缺失或不明显。

3.部分被查企业有限空间作业人员应急能力有欠缺。北京京东方显示技术公司岗位操作人员现场操作背负式正压空气呼吸器能力不足，且不掌握气体检测仪的使用方法。

三、下一步工作要求

（一）认真落实整改。北京市要针对此次明查暗访发现的问题和隐患，举一反三，深入查找根源和薄弱环节，以更高标准和更严要求落实整改，进一步扎实推动有限空间作业条件确认工作。

（二）进一步全面摸排企业底数。北京市要进一步全面开展涵盖造纸、酱腌菜生产和有污水处理系统的工业企业在内的所有工业企业有限空间作业摸底和检查工作，查漏补缺，完善基础台账，并监督企业逐项落实有限空间作业作业审批及执行、作业人员安全培训、安全警示标识设置等7方面措施。

各省级安全监管局要学习借鉴北京市安全监管局的有关做法，结合近期针对云南省和内蒙古自治区明察暗访的通报内容，认真吸取近期发生的湖南省长沙市浏阳市赤马湖食品厂“8·14”中毒事故、内蒙古自治区锡林郭勒盟苏尼特食品有限公司“8·1”中毒事故、河北省石家庄市辛集市欧赛皮革有限公司“5·29”中毒事故和广西壮族自治区南宁市宾阳县大桥金玉纸业有限公司“5·21”废水回收池中毒事故等教训，举一反三，查找工作的不足和差距，出真招、出硬招督促各地区和有关企业提高认识，切实落实《工贸企业有限空间作业安全管理与监督暂行规定》（国家安全监管总局令第59号）和国家安全监管总局关于有限空间作业条件确认工作部署要求。

请北京市安全监管局将工作落实情况和有关企业整改及行政处罚执法情况于2017年10月10日前报送国家安全监管总局监管四司（联系人及电话：胡福静，010-64463873）。
