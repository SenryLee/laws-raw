# 国家文物局关于廻龙塔保护规划意见的函

文物保函〔2017〕2089号

湖南省文物局：

你局《关于审批湖南省永州市零陵区廻龙塔保护规划（修改）的请示》(湘文物报〔2016〕198号)收悉。经研究，我局意见如下：

一、原则同意所报廻龙塔保护规划。

二、对该规划提出以下修改意见：

（一）进一步完善历史和科学价值评估。应将挡土墙纳入文物构成要素，并补充挡土墙的保护措施。

（二）应对廻龙塔的结构稳定性等实行整体评估，并以此为据制定保护措施；补充已实施保护工程的评估内容，明确实施效果和已解决的问题。

（三）结合廻龙塔景观视廊分析，完善环境控制要求；细化建设控制地带内的环境整治措施，避免园林化。

（四）补充与城市总体规划衔接的内容。梳理规划文本，避免错漏。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的廻龙塔保护规划报请湖南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好廻龙塔文物保护的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月29日
