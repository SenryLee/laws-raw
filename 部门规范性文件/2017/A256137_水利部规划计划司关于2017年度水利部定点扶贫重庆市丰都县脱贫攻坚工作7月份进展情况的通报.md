# 水利部规划计划司关于2017年度水利部定点扶贫重庆市丰都县脱贫攻坚工作7月份进展情况的通报

## 关于2017年度水利部定点扶贫重庆市丰都县脱贫攻坚工作7月份进展情况的通报

水利部定点扶贫重庆市丰都县工作组各成员单位：

为帮助丰都县巩固脱贫攻坚成果，按照《水利部对口帮扶重庆市丰都县脱贫攻坚实施方案》《水利部定点扶贫重庆市丰都县“八大工程”2017年度工作计划》要求，现将定点扶贫丰都县7月份工作进展情况通报如下：

一、近期开展的主要工作

（一）“八大工程”进展情况

1、农村饮水安全巩固提升工程。2017年，丰都县农村饮水安全巩固提升工程计划总投资3127万元，新建（改扩建）供水工程7处。截至目前，4处供水工程已全部完工，完成总投资3342.7万元（6月份完成投资3199.33万元），为计划总投资的106.9%。

2、千塘万亩特色产业支撑工程。丰都县千塘万亩特色产业支撑工程2017年计划总投资3650万元，整治山坪塘335口。截至目前，整治山坪塘任务已全部完成，完成总投资3650万元，新增、恢复和改善灌溉面积11968亩，支持发展特色产业4391亩，受益贫困户649户。

3、小型水库水源保障工程。2017年，丰都县小型水库水源保障工程计划完成总投资5000万元，续建水源工程项目3处，开工建设1处。截至目前，已完成总投资2351万元（6月份完成总投资1801万元），续建的3座水库中，硝厂沟水库主体工程已开工建设；沱沱坝、王家山水库主体工程尚未开工，正在抓紧开展进场公路开挖、临时施工用电、导流洞基础工程等建设；拟今年开工的三岔溪水库正在抓紧开展招投标；小月坝、观音岩、莲花、灯塔等4座水库前期工作正在加快开展。

4、贫困户产业帮扶工程。长江设计院、澧水公司、右江公司、中国水科院筹集的帮扶资金100万元，已全部到位。丰都县为345户贫困户发放小额贴息贷款1619.5万元（其中个人信用贷款700.5万元166户；新型农业经营主体贷款16家，贷款金额919万元，建立利益链接179户），用于种植、养殖及贸易业等产业发展，完成帮扶290户的年度任务。

5、贫困户转移就业技能培训工程。黄河水科院、发展研究中心和水利报社筹集的培训资金25万元，已全部到位。第一期贫困户转移就业技能培训班于5月份成功举办，80人次参加，目前正在加快推进第2期培训班相关工作。

6、贫困学生勤工俭学帮扶工程。按照《水利部定点帮扶丰都县2017年丰都籍贫困学生勤工俭学工作方案》，50名丰都籍贫困在校大学生勤工俭学岗位已全部落实。重庆市水利局重点抓好用人单位落实、学生安全生产教育，有序推进勤工俭学工作。

7、水利建设技术帮扶工程。中国水科院充分发挥技术优势，指导丰都县完成龙河国家级风景区申报工作；撰写三峡库区消落带治理研究报告；加快编制龙河流域规划报告，其中，“水资源利用规划”报告已完成70%，“水生态环境保护规划”报告已完成85%。长江设计院编制完成观音岩、莲花、小月坝水库初步设计报告，抓紧开展各专题报告编制工作；修改完成《重庆市丰都县龙河国家级水利风景区生态调节坝工程项目建设方案报告》，推进涉河建设方案及防洪影响评价报告编制。

8、专业技术人才培训工程。2017年，部水资源司牵头开展培训工作，计划培训丰都县干部职工101人次。截至目前，丰都县水务局已组织90人次参加黄河水科院、重庆市水利局等单位主办的专业技术培训班。

（二）其他相关帮扶事项

重庆市水利局积极与市财政局沟通协调，7月份分解下达丰都县2017年水利发展资金1618万元，涉及新建小型水库、水土保持、中小河流治理等建设任务。目前，各项工程正有序推进。

二、下一步工作建议

目前定点扶贫丰都县脱贫攻坚各项工作进展顺利，请各成员单位进一步加强协调配合。围绕水利定点扶贫丰都县“八大工程”年度任务，丰都县要加强前期工作，抓好项目实施和跟踪落实工作，加快推动工程建设，保证工程质量安全和效益发挥，确保年度任务的完成。
