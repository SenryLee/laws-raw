# 国家文物局关于五门堰龙门寺修缮工程立项的意见

## 关于五门堰龙门寺修缮工程立项的意见

办保函〔2017〕360号

陕西省文物局：

你局《关于五门堰——龙门寺保护修缮工程立项的请示》（陕文物字〔2017〕30号）收悉。经研究，我局意见如下：

一、暂不同意五门堰龙门寺修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）加强现状勘察和研究，明确各单体文物建筑的建造年代、主要病害类型、残损情况等，深入分析屋面漏雨、木构件糟朽、地面残损等病害原因，全面梳理近年来维修情况，客观评估不当改造影响，进一步论证工程实施的必要性和可行性。

（二）补充地方建造工艺、传统做法、建筑材料和构造特征等研究和分析内容。

（三）进一步细化工程措施，以现状整修为主，严格控制工程量和工程强度，避免过度维修。不影响使用功能的地面砖、石构件，应保持现状。同时，结合院落整治统筹考虑排水问题，细化排水措施。补充修缮后文物建筑和寺内碑刻展示内容。

（四）根据工程量合理编制经费预算，确定取费项目，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年3月31日
