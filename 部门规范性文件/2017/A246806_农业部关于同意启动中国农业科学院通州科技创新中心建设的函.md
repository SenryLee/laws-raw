# 农业部关于同意启动中国农业科学院通州科技创新中心建设的函

农计函〔2017〕2号

中国农业科学院：

《中国农业科学院关于建设通州科技创新中心的请示》（农科院基建〔2016〕288号）收悉。函复如下：

为开展前瞻性战略谋划和布局，打破学科界限，优化资源配置，打造国家现代农业创新平台，解决京区现有科研用房和试验用地不足等问题。经研究，同意你院会同中国水产科学研究院在北京市通州区于家务乡建设农业科技创新中心，你院征用建设用地542亩，总建筑规模控制在41.2万平方米，征用农业用地887亩。“十三五”期间，优先启动生物技术研究中心、作物表型鉴定设施、耕地保育与新型肥料创制、农业重大气象灾害模拟舱、农业科研大数据中心等5个国家重大科技基础设施平台建设。项目建设投资和土地征用费通过中央预算内投资和自筹资金解决。

请抓紧与北京市有关部门衔接沟通，加快推进科技创新中心前期工作。

农业部

2017年1月22日
