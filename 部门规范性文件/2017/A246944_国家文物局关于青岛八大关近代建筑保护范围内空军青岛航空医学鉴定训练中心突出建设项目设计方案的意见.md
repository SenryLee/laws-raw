# 国家文物局关于青岛八大关近代建筑保护范围内空军青岛航空医学鉴定训练中心突出建设项目设计方案的意见

## 关于青岛八大关近代建筑保护范围内空军青岛航空医学鉴定训练中心突出建设项目设计方案的意见

办保函〔2017〕28号

山东省文物局：

你局《关于报送空军青岛航空医学鉴定训练中心突出建设项目设计方案的请示》（鲁文发〔2016〕156号）收悉。经研究，我局意见如下：

一、暂不同意所报青岛八大关近代建筑保护范围内空军青岛航空医学鉴定训练中心突出建设项目设计方案。

二、该方案应做以下修改和完善：

（一）补充拟拆除42#、31#、41#和八一礼堂等四座建筑与八大关近代建筑群的关系说明分析，补充相关总平面图。

（二）补充拟改建空勤一科用房、空勤三科用房两座建筑的具体位置、建筑高度等内容。

（三）进一步明确八大关近代建筑群保护区划建设控制的管理规定及控制指标，新建和改建建设项目应符合建设控制的相关要求。

（四）重新核定新建和改建建筑高度。新建和改建建筑高度应按最高点计，不宜套用“传统大屋顶建筑高度按檐口计”的方法；计高应由室外现状地坪起算，如无明确的起算点规定，各栋高均应自各自所处室外的低点起算。

（五）进一步深化文物环境影响评估。

请你局根据上述意见组织相关单位对方案进行修改完善后，按程序另行报批。

专此。

国家文物局

2017年1月13日
