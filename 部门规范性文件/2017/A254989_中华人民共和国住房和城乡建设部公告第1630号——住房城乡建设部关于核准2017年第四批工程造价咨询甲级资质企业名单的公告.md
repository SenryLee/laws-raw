# 中华人民共和国住房和城乡建设部公告第1630号——住房城乡建设部关于核准2017年第四批工程造价咨询甲级资质企业名单的公告

## 中华人民共和国住房和城乡建设部公告

第1630号

## 住房城乡建设部关于核准2017年第四批工程造价咨询甲级资质企业名单的公告

根据《工程造价咨询企业管理办法》（建设部令第149号）的规定，我部组织对工程造价咨询企业晋升甲级资质进行了审核。现将核准的北京捷迅通力工程咨询有限公司等77家工程造价咨询甲级资质企业名单予以公布。

特此公告。

附件：核准的工程造价咨询甲级资质企业名单

住房城乡建设部

2017年8月18日
