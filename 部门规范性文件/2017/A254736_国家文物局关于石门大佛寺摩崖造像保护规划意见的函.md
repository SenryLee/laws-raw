# 国家文物局关于石门大佛寺摩崖造像保护规划意见的函

文物保函〔2017〕1499号

重庆市文物局：

你局《关于对石门大佛寺摩崖造像保护规划的请示》（渝文物〔2016〕262号）收悉。经研究，我局意见如下：

一、原则同意所报石门大佛寺摩崖造像保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

进一步厘清石门大佛寺与上佛寺等的关系。加强文物与航运系统历史关系研究，补充文物历史环境构成要素、历次维修工程效果评估和必要的沿江景观视线分析内容。

（二）关于保护区划与管理规定

应结合文物和重要景观要素分布情况、周边建设控制需要等，综合考虑保护区划问题，进一步补充保护区划调整依据。建议适当扩大建设控制地带南侧范围，将与文物景观影响密切的江对岸区域纳入建设控制地带。同时，应进一步论证景观协调区设置的必要性和可行性，建议将其纳入建设控制地带统筹考虑。进一步规范和细化保护区划管理规定，明确建设控制地带内建筑高度、规模、体量和外观等控制指标。

（三）关于保护措施

应针对现状评估结论，科学研提保护策略，尽量减少文物本体的工程干预，以水害治理为主。

（四） 关于环境整治和专项规划

根据文物保护和展示利用需要，科学调整展陈分区，结合游线设计统筹考虑相关展示、服务设施建设的选址问题，严格控制建设规模，尽量降低城市广场、步行街的景观影响；深化管理规划，明确文物部门与景区管理部门之间的责权关系，妥善处理文物保护与旅游开发之间的关系；补充监测专项规划，针对赋存岩体稳定性和铁路振动影响等，提出具体监测要求。“新建服务设施”应纳入展示利用规划。

（五）进一步校核与规范文本与图纸，精炼文本内容。文本用语应严谨、准确、统一。现状图与规划图应分类编号。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善并经你局核准后，于15个工作日内将规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的石门大佛寺摩崖造像保护规划报请重庆市人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体立项报告或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好石门大佛寺摩崖造像的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年8月22日
