# 国家新闻出版广电总局办公厅、全国老龄工作委员会办公室综合部关于公布2017年向全国老年人推荐优秀出版物的通知

## 关于公布2017年向全国老年人推荐优秀出版物的通知

新广出办发〔2017〕70号

各省、自治区、直辖市新闻出版广电局、老龄工作委员会办公室，新疆生产建设兵团新闻出版广电局、老龄工作委员会办公室，中央军委政治工作部宣传局，中央和国家机关各部委、各民主党派、各人民团体出版单位主管部门，中国出版集团公司，中国教育出版传媒集团有限公司，中国科技出版传媒集团有限公司：

为全面贯彻落实党的十九大精神，深入贯彻习近平新时代中国特色社会主义思想，弘扬孝老爱亲中华优秀传统文化，大力推动全民阅读，进一步丰富老年人的精神文化生活，国家新闻出版广电总局与全国老龄工作委员会办公室共同开展了2017年向全国老年人推荐优秀出版物活动。经专家评审、质量检查和媒体公示等严格程序，最终确定了2017年向全国老年人推荐的优秀出版物（目录详见附件）。现将有关要求通知如下。

一、切实加强宣传推广。各省级新闻出版广电局和老龄工作委员会办公室要积极开展向全国老龄读者宣传推荐入选的优秀出版物，组织各类媒体加强对入选出版物的宣传推介，把优秀出版物推荐给广大老龄读者，并可将这批优秀出版物纳入农家书屋、社区书屋目录，充分发挥引领示范作用。

二、广泛举办展示展销。各省级新闻出版广电局要组织出版单位、发行单位认真做好入选出版物的展示展销工作。在“敬老月”期间，各实体书店和网络书店要开展优秀出版物展示展销活动，中心城市新华书店要设立专柜、专架，集中展示展销向全国老年人推荐的优秀出版物。各相关单位要切实做好优秀老年人出版物的出版、供货、货源储备等工作，以优质的服务、优惠的价格向广大老龄读者提供更好更多的优秀出版物。

三、深入开展阅读活动。各省级新闻出版广电局和老龄工作委员会办公室要结合全民阅读活动、“敬老月”活动以及其他部门组织的敬老助老活动，充分利用向老年人推荐的优秀出版物，开展形式多样的阅读活动，吸引老龄读者积极参与，不断丰富老年人的精神文化生活。

四、认真做好总结工作。国家新闻出版广电总局和全国老龄工作委员会办公室将对入选出版物的出版单位予以表扬，并颁发入选证书。各省级新闻出版广电局和中央出版单位主管部门也要认真总结本地区本部门的推荐工作，表扬在此次活动中表现突出的出版单位。各相关出版单位要认真学习借鉴这批优秀出版物的出版经验，重视和加强老龄读物出版工作，为营造敬老养老助老的和谐社会风尚贡献力量。

附件：2017年向全国老年人推荐优秀出版物目录

国家新闻出版广电总局办公厅　全国老龄工作委员会办公室综合部
