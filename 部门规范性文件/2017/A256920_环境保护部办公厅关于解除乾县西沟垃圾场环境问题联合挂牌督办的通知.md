# 环境保护部办公厅关于解除乾县西沟垃圾场环境问题联合挂牌督办的通知

## 关于解除乾县西沟垃圾场环境问题联合挂牌督办的通知

环办环监函〔2017〕1604号

咸阳市人民政府：

按照我部《关于对乾县西沟垃圾场环境问题联合挂牌督办的通知》（环办环监〔2016〕76号）要求，你市督促乾县人民政府按照督办要求积极整改西沟垃圾场环境问题，并向我部提交了解除联合挂牌督办申请。经我部会同陕西省人民政府组织现场核查，目前乾县西沟垃圾场环境问题整改工作基本达到督办要求。

经商陕西省人民政府，现决定解除对乾县西沟垃圾场环境问题联合挂牌督办。请你市督促乾县人民政府认真落实改善环境质量的主体责任，指导乾县新建生活垃圾卫生填埋场、渗滤液处理设施和垃圾中转站规范运行，不断完善城乡垃圾收集管理长效机制，促进城乡环境质量持续改善。

环境保护部办公厅

2017年10月23日
