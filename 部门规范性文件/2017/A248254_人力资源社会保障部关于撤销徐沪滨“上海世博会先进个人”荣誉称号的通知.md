# 人力资源社会保障部关于撤销徐沪滨“上海世博会先进个人”荣誉称号的通知

人社部发〔2017〕18号

中国国际贸易促进委员会：

经研究决定，撤销贸促会原秘书长徐沪滨“上海世博会先进个人”荣誉称号，收回奖章、证书，停止其享受的有关待遇。

人力资源社会保障部

2017年3月9日
