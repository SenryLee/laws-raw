# 中华人民共和国财政部公告2017年第157号——决定发行2017年记账式贴现（五十五期）国债

## 中华人民共和国财政部公告

2017年第157号

根据国家国债发行的有关规定，财政部决定发行2017年记账式贴现（五十五期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

一、本期国债计划发行150亿元，实际发行面值金额150亿元。

二、本期国债期限91天，经招标确定的发行价格为99.048元，折合年收益率为3.85%，2017年11月27日开始计息，招标结束后至11月27日进行分销，11月29日起上市交易。

三、本期国债低于票面面值贴现发行，2018年2月26日（节假日顺延）按面值偿还。

其他事宜按《中华人民共和国财政部公告》（2017年第2号）规定执行。

特此公告。

中华人民共和国财政部

2017年11月24日
