# 环境保护部办公厅关于对河北石家庄市赞皇县垃圾填埋场环境问题挂牌督办的通知

## 关于对河北石家庄市赞皇县垃圾填埋场环境问题挂牌督办的通知

环办环监[2017]31号

河北省环境保护厅：

2017年3月，我部与住房城乡建设部联合你厅及省住房城乡建设厅对赞皇县垃圾填埋场进行现场检查，发现该填埋场没有落实石家庄市环境保护局要求，未搬迁卫生防护距离内常住居民（1户6人）。我部决定对赞皇县垃圾填埋场未搬迁卫生防护距离内居民问题进行挂牌督办。

请你厅督促相关单位落实督办要求（见附件），完成督办任务后，由你厅向我部提出解除挂牌督办的书面申请并附相关材料。我部将适时赴现场进行核查。

联系人：环境保护部环境监察局 阮仁节

电话：（010）66556434

传真：（010）66556475

附件：环境问题基本情况及督办要求

环境保护部办公厅

## 环境问题基本情况及督办要求

基本情况：赞皇县垃圾填埋场没有落实石家庄市环境保护局要求，未搬迁卫生防护距离（500米）内常住居民（1户6人，距该填埋场库区南坝偏东侧458.5米）。

督办要求：督促赞皇县人民政府推进该填埋场卫生防护距离内居民搬迁工作。

督办期限：2017年9月30日前完成督办事项。
