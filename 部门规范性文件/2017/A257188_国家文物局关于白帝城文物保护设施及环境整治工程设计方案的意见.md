# 国家文物局关于白帝城文物保护设施及环境整治工程设计方案的意见

文物保函〔2017〕1801号

重庆市文物局：

你局《关于报送重庆奉节白帝城文物保护设施及环境整治工程设计方案的请示》（渝文物〔2017〕221号）收悉。经研究，我局意见如下：

一、原则同意白帝城文物保护设施及环境整治工程和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）进一步补充现状勘察内容，详细论证说明工程实施的必要性，包括：核心保护区地面铺装更换、现状挡墙及边坡整治、恢复、竹枝园碑林碑廊以及新建展示用房等，并符合我局已批复的《白帝城保护规划》（文物保函〔2009〕1270号）的相关要求。

（二）进一步深化、完善方案设计，补充相关设计图纸。护坡加固工程应加强地质滑坡危害评估，根据评估结论提出针对性措施并由具备专业资质的单位完善设计方案。

三、请你局指导有关单位，根据上述意见对所报方案进行修改、完善，并根据《文物保护法》第十七条、第十八条的有关规定分别报送重庆市人民政府和城乡建设规划部门批准后实施。

专此函复。

国家文物局

2017年10月30日
