# 国家文物局关于汉武帝茂陵保护性基础设施建设项目涉及茂陵保护范围选址的意见

## 关于汉武帝茂陵保护性基础设施建设项目涉及茂陵保护范围选址的意见

办保函〔2017〕445号

陕西省文物局：

你局《关于汉武帝茂陵保护性基础设施建设项目选址的请示》（陕文物字〔2017〕56号）收悉。经研究，我局意见如下：

一、拟建汉武帝茂陵保护性基础设施选址涉及茂陵保护范围和建设控制地带的方案占压地下文物遗存，我局暂不同意所报方案。

二、所报方案尚需做以下必要的修改和完善：

（一）应在方案二的基础上对游客管理服务中心和生态停车场的选址做进一步优化，建议整体西移，以避开茂陵陵园外围墙及外壕沟遗址。

（二）若选址一的地块已具备实施条件，可考虑仅进行生态停车场建设，但应压缩规模，避开茂陵外藏坑遗址。

（三）应进一步严格控制拟建建筑及附属设施的规模、体量和高度，优化外观设计，注意与茂陵及其周边环境相结合。同时，游客管理服务中心的相关功能设置应与现茂陵博物馆统筹考虑，避免重复建设。

三、请你局指导建设单位，根据上述意见对所报方案做进一步修改和完善，做好文物影响评估，经你局核准后，按程序另行报批。

国家文物局

2017年4月14日
