# 国家文物局关于在桃花源古建筑群进行环境整治项目意见的函

## 关于在桃花源古建筑群进行环境整治项目意见的函

办保函〔2017〕769号

湖南省文物局：

你局《关于审批〈桃花源古建筑群环境整治方案〉的请示》（湘文物报〔2017〕63号）收悉。经研究，我局意见如下：

一、所报方案对文物周边环境的干预过多，缺乏必要的设计依据，对文物及其历史环境不利影响较大，我局暂不同意桃花源古建筑群环境整治工程。

二、该方案应进行必要的修改和完善：

（一）所报项目位于全国重点文物保护单位桃花源古建筑群保护范围和建设控制地带内，应严格按照《中华人民共和国文物保护法》和湖南省人民政府公布的《桃花源古建筑群保护规划》关于保护范围和建设控制地带的管理规定、具体控制要求，重新调整设计思路，合理确定项目内容，尽量减少对文物及周边环境的影响。

（二）应加强历史研究和资料搜集，详细分析、论证文物分布范围、建筑格局和历史环境要素等，在《桃花源古建筑群保护规划》指导下，统筹考虑管理用房、广场、停车场等设施建设项目的必要性，核定设施总需求量，明确功能布局，严格控制新建设施数量、规模和体量。

（三）进一步深化方案设计，建筑改造建议采用当地传统结构做法；明确道路铺装形式、材料，尽量做到朴实、协调；保护历史环境要素，不同意桃花山入口河道调整设计和新增水系。注意避免过度人工化和现代景观园林化设计倾向。

（四）补充文物影响评估报告，客观、准确地论证拟建项目对文物本体和环境风貌的影响，科学研提方案调整建议。

（五）进一步完善文本和图纸。补充方案总平面图、新建设施设计图和建筑立面改造设计图，完善尺寸标注。

三、请你局组织相关单位根据上述意见，对项目方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局

2017年6月20日
