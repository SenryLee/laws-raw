# 国家文物局关于社稷坛中山堂屋面修缮工程的意见

## 关于社稷坛中山堂屋面修缮工程的意见

办保函〔2017〕539号

北京市文物局：

你局《关于社稷坛中山堂抢险修缮工程方案的请示》（京文物〔2017〕326号）收悉。经研究，我局意见如下：

一、所报方案前期勘察和研究不足，工程干预量过大，文本深度不够，我局暂不同意社稷坛中山堂屋面修缮工程。

二、对所报方案提出以下修改意见：

（一）加强现状勘察和研究，深入分析中山堂屋面的残损原因，核实檐部沉降变形、大木架脱榫、屋面漏雨等的具体位置、范围，科学评估病害程度，在此基础上明确工程性质、工程内容和范围。补充中山堂历次修缮工程情况和工程效果评估内容。

（二）补充中山堂的建造工艺、做法、建筑材料和构造特征等研究和分析内容。

（三）应以现状整修为主，严格控制工程量和工程强度，避免大量更换原有木构件、瓦件。不同意屋面琉璃构件涂刷憎水剂；补充说明望板更换80%的原因；制定施工过程中重要构件、彩画的临时性保护措施，确保施工过程中文物安全。

（四）进一步规范图纸，注意工程措施与现状勘察的对应性，避免前后矛盾；补充屋面现状照片。

三、请你局根据上述意见，组织相关单位认真修改、完善设计方案，经你局审核后另行报批。

四、请你局督促地方人民政府切实加强社稷坛日常保养和岁修工作，及时发现和排除隐患，确保文物安全。

专此函。

国家文物局

2017年5月8日
