# 住房城乡建设部标准定额司关于同意钢管混凝土组合结构体系施工规程等79项推荐性工程建设地方标准备案的函

建标实函〔2017〕170号

河北、山西、江苏、浙江、福建、江西、山东、河南、广东、广西、海南、四川、陕西、甘肃、新疆省（自治区）住房城乡建设厅，北京、天津、上海、重庆市建委：

河北等省（区、市）《关于申请<钢管混凝土组合结构体系施工规程>等两项标准备案的函》（冀建标函[2017]8号）等函收悉，经研究，同意以下79项推荐性地方标准作为“中华人民共和国工程建设地方标准”备案（见附件）。
