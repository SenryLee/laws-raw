# 国家质量监督检验检疫总局公告2017年第61号——质检总局关于公布拟认定的首批在涉及“冲突钻石”和“冲突矿产”领域开展活动的境外非政府组织名单的公告

## 国家质量监督检验检疫总局公告

2017年第61号

## 质检总局关于公布拟认定的首批在涉及“冲突钻石”和“冲突矿产”领域开展活动的境外非政府组织名单的公告

依照《中华人民共和国境外非政府组织境内活动管理法》和《境外非政府组织在中国境内活动领域和项目目录、业务主管单位名录（2017）》有关规定，为依法管理境外非政府组织在中国境内开展涉及“冲突钻石”和“冲突矿产”领域的活动，现就拟认定的在上述领域开展活动的首批境外非政府组织名单公布如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 中英文名称 | 成立国家 | 活动领域 |
| 1 | 世界钻石理事会  World Diamond Council | 美国 | 冲突钻石 |
| 2 | 世界钻石交易所联盟  World Federation of Diamond Bourses | 比利时 | 冲突钻石 |
| 3 | 电子产业公民联盟  Electronic Industry Citizenship Coalition | 美国 | 冲突矿产 |

如有关单位或个人对上述认定持有异议，可自本公告发布之日起1个月内向质检总局书面提出，并说明异议具体内容、依据或理由。
