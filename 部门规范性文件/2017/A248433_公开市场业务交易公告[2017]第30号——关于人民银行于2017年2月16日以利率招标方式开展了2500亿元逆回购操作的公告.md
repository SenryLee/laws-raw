# 公开市场业务交易公告[2017]第30号——关于人民银行于2017年2月16日以利率招标方式开展了2500亿元逆回购操作的公告

## 公开市场业务交易公告

[2017]第30号

人民银行于2017年2月16日以利率招标方式开展了2500亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 7天 | 800亿元 | 2.35% |
| 14天 | 800亿元 | 2.50% |
| 28天 | 900亿元 | 2.65% |

中国人民银行公开市场业务操作室

二〇一七年二月十六日
