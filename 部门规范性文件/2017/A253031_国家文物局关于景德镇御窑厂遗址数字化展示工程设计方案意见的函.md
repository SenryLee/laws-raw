# 国家文物局关于景德镇御窑厂遗址数字化展示工程设计方案意见的函

## 关于景德镇御窑厂遗址数字化展示工程设计方案意见的函

文物保函〔2017〕959号

江西省文物局：

你局《关于呈报〈御窑厂遗址数字化展示工程设计方案〉的请示》（赣文物局字〔2017〕32号）收悉。经研究，我局意见如下：

一、原则同意景德镇御窑厂遗址数字化展示工程设计方案。

二、所报方案尚需做以下必要的修改和完善：

（一）应明确数字化展示是现有展示补充和提升的功能定位，并进一步优化数字化展示的相关需求。

（二）细化不同类型数字化展示的具体设计，明确产出情况及评估指标分析。同时，应补充不同数字化展示方式的内容设计，注意吸收已有考古及其他相关研究工作的成果，做到科学、准确，并应充分注意易读性。

（三）各类技术手段应用及数据采集应坚持目标导向，以满足后续工作需求为限，不得盲目追求新技术的应用以及高精度数据的采集。

（四）应在进行比选的基础上，针对不同的文物分别采用三维扫描建模或照片建模的方式，不得对所有文物同时开展两种方式的建模。同时，应系统梳理并充分利用已有数据，尤其是瓷器的高精度数据影响等，不得重复采集。

（五）细化网站建设、手机终端APP开发等的具体内容和框架。

（六）应注意与现有保护展示工程及标识导览系统实现有机结合。同时，各类数字化展示设施的布设应充分考虑现有展示设施的有效利用。

（七）细化工程量，并严格控制项目预算，做到测算科学，依据充分。

三、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改、完善和细化，经你局核准后实施。

国家文物局

2017年5月9日
