# 国家文物局关于在勉县武侯祠保护范围内进行院落排水设施改造项目的意见

文物保函〔2017〕1625号

陕西省文物局：

你局《关于申报勉县武侯祠院落有组织排水设施改造工程的请示》（陕文物字〔2017〕179号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位勉县武侯祠保护范围内实施院落排水设施工程和你局意见。

二、对该项目提出以下修改意见：

（一）该项目位于全国重点文物保护单位勉县武侯祠保护范围内，应遵守《中华人民共和国文物保护法》和陕西省人民政府关于勉县武侯祠保护管理的相关规定，严格控制施工范围，尽量减少设施建设对文物本体及周边环境的影响。

（二）应坚持最小干预原则，严格控制地面开挖规模，避免对文物建筑造成不利影响。

1. 优化排水方式，建议采用地表排水和暗沟排水相结合的方式。

2. 进一步论证排水沟采用混凝土形式的必要性，建议尽量采用砖石类传统材料砌筑。

3. 进一步论证因增设院落有组织排水系统而全面更换地面铺装的必要性，尽量保留原有铺装，对原状地面和原有排水方式应以维修保护为主；重新铺装部分应尽量使用原材料和原铺装形式。

（三）进一步论证污水系统改造项目的必要性、对文物本体的影响，并研提针对性措施。

（四）进一步规范文本与图纸，补充排水沟剖面图。

（五）完善文物影响评估报告，补充关于雨水系统和院落地面改造的相关评估和分析内容，科学研提方案调整建议。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，按照《中华人民共和国文物保护法》第十七条的规定，经陕西省人民政府批准实施。

施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。请加强对工程的监管，确保文物及其环境安全。

四、请你局督促地方人民政府尽快修改、完善《勉县武侯祠保护规划》，统筹考虑文物保护、环境整治、展示利用等工作，切实加强日常管理、巡查与岁修工作，确保文物本体与周边环境安全。

专此函复。

国家文物局

2017年9月11日
