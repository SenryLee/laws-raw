# 农业部办公厅关于切实做好2017年草原鼠虫害防治工作的通知

农办牧〔2017〕22号

有关省（自治区）畜牧（农牧、农业）厅（局、委），新疆生产建设兵团畜牧兽医局：

2017年草原鼠虫害防治补助资金已经财政部财农〔2017〕22号文件拨付地方（任务资金分配详见附件）。为切实做好草原鼠虫害防治工作，现将有关事项通知如下。

一、强化组织领导

今年是巩固“十三五”草原保护建设事业良好发展势头、推进生态文明体制改革的关键之年，做好草原鼠虫害防控工作意义重大。各地要在思想上高度重视，工作上狠抓落实，按照“属地管理、分级负责”的原则，切实强化组织领导，建立健全防控指挥协调机构，落实成员单位职责，完善应急响应机制，保障防治工作高效有序开展。

二、强化监测预警

要加强对重点区域和关键时期草原鼠虫害发生动态的监测预警，特别要加强包虫病流行区域鼠害和边境地区境外飞蝗的监测预警。组织技术人员深入草原腹地开展路线调查，定期采集固定监测站数据，密切跟踪种群动态，做到全方位覆盖，避免出现监测死角。结合村级草原管护员岗位设置，推进基层草原鼠虫害测报队伍建设，提高监测预警能力。

三、强化保障能力

要根据本地草原鼠虫害发生特点，提前做好物资储备、机械维修、飞机调度、组织动员、技术培训等工作，确保灾害发生后能够迅即应对。防控关键时期，各级业务部门要深入防灾一线做好技术服务与督导检查，确保各项措施落实到位。四川省有关部门要组织实施好石渠县草原鼠害综合治理试点项目，为推进藏区包虫病防治提供有力支撑。

四、强化绿色防控

要结合草原有害生物发生规律，大力推广应用生物制剂、植物源农药、天敌调控、物理防控和生态治理等绿色防控措施，减少化学农药用量，逐步提高草原生态系统自我修复能力。积极组织开展新药剂筛选和新技术试验示范，强化微生物治蝗协作，研究建立黑土滩（鼠荒地）和毒害草的综合治理技术体系。

五、强化信息宣传

要及时主动发布草原鼠虫害灾情信息，总结宣传防治成绩，推广典型经验做法，营造良好工作氛围。要把宣传工作作为推进政务公开、促进草原鼠虫害防治的重要手段，充分发挥广播电视、报刊杂志、网络平台等媒体的各自优势，实现从单向宣传向互动宣传转变，积极妥善处置舆情，掌握宣传主动权。

六、强化应急职守

6月1日至8月31日，各级草原虫灾防治机构要实行24小时值班制度和零报告制度。各省区每周三报送草原虫灾发生与防治情况，如出现重大灾情或防治事故等情况随时上报。请于5月1日前将草原虫害省级指挥机构人员名单和值班电话，6月1日前将草原鼠害、虫害防治实施方案，9月15日前将草原鼠虫害防治工作总结，报至农业部草原虫灾防治值班室（全国畜牧总站）。
