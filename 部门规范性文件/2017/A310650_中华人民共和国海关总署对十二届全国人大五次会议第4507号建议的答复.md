# 中华人民共和国海关总署对十二届全国人大五次会议第4507号建议的答复

黄志峰等13名代表：

你们提出的《关于加大对古雷开发区扶持力度的建议》（发展规划、建设项目和综合经济类第4507号）收悉。经认真研究，关于支持设立漳州古雷综合保税区的相关事宜，现答复如下：

设立海关特殊监管区域由国务院审批，海关总署为牵头审核报批和管理部门。根据《国务院关于促进海关特殊监管区域科学发展的指导意见》（国发〔2012〕58号）的精神和要求，新设海关特殊监管区域统一为综合保税区，综合保税区具备保税加工、保税物流和保税服务等功能。设立海关特殊监管区域应符合有利于实施国家区域发展战略规划、有利于中西部地区承接产业转移、有利于海关特殊监管区域整合优化以及确实有外向型大项目亟待进驻的原则。设立综合保税区应符合《海关特殊监管区域设立审核办法》的相关规定。

我署积极支持福建省外向型经济发展和深化两岸产业合作，支持福建省在具备条件的地区设立海关特殊监管区域。建议福建省人民政府对设立漳州古雷综合保税区进一步加强统筹协调，切实加大招商力度，以大项目落地作为申报设立区域的基础，确保入区项目适合综合保税区的政策功能，条件成熟时我署将会同相关部门予以积极支持。

感谢对我们工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2017年5月19日
