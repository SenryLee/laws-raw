# 国家质量监督检验检疫总局公告2017年第1号——质检总局关于出口新西兰葡萄及进口新西兰苹果、墨西哥蓝莓、秘鲁蓝莓、智利油桃、埃及葡萄植物检验检疫要求的公告

本法规附件5“智利油桃输华植物检验检疫要求”已被《海关总署关于进口智利鲜食核果植物检疫要求的公告》（海关总署公告2023年第138号）自2023年10月23日起废止。

## 国家质量监督检验检疫总局公告

2017年第1号

## 质检总局关于出口新西兰葡萄及进口新西兰苹果、墨西哥蓝莓、秘鲁蓝莓、智利油桃、埃及葡萄植物检验检疫要求的公告

根据风险分析结果，经与新西兰、墨西哥、秘鲁、智利和埃及等国检验检疫部门协商，质检总局与相关国家的检疫部门分别签署了《关于中国鲜食葡萄输往新西兰出口计划》《关于新西兰苹果输华植物检疫要求的议定书》《关于墨西哥鲜食蓝莓输华植物检疫要求的议定书》《关于秘鲁鲜食蓝莓输华植物检疫要求的议定书》《关于智利油桃输华植物检疫要求的议定书》《关于埃及鲜食葡萄输华植物检疫要求的议定书》。

即日起，允许符合相关要求（见附件1）的中国葡萄向新西兰出口；符合相关要求（见附件2、3、4、5、6）的新西兰苹果、墨西哥蓝莓、秘鲁蓝莓、智利油桃和埃及葡萄输往中国。

附件：1. 中国葡萄输新西兰植物检验检疫要求

2. 新西兰苹果输华植物检验检疫要求

3. 墨西哥蓝莓输华植物检验检疫要求

4. 秘鲁蓝莓输华植物检验检疫要求

5. 智利油桃输华植物检验检疫要求

6. 埃及葡萄输华检验植物检疫要求

质检总局

2017年1月11日
