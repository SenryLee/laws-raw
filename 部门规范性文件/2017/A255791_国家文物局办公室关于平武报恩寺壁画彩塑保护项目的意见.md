# 国家文物局办公室关于平武报恩寺壁画彩塑保护项目的意见

办保函〔2017〕984号

四川省文物局：

你局《关于报送四川平武报恩寺壁画彩塑保护修复设计方案的请示》（川文物〔2017〕66号）收悉。经研究，我局意见如下：

一、所报方案保护措施可行性论证不足，设计依据不充分，文本深度不够，我局暂不同意平武报恩寺壁画彩塑保护项目。

二、对所报方案提出以下修改意见：

（一）加强现状勘察和监测，明确平武报恩寺壁画彩塑保存环境的变化规律，全面、科学地勘察壁画和彩塑保存现状、工艺做法和使用材料等。根据环境监测数据进一步核实冻融病害的具体范围，补充彩塑制作工艺调查、霉菌病害具体情况和白蚁、木蜂等虫害的现状情况调查。

（二）注意加强前期试验研究工作与工程措施的对应性，根据试验结论科学指导方案设计。

1．明确温湿度监测中冷凝现象的监测结论。

2．补充酥碱部位盐分鉴定相关内容，为酥碱加固和脱盐措施提供依据。

3．补充灌浆材料与被灌部位的粘接力测试内容。

（三）坚持最小干预原则，严格控制工程范围和强度，明确壁画彩塑修复的使用材料、工艺做法和操作流程。

1．应以地仗层试验分析结果为依据科学确定修补材料具体成分。

2．应以白灰覆盖层成分分析结果为依据科学选择白灰覆盖层清除试剂。

3．慎重采取灌浆措施，应尽量采用边缘加固措施，对于必须要灌浆的，应进行必要的现场实验论证。

4．注意烟熏层清除过程中的溶剂残留问题。

（四）补充虫害防治具体措施，保证文物安全。

三、请你局组织相关单位根据所提意见，对项目方案进行修改完善后，按我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的相关要求另行报批。

专此函复。

国家文物局办公室

2017年8月21日
