# 公开市场业务交易公告[2017]第59号——关于3月29日不开展公开市场操作的公告

## 公开市场业务交易公告

[2017]第59号

临近月末财政持续支出，对冲央行逆回购到期后银行体系流动性总量适中，3月29日不开展公开市场操作。

中国人民银行公开市场业务操作室

二〇一七年三月二十九日
