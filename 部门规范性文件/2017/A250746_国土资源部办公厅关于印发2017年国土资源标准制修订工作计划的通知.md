# 国土资源部办公厅关于印发2017年国土资源标准制修订工作计划的通知

国土资厅发[2017]23号

各省、自治区、直辖市国土资源主管部门，中国地质调查局及部其它直属单位，各派驻地方的国家土地督察局，部机关各司局，全国国土资源标准化技术委员会及各分技术委员会，全国珠宝玉石标准化技术委员会，其他有关单位：

依据《国土资源标准体系》和《国土资源标准化管理办法》，部组织制定了《2017年国土资源标准制修订工作计划》，包括拟申请报批标准计划66项，拟开展标准预研究计划48项，在研标准项目备案22项，地方标准项目备案14项。现印发给你们，请认真组织实施。现将有关要求通知如下：

（一）提升标准质量。对列入拟报批标准计划的项目，请各起草单位按照《国土资源标准化管理办法》有关要求，应结合国土资源工作实际需求，广泛调研，加强协作，深入分析，试点验证，保证标准的一致性、适用性和先进水平，按时完成标准制修订任务。请技术归口单位加强跟进协调，做好标准审查和报批工作，保障标准质量。

（二）落实保障条件。对列入拟开展预研究计划的项目，请各推荐单位和起草单位积极协调，组织研制人员，保障研制经费，尽快启动标准预研究。请技术归口单位加强跟进协调，做好标准编制培训工作。

（三）加强衔接协调。对备案的在研标准项目，请有关单位在国土资源标准体系框架下，推动项目研究与标准研制紧密结合，促进研究成果及时转化为标准。请技术归口单位跟进项目研究进展，加强标准项目立项的系统性和科学性审查，加强项目研究与标准立项的衔接协调。对备案的地方标准，请有关省级国土资源主管部门积极组织标准宣贯和实施，加强与国家标准、行业标准的衔接协调。请有关社会团体，在国土资源标准体系框架下，积极开展标准研制，为制定国家标准、行业标准做好技术储备。

（四）支撑业务管理。请各省级国土资源主管部门、各司局、各直属单位，发挥好标准在推进工作、强化监管、创新管理等方面的作用，用标准规范来规范工作行为，维护行业秩序。用标准规范内部管理，提升管理水平。

2017年5月9日

附件：2017年国土资源标准制修订工作计划
