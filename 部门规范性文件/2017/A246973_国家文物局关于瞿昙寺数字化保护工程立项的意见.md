# 国家文物局关于瞿昙寺数字化保护工程立项的意见

## 关于瞿昙寺数字化保护工程立项的意见

办保函〔2017〕53号

青海省文物管理局：

你局《关于瞿昙寺数字化保护工程立项的请示》（青文物局〔2016〕192号）收悉。经研究，我局意见如下：

一、所报工程立项的必要性和可行性论述不足，技术路线不明确，内容杂乱，我局暂不同意瞿昙寺数字化保护工程立项。

二、应针对瞿昙寺文物保护管理需要，进一步研究开展数字化保护工程的必要性，论证具体工程目标、技术路线和实施内容等，并结合瞿昙寺保护展示工作进展，充分考虑数字化成果使用和平台维护等问题。

三、请你局指导地方人民政府按照《瞿昙寺（含药草台寺）文物保护规划》要求，切实做好文物保护和管理工作，加强日常养护、巡查和文物保护工程工地检查，确保文物本体及周边环境风貌安全。

专此函。

国家文物局

2017年1月24日
