# 中国证券监督管理委员会对十二届全国人大四次会议第6055号建议的答复（摘要）

## 对十二届全国人大四次会议第6055号建议的答复（摘要）

《关于加快推进我国原油期货市场建设的建议》收悉。经认真研究，现就有关问题答复如下：

**一、**关于抓住低油价有利时机开放我国原油期货市场的问题

近年来，国际市场原油价格波动较为剧烈。上市原油期货有利于涉油企业规避油价剧烈波动风险，增强我国在国际原油定价体系中的影响力和话语权，丰富完善我国石油储备体系建设。我会2012年启动原油期货市场的相关筹备工作，2013年按照国务院的统一部署，与发展改革委、能源局牵头，联合相关部委以及涉油企业等共20家单位成立了原油期货上市推进工作组，协调推进原油期货市场建设工作。目前，有关原油期货上市的部委配套政策已全部出台，交易所各项交易规则、细则已公开征求意见，正在进一步修改完善，其他相关准备工作也正有序推进。我会将密切关注和跟踪国内外原油现货市场和资本市场的发展情况，适时上市原油期货。

**二、**关于建立健全原油期货市场相关法律体系的问题

经过20多年发展，我国期货市场法规制度体系日益完善，但整体效力层级偏低。近年来，在全国人大财经委的直接组织下，期货法立法工作正在稳步推进。为配合期货市场的对外开放，我会于2015年发布了《境外交易者和境外经纪机构从事境内特定品种期货交易管理暂行办法》，规范了特定品种期货交易涉及的开户、运营、结算、保证金收取及存管要求、违约处理、纠纷调解处理等主要业务环节，并规定了对境外交易者、境外经纪机构业务活动的违法违规查处和跨境执法等监督管理职责。下一步，我会将在期货法立法相关工作中，统筹考虑将相关规定纳入其中。

**三、**关于引导多元投资主体共同参与原油期货市场交易的问题

原油期货市场作为国际化的交易平台，应吸引境内外涉油企业、各类金融机构和社会投资者广泛参与，才能逐步发展成为具有国际影响力的定价中心。目前，上海期货交易所国际能源交易中心正大力开展宣传培训，稳步推进境外注册工作，吸引境内外投资者积极参与，丰富原油期货市场的投资群体。

下一步，在原油期货上市时，我会将督促交易所合理制定手续费标准，在确保市场稳定运行的前提下，最大限度降低市场交易成本，吸引境内外投资者广泛参与。从长远来看，我会将通过不断加强基础设施建设、诚信体系建设、规范市场秩序，着力营造良好的市场环境，推动原油期货市场健康发展。
