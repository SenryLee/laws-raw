# 国家煤矿安监局办公室关于开展煤矿水文地质类型统计分析工作的通知

煤安监司函办[2017]16号

各省级煤矿安全监察局：

为摸清全国煤矿水文地质类型划分现状，分析煤矿防治水基础工作存在的问题，加强煤矿防治水工作，国家煤矿安监局决定对全国煤矿水文地质类型最新划分结果进行统计分析。请各省级煤矿安监局结合煤矿全面安全“体检”专项工作，对辖区内所有煤矿水文地质类型进行汇总分析，提出分析报告（主要包括现状、存在的问题、措施及建议），并填写附表，于2017年7月31日前连同电子版一并报送国家煤矿安监局事故调查司。

国家煤矿安监局将适时组织对煤矿水文地质类型划分情况进行抽查。

电子信箱：liufl@chinasafety.gov.cn。
