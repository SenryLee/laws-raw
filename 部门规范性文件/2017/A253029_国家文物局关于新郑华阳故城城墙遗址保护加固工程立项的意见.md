# 国家文物局关于新郑华阳故城城墙遗址保护加固工程立项的意见

## 关于新郑华阳故城城墙遗址保护加固工程立项的意见

办保函〔2017〕527号

河南省文物局：

你局《关于上报新郑华阳故城城垣保护加固工程立项的请示》（豫文物〔2016〕341号）收悉。经研究，我局意见如下：

一、暂不同意新郑华阳故城城墙遗址保护加固工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步核准工程范围。应坚持最小干预原则，严格控制工程范围和规模，不同意对全部城墙进行工程干预，应主要对存在安全稳定问题的城墙段落进行保护加固，已处于稳定状态的城墙应维持现状，避免过度干预。

（二）进一步明确被房屋建筑占压或作为农田使用的遗址区段实施工程的可行性。应在保护规划的指导下，统筹安排城墙本体的保护工作，分步实施。

（三）加强遗址现状勘察和评估，查明病害类型及成因，评估病害对遗址的危害程度和遗址的稳定性，为开展保护工程提供科学依据。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年5月8日
