# 交通运输部关于下达2017年度公路工程行业标准制修订项目计划的通知

交公路函〔2017〕387号

各有关单位：

现将2017年度公路工程行业标准制修订项目计划下达给你们。请各项目承担单位按照《公路工程行业标准制修订管理导则》（JTG A02-2013）和《公路工程标准编写导则》（JTG A04-2013）要求，认真组织开展编制工作，并于2017年6月30日前将2017年新上项目的编制大纲报部。项目经费将按《关于转复2017年交通运输战略规划政策标准规范教育培训类项目支出预算的通知》（财审预函〔2017〕99号）的规定拨付（具体数额详见附件），请严格按照国家和交通运输部有关规定使用。

联系人：部公路局技术管理处 张慧彧

联系电话：010-65292718。

交通运输部

2017年5月22日
