# 国家新闻出版广电总局关于“质量管理2017”辞书、社科和文艺类编校质量不合格出版物的通报

## 关于“质量管理2017”辞书、社科和文艺类编校质量不合格出版物的通报

新广出函〔2017〕242号

各省、自治区、直辖市和新疆生产建设兵团新闻出版广电局，中央军委政治工作部宣传局，中央和国家机关各部委、各民主党派、各人民团体出版单位主管部门，中国出版集团公司，中国教育出版传媒集团有限公司，中国科技出版传媒集团有限公司：

2017年国家新闻出版广电总局（以下简称“总局”）开展了出版物“质量管理2017”专项工作。其中，2017年上半年重点围绕辞书、社科和文艺类出版物进行了编校质量检查。

经检查，共有33种出版物编校质量不合格，涉及25家出版单位。总局依据《出版管理条例》和《图书质量管理规定》对相关出版单位下发了行政处罚决定书，给予警告的行政处罚，并要求相关出版单位在30日内全部收回不合格图书。

各级新闻出版广电行政部门、出版单位主管部门及各出版单位要进一步树立质量观念，强化精品意识，弘扬工匠精神，狠抓质量保障体系等质量管理制度的落实，加大出版物质量管理工作力度，全面提高出版物质量，推出更多精品力作。

附件：“质量管理2017”辞书、社科和文艺类编校质量不合格出版物名单

国家新闻出版广电总局

2017年8月18日
