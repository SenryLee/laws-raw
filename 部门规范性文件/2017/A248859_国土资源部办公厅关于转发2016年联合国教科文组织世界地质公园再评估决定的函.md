# 国土资源部办公厅关于转发2016年联合国教科文组织世界地质公园再评估决定的函

国土资厅函〔2017〕192号

安徽、江西、河南、广东、云南省国土资源主管部门：

2017年1月18日，收到联合国教科文组织世界地质公园秘书处来函（附件1），并转来联合国教科文组织世界地质公园理事会对2016年中国接受重新验证（即再评估）的8个联合国教科文组织世界地质公园再评估的最终决定。

2016年7-8月，联合国教科文组织世界地质公园秘书处组织专家对我国的黄山、龙虎山、三清山、嵩山、云台山、王屋山-黛眉山、丹霞山、石林等8个世界地质公园的建设情况进行了再评估实地考察。9月24-25日，教科文组织世界地质公园理事会在英国里耶维拉世界地质公园举行会议，审议了2016年全球22个世界地质公园的再评估报告及考察情况并确定了再评估最终结果，其中包括我国的8个世界地质公园。

现将联合国教科文组织对我国8个世界地质公园的再评估结果（附件2）和再评估决定函（附件3）转给你们。请督促有关地方人民政府和世界地质公园管理机构，认真研究教科文组织世界地质公园理事会提出的意见和建议，尽快制定整改方案，做好下一评估期世界地质公园建设的相关工作。

2017年2月3日

附件：

1.联合国教科文组织世界地质公园秘书处来函及译文

2.2016年中国世界地质公园再评估结果

3.联合国教科文组织世界地质公园理事会对8个世界地质公园的再评估决定函
