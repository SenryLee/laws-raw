# 中华人民共和国海关总署对十二届全国人大五次会议第3393号建议的答复

贾爱芹等8名代表：

你们提出的《关于将山西方略保税物流中心（B型）升级为国家级综合保税区的建议》（流通、旅游和服务类第3393号）收悉。经认真研究，现答复如下：

设立海关特殊监管区域由国务院审批，海关总署为牵头审核报批和管理部门。根据《国务院关于促进海关特殊监管区域科学发展的指导意见》（国发〔2012〕58号）的精神和要求，新设海关特殊监管区域统一为综合保税区，综合保税区具备保税加工、保税物流和保税服务等功能。设立海关特殊监管区域应符合有利于实施国家区域发展战略规划、有利于中西部地区承接产业转移、有利于海关特殊监管区域整合优化以及确实有外向型大项目亟待进驻的原则，且需符合《海关特殊监管区域设立审核办法》的相关规定。

我署积极支持山西省开放型经济发展和产业转型升级，支持山西省在具备条件的地区设立海关特殊监管区域。建议山西省人民政府及相关部门继续加大对山西方略保税物流中心（B型）发展的支持，首先把保税物流相关政策功能发挥好，同时从产业规划和招商引资着手，逐步引导产业企业向其周边聚集，以大项目落地作为申报设立综合保税区的基础，条件成熟时我署将会同相关部门予以积极支持。

感谢对我们工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2017年6月19日
