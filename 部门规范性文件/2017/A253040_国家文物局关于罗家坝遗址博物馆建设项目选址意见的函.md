# 国家文物局关于罗家坝遗址博物馆建设项目选址意见的函

## 关于罗家坝遗址博物馆建设项目选址意见的函

办保函〔2017〕621号

四川省文物局：

你局《关于在罗家坝遗址建设控制地带建设遗址博物馆的请示》（川文物〔2017〕51号）收悉。经研究，我局意见如下：

一、暂不同意罗家坝遗址博物馆建设项目涉及罗家坝遗址建设控制地带的选址及建设方案。

二、所报方案尚需做以下必要的修改和完善：

（一）补充《罗家坝遗址保护规划》对二类建设控制地带的相关规定及控制性指标。

（二）进一步优化遗址博物馆建筑设计及其周边区域的景观设计，应严格控制建筑规模、体量和高度，并优化外观设计，注意与遗址及其周边环境相协调。同时，应进一步明确罗家坝遗址博物馆的定位，科学确定功能布局，以使用功能为出发点优化建筑设计，做到合理恰当。

（三）开展必要的景观视廊分析，评估遗址博物馆建筑对罗家坝遗址及其周边环境的影响，并提出有针对性的减缓措施。

三、请你局指导建设单位，根据上述意见对所报方案作进一步修改和完善，做好文物影响评估，按程序另行报批。

国家文物局

2017年5月22日
