# 住房城乡建设部建筑市场监管司关于批准2017年第一批建设工程企业资质资格延续的通知

## 关于批准2017年第一批建设工程企业资质资格延续的通知

建市资函[2017]4号

各省、自治区住房城乡建设厅，直辖市建委，北京市规委国土委，新疆生产建设兵团建设局，国务院有关部门建设司（局），有关中央企业：

根据《中华人民共和国建筑法》及有关建设工程类企业资质管理规定，经审核，现批准四川新地平建筑设计咨询有限公司等3家单位工程设计资质延续，杭州江东建设工程项目管理有限公司等2家单位工程监理资质延续，山西和信达招标代理有限公司等7家工程招标代理资格延续。未予批准的单位可登录我部网站（www.mohurd.gov.cn），点击“办事大厅”中“受理发证信息查询”栏目进行查询。

附件：1.工程设计资质延续核准名单

2.工程监理资质延续核准名单

3.工程招标代理机构资格延续核准名单

住房城乡建设部建筑市场监管司

2017年1月17日
