# 国家文物局关于铁瓮城遗址北部山体修整保护工程立项的意见

## 关于铁瓮城遗址北部山体修整保护工程立项的意见

办保函〔2017〕418号

江苏省文物局：

你局《关于审批铁瓮城遗址北部山体修整保护工程立项的请示》（苏文物保〔2016〕335号）收悉。经研究，我局意见如下：

一、不同意铁瓮城遗址北部山体修整保护工程立项。

二、所报工程不属于文物保护工程项目，应作为涉及铁瓮城遗址保护范围的建设项目，做好文物影响评估，按程序另行报批。

国家文物局

2017年4月13日
