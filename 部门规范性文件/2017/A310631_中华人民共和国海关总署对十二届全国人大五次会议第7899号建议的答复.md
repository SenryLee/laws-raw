# 中华人民共和国海关总署对十二届全国人大五次会议第7899号建议的答复

龚敬政代表：

您提出的《关于做好对外开放创新政策研究意见的建议》（发展规划、建设项目和综合经济类第7899号）收悉。经研究，现答复如下：

一、关于推动缅甸政府将木姐口岸升格为国际口岸问题

我署高度重视并积极支持边境少数民族地区口岸发展工作，充分理解地方政府提升口岸开放程度的迫切需求。1997年中缅两国政府签署的《关于中缅边境管理与合作的协定》（以下简称《协定》）明确，双方在中缅边界设置瑞丽—木姐、畹町—九谷、勐定（清水河）—清水河、猴桥—甘败地、打洛—勐拉、章凤—雷基、南伞—果敢、弄岛—南坎等8对口岸，其中，瑞丽—木姐为国际性口岸，允许持有效护照及签证或边境通行证的双方公民，持有效护照及签证或有效国际旅行证件的第三国公民，以及货物通过。据此2001年国务院批准瑞丽口岸扩大对第三国人员开放，由于缅方原因迟迟无法实现。近年来，我署一直通过外交部敦促缅方严格落实《协定》，切实履行瑞丽—木姐国际口岸功能。2017年1月25日，由双方外交部牵头召开的《协定》执行情况第十四轮司局级会晤上，缅方表示：缅方愿就边境口岸开放和管理与中方加强合作。但鉴于当前缅中边境地区安全形势，造成口岸持护照通行等问题迟迟未能落实。缅方将适时实行双方公民在边境口岸持护照通行。

下一步我署将继续配合外交部与缅方进行沟通协商，并做好相关工作。

二、关于批准瑞丽市开展跨境电子商务试点问题

建议云南省政府向国务院主管部门提出申请，并征求相关部门意见后上报国务院批准。我署将根据国务院批复要求，在职责范围内做好相关工作，积极支持跨境电子商务健康、有序发展。

三、关于瑞丽口岸开展转关过境贸易业务问题

转关过境贸易业务属于新出现的一种贸易形式，近期刚刚发生重大走私案件，是否符合现有规定，我署正会同有关部门进行审慎研究。

四、关于批准瑞丽口岸中药材、药品、汽车整车进口指定口岸

一是根据《中华人民共和国药品管理法》规定，药品必须从允许药品进口的口岸进口，并由进口药品的企业向口岸所在地药品监督管理部门登记备案。允许药品进口的口岸由国务院药品监督管理部门会同海关总署提出，报国务院批准。关于批准瑞丽口岸为中药材、药品进口指定口岸问题，我署建议地方政府对照药品进口口岸的原则、标准及评估程序和有关工作要求等，按规定向国务院提出申请。我署将积极配合开展相关考核评估工作。

二是根据《汽车产业发展政策》的有关规定，我国对进口汽车整车实施了限定口岸管理政策，确定了“市场需要、运输便利、严格控制、有效监管”的审批原则，明确相关工作由我署牵头，会同发展改革委、工业和信息化部、商务部研究提出办理意见，上报国务院审批。关于批准瑞丽口岸汽车整车进口指定口岸问题，我署建议地方政府结合政策要求和发展实际，在符合口岸开放基本要求的前提下，开展综合研究和调研论证，按规定向国务院提出申请，我署将根据国务院有关要求，会同有关部门予以统筹研究。

五、关于推进中缅两国口岸管理部门之间信息互认、监管互认、执法互助，实现两国通关监管共同管理的创新模式。

由于缅方原因，中缅边境口岸尚无法实现持护照人员通行，部分口岸还为中方单边管理，因此目前中缅双方在口岸管理方面首要工作是落实《协定》中关于对口岸规定的内容，其次是推动口岸升格和改善口岸设施，然后才是研究口岸管理部门之间实现“三互”、“一口岸多通道”等创新工作。今年初我外交部在中缅《协定》执行情况第十四轮司局级会晤上提出双方要加强口岸合作，探索建立两国口岸主管部门间的合作机制问题，缅方表示愿予积极研究。待中缅国家层面建立口岸合作机制后，我署作为国家口岸主管部门将积极研究推动实现中缅口岸实现创新查验模式等问题。

六、建立中缅两国陆路口岸海关、检疫等口岸管理部门电子数据交换共享平台和“一口岸多通道”通关监管新机制问题

我署积极落实党中央、国务院决策部署，会同公安部、交通运输部、质检总局等相关管理部门推动口岸“三互”大通关建设，依托中央和地方两个层级的电子口岸平台，统筹推进我国“单一窗口”建设。按照《关于国际贸易“单一窗口”建设的框架意见》的总体布局，中央层面依托中国电子口岸平台，以“总对总”方式与各口岸管理和国际贸易相关部门系统对接，实现信息数据互换共享，开展国际合作对接。各地原则上以省（区、市）为单位，依托本地电子口岸建设一个省域“单一窗口”。为避免重复建设，建议中缅两国陆路口岸海关、检疫等口岸管理部门电子数据，依托电子口岸平台实现跨境互换，不再另行建设瑞丽市国际贸易“单一窗口”，以及电子数据交换共享平台。

七、关于增加云南沿边开放口岸数量问题

目前云南省共有经国务院批准对外开放的口岸18个，名列全国第5位，其中航空口岸4个，边境陆路口岸12个，澜沧江流域水运口岸2个。从总量来看云南省口岸数量基本能够满足对外开放的需要，但布局上尚有不尽如人意的地方，特别是中缅边境口岸数量少，功能不全且不能正常发挥。根据我署牵头制定的《国家口岸发展“十三五”规划》，“十三五”期间云南境内的中老、中越口岸开放均按我与毗邻国家达成的协议有序推进，但中缅口岸开放受制于缅甸局势，推进困难。下一步我们将配合外交部推动中缅口岸开放和管理的正常化，一旦缅方在口岸开放方面有所松动，我们将尽快启动国内口岸开放审理的相关程序。

感谢您对我们工作的关心和支持，我们将进一步加强政策宣传，改进监管和服务工作。欢迎您继续对我们的工作提出宝贵意见和建议。

海关总署

2017年7月12日
