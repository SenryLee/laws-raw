# 国家能源局综合司关于印发《生物天然气开发利用县域规划大纲》的通知

国能综新能〔2017〕248号

各省（区、市）发展改革委（能源局），新疆生产建设兵团发展改革委；中石油、中石化、中节能、中广核集团；水电水利规划设计总院，国家发展改革委能源研究所，国家可再生能源中心：

为落实中央财经领导小组第14次会议关于发展生物天然气的要求，推进生物天然气整县开发利用，实现商业化可持续发展，我们组织能源、农业、环保领域的研究机构编制了《生物天然气开发利用县域规划大纲》。现印发你们，请在组织编制县域规划、构建县域分布式开发利用模式、推进生物天然气规模化产业化专业化发展中遵照执行。

附件：生物天然气开发利用县域规划大纲

国家能源局综合司

2017年4月27日
