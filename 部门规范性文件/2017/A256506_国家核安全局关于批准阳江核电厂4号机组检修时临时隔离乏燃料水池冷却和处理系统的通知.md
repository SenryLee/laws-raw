# 国家核安全局关于批准阳江核电厂4号机组检修时临时隔离乏燃料水池冷却和处理系统的通知

## 关于批准阳江核电厂4号机组检修时临时隔离乏燃料水池冷却和处理系统的通知

国核安发〔2017〕245号

阳江核电有限公司：

你公司《关于申请临时停运和部分隔离阳江核电厂4号机组PTR系统循环冷却回路的请示》（广阳江〔2017〕62号）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的要求，我局对你公司提交的申请文件进行了审评，认为你公司阳江核电厂4号机组功率运行模式下临时隔离乏燃料水池冷却和处理系统进行管道与管座焊缝缺陷检修的申请是可以接受的，现予批准。

你公司应认真落实申请的各项承诺，做好安全风险预防和管理措施，确保阳江核电厂运行安全。

国家核安全局

2017年10月11日
