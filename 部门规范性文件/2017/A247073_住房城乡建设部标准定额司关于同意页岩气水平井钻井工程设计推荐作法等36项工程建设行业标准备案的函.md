# 住房城乡建设部标准定额司关于同意页岩气水平井钻井工程设计推荐作法等36项工程建设行业标准备案的函

建标实函[2017]37号

国家能源局综合司：

《国家能源局关于报送<页岩气水平井钻井工程设计推荐作法>等78项能源行业工程建设标准备案信息的函》（国能综科技[2016]901号）收悉。经研究，同意《页岩气水平井钻井工程设计推荐作法》等36项行业标准作为“中华人民共和国工程建设行业标准”备案（见附件）。

中华人民共和国住房和城乡建设部标准定额司

2017年2月3日
