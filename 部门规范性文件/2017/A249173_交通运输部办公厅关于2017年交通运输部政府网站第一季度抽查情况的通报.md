# 交通运输部办公厅关于2017年交通运输部政府网站第一季度抽查情况的通报

交办科技函〔2017〕457号

长江航务管理局、珠江航务管理局、部海事局，部内各司局：

按照《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）和《国务院办公厅秘书局关于2016年第四次全国政府网站抽查情况的通报》（国办秘函〔2017〕5号）有关要求，我部组织开展了2017年交通运输部政府网站第一季度抽查工作。现将有关情况通报如下：

一、抽查总体情况

2017年3月8日至3月15日，我部对13个政府网站进行了抽查，大部分网站信息内容建设情况较好，与上一季度抽查情况相比，“僵尸”、“睡眠”等现象有所减少，在公众服务方面有一定进步。哈尔滨海事党建网站由于各栏目长期未更新，判定为不合格网站；丹东海事局、东疆海事局网站监测周期内无法访问，判定为不合格网站。以上不合格网站按照集约化建设要求，已提出永久关停申请。

二、存在问题

在抽查工作开展的过程中发现，个别基层网站存在动态信息更新不及时、部门文件发布不全面、维护运行不到位的情况。网站办事服务实用性需进一步完善，网站办事指南要素类别不完整，个别办事指南中缺失“办事流程”和“联系电话”两类要素，部分网站的在线申报和查询系统不能正常访问。在网站开展的在线访谈、征集调查类活动较少，部分网站的咨询类栏目不显示有效信件或留言。

三、下一步工作

下一步我部将大力推进网站集约化建设，加快推动海事系统同质同类网站整合，大幅减少海事分支机构网站数量，降低网络安全风险。在开展集约化建设的过程中，要求各单位严格按照政府网站关停标准和程序进行，及时通过全国政府网站信息报送系统更新相关信息。同时，继续组织开展政府网站日常监测工作，及时发现和解决存在的问题。
