# 农业部十二届全国人大五次会议第2630号建议答复摘要

## 十二届全国人大五次会议第2630号建议答复摘要

农业产业化是我国农业经营体制机制的创新，是现代农业发展的方向。龙头企业是构建现代农业产业体系的重要主体，是推进农业产业化经营的关键。多年来，中央一直高度重视农业产业化龙头企业发展，要求采取有效措施，加大扶持力度。

按照中央要求，农业部会同有关部门，支持龙头企业围绕产业整体开发，促进农业产业链条延伸，强化产前、产中、产后衔接，密切生产、加工、销售等各环节连接，提高产加销一条龙、贸工农一体化程度。一方面，坚持把加强原料生产基地建设作为提升农业产业化经营水平的基础支撑来抓，明确要求各地结合优势农产品区域布局，以及龙头企业和消费市场的需求，建设专业化、标准化的原料生产基地；支持龙头企业加大技术投入力度，提高精深加工能力和水平，延伸拓展产业链条；引导大型连锁超市与农民合作社、龙头企业等直接对接，建立长期、稳定的购销关系，支持龙头企业建设配送中心、冷链物流等农产品流通基础设施，提高企业农产品贮藏、加工、运输和配送能力。通过以奖代补的方式支持龙头企业为农户提供贷款担保，带动农户发展规模化、标准化、专业化和集约化原料基地，参与农业全产业链发展。2014—2016年，共支持85家龙头企业为农户提供贷款担保，贷款总额超过61亿元。另一方面，依托当地优势产业，以各类农业园区为载体，以龙头企业为核心，吸引产业链上下游企业集群集聚发展，优化配置各类资源要素，创建一批主导产业链条完整、产品和产业附加值较高的国家农业产业化示范基地。目前，共认定了3批209个国家农业产业化示范基地，集聚各类龙头企业9000余家，年销售收入超过1.7万亿元，辐射带动2000多万农户。今年，农业部启动了农业产业化示范基地提质行动，提出了运行监测优胜劣汰、典型模式总结推介、创新完善跟进提升等方面的工作措施，并要求各级农业主管部门在政策创设、项目支持和宣传推介等方面，加大对农业产业化示范基地的支持力度。

财政部发挥农业综合开发对农业产业化的支持、推动作用，大力扶持农业区域优势特色产业，按照“缺什么补什么，什么弱扶什么”的原则，对各地农业综合开发优势特色产业规划确定的农业产业及产业链中的关键、薄弱环节进行重点支持、连续扶持，大力推进产业结构调整，实现全产业链开发。2016年，农业综合开发通过贷款贴息、财政补助等方式，投入中央财政资金约36亿元支持龙头企业，围绕蔬菜、粮食、果品、花卉林木、畜禽、饮料、中药材等产业发展的关键环节，建设了一批区域优势特色明显、示范带动作用强的种植养殖基地、农产品加工、流通服务设施等项目，推动了这些特色产业的全产业链开发。

商务部积极推动农产品流通基础设施建设，2014—2015年，会同财政部支持山西、内蒙古、安徽等15个省（区）开展跨区域农产品流通基础设施建设，重点支持产地集配中心、农产品交易仓储和冷链物流集散中心等设施建设。2016年，会同财政部支持山东、河南等10个省（区）发展冷链物流，重点推进冷链物流标准化和信息化体系建设，强化硬件支撑，创新运营模式，加强专业技术技能培训，提高冷链物流从业人员素质，解决“冷链不冷”和“断链”等问题，全面提升我国农产品冷链流通发展水平，夯实农业全产业链发展的基础和支撑。

下一步，农业部将继续会同相关部门，大力推进农业供给侧结构性改革，支持和引导龙头企业延长产业链、提升价值链、共享利益链，打造集种养殖、冷链物流、精深加工、品牌营销等多环节于一体的全产业链和全流通体系，推动传统农业向现代农业转型升级。

农业部
