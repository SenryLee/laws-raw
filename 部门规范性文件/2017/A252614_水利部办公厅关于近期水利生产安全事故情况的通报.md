# 水利部办公厅关于近期水利生产安全事故情况的通报

办安监函〔2017〕467号

各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局，部直属各单位：

今年以来，各地区各单位按照我部统一部署，紧密结合当地实际认真组织开展安全生产各项工作，水利安全生产保持平稳态势。但是，近期水利行业仍在个别领域接连发生事故：2017年2月17日，湖南省张家界市慈利县长峪水电开发有限公司在更换冷却水泵和清污过程中，违反操作规程一次性打开放水闸门，未提前报告当地镇政府，导致下游3位正在河边洗衣服的村民被冲走，造成2人死亡；2017年4月24日，湖南省怀化市洪江市群峰乡杨柳电站增效扩容改造项目清理隧道废渣时发生塌方，造成1人死亡。目前，2起事故正在由当地政府调查处理。同一工程类型在同一地区接连发生事故，给人民生命财产造成严重损失，造成较大的负面影响，暴露出一些重点领域主体责任不落实、监管不力等问题。按照“管行业必须管安全”的要求，为深刻吸取事故教训，举一反三，进一步强化水利安全生产监督管理，现将2起事故通报全国，就进一步加强水利安全生产工作提出以下要求。

一、提高认识，强化责任落实。各地区各单位要深刻认识做好安全生产工作的紧迫性和重要性，充分认识当前水利安全生产面临的严峻形势，强化红线意识和底线思维，克服麻痹思想和侥幸心理，坚决防止由于认不清、想不到、抓不实、管不严导致风险、隐患蜕变成生产安全事故。要切实履行各级水行政主管部门的安全监管职责，采取有效监管手段和措施，从水利工程建设和运行的各个环节强化监管。要落实水利生产经营单位和水利工程建设项目法人等各参建方的主体责任，健全机构，配足监管人员，细化安全措施，将安全责任落实到每个环节、个人和岗位，严格执行操作规程的相关规定。

二、进一步加大监督执法力度，切实做好事故隐患排查治理。各地区各单位要深刻汲取事故教训，进一步强化水行政主管部门安全监管责任，建立健全水利安全生产执法机制，综合运用安全监督工作考核、安全生产巡查、联合检查等措施，切实解决本地区本单位安全生产突出问题，严防各类安全事故。要按照《水利部办公厅关于做好汛期水利安全生产工作的通知》（办安监〔2017〕63号）、《水利部办公厅关于开展2017年度重大水利工程建设安全生产巡查的通知》（办安监函〔2017〕439号）和《水利部办公厅关于加强水利行业涉及危险化学品安全综合治理的通知》（办安监函〔2017〕358号）的要求，落实水利生产经营单位安全生产主体责任，做到隐患排查不留盲区和死角，杜绝零隐患。对排查出的安全隐患，要立即整改；对于不具备条件难以立即整改的，要做到隐患整改责任、措施、资金、时限、预案“五落实”，必要时，要停工停产，确保安全。

三、突出做好农村水电等重点领域安全生产工作。各级水行政主管部门要按照有关规定督促农村水电站建设和运行管理单位进一步强化主体责任落实，建立健全生产安全管理规章制度，落实安全措施，保障安全投入，加强安全培训。完善水库调度和工程检修泄水通报机制，定期开展应急演练。加强对隧洞工程施工检查，重点检查参建各方是否按照有关规程规范，以安全为核心做好施工组织管理。其他领域也要举一反三，引以为戒，扎实抓好安全生产各项工作。

四、严格事故信息报送和查处。各地区各单位要严格按照《水利安全生产信息报告和处置规则》（水安监〔2016〕220号）做好事故信息报告工作，不得迟报、瞒报和漏报。要按照“四不放过”和“科学严谨、依法依规、实事求是、注重实效”原则，督促各类安全事故的查处进度，严格执行生产安全事故行政问责制度，依法严肃追究事故责任单位和有关责任人的责任，落实事故防范和整改措施，坚决防止类似事故再次发生。

水利部办公厅
