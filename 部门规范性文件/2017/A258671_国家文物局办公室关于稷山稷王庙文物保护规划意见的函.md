# 国家文物局办公室关于稷山稷王庙文物保护规划意见的函

办保函〔2017〕1364号

山西省文物局：

你局《关于审批稷山稷王庙文物保护规划的请示》（晋文物〔2017〕170号）收悉。经研究，我局意见如下：

一、所报规划目标不清，保护区划不合理，体例和内容不符合《全国重点文物保护单位保护规划编制要求》，我局暂不同意所报稷山稷王庙规划。

二、所报规划应做以下必要修改和完善：

（一）进一步补充和深化价值评估内容，理顺科学价值、文化价值等表述并提高逻辑性、准确性。补充文物依存环境内的非文物建筑评估，应包含建筑名称、建设时间、数量、形制、体量、高度、功能等及对文物的具体影响评估。调整专项评估分类，如基础设施与防护设施等均应单独评估。在此基础上，重新制定规划的各项相关整治措施。

（二）进一步论证调整保护区划的必要性和可行性，明确和细化保护区划内的管理规定。建议调整保护范围的东侧界划，建设控制地带的南、北界划，确保可操作性。并在此基础上，对用地调整作出合理规划。

（三）进一步深化明确展示利用目标，梳理展示利用内容，加强展示方式和手段的研究，应结合庙内建筑特色，重点突出稷王农耕文化、祭祀仪式等。

三、请你局指导相关单位，按照上述意见对规划进行认真修改、完善，按相关程序另行报批。

国家文物局办公室

2017年12月13日
