# 国家文物局办公室关于在白台寺保护范围和建设控制地带内进行文物保护设施建设项目的意见

办保函〔2017〕911号

山西省文物局：

你局《关于审批新绛县白台寺抢救性文物保护设施建设项目设计方案的请示》（晋文物〔2017〕126号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位白台寺保护范围和建设控制地带内，设计依据不足，文本深度不够，我局暂不同意该项目。

二、对所报方案提出以下修改意见：

（一）从白台寺保护管理的实际需要出发，进一步论证文物保护设施建设项目的必要性和可行性，明确新建项目选址的科学性及对寺庙原有格局、文物环境的影响。补充山西省人民政府关于白台寺保护范围和建设控制地带的管理规定、具体控制要求和工程设计依据。

（二）深化方案设计内容，拟建设施应在满足功能需求前提下，尽量缩减建筑规模、体量，建筑形式应采用当地传统结构做法。围墙形式建议采用半通透式，并补充大门方案设计，风格尽量简洁、大方，与周边环境风貌相协调。适当减少院墙以内地面硬化及铺装范围，合理配置绿化，避免寺院环境过度人工化。

（三）补充文物影响评估报告，客观、准确论证拟建项目对文物本体和环境风貌的影响，科学研提方案调整建议。

（四）防雷工程不宜纳入本次工程范围，应按程序另行报批。

（五）应进一步规范文本与图纸，明确标注院落地面排水走向及出口位置。

三、请你局组织相关单位根据所提意见，对项目方案进行修改完善后，按程序另行报批。督促地方人民政府尽快组织编制《白台寺保护规划》，统筹考虑文物保护、环境整治、展示利用等工作，切实加强日常管理、巡查与岁修工作，确保文物本体与周边环境安全。

专此。

国家文物局办公室

2017年8月4日
