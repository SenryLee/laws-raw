# 国家文物局关于南汉二陵——康陵保护性设施建设工程设计方案的意见

## 关于南汉二陵——康陵保护性设施建设工程设计方案的意见

办保函〔2017〕482号

广东省文物局：

你局《关于全国重点文物保护单位南汉二陵—康陵保护设施建设工程设计方案的请示》（粤文物审〔2017〕3号）收悉。经研究，我局意见如下：

一、暂不同意南汉二陵—康陵保护性设施建设工程设计方案。

二、所报方案应做以下必要的修改和完善：

（一）补充保护规划中关于康陵保护展示的相关要求，合理确定保护性设施的设计原则和目标定位。

（二）进一步调整保护棚设计，严格控制建筑体量和高度，建筑外观形式不宜参考唐宋宫殿建筑形式，应简洁消隐，避免影响陵园的空间布局与陵墓礼制秩序，并应与南汉二陵博物馆相区别。建议进一步优化设计思路，开展不同的设计方案进行比选。

（三）应充分考虑当地气候特点，合理设计设施内部空间，避免造成室内环境控制方面的低效浪费。

（四）进一步细化墓室地下水防治的具体设计，做好保护性设施建设工程与康陵本体保护工程的衔接，补充保护性设施建设过程中文物的临时性保护措施。

（五）进一步校核工程预算，科学编制预算，严格控制建设成本，并充分考虑后续维护成本。

三、请你局指导方案设计单位联合专业考古研究单位，按照上述意见对方案进行修改和完善，并按程序另行报批。

国家文物局

2017年4月21日
