# 中华人民共和国海关总署对十二届全国人大五次会议第6790号建议的答复

冯云乔代表：

您提出的《关于加大中部地区保税物流中心建设力度的建议》（发展规划、建设项目和综合经济类第6790号）收悉。经认真研究并商交通运输部和中国铁路总公司，现答复如下：

一、海关总署认真贯彻落实中央决策部署，积极支持中部地区开放型经济的发展。为进一步推动加工贸易转型升级，改善投资环境，加快推进国家区域经济发展战略的实施，促进中西部地区承接产业转移，我署商财政部、税务总局、外汇局为包括湖北省在内的中西部地区部分省（自治区、直辖市）增加了保税物流中心（B型）规划指标，支持其在具备条件的地区增设保税物流中心（B型）。同时，我署积极创新海关监管机制，转变职能实现方式，研究制定了《海关总署关于支持和促进中国（湖北）自由贸易试验区建设发展的若干措施》，支持湖北省以自贸试验区建设发展为契机，不断优化产业结构、加快产业转型升级，更加主动有效地承接长三角、珠三角、环渤海等地区高技术含量、高附加值的加工贸易转移，加快形成江汉平原地区加工贸易产业集群，带动中部地区成为我国加工贸易梯度转移的重要承接地。

二、海关总署积极支持内陆地区开展区域性口岸发展规划的研究工作，请地方政府根据海关总署2016年下发的《国家口岸发展“十三五”规划》，结合当地外向型经济发展的需求，充分听取湖北省相关部门和驻鄂查验单位的意见，研究提出本地区口岸规划。如需国家口岸主管部门支持可按程序提出，我署将予以解答和指导。

三、为贯彻落实党中央、国务院关于我国国际贸易“单一窗口”（简称“单一窗口”）建设的一系列决策部署，海关总署按照《关于国际贸易“单一窗口”建设的框架意见》要求，积极推进“单一窗口”标准版制定推广和标准体系建设。目前，“单一窗口”标准版已在天津、重庆、浙江（含宁波）、福建、陕西、广东等地区开展试点。下一步我署将积极指导和支持湖北省，依托本地电子口岸平台，在省域内口岸推广应用“单一窗口”标准版，并结合口岸通关业务需求，打通物流信息节点，拓展特色服务功能，推动仙桃保税物流中心建设发展。

四、根据交通运输部《水运“十三五”发展规划》，汉江作为长江支流高等级航道，是内河水运“十三五”建设重点，交通运输部将着重进行航道升级改造和港口码头建设，为仙桃保税物流中心等中部地区保税物流中心建设提供交通基础设施保障。

五、江汉平原货运铁路是由地方为主、路地联合推进的铁路建设项目，包括天门至仙桃铁路支线、潜江铁路支线及仙桃至监利铁路支线。目前，天门至仙桃铁路支线、潜江铁路支线已开工建设，预计2018年建成运营，仙桃至监利铁路支线地方政府正在开展前期工作，中国铁路总公司将加强与地方政府的协调，争取早日开工建设。江汉平原货运铁路建成投产后，对促进保税物流中心以及地区经济社会发展将发挥重要作用。

感谢对我们工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2017年6月21日
