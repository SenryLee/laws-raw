# 工业和信息化部办公厅关于报送中国软件名城创建进展情况总结的通知

工厅信软〔2017〕499号

中国软件名城及创建城市工业和信息化主管部门：

为贯彻落实《中国软件名城创建管理办法（试行）》（工信部信软〔2017〕11号），我部将对中国软件名城创建进展情况进行梳理总结，着力摸清现状、总结经验、加强交流。现就有关事项通知如下：

一、请中国软件名城及创建城市对2012-2016年中国软件名城创建、发展提升的进展及成效进行系统梳理和总结。

二、请中国软件名城及创建城市于2017年7月10日前将2012-2016年中国软件名城创建工作总结（含附表）以机要交换或EMS邮寄方式报送我部（信息化和软件服务业司），并将电子版发送至联系人邮箱。

三、2012-2016年中国软件名城创建工作总结（提纲）及附表电子版可从我部（信息化和软件服务业司）网站下载。

四、中国软件名城及创建城市要按照打造综合型、特色型软件名城的不同定位和不同创建阶段的具体工作要求，集聚资源、加大投入，继续做好中国软件名城创建工作。
