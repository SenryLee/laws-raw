# 公开市场业务交易公告[2017]第62号——关于4月1日不开展公开市场操作的公告

## 公开市场业务交易公告

[2017]第62号

目前银行体系流动性总量处于较高水平，4月1日不开展公开市场操作。

中国人民银行公开市场业务操作室

二〇一七年四月一日
