# 住房城乡建设部标准定额司关于商请组织填报《有轨电车工程项目建设标准》编制调研问卷的函

建标综函〔2017〕190号

有关省、自治区住房城乡建设厅、发展改革委，直辖市建委、规划局（委）、发展改革委，新疆生产建设兵团建设局、发展改革委，有关单位：

根据我部和国家发展改革委关于2015年建设标准编制项目计划的要求，由广州地铁设计研究院有限公司组织开展《有轨电车工程项目建设标准》编制工作。为做好建设标准编制工作，主编单位拟定了调研问卷，并拟实地调研部分城市有轨电车规划、设计、建设、运营情况，请予支持。

一、填报范围

有关省、自治区、直辖市住房城乡建设、发展改革部门；各地有轨电车运营公司；有关工程设计院。

二、填报方式

请填报调研问卷的单位和人员，在住房城乡建设部网站首页的标准定额栏目下载调研问卷电子版，按照问卷类别分别填写，并请于2017年10月20日前将填报的调研问卷电子版发送主编单位。

三、其他事项

1.本次问卷调研的目的是客观、全面了解各地有轨电车规划、设计、建设和运营情况，仅用于建设标准编制工作。

2.填写调研问卷过程中有任何疑问，请及时与主编单位联系。
