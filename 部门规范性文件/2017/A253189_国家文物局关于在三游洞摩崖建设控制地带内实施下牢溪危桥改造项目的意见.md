# 国家文物局关于在三游洞摩崖建设控制地带内实施下牢溪危桥改造项目的意见

## 关于在三游洞摩崖建设控制地带内实施下牢溪危桥改造项目的意见

办保函〔2017〕873号

湖北省文物局：

你局《关于报送下牢溪危桥改造工程设计方案（修改稿）的请示》（鄂文物〔2017〕13号）收悉。经研究，我局意见如下：

一、所报方案（修改稿）取消方案二的理由不充分，在全国重点文物保护单位三游洞摩崖建设控制地带内进行下牢溪桥重建扩建、桥梁选型的必要性和设计依据不足，我局暂不同意下牢溪危桥改造工程。

二、请你局指导有关单位进一步论证工程实施的必要性和可行性，补充道路升级对文物本体及环境的影响评估，进一步说明方案调整的理由，对方案进行修改完善，经你局审核后按程序另行报批。

专此函复。

国家文物局

2017年7月24日
