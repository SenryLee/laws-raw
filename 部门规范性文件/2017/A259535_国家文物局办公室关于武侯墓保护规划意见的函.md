# 国家文物局办公室关于武侯墓保护规划意见的函

办保函〔2017〕1421号

陕西省文物局：

你局《关于呈报武侯墓保护规划的请示》（陕文物字〔2017〕5号）收悉。经研究，我局意见如下：

一、暂不同意武侯墓保护规划。

二、对该规划提出以下修改意见：

（一）加强历史研究，明确武侯墓的选址特征和历史格局，开展武侯墓与定军山之间的视线分析，以及武侯墓与武侯祠等附属建筑的空间和历史关系，并据此确定规划重点。

（二）进一步明确保护对象，梳理文物构成清单，分析历史环境要素。当代题刻、楹联等不应纳入文物本体。

（三）合理调整保护区划，依法完善管理规定，细化控制指标，明确建设控制地带的具体高度要求；保护范围内不应新建与文物保护无关的建构筑物，建议将停车场调整至建设控制地带。

（四）坚持最小干预原则，合理确定武侯墓保护工程级别。根据环境评估结论，依法加强保护区划内现有建构筑物的环境整治措施。完善展示利用规划，明确展示主题，取消与文物展示无关的商业性设施建设项目。

（五）加强与风景名胜区规划等相关规划的衔接。

（六）进一步规范完善文字和图纸。

三、请你局指导相关单位，按照上述意见对所报保护规划进行修改、完善，按相关程序另行报批。

国家文物局办公室

2017年12月26日
