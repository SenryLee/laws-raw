# 国土资源部办公厅关于暂停用于国土资源部备案的矿产资源储量评审业务的函

国土资厅函〔2017〕362号

北京中矿联咨询中心：

根据国家审计署《国土资源部2016年第四季度贯彻落实国家重大政策措施跟踪审计发现问题整改函》（审资源函〔2016〕11号）意见，经研究决定，你单位开展的用于国土资源部备案的矿产资源储量评审工作暂停。

2017年3月7日
