# 国家林业局办公室关于推介一批冰雪旅游典型单位的通知

办场字〔2017〕112号

各省、自治区、直辖市林业厅（局），内蒙古、吉林、龙江、大兴安岭森工（林业）集团公司，新疆生产建设兵团林业局，国家林业局各司局、各直属单位：

发展冰雪旅游在推动我国北方地区特别是重点国有林区的森林旅游发展中具有特殊意义，是践行“绿水青山就是金山银山，冰天雪地也是金山银山”重要思想的重要途径之一。

经过摸底调查，最近几年，一些森林旅游地在推动冰雪旅游发展中做出了很大努力，取得了明显成效。它们的冰雪旅游基础服务设施较完善、产品特色较鲜明、发展思路较清晰、社会认可度较高，具有可复制性和可推广性，为此，特从中推介一批典型单位（见附件），供各地了解学习参考借鉴。

希望具有发展冰雪旅游潜力的地区借鉴这些单位的典型经验，在保护好森林、湿地和野生动植物资源的前提下，充分发挥冰雪资源优势，更好地推动森林旅游发展。

特此通知。
