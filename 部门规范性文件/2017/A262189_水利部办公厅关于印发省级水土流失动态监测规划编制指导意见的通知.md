# 水利部办公厅关于印发省级水土流失动态监测规划编制指导意见的通知

办水保〔2017〕160号

各省、自治区、直辖市水利(水务)厅(局),各计划单列市水利(水务)局,新疆生产建设兵团水利局:

根据《水利部关于加强水土保持监测工作的通知》(水保〔2017〕36号)和《水利部办公厅关于开展2017年度水土保持三项重点任务考核工作的通知》(办水保函〔2017〕582号),为明确省级水土流失动态监测区城范围和主要任务,确保全国水土流失动态监测工作上下协同有序开展,水利部水土保持司组织编制了《省级水土流失动态监测规划编制指导意见》,现印发给你们。请各省结合实际,抓紧规划编制并按程序印发,要依据规划将水土流失动态监测所需经费纳入年度预算,做好省级水土流失动态监测规划实施工作。

水利部办公厅

2017年10月31日

附件：省级水土流失动态监测规划编制指导意见
