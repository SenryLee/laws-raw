# 国家文物局关于孙家城遗址防护工程立项的意见

## 关于孙家城遗址防护工程立项的意见

办保函〔2017〕258号

安徽省文物局：

你局《关于请求批准〈孙家城遗址防护工程立项报告〉的请示》（皖文物保〔2016〕173号）收悉。经研究，我局意见如下：

一、暂不同意孙家城遗址防护工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步明确遗址北部及东北部实施的护岸、护坡、排水沟整治工程的必要性及可行性，说明河道清淤的必要性，应尽可能减小干预，根据现状勘察结果合理确定工程内容和实施范围。

（二）加强现状勘察和评估，补充大沙河水文监测资料，确定洪水重现期及相应的洪水量、冲刷深度等，并委托专业部门对该工程的文物影响情况做出客观评估，确保文物本体安全。

（三）立项所报界桩工程已于2012年实施完成，应予核减。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年3月15日
