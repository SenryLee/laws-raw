# 国家核安全局关于同意变更东方阿海珐核泵有限责任公司民用核安全设备设计和制造部分许可证条件的复函

## 关于同意变更东方阿海珐核泵有限责任公司民用核安全设备设计和制造部分许可证条件的复函

国核安函[2017]38号

东方阿海珐核泵有限责任公司：

你公司《关于关闭制造许可证技术转让时间节点的申请》（ADJV函（2016）01号文）和《关于关闭设计许可证轴密封设计技术转让时间节点的申请》（ADJV函（2016）08号文）收悉。经审查，我局认为你公司已完成主泵“静压型轴密封设计”和“叶轮制造”两项技术转让，同意你公司关于变更民用核安全设备设计和制造许可证（国核安证字S（12）11号、国核安证字Z（14）07号）中相应许可证条件的申请。

你公司应继续加强主泵技术引进、消化和吸收，尽快完成动压型轴密封设计技术的转让。同时，完善质量保证体系，加强过程控制，确保主泵设计和制造质量。

特此函复。

国家核安全局

2017年4月14日
