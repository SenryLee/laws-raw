# 国家文物局关于在杜甫草堂建设控制地带内进行成都市青少年培训基地建设项目的意见

文物保函〔2017〕1482号

四川省文物局：

你局《关于报送〈成都市青少年培训基地建设项目建筑规划方案设计〉的请示》（川文物〔2017〕78号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位杜甫草堂建设控制地带内进行成都市青少年培训基地建设项目和你局意见。

二、对所报项目提出以下修改完善意见：

（一）应严格遵守《杜甫草堂文物保护规划》关于杜甫草堂建设控制地带的管理要求，建筑高度控制在3层以下；建筑体量、外观应与杜甫草堂文物建筑相协调；同时，应考虑建筑用途与安全问题，按照规划管理要求进一步降低建筑密度、增大疏散空间。

（二）适当增加绿化遮挡设计，降低建设项目对文物的景观影响。

（三）应充分考虑建设施工对文物安全的影响，制定必要的文物保护措施和应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十八条的规定报相关部门批准。施工中应加强监管，确保文物安全。

专此函复。

国家文物局

2017年8月21日
