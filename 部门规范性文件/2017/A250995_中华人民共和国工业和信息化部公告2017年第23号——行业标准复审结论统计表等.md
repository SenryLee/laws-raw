# 中华人民共和国工业和信息化部公告2017年第23号——行业标准复审结论统计表等

## 中华人民共和国工业和信息化部公告

2017年第23号

按照我部推荐性行业标准集中复审工作的安排，现已完成28726项推荐性行业标准的复审工作（复审结论统计表见附件1，各行业或领域复审结论表见附件2-7），其中《带压密封技术规范》等20466项行业标准继续有效，《镁钢制品绝热工程施工技术规范》等5511项行业标准予以修订，《化工蒸汽系统设计规定》等2749项行业标准自本公告发布之日起废止。

特此公告。

附件：1. 行业标准复审结论统计表

2. 工程建设、节能与综合利用和安全生产领域行业标准复审结论表

3. 原材料（化工、建材、钢铁、有色金属、稀土、黄金）行业标准复审结论表

4. 装备（机械、汽车、船舶、航空）行业标准复审结论表

5. 消费品（轻工、纺织、包装）行业标准复审结论表

6. 兵工民品和核工业行业标准复审结论表

7. 电子和通信行业标准复审结论表

工业和信息化部

2017年5月12日
