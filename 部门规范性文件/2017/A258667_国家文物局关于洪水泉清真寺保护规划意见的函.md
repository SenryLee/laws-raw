# 国家文物局关于洪水泉清真寺保护规划意见的函

文物保函〔2017〕1953号

青海省文物管理局：

你局《关于洪水泉清真寺文物保护规划的请示》（青文物局〔2017〕157号）收悉。经研究，我局意见如下：

一、原则同意所报洪水泉清真寺保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定

应在梳理历史环境内容的基础上，进一步厘清文物构成和保护对象，建筑遗址不宜纳入文物建筑。

（二）关于价值评估和现状评估

1. 深化价值评估，科学、全面评价洪水泉清真寺在地方民间信仰中的历史见证和文化载体意义。深入分析寺院格局演变与周边村落及历史街巷的关系，深入发掘文物历史价值。

2. 完善现状评估，客观评价文物建筑保存现状。细化环境评估内容，分析文物选址与周边山体自然景观的关系、周边村落建筑环境对文物本体的影响。补充说明宗教信仰传承和民俗活动延续情况。

（三）关于保护区划和管理规定

1. 应根据现状评估结论和文物保护管理需要，科学调整保护区划及具体边界，增强可操作性。进一步论证将周边道路及后期加建建筑纳入保护范围的科学性和必要性。

2. 梳理和完善保护区划管理规定，建设控制地带内新建建筑高度控制要求应与传统村落高度控制要求一致，补充高度调整依据。

（四）关于保护措施针对现状评估结论，研提文物保护对策，增强针对性与可操作性。不宜机械套用文物保护工程类型。

（五）关于环境整治和专项评估

1. 应根据文物保护和民生改善需要，进一步明确环境整治对象，提出具体措施要求，有效引导村落发展建设，增强可操作性。进一步论证清真寺东南方向台地下民居拆迁和对所有非文物建筑进行外立面整治的必要性和可行性。

2. 应结合文物保护、旅游发展和宗教活动使用需求，统筹考虑洪水泉清真寺展示利用的整体定位，进一步明确展示目标、内容和重点。

3. 深化管理规划，明确文物部门与宗教部门之间的责权关系，制定具体管理措施，妥善处理文物保护与宗教活动之间的关系。

（六）补充所报规划与历史文化名村保护规划、土地利用规划等相关规划的衔接内容。

（七）进一步规范文本和图纸。补充土地利用协调规划图、道路交通调整规划图、管理规划图等相关图纸。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的洪水泉清真寺保护规划报请青海省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体计划或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好洪水泉清真寺的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月7日
