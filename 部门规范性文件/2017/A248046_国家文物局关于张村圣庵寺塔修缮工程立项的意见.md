# 国家文物局关于张村圣庵寺塔修缮工程立项的意见

## 关于张村圣庵寺塔修缮工程立项的意见

办保函〔2017〕180号

山西省文物局：

你局《关于申请临猗县张村圣庵寺塔修缮工程立项的请示》（晋文物〔2017〕1号）收悉。经研究，我局意见如下：

一、暂不同意张村圣庵寺塔修缮工程立项。

二、所报工程立项须从以下方面进行修改完善：

（一）加强塔体基础及周边地质条件勘察，进一步明确文物保存现状、残损情况等，说明塔体倾斜状况、倾斜原因和发展趋势，深入分析塔体结构受力，科学评估塔体稳定性，在此基础上制定有针对性的修缮措施。

（二）应深入研究和分析地方建造工艺、传统做法、建筑材料和构造特征等，注意在维修中使用原工艺和原材料。

（三）坚持最小干预原则，以塔体现状整修加固为主，最大程度地保留文物建筑历史信息。应使用传统材料粘接风化酥碱塔砖；补充塔顶修复依据，并做好顶部防水处理；进一步论证使用钢筋锚杆植筋拉结新旧砌体的必要性，避免过度干预。

三、请你局指导项目单位根据上述意见对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此。

国家文物局

2017年2月24日
