# 农业部对十二届全国人大五次会议第3735号建议的答复

## 对十二届全国人大五次会议第3735号建议的答复

农办议〔2017〕57号

丽娜代表：

您提出的关于将塔城地区列入国家休闲观光农业示范区的建议收悉。经商发展改革委、财政部,现答复如下。

休闲农业是贯穿农村一二三产业，融合生产、生活和生态功能，紧密连结农业生产、农产品加工业、服务业的新型产业形态和新型消费业态。近年来，按照党中央国务院决策部署，农业部高度重视休闲农业发展，不断加强统筹规划，强化政策指导，提升公共服务，注重科学推动。在各有关部门和地方政府的共同推动下，休闲农业产业布局不断优化、发展质量不断提升、功能领域不断拓展，成为经济发展新业态、新亮点，成为推动农业供给侧结构性改革的重要力量，成为带动农民就业增收和产业脱贫的重要途径。

农业部坚持以品牌培育和示范创建作为重要手段，重点打造休闲农业和乡村旅游品牌体系，在全国树立了一批标杆，培育了一批品牌。截至目前，共创建全国休闲农业和乡村旅游示范县328个，包括新疆维吾尔自治区的10个示范县（市、区），成为带动各地休闲农业和乡村旅游发展的典范。为贯彻落实国家推动休闲农业和乡村旅游发展的政策精神，以全国休闲农业和乡村旅游示范县为载体，各部门不断加大支持力度。2016年，农业部会同发展改革委、财政部等14部门印发《关于大力发展休闲农业的指导意见》（农加发〔2016〕3号），提出7项主要任务和4项扶持保障政策。2015年，中央财政启动农村一二三产业融合发展试点，支持符合条件的休闲农业项目，开发和拓展农业多种功能，2017年进一步加强项目的扶持力度。2016年发展改革委利用专项建设基金，对包括休闲观光农业在内的农村一二三产业融合项目给予了积极支持。此外，中央财政还设立了旅游发展基金，重点扶持中西部地区旅游公共服务设施建设和新业态发展，同时，专门安排工作经费，用以支持休闲农业和乡村旅游的示范创建、宣传推介和人才培训。

新疆维吾尔自治区具有得天独厚的自然资源禀赋和民族特色文化，塔城地区水土光热资源丰富、自然资源秀美、农耕文化历史悠久，正在积极探索生产生态良性循环发展的新模式。下一步，农业部将贯彻落实党中央和国务院推动休闲农业发展的文件精神，在原有工作基础上，积极争取、强化协调，完善相关政策措施，与发展改革委、财政部等各部门共同推动、形成合力，统筹研究加强对休闲观光农业的支持，对休闲农业发展资源条件好、发展基础扎实的地区，在示范创建、品牌培育、项目扶持等方面优先倾斜。我部鼓励支持塔城地区创建全国休闲农业和乡村旅游示范县（市、区）。同时，塔城地区应立足自身农业资源优势，不断细化实化政策措施，加大改革力度、拓宽融资渠道、拓展农业多种功能，探索建立多形式利益联结机制，走适合当地特色的发展之路，促进休闲农业快速健康发展。

感谢您对休闲农业发展的关注和建议。
