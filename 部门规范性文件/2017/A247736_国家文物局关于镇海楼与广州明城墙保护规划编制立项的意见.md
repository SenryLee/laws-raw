# 国家文物局关于镇海楼与广州明城墙保护规划编制立项的意见

## 关于镇海楼与广州明城墙保护规划编制立项的意见

办保函〔2017〕153号

广东省文物局：

你局《关于全国重点文物保护单位镇海楼与广州明城墙保护规划立项的请示》（粤文物请〔2016〕69号）收悉。经研究，我局意见如下：

一、镇海楼与广州明城墙位于越秀公园内，周边环境整体状况良好，规划编制的必要性与紧迫性不足，我局暂不同意镇海楼与广州明城墙保护规划编制立项。

二、请你局指导当地人民政府加强“四有”建设，完善镇海楼与广州明城墙的保护区划、管理规定和具体保护管理措施，严格控制周边建设活动。同时，请你局督促有关单位进一步理顺管理机制，切实做好文物日常养护、巡查和岁修工作，确保文物及其周边环境安全。如发现影响文物安全的病害险情，应及时启动保护工作，并按要求履行报批程序。

专此函。

国家文物局

2017年2月22日
