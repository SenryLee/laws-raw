# 人力资源社会保障部关于同意终止中央国家机关职业技能鉴定工作委托关系的复函

人社部函〔2017〕67号

国家机关事务管理局：

《关于商请终止中央国家机关职业技能鉴定工作委托关系的函》（国管函〔2017〕9号）收悉。你局自1989年以来，受原劳动部和原人事部委托承担中央国家机关职业技能鉴定工作，为后勤工人的工资、住房等待遇调整提供了依据，为中央国家机关后勤保障提供了技能人才支撑。为适应中央国家机关后勤服务改革和职业资格改革要求，经研究，现就你局商请工作函复如下：

一、同意终止委托你局开展中央国家机关职业技能鉴定工作。自2017年7月1日起，你局不再开展中央国家机关职业技能鉴定工作，此前由你局以中央国家机关工人考核委员会名义颁发的国家职业资格证书继续有效。

二、你局承担的有关鉴定工作终止后，中央国家机关后勤工人可根据需要参加社会化职业技能鉴定考试。

三、我部将协调有关职业技能鉴定机构，为中央国家机关后勤工人提供职业技能鉴定考试服务，稳妥推进有关工作。

四、请你局通知中央国家机关各部门各单位根据国家有关规定，结合实际制定本部门本单位后勤工人管理办法，做好后勤工人岗位设置、聘用、工资待遇兑现等工作。

工作中遇到的情况和问题，请及时反馈我部。

人力资源社会保障部

2017年5月11日
