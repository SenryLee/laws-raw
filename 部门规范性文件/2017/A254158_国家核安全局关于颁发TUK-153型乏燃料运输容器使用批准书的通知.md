# 国家核安全局关于颁发TUK-153型乏燃料运输容器使用批准书的通知

## 关于颁发TUK-153型乏燃料运输容器使用批准书的通知

国核安发〔2017〕172号

中核清原环境技术工程有限责任公司：

你公司《关于申请进口TUK-153型乏燃料运输容器使用批准书的请示》（清原运发〔2014〕22号）收悉。

根据《放射性物品运输安全管理条例》及其配套规章《放射性物品运输安全许可管理办法》的有关要求，我局审查了你公司提交的申请材料，认为TUK-153型乏燃料运输容器的设计、制造满足我国相关法规和标准的要求，决定向你公司颁发TUK-153型乏燃料运输容器使用批准书，内容如下：

一、批准书编号：CN/055/B(U)F-96（NNSA）。

二、使用单位法定代表人：王海良。

使用单位住所：北京市西城区月坛北街乙1号。

三、设计单位：俄罗斯核容器联合股份公司工程中心；

制造单位：俄罗斯能源技术工程公司。

四、原设计批准号：RUS/6424/B(U)F-96 (Rev.1)。

五、运输容器必须按照设计安全分析报告规定的操作程序进行装载准备、装载和卸载。内容物必须满足原设计要求。

六、运输方式：道路、铁路和水路，独家运输。

七、使用环境温度：-40℃～+38℃。

八、运输容器编码：见附件。

九、有效期至：2022年7月31日。

附件：TUK-153型乏燃料运输容器编码

国家核安全局

2017年8月9日
