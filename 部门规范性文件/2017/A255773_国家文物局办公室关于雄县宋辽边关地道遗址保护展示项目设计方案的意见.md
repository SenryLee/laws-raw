# 国家文物局办公室关于雄县宋辽边关地道遗址保护展示项目设计方案的意见

办保函〔2017〕1056号

河北省文物局：

你局《关于呈报雄县宋辽边关地道遗址保护展示方案的请示》（冀文物字〔2017〕200号）收悉。经研究，我局意见如下：

一、暂不同意所报雄县宋辽边关地道遗址（邢村段）保护展示项目设计方案。

二、所报方案尚需做以下必要的修改和完善：

（一）进一步加强现状勘察和研究，补充开展必要的水文地质勘察，明确地道遗址结构稳定性、本体病害类型、成因及发展趋势，并在此基础上提出具有针对性的保护措施。

（二）明确地道遗址周边区域综合防排水的具体措施。建议科学调整地表排水路径并布设必要的防渗层，有效阻断地表水；调整地表植被，以耐旱匍匐草本植物为主，并优化灌溉方式。

（三）地道遗址出入口加固、内部通风、局部防渗等应提出具体措施。

（四）遗址陈列室应在现有方案一的思路上继续深化，平面布局应顺应古地道“东北—西南”走向特点；同时，地表展示区域应加强与当地土地及城乡发展规划的衔接，完善遗址辅助展示内容，避免过于城市园林化。

（五）应进一步深化保护工程设计，明确具体工程范围、工程措施、工程材料及工程量等。

三、请你局指导方案编制单位，根据上述意见对所报方案作进一步修改和完善，经你局核准后，按程序另行报我局审批。

国家文物局办公室

2017年9月14日
