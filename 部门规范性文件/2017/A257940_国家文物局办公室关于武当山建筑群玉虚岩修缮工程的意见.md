# 国家文物局办公室关于武当山建筑群玉虚岩修缮工程的意见

办保函〔2017〕1261号

湖北省文物局：

你局《关于上报武当山建筑群玉虚岩修缮工程勘察设计方案的请示》（鄂文物〔2017〕40号）收悉。经研究，我局意见如下：

一、所报方案的工程性质不符合我局《关于武当山古建筑群玉虚岩修缮工程立项的批复》要求，拟将西道房、圣母殿、山门、一进门等多个建筑单体重建，我局不同意该方案。该方案已于2011、2013年以来多次申报，并于2015年重新批复立项，应认真按照此前我局有关要求，对勘察设计方案进行认真修改。应坚持现状整修和局部加固的工程性质定位，尽最大可能保留不同时期有价值的做法，不得重建。

二、认真细致做好现状勘察，重点补充对缺失、残损构件和原形制、原做法的研究。在此基础上，可最低限度地补配对现有遗存的结构稳定性确有必要的构件。

三、保护管理用房的选址应符合相关规划要求，补充相关说明及图纸。不宜在该遗址内设置永久性保护管理用房。

四、全面细化具体工艺、做法、材料要求，明确各项措施的工程量，如：地面铺墁形式、柱顶石规格、木板壁规格和搭接方式、博风板规格、油饰色彩和材料要求、岩层加固处理等。取消防火剂的涂刷；遗址缺失石柱础不宜恢复；对不影响结构安全、排水和使用的原砖石构件，不得整体揭墁、更换，避免整饰一新。

五、规范完善文本和图纸。应补充完善残损、工程量和措施说明标注；补充现状照片；补充细部大样；注意核对文字说明与图纸，避免前后不一致;补充人员签章。

请你局指导地方政府和有关单位，按照上述意见对所报方案进行修改、完善，另行报批。同时，督促、指导当地做好文物的保护管理工作，确保人员、文物安全。

专此函复。

国家文物局办公室

2017年11月16日
