# 农业部办公厅关于报送在京单位2016-2017年跨年结转和新申请建房计划的函

农办计函〔2017〕17号

北京市住房和和城乡建设委员会：

按照《北京市住房和城乡建设委员会关于编报中央和部队在京单位2016年-2017年跨年结转和新申请建房计划的通知》（京建发〔2016〕457号）要求，现报送我部在京单位2016-2017年跨年结转和新申请建房计划。

请审批。

附件：1.建设项目储备计划结转报表（2016-2017年度）

2.建设项目施工计划结转报表（2016-2017年度）

3.中央和部队在京单位2016年建设工程竣工项目汇总表

4.中央和部队在京单位2017年新申请建设项目汇总表

农业部办公厅

2017年2月15日
