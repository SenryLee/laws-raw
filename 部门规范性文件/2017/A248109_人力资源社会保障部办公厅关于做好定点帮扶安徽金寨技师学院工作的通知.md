# 人力资源社会保障部办公厅关于做好定点帮扶安徽金寨技师学院工作的通知

人社厅发〔2017〕17号

北京、江苏、浙江、安徽、广东省（市）人力资源社会保障厅（局）：

安徽省金寨县是人力资源社会保障部定点帮扶的国家级贫困县。建设好安徽金寨技师学院对加快金寨县脱贫攻坚、推进金寨县全面小康进程具有重要意义。为贯彻落实人力资源社会保障部《定点帮扶安徽省金寨脱贫工作规划（2016—2020年）》（人社部发〔2016〕108号）精神，切实把定点帮扶工作落到实处，现就有关事项通知如下：

一、总体要求

（一）指导思想。深入贯彻党的十八大和十八届三中、四中、五中、六中全会精神，认真落实习近平总书记扶贫开发重要战略思想，坚持精准扶贫基本方略，进一步强化责任落实、优化结对关系、夯实帮扶措施，切实帮扶安徽金寨技师学院提升办学质量和水平，更好地发挥学院在促进革命老区脱贫致富中的重要作用，支持大别山集中连片贫困地区可持续发展。

（二）主要目标。经过帮扶各方不懈努力，不断健全结对协作和对口支援工作机制，不断拓展合作领域，充分发挥定点帮扶的综合效应，到2020年，使安徽金寨技师学院在办学规模、设施设备、内涵建设、培养质量等方面达到省内一流技工院校水平，为金寨县全面实现脱贫目标提供技能人才支撑。

（三）基本原则

加强统筹。北京等五省市人力资源社会保障厅（局）和帮扶院校要加强帮扶工作的领导，将定点帮扶工作纳入重要议事日程，科学制定帮扶计划并认真执行，统筹人力资源社会保障部门和技工院校优势资源，形成帮扶合力。

优势互补。立足帮扶双方实际情况，创新帮扶措施，实现帮扶双方长期合作、优势互补、互利共赢，探索帮扶欠发达地区培养高技能人才的新方法和新途径，为区域经济发展培养更多的高技能人才。

注重实效。按照帮扶理念精准、帮扶专业精准、帮扶项目精准、帮扶师资精准、帮扶措施精准的要求，聚焦专业建设，把增强安徽金寨技师学院办学水平、提高育人质量作为工作重点，注重帮扶效果。

二、主要任务

（一）强化专业建设。坚持面上指导与重点帮扶相结合，各帮扶院校重点帮扶1-2个专业（帮扶院校及相关专业一览表见附件）。各帮扶院校与安徽金寨技师学院联合成立专业建设委员会，在安徽金寨技师学院设立专家流动站，确保每个专业定期有1名帮扶院校专家驻站，加强对专业建设方案、人才培养方案、专业课程建设、专业教材编撰的指导。各帮扶院校利用企业资源优势，至少联系引进1家技术先进、专业对口的较大规模企业与定点帮扶的专业开展深度合作，校企双制共同培养高技能人才。到2020年，力争将帮扶专业建成安徽省级一流技工教育专业。

（二）支持实训基地建设。根据安徽金寨技师学院专业发展和培养高技能人才需求，对正在规划建设中的实训中心，由定点帮扶院校指导实训场地规划、实训设备配置规划和实训课程实施；对已经建成的实训室论证评估，合理布局调整，提高使用效率，建成一体化学习工作站。鼓励帮扶地区和帮扶院校支援先进的实训设备，帮扶院校因产业调整而闲置下来的实训设备可以转赠支持安徽金寨技师学院实训基地建设。到2020年，力争将所有定点帮扶专业实训基地建设成为省级技能比赛赛点。

（三）加强师资队伍建设。采取双向挂职、两地培训、委托培养和支教等方式，加快培养一支高技能、高素质师资队伍。帮扶院校根据专业建设、实训基地建设和教学工作需要，定期安排1-2名专业带头人或专业骨干教师到安徽金寨技师学院支教。安徽金寨技师学院各专业分期分批选派管理人员及专业教师到定点帮扶院校跟岗学习3-6个月。支教教师和跟岗学习人员的食宿问题，由安徽金寨技师学院和帮扶院校协商解决。到2020年，完成第一轮学习培训，各帮扶专业培养省级专业带头人1名以上。

（四）加强对学生的技能培训。帮扶院校采取到校指导、接纳培训等方式，帮助安徽金寨技师学院参加各级各类技能大赛的学生进行专业技能强化训练，提高学生竞技水平，对毕业年度学生开展岗前技能强化训练，提高学生的岗前适应能力和综合职业素养。到2020年，力争各帮扶专业至少1人次在省级以上技能大赛中获得较好成绩。

（五）协调帮助开展国际合作。帮扶院校将合作的外国企业和职业院校积极引荐给安徽金寨技师学院，加强国际交流与合作，学习借鉴发达国家先进职业教育模式，积极探索与国外高水平院校合作办学，拓展合作办学渠道，拓宽学生就业创业路径。

三、保障措施

（一）加强领导。北京等五省市人力资源社会保障部门和帮扶院校要把定点帮扶安徽金寨技师学院作为帮助革命老区精准扶贫、精准脱贫的政治任务来抓，加强组织领导，明确部门分工，形成工作合力。人力资源社会保障部职业能力建设司具体负责定点帮扶安徽金寨技师学院工作的综合协调。北京等五省市及帮扶院校所在城市人力资源社会保障部门要明确责任处室和负责人，负责定点帮扶工作的组织协调和督查调度。各帮扶院校要明确1名领导班子成员负责定点帮扶工作。

（二）政策支持。北京等五省市人力资源社会保障部门要制定有针对性的政策措施，为帮扶院校在人员派遣、设备捐赠、资金帮扶、项目建设、人员培训、联合办学、校企合作、就业创业等方面提供政策支持。支持各帮扶院校提高帮扶干部、专家、支教教师工资待遇，为进修学习的安徽金寨技师学院教职工提供必要的生活保障。

（三）加强督查。北京等五省市人力资源社会保障部门要加强对所辖帮扶技工院校帮扶工作的指导、督促、检查、考核，推动定点帮扶工作的落实。帮扶院校要将结对帮扶工作纳入帮扶人员年度考核，实施单项考评，帮扶成效好的给予表扬，并将帮扶工作成效作为评先、晋级、提拔的重要参考。
