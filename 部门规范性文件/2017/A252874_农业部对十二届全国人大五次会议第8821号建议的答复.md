# 农业部对十二届全国人大五次会议第8821号建议的答复

## 对十二届全国人大五次会议第8821号建议的答复

农办议〔2017〕104号

汪其德代表：

您提出的关于加大对贫困地区绿色农业政策支持力度的建议收悉。经商发展改革委、财政部、保监会和人民银行，现答复如下。

一、关于加大对贫困地区绿色发展政策倾斜

四川巴中地处秦巴山区，是我国重要的生态功能区，对保障国家生态安全，涵养生物多样性发挥着重要作用。我部高度重视巴中农业农村经济发展尤其是绿色农产品发展，2016年以来，会同有关部门累计安排绿色高产高效创建、畜禽良种推广、标准化养殖补助等各类农业资金约5亿元。加大绿色高产高效创建支持力度。安排中央财政专项资金开展绿色高产高效创建，以高产高效、节本增效、提质增效、环境友好为目标，指导当地开展协作攻关，集中力量攻克技术瓶颈，集成组装区域性、标准化高产高效技术模式，引领农业生产方式转变，带动提升当地种植业综合生产能力。深入实施化肥农药使用量零增长行动。以用肥量大的玉米、蔬菜、果树为重点，依托新型经营主体，示范推广秸秆养分还田、畜禽粪便资源化利用。开展区域生态循环农业示范。支持各地开展畜禽养殖废弃物资源化利用、农副资源综合开发、标准化清洁化生产，促进农牧结合、种养结合、生态循环，提高农业资源利用效率，推进区域内农业废弃物“零排放和全消纳”。

下一步，我部将加快建立以绿色生态为导向，以促进农业资源合理利用与生态环境保护为重点的绿色农业补贴政策体系，完善农业生态保护成效与资金分配挂钩的激励约束机制，相关的政策和扶持资金项目将向巴中倾斜支持，进一步加快巴中绿色农业发展。

二、关于加大对贫困地区农业发展科技支持

我部十分重视包括巴中在内的四川省现代农业产业发展，持续投入科研经费提升当地农业科技创新能力。“十二五”以来中央财政每年投入经费5420万元，支持水稻、玉米、小麦、大豆等35个产业技术，开展技术研究、集成和示范，为农户开展技术服务。加强科技研发推广。强化贫困地区农业发展科技支撑，依托现代农业产业技术体系，支持巴中科研专家开展动植物育种与繁育、病虫害防控、栽培与土肥、农机装备、加工等研究。加强新型职业农民培育。我部联合财政部在巴中地区实施新型职业农民培育工程，重点面向种养大户、家庭农场主、农民合作社骨干、农业社会化服务人员和农村创业青年，以提高生产经营能力和专业技能为目标，开展农业全产业链培训，促进农民创业兴业，培养了一批爱农业、懂技术、善经营的新型职业农民。针对贫困县有劳动能力的贫困人口，围绕当地主导产业和特色产业，在一个生产周期内，开展不少于5天的专项技能培训，帮助提升贫困人口增收致富信心和能力。加大农村实用人才培养。去年，将农业部、中组部共同开展的农村实用人才带头人示范培训调整为主要面向贫困地区实施，举办示范培训班，遴选种养大户、家庭农场主和农民合作社负责人等到农业部农村实用人才培训基地学习交流，包括巴中在内的一批农村实用人才带头人接受了培训。

下一步，我部将继续加强现代农业产业技术体系建设，强化贫困地区特色产业发展的科技支撑；加强农业技术推广体系建设，提升贫困地区技术服务能力；加快培育农村实用人才和新型职业农民，为贫困地区发展现代农业提供人才保障。

三、关于加大对贫困地区农业新型经营主体扶持力度

我部高度重视巴中等贫困地区的新型经营主体的扶持，会同有关部门认真落实中央部署，积极引导龙头企业通过多种渠道参与扶贫开发，充分利用龙头企业在行业、资金、技术等方面优势，帮助贫困地区培植产业基础、注入稀缺要素、促进产业升级、拓宽增收门路。同时，采取必要措施，积极支持农民专业合作组织等市场主体发展。一是强化政策支持。2016年4月，农业部、国务院扶贫办、国家发展改革委、财政部等9部门向各有关省（区、市）人民政府联合印发《贫困地区发展特色产业促进精准脱贫指导意见》（农计发〔2016〕59号），明确提出要培育壮大贫困地区农民合作社、龙头企业、种养大户等新型经营主体，支持新型经营主体通过土地托管、牲畜托养，吸收农民土地经营权入股等途径，与贫困户建立稳定带动关系，鼓励股份合作帮扶模式，推广订单帮扶模式。政府扶持资金通过以奖代补、贷款贴息等方式支持新型经营主体和贫困户。二是加大投入力度。2017年，中央安排财政专项扶贫资金861亿元，比上年增长30%。各地根据本地脱贫攻坚和产业发展需求，统筹安排资金用途，支持贫困地区贫困户与新型经营主体发展产业。2016年4月，国务院办公厅印发了《关于支持贫困县开展统筹整合使用财政涉农资金试点的意见》（国办发〔2017〕22号），支持贫困县开展统筹整合使用财政涉农资金试点，赋予贫困县统筹整合使用财政涉农资金的自主权。根据文件精神，贫困县可依据统筹使用上级财政下达的纳入整合范围的相关财政涉农资金，围绕自身需求，因地制宜支持贫困地区新型经营主体带动贫困户发展产业。三是支持农民专业合作经济组织发展。为提高农民进入市场的组织化程度，2003年起，中央财政安排专门资金支持农民专业合作组织发展。2016年，中央财政安排14亿元，采取切块下达方式，支持各地因地制宜发展粮食、农机、畜牧、林果等类型农业合作社，重点用于支持引进新品种和推广新技术、提供培训及服务、组织标准化生产、农产品加工、品牌培育、市场营销和信息咨询等。四是探索“保险+产业扶贫”新模式。近年来，我国农业保险快速发展，覆盖面进一步增强，服务能力和水平不断提高。截至2016年底，中央财政已将水稻、小麦、玉米等主要粮食作物以及能繁母猪、奶牛、育肥猪、棉花等15种涉及国计民生的品种纳入保费补贴目录。已有8家保险机构在12个省份开展“保险+期货”试点，涉及大豆、玉米、鸡蛋、棉花和白糖等多个品种。农业保险中已开发出扶贫专属保险产品近50个，有力支持了贫困地区特色产业发展。保监会批准中国人民保险集团股份有限公司设立50亿元的资管产品，专项用于参保贫困农户的小额融资。五是培育贫困地区农产品市场品牌。从去年12月至今年6月，我部共举办8期产业扶贫现场观摩，推广洛川苹果、赣南脐橙、定西马铃薯、广西百色芒果、贵州黔西南薏仁、河北平泉食用菌、湖北罗田黑山羊、安徽岳西茭白、河南信阳毛尖、山西平顺中药材、宁夏盐池滩羊、重庆石柱红辣椒等20余个区域公用品牌。同时，在新华社、人民日报、中央人民广播电台、中央电视台等中央主要媒体重要版面、重要时段集中推出产业扶贫范例系列报道，宣传区域公共品牌。支持举办中国国际农产品交易会、洛川苹果节、彭州蔬菜节、定西马铃薯节、贵阳国际特色农产品交易会等农业展会，帮助贫困地区农产品扩大市场影响，培育产品品牌，增强特色农产品市场竞争力。

下一步，我们将积极引导各地加大对贫困地区农业产业发展的指导和支持力度，加大贫困地区种养大户、农民合作社、农业产业化龙头企业等新型经营主体培育力度，帮助贫困地区引进适合当地的龙头企业，提高贫困地区农民组织化程度、农业产业增值能力和吸纳贫困农户就业增收能力；指导贫困地区创新贫困户、村集体、企业多方受益机制，把带动贫困户精准受益作为扶持新型经营主体、安排产业扶贫项目的前置条件，通过项目牵引，把贫困户“粘”在产业链上；加快总结推广各地探索成功的直接帮扶、订单帮扶、股份合作、托管等产业精准扶贫模式，引导贫困户与新型经营主体建立紧密合作关系，实现可持续发展；继续加大贫困地区特色农产品品牌宣传推介，支持贫困地区参加各类农产品展销会，加快贫困地区巩固特色农产品品牌创建。

感谢您对农业、农村工作的关心，希望今后继续对我部工作予以支持。
