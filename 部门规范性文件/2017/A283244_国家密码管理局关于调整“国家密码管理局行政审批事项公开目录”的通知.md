# 国家密码管理局关于调整“国家密码管理局行政审批事项公开目录”的通知

国密局字 〔2017〕344号

各省、自治区、直辖市密码管理局，新疆生产建设兵团密码管理局，深圳市密码管理局：

根据《国务院关于取消一批行政许可事项的决定》（国发〔2017〕46号），取消由我局负责实施的商用密码产品生产单位审批、商用密码产品销售单位许可、外商投资企业使用境外密码产品审批、境外组织和个人在华使用密码产品或者含有密码技术的设备审批等4项行政许可事项。据此，我局对《国家密码管理局行政审批事项公开目录》进行了调整，请遵照执行。

附件：国家密码管理局行政审批事项公开目录

国家密码管理局

2017年10月16日
