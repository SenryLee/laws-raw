# 国家文物局关于青岛八大关近代建筑——汇泉路7号东海饭店保护修缮工程立项的意见

## 关于青岛八大关近代建筑——汇泉路7号东海饭店保护修缮工程立项的意见

办保函〔2017〕134号

山东省文物局：

你局《关于青岛八大关近代建筑——汇泉路7号（东海饭店）保护修缮工程立项的请示》（鲁文发〔2016〕155号）收悉。经研究，我局意见如下：

一、暂不同意青岛八大关近代建筑——汇泉路7号（东海饭店）保护修缮工程立项。

二、立项报告尚需在以下方面做出修改：

（一）进一步深化文物现状勘察，补充近年来已实施的维修具体内容、完成情况和维修效果评估，为本次工程开展提供借鉴。

（二）加强对文物建筑形式特点、原有风貌的研究，坚持“最小干预”原则，严格控制工程量和工程范围。恢复建筑立面、阳台、廊道、客房等应慎重，并补充相关依据。

（三）建筑院落整治、排水设施等应在设计方案中予以统筹考虑。

（四）结合实际残损量和维修工程量，进一步细化工程经费的取费依据，调减工程预算。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此。

国家文物局

2017年2月21日
