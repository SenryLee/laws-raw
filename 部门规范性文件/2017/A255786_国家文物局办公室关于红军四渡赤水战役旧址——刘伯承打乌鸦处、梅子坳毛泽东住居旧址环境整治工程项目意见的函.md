# 国家文物局办公室关于红军四渡赤水战役旧址——刘伯承打乌鸦处、梅子坳毛泽东住居旧址环境整治工程项目意见的函

办保函〔2017〕902号

贵州省文物局：

你局《关于在全国重点文物保护单位红军四渡赤水战役旧址——刘伯承打乌鸦处、梅子坳毛泽东住居旧址实施环境整治工程的请示》（黔文物呈〔2017〕23号）收悉。经研究，我局意见如下：

一、风貌整治类建筑应注重保留其时代特征，保护历史事件发生地的环境风貌，避免建筑界面同质化、产品化，造成历史信息混淆。

二、刘伯承打乌鸦处的绿化修复应深化对该区域历史格局的调查资料，注重对其历史环境的恢复，对历史环境的保护要求也应在整治措施中予以说明。

三、深化场地道路铺装设计，缩减硬质铺装比例，避免过度园林化，补充详图及设计说明。

四、解决防火、防盗等问题，不应采用钢丝网围栏，可采用其它形式围栏，如板条栅栏等。

五、进一步调整停车场等配套服务设施集中布置，减少场地内外游线的交叉。

六、文物影响评估中应补充该建设项目对文物环境中的历史氛围、环境元素等方面的影响分析、评估。

请你局指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此。

国家文物局办公室

2017年8月2日
