# 国家邮政局关于同意授予锡林郭勒盟等七个城市首批“全国快递服务现代农业示范基地”称号的复函

国邮函〔2017〕4号

锡林郭勒、松原、苏州、赣州、烟台、百色、中卫市（盟）人民政府：

为充分发挥快递业在推动流通转型、促进消费升级方面的先导性作用，深入推进实施“快递下乡”工程，支持现代农业发展，国家邮政局于2016年组织开展了首批全国快递服务现代农业示范基地申报评选工作。在各地积极申报的基础上，经严格审核，国家邮政局同意授予锡林郭勒盟、松原市、苏州市、赣州市、烟台市、百色市和中卫市首批“全国快递服务现代农业示范基地”称号。

希望获得首批示范基地称号的城市继续努力，以示范项目为载体，推动其成为农业发展、农民致富、精准扶贫的新抓手，更好地助力地方经济发展；积极营造发展环境，注重在服务模式和服务能力方面形成典型经验，发挥示范和带动作用，引领产生更多快递服务农产品项目。

国家邮政局

2017年1月11日
