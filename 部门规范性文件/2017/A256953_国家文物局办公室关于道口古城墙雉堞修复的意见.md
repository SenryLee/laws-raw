# 国家文物局办公室关于道口古城墙雉堞修复的意见

办保函〔2017〕1198号

河南省文物局：

你局《关于报批滑县道口古城墙雉堞修复设计方案的请示》（豫文物〔2017〕219号）收悉。

经研究，滑县道口古城墙2014年已按我局批复的《滑县道口古城墙维修保护方案》进行了维修，而古城墙雉堞已经全部毁掉多年，修复的依据及必要性不足，我局不同意该项目。请你局督促当地人民政府树立正确的文物保护理念，妥善处理好文物保护与旅游发展的关系，确保文物安全。

国家文物局办公室

2017年10月25日
