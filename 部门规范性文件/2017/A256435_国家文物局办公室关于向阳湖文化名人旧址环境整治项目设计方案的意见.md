# 国家文物局办公室关于向阳湖文化名人旧址环境整治项目设计方案的意见

办保函〔2017〕1120号

湖北省文物局：

你局《关于申报<向阳湖文化名人旧址向阳区环境整治工程设计方案>的请示》（鄂文物〔2017〕43号）。经研究，我局意见如下：

一、环境整治项目应充分保护旧址及其历史环境的真实性，避免对旧址环境造成破坏。

二、深化文物影响评估，准确表述环境整治项目对文物的影响。如评估报告中表述“不存在新建建筑”，但方案有电瓶车管理用房建设项目等。

三、补充新建辅助用房、电瓶车管理用房、道路、停车场对旧址及其环境影响的分析图。

四、环境风貌应尽量简朴，过多的绿化、增加的景石及景墙、小品等，使旧址环境过于园林化，影响旧址的历史氛围。

五、景观照明应尽量简化，补充具体的内容说明和图纸，如总平面图、灯光种类、布置方式、效果等。

六、补充游览栈道铺设的理由说明。管理用房应有位置说明和是否符合保护管理要求的说明。

七、进一步补充完善方案文本和图纸。如：补充旧址周围建筑整治、改造图，补充部分图纸图例等。

请你局指导相关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此。

国家文物局办公室

2017年9月26日
