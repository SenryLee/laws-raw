# 国家发展改革委办公厅关于印发环境污染第三方治理典型案例（第一批）的通知

发改办环资〔2017〕2079号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团发展改革委：

为进一步推进环境污染第三方治理工作，推广实践经验、管理制度和有效模式，在面向全国征集环境污染第三方治理典型案例的基础上，经过评估、总结，决定推荐中煤旭阳焦化污水第三方治理等6个案例为环境污染第三方治理典型案例（第一批）。现印发给你们，供在推进环境污染第三方治理中参考借鉴。

附件：环境污染第三方治理典型案例（第一批）

国家发展改革委办公厅

2017年12月15日
