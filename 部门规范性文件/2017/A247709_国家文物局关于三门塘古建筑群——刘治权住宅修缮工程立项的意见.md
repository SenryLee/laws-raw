# 国家文物局关于三门塘古建筑群——刘治权住宅修缮工程立项的意见

## 关于三门塘古建筑群——刘治权住宅修缮工程立项的意见

办保函〔2017〕109号

贵州省文物局：

你局《关于送审〈三门塘古建筑群——刘治权住宅维修工程立项报告〉的请示》（黔文物呈〔2016〕100号）收悉。经研究，我局意见如下：

一、暂不同意三门塘古建筑群——刘治权住宅修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）加强现状勘察和研究，明确文物保存现状、主要病害类型、残损情况等，深入分析屋面漏雨、木构件糟朽等病害原因，客观评估历次修缮和后期居民改造影响，进一步论证工程实施的必要性和可行性。

（二）应根据前期勘察结果进一步核实工程范围和工程量，明确构件更换标准，尽可能保留原有构件，严禁大规模更新原有木柱、木板壁、地板、门窗等木构件，避免过度维修。恢复石库门脊饰及挂落应慎重，严禁缺乏科学依据的盲目复原。

（三）细化工程做法，采用灌浆加固措施修补开裂山墙时，应注意灌浆强度与原有墙体强度匹配，避免造成安全隐患。

（四）进一步明确刘治权住宅的管理使用情况和产权现状、居住人口等，充分考虑居民的生活需要和合理诉求，科学开展建筑内部空间调整，兼顾民生改善，统筹考虑文物建筑利用问题。

（五）根据工程量合理编制经费预算，进一步核减工程造价，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促地方人民政府抓紧编制三门塘古建筑群保护规划，统筹考虑文物建筑修缮、环境整治、展示利用等工作，协调处理文物保护与地方经济发展、民生改善的关系。同时，进一步明确刘治权住宅的管理责任，根据《古建筑保养维护规程》及时开展文物日常养护和岁修工作，并采取多种方式展示、宣传文物价值，充分体现文物保护的公益性和文化效益。

专此函。

国家文物局

2017年2月13日
