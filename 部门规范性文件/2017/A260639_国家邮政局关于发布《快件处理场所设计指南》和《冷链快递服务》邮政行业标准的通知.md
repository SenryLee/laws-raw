# 国家邮政局关于发布《快件处理场所设计指南》和《冷链快递服务》邮政行业标准的通知

国邮发〔2017〕101号

各省、自治区、直辖市邮政管理局，中国邮政集团公司，各主要快递企业：

现发布YZ/T 0161-2017《快件处理场所设计指南》和YZ/T 0162-2017《冷链快递服务》推荐性邮政行业标准。以上两项标准均自2018年3月1日起施行，由人民交通出版社负责出版发行。

《快件处理场所设计指南》和《冷链快递服务》的发布与实施，对于加快推进快件处理场所标准化建设，促进冷链快递服务质量提升，深化邮政业供给侧结构性改革具有重要意义。请各单位认真组织标准的宣贯工作，采取有力措施推动标准的实施，更好地促进邮政行业持续健康发展。
