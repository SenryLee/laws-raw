# 国家粮食局关于加快推进粮食行业科技创新人才发展的意见

国粮人〔2016〕289号

各省、自治区、直辖市及新疆生产建设兵团粮食局，中国储备粮管理总公司、中粮集团有限公司、中国航空工业集团公司，河南工业大学、南京财经大学、武汉轻工大学：

为深入贯彻落实全国科技创新大会和《国家创新驱动发展战略纲要》《关于深化人才发展体制机制改革的意见》精神，坚定不移地走科技兴粮、人才兴粮之路，加快推进粮食行业科技创新人才发展，提出如下意见。

一、总体要求

全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入学习贯彻习近平总书记系列重要讲话精神，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，牢固树立和贯彻创新、协调、绿色、开放、共享的发展理念，全面落实创新驱动发展和人才优先发展战略，大力实施科技兴粮和人才兴粮工程，在粮食行业科技创新人才发展体制机制的关键环节取得突破性进展，实现科技创新人才数量快速增加、素质大幅提升、结构较为合理、使用效能显著提高、竞争优势明显增强，建成一支适应粮食行业创新驱动发展需要的科技创新人才队伍，为保障国家粮食安全，实现藏粮于技的目标，加快发展现代粮食流通产业提供坚强的人才保障和智力支撑。

二、改进粮食行业科技创新人才培养支持机制

（一）完善科技创新领军人才培养支持方式。大力实施粮食行业百千万创新人才工程，加大对各层次科技创新拔尖人才的选拔培养力度。鼓励有条件的企事业单位设立“首席科学家（专家）”岗位，在科研、生活上予以重点支持。注重在实践中培养高层次人才，加强“粮安工程”等重点工程与科研工作的协同联动，依托粮食领域国家工程实验室、工程技术中心、重点实验室等技术创新平台，构建粮食行业科学、技术、工程专家协同创新机制，促进信息、技术、人才等创新要素互联互通互融。建立基础研究人才培养长期稳定支持机制，健全竞争性经费与稳定支持经费相协调的投入模式，鼓励创新型领军人才牵头组建科研团队，开展原创性基础研究和面向粮食行业特殊需求的应用研发。加大专业技术人才知识更新培训力度，充分发挥粮食行业教育培训基地作用，聚焦科技创新领域，开展高层次和紧缺急需专业技术人才专项培训。

（二）建立优秀青年科技创新人才支持制度。实施全国粮食行业青年拔尖人才优先培养计划，破除论资排辈、求全责备等观念，加大对优秀青年人才科技创新的选拔资助力度。要敢于让优秀青年专业技术人才主持重点科研项目、担任重要学术职务。要进一步加强青年人才创新意识和创新能力培养，探索建立以创新创业为导向的粮食行业青年人才培养机制，鼓励并大力支持青年拔尖人才围绕行业需求开展自主选题的科学研究、积极参加国内外重点学术交流活动，推荐他们到国际学术团体担任职务，支持青年科技创新人才作为科技特派员开展基层和农民科技服务。有关科研院所、企业要充分利用博士后科研工作站的平台，创造条件独立招收博士后研究人员，吸引更多优秀青年从事粮食领域博士后研究工作。继续推进服务粮食行业特殊需求博士人才培养项目建设，提高青年高层次人才培养质量。

（三）加强创新创造型技术技能人才培养。大力发扬工匠精神，继续实施高技能人才培养工程，每两年选拔一批全国粮食行业技能拔尖人才，通过组织培训、技术交流、建立工作室承担技术技能攻关项目等方式对技能拔尖人才予以重点培养，发挥其在技术攻关、技能创新和传技带徒等方面的带动作用。鼓励有条件的企业探索建立“首席技师”制度，发挥高技能人才的引领作用，不断提高技术技能人才经济待遇和社会地位。加大技能人才培训力度，广泛开展“岗位练兵”“技能竞赛”活动，定期举办全国粮食行业职业技能竞赛，在全行业形成“比、学、赶、超”的氛围，引导广大一线技能人才向创造型技术技能人才发展，形成与粮食流通事业发展相适应的技术技能人才队伍。

（四）创新科技创新后备人才教育培养模式。结合粮食行业人才需求，引导相关高校调整学科体系和专业设置，巩固传统粮食学科，发展涉粮交叉学科，拓展涉粮新兴学科。进一步落实共建高校的支持措施，重点扶持相关高校涉粮重点学科和重点实验室建设。完善产学研用结合的协同育人模式。通过定向招生、委托培养等方式，加快急需紧缺粮食专业人才培养。主动发挥行业在职业教育中的指导作用，利用好粮食行业职业教育集团平台，进一步深化校企合作、产教结合，加强企业与职业院校之间在订单培养、师资培养、实训基地建设、课程开发、教学改革等方面的深度合作。涉粮职业院校要充分发挥自身办学优势，扩大粮食专业招生，积极探索在非粮专业中融入粮食元素，让学生“知粮、懂粮、爱粮”，乐于到粮食行业就业。有关高校要抓住当前教育改革契机，按照“科学定位、特色发展”的要求，进一步突出自身“粮食”特色，更加紧密围绕粮食行业发展需求培养专门技术人才。

三、健全粮食行业科技创新人才引进评价激励机制

（一）完善科技创新人才引进机制。对急需紧缺高层次人才，要广开渠道，给予优惠政策，实现精准引进。打破“业内”“业外”界限，广开渠道，招贤聚才，积极吸引其他领域优秀科研人员和团队参加粮食科研工作。建立柔性引才机制，“不求所有、但求所用”“不求常在、但求常来”，通过项目（课题）招标、联合攻关、咨询服务等各种形式让人才为我所用。引导企业“招商引资”与“招才引智”并举，在引进项目、技术、资金的同时，采取各种方式灵活引进海内外智力。支持粮食行业院校、科研院所设立一定比例流动岗位，吸引有创新创业实践经验的企业家和科研人才兼职，鼓励院校聘请行业高层次人才担任兼职导师。中西部地区要充分利用国家相关扶持政策，通过挂职锻炼、交流任职、对口支援等多种形式引进粮食行业急需人才。

（二）坚持德才兼备，注重能力、实绩和贡献的科技创新人才评价导向。立足粮食流通事业发展需要，以实际能力、业绩和贡献为标准，不唯学历、不唯论文、不唯资历，突出专业性、创新性、实用性，不断提升人才评价科学化水平。积极探索推进分类评价办法，基础研究人才以同行学术评价为主，突出中长期目标导向，评价重点从研究成果数量转向研究质量、原创价值和实际贡献；应用研究和技术开发人才科研产品突出市场检验和用户评价，注重科研成果转化及对行业发展的影响。探索技能人才多元评价机制，突出技术技能和业绩导向，逐步完善社会化职业技能鉴定与企业技能人才评价、院校职业资格认证相结合的办法。

（三）实行以增加知识价值为导向的分配办法。认真贯彻落实中央办公厅、国务院办公厅《关于实行以增加知识价值为导向分配政策的若干意见》（厅字〔2016〕35号）文件要求，积极引导粮食行业院校、科研院所、企业实行体现自身特点的分配办法。要按照职能定位和发展方向，建立以实际贡献为评价标准、与岗位职责目标相统一的科技创新人才收入分配激励机制，使分配向优秀人才、关键岗位倾斜。对从事基础性研究和公益性研究的人员，要建立稳定性薪酬占高比例的岗位绩效薪酬体系和青年人才职业早期薪酬保障机制。对从事应用研究和技术开发的人员，要逐步建立与市场接轨的薪酬体系。对从事粮食流通理论研究的人员，以理论创新、决策咨询支撑和社会影响作为评价基本依据，形成合理的智力劳动补偿激励机制。按照国家规定加大财政科研项目资金对科研人员的激励力度，制定符合本单位实际的横向委托项目经费管理制度。要引导企业根据技术技能人才的技能水平、职业资格等级、实际岗位和工作业绩确定工资水平，建立高技能人才岗位津贴制度，对在技术改造、技术革新中作出突出贡献并取得重大经济效益的技术技能人才予以重奖。

（四）完善科技成果转移转化奖励机制。粮食行业各单位要认真贯彻《国务院关于印发实施<促进科技成果转化法>若干规定的通知》（国发〔2016〕16号）精神，按照《国家粮食局关于大力促进粮食科技成果转化的实施意见》（国粮储〔2016〕148号）要求，在充分听取本单位科技人员意见的基础上，结合本单位实际制定科技成果转移转化分配制度并有效实施，激励科技创新人才开拓创新，切实增强粮食行业创新驱动能力。

四、完善粮食行业科技创新人才服务保障机制

（一）加强组织领导。坚持党管人才原则，加强政治引领和政治吸纳，充分发挥党组织凝聚人才的重要作用。各省(区、市)粮食行政管理部门及有关中央企业要结合本地区、本单位实际，研究提出落实本意见的具体措施，实施与青年拔尖人才优先培养计划、高技能人才培养工程相对应的人才计划或工程，将工作任务层层分解，落实到位。要健全人才工作领导机构，配强工作力量，把人才工作作为一项基础性、全局性的重要工作，与其他业务工作同步考虑、同步部署、同步考核，与实施行业重大战略同步规划、同步推进。

（二）加强经费保障。各级粮食行政管理部门要主动作为，积极协调同级财政部门，把必要的人才经费列入财政预算，建立稳定的经费投入渠道。各用人单位要坚持人才优先发展的理念，进一步增加人才投入，提高人才经费的比重。在实施行业重点科研项目和重大建设工程项目时，统筹安排人才开发培养经费。要按照中央援疆援藏工作的要求，给予更多政策倾斜和支持。拓宽人才工作投入渠道，建立政府、企业、社会相结合的多元化投入机制，完善对高层次创新人才、高技能人才和优秀团队提供长期稳定的经费支持保障机制。

（三）加强信息服务。加强粮食行业人才信息平台建设，及时发布粮食行业人才供求信息，建立人才信息交流、共享机制。充分利用广播电视、报纸期刊及互联网多种宣传渠道，通过新闻报道、政策解读、人物访谈等多种形式广泛宣传科技兴粮、人才兴粮，大力宣传各地各单位人才工作中的先进经验、做法和成效，宣传粮食行业科技领军人才、创新创业人才、高技能人才等优秀人才的典型事迹，努力营造粮食行业尊重劳动、尊重知识、尊重人才、尊重创造的良好氛围，不断推进粮食行业科技创新人才队伍建设。
