# 农业部关于报送中国水稻研究所北方水稻研究中心建设项目可行性研究报告的函

农计发〔2017〕109号

国家发展改革委：

水稻是我国第一大粮食作物，其产量约占全国粮食总产量的40%左右。稻米是我国65%以上人口的主粮，在保障国家“口粮”安全方面具有举足轻重的地位。近年来，随着消费结构的进一步调整升级，东北地区的大米受到消费者青睐，呈供不应求的局面。同时，一些问题也开始显现。一是东北地区水稻品种类型单一，稻瘟病等危害日趋严重；二是稻作技术发展不平衡，全程机械化水平不高；三是东北“黑土地”黑土层逐年退化、地下水位逐年下降。这些问题已经严重影响到我国北方水稻产业的健康持续发展，亟须打造一个资源共享、联合创新的国家级平台，在品种资源的收集和创新、新品种选育、绿色高效栽培技术与生理研究、成果转化与推广等领域开展科研攻关。

中国水稻研究所是一个以水稻为主要研究对象的多学科综合性国家级科研单位，设有水稻生物学国家重点实验室、国家水稻改良中心、稻作技术研究与发展中心、农业部稻米及制品质量监督检验测试中心和科技信息中心等。研究所拥有中华农业科技奖优秀创新团队3个，农业部农业科研杰出创新团队4个，科技部创新人才推进计划重点领域创新团队2个，国家创新研究群体自然科学基金“稻类遗传育种学”项目1个，浙江省重点科技创新团队1个。“十二五”期间，研究所共获得了省部级以上奖励17项。总之，中国水稻研究所已经具备建设北方水稻研究中心所需的人才队伍优势。

中国水稻研究所北方水稻研究中心为《农业部直属单位中长期条件建设规划（2016-2025）》内项目。北方水稻研究中心建设地点位于黑龙江省双鸭山市宝清县。项目主要建设内容包括新建综合实验室4679平方米，研究生宿舍及食堂2347平方米，温网室、育秧棚及种子库等9980平方米，配套建设室外场区工程，购置仪器设备164台（套）。项目总投资9009万元，全部申请中央预算内投资。项目建设期3年。

项目建成后，将通过生物技术与常规技术相结合等手段，创制新型水稻种质资源，强化优质、高产、抗病水稻品种的选育，加强水稻高效栽培与生理研究，通过良种、良法、良田、良机相结合，推进科技创新成果集成示范、转化与推广，支撑北方水稻生产的发展。

现将《中国水稻研究所北方水稻研究中心可行性研究报告》报送你委，请审批。
