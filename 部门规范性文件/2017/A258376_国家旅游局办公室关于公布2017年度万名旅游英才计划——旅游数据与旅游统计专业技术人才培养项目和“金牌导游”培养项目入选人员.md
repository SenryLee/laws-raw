# 国家旅游局办公室关于公布2017年度万名旅游英才计划——旅游数据与旅游统计专业技术人才培养项目和“金牌导游”培养项目入选人员名单的通知

旅办发〔2017〕285号

各省、自治区、直辖市旅游发展委员会、旅游局：

根据《“万名旅游英才计划”实施方案》和《国家旅游局办公室关于组织实施2017年度万名旅游英才计划的通知》（旅办发〔2017〕192号），现将2017年度万名旅游英才计划——旅游数据与旅游统计专业技术人才培养项目和“金牌导游”培养项目入选人员名单印发给你们。入选人员申报项目实施期为1年，期间我局将指导开展相关项目工作，期满我局将组织项目验收总结。

请按照有关要求，加强对本地区入选人员的统筹指导，加大宣传力度，为人才发展创造有利条件。鼓励有条件的单位予以配套支持。

附件：1.2017年度万名旅游英才计划——旅游数据与旅游统计专业技术人才培养项目入选人员名单

2.2017年度万名旅游英才计划——“金牌导游”培养项目入选人员名单

国家旅游局办公室

2017年11月20日
