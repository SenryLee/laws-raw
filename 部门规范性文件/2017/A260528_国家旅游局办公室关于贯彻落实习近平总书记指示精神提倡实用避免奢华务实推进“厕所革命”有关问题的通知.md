# 国家旅游局办公室关于贯彻落实习近平总书记指示精神提倡实用避免奢华务实推进“厕所革命”有关问题的通知

旅办发〔2017〕341号

各省、自治区、直辖市旅游发展委员会、旅游局：

2015年以来，全国“厕所革命”进展顺利、成效显著。同时也要看到，个别地区的厕所存在脱离发展实际的竞相攀比、追求奢华等不良现象。为深入贯彻落实习近平总书记关于“厕所革命”的重要指示精神，务实推进“厕所革命”新三年行动计划，现将有关事项通知如下：

一、充分认识在“厕所革命”中提倡实用避免奢华的重要意义

提倡实用、避免奢华是深入贯彻落实习近平总书记关于“厕所革命”重要指示的重要内容，是提升旅游业品质的务实之举，是适应大众旅游新时代的必然要求，也是转变全行业工作作风的有效举措。各地要提高认识、转变观念，结合经济社会发展实际水平，因地制宜，注重实用，倡导环保，反对奢侈浪费，避免超规格超标准建设旅游厕所。

二、采取有针对性的措施，在“厕所革命”中提倡实用避免奢华

（一）从规划标准上把好关。在厕所项目规划中要体现实用原则，反对不按规划随处建设厕所，反对不切实际的“大而全”厕所。要按照相关标准进行厕所建设与管理，突出实用、卫生、便利，不得刻意追求高标准，不得随意突破有关标准中关于设施设备的规定。

（二）从建设管理上严要求。在旅游厕所的建设管理中要注重与环境协调，注重设施完备、功能实用、通风良好、清洁卫生，避免过度装饰，鼓励选用环保建筑材料，可根据地区特点就地取材。各地要加强对旅游厕所的管理，保证厕所外观整洁，内部管理有效，干燥、干净、无异味。

（三）从示范引导上抓典型。各地要按照实用简洁原则，切实推出一批外观整洁、功能实用、干净无味、节能节水、保护环境的厕所典型，加强示范引导，促进“厕所革命”朝实用化、环保化、人性化方向发展。

（四）从培训宣传上重实效。各地在“厕所革命”培训课程设置中要充分体现因地制宜、注重实用的原则。要加大“厕所革命”宣传力度，宣传在规划、设计、建设、管理中结合当地实际、方便实用，体现人性化、节约化、环保化的典型厕所，营造“厕所革命”的良好舆论氛围。

（五）从交流推广上树经验。在与国际组织和专业协会的交流合作中，将提倡方便实用和人文关怀作为“厕所革命”的一条重要经验。在各地举办的厕所展会、博览会中，要集中展示实用型、节能节水型、环保型厕所。

三、抓好工作落实，务实推进“厕所革命”

（一）落实工作责任。各地要深入贯彻落实习近平总书记重要指示精神，分解落实“厕所革命”新三年行动计划任务，注重在“厕所革命”中提倡实用避免奢华之风，将责任落实到具体岗位和人员。

（二）加强检查督导。各地要强化对厕所建设管理的检查督导。组织厕所专家、新闻媒体开展“厕所革命”明查暗访活动，鼓励游客投诉举报，一旦发现有不切实际的奢华厕所，要及时督促整改。

（三）强化考核奖惩。各地要将提倡实用反对奢华之风作为工作考核的重要内容。对在“厕所革命”坚持从实际出发、注重厕所实用性的典型要予以奖励，对片面追求奢华，造成不当浪费的，要坚决予以纠正。
