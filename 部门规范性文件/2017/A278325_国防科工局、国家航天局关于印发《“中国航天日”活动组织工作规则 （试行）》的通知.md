# 国防科工局、国家航天局关于印发《“中国航天日”活动组织工作规则 （试行）》的通知

## 国防科工局　国家航天局关于印发《“中国航天日”活动组织工作规则 （试行）》的通知

科工一司〔2017〕823号

各有关单位：

2016年3月，中央批准、国务院批复，将每年的4月24日设立为“中国航天日”。为进一步规范和保障“中国航天日”活动的有序组织和实施，国防科工局、国家航天局研究制定了《“中国航天日”活动组织工作规则 （试行）》，现予印发。

国防科工局

国家航天局

2017年7月5日
