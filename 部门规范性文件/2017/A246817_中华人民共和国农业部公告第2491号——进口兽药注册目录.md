# 中华人民共和国农业部公告第2491号——进口兽药注册目录

## 中华人民共和国农业部公告

第2491号

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准Labiana生命科学制药厂等2家公司生产的美洛昔康注射液等3个兽药产品在我国注册，核发《进口兽药注册证书》,并发布修订后的产品质量标准、说明书和标签，自发布之日起执行。

批准印度尼西亚美迪安有限公司生产的鸡传染性法氏囊病活疫苗（D22株）等7种兽药产品在我国变更注册。

特此公告。

附件：1.进口兽药注册目录

2.质量标准（略）

3.说明书和标签

农业部

2017年1月22日
