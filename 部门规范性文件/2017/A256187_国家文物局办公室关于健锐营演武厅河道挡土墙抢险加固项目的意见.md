# 国家文物局办公室关于健锐营演武厅河道挡土墙抢险加固项目的意见

办保函〔2017〕1112号

北京市文物局：

你局《关于健锐营演武厅河道挡土墙抢险加固工程方案的请示》（京文物〔2017〕1090号）收悉。经研究，我局意见如下：

一、所报方案技术路线不合理，维修措施过度，我局暂不同意健锐营演武厅河道挡土墙抢险加固项目。

二、对该方案提出以下修改意见：

（一）应深化现状勘察和研究，进一步核实现状挡土墙残损范围，量化统计数据，如：挡土墙裂缝具体部位、开裂长度、宽度、深度及走向等。补充河道基本情况、与健锐营演武厅之间的关系说明和挡土墙现状照片。

（二）应进一步优化设计方案。坚持最小干预原则，避免过度保护。

1．进一步论证进行大规模换土和增加灰土挤密桩加固措施的必要性。建议只对紧临新砌挡土墙内侧0.5-1米内范围回填土进行夯实处理，重点做好新、旧挡土墙内侧地面的防渗及排水处理。

2．明确新砌和择砌鼓闪开裂挡土墙的厚度、收分等的砌筑标准。

3．明确采取挡土墙加厚和增设牛腿支护等措施的具体部位。

4．进一步论证全部拆砌北岸既有红机砖挡土墙的必要性，建议在现状基础上进行局部拆砌并采取加固处理措施。

（三）进一步完善文本和图纸。补充新墙与原墙衔接部位设计详图、东西河道挡土墙立面图和挡土墙上下厚度及收分标注。注意法规文件的时效性。

三、请你局组织相关单位根据上述意见，对项目方案进行修改完善后，按我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的相关要求另行报批。

专此函复。
