# 农业部对十二届全国人大五次会议第3263号建议的答复

## 对十二届全国人大五次会议第3263号建议的答复

农办议〔2017〕4号

尼玛卓玛等4位代表：

你们提出的关于科技创新驱动青海智慧生态畜牧发展的建议收悉。现就有关问题答复如下。

青海是我国重要的草原牧区和三江源头汇水区，生态地位重要而特殊。习近平总书记在青海考察时强调，青海最大的价值在生态、最大的责任在生态、最大的潜力也在生态，必须把生态文明建设放在突出位置来抓，尊重自然、顺应自然、保护自然，筑牢国家生态安全屏障，实现经济效益、社会效益、生态效益相统一。青海草原总面积5.47亿亩，其中可利用面积4.74亿亩，广阔的草原既是生态文明建设的主战场，也是农牧民发展畜牧业的重要生产资料。大力发展生态畜牧业，在持续加强草原生态保护建设的基础上，合理利用好草原发展畜牧业生产，促进牧区生产生态生活相协调，是青海省畜牧业发展的必由之路。

我部高度重视青海省生态畜牧业发展，近年来持续加大政策支持力度，努力推进青海省畜牧业可持续发展和草原生态保护建设。2014年6月，我部批复青海省设立全国首个草地生态畜牧业试验区，支持青海省创新机制，完善制度，优化生产关系，整合生产要素，统筹推进草地畜牧业转型升级和草原生态保护建设，探索传统草原畜牧业转型升级的有效路径。在政策支持上，实施草原生态补助奖励、退牧还草工程等重大政策项目，大力推进草原生态保护建设；落实牛羊大县奖励、粮改饲和标准化规模养殖场（小区）建设等资金项目，不断提升草原畜牧业发展水平。在科技支撑上，在青海设立国家肉牛牦牛、肉羊、绒毛用羊、牧草产业技术体系综合试验站，实施青藏高原社区畜牧业行业科技专项，加速畜牧业科研和技术推广进程。在机制创新上，积极支持青海省开展农业可持续发展试验示范区建设，目前青海省已确定共和等6个县开展试验示范区创建工作。下一步，我部将会同有关部门根据试验示范区评估确定指标体系开展竞争性选拔，确定国家级可持续发展试验示范区，引导青海省探索生态畜牧业可持续发展的路径和模式。

你们提出的利用三江源生态监测数据库和综合数据管理平台，推进青海省生态畜牧业信息化、智能化发展的建议，契合当前生态文明建设的方向，操作性强，我们将建议青海省有关部门积极采纳，结合草原监测等工作予以推进，我部也将根据实际工作进展情况予以支持。在支持方式上，根据《农业部办公厅 财政部办公厅关于印发〈新一轮草原生态保护补助奖励政策实施指导意见（2016—2020年）〉的通知》精神，新一轮草原补奖政策实行绩效考核奖励，中央财政每年安排绩效评价奖励资金，由地方政府统筹用于草原生态保护建设和草牧业发展。青海省可根据实际情况，利用绩效评价奖励资金开展智慧生态畜牧业发展等工作。下一步，我部将继续协助指导青海省落实好新一轮草原生态保护补助奖励政策，协调争取加大绩效评价奖励资金支持力度，促进青海草原生态保护建设和草牧业发展。

感谢你们长期以来对畜牧业工作的关心和支持，希望今后继续对我部的工作予以支持。
