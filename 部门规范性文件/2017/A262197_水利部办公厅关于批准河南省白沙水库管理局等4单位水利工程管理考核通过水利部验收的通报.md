# 水利部办公厅关于批准河南省白沙水库管理局等4单位水利工程管理考核通过水利部验收的通报

办建管函〔2017〕1494号

各流域机构,各省、自治区、直辖市水利(水务)厅(局),各计划单列市水利(水务)局,新疆生产建设兵团水利局：

根据河南、山东和江苏省水利厅的申报,依据《水利工程管理考核办法》规定,水利部委托中国水利工程协会组织专家组,于2017年11月4日至10日,分别对河南省白沙水库管理局、山东省德州市丁东水库管理处和淄博市萌山水库管理处、江苏省溧阳市大溪水库管理处进行了水利工程管理考核验收。根据考核验收结果,经审査和公示,批准上述4单位通过水利部水利工程管理考核验收,现予以通报。

水利部办公厅

2017年11月27日
