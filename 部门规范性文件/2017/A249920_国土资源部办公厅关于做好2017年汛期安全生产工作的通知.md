# 国土资源部办公厅关于做好2017年汛期安全生产工作的通知

国土资电发〔2017〕12号

各省、自治区、直辖市国土资源主管部门，中国地质调查局及部其他直属单位，各派驻地方的国家土地督察局：

为认真贯彻习近平总书记、李克强总理关于做好防灾减灾和安全生产工作的重要指示精神，落实《国务院安委会办公室关于做好2017年汛期安全生产工作的通知》（安委办〔2017〕10号）要求，进一步做好2017年汛期安全生产有关工作，严防自然灾害引发生产安全事故，为党的十九大胜利召开营造良好的安全生产环境，现就有关事项通知如下：

一、加强组织领导，及早作出安排部署

要认真贯彻落实党中央、国务院的决策部署，把做好汛期安全生产工作摆到突出位置，结合职责分工和单位实际，提前安排、超前准备、强化责任、落实措施，全力防范应对有关自然灾害引发生产安全事故。要切实加强组织领导，指定专门机构和人员负责汛期安全生产工作。

地方各级国土资源主管部门要认真落实地方人民政府的统一部署，积极配合安全监管等部门，明确重点防范区域和单位，制定有效防范应对方案和措施，把措施落实到企业，任务分解到现场。地调局及部其他直属单位要进一步落实安全生产主体责任，针对本单位安全生产工作特点，对自然灾害引发生产安全事故的风险进行全面分析和评估，制订应对方案，明确防范措施，责任落实到岗位和人员。

二、强化应急准备，做好应急响应和处置工作

要加强应急值守，严格落实领导带班制度，确保应急通信畅通，信息报告及时准确。地方各级国土资源主管部门要进一步完善汛期地质灾害防治预案，配合有关部门强化应急准备，积极配合开展应急处置工作；配合有关部门加强汛期防灾救灾减灾知识宣传，普及应急知识，提高各类企业和从业人员的防灾意识和避险、自救、互救能力。地调局及部其他直属单位要进一步完善防范自然灾害引发生产安全事故的专项应急预案，组织开展应对各类自然灾害的应急演练，储备应急所需物资、装备，加强应急装备检查维护，一旦发生灾害或事故，拉得出、用得上，把损失降到最低程度。

三、强化监测预警，完善应急联动机制

地方各级国土资源主管部门要按照地方人民政府的统一部署，加强与安全监管、气象、水利等部门的联系，进一步完善协调联动机制，切实抓好汛期地质灾害监测预警，畅通信息传递沟通渠道，积极配合有关部门建立完善自然灾害引发生产安全事故预报、预警和预防机制，强化与安全监管、气象、水利、交通运输等部门间及与相关企业的应急联动，做到信息共享、资源共享，协同应对、处置自然灾害引发生产安全事故。

地调局及部其他直属单位要及时掌握水情及恶劣天气的预测预报，超前预防、有效应对各种极端灾害天气。野外作业单位（队伍）要加强与驻地基层政府及安全监管等部门的沟通联系，确保发生灾情能互通信息，及时响应。要针对安全防范重点部位、环节，认真研判自然灾害引发生产安全事故风险，进一步完善应急预案，加强应急演练，熟悉应对措施，充实各类应急物资，确保做到响应迅速，应对有效。

四、突出重点，深入开展汛期安全检查和隐患治理

地方各级国土资源主管部门要在地方人民政府的统一领导下，按照安委办〔2017〕10号文件的部署，配合有关部门部署汛期安全检查，督促指导企业深化隐患排查治理，落实安全防范措施。要督促企业进一步加强水害隐患排查治理，对易受滑坡、泥石流等自然灾害威胁的矿山、危险化学品、建筑施工、油气输送管线等，要督促采取相应的防范措施，遇有险情发生及时撤人和停止作业，防止出现人员伤亡和危险品、油气泄漏。加大对存在地质灾害隐患的公路、铁路沿线巡查和监控力度，发现危及行车安全的，要及时通报有关部门处理。

地调局及部其他直属单位要针对本单位安全生产特点以及面临的主要事故风险，深入开展隐患排查治理和除险加固，明确汛期安全生产重点防范区域和部位，制订有效防范应对方案和措施，根据气象等条件合理安排工作任务，严防出现人员伤亡和重大财产损失。

各派驻地方的国家土地督察局要结合实际，明确责任和要求，认真排查治理安全隐患，切实做好各项防灾工作，确保安全度汛。

国土资源部办公厅
