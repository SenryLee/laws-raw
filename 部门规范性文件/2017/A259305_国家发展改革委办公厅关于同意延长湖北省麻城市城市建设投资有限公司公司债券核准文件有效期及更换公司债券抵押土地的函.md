# 国家发展改革委办公厅关于同意延长湖北省麻城市城市建设投资有限公司公司债券核准文件有效期及更换公司债券抵押土地的函

发改办财金〔2017〕2103号

湖北省发展改革委：

报来《关于麻城市城市建设投资有限公司申请延长公司债券核准文件有效期及更换公司债券抵押土地的请示》（鄂发改财贸〔2017〕504号）收悉。经研究，现函复如下。

一、同意将《国家发展改革委关于湖北省麻城市城市建设投资有限公司发行公司债券核准的批复》（发改企业债券〔2016〕359号）文件有效期延长12个月至2018年12月23日。

二、同意将本期债券增信措施变更为由发行人以其合法拥有的17宗、面积合计870225.8平方米的国有土地使用权为本期债券偿付提供抵押担保，评估价值为130135.89万元。

三、请你委督促麻城市城市建设投资有限公司按照《公司法》《证券法》《企业债券管理条例》和规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

四、请你委督促麻城市城市建设投资有限公司按要求及时做好信息披露及债券资金管理，按照核准的募投资金投向合规使用债券资金，认真落实偿债措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅

2017年12月20日
