# 国家文物局关于三门塘古建筑群——潘显模住宅修缮工程立项的意见

## 关于三门塘古建筑群——潘显模住宅修缮工程立项的意见

办保函〔2017〕178号

贵州省文物局：

你局《关于送审〈三门塘古建筑群——潘显模住宅维修工程立项报告〉的请示》（黔文物呈〔2016〕101号）收悉。经研究，我局意见如下：

一、暂不同意三门塘古建筑群——潘显模住宅修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）深化现状勘察和研究，明确文物保存现状、主要病害类型、残损情况等，深入分析屋面漏雨、木构件糟朽等病害原因，客观评估历次修缮和后期居民改造影响，进一步论证工程实施的必要性和可行性。

（二）应严格控制工程量和工程强度，合理确定木构件更换、补配的具体数量和标准。进一步论证恢复无存脊饰和室内三合土地面的必要性。

（三）补充对地方建造工艺、传统做法、建筑材料和构造特征等研究和分析，确保在维修中使用原工艺和原材料。

（四）进一步明确潘显模住宅的管理使用情况和产权现状、居住人口等，充分考虑居民的生活需要和合理诉求，科学开展建筑内部空间调整，兼顾民生改善，统筹考虑文物建筑利用问题。同时，建议考虑与利益相关方签订责任书，落实保护修缮工作的权利和责任。

（五）根据工程量合理编制经费预算，进一步核减工程造价，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促地方人民政府抓紧编制三门塘古建筑群保护规划，统筹考虑文物建筑修缮、环境整治、展示利用等工作，协调处理文物保护与地方经济发展、民生改善的关系。同时，进一步明确潘显模住宅的管理责任，根据《古建筑保养维护规程》及时开展文物日常养护和岁修工作，并采取多种方式展示、宣传文物价值，确保文物及其周边环境安全。

专此函。

国家文物局

2017年2月24日
