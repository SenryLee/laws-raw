# 国家文物局办公室关于北京华宇星园林古建设计所文物保护工程勘察设计甲级资质证书内容变更的函

办保函〔2017〕1054号

北京市文物局：

你局《关于北京华宇星园林古建设计有限公司文物保护工程勘察设计甲级资质证书名称变更的的请示》（京文物〔2017〕1098号）收悉。

经研究，我局同意北京华宇星园林古建设计所文物保护工程勘察设计甲级资质证书中的名称由“北京华宇星园林古建设计所”变更为“北京华宇星园林古建设计有限公司”，经济性质由“法人企业”变更为“有限责任公司”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局办公室

2017年9月14日
