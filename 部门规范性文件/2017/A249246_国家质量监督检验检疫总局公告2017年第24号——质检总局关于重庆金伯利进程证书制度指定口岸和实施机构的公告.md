# 国家质量监督检验检疫总局公告2017年第24号——质检总局关于重庆金伯利进程证书制度指定口岸和实施机构的公告

## 国家质量监督检验检疫总局公告

2017年第24号

## 质检总局关于重庆金伯利进程证书制度指定口岸和实施机构的公告

为深入贯彻落实“十三五”规划纲要，支持内陆地区承接产业梯度转移，加快培育重庆钻石产业竞争新优势，依照联合国框架下《金伯利进程证书制度》、金伯利进程通过的相关行政决议和《中华人民共和国实施金伯利进程国际证书制度管理规定》（质检总局2002年第42号令），现公告如下：

指定重庆机场口岸作为金伯利进程证书制度实施口岸，重庆机场出入境检验检疫局作为金伯利进程证书制度实施机构，并驻重庆两路寸滩保税港区空港功能C区，受理加工贸易项下毛坯钻石进出口申报，实施核查检验，签发金伯利进程证书及相关单证，对重庆宝玉石产业协会开展的行业自律工作进行监督管理。

特此公告。

质检总局

2017年3月14日
