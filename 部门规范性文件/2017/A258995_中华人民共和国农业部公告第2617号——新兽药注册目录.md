# 中华人民共和国农业部公告第2617号——新兽药注册目录

## 中华人民共和国农业部公告

第2617号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准中国农业科学院兰州兽医研究所等4家单位申报的猪口蹄疫O型、A型二价灭活疫苗（Re-O/MYA98/JSCZ/2013株+Re-A/WH/09株）为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年12月11日
