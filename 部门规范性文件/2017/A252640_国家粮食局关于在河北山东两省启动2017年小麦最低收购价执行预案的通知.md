# 国家粮食局关于在河北山东两省启动2017年小麦最低收购价执行预案的通知

国粮调〔2017〕125号

中国储备粮管理总公司：

你公司《关于在河北山东两省启动2017年小麦最低收购价执行预案的请示》（中储粮〔2017〕204号）收悉。根据国家发展改革委、国家粮食局等部门《关于印发小麦和稻谷最低收购价执行预案的通知》（国粮调〔2016〕55号）有关规定，经研究，同意自7月6日起在河北省和山东省启动2017年小麦最低收购价执行预案。

国家粮食局

2017年7月4日
