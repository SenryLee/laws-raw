# 中国人民银行关于发布《人民币现金机具鉴别能力技术规范》行业标准的通知

银发〔2017〕166号

中国人民银行上海总部，各分行、营业管理部，各省会（首府）城市中心支行；国家开发银行、各政策性银行、国有商业银行、股份制银行，中国邮政储蓄银行：

《人民币现金机具鉴别能力技术规范》行业标准已经全国金融标准化技术委员会审查通过，现予以发布，并就有关事项通知如下：

一、标准的编号及名称

JR/T0154-2017 《人民币现金机具鉴别能力技术规范》

二、标准自2018年1月1日起实施

请人民银行各分支机构将本通知转发至辖区内地方性银行业金融机构。

附件：人民币现金机具鉴别能力技术规范
