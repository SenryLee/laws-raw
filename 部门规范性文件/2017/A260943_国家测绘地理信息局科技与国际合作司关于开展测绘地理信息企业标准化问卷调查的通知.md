# 国家测绘地理信息局科技与国际合作司关于开展测绘地理信息企业标准化问卷调查的通知

## 关于开展测绘地理信息企业标准化问卷调查的通知

测科函〔2017〕18号

各有关测绘地理信息企事业单位：

“十二五”以来，测绘地理信息标准化不断健全工作机制，开放型标准制修订机制逐渐形成，测绘地理信息企业参与标准化的积极性明显提高。企业标准化活动在测绘地理信息生产服务中起到了重要的技术基础作用，提高了企业的产品质量和管理水平，增强了企业的核心竞争力，为事业产业转型发展和整体技术进步提供了有力的技术支撑。

“十三五”期间，测绘地理信息行政主管部门将继续为企业参与标准化工作创造有利条件。一是在国家标准和行业标准的制修订中充分发挥企业的技术创新主体作用，鼓励企业积极将成熟的企业标准、团体标准上升为国家标准和行业标准。二是鼓励企业建立完善企业标准体系，根据需要自主制定、实施企业标准，鼓励具备相应能力的社会组织和产业技术联盟协调相关市场主体共同制定团体标准，供市场自愿选用，增加标准的有效供给。三是鼓励大型龙头企业、产业技术联盟积极参与国际标准化活动，将更多具有自主知识产权的技术和产品以标准化手段推向国际舞台。

为了在今后的工作中，更好地服务企业，提升企业标准化工作水平，现对企业标准化工作现状和需求开展专项调查，业内实行企业化管理的事业单位可自愿参与。有关事项通知如下：

一、请各企业单位填写《测绘地理信息企业标准调查问卷》（见附件），于2017年5月20日前反馈我司，同时报送电子文稿。

二、本次调查范围为行业大型企业或行业领域具有代表性的企业，对于本次调研所获得企业技术信息，我们承诺承担保密责任，并在今后的标准化活动中将积极参与调研的企业单位优先发展为有关技术委员会成员单位，在企业的标准化活动中给予更多地指导与支持。

三、我司将对调查到的企业标准化情况进行梳理统计，为全国测绘地理信息标准化工作会议提供素材；并遴选部分具有自主知识产权和行业普遍适用性的企业标准、团体标准，逐步分阶段上升为行业、国家标准。
