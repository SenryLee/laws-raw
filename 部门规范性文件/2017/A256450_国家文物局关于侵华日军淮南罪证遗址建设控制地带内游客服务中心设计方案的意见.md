# 国家文物局关于侵华日军淮南罪证遗址建设控制地带内游客服务中心设计方案的意见

文物保函〔2017〕1748号

安徽省文物局：

你局《关于审批侵华日军淮南罪证遗址建设控制地带内游客服务中心设计方案的请示》（皖文物保〔2017〕77号）收悉。经研究，我局意见如下：

一、原则同意侵华日军淮南罪证遗址建设控制地带内原接待处改建成游客服务中心的设计方案一。

二、设计方案除保留原硬山墙的形式外，建议尽可能对原红砖外墙采取修缮加固，避免完全拆除后采用仿红砖饰面。

三、游客服务中心的环境设计，应避免城市园林化，其建筑高度、体量、色彩及材料须与遗址周边生态公园的自然环境相协调。

请你局指导相关单位根据上述意见对方案一进行修改完善后，按照《中华人民共和国文物保护法》第十八条规定，经城乡建设规划部门批准后实施。工程施工期间，你局应加强监管，确保文物安全。

国家文物局

2017年10月12日
