# 国家文物局关于在勉县武侯祠保护范围内进行院落排水设施工程意见的函

## 关于在勉县武侯祠保护范围内进行院落排水设施工程意见的函

办保函〔2017〕755号

陕西省文物局：

你局《关于申报勉县武侯祠院落有组织排水设施改造工程的请示》（陕文物字〔2017〕91号）收悉。经研究，我局意见如下：

一、加强文物现状勘察，补充对勉县武侯祠原有排水系统、原有院落地面的详细勘察，明确院落原有排水方式，区分原地面和后期改造地面，深入研究原有排水设施、地面铺装的建造工艺、传统做法、使用材料等，为方案设计提供科学依据。

二、根据评估结论，对仍然保存的勉县武侯祠原有排水系统和院落地面应按照文物本体保护要求进行维修，不得列为改造对象、纳入本次工程范围。

三、非文物本体的排水设施改造，因处于文物院落内，应坚持最小干预原则，严格控制地面开挖规模，避免对文物建筑造成不利影响。

1．建议进一步优化排水方式，充分考虑排水系统的清理维护需要。

2．地面重新铺装应尽量使用原材料和原铺装形式，不同意采用混凝土和水泥砂浆。

3．应补充工程实施对文物建筑的影响评估和相应保护措施，避免穿越建筑檐下、台阶和甬路的排水管道影响文物建筑安全。

4．进一步论证排水沟采用混凝土形式的必要性。

四、进一步规范文本与图纸，完善图纸标注。

五、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局审核后另行报批。

六、请你局督促地方人民政府尽快修改、完善《勉县武侯祠保护规划》，统筹考虑文物保护、环境整治、展示利用等工作，切实加强日常管理、巡查与岁修工作，确保文物本体与周边环境安全。

专此函复。

国家文物局

2017年6月16日
