# 国家发展改革委办公厅关于组织开展“互联网+”行动实施效果评估工作的通知

发改办高技〔2017〕1793号

有关省、自治区、直辖市、新疆生产建设兵团发展改革委：

为贯彻落实《国务院关于积极推进“互联网+”行动的指导意见》（国发〔2015〕40号），我委于今年8-9月组织北京市、上海市、江苏省、浙江省、广东省、贵州省等六省市，开展了“互联网+”行动实施效果评估试点工作，据初步数据统计分析，成效良好。

在上述工作基础上，为更加科学、准确、客观地反映全国“互联网+”行动实施效果，我委拟在全国范围内组织开展“互联网+”行动实施效果评估工作。请你们根据本省实际，面向农业、制造、物流和能源等重点行业，采用选取典型企业和随机抽样相结合的方式，组织300家以上企业填写分行业评估问卷，并于11月17日（周五）前将问卷或汇总后问卷数据反馈我们。

感谢对我们工作的大力支持。
