# 国家新闻出版广电总局办公厅、中国作家协会办公厅关于开展2017年优秀网络文学原创作品推介活动的通知

## 关于开展2017年优秀网络文学原创作品推介活动的通知

新广出办发〔2017〕46号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央军委政治工作部宣传局，各省、自治区、直辖市作家协会，有关网络出版服务单位：

2015年以来，国家新闻出版广电总局组织开展了年度优秀网络文学原创作品推介活动，向社会推介了一批追求真善美、传播正能量的原创作品，得到社会广泛关注和读者认可。为深入贯彻落实习近平总书记系列重要讲话精神和《中共中央关于繁荣发展社会主义文艺的意见》，进一步发挥推介作品的示范作用，引导网络文学坚持以人民为中心的创作出版导向，更好地满足读者的精神文化需求，国家新闻出版广电总局、中国作家协会决定联合组织开展2017年优秀网络文学原创作品推介活动。现就有关事项通知如下：

一、申报主体

具有国家新闻出版广电总局颁发的网络出版服务许可证、业务范围涵盖网络文学出版的网络出版服务单位；纳入中国作家协会“全国网络文学重点园地”的网络文学单位。

二、申报范围

在上述申报单位主办的网站公开发表，且于2016年8月1日至2017年7月31日期间完本的网络文学原创作品。

三、申报标准

1.坚定文化自信，振奋民族精神。坚持正确历史观、民族观、国家观、文化观，从中华文化宝库中萃取精华、汲取能量，坚守中华文化立场，传承中华文化基因，展现中华审美风范，彰显中华文化精神内涵，艺术表现中华民族的“根”与“魂”。

2.弘扬社会主义核心价值观。用精彩的故事、鲜活的语言塑造丰满的艺术形象，赞美英雄，高扬爱国主义旗帜，凝聚中国力量，构筑中国精神、中国价值，倾情抒写多彩的中国、进步的中国、团结的中国。

3.坚持以人民为中心的创作导向。以马克思主义文艺观为指导，以人民火热的现实生活为根基，把人民作为创作表现的主体，生动展现人民创造历史的伟大实践，深刻表现人民群众伟大奋斗和火热生活，奏响时代之声、爱国之声、人民之声，讴歌全国各族人民追梦圆梦的奋斗历程。

4.把社会效益放在首位。坚持社会主义先进文化前进方向，把社会效益和社会价值放在首位，抵制片面追求点击率倾向，摒弃趋利媚俗之风，反对低级趣味，讲品位、重格调，弃粗鄙、戒恶搞，塑造美好心灵，引领社会风尚，把崇高的价值、美好的情感融入笔端，努力实现社会效益和经济效益、社会价值和市场价值相统一。

5.遵从艺术规律，秉持创新精神。紧跟时代潮流，大胆探索，锐意进取，拒绝跟风写作，避免同质化创作，在题材、体裁、形式上有创新；在观念、内容、风格上有特色，富有个性化和创造性，具有吸引力和感染力。

四、申报材料

申报单位应提交下列材料：

1.填写完整的《2017年优秀网络文学原创作品推介活动作品申报表》1份；

2.《2017年优秀网络文学原创作品推介活动作品申报表》电子文档、申报作品完整内容电子文档各1份；

3.申报单位营业执照、网络出版服务许可证复印件各1份；

4.申报作品作者身份证复印件1份；

5.申报单位与作品作者直接签署的版权证明材料1份；

6.申报单位负责人、作品作者近3年无违反新闻出版法规的声明各1份。

五、申报程序及要求

1.申报单位对作品进行认真筛选和审读，按通知要求填写、汇总材料后，于2017年8月30日前报送所在地省级新闻出版广电局或省级作家协会。

2.每个单位申报作品不超过20部，书面申报材料应齐全，电子文档应能正常读取。

3.省级新闻出版广电局或作家协会审核申报材料后，于2017年9月15日前将申报材料和作品寄送至新华网股份有限公司（地址:北京西城区宣武门西大街129号金隅大厦四层新华网；邮编：100031；联系电话：010-88050873；联系人：王志艳；传真：010-88050800；邮箱：wlwxtj@126.com）。

4.国家新闻出版广电总局和中国作家协会委托新华网股份有限公司组织专家对申报作品进行评审、遴选，于2018年一季度向社会公布，并在有关媒体上进行集中宣传推介。

5.本通知及附件表格可在国家新闻出版广电总局网站（www.sapprft.gov.cn）“通知公告”栏目、中国作家网“通知”栏目（www.chinawriter.com.cn）及新华网悦读频道（www.book.news.cn）下载。

6.请各省级新闻出版广电局、作家协会高度重视，按通知要求抓紧组织开展申报工作，加强工作进度管理，逾期申报将不予受理。
