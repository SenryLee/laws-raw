# 国家文物局关于在西安城墙建设控制地带内进行西安市和平门110千伏临时应急变电站工程项目意见的函

## 关于在西安城墙建设控制地带内进行西安市和平门110千伏临时应急变电站工程项目意见的函

办保函〔2017〕757号

陕西省文物局：

你局《关于西安市和平门110千伏变电站建设项目涉及西安城墙建设控制地带的请示》（陕文物字〔2017〕114号）收悉。经研究，我局意见如下：

一、所报建设项目位于全国重点文物保护单位西安城墙建设控制地带内，存在未批先建行为，严重影响护城河及城墙历史环境风貌，相关整改不到位，我局暂不同意该建设事项。

二、对所报方案提出以下修改意见：

（一）应严格遵守《中华人民共和国文物保护法》、《西安城墙保护总体规划》、《西安历史文化名城保护条例》相关要求和陕西省人民政府关于全国重点文物保护单位西安城墙建设控制地带的相关管理规定，以及我局办保函〔2016〕98号文件要求，对该工程进行认真整改，尽可能降低对文物及历史环境的影响，确保文物及其周边环境安全。

（二）补充该工程情况说明及文物影响评估，在此基础上研提整改措施并深化相应方案设计，同时充分考虑地下建设工程对护城河护坡的影响。

三、请你局根据相关督查要求和上述意见，指导相关单位抓紧开展整改并对项目方案进行修改完善后，按程序另行报批。

四、请你局督促西安市人民政府提高文物保护意识，切实加强西安城墙文物保护管理，依法严格控制西安城墙保护范围和建设控制地带内的建设活动，妥善处理文物保护与地方经济社会发展之间的关系，确保文物安全，保护古城历史风貌。确需建设的，应严格依法履行报批手续。

专此函复。

国家文物局

2017年6月16日
