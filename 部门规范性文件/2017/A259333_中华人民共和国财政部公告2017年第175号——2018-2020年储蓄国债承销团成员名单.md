# 中华人民共和国财政部公告2017年第175号——2018-2020年储蓄国债承销团成员名单

## 中华人民共和国财政部公告

2017年第175号

根据《国债承销团组建工作管理办法》（财库〔2017〕145号）等有关规定，经第三方专家评审、社会公示、签订国债承销主协议等环节，财政部会同中国人民银行、证监会确定农业银行等40家机构为 2018-2020年储蓄国债承销团成员，中国银行等54家机构为 2018-2020年记账式国债承销团成员（名单详见附件），现予以公布。

特此公告。

附件：1.2018-2020年储蓄国债承销团成员名单

2.2018-2020年记账式国债承销团成员名单

中华人民共和国财政部

2017年12月29日
