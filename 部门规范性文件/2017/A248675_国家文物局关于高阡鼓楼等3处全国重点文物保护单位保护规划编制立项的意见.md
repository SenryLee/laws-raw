# 国家文物局关于高阡鼓楼等3处全国重点文物保护单位保护规划编制立项的意见

## 关于高阡鼓楼等3处全国重点文物保护单位保护规划编制立项的意见

办保函〔2017〕244号

贵州省文物局：

你局《关于送审2017年贵州省全国重点文物保护单位保护规划第一批立项报告的请示》（黔文物呈〔2017〕1号）收悉。经研究，我局意见如下：

一、高阡鼓楼、宰俄鼓楼、金勾风雨桥等3处全国重点文物保护单位文物构成单一，规划编制的必要性与紧迫性不足，我局暂不同意以上3处单位保护规划编制立项。

二、请你局指导地方政府结合所在地传统村落保护规划编制，统筹考虑文物保护的规划措施和要求，合理确定文物保护区划、管理规定和具体建设控制指标，严格控制、科学引导文物周边区域的建设活动。同时，应切实做好文物日常养护、巡查和岁修工作，确保文物及其周边环境安全。如发现影响文物安全的病害险情，应及时启动保护工作，并按要求履行报批程序。

专此函。

国家文物局

2017年3月14日
