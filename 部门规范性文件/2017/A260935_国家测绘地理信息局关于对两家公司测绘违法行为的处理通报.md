# 国家测绘地理信息局关于对两家公司测绘违法行为的处理通报

## 关于对两家公司测绘违法行为的处理通报

国测法发〔2017〕3号

各省、自治区、直辖市测绘地理信息行政主管部门，局所属各单位，机关各司室：

近日，国家测绘地理信息局对中航四维（北京）航空遥感技术有限公司（甲级测绘资质单位，以下简称“中航四维公司”）转包测绘项目及图符（北京）航空遥感信息技术有限公司（无测绘资质单位，以下简称“北京图符公司”）无资质测绘行为进行了调查处理，现将有关情况通报如下：

一、事件背景

2012年3月，国家基础地理信息中心、重庆市规划局、中航四维公司三方签订合同，由中航四维公司承担国家基础航空摄影重庆市摄区项目。2012年5月，中航四维公司与北京图符公司签订合同，将该项目转包给北京图符公司。2012年6月至2013年12月，北京图符公司完成该项目，并将测绘成果提交给中航四维公司。2013年12月，国家基础地理信息中心对中航四维公司提交的该项目成果进行了验收，出具了验收合格报告。中航四维公司将承包的测绘项目转包和北京图符公司无测绘资质从事测绘活动的行为，分别违反了《中华人民共和国测绘法》第二十四条和第二十二条的规定，扰乱了测绘市场秩序，造成了不良影响。

二、处理措施

根据《中华人民共和国行政处罚法》第二十九条关于追责时效的规定，中航四维公司与北京图符公司测绘违法行为至今已超过二年追责时效，依法不再给予行政处罚。为严肃法纪，国家测绘地理信息局决定对上述两家公司给予以下处理：

（一）约谈中航四维公司和北京图符公司主要负责人，对其予以严肃批评教育。

（二）依据《测绘地理信息行业信用管理办法》和《测绘地理信息行业信用指标体系》，将中航四维公司转包测绘项目行为纳入该单位严重失信信息，记入测绘地理信息行业信用管理平台向社会发布。自该信息生效之日起两年内，中航四维公司不得申请新增测绘专业范围。

（三）将中航四维公司和北京图符公司测绘违法情况通报国家工商行政管理总局，记入国家企业信用信息公示系统。

（四）依据《国家基础航空航天影像获取业绩与诚信考核办法》有关规定，取消中航四维公司2017－2018年国家基础航空摄影项目投标资格。

（五）将北京图符公司涉嫌非法获取、持有国家秘密载体情况通报国家保密局，依照保密管理法律法规予以处理。

（六）将中航四维公司列为2017年度重点监管对象，对其测绘资质、质量、成果保密等情况进行全面检查。

三、工作要求

国家测绘地理信息局对中航四维公司和北京图符公司测绘违法行为的处理，贯彻了国务院“放管服”改革要求，是加强事中事后监管、全面推进依法行政的具体体现。

各级测绘地理信息行政主管部门要充分发挥这起负面典型的警示教育作用，举一反三，加强对本行政区域内测绘资质单位及测绘项目的监督检查，对测绘违法行为发现一起、处理一起，加大失信惩戒和公开曝光力度，形成“零容忍”震慑态势。要进一步加大测绘地理信息法治宣传教育力度，增强测绘资质单位及其从业人员尊法学法守法用法的意识，强化行业自律，谴责失信失德行为，促进市场公平竞争，保障测绘地理信息事业健康发展。
