# 国家文物局关于焦作当阳峪窑址窑炉遗址抢救性保护工程方案的意见

## 关于焦作当阳峪窑址窑炉遗址抢救性保护工程方案的意见

办保函〔2017〕15号

河南省文物局：

你局《关于上报焦作当阳峪窑址窑炉抢救性保护工程方案的请示》（豫文物〔2016〕286号）收悉。经研究，我局意见如下：

一、暂不同意焦作当阳峪窑址窑炉遗址抢救性保护工程方案。

二、所报方案应做以下必要的修改和完善：

（一）进一步深化遗址病害成因分析，了解遗址原基础形式和埋深，校核地基承载力和基底压力，查找不均匀沉降原因。同时，应补充不稳定斜坡的稳定性计算评价，并进一步明确其成因。

（二）进一步明确实施锚杆及灌浆加固的具体位置，补充锚杆设计图纸。

（三）完善抗滑桩设计，补充滑动体推力计算，科学设计抗滑桩位置和尺寸。同时，应严格细化施工措施，完善相关应急预案，抗滑桩应采取无振动无水施工工艺，确保遗址安全。

（四）保护性设施改建应进一步严格控制建筑规模、体量和高度，并注意与遗址及其周边环境相协调。进一步完善方案图纸，补充建筑设计效果图。

三、请你局指导方案设计单位联合专业考古研究单位，按照上述意见对方案进行修改和完善，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局
