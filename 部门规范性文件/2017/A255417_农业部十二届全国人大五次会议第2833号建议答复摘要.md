# 农业部十二届全国人大五次会议第2833号建议答复摘要

## 十二届全国人大五次会议第2833号建议答复摘要

一、关于加大产业结构调整力度问题

2015年以来，农业部联合相关部门大力推进农业供给侧结构性改革，先后印发了《关于进一步调整优化农业结构的指导意见》《全国种植业结构调整规划（2016—2020年）》等文件，指导各地因地制宜调减非优势区玉米，改种大豆、杂粮杂豆、马铃薯、优质饲草等作物。

2015年，农业部制定印发《关于“镰刀弯”地区玉米结构调整的指导意见》，提出到2020年“镰刀弯”地区调减玉米面积5000万亩以上。2015年，国家启动实施粮改饲试点工作，2016年中央财政安排资金10亿元，比2015年增加7亿元，扩大政策覆盖面。

二、关于加大对农村产业项目带头人扶持问题

中央财政安排了农民合作社专项转移支付资金，重点支持以国家示范社为主的各类农牧民专业合作社发展。农业部正在牵头起草《关于加快构建政策体系培育新型农业经营主体的意见》，加大扶持力度，引导农民合作社等新型农业经营主体多路径提升规模经营水平。

三、关于帮助合作社和农业项目带头人解决市场经营过程中资金困难问题

2013年，人民银行出台《关于加大金融创新力度支持现代农业加快发展的指导意见》，鼓励金融机构对种植粮食类农业经营主体，开展农机具抵押、存货抵押、大额订单质押、涉农直补资金担保、土地流转收益保证贷款等业务。农业部在拟出台的《关于加快构建政策体系培育新型农业经营主体的意见》中提出，要综合运用税收、奖补等政策，鼓励金融机构创新产品和服务，加大对新型农业经营主体、农村产业融合发展的信贷支持。
