# 国家文物局关于三元宫遗址本体保护工程立项的意见

## 关于三元宫遗址本体保护工程立项的意见

办保函〔2017〕203号

湖南省文物局：

你局《关于审批三元宫遗址本体保护工程立项的请示》（湘文物报〔2016〕206号）收悉。经研究，我局意见如下：

一、暂不同意三元宫遗址本体保护工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步梳理工程内容，明确工程性质，区分本体保护和环境整治工程。环境整治工程应按照涉及三元宫遗址保护范围和建设控制地带的建设项目，单独另行申报。

（二）加强现状勘察和评估，进一步明确鱼塘、沟渠及乔、灌木植被对遗址的影响程度和范围，说明回填鱼塘、沟渠和清除植被措施的必要性，明确植被清除措施的安全性和可行性。

（三）补充遗址保护规划中关于本体保护工程的具体内容和要求。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局
