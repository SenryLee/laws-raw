# 中华人民共和国住房和城乡建设部公告第1612号——住房城乡建设部关于2017年第十一批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

第1612号

## 住房城乡建设部关于2017年第十一批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，李莹等84名申报注册土木工程师（岩土）初始注册人员、陈越等191名申报一级注册结构工程师初始注册人员、江岸等216名申报注册公用设备工程师初始注册人员、李旭等127名申报注册电气工程师初始注册人员、赵鉴楚等54名申报注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予李莹等84名注册土木工程师（岩土）初始注册人员名单

2.准予陈越等191名一级注册结构工程师初始注册人员名单

3.准予江岸等216名注册公用设备工程师初始注册人员名单

4.准予李旭等127名注册电气工程师初始注册人员名单

5.准予赵鉴楚等54名注册化工工程师初始注册人员名单

住房城乡建设部

2017年7月19日
