# 国家文物局关于城四家子城址展示利用工程立项的意见

## 关于城四家子城址展示利用工程立项的意见

办保函〔2016〕1384号

吉林省文物局：

你局《关于城四家子遗址展示利用工程立项的请示》（吉文物发〔2016〕242号）收悉。经研究，我局意见如下：

一、暂不同意城四家子城址展示利用工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步论证拟采取技术路线的适用性和可行性，客观评估遗址保护利用前景并进一步分析遗址原位露明展示的必要性和可行性。

（二）加强展示利用的系统性和整体性，进一步明确展示重点，选取保存较好的典型点段进行展示。

（三）简化展示道路设计，注意控制工程规模、范围和强度，减少对遗址的干预。

（四）涉及城墙本体的工作应与已批准的本体保护工程方案进行衔接，避免重复工作。

（五）展陈及考古工作用房建设应按程序单独报审。

（六）严格控制工程预算，补充预算依据，科学编制预算。

三、请你局指导立项报告编制单位，根据上述意见对所报立项报告做进一步修改和完善，经你局核准后，按程序另行报批。

四、请你局督促地方人民政府切实加强城四家子城址的保护和管理，做好日常巡查和看护，确保遗址安全。

国家文物局

2017年1月4日
