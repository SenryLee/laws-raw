# 国家烟草专卖局关于批转湖南中烟工业有限责任公司查处16家供应商串通投标行为情况通报的通知

国烟办〔2017〕337号

行业各直属单位，中国烟草实业发展中心:

今年6月至7月间，湖南中烟工业有限责任公司招标监督人员和招标人代表先后在四个招标项目(预算金额共计482.2万元)中发现16家供应商串通投标线索。湖南中烟工业有限责任公司党组对此问题高度重视，立即协调政府监管部门进行查处，并根据湖南省发展和改革委员会《关于通报16家企业招标投标违规行为情况的公告》印发了《湖南中烟工业有限责任公司关于查处16家供应商串通投标行为情况的通报》（湘烟工〔2017〕178号），全面禁止16家供应商在6个月内参与湖南中烟工业有限责任公司新采购项目。湖南中烟工业有限责任公司通过及时发现和打击供应商串通投标行为，有力保障了“真招实招”，大大减少了企业的经济损失，有效维护了企业的合法权益。

现将《湖南中烟工业有限责任公司关于查处16家供应商串通投标行为情况的通报》批转给你们，请认真汲取经验教训，并在规范管理工作中切实做到“五个进一步”：进一步增强规范管理意识，充分认识规范管理工作的长期性、艰巨性、复杂性，始终把“严格规范”作为保持行业持续健康发展的“生命线”紧抓不放；进一步落实“三个保障机制”，切实提高“真招实招”水平，努力解决公开招标“三大顽疾”，有效防治工程项目、物资采购等重点领域的系统性廉洁风险；进一步推动采购管理信息化建设，积极贯彻落实《烟草行业采购管理信息系统建设操作规范》（国烟办综〔2017〕499号），以信息化为有力抓手全面提升规范管理水平；进一步加大规范管理全覆盖力度，建立常态化监督检查机制，及时发现问题，纠正问题，有效避免同类问题再次发生；进一步强化责任追究，在明确责任的基础上层层传导压力，级级压实责任，对违法违规行为发现一起，处理一起，决不姑息，决不手软，切实通过责任追究倒逼责任落实。
