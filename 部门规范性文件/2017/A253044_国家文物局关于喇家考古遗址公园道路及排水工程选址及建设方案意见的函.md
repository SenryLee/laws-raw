# 国家文物局关于喇家考古遗址公园道路及排水工程选址及建设方案意见的函

## 关于喇家考古遗址公园道路及排水工程选址及建设方案意见的函

办保函〔2017〕631号

青海省文物局：

你局《关于上报喇家国家考古遗址公园道路及排水工程施工设计的请示》（青文物局〔2017〕52号）收悉。经研究，我局意见如下：

一、暂不同意所报喇家考古遗址公园道路及排水工程选址及建设方案。

二、所报方案尚需做以下必要的修改和完善：

（一）优化道路设计，坚持遗址区禁止车行、步行为主的思路，不得建设南北贯通遗址区的车行主路，建议与遗址区外围的环路统筹考虑。环路应根据功能需求进一步简化，尽量避免在遗址区形成过于稠密的路网。

（二）人行道路宽度宜控制在2米之内，道路形式及材料应充分考虑与考古遗址公园内的景观环境及氛围相协调。

（三）排水工程应以地面排水为主，尽量不布设大型防排水工程。

（四）补充说明工程拟建区域地下文物遗存的分布情况，并据此优化建设工程选址，尤其是深挖排水管线工程的选址，应当避让重要地下文物遗存。如有必要，应开展考古勘探工作。

（五）应针对此次建设工程开展专门的文物影响评估，切实说明此次建设工程对遗址所产生的影响。

三、请你局指导建设单位，根据上述意见对所报方案作进一步修改和完善，做好文物影响评估，经你局核准后，按程序另行报批。

国家文物局

2017年5月24日
