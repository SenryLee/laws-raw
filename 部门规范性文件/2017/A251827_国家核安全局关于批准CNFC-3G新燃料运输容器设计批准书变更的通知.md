# 国家核安全局关于批准CNFC-3G新燃料运输容器设计批准书变更的通知

## 关于批准CNFC-3G新燃料运输容器设计批准书变更的通知

国核安发〔2017〕125号

中国核电工程有限公司：

你公司《关于CNFC-3G新燃料运输容器内容物初始富集度变更的请示》（核工经发〔2017〕2号）收悉。

根据《放射性物品运输安全管理条例》及其配套规章《放射性物品运输安全许可管理办法》的有关要求，我局审查了你公司提交的CNFC-3G新燃料运输容器设计批准书变更申请材料，批复如下：

一、同意放射性内容物特性变更。

放射性内容物特性应满足下列条件之一：

（一）当U-235最高初始富集度≤4.60%时，最多装载2组AFA 3G新燃料组件；

（二）当4.60%＜U-235初始富集度≤4.95%，最多装载2组AFA 3G新燃料组件，且每组燃料组件中应至少含有4根氧化钆可燃毒物棒。

二、设计安全分析报告升版为D版。

三、CNFC-3G新燃料运输容器设计批准书（国核安发〔2016〕276号）其余内容不变。

国家核安全局

2017年6月26日
