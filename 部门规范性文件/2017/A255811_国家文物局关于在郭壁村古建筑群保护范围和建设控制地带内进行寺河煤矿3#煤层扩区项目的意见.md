# 国家文物局关于在郭壁村古建筑群保护范围和建设控制地带内进行寺河煤矿3#煤层扩区项目的意见

文物保函〔2017〕1474号

山西省文物局：

你局《关于审批山西晋城无烟煤矿业集团有限责任公司寺河煤矿3#煤层扩区文物保护方案的请示》（晋文物〔2017〕155号）收悉。经研究，我局批复如下：

一、原则同意在郭壁村古建筑群保护范围和建设控制地带内进行寺河煤矿3#煤层扩区项目和你局意见。

二、对所报方案提出以下修改意见：

（一）拟建项目处于全国重点文物保护单位郭壁村古建筑群保护范围和建设控制地带的地下区域，煤矿开采对文物构成影响。保护方案应以确保文物安全为重点，严格控制开采范围，尽量减少煤矿开采对文物的影响。

（二）补充矿区地质构造勘察，校核采空区移动角，确定3#和15#煤层留设柱具体范围。

（三）优化方案设计，适当加大文物保护范围内地下留设柱的密度和宽度。进一步论证其他文物点按照保护范围边界基线外延20米确定煤柱范围的科学性，建议适当增大留设柱的范围，确保文物本体安全。

（四）建议研究适当扩大文物保护单位地下保护范围的可行性，如：以建设控制地带为基线向外向下斜射，将坡形塌陷线角由30度（即采空区移动角60度）调整为45度，确保文物安全。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后按《文物保护法》第十七条、第十八条的有关规定分别报山西省人民政府、城乡建设规划部门批准后实施。煤矿开采过程中请加强监管，确保文物安全。

此复。

国家文物局

2017年8月21日
