# 国家文物局关于北苑御焙遗址保护设施建设工程的意见

## 关于北苑御焙遗址保护设施建设工程的意见

办保函〔2017〕528号

福建省文物局：

你局《关于报送北苑御焙遗址保护设施建设工程设计方案的请示》（闽文物字〔2017〕61号）收悉。经研究，我局意见如下：

一、暂不同意北苑御焙遗址保护设施建设工程涉及北苑御焙遗址保护范围的选址方案。

二、所报方案尚需做以下必要的修改和完善：

（一）补充北苑御焙遗址文物遗存的分布情况，充分分析河流对文物遗存安全的影响，并在此基础上进一步补充说明进行河道整治和防排洪工程建设的必要性。同时，应补充必要的局部图纸，说明拟建河道整治项目与文物遗存的关系。

（二）进一步优化河道整治和防排洪工程的方案设计，注意与遗址及其周边环境相协调。

（三）消防工程应按程序单独报批。

三、请你局指导建设单位根据上述意见，对所报方案做进一步修改和完善，做好文物影响评估，经你局核准后按程序另行报批。

国家文物局

2017年5月8日
