# 国家烟草专卖局办公室关于建立青年托举人才责任导师培养机制的通知

国烟办综〔2017〕283号

行业各直属单位，中国烟草机械集团有限责任公司，中国烟草实业发展中心：

为推进中国科协“青年人才托举工程”入选人才的培养发展，国家局决定建立并实施青年托举人才责任导师培养机制。现将有关事项通知如下。

一、国家局根据青年托举人才的科研专业方向，从行业科技领军人才、学科带头人、科技重大专项首席专家中选定谢剑平等20位行业内外知名专家，分别作为青年托举人才的责任导师（见附件）。责任导师负责指导青年托举人才科研创新工作，以行业重大科研任务为主要载体，以责任导师提携领路为主要方式，协调并支持青年托举人才参与责任导师主持的行业重大科研攻关，指导青年托举人才独立承担科研项目，指导青年托举人才参加国内外高水平学术交流，加快提升青年托举人才的科研创新能力。

二、青年托举人才所在单位要充分发挥人才培养使用的主体作用，为青年托举人才干事创新、成就业绩创造条件、提供保障，充分关心人才成长、关心人才进步、关心人才生活。所在单位要积极配合并推进青年托举人才责任导师制培养，从本单位高层次人才中为青年托举人才遴选相应的科研业务导师，为青年托举人才搭建适合其发展的科研创新团队，帮助青年托举人才在科研创新能力、团队协作能力、个人综合素质等方面不断提升，支持助力青年托举人才成长。

三、加强青年托举人才培养的平台保障、资金保障和组织保障。在总公司科技项目计划中增设“青年人才托举项目计划”，为青年托举人才成长发展提供持续性、长期性的项目和资金支持。

四、青年托举人才要充分把握科研的“黄金期”，潜心研究，刻苦探索，力争做出突出业绩，努力成长为行业乃至国家科技领域高层次领军人才和学科带头人。
