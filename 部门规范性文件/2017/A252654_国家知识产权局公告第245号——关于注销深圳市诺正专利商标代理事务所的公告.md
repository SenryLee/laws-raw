# 国家知识产权局公告第245号——关于注销深圳市诺正专利商标代理事务所的公告

## 国家知识产权局公告

第245号

## 关于注销深圳市诺正专利商标代理事务所的公告

根据《专利代理条例》和《专利代理管理办法》的规定，依当事人申请，在其已经妥善处理各种尚未办结的事项后，我局同意注销深圳市诺正专利商标代理事务所（普通合伙）。

特此公告。

国家知识产权局

2017年6月23日
