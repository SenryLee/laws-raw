# 教育部关于张来斌等职务任免的通知

教任〔2017〕96号

中国石油大学（北京）：

2017年8月31日研究决定：

任命张来斌为中国石油大学（北京）校长，吴小林、陈大恩、张士诚、鲍志东为中国石油大学（北京）副校长，李根生、董朝霞、韩尚峰为中国石油大学（北京）副校长（试用期一年）；免去徐春明、庞雄奇的中国石油大学（北京）副校长职务。
