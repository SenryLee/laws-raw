# 国家文物局关于省级文物保护单位大风歌碑异地保护项目的意见

文物保函〔2017〕1587号

江苏省文物局：

你局《关于省级文物保护单位大风歌碑异地保护的请示》（苏文物保〔2017〕226号）收悉。经研究，我局意见如下：

一、原则同意所报大风歌碑异地保护项目和你局意见。

二、对该项目提出以下意见：

（一）应进一步细化大风歌碑迁移过程中各环节的具体保护措施，防止碑体折裂破损和表面磨损等，确保文物本体安全。

（二）不同意对大风歌碑表面实施清理措施和加固处理。可适当对碑体裂缝进行加固。

三、请你局指导有关单位根据上述意见对方案进行修改、完善，并根据《中华人民共和国文物保护法》第20条的规定报江苏省人民政府批准实施。迁移过程中应加强监管和监测，确保工程质量和文物安全。

专此函复。

国家文物局

2017年8月24日
