# 国家粮食局关于在湖南省启动2017年早籼稻最低收购价执行预案的通知

国粮调〔2017〕156号

中国储备粮管理总公司：

你公司《关于在湖南省启动2017年早籼稻最低收购价执行预案的请示》（中储粮〔2017〕262号）收悉。根据国家发展改革委、国家粮食局等部门《关于印发小麦和稻谷最低收购价执行预案的通知》（国粮调〔2016〕55号）有关规定，经研究，同意自8月16日起在湖南省启动2017年早籼稻最低收购价执行预案。

国家粮食局

2017年8月15日
