# 中共教育部党组关于陶韶菁等同志职务任免的通知

教党任〔2017〕187号

中共华南理工大学委员会：

经与中共广东省委商得一致，2017年7月24日研究决定：

陶韶菁同志任中共华南理工大学委员会副书记，李正、吴业春同志任中共华南理工大学委员会常委；免去彭新一、彭说龙同志的中共华南理工大学委员会常委职务。

中共教育部党组

2017年8月1日
