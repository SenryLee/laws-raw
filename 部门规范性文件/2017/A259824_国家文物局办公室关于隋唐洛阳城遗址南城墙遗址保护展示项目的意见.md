# 国家文物局办公室关于隋唐洛阳城遗址南城墙遗址保护展示项目的意见

办保函〔2017〕1464号

河南省文物局：

你局《关于再次上报隋唐洛阳城外郭城南城墙遗址保护展示工程设计方案的请示》（豫文物〔2017〕274号）收悉。经研究，我局意见如下：

一、所报方案深度不足，未能充分说明项目实施的可行性，我局暂不同意所报隋唐洛阳城外郭城南城墙遗址保护展示工程设计方案。

二、所报方案尚需做以下必要的修改和完善：

（一）隋唐洛阳城外郭城南城墙遗址规模较大，应结合洛阳现代城市功能布局统筹考虑南城墙遗址保护展示工作，建议以带状城市公园的思路开展整体设计，增强各展示区段和不同展示手法之间的系统性、连贯性和协调性。

（二）调整项目范围，将护城河遗迹纳入保护展示对象。

（三）补充最新的考古工作成果，并做有针对性的梳理与分析，说明地下文物遗存的性质、分布及保存情况。

（四）补充现状勘察，说明项目范围内地物现状，并具体分析项目可行性。

（五）深化设计内容，补充各区段的具体设计内容及拟采取的工程措施，并校核工程量；配套基础设施建设项目应补充说明选址、线路走向和具体占地范围。

（六）不同意采用露明覆罩方式展示东西角楼和厚载门节点。

（七）考古工作内容不应纳入本设计。

（八）补充相应的图纸。

三、请你局指导方案设计单位，根据上述意见对所报方案作进一步修改和完善后，按程序另行报批。

国家文物局办公室

2017年12月29日
