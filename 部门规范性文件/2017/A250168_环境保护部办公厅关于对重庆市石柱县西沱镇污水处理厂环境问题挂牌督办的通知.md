# 环境保护部办公厅关于对重庆市石柱县西沱镇污水处理厂环境问题挂牌督办的通知

## 关于对重庆市石柱县西沱镇污水处理厂环境问题挂牌督办的通知

环办环监〔2017〕40号

重庆市环境保护局：

2017年3月，我部联合你局对石柱县西沱镇污水处理厂进行现场检查，发现该厂存在不正常运行问题。我部决定对石柱县西沱镇污水处理厂不正常运行问题进行挂牌督办。

请你局督促相关单位落实督办要求（见附件），完成督办任务后，由你局向我部提出解除挂牌督办的书面申请并附相关材料。我部将适时赴现场进行核查。

联系人：环境保护部环境监察局 阮仁节

电话：（010）66556434

传真：（010）66556475

附件：环境问题基本情况及督办要求

环境保护部办公厅

2017年5月5日

附件

## 环境问题基本情况及督办要求

基本情况：该厂未按环境影响评价报告批复要求在污水排放口安装流量计、在线监控装置等设备，未建设接触消毒池；污泥池建设不规范，且没有污泥产生与转移记录；生产运行记录、药剂采购单据及使用记录缺失，内部管理较混乱，运行不正常。

督办要求：责成当地环保部门对上述的环境违法行为依法处理处罚，并进一步加强环境监管；督促石柱县人民政府对该厂未按环评批复要求建设相关环保设施、管理不到位等问题按要求整改到位。

督办期限：2017年6月30日前完成督办事项。
