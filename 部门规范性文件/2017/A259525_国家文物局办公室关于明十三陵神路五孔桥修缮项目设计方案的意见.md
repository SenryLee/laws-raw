# 国家文物局办公室关于明十三陵神路五孔桥修缮项目设计方案的意见

办保函〔2017〕1424号

北京市文物局：

你局《关于明十三陵神路五孔桥修缮工程方案的请示》（京文物〔2017〕1089号）收悉。经研究，我局意见如下：

一、暂不同意明十三陵神路五孔桥修缮项目设计方案。

二、所报方案需做以下修改完善：

（一）深化前期勘察研究，客观评估五孔桥的结构稳定性，分析桥体病害成因及S212省道运行期间的振动影响，核实桥体建造材料、工艺，为制定设计方案提供科学依据。补充桥梁结构检测报告和现状病害照片。

（二）明确“归安”和“补砌”构件与桥体稳定构件之间的工程技术措施，细化砖拱券裂缝的维修方法；不建议使用“水硬性石灰”等填缝材料，可粘接处理桥体局部断裂石构件。

（三）进一步论证设置西侧挡土墙的必要性和可行性，注意与桥体及周边环境风貌相协调。同时，应进行必要试验数据分析，确定五孔桥和S212省道的安全距离。

三、具体方案由你局指导有关单位按照上述意见进行修改、完善并经你局批准后实施。

四、请你局加强监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局指导有关单位进一步研究S212省道对五孔桥安全的影响，督促地方人民政府采取有效措施，确保文物安全。

国家文物局办公室
