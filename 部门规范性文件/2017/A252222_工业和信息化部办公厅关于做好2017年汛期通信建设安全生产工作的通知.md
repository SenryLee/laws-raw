# 工业和信息化部办公厅关于做好2017年汛期通信建设安全生产工作的通知

工信厅通信函〔2017〕375号

各省、自治区、直辖市通信管理局，中国电信集团公司、中国移动通信集团公司、中国联合网络通信集团有限公司、中国铁塔股份有限公司，相关单位：

近年来我国暴雨、大风、雷电等气象灾害多发频发，对安全生产影响较大。2017年6月10日，四川省华蓥市一通信铁塔基坑作业点因连日暴雨，在施工过程中发生事故，致4人死亡，事故详细原因仍在调查之中。为深刻吸取事故教训，举一反三，进一步落实各项安全生产措施，有效防范和坚决遏制类似事故发生，现提出以下要求：

一、牢固树立安全生产红线意识。各单位要深入贯彻落实党中央、国务院决策部署，把汛期安全生产工作摆到突出位置，始终把人民群众的生命安全放在首位。坚持安全第一、预防为主、综合治理，坚决克服麻痹大意和侥幸思想，严格遵守安全生产法律法规和相关规定，依法承担建设工程安全生产责任。要加强安全生产宣传教育，提升从业人员安全生产意识和技术水平。要对本地区自然灾害引发建设工程安全事故的风险进行全面分析评估，明确重点防范区域和环节，制定有效防范应对方案和措施。

二、切实加强施工现场安全管理。汛期洪水、滑坡、垮塌和泥石流等危险及有限空间有毒有害气体积聚隐患增多，工程施工难度和危险增大。各企业要严格落实安全生产主体责任，严格按照工程建设强制性标准和安全生产操作规范进行施工作业，及时了解气象灾害预警信息，充分考虑极端天气对工程建设的影响，严禁抢工期、赶进度等危及安全生产的行为，施工现场必须由安全生产考核合格的人员对安全生产进行监督。有限空间作业时，必须严格实行作业审批制度，严禁擅自进入有限空间作业；必须做到“先通风、再检测、后作业”，严禁通风、检测不合格作业；必须配备个人防中毒窒息等防护装备，设置安全警示标识，严禁无防护监护措施作业；必须制定应急措施，现场配备应急装备，严禁盲目施救。对存在洪水、滑坡、垮塌和泥石流等威胁的，要按规定采取防范应对措施。雷雨、大风等极端天气时，要按规定立即停止室外高空作业，要落实对塔吊等大型起重机械防风抗滑等相关措施。井下、高空、用电作业时，必须配备有害气体探测仪、防护绳、防触电等用具。

三、深入开展安全生产隐患排查。各企业要针对在建工程全面开展隐患排查治理，对发现的隐患建立台账，制定整改方案并逐一落实，在重大事故隐患排除前或者排除过程中无法保证安全的，应从危险区域内撤出作业人员。要建立完善事故应急救援预案，开展应急演练和人员避险自救培训，提升现场应急处置能力。各通信管理局要进一步强化监管检查，加大对重点地区和重点工程施工现场的抽查力度，特别是对施工工地、职工宿舍、临建设施等防汛防火重点部位，对通信线路人井内施工、架空杆路及铁塔施工等安全事故易发工程进行重点检查，对发现的问题和隐患要限期整改，跟踪落实。

四、严格落实事故报告制度。发生生产安全事故后，相关企业应当立即启动事故处理应急预案，采取有效措施，防止事故扩大，减少人员伤亡和财产损失，并按要求向当地政府安全生产监督管理部门和所在地通信管理局报告。通信管理局要按要求上报生产安全事故情况，及时跟踪事故救援进展情况，配合有关部门做好事故的调查处理，监督事故相关责任单位严格落实处理决定。

请各省（区、市）通信管理局、各电信企业总部于2017年7月31日前，将本地区、本企业通信建设工程安全生产隐患排查治理情况报部（信息通信发展司）。

工业和信息化部办公厅
