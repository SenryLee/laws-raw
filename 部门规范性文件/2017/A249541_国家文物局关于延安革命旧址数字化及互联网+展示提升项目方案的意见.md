# 国家文物局关于延安革命旧址数字化及互联网+展示提升项目方案的意见

## 关于延安革命旧址数字化及互联网+展示提升项目方案的意见

办保函〔2017〕319号

陕西省文物局：

你局《关于呈报延安革命旧址数字化及互联网+展示提升工程方案的请示》（陕文物字〔2016〕247号）收悉。经研究，我局意见如下：

一、暂不同意延安革命旧址数字化及互联网+展示提升工程方案。

二、该方案尚需从以下方面进行修改和完善:

（一）从延安革命旧址的文物价值、特点、展示现状及存在的问题、开放规模及管理水平等方面进一步分析论证项目的必要性和可行性。

（二）进一步阐述VR虚拟场景、增强虚拟现实、720云展示体验、通讯移动端数字展示等立项内容对于目前现状展示的具体提升作用，以及可为此提供必要支撑的历史研究成果。应根据实际情况分析说明适用上述展示手段的旧址范围，避免为了使用新技术而对历史进行臆造或演绎。

（三）鉴于目前我国尚缺乏互联网+革命文物展示方面的实践先例，可结合旧址自身条件现行开展小范围试点项目，跟踪观察评估实际效果，不断调整改进思路和技术路线，摸索并积累经验，逐步实现更大范围内的项目拓展。

（四）关于硬件开发，应进一步明确平台软件和系统功能，确保其稳定性、安全性和实用性，避免过渡开发建设。

（五）影视片拍摄不属于互联网+展示项目范畴，相关内容用应予剔除。

三、请你局指导有关单位根据上述意见对设计方案进行必要的调整和完善，另行报批。

国家文物局

2017年3月27日
