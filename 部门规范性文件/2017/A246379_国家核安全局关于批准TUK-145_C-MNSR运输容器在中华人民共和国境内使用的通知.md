# 国家核安全局关于批准TUK-145/C-MNSR运输容器在中华人民共和国境内使用的通知

## 关于批准TUK-145/C-MNSR运输容器在中华人民共和国境内使用的通知

国核安发[2017]2号

俄罗斯松树科学生产有限责任公司:

你公司《关于申请在中华人民共和国境内使用TUK-145/C-MNSR型放射性物品运输容器的请示》（07-85/1808）收悉。

你公司TUK-145/C-MNSR运输容器已取得俄罗斯设计批准，设计批准编号：RUS/3228/B(U)F-96T。根据《中华人民共和国放射性物品运输安全管理条例》的要求，我局核查了TUK-145/C-MNSR运输容器在原设计批准国取证的相关资料。现批复如下：

一、同意原编码为2的TUK-145/C-MNSR运输容器在中华人民共和国(以下简称中国）境内使用，在中国境内使用的编码为CN/054/B(U)F-96(NNSA)100NO.01，该编码必须清晰地标记在运输容器表面。

二、运输容器的使用应满足俄罗斯设计批准中相应的限值和条件要求。

三、中国原子能科学研究院应按照该运输容器入境使用申请过程中的各项承诺开展工作，确保在中国境内安全使用。

四、本批准在该运输容器设计批准有效期内有效。

国家核安全局

2017年1月4日
