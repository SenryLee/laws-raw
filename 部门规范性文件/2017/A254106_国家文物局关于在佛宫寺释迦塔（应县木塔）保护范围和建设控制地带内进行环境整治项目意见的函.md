# 国家文物局关于在佛宫寺释迦塔（应县木塔）保护范围和建设控制地带内进行环境整治项目意见的函

## 关于在佛宫寺释迦塔（应县木塔）保护范围和建设控制地带内进行环境整治项目意见的函

办保函〔2017〕882号

山西省文物局：

你局《关于审批应县佛宫寺释迦塔环境整治工程初步设计方案的请示》（晋文物〔2017〕111号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位佛宫寺释迦塔（应县木塔）的保护范围和建设控制地带内，方案设计思路不明确，对文物周边环境的干预过多，缺乏必要的设计依据，我局暂不同意佛宫寺释迦塔环境整治项目。

二、该方案应进行必要的修改和完善：

（一）应从佛宫寺释迦塔文物本体保护管理和展示利用的实际需要出发，进一步明确环境整治项目的必要性和可行性。补充山西省人民政府公布的《佛宫寺释迦塔保护规划（2011-2025）》关于保护范围和建设控制地带的管理规定、具体控制要求和工程设计依据。重新调整设计思路，根据保护规划要求和近期规划重点，合理确定项目内容，统筹考虑文物周边区域的环境整治和设计，确保文物本体安全，妥善保护文物周边环境。

（二）进一步深化方案设计，明确排水工程与地面绿化的关系，补充既有建筑的拆改措施。

（三）补充文物影响评估报告，客观、准确地论证拟建项目对文物本体和环境风貌的影响，科学研提方案调整建议。

（四）进一步规范文本与图纸，补充文物保护区划图和保护区划与工程范围的叠加图。

三、请你局督促当地人民政府按照我局《关于请进一步加强云冈石窟等单位保护范围和建设控制地带内违法建设工程整改处理工作的函》（文物督函[2009]1029号）和《关于佛宫寺释迦塔（应县木塔）塔北环境景观综合治理和环境整治工程的意见》（办保函〔2015〕497号）的要求，抓紧落实我局关于应县释迦文物馆违法建设项目的整改意见和关于应县释迦塔（应县木塔）环境整治项目的意见。

四、请你局组织相关单位根据上述意见，对项目方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局

2017年7月28日
