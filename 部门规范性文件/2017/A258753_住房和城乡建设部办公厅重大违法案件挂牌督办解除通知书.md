# 住房和城乡建设部办公厅重大违法案件挂牌督办解除通知书

## 重大违法案件挂牌督办解除通知书

建督办〔2017〕14号

河南省住房和城乡建设厅：

2017年3月，我部对河南省太康县华夏外国语小学违法建设案进行挂牌督办。你厅按照《重大违法案件挂牌督办通知书》要求，督促周口市、太康县人民政府及有关部门认真开展调查处理。目前，该案涉及违法行为已被依法查处。

经研究决定，同意你厅解除挂牌督办申请。请督促周口市、太康县人民政府及有关部门继续落实整改要求，加强规划管理和执法工作，切实维护规划权威性、严肃性。

中华人民共和国住房和城乡建设部办公厅

2017年11月28日
