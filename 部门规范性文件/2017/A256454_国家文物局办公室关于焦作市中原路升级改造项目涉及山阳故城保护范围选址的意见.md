# 国家文物局办公室关于焦作市中原路升级改造项目涉及山阳故城保护范围选址的意见

办保函〔2017〕1133号

河南省文物局：

你局《关于焦作市中原路升级改造项目涉及山阳故城保护范围和建设控制地带选址建设方案的请示》（豫文物〔2017〕240号）收悉。经研究，我局意见如下：

一、所报建设项目穿越山阳故城北城墙遗址，且现有设计方案拟拆除地面文物遗存，严重影响遗址及其周边环境，我局不同意所报焦作市中原路升级改造项目涉及山阳故城保护范围和建设控制地带的选址方案。

二、建议进一步比选道路建设方案，绕避山阳故城保护范围。补充开展全面的考古勘探，明确地下文物遗存的分布及保存情况，并据此优化道路选址。

三、请你局指导建设单位，根据上述意见对所报方案做进一步修改和完善后按程序另行报批。

国家文物局办公室

2017年10月9日
