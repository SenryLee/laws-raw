# 国家文物局办公室关于北京市密云区令公城堡抢险项目的意见

办保函〔2017〕1023号

北京市文物局：

你局《关于密云区太师屯镇令公城堡抢险工程设计方案的请示》（京文物〔2017〕838号）收悉。经研究，我局意见如下：

一、所报方案欠缺对文物本体构成、价值、历史沿革与建造方法的深入研究，设计依据与必要性不足，保护措施缺乏针对性，我局暂不同意密云区令公城堡抢险设计方案。

二、所报方案需做以下修改完善：

（一）深化现状调查和文献研究，进一步明确城台构造、城墙收分、砌筑工艺、材料种类、外包砌体与填心拉结等情况，加强稳定性评估，进一步完善具体保护修缮措施。

（二）针对地基不稳、条石破损等病害制定具体加固方案，补充杂草清除后的封护措施，防止雨水灌入墙体；城门维修应从安全角度出发，进一步论证拱券部分局部拆除的必要性和可行性。

（三）城墙归安修补不应超出现存部位高度，尽量利用现有材料，进一步细化城墙外皮与墙心拉结的方式与做法。

（四）拆除紧邻城墙建设的房屋和其他构筑物应慎重，避免影响墙体安全。

三、请你局指导方案设计单位，根据上述意见进一步修改、完善所报方案，并按我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局办公室

2017年9月1日
