# 农业部办公厅关于公布第一批全国农垦农作物良种展示示范基地的通知

农办垦〔2017〕14号

各省、自治区、直辖市农垦主管部门，新疆生产建设兵团农业局：

为贯彻落实《中共中央国务院关于进一步推进农垦改革发展的意见》和《全国现代农作物种业发展规划（2012-2020年）》等文件精神，优化农垦优良品种区域布局，加强品种展示示范，促进品种推广应用和更新换代，2017年，我部开展了全国农垦农作物良种展示示范基地认定工作。根据《全国农垦农作物良种展示示范基地认定工作方案》要求，经专家评审，现认定河北国营察北牧场雪川农业良种展示示范基地等15个基地为第一批全国农垦农作物良种展示示范基地（名单见附件）。

被认定的全国农垦农作物良种展示示范基地，要进一步加大基地基础设施建设力度，集成推广先进生产技术，建立先进高效管理模式，持续提升基地规模化、标准化、集约化、信息化水平，加快促进新品种的转化应用，并可在其工作和生产场所悬挂或树立“全国农垦农作物良种展示示范基地”标志或宣传板，加快农垦优良品种的推广与应用，推动农垦种业做大做强。

附件：第一批全国农垦农作物良种展示示范基地名单

农业部办公厅

2017年8月1日
