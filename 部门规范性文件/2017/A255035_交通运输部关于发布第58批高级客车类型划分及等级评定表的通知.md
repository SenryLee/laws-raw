# 交通运输部关于发布第58批高级客车类型划分及等级评定表的通知

交运发〔2017〕123号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

根据《营运客车类型划分及等级评定规则》（交公路发〔2002〕590号）规定，现发布第58批《高级客车（含公共汽车）类型划分及等级评定表》，请认真贯彻执行。

附件：

1.第58批高级客车（含公共汽车）类型划分及等级评定表

2.关于《高级客车（含公共汽车）类型划分及等级评定表》的说明

3.企业名称与厂家简称对照表

交通运输部

2017年8月18日
