# 国家知识产权局关于对黄典湘的专利代理惩戒决定书

## 关于对黄典湘的专利代理惩戒决定书

国知惩戒决字〔2017〕1号

姓名：黄典湘

身份证号：350102194908040392

资格证号：3501541

执业证号：3521801541.2

执业机构：厦门市精诚新创知识产权代理有限公司

2016年11月，福建省知识产权局向国家知识产权局专利代理惩戒委员会上报了《关于对专利代理人黄典湘惩戒意见的请示》（闽知发[2016]11号），其中提出，福建省专利代理惩戒委员会在对陈开银实名举报案件的查处中认定，专利代理人黄典湘在执业期间，将委托人陈开银的发明创造内容泄露给陈生金，陈生金申请专利后获得授权，导致委托人陈开银在后提交的专利申请无法获得授权，并提请国家知识产权局专利代理惩戒委员会针对黄典湘的违法违规行为，给予黄典湘吊销“专利代理人资格证书”的处罚。

经查，2011年11月，陈开银口头委托代理人黄典湘代理专利申请，并将技术内容以电子邮件方式发送给黄典湘，黄典湘根据技术内容撰写专利申请文件。2012年2月13日，陈开银与代理人黄典湘正式签订了书面申报专利协议书，委托黄典湘办理向国家知识产权局申请“容器罐”专利手续。并在协议中约定先以定金形式给黄典湘1千元，等拿到专利受理通知书后再付1千元。

2012年2月21日，黄典湘代陈开银就其发明内容同日提交实用新型专利申请（申请号为201220066511.x，发明名称为轻便一体式筒形钢筋混凝土预制容器罐）和发明专利申请（申请号为201210046053.8，发明名称为钢筋混凝土整体预制容器罐及其整体预制方法）。2013年3月13日，实用新型专利申请获得授权。发明专利申请因未缴纳申请费被视为撤回。

黄典湘在修改整理陈开银专利申请文件期间，多次与陈生金接触，得知陈生金有申请专利的需求，黄典湘将委托人陈开银的发明创造内容泄露给陈生金，并默许其申请专利。2012年2月17日，陈生金向国家知识产权局提交发明专利申请（申请号为201210039950.6，发明名称为一种桶形整体式混凝土储水塔罐及制备方法）。经审查，该申请于2015年1月7日获得授权。

经核对，陈生金提交“201210039950.6”发明专利与陈开银发送给黄典湘的技术内容以及陈开银就该技术内容提交的实用新型专利“201220066511.x”明显相同，仅有少量文字简单替换或删减。

2012年8月15日，陈开银针对“容器罐”发明又一次向国家知识产权局提交申请号为201210302935.6，发明名称为钢筋混凝土整体预制容器罐、容器池的发明专利申请。经审查，2016年9月16日，该申请被驳回，主要驳回理由是该申请的权利要求1—2，4—7的技术方案相对于陈生金 201210039950.6发明专利中记载的技术方案与公知常识的结合不具有创造性。

黄典湘对于其私自接受委托，撰写专利申请文件，并将委托人陈开银的发明创造内容泄露给陈生金的事实予以承认。

以上事实有下列证据材料为证：

1．福建省知识产权局《关于对专利代理人黄典湘惩戒意见的请示》（闽知发[2016]11号）

2．陈开银投诉信

3．陈开银与黄典湘往来电子邮件（6份）

4．申报专利协议书

5．陈开银专利申请说明书（草稿）

6．陈开银实用新型专利“201220066511.x”授权公告单行本

7．陈生金发明专利“201210039950.6”授权公告单行本

8．福建省知识产权局对黄典湘现场询问笔录

9．黄典湘书面陈述

10．陈开银发明专利申请“201210302935.6”及驳回决定

2016年12月1日，国家知识产权局召开专利代理惩戒委员会会议。会议讨论认为，根据《专利法》第十九条第三款的规定，专利代理机构应当遵守法律、行政法规，按照被代理人的委托办理专利申请或者其他专利事务；对被代理人发明创造的内容，除专利申请已经公布或者公告的以外，负有保密责任。《专利代理条例》第十七条规定，专利代理人必须承办专利代理机构委派的专利代理工作，不能自行接受委托。专利代理人黄典湘在执业期间，私自接受委托人陈开银的委托，撰写专利申请文件，并且对委托人陈开银尚未申报专利的发明内容未尽到保密职责，将其泄露给陈生金，导致陈生金先于陈开银申报专利，极大损害了委托人的利益。黄典湘的上述行为严重违背了专利代理人的职业道德，违反《专利法》第十九条、《专利代理条例》第十七条的规定，影响恶劣，属于《专利代理条例》第二十五条第一款第二项规定的“泄露委托人的发明创造内容”、第四项规定的“私自接受委托，承办专利代理业务，收取费用”以及《专利代理惩戒规则（试行）》第八条第一项规定的“违反专利法第十九条的规定，泄露委托人发明创造的内容”的情形。经国家知识产权局专利代理惩戒委员会讨论、表决，拟给予黄典湘吊销“专利代理人资格证书”的处罚。

国家知识产权局于2016年12月6日发出《专利代理惩戒意见告知书》（国知惩戒函字[2016]3号），告知黄典湘拟对其作出吊销“专利代理人资格证书”的处罚，拟作出处罚决定的事实、理由、依据，并告知其可以在接到告知书之日起10日内向国家知识产权局提出陈述和申辩，或者在接到告知书之日起5日内提出听证申请。

在规定的期限内，黄典湘未向国家知识产权局提出陈述和申辩或者听证申请。

惩戒决定：根据《专利代理条例》第二十五条第一款第二项、第四项以及《专利代理惩戒规则（试行）》第八条第一项的规定，决定给予黄典湘吊销“专利代理人资格证书”的处罚。

当事人如对本惩戒决定不服，可在收到本决定之日起60日内向国家知识产权局申请行政复议，也可以在收到本决定书之日起6个月内直接向有管辖权的人民法院提起诉讼。
