# 国家文物局关于西狭颂摩崖石刻保护设施建设项目意见的函

## 关于西狭颂摩崖石刻保护设施建设项目意见的函

办保函〔2017〕636号

甘肃省文物局：

你局《关于呈报西狭颂摩崖石刻保护设施建设项目文物保护方案的报告》（甘文局发〔2017〕87号）收悉。经研究，我局意见如下：

一、所报方案前期勘察不足，文本深度不够，我局暂不同意西狭颂摩崖石刻保护设施建设项目。

二、所报方案应进行以下必要的修改和完善：

（一）深化现状勘察研究，明确石刻本体病害情况和主要破坏因素，客观评估石刻载体稳定性、危岩体分布范围、栈道残损程度和结构安全等，为科学研提危岩体加固、栈道修缮等措施提供依据。

（二）根据现状勘察结论进一步深化、完善方案设计，坚持最小干预原则，严格控制工程范围及工程量。进一步论证栈道全部拆除重建的必要性以及电力线路选线和环保厕所选址的科学性和合理性。补充说明甘肃省人民政府关于西狭颂摩崖石刻保护范围和建设控制地带的管理规定和具体控制指标。

（三）应充分考虑施工对文物安全的影响，制定必要的文物保护措施和应急预案。

（四）应重新编制文物影响评估报告，深入论证拟建项目对文物本体安全和环境风貌的影响，做到客观、准确、科学，避免大篇幅套用方案内容。

（五）进一步校核文本内容，准确说明拟建项目与西狭颂摩崖石刻的位置关系。补充西狭颂摩崖石刻的分布范围与保护区划图、拟建项目与保护区划的叠加图等。

三、请你局组织有关单位根据上述意见，对所报方案进行修改、完善后，按程序另行报批。请你局督促、指导当地人民政府切实加强西狭颂摩崖石刻的日常保护管理，确保文物安全。

专此函。

国家文物局

2017年5月24日
