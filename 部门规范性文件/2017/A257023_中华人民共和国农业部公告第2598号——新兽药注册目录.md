# 中华人民共和国农业部公告第2598号——新兽药注册目录

## 中华人民共和国农业部公告

第2598号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准上海启盛生物科技有限公司等2家单位申报的水貂犬瘟热、病毒性肠炎二联活疫苗（CL08株+NA04株）为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

批准河北地邦动物保健科技有限公司申报的维生素B12注射液变更注册，增加规格10ml:0.5mg、50ml:2.5mg、100ml:5mg，其质量标准、标签和说明书按照《中国兽药典》同品种执行。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年10月24日
