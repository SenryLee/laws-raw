# 环境保护部办公厅关于通报2013年度环保公益性行业科研专项项目验收结果的函

## 关于通报2013年度环保公益性行业科研专项项目验收结果的函

环办科技函〔2017〕1701号

2013年度环保公益性行业科研专项各项目承担单位:

根据《公益性行业科研专项经费管理暂行办法》（环办〔2007〕53号）、《公益性行业科研专项经费环保项目验收规范(试行)》（环科函〔2011〕1号）、《关于进一步加强环保公益性行业科研专项经费项目验收工作的补充通知》（环科函〔2011〕17号）和《环保科研人员信用管理暂行办法》（环科函〔2009〕24号）的有关规定，我部组织开展了2013年度环保公益性行业科研专项项目验收工作，对58个项目任务完成情况和经费使用情况进行评价。验收结果表明，项目总体完成情况良好，58个项目均按照项目任务书要求完成了研究任务和考核指标，专项经费使用较合理，项目成果丰富，为环境保护中心工作和重点任务提供了重要的科技支撑。

“PM2.5源排放控制和监管体系研究”等14个项目产出明显、创新性较强、成果得到应用、总体评价为优。现提出表扬，项目负责人信用等级评定为优。

希望受表扬的项目单位和负责人再接再厉，继续深化成果应用，做好成果宣传与普及工作。请各有关单位学习借鉴受表扬项目承担单位和负责人的先进经验和做法，进一步加强项目监督管理，规范经费使用，强化项目产出与应用，做好成果凝练、宣传与科学普及工作，切实发挥科研成果对环境管理的支撑作用。

附件：2013年度环保公益性行业科研专项项目验收结果

环境保护部办公厅
