# 环境保护部办公厅关于解除深圳市中恒华发科技有限公司环境问题挂牌督办的通知

## 关于解除深圳市中恒华发科技有限公司环境问题挂牌督办的通知

环办应急函[2017]597号

广东省环境保护厅：

按照《关于对深圳市中恒华发科技有限公司环境问题挂牌督办的通知》（环办环监〔2016〕92号）要求，你厅督促深圳市人居环境委员会积极整改中恒华发科技有限公司环境问题，并向我部提交了解除挂牌督办申请。经我部现场核查，目前中恒华发科技有限公司环境问题整改基本达到督办要求。

经研究，现决定解除对深圳市中恒华发科技有限公司环境问题挂牌督办。请你厅督促深圳市人民政府及其有关主管部门认真落实环境保护责任，不断加大环境监管执法力度，严厉打击环境违法行为，改善环境质量，保障环境安全。

环境保护部办公厅

2017年4月19日
