# 国家文物局关于邦纳寺修缮工程立项的意见

## 关于邦纳寺修缮工程立项的意见

办保函〔2017〕289号

西藏自治区文物局：

你局《关于邦纳寺维修保护工程立项的请示》（藏文物字〔2017〕22号）收悉。经研究，我局意见如下：

一、暂不同意邦纳寺修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）加强现状勘察，查明文物主要病害类型、分布范围，合理评估病害程度和发展趋势，补充壁画专项勘察内容。应说明2009年修缮工程内容和效果，进一步论证工程实施的必要性和可行性。

（二）补充地方建造工艺、传统做法、建筑材料和构造特征等研究和分析内容。

（三）应进一步细化工程措施，坚持最小干预原则，以现状整修为主，注意老旧构件的合理利用，减少更换量。进一步论证增设屋面柔性防水涂膜的可行性，补充相关试验数据和说明。

（四）明确邦纳寺的管理使用情况，并根据宗教活动需要，科学调整建筑内部空间，统筹考虑文物建筑日常使用和保养维护问题。

（五）应根据工程量合理编制经费预算，进一步细化各单项取费依据，核减工程造价；拆迁费用不应纳入工程经费。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年3月21日
