# 工业和信息化部关于印发“食品企业质量安全检测技术示范中心”名单（第四批）的通知

工信部消费〔2017〕299号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团工业和信息化主管部门，有关单位：

为落实《国务院办公厅关于开展消费品工业“三品”专项行动营造良好市场环境的若干意见》（国办发〔2016〕40号）精神，依据《工业和信息化部办公厅关于组织申报“食品企业质量安全检测技术示范中心”的通知》（工信厅消费函〔2017〕571号），以及食品检验机构资质认定等相关规定，经企业自愿申报、各地工业和信息化主管部门推荐、专家评审、网上公示，现将“食品企业质量安全检测技术示范中心”名单（第四批）予以印发。

各地工业和信息化主管部门要继续加强工作指导，积极支持食品企业质量安全检测技术示范中心开展工作，加快推进食品企业质量安全检测能力建设。各食品企业质量安全检测技术示范中心要切实发挥服务、指导、示范及带动作用，为食品生产企业特别是中小食品生产企业提供人员培训、委托检测、应急检测等相关服务，不断提升食品行业质量安全保障水平。

特此通知。

附件：“食品企业质量安全检测技术示范中心”名单（第四批）
