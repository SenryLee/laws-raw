# 国家新闻出版广电总局办公厅关于2017年度“百人百部中国梦短纪录片扶持计划”

新广电办发〔2017〕78号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央三台、中央新影集团、电影频道节目中心、中国教育电视台：

根据《国家新闻出版广电总局办公厅关于开展“百人百部中国梦短纪录片扶持计划”的通知》（新广电办发[2015]98号）精神，总局组织纪录片业内专家学者对申报的作品进行了初评、复评两次评审，评审坚持优中选优、公平公正的原则，坚持聚焦“中国梦”、弘扬社会主义核心价值观、传承中华优秀传统文化、反映现实火热生活的标准，评选出《山路弯弯》等35部扶持作品（名单附后）。现予以公示，任何单位或个人如有异议，可于2017年12月20日前向总局宣传司反映。联系地址：北京市西城区复兴门外大街2号国家新闻出版广电总局宣传司，邮编：100866。联系人：罗引子，电话：010-86096287。

特此通知。
