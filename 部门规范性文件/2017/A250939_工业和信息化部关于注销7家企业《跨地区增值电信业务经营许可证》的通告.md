# 工业和信息化部关于注销7家企业《跨地区增值电信业务经营许可证》的通告

工信部信管函[2017]214号

近期，深圳市永恒进彩科技开发有限公司等7家企业（详见附件）向我部提交申请，要求注销其持有的《跨地区增值电信业务经营许可证》，并依据《电信业务经营许可管理办法》（工业和信息化部令第5号）规定，提交了股东会关于终止经营的决定、做好用户善后处理工作承诺书及解决用户善后问题的情况说明等材料。

为维护市场秩序，保障用户合法权益，我部于2017年3月24日至4月23日公示了拟注销《跨地区增值电信业务经营许可证》的相关信息，听取社会意见，接受社会监督。公示期未收到异议。

经审核，我部认为深圳市永恒进彩科技开发有限公司等7家企业符合退出电信业务市场条件，依据《电信业务经营许可管理办法》第三十四条规定，现注销其相关《跨地区增值电信业务经营许可证》。

特此通告。

附件：注销《跨地区增值电信业务经营许可证》的企业名单（2017年第2批）

工业和信息化部

2017年5月17日
