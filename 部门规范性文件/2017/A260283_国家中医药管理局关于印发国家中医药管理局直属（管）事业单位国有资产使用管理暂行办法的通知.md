# 国家中医药管理局关于印发国家中医药管理局直属（管）事业单位国有资产使用管理暂行办法的通知

## 关于印发国家中医药管理局直属（管）事业单位国有资产使用管理暂行办法的通知

国中医药规财发〔2017〕17号

局各直属（管）单位：

为进一步加强直属（管）单位国有资产管理工作，规范国有资产使用行为，维护国有资产安全、完整，提高资产使用效益，根据财政部《中央级事业单位国有资产使用管理暂行办法》（财教〔2009〕192号）等相关文件规定，结合中医药行业特点和我局工作实际，制定了《国家中医药管理局直属（管）事业单位国有资产使用管理暂行办法》，已经局长会议审议通过。现印发给你们，请遵照执行。

附件：国家中医药管理局直属（管）事业单位国有资产使用管理暂行办法

国家中医药管理局

2017年7月18日
