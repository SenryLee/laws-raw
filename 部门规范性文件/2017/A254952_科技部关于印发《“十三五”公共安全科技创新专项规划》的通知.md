# 科技部关于印发《“十三五”公共安全科技创新专项规划》的通知

国科发社〔2017〕102号

各省、自治区、直辖市及计划单列市科技厅（委、局），新疆生产建设兵团科技局，各有关单位：

为贯彻落实《中华人民共和国国民经济和社会发展第十三个五年规划纲要》、《国家创新驱动发展战略纲要》、《国家中长期科学和技术发展规划纲要（2006-2020年）》和《“十三五”国家科技创新规划》，明确“十三五”期间公共安全科技领域的发展思路、发展目标、重点任务和政策措施，科技部制定了《“十三五”公共安全科技创新专项规划》，现印发你们，请结合本部门、本地区的实际贯彻落实。

科技部

2017年4月24日

附件：“十三五”公共安全科技创新专项规划
