# 水利部办公厅关于长江三峡水利枢纽升船机工程项目竣工水土保持设施验收的复函

办水保函〔2017〕810号

中国长江三峡集团公司：

《中国长江三峡集团公司关于长江三峡水利枢纽升船机工程项目竣工水土保持设施验收的请示》（三峡枢〔2017〕177号）收悉。经研究，现函复如下：

长江三峡水利枢纽升船机工程于2015年5月基本建成，2016年9月试运行，相关水土保持设施已纳入2011年12月我部组织的长江三峡水利枢纽工程（坝区）水土保持设施验收范围。我部同意长江三峡水利枢纽升船机工程据此开展后续验收工作。

水利部办公厅

2017年7月17日
