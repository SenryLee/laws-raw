# 国家文物局关于重庆抗战金融机构旧址群——中国银行、中央银行旧址修缮工程立项的意见

## 关于重庆抗战金融机构旧址群——中国银行、中央银行旧址修缮工程立项的意见

办保函〔2017〕412号

重庆市文物局：

你局《关于审批全国重点文物保护单位重庆抗战金融机构旧址群——中国银行旧址修缮工程立项报告的请示》（渝文物〔2017〕6号）、《关于审批全国重点文物保护单位重庆抗战金融机构旧址群——中央银行旧址修缮工程立项报告的请示》（渝文物〔2017〕7号）收悉。经研究，我局意见如下：

一、暂不同意中国银行旧址、中央银行旧址修缮工程立项。

二、请你局指导有关单位，强化上述两处旧址现状勘察，详细梳理建筑各部位病害的类型及残损程度，调查研究文物历史沿革，进一步明确旧址原形制及后期改造、修缮情况，为拟采取的旧址墙面、内部格局、门窗内饰等修缮措施提供科学依据。在此基础上，根据我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）要求，另行报批。

国家文物局

2017年4月12日
