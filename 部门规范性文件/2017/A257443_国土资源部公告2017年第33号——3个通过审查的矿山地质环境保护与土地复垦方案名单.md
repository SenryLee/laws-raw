# 国土资源部公告2017年第33号——3个通过审查的矿山地质环境保护与土地复垦方案名单

## 国土资源部公告

2017年第33号

## 国土资源部关于宁夏银星煤业有限公司银星一井等3个矿山地质环境保护与土地复垦方案通过审查的公告

根据《土地复垦条例》、《矿山地质环境保护规定》等有关规定，宁夏银星煤业有限公司银星一井等3个矿山地质环境保护与土地复垦方案通过审查，现予公告。

2017年10月31日

附件：3个通过审查的矿山地质环境保护与土地复垦方案名单
