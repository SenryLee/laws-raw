# 中共国土资源部党组关于认真组织学习《习近平谈治国理政》第二卷的通知

国土资党发〔2017〕53号

国家海洋局、国家测绘地理信息局、中国地质调查局及部其他直属单位，各派驻地方的国家土地督察局，部机关各司局：

《习近平谈治国理政》第二卷已经党中央批准，由中央宣传部会同中央文献研究室、中国外文局编辑出版。根据中央办公厅转发《中央宣传部、中央组织部关于认真组织学习<习近平谈治国理政>第二卷的通知》（中办发〔2017〕66号）要求，现就认真组织学习《习近平谈治国理政》第二卷有关事项通知如下。

一、认识重大意义。《习近平谈治国理政》第二卷生动记录了以习近平同志为核心的党中央团结带领全党全国各族人民在新时代坚持和发展中国特色社会主义的伟大实践，集中反映了习近平新时代中国特色社会主义思想的发展脉络和主要内容。认真学习《习近平谈治国理政》第二卷，对于深入领会习近平新时代中国特色社会主义思想的时代背景、科学体系、精神实质、实践要求，深入领会这一思想的重大政治意义、理论意义、实践意义，不断提高马克思主义水平，具有重要意义。

二、加强组织领导。各级党组织要高度重视《习近平谈治国理政》第二卷的学习组织工作，把学习《习近平谈治国理政》第二卷与学习党的十九大精神结合起来，与推进“两学一做”学习教育常态化制度化结合起来，将其纳入学习贯彻党的十九大精神的具体安排之中。要把《习近平谈治国理政》第二卷和先期出版的《习近平谈治国理政》第一卷，作为深入学习领会习近平新时代中国特色社会主义思想和党的十九大精神的权威读本，采取召开座谈会、举办研讨班等多种形式，切实组织好学习，推动学习宣传贯彻党的十九大精神热潮向纵深发展。

三、深入学习领会。广大党员干部要以高度的使命感和责任感，系统、深入学习《习近平谈治国理政》第二卷，切实把思想和行动统一到习近平新时代中国特色社会主义思想上来，统一到党的十九大确定的重大决策部署上来。要通过深入学习领会，进一步增强政治意识、大局意识、核心意识、看齐意识，维护习近平总书记党中央的核心、全党的核心地位，维护党中央权威和集中统一领导，在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致。

四、党委（党组）中心组要率先垂范。党委（党组）理论学习中心组要采取自学、领读领学、交流互学等形式，认真研读这部重要著作，做到先学一步、学深一层，充分发挥示范带头作用。部党校、国家海洋局党校、国家测绘地理信息局党校和其他干部培训机构要及时将《习近平谈治国理政》第二卷纳入培训教学内容，加强理论阐释和宣讲，帮助党员干部系统深入领会习近平新时代中国特色社会主义思想。

五、坚持学以致用。要大力弘扬理论联系实际的优良学风，强化问题意识，树立问题导向，在认真学习《习近平谈治国理政》第二卷、深入领会习近平新时代中国特色社会主义思想的基础上，着力增强学习本领、政治领导本领、改革创新本领、科学发展本领、依法执行本领、群众工作本领、狠抓落实本领、驾驭风险本领，锐意进取，埋头苦干，努力开创新时代国土资源工作新局面。

中共国土资源部党组

2017年12月7日
