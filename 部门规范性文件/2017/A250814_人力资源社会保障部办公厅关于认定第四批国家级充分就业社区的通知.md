# 人力资源社会保障部办公厅关于认定第四批国家级充分就业社区的通知

人社厅发〔2017〕60号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）：

充分就业社区是公共就业服务体系的重要组成部分，是实现更加充分就业和更高质量就业的重要抓手。根据《人力资源社会保障部办公厅关于开展第四批国家级充分就业社区推荐认定工作的通知》（人社厅函〔2016〕466号）要求，各地按规定标准和程序组织开展了第四批国家级充分就业社区推荐工作。经城市推荐、省级复核、我部审核，并向社会公示后，现认定北京市东城区安定门街道五道营社区等194个社区为第四批国家级充分就业社区。特此公布。

各地要高度重视充分就业社区建设工作，将充分就业社区建设工作纳入就业工作整体规划；要进一步完善本省（区、市）星级充分就业社区认定标准和程序，定期组织星级充分就业社区认定工作；要加强对充分就业社区的动态管理，定期开展充分就业社区复查工作；要大力宣传国家级充分就业社区的先进事迹和典型经验，充分发挥其示范带动作用，为促进就业工作作出更大贡献。

附件：第四批国家级充分就业社区名单
