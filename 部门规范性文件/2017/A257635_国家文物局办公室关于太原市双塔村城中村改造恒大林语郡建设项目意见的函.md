# 国家文物局办公室关于太原市双塔村城中村改造恒大林语郡建设项目意见的函

办保函〔2017〕1256号

山西省文物局：

你局《关于在王家峰墓群建设控制地带进行太原市双塔村城中村改造恒大林语郡建设项目的请示》（晋文物〔2017〕184号）和《关于太原市双塔村城中村改造恒大林语郡建设项目涉及王家峰墓群有关情况的报告》收悉。经研究，我局意见如下：

一、原则同意你局行政处罚意见。

二、请你局严格按照《中华人民共和国文物保护法》、国务院办公厅《关于进一步加强文物安全工作的实施意见》（国办发〔2017〕81号）要求和山西省人民政府关于王家峰墓群保护区划的相关管理规定，督促地方人民政府进一步明确主体责任，落实整改要求，切实加强该建设项目的监管力度。同时，请山西省人民政府尽快制定、公布王家峰墓群建设控制地带的具体控制指标，依法及时履行涉建项目报批程序。

专此函。

国家文物局办公室

2017年11月14日
