# 国家文物局关于国立西南联合大学旧址展示工程立项的意见

## 关于国立西南联合大学旧址展示工程立项的意见

办保函〔2017〕413号

云南省文物局：

你局《关于国立西南联合大学旧址展示利用工程立项的请示》（云文物〔2017〕42号）收悉。经研究，我局意见如下：

一、在文物保护规划框架下，深入开展文物价值和开放、展示现状评估，客观分析目前存在的问题，为有效提升文物展示水平制定针对性解决方案。

二、展示内容应突出文物价值及相关历史信息。旧址内昆石铁路残存米轨为滇缅铁路遗迹，建议将其展示利用一并纳入考虑范畴。

三、妥善处理文物保护与展示的关系，确保文物安全。

四、进一步调整工程预算，剔除文化创意产品开发制作等无关内容。

国家文物局

2017年4月12日
