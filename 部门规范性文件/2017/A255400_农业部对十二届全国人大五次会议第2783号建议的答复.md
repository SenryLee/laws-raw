# 农业部对十二届全国人大五次会议第2783号建议的答复

## 对十二届全国人大五次会议第2783号建议的答复

农办议〔2017〕128号

杨杰等16名代表：

你们提出的关于在安徽省宿州市建立“中国农业科学院黄淮分院”的建议收悉。经我部认真研究，现答复如下。

一、关于在宿州市建立中国农业科学院黄淮分院

目前，我部所属中国农业科学院在河南、山东、江苏等省已设立棉花研究所、郑州果树研究所、农田灌溉研究所、烟草研究所、南京农业机械化研究所等5个中央级农业科研院所，这些研究所学科门类齐全、研究领域广泛、科研实力较强，已经为黄淮地区乃至全国现代农业发展提供了有力科技支撑。此外，中国农业科学院还与黄河三角洲国家农业高新技术产业示范区在山东东营市共建黄河三角洲现代农业工程技术研究院，在安徽省合肥市建设中国农业科学院合肥食品科学与营养创新研究院。目前，中国农业科学院在黄淮地区已经形成了相对完善的创新网络，将为黄淮地区现代农业发展提供有力科技支撑。

在宿州设置中国农业科学院黄淮分院，涉及到机构设置、人员编制、财政保障等一系列复杂问题，需要中央和地方多部门的沟通协调，在国家事业单位分类改革的大背景下，难度很大、不确定性也很大。综合考虑宿州市农业科技发展现状，结合中国农业科学院科研布局、机构改革等实际情况，目前在宿州市建立“中国农业科学院黄淮分院”的时机和条件尚未成熟。

二、关于在农业科技政策、平台、项目方面给予支持

宿州市是我国地方农业科技创新基础条件较好、创新水平较高、产业支撑引领较强的地区之一。近年来，我部高度重视宿州市农业科技创新工作，通过现代农业产业技术体系、国家农业科学试验站等建设，宿州农业科技创新条件明显改善、创新能力显著提升、产业支撑水平明显增强。一是支持建设现代农业产业技术体系。我部依托宿州市农业科学院，先后建设小麦、玉米、大豆、大宗蔬菜等4个现代农业产业技术体系综合试验站。在2016年启动实施的农业竞争力提升科技行动中，我部选定宿州市埇桥区作为首批实施区域，通过小麦产业技术体系+地方创新团队+地方农技推广和培训机构+安徽皖垦种业、大豆产业技术体系+地方创新团队+地方农技推广和培训机构+安徽龙华矿机集团新田农机制造有限公司等联合体，着力提升宿州市小麦、大豆等现代农业产业质量效益和竞争力水平。二是支持建设国家农业科学试验站。2017年我部启动实施农业基础性长期性科技工作，选取宿州市农业科学院为依托单位，建立国家农业科学实验站，开展作物种质资源、土壤质量、农业环境等观测检测工作，研究提出专业性、综合性分析报告，为科技创新、政策制定等提供服务和支撑。三是支持建设国家级（区域性）育制种基地（良种繁育基地）。我部于2014年种子工程项目中批准了黄淮海地区抗逆高产小麦育种研究宿州创新基地项目建设，2016年认定了宿州市萧县作为第一批区域性蔬菜良种繁育基地。

下一步，我们将继续支持宿州市农业科技创新工作，一是支持宿州市农业科学院在国家农业科技创新联盟的框架下，加强与省内、省外优势科教力量的联合协作，推动安徽地区农业科技创新联盟建设，切实解决制约当地农业“节本增效、质量安全、生态环保”等基础性、行业性、区域性重大关键技术问题。二是鼓励支持宿州市农业科教资源主动融入合肥营养健康产业科技创新中心建设，加快科技成果的孵化转化，促进科技人员的创新创业，打造区域农业经济增长极。三是以宿州农业科学院等单位的试验基地等科研平台为基础，我部将积极推动中国农业科学院与宿州市农业科学院“联合实验室—联合实验基地—科技示范园—现代农业产业园” 等基础科研条件平台的共建共享，充分利用中国农业科学院科技、人才、成果优势，加快区域农业科技创新和技术转移孵化，推进农业高新成果的产业化示范应用，为解决黄淮海区域重大农业关键技术难题和生产主要问题提供支撑。

感谢你们对农业科技工作的关心，并希望继续对“三农”工作予以关心和支持。
