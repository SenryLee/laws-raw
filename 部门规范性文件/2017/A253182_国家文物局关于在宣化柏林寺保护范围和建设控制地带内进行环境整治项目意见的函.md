# 国家文物局关于在宣化柏林寺保护范围和建设控制地带内进行环境整治项目意见的函

## 关于在宣化柏林寺保护范围和建设控制地带内进行环境整治项目意见的函

办保函〔2017〕859号

河北省文物局：

你局《关于呈报宣化柏林寺环境整治工程设计方案的请示》（冀文物字〔2017〕128号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位宣化柏林寺保护范围和建设控制地带内，设计依据不足，设计思路不正确，对文物环境不利影响较大，我局暂不同意宣化柏林寺环境整治项目。

二、该方案应进行必要的修改和完善：

（一）应严格按照《中华人民共和国文物保护法》和河北省人民政府关于宣化柏林寺保护区划的管理规定、具体控制要求，进一步明确环境整治的目的，突出对柏林寺文物价值、历史格局等的保护；重新调整设计思路，核减项目内容，尽量减少对文物及周边环境的影响。

（二）应加强历史研究和资料搜集，详细分析文物分布范围、建筑格局和历史环境要素等。进一步论证管理用房、小车库和厕所原址拆建，游客服务中心、观景亭、长廊、停车场等设施建设项目选址的科学性和必要性，核定设施总需求量，优化功能布局，严格控制新建设施数量、规模和体量。

（三）进一步深化方案设计，应根据历史研究及考古勘探结果，确定柏林寺围墙的具体位置，不同意没有历史依据的新建；缩小电瓶车停车场规模，地面不宜进行硬化处理；慎重考虑在周边山体上新建观景亭和长廊等，避免影响柏林寺景观环境；环境绿化应注意避免过度人工化和现代景观园林化设计倾向。

三、请你局组织相关单位根据上述意见，对项目方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局

2017年7月20日
