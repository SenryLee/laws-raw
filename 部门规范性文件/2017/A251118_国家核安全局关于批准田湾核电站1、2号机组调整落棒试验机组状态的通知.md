# 国家核安全局关于批准田湾核电站1、2号机组调整落棒试验机组状态的通知

## 关于批准田湾核电站1、2号机组调整落棒试验机组状态的通知

国核安发〔2017〕101号

江苏核电有限公司:

你公司《关于申请调整田湾核电站1、2号机组落棒时间和控制棒位置检查试验机组状态的函》（苏核发〔2017〕157号）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的有关要求，我局对你公司提交的申请文件进行了审评，认为你公司调整田湾核电站1、2号机组落棒试验机组状态的申请是可以接受的，现予批准。

你公司应严格按照我局批准的方案实施落棒试验机组状态的调整，确保机组运行安全。

国家核安全局

2017年5月26日
