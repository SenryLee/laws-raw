# 国家能源局关于印发《能源行业市场主体信用评价工作管理办法（试行）》的通知

国能发资质〔2017〕37号

各派出能源监管机构，有关能源企业，有关行业协会：

为加快推进能源行业信用体系建设，规范能源行业市场主体信用评价活动，我局制定了《能源行业市场主体信用评价工作管理办法（试行）》，现印发你们，请遵照执行。

附件：能源行业市场主体信用评价工作管理办法（试行）

国家能源局

2017年8月1日
