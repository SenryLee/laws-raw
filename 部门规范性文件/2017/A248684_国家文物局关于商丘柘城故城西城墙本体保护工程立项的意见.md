# 国家文物局关于商丘柘城故城西城墙本体保护工程立项的意见

## 关于商丘柘城故城西城墙本体保护工程立项的意见

办保函〔2017〕259号

河南省文物局：

你局《关于商丘柘城故城西城墙本体保护工程立项的请示》（豫文物〔2017〕15号）收悉。经研究，我局意见如下：

一、暂不同意商丘柘城故城西城墙本体保护工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步明确工程对象，应坚持最小干预的原则，严格控制工程范围和规模，已处于稳定状态的城墙应维持现状，仅对存在安全稳定问题的城墙段落进行保护加固。

（二）进一步明确本体保护工程实施的可行性，应首先清退占压城墙遗址的建筑和农田，为工程实施提供保障。

（三）西城墙木栈道及参观平台展示设施应待保护规划批复完成后统筹考虑。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年3月15日
