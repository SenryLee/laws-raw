# 国土资源部公告2017年第39号——国土资源部关于山东黄金矿业（莱州）有限公司（寺庄矿区）等5个矿山地质环境保护与土地复垦方案通过审查的公告

## 国土资源部公告

2017年第39号

## 国土资源部关于山东黄金矿业（莱州）有限公司（寺庄矿区）等5个矿山地质环境保护与土地复垦方案通过审查的公告

国土资源部关于山东黄金矿业（莱州）有限公司（寺庄矿区）等5个矿山地质环境保护与土地复垦方案通过审查的公告

根据《土地复垦条例》、《矿山地质环境保护规定》等有关规定，山东黄金矿业（莱州）有限公司（寺庄矿区）等5个矿山地质环境保护与土地复垦方案通过审查，现予公告。

2017年11月30日

附件：5个通过审查的矿山地质环境保护与土地复垦方案名单
