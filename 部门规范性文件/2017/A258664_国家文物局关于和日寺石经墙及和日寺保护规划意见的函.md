# 国家文物局关于和日寺石经墙及和日寺保护规划意见的函

文物保函〔2017〕1961号

青海省文物管理局：

你局《关于泽库县和日石经墙及和日寺文物保护规划的请示》（青文物局〔2017〕10号）收悉。经研究，我局意见如下：

一、原则同意所报和日寺石经墙及和日寺保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

深化价值评估和现状评估，进一步梳理物质文化遗产和非物质文化遗产的关系，突出石经墙的宗教价值和作为活态文化遗产的延续特征，科学分析宗教活动对文物本体的影响。补充分析石经墙的材料、工艺、形制及建造传统等。

（二）关于保护区划与管理规定

完善保护区划管理规定，明确保护范围内石经墙更新的范围、规模、执行主体和操作要求。补充一类建设控制地带建筑密度、色彩、样式等具体控制指标和要求。

（三）关于保护措施

1. 进一步完善保护措施，研究提出石经墙长期维护的技术导则。

2. 进一步论证石经墙保护性设施建设的必要性和依据。

3. 不同意转经道路面铺装石板。

（四）关于环境整治和专项规划

1. 进一步论证建设博物馆和传习所的必要性。

2. 明确文物部门与宗教部门的责权，妥善处理文物保护与宗教使用之间的关系。

（五）进一步规范文本和图纸表达。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的和日寺石经墙及和日寺保护规划报请青海省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体计划或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好和日寺石经墙及和日寺的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月6日
