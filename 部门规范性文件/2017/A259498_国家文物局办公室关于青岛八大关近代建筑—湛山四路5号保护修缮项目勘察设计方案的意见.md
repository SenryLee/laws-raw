# 国家文物局办公室关于青岛八大关近代建筑—湛山四路5号保护修缮项目勘察设计方案的意见

办保函〔2017〕1442号

山东省文物局：

你局《关于呈报青岛八大关近代建筑—湛山四路5号保护修缮工程勘察设计方案的请示》（鲁文发〔2017〕97号）收悉。经研究，我局意见如下：

一、进一步论证项目实施的必要性。深化文物建筑现状勘察，补充保存状况评估。

二、补充结构检测的评估结论，补充地基检测结论相应照片。

二、明确保护措施中“原做法”的具体内容及依据，补充墙面抹灰、砌体规格及工艺做法。

三、在建筑图中明确墙体节点加固图对应位置；补充钢筋网加固的墙体位置及必要性说明。

四、进一步深化设计图纸。补充剖面图，装修大样图，抗震结构设计图，重要部位详图、檐口节点图等。

五、请你局指导有关单位根据上述意见修改、完善方案，并根据我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）要求，按程序另行报批。

专此函复。

国家文物局办公室

2017年12月27日
