# 国土资源部办公厅关于启用国务院第三次全国土地调查领导小组办公室印章的函

国土资厅函〔2017〕1728号

各省、自治区、直辖市人民政府办公厅，新疆生产建设兵团办公厅，中央军委后勤保障部军事设施建设局，发展改革委、民政部、财政部、环境保护部、住房城乡建设部、水利部、农业部、统计局、林业局、海洋局、测绘地信局办公厅（办公室）：

根据《国务院关于开展第三次全国土地调查的通知》（国发〔2017〕48号）和《国务院办公厅关于颁发国务院第三次全国土地调查领导小组办公室印章的通知》（国办印函〔2017〕7号），“国务院第三次全国土地调查领导小组办公室”印章已由国务院制发，即日起正式启用。

特此函告。
