# 住房和城乡建设部办公厅重大违法案件挂牌督办通知书

## 重大违法案件挂牌督办通知书

建督办[2017]1号

甘肃省住房和城乡建设厅：

你省兰州市城关区人民政府与兰州港联生态环境发展有限公司未办理相关审批手续，违法建设“港联购物中心”，侵占泄洪通道长达1.3公里，占地面积约4万平方米，总建筑面积17.3万平方米，存在重大安全隐患，严重违反《中华人民共和国城乡规划法》第三十五条、第四十条等规定。

现决定对该案进行挂牌督办。请你厅责令立即停止违法建设，依法查处违法行为，并追究有关单位和个人责任。请于2017年6月2日前报告处理整改结果。依法整改到位后，我部将按程序解除挂牌督办。
