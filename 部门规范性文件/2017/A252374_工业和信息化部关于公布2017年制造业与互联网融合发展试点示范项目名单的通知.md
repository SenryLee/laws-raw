# 工业和信息化部关于公布2017年制造业与互联网融合发展试点示范项目名单的通知

工信部信软函〔2017〕279号

各省、自治区、直辖市及新疆生产建设兵团工业和信息化主管部门，有关单位：

为贯彻落实《国务院关于深化制造业与互联网融合发展的指导意见》（国发〔2016〕28号），推动基于互联网的制造业技术、模式、业态等创新和应用示范，根据《关于组织开展2017年制造业与互联网融合发展试点示范工作的通知》（工信厅信软函〔2017〕92号）要求，经各组织单位推荐、专家组评审、网上公示等环节，确定徐工工业云平台建设等70个项目为2017年制造业与互联网融合发展试点示范项目。现将项目名单予以公布，请结合实际，抓好试点示范工作。

附件：2017年制造业与互联网融合发展试点示范项目名单

工业和信息化部
