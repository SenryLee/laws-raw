# 国家文物局关于东吴大学旧址修缮工程立项的意见

## 关于东吴大学旧址修缮工程立项的意见

办保函〔2017〕288号

江苏省文物局：

你局《关于审批东吴大学旧址修缮利用工程立项的请示》（苏文物保〔2017〕31号）收悉。经研究，我局意见如下：

一、暂不同意东吴大学旧址修缮工程立项。

二、请你局指导当地人民政府按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号），抓紧组织开展东吴大学旧址保护规划编制工作，结合文物价值及保存现状评估，统筹考虑文物修缮及展示利用工程的开展，同时针对当地城乡发展对文物的影响提出有效对策，为东吴大学旧址本体及历史环境的整体保护提供科学指导。

国家文物局

2017年3月21日
