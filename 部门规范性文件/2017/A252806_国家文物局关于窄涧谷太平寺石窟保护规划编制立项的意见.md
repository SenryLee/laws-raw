# 国家文物局关于窄涧谷太平寺石窟保护规划编制立项的意见

## 关于窄涧谷太平寺石窟保护规划编制立项的意见

办保函〔2017〕433号

河南省文物局：

你局《关于沁阳市窄涧谷太平寺石窟保护规划立项的请示》（豫文物〔2017〕56号）收悉。经研究，我局意见如下：

一、窄涧谷太平寺石窟文物构成简单，规划编制的必要性和紧迫性不足，我局不同意窄涧谷太平寺石窟保护规划编制立项。

二、请你局督促、指导当地人民政府加强“四有”建设，完善窄涧谷太平寺石窟的保护区划、管理规定和具体保护管理措施，严格控制周边建设活动，妥善处理文物保护与景区建设、旅游开发的关系。同时，应加强日常保护管理，针对文物残损病害状况和发展趋势，适时开展相关保护工作，确保文物及周边环境安全。

专此函。

国家文物局

2017年4月12日
