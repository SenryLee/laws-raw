# 农业部对十二届全国人大五次会议第5987号建议的答复

## 对十二届全国人大五次会议第5987号建议的答复

农办议〔2017〕151号

阳国秀等10名代表：

你们提出的关于支持湖南食用菌良种繁育基地建设的建议收悉。经研究,现答复如下。

食用菌营养丰富，是公认的健康食品，发展食用菌产业是促进农民增收致富的重要途径。农业部高度重视食用菌生产，不断加大支持力度，推动食用菌产业健康稳定发展。一是加强食用菌品种保护。目前列入植物新品种保护名录的食用菌属（种）已达6种，可基本满足我国食用菌品种保护需要。在新修订的《种子法》中，将植物新品种保护单列为一章，提高了包括食用菌在内的植物新品种保护的法律地位。二是推进食用菌标准化生产。农业部加强标准体系建设，围绕食用菌产业发展需要，组织制定了一系列涵盖栽培基质（环境）、菌种、生产技术规程、收贮运、产品等各生产环节，以及安全技术类的国家标准和行业标准，有力促进了食用菌标准化生产水平的提升。三是加强食用菌良种繁育基地建设。农业部通过种子工程、农业综合开发项目不断加大对食用菌良种繁育基地建设支持力度。2006年以来，中央财政累计投入资金1.46多亿元，支持食用菌良种繁育基地建设，提升食用菌良种供应能力。

目前，农业部正在组织编制《现代种业提升工程建设规划（2017—2025年）》，已将食用菌良种繁育基地建设纳入支持内容。湖南省可依据现代种业提升工程规划及年度项目申报指南要求，申报此类项目，农业部将积极予以支持。

感谢你们对“三农”工作的关心，希望今后继续对我部工作予以支持。
