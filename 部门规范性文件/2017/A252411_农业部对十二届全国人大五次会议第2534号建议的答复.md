# 农业部对十二届全国人大五次会议第2534号建议的答复

## 对十二届全国人大五次会议第2534号建议的答复

农办议〔2017〕59号

丘杏红等6代表：

你们提出的关于建立农村创业孵化基地,帮助农村青年创业的建议收悉。经研究，现答复如下。

党中央、国务院高度重视农民创业创新，近年来出台了一系列政策措施。农业部立足职能，认真贯彻落实，把农村创业创新作为一项战略性、长期性、经常性的重要任务来抓。一是推动政策创设和落实。2016年11月，国务院办公厅印发《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》（国办发〔2016〕84号，以下简称《国办意见》），为返乡下乡人员创业创新提出了更系统、更全面、针对性更强的政策支持，从市场准入、金融服务、财政支持、用地用电、创业培训、社会保障、技术支持和创业园区等八个方面推动返乡下乡人员创业创新。2017年6月，农业部印发《关于开展支持返乡下乡人员创业创新政策落实督促检查工作的通知》（农办加〔2017〕18号），督促各地积极与有关部门沟通，制定实施意见。截至目前，已有12个省（市）政府办公厅配套制定了支持返乡下乡人员创业创新促进农村一二三产业融合发展的实施意见。二是建立协调推进机制。农业部联合国家发展改革委等12个部门建立“农村创业创新工作推进协调机制”，各成员单位相互支持配合，开展政策协调，督促政策落实。目前，已有17个省（区、市）建立了农村创业创新推进协调机制，并在农业部门下设办公室。三是推进网上创业就业。联合商务部等19部门加快发展农村电子商务；加强农业领域电子商务和网上创业平台建设，开展手机创业培训，召开“互联网+”现代农业工作会议暨新农民创业创新大会，积极培育农业电子商务市场主体，启动鲜活农产品和农业生产资料电子商务试点示范，进一步测试运行、健全完善全国信息进村入户平台。四是宣传推介典型示范。把培养和树立创业创新优秀带头人作为重要任务，遴选推介100个全国农村创业创新优秀带头人典型案例，发挥示范带动作用，弘扬创业创新精神。各项工作取得了积极进展和成效。

二、关于帮助农村青年创业培训方面

2014年，农业部联合财政部启动实施新型职业农民培育工程，目前全国共培育各类新型职业农民260多万人。2016年，中央财政安排资金13.86亿元，用于支持新型职业农民培训。2017年，中央财政投入15亿元，重点实施现代青年农场主培养计划、新型农业经营主体带头人轮训计划、农村实用人才带头人和农业产业精准扶贫培训计划，全年计划培育100万人以上。农村实用人才带头人和大学生村官示范培训项目，每年遴选一批种养大户、家庭农场主、农民合作社负责人和大学生村官等到农业部农村实用人才培训基地学习，帮助他们转变发展理念，提高生产经营水平，增强创业兴业、致富带富的本领。同时，探索采用政府购买服务方式，支持鼓励有条件的社会力量开展农村创业创新培训，组织培训班、专家对口帮扶等活动，为农民提供农业生产技术培训和跟踪服务。

二、关于建立农村创业孵化基地方面

依托现有开发区、农业产业园等各类园区以及专业市场、农民合作社、农业规模种养基地等，整合创建一批具有区域特色的返乡下乡人员创业创新园区（基地），是贯彻落实中央1号文件和《国办意见》精神的一项重要工作，有利于构建农村创业创新共享平台和服务体系，进一步增强各方面支持政策的引导性、精准性和协同性。2016年11月印发《农业部办公厅关于建立全国农村创业创新园区（基地）目录的通知》（农办加〔2016〕22号），各地符合条件的各类园区均可申报。坚持以农为本，以农业创业为主，引导从事设施农业、农产品流通、电子商务、农产品加工业、休闲旅游等创业创新的主体进入目录。2017年6月，农业部公布了1096个依法合规、功能完备、辐射带动能力较强、产业融合发展趋势明显的全国农村创业创新园区（基地）目录，为返乡下乡人员创业创新提供可选择的场所和高效便捷的服务。同时，强化政策集成，将《国办意见》提出的“八个政策大礼包”和农村产业融合政策，向园区整合，吸引地方政府、金融机构和社会资本向园区投资，把这些园区（基地）打造成农民创业创新的“孵化器”；依据园区（基地）实际运行变化情况，将适时更新目录，每年向社会公布一次。

下一步，农业部将充分发挥牵头作用，会同有关部门，统筹研究并督促各地抓好配套政策落实，加强农村青年创业创新能力素质培训、生产经营服务、产业政策扶持等服务；加大财政支持力度，联合发改委、财政部实施专项资金支持农民创业创新促进农村一二三产业融合发展，与农业银行、农业发展银行等整合信贷涉农资金向农民创业倾斜，让农民分享二三产业增值收益；发挥园区（基地）的引导作用，努力营造浓厚的农村创业创新良好氛围，推动农村创业创新蔚然成风。

感谢你们对农业工作的关心，希望今后继续关心和支持我部工作。
