# 交通运输部运输服务司关于做好禁毒公益宣传工作的函

## 关于做好禁毒公益宣传工作的函

交运便字〔2017〕42号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

为进一步贯彻落实习近平总书记等中央领导同志关于禁毒工作的重要指示批示精神，按照国家禁毒委员会的总体部署，在运输服务行业积极组织开展禁毒公益宣传，将禁毒知识纳入对旅客宣传内容，在长途客车、汽车站候车厅、具备条件的城市公共交通车辆、地铁，播放国家统一编制的禁毒公益宣传片。为做好禁毒公益宣传片的播放工作，现将有关事项通知如下：

一、认真做好禁毒公益宣传片播放组织工作

各级交通运输主管部门和道路运输管理机构要采取有效措施，做好禁毒公益宣传工作。一是做好禁毒公益宣传片的下载发放工作。要督促道路客运企业、客运站、城市公交企业、地铁运营企业尽快下载禁毒公益宣传片，明确播放时间安排。二是做好禁毒公益宣传片的播放使用工作。要督促客运企业为地铁、长途班线客车和旅游客车，在发车时或行驶途中安排一定时间对旅客循环播放；要督促客运站在候车厅内采取滚动方式播放，保证一定的播放时间，加大禁毒公益宣传力度。

二、加强监督检查，保证宣传效果

各级交通运输主管部门和道路运输管理机构要高度重视禁毒公益宣传片的播放使用，加强监督检查，指导督促客运站、运输企业切实按要求播放禁毒公益宣传片。

禁毒公益宣传片自通知下发起可在交通运输部道路运输司网站下载,下载网址为：http://zizhan.mot.gov.cn/sj/yunshs/jinduxuanchuan/index.html
