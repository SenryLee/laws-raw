# 国家文物局关于在凤凰山古建筑群保护范围和建设控制地带内进行岸线环境整治工程的意见

## 关于在凤凰山古建筑群保护范围和建设控制地带内进行岸线环境整治工程的意见

办保函〔2017〕399号

湖北省文物局：

你局《关于在全国重点文物保护单位凤凰山古建筑群建设控制地带内实施岸线环境整治工程的请示》（鄂文物〔2017〕10号）收悉。经研究，我局意见如下：

一、所报项目设计依据不足，文本深度不够，我局暂不同意在凤凰山古建筑群保护范围和建设控制地带内进行岸线环境整治工程。

二、所报方案应进行以下必要的修改和完善：

（一）应核实文物本体分布范围、工程范围及其与文物保护区划的关系，补充《凤凰山古建筑群文物保护规划》关于保护范围和建设控制地带的管理规定、具体控制要求。

（二）进一步深化方案设计，注意体现凤凰山古建筑群的主体地位和文化内涵，拟建项目的选址、高度、规模、外观样式、风格等应符合相关规定，与文物本体风貌相协调，避免过度人工化和现代景观园林化设计倾向。

（三）应充分考虑工程施工对文物安全的影响，制定必要的文物保护措施和应急预案。

（四）应重新编制文物影响评估报告，针对设计方案内容准确、客观地论证拟建项目影响，并研提工程措施调整建议，增强文物影响评估报告的针对性和科学性。

（五）进一步完善文本和图纸，补充工程范围与文物保护区划的叠加图，并在图上准确标注相关设施及道路的位置、走向、规模等内容。

三、请你局组织有关单位根据上述意见，对所报方案进行修改、完善后，按程序另行报批。

专此函。

国家文物局

2017年4月11日
