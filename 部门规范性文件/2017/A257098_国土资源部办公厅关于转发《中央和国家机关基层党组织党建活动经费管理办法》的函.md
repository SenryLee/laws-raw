# 国土资源部办公厅关于转发《中央和国家机关基层党组织党建活动经费管理办法》的函

国土资厅函〔2017〕1467号

国家海洋局、国家测绘地理信息局、中国地质调查局及部其他直属单位，各派驻地方的国家土地督察局，部机关各司局：

为进一步加强中央和国家机关基层党组织建设，推进“两学一做”学习教育常态化制度化，规范党建活动经费管理，财政部、中共中央直属机关工作委员会、中共中央国家机关工作委员会联合印发了《中央和国家机关基层党组织党建活动经费管理办法》（财行〔2017〕324号），现转发给你们，请遵照执行。

附件：财政部　中共中央直属机关工作委员会 中共中央国家机关工作委员会关于印发《中央和国家机关基层党组织党建活动经费管理办法》的通知

2017年10月13日
