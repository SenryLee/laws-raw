# 国家文物局关于云中郡故城城墙与二道路墓群抢救性保护工程立项的意见

## 关于云中郡故城城墙与二道路墓群抢救性保护工程立项的意见

办保函〔2017〕151号

内蒙古自治区文物局：

你局《关于全国重点文物保护单位云中郡故城城墙与二道路墓群抢救性保护工程立项的请示》（内文物发〔2016〕303号）收悉。经研究，我局意见如下：

一、暂不同意云中郡故城城墙与二道路墓群抢救性保护工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步明确工程对象，应坚持最小干预的原则，严格控制工程范围和规模，主要针对存在稳定性和安全性威胁的城墙区段开展保护工程，已处于稳定状态的城墙区段宜维持现状。

（二）进一步明确被房屋建筑占压或作为农田使用的遗址区段实施工程的可行性。

（三）工程措施和材料应当尽量符合传统工艺，可采用土坯砌补、支撑等物理方法减缓遗址本体的损坏，慎重使用锚固、灌浆等不可逆的措施与材料。

（四）进一步加强遗址的考古和研究工作，为保护工程提供科学依据。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局
