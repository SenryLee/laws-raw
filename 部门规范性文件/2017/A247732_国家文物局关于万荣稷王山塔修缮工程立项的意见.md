# 国家文物局关于万荣稷王山塔修缮工程立项的意见

## 关于万荣稷王山塔修缮工程立项的意见

办保函〔2017〕155号

山西省文物局：

你局《关于申请万荣县稷王山塔修缮工程立项的请示》（晋文物〔2017〕2号）收悉。经研究，我局意见如下：

一、暂不同意万荣稷王山塔修缮工程立项。

二、对该立项报告提出以下修改意见：

（一）应加强现状勘察，明确文物保存现状、塔体构造、残损情况、周边地质情况等，深入分析塔身残损、塔基风化等病害原因，科学评估塔体结构稳定性。客观评估2012年修缮工程效果，进一步论证工程实施的必要性和可行性。补充说明现状地面排水情况和附近采石场对文物的影响评估。

（二）塔体一层南面裂缝局部拆砌应慎重，查明开裂原因，并做好塔体的安全支护工作；应按原位置重砌塔顶松散砖；补充塔基周边场地排水设计，避免影响文物安全；补充塔刹复原依据，严禁缺乏科学依据的盲目复原。

（三）不同意在塔周修建仿古护栏，应沿古塔保护范围边界树立防护网并预留出入口。

（四）规范文本和图纸，补充总平面图。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年2月22日
