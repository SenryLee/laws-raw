# 国家文物局关于竹山书院保护规划意见的函

## 关于竹山书院保护规划意见的函

文物保函〔2017〕1198号

安徽省文物局：

你局《关于批准竹山书院保护规划的请示》（皖文物保〔2016〕155号）收悉。经研究，我局意见如下：

一、原则同意所报修改后的竹山书院保护规划。

二、对该规划进一步提出以下修改意见：

（一）加强现状评估，补充研究竹山书院与周边民居建筑的关系。

（二）应根据文物分布情况和保护管理需要，科学调整保护区划和管理规定。竹山书院西侧民居不宜纳入保护范围。建设控制地带位于历史文化名村核心保护范围，管理规定应与《历史文化名城名镇名村保护条例》和《雄村保护发展规划》要求相协调。

（三）进一步完善保护措施，“文化保护”应纳入管理规划；“标志标识措施”应纳入展示规划。

（四）应根据《全国重点文物保护单位保护规划编制要求》规范文本和图纸，增强规划图纸和规划文本的对应性。现状图与规划图应分类编号。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的竹山书院保护规划报请安徽省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体计划或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好竹山书院的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年7月6日
