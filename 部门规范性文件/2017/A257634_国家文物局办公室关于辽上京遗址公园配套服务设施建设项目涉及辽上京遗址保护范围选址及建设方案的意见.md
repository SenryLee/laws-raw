# 国家文物局办公室关于辽上京遗址公园配套服务设施建设项目涉及辽上京遗址保护范围选址及建设方案的意见

办保函〔2017〕1243号

内蒙古自治区文物局：

你局《关于建设辽上京国家考古遗址公园配套服务设施的请示》（内文物发〔2017〕129号）收悉。经研究，我局意见如下：

一、暂不同意辽上京遗址公园配套服务设施建设项目涉及辽上京遗址保护范围的选址及建设方案。

二、所报建设方案尚需做以下必要的修改和完善：

（一）拟建设施选址位于辽上京遗址保护范围内，且紧邻乾德门遗址，严重影响文物整体风貌，建议进一步论证项目选址的合理性和必要性。

（二）优化建筑外观设计和功能分区，核减游客服务中心建筑规模，严格控制建筑高度和体量，并注意与遗址及其周边环境相协调；不同意建设多功能广场中金属杆和喷泉等设施；补充相关景观分析和多功能广场设计图纸。

（三）进一步深化文物影响评估，客观分析拟建设施对辽上京遗址文物本体和景观风貌的影响，研提客观合理的评估建议。

三、请你局指导项目建设单位，根据上述意见对所报方案做进一步修改和完善，按程序另行报批。

国家文物局办公室

2017年11月8日
