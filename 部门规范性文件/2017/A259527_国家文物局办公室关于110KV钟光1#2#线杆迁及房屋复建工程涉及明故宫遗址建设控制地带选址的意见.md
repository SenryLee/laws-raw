# 国家文物局办公室关于110KV钟光1#2#线杆迁及房屋复建工程涉及明故宫遗址建设控制地带选址的意见

办保函〔2017〕1439号

江苏省文物局：

你局《关于审批南京弹簧有限公司110KV钟光1#2#线杆迁及房屋复建设计方案的请示》（苏文物保〔2017〕234号）收悉。经研究，我局意见如下：

一、根据最新考古工作成果，所报项目选址位于全国重点文物保护单位明故宫遗址皇城南城范围内，属于皇城的重要组成部分。我局暂不同意南京弹簧有限公司110KV钟光1#2#线杆迁及房屋复建工程涉及明故宫遗址建设控制地带的选址方案。

二、请你局组织专业考古研究单位进一步开展明故宫遗址皇城南城区域的考古和研究工作，明确遗存的分布范围和保存状况，并依法报请江苏省人民政府尽快将新发现遗存纳入明故宫遗址保护范围，落实保护措施，确保文物安全。

国家文物局办公室

2017年12月28日
