# 农业部对十二届全国人大五次会议第5397号建议答复摘要

## 十二届全国人大五次会议第5397号建议答复摘要

关于鼓励扶持中药材规范化种植。通过强化规划引导、完善标准体系、推行标准化生产，保护野生资源，加强了对中药材种植户的技术培训和指导，促进了中药材规范化种植，实现中药材种植养殖科学发展。下一步，将进一步完善中药材标准体系，建设一批全程标准化生产示范基地，加大技术培训和指导服务力度。

关于挖掘各省道地药材种植优势。通过加强道地药材基地建设、特色优势区建设、道地品种认证，突出特色、提升质量、创响品牌，推进道地药材生产发展。下一步，将继续加强道地药材生产指导和优势产区建设，加大扶持力度，推进道地药材生产发展。

关于运用科学手段提高药材质量。通过强化科技支撑、规范种子（苗）生产、加强病虫害绿色防控，推动规范化和标准化生产，控制农药残留，提高药材质量安全水平。下一步，将依托国家中药材产业技术体系，加强科技攻关，加快技术推广应用，努力促进中药材质量提升。

关于合理调控，有序种植，避免游资炒作。着力构建中药材现代流通体系，已基本建成中药资源动态监测和技术服务体系，实时掌握大宗常用药材产销情况，引导以销定产，促进生产与市场的有效衔接、有序发展。下一步，将继续做好中药材产销信息监测，积极争取增加监测品种、扩大监测范围，促进中药材生产和市场有序发展。

农业部

2017年9月1日
