# 国家文物局关于琅琊山摩崖石刻及碑刻保护规划意见的函

文物保函〔2017〕2015号

安徽省文物局：

你局《关于批准琅琊山摩崖石刻及碑刻保护规划的请示》（皖文物保〔2016〕154号）收悉。经研究，我局意见如下：

一、原则同意所报琅琊山摩崖造像及碑刻保护规划。

二、对该规划提出以下修改意见：

（一）提炼历史价值评估，深入挖掘琅琊山摩崖造像及碑刻在艺术史、文学史和历史研究中的重要性和意义；完善现状评估，明确重点研究范围和文物核心价值载体。补充非文物建筑对文物本体及环境的影响评估和已实施的文物保护工程情况。

（二）应根据文物分布情况和保护管理需要，结合地形地貌现状，科学调整保护区划及其具体边界，增强可操作性。做好与其他等级文物保护单位管理规定的衔接。

（三）应针对现状评估结论，研提具体保护措施，明确工程类型、内容和目标，尽量减少文物本体的工程干预。

（四）应根据现状评估结论进一步细化环境整治内容，加强历史环境保护，尽量避免景观环境过度人工化；补充保护设施和展示服务设施建设清单，说明拟建设施的具体面积、规模、高度和建筑风貌等；深化管理规划，明确文物部门、宗教部门与风景名胜区管理机构之间的责权关系，妥善处理文物保护、宗教活动和旅游发展之间的关系；进一步梳理监测规划内容，明确监测工作重点。进一步论证宗教用地调整的科学性和可行性。

（五）校核、规范文本与图纸，精炼文本内容。说明性内容应纳入规划说明。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的琅琊山摩崖造像及碑刻保护规划报请安徽省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好琅琊山摩崖造像及碑刻的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月20日
