# 国家文物局关于南京城墙建设控制地带内杏花村艺术活动街区配套项目的意见

## 关于南京城墙建设控制地带内杏花村艺术活动街区配套项目的意见

办保函〔2016〕1382号

江苏省文物局：

你局《关于审批南京市秦淮区门西B地块杏花村艺术活动街区及门西胡家花园配套地块传统文化公众体验区项目方案的请示》（苏文物保〔2016〕264号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位南京城墙建设控制地带内，考古工作不足，地下文物分布情况不明，我局暂不同意该项目。

二、对所报方案提出以下修改意见：

（一）应尽快组织专业机构继续开展拟建区域的考古工作，明确地下文物的分布和保存状况，科学评估考古发现遗迹的价值，并根据考古工作成果科学调整方案设计。补充拟建区域的考古勘探和发掘图、考古发掘报告和文物价值评估内容。

（二）进一步完善项目设计方案，补充已发现唐代建筑群等重要考古遗迹的保护展示措施，研提工程建设期间城墙本体和考古遗迹的保护措施、应急预案，妥善处理文物保护与城市建设发展之间的关系。补充基坑降水止损预案。

（三）应根据考古工作成果深化文物影响评估报告，进一步说明拟建项目对考古遗迹的影响。

三、请你局根据所提意见，对项目方案进行修改完善后，按程序另行报批。

专此函。

国家文物局

2017年1月4日
