# 水利部审计室关于印发《水利部审计室2017年工作要点》的通知

审发〔2017〕1号

部直属各单位，各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局：

现将《水利部审计室2017年工作要点》印发给你们，请结合实际，认真制定2017年审计工作计划，抓好组织实施，全面完成各项审计工作任务。

水利部审计室

2017年2月9日

## 水利部审计室2017年工作要点

2017年水利审计工作的总体要求是：全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入贯彻习近平总书记系列重要讲话精神，按照水利部党组的决策部署，紧紧围绕全国水利厅局长会议确定的重点任务，立足服务，强化监督，开拓创新，扎实工作，有效发挥水利审计在促进水利重大决策部署贯彻落实、维护资金安全、完善体制机制、服务改革发展和推进廉政建设等方面的积极作用。

一、推动政策落实，组织开展项目审计调查。会同财务司组织开展对四川红鱼洞水库及灌区、甘肃引洮供水二期、福建长泰枋洋水利枢纽等工程的审计调查，实现关口前移，促进项目资金安全、工程按期完成和效益尽早发挥；会同水保司组织开展对陕西、甘肃等省的国家水土保持重点工程审计调查，加大对水土保持专项资金的跟踪问效力度；组织开展对水利扶贫项目建设和资金管理的审计调查，促进扶贫脱贫攻坚政策落地生根。

二、围绕资金绩效，组织开展预算执行审计。始终贯彻绩效理念，以保障水利资金安全高效使用为目标，选取2-4个部直属单位开展预算执行审计，监督检查预决算的真实性、合法性和效益性；结合经济责任审计，聚焦重点领域、重点资金、重点项目和重点单位，着力关注贯彻落实中央“八项”规定精神、国务院“约法三章”要求、“三公”经费和会议费支出等情况，查找是否存在屡审屡犯和顶风违纪的问题，及时发现和纠正有令不行、有禁不止的行为，促进严格预算约束，盘活资金存量，优化支出结构，不断提高预算绩效管理水平。

三、实现关口前移，组织开展建设项目审计。着力做好国家防汛抗旱指挥系统二期工程、国家地下水监测工程（水利部分）项目的中期审计，加强对资金、进度和质量的监督；组织对广西大藤峡、黑河黄藏寺水利枢纽的跟踪审计，摸清真实情况，查找薄弱环节，督促及时整改；根据竣工验收工作安排，拟组织对四川武都引水工程、嘉陵江亭子口水电站等进行竣工决算审计，切实做好水利财务管理信息系统建设项目验收审计，监督指导部直属单位建设项目竣工决算审计，为竣工财务决算审批和竣工验收提供服务支撑。

四、监督权力运行，组织开展经济责任审计。按照领导干部的管理权限，根据人事部门的委托，组织对部管领导干部开展经济责任审计，立足权力运行与责任落实，促进领导干部守法守纪守规尽责；根据不同类别、不同层级领导干部经济责任审计的内容，采取灵活多样的审计方式，重点监督检查领导干部在政策落实、重大决策、履职用权和廉洁自律等方面的情况，推动健全制度、规范管理和深化发展，促进领导干部依法作为、主动作为、有效作为。

五、关注投资风险，组织开展企业效益审计。坚持以推动企业深化改革和提质增效为目标，选取2-4个部直属单位投资的企业，以审计调查或与其他专项审计相结合的方式，着力审计监督企业的重大投资决策和投资绩效、法人治理、资产质量、内部控制、经营管理及发展潜力等情况，加大对权力集中的重点岗位和资金密集的重点领域、重要环节的审计力度，及时揭示和反映重大风险隐患，维护国有资产安全、增强风险防范和核心竞争能力，提高企业管理水平。

六、提升审计实效，组织开展整改后续审计。组织开展对以前年度审计查出问题整改落实情况的后续审计，对屡审屡犯单位，与单位主要负责人进行约谈，明确整改期限，落实整改责任，对整改不到位的，查明原因，严格问责；不断完善后续审计工作机制，积极推动将审计整改情况纳入领导班子述职述廉、年度考核和任职考核，确保审计查出问题能及时得到整改、落到实处，努力提升水利审计的效能。

七、发挥专业优势，不断做好协调配合工作。按照水利部党组的统一部署，积极配合做好巡视全覆盖工作；充分发挥领导小组成员单位的作用，加强对“三公”经费、事业单位投资办企业、水利扶贫项目等检查工作；积极配合国家审计和纪检部门调查核实等有关事项；积极参与有关司局组织开展的重点水利工程、水利专项资金等方面的督导检查工作。

八、健全工作机制，不断夯实审计发展基础。加强统筹管理，整合审计资源，改进审计方式，逐步建立规范高效的水利审计联动机制，努力提升水利审计监督效能；以提高审计质量为目标，加大审计理论研究、业务管理和规范化建设的工作力度，组织对《水利基本建设项目竣工决算审计暂行办法》进行修订，尽快出台《水利行业内部审计工作规定》《水利审计项目质量控制办法》，为水利审计规范有序开展提供有力保障。

九、加强队伍建设，不断提升审计业务能力。坚持以审代训的同时，积极采取网络培训、脱产培训、案列教学、座谈交流等学习形式，着力拓宽水利审计人员培训渠道，不断提升水利审计队伍的综合素质和整体水平；组织举办一期水利审计部门负责人培训班，从思想、能力、纪律、作风和廉政等方面进行教育；组织召开全国水利审计工作会议，总结交流水利审计工作取得的成功经验和有效做法，研究部署水利审计工作任务。
