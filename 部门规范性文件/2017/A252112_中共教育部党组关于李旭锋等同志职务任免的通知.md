# 中共教育部党组关于李旭锋等同志职务任免的通知

教党任〔2017〕108号

中共四川大学委员会：

经与中共四川省委商得一致，2017年5月10日研究决定：

李旭锋同志任中共四川大学委员会副书记，曹萍同志任中共四川大学委员会常委、副书记，敬静同志任中共四川大学委员会委员、常委、副书记，侯太平、梁斌同志任中共四川大学委员会委员、常委，李蓉军、张林同志任中共四川大学委员会常委；免去罗中枢同志的中共四川大学委员会常务副书记、常委，周学东同志的中共四川大学委员会副书记、常委，李虹、李光宪、魏于全、步宏同志的中共四川大学委员会常委职务。

中共教育部党组

2017年5月18日
