# 国家新闻出版广电总局关于“质量管理2017”教辅、少儿和生活类编校质量不合格出版物的通报

## 关于“质量管理2017”教辅、少儿和生活类编校质量不合格出版物的通报

新广出函〔2017〕371号

各省、自治区、直辖市和新疆生产建设兵团新闻出版广电局，中央军委政治工作部宣传局，中央和国家机关各部委、各民主党派、各人民团体出版单位主管部门，中国出版集团公司，中国教育出版传媒集团有限公司，中国科技出版传媒集团有限公司：

2017年国家新闻出版广电总局（以下简称“总局”）开展了出版物“质量管理2017”专项工作。其中，2017年下半年重点围绕教辅、少儿和生活类出版物进行了编校质量检查。

经检查，共有24种出版物编校质量不合格，涉及19家出版单位。总局依据《出版管理条例》《图书质量管理规定》对相关出版单位下发了《行政处罚决定书》，给予警告的行政处罚，并责令相关出版单位在30日内全部收回不合格图书。

各级新闻出版广电行政部门、出版单位主管部门和各出版单位要深入学习贯彻党的十九大精神，牢固树立质量第一的意识，不断加大质量管理力度，狠抓出版质量保障制度的完善和落实，为满足新时代人民群众的文化需求，提供更多的优质精神食粮。

附件：“质量管理2017”教辅、少儿和生活类编校质量不合格出版物名单

国家新闻出版广电总局

2017年11月10日
