# 国家文物局关于西安市临潼区斜口公益性纪念堂项目涉及秦东陵保护范围选址意见的函

## 关于西安市临潼区斜口公益性纪念堂项目涉及秦东陵保护范围选址意见的函

办保函〔2017〕759号

陕西省文物局：

你局《关于西安市临潼区斜口公益性纪念堂项目选址涉及秦东陵保护范围的请示》（陕文物字〔2017〕94号）收悉。经研究，我局意见如下：

一、拟建项目选址位于全国重点文物保护单位秦东陵的保护范围内，临近秦东陵四号陵园及周边陪葬墓地，不利于秦东陵的后续保护与展示，我局不同意西安市临潼区斜口公益性纪念堂建设项目涉及秦东陵保护范围的选址及建设方案。

二、请你局指导有关单位进一步调整公益性纪念堂项目设计思路，避让秦东陵保护范围另行选址，以确保文物安全。

国家文物局

2017年6月16日
