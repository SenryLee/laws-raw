# 国家文物局关于彬县开元寺塔修缮工程立项的意见

## 关于彬县开元寺塔修缮工程立项的意见

办保函〔2017〕177号

陕西省文物局：

你局《关于彬县开元寺塔抢险加固工程立项的请示》（陕文物字〔2016〕262号）收悉。经研究，我局意见如下：

一、暂不同意彬县开元寺塔修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）加强现状勘察，明确文物保存现状、塔体构造、残损情况等，客观评估文物历次修缮工程效果，深入分析存在问题；深化监测数据研究，补充分析塔体结构受力，进一步明确塔体倾斜、塔基沉降等病害原因和发展趋势，科学评估塔体稳定性。

（二）在上述工作的基础上，明确工程性质，拟定具有针对性的保护加固措施。

（三）坚持最小干预原则，以排除安全隐患为主，严格控制工程范围和规模，避免过度维修。

（四）规范文本和图纸，注意专业术语的使用。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年2月24日
