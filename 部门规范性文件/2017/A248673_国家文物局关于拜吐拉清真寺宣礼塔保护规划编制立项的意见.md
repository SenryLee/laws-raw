# 国家文物局关于拜吐拉清真寺宣礼塔保护规划编制立项的意见

## 关于拜吐拉清真寺宣礼塔保护规划编制立项的意见

办保函〔2017〕246号

新疆维吾尔自治区文物局：

你局《关于报送拜吐拉清真寺宣礼塔保护规划立项报告的请示》（新文物保发〔2017〕27号）收悉。经研究，我局意见如下：

一、拜吐拉清真寺宣礼塔文物构成单一，所报立项报告对规划编制的必要性和可行性论述不足，文本深度不够，我局不同意拜吐拉清真寺宣礼塔保护规划编制立项。

二、请你局督促、指导地方人民政府加强“四有”建设，完善拜吐拉清真寺宣礼塔的保护区划、管理规定和具体保护管理措施，严格控制周边各类建设活动，加强日常保护管理，确保文物及其周边环境安全。

专此函。

国家文物局

2017年3月14日
