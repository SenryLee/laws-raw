# 国家安全监管总局办公厅关于印发全国安全生产“一张图”地方建设指导意见书的通知

安监总厅规划〔2017〕69号

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局、各省级煤矿安全监察局，有关省级煤矿安全监管部门：

为加快实现全国安全生产“一张图”，指导各地更好开展安全生产风险预警与防控工程建设，促进信息系统互联互通和信息共享，按照全国安全生产信息化“一盘棋”统筹规划、《全国安全生产信息化总体建设方案》（安监总科技〔2016〕143号，以下简称《总体建设方案》）和《国家安全监管总局关于下达2017年安全生产预防及应急专项资金工作目标任务的通知》（安监总财〔2017〕79号）具体要求，现将《全国安全生产“一张图”地方建设指导意见书》（详见附件，以下简称《指导意见书》）印发给你们，请遵照执行，并就有关事项通知如下：

一、加强组织领导

各级安全监管监察机构和有关省级煤矿安全监管部门要以提高安全生产监管监察执法效能和安全生产风险预警防控能力为目标，加强安全生产信息化工作，建立健全安全生产信息化领导机构和工作机构，完善工作制度，明确职责分工，确保责任到具体部门、人员。按照《总体建设方案》和《指导意见书》，抓紧制定本地区安全生产“一张图”工程各项目的技术实施方案，明确项目建设目标、规模、内容、方式和验收指标及项目概算等，于2017年9月15日前报国家安全监管总局信息化工作领导小组办公室（以下简称总局信息办）。

二、提高业务应用效能

各单位要加快开发部署业务应用信息系统，大力开展信息化应用技能培训，有效提升安全监管监察人员的信息化能力水平。到2018年底，所有省级安全监管局（以下简称省局）和煤矿安监局均要实现安全生产和职业健康监管监察、应急管理核心业务信息化覆盖率100%、推广应用率100%。

三、强化系统整合共享

各单位要加快整合分散的应用系统，推动平台化和一站式服务，消除信息孤岛，实现不同类型用户的统一登录和集成访问。建设统一数据交换平台，与国家安全监管总局应用系统互联互通、信息共享和无缝对接，确保全国安全生产信息化“一盘棋”建设。

四、突出试点先行

承担高危行业企业风险预警与防控试点工程的地区，要有步骤地选择试点企业验证风险分析模型的准确性，避免一窝蜂式部署。要按照《指导意见书》有关要求，开展安全生产规律性、关联性特征分析，实现高危行业企业风险预警和监管监察技术手段创新，为有效防范遏制重特大事故提供可靠技术支撑。

五、严格项目与资金管理

各单位要严格按照有关项目管理规定，依法依规履行项目建设手续，加强对项目建设、预算执行、建设目标、建设质量等关键环节的把控。严格遵守财务纪律，加强资金管理使用，不得挪用、占用专项资金，确保专款专用，发挥投资效益。

各省级安全监管局、煤矿安监局及煤矿安全监管部门分别牵头负责本辖区内有关项目的实施工作，按季度向国家安全监管总局信息办报送有关工作进展情况（电话：010- 64464665，电子邮箱：xinxihua@chinasafety.gov.cn），并于2018年9月底完成项目建设。国家安全监管总局将进一步加强工程建设的监督指导和评价考核，组织开展项目建设目标实现情况、建设内容完成情况、财政资金执行情况等方面的专项检查。
