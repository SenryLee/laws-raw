# 环境保护部办公厅关于深圳市沛泓电子有限公司PH700型爆炸物毒品探测仪中镍-63放射源实行豁免管理的复函

## 关于深圳市沛泓电子有限公司PH700型爆炸物毒品探测仪中镍-63放射源实行豁免管理的复函

环办辐射函〔2017〕1288号

深圳市沛泓电子有限公司：

你单位《关于含镍-63放射源的PH700型爆炸物毒品探测仪最终使用用户豁免管理申请》（沛泓字［2017］002号）收悉。根据《放射性同位素与射线装置安全和防护条例》（国务院令第449号）及《放射性同位素与射线装置安全和防护管理办法》（环境保护部令第18号）的有关规定，现函复如下：

一、你单位生产、销售的PH700型爆炸物毒品探测仪内含有一枚活度为5.5E+8贝可的镍-63放射源，为Ⅴ类放射源。鉴于该类放射源活度低，且上述型号炸药/毒品探测器的固有安全性较高，对环境、公众和工作人员的影响很小，我部同意对上述型号爆炸物毒品探测仪中使用的镍-63放射源实行有条件豁免管理，豁免用户仅限于公共安全部门。

二、使用上述型号爆炸物毒品探测仪的单位可以免于办理辐射安全许可证；你单位销售上述型号爆炸物毒品探测仪给最终用户也无需办理放射性同位素转让审批及备案手续。

三、上述型号爆炸物毒品探测仪中使用的镍-63放射源不作为放射性物质进行管理。如发生个别镍-63放射源失控，也不作为辐射事故处理。

四、你单位应健全相关制度，加强对所售爆炸物毒品探测仪中镍-63放射源的跟踪管理。在产品说明书和销售合同中明确告知产品中含有放射源，同时告知有关放射源的危害和防护知识及售后管理要求。负责对仪器报废后其中的废放射源进行管理，承担送贮到有资质的放射性废物收贮单位的责任。

五、你单位应制定上述型号爆炸物毒品探测仪销售台账、售出仪器跟踪管理及废放射源处理记录，并在每年1月底前汇总上一年的有关情况报告广东省环境保护厅。

特此函复。

环境保护部办公厅

2017年8月9日
