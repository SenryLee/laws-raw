# 国家安全监管总局办公厅关于2017年第一季度政府网站抽查情况的通报

厅函〔2017〕151号

各省级煤矿安全监察局，总局和煤矿安监局机关各司局，应急指挥中心：

按照《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）、《国务院办公厅秘书局关于2016年第四次全国政府网站抽查情况的通报》（国办秘函〔2017〕5号）要求，现将国家安全监管总局2017年第一季度网站抽查情况通报如下：

一、抽查总体情况

总局组织第三方机构，于2017年3月对负责普查范围内的网站进了抽查，共抽查了5家省级煤矿安监局网站，按照《国务院办公厅关于开展第一次全国政府网站普查的通知》（国办发〔2015〕15号）确定的普查标准，采用“自动扫描+人工复核”相结合的方式进行检查，逐一打分。

抽查结果显示，有2家网站综合评定为合格，分别为安徽煤矿安全监察局政府网站、湖南煤矿安全监察局政府网站；有3家网站综合评定为不合格，分别为：江西煤矿安全监察局政府网站、河南煤矿安全监察局政府网站、陕西煤矿安全监察局政府网站。

本次综合评定不合格网站将被列入今年后三个季度重点抽查监测对象。

二、发现的主要问题

一是信息更新不及时。3家不合格网站中，有2家网站存在监测时间点前2周内的动态、要闻类栏目，以及监测时间点前6个月内的通知公告、政策文件类栏目未更新达5个，被单项否决。二是发现空白栏目。3家不合格网站中，1家网站存在空白栏目数量达5个，被单项否决。三是部分链接不可用。3家不合格网站都存在不可用链接，其中2家网站首页存在不可用链接。四是网站首页间歇性无法访问。1家网站监测截至日期前7天内，首页打不开的次数占全部监测次数比例达0.14%。

三、有关网站整改措施

根据抽查结果，被抽查的3家不合格网站主管单位立即采取措施，有针对性地整改问题。

一是整合相关新闻动态类栏目，将栏目数量减少，避免由于信息量有限产生信息更新不及时问题。二是将已关闭网站的导航撤销，将不能正常访问的链接删除，并对网站进行技术问题排查，及时解决自动链接错链问题。三是采用服务外包等方式强化网站管理和维护，应用相关检测软件定期对网站进行自查，发现问题及时整改。四是抓紧招录计算机和网络管理方面专业人员，充实政府网站管理维护力量。

四、下一步工作要求

2016年以来，总局严格落实国务院办公厅要求，每季度对负责普查范围内政府网站开展抽查监测，结果显示大部分网站管理规范，但仍有少数网站对国家政策要求执行落实不到位，导致出现漏洞。各单位要深刻吸取教训，不断提高各网站建设质量水平：

（一）抓紧整改并定期自查监测。有关单位要对照抽查监测报告中提出的整改建议，采取有针对性措施对网站进行系统地、彻底地整改，避免在以后的抽查监测中出现类似问题。同时，所有网站抓紧采用服务外包等方式，强化网站管理和维护，定期对网站进行自查监测，发现问题及时整改。

（二）抓紧撤销驻地煤监分局网站。严格落实《国家安全监管总局办公厅关于进一步加强政府网站普查监测和建设管理工作的通知》（安监总厅宣教〔2016〕124号）要求，尚未撤销驻地煤监分局网站的，抓紧进行撤销处理，相关信息内容纳入所属省级煤矿安监局政府网站，网站撤销和内容纳入情况请及时报送总局人事司（宣教办）。

（三）明确专人负责管理和维护网站。当前，各省级煤矿安监局政府网站都明确了协调推进机构，但仍有一些网站没有明确专人、专业技术人员管理网站。各省级煤矿安监局要加大招录力度，至少明确一名专业技术人员专职负责管理和维护政府网站，并不断加大网站建设投入力度。
