# 交通运输部关于废（终）止、转化16项交通运输强制性行业标准的公告

根据《深化标准化工作改革方案》（国发〔2015〕13号）和《强制性标准整合精简工作方案》（国办发〔2016〕3号），交通运输部组织开展了交通运输强制性标准整合精简工作，经国务院标准化协调推进部际联席会议第三次全体会议审议通过后，现决定废止《交通行业工人技术等级标准 总则》等6项强制性行业标准，且自本公告发布之日起停止施行；《汽车导静电橡胶拖地带》等10项强制性行业标准转化为推荐性行业标准。

附件： 废止、转化16项交通运输强制性行业标准一览表

交通运输部

2017年3月9日
