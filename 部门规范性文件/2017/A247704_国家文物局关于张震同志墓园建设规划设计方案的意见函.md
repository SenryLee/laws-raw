# 国家文物局关于张震同志墓园建设规划设计方案的意见函

## 关于张震同志墓园建设规划设计方案的意见函

办保函〔2017〕118号

中宣部宣教局：

你局来函及所转《中共湖南省委 湖南省人民政府关于在湖南平江县长寿镇修建张震同志墓园的请示》、张震同志墓园建设规划设计方案收悉。经研究，我局对拟建张震同志墓园规划设计方案无异议。

此复。

国家文物局

2017年2月13日
