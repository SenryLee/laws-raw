# 国家文物局关于唱经楼保护规划意见的函

## 关于唱经楼保护规划意见的函

文物保函〔2017〕1197号

山西省文物局：

你局《关于审批太原市唱经楼文物保护规划的请示》（晋文物〔2016〕129号）收悉。经研究，我局意见如下：

一、原则同意所报唱经楼保护规划。

二、对该规划提出以下修改意见：

（一）应加强历史研究，补充唱经楼历史格局变化和功能演变相关内容，明确其在太原历史文化名城中的地位。进一步完善现状评估，补充具体文物建筑现状评估内容。

（二）应根据文物分布情况和保护管理需要，科学调整保护区划，建议将唱经楼南侧已拆待建区域纳入建设控制地带，增强可操作性。进一步规范和细化保护区划管理规定和建设控制指标。

（三）梳理环境整治措施，调整绿化设计，避免绿化用水影响文物建筑安全；结合周边文物资源情况统筹考虑管理用房和停车场选址、规模；根据现状评估结论，进一步明确安防、消防规划的具体内容。

（四）加强所报规划与《太原市城市总体规划》和《太原市历史文化名城规划》等的衔接。

（五）应根据《全国重点文物保护单位保护规划编制要求》进一步规范文本和图纸，增强规划图纸和规划文本的对应性。补充文物本体现状图、保护措施图、分期规划图等。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的唱经楼保护规划报请山西省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体计划或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好唱经楼的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年7月6日
