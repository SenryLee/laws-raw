# 国家文物局关于安城城墙保护规划意见的函

文物保函〔2017〕2095号

浙江省文物局：

你局《关于要求审批全国重点文物保护单位安城城墙文物保护规划的请示》（浙文物发〔2017〕159号）收悉。经研究，我局意见如下：

一、原则同意所报安城城墙保护规划。

二、对该规划提出以下修改意见：

（一）进一步梳理文物构成，建议将城内道路纳入文物环境；进一步加强研究，凝练文物价值。

（二）梳理、完善现状评估，明确文物的物权和产权，细化护城河桥梁本体保存现状评估，补充城内建筑高度对文物的影响评估。

（三）应根据文物保护管理需要，科学确定保护区划，进一步论证将城内全部纳入二类建设控制地带的必要性和可行性。合理确定保护范围与建设控制地带的具体边界，补充边界控制坐标点。

（四）完善保护区划管理规定，结合安城城墙视线通廊保护合理制定一类、二类建设控制地带的管理要求和具体控制指标。不得开展复建项目。

（五）根据现状评估结论，细化保护措施，明确保护工程的类型、对象、范围等，增强针对性。

（六）细化城墙与叠压建筑之间关系的考古调查研究。进一步完善展示规划，结合城墙整体展示原则合理组织游线。

（七）进一步精炼规划文本，规范、完善图纸表达，注意图文一致。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的安城城墙保护规划报请浙江省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好安城城墙的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月29日
