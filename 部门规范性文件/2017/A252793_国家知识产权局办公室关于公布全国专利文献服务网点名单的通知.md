# 国家知识产权局办公室关于公布全国专利文献服务网点名单的通知

## 关于公布全国专利文献服务网点名单的通知

国知办函办字〔2017〕531号

各省、自治区、直辖市、新疆生产建设兵团知识产权局，各有关单位：

为贯彻落实《国务院关于新形势下加快知识产权强国建设的若干意见》（国发〔2015〕71号），加强知识产权信息公共服务建设，促进专利信息的广泛传播和有效利用，我局开展了全国专利文献服务网点的选拔工作。通过各单位自主申报、各省（区、市）知识产权局评审后推荐，经我局复核批准，确定北京市知识产权信息中心等120家单位为全国专利文献服务网点，现予公布。

全国专利文献服务网点是全国专利信息传播利用工作体系的基础节点，是服务创新驱动和经济发展的专利文献支持中心、专利信息咨询中心和知识产权公共教育中心。

各省（区、市）知识产权局要加强对当地专利文献服务网点的管理、支持和引导，充分发挥专利文献服务网点的作用。

各专利文献服务网点要为社会公众、创新主体提供专利文献支持、专利信息咨询、公共教育等基础性公益服务，持续丰富服务内容，不断提升服务能力，积极创新服务方式，为助力创新创业、服务地方经济发展做出贡献。

特此通知。

附件：全国专利文献服务网点名单

国家知识产权局办公室
