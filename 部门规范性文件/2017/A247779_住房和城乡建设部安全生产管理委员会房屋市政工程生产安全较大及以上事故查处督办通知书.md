# 住房和城乡建设部安全生产管理委员会房屋市政工程生产安全较大及以上事故查处督办通知书

## 房屋市政工程生产安全较大及以上事故查处督办通知书

建安[2017]2号

福建省住房城乡建设厅：

2017年2月12日，你省厦门市轨道交通工程2号线海东区间右线盾构减压仓在减压过程中起火，造成3人受伤，后经抢救无效死亡。根据《房屋市政工程生产安全和质量事故查处督办暂行办法》（建质[2011]66号）的规定，现对该起事故查处工作启动督办程序。

请你厅依照有关规定，组织本部门及督促下级住房城乡建设部门按照要求做好事故查处相关工作，并于2017年4月12日前将查处情况报告我部。

联系人及电话：高康，010-58933041。

中华人民共和国住房和城乡建设部安全生产管理委员会

2017年2月13日
