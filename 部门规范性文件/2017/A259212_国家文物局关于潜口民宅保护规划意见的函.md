# 国家文物局关于潜口民宅保护规划意见的函

文物保函〔2017〕2002号

安徽省文物局：

你局《关于批准潜口民宅保护规划的请示》（皖文物保〔2016〕157号）收悉。经研究，我局意见如下：

一、原则同意所报潜口民宅保护规划。

二、对该规划提出以下修改意见：

（一）应充分考虑文物为异地搬迁集中安置的特征，进一步厘清文物本体构成，周边环境不应纳入保护对象。完善现状评估，根据文物类型客观评价保存现状，深化石牌坊、石桥等石质文物本体病害评估。补充地质灾害评估内容。

（二）进一步明确潜口民宅与潜口村展示利用的关系、目标和定位，充分注重文物建筑本体价值展示与阐释，丰富展示内容，优化展示路线，并合理控制利用强度。进一步论证拟改建交通道路和民宅搬迁的必要性和可行性，合理调整游客服务中心选址。

（三）环境整治措施可考虑当地乡土景观特色，合理选择植株，避免过度人工化。建议以绿篱替代现有围墙，增强两个园区的整体性和协调性，并加强潜口村村落环境保护。

（四）根据调整后的基础设施评估完善基础设施规划。进一步完善防灾规划，并补充说明防洪措施的必要性。

（五）进一步加强所报规划与相关规划的衔接内容。规范文本和图纸表达，加强图文对应性。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的潜口民宅保护规划报请安徽省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体立项报告或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好潜口民宅的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月19日
