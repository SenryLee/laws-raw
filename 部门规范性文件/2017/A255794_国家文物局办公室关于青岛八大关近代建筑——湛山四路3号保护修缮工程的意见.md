# 国家文物局办公室关于青岛八大关近代建筑——湛山四路3号保护修缮工程的意见

办保函〔2017〕1013号

山东省文物局：

你局《关于上报青岛八大关近代建筑——湛山四路3号保护修缮工程勘察设计方案的请示》（鲁文发〔2017〕61号）收悉。经研究，我局暂不同意该设计方案，并提出修改意见如下：

一、深化文物建筑历史沿革、文物价值的研究，补充对建筑各部分原材料、原工艺、原做法的研究。

二、补充文物建筑结构检测评估内容，根据评估结论制定针对性的保护加固措施。

三、补充屋面原做法的勘查，核查木椽和望板尺寸。不宜新做SBS改性沥青防水卷材，若确需添加现代防水材料，建议采用三元乙丙防水卷材。

四、明确外墙修补范围，应采用原材料和工艺进行修补，不得采用水泥砂浆和乳胶漆粉刷一新。

五、补充文物建筑内墙、门窗保存现状评估，不得全部统一拆除新做。五金件的添配应参照现存物的式样、材质和做工。

六、进一步明确现有门窗颜色是否为原始颜色，再行确定油饰方法和油漆种类。

七、统一更换为不锈钢檐沟和下水管的做法欠妥。若原构件保存状况较差，建议采用与原构件形态、色泽相近的彩铝屋面排水系统。

请你局组织相关单位根据上述意见对方案进行修改完善后，按照我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的要求另行报批。

专此。

国家文物局办公室
