# 国家知识产权局关于给予朱书明吊销“专利代理人资格证书”的专利代理惩戒决定书

## 关于给予朱书明吊销“专利代理人资格证书”的专利代理惩戒决定书

国知惩戒决字〔2017〕2号

专利代理惩戒决定书

姓 名：朱书明

身份证号：410122198605181710

资格证号：3216344

所在机构：镇江市创冠专利代理事务所（普通合伙）

2016年11月，中华全国专利代理人协会上报《关于对镇江市创冠专利代理事务所（普通合伙）朱书明等三人执业证办理事宜的请示函》，其中提出，中华全国专利代理人协会在审核镇江市创冠专利代理事务所（普通合伙）（以下简称“镇江创冠”）朱书明、吉李洁、舒佳英三名合伙人的专利代理人执业证申请材料时发现，合伙人朱书明、吉李洁、舒佳英存在出租专利代理资质的违法违规行为，提请国家知识产权局作出进一步处理。

经查，2016年8月31日，朱书明、吉李洁、舒佳英向国家知识产权局提交了设立镇江市创冠专利代理事务所（普通合伙）的申请，并提交了合伙协议、专利代理机构设立审批事项告知承诺书等申请材料。经审批，镇江创冠于2016年9月6日取得专利代理机构注册证。负责人：朱书明，合伙人：朱书明、吉李洁、舒佳英，出资额占比分别为50％、30％、20％，机构地址为镇江市新区丁卯智慧大道668号。

2016年10月，镇江创冠向中华全国专利代理人协会提交了朱书明、吉李洁、舒佳英的执业证申请材料，包括三人档案存放证明以及专利代理事务所合伙人聘用协议。

朱书明的聘用协议显示：江苏浩邦知识产权服务有限公司镇江分公司（以下简称“江苏浩邦”）聘用朱书明为新设事务所合伙人，朱书明通过代江苏浩邦持有事务所的股权股份的形式，向江苏浩邦提供其所具备的办所资质，以供江苏浩邦设立及经营事务所使用。江苏浩邦为实际出资人，朱书明不进行实际的资金投入，不参与事务所的经营决策、日常管理及收益分配。江苏浩邦承诺，在使用朱书明办所资质时，使用其提供的所有证书、证件和资料的范围限于设立及经营事务所的过程中，维持事务所专利代理机构资质及开展专利代理业务所必要的事务环节。协议生效期限为江苏浩邦收到朱书明符合办所资质的合格文件之日起至朱书明作为江苏浩邦合伙人2年期满止。协议期间，江苏浩邦支付朱书明顾问费5万元/年，支付方式一年一付。

在调查中，江苏浩邦和朱书明均对于协议内容的真实性予以承认。

以上事实有下列证据材料为证：

1．镇江市创冠专利代理事务所（普通合伙）合伙协议

2．专利代理机构设立审批事项告知承诺书

3．朱书明的聘用协议

4．关于创冠专利代理事务所的情况说明

根据《中华人民共和国行政许可法》第三十一条的规定，申请人申请行政许可，应当如实向行政机关提交有关材料和反映真实情况，并对其申请材料实质内容的真实性负责。根据《专利代理管理办法》第五条的规定，专利代理机构的合伙人或者股东应当符合具有专利代理人资格，具有2年以上在专利代理机构执业的经历，能够专职从事专利代理业务等条件。

朱书明将其专利代理人资格证书提供给江苏浩邦用于设立新的专利代理机构，收取报酬，代他人持有新设立专利代理机构的股份。在申请设立专利代理机构时，朱书明在知晓专利代理机构设立条件、申请要求和法律责任的前提下，作出“申请材料真实有效”等不实承诺，提供虚假的合伙协议，隐瞒其不作为事务所的实际出资人、合伙人的重要事实，采用欺骗的方式为镇江创冠取得专利代理执业许可。

经我局专利代理惩戒委员会会议讨论认为，朱书明的上述行为属于《中华人民共和国行政许可法》第八十条第一项规定的“涂改、倒卖、出租、出借行政许可证件，或者以其他形式非法转让行政许可”、《专利代理惩戒规则（试行）》第八条第四项规定的“提供虚假证据、隐瞒重要事实”的情形。根据《中华人民共和国行政许可法》第八十条、《专利代理条例》第二十五条、《专利代理惩戒规则（试行）》第八条的规定，应当予以惩戒, 拟给予朱书明吊销“专利代理人资格证书”的处罚。

我局于2017年1月10日发出《专利代理惩戒意见告知书》（国知惩戒函字〔2017〕2号），依法向朱书明告知拟对其作出吊销“专利代理人资格证书”的处罚的事实、理由、依据以及其依法享有的权利。朱书明未在法定期限内提出听证要求。

2017年1月27日，我局收到朱书明的书面申辩，朱书明在其申辩书中希望予以减轻处罚，并辩称，1.设立镇江创冠的所有申请材料是由镇江创冠提交，其仅在聘用协议上签字，其他申请材料并不知晓，也并没有签字，未构成“提供虚假证据，隐瞒重要事实”的情形；2.镇江创冠并未取得专利代理资质，未进行具体专利代理事务，未形成租借专利代理人资格证书的事实，危害小；3.积极与江苏浩邦联系，协商停止挂证行为，且镇江创冠并未从事专利代理工作，属于情节轻微的情形。

针对上述申辩理由，我局认为朱书明的申辩理由不能成立。具体理由如下：

朱书明承认其在聘用协议上签字。而聘用协议显示：朱书明向江苏浩邦提供其办所资质，供江苏浩邦设立及经营事务所使用，维持事务所的专利代理机构资质及开展专利代理业务所必要的事务环节，在事务所设立及经营过程中，朱书明全力配合江苏浩邦办理工商、税务、年检等各项事务。从聘用协议可知，朱书明对于出租专利代理资质是明知的，同时对随后在镇江创冠设立审批中提交虚假材料的违法违规行为，也是支持和放任的。朱书明配合江苏浩邦以欺骗的方式取得镇江创冠专利代理机构注册证，扰乱了专利代理行业市场竞争秩序，情节严重，社会影响恶劣。此外，朱书明并未提供证据证明，其存在采取有效措施减少行为社会危害性的事实。

综上，根据当事人违法行为的事实、性质、情节与社会危害程度，依据《中华人民共和国行政许可法》第八十条、《专利代理条例》第二十五条、《专利代理惩戒规则（试行）》第八条的规定，我局决定：给予朱书明吊销“专利代理人资格证书”的处罚。

当事人如对本决定不服，可以在接到本决定书之日起60日内向国家知识产权局提出行政复议，也可以在收到本决定书之日起6个月内向有管辖权的人民法院提起行政诉讼。复议和诉讼期间，上述决定不停止执行。

国家知识产权局

2017年3月6日
