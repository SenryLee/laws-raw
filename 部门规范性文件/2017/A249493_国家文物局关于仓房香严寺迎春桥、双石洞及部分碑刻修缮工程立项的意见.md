# 国家文物局关于仓房香严寺迎春桥、双石洞及部分碑刻修缮工程立项的意见

## 关于仓房香严寺迎春桥、双石洞及部分碑刻修缮工程立项的意见

办保函〔2017〕309号

河南省文物局：

你局《关于淅川仓房香严寺迎春桥、双石洞及部分碑刻维修保护工程立项的请示》（豫文物〔2017〕54号）收悉。经研究，我局意见如下：

一、迎春桥、双石洞不属于全国重点文物保护单位仓房香严寺的文物构成，所报维修保护工程不属于我局行政审批事项。

二、进一步说明现有散落碑刻的年代、文物价值及其与仓房香严寺的关系，明确石质文物保护及保护性设施建设的具体思路和措施，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

三、请你局督促地方人民政府严格执行《仓房香严寺文物保护规划》，落实日常管理和巡查责任，科学确定展示利用强度和方式，妥善解决文物保护和地方经济发展之间的关系。

专此函。

国家文物局

2017年3月24日
