# 公开市场业务交易公告[2017]第12号——关于人民银行于2017年1月18日以利率招标方式开展了4600亿元逆回购操作的公告

## 公开市场业务交易公告

[2017]第12号

人民银行于2017年1月18日以利率招标方式开展了4600亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 7天 | 2000亿元 | 2.25% |
| 28天 | 2600亿元 | 2.55% |
