# 中华人民共和国住房和城乡建设部公告第1722号——住房城乡建设部关于2017年第十八批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

第1722号

## 住房城乡建设部关于2017年第十八批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，杨赳等130名申报注册土木工程师（岩土）初始注册人员、李顺美等182名申报一级注册结构工程师初始注册人员、魏富强等196名申报注册公用设备工程师初始注册人员、李璟等144名申报注册电气工程师初始注册人员、孙亮等40名申报注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1．准予杨赳等130名注册土木工程师（岩土）初始注册人员名单

2．准予李顺美等182名一级注册结构工程师初始注册人员名单

3．准予魏富强等196名注册公用设备工程师初始注册人员名单

4．准予李璟等144名注册电气工程师初始注册人员名单

5．准予孙亮等40名注册化工工程师初始注册人员名单

住房城乡建设部

2017年11月2日
