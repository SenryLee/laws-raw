# 国家文物局关于辽源矿工墓建设控制地带锅炉房、水冲厕所及花圃建设项目的意见

文物保函〔2017〕1915号

吉林省文物局：

你局《关于报送东北沦陷时期辽源矿工墓拟建锅炉房、水冲厕所及花圃的请示》（吉文物发〔2017〕140号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、对所报项目提出以下修改完善意见：

（一）平整地形，降低锅炉房高度；简化水冲厕所立面设计形式，使其与环境相协调。

（二）采取有效措施，降低项目建设中粉尘和项目建成使用后锅炉房烟气，厕所污水等不良因素对文物环境的影响。

（三）补充保护区划图、文物保护单位与建设项目位置图等相关基础资料图纸。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十八条规定，报城乡建设规划部门批准实施。工程施工期间，应加强监管，确保文物安全。

国家文物局

2017年11月30日
