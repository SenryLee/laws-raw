# 国家文物局办公室关于南京主城水系连通生态补水第一批次节点建设工程（大树根闸一金川河生态补水工程）的意见

## 关于南京主城水系连通生态补水第一批次节点建设工程（大树根闸一金川河生态补水工程）的意见

办保函〔2017〕1186号

江苏省文物局：

你局《关于审批南京主城水系连通生态补水第一批次节点建设工程（大树根闸一金川河生态补水工程）方案设计的请示》（苏文物保〔2017〕233号）收悉。经研究，我局意见如下：

一、补充对南京原有水系的研究分析，说明生态补水系统对南京原有水系的影响程度。

二、涉及城墙遗址段落的建设控制地带内的工程，建设前需进行必要的考古勘探工作。

三、进一步完善南京城墙考古勘探、保存现状、日常监测等相关数据，核查并明确穿越城墙的现有管道维持现状是否满足整体工程要求，科学评估项目建设过程及使用过程中对文物本体稳定性的影响问题，补充相关风险评估内容。

四、补充拟建设工程C-E段（原管位降低）及D-C段（新建管道）施工技术方案。补充针对文物本体结构稳定及主要问题制定的保护措施。补充敷设管道后，恢复场地原状的工程做法和要求。

五、应补充说明施工阶段的文物安全监测措施和相关应急预案，及时排除安全隐患。

六、请你局根据上述意见，组织相关单位修改、完善设计方案后，按程序另行报批。

七、请你局责成南京市人民政府及相关单位认真遵守《文物保护法》《文物保护法实施条例》《南京城墙保护规划》等相关规定，严格控制南京城墙保护范围和建设控制地带内的建设活动，切实保护文物本体及其周边环境的安全。

国家文物局办公室

2017年10月20日
