# 交通运输部办公厅关于严明中秋国庆“两节”廉洁纪律杜绝节日腐败的通知

交办机党函〔2017〕1356号

部属各单位，部内各司局：

2017年中秋、国庆“两节”将至，各单位和广大党员干部要深入贯彻全面从严治党要求，严格落实中央八项规定精神，坚决抵制“四风”，杜绝节日腐败。现将“两节”期间有关纪律要求通知如下：

一、各单位要加强节日期间的廉洁教育和监督管理，正确处理保障干部职工节日福利与违规滥发津补贴的关系，严禁违规发放津贴、补贴、奖金和实物；严禁变相组织公款宴请、公款旅游等活动；严禁公车私用。

二、广大党员干部要从严律己，自觉遵守廉洁自律各项规定，不准违规收送月饼、礼品和礼金及有价证券；不准利用职务之便谋取私利；不准参加赌博等不健康娱乐活动；不准出入私人会所；不准酒后驾驶。

节日期间是“四风”问题易发、多发期，各部门各单位要高度重视，加强对“三严禁、五不准”的监督检查，一经发现，严肃查处，严厉追责。广大党员干部要牢固树立底线意识和红线意识，紧绷廉洁这根弦，坚决抵制歪风邪气，以实际行动维护和保持交通运输风清气正的良好氛围，以优异的成绩迎接党的十九大胜利召开。

交通运输部办公厅

2017年9月13日
