# 商务部公告2017年第73号——决定准予沧州金长兴石油产品有限公司等成品油批发经营许可

## 商务部公告

2017年第73号

依据《行政许可法》、《国务院对确需保留的行政审批项目设定行政许可的决定》(国务院令第412号)、《成品油市场管理办法》(商务部令2006年第23号)和《原油市场管理办法》(商务部令2006年第24号)的有关规定，经审核，商务部决定准予沧州金长兴石油产品有限公司、大连西太平洋石油化工有限公司、九江市越盛燃料化工油库有限公司、无棣众泽商贸有限公司、东营锐浩油品销售有限公司、中化石油（莱阳）有限公司（投资主体发生变化、注销新增）、福建省长乐市中海石化储运有限责任公司（投资主体发生变化、注销新增）成品油批发经营许可；

准予天津汇洋石油储运有限公司、天津壳牌石油储运有限公司、福建闽海能源有限公司、福建省长乐市中海石化储运有限责任公司（投资主体发生变化、注销新增）、海南华信国际控股有限公司、台州天棋石油有限公司（投资主体发生变化、注销新增）成品油仓储经营许可；

准予大庆联谊石化股份有限公司原油销售经营许可；

准予东北中石油国际事业有限公司、大连北方油品储运有限公司、海南华信石油基地有限公司、中海油烟台港石化仓储有限公司原油仓储经营许可；

注销福建省长乐市中海石化储运有限责任公司（投资主体发生变化、注销新增）、舟山市龙舟石化有限责任公司、宁波市鄞州商业石油有限公司、莱阳东方投资有限公司（投资主体发生变化、注销新增）成品油批发经营许可；

注销福建省长乐市中海石化储运有限责任公司（投资主体发生变化、注销新增）、台州天棋石油有限公司（投资主体发生变化、注销新增）成品油仓储经营许可。
