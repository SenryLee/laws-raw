# 国家旅游局监督管理司关于报送旅游标准化相关信息的通知

## 关于报送旅游标准化相关信息的通知

旅监管函〔2017〕81号

各省、自治区、直辖市旅游发展委员会、旅游局，新疆生产建设兵团旅游局：

为全面了解各地旅游标准化工作成果、促进交流，加强全国旅游标准化工作的沟通、协调和统筹，国家旅游局现决定开展旅游标准化信息报送汇总工作，具体事项通知如下：

一、报送各省级旅游局(委)旅游标准化工作的归口处室和旅游标准化技术委员会信息，填写《旅游标准化工作基本信息表》（附件1）。

二、做好已发布的旅游业省级地方标准的备案工作，填写《旅游业地方标准信息汇总表》（附件2）及《旅游业地方标准信息表》（附件3），同时提供地方标准文本的电子版。

三、推荐2-3名旅游标准化领域的专家（非公务员身份），作为第五届全国旅游标准化技术委员会委员的甄选对象，填写《全国旅游标准化工作专家推荐表》（附件4）。

请于5月15日前将以上信息报国家旅游局监督管理司，并将填写完成的表格和地方标准文本电子版发送至ttcc@cnta.gov.cn。相关表格附件在国家旅游局网站www.cnta.gov.cn“通知公告”栏目下载。联系人:刘庆安、凌素培，联系电话：010-65201333。

附件：1. 旅游标准化工作基本信息表

2. 旅游业地方标准信息汇总表

3. 旅游业地方标准信息表

4. 全国旅游标准化工作专家推荐表

国家旅游局监督管理司

2017年4月19日
