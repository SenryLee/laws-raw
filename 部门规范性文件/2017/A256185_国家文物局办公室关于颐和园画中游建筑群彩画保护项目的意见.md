# 国家文物局办公室关于颐和园画中游建筑群彩画保护项目的意见

办保函〔2017〕1115号

北京市文物局：

你局《关于颐和园画中游建筑群修缮工程彩画专项方案的请示》（京文物〔2017〕964号）收悉。经研究，我局意见如下：

一、所报项目前期勘察和研究不足，文本深度不够，我局暂不同意所报颐和园画中游建筑群彩画修缮项目。

二、对该项目提出以下修改意见：

（一）应切实加强前期勘察和研究，查明彩画主要病害类型、分布范围和残损程度，明确原彩画的形制特点、工艺技法和使用材料，结合彩画赋存环境条件和价值特征，分类制定具有针对性的保护措施。应加强相关历史资料收集、研究工作，为彩画纹样重绘提供依据。

（二）应依据颐和园保护展示需求，结合现状评估结论提出合理有效的技术路线。坚持最小干预原则，以现状修缮为主，严格控制补绘、重绘范围和干预强度。

1．明确采取彩画补绘措施的对象，进一步论证将现有彩画铲除重画的必要性。

2．补充说明缺失彩画补绘、重绘的设计依据。应在价值评估基础上，根据彩画的保护效果，确定重绘彩画色调，做好新旧彩画之间的衔接，避免造成对比过于强烈的效果。明确重绘彩画制作材料和工艺要求。设计图稿应经过专家论证后实施。

3．补充说明彩画修复的具体措施。

4．注意纹样留取和记录，最大限度地保存历史信息。

5．在壁画支撑体和地仗的基础上采用油饰彩画进行绘制的廊心画制作方法特殊，病害产生原因有别于普通壁画和彩画，应在进行专项研究后，制定有针对性的保护措施。

（三）进一步规范文本和图纸。补充彩画病害图、大样图等图纸。补充彩画现状纹样详图和细部照片。

三、请你局组织相关单位根据我局《关于颐和园画中游建筑群修缮工程方案的批复》（文物保函〔2014〕1209号）及上述意见，对项目进行修改完善后，按我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的相关要求另行报批。

专此函复。

国家文物局办公室
