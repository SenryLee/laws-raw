# 国家海洋局办公室关于印发《建设项目用海面积控制指标（试行）》的通知

沿海省、自治区、直辖市海洋厅（局），国家海洋局海洋咨询中心：

为全面贯彻落实《海岸线保护与利用管理办法》和《围填海管控办法》，推进海域海岸线资源全面节约和高效利用，根据生态用海、生态管海的要求，我局组织制定了《建设项目用海面积控制指标（试行）》。现印发给你们，请遵照执行。

国家海洋局办公室

2017年5月27日
