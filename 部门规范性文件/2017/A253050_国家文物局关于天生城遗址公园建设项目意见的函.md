# 国家文物局关于天生城遗址公园建设项目意见的函

## 关于天生城遗址公园建设项目意见的函

文物保函〔2017〕1068号

重庆市文物局：

你局《关于天生城大遗址公园设计方案的请示》（渝文物〔2017〕126号）收悉。经研究，我局意见如下：

一、原则同意天生城遗址公园建设项目。

二、该建设项目应做好以下几个方面的工作：

（一）进一步明确天生城遗址文物构成，准确区分文物本体、文物环境及其他建构筑物等，为后续工程实施奠定基础。

（二）应科学确定天生城遗址公园的定位和主要功能，以确保文物安全、系统阐释和展示文物价值为主，严格控制文物保护范围内的新建设施数量、规模，妥善解决文物保护与城市建设发展、民生改善之间的关系，充分发挥文物保护的综合效益。

（三）涉及天生城遗址城墙、寨门、炮台、摩崖石刻等文物本体保护修缮工程，应单独编制工程设计方案，并按程序报批。需申请国家重点文物保护专项补助资金的，应事先纳入重庆市全国重点文物保护单位保护项目年度计划，相关方案审批程序和要求以我局批复意见为准。

（四）出入口、参观游步道、防护栏、游客服务设施及配套基础设施等建设项目，以及风貌整治、绿化隔离带建设等相关项目，如涉及天生城遗址保护范围和建设控制地带的，应编制详细的建设工程设计方案，做好文物影响评估，按程序报我局审批。

（五）涉及考古发掘的，应按要求另行填报考古发掘申请书并按程序报批。涉及其他文物本体保护修缮的，应按有关规定报相应的文物部门审批。

三、请你局指导建设单位，按照上述意见有序推进天生城遗址文物保护和遗址公园建设工作，并加强事中事后监管和工地检查，确保工程质量和文物安全。

国家文物局

2017年6月7日
