# 国土资源部办公厅关于转发政府购买服务信息平台运行管理有关问题的通知

〔2017〕1616

各预算单位：

为加强政府购买服务信息网络建设，在全国范围内搭建政府与社会、中央与地方和各部门之间的信息交流平台，更好地推动政府购买服务改革工作发展，财政部依托“中国政府采购网”创办了“中国政府购买服务信息平台”，并印发了《关于政府购买服务信息平台运行管理有关问题的通知》（财综〔2017〕57号），现转发给你们，请遵照执行。

2017年11月13日
