# 中华人民共和国住房和城乡建设部公告第1729号——住房城乡建设部关于2017年第十六批注册监理工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

第1729号

## 住房城乡建设部关于2017年第十六批注册监理工程师初始注册人员名单的公告

根据《注册监理工程师管理规定》（建设部令第147号）和《关于建设部机关直接实施的行政许可事项有关规定和内容的公告》（建设部公告第278号），经审核，刘海林等353名申请注册监理工程师初始注册人员符合初始注册条件，准予注册。

特此公告。

附件：准予刘海林等353名注册监理工程师初始注册人员名单

住房城乡建设部

2017年11月16日
