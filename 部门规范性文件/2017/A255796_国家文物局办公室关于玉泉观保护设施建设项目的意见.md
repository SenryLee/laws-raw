# 国家文物局办公室关于玉泉观保护设施建设项目的意见

办保函〔2017〕1024号

甘肃省文物局：

你局《关于开展玉泉观保护设施建设项目的请示》（甘文局发〔2017〕134号）收悉。经研究，我局意见如下：

一、所报项目性质不清，设计依据不足，对文物环境影响较大，文本深度不够，我局暂不同意玉泉观保护设施建设项目。

二、该方案应进行以下必要的修改和完善：

（一）进一步核实项目对象是否为文物本体；涉及文物本体修缮的，如石质文物保护，应根据文物保护工程的原则和要求以及我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的相关要求另行报批。同时，应核实文物本体分布范围、项目范围及其与文物保护区划的关系。补充甘肃省人民政府关于玉泉观保护范围和建设控制地带的管理规定和具体控制要求、项目范围与文物保护区划叠加图以及维修改建总平面图中各子项具体项目内容。

（二）不同意采用钢筋混凝土网格、毛石挡土墙进行崖体和护坡加固。应加强现状勘察，进一步评估文物载体和环境特点，尽量在不改变现状的基础上选择不影响文物环境的加固方式。补充危崖体、护坡现状立面图和现状照片。

（三）应说明厕所的选址依据，严格控制建筑高度，并进一步优化平、立面设计。

（四）应进一步论证碑廊相关措施的必要性，并说明拟采取措施的工程性质、具体内容和操作要求。

（五）设计依据应将《中华人民共和国文物保护法》作为依据，并据此指导方案思路调整与相应措施内容修改。

（六）应充分考虑施工振动对文物安全的影响，制定必要的文物保护措施和应急预案。

（七）消防工程应按程序另行报批。

（八）应重新编制文物影响评估报告，根据方案内容准确、客观论证拟建项目对文物本体及环境风貌的影响，增强针对性。

三、请你局组织相关单位根据上述意见，对项目方案进行修改完善后，按程序另行报批。

四、请你局指导当地人民政府组织专业机构，按照《关于玉泉观保护规划的意见》（办保函〔2015〕332号）的要求，抓紧修改完善玉泉观保护规划，统筹考虑文物保护、展示利用、环境整治等方面工作。

专此函复。

国家文物局办公室

2017年8月31日
