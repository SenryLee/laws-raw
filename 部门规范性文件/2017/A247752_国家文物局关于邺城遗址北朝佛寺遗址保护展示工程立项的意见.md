# 国家文物局关于邺城遗址北朝佛寺遗址保护展示工程立项的意见

## 关于邺城遗址北朝佛寺遗址保护展示工程立项的意见

办保函〔2017〕65号

河北省文物局：

你局《关于邺城遗址北朝佛寺遗址保护展示工程立项的请示》（冀文物字〔2016〕209号）收悉。经研究，我局意见如下：

一、暂不同意邺城北朝佛寺遗址保护展示工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）佛寺塔基等遗址不宜露明保存，可采取必要的保护加固措施后采取标识或模拟展示的方式。

（二）不宜进行遗址区域表土整理，避免过度干预。

（三）遗存分布区域围栏防护应采取简单易行的方式，避免对遗址整体风貌产生过多不利影响。

（四）工程经费估算缺乏合理性，应严格控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局指导立项报告编制单位，根据上述意见对所报立项报告做进一步修改和完善，经你局核准后，按程序另行报批。

国家文物局

2017年2月8日
