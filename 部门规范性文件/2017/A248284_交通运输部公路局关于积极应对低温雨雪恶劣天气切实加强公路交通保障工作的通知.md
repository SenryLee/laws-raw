# 交通运输部公路局关于积极应对低温雨雪恶劣天气切实加强公路交通保障工作的通知

## 关于积极应对低温雨雪恶劣天气切实加强公路交通保障工作的通知

交公便字[2017]32号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委）：

根据中国气象局的气象预报，在冷空气影响下，今天起至2月23日，今年以来最大规模的雨雪天气来袭，雨雪将覆盖超一半国土，甘肃、陕西、内蒙古、山西部分地区有暴雪。新疆、西北地区东部、西南地区东部、华北中南部、黄淮、江淮、江汉、江南、华南北部等地气温将下降8℃以上，部分地区超过12℃。公路交通保障工作将面临更大的压力。在春运收官之际，为服务人民群众安全便捷出行，保障国家重点物资和人民群众生活必需品的正常运输，确保东北地区玉米及时外运，切实加强公路交通保障工作，现将有关事宜紧急函告如下：

一、高度重视，扎实做好应急值守工作。各单位要从讲政治、保稳定、确保市场供应的高度，充分认识当前应对低温雨雪天气做好公路交通保障工作的重要性，主要领导要亲自抓，明确责任，精心组织，周密部署。要进一步加强值班值守工作，特别是受此次恶劣天气影响的省份要立即行动，落实24小时值班和领导带班制度，密切关注天气变化，及时掌握本地区路网运行状况，一旦发生突发事件，要及时妥善处置，并按规定报送信息。

二、科学防范，加强路网运行监测和服务。各单位要针对本轮影响我国大部分区域的低温雨雪天气特点，结合各地区防御工作重点，加强路网运行监测，继续加强与气象、公安等相关部门的协调会商，密切关注天气变化趋势，立足超前防范，切实做好日常公路气象预报和重大公路气象预警工作，多渠道发布雨雪等公路气象预警信息，提醒受影响区域交通运输部门做好各项应对准备。要进一步做好公路出行信息服务，充分利用电视、广播、移动通信、微信、微博等媒体和公路沿线可变情报板，及时发布公路交通阻断等路况信息，引导社会公众及时调整出行路线。

三、抓好落实，全力保障公路通行及作业安全。各单位要把做好公路通行保障作为首要任务，根据天气变化，及时启动预案，落实各项措施，最大限度减小天气对公路通行的影响。要加强防滑料等应急物资的储备和补充，对重要的国省干线、桥隧加大养护、排查力度，做好公路抢通保通工作。要加强同公安交通管理机构的协作，科学应用警车带道、间断放行、车辆分流等措施，全力保障高速公路和普通国省干线的平稳运行。要加强省际间协调配合，确保管制措施一致，并提前分流，防止出现大范围的车辆拥堵。公路应急抢通保通作业要体现“以人为本”理念，严格按照《公路养护安全作业规程》（JTG H30-2015）的要求，加强公路应急保通现场安全作业管理，确保公路养护作业人员、设备和车辆的安全。

四、做好东北地区玉米外运保障工作。东北地区要进一步加强玉米外运公路运输保障，重点确保玉米运输通道顺畅、便捷。如遇恶劣天气造成公路阻断时，要及时引导玉米运输车辆绕道通行，确保玉米运输不中断，并及时除冰除雪保畅，尽早恢复畅通。

五、继续做好春运公路交通运输保障。此次恶劣天气影响期正值春运后期，各单位要严格按照春运工作有关要求，继续做好公路保畅与出行服务，顺利完成春运公路交通保障任务，并认真做好春运相关总结工作。

六、加强公路地质灾害隐患排查治理。随着春季气候转暖，南方雨水增多，北方冰雪冻土消融，山体坍塌和融雪性洪水等灾害进入高发期。各单位要按照“预防为主、防治结合”的原则，加大公路地质灾害隐患排查治理工作力度，重点排查山区、高危边坡、临河路段以及隧道出入口，及时消除隐患，确保通行车辆及行人安全。

交通运输部公路局
