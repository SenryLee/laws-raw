# 农业部办公厅关于公布全国生猪遗传改良计划种公猪站名单的通知

农办牧〔2017〕1号

各省、自治区、直辖市及计划单列市畜牧兽医（农业、农牧）局（厅、委、办）:

根据《全国生猪遗传改良计划（2009—2020）》规定，我部组织全国生猪遗传改良计划工作领导小组办公室和专家组对申报全国生猪遗传改良计划种公猪站的企业进行了评审。根据评审结果，现公布上海祥欣种公猪站（普通合伙）、广西农垦永新畜牧集团有限公司良圻原种猪场2家企业为全国生猪遗传改良计划种公猪站。

各省级畜牧兽医部门要积极做好核心育种场与种公猪站的对接协调，督促企业认真规范开展遗传交流，扎实推进生猪联合育种。全国生猪遗传改良计划种公猪站要认真履行义务，开展国家生猪核心育种场间遗传交流，不断提升种公猪和精液产品质量，定期报送种公猪精液交流情况，保质保量完成核心育种群公猪精液交换任务。

农业部办公厅
