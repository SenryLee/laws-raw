# 国家文物局办公室关于明长城宁夏三关口段防洪工程设计方案意见的函

办保函〔2017〕915号

宁夏回族自治区文物局：

你局《关于报送明长城宁夏三关口段防洪工程设计方案的请示》（宁文物发〔2017〕53号）收悉。经研究，我局意见如下：

暂不同意明长城宁夏三关口段防洪工程设计方案。

二、所报方案尚需做以下的修改和完善：

（一）应坚持最小干预原则，严格控制工程范围和工程量。防洪措施应以对现状冲沟治理为主，重点做好长城遗址豁口区域必要的防护处理，确保洪水下泄顺畅。

（二）进一步深化前期勘察，明确每处冲沟的洪水量、洪水位及冲刷深度，客观分析洪水的实际破坏和影响程度，在此基础上合理确定导、排洪沟的过水断面规模，严格控制土方开挖量。

（三）应细化拟建导、排洪沟等相关设施的外观设计，所采取的护坡结构外观应尽可能保持现有形态，不宜过分规整，注意与周边环境景观相协调，避免因工程建设造成遗址周边环境明显改变。

（四）补充防洪工程措施的文物影响及环境影响评估内容。

三、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改和完善，按程序另行报批。

国家文物局办公室

2017年8月4日
