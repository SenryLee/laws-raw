# 国家核安全局关于批准阳江核电厂3、4号机组运行技术规范升版的通知

## 关于批准阳江核电厂3、4号机组运行技术规范升版的通知

国核安发[2017]72号

阳江核电有限公司:

你公司《关于〈阳江核电厂3、4号机组运行技术规范〉修改升版的请示》（广阳江〔2016〕56号）及报批版的运行技术规范（11版）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的要求，我局对你公司提交的申请文件进行了审评，认为你公司关于阳江核电厂3、4号机组运行技术规范的修改升版是可以接受的，现予批准。

你公司应严格按照我局批准的文件进行升版，确保阳江核电厂3、4号机组运行安全。

国家核安全局

2017年4月12日
