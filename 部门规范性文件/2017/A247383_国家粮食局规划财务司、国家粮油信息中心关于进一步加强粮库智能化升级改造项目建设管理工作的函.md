# 国家粮食局规划财务司、国家粮油信息中心关于进一步加强粮库智能化升级改造项目建设管理工作的函

## 关于进一步加强粮库智能化升级改造项目建设管理工作的函

司便函财务〔2017〕14号

有关省（区、市）粮食局：

粮库智能化升级改造项目自2015年试点启动、2016年14个省大规模开展以来，有关省（区、市）财政、粮食部门不断努力，取得了积极进展，为粮食行业信息化建设全面推进奠定了基础，积累了经验。为进一步推进粮库智能化升级改造工作，管好用好财政资金，更好地发挥资金使用效益，现就有关事项通知如下：

一、切实管好用好财政资金

各省（区、市）粮食部门要严格执行《“粮安工程”危仓老库维修专项资金管理暂行办法》（财建〔2016〕872号）等规定，积极落实配套资金，规范资金安排使用，加强监督检查，督促有关单位严守财经纪律，有效使用资金，确保财政资金使用安全。

二、稳步推进项目实施

各省（区、市）粮食部门要精心策划、务实推进，认真研究制订项目实施方案，明确核心功能需求，避免形成“信息孤岛”和“数据烟囱”，确保实现互联互通，不能为信息化而信息化，一定要克服盲目性，坚持实用、管用、好用的原则，不搞大而全、花架子，更不搞形象工程。要按照项目实施方案严格把控实施进度，加强督导调度，确保项目顺利完成。

三、建立项目进度季度报送制度

请有关省（区、市）粮食局按照附件2、3表格要求，认真组织指导各项目单位填报项目进度情况，经核对汇总后，于每季度第一周工作日将纸质版（盖章）及电子版同时报送我司。

四、全面总结实施经验

为及时掌握各地行业信息化建设情况，全面总结梳理项目实施经验效果，请各有关省（区、市）粮食局按照报送内容提纲（附件1）有关要求，报送文字汇报材料，并填报截至目前的项目进度表（附件2、附件3）。请将上述有关材料于2月17日前报送规划财务司。
