# 国家安全生产监督管理总局公告2017年第7号——决定注销中安国研（北京）安全技术咨询有限公司安全评价甲级资质

## 国家安全生产监督管理总局公告

2017年第7号

为深入贯彻落实《国务院办公厅关于清理规范国务院部门行政审批中介服务的通知》（国办发〔2015〕31号）要求，依据《行政许可法》第七十条、《安全评价机构管理规定》（国家安全监管总局令第22号）第十八条等相关规定，经研究，决定注销中安国研（北京）安全技术咨询有限公司安全评价甲级资质，现予公告。

国家安全监管总局

2017年6月26日
