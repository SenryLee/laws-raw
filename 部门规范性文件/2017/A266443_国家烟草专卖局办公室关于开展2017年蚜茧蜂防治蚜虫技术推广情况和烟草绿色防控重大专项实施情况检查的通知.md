# 国家烟草专卖局办公室关于开展2017年蚜茧蜂防治蚜虫技术推广情况和烟草绿色防控重大专项实施情况检查的通知

国烟办综〔2017〕343号

行业各直属单位：

按照《国家烟草专卖局办公室关于做好2017年蚜茧蜂防治蚜虫技术推广工作的通知》（国烟办综〔2017〕153号）和《国家烟草专卖局办公室关于印发烟草绿色防控重大专项实施工作方案和技术方案的通知》（国烟办综〔2017〕193号）要求，经研究，决定对各烟叶主产省(区、市)2017年蚜茧蜂防治蚜虫技术推广情况及烟草绿色防控重大专项实施情况进行检查。现将有关事宜通知如下：

一、检查组织

由国家局科技司和中国烟叶公司共同组织，遴选蚜茧蜂防治蚜虫技术全国推广执行专家组成员、烟草绿色防控重大专项全国技术专家组成员以及各产区相关技术人员组成检查组，具体负责检查工作（成员名单和工作安排见附件1）。各相关省级局科技、烟叶主管部门要协助检查组完成辖区内的检查工作。

二、检查范围

云南、安徽、福建、广西、广东、江西、湖南、湖北、山东、重庆、河南、贵州、四川、黑龙江、吉林、辽宁和陕西等17个烟叶主产省(区、市)。原则上每个烟叶主产省（区、市）随机抽取2—5个地市级公司进行现场检查。

三、检查内容

1.蚜茧蜂防治蚜虫技术推广情况。重点检查组织保障、队伍建设、培训宣传、繁蜂点规划、繁蜂设施、繁蜂管理、烟草农业上的推广面积、放蜂及防治效果、大农业推广情况、过程管理及成本控制等内容。具体检查内容见《蚜茧蜂防治蚜虫技术推广情况检查评分表及评分细则》（附件2）。

2.烟草绿色防控重大专项实施情况。重点检查组织保障、经费保障、培训宣传、技术研发、示范区建设、辐射推广、防效评价、过程管理及配套政策措施等内容。具体检查内容见《烟草绿色防控重大专项实施情况检查评分表及评分细则》（附件3）。

四、检查方式

本次检查采取听取汇报、现场检查、随机走访、查验资料等相结合的方式进行。在此基础上，分别对蚜茧蜂防治蚜虫技术推广情况和烟草绿色防控重大专项实施情况评分表各项内容进行定量评价，并形成检查意见。

五、检查时间

本次检查根据各烟叶产区生产进度分批开展，原则上安排在7—8月份进行,具体检查时间另行通知。

六、其他事项

1．请检查组成员按照检查工作安排，及时开展检查工作，请所在单位给予支持。

2．检查组成员食宿及差旅费用自理，由所在单位报销，严格按照国家局相关规定执行。

国家局科技司联系人：陈勇、王新中，电话：010—63606470、63606201。

附件：1.检查组成员名单及工作安排

2.蚜茧蜂防治蚜虫技术推广情况检查评分表及评分细则

3.烟草绿色防控重大专项实施情况检查评分表及评分细则
