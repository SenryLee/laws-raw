# 中华人民共和国工业和信息化部公告2017年第10号——关于修订《产业转移指导目录(2012年本）》甘肃省部分条款的决定

## 中华人民共和国工业和信息化部公告

2017年第10号

为贯彻落实国家西部大开发战略，不断适应经济发展新形势，深入推进产业有序转移和转型升级，我部对《产业转移指导目录（2012年本）》涉及甘肃省部分内容进行了修订，形成《关于修订<产业转移指导目录（2012年本）>甘肃省部分条款的决定》，现予公布，自2017年5月1日起施行。《产业转移指导目录（2012年本）》中甘肃省部分的条款停止执行。

附件：关于修订《产业转移指导目录(2012年本）》甘肃省部分条款的决定

工业和信息化部
