# 交通运输部关于公布2017年全国调整修订或增补新设引航员登/离轮水域的公告

为进一步完善引航员登/离轮水域规划，规范引航作业秩序，提高引航安全保障，服务港口和水上运输健康发展，本公告对全国主要港口已有的部分引航员登/离轮水域进行调整和修订，同时，根据港口发展和规划情况，在一些水域增补或新设了引航员登/离轮水域。调整或修订的引航员登/离轮水域序号对应2013年及以后部发布的涉及引航员登/离轮水域公告内的序号；增补或新设的引航员登/离轮水域序号在2013年及以后部发布的涉及引航员登/离轮水域公告内的序号之后排序。

本公告自公布之日起施行。

附件：1.2017年全国引航员登/离轮水域修订表

2.2017年全国引航员登/离轮水域增补表

交通运输部

2017年3月3日
