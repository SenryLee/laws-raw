# 国家卫生计生委办公厅关于组织开展2017年世界防治结核病日宣传活动的通知

各省、自治区、直辖市卫生计生委，新疆生产建设兵团卫生局：

2017年3月24日是第22个“世界防治结核病日”。为深入宣传贯彻习近平总书记在全国卫生与健康大会上的重要讲话精神和《“十三五”全国结核病防治规划》，进一步提高公众对结核病的防治意识，加快推进健康中国建设，我委决定在3月24日前后开展世界防治结核病日宣传活动。现将有关事宜通知如下。

一、活动主题

今年的活动主题是:“社会共同努力，消除结核危害”，旨在倡导各级政府、各部门、各单位和个人积极投身到结核病防治工作中来，各施所长，共同行动，进一步完善结核病防治服务体系，减少结核病的感染和传播，形成良好的防治社会氛围。

二、活动内容及安排

（一）精心策划、扩大宣传的覆盖面。各地要认真梳理当地的结核病防治现状，结合《“十三五”全国结核病防治规划》要求，以结核病日宣传活动为契机，向地方党委政府做一全面汇报，争取相关支持。要提早部署，统筹调动各方资源，有计划、系统性地组织开展各项宣传活动，向社会各界积极宣传“十三五”时期结核病防治的总体目标。要在城镇广场、市民公园、社区中心等人流较多的地方，开展集中的宣传活动。要在医疗卫生机构、监管场所、学校、建筑工地等重点地区张贴宣传材料，设置咨询台等，全面宣传结核病防治核心知识。各地要把结核病防治的宣传教育工作常规化、持续化，与建设卫生城市、健康城市，普及全民健康生活方式等行动有机结合，促进防治工作科学发展，营造良好的社会和政策支持环境。

（二）点面结合，提高宣传的针对性。各级卫生计生行政部门要积极与宣传、人社、民政等部门联合，有针对性向结核病患者宣传结核病保障政策，鼓励病人坚持全程规范治疗。要充分总结百千万志愿者结核病防治知识传播活动的经验和成果，通过志愿者的行动，深入到防治一线，切实回答好对结核病防治问题的疑惑。要策划一些有特色的宣传活动，开发一批特色内容的宣传品，不断提高学生、老年人、流动人口等特殊群体的结核病防控能力。要进一步强化对定点医疗机构医务人员的宣传，提高对患者的发现、诊断和治疗管理能力以及医务人员的个人防护能力。

（三）创新形式，提升宣传的影响力。各地要充分利用微博、微信、移动客户端等新媒体平台，创新宣传方式。要用群众听得到、听得懂、听得进的科普宣传形式，如优秀科普作品展播、手机短信群发、公益广告、网络知识竞赛等形式，传播结核病防治知识，宣传有关政策，提高公众的认知水平，促进其行为习惯改善，增强群体防控能力。同时通过通俗性、趣味性的宣传，促使可疑者及早就医、明确诊断。

三、相关要求

为了便于各地更好地开展活动，我委组织制作了宣传海报（包括纸质材料和电子模版），近期将印发各地。各地可根据材料模版制作适合当地的宣传品。

各地要及时将主题日活动情况进行总结，提炼活动中的亮点和典型，并将活动总结（包括照片、视频等材料）于2017年4月30日前报我委疾控局。
