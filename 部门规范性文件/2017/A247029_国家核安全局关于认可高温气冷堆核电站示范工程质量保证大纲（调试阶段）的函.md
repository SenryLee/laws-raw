# 国家核安全局关于认可高温气冷堆核电站示范工程质量保证大纲（调试阶段）的函

## 关于认可高温气冷堆核电站示范工程质量保证大纲（调试阶段）的函

国核安函[2017]9号

华能山东石岛湾核电有限公司：

你公司《关于报送华能山东石岛湾核电厂高温气冷堆核电站示范工程质量保证大纲（调试阶段）的请示》（华能石核安〔2017〕9号）及附件收悉。

根据《民用核设施安全监督管理条例》及其实施细则的有关要求，我局对你公司提交的申请文件进行了审评，认为高温气冷堆核电站示范工程质量保证大纲（调试阶段）是可以接受的，现予认可。

你公司应严格遵守上述认可的质量保证大纲，加强高温气冷堆核电站示范工程调试工作的过程控制，确保核电机组的调试质量。

国家核安全局

2017年1月22日
