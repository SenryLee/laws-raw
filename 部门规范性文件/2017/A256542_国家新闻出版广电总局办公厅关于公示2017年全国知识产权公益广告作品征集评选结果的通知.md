# 国家新闻出版广电总局办公厅关于公示2017年全国知识产权公益广告作品征集评选结果的通知

新广电办发〔2017〕65号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央三台，电影频道节目中心，中国教育电视台：

为进一步宣传普及知识产权文化理念，提升全社会知识产权意识，推动知识产权事业更好更快地发展，2017年3月，国家新闻出版广电总局、国家知识产权局联合开展了2017年全国知识产权公益广告作品征集暨评审活动，得到社会各界积极响应。日前，经活动组委会审核，共评出一、二、三类作品及优秀类作品共41件，现予以公示。公示内容可以在国家新闻出版广电总局政府网站（网址：www.sapprft.gov.cn）通知公告区中查询。

请立即向辖区内有关单位或个人通报公示内容。有关单位和个人均可就公示内容存在的问题，于10月23日前向国家新闻出版广电总局传媒司反映。

附件：1.2017年全国知识产权公益广告作品征集活动广播类扶持作品名单

2.2017年全国知识产权公益广告作品征集活动电视类扶持作品名单

国家新闻出版广电总局办公厅

2017年9月28日
