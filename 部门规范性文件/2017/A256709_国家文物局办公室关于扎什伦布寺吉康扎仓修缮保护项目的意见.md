# 国家文物局办公室关于扎什伦布寺吉康扎仓修缮保护项目的意见

办保函〔2017〕1185号

西藏自治区文物局：

你局《关于扎什伦布寺吉康扎仓维修保护工程设计方案评审的请示》（藏文物字〔2017〕393号）收悉。经研究，我局意见如下：

一、所报方案现状勘察与维修设计说明、设计图不对应，维修依据不充分，对文物本体保护干预过大，我局暂不同意所报方案。

二、具体修改意见如下：

（一）深化现状勘察，进一步复核残损程度、部位、范围以及残损量，加强对受损情况的综合评估，为修缮工程提供充足的维修依据。

（二）根据补充完善后的残存现状，制定具有针对性的维修目标及措施，避免过度干预，严格控制工程量及工程范围。

（三）墙体勾缝不能使用混合砂浆；补充夯土及土坯砖墙体的修缮措施；室内地面应采用传统做法，不宜增加防潮层；原木构件不需要进行防腐处理。

（四）补充用电线路现状情况评估；相关改造应提供用电测算依据。

（五）进一步完善设计图纸。主要维修做法及工程量应于图纸直接标注，详细列表应列入设计说明。规范电器设计图纸。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善后，按程序另行报批。

国家文物局办公室

2017年10月20日
