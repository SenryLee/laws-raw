# 住房城乡建设部关于印发2017年国家建筑标准设计编制工作计划的通知

建质函〔2017〕255号

各省、自治区住房城乡建设厅，直辖市建委（规划国土委），新疆生产建设兵团建设局：

现将《2017年国家建筑标准设计编制工作计划》印发给你们，请在工作中予以支持和配合。
