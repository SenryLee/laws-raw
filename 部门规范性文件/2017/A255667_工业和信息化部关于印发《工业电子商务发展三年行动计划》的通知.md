# 工业和信息化部关于印发《工业电子商务发展三年行动计划》的通知

工信部信软〔2017〕227号

各省、自治区、直辖市及计划单列市、副省级省会城市、新疆生产建设兵团工业和信息化主管部门：

为贯彻落实《国务院关于深化制造业与互联网融合发展的指导意见》（国发〔2016〕28号），促进工业电子商务创新发展，制定《工业电子商务发展三年行动计划》。现印发给你们，请结合实际，组织开展相关工作。

附件：工业电子商务发展三年行动计划

工业和信息化部

2017年9月11日
