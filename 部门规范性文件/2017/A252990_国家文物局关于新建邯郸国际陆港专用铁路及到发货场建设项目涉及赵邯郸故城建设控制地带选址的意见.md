# 国家文物局关于新建邯郸国际陆港专用铁路及到发货场建设项目涉及赵邯郸故城建设控制地带选址的意见

## 关于新建邯郸国际陆港专用铁路及到发货场建设项目涉及赵邯郸故城建设控制地带选址的意见

办保函〔2017〕420号

河北省文物局：

你局《关于呈报新建邯郸国际陆港专用铁路到发线项目设计方案的请示》（冀文物字〔2017〕14号）收悉。经研究，我局意见如下：

一、新建邯郸国际陆港专用铁路及到发货场项目涉及赵邯郸故城一类建设控制地带，且紧邻遗址保护范围，对赵邯郸故城保护展示影响较大，我局暂不同意该建设项目。

二、建议进一步优化该建设项目选址，尽量远离遗址保护范围，建议考虑在渚河以西区域或南环路以南区域布设该项目。同时，应进一步做好该建设项目的文物影响评估，充分考虑赵邯郸故城保护展示以及赵王城考古遗址公园建设的相关需求，客观评估该建设项目所产生的影响，并提出相应的减缓措施。

三、请你局指导建设单位，根据上述意见对所报方案做进一步修改和完善，做好文物影响评估，经你局核准后按程序另行报批。

国家文物局

2017年4月13日
