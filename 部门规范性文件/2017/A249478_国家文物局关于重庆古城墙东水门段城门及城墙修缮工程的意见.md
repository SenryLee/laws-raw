# 国家文物局关于重庆古城墙东水门段城门及城墙修缮工程的意见

## 关于重庆古城墙东水门段城门及城墙修缮工程的意见

办保函〔2017〕268号

重庆市文物局：

你局《关于审批全国重点文物保护单位重庆古城墙——东水门段城门及城墙修缮工程立项报告的请示》（渝文物〔2017〕13号）收悉。经研究，我局意见如下：

一、暂不同意重庆古城墙东水门段城门及城墙修缮工程立项。

二、对所报立项报告提出以下修改意见：

（一）加强现状勘察和研究，明确文物保存现状、病害情况等，分析说明城墙构造、材质、砌筑工艺等。补充重庆古城墙历次修缮工程情况和工程效果评估内容，进一步论证工程实施的必要性和可行性。

（二）应科学、合理地确定勘察技术手段，增强针对性。明确热红外、超声波、微波、光学显微镜、XRD等设备的使用目的。

（三）应根据前期勘察结果进一步核实工程范围和工程量，以现状整修为主，尽可能保留原有构件，避免过度维修。

1．评估严重残损城墙的结构稳定性，采取现状加固保护措施确保文物安全，不同意拆除重砌做法。

2．不同意使用防风化处理措施。

3．植物清除应慎重，明确具体措施和操作流程，并制定必要的临时性加固措施和应急预案，避免植物清除过程中损害城墙本体。

（四）监测项目应在修缮工程结束后另行报批。

（五）应根据工程量实事求是地编制经费预算，补充取费标准，细化各单项取费依据。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年3月16日
