# 国家体育总局办公厅关于做好2018年度文化产业发展专项资金（重大项目方面）中央本级项目申报工作的通知

## 体育总局办公厅关于做好2018年度文化产业发展专项资金（重大项目方面）中央本级项目申报工作的通知

党中央有关部门办公厅（室），国务院有关部委、直属机构办公厅（室），体育总局有关直属单位：

根据财政部办公厅《关于申报2018年度文化产业发展专项资金（重大项目方面）中央本级项目的通知》（财办文[2017]50号），2018年文化产业发展专项资金（以下简称专项资金）继续重点用于落实党中央、国务院和宣传文化体育部门确定的重大政策、项目。其中，体育健身休闲产业由体育总局牵头负责，为做好2018年专项资金中央本级项目申报工作，现就有关工作通知如下：

一、主要目标

落实党中央、国务院关于推动体育产业发展的有关政策要求，促进财政政策与产业政策有机衔接。调整资金投入结构，降低直接补助比例，提高贷款贴息、保费补贴等事后奖补比例，进一步放大财政资金杠杆、撬动效应。

二、重点支持内容

（一）建设健身休闲设施。重点支持冰雪场、航空飞行营地、运动船艇码头、山地户外营地、自驾车房车营地及体育服务综合体的建设项目。

（二）拓展健身休闲服务。重点支持体育产业的综合服务平台、项目对接平台、共性技术支撑平台等；支持冰雪、航空、水上、山地户外、汽摩、马拉松、自行车、击剑有示范效应的赛事服务项目及各类营地服务项目；支持体育培训服务项目及制作、播放体育内容的服务项目。

除体育产业平台类项目可采取直接补助方式外，其他项目全部通过贷款贴息和保费补贴方式支持。

三、申报单位条件

（一）申报企业

1.申报主体必须为符合条件的企业。申报企业必须满足以下条件，一是2016年1月1日前在中国境内依法注册设立、有独立法人资格。二是企业财务管理制度健全，会计信用和纳税信用良好，具有一定规模实力、成长性好。三是最近三年内未受到体育行政部门处罚，且不存在重大法律纠纷。

2.申报项目必须为产业项目，符合国家体育产业重点发展方向，有一定规模、有突出特色，预期社会效益和经济效益显著，对体育产业发展有明显促进和示范作用。

3.原则上一个企业只能申报1个项目，一个企业集团只能申报2个项目（含企业集团下属企业项目）。企业集团下属企业申报须经企业集团审核并出具推荐函。

4.同一项目不得向宣传文化体育部门多头申报，或与其他来源渠道财政资金重复申报。企业不能就往年已获得各级财政资金支持的项目再行申报。

（二）申报材料

1.申请项目补助的平台类项目，需有前期投资和建设基础，预期社会效益和经济效益良好，原则上平台建设进度和已完成投资均不低于20%。申请补助金额不超过项目预计投资额的60%。需按附件1的要求提供相关材料。

2.申请贷款贴息的，利息及有关财务费用发生期限为2017年1月1日至2017年10月31日。支持金额控制在贷款利息（含财务费用）的90%，不高于企业申报金额。需按附件2的要求提供相关材料。

3.申报保险费补助的，保险费发生期限为2017年1月1日至2017年10月31日。支持金额控制在保险费的90%，不高于企业申报金额。需按附件3的要求提供相关材料。

每个项目只能选择以上一种支持方式。

三、申报程序

2017年12月4日前，中央各预算主管部门对所属项目单位提交的申报材料进行审核和汇总，形成专项资金申请文件（《文化产业发展专项资金绩效目标申报表》作为附件），以部函形式同时报送财政部和体育总局；项目申报文本请直接报送体育总局。逾期不予受理。

四、申报数量

（一）中央各部门、体育总局各直属单位推荐项目不超过2个。

（二）申报材料包括纸质申报材料1份和光盘1份，每个申报项目涉及的可行性研究报告、合同文本、付款凭证等，应按要求上传扫描件，电子文件须与纸质文件保持一致，并按申报材料要求排序，形成一份包含文件目录的PDF文档。

五、工作要求

（一）有关中央部门应遵循公开、公平、公正的原则，组织做好申报单位指导和项目推荐工作，严格初审程序。

（二）有关中央部门、体育总局各直属单位应按要求组织申报，严格把握推荐数量，保证工作进度。超过规定报送数量或逾期申报的，对推荐项目不予受理。
