# 工业和信息化部办公厅关于2017年一季度通信建设工程质量监督和安全生产情况的通报

工信厅通信函〔2017〕343号

各省、自治区、直辖市通信管理局，中国电信集团公司、中国移动通信集团公司、中国联合网络通信集团有限公司、中国铁塔股份有限公司，相关单位:

现将2017年一季度全国通信建设工程质量和安全生产情况通报如下：

一、基本情况

31个省（区、市）通信管理局均报送了通信工程质量监督情况（详见附件1），电信企业（含铁塔公司，下同）共申报质量监督项目32164项，办理竣工验收备案项目9536项，通信工程质量监督机构开展工程实体抽查项目785项，抽查发现问题的项目31项（详见附件2）。

二、存在的主要问题

从一季度情况看，抽查发现问题的项目存在的主要问题包括：

（一）工程质量和安全生产的问题

一是光交接箱、光缆分纤箱内光缆金属加强芯未做接地；二是光交接箱、蓄电池架未按要求进行抗震加固或对地加固不牢；三是架空线路与电力线交越时未采取保护措施；四是馈线在铁塔塔身进行盘留，存在安全隐患。

（二）相关企业的问题

一是电信企业未按规定进行质量监督申报和竣工验收备案，施工合同中未明确安全生产费支付方式、数额及时限；二是设计企业在设计文件中未按规定全额计列安全生产费，未针对项目提出防范安全生产事故的指导意见，未标注架空线路与电力线交越的具体位置，不能有效指导施工；三是施工企业项目负责人、专职安全生产管理人员未经安全生产考核，部分施工人员与施工组织方案中配备的人员不一致，未就安全施工的技术要求向施工作业班组、作业人员做出详细说明；四是监理企业现场监理人员与监理细则中配备的人员不一致，对不符合抗震加固等问题未及时指出并要求整改，监理资料中无旁站记录，未能有效履行监理职责。

三、2016年四季度通报问题的整改情况

中国电信集团公司要求存在问题的6个省公司进行逐项整改，对涉及的参建单位督促其整改，21个工程项目及7项材料设备检测存在的问题已全部整改完成。对检测存在问题涉及的批次产品，在相关地区进行全面检查，遗留库存产品做退、换货处理，复检合格之前暂停相应产品供货资格。同时，要求下属各公司对照通报所提出的隐患和问题，严格管理，举一反三，加大对工程现场的检查力度，进一步强化工程建设质量和安全生产管理，杜绝生产安全责任事故的发生。

中国移动通信集团公司对存在问题的6个省公司明确了整改要求，26个工程项目已全部整改完成。为严格执行基本建设程序，要求下属各公司将质量监督申报和验收备案工作纳入项目管理关键点予以监控；严格履行设计出版前后的审查、审批制度；强化施工过程中现场安全生产和施工规范管理，要求监理企业建立完善监理规划和实施细则，促进服务质量和效率提升。

中国联合网络通信集团有限公司要求存在问题的5个省分公司落实整改责任和整改措施，28个工程项目及5项材料设备检测存在的问题已全部完成整改。对存在问题的产品供货企业在招标时进行后评估扣分处理，对检测存在问题累计3次及以上的供货企业，暂停采购3个月。部分省分公司采取有效措施强化工程项目管理：江苏联通公司加大对工程设计安全交底和施工安全交底工作的考核力度，加强对服务合作企业的延伸管理；山西联通公司对项目经理提出批评，扣除二季度绩效工资，对存在问题的服务企业进行季度考核扣分，并给予口头警告。

中国铁塔股份有限公司要求存在问题的5个省分公司逐项进行整改，19个工程项目已全部完成整改。要求下属各公司按规定时限办理质量监督申报和竣工验收备案，各设计、施工和监理企业要认真履行职责，重点关注通报涉及的问题。为加强工程质量和安全生产管理，建立标准工序工艺库，对工程建设的关键点和主控项进行重点关注，提升工程项目综合管理能力。

四、相关要求

各通信管理局要全面落实《工业和信息化部办公厅关于做好2017年通信建设安全生产工作的通知》（工信厅通信函〔2017〕231号）的有关要求，强化对工程质量和安全生产的监督检查（每季度至少报送2项实体抽查工程情况），做好问题项目的后续跟踪和督促整改工作，对发现的违法违规问题要严格依法查处；要严格落实生产安全事故报告制度，按要求在2小时内将较大及以上生产安全事故基本情况报部，并按季度定期报送本地区发生的一般生产安全事故情况。

各电信企业要严格落实工程质量和安全生产管理要求，组织做好2017年版通信建设项目招标文件范本和2017年版信息通信工程定额的落实工作，对通报问题要认真落实整改要求，从完善制度、规范流程、加强检查等多方面提升工程建设管理水平。同时，要强化对工程中使用材料、设备的到货检测，加强对供货企业的违约失信考核。各集团公司总部应于7月10日前将《2017年一季度抽查工程项目发现主要问题汇总表》（附件2）所列问题的整改情况汇总报部（信息通信发展司）,部将在下季度通报整改情况。
