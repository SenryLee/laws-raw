# 国家能源局综合司关于同意能源行业煤制燃料标准化技术委员会换届方案的复函

国能综函科技〔2017〕429号

能源行业煤制燃料标准化技术委员会秘书处：

报来《关于能源行业煤制燃料标准化技术委员会换届的请示》（煤制燃料标委〔2017〕05号）收悉。经研究，现确认如下：

一、同意能源行业煤制燃料标准化技术委员会（NEA/TC19）换届方案。

二、第二届能源行业煤制燃料标准化技术委员会由34名委员组成（名单详见附件），张继明任主任委员，董万成、吴秀章、杨哲任副主任委员，张传江任秘书长。

三、能源行业煤制燃料标准化技术委员会的职责范围仍按照我局国能科技〔2011〕107号文执行。

四、第二届能源行业煤制燃料标准化技术委员会秘书处仍由中国神华煤制油化工有限公司承担，并负责日常管理及标准立项、报批等业务。

附件：第二届能源行业煤制燃料标准化技术委员会（NEA/TC19）委员名单

国家能源局综合司

2017年12月5日
