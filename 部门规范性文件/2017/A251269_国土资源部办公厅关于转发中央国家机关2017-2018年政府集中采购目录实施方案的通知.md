# 国土资源部办公厅关于转发中央国家机关2017-2018年政府集中采购目录实施方案的通知

国土资厅函〔2017〕691号

各预算单位：

根据政府采购法律法规和《国务院办公厅关于印发中央预算单位2017-2018年政府集中采购目录及标准的通知》（国办发〔2016〕96号），结合政府采购工作实际，中央国家机关政府采购中心印发了《中央国家机关2017-2018年政府集中采购目录实施方案》（国机采〔2017〕4号），现转发给你们，请遵照执行。

2017年5月4日
