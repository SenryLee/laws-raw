# 国家文物局办公室关于朝阳岩石刻保护规划意见的函

办保函〔2017〕1387号

湖南省文物局：

你局《关于审批〈朝阳岩石刻文物保护规划〉的请示》（湘文物报〔2016〕176号）收悉。经研究，我局意见如下：

一、所报规划前期研究不足，文本体例不规范，我局暂不同意朝阳岩石刻保护规划。

二、所报规划应做以下修改和完善：

（一）应进一步厘清文物构成和保护对象，核对全国重点文物保护单位简介内容，补充调整依据。进一步明确寓仙祠、篆石亭等文物建筑与朝阳岩石刻的关系。并深化价值评估。

（二）完善现状评估，客观评价文物本体保存现状和已实施的文物保护工程情况及效果，厘清文物病害和灾害评估，深化洪水影响评估内容。

（三）应根据文物分布情况、保护管理需要和地形地貌特征，科学调整保护区划边界。结合视线通廊分析和山体、水体等不同对象的管理要求，加强分类控制，补充分类依据。

（四）进一步明确建设控制地带内新建建筑高度、体量、色彩、外观样式等控制指标，增强管理规定针对性。

（五）应针对现状评估结论，有针对性的制定保护措施，尽量减少对文物本体的干预。石刻表面保护应慎重使用化学材料。建议加强文物安全监测措施的内容与要求。

（六）根据文物保护需要合理制定专项规划。深化管理规划，明确文物管理部门与公园管理部门的责权关系，妥善处理文物保护和旅游发展之间的关系。细化监测规划，进一步明确监测目标、内容和主要技术措施。

（七）应根据规划内容合理调整规划分期，增强可操作性。进一步加强所报规划与相关规划的衔接。

（八）应根据《全国重点文物保护单位保护规划编制要求》，进一步规范文本和图纸。加强图纸与文本的对应性，合理确定规划范围，调整图纸比例，补充石刻分布立面图等。注意引用法规文件的时效性。

三、请你局指导有关单位，根据上述意见对朝阳岩石刻保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月19日
