# 国家新闻出版广电总局办公厅关于公示2017年全国节能公益广告作品征集评选结果的通知

新广电办发〔2017〕35号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央三台，电影频道节目中心，中国教育电视台：

为深入开展以节能提高能效为重点的宣传活动，更好地传播节能文化、普及节能知识、提升全民意识、倡导绿色生活，引导全社会共同参与生态文明建设，共绘碧水蓝天，建设美丽中国，2017年5月，国家新闻出版广电总局与国家发展和改革委员会联合开展了全国节能公益广告作品征集评选活动，得到社会各界积极响应。日前，经活动组委会审核，共评出一、二、三类作品及优秀类作品共36件，优秀组织机构16家，现予以公示。公示内容可以在国家新闻出版广电总局政府网站（网址：www.sarft.gov.cn）通知公告区中查询。

请立即向辖区内有关单位或个人通报公示内容。有关单位和个人均可就公示内容存在的问题，于6月23日前向国家新闻出版广电总局传媒司反映。

国家新闻出版广电总局联系人：许旭，010-86098540。

附件：1.2017年全国节能公益广告作品征集活动广播类扶持作品名单

2.2017年全国节能公益广告作品征集活动电视类扶持作品名单

3.2017年全国节能公益广告作品征集活动优秀组织机构

国家新闻出版广电总局办公厅

2017年6月6日
