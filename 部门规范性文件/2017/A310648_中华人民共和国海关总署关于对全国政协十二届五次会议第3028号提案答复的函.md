# 中华人民共和国海关总署关于对全国政协十二届五次会议第3028号提案答复的函

陈建国等6名委员：

你们在全国政协十二届五次会议上提出的《关于进一步完善入境携带物品征税工作的提案》（第3028号）收悉。经商财政部，现答复如下：

一、关于提高居民旅客个人自用进境物品免税额度问题

近年来，随着我国经济的快速发展，国民收入水平和生活品质不断提升，国民对国外高品质商品的需求也不断攀升。但是目前来看，我国对进境居民旅客携带在境外获取的个人自用进境物品5000元的免税额度能够满足居民的日常需求。一是从绝对值上看，我国现行的5000元的免税额度并不低，甚至高于部分发达国家。如美国入境免税额为800美元（接近5000元人民币）、澳大利亚入境免税额900澳元（约4000元人民币）、加拿大入境免税额为750加元（约3000元人民币）、欧盟入境免税额为430欧元（约3000多元人民币）、韩国入境免税额为400美元（约2500元人民币）。二是从占人均收入的比例看，5000元免税额占2016年我国居民人均可支配收入的20%，而上述国家或地区居民行李免税额占其人均收入的比例均低于我国。

二、关于提高非居民旅客个人自用物品免税额度问题

从各国实践看，旅客个人自用物品免税额度的设立主要与入境的目的和停留时间相关。根据海关总署2010年第54号公告，2000元免税额度适用于非居民旅客拟留在中国境内的个人自用物品。非居民旅客以短期游客居多，具有停留时间短、流动性强的特点，2000元的免税额度应该能够满足其旅行需求。

综上两点，我们认为，暂不宜提高我国居民及非居民旅客携带入境行李物品的免税额度。

三、关于进一步完善和规范我国海关工作人员对入境人员携带物品检查的管理制度

海关是国家的进出关境监督管理机关，依照《海关法》等法律法规履行相应职责，做好实际监管工作。下一步，海关将进一步提升一线海关执法统一性，统一检查流程，在把好国门的基础上，做好通关服务。

感谢你们对海关监管工作的关心、理解与支持，并欢迎继续对我们的工作提出宝贵的意见和建议。

海关总署

2017年6月7日
