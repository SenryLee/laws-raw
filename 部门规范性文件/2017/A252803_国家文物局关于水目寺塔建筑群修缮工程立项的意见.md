# 国家文物局关于水目寺塔建筑群修缮工程立项的意见

## 关于水目寺塔建筑群修缮工程立项的意见

办保函〔2017〕416号

云南省文物局：

你局《关于水目寺塔建筑群保护修缮工程立项的请示》（云文物〔2017〕19号）收悉。经研究，我局意见如下：

一、暂不同意水目寺塔建筑群修缮工程立项。

二、应按照我局《关于水目寺塔建筑群修缮工程立项的意见》（办保函〔2016〕5号）要求，进一步明确水目寺塔建筑群的建造年代、文物价值及其与水目寺塔的关系，核实全国重点文物保护单位水目寺塔的文物构成，论证工程实施的必要性和可行性。

三、请你局督促地方人民政府根据《关于水目寺塔文物保护规划编制立项的批复》（文物保函〔2012〕679号）要求，抓紧编制水目寺塔文物保护规划, 进一步明确保护对象，统筹考虑文物修缮、展示利用和日常管理工作。同时，督促有关单位切实加强文物日常保养和岁修，落实管理维护责任，确保文物安全。

专此函。

国家文物局

2017年4月12日
