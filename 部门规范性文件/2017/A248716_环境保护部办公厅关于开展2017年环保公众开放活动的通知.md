# 环境保护部办公厅关于开展2017年环保公众开放活动的通知

## 关于开展2017年环保公众开放活动的通知

环办科技函[2017]385号

各省、自治区、直辖市环境保护厅（局），副省级城市环境保护局，环境保护部各直属单位，各有关单位:

为落实《关于进一步加强环境保护科学技术普及工作的意见》（环发〔2015〕66号）中关于推进环保科技资源开放的要求，充分利用环保科研院所和监测中心（站）等单位科技资源在环境科学传播中的专业优势，逐步建立和完善面向社会的定期开放制度，我部决定于2017年科技活动周和环境日期间继续组织开展环保公众开放活动（活动方案详见附件1），具体工作由中国环境科学学会组织实施。现请你单位组织有条件的单位自愿参加公众开放活动，于2017年4月15日前将推荐函报送我部，同时将电子版活动回执表（见附件2）报送中国环境科学学会。
