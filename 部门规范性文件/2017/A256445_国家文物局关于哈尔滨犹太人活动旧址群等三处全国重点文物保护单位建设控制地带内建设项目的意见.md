# 国家文物局关于哈尔滨犹太人活动旧址群等三处全国重点文物保护单位建设控制地带内建设项目的意见

文物保函〔2017〕1714号

黑龙江省文物管理局：

你局《关于对哈尔滨市道里区中央大街休闲区改造项目选址涉及哈尔滨犹太人活动旧址群等三处国保单位建设控制地带审批的请示》（黑文管字〔2017〕23号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、项目方案应做以下完善：

（一）补充该项目实施的必要性和可行性论证，特别说明该工程为临时建筑的原因。

（二）尽可能地缩小该项目的建筑体量，充分考虑与文物建筑风貌协调，增强新建设施的通透性和简洁性。如，西7区项目应适当缩小规模；调整西8区项目的风格及色调，使其与周边文物建筑风貌相协调。

（三）文物影响评估报告应从历史环境、视线分析及安全消防等方面补充工程建设对文物的影响评估。

（四）补充建设项目的相关法规依据，如全国重点文物保护单位建设控制地带的建设控制要求等。

三、请你局指导相关单位根据上述意见对方案进行修改完善，按照《中华人民共和国文物保护法》第十八条的规定，经当地城乡建设规划部门批准后实施。工程施工期间，应加强工程监管，确保文物安全。

专此函复。

国家文物局

2017年10月9日
