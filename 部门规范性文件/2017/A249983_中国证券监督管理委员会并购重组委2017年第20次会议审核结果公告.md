# 中国证券监督管理委员会并购重组委2017年第20次会议审核结果公告

## 并购重组委2017年第20次会议审核结果公告

中国证券监督管理委员会上市公司并购重组审核委员会2017年第20次会议于2017年4月27日上午召开。现将会议审核结果公告如下：

一、审核结果

河北宣化工程机械股份有限公司（发行股份购买资产）获无条件通过

上海华峰超纤(25.290, -0.29, -1.13%)材料股份有限公司（发行股份购买资产）获无条件通过
