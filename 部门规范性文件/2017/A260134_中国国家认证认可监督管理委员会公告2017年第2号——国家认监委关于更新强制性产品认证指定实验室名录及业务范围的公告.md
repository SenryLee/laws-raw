# 中国国家认证认可监督管理委员会公告2017年第2号——国家认监委关于更新强制性产品认证指定实验室名录及业务范围的公告

## 中国国家认证认可监督管理委员会公告

2017年第2号

## 国家认监委关于更新强制性产品认证指定实验室名录及业务范围的公告

为进一步便利认证委托人办理强制性产品认证，经对近期新指定强制性产品认证实验室信息进行梳理，并对部分指定实验室变更信息予以确认，现将汇总更新后的强制性产品认证指定实验室名录及业务范围予以发布。

国家认监委

2017年1月3日
