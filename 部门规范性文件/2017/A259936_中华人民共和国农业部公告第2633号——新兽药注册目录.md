# 中华人民共和国农业部公告第2633号——新兽药注册目录

## 中华人民共和国农业部公告

第2633号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准华中农业大学等13家单位申报的猪传染性胃肠炎、猪流行性腹泻二联活疫苗（WH-1R株+AJ1102-R株）等3种兽药产品为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

批准常州同泰生物药业科技股份有限公司等4家单位申报的狂犬病灭活疫苗（SAD株）生产工艺“疫苗制备抗原不浓缩”改为“疫苗制备抗原浓缩5～10倍”变更注册。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年12月27日
