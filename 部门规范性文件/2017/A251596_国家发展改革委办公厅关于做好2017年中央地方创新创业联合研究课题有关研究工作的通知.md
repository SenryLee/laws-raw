# 国家发展改革委办公厅关于做好2017年中央地方创新创业联合研究课题有关研究工作的通知

发改办高技〔2017〕1034号

各省、自治区、直辖市及计划单列市，新疆生产建设兵团发展改革委：

为进一步加强实施创新驱动发展战略、推进大众创业万众创新理论研究，更好地支撑创新创业工作，按照《国家发展改革委办公厅关于开展2017年中央地方创新创业联合研究课题申报的通知》（发改办高技〔2017〕250号），经审核，原则同意相关地方报送的66个课题入选2017年中央地方创新创业联合研究课题（名单见附件）。现将有关事项通知如下。

一、有关要求

（一）高度重视，确保质量。请承担课题研究任务的地方发展改革委高度重视，积极为课题研究提供条件，尽快组织相关单位开展课题研究工作。合理把握课题研究进度，确保课题研究质量，及时组织课题验收。

（二）加强交流，定期检查。各课题研究单位要积极参加课题交流。在2017年9月1日前和2017年12月1日前，分别报送课题研究和应用转化工作进展情况，相关电子版发送至sckt2017@126.com。

（三）注重转化，突出案例。相关地方发展改革委要提出研究成果应用转化方案，及时将研究成果转化为政策措施。课题研究单位要结合研究领域开展案例研究，撰写1—2个案例研究报告。研究成果应用转化方案和案例研究报告随课题研究成果一并报送。

二、进度安排

2017年6月，启动联合研究课题。

2017年6月至9月，分主题组织专题研讨会，开展课题交流；

2018年2月前，各课题研究单位将初步研究成果报送地方发展改革委，各地方发展改革委组织课题评价和验收；

2018年2—3月，我委将组织专家对课题成果进行评估，并对优秀课题研究成果进行表扬。

三、其他事项

（一）关于日常管理。我委委托国家信息中心承担联合研究课题管理的联系协调工作，并组织专家对课题成果进行评估。

（二）关于沟通交流。结合“创响中国”巡回接力活动，我委将组织若干次课题研讨会，推动课题研究单位之间相互交流研讨。

（三）关于结题表彰。课题验收后，我委将组织专家对联合研究课题成果和应用转化方案进行评估，并将课题成果质量和应用转化效果作为该地区未来继续承担国家地方联合课题研究任务的重要参考。根据课题成果质量及应用转化情况，我委将对优秀课题研究成果进行表扬，并推荐参加我委优秀研究课题评选。
