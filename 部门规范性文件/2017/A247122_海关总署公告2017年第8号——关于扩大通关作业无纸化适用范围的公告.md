# 海关总署公告2017年第8号——关于扩大通关作业无纸化适用范围的公告

## 海关总署公告

2017年第8号

## 关于扩大通关作业无纸化适用范围的公告

为加快落实外贸稳增长政策措施，进一步深化通关作业无纸化改革工作，提高贸易便利化水平，海关总署决定将适用通关作业无纸化企业范围扩大到所有信用等级企业。

企业经与直属海关、第三方认证机构（中国电子口岸数据中心）签订电子数据应用协议后，可在全国海关适用“通关作业无纸化”通关方式，不再需要重复签约。

本公告自公布之日起执行。

特此公告。

海关总署

2017年2月3日
