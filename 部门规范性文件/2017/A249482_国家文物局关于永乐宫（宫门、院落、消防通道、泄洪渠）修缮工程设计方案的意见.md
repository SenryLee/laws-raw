# 国家文物局关于永乐宫（宫门、院落、消防通道、泄洪渠）修缮工程设计方案的意见

## 关于永乐宫（宫门、院落、消防通道、泄洪渠）修缮工程设计方案的意见

办保函〔2017〕287号

山西省文物局：

你局《关于审批永乐宫（宫门、院落、消防通道、泄洪渠）修缮工程设计方案的请示》（晋文物〔2016〕201号）收悉。经研究，我局意见如下：

一、所报方案前期勘察不足，文本深度不够，我局暂不同意永乐宫（宫门、院落、消防通道、泄洪渠）修缮工程设计方案。

二、对该方案提出以下修改完善意见：

（一）应加强现状勘察和研究，明确文物保存现状和主要病害类型，深入分析宫门屋面、大木构架的残损原因，准确统计残损部位、数量及程度，为制定修缮措施提供依据。补充说明围墙的建筑形制、构造做法和《永乐宫文物保护规划》相关内容。

（二）补充地方建造工艺、传统做法、建筑材料和构造特征等研究和分析内容。

（三）进一步完善工程做法，以现状整修为主，严格控制工程量和工程强度，不同意宫门揭顶、更换全部望板的做法。建议设计生态消防通道，减少对文物及其周边景观环境的影响。

（四）进一步规范图纸，明确泄洪渠的沟底标高和坡度等内容；补充围墙现状图与设计图，院落、消防通道、泄洪渠的大比例平面图，并标注修缮范围与具体措施。

三、请你局根据上述意见和我局《关于永乐宫宫门修缮设计方案的意见》（办保函〔2015〕1599号）、《关于永乐宫（宫门、院落、消防通道、泄洪渠）修缮工程设计方案的意见》（办保函〔2016〕384号）要求，组织相关单位认真修改、完善设计方案，经你局审核后另行报批。

专此函。

国家文物局

2017年3月21日
