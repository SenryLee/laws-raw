# 国家文物局关于雍和宫法轮殿供暖建设项目的意见

文物保函〔2017〕1590号

北京市文物局：

你局《关于雍和宫法轮殿供暖建设工程方案的请示》（京文物〔2017〕986号）收悉。经研究，我局批复如下：

一、原则同意所报雍和宫法轮殿供暖建设项目和你局意见。

二、对该项目提出以下修改意见：

（一）应进一步细化工程做法和技术要求。

1．深入评估开挖室内管沟对文物建筑基础稳定性的影响；完善管沟设计，加强管沟壁防渗处理，补充渗水的报警和应对措施；明确室内砖地面垫层做法、管沟回填和原有地面铺装恢复的技术要求。

2．布设地面电源插座应当严格控制，并符合消防安全要求。

3．建议调整供暖管线直接穿过木质门槛引入室内的做法，避免造成文物建筑装修部位损伤及破坏。

4．进一步论证在经床下安装散热片的科学性、安全性，进行多方案比选后确定合理的取暖方式，尽可能减少对文物本体影响。

（二）补充室内增加暖气设备后对文物建筑安全、人身安全、环境风貌影响的评估。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善后，按照《中华人民共和国文物保护法》第十七条的规定，经北京市人民政府批准实施。请加强工程监管，确保文物安全。

四、请你局切实加强管理，督促、指导相关单位做好雍和宫相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2017年8月31日
