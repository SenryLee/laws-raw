# 中华人民共和国财政部公告第174号——决定发行2017年记账式贴现（六十一期）国债的公告

## 中华人民共和国财政部公告

第174号

根据国家国债发行的有关规定，财政部决定发行2017年记账式贴现（六十一期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

一、本期国债计划发行150亿元，实际发行面值金额150.5亿元。

二、本期国债期限91天，经招标确定的发行价格为99.071元，折合年收益率为3.76%，2018年1月2日开始计息，招标结束后至1月2日进行分销，1月4日起上市交易。

三、本期国债低于票面面值贴现发行，2018年4月3日（节假日顺延）按面值偿还。

其他事宜按《中华人民共和国财政部公告》（2017年第2号）规定执行。

特此公告。

中华人民共和国财政部

2017年12月29日
