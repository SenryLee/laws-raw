# 环境保护部关于国家环境保护城市土壤污染控制与修复工程技术中心和国家环境保护工业副产石膏资源化利用工程技术中心通过验收的通知

## 关于国家环境保护城市土壤污染控制与修复工程技术中心和国家环境保护工业副产石膏资源化利用工程技术中心通过验收的通知

环科技函〔2017〕282号

上海市环境科学研究院，江苏一夫科技股份有限公司：

按照《国家环境保护工程技术中心管理办法》（以下简称《管理办法》）的有关规定，环境保护部组织专家组对国家环境保护城市土壤污染控制与修复工程技术中心、国家环境保护工业副产石膏资源化利用工程技术中心（基本信息见附件，以下简称两家工程技术中心）进行了验收。

经审核，两家工程技术中心分别完成了各自《可行性研究报告》所确定的各项任务，达到了预期目标。经研究，同意通过验收。

请两家工程技术中心依托单位按照《管理办法》的有关规定，在已有工作基础上，加强产学研用结合，突出核心关键技术的研发、应用，充分发挥工程技术中心对国家环境管理和环境治理的技术支撑作用。

附件：通过验收的2家国家环境保护工程技术中心基本信息

环境保护部
