# 国家文物局关于响堂山石窟保护规划的意见

## 关于响堂山石窟保护规划的意见

办保函〔2017〕295号

河北省文物局：

你局《关于呈报响堂山石窟保护规划的请示》（冀文物字〔2016〕178号）收悉。经研究，我局意见如下：

一、所报规划文物构成和保护对象不准确，前期勘察和评估不足，保护区划不当，文本深度不够，我局暂不同意响堂山石窟保护规划。

二、所报规划应做以下必要修改和完善：

（一）关于文物认定和评估

1．进一步梳理文物构成和保护对象，客观评估天王殿、自来佛殿、阎王殿、罗汉殿、钟楼等近代复建建筑的价值，说明将其作为文物本体、历史建筑和文物环境的依据。

2．完善价值评估，深化响堂山石窟在中国古代石窟发展史中的地位和作用相关研究，补充石窟造像、艺术装饰等美学评估内容。

3．深化现状评估，明确文物载体范围和主要病害，客观评估历次加固防护、保护性设施建设等工程效果，以及煤矿采空区、水患、粉尘污染对文物及载体的影响，补充石窟内部环境监测、地质灾害评估内容，说明现状游客量和服务设施使用情况。

（二）关于保护区划和管理规定

1．应根据文物分布、历史环境、地形地物和保护管理需要，合理调整保护区划和具体边界，增强可操作性。建议北响堂石窟一类建设控制地带适当南扩，二类建设控制地带应当综合考虑山体与山前历史环境的保护需求，并与风景名胜区规划相协调；南响堂石窟二类建设控制地带边界宜缩小至滏阳河北岸。

2．应结合峰峰矿区响堂山风景名胜区的保护管理要求，进一步调整并细化管理规定，严格控制一类建设控制地带的建设活动，详细说明建设控制地带内新建建筑的规模、容积率、色彩、材质等具体控制指标和管理要求，合理调整建筑密度和绿地指标。风景名胜区一级保护区内不得新建建筑。

（三）关于保护措施

应根据现状评估结论，增强石窟、载体、建筑遗存、遗址等不同保护对象保护措施的针对性，明确保护工程的性质、内容和要求，增强针对性和专业性。石窟水患治理措施应由专业单位研究制定；采取防风化措施、进行保护性设施建设应慎重，充分考虑措施的必要性、可行性和文物影响，明确工程范围和要求；不同意实施灌浆堵漏加固工程。

（四）关于专项规划

1．统筹考虑南响堂石窟、北响堂石窟和常乐寺遗址的空间格局，以当前环境状况为依据，有针对性的研提环境整治措施。

2．根据采空区的分布范围、深度、规模以及岩石性质，客观评估其对文物的影响程度，分类研提采空区治理措施和操作要求，确保文物安全。

3．应根据游客量、展示服务和管理需求，统筹考虑新建游客中心、停车场、研究中心、展示中心的必要性，明确设施功能、选址、高度、体量、材质、色彩控制要求，尽量利用村镇现有公共文化服务设施，减少新建设施数量。补充说明新建建筑的选址依据。

4．应根据石窟消防需求、道路组织、相关建筑分布和开放程度，合理布置消防通道和消防器材，增强针对性。

（五）进一步完善与国家风景名胜区规划、森林公园规划等相关规划的协调措施。

（六）进一步梳理、规范文本，精炼规划条文，完善图纸信息，说明性文字内容应纳入规划说明。

三、请你局组织有关单位根据上述意见对所报保护规划进行修改、完善，按程序另行报批。

专此函。

国家文物局

2017年3月22日
