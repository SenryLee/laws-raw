# 中共教育部党组关于许征等同志职务任免的通知

教党任〔2017〕118号

中共复旦大学委员会：

经与中共上海市委商得一致，2017年5月10日研究决定：

许征同志任中共复旦大学委员会副书记，周亚明同志任中共复旦大学委员会常委；免去陈立民同志的中共复旦大学委员会副书记、常委职务。

中共教育部党组

2017年6月2日
