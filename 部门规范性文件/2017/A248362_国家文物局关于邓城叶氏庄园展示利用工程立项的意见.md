# 国家文物局关于邓城叶氏庄园展示利用工程立项的意见

## 关于邓城叶氏庄园展示利用工程立项的意见

办保函〔2017〕214号

河南省文物局：

你局《关于邓城叶氏庄园展示利用工程立项的请示》（豫文物〔2017〕59号）收悉。经研究，我局意见如下：

一、暂不同意邓城叶氏庄园展示利用工程立项。

二、请你局督促地方人民政府根据《关于邓城叶氏庄园修缮工程立项的批复》（文物保函〔2016〕369号）要求，抓紧编制邓城叶氏庄园保护规划，统筹考虑文物保护与展示工作。邓城叶氏庄园展示应注意突出文物的建筑艺术特色，及其在商水县近现代史中的重要地位，科学确定展示主题、方式、内容、游线设计、游客承载量等，协调处理好文物保护与旅游开发之间的关系。

三、请你局指导有关单位进一步论证工程实施的必要性和可行性，根据上述意见对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年3月6日
