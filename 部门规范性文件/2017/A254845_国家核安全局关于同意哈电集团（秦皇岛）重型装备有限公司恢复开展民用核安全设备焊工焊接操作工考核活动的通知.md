# 国家核安全局关于同意哈电集团（秦皇岛）重型装备有限公司恢复开展民用核安全设备焊工焊接操作工考核活动的通知

## 关于同意哈电集团（秦皇岛）重型装备有限公司恢复开展民用核安全设备焊工焊接操作工考核活动的通知

国核安函〔2017〕93号

哈电集团（秦皇岛）重型装备有限公司：

2017年7月28日，我局对你公司编造焊工考核过程记录文件等问题的整改情况进行了现场检查，认为你公司已按照相关要求对该事件进行了根本原因分析，并在核安全文化建设、质保体系完善、程序及制度落实等方面积极整改，取得阶段性成果。经研究，同意你公司自发文之日起恢复开展民用核安全设备焊工焊接操作工考核活动，同时提出如下核安全管理要求：

一、充分汲取经验教训，在后续民用核安全设备焊工焊接操作工考核活动中严格落实各项管理制度、质保程序和作业规程等。

二、持续巩固整改成果，建立长效机制，继续深入开展核安全文化宣贯和培育，强化人员管理，杜绝弄虚作假和违规操作行为。

三、我局委托环境保护部华北核与辐射安全监督站对你公司整改落实情况进行持续跟踪问效。

国家核安全局

2017年9月4日
