# 国家海洋局办公室关于实施《载人潜水器下潜作业规程》等4项海洋行业标准的通知

海办科字〔2017〕449号

沿海各省、自治区、直辖市及计划单列市海洋厅（局），涉海各有关高校、科研院所和企事业单位，局属各有关单位，局机关各有关部门，海标委及各分委会：

《载人潜水器下潜作业规程》等4项海洋行业标准已于2017年7月20日经国家海洋局批准发布（见附件），于2017年11月1日起实施。

请你们加强标准的应用实施，及时组织标准的宣贯和培训，自标准实施之日起，积极引用和使用以上标准。

附件：批准发布的《载人潜水器下潜作业规程》等4项海洋行业标准汇总表
