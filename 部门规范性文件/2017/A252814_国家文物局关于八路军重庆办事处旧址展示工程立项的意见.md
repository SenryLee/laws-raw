# 国家文物局关于八路军重庆办事处旧址展示工程立项的意见

## 关于八路军重庆办事处旧址展示工程立项的意见

办保函〔2017〕430号

重庆市文物局：

你局《关于审批全国重点文物保护单位八路军重庆办事处旧址展示利用工程立项报告的请示》（渝文物〔2017〕8号）收悉。经研究，我局意见如下：

一、应深入开展文物价值和开放、展示现状评估，客观分析目前存在的问题及展示提升的空间和条件，进一步论证工程实施的必要性和可行性。同时厘清展示利用思路，根据文物价值内涵确定展示内容与功能定位, 妥善处理各展示节点之间的关系，避免同质化倾向。

二、请你局指导有关单位，根据上述意见加强各项工作，并将展示利用相关内容纳入正在编制的八路军重庆办事处旧址保护规划中统筹考虑。在此基础上根据我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）要求，另行报批。

国家文物局

2017年4月12日
