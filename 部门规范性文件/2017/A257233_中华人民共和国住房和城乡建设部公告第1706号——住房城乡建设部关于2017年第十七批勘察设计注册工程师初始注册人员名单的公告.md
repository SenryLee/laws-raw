# 中华人民共和国住房和城乡建设部公告第1706号——住房城乡建设部关于2017年第十七批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

第1706号

## 住房城乡建设部关于2017年第十七批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）及有关规定，经审核，丁茂林等95名申报注册土木工程师（岩土）初始注册人员、王敬烨等155名申报一级注册结构工程师初始注册人员、杨帆等155名申报注册公用设备工程师初始注册人员、成洪甫等95名申报注册电气工程师初始注册人员、王蕴慧等37名申报注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1.准予丁茂林等95名注册土木工程师（岩土）初始注册人员名单

2.准予王敬烨等155名一级注册结构工程师初始注册人员名单

3.准予杨帆等155名注册公用设备工程师初始注册人员名单

4.准予成洪甫等95名注册电气工程师初始注册人员名单

5.准予王蕴慧等37名注册化工工程师初始注册人员名单

住房城乡建设部

2017年10月25日
