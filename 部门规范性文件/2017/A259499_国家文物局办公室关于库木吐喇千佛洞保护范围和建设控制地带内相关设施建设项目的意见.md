# 国家文物局办公室关于库木吐喇千佛洞保护范围和建设控制地带内相关设施建设项目的意见

办保函〔2017〕1440号

新疆维吾尔自治区文物局：

你局《关于报送新疆库木吐喇千佛洞文物保护利用设施建设项目初步设计的请示》（新文物字[2017]64号）收悉。经研究，我局意见如下：

一、该方案未能明确拟建项目与库木吐喇千佛洞文物保护区划及相关规划的关系，其必要性与可行性论证不充分，暂不同意所报方案。

二、具体修改意见如下：

（一）应补充库木吐喇千佛洞文物保护规划相关内容，并在文物保护区划总图中明确标示拟建项目的位置与范围，作为项目论证的基本参考。

（二）应按照文物保护规划及相关规划要求，进一步论证、缩减各设施建设规模，避免冗余建设及其对文化遗产景观环境带来的负面影响。

（三）对现有的管理用房、防洪坝等建构筑物，及绿化植被情况，应补充相关照片及图纸，并对其使用情况进行科学评估，审慎决策其去留。

（四）调整建筑与景观设计思路。应尽可能弱化新建建筑、构筑物和景观设计的体量感和形式符号，突出库木吐喇千佛洞的主体地位。景观设计应注意与当地气候相适应，不得大规模造景。

（五）道路、桥梁、停车场、防洪设施等的设计应补充相关专业技术论证内容。

（六）结合上述要求编写文物影响评估报告，客观评估拟建项目对文物本体及景观环境的影响。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善后，另行报批。

专此函复。

国家文物局办公室

2017年12月28日
