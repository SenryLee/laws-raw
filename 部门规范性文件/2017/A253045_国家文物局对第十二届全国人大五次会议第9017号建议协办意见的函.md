# 国家文物局对第十二届全国人大五次会议第9017号建议协办意见的函

## 对第十二届全国人大五次会议第9017号建议协办意见的函

办保函〔2017〕649号

河南省人民政府办公厅：

根据我局职能范围，现就白红战等16名代表提出的《关于大力支持郑州建设国家中心城市的建议》提出如下协办意见：

郑州市历史文化底蕴深厚，市域范围内共有各类不可移动文物8600余处。2016年，国家文物局公布《大遗址保护“十三五”专项规划》，提出以郑韩故城、郑州商城遗址等为重点，支持郑州市实施大遗址保护示范工程；继续指导做好郑州城市考古工作，不断廓清郑州城市发展脉络，明确重要遗址分布保存现状及其文化内涵，充分展现郑州在中华五千年文明发展过程中重要作用。同时，我局将会同有关部门继续积极推进郑州商城、郑韩故城、大河村等考古遗址公园建设，充分发挥大遗址保护和国家考古遗址公园的社会效益，使大遗址保护利用工作融入城市建设，承担城市公共文化服务功能，支持郑州建设彰显人文特色的现代化都市；支持郑州市各级政府和有关部门，认真贯彻国务院《关于进一步加强文物工作的指导意见》的有关要求，积极采取措施，充分发挥重要大遗址在文化传承中的作用，丰富城乡文化内涵，彰显地域文化特色。

以上意见供参考。
