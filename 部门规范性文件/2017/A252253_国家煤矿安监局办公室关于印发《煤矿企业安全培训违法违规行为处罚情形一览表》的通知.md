# 国家煤矿安监局办公室关于印发《煤矿企业安全培训违法违规行为处罚情形一览表》的通知

煤安监司函办〔2017〕30号

各产煤省、自治区、直辖市及新疆生产建设兵团煤矿安全培训主管部门：

现将汇编形成的《煤矿企业安全培训违法违规行为处罚情形一览表》予以印发，便于你们在煤矿安全培训监督检查执法中执行。

附件：煤矿企业安全培训违法违规行为处罚情形一览表

国家煤矿安监局办公室

2017年6月29日
