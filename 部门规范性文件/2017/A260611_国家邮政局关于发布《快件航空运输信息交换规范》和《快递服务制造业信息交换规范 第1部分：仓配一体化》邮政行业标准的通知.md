# 国家邮政局关于发布《快件航空运输信息交换规范》和《快递服务制造业信息交换规范 第1部分：仓配一体化》邮政行业标准的通知

国邮发〔2017〕45号

各省、自治区、直辖市邮政管理局，中国邮政集团公司，各主要快递企业：

现发布YZ/T 0158-2017《快件航空运输信息交换规范》和YZ/T 0159-2017《快递服务制造业信息交换规范 第1部分：仓配一体化》推荐性邮政行业标准。以上两项标准均自2017年8月1日起施行，由人民交通出版社负责出版发行。

《快件航空运输信息交换规范》和《快递服务制造业信息交换规范 第1部分：仓配一体化》的发布与实施，对于引导快递业加快实现与航空业、先进制造业之间的信息交换和共享，促进快递业与关联产业协同发展，提升快递业竞争能力和水平具有重要意义。请各单位认真组织标准的宣贯工作，采取有力措施推动标准的实施，更好地促进邮政行业持续健康发展。
