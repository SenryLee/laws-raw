# 国家邮政局关于加快推进全国邮件快件实名收寄信息系统推广应用工作的通知

国邮发〔2017〕31号

中国邮政集团公司、中国邮政速递物流股份有限公司、各主要快递企业总部：

为贯彻落实《中华人民共和国反恐怖主义法》和党中央、国务院有关决策部署，加快全国邮件快件实名收寄信息系统推广应用，提升落实实名收寄制度信息化、标准化、规范化水平，2017年2月10日，国家邮政局、公安部、国家安全部联合印发《关于加快全国邮件快件实名收寄信息系统推广应用工作的实施方案》（国邮发〔2017〕14号，以下简称《实施方案》），明确了实名收寄信息系统推广应用的总体要求、工作原则、职责分工、建设模式、实施步骤等有关内容。3月28日，国家邮政局、中央综治办、公安部、国家安全部联合召开全国电视电话会议，对实名收寄信息系统推广应用工作进行了全面动员部署。为加快推进实名收寄信息系统推广应用工作，抓好《实施方案》贯彻落实，现将有关事宜通知如下：

一、严格落实主体责任。各企业是实名收寄信息系统推广应用工作的主体责任单位，要将该项工作列入重要议事日程，成立由企业负责人担任组长的工作领导小组，加强统一领导，尤其要加强对所属分支机构和加盟企业的管理。要成立工作专班，明确职责分工，确保责任落实到人。要按照《实施方案》要求，抓紧研究制定各项配套制度措施，确保按期完成任务。要主动加强与邮政管理部门的联系，及时协调解决实名收寄信息系统建设和推广应用过程中遇到的问题。各企业领导小组及工作专班成员名单请于4月15日前报国家邮政局邮政业安全中心。

二、做好企业版实名收寄信息系统建设和优化升级工作。尚未建成实名收寄信息系统的企业要加大投入力度，加快企业版实名收寄信息系统开发建设进度，力争尽快投入使用，及时与国家邮政局实名监管信息系统实现数据对接。已完成项目建设并开展试点的企业要总结经验，及时解决数据不能及时、全量上传和终端操作效率低等问题。要不断提高数据质量，实名收寄采集的数据信息必须包含运单号码、寄件人有效身份证类型、有效身份证号、电话号码和寄件人、收件人姓名地址（GPS或手填，GPS优先）等内容，其他信息可通过异步方式录单上传。

三、做好信息安全保障工作。各企业要严守信息安全底线，遵循相关标准规范，加强信息安全基础建设，落实网络安全保护相关法律法规，建立健全信息安全事件应急联动处置机制，对提供服务过程中获取的用户个人信息，制定严格的信息安全保护制度，对采集、验证、传输、保存和销毁个人信息等行为予以规范，及时纠正登记内容繁琐重复、登记方式不规范等问题，建立健全全流程安全防范机制，防止个人信息泄露和非法使用。

四、切实保护用户合法权益。各企业要采取便捷高效的信息采集、核验方式，不断提高采集效率。要加强技术创新，利用电子运单、身份保护、权限管理、加密、线上线下举报制度等措施，有效防范非法采集、买卖、泄露、对外提供个人信息等行为，切实保护用户合法权益。要规范证件使用，对确需保留的证件复印件，应规范制式、加强防伪、便于识别。

五、强化教育培训。各企业要利用各类新闻媒体，加强相关政策的宣传，努力营造良好舆论氛围。要加大投入，加强技术队伍建设，研究完善吸引和稳定技术人才的机制。要通过开展业务培训会、印发使用指导手册等方式，加大业务培训力度，切实提高从业人员的信息安全意识和操作技能，确保制度执行不留死角。

六、加快工作推进进度。各企业要尽快研究制定实名收寄信息系统推进方案和工作计划，并定期报送工作进展情况，不断加大工作力度，鼓励先行先试，加快推广，确保2017年实名收寄信息化覆盖率达到40%以上，2018年年底前基本实现实名收寄信息化全覆盖的工作目标。各企业推进方案请于4月15日前报国家邮政局邮政业安全中心。

国家邮政局

2017年4月7日
