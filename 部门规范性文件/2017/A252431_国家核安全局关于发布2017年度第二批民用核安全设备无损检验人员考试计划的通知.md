# 国家核安全局关于发布2017年度第二批民用核安全设备无损检验人员考试计划的通知

## 关于发布2017年度第二批民用核安全设备无损检验人员考试计划的通知

国核安函〔2017〕65号

国核电站运行服务技术有限公司，中核武汉核电运行技术股份有限公司，中广核检测技术有限公司，中国核动力研究设计院，中国核工业二三建设有限公司：

经研究，现发布《2017年度第二批民用核安全设备无损检验人员考试计划》（见附件）。请各单位通过国家核安全局民用核安全设备无损检验人员资格管理信息系统（http://www.cqcn.org）填写考试报名表，并按相关要求报名参加考试。

附件：2017年度第二批民用核安全设备无损检验人员考试计划

国家核安全局

2017年7月10日
