# 中国证券监督管理委员会并购重组委2017年第22次会议审核结果公告

## 并购重组委2017年第22次会议审核结果公告

中国证券监督管理委员会上市公司并购重组审核委员会2017年第22次会议于2017年5月5日上午召开。现将会议审核结果公告如下：

一、审核结果

南方出版传媒股份有限公司（发行股份购买资产）获有条件通过

南京全信传输科技股份有限公司（发行股份购买资产）获无条件通过

北京佳讯飞鸿电气股份有限公司（发行股份购买资产）获无条件通过

二、审核意见

1.南方出版传媒股份有限公司购买资产方案的审核意见为：

请申请人补充披露本次交易募集配套资金的必要性和合理性。请独立财务顾问、律师核查并发表明确意见。

请申请人针对本次交易相关的土地房产权属瑕疵，对照首次公开发行时的承诺，补充说明承诺未实现的原因及下一步的解决方案。请独立财务顾问、律师核查并发表明确意见。

请南方出版传媒股份有限公司逐项予以落实，并在10个工作日内将有关补充材料及修改后的报告书报送上市公司监管部。

上市公司监管部

2017年5月5日
