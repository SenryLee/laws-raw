# 国家文物局关于萧大亨墓地石刻修缮工程立项的意见

## 关于萧大亨墓地石刻修缮工程立项的意见

办保函〔2017〕175号

山东省文物局：

你局《关于申请萧大亨墓地石刻维修工程立项的请示》（鲁文发〔2016〕194号）收悉。经研究，我局意见如下：

一、该工程实施的必要性和可行性不足，暂不同意萧大亨墓地石刻修缮工程立项。

二、对所报立项报告提出以下修改意见：

（一）加强前期勘察和研究，明确文物保存现状、主要病害类型、残损情况等，客观分析石刻污染、断裂、风化等病害原因，合理确定工程范围和保护对象，进一步论证工程实施的必要性。补充说明萧大亨墓神道、石像生地面的现状情况。

（二）进一步论证工程实施的可行性，补充实施依据。应在开展必要的、一定周期的文物环境监测工作基础上，明确文物所处环境的变化规律；进一步加强实验室和现场试验，在试验成果的基础上深化设计思路，并补充相关数据说明，明确材料配比、工艺技术、施工流程等，为制定有针对性的修缮措施提供科学依据，确保保护措施的可靠性与可行性。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促地方人民政府加强石刻及墓冢本体的日常养护、巡查和管理，统筹考虑文物保护和展示利用问题，落实人员责任，确保文物安全。

专此函。

国家文物局

2017年2月24日
