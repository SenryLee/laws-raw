# 水利部科技推广中心关于发布2017年度水利先进实用技术重点推广指导目录的通知

## 关于发布2017年度水利先进实用技术重点推广指导目录的通知

水技推〔2017〕15号

各流域机构，各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局，各有关单位：

为深入贯彻国家创新驱动发展战略，落实水利部党组提出的“推广转化100项先进实用水利科技成果，加快水利科技成果的转化应用”要求，为夯实水利基础、保障国家水安全、实现水利现代化提供坚实的科技支撑和技术引领，我中心根据《水利先进实用技术重点推广指导目录管理办法》，围绕新时期水利工作方针，结合水利工作实际技术需求，组织开展了《2017年水利先进实用技术重点推广指导目录》的评审工作，共有180项技术（产品）列入，现将评审结果予以发布。

各地要结合工作实际，加大创新步伐，认真组织好先进实用适用技术的推广转化，加强先进技术应用宣传，切实提高现代水利发展水平，努力实现科技兴水目标。

附件：《2017年度水利先进实用技术重点推广指导目录》
