# 全国银行间同业拆借中心关于发布《全国银行间同业拆借中心国债做市支持业务操作细则》的通知

## 关于发布《全国银行间同业拆借中心国债做市支持业务操作细则》的通知

中汇交发〔2017〕200号

国债做市支持参与机构：

为规范全国银行间债券市场做市商参与国债做市支持行为，保障国债做市支持机制顺利开展，全国银行间同业拆借中心（以下简称“交易中心”）制定了《全国银行间同业拆借中心国债做市支持业务操作细则》（以下简称《操作细则》），经财政部和中国人民银行同意，现向市场发布。交易中心即日起将提供国债做市支持操作平台及相关服务。国债做市支持参与机构可通过本币交易系统前台客户端登录国债做市支持操作平台，进行做市支持申报、竞价投标、信息查询等操作，操作流程请遵照《操作细则》执行。

特此通知。

附件：全国银行间同业拆借中心国债做市支持业务操作细则

全国银行间同业拆借中心

2017年6月9日

## 全国银行间同业拆借中心国债做市支持业务操作细则

**第一条**　为规范国债做市支持参与机构（以下简称“参与机构”）参与国债做市支持行为，保障国债做市支持机制顺利开展,根据《财政部、中国人民银行公告[2016]第122号》（以下简称“公告”）和《财政部、中国人民银行关于印发<国债做市支持操作规则>的通知》（财库〔2016〕154号，以下简称“规则”）制定本细则。

**第二条**　全国银行间同业拆借中心（以下简称“交易中心”）提供国债做市支持操作平台（以下简称“操作平台”）及相关服务。

**第三条**　参与机构是指全国银行间债券市场做市商中记账式国债承销团甲类成员。

在参与国债做市支持前，参与机构应为本机构用户在操作平台设置具体操作权限。

**第四条**　参与机构应基于真实需求，于申报日通过操作平台提交国债做市支持需求意向，需求意向信息包括做市支持方向、标的债券、申报量等。具体申报日期由交易中心向参与机构提前公布。

申报应在申报日上午9:00-12:00进行，申报时间结束前参与机构可对申报信息进行修改或撤销。同一申报日内，参与机构对同一债券同一方向仅可提交一条申报信息。

**第五条**　交易中心收集、整理参与机构申报信息，如达到《规则》规定的发起条件的，交易中心制作国债做市支持申请表，报财政部与人民银行。如未达到发起条件的，交易中心将申报数据报财政部与人民银行。

**第六条**　交易中心有关工作人员按照国债做市支持操作通知在操作平台设置当次国债做市支持要素，包括基本参数和竞价约束条件等，经财政部有关工作人员审核确认后通过操作平台向参与机构发布。

**第七条**　国债做市支持的基本参数包括：交易方向、标的债券、竞价时段、随买随卖量、结算方式、清算速度等。国债做市支持的竞价约束条件包括：每标位最低/最高申购/申售量、参与机构最高/最低申购/申售价位、价格变动幅度等。

**第八条**　竞价买卖按以下流程进行：

（一）参与机构根据操作平台设定的竞价约束条件，在国债做市支持操作日竞价时段即上午11:05-11:35，录入并复核申购/申售信息。

（二）申购/申售信息经复核后生效。复核前原录入用户可修改申购/申售信息；竞价时段结束前所有用户均可撤销申购/申售信息。

（三）竞价时段结束时，操作平台根据竞价规则生成买卖结果。随买随卖单一价格的形成机制为：按照随买参与机构所报卖价自低向高或随卖参与机构所报买价自高向低的顺序中标，直至满足操作平台设定的随买/随卖量为止，竞价成功机构以相同的价格（所有随买中标价格中的最高价格或所有随卖中标价格中的最低价格）来出售/购买中标国债。

若申购/申售总量大于随卖/随买量，则中标的最高随买价格之下或最低随卖价格之上的申购/申售按各自申购/申售量中标，中标的最高随买价格或最低随卖价格上的申购/申售按申购/申售量比例分配，取整至1000万元，尾数按申购/申售时间优先原则分配。

**第九条**　竞价成功并生成竞价结果后，操作平台将成交数据自动传输至中央国债登记结算有限责任公司用于结算。参与机构应严格按照与财政部签署的相关协议以及成交单的约定向财政部履行付款或付券义务。

**第十条**　参与机构开展国债做市支持行为应：（一）遵守财政部、人民银行和交易中心发布的相关业务规则和本细则；（二）遵循真实诚信的原则进行国债做市支持申报，在申报前应通过交易中心本币交易系统现券匿名买卖匹配功能满足本机构国债交易需求；（三）不得以任何形式操纵市场价格，扰乱市场秩序。

**第十一条**　参与机构若有以下情形的，交易中心可向财政部、人民银行报告：（一）无法正常履行国债参与机构义务的；（二）出现严重不正当竞价或操纵市场等行为的；（三）严重违反国债做市要求的；（四）其他违反法律法规或国债做市支持有关规定的行为。

**第十二条**　本细则未规定事宜，应遵照《公告》、《规则》和交易中心发布的《银行间债券市场债券交易规则》（中汇交发[2010]第283号）等有关规定执行。

本细则由交易中心负责解释和修订，自发布之日起实施。
