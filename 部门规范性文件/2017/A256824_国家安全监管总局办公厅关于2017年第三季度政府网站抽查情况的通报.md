# 国家安全监管总局办公厅关于2017年第三季度政府网站抽查情况的通报

安监总厅宣教函〔2017〕204号

各省级煤矿安监局，总局和煤矿安监局机关各司局，应急指挥中心：

按照《国务院办公厅关于印发政府网站发展指引的通知》（国办发〔2017〕47号）和《2017年第二季度全国政府网站抽查情况通报》要求，现将国家安全监管总局2017年第三季度网站抽查情况通报如下：

一、抽查总体情况

国家安全监管总局组织第三方机构，于2017年8月对负责普查范围内22家政府网站进了季度抽查，共抽查了7家网站，包括国家安全监管总局层面2家网站和省级煤矿安监局5家网站，抽查率达31.8%。按照《国务院办公厅关于开展第一次全国政府网站普查的通知》（国办发〔2015〕15号）确定的普查标准，采用“自动扫描+人工复核”相结合的方式进行检查，逐一打分。

抽查结果显示，5家网站综合评定为合格，分别为国家煤矿安监局网站、应急救援指挥中心网站、内蒙古煤矿安监局网站、重庆煤矿安监局网站、云南煤矿安监局网站；2家网站综合评定为不合格，分别为辽宁煤矿安监局网站、新疆煤矿安监局网站。

本次综合评定为不合格的网站将被列入今后重点抽查监测对象。

二、存在的主要问题

一是信息更新方面。被抽查的7家网站中，有6家存在信息更新不及时或空白栏目问题。2家不合格网站中，1家网站存在更新不及时栏目数量超过10个，被单项否决;1家网站存在空白栏目数量超过5个，被单项否决。二是在网站可用性方面。有6家网站存在不能正常访问的链接，最多的站内不可用链接达166个。1家网站监测截止日期前7天内首页不可连通比率达1.49%。三是互动回应方面。有5家网站信箱系统或网上咨询栏目无有效信息显示；有3家网站未开设调查征集栏目，或虽开设了栏目但一年内开展活动少于3次。此外，个别网站还存在基本信息不准确、办事指南要素缺失或不准确、标记栏目无准确名称、标记栏目链接错误等问题。

三、有关单位整改措施

此次抽查结束后，国家安全监管总局迅速将抽查发现问题的情况报告通过一对一发函方式发送到相关单位。有关单位高度重视，迅速整改，并分析查找原因制定相关对策。

一是逐条梳理、逐条整改。删除、合并空白栏目或进行信息填补，对更新不及时栏目增添信息或进行整合。逐条修复不可用链接，对确实修复不了的进行永久删除。二是定期开展自查自改。结合此次抽查发现的问题，各部门、各单位将定期自查列入工作计划，以及时发现问题、及时有效整改。三是进一步加强管理。不断完善细化政务公开目录和内容，增加公开工作的针对性，增加发布信息量，提高采集业务数据的及时性、准确性。四是加快网站升级改版速度。借抽查之机，尚未完成改版升级的加快改版升级速度，推动网站硬件、软件革新，推动科学合理规划栏目。

四、下一步工作要求

各部门、各单位要通过此次监测抽查，分析存在问题的深层次原因，并举一反三，采取有效措施，避免类似问题再次发生。同时，要严格按照《国务院办公厅关于印发政府网站发展指引的通知》（国办发〔2017〕47号）要求，进一步推进政府网站健康有序发展。

（一）加强政府网站规范管理。加快做好本部门、本单位政府网站查遗补漏工作，各网站均要在首页添加“我为政府网站找错”监督举报平台入口，及时准确处理平台留言，按照《政府网站发展指引》（国办发〔2017〕47号）要求规范网站名称和域名，加强链接管理。

（二）对栏目进行优化整合。各部门、各单位要对网站信息数据进行科学分类、及时更新，对信息数据无力持续更新或维护的栏目要进行优化整合，科学合理规划网站栏目设置。同时，严格做好内容迁移、公告和基本信息变更报备工作，杜绝“擅自关停”“只关停不迁移内容”等问题。

（三）不断提高网站功能实用性。各部门、各单位要进一步完善政府网站信息发布、解读回应和互动交流功能，加强政务服务功能建设，为企业和群众提供准确好用的办事服务。
