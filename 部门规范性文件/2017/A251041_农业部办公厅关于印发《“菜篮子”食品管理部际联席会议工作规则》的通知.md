# 农业部办公厅关于印发《“菜篮子”食品管理部际联席会议工作规则》的通知

农办市〔2017〕12号

国家发展改革委、财政部、国土资源部、环境保护部、交通运输部、商务部、国家卫生计生委、工商总局、食品药品监管总局、银监会、证监会、保监会办公厅：

为深入贯彻落实《国务院办公厅关于印发“菜篮子”市长负责制考核办法的通知》（国办发〔2017〕1号），全面提升“菜篮子”工程建设水平，经“菜篮子”食品管理部际联席会议（以下简称“联席会议”）成员单位共同研究决定，建立“菜篮子”食品管理部际联席会议工作规则。

一、主要职责和任务

（一）协调解决“菜篮子”发展重大政策问题，创新完善“菜篮子”市场调控机制和措施。

（二）监督检查“菜篮子”市长负责制落实情况，组织开展“菜篮子”市长负责制考核。

（三）制定“菜篮子”工程建设规划及实施方案，监督检查各地“菜篮子”工程建设情况。

（四）完成党中央、国务院交办的其他事项。

二、机构及成员构成

（一）联席会议由农业部、国家发展改革委、财政部、国土资源部、环境保护部、交通运输部、商务部、国家卫生计生委、工商总局、食品药品监管总局、银监会、证监会、保监会等13个部门组成。联席会议成员由13个部门的分管负责同志担任，农业部分管负责同志担任召集人。

（二）联席会议下设办公室，设在农业部市场与经济信息司，办公室成员由13个部门相关司（局）的负责同志担任，各单位指定一名处级干部担任联络员。

（三）联席会议成员、办公室成员及联络员因工作变动需要调整的，应向联席会议办公室备案。

三、议事规则

（一）联席会议议事方式分为成员会议和办公室会议。成员会议主要讨论涉及部门协调的重要事项，办公室会议主要讨论落实政策和协同推动工作中的具体问题。

（二）联席会议办公室负责筹备成员会议和办公室会议，以农业部办公厅名义印发会议通知，商成员单位准备会议材料并提前送交参会人员。

（三）成员会议和办公室会议后，由联席会议办公室负责整理会议纪要并印发各成员单位。需要请示的重大事项，由农业部会签各成员单位后报国务院。

附件：“菜篮子”食品管理部际联席会议成员、办公室成员名单
