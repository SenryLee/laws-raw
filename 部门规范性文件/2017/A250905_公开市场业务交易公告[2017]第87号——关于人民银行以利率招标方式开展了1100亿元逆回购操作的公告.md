# 公开市场业务交易公告[2017]第87号——关于人民银行以利率招标方式开展了1100亿元逆回购操作的公告

## 公开市场业务交易公告

[2017]第87号

2017年5月10日，在发放抵押补充贷款476亿元的基础上，人民银行以利率招标方式开展了1100亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 7天 | 900亿元 | 2.45% |
| 14天 | 100亿元 | 2.60% |
| 28天 | 100亿元 | 2.75% |

中国人民银行公开市场业务操作室

二〇一七年五月十日
