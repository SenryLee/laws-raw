# 农业部关于政协十二届全国委员会第五次会议第3352号（社会管理304号）提案答复的函

## 关于政协十二届全国委员会第五次会议第3352号（社会管理304号）提案答复的函

您提出的关于进一步加大“双返”创业政策扶持力度的提案收悉。经商人力资源社会保障部和中央宣传部，现答复如下。

一、关于强化组织领导，制定“双返”创业发展规划

2015年，农业部牵头制定了推进农民创业创新行动计划（2015—2017年）,加强对农民返乡创业创新的规划指导。2016年，国务院办公厅印发《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》（国办发〔2016〕84号，以下简称国办《意见》），为返乡下乡人员创业创新提出了更系统、更全面、针对性更强的政策支持。要求健全组织领导机制，把促进返乡下乡人员创业创新作为经济社会发展的重点任务予以统筹安排；农业部发挥牵头作用，明确推进机构，加强工作指导，建立部门间协调机制，督促返乡下乡人员创业创新政策落实，加强经验交流和推广；地方人民政府建立协调机制，明确任务分工，落实部门责任，形成工作合力；加强调查研究，结合本地实际，研究制定和落实支持返乡下乡人员创业创新的政策措施；提升公共服务能力，利用农村调查系统和农村固定观察点，加强对返乡下乡人员创业创新的动态监测和调查分析。

二、关于出台扶持“双返”创业人员的优惠政策措施

国办《意见》从市场准入、金融服务、财政支持、用地用电、创业培训、社会保障、技术支持和创业园区等八个方面提出了推动返乡下乡人员创业创新的政策措施。2017年1月,河南省结合本省实际,细化实化政策措施,以省政府办公厅名义印发了《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的实施意见》（豫政办〔2017〕21号）。

2017年6月，农业部公布了1096个依法合规、功能完备、辐射带动能力较强、产业融合发展趋势明显的全国农村创业创新园区（基地）目录，为返乡下乡人员创业创新提供可选择的场所和高效便捷的服务。同时，农业部联合有关部门，强化政策集成，将国办《意见》提出的“八个政策大礼包”和农村产业融合政策，向园区整合，吸引地方政府、金融机构和社会资本向园区投资，积极推进返乡大学生和农民工创业创新健康发展。

三、关于加大宣传推介工作力度

近年来，农业部积极开展创业创新宣传。国办《意见》公开后，农业部第一时间与国新办举行了专题新闻发布会，回答中外记者提问，解读文件内容，回应社会关切。通过编制手册、制定明白卡、编发短信微信微博等方式，广泛宣传解读政策措施。同时，召开农业系统支持返乡下乡创业创新工作视频会议，韩长赋部长讲话，对深入贯彻落实国办《意见》精神，推进返乡下乡创业创新工作进行动员部署。国办《意见》的出台，引起了社会各界广泛关注和热议，一周内有565家各类媒体发送消息和评论2668条。农业部组织筹办全国农村创业创新项目创意大赛，共有27个省（区、市）完成省级选拔赛，共遴选出320个优秀项目和选手，11月将在苏州举办总决赛，将真正的高手比出来。总结北京市密农人家科技有限公司创办农产品电商平台等100个典型案例，作为全国农村创业创新优秀带头人典型案例向社会推介，通过各种媒体和渠道广泛宣传，激励更多的返乡下乡人员创业创新，进一步营造全社会关心支持农村创业创新的良好氛围。中央宣传部做好“全国大众创业万众创新活动周”宣传报道，结合“五一”劳动节、大学生毕业季等时间节点，宣传返乡大学生和农民工创业人员回乡创业的典型，反映他们建设家乡、攻坚克难的风貌，讲好就业创业故事。

农业部将切实发挥牵头作用，协调推动政策落实，搭建公共服务平台，总结推广好经验好做法，继续深入挖掘和宣传一批“双返”创业人员中的典型人物，反映草根创业者艰苦奋斗、追求梦想的精神风貌，进一步发挥典型示范引领作用，促进农村创业创新蔚然成风。

感谢您对农村创业创新工作的关心，希望今后继续支持我部工作。

农业部

2017年9月15日
