# 国家文物局关于燕翼围展示利用工程立项的意见

## 关于燕翼围展示利用工程立项的意见

办保函〔2017〕293号

江西省文物局：

你局《关于呈报〈燕翼围展示利用工程立项报告〉的请示》（赣文物局字〔2017〕3号）收悉。经研究，我局意见如下：

一、深化展示需求研究，明确展示现状情况及存在的主要问题，完善展示利用的必要性分析。

二、展示内容应紧紧围绕文物建筑的价值及自身所承载的文化信息；展示方式应适宜文物建筑内部环境，严格控制声光电等设备的使用范围；展示工程应避免对文物本体造成新的破坏。

三、区域内仍有部分村民居住，应注意协调村民生活管理与展示利用之间的关系。

四、根据实际展示需求，合理选择展示项目，戏曲编排、非遗展示等项目不得纳入经费预算。

此复。

国家文物局

2017年3月21日
