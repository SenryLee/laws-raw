# 国家文物局关于大运河仪扬运河真州段故道保护与展示工程立项的意见

## 关于大运河仪扬运河真州段故道保护与展示工程立项的意见

办保函〔2017〕361号

江苏省文物局：

你局《关于上报全国重点文物保护单位大运河仪扬运河真州段故道保护与展示工程立项报告的请示》（苏文物保 〔2017〕36号）收悉。经研究，我局意见如下：

一、大运河仪扬运河真州段故道不属于全国重点文物保护单位大运河的文物构成，其保护展示工程不属于我局行政审批事项。

二、请你局督促地方人民政府按照《大运河遗产保护管理办法》要求，切实加强大运河江苏段文物的日常保养和岁修工作，落实管理维护责任，确保文物安全。

专此。

国家文物局

2017年3月31日
