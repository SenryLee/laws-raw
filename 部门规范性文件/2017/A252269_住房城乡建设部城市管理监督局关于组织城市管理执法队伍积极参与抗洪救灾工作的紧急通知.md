# 住房城乡建设部城市管理监督局关于组织城市管理执法队伍积极参与抗洪救灾工作的紧急通知

建督综函〔2017〕32号

各省、自治区住房城乡建设厅，北京市城市管理委员会、城市管理综合行政执法局，天津市市容和园林委员会，上海市住房城乡建设管理委员会，重庆市市政管理委员会，新疆生产建设兵团建设局：

近日部分地区遭遇暴雨连袭，多地出现洪涝灾情，造成严重损失。一些城市道路、房屋、桥梁等被淹，市政基础设施受损，部分城区停水停电，严重影响城市秩序和人民群众生产生活。为保障城市安全有序运行，保护人民群众生命财产安全，各地要组织动员城市管理执法队伍，在当地党委政府的统一领导下，积极投入抗洪救灾工作，发挥数字化城市管理平台的调度作用，充分发扬敢打硬仗连续作战的精神，以实际行动践行以人民为中心的理念，展现政治坚定作风优良的城市管理执法队伍形象。城市管理执法人员在参加抗洪抢险救灾时，要注重安全保障。

请你们加强对城市管理执法队伍参与抗洪救灾工作的指导，总结宣传基层队伍涌现的先进事迹，并及时将有关情况报我局。

中华人民共和国住房和城乡建设部城市管理监督局

2017年7月4日
