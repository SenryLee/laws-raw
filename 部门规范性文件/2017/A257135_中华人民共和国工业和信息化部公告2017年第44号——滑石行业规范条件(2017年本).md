# 中华人民共和国工业和信息化部公告2017年第44号——滑石行业规范条件(2017年本)

## 中华人民共和国工业和信息化部公告

2017年第44号

为保护性开发和高效利用滑石资源，推进产业结构优化，鼓励行业技术创新，改善生产经营环境，引导社会合理投资，促进滑石产业健康可持续发展，我部制定了《滑石行业规范条件（2017年本）》，现予公告。

附件：滑石行业规范条件(2017年本)

工业和信息化部

2017年10月26日
