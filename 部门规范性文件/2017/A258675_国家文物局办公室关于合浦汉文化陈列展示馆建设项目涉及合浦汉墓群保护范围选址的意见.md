# 国家文物局办公室关于合浦汉文化陈列展示馆建设项目涉及合浦汉墓群保护范围选址的意见

办保函〔2017〕1349号

广西壮族自治区文化厅：

你厅《关于报送合浦汉文化陈列展示馆建筑设计方案的请示》（桂文物报〔2017〕49号）收悉。经研究，我局意见如下：

一、暂不同意合浦汉文化陈列展示馆建设项目涉及合浦汉墓群保护范围的选址方案。

二、所报建设项目尚需做以下必要的修改和完善：

（一）建议另行选址，尽量远离文峰塔，以免影响文物周边景观环境。

（二）若确需在文峰塔旁选址，应严格控制占地面积和建筑高度，加强前期论证和可行性研究，充分说明建筑体量、功能和外观设计依据，深化方案设计深度。

（三）应进一步明确该展示馆的功能定位，突出主题，避免与现有合浦汉文化博物馆的功能定位、展示内容相重复。

三、请你厅指导建设单位根据上述意见对所报方案做进一步修改和完善，按程序另行报批。

国家文物局办公室

2017年12月12日
