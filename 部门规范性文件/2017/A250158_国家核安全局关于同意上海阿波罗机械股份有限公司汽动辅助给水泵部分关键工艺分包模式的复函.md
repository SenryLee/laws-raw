# 国家核安全局关于同意上海阿波罗机械股份有限公司汽动辅助给水泵部分关键工艺分包模式的复函

## 关于同意上海阿波罗机械股份有限公司汽动辅助给水泵部分关键工艺分包模式的复函

国核安函〔2017〕43号

上海阿波罗机械股份有限公司:

你公司《关于汽动辅助给水泵功能性试验分包等请示的备案函》（沪阿字［2017］第020号）收悉。经研究，我局同意你公司关于汽动辅助给水泵功能性试验等部分关键工艺的分包模式。

你公司应加强对分包活动的质量管理和过程控制，并对汽动辅助给水泵的设计和制造质量承担全面责任。

特此函复。

国家核安全局

2017年5月3日
