# 国家文物局关于环县塔保护规划编制立项的意见

## 关于环县塔保护规划编制立项的意见

办保函〔2016〕1396号

甘肃省文物局：

你局《关于环县塔保护规划（新编）立项的报告》（甘文局发〔2016〕167号）收悉。经研究，我局意见如下：

一、环县塔文物构成单一，规划编制的必要性不足，应结合所在地村镇总体规划编制统筹考虑文物保护的规划措施和要求，合理调整全国重点文物保护单位的保护区划、管理规定和具体保护管理措施，严格控制周边各类建设活动，可不再编制专项文物保护规划。

二、请你局督促、指导地方人民政府加强“四有”建设，加强日常巡查和监测，确保文物及其周边环境安全。

专此函。

国家文物局

2017年1月4日
