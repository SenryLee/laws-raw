# 国家文物局关于在法行寺塔建设控制地带内进行汝州市盛玺花园建设项目的意见

## 关于在法行寺塔建设控制地带内进行汝州市盛玺花园建设项目的意见

办保函〔2017〕291号

河南省文物局：

你局《关于报批汝州市盛玺花园建设项目设计方案的请示》（豫文物〔2017〕77号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位法行寺塔建设控制地带内，建筑高度过高，对文物影响过大，我局暂不同意该项目。

二、对所报方案提出以下修改意见：

（一）调整方案设计，进一步降低建筑高度，并注意建筑外观与文物本体及周边环境景观风貌相协调，尽量保持和延续汝州老城区的历史氛围。补充法行寺塔建设控制地带的管理制定和具体控制指标、文物周边环境现状照片等。

（二）调整文物影响评估报告编制思路，客观评估工程建设的文物安全和景观环境影响，科学分析法行寺塔周边建设情况，比对拟建区域的周边现状建筑高度，研提方案调整建议，增强文物影响评估报告的针对性和有效性。

三、请你局根据所提意见，对项目方案进行修改完善后，按程序另行报批。

四、请你局指导当地人民政府组织专业机构，按照《关于法行寺塔保护规划的意见》（办保函〔2015〕344号）的要求，抓紧修改、完善法行寺塔保护规划，统筹考虑文物保护、展示利用、环境整治等方面工作。

专此函。

国家文物局

2017年3月21日
