# 国家文物局办公室关于在宣化柏林寺保护范围和建设控制地带内进行环境整治项目的意见

办保函〔2017〕1314号

河北省文物局：

你局《关于呈报宣化柏林寺环境整治工程设计方案的请示》（冀文物字〔2017〕245号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位宣化柏林寺保护范围和建设控制地带内，设计依据不足，文本深度不够，对文物影响较大，我局暂不同意宣化柏林寺环境整治项目。

二、该方案应进行以下必要的修改和完善：

（一）应认真调整设计思路，以加强宣化柏林寺文物价值、历史格局等保护为目的，在深入研究原有建筑格局、历史环境要素等的基础上，进一步论证在文物保护区划范围内大量设施建设项目及其选址的科学性和必要性，合理核定设施总需求量，优化功能布局，严格控制新建设施数量、规模和体量，尽量减少对文物及周边环境的影响。如，管理用房、厕所、小车库及杂物间距离文物本体过近，建议拆除平整场地后另行选址，可考虑结合管理大厅及游客服务中心统筹设计，保护范围内尽量保护原有历史景观风貌；研究论证新建观景亭、长廊的依据，无确切依据的情况下不同意在保护区划内新建观景亭和长廊；应适当控制寺前公共空间规模，进一步缩减广场及停车场面积等。

（二）开展绿化工程之前应开展岩体稳定性评估，清理碎石过程中应注意保持山体岩石的稳定性。

（三）登山步道宽度不应超过1.5米，步道栏杆形式应简洁，同时应进一步勘察游客步道周边的山体安全，并进行必要的加固整治。

（四）完善方案图纸，补充必要的工程总平面图和对位关系图，正确反映总体设计的平面和竖向关系，并确保图文一致。

三、请你局指导相关单位根据上述意见和我局《关于在宣化柏林寺保护范围和建设控制地带内进行环境整治项目意见的函》（办保函〔2017〕859号）要求，认真修改、调整方案，按程序另行报批。

专此函复。

国家文物局办公室

2017年11月30日
