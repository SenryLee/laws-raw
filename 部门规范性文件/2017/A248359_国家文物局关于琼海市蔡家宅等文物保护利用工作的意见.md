# 国家文物局关于琼海市蔡家宅等文物保护利用工作的意见

## 关于琼海市蔡家宅等文物保护利用工作的意见

文物保函〔2017〕428号

海南省文化广电出版体育厅：

你厅《关于申请琼海市革命文物保护展示利用工程立项的请示》（琼文化〔2017〕19号）收悉。经研究，我局意见如下：

一、关于全国重点文物保护单位蔡家宅保护

第六批全国重点文物保护单位蔡家宅是20世纪30年代海南建筑文化的典型代表。2009年至2016年我局先后批复蔡家宅的保护修缮、安防、消防、防雷和展示利用工程项目，并由中央财政安排文物保护专项补助资金1500余万元。

请你厅加强指导做好上述工程项目的实施和检查、验收，并督促进一步加强对蔡家宅的日常维护保养和开放展示，充分发挥文物的社会作用。如确实需要新增蔡家宅保护工程项目和资金需求的，请按程序报批。

二、关于琼海市革命文物保护

我局将争取把琼海市革命类文物保护单位作为重点纳入并积极争取中央财政加大支持力度。

国家文物局

2017年3月3日
