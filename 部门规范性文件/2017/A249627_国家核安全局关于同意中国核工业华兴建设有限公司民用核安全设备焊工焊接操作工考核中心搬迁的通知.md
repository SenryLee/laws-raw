# 国家核安全局关于同意中国核工业华兴建设有限公司民用核安全设备焊工焊接操作工考核中心搬迁的通知

## 关于同意中国核工业华兴建设有限公司民用核安全设备焊工焊接操作工考核中心搬迁的通知

国核安函[2017]39号

中国核工业华兴建设有限公司：

你公司《关于民用核安全设备焊工焊接操作工考核中心地址搬迁申请的报告》（华兴函2016-53）收悉。经研究，同意你公司在新地址（江苏省南京市江宁区滨江开发区天成路58号）开展民用核安全设备焊工焊接操作工资格考核活动。

你公司应按照规定的考核活动范围开展民用核安全设备焊工焊接操作工考核活动，有效运行质量保证体系，确保民用核安全设备焊工焊接操作工考核活动质量。

特此通知。

国家核安全局

2017年4月17日
