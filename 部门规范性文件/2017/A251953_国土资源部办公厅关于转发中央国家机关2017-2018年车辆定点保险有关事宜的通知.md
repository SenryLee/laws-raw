# 国土资源部办公厅关于转发中央国家机关2017-2018年车辆定点保险有关事宜的通知

国土资厅函〔2017〕818号

各在京预算单位：

根据国务院办公厅有关文件要求及规定，中央国家机关政府采购中心通过公开招标方式确定了2017-2018年度中央国家机关机动车辆定点保险公司，印发了《关于中央国家机关2017-2018年车辆定点保险有关事宜的通知》（国机采〔2017〕7号），现转发给你们，请遵照执行。

2017年5月25日
