# 公开市场业务交易公告[2017]第163号——关于8月25日不开展公开市场操作的公告

## 公开市场业务交易公告

[2017]第163号

考虑到财政支出、地方国库现金管理商业银行定期存款操作、金融机构法定准备金退缴等因素将投放流动性，对冲央行逆回购到期后银行体系流动性处于适中水平，8月25日不开展公开市场操作。

中国人民银行公开市场业务操作室

二〇一七年八月二十五日
