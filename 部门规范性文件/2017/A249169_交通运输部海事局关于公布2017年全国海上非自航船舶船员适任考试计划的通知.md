# 交通运输部海事局关于公布2017年全国海上非自航船舶船员适任考试计划的通知

海船员函〔2017〕289号

长江航务管理局、各直属海事局：

为做好2017年度全国海上非自航船舶船员适任考试工作，现将有关事项通知如下：

一、海上非自航船舶船员适任考试考点设置

海上非自航船舶船员适任考试考点以方便考生和航运企业为原则，结合申请参加适任考试的考生人数和生源分布进行设置。考点的具体设置由各直属海事局根据本辖区实际情况确定。

二、2017年度全国海上非自航船舶船员适任考试计划

2017年度全国海上非自航船舶船员适任考试共举办2期（具体安排见附件）。

三、全国海上非自航船舶船员适任考试形式

全国海上非自航船舶船员适任考试采用计算机终端考试的形式。

请各单位通知有关培训机构和航运单位，按上述计划做好报名和考试相关工作。

附件：2017年度全国海上非自航船舶船员适任考试安排表

交通运输部海事局

2017年3月31日
