# 国家安全监管总局办公厅关于督促整改安全隐患问题的函

安监总厅管三函〔2017〕106号

河南省安全生产监督管理局：

国家安全监管总局督导组于2017年5月10日至11日，对你省洛阳炼化宏力化工有限责任公司等6家企业进行了检查，并在现场指出了存在的安全隐患问题。现将有关安全隐患问题（见附件）反馈你局，请你局组织当地安全监管部门，下达执法文书，依法进行行政处罚，督促有关企业尽快整改到位，确保安全生产，并就强化你省危险化学品安全生产工作提出以下要求：

一、加强特殊作业安全监管。要深刻吸取你省豫港（济源）焦化集团有限公司“4·28”爆炸和吉林省松原石化有限公司“2·17”闪爆事故教训，认真举一反三，全面查找存在的管理漏洞和薄弱环节，深入开展动火、进入受限空间等特殊作业安全整治，提出更有针对性、实效性的措施要求，并加大对动火、进入受限空间等特殊作业安全专项执法检查力度，依法从严从重处罚违法违规行为，有力督促企业严格按照有关法律法规标准规范强化规范特殊作业安全管理。

二、坚决防范遏制较大以上事故。要深刻认识防范遏制重特大事故的重要性和紧迫性，准确认清工作差距不足，深入贯彻落实《遏制危险化学品和烟花爆竹重特大事故工作意见》（安监总管三〔2016〕62号），牢固树立“抓小防大，抓大不放小”的工作思路，坚持从防范较大事故和着火、爆炸、中毒等典型事故入手，突出“两重点一重大”以及重点环节、重点部位管理，积极创新监管方式方法，强化贯彻力执行力落实力，大力开展基于风险点的风险管理控制、隐患排查治理、过程安全管理等工作，加速提升安全保障能力，有效防范遏制重特大事故发生。

三、全力推进危险化学品安全综合治理。要认真落实国务院安全生产委员会危险化学品安全综合治理电视电话专题会议和国家安全生产监管总局专题视频会议精神，按照你省实施方案，根据职责分工，全力推动危险化学品安全综合治理工作落实，尽快取得突破性进展和明显成效。要在认真抓好安全监管部门各项工作落实的同时，充分发挥安委会办公室的协调作用，积极主动作为，推动各有关部门落实好有关工作任务。要突出重点，加快做好全面摸排危险化学品安全风险，建立安全风险分布档案，形成电子图，建立危险化学品重大危险源数据库；盯紧盯牢危险化学品罐区、场站、仓库等重点区域场所，稳妥推进危险化学品生产企业搬迁工作；督促企业建立健全安全生产责任制，并加大日常执法处罚力度，严格落实企业安全生产主体责任。

请你省于6月16日前将有关执法处罚及整改落实情况和加强危险化学品安全监管举措报送国家安全监管总局监管三司。
