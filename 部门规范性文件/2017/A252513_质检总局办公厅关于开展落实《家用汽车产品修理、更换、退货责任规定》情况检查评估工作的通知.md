# 质检总局办公厅关于开展落实《家用汽车产品修理、更换、退货责任规定》情况检查评估工作的通知

质检办质函〔2017〕894号

各直属检验检疫局，各省、自治区、直辖市质量技术监督局（市场监督管理部门），质检总局缺陷产品管理中心：

为贯彻党中央、国务院关于开展质量提升行动的部署要求，促进汽车产品和服务质量提升，推动家用汽车企业落实产品质量担保责任，切实保护消费者合法权益，全面了解评估《家用汽车产品修理、更换、退货责任规定》（以下简称《规定》）制定实施以来的贯彻落实情况，质检总局定于2017年7月至10月对家用汽车产品生产者（从中华人民共和国境外进口家用汽车产品到境内销售的单位视同生产者）贯彻落实《规定》情况，以及推动产品和服务质量提升情况开展检查评估。现就有关事宜通知如下：

一、检查评估内容

（一）家用汽车产品生产者履行《规定》中生产者义务的情况，以及督促销售者和修理者履行《规定》的相关情况。

（二）实施《规定》以来的投入和效益情况，包括企业在产品研发制造、投诉处理机制、售后服务、配件供应、人员培训等方面促进产品和服务质量提升的相关情况。

二、时间进度安排

（一）自查评估阶段（8月底前完成）。

各省级质量技术监督部门组织督促辖区范围内家用汽车产品生产者对其执行《规定》的整体情况进行自查评估、填报表格（见附件）并提交总结报告，报告内容应包括落实《规定》建立工作机制和采取措施情况，《规定》实施以来修理、更换、退货的产品数量情况，落实《规定》对于产品和服务质量提升的促进作用，存在的问题和意见建议等内容。请省级质量技术监督部门于8月底前汇总生产者自查表格、总结报告，并将纸质版及电子版报送质量管理司。从境外进口家用汽车产品到境内销售的单位的自查评估、填报表格和提交总结报告由各直属检验检疫局组织督促，于8月底前报送检验监管司。

自查评估工作中涉及《规定》相关标准、规范、生产者备案信息、表格填报等问题，由缺陷产品管理中心提供技术支持。

（二）总局抽查阶段（10月底前完成）。

根据自查评估情况，总局统一组织或委托地方质检两局和有关单位对生产者进行抽查，通过实地走访和现场检查等方式，督促企业严格落实质量主体责任，完善产品质量担保责任。同时通过检查评估工作发掘先进经验和典型，加强宣传推广，激发汽车企业提升产品和服务质量的内生动力。

三、工作要求

（一）加强组织领导，积极推进落实。

各地质检两局要高度重视，结合消费者普遍关注的问题和本地区实际情况抓好组织落实，明确分工责任，确保检查评估工作取得实效。

（二）坚持规范和整治结合。

各地质检两局在开展《规定》检查评估的同时，要积极引导汽车企业规范自身经营行为，推动汽车企业加强自律、诚信守法经营，对于发现企业存在违反《规定》行为的，应及时提出监督整改意见，并认真组织回查确保相关问题整改到位。

（三）注重总结提炼，及时报送信息。

各地质检两局要注重总结《规定》实施中取得的好的经验、模式和做法，全面客观分析《规定》执行过程中存在的问题和困难，提出具有针对性和操作性的意见建议，形成总结报告，并于10月底前分别报送质量管理司和检验监管司。
