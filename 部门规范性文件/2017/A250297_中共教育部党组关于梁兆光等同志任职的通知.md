# 中共教育部党组关于梁兆光等同志任职的通知

教党任〔2017〕51号

部内有关司局：

按照中央组织部、中央统战部、国家民委关于选派西部地区和民族地区干部到中央单位挂职锻炼工作有关要求，经研究决定，任命：

梁兆光同志为政策法规司副司长；

马春晖同志为高校学生司副司长；

王慧同志为国际合作与交流司副司长。

以上同志挂职期均为一年，挂职期满后，挂任职务自行免去。

中共教育部党组

2017年4月7日
