# 农业部对十二届全国人大五次会议第1860号建议的答复

## 对十二届全国人大五次会议第1860号建议的答复

农办议〔2017〕211号

冯燕代表:

您提出的关于请农业部组织专家攻关研发秸秆低温降解剂的建议收悉。经商财政部，现答复如下。

一、关于请农业部组织专家攻关研发秸秆低温降解剂

长期以来，国家高度重视秸秆综合利用技术的科技研发工作，目前已经形成了秸秆栽培食用菌、压块燃料、生物柴油、田间快腐、饲料木质素降解等一批关键技术，开发研制了滚切式秸秆切碎装置、麦稻联合收割机配套打捆机、移动式生物质成型设备等一批关键装备，取得了显著的经济、社会和生态效益。我部专门设立了“作物秸秆还田技术”公益性行业科研项目，以我国五个主要农作区为研究对象，对各地出现的秸秆还田新问题、新需求进行技术研发和改造提升。此外，我部在现代农业产业技术体系中专门设置了秸秆利用岗位科学家，推动东北三省一区农科院和农垦科学院共同组建“东北区域玉米秸秆综合利用协同创新联盟”，搭建区域农业科技创新与交流平台。下一步，我部将组织秸秆利用岗位科学家和“东北区域玉米秸秆综合利用协同创新联盟”，针对玉米秸秆深翻还田、免耕覆盖、低温快腐、秸秆沼气发酵等关键技术瓶颈，积极争取国家重点研发项目，加大科技攻关力度。

二、关于对使用低温降解剂给予适当补贴

2016年，我部会同财政部围绕构建环京津冀生态一体化屏障，投入资金10亿元，在河北、山西、内蒙古、辽宁、吉林、黑龙江、江苏、安徽、山东、河南等10省（区）90个县，按照“整县推进、多元利用、政府扶持、市场运作”的原则，开展了秸秆综合利用试点，鼓励各地将使用低温降解剂纳入补贴范围，围绕“五料化”利用，探索可持续、可复制推广的秸秆综合利用技术、模式和机制。今年，为推动农业绿色发展，在继续开展试点建设的基础上，我部启动实施了“东北地区秸秆处理行动”，在东北地区60个玉米主产县开展整县推进秸秆综合利用，大力推广秸秆深翻还田、覆盖还田等循环利用技术，推动地方落实财政投入、税收优惠、金融信贷、用地、用电等政策，研究出台秸秆运输绿色通道、秸秆深加工享受农业用电价格、还田离田补贴等政策，不断提高秸秆产业化利用水平。下一步，我部将继续依托中央财政秸秆综合利用试点补助资金项目，支持秸秆综合利用的重点领域和关键环节，带动区域秸秆处理能力的整体提升。

三、关于加大组织推广力度

近年来，各地在推进秸秆综合利用的过程中都因地制宜形成了许多良好的运行模式。2016年，我部组织遴选了秸秆“五料化”利用19项技术，进行推介发布，为秸秆综合利用技术推广和知识普及提供指导。今年，我部在收集、总结各地模式的基础上，印发了《秸秆农用十大模式》，向全国宣传推广了山东齐河的麦秸覆盖玉米秸旋耕还田、江苏泗洪的稻麦秸秆粉碎旋耕还田、河北青县的秸秆沼气产业化综合利用等模式。为做好区域农作物秸秆全量化利用工作，我部印发了《区域农作物秸秆全量处理利用技术导则》，指导各地科学谋划和布局秸秆产业发展。同时，从2016年开始，为加强相近区域农作物秸秆综合利用的交流学习，我部在全国分区域、分作物、分利用途径召开秸秆机械化还田、离田系列现场交流会，广泛宣传推广秸秆综合利用的好做法、好经验和好典型。下一步，我部将继续加大成熟技术模式的推广应用力度，从根本上解决秸秆处理难、利用难的问题。

感谢您对农业和农村经济工作的关心，希望今后继续给予关注和支持。
