# 文化部办公厅关于公布全国地方戏曲南方会演参演剧目名单的通知

办艺函〔2017〕207号

上海市、江苏省、浙江省、安徽省、福建省、江西省、河南省、湖北省、湖南省、广东省、广西壮族自治区、海南省、重庆市、四川省、贵州省、云南省、西藏自治区文化厅(局)：

由中宣部文艺局、文化部艺术司主办的全国地方戏曲南方会演定于2017年9月19日至10月12日在湖北省武汉市举行。这是党的十九大召开前夕举办的一次重要地方戏曲会演活动，对于展示地方戏曲发展成就，加强地方戏曲院团交流，进一步推动地方戏曲传承发展具有积极意义。

经主办单位对各地申报的的作品进行审核，确定了17台剧目参加演出。现将参演剧目名单予以公布，并就有关事项通知如下:

一、请入选剧目所在地文化行政部门积极为演出单位参演全国地方戏曲南方会演创造便利条件，并协助入选剧目所在单位做好修改打磨工作，把握好剧目的思想导向性，努力提高艺术质量，以良好的精神风貌和精湛的艺术水准参加演出。

二、要高度重视宣传工作。在配合中宣部文艺局、文化部艺术司做好会演宣传工作的同时，各级文化行政部门要全力做好本地宣传工作。

三、要高度重视安全工作。请各级文化行政部门及各参演院团将主体责任落实到位，加强演职员安全教育，做好各方面的安全检查及安全保障工作。

本通知及附件可在文化部政府门户网站(www.mcprc.gov.cn)“公告通知”栏查询、下载。

特此通知。
