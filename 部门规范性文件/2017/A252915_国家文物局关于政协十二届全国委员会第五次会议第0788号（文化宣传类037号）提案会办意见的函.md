# 国家文物局关于政协十二届全国委员会第五次会议第0788号（文化宣传类037号）提案会办意见的函

## 关于政协十二届全国委员会第五次会议第0788号（文化宣传类037号）提案会办意见的函

办保函〔2017〕613号

水利部办公厅：

现就计时华委员提出的《关于加强我国水文化遗产保护与利用工作的提案》提出如下会办意见：

我国水文化遗产数量丰富，类型多样，具有重要的历史、艺术和科学价值。国家文物局一直高度重视水文化遗产相关的文物保护、管理及利用工作,已将大运河、都江堰、它山堰、通济堰、五门堰、镇海堤、洪泽湖大堤、紫阳堤、金口坝、渔梁坝、石龙坝水电站、辉河水坝遗址、鲍家屯水利工程、五龙口古代水利设施等一大批重要的水文化遗产，报请国务院核定公布为全国重点文物保护单位，中国大运河、都江堰还被联合国教科文组织列入《世界遗产名录》。同时，投入国家重点文物保护专项经费用于相关文物的规划编制、维修保护、展示利用以及监测系统建设等工作，有效改善了文物的保存和展示利用状况。

下一步，国家文物局将积极配合水利部等相关部门，进一步加大对水文化遗产保护工作的支持力度，重点做好以下工作：

第一，坚持依法行政，严格按照法律规定的职责开展水文化遗产保护管理。根据《中华人民共和国文物保护法》第八条规定，国务院文物行政部门主管全国文物保护工作，地方各级人民政府负责本行政区域内的文物保护工作，县级以上地方人民政府承担文物保护工作的部门对本行政区域内的文物保护实施监督管理，明确规定了文物保护的行业行政主管部门，确立了文物保护的属地管理原则。《文物保护法》第二十一条规定，国有不可移动文物由使用人负责修缮、保养。因此，列入各级文物保护单位的水文化遗产，应由文物部门负责监督管理，由所在地人民政府承担文物保护主体责任，由具体使用单位负责日常保养与修缮维护。

第二，积极开展水文化遗产的调查研究和宣传教育工作。国家文物局将配合水利部等相关部门，依托第三次全国文物普查有关成果，开展水文化遗产调查。加强基础研究，结合实际需求考虑制定水文化遗产相关的规范和标准。同时，国家文物局将督促、指导地方有关部门加强水文化遗产的日常管理，落实“四有”工作，制定科学可行的保护措施，确保文物安全，并进一步丰富和拓展水文化遗产的展示利用和宣传教育手段，充分发挥其公共文化服务功能和公益属性，引导社会公众自觉参与到水文化遗产保护行动中来，共同保护好珍贵遗产。

以上意见供参考。

国家文物局
