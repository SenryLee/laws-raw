# 中共教育部党组关于刘东志等同志职务任免的通知

教党任〔2017〕105号

中共天津大学委员会：

经与中共天津市委商得一致，2017年4月28日研究决定：

刘东志同志任中共天津大学委员会副书记，王树新同志任中共天津大学委员会常委；免去余建星、冯亚青同志的中共天津大学委员会常委职务。

中共教育部党组

2017年5月18日
