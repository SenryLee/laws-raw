# 教育部办公厅关于报送第二期特殊教育提升计划项目库的通知

教基厅函〔2017〕28号

各省、自治区、直辖市教育厅（教委）,新疆生产建设兵团教育局：

为贯彻落实《第二期特殊教育提升计划(2017-2020年)》和第二期特殊教育提升计划部署会议精神，进一步扩大特殊教育资源，改善特殊教育办学条件，全面提高特殊教育发展水平，请你们在编制省级实施方案的同时，抓紧建立第二期特殊教育提升计划省级项目库。我部将在各地报送省级项目库的基础上，建立“第二期特殊教育提升计划全国项目库”，并作为评价各地实施第二期特殊教育提升计划和中央财政专项资金奖补的重要依据。

各省（区、市）要按照《第二期特殊教育提升计划》所确定的目标任务和有关项目实施的要求（附件1），结合残疾学龄人口变化趋势和特殊教育事业发展等实际情况，科学测算特殊教育需求和存在的资源缺口，做好第二期特殊教育提升计划省级项目库的建设工作，认真填写《第二期特殊教育提升计划省级项目库》（附件2）,电子版下载地址：教育部门户网站基础教育司通知公告栏目。

请于9月25日前将省级项目库（加盖省级教育行政部门公章）报送教育部基础教育司，同时报送电子版。

联系人及联系方式：基础教育司，王红叶，010—66097807,tejiaochu@moe.edu.cn。

附件：1.第二期特殊教育提升计划对有关项目的要求

2.第二期特殊教育提升计划省级项目库

教育部办公厅

2017年8月2日
