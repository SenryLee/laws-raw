# 国家能源局综合司关于印发《2017年能源领域行业标准化工作要点》的通知

国能综科技[2017]216号

各能源行业标准化管理机构、各能源行业标准化技术委员会：

根据国家标准委《2017年全国标准化工作要点》及我局《2017年能源工作指导意见》，现提出《2017年能源领域行业标准化工作要点》并印发给你们，请结合本专业领域实际情况，贯彻落实好完善能源标准化管理制度、加强顶层设计和系统布局、强化重点领域标准制修订、提升能源标准国际化水平、进一步落实国家标准化改革重点工作、做好宣贯和培训等六个方面的工作，并及时做好年度总结。

附件：2017年能源领域行业标准化工作要点

国家能源局综合司

2017年4月1日

附件

## 2017年能源领域行业标准化工作要点

认真贯彻落实2017年全国标准化工作会议、全国能源工作会议、《2017年全国标准化工作要点》及《2017年能源工作指导意见》要求，紧密团结在以习近平同志为核心的党中央周围，全面贯彻党的十八大、十八届三中、四中、五中、六中全会和中央经济工作会议精神，牢固树立和落实“创新、协调、绿色、开放、共享”的新发展理念，围绕推动能源“四个革命、一个合作”需求，以推进能源供给侧结构性改革为主线，以提质增效为中心，在能源领域积极实施标准化战略，深入推进标准化改革，持续提升标准化管理水平，切实加强自身建设，以优异成绩迎接党的十九大胜利召开。

2017年重点做好以下工作：

一、完善能源标准化管理制度

贯彻国务院深化标准化改革精神，加强能源标准化制度建设，按照《标准化法》修订情况及其配套法规的新要求，总结能源标准化管理的实践经验，分析面临的新形势、新情况，修订完善《能源领域行业标准化管理办法（试行）》、《能源领域行业标准制定管理实施细则（试行）》、《能源领域行业标准化技术委员会管理实施细则（试行）》等能源标准化管理制度。

二、加强顶层设计和系统布局

在能源标准“三级管理”模式下，进一步加强国家能源局与行业标准化管理机构、标委会的沟通协调；坚持问题导向，加强核电标准结构优化及技术路线统一、水电技术标准“走出去”等能源领域标准化重大课题研究，提升科学管理水平；厘清能源行业标准化管理机构及标委会现有的管理职责问题，调整优化管理和技术资源配置；健全标委会考核评估机制，制定标委会考核评估方案，加强标委会动态管理；研究开展能源行业太阳能光热、能源互联网、岸电设施、储能、低压直流等新兴领域标委会组建工作。

三、强化重点领域标准制修订

紧密围绕能源革命和能源供给侧结构性改革，加快研制太阳能、能源互联网、油品质量升级等重点领域重要技术标准，完善标准体系建设，并逐步建立标准体系的动态维护机制（详见附件）；积极参与《节能标准体系建设方案》、《装备制造业标准化和质量提升规划》等国家标准体系规划实施；深入落实《“华龙一号”国家重大工程标准化示范项目实施方案》。

四、提升能源标准国际化水平

进一步加强与国际标准化组织（ISO）、国际电工委员会（IEC）等国际标准化组织的交流合作，支持相关能源企业、研究机构深入参与国际标准研制活动，增强我国在国际标准化活动中的话语权和影响力；积极推进核电标准的国际交流与合作，争取签署与法国核岛机械设备设计制造规则协会（AFCEN）的合作协议。配合国家“一带一路”倡议，围绕电力、油气等领域的重大能源工程及技术装备“走出去”，安排一批急需标准英文版翻译工作。

五、进一步落实国家标准化改革重点工作

按照国家标准化改革重点工作部门分工，组织落实能源领域强制性标准整合精简结论及推荐性标准集中复审结论，抓紧开展相关国家、行业标准的废止、转化、整合、修订等工作；推进落实工程建设强制性标准改革，在电力、石油天然气、煤炭等领域组织编制国家工程建设强制性标准体系。推进落实《节能标准体系建设方案》、《工程建设全文强制性标准体系》、《国家标准化体系建设发展规划（2016-2020年）》、《装备制造业标准化和质量提升规划》等国家标准规划任务。

六、做好标准宣贯和培训工作

以世界标准日、全国质量月等标准化重大活动和重要节点为契机，组织开展标准化会议、重要关键标准宣贯、培训等；围绕“华龙一号”国家重大工程标准化示范项目、第六阶段车用油品标准等影响范围大、社会关注度高的重点标准做好宣传贯彻工作。

附件：

能源重点领域重要技术标准研制及体系建设要求

石油天然气领域：组织修订天然气、普通柴油、车用乙醇汽油调合组分油和生物柴油等强制性国家标准；加强油气勘探开发、长输油气管道建设、海上石油勘探生产装备质量和作业安全等领域行业标准研制；持续完善页岩气标准体系，推进页岩气行业安全、环保等急需标准制定；推动天然气计量配套标准与国际接轨。

石油化工领域：抓紧落实第六阶段车用汽、柴油国家标准相关试验研究工作；制定地热能术语、地热开发环境影响评价、采出水余热利用、地下水回灌工程等地热能行业急需标准。

核电领域：围绕华龙一号、CAP1000和CAP1400核电项目建设所需，开展关键技术核电标准的研究、制定和修订；基于提高标准体系的协调性和系统性、利于用户使用我国核电标准等原则，持续优化完善核电标准体系，完成《压水堆核电厂标准体系项目表》的修订工作。

电力领域：加强节能环保标准化工作，制定超（超）临界机组、联合循环机组、高效燃气轮机以及火电建设与运行等急需标准；完善大坝安全管理标准体系，制定复杂地质条件下的水电专项施工技术标准以及节能环保施工标准；加快海上风电场工程建设、运行维护、海上升压站等方面标准编制；全面修订特高压标准体系，重点加强配用电领域标准建设，支持配电网规划设计、配电网运营管理、直流配电系统、用能信息采集、电能替代、需求响应等方面标准建设；加强电动汽车充换电设施标准体系动态维护，制定大功率充电、无线充电、充电服务平台信息交换等系列标准，制定分散式充电设施安装、检测、消防、运行维护标准；开展储能领域标准和核电常规岛标准的编制；制定行业用电分类标准。

电力装备领域：适应“互联网+智慧能源”、“中国制造2025”有关要求，推进电力装备新型标准体系建立，对现有标准体系进行全面梳理，做好标准项目的增补工作，提高标准适应性和实效性。

可再生能源领域：持续完善风电、光伏发电、生物液体燃料加工转化等领域标准体系；发布《水电行业技术标准体系》，加快移民安置、生态环保、流域安全等水电领域急需标准的制定；推动太阳能光热、分布式储能及能源安全生产、生物柴油、燃料醇类、燃料型非粮原料林培育和可持续经营标准制修订工作。

煤炭领域：持续完善煤矿瓦斯治理与利用、煤层气领域标准体系；推动煤制燃料领域关键产品标准、重点设备及标准及重点耗能单元能效标准研究，结合煤制燃料新产品开发制定合理适用的产品标准及配套标准。
