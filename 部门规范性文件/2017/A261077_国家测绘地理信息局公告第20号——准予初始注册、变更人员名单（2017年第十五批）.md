# 国家测绘地理信息局公告第20号——准予初始注册、变更人员名单（2017年第十五批）

## 国家测绘地理信息局公告

第20号

根据《注册测绘师制度暂行规定》和《注册测绘师执业管理办法（试行）》，经审核，叶洪剑等178人符合初始注册条件，准予初始注册；高智方等18人符合变更注册条件，准予变更注册。
