# 中华人民共和国农业部公告第2609号——注销的兽药产品批准文号目录

## 中华人民共和国农业部公告

第2609号

近期，北京市农业局、河南省畜牧局、山西省农业厅依法注销了北京保吉安科技有限公司、北京绿业潮兽药业有限公司、商丘市天一生物技术有限公司、山西天合元动物保健科技有限公司等4家企业的兽药生产许可证，江苏省农业委员会依法注销了海正药业南通有限公司非无菌原料药（非泼罗尼）生产线的兽药生产许可证，依据《中华人民共和国行政许可法》第七十条和《兽药产品准文号管理办法》第二十七条规定，现注销北京保吉安科技有限公司等上述5家企业的39个兽药产品批准文号（附件1），自有关公司兽药生产许可证注销之日起执行。

根据广西北流市盛威动物药品厂、宁波市三生药业有限公司、桂林养泰动保生物科技有限公司、北流市铜州药业有限公司等4家企业申请，同意注销有关公司取得的45个兽药产品批准文号（附件2），自本公告发布之日起执行。

依据《兽药产品准文号管理办法》第二十七条规定，兽药生产许可证有效期届满未申请延续或者申请后未获得批准的，相关企业取得的兽药产品批准文号自兽药生产许可证于有效期届满之日自动注销。

特此公告。

附件：1.注销的兽药产品批准文号目录（因企业兽药生产许可证被注销）

2.注销的兽药产品批准文号目录（依兽药生产企业申请）

农业部

2017年11月20日
