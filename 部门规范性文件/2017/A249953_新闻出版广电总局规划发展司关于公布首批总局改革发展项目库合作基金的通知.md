# 新闻出版广电总局规划发展司关于公布首批总局改革发展项目库合作基金的通知

## 关于公布首批总局改革发展项目库合作基金的通知

各省、自治区、直辖市及计划单列市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央各新闻出版单位主管部门：

根据《关于开展首批新闻出版改革发展项目库合作基金申报工作的通知》新广出办发〔2016〕95号精神和相关规定，总局开展了改革发展项目库合作基金遴选工作。经专家组评审核定并报总局领导同意，现将首批改革发展项目库合作基金名单予以公布。
