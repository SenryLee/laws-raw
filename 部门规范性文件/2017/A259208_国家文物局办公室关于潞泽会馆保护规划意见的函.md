# 国家文物局办公室关于潞泽会馆保护规划意见的函

办保函〔2017〕1388号

河南省文物局：

你局《关于洛阳潞泽会馆文物保护规划的请示》（豫文物〔2016〕244号）收悉。经研究，我局意见如下：

一、所报规划文物认定不清，保护区划不合理，我局暂不同意潞泽会馆保护规划。

二、所报规划应做以下必要修改和完善：

（一）关于文物认定和现状评估

1．应进一步厘清文物构成和保护对象，厘清层次,细化分类。

2．加强历史价值研究，补充潞泽会馆历史格局及环境变化相关内容。

3．加强现状评估，客观评价城市建设产生的环境影响。加强潞泽会馆院墙、铺地及石质文物保存现状评估。

（二）关于保护区划与管理规定

1．应根据文物分布情况和保护管理需要，结合文物历史格局，科学调整保护区划边界。保护范围南侧应包含遗址分布区，进一步论证将东西两侧博物馆纳入保护范围的必要性，补充调整依据。

2．根据文物周边历史环境特征，进一步完善保护区划管理规定，建议对建设控制地带分类后分别制定相应管理规定，严格控制河道两侧建设活动。根据潞泽会馆与文峰塔之间的视线通廊关系，适当调整建设控制地带内的建筑高度、规模、体量和外观等控制指标，增强可操作性。

（三）关于保护措施

应针对现状评估结论，研提文物保护措施，明确保护工程的类别、内容和要求。加强不同类别保护对象保护措施的针对性。不同意复建照壁、文昌阁和魁星楼等已消失建筑。

（四）关于环境整治和专项规划

深化环境整治措施，潞泽会馆南侧轴线恢复和道路调整应慎重，避免影响城市交通。完善展示利用规划，明确展示目标和内容，文物建筑与博物馆应统筹考虑、协同展示。根据周边道路及环境情况科学调整展示路线。完善考古研究规划，补充遗址相关内容。

（五）加强所报规划与《洛阳市历史文化名城保护规划》《隋唐洛阳城遗址保护规划》等相关规划的内容衔接。

（六）进一步规范文本和图纸，增强图文的对应性，规范用语。应将说明性内容纳入规划说明。

三、请你局指导有关单位，根据上述意见对潞泽会馆保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月19日
