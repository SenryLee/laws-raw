# 农业部关于政协十二届全国委员会第五次会议第1493号（农业水利类144号）提案答复的函

## 关于政协十二届全国委员会第五次会议第1493号（农业水利类144号）提案答复的函

农办案〔2017〕90号

磨长英委员：

您提出的“关于加强果蔬采后产地预冷能力建设，提升果蔬竞争力的提案”收悉。经商财政部，现答复如下。

一、关于加强政策扶持力度

农业部高度重视加强农产品冷链物流体系建设，积极参与制定并推动出台了《国务院办公厅关于加快发展冷链物流保障食品安全促进消费升级的意见》（国办发〔2017〕29号），重点在健全冷链物流标准和服务规范体系、完善基础设施网络、鼓励企业经营创新、提升信息化水平、加快技术装备创新和应用、加大行业监管力度、创新管理体制机制、完善政策支持体系等8个方面，推动完善我国农产品冷链物流体系。

2012年起，财政部会同农业部组织实施了农产品产地初加工补助政策，累计投入中央财政43亿元，共支持632个县、6万多个农户、9000多家合作社新建马铃薯贮藏窖、果蔬贮藏库等初加工设施12万余座，新增马铃薯贮藏能力200多万吨、果蔬贮藏能力270多万吨。2016年，财政部会同商务部组织实施冷链物流体系建设项目，安排中央财政资金10亿元、中央基本建设投资5300万元，重点支持建立冷链物流监控体系，推动冷库、冷藏车等安装冷链监控设备，建设冷链流通全程温控监测平台，完善冷链物流标准体系，加快冷链设施标准化改造，促进使用冷链运输标准化器具。2017年，国家农业综合开发项目将继续支持农业优势特色产业发展，符合农业综合开发政策规定的果蔬采后处理及产地预冷保鲜的项目，可积极向当地农发机构申请支持。

二、关于制定和完善果蔬采后处理技术标准及操作规程

国家有关部门高度重视果蔬采后加工生产标准化工作，目前已组织制定果蔬采后处理技术标准及操作规程类标准112项，涉及蔬菜领域的为42项、果蔬领域的70项。其中，国家标准39项、农业行业标准46项、商务行业标准17项、林业行业标准3项、地方标准7项。2016年，农业部指导成立了农产品冷链物流标准化技术委员会，旨在加强对果品、蔬菜、水产品、禽蛋等易腐农产品预冷、包装，低温贮藏、运输、销售等环节相关技术标准和专有设施装备等标准研究工作，推进我国农产品冷链物流标准化进程。同时，农业部还通过多种形式，加强标准宣贯，普及农产品冷链知识，不断提升农产品冷链物流标准化水平。

三、关于加大培育扶持采后处理和冷藏保鲜承担主体

农业部每年安排农业产业化项目，鼓励龙头企业建设农产品生产基地、带动农户发展生产和为农户提供贷款担保；通过举办相关培训等，提升龙头企业经营管理水平；搭建农业产业化交易会等产销对接平台，打造知名品牌；完善相关政策措施，推动龙头企业转型升级。为促进农民合作社发展，2014年，农业部等九部委联合印发了《关于引导和促进农民合作社规范发展的意见》（农经发〔2014〕7号），明确加大财税扶持、创新金融保险服务、给予用地用水用电支持、扩大涉农项目承担规模等，发挥政策导向作用，促进农民合作社规范健康发展。2017年，中央财政安排补助资金14亿元，重点支持国家农民合作社示范社，突出农产品加工、产品包装、市场营销等关键环节，积极发展生产、供销、信用“三位一体”综合合作。同时，农业部还在部分省份开展合作社贷款担保保费补助试点，探索建立政策性农业信贷担保体系。在促进家庭农场发展方面，2014年，农业部印发了《关于促进家庭农场发展的指导意见》（农经发〔2014〕1号），并指导全国30个省（区、市）出台了扶持家庭农场发展的指导意见。2017年，农业部、财政部共同实施的重点强农惠农政策中，明确提出支持家庭农场能力建设，以示范家庭农场为扶持对象，支持发展绿色农业、生态农业，提高农产品加工、标准化生产、市场营销等能力。据不完全统计，截至目前，各地扶持家庭农场发展的财政资金已经超过13.8亿元。从事果蔬采后处理和冷藏保鲜的各类农业经营主体，可积极向当地农业主管部门申请相关政策和项目资金支持。

四、关于加强技术培训

从2014年开始，农业部与财政部联合组织实施新型职业农民培育工程。截至目前，中央财政累计安排资金50.9亿元，重点面向种养大户、家庭农场主、农民合作社骨干、农业社会化服务人员和返乡涉农创业者，以提高生产经营能力和专业技能为目标，开展农业全产业链培训。各地可将果蔬采后商品化处理和产地预冷保鲜等技术知识和市场营销、品牌建设等通用知识纳入培训内容。同时，农业部还依托农村实用人才带头人和大学生村官示范培训项目，面向全国遴选种养大户、家庭农场主、农民合作社负责人和大学生村官等到农村实用人才培训基地学习，帮助他们转变发展理念，提升生产经营水平，增强创业兴业、致富带富的本领。

下一步，农业部将继续组织实施好农产品产地初加工补助政策等扶持政策，加大对农产品冷链物流建设的支持力度，加大对从事农产品采后处理和冷藏保鲜的各类农业经营主体的扶持力度，加大各类专业人才培训力度，加强果蔬采后处理相关标准的宣贯工作，不断提高农产品采后预冷技术水平，为保障农产品质量安全、增强市场竞争力做出新贡献。

感谢您对农业发展的关心，希望继续支持农业部工作。

农业部

2017年9月1日
