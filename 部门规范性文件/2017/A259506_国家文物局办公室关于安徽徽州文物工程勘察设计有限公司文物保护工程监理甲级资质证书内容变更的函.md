# 国家文物局办公室关于安徽徽州文物工程勘察设计有限公司文物保护工程监理甲级资质证书内容变更的函

办保函〔2017〕1419号

安徽省文物局：

你局《关于申请变更安徽徽州文物工程勘察设计有限公司文物保护工程监理资质证书的请示》（皖文物保〔2017〕98号）收悉。

经研究，我局同意安徽徽州文物工程勘察设计有限公司文物保护工程监理甲级资质证书中的法定代表人由“程忠平”变更为“王宏山”，单位地址由“安徽歙县徽州路5号”变更为“黄山经济开发区梅林大道88号（黄山徽文化产业园综合办公楼403室）”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2017年12月26日
