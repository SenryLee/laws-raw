# 中共教育部党组关于唐辉明等同志职务任免的通知

教党任〔2017〕123号

中共中国地质大学（武汉）委员会：

经与中共湖北省委商得一致，2017年6月1日研究决定：

唐辉明同志任中共中国地质大学（武汉）委员会副书记；免去傅安洲同志的中共中国地质大学（武汉）委员会副书记，郝芳同志的中共中国地质大学（武汉）委员会常委、委员职务。

中共教育部党组

2017年6月2日
