# 国家文物局关于贺兰山岩画文物保护利用设施建设项目的意见

## 关于贺兰山岩画文物保护利用设施建设项目的意见

办保函〔2017〕42号

宁夏回族自治区文物局：

你局《关于报送审批〈贺兰山岩画文物保护利用设施建设项目建设方案〉的请示》（宁文物发〔2016〕111号）收悉。经研究，我局意见如下：

一、所报方案设计思路不明确，设计依据不足，文本深度不够，我局暂不同意贺兰山岩画文物保护利用设施建设方案。

二、所报方案应进行以下必要的修改和完善：

（一）该工程位于全国重点文物保护单位贺兰山岩画保护范围和建设控制地带内，应严格遵守《中华人民共和国文物保护法》、《贺兰山贺兰口岩画文物保护总体规划》以及宁夏回族自治区人民政府关于贺兰山岩画文物保护的相关规定要求，合理确定工程内容和范围，妥善解决文物保护、展示利用和日常管理问题。

（二）应尽快开展工程范围内的专项工程地质勘察，明确区域内的气象、水文、地质等基本情况，梳理、研究当地自然灾害的类型、发生频率、强度等，补充必要的勘察数据、资料。同时，应深入、科学评估2016年暴雨山洪灾情的影响程度、防护设施有效性和大量设施受损原因，研提自然灾害治理措施和应急预案，确保文物所在区域环境安全。

（三）完善文物影响评估报告，深入论证拟建项目对文物本体安全和环境风貌的影响，做到客观、准确、科学。

（四）进一步完善方案设计，结合区域防灾要求和文物保护展示需要，统筹考虑基础设施、保护设施、服务设施的选址、建设规模、功能布局等，合理确定工程范围、技术和强度，确保相关设施与岩画遗址区自然和人文环境相协调。

（五）应论证修建木栈道的必要性，说明木栈道与浆砌片石道路的关系，进一步核减木栈道长度。

（六）电力工程、给水工程应注意与现有管理服务设施设计相衔接。

（七）应明确拟建项目与贺兰山岩画的位置关系。充分考虑施工对文物安全的影响，制定必要的文物保护措施和应急预案。补充《贺兰山贺兰口岩画文物保护总体规划》的有关内容，以及文物保护区划管理规定和具体控制指标。

三、请你局组织有关单位根据上述意见，对所报方案进行修改、完善后，按程序另行报批。

专此函。

国家文物局

2017年1月20日
