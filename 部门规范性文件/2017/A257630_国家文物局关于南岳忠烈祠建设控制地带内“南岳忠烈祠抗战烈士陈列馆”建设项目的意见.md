# 国家文物局关于南岳忠烈祠建设控制地带内“南岳忠烈祠抗战烈士陈列馆”建设项目的意见

文物保函〔2017〕1858号

湖南省文物局：

你局《关于审批南岳忠烈祠建设控制地带内“南岳忠烈祠抗战烈士陈列馆”建设工程设计方案的请示》（湘文物报〔2017〕134号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、对方案提出以下修改意见：

（一）深化现状勘察，补充现状地形图、保护区划图、现存文物分布图等相关基础资料图纸。

（二）进一步论证项目建设的必要性，补充建设项目选址变更的必要性说明。补充建设项目在文物保护区划内的位置图，核实说明建设项目与保护范围的位置关系。

（三）进一步缩小拟建项目的建筑体量，使其尽可能符合保护规划中建设控制要求。

（四）在南岳忠烈祠东侧、北侧控制硬化工程，适当增加绿化，弱化新建项目对原有祠堂视线影响，最大限度保护文物历史环境风貌。

（五）在借鉴传统建筑特色的基础上，进一步优化新建项目的建筑设计方案。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十八条规定，报城乡建设规划部门批准实施。工程施工期间，应加强监管，确保文物安全。

国家文物局

2017年11月16日
