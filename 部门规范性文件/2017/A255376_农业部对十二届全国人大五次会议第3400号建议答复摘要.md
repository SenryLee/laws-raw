# 农业部对十二届全国人大五次会议第3400号建议答复摘要

## 十二届全国人大五次会议第3400号建议答复摘要

农办议〔2017〕230号

丘陵山区坡地多、地块小而散、田块落差大,制约了丘陵山区机械化作业的发展。实行“改地适机”可以长远解决丘陵山区农业机械化问题，为丘陵地块使用市场上现有的大中型农机高效作业创造条件。农业部将于今年下半年召开全国“改地适机”现场会，推广重庆市等地的工作经验。同时也将积极协调争取出台“改地适机”的扶持政策措施，力求从根本上改变丘陵山区农业机械化落后的局面，并有针对性地促进丘陵山区农机新装备研发应用,完善推广相应的全程机械化生产模式。

下一步，农业部将指导支持慈利县推进丘陵山区机械化进程。指导湖南省农机主管部门结合“阳光工程”等农民培训项目，统筹考虑加强慈利县农机人才培训工作。指导慈利县实施好农业部2017年农业技术试验示范与服务支持项目，探索适宜当地全程机械化技术模式。指导省级农机主管部门按照《农业部办公厅关于加快农机购置补贴政策实施促进农业供给侧结构性改革的通知》要求，适应农业结构调整和农业绿色发展的需要，对高效植保、节水灌溉、高效施肥、秸秆还田离田、畜禽粪污资源化利用、病死畜禽无害化处理等机具实行敞开补贴，可据此加大对当地特色产业及农业绿色发展急需的农机具的补贴力度，提高丘陵山区农机化及养殖业废弃物资源化利用装备水平。

农业部

2017年8月18日
