# 国家文物局关于紫金城城址与铁河古墓群环境整治工程立项的意见

## 关于紫金城城址与铁河古墓群环境整治工程立项的意见

办保函〔2017〕100号

江西省文物局：

你局《关于呈报〈紫金城城址与铁河古墓群环境整治工程立项报告〉的请示》（赣文物局字〔2016〕208号）收悉。经研究，我局意见如下：

一、暂不同意紫金城城址与铁河古墓群环境整治工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步论证环境整治工程的必要性和紧迫性，加强统筹遗址的保护管理，应首先重点做好墎墩汉墓的保护展示。

（二）进一步明确工程对象、范围和内容，不宜将地形整治作为环境整治工作的主要内容。应在保护规划的指导下开展村庄拆迁、建筑风貌整治、道路建设、植被清理与调整等工作，并与相关规划进行衔接，避免产生矛盾造成重复投入或浪费。

（三）进一步明确开展工程所具备的考古工作基础，不应对尚未开展考古工作的区域进行相关整治，避免对地下遗存造成破坏。

三、请你局指导立项报告编制单位，根据上述意见对所报立项报告做进一步修改和完善，经你局核准后，按程序另行报批。

国家文物局
