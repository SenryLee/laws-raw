# 中华人民共和国水利部公告2017年第32号——水利部关于废止、宣布失效和修改部分规范性文件的公告

本篇法规中关于修改《水利建设市场主体信用信息管理暂行办法》（水建管〔2009〕496号）的相关规定已被《水利部关于印发水利建设市场主体信用信息管理办法的通知》自2019年11月25日起废止。本篇法规中关于修改《水利建设市场主体信用评价管理暂行办法》（水建管〔2015〕377号）的相关规定已被《水利部关于印发水利建设市场主体信用评价管理办法的通知》自2019年11月25日起废止。本篇法规中关于修改《水利部国家发展和改革委员会关于加快水利建设市场信用体系建设的实施意见》（水建管〔2014〕323号）的相关规定已被《水利部关于废止一批文件的公告》自2025年6月27日起废止。

## 水利部关于废止、宣布失效和修改部分规范性文件的公告

为了贯彻落实国务院简政放权、放管结合、优化服务改革措施，水利部对部门规范性文件进行了全面清理，经商有关部门，决定废止13件、宣布14件失效、修改13件，现予公布。
