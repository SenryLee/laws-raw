# 中国国家认证认可监督管理委员会公告2017年第20号——国家认监委关于发布强制性产品认证目录产品与2017年HS编码对应参考表的公告

## 中国国家认证认可监督管理委员会公告

2017年第20号

## 国家认监委关于发布强制性产品认证目录产品与2017年HS编码对应参考表的公告

为便利强制性产品认证目录内产品的进口贸易，提高监管效率，国家认监委组织编制完成了《强制性产品认证目录产品与2017年HS编码对应参考表》（以下简称《参考表》），现予以发布。

《参考表》仅作为强制性产品认证目录产品判定的参考，有关强制性产品认证目录产品的具体描述与界定，以国家认监委发布的相关产品实施强制性产品认证的公告为准。

附件：强制性产品认证目录产品与2017年HS编码对应表

国家认监委

2017年7月25日
