# 科技部办公厅关于启用“科技部政府信息公开工作专用章”的通知

机关各厅、司、局、办，直属机关党委，各直属事业单位，科技日报社：

根据科技部政府信息公开工作需要，按照《科学技术部印章管理办法》有关规定，“科技部政府信息公开工作专用章”从即日起启用，用于公民、法人或者其他组织向科技部提出政府信息公开申请的书面答复。

特此通知。

附件：科技部政府信息公开工作专用章（样章）

科技部办公厅

2017年7月7日
