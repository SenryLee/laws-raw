# 中华人民共和国农业部公告第2557号——新兽药注册目录

## 中华人民共和国农业部公告

第2557号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准北京市农林科学院等10家单位申报的鸡新城疫、传染性法氏囊病、禽流感（H9亚型）三联灭活疫苗（La Sota株+BJQ902株+WD株）等3个产品为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年8月2日
