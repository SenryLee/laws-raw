# 国家新闻出版广播电影电视总局关于开展2017年“百社千校”阅读活动的通知

## 关于开展2017年“百社千校”阅读活动的通知

新广出函〔2017〕322号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央军委政治工作部宣传局，中央和国家机关各部委、各民主党派、各人民团体出版单位主管部门，中国出版集团公司，中国教育出版传媒集团有限公司，中国科技出版传媒集团有限公司，有关出版单位：

为深入贯彻落实党中央、国务院关于开展全民阅读的重要部署，大力推动少年儿童阅读，为少年儿童健康成长营造良好文化环境，国家新闻出版广电总局决定2017年继续组织开展“百社千校”阅读活动。现将有关事项通知如下。

一、活动目的

深入学习宣传贯彻习近平总书记系列重要讲话精神和党中央治国理政新理念新思想新战略，加强中国梦和社会主义核心价值观宣传教育,弘扬中华优秀传统文化，进一步推动少年儿童阅读，不断丰富广大少年儿童的精神文化生活，在全国少年儿童中形成“爱读书、读好书、善读书”的良好读书风尚，营造建设书香社会的浓厚氛围。总局组织100家左右图书出版单位，与全国各地特别是老少边穷地区的千所中小学共同开展多种形式的阅读活动。

二、活动安排

（一）参加活动单位。2017年10月，各省级新闻出版广电行政部门和中央出版单位主管部门根据实际情况，启动组织工作。各省分别推荐1～4家出版单位并报备总局，中央出版单位自愿向总局报名，总局根据实际情况遴选出部分出版单位参加。

（二）活动时间安排。本次阅读活动2017年10月启动，2017年12月结束。参加活动的出版单位要因地制宜制定活动方案，并认真组织落实。

（三）报送相关材料。各省级新闻出版广电行政部门和中央出版单位主管部门将相关出版单位的活动方案、活动总结报告（含电子版）审核、汇总后，分别于10月20日、12月10日前，报送至总局出版管理司。

三、活动内容

（一）开展主题读书活动。深入学习贯彻习近平总书记系列重要讲话精神和党中央治国理政新理念新思想新战略，培育和践行社会主义核心价值观，开展中国特色社会主义和中国梦宣传教育，传承和弘扬中华优秀传统文化，深入开展主题读书活动，唱响主旋律，传播正能量，引导少年儿童为实现中华民族伟大复兴中国梦而奋斗。

（二）邀请名家走进校园。积极组织知名作家深入校园开展读书活动和阅读推广服务，举办校园书香节、经典导读、名作展示和推荐、名作诵读等系列活动，鼓励和动员少年儿童积极参与，形成名家带动，学校、老师、学生、家长全员参与，后期深化的立体化、多维度阅读模式，发挥知名作家和优秀作品的引领示范作用，营造浓厚的校园阅读氛围。

（三）开展阅读指导服务。组织作家、编辑、阅读推广人等走访贫困家庭、慰问少年儿童。按照少年儿童不同年龄段的智力和心理发育特点，以及少年儿童的阅读心理和阅读规律，为不同年龄段的少年儿童提供相应的阶梯阅读指导服务，通过多元的指导方式激发少年儿童阅读乐趣，通过构建阅读交流平台培养少年儿童阅读能力。

（四）捐赠优秀少儿图书。结合实际情况，根据少年儿童的阅读特点，向对口中小学校和学生捐赠“百种优秀青少年图书”、“大众喜爱的50种图书”等主题鲜明、内容丰富、形式新颖、可读性强的优秀少儿图书，同时倡导并带动更多的社会力量共同参与捐赠活动。（参与此次活动出版单位所捐赠图书可由韬奋基金会开具完税发票）

四、组织保障

（一）加强组织协调。各省级新闻出版广电行政部门和中央出版单位主管部门要组织相关出版单位精心策划，制订详细活动方案，与各自确定联系的对口中小学校加强协调配合（每家出版单位联系的中小学校原则上不少于10所），确保读书活动扎实开展，取得实效。

（二）创新活动形式。各省级新闻出版广电行政部门和中央出版单位主管部门要立足自身特色资源，结合各地区实际情况，组织相关出版单位充分利用课外实践活动开展阅读活动，并根据少年儿童的特点，积极创新活动形式，丰富活动载体，充分调动少年儿童阅读的积极性、主动性，吸引少年儿童广泛参与。

（三）大力宣传推广。各省级新闻出版广电行政部门和中央出版单位主管部门要充分利用报刊、电视、广播、网络等媒介，加大对“百社千校”阅读活动的宣传报道力度。总局将组织书香中国网、中国全民阅读网、全民阅读百网联盟和全民阅读媒体联盟等对各地“百社千校”阅读活动进行宣传推介。
