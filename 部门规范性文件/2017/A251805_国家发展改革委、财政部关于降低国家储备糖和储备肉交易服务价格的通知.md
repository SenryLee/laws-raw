# 国家发展改革委、财政部关于降低国家储备糖和储备肉交易服务价格的通知

## 国家发展改革委　财政部关于降低国家储备糖和储备肉交易服务价格的通知

发改价格〔2017〕1163号

华商储备商品管理中心：

为贯彻落实国务院关于清理规范涉企收费工作的总体部署，进一步减轻企业负担，现就调整国家储备糖和储备肉交易服务价格事项通知如下。

一、降低国家储备糖和储备肉交易服务价格，由每吨10元调整为5元。由你中心所属北京华商储备商品交易所有限责任公司在提供国家储备糖和储备肉交易服务时，向交易成功的买卖双方分别收取。

二、请你中心严格执行调整后的国家储备糖和储备肉交易服务价格，自觉维护正常价格秩序。对违反有关价格法律法规的行为，依法严肃查处。

三、上述规定自发文之日起执行，有效期5年。此前有关规定与本通知不符的，以本通知为准。

国家发展改革委

财政部

2017年6月20日
