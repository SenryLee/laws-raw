# 中华人民共和国海关总署对全国政协十二届五次会议第3939号提案的答复

左定超委员：

您提出的《关于设立遵义新舟机场航空口岸的提案》（第3939号）收悉。经研究并商中央编办、公安部、质检总局，现答复如下：

我署作为国家口岸主管部门高度重视内陆地区外向型经济发展，积极支持在符合条件的机场设立航空口岸。根据国家口岸整体布局，我们在牵头制定《国家口岸发展“十三五”规划》（以下简称《规划》）时，已将遵义机场列入。建议地方政府按照《规划》中口岸开放审理制度，积极培育遵义新舟机场航运市场，并进一步完善口岸查检设施，待相关指标达到国家规定条件后，我们将予以启动口岸开放审批程序。

关于口岸查验单位人员编制问题，中央编办表示：2010年6月印发实施的《口岸检查检验机构设置和编制管理办法》（中央编办发〔2010〕62号），对口岸查验机构设置、人员编制管理、审批程序以及管理权限等方面做出了具体明确规定。本届政府“约法三章”，明确财政供养人员只减不增，对机构编制工作提出了新的要求。对遵义机场开放涉及的口岸查验人员编制问题，将结合省政府具体请示要求，统筹研究办理。

感谢您对我们工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2017年6月25日
