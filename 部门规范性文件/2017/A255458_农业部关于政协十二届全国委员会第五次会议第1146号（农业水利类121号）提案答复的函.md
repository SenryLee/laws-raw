# 农业部关于政协十二届全国委员会第五次会议第1146号（农业水利类121号）提案答复的函

## 关于政协十二届全国委员会第五次会议第1146号（农业水利类121号）提案答复的函

农办案〔2017〕56号

杨忠岐委员：

您提出的关于“充分发挥绿肥作用，推动用地养地结合”的提案收悉。经认真研究，现答复如下。

一、关于明确绿肥在现代农业中的地位

绿肥是我国传统的有机肥源，在提供农作物所需养分、改良土壤、改善农田生态环境和防治土壤侵蚀和污染方面具有重要的作用。上世纪70年代，我国绿肥种植面积达到1.8亿亩，其后受化肥供应增多、农村劳动力转移、种植效益偏低等因素影响，绿肥种植面积不断下滑。近年来，农业部会同有关部门，采取有力措施，推动绿肥发展。一是加大资金支持。2008年以来，农业部在中央财政的支持下，结合实施土壤有机质提升等项目，在绿肥种植适宜省区安排专项资金，引导有条件的地方种植绿肥。江苏、湖南、江西等省也出台地方性补贴政策，扶持发展绿肥生产。二是集成技术模式。各级农业部门通过建立试验示范田、召开现场观摩会等形式，集成组装绿肥生产全程机械化、玉米前期套作绿肥、稻田绿肥与稻秆联合还田等技术，基本形成了主要农区绿肥种植利用技术模式。三是推动耕地质量保护立法。农业部积极参与《土地管理法》《土壤污染防治法》《基本农田保护条例》的制修订工作，组织开展《耕地质量保护条例》立法工作，推动出台地方性耕地质量保护法规规章，将种植绿肥、增施有机肥等作为保护和提升耕地质量的重要措施，用法律法规的形式确定下来。

下一步，农业部将会同有关部门，探索建立绿肥生产长效机制，促进绿肥种植，提升耕地质量。一是争取财政支持。结合实施耕地保护与质量提升、果菜茶有机肥替代化肥试点等项目，适度扩大绿肥种植补贴规模，鼓励适宜地区扩大绿肥种植面积。二是加强应用研究。组织有关专家，开展绿肥种植利用关键技术研发。研制推广绿肥开沟、机播机收、翻压还田等机械，减轻劳动强度，提高生产效益，降低生产成本。三是强化宣传培训。采取各种形式广泛宣传绿肥的作用，培训绿肥高产配套栽培技术，提高农民对种植绿肥的认识，为规模化种植绿肥创造条件。

二、关于创新绿肥种子生产机制

目前，种子仍是绿肥生产发展的重要制约因素，传统绿肥种子基地的潜力没有充分发挥，当前生产上应用的仍是30年前甚至更久以前的品种。近年来，湖南、贵州、江西、安徽等有绿肥种植传统的省份，开展紫云英、苕子、箭筈豌豆等绿肥品种的留种基地建设。湖南省安排专项资金支持绿肥良种繁育体系建设；贵州省计划建设绿肥留种基地20万亩，生产能力2400万公斤，建成后能满足600万亩耕地专用绿肥用种的需要。

下一步，农业部将根据绿肥发展布局，加大资金投入，引导社会资本参与，加快建设一批绿肥良种繁育基地。同时，加强绿肥种质资源保护与提纯复壮，解决绿肥品种种性混杂退化、产草量下降等问题，为发展绿肥生产提供支撑。

三、关于推行购买绿肥种植服务

中央高度重视农业补贴政策的有效实施，明确要求在稳定加大农业补贴力度的同时，逐步完善农业补贴政策，改进农业补贴方法，提高农业补贴政策效能。2016年，财政部会同农业部等部门印发了《关于全面推开农业“三项补贴”改革工作的通知》（财农〔2016〕26号，以下简称《通知》），全面推开农业“三项补贴”改革。《通知》明确相关补贴资金，支持对象重点向种粮大户、家庭农场、农民合作社和农业社会化服务组织等新型经营主体倾斜。同时，鼓励各地创新支持方式，采取贷款贴息、重大技术推广与服务补助等方式支持新型经营主体发展。绿肥种植补贴是农业生产性补贴的重要内容，在完善调整相关补贴政策的过程中，将继续对绿肥种植的公益性环节予以支持。同时，探索通过物化补助、政府购买服务等方式对农民种植绿肥予以补贴。

下一步，农业部将会同财政部等部门，在总结农业“三项补贴”改革经验的基础上，继续完善包括绿肥种植补贴在内的农业补贴政策。充分发挥社会化服务组织的技术优势和装备条件，采取政府购买服务等方式，促进绿肥发展。

四、关于稳定绿肥科研推广队伍

“十一五”以来，农业部先后启动实施了2项国家绿肥行业专项支持绿肥科研推广。2008年，启动公益性行业（农业）科研专项经费“绿肥作物生产与利用技术集成研究及示范”项目，累计安排科研经费5342万元，开展绿肥合理种植模式及综合管理技术研究与集成，推动绿肥品种资源的保存整理和培育创新。“十三五”期间，农业部加大对现代农业产业技术体系支持力度，每年安排16亿元资金，支持50个产业体系的科学家开展协同创新。2017年，农业部将绿肥纳入现代农业产业技术体系，聘任岗位科学家24人，建设绿肥综合试验站18个。这些工作的开展，有力推动了我国绿肥科研和产业的恢复性发展。

下一步，农业部将会同有关部门，围绕绿肥产业发展需求，依托绿肥产业技术体系开展共性技术和关键技术研究，组织教学、科学、推广部门和相关企业开展绿肥生产技术集成和示范，推进产学研结合，不断提升绿肥产业创新能力。

感谢您对绿肥生产的关心，希望今后继续对农业部工作予以支持。

农业部

2017年9月1日
