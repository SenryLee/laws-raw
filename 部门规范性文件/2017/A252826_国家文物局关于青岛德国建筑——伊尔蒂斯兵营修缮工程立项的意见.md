# 国家文物局关于青岛德国建筑——伊尔蒂斯兵营修缮工程立项的意见

## 关于青岛德国建筑——伊尔蒂斯兵营修缮工程立项的意见

办保函〔2017〕485号

山东省文物局：

你局《关于青岛德国建筑——伊尔蒂斯兵营保护修缮工程立项的请示》（鲁文发〔2017〕18号）收悉。经研究，我局意见如下：

一、暂不同意青岛德国建筑——伊尔蒂斯兵营修缮工程立项。

二、工程立项报告应从以下方面进行修改完善：

（一）严格控制工程范围和工程量，明确修缮标准，应当以确保文物安全、排除安全隐患为修缮目的。

（二）加强文物建筑现状勘察，应对建筑结构稳定性进行详细勘察，对混凝土等材质进行强度分析。补充文物建筑的历史维修与使用情况。

（三）院落整治、排水设施等内容应予以统筹考虑。

（四）进一步完善图纸，补充该兵营1号楼、2号楼、4号楼、7号楼总平面图。

（五）结合实际残损量和维修工程量，进一步细化工程经费的取费依据，核减工程经费预算。

三、请你局组织相关单位对立项报告进行修改完善后，并按《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的要求另行报批。

国家文物局

2017年4月19日
