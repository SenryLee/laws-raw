# 公开市场业务交易公告[2017]第207号——关于人民银行于2017年10月31日以利率招标方式开展了3000亿元逆回购操作的公告

## 公开市场业务交易公告

[2017]第207号

人民银行于2017年10月31日以利率招标方式开展了3000亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 1400亿元 | 2.45% |
| 14天 | 600亿元 | 2.60% |
| 63天 | 1000亿元 | 2.90% |

中国人民银行公开市场业务操作室

二〇一七年十月三十一日
