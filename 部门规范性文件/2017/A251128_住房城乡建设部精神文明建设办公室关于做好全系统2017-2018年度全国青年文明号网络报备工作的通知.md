# 住房城乡建设部精神文明建设办公室关于做好全系统2017-2018年度全国青年文明号网络报备工作的通知

建精办〔2017〕3号

各省、自治区住房城乡建设厅文明办，北京市住房城乡建设委、规划国土委、城市管理委、水务局、园林绿化局、城管执法局、住房公积金管理中心、公园管理中心文明办，天津市城乡建设委、市容园林管理委、国土房管局、水务局、规划局文明办，上海市建设交通党委、规划国土管理局，重庆市城乡建设委、市政管理委、规划局、国土房管局、园林局文明办，新疆生产建设兵团建设局文明办，中建总公司政工部：

根据团中央《关于开展“2017-2018年度全国青年文明号”创建工作的通知》要求，现将住房城乡建设系统全国青年文明号网络报备工作有关事项通知如下：

一、报备条件

凡拟参评住房城乡建设系统2017-2018年度全国青年文明号的集体需符合《青年文明号管理办法》中规定的集体基本条件。集体需于2017年9月31日前曾获全国青年文明号命名，或最近一届的省级青年文明号命名或复核认定。

二、网络报备

全国青年文明号网络报备工作依据《青年文明号活动管理办法》和《住房城乡建设系统全国青年文明号各级管理员、青年集体编码规则说明》（2011年印发），在青年文明号在线网站（http://www.qnwmh.org:8017）操作执行。

已参加2015-2016年度全国青年文明号网络报备集体的报备：按照上次报备编码，登录青年文明号在线网站网络办公系统，进入青年文明号网络办公协同系统，修改完善集体信息并提交报批，由三级管理员（地市级）、二级管理员（省级）逐级核对把关，最后经一级管理员（部文明办）审核后，纳入2017-2018年度全国青年文明号创建集体。

新参加网络报备集体的报备：创建集体向二级或三级管理员提出创建申请，由管理员对其创建资格进行初审后，登录网络系统选择“青年文明号数据”，进入“全国青年文明号”平台的“新建集体”页面，点击“新增”后，按要求填写相关内容，集体在获取用户名（编码）后，即可登录青年文明号在线网站根据系统提示，填写相关信息后，点击提交报批。

三、工作要求

（一）要认真组织。各地住房城乡建设系统全国青年文明号网络报备工作由各省住房城乡建设部门文明办负责组织；中建总公司所属青年文明号网络报备工作由中建总公司政工部负责组织。2017-2018年度全国青年文明号表彰名额，将依据本次报备数量进行分配。报备中，往届全国青年文明号应有一定比例。编码填写有误，填写虚假信息，均不能参加评选推荐。

（二）要按时完成。各省级住建部门文明办要组织拟参评2017-2018年度全国青年文明号务必于9月1日前完成网络报备，并将本系统往届全国青年文明号和新命名省级青年文明号名单报部文明办。此后报备的青年文明号集体，部文明办不再受理，并不得参评本届次全国青年文明号评选。

（三）要加强维护。请各级管理员设立创建台账，掌握所管创建集体编码情况，督促指导创建集体应用全国青年文明号网络办公协同系统，维护好基本数据，及时录入集体创建空间有关栏目，真实全面反映创建过程。未录入工作信息的创建集体，将被视为创建过程缺失，不能参评2017-2018年度全国青年文明号。

附件：全国青年文明号网络报备操作说明

住房城乡建设部文明办
