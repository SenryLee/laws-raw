# 国家新闻出版广电总局正式公布第二批认定学术期刊名单

新出报刊司〔2017〕196号

根据新闻出版广电总局《关于开展第二批学术期刊认定及清理工作的通知》（新广出办发〔2016〕32号），总局2016年开展了第二批学术期刊认定及清理工作，现将认定的第二批学术期刊名单正式予以公布（具体见附件）。

附件：国家新闻出版广电总局认定的第二批学术期刊名单

国家新闻出版广电总局

新闻报刊司

2017年4月10日
