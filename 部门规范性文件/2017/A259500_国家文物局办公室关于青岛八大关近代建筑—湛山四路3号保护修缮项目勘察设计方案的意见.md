# 国家文物局办公室关于青岛八大关近代建筑—湛山四路3号保护修缮项目勘察设计方案的意见

办保函〔2017〕1443号

山东省文物局：

你局《关于呈报青岛八大关近代建筑—湛山四路3号保护修缮工程勘察设计方案的请示》（鲁文发〔2017〕99号）收悉。经研究，我局意见如下：

一、应深化现状勘察，明确病害，补充建筑残损部位和残损量描述；补充勘察建筑梁架结构、地板、外墙面涂料；补充结构鉴定屋架检测。

二、明确保护措施，补充砖瓦规格及砌筑、抹灰工艺做法。

三、在建筑图中明确墙体节点加固图对应位置；补充钢筋网加固墙体的必要性说明；明确墙体裂缝压力灌浆部位及具体工艺，补充实施压力灌浆的必要性说明。

四、进一步修改完善设计图纸。补充完善剖面图、现状测绘图、平面图、装修大样图等相关图纸。

五、请你局指导有关单位根据上述意见修改、完善方案，并根据我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）要求，按程序报批。

专此函复。

国家文物局办公室

2017年12月27日
