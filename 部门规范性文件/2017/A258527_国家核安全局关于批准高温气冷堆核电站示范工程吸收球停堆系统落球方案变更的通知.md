# 国家核安全局关于批准高温气冷堆核电站示范工程吸收球停堆系统落球方案变更的通知

## 关于批准高温气冷堆核电站示范工程吸收球停堆系统落球方案变更的通知

国核安发〔2017〕300号

华能山东石岛湾核电有限公司:

你公司《关于变更HTR-PM吸收球停堆系统落球方案的请示》（华能石核安〔2017〕180号）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》等相关法规的要求，我局对你公司提交的文件进行了审评，认为高温气冷堆核电站示范工程吸收球停堆系统由落球装置失电自动落球变更为通过步进电机打开落球孔的落球方案安全上可以接受，现予以批准。

你公司应按照上报的设计变更方案及审评过程中所作的承诺开展施工和试验验证活动，并将设计变更情况体现在最终安全分析报告中。

国家核安全局

2017年12月1日
