# 农业部关于政协十二届全国委员会第五次会议第2417号（农业水利226号）提案答复的函

## 关于政协十二届全国委员会第五次会议第2417号（农业水利226号）提案答复的函

您提出的“关于支持和鼓励年轻人返乡下乡就业创业 推进农业供给侧结构性改革的提案”收悉。经商教育部、民政部和人力资源社会保障部，现答复如下。

一、关于创新支持和鼓励年轻人返乡下乡就业创业机制

2016年，国务院办公厅印发《关于支持返乡下乡人员创业创新促进农村一二三产业融合发展的意见》（国办发〔2016〕84号，以下简称国办《意见》），农业部积极会同有关部门，加大协调力度，推动政策落实，农村创业创新工作取得积极进展和成效。一是对返乡下乡人员创业创新提出了更为系统、更为全面、针对性更强的政策支持，从市场准入、金融服务、财政支持、用地用电、创业培训、社会保障、技术支持和创业园区等八个方面推动返乡下乡人员创业创新，现有的各项涉农政策也都向返乡下乡人员延伸和覆盖，支持对象不仅包括农民工、中高等院校毕业生、退役士兵和科技人员，还有企业主、归国留学人员和城镇人员，这样有利于建立城乡要素平等交换的关系，进一步拓展资金、技术、人才流向农村的渠道。二是按照国办《意见》要求，农业部发挥牵头作用，与国家发展改革委等12个部门建立了农村创业创新推进协调机制，各部委之间加强工作交流和经验推广，推动省一级建立推进协调机制，明确部门分工，形成合力，让政策真正落地见效。三是农业部牵头实施推进农民创业创新行动计划；联合国家发展改革委等6部门实施开发农业农村资源支持返乡创业行动计划；联合共青团中央、人力资源社会保障部推进农村青年创业富民行动；联合教育部、共青团中央实施现代农村青年农场主计划。通过一系列培训活动，帮助他们转变发展理念，提高生产经营水平，增强创业兴业、致富带富的本领。四是教育部指导各地从农村致富带头人、退伍军人、回乡大中专毕业生、外出务工经商人员等人员中培养选拔优秀年轻干部参与到农村基层管理中，不断优化农村基层干部结构，培养新一代农村农业“接班人”。

二、关于为年轻人返乡下乡就业创业提供更多更好的就业创业平台和空间

近年来，一大批返乡下乡青年到农村去创新创业，成为现代农业和新农村建设的生力军。2017年，农业部公布了1096个依法合规、功能完备、辐射带动能力较强、产业融合发展趋势明显的全国农村创业创新园区（基地）目录，为年轻人返乡下乡创业创新提供可选择的场所和高效便捷的服务。同时，强化政策集成，将国办《意见》提出的“八个政策大礼包”和农村产业融合政策，向园区整合，吸引地方政府、金融机构和社会资本向园区投资。引导年轻人顺应农村经营体制改革创新的大方向，通过联合与合作的方式开展创业创新；在组织形式和经营方式上，可以与农民合作，创办、领办农村合作组织，通过承包、租赁、入股等方式，不仅要自己富起来，也要带动更多农民富起来。民政部加快农村社区公共服务综合信息平台建设，积极推进社区信息化应用能力，结合信息进村入户和电子商务进农村，积极发展新型农业经营和农产品销售等服务项目，为年轻人返乡下乡创业就业提供良好的创业平台和氛围。

下一步，农业部联合其他部门继续实施好农村产业融合发展项目，支持发展农产品加工流通和直供直销、农村电子商务、农业多功能性拓展、产业扶贫等项目，支持能够让农民分享二三产业增值收益的经营主体；继续深入开展农村社区建设试点工作，加强农村社区综合服务设施建设，引导政府基本公共服务逐步向农村延伸，为各类人才在农村创业就业提供便利和良好平台。

三、关于充分发挥高等学校在支持、鼓励和引导年轻人返乡下乡就业创业，推进农业供给侧结构性改革中的作用

农业部着力加强农民教育培训体系建设，目前已在全国建立了30个部级农村实用人才培训基地，形成了全国农村实用人才培训网络。联合人力资源社会保障部等部门印发《关于实施农民等人员返乡创业培训五年行动计划（2016—2020年）的通知》（人社厅发〔2016〕90号），力争使有创业要求和培训愿望、具备一定创业条件或已创业的农民工等人员都能参加一次创业培训，有效提升创业能力。下一步，将继续发挥各级农业广播电视学校、涉农院校、科研推广机构、企业社会组织的优势，充分利用现有培训机构、资源网络、远程教育服务等平台，结合新型职业农民、农村实用人才带头人、职业技能等培训计划，培养农业高技能人才，构建现代农业生产经营者队伍。

教育部印发《关于做好2017届全国普通高等学校毕业生就业创业工作的通知》（教学〔2016〕11号）和《关于贯彻落实中央文件精神进一步引导和鼓励高校毕业生到基层工作的通知》（教学〔2017〕3号），鼓励高校毕业生回乡就业创业。一是鼓励毕业生到城乡社区从事教育文化、医疗卫生、健康养老等工作，鼓励毕业生到农村投身扶贫开发、技术推广、电子商务等事业。二是继续配合有关部门组织实施好“教师特岗计划”“大学生村官”“三支一扶”“西部计划”等中央基层就业项目，鼓励各地巩固并扩大实施地方基层就业项目。三是加强思想教育和宣传，广泛宣传国家鼓励毕业生到基层就业创业的政策，引导毕业生到农村创业创新。

感谢您对农村创业创新工作的关心，希望今后继续支持我部工作。

农业部

2017年9月15日
