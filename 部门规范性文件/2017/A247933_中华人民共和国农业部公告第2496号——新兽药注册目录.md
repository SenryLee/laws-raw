# 中华人民共和国农业部公告第2496号——新兽药注册目录

## 中华人民共和国农业部公告

第2496号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准南京农业大学等3家单位申报的猪圆环病毒2型阻断ELISA抗体检测试剂盒等2种产品为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

批准驻马店华中正大有限公司等7家单位申报的土霉素钙预混剂等3种兽药产品变更注册。其中土霉素钙预混剂和复方氯硝柳胺片的质量标准、说明书和标签分别按照农业部公告第2328号、1584号同品种规定执行。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年2月13日
