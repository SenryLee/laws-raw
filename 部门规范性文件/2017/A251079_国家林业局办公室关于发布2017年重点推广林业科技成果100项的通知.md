# 国家林业局办公室关于发布2017年重点推广林业科技成果100项的通知

办科字〔2017〕37号

各省、自治区、直辖市林业厅（局），内蒙古、吉林、龙江、大兴安岭森工（林业）集团公司，新疆生产建设兵团林业局，国家林业局各有关直属单位：

为贯彻落实《中华人民共和国促进科技成果转化法》和《国务院办公厅关于印发促进科技成果转移转化行动方案的通知》（国办发〔2016〕28号）精神，加快林业科技成果转化，促进先进科学技术在生产中的推广应用，我局围绕生态建设、产业发展、林业扶贫等重点工作对技术的需求，筛选出2017年重点推广林业科技成果100项（详见附件），现予发布。

请各地区各单位根据当地林业生产建设实际需求，加快推动100项重点林业科技成果的转化应用，并在中央财政林业科技示范推广、地方各类推广计划、产业发展专项、科技扶贫等方面予以重点应用。成果相关信息可登录“国家林业科技推广成果库管理信息系统”网站（http://113.6.251.102:800/）进行查询。

特此通知。
