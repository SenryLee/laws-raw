# 司法部关于批准美国吴异军律师事务所变更中文名称的通知

司发通〔2017〕123号

天津市司法局：

《关于对美国吴异军律师事务所申请更名材料审查情况的报告》收悉。经审核，我部同意美国吴异军律师事务所驻天津代表处(WU & KAO PLLC TIANJIN REPRESENTATIVE OFFICE(USA))中文名称变更为“美国达凯律师事务所驻天津代表处”。

请予办理变更手续。

司法部

2017年11月24日
