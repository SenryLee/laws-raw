# 中华人民共和国海关总署对全国政协十二届五次会议第4144号提案的答复

魏艺红委员：

您提出的《关于给予批准中国云南省勐康口岸扩大开放为国际性公路客货运输口岸的提案》（第4144号）收悉。经研究并商外交部，现将有关意见函告如下：

我署作为国家口岸主管部门高度重视并积极支持云南边境少数民族地区口岸建设和发展工作，充分理解地方政府提升口岸开放程度的需求。2011年7月国务院根据云南省政府的申请批准勐康公路口岸对外开放，口岸性质为双边公路客货运输口岸，同年8月中老两国政府签署了《关于边境口岸及其管理制度的协定》，明确勐康—兰堆口岸为国际性客货公路口岸，双方将在条件具备时通过外交途径商定开放时间。

勐康口岸自2011年对外开放以来，为地方外向型经济的发展起到了积极促进作用。2016年10月，在中老两国外交部牵头召开的中老边界联委会第十四次会议上，双方一致同意研究推动勐康—兰堆公路口岸升格为国际性口岸，同月云南省人民政府也正式向国务院提出勐康口岸扩大开放的请示，国务院已转我署办理。目前我署正在按程序商国家相关部门研究审理。

感谢您对我们工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2017年6月19日
