# 中共水利部直属机关委员会关于规范党员干部网络行为的倡议

## 关于规范党员干部网络行为的倡议

网络行为是党员干部言行的重要组成部分。为充分发挥党员干部的模范带头作用，走好网上群众路线，规范网络行为，形成健康向上、风清气正的网络环境，水利部直属机关党委向全体党员干部发出如下倡议：

一、严守政治纪律和政治规矩。牢固树立政治意识、大局意识、核心意识、看齐意识，坚决维护党中央权威，在思想上政治上行动上始终同以习近平同志为核心的党中央保持高度一致。严格遵守党规党纪，模范遵守国家法律法规，在网络行为中坚持正确政治方向，自觉宣传党的理论和路线方针政策，积极践行社会主义核心价值观，传播正能量、弘扬主旋律，共筑网上网下同心圆。

二、坚决抵制以下网络传播行为：发表违背党的基本路线，否定四项基本原则，歪曲党的政策，或者其他有严重政治问题的文章、演说、宣言、声明等；妄议中央大政方针，破坏党的集中统一；丑化党和国家形象，诋毁、污蔑党和国家领导人，歪曲党史、国史、军史，抹黑革命先烈和英雄模范；制造、传播各类谣言特别是政治类谣言，散步所谓“内部”消息或小道消息；出版、购买、传播非法出版物；宣扬封建迷信、淫秽色情；制作、传播其他有严重问题的文章、言论、音视频等信息内容。

三、不得参加以下网络活动：组织、参加反对党的理论和路线方针政策的网络论坛、群组、直播等活动；通过网络组党结社，参与和动员不法串联、联署、集会等网上非法组织、非法活动；参与网上宗教活动、邪教活动，纵容和支持宗教极端势力、民族分裂势力、暴力恐怖势力及其活动；利用网络泄露党和国家秘密；浏览、访问非法和反动网站等。

四、严格规范以职务身份注册网络账号行为。以职务身份在微博、微信、网络直播、论坛社区等境内外网络平台上注册账号、建立群组的，应当向所在党组织报告。

五、认真履行举报监督义务。发现网上违法违规违纪信息、活动的，要及时主动向有关部门、网络平台等举报，积极提供线索，协助有关方面处置。

倡导文明新风，净化网络环境，促进和谐稳定，是我们共同的责任。对在网络活动中以身作则、表现突出的党员干部，要充分肯定、热情鼓励；对坚持正确立场、传播正能量而遭受围攻的党员干部，要旗帜鲜明地给予保护和支持；对违反规定的，要依据党纪和国家法规进行严肃查处。让我们从现在做起、从自己做起、从点滴做起，坚持文明上网，携手共建绿色网络空间，为加快水利改革发展作出新的更大贡献，以良好的网络舆论氛围迎接党的十九大胜利召开！

中共水利部直属机关委员会

2017年6月7日
