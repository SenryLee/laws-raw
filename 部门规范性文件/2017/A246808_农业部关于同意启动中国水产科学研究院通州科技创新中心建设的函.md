# 农业部关于同意启动中国水产科学研究院通州科技创新中心建设的函

农计函〔2017〕3号

中国水产科学研究院：

《关于征地建设中国水产科学研究院通州科技创新中心的请示》（水科基函〔2016〕306号）收悉。函复如下：

为开展前瞻性战略谋划和布局，打破学科界限，优化资源配置，打造国家现代农业创新平台,解决京区现有科研设施不足等问题。经研究，同意你院会同中国农业科学院在北京市通州区于家务乡建设农业科技创新中心，你院征用建设用地203.4亩，总建筑规模控制在15万平方米。“十三五”期间，优先启动农业部水产品质量安全研究中心、渔业工程装备研究中心、国家渔业科技数据中心、国家渔业生物技术研究中心、国家渔业资源环境监测中心等科技基础设施平台建设。项目建设投资和土地征用费通过中央预算内投资和自筹资金解决。

请抓紧与北京市有关部门衔接沟通，加快推进科技创新中心前期工作。

农业部

2017年1月22日
