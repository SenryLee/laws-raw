# 国家文物局办公室关于老司城遗址小德政碑及附属遗迹抢救性保护项目设计方案的意见

办保函〔2017〕1114号

湖南省文物局：

你局《关于审批〈老司城遗址小德政碑及附属遗迹抢救性保护方案〉的请示》（湘文物报〔116〕号）收悉。经研究，我局意见如下：

一、所报老司城遗址小德政碑及附属遗迹保护项目拟采取的保护措施不属于抢救性保护范畴，我局暂不同意所报方案。

二、所报方案尚需做以下必要的修改和完善：

（一）小德政碑底部断裂修复、碑体空鼓、剥落及裂隙部位加固均应采用性能匹配、强度适当的无机材料,并做好碑体基础加固和防蠕滑处理。

（二）外闪倾斜影壁扶正应在现有技术措施的基础上，辅以地基同步支顶，确保文物安全。

（三）碑刻表面保护处理、脱盐及微生物防治应尽量采用物理手段，确需采用化学手段的，应开展必要的前期实验，合理确定所用材料，增强适用性。

（四）应适当加大保护棚顶部排水坡度，建议坡度不小于5%。

三、请你局根据上述意见，对所报方案做进一步修改和完善，并按照我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的要求，纳入下一年度的工作计划统筹考虑。

四、请你局指导地方人民政府，组织做好老司城遗址小德政碑及附属遗迹的临时性保护，确保文物安全。

国家文物局办公室

2017年9月26日
