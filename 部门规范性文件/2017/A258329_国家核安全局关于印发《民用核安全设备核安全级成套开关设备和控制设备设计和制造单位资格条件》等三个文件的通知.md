# 国家核安全局关于印发《民用核安全设备核安全级成套开关设备和控制设备设计和制造单位资格条件》等三个文件的通知

## 关于印发《民用核安全设备核安全级成套开关设备和控制设备设计和制造单位资格条件》等三个文件的通知

国核安发〔2017〕295号

各有关单位：

根据《民用核安全设备监督管理条例》和《民用核安全设备设计制造安装和无损检验监督管理规定》（HAF601）的规定，我部组织制订了《民用核安全设备核安全级成套开关设备和控制设备设计和制造单位资格条件》等三个文件，现予以发布，并于发布之日起施行。

附件：1.民用核安全设备核安全级成套开关设备和控制设备设计和制造单位资格条件

2.民用核安全设备核安全1、2、3级阀门设计和制造单位资格条件

3.民用核安全设备核安全1、2、3级管道制造单位资格条件

国家核安全局

2017年11月28日
