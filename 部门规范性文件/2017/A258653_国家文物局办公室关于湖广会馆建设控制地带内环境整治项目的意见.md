# 国家文物局办公室关于湖广会馆建设控制地带内环境整治项目的意见

办保函〔2017〕1351号

重庆市文物局：

你局《关于湖广会馆建设控制地带内环境整治项目设计方案的请示》（渝文物保〔2017〕277号）收悉。经研究，我局意见如下：

一、该方案未根据《国家文物局办公室关于在湖广会馆保护范围和建设控制地带内进行环境整治项目的意见》（办保函〔2017〕924号）进行实质性修改，暂不同意所报方案。

二、具体修改意见如下：

（一）应明确环境整治定位，有效保护空间肌理。进一步深化现状调查，补充完善设计范围内的现有建筑建造年代、形制、高度及街巷格局等相关信息。

（二）进一步调整、细化设计方案，确保整治措施与湖广会馆的保护要求相匹配，并切实保证设计文本与图纸的前后对应。

三、请你局指导有关单位，落实《国家文物局办公室关于在湖广会馆保护范围和建设控制地带内进行环境整治项目的意见》（办保函〔2017〕924号）的相关要求，并按照上述意见对所报方案进行修改、完善后另行报批。

国家文物局办公室

2017年12月11日
