# 国家文物局关于挹江门段南京城墙保护范围及建设控制地带内南京地铁5号线工程的意见

文物保函〔2017〕1691号

江苏省文物局：

你局《关于审批南京地铁5号线下穿挹江门南京城墙保护范围及建设控制地带方案的请示》（苏文物保〔2017〕153号）收悉。经研究，我局意见如下：

一、原则同意所报挹江门段南京城墙保护范围及建设控制地带内南京地铁5号线工程和你局意见。

二、对所报方案提出具体修改意见如下：

（一）应补充针对挹江门建筑基础的考古勘探数据，作为必要的计算依据。应进一步加大监测密度和频率，并尽可能增大埋深、扩大与文物本体的空间距离，优化风险防控预案，以确保文物建筑的安全。

（二）应根据岩土层的物理力学性质及均匀性和文物本体对变形的敏感性，校核和控制隧道开挖过程中地表及文物本体变形量，合理确定盾构掘进的施工参数、质量标准和技术要求，正确设定平衡压力和推进速度，减少超挖与欠挖现象，控制好盾构姿态，加强同步和二次注浆，控制好注浆量和注浆压力。

（三）应采取措施防止盾构掘进过程中地下水位下降引起的地表及文物本体的变形，特别应针对在挹江门附近穿越②-4b3+4 流塑状态的淤泥质粉质粘土地层的施工，制定专项施工技术措施，消除施工中影响文物安全的隐患。

（四）应补充报告引用附件《南京地铁3 号线沿线古建筑振动影响测试报告》中计算采用的列车运行时速和实测振动时的列车运行时速，建议充分考虑地铁列车提速的实际需求因素对文物的不利影响。

（五）加强施工管理和监督，严格按相关规范施工，在隧道开挖过程中，一旦施工条件发生变化或发现安全隐患，须停止开挖，及时处理，控制风险，必要时可对文物本体采取预加固措施。

（六）建立运营期间的长期监测系统，及时监测、定期评估长期地铁运营震动对文物的影响，并根据监测、评估结论采取针对性保护措施。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《文物保护法》第17条、18条的有关规定分别报江苏省人民政府、城乡建设规划部门批准后实施。请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

四、地铁出入口等地面建筑如涉及文物保护范围和建设控制地带的，应根据文物保护单位级别，依法另行履行相应报批手续。

国家文物局

2017年9月26日
