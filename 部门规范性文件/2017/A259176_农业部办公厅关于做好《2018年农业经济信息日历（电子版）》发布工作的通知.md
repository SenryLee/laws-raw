# 农业部办公厅关于做好《2018年农业经济信息日历（电子版）》发布工作的通知

农办市〔2017〕35号

各有关司局：

为贯彻落实中央《关于推进公共信息资源开放的若干意见》文件精神，落实部党组关于加强政府信息公开、加快推进农业市场监测预警体系建设的总体要求，进一步推进我部公共信息资源开放，释放经济价值和社会效应，在总结近两年发布《农业经济信息日历（电子版）》（见附件）做法和经验的基础上，按照《推进农业公共信息资源开放工作方案》的安排部署，市场与经济信息司会同有关司局制定了《2018年农业经济信息日历（电子版）》。从2018年开始，经济信息日历将在重点农产品市场信息平台上发布，请各有关单位及时、准确、全面地提供相关信息发布内容，进一步发挥农业信息在指导生产、引导市场和支持决策的重要作用。

在执行过程中，如有突发情况，请提前与市场与经济信息司联系，以便根据具体情况对信息发布的时间、内容等进行调整。

联系人：市场与经济信息司 刘福江

联系电话：010-59191561
