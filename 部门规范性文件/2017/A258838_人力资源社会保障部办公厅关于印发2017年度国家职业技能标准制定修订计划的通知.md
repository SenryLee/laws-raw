# 人力资源社会保障部办公厅关于印发2017年度国家职业技能标准制定修订计划的通知

人社厅函〔2017〕306号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局），国务院有关部门、有关行业组织人事劳动保障工作机构：

为做好国家职业资格目录实施工作，加强职业技能培训，我部拟组织国家职业技能标准制定修订工作。根据有关单位申请，我们编制了2017年度国家职业技能标准制定修订计划，现印发给你们。

请各有关单位抓紧启动标准制定修订工作，按照《国家职业技能标准编制技术规程》要求认真组织编写，于2018年6月底前完成。

附件：2017年度国家职业技能标准制定修订计划表
