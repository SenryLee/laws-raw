# 环境保护部关于同意国家环境保护环境影响评价数值模拟重点实验室通过验收的通知

## 关于同意国家环境保护环境影响评价数值模拟重点实验室通过验收的通知

环科技函[2017]97号

环境保护部环境工程评估中心：

按照《国家环境保护重点实验室管理办法》（环发〔2004〕138号）有关规定，你中心向我部报送了《国家环境保护环境影响评价数值模拟重点实验室建设总结报告》。2017年4月，我部对依托你中心建设的国家环境保护环境影响评价数值模拟重点实验室（以下简称实验室）进行了验收。

我部认为，实验室完成了《国家环境保护环境影响评价数值模拟重点实验室建设计划任务书》确定的建设任务。建设期内，实验室围绕环评导则重构、大数据建设、环境管理开展了大量研究，在环境影响评价法规模型与标准化、环境影响数值模拟技术与应用、污染源排放清单建设与应用、环境影响评价基础数据库建设与应用等方面取得了一批创新性的科研成果，引进和培养了多名技术骨干，为我国环评管理提供了有效的科技支撑。同时，实验室软硬件设施进一步完善，管理制度不断健全，形成了结构合理、稳定高效的科研团队，建立了“开放、流动、联合、竞争”的运行机制，达到了验收要求。经研究，我部同意实验室通过验收。

请你中心按照《国家环境保护重点实验室管理办法》的有关规定，在现有工作基础上，围绕国家环境保护重点任务，进一步集聚人才，加强与有关单位的科研合作，注重科学研究与环境管理的结合，更好地为国家环评管理与决策等工作提供支撑。

附件：重点实验室名称、主任和依托单位

环境保护部
