# 国家核安全局关于向成都中核高通同位素股份有限公司颁发用于运输的26种特殊形式放射性物品设计批准书的通知

## 关于向成都中核高通同位素股份有限公司颁发用于运输的26种特殊形式放射性物品设计批准书的通知

国核安发〔2017〕304号

成都中核高通同位素股份有限公司:

你公司《关于特殊形式放射性物品设计批准书取证申请的请示》（高通发〔2017〕42号）收悉。

根据《放射性物品运输安全管理条例》及其配套规章《放射性物品运输安全许可管理办法》的有关要求，我局审查了你公司提交的相关申请文件。你公司设计的用于运输的26种特殊形式放射性物品满足我国相关法规和标准的有关要求，决定向你公司颁发用于运输的26种特殊形式放射性物品设计批准书，内容如下：

一、法定代表人：范国民。

二、单位住所：成都市二环路南三段25号2栋3层6号。

三、设计批准编号、放射性内容物特性及设计说明见附件。

四、特殊形式放射性物品的包容系统为运输容器包容系统的组成部分，特殊形式放射性物品应装入满足放射性物品运输安全标准要求的运输容器方可运输。

五、有效期至：2022年11月30日。

六、本批准书不免除托运人遵守货包途经或抵达国政府任何要求的责任。本批准书不免除托运人遵守有关运输法规要求的责任。

附件：特殊形式放射性物品设计批准编号、放射性内容物特性及设计说明

国家核安全局

2017年12月5日
