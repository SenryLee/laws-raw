# 国家文物局关于在中漳伏羲庙保护范围和建设控制地带内进行文物保护设施建设项目的意见

文物保函〔2017〕1335号

山西省文物局：

你局《关于审批长子县中漳伏羲庙文物保护建设项目设计方案的请示》（晋文物〔2017〕124号）收悉。经研究，我局意见如下：

一、原则同意在中漳伏羲庙保护范围和建设控制地带内进行文物保护设施建设项目和你局意见。

二、对所报修改后的方案提出如下修改意见：

（一）该工程位于全国重点文物保护单位中漳伏羲庙保护范围和建设控制地带内，应严格遵守《中华人民共和国文物保护法》和山西省人民政府关于中漳伏羲庙保护区划的相关管理规定，严格控制工程范围（仅限于拆除民居建筑、处理周边垃圾、新建管理用房与厕所、道路硬化及绿化、给排水与电力设施改造）和工程强度，尽量减少施工建设对文物本体和景观环境的影响，确保文物安全。

（二）加强现状勘查和研究，明确中漳伏羲庙2015 年修缮工程情况和效果，补充现状照片。

（三）应进一步优化方案设计，管理用房和公厕建议采用当地传统民居建筑形式、做法，尽量保留历史环境特征。道路宽度应适度，适当压缩寺前广场绿化面积。不同意大量填方，改变院落地形高差，造成历史环境特征改变。避免过度人工化和现代景观园林化设计倾向。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，根据《中华人民共和国文物保护法》第17条、18条的有关规定分别报山西省人民政府和城乡建设规划部门批准后实施。施工中请加强工程监管，确保文物及历史环境安全。

国家文物局

2017年8月4日
