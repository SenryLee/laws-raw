# 国家发展改革委办公厅关于成立张家口市可再生能源示范区专家咨询委员会的通知

发改办高技〔2017〕1309号

科技部、财政部、国土资源部、国家能源局、中国科学院办公厅（综合司），北京市、天津市、河北省人民政府办公厅、发展改革委，张家口市人民政府，国家电网公司：

为贯彻落实国务院批复精神，加快推进河北省张家口市可再生能源示范区建设，确保完成规划部署的各项目标任务，经示范区建设协调推进工作组研究决定成立张家口市可再生能源示范区专家咨询委员会。现就有关事项通知如下：

一、专家咨询委员会主要职责。开展重大事项决策咨询；调查研究重大问题和重要政策并提出意见建议；跟踪和研究国内外可再生能源发展方向并提出意见建议；提出可再生能源领域国际交流与合作建议；承担其他专题咨询任务等。专家咨询委员会下设秘书处，具体负责专家咨询委员会的联络、组织和协调工作。

二、专家咨询委员会名单。

（一）名誉主任， 全国人大常委会原副委员长、两院院士路甬祥。

（二）主任委员，中科院副院长、中科院院士张涛。副主任委员，中国可再生能源学会理事长、北京化工大学校长、工程院院士谭天伟，清华大学建筑节能研究中心主任、工程院院士江亿，国家发展改革委能源所副所长王仲颖。

（三）委员共14名，国务院原参事、中国可再生能源学会原主任石定寰，华北电力大学校长、国家能源专家咨询委员会委员杨勇平，中科院工程热物理所研究员、中科院院士金红光，中科院大连化学物理所研究员、中科院院士李灿，中国人民银行研究局首席经济学家、中国金融学会绿色金融专业委员会主任马骏，国家电网公司能源研究院院长张运洲，中科院大连化学物理所研究员XXX民，中科院工程热物理所副所长陈海生，中科院电工所研究员许洪华，中科院广州能源所所长马隆龙，中科院电工所研究员王志峰，中国可再生能源学会风能专业委员会秘书长、鉴衡认证中心主任秦海岩，世界可再生能源理事会主席、前欧盟委员会委员Wolfgang Palz，花旗集团董事总经理兼全球环境金融与可持续发展主管Michael Eckhart。

（四）秘书长，秦海岩（兼）；副秘书长，河北省能源局副局长杨文生。

三、在可再生能源示范区建设推进工作中，请各有关单位要充分发挥专家咨询委员会的作用，加强与专家咨询委员会的日常沟通交流，为其创造便利的工作条件和良好的工作环境，积极支持其研究破解示范区建设过程中遇到突出问题的解决方案。请专家咨询委员会将相关工作计划、重大研究成果等及时与示范区建设协调推进工作组沟通，促进专家建议得到有效落实。
