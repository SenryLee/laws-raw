# 司法部关于同意农业部开展公职律师工作的函

司发函〔2017〕290号

农业部：

你部《关于申请在农业部开展公职律师工作的函》（农政函〔2017〕24号）收悉。经研究，同意在农业部开展公职律师工作，同意《农业部公职律师工作方案》，批准李生、李迎宾、陈朱勇等3名同志为公职律师。
