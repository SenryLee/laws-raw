# 农业部关于政协十二届全国委员会第五次会议第1732号（农业水利类153号）提案答复的函

## 关于政协十二届全国委员会第五次会议第1732号（农业水利类153号）提案答复的函

农办案〔2017〕79号

王继亮委员：

您提出的关于推广实施水肥一体化减肥增效技术的提案收悉。经认真研究，现答复如下。

一、关于宣传推广水肥一体化技术

大力推广水肥一体化技术，实现水分和养分的综合协调，提高水肥利用效率，对于转变农业发展方式，走绿色高效发展之路具有重要意义。国务院办公厅先后印发了《国家农业节水纲要（2012—2020年）》和《关于加快转变农业发展方式的意见》，对发展节水农业，促进水肥一体化技术推广应用提出了明确要求。农业部印发了《关于推进节水农业发展的意见》《水肥一体化技术指导意见》和《推进水肥一体化实施方案（2016—2020年）》等文件，提出了发展水肥一体化的总体思路、目标任务和基本原则。各级农业部门充分利用广播、电视、报纸、互联网等媒体，大力宣传国务院和农业部的决策部署，广泛宣传节水农业在促进粮食增产及农民增收中的作用，通过科技下乡、示范观摩、印发小册子等形式，向农民宣传水肥一体化等节水农业新技术、新模式，推动了水肥一体化技术的普及应用。

下一步，农业部将采取有力措施，加大宣传力度，结合开展“化肥农药减量在行动”主题宣传活动，挖掘各地推动水肥一体化发展的鲜活案例，树立一批典型样板，营造良好氛围。

二、关于在新疆棉区开展技术示范

针对新疆水资源状况和种植实际，农业部把水肥一体化技术推广作为一项重要措施，加强示范引导，加快推广应用。一是加大资金投入。2016年，农业部安排部门预算资金240万元，支持新疆在昌吉市和乌鲁木齐市建立高标准节水农业示范区，开展水肥一体化对比试验、新型地膜对比试验和抗旱抗逆试验。二是强化绩效考核。新疆将膜下滴灌水肥一体化技术纳入干部示范田考核指标，要求示范田责任领导定期深入田间地头掌握进度，检查质量，协调关键农时的技术服务、农资供应和农机具调配。三是建立激励机制。新疆部分县（市）政府设立财政专项奖励基金，对实施膜下滴灌水肥一体化技术成效显著的科技示范户给予奖励。通过示范点的带动，让广大种植户切实看到了水肥一体化技术带来的节本增收效应，推动了水肥一体化技术的推广应用。

下一步，农业部将会同有关部门，加大政策扶持力度，支持新疆棉区建立不同规模、不同标准的水肥一体化技术示范基地，发挥示范基地带动效应，积极引导种植大户、农民专业合作社等新型经营主体应用水肥一体化技术。

三、关于推广和普及水肥一体化技术

农业部会同有关部门，在水肥一体化技术推广方面开展了相关工作。一是加强顶层设计。按照“一控两减三基本”（严格控制农业用水总量，减少化肥和农药使用量，畜禽粪便、农作物秸秆、农膜基本资源化利用）的要求，制定《推进水肥一体化实施方案（2016―2020年）》（农办农〔2016〕9号），提出到2020年水肥一体化技术推广面积达到1.5亿亩的目标。二是强化政策扶持。2014年以来，中央财政每年安排10亿元专项资金，实施旱作农业技术推广项目，支持西北、华北干旱半干旱地区推广全膜覆盖、半膜覆盖、水肥一体化等旱作节水农业技术。三是支持产业发展。2016年，农业部推动成立高效复合肥料国家农业科技创新联盟和化肥减量增效国家农业科技创新联盟，将水溶肥料研发和水肥一体化技术推广作为重点内容，打造科企合作平台，推动产业快速发展。2016年，全国水肥一体化技术推广面积超过9000万亩。

下一步，农业部将采取有力措施，加快形成行政、科研、推广、企业、合作组织五位一体的推广机制，推动水肥一体化发展。一是发挥行政推动作用，整合相关项目、资金和技术力量；二是发挥推广队伍指导作用，提高技术服务能力；三是发挥科研教学单位技术创新作用，做好关键技术和设备研发；四是发挥企业产销衔接带动作用，提供产品和系统维护等增值服务；五是发挥农民专业合作组织主体作用，推进技术推广规模化和标准化。

四、关于加强相关人员和农民培训问题

农业部高度重视基层农技人员和农民培训工作。从2009年起，农业部在基层农技推广体系改革与建设示范县项目中，拿出10%左右的经费开展基层农技人员知识更新工作。2013年，农业部印发了《2013―2015年万名农技推广骨干人才培养计划指导意见》，通过异地研修、集中办班、现场观摩等形式分区域、分专业开展基层农技人员培训，不断提高基层农技人员业务能力和综合素质，提升科技服务能力。为推动膜下滴灌等水肥一体化技术应用，新疆农业部门组织编写了《标准化棉花膜下滴灌管理技术要求》《膜下滴灌安装注意事项》《棉花膜下滴灌苗期及中后期管理机械化技术措施要求》等技术手册，利用农贸集市、科技人员进村入户等形式免费发放，让农民尽快掌握水肥一体化技术。

下一步，农业部将会同有关部门，结合实施新型职业农民培训工程和农村实用人才带头人素质提升计划，逐级开展水肥一体化技术培训，提高基层技术人员、农民的专业素质和技术水平。通过技术讲座、印发资料、入户指导、现场观摩、田间学校等形式，普及推广水肥一体化技术。

感谢您对水肥一体化工作的关心，希望今后继续对农业部工作予以支持。

农业部

2017年9月1日
