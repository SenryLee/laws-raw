# 住房城乡建设部办公厅关于罗东、甘丹宁申报一级建造师注册弄虚作假行为的通报

建办市函[2017]131号

各省、自治区住房城乡建设厅，直辖市建委，新疆生产建设兵团建设局，国务院有关部门建设司（局）：

我部在一级建造师注册审查时发现，上海泓睿公路交通工程有限公司罗东、广西路建工程集团有限公司甘丹宁隐瞒其注册监理工程师已注册在其他单位的事实，存在提供虚假材料申请注册的违规行为。为加强注册执业管理，根据《注册建造师管理规定》（建设部令第153号）的有关规定，现对罗东、甘丹宁给予通报批评，一年内不受理其注册申请，并将其不良行为在全国建筑市场监管公共服务平台上予以公布。

附件：弄虚作假申报一级建造师注册人员名单

中华人民共和国住房和城乡建设部办公厅

2017年3月1日
