# 国家新闻出版广电总局办公厅关于2017年向全国青少年推荐百种优秀出版物并开展相关读书活动的通知

## 关于2017年向全国青少年推荐百种优秀出版物并开展相关读书活动的通知

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央军委政治工作部宣传局，中央和国家机关各部委、各民主党派、各人民团体出版单位主管部门，中国出版集团公司，中国教育出版传媒集团有限公司，中国科技出版传媒集团有限公司：

为全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，着力为党的十九大胜利召开营造良好氛围，培育和践行社会主义核心价值观，传承和弘扬中华优秀传统文化，大力推动青少年阅读，国家新闻出版广电总局组织开展了2017年向全国青少年（0~18岁）推荐百种优秀出版物活动。

2017年3月，总局下发《关于开展2017年向全国青少年推荐百种优秀出版物活动的通知》后，各省主管部门和出版单位高度重视、积极参与出版物报送工作，共有343家图书出版单位报送图书1479种，共有70家音像电子出版单位报送音像电子出版物192种。

2017年5月，总局组织专家对各出版单位报送的出版物进行认真评审、质量检查和公示。最终确定了2017年向全国青少年推荐的百种优秀出版物（见附件）。现将有关要求通知如下。

一、切实加强宣传推广。各地新闻出版广电局行政部门和主管部门要积极开展向全国青少年宣传推荐百种优秀出版物，请传统媒体和新兴媒体对入选出版物进行宣传推介。做好百种优秀出版物的重点宣传推广工作，把优秀出版物推荐给广大青少年读者，充分发挥优秀出版物的引领示范作用，引导青少年健康阅读。

二、认真做好展示展销。各地新闻出版广电行政部门要组织实体书店和网络书店做好百种优秀出版物的展示展销工作。暑假期间，中心城市新华书店要设立专柜、专架，集中展示展销。总局2017年向全国青少年推荐的百种优秀出版物。有条件的新华书店、其它实体书店和书城可以展示展销历年推荐的优秀出版物。京东、当当、亚马逊等网络书店也要开展出版物展示展销活动。各地要组织协调好百种优秀出版物的宣传、供货和货源储备等工作，以优质的服务、优惠的价格向青少年提供更好的出版物。

三、深入开展阅读活动。各地新闻出版广电行政部门要充分利用推荐的优秀青少年出版物，紧紧围绕实现中华民族伟大复兴中国梦这一主题，迎接宣传贯彻党的十九大这条主线，组织开展主题演讲、经典诵读、读书征文、知识竞赛等主题阅读活动，吸引青少年广泛参与。要在创新活动形式和提高活动质量方面下功夫，及时总结活动中的好做法、好经验，大力推动青少年阅读。
