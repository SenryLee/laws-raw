# 农业部关于印发《“十三五”全国草原防火规划》的通知

农牧发〔2017〕4号

有关省、自治区草原防火指挥部、畜牧（农牧、农业）厅（局），新疆生产建设兵团畜牧兽医局，黑龙江省农垦总局：

为提升草原防火应急管理水平，实现草原防火治理体系和治理能力现代化，我部组织制定了《“十三五”全国草原防火规划》，现印发给你们，请结合本地实际，认真组织实施。

农业部

2017年2月28日
