# 环境保护部公告2017年第32号——关于建设项目环境影响评价资质审查结果（2017年第九批）的公告

## 环境保护部公告

2017年第32号

## 关于建设项目环境影响评价资质审查结果（2017年第九批）的公告

根据《建设项目环境影响评价资质管理办法》（环境保护部令第36号）及相关文件的规定，我部对申请建设项目环境影响评价资质（以下简称资质）的相关机构进行了审查。现将审查结果（2017年第九批）公告如下：

一、批准安徽华境资环科技有限公司等3家机构乙级资质。

二、批准铁道第三勘察设计院集团有限公司资质证书中的机构名称变更。

三、批准天科院环境科技发展（天津）有限公司等9家机构调整评价范围。

四、批准西安建筑科技大学等9家机构资质证书中的住所变更或法定代表人变更。

五、批准安徽祥源科技股份有限公司等2家机构注销资质。

六、不予批准南通天虹环境科学研究所有限公司调整评价范围和资质延续，注销资质。

七、不予批准山东同济环境工程设计院有限公司调整评价范围。

审查结果的具体情况详见附件。第一至四项中的机构请于60日内携带单位证明，到我部行政审批大厅领取资质证书，其中第二至四项中的机构应在领取资质证书时携带原资质证书正、副本原件。第五、六项中的机构请于本公告发布之日起10日内将原资质证书正、副本原件交（寄）回我部行政审批大厅。自本公告发布之日起，第二至六项中的机构原资质证书正、副本原件同时作废。

上述机构不服本公告决定的，可在接到本公告之日起60日内向我部申请行政复议，也可在接到本公告之日起6个月内依法提起行政诉讼。在缩减评价范围或注销资质前已承接的环境影响报告书（表）需继续完成的，应在本公告发布之日起15日内，将有关情况连同编制委托合同等证明材料报我部审核。
