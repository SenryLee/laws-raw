# 农业部对十二届全国人大五次会议第2844号建议的答复

## 对十二届全国人大五次会议第2844号建议的答复

农办议〔2017〕208号

徐淙祥、陆胜祥代表：

你们提出的关于国家对粮食主产区加大秸秆利用和优质粮绿色生产投入的建议收悉。经商国家发展改革委、国家能源局、工业和信息化部，现答复如下。

一、关于支持种植大户、家庭农场农民专业合作社购置机械设备

我部已将秸秆粉碎还田机、青饲料收获机、青贮切碎机、翻转犁、深松机、捡拾压捆机、压捆机等促进秸秆综合利用的机具品目列入中央财政农机购置补贴范围。对属于这些品目的所有境内生产且通过农机推广鉴定的产品，农民可自主购置并按规定申请补贴，中央财政农机购置补贴资金补贴标准达到30%，极大促进了秸秆还田、离田机械化水平的提高。据统计，2016年全国机械化秸秆还田面积达7.2亿亩，秸秆捡拾打捆面积达0.65亿亩。下一步，我部将会同有关部门，进一步调整优化农机购置补贴机具种类范围，将更多符合要求的秸秆综合利用、农业废弃物利用等绿色发展机具纳入补贴范围，加快秸秆利用机械化进程。

二、关于支持秸秆过腹还田，形成生态农业良性循环

农作物秸秆适合草食动物消化利用，饲料化是秸秆传统用途，也是经济有效的利用方式。1992年，中央从促进资源综合利用、保障畜产品供给、节约粮食资源、保护生态环境的大局出发，做出实施秸秆养畜项目的重要决策，大力推进秸秆饲料化工作。20多年来，中央财政累计投入项目资金16.99亿元，立项建设秸秆养畜项目1591个，覆盖全国900多个县（市）。2017年，农业部办公厅、国家农业综合开发办公室印发了《农业综合开发区域生态循环农业项目指引（2017—2020年）》，集中力量推进区域生态循环农业项目建设，到2020年拟建设区域生态循环农业项目 300个左右；其中，对农作物秸秆及农产品加工剩余物等农副资源进行饲料化、肥料化、基料化、燃料化等综合开发，是区域生态循环农业的重要支持方向。下一步，我部将继续利用农业综合开发农副资源饲料化利用项目渠道，以规模化收储、专业化加工、高效利用为目标支持开展种养结合示范，探索形成生态农业良性循环的发展模式。

三、关于以县市为单位，兴办秸秆板材厂、秸秆饲料加工厂和秸秆发电厂

2016年我部会同财政部投入资金10亿元，在河北、山西、内蒙古、辽宁、吉林、黑龙江、江苏、安徽、山东、河南等10省（区）90个县，按照“整县推进、多元利用”的原则，开展了秸秆综合利用试点，围绕秸秆肥料化、饲料化、基料化、燃料化、原料化和收储运体系建设，探索可持续、可复制推广的秸秆综合利用技术、模式和机制。工业和信息化部高度重视秸秆造纸产业发展，与相关部门联合发布了《造纸工业发展规划》，将发展秸秆未漂纸浆及其制品生产技术列为鼓励发展的工艺技术，将年产10万—20万吨非木纤维浆设备列为重点研发的制浆造纸装备；2016年印发了《工业绿色发展规划（2016—2020）》明确提出，鼓励造纸行业利用农作物秸秆制浆，为秸秆产业化提供政策支持；发布了两批《再生资源综合利用先进适用技术目录》，将6项典型企业农作物秸秆资源化利用技术列入目录中。国家能源局发布实施了《生物质能发展“十三五”规划》，提出“十三五”期间农林生物质发电全面转向热电联产，到2020年，包括秸秆在内的生物质能利用规模将超过5800万吨标煤。下一步，我部将继续依托中央财政秸秆综合利用试点补助资金项目，支持秸秆综合利用的重点领域和关键环节，带动区域秸秆处理能力的整体提升，同时配合国家能源局组织一批农林生物质热电联产项目，为县城供暖及中小型工业园区供热，推进秸秆利用产业的健康发展。

感谢你们对农业和农村经济工作的关心，希望今后继续给予关注和支持。
