# 国家文物局关于纳达齐牛录关帝庙壁画修缮工程立项的意见

## 关于纳达齐牛录关帝庙壁画修缮工程立项的意见

办保函〔2017〕401号

新疆维吾尔自治区文物局：

你局《关于报送纳达齐牛录关帝庙壁画保护工程立项报告的请示》（新文物保发〔2017〕25号）收悉。经研究，我局意见如下：

一、暂不同意纳达齐牛录关帝庙壁画修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）加强现状勘察和历史研究，明确纳达齐牛录关帝庙壁画绘制年代、形制特点和工艺技法，深化病害类型、原因及影响因素分析，科学评估壁画地仗层和支撑墙体的稳定性。应补充说明纳达齐牛录关帝庙文物建筑本体修缮工程进展情况，明确文物建筑现状与壁画安全的关系，进一步论证工程实施的必要性和可行性。

（二）补充区域传统工艺、材料和做法的研究分析内容。

（三）应加强前期现场试验，根据颜料、地仗等检测试验结果深化设计思路，确保保护措施的可靠性与可行性。同时,应明确展示利用措施，并在方案设计中予以体现。

（四）根据工程量合理编制经费预算，确定取费项目，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促地方人民政府切实加强纳达齐牛录关帝庙日常保养工作，落实管理维护责任，确保文物安全。

专此函。

国家文物局

2017年4月11日
