# 国土资源部办公厅关于启用油气矿产储量管理信息系统的通知

国土资厅函〔2017〕1832号

中国石油天然气集团公司、中国石油化工集团公司、中国海洋石油总公司、中联煤层气有限责任公司，陕西延长石油（集团）有限责任公司等地方石油公司：

为进一步规范油气矿产资源储量评审备案、登记统计等管理工作，提高工作效率和管理水平，推进国土资源综合监管平台建设，根据《矿产资源登记统计管理办法》（国土资源部令2004年第23号）和《国土资源信息化“十三五”规划》，国土资源部研发完成了油气矿产储量管理信息系统。为做好相关工作的衔接，现将有关事项通知如下：

一、自发文之日起，启用油气矿产储量管理信息系统及相关报盘软件。各相关单位应使用国土资源部门户网站提供的信息系统软件，按照本通知和软件的用户使用手册要求组织报送油气储量评审备案和登记、统计材料。

2017年油气储量快报和通报数据均按该系统填报。已使用原系统填报的数据, 可通过油气矿产储量管理信息系统的数据导入功能将其导入。

二、自2018年3月15日起，油气储量评审备案、储量登记纳入国土资源部内网行政审批流程。相关电子报盘及纸质材料均报送至国土资源部政务大厅，由政务大厅统一接转和发送。

三、进一步加强油气储量数据的图形管理。在报送相关材料时，各油气公司需填写油气田代表井坐标和含油（气）面积范围坐标，坐标点个数的多少应以不引起范围形状变化为原则，确保数据准确、齐全，不符合要求的将予以退回重新报送。

四、油气储量管理信息系统软件和用户使用手册请登录www.mlr.gov.cn进入“办事服务-下载服务-软件下载-矿产资源登记统计”中查看和下载。

各油气公司要充分重视和使用好油气矿产储量管理信息系统和相关报盘软件，专人负责，加强指导，加大培训力度，组织做好所属各分公司的储量报送工作，确保按时保质完成储量数据报送工作。在使用系统过程中遇到问题，请及时与联系人联系。
