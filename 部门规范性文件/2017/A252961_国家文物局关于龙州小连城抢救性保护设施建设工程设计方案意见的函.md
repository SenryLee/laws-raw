# 国家文物局关于龙州小连城抢救性保护设施建设工程设计方案意见的函

## 关于龙州小连城抢救性保护设施建设工程设计方案意见的函

办保函〔2017〕780号

广西壮族自治区文化厅：

你厅《关于报送龙州县小连城抢救性保护设施建设工程设计方案的请示》（桂文物报〔2017〕34号）收悉。经研究，我局意见如下：

一、暂不同意小连城抢救性保护设施建设工程设计方案。

二、所报方案应做以下修改：

（一）补充《广西连城要塞遗址和友谊关—龙州小连城保护规划（2015—2030）》中关于保护区划及其管理规定的相关内容，并说明拟建项目是否符合保护规划的规定。

（二）对小连城历史环境进行充分论证与分析，说明保护界碑、消防设备房、水塔、看护管理用房等设施的选址分布、理由以及与文物本体之间的关系。

（三）补充对小垒城前后场地铺装整治及铺设巡护车道、步道的必要性说明，整齐划一的路面铺装形式与文物环境风貌不协调。小垒城的环境整治，应以草坪为主，不得进行地面硬化。巡护步道应尽可能与原有小道相似，不宜采取规整的方整石铺墁。

（四）结合实际看护管理需求，进一步缩减看护管理用房的体量，降低瞭望台等部分建筑高度。新建建筑形制应与文物环境风貌相协调。

（五）补充文物影响评估报告。

请你厅指导有关单位，根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局

2017年6月22日
