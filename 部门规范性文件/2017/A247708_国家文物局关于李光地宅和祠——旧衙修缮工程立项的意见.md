# 国家文物局关于李光地宅和祠——旧衙修缮工程立项的意见

## 关于李光地宅和祠——旧衙修缮工程立项的意见

办保函〔2017〕107号

福建省文物局：

你局《关于全国重点文物保护单位李光地宅和祠——旧衙修缮工程立项的请示》（闽文物字〔2016〕578号）收悉。经研究，我局意见如下：

一、暂不同意李光地宅和祠——旧衙修缮工程立项。

二、立项报告尚需在以下方面做出修改：

（一）加强现状勘察，明确保护对象，查明文物主要病害类型与残损状况，合理评估病害程度和发展趋势，进一步论证工程实施的必要性和可行性。

（二）应进一步细化工程措施，坚持最小干预原则，明确墙体、地面修缮的具体要求和做法，注意老旧构件的合理利用，并统筹考虑文物建筑利用问题。

（三）应根据工程量合理编制经费预算，进一步细化各单项取费依据，核减工程造价。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年2月13日
