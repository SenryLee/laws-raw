# 国家民委办公厅关于印发《国家民委2017年政务公开工作要点及任务分工》的通知

民办发[2017]53号

委机关各部门：

《国家民委2017年政务公开工作要点及任务分工》已经委领导同意，现印发给你们，请结合实际认真贯彻落实。

国家民委办公厅

2017年4月6日

## 国家民委2017年政务公开工作要点及任务分工

2017年，国家民委政务公开工作将认真贯彻落实中央民族工作会议精神，按照《政府信息公开条例》、《关于全面推进政务公开工作的意见》及实施细则要求，坚持以公开为常态、不公开为例外，全面推进决策、执行、管理、服务、结果公开，强化制度建设，深化公开内容，进一步加强信息发布、解读和回应，推进政务公开与民族工作、民委工作重点任务相结合，不断提高国家民委政务公开工作水平。

一、全面推进主动公开工作

（一）完善政务公开内容。

1.加快推进权力清单、责任清单、负面清单公开，坚持改革创新，注重精细化、可操作性，务求公开实效。（办公厅、舆情中心牵头，机关各部门配合）

2.推进规范性文件信息公开。定期统计规范性文件的制定、印发情况，应公开的规范性文件及时公开。（政策法规司牵头，办公厅配合）

3.完善政府信息公开目录，明确公开类别、公开事项、公开依据、公开时限等内容，进行定期审查和动态调整。严格落实公开属性认定机制，明确公开属性。（舆情中心）

（二）加大解读和回应力度。

4.各部门主要负责人应履行好“第一解读人和责任人”的职责，通过撰写文章、接受访谈、参加新闻发布会等多种方式，带头解读政策，主动回应社会关切。（相关部门牵头，文化宣传司配合）

5.按照“谁起草、谁解读”的要求，做到政策性文件与解读方案、解读材料同步组织、同步审签、同步公开。（文件起草部门）

6.统筹利用新闻发布会、新闻通稿、领导访谈、记者采访等形式，围绕涉及民族工作的热点问题，积极回应社会关切。（文化宣传司牵头，相关部门配合）

（三）强化公开平台建设。

7.积极利用新媒体发布政府信息，倾听社会意见、拓宽政府信息传播渠道。（文化宣传司牵头，舆情中心配合）

8.加强政府网站监管，做好日常监测和季度抽查，及时公开抽查情况。（舆情中心）

9.完成国家民委网站升级改造，充分发挥政务公开第一平台作用。（舆情中心）

二、推进重点领域信息公开

10.中央民族工作会议精神的贯彻落实情况。（机关各部门）

11.《国务院关于加快发展民族教育的决定》的贯彻落实情况。（教育科技司）

12.全国城市民族工作会议精神贯彻落实情况和维护少数民族合法权益信息。（政策法规司、监督检查司）

13.民族工作领域相关法规、规章和政策文件的修改、废止、实效情况，并在政府网站已发布的源文件上作出明确标注。（政策法规司牵头，舆情中心配合）

14.民族团结进步创建工作开展情况、全国民族团结进步示范单位评审命名等信息。（监督检查司）

15.《“十三五”促进民族地区和人口较少民族发展规划》《兴边富民行动“十三五”规划》相关解读及规划执行情况。（经济发展司）

16.民族地区贫困监测信息，中国民族统计年鉴统计数据等。（经济发展司）

17.少数民族特需商品名录。（经济发展司）

18.国家民委所属高校国家励志奖学金评审结果。（教育科技司）

19.科研项目立项审批、评审、立项、科研成果验收情况等信息。（教育科技司、研究室）

20.财政预决算、“三公”经费，按要求细化公开部门收支总体情况、财政拨款收支情况、机关运行经费安排和政府采购等情况。(财务司)

21.重大工程建设项目招标、中标信息。（财务司）

22.干部人事和社团工作政策法规、公务员考录、事业单位公开招聘、委属社团情况、专业技术职务资格评审、人才项目评审推荐、干部选拔任用和教育培训等信息。（人事司）

23.全面从严治党的重大部署、文件、信息等。（机关党委）

24.《国家民委2016年政府信息公开工作年度报告》。（舆情中心）

三、强化依申请公开

25.畅通依申请公开受理渠道，完善依申请公开申请接收、登记、办理、审核、答复、归档等环节制度规范。建立依申请公开信息目录，加强对依申请公开受理结果的审查，依法保障公众合理的信息公开需求。（舆情中心）

四、健全信息公开制度机制

26.出台《国家民委政务公开实施办法》。（办公厅、舆情中心）

27.健全国家民委政府信息公开监督检查制度，加强监督检查与考核评估。（舆情中心）

28.开展政务公开培训工作，进一步增强机关工作人员的公开意识，提高发布信息、解读政策、回应关切的能力。（舆情中心）
