# 国家安全监管总局办公厅关于规范和加强海洋石油安全生产考试工作的通知

安监总厅管一函〔2017〕200号

海洋石油作业安全办公室各分部，国家安全监管总局培训中心：

为进一步规范和加强海洋石油安全生产考试工作，解决考试题库不统一、工作不够规范、未纳入全国统一信息平台管理等问题，现就有关事项通知如下：

一、海洋石油作业安全办公室（以下简称海油安办）各分部要高度重视海洋石油安全生产考试体系建设工作，切实加强领导、加大投入，明确专人负责，按照《国家安全监管总局关于印发安全生产资格考试与证书管理暂行办法的通知》（安监总培训〔2013〕104号）等文件要求，抓紧建立教考分离、分级负责、统一标准、统一题库、统一证书、统一平台的考试体系。

二、海油安办各分部要依法做好辖区内海洋石油企业主要负责人、安全生产管理人员和特种作业人员的安全生产考试发证工作（以下简称海油安全考试）；海洋石油企业使用非海油安办分部考核发证的特种作业人员的，要在上岗前进行专门的海上作业安全培训；其他从业人员的考核工作，由企业依法自行组织。

三、海油安全考试使用统一题库。统一题库由国家级题库和海油安办分部题库组成，国家级题库由国家安全监管总局海油安办会同人事司（宣教办）组织命制；海油安办各分部要结合区域特点，认真做好本分部题库命制工作。统一题库中国家级题库试题的比例要高于80%，海油安办分部题库建立前全部使用国家级题库。

四、国家安全监管总局培训中心受委托承担全国海油安全考试的日常监督管理、技术支持和基础建设等工作。海油安办各分部分别确定1家考试机构作为辖区的考试中心，报国家安全监管总局海油安办备案。按照高效便民原则和工作需要，分部可批准所属考试中心设立考试点，承担具体组织实施工作。

五、海油安办各分部要规范考试业务流程，健全考务管理制度和人员队伍，并会同国家安全监管总局培训中心提高考试点规范建设水平。2018年1月1日前要使用全国统一的考试平台和题库进行考试，相关证书纳入全国统一考试平台管理。此前核发的证书在有效期内继续有效，各分部要抓紧汇总相关信息，年底前报国家安全监管总局培训中心，纳入全国平台管理。

六、海油安办各分部、各监督处和国家安全监管总局培训中心要加强考试机构和考试点工作监督检查，建立和严格执行巡考制度，对违反规定组织考试或取得证书的单位和人员要严肃处理，做到公平公正、严肃认真。
