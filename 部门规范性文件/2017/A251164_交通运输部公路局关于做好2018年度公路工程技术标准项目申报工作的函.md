# 交通运输部公路局关于做好2018年度公路工程技术标准项目申报工作的函

## 关于做好2018年度公路工程技术标准项目申报工作的函

交公便字〔2017〕104号

各有关单位：

根据部关于标准化工作的总体部署和公路建设、管理、养护、运营发展的实际需求，结合所征集的标准项目建议和专家意见，我局拟定了2018年度公路工程标准项目立项计划（附件一），现组织开展项目申报工作，有关要求如下：

一、申报作为公路工程标准项目主编单位、参编单位和主编、参编人员，其资格条件应满足《公路工程行业标准制修订管理导则》（JTG A02-2013）的规定。原则上，同一主编不得申报超过2项以上标准项目。

二、根据《交通运输部办公厅转发国务院办公厅关于印发中央预算单位2017-2018年政府集中采购目录及标准的通知》（交办财审〔2017〕4号)，公路工程标准项目经费额度在100万元以上的，将严格按照《中华人民共和国政府采购法》和《中华人民共和国招标投标法》有关规定确定项目承担单位。

三、申报单位应按要求填写《交通运输部公路工程行业标准立项申请报告》（附件二），并于2017年6月9日前将纸质和电子文档提交我局。
