# 国家文物局关于在南京城墙建设控制地带内进行天妃宫小学新校区建设项目的意见

文物保函〔2017〕1789号

江苏省文物局：

你局《关于审批天妃宫小学新校区项目规划设计方案的请示》（苏文物保〔2017〕232号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位南京城墙建设控制地带内进行天妃宫小学新校区建设项目和你局意见。

二、对所报项目提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《南京市历史文化名城保护规划》、《南京城墙保护规划》、《南京城墙保护条例》的相关管理规定，严格控制工程量和工程范围，尽量减少对文物及其环境的影响。

（二）进一步核实拟建项目涉及南京城墙段的绝对标高，位于建设控制地带内的建筑高度应严格遵守《南京城墙保护规划》关于该城墙段的高度要求。

（三）加强拟建建筑对城墙环境影响的视线分析，并提出绿化遮挡的指标要求。

（四）应充分考虑建设施工对城墙的影响，采取必要的文物保护措施和应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十八条的规定报城乡建设规划部门批准。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。施工中应加强监管，确保文物安全。

专此函复。

国家文物局

2017年10月27日
