# 农业部办公厅关于做好2017年违规渔具清理整治工作的通知

农办渔〔2017〕24号

各省、自治区、直辖市渔业主管厅（局）、新疆生产建设兵团水产局，各有关单位：

为贯彻落实全国渔业渔政工作会议和《农业部关于进一步加强国内渔船管控实施海洋渔业资源总量管理的通知》（农渔发〔2017〕2号）精神，切实加大渔业资源养护力度，现就做好2017年违规渔具清理整治工作通知如下。

一、精心组织，巩固成果，持之以恒抓好清理整治工作

近年来，我部在全国范围内组织开展违规渔具清理整治行动，取得了阶段性成果。截至目前，全国共清理违规渔具近85万张（顶），“绝户网”等违规渔具使用蔓延态势得到了一定程度的遏制。但各地工作开展不平衡，重视程度和整治效果还有待提高。为此，各级渔业主管部门和执法机构要进一步增强责任感和紧迫感，继续做好清理整治工作。要进一步完善相关工作机制，定期向本级党委、政府报告工作情况，将清理整治工作纳入政府工作议程和考核内容，充分发挥政府主导、部门协作机制的作用。要认真分析形势和存在问题，进一步理清工作思路，制订工作方案，明确工作目标，落实工作措施，确保清理整治工作取得实效。各地工作方案请于5月5日前报送我部渔业渔政管理局。

二、明确目标，突出重点，进一步加大执法检查力度

当前，违规渔具清理整治已进入攻坚阶段，各地要突出重点，保持执法高压态势，努力实现滩涂不见禁用陷阱类作业、近岸不见禁用耙刺及地拉网作业、渔具网目尺寸明显改善的管理目标。

一是全面清理禁用渔具。要继续保持对禁用渔具的执法高压态势，对浅海滩涂、交界海域等重点区域开展拉网式检查，消除死角盲区。同时设立举报电话，发挥群众监督作用，坚决打击生产、使用禁用渔具行为。对没收的禁用渔具，要集中公开销毁，同时组织媒体进行追踪报道，做到“发现一起，查处一起，公布一起、震慑一方”，防止禁用渔具死灰复燃。

二是积极推动网目尺寸执法检查。网目尺寸是渔具规范化管理的重要标志，当前网目尺寸严重偏离规定标准的现象仍然十分普遍。各地渔业部门要积极开展网目尺寸执法检查，对网目尺寸严重违反国家规定标准和拖网、张网网囊加装衬网等现象进行重点打击，使网目尺寸不符合规定的现象逐步得到改善。同时，要加强宣传和政策引导，鼓励渔民协会、渔业专业合作社、渔船渔机网具协会等组织开展行业自律，引导企业和渔民生产、经营、使用合规渔具。对严重违反规定的渔民和企业除依法处罚外，可按规定扣减渔业生产成本补贴，在行业内进行通报。

三是开展多部门、跨区域联合执法。各级渔政、渔监和渔检等部门要形成系统内工作合力，结合伏季休渔、安全生产管理等工作，加强对港口、重点海域、生产经营企业执法检查。同时要加强与海警、公安、工商、工信、质监等部门配合，强化陆上生产及流通环节执法管理，抓好休渔开捕前出港渔船检查，减少渔船携带违规渔具出海生产行为。对使用违规渔具构成犯罪的，要积极争取司法机关提前介入，根据《农业部关于加强农业行政执法与刑事司法衔接工作的实施意见》要求，坚决移交司法机关追究刑事责任。

三、加强督查，认真总结，确保工作取得实效

要加强督导检查，定期派出工作组赴重点地区督导，从工作机制是否建立、组织领导是否到位、行动方案制定和执行力度、宣传教育方式和效果、专项行动规模、工作档案整理、司法机关介入、查处违规渔具数量和整治效果等多方面进行全面督导，检查结果向社会或行业内通报。对整治工作重视程度不够、措施不力、效果不突出的单位和个人予以通报批评。要对清理整治工作及时进行总结，并做好情况汇总（填好附件汇总表）。相关工作总结和汇总表于12月15日前以正式文件报送我部渔业渔政管理局。
