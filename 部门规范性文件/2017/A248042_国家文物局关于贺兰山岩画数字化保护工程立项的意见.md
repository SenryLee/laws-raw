# 国家文物局关于贺兰山岩画数字化保护工程立项的意见

## 关于贺兰山岩画数字化保护工程立项的意见

办保函〔2017〕176号

宁夏回族自治区文物局：

你局《关于申请贺兰山岩画数字化保护立项的请示》（宁文物发〔2016〕119号）收悉。经研究，我局意见如下：

一、暂不同意贺兰山岩画数字化保护工程立项。

二、对该立项提出以下修改意见：

（一）应根据贺兰山岩画保存现状及文物保护管理需要，进一步论证数字化保护工程实施的必要性和效果，明确数字化保护工程的目标，科学确定数字化保护的工作内容、范围和技术路径。

（二）应进一步明确航空遥感影像航拍、中低空倾斜摄影、地面激光点云数据获取的工作范围、对象、技术方法、主要精度指标和预期成果，特别是岩画的影像数据采集和纹理映射技术方法和质量保证措施。补充地形图测绘、岩画本体测绘等相关工作内容。

（三）补充说明项目实施中的文物安全防护措施，确保文物安全。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年2月24日
