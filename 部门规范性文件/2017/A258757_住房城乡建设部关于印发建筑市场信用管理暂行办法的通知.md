# 住房城乡建设部关于印发建筑市场信用管理暂行办法的通知

建市〔2017〕241号

各省、自治区住房城乡建设厅，直辖市建委，北京市规划国土委，新疆生产建设兵团建设局：

现将《建筑市场信用管理暂行办法》印发给你们，请遵照执行。执行中遇到的问题，请及时函告我部建筑市场监管司。
