# 水利部关于印发《最严格水资源管理制度考核补助项目管理暂行办法》的通知

水资源〔2017〕400号

各省、自治区、直辖市水利(水务)厅(局)：

为贯彻落实党的十九大关于“实施国家节水行动”部暑和《国务院办公厅关于印发实行最严格水资源管理制度考核办法的通知》(国办发〔2013〕2号)要求,激励各地加强水资源管理、节约与保护工作,规范项目管理,我部制定了《最严格水资源管理制度考核补助项目管理暂行办法》。现印发给你们,请遵照执行。

水利部

2017年11月23日
