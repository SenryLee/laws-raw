# 中华人民共和国财政部公告2017年第89号——决定第一次续发行2017年记账式附息（十二期）国债

## 中华人民共和国财政部公告

2017年第89号

根据国家国债发行的有关规定，财政部决定第一次续发行2017年记账式附息（十二期）国债，已完成招标工作。现将有关事项公告如下：

一、本次国债计划续发行280亿元，实际续发行面值金额281.4亿元。

二、本次续发行国债的起息时间、票面利率等要素均与2017年记账式附息（十二期）国债相同，即起息日为2017年6月15日，票面年利率为3.62%；按年付息，每年的6月15日（节假日顺延，下同）支付利息，2019年6月15日偿还本金并支付最后一次利息。经招标确定的续发行价格为100.58元，折合年收益率为3.46%。本次续发行的国债从招标结束后至2017年7月13日进行分销，从7月17日起与之前发行的同期国债281.9亿元合并上市交易。

其他事宜按《中华人民共和国财政部公告》（2017年第2号）规定执行。

特此公告。

中华人民共和国财政部

2017年7月12日
