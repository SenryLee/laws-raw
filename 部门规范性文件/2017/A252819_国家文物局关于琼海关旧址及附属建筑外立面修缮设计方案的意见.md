# 国家文物局关于琼海关旧址及附属建筑外立面修缮设计方案的意见

## 关于琼海关旧址及附属建筑外立面修缮设计方案的意见

办保函〔2017〕428号

海南省文化广电出版体育厅：

你厅《关于审核琼海关旧址及附属建筑外立面修缮设计方案的请示》（琼文发〔2017〕40号）收悉。经研究，我局批复如下：

一、暂不同意所报工程技术方案。

二、所报方案需进行以下必要的修改和完善：

（一）根据最小干预原则对修缮措施进行必要调整。去除外墙面水泥砂浆以外三层，恢复石灰粉刷层，以及在石灰粉刷底层安装加筋网的做法均易伤及文物本体。建议对外墙面只做现状修补，并设法仿效原石灰粉刷层的视觉效果。

（二）补充附属建筑立面改造的设计依据。调查琼海关大楼尚存木门窗原油漆类型及颜色，为相关修缮设计提供参照。

（三）补充琼海关大楼砖墙基础现状勘察，若原防水功能已基本失效，应补充基础防潮措施。

（四）补充外立面饰线等必要的细部设计大样图。

二、请你厅指导有关单位，根据《文物保护工程设计文件编制深度要求（试行）》和上述意见对方案进行修改和完善，另行报批。

国家文物局
