# 环境保护部办公厅关于环评工程师职业资格证书“挂靠”问题集中治理工作情况的通报

## 关于环评工程师职业资格证书“挂靠”问题集中治理工作情况的通报

环办环评函〔2017〕1957号

各省、自治区、直辖市环境保护厅（局），新疆生产建设兵团环境保护局：

按照人力资源社会保障部的有关要求和统一部署，我部于2017年6月至8月组织开展了环评工程师职业资格证书“挂靠”问题集中治理工作。现将有关情况通报如下：

一、总体情况

2017年6月，我部印发《关于开展环评工程师职业资格证书“挂靠”问题集中治理工作的通知》（环办环评函〔2017〕879号），组织部署相关工作。此次集中治理工作分两阶段进行，第一阶段为环评机构自查，第二阶段为省级环保部门现场核查。同时，我部和各省级环保部门通过设立公开电话和邮箱、接受来信来访等多种形式收集相关问题线索。通过对全国913家环评机构全覆盖式集中治理检查，摸清了专职环评工程师底数，清理了“挂靠”环评工程师，发现和纠正了部分环评工程师从业申报中的不规范行为。

二、发现的问题

（一）经环评机构自查发现，16名环评工程师存在“挂靠”行为；131名环评工程师未如实申报从业情况，所持有的其他执（职）业资格证书注册在申报机构以外的其他单位，无法有效证明在申报的环评机构专职从业。

（二）经省级环保部门核查发现，32家环评机构的62名环评工程师未如实申报从业情况，所持有的其他执（职）业资格证书注册在申报机构以外的其他单位，无法有效证明在申报的环评机构专职从业。

（三）根据收集到的问题线索，经我部会同相关省级环保部门调查核实，2017年以来，5家机构的12名环评工程师存在“挂靠”行为。

三、问题处理结果

（一）经自查发现存在“挂靠”行为的16名环评工程师和未如实申报从业情况的131名环评工程师，已根据实际从业情况，主动申报注销原从业信息或完成其他执（职）业资格证书注销注册手续。上述人员中申报注销原从业信息的，予以注销登记编号，不再计入原申报的环评机构专职环评工程师数量，不得作为环境影响报告书（表）的编制主持人或主要编制人员。

（二）对经省级环保部门核查发现未如实申报从业情况的62名环评工程师（名单详见附件），予以注销登记编号，不再计入原申报的环评机构专职环评工程师数量，不得作为环境影响报告书（表）的编制主持人或主要编制人员，相关情况记入诚信记录并向社会公开。

（三）对经我部会同相关省级环保部门调查核实发现的12名存在“挂靠”行为的环评工程师，给予三年内不得作为资质申请机构配备的环评工程师和环境影响报告书（表）编制主持人或主要编制人员的相应处理；对5家相关机构，不予批准资质申请且一年内不得再次申请资质或责令限期整改。相关情况已记入诚信记录，并经由我部公告等形式向社会公开。

（四）此次集中治理后，对因专职环评工程师数量发生变化，已不符合相应资质条件的55家环评机构，重新核定其资质等级和评价范围或注销资质。相关情况已经由我部公告等形式向社会公开。
