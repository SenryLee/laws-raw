# 中华人民共和国工业和信息化部公告2017年第31号——符合《环保装备制造行业（大气治理）规范条件》企业名单（第二批）

## 中华人民共和国工业和信息化部公告

2017年第31号

按照《环保装备制造行业（大气治理）规范条件》（工业和信息化部公告2016年第66号），经企业自愿申报、地方工业主管部门审核推荐、专家评审及现场核实、网上公示等程序，现将符合《环保装备制造行业（大气治理）规范条件》企业名单（第二批）予以公告。

附件：符合《环保装备制造行业（大气治理）规范条件》企业名单（第二批）

工业和信息化部

2017年7月7日
