# 国家文物局办公室关于济南市章丘区“天佑医院”建设项目涉及危山汉墓保护范围选址的意见

办保函〔2017〕1135号

山东省文物局：

你局《关于报送济南市章丘区“天佑医院”建设工程涉及危山汉墓保护范围设计方案的请示》（鲁文发〔2017〕84号）收悉。经研究，我局意见如下：

一、所报项目选址位于山东省文物保护单位危山汉墓保护范围内，紧邻1号陪葬坑，拟建建筑体量较大，严重影响墓葬及其周边环境风貌。我局暂不同意所报济南市章丘区“天佑医院”建设工程涉及山东省文物保护单位危山汉墓保护范围的选址方案。

二、请你局指导建设单位切实加强前期论证和文物影响评估，进一步说明项目选址的必要性，客观分析建设影响，建议避开危山汉墓保护范围另行选址。

国家文物局办公室

2017年10月9日
