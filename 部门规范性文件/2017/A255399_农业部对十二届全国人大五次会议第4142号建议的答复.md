# 农业部对十二届全国人大五次会议第4142号建议的答复

## 对十二届全国人大五次会议第4142号建议的答复

农办议〔2017〕244号

张维国、刘运梅代表：

你们提出的关于解决取缔丹江口水库网箱养殖后资金补助的建议收悉。经商财政部，现答复如下。

一、关于中央财政安排专项资金对拆除的网箱养鱼设施进行经济补偿问题

2016年，中央财政下达有关省（区、市）水污染防治专项资金130亿元，重点支持水质较好湖泊生态环境保护、重点流域水污染防治、城市集中式饮用水源地保护、地下水污染防治等《水污染专项行动计划》确定的重点工作。该专项资金采取切块方式下达，由地方政府统筹使用,其中下达南水北调沿线省市水污染防治专项资金22.35亿元，湖北省为3.93亿元，用于丹江口水库保护治理。我部认为，从丹江口水库渔业持续健康发展和渔民生计、渔区稳定的角度出发，建议地方政府拆除养殖网箱和围栏不要“一刀切”，对于养殖滤食性鱼类的不投饵网箱和养殖草食性、滤食性不投饵围栏可继续保留。

二、关于落实生态补偿制度，恢复自然生态平衡问题

丹江口水库是南水北调中线工程核心水源区，也是增殖放流的重要水域。近年来，我部会同湖北省不断加强库区水生生物资源养护工作，将其列为《农业部关于做好“十三五”水生生物增殖放流工作的指导意见》中开展增殖放流的重要水域。2016年，湖北省安排中央财政专项转移支付资金80万元用于丹江口水库增殖放流。今年起，中央财政转移支付专项农业资源及生态保护项目进行整合改革，实行“大专项+任务清单”的管理方式，将包括增殖放流在内的资金整体切块到省，同时明确各支持方向的任务数量，湖北省农业（渔业）和财政部门将在细化方案中对省内各地的资金和任务进行分解，其中包括丹江口水库增殖放流资金。此外据了解，湖北省2017年从渔业油补政策调整一般性转移支付资金中安排2000万元，用于支持丹江口水库渔业资源养护等工作。今后，我部将持续关注并支持丹江口水库水生生物增殖放流工作。

感谢你们对渔业发展的关心支持，希望今后继续关心我部工作。
