# 公开市场业务交易公告[2017]第50号——关于人民银行以利率招标方式开展逆回购操作及MLF操作的公告

## 公开市场业务交易公告

[2017]第50号

2017年3月16日，人民银行以利率招标方式开展逆回购操作800亿元，并对17家金融机构开展MLF操作3030亿元，共计3830亿元。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 7天 | 200亿元 | 2.45% |
| 14天 | 200亿元 | 2.60% |
| 28天 | 400亿元 | 2.75% |

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 6个月 | 1135亿元 | 3.05% |
| 1年 | 1895亿元 | 3.20% |

中国人民银行公开市场业务操作室

二〇一七年三月十六日
