# 国家核安全局关于批准《防城港核电厂1、2号机组化学与放射化学技术规范（1版）》的通知

## 关于批准《防城港核电厂1、2号机组化学与放射化学技术规范（1版）》的通知

国核安发〔2017〕290号

广西防城港核电有限公司：

你公司《关于〈防城港核电厂1、2号机组化学与放射化学技术规范（0版）〉升版的请示》（桂防核〔2017〕80号）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的要求，我局对你公司提交的申请文件进行了审评，认为你公司《防城港核电厂1、2号机组化学与放射化学技术规范（1版）》（以下简称技术规范）是可以接受的，现予批准。

你公司应严格执行技术规范，确保防城港核电厂1、2号机组机组运行安全。

国家核安全局

2017年11月21日
