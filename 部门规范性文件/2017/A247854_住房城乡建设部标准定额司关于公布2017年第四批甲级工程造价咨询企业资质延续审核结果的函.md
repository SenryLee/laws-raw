# 住房城乡建设部标准定额司关于公布2017年第四批甲级工程造价咨询企业资质延续审核结果的函

建标造函[2017]63号

各省、自治区住房城乡建设厅，直辖市建委，各有关工程造价咨询企业管理机构：

根据《工程造价咨询企业管理办法》（建设部令第149号），以及《住房城乡建设部办公厅关于甲级工程造价咨询企业资质审核有关事项的通知》（建办标[2015]20号）要求，现将合格的天津银石建设投资咨询有限公司等16家企业，不予资质延续的唐山宏烨工程招标有限公司名单予以公布。

附件：1.2017年第四批甲级工程造价咨询企业资质延续名单

2.不予资质延续的甲级工程造价咨询企业名单

中华人民共和国住房和城乡建设部标准定额司

2017年2月28日
