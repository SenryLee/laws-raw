# 交通运输部、中国农业发展银行关于合力推进交通扶贫脱贫攻坚工作的通知

## 交通运输部 中国农业发展银行关于合力推进交通扶贫脱贫攻坚工作的通知

交规划发〔2017〕2号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），中国农业发展银行各分行：

为深入贯彻落实中央扶贫开发工作会议精神和《中共中央 国务院关于打赢脱贫攻坚战的决定》的部署要求，加快推进贫困地区交通发展，充分发挥政策性金融作用，破解贫困地区交通建设资金难题，现就合力推进交通扶贫脱贫攻坚工作有关要求通知如下：

一、充分认识合力推进交通扶贫脱贫攻坚工作的重要意义

全面建成小康社会，最艰巨最繁重的任务在贫困地区。加快贫困地区交通基础设施建设，补齐贫困地区交通运输发展短板，提升贫困地区交通运输服务水平，充分发挥交通扶贫对脱贫攻坚的基础支撑作用和先行引领作用，对提升贫困地区区域发展能力和全面建成小康社会具有重要战略意义。

“十三五”时期是打赢脱贫攻坚战的决胜阶段，交通扶贫建设任务重、资金需求量大，必须充分发挥政策性金融引导作用助推交通扶贫脱贫攻坚工作。中央扶贫开发工作会议后，农发行以服务脱贫攻坚统揽全局工作，率先制定政策性金融扶贫五年规划，率先对832个国家扶贫开发工作重点县和集中连片特殊困难地区县实现扶贫金融服务机构全覆盖。农发行机构网络健全、扶贫贷款资金利率优惠、贷款期限长等优势有助于缓解交通扶贫中的资金压力。各级交通运输主管部门和农发行分支机构要认真贯彻落实中央决策部署，深刻认识服务脱贫攻坚工作的重大历史使命和社会责任，合力破解交通扶贫资金难题，加快打赢“十三五”交通扶贫脱贫攻坚战。

二、扎实推进交通扶贫脱贫攻坚工作重点任务

准确把握党中央、国务院方针政策，坚持精准扶贫、精准脱贫的基本方略。有脱贫攻坚任务的各省（区、市）要围绕省级人民政府脱贫攻坚工作部署，以《“十三五”交通扶贫规划》为基础，结合《国家发展改革委、交通运输部、国务院扶贫办关于印发<关于进一步发挥交通扶贫脱贫攻坚基础支撑作用的实施意见>的通知》（发改基础〔2016〕926号）具体要求，针对不同区域交通发展需求，精准运用农发行信贷资金和农发重点基金，发挥信贷产品“组合拳”优势，把政策性信贷资金使用到最需要帮扶的地方，对交通扶贫项目真正起到引导和扶持作用。围绕交通扶贫规划范围内的1177个集中连片特困县、国家扶贫开发工作重点县、革命老区县、少数民族县、边境县，加快构建“外通内联、通村畅乡”的交通运输网络，主要支持范围包括：

（一）农村公路。重点支持纳入各省（区、市）“十三五”交通扶贫脱贫攻坚目标任务、“百万公里农村公路建设工程”的农村公路项目，主要包括乡镇、建制村、一定人口规模的自然村通硬化路项目；易地扶贫搬迁安置点通硬化路项目；乡村旅游公路、资源开发和通产业园区公路；窄路基路面公路拓宽改造；“油返砂”农村公路改造项目；农村公路安全生命防护工程建设、危桥改造、新建桥梁和渡口改造项目。

（二）普通国道和省道。重点支持交通运输部和各省（区、市）人民政府制定的“十三五”交通规划中的普通国道项目，优先安排实施“百项交通扶贫骨干通道工程”中的普通国道项目；大力支持纳入各省（区、市）“十三五”交通扶贫脱贫攻坚目标任务的省道新建和改造项目。

（三）贫困地区其他交通建设项目。重点支持对贫困人口覆盖率较高的县域城镇道路、内河航道等水运基础设施、运输站场及其它道路附属设施。

三、建立合力推进交通扶贫脱贫攻坚工作的紧密协作机制

各级交通运输主管部门和农发行应进一步建立健全协作机制，切实提升合作水平，拓展合作范围，加大合作力度。

（一）交通运输主管部门协助农发行做好扶贫贷款工作。

各级交通运输主管部门要把农发行作为交通扶贫贷款融资的重要合作银行，用好用足农发行信贷政策和产品组合，加快推进交通扶贫项目建设。加强行业指导，及时向农发行提供相关规划和政策信息。与农发行紧密开展项目对接合作，协助推进项目融资工作，及时向农发行提出资金需求和项目清单。协调同级发展改革、财政、扶贫办、人民银行、银监会等部门，为交通扶贫脱贫攻坚创造良好的外部环境。

（二）各级农发行为交通扶贫建设提供全面优质的金融服务。

各级农发行要发挥政策性银行铺路架桥作用，将交通扶贫脱贫攻坚项目作为重点支持对象，优化办贷手续，优先受理，优先评审，优先配置信贷资源，实行规模倾斜、利率优惠、期限延长等支持政策。及时向交通运输主管部门提供有关政策性金融政策，聚焦重点区域，因地、因项目制定合理的贷款方案，推介“统贷统还”等信贷模式。对纳入双方共同建立的PSL项目库的农村公路项目，及时向人民银行申请PSL贷款资金，其他农村交通建设项目贷款利率按照“对标当地同业、适当体现优惠”原则合理确定，为交通扶贫建设提供低成本贷款资金。实施贫困地区信贷政策差别化，对832个国家扶贫开发工作重点县和集中连片特困地区农村交通贷款取消地方政府财力区域准入限制；创新担保组合，结合本地实际加大扶贫创新力度，在整合担保资源方面出台新举措。

（三）深化合作，不断创新交通扶贫融资模式。

在充分挖掘现有政策潜力的基础上，不断优化创新扶贫政策，共同探索研究合规的政策性融资模式。建立会商机制，互通政策信息和交通融资业务进展情况等。加强交通扶贫联合调研、交通扶贫脱贫政策研究和培训。共同推动创造良好的交通扶贫建设项目融资环境。

各省级交通运输主管部门和农发行省级分行在交通扶贫脱贫工作中遇到的问题和建议，请及时向交通运输部和农发行总行反映。
