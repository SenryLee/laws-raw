# 环境保护部办公厅关于解除河北石家庄市赞皇县垃圾填埋场环境问题挂牌督办的通知

## 关于解除河北石家庄市赞皇县垃圾填埋场环境问题挂牌督办的通知

环办环监函〔2017〕1662号

河北省环境保护厅：

按照我部办公厅《关于对河北石家庄市赞皇县垃圾填埋场环境问题挂牌督办的通知》(环办环监〔2017〕31号)要求，你厅督促石家庄市和赞皇县政府及其相关部门按照督办要求积极整改，组织了初步现场核查，并向我部提交了解除挂牌督办的申请。经我部现场核查，河北石家庄市赞皇县垃圾填埋场环境问题整治达到督办要求。

经研究，现决定对河北石家庄市赞皇县垃圾填埋场环境问题解除挂牌督办。请你厅继续督促石家庄市和赞皇县政府及有关部门认真落实监管职责，加强日常监管，督促该垃圾填埋场落实环境保护主体责任，妥善处理与周边居民的关系。

环境保护部办公厅

2017年11月3日
