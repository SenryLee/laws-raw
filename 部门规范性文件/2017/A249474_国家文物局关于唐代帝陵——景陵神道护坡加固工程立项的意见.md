# 国家文物局关于唐代帝陵——景陵神道护坡加固工程立项的意见

## 关于唐代帝陵——景陵神道护坡加固工程立项的意见

办保函〔2017〕386号

陕西省文物局：

你局《关于唐代帝陵（景陵）神道护坡加固工程立项的请示》（陕文物字〔2017〕18号）收悉。经研究，我局意见如下：

一、暂不同意唐代帝陵—景陵神道护坡加固工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）补充保护规划中对景陵神道的相关规定，建议将护坡加固与神道及其两侧石刻的展示统筹考虑，以增强整体性。

（二）进一步加强神道及其两侧石刻本体现状勘察，补充说明保存现状及所存在的问题，在此基础上提出有针对性的保护措施。

（三）神道及其两侧石刻展示应注意符合景陵作为帝王陵寝的整体定位，并注意维护陵园氛围。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年4月11日
