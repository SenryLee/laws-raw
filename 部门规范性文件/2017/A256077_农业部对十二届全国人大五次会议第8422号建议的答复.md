# 农业部对十二届全国人大五次会议第8422号建议的答复

## 对十二届全国人大五次会议第8422号建议的答复

粮食安全是经济发展、社会稳定和国家安全的基础。中央始终高度重视粮食生产发展，通过完善稻谷、小麦、玉米、大豆等重要农产品价格形成机制、收储制度和补贴政策，保障农民种植收益，充分调动农民参与结构调整的积极性。重视农村土地承包经营权流转和发展适度规模经营，鼓励通过土地经营权流转、农业生产托管等多种方式，发展土地流转型、服务带动型等多种形式规模经营。按照“四化同步”战略部署，以推进供给侧结构性改革为目标，以提升科技服务水平为着力点，注重完善农业科技推广体系，提高农民科学素质，发展社会化服务组织，加快推动传统农业向现代农业转变。

农业部

2017年9月9日
