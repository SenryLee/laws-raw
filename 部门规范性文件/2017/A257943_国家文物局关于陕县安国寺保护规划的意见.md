# 国家文物局关于陕县安国寺保护规划的意见

文物保函〔2017〕1862号

河南省文物局：

你局《关于呈报陕县安国寺保护规划的请示》（豫文物〔2017〕205号）收悉。经研究，我局意见如下：

一、原则同意所报修改后的陕县安国寺保护规划。

二、对该规划提出以下修改意见：

（一）进一步补充说明将火神殿、方丈院及和尚院纳入附属文物的依据;适当扩大研究范围，补充安国寺选址与周边山形水系关系的分析。

（二）进一步完善保护区划的管理规定。对考古可能发现的文物遗迹应及时纳入保护范围，增加对保护范围内部分非文物建筑整治的规定，补充建设控制地带内建筑体量、容积率等相关控制指标。

（三）不同意保护措施中关于火神殿、方丈院、和尚院恢复院落格局的内容。

（四）进一步论证环境保护与整治中安国寺卫生间迁址的必要性。

（五）进一步规范图纸和文字表达。

三、请你局指导地方人民政府组织有关单位，按照上述意见对规划进行必要修改和完善，经你局核准后于15个工作日内将规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的陕县安国寺保护规划报请河南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好陕县安国寺文物保护的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年11月16日
