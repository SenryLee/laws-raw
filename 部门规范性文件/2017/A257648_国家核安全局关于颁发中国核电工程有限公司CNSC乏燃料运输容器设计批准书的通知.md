# 国家核安全局关于颁发中国核电工程有限公司CNSC乏燃料运输容器设计批准书的通知

## 关于颁发中国核电工程有限公司CNSC乏燃料运输容器设计批准书的通知

国核安发〔2017〕282号

中国核电工程有限公司：

你公司《关于CNSC乏燃料运输容器设计批准书取证申请的请示》（核工经发〔2013〕18号）收悉。

根据《放射性物品运输安全管理条例》及其配套规章《放射性物品运输安全许可管理办法》的有关要求，我局审查了你公司提交的申请材料，认为你公司设计的CNSC乏燃料运输容器满足我国相关法规和标准的要求，决定向你公司颁发CNSC乏燃料运输容器设计批准书，内容如下：

一、法定代表人：卢洪早。

二、单位住所：北京市海淀区西三环北路117号。

三、设计批准编号：CN/058/B(U)F-96(NNSA)。

四、设计安全分析报告版次：B版。

五、运输容器类型：B（U）F型；Ⅲ级（黄）。

六、放射性内容物特性：最多可以装载21组AFA2G、AFA3G或AFA3GAA乏燃料组件，U-235最高初始富集度为4.45wt％。AFA2G乏燃料组件燃耗深度不大于45000MWd/tU；AFA3G或AFA3GAA乏燃料组件燃耗深度不大于55000MWd/tU。

七、设计说明：CNSC乏燃料运输容器主要由上减震器、容器本体、下减震器和减震器螺栓组成。空容器质量(含减震器)约83740kg，容器最大外形尺寸2960×2950×6270mm。主体材料为06Cr19Ni10、XM-19/FXM-19。屏蔽材料包括屏蔽γ射线的铅和屏蔽中子的中子屏蔽材料。

八、操作要求：运输容器必须按照设计安全分析报告规定的操作程序进行装载准备、装载和卸载。

九、运输方式：道路、铁路、水路，独家使用。

十、使用环境温度：-40℃～+38℃。

十一、有效期至：2022年10月31日。

十二、本批准书不免除托运人遵守货包途经或抵达国政府任何要求的责任。本批准书不免除托运人遵守国家其他有关运输法规要求的责任。

国家核安全局

2017年11月14日
