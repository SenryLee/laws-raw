# 国家文物局关于紫金城址与铁河古墓群保护规划的意见

## 关于紫金城址与铁河古墓群保护规划的意见

办保函〔2017〕513号

江西省文物局：

你局《关于呈报〈紫金城城址与铁河古墓群保护规划〉的请示》（赣文物局字〔2017〕27号）收悉。经研究，我局意见如下：

一、暂不同意紫金城城址与铁河古墓群保护规划。

二、所报规划尚需做以下必要的修改和完善：

（一）补充最新的考古工作成果和相应的研究成果，梳理紫金城城址与周边墓群的空间分布关系，进一步提炼价值，并做好基于价值的地下文物遗存系统评估，作为保护规划的编制依据。

（二）进一步调整保护区划，城址的保护范围应充分考虑护城河遗迹的保护问题，墓群的保护范围应根据墓群分布规律及布局特点整体划定，建设控制地带应在现有基础上适当扩大，将山、水、城、墓的整体格局纳入管控范围。必要时，可对保护范围和建设控制地带做适当的分级分类处理。

（三）进一步梳理保护区划管理规定，做到严谨、准确。属于保护措施的应纳入相应章节，属于法律法规通用性规定，且无具体针对性的表述，可删去。

（四）进一步调整遗址本体保护措施，不得对城垣遗址做大规模恢复，植被调整亦应慎重，原则上不得大规模扰动。同时，应结合鄱阳湖泄洪区的分布范围，补充提出有针对性的文物保护措施。

（五）进一步优化展示规划，以提出总体目标、基本功能分区、原则性要求和相应的控制性指标为主，不宜固化具体设计，不宜过于强调与考古遗址公园有关的相关指标。该遗址的展示利用应有序开展，不得大搞建设，不得大规模改变现有地形地貌和景观环境。同时，应优化现有功能分区和道路系统，合理规划游客服务及配套区的选址等，并提出明确的控制性指标。

（六）不同意在紫金城城址范围内恢复水系。在考古遗址公园规划范围内布设现代公共墓地亦不妥。同时，与遗址保护展示无关的“休闲度假服务区”等概念不得在本规划中体现。

（七）补充提出考古研究基地的选址及建设指标。进一步缩减遗址博物馆的规模，提出控制性指标。

（八）强化安防规划，提出该遗址安全技术防范的具体要求。

（九）土地性质调整应符合现有土地政策，根据文物保护展示需求审慎提出，并考虑可操作性。同时，应进一步明确本规划的层级，对周边区域的乡镇建设规划提出明确的指导意见和衔接标准。

（十）加强文字校核，文字表述应清晰、准确，且应做到前后一致、文图一致。

三、请你局指导规划编制单位，根据上述意见对所报规划做进一步修改和完善，经你局核准后按程序另行报批。

国家文物局

2017年5月4日
