# 国家文物局关于岷东大道彭山段建设二期工程——九龙山隧道建设工程涉及江口崖墓保护范围选址的意见

## 关于岷东大道彭山段建设二期工程——九龙山隧道建设工程涉及江口崖墓保护范围选址的意见

办保函〔2017〕339号

四川省文物局：

你局《关于江口崖墓保护范围内进行建设工程的请示》（川文物〔2016〕133号）收悉。经研究，我局意见如下：

一、暂不同意岷东大道彭山段建设二期工程—九龙山隧道建设工程涉及江口崖墓保护范围的选址方案。

二、所报选址及建设方案尚需做以下必要的修改和完善：

（一）进一步明确该建设项目与江口崖墓保护区划的关系，并优化道路选线及施工设计，尽量对所涉及的3座崖墓进行避让。若确实无法避让，应进一步补充说明理由，并研提上述3座崖墓搬迁保护的具体措施，所需经费由工程部门承担。

（二）补充评估九龙山隧道建设及运营所产生震动对江口崖墓墓葬本体稳定性的影响评估，并采取有针对性的减缓措施，以降低不良影响。

（三）补充工程施工中文物临时性保护以及后续运营过程中文物保护的具体措施。

三、请你局指导建设单位，根据上述意见对所报建设方案做进一步修改和完善，并经你局核准后按程序另行报批。

国家文物局

2017年3月28日
