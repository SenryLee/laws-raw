# 国家文物局关于潜口民宅——方氏宗祠坊修缮工程立项的意见

## 关于潜口民宅——方氏宗祠坊修缮工程立项的意见

办保函〔2017〕149号

安徽省文物局：

你局《关于批准潜口民宅方氏宗祠坊修缮工程立项的请示》（皖文物保〔2017〕4号）收悉。经研究，我局意见如下：

一、暂不同意潜口民宅方氏宗祠坊修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）应加强现状勘察和研究，明确文物保存现状、主要病害类型、残损情况等，客观分析基础下沉、构件开裂、风化等病害原因和发展趋势，做好石坊稳定性评估工作，为制定有针对性的保护措施提供依据。

（二）应根据前期勘察结果进一步核实工程范围和工程量，以现状加固为主，严格控制地基基础加固和防风化处理范围,避免过度干预。

（三）应开展前期实验室和现场试验，进一步论证防风化保护技术措施和修复材料的安全性、稳定性和有效性，明确材料配比、工艺技术、施工流程等，补充相关数据说明。

（四）根据工程量合理编制经费预算，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年2月22日
