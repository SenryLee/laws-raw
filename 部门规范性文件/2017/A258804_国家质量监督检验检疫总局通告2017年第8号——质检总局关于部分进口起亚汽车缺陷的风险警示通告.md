# 国家质量监督检验检疫总局通告2017年第8号——质检总局关于部分进口起亚汽车缺陷的风险警示通告

## 国家质量监督检验检疫总局通告

2017年第8号

## 质检总局关于部分进口起亚汽车缺陷的风险警示通告

近期，广东出入境检验检疫局在对进口产品实施安全质量检验监管过程中，发现进口起亚极睿汽车在驻车制动时，驻车制动踏板在全行程的3/4以内达不到有效制动力，不符合国家强制性标准《机动车安全运行技术条件》（GB7258-2012）的要求。消费者在坡道等停车时，如果未对驻车踏板施加足够的行程，可能发生车辆意外滑行事故，存在安全隐患。

据现代汽车（中国）投资有限公司统计，上述质量安全隐患所涉及的车辆包括2016年10月4日至2017年8月24日期间生产制造的进口起亚极睿汽车，共计1760辆。目前，现代汽车（中国）投资有限公司已启动召回计划等相关工作。

为保护我国消费者生命健康和财产安全，根据《进出口商品检验法》及其实施条例和《进出口工业品风险管理办法》的规定，现发布风险警示通告如下：

一、请使用上述车辆的消费者尽快联系就近的授权经销商进行确认并妥当处置。在未确认或者未消除隐患之前，消费者应谨慎使用，操作该款车辆驻车制动时，要将驻车制动踏板踩至极限位置。已经由此缺陷造成损失的消费者应依据消费者权益保护的规定处理，并向所在地出入境检验检疫机构提供必要信息。

二、制造商现代汽车（中国）投资有限公司应尽快组织实施缺陷召回工作，消除缺陷。授权经销商应配合所在地出入境检验检疫机构的调查与监管工作，并及时准确报告召回实施情况。

三、各地出入境检验检疫机构要加强后续监管，督促辖区内进口起亚极睿汽车经销商认真履行召回义务和质量责任。各进口汽车口岸检验检疫机构要对同类进口车型重点监管，发现问题及时报告。

质检总局将继续密切关注该缺陷处置进展，视情况采取进一步监管措施。

质检总局

2017年12月7日
