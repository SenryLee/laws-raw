# 农业部关于政协十二届全国委员会第五次会议第4151号（资源环境类257号）提案答复

## 关于政协十二届全国委员会第五次会议第4151号（资源环境类257号）提案答复

吴鸿委员：

您提出的关于加强农村绿化,促进生态文明建设的提案收悉。现就涉及农业部职能的部分答复如下。

关于美丽乡村建设。美丽乡村建设是深入推进社会主义新农村和美丽中国建设的重大举措。农业部高度重视，按照党中央国务院决策部署，将美丽乡村和生态文明建设相统一，不断加强规化引导，强化公共服务，提升发展内涵，营造发展氛围，以发展休闲农业和乡村旅游作为重要抓手，强化产业支撑、改善乡村环境、增加农民收入。一是注重绿色发展。绿水青山是农村的宝贵资源和独特优势。2016年，国务院印发的《全国农业现代化规划（2016-2020年）》提出，要依托农村绿水青山、田园风光、乡土文化等资源，大力发展生态休闲农业。农业部始终牢固树立绿色发展理念，将生态保护作为美丽乡村建设和休闲农业发展的重要前提，在2017年4月首届全国休闲农业和乡村旅游大会上明确提出以“绿色”为导向的发展方式，遵循绿色发展理念，坚持绿色发展方式。二是加强政策指导。2016年农业部会同财政部等14部门印发《关于大力发展休闲农业的指导意见》（农加发〔2016〕3号），明确了“保护环境、持续发展”的基本原则，要求要遵循开发与保护并举、生产与生态并重的观念，统筹考虑资源和环境承载能力，加大生态环境保护力度。同时，在用地政策、财税支持、拓宽融资、公共服务方面提出了一系列政策措施。三是加大示范引领。农业部积极开展中国美丽休闲乡村推介、美丽乡村试点创建等品牌建设工作，都将绿色作为首要评价标准。例如，中国美丽休闲乡村的第一个基本条件就是要有优美的生态环境，要求必须制定具体有效的环境保护措施，自觉推动绿色发展、循环发展和低碳发展，形成山水林田湖有机生命综合体以及资源节约型空间格局、产业结构、生产方式和生活方式。四是加大扶持力度。2015年，中央财政启动农村一二三产业融合发展试点，2017年继续组织实施并将进一步加大扶持力度。项目积极支持开发和拓展农业多种功能，支持符合条件的休闲农业聚集村等提升公共服务设施，包括农村污水垃圾处理设施等，积极改善农村环境。五是加强规范管理。农业部先后发布《美丽乡村建设标准》《休闲农业术语、符号规范》《农家乐设施与服务规范》等5项标准，成立全国休闲农业专家委员会和中国重要农业文化遗产专家委员会，稳步推进统计监测工作，举办管理和从业人员培训班，多形式开展系列宣传推介活动等，多措并举加强对美丽乡村建设和休闲农业发展的科学化规范化管理。

下一步，农业部将继续牢固树立“创新、协调、绿色、开放、共享”的发展理念，积极推进实施休闲农业和乡村旅游提升工程，在政策落实上加大工作力度，督促地方因地制宜出台具体落实措施，严格要求遵循乡村自身发展规律，平衡产业开发和生态保护的关系，适度开发、科学开发，推进产业发展方式绿色化。通过进一步严格品牌创建条件、完善行业管理标准、加大管理培训力度、积极开展宣传引导等，不断加强统筹规划，强化科学推动，突出发展特色，推动美丽乡村绿色建设、科学规划和规范管理，促进实现农业增效、农民增收、农村增绿。

感谢您对美丽乡村建设的关注，希望今后继续关心我部工作。

农业部

2017年7月25日
