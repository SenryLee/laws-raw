# 国家文物局关于中国共产党第五次全国代表大会旧址建设控制地带内筷子湖泵站及出江管道建设项目的意见

文物保函〔2017〕1963号

湖北省文物局：

你局《关于申报〈筷子湖泵站及出江管道工程（新增管线路由）规划设计方案〉的请示》（鄂文物〔2017〕57号）收悉。经研究，我局意见如下：

一、原则同意所报方案二。

二、对方案提出以下修改意见：

（一）进一步论证说明新泵站选址的依据及必要性。泵房建筑应避让保护范围。

（二）尽可能减少泵站规模，适当降低泵房建筑高度，建议将建筑高度降为一层。同时应补充场地内绿化设计方案。

（三）在施工过程中应密切关注基坑的变形情况，监测振动及基坑降水对文物建筑的影响，制定相应的应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十八条规定，报城乡建设规划部门批准后实施。工程施工期间，你局应加强监管，确保文物安全。

国家文物局

2017年12月7日
