# 农业部办公厅关于“浙江湖州桑基鱼塘系统”入选联合国粮农组织全球重要农业文化遗产有关事项的通知

农办外〔2017〕17号

浙江省农业厅：

你厅关于将“浙江湖州桑基鱼塘系统”列入联合国粮农组织全球重要农业文化遗产（GIAHS）的申请业经我部评审通过，并转报给联合国粮农组织。近日，联合国粮农组织通知我部，该申请已通过相关委员会评审，各项条件符合GIAHS的要求，可以入选全球遗产名录。正式授牌将于2018年在意大利举行的国际遗产会议上予以确认。

请你厅根据农业部《重要农业文化遗产管理办法》（农业部公告第2283号）有关要求，协调地方各级部门，提高思想认识，认真做好后续工作，积极兑现申遗承诺，在组织领导、机构设置、政策创设、资金投入、品牌打造、宣传推介等方面加大工作力度，确保遗产得到保护传承和合理利用，为贯彻乡村振兴战略和加快农业农村发展提供有力支撑。

相关进展情况及时告我部。

农业部办公厅

2017年12月20日
