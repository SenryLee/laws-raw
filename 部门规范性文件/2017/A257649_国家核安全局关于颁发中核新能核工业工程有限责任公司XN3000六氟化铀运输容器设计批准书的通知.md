# 国家核安全局关于颁发中核新能核工业工程有限责任公司XN3000六氟化铀运输容器设计批准书的通知

## 关于颁发中核新能核工业工程有限责任公司XN3000六氟化铀运输容器设计批准书的通知

国核安发〔2017〕283号

中核新能核工业工程有限责任公司：

你公司《3m3六氟化铀运输货包设计审批申请》（公司发〔2014〕29号）收悉。

根据《放射性物品运输安全管理条例》及其配套规章《放射性物品运输安全许可管理办法》的有关要求，我局审查了你公司提交的申请材料，认为你公司设计的XN3000六氟化铀运输容器满足我国相关法规和标准的要求，决定向你公司颁发XN3000六氟化铀运输容器设计批准书，内容如下：

一、法定代表人：孙根利。

二、单位住所：山西省太原市小店区并州南路西一巷9号。

三、设计批准编号：CN/057/H(U)-96(NNSA)。

四、设计安全分析报告版次：D版。

五、运输容器类型：H（U）型、Ⅱ级（黄）。

六、放射性内容物特性：天然六氟化铀，最大装载量为9270kg。

七、设计说明：XN3000六氟化铀运输容器由外部XN3000六氟化铀容器隔热罩和内部XN3000六氟化铀容器两部分组成，主体结构材料为16MnDR。空容器质量约为2092kg，最大外部尺寸为3114mm×1500mm×1380mm。

八、操作要求：运输容器必须按照设计安全分析报告规定的操作程序进行装载准备、装载和卸载。

九、运输方式：道路、铁路、水路。

十、使用环境温度：-40℃～+38℃。

十一、有效期至：2022年10月31日。

十二、本批准书不免除托运人遵守货包途经或抵达国政府任何要求的责任。本批准书不免除托运人遵守国家其他有关运输法规要求的责任。

国家核安全局

2017年11月14日
