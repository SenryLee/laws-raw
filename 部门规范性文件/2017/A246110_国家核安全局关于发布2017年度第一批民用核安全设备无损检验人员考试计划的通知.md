# 国家核安全局关于发布2017年度第一批民用核安全设备无损检验人员考试计划的通知

## 关于发布2017年度第一批民用核安全设备无损检验人员考试计划的通知

国核安函[2017]2号

各无损检验人员考核单位及相关聘用单位：

经研究，现发布《2017年度第一批民用核安全设备无损检验人员考试计划》（见附件）。请各单位通过国家核安全局民用核安全设备无损检验人员资格管理信息系统（http://www.cqcn.org）填写考试报名表，并按相关要求报名参加考试。

附件：2017年度第一批民用核安全设备无损检验人员考核计划

国家核安全局

2017年1月3日
