# 国家文物局关于南京城墙保护范围内龙蟠中路399号东城水岸4栋C单元加装电梯项目的意见

文物保函〔2017〕1715号

江苏省文物局：

你局《关于审批南京市龙蟠中路399号东城水岸 4栋C单元加装电梯项目改造方案的请示》（苏文物保〔2017〕251号）收悉。经研究，我局意见如下：

一、原则同意南京城墙保护范围内龙蟠中路399号东城水岸 4栋C单元加装电梯项目和你局意见。

二、鉴于工程所在的区域可能有地下遗存，方案的施工组织设计中须增加考古工作内容。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《文物保护法》第十七条的有关规定报送江苏省人民政府批准后实施。

四、请你局切实加强协调和工程监管，督促项目管理单位加强施工全过程指导，落实各方责任，确保文物安全；同时在施工中密切关注地下文物遗存情况，如有文物遗存等重要发现，须立即停工上报，并组织研究提出处理意见和保护方案；涉及考古发掘的，需另行填报考古发掘申请书。

国家文物局

2017年10月9日
