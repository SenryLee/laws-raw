# 农业部对十二届全国人大五次会议第5820号建议答复摘要

## 十二届全国人大五次会议第5820号建议答复摘要

关于强化政策保障。通过制定发展规划、出台扶持政策、建立联席会议制度，加强中药材发展顶层设计，促进中药材种植养殖科学发展，提高道地药材综合生产能力，强化部门间协调配合，促进中药材产业发展。下一步，将继续抓好中药材有关规划的落实，加强部门协同配合，争取加大中药材生产扶持力度。

关于强化技术保障。通过建立国家中药材产业技术体系加强科技支撑能力建设，通过组织对中药材种植户的技术培训和指导技术推广先进实用栽培技术，通过中药材GAP实施提高生产标准化程度。下一步，将依托国家中药材产业技术体系，开展关键技术攻关，集成推广一批绿色生产技术模式，大力推进标准化生产。

关于强化投入保障。2011—2016年，通过实施中药材生产扶持项目，支持黑龙江中药企业建设中药材生产基地。在黑龙江省“两大平原”启动了涉农资金整合试点，由黑龙江省自主统筹安排支持中药材发展。下一步，将继续通过落实规划和项目实施，支持黑龙江道地中药材生产基地建设，促进产业链条上下游有效衔接。

关于强化流通保障。通过建设物流基地、构建流通体系、建立物流体系，实时掌握大宗常用药材产销情况，提升中药材物流组织化、标准化和现代化水平，促进产销衔接、以销定产。下一步，将争取更多政策支持，继续加强中药材流通体系建设，提升中药材行业物流现代化水平。

关于强化人才保障。通过新型职业农民培育工程，培养了一批爱农业、懂技术、善经营的新型职业农民；通过组织中药材生产技术交流与培训活动，培养一批掌握中药材GAP规范化种植、化肥农药减量增效等关键技术的专业技术人员。下一步，将进一步加大新型农业经营主体、技术骨干和“乡土”人才培训力度，示范带动中药材生产技术水平提升。

农业部

2017年9月1日
