# 国家文物局关于大工山—凤凰山铜矿遗址—金牛洞古采矿遗址载体加固和排水防涝工程立项的意见

## 关于大工山—凤凰山铜矿遗址—金牛洞古采矿遗址载体加固和排水防涝工程立项的意见

办保函〔2017〕6号

安徽省文物局：

你局《关于批准大工山—凤凰山铜矿遗址—金牛洞古采矿遗址载体加固和排水防涝工程立项的请示》（皖文物保〔2016〕160号）收悉。经研究，我局意见如下：

一、暂不同意大工山—凤凰山铜矿遗址金牛洞古采矿遗址载体加固和排水防涝工程。

二、所报立项报告应做以下必要的修改和完善：

（一）应将本次抢险加固的工程范围严格限定在山洪所引发确实影响金牛洞遗址稳定性和文物安全的险情区段，不得在未开展全面勘察的基础上盲目扩大工程范围。同时，抢险工程应以现状加固和消除安全隐患为主。

（二）应在查明险情成因的基础上，进一步评估遗址本体现状稳定性，并坚持最小干预原则，增强拟采取措施的针对性。对已处于稳定状态的区段，建议仅做好必要的清理与环境整理，不宜进行过多的工程干预。

（三）对确需进行抢险加固的区段，应加强相应的水文、地质勘察和周边古矿井灾害调查，并在此基础上明确工程技术路线。建议围绕受灾遗址周边载体小规模加固、相关古矿井灾害治理和遗址区排水防涝进行工程设计。防水排涝宜采取以截、导水为主，排水为辅的防治措施，防止地表水和地下水向坑内汇集，减少坑内积水和排水量。

（四）矿井洞口保护棚及踏步、道路等的维修不纳入本次抢险工程。

（五）进一步校核工程预算，控制工程规模和范围，科学编制预算。

三、请你局指导立项报告编制单位，根据上述意见对所报立项报告做进一步修改和完善，经你局核准后，按程序另行报批。

四、请你局督促地方人民政府切实加强大工山—凤凰山铜矿遗址的保护和管理，做好日常巡查和看护，确保遗址安全和人员安全。

国家文物局

2017年1月6日
