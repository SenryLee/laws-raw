# 国家文物局关于晋祠文昌宫修缮设计方案意见的函

## 关于晋祠文昌宫修缮设计方案意见的函

办保函〔2017〕632号

山西省文物局：

你局《关于审批晋祠文昌宫修缮设计方案的请示》（晋文物〔2017〕93号）收悉。经研究，我局意见如下：

一、所报修缮方案历经两次修改，仍存在前期勘察和研究不足，残损程度和原因评估不够准确，建造工艺、做法、材料和构造特征等研究分析不当，保护措施针对性差，工程干预量过大，文本深度不够，图纸不规范等问题，我局不同意所报晋祠文昌宫修缮设计方案。

二、晋祠为国务院公布的第一批全国重点文物保护单位，具有极为重要的文物价值。请你局督促、指导有关单位结合我局《关于晋祠文昌宫修缮方案的意见》（办保函〔2015〕69号）、《关于晋祠文昌宫修缮方案的意见》（办保函〔2015〕1537号）要求，重新组织编制设计方案，经你局审核后另行报批。

三、请你局督促地方人民政府切实加强晋祠的日常保养和岁修工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2017年5月24日
