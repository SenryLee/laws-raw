# 水利部关于印发福建福清核电一期工程水土保持设施验收鉴定书的函

水保函〔2017〕141号

福建福清核电有限公司：

根据《开发建设项目水土保持设施验收管理办法》的规定，水利部于2017年5月6日在福建省福清市组织召开了福建福清核电一期工程水土保持设施验收会议。会议认为，该工程水土保持设施基本达到了水土保持法律法规及技术规范、标准的要求，工程质量总体合格，运行期管理责任落实，同意通过验收。现印发福建福清核电一期工程水土保持设施验收鉴定书，请按照验收会议的要求，抓紧完建有关工程并处理好有关问题。

附件：生产建设项目水土保持设施验收鉴定书（编号：2017－12）

水利部

2017年6月27日
