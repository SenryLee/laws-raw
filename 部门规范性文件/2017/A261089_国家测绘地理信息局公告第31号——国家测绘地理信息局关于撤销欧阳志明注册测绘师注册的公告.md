# 国家测绘地理信息局公告第31号——国家测绘地理信息局关于撤销欧阳志明注册测绘师注册的公告

## 国家测绘地理信息局公告

第31号

## 国家测绘地理信息局关于撤销欧阳志明注册测绘师注册的公告

根据《注册测绘师制度暂行规定》，经研究决定，撤销欧阳志明注册测绘师注册，收回注册证和印章（编号163600170（00）），3年内不得再次申请注册。
