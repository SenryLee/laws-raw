# 司法部关于同意中国核工业集团公司开展公司律师工作的函

司发函〔2017〕246号

中国核工业集团公司：

你公司《关于申请开展公司律师试点工作的函》(中核法发〔2017〕15号)收悉。经研究，同意在中国核工业集团公司开展公司律师工作，批准来函所附公司律师试点工作方案。

请根据《司法部关于开展公司律师试点工作的意见》(司发通〔2002〕79号)，将申请公司律师人员名单、基本情况等材料送我部审核。

司法部

2017年9月6日
