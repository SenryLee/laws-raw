# 环境保护部公告2017年第36号——关于2017年上半年新化学物质环境管理登记批准情况的公告

## 环境保护部公告

2017年第36号

## 关于2017年上半年新化学物质环境管理登记批准情况的公告

根据《新化学物质环境管理办法》（环境保护部令第7号）第二十三条规定，现将2017年1-6月批准的新化学物质环境管理登记证情况予以公告。

附件：1.2017年1-6月新化学物质环境管理登记证常规申报批准情况表

2. 2017年1-6月批准的新化学物质常规申报登记证变更明细表

3. 2017年1-6月新化学物质环境管理登记证简易申报基本情形批准情况表

4. 2017年1-6月新化学物质环境管理登记证简易申报特殊情形批准情况表

环境保护部

2017年8月8日
