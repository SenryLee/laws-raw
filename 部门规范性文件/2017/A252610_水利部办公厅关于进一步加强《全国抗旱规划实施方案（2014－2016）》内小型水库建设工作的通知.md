# 水利部办公厅关于进一步加强《全国抗旱规划实施方案（2014－2016）》内小型水库建设工作的通知

办规计〔2017〕73号

有关省、自治区、直辖市水利（水务）厅（局）：

为加快推进《全国抗旱规划实施方案（2014－2016年）》（以下简称《实施方案》）内小型水库建设工作，现将有关工作要求通知如下。

一、切实落实建设主体责任。省级水行政主管部门要进一步督促地方政府强化主体责任，切实加强组织领导，建立健全工作目标责任制，抓好责任落实和责任追究，细化责任分工，明确具体工作目标和奖惩措施，逐库落实责任单位和责任人，确保小型水库建设责任落实到位、责任追究落实到位。

二、尽快落实地方建设资金。截至2017年3月底，规划内小型水库地方建设资金落实率为69．2％，但广西、四川、陕西、甘肃4省（自治区）地方建设资金落实率不足30％。请各地尤其是地方建设资金落实率低的省份省级水行政主管部门，务必要抓紧商省级财政部门进一步落实小型水库省级财政资金；同时，督促市、县政府及时落实小型水库建设资金，保证工程建设资金需求。对于市县财政较为困难的贫困地区，要适当增加省级财政资金补助比例，保证小型水库建设资金足额到位。要督促地方进一步完善资金使用管理制度，加快预算执行进度，确保资金效益充分发挥。

三、抓紧完成建设任务。截至2017年3月底，310座小型水库中全面或主体完工的项目为94座，仅为规划任务的30％，建设进度滞后。其中，山西、内蒙古、河南、湖北、广西7省（自治区）上报无项目完工；贵州、云南、广西、四川等4省（自治区）规划任务共195座，占规划总任务的63％，全面或主体完工项目仅52座。各地省级水行政主管部门要督促地方采取有力措施加快工程建设进度，会同相关地方对规划内小型水库逐库制定详细的工作计划，尤其是对于进度滞后的项目，应责成地方政府和项目法人进一步落实责任单位和责任人，分建设阶段和关键环节明确工作目标和时限要求，倒排工期，优化施工方案，把建设计划详细分解到日，抓紧完成规划内小型水库建设任务。同时，具备条件的项目要及时组织完成验收，水库未经验收，一律不得投入运用。对技术力量薄弱的地区，省级水行政主管部门要加大技术、管理人员等支持力度，必要时派出工作组现场蹲点指导。

四、确保工程质量安全。各地要规范水利建设市场准入，严格实行项目法人责任制、招标投标制、建设监理制、合同管理制和竣工验收制，加强小型水库项目建设全过程质量监控，实行工程建设质量终身责任制和责任追究制。要加强质量安全的全过程控制，做到层层把关、环环相扣，切实把好原材料进口关、施工质量关、设备采购关和竣工验收关，坚决防止重特大事故发生。对完工水库项目，要建立和完善水库运行管理规章制度，落实管护主体和经费，加强水库安全监测，确保工程安全良性运行。

五、高度重视生态保护。小型水库建设要把生态环境保护放在更加突出的位置。《实施方案》内小型水库项目，必须严格履行环境影响评价、水土保持方案审查等审批程序，严禁在主体功能区的禁止开发区实施项目建设，项目建设不得存在重大生态环境影响制约因素，有问题的项目要立即停工整改。要把环评批复要求的各项环保措施是否全面落实作为项目建设和验收的重要内容，确保生态环境保护设施与主体工程同时设计、同时施工、同时投产使用。要加强水库调度运行下泄生态流量的监管，明确监管责任，实行科学调度和梯级调度，切实保障河湖生态水量。

六、加强督导检查。省级水行政主管部门要把督导检查作为推进小型水库工程建设的重要手段，制定小型水库督导检查、稽察工作方案，并于近期抓紧组织对本地区规划内项目进行一次专项督查。对督导检查中发现的问题，要督促责任单位认真分析原因、找准症结，制定切实可行的整改方案，抓紧整改到位。要进一步建立健全奖惩机制，对工作推动不力、问题频发多发的责任人和责任单位，要严肃追究责任。

我部将继续通过《水利规划计划简报（全国小型水库进展情况通报）》，进一步加强对各地小型水库建设的动态跟踪，及时通报，并在地方专项督查工作基础上，适时开展专项调研督导工作。结合调研和各地建设实际进展情况，我部将对存在突出问题的省份向省级人民政府发出督办函。近期，财政部已布置对包括小型水库在内的有关水利项目建设进展情况开展重点绩效评价工作，评价内容包括项目管理、项目产出和项目效果等方面，其中，项目产出即项目建设完成情况为最主要的评价指标。评价结果将直接作为安排今后年度财政预算资金的重要依据。请各地各级水行政主管部门务必高度重视小型水库建设工作，在确保质量和安全的前提下，强力推进工程建设，确保规划任务按要求如期完成。

水利部办公厅
