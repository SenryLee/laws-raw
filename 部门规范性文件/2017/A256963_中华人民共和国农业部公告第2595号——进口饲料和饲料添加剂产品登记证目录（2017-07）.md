# 中华人民共和国农业部公告第2595号——进口饲料和饲料添加剂产品登记证目录（2017-07）

## 中华人民共和国农业部公告

第2595号

根据《进口饲料和饲料添加剂登记管理办法》有关规定，批准韩南生物株式会社等32家公司生产的56种饲料和饲料添加剂产品在我国登记或续展登记，并发给进口登记证（见附件1）。批准咕咕宝（粉体）（Cody-nutro?(Powder)）等12个产品中文和外文商品名称、申请企业名称和生产厂家名称变更（见附件2）。所登记产品的监督检验，按中华人民共和国国家标准或农业部发布的质量标准执行。

特此公告。

附件1.进口饲料和饲料添加剂产品登记证目录（2017-07）

2.换发进口饲料和饲料添加剂产品登记证目录（2017-05）

农业部

2017年10月18日
