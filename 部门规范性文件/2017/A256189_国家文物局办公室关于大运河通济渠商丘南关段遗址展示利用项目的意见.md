# 国家文物局办公室关于大运河通济渠商丘南关段遗址展示利用项目的意见

办保函〔2017〕1122号

河南省文物局：

你局《关于报批通济渠商丘南关段遗址展示利用方案的请示》（豫文物〔2017〕226号）收悉。经研究，我局意见如下：

一、应按照我局《关于大运河通济渠商丘南关段河道驳岸遗迹保护展示工程设计方案的意见》（办保函〔2015〕131号）的要求，抓紧编制大运河通济渠商丘南关段遗址保护管理规划，统筹考虑保护、管理、展示和利用问题。在该规划批复前，暂不同意该展示利用方案及此类大规模建设活动。

二、精简、压缩价值评估，删减与遗址无关的内容。与商丘古城相关的价值阐述、展示利用应主要依托古城开展，在该遗址中不应过多涉及。遗址展示涉及的用地规模过大，建议缩小范围，与本遗址无关的旅游内容，不宜放在本方案中；如属于文物保护范围和建设控制地带内的建设活动，应按照我局行政许可相关要求另行报批。

三、应按照大运河保护管理规划中有关通济渠段的展示要求，准确把握展示原则，进一步明确展示定位。展示内容应主要基于大运河通济渠商丘南关段遗址的相关考古发现，客观、详实地进行展示阐释。大运河、通济渠、宋代生活等仅限于背景介绍，不得喧宾夺主成为展示的主要内容，打造“主题公园”和仿古商业旅游街、滑雪等场景与遗址文化及遗址所处郊野环境不相符，应予调整，同时尽量减少场馆、广场、设施的建设和石材铺装等的使用。

四、应结合商丘市城市总体规划和发展需求分析，客观、审慎地评估该遗址服务于区域经济社会发展的总体定位，使其符合遗址所处的区位特征和实际的城市发展水平，避免过度投资、过度阐释带来的资源浪费。在明确总体定位的基础上，调整景观设计、建构筑物设计的思路和原则。

五、应以恰当手段展示通济渠商丘南关段的走向、范围，以及与古宋河、古宋路等遗址的格局关系。考虑到蓄水对于遗址本体有潜在影响，建议论证地形变化等其他展示手段的可行性。

六、应对遗址尚未开展的考古工作进行评估，适当预留空间。

请你局指导有关单位，按照上述意见对所报方案进行全面调整，分期分项另行报批。

专此。

国家文物局办公室

2017年9月27日
