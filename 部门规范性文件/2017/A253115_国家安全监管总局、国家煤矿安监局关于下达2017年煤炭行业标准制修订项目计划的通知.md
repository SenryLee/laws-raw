# 国家安全监管总局、国家煤矿安监局关于下达2017年煤炭行业标准制修订项目计划的通知

## 国家安全监管总局　国家煤矿安监局关于下达2017年煤炭行业标准制修订项目计划的通知

安监总煤装函〔2017〕57号

中国煤炭工业协会，全国煤炭标准化技术委员会、煤炭行业煤矿专用设备标准化技术委员会、煤炭行业煤矿安全标准化技术委员会：

现将《煤矿水中铜、铅、锌、镉、锰的测定》等23项2017年煤炭行业标准制修订项目计划（详见附件）下达给你们，请抓紧组织实施，并就有关要求通知如下：

一、按照《安全生产标准制修订工作细则》（国家安全监管总局令第9号）要求，制定工作计划，成立标准起草小组，明确专人负责，按期完成标准项目的制修订工作。

二、切实加强对煤炭行业标准起草工作的管理，跟踪督促检查标准项目制修订工作进展情况，及时审查，保证标准制修订质量。

附件：2017年煤炭行业标准制修订项目计划

国家安全监管总局

国家煤矿安监局

2017年7月27日
