# 国家核安全局关于批准阳江核电厂主泵密封保护改造申请的通知

## 关于批准阳江核电厂主泵密封保护改造申请的通知

国核安发〔2017〕150号

阳江核电有限公司：

你公司《关于阳江核电厂主泵密封保护改造申请的请示》（广阳江〔2017〕29号）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的要求，我局对你公司提交的申请文件进行了审评，认为你公司对阳江核电厂主泵密封保护改造的方案是可以接受的，现批准你公司1至4号机组在最近一次大修期间完成相应改造，5、6号机组在首次装料前完成相应变更。

你公司应严格按照我局批准的方案实施变更改造，在运行期间，重点加强对主泵一号密封压差有无异常的监测，确保阳江核电厂运行安全。

国家核安全局

2017年7月18日
