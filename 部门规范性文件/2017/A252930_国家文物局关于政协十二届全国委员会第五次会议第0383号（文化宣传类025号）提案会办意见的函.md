# 国家文物局关于政协十二届全国委员会第五次会议第0383号（文化宣传类025号）提案会办意见的函

## 关于政协十二届全国委员会第五次会议第0383号（文化宣传类025号）提案会办意见的函

办保函〔2017〕592号

广东省人民政府办公厅：

现就李崴委员提出的《关于加强对黄埔军校旧址的维护及申请世界文化遗产的提案》，提出以下会办意见：

一、关于黄埔军校旧址保护维修

黄埔军校旧址位于广东省广州市黄埔区长洲岛，是第一次国共合作时期，孙中山在苏联与中国共产党的帮助下，于1924年创建的革命军官学校。军校在黄埔办到第七期，1930年迁往南京。旧址现存大门、中山故居、孙总理纪念碑、东征阵亡烈士墓、黄埔军校校本部、俱乐部等处，总建筑面积14158平方米。1988年，黄埔军校旧址被国务院公布为第三批全国重点文物保护单位。我局一直以来非常重视黄埔军校旧址的保护利用工作。自2005年以来，我局先后批复和支持实施了黄埔军校旧址文物维修及安防方案，对于促进黄埔军校旧址的保护展示教育工作发挥了重要作用。

下一阶段，我局将会同广东省文物局指导当地人民政府组织编制黄埔军校旧址的文物保护规划，统筹安排文物本体保护、安全防范工程、环境整治和展示利用等工作，对存在险情的文物建筑及时排险抢修，有效改善其文物本体和环境风貌的保存状况。同时，加强对黄埔军校旧址文物价值的研究，充分挖掘黄埔军校革命文化内涵，探索形式多样的展示利用途径，充分发挥其爱国主义教育功能。我局将在技术、资金等方面积极提供支持和帮助。

二、关于黄埔军校旧址申报世界文化遗产

近年来，世界遗产申报工作的难度逐渐加大。根据将于2018年实行的新“限额制”，一个缔约国每年最多只能申报一项世界遗产。同时，世界遗产委员会不断推进世界遗产均衡性的全球战略，在评审世界遗产时，明确向没有世界遗产或世界遗产较少的国家，以及遗产类型较少的项目倾斜，而对世界遗产大国的限制将不断增多。

我国是世界遗产大国，目前拥有世界遗产50项，其中文化遗产35项，居世界第二。世界遗产申报审核评估相关国际专业咨询机构，对我国等世界遗产大国的申报项目，往往提出更高的标准。这就要求我国的申报项目要在各方面做好充分的准备。

按照《保护世界文化和自然遗产公约》及其《操作指南》的规定，申报世界文化遗产的项目，应该具有全世界范围内的突出普遍价值，较好的保存现状，扎实的保护管理基础，以及利益相关者对遗产保护的积极态度。根据申报工作规程，一项遗产要申报成为世界遗产，应该首先列入缔约国的世界遗产预备名单，并需要上报世界遗产中心至少一年，才有资格正式申请列入《世界遗产名录》。

目前，黄埔军校旧址申报世界文化遗产的各项基础工作比较薄弱，主要包括相关研究开展不充分，遗产价值提炼比较欠缺，没有明晰的价值表述，也缺乏对比分析和研究。我局建议应重点开展保护管理规划编制，启动有关突出普遍价值研究工作等。

我局将积极支持广东省有关单位成立黄埔军校旧址申遗的组织机构，帮助、指导地方文物部门编制有关申请材料，并组织专家评审，适时考虑将其纳入《中国世界文化遗产预备名单》。

以上意见供参考。
