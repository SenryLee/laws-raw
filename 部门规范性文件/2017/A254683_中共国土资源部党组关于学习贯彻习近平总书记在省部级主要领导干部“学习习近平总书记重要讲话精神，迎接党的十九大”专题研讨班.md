# 中共国土资源部党组关于学习贯彻习近平总书记在省部级主要领导干部“学习习近平总书记重要讲话精神，迎接党的十九大”专题研讨班上的重要讲话精神的通知

## 关于学习贯彻习近平总书记在省部级主要领导干部“学习习近平总书记重要讲话精神，迎接党的十九大”专题研讨班上的重要讲话精神的通知

国土资党发〔2017〕37号

国家海洋局、国家测绘地理信息局、中国地质调查局及部其他直属单位、各派驻地方的国家土地督察局、部机关各司局：

7月26日-27日，省部级主要领导干部“学习习近平总书记重要讲话精神，迎接党的十九大”专题研讨班在京举办，习近平总书记在培训班开班式上发表了重要讲话（以下简称讲话）。讲话系统总结了党的十八大以来党和国家事业发展的巨大成就和实践经验，深刻阐述了新的历史条件下坚持和发展中国特色社会主义的一系列重大理论和实践问题，深刻阐明了未来一个时期党和国家事业发展的大政方针，提出了一系列新的重要思想、重要观点、重大判断、重大举措，具有很强的思想性、战略性、前瞻性、指导性。讲话既是对十八大以来党中央治国理政伟大实践的科学深刻总结，也是为十九大胜利召开所做的思想理论准备，是坚持和发展中国特色社会主义的政治宣言和行动纲领，为我们扎实做好各项工作提供了根本遵循。

7月28日，部党组召开会议专门传达学习了讲话精神。部直属机关各级党组织和广大党员干部要把深入学习贯彻习近平总书记重要讲话精神作为当前和今后一个时期的重要政治任务，认真学习领会讲话精神，深入领会讲话的重大政治意义、理论意义和实践意义，深入领会讲话的丰富内涵、精神实质和基本要求，并以此指导和推动国土资源管理各项工作。

各级党组织和广大党员要把学习讲话精神与学习习近平总书记系列讲话精神结合起来，联系以习近平同志为核心的党中央治国理政的具体实践，联系党和国家的历史性变革和历史性成就，准确把握习近平总书记关于当前国际国内形势的科学分析、关于5年来党和国家事业发生的历史性变革的深刻阐述、关于新的历史条件下坚持和发展中国特色社会主义重大理论和实践问题的深刻阐述、关于未来一个时期党和国家事业发展大政方针和行动纲领的深刻阐述，深刻理解习近平总书记在坚持全面深化改革、全面依法治国、生态文明建设、国防和军队现代化、中国特色大国外交以及全面从严治党等治国理政各方面提出的新要求，把握思想精髓和核心要义，切实把思想和行动统一到讲话精神上来。

各级党组织和广大党员要通过学习讲话精神，牢固树立“四个自信”，进一步增强“四个意识”，特别是要增强维护核心的思想自觉和行动自觉，自觉在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致，抓好党中央国务院各项决策部署的贯彻落实，全面推进国土资源管理和改革各项工作，以优异成绩迎接党的十九大胜利召开。

请将传达学习情况及时报部直属机关党委。

中共国土资源部党组

2017年8月1日
