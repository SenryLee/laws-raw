# 国家文物局关于上海市文物保护项目检查意见的函

文物保函〔2017〕1836号

上海市文物局：

2017年8月23日，我局组织专家对你市徐家汇天主堂维修工程进行了检查，现将相关情况通报如下：

该项目参与各方形成了较好的协作模式，管理规范有序，工程效果达到文物保护要求，工程资料基本完备。请你局组织、协调相关单位加强地铁运营对文物安全影响的专项监测和评估，继续做好室内装修与文物建筑修缮的衔接，并补充该工程的勘察设计、施工、监理单位资质情况的说明，建议在现场设置反映本次及历史上徐家汇天主堂修缮保护的专题展陈，扎实做好工程资料的整理和工程报告的编写出版。

请你局进一步加强文物保护项目监管，提高方案论证质量和检查力度，督促地方人民政府提高文物保护意识，指导地方各级文物行政部门切实提高文物保护项目管理水平，依法合规做好文物保护项目实施。工程完工后，应按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》履行竣工验收程序。

此函。

国家文物局

2017年11月8日
