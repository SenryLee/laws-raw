# 国家文物局办公室关于延安革命遗址—杨家岭旧址建设控制地带内基础设施完善提升项目设计方案意见的函

办保函〔2017〕1165号

陕西省文物局：

你局《关于在延安革命遗址—杨家岭旧址建设控制地带内实施基础设施完善提升项目的请示》（陕文物字〔2017〕193号）收悉。经研究，我局意见如下：

一、延安革命遗址—杨家岭革命旧址基础设施完善提升项目位于杨家岭革命旧址建设控制地带内，停车场的规模对文物历史环境风貌影响较大，新建服务中心沿山脚展开立面过长。我局暂不同意该项目设计方案。

二、所报方案应作以下修改：

（一）依据陕西省人民政府公布的文物保护区划，并结合2017年8月已编制完成的《延安革命旧址群保护利用展示规划》，进一步充实相关基础设施完善提升项目选址依据，明确所处区域相关管控要求，补充新建建筑选址的合理性，以及视线影响和环境影响分析，同时补充、完善新建停车场、服务用房和旧址大门与保护区划关系说明及图纸。

（二）调整停车场规模，缩小停车场面积，尽可能降低停车场废气及噪音污染，切实加强文物的生态环境保护。

（三）削减新建服务中心建筑体量，避免沿山脚展开立面过长，并严格控制新建建筑的高度。

三、请你局指导有关单位，根据上述意见对杨家岭革命旧址基础设施完善提升项目方案进行修改完善后，按程序另行报批。

专此。

国家文物局办公室

2017年10月12日
