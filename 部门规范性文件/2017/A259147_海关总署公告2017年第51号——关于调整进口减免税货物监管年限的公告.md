# 海关总署公告2017年第51号——关于调整进口减免税货物监管年限的公告

## 海关总署公告

2017年第51号

## 关于调整进口减免税货物监管年限的公告

为支持企业技术改造，加快设备更新，推动产业升级，海关总署决定调整进口减免税货物的监管年限。现将有关事项公告如下：

进口减免税货物的监管年限为：

（一）船舶、飞机：8年；

（二）机动车辆：6年；

（三）其他货物：3年。

监管年限自货物进口放行之日起计算。

本公告自发布之日起施行。

特此公告。

海关总署

2017年10月24日
