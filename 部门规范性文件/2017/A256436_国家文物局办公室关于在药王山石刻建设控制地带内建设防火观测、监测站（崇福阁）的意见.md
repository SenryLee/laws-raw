# 国家文物局办公室关于在药王山石刻建设控制地带内建设防火观测、监测站（崇福阁）的意见

办保函〔2017〕1136号

陕西省文物局：

你局《关于在药王山石刻建设控制地带内建设防火观测、监测站（崇福阁）的请示》（陕文物字〔2017〕168号）收悉。经研究，我局意见如下：

一、所报项目位于药王山石刻建设控制地带内，建设高度、体量、色彩等与药王山历史环境不协调，暂不同意所报项目。

二、补充作为防火观测、监测站功能需求的设计说明。补充说明项目实施的必要性及相关部门批准文件，明确建设、管理单位以及文物保护管理单位的关系，说明城市相关规划、风景名胜区规划等对该区域的管理规定，明确防火责任及建设资金来源等。

三、补充说明药王山石刻保护范围和建设控制地带相关管理规定。根据考古勘探报告，寺台存在早期建筑遗址，如确需建设，建议调整设计思路、另行选址;同时根据考古勘探报告的结果，重新编制文物影响评估报告，客观、准确评估拟建项目对文物本体及周边环境造成的实际影响。

请你局责成相关单位，认真执行《文物保护法》、《文物保护法实施条例》等法律文件中的相关规定，严格控制药王山石刻保护范围和建设控制地带内的建设活动，切实保护文物本体及其周边环境的安全。

专此函复。

国家文物局办公室

2017年10月9日
