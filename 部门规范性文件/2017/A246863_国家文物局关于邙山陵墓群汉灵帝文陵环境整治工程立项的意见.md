# 国家文物局关于邙山陵墓群汉灵帝文陵环境整治工程立项的意见

## 关于邙山陵墓群汉灵帝文陵环境整治工程立项的意见

办保函〔2017〕27号

河南省文物局：

你局《关于邙山陵墓群汉灵帝文陵环境整治工程立项的请示》（豫文物〔2016〕279号）收悉。经研究，我局意见如下：

一、暂不同意邙山陵墓群汉灵帝文陵环境整治工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步明确工程性质，区分本体保护、展示和环境整治工程内容，按程序分别报审。

（二）应以保护规划为依据，明确环境整治和展示的目标、总体思路和控制要求，并结合文陵所处区位、展示前景分析等进一步论证环境整治和展示工程实施的必要性和可行性。

三、请你局指导立项报告编制单位，根据上述意见对所报立项报告做进一步修改和完善，经你局核准后，按程序另行报批。

国家文物局

2017年1月13日
