# 国家发展和改革委员会、国家体育总局、公安部、交通运输部、国家卫生和计划生育委员会、中国人民银行、国家工商行政管理总局、国家新闻出版广播电影电视总局、中国银行业监督管理委员会关于印发《支持社会力量举办马拉松、自行车等大型群众性体育赛事行动方案（2017年）》的通知

## 关于印发《支持社会力量举办马拉松、自行车等大型群众性体育赛事行动方案（2017年）》的通知

发改社会〔2017〕1294号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团发展改革委、体育局、公安厅、交通运输厅、卫生计生委、人民银行、工商局、新闻出版广电局、银监会：

为进一步激发体育消费，着力营造社会力量举办马拉松、自行车等大型群众性体育赛事的良好环境，巩固经济稳中向好发展势头，我们制定了《支持社会力量举办马拉松、自行车等大型群众性体育赛事行动方案（2017年）》。现印发给你们，请认真贯彻执行。
