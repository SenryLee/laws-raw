# 农业部办公厅关于印发《2017年农产品质量安全工作要点》的通知

农办质〔2017〕7号

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）、畜牧、兽医、农垦、农产品加工、渔业（局、委、办），新疆生产建设兵团农业局：

为贯彻落实中央农村工作会议、国务院食品安全委员会第四次全体会议和全国农业工作会议精神及“十三五”国家食品安全规划部署安排，深入推进农产品质量安全监管工作，我部制定了《2017年农产品质量安全工作要点》，现予印发。请结合本地区、本行业实际认真抓好落实。

农业部办公厅

2017年2月6日
