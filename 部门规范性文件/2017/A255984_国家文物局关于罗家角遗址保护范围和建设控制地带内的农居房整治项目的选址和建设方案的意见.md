# 国家文物局关于罗家角遗址保护范围和建设控制地带内的农居房整治项目的选址和建设方案的意见

文物保函〔2017〕1494号

浙江省文物局：

你局《关于要求在全国重点文物保护单位罗家角遗址保护区划内实施农居房整治项目的请示》（浙文物发〔2017〕211号）收悉。经研究，我局意见如下：

一、原则同意罗家角遗址保护范围和建设控制地带内农居房整治项目的选址和建设方案。

二、该建设项目应遵守现有设计，严格按照《罗家角遗址保护规划》要求，进一步明确农居房整治措施、范围和强度，严格控制拆改建筑的规模、高度和体量，优化建筑外观设计，注意与遗址及其周边环境相协调。应结合当地农居房建筑特点和产权人意愿，合理确定建设控制地带内拆改建筑的风貌特色，避免形式统一、僵化，兼顾文物保护和民生改善需要。

三、请你局组织专业考古研究单位，在农居房整治项目涉及罗家角遗址保护范围和建设控制地带的拟建区域，进一步开展必要的考古调查和发掘工作。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

四、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，按照《中华人民共和国文物保护法》第十七条、第十八条的规定，分别报浙江省人民政府和相应的城乡建设规划部门批准。

五、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促农居房产权人切实做好施工过程中的文物保护工作，确保文物安全。

国家文物局

2017年8月23日
