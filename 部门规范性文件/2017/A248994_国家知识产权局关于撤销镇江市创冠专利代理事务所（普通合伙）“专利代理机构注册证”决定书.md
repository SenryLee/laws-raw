# 国家知识产权局关于撤销镇江市创冠专利代理事务所（普通合伙）“专利代理机构注册证”决定书

## 关于撤销镇江市创冠专利代理事务所（普通合伙）“专利代理机构注册证”决定书

国知惩戒决字[2017]7号

机构名称：镇江市创冠专利代理事务所（普通合伙）

机构代码：32287

负 责 人：朱书明

合 伙 人：朱书明、吉李洁、舒佳英

机构地址：镇江市新区丁卯智慧大道668号

设立时间：2016年9月6日

2016年11月，中华全国专利代理人协会上报《关于对镇江市创冠专利代理事务所（普通合伙）朱书明等三人执业证办理事宜的请示函》，其中提出，在审核镇江市创冠专利代理事务所（普通合伙）（以下简称“镇江创冠”）朱书明、吉李洁、舒佳英三名合伙人的专利代理人执业证申请材料时发现，合伙人朱书明、吉李洁、舒佳英存在出租专利代理资质的违法违规行为，提请国家知识产权局作出进一步处理。

经查，2016年8月31日，朱书明、吉李洁、舒佳英向国家知识产权局提交了设立镇江市创冠专利代理事务所（普通合伙）的申请，并提交了合伙协议、专利代理机构设立审批事项告知承诺书等申请材料。经审批，镇江创冠于2016年9月6日取得专利代理机构注册证。负责人：朱书明，合伙人：朱书明、吉李洁、舒佳英，出资额占比分别为50%、30%、20%，机构地址为镇江市新区丁卯智慧大道668号。

2016年10月，镇江创冠向中华全国专利代理人协会提交了朱书明、吉李洁、舒佳英的执业证申请材料，包括三人档案存放证明以及专利代理事务所合伙人聘用协议。

朱书明的聘用协议显示：江苏浩邦知识产权服务有限公司镇江分公司（以下简称“江苏浩邦”）聘用朱书明为新设事务所合伙人，朱书明通过代江苏浩邦持有事务所的股权股份的形式，向江苏浩邦提供其所具备的办所资质，以供江苏浩邦设立及经营事务所使用。江苏浩邦为实际出资人，朱书明不进行实际的资金投入，不参与事务所的经营决策、日常管理及收益分配。江苏浩邦承诺，在使用朱书明办所资质时，使用其提供的所有证书、证件和资料的范围限于设立及经营事务所的过程中，维持事务所专利代理机构资质及开展专利代理业务所必要的事务环节。协议生效期限为江苏浩邦收到朱书明符合办所资质的合格文件之日起至朱书明作为江苏浩邦合伙人2年期满止。协议期间，江苏浩邦支付朱书明顾问费5万元/年，支付方式一年一付。

吉李洁的聘用协议显示：江苏浩邦和常越聘用吉李洁为新设事务所合伙人，江苏浩邦和常越出资筹建事务所，为事务所实际出资人。吉李洁不进行实际的资金投入，不参与事务所的经营决策、日常管理及收益分配。吉李洁持有的股权股份为代常越持有，吉李洁作为名义合伙人加入事务所。吉李洁提供的所有证书、证件和资料使用范围限于设立及经营事务所的过程中，维持事务所专利代理机构资质。协议生效期限为常越收到吉李洁符合办所资质的合格文件之日起至吉李洁作为常越方合伙人2年期满止。协议期间，江苏浩邦和常越支付吉李洁顾问费4.5万元/年，支付方式一年一付。

舒佳英的聘用协议显示：江苏浩邦聘用舒佳英为新设事务所合伙人，舒佳英通过代江苏浩邦持有事务所的股权股份的形式，向江苏浩邦提供其所具备的办所资质，以供江苏浩邦设立及经营事务所使用。舒佳英持有事务所股权股份性质为代江苏浩邦的雷小东持有。江苏浩邦为实际出资人。舒佳英不进行实际的资金投入，不参与事务所的经营决策、日常管理及收益分配。江苏浩邦承诺，在使用舒佳英办所资质时，使用其提供的所有证书、证件和资料的范围限于设立及经营事务所的过程中，维持事务所专利代理机构资质及开展专利代理业务所必要的事务环节。协议生效期限为江苏浩邦收到舒佳英符合办所资质的合格文件之日起至舒佳英作为江苏浩邦合伙人2年期满止，最长不超过26个月。协议期间，江苏浩邦支付舒佳英顾问费4.5万元/年，支付方式一年一付。

在调查中，江苏浩邦对于协议内容予以承认。

以上事实有下列证据材料为证：

一、镇江市创冠专利代理事务所（普通合伙）合伙协议

二、专利代理机构设立审批事项告知承诺书

三、朱书明的聘用协议

四、吉李洁的聘用协议

五、舒佳英的聘用协议

六、关于创冠专利代理事务所的情况说明

根据《中华人民共和国行政许可法》第三十一条的规定，申请人申请行政许可，应当如实向行政机关提交有关材料和反映真实情况，并对其申请材料实质内容的真实性负责。根据《专利代理管理办法》第五条的规定，专利代理机构的合伙人或者股东应当符合具有专利代理人资格，具有2年以上在专利代理机构执业的经历，能够专职从事专利代理业务等条件。

江苏浩邦租用朱书明、吉李洁、舒佳英三人的专利代理人资格证书设立“镇江市创冠专利代理事务所（普通合伙）”。镇江创冠在申请设立过程中，在知晓专利代理机构设立条件、申请要求和法律责任的前提下，作出“申请材料真实有效”等不实承诺，提供虚假的合伙协议，隐瞒事务所的实际出资人、合伙人不符合专利代理管理规定的重要事实，以欺骗的方式取得专利代理机构行政许可，属于《中华人民共和国行政许可法》第六十九条第二款规定“被许可人以欺骗、贿赂等不正当手段取得行政许可”的情形,应当予以撤销。

我局于2017年1月10日发出《关于拟撤销镇江市创冠专利代理事务所（普通合伙）专利代理机构注册证告知书》（国知惩戒函字〔2017〕1号），依法向镇江创冠告知拟撤销其“专利代理机构注册证”以及拟作出撤销事项的事实、理由、依据以及其依法享有的权利。镇江创冠在规定的期限内未提出听证申请以及陈述和申辩。

依据《中华人民共和国行政许可法》第六十九条第二款的规定，我局决定：撤销镇江市创冠专利代理事务所（普通合伙）“专利代理机构注册证”。

当事人如对本决定不服，可以在接到本决定书之日起60日内向国家知识产权局提出行政复议，也可以在收到本决定书之日起6个月内向有管辖权的人民法院提起诉讼。
