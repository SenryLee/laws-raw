# 中华人民共和国农业部公告第2506号——新兽药注册目录

## 中华人民共和国农业部公告

第2506号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准普莱柯生物工程股份有限公司等10家单位申报的鸡新城疫、禽流感（H9亚型）二联灭活疫苗（La Sota株+SZ株）等3种兽药产品为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

批准北京生泰尔科技股份有限公司等2家单位申报的柴胡口服液变更注册，新增靶动物犬监测期3年，并发布修订后的质量标准、说明书和标签，自发布之日起执行。

批准河北科星药业有限公司申报的安乃近注射液增加规格变更注册，质量标准、说明书和标签按照《中国兽药典》（2015版）同品种规定执行。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年3月14日
