# 国家文物局关于石堰坪古建筑群文物保护规划意见的函

## 关于石堰坪古建筑群文物保护规划意见的函

文物保函〔2017〕1256号

湖南省文物局：

你局《关于审批〈石堰坪古建筑群文物保护规划〉的请示》（湘文物报〔2017〕82号）收悉。经研究，我局意见如下：

一、原则同意所报规划。

二、对规划提出以下修改意见：

（一）应根据全国重点文物保护单位石堰坪古建筑群简介核定明确文物本体构成。

（二）完善文物本体残损状况评估，补充山体滑坡、泥石流、洪水等自然灾害对文物建筑的影响评估。

（三）将一类和二类建设控制地带合并为一类建设控制地带，将环境协调区调整为二类建设控制地带。

（四）完善展示利用规划，细化三个片区的展示内容和主题，补充游客流量控制要求。

（五）土地利用规划应明确规划范围内林地和基本农田边界线，并补充对村民宅基地近期和中期的控制标准。

（六）补充该规划与村庄规划、旅游规划等相关规划的衔接要求。

（七）校核规划文本和相关图纸，补充保护区划边界的地理坐标。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行修改完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局将经我局备案的石堰坪古建筑群保护规划报请湖南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，组织有关部门认真贯彻实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

国家文物局

2017年7月19日
