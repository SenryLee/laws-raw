# 国家文物局办公室关于热水墓群文物保护利用设施建设项目的意见

办保函〔2017〕1057号

青海省文物局：

你局《关于热水墓群文物保护利用设施建设项目的请示》（ 青文物局〔2017〕97号）收悉。经研究，我局意见如下：

一、暂不同意热水墓群文物保护利用设施建设项目设计方案。

二、所报方案尚需做以下必要的修改和完善：

（一）应根据热水墓群保护范围和建设控制地带的相关管理规定，进一步降低拟建游客管理中心和管理用房的建筑高度。同时，建议调整游客管理中心的建筑布局，弱化建筑体量，优化建筑形象和色彩设计，以与墓群及其周边环境相协调。其余4处管理用房的建筑形象和色彩设计亦应做适当调整和弱化。

（二）道路应结合当地地形合理设计，适当取高垫低，并尽量采用非硬化或半硬化路面，避免过度干扰墓群及其周边环境。

三、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改和完善，经你局核准后，按程序另行报批。

国家文物局办公室

2017年9月14日
