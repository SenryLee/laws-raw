# 中华人民共和国农业部公告第2488号——新兽药注册目录

## 中华人民共和国农业部公告

第2488号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准天康生物股份有限公司等5家单位申报的猪口蹄疫O型合成肽疫苗（多肽TC98+7309+TC07）等2种兽药产品为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年1月20日
