# 环境保护部办公厅关于开展2017年度环境保护科学技术奖推荐工作的通知

## 关于开展2017年度环境保护科学技术奖推荐工作的通知

环办科技函[2017]622号

各直属单位：

根据环境保护科学技术奖改革的有关要求，2017年度环境保护科学技术奖采用专家提名和我部直属单位推荐两种方式进行推荐。请各直属单位依照中国环境科学学会《关于开展2017年度环境保护科学技术奖项目征集工作的通知》（中环学发〔2017〕23号，见附件）的有关要求开展推荐工作。

由我部直属单位推荐的参评成果仅限于本单位为第一完成单位且本单位工作人员为第一完成人的成果。请各单位严格把关，保证推荐工作公平、公正、公开。

特此通知。

附件：《关于开展2017年度环境保护科学技术奖项目征集工作的通知》（中环学发〔2017〕23号）

环境保护部办公厅

2017年4月24日
