# 国家邮政局办公室关于促进2017年民族地区邮政业健康发展的实施意见

国邮办发〔2017〕14号

各省、自治区、直辖市邮政管理局：

我国是统一的多民族国家，少数民族有1亿多人口，民族地区占国土面积的64%，民族地区经济社会发展水平直接关系到国家改革发展大局，关系到全面建成小康社会的整体进程。为贯彻落实《交通运输部 国家民委关于贯彻<民族区域自治法>推进民族地区交通运输健康发展的意见》要求，促进民族地区邮政业健康发展，现提出如下意见：

一、加快推进建制村直接通邮。按照量化推进、重点考核、协调政策、争取保障的工作思路，研究制定推进建制村直接通邮工作方案，明确政企双方职责，健全考核评估体系，统筹优化农村地区邮政及社会资源配置，积极协调争取有关政府部门给予重视和支持，确保民族地区直接通邮服务全覆盖、可持续，充分发挥邮政服务地方经济发展、促进民族地区安定有序的支撑作用。2017年全国建制村直接通邮率提升2个百分点，达到96%。

二、加快推进邮政包裹按址投递。贯彻实施新修订的《邮政普遍服务》标准，督促邮政企业加大对民族地区运输和投递车辆的投入，优化作业流程，缩短包裹传递时限，改进投递方式，提升包裹投递服务质量。县级以上城区普通包裹实行按址实物投递，乡镇人民政府所在地单件重量5千克（含）以内的普通包裹实行按址实物投递，乡镇其它地区5千克（含）以内的普通包裹实行投递到村邮站、村委会等接收邮件的固定场所。

三、加快推进农产品进城示范项目。充分发挥邮政业在国家服务“三农”、精准扶贫战略中的经济社会效能，加快民族地区“农产品+大同城寄递”区域服务模式创新，助力地方政府培育一批经济效益好、可持续发展、带动脱贫、特色鲜明的农产品进城示范项目。支持邮政企业“一城一味”助农行动，发挥邮政在乡优势，探索邮政自营农产品返城标准，加强农产品进城绿色包装研究。支持快递企业“一地一品”助农行动，推进快递下乡，完善农产品流通渠道。建立季度报告制度，跟踪分析农产品配送业务发展情况，及时协调解决发展中存在的问题。

四、加快推进邮政农村电商体系建设。贯彻落实邮政普遍服务基础设施布局规划，加强中央投资项目行业审查，继续实施西部和农村地区邮政普遍服务基础设施建设工程，并覆盖至边境地区，不断强化邮政普遍服务能力。鼓励和支持邮政企业参与承担农村电子商务建设，依托“邮乐网”“邮掌柜”系统、便民服务站和分销渠道资源，打造民族地区线上线下一体化的邮政电商O2O平台。支持邮政企业依托县、乡、村三级邮政基础设施，科学布局仓储网络，推动民族地区农村电商邮政寄递网建设。改扩建地市和县级配送中心，建设市（县）级农村电商运营中心；购置配送车辆，提升邮政乡镇网点服务电商配送能力；整合村级邮政服务站点，加载村级电商服务功能或配备自助服务设施，构建统一的邮政农村电商公共服务体系。2017年全国建设具备信息化功能的村邮乐购站点5万个以上。

五、加快推进快递网点在乡镇全覆盖。加快提升民族地区乡镇快递网点的覆盖率，健全农村快递末端网点，引导快递企业合理规划快递节点布局，在少数民族特色乡镇、交通枢纽乡镇等地区建设高标准服务网络，提高快递网点均衡度和稳定性，实现民族地区县乡基本覆盖。鼓励第三方设置快递服务平台，为多家快递企业集中开展快件揽收投递服务。支持快递企业利用农家店、农村综合服务社、农产品购销代办站等开展投递服务。2017年末全国乡镇快递网点覆盖率提升5个百分点，达到85%。

六、加快推进关联产业融合协同发展。鼓励快递企业与电商企业深度融合，争取民族地区电商快递产业发展政策,建立政策共享机制。鼓励快递企业与农村商贸流通企业、供销合作社等共同制定运输配送计划，发展民族地区共同配送。鼓励寄递服务市场主体间信息互联互通、网络资源互惠共享，建立完善民族地区农产品进城、工业品下乡双向流通渠道，为农村电子商务提供方便快捷有效的寄递服务。支持农村邮政网络资源与交通运输资源的综合利用，结合民族地区资源特点，引导邮政和快递企业利用农村地区客运站、货运站等交通运输基础设施，建设仓储场地、小型分拨处理设施，推动合作共赢。支持邮政和快递企业积极探索客运班车代运邮件（快件）的模式，提升农村地区邮政服务时效和频次。

七、加强组织保障确保取得实效。各级邮政管理部门要增强政治意识和全局意识，高度重视民族地区邮政和快递服务工作，建立完善促进邮政业健康发展的组织协调机制，采取有针对性的配套措施，提高政策的精准度，确保国家各项民族政策在行业内落到实处。要加强与民族地区发改、财政、国土、商务、交通、农业、供销等部门的工作对接，争取在规划、财政、土地、项目、金融等方面给予支持。邮政和快递企业要根据本意见，坚持市场主导、政府引导原则，充分发挥主观能动性，主动对接邮政管理部门，形成政企合力，推动民族地区邮政业健康发展。各省局要于每季度末将有关工作情况及数据资料报送国家邮政局普遍服务司。
