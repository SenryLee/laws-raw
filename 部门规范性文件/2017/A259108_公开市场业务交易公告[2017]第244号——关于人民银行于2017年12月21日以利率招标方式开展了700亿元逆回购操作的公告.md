# 公开市场业务交易公告[2017]第244号——关于人民银行于2017年12月21日以利率招标方式开展了700亿元逆回购操作的公告

## 公开市场业务交易公告

[2017]第244号

人民银行于2017年12月21日以利率招标方式开展了700亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 300亿元 | 2.50% |
| 14天 | 300亿元 | 2.65% |
| 28天 | 100亿元 | 2.80% |

中国人民银行公开市场业务操作室

二〇一七年十二月二十一日
