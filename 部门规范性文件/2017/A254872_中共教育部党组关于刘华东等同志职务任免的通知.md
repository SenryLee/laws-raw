# 中共教育部党组关于刘华东等同志职务任免的通知

教党任〔2017〕177号

中共中国石油大学（华东）委员会：

经与中共山东省委商得一致，2017年7月24日研究决定：

刘华东同志任中共中国石油大学（华东）委员会副书记，张玲玲同志任中共中国石油大学（华东）委员会常委，操应长同志任中共中国石油大学（华东）委员会委员、常委；免去孙海峰、王瑞和、查明同志的中共中国石油大学（华东）委员会常委职务。

中共教育部党组

2017年8月1日
