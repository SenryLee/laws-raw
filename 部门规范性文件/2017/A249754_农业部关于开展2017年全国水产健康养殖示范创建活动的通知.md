# 农业部关于开展2017年全国水产健康养殖示范创建活动的通知

农渔发〔2017〕18号

各省、自治区、直辖市及计划单列市渔业主管厅（局），新疆生产建设兵团水产局：

为贯彻落实2017年中央1号文件精神和《农业部关于推进农业供给侧结构性改革的实施意见》（农发〔2017〕1号）总体部署，加快推进水产养殖提质增效、绿色发展，我部决定2017年继续组织开展全国水产健康养殖示范创建活动。现将有关事项通知如下。

一、工作目标

创建农业部渔业健康养殖示范县（以下简称示范县）10个以上；创建农业部水产健康养殖示范场（以下简称示范场）500个以上，其中辽宁、江苏、安徽、江西、山东、湖北、湖南、广东等8省创建30个以上，河北、吉林、黑龙江、浙江、福建、河南、广西、海南、四川等9省（区）创建20个以上，其余省份（包括大连、青岛、宁波、新疆生产建设兵团）创建10个以上；完成对2017年底到期的1720个示范场（详见农办渔〔2012〕139号和农办渔〔2012〕154号文件）的复查。

二、创建重点

2017年重点围绕以下方面组织开展创建活动。

（一）突出依法规范管理，不断提升养殖管理水平。依法建立健全养殖生产相关管理制度，细化养殖设施设备管理、水产品生产记录、投入品使用记录和安全使用、病害防控、养殖废水处理、水产品质量安全自检等制度规范等，明确具体操作流程，加快推动水产养殖标准化进程。

（二）突出基础设施建设，提升健康养殖保障能力。根据创建工作需要，加强养殖池塘标准化、规模化改造，完善循环用水、水质净化、废水资源化处理等设施设备，优化厂区环境；调减近岸过密投饵网箱养殖，加强离岸深水抗风浪网箱建设；配备水质监控、疫病防控、质量检测装备，推广物联网技术和相关设施设备建设。

（三）突出绿色发展理念，全面提升水产品质量和效益。紧紧围绕推进渔业供给侧结构性改革的工作主线，以绿色发展为导向，推广生态、免疫的病害防控方法和养殖不用药理念，把增加绿色优质水产品供给放在突出位置，强化品牌效应，不断提升水产养殖质量和效益。

三、工作安排

（一）示范县创建

示范县创建为全年连续性工作，继续按照《农业部关于开展农业部渔业健康养殖示范县创建活动的通知》（农渔发〔2013〕32号）文件执行。我部会同有关省级渔业主管部门安排对申请创建的县（市、区）进行实地指导，对省级初审合格的进行验收，年底前公布第三批示范县名单。

（二）示范场创建和复查

1.4—5月，省级渔业主管部门按照本通知精神，制定本地区示范创建实施方案，抓好动员部署，并组织辖区内养殖单位申报参加示范创建活动，申报材料逐级报省级渔业主管部门备案。

2.6—10月，省级渔业主管部门加强指导和动员，发动各创建单位自主开展生产条件改造、装备升级、完善各项管理制度、技术示范和培训等创建工作，并适时按照《农业部水产健康养殖示范场评分表（2017年版）》（附件1）相应标准进行验收（复查），结果在省级渔业主管部门官网上公示无异议后函报我部。

3.11—12月，我部对各地验收结果进行审核，发文公布示范场名单。

四、有关要求

（一）加强组织领导。全国水产健康养殖示范创建活动由农业部统一领导，部渔业渔政管理局组织实施。各省（区、市）渔业主管部门负责组织开展本辖区创建活动和具体验收（复查）工作。省级渔业主管部门主要负责人要切实加强对示范创建工作的领导，推进体制机制创新，及时解决好示范创建工作中存在的困难和问题，确保示范创建工作顺利进行，推动水产养殖供给侧结构性改革取得突破性进展。

（二）抓好任务落实。各省级渔业主管部门要结合本地区实际研究制定示范创建实施方案，逐项明确时间表、路线图、责任人。省级验收（复查）工作组要做到实地考核、逐条评价、严格把关、宁少毋滥，并对验收（复查）结果负责，省级渔业主管部门把好审核关。实行示范场、示范县动态管理，对工作中发现示范场（示范县）违反法律法规规定、不再符合示范条件的，要及时报告我部取消其称号，并对其违法行为依法查处。我部将组成若干工作组，对各地示范创建工作进行实地考察和督导，并对活动组织工作情况进行通报。

（三）加大政策扶持。中央财政渔业油补政策调整专项转移支付深水抗风浪养殖网箱推广补贴资金，优先安排水产健康养殖示范创建单位。鼓励中央财政渔业油补政策调整一般性转移支付资金向水产健康养殖示范创建单位和县倾斜，重点支持池塘标准化和工厂化循环水改造等水产养殖基础设施建设。各地也要积极争取支渔惠渔资金优先支持水产健康养殖示范创建工作。

（四）营造创建氛围。要综合运用广播、电视、网络、手机短信、微信、报刊、标语等手段，大力宣传水产健康养殖示范创建活动，不但要让广大养殖场户知晓、提高对示范创建活动重要性的认识，更要扩大健康养殖产品的知名度和品牌效应。要大力宣传示范创建的经验做法、典型模式、技术成果和工作成效，充分发挥示范带动作用，为加快现代水产养殖业发展增添新的亮点。

（五）及时上报信息。请于6月15日前将上半年示范创建工作总结正式函报我部渔业渔政管理局；从7月份开始，于每月3日前上报上个月量化指标进展情况。示范场验收（复查）工作全部完成后，请于10月31日前将《农业部水产健康养殖示范场评分表（2017年版）》（加盖公章）、《农业部水产健康养殖示范场基本信息汇总表》（附件2，加盖公章）及验收意见和工作总结正式函报我部渔业渔政管理局，同时将汇总表的电子版（Excel版）发送至aqucfish@163.com。

各单位在创建活动中如有问题，请与我部渔业渔政管理局联系。联系人：朱健祥 陈家勇，联系电话：010-59192918、59192930。
