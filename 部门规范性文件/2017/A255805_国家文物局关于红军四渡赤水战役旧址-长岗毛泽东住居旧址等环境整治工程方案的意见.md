# 国家文物局关于红军四渡赤水战役旧址-长岗毛泽东住居旧址等环境整治工程方案的意见

文物保函〔2017〕1376号

贵州省文物局：

你局《关于在全国重点文物保护单位红军四渡赤水战役旧址-长岗马店会议旧址、长岗毛泽东住居旧址、长岗红军医院旧址实施环境整治工程的请示》（黔文物呈〔2017〕22号）收悉。经研究，我局意见如下：

一、原则同意所报方案。

二、对该方案提出以下修改意见：

（一）深化文物环境风貌影响评估，场地铺装及绿化景观设计应与文物历史环境风貌相协调。

（二）充分利用现有构筑物进行乡土化景观设计，避免过度园林化和景观世俗化，并补充相关设计说明。

（三）正面临街不宜设置钢丝网围栏，建议采用栅栏、绿篱等方式进行隔离。

（四）进一步优化旧址与道路、民居紧邻节点的处理，注意把控场地历史尺度。

（五）方案中应明确管理用房的位置、形式、体量、高度等，管理用房不应破坏文物环境风貌。

三、请你局指导相关单位根据上述意见对方案进行修改完善，按照《中华人民共和国文物保护法》第十七条的规定，经省政府批准后实施。工程施工期间，应加强工程监管，确保文物安全。

国家文物局

2017年8月9日
