# 国家安全监管总局办公厅关于2017年第二季度政府网站抽查情况的通报

安监总厅宣教函〔2017〕119号

各省级煤矿安全监察局，总局和煤矿安监局机关各司局，应急指挥中心：

按照国务院办公厅有关文件要求，现将国家安全监管总局2017年第二季度政府网站抽查情况通报如下：

一、 抽查总体情况

总局组织第三方机构，于2017年5月对负责普查范围内政府网站进了季度抽查，共抽查了5家省级煤矿安监局网站，按照《国务院办公厅关于开展第一次全国政府网站普查的通知》确定的普查标准，采用“自动扫描+人工复核”相结合的方式进行检查，逐一打分。

抽查结果显示，2家网站综合评定为合格，分别为湖北煤矿安监局网站、甘肃煤矿安监局网站；有3家网站综合评定为不合格，分别为山西煤矿安监局网站、吉林煤矿安监局网站、黑龙江煤矿安监局网站。

本次综合评定为不合格的网站将被列入今后重点抽查监测对象。

二、 发现的主要问题

一是在网站可用性方面。被抽查的5家网站中，1家网站监测截止日期前7天内首页打不开次数占全部监测次数的3.64%；2家网站首页存在不能正常访问的链接；1家网站因为同时存在首页打不开情况和大量不能正常访问的链接等，扣分超过40分。被抽查的5家网站全部存在不能正常访问的链接。二是信息更新方面。3家不合格网站中，1家网站存在空白栏目数量超过5个，被单项否决；1家网站存在不及时更新栏目数量超过10个，被单项否决；2家合格网站中，1家网站存在个别不及时更新栏目和空白栏目问题。三是互动回应、政务服务方面。有4家网站监测时间点前1年内相关政务咨询栏目无有效信息展示；3家网站未开设调查征集类栏目；1家网站“责任清单”栏目不可用；1家网站《办事指南》栏目要素缺失。

三、有关网站整改措施

一是大力清除不可用链接。完善网站互动回应功能。已不再有效的不可用链接，修复不能正常访问的不可用链接，对网站进行技术问题排查，及时解决自动链接错链问题。二是调整网站栏目设置，删除或合并不能及时更新维护的栏目；增设互动回应栏目，搭建网民互动交流平台，不断优化网站互动服务功能。三是推动网站改版升级。要以此次抽查监测为契机，加大资金投入，加强专业人员力量，推动网站改版升级。

四、下一步工作要求

（一）强化对网站建设工作重要性的认识。近年来，党中央、国务院高度重视政府网站建设，2016年起陆续出台有关规范网站建设的制度文件，并对各政府网站进行常态化抽查监测，抽查结果公开通报。各单位要高度重视网站建设，把其纳入日常工作的重要部分，明确责任单位、责任人员，不断增加资金投入。

（二）持续规范网站管理，不断提升工作水平。网站建设是一个常态化、动态性工作，需持续改进。各单位要不断强化制度建设，规范内容发布，严格审核把关，强化日常管理。在不断强化网站人员力量的基础上，采取各种形式加强对网站管理人员、技术维护人员和信息采编人员综合能力、专业技能等方面的培训，提高建网、管网工作水平。

（三）抓紧上移已撤销网站的相关内容。当前，各省级煤矿安监局驻地监察分局都已按照有关要求，撤销了分局网站，但仍有部分分局未将相关信息内容纳入所属省级煤矿安监局网站。有关单位要精心设计页面或栏目，及时更新内容，尽快完成信息上移工作。

（四）大力推进网站改版升级。为适应网站建设的新形势、新任务、新要求，当前一些网站正在进行改版升级，一些网站改版升级正在筹备之中。各单位要将推进网站全面改版升级作为当前一个重要任务来抓，全力消除“不及时、不准确、不回应、不实用”问题，不断优化版面设计，完善栏目配置，提升互动功能，增强服务成效，把网站质量水平提升到新高度。
