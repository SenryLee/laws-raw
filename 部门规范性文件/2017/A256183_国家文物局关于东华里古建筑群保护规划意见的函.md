# 国家文物局关于东华里古建筑群保护规划意见的函

文物保函〔2017〕1708号

广东省文物局：

你局《关于全国重点文物保护单位东华里古建筑群保护规划的请示》（粤文物请〔2016〕67号）收悉。经研究，我局批复如下：

一、原则同意所报修改后的东华里古建筑群保护规划。

二、对该规划提出以下修改意见：

（一）梳理保护对象和文物构成，明确文物认定标准，厘清文物建筑和非文物建筑，进一步加强文物价值研究。

（二）完善现状评估，补充对“历史建筑”、“街巷”的评估内容；补充保护区划、基础设施等专项评估内容。

（三）结合已批复文物保护项目内容，细化文物本体保护措施，并区分文物建筑和非文物建筑的保护措施。

（四）细化环境整治内容，保护范围和建设控制地带的整治内容应分别阐述。

（五）梳理展示利用规划，明确展示利用强度。

（六）进一步梳理规划文本，增强图文对应。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的东华里古建筑群保护规划报请广东省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好东华里古建筑群的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年9月29日
