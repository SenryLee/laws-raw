# 国家文物局关于新四军军部旧址——政治部旧址修缮工程设计方案的意见

## 关于新四军军部旧址——政治部旧址修缮工程设计方案的意见

办保函〔2017〕429号

安徽省文物局：

你局《关于审批新四军军部旧址——政治部旧址修缮工程设计方案的请示》（皖文物保〔2017〕25号）收悉。经研究，我局意见如下：

一、所报方案需进行以下必要的修改和完善：

（一）深化价值评估，补充说明军部旧址整体情况，以及政治部旧址与新四军军部旧址的关系。

（二）深化现状勘察，详细记录文物建筑形制、布局、构造特征及原始材料、做法，补充关于建筑残损程度、范围、位置等的量化说明及产生根源分析，结合历次修缮对文物的改变，进一步深化文物保存现状评估，为制定针对性修缮措施提供科学依据。

（三）坚持最小干预原则，严格控制工程范围和工程量。进一步论证屋面添加现代防水卷材的必要性和可行性，并补充添加卷材后防瓦片下滑措施。注意保留庭院景观历史风貌，原则上不得随意改造。进一步论证庭院整治中移栽乔木的依据和必要性。

（四）细化椽粘补等修缮措施的工程做法说明，注意对原材料、原工艺的传承。补充说明墙体粉刷的材料、工序做法及防脱色、生霉措施，补充现有外墙面霉点的处理措施。注意外墙体表面不宜抹灰做旧。补充柱础移位处理措施。明确木构件表面油饰所使用的桐油种类。铁箍加固木柱应避免嵌入柱内。

（五）进一步校核文本和图纸，认真纠正文本内容前后不对应，图文描述不一致，夹杂与本工程无关内容等问题。在勘察图纸中补充文物残损量和修缮量等量化标注，并加强病害细节与照片之间的对应；补充整体排水图。总平面图应客观真实反映文物及其环境现状，补充旧址周边道路、建筑等环境要素及指北针。在设计图纸中补充构件尺寸标注，以及采用木杆连接加固墙体与木构件的措施详图；在屋面防水构造图中明确采用望砖或望瓦。

（六）补充白蚁病害勘察，并考虑委托专业机构编制蚁害防治方案，另行上报。

二、请你局指导有关单位，根据《文物保护工程设计文件编制深度要求（试行）》和上述意见对方案进行修改和完善，并根据我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）要求，组织专家或委托专业机构进行方案技术评审，依据评审意见进行审批。
