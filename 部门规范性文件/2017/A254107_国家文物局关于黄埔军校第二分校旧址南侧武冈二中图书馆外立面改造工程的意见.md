# 国家文物局关于黄埔军校第二分校旧址南侧武冈二中图书馆外立面改造工程的意见

## 关于黄埔军校第二分校旧址南侧武冈二中图书馆外立面改造工程的意见

办保函〔2017〕881号

湖南省文物局：

你局《关于审批〈黄埔军校第二分校旧址南侧武冈二中图书馆外立面提质改造设计方案〉的请示》（湘文物报〔2017〕67号）收悉。经研究，我局意见如下：

一、黄埔军校第二分校旧址2013年被国务院列为第七批全国重点文物保护单位，从申报材料看，迄今尚未由湖南省人民政府依法划定公布保护范围或确认沿用1996年列为省保单位时确定的保护范围，也未划定建设控制地带，其所谓保护区划内建设工程项目行政许可目前缺乏基本法定前提，我局不能审核黄埔军校第二分校旧址南侧武冈二中图书馆外立面提质改造设计方案。

二、请你局加强对黄埔军校第二分校旧址保护的指导，夯实文物保护“四有”基础工作，并提请湖南省人民政府按照文物保护法律法规的要求，尽快划定公布黄埔军校第二分校旧址全国重点文物保护单位保护范围并报我局备案，同时抓紧推进旧址文物保护规划制定工作，为提升旧址文物保护、利用、管理水平提供有力保障。

专此函复。

国家文物局

2017年7月26日
