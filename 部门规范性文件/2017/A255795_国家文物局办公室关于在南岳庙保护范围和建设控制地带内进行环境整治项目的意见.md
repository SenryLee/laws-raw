# 国家文物局办公室关于在南岳庙保护范围和建设控制地带内进行环境整治项目的意见

办保函〔2017〕1022号

湖南省文物局：

你局《关于审批〈南岳庙东侧围墙暨东华门环境整治与提质改造设计方案〉的请示》（湘文物报〔2017〕104号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位南岳庙保护范围内，设计依据不足，文本深度不够，我局暂不同意该项目。

二、对所报方案提出以下修改意见：

（一）应严格按照《中华人民共和国文物保护法》和《南岳庙保护规划》关于南岳庙保护范围和建设控制地带的相关管理规定、具体控制要求，进一步明确环境整治目的，突出南岳庙文物价值和历史格局等的保护。加强历史研究，核实项目性质，补充说明方案关于项目周围场地整改及环境整治的具体内容，尽量减少对文物及周边环境的影响。

（二）补充《南岳庙保护规划》中关于东侧围墙和东华门的相关内容及所在区域的相关管理规定，核实东华门和围墙与文物建筑的关系。根据历史研究及考古勘探结果，确定南岳庙围墙的具体位置，不同意没有历史依据的新建。

三、请你局组织相关单位根据所提意见，对项目方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2017年8月31日
