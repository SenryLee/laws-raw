# 中共国土资源部党组关于赵凤江等3名同志职务任免的通知

国土资党任〔2017〕9号

各省、自治区、直辖市及副省级城市国土资源主管部门，新疆生产建设兵团国土资源局，解放军土地管理局，国家海洋局、国家测绘地理信息局，中国地质调查局，武警黄金指挥部，部其他直属单位，各派驻地方的国家土地督察局，部机关各司局：

部党组2017年1月24日研究决定：

赵凤江任国家土地督察上海局副专员（试用期一年），免去其国家土地督察上海局副巡视员职务；

免去韩和平财务司巡视员职务，退休；

免去崔波中国地质博物馆纪委书记职务，退休。

中共国土资源部党组

2017年2月9日
