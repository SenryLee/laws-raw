# 中共教育部党组关于彭岚等同志职务任免的通知

教党任〔2017〕203号

中共电子科技大学委员会：

经与中共四川省委商得一致，2017年8月31日研究决定：

彭岚同志任中共电子科技大学委员会委员、常委、副书记、纪律检查委员会书记，靳敏同志任中共电子科技大学委员会副书记，徐红兵同志任中共电子科技大学委员会常委；免去罗佳慧同志的中共电子科技大学委员会副书记、常委、纪律检查委员会书记职务。

中共教育部党组

2017年9月8日
