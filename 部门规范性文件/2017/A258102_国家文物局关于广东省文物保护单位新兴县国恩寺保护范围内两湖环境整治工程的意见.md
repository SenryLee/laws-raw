# 国家文物局关于广东省文物保护单位新兴县国恩寺保护范围内两湖环境整治工程的意见

文物保函〔2017〕1881号

广东省文物局：

你局《关于在广东省文物保护单位新兴县国恩寺保护范围内的两湖实施环境整治工程的请示》（粤文物审〔2017〕152号）收悉。经研究，我局意见如下：

一、原则同意广东省文物保护单位新兴县国恩寺保护范围内两湖环境整治工程和你局意见。

二、对所报项目提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》和广东省人民政府关于新兴县国恩寺保护范围的相关管理规定，严格控制整治范围和工程量，尽量减少对文物本体及其环境的影响。

（二）加强历史研究，并开展必要的考古工作，明确国恩寺及周边环境的空间格局、水系植被、地形地貌等，确定相关历史环境要素。文物保护范围内的环境整治措施应按照最小干预原则，充分尊重文物历史环境，采用当地传统材料和做法，绿植应尽量采用地方树种，与文物景观环境相协调，避免对文物及历史环境造成干扰。

（三）应明确标示国恩寺现有围墙走向，说明两湖距离围墙的最小距离，计算相关部位的驳岸放坡，科学评估两湖在不同季节的地下水对国恩寺建筑及其所在山岗的影响。

（四）不得在文物保护范围内进行其他挖掘作业。

（五）应充分考虑建设施工对文物安全的影响，制定必要的文物保护措施和应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十七条的规定报广东省人民政府批准。施工中应加强监管，确保文物及环境安全。

国家文物局

2017年11月21日
