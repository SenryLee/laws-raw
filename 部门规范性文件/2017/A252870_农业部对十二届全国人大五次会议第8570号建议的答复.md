# 农业部对十二届全国人大五次会议第8570号建议的答复

## 对十二届全国人大五次会议第8570号建议的答复

农办议〔2017〕102号

阳国秀等5名代表：

你们提出的关于加大对草食牧业发展支持力度的建议收悉。经商财政部，现答复如下。

一、关于扩大秸秆养畜项目和基础母牛扩群项目实施范围

为推动种养业有机结合、促进秸秆综合利用，中央财政在1992—2014年实施秸秆养畜项目，累计建设国家级秸秆养畜示范县项目604个。为调动饲养肉牛基础母牛积极性，推进肉牛适度规模养殖， 促进肉牛产业持续健康发展，2014年起中央财政安排畜牧发展扶持资金，支持包括湖南在内的15个省份开展肉牛基础母牛扩群增量工作。2017年起，中央财政农业生产发展资金主要采取“大专项+项目清单”方式切块下达，由地方自主选择扶持的主导产业和支持的关键环节。你们所提建议，可以由地方在政策框架内统筹考虑支持。

二、关于加大对地方特色品种的扶持力度

畜禽遗传资源是人类赖以生存和发展的战略性资源，对于畜牧业可持续发展具有重要意义。为保护畜禽遗传资源，实现畜牧业可持续发展，保障国家种质资源安全，中央安排资金重点支持列入国家级畜禽遗传资源保护名录的畜禽品种保护工作。中央财政在农业部部门预算中专门安排了物种资源保护费，支持种质资源保护；中央预算内投资安排现代种业提升工程畜禽良种项目，支持建设完善一批制（繁）种基地、种质资源场和国家畜禽基因库。在特色品种开发利用方面，中央财政农业生产发展资金支持优势特色主导产业发展，围绕具有区域优势和地方特色的主导产业，着力培育打造有影响力的区域和品牌，道州灰鹅和九嶷山兔的开发利用可由地方结合实际和项目实施要求，统筹安排资金支持。下一步，农业部将继续加大对地方品种畜禽遗传资源保护和开发工作的支持力度。

感谢你们对草食牧业发展的关心，希望今后继续对我部工作给予支持。

农业部

2017年7月21日
