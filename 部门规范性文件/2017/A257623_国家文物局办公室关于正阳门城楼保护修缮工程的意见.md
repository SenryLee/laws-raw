# 国家文物局办公室关于正阳门城楼保护修缮工程的意见

办保函〔2017〕1233号

北京市文物局：

你局《关于正阳门城楼保护修缮工程方案的请示》（京文物〔2017〕1176号）收悉。经研究，我局意见如下：

一、根据现状照片，正阳门城楼现状基本稳定，拟修缮内容应定性为日常保养维护工作。

二、应总结历史修缮效果及安全检测结论，客观评估各项残损问题，据此提出有针对性的修缮措施。不得全面翻新地面铺装、墙面粉刷、油饰和彩画，盲目扩大工程量，仅进行局部修补即可。

三、进一步细化对原形制、材料和工艺的勘察研究。

四、按照最小干预原则，严格控制工程量和项目范围。进一步分析各处裂缝产生的原因，对已稳定的部位现状修补即可；对不影响结构安全、排水和使用的风化碎裂的砖石构件，不得整体揭墁、更换，并明确须采取措施的病害程度标准、具体部位和范围；下架油饰修补应注意区分地仗做法；地仗层保存尚好的，不得砍除，应尽可能续用。

五、审慎评估城台砖水泥勾缝对城台和砖构件的影响，进一步论证全部重新勾缝的必要性。

六、深化完善文本说明和图纸。核对平立剖面图轴线对位、详图的位置索引等。

请你局指导有关单位，按照上述意见和《古建筑保养维护规程》，做好对正阳门城楼的日常保养维护工作，确保文物建筑安全。

专此函复。

国家文物局办公室

2017年11月7日
