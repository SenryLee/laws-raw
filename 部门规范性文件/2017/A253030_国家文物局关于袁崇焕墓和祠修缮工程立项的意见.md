# 国家文物局关于袁崇焕墓和祠修缮工程立项的意见

## 关于袁崇焕墓和祠修缮工程立项的意见

办保函〔2017〕533号

北京市文物局：

你局《关于袁崇焕墓和祠修缮工程立项的请示》（京文物〔2016〕1748号）收悉。经研究，我局意见如下：

一、暂不同意袁崇焕墓和祠修缮工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步论证更换正殿、倒座房、山门大木构件以及揭顶修缮措施的必要性，区分日常保养维护与修缮工程内容，避免过度维修。

（二）深化现状勘察，加强对坟冢和建筑台阶等文物本体的历史沿革和形制调研，补充铲除坟冢外抹灰措施的依据，科学评估现有树木的价值和对文物本体的影响，制定有针对性的保护措施。

（三）石碑保护应单独制定保护措施并按程序报批。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年5月8日
