# 中共教育部党组关于余敏斌等同志职务任免的通知

教党任〔2017〕84号

中共中山大学委员会：

经与中共广东省委商得一致，2017年4月12日研究决定：

余敏斌、马骏同志任中共中山大学委员会副书记，肖海鹏同志任中共中山大学委员会常委，杨清华同志任中共中山大学委员会委员、常委；免去李萍同志的中共中山大学委员会副书记、常委，颜光美同志的中共中山大学委员会常委，魏明海同志的中共中山大学委员会常委、委员职务。

中共教育部党组

2017年5月4日
