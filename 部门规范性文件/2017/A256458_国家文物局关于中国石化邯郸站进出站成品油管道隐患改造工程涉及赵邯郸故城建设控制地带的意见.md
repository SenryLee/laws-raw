# 国家文物局关于中国石化邯郸站进出站成品油管道隐患改造工程涉及赵邯郸故城建设控制地带的意见

文物保函〔2017〕1717号

河北省文物局：

你局《关于呈报中国石化邯郸站进出站成品油管道隐患改造工程涉及赵邯郸故城建设控制地带设计方案的请示》（冀文物字〔2017〕216号）收悉。经研究，我局意见如下：

一、原则同意所报中国石化邯郸站进出站成品油管道隐患改造工程涉及赵邯郸故城建设控制地带的选址和设计方案。

二、该项目应遵守现有设计，严格控制工程范围和工程量；工程施工中切实注意文物安全，加强与地方文物部门的沟通，明确管道通过长度、挖沟深度、地表附属设施情况等，切实加强工程建设过程中的文物保护监管工作；施工过程中如发现文物，应及时停工并组织研究提出处理意见和保护方案，报我局批准后实施。

三、请你局指导设计单位根据考古勘探结果和文物保护的需要，进一步优化选址及建设方案，按照《中华人民共和国文物保护法》第十八条的规定，报城乡建设规划部门批准实施。

四、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促工程部门切实做好工程施工过程中的文物保护工作，确保文物安全。

国家文物局

2017年10月9日
