# 国家卫生计生委食品司关于菊粉有关问题的复函

国卫食品评便函〔2017〕257号

中国乳制品协会：

你协会《关于明确添加菊粉产品标签标示适用文件的请示》（中乳协〔2017〕83号）收悉。经研究，现函复如下：

同意废止《卫生部监督局关于含菊粉食品标识有关问题的批复》（卫监督食便函〔2009〕209号）。《国家卫生计生委食品司关于预包装食品含新食品原料标签标示以及低聚果糖有关问题的复函》（国卫食品标便函〔2015〕279号）已主动公开，可在我委网站查询。

专此函复。

国家卫生计生委食品司

2017年9月20日
