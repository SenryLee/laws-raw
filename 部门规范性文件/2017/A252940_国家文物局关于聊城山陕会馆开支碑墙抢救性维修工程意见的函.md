# 国家文物局关于聊城山陕会馆开支碑墙抢救性维修工程意见的函

## 关于聊城山陕会馆开支碑墙抢救性维修工程意见的函

办保函〔2017〕696号

山东省文物局：

你局《关于呈报山陕会馆开支碑墙抢救性维修方案的请示》（鲁文发〔2017〕46号）收悉。经研究，我局意见如下：

一、所报方案前期勘察和研究不足，措施缺乏针对性，我局暂不同意聊城山陕会馆开支碑墙抢救性维修工程。

二、对所报方案提出以下修改意见：

（一）应进一步加强现状勘察，切实了解开支碑墙险情真实情况，核实险情程度，进一步说明抢险工程的必要性和依据。

（二）坚持最小干预原则，以现状加固为主，严格控制工程强度和范围。在准确分析病害范围、程度和原因的基础上，提出有针对性的保护措施；进一步论证恢复檐廊的必要性，补充恢复依据。

（三）进一步规范文本和图纸,核实照片的真实性。校核图纸中指北针方向，明确病害具体部位，细化现状图和设计图中的工程量化标注。

三、请你局根据上述意见，组织相关单位修改、完善设计方案，经你局审核后另行报批。

专此函复。

国家文物局

2017年6月1日
