# 国家能源局综合司关于将安徽展图电力建设有限公司等企业移出2017年承装（修、试）电力设施企业“黑名单”的通知

国能综通资质〔2017〕44号

各派出能源监管机构：

根据《国家能源局综合司关于完善承装（修、试）电力设施许可管理“黑名单”退出机制等有关工作事项的通知》（国能综通资质〔2017〕33号）有关规定，经我局相关派出能源监管机构对安徽展图电力建设有限公司等7家被列入2017年承装（修、试）电力设施企业“黑名单”（以下简称“黑名单”）企业落实整改工作要求等信用修复情况予以核实认定，现将上述7家承装（修、试）电力设施企业（详见附件）自本通知印发之日起移出“黑名单”。请各派出能源监管机构持续加强对此类企业执行承装（修、试）电力设施许可管理制度情况的监督检查。

附件：移出“黑名单”的承装（修、试）电力设施企业

国家能源局综合司

2017年6月22日
