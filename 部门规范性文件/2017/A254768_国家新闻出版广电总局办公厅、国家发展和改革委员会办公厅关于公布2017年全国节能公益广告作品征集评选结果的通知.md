# 国家新闻出版广电总局办公厅、国家发展和改革委员会办公厅关于公布2017年全国节能公益广告作品征集评选结果的通知

## 国家新闻出版广电总局办公厅　国家发展和改革委员会办公厅关于公布2017年全国节能公益广告作品征集评选结果的通知

新广电办发〔2017〕49号

各省、自治区、直辖市新闻出版广电局、节能主管部门，新疆生产建设兵团新闻出版广电局、节能主管部门，中央三台，电影频道节目中心，中国教育电视台：

为充分调动社会各界力量积极参与节能减排行动，深入开展以节能提高能效为重点的宣传活动，更好地传播节能文化、普及节能知识、提升全民意识、倡导绿色生活，引导全社会共同参与生态文明建设，共绘碧水蓝天，建设美丽中国，2017年国家新闻出版广电总局和国家发展和改革委员会联合举办了全国节能公益广告作品征集评选活动。活动共评出一、二、三类作品及优秀类作品共36件，优秀组织机构16家，现将评选结果予以公布（参见附件1、2、3）。

根据《国家新闻出版广电总局 国家发展和改革委员会关于联合举办2017年全国节能公益广告作品征集暨展播活动的通知》（新广电发〔2017〕21号）要求，此次活动评选出的优秀作品将纳入“全国优秀广播电视公益广告作品库”，全国各级广播电视播出机构可以从作品库中下载相关作品进行展播。

附件：1.2017年全国节能公益广告作品征集活动广播类作品名单

2.2017年全国节能公益广告作品征集活动电视类作品名单

3.2017年全国节能公益广告作品征集活动优秀组织机构名单

国家新闻出版广电总局办公厅

国家发展和改革委办公厅

2017年8月11日
