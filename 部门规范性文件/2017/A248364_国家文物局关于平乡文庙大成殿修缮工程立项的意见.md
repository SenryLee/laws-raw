# 国家文物局关于平乡文庙大成殿修缮工程立项的意见

## 关于平乡文庙大成殿修缮工程立项的意见

办保函〔2017〕215号

河北省文物局：

你局《关于平乡文庙大成殿修缮保护工程立项的请示》（冀文物字〔2017〕12号）收悉。经研究，我局意见如下：

一、暂不同意平乡文庙大成殿修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）加强现状勘察和研究，明确文物保存现状、主要病害类型、残损情况等，深入分析屋面漏雨、木构架歪闪等病害原因，客观评估历次修缮工程效果，进一步论证工程实施的必要性和可行性。

（二）补充对地方建造工艺、传统做法、建筑材料和构造特征等研究和分析。

（三）应严格控制工程量和工程强度，结合修缮后文物的使用功能和利用方式，进一步论证恢复槅扇门窗、室内青砖地面、缺失木构件修复的必要性。

（四）根据工程量合理编制经费预算，确定取费项目，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年3月6日
