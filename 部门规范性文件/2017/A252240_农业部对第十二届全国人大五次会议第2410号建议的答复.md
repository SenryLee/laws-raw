# 农业部对第十二届全国人大五次会议第2410号建议的答复

## 对第十二届全国人大五次会议第2410号建议的答复

邵仲毅等18名代表：

你们提出的“关于推行‘新型高速公路’模式，加快高速公路转型升级的建议”收悉。经认真研究，现就“在临近高速公路的边远山区，沿路设立土特产原产地直销区”这一涉及我部职能的部分答复如下。

在高速沿线设立农产品原产地直销区，对丰富特色农产品市场供给，开拓偏远山区特色农产品销售渠道，提高特色农产品知名度，增加农民收入具有重要意义。解决边远山区农产品产销对接问题，要立足区域实际，因地制宜开展相关工作。一是要加强农产品流通基础设施建设；二是各级政府部门要积极组织产销对接活动；三是培育拓宽农产品流通渠道；四是要调动市场主体积极性，发挥市场主体在品牌建设、产销对接等方面的作用，促进农产品流通。

下一步，农业部将继续加大对边远地区农业发展的支持力度，加强特色农产品品牌培育，支持开展产销对接活动，推进农产品电子商务发展，拓宽农产品营销渠道，为促进农业增效、农民增收做出积极贡献。

感谢你们对“三农”工作的关心，希望今后继续对我部工作予以支持。
