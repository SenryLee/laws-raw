# 环境保护部关于同意国家环境保护城市大气复合污染成因与防治重点实验室通过验收的通知

## 关于同意国家环境保护城市大气复合污染成因与防治重点实验室通过验收的通知

环科技函〔2017〕275号

上海市环境科学研究院：

按照《国家环境保护重点实验室管理办法》（环发〔2004〕138号）有关规定，上海市环境保护局向我部报送了《国家环境保护城市大气复合污染成因与防治重点实验室建设总结报告》。2017年11月，我部对依托你院建设的国家环境保护城市大气复合污染成因与防治重点实验室进行了验收。

我部认为，实验室完成了《国家环境保护城市大气复合污染成因与防治重点实验室建设计划任务书》确定的建设任务。建设期内，围绕气溶胶物理化学特征、臭氧污染形成机制、大气污染来源与控制对策等领域开展研究和平台建设，开发了区域颗粒物集成源解析技术，建立了颗粒物快速源解析方法，构建了以工段为基础的精细化清单技术方法，研究成果在区域空气质量保障中得到应用，有力地支撑了我国城市及区域大气复合污染防治工作。实验室软硬件设施进一步完善，科研平台能力得到显著提升，引进和培养了多名技术骨干，形成了结构合理、稳定高效的科研团队，建立了较为完善的实验室管理制度及“开放、流动、联合、竞争”的运行机制，有力地支撑了城市及区域大气复合污染防治工作，达到了验收要求。

经研究，我部同意国家环境保护城市大气复合污染成因与防治重点实验室通过验收。

请按照《国家环境保护重点实验室管理办法》有关规定，围绕国家环境保护重点任务，进一步集聚人才，加强科研合作，注重科学研究与环境管理的结合，重视重点实验室建设工作，更好地为国家大气环境管理工作提供支撑。
