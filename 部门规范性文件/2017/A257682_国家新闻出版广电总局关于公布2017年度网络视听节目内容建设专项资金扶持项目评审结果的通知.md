# 国家新闻出版广电总局关于公布2017年度网络视听节目内容建设专项资金扶持项目评审结果的通知

新广电发〔2017〕229号

各省、自治区、直辖市新闻出版广电局，中央三台，中央直属单位《信息网络传播视听节目许可证》持证机构：

为引导和鼓励优秀网络视听节目制作播出，不断提升网络视听节目内容品质，推动传统媒体与新兴媒体融合发展，国家新闻出版广电总局今年继续开展网络视听节目内容建设专项资金扶持项目评审工作。

根据《网络视听节目内容建设专项经费使用管理暂行办法》和《网络视听节目内容建设扶持项目评审章程》，经各省级新闻出版广电行政部门、中央三台等单位推荐，总局网络视听节目内容建设专项资金评审委员会审核，最终确定2017年度网络视听节目内容建设扶持项目名单。扶持项目案例部分名单已先行公布，现将扶持项目节目部分评审结果予以公布，内容同时可在国家新闻出版广电总局政府网站（网址：http://www.sapprft.gov.cn）通知公告区中查询。

请各省级新闻出版广电行政部门即向所辖互联网视听节目服务机构及有关单位和个人通报公示内容。有关单位和个人均可就公示内容存在的问题，于11月13日前向国家新闻出版广电总局网络视听节目管理司反映（联系电话：010-86095630；传真：010-86095595）。

附件：1.2017年“弘扬社会主义核心价值观共筑中国梦”主题原创网络视听节目推选展播活动优秀作品及展播补助名单

2.2017年网络视听节目精品创作传播工程“网络视听节目优秀作品创作规划”补助名单

3.2017年优秀原创网络视听作品推选活动扶持项目补助名单

国家新闻出版广电总局

2017年11月6日
