# 国家档案局办公室关于组织推荐2017年国家档案局科技项目的通知

档办函〔2017〕21号

各省、自治区、直辖市档案局，各计划单列市档案局，新疆生产建设兵团档案局，中央和国家机关各部委档案部门，中央军委办公厅保密和档案局，各人民团体档案部门，各中央企业档案部门，中国人民大学档案学院：

现将《2017年国家档案局科技项目立项选题指南》（见附件1，以下简称《选题指南》）印发给你们。请按照《选题指南》规定的研究范围和方向确定选题，认真组织2017年国家档案局科技项目的推荐工作。

一、项目申报

项目申报单位须填写《国家档案局科技项目计划任务书》（格式见附件2，以下简称《计划任务书》），并对项目研究内容、研究现状、研究方法、成果形式等进行综合，形成1000字以内的《项目内容摘要》（格式见附件3）。

二、项目推荐

各省、自治区、直辖市、计划单列市档案局和新疆生产建设兵团档案局负责本行政区域内或主管范围内申报项目的审查和推荐；中央军委办公厅保密和档案局负责军队和武警系统申报项目的审查和推荐；中央和国家机关各部委档案部门、各人民团体档案部门、各中央企业档案部门、中国人民大学档案学院负责本单位及所属部门、机构申报项目的审查和推荐。

三、项目报送

推荐单位在《计划任务书》（一式6份）中填写审查意见、加盖公章，并填写《推荐2017年国家档案局科技项目汇总表》（格式见附件4，一式1份）加盖公章后，于2017年3月20日前（以当地邮戳为准）寄送至国家档案局技术部科技处，同时将《计划任务书》《项目内容摘要》（word版）和《推荐2017年国家档案局科技项目汇总表》（excel版）的电子版发送至国家档案局技术部科技处电子邮箱。

《计划任务书》《推荐2017年国家档案局科技项目汇总表》和《项目内容摘要》电子版可在国家档案局官方网站（网址：http://www.saac.gov.cn）“下载专区”中下载。
