# 国家文物局关于西安鼓楼保护范围内消防监控室建设项目的意见

文物保函〔2017〕2069号

陕西省文物局：

你局《关于上报鼓楼消防监控室建设项目设计方案的请示》（陕文物字〔2017〕239号）收悉。经研究，我局意见如下：

一、原则同意西安鼓楼保护范围内消防监控室建设项目设计方案和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）进一步论证该消防监控室的选址合理性，补充说明不在鼓楼上部或周边其他空间布设消防监控室的理由。

（二）进一步深化建筑结构设计，确保“无基础埋深”这一设计要点。如涉及地面开挖，应开展必要的考古工作。

（三）进一步优化建筑外观设计，可不限于仿古样式，在色彩、尺度、形体、设计施工精细度等方面与鼓楼相协调即可，并应重点考虑从鼓楼城台上方俯视该建筑屋顶的视觉效果。坡屋面与鼓楼城台交接处应做好防排水设计，避免对城台本体造成不利影响。

（四）进一步细化文物影响评估，补充评估依据和主要影响因素等。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》第十七条的规定报陕西省人民政府批准后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

专此函复。

国家文物局

2017年12月28日
