# 中华人民共和国农业部公告第2610号——进口兽药注册目录

## 中华人民共和国农业部公告

第2610号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准世德来有限公司等3家公司生产的复方甲醛溶液等3种兽药产品在我国再注册，核发《进口兽药注册证书》,并发布修订后的产品质量标准、说明书和标签，自发布之日起执行，原我部发布的本产品质量标准、说明书和标签同时废止。

批准美国法玛威生物制品股份有限公司等2家公司生产的猪支原体肺炎复合佐剂灭活疫苗（P株）等3种兽药产品在我国变更注册。

特此公告。

附件：1.进口兽药注册目录

2.质量标准（略）

3.说明书和标签

农业部

2017年11月21日
