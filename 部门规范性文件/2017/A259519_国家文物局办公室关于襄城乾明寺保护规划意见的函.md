# 国家文物局办公室关于襄城乾明寺保护规划意见的函

办保函〔2017〕1413号

河南省文物局：

你局《关于审批襄城乾明寺文物保护规划的请示》（豫文物〔2017〕141号）收悉。经研究，我局意见如下：

一、所报规划目标不明确，保护对象认定不合理，规划措施针对性不足，我局暂不同意所报襄城乾明寺保护规划。

二、所报规划应做以下必要修改和完善：

（一）应加强前期研究和考古调查，明确襄城乾明寺历史格局，进一步梳理文物本体和保护对象，客观评估文物价值。

（二）进一步完善现状评估。明确文物本体的结构安全和危害因素；补充照壁及其保存环境的评估内容，并对近年来保护范围内新建建筑的合法性和影响进行评估；细化现行保护区划评估；深化管理现状评估，明确管理主体和主要问题。明确周边村庄和烈士陵园的环境影响。

（三）根据文物保护管理需要科学调整保护区划，增强可操作性，进一步论证建设控制地带在山区范围扩大的必要性和可行性，补充说明缩小保护范围的依据，完善保护区划管理规定。

（四）根据现状评估结论进一步完善保护措施，明确实施对象、工程范围和控制要求，增强针对性。院落整治措施应调整至环境整治章节。

（五）合理调整用地性质，补充对保护范围内展示用地的控制要求，塔林遗址周边及山门前中轴线两侧不应规划为建设用地。

（六）进一步加强展示措施的针对性，并根据展示利用需求，合理确定停车场选址和规模。

（七）应明确文物部门与宗教部门的权责关系；加强本规划与城市总体规划等相关规划的衔接，及文物保护与城市发展的协调性。

（八）梳理规划文本，规范、完善图纸表达，合理调整图纸图幅，补充规划总图。

三、请你局指导相关单位，按照上述意见对规划进行认真修改、完善，按相关程序另行报批。

国家文物局办公室

2017年12月26日
