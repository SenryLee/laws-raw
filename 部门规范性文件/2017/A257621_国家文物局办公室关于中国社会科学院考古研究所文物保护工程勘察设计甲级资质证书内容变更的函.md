# 国家文物局办公室关于中国社会科学院考古研究所文物保护工程勘察设计甲级资质证书内容变更的函

办保函〔2017〕1220号

北京市文物局：

你局《关于中国社会科学院考古研究所更换文物保护勘察设计甲级资质法人信息的请示》（京文物〔2017〕1298号）收悉。

经研究，我局同意中国社会科学院考古研究所文物保护工程勘察设计甲级资质证书中的法定代表人由“王巍”变更为“陈星灿”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2017年11月2日
