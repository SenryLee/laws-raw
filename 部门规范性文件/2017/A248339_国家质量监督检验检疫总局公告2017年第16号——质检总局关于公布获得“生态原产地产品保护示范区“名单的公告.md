# 国家质量监督检验检疫总局公告2017年第16号——质检总局关于公布获得“生态原产地产品保护示范区“名单的公告

2017年第16号

## 质检总局关于公布获得“生态原产地产品保护示范区“名单的公告

为进一步落实生态文明建设战略，建设美丽中国目标，促进区域经济可持续发展，培育打造品牌竞争新优势，经甘肃、贵州、四川、重庆、山东检验检疫局推荐及质检总局评定组现场评定，批准甘肃省礼县人民政府等6家申报单位获评“生态原产地产品保护示范区”，即日起实施保护。现将获得“生态原产地产品保护示范区”的名单予以公布：
