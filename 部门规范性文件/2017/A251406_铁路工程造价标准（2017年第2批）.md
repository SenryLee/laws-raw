# 铁路工程造价标准（2017年第2批）

国铁科法〔2017〕31号

现公布《铁路基本建设工程设计概（预）算费用定额》（TZJ 3001-2017）铁路工程造价标准，自2017年7月1日起实施。《铁路基本建设工程投资预估算 估算 设计概预算费税取值规定》（铁建设〔2008〕11号）中关于预算费税取值相关内容同时废止。

本标准由中国铁道出版社出版发行。

国家铁路局

2017年5月6日
