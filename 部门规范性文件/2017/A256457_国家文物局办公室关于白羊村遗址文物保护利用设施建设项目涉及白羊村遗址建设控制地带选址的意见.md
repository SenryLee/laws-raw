# 国家文物局办公室关于白羊村遗址文物保护利用设施建设项目涉及白羊村遗址建设控制地带选址的意见

办保函〔2017〕1167号

云南省文物局：

你局《关于宾川白羊村遗址文物保护利用设施建设项目设计方案的请示》（云文物〔2017〕159号）收悉。经研究，我局意见如下：

一、暂不同意白羊村遗址文物保护利用设施建设项目涉及白羊村遗址建设控制地带的选址方案。

二、所报建设项目应进一步论证项目实施的必要性和可行性，在项目选址区域开展全面的考古勘探工作，明确遗存整体分布情况。同时，核减拟建建筑体量，优化建筑外观设计，确保拟建建筑与遗址及周边整体风貌相协调。

三、请你局指导项目建设单位，根据上述意见进一步修改和完善所报方案，按程序另行报批。

四、请你局指导当地人民政府组织专业机构，按照《关于白羊村遗址保护规划编制立项的批复》（文物保函〔2013〕1198号）要求，抓紧编制保护规划，合理划定保护区划，明确建设控制地带的具体控制指标，为白羊村遗址保护、展示和相关设施建设项目提供依据。

国家文物局办公室

2017年10月13日
