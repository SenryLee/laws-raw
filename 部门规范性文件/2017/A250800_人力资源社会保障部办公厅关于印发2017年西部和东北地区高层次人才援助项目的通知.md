# 人力资源社会保障部办公厅关于印发2017年西部和东北地区高层次人才援助项目的通知

人社厅函〔2017〕82号

有关省、自治区、直辖市人力资源社会保障厅（局），新疆生产建设兵团人力资源社会保障局：

实施高层次人才援助项目是加强西部和东北地区高层次人才队伍建设的重要举措，对吸引各类高层次人才投身西部大开发和振兴东北老工业基地，更好发挥高层次人才对推动西部和东北地区经济社会发展的支撑作用具有重要意义。 根据各地项目申报情况，按照“突出重点、好中选优、注重实效、统筹兼顾”的原则，我部遴选确定了2017年西部和东北地区高层次人才援助项目20项（项目名称及资助额度附后）。现就有关事项通知如下：

一、精心组织实施。各地要充分认识实施西部和东北地区高层次人才援助项目的重要意义，围绕服务本地区经济社会发展和人才队伍建设实际需求，严格按照项目主题和内容，精心组织实施，突出针对性和实效性，切实保证项目实施质量，真正发挥项目对实施创新发展、助推经济转型升级、保障改善民生、加强高层次人才队伍建设的重要作用。要充分发挥我部资助项目示范带动作用，配套支持政策，调动各方积极性，形成上下联动、齐抓共促的工作氛围。如项目实施有关事项发生变化，请提前报送情况说明，并在每期项目举办前，将项目实施通知纸质版报送我部专业技术人员管理司。

二、严守财经纪律。要严格执行国家有关经费管理规定，加强监督管理，做好经费预算、执行和审计工作，确保专款专用，提高经费使用效益。其中，高级研修项目，除往返交通费由学员承担外，不得向学员收取任何费用。要认真贯彻落实中央有关要求，改进工作作风，厉行勤俭节约，不得到中央办公厅、国务院办公厅规定的21个风景名胜区举办活动，不得借举办活动之名旅游，不得搞公款宴请。中央财政资助的经费如有结余，要按照有关规定及时退回我部账户，并附函说明。我部将采取抽查等方式，对部分项目进行监督巡查。

三、加强总结宣传。项目结束后，要认真总结项目实施成效和经验，查找问题和不足，提出改进措施建议，及时提交总结报告。各地项目实施情况总结和资助经费决算报告，请于2017年11月1日前报送我部专业技术人员管理司。项目实施情况总结将作为下一年度资助项目的重要依据。要组织各类媒体，及时总结宣传项目实施过程中涌现的典型经验和先进事迹，加大对项目实施成效宣传力度，提高社会影响力，营造良好社会氛围，打造人才工作服务西部大开发、振兴东北老工业基地战略新品牌。
