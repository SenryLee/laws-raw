# 国家文物局关于《古建筑木结构维护与加固技术规范（征求意见稿）》意见的复函

## 关于《古建筑木结构维护与加固技术规范（征求意见稿）》意见的复函

办保函〔2017〕261号

住房和城乡建设部标准定额司：

你司《关于征求国家标准〈古建筑木结构维护与加固技术规范〉（征求意见稿）意见的函》（建标标函〔2017〕71号）收悉。经研究，我局提出意见如下：

一、《古建筑木结构维护与加固技术规范（征求意见稿）》（以下简称《规范》）是我国古建筑保护维修领域推行的第一个技术规范，对古建筑保护工程勘察设计和施工组织起到了技术指导作用。项目承担单位应充分征求文物保护工程资质单位、专家和文物行政部门意见，进一步修改完善文本内容。

二、应明确《规范》的适用范围和主要内容，调整体例框架，增强《规范》的针对性。建议《规范》以古建筑木结构维修、加固为重点，仅适用于古建筑修缮工程；“8古建筑的防护”、“10相关工程的维修”等与木结构维修、加固无关内容，不宜纳入《规范》文本。

三、应慎重考虑现代工程技术应用于古建筑修缮工程的科学性和可行性，进一步搜集国内已有文物保护工程案例，总结、归纳适用于古建筑的安全性鉴定、抗震加固等专业技术要求，避免简单套用现代建筑标准。建议验证现有鉴定评级体系的实际效果，暂不宜将“6古建筑安全性鉴定”、“7古建筑抗震鉴定”作为通用标准。

四、应充分总结、评估我国现有古建筑木结构维修、加固技术手段及其效果，进一步调整、完善“9木构架的维修、加固”章节内容，注意吸纳行业内已有的成熟经验、做法，修改完善技术要求，增强针对性。

五、我局已颁布《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》，建议加强相关章节的内容衔接，避免验收标准不一致。

六、《规范》用语应准确、严谨、简洁。建议进一步核校“2术语”和文本内容，避免前后矛盾。
