# 国家邮政局关于做好全国“两会”期间邮政、快递服务和安全工作的通知

国邮电传〔2017〕10号

各省、自治区、直辖市邮政管理局：

十二届全国人大五次会议、全国政协十二届五次会议（以下称“两会”）将分别于2017年3月5日、3月3日在北京召开。为切实做好“两会”期间邮政、快递服务和安全工作，为“两会”顺利召开创造良好的寄递环境，现将有关事项通知如下：

一、切实增强政治自觉和责任自觉。全国“两会”召开是全国人民政治生活中的一件大事。做好“两会”期间寄递服务和安全保障工作责任重大，使命光荣。各级邮政管理部门要清醒认识当前面临的严峻形势，深入研究分析“两会”前后服务和安全工作的规律特点，针对春节后企业陆续复工、节后业务小高峰等因素，以及低温、雨雪、大风等灾害性天气，组织协调各方面力量，抓好各项工作措施的落实。要高度重视，切实加强组织领导，坚决克服麻痹思想和松懈情绪，进一步强化政治自觉和责任自觉，强化大局意识和责任意识，坚持“党政同责、一岗双责、齐抓共管、失职追责”，做到守土有责，守土尽责。要周密研究部署，消除监管盲区，堵塞监管漏洞，补齐服务短板，严防敌对势力和不法分子利用寄递渠道从事干扰“两会”顺利举办的破坏活动，严防因违规收寄各类禁寄物品导致发生重大寄递安全事件，严防行业内部因各种因素引发重大群体性事件和安全生产事故，努力为“两会”提供优质、安全的邮政、快递服务。

二、做好“两会”期间寄递服务工作。各级邮政管理部门要督促寄递企业加强管理，严格落实邮政、快递服务各项制度标准，确保各营业网点正常营业，保持正常生产经营。要认真做好消费者咨询服务、投诉处理等工作，保障消费者合法权益。北京市邮政管理局要督促邮政企业提前谋划，周密部署，制定工作方案和应急预案，确保各项工作有序开展。要挑选政治过硬、业务素质好、服务意识强的工作人员参与大会服务工作，加强宣传培训，规范服务行为，提高服务质量。要认真做好涉会邮件、报刊投递工作，制定专投作业方案，对涉会邮件实行专人、专车、专段、专投，未经会场和驻地秘书处批准，不得随意作退回处理。要加强邮政报刊亭管理，严禁出售政治性非法出版物、宗教极端宣传品等。

三、做好“两会”期间安全保障工作。各级邮政管理部门要围绕中心、服务大局，采取强有力措施，全力以赴保障寄递安全。一是严格执行收寄验视、过机安检、实名收寄三项制度。要认真宣贯《禁止寄递物品管理规定》，加强教育培训，重点加大对各类枪支弹药、易燃易爆物品、危险化学品等物品的查验力度，坚决将各类禁寄物品堵截在寄递渠道之外。要严格执行实名收寄制度，“两会”期间，对各地寄往北京的邮件、快件，除信件和已有安全保障机制的协议客户以外，统一实行实名收寄，要求寄件人出示有效身份证件并登记相关身份信息后方可收寄。要严格执行过机安检制度，“两会”期间，对寄往北京的邮件、快件实行100%过机安检并粘贴“已安检”标识。北京市邮政管理局要制定安保工作方案和突发事件专项应急预案，督促寄递企业加强安全防范，对寄往“两会”代表和委员驻地、中央领导机关驻地、长安街沿线重要单位等重点部位的邮件、快件在投递前进行二次安检，确保万无一失。二是全力确保行业安全稳定。要督促企业认真落实主体责任，开展动态隐患排查治理，加大对车辆、消防、用电、人员密集场所的安全检查力度。对查出的隐患和问题，能立即整改的要立即整改，不能立即整改的要落实安全防范措施；对重大隐患要挂牌督办整改，无法保证安全生产的，要坚决依法责令停产停业整改，并加强巡查、监控和盯守，严防发生火灾、触电、车辆安全、机械伤害等事故，坚决遏制重特大事故发生。要加强群体性维权事件应对处置工作，督促企业及时排查化解各类矛盾纠纷，严防发生违法招揽加盟经营快递业务的行为，坚决防止发生大规模集体进京上访和群体性聚集事件。北京市邮政管理局和环北京6省（区、市）邮政管理局要建立信息互通机制，加强对邻近京郊、环省交界地区寄递企业的安全检查，着力构筑环北京地区寄递安全“护城河”防线。三是加强安全宣传教育。要督促企业充分利用各类新闻媒体，深入开展寄递安全宣传活动，提升企业员工安全素质和用户安全意识。要把握正确的舆论导向，加强舆情应对，弘扬主旋律，传播正能量，营造浓厚的寄递安保氛围。四是强化安全执法检查。要加大执法检查和责任追究力度，采取明查暗访、联合执法检查等措施，切实做到“全覆盖、零容忍、严执法、重实效”，确保各项安全措施落实到位。

四、加强“两会”期间应急管理工作。各级邮政管理部门要充分发挥寄递渠道联合监管机制作用，加强与综治、公安、国家安全等部门的沟通联系，加强情报信息共享，联合开展督导检查，实行齐抓共管、综合治理。近期，国家邮政局将会同公安部对部分省（区、市）“两会”寄递安保工作落实情况进行联合督导检查。要进一步健全完善安全预测预警和应急协调联动机制，及时发布灾害性天气、地质灾害等预警信息，督促企业提前做好防范应对工作。要做好救援队伍、装备、物资等应急准备工作，确保一旦发生事故或紧急情况，能及时妥善处置。要加强应急值守和信息报送工作，“两会”期间实行24小时值班和领导带班制度，遇到重大问题和突发事件，要第一时间报告国家邮政局。

国家邮政局

2017年2月10日
