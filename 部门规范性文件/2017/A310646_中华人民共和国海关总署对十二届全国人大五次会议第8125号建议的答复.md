# 中华人民共和国海关总署对十二届全国人大五次会议第8125号建议的答复

张涛等4名代表：

你们提出的《关于在辽宁发展临港产业方面给予政策支持的建议》（发展规划、建设项目和综合经济类第8125号），其中“建议国家海关总署等部门支持建立大连、营口等沿海城市的海关多式联运监管中心，简化优化通关流程，提高海关监管和通关效率，推动多式联运快速发展”事宜由我署分办。经认真研究，现答复如下：

国际物流多式联运是服务国家“一带一路”发展战略，体现各种运输方式组合优势和综合效率的一种运输组织形式，对提高运输效率，降低物流成本，促进节能减排，推动现代物流业发展具有重要意义。

我署高度重视国际多式联运业务发展，已先后于2015年12月31日、2016年8月5日致函辽宁省人民政府，支持辽宁省在大连、营口建设多式联运海关监管中心。同时，我署正结合国家相关政策法规，研究制定多式联运海关监管业务相关管理办法，努力创新海关在国际多式联运业务方面的监管制度和监管方式，进一步简化优化通关流程，提高海关监管和通关效率，支持“一带一路”沿线物流关键节点地区开展国际多式联运业务，促进水运、空运、铁路、公路等运输方式的互联互通。大连海关根据我署要求，积极支持并参与大连、营口等城市的多式联运海关监管中心建设相关工作。据了解，大连和营口两市的多式联运海关监管中心均处于建设之中。

感谢您对海关工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2017年6月14日
