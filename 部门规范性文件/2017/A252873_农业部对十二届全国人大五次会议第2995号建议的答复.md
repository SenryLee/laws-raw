# 农业部对十二届全国人大五次会议第2995号建议的答复

## 对十二届全国人大五次会议第2995号建议的答复

农办议〔2017〕19号

您提出的关于将西部边远贫困地区市（州）级动物防疫体系基础实施建设列入国家动物防疫体系基础设施项目予以安排的建议收悉。经商国家发展改革委、财政部，现答复如下。

根据2016年中央1号文件、《全国农业现代化规划（2016-2020年）》（国发〔2016〕58号）、《国家中长期动物疫病防治规划（2012-2020年）》（国办发〔2012〕31号）等，国家发展改革委会同农业部、质检总局、国家林业局于2017年5月12日印发了《全国动植物保护能力提升工程建设规划（2017-2025年）》（发改农经〔2017〕913号，以下简称《规划》）。《规划》明确提出，为及时准确掌握优先防治病种流行态势和病原分布状况，选择238个具备实验室人员、技术和经费保障条件的地市级动物防疫机构重点进行病原学监测能力建设，承担国家下达的禽流感、口蹄疫、布病等优先防治病种的病原学监测、流行病学调查和信息直报任务，提高动物疫病早发现、早预警能力。

下一步，我们将按照《规划》要求，根据地方申报情况和年度投资安排，统筹加大对西部贫困地区地市级动物防疫机构建设的支持力度。

感谢您对兽医工作的关心和支持。

农业部

2017年7月1日
