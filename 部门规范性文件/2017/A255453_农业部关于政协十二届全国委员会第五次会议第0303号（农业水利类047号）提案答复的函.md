# 农业部关于政协十二届全国委员会第五次会议第0303号（农业水利类047号）提案答复的函

## 关于政协十二届全国委员会第五次会议第0303号（农业水利类047号）提案答复的函

农办案〔2017〕77号

民进中央：

关于进一步加强“互联网+农业”发展的提案收悉。经我部认真研究，现答复如下。

近年来，按照党中央、国务院决策部署，农业部及各有关部门，以“互联网+”打造现代农业升级版，加快推进农业农村信息化建设，取得了积极进展。农业部先后会同有关部门制定了《推进农业电子商务发展行动计划》《关于推进农业农村大数据发展的实施意见》《“互联网+”现代农业三年行动实施方案》《“十三五”全国农业农村信息化发展规划》等系列文件，加强顶层设计，明确任务责任，形成了“互联网+”现代农业基本政策框架。

一、关于建立综合服务平台及业务应用系统

近年来，农业部加快对国家农业数据中心进行云化升级改造，初步建成国家农业数据平台，提高了农业生产管理、指挥调度等数据支撑能力，促进农业物联网加快推广应用；加强与中国气象局、新华社、中粮集团等单位合作，推动国家农业数据中心、海外农业数据中心建设；在21个省区市开展生猪等8种重要农产品大数据试点工作；推动资金整合和信息平台布局优化，以农兽药基础数据平台、国家农产品质量安全追溯管理信息平台、重点农产品市场信息平台、新型经营主体信息直报平台建设为抓手，推进信息整合、联通、公开、共享和数据开发等工作；依托信息进村入户工程，积极引入公用事业单位和相关企业的服务资源，创新政府服务方式，让农民足不出村就能办想办的事。下一步，农业部将深入推进涉农信息资源和系统整合共享，加强农业执法和农村经营管理信息化建设，深入实施信息进村入户工程，持续推进各类涉农服务资源开放共享。

二、关于推进农业经营管理信息化

一是加强农村土地经营权流转信息化建设。农业部指导各地完善农村土地经营权流转配套制度，加强流转市场规范化管理，有效遏制了一些地方盲目追求流转速度的行为，促进了土地流转的平稳有序发展。建设土地确权登记数据汇交库，指导各地确权登记数据库建设工作和保证汇交数据质量，组织试点地区确权登记数据库汇交工作，开展国家级确权登记数据库和农村土地承包经营权信息应用平台建设。二是提升新型农业经营主体信息化应用能力。中共中央办公厅、国务院办公厅联合印发《关于加快构建政策体系培育新型农业经营主体的意见》，明确指出支持新型农业经营主体带动农户应用农业物联网和电子商务。2014年起农业部联合财政部启动实施新型职业农民培育工程，充分利用信息化手段开展在线培训和服务，实现线上线下融合发展。下一步，农业部将进一步提升土地流转管理服务信息化水平，支持各类新型经营主体积极运用现代信息技术提高产销水平。

三、关于推进农业生产加工信息化建设

近年来，农业部加大物联网、大数据、空间信息在农业生产加工领域的应用。2011年以来，发展改革委、农业部在北京、内蒙古、吉林、黑龙江等9省份先后启动实施了国家物联网重大应用示范工程和农业物联网区域试验工程。农业部组织开展了数字农业建设试点项目，重点开展大田种植、设施园艺、畜禽养殖、水产养殖等4类数字农业建设试点。2014年起，农业部先后向全社会推介了426项节本增效农业物联网软硬件产品、技术和应用模式。2016年，农业部成立了农业信息化标准化技术委员会，审议通过了农业信息化标准体系框架，进一步明确了农业信息化标准工作的重点任务，组织的13项农业物联网国家标准制修订项目获得国家标准委批复立项。下一步，我部将继续实施农业物联网区域试验工程，组织开展国家现代农业示范区数字农业示范项目，深入推进农业农村大数据试点工作，推进建立“天-空-地”一体化的农业遥感数据采集系统，探索农业农村大数据建设的有效模式和途径。

四、关于开展“互联网+”现代农业专项行动

2016年，农业部会同发展改革委、中央网信办等7个部门联合印发了《“互联网+”现代农业三年行动实施方案》，明确了未来三年“互联网+”现代农业行动的总体要求，提出了11项主要任务、6项重大工程，加快互联网与农业产业链、价值链和供应链的深度融合。在生产上，大力推进物联网在农业生产中的应用，推进大田种植、设施园艺、畜禽养殖、水产养殖物联网示范基地建设，推广节本增效农业物联网应用模式，构建国家农业物联网标准体系及相关公共服务平台，提升农业生产集约化、工程装备化、作业精准化和管理信息化水平。在经营上，大力发展农业电子商务，通过试点探索电商发展模式，实施网络扶贫；开展农业电子商务“平台对接”专项行动，推进农产品、农业生产资料和休闲农业上线销售；组织有关电商企业开展苹果电商销售月行动和贵州土鸡电商专项促销行动，拓宽了农产品销售渠道；加快推进标准体系建设，加强政企合作。在管理上，大力推进农业行业管理信息化建设，加强顶层设计和统筹协调，切实推进数据共享开放、开发利用，强化大数据关键技术研发，创新管理机制体制，推动形成覆盖全面、业务协同、上下贯通、众筹共享的发展格局。在服务上，2017年，农业部启动实施信息进村入户工程，并遴选10个省份开始整省推进示范。截至2017年6月底，全国共建成运营6.9万个益农信息社，提供公益服务1115万人次，开展便民服务1.8亿人次，实现电子商务交易额128亿元。下一步，农业部将以推动互联网、物联网等现代信息技术在农业生产、经营、管理、服务各环节和农村经济社会各领域深度融合为目标，加快推动“互联网+”现代农业各项行动落地实施。

感谢民进中央对“互联网+”现代农业工作的关心，希望继续对我部的工作给予支持。

农业部

2017年8月30日
