# 国家文物局办公室关于尧坝镇古建筑群保护规划意见的函

办保函〔2017〕1386号

四川省文物局：

你局《关于报送合江县尧坝镇古建筑群保护规划的请示》（川文物〔2017〕6号）收悉。经研究，我局意见如下：

一、所报规划文物认定不清，相应的专项评估、保护区划、管理措施等与《全国重点文物保护单位保护规划编制要求》存在较大差距，暂不同意所报规划。

二、对该规划提出以下修改意见：

（一）应进一步明确文物本体，根据国务院公布的尧坝镇古建筑群文物构成清单重新梳理构成要素，不应改变构成要素名称或有缺漏。

（二）应进一步总结历史文化价值和完善专项评估内容。应细化现状勘察研究，补充对文物本体的现状、环境现状、管理现状、展示利用、历史文化名镇名村保护设施项目实施情况的评估等，并制定具有针对性的保护措施。

（三）保护范围如非必要，可不划分为重点保护区和一般保护区的必要性。环境控制区缺乏法理依据，建议取消。制定合理有效的管理措施，加强与历史文化名镇名村规划的衔接。明确管理机构、人员配置、责权关系、规章制度、措施和日常工作内容。

（四）应补充防灾减灾专项规划和基础设施专项规划，特别是针对可能发生的山体滑坡、泥石流等自然灾害制定应急预案。

（五）应明确展示目标及定位，在价值评估的基础上深入挖掘尧坝镇古建筑群的内涵，合理展示古建筑群的核心价值。

（六）应进一步规范文本体例，精炼文本内容，统一文本用语。

三、请你局指导相关单位，按照上述意见对所报保护规划进行修改、完善，按相关程序另行报批。

国家文物局办公室

2017年12月19日
