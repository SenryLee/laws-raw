# 国家文物局关于弹子石摩崖造像五佛殿抢险加固工程意见的函

## 关于弹子石摩崖造像五佛殿抢险加固工程意见的函

办保函〔2017〕705号

重庆市文物局：

你局《关于审批重庆市弹子石摩崖造像抢险加固工程五佛殿抢险加固方案的请示》（渝文物〔2017〕112号）收悉。经研究，我局意见如下：

一、所报工程方案前期勘察和研究不足，文本深度不够，我局暂不同意弹子石摩崖造像五佛殿抢险加固工程方案。

二、对该方案提出以下修改完善意见：

（一）深化现状勘察，准确统计五佛殿各类构件残损数量，进一步分析、核准木构架歪闪变形原因。客观评估1997年和2008年修缮工程效果，明确五佛殿后期更换木柱的具体位置、材质和拼接情况等，为科学制定工程措施提供依据。

（二）补充五佛殿的建造工艺、做法、材料和构造特征等研究和分析内容。

（三）应加强前期试验检测分析工作，补充使用木材阻燃剂的试验依据和具体做法。

（四）应以排除建筑安全隐患为主，严格控制工程量和工程强度，细化工程做法和技术要求，并认真纠正不当做法。

1. 柱芯完好的糟朽木柱应采用包镶做法修补，尽量避免落架更换。

2. 地面、墙面修缮应使用传统材料做法。补充地面铺墁方砖的具体要求和方法。

3. 不同意地面采用细石混凝土垫层、水泥砂浆填缝的做法；不同意砖墙粉刷过程中添加金属网或玻璃丝网格布。

4. 不同意采用水泥砂浆修补柱础等石质构件并做防风化处理。

5. 补充屋顶脊饰、后期改造门窗等的设计依据，核对修缮图纸，严禁缺乏科学依据的盲目复原。

（四）进一步规范图纸，补充图纸尺寸标注、修缮做法说明和必要的节点详图。

三、请你局根据上述意见和我局《关于弹子石摩崖造像五佛殿抢险加固工程的意见》（办保函〔2017〕257号）要求，组织相关单位认真修改、完善设计方案，经你局审核后另行报批。建议该项目应与弹子石摩崖造像保护修缮工程统筹推进，方案实施前应指导相关单位对五佛殿木柱糟朽、檩枋脱榫等部位进行及时支护，防止险情加重，确保文物和人员安全。

专此函复。

国家文物局

2017年6月5日
