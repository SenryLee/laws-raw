# 国家文物局关于名山室保护规划意见的函

文物保函〔2017〕2001号

福建省文物局：

你局《关于全国重点文物保护单位名山室文物保护规划的请示》（闽文物字〔2016〕536号）收悉。经研究，我局意见如下：

一、原则同意所报名山室保护规划。

二、对该规划提出以下修改意见：

（一）进一步梳理文物构成，摩崖石刻应属于文物本体，周边环境及古树名木不属文物构成。完善价值评估，深入分析名山室在地方社会文化领域的历史地位和社会价值。

（二）加强现状评估，结合周围山体水系、地形地物和视阈分析，进一步完善周边环境评估内容，明确景观格局和形态特征。补充分析赋存载体的安全性和稳定性。

（三）进一步完善保护区划管理规定，补充保护范围内违章建筑的整治措施；建设控制地带的现状建筑及拟建建筑应分别提出控制要求。

（四）进一步完善石质文物保护措施，加强针对性；进一步论证生物霉菌治理措施的科学性和可行性；管理措施应纳入相应章节。

（五）完善环境整治内容，明确实施对象，细化整治措施。进一步完善名山室周边景观格局的保护和整治措施。明确展示利用规划的目标与定位，科学确定展示利用的主体、方式、游线及相关设施配置，统筹考虑宗教活动的需求。

（六）应明确文物古迹用地范围，明确文物部门和宗教部门的权属职责。

（七）完善文本和图纸表达，规划图例、图名，加强图文对应性。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的名山室保护规划报请福建省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体立项报告或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好名山室的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月19日
