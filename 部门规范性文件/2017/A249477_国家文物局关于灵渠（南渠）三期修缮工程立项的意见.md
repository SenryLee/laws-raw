# 国家文物局关于灵渠（南渠）三期修缮工程立项的意见

## 关于灵渠（南渠）三期修缮工程立项的意见

办保函〔2017〕269号

广西壮族自治区文化厅：

你厅《关于报送灵渠（南渠）三期修缮工程立项报告的请示》（桂文物报〔2017〕4号）收悉。经研究，我局意见如下：

一、暂不同意灵渠（南渠）三期修缮工程立项。

二、请你厅切实加强文物保护工程管理，督促地方人民政府和有关单位，全面梳理、评估灵渠文物保护工程进展情况和工程效果，核查项目开工率和经费使用情况。灵渠（南渠）一期、二期修缮工程竣工验收前，我局不再审批新的修缮工程。

三、请你厅督促地方人民政府根据《关于灵渠保护规划编制立项的批复》（文物保函〔2016〕700号）要求，抓紧编制灵渠保护规划，统筹考虑文物保护、展示、环境整治和申报世界遗产等方面工作。

专此函。

国家文物局

2017年3月16日
