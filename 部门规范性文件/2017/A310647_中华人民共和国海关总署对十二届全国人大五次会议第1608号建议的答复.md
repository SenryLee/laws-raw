# 中华人民共和国海关总署对十二届全国人大五次会议第1608号建议的答复

赵丰代表：

您提出的《关于支持博物馆（美术馆）国际合作办展的建议》（流通、旅游和服务类第1608号）收悉。经认真研究，现答复如下：

一、根据《中华人民共和国海关法》、《中华人民共和国进出口关税条例》等有关法律法规，对于暂时进境展览品，纳税义务人向海关缴纳相当于税款的保证金或者提供其他担保的，可暂不缴纳关税。如果地方博物馆（美术馆）向海关缴纳保证金存在困难，目前可以采取两种方式解决：一是根据我国加入的有关货物暂准进口的国际公约，海关接受暂时进境展览品以ATA单证册办理通关手续，因ATA单证册既是国际通用的报关文件，又是担保文件，因此无需向海关缴纳保证金；二是根据海关规定，在海关派员监管的场所举办展览会的，经主管地海关同意，可以就参展的展览品免予向海关提交担保。

二、2016年11月7日，第十二届全国人民代表大会常务委员会第二十四次会议审议通过了《全国人民代表大会常务委员会关于修改〈中华人民共和国对外贸易法〉等十二部法律的决定》，对《中华人民共和国海关法》有关条款进行了修改，以法律的形式正式取消了“暂时进出境货物的核准”行政审批事项。取消该项行政审批后，海关将暂时进出境展览品等有关货物纳入正常通关流程，取消了原法规中涉及行政审批等规定，进一步缩短了暂时进出境展览品等有关货物的通关时间，提高了通关效率。目前，我署正在广泛征求社会意见、进行实地调研，对《中华人民共和国海关暂时进出境货物管理办法》（海关总署第157号令公布，海关总署第212号令修改）进行修订。

感谢您对我们工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。
