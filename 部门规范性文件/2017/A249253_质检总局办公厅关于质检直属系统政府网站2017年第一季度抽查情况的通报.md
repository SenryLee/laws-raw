# 质检总局办公厅关于质检直属系统政府网站2017年第一季度抽查情况的通报

质检办函〔2017〕341号

各直属检验检疫局，认监委、标准委，总局各司局，中纤局：

为进一步加强全国质检直属系统政府网站信息内容建设，更好地发挥政府网站政务公开和服务群众主平台作用，按照《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）和《国务院办公厅秘书局关于2016年第四次全国政府网站抽查情况的通报》（国办秘函〔2017〕5号）等要求，总局办公厅会同信息中心组织对质检直属系统政府网站开展了2017年第一季度抽查。现将抽查情况通报如下：

一、抽查基本情况

本次质检直属系统政府网站季度抽查按照20%的抽查比例，共随机抽查了73个政府网站（包括总局、认监委、标准委、8个直属检验检疫局和62个分支检验检疫机构政府网站），并按照《全国政府网站普查评分表》进行评分。抽查结果显示，大部分政府网站内容水平显著提升，但仍有部分政府网站存在问题。其中，重庆检验检疫局、抚远检验检疫局、逊克检验检疫局、上饶检验检疫局、郑州综合保税区检验检疫局、梧州检验检疫局、文山检验检验局、阿克苏检验检疫局等8个单位网站因存在单项否决问题被判定为不合格。

二、抽查发现问题

（一）信息更新不及时问题依然存在。

部分政府网站仍然存在空白栏目、信息更新不及时等问题。存在空白栏目问题的网站占被抽查政府网站数量的3%，主要集中在场景式服务、人事信息、财政信息、应急管理等信息公开时效不强的栏目。存在新闻、动态等栏目更新不及时问题的网站较多，占被抽查政府网站数量的16%，少数网站也存在通知公告、政策法规、人事信息、财政信息等栏目更新不及时的问题。

（二）征集调查、在线访谈活动数量偏少。

部分网站开展征集调查活动的数量未达到“须举办3期以上”的底线要求，占被抽查政府网站数量的21%，少数网站甚至在近一年内未开展征集调查活动。在线访谈栏目非必设栏目，但在已开设在线访谈栏目的政府网站中，开展在线访谈活动次数低于“如开设在线访谈栏目，须举办3期以上”基本要求的政府网站占抽查政府网站数量的2%。

（三）链接错误问题仍需改善。

个别网站首页或其他页面依然存在链接错误或不可用等问题，主要存在于首页、办事服务、征集调查、在线访谈等栏目中。存在链接错误问题的政府网站，占被抽查政府网站数量的7%。

三、下一步工作要求

（一）高度重视网站管理。政府网站是政府信息公开的重要载体，是政府密切联系群众的重要桥梁，是转变政府职能、回应民生关切、提供公共服务的重要平台。各单位务必要高度重视政府网站管理工作，切实增强责任感和使命感，加强领导、落实责任，着力解决存在的突出问题，推动网站管理工作持续健康发展。

（二）切实开展网站整改。各单位整改时要认真查摆问题原因，举一反三，切实做好网站内容维护工作。各相关直属检验检疫局要牵头负责所辖分支检验检疫机构的整改工作。各单位要于4月30日前向总局办公厅报送整改报告。如需关停网站或出现严重问题不能及时整改到位的，要及时向总局办公厅报备。

（三）完善长效运维机制。各单位办公室是本单位政府网站建设管理的第一责任主体，负责本单位政府门户网站建设以及对本单位及分支机构政府网站的监督管理。各单位要进一步明确各业务部门的网站内容保障责任和信息化部门的网站运行维护等责任，建立健全政府网站信息内容建设年度考核评估和督查常态化工作机制，保障政府网站有效运行，杜绝问题再次发生。新改版的网站要避免出现空白栏目、更新不及时等问题。

（四）推进集约化建设和网站纠错。各单位要加强政府网站集约化建设，集中力量办好政府网站。各基层单位政府网站如缺乏运行维护能力，应及时迁移至上级单位政府网站统一运营，并在全国政府网站信息报送系统及时更新网站数据信息。按照国务院办公厅有关要求，各级质检部门政府网站要于4月30日前加挂“我为政府网站找错”平台入口，邀请广大网民帮助发现网站问题。（具体操作事宜请与总局信息中心联系，联系人：李素花，联系电话：010-82262317）

今后，总局办公厅将会同信息中心持续组织政府网站季度抽查，并将抽查及各单位整改情况报送国务院办公厅政府信息与政务公开办公室（以下简称“国办公开办”）。国办公开办将对各单位政府网站进行监督抽查，并对总局开展过季度抽查的网站进行复查。上述检查情况及各单位整改情况将纳入2017年质检直属系统政府网站绩效考核。

质检总局办公厅
