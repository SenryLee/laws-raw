# 国家文物局关于佑顺寺和朝阳北塔保护规划编制立项的意见

## 关于佑顺寺和朝阳北塔保护规划编制立项的意见

办保函〔2017〕312号

辽宁省文物局：

你局《关于上报佑顺寺保护规划立项报告的请示》（辽文物〔2017〕21号）、《关于上报朝阳北塔保护规划立项报告的请示》（辽文物〔2017〕23号）收悉。经研究，我局意见如下：

一、佑顺寺、朝阳北塔的文物构成较为简单，规划编制的必要性和紧迫性不足，我局不同意佑顺寺、朝阳北塔保护规划编制立项。

二、请你局督促、指导地方人民政府加强“四有”建设，完善佑顺寺、朝阳北塔的保护区划、管理规定和具体保护管理措施，严格控制周边各类建设活动。同时，应切实做好文物日常养护、巡查和岁修工作，确保文物安全。如发现影响文物安全的病害险情，应及时启动保护工作，并按要求履行报批程序。

专此函。

国家文物局

2017年3月24日
