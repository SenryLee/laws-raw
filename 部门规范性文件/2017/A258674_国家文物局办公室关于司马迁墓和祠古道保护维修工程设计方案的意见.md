# 国家文物局办公室关于司马迁墓和祠古道保护维修工程设计方案的意见

办保函〔2017〕1369号

陕西省文物局：

你局《关于上报司马迁墓和祠古道保护维修工程设计方案的请示》（陕文物字〔2017〕393号）收悉。经研究，我局意见如下：

一、所报方案中新建栈道的必要性不足，古道作为文物本体的保护内容不明确，我局暂不同意所报方案。

二、具体修改意见如下：

（一）应客观分析游客量及其踩踏对古道本体的影响，补充论证设置栈道的必要性。如确有必要，原则上栈道设计应尽可能借用古道两侧现有后期道路满足人行需求，设置体量最小的必要的跨越结构。新的栈道结构不得对古道文物本体产生破坏，尽可能不设固定基础。

（二）应补充分析古道本体存在的主要病害及其原因，仅对确有较快发展趋势的病害采取有针对性的延缓措施，并补充相应图纸和现状照片，避免不必要的干预。

（三）应补充必要的现状总平面图和相关保护区划图。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善后，按程序另行报批。

国家文物局办公室

2017年12月13日
