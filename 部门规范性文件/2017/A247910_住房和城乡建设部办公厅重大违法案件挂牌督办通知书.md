# 住房和城乡建设部办公厅重大违法案件挂牌督办通知书

## 重大违法案件挂牌督办通知书

建督办[2017]2号

河南省住房和城乡建设厅：

你省太康县华夏外国语小学2005年在未取得《建设工程规划许可证》情况下，先后建设了4栋教学楼、5栋宿舍楼、1座餐厅和8栋住宅楼；2010年违法占用毗邻的1.5万平方米集体土地擅自建设和销售多栋别墅，严重违反《中华人民共和国城市规划法》第三十二条和《中华人民共和国城乡规划法》第四十条等规定。

现决定对该案进行挂牌督办。请你厅责令立即停止违法建设，依法查处违法行为，并追究有关单位和个人责任。请于2017年6月2日前报告处理整改结果。依法整改到位后，我部将按程序解除挂牌督办。
