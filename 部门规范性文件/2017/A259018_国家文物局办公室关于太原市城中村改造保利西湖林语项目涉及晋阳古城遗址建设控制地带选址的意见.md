# 国家文物局办公室关于太原市城中村改造保利西湖林语项目涉及晋阳古城遗址建设控制地带选址的意见

办保函〔2017〕1396号

山西省文物局：

你局《关于在晋阳古城遗址建设控制地带内进行太原市城北村、贾家庄村城中村改造及保利西湖林语项目建设的请示》（晋文物〔2017〕211号）收悉。经研究，我局意见如下：

一、暂不同意太原市城北村、贾家庄村城中村改造保利西湖林语建设项目涉及晋阳古城遗址建设控制地带的选址方案。

二、所报建设项目紧邻晋阳古城遗址保护范围，建筑规模和体量过大，严重影响遗址及其周边环境风貌。建议重新调整设计，进一步降低建筑高度和容积率；靠近保护范围一侧应以景观绿化和设置社区活动中心、学校为主。文物影响评估应客观分析拟建建筑的影响，并研提具体调整建议。补充拟建建筑与晋阳古城遗址的视线分析，以及相关建筑立面图、剖面图、整体效果图等图纸和信息。

三、请你局指导项目建设单位，根据上述意见进一步修改和完善所报方案，按程序另行报批。

四、请你局指导当地人民政府组织专业机构，按照《关于晋阳古城遗址保护规划纲要的批复》（文物保函〔2011〕299号）要求，抓紧编制保护规划，明确建设控制地带的具体控制指标，为晋阳古城遗址相关保护与建设项目提供依据。

国家文物局办公室

2017年12月19日
