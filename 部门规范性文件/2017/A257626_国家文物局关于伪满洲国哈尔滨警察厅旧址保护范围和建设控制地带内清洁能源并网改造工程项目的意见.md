# 国家文物局关于伪满洲国哈尔滨警察厅旧址保护范围和建设控制地带内清洁能源并网改造工程项目的意见

文物保函〔2017〕1838号

黑龙江省文物局：

你局《关于哈尔滨清洁能源供暖并网改造工程穿行全国重点文物保护单位伪满警察厅旧址保护范围和建设控制地带的请示》（黑文管字〔2017〕27号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、对所报项目提出以下修改完善意见：

（一）保护范围内供暖管线应采取双重防渗处理，防止管线漏水影响文物建筑地基与基础。

（二）深化文物建筑主体结构勘察，做好施工期间文物本体的监测及记录工作。

（三）施工期间应对文物本体采取防护措施，加强人员机械管理，避免施工对文物造成损害。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十七条、第十八条规定，分别报黑龙江省人民政府和城乡建设规划部门批准后实施。工程施工期间，应加强监管，确保文物安全。

国家文物局

2017年11月9日
