# 中华人民共和国海关总署对十二届全国人大五次会议第1227号建议的答复

马光明代表：

您提出的《关于推进马鬃山口岸复通的建议》（第1227号）收悉。经研究并商外交部，现答复如下：

您曾在十二届全国人大三次会议上也提出过马鬃山口岸复关的建议，我署做过详细答复，近两年仍无新的进展。我署作为国家口岸主管部门充分理解恢复马鬃山边境口岸对促进甘肃省开放型经济发展的重要意义，我署和外交部等国家有关部门高度重视、积极支持马鬃山边境口岸恢复开放。

按照国家有关规定，边境口岸开放的前提是两国外交达成一致。自2015年来，中蒙两国正就重新签署《中蒙边境口岸管理制度及其协定》进行磋商，我署和外交部通过各种渠道多次就马鬃山口岸恢复开放问题与蒙方磋商，争取达成一致。在近两年召开的中蒙边境口岸管理合作委员会第一、二次会议和两轮《中蒙边境口岸管理制度及其协定》落实情况司局级会晤上，中方均将马鬃山口岸恢复开放列为会议议题，但蒙方均未予以积极回应。随着近年来两国关系发展和我有关省份经济改革深化，该口岸恢复开放的客观需求正在变强。下一步，我署将继续与外交部密切配合，加强与蒙方多途径、多层次的协商，同时也建议地方政府加强与蒙地方政府的沟通力度，共同努力争取早日实现该口岸恢复开放。

感谢您对我们工作的关心与支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2017年6月26日
