# 国家测绘地理信息局关于全国省级测绘地理信息主管部门2017年度测绘地理信息工作绩效考核结果的通报

## 关于全国省级测绘地理信息主管部门2017年度测绘地理信息工作绩效考核结果的通报

国测办发〔2017〕228号

各省、自治区、直辖市测绘地理信息主管部门：

2017年，全国省级测绘地理信息主管部门（以下简称省级部门）全面贯彻党的十八大和十九大精神，深入学习领会习近平新时代中国特色社会主义思想，深入贯彻落实习近平总书记给国测一大队老队员老党员回信重要指示精神，树立“四个意识”，坚定“四个自信”，团结带领广大干部职工坚持依法行政，坚持改革创新，牢牢把握新时代对测绘地理信息的新需求，着力服务大局、服务社会、服务民生，推动测绘地理信息工作打开了新局面，取得了新成效。

经全国省级测绘地理信息主管部门年度测绘地理信息工作绩效考核领导小组各成员单位评议、领导小组研究并报国家局党组审定，国家测绘地理信息局决定，浙江省测绘与地理信息局等10家省级部门2017年度测绘地理信息工作绩效考核结果为优秀，其余21家省级部门绩效考核结果为达标。山西省测绘地理信息局等6家省级部门绩效考核总体成绩较2016年有较大幅度提高，评定为突出进步单位。黑龙江测绘地理信息局等4家省级部门分别在推动测绘地理信息科技创新、服务地方政府“多规合一”、拓展测绘地理信息应用领域、推动所在地方测绘地理信息管理工作等方面取得较明显的成绩或实现历史性突破，评定为特色工作创新单位。

希望获得荣誉的省级部门再接再厉，进一步推动本地区测绘地理信息工作再上新台阶。全国省级部门要以绩效考核优秀部门为榜样，坚持以习近平新时代中国特色社会主义思想为指导， 认真学习贯彻党的十九大精神，切实把党的十九大精神转化为推动测绘地理信息事业改革创新发展的强大动力，深入贯彻落实党中央国务院关于测绘地理信息工作的决策部署，牢牢把握新时代对测绘地理信息的新需求，认真贯彻落实新发展理念，以深化供给侧结构性改革为主线，加快推进“五大业务”体系建设，不断优化和改造测绘地理信息生产服务模式，拓展测绘地理信息服务范围和领域，着力提升基础地理信息资源供给能力，提高测绘地理信息供给质量和效益，更好地满足经济社会发展和人民群众对测绘地理信息的新需要，切实担负起新时代测绘地理信息工作者的新使命，为决胜全面建成小康社会、实现中华民族伟大复兴的中国梦贡献力量。
