# 国土资源部办公厅关于推荐第六批全国油气勘查开采督察员的通知

国土资厅函〔2017〕370号

各省、自治区、直辖市国土资源主管部门，中国地质调查局，国土资源部信息中心、油气资源战略研究中心、中国国土资源经济研究院，有关石油企业办公厅（室）：

为加强油气督察员队伍建设，切实做好油气资源勘查开采监督管理工作，根据《国土资源部关于印发矿产勘查及油气开采督察员工作制度的通知》（国土资发〔2003〕99号）有关规定，我部拟开展第五批油气勘查开采督察员总结考核和第六批油气勘查开采督察员聘任工作，现将有关事项通知如下。

一、请各省级国土资源主管部门和部油气中心分别对所管理的油气督察员近3年来的工作开展情况进行总结考核，分析存在的问题并提出下一步工作目标和建议，同时对2014—2016年度中央下达的油气督察员经费管理和使用情况作出说明。

二、各单位根据分配名额（附件1），本着向基层倾斜、向油气资源勘查开采重点地区倾斜的原则，做好油气督察员的推荐工作，要将政治素质高、业务能力强、有责任心的同志推荐到油气督察员队伍中来，同时组织填写油气勘查开采督察员推荐表（附件2）和信息汇总表（附件3）。

三、各省级国土资源主管部门负责做好行政区域内所有油田产生的油气督察员推荐工作，具体名额由各省级国土资源主管部门在分配名额范围内自行掌握。

四、请各单位认真做好督察员推荐和总结考核工作，并将相关材料于2017年3月30日前，报国土资源部油气资源战略研究中心，同时将电子版照片、表格和总结报告发送至邮箱dcymlr＠163.com。
