# 中华人民共和国海关总署对十二届全国人大五次会议第5105号建议的答复

旺堆代表：

您提出的《关于支持南亚物流园区（珠峰开发开放试验区）项目建设的建议》（发展规划、建设项目和综合经济类第5105号）收悉。经认真研究，现答复如下：

2015年5月，保税物流中心（B型）（以下简称保税物流中心）设立审批已转为行政许可项目。根据《中华人民共和国行政许可法》及《中华人民共和国海关对保税物流中心（B型）的暂行管理办法》（海关总署令第130号，海关总署令第227号修订）的相关规定，保税物流中心的设立应由保税物流中心经营企业按照相关规定向当地直属海关提出书面申请，我署按照行政许可相关程序办理。根据《海关总署 财政部 税务总局 外汇局关于〈保税物流中心（B型）设立指导意见〉和〈2015—2017年保税物流中心（B型）设立规划〉的通知》（署加发〔2015〕51号）规定，西藏自治区现有1个可申请设立保税物流中心的指标。

我署积极支持西藏自治区开放型经济的发展，高度重视地方发展对设立保税物流中心的需求，将对日喀则地区根据地方经济发展需要提出的设立保税物流中心的申请给予积极支持，在收到保税物流中心设立申请后，严格按照行政许可相关程序办理。

感谢您对我们工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2017年6月19日
