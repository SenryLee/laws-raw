# 国家新闻出版广电总局关于2017年第一季度全国国产电视剧发行许可情况的通告

〔2017〕7号

根据国家电视剧内容管理的有关规定，现将总局及各省级新闻出版广电行政部门2017年第一季度全国《国产电视剧发行许可证》颁发统计情况予以通告。

2017年度1-3月，全国各类电视剧制作机构共计生产完成并获准发行国产电视剧56部2221集。根据总局以及各省电视剧管理部门的月报备案统计，题材比例情况如下：

现实题材剧目共计34部1287集，分别占总比例的60.71%、57.95%。其中，当代题材共计31部1169集，分别占总部、集数的55.36%、52.63%；现代题材共计3部118集，分别占总部、集数的5.36%、5.31%。

历史题材剧目共计21部894集，分别占总比例的37.5%、40.25%。其中，近代题材共计15部719集，分别占总部、集数的26.79%、32.37%；古代题材共计6部175集，分别占总部、集数的10.71%、7.88%。

重大题材共计1部40集，分别占总部、集数的1.79%、1.8%。

附件：2017年1-3月全国《国产电视剧发行许可证》目录

国家新闻出版广电总局

2017年5月27日
