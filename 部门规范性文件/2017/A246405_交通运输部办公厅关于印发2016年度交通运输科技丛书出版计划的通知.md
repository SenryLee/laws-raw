# 交通运输部办公厅关于印发2016年度交通运输科技丛书出版计划的通知

交办科技函〔2017〕14号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），中国交通建设集团有限公司、招商局集团、长安大学、上海海事大学、武汉理工大学、重庆交通大学、交通运输部科学研究院、交通运输部公路科学研究院、中国交通通信信息中心、交通运输部天津水运工程科学研究院、大连海事大学：

为深入实施创新驱动发展战略，加大交通运输科技成果的推广应用力度，集中展示交通运输领域科技成果，促进高层次的学术交流、技术传播和专业人才培养，我部组织编制了2016年度《交通运输科技丛书出版计划》（以下简称《科技丛书》），经评审和公示，现予发布，并就有关事宜通知如下：

一、列入2016年度《科技丛书》的学术著作共19本（见附件），可通过科技丛书查询交流平台（http://www.transst.cn）查阅。

二、各单位要高度重视科技丛书的编制出版、宣传展示、交流学习工作，充分发挥科技丛书鼓励创新、凝练成果、促进转化的重要载体作用。

三、各单位对科技丛书的编制出版、展示宣传等工作，若有意见、建议，请及时向交通运输部科技司反馈。

联系人：科技司 汪水银 010-65292860

交通运输部办公厅

2017年1月5日
