# 水利部规划计划司关于2017年度水利部定点扶贫重庆市丰都县脱贫攻坚工作5月份进展情况的通报

## 关于2017年度水利部定点扶贫重庆市丰都县脱贫攻坚工作5月份进展情况的通报

水利部定点扶贫重庆市丰都县工作组各成员单位：

为帮助丰都县巩固脱贫攻坚成果，按照《水利部对口帮扶重庆市丰都县脱贫攻坚实施方案》《水利部定点扶贫重庆市丰都县“八大工程”2017年度工作计划》要求，现将定点扶贫丰都县5月份工作进展情况通报如下：

一、近期开展的主要工作

（一）“八大工程”进展情况

1、农村饮水安全巩固提升工程。丰都县农村饮水安全巩固提升工程2017年计划完成年度总投资3127万元，新建（改扩建）供水工程7处。截至目前，4处已全部完工，完成总投资2757万元（4月份完成投资2524万元），占计划任务的88%，其中完成中央投资1102万元，占计划完成中央投资的124%。

2、千塘万亩特色产业支撑工程。丰都县千塘万亩特色产业支撑工程2017年计划总投资3650万元，整治山坪塘335口。截至目前，整治山坪塘任务已全部完成。

3、小型水库水源保障工程。2017年，丰都县小型水库水源保障工程计划完成总投资5000万元，续建水源工程项目3处，开工建设1处。截至目前，已完成投资1361万元（4月份完成投资806万元），加快推进王家山、沱沱坝、硝厂沟水库建设，小月坝、观音岩、莲花、灯塔等4座水库前期工作正在加快开展。

4、贫困户产业帮扶工程。部移民局协调长江设计院（20万元）、澧水公司（30万元）、右江公司（30万元）、中国水科院（20万元）拨付帮扶资金100万元，目前已全部到位。丰都县已为197户贫困户发放小额贴息贷款793.5万元（其中个人信用贷款446.5万110户；新型农业经营主体贷款9家，贷款金额347万元，建立利益链接87户），用于种植、养殖及贸易业等产业发展。

5、贫困户转移就业技能培训工程。长江委协调推进转移就业技能培训资金拨付工作，黄河水科院（20万元）、发展研究中心（2万元）和水利报社（3万元）培训资金已拨付到位。5月13日至19日，长江委牵头开展第一期贫困户转移就业技能培训班，主要培训内容为计算机操作、电子装配工等，80人次参加。

6、贫困学生勤工俭学帮扶工程。重庆水利局编制完成丰都县2017年勤工俭学工程实施方案，并结合贫困学生勤工俭学意愿，与重庆市水投集团、丰都县水务局落实好具体单位。

7、水利建设技术帮扶工程。中国水科院充分发挥技术优势，指导丰都县完成水利风景区的资料汇编工作，并上报至部景区办；抓紧开展三峡库区消落带基础资料的收集整理和技术路线的制定；加快推进龙河流域规划报告编制。长江设计院已编制完成观音岩、莲花水库初步设计报告，正在抓紧编制移民、水资源论证等专题报告；同时，加快小月坝水库初步设计报告编制工作，修改完善《重庆市丰都县龙河国家级水利风景区生态调节坝工程项目建设方案报告》。

8、专业技术人才培训工程。2017年，部水资源司牵头开展培训工作，计划培训丰都县干部职工101人次。截至目前，丰都县水务局已组织62人次参加发展研究中心、重庆市水利局等单位主办的专业技术培训班。

（二）其他相关帮扶事项

重庆市水利局积极与市发展改革委、市财政局沟通协调，5月安排丰都县2017年农村饮水安全巩固提升工程市级以上资金920万元，超全市平均水平。同时，下达市级以上资金7352万元，推进丰都县龙兴坝中型水库工程建设。

二、下一步工作建议

目前定点扶贫丰都县脱贫攻坚各项工作进展顺利，请各成员单位进一步加强协调配合，围绕水利定点扶贫丰都县“八大工程”年度任务，加强前期工作，抓好项目实施和跟踪落实工作，加快推动工程建设，保证工程质量安全和效益发挥，确保年度任务的完成，助力丰都县巩固脱贫攻坚成果。
