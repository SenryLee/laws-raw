# 中国证券监督管理委员会对十二届全国人大五次会议第8279号建议的答复

## 对十二届全国人大五次会议第8279号建议的答复

《关于以中德（沈阳）高端装备产业园为载体大力推进与德国工业4.0战略对接的建议》收悉。经认真研究，现就有关问题答复如下：

我会依法对证券市场实行集中统一监管，按照“公开、公平、公正”原则支持符合条件的各类企业上市融资，服务实体经济发展。近年来，我会始终坚持服从服务于实体经济内在需求，积极推进境内市场新股发行常态化和境外上市简政放权改革，通过境内外发行上市、并购重组等多种手段，支持包括智能制造、高端装备、汽车制造、工业服务及战略性新兴产业在内的企业利用资本市场做大做强，促进实体经济与资本市场的对接。2017年3月，人民银行牵头，我会等部委参与制定发布《关于金融支持制造强国建设的指导意见》，进一步明确了对制造强国建设提供金融支持和服务的要求。

为更好支持和服务制造强国建设，我会将积极支持中德（沈阳）高端装备产业园对接证券市场，支持园区内符合条件的各类企业重组上市，或通过并购重组方式注入上市公司。同时，符合发行上市条件的园区内企业，可向我会提出境内或境外发行上市申请，充分利用境内外两个市场、两种资源。下一步，我会将继续积极推进简政放权，全面优化流程，提升工作效率，提高服务实体经济的能力，积极为包括中德（沈阳）高端装备产业园在内的高端制造业发展提供金融支持。
