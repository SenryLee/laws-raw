# 国家文物局办公室关于德格印经院壁画数字化勘察测绘项目的意见

办保函〔2017〕1172号

四川省文物局：

《四川省文物局关于报送德格印经院壁画数字化勘察测绘技术方案的请示》（川文物〔2017〕95号）收悉。经研究，我局意见如下：

一、应进一步明确壁画数字化勘察测绘项目的主要任务和目标，分析数字化勘察、病害稳定性评估测绘等技术在壁画保护中的应用前景，深入研究数字档案资料留存、数据管理体系搭建、数字化成果共享及在艺术史和保护技术、展示利用方面等工作，促进文物本体保护。

二、请你局指导地方人民政府，切实做好德格印经院的保护和管理工作，加强日常养护、巡查和监测，确保文物安全。壁画如确需维修，应按照我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的要求履行审批程序。

国家文物局办公室

2017年10月16日
