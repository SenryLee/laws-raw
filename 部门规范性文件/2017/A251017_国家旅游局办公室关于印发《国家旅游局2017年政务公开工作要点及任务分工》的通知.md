# 国家旅游局办公室关于印发《国家旅游局2017年政务公开工作要点及任务分工》的通知

旅办发〔2017〕107号

各司室、直属单位，旅游专业协会：

《国家旅游局2017年政务公开工作要点及任务分工》已经局领导批准，现印发给你们，请认真贯彻执行。

国家旅游局办公室

2017年5月4日

## 国家旅游局2017年政务公开工作要点及任务分工

2017年，国家旅游局政府信息公开工作要深入贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，认真落实《政府工作报告》中有关旅游工作部署，按照中办、国办《关于全面推进政务公开工作的意见》及其实施细则（以下简称《意见》及实施细则）要求，全面推进决策、执行、管理、服务、结果公开（以下统称“五公开”），加强解读回应，扩大公众参与，增强公开实效，以优异成绩迎接党的十九大胜利召开。

一、推进“放管服”改革信息公开

1.以清单管理推动减权放权，各类清单都要及时向社会公开。按照国务院关于简政放权的统一部署，及时向社会公开权责清单。通过局官方网站及时公开取消、下放、保留行政审批项目以及非行政许可审批事项清理等信息，并动态更新，方便公众获取和监督（政法司、监管司、人事司负责）。

2.要及时公开政策性文件的废止、失效等情况，并在政府网站已发布的原文件上作出明确标注（政法司牵头，各有关单位按照职责分工分别负责）。

3.围绕年内实现“双随机、一公开”监管全覆盖目标，要探索形成并统一公布本级随机抽查事项清单，明确抽查依据、主体、内容、方式等，及时公开抽查结果和查处情况（监管司、规财司负责）。

4.大力推进“互联网+政务服务”，年内完成政务服务事项目录编制工作，通过局官方网站集中全面公开（办公室负责）。

5.推进行政审批事项的在线办理，推动企业注册登记、项目投资、创业创新以及与群众生活密切相关的服务事项上网，让企业和群众办事更加便捷（监管司、人事司牵头，各有关单位按照职责分工分别负责）。

二、进一步推进主动公开

6.围绕支持创业创新、推动新产业健康发展、改造提升传统产业等，加大政策及其执行情况公开力度，及时发布推广典型经验做法。在制定新产业、新业态、新模式等方面监管政策时，要通过征求意见、听证座谈、咨询协商等方式，扩大相关市场主体的参与度。注重收集公众对发展新产业、培育新动能政策的反映，主动及时做好解疑释惑和舆论引导工作（各有关单位按照职责分工分别负责）。

7.推进公共资源配置信息公开。及时完整公开政府采购项目信息、采购文件、中标或成交结果、采购合同等。推进工程建设项目招标、投标等信息公开工作（规划财务司负责）。

8.推进财政资金信息公开。做好部门预决算公开，及时公开经批准的预算、决算及单位职责、机构设置、机关运行经费等信息。细化预决算公开内容，除涉密信息外，部门预决算在公开到支出功能分类项级科目的基础上，一般公共预算基本支出公开到经济分类款级科目（规划财务司负责）。

9.重点推进旅游市场监管执法信息公开，及时公开行政处罚公开事件名称、被处罚姓名或名称，以及监管执法的依据、内容、标准、程序和结果。继续做好旅游不文明行为记录，依法依规公开当事人姓名、性别、户籍省份、不文明行为及造成的影响、后果、不文明行为记录期限（监管司负责）。

10.做好12301投诉举报平台建设工作，发布市场整治典型案例（质监所、监管司负责）。

三、全面落实“五公开”工作机制

11.认真落实《意见》及实施细则的相关要求，年内要完成“五公开”纳入办文办会程序、建立公开内容动态扩展机制等工作，加快制定主动公开基本目录，稳步有序拓展公开范围（办公室负责）。

12.对涉及公众利益、需要社会广泛知晓的电视电话会议，除涉及国家秘密的外，要积极通过网络、新媒体直播等向社会公开（各有关单位按照职责分工分别负责）。

13.进一步做好全国人大代表建议和全国政协委员提案办理结果公开工作，对涉及公共利益、社会广泛关注的建议提案，原则上都要公开答复全文，及时回应关切，接受群众监督（办公室牵头，各有关单位按照职责分工分别负责）。

四、进一步健全解读回应机制

14.切实落实《意见》及实施细则关于做好政策解读回应的相关规定。局主要负责人要履行好“第一解读人和责任人”的职责，充分利用新闻发布会、政策吹风会等方式，主动回应重大舆论关切，释放信号，引导预期（综合司牵头，各有关单位按照职责分工分别负责）。

15.要按照“谁起草、谁解读”的原则，做到政策性文件与解读方案、解读材料同步组织、同步审签、同步部署。严格执行特别重大、重大突发事件最迟5小时内发布权威信息、24小时内举行新闻发布会的时限要求，落实通报批评和约谈制度，确保回应不超时、内容不敷衍（综合司牵头，各有关单位按照职责分工分别负责）。

五、加强政务公开平台建设

16.办公室要切实履行对政府网站的监管责任，进一步加强和改进政府网站内容建设，做好日常监测和季度抽查，及时公开抽查情况；推进政府网站集约化，对保障不力的要关停上移，切实提高管理水平（办公室负责，信息中心配合）。

17.要用好管好政务新媒体，明确开办主体责任，健全内容发布审核机制，强化互动和服务功能，切实解决更新慢、“雷人雷语”、无序发声、敷衍了事等问题（综合司、信息中心负责）。

六、依法规范依申请公开工作

18.畅通依申请公开受理渠道，依法保障公众合理的信息需求。进一步规范依申请公开答复工作，严格按照法定时限答复，增强答复内容针对性并明示救济渠道，答复形式要严谨规范。对依申请公开工作中发现的依法行政方面问题，要及时向相关单位提出工作建议。对公众申请较为集中的政府信息，可以转为主动公开的，应当主动公开（办公室牵头，各有关单位按照职责分工分别负责）。

各单位要进一步提高对信息公开工作的认识，加强组织领导，明确责任分工，加强检查督导，确保各项任务落实到位。年内办公室将对政务公开工作开展情况进行一次全面检查，并统筹做好国务院办公厅专项督查和第三方评估有关工作。
