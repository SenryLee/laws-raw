# 国家食品药品监督管理总局办公厅关于印发化妆品监督抽检工作规范的通知

## 总局办公厅关于印发化妆品监督抽检工作规范的通知

食药监办药化监〔2017〕103号

各省、自治区、直辖市食品药品监督管理局，新疆生产建设兵团食品药品监督管理局，中国食品药品检定研究院:

为规范化妆品监督抽检工作，根据《化妆品卫生监督条例》等有关法规规章，国家食品药品监督管理总局组织制定了《化妆品监督抽检工作规范》，现予印发，请遵照执行。

食品药品监管总局办公厅

2017年7月27日

附件：化妆品监督抽检工作规范
