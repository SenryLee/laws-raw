# 中共教育部党组关于杜鹏、伊志宏同志职务任免的通知

教党任〔2017〕194号

中共中国人民大学委员会：

经与中共北京市委商得一致，2017年7月24日研究决定：

杜鹏同志任中共中国人民大学委员会常委；免去伊志宏同志的中共中国人民大学委员会常委职务。

中共教育部党组

2017年8月24日
