# 国家烟草专卖局办公室关于转发《“健康中国2030”规划纲要》的通知

国烟办新〔2017〕3号

行业各直属单位，国家局、总公司机关各部门、各单位：

为贯彻落实全国卫生与健康大会精神和《“健康中国2030”规划纲要》（中发〔2016〕23号，以下简称《纲要》），更好地支持健康中国建设，进一步推进控烟履约工作，现将《纲要》转发给你们，并就有关要求通知如下：

一、加强学习，认真领会

推进健康中国建设，是全面建成小康社会、基本实现社会主义现代化的重要基础，是全面提升中华民族健康素质、实现人民健康与经济社会协调发展的国家战略，是积极参与全球健康治理、履行2030年可持续发展议程国际承诺的重大举措。烟草行业同人民健康有着特殊的关联、特殊的责任、特殊的任务，实行烟草专卖管理、开展控烟履约工作是行业参与健康中国建设的主要内容。要从战略和全局的高度，充分认识此项工作的重要性、长期性和艰巨性，切实增强责任感、使命感，坚决落实党中央、国务院决策部署，坚持国家利益至上、消费者利益至上，坚持改革创新、科学发展。要牢固树立“全民健康”理念，坚决保障和不断提升行业广大干部职工的健康水平，为推进健康中国建设作出更大贡献。

二、结合本职，认真落实

按照《纲要》关于“开展控烟”的目标任务，结合行业职责，加大控烟履约工作力度，努力为人民健康服务。一是坚持依法组织实施控烟。落实烟草专卖管理要求，严格执行国家烟草专卖法律法规，严格执行国家指令性计划管理，严格执行国家税收和价格政策。按照“依法控烟、全面履约，政府主导、各界参与，多措并举、协调推进，突出重点、务求实效”原则，认真履行《烟草控制框架公约》及我国烟草控制规划明确规定的责任和义务。二是实施科技创新减少烟草危害。坚持以减少烟草吸入量、减少焦油含量、减少其他有害成分为主线，加强科技创新，追求优质低害，有效维护消费者健康。三是严厉打击烟草制品非法贸易。完善工作机制，持续提升打假打私工作科学化、法治化、常态化水平，不断提高市场净化率，有效维护消费者利益。

三、加强宣传，认真推进

深入开展健康宣传，形成全行业关心支持健康中国建设的良好氛围，提高广大干部职工的健康意识和水平。倡导健康文明生活方式，加强吸烟危害健康的宣传教育，坚决支持中小学生禁烟、坚决劝阻青少年吸烟。倡导依法科学控烟理念，理直气壮宣传烟草专卖制度所发挥的积极作用，加深社会对行业的认知和理解，营造理性控烟良好氛围，避免控烟“扩大化、片面化、绝对化”过激倾向，全面提升行业控烟履约形象。

附件：《“健康中国2030”规划纲要》

国家烟草专卖局办公室
