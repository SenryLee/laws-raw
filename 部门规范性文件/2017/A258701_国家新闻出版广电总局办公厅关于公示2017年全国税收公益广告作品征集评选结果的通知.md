# 国家新闻出版广电总局办公厅关于公示2017年全国税收公益广告作品征集评选结果的通知

新广电办发〔2017〕73号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央三台，电影频道节目中心，中国教育电视台：

为进一步宣传税收改革发展的成效和税收服务经济社会的成果，充分利用好公益广告这一载体，切实增强税收宣传的影响力和感染力，2017年6月，国家新闻出版广电总局、国家税务总局联合开展了2017年全国税收公益广告作品征集暨展播活动，得到社会各界积极响应。日前，经活动组委会审核，共评出一、二、三类作品及优秀类、入围类作品共127件，优秀活动组织单位12家，现予以公示。公示内容可以在国家新闻出版广电总局政府网站（网址：www.sapprft.gov.cn）通知公告区中查询。

请立即向辖区内有关单位或个人通报公示内容。有关单位和个人均可就公示内容存在的问题，于12月15日前向国家新闻出版广电总局传媒司反映。

国家新闻出版广电总局联系人：许旭，010-86098540。

附件：

1.2017年全国税收公益广告作品征集活动广播类扶持作品名单

2.2017年全国税收公益广告作品征集活动电视类扶持作品名单

3.2017年全国税收公益广告作品征集活动动漫类扶持作品名单

4.2017年全国税收公益广告作品征集活动优秀组织单位名单

国家新闻出版广电总局办公厅

2017年12月1日
