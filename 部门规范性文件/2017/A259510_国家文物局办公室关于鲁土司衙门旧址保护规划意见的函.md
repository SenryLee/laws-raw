# 国家文物局办公室关于鲁土司衙门旧址保护规划意见的函

办保函〔2017〕1415号

甘肃省文物局：

你局《关于呈报鲁土司衙门旧址文物保护规划的报告》（甘文局发〔2016〕126号）收悉。经研究，我局意见如下：

一、所报规划研究深度不足，我局暂不同意鲁土司衙门旧址保护规划。

二、所报规划应做以下必要修改和完善：

（一）明确规划目标。突出鲁土司衙门文物本体保护。明确保护对象，对已毁建筑遗址、墓园进行客观准确评估后，决定是否纳入文物构成要素。

（二）深化价值评估，完善现状评估。补充本体评估、已经实施的文物保护工程等内容的评估，并增加相应的评估图纸，加强评估与措施的对应。

（三）在与历史文化名镇保护规划充分衔接的基础上优化保护区划，理顺管理规定。

（四）规范图纸表达，增强文本与图纸对应性。

三、请你局指导有关单位，根据上述意见对鲁土司衙门旧址保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月26日
