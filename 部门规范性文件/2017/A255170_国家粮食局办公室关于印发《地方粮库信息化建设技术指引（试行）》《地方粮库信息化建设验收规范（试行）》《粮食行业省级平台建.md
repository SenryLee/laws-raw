# 国家粮食局办公室关于印发《地方粮库信息化建设技术指引（试行）》《地方粮库信息化建设验收规范（试行）》《粮食行业省级平台建设技术指引（试行）》和《粮食行业省级平台建设验收规范（试行）》的通知

国粮办发〔2017〕217号

各省、自治区、直辖市及新疆生产建设兵团粮食局，中国储备粮管理总公司，河南工业大学、南京财经大学、武汉轻工大学：

为进一步规范粮库信息化和省级平台建设，促进粮食行业信息化健康发展，我局组织编写了《地方粮库信息化建设技术指引（试行）》《地方粮库信息化建设验收规范（试行）》《粮食行业省级平台建设技术指引（试行）》和《粮食行业省级平台建设验收规范（试行）》（附件，电子版本在国家粮食局政府网站政策通知栏目下载）。现印发实施。

技术指引和验收规范先行先试，在试行推广中不断修订完善，请各地及时反馈意见建议。

特此通知。

联系人：彭守根 63906745

杨　正 63906247

附件：1.地方粮库信息化建设技术指引（试行）

2.地方粮库信息化建设验收规范（试行）

3.粮食行业省级平台建设技术指引（试行）

4.粮食行业省级平台建设验收规范（试行）

国家粮食局办公室
