# 国家核安全局关于停止哈电集团（秦皇岛）重型装备有限公司民用核安全设备焊工焊接操作工考核活动并责令限期整改的通知

## 关于停止哈电集团（秦皇岛）重型装备有限公司民用核安全设备焊工焊接操作工考核活动并责令限期整改的通知

国核安函[2017]40号

哈电集团（秦皇岛）重型装备有限公司:

我局于2017年3月15日对你公司民用核安全设备焊工焊接操作工考核中心（以下简称焊考中心）进行了现场检查，发现你公司焊考中心焊工项目考试过程中存在监考人员未按规定监考,同时编造考核过程记录文件的问题。根据《民用核安全设备焊工焊接操作工资格管理规定》（HAF603）第三十二条规定，我局决定责令你公司停止所有民用核安全设备焊工焊接操作工考核活动，并限于2017年7月31日前完成整改工作。同时，针对你公司提出如下核安全管理要求：

一、全面梳理存在问题，举一反三，制定切实有效的整改措施，坚决杜绝违规操作和弄虚作假，确保焊工考核质量保证体系有效运转。

二、认真组织开展核安全法规学习和核安全文化培训，提升焊考中心工作人员质量意识和核安全文化水平。

三、整改期限届满后，及时向我局提交整改报告。

四、经我局审查同意后，你公司方可重新开展民用核安全设备焊工焊接操作工考核活动。

国家核安全局

2017年5月3日
