# 国家知识产权局公告第242号——关于注销合肥市平海华一知识产权代理事务所（普通合伙）公告

## 国家知识产权局公告

第二四二号

## 关于注销合肥市平海华一知识产权代理事务所（普通合伙）公告

根据《专利代理条例》和《专利代理管理办法》的规定，依当事人申请，在其已经妥善处理各种尚未办结的事项后，我局同意注销合肥市平海华一知识产权代理事务所（普通合伙）。

特此公告。

国家知识产权局

2017年4月28日
