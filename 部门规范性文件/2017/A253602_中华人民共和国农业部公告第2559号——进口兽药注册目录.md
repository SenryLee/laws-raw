# 中华人民共和国农业部公告第2559号——进口兽药注册目录

## 中华人民共和国农业部公告

第2559号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准匈牙利诗华—费拉西亚兽医生物制品有限公司等3家公司生产的鸡新城疫、传染性支气管炎、减蛋综合征三联灭活疫苗（La Sota株+M41株+B8/78株）等4个产品在我国再注册，核发《进口兽药注册证书》,并发布修订后的产品质量标准、说明书和标签，自发布之日起执行。原我部发布的本产品质量标准、说明书和标签同时废止。

批准安德国际有限公司等2家公司生产的5个兽药产品在我国企业名称或生产厂名称变更注册。

特此公告。

附件：1.进口兽药注册目录

2.质量标准（略）

3.说明书和标签

农业部

2017年8月2日
