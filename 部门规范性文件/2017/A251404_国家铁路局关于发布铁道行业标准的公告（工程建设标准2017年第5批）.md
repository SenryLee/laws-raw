# 国家铁路局关于发布铁道行业标准的公告（工程建设标准2017年第5批）

## 国家铁路局关于发布铁道行业标准的公告

（工程建设标准2017年第5批）

国铁科法〔2017〕25号

现公布《铁路驼峰信号及编组站自动化系统设计规范》（TB 10069-2017）行业标准，自2017年7月1日起实施。《铁路驼峰信号设计规范》（TB 10069-2000）同时废止。

本标准由中国铁道出版社出版发行。

国家铁路局

2017年4月17日
