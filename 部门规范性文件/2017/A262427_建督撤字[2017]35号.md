# 建督撤字[2017]35号

李明水：

经调查核实，你在深圳市源远水利设计有限公司工作期间，违规将造价工程师资格证书注册在福建科艺建设有限公司，存在以欺骗手段取得注册证书的行为。

我部于2017年7月17日向你发出《住房城乡建设部撤销行政许可意见告知书》（建督撤告字[2017]43号），你于2017年8月10日签收，未在规定时间内提出书面陈述、申辩。

依据《中华人民共和国行政许可法》第六十九条、第七十九条以及《注册造价工程师管理办法》（建设部令第150号）第三十三条，我部决定撤销你的造价工程师注册，且你自撤销注册之日起3年内不得再次申请该项注册。请你在收到本决定书之日起15日内，持造价工程师注册证书和执业印章到福建省住房城乡建设厅办理相关手续。

如对本决定不服，你可自收到本决定书之日起60日内向我部申请行政复议或6个月内向人民法院提起行政诉讼。
