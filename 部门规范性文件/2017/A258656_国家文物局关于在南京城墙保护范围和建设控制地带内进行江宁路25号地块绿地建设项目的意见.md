# 国家文物局关于在南京城墙保护范围和建设控制地带内进行江宁路25号地块绿地建设项目的意见

文物保函〔2017〕1966号

江苏省文物局：

你局《关于审批江宁路25号地块绿地建设工程景观设计修改方案的请示》（苏文物保〔2017〕331号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位南京城墙保护范围和建设控制地带内进行江宁路25号地块绿地建设项目和你局意见。

二、对所报项目提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《南京市历史文化名城保护规划》、《南京城墙保护规划》、《南京城墙保护条例》的相关管理规定，严格控制工程量和工程范围，尽量减少对文物本体和地下遗存的影响。

（二）硬质景观处理应注意与城墙历史环境相协调。

（三）充分考虑建设施工对文物的影响，补充必要的应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十七条、第十八条的规定分别报江苏省人民政府和城乡建设规划部门批准。施工中请加强监管，确保工程质量和文物安全，施工过程中如发现文物，应进行保护并及时报告有关部门。

专此函复。

国家文物局

2017年12月7日
