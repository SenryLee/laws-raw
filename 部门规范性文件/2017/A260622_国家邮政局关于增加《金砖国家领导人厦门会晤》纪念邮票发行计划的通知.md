# 国家邮政局关于增加《金砖国家领导人厦门会晤》纪念邮票发行计划的通知

国邮发〔2017〕32号

中国邮政集团公司：

为宣传我国改革开放重大成就和重大外交成果，经商有关部门，我局决定在2017年纪特邮票发行计划中增加发行《金砖国家领导人厦门会晤》纪念邮票一套1枚，发行日期为2017年8月19日。请你公司据此抓紧开展相关工作。

国家邮政局

2017年4月13日
