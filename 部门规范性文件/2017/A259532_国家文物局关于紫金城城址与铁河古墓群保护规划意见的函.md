# 国家文物局关于紫金城城址与铁河古墓群保护规划意见的函

文物保函〔2017〕2055号

江西省文物局：

你局《关于呈报〈紫金城城址与铁河古墓群保护规划（修改稿）〉的请示》（赣文物局字〔2017〕107号）收悉。经研究，我局意见如下：

一、原则同意紫金城城址与铁河古墓群保护规划（修改稿）。

二、所报规划尚需做以下必要的修改和完善：

（一）结合地形参照物进一步优化保护范围和建设控制地带边界，增强可操作性。

（二）应根据文物保护管理需要，加强建设控制地带控制强度的分析研究，科学、合理研提具体建筑密度、容积率等控制指标和管理要求，进一步论证二类建设控制地带18米控高的依据。

（三）应结合考古工作成果调整展示利用规划，合理确定开放展示的区域和功能分区，预测游客量和运营维护成本，优化展示游线及出入口，避免大规模建设和过度干预。

（四）补充外部交通道路规划，统一布设墓葬区周围道路，并结合规划范围内村庄调控措施，进一步考虑配套服务设施建设问题，协调处理好文物保护展示和村民日常生产生活之间的关系。

（五）不同意大规模清理规划范围内现有植被，应注意保持现有生态环境和自然景观，避免过度城市园林化。不同意恢复历史水系。相关展示建议与标识系统建设统一考虑。

（六）进一步完善文本和图纸，做到科学、准确。不宜将创建5A级景区和申报世界文化遗产作为规划目标。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的保护规划报请江西省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护修缮、环境整治、阐释展示、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

国家文物局

2017年12月26日
