# 国家安全监管总局办公厅关于2017年第四季度政府网站抽查情况的通报

安监总厅宣教函〔2017〕278号

各省级煤矿安全监察局，总局和煤矿安监局机关各司局，应急指挥中心：

按照《国务院办公厅关于印发政府网站发展指引的通

知》（国办发〔2017〕47号）和《2017年第三季度全国政府网站抽查情况通报》要求，现将国家安全监管总局2017年第四季度政府网站抽查情况通报如下：

一、抽查总体情况

国家安全监管总局组织第三方机构于2017年11月11日至24日，对负责普查范围内的政府网站进行了季度抽查。按照《国务院办公厅关于开展第一次全国政府网站普查的通知》（国办发〔2015〕15号）确定的普查标准，采用“自动扫描+人工复核”相结合的方式，逐一打分评比。抽查对象为2017年前三季度总局抽查监测中发现的8家不合格网站。

抽查结果显示，5家网站综合评定为合格，分别为山西煤矿安全监察局网站、辽宁煤矿安全监察局网站、吉林煤矿安全监察局网站、江西煤矿安全监察局网站、陕西煤矿安全监察局网站；3家网站综合评定为不合格，分别为黑龙江煤矿安全监察局网站、河南煤矿安全监察局网站、新疆煤矿安全监察局网站。

二、发现的主要问题

（一）8家网站存在的主要问题

信息更新不及时。被抽查的8家网站中，有7家存在信息更新不及时或空白栏目问题。3家不合格网站中，2家网站存在更新不及时栏目数量超过10个，被单项否决;1家网站存在空白栏目数量超过5个，被单项否决。

不可用链接较多。有5家网站存在部分站内链接不可用问题，山西煤矿安全监察局网站不可用链接达100多条，辽宁煤矿安全监察局网站达200多条，黑龙江煤矿安全监察局网站不可用链接达300多条。

互动回应不够积极。有4家网站未开设政务咨询类栏目或1年内政务咨询栏目无有效信件展示；有4家网站未开设调查征集栏目，或虽开设了栏目但一年内开展活动少于3次。此外，有的网站还存在办事指南要素缺失或不准确、标记栏目无准确名称、标记栏目链接错误等问题。

（二）不合格网站存在的突出问题

黑龙江煤矿安全监察局网站共发现339个不可用链接、10个栏目更新不及时、2个空白栏目。此外，还发现2个互动回应相关问题，包块监测点前1年内开展调查征集活动次数少于3次、监测点前1年内政务咨询栏目无有效信件展示。办事指南要素缺失、基本信息不准确。

河南煤矿安全监察局网站共发现5个空白栏目、8个栏目更新不及时。此外，政务咨询未注明回复时间、办事指南要素缺失。

新疆煤矿安全监察局网站共发现13个栏目更新不及时、2个空白栏目、部分链接不可用。此外，还发现监测点前1年内政务咨询无有效信件展示、1年内未开展互动访谈活动。

三、有关单位整改措施

此次抽查结束后，8家单位高度重视，认真查找问题原因，迅速组织整改，并制定了相关改进措施。

黑龙江煤矿安全监察局拟结合《黑龙江煤矿安全监察局网络信息管理办法（试行）》和《黑龙江煤矿安全监察局政府网站管理办法（试行）》，建立规范的信息采集、审核、发布、更新机制。河南煤矿安全监察局正对网站开展全面梳理，严格按照网站普查标准对网站进行日常维护。新疆煤矿安全监察局积极借鉴其他单位网站建设经验，完善自身网站建设。辽宁煤矿安全监察局正在积极进行网站升级改版，添加互动回应类、调查征集类栏目。吉林煤矿安全监察局拟对网站进行全面升级改版。江西煤矿安全监察局拟招录计算机和网络管理方面的专业人员，充实网站管理维护力量。

四、下一步工作要求

此次监测抽查对象全部为今年前三个季度总局监测抽查中发现的不合格网站，但此次复查仍有3家网站不合格。经分析，一是个别网站管理仍不到位，栏目设计不合理，信息发布制度不健全；二是一些网站正处于改版升级过渡阶段，新旧网站架构和服务器操作系统兼容出现问题；三是网站技术管理人员缺失，网站建设和管理技术落后；四是网站管理人员、技术人员的综合能力、专业能力有待提高。

各单位要按照习近平总书记在党的十九大报告中提出的建设人民满意的服务型政府要求，认真贯彻落实国办发〔2017〕47号文件规定和国家安全监管总局工作要求，高度重视政府网站建设。一是建立健全运维机制，规范信息发布流程，建立网站监测抽查常态机制，对网站问题及时发现及时整改，提升网站安全防护能力。二是不断强化队伍建设。在确保有专职人员管理维护网站的基础上，充实新的专业技术人员力量，同时采取措施提升现有网站管理人员、技术人员能力。三是加强网站名称和域名管理，规范添加“我为政府网站找错”监督举报平台入口，及时办理和回复网民留言，切实解决网站问题，持续提升政府网站建设管理水平。
