# 中华人民共和国交通运输部公告2018年第54号——交通运输部关于发布《水运工程地基基础试验检测技术规程》（JTS 237–2017）的公告

## 中华人民共和国交通运输部公告

2018年第54号

## 交通运输部关于发布《水运工程地基基础试验检测技术规程》（JTS 237–2017）的公告

现发布《水运工程地基基础试验检测技术规程》（以下简称《规程》）。本《规程》为强制性行业标准，编号为JTS 237–2017,自2018年3月1日起施行。《港口工程桩基动力检测规程》（JTJ 249–2001）、《港口工程基桩静载荷试验规程》（JTJ 255–2002）同时废止。

本《规程》由交通运输部水运局负责管理和解释。

特此公告。

交通运输部

2017年12月11日
