# 财政部关于下达2017年“基层科普行动计划”资金预算的通知

## 关于下达2017年“基层科普行动计划”资金预算的通知

财科教〔2017〕27号

各省、自治区、直辖市财政厅（局）：

为提升全民科学素质，加强基层科普能力建设，中央财政从2017年起每年安排“基层科普行动计划”资金39750万元（项目代码：Z175050030001，具体详见附件），此项补助列入“1100227固定数额补助收入”科目，以后年度不再另行发文。

请你省（自治区、直辖市）结合工作实际，创新基层科普服务理念和服务方式，不断提升基层科普服务的覆盖面和实效性。

附件：2017年“基层科普行动计划”资金预算表

财政部

2017年4月14日
