# 水利部、国家发展改革委、财政部关于印发《加快灾后水利薄弱环节建设实施方案》的通知

## 水利部　国家发展改革委　财政部关于印发《加快灾后水利薄弱环节建设实施方案》的通知

水规计〔2017〕182号

有关省、自治区、直辖市及计划单列市、新疆生产建设兵团水利（水务）厅（局）、发展改革委、财政（财务）厅（局），水利部各流域机构：

按照国务院常务会议审议通过的《灾后水利薄弱环节和城市排水防涝补短板行动方案》有关工作部署，为进一步细化灾后水利薄弱环节建设目标任务和工作措施，水利部、发展改革委、财政部联合编制了《加快灾后水利薄弱环节建设实施方案》（以下简称《实施方案》）。现将《实施方案》印发你们，请遵照执行，并将有关事项通知如下：

一、灾后水利薄弱环节建设由省级人民政府负总责。各地要高度重视，切实加强组织领导，落实属地管理和工作主体责任，明确进度安排和工作要求，层层分解细化工作目标、任务和措施，保证各项工作的顺利实施。

二、按照建设一批、开工一批、储备一批的方式，压茬推进项目前期工作，加强技术审查，优化审批程序，加快项目审批，做好项目储备。要区分轻重缓急，合理安排建设时序，统筹推进项目实施。

三、地方各级政府要建立完善政府、企业、社会多元化投入机制，加大投入力度，用足用好金融支持水利政策，吸引社会资本参与水利建设和运营，多渠道筹措建设资金，确保工程建设需要。

四、加强项目建设管理，严格实行项目法人责任制、招标投标制、建设监理制、合同管理制和竣工验收制。健全工程质量责任体系，严格落实安全生产管理规定，确保工程质量和安全，对工程质量实行责任终身追究。工程建设中要严格落实生态环保等措施。

五、建立健全监督检查责任制，切实履行监管责任，加强对前期工作、工程进度、质量安全和资金使用等重点环节的监督检查力度。健全信息报送制度，全面及时掌握项目推进情况。加强廉政风险防控，对严重违规违纪或发生重大责任事故及安全生产事故的，严肃追究责任。

六、请各省级水利、财政部门按照《实施方案》中的项目备案要求，将流域面积200～3000平方公里中小河流治理、小型病险水库除险加固、农村基层防汛预报预警体系建设等三项任务的具体项目清单，于5月31日前报水利部、财政部备案。经备案确定的项目，实施过程中确需调整的，由省级水利和财政部门调整后，将调整情况向水利部、财政部报备。各省（自治区、直辖市、计划单列市）年度实施方案或项目清单（按备案表体例并明确各级投资）请于中央财政资金正式下达后一个月内报送水利部、财政部备案。
