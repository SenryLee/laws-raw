# 水利部规划计划司关于2017年度水利部定点扶贫重庆市丰都县脱贫攻坚上半年工作进展情况的通报

## 关于2017年度水利部定点扶贫重庆市丰都县脱贫攻坚上半年工作进展情况的通报

水利部定点扶贫重庆市丰都县工作组各成员单位：

为深入贯彻落实中央扶贫开发工作会议和中央单位定点扶贫工作会议精神，助力重庆丰都县巩固脱贫攻坚成果，2月15日，我司组织召开了定点扶贫丰都县工作会议，总结了2016年工作，明确了2017年度帮扶任务。会后，经商各成员单位，制定印发《水利部定点扶贫重庆丰都县“八大工程”2017年度工作计划》，进一步明确了年度任务、责任分工、完成时限和保障措施。截至目前，定点扶贫重庆市丰都县脱贫攻坚各项工作进展顺利，现将上半年工作情况通报如下：

一、“八大工程”有序推进

（一）农村饮水安全巩固提升工程

2017年，丰都县农村饮水安全巩固提升工程计划总投资3127万元，新建（改扩建）供水工程7处。截至目前，4处供水工程已全部完工，完成总投资3199.33万元，为计划总投资的102%。

（二）千塘万亩特色产业支撑工程

根据丰都县的请求，千塘万亩特色产业支撑工程2017年年度任务由整治山坪塘335口、新建10口调整为整治山坪塘335口，计划总投资由3874万元调整到3650万元。截至目前，335口山坪塘整治已全部完工，完成总投资3650万元，新增、恢复和改善灌溉面积11968亩，支持发展特色产业4391亩，受益贫困户649户。

（三）小型水库水源保障工程

2017年，丰都县计划开工建设水源工程项目1处，续建3处，总投资5000万元。截至目前，已完成总投资1801万元，续建的3座水库已完成投资1071万元，其中：硝厂沟水库主体工程开工建设；沱沱坝水库、王家山水库主体工程尚未开工，正在抓紧开展进场公路开挖、临时施工用电、导流洞基础工程等建设。观音岩小型水库项目已组织初设审查，其他4座小型水库前期工作正在有序推进。

（四）贫困户产业帮扶工程

2017年计划筹资100万元，通过小额贷款贴息等方式支持290户贫困户创业就业和产业发展。截至目前，已协调中国水科院（20万元）、澧水公司（30万元）、右江公司（30万元）、长江设计院（20万元）4家单位将100万帮扶资金拨付到位。该工程已撬动贷款1206.5万元帮扶270户贫困户（其中个人信用贷款564.5万136户；新型农业经营主体贷款14家，贷款金额642万元，建立利益链接134户）用于发展种植、养殖及贸易业等。

（五）贫困户转移就业技能培训工程

2017年，丰都县贫困户转移就业技能培训工程计划培训贫困户100人次，需筹集培训经费50万元。目前已协调黄河水科院（20万元）、水利报社（3万元）、发展研究中心（2万元）等3家单位共同筹集25万元，并已拨付到丰都县财政局专款账户，其余25万元为该工程2016年结余培训资金。5月13～19日，长江委在丰都县举办了贫困户转移就业技能培训工程第一期培训班（计算机操作、电子装配工2个培训班），共计培训人次80人次。

（六）贫困学生勤工俭学帮扶工程

重庆市水利局根据制定印发的《水利部定点帮扶丰都县2017年丰都籍贫困学生勤工俭学工作方案》，会同丰都县水务局选择确认50名需要帮扶的丰都籍贫困在校大学生。根据学生勤工俭学意愿，经协调安徽省水利厅、重庆市水投集团及有关区县，确定了勤工俭学贫困学生分配方案：1名由安徽省水利厅协调安排至黄山市水利单位；8名在重庆主城，由市水投集团统筹安排；41名回到丰都县，由丰都县水务局统筹安排到相关项目单位及企业。此外，市水利局进一步规范了勤工俭学程序，要求凡参加勤工俭学的学生，均需学生本人提出申请，经所在院校、家长同意后，由用人单位与学生签订勤工俭学协议书、勤工俭学安全责任书等。除暑期勤工俭学外，长江委积极与飞仙洞村邵明磊书记联系，充分发挥资源优势，帮助9名学生落实了寒假勤工俭学岗位。

（七）水利建设技术帮扶工程

中国水科院充分发挥技术优势，多次赴重庆市丰都县现场调研查勘，开展三峡库区消落带基础资料的收集整理和技术路线的制定，正在加快编制咨询报告；编制完成龙河谷水利风景区总体规划报告，指导丰都县完成水利风景区的资料汇编，并上报至部景区办；加快推进龙河流域规划报告编制。长江设计院编制完成的观音岩初步设计报告已通过审查、莲花水库已通过业主委托的重庆江河咨询公司评审，正在抓紧编制移民、水资源论证等其他专题报告，并已完成小月坝水库初步设计报告编制工作；修改完善《重庆市丰都县龙河国家级水利风景区生态调节坝工程项目建设方案报告》，并启动涉河建设方案及防洪影响评价报告编制工作。

（八）专业技术人才培训工程

2017年，部水资源司牵头开展培训工作，计划培训丰都县干部职工101人次。截至目前，丰都县水务局已组织67人次参加部水资源司、黄河水科院等单位主办的专业技术培训班。其中，黄河水科院专门面向丰都县水利系统干部举办了专业技术人才培训班，为30名水利干部讲授计划用水管理、取水许可监督等水利相关知识；部水资源司举办全国重要饮用水水源地安全保障达标建设培训班，邀请了2名丰都水利干部参加；部移民局组织包括丰都在内的定点扶贫县挂职副县长参加中央国家机关工委的培训班，为更好地开展挂职扶贫提供保障。

二、其他帮扶事项

（一）加大资金支持力度

部规划计划司、农水司积极协商，重庆市水利局商市发展改革委、市财政局等单位，在分解下达中央资金及安排市级资金时积极向丰都县倾斜。截至目前，已安排丰都县2017年农村饮水安全巩固提升工程市级以上资金920万元，超全市平均水平；安排千塘万亩特色产业支撑工程市级以上资金1840万元；安排小型水库工程建设市级以上资金1800万元，同时转下达丰都县龙兴坝中型水库工程建设中央投资7352万元，安排市级资金3352万元，支持丰都县加快水利基础设施建设。

（二）深入实地调查研究

4月20日，部移民局开展“购买农副产品，支持定点扶贫”专题调研，赴丰都等4个定点扶贫县，现场查看推荐农副产品生产加工情况、电商销售情况，了解农副产品电商销售存在的困难和问题，并已初步筛选出一批对当地群众脱贫致富有明显带动作用、质量有保障、口味有特色，并且在天猫或京东等知名电商平台有销售渠道的农副产品，建立了名优特色农副产品名录，拟计划下半年将名录推荐给广大水利干部职工，号召大家积极响应“购买农副产品，支持定点扶贫”行动，为打赢定点扶贫攻坚战贡献爱心和力量。

4月27日，国家防办实地考察了木腊园水库和山坪塘整治等脱贫攻坚工程，深入了解实际困难和扶贫需求，并对下一阶段脱贫攻坚工作与防汛抗旱工作提出了建议与要求。

目前定点扶贫丰都县脱贫攻坚各项工作进展顺利，各成员单位将继续按照职责分工，切实履行帮扶责任，进一步推动“八大工程”工作进度，及时帮助协调解决丰都县脱贫攻坚工作中遇到的困难和问题，助力丰都县巩固脱贫攻坚成果。
