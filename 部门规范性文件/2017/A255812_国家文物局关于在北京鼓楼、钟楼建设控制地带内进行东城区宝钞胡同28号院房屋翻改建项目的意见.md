# 国家文物局关于在北京鼓楼、钟楼建设控制地带内进行东城区宝钞胡同28号院房屋翻改建项目的意见

文物保函〔2017〕1475号

北京市文物局：

你局《关于东城区宝钞胡同28号院房屋翻建的请示》（京文物〔2017〕633号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位北京鼓楼、钟楼建设控制地带内进行东城区宝钞胡同28号院房屋翻改建项目和你局意见。

二、对该项目提出以下修改意见：

（一）该项目位于全国重点文物保护单位北京鼓楼、钟楼四类建设控制地带内，应严格遵守《中华人民共和国文物保护法》及《北京历史文化名城保护条例》、《北京历史文化名城保护规划》、《北京市旧城二十五片历史文化保护区保护规划》的有关要求，合理确定拟建房屋的规模、高度和外观样式，严格控制施工范围，尽量减少对景观环境的影响。

（二）地下室建设应符合《北京市旧城二十五片历史文化保护区保护规划》等的有关要求。

（三）尽量保留建筑原有老旧石质构件，确保拟建房屋与历史文化街区景观风貌相协调。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，按照《中华人民共和国文物保护法》第十八条的规定，报有关部门批准实施。

施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。施工中请加强工程监管，确保文物及历史环境安全。

国家文物局

2017年8月21日
