# 人力资源社会保障部办公厅关于开展2017年全国技工院校学生资助管理专项核查工作的通知

人社厅函〔2017〕116号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）：

为全面贯彻落实中等职业教育免学费和助学金政策（以下简称“资助政策”），确保技工院校学生资助管理工作责任和措施落实到位，保证资助资金安全，我部决定自今年6月起集中组织开展全国技工院校学生资助管理专项核查工作。现就有关事项通知如下：

一、核查目的

通过开展全国技工院校学生资助管理专项核查工作，排查和梳理技工院校学生学籍管理和资助管理工作中存在的问题和薄弱环节，促进各地完善学籍管理和资助管理制度，规范工作流程，强化资金监管，确保资助政策全面正确落实。

二、核查内容

各地要依据《关于扩大中等职业教育免学费政策范围 进一步完善国家助学金制度的意见》（财教〔2012〕376号）、《关于印发〈中等职业学校国家助学金管理办法〉的通知》（财科教〔2016〕35号）、《关于印发〈中等职业学校免学费补助资金管理办法〉的通知》（财科教〔2016〕36号）、《人力资源社会保障部办公厅关于做好2017年技工院校学生资助管理工作的通知》（人社厅发〔2017〕31号，以下简称“31号文件”）等文件要求，对本地区技工院校学生学籍管理情况、资助政策落实情况和全国技工院校电子注册和统计信息管理系统（以下简称“信息系统”）使用情况进行一次全面、彻底检查。重点核查内容如下：

（一）学生学籍管理情况。各地及技工院校是否按照31号文件要求，规范开展学生学籍注册工作。是否存在学籍注册滞后，实际在校生人数与信息系统中人数不符的问题。是否存在将非全日制学生、短期培训学员注册为全日制学生的违规行为。是否存在虚假注册学籍、双重注册学籍、对异动学籍信息处理不及时等问题。

（二）资助政策落实情况。各地及技工院校是否制定了免学费和助学金具体实施办法。是否严格按照政策要求，认定学生受助资格，受理学生申请，组织初审、审核和公示。是否存在资助申报审批滞后，导致符合资助条件的学生未能及时享受到资助政策的问题。是否存在虚构学生信息、为不符合受助条件的学生申报免学费和助学金等骗取国家资助资金的行为。

（三）资助资金管理情况。是否建立了完善的免学费和助学金资金预决算制度和结余资金管理制度。是否对免学费和助学金资金进行专账管理，且账目清楚合规。是否存在结余资金管理不规范、底数不清等问题。是否全部通过中职资助卡发放助学金，受助学生签字是否齐全，是否存在虚报、冒领、套取、挪用、滞留资助资金等违法违规问题。同时，对近年来本地区技工院校免学费和助学金拨付、发放和结余情况进行彻底清查，摸清底数。

（四）信息系统使用情况。各地及技工院校是否全部使用信息系统，各级管理员账户设置和管理是否符合相关要求。信息系统内学校基本信息是否全面、准确。是否全面严格通过信息系统进行学生学籍注册和管理、享受免学费和助学金学生资格申报、审核和审批。信息系统内在校学生人数、享受免学费和助学金学生人数是否与实际情况相符。是否全部通过信息系统进行学生毕业管理和打印毕业证书，实现毕业证书在线查询。

三、核查时间安排

全国专项核查工作分三个阶段进行。

第一阶段学校全面自查（6月）。各技工院校根据核查内容进行自查，由校长担任自查工作负责人，对本校资助工作管理制度建立、政策实施、资助资金发放和使用等情况进行全面梳理检查，针对本校资助管理工作中存在的不足进行改进。

第二阶段地方人力资源社会保障部门总体核查（9月）。各省（区、市）和地市人力资源社会保障部门，成立核查工作领导小组，研究制定工作方案，统筹安排核查工作。要在技工院校自查基础上，对所辖技工院校学生资助管理工作进行实地检查，确保不漏一所学校。核查结束后，各省级人力资源社会保障部门要将专项检查情况形成书面报告，内容包括核查方案、核查过程、资助管理基本情况、发现的问题、处理和整改措施以及下一步工作安排等，于9月底前报部职业能力建设司和全国技校资助办。

第三阶段我部重点抽查（10月）。根据各地专项核查和总结汇报情况，部职业能力建设司和全国技校资助办将组织进行重点抽查，并对专项核查工作进行总结。

四、工作要求

（一）提高认识，加强领导。各级人力资源社会保障部门要充分认识开展专项核查工作的重要性，切实加强对专项核查工作的领导。结合本地区实际，制订专项核查工作方案，明确核查工作重点环节和内容，仔细核查存在的问题和隐患，保证核查工作扎实、有序开展。

（二）严肃查处，彻底整改。各级人力资源社会保障部门对核查中发现的问题和隐患，要认真组织整改。对于冒领、套取、挪用、滞留资助资金等违法违规行为，要立即追缴违规资金，并严格追究相关人员的责任；对于涉嫌犯罪的，要移交司法机关处理。同时，要将有关情况第一时间逐级上报。

（三）完善制度，建立机制。各级人力资源社会保障部门和技工院校要进一步健全资助管理机构，充实工作队伍，明确各级资助管理机构和工作人员的管理责任。要完善学籍管理和资助管理制度，促进技工院校学生资助工作规范化管理。要加强日常风险防范，开展专项检查，加大投诉举报处理力度，对存在的问题早发现、早处理，建立健全监督管理工作机制。
