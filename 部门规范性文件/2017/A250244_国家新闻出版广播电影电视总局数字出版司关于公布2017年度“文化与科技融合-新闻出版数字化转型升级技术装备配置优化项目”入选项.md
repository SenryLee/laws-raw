# 国家新闻出版广播电影电视总局数字出版司关于公布2017年度“文化与科技融合-新闻出版数字化转型升级技术装备配置优化项目”入选项目的通知

## 关于公布2017年度“文化与科技融合-新闻出版数字化转型升级技术装备配置优化项目”入选项目的通知

数出[2017]39号

各省、自治区、直辖市新闻出版广电局，各相关企业：

为全面贯彻落实《关于推动新闻出版业数字化转型升级的指导意见》和《关于推动传统出版和新兴出版融合发展的指导意见》，继续深入推进新闻出版业数字化转型升级、融合发展，根据财政部《关于申报2017年度文化产业发展专项资金的通知》，在已发布《新闻出版企业数字化转型升级技术需求框架（2016版）》、《新闻出版业数字化转型升级技术服务商推荐名录（2016版）》的基础上，我司面向新闻出版企业开展了“文化与科技融合-数字化转型升级技术装备配置优化项目”征集工作，经企业申报、与总局改革发展项目库入选项目单位查重、专家评审，已遴选出一批符合本企业长远规划、项目设计合理、技术路线可行的优秀项目，现予以公布。

相关后续工作安排如下：

1.请各省、自治区、直辖市新闻出版广电局指导各入选项目的新闻出版企业，按照财政部《关于申报2017年度文化产业发展专项资金的通知 》（财办文[2017]25号）和总局《关于征集2017年度文化产业发展专项资金新闻出版广播影视重大项目的通知》（新广出办发[2017]25号），认真准备申报材料、严格履行申报程序，积极参与文化产业发展专项资金项目申报工作。

2.各入选项目的新闻出版企业，在准备申报材料时，要严格按照总局数字出版司《关于开展新闻出版企业数字化转型升级技术装备配置优化项目征集工作的通知》（数出[2017]32号）的要求，结合本企业自身发展的实际状况，明确项目建设目标、优化项目建设内容、细化项目经费预算，按“必备装备、优选装备、可选装备”的递进层次，提高需求与配置方案的匹配度，确保项目方案具备科学性与可行性。

附件：2017年度“文化与科技融合-新闻出版数字化转型升级技术装备配置优化项目”入选项目

数字出版司

2017年5月10日
