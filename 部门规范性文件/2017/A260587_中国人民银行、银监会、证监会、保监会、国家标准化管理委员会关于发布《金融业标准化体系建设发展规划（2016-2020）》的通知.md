# 中国人民银行、银监会、证监会、保监会、国家标准化管理委员会关于发布《金融业标准化体系建设发展规划（2016-2020）》的通知

## 中国人民银行　银监会　证监会　保监会国家标准化管理委员会关于发布《金融业标准化体系建设发展规划（2016-2020）》的通知

银发〔2017〕115号

现将《金融业标准化体系建设发展规划（2016-2020）》印发给你们，请认真贯彻执行。

请人民银行上海总部，各分行、营业管理部、省会（首府）城市中心支行会同所在省（区、市）银监会、证监局、保监局将本通知联合转发至辖区内金融机构。

请各省、自治区、直辖市质量技术监督局（市场监督管理部门）支持做好本地区金融标准化联络机制、宣贯实施等工作。
