# 中华人民共和国交通运输部公告2017第2号——交通运输部关于公布质量不合格道路运输车辆卫星定位系统车载终端的公告

## 中华人民共和国交通运输部公告

2017第2号

## 交通运输部关于公布质量不合格道路运输车辆卫星定位系统车载终端的公告

根据《道路运输车辆动态监督管理办法》（交通运输部、公安部、国家安监总局令2016年第55号）、《交通运输部办公厅关于2016年度道路运输车辆北斗导航车载终端和电子不停车收费（ETC）产品质量行业监督抽查结果的通报》（交办科技函〔2016〕1506号）及《交通运输部办公厅关于印发〈道路运输车辆卫星定位系统车载终端和平台标准符合性技术审查工作规范〉的通知》（交办运〔2016〕138号），河津市启航电子科技有限公司等单位生产的6个型号道路运输车辆卫星定位系统车载终端质量不合格，现予公布。自公告之日起，该6个型号车载终端从所属原公告批次目录中撤销。

附件：不符合道路运输车辆卫星定位系统标准及规范的车载终端

交通运输部

2017年1月19日
