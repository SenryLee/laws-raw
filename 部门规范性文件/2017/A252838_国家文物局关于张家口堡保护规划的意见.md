# 国家文物局关于张家口堡保护规划的意见

## 关于张家口堡保护规划的意见

办保函〔2017〕486号

河北省文物局：

你局《关于呈报张家口堡文物保护规划的请示》（冀文物字〔2016〕214号）收悉。经研究，我局意见如下：

一、所报规划保护区划和管理规定不当，规划深度不够，我局建议可根据相关意见补充完善张家口堡保护规划。

二、所报规划应做以下必要修改和完善：

（一）关于文物认定和评估

深化价值评估和现状评估内容，进一步明确文物具体价值，核实文物保护工程实施情况，统计占压、掏挖堡墙的建筑数量，客观评估文物保存现状。同时，细化景观环境评估，分析张家口堡及其与周边自然山体等景观的关系。补充户籍人口和居住人口关系的分析说明。

（二）关于保护区划和管理规定

1．应根据现状评估结论和文物保护管理需要，科学调整保护区划及具体边界，增强可操作性。建议将重要街巷纳入保护范围，并适当扩大西侧堡墙保护范围，整体保护张家口堡的历史格局。同时，应进一步细化建设控制地带分类，将原有环境协调区纳入建设控制地带统筹考虑。

2．细化管理规定，科学、合理地研提保护范围、各类建设控制地带的具体控制指标，兼顾文物保护、地方经济社会发展与民生改善需要，增强可操作性。

（三）关于环境整治和专项规划

1．应结合冬奥会筹办、张家口市旅游发展和居民生产生活需要，统筹考虑张家口堡展示利用的整体定位，明确展示主题，细化重要展示节点内容、利用方式和强度，注重文物保护服务地方社区和居民，妥善处理文物保护、旅游发展、城市建设、民生改善之间的关系。

2．进一步明确堡墙沿线民居整治、重要街道环境整治对象及具体要求。

3．“安防、消防、防雷”应单独编制专项规划。

4．补充防灾规划和社会居民调控规划；研究规划应增加街巷格局和堡墙研究内容。

（四）补充所报规划与《张家口市总体规划》、《张家口堡历史文化街区保护规划》等的衔接内容。

（五）进一步梳理规划分期，细化近期规划内容。

（六）应严格按照《全国重点文物保护单位保护规划编制审批办法》、《文物保护单位保护规划编制要求》，系统梳理文本内容，完善体例，规范用语；补充视廊分析图。

三、请你局组织有关单位根据上述意见和《关于张家口堡保护规划的意见》（办保函〔2015〕996号）要求，对所报保护规划进行修改、完善。

专此函。

国家文物局
