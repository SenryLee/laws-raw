# 中华人民共和国海关总署关于政协十二届全国委员会第五次会议第4201号（经济发展类263号）提案答复的函

马铁山：

您提出的关于《支持广西开展跨境经济合作，服务“一带一路”建设，推进区域经济发展的提案》（全国政协十二届五次会议提案第4201号）收悉，经研究，现答复如下：

一、关于通关业务制度改革的有关问题

我署历来支持广西开展跨境经济合作和贸易发展，统筹推进“三互”大通关改革和全国海关通关一体化改革，促进各项贸易便利化措施的落实，打击边境走私，建立优良外贸营商环境。

目前，正在积极推动全国海关通关一体化改革相关工作。通过机构重组和流程再造，建立风险防控、税收征管两个中心，实施“一次申报、分步处置”通关管理模式、改革税收征管方式、实施协同监管，破除业务条线和关区间藩篱，构建结构扁平、管理集约、协调统一的一体化通关管理格局。2016年6月1日，全国海关通关一体化改革在上海启动试点。此后通过发布一系列公告，先后三次逐步扩大试点范围。2017年7月1日起，实现全国海关通关一体化改革在进口领域的全覆盖，建成启用全国海关风险防控中心、税收征管中心（以下简称“两中心”），对全国口岸所有运输方式进口的《中华人民共和国进出口税则》全部章节商品，适用“一次申报、分步处置”通关模式，取消放行前审单，从“先审后放”变为“先放后审”，在进口货物放行后，海关对价格、归类、原产地等税收征管要素实施审核与处置，仅对极少数存在重大税收风险且放行后难以有效稽（核）查的报关单采取事中干预。年内将基本实现全国海关通关一体化。广西的通关制度改革将随着全国海关通关一体化的逐步推进而同步推进实现。

二、关于口岸国际合作的有关问题

我署（国家口岸办）高度重视与越南等毗邻国家间的口岸合作，中越两国自2013年签署《中越陆地边境口岸管理合作委员会工作条例》、建立双边口岸合作机制以来，共轮流举办了四次委员会工作例会，开展了三次口岸联合调研，双方在口岸开放、建设、管理和运行等方面达成了广泛共识，取得了一系列成果，有效促进了边境地区经济发展和人员往来。下一步，我署将继续发挥中越口岸合作机制的作用，进一步推动口岸务实合作，积极支持在有条件的口岸开展查验机制创新试点，不断提高口岸通行效率。

三、关于口岸部门“合作查验”相关事宜

按照国务院第174次常务会议的部署，我署牵头推进“跨部门一次性联合检查”相关工作，按照“三互”大通关改革的既定目标，在全面推进“一站式”作业的基础上，进一步深挖跨部门联合监管潜力。目前已制定《海关总署关于认真落实国务院第174次常务会议部署要求的工作方案》，形成了《推进跨部门一次性联合检查工作计划》。海关总署、公安部、交通运输部、质检总局等部委共同组成了“跨部门一次性联合检查”工作组，主要职责是通过全面梳理口岸通关检查方面的法律法规和职责规定，共同开展调研，对于口岸检查项目形成海关、检验检疫、边检、海事等部门协同共管、实施一次性联合检查的具体措施及任务分工，切实解决口岸“多道检查”“九龙治水”的问题。拟于2017年底前开展“一次性联合检查”试点，2018年底前实现全国口岸全覆盖。届时广西各口岸将同步实现跨部门一次性联合检查。

感谢您对海关工作的关心与支持，并欢迎继续对我们的工作提出宝贵的意见和建议。

海关总署

2017年7月13日
