# 农业部对十二届全国人大五次会议第4734号建议的答复

## 对十二届全国人大五次会议第4734号建议的答复

农办议〔2017〕162号

罗朝阳代表：

您提出的“关于扶持百色柑橘产业，助力老区脱贫奔康的建议”收悉。经商财政部、水利部,现答复如下。

一、关于支持良种苗木繁育能力建设问题

国家通过种子工程、农业综合开发等项目不断加大对柑橘良种繁育基地建设支持力度。“十二五”以来，中央财政累计投入资金4500多万元，支持柑橘良种苗木繁育基地建设，提升柑橘良种苗木供应能力。

目前，农业部正在组织编制《现代种业提升工程建设规划（2017—2025年）》，“十三五”期间，将继续支持柑橘等经济作物良种苗木繁育基地建设，着力提高我国经济作物良种化水平。百色市可依据现代种业提升工程规划及年度项目申报指南要求申报此类项目，农业部将对革命老区给予倾斜支持。

二、关于支持柑橘标准园建设问题

中央财政通过安排现代农业生产发展资金和农业综合开发资金，支持地方建设高标准农田和发展粮食及其他优势特色产业，采取“中央宏观指导、地方自主选择”的管理模式，将资金切块下达到地方，由地方自主选择扶持的主导产业和支持的关键环节。

百色地区是革命老区，是中央财政专项扶贫资金支持的重点区域之一。中央财政分配财政专项扶贫资金时，对贫困革命老区给予了大力倾斜。按照扶贫开发“中央统筹、省（自治区、直辖市）负总责、市（地）县抓落实”的工作机制和《关于支持贫困县开展统筹整合使用财政涉农资金试点的意见》（国办发〔2016〕22号）要求，中央财政各项涉农资金项目审批权限已下放到县，当地可根据脱贫攻坚规划，综合平衡好芒果、柑橘等特色水果种植，统筹使用各项涉农资金，支持产业扶贫。

下一步，农业部将通过绿色高产高效创建等项目继续支持园艺作物标准化生产。百色市可由各县在政策框架内，结合本地实际，统筹安排资金予以支持。

三、关于在百色柑橘产业规划、品种选育、新品种引进、生产过程管控等方面予以扶持与技术指导问题

在柑橘品种选育和新品种引进方面，农业部在中国农科院柑橘研究所设有国家果树种质柑橘圃，负责柑橘种质资源的收集、评价和利用。下一步，农业部将加大现有国家果树种质柑橘圃对百色市的支持力度，加快优良柑橘品种资源的推广应用。

在柑橘产地规划和生产过程管控方面，农业部将积极加大对百色市的扶持和技术指导力度。一是根据百色市的实际需要，积极组织资源区划、工程建设、产业发展等方面的专家，指导帮助百色市编制柑橘规划。二是继续通过绿色高产高效创建、果菜茶有机肥替代化肥示范等项目，支持百色市加强柑橘生产过程管控。三是积极组织柑橘产业技术体系有关专家和各级农业技术推广人员深入生产一线，加大培训力度，加快先进实用技术的集成和推广应用，帮助百色提升柑橘生产水平。

四、关于支持农田水利基础设施建设问题

中央一直高度重视百色水利工作，特别是“十二五”以来不断加大对百色农田水利基础设施的投入和建设力度，促进了农业增产、农民增收致富和农村生态环境改善。一是加快实施灌区建设与改造。将拟新建的百色水库灌区纳入全国“十三五”水利发展规划，灌区设计灌溉面积59.7万亩。二是全面推进小型农田水利设施建设。安排中央财政专项资金5.5亿元，支持百色以县为单元整体推进田间渠系配套、“五小水利”等小型农田水利设施建设，改善当地农业生产条件。三是大力发展特色农业高效节水灌溉。通过中央财政小农水和规模化高效节水灌溉项目安排投资4.4亿元，支持百色因地制宜推广普及先进适用节水灌溉技术，发展高效节水灌溉面积20.6万亩。

下一步，农业部将会同水利部，积极协调有关部门，进一步加大相关项目和资金支持力度，夯实农业特别是柑橘等特色产业发展的水利基础。

感谢您对“三农”工作的关心，希望今后继续对我部工作予以支持。
