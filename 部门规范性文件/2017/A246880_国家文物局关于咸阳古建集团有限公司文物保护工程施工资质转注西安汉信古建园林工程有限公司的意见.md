# 国家文物局关于咸阳古建集团有限公司文物保护工程施工资质转注西安汉信古建园林工程有限公司的意见

## 关于咸阳古建集团有限公司文物保护工程施工资质转注西安汉信古建园林工程有限公司的意见

办保函〔2016〕1393号

陕西省文物局：

你局《关于咸阳古建集团有限公司文物保护工程施工资质转注西安汉信古建园林工程有限公司的请示》（陕文物字〔2016〕188号）收悉。经研究，我局意见如下：

一、文物保护工程施工资质许可属于行政许可，根据《中华人民共和国行政许可法》等有关规定，依法取得的行政许可，除法律、法规规定依照法定条件和程序可以转让的外，不得转让。我局不同意咸阳古建集团有限公司文物保护工程施工一级资质转注西安汉信古建园林工程有限公司。

二、如西安汉信古建园林工程有限公司符合相关资质管理要求，应按照我局《文物保护工程施工资质管理办法（试行）》第三十条关于文物保护工程施工资质单位改制、合并、分立情况的相关要求，按程序重新申报材料，申请取得文物保护工程施工资质。

专此函。

国家文物局

2017年1月4日
