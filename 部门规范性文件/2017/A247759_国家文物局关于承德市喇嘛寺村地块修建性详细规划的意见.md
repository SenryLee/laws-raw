# 国家文物局关于承德市喇嘛寺村地块修建性详细规划的意见

## 关于承德市喇嘛寺村地块修建性详细规划的意见

办保函〔2017〕82号

河北省文物局：

你局《关于呈报承德市喇嘛寺村地块修建性详细规划的请示》（冀文物字〔2016〕266号）收悉。经研究，我局提出以下意见：

一、提供大比例尺图纸，进一步明确地块范围与不同保护区划的关系。

二、应严格按照建设控制高度要求限定各建筑总高，起算点为各单体建筑室外地坪。

三、应根据建设控制地带的范围核算建筑密度。A-1、A-2地块建筑密度应控制在20%以内。

四、适当调整地块布局，对周边山形地貌和文物古迹作出呼应，避免过于规整的道路布局和建筑组团。基于与溥仁寺、普乐寺、安远庙及避暑山庄的视线分析，应进一步优化总平面布局和景观设计；规划二路宜在相关考古工作的基础上，尽可能避让溥仁寺重点保护区；作为通往普宁寺、磬锤峰、五窑沟区域的主要通道，A-1、A-2地块布局应做相应优化调整。

五、应对区域内现存建筑作出评估，如有可能，建议考虑对其进行加固、改造和续用。

六、建议按照相关规划的用地性质，考虑增加复合业态的区域面积，适当减少较为单一的所谓“旅游度假酒店”占比。

七、进一步优化立面、绿化和水系设计。

请你局指导相关单位，根据上述意见修改、完善设计方案。修改后的方案经你局审核并提出初审意见后，报我局审批。

专此。

国家文物局

2017年2月8日
