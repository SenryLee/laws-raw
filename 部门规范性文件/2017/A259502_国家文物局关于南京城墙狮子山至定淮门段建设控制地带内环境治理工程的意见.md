# 国家文物局关于南京城墙狮子山至定淮门段建设控制地带内环境治理工程的意见

文物保函〔2017〕2049号

江苏省文物局：

你局《关于审批南京城墙狮子山至定淮门段环境治理工程方案的请示》（苏文物保〔2017〕327号）收悉。经研究，我局意见如下：

一、原则同意南京城墙狮子山至定淮门段建设控制地带内环境治理工程和你局意见。

二、对所报方案提出进一步修改完善意见如下：

（一）应进一步明确本次环境治理工程与城墙保护的关系，补充对文物本体及周边环境的影响评估。

（二）应细化技术措施，进一步说明使用锚杆加固时其头部防水、防松动的措施。

（三）应对施工方案的监测工作提出明确要求，并保证在施工过程中对边坡稳定性施行实时监测。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》第十八条的规定，报城乡建设规划部门批准后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局
