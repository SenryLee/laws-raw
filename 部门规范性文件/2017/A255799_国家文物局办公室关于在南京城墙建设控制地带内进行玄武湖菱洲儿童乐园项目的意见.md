# 国家文物局办公室关于在南京城墙建设控制地带内进行玄武湖菱洲儿童乐园项目的意见

办保函〔2017〕1051号

江苏省文物局：

你局《关于审批玄武湖菱洲儿童乐园工程方案的请示》（苏文物保〔2017〕209号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位南京城墙建设控制地带内，该方案对文物环境影响较大，我局暂不同意玄武湖菱洲儿童乐园项目。

二、该方案应进行以下必要的修改和完善：

（一）加强历史研究，深入分析菱洲的生态环境和历史环境特征，项目方案应尽量减少对自然环境的干预，充分保护菱洲的自然景观和历史风貌。

（二）进一步调整方案设计，所有新建建筑及游乐设施高度均应符合南京城墙建设控制地带高度限制要求，并尽量采用轻质、可逆的构造措施；新建建筑应简洁大方，与菱洲现有建筑风貌相协调，不宜采用欧式风格；应完善绿化设计，合理选择地方树种，确保岸线遮挡效果。

（三）进一步完善文物影响评估报告，根据方案内容准确、客观论证拟建项目对文物本体及环境风貌的影响，增强针对性。补充菱洲周边及南京城墙视点对拟建项目的景观视线分析图。

三、请你局组织相关单位根据上述意见，对项目方案进行修改完善后，按程序另行报批。

国家文物局办公室

2017年9月11日
