# 国家信访局2017年度处级以上党员领导干部民主生活会工作方案

国信党〔2017〕32号

根据《中共中央纪委机关 中共中央组织部关于开好2017年度县以上党和国家机关党员领导干部民主生活会的通知》（组通字〔2017〕40号）精神，制定国家信访局2017年度处级以上党员领导干部民主生活会工作方案。

一、民主生活会主题

认真学习领会习近平新时代中国特色社会主义思想，坚定维护以习近平同志为核心的党中央权威和集中统一领导，全面贯彻落实党的十九大各项决策部署。

二、局领导班子民主生活会工作安排

（一）精心组织学习研讨（召开民主生活会前）。

主要内容：联系思想和工作实际，深入学习领会党的十九大精神，坚持读原著学原文悟原理。局党组中心组继续围绕局党组确定的“四个专题”开展学习研讨，邀请中组部、中央国家机关工委和中央纪委驻国办纪检组有关部门负责同志参加。

相关要求：着力“六个聚焦”，深刻领会习近平新时代中国特色社会主义思想的历史地位和丰富内涵，搞清楚、弄明白“八个明确”主要内容和“十四个坚持”基本方略的重大创新思想创新观点，为开好民主生活会打牢思想基础。

责任分工：办公室、机关党委、人事司负责局党组中心组学习的组织联络协调工作；机关党委负责提供学习资料。

（二）征求意见建议和谈心谈话（2018年1月15日前）。

主要方式：

1. 向中央纪委二室、中组部干部三局、国务院应急办、中央纪委驻国办纪检组三室、中央国家机关工委办公室，各省（区、市）、新疆生产建设兵团及副省级城市信访工作机构，部分中央和国家机关信访部门发函，征求对局领导班子的意见建议。

2. 向各司室发放征求意见表并设立意见箱，征求对局领导班子及成员意见建议。

3. 局领导班子成员以一定方式征求相关方面对班子和本人的意见建议。

4. 局领导班子成员之间、班子成员与机关党员干部之间广泛进行谈心谈话。

相关要求：征求意见建议坚持发扬民主、开门纳谏，注重从群众反映中筛查问题、找准症结。谈心谈话情况及时填写纪实表。

责任分工：机关党委负责向地方及相关部门发放征求意见函，向司室发放征求意见表，设立意见箱。

（三）撰写对照检查材料和发言提纲（2018年1月25日前）。

主要内容：局领导班子和班子成员紧扣民主生活会主题，重点从以下6个方面查摆问题。

1. 学习贯彻习近平新时代中国特色社会主义思想，在学懂、弄通、做实上下功夫，牢固树立“四个意识”，坚定“四个自信”，做到“四个服从”，坚决维护习近平总书记在党中央和全党的核心地位、维护党中央权威和集中统一领导，自觉在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致。

2. 认真执行党中央决策部署和上级党委决议决定，带头坚持请示报告制度，工作中的重大问题及时请示报告，临机处置突发情况事后及时报告，个人有关事项按规定按程序向党组织请示报告。

3. 对党忠诚老实，对党组织讲实话、讲真话、不当两面派，不做“两面人”，不搞当面一套、背后一套，不在工作中报喜不报忧、报功不报过，甚至弄虚作假、欺瞒党组织。

4. 担当负责，攻坚克难，不回避矛盾，以钉钉子精神抓落实，履行全面从严治党责任，旗帜鲜明地批评和纠正所分管部门、领域或所在地区的违规违纪言行，严格执行党的干部政策，不打招呼、递条子，不封官许愿、跑风漏气，正确对待个人进退留转。

5. 纠正“四风”不止步，针对形式主义、官僚主义顽症，摆表现、找差距，抓住主要矛盾，特别要查找解决表态多调门高、行动少落实差等突出问题，身体力行、以上率下，带头转变作风，形成“头雁效应”。

6. 严格执行廉洁自律准则，自觉抵制“围猎”腐蚀，坚决反对特权思想和特权现象，严格执行办公用房、住房、用车、交通、工作人员配备、休假休息等方面的待遇规定，注重家庭、家教、家风，带头落实中央八项规定和实施细则精神。

在此基础上，局主要负责同志主持起草局领导班子对照检查材料，班子成员自己动手撰写个人发言提纲。

相关要求：要对照党章，对照《中共中央政治局关于加强和维护党中央集中统一领导的若干规定》《中共中央政治局贯彻落实中央八项规定实施细则》精神以及《国家信访局党组贯彻执行<中共中央政治局关于加强和维护党中央集中统一领导的若干规定>精神九条守则》《国家信访局党组关于贯彻执行中央八项规定及实施细则精神的具体办法》，对照初心和使命，坚持理论联系实际，坚持问题导向，强化问题意识，把自己摆进去、把思想摆进去、把工作摆进去，联系违纪违法反面典型，逐条查找梳理，找准存在的突出问题，深入具体地进行党性分析，做到落细落小、见人见事。班子成员发言提纲于2018年1月25日前报局主要负责同志审阅把关。

责任分工：办公室负责起草局领导班子对照检查材料。

（四）召开民主生活会（2018年2月初）。

主要内容：局主要负责同志代表班子作对照检查，带头开展批评和自我批评；班子成员之间开展批评和自我批评。

相关要求：要贯彻整风精神，勇于自我革命，开展积极健康的批评和自我批评，达到坚持真理、修正错误，增进团结、振奋精神的目的。自我批评内容要具体，剖析要透彻、抓住要害，整改措施要对着问题去，可操作、能落实。相互批评要出于公心、直截了当，不能以提希望代替点问题，不能以工作建议代替批评意见。

民主生活会上，班子成员要对上年度民主生活会整改措施落实情况逐项作出报告，对个人、家庭、亲属重大事项如实作出报告，对接受组织约谈函询等应当说明的情况逐一作出检查或说明。邀请中央纪委机关、中央组织部、中央国家机关工委有关部门负责同志和中央纪委驻国办纪检组、国务院办公厅人事司负责同志参加。

责任分工：办公室、人事司、机关党委负责会议的组织联络协调工作。

（五）抓好问题整改（2018年2月上旬）。

主要内容：

1. 会后针对查摆的问题列出整改清单，拿出过硬措施，扎扎实实地改，不断取得解决问题的实际效果。

2. 在局机关适当范围通报民主生活会情况。

3. 向上级党组织报送民主生活会情况。

相关要求：聚焦问题，有针对性地制定整改方案，明确整改责任单位、责任人和整改时限。

以上工作在民主生活会后10天内完成。

责任分工：办公室负责起草整改清单、整改措施、民主生活会情况报告及通报稿，人事司、机关党委负责上报有关单位。

三、司处两级民主生活会工作安排

司处两级民主生活会参照局领导班子民主生活会内容及要求进行。

（一）认真做好会前准备工作。在个人自学基础上，各司室组织党员干部，深入学习有关学习资料，认真开展专题学习研讨；广泛征求意见，深入开展谈心谈话；在征求意见、谈心谈话基础上，深入查摆问题、剖析根源，认真撰写班子对照检查材料和班子成员发言提纲。司室领导班子的对照检查材料和司室主要负责人的发言提纲报分管局领导和局主要负责同志审阅，其他班子成员的发言提纲报分管局领导审阅。处领导班子的对照检查材料和成员的发言提纲报司室主要负责人审阅。

（二）严格按照程序和要求召开民主生活会。围绕主题，按照要求，认真开展批评和自我批评，司处主要负责人带好头。分管局领导和人事司、机关党委、机关纪委负责同志参加相关司室的民主生活会，司室领导参加分管处的民主生活会，进行具体指导。各司室在2017年1月31日前召开民主生活会，会前3天通知人事司和机关党委。

（三）认真抓好整改落实。会后，司处领导班子及成员要针对查找出来的问题，研究制定整改方案和整改措施，明确整改责任，限时进行整改。会后7天内，向机关党委报送司室民主生活会情况和整改清单，并采取适当方式向本司室干部职工通报。
