# 国家林业局公告2017年第17号——国家林业局2017年第一批授予植物新品种权名单

## 国家林业局公告

2017年第17号

根据《中华人民共和国植物新品种保护条例》、《中华人民共和国植物新品种保护条例实施细则（林业部分）》规定，经国家林业局植物新品种保护办公室审查，“金焰”等160项植物新品种权申请符合授权条件，现决定授予植物新品种权（名单见附件），并颁发《植物新品种权证书》。

特此公告。

附件：国家林业局2017年第一批授予植物新品种权名单

国家林业局

2017年10月27日
