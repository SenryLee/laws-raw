# 国家文物局关于荆坪村古建筑群壁画、彩绘、泥塑修缮工程立项的意见

## 关于荆坪村古建筑群壁画、彩绘、泥塑修缮工程立项的意见

办保函〔2017〕111号

湖南省文物局：

你局《关于审批〈荆坪村古建筑群壁画、彩绘、泥塑抢救性保护工程立项报告〉的请示》（湘文物报〔2016〕186号）收悉。经研究，我局意见如下：

一、暂不同意荆坪村古建筑群壁画、彩塑、泥塑修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）进一步开展前期研究和保存环境监测工作，系统搜集相关监测数据，并采用无损方法分析和检测颜料成分、配比等，补充试验数据和说明。

（二）应加强现状勘察，明确壁画、彩绘、泥塑的病害类型，分类表述病害成因、分布范围、发展趋势等，量化残损程度，在此基础上确定工程实施范围。补充开裂、倾斜墙体的结构稳定性评估内容。

（三）应进一步厘清工程技术路线，选择科学、妥善的修缮措施，慎重论证壁画揭取的必要性，尽量采用原位修复措施，避免过度干预。细化泥塑、彩绘保护措施，增强可操作性。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年2月13日
