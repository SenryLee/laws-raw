# 工业和信息化部安全生产司关于做好“两会”期间民爆行业安全生产工作的通知

工安全函[2017]5号

各省、自治区、直辖市民爆行业主管部门：

按照国务院安委办《关于切实做好全国“两会”期间安全生产工作的通知》（安委办明电[2017]3号）的有关要求，为做好全国“两会”期间民爆行业安全生产工作，通知如下：

一、加强组织领导，落实安全生产责任

各级主管部门要充分认识做好全国“两会”期间民爆行业安全生产工作的重要性，以高度的政治责任感强化民爆行业安全生产工作，加强统筹协调和组织领导。要结合《工业和信息化部关于建立民爆企业安全生产长效机制的指导意见》，针对本地区实际情况和特点，督促市、县级民爆行业主管部门认真履行属地监管职责，推动安全管控措施和保障措施的落实；指导企业牢固树立安全生产主体责任意识，认真部署并落实针对性强的安全防控措施，推动企业安全生产长效机制建设。

二、强化安全监管，严防各类事故发生

各级主管部门要结合民爆行业实际，严格按照《关于深入开展民爆行业安全检查督查工作的通知》要求，强化节后及“两会”召开期间的安全监管力度，严肃查处各类违法违规生产经营活动，持续保持民爆行业“打非治违”的高压态势，逐级督导企业整改检查发现的安全隐患，严防各类生产安全事故发生。近期，部安全生产司将继续组织专家组对重点省份进行安全专项检查督查。

三、严格复产复工安全把控，保障企业平稳有序运行

各级主管部门要进一步加大对停产停工和复产复工的安全监管力度，严防复产复工期间发生生产安全事故。要督促民爆企业认真落实安全保障措施，节后复工前要对生产线工艺流程、专用设备设施和安全生产技术措施进行全面检查和测试，并制定和实施专项应急保障措施；停产停工的要安排好安全检查、危险品清理和保存、设备维护保养、厂（库）安全保卫、职工专项培训等相关工作。

四、加强值班值守，提高应急处置能力

各级主管部门要督促民爆企业结合实际情况制定和完善应急值守方案，加强全员安全警示教育，严格领导带班值班制度和关键岗位24小时值班制度，并按规定做好安全保卫和突出事件的信息报送工作，保证突发事件及时有效处置。
