# 水利部关于印发世行贷款山东省淮河流域重点平原洼地治理工程水土保持设施验收鉴定书的函

水保函〔2017〕137号

山东省水利厅：

根据《开发建设项目水土保持设施验收管理办法》的规定，水利部于2017年6月6日在山东省济南市组织召开了世行贷款山东省淮河流域重点平原洼地治理工程水土保持设施验收会议。会议认为，该工程水土保持设施基本达到了水土保持法律法规及技术规范、标准的要求，工程质量总体合格，运行期管理责任落实，同意通过验收。现印发世行贷款山东省淮河流域重点平原洼地治理工程水土保持设施验收鉴定书。

附件：生产建设项目水土保持设施验收鉴定书（编号：2017－14）

水利部

2017年6月27日
