# 国家文物局办公室关于在王昭君墓保护范围和建设控制地带内建设景观雕塑的意见

办保函〔2017〕986号

内蒙古自治区文物局：

你局《关于建设王昭君墓景雕塑的请示》（内文物发〔2017〕126号）收悉。经研究，我局意见如下：

一、王昭君墓是第六批全国重点文物保护单位，其周边环境应保持庄严肃穆的历史氛围。所报设计方案内容庞杂，严重影响文物现有景观风貌，不利于科学阐释和展示文物价值，我局暂不同意在王昭君墓保护范围和建设控制地带内建设景观雕塑，请你局指导建设单位另行选址建设。

二、请你局指导地方人民政府进一步加强对王昭君墓的日常管理和维护，严格控制相关建设行为，确保文物安全及其周边环境协调。

国家文物局办公室

2017年8月23日
