# 国家邮政局关于印发京津冀、长江三角洲、珠江三角洲地区快递服务发展“十三五”规划的通知

北京、天津、河北、上海、江苏、浙江、广东省（市）邮政管理局：

为充分把握国家区域发展战略机遇，促进区域快递服务科学发展和协同发展，国家局组织编制了《京津冀地区快递服务发展“十三五”规划》《长江三角洲地区快递服务发展“十三五”规划》和《珠江三角洲地区快递服务发展“十三五”规划》。现印发给你们，请遵照执行。

要充分认识区域快递服务规划的重要作用，加强组织领导，扎实开展规划宣贯，明确目标任务分工，细化实化保障措施，有力推动规划实施，切实发挥规划引领导向作用。要以规划实施为抓手，积极服务“一带一路”建设、京津冀协同发展、长江经济带发展等国家重大战略。要准确把握区域定位，推动构建特色鲜明的区域快递发展格局。要促进释放发展新动能，全力打造我国快递业改革发展的增长极。
