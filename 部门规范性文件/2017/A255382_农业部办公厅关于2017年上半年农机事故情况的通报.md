# 农业部办公厅关于2017年上半年农机事故情况的通报

农办机〔2017〕11号

各省、自治区、直辖市及计划单列市农机（农业、农牧）局（厅、委、办），新疆生产建设兵团农业局：

按照《农业机械安全监督管理条例》和《农业机械事故处理办法》规定，现对2017年上半年全国农机道路外事故情况、农机道路交通事故情况进行通报。

一、全国农机道路外事故情况及主要特点

2017年1～6月，累计报告在国家等级公路以外的农机事故358起，死亡48人，受伤107人，直接经济损失471.34万元。与去年同期相比，事故起数、死亡人数和直接经济损失分别上升了9.15%、60%和39.7%，受伤人数下降了6.14%。其中：拖拉机事故153起、死亡29人、受伤47人，分别占事故起数、死亡人数和受伤人数的42.7%、60.4%和43.9%。联合收割机事故187起、死亡13人、受伤52人，分别占事故起数、死亡人数和受伤人数的52.2%、27.1%和48.6%。其它农业机械事故18起、死亡6人、受伤8人，分别占事故起数、死亡人数和受伤人数的5.1%、12.5%和7.5%。全国上半年没有发生较大以上农机道路外事故。黑龙江、陕西、新疆、河南、湖南等省（区）死亡人数较上年同期增加了3人以上，增幅较大。

农机道路外事故的主要特点：

（一）操作失误是引发农机道路外事故的主要原因。在全国农机道路外事故中，因操作失误引发的事故252起、死亡31人、受伤70人，分别占事故起数、死亡人数和受伤人数的70.4%、64.6%和65.4%，三项占比均超过60%。

（二）死亡事故中无证驾驶和未年检农机占比较高。在全国农机道路外事故中，有82起事故为驾驶操作人员无证驾驶，造成28人死亡、25人受伤，分别占事故起数、死亡人数和受伤人数的22.9%、58.3%和23.4%；有73起事故为农机未按规定年检，造成21人死亡、27人受伤，分别占事故起数、死亡人数和受伤人数的20.4%、43.8%和25.2%。农机死亡事故中，无证驾驶和未年检占比均超过40%。

（三）农机事故中无牌行驶占比持续下降。在农机道路外事故中，有35起事故是农机无牌行驶，造成13人死亡、19人受伤，分别占事故起数、死亡人数和受伤人数的9.8%、27.1%和17.8%。三项占比分别较去年同期下降了7、26.2和7.6个百分点。

二、农机道路交通事故情况及特点分析

据公安部门提供的资料，2017年1～6月，全国共接报拖拉机肇事导致人员伤亡的道路交通事故783起，造成355人死亡、753人受伤，直接财产损失323.3万元。与去年同期相比，事故起数减少306起，下降28.1%;死亡人数减少102人，下降22.3%；受伤人数减少319人，下降29.8%；直接财产损失减少100.1万元，下降23.7%。其中，导致较大以上道路交通事故6起，同比下降14.3%；未导致重大道路交通事故。

全国拖拉机导致的道路交通事故中，40.7%的肇事拖拉机没有号牌。其中，安徽、江苏、浙江、福建、湖北、广东等6个省无号牌拖拉机肇事较为突出，占全国总数的53.3%。

全国拖拉机导致的道路交通事故中，24.6%的肇事者没有拖拉机驾驶证。其中，吉林、安徽、福建、湖北、云南等5个省份无证驾驶拖拉机事故较为突出，占全国总数的49.1%。

三、2017年上半年较大以上农业机械事故情况

据公安部门提供的资料，2017年上半年较大以上农业机械道路交通事故6起，具体情况如下。

（一）2017年2月4日8时许，王某驾驶小型轮式拖拉机，沿广西防城港市S311省道行驶至93km处，与甘某驾驶的小型轿车相撞，造成4人死亡、直接财产损失10500元、两车损坏的道路交通事故。

（二）2017年2月18日15时20分许，李某驾驶普通二轮摩托车由云南临沧市双江县忙糯乡方向驶往县城方向，至双江县勐忙线K0+900M时，与对向行驶的李某驾驶的小型方向盘式拖拉机发生碰撞，造成3人死亡、两车不同程度受损的道路交通事故。

（三）2017年4月3日20时30分许，王某驾驶解放牌重型仓栅式货车，沿河北邢台市大牙线由南向北行驶，至18公里+700米处，在躲避前方故障停车的王某无证驾驶的无牌拖拉机时，与对向行驶的小型普通客车相撞，造成4人死亡、2人受伤、车辆损坏的道路交通事故。

（四）2017年4月10日14时30分，岳某持C1E类机动车驾驶证驾驶运输型拖拉机，搭乘11人由中山村往大义村方向行驶，至重庆市开州区金峰镇大义村支路大堡坎路段，车辆后滑翻坠于道路右侧62米坎下，造成7人死亡、5人受伤、车辆损坏的道路交通事故。

（五）2017年4月24日11时40分许，潮某驾驶小型普通客车沿内蒙古乌兰察布市省道105线由西向东行驶，至319km+100m处时与前方同向行驶的由张某驾驶的小型四轮拖拉机（拖带车斗）发生尾随相撞，造成6人死亡、3人受伤、两车损坏的道路交通事故。

（六）2017年6月7日23时50分，薛某驾驶大中型拖拉机从四川乐山市洪雅县往夹江县方向行驶，至省道305线253KM+250M（夹江县黄土镇万松村路段）处，与对向驶来的小型轿车相撞，致轿车坠入道路右侧（洪雅至夹江方向）的水沟内，造成6人死亡、车辆严重损坏的交通事故。

四、存在问题及下一步工作要求

2017年上半年，各地认真落实安全生产责任制，加强农机安全生产宣传教育，开展农机事故应急处置演练，强化变型拖拉机专项整治，排查农机安全隐患，做好事故预防、处理和统计报告，农机安全生产工作总体有力有效。但是，仍有部分省份放松监管、事故抬头，对此必须高度重视，认真研究解决。国庆、中秋佳节将至，党的十九大即将召开，做好当前农机安全工作，确保广大农民群众过一个平安祥和的节日，为十九大召开营造稳定的安全生产环境，具有重要意义。

一是深入做好农机安全生产大检查工作。各地要严格按照大检查工作要求，认真部署、扎实推进，在完成自检自查阶段工作后，扎实组织开展好集中整治和巩固提高阶段有关工作，进一步强化农机安全生产责任，严查事故隐患，坚决防范遏制重特大农机事故。二是切实做好变型拖拉机整治工作。各地要认真总结整治工作中切实可行的好做法、好经验，将行之有效的监管措施固定下来、坚持下去，继续保持高压态势，严防违法行为反弹。三是积极做好农机安全监理免费政策的落实工作。各地要积极协调财政等部门做好经费保障、政策宣传、制度完善等工作，确保这一政策落到实处，确保安全监理工作进一步加强。四是扎实做好新修订规章和配套规范性文件的宣贯工作。修订的规章和配套规范性文件、标准公布实施后，各地要做好组织学习和贯彻工作，确保监理制度改革的平稳过渡。五是认真做好“平安农机”创建工作。各地要准确把握新时期创建工作的新变化、新要求，做好2016和2017两个年度的申报工作，于2017年9月底前报送推荐材料。
