# 中华人民共和国农业部公告第2561号——进口饲料和饲料添加剂产品登记证目录（2017-06）

## 中华人民共和国农业部公告

第2561号

根据《进口饲料和饲料添加剂登记管理办法》有关规定，批准墨西哥Baja Agro International, S.A. de C.V.公司等37家公司生产的60种饲料和饲料添加剂产品在我国登记或续展登记，并发给进口登记证（见附件）。所登记产品的监督检验，按中华人民共和国国家标准或农业部发布的质量标准执行。

批准帝斯曼营养产品法国有限公司生产的“罗维素?D3500”改变产品配方，重新颁发进口登记证，（2012）外饲准字437号的登记证同时作废。批准美国Desert King国际有限公司生产的“利可40”质量标准改变，重新颁发进口登记证，（2013）外饲准字231号的登记证同时作废。批准法国馥蒂公司生产的“诱食源VEO”、“奥利欧LX189 P2”和“奥利欧（反刍专用）常规型LX 185 P4”质量标准改变，重新颁发进口登记证，（2013）外饲准字428号、（2014）外饲准字238号和（2012）外饲准字353号的登记证同时作废。批准荷兰赛尔可公司生产的“菲乐斯（液体）”质量标准改变，重新颁发进口登记证，（2012）外饲准字435号的登记证同时作废。

特此公告。
