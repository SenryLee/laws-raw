# 商务部、中华全国供销合作总社公告2017年第33号——关于《SBT 10026-1992 洋葱》等56项国内贸易行业标准调整为供销合作行业标准的公告

## 商务部　中华全国供销合作总社公告

2017年第33号

## 关于《SBT 10026-1992 洋葱》等56项国内贸易行业标准调整为供销合作行业标准的公告

为适应标准化工作改革与发展的需要，现将《SB/T 10026-1992 洋葱》等56项国内贸易行业标准统一调整为供销合作行业标准，标准归口部门由商务部调整为中华全国供销合作总社。上述标准代号由SB/T改为GH/T，标准顺序号和年代号相应调整。

附件：调整归口部门的行业标准

商务部

中华全国供销合作总社

2017年6月22日
