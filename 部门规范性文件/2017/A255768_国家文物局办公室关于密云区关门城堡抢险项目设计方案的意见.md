# 国家文物局办公室关于密云区关门城堡抢险项目设计方案的意见

办保函〔2017〕965号

北京市文物局：

你局《关于密云区关门城堡抢险工程设计方案的请示》（京文物〔2017〕842号）收悉。经研究，我局意见如下：

一、所报方案未按照我局《关于北京密云区关门城堡抢险修缮工程设计方案的意见》（办保函〔2017〕421号）的要求修改，工程规模过大，干预过多，我局暂不同意该方案。

二、请你局指导有关单位，调整设计思路，按我局要求全面修改关门城堡抢险修缮项目设计方案。坚持最小干预原则，重点解决墙体结构稳定性问题，塌落后已形成稳定状态的墙体不宜过度干预。

三、请你局指导方案设计单位，根据上述意见修改和完善所报方案，按照我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局办公室

2017年8月17日
