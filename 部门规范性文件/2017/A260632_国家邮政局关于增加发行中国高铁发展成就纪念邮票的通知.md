# 国家邮政局关于增加发行中国高铁发展成就纪念邮票的通知

国邮发〔2017〕68号

中国邮政集团公司：

党的十八大以来，我国铁路建设取得了巨大成就，高铁已成为中国的另一张“国家名片”。我国高铁今年已经建成了“四纵四横”高铁网，成功研制了具有完全自主知识产权、达到世界先进水平的中国标准动车组，经中央批准，命名为“复兴号”。

为宣传我国高铁建设的巨大成就，同时结合2017年纪特邮票发行计划总体情况，经研究，我局决定在2017年纪特邮票发行计划中增加发行《中国高铁发展成就》纪念邮票一套4枚，小型张1枚，邮票内容分别为：1.宝兰高铁；2.上海虹桥站；3.沪昆高铁北盘江特大桥；4.中欧班列。小型张：复兴号。发行日期为2017年10月28日。

请你公司抓紧做好相关工作。

国家邮政局

2017年8月4日
