# 交通运输部办公厅关于公布2017年度交通运输行业科技创新人才推进计划入选名单的通知

交办科技函〔2017〕1069号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），部属各单位，各共建高校：

根据《交通运输部关于印发<交通运输行业科技创新人才推进计划管理办法>的通知》(交科技发〔2014〕101号)的有关规定，通过申报推荐、专家评审和公示，经交通运输部同意，确定钱国平等10名中青年科技创新领军人才、“海上交通安全空间信息技术创新团队”等5个重点领域创新团队和“港口与航道工程基础设施建养技术创新人才培养示范基地”等2个创新人才培养示范基地（详见附件）入选2017年度交通运输行业科技创新人才推进计划。

交通运输部办公厅

2017年7月28日
