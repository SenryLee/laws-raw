# 国家旅游局办公室关于印发《2017年全国导游资格考试大纲》的通知

旅办发〔2017〕108号

各省、自治区、直辖市旅游发展委员会、旅游局，新疆生产建设兵团旅游局：

为做好2017年全国导游资格考试工作，现将《2017年全国导游资格考试大纲》印发给你们，请认真贯彻执行。《2017年全国导游资格考试大纲》电子版可从国家旅游局官方网站“通知公告”栏目下载。

国家旅游局办公室

2017年5月5日

附件：2017年全国导游资格考试大纲
