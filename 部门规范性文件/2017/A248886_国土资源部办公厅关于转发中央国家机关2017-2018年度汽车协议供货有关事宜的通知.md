# 国土资源部办公厅关于转发中央国家机关2017-2018年度汽车协议供货有关事宜的通知

国土资厅函〔2017〕448号

中国地质调查局及部其他直属单位，各派驻地方的国家土地督察局：

为了指导和规范各单位采购轿车、越野车、商务车、皮卡、小型客车、大中型客车等各类汽车相关工作，中央国家机关政府采购中心按照有关规定，印发了《中央国家机关2017-2018年度汽车协议供货有关事宜的通知》（国机采〔2017〕2号），现转发给你们，请遵照执行。

2017年3月23日

附件：中央国家机关2017—2018年度汽车协议供货有关事宜的通知
