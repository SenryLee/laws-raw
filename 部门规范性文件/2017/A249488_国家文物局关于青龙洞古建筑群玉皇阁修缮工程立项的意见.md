# 国家文物局关于青龙洞古建筑群玉皇阁修缮工程立项的意见

## 关于青龙洞古建筑群玉皇阁修缮工程立项的意见

办保函〔2017〕300号

贵州省文物局：

你局《关于送审〈镇远县青龙洞古建筑群——玉皇阁本体维修工程立项报告〉的请示》（黔文物呈〔2016〕94号）收悉。经研究，我局意见如下：

一、暂不同意青龙洞古建筑群玉皇阁修缮工程立项。

二、请你局督促地方人民政府和有关单位，全面梳理青龙洞古建筑群文物保护工程情况，客观评估工程效果，分析、总结工程管理和维修技术经验，为做好青龙洞古建筑群保护工作提供依据。

三、请你局督促有关单位，认真落实我局《关于贵州省文物保护工程检查意见的函》（办保函〔2016〕1069号）要求，科学评估青龙洞古建筑群整体病害情况，按照《青龙洞古建筑群保护规划》分阶段、逐步开展维修工作，增强计划性和针对性。同时，请你局切实加强文物保护工程管理，指导有关单位做好已批准保护工程实施，确保工程质量和文物安全。待项目竣工验收后，再行开展其它文物建筑的保护修缮工作。

专此函。

国家文物局

2017年3月23日
