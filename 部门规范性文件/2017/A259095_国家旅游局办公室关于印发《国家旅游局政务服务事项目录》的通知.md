# 国家旅游局办公室关于印发《国家旅游局政务服务事项目录》的通知

旅办发〔2017〕329号

各司室、直属单位，旅游专业协会：

按照《国务院关于加快推进“互联网+政务服务”工作的指导意见》（国发〔2016〕55号）有关规定，经局领导同意，办公室制定了《国家旅游局政务服务事项目录》，现印发给你们，请遵照执行。《国家旅游局政务服务事项目录》将进行动态管理，执行过程中相关内容如有变动，请及时通知办公室。

国家旅游局办公室

2017年12月17日
