# 国家文物局关于安吉古城遗址、龙山越国贵族墓群保护总体规划意见的函

## 关于安吉古城遗址、龙山越国贵族墓群保护总体规划意见的函

文物保函〔2017〕1168号

浙江省文物局：

你局《关于上报全国重点文物保护单位安吉古城遗址、龙山越国贵族墓群文物保护总体规划的请示》（浙文物发〔2017〕145号）收悉。经研究，我局意见如下：

一、原则同意安吉古城遗址、龙山越国贵族墓群保护总体规划。

二、该规划应进一步研究用地性质调整的可行性，优先考虑考古遗址公园建设及重要墓葬区安全防护的需求，分期分批开展用地性质调整和土地征用工作；护城河保护展示不宜采用清理疏浚和放水贯通的方式，建议评估采用标识展示的可能性；改线道路选址应进一步远离古城外西北角高台建筑遗址；梳理规划文本，统一保护对象名称，补充规划层级说明，规范图文表达。

三、请你局指导地方人民政府组织规划编制单位和专业考古研究单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》的要求，将经我局备案的安吉古城遗址、龙山越国贵族墓群保护总体规划报请浙江省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制订具体方案并按程序报批。

六、请你局指导和协调地方人民政府切实加强安吉古城遗址、龙山越国贵族墓群的保护和管理工作，加强专门保护管理机构建设，完善专项管理法规，并提出具体实施步骤和保障措施，妥善解决土地用途调整、道路调整、居民搬迁以及环境整治等问题，确保规划的顺利实施。

国家文物局

2017年7月5日
