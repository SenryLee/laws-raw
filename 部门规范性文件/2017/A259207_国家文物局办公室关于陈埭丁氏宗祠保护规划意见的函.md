# 国家文物局办公室关于陈埭丁氏宗祠保护规划意见的函

办保函〔2017〕1390号

福建省文物局：

你局《关于全国重点文物保护单位陈埭丁氏宗祠文物保护规划的请示》（闽文物字〔2016〕539号）收悉。经研究，我局意见如下：

一、所报规划前期研究不足，保护区划不合理，我局暂不同意陈埭丁氏宗祠保护规划。

二、所报规划应做以下必要修改和完善：

（一）进一步梳理、明确保护对象，匾联、石碑等可作为附属文物。加强历史研究，厘清陈埭丁氏宗祠的历史格局，明确文物与周边建筑及村落的关系。完善专项评估，补充对宗祠活动现状及强度的评估内容。

（二）合理调整保护区划；保护范围应当与文物建筑本体相对应，增强可操作性。

（三）进一步论证前区广场和停车场建设的必要性，建议统筹考虑村镇发展需求另行选址。

（四）细化展示利用规划，进一步明确展示利用的目标、方式及内容，注意将展示利用与宗祠活动结合。

（五）进一步规范文本和图纸表达，加强图文对应性。

三、请你局指导有关单位，根据上述意见对陈埭丁氏宗祠保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月19日
