# 国家文物局关于上海商业储蓄银行旧址保护范围及建设控制地带内南京地铁5号线修改方案的意见

文物保函〔2017〕1855号

江苏省文物局：

你局《关于审批上海商业储蓄银行旧址保护范围及建设控制地带内南京地铁5号线工程修改方案的请示》（苏文物保〔2017〕308号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、对方案提出以下修改完善意见：

（一）根据岩土层物理力学性质及均匀性和文物建筑对变形的敏感性，采取超常规防护措施，防止施工过程中的地面沉降和振动对文物建筑产生影响。

（二）加强施工管理，细化盾构推进施工参数、质量标准和技术要求，正确设定平衡压力和推进速度，控制好盾构姿态，加强同步和二次注浆，控制好注浆量和注浆压力，消除施工中影响文物安全的隐患。

（三）建立完整的监测系统，加大监测频率，制定防灾预案，特别是对文物建筑应制定专项预加固方案，确保文物建筑安全。

（四）应对施工和运营期间的振动进行评估。若振动速度超出《古建筑防工业振动技术规范》的相关要求，应明确减振或隔振措施。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十七条、第十八条规定，分别报江苏省人民政府和城乡建设规划部门批准后实施。工程施工期间，你局应加强监管，确保文物安全。

四、地铁出入口等地面建筑如涉及文物保护范围和建设控制地带的，应根据文物保护单位级别，依法另行履行相应报批手续。

国家文物局

2017年11月16日
