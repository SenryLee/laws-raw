# 教育部办公厅关于2017年义务教育道德与法治、语文（二、八年级）有关教学用书事项的补充通知

教材厅函〔2017〕12号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

教育部组织编写的义务教育道德与法治、语文（二、八年级）教材已经国家教材委员会审定通过。现将有关事项通知如下:

一、2016年使用义务教育道德与法治、语文统编教材的地区，2017年全部使用审定通过的二、八年级统编教材。

二、全国所有地区义务教育六·三学制道德与法治八年级下全部使用统编法治专册教材。

三、教材中一律不得出现提供额外教学辅助资料的各类链接网址、二维码等信息。

四、各地要高度重视，抓紧安排，确保课前到书。

相关教学用书目录信息可登录教育部门户网站（www.moe.gov.cn）机构设置栏“教材局”下的“工作动态”查询下载。

附件：2017年义务教育道德与法治、语文（二、八年级）统编教材目录
