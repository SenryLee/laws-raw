# 农业部办公厅关于印发《2017年农业科教环能工作要点》的通知

农办科〔2017〕10号

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）、农机、畜牧、兽医、渔业（水利）厅（局、委、办），新疆生产建设兵团农业局，各有关单位：

为深入贯彻中央农村工作会议、中央1号文件和全国农业工作会议、农业部1号文件精神，围绕推进农业供给侧结构性改革工作主线，大力实施创新驱动发展战略，扎实做好农业科技教育与环保能源工作，我部制定了《2017年农业科教环能工作要点》。现印发你们，请结合本地区、本单位实际认真抓好落实，不断强化农业农村经济发展科技支撑。

农业部办公厅

2017年2月27日
