# 中华人民共和国农业部公告第2551号——进口饲料和饲料添加剂产品登记证目录、换发进口饲料和饲料添加剂产品登记证目录

## 中华人民共和国农业部公告

第2551号

根据《进口饲料和饲料添加剂登记管理办法》有关规定，批准美国礼来公司克林顿工厂等32家公司生产的82种饲料和饲料添加剂产品在我国登记或续展登记，并发给进口登记证（见附件1）。批准信东母猪宝（Nutripak Sow）等5个产品中文商品名称、申请企业名称和生产厂家名称变更（见附件2）。所登记产品的监督检验，按中华人民共和国国家标准或农业部发布的质量标准执行。

批准荷兰赛尔可公司生产的“赛可新”改变质量标准，重新颁发进口登记证，（2013）外饲准字427号的登记证同时作废。批准巴西SEMENTES SELECTA S.A.公司Araguari工厂生产的“X-SOY 600大豆浓缩蛋白”改变质量标准，重新颁发进口登记证，（2016）外饲准字083号的登记证同时作废。批准帝斯曼营养产品法国有限公司生产的“罗维素 ?Β-胡萝卜素10%”、“加丽素 ?红10%”和“加丽素 ?黄10%”改变产品配方，重新颁发进口登记证，（2014）外饲准字038号、（2014）外饲准字037号和　　（2013）外饲准字387号的登记证同时作废。

特此公告。

附件：1.进口饲料和饲料添加剂产品登记证目录（2017-05）

2.换发进口饲料和饲料添加剂产品登记证目录（2017-04）
