# 国土资源部办公厅关于配合做好岁末年初安全生产工作的通知

国土资电发〔2017〕46号

各省、自治区、直辖市国土资源主管部门，中国地质调查局及部其他直属单位，各派驻地方的国家土地督察局：

随着年终岁尾的来临，影响安全生产的不稳定因素增多，安全生产压力增大。为认真贯彻落实党的十九大精神，严格落实《国务院安委会办公室关于切实做好岁末年初安全生产工作的通知》（安委办明电〔2017〕18号）要求，切实配合有关部门做好岁末年初安全生产工作，有效防范各类事故反弹，坚决遏制重特大事故发生，现就有关要求通知如下。

一、深入贯彻落实党的十九大精神，切实增强做好岁末年初安全生产工作的责任感和使命感

岁末年初历来是安全生产的关键时期。当前，各类生产经营活动进入旺季，交通运输繁忙，一些企业赶工期、抢任务意愿强烈，加上低温、雨雪、冰冻、寒潮、雾霾等灾害性天气影响，诱发事故的因素在增加。同时，安全生产大检查工作结束后，一些地方和单位容易出现松懈思想，违法违规现象容易“回潮”，引发生产安全事故。地方各级国土资源主管部门、中国地质调查局及部其他直属单位要清醒认识当前安全生产形势的严峻性、复杂性，切实强化政治自觉和行动自觉，认真学习贯彻党的十九大精神，牢固树立安全发展理念，弘扬生命至上、安全第一的思想，认真贯彻安委办明电〔2017〕18号文件要求，进一步加强领导、落实责任，结合实际深入分析岁末年初安全生产的规律特点，超前研判可能出现的风险，采取针对性的管控措施，全力抓好有关安全防范措施落实，严防各类事故发生，确保国土资源系统安全生产形势稳定。

二、切实抓好安全隐患和问题整改，巩固深化安全生产大检查成果

地方各级国土资源主管部门要按照地方人民政府的统一部署，积极配合有关部门对安全生产大检查期间发现的企业安全隐患和问题整改情况进行复查，确保整改落实到位。对尚未整改完成的隐患和问题，属于国土资源主管部门职责范围的，要加强跟踪检查，实行挂牌督办，严格整改措施，强力督促企业整改。要切实加强对停产整顿、关闭取缔矿山或矿点的监督检查，落实专人盯守，严防明停暗开、假停假改，严防非法违法开采行为“死灰复燃”。

中国地质调查局及部其他直属单位要结合本部门、本单位实际，以危险化学品、消防、交通、勘查作业施工等为重点，深入排查、有效管控各类安全风险，及时整治消除各类安全隐患。要重点检查冬季安全防范措施落实情况，加强现场管理和重大危险源监控，发现隐患要立即整改。对一时难以整改到位的隐患，要落实整改责任措施，严密监控；存在重大隐患且不能保证安全的，要坚决停工停产，坚决防止风险管控不到位、隐患整治不彻底而发生事故。

三、加强重点行业领域安全监管执法和专项整治，坚决遏制重特大事故发生

地方各级国土资源主管部门要持续保持高压态势，严厉打击无证勘查开采、超越批准的矿区范围采矿等行为，严防违法违规勘查开采矿产资源引发安全事故。要按照地方人民政府的统一部署，结合职责分工，加强协调联动，强化对事故易发多发区域和企业的联合执法和检查督查。配合有关部门继续深入开展煤矿、非煤矿山安全专项整治，加强对已关闭矿井、停产整顿矿井和尾矿库等的巡查监控，严防违法违规突击生产和垮坝、坍塌、中毒等事故发生。要配合有关部门落实安全生产失信行为联合惩戒机制和“黑名单”管理制度，按照职责分工对有关失信生产经营单位实施有效惩戒。

四、强化应急管理和安全宣传教育，提升安全防范能力

地方各级国土资源主管部门要配合有关部门进一步健全安全风险预警和应急协调联动机制，加强灾害性天气的监测和预报预警工作。要配合有关部门进一步健全完善安全生产应急预案，进一步强化值班值守和应急联动，确保一旦发生事故险情能协助有关部门及时科学有效应对和处置。

中国地质调查局及部其他直属单位要完善细化各项应急处置预案，强化应急演练，做好应急队伍、装备、物资准备工作，加强值班值守，严格执行领导干部到岗值班、关键岗位24小时值班和事故信息报告制度。要强化安全生产宣传教育，采取多种形式，加强冬季用火用电用气、消防、交通等安全知识和逃生自救等常识宣传，进一步增强干部职工安全意识，提高避险减灾技能。要突出重点岗位作业人员，加强全员安全培训，进一步提升管控风险、消除隐患和有效应对初起险情的岗位应急处置能力。

各派驻地方的国家土地督察局要结合实际，进一步明确安全生产责任，采取有力措施，强化安全隐患排查治理，加强应急管理和安全宣传教育，切实抓好岁末年初安全生产工作。

国土资源部办公厅

2017年11月20日
