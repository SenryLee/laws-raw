# 国家文物局关于广东省文物保护单位广州起义烈士陵园保护范围内地铁十二号线工程方案意见的函

## 关于广东省文物保护单位广州起义烈士陵园保护范围内地铁十二号线工程方案意见的函

办保函〔2017〕560号

广东省文物局：

你局《关于在广东省文物保护单位广州起义烈士陵园保护范围内地铁十二号线工程方案的请示》（粤文物审〔2017〕28号）收悉。经研究，我局意见如下：

一、选线方案一与烈士墓冢距离过近，可能会对文物造成较大影响，不宜实施。

二、应从文物保护要求出发，深化建设方案对文物影响程度评估，统筹考虑文物保护与方便交通出行的关系，进一步比选、优化选线方案，补充完善设计说明。

三、轨道列车运行的振动影响可考虑按可感振动的尺度（不大于 1mm/s）进行监测控制，不宜按古建筑砖砌体结构与木结构的容许振动速度限值标准（《古建筑防工业振动技术规范》GB/T 50452-2008）。

请你局指导有关单位，根据上述意见对选线方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局

2017年5月12日
