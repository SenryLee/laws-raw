# 国家文物局关于省级文物保护单位南京高淳水阳江水牮迁移保护项目的意见

文物保函〔2017〕1373号

江苏省文物局：

你局《关于审批省级文物保护单位南京高淳水阳江水牮迁移保护工程修改方案的请示》（苏文物保〔2017〕170号）收悉。经研究，我局意见如下：

一、原则同意所报南京高淳水阳江水牮迁移保护项目和你局意见。

二、对所报工程提出以下修改完善意见：

（一）迁移保护方案需在方案三（分水牮原址保护，九水牮牮随堤退，于新堤重建方案）的基础上进一步修改完善，并进一步依法完善工程实施依据。

（二）应严格遵循文物保护原则实施整体迁移保护工程，全面保护南京高淳水阳江水牮的文物价值和历史信息。应补充九水牮对应河道的特征水位情况和水流特征，确定迁移后九水牮的最佳高程。迁移过程应全部采集地上、地下构件，系统编号记录，科学保存。

（三）项目实施后九水牮周边环境应尽量与原风貌相协调，不宜过度园林化，结合文物展示利用适当进行优化设计。

三、请你局组织相关单位根据上述意见对方案进行修改、完善，根据《中华人民共和国文物保护法》第20条的规定报江苏省人民政府批准。施工中应加强监管和动态监测，确保工程质量和文物安全。

国家文物局

2017年8月8日
