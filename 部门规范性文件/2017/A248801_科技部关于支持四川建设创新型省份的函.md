# 科技部关于支持四川建设创新型省份的函

国科函创〔2017〕24号

四川省人民政府：

《关于报送<四川创新型省份建设方案>的函》（川府函〔2017〕18号）收悉。经研究，函复如下。

一、同意《四川创新型省份建设方案》（以下简称《方案》），支持四川建设创新型省份。要始终把创新作为引领发展的第一动力，摆在发展全局的核心位置，充分发挥科技创新对全面创新的引领作用，将创新型省份建设作为全省上下实施创新驱动发展战略的关键标志性抓手，探索新常态下发展的新路径，打造新常态下发展的新引擎，创造新常态下发展的新优势，凝心聚力当好创新驱动发展的排头兵，为创新型国家建设提供有力支撑。2020年前，要率先进入创新型省份行列，发挥对西部地区乃至全国创新驱动发展的示范引领作用。

二、要努力形成具有四川特色的创新驱动发展模式，发挥好科技创新对推进供给侧结构性改革的支撑引领作用，突出军民融合创新、大众创新创业等区域优势，依靠科技创新破解绿色发展难题和重大民生问题，统筹推进好创新型省份和成都等创新型城市建设，发挥好成都国家自主创新示范区和各高新区的先行先试和引领辐射带动作用，加快实施系统推进全面创新改革试验、推进军民深度融合发展、加强创新型经济建设、发展壮大创新型企业、推动大众创业万众创新、构建重大创新平台、加强创新创业人才队伍建设7大重点任务。

三、要建立健全创新型省份建设管理体制机制，加强组织领导和工作保障，加大科技投入，强化协同推进，制定系列配套支持政策，做好监督评估和总结推广，把各项保障措施抓实抓好。

四、科技部将积极支持你省推进《方案》实施相关工作，建立定期工作会商机制，加强部省战略对接、政策衔接、措施协同，及时研究解决建设中的重大问题，持续监测评价建设进展情况，加强工作指导和支持力度，及时总结典型经验并予以推广。

科技部

2017年3月22日
