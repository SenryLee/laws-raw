# 商务部对外贸易司关于受理江苏盛泰化学科技有限公司固态棕榈硬脂进口备案登记及自动进口许可申请的通知

## 关于受理江苏盛泰化学科技有限公司固态棕榈硬脂进口备案登记及自动进口许可申请的通知

商贸农函〔2017〕177号

江苏省商务厅：

苏商贸函【2017】542号函收悉。

根据商务部2007年第118号公告，同意对江苏盛泰化学科技有限公司进口固态棕榈硬脂予以备案登记。从即日起，你厅可受理上述企业固态棕榈硬脂自动进口许可申请。

商务部对外贸易司

2017年9月22日
