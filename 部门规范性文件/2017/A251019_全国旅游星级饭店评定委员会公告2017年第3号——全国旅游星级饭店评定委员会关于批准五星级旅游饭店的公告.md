# 全国旅游星级饭店评定委员会公告2017年第3号——全国旅游星级饭店评定委员会关于批准五星级旅游饭店的公告

## 全国旅游星级饭店评定委员会公告

2017年第3号

## 全国旅游星级饭店评定委员会关于批准五星级旅游饭店的公告

2017年5月5日，经全国旅游星级饭店评定委员会研究决定，批准上海皇廷世际酒店（标牌编号：3150073）、上海瑞金洲际酒店（标牌编号：3150074）、上海万和昊美艺术酒店（标牌编号：3150075）、河南绿地千玺酒店管理有限公司金威万豪酒店（标牌编号：4150019）、广东海陵岛保利皇冠假日酒店（阳江市）（标牌编号：4450133）、四川九寨沟天源豪生度假酒店（标牌编号：5150034）、青海西宁新华联索菲特大酒店（标牌编号：6350003）为五星级旅游饭店。

特此公告。

全国旅游星级饭店评定委员会

2017年5月5日
