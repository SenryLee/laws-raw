# 科技部关于科技基础资源调查专项2017年度项目立项的通知

国科发基〔2017〕38号

教育部、水利部、农业部、卫生计生委、中科院：

国家科技基础资源调查专项项目立项评审工作已经结束。根据科技基础资源调查专项指南及专家评审结果，经研究，决定批准“中国西南地区极小种群野生植物调查与种质保存”等14个项目立项（见附件）。

请各有关部门和项目承担单位加强管理，认真做好组织实施工作。

附件：科技基础资源调查专项2017年度立项项目清单

科技部

2017年2月16日
