# 国家文物局办公室关于南堂修缮项目的意见

办保函〔2017〕1201号

北京市文物局：

你局《关于南堂修缮工程方案的请示》（京文物〔2017〕1087号）收悉。经研究，我局意见如下：

一、该工程现状勘察不详，必要性及依据不足，修缮措施缺少可行性，文本不规范，暂不同意所报方案。

二、具体修改意见如下：

（一）补充、深化现状勘察内容，细化对受损部位残损程度的说明与评估。补充墙面酥碱损坏程度的说明及其对墙体结构影响的评估。应对东北角裂缝及西北角屋架承重墙开裂进行评估和监测，根据评估、监测结果制定修缮措施。明确屋架开裂位置、走向及残损程度，评估其对整体结构的影响，对于一般性木材干缩造成的开裂，可适当嵌补。

（二）严格遵守最小干预原则，合理控制项目范围。尽可能留用使用原有构件，可修补加固使用的原则上都应继续使用，以保留原有历史信息。对墙面酥碱风化进行剔补应仅限于影响结构安全部位。明确需要更换的大木构件，对于不影响结构安全的应以辅助加固措施为主。建筑台明条石应以现状加固为主。

（三）恢复彩色玻璃应提供相应的历史资料，现状如无明显损坏的不应替换。对于内外增加防滑玻璃窗而造成整体效果的影响应做进一步分析说明。对于近代以来的改动，如不影响文物安全及外观效果，不宜恢复原貌；如确需恢复原貌，应提供依据并进行论证。

（四）建议对庭院做竖向设计，以解决因地平过高而造成的排水不畅、建筑台明被淹没等问题。

（五）注意听取使用单位意见，妥善处理好文物保护与宗教活动的关系。

（六）进一步规范图纸及文字表达，补充人员签章。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善后另行报批。

国家文物局办公室

2017年10月26日
