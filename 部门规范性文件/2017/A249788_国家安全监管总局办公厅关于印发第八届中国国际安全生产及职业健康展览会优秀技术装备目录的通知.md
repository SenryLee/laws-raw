# 国家安全监管总局办公厅关于印发第八届中国国际安全生产及职业健康展览会优秀技术装备目录的通知

安监总厅科技函〔2017〕57号

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局，各省级煤矿安全监察局，有关中央企业：

为了充分发挥先进技术装备对防范和遏制重特大生产安全事故的作用，促进企业进一步提升安全生产技防水平，根据《安全生产法》和《淘汰落后与推广先进安全技术装备目录管理办法》（安监总厅科技〔2015〕43号），现将第八届中国国际安全生产及职业健康展览会部分优秀技术装备产品予以发布，请结合实际，积极推广应用。

附件：第八届中国国际安全生产及职业健康展览会优秀技术装备目录

国家安全监管总局办公厅

2017年4月6日
