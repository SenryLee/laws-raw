# 国家文物局关于成都片区大遗址保护总体规划的意见

文物保函〔2017〕1731号

四川省文物局：

你局《关于报送〈成都片区大遗址总体保护规划〉的请示》（川文物〔2016〕40号）收悉。经研究，我局意见如下：

一、成都片区是我国大遗址保护的重点片区，编制总体规划有利于成都片区大遗址的整体保护，具有积极意义。我局对所报成都片区大遗址保护总体规划无异议。

二、所报规划尚需做如下修改和完善：

（一）进一步明确规划定位和层级，将该规划作为成都片区相关大遗址保护及所在区域城乡发展建设的依据，理顺遗址保护与城乡发展的空间关系，对城市发展方向等提出建议。

（二）进一步梳理成都片区大遗址之间的内在联系，研究成都平原先民活动空间及人居环境变迁历程，提炼形成文化遗存分布的空间格局框架及特征，构建文化遗存价值体系，为后续保护奠定基础。

（三）应根据文物保护需求重点提出相应的政策性建议与策略，补充完善保护区划及相关管理规定的总体原则和要点。

（四）管理规划应进一步提出相关数据库管理更新的机制及技术措施，以保障成都片区大遗址保护与管理的可持续性。

（五）应核实所提出保护区划与所涉及文物保护单位已公布保护区划的关系，以较为严格的区划边界与管理规定为准。

三、请你局指导规划编制单位，根据上述意见对所报规划做进一步修改和完善，经你局核准并报相应的地方人民政府公布实施。公布后的规划文本、图纸及相应的电子资料请一并报我局备案。

四、请你局指导地方人民政府，切实落实规划的相关要求和建议，做好与地方城乡发展规划和土地利用规划的衔接，妥善处理好大遗址保护与城乡发展的关系。

国家文物局

2017年10月10日
