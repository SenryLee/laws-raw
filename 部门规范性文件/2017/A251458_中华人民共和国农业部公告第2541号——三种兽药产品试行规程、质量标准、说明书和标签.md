# 中华人民共和国农业部公告第2541号——三种兽药产品试行规程、质量标准、说明书和标签

## 中华人民共和国农业部公告

第2541号

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准中国农业科学院哈尔滨兽医研究所提交的“重组禽流感病毒灭活疫苗（H7亚型，H7-Re1株）”“重组禽流感病毒（H5+H7）二价灭活疫苗（H5N1 Re-8株+H7N9 H7-Re1株）”“重组禽流感病毒（H5+H7）三价灭活疫苗（H5N1 Re-8株+Re-10株，H7N9 H7-Re1株）”等三种兽药产品试行规程、质量标准、说明书和标签，现予发布，自发布之日起执行。

特此公告。

附件：1.试行规程（略）

2.质量标准（略）

3.说明书和标签
