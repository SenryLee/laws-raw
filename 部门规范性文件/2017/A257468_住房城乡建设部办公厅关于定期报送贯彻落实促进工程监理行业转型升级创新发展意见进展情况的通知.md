# 住房城乡建设部办公厅关于定期报送贯彻落实促进工程监理行业转型升级创新发展意见进展情况的通知

建办市函〔2017〕744号

各省、自治区住房城乡建设厅，直辖市建委，新疆生产建设兵团建设局：

为贯彻落实《住房城乡建设部关于促进工程监理行业转型升级创新发展的意见》（建市[2017]145号，以下简称《意见》），及时掌握各地工作进展，确保各项改革任务有效落实，推动工程监理行业转型升级创新发展，现就报送《意见》贯彻落实情况有关事项通知如下。

一、报送内容

（一）贯彻落实《意见》制定的实施方案、配套政策措施；

（二）工程监理法规制度建设，规范性文件制定情况；

（三）推动监理服务主体多元化、监理服务模式创新和促进监理企业做大做强等情况；

（四）加强工程监理市场监管、推动监理行业诚信体系建设和违法违规行为处罚等情况；

（五）培育全过程工程咨询服务、监理企业报告质量监理等试点工作情况；

（六）存在的问题、下一步工作计划及有关工作建议。

二、报送要求

（一）各省级住房城乡建设主管部门要高度重视《意见》的贯彻落实工作，准确把握各项工作进展及存在的问题，按照通知要求及时报送有关情况。

（二）自本通知印发之日起至2019年底，请各省级住房城乡建设主管部门每半年汇总本地区贯彻落实《意见》情况，并分别于每年1月10日、7月10日前将有关情况报告（含电子版）报我部建筑市场监管司。首次情况报告请于2017年11月30日前报送。
