# 农业部办公厅关于加快上报耕地轮作休耕制度试点地区承包地确权登记数据的通知

农办经〔2017〕17号

河北、内蒙古、辽宁、吉林、黑龙江、湖南、贵州、云南、甘肃省（区）农业（农牧、农村经济）厅（委）：

为贯彻落实《农业部关于印发〈2017年耕地轮作休耕制度试点工作方案〉的通知》（农农发〔2017〕1号）、《农业部办公厅关于印发〈耕地轮作休耕制度试点“一平台五创新”重点工作落实方案〉的通知》（农办农〔2017〕4号）精神和部领导对耕地轮作休耕制度试点工作的有关要求，现就加快上报耕地轮作休耕制度试点地区承包地确权登记数据相关工作通知如下。

一、认真做好耕地轮作休耕数据上报

根据任务分解情况，2017年耕地轮作休耕制度试点共涉及9个省份187个县（市、区），除黑龙江、湖南和甘肃大部分县（市、区）已提交地块四至信息外，截至目前仍有117个县（市、区）未能提交符合要求的地块四至信息（具体名单见附件）。为保证耕地轮作休耕制度试点后续工作顺利开展，现要求上述117个县（市、区）不迟于2017年8月31日将农村承包地确权登记数据提交到农业部经管司。鉴于各地确权进度不一，数据基础差异较大，分类说明如下。

（一）确权登记数据已覆盖全部轮作休耕区域的，根据农村承包地确权登记颁证工作有关要求继续完善数据内容，按照规定的时间节点，以县（市、区）为单位，将全部农村承包地确权登记数据提交到省里，由省里统一提交至农业部。

（二）确权登记数据只覆盖部分轮作休耕区域的，加快确权工作进度，提高轮作休耕区域的确权登记数据覆盖率，按照规定的时间节点，以县（市、区）为单位，将现有农村承包地确权登记数据提交到省里，并对未覆盖区域作出书面说明，经省级农业主管部门审核后统一提交至农业部。

（三）确权登记数据未覆盖任何轮作休耕区域的，且未采取GPS定位等方法获取数据信息的，由县（市、区）农业局形成书面材料，说明承包地确权工作进展和轮作休耕任务落实情况，经省级农业主管部门审核后报农业部。

二、分工协作，密切配合

（一）种植业系统负责收集耕地轮作休耕制度试点地块有关信息，包括县、乡、村、组、补贴对象姓名、试点地块编码及面积等。

（二）经管系统负责收集附件中117个县（市、区）耕地轮作休耕制度试点地区的农村承包地确权登记数据。

（三）农业部规划设计研究院负责根据试点地块相关信息从承包地确权登记数据中提取符合要求的地块四至信息，进而开展遥感动态监测、建立遥感数字库等。

各地农业部门要做好统一部署，由种植业和经管系统密切配合，按规定时间和要求上报耕地轮作休耕制度试点地区承包地确权登记数据和试点地块有关信息。

三、有关要求

（一）各省要根据实际情况加大对有关县（市、区）的督促力度，合理安排工作进度，可以分批次向农业部提交农村承包地确权登记数据，确保在规定的时间节点前完成。

（二）农村承包地确权登记数据涉及高精度地理空间信息，各地在数据提交过程中要注意做好数据安全保密工作，采取专人专送的方式进行数据提交，严禁通过互联网或邮寄等方式上报。

请各地高度重视，加强组织协调，明确责任到人，在数据提交中遇到问题及时沟通和汇报，避免出现轮作休耕试点地块编码和承包地确权登记数据中信息不一致等情况，切实做好耕地轮作休耕制度试点地区承包地确权登记数据上报工作。
