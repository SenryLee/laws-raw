# 国家安全生产监督管理总局公告2017年第12号——2017年第二批安全生产失信联合惩戒的单位及其人员名单

## 国家安全生产监督管理总局公告

2017年第12号

根据《国家安全监管总局关于印发<对安全生产领域失信行为开展联合惩戒的实施办法>的通知》（安监总办〔2017〕49号）的规定，经审核，将河北省成安县鑫冶环保有限公司等28家生产经营单位及其有关人员纳入联合惩戒，其中，将山东省临沂金誉石化有限公司等16家生产经营单位及其有关人员纳入联合惩戒“黑名单”管理，现予公告。

附件：2017年第二批安全生产失信联合惩戒的单位及其人员名单

国家安全监管总局

2017年8月25日
