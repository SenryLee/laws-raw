# 国家文物局关于喇家考古遗址公园道路及排水工程建设项目涉及喇家遗址保护范围选址的意见

文物保函〔2017〕1389号

青海省文物局：

你局《关于呈报喇家遗址国家考古公园道路及排水设计方案的请示》（青文物局〔2017〕99号）收悉。经研究，我局意见如下：

一、原则同意喇家考古遗址公园道路及排水工程建设项目涉及喇家遗址保护范围的选址及建设方案。

二、喇家考古遗址公园道路应严格控制路面宽度，采用垫高方式铺设，并采用非硬化或半硬化路面形式。排水工程应注意做好隐蔽处理，避免影响遗址及其周边环境。

三、请你局组织专业考古研究单位，在该项目涉及喇家遗址的拟建区域进一步开展全面的考古调查和发掘工作。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。如需要开展考古发掘，应另行填报考古发掘申请书。

四、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，按照《中华人民共和国文物保护法》第十七条的规定，报青海省人民政府批准。

五、施工中，请你局组织专业机构做好工程建设的全程监管，并督促工程部门切实做好文物保护工作，确保文物安全。

六、请你局督促地方人民政府结合喇家考古遗址公园建设，统筹考虑园区内道路系统规划和展示服务设施建设问题，协调处理好文物保护、展示利用和地方经济社会发展之间的关系。

国家文物局

2017年8月14日
