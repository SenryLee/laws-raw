# 中华人民共和国农业部公告第2495号——新兽药注册目录

## 中华人民共和国农业部公告

第2495号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准华南农业大学等9家单位申报的禽流感病毒H5亚型灭活疫苗（D7株+rD8株）等2种产品为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年2月13日
