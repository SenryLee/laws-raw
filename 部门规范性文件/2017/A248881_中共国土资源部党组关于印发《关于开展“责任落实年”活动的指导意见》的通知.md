# 中共国土资源部党组关于印发《关于开展“责任落实年”活动的指导意见》的通知

国土资党发〔2017〕15号

各省、自治区、直辖市及副省级城市国土资源主管部门，新疆生产建设兵团国土资源局，中国地质调查局及部其他直属单位，各派驻地方的国家土地督察局，部机关各司局：

《关于开展“责任落实年”活动的指导意见》已经部党组审定，现印发给你们，请认真贯彻执行。

中共国土资源部党组

2017年3月10日

## 关于开展“责任落实年”活动的指导意见

为进一步加强国土资源系统党的建设、业务建设和干部队伍建设，坚决落实全面从严治党总体要求，深入推进国土资源领域各项改革，确保党中央、国务院关于国土资源重大决策部署的贯彻落实，为促进经济社会平稳健康发展提供有力的国土资源保障和支撑，部党组决定在国土资源系统开展“责任落实年”活动。现提出如下指导意见。

一、开展“责任落实年”活动的重要意义

去年以来，国土资源系统全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入学习贯彻习近平总书记系列重要讲话精神，认真贯彻落实新发展理念，主动适应经济发展新常态，把“能力建设年”活动作为“两学一做”学习教育的重要载体和有效抓手，通过加强学习培训、深入调查研究、强化实践锻炼、推进轮岗交流、树立正确用人导向、健全干部激励机制，全系统干部作风明显好转，履职担当、善作善为的能力明显提升，有力推动了国土资源事业的改革发展，提升了国土资源管理和服务水平，实现了国土资源工作“十三五”良好开局。同时也必须清醒地看到，按照中央统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局的要求，全系统各级党组织全面从严治党的主体责任落实还不够到位，基层党组织的战斗力尚需进一步提升；干部队伍勇挑重担、敢于担当、狠抓落实的责任意识还不强，在一定程度上还存在不会为、不敢为、庸政懒政怠政现象；国土资源领域“四梁八柱”性改革主体框架基本构筑、改革进入攻坚阶段，落实各项改革措施的力度需进一步加大。为此，部党组决定，在持续推进能力建设的同时，2017年在全系统开展“责任落实年”活动，进一步突出政治责任，强化岗位责任，压实改革责任，狠抓责任落实。

严格落实管党治党政治责任，不断增强全面从严治党的系统性、创造性、实效性，才能为国土资源事业改革发展提供坚强的政治保障；层层落实国土资源工作岗位责任，使广大干部不断增强高度自觉的责任意识，始终保持奋发有为的精神状态，人人都尽职尽责，才能确保党中央、国务院和部党组各项决策部署得以贯彻落实；全面落实国土资源重点领域改革责任，持续推进各项改革向纵深发展，不断增强改革的系统性、整体性、协同性，确保国土资源改革取得预期成效，才能为国土资源事业的健康发展注入生机和活力。

2017年是党的十九大召开之年，是实施“十三五”规划的重要一年，也是供给侧结构性改革的深化之年，国土资源工作任务艰巨而繁重。开展“责任落实年”活动，是深入学习贯彻习近平总书记系列重要讲话精神、落实中央关于全面从严治党要求的重要举措，是推进“两学一做”学习教育常态化制度化、巩固深化“能力建设年”活动成果的重要抓手，是推动国土资源重点领域改革举措有效落实、推进国土资源治理体系和治理能力现代化的现实需要，对于确保党中央、国务院关于国土资源重大决策部署落地生根、见到实效具有十分重要的意义。各级党组织和国土资源系统广大干部，要站在全面推进从严治党、服务和保障经济社会发展全局、持续推动国土资源事业改革发展的高度，充分认识开展“责任落实年”活动的重要意义，切实增强政治责任感和使命感，扎实开展“责任落实年”活动。

二、指导思想和工作目标

（一）指导思想。开展“责任落实年”活动要全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入学习贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，把“责任落实年”活动作为推进“两学一做”学习教育常态化制度化的有效抓手，以落实管党治党政治责任、国土资源工作岗位责任、国土资源重点领域改革责任为重点，有力推动党中央、国务院和部党组各项决策部署在全系统落实到位，促进国土资源事业持续平稳健康发展，以优异的成绩迎接党的十九大胜利召开。

（二）工作目标。通过开展“责任落实年”活动，努力实现以下目标：

----各级党组织全面从严治党的主体责任、纪检机构的监督责任进一步落实，各级领导干部特别是主要负责同志管党治党政治责任以及履行“一岗双责”的主动性进一步增强，党员干部“四个意识”进一步强化，全面从严治党各项工作向纵深推进，国土资源系统的政治生态更加清朗。

----各级干部岗位职责进一步明确，责任意识进一步增强，岗位责任得到有效履行，干部队伍的工作作风进一步转变，“四种能力”进一步提升，党中央、国务院和部党组各项决策部署得到全面落实，国土资源年度工作任务全面完成。

----国土资源领域改革责任切实落实，重大改革深入推进，统筹协调、各方联动的运行机制更加顺畅，改革的系统性、整体性、协同性进一步增强，各项改革取得预期成效。

三、主要任务

（一）严格落实政治责任，推进全面从严治党向纵深发展。各级党组织要牢固树立抓好党建是最大政绩的意识，认真落实党建工作责任制，坚持党建工作与业务工作同部署、同推进、同考核。各级党组（党委）作为抓党建的责任主体，要统筹领导和推进落实全面从严治党工作，重点履行对全面从严治党的领导、用人、保障、管理和监督责任；机关党委要按照上级党组织和同级党组的部署和要求，推进全面从严治党各项工作落实，重点履行协助、推进、教育、监督和引领责任；基层党组织具体落实全面从严治党各项要求，重点履行落实、统筹、教育、监督和管理责任。党组织书记是全面从严治党的“第一责任人”，要强化抓党建的主动意识、主业意识、主责意识，带头履行管党治党责任，亲自协调解决工作中的突出问题，督促班子成员履行管党治党责任，督促下级党组织主要负责人履行管党治党责任；党组织班子成员要履行“一岗双责”，根据分工切实抓好职责范围内的党建工作。各级纪检机构要认真履行好监督责任，强化党内监督，加强对各级党组织和党员领导干部履行职责、行使权力情况的监督，把检查全面从严治党主体责任落实情况作为监督执纪的重点，推动各级党组织解决党建工作中存在的突出问题。

（二）层层落实岗位责任，确保国土资源工作任务全面完成。各省（区、市）国土资源主管部门和部机关各司局、各督察局、部直属事业单位（以下简称各地各单位），要按照党中央、国务院以及部党组的决策部署，依据“三定”方案，明晰单位职责、内部处室职责、个人岗位职责；要将本单位年度党建工作、业务工作、改革工作等各项任务，层层分解落实到领导班子成员、各个处室和工作岗位，全员落实岗位责任。要按照量化可考的原则，建立工作台账，明确工作职责、主要任务、具体措施、完成时限、预期成果和责任人，形成责任清单，将责任和任务层层分解，落实到岗、责任到人。各级领导干部和每名干部职工都要明确个人职责，主动认领责任，以“工匠精神”做好本职工作，做到知责尽责、立足岗位、建功立业。

（三）全面落实改革责任，确保国土资源重点领域改革取得预期成效。要将党中央、国务院关于国土资源改革的各项任务逐项分解，落实到各相关司局、省（区、市）和改革试点地区。部全面深化改革领导小组全面统筹，定期研究解决改革推进中的重大问题，对改革工作作出阶段性部署，相关专项小组具体组织实施。部调控司负责改革工作的综合协调，业务司局负责具体改革任务的组织和指导，各督察局负责对改革试点任务的落实进行督促指导。试点地区国土资源主管部门要承担改革试点工作的主体责任。部、省要针对重点改革任务，完善督办协调、督察落实、考评激励、责任追究工作机制，构建上下贯通、协调联动的工作格局，确保各项改革取得预期成效。

四、工作要求

各地各单位要按照部党组的统一部署，紧密结合本地区、本单位实际，扎实推动政治责任、岗位责任、改革责任（以下简称“三个责任”）的落实，确保活动取得实效。

（一）坚持以上率下，层层落实责任。各级领导班子要带头落实“三个责任”，以上率下层层推进责任落实。领导干部要以身作则、作出表率，带头认领政治责任，认真履行岗位责任，勇于担当改革责任，并带头抓好责任落实。各地各单位要落实责任主体，理清责任链条，明确责任环节，拧紧责任螺丝，强化责任传导，既要按照各自的分工抓好责任落实，又要加强协同配合，构建以上率下、全员参与、协调联动、层层落实的工作格局，形成促进责任落实的工作合力。

（二）坚持重在日常，做到典型引路。各地各单位要按照“简便易行、实在管用、客观公正、重在日常”的原则，强化对各级干部落实“三个责任”的日常监督考核，对责任落实情况实行动态管理、定期督查督办，将责任落实融入日常、抓在经常。要坚持典型引路，对于工作推进有力、落实责任到位、活动成效显著的，总结推广经验，予以通报表扬；对贯彻执行不力、责任落实不到位、推诿扯皮、庸政懒政怠政的，要予以点名通报，督促限期整改。

（三）坚持正面激励，树立正确导向。开展“责任落实年”活动要纳入党建考核和绩效考核，把“三个责任”落实情况，作为领导班子和干部考核、评先表彰、干部使用的重要依据。坚持正确选人用人导向，强化正向激励，在推进“责任落实年”活动中考察干部、发现干部，让忠诚干净担当、为民务实清廉、奋发有为、锐意改革、实绩突出的干部得到重用，切实把那些想干事、能干事、干实事的干部选拔到重要岗位。建立科学的容错纠错机制，把严格管理干部和热情关心干部结合起来，切实做到“三个区别开来”，旗帜鲜明为敢于担当的干部担当、为敢于负责的干部负责，给干事者鼓劲，为担当者撑腰，营造敢于担当、干事创业、风清气正的政治生态。

（四）坚持问题导向，强化考评问责。坚持“有权必有责、有责要担当、失责必追究”，把监督检查、目标考核、责任追究有机地结合起来，做到失责必问、问责必严。各级党组织和纪检机构要认真落实“两个责任”，对责任不落实、不作为或乱作为的，对有令不行、有禁不止的，要抓住典型、动真碰硬、严肃问责。建立责任落实的“负面清单”和责任追究的倒查机制，对政治责任不落实、管党治党不力的，对工作失职、履职不力造成重大影响的，对改革措施不落实、影响改革进程的，既追究责任人的责任，也要上查一级，追究领导责任和党组织责任。

五、保障措施

（一）加强组织领导。部成立“责任落实年”活动领导小组，由部党组书记、部长、国家土地总督察姜大明同志任组长，分管负责同志任副组长。领导小组办公室设在部办公厅。各地各单位要成立相应的领导机构，将“责任落实年”活动纳入重要日程，确保活动目标明确、内容具体、措施扎实、有序推进。

（二）强化督促检查。部将“责任落实年”活动开展情况作为督查工作的重要内容，组成督导组开展督查督导，推动“三个责任”的落实。各地各单位要加强对活动开展情况的督促检查，及时了解掌握活动进展，及时发现和解决存在问题，确保“责任落实年”活动取得实实在在的效果。

（三）营造良好氛围。充分利用传统媒体和新媒体，大力宣传“责任落实年”活动开展情况，及时宣传报道活动开展动态和成效，充分发挥正面典型的引导和激励作用。适时组织召开“责任落实年”活动经验交流会，总结交流各地各单位在活动开展中创造的好经验好做法，为活动扎实开展搭建交流学习平台、营造良好舆论氛围。

各地各单位要按照本指导意见的要求，结合实际制定本地区本单位“责任落实年”活动实施方案，于3月底前报部活动领导小组办公室。
