# 商务部关于公布部分工业品出口企业名单及2018年出口配额的通知

商贸函〔2017〕第950号

根据《货物进出口管理条例》，现公布2018-2019年钨、锑、白银出口国营贸易企业名单以及磷矿石出口企业名单，下达白银、磷矿石2018年出口配额，并就有关事项通知如下：

一、2018年出口配额主要参照各企业近三年的产量、出口数量、出口金额进行计算。

二、请将配额尽快下达至相关企业。

三、部分企业因涉嫌违法违规，资质（配额）暂不授予（下达），视整改情况另行处理。

附件：1.2018-2019年度年钨、锑、白银出口国营贸易企业名单

2.2018年磷矿石出口企业名单

3.2018年白银、磷矿石出口配额分配表

商务部

2017年12月26日
