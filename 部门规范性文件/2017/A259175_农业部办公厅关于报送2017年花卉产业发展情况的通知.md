# 农业部办公厅关于报送2017年花卉产业发展情况的通知

农办农〔2017〕31号

各省、自治区、直辖市农业（农牧、农村经济、林业）厅（委、局），北京市园林绿化局、海南省花卉协会：

为准确掌握2017年全国花卉产业发展情况，现就有关事项通知如下。

一、报表填报

按照《花卉产业统计调查制度》（国统制〔2017〕173号）要求，认真做好花卉产销情况表等填报工作，确保数据准确、前后衔接。填报系统的网址为：http：//cjkz.agri.gov.cn。

二、工作总结

对本省（区、市）2017年花卉产业发展情况进行总结，包括花卉产业发展情况及主要特点、存在的主要问题、2018年工作打算等。

三、有关要求

请于2018年1月20日前完成网络填报，并将有关统计报表及总结文字材料发送到zzyjzc@agri.gov.cn。

联系人：种植业管理司经作处杜建斌，电话：010—59192879。

附件：花卉产业统计调查制度

农业部办公厅

2017年12月21日
