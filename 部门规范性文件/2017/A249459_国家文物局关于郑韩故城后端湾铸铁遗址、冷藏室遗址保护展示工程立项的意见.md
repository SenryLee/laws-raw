# 国家文物局关于郑韩故城后端湾铸铁遗址、冷藏室遗址保护展示工程立项的意见

## 关于郑韩故城后端湾铸铁遗址、冷藏室遗址保护展示工程立项的意见

办保函〔2017〕311号

河南省文物局：

你局所报郑韩故城后端湾铸铁遗址、冷藏室遗址保护展示工程立项申请（豫文物〔2017〕37、38号）收悉。经研究，我局意见如下：

一、暂不同意郑韩故城后端湾铸铁遗址、冷藏室遗址保护展示工程立项。

二、应结合郑韩故城考古遗址公园建设的总体进展以及遗址展示利用的总体需求，统筹考虑后端湾铸铁遗址和冷藏室遗址的展示问题，进一步科学分析对两处遗址进行展示的可行性与必要性，并结合遗址性质和特点确定恰当的展示思路和方式。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年3月24日
