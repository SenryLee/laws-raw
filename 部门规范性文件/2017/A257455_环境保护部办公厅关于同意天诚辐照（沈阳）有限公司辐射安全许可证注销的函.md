# 环境保护部办公厅关于同意天诚辐照（沈阳）有限公司辐射安全许可证注销的函

## 关于同意天诚辐照（沈阳）有限公司辐射安全许可证注销的函

环办辐射函〔2017〕1687号

天诚辐照（沈阳）有限公司：

你公司《〈辐射安全许可证〉注销申请》收悉。鉴于你公司辐照装置已完成退役并于2017年9月经我部终态验收合格，根据《放射性同位素与射线装置安全和防护条例》（国务院令第449号）有关规定，我部同意你公司申请，注销你公司辐射安全许可证（国环辐证［00044］）。

环境保护部办公厅

2017年11月8日
