# 国家文物局关于政协十二届全国委员会第五次会议第3116号（文化宣传类223号）提案会办意见的函

## 关于政协十二届全国委员会第五次会议第3116号（文化宣传类223号）提案会办意见的函

办保函〔2017〕615号

住房和城乡建设部办公厅：

现就言恭达委员提出的《关于城镇化建设中保护与利用好历史文化遗产的提案》，提出以下会办意见：

文物见证中华民族灿烂文明，承载中华优秀传统文化历史根脉，是弘扬社会主义核心价值观、实现经济社会可持续发展的宝贵资源。目前，全国共登录不可移动文物766722处，其中包括4296处全国重点文物保护单位。我局协同住房和城乡建设部报国务院批准公布了131座历史文化名城，两部局还先后公布了252个中国历史文化名镇、276个中国历史文化名村、30个中国历史文化街区和4157个中国传统村落。“十二五”期间，国家重点文物保护专项补助资金从2011年的39亿元增加到2015年的75亿元，5年累计安排专项资金310亿元，有力促进了文化遗产事业的发展。

下一步，我局将积极贯彻落实习近平总书记有关文物工作的重要指示批示精神，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）和《中共中央办公厅、国务院办公厅关于实施中华优秀传统文化传承发展工程的意见》（中办发〔2017〕5号）的部署，高度重视城市改造和新农村建设中的文物保护，积极会商有关部门，加强历史文化名城、村镇、街区和传统村落整体格局和历史风貌的保护，着力做好以下工作：

一、完善制度体系。推进《文物保护法》修订，完善文物保护基本制度。配合住房城乡建设部落实《文物保护法》有关规定，抓紧制订名城申报、管理、濒危与撤销的标准和办法，探索实施名城退出机制；加快制定《历史文化街区保护办法》，填补历史街区管理规范空白；完善《历史文化名城保护规划规范》，加强城乡规划与文物保护规划衔接。

二、切实加大文物保护力度，注重活态传承。坚持分类指导，突出重点，加强基础，实现由注重抢救性保护向抢救性与预防性保护并重转变，由注重文物本体保护向文物本体与周边环境、文化生态的整体保护转变，确保文物安全。加强保护展现古城古镇古村和历史文化街区富有地方特色和集体记忆的文化空间，将古民居、文物古迹等与其相关的民俗活动、传统手工艺技能保护和传承相结合，做好原有社区的文化氛围和活态多元风貌的保护，社区文化传承人及原住居民的保留，社区文化活动的挖掘与丰富等工作，并注重社区自然环境保护，做到文化遗产与人们生活、自然环境和谐相处。

三、创新管理，鼓励社会力量参与文物保护利用。充分发挥文物保护社会组织和志愿者的作用；利用公益性基金等平台筹措保护资金，依托“互联网+”等新科技，丰富文物展示利用形式和内容；探索政府和社会资本合作（PPP）模式，公布不可移动文物利用的项目清单，让社会团体或企业自主选择利用形式和运营模式。在保护利用过程中，坚持公益属性，发挥文物的公共文化服务功能。同时进一步推进文物保护利用中“简政放权、放管结合、优化服务”的体制机制改革，依法出台相关政策措施，拓宽文物流通渠道，鼓励民间收藏文物合法流通，推动文物保护利用和文化传承。

四、加强文物知识普及。充分发挥文物保护单位、博物馆社会教育的功能，特别关注未成年人成长和青少年教育，推进文化遗产纳入国民教育体系。加强与教育部门共建共享机制，创新文博机构教育服务的内容、形式和手段，经常举办针对性的展示、论坛、讲座等活动，开展研学旅行和文化旅游等文化体验，使青少年更多地了解文化遗产的丰富内涵。

以上意见供参考。

国家文物局
