# 国家文物局办公室关于朔州崇福寺彩塑壁画数字化勘察测绘的意见

办保函〔2017〕1210号

山西省文物局：

你局《关于审批朔州崇福寺彩塑壁画数字化勘察测绘技术方案的请示》（晋文物〔2017〕190号）收悉。经研究，我局意见如下：

一、应进一步明确彩塑壁画数字化勘察测绘项目的主要任务和目标，分析数字化勘察、病害稳定性评估测绘等技术在彩塑壁画保护中的应用前景，深入研究数字档案资料留存、数据管理体系搭建、数字化成果共享及在艺术史和保护技术、展示利用方面等工作，促进文物本体保护。

二、请你局指导相关单位按照上述意见对具体方案进行修改完善并组织实施;彩塑壁画本体维修，应按照我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的要求履行审批程序。同时，指导保护管理单位切实做好朔州崇福寺的保护和管理工作，加强日常养护、巡查和监测，确保文物安全。

国家文物局办公室

2017年10月30日
