# 中华人民共和国农业部公告第2511号——进口兽药注册目录

## 中华人民共和国农业部公告

第2511号

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准韩国RNL科技公司等3家公司生产的枸橼酸苹果酸粉等4个产品在我国注册和再注册，核发《进口兽药注册证书》,并发布产品质量标准、说明书和标签，自发布之日起执行。

批准西班牙海博莱生物大药厂生产的猪伪狂犬病毒gE糖蛋白阻断ELISA抗体检测试剂盒变更注册。

特此公告。

附件：1.进口兽药注册目录

2.质量标准（略）

3.说明书和标签
