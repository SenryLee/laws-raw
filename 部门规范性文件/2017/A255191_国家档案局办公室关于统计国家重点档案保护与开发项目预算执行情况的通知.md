# 国家档案局办公室关于统计国家重点档案保护与开发项目预算执行情况的通知

档办函〔2017〕39号

各省、自治区、直辖市档案局、馆，青岛市档案局、馆：

为做好2017年国家重点档案保护与开发项目预算执行工作，请按要求填报《2016年国家重点档案保护与开发项目预算执行情况统计表》（见附件1）和《2016年国家重点档案目录基础体系建设预算执行情况统计表》（见附件2），于2月10日前将表格纸质版（加盖单位公章）与电子版（光盘方式）报国家档案局行财司。电子表格可在国家档案局网站（www.saac.gov.cn）首页“下载专区”栏目中下载。

联系人：章永加、刘阳

联系电话：010-66176373（传）

附件：

1.2016年国家重点档案保护与开发项目预算执行情况统计表

2.2016年国家重点档案目录基础体系建设预算执行情况统计表

国家档案局办公室

2017年1月25日
