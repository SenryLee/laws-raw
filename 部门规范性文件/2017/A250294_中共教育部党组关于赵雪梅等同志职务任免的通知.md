# 中共教育部党组关于赵雪梅等同志职务任免的通知

教党任〔2017〕47号

中共武汉大学委员会：

经与中共湖北省委商得一致，2016年12月16日研究决定：

黄泰岩同志任中共武汉大学委员会常务副书记（正厅级），赵雪梅同志任中共武汉大学委员会副书记，沈壮海同志任中共武汉大学委员会常委、副书记；免去骆郁廷、王传中同志的中共武汉大学委员会副书记、常委职务。

中共教育部党组

2017年4月7日
