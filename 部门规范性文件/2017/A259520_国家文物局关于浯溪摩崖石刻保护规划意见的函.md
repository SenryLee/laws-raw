# 国家文物局关于浯溪摩崖石刻保护规划意见的函

文物保函〔2017〕2056号

湖南省文物局：

你局《关于审批浯溪摩崖石刻文物保护规划（2016-2030）（修改）的请示》（湘文物报〔2016〕161号）收悉。经研究，我局意见如下：

一、原则同意所报浯溪摩崖石刻保护规划。

二、对该规划提出以下修改意见：

（一）结合浯溪摩崖石刻的历史沿革，梳理保护对象认定，明确文物本体和历史环境构成。

（二）深化、完善现状评估。完善对赋存岩体的评估内容，明确岩体结构安全性和稳定性；细化洪水对文物本体影响程度的评估内容；补充景区建设对文物本体影响程度的评估。

（三）梳理保护区划管理规定，厘清管理规定和保护工程的区别；明确保护范围内不得进行任何与文物保护无关的内容；严格制定建设活动的控制要求。

（四）结合现状评估内容完善保护措施，明确保护工程实施对象、工程范围和工程要求。在评估历史环境的基础上，进一步确定拆迁的范围及必要性。

（五）进一步补充与相关规划衔接的内容。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的浯溪摩崖石刻保护规划报请湖南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好浯溪摩崖石刻文物保护的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月26日
