# 文化部关于废止部分规范性文件的通知

文政法函〔2017〕1152号

各省、自治区、直辖市文化厅（局），新疆生产建设兵团文化广播电视局，各计划单列市文化局，本部各司局、各直属单位，国家文物局：

特此通知。
