# 公开市场业务交易公告[2017]第239号——关于人民银行于12月14日开展逆回购操作500亿元，同时开展MLF操作2880亿元的公告

## 公开市场业务交易公告

[2017]第239号

为对冲税期和月内MLF到期对银行体系流动性的影响，满足金融机构合理的季节性流动性需求，维护银行体系流动性基本稳定，人民银行于12月14日开展逆回购操作500亿元，同时开展MLF操作2880亿元，具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 300亿元 | 2.50% |
| 28天 | 200亿元 | 2.80% |

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 1年 | 2880亿元 | 3.25% |

中国人民银行公开市场业务操作室

二〇一七年十二月十四日
