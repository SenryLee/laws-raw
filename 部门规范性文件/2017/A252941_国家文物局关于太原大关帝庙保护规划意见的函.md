# 国家文物局关于太原大关帝庙保护规划意见的函

## 关于太原大关帝庙保护规划意见的函

文物保函〔2017〕1048号

山西省文物局：

你局《关于审批太原大关帝庙文物保护规划的请示》（晋文物 〔2016〕130号）收悉。经研究，我局意见如下：

一、原则同意所报太原大关帝庙保护规划。

二、对该规划提出以下修改意见：

（一）深化价值评估，科学评价、全面归纳太原大关帝庙在太原城市历史中的地位和作用。加强文物周边历史环境研究，深入分析文物与周边历史街巷的关系，补充大关帝庙南北视线通廊分析。

（二）应根据文物分布情况和保护管理需要，科学调整保护区划及其具体边界。结合视线通廊分析，适当扩大北侧建设控制地带范围。补充对东侧商业街的控制要求。

（三）应针对现状评估结论，研提具有针对性与可操作性的文物保护策略。“保护标志等”应纳入专项规划。

（四）应根据现状评估结论，进一步明确环境整治对象，提出具体措施要求。

（五）进一步完善展示利用规划，根据文物保护和展示利用需要，进一步明确展示利用的主要内容和定位，结合周边文物资源情况统筹考虑停车场选址和规模。补充展示服务设施建设清单，进一步论证保护范围内建设项目的必要性，明确拟建设施的具体面积、规模、高度和建筑风貌等的指标要求。

（六）补充所报规划与相关规划的衔接内容。

（七）进一步校核与规范文本与图纸，规范用语。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的太原大关帝庙保护规划报请山西省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体立项报告或方案，并按程序报批。

六、请你局指导和协调地方人民政府落实保护规划要求，进一步做好太原大关帝庙的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年6月1日
