# 公开市场业务交易公告[2017]第162号——关于不开展公开市场操作的公告

## 公开市场业务交易公告

[2017]第162号

2017年8月24日开展800亿元中央国库现金管理商业银行定期存款操作，银行体系流动性总量处于适中水平，不开展公开市场操作。

中国人民银行公开市场业务操作室

二〇一七年八月二十四日
