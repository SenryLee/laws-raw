# 国家文物局关于南京地铁7号线工程选线方案的意见

## 关于南京地铁7号线工程选线方案的意见

办保函〔2017〕495号

江苏省文物局：

你局《关于审批〈南京地铁7号线选线规划设计方案〉的请示》（苏文物保〔2017〕42号）收悉。经研究，我局意见如下：

一、所报工程选线涉及全国重点文物保护单位南京城墙和省级文物保护单位石头城遗迹、姚南村明墓石刻等多处文物，对文物安全影响较大，我局暂不同意南京地铁7号线工程选线方案。

二、所报方案应进行以下必要的修改和完善：

（一）进一步优化地铁选线，地铁线路及站点应尽量远离文物本体，建议避让石头城遗址区和仙林六朝陵墓区。

（二）应准确说明轨道交通与文物的水平、竖向位置关系及距离。

（三）文物保护范围内应采取盾构法施工，合理确定盾构推进的施工系数、质量标准和技术要求，尽量减少施工对文物的影响。暗挖矿山法施工区段应根据地质条件和隧道断面合理确定分部施工方法，做好临时支撑加固，避免影响文物安全。

（四）应科学核定安全稳定振动控制标准、参数取值、计算模型、计算方法及结论值等，确保相关测算结论科学、可靠、准确。同时，应综合考虑岩土层物理力学性质、均匀性以及文物本体对变形的敏感性等因素，进一步深化文物保护措施和应急预案，确保南京地铁7号线施工和运营期间文物安全。

（五）不同意在姚南村明墓石刻东南侧建设西善桥停车场。

（六）进一步补充说明施工期与运营期监测工作方案，并保证数据连续和基准参考值一致。

（七）进一步完善文物影响评估报告，准确核实南京城墙的内部结构和承载能力，科学评估地铁建设和运营对南京城墙的影响。

三、请你局组织有关单位根据上述意见，对所报方案进行修改、完善后，按程序另行报批。

专此函。

国家文物局

2017年4月26日
