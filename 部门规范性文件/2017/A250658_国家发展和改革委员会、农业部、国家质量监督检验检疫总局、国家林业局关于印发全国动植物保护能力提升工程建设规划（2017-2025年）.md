# 国家发展和改革委员会、农业部、国家质量监督检验检疫总局、国家林业局关于印发全国动植物保护能力提升工程建设规划（2017-2025年）的通知

## 关于印发全国动植物保护能力提升工程建设规划（2017-2025年）的通知

发改农经〔2017〕913号

各省（区、市）、新疆生产建设兵团发展改革委、农业（畜牧、水产）厅、林业厅（局），各直属检验检疫局：

根据2016年中央1号文件及《全国农业现代化规划（2016－2020）年》有关要求，为进一步提升我国动植物疫病虫害防控能力，国家发展改革委、农业部、质检总局、国家林业局联合制定了《全国动植物保护能力提升工程建设规划（2017-2025年）》。现予印发，请结合本地实际认真组织实施。

附件：全国动植物保护能力提升工程建设规划（2017-2025年）
