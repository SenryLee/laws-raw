# 中华人民共和国工业和信息化部公告2017年第54号——日用玻璃规范条件

## 中华人民共和国工业和信息化部公告

2017年第54号

## 日用玻璃规范条件

为进一步加强日用玻璃行业管理，规范日用玻璃行业生产经营和投资行为，引导日用玻璃行业向资源节约、环境友好型产业发展，我部对2010年发布的《日用玻璃行业准入条件》进行了修订，形成《日用玻璃行业规范条件（2017年本）》。现予以公告。

附件：日用玻璃行业规范条件（2017年本）

工业和信息化部

2017年11月29日
