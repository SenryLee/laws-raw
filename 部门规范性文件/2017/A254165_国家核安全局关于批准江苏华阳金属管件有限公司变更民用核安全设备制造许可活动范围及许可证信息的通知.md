# 国家核安全局关于批准江苏华阳金属管件有限公司变更民用核安全设备制造许可活动范围及许可证信息的通知

## 关于批准江苏华阳金属管件有限公司变更民用核安全设备制造许可活动范围及许可证信息的通知

国核安发〔2017〕178号

江苏华阳管业股份有限公司:

你公司《关于江苏华阳金属管件有限公司民用核安全设备制造许可证扩证申请》（华阳［2014］第31号）、《关于江苏华阳金属管件有限公司增加许可活动场所的申请》（华阳［2016］第3号）和《关于江苏华阳金属管件有限公司民用核安全设备制造许可证变更申请》（华阳［2017］第5号）收悉。经研究，现通知如下：

根据《民用核安全设备监督管理条例》及其配套规章的要求，我局对你公司民用核安全设备制造许可活动范围及许可证信息变更申请进行了审查，认为你公司在所申请的民用核安全设备制造方面具备了《民用核安全设备监督管理条例》第十三条及《民用核安全设备设计制造安装和无损检验监督管理规定》第八条所要求的各项能力，现批准你公司《民用核安全设备制造许可证》(国核安证字Z（12）32号）增加附件所列许可活动范围，并同意你公司名称由“江苏华阳金属管件有限公司”变更为“江苏华阳管业股份有限公司”，同时增加制造活动场所“江苏省句容经济开发区福地西路南侧、富源路西侧”。

你公司应按照许可证规定的范围和条件，开展民用核安全设备制造活动，确保民用核安全设备制造质量。

附件：江苏华阳管业股份有限公司民用核安全设备制造许可活动范围表（新增）

国家核安全局

2017年8月12日
