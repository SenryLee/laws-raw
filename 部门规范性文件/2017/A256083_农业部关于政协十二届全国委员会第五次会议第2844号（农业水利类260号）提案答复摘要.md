# 农业部关于政协十二届全国委员会第五次会议第2844号（农业水利类260号）提案答复摘要

## 政协十二届全国委员会第五次会议第2844号（农业水利类260号）提案答复摘要

一、关于加快完善农业面源污染防治补偿法律法规问题

我部积极推动出台专门的法律法规或法律条文，建立农业面源污染防治补偿制度。开展农业生态补偿立法调研，配合有关部门制定《生态补偿条例》，推动全国21个省（区、市）颁布了省级农业生态环境保护条例，相继实施了测土配方施肥等一系列涉及农业面源污染防治补偿的项目，为研究建立农业面源污染防治补偿制度打好基础。

下一步，我部将继续会同有关部门，加快完善农业面源污染防治补偿法律法规体系。

二、关于加大农业面源污染防治补偿投入力度、拓宽融资渠道问题

我部会同有关部门，通过增加财政投资、改革补贴政策、加强市场培育等方式，积极拓宽融资渠道。先后出台《农业环境突出问题治理总体规划（2014—2018年）》《全国农业可持续发展规划（2015—2030年）》等政策文件，加大农业面源污染防治投入力度。推动印发《建立以绿色生态为导向的农业补贴制度改革方案》，推进农业三项补贴改革，积极构建促进农业资源与生态保护的农业补贴政策体系和激励约束机制。会同环境保护部印发了《培育发展农业面源污染治理、农村污水垃圾处理市场主体方案》，积极扶持社会化市场主体，推动第三方治理。

下一步，我部将会同有关部门，在严格控制新设专项转移支付的前提下，通过现有的财政投资、补贴、市场培育等渠道，加强资源整合，进一步加大农业面源污染防治补偿投入力度。

三、关于开展农业面源污染防治补偿试点示范问题

近年来，我部会同有关部门，实施一系列农业面源污染防治项目，为开展农业面源污染防治补偿积累经验。2005年以来组织实施测土配方施肥补贴项目，2017年开展有机肥替代化肥示范。加大绿色防控技术集成和示范推广力度，实施低毒生物农药示范推广补贴试点项目。推进畜禽粪污资源化利用，探索适合不同区域特点的畜禽粪污综合利用模式。开展秸秆、农膜综合利用试点，启动东北地区秸秆处理行动和农膜回收行动。2016—2017年，联合国家发展改革委启动农业突出问题治理项目，加强重点流域农业面源污染综合治理。

下一步，我部将会同有关部门，继续实施好现有试点示范项目，争取总结提炼出一批适合推广的好模式、好做法，推动农业面源污染防治工作。

四、关于加强农业面源污染防治关键技术攻关问题

我部高度重视科技在农业面源污染防治中的支撑作用。2011年，成立“农业部面源污染控制重点实验室”，推进农业面源污染综合防治研究，建立农业面源污染防控技术体系。2016年，成立国家农业废弃物循环利用创新联盟。“十三五”以来，我部会同科技部启动实施国家重点研发专项“农业面源和重金属污染农田综合防治与修复技术研发”。

下一步，我部将会同有关部门，继续加强农业面源污染防治关键技术研发。

五、关于加强农业面源污染监测和监督问题

我部始终把体系队伍建设和监测能力建设作为加强农业面源污染防治工作的重要抓手。目前，全国已构建起国家、省、市、县四级农业环境保护管理体系和专家队伍，建立了全国农业面源污染国控监测网络，开展农业面源污染典型调查与长期定位监测，实施了农产品产地土壤重金属污染普查，配合环境保护部先后启动了全国土壤污染状况详查和第二次全国污染源普查。

下一步，我部将继续加强农业环境保护管理体系和专家队伍建设，推进农业面源污染调查监测。

农业部
