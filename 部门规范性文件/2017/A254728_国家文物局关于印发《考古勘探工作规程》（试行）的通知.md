# 国家文物局关于印发《考古勘探工作规程》（试行）的通知

## 关于印发《考古勘探工作规程》（试行）的通知

文物保发〔2017〕14号

各省、自治区、直辖市文物局（文化厅）：

考古勘探工作是当前我国考古与文物保护工作的一项重要内容，是开展考古学研究、推进文物保护、服务好各类基本建设工程的重要基础。为规范我国考古勘探工作的程序、内容和技术要求，进一步提升考古勘探和相关管理工作的水平，我局组织编制了《考古勘探工作规程》（试行），现予印发。请你局（厅）组织相关单位认真学习并依照执行，切实加强考古勘探工作管理，及时组织开展专业人员培训，确保考古勘探工作质量不断得到提高。在规程执行过程中发现问题请及时向我局反馈。

附件：《考古勘探工作规程》（试行）
