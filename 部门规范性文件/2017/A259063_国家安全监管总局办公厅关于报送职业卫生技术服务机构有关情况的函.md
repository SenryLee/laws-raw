# 国家安全监管总局办公厅关于报送职业卫生技术服务机构有关情况的函

厅函〔2017〕546号

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局，各省级煤矿安全监察局：

为有序推进职业卫生技术服务机构资质管理制度改革，加强职业卫生技术服务机构监督管理，加快职业卫生技术服务机构信息化建设，摸清全国职业卫生技术服务机构现状，请你局按职责分工组织辖区内职业卫生技术服务机构（包括甲级、乙级和丙级机构）认真填写《职业卫生技术服务机构基本情况调查表》（附件1），汇总填写《职业卫生技术服务机构汇总表》（附件2）和《职业卫生技术服务机构监管情况汇总表》（附件3），填写信息和汇总数据截至2017年12月31日。请于2018年1月19日前将有关表格（加盖公章）报送国家安全监管总局职业健康司，同时将电子版（Word版）发送至zwj@chinasafety.gov.cn。相关表格在国家安全监管总局网站“职业健康”栏目下载。

联系人及电话：张伟军，010-64463617（带传真）。

附件：

1.职业卫生技术服务机构基本情况调查表

2.职业卫生技术服务机构汇总表

3.职业卫生技术服务机构监管情况汇总表

国家安全监管总局办公厅

2017年12月18日
