# 农业部关于政协十二届全国委员会第五次会议第3161号（资源环境类194号）提案答复摘要

## 政协十二届全国委员会第五次会议第3161号（资源环境类194号）提案答复摘要

近年来，我部会同环境保护部等部门持续强化农用地土壤环境管理，开展污染耕地治理修复工作，构建农产品质量安全保障体系，推进农产品产地环境保护，保障农产品质量安全。一是关于建立健全农用地土壤环境管理体制。《农业法》《环境保护法》《农产品质量安全法》《水污染防治法》《基本农田保护条例》等法律法规对耕地土壤保护都做出相关规定。目前《土壤污染防治法（草案）》已公开向社会征求意见，草案列专章对农用地管理职责进行了规定，强化农用地土壤环境保护。二是关于农产品产地保护区建设。我部不断强化农产品产地环境保护，开展优质农产品品牌建设，提升农产品质量安全水平。截至2016年底，全国共创建果菜茶标准园近6000个、畜禽养殖标准化示范场4179家、水产健康养殖示范场6218家、国家农产品质量安全县（市）107个，“三品一标”总数超过10万个。三是关于开展耕地污染治理修复。2014年以来，农业部、财政部在湖南长株潭地区开展重金属污染耕地修复及农作物种植结构调整试点，通过实施“VIP”（品种替代、灌溉水净化、pH值调节）等综合技术，探索了可借鉴、可复制、可推广的耕地重金属污染治理模式；在天津、湖南、广东、辽宁等地建立了9个重金属污染耕地治理示范区，针对各个治理示范区的污染特点，积极探索以农艺措施为主体的治理技术的示范和推广。四是关于建立农产品质量安全保障体系。国家有关部门高度重视政策法规标准建设在保障农产品质量安全方面的作用。国务院办公厅专门印发了《关于加强农产品质量安全监管工作的通知》，我部出台了《“十三五”全国农产品质量安全提升规划》《全国农业执法监管能力建设规划（2016-2020年）》《农业部关于加强农产品质量安全检验检测体系建设与管理的意见》；会同相关部门制定《食品中农药最大残留限量制定指南》《用于农药最大残留限量标准制定的作物分类》，及农产品产地适宜性评价技术规范、农业灌溉水质标准、城市再生水农田灌溉水质标准等系列标准规范。

下一步，我部将积极配合全国人大推进《土壤污染防治法》制定工作，完善法规体系，加强污染耕地治理修复及农产品产地保护区建设，建立健全农产品质量安全保障体系，保障农产品质量安全。

农业部

2017年9月11日
