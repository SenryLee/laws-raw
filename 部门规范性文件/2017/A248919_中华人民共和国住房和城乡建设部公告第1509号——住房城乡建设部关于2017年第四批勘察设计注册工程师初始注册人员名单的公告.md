# 中华人民共和国住房和城乡建设部公告第1509号——住房城乡建设部关于2017年第四批勘察设计注册工程师初始注册人员名单的公告

## 中华人民共和国住房和城乡建设部公告

第1509号

## 住房城乡建设部关于2017年第四批勘察设计注册工程师初始注册人员名单的公告

根据《勘察设计注册工程师管理规定》（建设部令第137号）和《关于建设部机关直接实施的行政许可事项有关规定和内容的公告》（建设部公告第278号）规定，经审核，马晓辉等11名申报注册土木工程师（岩土）初始注册人员、谢京臣等5名申报一级注册结构工程师初始注册人员、赵金亮等36名申报注册公用设备工程师初始注册人员、尹力文等47名申报注册电气工程师初始注册人员、郭广军1名申报注册化工工程师初始注册人员符合注册条件，准予注册。

特此公告。

附件：1．准予马晓辉等11名注册土木工程师（岩土）初始注册人员名单

2．准予谢京臣等5名一级注册结构工程师初始注册人员名单

3．准予赵金亮等36名注册公用设备工程师初始注册人员名单

4．准予尹力文等47名注册电气工程师初始注册人员名单

5．准予郭广军1名注册化工工程师初始注册人员名单

住房城乡建设部

2017年3月30日
