# 农业部关于政协十二届全国委员会第五次会议第0139号（资源环境类003号）提案答复摘要

## 政协十二届全国委员会第五次会议第0139号（资源环境类003号）提案答复摘要

一、关于建立健全海洋农业机械化发展长效机制

我部将会同有关部门，进一步加大对海洋渔业机械制造企业的扶持力度，引导和鼓励企业加强对海洋渔业机械设备产品的研发，生产更多更适合的海洋渔业机械产品；加强政策宣传，支持引导更多符合条件的海洋渔业机械纳入农机购置补贴目录，加快推广应用。

二、关于提高科技支撑力度，构建国家海洋农业机械化科技创新体系

我部将会同国家有关部门全链条创新设计、一体化组织实施，通过国家资源配置加快对海洋渔业机械化科研的支持，并积极支持企业参与项目研发工作，加大养殖设施机械化和数字化研发投入，满足我国海洋渔业机械化进程可持续发展的科研需求。

三、关于鼓励和引导合作经营的海洋农业生产新模式

我部将积极争取有关部门的支持，助推渔业各类新型经营主体更好发展，不断提升渔业生产组织化和产业化水平，为推广应用海洋渔业机械和提高海洋渔业机械化水平提供必要的基础条件。

四、关于发展海洋农业机械社会化服务体系

我部将加大宣传力度，积极推广先进适用的海水养殖机械和设备，扩大海水养殖数字渔业试点范围，并充分利用现有的扶持政策，进一步调动水产养殖生产经营者使用机械的积极性，促进提升我国海洋渔业机械化水平。

农业部

2017年8月17日
