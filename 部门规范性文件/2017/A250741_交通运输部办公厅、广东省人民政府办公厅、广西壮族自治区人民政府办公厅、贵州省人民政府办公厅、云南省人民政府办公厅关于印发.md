# 交通运输部办公厅、广东省人民政府办公厅、广西壮族自治区人民政府办公厅、贵州省人民政府办公厅、云南省人民政府办公厅关于印发珠江水运科学发展行动计划 （2016—2020年）的通知

## 交通运输部办公厅 广东省人民政府办公厅 广西壮族自治区人民政府办公厅贵州省人民政府办公厅 云南省人民政府办公厅关于印发珠江水运科学发展行动计划 （2016—2020年）的通知

交办水[2017]52号

广东、广西、贵州、云南省（自治区）交通运输、发展改革、财政、国土资源、环境保护、水利厅（委），沿江各地（市、州）人民政府，珠江航务管理局，广东、广西海事局：

为深入贯彻落实国家“一带一路”战略、深化泛珠三角区域合作，实施珠江—西江经济带发展规划，打造畅通、高效、平安、绿色的珠江水运体系，切实推动珠江水运科学发展，经交通运输部、广东省人民政府、广西壮族自治区人民政府、贵州省人民政府、云南省人民政府同意，现将《珠江水运科学发展行动计划（2016—2020年）》印发给你们，请遵照执行。
