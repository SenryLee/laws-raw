# 国家新闻出版广播电影电视总局办公厅关于报送2017年新闻出版统计快报数据的通知

## 关于报送2017年新闻出版统计快报数据的通知

新广出办发〔2017〕74号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中国新闻出版研究院，中央及中央各部门各单位在京出版、报纸、期刊、印刷、发行等各类出版传媒集团、图书出版社、报社、期刊社，各出版物进出口公司：

为及时掌握全国新闻出版行业的发展情况，按时向国家统计局提供2017年国民经济和社会发展统计公报所需的新闻出版业统计资料，现就报送2017年新闻出版统计快报数据的有关事项通知如下：

一、报送内容

（一）图书出版统计快报的指标为：本版图书出版品种数（种），其中包括新出和重印本版图书品种数（种）；全部图书的总印数（万册、张），总印张（千印张），定价总金额（万元）。

（二）报纸出版统计快报的指标为：全部报纸（不含校报）出版品种数（种），总印数（万份），总印张（千印张），定价总金额（万元）。

（三）期刊出版统计快报的指标为：期刊出版品种数（种），总印数（万册），总印张（千印张），定价总金额（万元）。

（四）出版、报纸、期刊、印刷、发行等各类出版传媒集团经营情况统计快报的指标为：资产总额（万元）、所有者权益（万元）、本年折旧（万元）、营业收入（万元）、主营业务收入（万元）、主营业务成本（万元）（限发行集团填写）、营业利润（万元）、利润总额（万元）、纳税总额（万元）、职工薪酬（万元）（包含本年应付工资总额、本年应付福利费总额、本年劳动待业养老医疗总额及其他应计入项）、年平均人数（人）。

（五）出版物进出口统计快报的指标为：出版物（图书、期刊、报纸、音像、电子出版物、数字出版物）进出口品种数（种）、金额（万美元）、数量（万册）。

（六）各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局根据本辖区2016年相关数据及2017年新闻出版产业发展情况，测算各行业的财务汇总数据，填报本辖区分行业财务数据汇总快报表。其指标为：资产总额（万元）、所有者权益（万元）、本年折旧（万元）、营业收入（万元）、主营业务收入（万元）、主营业务成本（万元）（限发行行业填写）、营业利润（万元）、利润总额（万元）、纳税总额（万元）、职工薪酬（万元）（包含本年应付工资总额、本年应付福利费总额、本年劳动待业养老医疗总额及其他应计入项）、年平均人数（人）。

二、报送方法

2017年新闻出版统计快报数据直接报送单位采取网络直报和传真相结合的方式。网络直报通过登录全国新闻出版统计网（www.ppsc.gov.cn）进入填报界面后直接填报并提交，待中国新闻出版研究院审核确认后，将快报表通过系统打印并加盖公章，传真到中国新闻出版研究院。

各省、自治区、直辖市新闻出版广电局及新疆生产建设兵团新闻出版广电局将本辖区新闻出版统计快报数据审核、汇总后，通过系统提交或电子邮件将数据报送至中国新闻出版研究院，待中国新闻出版研究院审核确认后，填写快报表（见附件）并加盖公章，寄到中国新闻出版研究院。

三、报送时间

各基层直报单位应于2017年12月8日前将2017年统计快报数据报出，各省、自治区、直辖市新闻出版广电局及新疆生产建设兵团新闻出版广电局应于2017年12月15日前将经审核的2017年统计快报汇总数据报出。
