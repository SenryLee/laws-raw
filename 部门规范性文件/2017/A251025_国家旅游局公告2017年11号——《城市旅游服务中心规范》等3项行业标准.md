# 国家旅游局公告2017年11号——《城市旅游服务中心规范》等3项行业标准

## 国家旅游局公告

2017年11号

《城市旅游服务中心规范》（LB/T 060-2017）、《自驾游目的地基础设施与公共服务指南》（LB/T 061-2017）、《旅游产品在线交易基本信息描述和要求》（LB/T 062-2017）等3项行业标准已经国家旅游局批准，现予以公布，2017年11月1日起实施。

国家旅游局

2017年5月22日

附件：

1.《城市旅游服务中心规范》

2.《自驾游目的地基础设施与公共服务指南》

3.《旅游产品在线交易基本信息描述和要求

》
