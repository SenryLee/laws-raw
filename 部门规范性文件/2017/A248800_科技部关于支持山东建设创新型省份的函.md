# 科技部关于支持山东建设创新型省份的函

国科函创〔2017〕23号

山东省人民政府：

《关于报送<山东创新型省份建设方案>的函》（鲁政字〔2017〕3号）收悉。经研究，函复如下。

一、同意《山东创新型省份建设方案》（以下简称《方案》），支持山东建设创新型省份。要始终把创新作为引领发展的第一动力，摆在发展全局的核心位置，充分发挥科技创新对全面创新的引领作用，将创新型省份建设作为全省上下实施创新驱动发展战略的关键标志性抓手，探索新常态下发展的新路径，打造新常态下发展的新引擎，创造新常态下发展的新优势，凝心聚力当好创新驱动发展的排头兵，为创新型国家建设提供有力支撑。2020年前，要率先进入创新型省份行列，努力在推动科学发展、全面建成小康社会进程中走在前列。

二、要努力形成具有山东特色和引领示范作用的创新发展模式，发挥好科技创新对推进供给侧结构性改革的支撑引领作用，以发展蓝色经济、高效生态经济为主导，做好省内各区域功能互补、相互促进、协调发展的文章，依靠科技创新破解绿色发展难题和重大民生问题，统筹推进好创新型省份和济南、青岛、济宁、烟台等创新型城市建设，发挥好山东半岛国家自主创新示范区和各高新区的先行先试及引领辐射带动作用，加快实施好全面深化科技体制改革、推动形成区域创新发展新格局、全面提升科技创新综合实力、大力推进创新平台载体建设、加快壮大创新型人才队伍、着力推进科技金融深度结合、加快推进科技服务民生、全面推进开放创新发展、大力优化创新创业生态环境9大重点任务。

三、要建立健全创新型省份建设管理体制机制，加强组织领导和工作保障，加大科技投入，强化协同推进，制定系列配套支持政策，做好监督评估和总结推广，把各项保障措施抓实抓好。

四、科技部将积极支持你省推进《方案》实施相关工作，建立定期工作会商机制，加强部省战略对接、政策衔接、措施协同，及时研究解决建设中的重大问题，持续监测评价建设进展情况，加强工作指导和支持力度，及时总结典型经验并予以推广。

科技部

2017年3月22日
