# 人力资源社会保障部办公厅关于做好定点帮扶宁都技工学校工作的通知

人社厅函〔2017〕114号

河北、江苏、江西省人力资源社会保障厅，部属有关单位：

江西省宁都县是人力资源社会保障部对口支援的国家级贫困县。建设好宁都技工学校对加快宁都县脱贫攻坚、推进宁都县全面小康进程具有重要意义。为贯彻落实人力资源社会保障部《关于对口支援江西省宁都县人力资源和社会保障事业发展的指导意见》（人社厅发〔2014〕6号）精神，切实把定点帮扶工作落到实处，现就有关事项通知如下：

一、指导思想

深入贯彻党的十八大和十八届三中、四中、五中、六中全会和习近平总书记系列重要讲话精神，创新帮扶思路，创优帮扶机制，创特帮扶措施，切实帮扶宁都技工学校完善办学条件、提升办学水平和质量，大力推进宁都技工学校改革创新，更好地服务宁都经济社会发展。

二、主要目标

建立健全结对协作和对口支援工作机制，支援宁都技工学校改善办学条件、夯实办学基础、扩展办学规模，帮扶该校加强专业建设、师资队伍建设、校企合作、内部管理等内涵建设，推进宁都技工学校改革创新发展，争取到2020年，学校在办学规模、设施设备、内涵建设和培养质量方面达到高级技工学校水平，为宁都县全面实现脱贫目标提供技能人才支撑。

三、工作任务

（一）组建专家指导服务团。从部职业能力建设专家智库、全国重点技工院校中挑选专家组成宁都技工学校专家指导服务团（名单见附件1），接受学校的咨询，采取书面答复或现场指导等方式，对办学定位、发展方向、专业设置、师资队伍建设、校园建设、学校管理、实训场所规划与布局、校企合作、对外交流等进行全方位的指导。

（二）建立帮扶院校与宁都技工学校的对接机制。各帮扶院校（名单见附件2）对宁都技工学校新设专业和已有专业进行定点帮扶，在该校设立专家流动站，确保定期至少有1名专家入站，以加强对专业建设方案、人才培养方案、专业课程建设、校本教材编撰的指导。按照双向挂职、两地培训、委托培养和支教等方式，各帮扶院校定期选派1-2名高技能人才、优秀教师到宁都技工学校支教，同时接纳宁都技工学校管理人员及教师分批到校培训或跟班顶岗学习3-6个月。各帮扶院校对宁都技工学校各专业实训场地的规划、实训设施设备的采购和配置、实训课程的设置和实施要进行有效指导，并支援部分实训设备。各帮扶院校充分利用企业资源优势，指导帮扶联系至少1家在该地区技术领先、专业对口的规模企业与宁都技工学校对口帮扶专业开展深度校企合作。各帮扶院校采取到校指导、接纳培训等方式，帮助宁都技工学校参加各级各类技能大赛的学生进行专业技能强化训练，提高学生竞技水平。

（三）对宁都技工学校给予资金、项目、政策等方面倾斜。积极协调发展改革部门将公共实训基地建设项目优先落户宁都。支持宁都技工学校建设高技能人才培训基地。协调落实现代职业教育质量提升计划等项目用以支持宁都技工学校建设与发展。支持宁都技工学校改革创新项目试点实施，在人才培养、校企合作、一体化教学改革、毕业生就业创业等领域给予政策、资金倾斜。落实师资能力提升计划，安排宁都技工学校管理人员和专业教师参加全国性培训，协调组织宁都技工学校专业教师赴企业跟班实践。

（四）帮扶指导信息化建设。加强智慧校园建设，指导构建教育资源共享共建体系，实现校园数字化资源全覆盖、职业技能与通识课程在线共享、教学过程和实训过程实时互动，不断优化一体化教学改革，提高教育教学质量。中国人力资源和社会保障出版集团向宁都技工学校捐赠相关图书资料。

四、保障措施

（一）加强统筹，整合资源。部定点帮扶宁都技工学校工作由职业能力建设司牵头，规划财务司、指导中心、出版集团参与。职业能力建设司负责综合协调，规划财务司负责协调帮扶宁都技工学校建设的项目和资金，指导中心负责支持宁都技工学校提升师资能力，出版集团负责支持宁都技工学校一体化课程改革、教材建设等工作。要加强在项目资金、专业建设、师资队伍、就业保障等方面的统筹协调，整合利用优势资源，创新帮扶机制、落实帮扶措施，推进宁都技工学校改革创新发展。

（二）上下联动，形成合力。建立上下联动帮扶工作机制，形成工作合力。人力资源社会保障部具体负责帮扶工作的综合协调，各帮扶院校所在地区人力资源社会保障部门具体负责帮扶工作的组织、督查和调度，各帮扶院校具体抓好帮扶工作的落实。江西省人力资源和社会保障厅积极协调同级发展改革、财政部门以及省内帮扶院校，将优惠政策和优质师资向宁都技工学校倾斜，确保宁都技工学校如期实现发展目标。

（三）立足实际，注重实效。立足帮扶双方实际，建立长期有效的定点帮扶机制，实现帮扶双方长期合作、优势互补、互利共赢。各帮扶院校所在地区人力资源社会保障部门要加大对帮扶院校帮扶工作的考评力度，推动定点帮扶工作的落实。帮扶院校要将定点帮扶工作纳入帮扶人员的年度目标考核范围，实施单项考评，帮扶成效好的给予表扬，并作为评先评优、提拔晋升的重要依据。
