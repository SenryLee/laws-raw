# 国家文物局关于柏山东岳庙彩塑数字化勘察测绘项目的意见

文物保函〔2017〕1608号

山西省文物局：

你局《关于审批蒲县柏山东岳庙彩塑数字化勘察测绘技术方案的请示》（晋文物〔2017〕181号）收悉。经研究，我局批复如下：

一、原则同意所报柏山东岳庙彩塑数字化勘察测绘项目和你局意见。

二、对该项目提出以下修改意见：

（一）应进一步调整目标定位.项目应针对2015年已完成的彩塑保护工程效果及彩塑保存状况，重点测绘并采集彩塑形状、色彩基线数据以及进行连续不断的微环境监测。更新和补充彩塑保护工程后的现状照片。

（二）进一步明确采样原则、采样量和测绘精度，厘清勘察对象层次，做到重点突出，层次鲜明,为后期研究和保护工作提供精准的基础信息数据。

（三）细化无人机拍摄和密集彩塑拍摄过程中的文物保护措施。

（四）进一步明确彩塑数字化勘察各环节工作量。细化经费预算，增强合理性和可操作性。

（五）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护和监测的顺利开展。

三、请你局指导有关单位，根据上述意见对方案进行修改、完善，经你局核准后实施。施工中应加强监督和管理，确保工程质量和文物安全。

专此函复。

国家文物局

2017年9月6日
