# 国家文物局关于马蹄寺石窟群保护设施建设项目的意见

## 关于马蹄寺石窟群保护设施建设项目的意见

办保函〔2016〕1385号

甘肃省文物局：

你局《关于呈报马蹄寺石窟群保护设施建设项目文物保护方案的报告》（甘文局发〔2016〕146号）收悉。经研究，我局意见如下：

一、所报项目方案工程性质不明，设计依据不足，文本深度不够，我局暂不同意马蹄寺石窟群保护设施建设项目。

二、所报方案应进行以下必要的修改和完善：

（一）应加强前期勘察，根据马蹄寺石窟群保护、展示和管理需要，进一步加强设施现状评估，客观论证改建、新建各类设施的必要性和可行性，并提供具体设计依据和说明。补充《马蹄寺石窟群文物保护规划》的有关内容，以及文物保护区划管理规定和具体控制指标。

（二）应科学划分工程类型，明确工程性质，危岩体加固工程和消防设施建设项目应按要求深化内容并另行报批。

（三）进一步深化设计方案，明确拟建项目的位置、范围和规模，补充具体设计内容、经济技术指标和图纸。应进一步说明步道、栈道的选线、外观、建造方式以及与石窟的位置关系，严格控制新建道路规模，合理确定铺装材料、色彩，尽量与周围环境风貌相协调。

（四）完善文物影响评估报告，深入论证拟建项目对马蹄寺石窟群文物本体和环境风貌的影响，做到客观、准确、科学。

（五）进一步规范文本，补充项目区域保护服务设施的现状照片。

三、请你局组织有关单位根据上述意见，对所报方案进行修改、完善，并经你局审核后按程序另行报批。

专此函。

国家文物局

2017年1月4日
