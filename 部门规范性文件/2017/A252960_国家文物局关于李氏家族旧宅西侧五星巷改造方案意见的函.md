# 国家文物局关于李氏家族旧宅西侧五星巷改造方案意见的函

## 关于李氏家族旧宅西侧五星巷改造方案意见的函

办保函〔2017〕781号

安徽省文物局：

你局《关于审批合肥市李氏家族旧宅西侧五星巷改造方案的请示》（皖文物保〔2017〕37号）收悉。经研究，我局意见如下：

一、暂不同意所报方案。

二、该方案应做以下修改：

（一）补充李氏家族旧宅的保护区划图及相关的管理规定，并明确拟实施改造项目的范围。

（二）深入研究李氏家族旧宅的建筑特色，五星巷立面改造应与文物环境风貌相协调，不宜突出商业氛围。

（三）街巷绿化和小品布置等应简洁古朴，不能刻意营造城市园林效果。

请你局指导有关单位，根据上述意见对方案进行完善后，按程序另行报批。

专此函复。

国家文物局

2017年6月22日
