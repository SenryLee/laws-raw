# 国家信访局对十二届全国人大五次会议第4750号建议的答复

你们提出的关于加强边疆少数民族地区信访基础设施建设的建议收悉，现答复如下：

近年来，按照中央的决策部署，国家信访局深入推进信访工作制度改革，全力打造阳光信访、责任信访、法治信访。有关边疆少数民族地区各项改革措施的落实落地情况，特别是信访基础设施建设和业务规范化建设，我们一直高度重视、密切关注。国务院副秘书长、国家信访局局长舒晓琴多次深入内蒙古、广西、云南、西藏、新疆等边疆少数民族地区调研指导工作，并对夯实信访基层基础建设等方面工作提出明确要求。2015年6月，国家信访局印发了《关于进一步加强和规范联合接访工作的意见》，强调各地要“按照方便群众、布局合理、功能完善、环境友好的要求，改善接访条件，满足接访需要”，“有条件的地方可在联合接访场所建立视频接访系统，搭建快捷高效服务群众的远程接访平台，方便信访群众就地反映诉求”，为这项工作提供了有力的政策支撑。此外，我们积极推进“互联网+信访”，全面实行网上信访工作模式，进一步完善各级网上信访受理办理平台，全力打造网上信访主渠道。2016年以来，我们相继开通手机APP和微信公众号，进一步拓宽群众诉求表达渠道，努力让数据多跑路，群众少跑腿。但是，由于各地经济社会发展不平衡，对信访基础设施投入不一，边疆少数民族地区也确实存在你们在《建议》中提及的，信访基础设施建设比较落后，与全国先进水平相比差距较大的问题。下一步，一方面，我们将继续督促指导各地加大投入，完善接待场所建设；另一方面，采取多种方式，积极倡导群众变“走访”为“网访”，搭建更加方便快捷的网上信访工作平台。

关于你们提出的由中央财政支持，中央和地方财政共同负担投入资金，参照公安、司法系统基础设施标准化建设的方式，加强和完善边疆少数民族地区信访基础设施建设的建议，中央财政近年来出台了一揽子支持边疆经济社会发展的政策和措施，由地方政府统筹安排，支持地方各项事业发展。边疆少数民族地区各级信访接待设施建设问题，应由所在省级人民政府统筹研究解决。申请中央基建专项资金支持少数民族地区基础设施建设，据与财政部沟通，可按照基本建设资金管理规定，向有关部门提出申请，由国家发展改革委牵头统筹研究。关于规范接访场所硬件设施建设内容及标准的建议，我们大力倡导搭建“一站式接待、一条龙办理、一揽子解决”的综合服务平台，但受经济发展水平、接访需求等因素影响，全国不宜实行“一刀切”，各地可结合实际，制定不同标准，满足当地群众信访需求。

感谢你们提出的宝贵意见建议，希望继续关心和支持信访工作。

国家信访局

2017年6月29日
