# 财政部干部教育中心关于举办2017年第二期政府采购业务（信息统计）培训班的通知

## 关于举办2017年第二期政府采购业务（信息统计）培训班的通知

财干教〔2017〕120号

各有关单位：

为做好2018年全国政府采购信息统计及中央单位政府采购计划编报工作，根据《2017年财政部干部教育培训计划》安排，财政部干部教育中心与国库司决定举办2017年第二期政府采购业务（信息统计）培训班。现将有关事项通知如下：

**一、**培训内容

（一）2018年全国政府采购信息统计编报工作。

（二）2018年中央单位政府采购计划编报工作。

（三）部署中央单位政府采购计划管理系统迁移工作。

**二、**培训对象

各省、自治区、直辖市、计划单列市财政厅（局）负责政府采购信息统计工作的人员,每单位1人；中央一级预算单位政府采购工作负责人及信息统计工作人员各1人；中央集中采购机构相关人员,每单位2人。

**三、**培训时间

2017年12月19日至21日，18日报到。

**四、**培训地点

山东威海蓝天宾馆(山东省威海市环海路1号)。

**五、**培训经费

培训费由财政部干部教育中心按标准统一核拨。

**六、**其他事项

（一）请各单位严格按照要求派人参训，并务必于12月12日前将填好的报名回执（见附件）发送至财政部国库司邮箱egptrain@sina.com和山东威海蓝天宾馆邮箱1020954127@qq.com。同时，请参训人员将到达威海、烟台的航班或到达威海的车次信息传真至山东威海蓝天宾馆，以便接站。

（二）联系人及联系电话。

1．财政部干部教育中心培训一处尚凤文，联系电话：010-68553624。

2．财政部国库司政府采购管理一处李承双，联系电话：010-68552386（兼传真）。

3．山东威海蓝天宾馆邹莉莉，联系电话：0631-5231670、5231063（传真）。
