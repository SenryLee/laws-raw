# 国家文物局关于桃渚城保护规划意见的函

文物保函〔2017〕1985号

浙江省文物局：

你局《关于要求审批全国重点文物保护单位桃渚城保护规划的请示》（浙文物发〔2016〕97号）收悉。经研究，我局意见如下：

一、原则同意所报规划。

二、对该规划提出以下修改意见：

（一）梳理保护对象和文物构成，明确文物认定标准，厘清文物建筑和非文物建筑。建议进一步区分非文物建筑、历史建筑和传统风貌建筑，细化评估到建筑单体。

（二）补充保护区划调整理由，完善管理规定。明确保护范围内非文物建筑的拆建标准，明确建设控制地带内建筑高度、屋顶形式及建设强度、用地性质、道路绿化、环境景观等要求。

（三）保护措施不应归入专项规划，应专章单列。清理距文物本体较近的乔木及根系时应注意对墙体的保护；对已掩埋的护城河段等遗址，应开展考古勘探，查清遗址范围，确保文物安全。

（四）专项规划应对排水、电力、消防管线的敷设走向、位置等提出明确要求。

（五）加强与相关规划衔接，补充与相关规划衔接内容。规划依据应增加《历史文化名城名镇名村保护条例》。

（六）加强研究规划，应增加桃渚城与下旧城、中旧城、烽堠等关系的内容。

（七）进一步规范文本体例，补充环境规划图、管理规划图、景观视廊控制图、高度控制图等图纸，规范图纸名称。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕]17号）的要求，将经我局备案的桃渚城保护规划报请浙江省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

国家文物局

2017年12月11日
