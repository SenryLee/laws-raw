# 国家文物局关于杨公阙保护规划的意见

## 关于杨公阙保护规划的意见

办保函〔2017〕92号

四川省文物局：

你局《关于报送〈杨公阙保护规划〉的请示》（川文物〔2016〕61号）收悉。经研究，我局意见如下：

一、所报规划的整体思路不清，规划措施不当，应做较大修改，我局不同意杨公阙保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

应加强考古和历史研究，明确杨公阙和墓葬之间的关系，并进一步厘清墓葬整体范围和格局，为科学确定保护对象、文物构成和保护区划提供依据。

（二）关于保护区划与管理规定

应结合考古研究成果，合理调整保护区划，明确建设控制地带分类，制定不同强度的控制要求和具体建设控制指标，增强可操作性。同时，应充分考虑地下文物埋藏区，为保护区划调整预留空间。补充基本农田的相关管理控制规定。

（三）关于保护措施

应针对文物病害情况，科学研提保护措施，慎重考虑纠偏、水泥修补块剔补、防风化加固等措施的科学性和可行性，严格控制干预强度。同时，进一步论证杨公阙保护亭重建、增设护栏的必要性和景观影响，不同意大规模保护性设施建设工程。

（四）关于环境整治和专项规划

1．应根据文物现状环境和保护管理的实际需求，合理研提环境整治、安消防和基础设施建设要求，明确新建道路、拆建围墙、改建管理用房和景观绿化的具体内容、设计依据。

2．应充分考虑杨公阙的区位条件，客观评估杨公阙展示利用前景，进一步简化展示服务设施内容。

3．应制定专项考古计划，明确考古和研究工作的主要目标、内容和技术路线，并注意考古调查与文献研究相集合。

（五）规范文本和图纸表达，加强图文对应性。

三、请你局指导有关单位进一步调整规划编制思路，从杨公阙保护管理的实际需求出发，合理研提规划措施，增强科学性和针对性。修改后的规划文本经你局同意后，按程序另行报批。

专此函。

国家文物局

2017年2月7日
