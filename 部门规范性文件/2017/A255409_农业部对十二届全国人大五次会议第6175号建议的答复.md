# 农业部对十二届全国人大五次会议第6175号建议的答复

## 对十二届全国人大五次会议第6175号建议的答复

农办议〔2017〕106号

刘连昌等2名代表：

你们提出的关于加快推进鲁苏豫皖黄河故道沿线精准扶贫的建议收悉。经研究，现将涉及我部职能的内容答复如下。

鲁苏豫皖黄河故道地区地处我国黄淮平原，是我国重要的农产品生产基地，对保障我国粮食安全发挥着重要的作用。我部高度重视该地区农业农村经济发展，持续加大支持力度。仅2016年，会同财政部、国家发展改革委安排山东、江苏、河南、安徽4省各类涉农项目资金627亿元，比2015年增长1%。

一、关于支持种植业绿色发展

近年来，我部围绕保障绿色农产品安全有效供给，不断加强产能建设，牢固树立绿色发展理念，夯实农民增收基础。一是加大绿色高产高效创建支持力度。2016年安排中央财政资金3.96亿元，支持山东、江苏、河南、安徽4省开展绿色高产高效创建，集成组装区域性、标准化高产高效技术模式，引领农业生产方式转变，带动提升该地区种植业综合生产能力。二是实施耕地保护与质量提升行动。安排专项资金，以推进秸秆还田为突破口，开展退化耕地综合治理、污染耕地阻控修复和土壤肥力保护提升综合技术模式试点，在鲁苏豫皖黄河故道耕地退化地区集中投入、连片建设，发挥示范带动作用。三是深入实施农药化肥使用量零增长行动。2016年安排中央财政资金11.7亿元，支持4省开展重大农作物病虫害统防统治、小麦“一喷三防”、测土配方施肥和有机肥替代化肥示范，推进统防统治与绿色防控融合，调优施肥结构，实行精准施肥，促进种养循环，减少化肥农药使用量。四是开展区域生态循环农业示范。2016年，安排4省区域生态循环农业项目资金4500万元，以提高农业资源利用效率和实现农业废弃物“零排放和全消纳”为目标，开展畜禽养殖废弃物资源化利用、农副资源综合开发、标准化清洁化生产等方面的建设，促进种养结合、生态循环。

下一步，农业部将紧紧围绕推进农业供给侧结构性改革这个工作主线，以绿色发展为导向，以结构调整为重点，以农民增收为目标，进一步加大对黄河故道地区工作指导力度，对符合国家投资方向、具备支持条件的项目，尽可能优先安排，发挥现代农业产业技术体系专家作用，加大农业科技帮扶力度，切实推动鲁苏豫皖黄河故道地区种植业健康、稳定、可持续发展。

二、关于支持农产品加工业发展。

提高农产品冷链物流能力，加快发展农产品精深加工是提高农业附加值的重要手段。近年来，我部主要从以下两个方面开展工作。一是大力发展农产品产地初加工。2012年，我部提出大力发展农产品产地初加工，实施中央财政补助。截止目前，累计支持河南省、山东省3.8亿元，扶持3400个农户、2570个合作社、135个家庭农场，新建马铃薯贮藏窖、果蔬贮藏库和烘干房等初加工设施6120座，新增马铃薯贮藏能力5.3万吨、果蔬贮藏能力35.7万吨、果蔬烘干能力10.3万吨。通过实施农产品初加工设施补助政策，有效地改善了鲁豫黄河故道沿线地区农产品产地初加工设施条件，大幅减少产后损失。据测算，水果、蔬菜产后损失率由项目实施前的25%下降到5%左右，蔬菜销售价格提高了30%-50%，为增加有效供给，带动农民增收，实现产业精准扶贫发挥了重要作用。二是促进农村一二三产业融合发展。今年农业部、财政部将全国所有省份均纳入农村一二三产业融合发展支出项目，采取先建后补、贷款贴息方式，支持能够让农民分享二三产业增值收益的经营主体，主要用于发展农产品加工流通和直供直销、农村电子商务、农业多功能性拓展、产业扶贫等工作。山东、江苏、河南、安徽均在实施项目范围内。

下一步，农业部将积极推进农产品产地初加工补助政策向鲁苏豫皖黄河故道沿线地区倾斜，优先安排江苏、安徽等未安排补助资金的省份，尤其是黄河故道地区。认真贯彻落实中央关于推进农村一二三产业融合发展的部署要求，立足职能，结合工作实际，指导鲁苏豫皖黄河故道地区做好项目实施工作，积极推进农村一二三产业融合发展。

三、关于支持休闲农业和乡村旅游发展

休闲农业和乡村旅游是促进一二三产业融合发展，带动贫困地区经济社会发展的重要手段。去年以来，我部围绕休闲农业与乡村旅游，重点开展以下几方面工作：一是联合国家发展改革委等14部门印发了《关于大力发展休闲农业的指导意见》（农加发〔2016〕3号），作为推进鲁苏豫皖地区休闲农业与发展乡村旅游的指导性文件。二是扩大品牌知名度和影响力，2016年认定江苏、山东、河南、安徽4省休闲农业和乡村旅游示范县12个、中国美丽乡村21个。三是根据季节特点和小长假时点分布，围绕“春节到农家过大年”“早春到乡村去踏青”“初夏到农村品美食”“仲秋到田间去采摘”四个主题，通过中国农业信息网、中国休闲农业网、农民日报等媒体和微信朋友圈等渠道，有步骤、分时段向社会推出鲁苏豫皖黄河故道沿线休闲农业和乡村旅游精品景点线路。四是做好沿线重要农业文化遗产发掘保护，开展重要农业文化遗产普查，组织专家对认定的遗产进行评估。截止目前，已在4省认定中国重要农业文化遗产8个。

下一步，农业部将继续实施休闲农业和乡村旅游提升工程，扶持建设一批功能完备、特色突出、服务优良的休闲农业聚集村、休闲农业园、休闲农业合作社，改善基础配套服务设施和休闲农业基地种养条件。引导社会资本支持黄河故道地区积极开展休闲旅游项目，探索农民利益分享机制。

感谢你们对农业、农村工作的关心和重视，希望今后继续对我部工作予以支持。
