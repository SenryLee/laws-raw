# 国家减灾委员会、民政部关于公布2017年全国综合减灾示范社区名单的通知

## 国家减灾委员会　民政部关于公布2017年全国综合减灾示范社区名单的通知

民发〔2017〕189号

各省、自治区、直辖市减灾委员会、民政厅（局），各计划单列市减灾委员会、民政局，新疆生产建设兵团减灾委员会、民政局：

今年以来，国家减灾委、民政部根据《民政部关于印发<全国综合减灾示范社区创建管理暂行办法>的通知》（民函〔2012〕191号）有关要求，在全国范围内开展了2017年全国综合减灾示范社区候选单位推荐工作。在各地民政部门检查、自评和推荐基础上，经审核，现公布2017年“全国综合减灾示范社区”名单（附后）。

各地要认真学习贯彻党的十九大和习近平总书记关于防灾减灾救灾工作的重要讲话精神，牢固树立灾害风险管理和综合减灾理念，深入总结全国综合减灾示范社区创建工作经验，创新工作思路，提升创建质量，推动社区减灾工作再上新台阶。全国综合减灾示范社区要再接再厉，继续发挥典型示范和带头作用，继续在提升公众的防灾减灾意识和自救互救技能上下功夫，为全面提升基层的防灾减灾救灾能力作出更大贡献。

附件：2017年全国综合减灾示范社区名单

国家减灾委员会　 民政部

2017年12月25日
