# 国家能源局公告2017年第12号——国家能源局2018年度能源软科学研究选题指南

## 国家能源局公告

2017年第12号

为加强能源重大问题研究，我局研究编制了《国家能源局2018年度能源软科学研究选题指南》（以下简称《选题指南》），现予公布。

为更好地服务能源重大政策制定，我局鼓励单位和个人在从事能源领域相关研究时参考《选题指南》确定选题，相关事宜可与我局法制和体制改革司联系。

联系方式：fagaisi@nea.gov.cn
