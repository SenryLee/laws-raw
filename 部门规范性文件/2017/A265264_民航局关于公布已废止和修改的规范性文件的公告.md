# 民航局关于公布已废止和修改的规范性文件的公告

民航公告〔2017〕11号

按照国务院有关要求，我局对现阶段民航领域与“放管服”改革不一致的、不利于新产业新业态发展的规范性文件进行了清理，已废止18件，修改18件。现予公布。

中国民用航空局

2017年12月21日

附件：已废止修改文件目录（截止2017年11月1日）
