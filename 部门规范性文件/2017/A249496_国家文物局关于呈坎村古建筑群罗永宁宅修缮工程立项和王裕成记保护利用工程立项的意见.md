# 国家文物局关于呈坎村古建筑群罗永宁宅修缮工程立项和王裕成记保护利用工程立项的意见

## 关于呈坎村古建筑群罗永宁宅修缮工程立项和王裕成记保护利用工程立项的意见

办保函〔2017〕329号

安徽省文物局：

你局《关于批准呈坎村古建筑群罗永宁宅修缮工程立项的请示》（皖文物保〔2017〕13号）、《关于批准黄山市呈坎村古建筑群——王裕成记保护利用工程立项的请示》（皖文物保〔2017〕14号）收悉。经研究，我局意见如下：

一、暂不同意呈坎村古建筑群罗永宁宅修缮工程立项和王裕成记保护利用工程立项。

二、请你局切实加强文物保护工程管理，督促地方人民政府和有关单位，全面梳理呈坎村古建筑群文物保护工程进展情况，总结、评估工程实施效果，核查项目开工率和经费使用情况，按照我局《关于进一步规范国家重点文物保护专项补助资金管理、提高使用绩效的通知》（文物办发〔2017〕5号）要求，尽快推进已批复项目实施。

三、请你局督促地方人民政府统筹考虑呈坎村古建筑群保护利用工作，明确整体工作思路和阶段分期，并切实加强罗永宁宅、王裕成记日常保养和岁修工作，落实管理维护责任，确保文物安全。

专此函。

国家文物局

2017年3月27日
