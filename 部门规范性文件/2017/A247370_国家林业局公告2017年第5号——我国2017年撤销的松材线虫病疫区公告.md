# 国家林业局公告2017年第5号——我国2017年撤销的松材线虫病疫区公告

## 国家林业局公告

2017年第5号

根据《植物检疫条例》和《全国林业检疫性有害生物疫区管理办法》（林造发﹝2013﹞17号）的有关规定，现将我国2017年撤销的松材线虫病疫区公告如下：

江苏省：镇江市京口区、镇江新区。

浙江省：宁波市江北区。

福建省：漳州市东山县。

湖北省：宜昌市点军区、猇亭区。

湖南省：郴州市苏仙区。

广西壮族自治区：梧州市万秀区。

贵州省:黔西南州安龙县。

特此公告。

国家林业局

2017年1月11日
