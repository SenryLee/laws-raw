# 人力资源社会保障部、公安部关于追授赵天昱、蔡松松2名同志“全国公安系统一级英雄模范”荣誉称号的决定

## 人力资源社会保障部　公安部关于追授赵天昱、蔡松松2名同志“全国公安系统一级英雄模范”荣誉称号的决定

人社部发[2017]23号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）、公安厅（局）：

近年来，全国公安机关和广大公安民警在党中央、国务院和地方各级党委、政府的坚强领导下，坚持围绕中心、服务大局，开拓创新、扎实工作，为维护国家安全和社会稳定，保卫改革开放和社会主义现代化建设，保障人民群众安居乐业作出了突出贡献，涌现出一大批英雄模范人物，赵天昱、蔡松松同志就是其中的优秀代表。

赵天昱同志是中国共产党党员，生前任吉林省辉南县公安局石道河派出所副所长，三级警督警衔。该同志从警20年来，始终战斗在打击违法犯罪和维护社会治安第一线，忠诚履职、敬业奉献，取得了突出的工作业绩。他以保一方平安为己任，不畏艰难、锐意进取，遇到急难险重任务，总是勇挑重担、冲锋在前，先后侦破刑事案件200余起，抓获犯罪嫌疑人60余名，多次因公负伤，为维护辖区社会治安稳定作出了突出贡献。他牢记并努力实践全心全意为人民服务宗旨，立足本职，积极为群众办实事、做好事、解难事，以自身模范行动树立了新时期人民警察的良好形象，先后荣立个人三等功2次、获嘉奖2次。2017年2月10日下午，赵天昱同志在执行抓捕任务过程中，面对持刀犯罪嫌疑人，英勇无畏、不怕牺牲，在身中21刀、严重负伤的情况下，仍与犯罪嫌疑人殊死搏斗，终因伤势过重，不幸壮烈牺牲，年仅42岁。

蔡松松同志是中国共产党党员，生前任四川省泸县公安局交通警察大队驻石桥派出所民警，三级警司警衔。蔡松松同志从警以来，始终怀着对党和人民的无限忠诚，带着强烈的事业心和责任感，全力以赴投入各项工作，爱岗敬业、顽强拼搏，秉公执法、无私奉献，在平凡的岗位上创造了不平凡的业绩，曾荣立个人三等功1次，获嘉奖3次，多次受到上级机关表彰。在理塘县公安局工作期间，他不惧高原环境艰苦，长期坚持奋战在应急处突、维护社会稳定第一线，先后参与了“打黑除恶”、“缉枪治爆”等一系列重大专项行动，圆满完成抓捕任务30余次，为保一方平安作出了突出贡献。调任泸县公安局后，他主动要求到基层交警执法一线工作，严格公正文明执法，满腔热情地帮助群众排忧解难，赢得了群众的广泛好评。2017年1月24日中午，正在家中休息的蔡松松同志听到附近水库有人落水的呼救后，不顾个人安危，立即冲到现场，奋勇跳进冰冷刺骨的水中，全力托起2名落水儿童游向岸边。在群众的帮助下，2名落水儿童成功获救，蔡松松同志却因体力不支沉入水中，不幸壮烈牺牲，年仅31岁。

赵天昱、蔡松松同志的先进事迹真实感人，具有鲜明的时代特征，充分体现了“忠诚、为民、公正、廉洁”的人民警察核心价值观，是广大公安民警学习的榜样。为表彰先进、弘扬正气，人力资源社会保障部、公安部决定，追授赵天昱、蔡松松2名同志“全国公安系统一级英雄模范”荣誉称号。

全体公安民警要以赵天昱、蔡松松同志为榜样，坚定不移高举中国特色社会主义伟大旗帜，更加紧密地团结在以习近平同志为核心的党中央周围，认真贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神，坚定理想信念、矢志不渝奋斗，锐意开拓进取、勇于改革创新，脚踏实地工作、默默无闻奉献，更好地担负起党和人民赋予的职责使命，为维护社会大局稳定、促进社会公平正义、保障人民安居乐业，实现“两个一百年”奋斗目标和中华民族伟大复兴的中国梦作出新的更大贡献。

人力资源社会保障部

公安部
