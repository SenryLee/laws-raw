# 国家文物局办公室关于明中都皇故城东安门游园景观设计的意见

办保函〔2017〕930号

安徽省文物局：

你局《关于审批明中都皇故城东安门游园景观设计方案的请示》（皖文物保〔2017〕55号）收悉。经研究，我局意见如下：

一、暂不同意明中都皇故城东安门游园景观设计方案。

二、请你局指导地方人民政府，重新调整《凤阳县中心城区排水工程专业规划》，论证利用明中都皇故城内外金水河以及护城河的可能性，不得将明中都皇故城东安门至东华门遗址之间的区域作为泄洪通道。

三、应在开展充分考古工作的基础上，结合明中都皇故城展示阐释的整体安排，统筹考虑明中都皇故城东安门遗址至东华门遗址之间空间区域的合理利用问题。明中都皇故城的展示应以中轴线遗迹的考古和保护、内外金水河及护城河的考古和保护为主，待上述工作结束后，再行考虑其他项目。

四、请你局进一步加强指导，督促地方人民政府增强工作的主动性和计划性，分清轻重缓急，有序推进明中都皇故城考古、保护和考古遗址公园建设工作。现阶段应以重点做好中轴线遗迹、内外金水河及护城河遗迹的考古和保护展示为主，切实加强文物保护工程管理和舆论宣传引导，确保工程质量和文物安全。

国家文物局办公室

2017年8月8日
