# 农业部关于政协十二届全国委员会第五次会议第1876号（农业水利类178号）提案答复的函

## 关于政协十二届全国委员会第五次会议第1876号（农业水利类178号）提案答复的函

农办案〔2017〕29号

车黎明委员:

您提出的关于大力发展“第二农业”的提案收悉。经认真研究，答复如下。

拓展农业多功能，推进农村一二三产业融合发展，是农业结构性调整的重要内容，对推进农业供给侧结构性改革，促进农业增效、农民增收和农村增绿具有重要意义。对此，农业部高度重视，采取有力措施，积极推进有关工作。

一、关于加快推进秸秆综合利用

2016年，农业部会同财政部投入10亿元，按照“整县推进、多元利用、政府扶持、市场运作”的原则，开展秸秆综合利用试点，使试点县秸秆综合利用率平均提高5个百分点以上，秸秆处理技术模式初步构建，配套政策机制不断完善。为推动农业绿色发展，农业部启动了“东北地区秸秆处理行动”等五大行动，2017年拟安排中央财政资金6亿元，在东北地区60个玉米主产县开展整县推进秸秆综合利用试点。

在开展试点工作的同时，大力推进秸秆能源化利用，推广秸秆热解气化、秸秆生物气化、秸秆固化成型、秸秆炭化等燃料化利用技术，建成秸秆固化成型示范工程1147处，年产固化成型燃料490多万吨；秸秆炭化工程103处，年产秸秆炭16万多吨；秸秆沼气、热解气化工程共1200多处，向农户供气20余万户，节能减排效益明显。推进秸秆利用技术研发推广，推动东北组建“东北区域玉米秸秆综合利用协同创新联盟”，针对玉米秸秆深翻还田、免耕覆盖、低温快腐、秸秆饲料无害防腐、秸秆沼气发酵等关键技术开展联合攻关；遴选推介秸秆“五料化”利用19项技术；印发《区域农作物秸秆处理利用技术导则》（农生态（生）〔2017〕9号），指导各地科学谋划和布局秸秆综合利用产业发展；印发《农业部办公厅关于推介发布秸秆农用十大模式的通知》（农办科〔2017〕24号）。这些举措有效引导了农民科学开展秸秆综合利用，促进了秸秆适用技术模式进村、入户、到田。

二、关于大力发展休闲农业和乡村旅游

农业部立足推进农业供给侧结构性改革，不断加强统筹规划，强化政策创设，注重科学推动，突出发展特色，强化公共服务，推动休闲农业和乡村旅游成为经济发展新产业新业态。2016年，会同财政部等14部门印发《关于大力发展休闲农业的指导意见》（农加发〔2016〕3号），提出7项主要任务和4项扶持保障政策。2017年，召开首届全国休闲农业和乡村旅游大会，明确产业发展思想、发展定位、发展方向和发展路子。联合国家旅游局开展全国休闲农业和乡村旅游示范创建，组织开展中国重要农业文化遗产发掘、中国美丽休闲乡村等品牌建设。共创建休闲农业和乡村旅游示范县328个，推介中国美丽休闲乡村370个，分四批认定中国重要农业文化遗产91项。通过标准制定、运行监测、教育培训、宣传推介等，努力为休闲农业和乡村旅游发展营造良好环境。

三、关于“互联网+”边远山区农产品销售

2015年，农业部办公厅印发《关于组织开展农业电子商务“平台对接”专项行动的通知》，促进农产品、农业生产资料生产、经营单位与涉农电子商务企业对接，引导农产品、农业生产资料上线销售；2016年，农业部等九部门联合印发《贫困地区发展特色产业促进精准脱贫指导意见》，明确要大力发展电子商务，增强产业支撑保障能力。

农业部与阿里、京东、苏宁、网库、邮乐网等5家大型电商企业签署合作协议，计划在产销对接等方面开展全方位合作；组织全国大型农垦企业赴南京与苏宁进行对接，在苏宁、天猫等大型电商平台开设“中国农垦旗舰店”；指导22个扶贫任务重的省（区、市）编制省、县两级产业扶贫规划，指导各地利用“互联网+”等手段，积极推动贫困地区产业发展和贫困群众脱贫增收；遴选洛川苹果、赣南脐橙、定西马铃薯等产业扶贫范例，开展5期全国产业扶贫现场观摩活动，引导贫困地区抓住“互联网+”现代农业发展契机，大力推进农产品电子商务发展，让好产品卖出好价格。

下一步，农业部将继续加大力度，扎实推进各项工作。在秸秆综合利用方面，继续依托中央财政秸秆综合利用试点补助资金项目，以县为单元，采取以奖代补的方式，支持秸秆综合利用的重点领域和关键环节，带动区域秸秆处理能力的整体提升。力争到2020年，东北地区秸秆综合利用率达到80%以上，新增秸秆利用能力2700多万吨。在休闲农业与乡村旅游方面，牢固树立“创新、协调、绿色、开放、共享”的发展理念，推进实施休闲农业和乡村旅游提升工程，推动政策落实，加强品牌培育和示范创建，推进农业与文化、科技、生态、旅游的融合，推动休闲农业和乡村旅游持续快速发展。在“互联网+”现代农业方面，将进一步加强与阿里、京东等大型电商企业合作，推动农产品特别是贫困地区农产品上网销售。继续指导贫困地区落实好《贫困地区发展特色产业促进精准脱贫指导意见》和产业扶贫规划，举办好产业扶贫系列现场观摩活动，总结推广产业扶贫范例，进一步推动发挥“互联网+”技术在产业扶贫中的作用。

感谢您对农业农村经济的关注和建议。希望您今后继续关心我部工作。

农业部

2017年8月21日
