# 中共教育部党组关于舒立春、黄蓉生同志职务任免的通知

教党任〔2017〕110号

中共西南大学委员会：

经与中共重庆市委商得一致，2017年5月15日研究决定：

舒立春同志任中共西南大学委员会委员、常委、书记；免去黄蓉生同志的中共西南大学委员会书记、常委职务。

中共教育部党组

2017年6月1日
