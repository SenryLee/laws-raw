# 全国旅游星级饭店评定委员会公告2017年第1号——关于取消五星级旅游饭店资格的公告

## 全国旅游星级饭店评定委员会公告

2017年第1号

## 关于取消五星级旅游饭店资格的公告

2017年1月11日，经全国旅游星级饭店评定委员会研究决定，取消辽宁省营口港丰大酒店（标牌编号：2150015）、浙江西子宾馆（标牌编号：3350022）、广东省东莞柏宁酒店（标牌编号：4450036）、广东省广州翡翠皇冠假日酒店（标牌编号：4450114）、广东省东莞市长安莲花山庄（标牌编号：4450038 ）等5家饭店的五星级旅游饭店资格。

特此公告。

全国旅游星级饭店评定委员会

2017年1月11日
