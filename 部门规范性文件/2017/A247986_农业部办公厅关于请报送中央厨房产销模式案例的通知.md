# 农业部办公厅关于请报送中央厨房产销模式案例的通知

农办加〔2017〕2号

各省、自治区、直辖市及计划单列市农产品加工业主管部门，新疆生产建设兵团农业局：

为贯彻2017年中央一号文件提出的关于“实施主食加工业提升行动，大力推广‘生产基地+中央厨房+餐饮门店’‘生产基地+加工企业+商超销售’等产销模式”的要求，我部将总结推广一批中央厨房产销典型模式，深入开展主食加工业提升行动。请你省（区、市）报送中央厨房模式案例，有关事项通知如下。

一、案例内容

1.企业基本情况。包括企业基本情况、主要产品、营收效益、带动农民就业增收情况等。

2.产销模式主要特点和做法。重点围绕中央厨房，从全产业链、价值链的角度，介绍企业在基地建设、技术创新、物流配送、市场营销、品牌建设等方面的做法和成效。

3.下一步打算和政策建议。包括企业今后发展愿景、存在困难和政策建议。

二、有关要求

1.案例材料。请每省（区、市）报送3-5个特色鲜明、前景良好、示范性强的案例。案例主要从本省的全国主食加工业示范企业和重点加工企业中选择。每个案例材料2500字左右，条理清楚、文字精炼、数据翔实，同时附2-3张图片（不小于3M/张）。

2.上报时间。请各地于3月31日前，将案例材料电子版和联系人信息（姓名、单位、职务、办公电话、手机、电子邮箱、微信号）发农业部农产品加工局规划统计处邮箱ghtjc@agri.gov.cn，并注明“中央厨房产销模式案例材料”。

我部将根据各地材料报送情况，组织专家开展实地调研，进一步完善案例模式，采取多种方式宣传推介，积极争取政策支持，加强科技服务和市场对接，促进加工企业做强做大和农民就业增收。
