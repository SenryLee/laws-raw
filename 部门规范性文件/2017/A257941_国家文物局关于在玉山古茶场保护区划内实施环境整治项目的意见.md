# 国家文物局关于在玉山古茶场保护区划内实施环境整治项目的意见

文物保函〔2017〕1856号

浙江省文物局：

你局《关于要求在全国重点文物保护单位玉山古茶场保护区划内实施环境整治项目的请示》（浙文物发〔2017〕330号）收悉。经研究，我局意见如下：

一、原则同意所报全国重点文物保护单位玉山古茶场保护范围和建设控制地带内玉山古茶场环境整治项目和你局意见。

二、对该项目提出以下修改意见：

（一）应严格遵守《中华人民共和国文物保护法》、《玉山古茶场保护规划》以及浙江省人民政府关于玉山古茶场保护区划的相关管理规定，确保建筑高度、密度、体量、色彩等符合要求，严格控制工程量和工程范围，尽量减少对文物本体及其环境的影响。

（二）进一步修改、完善设计方案，道路、地面铺装改造在不影响使用功能的地段和部分新老场地衔接区域，应尽量保留原始乡村地面和自然植被场地；植被种植应尽量采用当地品种，注意地域景观和生态平衡。

（三）扩大庙前水塘依据不足，应进一步评估其必要性。

（四）进一步梳理、规范图文表达，确保逻辑合理、图文一致。

（五）进一步完善文物影响评估报告，深入论证拟建项目对文物本体和环境风貌的影响，做到客观、准确、科学。

三、请你局根据所提意见，指导相关单位对项目方案进行修改完善，根据《中华人民共和国文物保护法》第十七条、第十八条的规定分别报浙江省人民政府、城乡建设规划部门批准。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。施工中应加强监管，确保文物及历史环境安全。

专此函复。

国家文物局

2017年11月16日
