# 国家文物局关于在地坪风雨桥保护范围和建设控制地带内进行看护展示用房及环境综合整治工程的意见

## 关于在地坪风雨桥保护范围和建设控制地带内进行看护展示用房及环境综合整治工程的意见

办保函〔2017〕417号

贵州省文物局：

你局《关于在全国重点文物保护单位地坪风雨桥保护范围内实施看护展示用房及环境综合整治工程的请示》（黔文物呈〔2017〕9号）收悉。经研究，我局意见如下：

一、所报项目的必要性和设计依据不足，对文物景观影响较大，我局暂不同意在地坪风雨桥保护范围和建设控制地带内进行看护展示用房及环境综合整治工程。

二、所报方案应进行以下必要的修改和完善：

（一）从地坪风雨桥保护管理的实际需要出发，进一步明确看护展示用房及环境综合整治工程的必要性和可行性，准确核实项目选址、工程范围以及与文物保护区划的关系。补充贵州省人民政府关于地坪风雨桥保护范围和建设控制地带的管理规定、具体控制要求和工程设计依据。

（二）深化方案设计内容，明确拟建建筑的高度、体量，科学论证观景台、村民芦笙坪、禾晾展示区建设的必要性，重新调整设计思路，避免设计风格过度人工化和城市景观园林化。不同意将场地自然植被替换为人工草坪。

（三）应重新编制文物影响评估报告，根据方案内容准确、客观地论证拟建项目对文物本体和环境风貌的影响，并进行必要的视线分析，研提工程措施调整建议，增强文物影响评估报告的针对性和科学性。

（四）应根据设计内容进一步简化文本，增强逻辑性。风雨桥结构检测分析报告、风雨桥木材部分检测报告与所报方案设计内容无关，建议删除。

三、请你局组织有关单位根据上述意见，对所报方案进行修改、完善后，按程序另行报批。

四、请你局督促地方人民政府认真落实《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号），正确处理文物保护、旅游开发和居民生产生活的关系，切实保护地坪风雨桥及周边环境的真实性和完整性。

专此函。

国家文物局

2017年4月12日
