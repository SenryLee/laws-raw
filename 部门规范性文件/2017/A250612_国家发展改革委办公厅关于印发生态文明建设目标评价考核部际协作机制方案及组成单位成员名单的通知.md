# 国家发展改革委办公厅关于印发生态文明建设目标评价考核部际协作机制方案及组成单位成员名单的通知

发改办环资〔2017〕490号

中央组织部、工业和信息化部、公安部、财政部、国土资源部、环境保护部、住房城乡建设部、交通运输部、水利部、农业部、国家卫生计生委、质检总局、国家统计局、国家林业局、国管局、国家能源局、国家海洋局办公厅（办公室）：

根据《中共中央办公厅、国务院办公厅关于印发〈生态文明建设目标评价考核办法〉的通知》（厅字[2016]45号）中“建立生态文明建设目标评价考核部际协作机制”的要求，为做好生态文明建设目标评价考核工作，加强部门协调配合，我委会同有关部门制定了生态文明建设目标评价考核部际协作机制方案。现印送你们，请按照执行。

附件：1.生态文明建设目标评价考核部际协作机制方案

2.生态文明建设目标评价考核部际协作机制组成单位成员名单
