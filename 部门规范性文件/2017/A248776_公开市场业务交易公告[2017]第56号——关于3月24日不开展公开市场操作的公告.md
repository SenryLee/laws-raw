# 公开市场业务交易公告[2017]第56号——关于3月24日不开展公开市场操作的公告

## 公开市场业务交易公告

[2017]第56号

随着月末财政支出力度加大，目前银行体系流动性处于较高水平，3月24日不开展公开市场操作。

中国人民银行公开市场业务操作室

二〇一七年三月二十四日
