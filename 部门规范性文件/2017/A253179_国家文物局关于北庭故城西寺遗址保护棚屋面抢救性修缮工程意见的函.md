# 国家文物局关于北庭故城西寺遗址保护棚屋面抢救性修缮工程意见的函

## 关于北庭故城西寺遗址保护棚屋面抢救性修缮工程意见的函

文物保函〔2017〕1284号

新疆维吾尔自治区文物局：

你局《关于报审北庭故城遗址保护棚屋面抢救性保护修缮工程勘察设计方案的请示》（新文物字〔2017〕11号）收悉。经研究，我局意见如下：

一、原则同意对北庭故城西寺遗址保护棚进行抢救性修缮。

二、所报方案尚需做以下必要的修改和完善：

（一）应在现有方案三的基础上，进一步深化保护棚屋面抢修工程设计，充分考虑风荷载、雪荷载等附加荷载影响，确保建筑安全。同时，应充分考虑屋面电伴热融雪系统的运行稳定性及维护成本问题，进一步评估必要性，优化设计内容，避免产生后续不良影响。

（二）应考虑建筑墙体加做外墙保温层的可行性，进一步提升室内环境质量。

（三）建筑墙面排水系统修缮应注意避免大规模扰动建筑墙体。

三、请你局指导方案设计单位，根据上述意见对所报方案作进一步修改和完善，经你局核准后实施。施工中，请你局加强监管，确保工程质量和文物安全。

国家文物局

2017年7月24日
