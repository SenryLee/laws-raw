# 国家林业局关于切实做好东北虎豹、大熊猫、雪豹等珍稀濒危野生动物和森林资源保护工作的通知

林护发〔2017〕134号

吉林、黑龙江、四川、陕西、甘肃、青海省林业厅，龙江森工集团，国家林业局各司局、各有关直属单位：

健全国家自然资源资产管理体制试点和国家公园体制试点（以下简称“两项试点”）是党中央作出的重要决策部署，是推进生态文明体制改革的重要内容。为切实维护试点区内东北虎豹、大熊猫、雪豹等珍稀濒危野生动物和森林资源安全，确保两项试点顺利实施，现将有关要求通知如下：

一、进一步提高认识，切实加强组织领导

有效保护东北虎豹、大熊猫、雪豹等珍稀濒危野生动物种群，实现稳定繁衍生息，是开展东北虎豹、大熊猫、祁连山国家公园体制试点的重要要求，是改革试点成功的重要保证。各有关省林业主管部门要认真学习领会中央关于生态文明建设、自然资源资产管理体制改革、国家公园建设的新精神新要求，特别是习近平总书记系列重要讲话精神，提高政治站位，强化“四个意识”，坚持“生态保护第一”的国家公园理念，按照“谁管辖谁负责”的要求，切实负责好本区域东北虎豹、大熊猫、雪豹等珍稀濒危野生动物和森林资源保护工作。要加强组织领导，就此项工作进行专门研究部署，做到主要领导亲自抓，分管领导具体抓，层层落实责任，确保责任到人、措施到位、人员到岗。要对试点区珍稀濒危野生动物主要活动区域划定保护责任区，明确负责机构、负责领导和具体责任人，确保试点区内东北虎豹、大熊猫、雪豹等珍稀濒危野生动物安全。

二、迅速组织开展专项行动，严厉打击各种违法行为

各有关省林业主管部门要迅速行动，立即组织力量开展大规模的“清山清套”活动，做到横向到边，纵向到底，不留死角，不留空白，彻底清除园区内的猎套、猎夹、网具、陷阱等猎捕工具和设施。2018年3月底前，要组织开展1—2次打击乱捕滥猎珍稀濒危野生动物专项行动，对有关违法行为一律依法从严处理。要加强野生动物分布区的野外巡护和看守工作，加大监测预警力度，发现问题及时向有关部门报告，严防乱捕滥猎和损毁珍稀濒危野生动物栖息地等违法活动。要加强冬季野生动物补饲工作和救护工作，为野生动物安全越冬提供保障。

三、加大森林资源保护力度，坚决杜绝发生重特大森林火灾

森林资源是东北虎豹、大熊猫、雪豹等珍稀濒危野生动物栖息繁衍的基础。要加强森林资源保护巡查工作，强化重点时期、重点地段、重点人员的监管巡查，对人口聚居村落、火灾易发地、重点防范区域、进山道路等重点区域组织人员巡逻值守。要严格林政执法，严厉打击违法占用林地、毁林开垦、滥砍盗伐林木等违法犯罪行为，发现一起，处理一起。严格禁止在园区内新批采矿权、探矿权，已审批的采矿权、探矿权要限期退出。要加强园区秋冬季森林防火工作，严格火源管理，严控生产生活用火，及时制止随意用火行为。要开展园区隐患排查，加大火情监测工作力度，充分利用各种监测手段，全方位、全时段监测火情，确保火情早发现、早报告，有效消除森林火灾隐患。

四、增强协同配合，迅速形成工作合力

各级林业主管部门特别是资源管理、野生动物保护、森林公安等有关部门要围绕珍稀濒危野生动物和森林资源保护，建立协调配合、齐抓共管的联合机制和打防结合、标本兼治的长效机制，增强工作协同性，形成打击涉林违法犯罪行为的合力。国家林业局各相关派驻森林资源监督机构要切实发挥监督职能，重点加强试点区内森林资源管理监督工作，发现重大问题，及时严肃查办。针对可能出现的涉林违法热点问题和社会舆论关注的焦点问题，要加强分析预判，把握舆情引导主动权，防止负面炒作。

五、强化督促检查，确保各项要求落到实处

各有关省林业主管部门要加强对本辖区珍稀濒危野生动物和森林资源保护情况的督促检查，确保各项要求落实到位。安排部署情况请于2017年12月1日前报告我局。落实过程中重要进展情况请及时报告。我局将组织成立督查组，适时对各有关省工作开展情况进行督促检查，落实责任不到位的，将通报批评。

特此通知。

国家林业局
