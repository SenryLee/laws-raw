# 国家安全生产监督管理总局公告2017年第8号——批准延期的甲级资质安全评价机构及其业务范围、批准延期的甲级资质检测检验机构及其业务范围

## 国家安全生产监督管理总局公告

2017年第8号

依据《行政许可法》《安全生产法》等规定，按照《国家安全监管总局关于安全评价与安全生产检测检验机构甲级资质延期换证有关工作的通知》（安监总规划〔2016〕120号）要求，经组织审查合格，同意北京中交华安科技有限公司等3家单位甲级安全评价资质、湖南煤矿安全监察局安全技术中心甲级安全生产检测检验资质延期，有效期至2020年7月19日，现予公告。

附件：1.批准延期的甲级资质安全评价机构及其业务范围

2.批准延期的甲级资质检测检验机构及其业务范围

国家安全监管总局

2017年7月20日
