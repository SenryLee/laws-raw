# 中华人民共和国工业和信息化部公告2017年第42号——载客车辆（M1类）车型的国家标准《汽车禁用物质要求》符合性情况名单（第六批）

## 中华人民共和国工业和信息化部公告

2017年第42号

按照《汽车有害物质和可回收利用率管理要求》（工业和信息化部公告2015年第38号）规定，现将载客车辆（M1类）车型的国家标准《汽车禁用物质要求》符合性情况名单（第六批）予以公告。

附件：载客车辆（M1类）车型的国家标准《汽车禁用物质要求》符合性情况名单（第六批）

工业和信息化部

2017年10月16日
