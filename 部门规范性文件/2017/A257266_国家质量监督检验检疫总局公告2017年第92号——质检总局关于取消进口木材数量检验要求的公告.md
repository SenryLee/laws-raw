# 国家质量监督检验检疫总局公告2017年第92号——质检总局关于取消进口木材数量检验要求的公告

## 国家质量监督检验检疫总局公告

2017年第92号

## 质检总局关于取消进口木材数量检验要求的公告

为提高通关便利化水平，根据《中华人民共和国进出口商品检验法实施条例》的有关规定，质检总局决定取消进口木材产品（涉及产品见附件）的数量检验要求，检验检疫部门不再实施进口木材数量检验。

本公告自公布之日起施行。

附件：涉及产品的HS编码

质检总局

2017年10月30日
