# 国家铁路局关于发布铁道行业标准的公告（工程建设标准2017年第3批）

## 国家铁路局关于发布铁道行业标准的公告

（工程建设标准2017年第3批）

国铁科法〔2017〕11号

现公布《铁路信号设计规范》（TB 10007-2017）行业标准，自2017年5月1日起实施。《铁路信号设计规范》（TB 10007-2006）同时废止。

本标准由中国铁道出版社出版发行。

国家铁路局

2017年1月19日
