# 国家文物局办公室关于在木兰围场御制碑、摩崖石刻保护范围内进行文物保护利用服务设施项目的意见

办保函〔2017〕980号

河北省文物局：

你局《关于呈报木兰围场御制碑及摩崖石刻文物保护利用服务设施项目建设方案的请示》（冀文物字〔2017〕157号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位木兰围场御制碑、摩崖石刻保护范围内，设计依据不足，对文物环境影响较大，我局暂不同意所报项目。

二、该方案应进行以下必要的修改和完善：

（一）加强现状勘察，进一步明确文物本体残损状况和病害原因，科学研提保护设施设计方案，有效解决雨水风化侵蚀问题。

（二）不同意在入崖口有作碑等七处碑址新建月台、防护栏及台阶，应对已有石基座进行适当整修，并做好排水。

（三）文物保护范围内人行步道建议采用自然石材铺设，形式不宜过于规整，应与文物及周边景观风貌相协调。保护范围外道路不属我局审批范围。

（四）管理用房位于文物保护范围外，不属我局审批范围。

（五）应重新编制文物影响评估报告，根据方案内容准确、客观论证拟建项目对文物本体及环境风貌的影响，增强针对性。

三、请你局组织相关单位根据上述意见，对项目方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2017年8月21日
