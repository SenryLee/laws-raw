# 国家文物局关于万字会旧址建设控制地带青岛东方饭店装修改造工程设计方案的意见

## 关于万字会旧址建设控制地带青岛东方饭店装修改造工程设计方案的意见

办保函〔2017〕302号

山东省文物局：

你局《关于呈报青岛东方饭店装修改造工程设计方案的请示》（鲁文发〔2017〕7号）收悉。经研究，我局意见如下：

一、暂不同意所报设计方案。

二、对方案提出以下修改意见：

（一）补充万字会旧址建设控制地带的具体控制指标，说明东方饭店装修改造工程与相关文物保护要求的一致性。

（二）深化东方饭店对万字会旧址历史环境的影响评估，细化以万字会旧址为中心的相关视线分析，补充东方饭店与万字会旧址建筑之间关系的分析图。

（三）补充拆除二层塔楼结构改为坡屋面等的说明及相关图纸。

三、请你局指导有关单位，根据上述意见对方案进行完善后，另行报批。

国家文物局

2017年3月27日
