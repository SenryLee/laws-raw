# 国家烟草专卖局关于开展行政执法公示制度执法全过程记录制度重大执法决定法制审核制度试点工作的通知

国烟专〔2017〕111号

各省级局：

推行行政执法公示制度、执法全过程记录制度、重大执法决定法制审核制度（以下统称三项制度）是党的十八届四中全会部署的重要改革任务，对于促进烟草专卖行政执法公正文明、严格规范，保障和监督烟草专卖行政管理部门依法履行职责，维护人民群众合法权益，具有重要意义。根据国家局的安排部署，现就开展三项制度试点工作有关事项通知如下：

一、试点单位和任务

根据《国务院办公厅关于印发推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度试点工作方案的通知》（国办发〔2017〕14号）的要求，天津市、河北省、安徽省、甘肃省和内蒙古呼和浩特市等22个地方的所有烟草专卖行政管理部门被纳入试点范围。国家局决定适度扩大试点任务，相关省级局要抓紧推动开展试点工作（《试点地方及试点任务表》见附件）。未纳入试点的单位可根据实际情况，自觉推进相关制度改革。

二、试点内容

（一）行政执法公示制度。

1．加强事前公开。试点单位要按有关要求，公开烟草专卖许可证的办理流程和服务指南，设立门户网站和实体性服务窗口或场所，配备相应的办证服务设施，及时发布并更新相关办证信息，方便群众办理。要按照《国家烟草专卖局关于印发专卖监管随机抽查事项清单和工作细则的通知》（国烟专〔2016〕319号）要求，建立健全检查对象名录库和执法检查人员名录库，合理确定抽查比例和频次，公开随机抽查事项清单等信息。

2．规范事中公示。试点单位烟草专卖行政执法人员从事执法活动，要佩戴国务院烟草专卖行政主管部门制发的标志，出示省级以上烟草专卖行政主管部门签发的检查证件，出具先行登记保存通知书等执法文书，做好告知说明工作。办证服务窗口要明示工作人员岗位工作信息。

3．推动事后公开。试点单位要研究确定烟草专卖行政处罚决定公开的范围、内容、方式、时限和程序，建立完善公开信息的审核、纠错和监督机制。要及时制订随机抽查结果信息公开的规定，确定检查信息公开的要素，做到随机抽查结果及时向社会公布。

4．做好信息共享。试点单位要按照地方人民政府统一部署，对接当地行政执法信息公示的统一平台，及时提供行政执法有关信息，配合实现执法信息互联互通。

（二）执法全过程记录制度。

1．规范文字记录。试点单位要按照《国家烟草专卖局关于印发烟草专卖行政处罚文书（试行）的通知》（国烟法〔2015〕9号）要求，依托专卖管理信息化建设，推行执法文书的规范化、电子化，明确执法案卷管理办法，确保执法文书和案卷的完整准确和妥善保存。

2．推行音像记录。试点单位要研究明确需要记录的执法活动和执法场所，对现场检查、调查取证、证据保全、文书送达等容易引发争议的烟草专卖行政执法过程进行全过程音像记录。

3．强化记录实效。建立健全执法全过程记录信息收集、保存、管理、使用等工作制度，加强数据统计分析，充分发挥全过程记录信息在案卷评查、执法监督、评议考核、舆情应对等方面的作用。

（三）重大执法决定法制审核制度。

1．落实审核主体。试点单位烟草法规部门负责本单位的法制审核工作。要配备和充实政治素质高、业务能力强、具有法律专业背景并与法制审核工作任务相适应的法制审核人员，建立定期培训制度，提高法制审核人员的法律素养和业务能力。

2．确定审核范围和内容。要按照《国家烟草专卖局关于印发烟草专卖重大执法行为法制审核办法（试行）的通知》（国烟法〔2016〕2号）要求，结合行政执法行为的类别、涉案金额、对当事人和社会的影响等因素，确定重大执法决定的范围，探索建立重大执法决定目录清单制度。针对不同行政执法行为，要明确具体审核内容。

3．细化审核程序。要根据《国家烟草专卖局关于印发烟草专卖重大执法行为法制审核办法（试行）的通知》（国烟法〔2016〕2号）规定的工作流程、送审材料、工作时限，完善法制审核工作方式和处理机制，严格落实责任追究机制。

三、试点单位工作步骤

（一）部署阶段（2017年4月）。试点单位要按照当地人民政府统一部署，结合烟草专卖行政管理工作实际，细化试点内容，明确工作进度，强化保障措施，形成试点工作实施方案。

（二）实施阶段（2017年5月—11月）。试点单位要按照实施方案开展工作，在实施过程中加强跟踪调研，不断完善措施并定期上报工作开展情况和阶段性总结。各试点单位之间要加强沟通交流，相互促进，共同提升。

（三）总结阶段（2017年12月）。试点单位要在2017年底前完成相关工作，在总结试点经验的同时,将总结报告报当地人民政府和国家局。

四、组织保障

（一）加强组织领导。试点单位所在省级局要高度重视试点工作，落实机构、人员及信息系统、装备、经费等保障措施，指导研究制订试点实施方案并监督落实，加强对试点工作的指导，开展工作交流，及时解决试点工作中遇到的困难和问题。

（二）鼓励探索创新。开展试点工作要与法治烟草建设、烟草专卖信息化建设相结合，积极探索多种实现模式，不断创新烟草专卖行政管理体制机制，相对成熟的方面要规范完善，相对薄弱的环节要健全强化。

（三）做好总结评估。试点单位所在省级局要对试点情况进行跟踪评估，及时研究试点工作中发现的新情况新问题，定期交流、通报试点进展情况；试点工作结束后，研究提出全面推行的意见。
