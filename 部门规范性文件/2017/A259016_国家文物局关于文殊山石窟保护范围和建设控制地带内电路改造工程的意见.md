# 国家文物局关于文殊山石窟保护范围和建设控制地带内电路改造工程的意见

文物保函〔2017〕1999号

甘肃省文物局：

你局《关于呈报〈文殊山石窟电路改造方案〉和〈文殊山石窟保护范围内电路改造工程文物影响评估报告〉的报告》（甘文局发〔2017〕136号）收悉。经研究，我局意见如下：

一、原则同意文殊山石窟电路改造方案和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）施工前应做好缆沟沿线文物勘探工作，施工过程中如发现历史遗存应立即停工，并上报至文物主管部门。

（二）新增箱式变电站、配电箱等设施应注意适当遮挡，以免影响文物环境。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》第十七条、第十八条的有关规定分别报送甘肃省人民政府和城乡建设规划部门批准后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局

2017年12月18日
