# 人力资源社会保障部、中央网信办关于追授曲昌荣同志“全国网络安全和信息化工作先进工作者”荣誉称号的决定

## 人力资源社会保障部　中央网信办关于追授曲昌荣同志“全国网络安全和信息化工作先进工作者”荣誉称号的决定

人社部发〔2017〕9号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）、网信办：

党的十八大以来，全国网信战线在以习近平同志为核心的党中央坚强领导下，牢固树立政治意识、大局意识、核心意识、看齐意识，坚定不移走中国特色社会主义治网之道，坚决维护网络安全，大力推动信息化发展，加快推进网络强国建设，为深入推进“四个全面”战略布局作出了新贡献，涌现出一大批先锋模范人物，曲昌荣同志就是其中的优秀代表。

曲昌荣同志是中国共产党党员，生前任中央网信办移动网络管理局副局长。该同志从事网信工作以来，坚持奋战在网信工作第一线。他事不避难、敢抓敢管，坚决开展移动互联网专项生态整治，圆满完成多项重要网络宣传引导和应急响应值守任务；他善于思考，勇于创新，积极拓展各类移动新媒体渠道，着力构建移动互联网微传播体系；他淳朴率真、心系群众，热心为移动互联网企业排忧解难，始终保持共产党人的政治本色。他以模范行动践行了“忠诚、担当、创新、廉洁、团结、奉献”的网信精神，赢得了广大干部群众的由衷赞誉。2016年11月24日，曲昌荣同志在工作岗位上突发疾病，经全力抢救无效于12月16日不幸去世。

曲昌荣同志是新时期全国网信战线广大工作者的杰出代表，是加快推进网络强国建设进程中的先锋模范。为表彰先进、弘扬正气，人力资源社会保障部、中央网信办决定，追授曲昌荣同志“全国网络安全和信息化工作先进工作者”荣誉称号。

全国网信战线广大干部职工要以曲昌荣同志为榜样，全面贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神，深入学习贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，更加紧密地团结在以习近平同志为核心的党中央周围，锐意进取，开拓创新，顽强拼搏，矢志奋斗，为建设网络强国、实现中华民族伟大复兴的中国梦作出新的更大贡献！
