# 国家文物局关于在净土寺保护范围内进行保护利用设施建设项目意见的函

## 关于在净土寺保护范围内进行保护利用设施建设项目意见的函

办保函〔2017〕614号

山西省文物局：

你局《关于审批应县净土寺保护利用设施建设项目设计方案的请示》（晋文物〔2017〕112号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位净土寺保护范围内，对寺庙历史格局影响较大，设计依据不足，设计思路不正确，文本深度不够，我局暂不同意该项目。

二、对所报方案提出以下修改意见：

（一）应按照《净土寺文物保护规划》的原则和要求，从净土寺整体保护、展示和管理的需要出发，进一步论证保护利用设施建设工程的必要性和可行性，统筹考虑文物保护、展示和服务设施建设问题，合理确定工程内容。补充净土寺保护范围管理规定和具体控制要求。

（二）进一步调整、完善设计方案。

1．进一步论证、研究新建管理用房、接待中心、展厅、文物库房等管理服务设施项目内容及选址的合理性，严格控制新建建筑规模、高度和建筑风貌等，建议集中选址于寺庙西侧已拆迁区域，避免对净土寺原有格局和院落空间造成误解。

2．消防通道建议设置在寺院外围，院落内部以消防栓等措施为主，尽量减少对文物及环境的影响。

3．进一步明确院落铺装做法，补充设计依据。

4．科学研提已发掘遗址的保护措施。

5．不同意复建钟鼓楼。进一步研究论证山门复建的依据。

（三）进一步完善文本和图纸。补充拟建区域的考古勘探和发掘图、考古发掘报告。

三、请你局组织相关单位根据所提意见和我局《关于净土寺抢救性文物保护基础设施建设项目初步设计方案的意见》（办保函〔2015〕698号）要求，对项目方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局

2017年5月22日
