# 国家安全生产监督管理总局公告2017年第16号——2017年第三批安全生产失信联合惩戒“黑名单”单位及其人员名单

## 国家安全生产监督管理总局公告

2017年第16号

根据《国家安全监管总局关于印发<对安全生产领域失信行为开展联合惩戒的实施办法>的通知》（安监总办〔2017〕49号）的规定，经审核，将河北亿能烟塔工程有限公司等158家生产经营单位及其有关人员纳入安全生产失信联合惩戒“黑名单”管理，现予公告。

附件：2017年第三批安全生产失信联合惩戒“黑名单”单位及其人员名单

国家安全监管总局

2017年12月4日
