# 国家文物局关于在荆州城墙建设控制地带内进行荆州古城龙凤庄建设项目的意见

## 关于在荆州城墙建设控制地带内进行荆州古城龙凤庄建设项目的意见

办保函〔2017〕448号

湖北省文物局：

你局《关于报送荆州古城龙凤庄项目规划建筑设计方案的请示》（鄂文物〔2017〕12号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位荆州城墙一类建设控制地带内，建筑高度超高，对文物影响较大，我局暂不同意该项目。

二、对所报方案提出以下修改意见：

（一）应按照《荆州城墙文物保护总体规划》要求，进一步降低建筑高度，建筑檐高不得超过12米；同时，应减小建筑面宽，压缩建筑体量，避免大体量联排建筑对荆州城墙造成压迫感，建筑外观应与荆州城墙及周边环境景观风貌相协调。

（二）应在拟建区域内开展全面考古发掘工作，明确该区域地下文物的分布与保存状况，科学论证、评估重要遗迹现象的文物价值，并根据考古发掘成果重新调整设计方案。同时，应深入研究工程建设对地下文物的影响，合理确定建筑的布局和规模，研提必要的遗址保护措施和应急预案。补充考古发掘报告和地下文物分布图。

（三）应根据考古工作成果综合考虑已发现宋代道路遗址的保护展示措施，研提多种比选方案，科学确定道路遗址与两侧建筑的合理距离。

三、请你局组织相关单位根据所提意见，对项目方案进行修改完善后，按程序另行报批。涉及考古发掘工作，应按要求填报《考古发掘申请书》。

专此函。

国家文物局

2017年4月17日
