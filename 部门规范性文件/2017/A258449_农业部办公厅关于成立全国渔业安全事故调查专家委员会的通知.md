# 农业部办公厅关于成立全国渔业安全事故调查专家委员会的通知

农办渔〔2017〕81号

各省、自治区、直辖市渔业主管厅（局），新疆生产建设兵团水产局，部内有关单位：

为贯彻落实《中共中央 国务院关于推进安全生产领域改革发展的意见》精神，根据《渔业船舶水上安全事故报告和调查处理规定》（农业部令2012年第9号），经研究，决定成立全国渔业安全事故调查专家委员会（以下简称专家委员会），现将有关事项通知如下。

一、重要意义

渔业安全事故调查处理是渔业安全生产管理的重要内容，成立专家委员会是践行渔业安全发展理念的重要举措。专家委员会将成为我国渔业安全生产管理和涉渔事故调查的重要力量，为推动我国渔业安全事故调查走向专业化、组织化、科学化提供坚强的技术支撑。

二、主要职能

专家委员会在农业部渔业渔政管理局领导下，受渔业渔政管理局指派依法参与我部职责范围内的渔业安全事故调查工作，协助开展相关渔业安全制度修订、业务培训等工作。专家委员会委员由渔业渔政管理局在渔业安全事故调查专家库中指定。

三、相关要求

各级渔业行政主管部门应大力支持专家委员会工作，并为各专家委员会委员依法承担委员会工作任务创造必要条件。专家委员会委员应坚持依法、公平、公正的工作原则，以认真负责的态度和扎实的业务水平履职尽责，为渔业安全事故调查工作作出应有的贡献。
