# 国家文物局关于红山国家森林公园景观绿化提升工程建设项目涉及红山遗址群选址意见的函

## 关于红山国家森林公园景观绿化提升工程建设项目涉及红山遗址群选址意见的函

办保函〔2017〕768号

内蒙古自治区文物局：

你局《关于红山遗址群范围内实施景观绿化提升工程设计方案的请示》（内文物发〔2017〕89号）收悉。经研究，我局意见如下：

一、暂不同意红山国家森林公园景观绿化提升工程涉及红山遗址群建设控制地带的选址方案。

二、赤峰红山为全国重点文物保护单位红山遗址群所在地，也是中国世界遗产预备名录——红山文化遗址中的重要组成部分，应根据文物保护及世界文化遗产申报相关要求，统筹考虑红山国家森林公园建设和景观绿化提升工程。

三、所报方案尚需做以下必要的修改和完善：

（一）红山国家森林公园绿化、景观平台建设和服务设施建设工程涉及遗址保护范围的选址，以及道路及附属电信电力、给排水等基础设施建设工程涉及遗址保护范围的选址均应另行调整。不同意红山文化遗址保护馆建设工程和方案所提相关文物保护工程。

（二）红山遗址群保护范围内的绿化工程，应选取浅根系植物，并采取撒播种植方式；景观平台建设工程应以现有设施的原址原规模改造为主，不得大规模扩建，并尽量采用木栈道方式连接；服务设施建设工程应优化具体设计，严格控制建筑体量、规模和高度，外观设计应注意与遗址及其周边环境相协调。

（三）主入口建设项目选址，以及道路建设工程及附属电信电力、给排水等基础设施建设工程应避让遗址保护范围。保护范围内仅允许建设必要的木栈道和步行道路，选址应避开重要文物遗存，并严格控制规模，做好具体设计，相关材料亦应尽量符合景观及环保要求。

（四）涉及遗址建设控制地带的乡村民俗、红山文化小镇、红山文化展示中心等建设项目选址，应避让重要地下文物遗存，并严格控制新建建筑规模、体量和高度。

三、请你局指导相关单位，根据上述意见进一步修改和完善所报方案，经你局核准后按程序另行报批。

专此函复。

国家文物局

2017年6月20日
