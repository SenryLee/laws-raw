# 人力资源社会保障部办公厅关于2016年度出版专业技术人员资格考试合格标准有关问题的通知

人社厅发〔2017〕1号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局），大连市人力资源社会保障局：

根据2016年度出版专业技术人员资格考试数据统计分析，经商国家新闻出版广电总局,现将考试合格标准及有关问题通知如下:

一、出版专业技术人员初级、中级资格考试各科目合格标准均为120分（各科目试卷满分均为200分）。

二、请各地按上述合格标准对出版专业技术人员资格考试人员成绩进行复核，并与我部人事考试中心核对数据，确认无误后，按附件要求逐项填写，并于2017年1月25日前送我部人事考试中心，附件数据为发放资格证书的依据。

三、请按照有关文件精神，及时向社会公布考试合格标准，并抓紧做好资格证书发放及考试后期的各项工作。

附件：2016年度出版专业技术人员资格考试情况统计表

人力资源社会保障部办公厅

2017年1月3日
