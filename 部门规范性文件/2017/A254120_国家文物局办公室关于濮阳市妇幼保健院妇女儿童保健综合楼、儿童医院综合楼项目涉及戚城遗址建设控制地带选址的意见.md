# 国家文物局办公室关于濮阳市妇幼保健院妇女儿童保健综合楼、儿童医院综合楼项目涉及戚城遗址建设控制地带选址的意见

办保函〔2017〕931号

河南省文物局：

你局《关于濮阳市妇幼保健院妇女儿童保健综合楼、儿童医院综合楼项目涉及戚城遗址建设控制地带设计方案的请示》（豫文物〔2017〕169号）收悉。经研究，我局意见如下：

一、所报项目选址位置经考古勘探发现重要地下文物遗存，我局不同意濮阳市妇幼保健院妇女儿童保健综合楼、儿童医院综合楼建设项目涉及戚城遗址建设控制地带的选址及建设方案。请你局指导项目建设单位另行选址建设，确保文物安全。

二、请你局组织专业考古研究单位进一步加强戚城遗址已发现地下文物遗存的考古和研究，明确地下文物遗存的分布范围，并尽快报请河南省人民政府根据考古工作成果调整戚城遗址的保护范围，将近年来新发现地下文物遗存分布区域纳入戚城遗址保护范围。同时，请你局指导地方人民政府抓紧编制戚城遗址保护规划，合理划定保护区划，明确建设控制地带的具体控制指标，妥善处理文物保护与城市建设之间的关系。

国家文物局办公室

2017年8月7日
