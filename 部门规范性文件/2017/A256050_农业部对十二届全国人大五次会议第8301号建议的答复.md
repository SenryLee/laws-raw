# 农业部对十二届全国人大五次会议第8301号建议的答复

## 对十二届全国人大五次会议第8301号建议的答复

周公卒代表：

您提出的“关于支持天然橡胶产业发展，确保橡胶产品供应安全的建议”收悉。经商财政部、税务总局、保监会，现答复如下。

一、关于支持天然橡胶基地建设

天然橡胶是国家战略性资源，近年来，中央财政通过国家天然橡胶基地建设、农业综合开发等资金，积极支持优势植胶区发展天然橡胶产业，为促进改善基础设施条件、推动产业稳定发展发挥了重要作用。同时通过林业改革发展资金对海南、云南、广东3省种植橡胶林和抚育改造等工作给予支持，着力提高当地天然橡胶生产水平。“十三五”期间，按照《国家天然橡胶基地建设规划（2016—2020年）》，将在优势植胶区选择自然灾害少、环境条件优越、生产基础好的区域，作为我国天然橡胶生产核心区，推进国家天然橡胶基地建设，新建国家天然橡胶基地70万亩。下一步，中央财政将进一步完善政策措施，促进橡胶产业持续健康发展。

二、关于加大橡胶收储力度

近年来，为保障国家资源安全、维护胶农利益，国家已开展天然橡胶收储工作，截至2016年底，累计收储天然橡胶65万吨，相当于国内年产量的80%。从长远看，解决我国天然橡胶产业发展问题，还应着眼于调整种植结构，加大生产、加工环节关键技术研发和推广力度，着力延长产业链条，通过降低成本、提高附加值等方法提高效益。同时，我部将根据产业现实情况，积极协调有关部门，争取加大对天然橡胶的收储力度。

三、关于支持海胶集团开展橡胶商业收储

企业建立商业储备，符合国家储备制度改革方向，有利于企业应对市场风险，促进橡胶产业发展。按照《国务院关于进一步健全国家储备制度的若干意见》（国发〔2016〕57号），国家将推动形成中央储备与地方储备、政府储备与企业储备互为补充的新型储备体系。企业商业储备是企业根据生产经营周期性变化需要保有的库存，按照定位，其储备规模、品种结构等可由企业根据市场情况自行安排，政府部门不宜过度介入。

四、关于对海外种胶企业按照核定产量给予进口增值税与关税减免

我国天然橡胶产量难以满足需求，且受可耕种面积限制，增产能力有限，每年需大量进口。部分企业积极“走出去”，在海外种植天然橡胶，有助于提高我国橡胶资源供给能力。但在返销产品的关税、增值税方面，如对我“走出去”企业在境外种植的天然橡胶减免进口税，自“走出去”目的国进口的部分天然橡胶适用的关税、增值税将低于来自其他国家或来自同一国家其他企业的进口产品，这将违反世界贸易组织关于“最惠国待遇”的有关规定，容易引起贸易争端。同时，天然橡胶属农作物，产量受气候等诸多因素影响，核定“走出去”企业产量在操作上有一定难度。鉴此，不宜对海外种胶企业按照核定产量给予进口增值税与关税减免。

五、关于推动扩大橡胶树保险范围

天然橡胶保险属于中央财政补贴险种，按照《中央财政农业保险保险费补贴管理办法》的有关规定，农业保险经办机构在拟定农业保险条款时，应当充分听取各地人民政府财政、农业、林业部门和农户代表意见，补贴险种的保险责任应涵盖当地主要的自然灾害、重大病虫害和意外事故等。关于代表所提扩大橡胶树保险责任范围的建议，我们鼓励并支持各地结合当地面临的主要灾害和意外事故，以及保险标的生长特点，在公平合理的基础上，协调地方相关部门和经办保险机构，科学确定农业保险责任范围。

六、关于由省政府安排救灾资金保障橡胶职工灾后基本生活

按现行政策，我国自然灾害生活救助实行分级负责、属地管理为主的原则，地方各级财政、民政部门根据本地区经济发展水平和财力可能，确定对受灾群众的救助项目和补助标准，保障受灾群众的基本生活。中央政府对遭受国家四级以上响应标准特大自然灾害的省份提供必要的支持。海南省应按上述相关规定，切实承担受灾群众生活救助的主体责任，保障受灾群众的基本生活。

感谢您对天然橡胶发展事业的关心，希望今后继续支持我部工作。
