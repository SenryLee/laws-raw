# 国家文物局办公室关于南京城墙保护区划内鸣羊街传统文化展示街区项目——高岗里以南至明城墙段的意见

办保函〔2017〕1352号

江苏省文物局：

你局《关于审批南京市秦淮区鸣羊街传统文化展示街区项目——高岗里以南至明城墙段设计方案的请示》（苏文物保〔2017〕238号）收悉。经研究，我局意见如下：

一、该项目建筑密度过大，文物影响评估不足，我局暂不同意该项目。

二、具体修改意见如下：

（一）建议适当减少新建建筑N1、N2的建设密度，参照高岗里传统建筑样式进一步优化设计，确保新建建筑与文物及历史文化街区景观风貌相协调，补充城墙与该街区的景观视线分析。

（二）进一步深化该区域的相关历史遗存和历史环境研究，补充说明与文物本体的依存关系，针对南京城墙及历史文化街区的保护要求，在空间上对相关环境要素予以认定。

（三）补充方案图纸中景观设计的内容，进一步优化交通流线设计，减少对文物建筑的干扰。

（四）充分考虑建设施工对文物安全的影响，制定必要的文物保护措施和应急预案。

（五）进一步完善文物影响评估报告，应着重评估建设项目对文物本体及历史环境在空间环境方面的影响。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善后另行报批。

国家文物局办公室

2017年12月11日
