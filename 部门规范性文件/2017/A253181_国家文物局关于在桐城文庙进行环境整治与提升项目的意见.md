# 国家文物局关于在桐城文庙进行环境整治与提升项目的意见

## 关于在桐城文庙进行环境整治与提升项目的意见

办保函〔2017〕858号

安徽省文物局：

你局《关于审批桐城文庙广场及周边环境整治与提升工程方案的请示》（皖文物保〔2017〕48号）收悉。经研究，我局意见如下：

一、暂不同意桐城文庙广场及周边环境整治工程方案。

二、补充说明桐城文庙文物保护规划情况，进一步明确中博馆、翰墨街等文庙周边现状情况。

三、围绕儒学遗产价值展示与阐释，进一步优化方案设计。建议广场采用“海墁”铺装方式，广场雕塑应突出儒学主题并适当增加广场乔木。门楼和景观石之间不宜设置甬路连接。

四、完善文物影响评估，客观、准确、科学地论证拟建项目对文物本体和环境风貌的影响，增强文物影响评估报告的针对性。

五、请你局根据上述意见，组织相关单位对所报方案进行修改、完善后另行报批。

专此。

国家文物局

2017年7月20日
