# 国家文物局关于程氏三宅保护规划意见的函

文物保函〔2017〕1872号

安徽省文物局：

你局《关于批准程氏三宅保护规划的请示》（皖文物保〔2016〕153号）收悉。经研究，我局意见如下：

一、原则同意所报程氏三宅保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

1．加强历史研究，进一步明确文物原功能形态和价值特征。

2．文物周边商业开发建设和我局批复意见不符，应补充其建设、处理和整改情况等，并深入评估现有建筑对文物的影响，且不得在本规划予以认可，应在规划措施中明确整改要求。

（二）关于保护区划与管理规定

合理划定建筑控制地带，细化保护区划管理规定，建设控制地带内应严格控制新建活动并明确依法审批要求，现有建筑改造应以文物历史格局为依据。

（三）关于保护措施

应根据《文物保护工程管理办法》细化文物保护措施，明确工程的性质、类型，加强针对性。

（四） 关于环境整治和专项规划

1．进一步明确展示利用的目标和定位，细化展示利用规划内容，加强可操作性。

2．完善环境整治内容，补充对保护区划内现有建筑的整治措施。

（五）加强所报规划与相关规划的衔接内容。

（六）规范文本和图纸表达，加强图文对应性。规划图纸中的现状保护区划表达有误，文物周边开发建设项目在建设控制地带内，应据实修正。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的程氏三宅保护规划报请安徽省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体立项报告或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好程氏三宅的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年11月20日
