# 农业部对十二届全国人大五次会议第4458号建议的答复

## 对十二届全国人大五次会议第4458号建议的答复

农办议〔2017〕243号

辛喜玉等11名代表：

你们提出的关于对丹江口库区取缔网箱养殖后加快渔民转型发展予以扶持的建议收悉。今年5月，我部派出调查组前往丹江口市进行了专门调研，你们反映的情况和问题属实。对于你们提出的两方面建议，经商财政部、环境保护部，现答复如下。

一、关于解决取缔网箱养殖补偿缺口资金和渔民后期生产生活安置资金问题

2016年，中央财政下达有关省（区、市）水污染防治专项资金130亿元，重点支持水质较好湖泊生态环境保护、重点流域水污染防治、城市集中式饮用水源地保护、地下水污染防治等《水污染专项行动计划》确定的重点工作。该专项资金采取切块方式下达，由地方政府统筹使用,其中下达南水北调沿线省市水污染防治专项资金22.35亿元，湖北省为3.93亿元，用于丹江口水库保护治理。我部认为，从丹江口水库渔业持续健康发展和渔民生计、渔区稳定的角度出发，建议地方政府拆除养殖网箱和围栏不要“一刀切”，对于有利于净水的养殖滤食性鱼类的不投饵网箱和养殖草食性、滤食性不投饵围栏可继续保留。

二、关于把丹江口市取缔网箱养殖纳入国家“十三五”水污染防治规划，制定优惠政策和资金进行扶持问题

2015年，国务院印发《水污染防治行动计划》，明确要求推进生态健康养殖，在重点河湖及近岸海域划定限制养殖区，实施水产养殖池塘、近海网箱养殖标准化改造。环境保护部编制了《重点流域水污染防治“十三五”规划》，将丹江口库区及上游地区纳入规划范围，提出加快推进污染较重城市河流达标治理、面源污染防治，开展总氮控制试点，提升水质安全保障水平。该规划即将印发实施。下一步，我部将加强与有关部门的沟通联系，并要求湖北省农业部门做好对接，争取对丹江口渔业转型发展给予更大支持。

感谢你们对渔业发展的关心支持，希望今后继续关心我部工作。
