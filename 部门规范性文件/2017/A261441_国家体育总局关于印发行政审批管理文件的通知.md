# 国家体育总局关于印发行政审批管理文件的通知

体政字〔2017〕131号

各省、自治区、直辖市、计划单列市、新疆生产建设兵团体育局，有关直属单位：

为规范行政审批行为、改进行政审批工作，精简行政审批材料、优化行政审批流程，进一步提高体育工作效率和为人民群众服务水平，国家体育总局根据法律法规和国务院要求，对所负责的行政审批事项进行了梳理，修改完善了相应管理文件，现印发给你们。在工作过程中遇到问题，请及时与国家体育总局联系。

附件：审批管理文件（略）

国家体育总局

2017年11月21日
