# 农业部关于政协十二届全国委员会第五次会议第1731号（农林水利类152号）提案答复摘要

## 政协十二届全国委员会第五次会议第1731号（农林水利类152号）提案答复摘要

关于加强茶产业基础设施建设。农业部先后印发《全国茶叶重点区域发展规划》《特色农产品优势区域布局规划（2013—2020年）》《关于抓住机遇做强茶产业的意见》，引导资金、技术、人才等生产要素向优势区域集中，打造优势产业带；实施茶叶标准园创建、老茶园改造、种子工程、农业综合开发、有机肥替代化肥及农机购置补贴等一批项目和政策，推进茶园生产设施、栽培技术和质量管理标准化。下一步，进一步加大资金投入力度，调整优化农机购置补贴机具种类范围，并鼓励引导社会资本投资，改善基础设施条件，提升标准化生产水平。

关于享受退耕还林优惠政策。2001年，林业局印发了《退耕还林工程生态林与经济林认定标准》，明确将茶树列为生态经济兼用树种，享受退耕还生态林补助政策。在新一轮退耕还林还草中，鼓励各地根据不同地理、气候和立地条件，宜乔则乔、宜灌则灌、宜草则草，且不再限定还生态林与经济林的比例。各地可根据地方实际，将符合退耕还林政策规定、适宜种茶的区域纳入新一轮退耕还林实施范围。

关于大力发展茶叶深加工。2016年，国务院办公厅印发了《关于进一步促进农产品加工业发展的意见》，要求提升包括茶叶在内的农产品精深加工水平。工业和信息化部安排技术改造等专项资金，支持一批包括茶叶在内的农产品加工龙头企业，造提升产品质量安全保障能力。农业部先后建立2个茶叶重点实验室、10个茶叶加工技术研发中心及一批茶叶试验站，加强茶叶加工关键共性技术研发推广。组织摄制《中国茶》产业宣传片，倡导健康饮茶，引导茶叶消费。下一步，有关部门将支持开展储藏、保鲜、烘干等初加工设施装备的研发和更新，扶持技术改造和精深加工，推动加工水平提升。

关于支持茶产区综合开发。农业部联合国家发展改革委等14部门印发了《关于大力发展休闲农业的指导意见》，要求将休闲农业项目用地列入土地利用总体规划和年度计划优先安排，落实税收优惠政策，对有条件的地方发展休闲农业的用水用电享受农业收费标准。2016年，组织认定了74个休闲农业和乡村旅游示范县，推介了150个中国美丽休闲乡村、768条休闲农业和乡村旅游精品景点线路，其中产茶县20多个。发布《美丽乡村建设标准》等标准，举办管理和从业人员培训班，组织系列宣传推介等活动，为休闲农业和乡村旅游发展营造良好环境。下一步，将按照中央一号文件的要求，进一步加大扶持力度、加强指导服务，推进茶区农业产业结构调整，促进一二三产业融合发展，带动茶区经济社会全面发展。
