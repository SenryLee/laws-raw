# 国家卫生计生委办公厅关于同步启动全民健康生活方式第二阶段行动的通知

国卫办疾控函〔2017〕495号

各省、自治区、直辖市卫生计生委，新疆生产建设兵团卫生局：

4月28日，我委会同国家体育总局、中华全国总工会、共青团中央、全国妇联、北京市人民政府在京联合举办“三减三健?迈向健康”全民健康生活方式行动第二阶段启动仪式。为扩大宣传效果，在全国范围内掀起全民健康生活方式行动的新高潮，请各地在5月份同步启动全民健康生活方式第二阶段行动。现将有关事宜通知如下：

一、各地要认真贯彻落实我委等5部门联合印发的《全民健康生活方式行动方案（2017-2025年）》，结合本地工作特色和各地开展的健康中国行宣传活动，联合相关部门开展行动，通过开展形式多样的健康科普活动和竞赛，普及健康生活方式知识与技能，促进健康生活方式的养成，深入推进全民健康生活方式行动。

二、各省级卫生计生行政部门要联合体育、工会、共青团和妇联于5月内择期举办全民健康生活方式行动第二阶段启动仪式等宣传活动，可结合健步走、健骨操、烹饪比赛等活动形式，活跃现场，丰富内涵。

三、各地要坚持政府主导、部门协作、动员社会、全民参与的工作机制，根据本地居民营养与健康状况，结合本地工作基础，依托群团组织阵地优势，有侧重、有选择、有计划地开展三减三健、适量运动、控烟限酒和心理健康等专项行动。

各省级卫生计生行政部门要及时收集、汇总启动仪式相关文字、图像、视频资料，于6月20日前将总结报送我委疾控局。
