# 国家文物局关于吉成井盐作坊遗址保护规划的意见

## 关于吉成井盐作坊遗址保护规划的意见

办保函〔2016〕1386号

四川省文物局：

你局《关于上报〈吉成井盐作坊遗址保护规划〉的请示》（川文物〔2015〕115号）收悉。经研究，我局意见如下：

一、暂不同意吉成井盐作坊遗址保护规划。

二、所报规划应做以下必要的修改和完善：

（一）进一步梳理明确保护对象构成，区分文物建筑本体与附属建筑，补充对文物建筑及相关设施沿革的分析认定。

（二）加强遗址研究，在此基础上进一步深化价值评估。

（三）完善现状评估，补充细化评估依据，增强环境评估的针对性。补充完善考古研究现状评估，明确考古与研究工作现存主要问题。

（四）完善保护区划管理规定，制定对建设控制地带内建筑的控制要求。

（五）规范梳理保护工程类型和内容，提高保护措施的针对性，生产设施和工艺流程恢复内容应移至展示规划部分。

（六）完善专项规划内容，统筹考虑建、构筑物搬迁，明确搬迁范围、搬迁安置选址及保障措施。完善展示利用规划，生产设施和工艺流程的恢复以满足展示需要为主，避免过度展示；论证新建建筑的必要性，尽可能利用原有民居或厂房改造博物馆和游客服务中心，明确具体经济技术指标。补充完善考古和研究专项规划，提出考古和研究的工作重点和工作计划。

（七）补充与相关规划衔接的内容。

（八）合理调整规划分期，调减近期工作内容，增强可操作性。

（九）进一步梳理规划文本结构和内容，规范专业用语，深化、规范图纸表达。

三、请你局指导规划编制单位联合专业考古研究单位，根据上述意见对吉成井盐作坊遗址保护规划做进一步修改和完善后，按程序另行报批。

国家文物局
