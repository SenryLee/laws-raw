# 水利部办公厅关于确认和补充水利部政务信息资源目录的通知

办信息函〔2017〕1163号

部机关各司局、部直属各单位：

为贯彻落实《国务院办公厅关于印发政务信息系统整合共享实施方案的通知》（国办发〔2017〕39号）及国家发展改革委推进落实《政务信息系统整合共享实施方案》全国视频工作会议有关要求，按照《水利部政务信息系统整合共享工作方案》工作部署，根据全国政务信息共享交换平台统一要求，水利部作为国务院部门类政务信息资源提供单位，需提供水利部政务信息资源目录，为此部网络安全与信息化领导小组办公室（以下简称部网信办）组织有关单位初步编制了《水利部政务信息资源目录》（详见附件1），现发给你们请进行确认和补充完善。现将有关事项通知如下：

一、政务信息资源目录数据范围

根据《政务信息系统整合共享实施方案》和工作范围要求，依据水利部“三定”方案规定的部门或单位职责，重点结合目前各部门和单位编制的部门规章、公报（年报、月报）、年鉴、工作总结和相关数据库等主要内容，按照全国政务信息共享交换平台目录模板格式要求，针对《水利部政务信息资源目录》，对已列入的政务信息资源进行确认，对未列入的政务信息资源进行补充。

二、政务信息资源目录元数据完善

政务资源目录元数据的填写依据《政务信息资源目录编制指南（试行）》（发改高技〔2017〕1272号）执行，本次重点完善的数据项如下：

1．信息资源名称：指描述政务信息资源内容的标题，如：《水利部信息化建设与管理办法》《中国水资源公报》等。

2．信息资源提供方：指提供政务信息资源的政务部门名称，水利部机关各司局、直属各单位统一填水利部。

3．提供方内部部门：指水利部内设机关司局或直属行政事业单位名称，如：农村水利司、水利信息中心等。

4．信息资源格式：指保存政务信息资源存储数据的分类和类型，如：电子文件、电子表格、数据库、图形图像、流媒体、自描述格式；ｄｏｃ、Ｄｏｃｘ、Ｈｔｍｌ、ＯＦＤ、Ｐｄｆ、Ｐｐｔ、Ｔｘｔ、Ｗｐｓ、Ｘｍｌ、其他（详见附件2）。

5．共享属性：指政务信息资源的共享类型和共享条件，其中：共享类型分为无条件共享、有条件共享和不予共享三类。若共享类型为不予共享的，应注明相关的法律、行政法规或党中央、国务院政策依据；为有条件共享的，应标明使用要求和共享范围；为无条件共享的，可不填。

6．共享方式：指提供方和获取方共同采用的政务信息资源共享分类和共享类型，其中：共享分类为共享平台方式、邮件或介质。当共享分类选择共享平台方式时，共享类型又分为接口、数据库和文件。

7．开放属性：指政务信息资源是否向社会开放，以及对开放条件的描述。

8．更新周期：指政务信息资源更新的频度，分为实时、每日、每周、每旬、每月、每季度、每年等。

三、工作要求

各部门、各单位要高度重视政务信息资源目录的确认、补充和元数据完善工作，加强组织领导，确保工作顺利开展，并严格审核后，于2017年10月13日前将确认后的《水利部政务信息资源目录》报送部网信办，并同时按照政务信息资源共享方式，准备好相关政务信息资源，准备开展政务信息资源共享。
