# 国家民委关于命名吐鲁番市为“全国民族团结进步创建示范市”的决定

民委发〔2017〕149号

各省、自治区、直辖市及新疆生产建设兵团民（宗）委（厅、局），委机关各部门、直属各单位，吐鲁番市市委、市政府：

2014年启动示范市创建工作以来，在新疆维吾尔自治区党委、政府领导下，吐鲁番市紧紧围绕社会稳定和长治久安总目标，高举各民族大团结旗帜，以“民族团结一家亲”活动为抓手，高位推动、落实责任，文化引领、植根群众，推动民族团结进步创建细化量化；拓宽载体，多方联动，扎实开展“九进”带动创建广覆盖；强化宣传，夯实基础，持续铸牢中华民族共同体意识；推动发展，改善民生，不断夯实民族团结物质基础。通过深入推进民族团结进步创建，民族关系更加团结和睦，宗教领域更加和顺，社会局面更加和谐稳定，综合经济实力快速提升，民生建设成效更加显著。

吐鲁番市的生动实践，为新疆的社会稳定和长治久安作出了有益探索，为全国民族工作创造了宝贵经验。经考核验收，决定命名吐鲁番市为“全国民族团结进步创建示范市”。

民族团结是各族人民的生命线，民族团结进步创建只有起点没有终点。新时代创建要有新气象，更要有新作为。希望吐鲁番市在新疆维吾尔自治区党委、政府的领导下，以此为新的起点，不忘初心、牢记使命、接续奋进，开启新时代民族工作新征程，为民族团结进步事业再立新功。要深入学习贯彻党的十九大精神和习近平新时代民族工作思想，牢牢把握“中华民族一家亲，同心共筑中国梦”的目标，铸牢中华民族共同体意识，增强中华民族凝聚力向心力。要进一步巩固提升创建成果，深化新时代民族团结进步创建，提高创建工作覆盖面、参与率和影响力，切实发挥好示范市的作用。要深化民族团结进步教育，注重人文化、实体化、大众化，强化“五个认同”，建设各民族共有精神家园。要促进各民族交往交流交融，营造共居共学共事共乐的和谐环境，让各民族在中华民族大家庭中手足相亲、守望相助。要坚持发展为第一要务，不断增进民生福祉，坚决打赢脱贫攻坚战，与全国同步建成小康社会，让各族群众在创建中有更多获得感幸福感安全感。要提升民族事务治理能力和水平，加强党对民族工作的领导，完善基层民族工作网络和运行机制，提高民族工作社会化、法治化、智能化、专业化水平，坚决维护民族团结社会稳定大局，为实现决胜全面建成小康社会、夺取新时代中国特色社会主义伟大胜利作出新的更大贡献。

国家民委

2017年12月26日
