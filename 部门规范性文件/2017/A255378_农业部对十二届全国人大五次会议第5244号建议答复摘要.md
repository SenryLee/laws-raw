# 农业部对十二届全国人大五次会议第5244号建议答复摘要

## 十二届全国人大五次会议第5244号建议答复摘要

农办议〔2017〕231号

国务院和各级农机化主管部门高度重视农机维修工作，积极采取措施促进农机维修行业健康发展。《国务院关于促进农业机械化和农机工业又好又快发展的意见》明确要求，推进农机服务组织建设和社会化服务，培育农机作业、维修等市场，大力培养农机作业能手、维修能手。农业部发布的《全国农业机械化发展第十三个五年规划》也将发展农机维修服务作为重要内容。农业部积极推动开展农机维修“企社共建”活动，鼓励和引导重点农机企业与农机合作社、社会维修点合作。各级农机化主管部门积极争取农机维修扶持资金，支持维修网点更新购置维修设备、升级改造维修车间。一些省市积极开展“星级文明网点”等维修示范创建活动，树立了一批先进典型。注重培养农机维修专业人才，农业部连续举办了农机维修高技能人才和师资培训班，各地也借助财政资金和社会力量培养了大量维修网点工人和合作社机手。

下一步，我部将会同相关部门深入组织开展调研，研究论证农机售后服务网络建设和维修服务产业发展的扶持措施，并从以下几方面加大工作力度：一是根据国家“放管服”改革精神，研究取消农机维修技术合格证，进一步激发市场活力、便民利民，加强事中、事后监管，建立长效管理服务机制，不断推进和规范农机维修网点建设。二是推动成立行业协会分会，研究发布服务规范、公约，搭建维修企业与农机产销企业合作共赢的平台。三是加强修理人员技能培训，组织开展维修工轮训、技能大赛等活动，提高维修队伍能力和水平。四是鼓励各地积极争取政策和资金支持，在维修网点用地、维修设备更新、政府购买维修服务等方面给予扶持，提升区域农机维修服务保障能力。五是大力加强对《农业机械维修业开业条件》的宣贯，引导维修行业推行承诺服务制，进一步规范服务内容、提高服务质量，维护维修市场诚信经营环境。

农业部

2017年8月18日
