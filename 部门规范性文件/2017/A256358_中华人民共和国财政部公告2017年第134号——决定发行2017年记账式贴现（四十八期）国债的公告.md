# 中华人民共和国财政部公告2017年第134号——决定发行2017年记账式贴现（四十八期）国债的公告

## 中华人民共和国财政部公告

2017年第134号

根据国家国债发行的有关规定，财政部决定发行2017年记账式贴现（四十八期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

一、本期国债计划发行100亿元，实际发行面值金额100亿元。

二、本期国债期限182天，经招标确定的发行价格为98.328元，折合年收益率为3.41%，2017年10月16日开始计息，招标结束后至10月16日进行分销，10月18日起上市交易。

三、本期国债低于票面面值贴现发行，2018年4月16日（节假日顺延）按面值偿还。

其他事宜按《中华人民共和国财政部公告》（2017年第2号）规定执行。

特此公告。

中华人民共和国财政部

2017年10月13日
