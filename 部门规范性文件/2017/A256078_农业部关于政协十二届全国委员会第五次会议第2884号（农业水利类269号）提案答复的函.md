# 农业部关于政协十二届全国委员会第五次会议第2884号（农业水利类269号）提案答复的函

## 关于政协十二届全国委员会第五次会议第2884号（农业水利类269号）提案答复的函

马力委员：

您提出的关于扶植和壮大油菜产业促进农民增收的提案收悉。经商工业和信息化部、财政部，现答复如下。

一、关于以政府为主导搞好市场体系建设问题

党的十八届三中全会明确提出，要处理好政府和市场的关系，使市场在资源配置中起决定性作用，更好发挥政府作用。按照中央的要求，发展改革委、农业部等部门大力推进油菜籽市场体系建设。一是推动油菜籽收储市场化改革。2008年以来，国家在部分主产区实行油菜籽临时收储政策，对于促进油菜籽生产和保护农民利益起到了积极作用。但由于临时收储价格过高、不能反映市场需求、下游企业经营困难加剧、财政负担加重等问题，经国务院批准，2015年起由地方政府负责组织各类企业进行油菜籽收购，不再实行油菜籽国家临时收储，充分发挥市场配置资源的决定性作用。二是加强规划引导。2016年，发展改革委、农业部会同有关部门制定印发《全国大宗油料作物生产发展规划（2016－2020年）》（以下简称《规划》），其中一条基本原则就是“政策引导，市场调节”，要求在充分发挥市场机制作用的基础上，加强市场调控，保障合理收益，保持市场基本稳定，保护农民生产积极性。下一步，发展改革委、农业部等有关部门将结合落实《规划》，以及油菜籽生产保护区划定，加强基础设施和市场体系建设，不断提升综合生产能力和市场化水平。

二、关于协同发展促进产业链延伸问题

通过规划引导、政策支持、产业带动等途径，扶植和壮大油菜产业，确保食用植物油有效供给。一是优化产业布局。2016年，农业部印发《全国农产品加工业与农村一二三产业融合发展规划（2016－2020年）》，明确提出在长江流域和北方等油菜主产区，重点开展优质原料基地建设；在东北、华北、长江中下游、大宗粮油作物生产核心区形成初加工产业带，引导生产合作组织、创新联盟发挥更大作用，建立更加专业、便捷的粮油生产仓储、物流、金融、信贷平台与服务网络。二是推动产业融合。2016年，中央财政农业综合开发资金累计投入60多亿元，用于包括油菜在内的产业化发展项目建设。积极支持粮油类龙头企业采取订单农业，“企业+合作社+农户”“企业+农户”等模式，带动农户发展规模化生产。同时，引导和支持地方培育紧密型利益联结机制，支持农户和农民合作社参股入股龙头企业，完善价值链，让更多农户和农民合作社从产品加工、销售等环节中受益。下一步，财政部、农业部等有关部门，将针对农业产业链中的关键环节、薄弱环节进行重点扶持、连续扶持，努力实现全产业链开发，拓宽农民增收渠道。

三、关于提高产业技术含量促进产业创新问题

国家高度重视油菜产业科技创新，不断加大科技研发投入，提升油菜产业技术含量。一是设立国家重点研发计划。通过中央财政科技计划（专项、基金等），对符合条件的农业科研活动进行支持，启动实施了“化学肥料和农药减施增效综合技术研发”“粮食丰产增效科技创新专项”“现代食品加工及粮食收储运技术与装备”“智能农机装备专项”等国家重点研发计划专项，有效提升了包括油菜产业在内的农业科技支撑能力。二是建立现代农业产业技术体系。中央财政安排专项资金，围绕油菜产业发展，从研发到市场各个环节，主要开展了种质资源收集评价、育种与繁育、病虫害防控、栽培与土肥、农机装备、产业加工等共性技术和关键技术的研究集成，为农户开展技术示范和技术服务，探索科技支撑油菜产业发展、提升区域创新能力的新机制。下一步，农业部将会同有关部门，继续支持油菜产业科技创新，加强人才队伍建设，加强基础条件建设，加强行业科技攻关，为油菜产业发展提供有力保障。

四、关于以品牌为导向支持龙头企业推进精深加工问题

通过行业规划、政策引导等，发展精深加工，延伸产业链条，促进油菜产业健康发展。一是加强产业发展指导。2017年，发展改革委、工业和信息化部联合印发《关于促进食品工业健康发展的指导意见》，明确提出加强食品全产业链质量安全管理，支持包括油菜籽在内的骨干食品企业延伸产业链条，推进原料生产、加工物流、市场营销等环节融合发展。二是开展品牌创建。2016年，农业部启动农产品加工业质量品牌提升行动，引导粮油等农产品加工企业推行标准化生产，提高质量管理水平，加快培育一批国际知名企业、一批国内知名企业和一批区域知名企业，打造一批具有广泛影响力和持久生命力的知名品牌。三是加强质量检测。国家支持一批包括油菜籽深加工在内的粮油加工企业，开展质量检（监）测体系、追溯体系等方面的质量安全保障能力升级改造，提升行业质量安全保障水平。审核批准3批共14家“食品企业质量安全检测技术示范中心”，为包括粮油加工在内的食品生产企业特别是中小食品生产企业提供委托检测、应急检测、技术培训、检测示范等服务。下一步，农业部将会同有关部门，继续支持农产品品牌建设，优化产业布局，延伸产业链条，提升加工能力，增强油菜产业竞争力。

感谢您对“三农”工作的关心，希望今后继续对农业部工作给予支持。

农业部

2017年9月1日
