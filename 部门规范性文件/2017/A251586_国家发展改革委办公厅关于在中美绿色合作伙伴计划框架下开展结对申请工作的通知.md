# 国家发展改革委办公厅关于在中美绿色合作伙伴计划框架下开展结对申请工作的通知

发改办国际〔2017〕670号

环境保护部办公厅、林业局办公室、能源局综合司，各省、自治区、直辖市及计划单列市、副省级省会城市、新疆生产建设兵团发展改革委，各相关企业：

为进一步推动中美能源和环境十年合作机制下中美绿色合作伙伴计划实施，我委与美国国务院决定开展新一轮绿色合作伙伴的筛选和结对工作，现就有关情况和中方候选伙伴的申报事宜通知如下：

一、2008年6月第四次中美战略经济对话期间，两国政府签署了《中美能源和环境十年合作框架文件》（以下简称“十年合作”）。中美双方在十年合作机制下开展能源环境领域的务实合作，共同应对环境可持续发展、气候变化和能源安全方面的挑战。十年合作在中方由国家发展改革委牵头，在美方由国务院牵头，双方有关部门和机构参与。目前，十年合作框架下有六个优先合作领域，分别是：清洁的大气、清洁的水、绿色港口与船舶、保护区和湿地生态系统保护、清洁、高效和有保障的电力生产和传输、能效，分别由环保部国际司、林业局国际司、能源局电力司及我委环资司牵头推进。

二、2008年12月第五次中美战略经济对话期间，两国政府又签署了十年合作框架下《绿色合作伙伴计划框架》。绿色合作伙伴计划是中美之间开展具体务实合作的一个平台，通过促成两国有关地方政府、企业和研究机构之间自愿结对，共同努力探索绿色发展的创新模式。截至目前，中美有关城市、机构和企业之间已建立40多对绿色合作伙伴结对，在清洁能源发电、电动汽车、环境治理、湿地保护、资源综合利用、节能增效、低碳发展等诸多领域开展了交流合作并取得良好成效，得到中美两国领导人和有关部门的肯定。

三、请希望加入绿色合作伙伴计划的中方单位根据实际情况填写申请表格（见附件），通过所在地政府部门提交申请表纸质版（中文），并加盖申请单位公章。同时，须访问“中美能源和环境十年合作框架”网站（http://tyf.ndrc.gov.cn）下载申请书电子版（中英文），将填写完整的申请书电子版（中英文版）于5月31日前发至ecopartner@163.com和solicitation@lbl.gov两个邮箱。未能在截至日期前将中英文版发送至上述两个邮箱的申请将被视为无效申请。

四、中美将各自邀请两国有关机构提交申请，之后双方牵头单位会同有关部门按既有程序对结对申请进行评审和筛选。入选的合作伙伴将签署合作意向书。

五、我委国合中心（外经办）负责绿色合作伙伴计划的具体解释与执行工作。
