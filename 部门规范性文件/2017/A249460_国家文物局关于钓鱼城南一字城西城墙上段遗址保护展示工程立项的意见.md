# 国家文物局关于钓鱼城南一字城西城墙上段遗址保护展示工程立项的意见

## 关于钓鱼城南一字城西城墙上段遗址保护展示工程立项的意见

办保函〔2017〕324号

重庆市文物局：

你局《关于钓鱼城南一字城西城墙上段遗址保护展示工程立项请示》（渝文物〔2017〕25号）收悉。经研究，我局意见如下：

一、暂不同意钓鱼城南一字城西城墙上段遗址保护展示工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步加强现状勘察，细化城墙遗址稳定性和安全性评估，明确本体保护加固的工程范围和工程量。

（二）应进一步论证历史地貌恢复的必要性，并评估拟采取工程措施的科学性和合理性，应充分考虑场地高程及后续排水等相关因素，确保遗址安全。

（三）应做好相关保护工程的统筹衔接，补充以往城墙保护加固工程情况及工程效果评估，明确本次立项报告中防滑坡处理工程与已开展的山体滑坡治理工程的关系，避免重复工作。

（四）不同意建设跨越城墙遗址的展示通道设施。相关展示附属设施不宜采用过度挑高的跨越方式和玻璃材料，应注意结合地形地貌，减小设施体量，弱化形式和材质对遗址及其环境的影响。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年3月27日
