# 国家测绘地理信息局办公室关于印发《智慧城市时空大数据与云平台建设技术大纲》（2017版）的通知

## 关于印发《智慧城市时空大数据与云平台建设技术大纲》（2017版）的通知

测办发〔2017〕29号

各省、自治区、直辖市测绘地理信息行政主管部门：

为进一步做好智慧城市时空大数据与云平台建设，按照《新型智慧城市建设部际协调工作组2016－2018年工作分工》有关要求，国家测绘地理信息局组织对《智慧城市时空信息云平台建设技术大纲》（2015版）进行了修改完善，形成《智慧城市时空大数据与云平台建设技术大纲》（2017版）（以下简称2017版《技术大纲》），现印发给你们，请遵照执行，并做好以下工作。

一、组织相关管理人员、技术人员对2017版《技术大纲》进行学习研究，充分把握测绘地理信息在智慧城市建设中的定位与任务，掌握时空大数据与云平台建设的主要内容、建设思路、技术路线及建设要求等。

二、将2017版《技术大纲》转发至已开展及拟开展智慧城市时空大数据与云平台建设的城市，指导其进行学习研讨，并结合城市特点进行项目设计和实施。

三、执行2017版《技术大纲》过程中的问题与建议，请与中国测绘科学研究院联系。
