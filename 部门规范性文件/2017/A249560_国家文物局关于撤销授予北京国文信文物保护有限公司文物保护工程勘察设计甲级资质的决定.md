# 国家文物局关于撤销授予北京国文信文物保护有限公司文物保护工程勘察设计甲级资质的决定

## 关于撤销授予北京国文信文物保护有限公司文物保护工程勘察设计甲级资质的决定

文物保函〔2017〕713号

北京市文物局：

在近期的国家审计过程中，我局发现2013年9月30日第14次局务会议关于授予中国文物信息咨询中心所属北京国文信文物保护有限公司文物保护工程勘察设计甲级资质的决定，存在申报程序不规范、对申报条件把关不严、违规授予资质问题。根据《中华人民共和国行政许可法》第六十九条第一款第四项的规定，经局务会研究决定，撤销文物保函〔2014〕63号文件授予北京国文信文物保护有限公司文物保护工程勘察设计甲级资质的决定。

专此。

国家文物局

2017年4月10日
