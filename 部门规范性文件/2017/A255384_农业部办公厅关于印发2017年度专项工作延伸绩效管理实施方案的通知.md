# 农业部办公厅关于印发2017年度专项工作延伸绩效管理实施方案的通知

农办办〔2017〕34号

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）、农机、畜牧、兽医、农垦、渔业厅（局、委、办），新疆生产建设兵团农业局、畜牧兽医局，部属有关单位：

为切实抓好党中央、国务院有关农业农村经济工作重大决策部署的贯彻落实，推动各项“三农”政策落地生根、开花结果，根据《农业部绩效管理办法》《农业部关于深入推进绩效管理工作的意见》《农业部专项工作延伸绩效管理实施办法（试行）》有关要求，2017年度农业部继续就落实强农惠农富农政策等10项专项工作开展延伸绩效管理。现将实施方案（详见附件1—10）印发你们，请各地各有关农业部门和单位采取有效措施，切实抓好落实。

2017年度专项工作延伸绩效管理主要有以下新变化：一是增加项目。增设“推进农业信息化发展”“促进农业对外合作”“强化水生生物资源养护”3项延伸绩效管理。二是调整优秀比例。考虑项目增加、基数扩大，为体现“优中选优”的原则，适当调整优秀比例：对全国范围实施的项目，优秀单位名额比例原则上按1/4掌握，部分地区试点的原则上按1/3掌握。三是强化结果运用。延伸绩效管理的评估结果将在年中有关会议上进行通报，并函告相关省、自治区、直辖市、计划单列市人民政府。同时，每个项目从近2年连续参与试点的单位中，各选出1—2个与上年相比总分增加、名次提升、或者工作进步明显的单位，与优秀单位一并通报表扬、一并发函通报相关人民政府。

农业部将进一步加大督促检查力度，重点结合中央大督查、行业系统督查、专项督查等督查行动要求，强化对各地各农业部门和单位延伸绩效管理的督促检查，把延伸绩效管理确定的各项目标任务完成情况纳入督查范围，把督查情况作为绩效评估的重要参考，逐步形成督查工作与绩效管理协调联动的良好机制，更加有力地推动中央有关“三农”重大决策部署的贯彻落实，为农业农村经济发展不断做出新的更大贡献。
