# 中共教育部党组关于朱鸣雄、刘永章同志任职的通知

教党任〔2017〕58号

中共上海财经大学委员会：

经与中共上海市委商得一致，2017年4月1日研究决定：

朱鸣雄同志任中共上海财经大学委员会常委、副书记；免去刘永章同志的中共上海财经大学委员会副书记、常委职务。

中共教育部党组

2017年4月13日
