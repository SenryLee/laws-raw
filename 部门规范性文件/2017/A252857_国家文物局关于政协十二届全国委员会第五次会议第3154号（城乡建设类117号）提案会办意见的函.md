# 国家文物局关于政协十二届全国委员会第五次会议第3154号（城乡建设类117号）提案会办意见的函

## 关于政协十二届全国委员会第五次会议第3154号（城乡建设类117号）提案会办意见的函

办保函〔2017〕549号

住房城乡建设部办公厅：

卢天锡委员提出的《关于进一步加强传统民居保护的提案》（第3154号）已交由你部会同我局和财政部等部门办理。现将我局会办意见函告如下：

一、传统村落中传统民居保护基本情况

传统村落中的优秀传统民居是我国文化遗产的重要组成部分，蕴藏着极其丰富的文化内涵。保护传统民居对于传承文化遗产、弘扬优秀传统文化、建设环境友好型社会、推进农业和农村的现代化都具有重要意义。党的十八大以来，传统村落的保护得到高度重视，国家文物局、住建部等七部局先后公布了四批中国传统村落4157个。2014年，我局在中国传统村落范围内选取了270个全国重点文物保护单位和省级文物保护单位集中成片传统村落，开展整体保护利用工作。三年来，我局加强顶层设计和基础性工作，印发《国保和省保单位集中成片传统村落整体保护利用工作实施方案》，制定《中国传统村落乡土建筑保护利用导则》；举办专题培训班；指导编制并审批了传统村落文物保护总体方案；争取中央财政传统村落文物保护经费13.2亿元；将浙江省松阳县列为我局传统村落整体保护利用试验区；支持相关社会组织开展传统村落中的“拯救老屋”行动，对松阳县域内的传统民居进行保护修缮。截至2016年12月底，首批51个传统村落保护利用工程项目已基本完成，第二批100个传统村落整体保护利用项目正在推进实施，2017年将启动第三批119个村落保护利用工程项目。通过近几年开展的传统村落保护工作，使传统村落中的传统民居保存状况有了较大改善，对于促进传统民居的保护工作发挥了重要作用。

二、下一步工作计划

（一）重视传统村落保护法规制度建设。结合目前正在开展的《中华人民共和国文物保护法》修订工作，积极争取将传统村落中优秀传统民居保护有关内容纳入其中；并可考虑为传统村落保护单独制定规章制度。同时积极引导各地结合实际，研究制定本区域的传统村落保护办法及政策。

（二）加强历史研究，突出地方特色。结合村落的调查成果，系统研究、厘清村落历史发展脉络，充分发掘传统民居的历史文化内涵，全面、客观认识传统民居历史文化价值和独特个性。突出传统村落整体保护，既保护村落中的传统民居，也保护村落的环境风貌。传统民居修缮尽量采用传统工艺和做法，尽可能多地保持民居原有特色。对于大部分延续居住功能的传统民居以外貌保护为主，对内部进行适当改造，满足日常生活需要。

（三）强化技术指导，抓出示范案例。我局将通过召开保护利用现场会、组织专家工地检查、不同省份交叉检查等形式，加大对传统村落文物保护工程督促进度，加强工程技术指导。通过推进国保和省保单位集中成片传统村落整体保护和松阳县传统村落试验区工作，引导地方政府做好村落业态发展，力争在民生改善、环境整治、产业培育等方面结果实、出经验，成为文物保护利用的典型，探索解决“空心村”和过度商业开发的症结问题。

（四）引导社会力量参与传统村落中传统民居保护利用。各级地方政府及文物行政部门将创新管理，拓宽渠道，鼓励引导社会力量参与传统民居保护利用。充分发挥文物保护社会组织和志愿者团队的作用，利用公益性基金等平台筹措保护资金，依托“互联网+”等新手段丰富文物展示利用内容。推广政府和社会资本合作（PPP）模式。社会资本参与集体产权的传统民居保护利用，在保证不破坏文物和不改变所有权的前提下，可签订文物保护管理责任书，允许出资方享有一定的使用权。

专此函复。

国家文物局

2017年5月12日
