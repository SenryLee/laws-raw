# 环境保护部公告2017年第13号——关于建设项目环境影响评价资质审查结果（2017年第五批）的公告

## 环境保护部公告

2017年第13号

## 关于建设项目环境影响评价资质审查结果（2017年第五批）的公告

根据《建设项目环境影响评价资质管理办法》（环境保护部令第36号）及相关文件的规定，我部对申请建设项目环境影响评价资质（以下简称资质）的相关机构进行了审查。现将审查结果（2017年第五批）公告如下：

一、批准大连万锦环境工程有限公司等8家机构乙级资质。

二、批准北京神州瑞霖环保科技股份有限公司等5家机构资质证书中的机构名称变更。

三、批准吉林省环科环保技术有限公司等8家机构调整评价范围。

四、批准中国天辰工程有限公司等6家机构资质延续。

五、批准沈阳绿恒环境咨询有限公司等11家机构资质证书中的住所变更或法定代表人变更。

六、不予批准河南金环环境影响评价有限公司调整评价范围。

七、经重新核定，中国人民解放军后勤工程学院环境保护科学研究所资质等级由甲级降为乙级，大连机工机械环保研究所予以注销资质。

审查结果的具体情况详见附件。第一至五项和第七项中降级的机构请于60日内携带单位证明，到我部行政审批大厅领取资质证书，其中第二至五项和第七项中降级的机构应在领取资质证书时携带原资质证书正、副本原件。自本公告发布之日起，第二至五项和第七项中的机构原资质证书正、副本原件同时作废。

上述机构不服本公告决定的，可在接到本公告之日起60日内向我部申请行政复议，也可在接到本公告之日起6个月内依法提起行政诉讼。在未获延续的评价范围内、注销资质前和按原资质等级已承接的环境影响报告书（表）需继续完成的，应在本公告发布之日起15日内，将有关情况连同编制委托合同等证明材料报我部审核。
