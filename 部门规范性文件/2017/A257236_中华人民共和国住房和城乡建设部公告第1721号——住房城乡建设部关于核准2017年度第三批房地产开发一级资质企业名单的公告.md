# 中华人民共和国住房和城乡建设部公告第1721号——住房城乡建设部关于核准2017年度第三批房地产开发一级资质企业名单的公告

## 中华人民共和国住房和城乡建设部公告

第1721号

## 住房城乡建设部关于核准2017年度第三批房地产开发一级资质企业名单的公告

根据行政许可法、《城市房地产开发经营管理条例》和《房地产开发企业资质管理规定》，我部对2017年第三批申请晋升和延续房地产开发一级资质企业进行了审查。现将核准的华瀚投资集团有限公司等103家房地产开发一级资质企业名单予以公布。

特此公告。

附件：核准的房地产开发一级资质企业名单

住房城乡建设部

2017年11月2日
