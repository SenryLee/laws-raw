# 农业部关于政协十二届全国委员会第五次会议第0270号（资源环境类020号）提案答复摘要

## 政协十二届全国委员会第五次会议第0270号（资源环境类020号）提案答复摘要

一、关于加强畜禽养殖废弃物处理

近年来，我部会同相关部门积极推进畜禽粪污资源化利用工作。推动出台了《关于加快推进畜禽养殖废弃物资源化利用的意见》，这是建国以来首个聚焦畜禽养殖环境问题的指导性文件。在投资体制方面，支持采取政府和社会资本合作（PPP）模式，调动社会资本积极性，鼓励建立受益者付费机制，培育壮大多种类型的粪污处理社会化服务组织。在项目监管和资金管理方面，推动落实规模养殖场主体责任制度，严格执行环境保护相关法律法规和规定；加强财税政策支持，鼓励地方政府对畜禽养殖废弃物资源化利用装备实行敞开补贴，落实沼气发电上网标杆电价和上网电量全额保障性收购政策。在源头减排和废弃物资源化利用方面，启动实施畜禽粪污资源化利用行动，坚持源头减量、过程控制、末端利用的治理路径，以畜牧大县和规模养殖场为重点，以沼气和生物天然气为主要处理方向，以农用有机肥和农村能源为主要利用方向，实行以地定畜，促进种养结合、农牧循环。下一步，我部将会同有关部门不断加强畜禽养殖废弃物处理和资源化利用工作，强化政策支持，加强过程监管，全面推进畜禽养殖废弃物资源化利用，加快构建种养结合、农牧循环的可持续发展新格局。

二、关于加强农村生活污水治理

近年来，环境保护部、住房城乡建设部等部门积极推进农村生活污染治理工作。环境保护部通过实施“以奖促治”政策，开展农村环境综合整治。截至2016年底，安排中央财政资金375亿元支持10.8万个行政村开展环境综合整治，建成了一大批农村生活污水、垃圾处理设施，有效促进了农村环境问题治理。2016年住房城乡建设部在全国100个县开展农村生活污水治理示范工作，推广“统一规划、统一建设、统一运行、统一管理”的城乡统筹治理模式。下一步，环境保护部、水利部等相关部门将不断加大农村生活污水处理支持力度，提高农村生活污染治理水平。

三、关于大力推进生态循环农业建设

近年来，我部持续开展生态循环农业建设，探索形成了“猪-沼-果”、稻鱼共生、林果间作等一大批典型生态循环农业模式。2014年以来，农业部与浙江、安徽、海南签订合作备忘录，启动整省推进生态循环农业建设，在技术模式、管理机制、产业化带动等方面加大探索力度；在全国建设了13个现代生态农业示范基地，总结适合不同区域发展的现代生态农业建设模式和标准。实施化肥农药使用量零增长行动，扩大测土配方施肥范围，推进秸秆还田、种植绿肥、增施有机肥；启动果菜茶有机肥替代化肥行动，建设100个示范县。加大绿色防控力度，推进农作物病虫害专业化统防统治，扶持专业化服务组织，集成推广全程农药减量控害模式。推进生态健康水产养殖，创建农业部水产健康养殖示范场6218家；在辽宁、江苏等11个省（区、市）开展水产养殖用药减量行动试点行动，实施绿色生态养殖技术、病害综合防控技术、养殖全过程质量监控技术等措施。推进“三品一标”发展。截至2016年底，全国“三品一标”总数超过10万个。下一步，我部将不断加大化肥农药科学使用力度，推进畜禽养殖废弃物资源化利用，大力发展生态循环农业和“三品一标”，促进农业绿色发展。

四、关于实施河道全面治理

2016年11月，中共中央办公厅、国务院办公厅联合印发了《关于全面推行河长制的意见》，推动构建责任明确、协调有序、监管严格、保护有力的河湖管理保护机制，为维护河湖健康生命、实现河湖功能永续利用提供制度保障。2016年12月，水利部等十部门联合召开视频会议，并印发了《贯彻落实〈关于全面推行河长制的意见〉实施方案》，全面推进河长制工作，同时成立部际联席会议及水利部推进河长制工作领导小组，强化督导检查。
