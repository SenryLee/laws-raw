# 农业部关于印发《粮改饲工作实施方案》的通知

农牧发〔2017〕8号

各有关省、自治区畜牧（农牧、农业）厅（委、局），黑龙江省农垦总局：

为贯彻今年中央1号文件精神，全面落实《政府工作报告》粮改饲试点任务目标，经商财政部，农业部制定了《粮改饲工作实施方案》。现印发你们，请结合本地实际，切实抓好落实。

农业部

2017年5月23日
