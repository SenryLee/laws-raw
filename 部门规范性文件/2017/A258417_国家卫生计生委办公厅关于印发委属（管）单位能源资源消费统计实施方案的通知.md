# 国家卫生计生委办公厅关于印发委属（管）单位能源资源消费统计实施方案的通知

国卫办规划函〔2017〕1113号

委属（管）单位：

为深入贯彻落实《公共机构节能条例》，进一步加强我委属（管）单位统计工作，根据国家机关事务管理局《关于印发<公共机构能源资源消费统计制度>的通知》（国管节能〔2017〕316号）要求，我委修订了《国家卫生计生委属（管）单位能源资源消费统计实施方案》。现印发你们，请遵照执行。

国家卫生计生委办公厅

2017年11月14日

附：国家卫生计生委属（管）单位能源资源消费统计实施方案
