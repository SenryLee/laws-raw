# 国土资源部办公厅关于做好2017年度全国石油天然气储量登记统计工作的通知

中国石油天然气集团公司、中国石油化工集团公司、中国海洋石油总公司、中联煤层气有限责任公司，陕西延长石油（集团）有限责任公司等地方石油公司，部信息中心、部油气储量评审办公室：

根据《矿产资源登记统计管理办法》（国土资源部令第23号）、《国土资源部办公厅关于做好石油天然气探明可采储量动态管理的通知》（国土资厅发〔2011〕3号）以及《国土资源部办公厅关于启用油气矿产储量管理信息系统的通知》（国土资厅函〔2017〕1832号）有关规定，现将2017年度全国石油天然气储量登记统计有关事项通知如下：

一、请各油公司于2018年1月10日前将本公司快报统计数据报送国土资源部，具体统计内容见附件1，附件2。

2018年3月1日前将本公司及所属分公司填报的登记统计数据软盘及储量变化情况分析报告等报国土资源部 (电子邮箱：zjliu@infomail.mlr.gov.cn。)。

二、统计时以自然年度为统计单元，以每年12月31日为统计截止日。今年数据录入、汇总、分析和上报登记统计数据须使用国土资源部新版油气矿产储量管理信息系统；对已使用原系统填报的数据, 各油公司可通过油气矿产储量管理信息系统的数据导入功能将其导入。

三、部信息中心及部油气储量评审办公室做好技术支撑工作，在2018年2月底前完成全国油气储量登记统计数据更新工作。
