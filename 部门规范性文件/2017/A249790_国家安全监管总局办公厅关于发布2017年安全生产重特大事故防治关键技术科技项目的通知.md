# 国家安全监管总局办公厅关于发布2017年安全生产重特大事故防治关键技术科技项目的通知

厅函〔2017〕170号

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局，各省级煤矿安全监察局，各有关单位：

为贯彻落实《中共中央 国务院关于推进安全生产领域改革发展的意见》，充分调动社会力量参与安全生产科技攻关，进一步提升防范和遏制重特大事故的科技支撑保障能力，根据《国家安全监管总局关于推动安全生产科技创新的若干意见》（安监总科技〔2016〕100号）和《安全生产科技项目管理规定》（安监总厅科技〔2014〕76号），国家安全监管总局组织开展了2017年安全生产重特大事故防治关键技术科技项目征集工作。现将《2017年安全生产重特大事故防治关键技术科技项目目录》（见附件）予以发布，并将有关要求通知如下：

一、请各推荐单位与项目牵头单位签订《安全生产科技项目任务书》，明确研究目标、研究任务、考核指标等内容，督促各项目单位落实资金，抓紧开展攻关研究。

二、请各项目牵头单位按照项目任务书规定，积极开展科技攻关工作，确保按时完成研究任务，同时关注项目成果转化应用，推动科技成果市场化。

三、请各推荐单位按科技项目管理相关规定组织做好项目验收工作，并及时将项目验收成果及绩效评定情况上传至“安全生产科技项目征集管理系统”（网址：http://www.safetytech.org.cn/cms/）。

附件：2017年安全生产重特大事故防治关键技术科技项目目录

国家安全监管总局办公厅

2017年4月10日
