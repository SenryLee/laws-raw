# 国家知识产权局办公室关于印发2017年度国家知识产权局专利战略推进工程项目立项的通知

## 关于印发2017年度国家知识产权局专利战略推进工程项目立项的通知

国知办函办字〔2017〕633号

根据《国家知识产权局专利战略推进工程管理办法》的有关规定，2017年国家知识产权局专利战略推进工程立项工作已经结束，现将立项项目名单印发，请认真做好项目的组织实施工作。现将有关事项通知如下：

一、请各项目承担单位填写《国家知识产权局专利推进工程合同书》，一式4份，均需原件，其中的项目编号、项目名称、承担单位等必须与立项项目名单中的内容一致。承担单位负责人签字并加盖公章后，报送归口管理部门。归口管理部门作为保证单位，对合同书进行审核无误后加盖公章。合同电子件同步发送至wuwei_6@sipo.gov.cn邮箱。

二、2017年国家知识产权局专利战略推进工程项目的研究期限为2017年8月至2018年8月，请保障好研究的进度和质量。

特此通知。

附件：1.2017年国家知识产权局专利战略推进工程立项项目名单

2.国家知识产权局专利战略推进工程合同书

国家知识产权局办公室

2017年9月1日
