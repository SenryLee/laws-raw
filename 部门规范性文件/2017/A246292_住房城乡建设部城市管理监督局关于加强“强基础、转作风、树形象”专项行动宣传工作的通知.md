# 住房城乡建设部城市管理监督局关于加强“强基础、转作风、树形象”专项行动宣传工作的通知

建督政函[2017]1号

各省、自治区住房城乡建设厅，直辖市城市管理主管部门及有关部门，新疆生产建设兵团建设局：

为进一步贯彻落实《中共中央国务院关于深入推进城市执法体制改革改进城市管理工作的指导意见》（中发[2015]37号），各地城市管理部门按照《住房城乡建设部关于印发全国城市管理执法队伍“强基础、转作风、树形象”专项行动方案的通知》（建督[2016]244号）要求，以开展“强基础、转作风、树形象”专项行动为主线，不断加强队伍建设，提升城市管理和服务水平，取得了初步成效。为扩大专项行动效果，形成上下联动、多方参与的格局，现就进一步加强宣传工作通知如下：

一、全面开展宣传工作。加强与新闻媒体的联动协作，利用中国建设报等媒体，以“人民城管为人民”为主题，开展系列主题宣传活动，宣传城市管理工作的意义和成效。各地要主动利用官方网站、官方微信、官方微博等平台，持续发布专项行动信息，营造浓厚氛围。中国建设报及“大城管”微信公众号（微信号：jsb-zgcg）将设立专项行动专栏，请各地积极参与。

二、征集发布专项行动宣传口号。我局委托中国建设报及“大城管”微信公众号面向社会公开征集城市管理工作宣传口号，激发公众参与城市管理的热情。各地要选择一批主题鲜明、符合地方特色、群众喜闻乐见的口号，在主要公共场所设立宣传牌，发布公益广告。各城市可设立若干重点宣传牌，如“强基础、转作风、树形象，全国城管在行动”、“为人民管理城市”、“服务为先、管理优化、执法规范，城管在您身边”等。为形成全国统一的宣传效果，也可由“住房城乡建设部城市管理监督局”和“某某市城市管理局”联合署名发布。

三、面向市民广泛深入宣传。各地要通过设立公众开放日（体验日）、开展主题体验活动，组织城管进社区、进校园等方式，每季度至少开展一次互动宣传，赢得广大群众的理解和支持。要依托社区，发展壮大城市管理志愿服务队伍，主动邀请媒体对志愿服务活动进行宣传报道，鼓励引导志愿服务。要通过聘请市民监督员，开展群众评议等活动，主动接受社会和公众监督，形成多元共治的城市管理工作格局。

四、开展城管主题文化活动。通过组织演讲比赛、技能大赛、文体演出等主题文化活动，提高城市管理执法队伍的凝聚力和战斗力。

五、发挥好数字化城市管理平台的作用。通过城市管理官方网站、手机APP、12319热线电话等宣传平台，畅通与群众沟通交流的渠道，及时发现、解决城市管理中的问题，回应社会关切。

六、总结和宣传先进典型。各地要发掘专项行动中涌现的先进事迹和典型经验，及时总结推广好经验、好做法，加强宣传报道，发挥典型示范作用。

各地城市管理部门要充分认识宣传工作的重要作用，本着节约高效的原则，积极利用各种宣传资源和力量，对专项行动进行全方位、多角度宣传动员，凝聚各方力量，推动专项行动取得实效，更好地为人民管理城市。

中华人民共和国住房和城乡建设部城市管理监督局

2017年1月3日
