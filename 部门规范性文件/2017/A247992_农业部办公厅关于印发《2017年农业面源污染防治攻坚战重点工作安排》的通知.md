# 农业部办公厅关于印发《2017年农业面源污染防治攻坚战重点工作安排》的通知

农办科〔2017〕8号

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）、农机、畜牧、兽医、农垦、农产品加工、渔业厅（局、委、办），新疆生产建设兵团农业局，部属有关单位：

2017年，要深入贯彻中央关于生态文明建设的重大决策部署，落实中央1号文件要求，按照“重点突破、综合治理、循环利用、绿色发展”的要求，紧紧围绕“一控两减三基本”目标，进一步强化试点示范、监测考核、政策创设，坚决打好农业面源污染防治攻坚战。

农业部办公厅

2017年2月28日
