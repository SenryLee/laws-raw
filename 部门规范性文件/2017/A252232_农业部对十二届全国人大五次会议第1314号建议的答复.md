# 农业部对十二届全国人大五次会议第1314号建议的答复

## 对十二届全国人大五次会议第1314号建议的答复

农办议〔2017〕24号

钟雪玲等13名代表：

你们提出的关于在优质黄栀子中心产区设立国家级科研平台的建议收悉。现答复如下。

黄栀子是水土保持的优良树种，对荒山荒坡的绿化改造和固土保湿非常有利。黄栀子从花朵到果实皆可利用，可食用、可入药、可炼油，具有极高的经济价值，其果实是全国中药材市场紧俏产品，市场前景广阔。发展黄栀子产业，既符合国家产业发展政策，又有利于促进农民增收致富，具有十分重要的意义。

福建福鼎市地处闽浙交界地带，具有悠久的黄栀子栽培种植历史。长期以来，福鼎市委市政府高度重视黄栀子生产，将其作为山区农民脱贫致富的拳头产品加以扶持，并举办了黄栀子专题摄影展和黄栀子旅游文化节等活动，使黄栀子产业得到迅速发展。福鼎市已成为全国最大的黄栀子种植基地和集散地之一，黄栀子已经成为当地农民增收致富的的重要产业，具有广阔的发展前景。

今年以来，为贯彻落实中央一号文件精神，加快培育农业农村发展新动能，农业部、财政部积极推动现代农业产业园建设工作，现已正式批准创建了11个国家现代农业产业园。在创建现代农业产业园的基本条件方面，要求做到发展功能定位明确、规划布局科学合理、建设水平区域领先、绿色发展成效突出、带动农民作用显著、政策支持措施有力、组织管理健全完善等。在创建现代农业产业园的重点任务方面，要求做大做强主导产业，促进生产要素集聚，推进产加销、贸工农一体化发展，推进适度规模经营，提升农业质量效益和竞争力。下一步，建议福鼎市有关部门，做好基础工作，为明年申请创建国家现代农业产业园做好准备，按程序开展申报创建工作，在符合条件并通过竞争性选拔的情况下我部将予以重点考虑。

同时，我部还在积极谋划建立一批现代农业产业科技创新中心。现代农业产业科技创新中心，是集聚科技、人才、资本等要素、开放共享的创新创业平台。我部推进这项工作的总体考虑是建一个成一个，成熟一个、认定一个，要求有4个基本标准：一是科技创新能力强，主要依托的科研院校创新实力要强，要能广泛吸引国内外优势农业科技力量进驻；二是科技型企业强，要能培育吸引创新型龙头企业进驻，进一步强化企业科技实力和竞争力；三是地区辐射能力强，要能促进产业集群发展，形成区域农业经济增长极；四是地方党委政府高度重视，政策支持和投入力度要大，要能广泛带动社会力量参与。福鼎市黄栀子产业已经具备一定产业基础，但是总体建设条件还有待提升。下一步，建议进一步强化与优势科技力量的合作，提升企业科技创新能力，在达到基本申报要求后可按程序申报。

感谢你们对农业和农业科技工作的关心，希望继续对我部工作予以支持。
