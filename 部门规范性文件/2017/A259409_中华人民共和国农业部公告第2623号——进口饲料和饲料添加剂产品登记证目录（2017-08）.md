# 中华人民共和国农业部公告第2623号——进口饲料和饲料添加剂产品登记证目录（2017-08）

## 中华人民共和国农业部公告

第2623号

根据《进口饲料和饲料添加剂登记管理办法》有关规定，批准马其顿共和国Bitola市酵母和酒精酿造厂等49家公司生产的89种饲料和饲料添加剂产品在我国登记或续展登记，并发给进口登记证（见附件1）。批准晶好肽(SMQF)等3个产品申请企业名称、生产厂家名称和生产地址名称变更（见附件2）。所登记产品的监督检验，按中华人民共和国国家标准或农业部发布的质量标准执行。

特此公告。

附件1.进口饲料和饲料添加剂产品登记证目录（2017-08）

2.换发进口饲料和饲料添加剂产品登记证目录（2017-06）
