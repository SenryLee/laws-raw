# 农业部办公厅关于成立农业部畜禽养殖废弃物处理和资源化领导小组的通知

农办牧(2017)2号

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）、畜牧局（厅、委、办），新疆生产建设兵团农业局、畜牧兽医局，部有关司局和直属单位：

为深入贯彻落实习近平总书记在中央财经领导小组第十四次会议上的重要讲话精神，着力解决好畜禽养殖废弃物处理和资源化问题，我部决定成立农业部畜禽养殖废弃物处理和资源化领导小组（以下简称领导小组）。领导小组的主要职责是统筹协调畜禽养殖废弃物处理和资源化工作，研究解决重大问题，加强政策顶层设计，协调推进重点工作，组织开展监督检查等。

领导小组由组长、副组长、成员单位组成。组长由于康震副部长担任，副组长由畜牧业司主要负责同志担任，成员由部办公厅、经管司（站）、市场司、计划司、财务司、科教司、种植业司、畜牧业司、兽医局、监管局和生态总站、畜牧总站等有关司局和直属单位的负责同志组成。领导小组下设办公室，办公室主任由畜牧业司负责同志兼任，办公室成员由领导小组成员单位有关处室负责同志组成，办公室设在畜牧业司，具体承担日常工作。
