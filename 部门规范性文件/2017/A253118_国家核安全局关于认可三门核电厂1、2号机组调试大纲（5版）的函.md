# 国家核安全局关于认可三门核电厂1、2号机组调试大纲（5版）的函

## 关于认可三门核电厂1、2号机组调试大纲（5版）的函

国核安函〔2017〕68号

三门核电有限公司：

你公司《关于恳请批复〈三门核电一期工程1&2号机组调试大纲〉（5版）的请示》（三门核核安发〔2017〕240号）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的有关规定，我局对你公司提交的申请文件进行了审评，认为你公司三门核电厂1、2号机组调试大纲（5版）是可以接受的，现予认可。

你公司在三门核电厂1、2号机组的调试过程中应严格执行该大纲，保证大纲实施的有效性，确保调试的安全和质量。调试过程中如发生重大异常，应及时向我局和环境保护部华东核与辐射安全监督站报告。

国家核安全局

2017年7月18日
