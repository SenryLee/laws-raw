# 教育部办公厅关于公布实施专科教育高等学校备案名单的函

教发厅函〔2017〕53号

有关省、自治区、直辖市人民政府办公厅：

根据《高等教育法》《普通高等学校设置暂行条例》等有关法律法规的规定，现将省级人民政府审批新设、更名、变更办学体制、撤销的专科层次高等学校备案名单予以公布。

专此函告。

附件：省级人民政府审批设置实施专科教育高等学校备案名单

教育部办公厅

2017年5月10日
