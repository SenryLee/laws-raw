# 国家文物局关于郭沫若故居水电路改造工程方案的意见

文物保函〔2017〕1747号

北京市文物局：

你局《关于郭沫若故居水电路改造工程的请示》（京文物〔2017〕1231号）收悉。经研究，我局意见如下：

一、原则同意郭沫若故居水电路改造工程方案。

二、所报方案应补充完善如下内容：

（一）补充说明实施水电路改造的必要性。

（二）补充郭沫若故居的现状勘察、现状照片及现状图纸，特别是涉及水电路改造的建筑部位及地面的原状勘察，包括民国初年故居建筑始建后，直至郭沫若居住时的卫生洁具保存状况。如有发现，应在方案中落实保护措施。

（三）水电路改造的管线布局和走向，应避开有保护价值的建筑部位。补充说明施工过程中的文物保护要求和措施。

请你局指导相关单位根据上述意见对方案进行修改完善后予以实施。工程施工期间，你局应加强监管，确保文物安全。

国家文物局

2017年10月12日
