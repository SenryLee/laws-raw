# 国家新闻出版广播电影电视总局办公厅关于做好农家书屋配备党的十九大文件及学习辅导读物有关工作的通知

## 关于做好农家书屋配备党的十九大文件及学习辅导读物有关工作的通知

新广出办发〔2017〕67号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局：

为全面、深入学习宣传贯彻党的十九大精神，巩固农村思想文化阵地，为决胜全面小康社会实现中国梦奠定坚实群众基础，根据总局党组部署，现将农家书屋配齐配好党的十九大文件及学习辅导读物有关事项通知如下：

1.确保党的十九大文件及学习辅导读物配备到位。党的十九大文件及学习辅导读物将分别由人民出版社和学习出版社、党建读物出版社出版发行。其中，人民出版社将出版《党的十九大报告》（单行本）、《中国共产党党章》、《文件汇编》、《辅导读本》，这些出版物是准确传达、生动阐释、深入学习党的十九大精神的权威材料。各地要确保农家书屋配齐配好上述4种出版物，坚决执行，不打折扣，务必年底前完成补充配送工作。

2.组织开展好党的十九大精神学习宣传各项活动。各地要结合当地党委统一工作部署，依托农家书屋，深入开展党的十九大精神学习宣传、交流辅导等专题活动。学习宣传交流活动要紧密结合农村文化建设实际、紧密结合农民群众所思所想、紧密结合“深入生活·扎根人民”、“我的书屋·我的梦”等农家书屋主题活动，努力做到深入浅出、入脑入心。学习宣传交流活动要精心组织、扩大覆盖，形式多样、确保实效，使农家书屋成为农民群众学习宣传贯彻党的十九大精神的重要平台。

3.加强组织领导。各地要牢固树立“四个意识”、强化责任担当，充分认识在广大农村学习宣传贯彻党的十九大精神的重大意义，将农家书屋配齐配好党的十九大文件及学习辅导读物工作作为当前首要政治任务列上重要议事日程，尽早制定方案，提前启动谋划，落实农家书屋出版物补充更新资金，协调出版、印刷、发行单位做好相关工作，确保该项政治任务圆满完成。

各地工作开展情况应于12月15日前上报总局印刷发行司。总局将派出督查组进行督导检查，对党的十九大文件及学习辅导读物配备不到位的地方，将通报批评、严肃处理。
