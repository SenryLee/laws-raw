# 国家文物局关于“中美合作所”集中营旧址展示工程立项的意见

## 关于“中美合作所”集中营旧址展示工程立项的意见

办保函〔2017〕306号

重庆市文物局：

你局《关于审批全国重点文物保护单位“中美合作所”集中营旧址展示利用工程立项报告的请示》（渝文物〔2017〕3号）收悉。经研究，我局意见如下：

一、暂不同意“中美合作所”集中营旧址展示工程立项。

二、立项报告应从以下方面进一步修改和完善：

（一）对旧址展示现状进行评估，补充相关图纸、照片，分析归纳存在的问题。在此基础上结合展示提升工程的目标、内容，以及历史研究进展、技术手段等必要条件，进一步论证项目实施的必要性和可行性。

（二）立项报告所列工程内容与《“中美合作所”集中营旧址部分文物建筑修缮工程立项报告》存在多处重复，需校核并删减。

（三）在渣滓洞、白公馆、梅园等文物建筑外围新建展室等内容应按涉建项目另行报批。

三、请你局指导项目单位根据上述意见对立项报告做出修改和完善，经你局审核后另行报批。

此复。

国家文物局

2017年3月27日
