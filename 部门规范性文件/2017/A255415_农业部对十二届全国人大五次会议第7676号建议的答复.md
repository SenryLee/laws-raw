# 农业部对十二届全国人大五次会议第7676号建议的答复

## 对十二届全国人大五次会议第7676号建议的答复

农办议〔2017〕195号

李培忠代表：

您提出的关于推动黑龙江绿色食品产业发展的建议收悉。现就涉及我部职能的部分答复如下。

一、关于鼓励新型农业经营主体运用新思维、发展新模式

农业产业化是我国农业经营体制机制的创新，是现代农业发展的方向。龙头企业是构建现代农业产业体系的重要主体，是推进农业产业化经营的关键。近年来，农业部按照中央有关要求，加大对龙头企业的支持力度，充分发挥龙头企业在现代农业建设中的引领作用，引导龙头企业紧跟科技新前沿，瞄准消费新趋势，将“互联网+”“生态+”等现代新理念引入生产经营活动，创新生产方式、经营方式和资源利用方式。2016年，农业部会同全国农业产业化联席会议八部门共同推介了20家农村产业融合典型龙头企业，其中包括了大北农、万年贡等一批积极应用“互联网+”信息技术和生态休闲新模式的龙头企业。推介结果以农业部办公厅文件公布，并在农民日报进行了专版宣传报道，提高了这些龙头企业的知名度与影响力，引导更多龙头企业向模式创新、产业融合方向发展。

今年5月，中共中央办公厅、国务院办公厅印发了《关于加快构建政策体系 培育新型农业经营主体的意见》，提出要加快实施“互联网+”现代农业行动，支持家庭农场、农民合作社、农业产业化龙头企业等新型农业经营主体带动农户应用农业物联网和电子商务。实施信息进村入户入社工程，建立农业信息监测分析预警体系，为新型农业经营主体提供市场信息服务。

下一步，我们将深入贯彻落实中央有关要求，适应当前新业态、新模式蓬勃发展的需要，对《国家重点龙头企业认定和运行监测管理办法》进行修订，将电商类龙头企业的认定标准吸纳到总体的管理办法中，引导龙头企业带动家庭农场、农民合作社等新型农业经营主体应用互联网新思维新技术，提高农业发展的整体质量和效益。

二、关于绿色标准化建设

农业部高度重视农业标准化工作，严格贯彻落实《标准化法》《农产品质量安全法》等法规，围绕农业转方式调结构、农业供给侧结构性改革，组织编制并加快落实《农药残留标准体系工作方案（2015-2020年）》《兽药残留标准体系工作方案（2017-2025年）》《食品安全国家标准食品中农药最大残留限量标准》《动物性食品中兽药最大残留限量》，积极推进落实农业标准化各项工作任务。截至2017年4月，制定农药残留限量标准4140项、兽药残留限量标准1584项，制定发布农业行业标准5121项，各地制定农业生产技术规范1.8万项。认证无公害农产品3432个，获证主体1902个，总产量400万吨。绿色食品、有机农产品新申报企业803家，产品1651个。

下一步，农业部将继续推进绿色化标准化生产，加快实施农药残留标准制修订计划，推进按标生产、绿色防控。继续开展农业标准化创建活动，支持建设一批菜果茶标准园、畜禽水产健康养殖场。实施“三品一标”品牌提升战略，支持发展无公害农产品、绿色食品、有机农产品，加强农产品地理标志保护，力争“三品一标”的发展速度在6%以上，打造一批安全优质的农产品公共品牌。

感谢您对“三农”工作的关心，希望今后继续对我部工作给予支持。
