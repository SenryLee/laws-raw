# 国家林业局关于开展向河北省塞罕坝机械林场学习活动的决定

林场发〔2017〕90号

各省、自治区、直辖市林业厅（局），内蒙古、吉林、龙江、大兴安岭森工（林业）集团公司，新疆生产建设兵团林业局，国家林业局各司局、各直属单位：

塞罕坝机械林场是为了改变“风沙紧逼北京城”的严峻形势，1962年由原林业部决定在河北省承德市围场县建立的，1968年划归河北省林业厅管理至今。55年来，在极端困难的立地条件下，塞罕坝机械林场艰苦创业、接力传承，成功将一棵树的莽莽荒漠变成了百万亩人工绿海。有林地面积由建场之初的24万亩增加到现在的112万亩，蓄积量由33万立方米增加到1012万立方米，森林覆盖率由12%增加到80%，为京津地区筑起了一道坚实的绿色屏障。党的十八大以来，塞罕坝机械林场更加顺应形势，着力改革创新，不断加强森林资源保护，切实提高森林资源生态功能，主动全面压缩木材产量，大力发展森林旅游、绿化苗木和林下种植养殖等绿色产业，收入突破亿元大关，进一步焕发了生机和活力。塞罕坝机械林场的成功经验生动诠释了习近平总书记提出的“绿水青山就是金山银山”的重要思想，集中展现了“忠于使命、艰苦创业、科学求实、绿色发展”的塞罕坝精神，成为我国生态文明建设的典型代表。为充分发挥塞罕坝机械林场成功经验的引领作用和塞罕坝精神的鼓舞作用，进一步激发林业系统广大干部职工干事创业的热情，推动林业现代化建设，我局决定在全国广泛开展向塞罕坝机械林场学习活动。

一、学习他们忠于使命的崇高品质，着力推进国土绿化

塞罕坝机械林场建场的主要任务是改变当地自然面貌，保持水土，为改变京津地带风沙危害创造条件；研究积累高寒地区造林和育林的经验；总结推广大型国营机械化林场经营管理的经验。55年来，塞罕坝人始终牢记党和人民的重托，坚决履行“为首都阻沙源、为京津涵水源”的神圣使命，在自然条件极其恶劣的情况下，不忘初心，攻坚克难，阻沙涵水，修复生态，在高寒地区成功培育了112万亩森林，造林成活率达95%以上，积累了大型国有林场管理的成功经验，交出一份完美的答卷，使塞罕坝再次成为名副其实的“美丽的高岭”，创造了“荒原变林海”的丰功伟绩。当前我国依然是一个缺林少绿、生态脆弱的国家，人民群众期盼山更绿、水更清、环境更宜居，造林绿化、改善生态任重而道远。学习塞罕坝机械林场，就是要牢记习近平总书记“四个着力”的殷殷嘱托，切实承担起国土绿化和生态保护的使命，坚持不懈地植树造林，持之以恒地绿化国土，特别是要充分发挥国有林场林区在国土绿化中的骨干带动作用，为建设生态文明和美丽中国创造更好的生态条件。

二、学习他们艰苦创业的优良作风，着力提高森林质量

塞罕坝机械林场的第一支建设队伍369人，来自全国18个省市，平均年龄24岁。他们听从党的召唤，响应国家号召，扎根荒原，先治坡、后置窝，先生产、后生活，吃黑莜面、喝冰雪水，住马架子、睡地窨子，顶风冒雪、垦荒植树，战胜了百年不遇的自然灾害，用智慧和汗水为无边荒原带来了勃勃生机。进入21世纪，塞罕坝人开始二次创业，始终把提高森林质量作为中心工作。多年来，累计抚育森林260余万亩，对人工林采取全周期、全领域、全方位的培育经营，先后开展了华北落叶松人工林集约经营系统、冀北云杉人工林高效经营技术和樟子松经营技术等研究，探索出了大密度初植、多次中间抚育利用和近自然经营相结合的人工林可持续经营模式。森林质量明显提高，蓄积量达1012万立方米，用只占河北省国有林面积13%的林地，培育出了占河北国有林蓄积量35%的森林资源，单位面积的林木蓄积量分别达到全国人工林平均水平的2.76倍、全国森林平均水平的1.58倍。当前，我国林业发展方式依旧相对粗放，重挖坑栽树、轻经营管理，重数量增长、轻质量提升，纯林和过疏过密林分所占比重大。学习塞罕坝机械林场，就是学习他们几十年如一日地将主要精力集中到森林资源保护培育上来，以“功成不必在我”的坚定信念，艰苦奋斗，久久为功，为子孙后代留下无可替代的美丽家园。

三、学习他们科学求实的严谨态度，着力推进国有林场改革

塞罕坝机械林场在物质和技术几乎一片空白的条件下，将科学技术同塞罕坝的实际相结合，刻苦钻研、大胆创新，不断改进，即使面对重大挫折也不气馁、不懈怠。他们只为成事想办法，不为困难找理由，先后开创了国内使用机械成功栽植针叶树的先河，攻克了高寒地区引种、育苗、造林等一项项技术难关，造林成活率达到95%以上，多项科研成果获得国家、省部级奖励，5项成果达到国际先进水平，部分成果填补了世界同类研究空白，闯出了科技创新促进林场可持续发展的成功模式。当前国有林场改革正处于审批实施市县级方案的攻坚时期和各项改革措施落地生根的关键阶段，部分地区存在等、靠、要思想和畏难情绪，改革进展较慢。学习塞罕坝机械林场，就是要坚持求真务实，发扬科学精神，奔着问题去、盯着问题改，困难面前不低头、矛盾面前不退缩，解放思想、奋发进取，主动作为、强化担当，敢于啃硬骨头，勇于打攻坚战，着力解决改革推进过程中的深层次矛盾，积极推动改革稳步有序进行。

四、学习他们绿色发展的不懈追求，着力打赢林业脱贫攻坚战

塞罕坝人咬定青山不放松，一张蓝图绘到底，用实际行动谱写了绿色发展的华美乐章。与建场初期相比，塞罕坝及周边区域小气候有效改善，无霜期由52天增加到64天，降水量由410mm增加到460mm，6级以上大风天数由83天减少到53天，每年涵养水源、净化水质1.37亿立方米，吸收二氧化碳74.7万吨，释放氧气54.5万吨，被誉为“华北绿肺”、“天然氧吧”。经评估，塞罕坝机械林场的森林资产总价值为200亿元，每年可提供超过120亿元的生态服务价值。森林旅游、绿化苗木等绿色产业已成为林场收入的主要来源，累计上缴利税近亿元，创造了大量就业岗位。同时，也带动了周边地区的乡村游、农家乐、养殖业、山野特产、手工艺品、交通运输等外围产业的发展，每年可实现社会总收入6亿多元。我国林区、山区、沙区集中了全国60%的贫困人口，既是发展林业的重点地区，又是脱贫攻坚的主战场。早在20多年前，习近平总书记担任福建宁德地委书记时就指出，闽东的振兴在于林，森林是水库、钱库、粮库，提出了著名的“三库”理论。学习塞罕坝机械林场，就要学习他们对生态优先、绿色发展的执着追求，坚决摒弃一切破坏生态环境的发展模式，在改善生态状况，扩大生态空间的同时，通过科学利用森林资源，积极发展绿色富民产业，带动周边贫困人口脱贫，助力区域脱贫攻坚，打赢林业脱贫攻坚战。

各地区各单位一定要认真组织，精心部署，广泛深入开展向塞罕坝机械林场学习活动，大力弘扬“忠于使命、艰苦创业、科学求实、绿色发展”的塞罕坝精神，激励全国林业系统广大干部职工以塞罕坝机械林场为榜样，紧密团结在以习近平同志为核心的党中央周围，牢记保护培育森林资源、维护国家生态安全的使命，坚持科学求实的态度和绿色发展理念，撸起袖子加油干，一年接着一年干，一山连着一山绿，将生态文明建设的美好蓝图转化为生动现实，为实现全面建成小康社会和中华民族伟大复兴中国梦的宏伟目标而努力奋斗，以优异的成绩迎接党的十九大胜利召开。
