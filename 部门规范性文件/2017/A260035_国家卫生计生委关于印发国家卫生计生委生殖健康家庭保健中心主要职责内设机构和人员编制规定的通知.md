# 国家卫生计生委关于印发国家卫生计生委生殖健康家庭保健中心主要职责内设机构和人员编制规定的通知

国卫人发〔2017〕72号

各省、自治区、直辖市卫生计生委，新疆生产建设兵团卫生局、人口计生委，委机关各司局，委直属和联系单位，国家中医药管理局：

《国家卫生计生委生殖健康家庭保健中心主要职责内设机构和人员编制规定》已经委党组会议研究通过，现予印发。

国家卫生计生委

2017年12月26日

## 国家卫生计生委生殖健康家庭保健中心主要职责内设机构和人员编制规定

根据《中央编办关于国家卫生计生委所属事业单位机构编制调整的批复》（中央编办复字〔2014〕68号）、《中央编办关于国家卫生计生委人才交流服务中心（国家卫生计生委生殖健康家庭保健中心）等单位更名的批复》（中央编办复字〔2016〕25号），设立国家卫生计生委生殖健康家庭保健中心，为国家卫生计生委直属事业单位。

一、主要职责

（一）面向卫生计生系统，开展生殖健康、家庭保健、健康服务等方面的管理和技术培训。

（二）承办发展中国家、人口与发展南南合作伙伴组织成员国生殖健康、家庭保健等领域培训；承办援外培训。

（三）承办卫生计生领域人才队伍建设相关培训。

（四）开展健康产业发展研究和生殖健康、家庭保健新技术、新产品的推广。

（五）承办国家卫生计生委交办的其他事项。

二、内设机构

根据上述职责，国家卫生计生委生殖健康家庭保健中心设2个内设机构。

（一）办公室。

负责中心文电档案、机要保密、安全保卫、后勤保障等日常运转和综合协调；承担重要文稿起草和政务信息工作；承担中心党群、人事、纪检工作和离退休人员管理工作；承担中心财务、资产管理、内部审计等工作。

（二）事业发展处（培训处）。

承办发展中国家、人口与发展南南合作伙伴组织成员国生殖健康、家庭保健等领域培训；承办援外培训，制定培训计划，协调组织开展培训；面向各级卫生计生系统，组织开展公立医院改革、队伍职业化建设、人口和生殖健康领域、家庭保健等方面的培训。开展健康产业发展研究和生殖健康、家庭保健新技术、新产品的推广。

三、人员编制

国家卫生计生委生殖健康家庭保健中心经费自理事业编制9名。其中，领导班子职数2名；内设机构正副职领导职数3名。

四、附则

本规定由国家卫生计生委人事司负责解释，其调整由国家卫生计生委人事司按规定程序办理。
