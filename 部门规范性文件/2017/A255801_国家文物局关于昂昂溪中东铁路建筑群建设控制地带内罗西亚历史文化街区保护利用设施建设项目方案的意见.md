# 国家文物局关于昂昂溪中东铁路建筑群建设控制地带内罗西亚历史文化街区保护利用设施建设项目方案的意见

文物保函〔2017〕1320号

黑龙江省文物局：

你局《关于罗西亚历史文化街区保护利用设施建设项目涉及国保单位建设控制地带的请示》（黑文管字〔2017〕14号）收悉。经研究，我局意见如下：

一、原则同意所报昂昂溪中东铁路建筑群建设控制地带内的罗西亚历史文化街区保护利用设施建设项目方案。

二、对方案提出以下修改意见：

（一）补充罗西亚历史文化街区主干道的历史资料。主干道设计应尽可能符合历史环境风貌，地面铺装材料的形式和色彩，需与文物建筑群相协调。

（二）补充《近现代历史建筑结构安全性评估导则》（WW/T 0048-2014）作为文物影响评估依据，并根据《导则》相关标准，对涉及昂昂溪中东铁路建筑群文物建筑安全性的主要评估数据进行复核。

（三）细化全部道路与相邻文物建筑的标高图纸和说明，补充排水设计详图。

三、请你局指导相关单位根据上述意见对方案进行修改完善，按照《中华人民共和国文物保护法》第十八条的规定，报城乡建设规划部门批准后实施。工程施工期间，应加强对工程的监管，确保文物安全。

此复。

国家文物局

2017年8月1日
