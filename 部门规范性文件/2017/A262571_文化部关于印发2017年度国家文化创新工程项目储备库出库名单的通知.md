# 文化部关于印发2017年度国家文化创新工程项目储备库出库名单的通知

文科技函〔2017〕1058号

北京市、内蒙古自治区、江苏省、浙江省、安徽省、湖北省、广东省文化厅（局），故宫博物院、中央文化管理干部学院，上海音乐学院，中央音乐学院：

2017年度国家文化创新工程项目评审入库工作已经完成，现将国家文化创新工程项目储备库出库名单印发给你们，并就有关工作通知如下：

一、国家文化创新工程项目的评审、入库和出库实施是我部一项重要工作，请各单位予以高度重视，凡出库项目，须切实纳入工作计划，在经费、人员等方面予以支持，提供必要条件，确保工作顺利进行。

二、请你单位组织相关项目承担单位按照《国家文化创新工程项目管理办法（暂行）》的规定，依据评审意见认真填写《国家文化创新工程项目合同书》。合同书电子版请登录文化部政府门户网站，在“文化资讯”栏目中的“文化科技司”页面下载。

三、请于2017年10月30日前将合同书电子版发送至文化部文化科技司电子邮箱,经审核通过后，于2017年11月15日前将加盖公章的合同书纸质版寄送文化部文化科技司。

联系人：文化部文化科技司科技处 乔伟

电话：010-59882146

通讯地址：北京市东城区朝阳门北大街10号，100020。
