# 住房城乡建设部标准定额司关于同意化工装置自控专业设计管理规范 自控专业的职责范围等18项工程建设行业标准备案的函

建标实函〔2017〕252号

中国石油和化工勘察设计协会：

你会《关于申请<化工装置自控专业设计管理规范 自控专业的职责范围>等十八项行业标准备案的函》（中石化勘设协函〔2017〕23号）收悉。经研究，同意《化工装置自控专业设计管理规范 自控专业的职责范围》等18项行业标准作为“中华人民共和国工程建设行业标准”备案（见附件）。

中华人民共和国住房和城乡建设部标准定额司

2017年12月28日
