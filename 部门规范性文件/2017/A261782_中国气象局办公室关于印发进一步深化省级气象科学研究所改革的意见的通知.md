# 中国气象局办公室关于印发进一步深化省级气象科学研究所改革的意见的通知

气办发〔2017〕28号

各省、自治区、直辖市气象局：

为深入学习贯彻党的十九大精神，贯彻全国科技创新大会以及全国气象科技创新大会部署，落实《关于增强气象人才科技创新活力的若干意见》（中气党发〔2017〕25号），全面推进省级气象科学研究所改革，中国气象局组织制定了《中国气象局关于进一步深化省级气象科学研究所改革的意见》（简称《意见》），现印发给你们，请组织实施。请相关省（区、市）气象局按照《意见》要求组织制定所属省级气象科学研究所的改革方案，积极推进研究所改革，将改革方案于2018年1月31日前报科技与气候变化司备案。

中国气象局办公室

2017年11月16日

## 中国气象局关于进一步深化省级气象科学研究所改革的意见

省级气象科学研究所（简称省所）是国家气象科技创新体系的重要组成部分，是各省（区、市）气象局（简称省局）实现气象现代化的重要科技支撑力量。自2011年开展省所改革试点以来，中国气象局加大了对省所发展的指导和投入，各省局也积极部署、加大支持，省所研发方向进一步凝练，特色领域进一步发展，科技创新能力进一步提升。但仍存在对省局核心业务科技支撑不够、研发队伍体量偏小、创新活力不足、协同创新乏力等问题。为深入学习贯彻党的十九大精神，贯彻全国科技创新大会以及全国气象科技创新大会精神，落实《关于增强气象人才科技创新活力的若干意见》（中气党发〔2017〕25号），进一步增强省所的创新能力，提升对气象现代化的科技支撑能力，现就进一步深化省所改革，提出如下意见。

一、改革思路和目标

坚持创新发展理念，通过科技创新和制度创新，使省所进一步聚焦核心业务技术需求和特色领域发展，研发力量不断增强，开放合作、协同创新、考评激励机制不断完善，人才队伍素质和创新活力进一步提升，创新生态和科研环境进一步优化。力争到2020年，省所对本省核心业务的科技支撑能力和特色领域的创新能力得到显著提升，成为省级业务技术创新平台。

二、主要任务

1.明确省所定位，突出研发职能

聚焦本省核心业务关键技术和特色领域，优化研发方向，着力打造本省科技引领、创新驱动的核心力量。围绕核心业务需求，重点开展灾害性天气监测预报预警、数值模式本地化应用及产品释用、气象资料综合应用等技术研究。瞄准精细化预报服务需求，围绕地方经济社会发展需要，持续推进预报服务等核心领域和特色领域的科技创新，夯实发展基础，增强自主创新能力。强化科研与业务的紧密结合，通过开展应用研究、技术开发和技术推广，提高科技支撑能力。做好已有业务服务工作，保证省所稳定发展。

2.增强研发力量，强化人才队伍建设

依据省所研发职能和科技任务需求，补充调整科技人员，优化人才结构，壮大研发力量。在重点领域精准或柔性引进高层次专家，加大对青年人才的支持力度。围绕特色领域和核心业务关键技术，整合科研、业务单位科技力量，组建科技创新团队，造就一批有影响力的省级科技创新领军人才、科研业务骨干、青年科技人才和高水平创新团队。赋予团队首席（学科带头人）及创新团队更大的技术路线决定权、经费支配权和资源调动权，支持科技人才出国访问、交流和培训。

3.强化开放合作，推进协同创新

建立以省所为核心的科研业务合作平台，强化省所与省局核心业务单位之间的科研合作，促进融合式发展。建立科研、业务人员定常双向交流机制，推动同领域科研与业务人员间的交流轮岗。建立流动人员岗位和薪酬管理制度，实现科研业务人员在科研任务实施过程中的有序流动。推进协同创新，围绕省局核心业务关键技术，加强与相关科研院所的合作，聚集优势力量，开展联合攻关。有条件的省份可结合自身的优势领域和学科建设，探索与国家级气象科研院所合作建设联合研究机构，国家级气象科研院所要加强指导，并在人、财、物方面对省所改革发展给予积极的支持。注重与高校、科研院所及海内外研究机构的务实合作。强化对市、县级气象业务单位的技术辐射和科研指导。

4.完善考评机制，激发创新活力

建立科研业务分类评价机制，充分体现科技创新和业务贡献，注重研发工作的专业性、创新性、实用性和对业务的支撑保障能力。强化对创新团队的考核，以团队首席（学科带头人）为主负责对团队成员进行考核。实行以增加知识价值为导向的分配政策，完善绩效考核和分配机制，将绩效分配向关键岗位、科研骨干和做出突出贡献的科研人员和创新团队倾斜。明确科研绩效奖励不纳入绩效工资总量，激发创新活力。

5.强化科技供给，推进成果转化

建立以业务单位为主体、业务应用为导向、科研业务紧密结合的技术创新体系。围绕核心业务关键技术和特色领域需求，强化成果应用目标管理，推进研发任务落实和成果产出及应用。积极引进、消化、集成创新相关科技成果，与业务单位联合建设科技成果中试基地，组建联合中试团队，实现研发-中试-应用链条无缝对接，提高科技成果供给与转化效率。倡导创新文化，强化知识产权创造、保护、运用。充分利用国家、中国气象局和地方科技政策，建立气象科技成果转化收益分配制度。

6.理顺投入机制，注重长效发展

积极申请或参与国家科技计划项目攻关，积极争取地方科研和建设项目支持。做好与国家级科研院所对接，通过中央级公益性科研院所基本科研业务费和中央级科学事业单位修缮购置专项资金支持，加强省所科技研发和基础条件建设。用好中国气象局省所发展专项经费和小型业务建设项目，着力支持核心业务关键技术和特色领域发展。各省局要加大支持省所改革发展的经费投入。

三、保障措施

各省局要承担起省所改革的主体责任，强化领导，统筹协调，牵头组织制定省所改革方案，做好省所改革的人员、经费等方面的支持保障工作。各省所要精心组织，明确目标，落实省所改革的各项重点任务，确保2020年实现改革目标。中国气象局将加强对省所改革的政策支持，组织开展省所改革发展过程督查和成效评估，对于学科优势明显、人才队伍优秀、运行机制完善的省所，加大支持力度。
