# 中共教育部党组关于徐卫亚等同志职务任免的通知

教党任〔2017〕210号

中共河海大学委员会：

经与中共江苏省委商得一致,2017年8月31日研究决定：

徐卫亚、许峰、郑金海、陆国宾同志任中共河海大学委员会委员、常委，董增川同志任中共河海大学委员会常委；免去鞠平、朱跃龙、王超同志的中共河海大学委员会常委，王济干同志的中共河海大学委员会副书记、常委、委员职务。

中共教育部党组

2017年9月19日
