# 国家新闻出版广电总局办公厅、国家知识产权局办公室关于公布2017年全国知识产权公益广告作品征集评选结果的通知

## 国家新闻出版广电总局办公厅　国家知识产权局办公室关于公布2017年全国知识产权公益广告作品征集评选结果的通知

新广电办发〔2017〕79号

各省、自治区、直辖市新闻出版广电局、知识产权局，新疆生产建设兵团新闻出版广电局、知识产权局，中央三台,电影频道节目中心,中国教育电视台：

为进一步宣传普及知识产权文化理念，提升全社会知识产权意识，推动知识产权事业更好更快地发展，2017年国家新闻出版广电总局和国家知识产权局联合举办了知识产权公益广告作品征集暨评审活动。活动共评出一、二、三类作品及优秀类作品共41件，现将评选结果予以公布（参见附件1、2）。

根据《国家新闻出版广电总局国家知识产权局关于联合举办2017年全国知识产权公益广告作品征集暨评审活动的通知》（新广电发〔2017〕40号）要求，此次活动评选出的优秀作品将纳入“全国优秀广播电视公益广告作品库”，全国各级广播电视播出机构可以从作品库中下载相关作品进行展播。

附件：1.2017年全国知识产权公益广告作品征集活动广播类扶持作品名单

2.2017年全国知识产权公益广告作品征集活动电视类扶持作品名单

国家新闻出版广电总局办公厅　国家知识产权局办公室

2017年11月21日
