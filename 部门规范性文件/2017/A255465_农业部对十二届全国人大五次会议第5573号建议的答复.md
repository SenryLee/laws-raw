# 农业部对十二届全国人大五次会议第5573号建议的答复

## 对十二届全国人大五次会议第5573号建议的答复

农办议〔2017〕217号

储亚平代表：

您提出的关于利用绿色技术推动化肥减量工作与农产品提质增产的建议收悉。经商财政部，现答复如下。

一、关于在化肥减量与农产品提质增产中推广绿色技术

有机水溶肥料是指经过特殊工艺，在水溶肥中加入氨基酸、腐殖酸、聚谷氨酸等有机活性物质的一类水溶肥的统称，具有养分利用率高、减肥增效、培肥土壤等效果。有机水溶肥料主要采用叶面喷施或喷滴灌等方式，在水果、蔬菜、花卉等经济园艺作物上应用较广。2015年，农业部制定印发的《到2020年化肥使用量零增长行动方案》明确提出，示范推广缓释肥料、水溶性肥料、液体肥料、叶面肥、生物肥料、土壤调理剂等高效新型肥料，不断提高肥料利用率。2016年，中央财政安排7亿元资金，实施测土配方施肥补贴项目，全国测土配方施肥技术推广面积达16亿亩，水肥一体化应用面积9000多万亩，全国农用化肥用量自改革开放以来首次出现负增长。在项目实施中，各级农业部门将有机水溶肥料作为新产品推广的一项重要内容，通过农企合作等方式，加强与相关肥料企业的协作，在不同区域、不同作物上开展了有机水溶肥料的试验示范和技术推广，推动了有机水溶肥的应用，促进了农业提质增效、农民增产增收。

下一步，农业部将以绿色发展为导向，结合化肥使用量零增长行动、果菜茶有机肥替代化肥行动、水肥一体化示范等工作的开展，因地制宜推广包括聚谷氨酸有机水溶肥料在内的新肥料、新技术，加快推动形成农业绿色发展方式。

二、关于利用农业科技创新技术进行耕地质量提升

我国耕地长期高强度、超负荷利用，质量状况堪忧，保护任务十分艰巨。农业部高度重视耕地质量问题，落实“藏粮于地、藏粮于技”战略，切实抓好耕地质量建设。从2015年开始，农业部组织实施了耕地质量保护与提升行动，以新建成的高标准农田、耕地退化污染重点区域和占补平衡补充耕地为重点，开展退化耕地综合治理、土壤肥力保护提升、污染耕地阻控修复。2017年，在中央财政的支持下，农业部在全国选择300个重点县，建设耕地质量提升和化肥减量增效示范区，集成推广一批土壤改良、地力培肥和治理修复技术模式，着力提升耕地质量水平。

下一步，农业部将会同有关部门，结合耕地质量保护与提升行动的开展，根据不同土壤障碍因素和农业生产实际需要，因地制宜推广聚谷氨酸有机水溶肥料，提高肥料利用效率，平衡土壤养分，提升耕地质量水平。

三、关于加大财政资金支持

2016年，中央财政安排7亿元，支持测土配方施肥补贴项目，在全国建立200个化肥减量增效示范区，集成推广化

肥减量增效技术。同时，农业部安排部门预算资金，建立11个高标准节水农业示范区，因地制宜推广水肥一体化技术。在项目实施中，各地结合实际，将有机水溶肥料的推广应用作为重要措施，加大资金支持力度，采取物化补助等方式，支持农民在适宜作物上施用有机水溶肥料。

2015年，按照《国务院印发关于深化中央财政科技计划（专项、基金等）管理改革方案的通知》要求，农业部、科技部组织实施“化学肥料和农药减施增效综合技术研发”国家重点研发计划试点专项，将新型水溶肥料研制作为其中的一项重点内容，支持研制溶解度高、组分之间无化学反应沉淀、低盐指数的水溶肥生产材料，研发不同作物专用的多功能、性质稳定、成本低廉的高效水溶肥料生产工艺技术，制定生产技术标准和质量标准，推动新型水溶肥料产业化发展和规模化应用。

下一步，农业部将会同有关部门，加大资金整合统筹力度，通过现有渠道对聚谷氨酸有机水溶肥料等高效新型肥料的推广应用予以合理支持。进一步完善绿色产品政府采购政策，研究将符合政府采购政策要求的有机水溶肥料等绿色技术、新材料、新产品纳入支持范围。同时，结合“化学肥料和农药减施增效综合技术研发”国家重点研发计划试点专项，支持科研机构和企业开展有机水溶肥料技术研发、成果转化和推广工作。

感谢您对“三农”工作的关心，希望今后继续对农业部工作予以支持。
