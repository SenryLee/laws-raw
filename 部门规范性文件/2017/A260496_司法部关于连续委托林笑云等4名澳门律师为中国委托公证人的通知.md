# 司法部关于连续委托林笑云等4名澳门律师为中国委托公证人的通知

司发通〔2017〕119号

各省、自治区、直辖市司法厅(局)，新疆生产建设兵团司法局：

根据《内地与澳门关于建立更紧密经贸关系的安排》，经研究，决定连续委托林笑云(女)、黄显辉、石立炘、赵鲁4名澳门律师为中国委托公证人。

司法部

2017年11月24日
