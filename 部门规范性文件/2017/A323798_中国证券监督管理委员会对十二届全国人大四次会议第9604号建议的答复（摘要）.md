# 中国证券监督管理委员会对十二届全国人大四次会议第9604号建议的答复（摘要）

## 对十二届全国人大四次会议第9604号建议的答复（摘要）

《关于解决中小企业融资难问题的建议》收悉。经认真研究，现就有关问题答复如下：

近年来，我会大力推进多层次资本市场建设，努力建设便利不同类型企业融资的多层次资本市场体系，对服务中小企业融资发挥了积极作用。

一是支持符合条件的中小企业在中小企业板和创业板发行上市。2015年，共有130家企业在中小企业板和创业板上市，融资总额达4797.51亿元。

二是不断提升全国中小企业股份转让系统（即新三板）对中小微企业的支持力度。2015年，新三板共有挂牌公司5129家，总股本2959.51亿股，总市值24584.42亿元，1887家挂牌公司共计进行了2565次定向发行，累计发行股票230.79亿股，累计融资1216.17亿元。

三是推动区域性股权市场规范发展，支持中小企业直接融资。截至2015年底，37家区域性股权市场共有挂牌股份公司3375家，展示企业4.15万家，累计为企业实现各类融资4331.56亿元。

四是支持中小企业通过债券市场融资。2015年，中小企业在交易所发行公司债券160只，融资523.29亿元。

下一步，我会将继续贯彻落实党中央、国务院关于资本市场发展的决策部署，持续支持中小企业直接融资。
