# 国家能源局综合司关于印发2017年能源行业核电标准制（修）订计划及核电标准英文版翻译出版计划的通知

国能综函科技〔2017〕136号

各有关单位：

经研究，现将2017年能源行业核电标准制（修）订计划（共计115项，见附件1）及2017年能源行业核电标准英文版翻译出版计划（共计14项，见附件2）下达给你们，请认真组织各有关标准化技术委员会、标准起草单位、翻译承担单位抓好落实，按时完成任务。

附件：

1.2017年能源行业核电标准制（修）订计划项目汇总表

2.2017年能源行业核电标准英文版翻译出版计划项目汇总表

国家能源局综合司

2017年6月23日
