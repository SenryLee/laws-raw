# 国家文物局关于崖城学宫保护规划意见的函

文物保函〔2017〕1861号

海南省文化广电出版体育厅：

你厅《关于审核三亚崖城学宫保护规划的请示》(琼文发〔2017〕77号)收悉。经研究，我局意见如下：

一、原则同意所报崖城学宫保护规划。

二、对该规划提出以下修改意见：

（一）进一步核实文物本体构成。加强对学宫历史格局的研究，补充复建建筑和新建建筑的风貌影响评估。

（二）补充文物建筑形制特点及基本做法，细化残损现状描述；准确定性保护措施。

（三）补充对城市总体规划和历史文化名镇保护规划的评估，并在此基础上进一步论证保护区划调整及建设控制地带分类的可行性和合理性，同时，进一步完善和上位规划的衔接整合。

（四）完善周边区域环境中街巷历史格局、空间尺度、建筑肌理等方面的评估，归纳总结周边历史建筑的特征属性，为控制要求提供明确依据；不宜按现行一般规范对消防通道进行统一拓宽，应考虑采用特殊消防车辆满足历史街区保护的消防需求。

（五）加强对中国古代边陲文庙遗存文化展示的研究；建议重点考虑学宫在日常市民文化活动中活化利用，利用学宫南院非文物建筑，使学宫西侧外部空间更好地纳入城市公共空间。西侧管理服务区建筑体量过大，应当予以分割，并控制建筑单体的体量。

（六）细化考古工作计划，明确对可能的地下遗迹的保护要求。

（七）进一步规范完善图纸绘制，梳理简化规划文本。

三、请你厅指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善，经你厅核准后于15个工作日内将规划文本图纸及相关电子档案等材料报我局备案。

四、请你厅按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的崖城学宫保护规划报请海南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你厅指导和协调地方人民政府在保护规划的指导下，进一步做好崖城学宫文物保护的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年11月15日
