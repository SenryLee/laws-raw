# 中国国家认证认可监督管理委员会公告2017年第38号——国家认监委关于关于强制性产品指定认证机构中汽认证中心名称变更的公告

## 中国国家认证认可监督管理委员会公告

2017年第38号

## 国家认监委关于关于强制性产品指定认证机构中汽认证中心名称变更的公告

根据中汽认证中心《关于认证机构名称变更的请示》（中汽认证质发〔2017〕99号），现将强制性产品认证指定认证机构“中汽认证中心”名称变更为“中汽认证中心有限公司”，其指定业务领域不变。现予以公告。

国家认监委

2017年11月21日
