# 国家测绘地理信息局关于印发《2017年全国测绘地理信息普法依法治理工作要点》的通知

## 关于印发《2017年全国测绘地理信息普法依法治理工作要点》的通知

国测法发〔2017〕6号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团测绘地理信息主管部门，局所属各单位，机关各司室：

为做好2017年全国测绘地理信息普法依法治理工作，根据《全国普法办公室关于印发〈2017年全国普法依法治理工作要点〉的通知》（普法办〔2017〕1号），结合国家测绘地理信息局年度重点工作，我局制定了《2017年全国测绘地理信息普法依法治理工作要点》，现印发给你们，请结合实际认真贯彻落实。

国家测绘地理信息局

2017年5月27日

## 2017年全国测绘地理信息普法依法治理工作要点

2017年全国测绘地理信息普法依法治理工作的总体要求是：全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入贯彻习近平总书记系列重要讲话精神，认真贯彻落实测绘地理信息“七五”普法规划，深入开展修订颁布后的《中华人民共和国测绘法》（以下简称新《测绘法》）学习宣传贯彻实施工作，全面推动新《测绘法》各项制度的贯彻落实，营造测绘地理信息事业发展良好法治氛围。

一、深入学习宣传习近平总书记关于全面依法治国的重要论述。以习近平总书记系列重要讲话精神作为测绘地理信息法治建设和法治宣传教育工作的根本指针和行动指南。要认真学习、深刻理解、系统把握全面依法治国的重大意义、指导思想、总目标、基本原则和总体要求，进一步增强“四个意识”，坚定“四个自信”，大力宣传推进科学立法、严格执法、公正司法、全民守法，增强全民法治观念，更好地发挥法治的引领和规范作用。

二、认真学习宣传党内法规。认真贯彻落实中共中央办公厅《关于推进“两学一做”学习教育常态化制度化的意见》，重点学习宣传《中国共产党章程》《中国共产党廉洁自律准则》《中国共产党纪律处分条例》《中国共产党问责条例》《关于新形势下党内政治生活的若干准则》《中国共产党党内监督条例》等党内法规，教育引导测绘地理信息系统广大党员按照“四讲四有”标准，做到政治合格、执行纪律合格、品德合格、发挥作用合格。

三、组织开展新《测绘法》学习宣传贯彻活动。各级测绘地理信息主管部门要把学习宣传贯彻好新《测绘法》作为一项重大政治任务。通过召开会议部署、组织学习培训、开展社会宣传、编印宣传材料等多种形式，深入解读、广泛宣传新《测绘法》颁布的重大背景、重要意义和主要内容，进一步增强测绘地理信息系统、行业和社会公众的测绘地理信息法治观念和法治意识，增进各级政府及其有关部门对测绘地理信息工作的高度重视和大力支持，依法促进测绘地理信息事业健康发展。

四、切实抓好国家工作人员学法用法。贯彻落实《国家测绘地理信息局关于完善国家工作人员学法用法制度的实施意见》，重点抓好领导干部这个“关键少数”，提高领导干部运用法治思维和法治方式深化改革、推动发展的能力。健全党组（党委）中心组学法制度、集体和个人学法制度，坚持重大决策前专题学法，积极利用国家宪法日、宪法宣誓以及其他法律法规颁布实施纪念日等开展学法用法活动。健全法治培训机制，组织开展新《测绘法》培训、测绘地理信息行政执法人员培训等工作。落实重大行政决策合法性审查机制、公职律师和法律顾问制度、信息公开制度。健全国家工作人员学法用法考核机制，推动年度考核述法制度落实。

五、认真落实国家机关“谁执法谁普法”普法责任制。各级测绘地理信息主管部门要贯彻《中共中央办公厅 国务院办公厅印发<关于实行国家机关“谁执法谁普法”普法责任制的意见>的通知》（中办发[2017]31号）精神，落实国家机关普法责任。要把普法工作纳入本部门工作总体布局，做到与其他业务工作同部署、同检查、同落实。按照普法责任制要求，制定普法计划和责任清单，明确普法任务和工作要求。建立健全普法领导和工作机构，明确具体责任部门和责任人员。要把普法责任制落实情况纳入省级测绘地理信息主管部门年度工作绩效考核和领导干部政绩考核，推动普法责任制各项要求落到实处。

六、运用新媒体新技术开展普法。各级测绘地理信息主管部门要继续巩固官方网站的传统宣传阵地，丰富普法内容，开设新《测绘法》宣传专栏，及时登载当地开展的新《测绘法》贯彻实施工作和学习宣传活动。开展“互联网+法治宣传”活动，各级测绘地理信息主管部门和行业单位要充分利用微博、微信、客户端等新媒体，探索运用视频直播、秒拍、线上答题、软文推广等新形式，创新开展普法宣传，增强社会各界对测绘地理信息法律法规和测绘地理信息工作的了解，提升法治宣传影响力。

七、建好用好国家测绘地理信息局普法讲师团。按照全国普法办的要求，国家测绘地理信息局将组建“七五”普法讲师团，开展多种形式的法治讲座、培训，宣讲测绘地理信息法律法规规章、重大规划、“五大业务体系”和“放管服”改革等内容。地方各级测绘地理信息主管部门要充分利用好普法讲师团，开展各种形式的普法宣讲活动，深入推进新《测绘法》、测绘地理信息法规及重点工作的学习贯彻。

八、深入推进测绘地理信息依法治理。加快测绘地理信息综合监管平台建设，提高行政管理效能，提升测绘地理信息部门监管、服务的科学化、信息化水平。统筹开展测绘资质、质量、成果、地图管理“双随机一公开”抽查，加强事中事后监管，营造公平竞争的发展环境。推进测绘地理信息综合执法和联合执法，加强基层执法能力建设，加大案件查处力度。组织开展测绘地理信息行业信用信息的常态化征集和发布，建立健全褒扬诚信、惩戒失信的机制，强化信用约束，加强信息共享。
