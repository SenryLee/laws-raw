# 国家文物局办公室关于万泉文庙保护规划意见的函

办保函〔2017〕1420号

山西省文物局：

你局《关于审批万荣万泉文庙文物保护规划的请示》（晋文物〔2017〕89号）收悉。经研究，我局意见如下：

一、所报规划的体例和内容与《全国重点文物保护单位保护规划编制要求》存在较大差距，我局暂不同意万泉文庙保护规划。

二、所报规划应做以下必要修改和完善：

（一）应进一步明确规划目标，结合现状勘察分析需解决的问题。结合考古调查勘探和研究成果，进一步确认万泉文庙历史格局。

（二）完善现状评估，客观评估文物本体及环境存在的主要问题及展示资源条件，明确管理单位。

（三）合理调整保护区划，严格制定保护区划管理规定。

（四）完善环境整治措施。明确保护范围内信号塔的限期搬迁；完善对建设控制地带范围内的超高建筑的整治措施。

（五）建议在展示利用规划中，考虑为社区提供服务的可能性。

（六）进一步梳理、规范规划文本和图纸。

三、请你局指导有关单位，根据上述意见对万泉文庙保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月26日
