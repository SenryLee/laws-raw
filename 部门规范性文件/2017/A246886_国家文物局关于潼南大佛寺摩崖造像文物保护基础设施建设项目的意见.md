# 国家文物局关于潼南大佛寺摩崖造像文物保护基础设施建设项目的意见

## 关于潼南大佛寺摩崖造像文物保护基础设施建设项目的意见

办保函〔2017〕8号

重庆市文物局：

你局《关于审批潼南大佛寺摩崖造像文物保护基础设施建设项目规划设计方案的请示》（渝文物〔2016〕338号）收悉。经研究，我局意见如下：

一、所报项目实施的必要性不足，方案设计思路不当，对文物景观风貌影响较大，我局暂不同意潼南大佛寺摩崖造像文物保护基础设施建设项目。

二、所报方案应进行以下必要的修改和完善：

（一）应调整设计思路，从潼南大佛寺摩崖造像保护管理和展示利用的实际需要出发，科学评估现有基础设施的主要问题和功能需求，进一步论证新建设施的必要性和影响，在此基础上合理研提新建设施的数量、功能、规模、选址及外观样式等。

（二）应系统梳理相关历史文献资料，开展必要的考古工作，明确摩崖造像、文物建筑和附属文物的历史沿革、分布范围与空间格局，为科学整治大佛寺环境提供依据。

（三）应结合历史研究与考古工作成果，调整、完善设计方案，充分保护文物本体、空间格局及历史风貌的真实性和完整性。道路、绿地、广场等设计应充分尊重大佛寺原有格局和道路组织，避免现代化和景观园林化设计倾向。补充潼南大佛寺摩崖造像建设控制地带的管理规定和具体控制要求。

（四）应根据大佛寺的历史文化价值内涵，科学确定展示主题和展示内容，补充说明大佛寺的现状使用功能以及文物部门与宗教部门的责权关系。

（五）进一步完善文本和图纸，补充现状平面图。完善文物影响评估报告，深入论证拟建项目对文物本体和环境风貌的影响，做到客观、准确、科学。

三、请你局组织有关单位根据上述意见，对所报方案进行修改、完善后，按程序另行报批。

四、请你局指导当地人民政府组织专业机构，按照《关于潼南大佛寺摩崖造像保护规划的意见》（办保函〔2015〕330号）的要求，抓紧修改完善保护规划，统筹考虑文物保护、展示利用、环境整治等方面工作。

专此函。

国家文物局

2017年1月6日
