# 国家文物局关于蔡家宅附属设施及环境整治施工设计方案的意见

## 关于蔡家宅附属设施及环境整治施工设计方案的意见

办保函〔2017〕396号

海南省文物局：

你局《关于审核蔡家宅附属设施及环境整治施工设计方案的请示》（琼文发[2017]19号）收悉。经研究，我局意见如下：

一、暂不同意所报设计方案。

二、对方案提出以下修改意见：

（一）深化建设项目对文物本体及环境的影响评估，作到客观全面。

（二）在保护范围内接待中心前广场、公共卫生间、休闲亭、林荫小道等建设项目必要性不足，且对文物建筑环境风貌造成明显影响，应依据文物保护规划相关要求另行合理选址。

（三）荷花池恢复整治项目中的砌筑驳岸、栏杆等建设项目对文物本体影响过大，应予以取消。

（四）大范围地面硬化对文物环境风貌影响较大，应进行合理压缩。

三、请你局指导有关单位，根据上述意见对方案进行完善后，另行报批。

专此。

国家文物局

2017年4月10日
