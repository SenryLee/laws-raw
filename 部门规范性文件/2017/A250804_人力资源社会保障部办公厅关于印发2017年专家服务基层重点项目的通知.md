# 人力资源社会保障部办公厅关于印发2017年专家服务基层重点项目的通知

人社厅函〔2017〕96号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅(局)：

开展专家服务基层活动是助推基层经济社会发展和科技创新的重要举措，也是加强专家队伍建设的重要抓手。近年来，我部深入实施万名专家服务基层行动计划，各级人社部门组织各行业领域专家深入基层一线开展服务工作，取得了良好的社会效益、经济效益和人才效益，深受基层单位、专业技术人员和广大人民群众的欢迎。国务院领导对专家服务基层的做法和成效给予了充分肯定。为进一步做好2017年专家服务基层工作，我们根据各地服务活动申报情况，遴选确定了56个重点项目（项目名称及资助额度附后）。各地人社部门要充分认识专家服务基层工作的重要意义，增强责任意识，切实组织实施好今年的专家服务基层重点项目。

一、精心组织实施，确保取得实效。各地区要严格按照主题和内容组织实施服务活动。围绕基层需求，找准找好服务专家，积极发挥人社部门职能作用，做好专家与基层单位的对接，为专家深入基层提供必要的工作、生活和服务保障，为他们更好发挥作用创造条件。要突出服务活动的针对性，解决迫切问题、保障改善民生、带动人才成长、助推基层发展，确保活动取得实效。

二、严格过程管理，遵守财经纪律。要认真贯彻落实中央有关要求，对服务活动全程加强管理，不得借活动之名旅游参观、公款宴请，改进工作作风，沉下身子搞服务。要严格执行国家有关经费管理规定，活动执行经费预决算制度，遵守财务和审计规定，确保专款专用，提高使用效益，厉行勤俭节约，不得铺张浪费。资助的活动经费如有结余，要按照有关规定及时退回我部，附函说明情况并承担审计责任。

三、加强总结宣传，营造良好氛围。项目结束后，要认真总结活动情况，积累经验、查找不足、不断改进。要及时发掘在服务基层中涌现出的鲜活经验和先进事迹，宣传弘扬基层群众和专业技术人员勇于奋斗、积极进取的风貌；专家心系群众、无私奉献的精神，不断提高专家服务基层活动的社会影响力，营造全社会关心支持专家服务基层工作的良好舆论氛围。

各地人社部门要按时完成今年纳入计划的各项重点项目，并于2017年12月1日前，将工作总结及经费决算报告报我部专业技术人员管理司。工作总结和经费使用情况将作为下一年度遴选项目和资助经费的重要依据。我部将对部分项目进行监督巡查。
