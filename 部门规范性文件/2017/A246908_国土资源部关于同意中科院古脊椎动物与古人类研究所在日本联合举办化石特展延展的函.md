# 国土资源部关于同意中科院古脊椎动物与古人类研究所在日本联合举办化石特展延展的函

中国科学院：

《关于申请在日本举办“恐龙大移居”特别展延展的函》（科发函字〔2016〕497号）收悉。经研究，为开展中日科技文化交流，弘扬我国地质遗迹文化，促进地质遗迹资源的合理利用，依据《古生物化石保护条例》（国务院令第580号）规定，同意经《国土资源部关于同意中科院古脊椎动物与古人类研究所赴日本共同举办化石特展的函》（国土资函〔2016〕320号）批准的古脊椎动物与古人类研究所在日本福井县立恐龙博物馆联合举办的“恐龙的大移居”特展延展5个月，即延展至2017年6月7日。

展览结束后，请敦促出展单位确保将所有出境展品安全、及时运回，并请出展单位于2017年7月7日前向国土资源部提交展品进境报告。

2017年1月3日
