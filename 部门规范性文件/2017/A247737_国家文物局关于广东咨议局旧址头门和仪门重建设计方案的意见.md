# 国家文物局关于广东咨议局旧址头门和仪门重建设计方案的意见

## 关于广东咨议局旧址头门和仪门重建设计方案的意见

办保函〔2017〕127号

广东省文物局：

你局《关于上报全国重点文物保护单位广东咨议局旧址大门（头门和仪门）重建设计方案的请示》（粤文物请〔2016〕81号）收悉。经研究，我局意见如下：

鉴于广东咨议局旧址大门（头门和仪门）早已不复存在，目前可资研究的资料既不满足在现代地形图上对广东咨议局旧址大门（头门和仪门）进行定位的条件，也缺乏建筑形制的具体做法记载，广东咨议局旧址大门（头门和仪门）重建的必要性和依据不足，根据《文物保护法》第二十二条规定，我局暂不同意广东咨议局旧址大门（头门和仪门）重建设计方案。

专此。

国家文物局

2017年2月17日
