# 国家文物局关于归德府城墙西墙、北墙维修保护工程立项的意见

## 关于归德府城墙西墙、北墙维修保护工程立项的意见

办保函〔2016〕1383号

河南省文物局：

你局《关于归德府城墙（西墙、北墙）维修保护工程立项的请示》（豫文物〔2016〕274号）收悉。经研究，我局意见如下：

一、所报工程立项的工程对象不明确，必要性和可行性论述不足，我局暂不同意归德府城墙西墙、北墙维修保护工程立项。

二、对该立项文本提出以下修改意见：

（一）应进一步说明工程实施的必要性和可行性，根据《归德府城墙保护规划》的原则和要求，结合城墙保护、展示和管理需要，统筹考虑西墙、北墙维修工程的目标和任务分期。

（二）加强现状勘察和研究，客观分析文物保存现状、病害情况等，进一步明确工程对象、施工范围和工程措施。

（三）应系统评估归德府城墙一期工程实施效果，分析所采用措施的有效性和安全性，为科学研提城墙保护措施提供依据。补充归德府城墙一期保护工程情况和工程效果评估内容。

（四）应按照《全国重点文物保护单位文物保护工程立项报告规范文本（试行）》要求，认真编写立项报告，不得套用归德府城墙一期项目文本内容。同时，应根据工程量合理编制经费预算，进一步调减工程造价，补充取费标准。“施工现场拆迁”不应列入经费申报内容。

三、请你局根据《全国重点文物保护单位文物保护工程立项报告规范文本（试行）》的相关要求及我局所提意见，对立项报告进行修改完善后，按程序另行报批。

专此函。

国家文物局

2017年1月4日
