# 国家文物局办公室关于胜果寺塔保护规划意见的函

办保函〔2017〕966号

河南省文物局：

你局《关于再次上报修武胜果寺塔保护规划的请示》（豫文物〔2016〕200号）收悉。经研究，我局意见如下：

一、所报规划价值评估和研究不足，保护区划不合理，规划深度不够，我局暂不同意胜果寺塔保护规划。

二、所报规划应做以下必要修改和完善：

（一）应加强胜果寺塔价值研究，全面搜集、整理文献史料，结合考古工作成果，明确胜果寺塔、寺院和周边街巷的关系。

（二）应根据文物分布情况、保护管理需要和现行保护区划评估结论，进一步补充保护区划调整依据，科学调整保护区划边界。建议建设控制地带分类，明确各类建设控制地带管理规定和具体控制指标。

（三）“保护标志”等应纳入专项规划。

（四）应针对现状评估结论，合理确定环境整治范围、措施和力度，慎重考虑大规模拆除文物周边现有建筑的必要性，严格控制广场、绿地的建设规模，降低文物环境影响；“消防、安防”应纳入防灾减灾规划；补充考古研究规划，明确考古工作计划和具体内容。

（五）进一步规范文本与图纸。

三、请你局组织有关单位根据上述意见对所报保护规划进行修改、完善，按相关程序另行报批。

国家文物局办公室

2017年8月22日
