# 国家文物局关于南京城墙通济门遗址文物保护与展示工程立项的意见

## 关于南京城墙通济门遗址文物保护与展示工程立项的意见

办保函〔2017〕344号

江苏省文物局：

你局《关于审批南京城墙通济门遗址文物保护与展示工程立项的请示》（苏文物保〔2017〕17号）收悉。经研究，我局意见如下：

一、暂不同意南京城墙通济门遗址文物保护与展示工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）应根据《南京城墙保护规划》要求，客观评估通济门遗址的文物价值，进一步论证遗址展示的必要性和可行性。

（二）应结合遗址本体保存情况、周边建设现状和社区文化生活需要，明确展示定位和目标，科学确定展示方式、主题和具体设计内容。不同意覆罩大棚展示设计思路，建议采用植被标识、覆土模拟等多种方式科学阐释通济门遗址的价值内涵。

（三）占压文物建构筑物拆除、基础设施改造等不属于文物保护工程范畴，不得纳入本项目。

（四）应根据工程量合理编制经费预算，补充各单项费用取费依据。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促有关单位切实做好南京城墙通济门遗址的保护工作，在考古发掘结束后应采取必要的回填保护措施，确保文物安全。

专此函。

国家文物局

2017年3月28日
