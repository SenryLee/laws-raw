# 国家文物局关于阳明祠展示利用工程立项的意见

## 关于阳明祠展示利用工程立项的意见

办保函〔2017〕147号

贵州省文物局：

你局《关于送审〈阳明洞和阳明祠（阳明祠）展示利用立项报告〉的请示》（黔文物呈〔2016〕95号）收悉。经研究，我局意见如下：

一、暂不同意阳明祠展示利用工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）加强历史资料的收集和研究，深入挖掘阳明祠历史文化内涵，分析现有展陈效果和存在问题，补充说明现状展陈面积、功能分区、游客量和设施设备情况等，进一步论证工程实施的必要性和可行性。补充说明《阳明祠保护规划》中展示利用的相关内容。

（二）应明确展示利用定位，详细说明展示主题、方式、内容和游线设计等，妥善处理各展示节点之间的关系。

（三）应根据建筑结构特点和承载力，科学确定改造方式和使用强度，不得随意改变文物建筑结构。说明新增设施设备与文物建筑本体的关系，补充施工过程中的临时性保护措施。不同意建设后山碑廊，新建建筑不得纳入展示利用工程。

（四）根据工程量合理编制经费预算，进一步核减工程造价，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年2月22日
