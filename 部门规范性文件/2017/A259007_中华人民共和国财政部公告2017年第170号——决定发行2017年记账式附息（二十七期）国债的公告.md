# 中华人民共和国财政部公告2017年第170号——决定发行2017年记账式附息（二十七期）国债的公告

## 中华人民共和国财政部公告

2017年第170号

根据国家国债发行的有关规定，财政部决定发行2017年记账式附息（二十七期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

一、本期国债计划发行260亿元，实际发行面值金额262.2亿元。

二、本期国债期限7年，经招标确定的票面年利率为3.9%，2017年12月21日开始计息，招标结束后至12月21日进行分销，12月25日起上市交易。

三、本期国债为固定利率附息债，利息按年支付，利息支付日为每年的12月21日（节假日顺延，下同），2024年12月21日偿还本金并支付最后一次利息。

其他事宜按《中华人民共和国财政部公告》（2017年第2号）规定执行。

特此公告。

中华人民共和国财政部

2017年12月20日
