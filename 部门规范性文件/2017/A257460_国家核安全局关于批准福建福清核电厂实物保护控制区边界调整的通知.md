# 国家核安全局关于批准福建福清核电厂实物保护控制区边界调整的通知

## 关于批准福建福清核电厂实物保护控制区边界调整的通知

国核安发〔2017〕267号

福建福清核电有限公司：

你公司《关于呈送福建福清核电厂实物保护控制区边界调整申请的报告》（福核发〔2016〕735号）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的要求，我局对你公司提交的申请文件进行了审评，认为你公司关于福建福清核电厂取水口拦污拦船网处实物保护控制区边界的调整是可以接受的，现予批准。

你公司应严格按照我局批准的方案实施福建福清核电厂实物保护控制区的边界调整，确保核电厂运行安全。

国家核安全局

2017年11月7日
