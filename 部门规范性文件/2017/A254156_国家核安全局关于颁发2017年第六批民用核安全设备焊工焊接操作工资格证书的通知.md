# 国家核安全局关于颁发2017年第六批民用核安全设备焊工焊接操作工资格证书的通知

## 关于颁发2017年第六批民用核安全设备焊工焊接操作工资格证书的通知

国核安发〔2017〕168号

各聘用单位：

根据《民用核安全设备监督管理条例》和《民用核安全设备焊工焊接操作工资格管理规定》（HAF603），我局对上海电气核电设备有限公司等6家民用核安全设备焊工焊接操作工考核中心的焊工项目考试评定报告进行了审查（考试编号见附件1），认为上海第一机床厂有限公司等39家聘用单位的335名焊工焊接操作工符合相关要求，批准颁发民用核安全设备焊工焊接操作工资格证书（基本信息见附件2），共计568项合格项目。

民用核安全设备焊工焊接操作工聘用单位应加强对本单位焊工焊接操作工的管理，保证其在考试合格项目对应范围内从事焊接活动；焊工焊接操作工应严格按照操作规程进行民用核安全设备焊接活动。民用核安全设备焊工焊接操作工聘用单位和焊工焊接操作工对焊接质量负责。

特此通知。
