# 国家文物局关于邛窑遗址文保中心建设项目涉及邛窑遗址保护范围选址的意见

## 关于邛窑遗址文保中心建设项目涉及邛窑遗址保护范围选址的意见

办保函〔2017〕242号

四川省文物局：

你局《关于上报〈邛窑遗址文保中心设计方案〉的请示》（川文物〔2016〕147号）收悉。经研究，我局意见如下：

一、暂不同意邛窑遗址文保中心建设项目涉及邛窑遗址保护范围的选址方案。

二、所报方案尚需做以下必要的修改和完善：

（一）补充说明《邛窑遗址保护总体规划（2013—2025）》中对文保中心建设项目选址的相关规定及建筑规模等的技术性指标。

（二）建议进一步优化选址，避开邛窑遗址保护范围，并事先开展全面的考古调查勘探，避免占压地下文物遗存。

（三）进一步明确文保中心的定位，合理布设相关功能，并严格控制建筑规模、体量和高度，并注意与遗址及其周边环境相协调。游客服务用房的选址宜与邛窑遗址的参观游览布局相协调。

三、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改完善，并开展必要的文物影响评估，经你局核准后，按程序另行报批。

国家文物局

2017年3月15日
