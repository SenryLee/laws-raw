# 国家文物局关于在南京城墙建设控制地带内进行玄武湖菱洲儿童乐园建设项目的意见

文物保函〔2017〕1916号

江苏省文物局：

你局《关于审批南京城墙建设控制地带内玄武湖菱洲儿童乐园项目修改方案的请示》（苏文物保〔2017〕322号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位南京城墙建设控制地带内进行玄武湖菱洲儿童乐园建设项目和你局意见。

二、对所报项目提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《南京市历史文化名城保护规划》、《南京城墙保护规划》、《南京城墙保护条例》的相关管理规定，合理确定拟建项目的高度、规模、色彩和外观样式等，尽量减少对文物本体、历史环境和自然环境的影响。

（二）进一步优化方案设计，采用对环境最小干预的设计手法，加强生态保护；新建建筑及设施形式应简洁，并尽量采用轻质、可逆的构造措施，确保拟建项目与玄武湖自然环境和历史环境相协调。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十八条的规定报城乡建设规划部门批准。批准实施前注意进一步广泛听取社会各界关于项目实施的相关意见。施工中应加强监管，确保文物及其环境安全。

专此函复。

国家文物局

2017年11月30日
