# 国家文物局关于白鹿书院屋面修缮及挡土墙加固工程立项的意见

## 关于白鹿书院屋面修缮及挡土墙加固工程立项的意见

办保函〔2017〕114号

江西省文物局：

你局《关于呈报〈白鹿书院屋面维修及护坡挡土墙文物保护工程立项报告〉的请示》（赣文物局字〔2016〕203号）收悉。经研究，我局意见如下：

一、暂不同意白鹿书院屋面修缮及挡土墙加固工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）加强现状勘察和研究，准确核实文物构成和保护对象，科学区分文物建筑与非文物建筑，在此基础上进一步明确修缮范围和工程量。

（二）应根据现状勘察结论，深入研究和分析各单体文物建筑的原有屋面做法，慎重论证屋面揭顶维修的必要性，建议以现状整修为主，避免过度干预。

（三）应开展必要的地质灾害专项勘察，进一步评估近年来文物所在区域暴雨、泥石流等自然灾害发生频率、破坏程度等，查明工程地质类型、地表径流量和挡土墙病害原因，科学评估现有挡土墙的结构稳定性和防护效果。同时，进一步细化挡土墙设计，充分考虑植物生长影响，合理设计排水设施，确保防护设施安全、有效，并与文物周边景观风貌相协调。

（四）应制定必要的游客管理措施，确保人员安全。

（五）应根据工程量合理编制经费预算，确定取费项目，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促有关单位切实履行文物日常管理责任，严格执行《古建筑保养维护规程》要求，制定白鹿书院日常养护和岁修工作计划，落实人员和经费保障，及时做好文物建筑屋面、院落的植物清理工作，确保文物安全。

专此函。

国家文物局

2017年2月13日
