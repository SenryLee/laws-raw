# 国家文物局关于沘江古桥梁群保护规划编制立项的意见

## 关于沘江古桥梁群保护规划编制立项的意见

办保函〔2017〕358号

云南省文物局：

你局《关于沘江古桥梁群保护规划（新编）立项的请示》（云文物〔2017〕8号）收悉。经研究，我局意见如下：

一、沘江古桥梁群文物类型单一、布局分散，规划编制的必要性和可行性不足，我局不同意沘江古桥梁群保护规划编制立项。

二、请你局督促、指导地方人民政府加强“四有”建设，完善沘江古桥梁群的保护区划、管理规定和具体保护管理措施，严格控制周边各类建设活动。同时，应切实做好文物日常养护、巡查和岁修工作，确保文物安全。如发现影响文物安全的病害险情，应及时启动保护工作，并按要求履行报批程序。

专此函。

国家文物局

2017年3月31日
