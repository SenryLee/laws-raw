# 国家文物局办公室关于昌都卡若遗址文化旅游提升工程建设及选址的意见

办保函〔2017〕1465号

西藏自治区文物局：

你局《关于审批昌都卡若遗址文化旅游提升工程设计方案的请示》（藏文物字〔2017〕545号）收悉。经研究，我局意见如下：

一、暂不同意昌都卡若遗址文化旅游提升工程的建设及选址方案。

二、所报建设方案应进一步深化设计，明确项目选址与遗址保护区划的位置关系，科学论证项目实施规模的必要性和可行性，补充文物影响评估报告、相关文物保护措施和相关工程设计图。

三、请你局指导项目建设单位，根据上述意见进一步修改和完善所报方案，按程序另行报批。

国家文物局办公室

2017年12月29日
