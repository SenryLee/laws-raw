# 国家文物局办公室关于明十三陵万贵妃墓抢险加固项目的意见

办保函〔2017〕982号

北京市文物局：

你局《关于明十三陵万贵妃墓抢险加固工程设计方案的请示》（京文物〔2017〕703号）收悉。经研究，我局意见如下：

一、应进一步加强前期勘察和评估，科学确定明十三陵万贵妃墓园寝门、东西随墙门、内园寝门及园寝围墙的病害情况和发展趋势，论证险情级别和开展抢险加固项目的必要性和紧迫性。我局暂不同意所报明十三陵万贵妃墓抢险加固工程设计方案。

二、请你局指导昌平区人民政府进一步加强明十三陵万贵妃墓的日常管理和保护工作，做好墓园寝门、围墙等稳定性监测，严格控制可能影响文物本体稳定性的居民生产生活活动，并适时采取必要的临时性保护措施，确保文物安全。确实出现重大险情的，请抓紧编制专门的抢险加固方案，按程序报我局批准。

三、请你局指导昌平区人民政府进一步加强统筹规划，恰当处理明十三陵万贵妃墓本体保护与周边居民日常生产生活之间的关系，合理规划万贵妃墓的后续展示利用工作，充分发挥文物保护的社会效益。

国家文物局办公室

2017年8月22日
