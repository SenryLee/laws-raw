# 国家文物局关于万荣后土庙保护规划意见的函

文物保函〔2017〕1952号

山西省文物局：

你局《关于审批万荣后土庙文物保护规划的请示》（晋文物〔2016〕203号）收悉。经研究，我局意见如下：

一、原则同意所报万荣后土庙保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

1. 加强后土文化研究，厘清万荣后土庙的选址、空间格局、历史演变及文化活动空间等内容。在此基础上，进一步梳理文物构成，补充将香亭纳入文物本体的依据。

2. 完善文物现状评估及洪水影响评估，细化万荣后土庙宗教及民俗活动的现状评估，补充各文物建筑的时代信息、已实施保护工程的评估内容。

（二）关于保护区划与管理规定

1. 应根据文物保护管理需要，科学确定保护区划，补充完善建设控制地带分级和边界划定的依据。

2. 完善保护区划管理规定，明确保护范围内应拆除的非文物建筑以及对已有建筑的改造要求，如改造的规模、高度、层数、体量、样式和色彩等具体指标，细化建设控制地带的控制指标和要求等。

（三）关于保护措施

加强保护措施的针对性，细化、补充对原庙淹没区可能埋藏的遗迹遗物的保护措施。

（四）关于环境整治和专项规划

1. 进一步明确展示利用的目标、方式和内容，充分考虑对后土文化的阐释与展示，科学确定游客承载量。

2. 进一步完善防灾规划，补充大型活动疏散预案，明确民俗活动集散场地。

（五）校正、规范文本和图纸表达，加强图文对应性，地形剖面图应表达后土庙与黄河、汾河之间的地形关系。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的万荣后土庙文物保护规划报请山西省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体计划或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好万荣后土庙的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月7日
