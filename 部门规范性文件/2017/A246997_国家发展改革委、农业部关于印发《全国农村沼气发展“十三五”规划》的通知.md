# 国家发展改革委、农业部关于印发《全国农村沼气发展“十三五”规划》的通知

## 国家发展改革委 农业部关于印发《全国农村沼气发展“十三五”规划》的通知

发改农经〔2017〕178号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团发展改革委、农业（农牧、农村经济）厅（委、局），广西壮族自治区林业厅：

为贯彻落实党中央、国务院关于农村沼气工作的决策部署，进一步做好“十三五”时期的农村沼气转型升级工作，我们组织编制了《全国农村沼气发展“十三五”规划》，现印发给你们，请认真组织实施。

附件：全国农村沼气发展“十三五”规划

国家发展改革委

农业部

2017年1月25日
