# 农业部对十二届全国人大五次会议第1161号建议答复摘要

## 十二届全国人大五次会议第1161号建议答复摘要

中央高度重视培育新型农业经营主体。近年来的中央1号文件都对此提出了明确要求。2017年5月，中办、国办印发《关于加快构建政策体系培育新型农业经营主体的意见》，进一步明确了扶持新型农业经营主体的政策措施。为贯彻落实中央要求，农业部会同有关部门，整合各类扶持政策，不断改善新型农业经营主体发展的外部环境。大力培育各类服务组织，支持农业生产托管和服务规模经营发展，提高农业社会化服务能力。同时，实施新型职业农民培育工程，大力培养现代职业农民，不断提高农业经营者素质。

农业部

2017年8月17日
