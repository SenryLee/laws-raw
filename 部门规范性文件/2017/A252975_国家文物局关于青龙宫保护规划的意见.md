# 国家文物局关于青龙宫保护规划的意见

## 关于青龙宫保护规划的意见

办保函〔2017〕826号

河南省文物局：

你局《关于武陟青龙宫保护规划的请示》（豫文物〔2016〕189号）收悉。经研究，我局意见如下：

一、所报规划保护对象认定不清，价值评估和研究不足，规划深度不够，我局暂不同意所报青龙宫保护规划。

二、所报规划应做以下必要修改和完善：

（一）应进一步厘清文物构成和保护对象，梳理青龙宫历史沿革，客观评估青龙故居遗址的文物价值，明确与青龙宫之间的关系，说明将其纳入保护对象的必要性和依据，在此基础上确定文物构成清单。非物质文化遗产不宜纳入保护对象。

（二）深化历史价值评估。进一步完善现状评估，重点分析文物本体保存现状、周边环境情况和村落建设活动对文物的影响。补充非文物建筑、院落铺装、水体等对文物历史格局和环境的影响，以及现行保护区划与管理规定执行情况等评估内容。

（三）应根据文物实际情况和保护管理需要，科学调整保护区划及其具体边界。进一步完善保护区划管理规定，应对建设控制地带分类后分别制定相应管理规定，适当降低建筑限高，加强青龙广场及青龙宫西侧区域的控制力度，保护文物环境。

（四）增强现状评估结论与保护措施的对应性。

（五）应针对现状评估结论，细化环境整治内容，结合历史文化名村保护，加强青龙宫周边的环境整治，重点保护村落历史环境风貌；深化管理规划，增强民俗活动管理，制定必要的高峰时期人流控制和引导措施。进一步论证将青龙故居纳入展陈体系的必要性。

（六）应根据《全国重点文物保护单位保护规划编制要求》，进一步规范文本和图纸，说明性文字应纳入规划说明。

三、请你局指导有关单位，根据上述意见对青龙宫保护规划进行全面、认真的修改完善，按程序另行报批。

专此函复。

国家文物局

2017年7月6日
