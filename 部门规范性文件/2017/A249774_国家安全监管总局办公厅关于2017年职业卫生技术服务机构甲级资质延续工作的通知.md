# 国家安全监管总局办公厅关于2017年职业卫生技术服务机构甲级资质延续工作的通知

安监总厅安健函〔2017〕32号

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局，各有关单位：

按照国务院行政审批制度改革要求，为进一步简化审批环节，提高行政效能，根据国家安全监管总局有关工作安排，现将2017年职业卫生技术服务机构甲级资质延续工作有关事项通知如下：

一、延续对象

2017年甲级资质到期的42家职业卫生技术服务机构（以下简称甲级机构，名单见附件1）。

二、资质有效期限

2017年资质到期的甲级机构资质证书有效期限统一顺延至2017年12月31日。

三、工作程序

2017年甲级机构资质延续实行统一实验室检测能力和专业技术人员能力考核、集中材料申报、统一申请情况公示、集中资料审查和分类现场核查。具体工作程序如下：

（一）实验室检测能力考核。3月份开始，总局组织进行盲样考核（每个单位考核3个盲样，包括金属类、无机类和有机溶剂类），盲样检测结果报告同资质延续申报材料一并提交。盲样考核合格的，方可进行资质延续评审。2014～2016年连续三年参加实验室间比对综合判定结果未出现“基本合格”或“不合格”的（见附件1），可免于盲样考核。

（二）专业技术人员能力考核。总局统一对甲级机构从事职业卫生检测、评价工作的专业技术人员进行能力考核（考核要求详见附件2）。未经能力考核合格的人员，不得独立从事职业卫生检测、评价工作。专业技术人员能力考核具体安排另行通知。

（三）材料申报。各有关甲级机构按要求（见附件3）于2017年4月17日至4月28日将资质延续申报材料报送至总局政策法规司行政审批处。

总局根据各有关甲级机构申报业绩清单随机抽取4份技术服务报告（包括2份评价报告和2份检测报告），各有关甲级机构将被抽取的技术服务报告（包括报告书、相关过程材料及原始记录）复印件加盖公章后于2017年5月15日至5月21日寄送至总局职业健康司技术服务处。参加2016年度职业卫生技术服务机构评价能力验证结果为“优秀”的（见附件1），可免于报送评价报告（第二类业务范围的除外）。

（四）申请情况公示。总局对甲级机构资质延续申请情况统一进行技术评审前公示。公示期间有反映或举报申请单位弄虚作假或其他违法违规行为的，总局将对有关情况核实后依法处理。公示无问题的，按规定程序组织对申请单位进行技术评审。

（五）资料审查。总局职业健康司对各有关甲级机构申报材料进行形式审查，申报材料齐全的，组织专家对其提交的技术服务报告进行集中技术审查。

（六）现场核查。重点核查职业卫生工程、公共卫生和相关行业领域工程技术人员等专业技术人员数量和条件符合情况，工作场所和实验室面积、布局符合情况，仪器设备种类、数量和计量检定符合情况，人员培训、期间核查、内审和管理评审实施情况等。

2017年首次资质延续的甲级机构，由总局组织专家组按要求对其进行现场核查；非首次资质延续的甲级机构，由机构所在地省级安全监管局按要求对其进行现场核查，并填写《甲级机构资质延续现场核查表》（见附件4）。

（七）综合评判。总局职业健康司根据对申报材料技术审查、现场核查和整改等情况，提出是否批准其职业卫生技术服务机构甲级资质延续的建议意见，按程序完成审批后，核准其资质延续并换发资质证书。

四、工作要求

（一）认真准备。各有关甲级机构要认真做好延续准备工作，按时提交申报材料，积极配合做好现场核查工作。总局职业健康司将组织有关省级安全监管局职业卫生技术服务机构监管工作职能处室负责同志和职业卫生专家进行2017年甲级资质延续工作指导培训，安排布置资质延续工作，明确工作程序和标准。

（二）严格程序。要严格按照程序开展甲级机构资质延续工作。在资料审查和现场核查过程中，要按要求对各项内容进行评审，详细记录存在问题。现场核查结束后，要向被核查机构主要负责人反馈意见，由机构主要负责人在现场核查表上确认签字并加盖单位公章。

各有关省级安全监管局按要求对非首次延续甲级机构进行现场核查后，请于2017年7月10日前将现场核查结果（含现场核查表）报送总局职业健康司。各有关甲级机构应当对考核发现问题进行认真整改，并将整改报告报送所在地省级安全监管局和总局职业健康司。

（三）严格标准。本次甲级机构资质延续的条件、标准要严格按照职业卫生技术服务机构资质认可现行规定执行，经技术评审不满足资质条件或发现技术服务能力达不到要求的，由总局依法依规取消其甲级资质或核减其业务范围；发现存在违法违规行为的，由机构所在地省级安全监管局实施行政处罚。

（四）廉洁自律。实验室检测能力考核、专业技术人员能力考核以及总局派出的首次资质延续甲级机构现场核查所需费用由总局统一承担。各有关甲级机构要严格遵守中央八项规定精神和党风廉洁建设有关规定。违反廉洁建设规定的，立即终止现场核查。专家有违反廉洁建设规定的，按照《国家安全监管总局职业卫生专家管理办法》（安监总厅安健〔2012〕49号）有关规定处理。
