# 国家文物局关于朝天宫建设控制地带内仓巷和木屐巷道路改造工程的意见

文物保函〔2017〕1984号

江苏省文物局：

你局《关于审批秦淮区仓巷和木屐巷道路改造工程方案设计的请示》（苏文物保〔2017〕231号）收悉。经研究，我局意见如下：

一、原则同意在朝天宫建设控制地带内开展南京市秦淮区仓巷和木屐巷道路改造工程和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）进一步细化工程减震措施和相关指标，减少工程对地层的扰动。

（二）针对燃气管道施工及使用过程中可能产生的泄露、爆燃、地面沉降等问题，补充制定严格的施工保障措施和应急预案，确保文物安全。

（三）补充道路景观设计的相关内容，使之与朝天宫文物建筑风貌相协调，道路改造应注意近代城市设施遗存，不得对两侧建筑造成负面影响。

（四）请你局组织专业考古研究单位，在项目拟建区域进一步开展必要的考古调查和发掘工作。遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》第十八条的有关规定报城乡建设规划部门批准后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局

2017年12月11日
