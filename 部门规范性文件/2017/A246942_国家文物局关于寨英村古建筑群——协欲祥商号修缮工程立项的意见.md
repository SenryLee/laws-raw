# 国家文物局关于寨英村古建筑群——协欲祥商号修缮工程立项的意见

## 关于寨英村古建筑群——协欲祥商号修缮工程立项的意见

办保函〔2017〕22号

贵州省文物局：

你局《关于送审〈寨英村古建筑群·协欲祥商号修缮工程立项报告〉的请示》（黔文物呈〔2016〕99号）收悉。经研究，我局意见如下：

一、寨英村古建筑群规模较大，文物类型多样，应根据文物保存现状和病害程度，结合文物展示利用和地方经济社会发展需要，区分轻重缓急，有序开展寨英村古建筑群保护工作。

二、应根据《寨英村古建筑群保护规划》的原则和要求，进一步明确“十三五”期间保护维修工作的整体思路和目标，系统梳理寨英村古建筑群已实施文物保护工程情况，客观评估工程效果，综合考虑文物保护、民生改善和地方社会经济发展问题，增强工作的计划性、科学性。

三、暂不同意寨英村古建筑群——协欲祥商号修缮工程。应进一步明确协欲祥商号修缮工程与寨英村古建筑群保护利用工作中的关系，建议现阶段重点做好我局已批复项目的实施，确保工程质量。待项目取得阶段性成果后，再行开展其它文物建筑的保护修缮工作。

专此函。

国家文物局

2017年1月13日
