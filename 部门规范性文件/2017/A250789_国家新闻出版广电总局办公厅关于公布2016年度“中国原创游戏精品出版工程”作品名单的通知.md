# 国家新闻出版广电总局办公厅关于公布2016年度“中国原创游戏精品出版工程”作品名单的通知

## 关于公布2016年度“中国原创游戏精品出版工程”作品名单的通知

新广出办发〔2017〕26号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央军委政治工作部宣传局，有关游戏出版服务单位、游戏企业：

2016年11月，国家新闻出版广电总局发出《关于实施 “中国原创游戏精品出版工程”的通知》（新广出办发〔2016〕98号），决定组织实施“中国原创游戏精品出版工程”(以下简称“游戏精品工程”)。经各省级新闻出版广电部门申报推荐，国家新闻出版广电总局组织论证评审，并向社会公示，2016年度“游戏精品工程”作品揭晓，从17个省（自治区、直辖市）87家游戏出版服务单位、游戏企业申报的173款作品中，最终确定《列王的纷争》、《球球大作战》、《放开那三国2》等30款作品为2016年度“游戏精品工程”作品，现予公布。

为实现“游戏精品工程”目标任务，各级新闻出版广电部门要按《关于实施 “中国原创游戏精品出版工程”的通知》要求，切实加大扶持力度，积极落实扶持措施。有关游戏出版服务单位、游戏企业，要确保2016年度“游戏精品工程”作品质量，认真做好出版运营工作；要进一步提高精品意识，主动弘扬优秀文化，总结成功经验多出精品，为游戏产业健康繁荣发展做出更大贡献。

附件：2016年“中国原创游戏精品出版工程”作品名单

国家新闻出版广电总局办公厅

2017年5月1日
