# 国家文物局办公室关于北五省会馆保护规划意见的函

办保函〔2017〕1430号

湖南省文物局：

你局《关于审批湖南省湘潭市北五省会馆文物保护规划的请示》（湘文物报〔2016〕143号）收悉。经研究，我局意见如下：

一、所报规划总体内容尚有欠缺，与《全国重点文物保护单位保护规划编制要求》存在差距，我局暂不同意北五省会馆保护规划。

二、所报规划应做以下必要修改和完善：

（一）进一步梳理保护对象。应在准确认识真实性概念的基础上认定文物本体，1980年代重建的钟鼓楼、牌坊、厢房等不应认定为文物本体；应补充对历史环境的认定，建议将与北五省会馆相关联的历史建筑纳入历史环境要素。

（二）进一步完善现状评估。合理判定文物建筑残损级别，应分别评估后殿、商会、客房等文物建筑；细化灾害评估，明确灾害强度、频率及对文物本体的影响程度，为制定相应的规划措施提出科学依据；补充对现行保护区划的评估。

（三）进一步细化、规范保护区划管理规定。应严格限制保护范围内展陈设施建设的强度，禁止对文物风貌产生不利影响；应增强建设控制的强制性要求，严格控制建筑总高，“檐口高度不超过14米、与文物建筑之间保持1米以上安全距离”等要求过于宽松，应补充建筑密度、容积率等控制指标。

（四）进一步梳理保护措施。应按照《文物保护工程管理办法》明确保护工程性质、工程范围和控制要求。保护措施应与评估结论对应，并厘清其与管理措施的区别。

（五）进一步完善专项规划。应明确游客服务中心、管理中心等具体位置，补充选址的可行性分析；应在管理规划中细化对民俗活动的管理要求；按百年一遇的防洪标准设防的必要性不足。

（六）进一步明确规划衔接。应厘清文物保护规划与历史街区保护规划二者在范围、规划内容、规划目标等方面的区别。

（七）进一步完善规划文本，规范规划图纸。目前规划范围内的图纸深度不足，与规划文本对应性不强。应补充必要的卫星影像图、周边环境评估图、用地性质调整图、保护规划总图等。精炼文本，不宜用大量评估表格代替评估结论。

三、请你局指导有关单位，根据上述意见对北五省会馆保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月26日
