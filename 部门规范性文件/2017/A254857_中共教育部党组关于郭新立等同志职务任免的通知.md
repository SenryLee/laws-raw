# 中共教育部党组关于郭新立等同志职务任免的通知

教党任〔2017〕170号

中共山东大学委员会：

经与中共山东省委商得一致，2017年7月11日研究决定：

郭新立同志任中共山东大学委员会委员、常委，樊丽明同志任中共山东大学委员会委员、常委、副书记；免去李守信同志的中共山东大学委员会常委，张荣同志的中共山东大学委员会副书记、常委、委员职务。

中共教育部党组

2017年8月1日
