# 农业部对十二届全国人大五次会议第5840号建议的答复

## 对十二届全国人大五次会议第5840号建议的答复

农办议〔2017〕46号

费聿玲代表：

您提出的关于支持黑河市大豆产业发展的建议收悉。经商国家发展改革委、财政部、食品药品监管总局，现答复如下。

一、关于完善大豆目标价格改革试点配套制度

根据党中央、国务院决策部署，国家于2014年取消大豆临时收储政策，启动了为期三年的东北三省和内蒙古自治区大豆目标价格改革试点。按照试点方案规定，中央财政根据国家统计局统计的试点省份大豆产量和国家发展改革委监测的分省市场价格与目标价格的价差，测算分配分省补贴资金。大豆的目标价格水平综合考虑粮食供求平衡、农民种植基本收益、中央财政承受能力、产业链协调发展等因素，每年确定一次，近年来都确定为4800元/吨。总体看，大豆目标价格改革取得了一定成效，实现了大豆价格由市场供求形成，较好地保护了农民利益，遏制了大豆生产快速下滑势头，减轻财政负担，但同时也面临着监测价格与市场价格不一致、大豆非主产区面积核实难度大、操作成本高等问题。为贯彻落实2017年中央1号文件精神，经国务院批准，自2017年起调整大豆目标价格政策，实行市场化收购加补贴的新机制，国家对大豆生产给予补贴。中央财政对东北三省和内蒙古自治区给予一定补贴，由地方政府将补贴资金兑付到大豆生产者。

二、关于强化大豆农产品市场监管

农业部、食品药品监管总局等部门高度重视大豆及大豆生产食品的质量安全监管工作。依据《农业转基因生物标识管理办法》和《农业转基因生物标签的标识》国家标准，我国对转基因大豆、玉米、油菜、棉花、番茄等5类作物17种产品实行按目录定性标识，凡是列入标识管理目录并用于销售的农业转基因生物，必须进行标识。近年来，农业部严格督查检查，督促省级农业行政主管部门按照属地管理，协调配合食品药品监管、工商管理等部门，加强对转基因农产品的标识监管，对发现市场销售转基因大豆、大豆油应当标识但未按要求标识的违法违规行为依法进行查处。从督查情况看，转基因农产品标识良好，基本做到了应标尽标。标识与安全性无关，主要是满足消费者的知情权和选择权。

三、关于支持开展专用品种生产

农业部高度重视黑河市大豆专用品种选育推广，自2014年起组织了大豆良种重大科研联合攻关，并在黑河市等大豆主产区进行展示示范，累计展示示范面积超过100万亩。组织对300个新品种分生态区统一进行适应性、丰产性、抗逆性、品质以及适应机械化作业等性状的试验，选育了一批苗头性大豆优良品种，在黑龙江赵光农场、建设农场等第四积温带选拔出综合性状较好、亩产200千克以上的品种11个，其中“黑河43”平均亩产达243.6千克，这批品种将为黑龙江调减玉米面积、恢复大豆生产发挥积极作用。2017年1月，农业部认定了包括黑河市下辖的北安市和五大连池市2个大豆良繁基地在内的49个区域性良种繁育基地。下一步，农业部将继续深入推进大豆良种联合攻关，并将依托黑龙江省农业科学院黑河分院等单位，在东北等大豆主产区设立苗头品系测试试验示范点，对优质大豆新品种、新品系进行综合生产能力测试和示范，开展优质食用大豆及配套栽培技术大面积高产示范。通过实施现代种业提升工程，对已认定的大豆区域性良繁基地建设加大支持力度。

另外，农业部高度重视农作物品种生产与市场对接工作，依托中国农业科学院成立了国家科技成果产权交易中心，并与黑龙江龙科种业科技成果产权交易有限公司开展了初步合作，向全国广泛征集种业科技成果937条，促进了种业科技成果实时转化推广。下一步，农业部将继续推进国家科技成果产权交易中心工作，整合有关种业数据信息，构建种业大数据平台，促进包括大豆在内的农作物品种与市场有序对接。

四、关于加大对黑河优质食用大豆生产支持力度

农业部会同有关部门，认真贯彻落实党中央、国务院决策部署，着力调整优化种植结构，积极发展大豆生产，提升大豆生产质量效益和竞争力。

一是积极促进大豆生产发展。农业部制定印发《关于促进大豆生产发展的指导意见》，提出以市场需求为导向，重点发展高蛋白大豆，满足食用大豆消费需求，保持东北优势区油用大豆生产能力。2016年，农业部会同财政部，整合中央财政资金7.5亿元，在东北地区开展粮豆轮作试点500万亩，以玉米大豆轮作为主，增加优质食用大豆供给。2017年将轮作试点面积扩大到1000万亩。组织专家分区域、分作物制定结构调整技术意见，组织开展技术培训，引导农民改变种植习惯，掌握相应栽培技术。加强区域间和品种间余缺调剂，满足种植结构调整需要。同时，指导地方做好结构调整所需农机的改装配套。

二是支持黑河市开展耕地质量保护与提升等工作。2015年以来，中央财政每年安排5亿元专项资金，支持包括黑河市在内的试点地区开展黑土地保护利用试点。通过实施《全国高标准农田建设总体规划（2011-2020年）》《全国新增1000亿斤粮食生产能力规划（2009-2020年）》《国家农业综合开发高标准农田建设规划（2011-2020年）》等，支持黑河市建设集中连片、旱涝保收、稳产高产、生态友好的高标准农田，组织实施耕地保护与质量提升工程，不断夯实大豆生产的耕地质量基础。

三是支持黑河市建设大豆生产保护区。2017年3月，国务院印发《关于建立粮食生产功能区和重要农产品生产保护区的指导意见》（国发〔2017〕24号），全面启动粮食生产功能区和重要农产品生产保护区（以下统称“两区”）划定和建设工作，并要求黑龙江省等大豆主产区划定1亿亩大豆生产保护区。农业部将会同有关部门，认真贯彻落实国发〔2017〕24号文件要求，统筹支持黑河市划定和建设大豆生产保护区，同时，把“两区”作为农业固定资产投资安排的重点领域，安排高标准农田、大中型灌区续建配套及节水改造等农业基础设施建设投资向“两区”倾斜。

五、关于加大对大豆主产区加工企业支持力度

2014年以来，国家主要通过实施大豆目标价格政策，理顺大豆产业链上下游价格关系，支持促进包括大豆加工企业在内的全产业链协调发展。大豆市场价格已从2014年的4700元/吨左右下降至目前的3700元/吨左右，大幅降低了大豆加工企业的生产成本。而且，大豆加工行业属于竞争性领域，国家不宜给予加工企业过多补贴政策，以更好地使市场在资源配置中发挥决定性作用，维护公平竞争的市场环境。

根据中央财政涉农资金整合改革的要求，从2017年起，农产品产地初加工补助政策将纳入中央财政农业生产发展资金项目农村一二三产业融合发展支出方向，并覆盖全国所有省份。黑龙江省可使用中央财政分配给本省的农业生产发展项目等资金，结合实际，支持本省符合条件的大豆加工流通企业建设农产品产地初加工设施。

感谢您对农产品加工事业发展的关心，希望继续对我部工作给予支持。
