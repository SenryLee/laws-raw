# 国家邮政局普遍服务司关于《中国共产党第十九次全国代表大会》纪念邮票发行日期等相关事宜的通知

## 关于《中国共产党第十九次全国代表大会》纪念邮票发行日期等相关事宜的通知

局普函〔2017〕23号

中国邮政集团公司邮票发行部：

经研究，现将《中国共产党第十九次全国代表大会》纪念邮票发行日期等相关事宜通知如下：

一、2017年纪特邮票发行计划中《中国共产党第十九次全国代表大会》纪念邮票发行日期确定为2017年10月18日。

二、经商中国社会科学院等有关部门，决定将我局下达的2018年第一批纪念邮票选题中（国邮发[2017]69号）《近代民族英雄》纪念邮票确定为一套5枚，表现内容分别为：1.林则徐；2.关天培；3.刘永福；4.冯子材；5.邓世昌。

林则徐以虎门销烟、奋力抗英而闻名中外，成为一代名臣、民族英雄，为后人称颂；关天培镇守虎门要塞，面对英军猛攻，仍死守阵地，顽强抵抗，终因援军未至，被枪弹击中，壮烈殉国；刘永福曾援越抗法，赴台抗日，在十九世纪末扛起了反“****”的大旗；冯子材在中越边境的前隘一战歼灭入侵国境的法军主力，取得了震惊中外的镇南关大捷；邓世昌是近代著名海军将领，甲午中日战争时为致远号巡洋舰管带，在1894年9月17日海战中捐躯报国。

请据此做好相关工作。

国家邮政局普遍服务司

2017年9月5日
