# 国家粮食局办公室关于调整全国粮食职业教育教学指导委员会（2015-2019年）组成人员的通知

国粮办人〔2017〕85号

各省、自治区、直辖市及新疆生产建设兵团粮食局，中国储备粮管理总公司、中粮集团有限公司，河南工业大学、南京财经大学、武汉轻工大学，国家粮食局机关各司室，直属单位、联系单位：

根据《全国粮食职业教育教学指导委员会章程》和工作需要，经国家粮食局领导同意，现就调整全国粮食职业教育教学指导委员会（以下简称粮食教指委）组成人员通知如下：

聘任中国粮食研究培训中心主任颜波为粮食教指委副主任委员，中国粮食研究培训中心副主任唐柏飞为粮食教指委秘书长。任期至2019年12月31日止。

中国粮食研究培训中心原副主任刘力不再担任粮食教指委副主任委员兼秘书长。

国家粮食局办公室

2017年4月26日
