# 国家文物局关于岩门长官司城保护规划意见的函

文物保函〔2017〕1923号

贵州省文物局：

你局《关于送审〈岩门长官司城保护规划（2016-2030）〉的请示》（黔文物呈〔2017〕38号）收悉。经研究，我局意见如下：

一、原则同意所报岩门长官司城保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

1. 深化岩门长官司城的整体研究，厘清其历史格局演变过程，明确新、旧司城的关系。从民族关系及军事功能等方面进一步完善价值评估。

2. 进一步完善文物现状评估，深化衙署等建筑遗址的评估内容。补充平寨航电枢纽工程对文物的影响评估，并制定相应规划措施。

（二）关于保护区划与管理规定

1. 应根据文物保护管理需要，科学划定保护区划。进一步论证保护范围内新建展示、管理设施的必要性，并限定其选址和规模。明确建设控制地带的范围和分类。

2. 根据不同用地性质进一步细化管理规定。

（三）关于保护措施

应根据《文物保护工程管理办法》，细化、完善文物保护措施，明确工程性质、类型，加强针对性。

（四）关于环境整治和专项规划

1. 应根据现状评估对规划范围内各类建设活动拟定针对性的整治措施，并补充河道治理措施。

2. 建议补充文物所在两县管理协调机制。

3. 补充考古规划，并明确规划目标、内容和技术路线。

4. 充分考虑文物的活化利用及服务民众的方式，补充社会调控规划。

（五）加强所报规划与相关规划的衔接内容。

（六）规范文本和图纸表达，校正、统一图例，加强图文对应性。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的岩门长官司城保护规划报请贵州省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体工作计划或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好岩门长官司城的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

专此函复。

国家文物局

2017年11月30日
