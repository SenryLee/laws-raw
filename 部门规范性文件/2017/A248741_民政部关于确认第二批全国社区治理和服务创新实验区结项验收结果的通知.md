# 民政部关于确认第二批全国社区治理和服务创新实验区结项验收结果的通知

民函〔2017〕10号

各省、自治区、直辖市民政厅（局），新疆生产建设兵团民政局：

2016年以来，根据《民政部办公厅关于做好2016年全国社区治理和服务创新实验区工作的通知》（民办函〔2016〕40号）要求，民政部启动第二批全国社区治理和服务创新实验区结项验收工作。经过实验区自我评估、省级部门审核、第三方验收组材料审核和实地验收等工作程序，现确认北京市东城区、朝阳区，天津市和平区，河北省承德市双滦区，内蒙古自治区包头市青山区、二连浩特市，辽宁省大连市沙河口区，黑龙江省哈尔滨市南岗区，上海市徐汇区、杨浦区、浦东新区，江苏省南京市玄武区、雨花台区、常州市天宁区、苏州工业园区，浙江省嘉兴市秀洲区新塍镇，福建省厦门市，山东省青岛市黄岛区，湖北省武汉市武昌区、黄石市，湖南省长沙市开福区、雨花区，广东省广州市越秀区、南沙区、深圳市罗湖区、坪山新区、佛山市南海区，重庆市渝中区，四川省成都市成华区，云南省昆明市盘龙区，新疆生产建设兵团石河子市等31个实验区圆满完成各项实验任务，结项验收结果为“合格”。

各省级民政部门要继续指导上述单位深入贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神，紧紧围绕中央关于加强和完善社区治理的目标任务，健全完善党领导下的社区治理体系，不断提升社区治理水平，为扎实推进社区治理现代化和深化基层社会体制改革提供鲜活样板。

民政部

2017年1月18日
