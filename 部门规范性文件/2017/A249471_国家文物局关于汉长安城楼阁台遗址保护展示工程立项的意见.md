# 国家文物局关于汉长安城楼阁台遗址保护展示工程立项的意见

## 关于汉长安城楼阁台遗址保护展示工程立项的意见

办保函〔2017〕372号

陕西省文物局：

你局《关于上报汉长安城楼阁台遗址保护展示工程立项的请示》（陕文物字〔2017〕28号）收悉。经研究，我局意见如下：

一、暂不同意汉长安城楼阁台遗址保护展示工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步明确本体保护工程实施的可行性，应首先清退占压遗址的现代坟和建筑，为工程实施提供保障。

（二）补充保护规划对楼阁台遗址的规划措施和相关要求，进一步明确遗址的展示条件，评估展示前景，论证展示工程的必要性和可行性。

（三）进一步加强遗址的考古和研究工作，为保护工程提供科学依据。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年4月1日
