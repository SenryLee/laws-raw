# 国家文物局关于在桐城文庙保护范围内进行公厕异地重建项目的意见

文物保函〔2017〕1374号

安徽省文物局：

你局《关于审批桐城文庙公厕异地重建方案的请示》（皖文物保〔2017〕56号）收悉。经研究，我局意见如下：

一、原则同意在桐城文庙保护范围内进行公厕异地重建项目和你局意见。

二、对所报方案提出如下修改意见：

（一）该工程位于全国重点文物保护单位桐城文庙保护范围内，应严格遵守《中华人民共和国文物保护法》和安徽省人民政府关于桐城文庙保护区划的相关管理规定，严格控制工程范围和工程强度，合理改善文物环境。

（二）应优化方案设计，进一步完善拟建厕所的立面效果和屋面比例等，适当缩小建筑体量，确保厕所建筑与桐城文庙文物建筑本体及环境相协调。

（三）进一步规范文本与图纸，完善图纸尺寸标注，补充文物建筑和院落环境现状照片。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，按程序报批准后实施。施工中请加强工程监管，确保文物及历史环境安全。

国家文物局

2017年8月8日
