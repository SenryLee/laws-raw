# 国家文物局关于瞿塘峡摩崖石刻文物保护管理设施建设方案的意见

文物保函〔2017〕1800号

重庆市文物局：

你局《关于报送瞿塘峡摩崖石刻文物保护管理设施建设设计方案的请示》（渝文物〔2017〕222号）收悉。经研究，我局意见如下：

一、原则同意瞿塘峡摩崖石刻文物保护管理设施项目和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）进一步补充完善现状勘察内容，明确实施方案与现状已有措施之间的关系。

（二）加强对该地区地质滑坡破坏威胁的评估并提出针对性措施。若确需加固，应由具备相关资质的专业单位制定科学加固方案，并尽量避免人工化；若坡体状态稳定，不宜过多干预坡体状态，应取消护坡整理措施。

（三）进一步优化地面铺装、栏杆、景点介绍牌等设计，确保与摩崖石刻整体环境相协调。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《文物保护法》第十七条、第十八条规定分别报送重庆市人民政府和城乡建设规划部门批准后实施。

四、请你局切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

专此函复。

国家文物局

2017年10月30日
