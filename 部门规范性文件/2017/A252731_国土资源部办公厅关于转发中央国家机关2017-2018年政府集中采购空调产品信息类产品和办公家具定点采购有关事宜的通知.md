# 国土资源部办公厅关于转发中央国家机关2017-2018年政府集中采购空调产品信息类产品和办公家具定点采购有关事宜的通知

国土资厅函〔2017〕1088号

各预算单位：

根据国务院办公厅有关文件要求及规定，中央国家机关政府采购中心通过公开招标方式确定了2017年空调产品协议供货商、2017-2018年信息类产品协议供货商、2017-2018年办公家具定点企业，并印发了《关于中央国家机关2017-2018年政府集中采购空调产品有关事宜的通知》（国机采〔2017〕8号）、《关于中央国家机关2017-2018年政府集中采购信息类产品有关事宜的通知》（国机采〔2017〕9号）、《关于中央国家机关2017-2018年办公家具定点采购有关事宜的通知》（国机采〔2017〕11号），现转发给你们，请遵照执行。

2017年7月12日

附件：《关于中央国家机关2017-2018年政府集中采购空调产品有关事宜的通知》等
