# 国家文物局关于重庆白鹤梁题刻水下保护体交通廊道外防撞设施工程初步设计方案意见的函

## 关于重庆白鹤梁题刻水下保护体交通廊道外防撞设施工程初步设计方案意见的函

办保函〔2017〕760号

重庆市文物局：

你局《关于报审重庆白鹤梁题刻水下保护体交通廊道外防撞设施工程初步设计报告的请示》（渝文物〔2017〕135号）收悉。经研究，我局意见如下：

一、暂不同意重庆白鹤梁题刻水下保护体交通廊道外防撞设施工程初步设计方案。

二、所报方案尚需做以下必要的修改和完善：

（一）应重新论证“趸船防撞体”与“双平台框架结构防撞体”的优劣，并在此基础上进一步优化技术路线，充分考虑白鹤梁题刻水下保护体及交通廊道的本体安全、工程对景观环境的影响，以及后续运行维护成本等因素，科学、合理地确定防撞设施设计思路和技术路线。

（二）采用“趸船防撞体”方案时，应在确保功能需求的前提下，将趸船布设与游客参观游览路线相结合，进一步改善参观体验。

（三）采用“双平台框架结构防撞体”方案时，应优化水平面防撞体的具体设计，论证斜坡面设置防撞体的必要性，补充必要的数据计算和模拟实验，在确保功能效果的基础上，进一步缩减水平面防撞体的宽度，避免影响周边景观。同时，应考虑防撞体耐久性问题，提出具体解决方案。

（四）补充防撞预警预报系统建设具体设计。

三、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改和完善，经你局核准后，按程序另行报批。

国家文物局

2017年6月16日
