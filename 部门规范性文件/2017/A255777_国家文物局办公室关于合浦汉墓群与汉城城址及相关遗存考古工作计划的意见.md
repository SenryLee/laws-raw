# 国家文物局办公室关于合浦汉墓群与汉城城址及相关遗存考古工作计划的意见

办保函〔2017〕1069号

广西壮族自治区文化厅：

你厅《关于报送合浦汉墓群与汉城城址及相关遗存考古工作计划（2017-2021年）的请示》（桂文物报〔2017〕45号）收悉。经研究，我局意见如下：

一、暂不同意所报合浦汉墓群与汉城城址及相关遗存考古工作计划。该计划应明确以探究北部湾地区“海上丝绸之路”重要遗存的分布、构成、性质与价值为主要目标，为研究北部湾地区在“海上丝绸之路”发展过程中的地位、作用及变化动因提供支撑。

二、该计划应做以下调整、完善：

（一）重点开展南柳江流域、北部湾沿岸和附近海域水下调查。调查工作应结合研究课题，合理确定工作区域，搞清流域内次级聚落与中心城址、内水与沿海港口等相互关系和发展规律，水下考古调查应结合陆地调查的线索，进一步明确调查范围及方式，细化具体工作方案。

（二）大浪古城、草鞋村遗址应开展系统性考古调查、勘探，尽快搞清遗址格局和路网、水系分布情况，不同意大面积发掘、揭露重要遗迹。合浦汉墓群考古工作应集中做好以往考古资料的整理和报告编写工作；考古勘探应充分评估安全性和必要性；在明确国家考古遗址公园的展示对象和具体展示方式前，暂不进行考古发掘。

（三）暂不开展遥感考古工作。应进一步细化地理信息系统与数据库建设方案，充分利用已有航片、地图等资料，不得重复购置搭建系统所需软硬件设备。

（四）应切实做好考古工作与世界文化遗产申报工作的沟通、协调，统筹考虑考古、研究、世界文化遗产申报、大遗址保护和国家考古遗址公园建设等问题。

（五）应进一步确定人员队伍，积极吸纳相关专业机构力量，并明确各方责任。

三、请你厅指导有关单位尽快明确项目负责人和参与人员，根据以上意见进一步调整、完善考古工作计划，按程序另行报批。

国家文物局办公室
