# 国家文物局关于苑陵故城遗址公园西门入口及东门入口建设项目选址意见的函

## 关于苑陵故城遗址公园西门入口及东门入口建设项目选址意见的函

办保函〔2017〕761号

河南省文物局：

你局《关于报批苑陵故城遗址公园西门入口建设项目设计方案的请示》（豫文物〔2017〕179号）和《关于报批苑陵故城遗址公园东门入口建设项目设计方案的请示》（豫文物〔2017〕180号）收悉。经研究，我局意见如下：

一、所报方案的设计思路不当，项目建设的必要性不足，我局暂不同意苑陵故城遗址公园西门入口和东门入口建设项目涉及苑陵故城保护范围的选址及建设方案。

二、应根据苑陵故城整体保护展示和园博园建设需要，统筹考虑节点设计和西门、东门入口建设方式，坚持最小干预原则，最大程度地保护遗址的真实性和完整性，以及遗址区的历史景观环境，营造庄严肃穆的遗址氛围。

三、请你局指导建设单位调整、完善设计方案，并按程序另行报批。

国家文物局

2017年6月16日
