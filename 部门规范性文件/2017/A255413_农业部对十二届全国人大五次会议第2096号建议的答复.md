# 农业部对十二届全国人大五次会议第2096号建议的答复

## 对十二届全国人大五次会议第2096号建议的答复

农办议〔2017〕183号

潘建华等10名代表：

你们提出的“关于大力支持东部沿海地区现代农业龙头企业发展，促进食品安全的建议”收悉。经商国家发展改革委、财政部、商务部、交通运输部，现答复如下。

农业产业化是现代农业发展的方向，龙头企业是推进农业产业化经营的关键，是促进农村一二三产业融合发展的引领力量。多年来，党中央、国务院高度重视，加大政策扶持，强化指导服务，推进龙头企业实现快速健康发展。目前，全国各类龙头企业13万家，年销售收入达9.7万亿元，以龙头企业为主体的各类农业产业化经营组织辐射带动农户1.27亿户，为保障我国重要农产品有效供给、促进现代农业建设和农民增收发挥了重要作用。你们提出的建议对于更好促进龙头企业发展具有重要参考价值。

一、关于支持龙头企业建设食用农产品标准化原料生产基地

农业标准化是规范农业生产和保障消费安全的有效措施。我部严格贯彻落实《标准化法》《农产品质量安全法》《农药管理条例》《兽药管理条例》等法律法规，组织编制并加快落实《农药残留标准体系工作方案（2015-2020年）》《兽药残留标准体系工作方案（2017-2025年）》《食品安全国家标准食品中农药最大残留限量》《动物性食品中兽药最高残留限量》，积极推进农业标准化各项工作任务。

你们提到的农产品标准化原料基地建设，其作为龙头企业的“第一车间”，对于企业获得稳定、优质、安全的原料，提高农产品质量安全水平具有重要意义。财政部2016年农业产业化发展项目通过贷款贴息、财政补助等方式，共投入中央财政资金60多亿元，加大对农民合作社、龙头企业等新型农业经营主体的支持力度，建设了一批区域优势特色明显、示范带动作用强的种养殖基地、农产品加工、流通服务设施等产业发展项目。我部“十二五”期间创建园艺作物标准园、热带作物标准化生产示范园、畜禽养殖标准化示范场和水产健康养殖示范场10059个；积极推进“三品一标”发展，目前全国有效无公害农产品产地超过3.5万个，绿色食品原料标准化生产基地696个，有机农业示范基地24个，农产品地理标志示范基地20个，规模化、标准化、集约化原料基地规模稳步扩大。同时，以龙头企业和农民合作社为主体，依靠当地政府主导推动，以核心示范区建设为重点，指导各地创建了标准化示范县185个。

今年3月，我部印发了《“十三五”全国农产品质量安全提升规划》，明确提出将继续开展农业标准化示范区（县）创建和园艺作物、畜禽水产养殖、畜禽屠宰加工标准化示范创建，鼓励各地因地制宜创建农业标准化生产示范园（区）、示范乡（镇）、示范场（企业、合作社），推进新型农业经营主体和农业示范园（区）率先实行标准化生产，通过“公司+农户”“农民合作社+农户”等多种方式发展规模经营，带动千家万户走上规范安全生产轨道。

二、关于支持龙头企业完善食用农产品生产过程检验检测

强化农产品生产过程中的检验检测、构建农产品质量安全追溯体系，有助于落实生产经营主体责任和增强食用农产品消费信心。国务院2012年印发的《关于支持农业产业化龙头企业发展的意见》（国发〔2012〕10号）明确提出，龙头企业要大力推进标准化生产，建立健全投入品登记使用管理制度和生产操作规程，完善农产品质量安全全程控制和可追溯制度。目前，在1.6万多家省级以上重点龙头企业中，超过6成的建有专门质检机构，超过7成的通过ISO9000、HACCP等质量体系认证，超过一半的获得省以上名牌产品或著名（驰名）商标。商务部自2010年以来，会同财政部在全国58个城市开展了肉类蔬菜流通追溯体系建设试点，支持试点城市围绕肉类蔬菜流通主渠道，建设覆盖屠宰、批发、超市、农贸市场、团体采购单位等城市肉菜主要流通节点的信息化追溯体系。其中，山东、江苏、浙江、福建、广东、海南等东部沿海六省共有16个城市成为试点单位。这些地区的龙头企业积极参与追溯体系建设试点，构建从种养殖源头到流通终端的全过程追溯体系。2015年底国务院办公厅印发了《关于加快推进重要产品追溯体系建设的意见》（国办发〔2015〕95号），2017年初商务部、农业部等七部门联合印发了《关于推进重要产品信息化追溯体系建设的指导意见》（商秩发〔2017〕53号），对支持大型龙头企业参与追溯体系建设提出了具体要求。下一步，商务部将继续支持有条件的大型龙头企业和大型流通企业，参与重要产品追溯体系建设，构建全过程质量安全追溯链条，强化食用农产品安全保障能力。

关于你们提到的建设一批区域性农畜水产品检验检测机构的建议，2007年以来国家发展改革委先后批复了我部编制的《全国农产品质量安全检验检测体系建设规划（2006-2010年）》和《全国农产品质量安全检验检测体系建设规划（2011-2015年）》。截至2016年，共安排投资130亿元（其中中央投资93亿元），建设了部、省、地、县质检机构2770个，加上各地自己建设的农产品质检机构，总数达到3332家，检测人员达3.5万人,实现了农产品检测体系建设地市全覆盖和县级基本覆盖。同时，我部制定出台了《关于加强农产品质量安全检验检测体系建设与管理的意见》（农质发〔2014〕11号），指导各地强化专业技术队伍建设，严格检验检测机构管理，并加大督导检查力度，确保质检体系建设项目落到实处、发挥实效。下一步，我部将进一步加强农产品质量安全检验检测体系建设和管理。一是加快项目建设进度，督促各地在建项目尽快完工；二是推动基层检验检测机构资质认定工作，确保已建成的质检机构取得合法资质，及时开展工作；三是加强培训，提高检验检测人员能力；四是继续争取财政支持，加大检验检测经费投入力度，扩大监测范围；五是加大检测技术能力验证考核力度，确保检得出、检得准，为农产品质量安全监管提供有力支撑。

三、关于支持龙头企业强化食用农产品储运环节控制保障

建立顺畅、便捷的鲜活农产品流通网络对于提高农产品流通效率具有重要意义。我国《收费公路管理条例》规定，鲜活农产品运输车辆可以减免车辆通行费。目前，纳入《鲜活农产品品种目录》享受“绿色通道”优惠政策的农产品包括新鲜蔬菜、新鲜水果、鲜活水产品、新鲜的肉蛋奶、活的畜禽等5个大类、24个分类、146个具体品种或类别。该目录是按照国家“菜篮子工程”建设要求在充分考虑群众基本生活需要的基础上慎重制定的，满足了群众基本生活的正常需要。根据规定，交通运输部督促各地交通运输部门在地方政府统一组织领导下，严格落实鲜活农产品运输“绿色通道”政策，对整车合法装载运输鲜活农产品车辆免收通行费，保障鲜活农产品运输车辆高效通行。包括东部沿海地区在内的全国所有收费公路，对于鲜活农产品运输车辆均已实行了免收通行费的“绿色通道”政策；对于非鲜活农产品类的其它农副产品运输车辆，应当按照《收费公路管理条例》的规定，依法正常缴纳车辆通行费。

你们提到的支持东部沿海地区区域性食用农产品冷链物流中心建设的问题，2016年交通运输部印发了《“十三五”货运枢纽（物流园区）建设方案》，并配套施行了《交通运输部货运枢纽（物流园区）投资补助项目管理办法（试行）》，重点支持以货运服务功能为主体、公共服务属性强的物流园区建设。目前，已安排资金支持了31个货运枢纽（物流园区）项目建设，其中8个具有冷链服务功能。2017年4月，国务院办公厅印发了《关于加快发展冷链物流保障食品安全促进消费升级的意见》（国办发﹝2017﹞29号），将完善冷链物流基础设施网络作为8项重点措施之一，提出鼓励全国性、区域性农产品批发市场建设冷藏冷冻、流通加工冷链设施；加强面向城市消费的低温加工处理中心和冷链配送设施建设，发展城市“最后一公里”低温配送；大中型城市要根据冷链物流等设施的用地需求，分级做好物流基础设施的布局规划，并与城市总体规划、土地利用总体规划做好衔接。下一步，国家发展改革委将会同相关部门认真做好已出台政策的贯彻落实工作，并结合具体工作认真吸收采纳你们的建议。

感谢你们对“三农”工作的关心，希望今后继续对我部工作给予支持。
