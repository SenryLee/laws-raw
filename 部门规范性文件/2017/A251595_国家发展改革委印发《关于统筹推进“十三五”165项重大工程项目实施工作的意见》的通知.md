# 国家发展改革委印发《关于统筹推进“十三五”165项重大工程项目实施工作的意见》的通知

发改规划〔2017〕730号

中央和国家机关有关部门、直属机构，有关人民团体，有关中央管理企业和金融机构：

经国务院同意，现将《关于统筹推进“十三五”165项重大工程项目实施工作的意见》（以下简称《意见》）印发你们，请结合实际认真执行。

各有关单位要按照职能和“十三五”规划《纲要》分工要求，细化实施责任和目标任务，建立实施工作台账和跟踪机制，强化统筹协调和支撑保障，着力破除体制机制障碍和实施参与门槛。为确保实施工作有序有力推进，及时掌握相关工作进展和问题，请各单位按《意见》附件1要求，认真填写有关材料并按时送我委汇总。

传真：68501657，2074（红）
