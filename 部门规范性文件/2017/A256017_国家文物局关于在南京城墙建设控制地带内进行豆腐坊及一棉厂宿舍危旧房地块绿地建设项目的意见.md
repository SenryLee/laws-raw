# 国家文物局关于在南京城墙建设控制地带内进行豆腐坊及一棉厂宿舍危旧房地块绿地建设项目的意见

文物保函〔2017〕1659号

江苏省文物局：

你局《关于审批南京市沿明城墙环境综合整治工程——豆腐坊及一棉厂宿舍危旧房地块绿地建设工程景观方案设计的请示》（苏文物保〔2017〕236号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位南京城墙建设控制地带内进行豆腐坊及一棉厂宿舍危旧房地块绿地建设项目和你局意见。

二、对所报项目提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《南京市历史文化名城保护规划》、《南京城墙保护规划》、《南京城墙保护条例》的相关管理规定，严格控制工程量和工程范围，尽量减少对文物本体和地下遗存的影响。

（二）设计依据应补充《中华人民共和国文物保护法》。

（三）进一步核对现状分析图与方案总平面图的拆建范围与内容，确保前后一致，不得新建任何建筑。

（四）应补充现有建筑拆除中必要的文物保护措施和应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十八条的规定报城乡建设规划部门批准。施工中应加强监管，确保文物安全。

专此函复。

国家文物局

2017年9月18日
