# 住房和城乡建设部执业资格注册中心关于2017年第一批申请勘察设计注册工程师初始注册审查意见的公示

## 关于2017年第一批申请勘察设计注册工程师初始注册审查意见的公示

根据《勘察设计注册工程师管理规定》，经审核，金海滨等13人符合注册土木工程师（岩土）初始注册条件（附件1）；赵淑辉等7人符合一级注册结构工程师初始注册条件（附件2）；朱红芬等40人符合注册公用设备工程师初始注册条件（附件3）；商晓春等62人符合注册电气工程师初始注册条件（附件4）；范传宏等8人符合注册化工工程师初始注册条件（附件5），现予以公示。公示截止日期为2017年1月26日。

任何单位和个人如对公示名单上的人员情况持有异议，均可在公示期间向住房和城乡建设部执业资格注册中心进行举报或反映（地址：北京市海淀区甘家口21号楼二层，邮编：100037，联系电话：010-68313531）。举报及反映材料需加盖单位公章或签署真实姓名并留下联系地址、邮编和电话。

附件：1. 金海滨等13名符合注册土木工程师（岩土）初始注册条件人员名单

2. 赵淑辉等7名符合一级注册结构工程师初始注册条件人员名单

3. 朱红芬等40名符合注册公用设备工程师初始注册条件人员名单

4. 商晓春等62名符合注册电气工程师初始注册条件人员名单

5. 范传宏等8名符合注册化工工程师初始注册条件人员名单

住房和城乡建设部执业资格注册中心

2017年1月16日
