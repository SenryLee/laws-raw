# 农业部对十二届全国人大五次会议第8708号建议的答复

## 对十二届全国人大五次会议第8708号建议的答复

农办议〔2017〕150号

李旭代表：

您提出的关于将四川省纳入农业部“粮改饲”试点省份的建议收悉,现答复如下。

当前，我国农业的主要矛盾为结构性矛盾，主要体现在阶段性、结构性供过于求和供给不足并存。从种植业来看，调结构最突出最紧迫的品种是玉米，最集中最核心的区域在“镰刀弯”地区。2015年，农业部会同财政部以东北冷凉区、北方农牧交错带等“镰刀弯”地区的非优势产区为重点，在河北、山西、内蒙古等10个省区开展粮改饲试点，通过调动市场主体使用青贮玉米、苜蓿、燕麦等优质饲草料的积极性，依靠市场机制引导农民因地制宜改种优质饲草，调减玉米种植面积，构建农牧结合、粮草兼顾的新型农牧业结构。2016年农业部发布《全国种植业结构调整规划（2016-2020年）》（以下简称《规划》），引导各地按照科学、生态和可持续的要求进行种植结构调整。《规划》明确提出调减玉米的重点是“镰刀弯”地区和黄淮海低产地区。为落实《规划》要求，2016年粮改饲试点范围扩大到“镰刀弯”地区和黄淮海玉米主产区的17个省区，四川省未包括在内。

推动种植业结构调整是一项复杂的系统工程，粮改饲试点需要与玉米种植结构调整、促进草食畜牧业发展等因素协同配套，综合考虑各地资源条件、草食畜牧业发展现状和潜力，以需求为导向因地制宜、逐步推进。下一步，我部将会同有关部门，进一步总结粮改饲试点经验，积极争取扩大试点实施面积，在全力保障重点地区粮改饲工作深入推进的同时，研究适时扩大试点范围的可能性。

感谢您长期以来对畜牧业工作的关心，希望今后继续对我部的工作予以支持！
