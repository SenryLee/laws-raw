# 司法部关于批准中国船舶工业集团公司公司律师试点工作方案和公司律师名单的函

司发函〔2017〕261号

中国船舶工业集团公司：

你公司《关于报送公司律师试点工作方案和申请人员名单的请示》(船工法规〔2017〕563号)收悉。经审查，批准该工作方案，同意以下33人为公司律师：
