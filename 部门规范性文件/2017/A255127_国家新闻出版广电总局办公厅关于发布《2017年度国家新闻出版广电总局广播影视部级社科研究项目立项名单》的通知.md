# 国家新闻出版广电总局办公厅关于发布《2017年度国家新闻出版广电总局广播影视部级社科研究项目立项名单》的通知

新广电办发〔2017〕53号

各省、自治区、直辖市、计划单列市、新疆生产建设兵团新闻出版广电局，总局机关各司局、直属各单位，各相关单位：

按照国家新闻出版广电总局部级社科研究项目管理有关规定，总局办公厅组织专家进行了2017年度广播影视部级社科研究项目评审工作。经专家评审并经总局领导审定，现将立项课题予以发布。请立项课题负责人与国家新闻出版广电总局社科研究项目规划办公室联系，办理相关立项手续。

特此通知

联系人：靳丹

联系电话：86096604
