# 中共教育部党组关于顾锋、奚立峰同志任职的通知

教党任〔2017〕207号

中共上海交通大学委员会：

经与中共上海市委商得一致， 2017年8月31日研究决定：

顾锋同志任中共上海交通大学委员会副书记，奚立峰同志任中共上海交通大学委员会委员、常委。

中共教育部党组

2017年9月11日
