# 农业部对十二届全国人大五次会议第2828号建议的答复

## 对十二届全国人大五次会议第2828号建议的答复

农办议〔2017〕105号

杨杰代表：

您提出的关于因地制宜做好基层产业扶贫的建议收悉。经商保监会、银监会,现答复如下。

发展产业是贫困人口实现脱贫的根本之策。中央扶贫开发工作会议以来，各地各部门坚决贯彻中央脱贫攻坚决策部署，按照精准扶贫、精准脱贫基本方略，采取超常措施，大力推进产业扶贫工作，取得积极成效。

一、关于构建开放性的产业扶贫平台

2016年4月，农业部、国家发展改革委、财政部、国务院扶贫办等9部门联合印发《贫困地区发展特色产业促进精准脱贫指导意见》，从科学确定特色产业、促进一二三产业融合发展、发挥新型经营主体带动作用、完善利益联结机制、增强产业支撑保障能力、加大产业扶贫投入力度、创新金融扶持机制、加大保险支持力度等方面，明确了产业扶贫工作的支持方向和重点。2016年5月，汪洋副总理在全国产业扶贫工作电视电话会议上强调，政府要营造有利于产业发展的市场环境，对贫困农户加强信息服务、技术指导、经营培训、资金扶持等，帮助农户了解市场、开拓市场、适应市场。2016年下半年，指导22个扶贫任务重的省（区、市）编制完成省、县两级产业扶贫规划，推动贫困地区落实产业扶贫发展，依据当地资源禀赋，携手各类市场主体，因地制宜发展产业，带动脱贫致富。

二、关于放大龙头企业带动作用

龙头企业是小生产和大市场的纽带，是提高产业扶贫效益、降低市场风险的重要保障。近年来，农业部会同有关部门认真落实中央要求，积极引导龙头企业通过多种渠道参与扶贫开发，充分利用龙头企业在行业、资金、技术等方面优势，帮助贫困地区培植产业基础、注入稀缺要素、促进产业升级、拓宽增收门路。2017年3月，在河北阜平召开环京津农业扶贫对接会，会同北京、天津两市，组织120多家企业、经销商和批发市场与环京津28个贫困县进行对接，签署各类合作协议168个，有力促进了当地产业扶贫工作。近两年，还组织企业与西藏、新疆、青海方面对接，在特色品种保护开发、特色农产品种植、农产品加工、农业技术推广、品牌提升、市场销售等方面达成一系列合作协议。

三、关于完善扶贫利益联结机制

汪洋副总理在全国农业产业扶贫精准脱贫经验交流会上强调，产业扶贫，发展产业只是手段，脱贫才是目的。近年来，各地各部门积极探索股份合作帮扶、订单帮扶等利益联结机制，鼓励资产折股量化，政府扶持资金通过以奖代补、贷款贴息等方式支持新型经营主体和贫困户。2016年，农业部在深入调研基础上，系统总结洛川苹果、赣南脐橙、定西马铃薯通过产业发展带动精准脱贫的经验做法和机制创新，形成《发展特色优势产业带动精准脱贫的范例》报告，习近平总书记作出重要批示。按照习近平总书记批示要求，在全国层面又先后遴选了广西百色芒果、贵州黔西南薏仁、河北平泉食用菌、湖北罗田黑山羊、安徽岳西茭白、河南信阳毛尖、山西平顺中药材、宁夏盐池滩羊、重庆石柱红辣椒、四川苍溪猕猴桃等10个立得住、叫得响、推得开的产业扶贫范例，并在范例点举办了8期产业扶贫现场观摩培训，全国11个集中连片特困地区533个贫困县负责同志及扶贫任务重的省份农业、扶贫部门负责同志共1000多人参加培训，起到了解疑、释惑，增信心、强能力的作用。

四、关于探索“保险+产业扶贫”新模式

近年来，我国农业保险快速发展，覆盖面进一步增强，服务能力和水平不断提高。截至2016年底，中央财政已将水稻、小麦、玉米等主要粮食作物以及能繁母猪、奶牛、育肥猪、棉花、森林等15种涉及国计民生的品种纳入保费补贴目录。已有8家保险机构在12个省份开展“保险+期货”试点，涉及大豆、玉米、鸡蛋、棉花和白糖等多个品种。农业保险中已开发出扶贫专属保险产品近50个，有力支持了贫困地区特色产业发展。保监会批准中国人民保险集团股份有限公司设立50亿元的资管产品，专项用于参保贫困农户的小额融资。中国保险业产业扶贫投资基金已达10亿元。

五、关于发展扶贫小额贷款

银监会大力推动各银行金融机构把扶贫小额信贷作为银行业金融机构实施精准扶贫、精准脱贫方略，引导金融机构安排专门资金，持续加大扶贫小额信贷投放力度，积极拓展扶贫小额信贷适用范围。对建档立卡贫困户5万元以内、3年以下的贷款，采取信用贷款方式，不设抵押担保门槛；实行利率优惠，利率水平原则上不超过基准利率；对有贷款意愿、有就业创业潜质、技能素质和一定还款能力的建档立卡贫困户保证应贷尽贷。全面推行银行“包干服务”制度，由银监部门根据当地银行业金融机构服务专长和实际情况，对扶贫小额信贷发放，按乡镇明确一家责任银行，由责任银行对建档立卡贫困户实现名单制管理，对贫困户开展逐户走访和信用评定。截至2016年12月末，全国银行业金融机构发放扶贫小额信贷余额1658亿元，支持建档立卡贫困户402万户，发放扶贫项目贷款余额802.7亿元。

下一步，农业部将会同有关部门继续贯彻落实中央脱贫攻坚决策部署，以解决产业扶贫中存在的突出问题为重点，在五个方面下足“绣花”功夫。一是强化规划引领。督促各地落实好产业精准扶贫规划，把产业项目与贫困乡、贫困村和贫困户精准对接，努力实现村村有特色产业、户户有增收门路。二是强化市场引导。指导贫困地区找准市场定位，支持创建特色农产品优势区，培育差异化比较优势，将资源优势转化为产品优势，防止农产品卖难，让优势特色产业发展转化为脱贫成效。三是强化龙头带动。加强贫困地区新型职业农民和脱贫致富带头人培养，加快龙头企业、农民合作社等新型经营主体培育，支持和鼓励返乡人员在贫困地区创业兴业，带动贫困群众实现就业增收、参与市场竞争。四是强化利益共享。探索和完善利益联结机制，支持有劳动能力的贫困户通过扶贫产业发展就近就地就业，引导财政资金折股量化，总结推广股份合作、订单帮扶、生产托管等帮扶模式，使产业发展与贫困户利益更加紧密、让贫困户受益更加精准。五是强化技术服务。组织农技专家到田间地头开展易学易懂易用的技术帮扶，让技术服务精准连接贫困户，让贫困户真正学会种养业技能，增强发展产业的信心和能力。

感谢您对农业、农村工作的关心，希望今后继续对我部工作予以支持。
