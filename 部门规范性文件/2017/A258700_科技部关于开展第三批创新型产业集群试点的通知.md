# 科技部关于开展第三批创新型产业集群试点的通知

国科发火〔2017〕374号

有关省、自治区、直辖市及计划单列市科技厅（委、局）：

为深入学习贯彻党的十九大精神，着力加快建设实体经济、科技创新、现代金融、人力资源协同发展的产业体系，促进我国产业迈向全球价值链中高端，根据《创新型产业集群试点认定管理办法》（国科发火〔2013〕230号），经审核，现将扬州数控成形机床等29个产业集群（详见附件）纳入第三批创新型产业集群试点名单。

希望你们继续加强对创新型产业集群试点工作的领导和支持，进一步完善试点工作的协调推进机制和保障措施，加强创新体系建设，强化协同创新，为实施创新驱动发展战略、加快新旧动能转换做好支撑和示范。

附件：第三批创新型产业集群试点名单

科技部

2017年12月1日
