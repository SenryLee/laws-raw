# 国家文物局办公室关于长陵保护展示工程方案的意见

办保函〔2017〕935号

陕西省文物局：

你局《关于上报长陵保护展示工程方案的请示》（陕文物字〔2017〕130号）收悉。经研究，我局意见如下：

一、所报方案内容庞杂，深度不足，我局暂不同意所报长陵展示工程设计方案。

二、所报方案尚需做以下必要的修改和完善：

（一）进一步加强现状勘察，明确帝陵、后陵、陪葬墓及陵墙地表现存遗迹的残损状况、成因及发展趋势，并在此基础上进一步增强拟采取保护措施的针对性。应重点做好坑洞回填、失稳部位加固，避免过度干预。遗存表面现有植被原则上不做清理。

（二）应进一步深化保护工程设计，明确具体工程范围、工程措施、工程材料及工程量等。

（三）应进一步明确展示重点，考古工作开展不充分的区域，不宜盲目展示，切忌全面铺开。应根据总体展示思路明确长陵展示分区，分清轻重缓急，有序进行展示设计。建议结合长陵博物馆建设与开放，现阶段重点做好陵园及陵邑范围内相关遗存的保护展示工作。

（四）展示所涉及区域的植被调整应以现状整理为主，注意充分尊重长陵的现有生态环境，注重体现庄严肃穆的陵区氛围，不得采用城市园林化的景观设计手法。

（五）陵区范围内应避免过度设置硬化路面，且路网不宜过密。各类参观游览辅助设施亦应严格控制规模和体量，且应仅在关键节点布设。

三、请你局指导方案编制单位，根据上述意见对所报方案作进一步修改和完善，经你局核准后按程序另行报批。

国家文物局办公室

2017年8月9日
