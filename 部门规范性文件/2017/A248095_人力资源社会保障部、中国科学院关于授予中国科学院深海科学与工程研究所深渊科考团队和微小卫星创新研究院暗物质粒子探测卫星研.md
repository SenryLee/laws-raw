# 人力资源社会保障部、中国科学院关于授予中国科学院深海科学与工程研究所深渊科考团队和微小卫星创新研究院暗物质粒子探测卫星研制团队“中国科学院先进集体”荣誉称号的决定

## 人力资源社会保障部　中国科学院关于授予中国科学院深海科学与工程研究所深渊科考团队和微小卫星创新研究院暗物质粒子探测卫星研制团队“中国科学院先进集体”荣誉称号的决定

人社部发〔2017〕6号

中国科学院院属各单位、院机关各部门：

近年来，在党中央、国务院的正确领导下，中国科学院全体科技工作者和广大干部职工高举中国特色社会主义伟大旗帜，以邓小平理论、“三个代表”重要思想、科学发展观为指导，全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入学习贯彻习近平总书记系列重要讲话精神，面向世界科技前沿，面向国家重大需求，面向国民经济主战场，以饱满的热情投身科技创新实践，立足本职，锐意进取，追求卓越，为推动我国经济社会发展和科技进步作出了重要贡献，涌现出一批出创新成果、出创新人才、出创新思想的先进集体。

为及时表彰在创新实践中成绩显著、成果突出的科技团队，进一步激励广大科技人员投身科技创新的积极性、主动性和创造性，人力资源社会保障部、中国科学院决定，授予深海科学与工程研究所深渊科考团队、微小卫星创新研究院暗物质粒子探测卫星研制团队“中国科学院先进集体”荣誉称号。希望受到表彰的先进集体珍惜荣誉，谦虚谨慎，积极进取，再接再厉，更加奋发有为地做好各项工作，为推动创新驱动发展再立新功。

中国科学院全体科技工作者和广大干部职工要以受表彰的先进集体为榜样，紧密团结在以习近平同志为核心的党中央周围，围绕“四个全面”战略布局，扎实推进“率先行动”计划，牢记使命，勇于担当，脚踏实地，勇攀高峰，加快促进“三重大”创新成果产出，在建设世界科技强国的进程中积极发挥国家战略科技力量作用，为决胜全面建成小康社会、实现中华民族伟大复兴中国梦作出新的更大贡献。

人力资源社会保障部

中国科学院
