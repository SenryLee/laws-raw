# 国家林业局关于下达2017年林业行业标准制修订项目计划的通知

林科发〔2017〕88号

各省、自治区、直辖市林业厅（局）,内蒙古、吉林、龙江、大兴安岭森工（林业）集团公司,新疆生产建设兵团林业局，国家林业局各司局、各直属单位，各林业专业标准化技术委员会，各有关单位：

经研究，现将2017年林业行业标准制修订项目计划192项（见附件）下达给你们，并将有关事项通知如下：

一、加强标准项目管理。各标准项目承担单位主管部门要认真履行监管职责，加强对标准项目的组织管理和监督检查，确保标准制修订项目各项任务按时完成。

二、强化组织协调和技术指导。各林业专业标准化技术委员会要切实做好归口标准的组织协调工作，加强技术指导，确保标准制修订质量，及时组织标准征求意见、标准审定和标准报批，按时保质完成标准制修订工作。

三、切实做好标准制修订工作。各标准项目承担单位要健全项目责任制，严格按照项目计划进度完成各阶段任务。要严格按照《林业标准化管理办法》和《标准化工作导则 第1部分：标准的结构和编写》（GB/T 1.1-2009）要求，做好标准制修订项目各阶段工作。在前期标准研究的基础上，再深入开展研究，广泛征求意见，进一步修改完善，确实提高标准的针对性、实用性和可操作性。

四、严格标准项目财务管理制度。各标准项目承担单位要严格按照《林业行业标准制修订经费管理办法》（林规发〔2011〕169号）规定，规范财政经费使用，加强项目资金的使用管理，确保资金安全运行，提高资金使用效益。

特此通知。
