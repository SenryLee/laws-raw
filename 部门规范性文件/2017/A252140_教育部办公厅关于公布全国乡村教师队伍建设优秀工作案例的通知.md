# 教育部办公厅关于公布全国乡村教师队伍建设优秀工作案例的通知

教师厅函〔2017〕10号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

《乡村教师支持计划（2015-2020年）》印发以来，各地出台了实施办法，因地制宜提出符合乡村教育实际的支持政策和有效措施，探索出了一批先进做法，涌现出了一批先进典型。

为总结经验、宣传先进，激励各地开拓进取，攻坚克难，进一步加强乡村教师队伍建设，在2016年首批20个优秀工作案例评选基础上，再次选出11个优秀工作案例（见附件）。希望全国各地认真学习借鉴优秀案例做法，全面深入推进乡村教师队伍建设，努力培养造就一支素质优良、甘于奉献、扎根乡村的教师队伍，为基本实现教育现代化、全面建成小康社会做出新的更大贡献。

附件：全国乡村教师队伍建设优秀工作案例

教育部办公厅

2017年6月7日
