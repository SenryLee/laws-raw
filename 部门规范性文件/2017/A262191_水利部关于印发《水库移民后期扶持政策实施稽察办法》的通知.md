# 水利部关于印发《水库移民后期扶持政策实施稽察办法》的通知

水电移〔2017〕360号

各省、自治区、直辖市水利(水务)厅(局)和移民管理机构,新疆生产建设兵团水利局及移民管理机构,部直属各单位:

为加强水库移民后期扶持政策实施监督管理,根据《大中型水利水电工程建设征地补偿和移民安置条例》和《国务院关于完善大中型水库移民后期扶持政策的意见》等有关规定,我部制定了《水库移民后期扶持政策实施稽察办法》,现予印发,请遵照执行。

水利部

2017年11月6日
