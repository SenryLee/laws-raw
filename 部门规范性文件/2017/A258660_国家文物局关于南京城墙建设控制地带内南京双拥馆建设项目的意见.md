# 国家文物局关于南京城墙建设控制地带内南京双拥馆建设项目的意见

文物保函〔2017〕1982号

江苏省文物局：

你局《关于审批南京城墙建设控制地带内南京双拥馆建设方案的请示》（苏文物保〔2017〕334号）收悉。经研究，我局意见如下：

一、原则同意南京城墙建设控制地带内南京双拥馆建设方案和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）进一步评估建设项目对文物本体历史环境、视觉效果的影响。

（二）补充该地块现有建筑及拆除情况说明。

（三）统筹考虑南京城墙及石头城建设控制地带内的相关规定，从严控制建筑总高及面积。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《文物保护法》第十七条、第十八条的有关规定分别报送江苏省人民政府和城乡建设规划部门批准后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局

2017年12月11日
