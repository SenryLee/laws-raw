# 中国证券监督管理委员会对十二届全国人大五次会议第3883号建议的答复

## 对十二届全国人大五次会议第3883号建议的答复

《关于推动传统行业国家级高新技术企业挂牌新三板的建议》收悉。现答复如下：

全国中小企业股份转让系统（新三板）是我国多层次资本市场体系的重要组成部分，对服务中小微企业、支持创新创业具有非常重要的作用。我会始终高度重视新三板的发展，自新三板试点扩大至全国后，不断完善基础制度，加快改革创新，切实提高新三板服务实体经济的能力。

**一、**关于新三板适度放宽传统类高新技术企业准入门槛的建议

结合新三板的市场定位、发展现状和国家产业政策要求，2016年9月，我会指导全国中小企业股份转让系统有限责任公司（以下简称全国股转公司），出台了针对挂牌公司准入实施负面清单管理的相关规则，对科创类及传统行业企业分别制定了准入标准，目的是引导主办券商的推荐工作聚焦新三板市场定位，促进主办券商完善遴选标准，提高挂牌公司整体质量。对于传统行业包括传统行业中的高新技术企业，新三板并非对其“一刀切”，而是将“公司最近一年及一期的主营业务中存在国家淘汰落后及过剩产能类行业”列为负面清单情形之一，目的是积极服务国家供给侧结构性改革，助力“去产能”任务。2017年9月6日，全国股转公司总结了负面清单实施以来的情况，吸收了市场主体普遍接受且对市场发展和风险控制有利的部分要求，摒弃了挂牌准入负面清单中不便于操作的相关要求，对《全国中小企业股份转让系统股票挂牌条件适用基本标准指引》（以下简称《标准指引》）进行了修订，要求公司最近两个会计年度的营业收入累计不低于1000万元（研发周期较长的除外），挂牌准入负面清单不再继续适用。

下一步，我会将指导全国股转公司密切关注《标准指引》执行情况，并结合市场的反馈意见，在坚持申请挂牌公司业务明确、具备可持续经营能力原则的基础上，进一步完善相关业务规则，继续支持和引导符合条件的各类企业在新三板挂牌。

**二、**关于新三板能够发挥自身灵活性和包容性的建议

新三板是经国务院批准、依据《证券法》设立的全国性证券交易场所。新三板服务范围是全国性的，服务对象主要为创新型、创业型、成长型中小微企业，以包容性理念设置挂牌条件，对企业不作所有制、地域和盈利等方面限制性要求，企业登陆新三板预期明、用时短、成本低，一大批符合经济转型升级方向的企业成功挂牌，并实现了加速发展，对提高创新能力，增加有效供给，促进产业结构转型升级发挥着积极作用。截至2017年10月末，新三板挂牌公司达11619家，总股本6846.98亿股，总市值近5.17 万亿元。新三板挂牌公司分布在31个省（区、市），覆盖所有89个非综合类大类行业。2017年初至10月末，挂牌公司共完成发行　2307次，累计发行176.12亿股，累计募集金额1067.17亿元。

目前，证监会对于发行后股东人数不超过200人的挂牌公司股票发行豁免核准，由全国股转公司实行备案审查。全国股转公司已经针对不同类型的股票发行采取了不同的审查方式，对于其中不涉及收购、资产认购及业绩对赌的股票发行，精简了审查出函流程，进一步提高募集资金使用效率。下一步，证监会将指导全国股转公司继续优化备案审查流程，提高工作效率，为挂牌公司提供更好的市场环境和融资支持服务，进一步发挥新三板包容性和多元化的优势。

**三、**关于新三板在供给侧结构性改革和“大众创业万众创新”等战略中发挥支持作用的建议

新三板对落实国家创新驱动发展战略、助力创新创业、服务供给侧结构性改革发挥着积极作用，突出表现在以下方面：一是畅通了民间资本投资渠道，目前，私募股权投资基金和创业投资基金持股的挂牌公司数量占比超过60%，推动改变过去私募股权投资基金和创业投资基金集中做成熟项目的状况。二是提高了金融体系协同效应，新三板与30多家商业银行展开战略合作。2016年商业银行为挂牌公司提供授信额度超过1300亿元。三是增强了对贫困地区和民族地区的服务，目前对民族地区和贫困地区挂牌企业设立单独通道，实行“即报即审、审过即挂”政策，同时减免费用。四是推动了中小微企业规范发展，一万余家股份公司在新三板平台上按照公众公司的要求，逐步规范会计信息，健全公司治理，提高运作透明度，在社会上起到了很好的示范引领作用，也促进了社会诚信契约精神的深入发展。

下一步，证监会将指导新三板进一步健全规则体系，提升市场运行效率，夯实市场发展基础，充分发挥新三板促进技术转化的孵化作用、鼓励创业投资的培育作用、优化企业财务结构的直接融资效应，更好地服务供给侧结构性改革，助力经济转型升级。
