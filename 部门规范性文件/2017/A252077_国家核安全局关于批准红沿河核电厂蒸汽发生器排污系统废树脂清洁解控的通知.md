# 国家核安全局关于批准红沿河核电厂蒸汽发生器排污系统废树脂清洁解控的通知

## 关于批准红沿河核电厂蒸汽发生器排污系统废树脂清洁解控的通知

国核安发〔2017〕133号

辽宁红沿河核电有限公司：

你公司《关于辽宁红沿河核电厂蒸汽发生器排污系统废树脂清洁解控的请示》（辽红核〔2016〕95号）收悉。

根据《中华人民共和国民用核设施安全监督管理条例》及其实施细则的有关要求，我局对你公司提交的申请文件进行了审评，认为你公司对红沿河核电厂蒸汽发生器排污系统废树脂清洁解控是可以接受的，现予批准。

你公司应严格按照我局批准的方案实施清洁解控，确保机组运行安全。

国家核安全局

2017年6月30日
