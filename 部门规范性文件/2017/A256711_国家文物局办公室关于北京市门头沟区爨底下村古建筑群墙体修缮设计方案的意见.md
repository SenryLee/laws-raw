# 国家文物局办公室关于北京市门头沟区爨底下村古建筑群墙体修缮设计方案的意见

办保函〔2017〕1187号

北京市文物局：

你局《关于门头沟区爨底下村古建筑群墙体修缮工程设计方案的请示》（京文物〔2017〕1244号）收悉。经研究，我局暂不同意该修缮工程设计方案，并提出如下意见：

一、应进一步明确工程性质，文本里把工程性质定为“重点修复”，而在主要修缮内容定为“现状整修”，应核实。

二、深化文物现状勘察，全面分析评估墙体开裂原因，注意上部临时建筑和地基基础对墙体开裂的影响。若有直接影响，应解决好上部临时建筑的排水和地面裂缝等问题。

三、进一步深化设计文本和图纸。

请你局指导相关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2017年10月20日
