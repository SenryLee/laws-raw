# 国家安全生产监督管理总局公告2017年第17号——危险化学品从业单位安全生产标准化一级企业名单（第四批）

## 国家安全生产监督管理总局公告

2017年第17号

根据《国家安全监管总局关于印发危险化学品从业单位安全生产标准化评审标准的通知》（安监总管三〔2011〕93号）和《国家安全监管总局关于印发企业安全生产标准化评审工作管理办法（试行）的通知》（安监总办〔2014〕49号）的规定，经考评，江苏联化科技有限公司等4家企业为危险化学品从业单位安全生产标准化一级企业，现予公告。

附件：危险化学品从业单位安全生产标准化一级企业名单（第四批）

国家安全监管总局

2017年12月5日

附件

## 危险化学品从业单位安全生产标准化一级企业名单（第四批）

1.江苏联化科技有限公司

2.南京诚志清洁能源有限公司

3.中化兴中石油转运（舟山）有限公司

4.广东珠海金湾液化天然气有限公司
