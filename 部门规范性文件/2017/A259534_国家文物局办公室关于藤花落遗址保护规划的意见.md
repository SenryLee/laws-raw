# 国家文物局办公室关于藤花落遗址保护规划的意见

办保函〔2017〕1429号

江苏省文物局：

你局《关于审批〈藤花落遗址保护规划〉的请示》（苏文物保〔2017〕4号）收悉。经研究，我局意见如下：

一、暂不同意藤花落遗址保护规划。

二、对该规划提出以下修改意见：

（一）进一步加强与考古单位合作，明确遗址保护对象构成及保存现状，核定松花江路北侧遗存的实际分布情况，为科学确定规划范围和措施提供依据。

（二）进一步优化保护区划调整措施，根据松花江路北侧地下遗存保存状况确定合适保护级别；适当缩小松花江路南侧保护范围和建设控制地带。

（三）针对不同区域实际情况，根据保护区划分级分类进一步细化管理规定，提高管理措施的针对性和可操作性。

（四）加强与相关部门的沟通，补充与相关规划的衔接内容，完善人口调控、道路建设、用地性质调整等措施。遗址保护区划内的现有建构筑物拆迁应慎重，合理确定环境整治范围、规模和时序安排。

（五）应根据遗址现状评估结论，合理确定展示利用强度，进一步论证建设考古遗址公园的可行性和必要性，控制公园建设规模，注意服务当地经济社会发展的需求。

三、请你局指导相关单位，按照上述意见对所报保护规划进行修改、完善，按相关程序另行报批。

国家文物局办公室

2017年12月26日
