# 农业部办公厅关于报送贯彻落实《国务院办公厅关于进一步促进农产品加工业发展的意见》有关情况的通知

农办加〔2017〕14号

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）厅（局、委、办），新疆生产建设兵团农业局：

近年来，我国农产品加工业有了长足发展，已成为农业现代化的支撑力量、国民经济的重要产业和事关国民营养健康的民生产业。为进一步促进农产品加工业发展，深入推进农业供给侧结构性改革，去年12月，国务院办公厅印发了《关于进一步促进农产品加工业发展的意见》（国办发〔2016〕93号，以下简称《意见》），对“十三五”和今后一个时期我国农产品加工业发展作出了全面部署。

农业部高度重视《意见》贯彻落实工作，今年4月在河南专门召开了全国农产品加工业发展和农业品牌创建推进工作会议，韩长赋部长出席会议并讲话，要求各级农业部门必须深刻领会、准确把握文件精神，进一步理清思路、明确目标，突出重点、狠抓落实，全力开创农产品加工业发展新局面。目前，部分省（区、市）积极贯彻落实《意见》，不断细化实化政策措施，有针对性地制定了本省的实施意见，全面推动了当地农产品加工业持续健康发展。但仍有一些省（区、市）对《意见》的贯彻落实至今尚未作出安排部署，直接影响到中央政策措施的落地见效。

为了推动《意见》贯彻落实，根据任务分工要求，农业部将牵头督查《意见》贯彻落实情况，并将有关进展上报国务院。现就督查内容和有关要求通知如下。

一、督查内容

（一）各省（区、市）贯彻落实《意见》的工作进展和取得成效，特别是在制定本省实施意见，细化实化政策措施等方面的进展情况；

（二）各省（区、市）农业部门发挥牵头作用，履行对农产品加工业规划、指导、管理、服务等职能，督促各项政策措施落实，完善工作机制等情况；

（三）各省（区、市）在贯彻落实《意见》过程中存在的突出困难和问题；

（四）各省（区、市）下一步贯彻落实《意见》的工作重点和重要举措。

二、有关要求

请各省（区、市）认真开展自查，并总结工作进展情况，于2017年6月30日前将贯彻落实情况以书面形式报送农业部农产品加工局，同时发送电子文档。农业部将于下半年适时开展督促检查和抽查活动。
