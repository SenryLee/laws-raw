# 国家质量监督检验检疫总局公告2017年第74号——质检总局关于公布2017年国家级出口食品农产品质量安全示范区名单的公告

## 国家质量监督检验检疫总局公告

2017年第74号

## 质检总局关于公布2017年国家级出口食品农产品质量安全示范区名单的公告

根据质检总局关于国家级出口食品农产品质量安全示范区建设和考核的相关管理规定，经地方人民政府申请、相关直属检验检疫局初审以及质检总局文件审查和现场考核，全国78个新申报示范区（附件1）符合相关规定要求，批准为国家级出口食品农产品质量安全示范区。289个示范区经年审合格，继续保留国家级出口食品农产品质量安全示范区称号（附件2）。

特此公告。

附件：1. 2017年新增国家级出口食品农产品质量安全示范区名单

2. 2017年年审合格国家级出口食品农产品质量安全示范区名单

质检总局

2017年9月15日
