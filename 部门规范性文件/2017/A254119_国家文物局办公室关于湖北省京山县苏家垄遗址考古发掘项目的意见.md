# 国家文物局办公室关于湖北省京山县苏家垄遗址考古发掘项目的意见

办保函〔2017〕922号

湖北省文物局：

你局报送的湖北省京山县坪坝镇苏家垄遗址考古发掘项目申请书（存档编号2017168028）收悉。经研究，我局意见如下：

一、苏家垄遗址紧邻全国重点文物保护单位苏家垄墓群，现已发现大量青铜炼渣和窑炉遗迹，对于研究曾国青铜冶炼技术和曾国历史文化具有重要意义。请你局加强指导，督促考古单位进一步明确苏家垄遗址考古工作的目标、重点和技术路线，将该考古项目纳入2018年度主动性考古发掘项目统一规划，并按程序另行报批。

二、请你局加强管理，督促地方人民政府落实遗址的日常巡查和看护工作，确保文物本体安全。

国家文物局办公室

2017年8月8日
