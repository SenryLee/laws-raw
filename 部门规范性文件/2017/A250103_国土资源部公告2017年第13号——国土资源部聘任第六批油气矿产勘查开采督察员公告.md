# 国土资源部公告2017年第13号——国土资源部聘任第六批油气矿产勘查开采督察员公告

## 国土资源部公告

2017年第13号

## 国土资源部聘任第六批油气矿产勘查开采督察员公告

国土资源部2013年11月20日聘任的油气矿产勘查开采督察员任期已满，按照《矿产勘查及油气开采督察员工作制度》（国土资发〔2003〕99号）的规定，聘任丁峰等503人为新一批油气矿产勘查开采督察员，任期3年，2017年5月5日至2020年5月4日，现予以公告。

国土资源部

2017年5月5日
