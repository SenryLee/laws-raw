# 司法部关于印发2018年度注册的中国委托公证人（香港）名单的通知

司发通〔2017〕136号

各省、自治区、直辖市司法厅(局)，新疆生产建设兵团司法局：

根据《中国委托公证人(香港)管理办法》的规定，我部经审查，决定对阮北耀等396名中国委托公证人(香港)予以2018年度注册。现将2018年度注册的中国委托公证人(香港)名单印发你们。请即转各地司法局、各公证处，作为受理中国委托公证人办理的涉港公证文书核验的依据。
