# 国家文物局关于东北民主联军前线指挥部旧址建设控制地带民安大街地下公共停车场建设项目的意见

文物保函〔2017〕1913号

黑龙江省文物局：

你局《关于哈尔滨双城区民安大街地下公共停车场项目选址涉及东北民主联军前线指挥部建设控制地带审批的请示》（黑文管字〔2017〕24号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、对方案提出以下修改完善意见：

（一）适当降低出入口地面构筑物高度，减少对文物环境的影响。

（二）应对停车场施工期间产生的震动进行评估，根据评估结果，制定减振措施。

（三）补充建设项目对文物环节影响的评估。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十八条规定，报城乡建设规划部门批准实施。工程施工期间，应加强监管，确保文物安全。

国家文物局

2017年11月30日
