# 国家林业局关于印发《退化防护林修复技术规定（试行）》的通知

林造发〔2017〕7号

各省、自治区、直辖市林业厅（局），内蒙古、吉林、龙江、大兴安岭、长白山森工（林业）集团公司，新疆生产建设兵团林业局，各计划单列市林业局：

为进一步规范退化防护林修复技术，科学指导退化防护林修复工作，提高修复质量和效益，我局研究制定了《退化防护林修复技术规定（试行）》（见附件），现印发给你们，请遵照执行。

附件：退化防护林修复技术规定（试行）

国家林业局

2017年1月24日
