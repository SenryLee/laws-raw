# 中华人民共和国工业和信息化部公告2017年第59号——符合水泥行业规范条件生产线名单（第十批）、符合平板玻璃行业规范条件生产线名单（第八批）、符合耐火材料行业规范条件生产线名单（第一批）

## 中华人民共和国工业和信息化部公告

2017年第59号

根据《水泥行业规范条件（2015年本）》《平板玻璃行业规范条件（2014年本）》《耐火材料行业规范条件（2014年本）》和相关公告管理暂行办法，经企业申报、省级工业和信息化主管部门核实推荐、专家复核和网上公示，现将符合水泥行业规范条件生产线名单（第十批）、符合平板玻璃行业规范条件生产线名单（第八批）、符合耐火材料行业规范条件生产线名单（第一批）予以公告。

附件：1.符合水泥行业规范条件生产线名单（第十批）

2.符合平板玻璃行业规范条件生产线名单（第八批）

3.符合耐火材料行业规范条件生产线名单（第一批）

工业和信息化部

2017年12月20日
