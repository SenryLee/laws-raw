# 国家文物局关于上海商业储蓄银行旧址保护范围及建设控制地带内南京地铁5号线工程方案意见的函

## 关于上海商业储蓄银行旧址保护范围及建设控制地带内南京地铁5号线工程方案意见的函

办保函〔2017〕782号

江苏省文物局：

你局《关于审批上海商业储蓄银行旧址保护范围及建设控制地带内南京地铁5号线工程方案的请示》（苏文物保〔2017〕159号）收悉。经研究，我局意见如下：

一、暂不同意上海商业储蓄银行旧址保护范围及建设控制地带内南京地铁5 号线工程方案。

二、所报方案应做以下修改：

（一）根据南京地铁5号线选线规划设计方案及评估报告修改说明，地下隧道需严格控制隧道顶部至地面的距离，原则上应不小于两倍地铁隧道直径（12.4m）。现穿越上海商业储蓄银行旧址段地铁盾构最高点距地表仅10米，振动影响应十分明显，需进一步论证、评估5号线工程对旧址的影响并调整有关措施。

（二）进一步补充完善上海商业储蓄银行旧址的现状勘察资料，全面分析该建筑的原结构及地基基础（包括液化层）情况，为制定旧址文物保护措施提供依据。

（三）上海商业储蓄银行旧址为近代建筑，应根据《近现代历史建筑结构安全性评估导则》（WW/T 0048-2014）等相关标准的规定开展地铁工程文物影响评估。

请你局指导有关单位，根据上述意见对工程方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局

2017年6月22日
