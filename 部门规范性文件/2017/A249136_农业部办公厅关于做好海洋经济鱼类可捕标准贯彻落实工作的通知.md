# 农业部办公厅关于做好海洋经济鱼类可捕标准贯彻落实工作的通知

农办渔〔2017〕22号

沿海各省、自治区、直辖市渔业主管厅（局）：

水产行业标准《重要渔业资源品种可捕规格第1部分：海洋经济鱼类》（农业部公告第2466号，以下简称《标准》）自2017年4月1日起正式实施，为做好《标准》贯彻落实工作，切实加强海洋幼鱼资源保护，提出有关要求如下。

一、高度重视，尽快建立健全地方相关制度标准

幼鱼是渔业资源的补充群体，保护幼鱼资源是实现渔业资源恢复和可持续利用的关键。目前，不少地方海洋捕捞作业存在渔获物中幼鱼比例过高的问题，对幼鱼资源造成极大破坏。各级渔业主管部门要进一步提高对幼鱼资源保护工作的重视程度，把此项工作作为促进海洋渔业可持续发展的重要措施，纳入渔业渔政管理工作的议事日程。

《标准》规定了15种重要海洋经济鱼类的最小可捕规格，为今后加强幼鱼资源保护提供了重要依据。各地可以在《标准》的基础上，制定本地区重要海洋渔业资源品种的可捕规格，原则上各地制定的标准应严于国家标准。各地可结合本地实际，制定渔获物中幼鱼比例标准，积极推动将幼鱼比例作为渔政执法检查的法律依据，明确捕捞、运输、销售、使用幼鱼资源等不同情形的执法处罚标准，为幼鱼资源保护执法工作创造必要条件。

二、完善工作机制，严厉打击各类破坏幼鱼资源的行为

各级渔业主管部门要积极推动当地人民政府加强对幼鱼资源保护工作的统一领导，建立以渔政执法力量为主导，海警、公安、工商、交通等多部门协调配合的幼鱼资源保护工作机制。要加强伏休管理，加大对使用“绝户网”等违规渔具、涉渔“三无”船舶、“电毒炸”等违法行为的打击力度。要创新渔政执法方式方法，由生产环节执法为主向生产过程和产品终端执法两者并重转变。加强海上、港口、市场、运输、鱼粉（水产品）加工、养殖和消费终端等不同环节的执法监管，严厉打击各类破坏幼鱼资源的行为。

三、做好资源养护，加快幼鱼资源修复

各级渔业主管部门要继续加强水生生物保护区建设，保护好海洋鱼类的产卵场、索饵场、越冬场以及洄游通道等重要栖息地；要加大渔业资源增殖放流的工作力度，积极开展海洋牧场和人工鱼礁建设，修复海洋渔业资源和生态环境；要积极推广健康生态养殖方式和人工配合饲料，加快替代冰鲜幼杂鱼直接投喂。

四、加强宣传培训，提高幼鱼资源保护意识

各级渔业主管部门要充分利用广播、电视、报纸、标语等传统宣传方式以及微信、微博等新媒体，对渔船、渔港、渔村、市场等重点场所开展有针对性的宣传工作；要建立破坏幼鱼资源举报渠道，充分发挥社会各界力量，对破坏幼鱼资源的各类行为进行监督。
