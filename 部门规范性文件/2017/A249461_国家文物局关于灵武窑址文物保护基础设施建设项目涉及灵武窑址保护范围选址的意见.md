# 国家文物局关于灵武窑址文物保护基础设施建设项目涉及灵武窑址保护范围选址的意见

## 关于灵武窑址文物保护基础设施建设项目涉及灵武窑址保护范围选址的意见

办保函〔2017〕323号

宁夏回族自治区文物局：

你局《关于报送审批〈灵武窑址文物保护基础设施建设项目设计方案〉的请示》（宁文物发〔2017〕7号）收悉。经研究，我局意见如下：

一、暂不同意灵武窑址文物保护基础设施建设项目设计方案。

二、所报方案尚需做以下必要的修改和完善：

（一）进一步明确拟建基础设施与灵武窑址文物遗存和保护区划的关系，并补充相应的图纸。

（二）防洪工程应进一步补充论证必要性，并提出具体的工程设计。

（三）巡护路线应根据巡护要求做进一步优化，且应尽量控制道路体量，避免过度建设。同时，建议道路采用砂石路面，以与遗址及其周边环境相协调。

（四）补充说明现有保护围栏的状况，并论证新建保护围栏的必要性。若确有必要，应优化设计，做到简洁大方，并严格控制建设和后续维护成本。

（五）保护用房的选址应与巡护路线设置统筹考虑，且应严格控制建筑规模、体量和高度，优化外观设计，注意与遗址及其周边环境相协调。同时，配套供水设施规模按2000人规模测算欠妥，应进一步校核。

三、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改和完善，经你局核准后按程序另行报批。

国家文物局

2017年3月27日
