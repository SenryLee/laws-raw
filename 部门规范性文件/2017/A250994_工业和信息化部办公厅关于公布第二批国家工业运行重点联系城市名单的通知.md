# 工业和信息化部办公厅关于公布第二批国家工业运行重点联系城市名单的通知

工信厅运行函[2017]300号

内蒙古、辽宁、吉林、黑龙江、江苏、山东、河南、湖南、广东、广西、四川、贵州、陕西省（自治区）工业和信息化主管部门：

首批40个国家工业运行重点联系城市公布以来，重点联系城市在健全工业运行监测预测预警工作机制，促进工业稳增长、调结构、增效益中发挥了重要作用。为进一步完善国家工业运行重点联系城市平台，提升工业经济运行分析质量，根据《工业和信息化部办公厅关于做好第二批国家工业运行重点联系城市申报有关工作的通知》（工信厅运行函〔2017〕89号）要求，经城市申报、省级工业和信息化部门预审、专家评审以及网站公示，遴选出15个国家工业运行重点联系城市，现予公布。有关事项通知如下：

一、第二批工业运行重点联系城市名单：包头市、抚顺市、吉林市、齐齐哈尔市、徐州市、南通市、潍坊市、淄博市、许昌市、株洲市、中山市、柳州市、德阳市、遵义市和榆林市。

二、按照《国家工业运行重点联系城市实施办法》，工业运行重点联系城市要围绕促进工业平稳健康发展目标，及时上报月度、季度、年度工业运行相关统计数据，按时报送重点企业调查问卷，以及企业生产经营的问题和诉求，每季度上报本市工业运行分析报告，为全国工业运行分析和出台政策措施提供参考。

三、各地工业和信息化主管部门要认真落实国家出台的工业稳增长调结构增效益相关政策措施，督促本地区重点联系城市及时上报相关工业运行信息，交流工业平稳增长和转型升级好的经验和做法，为把握全国工业运行态势，及时发现苗头性、趋势性的新情况新问题，监测新旧动能转换等工作作出积极贡献。
