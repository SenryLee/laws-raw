# 国家文物局关于旌德文庙文昌塔修缮工程立项的意见

## 关于旌德文庙文昌塔修缮工程立项的意见

办保函〔2017〕217号

安徽省文物局：

你局《关于批准旌德文庙文昌塔修缮工程立项的请示》（皖文物保〔2017〕11号）收悉。经研究，我局意见如下：

一、暂不同意旌德文庙文昌塔修缮工程立项。

二、对该立项报告提出以下修改意见：

（一）应加强现状勘察，深入分析塔身残损、塔基风化等病害原因，科学评估塔体结构稳定性和2001年修缮工程效果，进一步论证工程实施的必要性和可行性。

（二）应深入研究文昌塔的建筑形制、建造工艺、建筑材料和构造特征等，准确界定工程性质，科学确定工程量、工程范围和具体修缮措施，重点解决塔体结构安全问题，避免过度维修。

（三）根据工程量合理编制经费预算，确定取费项目，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年3月6日
