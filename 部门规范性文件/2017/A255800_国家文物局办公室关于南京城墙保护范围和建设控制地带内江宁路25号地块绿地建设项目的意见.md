# 国家文物局办公室关于南京城墙保护范围和建设控制地带内江宁路25号地块绿地建设项目的意见

办保函〔2017〕1070号

江苏省文物局：

你局《关于审批南京市沿明城墙环境综合整治工程——江宁路25号地块绿地建设工程景观方案设计的请示》（苏文物保〔2017〕230号）收悉。经研究，我局意见如下：

一、所报项目设计依据不足，对文物景观影响较大，我局暂不同意江宁路25号地块绿地建设项目。

二、该方案应进行以下必要的修改和完善：

（一）立体停车楼对城墙景观影响较大，应重新进行方案设计。建议进一步降低地上建筑高度，分解建筑体量，建筑色彩宜采用灰色调，并采取绿化遮挡措施降低停车楼对城墙的景观影响。

（二）设计依据应补充《中华人民共和国文物保护法》，并据此指导方案思路调整与内容修改。补充《南京城墙保护规划》、《南京市城墙保护条例》关于南京城墙保护范围和建设控制地带的控制指标和具体要求。

（三）补充说明规划教育用地的设计内容、方案和具体指标。

（四）进一步核对现状分析图与方案总平面图的拆建范围与相关数据，确保前后一致。

（五）应补充建设施工中必要的文物保护措施和应急预案。

（六）应进一步完善文物影响评估报告，根据方案内容准确、客观论证拟建项目对城墙本体及景观风貌的影响，增强针对性。

三、请你局组织相关单位根据上述意见，对项目方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2017年9月18日
