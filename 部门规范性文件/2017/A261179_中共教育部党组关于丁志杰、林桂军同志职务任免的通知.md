# 中共教育部党组关于丁志杰、林桂军同志职务任免的通知

教党任〔2017〕283号

中共对外经济贸易大学委员会：

经与中共北京市委商得一致，2017年12月20日研究决定：

丁志杰同志任中共对外经济贸易大学委员会常委；免去林桂军同志的中共对外经济贸易大学委员会常委职务。

中共教育部党组

2017年12月29日
