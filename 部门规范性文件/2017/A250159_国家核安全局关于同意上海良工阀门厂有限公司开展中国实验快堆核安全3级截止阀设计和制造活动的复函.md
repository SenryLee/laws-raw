# 国家核安全局关于同意上海良工阀门厂有限公司开展中国实验快堆核安全3级截止阀设计和制造活动的复函

## 关于同意上海良工阀门厂有限公司开展中国实验快堆核安全3级截止阀设计和制造活动的复函

国核安函〔2017〕44号

上海良工阀门厂有限公司:

你公司《关于申请承接中国实验快堆常规岛及辅助系统改造项目核安全3级电动截止阀的请示（第二部分）》（良核阀字(2017)第1号）收悉。经研究，我局同意你公司开展中国实验快堆改造项目核安全3级电动截止阀（设计温度≤540℃，设计压力≤17MPa）的设计和制造活动。

你公司应严格按照标准规范和技术规格书的要求开展设计和制造活动，有效运行质量保证体系，认真履行报告和备案制度，加强质量管理和过程控制，确保核级阀门设计和制造质量。

特此函复。

国家核安全局

2017年5月3日
