# 中华人民共和国工业和信息化部公告2017年第50号——国家工业节能技术装备推荐目录（2017）

## 中华人民共和国工业和信息化部公告

2017年第50号

附件：1.国家工业节能技术装备推荐目录（2017）

2.国家工业节能技术应用指南与案例（2017）

2017年11月10日
