# 国家文物局关于南京城墙保护范围和建设控制地带内小桃园护城河西岸二期、三期景观建设项目意见的函

文物保函〔2017〕1917号

江苏省文物局：

你局《关于审批南京城墙保护范围及建设控制地带内小桃园护城河西岸景观规划设计修改方案的请示》（苏文物保〔2017〕252号）收悉。经研究，我局意见如下：

一、原则同意小桃园护城河西岸二期、三期景观建设项目和你局意见。

二、该方案应进行以下必要的修改和完善：

（一）应严格遵守《南京城墙保护规划》的相关管理规定，进一步调整二期、三期方案设计，保护城墙的历史环境。植物树种选择及景观设计应尽量简化，驳岸应保持自然形态，避免过度景观园林化。不得进行大范围场地竖向变化，补充方案图纸中景观竖向设计内容。充分考虑建设施工对南京城墙及护城河的影响，补充必要的文物保护措施和应急预案。

（二）二期工程应准确校核南京城墙保护区划图以及与二期工程范围的关系；不同意在保护范围及建设控制地带内进行山体恢复；优化公共厕所外观设计，应与城墙、护城河历史景观相协调，并注意处理好厕所污染问题。

（三）应进一步完善文物影响评估报告，根据方案内容准确、客观论证拟建项目对城墙本体及景观风貌的影响，增强针对性。补充南京城墙与小桃园护城河西岸二、三期工程的视线分析图。

三、请你局指导相关单位根据上述意见对具体方案进行修改完善，根据《中华人民共和国文物保护法》第十七条、第十八条的规定报江苏省人民政府和城乡建设规划部门批准。施工中应加强监管，并加强对文物本体、山体及相关环境的监测，做好山体防护和植被恢复，确保文物安全。

国家文物局

2017年11月30日
