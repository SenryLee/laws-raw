# 中华人民共和国住房和城乡建设部公告第1720号——住房城乡建设部关于注销秦皇岛工建工程咨询有限公司工程造价咨询甲级资质的公告

## 中华人民共和国住房和城乡建设部公告

第1720号

## 住房城乡建设部关于注销秦皇岛工建工程咨询有限公司工程造价咨询甲级资质的公告

经核查，秦皇岛工建工程咨询有限公司已不符合《工程造价咨询企业管理办法》（建设部令第149号）规定的工程造价咨询企业甲级资质标准，现注销该企业甲级资质，资质证书（证号为甲141113001990）予以废止。

特此公告。

住房城乡建设部

2017年11月1日
