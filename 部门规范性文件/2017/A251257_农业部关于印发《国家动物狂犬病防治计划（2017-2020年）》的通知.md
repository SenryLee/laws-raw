# 农业部关于印发《国家动物狂犬病防治计划（2017-2020年）》的通知

农医发〔2017〕18号

各省、自治区、直辖市及计划单列市畜牧兽医（农牧、农业）厅（局、委、办），新疆生产建设兵团畜牧兽医局，部属有关事业单位，中国农业科学院长春兽医研究所：

为贯彻落实《国家中长期动物疫病防治规划（2012-2020年）》，进一步做好动物狂犬病防治工作，根据《中华人民共和国动物防疫法》等法律法规，我部组织制定了《国家动物狂犬病防治计划（2017-2020年）》。现印发你们，请遵照执行。

农业部

2017年6月2日

附件：国家动物狂犬病防治计划（2017-2020年）
