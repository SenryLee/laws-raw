# 国家文物局关于靖远寺彩绘修缮工程立项的意见

## 关于靖远寺彩绘修缮工程立项的意见

办保函〔2017〕425号

新疆维吾尔自治区文物局：

你局《关于报送靖远寺彩绘工程立项报告的请示》（新文物保发〔2017〕26号）收悉。经研究，我局意见如下：

一、暂不同意靖远寺彩绘修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）补充彩绘工程立项的必要性分析。在前期勘察的基础上，明确现有彩绘的分布范围、保存现状、赋存环境和主要病害，客观评估2012年靖远寺文物建筑抢救性保护修缮工程效果，为科学制定保护措施提供依据。补充彩绘病害照片。

（二）补充靖远寺所在地区彩绘的传统制作工艺、材料和做法的研究分析内容。

（三）应根据前期勘察结果进一步核实工程范围，明确具体修缮措施、做法和技术要求，以现状保护为主，避免过度干预。

（四）应根据《靖远寺文物保护规划》的原则和要求，结合文物保护、展示和管理需要，统筹考虑靖远寺彩绘保护工程的进度安排。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年4月12日
