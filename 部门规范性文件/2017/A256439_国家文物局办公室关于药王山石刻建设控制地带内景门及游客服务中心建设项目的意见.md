# 国家文物局办公室关于药王山石刻建设控制地带内景门及游客服务中心建设项目的意见

办保函〔2017〕1164号

陕西省文物局：

你局《关于在药王山石刻建设控制地带内建设景门及游客服务中心的请示》（陕文物字〔2017〕167号）收悉。经研究，我局意见如下：

一、所报项目所处药王山石刻建设控制地带相关管理规定不清楚，且建设体量、规模等与药王山历史环境不协调，暂不同意所报景门及游客服务中心建设项目。

二、应重新论证项目建设的必要性和选址的科学性。如确需建设，应按照药王山石刻保护区划管理规定调整设计方案，以满足基本功能需求为前提，淡化形象设计，补充完善设计说明内容；同时科学评估建设项目的具体内容和各功能建筑的需求分析，补充、细化建设项目对药王山石刻景观环境影响评估。

三、取消建筑前广场设计，保持历史地形地貌。

四、补充方案总平面图与相关设计图纸，补充拟建景门的位置、规模等相关内容。补充建设用地的考古勘探。

五、请你局指导有关单位按照上述意见重新调整设计思路与选址、修改完善方案，按程序另行报批。

国家文物局办公室

2017年10月12日
