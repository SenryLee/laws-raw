# 住房城乡建设部办公厅关于印发《绿色建筑后评估技术指南》（办公和商店建筑版）的通知

建办科[2017]15号

各省、自治区住房城乡建设厅，直辖市建委，新疆生产建设兵团建设局：

为贯彻落实《国家新型城镇化规划（2014-2020年）》和《国务院办公厅关于转发发展改革委 住房城乡建设部绿色建筑行动方案的通知》（国办发[2013]1号），进一步提高绿色建筑发展质量，确保绿色建筑各项技术措施发挥实际效果，我部组织制定了《绿色建筑后评估技术指南》（办公和商店建筑版）（电子版可在住房城乡建设部网站下载，网址为http://www.mohurd.gov.cn）。现予以印发，请在工作中参照执行。

附件：《绿色建筑后评估技术指南》（办公和商店建筑版）

中华人民共和国住房和城乡建设部办公厅

2017年3月1日
