# 农业部关于政协十二届全国委员会第五次会议第1815号（农业水利类166号）提案答复摘要

## 关于政协十二届全国委员会第五次会议第1815号（农业水利类166号）提案答复摘要

卫小春委员：

您提出的关于农村土地承包经营权入股试点存在的法律问题思考的提案收悉。经商最高人民法院，现答复如下。

党的十八届三中全会提出“允许农民以土地承包经营权入股发展农业产业化经营”的改革任务。2015年、2016年中央1号文件明确要求引导农民以土地经营权入股龙头企业和农民合作社。为贯彻落实中央要求，农业部批复在黑龙江桦南县、江苏武进区、浙江桐庐县、山东青州市、重庆涪陵区、四川崇州市、贵州盘州市开展土地经营权入股发展农业产业化经营试点。其他一些地方也尝试性地开展了相关工作。各地在探索土地经营权入股的载体形式、土地股份组织运行机制和引导入股政策配套措施方面取得了一定的成效，但也正如您所提出的，有的地方的相关探索存在入股主体定位不准等问题，还需要进一步推动完善。

一、关于土地经营权入股载体形式

农业部在推进土地经营权入股发展农业产业化经营试点中，鼓励各地积极探索适应农村实际和农民需求的多种入股载体形式。农民以土地经营权入股，可以直接入股公司，也可以直接入股农民合作社，可以先入股到农民合作社，合作社再入股公司，也可以与公司开展非法人形式的股份合作等。但不论采取何种形式，公司、农民合作社的运行管理都应遵循有关法律法规规定。其中，农民以土地经营权先入股到农民合作社，合作社再入股公司的形式，解决了农民数量较多的情况下，公司法对有限责任公司股东人数上限的限制，同时，也有利于农民联合维护自身权益和公司开展日常经营管理，并促进农民合作社、公司享受有关政策。贵州盘州市主要采取这种形式，据统计，到2017年6月，当地已经组建以土地经营权入股的农民合作社500多个，合作社参与入股的农业项目公司100多个。

二、关于土地经营权价值评估措施

土地经营权价值评估是土地经营权入股发展农业产业化经营的关键环节之一。在指导土地经营权入股试点时，农业部将其作为探索重点。目前，各地的主要做法是按照土地年租金乘以入股年限计算土地经营权的价值，也有的按照土地租金与其他种植成本计算各方持股比例等。如黑龙江桦南县、江苏武进区、重庆涪陵区等已经出台土地经营权价值评估、发布等相关政策措施，明确土地经营权评估作价的机构、程序、方法等内容。其中，按照“收益法”评估的，即是根据近3年当地相关作物平均产量乘以平均价格，扣除相关生产成本等进行计算。有的试点中，公司、合作社的非农民股东（合作社成员）就以此作为“保底收益”的标准，每年向农民股东（合作社成员）垫付“保底收益”。

三、关于完善农地入股的法律纠纷解决机制

为了给予农民更多解决土地承包纠纷的途径，农村土地承包经营纠纷调解仲裁法规定当事人和解、调解不成或者不愿和解、调解的，可以向农村土地承包仲裁委员会申请仲裁，也可以直接向人民法院起诉。其中，申请仲裁的，如果当事人不服仲裁裁决，可以自收到裁决书之日起三十日内向人民法院起诉。多年来，农业部积极指导推动农村土地承包经营纠纷调解仲裁体系建设。截至2016年底，全国已设立仲裁委员会2472个，比2010年增长了1.4倍，其中县级仲裁委员会达到2374个，基本覆盖全国各涉农县（市、区）；聘任仲裁员达到3.9万名，比2010年增长了2.4倍。乡镇一级设立农村土地承包调解委员会31716个，村级调解组织59万个。总体上看，“乡村调解、县市仲裁、司法保障”的农村土地承包经营纠纷调解仲裁体系已基本健全，绝大部分纠纷得到及时妥善化解，一些突出问题得到解决。对于您提出的法院未形成专业审判机制问题，最高人民法院将会通过出台指导性意见、加强对法官的培训力度等方式，妥善处理涉农案件，维护农民合法权益和农村和谐稳定。

感谢您对“三农”工作的关心，希望今后继续对我部工作给予支持。

农业部

2017年9月19日
