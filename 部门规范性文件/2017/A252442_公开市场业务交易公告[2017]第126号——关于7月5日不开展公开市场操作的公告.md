# 公开市场业务交易公告[2017]第126号——关于7月5日不开展公开市场操作的公告

## 公开市场业务交易公告

[2017]第126号

近期银行体系流动性充裕，对冲金融机构缴纳法定存款准备金和央行逆回购到期等因素后，银行体系流动性总量仍处于较高水平，7月5日不开展公开市场操作。

中国人民银行公开市场业务操作室

二〇一七年七月五日
