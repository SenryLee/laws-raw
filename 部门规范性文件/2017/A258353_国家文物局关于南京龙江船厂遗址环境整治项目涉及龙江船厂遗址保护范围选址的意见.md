# 国家文物局关于南京龙江船厂遗址环境整治项目涉及龙江船厂遗址保护范围选址的意见

文物保函〔2017〕1909号

江苏省文物局：

你局《关于审批南京龙江船厂遗址保护与展示方案的请示》（苏文物保〔2017〕296号）收悉。经研究，我局意见如下：

一、原则同意南京龙江船厂遗址环境整治项目涉及龙江船厂遗址保护范围的选址方案。

二、对该方案提出如下修改意见：

（一）加强前期勘察研究，进一步收集、整理文献资料，深入分析龙江船厂所在地区的地形地貌变化，为方案设计提供科学依据。

（二）应进一步调整环境整治方案，合理确定现有建筑拆改范围和功能设置。5、6号作塘之间应以绿化为主，确保空间视廊通畅；作塘西段应采取必要的标识措施，重点展示作塘与长江的历史位置关系。

（三）建议结合扬子江大道龙江船厂遗址段下穿工程进一步深化西侧入口区域的整体设计，尽可能展示龙江船厂与夹江的空间关系，同时结合西侧海上安澜的改造和功能需求进一步科学论证东侧博物馆改扩建的必要性。

（四）明确遗址区内拆除工程的工程做法、环境修复措施和临时性文物保护措施，确保文物安全。规范文本图纸表达，补充建筑立面、剖面图。

（五）涉及龙江船厂遗址保护展示的方案按程序另行报批。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十七条规定，报江苏省人民政府批准后实施。

四、请你局组织专业考古研究单位，在项目涉及区域进一步开展必要的考古调查和发掘工作。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

五、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请你局加强工程监管，及时开展工程检查，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、请你局切实加强管理，督促、指导相关单位做好环境整治后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

国家文物局

2017年11月29日
