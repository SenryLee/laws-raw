# 中华人民共和国农业部公告第2601号——兽药标准目录

## 中华人民共和国农业部公告

第2601号

根据《兽药管理条例》规定，我部组织制定了“口蹄疫O型灭活疫苗（OHM/02株）”等3种兽药产品试行规程、质量标准、说明书和标签，现予发布，自发布之日起执行。

特此公告。

附件：1.兽药标准目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年11月3日

附件1
