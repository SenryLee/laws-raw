# 国家文物局关于贺兰山岩画文物保护利用设施建设项目的意见

## 关于贺兰山岩画文物保护利用设施建设项目的意见

办保函〔2017〕414号

宁夏回族自治区文物局：

你局《关于报送审批〈贺兰山岩画文物保护利用设施建设项目建设方案〉的请示》（宁文物发〔2017〕33号）收悉。经研究，我局意见如下：

一、所报方案设计思路不明确，设计依据不足，文本深度不够，我局暂不同意贺兰山岩画文物保护利用设施建设项目。

二、请你局组织有关单位根据我局《关于贺兰山岩画文物保护利用设施建设项目的意见》（办保函〔2017〕42号）要求，认真修改、完善方案，补充设计依据和相关资料，并按程序另行报批。

专此函。

国家文物局

2017年4月12日
