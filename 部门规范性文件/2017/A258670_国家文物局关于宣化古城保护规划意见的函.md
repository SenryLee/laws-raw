# 国家文物局关于宣化古城保护规划意见的函

文物保函〔2017〕1951号

河北省文物局：

你局《关于呈报宣化古城保护规划的请示》（冀文物字〔2017〕74号）收悉。经研究，我局意见如下：

一、原则同意所报宣化古城保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

深化历史研究，明确宣化古城的文物构成要素，进一步加强对古城格局演变的考古研究与整体保护。

（二）关于保护区划与管理规定

1. 应根据文物保护管理需要，进一步优化保护区划范围，建议将文庙纳入建设控制地带，沿城墙外围划定I类建设控制地带，并补充说明保护区划调整的理由和依据。

2. 完善保护区划管理规定，进一步明确建筑密度、体量等控制指标和要求，加强可操作性。

（三）关于保护措施

根据城墙现状分段评估结论进一步完善、细化保护措施，增强针对性和对应性。

（四） 关于环境整治和专项规划

1. 进一步明确展示利用的目标、方式和内容，不得复建城门和角楼。

2. 补充考古专项规划。

（五）加强本规划与相关规划的衔接。

（六）进一步规范、完善文本和图纸表达，补充视阈分析。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的宣化古城保护规划报请河北省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体计划或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好宣化古城的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月7日
