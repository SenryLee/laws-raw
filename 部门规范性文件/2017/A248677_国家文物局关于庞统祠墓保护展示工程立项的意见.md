# 国家文物局关于庞统祠墓保护展示工程立项的意见

## 关于庞统祠墓保护展示工程立项的意见

办保函〔2017〕243号

四川省文物局：

你局《关于庞统祠墓保护展示工程立项的请示》（川文物〔2016〕132号）收悉。经研究，我局意见如下：

一、暂不同意庞统祠墓保护展示工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）补充2010年以来已实施修缮工程情况说明和工程总结，全面评估维修后庞统祠墓的保存现状和主要问题，严格论证工程实施的必要性和可行性，补充《庞统祠墓保护规划》中相关内容。

（二）应客观分析现有展陈效果和存在问题，说明现状展陈面积、功能分区、游客量和设施设备情况等，在此基础上论证展示工程立项的必要性，明确展示利用定位，明确展示主题、方式、内容和游线设计等。

（三）根据工程量合理编制经费预算，进一步核减工程造价，补充取费标准。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促地方人民政府，进一步明确庞统祠墓的管理责任，根据《古建筑保养维护规程》及时开展文物日常养护和岁修工作，确保文物安全。

专此函。

国家文物局

2017年3月14日
