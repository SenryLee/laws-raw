# 住房城乡建设部关于2017年中国人居环境奖获奖名单的通报

建城〔2017〕224号

各省、自治区住房城乡建设厅，海南省规划委、水务厅，北京市住房城乡建设委、规划国土委、水务局、园林绿化局、城市管委，天津市城乡建设委、市容园林委、水务局、规划局，上海市住房城乡建设管理委、规划国土局、绿化市容局、水务局、城市管理执法局，重庆市城乡建设委、规划局、城市管理委，新疆生产建设兵团建设局：

经研究，决定授予江苏省如皋市、安徽省六安市2017年中国人居环境奖；授予北京市东城区东四南历史街区保护更新公众参与项目等60个项目中国人居环境范例奖。

中华人民共和国住房和城乡建设部

2017年10月27日
