# 国家文物局关于汇南墓群保护展示工程立项的意见

## 关于汇南墓群保护展示工程立项的意见

办保函〔2017〕198号

重庆市文物局：

你局《关于汇南墓群保护展示利用工程立项的请示》（渝文物〔2017〕18号）收悉。经研究，我局意见如下：

一、暂不同意汇南墓群保护展示工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步明确工程内容和工程定位，区分保护展示和环境整治工程内容。环境整治工程应按照涉及汇南墓群保护范围和建设控制地带的建设项目单独另行申报。

（二）应首先做好存在安全隐患的墓葬本体的保护加固，展示和环境整治工作应在保护规划的指导下统筹开展。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年3月2日
