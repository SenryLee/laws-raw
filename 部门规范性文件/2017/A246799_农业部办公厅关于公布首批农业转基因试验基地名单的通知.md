# 农业部办公厅关于公布首批农业转基因试验基地名单的通知

农办科〔2017〕7号

各有关单位：

为落实《国家南繁科研育种基地（海南）建设规划（2015-2025年）》的相关要求，加强南繁试验农业转基因生物安全监管工作，强化转基因研究试验的追溯管理，农业部组织开展了农业转基因试验基地申报认定工作。经专家评审，确定中国农业科学院棉花研究所三亚大茅基地等6个基地为首批农业转基因试验基地，现予以公布（名单见附件）。

农业转基因试验基地认定是南繁基地建设的重要任务，是加强转基因监管的重要措施，转基因试验将逐步纳入试验基地内进行。请确定为农业转基因试验基地的单位切实发挥示范带头作用，进一步加强基地建设和管理，为强化农业转基因试验源头监管提供保障和支撑。

附件：首批农业转基因生物试验基地名单

农业部办公厅

2017年1月23日
