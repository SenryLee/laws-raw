# 国家文物局办公室关于崇圣寺三塔保护区划内游客休息服务区域设计实施方案的意见

办保函〔2017〕1394号

云南省文物局：

你局《关于请求批准大理崇圣寺三塔文化旅游区游客服务区域设计实施方案的请示》（云文物〔2017〕158号）收悉。经研究，我局意见如下：

一、该项目所处位置和相关保护规定表述不清，技术文件不规范，暂不同意所报项目。

二、具体修改意见如下：

（一）明确保护区划范围，根据管理规定的具体要求科学评估拟建项目对文物本体及环境造成的影响。

（二）明确拟建项目的具体功能，进一步论证拟建项目的必要性和选址的合理性。

（三）设计技术文件应符合方案设计阶段的技术标准。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善后另行报批。

国家文物局办公室

2017年12月18日
