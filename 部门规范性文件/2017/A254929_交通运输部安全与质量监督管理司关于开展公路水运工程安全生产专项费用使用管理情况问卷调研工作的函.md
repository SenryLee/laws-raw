# 交通运输部安全与质量监督管理司关于开展公路水运工程安全生产专项费用使用管理情况问卷调研工作的函

交安监公函〔2017〕37号

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），长江航务管理局：

近年来，国家不断出台了有关安全生产专项经费管理制度，为公路水运工程建设领域安全生产管理工作提供了有效的经费保障，取得了明显实效。但当前公路水运工程建设领域安全生产专项经费使用管理责任不清、管理程序不明、适用范围不准确等问题尚未得到有效解决，为规范安全生产专项费用使用管理，保障专项经费有效用于安全生产工作，我司拟出台有关管理制度，现开展专项费用使用管理情况问卷调研。

请你单位组织不同投资或管理方式的3个以上公路工程在建项目及1个以上水运工程在建项目的参建单位填写调研问卷，请于9月15日前将调研问卷电子版发至专项经费调研组邮箱：458706321@qq.com。

调研问卷电子版请在交通运输部安全与质量监督管理司网站上下载。

联系人及电话：部安全与质量监督管理司公路处，桂志敬，电话：010-65292788；贵州省交通建设工程质量监督局，周斌良，电话：13985180574。
