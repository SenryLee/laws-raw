# 国家文物局办公室关于伍仁桥保护规划意见的函

办保函〔2017〕1416号

河北省文物局：

你局《关于呈报伍仁桥保护规划的请示》（冀文物字〔2017〕184号）收悉。经研究，我局意见如下：

一、所报规划保护区划不合理，规划深度不够，我局暂不同意伍仁桥保护规划。

二、所报规划应做以下必要修改和完善：

（一）应进一步明确保护对象和文物构成，论证保护区划调整的可行性。加强周边环境影响评估，特别是周边村落道路等与伍仁桥的关系和影响。

（二）建议参照《石质文物保护工程勘察规范WWT0063 2015》、《石质文物病害分类与图示WW/T0002-2007》对伍仁桥的现状进行进一步的深入评估和病害分析。

（三）应进一步强化保护措施与现状分析的对应关系。如，缺失构件若不影响结构和行人安全，原则上不补配新构件；是否清理桥面沥青，应基于桥梁的使用状况确定。

（四）石桥周边环境已明显改变，应进一步优化展示利用规划。周边建筑外观的协调需要明确基准，主出入口不宜直接与省道相连。

（五）应注意规划依据的时效性，核实规划依据所列文件的年代。进一步的优化文本与图纸，加强图文之间的逻辑关系。

三、请你局指导有关单位，根据上述意见对伍仁桥保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月26日
