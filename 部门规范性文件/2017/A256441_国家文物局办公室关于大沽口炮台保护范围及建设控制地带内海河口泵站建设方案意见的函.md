# 国家文物局办公室关于大沽口炮台保护范围及建设控制地带内海河口泵站建设方案意见的函

办保函〔2017〕1166号

天津市文物局：

你局《关于报审大沽口炮台保护范围和建设控制地带内建设海河口泵站建设方案的的请示》（津文物〔2017〕54号）收悉。

经研究，所报大沽口炮台保护范围和建设控制地带内海河口泵站建设方案尚未根据我局办保函〔2017〕909号文件认真修改完善并作出详细说明，我局暂不同意该建设方案。

请你局指导有关单位，对照我局办保函〔2017〕909号文件提出的意见，完成海河口泵站建设方案的修改工作，并按程序另行报批。

国家文物局办公室

2017年10月12日
