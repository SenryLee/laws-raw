# 国土资源部、国家测绘地理信息局关于开展全覆盖排查整治“问题地图”专项行动的通知

## 国土资源部　国家测绘地理信息局关于开展全覆盖排查整治“问题地图”专项行动的通知

国土资发〔2017〕99号

各省、自治区、直辖市测绘地理信息主管部门，中央级地图编制、出版及使用登载单位，国土资源部有关直属单位，国家测绘地理信息局所属各单位、机关各司室：

为贯彻落实中央领导近日关于全覆盖排查整治“问题地图”的重要批示精神，国土资源部、国家测绘地理信息局会同中央网信办、国办信息公开办、新闻出版广电总局、外交部、教育部、工业和信息化部、公安部、海关总署、工商总局、国家保密局、国家文物局、联参战保局等部门决定开展全覆盖排查整治“问题地图”专项行动。现将《全覆盖排查整治“问题地图”专项行动工作方案》印发给你们，请遵照执行。

2017年8月21日
