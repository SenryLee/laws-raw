# 农业部办公厅关于印发《2017年畜牧业工作要点》的通知

农办牧〔2017〕6号

各省、自治区、直辖市畜牧（农牧、农业）局（厅、委、办），新疆生产建设兵团畜牧兽医局：

为深入贯彻中央农村工作会议和中央1号文件精神，全面落实全国农业工作会议和农业部1号文件部署，切实做好2017年畜牧业各项工作，我部制定了《2017年畜牧业工作要点》。现印发你们，请结合实际，狠抓落实，确保各项工作如期完成。

农业部办公厅

2017年2月6日
