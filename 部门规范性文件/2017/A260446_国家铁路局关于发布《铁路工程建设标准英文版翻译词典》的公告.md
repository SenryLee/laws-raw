# 国家铁路局关于发布《铁路工程建设标准英文版翻译词典》的公告

国铁科法〔2017〕89号

为规范铁路工程建设标准专业词汇和技术术语的翻译，保证翻译质量，现发布《铁路工程建设标准英文版翻译词典》。原《铁路工程建设标准英文版翻译指南》（建技〔2017〕184号）同时废止。

本词典由中国铁道出版社组织出版发行。

国家铁路局

2017年12月22日
