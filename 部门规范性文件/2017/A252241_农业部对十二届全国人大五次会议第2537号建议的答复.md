# 农业部对十二届全国人大五次会议第2537号建议的答复

## 对十二届全国人大五次会议第2537号建议的答复

汪尔琪、郭丽虹代表：

你们提出的关于加大对赤峰市打造京津冀地区绿色蔬菜基地政策支持力度的建议收悉。经商财政部，现答复如下。

赤峰市地处我国北部高纬度夏秋蔬菜优势区域，夏季凉爽，光照条件充足、生物资源丰富、生态环境优良，发展夏秋淡季蔬菜优势明显，是京津冀地区蔬菜的重要供应基地。近年来，赤峰市设施蔬菜带动农牧民增收作用显著，已成为以产业扶贫落实精准扶贫的有力抓手。我部高度重视赤峰市蔬菜产业绿色发展，从资金、项目等多方面，对赤峰市蔬菜产业链的多个关键环节给予重点支持，助力其打造京津冀地区绿色蔬菜基地。

一是提高优质种苗供应能力。2011年以来，通过农业综合开发、现代种业提升工程等项目，共安排中央财政资金1000多万元，支持赤峰市建设设施蔬菜优质种苗繁育基地以及集约化育苗基地，保障了蔬菜种苗供应。二是加强蔬菜基础设施建设。2013年，中央财政安排资金1250万元，支持赤峰市开展北方城市冬季设施蔬菜开发试点，新建标准化蔬菜温室大棚2500亩，集成了绿色高产高效标准化技术模式，提高了内蒙古自治区冬春蔬菜自给率。三是推进蔬菜标准化生产。2010年以来，安排中央财政资金400多万元，支持赤峰市建设蔬菜标准园8个，推进“五化生产”（规模化种植、标准化生产、商品化处理、品牌化销售、产业化经营），强化“五项管理制度”（农药管理、档案记录、产品检测、产地准出和质量追溯），构建全程绿色生产和质量安全管理长效机制，稳定提高赤峰市蔬菜产品质量安全水平。四是加强生产信息引导。2013年以来，每年支持内蒙古24万元，用于支持松山区、宁城县、五原县等8个县区开展蔬菜生产信息监测，每个县区设10个信息采集点。通过蔬菜生产信息监测，及时掌握蔬菜生产动态情况，科学研判发展趋势，适时发布预警信息，指导农民合理安排生产，引导产品有序流通，增强调控的主动性，促进生产稳定发展、市场均衡供应。

下一步，我部将继续支持赤峰市以市场需求为导向，发挥自身优势，挖掘蔬菜绿色发展潜力，加强蔬菜品牌创建，助力赤峰市打造京津冀地区绿色蔬菜基地。

感谢你们对三农事业的关心与支持，希望今后继续支持我部工作。

农业部

2017年7月7日
