# 国家文物局关于在阿尤赛沟口墓群和则克台萨哈西北墓群G218公路拟建区域进行考古发掘的意见

## 关于在阿尤赛沟口墓群和则克台萨哈西北墓群G218公路拟建区域进行考古发掘的意见

办保函〔2017〕706号

新疆维吾尔自治区文物局：

你局《关于抢救性发掘伊犁州新源县G218线种羊场至那拉提（DNSJ-2、3）段选址区域内自治区级文物保护单位的请示》（新文物字〔2017〕9号）收悉。经研究，我局意见如下：

一、G218公路建设项目涉及阿尤赛沟口墓群和则克台萨哈西北墓群两处省级文物保护单位保护范围，请你局按照《中华人民共和国文物保护法》和《国家文物局行政审批事项办事指南》要求，完善申请材料，先行报批G218公路涉及阿尤赛沟口墓群和则克台萨哈西北墓群两处省级文物保护单位的选址方案。

二、该路段选址方案获得我局批复前，暂不同意相关考古发掘项目。

国家文物局

2017年6月5日
