# 中华人民共和国农业部公告第2558号——新兽药注册目录

## 中华人民共和国农业部公告

第2558号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准河南省康星药业股份有限公司等6家单位申报的商陆口服液等2个产品为新兽药，核发《新兽药注册证书》，并发布产品质量标准、说明书和标签，自发布之日起执行。

特此公告。

附件：1.新兽药注册目录

2.质量标准（略）

3.说明书和标签

农业部

2017年8月2日
