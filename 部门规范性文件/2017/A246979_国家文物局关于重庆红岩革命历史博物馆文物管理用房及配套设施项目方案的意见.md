# 国家文物局关于重庆红岩革命历史博物馆文物管理用房及配套设施项目方案的意见

## 关于重庆红岩革命历史博物馆文物管理用房及配套设施项目方案的意见

办保函〔2017〕43号

重庆市文物局：

你局《关于报送重庆红岩革命历史博物馆文物管理用房及配套设施项目方案的请示》（渝文物〔2016〕337号）收悉。经研究，我局意见如下：

一、暂不同意该方案。

二、应对方案进行以下必要的补充和修改：

（一）补充八路军驻重庆办事处旧址文物保护规划中关于建设控制地带的管理规定及相关控制指标，并就拟建项目做出符合性说明。

（二）补充拟建项目对八路军驻重庆办事处旧址文物环境影响评估。同时应根据实际使用需求合理压缩新建建筑设计体量，淡化入口广场和屋顶广场等景观设计，避免对文物历史环境风貌造成不良影响。

请你局指导项目单位根据上述意见对方案进行完善，按程序另行报批。

国家文物局

2017年1月20日
