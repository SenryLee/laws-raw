# 文化部、财政部、海关总署、税务总局关于公布2018年进口免税资格动漫企业名单的通知

## 文化部　财政部　海关总署　税务总局关于公布2018年进口免税资格动漫企业名单的通知

文产函〔2017〕1211号

各省、自治区、直辖市文化厅（局）、财政厅（局）、国家税务局，新疆生产建设兵团文化广播电视局、财务局，各计划单列市文化局、财政局、国家税务局，海关总署广东分署、各直属海关：

根据《财政部 海关总署 国家税务总局关于动漫企业进口动漫开发生产用品税收政策的通知》（财关税〔2016〕36号），文化部会同财政部、海关总署、税务总局对2017年提出进口免税资格申请和年审的企业进行了审核。

经审核，北京大千阳光数字科技股份有限公司等2家企业（具体名单见附件1）自2018年起获得进口免税资格，有效期自2018年1月1日起至2018年12月31日止。北京迪生动画制作有限公司等31家企业（具体名单见附件2）通过2017年进口免税资格年审，继续获得进口免税资格，有效期延至2018年12月31日止。北京万豪天际文化传播股份有限公司等3家企业（具体名单见附件3）未提出年审申请，列入2017年进口免税资格年审不合格名单，自2018年1月1日起取消其进口免税资格。

2018年具有进口免税资格的企业应按照《文化部办公厅关于转发〈财政部 海关总署 国家税务总局关于动漫企业进口动漫开发生产用品税收政策的通知〉的通知》（办产函〔2016〕315号）的有关规定，于2018年9月15日前向所在省（自治区、直辖市）文化厅（局）、计划单列市文化局提出年审申请。年审合格企业将继续获得下一年度进口免税资格，年审不合格企业自下一年度起取消其进口免税资格，不提出年审申请的企业将列入年审不合格企业名单。

特此通知。

附件：1.自2018年起获得进口免税资格的动漫企业名单

2.2017年进口免税资格年审合格动漫企业名单

3.2017年进口免税资格年审不合格动漫企业名单

文化部　　财政部　　海关总署　　税务总局
