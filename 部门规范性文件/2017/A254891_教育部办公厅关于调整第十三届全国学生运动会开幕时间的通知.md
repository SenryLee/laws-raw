# 教育部办公厅关于调整第十三届全国学生运动会开幕时间的通知

教体艺厅函〔2017〕36号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

由教育部、国家体育总局、共青团中央联合主办，浙江省人民政府承办的第十三届全国学生运动会，原定于2017年9月4日在浙江省杭州市举行的开幕式因故提前至9月3日举行（原定赛事时间不变），请做好因开幕式时间调整而带来的组织协调工作。

（联系人及电话：许弘 010-66096472）

教育部办公厅
