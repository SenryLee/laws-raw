# 农业部办公厅关于组织报送境外农业合作示范区和农业对外开放合作试验区建设试点进展情况的通知

农办外〔2017〕12号

各有关省、自治区、直辖市及计划单列市农业（农牧、农村经济）、农机、畜牧、兽医、农垦、农产品加工、渔业（水利）厅（局、委、办），新疆生产建设兵团农业局，中国热带农业科学院：

为贯彻党中央、国务院关于促进农业对外合作的总体精神，按照农业对外合作部际联席会议统一部署，我部于2017年7月分别认定塔吉克斯坦—中国农业合作示范园等10个境外园区和海南省琼海市等10个试验区为首批境外农业合作示范区和首批农业对外开放合作试验区（以下简称“两区”）建设试点（见农外发〔2017〕3号文）。试点开展以来，在各相关省（区、市）农业主管部门的指导下，牵头企业和组织实施单位充分发挥自身优势，完善建设实施方案，加强全产业链建设，打造政策集成创设平台，强化政策先行先试，园区建设工作取得一定成效。

为全面掌握试点认定以来“两区”建设的进展情况，认真梳理总结试点的好经验、好做法，分析解决存在的困难和问题，进一步推进“两区”建设，请你单位组织“两区”建设试点牵头企业和实施单位报送试点进展情况总结（2000字以内），按要求填报“两区”建设进展情况统计表（见附件1、2），并于12月5日前将纸质件一式1份（盖章）、电子版报送农业部国际合作司。
