# 中华人民共和国农业部公告第2497号——进口兽药注册目录

## 中华人民共和国农业部公告

第2497号

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准梅里亚有限公司法国生产厂等2家公司生产的猪圆环病毒2型灭活疫苗（1010株）等2个兽药产品在我国注册，核发《进口兽药注册证书》,并发布产品质量标准、说明书和标签，自发布之日起执行。

批准梅里亚有限公司（美国）等4家公司生产的鸡马立克氏病Ⅰ型、Ⅲ型二价活疫苗等4个兽药产品在我国再注册，并发布修订后的产品质量标准、说明书和标签，自发布之日起执行。此前发布的同品种兽药质量标准、说明书和标签同时废止。

批准罗曼动物保健国际生产的鸡毒支原体灭活疫苗（R株）等5种兽药产品在我国变更注册。

特此公告。
