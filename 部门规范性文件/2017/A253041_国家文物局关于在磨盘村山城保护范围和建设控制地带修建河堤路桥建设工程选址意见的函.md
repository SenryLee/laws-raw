# 国家文物局关于在磨盘村山城保护范围和建设控制地带修建河堤路桥建设工程选址意见的函

## 关于在磨盘村山城保护范围和建设控制地带修建河堤路桥建设工程选址意见的函

办保函〔2017〕618号

吉林省文物局：

你局《关于在磨盘村山城保护范围和建设控制地带修建河堤、路桥的请示》（吉文物发〔2017〕97号）收悉。经研究，我局意见如下：

一、暂不同意吉林延边延龙图新区布尔哈通河、海兰河综合治理工程及路桥建设工程项目涉及磨盘村山城保护范围和建设控制地带的选址方案。

二、所报方案尚需做以下必要的修改和完善：

（一）补充说明《磨盘村山城保护规划》对该项目拟建区域的管理规定和具体控制性指标。

（二）补充说明该项目拟建区域地下文物遗存的分布及保存情况。若有必要，应补充开展全面的考古勘探。

（三）补充说明吉林延龙图文化旅游区涉及磨盘村山城保护范围和建设控制地带的项目布设情况、相应的技术性指标，以便统筹考虑拟建项目对磨盘村山城的影响。

（四）进一步开展必要的景观视廊分析，评估布尔哈通河、海兰河综合治理工程及路桥建设工程对磨盘村山城景观环境的影响，并提出有针对性的减缓措施。

三、请你局指导建设单位，根据上述意见对所报方案作进一步修改和完善，按程序另行报批。

国家文物局

2017年5月22日
