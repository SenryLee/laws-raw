# 国家文物局关于徐显秀墓保护性设施建设工程立项的意见

## 关于徐显秀墓保护性设施建设工程立项的意见

办保函〔2017〕204号

山西省文物局：

你局《关于王家峰北齐徐显秀墓保护设施建设工程立项的请示》（晋文物〔2016〕218号）收悉。经研究，我局意见如下：

一、暂不同意王家峰墓群徐显秀墓保护性设施建设工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）墓葬封土建设堆膜结构保护棚必要性和可行性不足，应采用传统方法对封土进行保护加固，避免对封土风貌造成较大干扰。

（二）墓道保护棚的设计应充分考虑当地环境因素，加强针对高温、高湿、冻融等破坏因素的防范措施。

（三）补充墓道保护棚运营和维护成本的评估，说明长期运营维护的可行性。

三、请你局指导当地人民政府，进一步加强对徐显秀墓本体、壁画及现有保护性设施的日常维护与监测，确保文物安全。若保护性设施确有改造必要，应根据上述意见组织相关单位对立项报告进行修改完善，并进一步阐明必要性与可行性，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年3月2日
