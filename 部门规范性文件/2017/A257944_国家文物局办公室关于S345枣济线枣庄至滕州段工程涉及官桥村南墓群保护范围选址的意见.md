# 国家文物局办公室关于S345枣济线枣庄至滕州段工程涉及官桥村南墓群保护范围选址的意见

办保函〔2017〕1265号

山东省文物局：

你局《关于S345枣济线枣庄至滕州段工程涉及官桥村南墓群选址的请示》（鲁文发〔2017〕100号）收悉。经研究，我局意见如下：

一、所报项目拟穿越山东省重点文物保护单位官桥村南墓群保护范围，严重影响墓葬本体保护及其周边环境风貌，我局暂不同意所报S345枣济线枣庄至滕州段工程涉及山东省重点文物保护单位官桥村南墓群保护范围的选址方案。

二、请你局指导建设单位切实加强前期论证和文物影响评估，进一步说明项目选址的必要性，客观分析公路建设影响，建议避开官桥村南墓群保护范围另行选址。

国家文物局办公室

2017年11月16日
