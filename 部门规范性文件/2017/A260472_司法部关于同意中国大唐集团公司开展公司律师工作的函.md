# 司法部关于同意中国大唐集团公司开展公司律师工作的函

司发函〔2017〕264号

中国大唐集团公司：

你公司《关于申请开展公司律师试点工作的函》(大唐集团法函〔2017〕53号)收悉。经研究，同意在中国大唐集团公司开展公司律师工作，批准来函所附《中国大唐集团公司关于构建公司律师队伍的工作方案》。

请根据《司法部关于开展公司律师试点工作的意见》(司发通〔2002〕79号)，将申请担任公司律师人员名单、基本情况等材料送我部审核。

司法部

2017年9月23日
