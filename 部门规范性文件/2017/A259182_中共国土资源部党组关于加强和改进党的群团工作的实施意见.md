# 中共国土资源部党组关于加强和改进党的群团工作的实施意见

（2017年12月26日）

国家海洋局、国家测绘地理信息局，中国地质调查局及部其他直属单位，各派驻地方的国家土地督察局，部机关各司局：

为深入贯彻中央党的群团工作会议精神特别是习近平总书记关于党的群团工作和群团改革的系列重要指示精神，根据《中共中央关于加强和改进党的群团工作的意见》（中发〔2015〕4号）和《中央国家机关工委关于进一步加强中央国家机关党的群团工作的指导意见》（国工发〔2017〕10号）要求，现就进一步加强和改进新形势下国土资源部党的群团工作制定如下实施意见。

一、把握做好新形势下群团工作的总体要求

（一）重要意义。群团事业是党的事业的重要组成部分，党的群团工作是党通过群团组织开展的群众工作，是党组织动员广大人民群众为完成党的中心任务而奋斗的重要法宝。近年来，部直属机关各级群团组织紧紧围绕国土资源管理工作大局，发挥自身特点和优势，推进群团工作转型发展和机制创新，团结动员广大群众投身国土资源管理主战场，做出了积极贡献。新形势下，党的群团工作只能加强、不能削弱，只能改进提高、不能停滞不前。

（二）指导思想。新形势下加强和改进党的群团工作，必须贯彻落实党的十八大和十八届三中、四中、五中、六中全会及中央党的群团工作会议精神，高举中国特色社会主义伟大旗帜，以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻习近平总书记系列重要讲话精神，全面落实中央关于党的群团工作的重大决策部署，深刻把握中国特色社会主义群团发展道路“六个坚持”的基本要求和“三统一”的基本特征，坚持围绕中心、服务大局、解放思想、改革创新，切实保持和增强党的群团工作的政治性、先进性和群众性，以密切党同人民群众的血肉联系为核心，以发挥群团组织优势和作用为重点，最广泛地把群众组织起来、动员起来、团结起来，统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，努力提高国土资源供给质量和效率，为实现“两个一百年”奋斗目标奠定更加坚实的资源基础。

（三）基本要求。要保持和增强党的群团工作的政治性，始终把群团组织置于党的领导之下，在思想上政治上行动上始终同以习近平同志为核心的党中央保持高度一致，把所联系的群众最广泛最紧密地团结在党的周围，确保群团工作和群团组织始终沿着正确政治方向前进。要保持和增强群团组织的先进性，紧紧围绕党和国家及部的工作大局，找准工作的结合点和着力点，组织动员广大人民群众在改革发展稳定第一线建功立业、贡献力量，教育引导广大人民群众坚定走中国特色社会主义道路，自觉践行社会主义核心价值观。要保持和增强群团组织的群众性，以群众为中心，更多关注、关心、关爱普通群众，维护和发展群众利益，建立健全联系群众的长效机制，争当全心全意为人民服务宗旨的忠实践行者、党的群众路线的坚定执行者、党的群众工作的行家里手。

二、切实加强党对群团工作的组织领导

（四）落实群团工作领导责任。各级党组织要加强和改进对群团工作的统一领导，把群团工作摆上重要议程，落实把好方向的责任，加强对群团组织的政治领导和思想引领；落实统筹指导的责任，把群团工作纳入党组织工作总体格局，与其他工作同部署同检查同总结；落实用好干部的责任，把群团组织作为锻炼培养干部的重要阵地。党组织主要负责同志要亲自抓、带头抓群团工作，积极参加群团组织的重大活动。

（五）健全群团工作领导体制。群团组织实行分级管理、以同级党组织领导为主的体制，工会、共青团、妇联等受同级党组织和上级组织双重领导。同级党组织应该注意听取上级群团组织意见，加强沟通协调，形成工作合力。上级群团组织依法依章程领导或指导下级群团组织工作。各司局一般由支部书记或副书记分管群团工作，各督察局一般由机关党委书记或副书记分管群团工作，各直属单位一般由党组织书记或副书记分管群团工作，具体分工根据实际确定。

（六）完善党建带群建工作机制。坚持党组织统一领导、党政齐抓共管、部门各负其责、党员干部带头示范、群团组织履职尽责的工作格局。部门党组织把群团建设纳入党建工作总体部署，统筹基层党群组织工作资源配置和使用，做到共建组织、队伍、阵地，实现群建与党建工作统一部署、检查、考评。制定群团组织推优办法，把群团组织推优作为产生入党积极分子人选的方式之一。

（七）建立健全相关工作制度。建立健全党组织定期研究群团工作制度。部党组每年至少研究1次群团工作，部党建工作领导小组及时研究解决群团工作中的问题。部直属机关各级党组织要定期听取群团工作汇报，每年至少专题研究1次群团工作，党委每届任期内至少召开1次群团工作会议。建立健全群团组织负责人参加或列席有关会议制度。党组织有关工作会议应请工会、共青团、妇工委等群团组织主要负责人参加或列席。有关司局研究涉及群众切身利益和群团组织相关工作的政策法规、发展规划、重大决策时，应注意听取群团组织意见。建立健全群团工作督查考核制度。把群团工作纳入各级基层党组织绩效目标考核，把群团工作成效作为考核领导班子和分管负责同志的重要内容。

三、推动群团组织在国土资源管理改革发展中发挥作用

（八）凝聚思想共识。群团组织要自觉增强政治意识、大局意识、核心意识、看齐意识，坚决同以习近平同志为核心的党中央保持高度一致，坚决贯彻党的意志和主张，坚决落实党的决策部署，引领广大干部职工永远听党话、跟党走。要组织动员广大干部职工积极践行创新、协调、绿色、开放、共享发展理念。要把推动国土资源管理改革发展作为群团组织的重大任务，深入开展形势任务教育，引导广大干部职工充分认识深化改革的重大意义，准确把握改革的总体部署，进一步统一思想、坚定信心，促进形成最广泛的合力。要组织干部职工特别是青年干部深入国土资源管理基层一线学习调研，了解实际情况，增进群众感情，增强责任感使命感。

（九）服务中心工作。群团组织要致力发挥团结动员群众干事创业的积极作用，围绕“尽职尽责保护国土资源、节约集约利用国土资源、尽心尽力维护群众权益”工作定位，围绕国土资源“十三五”规划各项任务，紧紧结合自身职责，深入开展群众性劳动竞赛、技能比武、创建职工之家、“青年文明号”、“青年岗位能手”、“巾帼建功”、“业务论坛”、“能力建设”等活动，把工人阶级主力军、青年生力军、妇女半边天作用和人才第一资源作用，转化为促进国土资源管理改革发展的强大力量。要创新动员形式，在保障重大任务、支援抢险救灾、应对重大突发事件中发挥积极作用。要积极参与民主政治建设。要通过开展法制宣传教育、动员干部职工践行社会主义法治精神等工作，在推进法治国土建设中发挥积极作用。要结合各自特色优势，通过开展志愿服务、搭建帮扶平台、宣传方针政策、倡树新风正气等工作，在国土资源助力脱贫攻坚工作中发挥积极作用。

（十）维护群众权益。群团组织要把竭诚为职工群众服务作为工作的出发点和落脚点，坚持贴近职工需求、贴近职工思想状况开展活动，使群团组织真正成为群众信赖的职工之家、青年之家、妇女之家、科技工作者之家。要千方百计为干部职工服务，力所能及地为干部职工办实事、解难事，开展好送温暖活动，把部党组对广大干部职工的关心关爱落到实处，让干部职工有更多的获得感和归属感。要加强人文关怀和心理疏导，关注职工的身心健康，定期深入群众，了解干部职工所思所想。

（十一）推动科技创新。群团组织要积极配合有关职能部门，围绕“三深一土”，通过创新论坛、创新大赛等形式，营造浓厚的创新氛围。大力宣传科技创新典型的先进事迹，引导干部职工形成锐意进取的良好风尚。开展“科学道德和学风建设”主题活动，引导科技工作者弘扬科学精神，发挥示范作用。广泛深入开展科普活动，引导群众崇尚科学、提高科学素质。

四、推动群团组织引导群众自觉培育和践行社会主义核心价值观

（十二）加强对群众的思想引导。群团组织要从广大群众思想实际出发，把社会主义核心价值观转化为生动活泼、特色鲜明、富有成效的群众性实践，引领广大干部职工崇德向善、敬业诚信、遵纪守法、互助友爱、文明和谐。广泛开展“职业道德建设”、“奋斗的青春最美丽”、“五好家庭”、“培育良好家风” 等主题教育活动，引导广大职工弘扬劳模精神、劳动精神和工人阶级伟大品格，加强对青年的理想信念教育，引导女职工弘扬传统美德和自尊自信自立自强精神，培育良好家风、以好的家风支撑起良好的社会风气。

（十三）传承国土资源系统优良传统。群团组织要引导广大群众不忘初心、继续前进，继承和发扬国土资源前辈留下的光荣传统和优良作风，学习他们理想高远、信念坚定的精神品质，维护党规、严守党纪的自觉意识，正心修身、敬事爱民的高尚情怀，真抓实干、鞠躬尽瘁的奋斗精神，引领广大群众满怀对党和人民的无限忠诚、对国土资源事业的真诚热爱，在保护资源、保障发展、维护权益的实践中矢志奋斗、做出贡献。

（十四）注重典型示范引领。坚持把群团组织创先争优当作一项经常性工作抓紧抓好，继续开展“劳动模范”、“青年五四奖章”、“三八红旗手”等推荐评选活动，引导广大群众争做中华民族传统美德的传承者、社会主义道德规范的实践者和科学精神的传播者。广泛开展向身边的先进典型学习活动，发挥各类先进典型、劳动模范的示范带头作用，努力在部直属机关形成学习先进、追赶先进、争当先进的良好氛围。

五、推动群团组织改革创新增强活力

（十五）深化群团改革。部直属机关各级党组织要负起组织推进群团改革的责任，正确把握方向，及时了解情况，认真解决难题，以改革推动群团组织提高工作和服务水平，努力开创党的群团工作新局面。要认真落实中央群团改革精神和全国总工会、共青团中央、全国妇联、中国侨联和中央国家机关工委的要求，紧密结合部直属机关实际，稳步推进各级群团组织改革，通过创新性工作加强自身建设、增强发展活力、赢得群众信任。

（十六）改进群团组织工作作风。群团组织要切实增强危机感、紧迫感、使命感、责任感，切实增强主业意识和主责精神，积极作为、主动担当，下力气解决群团基层组织薄弱、群团工作吸引力凝聚力不够、群团活动形式单一、群团作用发挥不够等突出问题。群团组织要严格遵循“三严三实”要求，自觉践行党的群众路线，把密切联系群众作为根本的工作作风，推行群团干部直接联系基层群众制度，坚决克服“机关化、行政化、贵族化、娱乐化”现象。

（十七）推动群团工作全覆盖。以提高吸引力、凝聚力、战斗力和扩大有效覆盖面为目标，创新群团组织设置、成员发展、联系群众、开展活动的方式，立体化、多层面扩大组织覆盖、工作覆盖和活动覆盖。部直属机关各单位要根据有关规定进一步建立和完善各级工青妇组织，机关司局要设立分工会、青年小组，鼓励司局党支部设立青年委员；各督察局要设立工会、妇女组织，根据情况成立团组织或青年小组；直属事业单位也要建立健全相应群团组织。

（十八）提高群团工作科学化水平。努力适应新形势下做好群团工作的新要求，不断解放思想，更新观念，以群众喜闻乐见、便于参加的形式和方法开展工作。要开展丰富多彩的集体活动，增进干部职工集体主义观念。鼓励建立各类职工文体协会、兴趣小组和青年联合会。加强网上群团建设，充分发挥信息化技术在畅通工作渠道、拓宽工作覆盖面、提高工作效率方面的作用，用好手机APP、微信、微博等新媒体平台。

六、加大对群团工作的支持保障力度

（十九）完善群团工作经费保障制度。各单位要依法依规按时足额计拨上缴工会经费。要保障共青团和妇女工作经费。规范群团组织经费管理使用制度，任何组织和个人不得侵占、挪用群团组织经费。

（二十）加强群团组织干部队伍建设。要将群团干部培养纳入干部工作总体规划，把群团工作岗位作为提高干部做群众工作能力的重要平台。要高度重视群团组织基础建设，督促指导按时换届，配齐配强群团组织负责人。群团组织一般要有专职干部。工会、共青团、妇女组织的副职和委员要增加一线代表的比例。职工200人以上的单位的工会，可以设专职工会主席或者副主席，在单位领导班子职数内，主席可以按同级副职配备。要适应新形势要求，积极探索不同于党政干部的群团组织干部管理方式，采取多元化兼职化的方式充实群团干部队伍。建立青年、妇女人才库，把群团组织建设成为培养输送优秀干部的重要基地。支持群团组织定期开展干部队伍培训，纳入干部教育培训整体规划。

（二十一）支持群团组织依照各自章程行使职能职责。尊重群团组织性质、特点和规律，支持群团组织发挥各自优势、体现群众特点，创造性开展工作。群团组织要把握好自身职能定位，增强主动精神，广泛开展具有思想性、教育性的群众性活动。部属新闻媒体要加强对群团工作的舆论宣传，组织、人事、财务、科技等部门要发挥各自优势，推动群团事业发展。
