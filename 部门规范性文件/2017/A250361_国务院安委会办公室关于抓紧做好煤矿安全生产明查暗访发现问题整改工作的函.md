# 国务院安委会办公室关于抓紧做好煤矿安全生产明查暗访发现问题整改工作的函

安办函〔2017〕25号

湖南省安全生产委员会：

2017年3月22日至24日，国务院安委会办公室组织对你省邵阳市、娄底市煤矿安全生产工作进行了明查暗访，随机检查4处煤矿，发现以下突出问题：

一、未按规定核定灾害严重矿井生产能力。湘煤集团牛马司矿业公司水井头煤矿为煤与瓦斯突出矿井，现场检查发现该矿未按国家安全监管总局等四部门印发的《关于开展灾害严重煤矿生产能力核定工作的通知》（安监总煤行〔2015〕98号）要求重新核定煤矿生产能力。

二、机电运输管理存在明显差距、标准化水平低。一是钢丝绳未按规定检验、检查。湘煤集团牛马司矿业公司水井头煤矿升降人员和物料用的缠绕式提升钢丝绳，自2016年1月以来未进行性能检验；新钢丝绳悬挂前，未对钢丝绳做拉断、弯曲和扭转试验；湖南华润煤业有限公司良相煤矿2017年3月5日发生断绳跑车事故后，在检查发现钢丝绳里层锈蚀严重的情况下，仅对主绳进行了更换，相同使用条件下的副绳没有更换、仍在使用。二是在用调度绞车不达标。湖南华润煤业有限公司良相煤矿4部在用绞车普遍存在排绳杂乱、安全距离不足、信号位置设置不合理等问题。三是运输皮带不达标。湖南华润煤业有限公司良相煤矿1133回采工作面带式输送机保护装置不全，皮带磨损严重，接头连接、托辊间距不符合规定。四是在用矿车不达标。湖南华润煤业有限公司良相煤矿多数矿车碰头磨损严重、甚至缺失，部分矿车变形严重、无防脱销。五是轨道铺设不达标。湖南华润煤业有限公司良相煤矿+225进风石门轨道仍采用禁止使用的“驴尾巴”道岔（简易道岔），且井下多处轨缝间隙达60mm以上。

三、通防管理不到位，瓦斯抽采不足。湘煤集团牛马司矿业公司水井头煤矿未严格执行测风制度，总回风巷每月仅测1次风量，矿井安全监测系统没有实现热备，系统容量小，导致瓦斯传感器、开关量不够；33210掘进工作面停风后短时间内瓦斯浓度快速上升到1.98%，采煤工作面瓦斯浓度波动大，出煤时瓦斯浓度接近平时瓦斯浓度的2倍，反映出矿井瓦斯抽采效果不能满足生产要求。

四、矿井调度台账作假，隐患排查治理流于形式。湘煤集团牛马司矿业公司水井头煤矿监测监控报警台账载明：“1月19日，33210掘进工作面瓦斯超限的原因是运输工字钢刮坏风筒”，但调度记录台账载明“33210掘进工作面监测监控断线”，应付检查；3月22日检查时发现，3128采煤工作面不但隐患排查已经填写到3月30日，同时隐患整改也已经填写完成，并且代替责任人、验收人签字，弄虚作假。

五、采煤工作面标准化水平低。湖南华润煤业有限公司良相煤矿1133回采工作面支护质量达不到要求，单体液压支柱迎山角不符合规定，三用阀方向不一，多处支柱违规支设在顶梁鱼口处，“三直一平”严重超出规定；同时工作面上、下出口断面小、高度不符合规定，上、下两巷顶板离层仪均损坏，起不到监测顶板离层的作用，围岩变形观测牌板记录数据与实际相差较大，无法反映真实情况；火工品管理不严格，炸药箱、雷管箱存放位置不符合支护完整、避开电气设备的要求。

六、停产矿井管理存在漏洞。邵阳市邵阳县马塘湾煤矿自2016年初以来一直处于停产状态，井口未设置防止人员误入的警示标识和栅栏。

七、机电运输事故多发。在2017年娄底市涟源祖保煤矿“2?14”事故发生后，湖南华润煤业有限公司没有吸取事故教训，唐洞煤矿2月27日发生一起放炮事故、造成1人死亡，良相煤矿3月5日发生一起副井断绳跑车运输事故，造成1人死亡、1人重伤。

请你省高度重视明查暗访发现的问题，认真抓好整改落实，并举一反三，做好以下工作：

一、对灾害严重未按规定进行能力核定的矿井，要立即督促开展能力核定工作，在重新核定前，矿井按不超过原生产能力的80%组织生产。

二、督促煤炭行业管理部门专题研究煤矿机电运输问题，部署机电运输专项整治工作，要求煤矿企业加快实施运输方式革新、运输设备升级改造，对不合格、不达标的机电运输设备、设施坚决停用，彻底解决运输方式落后、运输环节多、隐患多、事故多发的问题。

三、督促煤矿企业加强煤矿安全基础建设，并严格煤矿安全生产标准化达标考核定级，建议省级安全生产标准化主管部门降低或取消湖南华润煤业有限公司良相煤矿二级安全生产标准化等级。

四、督促省、市、县煤矿安全监管部门，针对下一步复工复产煤矿增多的实际，严格复工复产程序、验收标准和签字手续，对存在隐患或隐患整改不到位、不具备安全生产条件的煤矿，一律不得签字予以复工复产，对于停产矿井，逐矿落实包矿盯守责任，坚决防范和遏制煤矿重特大事故发生。

五、你省要加大淘汰落后产能的决心和力度，依据国发〔2016〕7号、国办发〔2013〕99号等文件要求，借助煤炭行业化解过剩产能平台，利用市场化、法治化手段，重点关闭9万吨/年及以下不具备安全生产条件的煤矿，加快关闭9万吨/年及以下煤与瓦斯突出等灾害严重的煤矿，坚决关闭发生较大及以上责任事故的9万吨/年及以下的煤矿。

请于2017年4月21日前报送国务院安委会办公室整改落实情况。

国务院安委会办公室

2017年4月7日
