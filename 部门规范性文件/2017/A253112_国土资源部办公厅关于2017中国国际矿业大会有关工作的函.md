# 国土资源部办公厅关于2017中国国际矿业大会有关工作的函

国土资厅函〔2017〕1118号

各省、自治区、直辖市国土资源主管部门，中国地质调查局及部其他相关直属单位，部机关各相关司局：

经国务院批准，由国土资源部、天津市人民政府、中国矿业联合会共同主办的2017中国国际矿业大会将于2017年9月23日至25日在天津市举行，并将同期举办矿业博览会。

本次会议将深入贯彻落实“创新、协调、绿色、开放、共享”的新发展理念，助推“一带一路”建设，就全球矿业形势与政策、矿业投资与金融、矿业勘探与开发、矿业绿色发展等专题进行研讨，重点组织国内外矿业合作项目的推介、洽谈、交流和签约等活动，进一步推动国内外矿业企业开展实质性项目合作。

为加强项目对接交流，推动国内外矿业企业开展实质性项目洽谈与合作，请各单位协助组织相关地勘单位和矿业企业填写推介洽谈项目表（见附件），于8月20日前报至部中央地质勘查基金管理中心。

请各省级国土资源主管部门结合工作实际，协助组织做好本地区地勘单位、矿业企业的参会参展相关工作。请部相关司局、直属单位按分工做好有关筹备工作。
