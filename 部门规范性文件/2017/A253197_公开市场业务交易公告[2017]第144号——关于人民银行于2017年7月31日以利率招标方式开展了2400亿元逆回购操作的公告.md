# 公开市场业务交易公告[2017]第144号——关于人民银行于2017年7月31日以利率招标方式开展了2400亿元逆回购操作的公告

## 公开市场业务交易公告

[2017]第144号

人民银行于2017年7月31日以利率招标方式开展了2400亿元逆回购操作。具体情况如下：

逆回购操作情况

| 7天 | 1600亿元 | 2.45% |
| 14天 | 800亿元 | 2.60% |
