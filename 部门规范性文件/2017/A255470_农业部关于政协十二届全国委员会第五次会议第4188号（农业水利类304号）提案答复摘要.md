# 农业部关于政协十二届全国委员会第五次会议第4188号（农业水利类304号）提案答复摘要

## 政协十二届全国委员会第五次会议第4188号（农业水利类304号）提案答复摘要

一、关于把三江平原建设成国家粮食生产功能区和国家重要农产品保护区并加大建设力度问题

国家高度重视三江平原农业发展，加强基础设施建设，巩固提升粮食产能。一是加强高标准农田建设。近年来，通过新增千亿斤粮食产能田间工程投资渠道，支持建设高标准农田，改善了三江平原地区农业基础设施条件。二是加强东北黑土地保护。2015年以来，中央财政每年安排专项资金5亿元，在东北四省（区）选择17个县（市、区、旗）开展东北黑土地保护利用试点。下一步，农业部将按照《东北黑土地保护规划纲要（2017-2030年）》要求，进一步加大东北黑土地保护力度。三是加强耕地质量监测。目前，农业部已建立分布于30个省的国家级耕地质量长期定位监测点357个，省市县级耕地质量监测点14000多个，初步形成了国家、省（区、市）、市（州）、县四级监测体系。

2017年4月，国务院印发《关于建立粮食生产功能区和重要农产品生产保护区的指导意见》（以下简称《意见》）。目前，国家有关部门正在按照中央部署，抓紧贯彻落实《意见》要求，加快推进全国粮食生产功能区和重要农产品生产保护区的划定、建设工作。

二、关于加大三江平原国家重要农产品精深加工开发力度问题

农业部高度重视东北地区农产品加工业发展，加强引导，加大支持，提升农产品加工能力。一是促进产业融合发展。认真贯彻落实《国务院办公厅关于推进农村一二三产业融合发展的指导意见》要求，积极推进农村一二三产业融合发展。2017年，中央财政安排专门资金，整县制推进农村一二三产业融合发展。二是加快科技成果转化。国家农产品加工技术研发体系在黑龙江省设立了6家研发分中心，主要开展大豆、乳制品、稻谷等大宗农产品加工科技研发。三是加强知名品牌培育。2016年，农业部印发了《关于开展农产品加工业质量品牌提升行动的通知》，加快培育知名企业，打造知名品牌。

下一步，农业部将进一步加大对东北地区重要农产品精深加工领域科技攻关、技术推广和推介宣传的支持力度，促进农产品精深加工产业开发。

三、关于加大三江平原国家重要农产品保护区产品品牌建设与市场推广工作问题

农业部高度重视农产品品牌建设与市场推广工作，积极搭建平台，扩大产品市场，加快农产品品牌建设。一是举办农交会。在第十四届农交会期间，以“品牌化”为引领，创新性开展丰富多样的品牌活动，设立“百个合作社百个农产品品牌”展示专区，举办中国品牌农业论坛、全国名特优果品品鉴会等活动，受到社会各界高度关注。二是开展品牌推介活动。2016年，围绕社会新热点，紧盯消费新需求，组织举办了中国苹果品牌大会、中国大米品牌大会、中国水产品品牌大会等品牌农产品推介活动，提高了农业品牌知名度和影响力。三是提升品牌管理能力。2016年举办三期农业品牌建设专题培训班，培训学员300多人。

下一步，农业部将紧紧围绕推进农业供给侧结构性改革这条工作主线，以绿色发展为导向，以改革创新为动力，以结构调整为重点，从资源禀赋和产业特色入手，加快培育一批创新能力强、竞争优势明显、文化底蕴深厚的农业品牌。
