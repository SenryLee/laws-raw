# 中共教育部党组关于叶民、周谷平同志职务任免的通知

教党任〔2017〕208号

中共浙江大学委员会：

经与中共浙江省委商得一致， 2017年8月31日研究决定：

叶民同志任中共浙江大学委员会委员、常委、副书记，纪律检查委员会书记；免去周谷平同志的中共浙江大学委员会副书记、常委，纪律检查委员会书记职务。

中共教育部党组

2017年9月11日
