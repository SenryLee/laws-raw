# 司法部关于同意中国农业发展集团有限公司开展公司律师工作的函

司发函〔2017〕307号

中国农业发展集团有限公司：

你公司《关于申请开展公司律师试点工作的函》(中农法律函〔2017〕74号)收悉。经研究，同意在中国农发集团开展公司律师工作，批准《中国农业发展集团有限公司公司律师试点工作方案》。

请根据《司法部关于开展公司律师试点工作的意见》(司发通〔2002〕79号)，将你公司申请公司律师人员名单、基本情况等材料送我部审核。

司法部

2017年12月9日
