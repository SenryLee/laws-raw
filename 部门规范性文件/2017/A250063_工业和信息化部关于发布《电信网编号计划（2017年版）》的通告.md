# 工业和信息化部关于发布《电信网编号计划（2017年版）》的通告

工信部信管[2017]68号

为适应技术业务发展、满足社会服务需求，我部对《电信网编号计划（2010年版）》进行了修订。现将《电信网编号计划（2017年版）》予以公布，即日起施行，《电信网编号计划（2010年版）》同时废止。

附件：电信网编号计划（2017年版）

工业和信息化部

2017年4月13日
