# 国家文物局关于奉国寺大雄殿彩绘泥塑二期保护修复方案意见的函

## 关于奉国寺大雄殿彩绘泥塑二期保护修复方案意见的函

办保函〔2017〕617号

辽宁省文物局：

你局《关于上报奉国寺彩绘泥塑二期保护修复方案的请示》（辽文物〔2017〕35号）收悉。经研究，我局意见如下：

一、暂不同意奉国寺大雄殿彩绘泥塑二期保护修复工程。

二、奉国寺是第一批全国重点文物保护单位，大雄殿内的彩绘泥塑形制独特，具有重要的历史、科学和艺术价值。请你局加强管理，督促有关单位按照我局《关于奉国寺大雄殿彩绘泥塑一期保护修复方案(修改稿)的批复》（文物保函〔2016〕1372号）要求，抓紧实施一期保护修复工程。待一期工程结束后，客观评估工程效果，分析、总结工程经验，进一步论证开展二期工程的必要性和可行性，并按程序另行报批。

专此函复。

国家文物局

2017年5月22日
