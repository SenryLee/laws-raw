# 国家文物局办公室关于南京主城水系连通生态补水第一批次节点建设工程象房村泵站——月牙湖段工程的意见

办保函〔2017〕1182号

江苏省文物局：

你局《关于审批南京主城水系连通生态补水第一批次节点建设工程象房村泵站——月牙湖段工程方案请示（南京城墙）》（苏文物保〔2017〕250号）收悉。经研究，我局意见如下：

一、应补充对南京原有水系的研究分析，说明生态补水系统对南京原有水系的影响程度。

二、涉及城墙遗址段落的建设控制地带内的工程，建设前需进行必要的考古勘探工作。

三、针对高排涵进水口前新建溢流堰工程，设计过于园林景观化，应围绕保护文物历史环境风貌为主，进一步优化设计。

四、进一步完善南京城墙考古勘探、保存现状、日常监测等相关数据，核查并明确穿越城墙的现有管道维持现状是否满足整体工程要求，科学评估项目建设过程及使用过程中对文物本体稳定性的影响问题，补充相关风险评估内容。针对酒精厂路新建涵闸工程，需严格控制工程范围和工程强度，并充分考虑工程施工对文物安全的影响，制定必要的文物保护措施和应急预案。

五、请你局根据上述意见，组织相关单位对方案修改、完善后，按程序另行报批。

六、请你局责成南京市人民政府及相关单位认真遵守《文物保护法》《文物保护法实施条例》《南京城墙保护规划》等相关规定，严格控制南京城墙保护范围和建设控制地带内的建设活动，切实保护文物本体及其周边环境的安全。

国家文物局办公室

2017年10月20日
