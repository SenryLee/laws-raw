# 教育部办公厅关于组织中小学生上好2017年《开学第一课》的通知

教基厅函〔2017〕30号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

为深入贯彻习近平总书记系列重要讲话精神，汲取中华优秀传统文化的思想精髓和道德精髓，用中华优秀传统文化助推中国梦的实现，为党的十九大胜利召开营造良好氛围，教育部和中央电视台联合制作了大型公益电视节目《开学第一课》。为引导各地各校上好2017年《开学第一课》，现将有关事项通知如下。

一、节目播出时间

9月4日（星期一）20:00在中央电视台综合频道（CCTV-1）播出。

二、节目主题

2017年《开学第一课》以“中华骄傲”为主题，旨在引导中小学生从博大精深的传统文化中寻找中国自信的源泉，培养他们爱党爱国爱人民，增强民族文化自信和价值观自信，树立为共产主义远大理想和中国特色社会主义共同理想而奋斗的信念和信心。

三、工作要求

各地要高度重视，将《开学第一课》作为中华优秀传统文化教育和开学教育的重要组成部分，及时把《开学第一课》播出时间及频道通知到各中小学校，并要求学校组织收看，或通知到每一位学生，让其在家与父母共同观看。播出后，将在教育部网站提供节目链接，供在线观看。各中小学校要结合实际情况，通过主题班（团、队）会、观后感、微博微信、演讲比赛、社会实践等丰富多彩的后续活动，将中华优秀传统文化教育落实到青少年学生日常学习生活中，深入推进中小学社会主义核心价值观教育。

教育部办公厅
