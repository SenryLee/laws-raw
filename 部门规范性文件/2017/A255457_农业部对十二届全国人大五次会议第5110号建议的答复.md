# 农业部对十二届全国人大五次会议第5110号建议的答复

## 对十二届全国人大五次会议第5110号建议的答复

农办议〔2017〕236号

陈敏等13名代表：

你们提出的关于大力推广使用有机水溶肥，同步推进化肥减量与农田土壤污染防治的建议收悉。经商财政部，现答复如下。

一、关于大力推广有机水溶肥料问题

有机水溶肥料是新型肥料开发的重点领域之一，具有溶解性好、见效快、利用率高等特点，可用于叶面喷施和水肥一体化施用，在农业生产中发展潜力巨大。近年来，农业部在有机水溶肥料推广方面开展了大量工作。一是加强产品登记管理。目前，农业部批准登记的有机水溶肥料产品有174个，涉及生产企业124个。通过完善产品技术指标，加强肥料登记管理，强化质量监管，进一步规范了市场秩序，促进了有机水溶肥料产业健康发展。二是加强技术推广。2015年，农业部制定印发《到2020年化肥使用量零增长行动方案》明确提出，示范推广缓释肥料、水溶性肥料、液体肥料、叶面肥、生物肥料、土壤调理剂等高效新型肥料，不断提高肥料利用率，推动肥料产业转型升级。各级农业技术推广部门通过农企合作等方式，加强与相关肥料企业的协作，在不同区域、不同作物上开展了有机水溶肥料的试验示范和技术推广，促进了有机水溶肥料的应用。三是加大项目支持力度。各级农业部门结合测土配方施肥、水肥一体化项目实施，将有机水溶肥作为新产品推广的一项重要内容，支持农民施用包括有机水溶肥料在内的新型高效肥料。在实施冬小麦“一喷三防”补助政策时，也将有机水溶肥料纳入政府采购范围。

下一步，农业部将结合化肥使用量零增长行动、果菜茶有机肥替代化肥行动和耕地质量保护与提升行动的开展，积极推动有机水溶肥料推广应用。一是推进科技创新。组织科研院所、企业开展联合攻关，加强有机水溶肥料应用机理研究，开发新型有机水溶肥料产品，完善技术标准，推动产业健康发展。二是推进集成创新。结合农业生产实际，根据土壤养分状况和作物生长需肥规律，分区域、分作物集成组装一批有机水溶肥料施肥技术模式。三是加快推广应用。积极争取政策，加强农企合作，鼓励和支持企业在适宜地区、适宜作物上推广应用有机水溶肥料。

二、关于在水溶肥料推广应用中给予政策支持问题

2016年，中央财政安排7亿元，支持测土配方施肥补贴项目，在全国建立200个化肥减量增效示范区，集成推广化肥减量增效技术。同时，农业部安排部门预算资金，建立11个高标准节水农业示范区，因地制宜推广水肥一体化技术。在项目实施中，各地结合实际，将有机水溶肥料的推广应用作为重要措施，加大资金支持力度，采取物化补助等方式，支持农民在适宜作物上施用有机水溶肥料。

2015年，按照《国务院印发关于深化中央财政科技计划（专项、基金等）管理改革方案的通知》（国发〔2014〕64号）要求，农业部、科技部组织实施“化学肥料和农药减施增效综合技术研发”国家重点研发计划试点专项，将新型水溶肥料研制作为其中的一项重点内容，支持研制溶解度高、组分之间无化学反应沉淀、低盐指数的水溶肥生产材料，建立不同作物专用的多功能、性质稳定、成本低廉的高效水溶肥料生产工艺技术，制定生产技术标准和质量标准，推动新型水溶肥料产业化发展和规模化应用。

下一步，农业部将会同有关部门，加大资金整合统筹力度，通过现有渠道对有机水溶肥料的推广应用予以合理支持。完善绿色产品政府采购政策，研究将符合政府采购政策要求的有机水溶肥料等绿色技术、新材料、新产品纳入支持范围。同时，结合“化学肥料和农药减施增效综合技术研发”国家重点研发计划试点专项，支持科研机构和企业开展有机水溶肥料技术研发、成果转化和推广工作。

感谢你们对科学施肥工作的关心，希望今后继续对农业部工作予以支持。
