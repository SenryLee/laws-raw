# 国家文物局关于西安文物保护考古中心建设项目涉及杜陵保护范围选址的意见

## 关于西安文物保护考古中心建设项目涉及杜陵保护范围选址的意见

办保函〔2017〕115号

陕西省文物局：

你局《关于西安文物保护考古中心建设项目选址的请示》（陕文物字〔2016〕267号）收悉。经研究，我局意见如下;

一、暂不同意西安文物保护考古中心建设项目涉及杜陵一般保护范围的选址方案。

二、所报方案尚需做以下必要的修改和完善：

（一）进一步分析并论证该项目在杜陵一般保护范围内选址的必要性与可行性，并对该项目的相关功能进行评估，科学分析其合理性。若确需在杜陵保护范围内选址建设该项目，应进一步严格控制该项目的建筑规模、体量和高度，优化功能布局，并注意与杜陵及其周边环境相协调。

（二）补充说明保护规划中对杜陵博物馆建设的相关要求。

（三）进一步明确该项目的建筑高度，并注意符合保护规划的相关规定。

（四）补充拟建建筑剖面设计图纸。

三、请你局指导建设单位根据上述意见对所报建设项目选址方案作进一步修改和完善，做好文物影响评估，经你局核准后，按程序另行报批。

国家文物局

2017年2月13日
