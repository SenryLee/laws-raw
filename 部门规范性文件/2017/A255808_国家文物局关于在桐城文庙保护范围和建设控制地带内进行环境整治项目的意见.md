# 国家文物局关于在桐城文庙保护范围和建设控制地带内进行环境整治项目的意见

文物保函〔2017〕1468号

安徽省文物局：

你局《关于再次审批桐城文庙周边环境整治与提升工程方案的请示》（皖文物保〔2017〕70号）收悉。经研究，我局意见如下：

一、原则同意在桐城文庙保护范围和建设控制地带内进行环境整治项目和你局意见。

二、对所报修改后的方案提出以下意见：

（一）应严格遵守《中华人民共和国文物保护法》和安徽省人民政府关于桐城文庙保护范围和建设控制地带的相关管理规定，严格控制工程范围和工程强度，尽量减少施工建设对文物本体的和景观环境的影响，确保文物安全。

（二）在不影响广场使用要求的前提下，可适当增加周边乔木绿化，增加游人舒适度。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，按《中华人民共和国文物保护法》第十七条、第十八条的规定，分别报安徽省人民政府、城乡规划部门批准后实施。

施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。施工中应加强工程监管，确保文物及历史环境安全。

国家文物局

2017年8月21日
