# 国家文物局办公室关于南岳庙圣帝殿文物本体专项技术监测项目的意见

办保函〔2017〕1391号

湖南省文物局：

你局《关于审批〈南岳庙圣帝殿文物本体及保存环境监测系统设计方案〉的请示》（湘文物报〔2017〕123号）收悉。经研究，我局意见如下：

一、南岳庙圣帝殿于2015年进行了修缮，文物本体不存在较大安全隐患，应加强实施南岳庙圣帝殿文物本体及保存环境监测项目的必要性与可行性研究。

二、建议仅针对石柱、木柱连接节点不合理、相邻柱沉降差较大、倾斜柱等长期存在的问题，研究开展适宜的专项监测工作，不宜大量安装设备及建设软件平台。

此函。

国家文物局办公室

2017年12月18日
