# 国家文物局关于二七绿都广场建设项目涉及郑州商代遗址二类建设控制地带选址意见的函

## 关于二七绿都广场建设项目涉及郑州商代遗址二类建设控制地带选址意见的函

办保函〔2017〕783号

河南省文物局：

你局《关于报批郑州绿都不动产有限公司二七绿都广场项目选址方案的请示》（豫文物〔2017〕156号）收悉。经研究，我局意见如下：

一、暂不同意二七绿都广场建设项目涉及郑州商代遗址二类建设控制地带的选址方案。

二、所报方案应进行以下必要的修改和完善：

（一）应根据考古调查勘探结果，进一步明确西侧建设控制地带内新发现夯土遗迹的性质和价值；如确属郑州商代遗址城垣遗迹，应科学调整现有选址方案，避让重要遗迹，确保文物安全。同时，应将建设范围严格限定在郑州商代遗址二类建设控制地带内，严格控制建筑规模、高度和体量，注意与遗址及其周边环境相协调。

（二）优化施工设计，地下井池设置须避让遗址保护范围，确保文物安全。

（三）该建设项目地块涉及的遗址保护范围不得进行建设，补充具体绿化设计和植被养护要求，应结合绿化开展必要的遗址展示，说明该区域在城市沿革中的历史地位，以充分展现郑州城市演变发展脉络。

三、请你局指导建设单位调整、完善设计方案，并按程序另行报批。

国家文物局

2017年6月22日
