# 农业部对十二届全国人大五次会议第2066号建议的答复

## 对十二届全国人大五次会议第2066号建议的答复

农办议〔2017〕212号

邹继宏代表:

您提出的关于着力推进农作物秸秆综合利用的建议收悉。经商国家发展改革委、财政部、国家能源局，现答复如下。

一、关于加大政策扶持力度

长期以来，我部会同国家发展改革委、财政部加大支持力度，出台了一系列秸秆综合利用奖补政策，不断破解秸秆综合利用发展瓶颈。在农机购置补贴方面，我部将秸秆粉碎还田机、青饲料收获机、青贮切碎机、翻转犁、深松机、捡拾压捆机、压捆机等促进秸秆综合利用的机具品目列入中央财政农机购置补贴范围，对属于这些品目的所有境内生产且通过农机推广鉴定的产品，农民可自主购置并按规定申请补贴，中央财政农机购置补贴资金补贴标准达到30%，极大地促进了秸秆还田、离田机械水平的提高。目前全国秸秆还田、捡拾打捆、青贮收获机械保有量分别达到85万台、4.6万台、4.3万台，较上年分别增长5.5%、26%、6%，秸秆机械化还田面积达7.2亿亩，秸秆捡拾打捆面积达0.65亿亩。在电价优惠方面，国家发展改革委出台了《关于完善农林生物质发电价格政策的通知》，对于新建农林生物质发电项目，统一执行标杆上网电价每千瓦时0.75元。在税收优惠方面，财政部、税务总局、国家发展改革委联合印发了《资源综合利用企业所得税优惠目录（2015）版》，对以秸秆为主要（燃料）原料的电力、热力、代木产品企业，减按90％计入当年收入总额计算企业所得税，并实行增值税即征即退政策。在秸秆能源化利用方面，我部会同国家发展改革委、国家能源局积极开展秸秆热解气化清洁能源利用工程的推广应用，计划到2020年，将在北方冬季取暖地区和粮棉主产省，以中央预算内资金补助形式分批支持数百个秸秆热解利用样板县，以产业化、商业化方式带动秸秆高值化利用。下一步，我部将会同相关部门，进一步加大工作力度，为秸秆运输、秸秆还田补贴、固化成型补贴等方面提供政策支持。

二、关于加强秸秆综合利用技术研发和推广应用

国家高度重视秸秆综合利用技术的科技研发工作，目前已经形成了秸秆栽培食用菌、压块燃料、生物柴油、田间快腐、饲料木质素降解等一批关键技术，开发研制了滚切式秸秆切碎装置、麦稻联合收割机配套打捆机、移动式生物质成型设备等一批关键装备，取得了显著的经济、社会和生态效益。我部专门设立了“作物秸秆还田技术”公益性行业科研项目，以我国五个主要农作区为研究对象，对各地出现的秸秆还田新问题、新需求进行技术研发和改造提升。此外，我部在现代农业产业技术体系中专门设置了秸秆利用岗位科学家，推动东北三省一区农科院和农垦科学院共同组建“东北区域玉米秸秆综合利用协同创新联盟”，搭建区域农业科技创新与交流平台，针对玉米秸秆深翻还田、免耕覆盖、低温快腐、秸秆沼气发酵等关键技术瓶颈，积极争取国家重点研发项目，加大科技攻关力度。下一步，我部将会同相关部门进一步整合科研资源，推进建立秸秆科技创新机制，引进和消化吸收国外先进技术，形成一套经济、实用的集成技术体系。

三、关于大力推进秸秆综合利用产业化

2016年，我部会同财政部围绕构建环京津冀生态一体化屏障，投入资金10亿元，在河北、山西、内蒙古、辽宁、吉林、黑龙江、江苏、安徽、山东、河南等10省（区）90个县，按照“整县推进、多元利用、政府扶持、市场运作”的原则，开展了秸秆综合利用试点，围绕秸秆肥料化、饲料化、基料化、燃料化、原料化和收储运体系建设，探索区域可持续、可复制推广的秸秆综合利用技术、模式和机制。今年，为推动农业绿色发展，在继续开展试点建设的基础上，我部启动实施了“东北地区秸秆处理行动”，在东北地区60个玉米主产县开展整县推进秸秆综合利用，大力推广秸秆深翻还田、覆盖还田等循环利用技术，积极发展以秸秆为原料的加工业和食用菌生产，不断增强秸秆产业发展动能。国家能源局高度重视秸秆生产燃料乙醇产业发展，在《生物质能发展“十三五”规划》中提出：“大力发展纤维素乙醇，到2020年生物燃料乙醇年利用量达到400万吨”；在《可再生能源“十三五”规划》中提出：“推进以农林剩余物为主要原料的纤维素乙醇和生物质热化学转化制备液体燃料示范工程”。下一步，我部将继续依托中央财政秸秆综合利用试点补助资金项目，支持秸秆综合利用的重点领域和关键环节，积极推动相关职能部门完善配套政策，加快秸秆产业化发展步伐。

感谢您对农业和农村经济工作的关心，希望今后继续给予关注和支持。
