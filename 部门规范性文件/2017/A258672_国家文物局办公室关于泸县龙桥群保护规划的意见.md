# 国家文物局办公室关于泸县龙桥群保护规划的意见

办保函〔2017〕1365号

四川省文物局：

你局《关于报送〈泸县龙桥群保护规划〉的请示》（川文物〔2017〕112号）收悉。经研究，我局意见如下：

一、所报规划目标不清晰，现状评估不足，保护措施、管理措施不明确，保护区划划定可操作性差，图纸表达不规范，我局暂不同意所报规划。

二、对该规划提出以下修改意见：

（一）进一步深化文物本体研究，补充龙桥历史沿革、面积、建造时期、修筑方式、建造技艺、所处位置、环境等内容，分析46处龙桥分布特征及相互联系。

（二）进一步细化现状评估内容，根据文物本体面临的主要问题及威胁因素提出科学合理、具有针对性的保护措施。

（三）应根据单体龙桥所处环境及保护管理需要合理划定保护区划，保证文本描述与图纸表达保持一致，增强可操作性。

（四）完善管理机制建设，明确管理部门、使用部门及人员对于保护管理、日常维护、安全防范的权责关系。

（五）补充评估龙桥群作为当地居民交通设施的延续性，在保障其原有功能的前提下，根据文物特征合理进行价值展示阐释。

（六）应结合文物本体与村落分布特征合理规划停车场及休息广场位置、规模，避免对文物本体及环境造成影响。加强同水利、交通部门沟通合作，合理制定道路交通及防灾减灾规划。补充监测规划内容，明确监测目标及措施要求。

三、请你局指导相关单位，按照上述意见对所报保护规划进行修改、完善，按相关程序另行报批。

国家文物局办公室

2017年12月13日
