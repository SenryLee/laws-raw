# 住房城乡建设部标准定额司关于同意铁路线路设计规范等3项工程建设行业标准备案的函

建标实函〔2017〕216号

国家铁路局科技与法制司：

你司《关于<铁路线路设计规范>和<铁路车站及枢纽设计规范>两项行业标准备案的函》（科法便函[2017]218号）、《关于<铁路轨道设计规范>行业标准备案的函》（科法便函[2017]231号）收悉。经研究，同意《铁路线路设计规范》等3项行业标准作为“中华人民共和国工程建设行业标准”备案（见附件）。

中华人民共和国住房和城乡建设部标准定额司

2017年11月2日
