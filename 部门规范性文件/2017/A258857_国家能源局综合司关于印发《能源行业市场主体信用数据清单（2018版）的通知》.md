# 国家能源局综合司关于印发《能源行业市场主体信用数据清单（2018版）的通知》

国能综通资质〔2017〕105号

各司,各派出能源监管机构,各直属事业单位,有关能源企业和行业协会:

为实现能源行业市场主体信用信息的归集,规范归集管理工作，根据《国务院关于印发社会信用体系建设规划纲要(2014－2020年)的通知》(国发〔2014)21号)、《国家能源局关于印发<能源行业信用体系建设实施意见(2016-2020年)>的通知》(国能资质〔2016〕350号)、《国家能源局关于印发<能源行业市场主体信用信息归集和使用管理办法>的通知》(国能资质〔2016〕388号号)等相关文件，我局编制形成《能源行业市场主体信用数据清单(2018版)》,现予印发。数据清单自印发之目起施行。

国家能源局综合司

2017年11月17日

附件：能源行业市场主体信用数据清单（2018版）
