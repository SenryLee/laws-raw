# 国家文物局关于禹会村遗址祭祀台基展示工程立项的意见

## 关于禹会村遗址祭祀台基展示工程立项的意见

办保函〔2017〕270号

安徽省文物局：

你局《关于请求批准〈禹会村遗址祭祀台基展示工程立项报告〉的请示》（皖文物保〔2016〕170号）收悉。经研究，我局意见如下：

一、暂不同意禹会村遗址祭祀台基展示工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步明确遗址的区位条件和展示条件，论证展示工程的必要性和可行性。

（二）暂不同意对已回填的遗址再次发掘并建设覆罩大棚进行展示，建议考虑模拟展示或标识展示的方式进行比选。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年3月16日
