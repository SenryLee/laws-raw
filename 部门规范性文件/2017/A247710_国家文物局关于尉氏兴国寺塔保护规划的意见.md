# 国家文物局关于尉氏兴国寺塔保护规划的意见

## 关于尉氏兴国寺塔保护规划的意见

办保函〔2017〕117号

河南省文物局：

你局《关于尉氏兴国寺塔保护规划的请示》（豫文物〔2016〕107号）收悉。经研究，我局意见如下：

一、所报规划的目标和定位不明，文本深度不够，规划措施的可操作性不强，我局暂不同意尉氏兴国寺塔保护规划。

二、对该规划提出以下修改意见：

（一）关于历史研究和评估

进一步加强历史研究，厘清兴国寺与兴国寺塔的空间关系、遗址保存状况、与城市的历史关系等，在此基础上深化价值评估，补充说明兴国寺塔的城市历史坐标价值。同时，应客观评估现状保护区划执行情况和存在问题，为保护区划调整提供依据。

（二）关于保护区划与管理规定

应根据文物保护需要、地形地物特征及视域分析结果，进一步调整保护区划的范围和边界，避免切割现状房屋，并慎重考虑将城市道路纳入保护范围的必要性和可操作性。同时，应注意控制十字路口临街建筑的高度和体量，明确建设控制地带的控制指标和拆改要求。

（三）关于保护措施

应合理研提保护措施，以日常养护、岁修和巡查为主，明确补配措施的适用范围，严格控制干预强度。

（四）关于环境整治和专项规划

1．建议补充考古规划内容，明确兴国寺原有规模和空间格局，确定寺院与塔之间的空间关系。

2．应针对兴国寺塔现状和保护管理需要，进一步简化专项规划内容，增强针对性。环境整治、基础设施建设、展示利用规划应重新调整思路，核减新建设施数量和规模，做到适度、合理；论证消防系统和安防系统建设、大规模景观绿化的必要性，建议结合城市建设发展统筹考虑；不同意新建游客服务中心。

（五）进一步规范文本和图纸，加强文本与图纸的对应性，统一图文表达。保护区划图应注明四至坐标。

三、请你局指导有关单位，根据上述意见对尉氏兴国寺塔保护规划进行全面、认真的修改完善，按程序另行报批。

专此函。

国家文物局

2017年2月13日
