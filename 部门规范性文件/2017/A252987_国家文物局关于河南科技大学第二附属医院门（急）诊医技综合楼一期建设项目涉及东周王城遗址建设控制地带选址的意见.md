# 国家文物局关于河南科技大学第二附属医院门（急）诊医技综合楼一期建设项目涉及东周王城遗址建设控制地带选址的意见

## 关于河南科技大学第二附属医院门（急）诊医技综合楼一期建设项目涉及东周王城遗址建设控制地带选址的意见

办保函〔2017〕434号

河南省文物局：

你局《关于上报河南科技大学第二附属医院门（急）诊医技综合楼一期设计方案的请示》（豫文物〔2017〕121号）收悉。经研究，我局意见如下：

一、所报河南科技大学第二附属医院门（急）诊医技综合楼一期建设项目涉及东周王城遗址建设控制地带，所报材料不详，无法判断对东周王城遗址的影响。我局暂不同意该项目选址方案。

二、所报选址及建设方案尚需做以下必要的修改和完善：

（一）进一步补充说明该建设项目的占地范围和面积，并明确该项目拟建建筑及其附属设施的具体占地情况，包括地下基础部分。

（二）进一步补充说明该项目拟建区域地下文物遗存分布及保存的具体情况。涉及新的考古发掘的，应另行填报考古发掘申请书。

（三）重新开展文物影响评估，应结合拟建项目占地范围内地下文物遗存的分布及保存情况，进一步说明该建设项目对东周王城遗址的影响。

三、请你局指导建设单位，根据上述意见对所报方案做进一步修改和完善，做好文物影响评估，经你局核准后按程序另行报批。

国家文物局

2017年4月13日
