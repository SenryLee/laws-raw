# 人力资源社会保障部办公厅关于加强技工教育和职业培训教材建设工作的通知

人社厅函〔2017〕107号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）：

为贯彻落实《技工教育“十三五”规划》（人社部发〔2016〕121号），充分发挥技工教育和职业培训教材的基础性、支撑性作用，全面提高技能人才培养质量，现就加强技工教育和职业培训教材建设工作通知如下：

一、统筹推进，大力开发技工教育和职业培训教材

（一）积极开拓技工教育教材新领域。服务产业转型升级和技工院校新专业建设需要，大力开发战略性新兴产业、先进制造业、现代服务业等相关专业教材。以国家技能人才培养标准和一体化课程规范为引领，扩大一体化课程教材规模。充分发挥世界技能大赛的带动作用，做好相关教材开发，推动技工院校在课程设置、教学内容等方面与世界先进标准对接。及时总结企业新型学徒制试点经验，探索开发贴近企业岗位实际、符合技能人才成长规律的相关教材。

（二）整体推进职业培训教材建设。以《职业培训包开发技术规程》为遵循，结合新经济、新产业、新职业发展，积极开发集培训目标、培训内容、教学资源、考核大纲为一体的职业培训包，不断丰富品种、系列。围绕“大众创业、万众创新”，加快创新创业相关培训教材开发。

（三）加快开发高技能人才培训教材。根据我国经济社会发展、产业转型升级和供给侧结构性改革需要，以《中国制造2025》为引领，以国家十大振兴产业和战略性新兴产业紧缺型高技能人才培养为重点，以先进制造业高端技术、高技能人才核心技能和工艺研发能力为主要方向，加快高技能人才培训教材开发步伐，基本形成规模合理、工种齐全、技能高端的高技能人才培训教材体系，为深入实施国家高技能人才振兴计划服务。

二、提升质量，强化技工教育和职业培训教材的规范管理

（一）强化教材思想性。深入学习贯彻习近平总书记系列重要讲话精神，自觉把中国特色社会主义理论体系贯穿教材建设的全过程，坚持以社会主义核心价值观引领技工教育，深入开展爱国主义、集体主义、社会主义教育，有机融入中华优秀传统文化、革命传统、法治意识和国家安全、民族团结以及生态文明教育，落实立德树人根本任务。要大力弘扬劳动光荣、技能宝贵、创造伟大的时代风尚，突出技工教育和职业培训特色，注重融入职业精神、工匠精神教育。

（二）精心编写（修订）教材。优化教材编写团队，完善教材编写程序，积极吸收借鉴优秀教材编写经验，在精编细选、精益求精上下功夫，努力多出精品教材。要充分反映技工教育和职业培训最新教学成果，及时反映新技术、新工艺、新材料、新设备的应用。把握现代教育培训技术发展趋势，积极推进教材数字化，增强教育培训效果。我部组织制定技工院校德育、语文、历史、数学、英语、计算机基础与应用、体育与健康课程标准，以及专业教学计划和教学大纲，作为教材编审的主要依据。技工教育和职业培训教材一般不超过3年修订一次。

（三）规范教材选用。建立健全技工教育和职业培训教材目录制度，我部定期公布技工教育和职业培训教材目录。各省级人力资源社会保障部门负责指导技工院校和职业培训机构做好教材选用工作。技工院校德育、语文、历史等国家课程教材必须在国家公布的目录中选用，数学、英语、计算机基础与应用、体育与健康等公共基础课在教材目录中优先选用，专业课教材应从教材目录中择优选用。开展一体化课程教学改革试点的技工院校，应按照部颁一体化课程规范执行，使用统一组织开发的一体化教材。对政府补贴性职业培训和创业培训，从职业培训教材目录中选用教材。要坚决打击盗版行为，防止盗版教材进课堂。

三、加强领导，细化工作措施

（一）落实责任分工。人力资源社会保障部职业培训教材工作委员会统筹全国技工教育和职业培训教材建设工作。各地人力资源社会保障部门要强化责任，把教材建设作为职业能力建设领域重要工作摆上工作日程，强化工作分工和督促检查，务求工作实效。要指导技工院校和职业培训机构实行教材使用校长责任制，确保课程开设齐全、教材使用规范，不发生违法违纪问题。

（二）建设高素质编审队伍。加强国家级教材编审人员的遴选和培训，加快建设一支高素质的编写和审稿专家队伍。优化编写团队结构，吸收相关领域学科专家、课程专家、教研人员、一线优秀教师以及行业企业专业技术人员、高技能人才等不同方面人员参加教材编写。技工院校、职业培训机构要推荐优秀教师参加教材编写。严格编审人员管理，各单位要对参与教材编审的人员进行审核，在政治立场、师德师风、学术诚信等方面存在问题的人员不得参与教材编审。

（三）加大教材研究力度。加强关系技工教育和职业培训教材建设全局的基础研究、国内外技工教育和职业培训教材建设比较研究，技能人才培养规律和教材开发体系研究，夯实教材建设理论基础。试点建设国家技工教育与职业培训教材建设研究基地，采取竞争入选、定期评估、动态调整的管理办法，主要依托优质技工院校、有关教育教学研究机构，设立若干课程教材研究基地，为教材建设提供理论支持和决策依据。

（四）健全工作制度。凡承担国家级教材编审任务的人员，所在单位应充分保障其编审时间，并提供必要的条件，建立优秀教材编修在工作量计算、科研成果统计、职称评聘方面的认定机制。要健全教材建设相关规章制度，依法依规推进教材建设。充分发挥新闻媒体宣传引导作用，总结宣传教材建设经验做法，大力推广教材建设优秀成果和先进典型，不断营造有利于推动教材建设的良好环境和氛围。
