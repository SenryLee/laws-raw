# 国家文物局关于溪头三槐堂保护规划的意见

## 关于溪头三槐堂保护规划的意见

办保函〔2017〕116号

安徽省文物局：

你局《关于批准溪头三槐堂保护规划的请示》（皖文物保〔2016〕102号）收悉。经研究，我局意见如下：

一、所报规划文物构成和保护对象不明，现状评估不足，保护区划和管理规定可操作性不强，文本深度不够，我局暂不同意溪头三槐堂保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

1．深化前期研究，分析溪头三槐堂的历史格局、选址特征以及与溪头村的关系，明确文物本体、附属文物及历史环境要素。

2．完善现状评估内容。进一步细化各单体建筑的保存现状，明确影响文物本体安全的主要自然和人为因素，开展文物周边区域景观视廊分析，补充历次保护工程实施效果、展示利用情况和管理现状评估内容。

（二）关于保护区划与管理规定

1．结合文物历史格局、地形地貌特征和景观视线分析结论，合理调整保护区划，适当扩大建设控制地带范围，建议将东侧吴树琴与吴兆棠故居、北侧山体、南侧农田纳入建设控制地带。补充说明保护区划调整的思路和依据。

2．结合溪头村建设发展和文物保护要求，科学确定具体控制指标和管理要求，增强可操作性。

（三）关于保护措施

1．根据评估结论细化文物保护措施，合理确定文物本体、附属文物的保护措施和强度，明确工程性质和类型。

2．应注意保护文物周边的历史环境，细化历史环境要素及传统建筑的保护措施。

（四）关于环境整治和专项规划

1．应增强环境整治措施的针对性，合理控制整治范围，应尽量保持历史原貌特征，不宜在三槐堂门前建设停车场。

2．加强展示利用研究，深入挖掘文物历史内涵和地域特色，合理确定展示原则，明确展示主题、内容、方式。

3．完善管理规划，明确管理部门权责关系，制定具体管理措施。

4．完善消防规划，提出具有可操作性的消防措施。补充防灾减灾评估内容，并制定相关应急预案。

（五）补充所报规划与相关规划的衔接内容，处理好村落发展与文物保护的关系。

（六）梳理、完善图纸，补充图号，规范图例。

三、请你局指导有关单位，根据上述意见对溪头三槐堂保护规划进行全面、认真的修改完善，按程序另行报批。

专此函。

国家文物局

2017年2月13日
