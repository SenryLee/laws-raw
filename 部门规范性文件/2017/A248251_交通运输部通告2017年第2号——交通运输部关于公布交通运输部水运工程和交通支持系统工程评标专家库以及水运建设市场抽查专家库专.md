# 交通运输部通告2017年第2号——交通运输部关于公布交通运输部水运工程和交通支持系统工程评标专家库以及水运建设市场抽查专家库专家名单的通告

## 交通运输部通告

2017年第2号

## 交通运输部关于公布交通运输部水运工程和交通支持系统工程评标专家库以及水运建设市场抽查专家库专家名单的通告

为适应水运工程和交通支持系统工程建设项目招标投标工作和水运建设市场监管工作的需要，加强事中事后监管，提高行业服务水平，根据《交通运输部水运工程和交通支持系统工程综合评标专家库管理办法》（交水发〔2012〕554号），我部组织开展了新一轮水运工程和交通支持系统工程评标专家库以及水运建设市场抽查专家库建设工作。经组织申报、专家资格审核并通过公示，形成了水运工程和交通支持系统工程评标专家库以及水运建设市场抽查专家库专家名单，现予以公布。

特此通告。

附件：1.水运工程和交通支持系统工程评标专家库专家名单

2.水运建设市场抽查专家库专家名单

交通运输部

2017年1月26日
