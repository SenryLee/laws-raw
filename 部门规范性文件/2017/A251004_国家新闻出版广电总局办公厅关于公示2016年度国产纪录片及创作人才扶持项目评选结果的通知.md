# 国家新闻出版广电总局办公厅关于公示2016年度国产纪录片及创作人才扶持项目评选结果的通知

新广电办发（2017）32号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央三台、电影频道节目中心、中央新影集团，中国农业电影电视中心，中国教育电视台，中央军委政治工作部宣传局：

2016年，国产纪录片涌现出一批思想性、艺术性、观赏性相统一的精品力作，社会影响力、美誉度不断提升。为了进一步从制作、播出、产业、人才等多个环节加大对国产纪录片的扶持引导力度，发挥优秀作品、制作机构、播出机构和创作人才的引领示范作用，国家新闻出版广电总局坚持客观公正、优中选优的原则，评选出2016年度国产纪录片及创作人才扶持项目的获奖项目，现予以公示。

公示内容可在国家新闻出版广电总局政府网站（http://www.chinasarft.gov.cn/）公告区中查询，同时可在中国纪录片网（http://www.docuchina.cn/）上查询。任何单位或个人如对评审结果有异议，可于2017年6月5日前向国家新闻出版广电总局宣传司反映。联系地址：北京市西城区复兴门外大街2号国家新闻出版广电总局宣传司，邮编：100866;联系人：罗引子、颉昀;电话：010-86096287,86092361。

附件：2016年度国产纪录片及创作人才扶持项目评选结果

国家新闻出版广电总局办公厅

2017年5月15日
