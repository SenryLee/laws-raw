# 中华人民共和国财政部公告2017年第59号——决定发行2017年记账式贴现（二十一期）国债

## 中华人民共和国财政部公告

2017年第59号

根据国家国债发行的有关规定，财政部决定发行2017年记账式贴现（二十一期）国债（以下简称本期国债），已完成招标工作。现将有关事项公告如下：

一、本期国债计划发行100亿元，实际发行面值金额100亿元。

二、本期国债期限91天，经招标确定的发行价格为99.247元，折合年收益率为3.04%，2017年5月8日开始计息，招标结束后至5月8日进行分销，5月10日起上市交易。

三、本期国债低于票面面值贴现发行，2017年8月7日（节假日顺延）按面值偿还。

其他事宜按《中华人民共和国财政部公告》（2017年第2号）规定执行。

特此公告。

中华人民共和国财政部

2017年5月5日
