# 国家文物局办公室关于彬县大佛寺石窟明镜台上岩体卵石层脱落抢险加固项目的意见

办保函〔2017〕1372号

陕西省文物局：

你局《关于呈报彬县大佛寺石窟明镜台上岩体卵石层脱落抢险工程设计方案的请示》（陕文物字〔2017〕198号）收悉。经研究，我局意见如下：

一、应做好对卵石层的补充勘察。应补充现场落石和危岩体的照片及说明，明确落石量、区域及诱发因素；应重点核实卵石层及存在安全隐患的卵石层的分布范围，以及所处地形地貌、卵石层所属地层及年代、粒度、成分、胶结状态、物理力学特征、卵石层与黄土堆积及砂岩的关系等；可删减与卵石层无关的信息。

二、水文地质条件应重点分析降水下渗补给地下水对卵石层的影响。

三、应按照“最小干预”原则，基于补充勘察结论，将防治范围限定在有安全隐患的卵石层区域，避免大规模地设置锚杆和山体挂网，并注意考虑柔性防护网的颜色和外观等相关因素，尽可能减少对山体和遗产景观环境的影响。

四、补充论证使用不锈钢棒而不是螺纹钢作为锚固杆件的必要性。

五、细化完善立面勘测图和修缮设计图，确保锚杆和柔性防护网的科学布置，以切实做好落石防治。

六、具体方案由你局指导有关单位按照上述意见进行修改、完善并经你局批准后实施。实施前，应根据现场情况及时开展必要的支护、防护工作，确保文物、人员安全，并注意与其他相关工程做好衔接。

七、请你局加强监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

专此函复。

国家文物局办公室
