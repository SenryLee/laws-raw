# 中华人民共和国财政部公告2017年第141号——决定第一次续发行2017年记账式附息（二十期）国债的公告

## 中华人民共和国财政部公告

2017年第141号

根据国家国债发行的有关规定，财政部决定第一次续发行2017年记账式附息（二十期）国债，已完成招标工作。现将有关事项公告如下：

一、本次国债计划续发行360亿元，实际续发行面值金额360.7亿元。

二、本次续发行国债的起息时间、票面利率等要素均与2017年记账式附息（二十期）国债相同，即起息日为2017年9月21日，票面年利率为3.69%；按年付息，每年的9月21日（节假日顺延，下同）支付利息，2024年9月21日偿还本金并支付最后一次利息。经招标确定的续发行价格为99.86元，折合年收益率为3.77%。本次续发行的国债从招标结束后至2017年10月26日进行分销，从10月30日起与之前发行的同期国债400.9亿元合并上市交易。

其他事宜按《中华人民共和国财政部公告》（2017年第2号）规定执行。

特此公告。

中华人民共和国财政部

2017年10月25日
