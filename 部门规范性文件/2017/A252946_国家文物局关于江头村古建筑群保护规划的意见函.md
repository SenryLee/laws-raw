# 国家文物局关于江头村古建筑群保护规划的意见函

## 关于江头村古建筑群保护规划的意见函

文物保函〔2017〕1062号

广西壮族自治区文化厅：

你厅《关于重新报送全国重点文物保护单位江头村古建筑群保护规划的请示》（桂文物报〔2016〕39号）收悉。经研究，我局意见如下：

一、原则同意所报规划。

二、对该规划提出以下修改意见：

（一）深化文物建筑现状评估，特别应对近年来开展的文物建筑保护修缮情况进行评估。

（二）适当调整保护区划，缩小二类建设控制地带范围，增强可操作性。

（三）保护范围内不得新建建筑，取消保护范围管理规定中新建建筑控制高度要求。

（四）取消建设控制地带管理规定中建筑物拆除要求，此项内容应调整至环境整治规划章节。

（五）江头村的新村建设、古建筑群保护管理用房等建设项目，应进一步明确选址、规模、形制等建设指标及控制要求，避免其对古建筑群环境风貌造成影响。

（六）补充该规划与村镇发展规划、土地利用规划等相关规划衔接的说明。保护范围内用地性质改为文物古迹用地依据和可行性不足。

（七）规范规划文本体例和表达，并补充规划图纸，

三、请你厅指导地方人民政府组织规划编制单位，按照上述意见，对规划进行修改完善后，于15个工作日内将经你厅核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你厅将经我局备案的江头村古建筑群保护规划报请广西壮族自治区人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，组织有关部门认真贯彻实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

专此。

国家文物局

2017年6月5日
