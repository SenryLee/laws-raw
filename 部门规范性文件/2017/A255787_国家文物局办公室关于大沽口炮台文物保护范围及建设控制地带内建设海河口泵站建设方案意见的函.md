# 国家文物局办公室关于大沽口炮台文物保护范围及建设控制地带内建设海河口泵站建设方案意见的函

办保函〔2017〕909号

天津市文物局：

你局《关于报审大沽口炮台建设控制地带内海河口泵站建设方案的的请示》（津文物〔2017〕25号）收悉。经研究，我局意见如下：

一、暂不同意海河口泵站建设方案。

二、所报方案应做以下修改：

（一）项目选址和建设应尽可能避开大沽口炮台面向渤海一侧的空间视廊，且新建海堤不宜与炮台直接相连。

（二）补充建设项目对文物的环境风貌影响分析，包括大沽口炮台面对拟建泵站的视觉环境效果图。

（三）结合泵站建设，进一步加强大沽口炮台周边的环境治理。环境设计应充分考虑历史风貌，尽可能保持原有自然生态，不宜过于城市公园化。

（四）应对泵站施工和运营期间的文物影响程度进行评估并提出相应保护措施，包括施工期间对大沽口炮台的文物保护监测、汛期的防洪措施等，以确保文物的安全。

三、请你局指导有关单位，根据上述意见对建设方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2017年8月3日
