# 国家文物局关于金塔修缮工程立项的意见

## 关于金塔修缮工程立项的意见

办保函〔2017〕263号

辽宁省文物局：

你局《关于上报金塔抢险加固工程立项报告的请示》（辽文物〔2017〕6号）收悉。经研究，我局意见如下：

一、暂不同意金塔修缮工程立项。

二、对该方案提出以下修改意见：

（一）应加强现状勘察，明确文物保存现状和周边地质情况等，详细梳理2000年和2004年修缮工程情况，科学评估塔体结构稳定性和修缮工程效果，深入分析塔座开裂原因，进一步论证工程实施的必要性和可行性。补充2008年至今的塔体裂缝监测数据、分析报告和相关资料。

（二）应说明挡墙建筑年代、功能和2016年坍塌破坏情况，科学分析挡墙倒塌原因和对文物安全的影响。

（三）应深入研究金塔建造工艺、构造特征等，严格控制工程范围和规模，重点解决塔体结构安全问题，避免过度维修。应针对挡墙功能设计，进一步明确挡墙维修的整体思路和措施。

（四）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年3月16日
