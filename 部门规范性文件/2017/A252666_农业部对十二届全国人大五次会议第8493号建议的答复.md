# 农业部对十二届全国人大五次会议第8493号建议的答复

## 对十二届全国人大五次会议第8493号建议的答复

农办议〔2017〕32号

赵治海代表：

您提出的“关于加强粉垄技术推广，助力我国农业绿色发展的建议”收悉。经商财政部，现答复如下。

一、关于在国家层面重视和加强粉垄技术推广应用

粉垄耕作技术具有活土、保水、增氧、淡盐等综合作用，有利于提高农作物单产、促进农业绿色发展。农业部高度关注该技术，2017年，安排一定资金支持广西壮族自治区农业科学院开展“粉垄绿色生态农业技术示范推广”。同时，将“粉垄绿色生态农业技术”纳入农业部2017年主推技术予以推介发布。国家设立主要农作物生产全程机械化示范县创建项目，支持我国粮棉油糖主产区在5年期间每年选择近100个县，开展水稻、玉米、小麦、棉花、油菜、甘蔗等9种作物生产全程机械化示范县创建，以耕、种、收等为重点环节，推广先进适用农机化技术及装备，各地可结合实际将粉垄技术纳入，探索全程机械化生产模式，打造我国农业机械化发展的升级版。下一步，农业部将持续关注粉垄技术，支持有条件的地区先行先试，鼓励龙头企业、种粮大户、农机合作社等使用粉垄耕作技术。

二、关于在全国层面开展张杂谷的推广种植

按照中央部署要求，农业部制发了《全国种植业结构调整规划（2016—2020年）》，指导各地科学有序推进种植结构调整，适当调减“镰刀弯”非优势地区玉米面积，改种耐旱耐瘠薄的薯类、杂粮杂豆。2016年，投入中央财政经费2240万元，支持现代农业产业技术体系近40名首席和岗位专家，围绕谷子糜子产业发展需求，开展适合产业化生产的谷子糜子品种选育、绿色防控等提质增效配套技术集成示范，为谷子糜子产业发展提供了有力的科技支撑。下一步，农业部将继续推进以减玉米为主的种植结构调整，加强政策支持、信息引导，进一步促进包括“张杂谷”在内的杂粮等替代作物生产发展，结合粉垄技术等实用技术，提高作物的产量和品质。

三、关于加强对粉垄机械研发和推广的投入

国家高度重视先进、适用、安全、可靠农业机械的研发和推广应用。在研发方面，为落实《中国制造2025》部署，农业部等相关部委联合制发了《农机装备发展行动方案（2016—2025）》，明确了包括耕整地机械在内的农机装备研发的发展方向和重点，提出了相关推进措施；国家重点研发计划“智能农机装备”专项启动实施了“农田提质工程技术与装备研发项目”；为鼓励企业创新，国家实行了“研发费用加计扣除政策”，2016年进一步放宽了该政策的研发活动范围、简化了审核管理，并加强了对高新技术企业的支持；今年4月19日，国务院决定将科技型中小企业研发费加计扣除比例由50%提高到75%，目前财政部正在会同税务总局、科技部研究制定政策文件。在推广应用方面，农业部、财政部办公厅联合印发的《2015—2017年农业机械购置补贴实施指导意见》，已将耕整地机械的15个品目纳入了补贴范围；将开展农机新产品补贴试点省份由去年的3个省增加到了今年10个，支持农机产品研发创新；每年投入财政资金近5000万元，在全国约100个县开展主要农作物全程机械化试验示范，探索熟化技术，推进农机新产品新技术的推广应用。

今后，我部将进一步加强与有关部门的沟通合作，积极推进协同创新，促进先进机具的研发。同时进一步完善农机购置补贴等政策，对粉垄机等新研制、仍有较大改进提升空间的暂不具备补贴条件的产品，研究相关扶持措施。

关于将粉垄机耕列入深耕深松补贴问题。中央财政已连续5年安排资金支持适宜省份开展深松整地作业补贴，粉垄机耕作为一项新型耕作技术，可由地方先行先试，探索经验。下一步，我们将商相关部门，深入开展调研，广泛听取各方意见，完善包括粉垄机耕作业在内的农机作业补贴措施。

四、关于建立国家粉垄技术研究工程中心

《农机装备发展行动方案（2016—2025年）》将耕整地机械纳入了主机产品创新专项，将筹建农机领域国家级制造业创新中心纳入了公共服务平台建设专项。《农业科技创新能力条件建设规划（2016—2020年）》拟新建22个农业机械化科学试验基地，8个已启动实施，支持包括粉垄技术装备在内的试验研究。下一步，我部将继续关注农机领域国家级研发中心建设，争取更多有效支持。

感谢您对农业机械化工作的关心，希望继续对我部工作给予支持。
