# 国家文物局关于许昌关帝庙保护规划意见的函

文物保函〔2017〕2014号

河南省文物局：

你局《关于审批许昌关帝庙文物保护规划的请示》（豫文物 〔2016〕272号）收悉。经研究，我局意见如下：

一、原则同意所报许昌关帝庙保护规划。

二、对该规划提出以下修改意见：

（一）应进一步厘清文物构成和保护对象，碑刻应纳入附属文物。

（二）深化价值评估，进一步提炼许昌关帝庙在三国文化和关圣文化建筑群研究中的历史价值和意义；完善现状评估，细化古道、水系等景观环境评估，补充必要的文物视线通廊分析和水害影响评估内容。

（三）应根据文物价值评估、文物分布情况和保护管理实际需要，结合视线通廊分析,科学调整保护区划及其具体边界。建设控制地带南侧边界应适当增加一定的保护距离。建议考虑将建设控制地带分级分类管理，增强可操作性，严格控制绿地、河道区域建设。

（四）针对现状评估结论，研提文物保护策略和具体的措施，增强针对性与可操作性。

（五）根据文物保护和展示利用需要，进一步明确展示利用的主要内容和重点，明确拟建相关服务设施的具体规模、高度和建筑风貌。

（六）进一步校核与规范文本与图纸，规范用语。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的许昌关帝庙保护规划报请河南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体立项报告或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好许昌关帝庙的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年12月20日
