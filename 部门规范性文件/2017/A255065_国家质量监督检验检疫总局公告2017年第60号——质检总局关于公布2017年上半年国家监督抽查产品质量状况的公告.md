# 国家质量监督检验检疫总局公告2017年第60号——质检总局关于公布2017年上半年国家监督抽查产品质量状况的公告

## 国家质量监督检验检疫总局公告

2017年第60号

## 质检总局关于公布2017年上半年国家监督抽查产品质量状况的公告

2017年上半年，质检总局全面贯彻落实国务院关于推广“双随机、一公开”监管工作的决策部署，加大推进简政放权、放管结合、优化服务改革力度，组织开展了日用及纺织品、电子电器、轻工产品、建筑和装饰装修材料、农业生产资料、机械及安防产品、电工及材料等7大类产品质量国家监督抽查。现将有关情况公告如下：

一、基本情况

（一）2017年上半年，国家监督抽查产品41种。其中包括：针织内衣、女士内衣等2种日用及纺织品；笔记本电脑、吸油烟机、电烤箱、室内加热器、房间空气调节器、家用电动洗衣机、储水式电热水器、热泵热水机（器）、电磁灶、食具消毒柜、集成电路（IC）卡读写机等11种电子电器；卫生巾、纸尿裤、纸巾纸、家用卫生杀虫用品、家用燃气灶具、自行车、电动自行车、树脂镜片等8种轻工产品；

建筑防水涂料、溶剂型木器涂料、实木地板、浸渍纸层压木质地板、浸渍胶膜纸饰面人造板、机制地毯等6种建筑和装饰装修材料；播种机、磷肥、农药、稻麦联合收割机、植物保护机械等5种农业生产资料；磨床、容积式空气压缩机、锁具、防爆电气等4种机械及安防产品；砂轮、动力用煤、钢丝绳、阀门、稀土氧化物等5种电工及材料产品。按照抽查企业数划分，7大类产品抽查比例见图1。

（二）2017年上半年，共抽查了2664家企业生产的2674批次产品，检出250批次产品不合格，不合格产品检出率为9.3%，从抽查情况看，产品抽查合格率为90.7%，与2016年同期国家监督抽查合格率相比，提高了0.4个百分点。

（三）从企业生产规模来看，抽查的大、中、小型企业数分别占抽查企业总数的12.9%、18.8%和68.3%，产品抽查合格率分别为96.9%、94.8%和88.3%。与2016年同期相比，大、中、小型企业抽查合格率分别提高了1.4、2.1和0.2个百分点。抽查结果反映出各类型企业质量水平均有提高，大、中型生产企业产品质量水平持续领先于小型企业。2017年上半年与2016年同期合格率对比情况见图2。

（四）从实施市场准入管理的产品抽查情况看，2017上半年抽查了10种实施工业产品生产许可证管理的产品，覆盖769家企业的769批次产品，检出77批次不合格产品，产品抽查合格率为90%。抽查了11种实施CCC认证产品，抽查626家企业的635批次产品，检出79批次不合格产品，抽查合格率为87.6%。

（五）从不同产品抽查合格率分布情况看，2017年上半年抽查合格率为100%的产品数占抽查产品总数的4%，与2016年同期持平；抽查合格率在80%以上的产品数占抽查产品总数的91.4%，同比下降了3.2个百分点。抽查的41种产品中，有25种产品抽查合格率在90%以上，仍有3种抽查合格率低于80%，其中电磁灶产品抽查合格率最低，仅为60.4%。

（二）从抽查地区分布来看，东部地区抽查产品数量较多，共抽查2205批次，占抽查产品总数的82.5%；中、西部地区分别抽查了257批次和212批次，占抽查产品总数的9.6%和7.9%。随着我国实施“一带一路”战略，西部抽查产品质量水平出现了大幅提升，西部地区产品抽查合格率为91.7%，高于国家监督抽查全国平均水平1个百分点；东部地区产品抽查合格率为89.2%，低于国家监督抽查全国平均水平1.5个百分点；中部地区产品抽查合格率为88.1%，低于国家监督抽查全国平均水平2.6个百分点。与2016年同期相比，西部地区抽查合格率提高了3.5个百分点，东部和中部地区分别下降了1.3和3个百分点。2017年上半年与2016年同期东部、中部、西部产品抽查合格率对比情况见图3。

三、产品质量抽查结果分析

（一）日用及纺织品。上半年抽查了2种201家企业生产的201批次产品，抽查合格率为95%，比2016年同期提高了2.7个百分点。针织内衣、女士内衣2种产品的抽查合格率均在90%以上。

（二）电子电器。上半年抽查了11种498家企业生产的499批次产品，抽查合格率为83.2%，比2016年同期下降了4.4个百分点。其中，笔记本电脑、吸油烟机和房间空气调节器3种产品抽查合格率均在90%以上；电烤箱、室内加热器、家用电动洗衣机、储水式电热水器、热泵热水机和集成电路（IC）卡读写机6种产品抽查合格率均在90%以下。电磁灶质量问题较突出，产品抽查合格率为60.4%，主要不合格项目涉及到对触及带电部件的防护、非正常工作、机械强度、接地措施、能效等级、端子骚扰电压、电磁辐射骚扰等7个项目。

（三）轻工产品。上半年抽查了8种532家企业生产的541批次产品，产品抽查合格率为90.4%，比2016年同期下降了1.4个百分点。其中，卫生巾（含卫生护垫）、纸尿裤（片、垫）、纸巾纸、家用卫生杀虫用品和电动自行车5种产品抽查合格率均在90%以上；家用燃气灶、自行车、树脂镜片3种产品抽查合格率均在90%以下。

（四）建筑和装饰装修材料。上半年抽查了6种414家企业生产的414批次产品，产品抽查合格率为94.4%，比2016年同期提高了3.2个百分点。其中，机织地毯的产品抽查合格率为100%；建筑用防水涂料、实木地板、溶剂型木器涂料和浸渍纸层压木质地板4种产品抽查合格率均在90%以上。浸渍胶膜纸饰面人造板产品抽查合格率在90%以下。

（五）农业生产资料。上半年抽查了5种393家企业生产的393批次产品，产品抽查合格率为96.4%，比2016年同期提高了6.4个百分点。其中，播种机的产品抽查合格率为100%；植物保护机械、稻麦联合收割机、农药和磷肥4种产品抽查合格率均在90%以上。

（六）机械及安防产品。上半年抽查了4种196家企业生产的196批次产品，产品抽查合格率为88.8%，比2016年同期降低了0.7个百分点。其中，磨床的产品抽查合格率为100%；容积式空气压缩机和锁具2种产品抽查合格率均在90%以上；防爆电气（防爆开关）1种产品抽查合格率在90%以下。防爆电气质量问题较突出，产品抽查合格率为74.4%，主要不合格项目涉及到防爆标志、警告标志、接地连接件、隔爆接合面参数、抗冲击试验、电缆和导管引入装置的夹紧和密封试验等7个项目。

（七）电工及材料。上半年抽查了5种430家企业生产的430批次产品，产品抽查合格率为89.5%，与2016年同期基本持平，比2016年下降了0.4个百分点。其中，稀土氧化物的产品抽查合格率为100%；钢丝绳的产品抽查合格率在90%以上；砂轮、阀门和动力用煤3种产品的产品抽查合格率均在90%以下。

四、跟踪抽查结果分析

（一）产品跟踪抽查情况。从跟踪抽查情况看，2017年上半年抽查产品中，近5年抽查3次以上的产品有31种，占抽查产品总数的82.9%。其中卫生巾（含卫生护垫）、农药、纸尿裤（片、垫）和实木地板等产品连续3年产品抽查合格率保持在95%以上。与2016年相比， 2017年上半年跟踪抽查了23种产品，有12种产品抽查合格率有所提高，平均提高了7.3个百分点。其中，产品抽查合格率上升幅度最大的是电磁灶，上升了24.2个百分点；下降幅度最大的是家用燃气灶，下降了10.9个百分点。

（二）不合格企业跟踪抽查情况。在跟踪抽查的293家前一次抽查不合格企业中，发现有84家企业已不再生产同类产品或已停产停业，占跟踪抽查企业总数的28.7%；在实际抽样检验的201家企业中，有164家企业产品跟踪抽查合格，占跟踪抽查企业总数的81.6%；有37家企业连续两次产品质量抽查不合格，占跟踪抽查企业总数的18.4%。跟踪抽查结果表明，各地质量技术监督部门针对抽查发现的问题，依法严格后处理，督促生产企业整改复查，发挥了督促企业落实主体责任、规范生产与提高产品质量的作用。

2017年上半年国家监督抽查结果已通过质检总局网站分批向社会公告，质检总局已责成相关省（自治区、直辖市）质量技术监督部门按照有关法律法规，对抽查不合格的产品及其生产企业依法进行处理，督促不合格产品生产企业落实产品质量安全主体责任。
