# 农业部对十二届全国人大五次会议第8425号建议的答复

## 对十二届全国人大五次会议第8425号建议的答复

农办议〔2017〕155号

靳保芳等4名代表：

你们提出的关于重视城镇化中农村衰落问题的建议收悉。经认真研究，现结合我部职能就“土地流转”和“农业机械化”问题答复如下。

一、关于加快土地流转

中央高度重视农村承包土地经营权流转和发展适度规模经营，多年来出台了一系列的政策，为土地流转规范有序开展奠定了坚实基础。2014年，中办、国办印发的《关于引导农村土地经营权有序流转发展农业适度规模经营的意见》（以下简称《意见》）明确提出,既要加大政策扶持力度，加强典型示范引导，鼓励创新农业经营体制机制，又要因地制宜、循序渐进，不能搞大跃进，不能搞强迫命令，不能搞行政瞎指挥。2016年，中办、国办印发了《关于完善农村土地所有权承包权经营权分置办法的意见》，这是继家庭联产承包责任制后农村改革又一重大制度创新。2017年，中央1号文件再次强调，大力培育新型农业经营主体和服务主体，通过经营权流转、股份合作、代耕代种、土地托管等多种方式，加快发展土地流转型、服务带动型等多种形式规模经营。

为贯彻落实好中央要求，我部积极指导地方完善配套制度。目前，全国已有30个省（市、区）印发了《意见》的实施意见，20个省（区、市）出台了工商资本租赁农地监管和风险防范政策文件。江苏、甘肃、重庆、山西、河北等以省(市)委办公厅和省（市）政府办公厅名义下发了完善“三权分置”办法的实施意见。同时，我部大力加强流转市场规范化管理。2016年6月，我部印发了《农村土地经营权流转交易市场运行规范（试行）》，进一步明确了在流转交易市场进行交易的相关规程，促进了土地流转的平稳有序发展。据统计，截至2016年底，全国家庭承包耕地流转面积达到4.79亿亩，占家庭承包经营耕地总面积的35.1%，流转合同签订率达到68.2%，农户承包地规范有序流转的机制初步建立。

下一步，我部将指导各地着力开展以下工作：一是完善农业适度规模经营政策体系。认真贯彻中央关于加快构建政策体系培育新型农业经营主体的意见，建立健全促进适度规模经营健康发展的政策措施。鼓励通过土地经营权流转、农业生产托管等多种方式，加快发展土地流转型、服务带动型等多种形式规模经营。引导农民在自愿基础上，通过村组内互换并地等方式，实现按户连片种植，解决地块细碎化等问题。二是严格规范土地流转行为。尊重农民在流转中的主体地位，村级组织只能在农户书面委托的前提下才能组织统一流转，禁止以少数服从多数的名义将整村整组农户承包地集中对外招商经营。三是加快完善土地流转服务。督促地方按照《农村土地经营权流转交易市场运行规范（试行）》要求，健全土地经营权流转市场，规范市场运行机制。引导土地流转双方签订书面流转合同，保护流转双方的权益。四是完善工商资本租地监管和风险防范制度。进一步指导各地对工商资本长时间、大面积租赁农户承包地明确上限控制，分级备案、审查审核、风险保障金和事中事后监管等“五项制度”，严格准入门槛，加强事中事后监管，防止浪费农地资源、损害农民土地权益。

二、关于提高农业机械化水平

农业机械化是农业现代化的重要标志和物质技术基础，没有农业机械化，就没有农业现代化。党中央、国务院高度重视农业机械化发展，出台了一系列扶持政策和推动措施，农业机械化实现了稳步、健康、快速发展。目前，全国农作物耕种收综合机械化率已超过65%，我国农业生产方式实现了从人畜力为主向机械作业为主的历史性转变，农业机械化进入由中级阶段向高级阶段快速迈进的时期。

为进一步推动农业机械化水平不断提高，我部将重点做好以下几方面工作：一是深入推进主要农作物生产全程机械化。印发《农业部关于开展主要农作物生产全程机械化推进行动的意见》，推动建设500个左右率先基本实现生产全程机械化的示范县。以粮棉油糖等主要农作物及饲草料为对象，推进作物品种、栽培技术和机械装备集成配套和生产全过程各环节机械化技术配套，力争到2020年，实现全国农作物耕种收综合机械化率达到70%左右，小麦、水稻、玉米三大粮食作物耕种收综合机械化率均达到并稳定在80%以上，畜牧业、渔业、农产品初加工、果茶桑、设施农业机械化水平显著提高。二是认真实施农机购置补贴政策。中央财政从2004年启动实施农机购置补贴政策，年度资金规模由最初的7000万元增加到2016年的237.5亿元，实施区域由66个县逐步覆盖所有农牧业县（场）。下一步，我部将主动适应推进农业供给侧结构性改革和建立绿色生态导向农业补贴制度改革新要求，围绕农业生产重点领域、主要农作物全程机械化生产、关键环节技术应用等，加快推进补贴范围内所有机具敞开补贴。围绕支撑农机新产品推广应用，组织开展新产品购置补贴试点。适时组织调整补贴机具种类范围，满足合理需求。健全管理机制，着力推进信息公开、绩效管理、内部控制、违规查处，确保政策规范有序实施。三是扩大农业机械化技术推广应用。加快深松整地、保护性耕作、精准施药、化肥深施、节水灌溉、秸秆机械化还田收贮、残膜机械化回收利用、病死畜禽无害化处理及畜禽粪便资源化利用等机械化技术的推广应用，加强设施农业、养殖业及丘陵山区机械化技术的示范推广，助力农业结构调整。配合工业和信息化部组织实施好《中国制造2025》农机装备发展行动方案，配合科技部实施好国家重大研发计划“智能农机装备”项目，开展农机科技创新联盟的建设工作，加快建设国家水稻、甘蔗、棉花等全程机械化科研基地，推进重大科技攻关，促进新产品、新技术的研发。四是大力发展农机社会化服务。培育壮大农机合作社、农机作业公司等农机经营服务主体，鼓励引导农机合作社在服务内容上向综合化拓展，在组织管理上向规范化发展，在市场竞争中向品牌化提升。引导农机合作社通过多种形式开展便捷的社会化服务，带动先进农业技术推广应用和适度规模经营发展。通过大力发展农业机械化，努力为加快推进农业现代化进程提供物质支撑。

感谢你们对农业、农村工作的关心，希望今后继续对我部工作予以支持。
