# 国家文物局关于在凤凰山古建筑群保护范围和建设控制地带内实施岸线环境整治项目的意见

文物保函〔2017〕1495号

湖北省文物局：

你局《关于在全国重点文物保护单位凤凰山古建筑群建设控制地带内实施岸线环境整治工程的请示》（鄂文物〔2017〕36号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位凤凰山古建筑群保护范围和建设控制地带内实施岸线环境整治项目和你局意见。

二、对所报项目提出以下修改完善意见：

（一）所报项目位于全国重点文物保护单位凤凰山古建筑群保护范围和建设控制地带内，应严格遵守《中华人民共和国文物保护法》和湖北省人民政府关于凤凰山古建筑群保护区划的相关管理规定，严格控制施工范围，确保文物安全。

（二）进一步完善设计方案，广场不宜大面积使用大理石铺装，建议采用地方石材，并考虑植树遮阳处理。进一步优化厕所、栏杆、花坛、道路的形式和材料，确保与文物景观风貌相协调。

（三）应充分考虑建设施工对文物安全的影响，制定必要的文物保护措施和应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十七条、第十八条的规定分别报湖北省人民政府和城乡建设规划部门批准后实施。施工中应加强监管，确保文物安全。

专此函复。

国家文物局

2017年8月22日
