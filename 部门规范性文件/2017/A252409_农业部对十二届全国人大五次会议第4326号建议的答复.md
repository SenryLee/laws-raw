# 农业部对十二届全国人大五次会议第4326号建议的答复

## 对十二届全国人大五次会议第4326号建议的答复

农办议〔2017〕88号

胡忠雄、杨莉代表：

你们提出的关于积极探索农业供给侧结构性改革并将湖南省岳阳市屈原管理区纳入全国农村改革试点范围的建议收悉。经商财政部、科技部、国家旅游局、国土资源部、国家发展改革委等单位，结合6月下旬我部全国人大重点建议调研组与代表面对面沟通交流及赴屈原管理区实地调研情况，现答复如下。

一、关于在全国积极实践探索推广农村各项改革经验

党的十八届三中全会以来，中央陆续安排了一批重大农村改革试点试验，为全面深化农村改革探索路径、积累经验。农村改革试验区作为中央推动试点试验的重要平台，以完善生产关系为核心，着力推进农村改革创新，重点围绕农村基本经营制度、农村土地管理制度、农业支持保护制度、现代农村金融制度、农村集体产权制度、农村社会治理制度和城乡发展一体化体制机制等方面开展改革试验，试验内容基本涵盖了当前农村改革的重点领域。为及时总结做法成熟、适用性强的试验成果，推动试验成果转化推广，农业部会同农村改革试验区工作联席会议各成员单位，按照中央领导同志对农村改革试验工作的重要批示精神，在督导调研、专家评估和专题研讨的基础上，形成了多篇政策转化建议专题报告，筛选出了30多项起步较早、做法成熟、效果明显、适用性强的试验成果，分送中央领导和有关部门供制定政策时研究参考；先后推出60多个改革典型案例，印发省级试验区工作主管部门和各试验区参考借鉴；初步统计已有涉及40项试验内容的61项试验成果对54件省部级以上层级政策文件制定产生了重要参考作用。目前农村改革试验区工作已进入探索的加速期、成果的盛产期，形成了许多突破性的改革亮点，探索出了许多创新性的改革方法，为深化农村改革探明了方向和路径，有些试验区已经成为改革样板，形成了“样板扩散效应”，为面上改革提供了有益借鉴。

与此同时，按照党中央、国务院部署，相关部委的各项改革也在有序推进。例如，成渝统筹城乡国家配套改革试验、黑龙江两大平原现代农业综合配套改革试验、粮食等重要农产品价格形成机制和收储制度改革等试点积累了不少可复制、可推广的经验，国家发展改革委等部门正在研究在更大范围推广；农村土地征收制度、集体经营性建设用地入市、宅基地制度改革等三项试点已进行2年，国土资源部正在会同有关部门和地区开展制度提炼和总结验收工作。

下一步，我部将认真落实党中央、国务院决策部署和中央一号文件精神，积极会同有关部门推动各地扎实做好试点试验工作，持续放大改革示范效应。一方面，加强对试点试验的督导。落实试点任务牵头职责，指导和推动相关试点地区按照批复的试验方案，有序推出改革举措，确保完成好中央交办的改革任务。推动有条件的地区拓展深化试点试验主题，开展综合性改革试点试验。另一方面，加强经验总结和成果转化。及时关注、跟踪和总结各地好做法、好模式，择机在更大范围进行推广；推动各地成熟经验向政策转化，不断巩固改革试点试验成果；对经试点检验不适应改革发展要求的法律法规，及时提出修改建议。

二、关于将屈原管理区纳入全国农村改革试点范围

2016年，在湖南省委、省政府和岳阳市委、市政府的指导支持下，屈原管理区启动了湖南省农村改革集中区创建工作。从实地调研看，岳阳市委、市政府对屈原管理区农村改革工作高度重视，成立了28个单位组成的工作领导小组，健全了改革工作机制。屈原管理区通过有序推进地方多规合一、土地股份合作、农业旅游业融合、农户集中居住、构建城乡发展一体化体制机制等改革，取得了初步成效。总体上看，屈原管理区推进农村改革的热情较高、意愿较强、工作基础较好。

2009年，针对农村改革发展的新形势新变化，中央启动了新形势下的农村改革试验区工作，由中央农村工作领导小组直接领导，建立了农业部、中央农办、国家发展改革委、保监会等20个部门和单位组成的联席会议制度，具体指导改革试点试验工作。农村改革试验区和试验项目设立实行的是地方申报、省级推荐、中央部门审核、联席会议审议、中央农村工作领导小组批准的程序。按照中央提出“有步骤、有计划逐步在全国设立50个试验区”的设想，我部会同联席会议成员单位于2011年和2014年批复了两批共58个试验区。中央对改革试点工作有明确指示，试点试验要把制度创新作为核心任务，把形成可复制、可推广的制度成果作为基本要求，不能建成要照顾、争优惠的“政策洼地”，不能一哄而上，布点不宜过多，范围不宜过大。

下一步，我部将会同有关部门加强对屈原管理区农村改革试点试验的指导支持，持续关注农村改革集中区创建工作。作为农村改革试验区工作联席会议牵头部门，我部支持屈原管理区申报农村改革试验区，建议屈原管理区可根据自身优势和实际需要，按照《农村改革试验区工作运行管理办法》有关要求，以推动农业供给侧结构性改革为主线，以创新农村一二三产业融合发展机制、深化农村土地管理制度改革和农村集体产权制度改革等为试验主题，拟定试验方案并提出申请，由湖南省人民政府向我部推荐，我部将择机会同联席会议成员单位研究审议，报中央农村工作领导小组审定。

三、关于加强对屈原管理区的政策支持

我部高度重视对屈原管理区的政策支持。2010年，我部认定屈原管理区为第一批国家现代农业示范区。在项目资金安排上，印发了《关于推进农业项目资金倾斜支持国家现代农业示范区建设的通知》，引导各项涉农资金投入示范区；在财政支持上，会同财政部选择部分示范区实施以奖代补政策，每年安排1000万元，连续安排三年；在金融支持上，分别联合国家开发银行、中国邮政储蓄银行印发了《关于开发性金融支持现代农业示范区建设的意见》《关于邮政储蓄资金支持现代农业示范区建设的意见》，积极推动金融机构与示范区加强合作。2016年，我部将屈原管理区纳入深化农垦改革专项试点，安排了“积极发展多种形式的适度规模经营”“改组组建农垦国有资本投资、运营公司”“开展贫困农场精准扶贫、精准脱贫”“加强党的领导和党的建设，充分发挥农垦党组织的政治核心作用”等4项试点任务。2017年，我部会同国家发展改革委、财政部选择屈原管理区建设农业面源污染综合治理试点项目，中央补助资金0.3亿元，主要开展农田面源污染防治、畜禽水产养殖污染减排、地表径流污水净化利用等工程建设，探索总结洞庭湖流域农业面源污染防治成功经验。下一步，我部将会同有关部门加大对湖南岳阳屈原管理区国家现代农业示范区相关项目支持力度，推动示范区建设上水平、出经验。会同国家发展改革委、财政部等根据国家相关规划和年度资金规模继续对屈原管理区高标准农田、农业面污染源综合整治、河湖连通、农业产业融合发展等项目予以积极支持。

科技部等部门高度重视农业科技园区的工作。2013年在屈原管理区批复建设了岳阳国家农业科技园区。科技园区以市场化为导向，创新科技支持农业农村发展的体制机制，探索建立农业技术试验示范推广扩散联动机制，培育新型农业经营主体、农民创新创业平台和农业发展新动能。下一步，科技部将统筹布局、科学规划、根据区域资源禀赋不同，按照“一园区一主导产业”布局，实现科技园区错位发展。建议岳阳国家农业科技园区坚持市场化、标准化、生态化思路发展现代农业，加快转变农业发展方式，健全农业科技推广体系，全面提升科技创新水平，坚持走依靠创新驱动实现自我发展的农业现代化道路。

屈原管理区旅游资源丰富，但旅游业知名度还有待提升。下一步相关部门将进一步加大支持指导力度，支持当地旅游产业做大做强。一是支持凤凰乡开展特色村镇建设。根据今年中央1号文件和国务院办公厅《关于推进农村一二三产业融合发展的指导意见》（国办发〔2015〕93号）要求，住房城乡建设部和国家发展改革委正在推进特色村镇建设。屈原管理区可在湖南省和岳阳市有关部门指导下，按照农业文化旅游“三位一体”、生产生活生态同步改善、一二三产业深度融合的思路，探索开展凤凰乡特色村镇建设，提升建设水平，在符合相关条件的前提下按程序申报，有关部门将予以支持。二是推进旅游产业提档升级。国家旅游局将会同有关部门指导屈原管理区深入挖掘屈原爱国文化旅游资源，提升旅游产品的文化内涵，不断完善乡村旅游产品体系和接待服务水平；优先支持该地A级景区等国家重点旅游品牌创建、旅游人才培训、民俗文化旅游品牌宣传推广等。

感谢你们对“三农”工作的关心。
