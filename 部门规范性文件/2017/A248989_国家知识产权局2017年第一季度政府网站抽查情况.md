# 国家知识产权局2017年第一季度政府网站抽查情况

国知办函办字〔2017〕126号

根据《国务院办公厅秘书局关于2016年第四次全国政府网站抽查情况的通报》（国办秘函〔2017〕5号）要求，我局认真组织开展2017年第一季度网站抽查工作，突出重点、强化监管、严格标准，对管理的政府网站进行随机抽查。

一、强化监管、常态抽查

今年3月，按照国务院办公厅有关要求，我局在网站管理部门自查的基础上采取抽查的方式，检查了“国家知识产权局政府网站”和“重点产业专利信息服务平台”政府网站。这两个网站为我局在全国政府网站信息报送系统中填报的7个政府网站中的2个（我局共计填报11个政府网站，其中有3个网站已申请例外，1个网站已关停），抽查率为我局运行政府网站总数的28.6%，满足不低于运行政府网站总数10%的要求。抽查工作按照《国务院办公厅关于开展第一次全国政府网站普查的通知》确定的检查标准进行。

“国家知识产权局政府网站”为我局政府门户网站，严格按照国办要求运行和维护，确保在网站可用性、信息更新情况、互动回应情况和服务实用情况等方面运行良好。信息类栏目更新及时，2016年共发布动态信息1910条，未出现明显错误，保证门户网站发布信息的准确性、及时性和权威性，全年共组织开展6次意见征集活动。进一步推进门户网站集约化建设，将原有“中国及多国审查信息查询系统”网站并入门户网站，规范网上服务事项，优化网上服务流程。定期对网站各项内容进行全面检查，检查频率高于国办要求，保证门户网站健康有序运行。

“重点产业专利信息服务平台”是为配合国务院十大重点产业调整和振兴规划的实施、发挥专利信息对经济社会发展和企业创新活动的支撑作用而建设的信息服务平台，致力于为十大重点产业提供公益性的专利信息服务。网站总体运营状况良好，2016年度公众页面浏览总量约4759万次，日均文件点击量约14.3万次，检查过程未出现政府网站普查评分表列出的各项问题。

二、完善制度、保障安全

一是重新修订《政府网站管理办法》和《网站编辑手册》。针对我局政府门户网站信息量大、功能性强、受众面广的特点，制订质量考核标准，完善网站信息采集、审核、发布各项工作流程，保证门户网站的各个栏目都有专门人员负责管理。网站信息发布采取三审制，由2名网站编辑和1名管理人员分别进行编辑、审核和签发。

二是建立健全门户网站问题问责机制。明确网站问题责任追究和处罚办法，强化相关人员的责任意识，切实巩固全国政府网站普查成果，坚决防止“不及时、不准确、不回应、不实用”问题反弹。

三是加强政府网站的网络安全保障工作。落实信息安全责任制，明确网站信息安全负责人和安全责任。加强信息安全管理，提升政府网站防篡改、防渗透和防攻击能力，维护网站安全。

三、倾听意见、服务公众

一是将网民留言办理作为重要日常工作来抓。充分发挥“我为政府网站找错”监督举报平台作用，倾听网民意见建议，认真核实纠正问题，改进完善相关工作，推进政府网站持续健康发展。截至目前，已转办、处理、回应网民参与提出的网站问题17件，网站管理单位能够及时对留言进行核实、处理和反馈，留言办结率达100%。

二是促进重要政策信息联动发布水平持续提升。推行专人“盯网”制度，保证在重要信息发布后24小时内转载到我局政府门户网站和局内网站的“国务院文件”专栏，促进国务院文件的贯彻落实。截至目前，网站已转载国务院政策信息59件。

三是定期向社会公开政府网站季度抽查结果。在局门户网站开设栏目，于每季度末将政府网站抽查情况向公众公开，曝光出现问题的网站名单，主动公开检查情况，自觉接受社会监督。

下一步，我局将结合实际进一步抓好政府网站管理工作。继续增强监督检查力度，对发现的问题及时通报、切实整改，彻底消除隐患。主动作为、优化服务，大力推进政府网站集约化建设。充分倾听网民意见建议，公开网站抽查情况，改进完善网站工作，推进我局政府网站持续健康发展。
