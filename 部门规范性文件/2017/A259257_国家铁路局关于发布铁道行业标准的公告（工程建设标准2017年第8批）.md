# 国家铁路局关于发布铁道行业标准的公告（工程建设标准2017年第8批）

## 国家铁路局关于发布铁道行业标准的公告

（工程建设标准2017年第8批）

国铁科法〔2017〕71号

现公布《铁路轨道设计规范》（TB 10082-2017）行业标准，自2017年12月20日起实施。《铁路轨道设计规范》（TB 10082-2005）同时废止。

本标准由中国铁道出版社出版发行。

国家铁路局

2017年9月29日
