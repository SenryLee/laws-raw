# 住房和城乡建设部工程质量安全监管司关于开展工程质量检测有关情况调查的函

## 关于开展工程质量检测有关情况调查的函

建质质函[2017]6号

各省、自治区住房城乡建设厅，直辖市建委，新疆生产建设兵团建设局：

为加强工程质量检测管理，做好《建设工程质量检测管理办法》（建设部令第141号）修订工作，现就工程质量检测有关情况进行书面调查。请按要求认真填写《房屋建筑和市政基础设施工程质量检测有关情况调查问卷》（见附件），并于4月14日前反馈我司。

联系人：范宏柱

电话：010-58933293　010-58934250（传真）

附件：房屋建筑和市政基础设施工程质量检测有关情况调查问卷

中华人民共和国住房和城乡建设部工程质量安全监管司

2017年3月7日
