# 环境保护部办公厅关于解除内江市甜郁纸业有限公司等3起环境违法案件挂牌督办的通知

## 关于解除内江市甜郁纸业有限公司等3起环境违法案件挂牌督办的通知

环办环监函〔2017〕1509号

四川省环境保护厅：

按照我部《关于对四川省煤焦化集团有限公司等4起环境违法案挂牌督办的通如》(环办环监〔2016〕4号)要求，你厅督促相关地方和企业积极开展整改，并向我部提交了解除挂牌督办申请，我部组织对案件的整改情况进行核查，目前，内江市甜郁纸业有限公司、隆昌新能源工业园、四川省川威集团下属成渝钒钛科技有限公司和内江市博威新宇化工有限公司3起环境违法案的整治基本达到督办要求。

经研究，现决定对内江市甜郁纸业有限公司、隆昌新能源工业园、四川省川威集团下属成渝钒钛科技有限公司和内江市博威新宇化工有限公司3起环境违法案解除挂牌督办。请你厅继续加强督查，督促地方政府和环保部门加大日常监管和监测力度，督促企业正常运行污染防治设施，确保污染物稳定达标排放；督促四川省川威集团下属成渝钒钛科技有限公司认真落实钒产品深加工生产线的建设，并在后续工程建设中严格执行环评及环保“三同时”制度。

环境保护部办公厅

2017年9月26日
