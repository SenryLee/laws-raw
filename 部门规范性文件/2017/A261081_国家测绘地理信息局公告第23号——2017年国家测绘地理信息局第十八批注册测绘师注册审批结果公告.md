# 国家测绘地理信息局公告第23号——2017年国家测绘地理信息局第十八批注册测绘师注册审批结果公告

## 国家测绘地理信息局公告

第23号

## 2017年国家测绘地理信息局第十八批注册测绘师注册审批结果公告

根据《注册测绘师制度暂行规定》和《注册测绘师执业管理办法（试行）》，经审核，张艳良等55人符合初始注册条件，准予初始注册；刘明娴等18人符合变更注册条件，准予变更注册；杨小伟等3人符合注销注册条件，准予注销注册。

附件2：准予变更注册人员名单
