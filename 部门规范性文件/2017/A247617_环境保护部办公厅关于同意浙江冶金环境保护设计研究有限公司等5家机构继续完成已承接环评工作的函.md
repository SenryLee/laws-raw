# 环境保护部办公厅关于同意浙江冶金环境保护设计研究有限公司等5家机构继续完成已承接环评工作的函

## 关于同意浙江冶金环境保护设计研究有限公司等5家机构继续完成已承接环评工作的函

环办环评函[2017]176号

浙江冶金环境保护设计研究有限公司，安徽师范大学，海南寰亚生态环境工程咨询有限公司，重庆化工设计研究院有限公司，云南绿色环境科技开发有限公司：

根据《建设项目环境影响评价资质管理办法》（环境保护部令 第36号）的相关要求，经审核，同意浙江冶金环境保护设计研究有限公司等4家机构缩减评价范围后继续完成原已承接的环境影响报告书编制工作，同意安徽师范大学环评机构改制后继续完成原已承接的环境影响报告书（表）编制工作（详见附件）。

附件：可继续完成的建设项目环境影响报告书(表)清单

2017年2月10日
