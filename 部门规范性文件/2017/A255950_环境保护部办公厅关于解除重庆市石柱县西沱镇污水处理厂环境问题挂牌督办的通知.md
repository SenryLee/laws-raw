# 环境保护部办公厅关于解除重庆市石柱县西沱镇污水处理厂环境问题挂牌督办的通知

## 关于解除重庆市石柱县西沱镇污水处理厂环境问题挂牌督办的通知

环办环监函〔2017〕1513号

重庆市环境保护局：

按照《关于对重庆市石柱县西沱镇污水处理厂环境问题挂牌督办的通知》（环办环监〔2017〕40号）要求，你局督促相关单位按照督办要求积极整改西沱镇污水处理厂环境问题，并向我部提交了解除挂牌督办申请。经我部现场检查，目前西沱镇污水处理厂环境问题整改达到督办要求。

经研究，现决定解除对重庆市石柱县西沱镇污水处理厂环境问题挂牌督办。请你局继续督促石柱县人民政府和相关单位认真落实环境保护责任，进一步加大污水管网建设，加强对西沱镇污水处理厂环境监管力度，督促其加快按照重庆市统一要求部署开展提标改造，确保稳定达标排放，严格防范各类环境风险。

环境保护部办公厅

2017年9月27日
