# 环境保护部办公厅 、国家发展和改革委员会办公厅关于印发《生态保护红线划定指南》的通知

## 关于印发《生态保护红线划定指南》的通知

环办生态〔2017〕48号

各省、自治区、直辖市环境保护厅（局）、发展改革委，新疆生产建设兵团环境保护局、发展改革委:

根据中共中央办公厅、国务院办公厅《关于划定并严守生态保护红线的若干意见》的安排部署，环境保护部、发展改革委共同组织编制了《生态保护红线划定指南》（见附件），现印发给你们。请按照本指南要求，加快推进本地区生态保护红线划定工作。
