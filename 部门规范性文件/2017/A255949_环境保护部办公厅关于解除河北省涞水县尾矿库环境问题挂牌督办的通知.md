# 环境保护部办公厅关于解除河北省涞水县尾矿库环境问题挂牌督办的通知

## 关于解除河北省涞水县尾矿库环境问题挂牌督办的通知

环办环监函〔2017〕1512号

保定市人民政府：

按照《关于对涞水县尾矿库环境问题挂牌督办的通知》（环办应急〔2016〕79号）要求，你市人民政府督促涞水县人民政府按照督办要求积极整改尾矿库环境问题，并向我部和河北省人民政府提交了解除挂牌督办申请。经现场核查，目前涞水县尾矿库环境问题整改达到督办要求。

经商河北省人民政府，现决定解除对涞水县尾矿库环境问题挂牌督办。请你市人民政府督促涞水县人民政府认真落实环境保护职责，继续强化尾矿库环境监督管理和整治力度，做好环境风险防范和应急准备工作，促进环境质量持续改善。

环境保护部办公厅

2017年9月27日
