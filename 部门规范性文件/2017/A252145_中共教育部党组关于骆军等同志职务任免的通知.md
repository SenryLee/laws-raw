# 中共教育部党组关于骆军等同志职务任免的通知

教党任〔2017〕136号

中共华中师范大学委员会：

经与中共湖北省委商得一致，2017年6月1日研究决定：

骆军同志任中共华中师范大学委员会副书记，夏立新同志任中共华中师范大学委员会委员、常委；免去谢守成同志的中共华中师范大学委员会副书记、常委，黄永林同志的中共华中师范大学委员会常委职务。

中共教育部党组

2017年6月14日
