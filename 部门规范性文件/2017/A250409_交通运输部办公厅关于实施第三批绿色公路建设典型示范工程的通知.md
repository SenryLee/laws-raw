# 交通运输部办公厅关于实施第三批绿色公路建设典型示范工程的通知

交办公路函〔2017〕552号

为贯彻落实《交通运输部办公厅关于实施绿色公路建设的指导意见》（交办公路〔2016〕93号）要求，推动公路建设转型升级，经交通运输部同意，现公布第三批绿色公路建设典型示范工程名单（项目清单附后）。

截至目前，部已公布绿色公路建设项目33个，达到了各省（区、市）全覆盖。请各省级交通运输主管部门按照绿色公路建设有关要求，组织示范项目各参建单位细化实施方案，做实示范内容，突出示范亮点，强化示范引领，不断总结经验，加强经验交流，全面提升公路建设水平。有关项目示范实施方案请及时报部。

部公路局联系人：宾帆，联系电话：010-65292742，邮箱：moc08@163.com。

交通运输部办公厅
