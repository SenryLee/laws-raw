# 农业部对十二届全国人大五次会议第6767号建议的答复

## 对十二届全国人大五次会议第6767号建议的答复

农办议〔2017〕281号

姚建民代表：

您提出的关于国家将地膜实物补贴方式变为资金补贴的建议收悉。经商财政部，现答复如下。

近年来，中央财政安排资金支持山西、新疆等干旱和半干旱地区推广以地膜覆盖为主的旱作农业技术，并鼓励采取“新膜换旧膜、厚膜换薄膜”的方式，引导农民使用厚度0.01毫米以上的地膜，推动地膜产业技术创新和新产品推广，多措并举减少白色污染。通过项目实施，极大调动了农民群众应用旱作节水农业技术的积极性，推动了旱作区农业稳定增产、农民持续增收。2017年，中央财政在农业生产发展资金中安排10亿元，继续支持推广旱作农业和地膜清洁生产技术，并在内蒙古、甘肃和新疆选择部分地区探索建立废旧地膜回收利用体系，推进废旧地膜资源化利用。在组织实施上，我们将积极推动地方采取政府购买服务、政府与社会资本合作等创新模式，提高财政资金使用效率。

下一步，我部将会同财政部在深入调研基础上，进一步完善项目实施机制和资金使用方式，加大废旧地膜回收利用力度，鼓励地膜产业技术创新，开展新型多功能地膜、可降解地膜等新产品、新材料试验示范和推广应用，提高政策效益和资金使用效率。

感谢您对农业农村经济工作的关心，希望今后继续对我部工作给予支持。
