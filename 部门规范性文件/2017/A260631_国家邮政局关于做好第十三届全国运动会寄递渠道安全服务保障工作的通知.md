# 国家邮政局关于做好第十三届全国运动会寄递渠道安全服务保障工作的通知

国邮电传〔2017〕53号

各省、自治区、直辖市邮政管理局：

第十三届全国运动会（以下简称全运会）将于8月27日至9月8日在天津举行。为落实国家反恐办《关于做好第十三届全运会安保反恐怖工作的通知》和《第十三届全国运动会环津社会面治安管控方案》要求，切实做好全运会期间寄递渠道安全服务保障工作，现将有关事项通知如下：

一、充分认识做好全运会寄递安全服务保障工作的重大意义。全运会是我国规模最大、水平最高的综合性体育盛会，是我国优秀体育人才大聚会、优秀体育成果大检阅的重要舞台。此次赛事具有人流量大、群众活动多、媒体集中、时间周期长等特点，寄递渠道安全服务保障工作任务重、要求高。寄递渠道作为环津社会面治安管控的重点领域，安全保障工作容不得丝毫闪失。各级邮政管理部门要充分认识做好全运会寄递安全服务保障工作的极端重要性，切实增强忧患意识、责任意识和担当意识，加强组织领导，细化工作措施，明确任务分工，确保工作取得实效。要统筹安排，周密部署，精心组织，各地特别是天津及北京、河北、辽宁、山东环津4省（市）和山西、内蒙古、河南、陕西、甘肃、青海、宁夏、新疆等环疆及出疆进津通道8省（区）邮政管理部门，要严格落实各项工作部署和防范措施，严密防范敌对势力、不法分子利用寄递渠道从事暴力恐怖袭击和捣乱破坏活动，严防行业内部发生重特大安全事故和群体性事件，确保寄递渠道安全畅通，努力为全运会顺利举行作出积极贡献。

二、强化管理，全力做好寄递服务工作。各级邮政管理部门要督促寄递企业加强管理，采取有效措施改善服务，确保各营业网点正常营业，不断提升寄递服务水平和质量。督促企业认真做好消费者咨询服务、投诉处理等工作，妥善处理邮件快件延误、丢失损毁、赔偿等用户反映突出的服务热点问题。天津市邮政管理局要督促辖区邮政企业认真做好全运会期间邮政服务保障工作，挑选政治过硬、业务素质好、服务意识强的工作人员参与服务。要督促邮政企业按照有关服务规范要求，认真做好全运会期间邮件、报刊投递工作，不得随意将邮件作退回处理。要制定邮件专投作业方案，对全运会期间邮件实行专人、专线、专车、专项检查、专项服务“五专”要求，满足参会代表的用邮需求。要加强邮政报刊亭管理，严禁出售非法出版物。要做好全运会特种邮票发行服务保障工作，确保稳妥有序。

三、强化督导，严格落实寄递安全管控措施。各级邮政管理部门要督促寄递企业严格落实8月9日邮政业安全综合整治电视电话会议和8月16日企业总部寄递安全管理工作座谈会部署要求，切实履行安全主体责任，严格落实各项制度措施，进一步夯实安全基础。要强化源头管控，严格执行收寄验视制度，重点加大对疑似爆炸装置、危险化学品、各类枪支弹药、易燃易爆物品、政治性非法出版物等违禁物品的查验力度，坚决将各类禁寄物品堵截在寄递渠道之外。要严格执行实名收寄制度，加快实名收寄信息系统推广应用，做好寄递客户身份、物品信息登记工作。要严格执行过机安检制度，8月20日8时至9月10日24时，各地寄往天津的邮件快件一律经过机安检后加盖或者粘贴安检标识。天津市邮政管理局要制定专门工作方案，督促寄递企业对规定期限内无“安检”标识的进津邮件快件一律予以退返，对寄达的邮件快件进行二次安检，配合相关部门对寄往核心区的邮件快件实施更加严格的安检措施，确保万无一失。各级邮政管理要加强执法检查，对安全制度执行不到位、存在重大安全隐患的，坚持“零容忍”，依法予以严厉查处。

四、强化防范，全力确保行业安全稳定。各级邮政管理部门要督促寄递企业开展安全隐患排查治理和违法寄递危险化学品整治工作，突出加强分拨中心、营业场所、员工宿舍等重点部位和人员、车辆、消防、用电等安全检查力度，切实做到防患于未然。要督促企业做好矛盾纠纷排查化解工作，严防发生群体性事件。要加强与公安、国家安全等部门的协作配合，加强情报信息共享和交流，对全运会期间可能发生的各类突发事件进行预测分析，采取针对性防范措施，遇有企图通过寄递渠道寄递危爆物品等可疑情况，及时通报公安、国家安全等部门落地核查。要强化应急保障，确保一旦发生突发情况能够及时有效处置。要加强应急值守和信息报送工作，严格执行值班和领导带班制度，遇到重大问题和突发事件，要及时报告。

国家邮政局

2017年8月18日
