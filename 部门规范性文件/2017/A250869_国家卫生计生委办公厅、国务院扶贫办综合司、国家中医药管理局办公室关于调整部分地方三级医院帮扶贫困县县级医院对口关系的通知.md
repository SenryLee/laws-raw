# 国家卫生计生委办公厅、国务院扶贫办综合司、国家中医药管理局办公室关于调整部分地方三级医院帮扶贫困县县级医院对口关系的通知

## 关于调整部分地方三级医院帮扶贫困县县级医院对口关系的通知

国卫办医函〔2017〕421号

各省、自治区、直辖市卫生计生委、中医药管理局、扶贫办，新疆生产建设兵团卫生局、扶贫办：

2016年，国家卫生计生委、国务院扶贫办、国家中医药管理局等5部门联合印发了《加强三级医院对口帮扶贫困县县级医院工作方案》（国卫医发〔2016〕7号，以下简称《工作方案》）。一年来，各地积极落实帮扶要求，通过派驻医务人员、搭建远程医疗平台、开展相关培训等方式，不断推进对口帮扶工作。为进一步落实健康扶贫工作，针对各地反映的问题和对口帮扶医院合作意愿，经商各相关省份卫生计生行政部门、中医药管理部门，决定对部分地方三级医院帮扶贫困县县级医院的对口关系进行调整。现将调整表印发给你们，其他地方三级医院、军队和武警部队医院与贫困县县级医院的对口帮扶关系不变。地方各级卫生计生行政部门、扶贫办、中医药管理部门要指导辖区内对口帮扶关系调整的相关方，于2017年6月底前签订新的帮扶协议，对口关系调整过程中要确保工作有序衔接、不断档。承担对口帮扶工作的各医院，要认真落实《工作方案》，有针对性地开展对口帮扶工作，2017年6月底前实现贫困县县医院远程医疗全覆盖，进一步推动优质医疗资源向贫困县下沉。
