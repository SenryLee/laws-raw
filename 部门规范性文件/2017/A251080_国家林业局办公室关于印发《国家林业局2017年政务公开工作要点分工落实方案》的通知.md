# 国家林业局办公室关于印发《国家林业局2017年政务公开工作要点分工落实方案》的通知

办发字〔2017〕51号

国家林业局各司局、各直属单位：

为深入贯彻落实《中华人民共和国政府信息公开条例》和中共中央办公厅、国务院办公厅《关于全面推行政务公开工作的意见》及其实施细则（以下简称《意见》及实施细则），大力推进我局政务公开工作，按照《国务院办公厅关于印发2017年政务公开工作要点的通知》（国办发〔2017〕24号）要求，我局制定了《国家林业局2017年政务公开工作要点分工落实方案》（见附件）。现印发给你们，请认真贯彻执行。

一、各司局、各直属单位要按照分工要求，紧密围绕林业中心工作及社会关切，采取切实有效措施，认真做好政务公开工作，保障人民群众知情权、参与权、表达权和监督权，增强公开实效，助力林业改革发展和林业现代化建设。

二、牵头司局、直属单位对政务公开信息负总责，其他司局、直属单位要根据各自职能分工，积极配合，加强合作。需要增加配合单位的，请牵头单位商有关单位自行确定。

三、请各牵头司局、直属单位于2017年12月30日前，将政务公开情况报局办公室机要值班处（国林宾馆528房间）。

## 国家林业局2017年政务公开工作要点分工落实方案

为确保我局2017年政务公开工作落到实处，根据《国务院办公厅关于印发2017年政务公开工作要点的通知》（国办发〔2017〕24号）要求，结合我局实际，现提出如下分工方案。

一、以政务公开助力稳增长

1.出台关于重大建设项目批准和实施、公共资源配置领域信息公开的指导意见，明确公开的主体、范围、程序等。围绕易地扶贫搬迁、生态环保等重大建设项目，做好审批、核准、备案等结果公开，落实责任，着力推进实施过程信息公开。（计财司牵头落实，造林司、资源司、保护司、场圃总站、天保办、三北局、退耕办、治沙办、速丰办、湿地办配合）

2.全面公开PPP相关法律法规、政策文件、项目进展、专家库等信息，做好项目准备、实施等阶段信息公开工作，加大对社会资本参与方式、项目合同和回报机制等内容的公开力度，着力提高公开的及时性、准确性和完整性，激发社会资本的参与热情。（计财司牵头落实，相关司局、直属单位配合）

二、以政务公开助力促改革

3.投资核准事项清单、国家职业资格目录清单、政府定价或指导价经营服务性收费清单、中介服务事项清单等，都要集中发布，接受群众监督，推动政府更好依法规范履职。（计财司、人事司按职能分工分别牵头落实，相关司局、直属单位配合）

4.及时公开政策性文件的废止、失效等情况，并在政府网站已发布的原文件上作出明确标注。（各司局、各相关直属单位按职能分工分别牵头落实）

5.大力推进“互联网+政务服务”，年内完成政务服务事项目录编制工作，通过本级政府门户网站集中全面公开。（信息办牵头落实，相关司局、直属单位配合）

6.做好国有产权交易、增资扩股项目的信息披露和结果公示工作，推动产权交易机构与公共资源交易平台实现信息共享。依法依规公开中央企业生产经营、业绩考核总体情况，国有资产保值增值情况，中央企业改革重组结果，中央企业负责人重大变动、年度薪酬，以及中央企业履行社会责任重点工作情况。指导中央企业做好信息公开试点工作。（计财司、人事司按职能分工分别牵头落实，出版社配合）

7.加大强农惠农政策公开力度，深入解读农村产权制度改革、农业补贴、农村劳动力转移就业、农民工返乡创业等政策措施，通过编印操作手册、组织专题培训、驻村干部讲解等方式，真正让农民群众看得到、听得懂。（林改司牵头落实，相关司局、直属单位配合）

8.深入推进预决算公开，集中公开部门预决算，对公开内容进行分级分类，方便公众查阅和监督。（计财司牵头落实）

三、以政务公开助力调结构

9.定期发布林产品消费市场运行情况分析报告和森林旅游发展报告，重点公开与群众密切相关的林产品和森林旅游行业发展情况，引导消费升级。（计财司、林改司、场圃总站按职能分工分别牵头落实）

10.推动推荐性国家标准和林业行业标准全文公开。做好质量提升行动、执法专项行动信息公开，发布中国品牌价值评价结果，公开质量违法行为记录、缺陷产品名单及后续处理情况，促进中高端产品供给。及时公布流通领域商品质量抽检结果。（科技司、科技中心按职能分工分别牵头落实）

11.加大对查处假冒伪劣、虚假广告、价格欺诈等行为的公开力度。（场圃总站牵头落实）

四、以政务公开助力惠民生

12.围绕实施精准扶贫、精准脱贫，加大扶贫政策、扶贫对象、帮扶措施、扶贫成效、扶贫资金项目安排等信息公开力度。高度重视困难群众救助信息公开，切实增强公开的针对性和有效性，让困难群众知晓政策、得到保障。（计财司牵头落实）

13.及时公开全面推行“河长制”工作实施方案、管理保护目标以及河湖保护情况。（湿地办牵头落实）

14.进一步做好教育监管信息公开，继续推进国家林业局直属高校本科教学质量报告、毕业生就业质量年度报告和高校信息公开年度报告公开，加大国家教育督导评估监测报告发布力度。（人事司牵头落实）

15.加大森林食品监管信息公开力度，公开森林食品安全违法行为处罚信息。定期公布全国森林食品抽检总体情况、发现的主要问题和核查处置情况。（科技司牵头落实，相关司局、直属单位配合）

16.建设新媒体发布平台，强化森林食品安全定期常态性抽检信息公开机制，增强公众获取抽检结果、了解食品知识的便利度。（信息办牵头落实，科技司配合）

五、以政务公开助力防风险

17.深化棚户区改造及配套基础设施建设、农村危房改造相关政策措施执行情况公开工作，进一步做好保障性安居工程相关任务完成情况等方面的公开。（计财司牵头落实）

18.及时发布重特大事故预警信息和安全提示，做好重大风险隐患排查信息公开工作。（造林司、资源司、保护司、防火办、治沙办按职能分工分别牵头落实）

19.加大安全生产监管监察信息公开力度，公开常规检查执法、暗查暗访、突击检查、随机抽查等执法信息。落实好安全生产不良记录“黑名单”制度，并向社会公布。（林改司牵头落实，相关司局、直属单位配合）

六、增强政务公开实效

20.全面落实“五公开”工作机制。认真落实《意见》及实施细则的相关要求，年内要完成“五公开”纳入办文办会程序、建立公开内容动态扩展机制等工作，加快制定主动公开基本目录，稳步有序拓展公开范围。（办公室牵头落实，相关司局、直属单位配合）

21.对涉及公众利益、需要社会广泛知晓的电视电话会议，除涉及国家秘密的外，要积极通过网络、新媒体直播等向社会公开。（办公室牵头落实，信息办配合）

22.进一步做好全国人大代表建议和全国政协委员提案办理结果公开工作，对涉及公共利益、社会广泛关注的建议提案，原则上都要公开答复全文，及时回应关切，接受群众监督。（办公室牵头落实，相关司局、直属单位配合）

23.林业主管部门主要负责人要履行好“第一解读人和责任人”的职责，充分利用新闻发布会、政策吹风会等方式，主动回应重大舆论关切，释放信号，引导预期。（宣传办牵头落实，相关司局、直属单位配合）

24.切实落实《意见》及实施细则关于做好政策解读回应的相关规定。要按照“谁起草、谁解读”的原则，做到政策性文件与解读方案、解读材料同步组织、同步审签、同步部署。严格执行特别重大、重大突发事件最迟5小时内发布权威信息、24小时内举行新闻发布会的时限要求，落实通报批评和约谈制度，确保回应不超时、内容不敷衍。（各司局、各相关直属单位按职能分工分别牵头落实，办公室、信息办、宣传办配合）

25.要切实履行对政府网站的监管责任，进一步加强和改进政府网站内容建设，做好日常监测和季度抽查，及时公开抽查情况；推进政府网站集约化，对保障不力的要关停上移，切实提高管理水平。（信息办牵头落实，相关司局、直属单位配合）

26.按照全国政务服务体系普查要求，全面梳理进驻行政许可受理中心服务事项、服务信息公开情况、系统建设情况等，认真组织填报，确保数据信息真实、准确、完整。（政法司牵头落实，相关司局、直属单位配合）

27.要用好管好政务新媒体，明确开办主体责任，健全内容发布审核机制，强化互动和服务功能，切实解决更新慢、“雷人雷语”、无序发声、敷衍了事等问题。争取入驻国务院客户端。（信息办、宣传办按职能分工分别牵头落实）

28.适应互联网发展要求，积极推进政府公报同步上网，加快历史公报数字化工作。（政法司牵头落实）

29.畅通依申请公开受理渠道，依法保障公众合理的信息需求。进一步规范依申请公开答复工作，严格按照法定时限答复，增强答复内容针对性。对公众申请较为集中的政府信息，可以转为主动公开的，应当主动公开。（各司局、各相关直属单位按职能分工分别牵头落实）

30.加强督查评估，将政务公开纳入绩效考核体系。无绩效考核体系的，年内要建立政务公开专项考核机制。（人事司牵头落实）
