# 农业部对十二届全国人大五次会议第9345号建议的答复

## 对十二届全国人大五次会议第9345号建议的答复

农办议〔2017〕214号

王广基等8名代表：

你们提出的“关于支持中药资源高效循环利用，推进中药绿色制造工程的建议”收悉。现就涉及我部职能的部分答复如下。

中药材是中医药事业传承和发展的物质基础。近年来，我国中药材生产保持发展的势头，为促进中药工业和健康产业发展发挥了重要作用。据统计，2016年中药材种植面积3350多万亩，产量约200万吨，中药饮片加工产值约2000亿元。农业部高度重视中药材产业发展，大力推进中药材资源循环利用。

推动中药材作畜禽饲料原料。部分中药材富含粗蛋白、粗脂肪、维生素、矿物质等，有的还具有消食健胃等作用，能提高饲料的转化率。农业部在试验研究的基础上，发布公告，推荐110多种中药材用作畜禽饲料原料。

推动中药材用于防治畜禽疾病。中药材是一类天然、环保型绿色药物，用作鱼类和畜禽疾病防治，具有毒副作用小、安全性高、成本低、残留少或无残留等优点。农业部发布兽药典（2010版），明确提出鼓励推广使用中药材防治畜禽疾病，促进提高鱼类和畜禽产品质量安全水平。

推进中药材用于制作生物农药。利用中药材的某些部位（根、茎、叶、花或果实）、中药副产物和加工废弃物，经过提纯获得有效成分，可用来制作植物源农药。农业部积极引导中药植物源农药的研发，目前已成功利用苦参、丁香、肉桂、樟脑、肉豆蔻、黄芩、川楝、地瓜子、苦檀子、鸡血藤、鱼藤等多种中药材提取苦参碱、烟碱、鱼藤酮等20余类原药，加工制作生物农药制剂100余种，对防控植物病、虫、杂草等有害生物危害发挥了重要作用。

推进中药加工废弃物制作基质和肥料。中药加工固体废弃物，富含有机质及氮、磷钾等养分，质轻、透气性好，是一种优质的有机肥和轻基质原料。农业部通过化肥使用量零增长行动和有机肥替代化肥行动，鼓励经无害化处理的中药加工固体废弃物，与辅料配成的基质，用于蔬菜、西甜瓜、草莓、花卉等育苗和无土栽培，取得较好效果。并引导有机肥加工企业将经无害化处理的中药加工固体废弃物，与畜禽粪便，按照一定的比例配制成有机肥，施用后有效改善土壤理化性状，提高土壤肥力。

下一步，农业部将加大研究开发和示范推广力度，引导中药材用作畜禽饲料原料、防治鱼类和畜禽疾病，促进中药材及加工副产品在养殖业中应用。结合实施农药、化肥使用量零增长行动，加快中药植物源农药等生物农药推广步伐，鼓励有机肥加工企业利用中药加工固体废弃物生产有机肥，提高中药加工固体废弃物利用率，促进中药资源高效循环利用。

感谢你们对我国中药材产业的关心，希望今后继续对农业部工作予以支持。
