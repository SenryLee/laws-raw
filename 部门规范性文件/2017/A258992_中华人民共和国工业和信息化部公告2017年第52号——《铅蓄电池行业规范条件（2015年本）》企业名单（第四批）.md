# 中华人民共和国工业和信息化部公告2017年第52号——《铅蓄电池行业规范条件（2015年本）》企业名单（第四批）

## 中华人民共和国工业和信息化部公告

2017年第52号

## 《铅蓄电池行业规范条件（2015年本）》企业名单（第四批）

为推动我国铅蓄电池行业可持续发展，依据《铅蓄电池行业规范条件（2015年本）》及《铅蓄电池行业规范公告管理办法（2015年本）》，经企业申请、省级工业和信息化主管部门初审、专家审核、工业和信息化部复核以及网上公示等程序，19家企业列入《符合<铅蓄电池行业规范条件（2015年本）>企业名单（第四批）》，现予以公告。

附件：符合《铅蓄电池行业规范条件（2015年本）》企业名单（第四批）
