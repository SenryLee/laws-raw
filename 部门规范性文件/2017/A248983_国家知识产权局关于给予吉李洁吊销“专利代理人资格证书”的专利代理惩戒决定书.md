# 国家知识产权局关于给予吉李洁吊销“专利代理人资格证书”的专利代理惩戒决定书

## 关于给予吉李洁吊销“专利代理人资格证书”的专利代理惩戒决定书

国知惩戒决字〔2017〕4号

专利代理惩戒决定书

姓　　名：吉李洁

身份证号：65010219860226654x

资格证号：3216266

所在机构：镇江市创冠专利代理事务所（普通合伙）

2016年11月，中华全国专利代理人协会上报《关于对镇江市创冠专利代理事务所（普通合伙）朱书明等三人执业证办理事宜的请示函》，其中提出，中华全国专利代理人协会在审核镇江市创冠专利代理事务所（普通合伙）（以下简称“镇江创冠”）朱书明、吉李洁、舒佳英三名合伙人的专利代理人执业证申请材料时发现，合伙人朱书明、吉李洁、舒佳英存在出租专利代理资质的违法违规行为，提请国家知识产权局作出进一步处理。

经查，2016年8月31日，朱书明、吉李洁、舒佳英向国家知识产权局提交了设立镇江市创冠专利代理事务所（普通合伙）的申请，并提交了合伙协议、专利代理机构设立审批事项告知承诺书等申请材料。经审批，镇江创冠于2016年9月6日取得专利代理机构注册证。负责人：朱书明，合伙人：朱书明、吉李洁、舒佳英，出资额占比分别为50%、30%、20%，机构地址为镇江市新区丁卯智慧大道668号。

2016年10月，镇江创冠向中华全国专利代理人协会提交了朱书明、吉李洁、舒佳英的执业证申请材料，包括三人档案存放证明以及专利代理事务所合伙人聘用协议。

吉李洁的聘用协议显示：江苏浩邦知识产权服务有限公司镇江分公司（简称“江苏浩邦”）和常越聘用吉李洁为新设事务所合伙人，常越出资筹建事务所，为事务所实际出资人。吉李洁不进行实际的资金投入，不参与事务所的经营决策、日常管理及收益分配。吉李洁持有的股权股份为代常越持有，吉李洁作为名义合伙人加入事务所。吉李洁提供的所有证书、证件和资料使用范围限于设立及经营事务所的过程中，维持事务所专利代理机构资质。协议生效期限为常越收到吉李洁符合办所资质的合格文件之日起至吉李洁作为常越方合伙人2年期满止。协议期间，江苏浩邦和常越支付吉李洁顾问费4.5万元/年，支付方式一年一付。

在调查中，江苏浩邦和吉李洁均对于协议内容的真实性予以承认。

以上事实有下列证据材料为证：

1．镇江市创冠专利代理事务所（普通合伙）合伙协议

2．专利代理机构设立审批事项告知承诺书

3．吉李洁的聘用协议

4．关于创冠专利代理事务所的情况说明

根据《中华人民共和国行政许可法》第三十一条的规定，申请人申请行政许可，应当如实向行政机关提交有关材料和反映真实情况，并对其申请材料实质内容的真实性负责。根据《专利代理管理办法》第五条的规定，专利代理机构的合伙人或者股东应当符合具有专利代理人资格，具有2年以上在专利代理机构执业的经历，能够专职从事专利代理业务等条件。

吉李洁将其专利代理人资格证书提供给江苏浩邦以及常越用于设立新的专利代理机构，收取报酬，代他人持有新设立专利代理机构的股份。在申请设立专利代理机构时，吉李洁在知晓专利代理机构设立条件、申请要求和法律责任的前提下，作出“申请材料真实有效”等不实承诺，提供虚假的合伙协议，隐瞒其不作为事务所的实际出资人、合伙人的重要事实，采用欺骗的方式为镇江创冠取得专利代理执业许可。

经我局专利代理惩戒委员会会议讨论认为，吉李洁的上述行为属于《中华人民共和国行政许可法》第八十条第一项规定的“涂改、倒卖、出租、出借行政许可证件，或者以其他形式非法转让行政许可”、《专利代理惩戒规则（试行）》第八条第四项规定的“提供虚假证据、隐瞒重要事实”的情形。根据《中华人民共和国行政许可法》第八十条、《专利代理条例》第二十五条、《专利代理惩戒规则（试行）》第八条的规定，应当予以惩戒, 拟给予吉李洁吊销“专利代理人资格证书”的处罚。

我局于2017年1月10日发出《专利代理惩戒意见告知书》（国知惩戒函字〔2017〕3号），依法向吉李洁告知拟对其作出吊销“专利代理人资格证书”的处罚的事实、理由、依据以及其依法享有的权利。吉李洁未在法定期限内提出听证要求。

2017年1月27日，我局收到吉李洁的书面申辩。吉李洁申辩称，1. 其并未取得专利代理执业资格，不属于《专利代理条例》、《专利代理惩戒规则（试行）》中定义的专利代理人，不适用《专利代理惩戒规则（试行）》；2.对于镇江市创冠专利代理事务所（普通合伙）合伙协议、专利代理机构设立审批告知承诺书不知晓，上面的签字也并非其本人签署，并未“提供虚假证据、隐瞒重要事实”，不适用《专利代理惩戒规则（试行）》第八条，其并未从事专利代理业务，不适用《专利代理惩戒规则（试行）》第九条；3.其主动向常越提出终止聘用协议，其行为并未造成损害和严重后果，认为给予“吊销专利代理人资格的惩戒”处罚过重。

针对上述申辩理由，我局认为吉李洁的申辩理由不能成立。具体理由如下：

吉李洁将其专利代理人资格证书租借给江苏浩邦及常越设立镇江创冠，镇江创冠于2016年9月6日取得专利代理机构注册证，吉李洁为镇江创冠合伙人。吉李洁承认与常越签订聘用协议，而聘用协议显示：吉李洁以名义合伙人加入事务所，向常越提供其办所资质，供常越设立及经营事务所使用，维持事务所的专利代理机构资质，在事务所设立及经营过程中，吉李洁全力配合常越办理工商、税务、年检等各项事务。从聘用协议可知，吉李洁对于出租专利代理资质是明知的。同时对随后在镇江创冠设立审批中提交虚假材料的违法违规行为，也是支持和放任的。吉李洁配合江苏浩邦、常越以欺骗的方式取得镇江创冠专利代理机构注册证，扰乱了专利代理行业市场竞争秩序，情节严重，社会影响恶劣。此外，吉李洁并未提供证据证明，其存在采取有效措施减少行为社会危害性的事实。

综上，根据当事人违法行为的事实、性质、情节与社会危害程度，依据《中华人民共和国行政许可法》第八十条、《专利代理条例》第二十五条、《专利代理惩戒规则（试行）》第八条的规定，我局决定：给予吉李洁吊销“专利代理人资格证书”的处罚。

当事人如对本决定不服，可以在接到本决定书之日起60日内向国家知识产权局提出行政复议，也可以在收到本决定书之日起6个月内向有管辖权的人民法院提起诉讼。复议和诉讼期间，上述决定不停止执行。

国家知识产权局

2017年3月6日
