# 公开市场业务交易公告[2017]第113号——关于人民银行于2017年6月16日以利率招标方式开展了2900亿元逆回购操作的公告

## 公开市场业务交易公告

[2017]第113号

为对冲稅期和逆回购、MLF到期等因素影响，人民银行于2017年6月16日以利率招标方式开展了2900亿元逆回购操作。

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 交易量 | 中标利率 |
| 7天 | 300亿元 | 2.45% |
| 14天 | 1600亿元 | 2.60% |
| 28天 | 1000亿元 | 2.75% |

中国人民银行公开市场业务操作室

二〇一七年六月十六日
