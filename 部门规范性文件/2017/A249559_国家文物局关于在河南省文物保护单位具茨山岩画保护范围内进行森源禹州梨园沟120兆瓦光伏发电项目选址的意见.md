# 国家文物局关于在河南省文物保护单位具茨山岩画保护范围内进行森源禹州梨园沟120兆瓦光伏发电项目选址的意见

## 关于在河南省文物保护单位具茨山岩画保护范围内进行森源禹州梨园沟120兆瓦光伏发电项目选址的意见

办保函〔2017〕373号

河南省文物局：

你局《关于报批森源禹州梨园沟120兆瓦光伏发电项目选址及设计方案的请示》（豫文物〔2017〕93号）收悉。经研究，我局意见如下：

一、该项目位于河南省文物保护单位具茨山岩画保护范围内，对文物景观影响过大，我局暂不同意在具茨山岩画保护范围内进行森源禹州梨园沟120兆瓦光伏发电项目。

二、对所报方案提出以下修改意见：

（一）加强现状勘察和历史研究，深入分析具茨山岩画的分布区域、岩画朝向及其依存的自然环境和历史环境。所建项目选址应尽量避让和远离具茨山岩画保护范围，充分尊重地形地貌，严格控制工程开挖量，尽量减少对文物本体和景观风貌的影响。

（二）根据文物保护需要，进一步优化拟建项目的平面布局、设备架设方式及场地绿化措施。补充拟建项目与文物本体及其环境的景观分析图。

（三）配套建筑应在保护范围外选址，建筑形制应简洁大方，外观以素色为主，尽量与文物及周边环境相协调。补充配套建筑外观设计图及其与具茨山岩画的位置关系图。

（四）调整、完善文物影响评估报告，科学、客观地评估所建项目对岩画安全及景观风貌的影响。

三、请你局根据所提意见，对项目方案进行修改完善后，按程序另行报批。

专此函。

国家文物局

2017年4月5日
