# 国家文物局关于湘桂古道永州段修缮工程（二期）立项的意见

## 关于湘桂古道永州段修缮工程（二期）立项的意见

办保函〔2017〕23号

湖南省文物局：

你局《全国重点文物保护单位湘桂古道永州段修缮工程（二期）立项的请示》（湘文物报〔2016〕200号）收悉。经研究，我局意见如下：

一、所报工程立项的工程目标不明，必要性和紧迫性不足，我局暂不同意湘桂古道永州段修缮工程（二期）立项。

二、对所报立项报告文本提出以下修改意见：

（一）应进一步明确湘桂古道永州段修缮工程（二期）的设计思路和定位，根据文物病害情况、展示利用需要和地方经济社会发展现状，统筹考虑修缮工程实施的必要性和可行性。

（二）应全面梳理文物建筑历次修缮工程情况，客观评估工程效果，总结当地建造工艺、传统做法、建筑材料等，为制定保护措施提供依据。

（三）应在湘桂古道永州段修缮工程（一期）结束后，系统评估修缮效果，客观分析、总结工程经验成果，适时启动二期修缮工程。

三、请你局根据文物保护工程立项的相关要求及我局所提意见，对立项报告进行修改完善后，按程序另行报批。

专此函。

国家文物局

2017年1月13日
