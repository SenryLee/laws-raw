# 国家文物局关于渡江战役总前委旧址修缮工程立项的意见

## 关于渡江战役总前委旧址修缮工程立项的意见

办保函〔2017〕337号

安徽省文物局：

你局《关于批准渡江战役总前委旧址修缮工程立项的请示》（皖文物保〔2017〕17号）收悉。经研究，我局意见如下：

一、所报立项报告未按照我局《关于渡江战役总前委旧址修缮工程立项的意见》（办保函﹝2015﹞558号）的要求进行修改完善，工程实施的必要性与可行性分析论述不足，保护措施不合理，暂不同意渡江战役总前委旧址修缮工程立项。

二、请你局加强指导有关单位，根据我局办保函﹝2015﹞558号文的意见，对该工程项目内容重新进行梳理，并做出必要调整，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年3月27日
