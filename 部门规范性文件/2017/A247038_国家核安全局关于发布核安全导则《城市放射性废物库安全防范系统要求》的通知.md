# 国家核安全局关于发布核安全导则《城市放射性废物库安全防范系统要求》的通知

## 关于发布核安全导则《城市放射性废物库安全防范系统要求》的通知

国核安发[2017]26号

各有关单位：

为进一步完善我国核与辐射安全法规体系，提高我国城市放射性废物库的安全防范水平，我局组织制定了核安全导则《城市放射性废物库安全防范系统要求》（HAD 802/01-2017），现予以发布。本导则自发布之日起实施。

附件：城市放射性废物库安全防范系统要求

国家核安全局

2017年2月4日
