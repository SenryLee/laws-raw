# 中共教育部党组关于郭海、颜吾佴同志职务任免的通知

教党任〔2017〕179号

中共北京交通大学委员会：

经与中共北京市委商得一致，2017年7月24日研究决定：

郭海同志任中共北京交通大学委员会委员、常委、副书记，纪律检查委员会书记；免去颜吾佴同志的中共北京交通大学纪律检查委员会书记职务。

中共教育部党组

2017年8月1日
