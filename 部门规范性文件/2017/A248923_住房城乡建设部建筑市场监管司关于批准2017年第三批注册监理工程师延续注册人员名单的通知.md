# 住房城乡建设部建筑市场监管司关于批准2017年第三批注册监理工程师延续注册人员名单的通知

## 关于批准2017年第三批注册监理工程师延续注册人员名单的通知

建市监函[2017]20号

各省、自治区住房城乡建设厅，直辖市建委，新疆生产建设兵团建设局，国务院有关部门建设司（局）：

根据《注册监理工程师管理规定》（建设部令第147号）及注册监理工程师有关规定，经审核，鹿铁柱等5230名申请注册监理工程师延续注册人员符合延续注册条件，准予注册。

附件：准予鹿铁柱等5230名注册监理工程师延续注册人员名单

住房城乡建设部建筑市场监管司

2017年4月5日
