# 中华人民共和国农业部公告第2576号——新兽药注册目录

## 中华人民共和国农业部公告

第2576号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准中牧实业股份有限公司等6家单位申报的猪口蹄疫O型合成肽疫苗（多肽0405+0457）等2种兽药产品为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

批准齐鲁动物保健品有限公司申报的注射用头孢噻呋钠增加靶动物牛变更注册，并发布修订后的质量标准、说明书和标签，自发布之日起执行。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年8月31日
