# 国家文物局办公室关于须弥山石窟环境整治项目的意见

办保函〔2017〕979号

宁夏回族自治区文物局：

你局《关于报送须弥山石窟保护设施建设项目设计方案的请示》（宁文物发〔2017〕80号）收悉。经研究，我局意见如下：

一、所报项目设计依据不足，方案深度不够，我局暂不同意须弥山石窟环境整治项目。

二、所报方案应进行以下必要的修改和完善：

（一）进一步明确项目依据，说明《须弥山石窟文物保护规划》关于管理用房、看护房以及环境整治的相关内容，补充须弥山石窟保护范围和建设控制地带的管理规定和具体控制指标。拟建项目应与规划内容一致，并符合相关管理规定。

（二）深化现状勘察，拟维修道路与防护栏应在图纸分段编号，并补充相应的现状照片。进一步深化设计方案，明确拟维修道路的材质、色彩、工程措施、操作要求等。补充防护栏的外观样式及设计依据。

（三）景区前广场局部修补应统筹考虑场地排水问题。

（四）补充界桩设置的依据和布设图纸。应根据文物保护需要合理调整布设间距，减少界桩数量，避免影响文物景观。

（五）应重新编制文物影响评估报告，客观、准确、科学地论证拟建项目对文物本体和环境风貌的影响，增强评估的针对性。

三、请你局组织有关单位根据上述意见和我局《关于须弥山石窟环境整治项目的意见》（办保函〔2017〕336号）的要求，对所报方案进行修改、完善后，按程序另行报批。

专此函。

国家文物局办公室

2017年8月21日
