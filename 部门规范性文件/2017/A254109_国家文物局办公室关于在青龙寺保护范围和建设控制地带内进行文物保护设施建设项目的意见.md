# 国家文物局办公室关于在青龙寺保护范围和建设控制地带内进行文物保护设施建设项目的意见

办保函〔2017〕910号

山西省文物局：

你局《关于审批稷山县青龙寺文物保护设施建设项目设计方案的请示》（晋文物〔2017〕125号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位青龙寺保护范围和建设控制地带内，对文物景观影响较大，设计依据不足，文本深度不够，我局暂不同意该项目。

二、对所报方案提出以下修改意见：

（一）应从青龙寺保护管理的实际需要出发，进一步明确文物保护设施建设项目的必要性和可行性，准确核实项目内容、工程范围以及与文物保护区划的关系，说明庙前栏杆及踏步、庙前花栏墙是否为青龙寺文物构成。补充《青龙寺保护规划》关于保护范围和建设控制地带的管理规定、具体控制要求和工程设计依据。

（二）深化方案设计，进一步明确工程内容，厘清土方填挖与垃圾清运工程，核准土方量；拟建及改建建筑应采用当地传统建筑形式结构做法，建筑风格力求简洁；科学论证拆除重砌现有围墙的必要性，建议围墙进行现状改造，保持外观与周边景观环境相协调。

（三）补充文物影响评估报告，根据方案内容准确、客观地论证拟建项目对文物本体、寺庙原有格局和院落空间的影响，科学研提方案调整建议。

（四）防雷工程不宜纳入本次工程范围，应按程序另行报批。

（五）补充单位、人员签章，规范、校核文本图纸并与项目内容一致，如：校核设备用房、改造管理用房等内容。

三、请你局组织相关单位根据所提意见，对项目方案进行修改完善后，按程序另行报批。

专此。

国家文物局办公室

2017年8月4日
