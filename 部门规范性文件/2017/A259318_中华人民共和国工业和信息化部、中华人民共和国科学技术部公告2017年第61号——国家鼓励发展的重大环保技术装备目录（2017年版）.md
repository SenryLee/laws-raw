# 中华人民共和国工业和信息化部、中华人民共和国科学技术部公告2017年第61号——国家鼓励发展的重大环保技术装备目录（2017年版）

## 中华人民共和国工业和信息化部　中华人民共和国科学技术部公告

2017年第61号

为贯彻落实《中国制造2025》（国发〔2015〕28号）和《“十三五”国家战略性新兴产业发展规划》（国发〔2016〕67号），引导重大环保技术装备研发与产业化对接，加快新技术、新产品、新装备的推广应用，提高环保装备制造业水平，促进环保产业持续健康发展，工业和信息化部联合科技部制定了《国家鼓励发展的重大环保技术装备目录（2017年版）》，现予公告。

附件：国家鼓励发展的重大环保技术装备目录（2017年版）

工业和信息化部

科学技术部

2017年12月27日
