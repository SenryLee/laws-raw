# 国家文物局办公室关于兴国寺塔保护规划意见的函

办保函〔2017〕987号

山东省文物局：

你局《关于呈报兴国寺塔环境保护规划的请示》（鲁文发〔2016〕179号）收悉。经研究，我局意见如下：

一、所报规划命名不规范，规划目标和性质不明，规划内容不合理，我局不同意所报兴国寺塔环境保护规划。

二、请你局督促、指导地方人民政府加强“四有”建设，完善兴国寺塔的保护区划、管理规定和具体保护管理措施，严格控制周边各类建设活动。同时，应切实做好文物日常养护、巡查和岁修工作，确保文物安全，如发现影响文物安全的病害险情，应及时启动保护工作，并按要求履行报批程序。涉及文物周边环境整治工作的，应根据文物保护区划的管理规定和控制要求，合理确定整治范围和内容，并按程序报批。

专此函复。

国家文物局办公室

2017年8月22日
