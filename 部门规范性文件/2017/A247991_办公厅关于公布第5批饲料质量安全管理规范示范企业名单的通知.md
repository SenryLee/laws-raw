# 办公厅关于公布第5批饲料质量安全管理规范示范企业名单的通知

## 农业部办公厅关于公布第5批饲料质量安全管理规范示范企业名单的通知

农办牧〔2017〕11号

各省、自治区、直辖市畜牧（农业、农牧）厅（委、局、办），饲料工作（工业）办公室：

为全面落实《饲料质量安全管理规范》（以下简称《规范》），树立饲料企业质量安全管理标杆，推动饲料产品品牌建设，我部组织开展了饲料质量安全管理规范示范企业创建活动。经专家组现场审核，河北等16个省、自治区的51家饲料生产企业通过部级验收，现予公布，有效期3年（2017年3月至2020年3月）。希望示范企业珍惜荣誉，发挥带动作用，引领行业提升质量安全管理水平，为推动行业进步做出积极贡献。各级饲料管理部门要加强监督检查，发现示范企业存在违法违规行为或不再具备示范作用的，及时通报我部撤销其示范企业称号。

各级饲料管理部门要按照《农业部关于全面实施〈饲料质量安全管理规范〉的意见》（农牧发〔2015〕8号）要求，把实施《规范》作为落实生产者主体责任、保证饲料产品质量安全、提升监管能力的重要抓手，切实加强组织领导、着力强化工作落实，综合运用行政许可、监督执法、指导培训、示范创建等手段，确保《规范》落实到辖区每一家饲料生产企业。我部将把实施《规范》作为省级饲料管理部门工作督导检查的重要内容，对行动迟缓、实施滞后的地方予以通报。

附件：饲料质量安全管理规范示范企业名单（第5批）
