# 国家发展改革委办公厅关于开展2017年中央地方创新创业联合研究课题申报的通知

发改办高技〔2017〕250号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团发展改革委：

为切实发挥发展改革系统工作合力，进一步加强实施创新驱动发展战略、推进大众创业万众创新理论研究，更好支撑创新创业工作，我委决定开展2017年国家地方创新创业联合课题研究。现将有关事项通知如下：

一、总体要求

（一）高度重视。本次联合研究课题将列入国家发展改革委重大课题研究，各地发展改革委要高度重视，结合本地工作实际和研究力量，提出课题方案，切实做好组织实施，形成系列高质量研究成果，推动创新创业工作。

（二）自选题目。各地方根据自身创新创业发展情况和特点，参考创新创业联合研究课题题目（见附件1）选择1-2个课题题目，也可结合本地工作实际另行提出研究备选课题。首批区域双创示范基地所在省市，要同步组织各示范基地开展至少1项课题研究。

（三）有序推进。各地方选择研究课题题目后，请在规定时间内将选题考虑报我委高技术司，我委将择优选定部分课题启动国家地方联合研究。对确定的国家地方联合研究课题，请各地方及时组织开展研究工作。我委将适时召开课题研究讨论交流会，加强各研究参与单位的沟通交流。

（四）成果应用。课题要突出成果的社会效益和经济效益，要充分吸收国内外研究成果，突出我国创新创业工作特色与理论创新，提出切实的思路和举措，注重成果有效转化，为政策制定提供参考。

二、进度安排

（一）上报课题题目。3月10日前，请各地方将申报研究题目及申报书按照附件2、3格式报我委高技术司，电子版请发邮箱sckt2017@126.com。

（二）上报课题研究成果。10月底以前，请各地方将最终课题研究成果及应用情况报我委高技术司。

三、其他事项

（一）关于课题研究经费。纳入国家地方联合课题研究的课题经费请各地方自筹，国家发展改革委不安排课题研究经费。

（二）关于课题奖励。根据课题成果质量及应用情况，国家发展改革委将对优秀课题研究成果进行通报表扬和奖励。

附件：1.国家地方创新创业联合研究课题参考题目

2.创新创业联合研究课题清单

3.国家地方创新创业联合研究课题申报书
