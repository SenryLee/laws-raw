# 教育部办公厅关于公布第二批全国中小学心理健康教育特色学校名单并启动第三批特色学校争创工作的通知

教基厅函〔2017〕21号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

根据《教育部办公厅关于实施中小学心理健康教育特色学校争创计划的通知》（教基一厅函〔2014〕14号）、《教育部办公厅关于公布首批全国中小学心理健康教育特色学校名单并启动第二批特色学校争创工作的通知》（教基一厅函〔2015〕44号）要求，我部启动了第二批全国中小学心理健康教育特色学校争创工作。在省级教育部门审核推荐，组织专家综合评审的基础上，现认定并命名北方交通大学附属中学等209所中小学校为第二批全国中小学心理健康教育特色学校（以下简称特色学校）。

希望各地教育部门高度重视特色学校争创工作，广泛宣传特色学校的典型经验，进一步发挥特色学校的示范引领作用，加强区域内合作交流，促进中小学校共同提高心理健康教育水平。同时，请各地按照教基一厅函〔2014〕14号通知要求，开展第三批特色学校争创工作，请各省级教育部门根据当地争创工作情况于2018年9月30日前推荐5-8所工作突出的学校，报送教育部基础教育司。

（联系人及电话：赵珊010-66096369）

附件：第二批全国中小学心理健康教育特色学校名单
