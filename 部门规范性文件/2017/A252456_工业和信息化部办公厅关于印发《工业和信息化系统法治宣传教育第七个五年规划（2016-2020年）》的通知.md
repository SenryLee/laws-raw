# 工业和信息化部办公厅关于印发《工业和信息化系统法治宣传教育第七个五年规划（2016-2020年）》的通知

工信厅政〔2017〕54号

各省、自治区、直辖市通信管理局、工业和信息化主管部门，部属各单位，部属各高校，部机关各司局：

为深入推进工业和信息化系统法治宣传教育工作，根据《中央宣传部、司法部关于在公民中开展法治宣传教育的第七个五年规划（2016-2020年）》，制定《工业和信息化系统第七个五年法治宣传教育规划（2016-2020年）》。现印发你们，请结合实际，认真组织实施。

工业和信息化部办公厅

2017年3月31日

附件： 工业和信息化系统法治宣传教育第七个五年规划
