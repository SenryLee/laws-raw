# 国家文物局关于张家界市永定区湘鄂川黔革命根据地旧址展示工程立项的意见

## 关于张家界市永定区湘鄂川黔革命根据地旧址展示工程立项的意见

办保函〔2017〕335号

湖南省文物局：

你局《关于永定区湘鄂川黔革命根据地旧址展示利用工程立项的请示》（湘文物报〔2017〕15号）收悉。经研究，我局意见如下：

一、深入开展文物价值和开放、展示现状评估，客观分析目前存在的问题，为有效提升文物展示水平制定针对性解决方案。

二、坚持文物保护原则，严格控制展示设施、设备的规模和体量，不得对文物建筑本体和历史空间格局造成破坏或改变，其外观和色彩应与文物及其环境相协调，其材质应具备防火性能。

三、展示内容应紧紧围绕文物建筑的价值及自身所承载的文化信息；恢复室内场景设计须有相关历史依据。

国家文物局

2017年3月27日
