# 国家文物局关于柳州市白莲洞遗址本体保护工程立项的意见

## 关于柳州市白莲洞遗址本体保护工程立项的意见

办保函〔2017〕216号

广西壮族自治区文化厅：

你厅《关于报送柳州市白莲洞遗址本体保护立项报告的请示》（桂文物报〔2017〕1号）收悉。经研究，我局意见如下：

一、暂不同意柳州市白莲洞遗址本体保护工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）补充评估拟采取的渗水治理工程措施的有效性及后续维护的可行性，并据此进一步优化技术路线。

（二）补充分析洞穴内壁表面风化硬化和污垢对遗址本体安全的影响，在此基础上，进一步论证开展洞穴清理和渗水治理工程的必要性。同时应考虑文物本体表面清理保护与洞穴渗水治理的时序问题。

（三）进一步加强悬空土体的分布规模和稳定性的勘察评估，明确本体局部凹槽支撑的工程范围和具体措施。

三、请你厅根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局指导地方人民政府加强白莲洞遗址文物本体的日常维护和监管，做好必要的临时性支护，确保文物安全。

国家文物局

2017年3月7日
