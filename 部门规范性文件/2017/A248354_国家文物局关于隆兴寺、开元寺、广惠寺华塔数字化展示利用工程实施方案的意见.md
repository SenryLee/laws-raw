# 国家文物局关于隆兴寺、开元寺、广惠寺华塔数字化展示利用工程实施方案的意见

## 关于隆兴寺、开元寺、广惠寺华塔数字化展示利用工程实施方案的意见

办保函〔2017〕199号

河北省文物局：

你局《关于呈报正定隆兴寺等三处全国重点文物保护单位数字化展示利用工程实施方案的请示》（冀文物字〔2016〕262号）收悉。经研究，我局意见如下：

一、所报工程方案内容简单，设计深度不足，我局暂不同意全国重点文物保护单位隆兴寺、开元寺、广惠寺华塔数字化展示利用工程方案。

二、对该方案提出以下修改意见：

（一）应进一步明确工作内容和目标，从全面获取和记录文物信息、提升现有展示水平的角度，科学确定数字化展示工作重点，增强项目的针对性和可行性。补充《隆兴寺保护规划》、《开元寺保护规划》、《广惠寺华塔保护规划》中涉及数字化展示工程的相关内容。

(二)应针对隆兴寺、开元寺、广惠寺华塔等文物建筑特点，细化方案设计，避免简单介绍仪器设备参数和通用操作标准。应研提具体数字化展示利用的技术路线，明确扫描建模部位、精细化程度、成果表现形式、线图绘制方法、野外作业方式等，细化工作技术流程和质量保证措施。

（三）应充分考虑隆兴寺、开元寺、广惠寺华塔展示需要，进一步明确数字化展示与现有展陈体系的衔接，利用多种科技手段阐释文物价值，加强数字化展示内容设计和研发，提升文物整体展陈水平。

三、请你局根据上述意见和我局《关于隆兴寺、开元寺、广惠寺华塔数字化展示项目立项的批复》（文物保函〔2016〕1106号）要求，组织相关单位修改、完善设计方案，经你局审核后另行报批。

专此函。

国家文物局

2017年3月2日
