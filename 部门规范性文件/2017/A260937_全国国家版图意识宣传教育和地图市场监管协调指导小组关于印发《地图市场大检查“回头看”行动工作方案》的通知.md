# 全国国家版图意识宣传教育和地图市场监管协调指导小组关于印发《地图市场大检查“回头看”行动工作方案》的通知

## 关于印发《地图市场大检查“回头看”行动工作方案》的通知

国图宣教管〔2017〕2号

各省、自治区、直辖市国家版图意识宣传教育和地图市场监管协调指导机构，各有关单位：

根据《国家版图意识宣传教育和地图市场监管2017年工作要点》，全国国家版图意识宣传教育和地图市场监管协调指导小组制定了《地图市场大检查“回头看”行动工作方案》，现印发给你们。请结合本地实际制定实施方案，及时开展工作，依法查处地图市场各类违法违规案件，维护良好地图市场秩序。

全国国家版图意识宣传教育和地图市场监管协调指导小组

（国家测绘地理信息局代章）

2017年3月7日

## 地图市场大检查“回头看”行动工作方案

2016年，由国家测绘地理信息局、中央网信办、外交部、教育部、工业和信息化部、公安部、民政部、商务部、海关总署、工商总局、新闻出版广电总局、国家保密局等12部门组成的全国国家版图意识宣传教育和地图市场监管协调指导小组（以下简称全国协调指导小组）在全国开展了地图市场大检查工作，各地各单位高度重视、科学部署、全面推进，查处了一大批涉及地图的违法违规行为，工作取得明显成效，有力地规范了地图市场秩序。为巩固2016年全国地图市场大检查工作成果，防止地图市场违法违规行为出现反弹，进一步做好对有关薄弱环节的监管工作，全国协调指导小组决定2017年在全国开展地图市场大检查“回头看”行动。工作方案如下：

一、工作目标

通过开展地图市场大检查“回头看”行动，对2016年地图市场大检查工作中存在问题的重点区域和环节进行全面清查，依法查处各类地图违法违规行为，进一步规范地图市场秩序，促进地图市场繁荣健康发展，切实维护国家领土主权、安全和利益。

二、工作内容

（一）对2016年地图市场大检查中发现的违法违规行为，跟踪检查整改情况，落实有关查处措施。

（二）各地根据本地实际，针对2016年地图市场大检查中涉及“问题地图”较多的场所、地图类型以及有关薄弱环节，开展全面清查工作，重点针对以下地图产品中涉及的违法违规行为进行检查：

1．互联网网站（含微博、微信公众号等移动互联网APP）中登载的各类地图产品，包括静态地图、互联网地图服务；

2．电子商务平台展示和交易的各类地图产品；

3．教辅材料、展览（展会）中涉及的地图以及媒体登载使用的地图。

（三）开展对导航电子地图制作单位和互联网地图服务单位地理信息安全保密隐患的排查。组织对地图数据采集、地图生产制作和提供服务等环节中存在的安全隐患进行全面排查，对存在的问题和违法违规行为进行整改和查处，进一步维护地理信息安全。

三、工作步骤

（一）动员部署阶段（3月）

1．制定方案。全国协调指导小组制定地图市场大检查“回头看”行动工作方案，提出工作要求，明确职责分工，落实工作责任。

2．宣传发动。全国协调指导小组印发文件进行部署，各地协调指导机构结合本地实际制定实施方案，对外公布举报电话、电子信箱、微博、微信公众号等，积极宣传发动社会力量发现和举报地图市场中存在的涉及地图违法违规行为，鼓励各地对有效举报给予一定奖励。

（二）组织实施阶段（4月至10月）

全国协调指导小组对部分省、自治区、直辖市地图市场大检查“回头看”行动情况进行检查指导，协调组织有关单位和专家对涉及“问题地图”较多的场所和地图类型进行调查，对部分导航电子地图制作单位、全国性互联网地图服务单位在数据采集、地图生产制作和提供服务等环节的安全保密管理及使用保密处理技术和保密插件情况进行检查，对存在的违法违规行为及时予以查处。

各地协调指导机构指导市、县开展本区域内地图市场大检查“回头看”。根据监管职责分工，按照属地化管理原则，对照检查工作内容，对本地区地图市场有针对性的开展检查，依法查处有关违法违规行为。配合全国协调指导小组对导航电子地图制作单位、全国性互联网地图服务单位进行实地检查。

（三）总结巩固阶段（11月）

1．工作情况上报。各省级协调指导机构梳理本地区有关地图违法违规行为，总结工作开展情况，于11月20日前将工作总结报告（含《地图市场大检查“回头看”行动情况统计表》，见附件1）及典型案例（见附件2）报全国协调指导小组办公室（设在国家测绘地理信息局地理信息与地图司，请各地协调指导机构同时将报送材料的电子稿发送至ditu@sbsm.gov.cn）。

2．工作总结。全国协调指导小组审议全国地图市场大检查“回头看”行动工作开展情况，对检查工作进行总结。

四、工作要求

（一）严格执法。各地协调指导机构要严格执法，加大对涉及地图的各类违法违规行为的查处力度，发现一起查处一起，对“问题地图”等形成持续高压态势。对列入各级测绘地理信息行政主管部门随机抽查事项清单检查的项目，要严格按照“双随机”执法检查有关要求开展工作。

（二）加强协作。各省协调指导机构要进一步健全完善协作机制，成员单位间要协同配合，开展多部门联合检查与执法。各地测绘地信和网信部门要积极贯彻落实《关于规范互联网服务单位使用地图的通知》（国测图发〔2016〕2号），建立互联网地图监管应急处置机制，健全和落实定期统计和汇报制度。

（三）疏堵结合。积极开展各种形式的国家版图意识宣传教育活动，不断丰富各类公益性地图产品。要充分发挥舆论的宣传引导作用，对依法查处的典型违法案件予以曝光，深刻剖析，通过开展警示宣传教育，营造公民自觉维护国家主权、安全和利益的社会环境。
