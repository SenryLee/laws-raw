# 海关总署公告2017年第57号——关于调整部分消费品进口关税的公告

## 海关总署公告

2017年第57号

## 关于调整部分消费品进口关税的公告

根据《国务院关税税则委员会关于调整部分消费品进口关税的通知》（税委会〔2017〕25号），自2017年12月1日起，以暂定税率方式降低部分消费品进口关税。具体税目及税率调整情况详见财政部网站。

特此公告。

海关总署

2017年11月27日
