# 国家食品药品监督管理总局办公厅关于同意广东省食品药品检验所增加生物制品批签发证明文件授权签发人的通知

## 总局办公厅关于同意广东省食品药品检验所增加生物制品批签发证明文件授权签发人的通知

食药监办药化管函〔2017〕241号

广东省食品药品检验所：

你局《关于增加生物制品批签发证明文件授权签字人的请示》（粤药检业〔2017〕58号）收悉。经研究，同意增加方继辉同志为生物制品批签发证明文件签发人，承担生物制品批签发证明文件的签发工作。

食品药品监管总局办公厅

2017年4月17日
