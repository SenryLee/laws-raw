# 科技部基础研究司关于国家重点实验室等科技创新基地在2017年科技活动周期间开展公众开放活动的通知

国科基函〔2017〕7号

各有关国家重点实验室，试点国家实验室，国家工程技术研究中心：

近日，科技部、中央宣传部、中国科协发出通知，决定于5月20日至27日继续举办2017年全国科技活动周。今年全国科技活动周主题为“科技强国 创新圆梦”，旨在贯彻落实习近平总书记在全国科技创新大会上关于“科技创新、科学普及是实现创新发展的两翼，要把科学普及放在与科技创新同等重要位置”的重要指示，动员号召全国科技工作者和社会各界，积极投身建设世界科技强国的伟大实践；充分调动全社会科技资源服务于脱贫攻坚战，以科技创新驱动精准扶贫精准脱贫，让人民群众共享科技改革发展成果，提高获得感和幸福感，推动全面建成小康社会，实现中华民族伟大复兴的中国梦。根据通知要求，请各国家重点实验室、试点国家实验室、国家工程技术研究中心结合自身特色，主动开展各种形式的公众开放活动和科普工作。活动结束后，请将有关活动情况、取得的效果等及时总结，并通过年报系统进行上报。

特此通知。

科技部基础研究司

2017年4月5日
