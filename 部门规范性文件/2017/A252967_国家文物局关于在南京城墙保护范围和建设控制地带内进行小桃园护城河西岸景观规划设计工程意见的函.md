# 国家文物局关于在南京城墙保护范围和建设控制地带内进行小桃园护城河西岸景观规划设计工程意见的函

## 关于在南京城墙保护范围和建设控制地带内进行小桃园护城河西岸景观规划设计工程意见的函

办保函〔2017〕797号

江苏省文物局：

你局《关于审批小桃园护城河西岸二期景观规划设计方案的请示》（苏文物保〔2017〕118号）、《关于审批小桃园护城河西岸三期景观规划设计方案的请示》（苏文物保〔2017〕119号）收悉。经研究，我局意见如下：

一、所报项目位于南京城墙保护范围和建设控制地带内，方案设计思路不当，对文物景观及历史环境影响较大，我局暂不同意小桃园护城河西岸二、三期景观项目。

二、对所报方案提出以下修改意见：

（一）应严格遵守《中华人民共和国文物保护法》、《南京市历史文化名城保护规划》、《南京城墙保护规划》、《南京城墙保护条例》的相关管理规定，重新调整设计思路，加强南京城墙历史研究和价值发掘，结合文物历史环境要素确定项目内容，尽量减少建设项目对文物及周边环境的影响。同时注意避免过度人工化和现代景观园林化设计倾向。

（二）应充分考虑地形特征，建议拟建服务设施另行选址建设，如确需建设，应降低建筑高度，减小建筑规模；进一步说明护城河中增加岛屿、小桥的必要性；同时，减小场地内硬质广场面积；对在建幼儿园、周边居住小区等进行必要的绿化遮挡，确保与南京城墙景观风貌和历史氛围相协调。

（三）结合市政工程做好场地排水，避免影响城墙安全。

（四）统筹考虑护城河两岸景观设计风格，做到相互呼应。

（五）不同意工程范围内进行微地形改造工程。

三、请你局根据所提意见，对项目方案进行修改完善后，按程序另行报批。

专此函。

国家文物局

2017年6月27日
