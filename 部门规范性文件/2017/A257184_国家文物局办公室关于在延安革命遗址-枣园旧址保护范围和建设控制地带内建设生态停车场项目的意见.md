# 国家文物局办公室关于在延安革命遗址-枣园旧址保护范围和建设控制地带内建设生态停车场项目的意见

办保函〔2017〕1211号

陕西省文物局：

你局《关于在延安革命遗址-枣园旧址保护范围和建设控制地带内建设生态停车场的请示》（陕文物字〔2017〕192号）收悉。经研究，我局意见如下：

一、暂不同意所报项目。

二、对方案提出以下修改意见：

（一）补充说明项目建设的必要性，明确项目选址和建设规模是否符合延安革命遗址保护规划相关要求。

（二）停车场建设距离旧址过近，破坏了旧址原有历史环境风貌。停车场建设应远离旧址的保护范围。

（三）适当缩小管理用房建筑体量，避免对旧址环境风貌造成影响。

（四）根据《文物保护单位游客承载量评估规范》合理测算参观旧址的游客数量，并据此确定停车场的建设规模。

请你局组织相关单位根据上述意见对方案进行修改完善后，按程序另行报批。

专此函复。

国家文物局办公室

2017年10月30日
