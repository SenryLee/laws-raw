# 水利部关于印发世行贷款安徽省淮河流域重点平原洼地治理工程水土保持设施验收鉴定书的函

水保函〔2017〕145号

安徽省淮河重点平原洼地治理外资项目管理办公室：

根据《开发建设项目水土保持设施验收管理办法》的规定，水利部于2017年6月9日在安徽省合肥市组织召开了世行贷款安徽省淮河流域重点平原洼地治理工程水土保持设施验收会议。会议认为，该工程水土保持设施基本达到了水土保持法律法规及技术规范、标准的要求，工程质量总体合格，运行期管理责任落实，同意通过验收。现印发世行贷款安徽省淮河流域重点平原洼地治理工程水土保持设施验收鉴定书。

附件：生产建设项目水土保持设施验收鉴定书（编号2017－15）

水利部

2017年7月4日
