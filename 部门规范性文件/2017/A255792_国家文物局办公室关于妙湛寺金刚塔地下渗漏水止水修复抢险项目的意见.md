# 国家文物局办公室关于妙湛寺金刚塔地下渗漏水止水修复抢险项目的意见

办保函〔2017〕985号

云南省文物局：

你局《关于请求批准妙湛寺金刚塔地下渗漏水止水修复抢险工程勘察报告与设计方案的请示》（云文物〔2017〕108号）收悉。经研究，我局意见如下：

一、所报方案技术路线不合理，维修措施有待深化，我局暂不同意妙湛寺金刚塔地下渗漏水止水修复抢险项目。

二、对该方案提出以下修改意见：

（一）应深化现状勘察和研究，核实地下通道混凝土结构存在的局部缺陷的具体部位，补充已实施工程情况和效果评估内容。

（二）建议进行方案比选研究，论证将塔基以下空间和塔体周围通道回填并使其稳定、牢固的可能性。

三、请你局组织相关单位根据所提意见，对项目方案进行修改完善后，按我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的相关要求另行报批。

专此函复。

国家文物局办公室

2017年8月22日
