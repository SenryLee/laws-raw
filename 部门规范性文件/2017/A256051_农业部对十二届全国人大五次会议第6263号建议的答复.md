# 农业部对十二届全国人大五次会议第6263号建议的答复

## 对十二届全国人大五次会议第6263号建议的答复

农办议〔2017〕346号

徐清代表：

您提出的关于加强监督农村集体资产资源交易的建议收悉。经认真研究，现答复如下。

引导农村产权流转交易市场健康发展，推动农村产权流转交易公开、公正、公平，并规范运行，有利于保障农村集体经济组织和农民的财产权益，有利于提高农村资源要素合理配置和利用效率，有利于农村社会和谐稳定。党中央、国务院高度重视加强监督农村集体资产资源交易，在近年的农业农村工作文件中均有明确要求，2014年，国务院办公厅出台《关于引导农村产权流转交易市场健康发展的意见》（以下简称《意见》），对农村产权交易的运行和监管进行全面规范。

一、关于氛围监督

为切实增强村干部的法律意识和农民群众对集体资产资源的权利意识，农业部深入开展了村干部业务培训、新型职业农民培训等一系列专题培训。今年，为贯彻落实《中共中央国务院关于稳步推进农村集体产权制度改革的意见》，利用全国农业远程教育平台开展了专题培训，向全国1000多个卫星站点进行直播，广大农民群众在互联网平台就可以观看培训课程，及时了解中央有关农村集体产权制度改革的精神，推动逐步构建归属清晰、权能完整、流转顺畅、保护严格的中国特色社会主义农村集体产权制度。同时，将中央和地方已出台的农村产权流转交易市场建设文件、实施意见、交易管理办法等汇编成册，形成《农村产权流转交易市场建设文件汇编》，免费发放给各地，供基层干部和群众学习参考。民政部也广泛开展对新当选村干部的培训，帮助他们学习相关法律法规和实用技术。

下一步，农业部将会同有关部门继续加大对村干部和农民群众的培训，加强法律法规和政策宣传，营造各级干部群众共同监督农村集体资产资源交易的良好氛围。

二、关于把关监督

切实把好农村产权交易主体准入和农村集体资产入场交易的关口，是确保农村集体产权交易规范有序的关键。《意见》明确规定，现阶段农村产权交易市场流转交易的主体主要是农户、农民合作社、农村集体经济组织、涉农企业和其他投资者，要依法对各类市场主体的资格进行审查核实、登记备案。强调农户拥有的产权是否入场交易由农户自主决定，任何组织和个人不得强迫或妨碍自主交易；达到一定标的额以上的农村集体产权流转，必须进入市场公开交易，防止暗箱操作。明确提出，要建立健全规范的市场管理制度和交易规则，实行统一规范的业务受理、信息发布、交易签约、交易中（终）止、交易（合同）鉴证、档案管理等制度，交易过程应公开公正。实践中，各地出台了一系列引导农村产权流转交易市场健康发展的文件，对交易的市场主体资格、资产资源范围、交易程序和行为规范等作出明确规定，切实加强对集体资产资源交易的全程把关，取得了一定成效。广东省佛山市农村产权交易平台运行以来，因农村集体资产财务管理问题引发的信访案件下降了90%以上。

下一步，农业部将继续指导各地加快推进农村产权流转交易市场建设，加强对交易过程的把关监督，让集体资产资源交易在阳光下运行。

三、关于联动监督

全面落实村级民主理财和完善村级财务公开，是实现农村集体产权交易联动监督的重要保障。农业部积极推动相关工作深入开展，出台《关于加强村集体经济组织民主理财民主监督的意见》，要求村民主理财小组要按照事前参与、事中监督、事后检查的要求，全过程参与集体资产资源交易,实现联动监督；出台《农村集体经济组织财务公开规定》，要求对集体经济组织的财务收支、资产资源、收益分配等事项进行全面公开，对资产资源发包、租赁、出让、投资及收益，工程招投标及预决算等事项进行逐项逐笔公开。2016年，推动出台《中共中央国务院关于稳步推进农村集体产权制度改革的意见》，明确提出要落实民主理财，规范财务公开，切实维护集体成员的监督管理权。目前，全国95%的村建立了村民理财小组，超过98%的村集体实行了财务公开，其中比较规范的村超过70%，有力地促进了农村经济发展与社会和谐稳定。

下一步，农业部将进一步指导各地落实民主理财，规范财务公开，切实加强农民群众对集体资产资源交易的联动监督。

四、关于标后监督和追责监督

农村集体资产资源交易的标后监督和追责监督需要政府部门主动作为，发挥好监督管理作用。中央明确要求县级以上地方政府要加强农村产权流转交易服务和监督管理。对于设立农村产权流转交易市场的地方，要成立由相关部门组成的农村产权流转交易监督管理委员会，负责对市场运行进行指导和监管，防止和纠正发生在群众身边的腐败行为。要加强农村集体经济审计监督，对于侵占集体资金和资产的，要如数退赔，涉及违规违纪的移交纪检监察机关处理，构成犯罪的移交司法机关依法追究当事人的刑事责任。近年来，农业部不断加大对包括农村集体资产资源交易在内的农村审计力度，2016年全国共审计约41.2万个单位，涉及金额约1.48万亿元；审计出违纪单位6828个，违纪金额约5.8亿元，大大减少了集体资产资源交易引发的农村信访案件。

下一步，农业部将加强与相关部门的协同配合，进一步加大农村审计力度，推动各地扎实做好农村集体资产资源交易的标后监督和追责监督。

感谢您对加强监督农村集体资产资源交易问题的关心，希望今后继续对我部工作予以支持。
