# 国家文物局关于广州圣心大教堂建设控制地带内广州市第三中学2号教学楼加装电梯的意见

文物保函〔2017〕1900号

广东省文物局：

你局《关于在全国重点文物保护单位广州圣心大教堂建设控制地带内广州市第三中学2号教学楼加装电梯工程设计方案的请示》（粤文物审〔2017〕137号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、请你局根据《中华人民共和国文物保护法》第十八条规定，将该方案报城乡建设规划部门批准实施。工程施工期间,你局应加强监管，确保文物安全。

国家文物局

2017年11月24日
