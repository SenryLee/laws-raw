# 国家发展改革委办公厅关于同意延长重庆市双福建设开发有限公司公司债券核准文件有效期的函

发改办财金〔2017〕1630号

重庆市发展改革委：

你委报来《关于重庆市双福建设开发有限公司2016年企业债券有关事项的请示》（渝发改资〔2017〕1074号）收悉。经研究，现函复如下。

一、同意将《国家发展改革委关于重庆市双福建设开发有限公司发行企业债券核准的批复》（发改企业债券〔2016〕297号）文件有效期延长12个月至2018年10月12日。

二、请你委督促重庆市双福建设开发有限公司按照《公司法》《证券法》《企业债券管理条例》和规范性文件要求，在发行前认真核对是否符合法律法规和规范性文件规定的发行条件，在发行首日前10个工作日向我委报备。

三、请你委督促重庆市双福建设开发有限公司按要求及时做好信息披露及债券资金管理，按照核准的募投资金投向合规使用债券资金，认真落实偿债措施，确保本息按期兑付，保护投资者合法权益。

国家发展改革委办公厅

2017年9月28日
