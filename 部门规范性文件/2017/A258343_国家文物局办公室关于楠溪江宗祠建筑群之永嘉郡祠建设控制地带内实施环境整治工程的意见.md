# 国家文物局办公室关于楠溪江宗祠建筑群之永嘉郡祠建设控制地带内实施环境整治工程的意见

办保函〔2017〕1312号

浙江省文物局：

你局《关于要求在全国重点文物保护单位楠溪江宗祠建筑群之永嘉郡祠建设控制地带内实施环境整治工程的请示》（浙文物发〔2017〕348号）收悉。经研究，我局意见如下：

一、所报方案缺项较多，深度不够，暂不同意所报方案。

二、具体修改意见如下：

（一）补充浙江省人民政府公布的保护范围和建设控制地带相关管理规定、文物保护规划中的相关图纸和对应的建设控制地带的管理要求，及与村镇规划等相关规划关于该区域的要求及本方案与其相衔接、协调的内容。

（二）补充、深化现状分析并提高针对性，进一步论证和说明实施环境整治工程的必要性。应结合永嘉郡祠原有历史格局特征保护需要制定设计方案，设计目标应以维护文物建筑的景观环境，提升院落整体空间保护为主，避免过多建设项目对文物及历史环境造成空间干扰。如宗祠南侧的新建建筑依据不足，且传达了错误的历史信息，对文物历史环境的真实性有较大影响。不宜使用大量城市园林手法，应减少硬质铺装的范围和面积，并尽量体现乡土特色。

（三）补充、完善文本和图纸，如，补充必要的总平面工程实施范围图和节点详图，深化总平面图中的平面和竖向关系，补充标注必要的标高和庭院及场地铺装的材料和损伤状态，补充排水方案设计等。

三、请你局指导相关单位根据上述意见对所报方案进行修改完善后按程序另行报批，并督促其依法严格控制楠溪江宗祠建筑群之永嘉郡祠建设控制地带内的建设活动，切实保护文物本体及其周边环境的安全。

国家文物局办公室

2017年11月30日
