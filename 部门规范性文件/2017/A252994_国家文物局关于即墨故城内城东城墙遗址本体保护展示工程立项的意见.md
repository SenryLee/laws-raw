# 国家文物局关于即墨故城内城东城墙遗址本体保护展示工程立项的意见

## 关于即墨故城内城东城墙遗址本体保护展示工程立项的意见

办保函〔2017〕446号

山东省文物局：

你局《关于即墨故城遗址—即墨故城内城东城墙本体保护与展示工程立项的请示》（鲁文发〔2017〕15号）收悉。经研究，我局意见如下：

一、暂不同意即墨故城内城东城墙遗址本体保护展示工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）加强前期工作，补充考古勘探相关图纸资料和研究资料，深化对城墙遗址价值的研究。

（二）进一步梳理项目内容，明确工程对象和实施范围，研提有针对性的保护措施。

（三）应按照保护规划的相关要求，明确遗址展示的定位和目标，统筹安排遗址的保护展示工作。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年4月14日
