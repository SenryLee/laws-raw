# 农业部印发关于贯彻落实《土壤污染防治行动计划》的实施意见

农科教发〔2017〕3号

各省、自治区、直辖市及计划单列市农业（农牧、农村经济）、畜牧、兽医厅（局、委、办），新疆生产建设兵团农业局：

为深入贯彻落实《土壤污染防治行动计划》，切实加强农用地土壤污染防治，逐步改善土壤环境质量，保障农产品质量安全，特制定本实施意见。

农业部

2017年3月6日
