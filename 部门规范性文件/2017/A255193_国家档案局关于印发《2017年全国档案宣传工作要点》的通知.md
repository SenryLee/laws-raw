# 国家档案局关于印发《2017年全国档案宣传工作要点》的通知

档发〔2017〕1号

各省、自治区、直辖市档案局，各计划单列市档案局，新疆生产建设兵团档案局，中央和国家机关各部委档案部门，中央军委办公厅保密和档案局，各人民团体档案部门，各中央企业档案部门，中国人民大学档案学院：

现将《2017年全国档案宣传工作要点》印发给你们，请结合实际认真贯彻执行。

国家档案局

2017年3月2日

## 2017年全国档案宣传工作要点

2017年是全面实施“十三五”规划、全面建成小康社会的重要一年，我们党将召开第十九次全国代表大会。全国档案宣传工作要全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，坚持以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，增强政治意识、大局意识、核心意识、看齐意识，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，围绕迎接、宣传、贯彻党的十九大，坚持稳中求进工作总基调，大力宣传档案部门学习贯彻党的理论和路线方针政策的实际成效，大力宣传档案工作服务党和国家中心工作的创新做法，大力宣传档案事业改革发展的生动实践，唱响主旋律、弘扬正能量，为党的十九大胜利召开营造良好氛围，为档案事业科学发展提供舆论保证。

一、围绕党的十九大扎实开展主题宣传

坚持把学习宣传贯彻习近平总书记系列重要讲话精神作为一项重大政治任务，准确把握系列讲话的丰富内涵和精神实质，深入阐释蕴含其中的重大思想观点，充分展示各级档案部门贯彻落实的实践成果，引导广大档案工作者自觉把思想和行动统一到系列讲话精神上来，坚决同以习近平同志为核心的党中央保持高度一致。深入开展党中央治国理政新理念新思想新战略重大主题宣传，广泛宣传党的十八大以来理论创新、实践创新、制度创新的重大成果，推动党的各项决策部署在档案部门深入人心、落地生根。深入开展“砥砺奋进的五年”主题宣传教育，注重运用我国各行业各领域特别是档案工作领域改革发展的鲜活事例，大力宣传“五位一体”总体布局和“四个全面”战略布局的重大进展，充分展示党的十八大以来党和国家走过的不平凡历程，展示我们党治国理政的卓越能力和非凡成就。持续深化中国特色社会主义和中国梦宣传教育，引导广大档案工作者坚定理想信念、增强“四个自信”。党的十九大开幕后，全力做好大会的新闻宣传工作，及时传递中央声音，准确解读中央精神，推动各级档案部门把党的十九大精神传达好、学习好、贯彻好。

二、利用档案巩固和发展主流意识形态

深入贯彻落实习近平总书记“让历史说话、用史实发言”的重要指示，坚持以社会主义核心价值观为引领，深入挖掘档案信息资源的时代价值，广泛宣传档案编研和开发利用成果，充分发挥档案在巩固和发展主流意识形态中的独特作用。做好庆祝中国人民解放军建军90周年、内蒙古自治区成立70周年、香港回归20周年等重大活动的宣传，通过公布档案史料、出版档案图册、举办档案展览等方式，集中呈现历史性发展变化，充分激发人们爱党爱国爱军的情怀。以举行纪念全民族抗战爆发80周年仪式、南京大屠杀死难者国家公祭仪式等为契机，深化爱国主义教育，做好《拉贝日记》《南京大屠杀档案》以及《抗日战争档案汇编》等重点档案图书的出版和宣传工作，用档案铭记抗战历史、弘扬抗战精神。利用档案坚决反击历史虚无主义，对歪曲、否定党史国史军史以及诋毁、诬蔑党和国家领导人的各种言论，要主动发声、坚决斗争，彻底揭穿历史虚无主义者编造的种种谎言，还原历史真相、捍卫社会正义、壮大主流声音。加强与大中小学的合作，依托档案馆深入开展中国近现代史特别是党史国史军史宣传教育。加强与党员干部教育培训机构的合作，利用档案办好党性教育主题教室。配合国家“一带一路”战略，扩大档案对外合作交流，借助档案讲好中国故事，传播好中国声音。继续办好“中国档案珍品展”“红星照耀中国——外国记者眼中的中国共产党人”“信仰的力量——中国共产党人的家国情怀”等档案展览，大力弘扬中华优秀传统文化、革命文化和社会主义先进文化。

三、营造档案事业改革发展的良好氛围

深刻把握档案工作面临的新形势新任务，广泛宣传党和政府加强、改进档案工作的新要求新举措，充分展现档案事业健康发展的良好局面，引导各级档案部门明确前进方向、增强发展信心。深入开展档案政策法规的宣传阐释，以纪念《档案法》颁布30周年为契机进一步深化档案“七五”法治宣传教育，继续做好中共中央办公厅、国务院办公厅《关于加强和改进新形势下档案工作的意见》以及《全国档案事业发展“十三五”规划纲要》的宣传解读，扎实做好新出台政策文件、工作举措以及全国档案局长馆长会议等重要会议精神的宣传解读。大力宣传各地区各部门推进档案事业发展的创新实践，着重宣传档案工作围绕中心、服务大局的典型事例，档案工作在服务“五位一体”总体布局和“四个全面”战略布局中的重要作用，以及各级档案部门加快档案资源体系、档案利用体系、档案安全体系建设的积极探索。大力宣传各级档案部门加强党的建设的经验做法，推动全面从严治党要求、“两学一做”学习教育常态化制度化在档案部门的深入贯彻。大力宣传档案工作中涌现出的先进集体和优秀个人，用榜样的力量激励广大档案工作者积极进取、扎实作为。加强档案政务信息公开和新闻发布工作，加大权威信息发布力度，及时应对舆情热点，有效回应社会关切。

四、开展“国际档案日”系列宣传活动

以“档案——我们共同的记忆”为主题，组织各级档案部门集中开展2017年“国际档案日”系列宣传活动，通过举办主题征文、出版宣传挂图、开展主题讲座等方式，吸引更多人关注档案、走近档案，帮助社会公众认识档案价值、增强档案意识，推动各级档案部门更加重视档案的接收整理、安全保护和开发利用，使档案更好地服务党和国家中心工作、服务经济社会发展、服务广大人民群众。加强对活动的创新谋划，做到档案特色鲜明、形式丰富多样、群众参与广泛，进一步提升活动的吸引力和感召力；加强对活动的宣传报道，实现新老媒体结合，线上线下互动、社交媒体联动，进一步扩大活动的关注度和美誉度，把“国际档案日”系列宣传活动打造成档案宣传工作的最佳品牌。

五、加强档案报刊、网站等宣传阵地管理

各级档案部门要自觉服从和服务党的十九大这个大局，充分认识做好档案宣传工作的重要意义，认真落实意识形态工作责任制，对所属报刊、网站以及微博、微信公众号、移动客户端等宣传阵地全面加强管理，强化内容审核把关，强化舆情研判应对，强化人员教育管理，确保档案宣传工作不出现任何问题。档案报刊、网站等宣传阵地要深入贯彻党的宣传思想工作方针政策，始终坚持正确的政治方向和舆论导向，始终坚持依法依规办报办刊办网，坚决杜绝导向错误、虚假宣传、非法谋利等违纪违法行为。档案报刊、网站等宣传阵地的工作人员要自觉践行马克思主义新闻观、文艺观，恪守职业道德，严守工作纪律，以良好的职业精神做好档案宣传工作。档案报刊、网站等宣传阵地的各级党组织要全面落实管党治党责任，严肃党内政治生活，强化监督执纪问责，为做好档案宣传工作提供有力保证。
