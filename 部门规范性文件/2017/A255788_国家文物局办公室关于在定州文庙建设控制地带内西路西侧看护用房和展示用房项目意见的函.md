# 国家文物局办公室关于在定州文庙建设控制地带内西路西侧看护用房和展示用房项目意见的函

办保函〔2017〕925号

河北省文物局：

你局《关于呈报定州文庙西路西侧看护用房和展示用房设计方案的请示》（冀文物字〔2017〕148号）收悉。经研究，我局意见如下：

一、所报项目位于定州文庙建设控制地带内，拟建建筑密度过大，对寺庙历史格局影响较大，设计依据不足，设计思路不正确，我局暂不同意定州文庙西路西侧看护用房和展示用房项目。

二、对该方案提出以下修改完善意见：

（一）应从定州文庙整体保护、展示和管理的需要出发，进一步论证建设看护用房和展示用房的必要性，重新调整设计思路，进一步研究定州文庙历史格局。补充定州文庙保护区划相关管理规定和相关考古勘察资料。

（二）应调整方案设计，进一步论证拟建内容及项目选址的合理性。应尽量利用现有建筑承担看护展示需求。不同意紧靠文物本体新加建一路建筑，避免对定州文庙原有格局和院落空间造成误解。

（三）按照我局文物保函〔2014〕1673号文件要求，尽快完成定州文庙保护规划编制工作。

三、请你局组织相关单位根据上述意见，对项目方案进行修改完善后，按程序另行报批。

国家文物局办公室

2017年8月8日
