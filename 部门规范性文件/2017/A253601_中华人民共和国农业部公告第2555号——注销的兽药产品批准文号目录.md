# 中华人民共和国农业部公告第2555号——注销的兽药产品批准文号目录

## 中华人民共和国农业部公告

第2555号

近期，广西壮族自治区水产畜牧兽医局依法吊销了广西正通瑞和生物制药有限公司的兽药生产许可证，河南省畜牧局、山东省畜牧兽医局、广西壮族自治区水产畜牧兽医局、宁夏回族自治区农牧厅等4个省级兽医行政管理部门依法注销了郑州汉邦生物技术有限公司、博爱县凯森植化有限责任公司、河南惠丰制药有限公司、硕腾(烟台)动物保健品有限公司、烟台神龙蚕用药业科技开发有限公司、广西三晶兽药有限公司、宁夏泰瑞制药股份有限公司贺兰分公司等7家企业的兽药生产许可证，依据《中华人民共和国行政许可法》第七十条和《兽药产品批准文号管理办法》第二十七条规定，现注销上述8家企业取得的154个兽药产品批准文号（附件1），自其兽药生产许可证吊销或注销之日起执行。

根据瑞普（保定）生物药业有限公司申请，同意注销其取得的鸡新城疫、传染性支气管炎、禽流感（H9亚型）三联灭活疫苗（LaSota株+M41株+HP株）和鸡新城疫、传染性支气管炎、减蛋综合征三联灭活疫苗（LaSota株+M41株+Z16株）兽药产品批准文号（附件2），自本公告发布之日起执行。

特此公告。

附件：1.注销的兽药产品批准文号目录（因企业兽药生产许可证被吊销或注销）

2.注销的兽药产品批准文号目录（依兽药生产企业申请）

农业部

2017年8月2日
