# 交通运输部办公厅关于进一步改进提升12328电话运行服务质量有关工作的通知

交办运函〔2017〕184号

各省、自治区、直辖市、新疆生产建设兵团及计划单列市交通运输厅（局、委）:

为贯彻落实《12328交通运输服务监督电话管理办法》等制度要求及有关工作安排，按照“先开通响应、再联网运行、后综合应用”的总体部署，在去年基本实现12328交通运输服务监督电话（以下简称12328电话）全国联网运行的基础上，2017年各级交通运输主管部门要坚持问题和目标导向，以提升服务质量，加强监测分析为重点，进一步提升12328电话系统运行管理和综合服务能力，努力打造全领域覆盖、全天候运行的交通运输服务监督“一号通”。现将有关工作通知如下：

一、进一步提高系统联网运行质量

目前，12328电话已基本实现全国联网运行，但部分地区仍存在联网运行不稳定，系统功能不完善等问题，特别是个别省份省级平台与地市之间尚未实现联网运行全覆盖，业务自动报送不及时、工单内容不完整、呼叫等待时长记录不准确、有通话记录无工单、有工单无通话记录等问题比较突出，距离“12328电话业务工单自动报送、自动统计，电话业务在部、省、市间自动流转和跨区域、跨部门业务协同”目标还有一定差距。各省级交通运输主管部门要进一步加强组织领导，加大支持力度，强化督导检查，全面打通省与市之间的联通网络，确保2017年6月底前实现12328电话部、省、市三级联网运行全覆盖和系统稳定高效运行，确保12328电话服务无盲区、无死角，联网运行不断网、不掉线。要加快推进12328电话与交通运输领域其他热线电话的资源整合与号码转并工作，2017年底前，各地要基本实现除12306、12305、12395等行业热线电话外，交通运输领域其他热线电话，特别是以“96”开头的路网服务类电话向12328电话的号码转并与整合，实现交通运输服务监督“一号通”。12328电话与12345等政务热线已进行资源整合的地区，要协调有关部门畅通信息数据交换接口，规范工单办理流程，确保12328电话畅通，信息数据实时交换共享，业务办理和信息统计分析等工作顺利开展。

二、进一步加强数据分析和报送工作

做好12328电话信息数据统计分析工作，确保信息数据内容真实、报送规范、统计准确，是提升12328电话综合服务能力的基础支撑。目前，各地在12328电话信息数据报送过程中，还不同程度存在指标分类不准确、数据填写不完整、统计口径不一致、报送格式不规范、数据挖掘不充分等问题。各地要针对上述问题，进一步加强信息数据报送工作，统一数据统计口径，规范信息填报格式，严格信息报送时限，全面提高信息数据报送质量。鉴于目前部分省份12328电话系统联网运行工作还在进一步深化，请各省级交通运输主管部门继续以人工填报方式报送2017年信息数据，同时加强人工报送与系统自动报送的工作衔接，并对两个报送渠道的数据进行一致性校验。各省份要于2017年9月底前完成人工报送向系统自动报送的转换。各地要重点加强对投诉举报类业务工单办理情况的跟踪督导，认真研究梳理投诉举报类电话业务工单办理情况，编制形成《12328电话投诉举报类业务办理情况报告》（内容应包括基本情况、业务构成、结构变化及原因、处理情况、个案剖析、意见建议等），与季度信息数据报表一并报部。河北、宁夏、陕西、西藏、新疆等采用省级集中受理模式的省份，要以地市为单位对受理的信息数据进行细分后再行报送。开通自动语音服务的省份，应通过技术手段将自动语音播报内容转化为电话工单后，按照工单报送格式通过系统报送。

三、进一步强化成果转化应用

各地要围绕实现12328电话信息数据分析常态化，组织12328电话服务中心和相关业务部门，利用大数据技术手段，对12328电话信息数据进行深入挖掘分析，共同研究梳理交通运输行业管理、服务保障、安全监管等方面存在的规律性、普遍性问题，认真查找苗头性、倾向性问题及原因，提出改进建议，为有关部门和单位优化行业管理、提升服务质量、维护行业稳定、加强春运等重点时段运输组织保障等工作提供参考借鉴。要加强12328电话服务中心与交通运输各业务部门和单位间的信息共享与业务联动，进一步健全呼叫受理、业务转办、跟踪回访、统计分析、监督考核等工作制度，形成工作闭环。各省级交通运输主管部门要及时总结梳理有关部门和企业利用12328电话系统、加强行业管理、改进运输服务的典型案例，连同季度信息数据报表一并报部，以更好地服务领导决策。

四、进一步加强考核评估工作

2017年起，部将重点围绕12328电话运行管理、联网质量、业务办理、数据报送、成果应用等工作，建立健全12328电话工作动态监测评估制度，全面加强对各地12328工作的绩效评估，并将评估结果作为评选“全国12328电话十佳服务中心”和“全国12328电话百佳话务人员”的重要依据。各省级交通运输主管部门也要加快建立健全本省份的12328电话工作运行服务质量考评制度，通过系统监测、现场督查、暗访检查、随机抽查等方式，对各地市和有关单位12328电话工作情况进行定期考评和通报。对于工作推进有力、运行服务质量突出的单位和个人，要通过适当形式予以通报表扬；对于电话系统建设和联网运行工作进展缓慢、服务效果差、群众满意度不高的单位，要视情予以通报批评。各地市交通运输主管部门要结合实际制定详细的考评细则，加强对12328服务中心和承办单位电话业务受理、办理情况的考核管理，提升12328电话管理工作效率、业务办理质量和群众满意度。

五、进一步丰富系统服务功能

2016年，部基本完成了12328电话全国基础知识库系统框架设计和部分知识数据的初装入库。下一步，部将根据需要继续开展知识数据拆解入库等工作，不断优化系统功能。各地要按照部发布的《12328交通运输服务监督电话系统第6部分：知识库数据元》等标准，加快建设完善地方知识库，并适时做好知识库更新维护、话务人员培训等工作，加快实现知识库系统联网运行以及地方知识库与部级知识库的业务对接。为进一步拓展服务渠道，部将在2017年适时开通12328网站、微信公众号、APP移动客户端等服务渠道，进一步方便群众使用。各地要结合实际，积极实施本地化二次开发或自主建设，逐步开通本地区的12328网站、微信公众号、APP移动客户端等服务渠道，进一步优化系统功能，实现12328系统的多渠道业务融合。

六、加大宣传推广力度

各地要围绕提高12328电话系统的认知度和影响力，通过在媒体播放公益广告短片，在运输服务场所张贴宣传海报，以及发放宣传手册、报道典型案例等形式，加大对12328电话服务功能、服务范围、受理流程等的宣传推广力度，加快塑造形象统一、特征鲜明、识别度高的12328服务品牌。要按照《交通运输部办公厅关于启用12328交通运输服务监督电话标识的通知》（交办运〔2014〕197号）要求，利用运输装备、广告牌等载体，加强对12328电话标识的规范使用和宣传推广，让人民群众更好地认识12328、了解12328，使12328电话真正成为人民群众想用、会用、爱用的交通运输服务监督热线。
