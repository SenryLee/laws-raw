# 国家文物局办公室关于襄城城墙保护规划意见的函

办保函〔2017〕1431号

河南省文物局：

你局《关于审批襄城城墙文物保护规划的请示》（豫文物〔2017〕140号）收悉。经研究，我局意见如下：

一、所报规划文物本体认定不清，保护区划不合理，文本深度不够，我局暂不同意所报襄城城墙保护规划。

二、所报规划应做以下必要修改和完善：

（一）深化前期调查和历史研究，进一步梳理文物本体和保护对象，应开展必要的考古调查确认地表不存城墙段落的地下遗存情况，并注意城墙与山形水系的关系，复建的北城门不应纳入文物本体。

（二）完善现状评估，进一步明确局部缺失墙体对城墙本体安全的影响程度，客观评估植被对城墙的影响。细化环境评估，明确紧邻城墙的建筑年代、高度、风貌等内容，深入分析城市活动对城墙的影响。补充复建北城门及现存城墙墙体后期加固修复工程效果评估内容。

（三）根据文物保护管理需要和城市建设情况合理调整保护区划，增强可操作性，省级文物保护单位清真寺不应纳入建设控制地带。进一步说明将城墙遗址可能分布区域划为一般保护区的理由。补充保护区划的边界划定依据，完善保护区划管理规定，涉及环境整治和专项规划的内容应纳入相关章节。

（四）根据现状评估结论和不同病害类型，进一步细化保护措施，明确保护工程的类型、对象、范围等，增强针对性。明确西南城墙防洪设施建设维护的相关要求，并补充相关防护措施。

（五）根据保护区划管理规定合理调整环境整治措施。合理调整用地性质，补充调整依据。结合城墙承载能力和展示需求科学制定展示规划，明确展示主题、内容和方式。北门外停车场应结合古城停车统筹考虑，合理选址，控制规模。

（六）进一步加强本规划与相关规划的衔接，分析城市总体规划对城墙保护管理的影响，加强城墙保护与城市发展的协调性。梳理规划文本，规范、完善图纸表达。

三、请你局指导相关单位，按照上述意见对规划进行认真修改、完善，按相关程序另行报批。

国家文物局办公室

2017年12月27日
