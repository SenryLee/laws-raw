# 国家文物局关于国民党“一大”旧址保护范围内图书馆二期改扩建工程方案的意见

## 关于国民党“一大”旧址保护范围内图书馆二期改扩建工程方案的意见

办保函〔2017〕342号

广东省文物局：

你局《关于全国重点文物保护单位国民党“一大”旧址保护范围内建设工程方案的请示》（粤文物审[2016]173号）收悉。经研究，我局意见如下：

一、图书馆二期改扩建项目应充分考虑文物保护相关要求。建设项目应符合国民党“一大”旧址保护范围管理规定的相关要求，改扩建项目尽量避免对文物建筑及其历史环境造成影响。

二、深化现状勘察，补充博物馆旧馆现状高度和相关测绘图；明确改建后的建筑高度和体量变化情况。

三、进一步明确改扩建项目内容。可在保持原广东省博物馆旧馆现有规模前提下，进行适当的装饰改造，改造风格应以文物建筑特征为依据。不得在保护范围内扩大建设规模。

请你局根据上述意见组织相关单位对方案进行修改完善后，按程序另行报批。

专此。

国家文物局

2017年3月28日
