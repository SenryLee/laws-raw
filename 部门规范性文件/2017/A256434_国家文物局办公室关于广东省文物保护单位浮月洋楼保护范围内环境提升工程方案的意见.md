# 国家文物局办公室关于广东省文物保护单位浮月洋楼保护范围内环境提升工程方案的意见

办保函〔2017〕1119号

广东省文物局：

你局《关于广东省文物保护单位浮月洋楼保护范围内环境提升工程方案的请示》（粤文物审〔2017〕119号）收悉。经研究，我局意见如下：

一、进一步明确环境提升的项目定位，正确处理文物保护与旅游开发的关系，应在有利于文物保护的基础上严格控制开发强度和新建项目数量。

二、补充文物保护和利用的现状情况分析，补充现场勘察内容，包括现状照片、最新地形测绘图等资料，真实反映浮月村的地形、地貌现状，说明15栋文物建筑与村落原有景观环境的关系。

三、环境提升应循序渐进，不轻易改变文物的原有环境风貌，如传统的田埂、古村小路小巷、稻田簇拥洋楼的生态环境等。停车场应移出保护范围外，兴建6个广场、改造提升游步道必要性不足，对文物环境风貌干扰较大。“五彩稻田”的做法，改变了环境的真实性，破坏了村落原有的田园风光和景观效果，不宜实施。

四、国旗楼北侧新建建筑（商铺）距国旗楼较近，严重影响文物建筑的历史环境风貌，不得实施。

五、进一步修改完善方案文本和图纸，使文字、图示更加简明扼要。

请你局指导相关单位根据上述意见对方案进行修改完善后，按程序另行报批。

国家文物局办公室

2017年9月26日
