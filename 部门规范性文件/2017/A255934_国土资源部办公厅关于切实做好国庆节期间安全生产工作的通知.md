# 国土资源部办公厅关于切实做好国庆节期间安全生产工作的通知

国土资电发〔2017〕34号

各省、自治区、直辖市国土资源主管部门，中国地质调查局及部其他直属单位，各派驻地方的国家土地督察局：

2017年国庆节、中秋节将至,党的第十九次全国代表大会即将召开。为切实做好节日期间安全生产有关工作，严防事故发生，让人民群众过一个安全欢乐祥和的节日，为党的十九大胜利召开营造稳定的安全生产环境，按照《国务院安委会办公室关于切实做好2017年国庆节期间安全生产工作的通知》（安委办明电〔2017〕13号）的部署，现就有关要求通知如下。

一、进一步增强政治自觉和责任意识，狠抓安全防范责任措施落实

今年国庆节、中秋节叠加，假期时间长，群众出行和公众活动增多，人流、物流、车流集中，安全生产压力增大。节后随即召开党的十九大，这是党和国家政治生活中的大事，做好节日期间安全生产工作，有着特殊重要的意义。要切实增强政治自觉和责任自觉，加强对节日期间安全生产工作的组织领导，紧密结合正在开展的安全生产大检查，周密安排部署。要进一步增强安全风险意识，针对节日期间安全生产规律特点，从严从实从细抓好各项安全防范措施落实。各级领导干部要带头深入基层督促检查，推动各项工作责任措施落实到位。节日期间因责任不落实、措施不得力、监管不到位甚至失职渎职而发生生产安全事故的，要依法严肃追责问责。

二、深入开展安全生产大检查，全面排查整治安全隐患

地方各级国土资源主管部门要按照国务院安委会部署，结合职责分工，积极配合有关部门深化矿山、危险化学品、油气输送管道等重点行业领域安全生产大检查，及时发现、整改消除隐患，有效防范各类事故发生。要积极参与联合执法、联合督查等行动，严厉打击非法违法、违规违章行为，积极配合有关部门监督企业落实停产停工整改措施。要加大已取缔关闭矿山、矿点巡查监控力度，严防国庆节日期间违法违规生产。

中国地质调查局及部其他直属单位要针对国庆节日期间特点，认真梳理本部门、本单位安全生产重点环节，以危险化学品、消防、交通、勘查作业施工等为重点，继续深入开展安全生产大检查。对发现的隐患和问题，要坚决按照整改责任、措施、资金、时限、预案“五落实”要求，限期整改到位。特别要严格落实开放场所、人员密集场所、高层建筑和用气、用电安全安全管理，加强安全检查和隐患排查，严防火灾和拥挤踩踏等事故。要切实加强野外作业单位安全保护和防范，确保野外作业生产、交通安全。

三、加强应急管理，提高事故防范应对能力

要进一步加强安全生产应急管理工作，健全完善生产安全事故应急预案，加强节日期间值班值守，严格执行24小时专人值班和关键岗位领导到岗带班制度，遇有突发事件或重要紧急情况及时采取有效措施妥善应对和科学处置。

地方各级国土资源主管部门要进一步健全完善部门间应急协调联动机制，加强灾害性天气、地质灾害预报预警，通过互联网、广播电视和短信、微信微博、电子显示屏等多种方式及时发布预警等信息。

中国地质调查局及部其他直属单位要进一步完善各项应急预案，做好救援队伍、物资、装备等应急准备工作。要强化安全生产宣传教育，加大交通、旅游、消防等安全知识和初起险情应急处置、逃生自救等常识的宣传力度，提高事故防范应对能力。节日期间坚持正常生产作业的单位要加强现场安全管理，强化安全风险管控和隐患排查治理,严格执行企业负责人带班作业制度，严防违规作业、违章指挥、违反劳动纪律造成事故发生。

各省（区、市）国土资源主管部门、中国地质调查局及部其他直属单位要紧密结合自身实际进一步安排部署，认真抓好贯彻落实。各派驻地方的国家土地督察局也要明确安全生产工作责任和要求，认真排查治理安全隐患，切实做好国庆节日期间安全生产工作。

国土资源部办公厅

2017年9月30日
