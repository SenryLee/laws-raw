# 国家文物局关于金上京南城南墙西门瓮城遗址保护展示工程立项的意见

## 关于金上京南城南墙西门瓮城遗址保护展示工程立项的意见

办保函〔2017〕388号

黑龙江省文物管理局：

你局《关于全国重点文物保护单位金上京会宁府遗址南城南墙西门瓮城保护展示利用工程立项的请示》（黑文管字〔2017〕9号）收悉。经研究，我局意见如下：

一、暂不同意金上京南城南墙西门瓮城遗址保护展示工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）暂不同意对已回填的南瓮城遗址局部揭露并建设覆罩大棚进行展示，建议采用模拟展示或标识展示的方式。

（二）进一步明确金上京会宁府遗址的总体展示思路，并在此框架下统筹考虑重要节点的展示问题，做好必要的展示前景分析，合理确定展示方式。同时，建议整体考虑金上京会宁府遗址标识系统建设及参观线路布设等事宜。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局

2017年4月10日
