# 住房城乡建设部标准定额司关于同意铁路给水排水设计规范等8项工程建设行业标准备案的函

建标实函[2017]38号

国家铁路局科技与法制司：

《国家铁路局科技与法制司关于<铁路工程设计防火规范>和<铁路给水排水设计规范>行业标准备案的函》（科法便函[2016]259号）收悉。经研究，同意《铁路给水排水设计规范》等8项行业标准作为“中华人民共和国工程建设行业标准”备案（见附件）。

中华人民共和国住房和城乡建设部标准定额司

2017年2月3日
