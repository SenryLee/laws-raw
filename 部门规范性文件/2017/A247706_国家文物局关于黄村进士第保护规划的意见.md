# 国家文物局关于黄村进士第保护规划的意见

## 关于黄村进士第保护规划的意见

办保函〔2017〕112号

安徽省文物局：

你局《关于批准黄村进士第保护规划的请示》（皖文物保〔2016〕101号）收悉。经研究，我局意见如下：

一、所报规划现状勘察不足，保护区划和管理规定缺乏可操作性，文本深度不够，我局暂不同意黄村进士第保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

1．应进一步明确规划重点，以黄村进士第为主，系统梳理其与黄村的历史和空间关系，科学确定文物构成、保护对象、附属文物和历史环境要素等。

2．调整现状评估体例，凝练评估内容，做到准确、客观、简洁。真实性和完整性评估内容缺乏针对性，建议纳入文物本体现状评估章节；环境评估应以黄村进士第周边区域为主，不宜扩大至整个黄村范围；展示利用评估应明确现状展示方式、年游客量、游客承载量等内容；补充历次保护工程实施效果、保护区划执行情况等评估内容。

（二）关于保护区划与管理规定

1．应根据文物建筑整体格局和日常保护管理需要，充分考虑黄村建设发展和保护范围内居民生活问题，进一步论证扩大保护范围和建设控制地带的必要性和依据；同时，结合地形地貌和历史环境分析，进一步调整保护范围与建设控制地带的具体边界。

2．应细化建设控制地带分类，明确各类建设控制地带的具体建筑高度、体量、密度等控制指标，增强可操作性。

（三）关于保护措施

应根据黄村进士第已实施保护工程情况，进一步调整、简化文物保护措施，严格控制工程内容、范围和强度，避免过度维修。文物建筑结构稳定性监测、环境监测针对性不足，建议删除。

（四）关于环境整治和专项规划

1．应进一步调整环境规划思路，明确黄村进士第的环境要素和保护重点，核减环境整治、历史环境保护与修复、空间景观风貌保护、生态环境保护的内容和实施范围，做到最小干预。

2．深化展示利用规划，科学确定黄村进士第的使用功能和展示利用方式，注意延续文物原有功能，强化文物与黄村居民生活的联系。相关管理、展示和服务配套设施应结合黄村基础设施建设统筹考虑。

3．土地利用规划中调整文物古迹用地的必要性不足，建议保持村落土地利用现状；进一步简化基础设施规划内容，文物周边区域的道路交通、环卫设施建议纳入黄村村镇发展规划。

（五）补充与上位规划及相关规划的衔接，处理好文物保护与村落发展的关系。

（六）进一步规范、完善文本和规划图纸。文本内容应简洁、严谨、具有逻辑性，涉及休宁县、商山镇历史沿革等无关内容应删除；遗存构成、价值评估等部分表述应凝练；补充图号，规范图例。

三、请你局指导有关单位，根据上述意见对黄村进士第保护规划进行全面、认真的修改完善，按程序另行报批。

专此函。

国家文物局

2017年2月13日
