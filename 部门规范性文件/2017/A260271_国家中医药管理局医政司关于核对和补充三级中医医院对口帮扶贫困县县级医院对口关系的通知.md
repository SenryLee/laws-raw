# 国家中医药管理局医政司关于核对和补充三级中医医院对口帮扶贫困县县级医院对口关系的通知

## 关于核对和补充三级中医医院对口帮扶贫困县县级医院对口关系的通知

各省、自治区、直辖市中医药管理局医政处：

2016年我局与国家卫生计生委、国务院扶贫办、中央军委政治工作部、中央军委后勤保障部联合印发了《加强三级医院对口帮扶贫困县县级医院工作方案》（国卫医发〔2016〕7号），明确了三级医院对口帮扶贫困县县级医院关系。2017年我局又与国家卫生计生委、国务院扶贫办联合印发《关于调整部分地方三级医院帮扶贫困县县级医院对口关系的通知》（国卫办医函〔2017〕421号），根据对口帮扶医院合作意愿，对2016年公布的部分地区对口帮扶关系予以调整。

为准确掌握各地医院对口帮扶工作进展，我司将上述对口关系中的中医医院部分摘编，形成了三级中医医院对口帮扶贫困县县级医院对口关系表（见附件1），请你处予以核对。如有新增，请确定支援医院为三级医院、受援县为贫困县（指集中连片特殊困难地区县和国家扶贫开发工作重点县），且支受双方已签订帮扶协议，可填写新增三级中医医院对口帮扶贫困县县级医院对口关系表（见附件2）。以上材料，请省级中医药管理部门汇总后，于2017年6月30日前以纸质盖章件和电子版报送我司基层服务管理处。
