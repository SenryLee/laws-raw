# 农业部关于政协十二届全国委员会第五次会议第2890号（农业水利类271号）提案答复的函

## 关于政协十二届全国委员会第五次会议第2890号（农业水利类271号）提案答复的函

农办案〔2017〕96号

郭为委员：

您提出的关于推进农村产权流转交易市场建设的提案收悉。经商人民银行、财政部，现答复如下。

党中央、国务院高度重视农村产权流转交易市场建设。党的十八届三中全会明确提出，建立农村产权流转交易市场，推动农村产权流转交易公开、公正、规范运行。2014年12月，《国务院办公厅关于引导农村产权流转交易市场健康发展的意见》（国办发〔2014〕71号）公开发布。为贯彻落实中央精神，农业部等有关部门开展了一系列工作，推动农村产权流转交易市场建设与发展。

一、关于推进以县域为主的农村产权流转交易市场建设

现阶段农村产权流转交易市场建设以县域为主是中央的明确要求。2016年，农业部会同有关部门推动出台《中共中央国务院关于稳步推进农村集体产权制度改革的意见》，明确提出“鼓励地方特别是县乡依托集体资产监督管理、土地经营权流转管理等平台，建立符合农村实际需要的产权流转交易市场”。据农业部组织开展的全国农村产权流转交易市场建设情况摸底调查显示，全国约有三分之一左右的县建立了农村产权流转交易市场，且大多依托土地流转中心或“三资”管理中心。各地农村产权流转交易市场建设积极推进，覆盖面不断扩大，部分地方设立了覆盖地（市）乃至省（区、市）地域范围的市场，承担更大范围的信息整合发布和大额流转交易。北京、上海、天津、河北、山东、江苏、重庆7个省份建立了省级交易市场平台，有的已是政企合作建立的农村产权流转交易市场。

下一步，农业部将认真贯彻落实中央要求，会同有关部门深入开展调查研究，总结地方实践经验，扎实推进农村产权流转交易市场建设。

二、关于加快推进农村土地承包经营权确权登记颁证

自2009年以来，农业部积极推动农村土地承包经营权确权登记颁证试点工作，试点范围不断扩大，成效显著，截至2017年3月底，全国2628个县、3.2万个乡镇、52.5万个村开展了土地承包经营权确权登记颁证工作，已完成确权面积9.4亿亩。2014年起，中央财政设立“农村土地承包经营权确权登记颁证经费补助”专项转移支付，根据国土资源部国土二调公布的各省农村集体耕地面积，按照每亩一次性补助10元的标准对各省实行定额补助,补助期限为5年，即2014年至2018年，与全国农村土地承包经营权确权登记颁证的总体部署相适应。截至目前，中央财政已经按照国务院批准的方案将2014年、2015年和2016年的补助资金共计约120亿元拨付各省、自治区、直辖市和计划单列市。

下一步，农业部将按照中央要求，会同有关部门加快推进农村土地承包经营权确权登记颁证相关工作，推进土地承包经营权有序流转交易，实现好、维护好广大农民群众的土地承包权益。

三、关于完善抵押融资等衍生服务

根据《国务院关于开展农村承包土地的经营权和农民住房财产权抵押贷款试点的指导意见》精神，2016年，人民银行会同财政部等有关部门联合印发了《农村承包土地的经营权抵押贷款试点暂行办法》和《农民住房财产权抵押贷款试点暂行办法》，要求各试点地区稳妥有序开展“两权”抵押贷款业务，有效盘活农村集体资金、资产、资源，促进农民增收致富和农业现代化发展。

为丰富农村产权交易市场功能，人民银行积极推动金融机构与农村产权交易市场平台对接融合，特别是在“两权”抵押贷款试点工作中，积极会同有关部门指导试点地区加快农村产权交易市场建设，适应交易主体、目的和方式多样化的需求，建立“两权”抵押、流转、评估的专业化服务机制，不断拓展服务功能，逐步发展成集信息发布、产权交易、法律咨询、资产评估、抵押融资等为一体的为农服务综合平台。部分地区还通过交易平台为农民从事农业生产、经营、管理提供信息发布、政策咨询和流转指导等服务。

下一步，人民银行、财政部将与有关部门密切配合，支持加快农村产权交易市场建设，完善金融服务功能和手段，积极推动产权交易平台与金融机构之间的数据开放共享，进一步提高农村要素配置和利用效率。

四、关于推动农业农村数据资源共享开放

2015年国务院印发了《促进大数据发展行动纲要》，明确提出发展农业农村大数据，推进“金农”等信息系统跨部门、跨区域共享，推动农业等领域政府数据集向社会开放。今年中央又印发了《国家电子政务总体方案》，明确要求各部门建设一个统一的“基础设施体系、标准规范体系和安全保障体系”和统一的“综合业务信息系统、政务信息数据库、数据共享交换平台和门户”。按照中央部署，农业部加快推进政务信息资源建设的顶层设计，制订了《“十三五”农业部电子政务发展规划》，大力推动信息系统对接和信息资源整合共享工作，按照“整合已建、规范在建、规划待建”的工作路线，推进业务整合和数据融合。同时，对国家农业数据中心进行云化升级改造，最大限度整合农业部各单位、各省农业系统及涉农部门相关数据，已初步建成一个一体化、高可用、高扩展、高性能的国家农业数据云平台，网络体系和基础设施进一步完善。

下一步，农业部将持续推进政务信息资源整合共享和大数据发展应用工作，强化涉农信息平台建设，加快提升农村信息服务能力。

感谢您对“三农”工作的关心，希望今后继续支持我们的工作。

农业部

2017年9月1日
