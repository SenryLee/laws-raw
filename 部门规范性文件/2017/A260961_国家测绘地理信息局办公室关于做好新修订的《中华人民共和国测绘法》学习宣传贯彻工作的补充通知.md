# 国家测绘地理信息局办公室关于做好新修订的《中华人民共和国测绘法》学习宣传贯彻工作的补充通知

## 关于做好新修订的《中华人民共和国测绘法》学习宣传贯彻工作的补充通知

测办发〔2017〕26号

各省、自治区、直辖市测绘地理信息主管部门：

为认真贯彻落实中央领导同志近期关于全覆盖排查整治“问题地图”的重要批示精神，强化国家版图意识教育，营造全社会对国家版图高度重视与积极参与的浓厚氛围，大力开展排查整治“问题地图”专项行动，维护地图市场秩序，国家测绘地理信息局决定将进一步强化国家版图意识作为学习宣传贯彻新《测绘法》工作的一项重要内容。现将有关事项补充通知如下：

一、加强相关法律法规宣贯解读

（一）宣传有关法律法规。“8·29”全国测绘法宣传日活动期间，各级测绘地理信息主管部门应当在官方网站显著位置全文登载新《测绘法》《地图管理条例》等测绘地理信息法律法规；在官方网站、微博、微信等宣传平台开通“8·29”全国测绘法宣传日专栏，刊登本地区开展国家版图意识宣传教育、“问题地图”排查整治工作动态等内容。

（二）推广普及标准地图。各级测绘地理信息主管部门应当在官方网站显著位置提供各类标准地图的浏览、下载等公共服务。“8·29”全国测绘法宣传日活动期间，各级测绘地理信息主管部门要针对“问题地图”的错误所在，刊登正确地图及错误地图示例，引导公众正确使用地图。

二、强化国家版图意识宣传教育

（三）开展学法用法活动。各级测绘地理信息主管部门应当对本辖区测绘资质单位，尤其是导航电子地图制作、地图编制、互联网地图服务资质单位，通过组织集中学习、举办讲座、组织考试、竞赛答题等形式，开展1－2次学法用法活动，提高相关从业人员的依法测绘意识和国家版图意识。

（四）开展系列宣传活动。各级测绘地理信息主管部门应当加强与地方政府有关部门的协作，“8·29”全国测绘法宣传日活动期间，充分发挥电子显示屏、服务窗口触摸屏、公交移动电视屏、手机屏等新媒介作用，通过设点宣传、电视播报、发送短信、报纸传媒、网络宣传等方式，深入普及正确使用地图的有关知识，广泛开展国家版图意识宣传教育。

三、普法执法并举，净化地图市场

（五）依法查处“问题地图”。各级测绘地理信息主管部门要按照全覆盖排查整治“问题地图”专项行动工作方案要求，扎实开展宣传发动、自查整改、巡查整治、汇报总结、回头看等各阶段工作，不搞形式，不走过场。对发现的“问题地图”，要依法严肃查处。

（六）加强正反两方面宣传。各级测绘地理信息主管部门要牢牢把握正面宣传为主的原则，结合“问题地图”排查整治专项行动，进行现场地图法律法规普及教育，及时曝光“问题地图”案件，深刻剖析违法成因和危害，开展“以案说法”，加强警示教育，发挥查办案件对违法从业者的震慑作用。

四、有关要求

（七）增强责任担当。强化国家版图意识、依法查处“问题地图”，是一项严肃的政治任务。各级测绘地理信息主管部门要着力强化政治意识、大局意识、核心意识、看齐意识，把这项工作作为今年一项重中之重的工作，按照国家测绘地理信息局的统一部署，全面依法履责，抓紧抓好抓实。

（八）迅速部署落实。各级测绘地理信息主管部门要迅速将本通知精神向本单位和所辖市县级测绘地理信息主管部门和测绘资质单位传达，统一思想认识，层层压实责任。要组织开展系列有声势、有深度、有影响的测绘法宣传活动,提高吸引力和感染力，确保宣传活动取得实效。

（九）及时报送信息。各级测绘地理信息主管部门要及时发现、认真总结本地区强化国家版图意识、依法查处“问题地图”的好经验、好做法，对全局工作有启发指导、借鉴意义的措施要加以提炼整理，并上报国家测绘地理信息局。
