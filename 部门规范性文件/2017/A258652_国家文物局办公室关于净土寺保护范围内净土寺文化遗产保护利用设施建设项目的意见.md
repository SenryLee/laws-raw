# 国家文物局办公室关于净土寺保护范围内净土寺文化遗产保护利用设施建设项目的意见

办保函〔2017〕1350号

山西省文物局：

你局《关于审批应县净土寺文化遗产保护利用设施建设项目设计方案的请示》（晋文物〔2017〕231号）收悉。经研究，我局意见如下：

一、所报方案包含不同类型的项目，设计依据和深度不足，暂不同意所报方案。

二、具体修改意见如下：

（一）相关建设项目应统筹考虑净土寺和应县木塔的保护要求，补充净土寺保护规划中关于保护范围和建设控制地带内的规划图纸，包括本体保护、环境整治、展示利用和管理规划等。

（二）应加强对净土寺历史格局的考证研究，准确认定文物构成，如大殿内的天空楼阁藻井是大殿建筑的一部分，不是净土寺的附属文物。

（三）涉及文物本体的安防、消防设施安装，属于专项设计，应另行委托具有相应资质的机构编制方案。涉及净土寺大殿、遗址的保护项目，应另行编制保护方案。

（四）净土寺历史范围内的整治项目，特别是拟建展厅、管理用房、厕所等建设项目，应提供历史依据。

（五）根据考古资料推测的净土寺围墙范围，相对于大殿和中轴线偏东，与中国古代寺院一般格局有别，建议进行进一步的历史文献和考古研究，核实准确。应确认中路院落两侧是否还有偏院。

（六）净土寺的旅游配套设施建设应与应县木塔和应县历史文化街区的整治、旅游统筹考虑，避免不必要的开发建设。停车场、展示管理用房建设应注意控制建设力度，朴实简洁，避免喧宾夺主。

（七）建议根据文物保护管理要求，调整、分解方案。分别编制文物保护、消防、安防方案，并在保护方案和考古成果的基础上，编制环境整治方案。

三、请你局责成相关单位，认真执行《文物保护法》、《文物保护法实施条例》等法律文件中的相关规定，严格控制净土寺保护范围和建设控制地带内的建设活动，切实保护文物本体及其周边环境的安全。
