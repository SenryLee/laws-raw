# 环境保护部办公厅关于解除山东省龙口市尾矿库环境问题联合挂牌督办的通知

## 关于解除山东省龙口市尾矿库环境问题联合挂牌督办的通知

环办应急函[2017]495号

烟台市人民政府：

按照《关于对龙口市尾矿库环境问题挂牌督办的通知》（环办应急〔2016〕77号）要求，你市人民政府督促龙口市人民政府按照督办要求积极整改尾矿库环境问题，并向我部提交了解除挂牌督办申请。经我部联合山东省人民政府现场核查，目前龙口市尾矿库环境问题整改基本达到督办要求。

经商山东省人民政府，现决定解除对龙口市尾矿库环境问题挂牌督办。请你市人民政府督促龙口市人民政府认真落实环境保护责任，继续强化尾矿库环境监督管理和整治力度，做好风险防范和应急准备工作，促进环境质量持续改善。

环境保护部办公厅

2017年4月1日
