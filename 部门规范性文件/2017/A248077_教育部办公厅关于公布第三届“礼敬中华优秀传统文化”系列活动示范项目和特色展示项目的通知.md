# 教育部办公厅关于公布第三届“礼敬中华优秀传统文化”系列活动示范项目和特色展示项目的通知

教思政厅函[2017]2号

各省、自治区、直辖市党委教育工作部门、教育厅（教委），新疆生产建设兵团教育局，部属各高等学校党委：

为深入贯彻落实中央关于培育和践行社会主义核心价值观的意见要求和习近平总书记关于弘扬中华优秀传统文化系列重要讲话精神，按照《中共教育部党组关于教育系统深入开展爱国主义教育的实施意见》（教党〔2016〕4号）部署，教育部与光明日报社以“爱国情·强国志·报国行”为主题，组织开展了第三届“礼敬中华优秀传统文化”系列活动。各地各高校围绕主题，突出地域特色、学校特色、学科优势，结合“两学一做”学习教育、纪念建党95周年主题和校园文化建设实践，立足立德树人根本任务，不断增强师生四个自信，打造了一批富有时代气息、体现文化内涵、具有价值导向的品牌活动，产生了良好社会反响。

根据活动工作方案，经高校自主申报、专家推荐、网上公示，共确定第三届“礼敬中华优秀传统文化”示范项目10项、特色展示项目30项，现予以公布。希望各地各高校认真学习借鉴，创新活动载体形式，进一步推动“礼敬中华优秀传统文化”系列活动深入开展。

附件：

1．第三届“礼敬中华优秀传统文化”系列活动示范项目名单

2．第三届“礼敬中华优秀传统文化”系列活动特色展示项目名单

教育部办公厅

2017年2月9日
