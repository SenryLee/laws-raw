# 国家发展改革委、民航局关于印发《推进京津冀民航协同发展实施意见》的通知

## 国家发展改革委　民航局关于印发《推进京津冀民航协同发展实施意见》的通知

发改基础〔2017〕2048号

公安部、国土资源部、住房城乡建设部、交通运输部、海关总署、税务总局、质检总局、铁路局，军委联合参谋部、空军参谋部，空管委办公室，铁路总公司，北京市、天津市、河北省发展改革委，民航华北地区管理局：

为贯彻落实国务院领导同志重要批示精神，深入推进京津冀民航协同发展，经商京津冀协同发展领导小组办公室，现将《推进京津冀民航协同发展实施意见》印发你们，请认真贯彻执行。在执行过程中，各单位要深入学习贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，认真落实《京津冀协同发展规划纲要》重要决策部署，加快推进京津冀民航协同发展，着力打造京津冀世界级航空机场群。

附件：推进京津冀民航协同发展实施意见

国家发展改革委

民航局
