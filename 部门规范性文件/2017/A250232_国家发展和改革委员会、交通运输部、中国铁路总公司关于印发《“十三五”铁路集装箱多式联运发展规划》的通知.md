# 国家发展和改革委员会、交通运输部、中国铁路总公司关于印发《“十三五”铁路集装箱多式联运发展规划》的通知

## 关于印发《“十三五”铁路集装箱多式联运发展规划》的通知

发改基础〔2017〕738号

各省、自治区、直辖市及计划单列市、新疆生产建设兵团发展改革委、交通运输厅、铁路局：

为贯彻落实“十三五”规划《纲要》、《“十三五”现代综合交通运输体系发展规划》、《中长期铁路网规划》、《营造良好市场环境推动交通物流融合发展实施方案》以及铁路发展改革等要求，加快铁路集装箱发展，促进集装箱多式联运，推动物流业降本增效，现将《“十三五”铁路集装箱多式联运发展规划》印发你们，请结合实际认真贯彻落实。

附件：“十三五”铁路集装箱多式联运发展规划

国家发展改革委

交通运输部

中国铁路总公司

2017年4月19日
