# 国土资源部办公厅关于转发《国家科技重大专项（民口）管理规定》的函

国土资厅函〔2017〕994号

中国地质调查局及部其他直属单位：

为进一步明确科技重大专项的组织管理和工作流程，推动科技重大专项的组织实施，根据《国务院办公厅关于印发国家科技重大专项组织实施工作规则的通知》（国办发〔2016〕105号）和国家科技计划管理改革的有关要求，科技部、发展改革委、财政部印发了《国家科技重大专项（民口）管理规定》（国科发专〔2017〕145号）（以下简称《管理办法》），现转发给你们，请遵照执行。请各单位按《管理办法》要求，切实做好国家科技重大专项（民口）项目（课题）组织实施、资金管理、知识产权、信息档案及国际合作等方面工作，保障项目顺利执行。

2017年6月27日

附件：科技部+发展改革委+财政部关于印发《国家科技重大专项（民口）管理规定》的通知
