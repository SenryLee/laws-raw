# 农业部对十二届全国人大五次会议第6109号建议的答复

## 对十二届全国人大五次会议第6109号建议的答复

农办议〔2017〕95号

包景岭等16名代表：

你们提出的“关于落实绿色发展理念，推进‘绿色扶贫’的建议”收悉。经研究，现将涉及我部职能的内容答复如下。

贫困地区大多自然资源丰富，具有发展优质特色农产品的潜力，但受经济基础、物质装备条件、生产经营模式等因素影响，绿色资源优势尚未有效转化为产品优势，成为制约农村贫困人口增收脱贫的瓶颈。近年来，我部坚持“两山”理论，大力推进农业供给侧结构性改革，以增加绿色优质农产品有效供给，满足市场多层次、高质量、个性化的消费需求为主要任务，加快推进产业扶贫，增强贫困地区内生动力，助力贫困地区脱贫攻坚。

一、关于保障绿色供给

近年来，我部围绕保障绿色农产品安全有效供给，不断加强产能建设，牢固树立绿色发展理念，夯实农民增收基础。一是加大绿色高产高效创建支持力度。2017年安排中央财政资金15亿元，开展绿色高产高效创建，以高产高效、节本增效、提质增效、环境友好为目标，指导贫困地区开展协作攻关，集中力量攻克技术瓶颈，集成组装区域性、标准化高产高效技术模式，引领农业生产方式转变，带动提升贫困种植业综合生产能力。二是深入实施化肥农药使用量零增长行动。以用肥量大的玉米、蔬菜、果树为重点，突出贫困地区，依托新型经营主体，示范推广秸秆养分还田、畜禽粪便资源化利用。2017年安排中央财政资金10亿元，选择100个县（市）开展有机肥替代化肥示范，增施有机肥，促进种养循环，实现化肥减量。结合耕地保护与质量提升项目开展测土配方，通过调优施肥结构，开展精准施肥，加快贫困地区推广新型高效缓释肥料和机械施肥、种肥同播等技术，示范带动肥料减量。在贫困地区推进统防统治与绿色防控融合。2017年安排中央财政资金8亿元，开展农作物重大病虫害统防统治，依托新型农业经营主体、病虫防治服务组织，集成示范病虫综合治理、农药减量控害技术模式。开展新农药、新助剂、新药械试验示范，组建自走式植保机械、航空植保、天敌昆虫、生物农药、高效低风险农药等科技创新联盟，加快技术创新和推广应用。三是开展区域生态循环农业示范。2016年，安排区域生态循环农业项目资金3.4亿元，支持各地开展畜禽养殖废弃物资源化利用、农副资源综合开发、标准化清洁化生产，促进农牧结合、种养结合、生态循环，提高农业资源利用效率，推进区域内农业废弃物“零排放和全消纳”。

下一步，农业部将紧紧围绕推进农业供给侧结构性改革这个工作主线，以绿色发展为导向，以结构调整为重点，以农民增收为目标，指导贫困地区找准市场定位，培育差异化比较优势，增加优质特色品牌农产品供给，避免同质竞争，切实推动贫困地区产业健康、稳定、可持续发展。

二、关于推动绿色消费

我部高度重视绿色优质农产品品牌建设和农产品质量安全监管，帮助贫困县打造区域公用品牌，着力推进品牌农业发展，完善标准体系建设，狠抓农产品标准化生产，强化全程质量监控，确保餐桌上的安全。一是大力推广贫困地区区域农产品公用品牌。从去年12月至今年6月，我部共举办8期产业扶贫现场观摩，推广洛川苹果、赣南脐橙、定西马铃薯、广西百色芒果、贵州黔西南薏仁、河北平泉食用菌、湖北罗田黑山羊、安徽岳西茭白、河南信阳毛尖、山西平顺中药材、宁夏盐池滩羊、重庆石柱红辣椒等20余个区域公用品牌。同时，在新华社、人民日报、中央人民广播电台、中央电视台等中央主要媒体重要版面、重要时段集中推出产业扶贫范例系列报道，宣传区域品牌。支持举办中国国际农产品交易会、洛川苹果节、彭州蔬菜节、定西马铃薯节、贵阳国际特色农产品交易会等农业展会，帮助贫困地区农产品扩大市场影响，培育产品品牌，增强特色农产品市场竞争力。二是扎实开展绿色、有机产品认定创建。截至2017年4月，我部共认定绿色食品、有机农产品2231个，公告颁证农产品地理标志2117件。共创建果菜茶标准园近6000个，畜禽养殖标准化示范场4179家，水产健康养殖示范场6218家，全国水产健康养殖示范面积达到51%。三是积极推进农产品质量安全监管体系建设。截至目前，全国所有省（区、市）、88%的地市、75%的县（区、市）、97%的乡镇建立了农产品质量安全监管机构，落实监管人员11.7万人。71.1%的地市、56.6%的县和21.9%的乡镇已安排专项监管经费，农产品质量安全监管能力明显提升。为保障农产品安全供给提供了重要保障。四是扎实开展农产品质量安全县创建。2014年，农业部启动实施国家农产品质量安全县创建活动，重点加强投入品监管、标准化生产、打击违法违规行为、监管体系建设、制度机制创新等8个方面。截至目前，共有318个县（市）参与“国家农产品质量安全县（市）”创建工作。目前各试点单位正在有力有序开展创建工作。

下一步，我部将继续加大贫困地区特色农产品品牌宣传推介，支持贫困地区参加各类农产品展销会。巩固特色农产品品牌创建成果，进一步加强农产品质量安全监管体系建设，确保创建品牌成为真正叫得响、受消费者欢迎的金字招牌。

三、关于搭建绿色供应链

提高农产品冷链物流能力，拓宽优质绿色农产品销路，是打通田间到餐桌的重要途径。近年来，我部主要从以下两个方面开展工作。一是大力发展农产品产地初加工。2012年起，我部实施农产品产地初加工补助项目，截至目前，累计安排中央资金36亿元，实施区域由最初的12个省（区、市）扩大到20个省（区、市），实施区域重点面向贫困地区。据不完全统计，共扶持632个县、8300多个合作社、近5万农户新建马铃薯贮藏窖、果蔬贮藏库和烘干房等初加工设施10万余座，新增马铃薯贮藏能力170万吨、果蔬贮藏能力240万吨、果蔬烘干能力240万吨。通过实施农产品初加工设施补助政策，有效改善了集中连片贫困地区农产品产地初加工设施条件，大幅减少产后损失。据测算，水果、蔬菜产后损失率由项目实施前的25%下降到5%左右，蔬菜销售价格提高了30%-50%。同时，初加工设施建设有效延长了水果、蔬菜等贮存期，实现错季销售，有效避免了农产品价格大起大落，为增加有效供给、带动农民增收发挥了重要作用。二是推动产销衔接。2015年，我部印发《农业部办公厅关于组织开展农业电子商务“平台对接”专项行动的通知》，充分发挥农业部门牵线搭桥的作用，促进农产品、农业生产资料生产者与电子商务企业对接，引导农产品、农业生产资料上线销售。组织阿里巴巴、京东、苏宁等大型电商企业开展苹果电商销售月行动，累计销售苹果5.4万吨。与京东进行对接，谋划开设现代农业示范区专栏，宣传推介特色农产品；组织全国大型农垦企业与苏宁进行对接，在苏宁、天猫等大型电商平台开设“中国农垦旗舰店”。2016年，我部主办农业展会16场，在主产区、主销区以及新疆、宁夏、武陵山等偏远贫困地区开展了10多场产销对接活动，组织了400多人（次）经销商深入产区，推动产销双方建立长期合作关系。三是深化与电商企业合作。在全国“互联网+”现代农业工作会议暨新农民创业创新大会上，我部与阿里、京东、苏宁、网库、邮乐网等5家大型电商企业签署了具体合作协议，计划在产销对接、产业链和基础设施建设、电子商务培训、标准体系、质量安全追溯体系、监测统计体系等方面开展全方位合作。印发《农业电子商务试点方案》，部署北京等10个省份分别开展农产品、农业生产资料和休闲农业电子商务试点，推动12家电商企业与10个省份签订共同推进农业电子商务试点工作协议，积极探索农业电子商务新模式。

下一步，我部将继续支持贫困地区发展农产品加工业，实施农产品产地初加工补助政策，推进农品加工技术研发、示范和推广，提升就地转化能力和精深加工水平。着力把电子商务培育成为农产品流通的重要方式。同时，进一步推进“农商互联”，充分发挥农业部门牵线搭桥的作用，推动贫困地区新型农业经营主体与大型电商企业开展合作，大力开展试点示范，建立稳固的销售渠道。

感谢你们对农业、农村工作的关心，希望今后继续对我部工作予以支持。
