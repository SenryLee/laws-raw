# 中华人民共和国海关总署对十二届全国人大五次会议第6487号建议的答复

唐林代表：

您提出的《关于支持重庆果园港申报汽车整车进口口岸的建议》（流通、旅游和服务类第6487号）收悉，现就有关事项答复如下：

根据2004年《汽车产业发展政策》（国家发展和改革委员会令第8号）规定：“国家指定大连新港、天津新港、上海港、黄埔港四个沿海港口和满洲里、深圳（皇岗）两个陆地口岸，以及新疆阿拉山口口岸（进口新疆自治区自用、原产地为独联体国家的汽车整车）为整车进口口岸。进口汽车整车必须通过以上口岸进口”。

近年来，多地根据自身经济发展需要提出了增设汽车整车进口口岸等要求。为便于工作开展，2010年国务院确定“市场需要、运输便利、严格控制、有效监管”的审批原则，并明确相关工作由我署牵头，会同发展改革委、工业和信息化部、商务部研究提出办理意见，报国务院审批。

适度增设整车口岸是国务院改进口岸工作支持外贸发展的具体要求，我署在工作中始终予以高度重视。根据有关地方申请，结合上述审批原则，我署已会同有关部委研究上报多批新增整车进口口岸等工作意见。截至2017年6月，全国已有汽车整车进口口岸26个。

经国务院批准，2014年重庆市在重庆铁路口岸设立汽车整车进口口岸，并已正常开展汽车整车进口业务。关于果园港增设汽车整车进口口岸问题，我署充分理解地方有关需求，但截至目前我署尚未收到国务院办公厅转来重庆市有关增设汽车整车进口口岸的相关申请。建议有关地方人民政府结合国务院相关精神和地方实际需求，在充分考虑发挥已有汽车整车口岸作用的基础上，在符合口岸开放基本要求的前提下，就增设果园港为汽车整车进口口岸的相关工作加强综合研究和调研论证。如确有必要，建议地方人民政府按有关程序将相关申请上报国务院。我署将根据国务院有关要求，结合地方申请，会同有关部委予以统筹研究。

感谢您对海关工作的关心与支持，并欢迎继续对我们的工作提出宝贵的意见和建议。
