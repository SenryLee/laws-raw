# 国土资源部颁发地质勘查资质证书公告（2017）

## 国土资源部颁发地质勘查资质证书公告

根据《地质勘查资质管理条例》（国务院令第520号）的有关规定，现将截至2016年12月31日，国土资源部颁发的在有效期限内的地质勘查资质证书予以公告。

国土资源部

2017年1月16日
