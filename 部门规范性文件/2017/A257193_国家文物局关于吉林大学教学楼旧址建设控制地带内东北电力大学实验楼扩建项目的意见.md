# 国家文物局关于吉林大学教学楼旧址建设控制地带内东北电力大学实验楼扩建项目的意见

文物保函〔2017〕1813号

吉林省文物局：

你局《关于东北电力大学实验楼扩建项目涉及吉林大学教学楼旧址建设控制地带的请示》（吉文物发〔2017〕202号）收悉。经研究，我局意见如下：

一、原则同意所报项目。

二、对方案提出以下修改意见：

（一）进一步调整新建项目玻璃及外立面局部涂料色彩，使其与文物建筑相协调。

（二）充分考虑建设施工对文物建筑安全的影响，制定相应的文物保护应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善后，按照《中华人民共和国文物保护法》第十八条规定，报城乡建设规划部门批准实施。工程施工期间，你局应加强监管，确保文物安全。

国家文物局

2017年11月2日
