# 国家旅游局办公室关于做好2018年元旦假日旅游工作的通知

旅办发〔2017〕337号

各省、自治区、直辖市旅游发展委员会、旅游局：

2018年元旦将至,为认真贯彻落实党的十九大精神，满足广大游客对于美好假日旅游活动的向往和需求，确保全国人民度过一个欢乐祥和的元旦假期，实现假日旅游“安全、秩序、质量、效益、文明”的工作目标，现将有关事项通知如下：

一、保障假日旅游安全

高度重视假日旅游安全工作，明确假日旅游安全生产责任，制定假日旅游安全应急预案，提前发布假日旅游安全出行提示，联合相关部门开展假日旅游安全生产检查和整改，严格按照程序及时处置涉旅突发事件，确保旅游市场运行平稳。

二、狠抓假日旅游流量管理

严格督促景区执行核定的最大承载量，推动门票预约机制建设，及时发布旅游信息，引导游客流向，倡导游客错峰出行，积极推进全域旅游，提升有效供给，努力实现游客合理时空分流。

三、提升假日旅游供给

充分发挥主观能动性，深化全域旅游发展理念，深入挖掘各类资源，推出个性化旅游产品和季节性旅游线路，组织开展具有民俗民族特色的旅游活动，推广“旅游1+3+N”管理体制，加大旅游公共基础设施建设投入，推动厕所革命等旅游公共服务重点工程，组织开放假日临时应急服务设施，为广大游客提供更高品质的假日旅游产品和更便利的假日旅游公共服务。

四、规范假日旅游市场秩序

联合相关部门，核查旅游企业依法、守法从事旅游经营情况，重点查处违法违规经营行为，及时受理12301旅游热线等服务平台咨询和投诉，构建假日旅游市场诚信经营环境，倡导游客文明旅游，鼓励媒体宣传守信和文明典型，警示失信和不文明案例，鼓励旅游志愿者宣传活动，多部门齐抓共管，多主体共同参与，共建良好的假日旅游市场秩序，保障广大游客的合法权益。

五、加强假日旅游新闻宣传

提前规划、制定方案，邀请媒体集中报道假日旅游市场运行情况，组织媒体深入基层挖掘先进经验和事迹，发布《假日旅游市场信息》，发布文明旅游、诚信经营信息，深入掌握市场情况和舆论动向，及时回应游客反映的热点问题，收集游客意见和建议，核实整改负面舆情反映情况，通过广泛宣传和主动引导营造美好的假日旅游氛围，宣传健康积极、寓教于游的假日旅游休闲生活。

六、做好假日旅游值班和信息报送

根据假日旅游工作需要，实行领导带班，干部职工值班、备班制度，加强情况沟通和值班交接，保持人员通讯畅通，及时处理相关业务和事务，有效应对各类涉旅突发事件，统计假日旅游市场数据，报送假日旅游市场信息。数据要真实有效，信息要全面翔实，能够反映市场客观情况。

相关报送内容及时间要求如下：

1.请于2017年12月22日17：00前将本单位《元旦假日值班表》报送至国家旅游局。

2.请于2017年12月30日、12月31日15：00前将当日《假日旅游市场信息》报送至国家旅游局。

3.请于2018年1月1日15：00前将《2018年元旦假日旅游情况总结》报送至国家旅游局。

4.联系人：余青青，联系电话：010-65201747，电子信箱：jiari@cnta.gov.cn。

请各地高度重视，加强组织领导，认真部署落实有关工作，确保本通知精神落到实处。

附件：1.2018年元旦假日旅游值备班报送表

2.每日假日旅游市场信息模板

3.假日旅游市场情况总结模板
