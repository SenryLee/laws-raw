# 国家文物局关于魏家窝铺遗址展示工程（一期）立项的意见

## 关于魏家窝铺遗址展示工程（一期）立项的意见

办保函〔2017〕99号

内蒙古自治区文物局：

你局《关于内蒙古魏家窝铺遗址展示工程一期立项请示》（内文物发〔2016〕117号）收悉。经研究，我局意见如下：

一、暂不同意魏家窝铺遗址展示工程（一期）立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步研究评估遗址价值，分析可展示内容，并明确遗址展示定位、展示目标和总体思路。

（二）补充遗址展示利用条件评估，结合遗址所处区位、展示前景分析等论证遗址展示工程实施的必要性。

三、请你局指导立项报告编制单位，根据上述意见对所报立项报告做进一步修改和完善，经你局核准后，按程序另行报批。

国家文物局

2017年2月8日
