# 中共教育部党组关于于祥成等同志职务任免的通知

教党任〔2017〕178号

中共湖南大学委员会：

经与中共湖南省委商得一致，2017年7月24日研究决定：

于祥成同志任中共湖南大学委员会常委、副书记，谢赤同志任中共湖南大学委员会委员、常委，徐国正同志任中共湖南大学委员会常委；免去栾永玉同志的中共湖南大学委员会副书记、常委、委员、纪律检查委员会书记，陈收同志的中共湖南大学委员会常委，韩旭、杨胜刚同志的中共湖南大学委员会常委、委员职务。

中共教育部党组

2017年8月1日
