# 国家文物局关于做好景德镇御窑博物馆新馆西北角新发现重要文物遗迹保护工作的意见

文物保函〔2017〕1698号

江西省文物局：

你局《关于呈报景德镇御窑博物馆新馆西北角发现重要遗迹保护措施的请示》（赣文物局字〔2017〕134号）收悉。经研究，我局意见如下：

一、原则同意对景德镇御窑博物馆新馆西北角新发现重要文物遗迹进行原址保护展示。

二、在进行文物遗迹保护展示时应做好以下工作：

（一）应加强该处文物遗迹的临时性保护工作，如有必要可做临时性回填，确保文物安全。

（二）尽快组织编制专项文物保护展示方案，研提具有针对性的本体保护展示措施，在确保文物安全的前提下，科学展示其核心价值与丰富内涵。相关展示应注重维护文物遗迹的整体性，除必要的标识解说系统外，不宜布设过多辅助展示设施。

（三）建议进一步优化调整中华北路的交通通行功能和御窑厂遗址核心区现状东围墙，将该处遗迹纳入御窑厂国家考古遗址公园范围进行统筹保护管理，并做好与博物馆区域的衔接。

（四）进一步开展现保护范围北边界（斗富弄一线）以北区域等重点区域的考古工作，明确御窑厂遗址的分布范围，为保护规划修编和后续保护工作奠定基础。

三、请你局指导地方人民政府，根据上述意见组织做好该处文物遗迹的保护展示工作，并加强日常维护与管理，确保文物安全。请你局指导有关单位做好保护展示方案编制工作，并按程序报我局批准。

国家文物局

2017年9月27日
