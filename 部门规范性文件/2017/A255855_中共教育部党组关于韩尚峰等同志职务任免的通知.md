# 中共教育部党组关于韩尚峰等同志职务任免的通知

教党任〔2017〕205号

中共中国石油大学（北京）委员会：

经与中共北京市委商得一致，2017年8月31日研究决定：

韩尚峰同志任中共中国石油大学（北京）委员会常委、副书记，鲍志东、李根生、董朝霞同志任中共中国石油大学（北京）委员会委员、常委；免去徐春明、庞雄奇同志的中共中国石油大学（北京）委员会常委职务。

中共教育部党组

2017年9月8日
