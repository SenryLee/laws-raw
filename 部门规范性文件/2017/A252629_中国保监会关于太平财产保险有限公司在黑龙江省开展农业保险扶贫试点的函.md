# 中国保监会关于太平财产保险有限公司在黑龙江省开展农业保险扶贫试点的函

保监函〔2017〕85号

太平财产保险有限公司：

你公司《关于在黑龙江省扩大保险扶贫试点的请示》（太平财〔2017〕262号）收悉。经研究，我会支持你公司在黑龙江省开展农业保险扶贫试点。你公司要认真贯彻落实党中央国务院关于脱贫攻坚工作有关精神，积极总结推广前期试点经验，加大资源投入，针对黑龙江省贫困地区产业脱贫需求，探索保险服务脱贫攻坚新模式，为农户提供更多更好的保险服务。试点中遇到的新情况、新问题，应及时向我会报告。

中国保监会

2017年7月7日
