# 中共教育部党组关于沈国华、王家勤同志职务任免的通知

教党任〔2017〕112号

部内各司局：

中共教育部党组2017年4月12日研究提议，中央国家机关工委2017年5月25日决定，任命沈国华同志为中共教育部直属机关委员会副书记、直属机关纪律检查委员会书记，免去王家勤同志的中共教育部直属机关委员会副书记、直属机关纪律检查委员会书记职务。

中共教育部党组

2017年5月31日
