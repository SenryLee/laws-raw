# 农业部对十二届全国人大五次会议第7887号建议的答复

## 对十二届全国人大五次会议第7887号建议的答复

农办议〔2017〕295号

刘锦秀代表：

关于大力实施南方现代草地畜牧业项目的建议收悉。经商财政部，现答复如下。

一、关于加大南方现代草地畜牧业推进行动实施力度

从2014年起，中央财政每年安排“畜牧业发展扶持资金”3亿元，在安徽、江西、湖北、湖南、广东、广西、重庆、四川、贵州和云南等10省（区、市），开展南方现代草地畜牧业推进行动。旨在保护生态环境前提下，合理开发利用南方草山草地资源，在集中连片草山草地重点建设一批草地规模较大、养殖基础较好、发展优势较明显、示范带动能力强的牛羊肉生产基地，逐步改善南方草地畜牧业基础设施和科技支撑条件，提高草地资源利用率和农村劳动生产率，推动南方现代草地畜牧业发展，促进农牧民增收。截至2016年底，中央财政累计安排9亿元支持南方现代草地畜牧业推进行动，共有102家农牧业专业合作组织和205家农牧业企业承担了该项目，改良天然草地65.7万亩，建植人工草地33.6万亩，牛羊存栏量较实施前提高45.3%，培训农牧民6.2万人次。下一步，我部将与财政部加强沟通协调，根据中央财力情况争取加大项目投入力度，促进南方现代草地畜牧业持续健康发展。

二、关于科学制定项目管理措施和统一牧草供种制度

2014年项目实施之初，财政部和农业部即制定了项目实施指导意见，对项目实施的基本原则、范围主体、申报条件、项目内容、工作要求和组织实施等进行了明确规定。之后每年都会制定有关项目实施指导意见，对项目管理措施进行明确。南方现代草地畜牧业推进行动是一个示范性项目，以具有一定生产规模和技术水平的农牧业专业合作组织及企业为项目承担主体，以确保项目实施成效。为了促进南方草地区农牧民增收，我们在项目实施指导意见中明确要求，项目实施主体要与周边辐射带动农牧户签订草产品、畜产品购销合同或劳动合同。同时，在草种使用方面，项目要求普及使用优良牧草种子，推广应用草种包衣等高产集成技术。按照简政放权的原则，南方现代草地畜牧业推进行动实行项目、资金、任务、责任“四到省”，中央财政将补助资金切块下达到省（区、市），由省级草原行政主管和财政部门组织开展项目申报、批复、公示、绩效评价和检查验收等工作，各地可以因地制宜探索建立牧草统一供种等制度措施。下一步，我部将与财政部加强沟通协调，积极完善政策内容，强化项目监督管理，确保资金使用效益。

感谢您对草原保护建设工作的关心，希望继续对我部的工作予以支持。

农业部

2017年9月15日
