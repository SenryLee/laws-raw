# 国家核安全局关于同意常州八益电缆股份有限公司民用核安全设备许可证信息变更的复函

## 关于同意常州八益电缆股份有限公司民用核安全设备许可证信息变更的复函

国核安函[2017]28号

常州八益电缆股份有限公司：

你公司《关于民用核安全设备设计和制造许可证中民用核安全设备设计和制造许可范围变更的申请报告》（常八益缆发〔2017〕01号）收悉。根据《民用核安全设备监督管理条例》及其配套规章的有关规定，我局对你公司民用核安全设备许可证信息变更申请进行了审查。经研究，同意你公司民用核安全设备设计许可证（国核安证字S（14）02号）和民用核安全设备制造许可证（国核安证字Z（14）02号）增加相关活动范围（见附件）。

附件：常州八益电缆股份有限公司新增民用核安全设备许可活动范围

国家核安全局

2017年3月20日
