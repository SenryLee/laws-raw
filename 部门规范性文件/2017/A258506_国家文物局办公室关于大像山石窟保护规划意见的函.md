# 国家文物局办公室关于大像山石窟保护规划意见的函

办保函〔2017〕1311号

甘肃省文物局：

你局《关于呈报大像山石窟保护规划的报告》（甘文局发〔2017〕13号）收悉。经研究，我局意见如下：

一、大像山石窟保护规划现状评估不完整，保护和整治措施不足，暂不同意所报规划。

二、对该规划提出以下修改意见：

（一）进一步梳理保护对象和文物本体，通广渠应列为保护对象，石窟内的题刻、壁画应纳入文物本体。

（二）深入评估大像山石窟周围建成环境和建筑现状，明确周边建筑、北部地区及大像山文化主题公园对文物本体、环境、景观风貌的影响，对于在保护区划内未经批准的建设活动不得在本规划中予以认可，在规划措施中应明确整改要求。完善现行保护区划的评估内容，细化保护区划管理规定，建设控制地带内应严格控制新建活动，并明确依法审批要求，现有建筑的整治、改造应以文物历史格局为依据。

（三）补充石窟所在区域立面、剖面图，全面评估工程地质状况；补充石窟寺窟内稳定性、温、湿度等监测体系。

（四）进一步完善图文表达，增强评估和措施的对应性，补充规划总图。

三、请你局指导相关单位，按照上述意见对所报保护规划进行修改、完善，按相关程序另行报批。

国家文物局办公室

2017年11月30日
