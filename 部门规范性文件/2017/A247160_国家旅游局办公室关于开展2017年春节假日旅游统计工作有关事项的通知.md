# 国家旅游局办公室关于开展2017年春节假日旅游统计工作有关事项的通知

旅办发〔2017〕6号

各省、自治区、直辖市旅游发展委员会、旅游局：

按照《国家旅游局关于做好2017年元旦春节假日旅游工作的通知》（旅游明电〔2016〕198号）要求，为确保春节假日旅游统计工作顺利进行，现将有关事项通知如下：

一、统计报送相关工作安排

（一）1月27日至2月2日，报送各类旅游新闻和旅游服务信息

根据《“黄金周”旅游信息统计调查制度》工作要求，请参加春节假日旅游统计报送的重点旅游城市（北京、天津、长春、吉林、哈尔滨、上海、南京、无锡、苏州、杭州、厦门、广州、深圳、桂林、海口、三亚、重庆、成都、昆明）和景区（长白山、曲阜三孔、博鳌、玉龙雪山）安排专人负责收集汇总当地假日旅游情况，将本地区市场情况、市场热点、有特色的节庆活动、新的旅游项目等旅游信息，于1月27日至2月2日每天15时前，填报到“旅假日综3表”——“当日接待情况总体概述”中，通过网络报送国家旅游局。

（二）“旅假日综5表”和“旅假日综6表”的报送

各指定重点旅游城市（包括纳入国庆假日旅游统计报送的承德、秦皇岛、沈阳、大连、宁波、黄山、南昌、瑞金、青岛、洛阳、武汉、长沙、张家界、韶山、广安、贵阳、遵义、西安、延安、银川等其他指定重点旅游城市）于2月3日8时前将有单位负责人签字并加盖公章的“旅假日综5表”以传真形式报送国家旅游局。

各省（自治区、直辖市）旅发委、旅游局于2月3日12时前将有单位负责人签字并加盖公章的“旅假日综6表”以传真形式报送国家旅游局。

二、统计报送模拟测试时间安排

为保障假日旅游统计报送网络系统在春节假日期间顺利运行，国家旅游局决定于2017年1月19日，组织纳入全国春节假日旅游统计报送范围的重点旅游城市和景区进行模拟测试。要求参加测试的城市和景区旅发委、旅游局于1月19日15时至17时，通过点击http://www.cnta.gov.cn（国家旅游局官网）“假日旅游”模块（进入密码与2016年春节相同），将反映当天旅游市场的信息填报到“旅假日综3表”——“当日接待情况总体概述”中，进行提交。
