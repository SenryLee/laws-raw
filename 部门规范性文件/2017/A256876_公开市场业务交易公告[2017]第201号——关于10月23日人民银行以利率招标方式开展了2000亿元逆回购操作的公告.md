# 公开市场业务交易公告[2017]第201号——关于10月23日人民银行以利率招标方式开展了2000亿元逆回购操作的公告

## 公开市场业务交易公告

[2017]第201号

为对冲税期高峰、政府债券发行缴款和央行逆回购到期等因素的影响，维护银行体系流动性基本稳定，10月23日人民银行以利率招标方式开展了2000亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 1100亿元 | 2.45% |
| 14天 | 900亿元 | 2.60% |

中国人民银行公开市场业务操作室

二〇一七年十月二十三日
