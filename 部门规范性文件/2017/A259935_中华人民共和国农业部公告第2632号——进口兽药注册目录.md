# 中华人民共和国农业部公告第2632号——进口兽药注册目录

## 中华人民共和国农业部公告

第2632号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准丹麦Pharmacosmos A/S公司等5家公司生产的右旋糖酐铁注射液等6种兽药产品在我国再注册，核发《进口兽药注册证书》,发布修订后的产品质量标准、说明书和标签，并发布泰乐菌素残留检测方法标准（试行），自发布之日起执行，原我部发布的本产品质量标准、说明书和标签同时废止。

批准辉瑞集团法玛西亚?普强公司等3家公司生产的硫酸大观霉素等4种兽药产品在我国变更注册。

特此公告。

附件：1.进口兽药注册目录

2.质量标准（略）

3.说明书和标签

4.泰乐菌素残留检测方法标准（试行）

农业部

2017年12月27日
