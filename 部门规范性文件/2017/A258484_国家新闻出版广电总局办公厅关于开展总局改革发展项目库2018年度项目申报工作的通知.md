# 国家新闻出版广电总局办公厅关于开展总局改革发展项目库2018年度项目申报工作的通知

新广出办函〔2017〕283号

党中央有关部门办公厅（室），国务院各部委、各直属机构办公厅（室），各省、自治区、直辖市及计划单列市、新疆生产建设兵团新闻出版广电局，有关中央企业，总局直属各单位：

为学习贯彻落实党的十九大精神，落实国家“十三五”规划《纲要》和《新闻出版广播影视“十三五”发展规划》，有效实施项目带动战略，促进新闻出版广播影视产业发展，推动我国从新闻出版广播影视大国向新闻出版广播影视强国迈进，经研究，决定开展总局改革发展项目库2018年度项目申报工作，现将有关事项通知如下：

一、中央各部门各单位，各省、自治区、直辖市、计划单列市新闻出版广电行政主管部门要高度重视，组织做好2018年度项目申报工作，加强对项目申报工作的指导，认真审核把关，有条件的地区和部门要组织专家评审，提高项目申报质量，为争取各文化产业发展专项资金和其他各类文化基金的支持奠定基础。

二、各有关新闻出版单位要重点围绕《新闻出版广播影视“十三五”发展规划》，按照《国家新闻出版广电总局改革发展项目库2018年度项目申报指南》的要求，积极准备项目申报材料，认真填报项目申报信息，申报一批具有战略性、引导性和带动性的新闻出版广播影视在建、新建项目。

三、总局改革发展项目库2018年度实行网络申报和纸质申报，各申报单位完成网络申报的同时，须报送纸质申报材料（一式一份），网络申报材料与纸质申报材料必须完全一致。

四、总局改革发展项目库2018年度项目申报截止时间为2018年1月15日。

附件：国家新闻出版广电总局改革发展项目库2018年度项目申报指南

国家新闻出版广电总局办公厅

2017年11月24日
