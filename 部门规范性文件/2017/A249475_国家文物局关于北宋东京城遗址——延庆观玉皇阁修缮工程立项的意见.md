# 国家文物局关于北宋东京城遗址——延庆观玉皇阁修缮工程立项的意见

## 关于北宋东京城遗址——延庆观玉皇阁修缮工程立项的意见

办保函〔2017〕271号

河南省文物局：

你局《关于北宋东京城遗址（延庆观玉皇阁）修缮工程立项的请示》（豫文物〔2016〕338号）收悉。经研究，我局意见如下：

一、暂不同意北宋东京城遗址——延庆观玉皇阁修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）应在充分利用2010年顶升工程基础勘察测绘资料的基础上加强勘察研究，明确文物保存现状、主要病害类型、残损情况等，深入分析墙体开裂、墙面脱落、石质构件断裂等病害问题与2010年顶升工程之间的关系，客观评估玉皇阁的结构稳定性，进一步论证工程实施的必要性和可行性。

（二）补充地方建造工艺、传统做法、建筑材料和构造特征等研究和分析内容。

（三）根据工程量合理编制经费预算，进一步核减工程造价，补充各单项取费依据。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

专此函。

国家文物局

2017年3月16日
