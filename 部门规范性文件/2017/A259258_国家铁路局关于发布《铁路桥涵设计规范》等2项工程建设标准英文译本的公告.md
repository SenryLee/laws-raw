# 国家铁路局关于发布《铁路桥涵设计规范》等2项工程建设标准英文译本的公告

国铁科法〔2017〕73号

现发布《铁路桥涵设计规范》（TB 10002-2017）、《铁路信号设计规范》（TB 10007-2017）等2项铁路工程建设标准英文译本。英文译本与中文版标准在技术上出现异议时，以中文版为准。

以上英文译本由中国铁道出版社组织出版发行。

国家铁路局

2017年9月29日
