# 商务部公告2017年第7号——决定准予陕西华联石油化工销售有限公司等成品油批发经营许可的公告

## 商务部公告

2017年第7号

依据《行政许可法》、《国务院对确需保留的行政审批项目设定行政许可的决定》(国务院令第412号)、《成品油市场管理办法》(商务部令2006年第23号)和《原油市场管理办法》(商务部令2006年第24号)的有关规定，经审核，商务部决定准予陕西华联石油化工销售有限公司、博兴兴港铁运有限公司、秀山民生石油化工有限公司、濮阳丰范贸易有限公司、山东军胜物流有限公司、威海运通石油有限公司成品油批发经营许可；

准予中化港务（厦门）石化仓储有限公司、江苏国邦石油化工有限公司、浙江神华储运有限公司（投资主体发生变化、注销新增）、国投孚宝洋浦罐区码头有限公司成品油仓储经营许可；

准予瀚坤能源发展有限公司原油仓储经营许可；

注销沈阳天元石油化工公司、中国石油天然气股份有限公司黑龙江牡丹江宁安经营部、浙江神华储运有限公司（投资主体发生变化、注销新增）、吉林省石油开发股份有限公司、吉林省润滑油公司石铁联营公司、长春龙铁石化联营有限公司、吉林省鑫河实业有限公司成品油批发经营许可。

商务部

2017年1月20日
