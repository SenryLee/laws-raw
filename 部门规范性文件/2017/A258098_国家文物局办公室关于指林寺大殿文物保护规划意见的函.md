# 国家文物局办公室关于指林寺大殿文物保护规划意见的函

办保函〔2017〕1284号

云南省文物局：

你局《关于请求批准指林寺大殿文物保护规划的请示》（云文物〔2017〕139号）收悉。经研究，我局意见如下：

一、指林寺大殿文物保护规划现状评估不完整，保护和整治措施无针对性，部分内容前后矛盾，文本及图纸与《全国重点文物保护单位保护规划编制要求》存在较大差距，暂不同意所报规划。

二、对该规划提出以下修改意见：

（一）补充“文物构成”章节，明确文物构成、附属文物、文物环境构成，确定保护对象。指林寺内现地表不存的山门、双塔、天王殿、准提阁等认定为建筑遗址缺乏科学依据；进一步完善历史环境构成要素。

（二）完善、深化现状评估。补充文物保存现状评估结论、保护现状评估、保护范围内建筑物利用功能评估，明确环境评估的范围和具体对象。

（三）合理调整保护区划。保护范围应按照文物保护需求、历史上的寺院范围、实际管理范围等实际情况综合确定，在不确定恢复重建寺院是否必要、可行的情况下，不应基于重建后的寺院平面来界划保护范围，不应采用复原图作为保护区划底图。建设控制地带不应在保护范围外部简单外扩而成，应考虑环境现状，并与建水市总体规划、控制性详细规划、历史文化名城保护规划相衔接。

（四）完善保护措施，补充对附属文物特别是大殿内壁画的保护要求。

（五）调整、深化环境规划。对恢复寺院其他建筑的必要性和可行性进行分析，保护范围内应严格控制恢复建设活动。进一步论证重建建筑的必要性和可行性，评估对文物真实性的影响。明确各类外围建筑整治措施适用的具体对象。

（六）补充保护规划与历史文化名城保护规划的衔接，特别是在保护区划与环境整治、展示利用方面应与历史街区的保护相衔接。

（七）明确指林寺的展示利用策略，指林寺目前管理范围内的一般建筑已经全部拆除，建议根据指林寺的价值阐释与展示要求，结合周边城镇文化建设的需求，提出合理适当的展示主题和功能分区，尽可能避免大规模的展示服务设施建设。

（八）完善管理规划，明确指林寺的权属与文物管理的责任主体。

（九）进一步规范文本和图纸表达。图纸应采用符合现状的地形图为底图，补充保存现状评估图、环境现状评估图、建筑利用现状评估图、环境整治规划图、建筑功能规划图等，并按规范绘制其他图纸。

三、请你局指导相关单位，按照上述意见对所报保护规划进行修改、完善，按相关程序另行报批。

国家文物局办公室

2017年11月21日
