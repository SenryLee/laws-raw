# 国家发展改革委办公厅关于报送环境污染第三方治理典型案例的通知

发改办环资〔2017〕779号

各省、自治区、直辖市及计划单列市发展改革委，新疆生产建设兵团发展改革委：

为进一步推进环境污染第三方治理工作，推广成功经验、管理制度和有效模式，现面向全国组织征集环境污染第三方治理典型案例。有关事项通知如下。

一、征集范围

此次环境污染第三方治理典型案例征集对象为城镇污水垃圾处理等环境公共基础设施领域、工业园区和重点企业污染治理等领域投入运营、已开工或已签订合同并正在开展前期工作，有示范引领作用的环境污染第三方治理项目。

二、征集条件

按照污染治理“市场化、专业化、产业化”导向，环境污染第三方治理典型案例应操作规范，符合有关政策法规，并在第三方选择、地方性法规或规章建立、规范性合同、价费机制建立、投融资机制创新、全程监管体系建立等方面具有典型示范价值，适于向社会公开推广。

三、申报材料要求

具体项目案例申报材料应内容真实、层次清晰、数据准确、观点明确。主要包括以下内容。

（一）基本情况

包含环境污染第三方治理典型案例名称、所属行业、建设规模和建设内容、社会资本方概况、项目目前进展情况、环境效益和经济效益等内容。

（二）典型案例借鉴价值

根据环境污染第三方治理试点的任务要求，典型案例的借鉴价值重点围绕但不限于以下内容进行详细说明。

1、地方性法规或规章建设。项目所在市（县）对第三方治理企业或特许经营企业选择、收费管理、投资回报、运营补贴、服务标准、信息披露、过程监管、违约处罚等制度建设情况。

2、项目收费机制建设。城镇污水、垃圾处理项目所在省、市、县收费机制建设情况，包括调整完善处理收费标准、提高收缴率等；收费不能满足投资者弥补成本、合理收益的，政府补贴制度设计及绩效考核等。第三方治理项目价格、收费合理调整等。

3、项目投融资机制创新。第三方治理项目融资模式及筹资渠道。地方政府通过补贴、奖励等政策措施引导社会资本进入情况等。

4、项目监管体系建设。第三方治理企业选择模式。项目合同主要内容及执行情况。项目付款方式。第三方治理责任界定、效果评估等。

（三）相关证明文件

请提供与第三方签署的合同材料电子版（同时提供封面及盖章页扫描件），项目审批、核准或备案文件，已出台的地方性法规或规章文件及政府会议纪要等材料，并结合实际提供与典型案例有关的照片、新闻报道等材料。

四、申报方式

本次案例征集由省级发展改革委负责组织申报。国家发展改革委会同有关部门批复的环境污染第三方治理试点省（市）可报送2-3个典型案例，其他省（市）报送1-2个典型案例。国家发展改革委将组织专家进行评审，筛选出的典型案例将通过多种方式进行推广，并采取适当方式予以支持。

请各省级发展改革委认真做好本地区环境污染第三方治理典型案例征集工作。

五、报送截止时间及方式

典型案例报送截止日期为2017年6月8日。请各省级发展改革委将申报文件及材料报送至国家发展改革委（环资司）。电子版请发送至电子邮箱。
