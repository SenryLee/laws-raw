# 国家文物局办公室关于古田临水宫壁画彩绘保护项目的意见

办保函〔2017〕1223号

福建省文物局：

你局《关于全国重点文物保护单位古田临水宫壁画彩绘保护设计方案（第二稿）的请示》（闽文物字〔2017〕382号）收悉。经研究，我局意见如下：

一、进一步深化现状勘察。应补充对地仗层材料和各类胶结材料的分析；补充对水泥材质的检测鉴定；明确是否存在底稿；补充各类病害病因分析的依据，如可溶盐分析数据、光照强度和照射规律监测数据等；核实、确认彩画整体保存情况、油饰彩画历史维修情况，查核彩画残留位置和范围并明确标注；核准壁画空鼓的具体范围和面积，核实地仗层厚度及可承载的灌浆压力，评估灌浆措施及设定参数的可行性。

二、完善前期试验。补充灌浆试验，应对壁画灌浆材料及其配比进行重新比选；前期试验应基于颜料分析结论，采用同种颜料进行试验；应补充封护材料涂刷在模拟颜料层后的老化性能试验。

三、根据勘察、评估及试验结论，调整完善修缮措施。重新论证不同彩画清理程度的措施要求，避免过度干预；加固材料选择应基于原材料分析，尽可能继续采用原材料；回贴起甲、加固和表面封护尽量采用同种材料；补充说明脱盐处理内容；B72 使用浓度较高，应根据前期试验进行调整，避免颜料层变色或眩光。

四、补充、规范设计图纸。如，补充壁画揭取及回贴加固的施工详图，重点核实拟采取措施对壁画本体的影响；补充、规范壁画修缮设计图。按照壁画保护修复方案的相关编制规范要求，认真规范勘察设计图纸，全面、详实记录壁画、彩画的分布、现状及病害等，并提供足够清晰的图纸。

五、具体方案由你局指导有关单位按照上述意见进行修改、完善并经你局批准后实施。

六、请你局加强监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

专此函复。

国家文物局办公室
