# 中国证券监督管理委员会对十二届全国人大四次会议第9236号建议的答复(摘要)

## 对十二届全国人大四次会议第9236号建议的答复(摘要)

《关于积极推进铁矿石期货国际化，建设铁矿石国际交易中心的建议》收悉。经认真研究，现就有关问题答复如下：

大连商品交易所（以下简称大商所）铁矿石期货交易活跃，运行总体平稳，定价和避险功能初步得到市场认可，并且已在一定程度上间接影响了普氏指数定价的既有格局。境外投资者的逐步引入和期货市场相关法规制度体系的完善，将有利于我国建成全球的铁矿石交易和定价中心。

近年来，我会一直积极推进铁矿石期货国际化进程。目前，铁矿石期货已经在大连海关保税监管场所内实行保税交割，保税交割暂免征收增值税政策也已落实。下一步，为全面引入境外交易者参与铁矿石期货交易，我会将研究推进把铁矿石期货确定为特定品种，取得相应的财税、外汇、人民币账户开立等政策，引入境外投资者参与境内铁矿石期货交易。

我会鼓励大商所积极服务实体经济发展，帮助企业利用期货市场稳定生产经营，规避价格波动风险，并通过对内改革和对外开放逐步吸引国内外矿商和金融机构参与交易，进一步扩大期货市场的定价影响力，逐步引导铁矿石期货价格成为现货贸易的定价基准。
