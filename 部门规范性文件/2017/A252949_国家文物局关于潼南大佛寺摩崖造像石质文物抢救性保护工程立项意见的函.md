# 国家文物局关于潼南大佛寺摩崖造像石质文物抢救性保护工程立项意见的函

## 关于潼南大佛寺摩崖造像石质文物抢救性保护工程立项意见的函

办保函〔2017〕754号

重庆市文物局：

你局《关于潼南大佛寺摩崖造像石质文物抢救性保护工程立项的请示》（渝文物〔2017〕23号）收悉。经研究，我局意见如下：

一、不同意潼南大佛寺摩崖造像石质文物抢救性保护工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）准确界定工程性质，科学确定技术路线。如，风化及残损摩崖造像的修复加固应定性为本体修复加固，并严格按文物本体修复加固的技术路线和要求开展工作，不宜仓促按抢救性工作实施。

（二）加强前期勘察和研究工作，补充对已有勘察、研究成果的整理、分析与评估，深入分析病害原因，制定针对性的保护措施。如，水害治理应重点解决雨水及面流水问题。

（三）坚持最小干预原则，严格控制工程范围和规模。围绕水害治理和本体修复工作可开展必要的勘察、试验工作，与此无关的前期工作可简化；开展区域工程地质调查的规模过大，应适当控制。

（四）应根据工程量合理控制经费预算。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促地方人民政府根据《关于潼南大佛寺摩崖造像保护规划的意见》（办保函〔2015〕330号）要求，抓紧编制潼南大佛寺摩崖造像保护规划,统筹考虑石质文物保护、展示利用、环境整治和日常管理工作，确保文物及其周边环境安全。

专此函复。

国家文物局

2017年6月16日
