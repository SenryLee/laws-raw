# 国土资源部办公厅关于印发《探明储量的油气矿产资源统一确权登记调研工作方案》的函

国土资厅函〔2017〕746号

中国石油天然气股份有限公司、中国石油化工股份有限公司、中海石油（中国）有限公司、陕西延长石油（集团）有限责任公司、中联煤层气有限责任公司,部油气中心:

根据《探明储量的矿产资源纳入自然资源统一确权登记试点工作方案》（国土资厅函〔2017〕409号）的有关要求，我部拟组织开展探明储量的油气矿产资源统一确权登记工作专项调研，现将调研工作方案印发给你们，请予以支持并做好相关准备工作。

2017年5月15日

## 探明储量的油气矿产资源统一确权登记调研工作方案

为认真贯彻落实党中央、国务院关于加快构建自然资源资产产权制度的总体要求和部党组关于开展自然资源统一确权登记的工作部署，按照部“责任落实年”工作要求，切实推进探明储量的油气矿产资源统一确权登记（以下简称“油气确权登记”）工作落实到位，开展油气确权登记调研工作，掌握普遍规律，及时发现、研究解决重点难点问题，形成可复制可推广的工作经验，为全面推广油气确权登记夯实工作基础。特制订本调研工作方案。

一、调研主要内容

（一）重点了解的有关工作情况。

1.油公司储量管理工作情况。截至2016年底石油、天然气、煤层气和页岩气储量管理流程及储量备案等情况。

2.油气储量数据库基本情况。油气储量数据库参数完整性，不同矿业权、不同省份的储量分割原则，储量估算面积坐标系统及图形格式等。

3.现有油气探明储量数据库、登记统计库与矿业权审批登记数据库的衔接情况。

（二）重点研讨的几个问题。

1.油气确权登记的技术要求和细则。

2.目前现有技术标准规范和储量评审备案登记制度是否能满足油气确权登记，如何建立有效的运行机制和保障措施，确保登记及时、内容客观真实。

3.推进油气确权登记工作意见和建议。

二、调研对象及范围

（一）调研对象。中国石油天然气股份有限公司、中国石油化工股份有限公司、中海石油（中国）有限公司、陕西延长石油（集团）有限责任公司、中联煤层气有限责任公司等。

（二）调研范围。拟调研的各油气公司总部以及中国石油天然气股份有限公司西南油气田分公司、中国石油化工股份有限公司江苏油田分公司、中海石油（中国）有限公司湛江分公司、陕西延长石油（集团）有限责任公司延安气田、中联煤层气有限责任公司山西晋城潘河煤层气田等。

三、调研方式

实地调研和座谈、研讨相结合。对调研油气田开展实地调研，组织储量管理人员、技术人员及有关专家座谈和研讨。

四、调研时间及进度安排

（一）开展调研。2017年6月至7月，利用1个月左右的时间分成2个调研组，赴各油公司开展调研工作。

（二）调研总结。7月底前，形成提交调研分报告及总报告。

（三）形成技术要求。8月底前，针对调研总结出的共性问题，召开油气确权登记技术交流会。9月底前，提出解决问题的技术路线和方法，形成技术要求。

五、调研组组成

设2个调研组，由储量司、部油气中心带队，成员由各油气公司、调研单位有关人员和有关专家组成。

第一组 中国石油天然气股份有限公司总部，西南油气田分公司；中海石油（中国）有限公司总部，湛江分公司。

第二组 中国石油化工股份有限公司总部，江苏油田分公司；陕西延长石油（集团）有限责任公司总部,延安气田；中联煤层气有限责任公司总部，山西晋城潘河煤层气田。

六、调研成果

（一）油气确权登记调研报告。

（二）油气确权登记技术要求。

各组调研的具体时间、调研组人员组成另行通知，请各相关单位提前做好准备工作。
