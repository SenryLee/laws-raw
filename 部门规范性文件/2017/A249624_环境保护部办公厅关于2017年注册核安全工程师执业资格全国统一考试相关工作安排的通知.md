# 环境保护部办公厅关于2017年注册核安全工程师执业资格全国统一考试相关工作安排的通知

## 关于2017年注册核安全工程师执业资格全国统一考试相关工作安排的通知

环办核设函[2017]560号

各有关单位：

根据《注册核安全工程师执业资格制度暂行规定》（人发〔2002〕106号）和《人力资源社会保障部办公厅关于2017年度专业技术人员资格考试计划及有关问题的通知》（人社厅发〔2016〕174号）的有关规定，现将2017年注册核安全工程师执业资格全国统一考试相关工作安排通知如下：

一、考试时间为2017年9月23日、24日。考试依据《注册核安全工程师执业资格考试大纲（2013版）》进行。

二、考试报名和资格审查工作由环境保护部核与辐射安全中心负责。

具体报考条件和报名方式请登录环境保护部核与辐射安全中心网站（网址：http://www.chinansc.cn/），在“环境保护部注册核安全工程师”专栏中查询。
