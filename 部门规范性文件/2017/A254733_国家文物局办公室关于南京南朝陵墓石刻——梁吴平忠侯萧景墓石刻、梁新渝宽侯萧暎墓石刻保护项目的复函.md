# 国家文物局办公室关于南京南朝陵墓石刻——梁吴平忠侯萧景墓石刻、梁新渝宽侯萧暎墓石刻保护项目的复函

办保函〔2017〕921号

江苏省文物局：

你局《关于审批南京南朝陵墓石刻——梁吴平忠侯萧景墓石刻、梁新渝宽侯萧暎墓石刻抢救性保护设计方案的请示》（苏文物保〔2017〕165号）收悉。经研究，我局意见如下：

一、所报方案技术路线不合理，文本深度不够，我局暂不同意南京南朝陵墓石刻——梁吴平忠侯萧景墓石刻、梁新渝宽侯萧暎墓石刻保护项目。

二、对所报方案提出以下修改意见：

（一）应调整设计思路，尽可能原址保护，不同意提升萧景墓石刻和萧暎墓神道柱石刻地坪的做法。建议在不改变文物原有竖向高程的前提下，研提多种比选方案。

（二）应进一步优化方案设计，不同意道路走向采用曲径处理，价值展示应以营造墓葬神道气氛为目标，道路布局应反映神道的走向、规制，避免过度人工化和现代景观园林化设计。

（三）补充石刻本体保护措施，同时研提切实有效的围挡方式避免人为接触、攀爬等引起石刻破坏，保证文物安全。

三、请你局组织相关单位根据所提意见，对项目方案进行修改完善后，按我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的相关要求另行报批。

四、请你局督促地方人民政府尽快完成《南京南朝陵墓石刻保护规划》编制工作，统筹考虑文物保护、环境整治、展示利用等工作，切实加强日常管理、巡查与岁修工作，确保文物本体与周边环境安全。

专此函复。

国家文物局办公室

2017年8月8日
