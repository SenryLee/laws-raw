# 农业部关于政协十二届全国委员会第五次会议第2879号（农业水利类267号）提案答复摘要

## 政协十二届全国委员会第五次会议第2879号（农业水利类267号）提案答复摘要

土壤是构成生态系统的基本要素之一，是人类赖以生存的物质基础，防治土壤污染，直接关系到农产品质量安全、人民群众身体健康和经济社会的可持续发展。近年来，我部积极会同相关部门推进农产品产地环境保护立法工作。一是关于制定《土壤污染防治法》。目前《土壤污染防治法（草案）》已公开向社会征求意见，草案列专章对农用地进行了规定，强化农用地土壤环境保护。二是关于推动农产品产地环境保护专门立法及修改相关法律法规。《农业法》《农产品质量安全法》等法律法规对耕地土壤保护都有相关规定。目前我部正联合环境保护部编制《农用地土壤环境管理办法》，加强农用地土壤环境保护，保障农产品质量安全。三是关于推进农产品产地环境保护地方立法。我部会同相关部门积极推动地方开展土壤污染防治立法工作。目前,《福建省土壤污染防治办法》《湖北省土壤污染防治条例》已经出台,《湖南省土壤污染防治条例》《广东省土壤污染防治条例》《吉林省黑土地保护条例》正在制定中。

下一步，我部将积极配合全国人大推进《土壤污染防治法》制定工作；加强研究推动相关法律法规的制修订工作，完善法规体系，推动地方强化土壤污染防治法制建设，全力做好农产品产地土壤环境保护和污染治理工作，保障农产品质量安全。

农业部
