# 环境保护部办公厅关于表扬浙江省环境监管执法工作的通报

## 关于表扬浙江省环境监管执法工作的通报

环办环监函[2017]409号

各省、自治区、直辖市环境保护厅（局），新疆生产建设兵团环境保护局：

近年来，浙江省以“绿水青山就是金山银山”重要思想为指引，按照“干在实处、走在前列、勇立潮头”要求，致力于打造全国最严环保执法省份，环境执法力度保持全国领先。特别是2016年紧密围绕国家大气、水、土壤污染防治行动计划重大部署和浙江省“五水共治”重大举措，以服务保障重大活动环境质量和全面剿灭劣V类水体为推动，深入开展环境保护法实施年活动，精准施策、精细化管理，执法力度再创新高，全面助推经济转型升级和环境质量改善。经研究，我部决定对浙江省环境执法工作予以通报表扬。浙江省环境监管执法工作的典型做法主要体现在以下6个方面：

一、突出压力传导，倒逼监管责任落实。浙江省将省委主要领导高度重视环境执法工作的最大优势，转化为推动各级党委政府领导真重视、责任真落实。特别是借力浙江卫视《今日聚焦》、浙江日报“治水拆违大查访”等栏目，用媒体聚焦力提升环境执法工作倒逼力。省委、省政府领导对每期《今日聚焦》节目都作出批示，有力地督促基层党委政府迅速做好曝光环境问题的整改，推动一大批“老大难”突出环境问题得到解决。

二、突出先行先试，压实各方监管责任。注重执法监管方式创新和基层监管责任落实，全面实现省市县乡村五级河长制和环境监管网格化管理全覆盖，配备各级河长6.1万名。建立企业环境监督员、农村环境监督员、环保协管员、环保义务巡防员等制度，全省农村监督员队伍达1.8万余人。建立乡镇（街道）环境监管责任制，明确乡镇（街道）的环保日常监管工作责任，实现督政和查企并重，使环境监管有保障、有底气。

三、突出机制建设，打造全程监管链条。通过不断加强打击环境违法行为的联动机制、发现机制和监督机制建设，打出执法最严组合拳。建立在线巡检调度制度，省环境监控平台每日对全省1345家重点排污企业在线监测数据进行高频次巡检，对于数据异常企业每日发送属地环保部门查处。建立重奖举报和线人制度，对于提供环境违法犯罪线索的最高奖励10万元，一般行政处罚的奖励3万元。建立行政处罚过程管理制度，加强移动执法系统和电子处罚平台使用，统一处罚标准、流程和监督等环节，严格限定自由裁量权，构建起全方位、立体化、全过程环境监管机制。

四、强化高压严管，推动企业自觉守法。持续保持执法高压态势，进一步营造良好环境秩序，特别是2016年以环境保护法实施年活动为推动，全省共查处按日计罚案件79件，查封、扣押案件1325件，限产、停产案件347件，移送行政拘留案件591件，移送涉嫌环境污染犯罪案件457件，并率先查处全国首例环境信息不公开案件，以及公开曝光多起污染源在线数据造假案件，执法刚性进一步显现。

五、强化行刑衔接，放大案件警示作用。所有市、县实现环保公安联络室或警务室全覆盖，并配置省市县乡四级“河道警长”，建立检察院驻环保部门检察室和法院驻环保部门执行站，率先出台全省性的涉嫌环境犯罪案件调查取证、移送等工作规程，印发多个办理环境刑事案件会议纪要，为打击环境违法犯罪提供有力支撑。2013年以来全省共向公安机关移送案件3903件，行政拘留2114人、刑事拘留3553人，查处了非法倾倒废液、偷排危险废物等一批大案要案，打击力度一直位居全国首位。2016年召开三次新闻发布会，分16批公开曝光167个环境违法典型案件，实现“查处一案、教育一片、警示一方”的效果。

六、强化多元支撑，提升环境监管效能。大力提升环境执法精细化和标准化水平，编发《浙江省重点行业环境监察简要指南要点手册》和《浙江省环境执法人员行政执法规范手册》，在全国率先制定《浙江省大案要案认定标准》，推广第三方监管，通过政府购买服务解决基层执法人员力量和专业能力不足的问题。全省2700多名环境监察执法人员，年均完成立案处罚案件1万多件、移送公安案件1000件、受理调处环境信访近10万件、完成排污收费近10亿元、处置突发环境事件近30起，人均办案量等远远高于其他地区。同时，还大力开展环境监察文化建设，将准军事化管理融入队伍建设，全力打造环境执法铁军。

希望浙江省各级环保部门再接再厉，始终保持从严打击环境违法行为的高压态势，以严格执法监管倒逼转型升级和环境持续改善。各地环保部门要充分学习借鉴浙江省先进经验，根据本地区实际情况，不断完善环境监管执法机制建设，加大对各类环境违法行为惩处力度，为改善环境质量和推动经济转型做出积极贡献。

环境保护部办公厅
