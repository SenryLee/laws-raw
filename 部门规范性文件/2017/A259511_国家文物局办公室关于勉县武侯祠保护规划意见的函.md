# 国家文物局办公室关于勉县武侯祠保护规划意见的函

办保函〔2017〕1427号

陕西省文物局：

你局《关于呈报勉县武侯祠保护规划的请示》（陕文物字〔2017〕74号）收悉。经研究，我局意见如下：

一、所报规划前期研究不足，体例和内容与《全国重点文物保护单位保护规划编制要求》存在一定差距，我局暂不同意勉县武侯祠保护规划。

二、所报规划应做以下必要修改和完善：

（一）进一步加强勉县武侯祠的历史研究，说明勉县武侯祠与墓的关联，研究明代勉县武侯祠迁建的历史过程，补充分析武侯祠与原勉县县城的历史关系。

（二）进一步梳理文物本体构成，完善现状评估。细化保护范围内非文物建筑的评估内容，明确其建造年代、形式、合法性等内容，细化建设控制地带内的环境评估。

（三）合理调整保护区划，完善管理规定。保护范围应考虑武侯祠原有历史格局；注意建设控制地带管理规定的有效性和可操作性，严格控制建筑高度。

（四）增强保护措施与评估内容和结论的对应性。合理制定环境整治措施。细化环境整治目标、高度设定、风貌要求等内容。应重视对武侯祠中轴线景观视廊的保护，适当控制南侧广场和东侧停车场的规模。

（五）进一步梳理、规范规划文本和图纸。

三、请你局指导有关单位，根据上述意见对勉县武侯祠保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月26日
