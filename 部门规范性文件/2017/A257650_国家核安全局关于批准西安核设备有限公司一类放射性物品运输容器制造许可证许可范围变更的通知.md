# 国家核安全局关于批准西安核设备有限公司一类放射性物品运输容器制造许可证许可范围变更的通知

## 关于批准西安核设备有限公司一类放射性物品运输容器制造许可证许可范围变更的通知

国核安发〔2017〕284号

西安核设备有限公司:

你公司《关于放射性物品运输容器制造许可证取证申请的请示》（西核安发〔2014〕56号）收悉。

根据《放射性物品运输安全管理条例》及其配套规章《放射性物品运输安全许可管理办法》的相关要求，我局对你公司提交的关于CNSC乏燃料运输容器制造许可申请进行了审查，认为你公司在CNSC乏燃料运输容器制造方面已具备法规所要求的各项能力，批复如下：

一、同意你公司一类放射性物品运输容器制造许可证（国核安证字第1635号，以下简称制造许可证）的许可范围增加“CNSC乏燃料运输容器，CN/058/B(U)F-96(NNSA)”。

二、CNSC乏燃料运输容器制造应严格按照设计要求进行检验和试验。

三、制造许可证其余内容不变。

国家核安全局

2017年11月14日
