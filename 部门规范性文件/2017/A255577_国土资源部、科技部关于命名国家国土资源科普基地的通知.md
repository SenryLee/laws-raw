# 国土资源部、科技部关于命名国家国土资源科普基地的通知

## 国土资源部　科技部关于命名国家国土资源科普基地的通知

国土资发〔2017〕106号

各省、自治区、直辖市国土资源主管部门、科技厅（委、局），新疆生产建设兵团国土资源局、科技局，各有关单位：

为贯彻落实《中华人民共和国科学技术普及法》和《全民科学素质行动计划纲要》，加强国土资源科普基础设施建设，国土资源部分四批命名建设了176个国土资源科普基地（以下简称“科普基地”）。按照《国土资源科普基地推荐及命名暂行办法》，2012年、2014年和2017年分别对前三批科普基地进行了评估，北京房山世界地质公园等32个科普基地被评估为优秀。根据《“十三五”国家科技创新规划》推进国家特色科普基地建设的要求，为充分发挥优秀科普基地的引领示范作用，国土资源部、科技部将32个优秀科普基地命名为“国家国土资源科普基地”。

请获得“国家国土资源科普基地”称号的单位，创新科普手段，提升科普服务能力，面向全国发挥科普基地引领示范作用，全面推进国土资源科普工作社会化、群众化、经常化，为提高全民国土资源科学素养，提升国土资源事业公众认知度做出新的更大贡献。

2017年9月4日

附件：国家国土资源科普基地名单
