# 国家文物局关于在碧水寺摩崖造像保护范围内进行绵阳市东原大桥接线工程二期项目的意见

## 关于在碧水寺摩崖造像保护范围内进行绵阳市东原大桥接线工程二期项目的意见

办保函〔2017〕487号

四川省文物局：

你局《关于报送〈绵阳市东原大桥接线工程二期项目工程设计方案〉的请示》（川文物〔2017〕13号）收悉。经研究，我局意见如下：

一、所报项目位于全国重点文物保护单位碧水寺摩崖造像保护范围内，对文物安全和景观风貌影响较大，方案深度不够，我局暂不同意该项目。

二、对所报方案提出以下修改意见：

（一）进一步明确文物分布范围、工程范围以及拟建项目与文物本体的距离和空间关系。补充碧水寺摩崖造像保护范围的管理规定和具体控制要求、文物保护区划与工程范围的叠加图。

（二）应客观论证在碧水寺摩崖造像保护范围内选线建设的必要性，详细说明拟建区域内文物分布数量和保存现状，并按照文物保护要求进一步调整拟建项目的选线、规模、外观等。

（三）充分考虑工程建设对文物安全的影响，制定必要的文物保护措施和应急预案，确保文物安全。

（四）调整文物影响评估报告编制思路，客观评估工程建设对文物安全和景观环境的影响，准确绘制视线廊道分析图，研提方案调整建议，增强文物影响评估报告的针对性、科学性和有效性。

三、请你局组织相关单位根据所提意见，对项目方案进行修改完善后，按程序另行报批。

专此函。

国家文物局

2017年4月21日
