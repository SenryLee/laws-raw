# 中华人民共和国海关总署对十二届全国人大五次会议第7789号建议的答复

郑维勇代表：

您在十二届全国人大五次会议上提出的《关于设立遵义新舟机场航空口岸的建议》（发展规划、建设项目和综合经济类第7789号）收悉。经研究并商中央编办、公安部、质检总局，现答复如下：

我署作为国家口岸主管部门高度重视内陆地区外向型经济发展，积极支持在符合条件的机场设立航空口岸。根据国家口岸整体布局，我们在牵头制定《国家口岸发展“十三五”规划》（以下简称《规划》）时，已将遵义机场列入。建议地方政府按照《规划》中口岸开放审理制度，积极培育遵义新舟机场航运市场，并进一步完善口岸查验基础设施和条件，待相关指标达到国家规定条件标准后，我们将予以启动审理程序。

关于口岸查验单位人员编制问题，中央编办表示：2010年6月印发实施的《口岸检查检验机构设置和编制管理办法》（中央编办发〔2010〕62号），对口岸查验机构设置、人员编制管理、审批程序以及管理权限等方面做出了具体明确规定。本届政府明确财政供养人员只减不增，对机构编制工作提出了新的要求。关于遵义机场开放涉及的口岸查验人员编制问题，将在日后开放办理中根据贵州省政府的具体请求统筹研究。

感谢您对我们工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

附件：代表建议办理和答复征求意见表（略）

海关总署
