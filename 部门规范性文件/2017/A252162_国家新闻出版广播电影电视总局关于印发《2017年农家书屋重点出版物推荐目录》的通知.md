# 国家新闻出版广播电影电视总局关于印发《2017年农家书屋重点出版物推荐目录》的通知

## 关于印发《2017年农家书屋重点出版物推荐目录》的通知

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局：

为加强农家书屋维护使用，推进农家书屋提质增效，推动全民阅读活动，指导各地做好2017年农家书屋出版物补充更新工作，在广大农村为党的十九大胜利召开营造出良好的文化氛围，国家新闻出版广电总局制定了《2017年农家书屋重点出版物推荐目录》（以下简称《2017年推荐目录》）。现印发给你们，并将有关事项通知如下：

一、关于《2017年推荐目录》的制定

1.《关于推荐2017年农家书屋重点出版物的通知》（新广出办发〔2017〕47号）下发后，共有485家图书出版单位选送图书3317种，103家音像出版单位选送音像制品和电子出版物440种，24家出版单位选送少数民族文字出版物873种。根据《2017年农家书屋重点出版物推荐目录评审办法》，总局组织专家共评选出图书1190种、音像制品和电子出版物150种、少数民族文字出版物422种、报纸31种、期刊148种列入《2017年推荐目录》。同时，中宣部办公厅和总局办公厅公布的“2017年主题出版重点出版物”、“2017年向全国青少年推荐的百种优秀出版物”全部列入《2017年推荐目录》。

2.《2017年推荐目录》图书部分按政经、科技、文化、医卫生活、少儿、其他分为6类，每类中按照出版者前缀排序；报纸、期刊按照刊号排序；音像制品和电子出版物按社科、文艺、教育、科技分为4类，每类中按照出版单位汉语拼音排序。为方便基层选书，总局将入选图书的内容简介以及封面、版权页、目录、试读页的图片制成光盘随《2017年推荐目录》下发（《2017年推荐目录》可在中国农家书屋网www.zgnjsw.gov.cn查询下载）。

二、关于《2017年推荐目录》的执行

（一）强化资金保障，落实好农家书屋补充更新标准

各级新闻出版广电行政部门要认真贯彻《公共文化服务保障法》，严格执行《中央补助地方公共文化服务体系建设专项资金管理暂行办法》（财教〔2015〕527号）的相关规定，用好专项资金，并积极争取地方财政资金支持。确保每个农家书屋补充图书不少于60种，提高农家书屋的配书质量；报刊、音像制品和电子出版物可由各地根据实际情况补充一定数量；对开展延伸服务的农家书屋，在补充更新数量上要适当倾斜；对报纸投送周期超过5天的边远地区行政村，应通过农家书屋数字化建设实现报纸的及时有效更新，鼓励网络不通达地区建设卫星数字农家书屋。

（二）匹配群众需求，强化推荐目录刚性执行

各级新闻出版广电行政部门要围绕迎接宣传贯彻党的十九大这条主线，配好配齐党的十九大文件文献和迎接宣传贯彻十九大主题出版物，加大少儿类图书和优秀畅销书配备比例，鼓励少数民族地区农家书屋配备双语出版物，更好地发挥好农家书屋重要的文化平台和思想主阵地作用。要不断优化农家书屋出版物供给方式，广泛征求基层意见，探索制定多套采购目录，提高配书的差异化和针对性，逐步建立“按需制单、百姓点单”模式。在农家书屋补充更新的出版物中，《2017年推荐目录》列入的品种和数量比例不得低于50%，同时本省（区、市）版出版物比例不得超过30%。各省（区、市）新闻出版广电局要加强统筹指导，及时将《2017年推荐目录》下发至所辖各市县，对市县采购目录是否符合总局要求认真审核、严格把关。

（三）规范政府采购，确保政府惠民项目合理透明公开

各级新闻出版广电行政部门要严格执行《中华人民共和国政府采购法实施条例》，以合理的图书印张价格为依据，避免因采购价格过高或过低而损害群众利益。要加大信息公开力度，通过中国农家书屋网、本单位门户网站和政府采购网站及时公布政府采购工作信息，接受社会监督。在采购中不得擅自变更已列入目录的品种，每个农家书屋要留存出版物配送清单，以备查验，要确保配送单位将补充图书开包上架，投入使用。

（四）加强监督检查，严肃查处配书违规问题

各省（区、市）新闻出版广电局要切实履职尽责，切实保障资金使用效率和出版物质量，对补充工作由市县开展的地区，要以不折不扣地落实农家书屋出版物补充更新标准为抓手，加强监督检查，抓好工作落实，对不执行总局目录、补充更新不达标、采购程序不规范、劣质和库存图书进书屋等问题严肃查处并通报批评。

各地要在2017年12月31日前完成本年度农家书屋出版物补充配送工作。总局将对各地工作开展情况进行督查和考核。请各省（区、市）新闻出版广电局在本辖区农家书屋出版物采购目录确定后20个工作日内将目录报总局印刷发行司备案，在配送工作完成后20个工作日内书面报送农家书屋补充更新工作完成情况报告。
