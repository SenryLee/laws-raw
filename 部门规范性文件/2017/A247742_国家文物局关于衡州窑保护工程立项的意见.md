# 国家文物局关于衡州窑保护工程立项的意见

## 关于衡州窑保护工程立项的意见

办保函〔2017〕70号

湖南省文物局：

你局《关于审批衡州窑保护工程立项的请示》（湘文物报〔2016〕208号）收悉。经研究，我局意见如下：

一、该窑址开展大规模工程干预的必要性不足，暂不同意衡州窑保护工程立项。

二、应进一步完善对窑址的现状勘察和分析，梳理保护工程对象，明确开展工程所具备的考古工作基础，论证实施大规模工程干预的必要性，如确有抢险加固必要的，应严格控制工程范围，并按程序另行报批。

三、请你局指导立项报告编制单位，根据上述意见对所报立项报告做进一步修改和完善，经你局核准后，按程序另行报批。

国家文物局

2017年2月8日
