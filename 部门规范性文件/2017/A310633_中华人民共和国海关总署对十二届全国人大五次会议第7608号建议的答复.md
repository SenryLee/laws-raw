# 中华人民共和国海关总署对十二届全国人大五次会议第7608号建议的答复

冯玉臻代表：

您在十二届全国人大五次会议上提出的《关于给予敖伦布拉格国际物流园区支持政策的建议》（流通、旅游和服务类第7608号）收悉。经认真研究，现答复如下：

一、关于对敖伦布拉格国际物流园区口岸服务区赋予保税功能，可通过申请设立海关特殊监管区域或保税监管场所实现。

设立海关特殊监管区域由地方省级政府提出报国务院审批，我署为牵头审核报批和管理部门。根据《国务院关于促进海关特殊监管区域科学发展的指导意见》（国发〔2012〕58号）的精神和要求，新设海关特殊监管区域统一为综合保税区，综合保税区具备保税加工、保税物流和保税服务等功能。设立海关特殊监管区域应符合有利于实施国家区域发展战略规划、有利于中西部地区承接产业转移、有利于海关特殊监管区域整合优化以及确实有外向型大项目亟待进驻的原则，且需符合《海关特殊监管区域设立审核办法》的相关规定。

保税监管场所中的保税仓库、保税物流中心（A型）和保税物流中心（B型）都可实现货物的保税功能，现以上3种保税监管场所的设立审批已转为行政许可项目，根据《中华人民共和国行政许可法》及《中华人民共和国海关对保税仓库及所存货物的管理规定》（海关总署令第105号，海关总署令第 227号修订）、《中华人民共和国海关对保税物流中心（A型）的暂行管理办法》（海关总署令第129号，海关总署令第227号修订）和《中华人民共和国海关对保税物流中心（B型）的暂行管理办法》（海关总署令第130号，海关总署令第227号修订）的相关规定，3种保税监管场所的设立应由经营企业按照相关规定向当地主管海关或直属海关提出书面申请，直属海关或海关总署按照行政许可相关程序办理。

二、关于“恳请国家海关总署、质检总局支持实行‘乌力吉口岸－敖伦布拉格国际物流园区’的联动监管模式，将乌力吉口岸的主要服务功能布局在敖伦布拉格国际物流园区，口岸仅保留必须布设于国境线的现场功能，如进口货物称重、施封，出口货物放行以及边检功能”，若该口岸实际存在安全准入查验需求，应在相应环节保留安全准入查验功能。

感谢您对我们工作的关心和支持，并欢迎继续对我们的工作提出宝贵意见和建议。

海关总署

2017年7月11日
