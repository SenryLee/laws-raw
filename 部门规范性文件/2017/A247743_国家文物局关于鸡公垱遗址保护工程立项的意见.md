# 国家文物局关于鸡公垱遗址保护工程立项的意见

## 关于鸡公垱遗址保护工程立项的意见

办保函〔2017〕97号

湖南省文物局：

你局《关于审批鸡公垱遗址抢救性保护工程立项的请示》（湘文物报〔2016〕207号）收悉。经研究，我局意见如下：

一、暂不同意鸡公垱遗址保护工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）深化遗址现状勘察，进一步明确遗址保存现状和现存的主要问题，说明拟实施工程对象、范围和工程性质，论证工程实施的必要性。

（二）应进一步评估遗址展示利用前景，并根据需求科学安排遗址保护、环境整治和展示利用工作。

三、请你局指导立项报告编制单位，根据上述意见对所报立项报告做进一步修改和完善，经你局核准后，按程序另行报批。

国家文物局

2017年2月8日
