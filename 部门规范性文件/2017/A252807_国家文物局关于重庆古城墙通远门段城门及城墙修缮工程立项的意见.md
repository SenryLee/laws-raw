# 国家文物局关于重庆古城墙通远门段城门及城墙修缮工程立项的意见

## 关于重庆古城墙通远门段城门及城墙修缮工程立项的意见

办保函〔2017〕431号

重庆市文物局：

你局《关于审批全国重点文物保护单位重庆古城墙——通远门段城门及城墙修缮工程立项报告的请示》（渝文物〔2017〕2号）收悉。经研究，我局意见如下：

一、暂不同意重庆古城墙通远门段城门及城墙修缮工程立项。

二、对所报立项报告提出以下修改意见：

（一）加强现状勘察和研究，明确文物保存现状、病害情况等，分析说明城墙构造、材质、砌筑工艺等。同时，客观评估2004年修缮工程效果，进一步论证工程实施的必要性和可行性。补充城墙病害现状照片。

（二）应结合文物本体保存情况、周边建设现状和社区文化生活需要，科学确定保护展示措施，进一步明确保护技术路线，以现状整修为主，重点解决影响城墙结构安全的病害问题，避免过度干预。

（三）通远楼和桂香阁不属于全国重点文物保护单位重庆古城墙的文物构成，不应列入工程范围。

（四）应根据工程量合理编制经费预算，补充取费标准，细化各单项取费依据。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

四、请你局督促地方人民政府切实加强重庆古城墙日常保养和岁修工作，及时清理影响文物安全的植物，确保文物安全。

专此函。

国家文物局

2017年4月12日
