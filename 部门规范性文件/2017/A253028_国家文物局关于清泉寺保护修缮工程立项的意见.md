# 国家文物局关于清泉寺保护修缮工程立项的意见

## 关于清泉寺保护修缮工程立项的意见

办保函〔2017〕534号

辽宁省文物局：

你局《关于上报清泉寺保护修缮工程立项报告的请示》（辽文物〔2017〕1号）收悉。经研究，我局意见如下：

一、暂不同意清泉寺保护修缮工程立项。

二、所报立项报告应做以下必要的修改和完善：

（一）进一步论证开展修缮工程的必要性，区分日常保养维护与修缮工程内容，避免过度维修。

（二）加强现状勘察，加强禅房、焚帛炉的历史沿革和原形制的研究，明确工程措施依据。

（三）进一步梳理项目对象和实施范围，增强保护措施与项目内容的对应性。

（四）严格控制工程范围和规模，根据工程量进一步核准工程预算，补充预算依据，科学编制预算。

三、请你局根据上述意见组织相关单位对立项报告进行修改完善后，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的有关规定另行报批。

国家文物局
