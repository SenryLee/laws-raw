# 国家文物局关于须弥山石窟环境整治项目的意见

## 关于须弥山石窟环境整治项目的意见

办保函〔2017〕336号

宁夏回族自治区文物局：

你局《关于报送审批〈须弥山石窟保护性设施建设项目设计方案〉的请示》（宁文物发〔2017〕3号）收悉。经研究，我局意见如下：

一、所报项目的必要性和设计依据不足，工程量过大，我局暂不同意须弥山石窟环境整治项目。

二、所报方案应进行以下必要的修改和完善：

（一）应根据《须弥山石窟文物保护规划》要求和文物保护管理需要，科学评估现有道路、广场和管理用房的使用现状、主要问题，进一步论证保护性设施建设的必要性。补充《须弥山石窟文物保护规划》关于拟建项目的相关内容、保护范围管理规定和具体建设控制指标。

（二）不同意大规模维修盘山道路，应进一步明确维修地段，控制和压缩工程量，不影响使用的砂岩道路和红砖道路应尽量维持原状。松树洼至喇叭塔段道路应以现状维护为主，不宜全部拆卸重砌。应调整新建道路的使用材料，尽量采用与周边基岩色彩相近的石材。

（三）景区前广场地面维修应以局部剔补为主，不同意全部更换铺装材料。

（四）应核对《须弥山石窟文物保护规划》内容，进一步明确管理用房的整治措施，说明现状维修的必要性和依据，并按程序另行报批。

（五）进一步减小界桩尺寸，并根据文物保护需要合理调整布设间距。补充界桩布设图纸。

（六）应重新编制文物影响评估报告，客观、准确、科学地论证拟建项目对文物本体和环境风貌的影响，增强文物影响评估报告的针对性。

三、请你局组织有关单位根据上述意见，对所报方案进行修改、完善后，按程序另行报批。

专此函。

国家文物局

2017年3月27日
