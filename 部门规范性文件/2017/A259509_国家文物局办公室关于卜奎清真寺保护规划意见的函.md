# 国家文物局办公室关于卜奎清真寺保护规划意见的函

办保函〔2017〕1414号

黑龙江省文物局：

你局《关于卜奎清真寺保护规划的请示》（黑文管字〔2017〕11号）收悉。经研究，我局意见如下：

一、所报规划的体例和内容与《全国重点文物保护单位保护规划编制要求》存在较大差距，我局暂不同意卜奎清真寺保护规划。

二、所报规划应做以下必要修改和完善：

（一）进一步明确规划目标和需要解决的核心问题。梳理保护对象，深化历史格局分析，明确清真寺与城市的关系。

（二）完善现状评估。应分别评估文物建筑和非文物建筑；客观评估文物周边建筑环境，分析其对文物本体及环境的影响。

（三）合理调整保护区划，完善管理规定。建议保护区划设置为保护范围和建设控制地带两级。合理制定利用措施，加强对大型宗教活动的管理。

（四）明确文物管理使用单位和文物主管部门的责权。加强与齐齐哈尔历史文化名城等相关规划的衔接。

（五）进一步梳理、规范规划文本和图纸。

三、请你局指导有关单位，根据上述意见对卜奎清真寺保护规划进行全面、认真的修改完善，按程序另行报批。

国家文物局办公室

2017年12月26日
