# 环境保护部办公厅、科技部办公厅、商务部办公厅关于发布国家生态工业示范园区复查评估结果的通知

## 关于发布国家生态工业示范园区复查评估结果的通知

环办科技函[2017]248号

北京经济技术开发区，上海金桥出口加工区，无锡新区（高新技术产业开发区），烟台经济技术开发区，上海市莘庄工业区，广州开发区，张家港保税区暨扬子江国际化学工业园，扬州经济技术开发区，潍坊滨海经济开发区，昆山经济技术开发区，日照经济技术开发区：

根据《国家生态工业示范园区管理办法》和《关于开展国家生态工业示范园区复查评估的通知》（环办科技函〔2016〕152号）要求，本着公开、公平、公正的复查评估原则，国家生态工业示范园区建设协调领导小组办公室组织专家对部分园区开展了复查评估工作。现将评估结果通知如下：

一、本次复查评估的11家园区自命名以来，通过采取企业间废物交换与利用、物质和能量梯级利用以及基础设施共享等措施，积极构建以资源能源高效利用、废物循环利用、污染物减量排放为主要特征的绿色、循环、低碳的工业共生体系，取得较好的生态建设成效。11家园区全部通过复查评估（评估结果见附件）。

二、评估结果排名靠前的园区，生态建设成效突出。园区不断优化产业结构，安排专项资金支持企业进行污染减排技术改造，单位工业增加值的综合能耗、新鲜水耗、废水产生量等指标持续改善。园区以物联网技术为核心，搭建再生资源公共服务平台，推动固体废物回收向精细化转变，园区单位工业增加值固体废物产生量仅0.02吨/万元，远低于《综合类生态工业园区标准》（HJ/T274-2009）规定的0.1吨/万元。这些成功做法值得其他园区认真学习，加以借鉴。

三、复查评估中也发现个别园区存在一些问题。有的园区高耗能、高耗水企业数量多，产业结构不合理，多项指标不进反退。有的园区不注重生态工业链构建，单位工业增加值的新鲜水耗、COD排放量等持续上升。希望复查发现上述问题的园区，认真对待复查评估结果，坚持问题导向，针对评估发现的问题，深入查找原因，认真研究解决对策，科学制定整改方案，切实完成整改任务，并将相关落实情况纳入后续年度评价报告。

请参与本次复查评估的11家园区，认真研究专家组意见，并将其作为进一步改进园区工作的依据，不断提升园区绿色与可持续发展水平，充分发挥国家生态工业示范园区的引领和示范作用。
