# 农业部发展计划司关于请报送国家现代农业产业园申请创建基本情况的函

## 关于请报送国家现代农业产业园申请创建基本情况的函

农计[示范][2017]20号

各省、自治区、直辖市农业（农牧、农村经济）厅（局、委、办）、新疆生产建设兵团农业局、黑龙江省农垦总局、广东省农垦总局：

为贯彻落实《农业部财政部关于开展国家现代农业产业园创建工作的通知》（农计发〔2017〕40号）有关精神，全面了解拟申请创建国家现代农业产业园的有关情况，请你省（区、市）组织有关单位如实填写《2017年国家现代农业产业园申请创建基本情况表》，并于2017年5月3日（周三）报送至我部发展计划司示范区指导处（含电子版，发送至sfqglbgs@agri.gov.cn）。

附件：2017年国家现代农业产业园申请创建基本情况表

联系人：矫健
