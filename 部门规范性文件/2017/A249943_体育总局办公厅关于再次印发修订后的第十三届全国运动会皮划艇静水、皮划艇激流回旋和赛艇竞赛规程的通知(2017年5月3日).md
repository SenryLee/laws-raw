# 体育总局办公厅关于再次印发修订后的第十三届全国运动会皮划艇静水、皮划艇激流回旋和赛艇竞赛规程的通知(2017年5月3日)

## 体育总局办公厅关于再次印发修订后的第十三届全国运动会皮划艇静水、皮划艇激流回旋和赛艇竞赛规程的通知

各省、自治区、直辖市、新疆生产建设兵团体育局，中央军委政治工作部宣传局文化处、中央军委训练管理部训练局军事体育处，有关行业体协，水上运动管理中心：

为做好东京2020年奥运会备战工作，经研究，决定第十三届全国运动会增加皮划艇静水200米女子单人划艇和500米女子双人划艇、皮划艇激流回旋女子单人划艇、赛艇2000米女子四人单桨无舵手共4个小项。

根据以上项目调整，现将再次修订后的项目竞赛规程印发给你们，请遵照执行。体育总局办公厅2017年3月21日公布的修订后的《第十三届全国运动会皮划艇静水、皮划艇激流回旋、赛艇竞赛规程》（体竞字[2017]37号）废止。

体育总局办公厅

2017年5月3日
