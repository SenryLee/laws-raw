# 国家文物局关于郑义门古建筑群之郑氏宗祠环境整治设计方案的意见

## 关于郑义门古建筑群之郑氏宗祠环境整治设计方案的意见

办保函〔2017〕201号

浙江省文物局：

你局《关于要求审批郑义门古建筑群之郑氏宗祠保护区划内实施环境整治工程的请示》（浙文物发〔2017〕13号）收悉。经研究，我局意见如下：

一、暂不同意郑义门古建筑群之郑氏宗祠保护区划内环境整治设计方案。

二、所报方案需在以下方面做出修改：

（一）补充郑氏宗祠保护区划内建设项目控制要求，进一步明确该工程项目与郑氏宗祠保护区划的具体位置关系，并据此调整修改设计方案。

（二）综合改造难度、环境风貌影响等因素，进一步论证楼房降低层高的可行性。

（三）西入口广场不宜采用规整的石板。街面道路铺装应考虑传统街巷道路做法，特别是注意中线石条铺装两侧的石块铺法。

（四）补充文物环境影响评估报告。

三、请你局指导项目单位根据上述意见对设计方案进行必要的调整和完善，另行报批。

专此。

国家文物局

2017年3月3日
