# 中华人民共和国农业部公告第2501号——关于批准国家禽流感参考实验室推荐的H5亚型高致病性禽流感疫苗生产毒种变更并发布“重组禽流感病毒灭活疫苗（H5N1亚型，Re-10株）”等三种兽药产品试行规程、质量标准、说明书和标签的公告

## 中华人民共和国农业部公告

第2501号

根据《兽药管理条例》和《兽药注册办法》规定，经审核，批准国家禽流感参考实验室推荐的H5亚型高致病性禽流感疫苗生产毒种变更，并发布“重组禽流感病毒灭活疫苗（H5N1亚型，Re-10株）”“重组禽流感病毒H5亚型二价灭活疫苗（Re-8株+Re-10株）”及“重组禽流感病毒H5亚型三价灭活疫苗（Re-7株+Re-8株+Re-10株）”等三种兽药产品试行规程、质量标准、说明书和标签，自发布之日起执行。

特此公告。

附件：1.试行规程（略）

2.质量标准（略）

3.说明书和标签

农业部

2017年3月20日
