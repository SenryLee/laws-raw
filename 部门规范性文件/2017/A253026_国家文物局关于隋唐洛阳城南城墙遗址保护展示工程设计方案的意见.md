# 国家文物局关于隋唐洛阳城南城墙遗址保护展示工程设计方案的意见

## 关于隋唐洛阳城南城墙遗址保护展示工程设计方案的意见

办保函〔2017〕526号

河南省文物局：

你局《关于上报隋唐洛阳城南城墙遗址保护展示工程设计方案的请示》（豫文物〔2017〕135号）收悉。经研究，我局意见如下：

一、暂不同意隋唐洛阳城南城墙遗址保护展示工程设计方案。

二、所报方案应做以下必要的修改和完善：

（一）进一步研究并明确隋唐洛阳城南城墙遗址的价值。建议开展必要的价值评估，认真分析南城墙遗址在隋唐洛阳城遗址价值阐释中的地位和作用，并据此合理确定展示定位、目标与方式方法等。同时，应开展必要的展示前景评估。

（二）补充说明隋唐洛阳城南城墙遗址的分布及保存状况。

（三）不同意进行覆罩、露明、模拟或木构架标识展示。应重新开展展示设计，将隋唐洛阳城南城墙遗址作为整体来考虑，以地表标识展示和绿化展示为主，重点展示其走向、规模、规制等，并严格控制工程量。同时，可考虑开展必要的辅助标识系统设计。

（四）建议将隋唐洛阳城南城墙遗址展示与周边区域的城市设计统筹考虑，鼓励建设具有文化内涵的城市公共空间或城市绿地。

（五）应补充总体效果图，并进一步校核工程预算，科学编制预算，严格控制建设成本，充分考虑后续维护成本。

三、请你局指导方案设计单位联合专业考古研究单位，按照上述意见对方案进行修改和完善，经你局核准后按程序另行报批。

国家文物局

2017年5月8日
