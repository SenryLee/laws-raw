# 国家文物局关于政协十二届全国委员会第五次会议第3919号（文化宣传类314号）提案会办意见的函

## 关于政协十二届全国委员会第五次会议第3919号（文化宣传类314号）提案会办意见的函

办保函〔2017〕629号

四川省人民政府办公厅：

现就高晓笛等29位委员提出的“关于统筹规划 妥善保护四川省自贡市盐商历史文化遗存的提案”，提出以下会办意见：

盐业是我国古代手工业经济发展的重要分支，与盐商相关的不可移动文物，不仅具有重要的历史、艺术和科学价值，还具有重要的社会价值和研究价值。四川自贡是我国盐业发展的重要区域，在长达千年的历史发展过程中留存了大量的历史文化遗产,对于展示盐业发展历程、研究我国古代工业经济以及自贡地域文化具有重要意义。

我局一直以来十分重视自贡盐商相关文物的保护管理工作。吉成井盐作坊遗址、东源井古盐场被国务院公布为全国重点文物保护单位，贡井胡慎怡堂被列为省级文物保护单位，三多寨胡慎怡堂被列为区级文物保护单位。同时，安排专项经费用于相关文物的规划编制等工作，并督促地方加强文物日常管理和养护工作，有效改善了文物的保存状况。

针对高晓笛等委员提出的贡井胡氏民居保护区划不合理、盐商文物有待摸底调查等问题和提议，建议你省组织专家论证，深入分析贡井胡慎怡堂现行保护区划的实施情况和主要问题，进一步完善相关的保护管理工作。建议地方人民政府根据第三次全国文物普查成果，将具有重要历史、艺术和科学价值的盐商相关不可移动文物及时公布为相应级别的文物保护单位，依法保护，落实“四有”工作，确保文物安全。我局将督促指导地方有关部门加强日常管理，对于保存现状堪忧和存在险情的文物及时进行保护维修，切实改善盐商相关文物的保存现状，共同保护好珍贵文化遗产。

关于成立盐商历史博物馆问题，四川已建有自贡市盐业历史博物馆，建议在现有基础上增加有关盐商历史及文物展览、展示，加强有关盐业历史资源的整合利用，发挥应有的文化传承作用。

以上意见供参考。

国家文物局

2017年5月22日
