# 国家文物局关于青莲阁整体平移工程项目意见的函

## 关于青莲阁整体平移工程项目意见的函

办保函〔2017〕650号

山东省文物局：

你局《关于呈报青莲阁整体平移工程方案及可行性研究报告的请示》（鲁文发〔2017〕42号）收悉。经研究，我局提出如下意见：

一、经查，所报工程存在未经批准、擅自施工的行为，须立即停工整改，恢复文物原貌。

二、所报修改后的方案必要性论述不足，方案设计思路不当，我局暂不同意青莲阁整体平移工程项目，并提出以下修改、完善意见：

（一）深入研究中华人民共和国成立以来泗河两次洪水溃堤的原因，科学分析泗河青莲阁段防洪压力，补充论证项目实施的必要性、可行性。

（二）科学、准确开展文物影响评估，调整方案思路，尽可能实施原址保护，确保文物安全。

（三）坚持最小干预原则，细化青莲阁原址加固维护措施和操作要求。同时，应合理布置堤线、确定堤距、选择堤型，尽量减小青莲阁段堤坝的高度与宽度，研提堤坝青莲阁段结构处理措施，在满足防洪需求的条件下妥善保护文物本体及环境风貌。

（四）补充50年一遇洪水水面高度测算依据以及坝体高度宽度的计算依据，历史上洪水漫堤处与青莲阁的位置关系图，河堤加固前后青莲阁与河堤、河流位置剖面图，青莲阁与金口坝的景观视廊分析图。

三、请你局组织有关单位根据上述意见和我局《关于青莲阁整体平移工程项目的意见》（办保函〔2017〕125号），对所报方案进行修改、完善后，按程序另行报批。

四、请你局督促地方人民政府认真落实《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号），明确责任、严肃整改，正确处理文物保护、泗河综合开发和地方社会经济发展的关系，切实保护青莲阁文物本体及周边环境的真实性、完整性以及青莲阁与泗河的空间历史关系。相关整改情况由你局核实后尽快上报我局。

国家文物局

2017年5月24日
