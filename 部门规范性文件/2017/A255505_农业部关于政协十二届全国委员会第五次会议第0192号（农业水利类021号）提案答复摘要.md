# 农业部关于政协十二届全国委员会第五次会议第0192号（农业水利类021号）提案答复摘要

## 政协十二届全国委员会第五次会议第0192号（农业水利类021号）提案答复摘要

近年来，国家高度重视农膜污染治理，采取积极有效的应对措施，不断加大农田地膜污染防治工作力度。

一是支持科技型中小企业发展。为鼓励企业加大研发投入，财政部、税务总局、科技部印发了《关于提高科技型中小企业研究开发费用税前加计扣除比例的通知》，将科技型中小企业为开发新技术、新产品、新工艺发生的研究开发费用，在按规定据实扣除的基础上，在企业所得税前加计扣除比例由50%提高至70%。中国银监会于2012年印发了《绿色信贷指引》，符合绿色信贷条件的食品安全类农业、循环农业和生态农业贷款等可享受相应政策支持。下一步，财政部将会同有关部门研究完善相关政策文件，推动科技型中小企业发展。

二是加强可降解膜标准化建设。国家标准委已经下达《全生物降解农用地膜覆盖薄膜》和《复合型双降解生态地膜》2项国家标准研制项目。其中，《全生物降解农用地膜覆盖薄膜》已基本完成技术指标论证，预计于2018年上半年发布实施。《复合型双降解生态地膜》正在征求有关方面意见。下一步，相关部门将进一步加强生物降解地膜标准化工作。

三是加强农膜回收利用。2017年，印发了《农膜回收行动方案》，提出在新疆等地启动建设100个地膜污染治理示范县，通过2—3年的时间，率先实现地膜基本资源化利用。2016年中央财政安排10亿元，继续支持河北、新疆等10个省（自治区）开展以地膜覆盖为主的旱作农业技术推广工作。2015年以来，我部在新疆等13个重点用膜省份开展全生物可降解地膜和非降解地膜对比试验，筛选应用效果好的可降解地膜。下一步，我部将会同财政部在深入调研基础上，进一步完善项目实施机制和资金使用方式，加大废旧地膜回收利用力度，鼓励地膜产业技术创新，开展新型多功能地膜、可降解地膜等新产品、新材料试验示范和推广应用，提高政策效益和资金使用效率。
