# 国家文物局关于儋州故城抢险加固工程立项的意见

## 关于儋州故城抢险加固工程立项的意见

办保函〔2017〕94号

海南省文化广电出版体育厅：

你厅《关于申请儋州故城抢险加固工程立项的请示》（琼文发〔2016〕229号）收悉。经研究，我局意见如下：

所报儋州故城抢险加固工程应当纳入我局此前已批准的儋州故城武定门、镇海门本体加固保护及周边环境整治工程（文物保函〔2015〕356号）中统筹考虑，不必单独申报立项。同时，应根据台风损害情况，对原定的工程技术措施进行必要的优化和调整，以增强针对性，确保文物安全。

国家文物局

2017年2月8日
