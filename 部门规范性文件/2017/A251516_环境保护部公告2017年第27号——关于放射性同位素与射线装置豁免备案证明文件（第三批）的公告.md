# 环境保护部公告2017年第27号——关于放射性同位素与射线装置豁免备案证明文件（第三批）的公告

## 环境保护部公告

2017年第27号

## 关于放射性同位素与射线装置豁免备案证明文件（第三批）的公告

根据《放射性同位素与射线装置安全和防护管理办法》（环境保护部令 第18号）第五十四条的相关规定，我部将各有关省份已获得豁免备案证明文件的活动或活动中的射线装置、放射源或者非密封放射性物质(第三批)予以公告(详细内容见附件1和2)。

经我部公告的活动或活动中的射线装置、放射源或者非密封放射性物质，其豁免备案证明文书在全国有效，可不再逐一办理豁免备案证明文件。

附件：1.第三批已获各有关省份豁免备案证明文件的放射性同位素汇总表

2.第三批已获各有关省份豁免备案证明文件的射线装置汇总表

环境保护部

2017年6月12日
