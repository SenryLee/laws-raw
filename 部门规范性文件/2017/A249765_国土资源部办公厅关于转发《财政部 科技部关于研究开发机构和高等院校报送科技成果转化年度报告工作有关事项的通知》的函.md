# 国土资源部办公厅关于转发《财政部 科技部关于研究开发机构和高等院校报送科技成果转化年度报告工作有关事项的通知》的函

国土资厅函〔2017〕609号

中国地质调查局：

为落实《中华人民共和国促进科技成果转化法》和《国务院关于印发实施<中华人民共和国促进科技成果转化法>若干规定的通知》（国发〔2016〕16号），财政部、科技部印发了《关于研究开发机构和高等院校报送科技成果转化年度报告工作有关事项的通知》（财科教〔2017〕22号），现转发给你单位。请组织局属研发机构按照文件要求填报年度科技成果转化报告，并在此基础上梳理形成局科技成果转化年度总结报告，于7月14日前正式报送部科技主管部门。

联系人及电话：徐浩 赵财胜 66558427 66558409

2017年4月18日
