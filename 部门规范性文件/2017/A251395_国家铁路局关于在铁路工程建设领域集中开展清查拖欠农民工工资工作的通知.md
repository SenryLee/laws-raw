# 国家铁路局关于在铁路工程建设领域集中开展清查拖欠农民工工资工作的通知

国铁工程监函〔2017〕16号

农民工为国家经济社会发展作出了巨大贡献。落实以人民为中心的发展思想，切实解决好欠薪问题，是党中央国务院实施更加积极就业政策、增加农民工打工收入、增进社会公平正义的重要举措。2月3日国务院召开常务会议，研究部署解决农民工工资拖欠问题。铁路工程建设领域是农民工务工较为集中的领域之一，为保障广大农民工切身权益，贯彻落实2月3日国务院常务会议精神，现将铁路工程建设领域清查拖欠农民工工资的有关事项通知如下：

一、立即组织开展清查拖欠农民工工资专项行动。一是发动铁路工程建设项目建设单位组织各施工总承包单位开展拖欠农民工工资自查（自查内容见附件1），并对自查情况及问题整改情况进行监督检查。二是重点抽查：铁路工程建设项目工程款是否按照合同约定及时足额拨付，建设项目是否按《国务院办公厅关于全面治理拖欠农民工工资问题的意见》（国办发〔2016〕1号，以下简称《意见》）要求建立工资保证金制度，施工总承包企业是否按《意见》要求在工程项目所在地银行开设农民工工资（劳务费）专用账户。三是铁路工程监管人员在近期履行工程监督检查或调查职责时，要结合清查专项行动，深入一线作业班组，面对面访谈施工作业人员，了解是否存在拖欠工程款和拖欠工资情况。

二、积极配合人社部门开展欠薪问题专项整治行动。一是对自查或抽查中发现的难以协调解决的欠薪问题，要及时移交当地人力资源社会保障部门依法处理。二是结合铁路工程建设市场秩序整治“三违”专项行动，对欠薪单位开展问题追溯，深入调查是否存在工程转包和违法分包行为，调查属实的要依法从快、从重处理。三是对存在工程款拖欠的铁路工程建设项目，按照“谁审批、谁监管”的原则通报有关项目审批部门和单位。

三、依法认真处理有关拖欠农民工工资的投诉举报。一是要按照《铁路工程建设投诉举报处理办法》（国铁工程监〔2016〕7号）规定，及时受理涉及铁路工程建设领域的拖欠农民工工资的投诉举报。二是对按规定受理的相关投诉举报要认真组织调查，查明欠薪事实，为被欠薪农民工“撑腰”。三是要积极协调有关建设单位或施工总承包企业的上级管理部门，由其督促欠薪单位尽早支付拖欠农民工工资。

四、努力落实有关欠薪治理的长效机制。一是鼓励铁路工程建设项目依法开展专业工程承包和劳务分包，施工承包企业应依法与农民工签订劳动合同。二是按《意见》要求，督促各铁路工程建设项目的施工总承包企业在施工现场醒目位置设立维权信息告示牌，明示项目建设管理基本信息、劳动用工相关规定、属地劳动保障监察投诉举报维权渠道等信息。三是铁路工程建设项目的建设单位应全面推行施工过程结算、工资专户管理和银行代发等制度，确保农民工拿到“辛苦钱”。四是建立拖欠工资“黑名单”制度，对列入名单的铁路工程施工企业，取消申报铁路优质工程奖资格，并按规定对其进行资质动态核查；情节严重的，建议住建部门降低其资质等级。

请各单位按照附件2格式于2017年3月5日前将拖欠工程款和农民工工资的清查情况报局工程监管司。
