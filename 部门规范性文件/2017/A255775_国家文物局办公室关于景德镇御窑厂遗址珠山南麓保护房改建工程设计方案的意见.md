# 国家文物局办公室关于景德镇御窑厂遗址珠山南麓保护房改建工程设计方案的意见

办保函〔2017〕1058号

江西省文物局：

你局《关于呈报〈景德镇御窑厂遗址珠山南麓保护房改建工程设计方案（修改稿三）〉的请示》（赣文物局字〔2017〕117号）收悉。经研究，我局意见如下：

一、暂不同意所报御窑厂珠山南麓遗址保护性设施建筑设计方案修改稿。

二、所报方案尚需做以下必要的修改和完善：

（一）充分吸收最新的考古工作成果，明确遗址分布范围，并据此合理确定保护性设施的规模和建筑基础的位置，确保文物安全。保护性设施的建筑基础应尽量采用桩基础，东侧及南侧宜采用开敞式设计，为后续工作预留余地和空间。

（二）补充评估御窑厂珠山南麓遗址保存所需环境条件，并在保护性设施设计中统筹考虑遗址保存环境需求。

（三）进一步调整保护性设施的具体设计，建议采用消隐的建筑设计手法，简化建筑风格，突出遗址本体内在关联及完整性，并注意与御窑厂考古遗址公园内现有景观环境以及其他设施的风格相协调。

（四）进一步完善保护性设施内部展示的具体设计，宜充分考虑遗址特点，增强拟采取展示方式方法的针对性和有效性，避免重复。

（五）进一步优化图纸表达，做到清晰、准确。

三、请你局指导方案设计单位，根据上述意见对所报方案作进一步修改和完善后，按程序另行报批。同时，应考虑遗址本体保护的相关需求，尽快提出具体的设计方案，按程序另行报批。

国家文物局办公室

2017年9月14日
