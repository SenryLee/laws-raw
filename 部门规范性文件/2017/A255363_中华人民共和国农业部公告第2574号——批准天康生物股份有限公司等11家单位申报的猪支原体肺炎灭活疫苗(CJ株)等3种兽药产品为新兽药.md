# 中华人民共和国农业部公告第2574号——批准天康生物股份有限公司等11家单位申报的猪支原体肺炎灭活疫苗(CJ株)等3种兽药产品为新兽药的公告

## 中华人民共和国农业部公告

第2574号

根据《兽药管理条例》和《兽药注册办法》规定，经审查，批准天康生物股份有限公司等11家单位申报的猪支原体肺炎灭活疫苗（CJ株）等3种兽药产品为新兽药，核发《新兽药注册证书》，并发布产品试行规程、质量标准、说明书和标签，自发布之日起执行。

特此公告。

附件：1.新兽药注册目录

2.试行规程（略）

3.质量标准（略）

4.说明书和标签

农业部

2017年8月31日
