# 国家林业局办公室关于做好2017年汛期安全生产工作的通知

办改字〔2017〕50号

各省、自治区、直辖市林业厅（局），内蒙古、吉林、龙江、大兴安岭、长白山森工（林业）集团公司，新疆生产建设兵团林业局，国家林业局各司局、各直属单位：

近年来，我国气象灾害多发频发，对安全生产造成较大影响。据预测，2017年我国极端气象水文事件仍有可能多发。为贯彻落实习近平总书记、李克强总理关于做好防灾减灾和安全生产工作的重要指示精神，严防自然灾害引发生产安全事故，按照国务院安全生产委员会的总体部署，现就做好汛期林业安全生产工作有关事项通知如下：

一、加强组织领导，及早安排部署

各地林业主管部门和国家林业局各有关司局、各有关直属单位要认真研判当前本地区、主管业务工作领域安全生产面临的形势，坚决克服麻痹大意和侥幸思想，进一步强化红线意识和底线思维，以高度责任感和使命感抓好林业安全生产工作。要切实加强组织领导，指定专门机构和人员负责汛期林业安全生产工作，主要负责同志要亲自安排部署，分管领导要亲自检查推动。要按照“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，针对本地区、主管业务工作领域安全生产工作特点，对自然灾害引发林业生产安全事故的风险进行全面分析和评估。要明确本地区、主管业务工作领域林业安全生产重点防范区域，进一步落实责任单位，科学制定防范应对方案和措施，并做到责任到岗到人。

二、切实突出重点，深入开展隐患治理

各地林业主管部门和国家林业局各有关司局、各有关直属单位要针对汛期强降雨、洪水、台风、泥石流、高温等灾害因素对林业安全生产威胁加大的风险，集中力量组织一次安全生产大检查。营林造林、国有林区、国有林场、自然保护区、森林公园、沙漠公园、湿地公园等业务主管司局和直属单位要按照“谁主管、谁负责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，切实履行好行业安全生产工作指导职责，组织指导和监督主管业务工作领域的检查督查。要紧紧抓住林区辖区内矿山、危化品、道路交通、建筑施工、消防等容易发生群死群伤的重点领域，深入开展安全隐患治理。对检查过程中发现的重大隐患和违法违规行为，要坚决依法责令停产停业整改。内蒙古、吉林、龙江、大兴安岭、长白山森工（林业）集团公司要进一步落实好企业安全生产主体责任，自觉接受属地监管，不断加强生产经营场所和设施设备的隐患排查治理，坚决杜绝冒险作业，遇有极端天气要及时停止作业，确保生产安全，确保人员安全。

三、强化应急准备，科学有效处置

各地林业主管部门和国家林业局各有关司局、各有关直属单位要密切与气象、海洋、国土资源、水利等部门的沟通联系，充分运用自然灾害预测预报成果，科学研判可能对林业安全生产带来的影响，及时、准确发布安全生产预警信息。要针对汛情特点，完善安全生产应急预案，组织开展经常性的应急演练，强化应急人财物保障。要指导和督促林业生产经营单位加强应急准备，强化对一线职工化解险情和自救互救的教育培训。要加强应急值守，落实领导干部带班、关键岗位24小时值班和事故信息报告制度。一旦发生事故险情，要及时报告并启动预案，妥善应对处置，将林业生产安全事故造成的损失和影响降到最低。对玩忽职守、疏于管理、责任不落实、人员不到位和抢险不及时而造成重大伤亡事故的，要依法依规严肃追究有关负责人的责任。

各地林业主管部门和国家林业局各有关司局、各有关直属单位要紧密结合自身工作实际，对汛期安全生产工作做出进一步安排部署，及时开展汛期安全自查自改，确保取得实实在在的成效，为党的十九大胜利召开营造良好的安全生产环境。

特此通知。

国家林业局办公室
