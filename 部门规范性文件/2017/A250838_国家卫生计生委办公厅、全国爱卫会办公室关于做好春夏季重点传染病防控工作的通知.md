# 国家卫生计生委办公厅、全国爱卫会办公室关于做好春夏季重点传染病防控工作的通知

## 关于做好春夏季重点传染病防控工作的通知

各省、自治区、直辖市卫生计生委、爱卫办，新疆生产建设兵团卫生局、爱卫办，中国疾控中心：

春夏季是手足口病、霍乱等肠道传染病以及疟疾、登革热等蚊媒传染病的高发季节，寨卡病毒病、黄热病等传染病输入风险持续存在，疫情防控形势依然严峻。为有效防控春夏季重点传染病的发生和流行，切实保护人民群众身体健康和生命安全，现就有关要求通知如下：

一、加强组织领导，提前部署防控工作

各地要认真贯彻落实全国卫生与健康大会精神，按照2017年全国卫生计生工作会议、全国疾病预防控制会议的统一部署，从保护人民群众生命健康的高度出发，重视春夏季重点传染病防控工作。要始终坚持预防为主的工作方针，关口前移，结合本地区传染病防控实际，研究制订切实可行的防控方案，明确防控工作的时间表和路线图，确保各项防控措施落在实处。要结合夏季洪涝等灾害多发的特点，提前谋划部署，做好应急值守和物资储备等工作。

二、推进联防联控，密切部门协作配合

各地要在当地党委和政府的统一领导下，主动加强与农业、教育、质检等部门合作，强化联防联控工作机制，健全部门间信息通报，落实各部门职责任务，形成防控工作合力。要协调农业部门做好动物免疫、病死畜禽无害化处理，落实人畜共患传染病源头治理。配合教育部门指导学校、托幼机构做好入学入托接种证查验、晨检和缺勤缺课登记报告，做好疫情苗头识别和风险研判，及时采取防控措施，防范校园传染病暴发疫情。配合质检部门做好口岸检疫查验、有害媒介生物消杀灭工作，防范传染病输入。

三、强化监测预警，依法科学防控疫情

各地要高度重视春夏季传染病监测预警工作，认真做好手足口病、登革热、流感样病例、不明原因肺炎、蚊媒密度等监测报告工作。加快推进国家致病菌识别网建设，提高霍乱等细菌性传染病早期发现和快速处置能力。“一带一路”沿线省份及边境地区要密切关注周边国家疟疾、寨卡病毒病等重点传染病疫情动态，加强相关信息的分析与利用，及时评估输入风险，做好防范和应对准备。出现传染病疫情后，各地疾控机构要依法依规迅速开展相关调查处置工作，落实早发现、早诊断、早报告、早治疗、早隔离措施，防止传染病疫情蔓延扩散。

四、加强培训指导，做好病例诊断救治

各地要有针对性地对各级医务人员,特别是基层医务人员开展专题培训，不断提高其对寨卡病毒病、登革热、手足口病等早期识别、诊断治疗等水平。各级各类医疗卫生机构要严格执行传染病预检分诊制度，认真做好疫情登记报告工作，加强发热门诊、肠道门诊、重症监护室等重点区域的院内感染控制，做好重症病例的集中收治，最大限度地减少重症和死亡病例发生。

五、加强群防群控，开展春夏季爱国卫生运动

各地要利用爱国卫生运动65周年的有利契机，按照全国统一部署，大力开展社会宣传和群众动员，形成新时期爱国卫生运动的新高潮。要充分发挥爱卫会统筹协调作用，紧密结合第29个爱国卫生月、卫生城镇创建和城乡环境卫生整洁行动等工作，集中统一组织开展专项活动，特别是要全面深入开展春夏季城乡环境卫生综合整治，切实做好农村改厕和粪便无害化处理，加强老城区、城乡结合部以及中小学校、托幼机构卫生管理，清理卫生死角，消除“四害”孳生地，集中开展灭鼠、灭蟑、灭蚊、灭蝇活动，从源头上预防和控制肠道传染病、虫媒传染病等春夏季传染病的发生流行。

六、加强健康宣教，提高居民防控意识

各地要将春夏季传染病防控作为健康教育与健康促进的重要内容，结合本地区当前传染病疫情形势，不断创新宣教形式，拓展宣教平台，有针对性地开展健康宣教工作。通过健康宣教，倡导强调“每个人是自己健康的第一责任人”的理念，强化个人健康意识，积极促进群众养成良好的卫生习惯，预防春夏季传染病的发生。要坚持依法及时准确公开发布传染病疫情及防控信息，密切关注舆情动态，加强舆论引导，及时回应社会关注，及时澄清不实传言，维护社会稳定和安全。

各地要切实增强做好春夏季传染病防控工作的使命感和责任感，落实春夏季传染病防控的属地责任、部门责任、单位责任和个人责任，坚持问题导向，补短板，重落实，确保各项工作扎实、高效、科学、有序推进。国家卫生计生委和全国爱卫办将适时对重点地区工作情况进行现场督导，总结推广成功经验，对于传染病防控不力的地区进行通报批评。
