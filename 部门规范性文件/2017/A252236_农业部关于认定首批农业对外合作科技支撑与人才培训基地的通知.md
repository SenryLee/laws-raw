# 农业部关于认定首批农业对外合作科技支撑与人才培训基地的通知

农外发〔2017〕2号

各省、自 治区、直辖市及计划 单列 市农业（ 农牧、 农村经济）、 农机、畜牧、兽医、农垦、农产品 加工、 渔业厅（局、 委、 办）， 新疆生产建设兵团 农业局：

为贯彻党中央、国务院关于促进农业对外合作的总体精神，落实农业对外合作部际联席会议、全国农业对外合作工作会议安排部署，建立农业走出去科技支撑服务体系，加强农业对外合作人才队伍建设，根据《农业部办公厅关于组织开展农业对外合作科技支撑与人才培训基地遴选试点工作的通知》（农办外〔2016〕3号），经组织申报、专家初评、现场答辩、实地复核、网上公示等程序，决定认定中国农业科学院海外农业研究中心等单位为首批农业对外合作科技支撑与人才培训基地（以下简称“基地”）。

各基地要发挥政策优势，按照各自功能定位，积极开展信息收集加工、技术孵化转移、现代农业展示、经验模式推广、人才培养培训等工作。省级农业行政主管部门要创造条件，支持基地建设和发展，做好基地运行的管理和服务，结合本地实际，加快推进农业对外合作科技支撑与人才培训工作。有关基地运行和工作开展情况，每半年向我部报送总结材料。

## 首批农业对外合作科技支撑与人才培训基地功能定位

一、中国农业科学院海外农业研究中心

核心任务是为农业决策提供支撑服务。面向全球，开展农业对外合作相关政策、技术、人文信息的采集、加工和发布等，为农业走出去提供咨询服务等。

二、中国热带农业科学院

面向中南半岛、非洲等重点地区，联合云南、广西等地科研院所，提供粮食和热带、亚热带特色农作物种植技术的孵化、推广和培训等。

三、西北农林科技大学联合体

由西北农林科技大学牵头，联合中国（宁夏）—以色列农业技术培训中心，面向中亚、西亚和北非国家，发挥杨凌农业高新技术产业示范区的优势，提供旱作农业技术成果的孵化、推广和培训等。

四、江苏联合体

由江苏省农业委员会牵头，组织南京农业大学、江苏农林职业技术学院、江苏农牧科技职业学院、苏州农业职业技术学院、中国水产科学研究院淡水渔业研究中心、扬州大学，形成联合体。联合体办公室设在江苏农林职业技术学院。核心任务是展示和推广我国现代农业发展成就。面向全球特别是欠发达国家，展示和推广我国现代农业发展的先进理念、模式、经验和技术，开展农业走出去人才培养、职业农民培育、淡水渔业技术培训等。
