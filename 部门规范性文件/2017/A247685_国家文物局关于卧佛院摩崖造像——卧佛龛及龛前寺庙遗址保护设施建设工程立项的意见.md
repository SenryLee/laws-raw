# 国家文物局关于卧佛院摩崖造像——卧佛龛及龛前寺庙遗址保护设施建设工程立项的意见

## 关于卧佛院摩崖造像——卧佛龛及龛前寺庙遗址保护设施建设工程立项的意见

办保函〔2017〕81号

四川省文物局：

你局《关于卧佛院摩崖造像卧佛龛及龛前寺庙遗址保护设施建设工程立项的请示》（川文物〔2016〕122号）收悉。经研究，我局意见如下：

一、所报工程立项的设计思路不清，工程内容不明，文本深度不够，我局暂不同意卧佛院摩崖造像卧佛龛及龛前寺庙遗址保护设施建设工程立项。

二、应进一步加强前期勘察，明确卧佛龛保存现状、残损状况及主要病害，在此基础上客观分析建设保护性设施的必要性和可行性，进行文物和景观影响评估，并研提具体设计思路和概念性设计图。请你局指导当地人民政府组织专业机构修改完善立项报告，按照《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的相关要求集中报批。

三、请你局切实加强管理，核实龛前寺庙遗址发掘后保护情况，督促有关单位尽快做好遗址保护性回填工作，确保文物安全。

专此函复。

国家文物局

2017年2月7日
