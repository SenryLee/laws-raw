# 农业部关于政协十二届全国委员会第五次会议第0222号（农业水利类029号）提案的答复摘要

## 政协十二届全国委员会第五次会议第0222号（农业水利类029号）提案的答复摘要

确保国家粮食安全始终是治国理政的头等大事。贯彻落实中央的战略部署，农业部会同有关部门落实各项强农惠农富农政策，坚持并完善稻谷、小麦最低收购价，较好地保护了农民种粮积极性，促进了粮食连年丰收；加强进出口管理，有效利用国际市场进行品种余缺调剂，避免大量进口对国内粮食生产和市场造成冲击；强化政策扶持，推进科技创新，促进大豆、杂粮生产发展；启动库存玉米消化工作，因势利导发展燃料乙醇，安排燃料乙醇企业参加定向销售，进一步缓解玉米库存压力。同时，重视农村土地承包经营权流转和发展适度规模经营，通过强化政策引导，加大扶持力度，大力培育新型农业经营主体和服务主体，推进土地适度规模经营健康发展。

农业部

2017年9月1日
