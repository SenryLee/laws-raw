# 国家文物局关于纳达齐牛录关帝庙保护规划编制立项的意见

## 关于纳达齐牛录关帝庙保护规划编制立项的意见

办保函〔2017〕395号

新疆维吾尔自治区文物局：

你局《关于报送纳达齐牛录关帝庙保护规划立项报告的请示》（新文物保发〔2017〕28号）收悉。经研究，我局意见如下：

一、纳达齐牛录关帝庙文物构成单一，规划编制的必要性和紧迫性不足，我局不同意纳达齐牛录关帝庙保护规划编制立项。

二、请你局督促、指导地方人民政府加强“四有”建设，完善纳达齐牛录关帝庙的保护区划、管理规定和具体保护管理措施，严格控制周边各类建设活动。同时，应切实做好文物日常养护、巡查和岁修工作，确保文物安全。如发现影响文物安全的病害险情，应及时启动保护工作，并按要求履行报批程序。

专此函。

国家文物局

2017年4月10日
