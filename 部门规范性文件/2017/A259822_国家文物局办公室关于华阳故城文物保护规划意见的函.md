# 国家文物局办公室关于华阳故城文物保护规划意见的函

办保函〔2017〕1454号

河南省文物局：

你局《关于报批华阳故城文物保护规划的请示》（豫文物〔2017〕28号）收悉。经研究，我局意见如下：

一、暂不同意华阳故城文物保护规划。

二、对该规划提出以下修改意见：

（一）进一步加强考古研究，根据考古工作成果和文献资料，系统梳理华阳故城的历史沿革，分析遗址范围内不同时期文化遗存的关系，完善价值评估，明确保护对象构成和环境要素，合理划定保护区划。

（二）补充完善历史灾害评估，强化防灾措施的针对性。

（三）应根据遗址保护展示需要，科学确定管理和综合服务区选址，尽量利用现有建筑，避免大规模新建设施。

（四）完善社区居民调控规划，明确居民搬迁位置，分步实施搬迁措施。完善与相关上位规划的衔接，科学梳理道路体系，根据需要与可能，合理调整用地属性。

（五）进一步梳理规划文本结构和内容，规范专业用语，深化、规范图纸表达。

三、请你局指导规划编制单位联合专业考古研究单位，根据上述意见对华阳故城文物保护规划进一步修改和完善后，按程序另行报批。

国家文物局办公室

2017年12月28日
