# 农业部办公厅关于公布2017年热作标准化生产示范园创建单位名单的通知

农办垦〔2017〕12号

广东、海南、云南、广西、福建、四川、贵州、湖南、西藏省（自治区）农业（牧）厅（委员会），广东、海南省农垦总局，广西、云南省（自治区）农垦局：

为推进热作供给侧结构性改革、培育高端热作产业，根据《农业部关于推进农业供给侧结构性改革的实施意见》（农发〔2017〕1号）和《热作标准化生产示范园管理办法（暂行）》（农办垦〔2010〕64号），经自主申报、省级主管部门审核推荐，确定广东省广州市增城东林果业园麻车新果场增城区石滩镇荔枝标准化生产示范园等42个单位为2017年热作标准化生产示范园创建单位，现予以公布（具体名单见附件）。

请各相关单位按照《热作标准化生产示范园管理办法（暂行）》和《关于大力推进高端热作产业发展的通知》（农热办〔2016〕5号）要求，在创建过程中推进示范园转型升级，逐步将标准化规程覆盖到全产业链，并及时将示范园创建情况报送我部。我部将适时组织认定第七批农业部热作标准化生产示范园。

附件：2017年农业部热作标准化生产示范园创建单位名单

农业部办公厅

2017年6月28日
