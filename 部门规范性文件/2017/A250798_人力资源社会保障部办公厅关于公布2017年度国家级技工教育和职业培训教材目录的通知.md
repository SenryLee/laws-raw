# 人力资源社会保障部办公厅关于公布2017年度国家级技工教育和职业培训教材目录的通知

人社厅函〔2017〕77号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）：

为贯彻落实《技工教育“十三五”规划》精神，推进技工教育和职业培训事业更好发展，我部职业培训教材工作委员会组织开展了国家级技工教育和职业培训教材评审工作。经专家评审，共有131种教材合格，现予以公布。

请各地人社部门指导各类技工院校和职业培训机构做好教材选用工作，并及时将教材需求信息和使用意见反馈我部职业培训教材工作委员会办公室。

附件：2017年度国家级技工教育和职业培训教材目录

人力资源社会保障部办公厅

2017年4月11日
