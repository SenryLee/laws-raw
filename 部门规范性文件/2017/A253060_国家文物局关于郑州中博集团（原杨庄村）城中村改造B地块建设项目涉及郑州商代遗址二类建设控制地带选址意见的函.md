# 国家文物局关于郑州中博集团（原杨庄村）城中村改造B地块建设项目涉及郑州商代遗址二类建设控制地带选址意见的函

## 关于郑州中博集团（原杨庄村）城中村改造B地块建设项目涉及郑州商代遗址二类建设控制地带选址意见的函

文物保函〔2017〕1162号

河南省文物局：

你局《关于报批郑州中博集团（原杨庄村）城中村改造项目B地块规划选址方案的请示》（豫文物〔2017〕157号）收悉。经研究，我局意见如下：

一、暂不同意郑州中博集团（原杨庄村）城中村改造B地块建设项目涉及郑州商代遗址二类建设控制地带的选址方案。

二、所报方案应进行以下必要调整和完善：

（一）应根据考古调查勘探结果，进一步明确新发现城垣遗址的分布范围，科学调整现有选址方案，避让新发现城垣遗址，确保文物安全。

（二）应将建设范围严格限定在郑州商代遗址二类建设控制地带内，严格控制建筑规模、高度和体量，注意与遗址及其周边环境相协调。同时，进一步核实外郭城城垣遗址周边的具体设计，新建设施不得占压遗址保护范围，确保遗址安全。

（三）该建设项目地块涉及的遗址保护范围不得进行建设，补充具体绿化设计和植被养护要求，应结合绿化进行必要的遗址展示，说明该区域在城市沿革中的历史地位，充分展现郑州城市演变发展脉络。

三、请你局指导建设单位调整、完善设计方案，并按程序另行报批。

国家文物局

2017年7月3日
