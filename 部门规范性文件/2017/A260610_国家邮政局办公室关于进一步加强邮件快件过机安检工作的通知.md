# 国家邮政局办公室关于进一步加强邮件快件过机安检工作的通知

国邮办发〔2017〕19号

各省、自治区、直辖市邮政管理局：

为贯彻落实国务院《关于促进快递业发展的若干意见》（国发〔2015〕61号）和中央综治办等九部门《关于加强邮件、快件寄递安全管理工作的若干意见》（中综办〔2014〕24号）等文件精神，以及《中华人民共和国反恐怖主义法》有关规定，严格寄递物品安全管理，切实保障寄递渠道安全畅通，现就进一步加强邮件快件过机安检工作通知如下：

一、提高思想认识，强化监督管理

邮件快件过机安检，是落实寄递渠道安全管理“三项制度”的内在要求，是加强寄递物品安全管理的重要抓手，是有效防范枪支弹药、爆炸装置、管制器具、危险化学品等禁寄物品进入寄递渠道的重要手段。近年来在全系统上下共同努力、相关部门大力推动和各级地方政府支持下，寄递企业X射线安检机配置工作取得明显成效，但仍存在安检机使用率不高、管理不规范、检查效果不好等问题，过机安检制度尚未真正有效发挥作用。各级邮政管理部门要把督促寄递企业加强安检机使用管理作为推进落实“三项制度”重要内容，统一思想认识，明确任务目标，切实加大监管力度。要在摸清寄递企业安检机配置和使用情况基础上，细化工作方案，优化工作举措，因地制宜采取有针对性的监管措施。要加强督导检查和培训交流，逐级压实工作责任，务求工作实效。

二、加强使用管理，确保应检必检

各级邮政管理部门要依照《邮政业安全生产设备配置规范》和《邮件快件微剂量X射线安全检查设备配置管理办法（试行）》等规定，督促寄递企业将安检机配置到位，并针对安检机使用管理中存在的问题，不断优化安检机使用管理流程，落实应检必检要求。

（一）督促指导寄递企业切实承担安全管理主体责任，完善安全风险防控体系，加强对已配置安检设备的使用管理，强化邮件快件安检工作源头管理，提升全网络安全管理水平和安全防范能力。省级寄递企业要按照“谁收寄、谁安检、谁负责”和属地管理的要求，承担出省邮件快件的安检责任。

（二）督促指导寄递企业优化安检流程，采取调整过机安检操作环节、延长传输带等措施，确保邮件快件逐件过机安检。已过机安检的邮件快件要在醒目位置逐件加盖安检戳记或者粘贴安检标识，载明安检单位、安检地区、安检时间。未加盖安检戳记或者粘贴安检标识的，或者安检单位、安检地区、安检时间无法准确追溯的，视同没有过机安检，不得发往下一环节。

（三）督促指导寄递企业对协议客户交寄的大宗邮件快件采取特定规格包装或者在面单上加以明显区分后，可以按规定采取特定方式过机安检。但通过航空、高铁运输的邮件快件，或者寄往重点地区、重要部位、重大活动所在地的邮件快件，以及国际和港澳台邮件快件，必须全面过机安检。

（四）督促指导寄递企业对寄往重点地区、重要部位、重大活动所在地的邮件快件，在寄达地进行二次过机安检，加盖二次安检戳记或者粘贴二次安检标识。未进行二次安检、未加盖二次安检戳记或者粘贴二次安检标识的，不得投递。

（五）督促指导寄递企业建立过机安检信息登记制度，逐日详细记录安检机运行情况、邮件快件过机安检数量，以及查获危险品、违禁品情况等。寄递企业对在过机安检过程中发现的禁寄物品或者疑似禁寄物品，应当按照规定程序进行处置，并及时上报相关部门。

（六）督促指导寄递企业建立健全安检人员管理机制，加强安检人员档案管理，建立过机安检工作奖惩和岗位津贴制度，强化安检业务培训，提高安检工作能力，保持安检队伍稳定。

三、加强日常检查，严格落实责任

各级邮政管理部门要切实履行监管职责，加强过机安检工作日常检查，采取现场监督过机安检、检查过机安检管理制度和工作记录、调阅安检现场监控视频等方式，对寄递企业落实过机安检制度情况进行检查。对未按规定配置安检设备、不落实过机安检制度、不按照规定使用安检设备、不加盖安检戳记或者粘贴安检标识的寄递企业，要依法严肃处理。要主动向地方党委、政府汇报过机安检工作情况，争取政策、资金支持和工作指导，落实寄递渠道安全管理属地责任。要加强与所在地综治、公安、国家安全等部门沟通配合，建立安检机使用监管协作机制，加大对寄递企业落实过机安检制度的监管力度，强化寄递企业主体责任落实。
