# 农业部对十二届全国人大五次会议第7639号建议答复摘要

## 十二届全国人大五次会议第7639号建议答复摘要

农办议〔2017〕249号

近年来，农业部、财政部等部门积极采取措施推进丘陵山区农业机械化发展。国家公益性行业（农业）科研专项累计投入5800万元，支持开展了丘陵山地小型农机具技术研究示范、山地橘园省力栽培机械研究示范、茶园综合机械化作业技术等科研项目。考虑到丘陵山区农业机械发展需要，在优化补贴机具种类范围过程中，对微耕机、耕整机、田间管理机等小型机具品目予以保留，并在种植施肥、田间管理、谷物收获、农产品初加工机械中注重兼顾小型农机具。2013年发布的《全国高标准农田建设总体规划》，提出“田间道路是机械化作业的基本前提”。发展改革、国土资源、农业综合开发等部门不断加大包括丘陵山区机耕道在内的土地整治、标准农田建设等工程的投入力度。

下一步，农业部等有关部门将深入开展丘陵山区农业机械化发展扶持政策的研究和创设，支持引导丘陵山区省份农业机械化加快发展。积极推动各地结合高标准农田建设，加大丘陵山区耕地整理力度。积极谋划科研计划项目，支持丘陵山区农业机械化科技创新，鼓励引导农机制造企业加强丘陵山区适用机具研发供给。创新丘陵山区农机社会化服务机制，引领支撑多种形式适度规模经营发展。大力培育农机合作社等新型农业经营服务主体、农机作业能手等新型职业农民，发展农业社会化服务，加强基层农技（农机）推广体系建设，多措并举提高丘陵山区农业机械化发展水平。

农业部

2017年8月24日
