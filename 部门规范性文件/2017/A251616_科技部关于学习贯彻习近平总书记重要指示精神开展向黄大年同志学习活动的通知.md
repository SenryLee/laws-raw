# 科技部关于学习贯彻习近平总书记重要指示精神开展向黄大年同志学习活动的通知

国科发厅〔2017〕151号

各省、自治区、直辖市及计划单列市、副省级城市科技厅（委、局），新疆生产建设兵团科技局，中央和国家机关有关部门科技主管司局，各有关单位：

近日，习近平总书记对黄大年同志先进事迹做出重要指示：“黄大年同志秉持科技报国理想，把为祖国富强、民族振兴、人民幸福贡献力量作为毕生追求，为我国教育科研事业做出了突出贡献，他的先进事迹感人肺腑。我们要以黄大年同志为榜样，学习他心有大我、至诚报国的爱国情怀，学习他教书育人、敢为人先的敬业精神，学习他淡泊名利、甘于奉献的高尚情操，把爱国之情、报国之志融入祖国改革发展的伟大事业之中，融入人民创造历史的伟大奋斗之中，从自己做起，从本职岗位做起，为实现‘两个一百年’奋斗目标、实现中华民族伟大复兴的中国梦贡献智慧和力量。”为认真学习贯彻习近平总书记重要指示精神、深入开展向黄大年同志学习活动，动员广大科技人员投身创新驱动发展战略实施，凝聚起建设世界科技强国的伟大力量，现将有关事项通知如下。

一、认真学习领会习近平总书记重要指示精神。习近平总书记的重要指示高度评价了黄大年同志的突出贡献和崇高精神，充分体现了党中央对广大知识分子和科技人员的重视、关爱与期待，饱含了对广大党员干部牢记宗旨、忠诚报国的殷切期望，进一步丰富了以习近平同志为核心的党中央对于加强科技人才队伍建设，激发广大科技人员的爱国热忱和奉献精神的基本要求和时代内涵。认真学习领会习近平总书记的重要指示精神，对于进一步调动广大科技人员的积极性创造性，坚持走中国特色自主创新道路，深入实施创新驱动发展战略，实现“三步走”战略目标，具有十分重要的意义。各级科技管理部门要认真学习贯彻习近平总书记重要指示精神，牢固树立“四个意识”，引导广大科技人员坚定理想信念，自觉在思想上政治上行动上始终同以习近平同志为核心的党中央保持高度一致。把深入开展向黄大年同志学习活动，摆上重要日程，精心组织实施，切实抓紧抓好，确保取得实效。

二、深入学习宣传黄大年同志的先进事迹。黄大年同志是新时期留学回国人员爱国报国的先进楷模，是一线科研人员的杰出榜样，是知识分子的优秀代表，是践行社会主义核心价值观的突出典型。黄大年同志生前是吉林大学地球探测科学与技术学院教授、博士生导师，是著名地球物理学家，是东北地区首位国家“千人计划”特聘教授。在国内外学术领域和海外归国人才中享有很高的声誉。黄大年同志带领科研团队不断创新、刻苦攻关，取得了一系列重大科技成果，填补了多项国内技术空白，部分成果达到国际领先水平。为党的事业、为科技创新奋斗到生命的最后一息。各级科技管理部门要认真组织学习黄大年同志先进事迹，面向基层一线科技人员特别是青年科技人员，开展内容丰富、形式多样的宣传活动。组织相关媒体，围绕黄大年的爱国情怀、高尚情操和敬业精神等，开展人物事迹报道，引导广大科技人员把智慧和力量凝聚到实施创新驱动发展战略上来，在科技界迅速形成学习宣传热潮。

三、把学习宣传黄大年同志先进事迹作为“两学一做”学习教育常态化制度化的重要内容。推进“两学一做”学习教育常态化制度化是坚定维护以习近平同志为核心的党中央权威、加强党的思想政治建设的有效途径，是坚持思想建党、组织建党、制度治党紧密结合，不断深化全面从严治党的战略性、基础性工程，是确保习近平科技创新思想作为科技创新工作根本指导的重要举措。要把开展向黄大年同志学习活动同推进“两学一做”学习教育常态化制度化结合起来，统筹部署、统筹安排。坚持“学”为基础，要把思想教育作为首要任务，把黄大年同志的先进事迹和崇高思想作为鲜活教材。坚持“做”是关键，强化实干担当，要以黄大年同志为榜样，以建设世界科技强国为己任，刻苦钻研，忘我工作，推进科技改革发展不断取得新突破。加强对学习教育的组织领导，引导广大党员干部学先进、赶先进，充分发挥党员的先锋模范作用。

四、动员广大科技人员以更加高昂的斗志投身建设世界科技强国的伟大实践。2016年5月30日，党中央、国务院隆重召开全国科技创新大会，习近平总书记发表了重要讲话，向全党全国发出了建设世界科技强国的号召，对加快实施创新驱动发展战略作出全面部署。当前，我国科技事业发展进入新的阶段，科技创新取得了举世瞩目的巨大成就，发生了整体性、格局性的深刻变化，正处于从量的积累向质的飞跃、点的突破向系统能力提升的重要时期，一些重要领域方向跻身世界先进行列。在这个伟大的创新时代，积极响应习近平总书记号召，加快实施创新驱动发展战略，建设世界科技强国，需要千千万万个黄大年式的科技人员。广大科技人员要按照习近平总书记的要求，切实把爱国之情、报国之志融入祖国改革发展的伟大事业之中，融入实施创新驱动发展战略，建设世界科技强国的伟大实践之中。增强创新自信，把握时代机遇，勇于担当责任，努力开拓奋进，不断取得更大的科技创新成果，为实现“两个一百年”奋斗目标、实现中华民族伟大复兴的中国梦贡献智慧和力量，以优异成绩迎接党的十九大胜利召开。

各地方、各部门要将学习贯彻中的好经验、好做法及时报送科技部。
