# 国家文物局办公室关于麟游县镇头初级中学校舍拆建项目涉及隋仁寿宫唐九成宫遗址一类建设控制地带选址的意见

办保函〔2017〕1313号

陕西省文物局：

你局《关于在隋仁寿宫·唐九成宫遗址建设控制地带内进行麟游县镇头初级中学校舍拆建项目的请示》（陕文物字〔2017〕178号）收悉。经研究，我局意见如下：

一、所报项目选址位于隋仁寿宫唐九成宫遗址一类建设控制地带内，根据陕西省人民政府公布的《隋仁寿宫唐九成宫遗址保护总体规划》，该区域为禁建区。我局暂不同意麟游县镇头初级中学校舍拆建项目涉及隋仁寿宫唐九成宫遗址一类建设控制地带的选址方案。

二、请你局指导建设单位切实加强前期论证和文物影响评估，进一步说明项目选址的必要性，客观分析建设影响，建议尽量避让隋仁寿宫唐九成宫遗址一类建设控制地带另行选址。

三、请你局指导地方人民政府，进一步研究确定隋仁寿宫唐九成宫遗址保护展示的整体思路和一类建设控制地带的管控目标，妥善处理文物保护与民生改善的关系。

国家文物局办公室

2017年11月30日
