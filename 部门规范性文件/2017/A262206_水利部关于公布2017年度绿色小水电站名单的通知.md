# 水利部关于公布2017年度绿色小水电站名单的通知

水电移〔2017〕450号

部机关各有关司局，部直属各有关单位，各有关省、自治区、直辖市水利（水务）厅（局）、新疆生产建设兵团水利局：

根据《水利部关于开展绿色小水电站创建工作的通知》精神，各地积极开展了绿色小水电站创建工作。经申报、初验、审核和公示，确定河北省邯郸市东武仕水电站等44座电站为2017年度绿色小水电站（名单详见附件）。

附件：2017年度绿色小水电站名单

水利部

2017年12月20日

## 2017年度绿色小水电站名单
