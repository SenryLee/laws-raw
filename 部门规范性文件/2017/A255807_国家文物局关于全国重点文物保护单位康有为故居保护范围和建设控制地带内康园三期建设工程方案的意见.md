# 国家文物局关于全国重点文物保护单位康有为故居保护范围和建设控制地带内康园三期建设工程方案的意见

文物保函〔2017〕1391号

广东省文物局：

你局《关于在全国重点文物保护单位康有为故居保护范围和建设控制地带内康园三期建设工程的请示》（粤文物审〔2017〕74号）收悉。经研究，我局意见如下：

一、原则同意所报康有为故居保护范围和建设控制地带内康园三期建设工程方案。

二、对方案提出以下修改意见：

（一）补充建设工程所涉既有建筑现状照片，加强项目与佛山市城市总体规划和佛山市历史文化名城保护规划相关内容的衔接。

（二）尽可能保留建筑的地方传统做法及构造特征。康氏宗祠正脊形式如为历史原状，应保持其现有风格；康有为纪念馆等新建建筑装饰，可以当地传统做法为依据。

（三）金属材质门窗和护栏应在色彩上与文物环境相协调。

（四）道路铺装及绿化应保持文物历史环境氛围，地面不宜大面积铺设砖石，避免过度景观园林化倾向。

（五）深化文物影响评估，科学分析所选工程材料、色彩等方面的适用性，并根据评估结论优化方案设计。

三、请你局指导相关单位根据上述意见对方案进行修改完善，按照《中华人民共和国文物保护法》第十七条、第十八条的规定，分别经广东省人民政府和城乡建设规划部门批准后实施。工程施工期间，你局应加强监管，确保文物安全。

国家文物局

2017年8月14日
