# 国家林业局办公室关于切实做好全国“两会”期间林业安全生产工作的通知

办改字〔2017〕24号

各省、自治区、直辖市林业厅（局），内蒙古、吉林、龙江、大兴安岭、长白山森工（林业）集团公司，新疆生产建设兵团林业局，国家林业局各司局、各直属单位：

全国“两会”即将召开，确保全国“两会”期间生产安全是当前安全生产工作的一项重要任务。为切实做好林业安全生产工作，确保全国“两会”期间安全生产形势稳定，现将有关要求通知如下：

一、进一步提高思想认识，狠抓各项安全措施的落实

各地林业主管部门和国家林业局各有关司局、各有关直属单位要充分认识做好全国“两会”期间安全生产工作的重要意义，强化政治自觉和责任自觉，强化大局意识和责任意识，坚决克服林业行业多年未出现大的生产安全事故的麻痹大意思想。要按照中央提出的“党政同责、一岗双责、失职追责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的工作要求，狠抓责任落实。各地要按照本级政府安全生产委员会确定的部门工作职责，切实落实好林业安全生产属地管理和行业管理责任。内蒙古、吉林、龙江、大兴安岭、长白山森工（林业）集团公司要认真落实企业安全生产主体责任，主动接受属地监管。国家林业局各有关司局、各有关直属单位要按照“谁主管、谁负责”的要求，落实好本司局、本直属单位业务范围内的安全生产工作行业管理责任，严格履行“一岗双责”。各地林业主管部门和国家林业局各有关司局、各有关直属单位要深入研究分析全国“两会”前后林业安全生产工作的规律特点，采取针对性的预防措施，狠抓工作措施落实，坚决防范和遏制重特大事故发生，为全国“两会”胜利召开创造稳定的安全生产环境。

二、深入开展隐患排查治理，不断强化事故预防工作

各地林业主管部门和国家林业局各有关司局、各有关直属单位要认真贯彻落实全国林业安全生产电视电话会议精神，加强安全防范，督促整改前一阶段安全生产大检查发现的安全隐患，推动林业生产经营单位认真落实主体责任，加强安全管理。同时，要针对林业安全生产工作特点，不断加强对国有林区、国有林场、森林公园、湿地公园、沙漠公园等林区和林业生产经营单位的隐患排查治理。对查出的隐患和问题，能立即整改的要立即整改，不能立即整改的要落实安全防范措施；对重大隐患要挂牌督办整改，无法保证安全生产的，要坚决依法责令停产停业整改，并加强巡查、监控和盯守。

三、大力加强安全警示教育，切实提高安全防范能力

各地林业主管部门和国家林业局各有关司局、各有关直属单位要进一步健全信息共享、协调联动机制，加强灾害性天气、地质灾害等预测预报，及时发布预警信息。要充分利用电视、广播、报纸等传统媒体和微博、微信、新闻客户端等新媒体进行安全提示，提高林区广大群众和林业生产经营单位职工应急避险意识以及自救互救技能。要进一步健全完善应急预案，做好救援队伍、装备、物资等应急准备。要加强值班值守，严格执行领导干部到岗带班、关键岗位24小时值班制度和事故信息报告制度，一旦发生事故或险情，要组织救援力量和装备物资快速响应、有效应对、妥善处置。

特此通知。

国家林业局办公室
