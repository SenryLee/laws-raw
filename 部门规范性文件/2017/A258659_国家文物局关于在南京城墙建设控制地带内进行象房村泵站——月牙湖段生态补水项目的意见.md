# 国家文物局关于在南京城墙建设控制地带内进行象房村泵站——月牙湖段生态补水项目的意见

文物保函〔2017〕1970号

江苏省文物局：

你局《关于审批南京主城水系连通生态补水第一批次节点建设工程象房村泵站——月牙湖段工程修改方案的请示》（苏文物保〔2017〕325号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位南京城墙建设控制地带内进行象房村泵站——月牙湖段生态补水项目和你局意见。

二、对所报项目提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《南京市历史文化名城保护规划》、《南京城墙保护规划》、《南京城墙保护条例》的相关管理规定，严格控制工程量和工程范围，尽量减少对文物本体和地下遗存的影响。

（二）进一步调整高排涵进水口前新建溢流堰的设计内容，以满足行洪效果为主，避免过多增加景观设施。

（三）充分考虑建设施工对文物的影响，进一步完善文物保护措施和应急预案，施工范围应尽量远离文物本体，并在施工过程中对地下水位、防渗、文物本体变形等方面进行实时监测，确保文物安全。补充施工完成后恢复场地原状的景观设计图纸，确保与城墙历史环境相协调。

（四）应进一步加强对南京原有水系的研究分析及生态补水系统对南京原有水系的影响评估。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十八条的规定报城乡建设规划部门批准。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，并注意场地内可能存在的历史河道、驳坎及其与护城河的连通关系，如有重要发现，应及时调整设计方案。施工中请加强监管，确保工程质量和文物安全。

专此函复。

国家文物局

2017年12月7日
