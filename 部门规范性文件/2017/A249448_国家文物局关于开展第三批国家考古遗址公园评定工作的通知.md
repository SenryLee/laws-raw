# 国家文物局关于开展第三批国家考古遗址公园评定工作的通知

## 关于开展第三批国家考古遗址公园评定工作的通知

文物保函〔2017〕560号

各省、自治区、直辖市文物局：

为贯彻落实国务院《关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的精神，加强大遗址保护和国家考古遗址公园建设，经研究，国家文物局决定启动第三批国家考古遗址公园评定工作。

请各单位根据《国家考古遗址公园管理办法（试行）》的有关规定，提交相关申报材料（要求附后）。申报材料的受理时间截至2017年7月31日。

材料请寄至：

北京市东城区北河沿大街83号，邮编：100009

国家文物局文物保护与考古司考古处

联系人：王彬

联系电话：010-56792077

传真：010-56792133

电子邮箱：kaoguchu@sach.gov.cn

专此通知。

附件：

1：申报材料要求

2：国家考古遗址公园立项申报书

3：国家考古遗址公园评定申报书
