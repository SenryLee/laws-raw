# 国家新闻出版广电总局办公厅关于开展2017年“少儿报刊阅读季”活动的通知

## 关于开展2017年“少儿报刊阅读季”活动的通知

新广出办函〔2017〕79号

各省、自治区、直辖市新闻出版广电局，新疆生产建设兵团新闻出版广电局，中央和国家机关各部委、各民主党派、各人民团体报刊主管部门：

为深入贯彻落实全民阅读工作部署，充分发挥优秀少儿报刊对广大少年儿童的教育引导作用，国家新闻出版广电总局决定从2017年4月至10月开展2017年“少儿报刊阅读季”活动，现将有关事项通知如下：

一、 活动安排

(一) 参与范围

全国少年儿童类报刊应以2017年“少儿报刊阅读季”活动为载体，广泛开展少儿报刊阅读活动。特别是历年来总局推荐的优秀少儿报刊出版单位应积极开展各类活动，充分发挥示范引领作用。

(二) 时间安排

2017年“少儿报刊阅读季”活动从2017年4月23日开始，至10月31日结束。总局将在“4·23世界读书日”期间，在北京举办启动仪式。各地可结合工作实际，适时开展多种形式的少儿报刊阅读推广活动，积极组织媒体进行广泛宣传，营造良好环境和浓郁氛围。

(三) 具体活动

1.开展“中国梦·少年说”主题活动。通过开展多种形式的征文、征画、演讲、讲座、论坛等活动，帮助少年儿童从小培育和践行社会主义核心价值观，从小树立追求真理、报效祖国的远大志向，从小学习创造新生活的新理念、新知识、新本领，为实现中华民族伟大复兴的中国梦做好准备。

2.开展“我的悦读童年”报刊阅读推广活动。深入贯彻国家新闻出版广电总局印发的《关于开展2017年全民阅读活动工作的通知》精神，组织开展2017年“全国少年儿童喜爱的报刊”评审推荐工作；开展主题演讲、主题征文、知识竞赛、主题论坛等各类阅读推广活动，激发少年儿童的阅读兴趣，拓展他们的阅读视野。

3.开展“我与报刊的童年故事”活动，寻找在报刊陪伴下成长的榜样人物，向少年儿童展示阅读的力量。同时，鼓励和支持作家、科学家、阅读推广人等开展报刊阅读推广活动，加强对少儿阅读规律的研究和运用，帮助广大少年儿童爱上阅读、学会阅读，在阅读中学习做人、学习立志、学习创造。

4.开展“少年传承中华传统文化”活动。深入贯彻中办、国办《关于实施中华优秀传统文化传承发展工程的意见》精神，将中华优秀传统文化贯穿到少儿报刊编辑出版发行、阅读推广全过程中，通过编读互动、经典诵读、主题推广等活动，注重文化熏陶和实践养成，用中华文化遗产、传统美德、人文精神滋养少年儿童的精神，浸润他们的心灵。

5.组织报刊捐赠公益活动。认真落实今年3月1日起施行的《公共文化服务保障法》，组织报刊出版单位向老少边贫地区儿童、农村少年儿童、留守儿童、城市流动儿童较为集中的乡村小学、中小城市图书馆、农家书屋等进行捐赠，鼓励企事业单位及个人进行捐赠，充分保障弱势群体的阅读权益。

二、组织机构

2017年“少儿报刊阅读季”活动纳入国家新闻出版广电总局全民阅读工作部署，由总局新闻报刊司组织实施，中国少年儿童报刊工作者协会和中国出版协会少儿读物出版工作委员会联合承办。各省级新闻出版广电局应将此活动纳入各地全民阅读工作部署，建立完善相关工作机构，组织领导协调本地区开展工作。

三、工作要求

1.加强组织领导。各级新闻出版广电行政部门、少儿报刊主管主办及出版单位要高度重视本项工作，制定工作方案，完善工作机制，加强综合协调，落实经费保障，确保活动扎实有效开展，推动建立少儿报刊阅读推广的常态机制。

2.加大宣传推广力度。各级新闻出版广电行政部门、少儿报刊主管主办单位及出版单位应围绕活动主题，精心策划宣传，综合运用报刊、广电、网络各种媒体手段，不断扩大“阅读季”活动影响，通过阅读，使青少年树立“从小学习做人，从小学习立志，从小学习创造”的理念。

3.带动各方力量参与。各级新闻出版广电行政部门应加强与宣传、教育、文化、妇联、共青团等部门的沟通协调，鼓励和支持文化团体、教育机构和其他社会组织开展阅读推广活动，凝聚各方力量共同参与2017年“少儿报刊阅读季”工作。

各省级新闻出版广电行政部门要根据本通知要求，精心制订本地“阅读季”活动落实方案，及时掌握本地区活动开展情况，并在5月-10月每月30日前向总局新闻报刊司报送当月活动进展情况，在2017年11月底前报送活动总体情况。

国家新闻出版广电总局办公厅

2017年3月7日
