# 国家文物局关于五泉山建筑群庄严寺管理用房建设项目的意见

文物保函〔2017〕1750号

甘肃省文物局：

你局《关于开展五泉山建筑群庄严寺管理用房建设项目的报告》（甘文局发〔2017〕141号）收悉。经研究，我局意见如下：

一、原则同意五泉山建筑群庄严寺管理用房建设项目和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）管理用房建设项目前，应拆除对文物建筑安全和风貌影响较大的彩钢板房等临时建筑，以恢复和保护庄严寺庙原有历史环境。

（二）补充地基基础勘察报告；由于基坑开挖深度较大，应补充对文物建筑本体的影响评估。

（三）进一步控制建设规模，建议取消中殿两侧的监控室、消防器材室、卫生间建筑，其功能分配至其它新建筑上，只保留两侧各一座建筑，以保证中殿的文物风貌得到较好呈现。

（四）进一步优化管线路由；上、下水等管道应尽量在周边绕行敷设，不宜横穿中线。

（五）进一步补充完善传统工艺做法及要求，如木结构、墙体及材料等。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《中华人民共和国文物保护法》第十七条的有关规定报送甘肃省人民政府批准后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局

2017年10月12日
