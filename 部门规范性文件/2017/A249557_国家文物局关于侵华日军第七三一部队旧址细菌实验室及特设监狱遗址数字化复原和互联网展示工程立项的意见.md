# 国家文物局关于侵华日军第七三一部队旧址细菌实验室及特设监狱遗址数字化复原和互联网展示工程立项的意见

## 关于侵华日军第七三一部队旧址细菌实验室及特设监狱遗址数字化复原和互联网展示工程立项的意见

办保函〔2017〕390号

黑龙江省文物局：

你局《关于报送侵华日军第七三一部队旧址细菌实验室及特设监狱遗址数字化复原和互联网展示工程立项的请示》（黑文管字〔2017〕6号）收悉。经研究，我局意见如下：

一、应结合文物价值、内涵及特点，深入评估遗址展示现状，分析存在的问题，通过数字化及互联网技术丰富展示手段，有效提升遗址展示水平。

二、展示内容应突出文物价值及相关历史信息，并采取线上、线下多种模式综合运用数字化复原成果。

三、数字化复原设计须充分尊重历史，并体现相关历史研究成果。

国家文物局

2017年4月10日
