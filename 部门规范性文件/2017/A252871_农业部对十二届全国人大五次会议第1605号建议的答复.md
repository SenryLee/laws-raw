# 农业部对十二届全国人大五次会议第1605号建议的答复

## 对十二届全国人大五次会议第1605号建议的答复

杨娟娟代表：

您提出的关于大力支持贫困地区特色农业发展的建议收悉。经商国家发展改革委、科技部、国土资源部、证监会，现答复如下。

产业是贫困地区发展的根基，是实现脱贫的主要依托。党中央、国务院高度重视产业扶贫工作，把产业扶贫摆在“五个一批”的首位。按照中央决策部署，农业部会同相关部门齐心协力、创新政策、完善机制、攻坚克难，扎实推进产业扶贫工作。

一、关于加强贫困地区农业基础设施建设

2016年4月，国务院办公厅印发了《关于支持贫困县开展统筹整合使用财政涉农资金试点的意见》（国办发〔2016〕22号），支持贫困县开展统筹整合使用财政涉农资金试点，赋予贫困县统筹整合使用财政涉农资金的自主权。根据文件精神，贫困县可依据统筹使用上级财政下达的纳入整合范围的相关财政涉农资金，围绕自身需求，因地制宜支持贫困地区基础设施建设和产业发展。国家发展改革委专门印发了《关于支持贫困地区农林水利基础设施建设推进脱贫攻坚的指导意见》（发改农经〔2016〕537号），强调突出重点，整合资源，支持贫困地区以脱贫攻坚规划和行业发展规划为统领，加强对涉农领域资金的统筹使用，要求“十三五”时期中央预算内农林水利建设投资用于贫困地区的比重达到40%左右，并要求地方同步加大投入。农业部也专门印发了《关于加大贫困地区项目资金倾斜支持力度促进特色产业精准扶贫的意见》（农计发〔2016〕94号），要求积极推动农业基础设施建设项目向贫困地区倾斜。对于在新增千亿斤粮食生产能力规划范围内的151个贫困县，年度项目资金优先倾斜安排，加快建成一批旱涝保收、高产稳产、生态良好的高标准农田；向符合条件的贫困地区优先安排标准化规模养殖场建设项目，改善水电路、粪污处理、防疫、质量检测等基础设施条件，培育壮大一批设施完备、环境友好的养殖场（小区），巩固和提升贫困地区特色产业带动能力。

下一步，农业部将会同相关部委，按照有关文件要求，落实好相关工作，力争通过资金投入和项目实施，加快改善贫困地区农业基础设施条件，为贫困地区农业发展和产业扶贫提供基础支撑。

二、关于理顺融资平台，优先支持贫困地区符合条件的农业企业挂靠新三板上市融资

2016年9月，证监会发布《关于发挥资本市场作用服务国家脱贫攻坚战略的意见》（证监会公告〔2016〕19号），对贫困地区企业首次公开发行股票、新三板挂牌、发行债券、并购重组等开辟绿色通道，支持贫困地区农业产业发展，帮助贫困群众稳定脱贫。支持贫困地区农业企业利用多层次资本市场融资。在首次公开发行股票方面，对注册地和主要生产经营地均在贫困地区且开展生产经营满三年、缴纳所得税满三年的企业，或者注册地在贫困地区、最近一年在贫困地区缴纳所得税不低于2000万元且承诺上市后三年内不变更注册地的企业，申请首次公开发行股票并上市的，适用“即报即审、审过即发”政策；在新三板挂牌方面，对注册地在贫困地区的企业申请在全国中小企业股份转让系统挂牌的，实行“专人对接、专项审核”，适用“即报即审、审过即挂”政策，减免挂牌初费；在发行债券方面，对注册地在贫困地区的企业发行公司债、资产支持证券的，实行“专人对接、专项审核”，适用“即报即审”政策。支持和鼓励上市公司履行社会责任服务国家脱贫攻坚战略。在并购重组方面，鼓励上市公司支持贫困地区的产业发展，支持上市公司对贫困地区的企业开展并购重组。对涉及贫困地区的上市公司并购重组项目，优先安排加快审核；对符合条件的农业产业化龙头企业的并购重组项目，重点支持加快审核。支持和鼓励证券基金经营机构履行社会责任服务国家脱贫攻坚战略。在产业基金方面，鼓励上市公司、证券公司等市场主体设立或参与市场化运作的贫困地区产业投资基金和扶贫公益基金。对积极参与扶贫的私募基金管理机构，将其相关产品备案纳入登记备案绿色通道。在行业扶贫方面，证券业协会 “发布一司一县”、期货业协会发布“一司一结对”帮扶行动倡议，鼓励引导证券期货经营机构结对帮扶贫困县。

下一步，证监会继续贯彻落实党中央、国务院对扶贫工作的决策部署，充分发挥资本市场在脱贫攻坚中的作用，对贫困地区符合条件的农业企业融资予以倾斜。

三、关于支持建立特色农业产业园区

现代农业产业园建设是新时期中央推进农业供给侧结构性改革、加快农业现代化的重大举措，是培育农业农村经济发展新动能和推进农民增收机制创新的重要载体。按照党中央、国务院的决策部署，农业部会同有关部门积极推进现代农业产业园的建设，启动了国家现代农业产业园创建工作，正在研究制定推进现代农业产业园建设的指导意见，引导各省、地、市建立一批以规模化种养基地为支撑，农业产业化龙头企业带动，现代生产要素集聚，“生产+加工+科技+营销”的现代农业产业园。同时，为推进特色农产品优势区建设，农业部会同国家发展改革委正在组织编制《特色农产品优势区建设规划》。规划印发后，农业部将会同有关部门统筹支持全国各地特别是贫困地区特色农产品优势区建设，将特色农产品产业做大做强，带动农民增收和贫困人口脱贫致富。

下一步，农业部将认真贯彻落实党中央、国务院的部署要求，进一步加大工作力度，鼓励和吸引特色农业企业建设运营产业园，建设科技研发中心、生产基地、加工中心，支持贫困地区特色农业发展，为探索中国特色新型农业现代化道路做出积极贡献。

四、关于降低贫困地区土地政策门槛，增加发展用地指标

2016年，国土资源部制定了《关于用好用活增减挂钩政策积极支持扶贫开发及易地扶贫搬迁工作的通知》（国土资规〔2016〕2号），提出将增减挂钩指标向贫困地区倾斜，并允许连片特困地区和国家扶贫开发工作重点县将增减挂钩节余指标在省域范围内流转使用，显化土地增值收益，加大返还贫困地区农村资金。农业部专门印发了《农村土地经营权流转交易市场运行规范（试行）》（农经发〔2016〕9号），进一步明确流转交易市场进行交易的相关规程。2017年，国土资源部下达土地利用计划时，专项安排国家扶贫开发工作重点县、集中连片特困地区每县600亩计划指标。湖南省可根据当地实际，按照有关政策规定，组织贫困地区开展增减挂钩试点，专项安排计划指标，支持特色农业产业建设，促进当地农业转型发展和新农村建设。

五、关于支持贫困地区特色农业品牌建设

近年来，农业部高度重视贫困地区特色农产品品牌创建工作。通过举办系列产品推荐、组织现场观摩等形式，不断加大宣传力度，帮助贫困地区提高特色农产品市场影响力。大力推广贫困地区区域农产品公用品牌。从去年12月至今年6月，我部共举办8期产业扶贫现场观摩，推广洛川苹果、赣南脐橙、定西马铃薯、广西百色芒果、贵州黔西南薏仁、河北平泉食用菌、湖北罗田黑山羊、安徽岳西茭白、河南信阳毛尖、山西平顺中药材、宁夏盐池滩羊、重庆石柱红辣椒等20余个区域公用品牌。同时，在新华社、人民日报、中央人民广播电台、中央电视台等中央主要媒体重要版面、重要时段集中推出产业扶贫范例系列报道，宣传区域品牌。支持举办洛川苹果节、彭州蔬菜节、定西马铃薯节、贵阳国际特色农产品交易会等农业展会，帮助贫困地区农产品扩大市场影响，培育产品品牌，增强特色农产品市场竞争力。多渠道支持贫困地区开展品牌创建。农业部通过在CCTV7、农民日报、中国农业信息网等媒体免费广告、开设专栏等形式，宣传推介农产品品牌。在第十四届中国国际农产品交易会期间举办产业扶贫专题展，组织64个贫困县、146家企业、29个农民合作社参展，举办贫困地区产品推进会13场。为贫困地区207家企业减免申报有机、绿色、地理标志费用，支持新疆和大兴安岭南麓片区创建18个绿色食品原料标准化生产基地。

下一步，农业部在品牌创建、展会工作、范例报道等方面继续加大对贫困地区支持力度，帮助打造区域公用品牌，提升贫困地区特色优质农产品的市场竞争力和影响力，促进贫困地区农业提质增效和农民脱贫增收。

六、关于加大智力帮扶力度，提高贫困地区特色农业发展科技水平

近年来，相关部门不断加大贫困地区科技和人才支持力度，努力为贫困地区发展提供智力支撑。农业部依托现代农业产业技术体系，支持贫困地区科研单位401名专家，开展动植物育种与繁育、病虫害防控、栽培与土肥、农机装备、加工等研究；落实项目资金5.6亿元，支持贫困地区开展绿色高产高效创建、稻渔综合种养，集成示范推广旱作农业、保护性耕作等技术应用；组织农业科研杰出人才和技术专家500人次，为湖南湘西等贫困地区的产业发展“把脉问诊”；会同财政部，重点面向种养大户、家庭农场主、农民合作社骨干、农业社会化服务人员和农村创业青年，培养一批爱农业、懂技术、善经营的新型职业农民；针对贫困县有劳动能力的贫困人口，围绕当地主导产业和特色产业，在一个生产周期内，开展不少于5天的专项技能培训，提高贫困户自我发展能力；会同中组部共同开展的农村实用人才带头人示范培训，面向贫困地区举办177期示范培训班，遴选1.77万名种养大户、家庭农场主和农民合作社负责人到农业部农村实用人才培训基地学习交流。科技部深入推行科技特派员制度，目前有84.5万名科技特派员活跃在农村基层、农业一线，带动人才、技术、管理、信息以及资本等现代生产要素向贫困地区流动，培育贫困地区创业主体，发展特色支柱产业；牵头实施“边远贫困地区、边疆民族地区和革命老区人才支持计划科技人员专项计划”，围绕“三区”支柱产业大力引导科技成果的转移和转化，为当地经济社会发展提供人才支持和智力服务；通过星火计划、中央引导地方科技发展专项资金、重点研发计划等项目实施，为培育壮大贫困地区特色支柱产业提供技术支撑。

下一步，相关部门将继续大力实施农村实用人才培养、新型职业农民培育等教育培训计划，优先安排贫困地区人员参加各项学习培训内容，促进农业综合技能提升；继续围绕贫困地区特色优势农业发展，引进、集成、示范推广优良农畜品种和先进实用技术，提升贫困地区农牧业发展的科技含量，增强发展后劲；继续围绕贫困地区、革命老区特色支柱产业发展，在政策、项目、资金、人才等方面继续向贫困地区予以倾斜，加大先进适用技术成果向贫困地区的转移转化力度，加大对贫困地区特色农业的支持力度。

感谢您对农业、农村工作的关心，希望今后继续对农业部工作予以支持。
