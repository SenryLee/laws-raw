# 国家质量监督检验检疫总局公告2017年第88号——质检总局关于公布获得生态原产地产品保护示范区名单的公告

## 国家质量监督检验检疫总局公告

2017年第88号

## 质检总局关于公布获得生态原产地产品保护示范区名单的公告

为进一步落实生态文明建设，建设美丽中国，促进区域经济可持续发展，培育打造品牌竞争新优势，经河南、山西、陕西、贵州检验检疫局推荐，质检总局评定组通过现场评定，批准河南省民权县人民政府等9家申报单位获评生态原产地产品保护示范区，即日起实施保护。现将获得生态原产地产品保护示范区的名单予以公布。
