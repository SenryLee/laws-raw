# 环境保护部关于申报2018年度中国-东盟海上合作基金项目的函

## 关于申报2018年度中国-东盟海上合作基金项目的函

环国际函〔2017〕164号

外交部、财政部:

根据外交部《关于申报2018年度中国-东盟海上合作基金项目的通知》（外财函〔2017〕268号），我部拟申报项目如下：

1.中国-东盟滨海湿地的修复与重建能力建设合作项目

2.中国-东盟海洋生物廊道建设合作项目

项目申报材料附后，请予审批。

联系人：环境保护部国际合作司 胡云方

电话：66556546

附件：2018年度中国-东盟海上合作基金项目申报材料

环境保护部

2017年7月28日
