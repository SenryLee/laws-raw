# 全国旅游星级饭店评定委员会公告2017年第6号——全国旅游星级饭店评定委员会关于取消五星级旅游饭店资格的公告

## 全国旅游星级饭店评定委员会关于取消五星级旅游饭店资格的公告

2017年5月31日，经全国旅游星级饭店评定委员会研究决定，取消广东省深圳南海酒店有限公司（标牌编号：4450024）的五星级旅游饭店资格。
