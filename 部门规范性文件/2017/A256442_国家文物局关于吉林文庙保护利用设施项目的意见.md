# 国家文物局关于吉林文庙保护利用设施项目的意见

文物保函〔2017〕1711号

吉林省文物局：

你局《关于报送吉林文庙保护利用设施项目的请示》（吉文物发〔2017〕188号）收悉。经研究，我局意见如下：

一、原则同意吉林文庙保护利用设施项目和你局意见。

二、对所报方案提出进一步修改完善意见：

（一）院落排水外管网项目

1．进一步补充完善文庙历史排水系统的研究，充分论证泮池与市政管网连接、新建排水明渠、集水池的可行性并确保文物安全距离。

2．不宜开挖穿越院墙的管沟，建议采用顶管技术打洞。

3．建议将排水明沟工程与甬路铺墁工程结合进行，排水明沟走向沿甬路牙子内侧；进一步细化设计，如明确排水明沟雨水篦子材质等。

4．集水池等地下设施的埋深，应满足冻结深度和覆土绿化的需要，并完善管沟覆土做法。

（二）院落降土项目

1．补充完善文庙原始地面的现状勘察，局部探明甬路、散水的格局特征和保存状况，及院落地面抬升的原因、位置、结构特征等详细勘察资料，进一步明确现有地表与原始地面的关系。

2．补充说明降土后的甬路临时维护措施及我局2011年《关于吉林省吉林文庙保护修缮工程设计方案的批复》中关于甬路保护相关要求的落实情况。

3．应按照《吉林省吉林文庙保护利用设施建设项目文物影响评估》中的“绿化减缓措施图”内容要求减少补种树木数量，缩小绿环改造范围，进一步论证完善植物更换、补栽、移植等方面的文物影响依据。

4．建议取消东侧甬路东面、西侧甬路西面的新加石坐凳，避免对厢房立面景观和文物环境造成负面影响；建议取消燎炉遗址、水井遗址所在处及其对称位置的石坐凳，便于后续的遗址标示展示。

5．进一步细化景观设计和节点大样，如明确六边形树池的平面方向，增加树池混凝土垫层凹槽，石坐凳座面下方边缘剔凿滴水槽等，有效保障文物环境和避免冻融破坏。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，并根据《文物保护法》第十七条的有关规定报送吉林省人民政府批准后实施。

四、请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保文物安全。

国家文物局
