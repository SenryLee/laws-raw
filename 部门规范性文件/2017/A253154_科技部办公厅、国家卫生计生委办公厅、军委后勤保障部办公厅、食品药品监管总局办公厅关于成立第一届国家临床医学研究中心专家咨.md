# 科技部办公厅、国家卫生计生委办公厅、军委后勤保障部办公厅、食品药品监管总局办公厅关于成立第一届国家临床医学研究中心专家咨询委员会的通知

## 科技部办公厅　国家卫生计生委办公厅军委后勤保障部办公厅　食品药品监管总局办公厅关于成立第一届国家临床医学研究中心专家咨询委员会的通知

国科办函社〔2017〕486号

各有关单位：

按照《国家临床医学研究中心管理办法（2017年修订）》要求，经科技部、国家卫生计生委、军委后勤保障部和食品药品监管总局四个国家临床医学研究中心管理部门推荐，确定了由23名专家组成的第一届国家临床医学研究中心专家咨询委员会（名单见附件）。

专家咨询委员会的主要职责是为中心的建设布局规划、运行管理和评审评估等工作提供咨询；对各中心提出的临床研究重点方向、任务及战略规划等提供咨询；承担管理部门委托的其他工作。每届专家咨询委员会专家聘期三年。

附件：第一届国家临床医学研究中心专家咨询委员会名单

科技部办公厅　　 国家卫生计生委办公厅

军委后勤保障部办公厅　　食品药品监管总局办公厅
