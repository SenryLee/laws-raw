# 国家卫生计生委办公厅关于公布第三批健康促进县（区）项目试点的通知

国卫办宣传函〔2017〕307号

各省、自治区、直辖市卫生计生委，新疆生产建设兵团卫生局：

为贯彻落实《关于加强健康促进与教育的指导意见》（国卫宣传发〔2016〕62号）和《“十三五”全国健康促进与教育工作规划》（国卫宣传发〔2017〕2号）关于加强健康促进县（区）建设工作有关要求，2017年我委将启动第三批健康促进县（区）创建工作。经各地积极申报及我委审核，决定将北京市西城区等68个县（区、县级市、旗）确定为第三批全国健康促进县（区）项目试点地区。现将试点名单印发你们，请严格按照创建工作要求，加强组织领导，做好经费、人员等保障工作，积极探索区域健康促进综合干预模式，建立健康促进长效机制，确保试点工作取得实效。

附件：第三批全国健康促进县（区）项目试点名单

国家卫生计生委办公厅

2017年3月29日
