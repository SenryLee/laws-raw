# 国家新闻出版广电总局关于2017年第三季度全国国产电视剧发行许可情况的通告

〔2017〕11号

根据国家电视剧内容管理的有关规定，现将总局及各省级新闻出版广电行政部门2017年第三季度全国《国产电视剧发行许可证》颁发统计情况予以通告。

2017年度7-9月，全国各类电视剧制作机构共计生产完成并获准发行国产电视剧72部3031集。根据总局以及各省电视剧管理部门的月报备案统计，题材比例情况如下：

现实题材剧目共计42部1654集，分别占总比例的58.33%、54.57%。其中，当代题材共计37部1445集，分别占总部、集数的51.39%、47.67%；现代题材共计5部209集，分别占总部、集数的6.94%、6.9%。

历史题材剧目共计28部1315集，分别占总比例的38.89%、43.39%。其中，近代题材共计22部948集，分别占总部、集数的30.56%、31.28%；古代题材共计6部367集，分别占总部、集数的8.33%、12.11%。

重大题材共计2部62集，分别占总部、集数的2.78%、2.05%。其中，重大革命2部62集。

附件：2017年度7-9月全国《国产电视剧发行许可证》目录
