# 国家文物局关于赤壁摩崖石刻保护规划意见的函

文物保函〔2017〕1922号

湖北省文物局：

你局《关于申报赤壁摩崖石刻保护规划的请示》（鄂文物〔2017〕17号）收悉。经研究，我局批复如下：

一、原则同意所报赤壁摩崖石刻保护规划。

二、对该规划提出以下修改意见：

（一）进一步完善现状评估，增强评估的针对性。补充洪水对文物本体影响的评估，补充交通、基础设施及相关城市规划、风景名胜区规划的评估内容。

（二）完善保护区划管理规定，明确建设控制地带内建筑高度、风貌、规模等控制要求及指标，补充对位于一类建设控制地带内水利设施的控制要求。

（三）进一步梳理保护措施，厘清保护措施与日常管理和专项规划的区别。按照工程性质、保护对象和范围、相关控制要求和节点等进行编制。

（四）深化管理规划，明确管理机构、责权关系、措施和日常工作内容，补充对风景名胜区的管理和协调内容。深化防灾减灾规划、环境规划，明确区分历史和自然环境的保护要求，补充环境整治中拆迁后的整治目标。

（五）进一步规范文本体例，精炼文本内容，统一文本用语，补充安防、视线通廊、交通、基础设施等评估和规划图纸。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的赤壁摩崖石刻保护规划报请湖北省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好赤壁摩崖石刻保护的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

国家文物局

2017年11月30日
