# 国家文物局关于在广教寺双塔保护范围内建设保护管理用房的意见

文物保函〔2017〕1873号

安徽省文物局：

你局《关于审批宣城广教寺双塔保护管理用房建筑设计方案的请示》（皖文物保〔2017〕82号）收悉。经研究，我局意见如下：

一、原则同意在全国重点文物保护单位广教寺双塔保护范围内进行保护管理用房建设和你局意见。

二、对所报项目提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《广教寺双塔保护总体规划》以及安徽省人民政府关于广教寺双塔保护范围的相关管理规定，确保建筑高度、体量、外观样式等符合要求，严格控制工程量和工程范围，尽量减少对文物本体及其环境的影响。

（二）进一步完善方案设计。管理用房外观应简洁，与周边建筑风格相协调；建筑设计应充分考虑地形特征，注意建筑与护坡安全；补充说明调整管理用房选址的理由和选址依据。

（三）应充分考虑建设施工对文物安全的影响，制定必要的文物保护措施和应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善，根据《中华人民共和国文物保护法》第十七条的规定报安徽省人民政府批准。施工中应加强监管，确保文物及历史环境安全。

国家文物局

2017年11月20日
