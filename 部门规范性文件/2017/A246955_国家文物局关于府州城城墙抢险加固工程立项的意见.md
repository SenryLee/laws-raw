# 国家文物局关于府州城城墙抢险加固工程立项的意见

## 关于府州城城墙抢险加固工程立项的意见

办保函〔2017〕39号

陕西省文物局：

你局《关于府州城城墙抢险加固工程立项的请示》（陕文物字〔2016〕231号）收悉。经研究，我局意见如下：

一、所报工程立项的工程性质不明确，工程措施干预过大，缺乏必要的图纸和基础资料，我局暂不同意府州城城墙抢险加固工程立项。

二、对所报立项报告提出以下修改意见：

（一）应根据府州城城墙整体保护展示和城镇建设发展需要，进一步明确城墙保护维修工作的思路和目标，统筹考虑维修重点和进度安排，最大限度地保留城墙的历史信息。补充府州城城墙历次修缮工程情况和工程效果评估内容。

（二）加强现状勘察和研究，明确文物保存现状、病害情况等，补充城墙形制、走向、现状高度等内容。同时，应进一步确定工程性质和内容，准确界定工程范围、强度和具体措施，重点解决城墙结构稳定性问题，确保墙体安全。

（三）完善文本和图纸，补充总平面图。

（四）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。

三、请你局组织有关单位根据《全国重点文物保护单位文物保护工程立项报告规范文本（试行）》的相关要求及我局所提意见，认真修改完善立项报告，并按程序报批。

专此函。

国家文物局

2017年1月20日
