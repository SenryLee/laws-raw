# 国家文物局关于直波碉楼保护规划的意见

## 关于直波碉楼保护规划的意见

办保函〔2017〕91号

四川省文物局：

你局《关于报送〈直波碉楼保护规划〉的请示》（川文物〔2016〕64号）收悉。经研究，我局意见如下：

一、所报规划保护对象认定不清，规划价值评估和研究不足，保护区划不合理，文本编写混乱等诸多问题，应做较大修改，我局不同意《直波碉楼保护规划》。

二、所报规划应做以下必要修改和完善：

（一）关于文物认定和现状评估

1．进一步梳理文物构成和保护对象，明确文物构成;同时，加强历史研究，说明直波碉楼、官寨碉楼、直波古城、直波村寨之间的历史关系。

2．进一步梳理价值评估，分析保护对象年代、选址和建筑形制，突出碉楼作为军事防御建筑的历史价值和特点。

3．进一步完善现状评估，明确文物周边区域建设发展现状，开展必要的景观视域分析，客观评估地震、洪水等自然灾害情况，梳理、归纳评估结论。

（二）关于保护区划与管理规定

应根据文物保护管理需要进一步调整保护区划，建设控制地带应细化分类，并进一步制定具有可操作性的建设控制指标，合理引导村镇建设发展；完善保护区划管理规定。

（三）关于保护措施

应按照《文物保护工程管理办法》，进一步梳理、完善保护对策，管理规定、专项规划内容纳入相应章节。

（四）应梳理、完善专项规划内容，补充考古研究、基础设施建设、居民调控、防灾等专项规划，并在展示规划中明确旅游发展的控制要求。

（五）加强与上位规划及相关规划的衔接。

（六）进一步提炼文本，规范图纸表达。

三、请你局指导有关单位，根据上述意见对直波碉楼保护规划进行全面、认真的修改完善，按程序另行报批。

专此函。

国家文物局

2017年2月7日
