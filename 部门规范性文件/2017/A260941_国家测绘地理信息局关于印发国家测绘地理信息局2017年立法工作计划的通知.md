# 国家测绘地理信息局关于印发国家测绘地理信息局2017年立法工作计划的通知

## 关于印发国家测绘地理信息局2017年立法工作计划的通知

国测法发〔2017〕4号

机关各司室：

《国家测绘地理信息局2017年立法工作计划》已经局务会审议通过，现印发给你们，请认真组织落实。

实施局立法工作计划，必须深入贯彻落实党的十八大、十八届三中、四中、五中、六中全会以及习近平总书记系列重要讲话精神，按照“五位一体”总体布局和“四个全面”战略布局，牢固树立和切实贯彻新发展理念，紧紧围绕测绘地理信息中心工作，以推进测绘地理信息事业加快改革创新发展、大力提升依法行政能力和服务保障水平、全面推进测绘地理信息法治建设等为重点，坚持科学立法、民主立法，努力提高立法质量，更好地发挥法治的引领和保障作用，不断提升测绘地理信息法治化水平。

对局2017年立法工作计划要求年内完成的立法项目，各有关司室要按照《国家测绘地理信息局法规制定程序规定》的要求，制定具体工作方案，明确工作进度，落实工作任务，及时完成起草任务，按时提交送审稿；法规与行业管理司要抓紧审查，有关司室要积极配合。对局2017年立法工作计划列入的调研类项目，有关司室也要抓紧开展研究和起草工作，按时完成任务。法规与行业管理司要加强与有关司室的协调配合，及时了解进展情况，强化督促检查，努力提高送审稿质量，确保立法工作计划顺利实施。

国家测绘地理信息局

2017年4月12日

## 国家测绘地理信息局2017年立法工作计划

2017年，是推进供给侧结构性改革的攻坚之年，也是测绘地理信息事业加快改革创新发展的关键之年，围绕2017年测绘地理信息工作要点，局2017年立法工作的总体思路是：深入贯彻落实党的十八大、十八届三中、四中、五中、六中全会精神，认真学习贯彻习近平总书记系列重要讲话和给国测一大队老队员老党员回信重要指示精神，按照“五位一体”总体布局和“四个全面”战略布局，牢固树立和切实贯彻新发展理念，贯彻落实《法治政府建设实施纲要（2015－2020年）》，稳步实施《国家测绘地理信息局立法规划（2015－2020年）》，转变政府职能，加强事中事后监管，持续推进简政放权、放管结合、优化服务，激发市场活力，保障国家地理信息安全，为事业改革发展提供良好法治环境和有力法治保障。

2017年国家测绘地理信息局立法项目共计15件。其中力争年内完成的立法项目9件，调研类立法项目6件。

一、力争年内完成的立法项目（共9件）

（一）已报全国人大审议的法律草案

1．为夯实测绘地理信息法治基础，贯彻落实总体国家安全观，切实维护国家地理信息安全，强化测绘地理信息统一监督管理，提高公共服务保障能力，促进地理信息产业发展，有必要修订《中华人民共和国测绘法》（以下简称《测绘法》）。目前，《测绘法》修订草案已经十二届全国人大常委会第二十四次会议第一次审议。2017年继续配合立法机关深入开展调研、论证、协调、修改、审议等工作，全力推进新《测绘法》早日修订出台，为测绘地理信息事业改革发展提供有力法治保障。（法规与行业管理司牵头、机关各司室配合）

（二）拟由国土资源部发布的部门规章

2．为进一步细化《地图管理条例》有关规定，完善地图审核工作机制，明确地图审核流程，研究修订《地图审核管理规定》。（法规与行业管理司、地理信息与地图司）

（三）拟由国家测绘地理信息局发布的规范性文件

3．为加强我局电子政务内网管理，保障高效、安全运行，实现与国家电子政务内网国办中心节点的互联互通，研究制定《国家测绘地理信息局电子政务内网管理暂行办法》。（办公室）

4．为构建新型基础测绘体系，进一步加强并规范国家基础测绘项目的管理，提高统筹服务能力，研究修订《国家基础测绘项目管理办法》。（国土测绘司）

5．为加强卫星导航定位基准站的统筹管理，保障国家地理信息安全，促进地理信息产业发展，研究制定《卫星导航定位基准站服务管理办法》。（国土测绘司）

6．为进一步细化上位法规定，完善地图审核程序，提高行政许可的规范化水平，研究修订《地图审核程序规定》。（地理信息与地图司）

7．为进一步规范工程中心管理，发挥工程中心的科技创新平台作用，研究修订《国家测绘地理信息局工程技术研究中心管理办法》。（科技与国际合作司）

8．为提高地理信息标准的科学性、协调性和适用性，促进地理信息标准化工作的规范化、制度化，研究修订《地理信息标准化工作管理规定》。（科技与国际合作司）

9．为适应新形势新任务对测绘标准化工作的新要求和新需求，完善标准范围和相关制度，研究修订《测绘标准化工作管理规定》。（科技与国际合作司）

二、调研类项目（共6件）

（一）拟由国务院发布的行政法规

1．为确保地理国情监测工作的有效开展，规范使用地理国情监测成果，充分发挥其在政府决策、经济社会发展和社会公众服务中的作用，研究制定《地理国情监测条例》。（国土测绘司牵头、相关司室配合）

（二）拟由国土资源部发布的部门规章

2．为配合不动产统一登记制度建设，进一步强化不动产测绘管理，衔接不动产测绘与不动产登记，优化事前准入审批流程，加强事中事后监管，研究制定《不动产测绘管理规定》。（法规与行业管理司）

（三）拟由国家测绘地理信息局发布的规范性文件

3．为规范和繁荣测绘地理信息市场，强化监管和服务，促进市场公平，规范市场秩序，研究修订《测绘地理信息市场管理办法》。（法规与行业管理司）

4．为加强非涉密测绘成果的规范管理，促进测绘成果的社会化应用，研究制定《国家测绘地理信息局非涉密测绘成果管理暂行办法》（地理信息与地图司）

5．为明确测绘地理信息成果的定密机制，与时俱进规范成果管理，促进成果应用，研究制定《测绘地理信息成果定密管理规定》。（地理信息与地图司）

6．为完善地理信息公共服务平台运行机制，切实发挥地理信息公共服务平台在地理信息公共服务中的作用，研究制定《地理信息公共服务平台管理暂行办法》。（地理信息与地图司）
