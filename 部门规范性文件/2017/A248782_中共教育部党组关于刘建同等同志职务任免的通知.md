# 中共教育部党组关于刘建同等同志职务任免的通知

教党任[2017]35号

部内各司局：

中共教育部党组2017年1月25日决定，任命：

刘建同同志为教师工作司巡视员；

王大泉同志为政策法规司副司长（试用期一年）；

刘玉光同志为财务司副司长（试用期一年）；

周为同志为职业教育与成人教育司副司长（试用期一年）；

王启明同志为高等教育司副司长（试用期一年）；

朱小杰同志为民族教育司副司长；

黄伟同志为教师工作司副司长（试用期一年）；

谭方正同志为社会科学司副司长（试用期一年）；

李海同志为国际合作与交流司副司长（试用期一年）。

以上同志原任职务自然免去。

任命孙海波同志为高校学生司副司长（试用期一年）。

因另有任用，免去何光彩同志的民族教育司副司长职务。

中共教育部党组

2017年2月27日
