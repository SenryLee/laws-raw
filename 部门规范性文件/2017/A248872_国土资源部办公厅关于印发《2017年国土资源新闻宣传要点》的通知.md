# 国土资源部办公厅关于印发《2017年国土资源新闻宣传要点》的通知

国土资厅函〔2017〕399号

各省、自治区、直辖市国土资源主管部门，新疆生产建设兵团国土资源局，中国地质调查局和部其他直属单位，各派驻地方的国家土地督察局，部机关各司局：

《2017年国土资源新闻宣传要点》已经部领导审定，现印发给你们，请结合实际细化方案，认真抓好贯彻落实，为迎接宣传贯彻党的十九大营造良好舆论氛围。

请各单位将贯彻落实本要点的年度宣传工作总结和在中央主要媒体开展国土资源宣传报道的情况，请于2018年1月15日前报部办公厅。

2017年3月13日

## 2017年国土资源新闻宣传要点

2017年国土资源新闻宣传工作要全面贯彻党的十八大和十八届三中、四中、五中、六中全会和全国宣传部长会议精神，深入贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，切实增强政治意识、大局意识、核心意识、看齐意识，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，围绕迎接、宣传、贯彻党的十九大，坚持稳中求进工作总基调，坚持围绕中心、服务大局，坚持正确舆论导向，着力加强国土资源供给侧结构性改革的宣传，着力加强国土资源保护和节约集约利用的宣传，着力加强国土资源扶贫和地灾防治的宣传，着力加强“责任落实年”的宣传，着力加强国土资源改革创新的舆论宣传引导，着力讲好国土资源故事、传播好国土资源声音，为开创国土资源事业改革发展新局面提供有力舆论保障。

一、大力营造迎接宣传贯彻党的十九大的良好舆论氛围

坚持把深入学习宣传贯彻习近平总书记系列重要讲话精神作为一项重大政治任务，特别是深入宣传贯彻习近平总书记关于国土资源工作的一系列重要指示精神，大力宣传国土资源部门贯彻落实党中央治国理政新理念新思想新战略的重要部署、重大举措。深入宣传党的十八届六中全会精神及贯彻落实情况，宣传突出抓好理想信念教育，坚定不移推进全面从严治党的重大部署，推动“两学一做”学习教育常态化制度化取得的成效。

深入宣传贯彻落实中央经济工作会议精神，重点宣传国土资源部门坚持新发展理念，主动适应经济发展新常态，着力推进供给侧结构性改革，切实做好减少过剩产能、服务保障经济振兴等的新举措新进展。深入宣传贯彻落实中央农村工作会议精神，重点宣传加快构建保障农业发展用地机制，进一步完善现代农业发展用地政策，支持农村新产业、新业态发展的政策措施和成效。认真组织开展贯彻落实十二届全国人大五次会议和全国政协十二届五次会议精神的宣传报道，深入宣传解读政府工作报告关于国土资源工作的主要内容和基本精神，宣传贯彻落实政府工作报告的政策措施和工作进展。

深入宣传党的十八大以来国土资源系统努力适应经济发展新常态，积极应对经济下行压力加大、资源环境约束趋紧等重大挑战，顽强拼搏、锐意进取，为经济社会持续健康发展作出的积极贡献。认真组织开展“砥砺奋进的五年”主题宣传活动。宣传国土资源系统践行社会主义核心价值观和国土资源系统的先进典型，组织开展最美国土资源人物评选，广泛宣传“三光荣”、“四特别”精神，壮大主流声音，唱响主旋律，为迎接党的十九大营造良好舆论氛围。精心组织学习贯彻落实党的十九大精神的宣传报道。

二、广泛突出宣传十八大以来国土资源工作取得的重要成就

广泛宣传国土资源保护成效。宣传坚守18亿亩耕地红线，努力加强耕地保护，大力开展土地整治和高标准农田建设，划定永久基本农田，持续推进找矿突破战略行动，为国家经济健康发展提供资源保障的工作成效。

广泛宣传国土资源节约集约利用成效。宣传全面推进土地节约集约利用，严控增量、盘活存量、优化结构、提升效率的典型和经验。宣传开展矿产资源节约和综合利用的成效。宣传国土资源节约集约模范县市创建活动的先进典型和经验。

广泛宣传维护群众资源权益成效。宣传不动产统一登记制度全面推进，农村集体土地所有权登记全面完成，加强房地产市场调控，保障性安居工程用地应保尽保的工作成效。宣传强化重点地区和重要时段地质灾害防治，加强“十有县”和省级地质灾害综合防治体系建设的工作成果。宣传全力支持脱贫攻坚，全力推动精准扶贫、精准脱贫取得的成效。

广泛宣传国土资源管理重点领域制度改革创新成效。宣传加强顶层设计，重点推进土地制度改革试点的典型经验。宣传改革完善征地办法，对被征地农民实行多元化安置的成果。宣传深化科技体制改革，加快科技创新的工作成果。宣传推进“放管服”改革取得的成效。

宣传国土资源利用和管理秩序持续向好成效。宣传国土资源法律法规日益健全，执法监察手段不断丰富，土地督察业务体系更加完善的工作成果。宣传国土资源规划体系基本形成，规划统筹管控作用得到加强的工作成果。宣传国土资源政务信息公开力度不断加大的成效。宣传国际合作深化拓展的成果。宣传推进“放管服”改革取得的成效。

广泛宣传开展党的群众路线教育实践活动、“三严三实”专题教育和“两学一做”学习教育取得的成效。宣传贯彻党要管党、从严治党方针，认真落实“两个责任”，着力建章立制，扎紧制度笼子，严肃查处腐败案件，坚决遏制土地出让和矿产开发领域腐败易发多发势头取得的成效。

三、着力宣传2017年国土资源重点工作

大力宣传国土资源系统开展“责任落实年”活动的重要意义及做法成效。重点宣传“责任落实年”活动开展情况，及时宣传报道活动开展动态和成效，宣传总结各地各单位在活动开展中创造的好经验好做法，为活动扎实开展搭建交流学习平台、营造良好舆论氛围。

大力宣传持续推进供给侧结构性改革，严把新增产能用地、用矿关口，加强执法监管，积极推动化解过剩产能的工作成果。宣传开展低效用地再开发和工矿废弃地复垦利用取得的成效。宣传优化土地供应结构，盘活土地等闲置资产取得的进展。宣传以非常之策助脱贫取得的成效。

大力宣传提高资源保障能力，支持重点产业发展，落实住房用地供应分类管理制度的成效。宣传落实和完善产业用地政策，促进新型城镇化建设的成果。宣传做好《全国国土规划纲要》实施和省级国土规划、乡村土地利用规划编制，开展城市开发边界划定工作取得的成果。

适时总结宣传统筹协调推进农村土地制度改革三项试点取得的经验。宣传、深入推进自然资源管理制度改革等综合性改革的经验。宣传、扩大国有土地有偿使用范围的配套政策和改革的经验。宣传开展建设用地使用权转让、出租、抵押等二级市场试点的经验。宣传，以及协同推进山水林田湖生态保护修复试点工程的成效和经验。宣传深化“放管服”改革，进一步简化审批程序，推行“互联网+政务服务”取得的成效。

广泛宣传实施国土资源科技创新战略，推进“三深一土”任务实施，实施高层次创新型科技人才培养工程取得的成果。宣传加强重大科技体制改革政策实施，落实科研管理共同责任机制的成果。

深入宣传创新耕地保护机制，贯彻党中央、国务院关于加强耕地保护和改进占补平衡的意见，强化耕地数量质量生态“三位一体”管护的工作成效。宣传全面推进建设占用耕地耕作层剥离再利用的典型经验。宣传、落实《土地整治规划》，、统筹实施土地整治和高标准农田建设的典型经验以及工作成果。宣传推进永久基本农田划定、保护的工作成效。宣传促进健全耕地保护补偿机制的政策措施和经验。

大力宣传矿产资源勘查开发和保护，宣传找矿突破战略行动第三阶段重点工作，加强公益性、基础性地质调查的工作成果。宣传开展探明储量矿产资源统一确权登记工作试点的经验。宣传城市地质调查工作为城市规划和地下空间开发利用服务的做法。做好国际矿业大会的宣传。

广泛宣传深入推进资源节约集约利用，坚持最严格的节约用地制度，全面实施建设用地总量与强度“双控”行动，落实单位国内生产总值建设用地下降目标取得的工作成效。宣传推进城镇低效用地再开发的典型经验。大力宣传、国土资源节约集约模范县市创建活动的典型经验。宣传绿色矿业发展示范区和矿产资源综合利用示范基地建设成果。

广泛宣传维护群众资源权益，加快不动产统一登记数据整合，健全不动产权籍调查制度的工作成果。宣传维护被征地农民合法权益，加大征地信息公开力度的典型经验。宣传落实地质灾害防治责任制，推进地质灾害综合防灾体系建设的典型经验。做好煤矿超层越界专项检查整治行动宣传。
