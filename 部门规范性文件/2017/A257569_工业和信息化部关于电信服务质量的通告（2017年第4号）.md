# 工业和信息化部关于电信服务质量的通告（2017年第4号）

工信部信管函〔2017〕499号

为推进电信服务质量持续改善，根据《中华人民共和国电信条例》相关规定，现将2017年第三季度电信服务有关情况通告如下：

一、电信服务基本情况

（一）服务能力持续提升。截至三季度末，全国电话用户总数达到15.92亿户，其中移动电话用户13.95亿户。“宽带中国”战略稳步推进，宽带提速效果日益显著。固定宽带用户达到3.37亿户，其中20Mbps及以上用户占比达89%，50Mbps及以上用户占比达61.5%。光纤宽带加快普及，光纤接入（FTTH/O）用户总数达到2.79亿户，占固定宽带用户总数的82.7%。移动宽带用户达到10.9亿户，其中4G用户保持稳步增长，全国新增4G用户1.77亿户，总数达到9.47亿户，占比达67.9%。

（二）网络运行安全畅通。三季度，全国电信网和互联网运行平稳，通信服务质量整体稳定，电话接通率、互联网可接入率等符合《电信服务规范》指标要求。三季度，通信行业周密部署，圆满完成金砖国家领导人第九次会晤网络安全和通信保障任务，全力做好党的十九大网络安全和通信服务保障工作；同时快速响应，积极应对四川、广东、福建等地地震和气象类突发事件。累计投入应急通信保障人员23.9万人次、抢修车辆8.8万台次、油机13万台次、发送公益应急短信息16.6亿条，及时抢修恢复基站8.6万站次、通信光缆1.5万公里，保障抗灾救灾指挥及党政军等重要部门通信畅通，迅速恢复了灾区的通信服务，有力保障了公众通信网络整体运行平稳。

（三）推动互联网与经济社会各领域深入融合。国务院印发《关于进一步扩大和升级信息消费持续释放内需潜力的指导意见》，部署进一步扩大和升级信息消费，充分释放内需潜力，壮大经济发展内生动力。工业和信息化部发布《工业和信息化部关于进一步扩大宽带接入网业务开放试点范围的通告》，进一步放开基础电信运营领域，激发民间投资潜力和创新活力，推动形成宽带市场多种主体相互竞争、优势互补、共同发展的市场格局。截至三季度末，移动互联网接入流量累计达154亿吉比特，同比增长148.3%；固定互联网宽带接入流量达1308亿吉比特，保持稳步快速增长；智能手机出货量为3.45亿部，同比下降7.0%。

二、电信用户申诉举报情况

（一）电信服务申诉情况。三季度，工业和信息化部及各省（自治区、直辖市）电信用户申诉受理机构共受理电信用户申诉17245人次，同比下降24.1%，环比上升28.0%；季度百万用户申诉率为9.0人次，同比下降3.5人次，环比上升1.9人次（详见附件1、2）。收费争议类申诉占比38.1%，环比上升6.7个百分点，用户主要反映手机上网费用争议和套餐收费争议；用户服务类申诉占比41.2%，环比下降5.3个百分点；网络质量类申诉占比20.7%，环比下降1.4个百分点。

各级申诉受理机构按照《电信用户申诉处理办法》相关规定，对用户申诉进行了处理和调解，有效维护了电信用户合法权益。

（二）垃圾短信举报情况。三季度，12321网络不良与垃圾信息举报受理中心受理垃圾短信举报36796件，同比上升23.4%，环比下降4.4%。其中，点对点类垃圾短信举报6275件，占举报总量的17.1%，较上季度下降2.9个百分点，被举报率为4.0件/百万用户，环比下降22.2%；端口类举报22913件，占举报总量的62.3%，较上季度上升0.3个百分点，被举报率为16.0件/亿条，环比下降3.8%；疑似伪基站发送短信相关举报7608件，占举报总量的20.7%，较上季度上升2.6个百分点。从内容看，商业广告营销类占比79.5%，较上季度上升2.9个百分点，主要涉及商品零售营销、金融保险推销等；涉嫌违法犯罪类占比20.5%，主要涉及欺诈、非法经营活动等。相关电信企业已将发送垃圾短信的号码及端口进行处置，内容涉嫌违法犯罪的已提请公安部门处理。

（三）不良手机应用举报情况。三季度，12321网络不良与垃圾信息举报受理中心共接到不良手机应用有效举报192049件次，同比下降41.4%，环比上升10.3%。通过行业自律，联合应用商店、安全检测厂商对其中存在问题的966款不良手机应用进行了下架处理。

三、电信服务监管情况

（一）三季度，工业和信息化部发布《互联网域名管理办法》《关于进一步规范境内域名注册服务市场的通知》《关于进一步加强未备案网站管理工作的通知》，规范互联网域名服务和境内域名注册服务市场，保障互联网域名系统安全、可靠运行，加强网站管理，保护用户合法权益，促进中国互联网健康发展。

（二）三季度，工业和信息化部发布《公共互联网网络安全威胁监测与处置办法》《工业和信息化部关于开展2017年电信和互联网行业网络安全试点示范工作的通知》，健全公共互联网网络安全威胁监测与处置机制，指导鼓励企业建立、完善和创新安全技术手段，提升电信和互联网行业网络安全保障能力和水平，维护公民、法人和其他组织的合法权益。

（三）三季度，工业和信息化部组织对55家手机应用商店的应用软件进行技术检测，发现违规软件31款，涉及违规收集使用用户个人信息、恶意“吸费”、强行捆绑推广其他应用软件等问题（详见附件3），已责令下架。组织对三家基础电信企业和72家增值电信企业180项业务进行抽查，发现6项增值业务存在问题，涉及业务内容更新不及时、业务无法使用等（详见附件4），已督促整改。

工业和信息化部、各省（自治区、直辖市）通信管理局依据《中华人民共和国电信条例》等有关规定，对检查发现的问题及侵害电信用户合法权益的行为进行责任追究，问责督办15件次，查处违规电信企业16家次。

（四）9月底，工业和信息化部组织督查组，对北京地区三家基础电信企业市公司和部分区公司，以及部分宽带接入试点企业进行了检查，检查内容包括开展电信行业行风纠风工作情况、提升信息通信领域服务质量和效率工作情况、提升网络质量和服务水平专项工作情况、宽带接入服务行为专项整治工作情况等。

（五）三季度，工业和信息化部按照党的十九大网络信息安全保障工作安排和2017年省级基础电信企业网络与信息安全责任考核中期检查工作要求，组织对基础电信企业进行全面检查，重点对北京、河北、吉林等11个省（区、市）公司及三家基础电信企业CDN/云基地（公司）十九大保障及安全责任考核工作落实情况进行了实地抽查，并现场针对检查发现的突出问题明确了整改要求。

（六）三季度，工业和信息化部要求三家基础电信企业集团公司按照《关于进一步防范和打击通讯信息诈骗工作的实施意见》（工信部网安函〔2016〕452号）和用户举报通报有关要求，指导各省公司进一步完善防范打击通讯信息诈骗制度建设，做好用户举报通报核查、处置、问责工作；强化技术手段建设、使用和管理，提升疑似诈骗手机号码预警能力；持续加大监督检查问责力度，确保压力不减、要求不松。

四、经营及消费提示

（一）经营提示

1.三家基础电信企业要做好取消手机国内长途和漫游费的后续工作，特别是用户服务工作，继续做好用户相关咨询问题的解释说明，妥善解决用户投诉，维护用户合法权益。

2.三家基础电信企业要高度重视近期用户集中反映的部分资费套餐限制老用户选择问题，严格执行《关于保障移动电话用户资费方案选择权的通知》（信部联清〔2006〕630号）等文件，不得推出限制老用户选择的资费方案，并妥善解决相关用户投诉，切实维护用户合法权益。

3.各企业在进行年底促销时，不得虚假宣传、夸大宣传，不得模糊或淡化限制性条件，不得恶意贬低竞争对手，严格遵守相关要求，切实保障用户的知情权、选择权等合法权益。

（二）消费提示

1.工业和信息化部提醒广大用户增强防范意识和风险意识，谨防通讯信息诈骗，接到疑似诈骗电话请拨打12321或电信企业客服热线及时举报。

2.工业和信息化部提醒广大用户在办理电信业务和使用互联网服务时，要仔细阅读服务协议、隐私条款，详细了解业务中的注意事项或限制性条件，理性选择适合自身需求的产品。
