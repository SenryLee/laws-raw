# 国家文物局办公室关于北京孔庙、国子监院内16座碑亭修缮工程的意见

办保函〔2017〕1393号

北京市文物局：

你局《关于孔庙国子监碑亭修缮工程方案的请示》（京文物〔2017〕1487号）收悉。经研究，我局意见如下：

一、根据所报方案，孔庙、国子监院内16座碑亭现状基本稳定，拟修缮内容应定性为日常保养维护工作。

二、应进一步核实各碑亭的残损情况，明确保护措施和工程量，尽可能避免不必要的干预。

三、进一步深化方案图纸深度。

四、请你局指导有关单位，按照上述意见和《古建筑保养维护规程》，做好对孔庙、国子监的日常保养维护工作，确保文物建筑安全。

专此函复。

国家文物局办公室

2017年12月18日
