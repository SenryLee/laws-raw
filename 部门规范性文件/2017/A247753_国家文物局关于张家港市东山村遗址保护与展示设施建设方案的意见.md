# 国家文物局关于张家港市东山村遗址保护与展示设施建设方案的意见

## 关于张家港市东山村遗址保护与展示设施建设方案的意见

办保函〔2017〕96号

江苏省文物局：

你局《关于呈报〈张家港市东山村遗址保护与展示设施建设方案〉的请示》（苏文物保〔2016〕269号）收悉。经研究，我局意见如下：

一、暂不同意张家港市东山村遗址保护与展示设施建设方案。

二、所报方案尚需做以下必要的修改和完善：

（一）补充说明东山村遗址分布及保存的整体情况，并说明后续保护展示的整体思路。同时，应进一步说明拟保护展示遗址考古、保护等情况。

（二）补充说明拟展示遗址所处区域的城市发展及规划情况，进一步明确拟建保护展示设施的后续功能定位。

（三）在上述工作的基础上，进一步优化保护展示设施的具体设计，合理安排功能布局，优化外观设计，注意与遗址及其周边环境相协调。同时，进一步补充说明保护展示设施内部遗址展示的相关设计。

（四）进一步规范文本和图纸，做到科学、详细。

三、请你局指导方案设计单位根据上述意见，对所报方案做进一步修改和完善，经你局核准后，按程序另行报批。

国家文物局

2017年2月8日
