# 国家文物局关于归德府城墙西墙、北墙维修保护工程立项的意见

## 关于归德府城墙西墙、北墙维修保护工程立项的意见

办保函〔2017〕330号

河南省文物局：

你局《关于再次上报归德府城墙（西墙、北墙）维修保护工程立项的请示》（豫文物〔2017〕60号）收悉。经研究，我局意见如下：

一、暂不同意归德府城墙西墙、北墙维修保护工程立项。

二、请你局切实加强文物保护工程管理，督促地方人民政府和有关单位，全面梳理归德府城墙文物保护工程进展情况，总结、评估工程实施效果，核查项目进度、质量和经费使用情况，按照我局《关于进一步规范国家重点文物保护专项补助资金管理、提高使用绩效的通知》（文物办发〔2017〕5号）要求，根据相关批复文件、方案设计等的要求，抓好已批复项目的实施工作，确保工程质量和工地安全。

三、应根据《归德府城墙保护规划》的原则和要求，结合城墙保护、展示和管理需要，统筹考虑西墙、北墙维修工程的目标和任务分期。

四、请你局督促地方人民政府切实加强归德府城墙日常保养和岁修工作，落实管理维护责任，确保文物安全。

专此函。

国家文物局

2017年3月27日
