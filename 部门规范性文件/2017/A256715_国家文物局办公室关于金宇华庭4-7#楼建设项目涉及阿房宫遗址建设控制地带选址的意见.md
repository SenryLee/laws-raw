# 国家文物局办公室关于金宇华庭4-7#楼建设项目涉及阿房宫遗址建设控制地带选址的意见

办保函〔2017〕1183号

陕西省文物局：

你局《关于金宇华庭4-7#楼项目选址涉及阿房宫遗址建设控制地带的请示》（陕文物字〔2017〕185号）收悉。经研究，我局意见如下：

一、所报项目选址位于上林苑一号建筑遗址、二号建筑遗址的一类建设控制地带内，且为住宅建设项目，不符合《阿房宫遗址保护规划》关于一类建设控制地带的管理规定和控制要求。我局暂不同意金宇华庭4-7#楼建设项目涉及阿房宫遗址一类建设控制地带的选址方案。

二、请你局按照《阿房宫遗址保护规划》要求，指导项目建设单位，进一步论证项目建设的必要性和可行性，建议另行选址，确保文物安全。

国家文物局办公室

2017年10月20日
