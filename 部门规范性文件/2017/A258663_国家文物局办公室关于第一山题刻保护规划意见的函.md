# 国家文物局办公室关于第一山题刻保护规划意见的函

办保函〔2017〕1333号

江苏省文物局：

你局《关于审批〈第一山题刻保护规划〉的请示》（苏文物保〔2016〕310号）收悉。经研究，我局意见如下：

一、所报规划保护对象认定不清，规划深度不够，我局暂不同意第一山题刻保护规划。

二、所报规划应做以下必要修改和完善：

（一）关于文物认定和现状评估

1. 梳理文物构成，补充规划文物构成与全国重点文物保护单位文物构成的对照清单，说明石刻数量不一致的原因。进一步明确保护对象，并说明依据。

2. 补充说明将山下临江旧城改造区域纳入规划范围的可行性和必要性。

3. 加强历史研究，明确第一山题刻与运河的关系，进一步完善价值评估，提炼文物核心价值。

4. 深化现状评估，补充题刻赋存载体稳定性和安全性评估以及新建建筑对文物的影响评估。

（二）关于保护区划与管理规定

1. 根据文物本体分布和保护管理需要，科学划定保护区划，建议适当缩小保护区划范围。保护范围不宜分级，建设控制地带应结合用地性质合理分类。

2. 进一步细化、完善保护区划管理规定。

（三）关于保护措施

1. 应进一步梳理、完善石刻本体保护措施，细化监测措施，补充题刻承载载体的保护措施，加强专业性和针对性。

2. 进一步论证建设保护性设施的必要性，并明确保护性设施的选址、规模、高度、风貌、材料等控制要求。

（四）关于环境整治和专项规划

1. 应根据文物周围建筑风貌影响评估，合理控制环境整治的范围和力度，增强可操作性。

2. 展示利用规划应明确展示的目标、方式和主题，并科学确定游客承载量，确保文物安全。

3. 管理规划应明确文物管理单位和国家森林公园管理单位的权责关系。

4. 基础设施规划应根据文物保护管理需要合理确定规划内容。

（五）补充所报规划与国家森林公园规划等相关规划的衔接内容。

（六）进一步深化文本，注意规范用语，校核图纸表达，补充规划分期等图纸内容。

三、请你局指导有关单位，根据上述意见对第一山题刻保护规划进行全面、认真的修改完善，按程序另行报批。

专此函。

国家文物局办公室

2017年12月6日
