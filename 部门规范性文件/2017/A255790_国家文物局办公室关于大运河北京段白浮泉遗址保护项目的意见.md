# 国家文物局办公室关于大运河北京段白浮泉遗址保护项目的意见

办保函〔2017〕983号

北京市文物局：

你局《关于大运河——白浮泉遗址修缮方案的请示》（京文物〔2017〕770号）收悉。经研究，我局意见如下：

一、所报方案前期勘察和研究不足，设计依据不充分，文本深度不够，我局暂不同意大运河北京段白浮泉遗址修缮项目。

二、对所报方案提出以下修改意见：

（一）加强现状勘察和研究，核实碑亭地面酥碱、油饰残破、博缝板开裂、东配殿屋面瓦松动等的具体位置、范围，科学评估病害程度，明确各文物建筑具体残损范围及残损量。补充泊岸残损现状勘察、病因分析和大运河北京段白浮泉遗址历次修缮工程情况和工程效果评估内容，在此基础上合理确定工程性质和范围。

（二）补充大运河北京段白浮泉遗址的建造工艺、做法、建筑材料和构造特征等研究和分析内容。

（三）应以现状整修为主，严格控制工程量和工程强度，避免过度保护。不同意九龙头石雕清洗见新和修补残损部位，石雕和条石仅做表面局部油污清洗即可。东、西配殿已破坏的壁画进行拓样复绘应慎重，建议实施随色处理措施。

（四）进一步补充设计依据，完善工程做法，细化修缮措施。

1．根据现状评估结论进一步核定泊岸拆砌、修补、补配、重砌等措施。

2．进一步论证拆除都龙王庙正殿西侧2米范围内散水及甬路铺装，重做灰土并铺墁散水及甬路和拆除现有护坡墙并按原制恢复的必要性和可行性，补充设计依据。

3．不同意院内地面重做绿植和铺墁的做法，避免改变原有院落形制。

（五）九龙池周围甬路修缮项目不宜纳入本次工程范围。按照环境整治原则对现状铺装进行现状修缮即可。

（六）进一步规范文本和图纸，细化现状图纸，补充标注残损范围和残损量。

三、请你局组织相关单位根据所提意见，对项目方案进行修改完善后，按我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）的相关要求另行报批。

专此。

国家文物局办公室

2017年8月21日
