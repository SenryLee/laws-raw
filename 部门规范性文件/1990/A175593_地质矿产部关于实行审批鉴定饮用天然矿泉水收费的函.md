# 地质矿产部关于实行审批鉴定饮用天然矿泉水收费的函

## 地质矿产部关于实行审批鉴定饮用天然矿泉水收费的函（1990年1月18日　地发17号）

国家物价局：

我国矿泉水资源丰富，分布地区广，随着国民经济建设发展和对外开放的需要，矿泉水资源开发日趋增多。由于矿泉水既是矿产资源，又属生活饮料，为保证消费者的利益，又保护好国家矿产资源，加强科学管理，1988年国家标准局发布了《饮用天然矿泉水国家标准》(附件)。根据国家标准的要求，对其技术质量要严格审查检测。经卫生部、轻工业部和地矿部三部主管部门协商；制定了对饮用天然矿泉水实行国家鉴定和审批的制度，内容包括：评审咨询、专项测试、现场调查、复审及批准证书。由于饮用天然矿泉水属开发性质，各主管部门无此专项经费，采取谁开发受益，谁支付上述费用的原则。经测算每一个拟开发的矿泉水产地、厂家需交评审检测费3500．00元。其中：

```
评审费　　　　　　25％

现场调查差旅费　　45％

复检费　　　　　　15％

管理费　　　　　　15％
```

对属国家或省区贫困县以及经费确有困难的部门单位出具地(市)级证明可酌情减免。上述事项由三部主管部门共同管理，根据国标规定，具体工作由挂靠单位地矿部地质环境管理司(原水文地质工程地质司)办理。

附件：饮用天然矿泉水国家标准(GB8537—87)(略)
