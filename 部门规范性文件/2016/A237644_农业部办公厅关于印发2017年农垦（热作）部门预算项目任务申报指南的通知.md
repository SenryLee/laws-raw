# 农业部办公厅关于印发2017年农垦（热作）部门预算项目任务申报指南的通知

农办垦[2016]15号

各省、自治区、直辖市及广州、南京市农垦管理部门，新疆生产建设兵团办公厅，海拉尔、大兴安岭农（牧）场管理局，福建、湖南、广东、广西、海南、四川、贵州、云南省、自治区农业厅（委），福建、广东、广西、海南、贵州、云南省、自治区农科院，海南大学，中国热带农业科学院，农业部南亚热带作物中心：

为做好2017年农垦（热作）部门预算项目实施准备工作,提高项目管理精准度,提升项目支出预算编制水平,我部编制了2017年农垦(热作)部门预算项目任务指南（以下简称“指南”）,现印发给你们,并就有关事项通知如下。

一、请各部门、单位按照“指南”要求，结合实际，认真组织开展2017年预算项目任务申报工作，科学设计项目任务方案内容和绩效目标，清晰反映具体活动内容和结果，实事求是测算支出需求。除热作专项以外，其他预算项目任务以省级主管部门作为项目任务申报单位。

二、请申报单位认真审核项目任务资金支出，资金经济分类预算表中没有列支的支出科目，一律不得申报。

三、请各申报单位于2016年7月5日前，将“指南”规定的申报材料报送我部农垦局部门预算项目任务分管处室。项目任务申报材料电子格式可从农业部农垦局网站（www.nkj.moa.gov.cn）下载。

附件：1.2017年农垦执法监管专项工作经费（农垦安全生产专项）项目任务指南

2.2017年农产品质量安全监管专项经费（农垦农产品质量追溯专项）项目任务指南

3.2017年农业国际交流与合作（农垦“走出去”专项）项目任务指南

4.2017年农业农村资源等监测统计经费（农垦工业信息化专项）项目任务指南

5.2017年农业技术试验示范与技术服务支持（南亚热作专项）项目任务指南

6.2017年物种品种资源保护费（热带作物）项目任务指南

7.2017年农作物病虫鼠害疫情监测与防治经费（热带作物）项目任务指南

8.2017年农业业务培训费项目任务指南

9.2017年农业农村资源等监测统计经费（农垦农工负担监测专项）项目任务指南

10.2017年农垦执法监管专项工作经费（农垦土地确权专项）项目任务指南

11.2016年农垦执法监管专项工作经费（农垦社会事业发展专项）项目任务指南

12.2017年农业技术试验示范与技术服务支持（农垦农业技术试验示范与技术服务支持专项经费）项目任务指南

13.2017年农业农村资源等监测统计经费（天然橡胶产业运行预警体系建设专项）项目任务指南
