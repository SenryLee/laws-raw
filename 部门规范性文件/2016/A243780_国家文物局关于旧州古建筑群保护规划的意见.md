# 国家文物局关于旧州古建筑群保护规划的意见

## 关于旧州古建筑群保护规划的意见

办保函〔2016〕1132号

贵州省文物局：

你局《关于送审〈贵州旧州古建筑群保护规划〉的请示》（黔文物呈〔2015〕188号）收悉。经研究，我局意见如下：

一、所报规划的保护对象和文物构成不明，前期勘察和研究不足，文本深度不够，我局暂不同意旧州古建筑群保护规划。

二、所报规划应做以下必要修改和完善：

（一）关于文物认定和评估

1.进一步梳理、明确文物构成和保护对象，说明文物构成增加原因和依据，并根据建筑类型分类表述保护对象，补充文物认定清单。

2. 深化价值评估，加强历史研究，系统梳理旧州古建筑群在黔东南交通贸易中的历史地位和作用，深入挖掘文物的历史价值、艺术价值和科学价值，并客观评估后期恢复新建建筑的真实性。

3. 加强现状评估，应在各文物建筑单体病害情况评估的基础上，系统归纳旧州古建筑群的整体保存状况，明确评估结论。同时，完善自然环境和历史人文环境评估内容，并客观评价现行保护区划与管理措施执行效果、历次修缮工程情况、周边区域建设活动及基础设施状况等。

4. 补充说明当地洪涝等自然灾害情况。

（二）关于保护区划和管理规定

1. 应根据文物分布情况、现状评估结论和保护管理需要，进一步调整保护区划和具体边界，增强可操作性。建议慎重论证设立风貌协调区的必要性，可考虑缩小风貌协调区范围，并将其纳入建设控制地带。补充保护区划调整的整体思路说明和依据。

2. 应结合《历史文化名城名镇名村保护条例》要求，合理调整管理规定，科学确定建设控制地带的管理要求和具体建筑控制指标，并进一步降低建筑限高。

（三）关于保护措施

应根据现状评估结论，针对不同类型的保护对象分别研提文物保护措施，进一步明确保护工程的类别、内容和要求，提高保护措施的针对性与专业性。

（四）关于环境整治和专项规划

1. 加强展示利用研究，应分别制订民居、祠庙、桥梁等不同类型文物的展示利用方式、展示主题、展示内容等，充分考虑当地居民的合理诉求，确保文物安全和合理利用，兼顾民生改善和地方经济社会发展。补充游客容量测算依据。

2. 完善专项规划内容。电力电信、给排水等基础设施建设应注意与周边区域的市政设施建设相衔接；安全防护规划应补充防洪相关内容；管理规划应补充居民调控的具体目标和规划要求。

（五）加强与相关上位规划和历史文化名镇规划的衔接。

（六）结合实际调整规划分期与规划时限。

（七）核实经费预算，补充取费标准。

（八）进一步规范、梳理文本。规划依据所引法律文件应注意时效性；完善规划图纸，增强图文对应性，补充历史名镇保护区划图。

三、请你局组织有关单位根据上述意见对所报保护规划进行修改、完善，按程序另行报批。

专此函。

国家文物局
