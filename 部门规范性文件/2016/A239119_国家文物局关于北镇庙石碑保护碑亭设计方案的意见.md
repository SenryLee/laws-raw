# 国家文物局关于北镇庙石碑保护碑亭设计方案的意见

## 关于北镇庙石碑保护碑亭设计方案的意见

办保函〔2016〕699号

辽宁省文物局：

你局《关于上报北镇庙石碑保护碑亭设计方案的请示》（辽文物〔2016〕34号）收悉。经研究，我局意见如下：

一、所报方案的设计依据不足，文本深度不够，我局暂不同意北镇庙石碑保护碑亭设计方案。

二、对所报方案提出以下修改意见：

（一）应加强前期勘察和研究，进一步明确石碑保存现状、主要病害类型和病因，充分说明气候变化对石碑安全的影响，论证建设保护碑亭、碑廊的必要性和可行性，评估拟建碑亭、碑廊对文物及其周边环境的影响。补充《北镇庙文物保护规划》关于碑亭、碑廊建设的相关内容。

（二）进一步梳理历史资料，明确碑亭位置、形制、建筑材料和构造特征等，核实工程性质和内容，从保护性设施建设的角度调整方案设计思路。

（三）完善和深化方案内容。

1. 应明确碑亭、碑廊外观样式和功能之间的关系，比较木构建筑和现代材料、样式的优劣，研提多种比选方案。

2. 结合遗存台基位置、老照片资料和北镇庙现有文物建筑样式，明确拟建六角亭与方亭的建筑体量关系，进一步调整六角亭设计尺寸，校核方亭歇山顶屋面的收山比例。

3. 应慎重考虑现有台基遗址的保护问题，明确拟建碑亭与遗址的空间位置关系，研提具体的遗址保护措施。

4. 明确新建碑廊的选址、建设规模、建筑高度、外观等具体内容和项目设计依据，说明拟建碑廊台基与石碑的关系，评估石碑提升移动的安全问题，统筹考虑石碑基座和碑廊基础设计。

（四）补充北镇庙石碑的现状图。

三、请你局组织有关单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，对所报方案进行修改、完善，按程序另行报批。

专此函。

国家文物局

2016年7月4日
