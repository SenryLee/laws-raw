# 科技部关于征集中国与欧洲核子研究中心（CERN）2016年度政府间科技合作项目建议的通知

国科发外〔2016〕36号

各省、自治区、直辖市及计划单列市科技厅（委、局），国务院各有关部门科技主管单位，各有关单位：

根据中华人民共和国政府和欧洲核子研究中心（CERN）关于在CERN研究项目中进一步开展科技合作的协议以及据此签订的专项议定书—ALICE实验，现征集“欧洲核子研究中心（CERN）”2016年度政府间科技合作项目建议。有关事项通知如下。

一、项目简介及目标

欧洲核子研究中心（CERN）是目前世界上最大的粒子物理研究中心，是基础科学研究、高技术研发、一流人才培养的重要国际基地。CERN目前正在运行的大型强子对撞机（LHC）是世界上最先进、能量和亮度最高的强子对撞机。LHC上有4个重要实验，分别是：代表高能量前沿的ATLAS和CMS实验、高精度前沿的LHCb实验和研究相对论重离子碰撞物理的ALICE实验。

上世纪80年代以来，我国一直与CERN保持良好合作关系。2004年科技部代表中国政府与CERN签署科技合作协议，2010年11月我国与CERN签署《关于进一步加强科技合作的联合意向声明》，进一步加强合作。2012年12月第一次“中国—CERN合作委员会会议”在我国召开，双方对合作领域、项目、人员、资助等进行了交流，确定了合作委员会的年会机制。我国参加了LHC上的全部4个实验（ALICE, ATLAS,CMS,和LHCb），同时参与了LHC加速器和网格计算技术研究工作。通过与CERN近30年的合作，我国在基础科学研究、高技术发展和人才培养等多方面获得了很大收益。

此次征集的项目旨在继续支持国内相关单位参与CERN合作研究，在实现中方对外承诺的同时，提升国内相关高新和前沿基础研究的科技创新能力，为解决人类共同关注的科学目标做出贡献。

二、2016年拟支持的重点领域与重点方向

（一）重点领域。

1. 高性能先进粒子探测与数据处理技术；

2. 极端相对论重离子碰撞实验物理。

（二）重点方向。

1. ALICE像素探测器及其数据处理系统研制。

根据ALICE探测器升级项目的总体安排，基于中国组承担的任务，结合预研阶段取得的成果，继续合作研发完成抗高辐照的新一代硅像素探测器的像素探测单元及其高速读出电子学系统。合作研发单片有源硅像素传感器（MAPS）芯片，使各项性能指标满足ALICE内部寻迹系统（ITS）的要求。研制全自动化的MAPS芯片测试和模块集成装置，测试芯片性能、集成硅像素探测器模块，建造、安装调试和校正ITS硅像素探测器，开展相应的数据处理方法研究。参加时间投影室像素读出探测器（GEM）的研发，掌握关键技术。

建立重味信号测量的蒙特卡罗和数据分析程序，系统研究像素探测器物理性能。开展对重味强子谱、衰变轻子谱、重味标记喷注、以及各向异性流测量的模拟研究，为探测器升级后的实验数据分析和物理观测做好全面准备。

2. ALICE实验重味物理研究。

利用含有重味夸克的强子和夸克偶素作为探针，研究相对论重离子碰撞产生的夸克物质的特性。测量在相对论重离子碰撞中重味强子和夸克偶素的产生，研究夸克物质中的强子化机制和重味夸克偶素产生机制，获取夸克物质的早期信息；测量重味强子和重味夸克偶素的各向异性分布，研究重味夸克与夸克物质的相互作用，研究重味夸克在夸克物质中的能量损失机制、热化程度及输运特征。

3. ALICE实验喷注物理研究。

研究强相互作用下部分子的能量损失机制和喷注对夸克—胶子等离子体（QGP）的激发效应。结合中方参与建造的光子谱仪PHOS和ALICE电磁量能器EMCal，实现对双喷注和光子—喷注的精确测量，专注于大型强子对撞机LHC上超高能核—核碰撞中的喷注产额、结构和强子组分的精确测量，探索TeV能区喷注能量损失对部分子类型、色荷以及穿越介质的路径长度的依赖，提取反映QGP物质性质的粘滞系数、输运系数等重要物理参量。通过与理论模型比较，确定夸克物质的基本性质。此外，将通过高能强子—强子关联或喷注—强子关联，研究介质对喷注的响应。

4. ALICE实验奇特粒子态、奇异性核和反物质相互作用研究。

研究奇异性粒子、非奇异粒子间相互作用和反物质间相互作用，通过积极寻找新的奇异性核和反物质共振态，包括双重子或包含双超子的奇特超核等稀有粒子，以期对量子色动力学（QCD）物理图象中多超子体系的理解带来突破。重点测量超核和轻核的产生，并以此为基础，提取奇异性布局因子（Sn），研究超子—核子相互作用；测量超氚核衰变特性，获得超氚核更为精确的关于衰变道、寿命等实验数据；参与ALICE探测器数据在线和离线处理系统的升级研究，实现海量数据实时在线处理与分析，挑选含奇特粒子的稀有事例；测量反粒子间关联函数，提取散射长度和有效力程，研究反物质间相互作用。

三、项目建议的撰写与提交

（一）编写要求。

1. 申报单位应已在ALICE框架下签署了相关合作协议，并参加了ALICE实验升级的研发工作。服从国家对CERN国际合作的总体安排及协议要求，前期已支持过的项目本次暂不再支持。

2. 申报单位应为具有较强科研能力和条件、运行管理规范、在中国大陆境内注册3年以上的、具有独立法人资格的企业、科研院所、高等学校等。

3. 项目负责人和主要参加人员应遵守《国家科技计划项目承担人员管理的暂行办法》（国科发计字〔2002〕123号）的相关规定。作为项目负责人，同期主持的国家基本科技计划项目数原则上不得超过1项；作为主要参与人员，同期参与承担的国家基本科技计划项目数（含负责主持的项目数）原则上不得超过2项。

4. 申报项目受理后，原则上不能更改申报单位和负责人。

5. 凡此次提交项目建议的单位，不得一题多报、项目打包或申请重复资助。

（二）项目经费及期限。

1. 项目实行总额预算控制，总经费3400万元。每个项目原则上不超过800万元，项目经费将按照预算分年度拨付。经费实行专款专用，用于项目研发、技术标准、物理科学问题研究等学术研讨以及国际合作交流等。

2. 项目执行期为五年。

（三）申报建议提交方法。

1. 项目申报单位需通过上一级组织推荐部门提交项目建议书。组织推荐部门指项目申报单位所在省、自治区、直辖市或计划单列市的科技厅（委、局），或申请单位所隶属的国务院部门主管司局。

2. 请按照项目建议书附件格式及要求填写，请勿更改原始文件的格式或另行制作文件填写。

3.请通过国家科技管理信息系统项目申报中心（http://program.most.gov.cn）统一填报。网络填报的受理时间为本通知发布之日起至2016年3月7日。（技术咨询电话：010—88659000）

网上填报提交后，请于2016年3月7日前（以寄出时间为准）将加盖组织推荐部门公章的推荐函（纸质，一式4份）、项目建议基本信息表、项目建议书（通过系统直接生成打印，纸质，一式4份）寄送至中国科学技术交流中心。请不要现场报送。
