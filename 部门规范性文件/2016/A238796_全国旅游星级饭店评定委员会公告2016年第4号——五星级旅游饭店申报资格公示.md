# 全国旅游星级饭店评定委员会公告2016年第4号——五星级旅游饭店申报资格公示

## 全国旅游星级饭店评定委员会公告

2016年第4号

## 五星级旅游饭店申报资格公示

经饭店自愿申报、省级旅游星级饭店评定委员会推荐，在严格审查的基础上，全国旅游星级饭店评定委员会办公室审核同意江苏省南京香格里拉大酒店具备申请评定五星级旅游饭店的资格。根据《<旅游饭店星级的划分与评定>（GB/T14308-2010）工作规程》，现公示如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 地区 | 饭店名称 | 推荐时间 |
| 1 | 江苏 | 南京香格里拉大酒店 | 2016年6月 |

公示期为2016年7月7日—2016年8月5日（30个自然日）。凡对该饭店申报评定五星级旅游饭店的资格有意见者，请及时以书面或口头形式向全国旅游星级饭店评定委员会办公室反映。

接待时间：工作日8:00-11:00，13:30-17:00

联系电话：010-8516 6813或6843

全国旅游星级饭店评定委员会办公室

2016年7月7日
