# 国家质量监督检验检疫总局公告2016年第50号——质检总局关于受理苗药茶枕系列产品等产品申报生态原产地产品保护的公告

## 国家质量监督检验检疫总局公告

2016年第50号

## 质检总局关于受理苗药茶枕系列产品等产品申报生态原产地产品保护的公告

日前，贵州紫日茶业科技有限公司等单位申请对苗药茶枕系列产品等9个产品进行生态原产地产品保护。根据《原产地标记管理规定》及其实施办法和《生态原产地产品保护评定通则》《生态原产地产品保护工作导则》等规定，经贵州、广东出入境检验检疫局初审，我局采信北京万诚信用评价有限公司的评定结果，山源大苗山灵芝等9个产品符合相关规定的保护条件，我局拟对其实施生态原产地产品保护。现将本次拟保护的产品及相关信息公告如下：

|  |  |  |
| --- | --- | --- |
| 序号 | 产 品 名 称 | 申 报 单 位 |
| 1 | 苗药茶枕系列产品 | 贵州紫日茶业科技有限公司 |
| 2 | 都匀毛尖系列“贵台红”红茶 | 贵州省灵峰科技产业园有限公司 |
| 3 | 正安天赐茶叶 | 正安天赐生态科技有限公司 |
| 4 | 贵州兴仁聚丰薏苡系列产品（仁、米、粉） | 贵州兴仁聚丰薏苡股份有限公司 |
| 5 | 廉江红橙 | 广东岭南红橙有限公司 |
| 6 | 宣府茗龙茶及其系列产品 | 广东茗龙茶业有限公司 |
| 7 | 茗皇茶及其系列产品 | 广东茗皇茶业有限公司 |
| 8 | 红江橙（红江牌） | 广东省红江农场 |
| 9 | 桑醇酒及其系列产品 | 广东桑醇酒业有限公司 |

如有关单位或个人对上述产品申请生态原产地产品保护持有异议，可自公示之日起1个月内向我局生态原产地产品保护管理办公室书面提出，并说明异议具体内容及理由。
