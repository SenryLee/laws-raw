# 人力资源社会保障部办公厅关于2016年度投资建设项目管理师资格考试合格标准意见的函

人社厅函〔2016〕276号

中国投资协会：

你协会《关于2016年度投资建设项目管理师考试合格标准有关问题的函》（中投协字〔2016〕026号）收悉。根据考试数据统计分析，经商国家发展改革委，同意你协会提出的将2016年度投资建设项目管理师资格考试各科目合格标准确定为试卷满分60%的意见（即90分）。具体合格标准见下表。

|  |  |  |
| --- | --- | --- |
| **科目名称** | **合格标准** | **试卷满分** |
| 宏观经济政策 | 90 | 150 |
| 投资建设项目决策 | 90 | 150 |
| 投资建设项目组织 | 90 | 150 |
| 投资建设项目实施 | 90 | 150 |

为便于各地人力资源社会保障部门及时掌握各类专业技术人才评价情况，加强专业技术人才队伍管理，请及时将投资建设项目管理师资格考试及发证情况送各地人力资源社会保障厅（局）备案。

人力资源社会保障部办公厅

2016年7月13日
