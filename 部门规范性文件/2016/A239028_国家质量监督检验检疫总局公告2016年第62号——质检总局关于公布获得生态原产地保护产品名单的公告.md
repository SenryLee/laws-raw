# 国家质量监督检验检疫总局公告2016年第62号——质检总局关于公布获得生态原产地保护产品名单的公告

## 国家质量监督检验检疫总局公告

2016年第62号

## 质检总局关于公布获得生态原产地保护产品名单的公告

根据《原产地标记管理规定》及其实施办法、《生态原产地产品保护评定通则》等规定，经审核评定，批准苗药茶枕系列产品等4项产品为生态原产地保护产品，准予其使用生态原产地产品保护标志，自即日起实施保护。现将获得生态原产地保护的产品名单予以公布。

|| 序号 | 产 品 名 称 | 申 报 单 位 |
|  |  |  |
| --- | --- | --- |
| 1 | 苗药茶枕系列产品 | 贵州紫日茶业科技有限公司 |
| 2 | 都匀毛尖系列“贵台红”红茶 | 贵州省灵峰科技产业园有限公司 |
| 3 | 正安天赐茶叶 | 正安天赐生态科技有限公司 |
| 4 | 贵州兴仁聚丰薏苡系列产品（仁、米、粉） | 贵州兴仁聚丰薏苡股份有限公司 |

质检总局

2016年7月1日
