# 国家文物局关于南京城墙（太平门至解放门段）加固修复设计方案的意见

## 关于南京城墙（太平门至解放门段）加固修复设计方案的意见

办保函〔2016〕879号

江苏省文物局：

你局《关于审批南京城墙加固与防风化保护工程——太平门至解放门段加固修复设计方案的请示》（苏文物保〔2016〕136号）收悉。经研究，我局意见如下：

一、所报方案前期勘察和研究不足，保护措施不当，工程干预量过大，我局暂不同意南京城墙（太平门至解放门段）加固修复设计方案。

二、对该立项文本提出以下修改意见：

（一）应调整设计思路，坚持最小干预原则，以现状维修为主，合理确定工程范围和工程强度，确保南京城墙的真实性。

（二）应加强现状勘察和研究，明确城墙形制特点和保存现状、主要病害类型、残损情况、对文物本体安全的影响等，客观评估城墙的稳定性和墙体强度。

1. 深入研究城墙原形制、原做法，明确城墙构造、砌法、收分、排水系统、灰浆成分等，补充本次维修段翔实的断面构造数据，以及外包砖砌体结构基础埋深、城墙顶部海墁结构及保存情况、底部散水情况等。

2. 明确“包山墙”的原形制、地面标高、基础情况、回填土的分布范围、厚度和形成时间等，分析回填土对城墙安全的影响，核实“包山墙”复合结构稳定性分析结论，论证计算模型和计算参数的科学性和准确性。

3. 进一步说明监测点布置原则和布置方法，科学界定结构、构造性病害类型和程度，对比论证地质雷达探测结果的准确性。

4. 补充地质水文、地表水径流、城墙周边绿化等资料，分析其对文物安全的影响。

5. 系统梳理已实施的保护工程情况，分析砌体斜向开裂加固、顶部地面排水处理、墙砖酥碱防治等措施和实施效果，为制定有针对性的保护措施提供依据。

（三）应进行必要的实验室和现场实验，分析原城墙粘结材料，开展外包砖体的物理学测试，并根据灌浆目的进行灌浆材料的比选实验。

（四）应坚持最小干预原则，以现状加固为主，科学确定修缮任务和工程措施，避免过度维修和不当干预。

1. 深入论证实施土层锚杆和地下连续墙加固措施、增设钢筋铁扒锔、植入钢筋锚杆的必要性、可靠性和合理性。

2. 应根据现状勘察结论明确回填土处理措施，建议适当清除回填土，尽可能恢复原地面，可采取灌浆或树根桩加固处理措施，减小城墙后侧的主动土压力。

3. 进一步明确墙体砖拆砌原则、要求，规范具体做法。城墙表面缝隙勾抹宜采用传统材料，不宜选择水硬性石灰砂浆；不宜使用砖粉与环氧树脂混合修补破损较浅的墙面。

4. 应调整排水措施，明确原城墙顶部传统防渗排水做法，尽量恢复原有排水系统，不同意采用现代防水卷材和混凝土顶板。

5. 不同意城墙两侧局部换土措施。

6. 宜采用人工方法清除城墙植物，避免污染地下水和城市环境。同时，应加强日常养护，及时清理城墙植物，确保城墙安全。

（五）城墙表观修复部分设计内容和城墙墙体下部的排水设计内容暂不纳入本方案。

（六）进一步完善文本和图纸。统一文本与图纸中修补墙砖尺寸，增强图文对应性；补充必要的施工剖面图、节点大样图、工程布置图，节点大样图不宜以示意图代替。

（七）根据工程量合理编制经费预算，确定取费项目，补充取费标准。

三、请你局根据上述意见，组织专业机构修改、完善设计方案，经你局审核后另行报批。

专此函。

国家文物局

2016年8月12日
