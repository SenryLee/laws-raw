# 中国保险监督管理委员会公告第3号－－保险经纪资格考试报名公告

## 中国保险监督管理委员会公告(第3号)

根据《保险经纪人管理规定（试行）》，中国保险监督管理委员会定于1999年5月15日举行第一次保险经纪资格考试。现将有关事项公告如下：

**一、**报名时间 自公告之日起至1999年3月15日（以报名资料寄出日的邮戳日期为准）止。

**二、**考试时间 1999年5月15日，上午8：30-11：30《财政金融综合知识》，2：00-5：00《保险理论与实务》。

**三、**考试地点 本次考试，全国共设六个指定考点，详见下表：

```
考 点　　　　　　　　　　　　　　　　辖 区

中央财经大学　　　　北京、天津、黑龙江、吉林、辽宁、河北和内蒙古

陕西财经学院　　　　陕西、山西、宁夏、甘肃、青海和新疆

上海财经大学　　　　上海、山东、江苏、安徽、浙江和福建

武汉大学　　　　　　河南、湖北、湖南和江西

西南财经大学　　　　重庆、四川、贵州、云南和西藏

广州金融高等专科学校广东、广西、海南和深圳
```
