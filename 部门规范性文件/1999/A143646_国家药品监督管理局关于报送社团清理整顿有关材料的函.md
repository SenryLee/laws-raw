# 国家药品监督管理局关于报送社团清理整顿有关材料的函

## 国家药品监督管理局关于报送社团清理整顿有关材料的函（药管办[1999]126号）

民政部民间组织管理局：

根据《国务院办公厅转发民政部关于清理整顿社会团体意见的通知》(国办发[1997]11号)和国务院颁发的《社会团体登记管理条例》等文件精神，我局对原国家医药管理局所属社团进行了清理整顿。现将清理整顿审查情况及初审意见和社会团体《清理整顿报告书》报送你局，请审核。

附件：关于社团清理整顿审查情况的说明

国家药品监督管理局办公室

一九九九年九月二十日

附件：

关于社团清理整顿审查情况的说明

医药行业社团共20个，其中原国家医药管理局作为业务主管部门的14个：中国化学制药工业协会、中国医药商业协会、中国医疗器械行业协会、中国医药包装协会、中国制药装备行业协会、中国医药科研开发促进会、中国淀粉工业协会、中国医药工程设计协会、中国医药设备工程协会、全国医药技术市场协会、中国药文化研究会、中国医药企业管理协会、中国医药企业发展促进会、中国非处方药物协会；作为挂靠单位管理的6个：中国药学会、中国医药质量管理协会、中国医药职工思想政治工作研究会、中国医药报刊协会、中国医药会计协会、中国医药教育协会。

鉴于我局为国务院新组建的主管全国药品监督的行政执法机构，没有医药行业管理职能，根据国务院赋予我局的职能及更好地发挥社会团体的桥梁和纽带作用，提出以下初审意见：

**一、**我局作为业务主管部门的社团

1．中国化学制药工业协会

2．中国医药商业协会

3．中国医疗器械行业协会

4．中国医药包装协会

5．中国药学会(挂靠我局)

6．中国医药报刊协会

**二、**移交其他部门的社团

1．中国制药装备行业协会

2．中国医药科研开发促进会

3．中国淀粉工业协会

4．中国医药工程设计协会

5．中国医药设备工程协会

6．全国医药技术市场协会

7．中国医药企业管理协会

8．中国医药职工思想政治工作研究会(挂靠)

9．中国医药质量管理协会(挂靠)

10．中国医药教育协会

11．中国医药会计协会(挂靠

)

**三、**予以撤消的社团

1．中国医药企业发展促进会

2．中国药文化研究会

**四、**予以合并的社团

中国非处方药物协会(并入中国药学会

)

**五、**拟成立的协会

1．中国药品监督管理系统职工思想政治工作研究会

2．中国麻醉药品协会

由于国务院机构改革，原国家医药管理局撤消，中国药学会、中国非处方药物协会、中国医药职工政治思想研究会、中国医药设备工程协会、中国医药报刊协会、中国医药质量管理协会等党政领导干部兼职问题未能如期解决，但我局党组已提出明确整改方案，除特殊情况外，党政领导干部一律不再兼任社团职务。

根据民政部《关于社会团体清理整顿审定工作有关问题的通知》(民社函[1999]97号)要求，我局先负责完成予以保留及移交其他部门社团的审定换证工作，然后再办理变更手续及移交事宜。中国医药报刊协会原业务主管部门为国家新闻出版署，我局同意其业务主管单位变更为国家药品监督管理局。
