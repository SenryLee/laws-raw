# 教育部办公厅关于印发高等学校《交响音乐赏析》教学指导纲要试行的通知

## 教育部办公厅关于印发高等学校《交响音乐赏析》教学指导纲要试行的通知（教体艺厅[1999]7号　1999年8月4日）

为了深入贯彻落实《关于印发〈李岚清同志与部分音乐家座谈在高等学校提倡交响音乐问题的讲话〉的通知》(教办[1997]32号)精神，进一步加强高等学校的美育工作，提高大 学生 的文化艺术修养，陶冶情操，启迪智慧，促进身心全面和谐发展，我部在广泛征求意见的基 础上，组织制订了《高等学校〈交响音乐赏析〉教学指导纲要(试行)》(简称“纲要”) ， 现下发给你们，请参照执行。

开设艺术选修课是高等学校实施美育的重要途径，各校应根据《中共中央国务院关于深化教育改革全面推进素质教育的决定》中关于“高等学校应要求学生选修一定学时的包括艺术在 内的人文学科课程”的要求，结合学校的实际，合理确定课程设置，选择根据“纲要”编写 的教材，妥善解决 师资和设备器材等问题，以推动高校美育健康、深入的发展。

高等学校《交响音乐赏析》 教学指导纲要(试行

)

**一、**教学目的与任务

《交响音乐赏析》是高等学校公共艺术类课程中的一门限制性选修课。本课的主要任务是面 向全体学生进行交响音乐的普及教育。通过赏析交响音乐作品，增强学生对高雅音乐的兴趣 与爱好；了解交响音乐及有关基本知识；提高感受、理解、鉴赏音乐的能力；养成欣赏音乐 的文明习惯；培养学生具有高雅的审美情趣，以达到促进学生身心和谐发展、提高素质的目 的。

**二、**教学内容

1、交响音乐赏析基础知识(15%—20%)

(1)交响音乐发展沿革、略况，不同风格流派及其交响音乐作品产生的时代背景、 艺术特点和成就；　

(2)著名作曲家生平、创作思想、历史地位与贡献；

(3)欣赏交响音乐必需的基本知识。

2、中外著名作曲家优秀交响音乐作品的赏析(80%—85%)，授课方案及推荐曲目附后。

**三、**教学要求

1、从目前我国大学生整体音乐水平的实际状况出发，加强教学的针对性，做到难易适度， 深入浅出。

2、课堂教学应以听赏音乐为主，着重培养学生对音乐作品的艺术感受、理解和审美体验。 听赏曲目不少于“纲要”推荐曲目的70%，重点听赏曲目不少于20%。

3、鼓励学生积极参与教学过程，激发学生学习音乐的兴趣和热情。

4、充分利用各种现代化教学手段，最大限度地强化学生的听觉审美感受。

5、教学形式应当多样化，除课堂教学外，还应开展丰富多彩的课外音乐欣赏活动。比如举办音乐欣赏讲座、组织学生听交响音乐会等。课内课外密切结合，使音乐欣赏活动 取得更佳效果。

**四、**成绩考核

1、交响音乐欣赏课的考核成绩纳入普通高校学生的考绩范围。

2、考核方法分平时考查和期末考试两类。考试方式可采用听辨、问卷、撰写鉴赏心得(乐曲 的内涵 与结构及个人感受)形式。

**五、**教学条件

1、学校应设立专用音乐教室。5000人以上的学校，其专用音乐教室至少应容纳150人上课。 暂没有专用音乐教室的学校，要充分利用其它教室(如：电化教室)开课。教室内的配套设施 应当齐全。其中包括高级音响器材、录像机(或VCD)、电视机、录音带、录像带、CD盘、V CD盘(共50—150盘)等。

2、学校图书馆应购置有关音乐艺术类的图书、杂志、音像资料等，以满足师生的需要。

**六、**说明

1、本课程用一学期(按17周计)授完，周课时为2学时，计算学分；有条件的学校可作为必修 课。　　

2、编写《交响音乐赏析》教材应以本“纲要”为依据。教材中的曲目应从“纲要”推荐曲目中选择，但曲目顺序可根据教材体例自行安排。

3、《交响音乐赏析》教材应包括：教科书、教学参考书和配套音像资料(录音带或CD、录像带、VCD等)。

4、学校应配备专职音乐教师授课，必要时也可外请专家讲授。

5、教师必须按本“纲要”的内容和要求授课，但对教学内容的顺序、容量等，可根据实际 情况作适当的调整。

附：推荐曲目(按时期)(略)
