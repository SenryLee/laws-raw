# 自然资源部直属机关纪委关于紧盯“五一”、端午期间“四风”问题的通知

## 关于紧盯“五一”、端午期间“四风”问题的通知

国家林业和草原局、中国地质调查局直属机关党委、纪委，各单位党委（支部）、纪委，各司局党支部：

“五一”、端午将至，按照中央纪委国家监委关于紧盯节日期间“四风”问题的通知要求，进一步贯彻落实中共自然资源部党组、中央纪委国家监委驻自然资源部纪检监察组联合印发元旦、春节期间严格落实中央八项规定精神的通知，紧盯重要节点，坚决防止“四风”反弹，确保节日风清气正，现就有关事项通知如下：

（一）各级党组织要认真落实全面从严治党主体责任，及时传达通知要求，采取有力措施、多种方式，使全体党员干部严格执行中央八项规定及其实施细则精神，让党员干部深刻认识越往后执纪越严、处理越重的要求，自觉做到严守纪律要求，时刻绷紧廉政之弦。

（二）各级纪检组织要认真履行监督责任，组织本单位党

员干部认真学习中央纪委近期公开曝光违反中央八项规定精神问题的新闻通报，对照自身进行检查，并严格落实有关要求。同时，结合张红红、王宗亚利用职务便利违纪违法典型案例，深刻汲取教训，以案释纪明纪，用身边人身边事开展警示教育。

（三）要盯紧盯住假期“四风”问题，进一步畅通本单位监督举报渠道，创新监督方式和手段，针对节日期间“四风”问题易发的重点部位，抓住关键少数和重点环节，组织开展监督检查，紧盯节日期间不正之风。

（四）对群众反映的、舆论媒体关注的、监督检查中发现的发生在节日期间的“四风”问题线索、重要舆情，要第一时间逐级报告，及时核查处置。

各单位“五一”、端午期间纠“四风”防反弹工作情况，请于6月17日前报送部直属机关纪委。
