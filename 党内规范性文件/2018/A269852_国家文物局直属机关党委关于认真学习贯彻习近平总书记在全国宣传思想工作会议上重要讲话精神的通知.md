# 国家文物局直属机关党委关于认真学习贯彻习近平总书记在全国宣传思想工作会议上重要讲话精神的通知

党委发〔2018〕24号

各司室、各直属机关党委（总支、支部），各局管社会组织党支部：

全国宣传思想工作会议8月21日至22日在北京召开，习近平总书记出席并发表重要讲话。讲话站在新时代党和国家事业发展全局的高度，深刻总结党的十八大以来党的宣传思想工作的历史性成就和历史性变革，作出一系列重大工作部署。讲话总揽全局、视野高远、内涵丰富、思想精深，是指导新形势下党的宣传思想工作的纲领性文献。

认真学习贯彻习近平总书记在全国宣传思想工作会议上的重要讲话精神，对于强化“四个意识”、坚定“四个自信”，自觉肩负起新形势下文物保护利用改革工作的使命任务，奋力开创文物工作新局面具有重要意义。局系统各级党组织要加强组织领导，精心设计方案，开展专题学习，深刻领会精神，抓好贯彻落实。现将有关要求通知如下：

一、提高政治站位，把思想和行动统一到讲话精神上来

要把深入学习宣传贯彻习近平新时代中国特色社会主义思想作为首要政治任务，以习近平新时代中国特色社会主义思想和党的十九大精神为指导，增强“四个意识”、坚定“四个自信”，坚持“两个维护”。要充分理解党的十八大以来宣传思想工作的重大成果，充分领会新形势下宣传思想工作的使命任务，深刻认识新形势下宣传思想工作的重点任务，切实增强做好宣传思想工作的责任感使命感。切实把思想和行动统一到讲话精神上来。

二、统筹谋划部署，把学习贯彻讲话精神不断引向深入

局系统各级党组织要把深入学习习近平总书记在全国宣传思想工作会议上的重要讲话精神作为当前和今后一个时期的一项重要政治任务，加强组织领导，统筹谋划部署，将习近平总书记重要讲话作为理论学习中心组、“三会一课”和党员干部学习培训的重要内容。广大党员领导干部要带头学、带头干，引导干部职工增强对习近平中国特色社会主义思想的政治认同、思想认同、理论认同和情感认同。

三、狠抓工作落实，把讲话精神落实到文物保护利用改革工作中

要结合中央全面深化改革委员会第三次会议精神，进一步增强改革的信心和动力，进一步增强改革的系统性、整体性，主动作为、攻坚克难，守住政治底线和安全底线，聚焦文物工作重点难点问题，加强制度设计和精准管理，加强文物保护利用理念和实践创新，努力开创新时代文物工作的新局面。

请各单位党组织及时将学习贯彻习近平总书记在全国宣传思想工作会议上的重要讲话精神有关情况报送国家文物局直属机关党委。

特此通知。

国家文物局直属机关党委

2018年10月8日
