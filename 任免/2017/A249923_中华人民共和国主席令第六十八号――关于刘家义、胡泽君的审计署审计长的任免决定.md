# 中华人民共和国主席令第六十八号――关于刘家义、胡泽君的审计署审计长的任免决定

## 主席令

（第六十八号）

根据中华人民共和国第十二届全国人民代表大会常务委员会第二十七次会议于2017年4月27日的决定：

免去刘家义的审计署审计长职务；

任命胡泽君（女）为审计署审计长。

中华人民共和国主席　习近平

2017年4月27日
