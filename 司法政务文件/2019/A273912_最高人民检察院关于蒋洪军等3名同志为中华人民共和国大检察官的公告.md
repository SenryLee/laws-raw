# 最高人民检察院关于蒋洪军等3名同志为中华人民共和国大检察官的公告

检〔2019〕1号

根据《中华人民共和国检察官法》等有关规定，蒋洪军为中华人民共和国一级大检察官，万春、张志杰为中华人民共和国二级大检察官。

现予公告。

中华人民共和国最高人民检察院检察长 中华人民共和国首席大检察官 张军

2019年2月2日
