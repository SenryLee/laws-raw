# 最高人民法院关于全国法院“百篇优秀裁判文书”获奖名单公示

## 全国法院“百篇优秀裁判文书”获奖名单公示

为展现全国法院优秀裁判文书制作水平，充分发挥精品文书引领示范作用，由最高人民法院审判管理办公室主办，各高级人民法院审判管理部门协办的首届全国法院“百篇优秀裁判文书”活动已顺利结束。经过初评、复评、总评等各阶段严格选拔，最终评定出全国法院“百篇优秀裁判文书”获奖名单。现将上述名单予以公示，公示期为7个工作日，公示期间无异议的，确定为最终获奖名单。
