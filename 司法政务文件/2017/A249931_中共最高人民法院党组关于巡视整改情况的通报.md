# 中共最高人民法院党组关于巡视整改情况的通报

根据中央统一部署，2016年11月11日至2017年1月10日，中央第二巡视组对最高人民法院党组进行了巡视。2017年2月17日，中央巡视组向最高人民法院党组反馈了巡视意见。根据《中国共产党党内监督条例》和《中国共产党巡视工作条例》有关规定，现将巡视整改情况予以公布。

一、深入学习贯彻习近平总书记系列重要讲话精神，切实提高政治站位和政治觉悟，把巡视整改作为一项严肃的重大政治任务抓紧抓好

中央巡视组对最高人民法院党组开展专项巡视，体现了党中央对最高人民法院的高度重视和亲切关怀，是对最高人民法院坚持党的领导、加强党的建设、全面从严治党以及党风廉政建设和反腐败工作的全面体检和有力促进，也是对最高人民法院机关广大干部特别是领导干部一次深刻的党性锻炼和警示教育。最高人民法院党组深入学习贯彻习近平总书记系列重要讲话精神，认真学习贯彻习近平总书记关于巡视工作的重要指示精神，认真落实王岐山同志有关指示要求、赵乐际同志在情况反馈会议上的讲话精神和中央巡视办、中央第二巡视组部署要求，严格落实巡视整改主体责任，进一步突出党的领导、抓住党的建设，聚焦全面从严治党，把巡视整改作为一项严肃的重大政治任务和当前头等大事牢牢抓在手上，坚持立行立改、全面整改，坚持举一反三、标本兼治，确保整改取得扎实成效。截至目前，中央巡视反馈意见中指出的33个问题已经全部对照整改。在104项具体整改任务中，75项已经完成，20项已经立行立改并将长期坚持，占全部整改任务的91%。另有9项整改任务将在年内完成，目前已经取得实质性或阶段性进展。共制定或修订出台规范性文件46件，发出通知11个，举办全国性会议或培训7次。

（一）坚决落实中央政治巡视要求，始终把习近平总书记系列重要讲话精神作为巡视整改的根本遵循。党的十八大以来，以习近平同志为核心的党中央坚定推进全面从严治党，把巡视工作作为党内监督的战略性制度安排，摆在更加突出的位置，充分发挥巡视工作的利剑作用，集中整饬党风，严厉惩治腐败，净化党内政治生态，党内政治生活呈现新气象，赢得了党心民心，为开创党和国家事业新局面提供了重要保证。习近平总书记高度重视巡视工作，多次发表重要讲话、作出重要指示，为我们进一步落实全面从严治党要求、解决管党治党中存在的突出问题指明了方向。最高人民法院党组对习近平总书记关于巡视工作的重要讲话和关于人民法院工作的重要指示精神，对王岐山同志和孟建柱、赵乐际等中央领导同志的有关指示要求，对叶青纯同志代表中央巡视组反馈的专项巡视意见，反复学习、深刻领会。

召开党组会、全国法院党风廉政建设和反腐败工作会议、巡视整改工作动员部署会、党建工作领导小组会、巡视整改专题民主生活会、党组中心组专题集中学习会，全面加强对习近平总书记系列重要讲话精神的学习，迅速把思想和行动统一到习近平总书记系列重要讲话精神上来，统一到中央巡视组的反馈意见和整改要求上来，进一步提高政治站位和政治觉悟，强化政治纪律和政治规矩，确保各项巡视整改工作扎实有序推进。

（二）加强组织领导，严格落实巡视整改主体责任。中央巡视办和中央第二巡视组反馈意见后，最高人民法院党组第一时间召开党组会议，传达学习中央精神，研究部署巡视整改工作，迅速落实中央巡视反馈意见，对能够立即整改的，立行立改、立即处置。巡视整改期间，周强同志8次主持召开党组会专题听取整改情况汇报，研究突出问题，加强督促检查，确保落实见效。成立党组巡视整改工作领导小组，党组书记周强同志任组长，两位党组副书记任副组长，切实加强对巡视整改工作的组织领导。周强同志认真落实整改第一责任人责任，带头抓整改，亲自抓落实，对巡视整改重要问题亲自部署、亲自协调，努力做到真认账、真反思、真整改、真负责。班子成员坚持把自己摆进去，自觉为党担责、为党尽责、为党负责，主动认领责任，在抓好自身整改的同时，积极抓好分管部门、主管领域的整改工作，防止把层层传导压力变成层层推卸责任。机关各部门负责同志坚持一级抓一级，层层明确责任，层层抓落实。及时制定全面整改工作方案和整改台账，坚持照单全收、一项不漏，共梳理出3大类10个方面33个具体问题。坚持条条要整改、件件有落实，并进一步自我加压，细化成104项具体整改任务。就选人用人、意识形态两个领域制定专项整改方案。3月3日，党组召开巡视整改工作动员部署会，对整改工作进行全面部署，强调要把巡视整改工作作为维护以习近平同志为核心的党中央权威和集中统一领导的一次全面“政治体检”，作为对党是否绝对忠诚的具体检验，采取切实有效措施，狠抓巡视整改任务落实。

（三）健全工作机制，细化任务分工。党组巡视整改工作领导小组下设整改办，负责日常协调、监督、指导、检查等工作职责，坚持每周召开例会，听取汇报，研究问题，掌握进度，提出建议，及时向院党组和巡视整改工作领导小组报告工作。建立对账销号制度，倒排时间节点，实行挂图作战，各责任单位申请销号必须提供证明材料，并报院党组审核。对于整改不彻底、措施不过硬、质量不达标的坚决不予销号。加强督查督办，各项整改任务均有专人负责跟踪督办，对口联络全院各单位，做好经常性督促提醒，发现问题及时纠正。对两个月内必须完成的重点整改事项按日倒排期限，实时跟踪督办。对于组织领导不力、工作滞后、整改不到位的单位，对主要负责人严肃批评、督促改正。及时向中央巡视办和中央第二巡视组汇报整改工作进展情况，确保整改工作取得实实在在的成效。坚持开门搞整改，截至目前共编发巡视整改工作专刊25期，定期通报整改工作进展情况，接受全院干警监督。

（四）坚持全员全系统整改，推动形成上下联动的整改工作格局。最高人民法院机关和直属单位各党组织认真对照院党组整改工作方案和全面整改台账，结合自身工作实际，制定本单位整改实施方案，进一步细化整改措施，明确专人办理整改任务，定期报告进展情况。承担具体整改任务的牵头责任单位带头抓好整改，把责任落实到每个处室、每名同志。其他各单位针对反馈意见中指出的普遍性问题，以统一的标准、快速的节奏推进整改落实。为推进全国法院同步开展整改，对照中央巡视反馈意见，梳理出法院系统普遍存在的8个方面共性问题，专门下发通知要求各级法院深入查找自身及辖区法院存在的问题，确保中央巡视反馈意见在法院系统落实落地。各高级人民法院迅速在辖区法院同步进行整改，召开党组会专题研究部署，制定整改方案和台账，把巡视整改不断引向深入，形成了上下联动、合力整改的工作格局。

（五）坚持标本兼治，确保整改取得扎实成效。最高人民法院党组坚持以巡视整改为契机，出实招、出硬招，不搞花拳绣腿、不搞应景式整改，力求达到提高认识、改进工作的目的。充分运用巡视成果，抓住突出问题，深刻剖析根源，既解决好反馈意见指出的问题，又注重解决其他关联性问题；既解决好具体问题，又注重解决普遍共性问题；既解决好面上问题，又注重解决深层次问题。对巡视中发现的普遍共性问题，坚持立足当前、着眼长远，在抓好集中整改的同时，及时开展调查研究，总结形成理论和制度成果，堵塞管理漏洞，提高工作质效。坚持统筹兼顾，自觉将巡视整改工作与司法改革、审判执行、队伍建设等各项工作结合起来，做到两手抓、两促进，推动人民法院工作取得新进步。

二、切实增强政治意识，充分发挥党组的领导核心作用

坚持党的领导、加强党的建设，维护以习近平同志为核心的党中央权威是最重要的政治原则。最高人民法院党组深刻剖析反思，要求机关各单位和地方各级法院牢固树立“四个意识”，坚决维护以习近平同志为核心的党中央权威和集中统一领导，始终坚持在党的领导下依法独立公正行使审判权，坚定不移走中国特色社会主义法治道路，确保人民法院工作正确政治方向。

（一）着力解决“政治纪律和政治规矩执行不严”问题

一是严明政治纪律和政治规矩。院党组从政治上、思想上、工作上采取坚决有效措施，全面彻底肃清XXX流毒影响，突出法院领导干部这个重点，着力深化思想、政治、组织、作风等方面的肃清工作。将学习习近平总书记系列重要讲话精神作为国家法官学院所有培训班次必修课，强化理论武装。专门举办4期全国法院中级、基层法院院长学习贯彻习近平总书记系列重要讲话精神培训班，切实加强对法院干警的政治纪律和政治规矩教育。

二是加大干部轮岗交流力度。严格落实《最高人民法院干部轮岗交流暂行办法》，研究提出开展机关干部轮岗交流工作的具体意见，对符合条件人员有计划地开展轮岗交流。结合第一、第二巡回法庭人员轮换，已轮岗交流5名同志，下一步拟结合人员分类管理改革，加大综合部门和审判部门以及不同审判部门之间的人员交流力度。改进干部考察方式，延伸干部考察范围，注重了解干部“八小时以外”生活圈、社交圈情况，全面了解人选综合表现。制定《干部管理监督工作联席会议实施办法》，建立组织部门与纪检监察等部门的信息交流和联动机制，形成监督合力，坚决抵制“圈子文化”影响。

（二）着力解决“党组的领导核心作用发挥不充分”问题

一是加强对法院系统党的建设工作的指导。制定下发《关于深入落实全面从严治党要求进一步加强人民法院党的建设的指导意见》，着力解决部分法院党的领导弱化、党的建设缺失、全面从严治党不力等问题。制定《中共最高人民法院党组公文办理规定》，对以最高人民法院党组名义制发公文的办理原则、内容范围、办理程序等内容作出明确规定。适时召开全国法院党建工作会议，深入研究新形势下加强法院党建工作的思路措施，部署加强法院系统党的建设。

二是采取有效措施深入推进司法体制改革。进一步落实司法改革主体责任，加强对司法体制改革的领导，对7个省（区）法院司法责任制改革，特别是法官员额制和工资制度改革进展情况进行督察。召开全国法院司法责任制督察暨繁简分流机制改革推进会，要求各级人民法院以钉钉子的精神狠抓改革任务落实。目前，全国法院法官员额制改革已经基本完成，法官单独职务序列及工资制度改革扎实推进，最高人民法院机关即将启动司法责任制等综合改革，确保党的十九大前基本完成司法体制改革任务。加强法院内部监督制约机制建设，制定发布《关于健全完善审判权力运行监督机制的指导意见》《关于加强各级人民法院院庭长办理案件工作的意见（试行）》，做到既充分放权，又有效监督。制定发布《关于全面推进以审判为中心的刑事诉讼制度改革的实施意见》，修订《关于人民法院庭审录音录像的若干规定》，研究制定庭前会议、非法证据排除和法庭审理规程，进一步完善以审判为中心诉讼制度改革的配套措施。严格落实领导干部插手过问案件记录和责任追究“两个规定”，全面建成并上线运行全国法院外部过问案件信息专库直报系统。继续大力破解执行难问题，制定发布《关于民事执行中财产调查若干问题的规定》《关于执行款物管理工作的规定》等司法解释，委托中国社会科学院对2016年执行工作进行评估，向全国法院发出执行工作禁令和执行规范流程，部署启动规范执行行为专项整治行动，广泛开展执行宣传，评选推出十大执行典型案例，积极推动通过互联网平台对失信被执行人进行信用惩戒，大力推进信用中国建设。

三是加大司法体制改革政策宣传力度。发布《中国法院的司法改革（2013-2016）》《中国法院的司法公开（2013-2016）》两个白皮书，扩大司法改革的社会影响力。认真研究梳理各地法院落实司法改革中出现的困难和问题，在人民法院报开设“司法改革热点问答”系列专栏，陆续就司法改革政策热点问题进行解答。全国“两会”期间，组织对司法改革情况进行集中宣传报道，凝聚改革共识，展现改革成果。在中国法院博物馆举办司法改革特展，并同步开通网上展厅，部分全国人大代表、政协委员和各界群众积极参观展览，线上线下累计有5万余人次参观，社会反响热烈。

（三）着力解决“意识形态责任制落实不够有力”问题

认真传达学习中央有关会议和文件精神，推动意识形态领域整改工作深入开展。进一步明确领导责任，加强党组对意识形态工作的领导，党组书记对意识形态工作和党建工作负总责，明确由两位党组副书记分别协助分管意识形态和党建工作。制定《人民法院意识形态工作责任制实施细则》《人民法院网络意识形态工作责任制实施细则》，着力加强意识形态阵地建设和管理，坚决抵制批驳西方“宪政民主”“三权分立”“司法独立”等错误思潮影响，切实维护司法领域意识形态安全。针对重大、热点案件的审理，强调既要坚持严格司法、依法裁判，又要高度关注社情民意、社会舆论，努力形成舆论与司法的良性互动，最大限度地凝聚共识。

三、着力加强党的建设，严肃党内政治生活

加强党的建设是政治巡视的根本要求。院党组牢固树立“抓党建是本职、不抓党建是失职”的观念，自觉站在巩固党的执政基础的政治高度，切实把抓党建工作主体责任扛起来，努力做到真管真严、敢管敢严、长管长严，不断提升管党治党能力和水平。

（一）着力解决“党的组织建设不规范”问题

强化党组抓党建的领导责任，修改《中共最高人民法院党组工作规则》，将党组定期听取机关党建工作汇报、研究解决党建工作相关问题作为党组重要议事内容。制定发布《中共最高人民法院巡回法庭分党组工作规则》，切实加强党对巡回法庭工作的领导。加强机关党委、机关纪委自身建设，制定换届选举办法和名额分配方案，适时召开党员代表大会进行换届选举。加强对基层党组织工作的指导，制定发布《最高人民法院机关党建工作述职考核制度实施细则》《最高人民法院机关和直属单位党组织的设立与换届选举制度实施细则》，健全党组织按期换届提醒和督促指导机制，强化机关各级党组织书记管党治党主体责任，健全民主集中制，完善党内选举制度，推进机关和直属单位党组织规范化制度化建设，增强基层党组织创造力、凝聚力、战斗力。

（二）着力解决“党内政治生活不严格”问题

（五）深入推进“两学一做”学习教育常态化制度化，不断提高党内政治生活的质量和水平。认真贯彻落实《关于推进“两学一做”学习教育常态化制度化的意见》，坚持用党章党规党纪规范党组织和党员行为，用习近平总书记系列重要讲话精神武装头脑、指导实践、推动工作，教育引导人民法院广大党员干部学思践悟、知行合一，做到政治合格、执行纪律合格、品德合格、发挥作用合格。以“两学一做”学习教育常态化制度化为契机，进一步严肃党内政治生活，依托党组理论学习中心组学习、党支部“三会一课”等基本制度，抓好“两学一做”学习教育，做到融入日常、抓在经常，防止形式主义，防止党建工作和业务工作“两张皮”，使人民法院各级党组织真正成为教育党员的学校、团结群众的核心、攻坚克难的堡垒。坚持领导干部率先垂范，带头学深悟透习近平总书记系列重要讲话精神，坚持和完善民主集中制，用好批评和自我批评这个武器，以普通党员身份参加党的组织生活，注重家庭家教家风，保持清正廉洁的政治本色，切实增强党内政治生活的政治性、时代性、原则性、战斗性，在人民法院营造良好政治生态。

（六）认真履行“两个责任”，推进全面从严治党向纵深发展。认真落实《中国共产党党组工作条例（试行）》《关于新形势下党内政治生活的若干准则》《中国共产党党内监督条例》，不断加强和改进党组工作，切实履行管党治党主体责任。认真履行“两个责任”，切实落实“一岗双责”，进一步完善党内监督体系，坚持对法院干警从严教育、从严管理、从严监督，以零容忍态度惩治司法腐败，持之以恒地把党风廉政建设和反腐败斗争进行到底。加强对机关和法院系统党建工作的指导，加强对下级法院领导班子及成员的协管监督。支持纪检监察机构聚焦监督执纪问责主业，实践好“四种形态”，健全完善主动发现干警违纪违法问题线索机制、纪检组长和廉政监察员定期谈话机制。坚持“抓早抓小”，充分运用约谈提醒、诫勉谈话等监督手段，帮助领导干部纠正思想、作风、纪律等方面的苗头性、倾向性问题。扎实推进作风建设，狠抓中央八项规定精神的落实，坚决杜绝文山会海、官僚主义、公款旅游、滥发津补贴以及热衷出书讲课、追名逐利赚外快等问题，坚决防止“四风”等问题反弹回潮。

（七）巩固扩大巡视整改成果，推动形成长效工作机制。正确处理当前和长远的关系、解决当前突出问题和建章立制的关系，坚决摒弃“过关”思想，不断把巡视整改工作引向深入。对已经完成的巡视整改任务，适时组织“回头看”，着力巩固巡视整改成果，防止已整改的问题反弹回潮；对要求年内整改到位的任务，严格按照整改工作方案及台账要求，加大工作力度、确保在限定时间内整改落实到位；对需要长期坚持的整改任务，进一步细化责任、明确要求，加强跟踪问效，确保取得实效。坚持把具体问题整改与构建长效机制有机结合起来，深刻剖析问题根源，举一反三，认真研究标本兼治措施，把一些好做法、好经验以制度的形式固定下来，推动解决制约司法为民、公正司法的体制机制性问题。健全防止利益冲突机制，构建不敢腐、不能腐、不想腐的长效机制，进一步防范司法廉洁风险。严格执行任职回避、防止干预过问案件“两个规定”以及规范司法人员与有关人员接触交往行为的规定，全面清理法院干警特别是审判执行人员违反规定从事营利活动、违规兼职、配偶子女违规从事律师职业等问题，防止私人利益与公共利益冲突。加强重点岗位、关键领域管理，深刻汲取近年来一些法院干警违纪违法的教训，加大对重点岗位领导干部日常监管和风险防控力度，坚决铲除滋生腐败的土壤，从源头上减少司法腐败问题。

（八）强化责任担当，切实担负起党和人民赋予的重大职责使命。以巡视整改为契机，充分发挥最高人民法院党组在国家审判机关贯彻以习近平同志为核心的党中央决策部署的核心作用，充分发挥人民法院维护国家政治安全特别是政权安全、制度安全的重要作用，充分发挥人民法院维护公平正义、保障人民权益、巩固党的群众基础的重要作用。把深化巡视整改落实同做好当前和今后一个时期的人民法院工作紧密结合起来，坚持两手抓、两不误、两促进，将深化巡视整改落实作为推进最高人民法院党的建设、深化司法体制改革、坚持司法为民公正司法的强大动力。紧紧围绕党和国家工作大局，适应经济发展新常态，发挥司法维护国家安全和社会稳定、保障人民安居乐业的重要职能作用，发挥司法维护社会公平正义的最后一道防线作用，为经济社会发展提供更加有力司法服务和保障。严格按照中央确定的时间表坚定不移推进司法改革，以自我革命的勇气，直面矛盾、正视问题、敢于担当，努力以改革的办法解决改革发展中出现的问题，确保在党的十九大前基本完成司法体制改革任务，确保改革成效体现在办案质量和效率上，体现在司法公信力提高上。始终坚持以人民呼声为第一信号，切实加强和改进审判执行工作，妥善审理教育、就业、医疗、养老等民生领域案件，加快智慧法院建设，不断完善司法便民利民举措，确保如期实现“用两到三年时间基本解决执行难”目标，努力让人民群众在每一个司法案件中感受到公平正义，为党的十九大胜利召开营造安全稳定的社会环境和公平正义的法治环境。
