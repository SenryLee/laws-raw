# 中国保险监督管理委员会关于经雷任职资格的批复

## 中国保险监督管理委员会关于经雷任职资格的批复（保监资金〔2011〕2049号）

美国友邦保险有限公司上海分公司：

你公司《关于经雷先生任职资格行政许可的请示》（友中发2011－120号）收悉。经审核，经雷符合《保险公司董事、监事和高级管理人员任职资格管理规定》和《保险资金运用管理暂行办法》的有关要求，核准其担任你公司资产管理部门负责人的任职资格。

此复

中国保险监督管理委员会

二○一一年十二月三十日
