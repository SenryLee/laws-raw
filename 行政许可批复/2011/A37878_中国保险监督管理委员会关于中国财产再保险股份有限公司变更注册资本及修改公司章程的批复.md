# 中国保险监督管理委员会关于中国财产再保险股份有限公司变更注册资本及修改公司章程的批复

## 中国保险监督管理委员会关于中国财产再保险股份有限公司变更注册资本及修改公司章程的批复（保监发改〔2011〕37号）

中国财产再保险股份有限公司：

你公司《关于增加注册资本和相应修改公司章程的请示》（中再产险发〔2010〕148号）收悉。经审核，现批复如下：

**一、**同意你公司注册资本变更为75.3225亿元人民币。增资后，你公司股东持股数量和持股比例如下：（1）中国再保险（集团）股份有限公司持有7，532，237，600股，占总股本的99.9998%；（2）上海怡达科技投资有限责任公司持有12，400股，占总股本的0.0002%。

**二、**核准你公司对公司章程作如下修改：

（一）第十条修改为：公司的注册资本为人民币75.3225亿元。全部资本划分为等额股份，每股面值为人民币1元，股份总数为75.3225亿股。

（二）第十二条修改为：公司股份结构情况如下：

|  |  |  |
| --- | --- | --- |
| 股东名称 | 持有股份数（股） | 占总股本比例 |
| 中国再保险（集团）股份有限公司 | 7，532，237，600 | 99.9998% |
| 上海怡达科技投资有限责任公司 | 12，400 | 0.0002% |

请你公司按照有关规定办理变更手续。

中国保险监督管理委员会

二○一一年一月十日
