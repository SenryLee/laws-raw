# 中国证券监督管理委员会关于核准同方股份有限公司下属境外公司在境外发行股票并在香港交易所上市的批复

## 中国证券监督管理委员会关于核准同方股份有限公司下属境外公司在境外发行股票并在香港交易所上市的批复（证监许可〔2011〕1087号）

同方股份有限公司：

你公司报送的《关于同方股份有限公司分拆Technovator Int Private Ltd.并拟在香港联合交易所有限公司主板上市的上市申请报告》（同方文字〔2011〕第061号）及相关文件收悉。根据《证券法》和《国务院关于进一步加强在境外发行股票和上市管理的通知》（国发〔1997〕21号）等有关规定，经审核，现批复如下：

**一、**同意你公司下属公司新加坡科诺威德有限公司（Technovator Int Private Ltd.，在新加坡注册，以下简称科诺威德）在境外首次公开发行股票。完成本次发行后，科诺威德可在香港交易所主板上市。

**二、**科诺威德上市完成后15个工作日内，你公司应将有关情况书面报告我会。

**三、**在科诺威德上市过程中，你公司应严格遵守境内外有关法律、法规和规则。

二○一一年七月十二日
