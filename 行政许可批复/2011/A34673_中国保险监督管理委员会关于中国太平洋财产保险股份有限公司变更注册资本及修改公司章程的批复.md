# 中国保险监督管理委员会关于中国太平洋财产保险股份有限公司变更注册资本及修改公司章程的批复

## 中国保险监督管理委员会关于中国太平洋财产保险股份有限公司变更注册资本及修改公司章程的批复（保监发改〔2011〕424号）

中国太平洋财产保险股份有限公司：

你公司《关于中国太平洋财产保险股份有限公司变更注册资本及修改章程的请示》（太保产〔2011〕13号）收悉。经审核，现批复如下：

**一、**同意你公司注册资本变更为73亿元人民币。增资后，你公司股东持股数量和持股比例如下：（1）中国太平洋保险（集团）股份有限公司持有7，190，599，260股，占总股本的98.50136%；（2）申能（集团）有限公司持有34，072，208股，占总股本的0.46674%；（3）上海国有资产经营有限公司持有19，010，416股，占总股本的0.26042%；（4）上海海烟投资管理有限公司持有33，977，045股，占总股本的0.46544%；（5）云南红塔集团有限公司持有22，341，071股，占总股本的0.30604%。

**二、**核准你公司对公司章程作如下修改：

（一）第六条修改为：公司注册资本为人民币7，300，000，000元，实收资本为人民币7，300，000，000元。

（二）第十四条修改为：公司经批准发行的股份总数为7，300，000，000股，目前的股权结构如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 认购股份数（股） | 持股比例（%） |
| 1 | 中国太平洋保险（集团）股份有限公司 | 7，190，599，260 | 98.50136 |
| 2 | 申能（集团）有限公司 | 34，072，208 | 0.46674 |
| 3 | 上海国有资产经营有限公司 | 19，010，416 | 0.26042 |
| 4 | 上海海烟投资管理有限公司 | 33，977，045 | 0.46544 |
| 5 | 云南红塔集团有限公司 | 22，341，071 | 0.30604 |
| 合 计 | | 7，300，000，000 | 100 |

（三）对《公司章程历次修改记录》的修改情况详见附件。

请你公司按照有关规定办理变更手续。

中国保险监督管理委员会

二○一一年三月三十日
