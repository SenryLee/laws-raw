# 中国证券监督管理委员会关于核准新华基金管理有限公司变更注册资本的批复

## 中国证券监督管理委员会关于核准新华基金管理有限公司变更注册资本的批复（证监许可[2011]1622号）

新华基金管理有限公司：

你公司报送的《新华基金管理有限公司关于进行增资扩股及新增股东等重大变更的申请报告》（新基发[2011]71号）及相关文件收悉。根据《公司法》、《证券投资基金法》和《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由 100，000，000 元人民币增加到160，000，000 元。其中，新华信托股份有限公司增加出资28，800，000 元，陕西蓝潼电子投资有限公司增加出资18，000，000 元，杭州永原网络科技有限公司认购出资13，200，000元。

你公司变更注册资本后，公司的股权结构为：

人民币 元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 新华信托股份有限公司 | 76，800，000 | 48％ |
| 2 | 陕西蓝潼电子投资有限公司 | 48，000，000 | 30％ |
| 3 | 上海大众环境产业有限公司 | 22，000，000 | 13.75％ |
| 4 | 杭州永原网络科技有限公司 | 13，200，000 | 8.25％ |
|  | 合计 | 160，000，000 | 100％ |

**二、**核准你公司所作的与变更公司注册资本、股东出资相关的公司章程修改。

**三、**你公司应当按规定及时办理工商变更登记等相关事宜，并到我会换领《基金管理资格证书》。

中国证券监督管理委员会

二○一一年十月九日
