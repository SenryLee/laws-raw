# 文化部关于同意韩国《Jump》剧组、美国吉他手Mike C Mclaughlin到北京市演出的批复

## 文化部关于同意韩国《Jump》剧组、美国吉他手Mike　C　Mclaughlin到北京市演出的批复（文市函〔2011〕1899号）

北京市文化局：

你局京文外发〔2011〕699号、700号请示收悉。

经研究，同意北京保利剧院管理有限公司邀请韩国预感有限公司《Jump》剧组一行15人，于2011年12月2日至2012年1月26日；美国吉他手Mike C Mclaughlin，于2011年12月15日至2012年6月30日到北京市等地演出。

此复。

二○一一年十月十三日
