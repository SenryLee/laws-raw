# 中国保险监督管理委员会关于法国再保险公司北京分公司与法国财产再保险公司(SCOR GLOBAL P＆C SE)从事再保险业务的批复(保监产险[2011]2015号)

## 中国保险监督管理委员会关于法国再保险公司北京分公司与法国财产再保险公司（SCOR　GLOBAL　P＆C　SE）从事再保险业务的批复（保监产险〔2011〕2015号）

法国再保险公司北京分公司：

你公司《关于2012年超赔分出关联交易的申请》（法再北分再保财〔2011〕第3号）及其补正材料收悉。经审核，原则同意你公司2012年度与法国财产再保险公司（SCOR GLOBAL P&C SE）从事再保险关联交易。

中国保险监督管理委员会
