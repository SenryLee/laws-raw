# 中国保险监督管理委员会关于正德人寿保险股份有限公司修改章程的批复(2011)

## 中国保险监督管理委员会关于正德人寿保险股份有限公司修改章程的批复（保监发改〔2011〕1736号）

正德人寿保险股份有限公司：

你公司关于修改章程的请示（正保发〔2011〕165号）收悉。经审查，核准你公司2011年5月16日股东大会决议将章程第二十二条修改如下：

第二十二条 设立方式及股权结构

公司采取发起方式设立，发起人认购股份如下表：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 发起人 | 股份额  　　（亿股） | 股份比例（%） |
| 1 | 浙江凌达实业有限公司 | 1 | 20 |
| 2 | 浙江美好控股集团有限公司 | 1 | 20 |
| 3 | 五环氨纶实业集团有限公司 | 1 | 20 |
| 4 | 福州开发区泰孚实业有限公司 | 1 | 20 |
| 5 | 新冠投资集团有限公司 | 1 | 20 |
| 合计 |  | 5 | 100 |

出资形式：公司发起人均以货币出资。

本公司发起人“浙江美好控股集团有限公司”已于2007年8月31日经国家工商总局名称核准及浙江省工商局批准更名为“美好控股集团有限公司”。
