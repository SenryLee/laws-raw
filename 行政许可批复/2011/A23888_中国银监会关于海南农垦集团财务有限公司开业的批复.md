# 中国银监会关于海南农垦集团财务有限公司开业的批复

## 中国银监会关于海南农垦集团财务有限公司开业的批复(银监复[2011]551号)

海南省农垦集团有限公司：

《海南省农垦集团有限公司关于核准海南农垦集团财务有限公司开业的请示》（琼垦企字〔２０１１〕２５１号）收悉。根据《企业集团财务公司管理办法》（中国银监会令２００６年第８号）和《非银行金融机构行政许可事项实施办法》（中国银监会令２００７年第１３号）的规定，现批复如下：

一、批准海南农垦集团财务有限公司开业。该公司中文名称为“海南农垦集团财务有限公司”，英文名称为“Hainan State Farms Group Finance Co.,Ltd.”。公司住所为海南省海口市滨海大道１１５号海垦国际金融中心２３层。

二、批准该公司注册资本为５亿元人民币，该公司股东构成、出资额及出资比例如下：

（一）海南省农垦集团有限公司，出资４亿元人民币，出资比例８０％；

（二）海南天然橡胶产业集团股份有限公司，出资１亿元人民币，出资比例２０％。

三、批准该公司经营以下本外币业务：

（一）对成员单位办理财务和融资顾问、信用鉴证及相关的咨询、代理业务；

（二）协助成员单位实现交易款项的收付；

（三）经批准的保险代理业务；

（四）对成员单位提供担保；

（五）办理成员单位之间的委托贷款；

（六）对成员单位办理票据承兑与贴现；

（七）办理成员单位之间的内部转账结算及相应的结算、清算方案设计；

（八）吸收成员单位的存款；

（九）对成员单位办理贷款及融资租赁；

（十）从事同业拆借。

四、核准该公司以下董事和高级管理人员任职资格：

王一新董事长

彭富庆董事

李明泉董事

杨志成董事

邓文杰董事、总经理

周菊芝副总经理

五、批准《海南农垦集团财务有限公司章程》。

接此批复后，你公司应按照相关规定办理海南农垦集团财务有限公司开业前的有关手续。

二○一一年十二月八日
