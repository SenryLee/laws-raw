# 国家邮政局关于同意仿印《京剧脸谱》等邮票图案制作贵金属制品的批复

国邮复〔2019〕142号

中国邮政集团公司上海市分公司：

根据《中华人民共和国邮政法实施细则》规定，按照《仿印邮票图案管理办法》规定程序，国家邮政局对你公司经上海市邮政管理局初审的有关仿印邮票图案及其制品的申请材料依法进行了审核。现批复如下：

一、同意你公司原色原大（30毫米×40毫米）仿印T.45《京剧脸谱》（全套8枚）邮票图案制作5克/枚纯银制品，制作数量为3000套（8枚/套）。承制单位：上海金嘉纪念章有限公司。

同意你公司原色原大（31毫米×38.5毫米）仿印T.106《熊猫》第1图和第3图、原色原大（38.5毫米×31毫米）仿印T.106《熊猫》第2图和第4图邮票图案制作5克/枚纯银制品，制作数量为5000套（4枚/套）。承制单位：上海金嘉纪念章有限公司。

同意你公司原色原大（28毫米×55毫米）仿印2012-7《福禄寿喜》（全套4枚）邮票图案制作10克/枚纯银制品，制作数量为5000套（4枚/套）。承制单位：上海金嘉纪念章有限公司。

二、仿印邮票图案制品或者其外包装上须标明下列各项：

（一）仿印单位名称、地址；

（二）审批机关和批准文号；

（三）制作数量；

（四）制作单位；

（五）印制单位；

（六）其他应当标明的有关事项。

三、仿印T.45《京剧脸谱》（全套8枚）、T.106《熊猫》（全套4枚）和2012-7《福禄寿喜》（全套4枚）邮票图案及其制品由上海市邮政管理局负责监制。你公司须持批准文件与承制企业按照国家有关规定签订印制合同，并在印制前将仿印邮票图案样品送监制单位——上海市邮政管理局（地址：上海市静安区愚园路311号401室）审签后方可正式生产。在仿印邮票图案制品发行前向国家邮政局（地址：北京市西城区北礼士路甲8号）送缴样品存档。不得转让获准仿印邮票图案的制作权和发行权。

四、此文件有效期截止到2020年7月10日。如在批文有效期内未进行仿印，必须报国家邮政局备案，并将批准文件退回。

国家邮政局

2019年7月10日
