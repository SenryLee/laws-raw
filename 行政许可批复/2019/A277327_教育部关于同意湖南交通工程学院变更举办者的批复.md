# 教育部关于同意湖南交通工程学院变更举办者的批复

教发函〔2019〕21号

湖南省教育厅：

你厅《关于湖南交通工程学院变更举办者的请示》（湘教〔2018〕101号）收悉。根据《中华人民共和国民办教育促进法》《民办高等学校办学管理若干规定》（教育部25号令）等有关规定，经审核研究，我部同意湖南交通工程学院举办者由自然人“刘福生”变更为“湖南中盛教育投资有限责任公司”。

特此批复。

教育部

2019年5月7日
