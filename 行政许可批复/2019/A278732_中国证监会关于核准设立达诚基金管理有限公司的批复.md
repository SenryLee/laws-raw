# 中国证监会关于核准设立达诚基金管理有限公司的批复

## 关于核准设立达诚基金管理有限公司的批复

证监许可〔2019〕1127号

宋宜农、章月平、赵楠、徐蔓青、李峻：

你们报送的《关于设立达诚基金管理有限公司（筹）的申请报告》（达诚基金〔2017〕1号）、《关于申请开展特定客户资产管理业务的申请报告》（达诚基金〔2017〕2号）及相关文件收悉。根据《公司法》《证券投资基金法》《证券投资基金管理公司管理办法》（证监会令第84号）和《证券投资基金行业高级管理人员任职管理办法》（证监会令第23号）等有关规定，经审核，现批复如下：

一、核准设立达诚基金管理有限公司（以下简称达诚基金），对公司章程草案无异议，公司注册地为上海市，公司经营范围为公开募集证券投资基金管理、基金销售、特定客户资产管理和中国证监会许可的其他业务。

二、核准达诚基金注册资本为1亿元人民币，核准股权结构为：

三、对宋宜农（公民身份号码：110103××××××××0914）任法定代表人兼董事长、赵楠（公民身份号码：422701××××××××0012）任总经理、赵鹏（公民身份号码：230107××××××××2213）任督察长无异议。宋宜农应当自核准之日起30日内辞去在其他经营性机构所兼任的职务，并在辞任后10日内报告我会。

四、你们应当按照《公司法》《证券投资基金法》《证券投资基金管理公司管理办法》等法律法规和有关规定的要求，自批复之日起6个月内完成达诚基金组建工作，足额缴付出资，选举董事、监事，聘任高级管理人员。

五、达诚基金在取得工商行政管理机关颁发的营业执照后，到我会领取经营证券期货业务许可证；在取得经营证券期货业务许可证前，不得以该名称对外开展业务；自取得经营证券期货业务许可证之日起6个月内，应当发行公募基金产品。

六、达诚基金应当按照诚实信用原则认真履行职责，与股东之间建立有效的风险隔离制度，严格自律，规范运作，防范利益输送，加强公平交易管理，切实保护基金份额持有人的利益。

中国证监会
