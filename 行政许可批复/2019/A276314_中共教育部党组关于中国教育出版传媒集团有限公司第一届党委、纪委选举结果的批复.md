# 中共教育部党组关于中国教育出版传媒集团有限公司第一届党委、纪委选举结果的批复

教党函〔2019〕35号

中共中国教育出版传媒集团有限公司委员会：

你单位《关于中共中国教育出版传媒集团有限公司第三次代表大会和第一届党委会、纪委会第一次全体会议选举结果的报告》（中教集党〔2019〕28号）收悉。经研究，同意你单位党员代表大会选举结果，由于春迟、冯云生、花向荣、苏雨恒、谷新矿、宋永刚、殷忠民、黄强、曾卓明组成中共中国教育出版传媒集团有限公司第一届委员会。批准冯云生同志任党委书记，殷忠民、宋永刚同志任党委副书记。

同意中共中国教育出版传媒集团有限公司第一届纪委会选举结果，批准花向荣同志任纪委书记。

特此批复。

中共教育部党组

2019年4月1日
