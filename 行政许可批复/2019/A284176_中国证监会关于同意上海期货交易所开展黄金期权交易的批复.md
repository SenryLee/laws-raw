# 中国证监会关于同意上海期货交易所开展黄金期权交易的批复

## 关于同意上海期货交易所开展黄金期权交易的批复

上海期货交易所：

你所报送的《关于申请黄金期权上市的请示》（上期发〔2019〕108号）收悉。根据《期货交易管理条例》和《期货交易所管理办法》（证监会令第42号）有关规定，现批复如下：同意你所组织开展黄金期权交易，请做好各项监管工作，确保黄金期权平稳运行和健康发展。

中国证监会

2019年11月22日
