# 国家邮政局关于同意仿印《己亥年》等邮票图案制作仿印制品的批复

国邮复〔2019〕129号

中国邮政储蓄银行股份有限公司：

根据《中华人民共和国邮政法实施细则》规定，按照《仿印邮票图案管理办法》规定程序，国家邮政局对你公司经北京市邮政管理局初审的有关仿印邮票图案及其制品的申请材料依法进行了审核。现批复如下：

一、同意你公司原色原大（36毫米×36毫米）仿印2019-1《己亥年》（全套2枚）、原色原大（26毫米×31毫米）仿印T.80《癸亥年》（全套1枚）邮票图案制作2克/套纯金制品，制作数量为220000套（10枚/套，其中《己亥年》2枚，《癸亥年》8枚）。承制单位：中钞长城贵金属有限公司。

同意你公司原色原大（36毫米×36毫米）仿印2019-1《己亥年》（全套2枚）、原色原大（26毫米×31毫米）仿印T.80《癸亥年》（全套1枚）邮票图案制作4克/套纯金制品，制作数量为10000套（20枚/套，其中《己亥年》4枚，《癸亥年》16枚）。承制单位：中钞长城贵金属有限公司。

同意你公司原色放大（40.5毫米×40.5毫米）仿印2019-1《己亥年》第一图邮票图案制作10克/套PVC制品，制作数量为700000套（1枚/套）。承制单位：楚天龙股份有限公司。

同意你公司原色缩小（35.3毫米×35.3毫米）仿印2019-1《己亥年》第二图邮票图案制作10克/套PVC制品，制作数量为2000000套（1枚/套）。承制单位：北京握奇数据股份有限公司。

同意你公司原色缩小（35.3毫米×35.3毫米）仿印2019-1《己亥年》第二图邮票图案制作10克/套PVC制品，制作数量为2000000套（1枚/套）。承制单位：星汉智能科技股份有限公司。

同意你公司原色缩小（35.3毫米×35.3毫米）仿印2019-1《己亥年》第二图邮票图案制作10克/套PVC制品，制作数量为3000000套（1枚/套）。承制单位：楚天龙股份有限公司。

同意你公司原色缩小（35.3毫米×35.3毫米）仿印2019-1《己亥年》第二图邮票图案制作10克/套PVC制品，制作数量为500000套（1枚/套）。承制单位：鸿博股份有限公司。

同意你公司原色缩小（35.3毫米×35.3毫米）仿印2019-1《己亥年》第二图邮票图案制作10克/套PVC制品，制作数量为500000套（1枚/套）。承制单位：捷德（中国）信息科技有限公司。

二、仿印邮票图案制品或者其外包装上须标明下列各项：

（一）仿印单位名称、地址；

（二）审批机关和批准文号；

（三）制作数量；

（四）制作单位；

（五）印制单位；

（六）其他应当标明的有关事项。

三、仿印2019-1《己亥年》（全套2枚）、T.80《癸亥年》（全套1枚）邮票图案及其制品由北京市邮政管理局负责监制。你公司须持批准文件与承制企业按照国家有关规定签订印制合同，并在印制前将仿印邮票图案样品送监制单位——北京市邮政管理局（地址：北京市海淀区万寿路18号）审签后方可正式生产。在仿印邮票图案制品发行前向国家邮政局（地址：北京市西城区北礼士路甲8号）送缴样品存档。不得转让获准仿印邮票图案的制作权和发行权。

四、此文件有效期截止到2020年6月3日。如在批文有效期内未进行仿印，必须报国家邮政局备案，并将批准文件退回。

国家邮政局

2019年6月3日
