# 国家文物局关于北海永安寺琉璃宇墙、碑亭修缮项目设计方案的批复

文物保函〔2019〕209号

北京市文物局：

你局《关于北海及团城——永安寺琉璃宇墙、碑亭修缮工程的请示》（京文物〔2018〕1862号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步细化永安寺的价值评估，区分修缮记录与历史沿革。

（二）深化现状勘察。结合屋面瓦和苫背保存情况，核实望板及其油饰残损的具体原因；校核宇墙正、反两面断砖数量，明确裂缝类型，从局部受力、灰浆硬度等方面分析宇墙病害成因。

（三）依据宇墙病害成因进一步细化其保护加固措施，明确更换、补配构件的规格和质量要求。严格控制宇墙新添配琉璃构件的数量，不得更换已风化但仍满足结构要求的琉璃构件。

（四）补充补配木构件的规格要求，并尽量选与原构件材质相同材料。若采取铁箍加固，需给出加固设计详图。

（五）东西碑亭尽可能续用现有地仗层，宜以现状色调确定碑亭油饰色彩。

（六）通过增加封护板厚度、包裹软质材料等方式，加强对御碑和室内彩画的防护，避免施工过程中对文物造成损害。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局
