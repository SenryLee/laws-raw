# 国家邮政局关于《中国人民政治协商会议成立七十周年》纪念邮票图稿的批复

国邮复〔2019〕170号

中国邮政集团公司：

你公司关于报审《中国人民政治协商会议成立七十周年》纪念邮票图稿的请示（中国邮政〔2019〕424号）收悉。根据国家邮政局审定的2019年纪特邮票发行计划，该纪念邮票1套2枚。邮票内容为：1. 人民政协七十周年；2.全国政协礼堂新貌。发行日期为2019年9月21日。经审查并征求有关部门意见，同意使用修改后的邮票图稿（见附件）印制邮票。

此复。
