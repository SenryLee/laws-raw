# 国家邮政局关于同意仿印《庚子年》邮票图案制作贵金属制品的批复

国邮复〔2019〕236号

中国邮政集团公司山东省分公司：

根据《中华人民共和国邮政法实施细则》规定，按照《仿印邮票图案管理办法》规定程序，国家邮政局对你公司经山东省邮政管理局初审的有关仿印邮票图案及其制品的申请材料依法进行了审核。现批复如下：

一、同意你公司单色原大（36毫米×36毫米）仿印2020-1《庚子年》（全套2枚）邮票图案制作4克/套四方连纯金制品，制作数量为3000套（8枚/套，第1图、第2图各4枚）。承制单位：深圳市金宝盈文化股份有限公司。

同意你公司单色原大（36毫米×36毫米）仿印2020-1《庚子年》（全套2枚）邮票图案制作0.07克/枚纯金制品，制作数量为7000套（2枚/套）。承制单位：深圳市金宝盈文化股份有限公司。

同意你公司原色原大（36毫米×36毫米）仿印2020-1《庚子年》（全套2枚）邮票图案制作5克/枚纯银制品，制作数量为1000套（2枚/套）。承制单位：宝泉贵金属制造有限公司。

同意你公司原色原大（36毫米×36毫米）仿印2020-1《庚子年》（全套2枚）邮票图案制作15克/枚纯银制品，制作数量为1000套（2枚/套）。承制单位：宝泉贵金属制造有限公司。

同意你公司单色原大（36毫米×36毫米）仿印2020-1《庚子年》（全套2枚）邮票图案制作1克/枚纯银制品，制作数量为5000套（2枚/套）。承制单位：宝泉贵金属制造有限公司。

同意你公司单色缩小（20毫米×20毫米）仿印2020-1《庚子年》（全套2枚）邮票图案制作15克/套纯金制品，制作数量为500套（2枚/套）。承制单位：江苏金一文化发展有限公司。

同意你公司单色缩小（20毫米×20毫米）仿印2020-1《庚子年》（全套2枚）邮票图案制作35克/套纯金制品，制作数量为2500套（2枚/套）。承制单位：江苏金一文化发展有限公司。

同意你公司原色放大（200毫米×200毫米）仿印2020-1《庚子年》（全套2枚）邮票图案制作帆布制品，制作数量为2000套（2枚/套）。承制单位：北京华菲尔工贸中心。

同意你公司单色放大（100毫米×100毫米）仿印2020-1《庚子年》（全套2枚）邮票图案制作纸质制品，制作数量为5700套（2枚/套）。承制单位：北京华菲尔工贸中心。

二、仿印邮票图案制品或者其外包装上须标明下列各项：

（一）仿印单位名称、地址；

（二）审批机关和批准文号；

（三）制作数量；

（四）制作单位；

（五）印制单位；

（六）其他应当标明的有关事项。

三、仿印2020-1《庚子年》（全套2枚）邮票图案及其制品由山东省邮政管理局负责监制。你公司须持批准文件与承制企业按照国家有关规定签订印制合同，并在印制前将仿印邮票图案样品送监制单位——山东省邮政管理局（地址：山东省济南市纬二路168号）审签后方可正式生产。在仿印邮票图案制品发行前向国家邮政局（地址：北京市西城区北礼士路甲8号）送缴样品存档。不得转让获准仿印邮票图案的制作权和发行权。

四、此文件有效期截止到2020年12月30日。如在批文有效期内未进行仿印，必须报国家邮政局备案，并将批准文件退回。

国家邮政局
