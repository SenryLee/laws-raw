# 交通运输部关于外籍船舶临时进靠广东省烽火海洋网络设备有限公司配套码头期限的批复

交海批〔2019〕22号

广东省人民政府口岸办公室：

《广东省口岸办关于烽火海洋网络设备有限公司码头临时进靠外籍船舶装载作业的请示》（粤府口字〔2019〕4号）和《珠海市港口管理局关于烽火海洋网络设备有限公司申请外籍船只临时进入并靠泊配套码头的意见》（珠港口字〔2019〕36号）收悉，根据《国务院关于口岸开放的若干规定》，经征询国家检查检验机构和军委联参意见，同意外籍船舶临时进出烽火海洋网络设备有限公司配套码头，期限自2019年7月1日至2019年9月15日。

你办应督促相关部门认真履职，确保临时进出烽火海洋网络设备有限公司码头的外籍船舶严格遵守国家法律法规以及军方有关规定要求，提前报告船舶进出港动态，做好在船人员的管理，遵守通航管理和港口设施保安规定，确保船舶安全。

请按照国家有关规定和要求，尽快完成口岸正式开放所需手续。

交通运输部

2019年6月27日
