# 国家邮政局关于《中葡建交四十周年》纪念邮票图稿的批复

国邮复〔2019〕25号

中国邮政集团公司：

你公司关于报审《中葡建交四十周年》纪念邮票图稿的文（中国邮政函〔2018〕141号）收悉。根据我局审定的2019年纪特邮票发行计划，该纪念邮票一套2枚，邮票内容为：1.紫砂茶具；2.银茶具。发行日期为2019年2月8日。经审查并征求有关部门意见，同意使用该图稿印制邮票。

此复。

国家邮政局

2019年1月10日
