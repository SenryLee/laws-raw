# 国家发展改革委关于甘肃兰州中川国际机场三期扩建工程项目建议书的批复

发改基础〔2019〕319号

甘肃省发展改革委：

报来《关于上报兰州中川国际机场三期扩建工程预可行性研究报告的请示》（甘发改交运〔2018〕940号）及有关材料均悉。经研究，现批复如下。

一、为提升兰州中川国际机场的综合保障能力和服务水平，适应航空业务量快速增长需要，完善区域综合交通运输体系，促进经济社会发展，同意实施兰州中川国际机场三期扩建工程。

二、本期工程按2030年旅客吞吐量3800万人次、货邮吞吐量30万吨的目标设计。主要建设内容包括：

（一）机场工程。飞行区等级指标4E，在现西一跑道东侧380米处新建1条长4000米、宽45米的西二跑道；在西二跑道东侧1700米处新建1条长4000米、宽45米的东一跑道，双向设置I类精密进近系统。在西二跑道和东一跑道之间建设40万平方米的T3航站楼及87个机位的站坪、9个机位的除冰坪、27万平方米的综合交通中心，以及货运、航食、消防救援等辅助生产生活设施，配套建设供电、给排水、供热、制冷、供气等配套设施。

（二）空管工程。新建塔台小区，包括1座塔台、2100平方米的附属技术用房和640平方米的业务用房等；新建空管小区，包括管制综合楼、动力能源站等，总建筑面积2.15万平方米；新建2座场面监视雷达、1套多点定位系统，以及航管、通信、气象等设施。

（三）供油工程。新建4座1万立方米的油罐，第二航空加油站，航油综合保障中心及机坪加油管线等。

三、项目总投资约316.9亿元，其中，机场工程295亿元，原则上由我委、民航局、甘肃省人民政府、兰州市人民政府和甘肃省民航机场集团有限公司共同筹措解决；空管工程14.2亿元，由民航局安排民航发展基金解决；供油工程7.7亿元，由中国航空油料有限责任公司筹措解决，具体资金安排在项目可行性研究阶段确定。

四、在后续阶段，要重点做好以下工作：

（一）深化航空业务量预测分析，优化机场总平面布局及建设方案，提高机场运行效率和资源利用率。

（二）完善机场集疏运系统规划，强化机场与铁路、城市轨道交通等方式的有机衔接，实现便捷高效换乘，充分发挥机场综合交通枢纽作用。

（三）落实项目资金筹措方案，防范新增地方政府债务风险，为项目建设及运营提供必要的资金保障。

（四）做好机场与城市总体规划和土地利用规划的衔接，管控好机场净空、电磁环境和规划发展用地，确保机场安全运行和可持续发展。
