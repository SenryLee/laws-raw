# 国家文物局关于房山云居寺塔及石经断龙桥抢险加固工程方案变更的批复

文物保函〔2019〕91号

北京市文物局：

你局《关于房山云居寺塔及石经断龙桥抢险加固工程方案变更的请示》（京文物〔2019〕12号）收悉。经研究，我局原则同意所报房山云居寺塔及石经断龙桥抢险加固工程方案变更。

一、变更后的方案尚需作以下必要的修改和完善：

（一）进一步评估拟拆除金刚墙的歪闪程度和稳定性，补充论证预加固后进行基础加固或托换的可行性，尽量减少墙体拆砌范围。如确需整体拆砌，重新砌筑应遵循传统工艺和做法。

（二）深化完善修缮措施。应加强各分水金刚墙北端抗水流冲击能力的保护措施；细化卵石间灌注级配砂石及砌筑灰浆的具体要求。

（三）补配石构件的表面处理应采用手工操作，以确保石面防滑、稳固，与原石材的制作工艺及外观相协调。

（四）补充现状照片和图纸，完善工序和档案记录。

二、请你局指导有关单位按照上述意见修改、完善，变更后的方案，经你局批准后实施。

三、按照《国家文物局关于房山云居寺及石经断龙桥抢险加固项目的批复》（文物保函〔2017〕1649号）要求，做好施工中的各项工作，确保项目质量和文物、人员安全。

专此函复。

国家文物局

2019年1月23日
