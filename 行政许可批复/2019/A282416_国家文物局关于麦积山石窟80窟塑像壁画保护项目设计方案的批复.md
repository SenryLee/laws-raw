# 国家文物局关于麦积山石窟80窟塑像壁画保护项目设计方案的批复

文物保函〔2019〕816号

甘肃省文物局：

你局《关于呈报麦积山石窟80窟塑像壁画保护项目设计方案的请示》（甘文局发〔2019〕108号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需做以下必要的修改和完善：

（一）进一步细化材料检测分析工作。补充对木骨架材种、地仗纤维的科学鉴定；补充可溶盐晶相学分析；颜料分析不应仅通过元素检测进行推测，应采样进行显微鉴定；补充胶结材料分析的相关内容。

（二）补充示意图，简要说明第80窟的彩塑制作工艺。

（三）应充分考虑石窟所在环境及原制作材料的特点，补充深化多种保护加固材料的实验室比选。

（四）进一步论证灌浆处理的必要性。

（五）进一步总结分析洞窟微环境对泥塑壁画的影响，采取有针对性的处理措施，并对后续预防性保护工作提出建议。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年8月14日
