# 国家邮政局关于《中俄建交七十周年》纪念邮票图稿的批复

国邮复〔2019〕154号

中国邮政集团公司：

你公司关于报审《中俄建交七十周年》纪念邮票图稿的请示（中国邮政〔2019〕454号）收悉。根据我局审定的2019年纪特邮票发行计划，该纪念邮票1套2枚。邮票内容为：1.长江·朝天门长江大桥；2. 伏尔加河·萨拉托夫大桥。发行日期为2019年10月2日。经审查，同意采用第一方案印制邮票。

此复。

国家邮政局

2019年8月7日
