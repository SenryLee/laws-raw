# 国家文物局关于天津市文化遗产保护中心更换考古发掘资质证书的批复

文物保函〔2019〕710号

天津市文物局：

你局《关于天津市文化遗产保护中心更换考古发掘资质证书的请示》（津文物发〔2019〕17号）收悉。

经研究，我局同意为天津市文化遗产保护中心更换新的《中华人民共和国考古发掘资质证书》。请通知有关单位携原资质证书正、副本来我局办理更换手续。

国家文物局

2019年7月16日
