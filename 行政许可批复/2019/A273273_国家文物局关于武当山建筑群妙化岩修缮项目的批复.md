# 国家文物局关于武当山建筑群妙化岩修缮项目的批复

文物保函〔2019〕10号

湖北省文化和旅游厅：

原湖北省文物局《关于报送武当山古建筑群妙化岩修缮工程设计方案的请示》（鄂文物〔2018〕46号）收悉。经研究，我局原则同意所报武当山古建筑群妙化岩修缮项目方案。

一、所报方案尚需做作以下必要的修改和完善：

（一）进一步完善现状勘察。应补充对周边散落构件的清理、收集、记录和分析，补充构件照片及详图，作为修缮设计的基本参考；准确分析山墙产生纵向通裂缝的原因。

（二）补充完善现状勘察图纸。总平面图应补充标注建筑与周边岩体、洞穴、所在平台边缘的距离尺寸；补充各点位标高标注和排水方向；补充冰盘檐现状做法详图；核实须弥座是否存在残缺。

（三）补充深化对比研究，论证并细化修复设计。应扩大对比研究范围，尽可能详实地分析武当山同时期同类建筑的形制和做法；廊梅祠屋面与设计方案样式不同，应进一步细化分析其参考作用；细化屋面举架和曲度分析；明确从屋面至拱券的构造层做法和材料，补充剖面构造标注，注意核算屋面荷载、拱脚侧推力、拱券稳定性及下部墙体承载力；补充角梁、屋脊、脊兽、正吻、勾头滴水等的做法依据、平面、构造剖面和构件详图；细化檐部椽飞、冰盘檐的做法和详图，核实椽飞构件的出挑倾角，注意考虑椽后部覆压构造设计；细化石窗扇和门的设计依据及节点详图。

（四）结合修缮措施深化，审慎界定修缮完成后妙化岩的总体外观，尤其是保留加固部分与修复部分的外观协调性和交接面处理。

（五）进一步明确修缮措施要求。结合荷载、承载力等验算，补充论证墙体修缮措施的可靠性，以及是否需加强墙体拉接；进一步细化旧墙体加固、新旧砌体衔接、局部墙体拆砌、灌浆加固的具体材料和工艺要求；对清理中发现的旧构件，应最大限度用于原位，图纸中应明确具体部位；审慎论证砂浆修补风化、酥碱砖石的具体适用标准、材料、工艺和范围，避免加强冻融影响；明确对墙面灰的渗透加固做法，暂不宜使用环氧树脂或其他化学药剂进行加固，粘结材料强度不应过高。

（六）细化建筑物与山体间的衔接节点设计。

（七）补充施工期间对丹床等石雕构件的防护措施，确保文物安全。

二、具体方案由你厅指导有关单位按照上述意见修改、完善并经你厅批准后实施。

三、施工前请你厅督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你厅按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你厅切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局
