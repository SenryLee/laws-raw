# 国家卫生健康委关于中山大学附属第一医院医学综合楼工程初步设计和投资概算的批复

国卫规划函〔2019〕3号

中山大学附属第一医院：

你院《关于报批医学综合楼工程初步设计和投资概算的请示》（附一〔2018〕18号）收悉。经研究，批复如下：

原则同意你院医学综合楼工程初步设计和投资概算。该工程总建筑面积54,100平方米，其中，地上建筑面积43,253平方米，地下建筑面积10,847平方米。工程概算总投资51,466万元，资金来源为申请中央预算内投资和医院筹措资金共同解决。

请你院按照国家有关规定，严格执行基本建设程序，落实项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计和投资概算，抓紧组织开展下一步工作。按照《中央预算内直接投资项目概算管理暂行办法》（发改投资〔2015〕482号）和《国家卫生健康委员会属（管）单位基本建设管理办法》（国卫规划发〔2018〕7号）规定，加强全过程监督和概算管理，确保不突破批复的总投资概算。

此复。

国家卫生健康委

2019年1月4日
