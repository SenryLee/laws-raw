# 国家邮政局关于《粤港澳大湾区》特种邮票发行计划有关事宜的批复

国邮复〔2019〕161号

中国邮政集团公司：

你公司关于报送《粤港澳大湾区》邮票发行计划相关信息的请示（中国邮政〔2019〕480号）收悉。经研究，同意《粤港澳大湾区》特种邮票发行计划确定为一套3枚，表现内容分别为：1.国际科创中心；2.要素便捷流动；3.优质生活圈。面值均为1.20元。发行日期为2019年9月26日。

为宣传推动粤港澳大湾区建设发展，同意增加发行《粤港澳大湾区》小全张1枚。

请你公司据此抓紧开展相关工作。

此复。

国家邮政局

2019年8月14日
