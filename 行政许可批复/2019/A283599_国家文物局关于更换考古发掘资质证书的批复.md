# 国家文物局关于更换考古发掘资质证书的批复

文物保函〔2019〕1053号

安徽省文物局：

你局《关于变更安徽省考古研究所发掘资质证书的请示》（皖文物保〔2019〕53号）收悉。

经研究，我局同意变更安徽省文物考古研究所考古发掘资质证书法定代表人为叶润清，并更换《中华人民共和国考古发掘资质证书》，对相关机构信息进行变更。请通知有关单位携原资质证书正、副本来我局办理更换手续。

此复。

国家文物局

2019年10月16日
