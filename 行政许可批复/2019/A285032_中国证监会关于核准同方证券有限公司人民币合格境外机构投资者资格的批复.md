# 中国证监会关于核准同方证券有限公司人民币合格境外机构投资者资格的批复

## 关于核准同方证券有限公司人民币合格境外机构投资者资格的批复

同方证券有限公司：

你公司报送的关于人民币合格境外机构投资者资格的申请及相关文件收悉，根据《人民币合格境外机构投资者境内证券投资试点办法》（证监会令第90号）等有关规定，经审核，现批复如下：

一、核准同方证券有限公司Tongfang Securities Limited）人民币合格境外机构投资者资格。

二、你公司在开展人民币合格境外机构投资者业务过程中，应当严格遵守有关规定，依法履行职责、承担责任。

中国证监会

2019年11月26日
