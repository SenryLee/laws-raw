# 国家文物局关于曾庙景圣门、育英门、东围墙修缮项目设计方案的批复

文物保函〔2019〕312号

山东省文物局：

你局《关于呈报曾庙景圣门、育英门、东围墙维修方案的请示》（鲁文发〔2018〕112号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）深化文物墙体现状勘察，分析墙体病害成因，严格控制墙体干预强度，尽量减少剔补范围。补充新砖与老砖连接做法，明确砖缝勾补具体要求；应现状保留不影响结构稳定性和使用的砖石构件，不得统一进行磨头打磨和桐油钻生。

（二）核实文物墙顶原有构造，细化瓦面残损状况说明，补充墙顶平面图，景圣门屋面应采取局部揭瓦修缮。

（三）细化说明景圣门、育英门木柱残损程度，补充现状照片，明确采取包镶、墩接修缮措施的必要性。

（四）明确原油饰地仗做法，以此为依据修复局部残损油饰地仗，细化相关工艺要求。

（五）核实墙面不同部位的抹灰做法，补充采用红浆、包金土浆、白浆做法的依据及工艺做法要求，不应使用现代墙面涂料。

（六）完善院落及场地排水方案，补充竖向设计图纸。

（七）规范文本，校核文字，补充图纸量化标注。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局
