# 国家文物局关于潮州开元寺地藏阁抢险加固设计方案的批复

文物保函〔2019〕556号

广东省文物局：

你局《关于全国重点文物保护单位潮州开元寺地藏阁抢险加固设计方案的请示》（粤文物审〔2019〕48号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）深化现状勘察，进一步明确险情涉及范围，细化相关文字、图纸表述。

（二）梳理损坏构件的数量及保存情况，补充对可续用构件的补强修复措施。

（三）深化完善支顶、换柱和打牮拨正施工方案。校核拟支顶部位的荷载，增加支垫木块的强度要求，明确支撑钢管的壁厚规定，补充支顶的平面布置图和立面设计图；应明确是否对上部屋面瓦、脊饰等进行扰动，如有必要，应对脊饰进行防护。

（四）明确蚁害防治的措施、材料及具体要求，注意与抢险加固工作做好衔接。

（五）补充必要的监测措施，完善设计预算。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年6月14日
