# 交通运输部关于交通运输环境保护标准化技术委员会换届及组成方案的批复

交科技函〔2019〕4号

交通运输环境保护标准化技术委员会：

你委《关于开展交通运输环境保护标准化技术委员会换届工作的请示》（交环标〔2018〕22号）收悉。经研究，同意交通运输环境保护标准化技术委员会换届及组成方案。

第三届交通运输环境保护标准化技术委员会由41名委员组成（委员名单见附件）。交通运输部公路科学研究院岑晏青任主任委员，交通运输部天津水运工程科学研究院朱建华、江西省高速公路投资集团有限责任公司俞文生、贵州省交通科学研究院股份有限公司马旭东任副主任委员，交通运输部公路科学研究院邵社刚任委员兼秘书长，交通运输部天津水运工程科学研究院彭士涛任委员兼副秘书长。秘书处承担单位为交通运输部公路科学研究院。请按照标委会章程进行管理。
