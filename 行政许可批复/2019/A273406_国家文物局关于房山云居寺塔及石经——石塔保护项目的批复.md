# 国家文物局关于房山云居寺塔及石经——石塔保护项目的批复

文物保函〔2019〕22号

北京市文物局：

你局《关于房山云居寺塔及石经——石塔保护工程设计方案的请示》（京文物〔2018〕1565号）收悉。经研究，我局原则同意所报房山云居寺石塔保护项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应进一步加强现状勘察。细化勘察塔体表面污染物，分析其类型和污染原因；补充分析塔体裂缝对结构安全性的影响；补充分析后加角铁的加固效果；补充对太极元年塔基础形制及保存情况的勘察。

（二）应按照“最小干预”原则，严格控制修缮范围。应依据详细勘察结论，如果塔体裂缝对结构影响较小，可加强监测，暂不进行灌浆处理；如后加角铁对结构安全的必要性不足，可考虑拆除；如确需加固，应考虑加固材料的热胀冷缩系数，审慎论证其选材；清洗工作应以清洗铁锈为主，不宜清洗其他附着物；补充论证对塔基进行高压注浆加固的必要性，充分考虑其次生病害，如无把握，建议采用传统方式维修基础。暂不同意实施防风化加固措施，可开展前期局部试验。

（三）进一步细化各修缮措施，明确各修缮措施实施的具体位置、范围，补充对材料、工艺的具体要求。

（四）进一步校核文字，补充完善修缮设计图纸。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年1月8日
