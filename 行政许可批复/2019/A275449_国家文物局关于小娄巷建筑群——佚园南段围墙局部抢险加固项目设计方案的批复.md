# 国家文物局关于小娄巷建筑群——佚园南段围墙局部抢险加固项目设计方案的批复

文物保函〔2019〕268号

江苏省文物局：

你局《关于审批小娄巷建筑群——佚园南段围墙局部抢险加固工程方案的请示》（苏文物保〔2019〕4号）收悉。经研究，我局原则同意所报佚园南段围墙局部抢险加固项目设计方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步勘察现有混凝土防护墙的结构可靠性，深化扶壁柱和基础的相关设计方案，并补充必要的设计图纸。

（二）补充完善施工期间及施工后期，佚园南围墙的监测方案和应急预案。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。同时，建议进一步考证佚园南围墙原貌及原有做法，研究其价值，评估其整体稳定性，判断是否需要进行全面修缮。

专此函复。

国家文物局

2019年3月19日
