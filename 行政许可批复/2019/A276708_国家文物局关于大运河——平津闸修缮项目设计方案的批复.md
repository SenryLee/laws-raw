# 国家文物局关于大运河——平津闸修缮项目设计方案的批复

文物保函〔2019〕365号

北京市文物局：

你局《关于大运河——平津闸修缮工程的请示》（京文物〔2018〕1955号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）补充木质平板桥复原依据，尽量弱化木质平板桥的体量感和形式感；新建钢制平板桥的必要性不足，不得移位重建。

（二）暂不同意恢复两侧闸房，其必要性和设计依据不足。若绞盘确需防护，建议采用现代防护设施，严格控制体量，并加强与周边景观环境的协调。

（三）细化北岸条石地面测绘，补充论证条石揭墁、重新对应榫口的必要性，建议保留现有条石地面现状，仅作现状整修即可，避免过度扰动。

（四）补充原构件保护措施，严格控制补配构件数量，取消“石材见新、重新剔凿卡口”等不当做法，补充石材粘接材料的配比要求。

（五）进一步规范体例、校核文本、细化图纸，补充全景照片。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年4月18日
