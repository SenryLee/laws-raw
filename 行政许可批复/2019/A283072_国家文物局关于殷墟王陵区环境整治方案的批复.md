# 国家文物局关于殷墟王陵区环境整治方案的批复

办保函〔2019〕812号

河南省文物局：

你局《关于报批殷墟遗址王陵区环境整治工程方案的请示》（豫文物〔2019〕134号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需做以下必要的修改和完善：

（一）应进一步加强考古和研究，系统梳理殷墟考古工作成果，开展全面的考古调查和发掘工作，明确工程涉及区域内文物分布和保存现状，在此基础上调整完善方案设计内容，提升殷墟王陵区环境风貌。

（二）科学分析王陵区管理服务设施需求，大幅度核减新建南大门体量、简化大门样式，减少管理用房数量和广场硬化面积。

（三）进一步考虑王陵墓葬、260号墓、车马坑等现有展示建筑外观改造的必要性，应统筹考虑王陵区保护和开放展示需要，研提260号墓、车马坑的保护性设施改造措施，建议根据殷墟遗址博物馆建设情况适时进行车马坑迁移展示。

（四）补充说明设置连接南北门轴线道路的考古依据；植被应尽量选择本地植物种类，不宜使用水稻；优化围墙样式和选材，核减王陵区内人工设施数量，避免城市园林化景观设计倾向。

（五）严格控制工程范围和施工强度，做好施工中的文物保护工作，考古专业人员应全程监督、配合，确保文物安全。

二、具体方案由你局指导有关单位按照上述意见和考古发掘成果修改、完善，并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年8月13日
