# 中国证监会关于核准摩根士丹利华鑫基金管理有限公司变更股权的批复

## 关于核准摩根士丹利华鑫基金管理有限公司变更股权的批复

证监许可〔2019〕1028号

摩根士丹利华鑫基金管理有限公司：

你公司报送的《关于深圳市招融投资控股有限公司10.989%股权变更及深圳市基石创业投资有限公司增资事项的申请报告》（摩根士丹利华鑫基金字〔2018〕036号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

一、核准深圳市招融投资控股有限公司将其持有的你公司股权转让给摩根士丹利国际控股公司（Morgan Stanley International Holdings Inc.），深圳市基石创业投资有限公司认购你公司的新增注册资本。转让及认购完成后，你公司注册资本增加至2.5亿元人民币，股权结构变更为：

|  |  |  |
| --- | --- | --- |
| 序号 | 股东名称 | 持股比例 |
| 1 | 摩根士丹利国际控股公司 | 44% |
| 2 | 华鑫证券有限责任公司 | 36% |
| 3 | 深圳市基石创业投资有限公司 | 15% |
| 4 | 深圳市中技实业（集团）有限公司 | 5% |
|  | 合计 | 100% |

二、你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2019年6月6日
