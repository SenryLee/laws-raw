# 国家文物局关于更换考古发掘资质证书的批复

文物保函〔2019〕834号

黑龙江省文化和旅游厅：

你厅《关于变更黑龙江省文物考古研究所考古发掘资质证书有关信息的请示》（黑文旅呈〔2019〕76号）收悉。

经研究，我局同意变更黑龙江省文物考古研究所考古发掘资质证书法定代表人为赵永军，并更换《中华人民共和国考古发掘资质证书》。请通知有关单位携原资质证书正、副本来我局办理更换手续。

国家文物局

2019年8月19日
