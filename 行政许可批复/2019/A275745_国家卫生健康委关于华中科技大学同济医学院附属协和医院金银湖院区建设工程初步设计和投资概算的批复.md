# 国家卫生健康委关于华中科技大学同济医学院附属协和医院金银湖院区建设工程初步设计和投资概算的批复

国卫规划函〔2019〕69号

华中科技大学同济医学院附属协和医院：

你院《关于报请审批金银湖院区建设工程初步设计及投资概算的请示》（协和行字〔2018〕78号）收悉。经研究，批复如下：

原则同意你院金银湖院区建设工程初步设计和投资概算。该工程总建筑面积118,378平方米，其中，地上建筑面积84,397平方米，地下建筑面积33,981平方米。工程概算总投资95,603万元，资金来源为地方政府投资和医院筹措资金共同解决。

请你院按照国家有关规定，严格执行基本建设程序，落实项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计和投资概算，抓紧组织开展下一步工作。按照《中央预算内直接投资项目概算管理暂行办法》（发改投资〔2015〕482号）和《国家卫生健康委员会属（管）单位基本建设管理办法》（国卫规划发〔2018〕7号）规定，加强全过程监督和概算管理，确保不突破批复的总投资概算。

此复。

国家卫生健康委

2019年3月29日
