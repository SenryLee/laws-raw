# 交通运输部关于国际航行船舶临时进出福州港黄岐港区黄岐对台客运码头期限的批复

交海批〔2019〕33号

福建省人民政府口岸工作办公室：

《福建省人民政府口岸工作办公室关于请求延长国际航行船舶临时进出福州港黄岐港区黄岐对台客运码头的请示》（闽口岸〔2019〕25号）收悉。根据《国务院关于口岸开放的若干规定》，经征询国家检查检验机构和军委联参意见，同意国际航行船舶临时进出福州港黄岐港区黄岐对台客运码头，期限延长至2020年5月3日。

你办应督促相关部门认真履职，确保临时进出福州港黄岐港区的国际航行船舶严格遵守国家法律法规以及军方有关规定要求，提前报告船舶进出港动态，做好在船人员的管理，遵守通航管理规定，确保船舶安全。

请按照国家有关规定和要求，尽快完成口岸正式开放所需手续。

交通运输部

2019年10月28日
