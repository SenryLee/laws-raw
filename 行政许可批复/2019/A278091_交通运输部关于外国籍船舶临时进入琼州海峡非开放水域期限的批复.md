# 交通运输部关于外国籍船舶临时进入琼州海峡非开放水域期限的批复

交海批〔2019〕13号

海南省商务厅：

《海南省商务厅关于商请批准南方主网与海南电网第二回联网工程外籍船舶临时进入琼州海峡非开放水域施工作业续期的请示》（琼商〔2019〕66号）收悉。根据《国务院关于口岸开放的若干规定》，经征询国家检查检验机构和军委联参意见，同意外国籍船舶Normand pacific（挪威籍）和Joseph Plateau（卢森堡籍）临时进入琼州海峡非开放水域，期限自2019年5月1日至2019年7月31日。

你厅应督促相关部门认真履职，确保临时进出琼州海峡非开放水域的2艘外国籍船舶在确定的水域范围内活动，严格遵守国家法律法规以及军方有关规定要求，提前报告船舶动态，做好在船人员的管理，遵守通航管理规定，确保船舶安全。

交通运输部

2019年4月16日
