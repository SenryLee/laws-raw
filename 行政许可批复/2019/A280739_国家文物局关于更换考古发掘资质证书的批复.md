# 国家文物局关于更换考古发掘资质证书的批复

文物保函〔2019〕784号

山东省文化和旅游厅：

你厅《关于更换济南市考古研究所考古发掘资质证书的请示》收悉。

经研究，我局同意为济南市考古研究所更换新的《中华人民共和国考古发掘资质证书》。请通知有关单位携原资质证书正、副本来我局办理更换手续。

国家文物局

2019年8月7日
