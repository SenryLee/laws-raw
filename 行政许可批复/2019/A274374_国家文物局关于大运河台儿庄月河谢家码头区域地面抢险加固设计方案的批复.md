# 国家文物局关于大运河台儿庄月河谢家码头区域地面抢险加固设计方案的批复

文物保函〔2019〕154号

山东省文物局：

你局《关于大运河台儿庄月河谢家码头区域地面抢险加固方案的请示》（鲁文发〔2019〕3号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步明确本项目与大运河中河台儿庄（月河）段驳岸维修项目的关系。该项目应与驳岸本体维修相协调，不能影响文物本体的安全。

（二）深化现状勘察。补充地质勘察资料，查清地层岩性及物理力学性质，明确既有基础土夯实厚度及质量，对比周边完好区段，综合分析病害成因。

（三）提高保护措施的针对性。根据岩土层的物理力学性质，确定换填土层的厚度或采取其它补强措施，确保道路整体稳定性。

（四）细化铺设垫层的铺设方式。应尽量人工夯实，不采用机械夯实，以免机械振动对驳岸产生不利影响。

（五）进一步评估病害对驳岸的影响，补充驳岸的防护措施。细化排水设计，应做好管道及地面排水。

（六）补充完善设计图纸。如地面石规格、垫层包括持力层工艺做法标注、排水图纸等。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年2月14日
