# 国家文物局关于大栅栏商业建筑——谦祥益修缮工程设计方案的批复

文物保函〔2019〕161号

北京市文物局：

你局《关于大栅栏商业建筑——谦祥益修缮工程的请示》（京文物〔2018〕1907号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）工程应以现状加固整修为主，台明石构件保护应以清洗、勾缝为主，并保持石材表面原有色彩和质感。残墙面应以红砖砌体的局部剔换为主，以保持墙面的协调。

（二）东侧门脸首层墙体采用单面钢筋网50mm厚喷射混凝土加固，应通过减小拉结筋间距、加强拉结筋与墙体锚固能力等措施，确保加固的面层与老墙体的可靠连接。

（三）进一步减小干预，在保证砖砌体结构安全的前提下，将面砖剔补保护的标准提高到表面酥碱深度超过20mm。

（四）进一步优化北墙的结构支护方式，建议考虑将柱子置于墙外侧，并结合对墙体的支扶加固。

（五）补充南侧影壁墙保护的具体设计，增强针对性。

（六）进一步优化、细化中部天井的屋顶部分的复原设计，统筹考虑室内空间改造与屋顶的关系，尽量考虑保留原有屋顶及墙体。同时，应细化玻璃天棚基础施工对老建筑的保护措施，确保文物的安全。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年2月14日
