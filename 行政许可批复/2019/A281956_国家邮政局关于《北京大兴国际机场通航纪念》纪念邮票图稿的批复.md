# 国家邮政局关于《北京大兴国际机场通航纪念》纪念邮票图稿的批复

国邮复〔2019〕171号

中国邮政集团公司：

你公司关于报审《北京大兴国际机场通航纪念》纪念邮票图稿的请示（中国邮政〔2019〕544号）收悉。根据国家邮政局审定的2019年纪特邮票发行计划，该纪念邮票1套1枚。邮票内容为：北京大兴国际机场通航纪念。发行日期为2019年9月26日。经审查，同意使用该图稿印制邮票。

此复。
