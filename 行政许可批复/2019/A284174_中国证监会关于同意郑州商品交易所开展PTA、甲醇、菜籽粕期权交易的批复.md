# 中国证监会关于同意郑州商品交易所开展PTA、甲醇、菜籽粕期权交易的批复

## 关于同意郑州商品交易所开展PTA、甲醇、菜籽粕期权交易的批复

郑州商品交易所：

你所报送的《关于PTA、甲醇、菜籽油及菜籽粕期权上市的请示》（郑商发〔2019〕70号）收悉。根据《期货交易管理条例》和《期货交易所管理办法》（证监会令第42号）有关规定，现批复如下：同意你所组织开展PTA、甲醇、菜籽粕期权交易，请做好各项监管工作，确保PTA、甲醇、菜籽粕期权平稳运行和健康发展。

中国证监会

2019年11月22日
