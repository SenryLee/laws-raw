# 国家文物局关于南堂修缮方案的批复

文物保函〔2019〕272号

北京市文物局：

你局《关于南堂修缮方案的请示》（京文物〔2019〕216号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）应按照《近现代历史建筑结构安全性评估导则》（WW/T0048-2014）的相关标准，补充完善对南堂的结构安全评估，不应完全套用《房屋结构综合安全性鉴定标准》（DB11/637-2015）。

（二）按照“最小干预”原则，调整完善屋面及木梁架修缮措施。屋面局部挑顶、查补、换瓦等不同措施的范围应明确标注，并应控制挑顶范围，降低瓦件更换量；木构件开裂加固不应统一套用铁箍加固的方式，应针对裂缝性质制定有针对性的加固措施，适当控制铁箍数量；不宜全部更换东、西倒座椽子。

（三）充分考虑顶部和底部承重结构交接的可行性、荷载增加的后续影响、地基基础承载力和承重方式、以及对空间、外观的影响等各种因素，补充结构验算和各节点大样详图，进一步论证墙体和室内砖柱采用外挂钢筋网喷锚加固的合理性和必要性。墙体和砖柱结构加固措施在实施前应开展相应实验。

（四）补充钟楼基础注浆的结构验算，细化完善加固方案，并在实施前开展相应实验。

（五）建议采用涂刷或灌浆方式处理轻微墙体裂缝，注意填缝材料选色及边缘处理。

（六）补充完善对南堂彩色玻璃图案、材料及工艺的研究，尽量保留原有彩色玻璃。建议由相关专业单位编制专项方案。

（七）补充细化院落、圣母山等的现状勘察、整治措施及图纸，应主要基于现状布局进行整治，不宜大规模改变其布局和外观。

（八）应基于后续功能需求，统筹考虑相关设计，如内装修、基础设施布线等。安防、消防和防雷设计方案应按照相关程序另行报批。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年3月20日
