# 国家文物局关于殷墟入口区及宫庙区环境整治方案的批复

文物保函〔2019〕811号

河南省文物局：

你局《关于报批殷墟遗址入口区及宫庙区环境整治工程方案的请示》（豫文物〔2019〕135号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需做以下必要的修改和完善：

（一）应进一步加强考古和研究工作，系统梳理殷墟已有考古资料，在工程涉及区域内开展全面的考古调查和发掘，明确文物分布和保存现状，并根据考古工作成果调整、完善方案设计。

（二）优化停车场选址，综合考虑地下文物分布情况和殷墟国家考古遗址公园游线设计，科学确定停车场数量、规模和选址，建议采用分散停车方式并控制停车场面积，考虑在入口区东部选址的可行性，不宜新建停车场专用道路。

（三）充分论证入口区设置大面积绿地、池苑区大量种植乔木的必要性、可行性和后续养护问题，科学确定植被种类、布局，尽量选用本地植物品种，保持历史氛围，避免城市现代园林设计倾向。不宜在遗址区内设置点状树阵。

（四）严格控制工程范围和施工强度，核减入口区及宫庙区内设施数量，优化围墙样式和选材，景观小品应突出殷墟文化特色。园区道路应根据考古成果和使用要求，进一步调整选线，优化工程做法，不宜直接套用城市公路建设标准。

（五）新建设备管线应避让文物遗存密集区和重要遗址，做好施工中的文物保护工作，专业考古人员应全程参与、监督，确保文物安全。

二、具体方案由你局指导有关单位按照上述意见和考古发掘成果修改、完善，并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年8月13日
