# 国家邮政局关于公布纪特邮票计划发行数量有关事宜的批复

国邮复〔2019〕225号

中国邮政集团公司：

你公司关于公布纪特邮票计划发行数量有关事项的请示（中国邮政〔2019〕715号）收悉。为满足广大消费者的需求，进一步营造公开透明的市场环境，推进政府信息公开工作，经研究，我局同意于每套纪特邮票发行日前向社会公开纪特邮票计划发行数量信息。我局将从2020年《庚子年》特种邮票开始，向社会公开已审定的纪特邮票计划发行数量，即每套邮票各图（含其他品种）的计划发行数量，公开后，原则上不予变更。

你公司可按照我局公开的计划发行数量自行安排公告，并做好相关工作。

国家邮政局

2019年12月17日
