# 国家文物局关于通州富育女校修缮项目设计方案的批复

文物保函〔2019〕439号

北京市文物局：

你局《关于通州近代学校建筑群富育女校修缮工程方案的请示》（京文物〔2019〕499号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善

（一）补充翠柏楼、映竹楼、图书馆楼屋面防水层修复处理材料及施工工艺说明。

（二）砌筑墙体裂缝处应采用高强、微膨胀水泥浆灌浆，并合理控制浆液的稀稠度及灌浆压力，及时清洗外流到墙面上的浆液。

（三）翠柏楼、映竹楼、图书馆楼建筑墙体及台帮陡板砖建议采用中低压水洗法去除后刷涂料，水洗效果不佳处可采用脱漆剂。百友楼西侧外墙亦建议采用中低压水洗法去除墙面污染。

（四）墙面采用钢筋网水泥砂浆面层加固时，应在纵横墙交接处和楼层处，增加配筋和抗震构造措施。混凝土构件露筋处，应除锈后，采用砂浆修补。

（五）建议外廊砖柱、砖柱与木梁间节点采用附加角钢或开槽嵌设钢板等方式进行加固措施，并注意外观协调。同时，进一步勘察考证外廊砖柱、砖柱与木梁间节点、梁架历史沿革、历次维修记录和老照片等，明确使用要求，在保证安全的前提下恢复原状。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年5月10日
