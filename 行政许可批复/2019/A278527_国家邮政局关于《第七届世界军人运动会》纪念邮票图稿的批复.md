# 国家邮政局关于《第七届世界军人运动会》纪念邮票图稿的批复

国邮复〔2019〕134号

中国邮政集团公司：

你公司关于报审《第七届世界军人运动会》纪念邮票图稿的请示（中国邮政〔2019〕348号）收悉。根据2019年纪特邮票发行计划，该纪念邮票1套4枚。邮票内容为：1.田径·标枪；2.军事五项·障碍跑；3.海军五项·航海技术；4.跳伞·四人造型。发行日期为2019年7月10日。经审查，同意使用修改后的图稿（见附件）印制邮票。

你公司应加强邮票图案设计工作，提前安排，精心组织，确保按有关规定时限报审邮票图案。

此复。

附件：“第七届世界军人运动会”纪念邮票图稿复印件

国家邮政局

2019年6月18日
