# 国家邮政局关于《“五四”运动一百周年》纪念邮票图稿的批复

国邮复〔2019〕67号

中国邮政集团公司：

你公司关于报审《“五四”运动一百周年》纪念邮票图稿的请示（中国邮政〔2019〕159号）收悉。根据我局审定的2019年纪特邮票发行计划，该纪念邮票一套2枚，邮票内容为：1.传承“五四”精神；2.奋进新时代。发行日期为2019年5月4日。经审查，同意使用该套图稿（图稿复印件见附件）印制邮票。

此复。

附件：“‘五四’运动一百周年”纪念邮票图稿复印件（略）

国家邮政局
