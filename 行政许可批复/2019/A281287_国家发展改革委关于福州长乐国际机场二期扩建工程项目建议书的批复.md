# 国家发展改革委关于福州长乐国际机场二期扩建工程项目建议书的批复

发改基础〔2019〕1389号

福建省发展改革委：

报来《关于上报福州长乐国际机场二期扩建工程项目建议书的请示》（闽发改交通〔2019〕325号）及有关材料均悉。经研究，现批复如下。

一、为完善区域综合交通运输体系，适应航空运输快速增长需求，提升机场综合保障能力和服务水平，促进地方经济社会发展，同意实施福州长乐国际机场二期扩建工程。

二、本期工程按照满足2030年旅客吞吐量3600万人次、货邮吞吐量45万吨的目标设计。飞行区等级指标4F.主要建设内容包括：

（一）机场工程。在现有跑道东侧1920米处新建1条长3600米、宽60米的第二跑道，双向设置Ⅰ类精密进近灯光系统，相应建设平行滑行道，在现航站区东侧新建25.5万平方米的T2航站楼，新建60个站坪机位、8个货机位，配套建设货运、机务维修、供电、供水、消防救援等工程。

（二）空管工程。建设第二塔台以及塔台裙楼1820平方米；建设管制中心9000平方米、动力能源用房1500平方米、职工食堂970平方米等，改造现航管楼及航管中心，配套建设管制、通信、导航、监视、气象等设施。

（三）供油工程。新建第二航空加油站以及机坪加油管线等设施。

三、项目总投资约212.5亿元。其中，机场工程投资约202亿元，由民航局、福州市人民政府、福建省投资开发集团有限责任公司、元翔（福州）国际航空港有限公司共同筹措解决；空管工程投资约8.9亿元，由民航局安排民航发展基金解决；供油工程投资约1.6亿元，由中国航空油料有限责任公司筹措解决。具体资金安排在项目可行性研究阶段确定。

四、下一步重点做好以下工作：

（一）加强与军民航有关部门沟通协调，尽快制定空域使用方案，满足本期工程扩建后机场空域使用需求。

（二）协调国家相关部门做好与有关方面沟通，进一步提升机场双跑道运行容量。

（三）深化航空业务量预测分析，进一步优化机场总平面布局，加强综合交通建设规划研究，提高机场运行效率和资源利用率。

（四）落实项目资金筹措方案，防范新增地方政府债务风险，为项目建设及运营提供必要的资金保障。

（五）做好机场与城市总体规划、土地利用规划的衔接，管控好机场净空、电磁环境和规划发展用地，确保机场安全运行和可持续发展。
