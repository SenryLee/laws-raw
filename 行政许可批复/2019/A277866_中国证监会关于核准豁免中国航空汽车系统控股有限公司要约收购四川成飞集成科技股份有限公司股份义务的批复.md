# 中国证监会关于核准豁免中国航空汽车系统控股有限公司要约收购四川成飞集成科技股份有限公司股份义务的批复

## 关于核准豁免中国航空汽车系统控股有限公司要约收购四川成飞集成科技股份有限公司股份义务的批复

证监许可〔2019〕927号

中国航空汽车系统控股有限公司：

你公司报送的《中国航空汽车系统控股有限公司关于豁免要约收购四川成飞集成科技股份有限公司之申请报告》及相关文件收悉。根据《公司法》《证券法》《上市公司收购管理办法》（证监会令第108号）等有关规定，经审核，现批复如下：

一、核准豁免你公司因协议安排而控制四川成飞集成科技股份有限公司190,719,663股股份，约占该公司总股本的53.17%而应履行的要约收购义务。

二、你公司应当按照有关规定及时履行信息披露义务。

三、你公司应当会同四川成飞集成科技股份有限公司按照有关规定办理相关手续。

四、你公司在实施过程中，如发生法律、法规要求披露的重大事项或遇重大问题，应当及时报告我会。

中国证监会

2019年5月22日
