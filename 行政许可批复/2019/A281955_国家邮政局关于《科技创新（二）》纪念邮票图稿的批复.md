# 国家邮政局关于《科技创新（二）》纪念邮票图稿的批复

国邮复〔2019〕172号

中国邮政集团公司：

你公司关于报审《科技创新（二）》纪念邮票图稿的请示（中国邮政〔2019〕560号）收悉。根据国家邮政局审定的2019年纪特邮票发行计划，该纪念邮票1套5枚。邮票内容为：1.嫦娥四号；2.体细胞克隆猴；3.量子反常霍尔效应的实验发现；4.阿尔茨海默病治疗新药GV-971;5.中国散裂中子源。发行日期为2019年11月1日。经审查，同意使用该图稿印制邮票。

此复。

国家邮政局

2019年9月11日
