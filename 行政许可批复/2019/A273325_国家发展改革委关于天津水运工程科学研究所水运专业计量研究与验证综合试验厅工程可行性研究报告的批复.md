# 国家发展改革委关于天津水运工程科学研究所水运专业计量研究与验证综合试验厅工程可行性研究报告的批复

发改投资〔2019〕23号

交通运输部：

报来《交通运输部关于报请审批天津水运工程科学研究所水运专业计量研究与验证综合试验厅工程可行性研究报告的函》（交规划函〔2018〕345号）等均悉。经研究，现批复如下：

一、为落实《计量发展规划（2013-2020年）》（国发〔2013〕10号）要求，提高国家水运工程检测设备计量站的计量研究与测试能力，完善水运行业工程检测仪器计量标准体系，提升水运工程建设质量，同意建设天津水运工程科学研究所水运专业计量研究与验证综合试验厅项目（2017-000052-73-01-001431）。

二、该项目位于天津水运工程科学研究所大型水动力试验基地用地范围内，总占地面积约10102.2平方米，主要建设内容为：水运专业计量研究与验证综合试验厅，建筑面积为4494.6平方米；主要计量检定设施包括多功能六面消声水池（30米长、12米宽、8.3米深）、水深与流速检定水槽（103米长、3米宽、3.5米深）、潮波检定水塔（直径为2米、高为11米）、计量测试及性能试验室等、购置计量检定与研究设备40套，建设道路、管网、绿化等配套的室外工程。

三、项目总投资7967万元，利用你部部门自身建设中央预算内投资统筹解决。

四、交通运输部天津水运工程科学研究所为项目法人，负责项目的组织实施与管理。

五、本项目勘察、设计、施工、监理和设备采购等全部采用公开招标方式，招标组织形式为委托招标。

六、下阶段请组织有关方面尽早开展地质勘查等工作，满足设计阶段基础资料要求。请尽快组织编制项目初步设计，并将概算报我委核定。

国家发展改革委

2019年1月4日
