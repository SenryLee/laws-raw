# 国家发展改革委关于大连海事大学智能研究与实训两用船建造项目建议书的批复

发改投资〔2019〕1151号

交通运输部：

你部《关于报请审批大连海事大学科研与实训两用智能船建造项目建议书的函》（交规划函〔2019〕52号）收悉。经研究，现批复如下。

一、为适应船舶技术发展对航海人才队伍教学与实训的要求，具有开展智能船舶设备与系统测试和验证的条件，同意建造1艘智能研究与实训两用船。

二、智能研究与实训两用船设计航区为无限航区，船舶主尺度约为69米×10.5米×4.8米（总长×型宽×型深），设计吃水3.5米；设计航速20节，续航力为2500海里左右，自持力为6天；动力装置采用全电力推进系统，配置3台1380千瓦柴油发电机组、1台应急发电机组和2台吊舱式推进器。

三、项目总投资10740万元，原则同意安排中央预算内投资解决。

请你部按以上原则，组织开展大连海事大学智能研究与实训两用船建造项目可行性研究报告的编制和审查工作，同时督促项目单位落实该项目的节能审查、社会稳定风险评估等前期工作。待以上工作完成后，将项目可行性研究报告报我委审批。

国家发展改革委

2019年7月1日
