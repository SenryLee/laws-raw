# 国家邮政局关于《中国植树节》纪念邮票图稿的批复

国邮复〔2019〕38号

中国邮政集团公司：

你公司关于报审《中国植树节》纪念邮票图稿的请示（中国邮政〔2019〕72号）收悉。根据我局审定的2019年纪特邮票发行计划，该纪念邮票一套1枚，邮票内容为：中国植树节。发行日期为2019年3月12日。经审查，同意使用该图稿印制邮票。

此复。

国家邮政局

2019年2月12日
