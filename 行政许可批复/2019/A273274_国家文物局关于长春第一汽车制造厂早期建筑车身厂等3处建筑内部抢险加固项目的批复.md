# 国家文物局关于长春第一汽车制造厂早期建筑车身厂等3处建筑内部抢险加固项目的批复

文物保函〔2019〕12号

吉林省文物局：

你局《关于长春第一汽车制造厂早期建筑车身厂等3处建筑内部抢险加固工程设计方案的请示》（吉文物发〔2018〕252号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步优化设计，贯彻最小干预原则，在进一步开展详细勘察的基础上，尽量减小工程干预范围，并增强拟采取干预措施的可逆性。同时，建议充分考虑先按原施工工艺对建筑进行必要加固补强，再增加必要抗震、加固构件的可能性。

（二）进一步优化发动机厂、底盘厂、总装厂结构加固方案，在确保加固效果的前提下，可适当减少拟增设抗震结构的系杆和支撑数量，避免影响空间整体性；补充增设抗震横墙等部分结构的相关依据，应尽量减少对原有建筑影响。进一步明确天窗架增设竖向支撑的必要性。屋面整体重铺应明确防水材料。

（三）进一步勘察车身厂的具体残损情况，明确加固范围，尽可能减少干预。宜进一步论证B-D/4-15首层楼盖大面积加固的必要性。

（四）进一步明确对生活间地面、粉刷层、吊顶等的拆除修复范围，应尽量保留原有生产痕迹，采用原有建筑材料修复。屋架、托架杆件等亦不宜采用加大截面做法。

（五）应采用物理方式处理车身厂、底盘厂、总装厂等建筑中的旧漆膜，不宜采用火喷法。

（六）修复砂浆厚度超过50mm时，应在分层抹灰时采用一定的加固措施。

（七）进一步规范、校核图纸文本。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年1月3日
