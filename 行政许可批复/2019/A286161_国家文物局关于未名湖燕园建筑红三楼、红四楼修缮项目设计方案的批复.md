# 国家文物局关于未名湖燕园建筑红三楼、红四楼修缮项目设计方案的批复

文物保函〔2019〕1274号

北京市文物局：

你局《关于再次申报未名湖燕园建筑红三楼、红四楼修缮工程设计方案的请示》（京文物〔2019〕1448号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改：

（一）深化现状勘查，进一步明确屋面构造、做法、材质以及残损范围和程度。应结合分析历次修缮工程和历史资料，考证建筑屋面原始做法，评估历次修缮对文物本体原状的扰动情况，明确本次修缮是否予以恢复。

（二）细化木构架加固措施。科学计算木构架设置铁箍及螺栓加固的位置及数量，细化木构件防火防腐的工艺做法。建议在新添配木屋架隐蔽部位明确更新年份。

（三）细化建筑周边排水措施，规范室内电路等管线铺设，明确红三楼封闭楼梯间隔墙重新砌筑的依据。

（四）细化油饰彩绘具体做法，严格控制重新油饰彩绘范围，注意新旧色彩的协调。

（五）平面图、立面图及剖面图应完整反映建筑特征、残损范围、残损状况和具体做法，细化标注内容，加强对施工的指导性。

二、方案由你局指导有关单位按照上述意见完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中应加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导；督促施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》进行验收。并请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年12月9日
