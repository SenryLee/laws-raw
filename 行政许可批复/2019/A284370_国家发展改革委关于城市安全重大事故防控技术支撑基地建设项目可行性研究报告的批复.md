# 国家发展改革委关于城市安全重大事故防控技术支撑基地建设项目可行性研究报告的批复

发改投资〔2019〕1836号

应急管理部、教育部：

报来《关于报送城市安全重大事故防控技术支撑基地建设项目可行性研究报告的函》（安监总规划函〔2018〕5号）、《关于报送城市安全重大事故防控技术支撑基地建设项目可行性研究报告（调整版）的函》（应急函〔2019〕220号）等均悉。经研究，现批复如下。

一、为贯彻落实《中共中央 国务院关于推进安全生产领域改革发展的意见》（中发〔2016〕32号），推进实施《安全生产“十三五”规划》（国办发〔2017〕3号）和《安全生产监管部门和煤矿安全监察机构监管监察能力建设规划（2016—2020年）》（安监总规划〔2017〕70号），提升城市重大安全生产事故防范与控制、事故调查与鉴定技术支撑能力，原则同意城市安全重大事故防控技术支撑基地建设项目（2017-000052-73-01-002545）可行性研究报告（调整版）。

二、依托清华大学建设国际一流的城市安全重大事故防控技术支撑基地，包括城市建构筑物垮塌试验分基地、城市交通事故试验分基地、城市地下管线管廊试验分基地、城市人员密集场所拥挤踩踏试验分基地等4个分基地，共包含结构垮塌事故模拟实验平台、土方工程事故模拟实验平台、热力耦合事故模拟实验平台、轨道交通事故模拟实验平台、道路交通事故模拟实验场、车辆事故模拟实验平台、地下管线事故模拟实验平台、地下管廊事故模拟实验平台、人群拥挤踩踏事故模拟实验平台、个体行为与心理实验平台等10个平台/实验场。项目共购置安装实验装备2366台（套），单独购买软件2套。

三、项目建设总投资95343万元，其中工程费用88851万元，工程建设其他费1952万元，预备费4540万元。由我委安排中央预算内投资解决。

四、请应急管理部会同教育部、清华大学，进一步加强技术攻关，强化技术经济和环保安全研究，优化项目建设方案，加快编制项目初步设计，由我委核定初步设计概算投资。

五、请各有关单位加强领导，密切配合、精心组织、规范管理，确保项目建设运行符合要求。按照《中央预算内直接投资项目管理办法》（国家发展改革委2014年第7号令）等有关规定，加强项目管理，严格控制投资。建设过程中要实行项目法人责任制、招标投标制、工程监理制和合同管理制，在招投标过程中要严格执行《中华人民共和国招标投标法》有关规定，确保建设工期和设备质量。项目建成后，要建立完善运行机制，为安全生产做好技术支撑服务。

附件：城市安全重大事故防控技术支撑基地建设项目招标核准意见表

国家发展改革委
