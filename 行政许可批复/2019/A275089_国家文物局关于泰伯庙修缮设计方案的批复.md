# 国家文物局关于泰伯庙修缮设计方案的批复

文物保函〔2019〕238号

江苏省文物局：

你局《关于审批无锡泰伯庙修缮设计方案的请示（泰伯庙和墓）》（苏文物保〔2019〕34号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）加强文物现状勘察，明确建筑形制、材料、工艺特征，细化残损程度和范围标注。

（二）遵循最小干预原则，严格控制修缮范围、力度和更换构件的数量。

（三）补充屋面基层材料及工艺做法。结合望砖、椽损坏分布，确定屋面揭顶维修的范围，完善屋面构件保护措施。

（四）铲除全部外墙涂料更换颜色重新粉刷、重新油饰全部门窗及木构架等措施干预过大，应慎重考虑其必要性。

（五）隐蔽部位保存状况较好的红机砖，应尽量保持现状，不必主动拆砌。补充拟恢复地面铺装做法的依据。

（六）进一步明确防虫防腐的范围，并提出针对性和可行性的技术要求。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年3月8日
