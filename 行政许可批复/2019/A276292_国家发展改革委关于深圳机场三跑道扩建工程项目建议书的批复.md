# 国家发展改革委关于深圳机场三跑道扩建工程项目建议书的批复

发改基础〔2019〕563号

深圳市发展改革委：

报来《关于呈报深圳机场三跑道扩建工程项目预可研报告的请示》（深发改﹝2018﹞1526号）及有关材料均悉。经研究，现批复如下。

一、为适应航空业务量快速增长需要，提升机场综合保障能力和服务水平，加快推进国际航空枢纽和珠三角地区世界级机场群建设，促进区域经济社会发展，同意实施深圳机场三跑道扩建工程。

二、本期工程按照满足2030年旅客吞吐量8000万人次、货邮吞吐量260万吨的目标进行设计。飞行区等级指标4F。主要建设内容包括：

（一）机场工程。在西跑道西侧550米处新建长3600米、宽60米的第三跑道及滑行道系统，主降方向设置Ⅲ类精密进近助航灯光系统，次降方向设置Ⅰ类精密进近助航灯光系统，配套建设供电、供水、消防救援等设施。

（二）空管工程。建设塔台裙房3500平方米、运行业务楼8500平方米、动力设备用房1500平方米，配套建设管制、通信、导航、监视、气象等设施。

三、项目总投资约93.5亿元。其中，机场工程投资约88.6亿元，由深圳市人民政府安排市本级财政公共预算解决；空管工程投资约4.9亿元，由民航局安排民航发展基金解决。具体资金安排在项目可行性研究阶段确定。

四、在后续阶段，要重点做好以下工作：

（一）加强与军民航有关部门沟通衔接，深入推进空域使用、航线划设、飞行程序方案等与军民航协调工作，以满足本期工程扩建后机场空域使用需求。

（二）深化航空业务量预测分析，进一步优化机场总平面布局及建设方案，提高机场运行效率和资源利用率。

（三）优化陆域形成及软基处理设计方案，控制工程投资。协调落实空管工程建设用地事宜，尽快明确供地方式。

（四）落实项目资金筹措方案，防范新增地方政府债务风险，为项目建设及运营提供必要的资金保障。

（五）做好机场与城市总体规划和土地利用规划的衔接，管控好机场净空、电磁环境和规划发展用地，确保机场安全运行和可持续发展。
