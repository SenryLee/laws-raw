# 国家发展改革委关于水运科学研究所天津海上溢油应急处置实验系统建设工程项目建议书的批复

发改投资〔2019〕154号

交通运输部：

你部《关于报请审批水运科学研究所天津海上溢油应急处置实验系统建设工程项目建议书的函》（交规划函〔2018〕701号）收悉。经研究，现批复如下。

一、为进一步提升我国海上溢油应急处置技术研究能力，提高海上溢油应急处置的快速、可靠、有效水平，促进溢油应急处置设备、材料的国产化，支撑我国建设海洋强国和交通强国的发展战略，更好地履行我国承担的国际义务。原则同意在中新天津生态城建设天津海上溢油应急处置实验系统建设工程。

二、项目建设内容为：综合实验水池、风化实验设施、岸滩溢油实验设施、控制楼、造波机房、实验楼、科研楼、设备库房、污水处理间、给水消防泵房、换热机房、油罐池、清洗池以及工艺设备等。占地46166平方米，总建筑面积8401平方米。

三、项目总投资31197万元，原则同意安排中央预算内投资解决。

四、请注重研究项目试验过程中的环境保护措施，并优化项目建设内容。

请你部按以上原则，组织开展天津海上溢油应急处置实验系统建设工程可行性研究报告的编制和审查工作。同时督促项目单位落实该项目的用地预审、规划选址、节能审查、社会稳定风险分析评估等前期工作。待以上工作完成后，将项目可行性研究报告报我委审批。

国家发展改革委

2019年1月23日
