# 国家文物局关于北京怀柔区箭扣长城东段（123号敌台—126号敌台及边墙）保护项目设计方案的批复

文物保函〔2019〕14号

北京市文物局：

你局《关于怀柔区箭扣长城东段修缮工程（123号敌台——126号敌台及边墙）设计方案的请示》（京文物〔2018〕1733号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）应进一步开展必要的考古工作，加强基础资料研究，明确本段长城的历史沿革、历年修缮情况，梳理敌台及边墙的建筑材料、工艺及技术，并细化病害调查，明确残损类型及成因，量化残损程度，为科学编制方案提供依据。

（二）应坚持最小干预原则，以现状加固为主，严格控制项目范围和强度，不宜大面积清理植被及腐质土。建议根据现状清理结果计算散落砖石量和归安工程量，明确灌浆的材料配比及施工工艺，试验并评估修缮措施的有效性，在此基础上调整完善保护方案。

（三）规范图文表达，细化图文标识。补充长城赋存山体地质情况调查评估、修缮材料检测报告等。

二、请你局指导有关单位按照《长城保护维修工作指导意见》《文物保护工程设计文件编制深度要求（试行）》和上述意见对方案进行修改完善，确保方案的科学性、规范性和可操作性。修改后的方案经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局督促地方人民政府认真落实主体责任，切实加强日常养护和游客管理工作，及时发现和排除隐患，确保文物安全。

六、请你局切实加强北京市长城保护修缮项目的宏观规划和指导，明确年度重点工作计划和实施安排，按照轻重缓急指导地方人民政府有序开展长城保护工作，确保工程质量。同时，请你局进一步明确怀柔区箭扣段长城保护修缮项目的实施分期，分段分期开展保护维修工作，并全程监管项目质量，及时发现并解决项目存在的各类问题，推动北京市长城保护修缮项目实施水平不断提升。

专此函复。

国家文物局

2019年1月3日
