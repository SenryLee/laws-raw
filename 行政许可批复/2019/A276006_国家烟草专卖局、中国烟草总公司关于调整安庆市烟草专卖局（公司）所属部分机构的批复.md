# 国家烟草专卖局、中国烟草总公司关于调整安庆市烟草专卖局（公司）所属部分机构的批复

## 国家烟草专卖局　中国烟草总公司关于调整安庆市烟草专卖局（公司）所属部分机构的批复

国烟人〔2019〕88号

安徽省烟草专卖局（公司）：

《安徽省烟草专卖局关于潜山县烟草专卖局更名的请示》（皖烟人〔2018〕354号）收悉。根据《民政部关于同意安徽省撤销潜山县设立县级潜山市的批复》（民函〔2018〕104号）及《烟草行业机构编制管理办法》（国烟人〔2015〕187号）精神，经研究，现批复如下：

一、撤销潜山县烟草专卖局，设立潜山市烟草专卖局。

二、将安庆市烟草公司潜山县营销部名称变更为安庆市烟草公司潜山市营销部。

三、潜山市烟草专卖局和安庆市烟草公司潜山市营销部合署办公，负责辖区内的烟草专卖管理和卷烟营销工作。

接此批复后，请你局（公司）按照有关规定及本批复办理相关事宜。

国家烟草专卖局　中国烟草总公司

2019年3月28日
