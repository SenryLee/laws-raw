# 国家文物局关于喜峰口西潘家口段长城保护维修设计方案的批复

文物保函〔2019〕139号

河北省文物局：

你局《关于呈报〈河北省喜峰口西潘家口段长城保护维修工程设计方案〉的请示》（冀文物字〔2018〕219号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需做以下必要的修改和完善：

（一）进一步开展前期考古和现场勘察工作，加强基础资料研究，明确本段长城的历史沿革、历年修缮情况和文物价值，充分评估敌台及城墙的结构稳定性，细化病害调查，明确敌台及城墙残损程度、病害类型和成因等。应根据需要补充长城赋存山体地质构造、岩性特征和稳定性等地质勘察内容。

（二）坚持最小干预原则开展现状加固，细化工程措施，核减城墙地面、垛墙、宇墙的补砌范围；说明具体工程做法，明确锚杆加固所需材料、工艺；建议砖墙修补时，新旧砌体间增加必要的拉接材料，注意归安砌体与原墙体的可识别性；深化墙体支撑钢架的结构和固定形式设计，墙体加固应考虑钢架支撑与填充加固措施相结合；未发现结构稳定性问题的部位宜保持现状。

（三）应充分研究长城塌落石块归安的可行性，不宜使用塌落石块制作石笼挡墙；补充有关木栈道对环境风貌的影响评估并根据评估结论补充、调整设计详图。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

六、请你局督促地方人民政府认真落实主体责任，结合项目实施同步开展长城两侧的专项整治工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年2月11日
