# 国家发展改革委关于大连海事大学海洋运输工程学科实验楼项目建议书的批复

发改投资〔2019〕708号

交通运输部：

你部《关于报请审批大连海事大学海洋运输工程学科实验楼项目建议书的函》（交规划函〔2018〕754号）收悉。经研究，现批复如下。

一、为整合大连海事大学现有学科教学和科研资源，加强船舶、航运、物流等学科群的协同发展，提高学校海洋运输工程学科教学和科研水平，支撑培养高素质海事人才。同意在大连海事大学西山校区，建设大连海事大学海洋运输工程学科实验楼。

二、项目建设内容为：实验楼用于建设智能船舶开发及运用、高效海运物流系统与运营管理、船舶污染防控与节能、船舶运输安全保障、海底工程等5个技术学科公共平台。项目总用地面积14123平米，总建筑面积29223平米，其中地下建筑面积6090平米，地上建筑面积23133平米。

三、项目总投资14180万元，其中工程费用为11524万元，工程建设其他费用1606万元，预备费1050万元，原则同意安排中央预算内投资解决。

请你部按以上原则，组织开展大连海事大学海洋运输工程学科实验楼项目可行性研究报告的编制和审查工作，同时督促项目单位落实该项目的用地预审、规划选址、节能审查、社会稳定风险分析评估等前期工作。待以上工作完成后，将项目可行性研究报告报我委审批。

国家发展改革委

2019年4月18日
