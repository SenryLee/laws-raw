# 国家文物局关于故宫延庆殿区建筑群油饰、彩画保护项目设计方案的批复

文物保函〔2019〕152号

北京市文物局：

你局《关于故宫延庆殿区古建筑群油饰、彩画保护工程设计方案的请示》（京文物〔2018〕1611号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）应遵循不改变文物原状和最小干预的原则，原状保护所有清代彩画，并最大限度保护清代油饰及包金墙做法。

（二）进一步加强对油饰彩画的前期勘察，核实勘察和分析结果。如采用多光谱成像等技术，结合颜料及胶结材料分析，辨识确定彩画原图案，为修缮设计提供依据。

（三）对拟保存的彩画进行加固、清理、显色处理应遵循可逆性和可再处理原则，尽量使用传统材料，不宜采用环氧类等热固性材料。

（四）对室内白樘篦子等进行重新裱糊时，应参考原裱糊纸张的鉴定检测结果。

（五）校核文字，规范图纸。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局
