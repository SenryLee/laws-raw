# 国家文物局关于太庙——世庙北院墙修缮工程方案的批复

文物保函〔2019〕1191号

北京市文物局：

你局《关于世庙北院墙修缮工程方案的请示》（京文物〔2019〕1051号）收悉。经研究，我局原则同意所报方案。

一、对方案提出以下修改意见：

（一）深化勘察墙体内部砌筑构造、基础埋深、墙体原有形制、做法等，有效处理墙体地坪降低后的组织排水。

（二）在保证墙体结构安全的前提下合理确定修缮措施，墙体不得全部拆除重砌。剔除墙体抹灰面后，应根据残损状况确定是否拆砌，对现状保存较好的墙体尽量采用加固方法保留，局部拆除的保存较好的旧砖应集中使用。

（三）补充墙身上部“甃瓦为墙”的工艺特色调查，说明甃瓦墙身的保存现状，并提出相应的保护措施。

（四）进一步完善规范设计图纸，补充文物残损病害评估图，建议按1：30绘制方案剖面图。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年11月15日
