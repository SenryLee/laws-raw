# 交通运输部关于境外游艇和帆船临时进出陵水清水湾游艇会码头和三亚半山半岛帆船港期限的批复

交海批〔2019〕38号

海南省口岸办公室：

《海南省口岸办公室关于请求批准陵水清水湾游艇会码头和三亚半山半岛帆船港临时开放的请示》（琼口岸〔2019〕11号）收悉。根据《国务院关于口岸开放的若干规定》，经征询国家检查检验机构和军委联参意见，同意境外游艇和帆船临时进出陵水清水湾游艇会码头和三亚半山半岛帆船港，期限自2020年1月16日至2020年7月15日。

你办应督促相关部门认真履职，确保临时进出陵水清水湾游艇会码头和三亚半山半岛帆船港的游艇和帆船严格遵守我国法律法规及有关规定要求，严格执行和落实军方的规定要求，做好在船人员的管理，遵守通航管理规定，落实安全责任。

交通运输部

2019年12月5日
