# 交通运输部关于外贸船舶临时进出宜宾港和泸州港部分码头泊位期限的批复

交海批〔2019〕39号

四川省人民政府口岸与物流办公室：

《四川省人民政府口岸与物流办公室关于恳请顺延外贸船舶临时进出宜宾港期限的请示》（川口物办〔2019〕4号）和《四川省人民政府口岸与物流办公室关于恳请顺延外贸船舶临时进出泸州港期限的请示》（川口物办〔2019〕5号）收悉。根据《国务院关于口岸开放的若干规定》和国家有关规定，经征询国家检查检验机构和军委联参意见，同意外贸船舶临时进出宜宾港志城作业区4#泊位和泸州港集装箱码头1#、2#、3#泊位，进出期限自批复之日至2020年6月11日。

你办应督促相关部门认真履职，确保临时进出宜宾、泸州港的外贸船舶严格遵守我国法律法规以及军方有关规定要求，提前报告船舶进出港动态，做好在船人员的管理，遵守通航管理规定，确保船舶安全。

请按照国家有关规定和要求，尽快完成口岸正式开放所需手续。

交通运输部

2019年12月9日
