# 国家邮政局关于《2019年中国北京世界园艺博览会》纪念邮票图稿的批复

国邮复〔2019〕70号

中国邮政集团公司：

你公司关于报审《2019年中国北京世界园艺博览会》纪念邮票图稿的请示（中国邮政〔2019〕162号）收悉。根据我局审定的2019年纪特邮票发行计划，该纪念邮票一套2枚，邮票内容为：1.绿色生活；2.美丽家园。发行日期为2019年4月29日。根据有关部门意见，同意将该套邮票名称由《2019北京世界园艺博览会》调整为《2019年中国北京世界园艺博览会》。经审查，同意使用该图稿印制邮票。

此复。

国家邮政局

2019年3月20日
