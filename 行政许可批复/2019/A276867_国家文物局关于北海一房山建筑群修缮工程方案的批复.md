# 国家文物局关于北海一房山建筑群修缮工程方案的批复

文物保函〔2019〕388号

北京市文物局：

你局《关于北海及团城——一房山建筑群修缮工程方案的请示》（京文物〔2019〕348号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）深化现状勘察评估，进一步核实屋面的残损比例，核实椽飞地仗做法；补充院落排水及出水口情况说明，补充游廊台基裂缝及踏步两侧风化情况勘察。

（二）坚持最小干预原则，严格控制工程量。根据价值评估和现状勘察结论，提出针对性的保护措施；明确地面排水方式、方向和坡度；补充青灰、油灰的材料配比和勾缝做法要求。

（三）核实耳房东西立面彩画的形制依据，补充新旧彩画协调的要求和做法。对于地仗较好的彩画，可进行过色见新；由于积尘导致的“褪色”情况应以除尘为主，不应补绘；补充清理油饰彩画除尘、加固的材料和工艺。

（四）补充分析楹联匾额的制作年代、材料和工艺，提出专项保护措施，不应将楹联匾额当做普通油饰处理。

（五）进一步核对、修改设计说明及图纸。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年4月25日
