# 中国证监会关于核准安信证券股份有限公司设立资产管理子公司的批复

## 关于核准安信证券股份有限公司设立资产管理子公司的批复

证监许可〔2019〕2630号

安信证券股份有限公司：

《安信证券股份有限公司关于设立资产管理子公司的申请报告》（安证报〔2018〕107号）及相关文件收悉。根据《证券法》、《公司法》、《证券公司监督管理条例》、《证券公司股权管理规定》（证监会令第156号）、《证券公司业务范围审批暂行规定》（证监会公告〔2008〕42号）、《证券公司设立子公司试行规定》（证监会公告〔2012〕27号）等有关规定，经审核，现批复如下：

一、核准你公司设立安信证券资产管理有限公司（以下简称安信资管）。安信资管注册地为深圳市，注册资本为10亿元，业务范围为证券资产管理，股东名称及出资额、出资比例如下：

|  |  |  |
| --- | --- | --- |
| 股东名称 | 出资额（亿元） | 出资比例 |
| 安信证券股份有限公司 | 10 | 100% |

上述出资中，你公司的出资为现金出资。

二、我会对安信资管章程草案无异议。安信资管设立后，应当将股东制定的公司章程报住所地证监局核准。

三、核准安信资管作为合格境内机构投资者，从事境外证券投资管理业务。安信资管应当严格按照《合格境内机构投资者境外证券投资管理试行办法》等有关规定，从事境外证券投资管理业务。

四、你公司应当按照《公司法》、《证券法》、《证券公司监督管理条例》等法律、法规和有关规定的要求，完成安信资管组建工作，足额缴付出资，选举董事、监事，聘任高级管理人员。

五、核准你公司变更业务范围，减少证券资产管理，不得作为合格境内机构投资者，从事境外证券投资管理业务。你公司应当认真落实相关业务了结计划安排和平稳处理现有客户相关事项的方案，做好相关业务清理和移交工作，平稳处理现有客户相关事项，确保客户合法权益不受损害，妥善安置员工，维护社会稳定。

六、你公司应当自本批复下发之日起6个月内完成工商变更登记和安信资管的工商设立登记工作，逾期未完成的，本批复自动失效。

你公司、安信资管应当自换领或取得营业执照之日起15日内，向我会申请换发或申请经营证券业务许可证。安信资管在取得经营证券期货业务许可证前，不得以该名称对外开展业务。

七、安信资管组建中如遇重大问题，须及时报告我会和深圳证监局。

中国证监会

2019年12月3日
