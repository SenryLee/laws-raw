# 中国证监会关于核准国海证券股份有限公司变更实际控制人的批复

## 关于核准国海证券股份有限公司变更实际控制人的批复

证监许可〔2019〕1244号

国海证券股份有限公司：

你公司报送的《国海证券股份有限公司关于实际控制人变更的申请报告》（国海报〔2018〕342号）及相关文件收悉。根据《证券法》《证券公司监督管理条例》等有关规定，经审核，现批复如下：

一、核准广西投资集团有限公司成为你公司实际控制人。

二、你公司在变更实际控制人过程中如遇重大问题，须及时报告我会和公司住所地证监局。

中国证监会

2019年7月8日
