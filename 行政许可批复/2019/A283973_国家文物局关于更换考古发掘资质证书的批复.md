# 国家文物局关于更换考古发掘资质证书的批复

文物保函〔2019〕1165号

江西省文化和旅游厅：

你厅《关于变更江西省文物考古研究院团体考古发掘资质证书有关信息的请示》（赣文旅文〔2019〕176号）收悉。

经研究，我局同意变更江西省文物考古研究院考古发掘资质证书法定代表人为柯中华，并更换《中华人民共和国考古发掘资质证书》，对相关机构信息进行变更。请通知有关单位携原资质证书正、副本来我局办理更换手续。

此复。

国家文物局

2019年11月11日
