# 国家文物局关于颐和园瞰碧台保护修缮项目的批复

文物保函〔2019〕124号

北京市文物局：

你局《关于颐和园瞰碧台古建筑保护修缮工程方案的请示》（京文物〔2018〕1863号）收悉。经研究，我局原则同意颐和园瞰碧台保护修缮项目。

一、所报方案尚需作以下必要的修改和完善：

（一）深化现状勘察，补充现状照片。进一步梳理完善历史沿革，核查油饰、吊顶的做法，核实补配瓦件的规格，详细评估火灾对各构件的影响情况，补充对排水系统的勘察评估。

（二）应对过火构件进行详细甄选，控制构件更换数量，在确保结构安全的基础上尽可能予以修复续用。

（三）根据后续利用功能确定立面门窗和内装修设计。如确需复原，应深入论证设计依据，并补充相应的大样图。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

四、施工中请你局加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

五、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

六、请你局切实加强管理，督促、指导相关单位引以为戒，严格落实文物消防安全责任，切实做好修缮后相关文物的日常养护和开放展示等工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年1月31日
