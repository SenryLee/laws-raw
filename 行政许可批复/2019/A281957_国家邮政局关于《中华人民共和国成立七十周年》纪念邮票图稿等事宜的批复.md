# 国家邮政局关于《中华人民共和国成立七十周年》纪念邮票图稿等事宜的批复

国邮复〔2019〕173号

中国邮政集团公司：

你公司关于报审《中华人民共和国成立七十周年》纪念邮票图稿的请示（中国邮政〔2019〕453号）等收悉。

经研究，同意将该套纪念邮票发行计划调整为一套5枚，小型张1枚。邮票内容分别为：1.经济持续健康发展；2.社会主义民主政治推进；3.文化繁荣兴盛；4.人民生活不断改善；5.建设美丽中国。小型张内容为：祝福祖国。发行日期为2019年10月1日。同意与香港邮政、澳门邮电共同印制同题材小型张本票1本。

经审查，同意使用修改后的图稿（见附件）印制邮票。

请据此抓紧开展相关工作。

此复。

附件：《中华人民共和国成立七十周年》纪念邮票图稿复印件（略）

国家邮政局

2019年9月17日
