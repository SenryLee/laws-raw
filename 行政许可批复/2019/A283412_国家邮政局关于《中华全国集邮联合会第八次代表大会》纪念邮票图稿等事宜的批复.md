# 国家邮政局关于《中华全国集邮联合会第八次代表大会》纪念邮票图稿等事宜的批复

国邮复〔2019〕194号

中国邮政集团公司：

你公司关于报审《中华全国集邮联合会第八次代表大会》纪念邮票图稿的请示（中国邮政〔2019〕637号）收悉。根据国家邮政局审定的2019年纪特邮票发行计划，该纪念邮票1套1枚（小型张），内容为：中华全国集邮联合会第八次代表大会。经审查，同意使用修改后的图稿印制邮票。

经研究，我局决定对原计划于2019年10月发行的《中华全国集邮联合会第八次代表大会》纪念邮票的发行日期予以调整，具体日期另行通知。

此复。

国家邮政局

2019年10月30日
