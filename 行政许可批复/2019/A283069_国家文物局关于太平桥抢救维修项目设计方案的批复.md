# 国家文物局关于太平桥抢救维修项目设计方案的批复

文物保函〔2019〕829号

江西省文化和旅游厅：

你厅《关于呈报太平桥抢救性维修工程设计方案的请示》（赣文旅文〔2019〕131号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步完善桥体结构稳定性勘察与评估。补充分水嘴、桥墩、翼墙、基础及背水面被洪水冲刷、掏蚀情况的调查；补充分析下游驳岸的坍塌原因。

（二）补充勘察夯填土的材料配比、构造层次和包边石砌筑浆料的配比。

（三）根据勘察评估结论进一步优化工程措施，尽可能保留续用原有石质构件。补夯部分应适当减少每层虚铺的厚度，增加夯填时包边块石的保护措施，并补充后填夯土与现存包边层加强结合的技术措施；进一步论证是否采用糯米浆及具体的构造层、工艺；桥体补配石材应明确材质、颜色等要求；细化面层砌筑工艺要求，避免整饬一新。

（四）补充桥面排水方式和坡度说明，桥端石坡道处应考虑汇集雨水的排放。

（五）从文物本体保护和环境协调的角度，补充上游增加保护驳岸的必要性说明。结合水文分析，审慎论证是否需要采取适当措施加大太平桥处的过水断面。

二、具体方案由你厅抓紧指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你厅督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你厅按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你厅切实加强管理，督促、指导相关单位做好太平桥的临时支护工作，并建立健全修缮后的日常养护机制，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局
