# 国家文物局关于吉林省博物院一级文物1938年杨靖宇使用过的饭桌修复计划的批复

文物博函〔2019〕928号

吉林省博物院：

你院《吉林省博物院关于修复一级文物的请示》（吉博文〔2019〕26号）收悉。经研究，我局批复如下：

同意所报1938年杨靖宇使用过的饭桌（登记号：A00131）一级文物修复计划。请你院按照技术标准要求，做好项目实施工作，并及时将修复档案、评估验收材料等报我局备案。

此复。

国家文物局

2019年9月5日
