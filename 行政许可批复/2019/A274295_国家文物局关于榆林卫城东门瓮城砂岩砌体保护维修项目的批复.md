# 国家文物局关于榆林卫城东门瓮城砂岩砌体保护维修项目的批复

文物保函〔2019〕92号

陕西省文物局：

你局《关于上报〈榆林卫城东门瓮城砂岩砌体抢救性保护方案〉的请示》（陕文物字〔2018〕202号）收悉。经研究，我局原则同意开展榆林卫城东门瓮城砂岩砌体抢救性保护项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应严格控制项目范围和施工强度，坚持最小干预原则，重点解决瓮城结构失稳问题，以物理加固措施为主，慎用化学措施。

（二）进一步评估瓮城的结构稳定性，细化病害调查，明确墙体结构性裂缝的类型和成因，量化残损程度。墙面酥碱不影响结构安全的部位，应以现状保护为主，不宜盲目人为干预。

（三）细化抢险加固措施，充分考虑瓮城与城墙连接处的防水问题，明确砌体替补的具体位置及数量；慎重论证砂岩砌体表面微生物病害治理措施，以局部治理为主，不宜大面积清洗或替补砌体；核减锚杆数量并校核锚杆加固措施对应的力学计算、垫板规格和强度。

（四）暂不同意表面防风化、大面积清洗砂岩砌体、底边锁水等措施，应进一步论证措施的安全性和有效性。补充掏补、替补施工的临时性支护方案。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局督促地方人民政府认真落实主体责任，结合项目实施同步开展瓮城城门两侧占压建筑的专项整治工作，切实加强文物日常管理和养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年1月23日
