# 国家文物局关于曹植墓隋碑亭保护修缮设计方案的批复

文物保函〔2019〕570号

山东省文物局：

你局《关于呈报曹植墓隋碑亭保护修缮方案的请示》（鲁文发〔2019〕27号）收悉。经研究，我局原则同意曹植墓隋碑亭保护修缮方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步深化现状勘察，确定病害位置、程度、成因、发展趋势等，充分评估墙体稳定性，明确建筑沉降、变形对碑刻安全的影响。

（二）进一步完善修缮措施，规范工程做法说明。屋面苫背、铺瓦应使用当地传统材料和工艺做法；量化酥碱墙砖的剔补工程量，墙面抹灰应采用靠骨灰做法，并明确钉麻揪的方式和使用材料；细化、调整室外排水与暗沟的联通方式，避免雨水倒灌。

（三）严格控制项目范围和强度，充分论证墙体灌浆加固的必要性，建议采用勾抹方式嵌实墙体裂缝和脱落灰缝；室内地面不宜做聚氨酯防水，可加铺一层衬砖，并满灌白灰浆。明确室外地坪降土标高，并根据文献资料确定室外地面石板铺墁范围和形式。补充施工中碑刻保护措施。

（四）规范图文表达，细化窗子、垂脊祥云花纹大样图；补充建筑散水及室外排水设计、碑亭周边树木的文物影响评估和相应处理措施。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时评估维修效果、发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年6月18日
