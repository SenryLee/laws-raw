# 交通运输部关于国际航行船舶临时进出福建省瀚海船业有限公司码头期限的批复

交海批〔2019〕5号

福建省口岸工作办公室：

《福建省人民政府口岸工作办公室关于请求延长国际航行船舶临时进出福建省瀚海船业有限公司码头期限的请示》（闽口岸〔2018〕59号）收悉。根据《国务院关于口岸开放的若干规定》，经征询并综合考虑国家检查检验机构和军委联参的意见，认为该码头相关设施设备尚不满足监管要求，故不同意你办提出的国际航行船舶临时进出福建省瀚海船业有限公司码头的申请。

此复。

交通运输部

2019年1月30日
