# 国家烟草专卖局、中国烟草总公司关于调整长治市烟草专卖局（公司）所属部分机构的批复

## 国家烟草专卖局　中国烟草总公司关于调整长治市烟草专卖局（公司）所属部分机构的批复

国烟人〔2019〕29号

山西省烟草专卖局（公司）：

《山西省烟草专卖局（公司）关于依照长治市新的行政区划调整所属部分县局（营销部）的请示》（晋烟人〔2019〕4号）收悉。根据《国务院关于同意山西省调整长治市部分行政区划的批复》（国函〔2018〕87号）及《烟草行业机构编制管理办法》（国烟人〔2015〕187号）精神，经研究，现批复如下：

一、撤销山西省长治市城区烟草专卖局、山西省烟草公司长治市公司城区营销部，撤销山西省长治市郊区烟草专卖局、山西省烟草公司长治市公司郊区营销部。合并设立长治市潞州区烟草专卖局、山西省烟草公司长治市公司潞州区营销部，长治市潞州区烟草专卖局和山西省烟草公司长治市公司潞州区营销部合署办公，负责辖区内的烟草专卖管理和卷烟营销工作。

二、撤销山西省长治县烟草专卖局、山西省烟草公司长治市公司长治县营销部。设立长治市上党区烟草专卖局、山西省烟草公司长治市公司上党区营销部，长治市上党区烟草专卖局和山西省烟草公司长治市公司上党区营销部合署办公，负责辖区内的烟草专卖管理和卷烟营销工作。

三、撤销山西省屯留县烟草专卖局、山西省烟草公司长治市公司屯留县营销部。设立长治市屯留区烟草专卖局、山西省烟草公司长治市公司屯留区营销部，长治市屯留区烟草专卖局和山西省烟草公司长治市公司屯留区营销部合署办公，负责辖区内的烟草专卖管理和卷烟营销工作。

四、撤销山西省潞城市烟草专卖局、山西省烟草公司长治市公司潞城市营销部。设立长治市潞城区烟草专卖局、山西省烟草公司长治市公司潞城区营销部，长治市潞城区烟草专卖局和山西省烟草公司长治市公司潞城区营销部合署办公，负责辖区内的烟草专卖管理和卷烟营销工作。

接此批复后，请你局（公司）按照有关规定及本批复办理相关事宜。

国家烟草专卖局　中国烟草总公司

2019年1月30日
