# 交通运输部关于外国籍游艇临时进出深圳七星湾游艇会期限的批复

交海批〔2019〕24号

深圳海事局：

《深圳海事局关于外国籍游艇临时进出七星湾游艇会有关事项的请示》（深海船舶〔2019〕93号）收悉。根据《国务院关于口岸开放的若干规定》的有关规定，经征询国家检查检验机构和军委联参意见，同意外国籍（包括中国香港籍）游艇临时进出深圳七星湾游艇会码头，进出期限自2019年10月22日至2019年11月5日。

你局应注意提请各口岸查验机构加强管理，确保外国籍（包括中国香港籍）游艇临时进出深圳七星湾游艇会码头期间，严格遵守国家法律法规和军方有关规定，满足临时性监管设施有关要求，严格管控活动范围，提前通报靠泊情况，做好在船人员的管理，遵守通航管理规定，确保安全。

交通运输部

2019年7月25日
