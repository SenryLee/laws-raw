# 国家文物局关于良渚遗址南城墙和老虎岭水坝保护项目设计方案的批复

文物保函〔2019〕1244号

浙江省文物局：

你局《关于全国重点文物保护单位良渚遗址之南城墙和老虎岭水坝保护工程设计方案的请示》（浙文物发〔2019〕217号）收悉。经研究，我局原则同意所报方案和你局意见。

一、所报方案尚需做以下必要的修改和完善：

（一）加强前期勘察，明确良渚古城南城墙遗址区域水文地质特点，分析台风、暴雨等极端天气对文物安全的影响，进一步论证地下水、温差、岩土性质等因素与文物病害的关系；深化城墙土质、建造工艺和使用过程研究，明确土壤可溶盐分类别，准确分析各元素含量，XRD测试应明确破坏城墙本体的矿物类型，补充0.074mm以下粒径分布数据。

（二）保护棚改造应增强针对性，重点解决现存设计缺陷，提高设施安全性和保护效果。

1．水沟平面布局应与保护棚滴水范围相对应，设计数据应考虑漫水问题，确保排水通畅。排水沟与保护棚勒角交界缝隙应做必要的密封处理，防止雨水渗入。

2．应考虑栈道遮盖范围的地表植物和微生物滋生问题，制定必要的防范措施。

3．进一步论证拟采用屋面铺装材料的消除冷凝水、隔热、避光等效果，合理确定使用材料、铺装方式。

4．明确保护棚改造施工流程，施工过程中的文物保护措施和施工技术要求，避免施工过程中引发文物安全问题。

5．补充保护棚现状图和设计图、保护棚周边区域文物分布图。

（三）优化本体保护措施，充分论证土体剖面加固的可行性，进一步明确材料配比、工艺流程、实施范围等，建议开展加固材料的环境适应性试验，根据试验结果调整相关措施，严格控制化学材料使用范围，避免过度干预；细化防渗结构层设计，必要时可通过修整出台梁、坑窝等咬合式接合面以防垫层滑动，做好新旧地表平滑顺接。

（四）严格控制项目范围和强度，尽量采用物理加固措施，裂缝注浆不宜采用锚杆加固。充分论证喷淋雾化补水系统的安全性、有效性和后期运营维护成本，明确喷淋后土壤表面湿度、内部含水率、渗透时间等具体技术指标，补充自动排水系统设备安装位置、排水管路由等内容，进行必要模拟实验，制定必要的应急预案和管理要求，不宜盲目安装使用。

（五）制定项目实施后的监测和跟踪评估措施，进一步加强日常监测和数据分析，及时研判遗址病害发展趋势和安全稳定性，必要时应考虑回填保护。

二、具体保护棚改造和文物本体保护方案由你局指导有关单位按照上述意见修改、完善，并经你局核准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局
