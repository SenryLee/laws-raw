# 国家文物局关于榆林卫城东城墙抢险加固项目的批复

文物保函〔2019〕102号

陕西省文物局：

你局《关于上报〈榆林卫城东墙体保护修缮展示工程设计方案〉的请示》（陕文物字〔2018〕201号）收悉。经研究，我局原则同意实施榆林卫城东城墙墙体抢险加固项目。

一、所报方案尚需作以下必要的修改和完善：

（一）方案过多强调恢复城墙的完整性，部分工程措施存在过度干预问题。进一步明确项目性质和施工强度，本次抢险加固项目应坚持最小干预原则，解决墙体垮塌和结构失稳问题，严格控制施工范围和干预程度，不得进行城墙复原展示。

（二）应开展前期考古和研究工作，明确城墙的建筑材料、工艺和技术，充分考虑城墙顶部排水和防渗需求；评估城墙的结构稳定性，细化病害调查，明确城墙残损程度、病害类型和成因，为科学编制方案提供依据。

（三）细化工程措施，明确城墙内侧夯土的材质要求、压实系数和土工格栅的设置需求等，妥善处理新旧夯土间的搭接问题；风化深度大于20mm的砖块不宜剔补，充分论证设置旋喷桩的必要性。

（四）应在方案B的基础上进一步深化内城台展示设计，不宜在夯土内部设置结构支撑。

（五）进一步深化图文表达，补充灌浆压力不小于30MPa的文物影响评估、东城墙内城台展示区域周边排水措施等内容。

二、请你局指导有关单位按照《长城保护维修工作指导意见》《文物保护工程设计文件编制深度要求（试行）》和上述意见对方案进行修改完善，经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局督促地方人民政府认真落实主体责任，结合项目实施开展城墙两侧现代建筑的专项整治工作，切实加强日常管理和养护，及时发现和排除隐患，确保文物安全。

六、应根据地方经济发展和居民生活需要，统筹考虑城内外道路系统建设，涉及敌台D6-D7间下穿式隧道建设项目，应按程序另行报批。

专此函复。

国家文物局

2019年1月25日
