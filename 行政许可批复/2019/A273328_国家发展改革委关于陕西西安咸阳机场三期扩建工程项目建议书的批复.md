# 国家发展改革委关于陕西西安咸阳机场三期扩建工程项目建议书的批复

发改基础〔2019〕52号

陕西省发展改革委：

报来《关于上报西安咸阳国际机场三期扩建工程预可行性研究报告的请示》（陕发改基础〔2018〕785号）及有关材料均悉。经研究，现批复如下：

一、为进一步促进区域经济社会协调发展，加快西安国际航空枢纽建设，提升机场综合保障能力和服务水平，适应航空业务量快速增长需要，同意实施西安咸阳机场三期扩建工程。

二、本期工程按2030年旅客吞吐量8300万人次、货邮吞吐量100万吨的目标设计。主要建设内容包括：

（一）机场工程。北飞行区等级指标4E，将现北跑道改造为平行滑行道，在其北侧新建长3800米、宽45米的北一跑道，双向设置Ⅰ类精密进近灯光系统；在北一跑道北侧新建长3800米、宽45米的北二跑道，主降方向设置Ⅲ类精密进近灯光系统，次降方向设置Ⅰ类精密进近灯光系统。南飞行区等级指标4F，在现南跑道南侧新建长3000米、宽60米的南二跑道，双向设置Ⅰ类精密进近灯光系统。新建70万平方米的东航站楼、115个机位的站坪、35万平方米的综合交通中心及停车楼，以及货运、航空食品、消防救援等辅助生产生活设施，配套建设供电、给排水、供热、制冷、供气等配套设施。

（二）空管工程。建设西北空管运行保障基地，包括终端管制大楼、气象大楼、动力能源中心等；对现有塔台进行局部改造，配套建设航管、监视、导航、气象、通信等设施。

（三）供油工程。新建机场油库和第三航空加油站，扩建机坪加油管线，更新长陵油库至机场油库输油管线等。

三、项目总投资471.4亿元，其中，机场工程443.2亿元，原则上由我委、民航局、陕西省人民政府、西安市人民政府、咸阳市人民政府、西咸新区管委会和西部机场集团共同筹措解决；空管工程18.7亿元，由民航局安排民航发展基金解决；供油工程9.5亿元，由中国航空油料有限责任公司筹措解决。具体资金安排在项目可行性研究阶段确定。

四、在后续阶段，要重点做好以下工作：

（一）积极与军方沟通协调，进一步优化空域规划方案，以满足本期工程扩建后机场空域使用需求。

（二）深化航空业务量预测，科学确定机场终端规模，优化机场总平面布局及建设方案，提高机场运行效率和资源利用率。

（三）完善机场集疏运系统规划，强化机场与铁路、城市轨道交通等方式的有机衔接，实现便捷高效换乘。确保集疏运系统与机场同步建成，充分发挥机场综合交通枢纽作用。

（四）进一步研究提供优惠政策，降低土地成本费用，妥善做好征地拆迁安置、噪声影响处理和社会稳定风险防范工作。

（五）研究落实项目资金筹措方案，拓宽融资渠道，优化投资结构，为项目建设及后续进场运营提供必要的资金保障。

（六）做好机场与城市总体规划和土地利用规划的衔接，管控好机场净空、电磁环境和规划发展用地，确保机场安全运行及可持续发展。
