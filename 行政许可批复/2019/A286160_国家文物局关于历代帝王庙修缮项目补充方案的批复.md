# 国家文物局关于历代帝王庙修缮项目补充方案的批复

文物保函〔2019〕1257号

北京市文物局：

你局《关于历代帝王庙修缮工程补充方案的请示》（京文物〔2019〕1339号）收悉。经研究，我局原则同意所报补充方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步明确屋面修缮变更工程量；补充揭落筒瓦和瓦筒瓦工序中对底瓦和灰背的保护措施，不得破坏底瓦和灰背。

（二）施工揭瓦应编号并小心揭除，按屋面方位编号码放，清理后原样上屋恢复，保存完好无脱灰松动的屋面瓦件应尽量减少干预。替换下来的残瓦件应统一编号，作为标本保存。

（三）准确核实西南碑亭角梁糟朽缺失的长度；检测需更换木料的材质，按原材质补配；补充糟朽角梁侧面照片，补绘角梁现状及补配加固详图。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年12月2日
