# 交通运输部关于长江下游江心洲至乌江河航道整治二期工程初步设计的批复

交水函〔2019〕869号

长江航务管理局：

《长航局关于呈报长江下游江心洲至乌江河段航道整治二期工程初步设计的请示》（长航规〔2019〕294号）及有关设计文件收悉。经委托中交第一航务工程勘察设计院有限公司技术咨询，并组织有关部门、单位和专家审查，该工程初步设计文件符合我部关于航道工程初步设计文件编制规定的内容和深度要求。根据审查意见，有关单位对初步设计文件进行了修改完善。现批复如下：

一、建设规模和内容

本工程位于长江干线江心洲至乌江河段，上起安徽东西梁山，下至江苏下三山，全长约56公里。建设I级航道，航道尺度为10.5米×200米×1050米（水深×航宽×弯曲半径），保证率98%。满足1万吨级内河散货船、1万吨级海船、特定航线2万吨级江海直达船和4×5000吨级顶推船队双向通航。

主要建设内容包括：加高上何家洲原有3道护底带，新建2道护底带守护江心洲心滩滩头，并对下何家洲高滩进行护岸守护；同时对小黄洲洲头过渡段进行疏浚，疏浚工程量248万方；配套建设航道整治建筑物示位标及其他有关设施。

二、总体设计

基本同意设计推荐的方案二。

（一）设计水位。

同意设计最低通航水位为0.95米（马鞍山水位站，1985国家高程基准，下同）。

（二）平面布置。

1.上何家洲护底带加高工程。

对上何家洲原有3道护底带进行棱体加高，加高高度按高程分段控制，1#护底带棱体顶高程-2.00～-3.00米，2#护底带棱体顶高程0.00～-6.50米，3#护底带棱体顶高程1.50～-11.00米；棱体长度分别为181米（含勾头）、254米、501米（含勾头），顶宽均为10米。对原有护底带进行加宽，两侧护底各加宽30米，头部护底加宽80米，加宽后长度分别为351米、424米、671米。

2.江心洲心滩滩头守护工程。

江心洲心滩滩头布置一纵一横2道护底带，1#（纵向）护底带长857米、宽150米，沿护底带轴线布置棱体长717米，其中头部273米范围棱体厚3～5米，根部171米范围棱体厚2.5米，中间平顺衔接；2#（横向）护底带长362米、宽140米，沿护底带轴线布置棱体长232米、厚3米。棱体顶宽均为10米。对心滩右缘岸坡崩窝进行处理。

3.下何家洲高滩守护工程。

对下何家洲洲头及右缘高滩进行护岸守护，守护长度1822米，两端各设置100米长过渡段。护岸后方实施生态固滩，面积12.46万平方米。

4.小黄洲洲头过渡段疏浚工程。

对小黄洲洲头过渡段航槽进行疏浚，长度为2784米，面积约0.58平方公里，疏浚底高程为设计最低通航水位以下10.5米。

三、水工建筑物工程

基本同意设计推荐的水工建筑物结构设计方案。

（一）上何家洲护底带加高工程。

护底带棱体采用拋石结构，棱体上游侧坡比为1：2、下游侧坡比为1:3，勾头部分上下游坡比均为1:3，棱体头部向河侧坡比为1:10。棱体堤心采用70～300千克块石，护面采用200～300千克块石，厚1米。护底带采用D型联锁软体排加宽原有护底，排上拋石厚1米，排边20米（排内排外各10米）拋石厚2米。

（二）江心洲心滩滩头守护工程。

护底带采用D型联锁软体排，排上拋石厚1米，排边20米（排内排外各10米）拋石厚2米。护底带棱体采用拋石结构。

1#（纵向）护底带棱体两侧坡比均为1:2.5，头部向河侧坡比为1:10；2#（横向）护底带棱体上游侧坡比为1:2、下游侧坡比为1:3，头部向河侧坡比为1:10。棱体堤心均采用70～300千克块石，护面均采用200～300千克块石，厚1米。护底带均采用D型联锁软体排，排上拋石厚1米，排边20米（排内排外各10米）拋石厚2米。崩窝处理采用抛石结构。

（三）下何家洲高滩守护工程。

采用斜坡式平顺护岸结构。主要包括陆上护坡、枯水平台和水下护底三部分。

陆上护坡：采用钢丝网格护面，下设反滤层，坡面设排水沟，坡顶设截流沟。对岸坡陡于1:3的部位按1:3进行削坡。

枯水平台：采用铺石结构，宽3米、厚1米。

水下护底：采用D型联锁软体排，排上抛石厚1米，排边20米拋石厚1.5米，下何家洲洲头部位护底宽度为180米，其他部位宽度为120米。对陡于1:3的部位抛填袋装砂进行补坡。

过渡段陆上护坡采用0.8米厚铺石，水下护底采用抛石，抛石厚度为1米。

生态固滩工程采用种植土回填后，利用土工格栅进行固土植草。

四、疏浚工程

基本同意设计推荐的疏浚工程设计方案。

疏浚底高程为设计最低通航水位以下10.5米，超深0.5米，超宽3米，疏浚区0+000～1+600设计边坡1:8，1+600～2+784设计边坡1:5。疏浚土抛至上何家洲护底带坝田区。

五、航标和配套工程

基本同意设计推荐的航标和配套工程设计方案。

新建岸标4座，改造浮标18座；配布航道整治建筑物助航标志3座，调整4座。

六、施工与通航

基本同意设计提出的施工与通航安全措施，下阶段进一步细化施工组织设计，实施中要加强现场管理，保障工程顺利实施和船舶航行安全。

七、安全环保节能等

基本同意安全、环保、节能等设计内容，下阶段根据防洪、环评批复意见适当优化工程方案，并组织好实施。

八、工程建设期

同意工程施工组织安排，核定本工程建设期为39个月（含试运行期12个月）。

九、工程概算

工程概算待国家发展和改革委员会核定后另行批复。

建设单位要加强与有关方面的沟通和协调，加强观测分析，对工程实施动态管理，确保工程建设效果和投资效益。
