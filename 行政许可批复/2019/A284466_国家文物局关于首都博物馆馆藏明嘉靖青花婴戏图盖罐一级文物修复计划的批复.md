# 国家文物局关于首都博物馆馆藏明嘉靖青花婴戏图盖罐一级文物修复计划的批复

文物博函〔2019〕1206号

首都博物馆：

你馆《首都博物馆关于修复馆藏文物明嘉靖青花婴戏图盖罐盖的请示》（首博发〔2019〕59号）收悉。经研究，我局批复如下：

同意所报馆藏明嘉靖青花婴戏图盖罐（总登记号：Y354）一级文物修复计划。请你馆按照技术标准要求，做好项目实施工作，并及时将修复档案、评估验收材料等报我局备案。

此复。

国家文物局

2019年11月18日
