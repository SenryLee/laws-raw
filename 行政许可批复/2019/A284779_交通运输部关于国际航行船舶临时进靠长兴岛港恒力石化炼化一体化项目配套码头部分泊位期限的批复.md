# 交通运输部关于国际航行船舶临时进靠长兴岛港恒力石化炼化一体化项目配套码头部分泊位期限的批复

交海批〔2019〕31号

大连市人民政府口岸办公室：

大连市人民政府口岸办公室《关于延长长兴岛港口岸恒力石化炼化一体化项目配套码头临时进靠国际航行船舶期限的请示》（大口岸发〔2019〕42号）收悉。根据《国务院关于口岸开放的若干规定》，经征询国家检查检验机构和军委联参意见，同意国际航行船舶临时进出长兴岛港恒力石化炼化一体化项目配套码头114号（30万吨级）原油泊位，112号（3万吨级）、113号（5万吨级）成品油泊位，期限延长至2020年4月10日。

你办应督促相关部门认真履职，确保临时进出长兴岛港恒力石化炼化一体化项目配套码头的国际航行船舶严格遵守国家法律法规以及军方有关规定要求，切实做好军事设施保护工作，严禁进入非开放水域，并按有关规定和军方要求提前报告船舶进出港动态，做好在船人员的管理，遵守通航管理规定，确保船舶安全。

请按照国家有关规定和要求，尽快完成口岸正式开放所需手续。

交通运输部

2019年9月25日
