# 国家文物局关于平武报恩寺大雄宝殿壁画及“三大士”彩塑墙保护修缮项目的批复

文物保函〔2019〕1229号

四川省文物局：

你局《关于报送四川平武报恩寺壁画彩塑墙保护修复设计方案的请示》（川文物〔2019〕45号）收悉。经研究，我局原则同意大雄宝殿壁画及“三大士”彩塑墙保护修缮项目。

一、对方案提出以下修改意见：

（一）深化病因分析，明确酥碱病害成因，分析空气湿度变化对活化墙体表面和内部盐分的机理。

（二）进一步加强实验的科学性。调整加固材料使用量，壁画表面加固后不得有眩光；进一步完善烟熏清理实验，合理选择清理备选材料；修补实验中修补材料应注意避免自重过高。

（三）不建议进行表面封护。防霉防虫应考虑大环境综合防治，不应使用防霉剂、药剂喷涂壁画。

（四）保护方案中使用的保护材料要注明成分和使用浓度。施工前应对彩塑采取一定的保护措施，补充彩塑墙彩塑加固归位支顶、锚固施工设计图。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、大雄宝殿壁画及“三大士”彩塑墙保护修缮工程完成后，由你局组织专家对工程质量和工程效果进行评估，在满足文物保护要求的基础上，再另行报批平武报恩寺其他壁画和彩塑墙保护工程方案。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

五、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工初步验收工作后，按程序报我局开展竣工验收。六、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局
