# 国家文物局关于西交民巷近代银行建筑群华资商业银行总办事处旧址保护项目方案的批复

文物保函〔2019〕121号

北京市文物局：

你局《关于西交民巷近代银行建筑群华资商业银行总办事处旧址修缮工程方案的请示》（京文物〔2018〕1313号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）应坚持最小干预原则，以现状整修加固为主。

（二）补充开展必要的建筑历史研究，明确历次维修工程所实施的工程内容，尤其是2013年外立面维修的基本情况，并进一步深化建筑外立面勘察，查明建筑立面原有材料、工艺及做法和残损程度，为工程设计提供依据。

（三）建筑外墙抹灰应在现状加固的基础上尽量予以保留。确实无法保留的，应按原有材料和原有工艺进行修复，不宜采用真石漆喷涂的方式。同时，外墙窗楣原抹灰线角亦不宜用预制石膏线替代。

（四）进一步细化工程做法、施工工艺及所用材料规格、型号、性能等，包括：明确喷抹仿石涂料面层、檐口仿石漆等工艺做法及具体材料要求；补充墙面、檐口等清洗剂的成分及详细清洗方案；补充墙面装饰线条“干粘石面层”剔补衔接的处理方式，重做水泥砂浆的水泥标号、抹墙的工艺做法、石粒的种类和规格等要求；补充SBS卷材抗衰老年限、耐寒度等指标要求；补充雨水管的壁厚要求及安装工艺。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年1月31日
