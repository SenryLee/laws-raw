# 国家文物局关于大运河——永通桥修缮项目设计方案的批复

文物保函〔2019〕364号

北京市文物局：

你局《关于大运河——永通桥修缮工程的请示》（京文物〔2018〕1954号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）深化现状勘察，细化说明各类残损的部位和程度，核实桥底板、河底装板等的残损情况。

（二）补充桥体结构安全检测，核实结构强度，分析明确桥身鼓闪病害成因，采取有针对性的保护措施。

（三）评估改变桥面做法对桥体结构的影响，补充细化清除桥面沥青和混凝土后对原有桥面石的保护措施。

（四）细化粘结、勾缝等做法说明，完善材料、工艺等相关技术要求，补充论证栏板与望柱间缝隙的处理措施。建议取消铁质围栏。

（五）进一步完善设计说明，补充相关照片和图纸。如，补充拟更换构件的现状照片；补充详细的各桥洞横剖面、桥面俯视平面、东立面等图纸。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护项目相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年4月18日
