# 国家文物局关于金陵兵工厂旧址宿舍楼（行保楼）保护修缮项目设计方案的批复

文物保函〔2019〕319号

江苏省文物局：

你局《关于审批金陵兵工厂旧址宿舍楼（行保楼）修缮设计方案的请示》（苏文物保〔2019〕35号）收悉。经研究，我局原则同意所报金陵兵工厂旧址宿舍楼（行保楼）保护修缮设计方案。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步深化现状勘察，查明建筑形制、结构、环境特征、保存现状、具体损伤和病害等具体情况，并补充相应的测绘图。

（二）建议将项目性质调整为修缮加固。进一步深化价值研究和建筑历史研究，明确行保楼的原建筑形制、工艺、做法，对历史上的不当维修进行甄别，并在此基础上补充优化修缮设计说明，增强修缮加固措施的针对性，尽可能恢复行保楼的原有建筑风貌。

（三）优化门窗、消防楼梯等改造设计，避免影响文物建筑原貌，建议增加喷淋消防设施确保文物安全。

（四）补充评估结构加固措施中采用植筋、压力注浆、碳布等措施对文物的影响，并根据评估结论对相应措施做适当优化，尽量保留完整的历史信息。

（五）进一步细化完善相关设计图纸，明确碳纤维加固、贴钢加固的具体位置，并进一步校核方案，规范引用表述和设计依据，统一图文表达。另，补充结构鉴定报告与修缮加固项目内容的一致性说明。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年4月1日
