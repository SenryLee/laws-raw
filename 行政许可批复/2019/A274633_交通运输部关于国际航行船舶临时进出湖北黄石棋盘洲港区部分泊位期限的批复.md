# 交通运输部关于国际航行船舶临时进出湖北黄石棋盘洲港区部分泊位期限的批复

交海批〔2019〕4号

长江航务管理局：

《长航局关于申请国际航行船舶临时进出湖北黄石棋盘洲港区部分泊位的请示》（长航运〔2018〕413号）收悉。根据《国务院关于口岸开放的若干规定》和国家有关规定，经征询国家检查检验机构和军委联参意见，同意国际航行船舶临时进出黄石棋盘洲港区8、9号泊位，进出期限自批准之日至2019年7月30日。上述码头泊位在临时开放期间不得经营煤炭进口业务。

你局应督促相关部门认真履职，确保临时进出黄石棋盘洲港区的国际航行船舶严格遵守国家法律法规以及军方有关规定要求，提前报告船舶进出港动态，做好在船人员管理，遵守通航管理规定，确保船舶安全。

请按照国家有关规定和要求，尽快完成口岸正式开放所需手续。

交通运输部

2019年2月11日
