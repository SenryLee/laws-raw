# 国家文物局关于妙应寺白塔西路修缮项目的批复

文物保函〔2019〕51号

北京市文物局：

你局《关于白塔寺（妙应寺白塔）西路修缮工程的请示》（京文物〔2018〕1900号）收悉。经研究，我局原则同意所报妙应寺白塔西路修缮项目。

一、所报方案尚需作以下必要的修改和完善：

（一）进一步细化白塔寺西路历史格局变迁的研究。

（二）应深化现状勘察，科学分析病害成因。细化对残损部位、范围、程度的勘察，补充量化数据；客观评估2010年维修的效果，为本次修缮提供参考。

（三）深化完善修缮做法，注意与现状勘察相对应，严格控制构件更换比例。补充粘接大木构件使用的环氧树脂的型号、材料、配比及相关要求；明确补配垂带、踏跺石的加工工艺要求；补充六间房木柱墩接的具体方式；细化一麻五灰、一麻三灰、三道灰等不同地仗的具体做法；进一步明确彩画除尘、下金檩镶补部分新做彩画的相应做法和要求，细化新旧彩画交接位置的处理要求。

（四）应规范完善设计文件，核查图纸完整性和序号、标题等。

（五）明确展示利用定位，并基于其功能需求统筹考虑相关设计，如内装修、基础设施布线等。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年1月14日
