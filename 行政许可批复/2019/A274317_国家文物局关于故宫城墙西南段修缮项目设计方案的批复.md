# 国家文物局关于故宫城墙西南段修缮项目设计方案的批复

文物保函〔2019〕134号

北京市文物局：

你局《关于故宫城墙（西南段）修缮工程设计方案的请示》（京文物〔2018〕1816号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需作以下必要的修改和完善：

（一）应进一步深化现状勘察记录，尽可能明确城墙各部位的历史修缮内容和时间，细化残损位置、程度和数量，补充残损照片位置说明。

（二）补充核实部分现状。补充勘察墙体两侧包砖砌体的基础做法及保存情况，核实包砖砌体基础是否独立设置；补充核实墙体内侧原散水做法；结合顶层病害图现场复核顶面残损情况，并明确顶层地面标高变化、排水方向与排水口。

（三）深入分析各类病害原因，完善墙体的结构安全稳定性评估。补充城砖、夯土强度检测数据；尽可能核实夯土空洞的范围、程度和原因；补充分析砖构件碎裂、墙体开裂等病害的原因；研究分析面层砖离鼓与墙体整体鼓胀间的关系，以及丁砖大面积拉断离鼓的具体原因；进一步明确易溶盐的成分与来源。

（四）应坚持“最小干预”原则，严格控制修缮范围和工程量。建议考虑在现有砖垫层上进行找平、防渗修复，以及进行局部灌浆充填等局部处理，尽可能避免揭至夯土层或扰动密实夯土；侧墙局部拆砌应尽可能减少对尚牢固的背里砌体的扰动，注意根据拆砌范围和所在上、中、下部位，采取多种加强新老砌体拉接的措施。

（五）应进一步深化修缮设计。修缮通则应与病害类型相对应；应注意甄别墙体鼓闪、裂缝的性质和原因，分类施策；进一步补充顶层地面干摆砌筑的依据，充分考虑热涨冷缩的影响；补充城墙侧面修复的原有形制和错缝铺设要求；明确顶面排水方向和坡度设计；补充说明底部散水修缮措施的依据。

（六）细化完善各项修缮措施。墙面修复涉及丁砖断裂部位的，宜采取不完全剔换丁砖做法，控制指标建议为上下间隔不大于两层砖、水平间隔不大于三块砖；局部剔补应与钉埋铁制锚杆拉接相结合，锚杆埋深应大于悬挑长度；结合现场实际情况完善暗拉接方式，确保实效；进一步明确挖补和拆砌的区别；细化墙面打点勾缝的具体要求；明确对每日砌筑高度的控制要求；替换、补配构件应进行标识。

（七）应选取局部开展样板段修缮，待现场论证确认后再行大范围实施。

（八）进一步校核文字，完善图纸，规范图例标识。现状照片、病害记录与修缮措施应前后对应；统一城墙地面、干摆海墁地面、顶层面砖等称谓；在城墙侧墙立面图中补充标示拆砌部位及范围，加强对施工的指导性；补充总平面图、总立面图，及堞墙、宇墙、地面、排水口的详图等。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和项目监管，及时开展项目检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保项目质量和文物、人员安全。

四、项目竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好项目竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2019年2月1日
