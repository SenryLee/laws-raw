# 国家发展改革委关于连云港军民合用机场民用部分迁建工程可行性研究报告的批复

发改基础〔2019〕21号

江苏省发展改革委：

你委《关于上报连云港民用机场迁建工程可行性研究报告的请示》（苏发改基础发〔2018〕1121号）及有关材料均悉。经研究，现批复如下。

一、为缓解军民航飞行矛盾，拓展民航发展空间，适应江苏北部地区航空运输发展的需要，促进区域经济社会和旅游业发展，同意迁建连云港军民合用机场民用部分。

二、建设内容及规模

本期工程按满足年旅客吞吐量250万人次、货邮吞吐量2.4万吨的目标设计，飞行区等级指标4D。主要建设内容为：

（一）机场工程

建设1条长2800米的跑道、1条长1900米的部分平行滑行道，跑道主、次降方向均设置I类精密进近系统；建设3万平方米的航站楼和16个机位的站坪；建设1座塔台和1500平方米的航管楼；配套建设空管、货运、供电、供水、消防救援等设施。

（二）徐连导航台工程

更新ATM、DDN、甚高频等设备，搬迁语音记录仪、KU卫星、UPS设备、柴油发电机等。

（三）供油工程

新建油库、汽车加油站等。

三、项目总投资为23.13亿元，其中：机场工程投资22.71亿元，民航局安排民航发展基金5.2亿元，江苏省人民政府安排财政资金5.2亿元，其余资金由连云港市人民政府安排财政资金解决；徐连导航台工程投资0.13亿元，由民航局安排民航发展基金解决；供油工程投资0.29亿元，由中国航空油料有限责任公司筹措解决。

四、连云港花果山机场建设投资有限公司、江苏空管分局和中国航空油料有限责任公司分别作为机场工程、徐连导航台工程和供油工程的项目法人，负责各自项目的组织实施与管理。

五、本项目勘察、设计、施工、监理和重要设备材料采购等均采用公开招标，招标组织形式为委托招标。

六、在后续阶段，重点做好以下工作。

（一）会同军民航有关方面，抓紧落实空域使用和飞行程序优化方案，提高空域资源使用效率。

（二）进一步优化地势设计和总平面布局，控制好机场净空、电磁环境和规划发展用地，确保机场建成后安全运营。

（三）机场建设应体现节能环保要求，优化用能工艺，选用高效节能设备，切实加强节能管理。

（四）落实机场联通长深等高速公路连接线的建设方案、投资主体和资金来源，确保与机场工程同步建成投产。

（五）切实落实各项风险防范化解措施，制定有效的应急处置预案，保障机场顺利实施。
