# 中国证监会关于核准中航基金管理有限公司变更股权的批复

## 关于核准中航基金管理有限公司变更股权的批复

证监许可〔2020〕895号

中航基金管理有限公司：

《关于中航基金管理有限公司变更百分之五以上股权的股东的申请报告》（中航基金字〔2019〕167号）及相关文件收悉。根据《证券投资基金法》《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

一、核准北京首钢基金有限公司认购你公司的新增注册资本。上述增资事项完成后，你公司股权结构为：

人民币　万元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额 | 出资比例 |
| 1 | 中航证券有限公司 | 16500 | 55% |
| 2 | 北京首钢基金有限公司 | 13500 | 45% |
|  | 合计 | 30,000 | 100% |

二、你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2020年5月11日
