# 中国证监会关于核准设立金圆统一证券有限公司的批复

## 关于核准设立金圆统一证券有限公司的批复

证监许可〔2020〕274号

厦门金圆投资集团有限公司，统一综合证券股份有限公司：

你们报送的《外资参股证券公司设立申请》及相关文件收悉。根据《证券法》《公司法》《证券公司监督管理条例》《外商投资证券公司管理办法》（证监会令第140号）《证券公司股权管理规定》（证监会令第156号）《证券公司业务范围审批暂行规定》（证监会公告〔2008〕42号）等有关规定，经审核，现批复如下：

一、核准设立金圆统一证券有限公司（以下简称金圆统一证券）。金圆统一证券注册地为福建省厦门市，注册资本为人民币12亿元，业务范围为证券经纪、证券自营、证券承销与保荐，股东名称及出资额、出资比例如下：

|  |  |  |  |
| --- | --- | --- | --- |
|  | **股东名称** | **出资额（亿元）** | **出资比例** |
| 1 | 厦门金圆投资集团有限公司 | 6.12 | 51% |
| 2 | 统一综合证券股份有限公司 | 5.88 | 49% |
|  | 合计 | 12 | 100% |

上述出资中，股东的出资均为货币出资，其中统一综合证券股份有限公司以等值可自由兑换货币出资。

二、核准厦门金圆投资集团有限公司、统一综合证券股份有限公司签署的合资合同，我会对金圆统一证券章程草案无异议。金圆统一证券设立后，应当将股东会表决通过的公司章程报住所地证监局核准。

三、你们应当按照《公司法》《证券法》《证券公司监督管理条例》《外商投资证券公司管理办法》（证监会令第140号）等法律、法规和有关规定的要求，完成金圆统一证券组建工作，足额缴付出资，选举董事、监事，聘任高级管理人员。

四、你们应当自本批复下发之日起6个月内完成金圆统一证券的工商设立登记工作。

金圆统一证券应当自取得营业执照之日起15日内，向我会申请经营证券期货业务许可证。金圆统一证券在取得经营证券期货业务许可证前，不得以该名称对外开展业务。

五、金圆统一证券组建中如遇重大问题，须及时报告我会和金圆统一证券拟设地证监局。

中国证监会

2020年2月17日
