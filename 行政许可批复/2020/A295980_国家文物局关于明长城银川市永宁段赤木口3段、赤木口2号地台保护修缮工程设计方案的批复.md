# 国家文物局关于明长城银川市永宁段赤木口3段、赤木口2号地台保护修缮工程设计方案的批复

文物保函〔2020〕1182号

宁夏回族自治区文物局：

你局《关于报审明长城银川市永宁段赤木口3段、赤木口2号敌台保护修缮工程勘察设计方案的请示》（宁文物发〔2020〕80号）收悉。经研究，我局原则同意所报方案。

一、所报方案尚需做以下必要的修改和完善：

（一）项目实施范围为赤木口3段（长城资源认定编码：152921382101170003）、赤木口2号敌台（长城资源认定编码：152921382101170002）。

（二）进一步加强前期勘察研究，明确墙体及敌台保存现状和病害程度，为制定保护措施提供科学依据：

1．应开展考古工作，进一步明确拟修缮墙体和敌台的分布范围、构造等；加强原有材料研究，分析建造工艺及技术特点。

2．开展墙体夯土成分检测，明确土样检测的质量标准，详细说明土样成分及比例。补充开展夯土土料及裂隙灌浆料等现场配比试验，科学确定夯土土料的最优含水量。

3．评估水文地质灾害、气候变化对墙体及敌台安全的影响，校核墙体及敌台存在“构造裂隙”的可能性。

（三）应根据病害情况分级分区优化技术措施：

1．应充分考虑裂隙产生原因和不同裂隙的特征，分类制定具体加固措施。建议重点加固影响墙体结构稳定性的裂缝，确保墙体安全。

2．论证使用SH渗透加固材料的必要性，分析其应用效果和存在问题。建议开展渗透加固材料的比选试验，确保渗透加固材料兼容、耐久。

3．细化墙体底部掏蚀区域的夯筑支顶施工方案；不得采用厚碎石垫层、上覆三七灰土、其上补夯墙体的做法；拉结竹筋应进行防腐处理。嵌补回填措施应确保在夯筑施工面较小的条件下，达到设计夯实系数。

4．补充说明坡脚处理措施，可通过适度找坡并植草，兼顾场地排水和坡脚加固需要。补充冲沟治理措施和场地排水设计。

（四）严格控制项目范围、规模和强度，重点解决墙体的结构稳定性问题。应按照《文物保护工程设计文件编制深度要求（试行）》要求，进一步完善现状勘察和施工设计图纸。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局
