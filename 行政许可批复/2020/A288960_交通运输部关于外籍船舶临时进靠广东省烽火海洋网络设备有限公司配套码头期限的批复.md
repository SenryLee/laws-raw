# 交通运输部关于外籍船舶临时进靠广东省烽火海洋网络设备有限公司配套码头期限的批复

交海批〔2020〕9号

广东省人民政府口岸办公室:

《广东省口岸办关于延续烽火海洋网络设备有限公司配套码头临时进靠外籍船舶装载作业期限的请示》（粤府口字〔2020〕9号）收悉，根据《国务院关于口岸开放的若干规定》，经征询国家检查检验机构和军委联参意见，同意外籍船舶临时进出广东省烽火海洋网络设备有限公司配套码头，期限自批复之日起至2020年9月23日。

你办应注意提醒各口岸查验管理相关机构加强管理，确保临时进出烽火海洋网络设备有限公司码头的外籍船舶严格遵守我国法律法规以及军方有关规定要求，提前报告船舶进出港动态，做好在船人员的管理，遵守通航管理和港口设施保安规定，确保船舶安全。

请按照国家有关规定和要求，尽快完成口岸正式开放所需手续。

交通运输部

2020年3月24日
