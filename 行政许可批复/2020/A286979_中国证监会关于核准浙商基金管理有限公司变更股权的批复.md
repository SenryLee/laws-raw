# 中国证监会关于核准浙商基金管理有限公司变更股权的批复

## 关于核准浙商基金管理有限公司变更股权的批复

证监许可〔2020〕192号

浙商基金管理有限公司：

《关于浙商基金管理有限公司变更股东的申请报告》（浙商基金〔2019〕571号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

一、核准浙江浙大网新集团有限公司、通联资本管理有限公司将所持你公司全部股权合计50%转让给民生人寿保险股份有限公司。转让完成后，你公司股权结构为：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额（万元） | 出资比例 |
| 1 | 浙商证券股份有限公司 | 7,500 | 25% |
| 2 | 养生堂有限公司 | 7,500 | 25% |
| 3 | 民生人寿保险股份有限公司 | 15,000 | 50% |
|  | 合计 | 30,000 | 100% |

二、你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2020年1月22日
