# 国家卫生健康委关于西安交通大学医学院第二附属医院疑难病症诊治能力提升工程（呼吸系统方向）初步设计和投资概算的批复

国卫规划函〔2020〕339号

西安交通大学医学院第二附属医院：

你院《关于报请审批疑难病症诊治能力提升工程（呼吸系统方向）初步设计和投资概算的请示》（西交二院〔2020〕52号）收悉。经研究，批复如下：

原则同意你院疑难病症诊治能力提升工程（呼吸系统方向）初步设计和投资概算。工程主要建设内容为：购置呼吸系统疾病诊疗及科研相关设备、开展信息化建设、部分业务用房改造。概算总投资19,619万元，资金来源为安排中央预算内投资和医院筹措资金共同解决。

请你院按照国家有关规定，严格执行基本建设程序和政府采购管理制度，落实项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计和投资概算，抓紧组织开展下一步工作。按照《中央预算内直接投资项目概算管理暂行办法》（发改投资〔2015〕482号）和《国家卫生健康委员会属（管）单位基本建设管理办法》（国卫规划发〔2018〕7号）规定，加强全过程监督和概算管理，确保不突破批复的总投资概算。

此复。

国家卫生健康委

2020年8月20日
