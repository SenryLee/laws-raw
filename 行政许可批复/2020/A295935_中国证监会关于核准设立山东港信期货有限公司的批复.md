# 中国证监会关于核准设立山东港信期货有限公司的批复

## 关于核准设立山东港信期货有限公司的批复

证监许可〔2020〕3267号

青岛港（集团）有限公司，青岛国信金融控股有限公司，青岛上合发展集团有限公司：

你们报送的《关于设立山东港信期货有限公司的申请》（青港财字〔2020〕171号）及相关文件收悉。根据《公司法》《期货交易管理条例》《期货公司监督管理办法》（证监会令第155号）等有关规定，经审核，现批复如下：

一、核准设立山东港信期货有限公司（以下简称港信期货）。港信期货注册地为山东省青岛市，注册资本为人民币10亿元，业务范围为商品期货经纪。港信期货股东名称及出资额、出资比例如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额  （人民币 亿元） | 出资比例 |
| 1 | 青岛港（集团）有限公司 | 6 | 60% |
| 2 | 青岛国信金融控股有限公司 | 3.6 | 36% |
| 3 | 青岛上合发展集团有限公司 | 0.4 | 4% |
| 合计 | | 10 | 100% |

上述出资中，股东的出资均为货币出资。

二、我会对港信期货公司章程草案无异议。港信期货设立后，应当将经股东会通过的公司章程报住所地证监局备案。

三、你们应当按照《公司法》《期货交易管理条例》《期货公司监督管理办法》等法律、法规和有关规定的要求，自批复之日起6个月内完成港信期货设立工作；逾期未完成的，本批复自动失效。

四、港信期货向我会申请并取得经营证券期货业务许可证前，不得对外开展业务。港信期货应在取得经营证券期货业务许可证后3个月内开始营业。

五、港信期货设立中如遇重大问题，须及时报告港信期货拟设地证监局。

中国证监会

2020年12月2日
