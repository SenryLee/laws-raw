# 中国证监会关于核准设立甬兴证券有限公司及其子公司、分公司的批复

## 关于核准设立甬兴证券有限公司及其子公司、分公司的批复

证监许可〔2020〕193号

宁波开发投资集团有限公司：

你公司报送的《关于甬兴证券有限公司等机构的设立申请》（甬投〔2019〕76号）及相关文件收悉。根据《证券法》、《公司法》、《证券公司监督管理条例》、《证券公司股权管理规定》（证监会令第156号）、《证券公司业务范围审批暂行规定》（证监会公告〔2008〕42号）、《证券公司设立子公司试行规定》（证监会公告〔2012〕27号）、《证券公司分支机构监管规定》（证监会公告〔2013〕17号）等有关规定，经审核，现批复如下：

一、核准设立甬兴证券有限公司（以下简称甬兴证券）。甬兴证券注册地为宁波市，注册资本为人民币20亿元，业务范围为证券经纪、证券投资咨询、证券自营、证券承销与保荐、证券投资基金销售，股东名称及出资额、出资比例如下：

|  |  |  |
| --- | --- | --- |
| **股东名称** | **出资额（亿元）** | **出资比例** |
| 宁波开发投资集团有限公司 | 20 | 100% |

上述出资中，你公司的出资为货币出资。

二、核准设立上海甬兴证券资产管理有限公司（以下简称甬兴资管）。甬兴资管注册地为上海市，注册资本为人民币2亿元，业务范围为证券资产管理，股东名称及出资额、出资比例如下：

|  |  |  |
| --- | --- | --- |
| **股东名称** | **出资额（亿元）** | **出资比例** |
| 甬兴证券有限公司 | 2 | 100% |

上述出资中，甬兴证券的出资为货币出资。

三、核准甬兴证券在上海市设立1家分公司（以下简称上海分公司），业务范围为证券经纪、证券承销与保荐（限承揽）、证券投资基金销售。

四、我会对甬兴证券、甬兴资管公司章程草案无异议。甬兴证券、甬兴资管设立后，应当将股东制定的公司章程报住所地证监局核准。

五、你公司应当按照《公司法》、《证券法》、《证券公司监督管理条例》等法律、法规和有关规定的要求，完成甬兴证券、甬兴资管组建工作，足额缴付出资，选举董事、监事，聘任高级管理人员。

六、你们应当自本批复下发之日起6个月内完成甬兴证券、甬兴资管及上海分公司的工商设立登记工作；逾期未完成的，本批复自动失效。

七、甬兴证券、甬兴资管应当自取得营业执照之日起15日内，向我会申请经营证券期货业务许可证。甬兴证券、甬兴资管在取得经营证券期货业务许可证前，不得以该名称对外开展业务。

八、甬兴证券应当自上海分公司取得营业执照之日起15日内，向相关证监局申请颁发经营证券期货业务许可证。

九、甬兴证券及甬兴资管、上海分公司组建中如遇重大问题，须及时报告我会和相关证监局。

中国证监会

2020年1月22日
