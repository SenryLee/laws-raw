# 中国证监会关于核准东方基金管理有限责任公司变更股权的批复

## 关于核准东方基金管理有限责任公司变更股权的批复

证监许可〔2020〕562号

东方基金管理有限责任公司：

《关于股权转让及增加注册资本的申请报告》（东方〔2019〕186号）及相关文件收悉。根据《证券投资基金法》《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

一、核准河北省国有资产控股运营有限公司将其持有的你公司27%股权转让给河北国控资本管理有限公司。核准天津汇智长行企业管理咨询中心（有限合伙）、天津汇远长行企业管理咨询中心（有限合伙）、天津汇聚长行企业管理咨询中心（有限合伙）认购你公司的新增注册资本。上述股权转让事项完成后，你公司股权结构为：

人民币　万元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额 | 出资比例 |
| 1 | 东北证券股份有限公司 | 19200 | 57.6% |
| 2 | 河北国控资本管理有限公司 | 8100 | 24.3% |
| 3 | 渤海国际信托股份有限公司 | 2700 | 8.1% |
| 4 | 天津汇智长行企业管理咨询中心（有限合伙） | 1170 | 3.51% |
| 5 | 天津汇远长行企业管理咨询中心（有限合伙） | 1123 | 3.37% |
| 6 | 天津汇聚长行企业管理咨询中心（有限合伙） | 1040 | 3.12% |
|  | 合计 | 33333 | 100% |

二、你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会
