# 中国证券监督管理委员会关于核准泰信基金管理有限公司变更注册资本的批复

## 中国证券监督管理委员会关于核准泰信基金管理有限公司变更注册资本的批复（证监许可[2008]564号）

泰信基金管理有限公司：

你公司报送的《泰信基金管理有限公司关于增加注册资本并修改公司章程的申请报告》及相关文件收悉。根据《公司法》、《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由10000万元变更为20000万元人民币，山东省国际信托有限公司增加出资4500万元人民币，江苏省投资管理有限公司增加出资3000万元人民币，青岛国信实业有限公司增加出资2500万元人民币。

你公司变更注册资本后股权结构为：

```
股东名称　　　　　　　　　　　　　出资额　　　　　出资比例

（一）山东省国际信托有限公司　　　9000万元　　　　45％

（二）江苏省投资管理有限公司　　　6000万元　　　　30％

（三）青岛国信实业有限公司　　　　5000万元

25％
```

**二、**核准你公司对公司章程所作的修改。

你公司应按规定及时办理变更注册资本和公司章程等相关事宜，并持验资报告到我会更换基金管理公司基金管理资格证书。

二○○八年四月十六日
