# 中国证券监督管理委员会关于核准融通基金管理有限公司变更股权及章程修改的批复

## 中国证券监督管理委员会关于核准融通基金管理有限公司变更股权及章程修改的批复（证监许可【2008】1200号）

融通基金管理有限公司：

你公司报送的《关于融通基金管理有限公司股东变更事项的申请报告》及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准新时代证券有限责任公司受让河北证券有限责任公司所持有你公司40%的股权。本次股权转让完成后，你公司股权结构为：

```
股东名称　　　　　　　　　出资额　　　　　出资比例

新时代证券有限责任公司　　　　　7500万元　　　60%

日兴资产管理有限公司　　　　　　5000万元

40%
```

**二、**核准你公司对公司章程所作的修改。

**三、**你公司应当根据本批复到有关工商行政管理机关申请变更登记。

你公司及各股东应当及时办理股权转让相关事宜，完善公司治理结构，公司股东会、董事会、监事会和高级管理人员应当严格按照公司章程和有关规定履行职权、承担责任，维护公司及基金份额持有人的合法权益。

中国证券监督管理委员会

二○○八年十月十四日
