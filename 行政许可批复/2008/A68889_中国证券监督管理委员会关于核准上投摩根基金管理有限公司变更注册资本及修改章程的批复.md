# 中国证券监督管理委员会关于核准上投摩根基金管理有限公司变更注册资本及修改章程的批复

## 中国证券监督管理委员会关于核准上投摩根基金管理有限公司变更注册资本及修改章程的批复（证监许可【2008】1331号）

上投摩根基金管理有限公司：

你公司报送的《上投摩根基金管理有限公司关于股东利润转增资本的请示》（上投摩根字[2008]131号）及相关文件收悉。根据《公司法》、《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将利润转增为注册资本，注册资本由1.5亿元增加至2.5亿元。

你公司增加注册资本后，股东出资额及出资比例为：

```
股东名称　　　　　　　　出资额（人民币）　　出资比例

（一）上海国际信托有限公司　12750万元　　　51％

（二）摩根富林明资产管理　　12250万元　　　49％

（英国）有限公司
```

**二、**核准你公司对公司章程所作的相应修改。

你公司应及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证券监督管理委员会

二○○八年十二月三日
