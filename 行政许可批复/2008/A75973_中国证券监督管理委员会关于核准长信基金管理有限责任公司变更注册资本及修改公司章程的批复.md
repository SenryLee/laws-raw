# 中国证券监督管理委员会关于核准长信基金管理有限责任公司变更注册资本及修改公司章程的批复

## 中国证券监督管理委员会关于核准长信基金管理有限责任公司变更注册资本及修改公司章程的批复（证监许可[2008]567号）

长信基金管理有限责任公司：

你公司报送的《长信基金管理有限责任公司关于变更注册资本行政许可事项的申请》（长信字[2008]021号）、《长信基金管理有限责任公司关于公司章程修订行政许可事项的请示》（长信字[2006]222号）及相关文件收悉。根据《公司法》、《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由10000万元变更为15000万元人民币，长江证券股份有限公司增加出资2450万元人民币，上海海欣集团股份有限公司增加出资1716.5万元人民币，武汉钢铁股份有限公司增加出资833.5万元。

你公司变更注册资本后股权结构为：

```
股东名称　　　　　　　　　　　　　出资额　　出资比例

（一）长江证券股份有限公司　　　　7350万元　　　　49％

（二）上海海欣集团股份有限公司　　5149.5万元　　　34.33％

（三）武汉钢铁股份有限公司　　　　2500.5万元　　　16.

67％
```

**二、**核准你公司对公司章程所作的修改。

你公司应按规定及时办理变更注册资本和公司章程等相关事宜，并持验资报告到我会更换基金管理公司基金管理资格证书。

二○○八年四月十七日
