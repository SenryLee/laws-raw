# 中国证券监督管理委员会关于核准信诚基金管理有限公司变更注册资本及修改章程的批复

## 中国证券监督管理委员会关于核准信诚基金管理有限公司变更注册资本及修改章程的批复（证监许可【2008】1225号）

信诚基金管理有限公司：

你公司报送的《信诚基金关于增加注册资本和修改公司章程的申请报告》（信诚司发[2008]099号）及相关文件收悉。根据《公司法》、《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由1亿元增加到2亿元，中信信托有限责任公司（原中信信托投资有限责任公司）增加出资4900万元，英国保诚集团股份有限公司增加出资相当于4900万元人民币的外汇现金，中新苏州工业园区创业投资有限公司增加出资200万元。

你公司增加注册资本后，股东出资额及出资比例为：

```
股东名称　　　　　　出资额　　　　　出资比例

（一）中信信托有限责任公司　　9800万元　　　49％

（二）英国保诚集团股份有限公司9800万元人民币49％

等值的外汇现金

（三）中新苏州工业园区创业投资有限公司 400万元

2％
```

**二、**核准你公司对公司章程所作的修改。

你公司及各股东应及时办理工商变更登记、基金管理资格证书变更等相关事宜。

中国证券监督管理委员会

二○○八年十月二十二日
