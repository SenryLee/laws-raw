# 中国证券监督管理委员会关于核准益民基金管理有限公司变更股权及修改章程的批复

## 中国证券监督管理委员会关于核准益民基金管理有限公司变更股权及修改章程的批复（证监许可【2008】1235号）

益民基金管理有限公司：

你公司报送的《关于核准益民基金管理有限公司股权转让的申请报告》（益民字[2008]46号）及相关文件收悉。根据《公司法》、《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准中山证券有限责任公司受让华夏建通科技开发股份有限公司所持你公司20%（2000万元）股权。

上述股权转让完成后，你公司股东出资额及出资比例为：

```
股东名称　　　　　　出资额　　　　　出资比例

（一）重庆国际信托有限公司　　　　3000万元　　　　　30％

（原重庆国际信托投资有限公司）

（二）重庆路桥股份有限公司　　　　2500万元　　　　　25％

（三）中国新纪元有限公司　　　　　2500万元　　　　　25％

（四）中山证券有限责任公司　　　　2000万元　　　　　20％
```

**二、**核准你公司对公司章程所作的修改。

你公司及相关股东应及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证券监督管理委员会

二○○八年十月二十八日
