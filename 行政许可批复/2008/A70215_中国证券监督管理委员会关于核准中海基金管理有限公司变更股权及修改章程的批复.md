# 中国证券监督管理委员会关于核准中海基金管理有限公司变更股权及修改章程的批复

## 中国证券监督管理委员会关于核准中海基金管理有限公司变更股权及修改章程的批复（证监许可[2008]1220号）

中海基金管理有限公司：

你公司报送的《中海基金管理有限公司关于股权转让及章程修改等重大变更事项的申请》（中海基[2008]121号）及相关文件收悉。根据《公司法》、《证券投资基金法》和《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**　 核准法国爱德蒙得洛希尔银行股份有限公司（LA COMPAGNIEFINANCIEREEDMOND DE ROTHSCHILD BANQUE）受让云南烟草兴云投资股份有限公司持有的你公司15.385％股权。

上述股权转让完成后，你公司股东出资额及出资比例为：

```
股东名称　　　　　　出资额　出资比例

（一）中海信托股份有限公司　6100万元　46.923％

（原名中海信托有限责任公司）

（二）国联证券股份有限公司　4900万元　37.692％

（原名国联证券有限责任公司）

（三）法国爱德蒙得洛希尔银行2000万元　　　　15.385％

股份有限公司
```

**二、**核准你公司对公司章程所作的修改。

你公司及各股东应及时办理变更股权相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证券监督管理委员会

二○○八年十月二十一日
