# 国家文物局关于北京市第一0一中学翻建操场看台设计方案的批复

## 国家文物局关于北京市第一0一中学翻建操场看台设计方案的批复（文物保函〔2008〕523号）

北京市文物局：

你局《关于北京市第一〇一中学翻建操场看台设计方案的请示》（京文物〔2008〕411号）收悉。经研究，我局批复如下：

**一、**原则同意你局关于北京第一〇一中学翻建操场看台设计方案的意见。请你局组织专业单位对该工程拟建区域进行考古调查、勘探，如需进行考古发掘，请按程序申请。请你局加强管理，确保考古工作质量和工地安全，遇有重要发现，应及时向我局报告。

**二、**应严格控制该项目的占地规模及高度，建筑外观形式应力求简化，以避免对圆明园遗址环境风貌造成干扰。在确保安全的情况下，建筑地基尽量不扰动圆明园遗址。

**三、**请你局根据考古工作结果和圆明园遗址建设控制地带保护管理要求，指导有关单位进一步完善北京第一〇一中学翻建操场看台设计方案，并经你局核准后实施。

**四、**根据《圆明园遗址公园规划》，北京第一〇一中学属于远期搬迁项目。请你局按照规划要求，会同当地人民政府组织制订北京第一〇一中学搬迁计划并逐步实施。

国家文物局

二○○八年六月二日
