# 中国证券监督管理委员会关于核准万家基金管理有限公司变更股权及修改章程的批复

## 中国证券监督管理委员会关于核准万家基金管理有限公司变更股权及修改章程的批复（证监许可[2008]1410号）

万家基金管理有限公司：

你公司报送的《万家基金管理有限公司关于股东出资转让的申请》（万家基字[2008]51号）及相关文件收悉。根据《公司法》、《证券投资基金法》和《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**　 核准山东省国有资产投资控股有限公司受让齐鲁证券有限公司持有的你公司11％的股权。

上述股权转让完成后，你公司股东出资额及出资比例为：

```
股东名称　　　　　　　　　　　出资额　出资比例

（一）齐鲁证券有限公司　　　　4900万元　　　　49％

（二）上海久事公司　　　　　　2000万元　　　　20％

（三）深圳市中航投资管理有限公司　 2000万元　　　　20％

（四）山东省国有资产投资控股　1100万元　　　　11％

有限公司
```

**二、**同意你公司对公司章程所作的修改。

你公司及相关股东应及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证券监督管理委员会

二○○八年十二月十六日
