# 中国证券监督管理委员会关于同意中国银河证券股份有限公司筹建方案的批复

## 中国证券监督管理委员会关于同意中国银河证券股份有限公司筹建方案的批复（证监机构字[2005]163号）

中国银河金融控股有限责任公司：

你公司《关于中国银河证券股份有限公司筹备申请》（中银金控发[2005]1号）及有关申请文件收悉。经审核，现批复如下：

**一、**同意你公司发起设立一家证券公司，注册地在北京市。

**二、**同意拟设立公司名称为“中国银河证券股份有限公司”，但筹建期间不得以该名称对外开展业务。

**三、**同意中国银河证券股份有限公司的注册资本为60亿元人民币。核准以下单位的股东资格及出资金额：

```
（一）中国银河金融控股有限责任公司　　　　　599，300万元

（二）北京清华科技创业投资有限公司　　　　　200万元

（三）重庆市水务控股（集团）有限公司　　　　200万元

（四）中国通用技术（集团）控股有限责任公司　200万元

（五）中国建材股份有限公司　　　　　　　　　100万元
```

**四、**你公司接本批复后，应按照《中华人民共和国公司法》、《中华人民共和国证券法》、《关于印发＜关于进一步加强证券公司监管的若干意见＞的通知》（证监机构字[1999]14号）等法律、法规和有关政策的要求，在6个月内完成中国银河证券股份有限公司的筹建工作，确保资本金足额到位，并聘请具有证券相关业务资格的会计师事务所进行验资，召开股东大会，选举产生董事会、监事会，选举拟任董事长、副董事长、监事长，决定拟聘正、副总经理及其他高级管理人员人选，拟定公司章程。

**五、**你公司应聘请律师事务所对中国银河证券股份有限公司开业有关事项的真实性、合法性出具法律意见书。

**六、**你公司在报送开业申请文件时应同时提交以下文件：（一）具有证券相关业务资格的会计师事务所出具的中国银河证券有限责任公司截至2005年9月30日的审计报告；（二）按市场原则，完成相关程序后签署的具有法律效力的《资产收购协议》，所收购的中国银河证券有限责任公司的证券类资产不包括自营证券及受托理财资产；（三）具有证券相关业务资格的会计师事务所出具的所收购的中国银河证券有限责任公司的证券类资产不存在不良债权债务、经纪业务的客户交易结算资金归位的专项审计报告；（四）具有证券相关业务资格的资产评估机构出具的上述证券类资产的评估报告，评估结果应取得财政部的确认；（五）中国银河证券股份有限公司的模拟资产负债表和模拟净资本计算表；（六）中国银河证券有限责任公司关于其分支机构的处置意见；（七）有关各方确认的业务转接、人员安置等相关问题的实施方案。

**七、**中国银河证券股份有限公司按市场原则收购相关证券类资产后，中国银河证券有限责任公司应转为实业公司，并就委托理财个人债权等问题制定切实可行的解决方案。

**八、**中国银河证券股份有限公司筹建工作完成后，请将开业申请、验资报告、公司章程及法律意见书等报送我会复查。公司高级管理人员任职须事先取得高管资格。公司的全体董事均须在我会备案。

**九、**中国银河证券股份有限公司设立后，其客户交易结算资金须实施第三方存管。在公司正式开业前，经纪业务客户交易结算资金第三方存管方案需通过我会的评审。

**十、**中国银河证券股份有限公司在组建过程中，应加强领导，周密组织，并建立良好的公司治理结构和严格的内控机制。同时应继续严肃查处对违法违规行为负有责任的人员，涉嫌违规的，及时报告有关监管机关；涉嫌犯罪的，应移送司法机关。

二○○五年十二月二十二日
