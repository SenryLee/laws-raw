# 中国证监会关于核准汇添富基金管理股份有限公司变更股权的批复

## 关于核准汇添富基金管理股份有限公司变更股权的批复

证监许可〔2016〕3129号

汇添富基金管理股份有限公司：

你公司报送的《汇添富基金管理股份有限公司关于增加注册资本的申请报告》（汇添富发字〔2016〕498号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

一、核准上海菁聚金投资管理合伙企业（有限合伙）认购你公司的新增注册资本，转让完成后，你公司股权结构为：

人民币　元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额 | 出资比例 |
| 1 | 东方证券股份有限公司 | 47,000,000 | 35.412% |
| 2 | 上海菁聚金投资管理合伙企业（有限合伙） | 32,724,224 | 24.656% |
| 3 | 上海上报资产管理有限公司 | 26,500,000 | 19.966% |
| 4 | 东航金控有限责任公司 | 26,500,000 | 19.966% |
|  | 合计 | 132,724,224 | 100% |

二、你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2016年12月19日
