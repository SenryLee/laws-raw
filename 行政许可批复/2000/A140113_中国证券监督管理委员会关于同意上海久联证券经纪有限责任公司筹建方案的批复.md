# 中国证券监督管理委员会关于同意上海久联证券经纪有限责任公司筹建方案的批复

## 中国证券监督管理委员会关于同意上海久联证券经纪有限责任公司筹建方案的批复（2000年6月6日　证监机构字[2000]第118号）

上海市人民政府：你市《关于报请审核上海久联证券经纪有限公司筹建申请材料的函》(沪府函[2000]14号)及有关材料收悉。经研究，批复如下：

**一、**同意上海久联证券经纪有限责任公司筹建方案。

**二、**同意公司名称为“上海久联证券经纪有限责任公司”，该名称需待公司筹建完成并经工商登记后方可使用。

**三、**同意上海久联证券经纪有限责任公司在上海市设立2家证券营业部。证券营业部筹建完毕并经上海证券监管办公室验收合格后，再向我会申请开业。

**四、**同意上海久联证券经纪有限责任公司注册资本金为人民币2亿元，同意以下股东资格及出资份额：

```
(一)上海久联集团公司户　　　　　　12，000万元

(二)申能(集团)公司　　　　　　4，000万元

(三)上海普陀国有资产公司　　　1，000万元

(四)上海商业投资公司　　　　　1，000万元

(五)上海新物业建设公司　　　　1，000万元

(六)上海浦东商业建设公司　　　1，000万元
```

**五、**你市接此批复后，通知上海久联证券经纪有限责任公司筹备组按照　《中华人民共和国公司法》 、《关于印发＜关于进一步加强证券公司监管的若干意见＞的通知》(证监机构字[1999]14号)等有关法律、法规和政策的规定，抓紧落实资本到位工作，聘请具有从事证券业务资格的会计师事务所进行验资，召开股东大会，选举产生董事会，选举拟任董事长及拟聘正、副总经理，拟定公司章程。以上事项需由具备从事证券业务资格的律师事务所出具法律意见书。

**六、**新公司应在本批复下发之日起六个月内完成筹建工作。新公司筹建完毕后，应将验资报告、公司章程、拟聘(任)高级管理人员任职资格申报材料及法律意见书报我会复查。
