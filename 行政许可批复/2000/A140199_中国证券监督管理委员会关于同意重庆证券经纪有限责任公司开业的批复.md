# 中国证券监督管理委员会关于同意重庆证券经纪有限责任公司开业的批复

## 中国证券监督管理委员会关于同意重庆证券经纪有限责任公司开业的批复（证监机构字[2000]110号　2000年5月31日）

重庆证券经纪有限责任公司筹备组：

你们报送的《重庆证券经纪有限公司申请开业的报告》和《关于重庆证券经纪有限公司重庆上清寺证券营业部申请开业的报告》及相关材料收悉。经研究，现批复如下：

**一、**同意重庆证券经纪有限责任公司及其重庆中山三路证券营业部开业。

**二、**核准重庆证券经纪有限责任公司注册资本为1亿元。经重庆华源会计师事务所验证(华源验字[1999]第31号)，你公司1亿元资本金已足额到位。核准以下股东及其出资额：

```
(一)重庆未来投资有限公司　　　4，693万元

(二)上海成日企业发展有限公司　1，980万元

(三)上海浦东顾路工业总公司　　1，000万元

(四)上海渝龙实业股份有限公司　1，900万元

(五)重庆市开发投资有限公司　427万元
```

**三、**核准《重庆证券经纪有限责任公司章程》。

**四、**确认夏峰、李强、余树林、陈朝荣、陈华担任重庆证券经纪有限责任公司高级管理人员的任职资格，其中，夏峰任董事长，李强任总经理，余树林、陈朝荣和陈华任副总经理。

**五、**请你公司接此批复后，到我会领取《经营证券业务许可证》和《证券经营机构营业许可证》。自本批复下发之日起一个月内，重庆证券经纪有限责任公司及重庆中山三路证券营业部必须挂牌开业，逾期本批复自动失效。
