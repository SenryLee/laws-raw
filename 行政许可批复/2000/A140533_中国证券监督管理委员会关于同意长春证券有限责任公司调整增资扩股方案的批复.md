# 中国证券监督管理委员会关于同意长春证券有限责任公司调整增资扩股方案的批复

## 中国证券监督管理委员会关于同意长春证券有限责任公司调整增资扩股方案的批复（证监机构字[2000]84号　2000年4月29日）

长春证券有限责任公司：

你公司《关于股权变更的请示》(长证发[2000]01号)、《关于调整增资扩股的请示》(长证发[2000]07号)及有关材料收悉。经审核，现批复如下：

**一、**同意你公司调整增资扩股方案。

**二、**同意以下股东的入股资格及出资额：

```
(一)吉林省置业集群通讯公司　　　4000万元

(二)吉林省富邦农业发展公司　　　4000万元

(三)吉林省银隆科贸开发有限公司　4000万元

(四)长春市联合物业管理公司　　　4000万元

(五)吉林国际信托投资公司　　　　4000万元
```

其中，吉林省国际信托投资公司暂以现金形式入股你公司，待中国人民银行对该公司及其所属证券营业部处置意见下达后，由该公司以其所属证券营业部折股置换所持你公司股权，不足部分以现金补齐。吉林国际信托投资公司只有经中国人民银行批准予以保留，才能持有长春证券有限责任公司的股权，否则，其股权应对外转让。

**三、**请你公司接此批复后，严格按照《关于长春证券有限责任公司股权变更及增资扩股方案的批复》(证监机构字[1999]01号)第四、第五条要求，落实有关工作。
