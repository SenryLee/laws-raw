# 中国保险监督管理委员会关于太平养老保险股份有限公司修改章程的批复

## 中国保险监督管理委员会关于太平养老保险股份有限公司修改章程的批复（保监发改〔2009〕1343号）

太平养老保险股份有限公司：

你公司关于修改公司章程的请示（太平养老〔2009〕72号）收悉。经审查，核准你公司2009年8月19日股东大会决议对公司章程进行的以下修改：

**一、**第二条第二款修改为：经中国保险监督管理委员会（‘保监会’）批准，公司由中国太平保险集团公司、太平人寿保险有限公司、太平资产管理（香港）有限公司、富通保险国际股份有限公司和太平财产保险有限公司共同出资设立，在国家工商行政管理总局注册登记，领取营业执照。

**二、**第十三条修改为：公司各股东出资额及出资比例如下：

|  |  |  |
| --- | --- | --- |
| 股东名称 | 出资额（人民币） | 出资比例（%） |
| 中国太平保险集团公司 | 0.32亿元 | 4.0% |
| 太平人寿保险有限公司 | 5.16亿元 | 64.5% |
| 太平资产管理（香港）有限公司 | 1.12亿元 | 14.0% |
| 富通保险国际股份有限公司 | 0.8亿元 | 10.0% |
| 太平财产保险有限公司 | 0.6亿元 | 7.5% |

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

二○○九年十二月二十二日
