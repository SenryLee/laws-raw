# 中国证券监督管理委员会关于核准国泰基金管理有限公司变更股权、变更住所的批复

## 中国证券监督管理委员会关于核准国泰基金管理有限公司变更股权、变更住所的批复（证监许可[2009]1163号）

国泰基金管理有限公司：

你公司报送的《关于国泰基金管理有限公司股东变更和住所变更的申请》（国泰基董[2009]055号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**　 核准意大利忠利集团（Assicurazioni Generali S.p.A.）受让中国建银投资有限责任公司持有的你公司10％股权、万联证券有限责任公司持有的你公司20%股权。转让完成后，你公司股权结构为：

人民币 元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 中国建银投资有限责任公司 | 66，000，000 | 60％ |
| 2 | 意大利忠利集团 | 33，000，000 | 30％ |
| 3 | 中国电力财务有限公司 | 11，000，000 | 10％ |
|  | 合计 | 110，000，000 | 100％ |

**二、**核准你公司将住所变更为上海市浦东新区世纪大道100号上海环球金融中心39楼。

**三、**核准你公司所作的与股权变更、住所变更相关的章程修改。

**四、**你公司及各股东应当完善公司治理，维护公司及基金份额持有人的合法权益，并按规定办理工商变更登记等相关事宜，及时到我会换领《基金管理资格证书》。

中国证券监督管理委员会

二○○九年十一月六日
