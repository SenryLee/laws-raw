# 中国证券监督管理委员会关于核准中欧基金管理有限公司变更股东及修改章程的批复

## 中国证券监督管理委员会关于核准中欧基金管理有限公司变更股东及修改章程的批复（证监许可【2009】13号）

中欧基金管理有限公司：

你公司报送的《中欧基金管理有限公司关于股东变更及修改公司章程的申请报告》（中欧监字[2008]第029号）及相关文件收悉。根据《公司法》、《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准隆巴第及皮埃蒙特银行与Banche Popolari Unite S.c.p.a.合并后的意联银行（Unione di Banche Italiane S.c.p.a.）为你公司股东，股东变更后，你公司股权结构为：

人民币 元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 意联银行 | 58800000 | 49％ |
| 2 | 国都证券有限责任公司 | 56400000 | 47％ |
| 3 | 平顶山煤业（集团）有限责任公司 | 4800000 | 4％ |
|  | 合计 | 120000000 | 100％ |

**二、**核准你公司对公司章程所作的修改。

你公司及相关股东应及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证券监督管理委员会

二○○九年一月六日
