# 国家发展改革委关于广州华润南沙热电“上大压小”新建工程核准的批复

（2009年4月28日　发改能源〔2009〕963号）

广东省发展改革委：

报来《广东省发展改革委关于上报广州华润热电有限公司南沙2x300Mw“上大压小”热电联供项目核准申请报告的请示》（粤发改能〔2008〕1228号）及有关材料收悉。经研究，现就该项目核准事项批复如下：

**一、**为落实国务院国发〔2007〕2号文件精神，促进小火电机组关停工作，优化电源结构，提高能源利用效率，改善环境，同意建设广州华润南沙热电“上大压小”新建工程。

项目单位为广州华润热电有限公司。

**二、**项目建设地点为广州市南沙区黄阁镇小虎岛。

**三、**本工程建设2台30万千瓦国产亚临界燃煤热电机组。相应关停广州市花都巴江发电厂B#1～#3（3x1.07万千瓦）、C#1（1 x0.55万千瓦）、D # 1～#4（4x2.185万千瓦），合计12.5万千瓦燃油小机组，占用广东省火电建设规模29万千瓦。项目投产后，形成600吨／时供汽能力，并拆除供热区内25台分散锅炉。

电厂采用二次循环水冷却方式，年用水量约1420万立方米，生产用水使用珠江水。电厂投产后，年需燃煤约134万吨，由山西大同煤矿和宁武煤矿供应，经铁海联运至电厂。电厂配套建设1个3.5万吨级煤炭接卸泊位，年通过能力160万吨，码头长230米。电厂所排灰渣全部综合利用，厂内建设密闭灰库作为电厂事故周转备用。

电厂以220千伏电压等级接入系统。电网工程由电网企业投资建设，具体方案另行审定。电厂同步安装热力负荷实时在线监测装置，并与发电调度机构联网。

**四、**本工程动态总投资29.7亿元。其中项目资本金为7.5亿元，约占动态总投资的25 %，由华润电力控股有限公司和广州南沙资产经营有限公司分别按70％和30％的比例以自有资金出资。

资本金以外所需资金22.2亿元，分别申请中国工商银行和中国农业银行贷款解决。

**五、**本工程安装高效静电除尘、脱硫、脱硝设施和在线烟气连续监测装置。各项排放指标要满足国家环保要求。

**六、**项目单位要优化工程设计，选用节能设备，加强节能管理。项目投产后发、供电煤耗等各项能耗指标应控制在设计水平。

**七、**项目建设应严格执行《招标投标法》的有关规定，所需设备通过公开招标采购。

**八、**核准项目的相关文件分别是《规划选址意见书》（选字第440000200900042号）、《关于广州华润热电有限公司2x 300MW热电机组工程环境影响报告书的批复》（环审〔2009〕55号）、《关于广州华润热电厂二期工程建设用地预审意见的复函》（国土资预审字〔2008〕183号）和《关于广州华润热电有限公司二期工程水土保持方案的复函》（水保函〔2006〕381号）等。

**九、**如需对本项目核准文件所规定的有关内容进行调整，请及时以书面形式向我委报告，并按照规定办理。

**十、**请项目单位根据本核准文件，办理相关城乡规划、土地使用、资源利用、安全生产等手续。

**十一、**本核准文件有效期限为2年，自发布之日起计算。在核准文件有效期内未开工建设项目的，应在核准文件有效期届满30日前向我委申请延期。项目在核准文件有效期内未开工建设也未申请延期的，或虽提出延期申请但未获批准的，本核准文件自动失效。
