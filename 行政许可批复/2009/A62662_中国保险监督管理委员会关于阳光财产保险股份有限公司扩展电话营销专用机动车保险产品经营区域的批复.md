# 中国保险监督管理委员会关于阳光财产保险股份有限公司扩展电话营销专用机动车保险产品经营区域的批复

## 中国保险监督管理委员会关于阳光财产保险股份有限公司扩展电话营销专用机动车保险产品经营区域的批复（保监产险〔2009〕451号）

阳光财产保险股份有限公司：

你公司《关于申请在福建、黑龙江、上海等21个省市使用阳光财险电话营销专用机动车商业保险条款和费率的请示》（阳光财险〔2009〕13号）收悉。经审核，同意你公司增加在天津、河北、山西、内蒙古、辽宁、吉林、黑龙江、上海、安徽、福建、江西、湖北、湖南、广西、重庆、贵州、云南、甘肃、青海、新疆、大连等21个地区使用电话营销专用机动车商业保险产品。保险费率见附件，保险条款等未尽事宜适用保监产险〔2008〕1457号文件的规定。

费率使用说明

**一、**各险种保费计算方法

（一）第三者责任保险

1．按照被保险人类别、机动车用途、座位数/吨位数/排量/功率、责任限额直接查找保费。

（二）机动车损失保险

1．按照被保险人类别、机动车用途、座位数/吨位数/排量/功率、机动车使用年限所属档次查找基础保费和费率；

保费 ＝ 基础保费 ＋ 保险金额 × 费率。

以下表为例说明保费的计算方法。

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 使用性质和车辆种类 | | 机动车损失保险 |  |  |  |
| 1年以下 |  | 1-2年 |  |
| 基础保费 | 费率 | 基础保费 | 费率 |
| 家庭自用机动车 | 6座以下 | 459 | 1.0880% | 437 | 1.0370% |
| 6-10座 | 550 | 1.0880% | 524 | 1.0370% |

例1：假定某5座家庭自用机动车投保车损险，车龄为1年以下，保险金额为10万元。在费率表上查得对应的基础保费为458元，费率为1.09%，则该机动车的保费＝458＋10万×1.09%＝1548元。如果保险金额变为15万元，则该机动车的保费＝458＋15万×1.09％＝2093元。

（三）车上人员责任险

按照被保险人类别、机动车用途、座位数查找费率；

驾驶人保费 ＝ 每次事故责任限额 × 费率

乘客保费 ＝ 每次事故每人责任限额 × 费率 × 投保乘客座位数

（四）机动车盗抢保险

按照被保险人类别、机动车用途、座位数查找基础保费和费率；

保费 ＝ 基础保费 ＋ 保险金额 × 费率

（五）玻璃单独破碎险

按照被保险人类别、座位数、投保国产/进口玻璃查找费率；

保费 ＝ 新车购置价 × 费率

（六）车身划痕损失险

按车龄、新车购置价、保额所属档次直接查找保费。

（七）可选免赔额特约条款

按照选择的免赔额、新车购置价查找费率折扣系数；

约定免赔额之后的机动车损失保险保费 ＝ 机动车损失保险保费 × 费率折扣系数

（八）不计免赔率特约条款

按照适用的险种查找费率；

保费 ＝ 适用本条款的险种标准保费 × 费率

（九）自燃损失险

按照适用的车龄查找费率；

保费＝赔偿限额×费率

（十）新增加设备损失险

新增设备损失险保费 ＝ 保险金额 × 车损险标准保费 ∕ 车损险保险金额。

（十一）代步车费用险

固定费率；

保费 ＝ 日赔偿金额 × 最高赔偿天数的10%

（十二）车上货物责任险

按照车辆的使用性质查找费率；

保费 ＝ 赔偿限额 × 费率

（十三）发动机特别损失险

固定费率；

保费 ＝ 新车购置价 × 费率

（十四）交通事故精神损害赔偿责任险

固定费率；

保费 ＝ 赔偿限额 × 费率

注：适用于投保了第三者责任商业保险和车上人员责任险的机动车。

（十五）救助特约条款

固定年保费；无需计算；

注：适用于投保了机动车损失保险的9座以下客车。

（十六）选择修理厂特约条款

固定费率；

选择本特约条款后机动车损失保险保费 ＝ 机动车损失保险保费 × 1.1

注：适用于已投保机动车损失保险的机动车。

（十七）法律费用特约条款

按照责任限额直接查找固定保费；

注：适用于已投保第三者责任保险或车上人员责任保险的机动车。

（十八）使用安全带补偿特约险

固定费率；

保费 ＝ 赔偿限额 × 费率

注：适用于已投保车上人员责任险的机动车。

（十九）异地出险住宿交通费特约条款

按照责任限额直接查找固定保费；

注：适用于已投保机动车损失险和第三者责任保险的机动车。

**二、**使用费率调整系数表进行费率调整

（一）无赔款优待及上年赔款记录费率调整系数

根据历史赔款记录，按照规定的费率调整系数进行费率调整。

（二）约定行驶区域系数

可选择约定仅在一省区域内行使。

（三）指定驾驶人、性别、驾龄、年龄系数

仅适用于家庭自用车指定驾驶人的情况，当指定多名驾驶人时，以乘积高者为准。　

（四）使用规则

1.费率调整系数采用系数连乘的方式：

费率调整系数 ＝ 系数1 × 系数2 × 系数3 × ……

2.使用费率调整系数后，各险别的费率优惠幅度超过监管部门规定的最大优惠幅度，按照监管部门规定的最大优

惠幅度执行。

3.费率调整系数表不适用于摩托车和拖拉机。

**三、**其他

在费率表中，凡涉及分段的陈述都按照“含起点不含终点”的原则来解释。

例如：“6座以下”的含义为5座、4座、3座、2座、1座，不包含6座；

“6-10座”的含义为6座、7座、8座、9座，不包含10座；

“20座以上”的含义为20座、21座、…，包含20座；

“10万以下”不包含10 万；

“10-20万”包含10万，不包含20万；

“20万以上”包含20万。
