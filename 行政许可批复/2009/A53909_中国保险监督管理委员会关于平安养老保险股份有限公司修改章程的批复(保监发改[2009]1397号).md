# 中国保险监督管理委员会关于平安养老保险股份有限公司修改章程的批复(保监发改[2009]1397号)

## 中国保险监督管理委员会关于平安养老保险股份有限公司修改章程的批复（保监发改〔2009〕1397号）

平安养老保险股份有限公司：

你公司关于申请修改公司章程的请示（平保养发〔2009〕121号）收悉。经审查，核准你公司2009年10月15日股东大会决议对章程进行的如下修改：

**一、**第五条修改为：公司注册资本为人民币27亿元。

**二、**章程附件股份结构表修改为：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东全称 | 持股数量（万股） | 持股比例 |
| 1 | 中国平安保险（集团）股份有限公司 | 268500 | 99.44% |
| 2 | 中国平安人寿保险股份有限公司 | 900 | 0.33% |
| 3 | 中国平安财产保险股份有限公司 | 300 | 0.11% |
| 4 | 平安信托投资有限责任公司 | 150 | 0.06% |
| 5 | 深圳市平安创新资本投资有限公司 | 150 | 0.06% |
|  | 合　计 | 270，000 | 100% |

请你公司依照有关规定办理变更事宜。

此复
