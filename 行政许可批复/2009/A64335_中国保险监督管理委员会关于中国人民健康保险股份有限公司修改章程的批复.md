# 中国保险监督管理委员会关于中国人民健康保险股份有限公司修改章程的批复

## 中国保险监督管理委员会关于中国人民健康保险股份有限公司修改章程的批复（保监发改〔2009〕313号）

中国人民健康保险股份有限公司：

你公司《关于中国人民健康保险股份有限公司修改公司章程的请示》（人保健康发〔2009〕65号）收悉。经审查，批准你公司2008年11月18日股东大会决议对章程进行的以下修改：

**一、**第四条修改为：“公司住所：北京市西城区太平桥大街丰汇园11号楼南翼7-10层。”

**二、**第十二条修改为：“公司的注册资本为在公司登记机关登记的实收资本总额。公司的注册资本总额为人民币叁拾亿元（RMB￥3，000，000，000），其中包括根据缴付日中国人民银行公布的基准汇率折算相当于人民币壹亿玖千万元（RMB￥190，000，000）的欧元。公司注册资本划分为等额股份，共叁拾亿股，每股面值人民币壹元（RMB￥1），全部由股东认购。”

**三、**第十三条修改为：公司股东及其认购的公司股份

（一）公司股东为：

1、中国人民保险集团公司（以下简称“人保集团”）；

2、DKV Deutsche Krankenversicherung AG（德国健康保险股份公司）（以下简称“DKV”）；

3、中国华闻投资控股有限公司（以下简称“华闻控股”）；

4、首都机场集团公司（以下简称“首都机场”）；

5、广西新长江高速公路有限责任公司（以下简称“新长江”）。

（二）公司股东认购的公司股份

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 股东名称 | 出资额 | 认购股份（股） | 持股比例 | 出资方式 |
| 人保集团 | 2，510，000，000元人民币 | 2，510，000，000 | 83.67% | 货币 |
| DKV | 【】欧元* | 190，000，000 | 6.33% | 货币 |
| 华闻控股 | 100，000，000元人民币 | 100，000，000 | 3.33% | 货币 |
| 首都机场 | 100，000，000元人民币 | 100，000，000 | 3.33% | 货币 |
| 新长江 | 100，000，000元人民币 | 100，000，000 | 3.33% | 货币 |

*注：DKV的出资缴付按当日中国人民银行公布的基准汇率折算，相当于人民币壹亿玖千万元（RMB￥190，000，000）。

**四、**第十六条修改为：“公司股份的处置

公司股东自公司成立之日起五年内不得以对其持有的公司股份所有权产生实质性影响的方式处置该公司股份。

股东之间相互转让股份不受前款规定限制。

公司股东转让或质押其持有的公司股份应同时满足下列条件：

（一） 该等转让或质押不应给公司带来任何不利影响；

（二） 股东转让其所持有的公司股份的，受让方为符合向保险公司投资的法定条件的法人；

（三） 其他股东在同等条件下有优先购买权，该优先购买权应该按照股东大会授权董事会制定的操作细则来实施；

（四） 股东将其持有股份进行质押的，应当自该事实发生之日起三个工作日内，向公司作出书面报告；

（五） 公司股份的转让不能违反相关的法律法规和规章，包括但不限于公司法关于股份有限公司股东人数的规定，以及中国保监会关于单个股东（及其关联方）、外资股东的持股比例限制的规定。

股东转让其持有的公司股份应报中国保监会批准或备案。

公司股东违反本条款规定处置所持有的公司股份，由此获得的收益归公司所有，该部分收益计入公司资本公积金。”

**五、**第十三条、三十九条、四十条、五十二条、五十三条中的“中国人保控股公司”和“人保控股”分别修改为“中国人民保险集团公司”和“人保集团”。

请你公司尽快按照有关监管规定对章程进行相应修改，报中国保监会批准，并按照有关规定办理变更事宜。

此复

中国保险监督管理委员会

二○○九年四月十三日
