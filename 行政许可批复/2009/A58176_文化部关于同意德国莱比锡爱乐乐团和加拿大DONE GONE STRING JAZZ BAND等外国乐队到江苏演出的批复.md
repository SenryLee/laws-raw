# 文化部关于同意德国莱比锡爱乐乐团和加拿大DONE GONE STRING JAZZ BAND等外国乐队到江苏演出的批复

## 文化部关于同意德国莱比锡爱乐乐团和加拿大DONE　GONE　STRING　JAZZ　BAND等外国乐队到江苏演出的批复（文市函〔2009〕1904号）

江苏省文化厅：

你厅苏文市（外）370、371号请示收悉。

经研究，同意江苏省演出公司邀请加拿大DONE GONE STRING JAZZ BAND乐队一行5人、国际联合BIMBACHE JAZZ&RAICES EIHIERRO乐队一行8人、德国KONIG TRIO JAZZ BAND乐队一行3人、比利时SNAARMAARWAAR乐队一行5人、荷兰LATIN JAZZ MOOTS TANGO乐队一行7人，于2009年11月13日至17日到江苏省南京市演出；邀请德国莱比锡爱乐乐团一行58人，于2009年12月15日至2010年1月20日到江苏等地演出。

请举办单位严格按照《营业性演出管理条例》及其实施细则的有关规定组织演出，并依法纳税。

请你厅审定演出节目并做好监督检查工作。

此复。

二○○九年九月二十一日
