# 中国保险监督管理委员会关于中国大地财产保险股份有限公司机动车商业保险法律费用特约条款费率的批复

## 中国保险监督管理委员会关于中国大地财产保险股份有限公司机动车商业保险法律费用特约条款费率的批复（保监产险〔2009〕1143号）

中国大地财产保险股份有限公司：

你公司《关于审核机动车辆保险法律费用特约条款的请示》（大地财保发〔2009〕231号）及其补正材料收悉。经审核，同意你公司使用机动车商业保险法律费用特约条款费率，条款编号为A11G03F01091104；有关保险条款费率的其他未尽事宜，适用保监产险〔2009〕957号文件的规定。

二○○九年十一月四日

附件：

中国大地财产保险股份有限公司机动车商业保险法律费用特约条款

投保了机动车第三者责任保险或车上人员责任保险的机动车，可附加本特约条款。

保险期间内，经保险人事先书面同意，被保险人因发生第三者责任保险或车上人员责任保险的保险事故给第三者或车上人员造成损害而被提起仲裁或诉讼的，对应由被保险人支付的仲裁或者诉讼费用以及其他费用，保险人在本特约条款的每次事故责任限额内负责赔偿。每次事故责任限额由投保人和保险人在投保时按1万元、2万元、5万元的档次协商确定。

法律费用特约条款费率说明

（2009版）

本费率说明适用于中国大地财产保险股份有限公司在全国范围内使用的机动车保险费率表。

本费率说明由保险费率表、保险费率使用说明两部分组成。

**一、**保险费率表

|  |  |  |  |
| --- | --- | --- | --- |
| 法律费用特约条款 | | | |
| 责任限额 | 1万元 | 2万元 | 5万元 |
| 保费（元） | 50 | 80 | 150 |

**二、**保险费率表使用说明

（一）保费计算方法

法律费用特约险实行固定基准保费，按照不同的责任限额直接查找保费。

（二）使用我公司原费率调整系数表进行费率调整

1、费率调整系数采用系数连乘的方式：

费率调整系数＝系数1×系数2×系数3×……　　2、使用费率调整系数后，各险别的费率优惠幅度超过监管部门规定的最大优惠幅度，按照监管部门规定的最大优惠幅度执行。
