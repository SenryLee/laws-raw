# 国家文物局关于天津五大道近代建筑群建设控制地带内和平区睦南道81号地下室建设项目的批复

文物保函〔2023〕69号

天津市文物局:

《天津市文物局关于在天津五大道近代建筑群建设控制地带内实施和平区睦南道81号地下室新建工程的请示》（津文物发〔2022〕23号）收悉。经研究，我局原则同意在天津五大道近代建筑群建设控制地带内实施和平区睦南道81号地下室建设项目。

**一、**对项目方案提出以下修改意见：

（一）优化设计方案。应核算并加大基坑与文物本体间的距离，切实避免影响文物建筑地基基础稳定性。进一步评估基坑降水、施工振动对文物建筑地基基础的影响。拉森钢板桩临近文物施工存在不确定性，临卞氏旧居一侧宜改用旋挖成孔钢筋混凝土支护桩，优化施工工艺，最大限度降低振动，桩间应采用旋喷桩形成帷幕并用内支撑支护，确保文物安全。

（二）完善应急预案。补充施工期间各项突发事件应急预案和文物监测方案。进一步核实支护结构变形超过阈值时，场外卸土或临时钢撑的可行性，确保应急措施及时、有效。

**二、**请你局指导相关单位根据以上意见对所报项目进行修改、完善，并按照《中华人民共和国文物保护法》等有关法律法规，履行相应审批程序后实施。

**三、**请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，切实做好工程参与人员的培训工作，确保文物安全。项目实施过程中如发现重要文物遗存，应立即停止施工并研提保护措施。

此复。

国家文物局

2023年1月20日
