# 国家文物局关于大运河南运河建设控制地带内实施天津西站南片区（京津冀同城商务区一期）B、C地块南区项目的批复

文物保函〔2025〕569号

天津市文物局:

《天津市文物局关于在大运河（南运河）建设控制地带内实施天津西站南片区（京津冀同城商务区一期）B、C地块南区项目的请示》（津文物发〔2025〕4号）收悉。经研究，我局原则同意所报项目。

**一、**所报方案尚需作以下必要的修改和完善：

（一）优化拟建建筑外观设计，建筑风格应力求简洁，建筑外立面以低饱和度色彩为宜，核减外立面玻璃幕墙的面积并采用低反射玻璃。

（二）优化项目整体建筑高度，建议将B3办公楼降至与B4办公楼基本等高，1#住宅降至8层，可通过增加北侧建筑高度补足建筑面积。

（三）优化项目景观设计，增加项目沿大运河一侧的绿化高度和厚度，选用当地植被，适当补充景观小品等大运河遗产价值展示设施。

（四）补充施工期间的大运河监测措施、防护措施和应急预案，细化施工废渣、污水、粉尘、噪音污染管理及处置措施，施工结束后及时做好场地清理和环境修复工作。

**二、**请你局指导相关单位，全面落实《大运河文化保护传承利用规划纲要》要求，并根据以上意见对所报项目方案进行修改、完善，按照《中华人民共和国文物保护法》有关规定，履行相应审批程序后实施。

**三、**请你局会同相关部门加强对项目实施过程的全程监管，组织专业机构参与指导，确保文物安全。项目实施过程中如有文物遗存等重要发现，应立即停止施工并研提保护措施。

此复。

国家文物局
