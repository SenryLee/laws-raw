# 中国保险监督管理委员会关于新华资产管理股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于新华资产管理股份有限公司修改章程的批复（保监许可〔2014〕255号）

新华资产管理股份有限公司：

你公司关于修改章程的请示（新资发〔2014〕4号）收悉。经审查，核准你公司2013年第四次临时股东大会决议对章程做出的以下修改：

**一、**第五条修改为：公司注册资本为人民币伍亿元（￥500，000，000元）。

**二、**第十三条修改为：公司股份总数为伍亿股（500，000，000股）。

**三、**第十七条修改为：公司目前的股份结构如下表：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 持股数量（万股） | 持股比例（%） |
| 1 | 新华人寿保险股份有限公司 | 49，700 | 99.4% |
| 2 | 东方集团实业股份有限公司 | 100 | 0.2% |
| 3 | 新产业投资股份有限公司 | 100 | 0.2% |
| 4 | 中航投资控股股份有限公司 | 100 | 0.2% |
|  | 合计 | 50，000 | 100% |

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年3月24日
