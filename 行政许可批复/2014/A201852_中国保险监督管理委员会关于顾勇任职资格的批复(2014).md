# 中国保险监督管理委员会关于顾勇任职资格的批复(2014)

## 中国保险监督管理委员会关于顾勇任职资格的批复（保监许可〔2014〕515号）

建信人寿保险有限公司：

你公司《关于对顾勇进行任职资格审查的请示》（建信人寿总报〔2014〕255号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》及《保险公司内部审计指引（试行）》的有关要求，经审查，核准顾勇担任你公司审计责任人的任职资格。

此复

中国保监会

2014年6月15日
