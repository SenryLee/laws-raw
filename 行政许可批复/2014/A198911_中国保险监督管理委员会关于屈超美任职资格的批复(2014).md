# 中国保险监督管理委员会关于屈超美任职资格的批复(2014)

## 中国保险监督管理委员会关于屈超美任职资格的批复（保监许可〔2014〕775号）

安邦养老保险股份有限公司：

你公司《关于副总经理屈超美任职资格核准的请示》（安邦养老发〔2014〕77号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准屈超美担任你公司副总经理的任职资格。

此复

中国保监会

2014年9月10日
