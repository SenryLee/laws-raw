# 国家文物局关于撒拉族清真寺古建筑群塔沙坡清真寺唤礼楼维修工程立项的批复

## 国家文物局关于撒拉族清真寺古建筑群塔沙坡清真寺唤礼楼维修工程立项的批复（文物保函〔2014〕1655号）

青海省文化和新闻出版厅：

你厅《关于申请循化县塔沙坡清真寺唤礼楼抢险加固工程经费的请示》（青文新物〔2013〕45号）收悉。经研究，我局批复如下：

**一、**原则同意撒拉族清真寺古建筑群塔沙坡清真寺唤礼楼维修工程立项。

**二、**对所报方案提出修改完善意见如下：

（一）进一步深化现状勘察和前期研究：

1．细化现状勘察，补充残损现状的量化数据。

2．补充一层外墙开裂原因的分析。

3．删除与唤礼楼无关的其它古建筑内容，精简文本。

（二）进一步完善工程措施：

1．尽量采用传统做法。如不宜采用“浇筑钢筋混凝土承台”；周边院落细墁地砖应采用原做法，明确铺墁方式、材料尺寸、配浆比等，并在图纸中标注范围等。

2．补充防虫防腐处理的具体方案；补充木构件的油饰做法。

3．补充复原木装修、门窗、栏杆、隔心板等做法的依据。

（三）按照工程方案图纸绘制要求，全面规范、完善、校核设计图纸。补充各图纸尺寸标注，核对文字和标注的矛盾、错误；准确表述文物保护工程术语；补充斗拱、装修等大样图。

**三、**请你厅根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织具有相关资质的单位对方案进行修改、完善，委托我局认定的第三方咨询评估机构进行方案技术评审，并依据第三方咨询评估机构的评估结论进行审批。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

此复。

国家文物局

2014年6月6日
