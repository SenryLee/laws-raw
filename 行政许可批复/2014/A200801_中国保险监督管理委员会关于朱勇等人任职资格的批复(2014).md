# 中国保险监督管理委员会关于朱勇等人任职资格的批复(2014)

## 中国保险监督管理委员会关于朱勇等人任职资格的批复（保监许可〔2014〕600号）

友邦保险有限公司广东分公司：

你分公司关于朱勇等人任职资格核准的申请材料（粤友邦〔2014〕361、362、363号）收悉。经审查，朱勇、杨东强、季振杰符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准上述三人担任你分公司副总经理的任职资格。

此复

中国保监会

2014年7月8日
