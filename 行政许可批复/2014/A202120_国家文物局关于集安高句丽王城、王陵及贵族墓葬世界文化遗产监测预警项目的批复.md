# 国家文物局关于集安高句丽王城、王陵及贵族墓葬世界文化遗产监测预警项目的批复

## 国家文物局关于集安高句丽王城、王陵及贵族墓葬世界文化遗产监测预警项目的批复（文物保函〔2014〕2000号）

吉林省文物局：

你局《关于集安高句丽王城、王陵及贵族墓葬世界文化遗产监测预警项目技术方案的请示》（吉文物发〔2014〕138号）收悉。经研究，我局批复如下：

**一、**原则同意集安高句丽王城、王陵及贵族墓葬世界文化遗产监测预警项目。

**二、**对该遗产地监测预警工作提出以下意见：

（一）应针对集安高句丽王城、王陵及贵族墓葬的价值特点、存在的主要问题和面临的主要风险，有重点地做好该监测预警项目的技术设计。监测预警系统应重点考虑文物动态数据的综合分析能力，能够及时发出预警报告，并为科学管理提供实时的信息支持。建议进一步加强监测信息的分析和研究工作，尤其是下层数据分析和评估软件的设计，并明确指出预警指标的定量分析方法。

（二）对于遗产区自然和人文环境的监测，应与其所在地相关部门的监测工作相结合，实现数据和信息的共享，避免重复建设。

（三）应突出阶段性技术重点，优化项目实施计划。

（四）明确系统日常维护的技术标准和管理要求。

（五）应结合监测预警系统的建设，做好相关基础档案资料的数据收集、整理、录入和管理工作。

（六）进一步补充和细化经费预算，明确日常维护经费的主要科目和额度。

**三、**请你局指导有关单位，根据上述意见对所报方案进行修改、完善，经你局核准后实施。请加强监管，确保工作质量。

此复。

国家文物局

2014年6月9日
