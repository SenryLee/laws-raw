# 国家文物局关于扬州城遗址唐子城宋堡城护城河遗址保护展示工程设计方案的批复

## 国家文物局关于扬州城遗址唐子城宋堡城护城河遗址保护展示工程设计方案的批复（文物保函〔2014〕616号）

江苏省文物局：

你局《关于审批扬州城遗址唐子城宋堡城护城河遗址保护展示工程设计方案的请示》（苏文物保〔2013〕215号）收悉。经研究，我局批复如下：

**一、**原则同意扬州城遗址唐子城宋堡城护城河遗址保护展示工程设计方案和你局意见。

**二、**所报方案尚需做以下必要的修改和完善：

（一）进一步加强护城河遗迹保护展示的整体景观控制，以自然河道或沼泽湿地为主要景观，避免过多的人工痕迹，以与扬州城遗址及其周边环境相协调。同时，护城河遗迹保护展示应注意控制规模，恰当处理与城墙遗迹的关系，为唐子城宋堡城遗址城墙遗迹及其他重要遗迹的展示预留足够空间。

（二）应在补充开展必要考古工作的基础上，进一步细化主要展示节点的具体设计。

（三）进一步深化护城河遗迹护岸的具体设计，以生态驳岸为主，建议考虑采用湿地植被进行河面和河岸之间过渡的可能性。若确需砌筑护堤或挡土墙，建议慎用水泥等现代材料，并注意做好生态恢复。

（四）应进一步优化各类服务设施及基础设施的空间布局，统筹考虑唐子城宋堡城整体展示的需求，避免重复建设。同时，各类服务设施应以满足最低功能需求为限，力求简洁、大方，并应注意避开唐子城宋堡城城墙等重要遗迹。

**三、**请你局指导方案设计单位联合专业考古研究单位，根据上述意见对方案作进一步修改完善，制定科学、详细的施工方案，经你局核准后实施。

**四、**施工前，请你局组织专业考古研究单位进一步开展必要的考古工作；施工中，请你局委派专业考古研究单位加强对工程的全程监管，确保工程质量和文物安全。

此复。

国家文物局

2014年5月8日
