# 中国保险监督管理委员会关于众诚汽车保险股份有限公司修改章程的批复(保监许可[2014]792号)

## 中国保险监督管理委员会关于众诚汽车保险股份有限公司修改章程的批复（保监许可〔2014〕792号）

众诚汽车保险股份有限公司：

你公司关于修改章程的请示（众诚保险〔2014〕254号）收悉。经审查，核准你公司2014年4月9日股东大会决议对章程做出的以下修改：

**一、**第十七条《股份结构表》修改为：

|  |  |  |  |
| --- | --- | --- | --- |
| 股东名称 | 持股数量 | 持股比例 | 备注 |
| 广州汽车集团股份有限公司 | 100，000，000 | 20% | / |
| 广州汽车集团零部件有限公司 | 100，000，000 | 20% | / |
| 广州汽车集团商贸有限公司 | 100，000，000 | 20% | / |
| 广东粤财信托有限公司 | 100，000，000 | 20% | / |
| 广东省粤科金融集团有限公司 | 50，000，000 | 10% | / |
| 广州长隆集团有限公司 | 50，000，000 | 10% | 广州市长隆酒店有限公司被其母公司广州长隆集团有限公司吸收合并。 |
| 合计 | 500，000，000 | 100% | / |

**二、**第七十八条第二款修改为：公司前两届董事候选人由广州汽车集团股份有限公司提名2人，广州汽车集团零部件有限公司、广州汽车集团商贸有限公司、广东粤财信托有限公司、广东省粤科金融集团有限公司与广州长隆集团有限公司各提名1人；前两届职工代表以外的监事候选人，由广州汽车集团股份有限公司提名；第三届起，董事、监事候选人提名方式另行确定。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年9月19日
