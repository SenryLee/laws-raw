# 国家文物局关于寿县古城墙保护规划的批复

## 国家文物局关于寿县古城墙保护规划的批复（文物保函〔2014〕2195号）

安徽省文物局：

你局《关于请求审批＜寿县古城墙文物保护规划＞的请示》（皖文物保[2013]245号）收悉。经研究，我局批复如下：

**一、**原则同意所报寿县古城墙保护规划。

**二、**对该规划提出以下完善意见：

（一）进一步加强该保护规划与历史文化名城规划、寿春城遗址保护规划等相关规划的衔接和协调，补充专项章节。

（二）关于评估部分

1.补充完善规划范围内生态环境、建设环境的相关评估。

2.补充完善城墙形制研究内容；补充对原保护区划的评估；补充城墙作为军事防御设施的评估。

（三）关于保护区划部分

1.进一步梳理保护区划的管理规定，补充完善有关控制指标，并将措施性的内容移至相关专项规划章节中。

2.保护范围的城外范围宜适当控制，确保文物保护，同时兼顾可实施性。

3.建议城内建设控制地带的管理规定与历史文化名城保护要求相协调。

4.明确建筑控高中的建筑总高控制要求。

5.补充保护区划的坐标。

（三）建议补充监测、防灾等专项规划内容。

（四）合理调整规划分期。

（五）进一步校核文本。如统一规划名称，修改文字或图面中标注错误，规范图纸的绘制和表达。

**三、**请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

**四、**请你局按照《国务院关于加强文化遗产保护的通知》的要求，将已经我局备案的寿县古城墙保护规划报请安徽省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

**五、**规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

**六、**请你局指导和协调地方人民政府在保护规划的指导下，进一步做好寿县古城墙的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，妥善保护文物本体及周边环境安全，确保规划顺利实施。

此复。

国家文物局

2014年6月17日
