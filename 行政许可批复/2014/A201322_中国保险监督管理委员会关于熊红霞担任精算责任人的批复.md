# 中国保险监督管理委员会关于熊红霞担任精算责任人的批复

## 中国保险监督管理委员会关于熊红霞担任精算责任人的批复（保监许可〔2014〕537号）

安诚财产保险股份有限公司：

你公司《关于核准熊红霞同志任职资格的请示》（安保文〔2014〕109号）收悉。经审核，同意熊红霞担任你公司精算责任人。
