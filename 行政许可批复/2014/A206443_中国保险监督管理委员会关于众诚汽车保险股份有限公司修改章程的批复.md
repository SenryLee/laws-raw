# 中国保险监督管理委员会关于众诚汽车保险股份有限公司修改章程的批复

## 中国保险监督管理委员会关于众诚汽车保险股份有限公司修改章程的批复（保监许可〔2014〕142号）

众诚汽车保险股份有限公司：

你公司关于修改章程的请示（众诚保险〔2013〕339号）及补充材料收悉。经审查，核准你公司2013年第一次临时股东大会和2013年第二次临时股东大会决议对章程做出的以下修改：

**一、**第二条第三款修改为：公司经中国保险监督管理委员会（以下简称“中国保监会”）的批准（开业批准文号为保监发改〔2011〕807号），并在广州市工商行政管理局注册登记成立，营业执照签发之日（二○一一年六月八日）为公司成立日期。

**二、**第四条公司住所修改为：广东省广州市天河区广州大道中988号13楼。

**三、**第十七条新增第二款：公司股权情况如下《股份结构表》所示。

|  |  |  |  |
| --- | --- | --- | --- |
| 股东名称 | 持股数量 | 持股比例 | 备注 |
| 广州汽车集团股份有限公司 | 100，000，000 | 20% | ∕ |
| 广州汽车集团零部件  有限公司 | 100，000，000 | 20% | ∕ |
| 广州汽车集团商贸有限公司 | 100，000，000 | 20% | ∕ |
| 广东粤财信托有限公司 | 100，000，000 | 20% | ∕ |
| 广东省粤科风险投资  集团有限公司 | 50，000，000 | 10% | ∕ |
| 广州长隆集团有限公司 | 50，000，000 | 10% | 广州市长隆酒店有限公司被其母公司广州长隆集团有限公司吸收合并。 |
| 合计 | 500，000，000 | 100% | ∕ |

**四、**第七十八条中“广州市长隆酒店有限公司”修改为“广州长隆集团有限公司”。

请你公司依照有关规定办理变更事宜。

此复

中国保监会
