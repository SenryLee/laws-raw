# 国家文物局关于海藏寺保护修缮工程立项的批复

## 国家文物局关于海藏寺保护修缮工程立项的批复（文物保函〔2014〕1833号）

甘肃省文物局：

你局《关于海藏寺保护修缮工程立项的报告》（甘文局发〔2014〕180号）收悉。经研究，我局批复如下：

**一、**同意海藏寺保护修缮工程立项。

**二、**在编制工程方案时，应注意以下方面：

（一）该工程应以现状修整为主，辅以局部重点修缮，不应将全部建筑都列为重点修缮。

（二）工程内容和范围为海藏寺内牌楼、山门、大雄宝殿、三圣殿、地藏殿、天王殿、藏经阁、灵钧台、东西配殿、东西垂花门的保护维修以及环境治理。其中，灵钧台夯土高台、灵钧台之上的天王殿和藏经阁、以及藏经阁的壁画和彩画为此次修缮的重点。

（三）加强现状勘察，查明拟修缮建筑具体残损及病害状况，制定有针对性的保护措施，尽可能多地保存建筑原状和所有历史信息，保证工程质量。

（四）应详细勘察原工艺原做法，注重对地方传统工艺做法的保护。

（五）应进一步明确文物建筑周边环境治理的内容。

（六）细化经费估算，补充取费依据。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织具有相应资质的专业单位编制工程技术方案，委托我局认定的第三方咨询评估机构进行方案技术评审，并依据第三方咨询评估机构的评估结论进行审批。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

此复。

国家文物局

2014年6月6日
