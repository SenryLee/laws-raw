# 中国保险监督管理委员会关于太平资产管理有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于太平资产管理有限公司修改章程的批复（保监许可〔2014〕192号）

太平资产管理有限公司：

你公司关于修改章程的请示（太平资产〔2014〕22号）收悉。经审查，核准你公司2013年股东会第五次临时会议特别决议对章程做出的以下修改：

**一、**第十条修改为：公司注册资本：人民币5亿元。

**二、**第二十六条、第二十七条、第三十一条、第五十三条中删除涉及“中国太平集团”的相关内容。

**三、**第十一条股东的名称、出资方式及出资额中股东中国太平保险控股有限公司出资额修改为人民币400，000，000元，持股比例修改为80％；股东荷兰富杰保险国际股份有限公司出资额修改为折合人民币100，000，000元；中国太平保险集团公司不再持有公司股份。

**四、**第六十四条修改为：中国太平控股享有八名董事候选人提名权，荷兰富杰及新股东（如适用）合共享有二名董事候选人的提名权。

**五、**章程附件股权结构表中股东中国太平保险控股有限公司出资额修改为400，000，000元，持股比例修改为80％；股东荷兰富杰保险国际股份有限公司出资额修改为100，000，000元；中国太平保险集团公司不再持有公司股份；合计出资额修改为500，000，000元。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年3月10日
