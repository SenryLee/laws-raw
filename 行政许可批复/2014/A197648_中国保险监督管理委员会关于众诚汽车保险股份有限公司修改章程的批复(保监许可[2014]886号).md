# 中国保险监督管理委员会关于众诚汽车保险股份有限公司修改章程的批复(保监许可[2014]886号)

## 中国保险监督管理委员会关于众诚汽车保险股份有限公司修改章程的批复（保监许可〔2014〕886号）

众诚汽车保险股份有限公司：

你公司关于修改公司章程的请示（众诚保险〔2014〕299号）收悉。经审查，核准你公司2014年第1次（临时）股东大会对章程做出的以下修改：

**一、**第一章第五条修改为：公司注册资本为人民币7.25亿元。

**二、**第三章第十七条修改为：公司股权情况如下《股份结构表》所示。

|  |  |  |  |
| --- | --- | --- | --- |
| 股东名称 | 持股数量 | 持股比例 | 备注 |
| 广州汽车集团股份有限公司 | 145，000，000 | 20% | / |
| 广州汽车集团零部件有限公司 | 145，000，000 | 20% | / |
| 广州汽车集团商贸有限公司 | 145，000，000 | 20% | / |
| 广州粤财信托有限公司 | 100，000，000 | 13.79% | / |
| 广州发展集团有限公司 | 60，000，000 | 8.28% | / |
| 广东省粤科金融集团有限公司 | 50，000，000 | 6.895% | / |
| 广州长隆集团有限公司 | 50，000，000 | 6.895% | 广州市长隆酒店有限公司被其母公司广州长隆集团有限公司吸收合并 |
| 利泰集团有限公司 | 30，000，000 | 4.14% | / |
| 合计 | 725，000，000 | 100% | / |

**三、**第三章第十八条修改为：公司股份总数为725，000，000股，每股金额1元。公司的股本结构为：普通股。

请你公司依照有关规定办理变更事宜。

此复

中国保监会
