# 国家文物局关于鲁土司衙门旧址——雷坛修缮工程立项的批复

## 国家文物局关于鲁土司衙门旧址--雷坛修缮工程立项的批复（文物保函〔2014〕2285号）

甘肃省文物局：

你局《关于鲁土司衙门旧址--雷坛修缮工程立项的报告》（甘文局发[2014]52号）收悉。经研究，我局批复如下：

**一、**原则同意鲁土司衙门旧址--雷坛修缮工程立项。

**二、**在编制工程方案时，应注意以下方面：

（一）该工程属文物修缮工程，应遵循“不改变文物原状”、“最小干预”等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围和内容包括雷坛大殿维修及院落排水整治。雷坛大殿内泥塑、壁画维修，安防、消防和防雷设施安装等应按程序另行报批；围墙恢复、院落绿化等环境整治项目暂不予立项。

（三）深化文物勘察，准确评估并详细论述文物病害的原因及残损状况，制定有针对性的保护措施。

（四）进一步核定工程预算。

（五）进一步明确拟维修建筑的用途和展示利用方式，并在方案设计中予以体现。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织具有相应资质的专业单位编制工程技术方案，委托我局认定的第三方咨询评估机构进行方案技术评审，并依据第三方咨询评估机构的评估结论进行审批。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

**五、**请你局尽快组织有关单位编制鲁土司衙门旧址文物保护规划，合理调整文物保护范围和建设控制地带，明确相关管理要求，统筹开展鲁土司衙门旧址各项文物保护维修和环境整治工作，保护文物及环境风貌的真实性和完整性。

此复。

国家文物局

2014年7月7日
