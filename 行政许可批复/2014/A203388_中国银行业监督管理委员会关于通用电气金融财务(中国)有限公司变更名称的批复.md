# 中国银行业监督管理委员会关于通用电气金融财务(中国)有限公司变更名称的批复

中国银行业监督管理委员会关于通用电气金融财务（中国）有限公司变更名称的批复

（银监复[2014]303号）

通用电气金融财务（中国）有限公司：

你公司董事长杨志中签署的致我会的函收悉。

根据《中华人民共和国外资银行管理条例》（国务院令第478号，以下简称《条例》）和《中华人民共和国外资银行管理条例实施细则》（中国银监会令2006年第6号，以下简称《实施细则》）的有关规定，经审核，现批复如下：

**一、**批准通用电气金融财务（中国）有限公司中文名称变更为星明财务有限公司，英文名称变更为Starbright Finance Co.， Ltd.。该公司其他事项不变。

**二、**通用电气金融财务（中国）有限公司须按《条例》和《实施细则》的有关规定办理变更事宜。

2014年5月9日
