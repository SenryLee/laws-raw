# 国家文物局关于南京城墙前湖段缺口保护展示工程的批复

## 国家文物局关于南京城墙前湖段缺口保护展示工程的批复（文物保函〔2014〕2216号）

江苏省文物局：

你局《关于南京城墙前湖段缺口保护展示工程设计修改方案的请示》（苏文物保[2014]208号）收悉。经研究，我局批复如下：

**一、**鉴于该处城墙具有丰富历史信息及学术价值、历史价值，加强其保护和展示具有理论和现实意义，我局原则同意南京城墙前湖段缺口保护展示工程设计方案一。

**二、**方案一尚须作如下修改完善：

（一）该工程应当符合《南京城墙保护规划》的有关要求，并与城墙历史风貌相协调。

（二）注意加强对城墙整体立面的研究。

（三）在方案一的顶部通道与城墙连接处，可有一定方式的联通标示。

（四）钢架结构外观色泽、形态、尺度等应尽可能与城墙砖体外观相协调。

（五）方案中一层、二层、顶层的栏杆建议修改为简洁的钢结构，尽量不采用玻璃栏杆（栏板）。

（六）明早期矮城墙不宜做较大动作的规整性修复，可开展必要的监测并依据监测结论制定相应保护措施内容，确保文物本体安全；在保障安全的前提下，保持残缺、沧桑、古朴的原有形态为宜。

（七）在保护历史信息的前提下，加强该处城墙的安全性是工作重点，注意游客观览的防护和疏导措施，合理控制参观人流及人员数量，不宜引导大量人流聚集此地，保证文物、人员安全。

（八）补充工程实施中关于城墙基础的相关保护措施，注意保证城墙原基础的稳定性，减少对城墙本体的扰动。

**三、**请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。请加强工程监管，确保工程质量和文物、人员安全。

此复。

国家文物局

2014年6月18日
