# 国家文物局关于德州码头保护与展示工程设计方案的批复

## 国家文物局关于德州码头保护与展示工程设计方案的批复（文物保函〔2014〕2051号）

山东省文物局：

你局《关于呈报德州码头保护与展示工程设计方案的请示》（鲁文发〔2014〕359号）收悉。经研究，我局批复如下：

**一、**原则同意所报德州码头保护与展示工程设计方案。

**二、**对该方案提出以下修改意见：

（一）进一步深入研究现存文物本体的原材料、原形制和原工艺，为细化保护措施以及局部小范围修复提供科学依据。

（二）应尽最大可能保留屋面及货场铺地等原始构件，不得进行大规模更换。对已被后期改动并不符合历史原貌的码头台阶和大堤壃礤，应依据其历史原状进行修缮。补配构件应采用适当方式进行标识。

（三）应进一步核实库房建筑屋顶是否存在飞檐。如无确凿依据，不得进行恢复。

（四）进一步规范设计图纸，准确表述建筑、构筑物的重要细部结构、形制，并对保护维修措施及重要指标进行明确标注。

**三、**请你局指导有关单位，根据上述意见对所报方案进行修改、完善，经你局核准后实施。请加强施工监管，确保工程质量和文物、人员安全。

此复。

国家文物局

2014年6月9日
