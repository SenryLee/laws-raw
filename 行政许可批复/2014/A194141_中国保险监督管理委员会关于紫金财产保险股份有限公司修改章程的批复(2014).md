# 中国保险监督管理委员会关于紫金财产保险股份有限公司修改章程的批复(2014)

紫金财产保险股份有限公司：

你公司关于修改章程的请示（紫保发〔2014〕158号）收悉。经审查，核准你公司2013年度股东大会决议对章程做出的以下修改：
