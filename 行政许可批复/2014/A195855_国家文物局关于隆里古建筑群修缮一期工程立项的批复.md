# 国家文物局关于隆里古建筑群修缮一期工程立项的批复

## 国家文物局关于隆里古建筑群修缮一期工程立项的批复（文物保函〔2014〕1745号）

贵州省文物局：

你局《关于送审〈隆里古建筑群修缮工程立项报告〉的请示》（黔文物呈〔2014〕85号）收悉。经研究，我局批复如下：

**一、**同意隆里古建筑群修缮一期工程立项。

**二、**在编制工程方案时，应注意以下方面：

（一）该工程属文物修缮工程，应遵循“不改变文物原状”、“最小干预”等原则，充分保护文物的真实性和完整性。

（二）工程范围为隆里古建筑群清阳门、正阳门、迎恩门、状元桥、平水石桥文物建筑本体，苏湖世第、陈氏宗祠、二郎庙、真武庙、龙标书院文物建筑本体及院落，以及位于保护范围的“三街六巷”街巷原有道路。

（三）深化文物现状勘察，分析病害形成原因及破坏程度，明确建筑残损部位及残损量，制定有针对性的保护措施，科学分期，分步实施，保证工程质量。

（四）进一步对苏湖世第宅封火墙现状及做法进行勘察，若无充分依据不宜拆除重砌。

（五）对彩画、泥塑尽量采取原状保护措施，补绘、修复须审慎评估和论证。

（六）明确拟修缮建筑的功能和展示利用方式，并在方案设计中予以体现。

（七）细化经费估算，补充取费依据。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织具有相应资质的专业单位编制工程技术方案，委托我局认定的第三方咨询评估机构进行方案技术评审，并依据第三方咨询评估机构的评估结论进行审批。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

此复。

国家文物局

2014年6月6日
