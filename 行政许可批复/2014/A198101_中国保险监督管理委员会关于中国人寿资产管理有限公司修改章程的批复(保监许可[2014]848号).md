# 中国保险监督管理委员会关于中国人寿资产管理有限公司修改章程的批复(保监许可[2014]848号)

## 中国保险监督管理委员会关于中国人寿资产管理有限公司修改章程的批复（保监许可〔2014〕848号）

中国人寿资产管理有限公司：

你公司关于修改公司章程的请示（国寿资发〔2014〕134号）收悉。经审查，核准你公司2014年9月10日股东会议决议对章程做出的以下修改：

**一、**第十一条修改为：公司的注册资本为人民币40亿元。

**二、**第十四条修改为：公司股东以现金出资。各股东的出资额及其占公司注册资本的比例如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 股东名称 | 出资额（人民币亿元） | 出资方式 | 占注册资本比例 |
| 中国人寿保险（集团）公司 | 16.0 | 现金 | 40% |
| 中国人寿保险股份有限公司 | 24.0 | 现金 | 60% |
| 合计 | 40.0 |  | 100% |

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年10月11日
