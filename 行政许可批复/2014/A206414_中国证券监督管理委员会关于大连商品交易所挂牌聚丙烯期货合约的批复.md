# 中国证券监督管理委员会关于大连商品交易所挂牌聚丙烯期货合约的批复

大连商品交易所：

你所《大连商品交易所关于聚丙烯期货合约上市的请示》（大商所发〔2014〕25号）收悉。根据《期货交易管理条例》和《期货交易所管理办法》的有关规定，现批复如下：

**一、**同意你所挂牌交易聚丙烯期货合约。

**二、**合约具体挂牌时间由你所根据市场状况及各项准备工作的进展情况确定。

**三、**你所应当以高度负责的精神，进一步做好上市前的各项准备工作，注意防范和妥善化解可能出现的市场风险，确保聚丙烯期货的顺利推出和平稳运行。

**四、**在聚丙烯期货上市后，你所应当按照服务实体经济的根本要求，密切关注相关现货市场状况，切实履行好交易、结算、交割、监查等重要环节的监管和服务职责，继续做好市场培育和投资者教育工作。

在组织聚丙烯期货合约交易过程中，如遇重大事项，你所应当及时报告我会。

中国证监会

2014年2月14日
