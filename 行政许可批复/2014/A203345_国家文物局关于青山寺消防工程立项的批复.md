# 国家文物局关于青山寺消防工程立项的批复

## 国家文物局关于青山寺消防工程立项的批复（文物督函〔2014〕627号）

山东省文物局：

你局《关于申请青山寺消防设施建设工程立项的请示》（鲁文物发〔2014〕68号）收悉。经研究，我局批复如下：

**一、**同意青山寺消防工程立项。

**二、**在工程设计方案编制过程中应注意以下问题：

（一）要对青山寺实施全面、详细勘察，根据勘察情况，明确防护对象和消防系统用电等保障条件，科学编制工程方案。

（二）根据青山寺建筑特点、所处环境、管理使用等情况，全面评估火灾风险，有针对性的选择适当、适度和有效的消防设施、设备，避免设备堆砌和防护过度。

（三）必须对原有消防设施现状和使用功能进行全面评估，并与新建消防系统有机结合。明确消防水源，合理设计消防供水系统。明确义务消防组织和人员保障情况，加强消防管理和日常演练，规范用火用电。

（四）根据实际需求和工程规模，合理编制工程概预算。

（五）明确工程实施中的文物保护要求和具体措施，消防设施建设、管线布设和设备安装方式等不得对文物本体及环境风貌造成破坏。

请你局督促指导建设单位组织具有相应资质的设计单位，依据文物保护、消防管理有关规定和标准要求，科学合理编制消防工程方案，并按规定履行方案审批程序。

此复。

国家文物局

2014年5月9日
