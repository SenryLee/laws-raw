# 中国保险监督管理委员会关于阳光农业相互保险公司修改章程的批复(2014)

## 中国保险监督管理委员会关于阳光农业相互保险公司修改章程的批复（保监许可〔2014〕675号）

阳光农业相互保险公司：

你公司关于修改章程的请示及补充材料（阳光呈〔2014〕95号、103号）收悉。经审查，核准你公司2014年4月22日第三届会员代表大会第一次会议对章程进行的修改。请你公司依照有关规定办理变更事宜。

此复
