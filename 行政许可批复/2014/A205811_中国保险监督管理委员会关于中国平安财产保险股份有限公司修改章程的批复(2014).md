# 中国保险监督管理委员会关于中国平安财产保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中国平安财产保险股份有限公司修改章程的批复（保监许可〔2014〕189号）

中国平安财产保险股份有限公司：

你公司关于修改章程的请示（平保产发〔2014〕72号）收悉。经审查，核准你公司对章程附件股份结构表做出的以下修改：

**一、**股东“源信行投资有限公司”变更为“西藏林芝鼎方源投资顾问有限公司”。

**二、**股东“北京富泰华管理咨询有限公司”变更为“休宁新华资产投资管理有限公司”。

**三、**股东“深大电话有限公司”变更为“广东省电信实业集团公司”。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年3月5日
