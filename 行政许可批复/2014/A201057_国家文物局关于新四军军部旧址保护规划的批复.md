# 国家文物局关于新四军军部旧址保护规划的批复

## 国家文物局关于新四军军部旧址保护规划的批复（文物保函〔2014〕2194号）

安徽省文物局：

你局《关于请求审批＜新四军军部旧址文物保护规划＞的请示》（皖文物保[2013]223号）收悉。经研究，我局批复如下：

**一、**原则同意所报新四军军部旧址保护规划。

**二、**对该规划提出以下修改意见：

（一）建议将概况介绍中的文物历史沿革等内容调整到规划说明或附件中。

（二）在现状评估部分，应将大会堂旧址门口石鼓墩、修械所等处的围墙纳入到相应评估对象中。

（三）保护区划部分

1.建设控制地带划为两类，各自的管理规定应分别表述。二类建设控制地带应尽量维持现有建筑高度，不宜调整为6米限高。

2.进一步调整修改保护区划管理规定，其中部分内容属于保护措施，应调整至保护措施章节。

（四）根据现状评估内容，充实有针对性的保护措施。

（五）补充安防、消防、技防等相关专项规划。

（六）进一步精简规划文本，补充完善规划图纸，如规划总图、道路总图和管理总图等。规划总图应准确反映各文物点之间的相互关系。

**三、**请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

**四、**请你局按照《国务院关于加强文化遗产保护的通知》的要求，将经我局备案的新四军军部旧址保护规划报请安徽省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

**五、**规划涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

此复。

国家文物局

2014年7月2日
