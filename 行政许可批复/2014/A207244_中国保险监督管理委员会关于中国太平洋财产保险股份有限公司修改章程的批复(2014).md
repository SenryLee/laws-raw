# 中国保险监督管理委员会关于中国太平洋财产保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中国太平洋财产保险股份有限公司修改章程的批复（保监许可〔2014〕79号）

中国太平洋财产保险股份有限公司：

你公司关于修改公司章程的请示（太保产〔2013〕267号）及补充材料收悉。经审查，核准你公司2013年第二次临时股东大会决议对章程做出的以下修改：

**一、**第六条修改为：公司注册资本为人民币18，000，000，000元，实收资本为人民币18，000，000，000元。

**二、**第十四条中公司经批准发行的股份总数修改为18，000，000，000 股。股权结构表中中国太平洋保险（集团）股份有限公司认购股份数修改为17，730，244，751股；申能（集团）有限公司认购股份数修改为84，013，664股；上海国有资产经营有限公司认购股份数修改为46，874，998股；上海海烟投资管理有限公司认购股份数修改为83，779，014股；云南红塔集团有限公司认购股份数修改为55，087，573股；合计认购股份数修改为18，000，000，000 股。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年1月21日
