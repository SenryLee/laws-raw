# 中国保险监督管理委员会关于中银保险有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中银保险有限公司修改章程的批复（保监许可〔2014〕854号）

中银保险有限公司：

你公司关于修改公司章程的请示（中银保险报〔2014〕167号）及补充材料收悉。经审查，核准你公司第四届董事会第一次会议决议对章程做出的以下修改：

**一、**第一章第三条修改为：名称和住所

本公司注册名称：中银保险有限公司

简称：中银保险

英文名称：Bank of China Insurance Company Limited.

简称：BOC INSURANCE

本公司住所：北京市西城区西单北大街110号西单汇大厦9、10、11层

**二、**第一章第四条修改为：注册资本和经营期限

本公司注册资本为人民币4，535，080，000.00元。本公司为永久存续的有限公司。

**三、**第一章第八条修改为：本公司股东表和股权结构表

|  |  |  |  |
| --- | --- | --- | --- |
| 股东名称 | 出资额 | 持股比例 | 备注 |
| 中国银行股份  有限公司 | 人民币  4，535，080，000.00元 | 100% | 无 |

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年10月14日
