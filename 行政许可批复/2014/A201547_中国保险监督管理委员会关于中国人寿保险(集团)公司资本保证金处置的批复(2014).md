# 中国保险监督管理委员会关于中国人寿保险(集团)公司资本保证金处置的批复(2014)

## 中国保险监督管理委员会关于中国人寿保险（集团）公司资本保证金处置的批复（保监许可〔2014〕534号）

中国人寿保险（集团）公司：

你公司《关于变更中国人寿保险（集团）公司资本保证金存款性质的请示》（国寿集团发〔2014〕65号）收悉。经审核，同意你公司变更存放于交通银行苏州分行营业部的9.2亿元人民币资本保证金存款性质，该存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保监会

2014年6月17日
