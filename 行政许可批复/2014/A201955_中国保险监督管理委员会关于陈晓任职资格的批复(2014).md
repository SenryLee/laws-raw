# 中国保险监督管理委员会关于陈晓任职资格的批复(2014)

## 中国保险监督管理委员会关于陈晓任职资格的批复（保监许可〔2014〕507号）

大众保险股份有限公司：

你公司关于陈晓任职资格核准的申请材料（大众保险〔2014〕96号）收悉。经审查，陈晓符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准其担任你公司董事和总经理的任职资格。

此复

中国保监会

2014年6月12日
