# 国家文物局关于青海明长城乐都段保护工程设计方案的批复

## 国家文物局关于青海明长城乐都段保护工程设计方案的批复（文物保函〔2014〕1587号）

青海省文化和新闻出版厅：

你厅《关于报送青海明长城乐都区段保护工程设计方案的请示》（青文新物〔2014〕31号）收悉。经研究，我局批复如下：

**一、**原则同意青海省境内明长城乐都段（一期）（长城认定编码：碾伯古城632123353102170015，碾线岭堡632123353102170006，碾木沟堡632123353102170005，那家庄堡632123353102170003，碾线岭烽火台632123353201170008，碾木沟烽火台632123353201170007，和那家庄烽火台632123353201170002）抢险加固工程设计方案。

**二、**对该方案提出如下修改意见：

（一）该抢险加固工程应以消除相关长城遗存结构稳定性病害为主要内容，以“最小干预”为基本原则，不宜按照《建筑抗震设计规范》提高两度设计保护措施，严格控制修缮范围。

（二）进一步细化相关长城遗存的残损及病害分析，补充对长城所处环境的分析和评估，规范现状勘察图纸，将残损及病害情况、现状照片等与现状勘察图纸标注相对应。

（三）补充玻璃纤维锚杆、钢筋锚杆、木锚杆加固措施的必要性和可行性分析，补充相关力学计算过程和结论，应尽可能减少锚杆加固的实施范围和工程量。如确需实施，在施工完成后，应对锚杆端头做隐蔽性处理。

（四）应尽量控制补夯、补砌措施的实施范围。如确需实施，应采用传统材料、形制和工艺，并采取适当方式进行标识。

（五）不宜大面积实施防风化渗透加固措施。

（六）不宜大面积实施植被剔除措施，避免造成新的安全隐患。

（七）进一步校核方案文本和图纸，规范图纸绘制，补充各墙体标高等关键技术指标，并应避免出现文本与图纸前后矛盾的情况。

**三、**请你厅指导有关单位，根据上述意见对所报方案进行修改、完善，经你局核准后实施。请加强施工监管，确保工程质量和文物、人员安全。

此复。

国家文物局

2014年6月9日
