# 中国保险监督管理委员会关于中融人寿保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中融人寿保险股份有限公司修改章程的批复（保监许可〔2014〕655号）

中融人寿保险股份有限公司：

你公司关于修改章程的请示（中融保报〔2014〕110号）及补充材料收悉。经审查，核准你公司2013年度股东大会决议对章程做出的以下修改：

**一、**第六条修改为：公司注册资本为人民币5亿元。

**二、**第二十一条修改为：公司经批准发行的普通股总数为5亿股。

**三、**第二十二条修改为：公司股份总数为500，000，000股，均为普通股，每股面值人民币1元。各股东持股数详见附件《股东名册》。
