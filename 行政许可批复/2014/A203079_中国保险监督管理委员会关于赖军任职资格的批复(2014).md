# 中国保险监督管理委员会关于赖军任职资格的批复(2014)

## 中国保险监督管理委员会关于赖军任职资格的批复（保监许可〔2014〕412号）

中华联合保险控股股份有限公司：

你公司《关于核准赖军中华联合保险控股股份有限公司副总经理任职资格的请示》（中华控股发〔2014〕50号）收悉。经审核，赖军符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准其担任你公司副总经理的任职资格。

此复

中国保监会

2014年5月15日
