# 中国保险监督管理委员会关于劳合社保险(中国)有限公司增加注册资本和修改章程的批复(2014)

## 中国保险监督管理委员会关于劳合社保险（中国）有限公司增加注册资本和修改章程的批复（保监许可〔2014〕803号）

劳合社保险（中国）有限公司：

你公司关于增加注册资本和修改章程的请示（劳合社〔2014〕158、159号）收悉。经研究，现批复如下：

**一、**批准你公司注册资本金从2.2亿元人民币变更为10亿元人民币。

**二、**批准你公司将章程第8.1条修改为“公司的投资总额和注册资本均为十亿元人民币（RMB1，000，000，000）”。

请你公司持此批复办理相关变更手续。

中国保监会

2014年9月23日
