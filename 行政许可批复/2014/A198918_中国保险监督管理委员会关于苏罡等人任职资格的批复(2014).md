# 中国保险监督管理委员会关于苏罡等人任职资格的批复(2014)

## 中国保险监督管理委员会关于苏罡等人任职资格的批复（保监许可〔2014〕770号）

中国太平洋人寿保险股份有限公司：

你公司《关于对苏罡等同志进行高级管理人员任职资格审核的请示》（太保寿〔2014〕224号）收悉。现批复如下：

**一、**根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准苏罡、周晓楠担任你公司副总经理的任职资格，核准崔顺心、王润东、李劲松担任你公司总经理助理的任职资格。

**二、**根据《保险公司总精算师管理办法》和《中国保监会关于加强人身保险公司总精算师管理的通知》的有关要求，经审查，核准陈秀娟担任你公司总精算师的任职资格。

中国保监会

2014年9月10日
