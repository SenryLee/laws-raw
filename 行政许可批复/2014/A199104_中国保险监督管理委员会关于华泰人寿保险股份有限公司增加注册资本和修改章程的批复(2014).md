# 中国保险监督管理委员会关于华泰人寿保险股份有限公司增加注册资本和修改章程的批复(2014)

## 中国保险监督管理委员会关于华泰人寿保险股份有限公司增加注册资本和修改章程的批复（保监许可〔2014〕760号）

华泰人寿保险股份有限公司：

你公司关于增加注册资本和修改章程的请示（华寿字〔2014〕172、174号）收悉。经研究，现批复如下：

**一、**批准你公司注册资本金从25.325亿元人民币变更为27.325亿元人民币。

**二、**批准你公司对章程进行如下修改：

1.章程第6条修改为“公司注册资本为人民币2，732，500，000元”。

2.章程第19条修改为“公司经批准发行的普通股总数为2，732，500，000股，占公司可发行普通股总数的百分之百（100%）”。

3.将章程附件中“股东名册（股份结构表）”中各股东的持股数额、股份所占比例作相应的调整，并将股东中国贵州茅台酒厂有限责任公司名称修改为“中国贵州茅台酒厂（集团）有限责任公司”。

请你公司持此批复办理相关变更手续。

中国保监会

2014年9月4日
