# 中国保险监督管理委员会关于中德安联人寿保险有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中德安联人寿保险有限公司修改章程的批复（监许可〔2014〕407号）

中德安联人寿保险有限公司：

你公司关于修改章程的申请材料（安联发〔2014〕038号）收悉。经研究，批准你公司将章程第四条修改为“本公司总部的营业场所为上海市浦东南路360号新上海国际大厦2楼A区、C区及37楼A区，38楼A区，或者根据董事会决议并经中国保监会批准，搬入任何其他地址。公司根据业务需要，逐步在保监会批准的区域内设立分公司、办事处或代理机构”。

请你公司持此批复办理有关变更手续。

此复

中国保监会

2014年5月13日
