# 中国银行业监督管理委员会关于中信银行李庆萍任职资格的批复(银监复[2014]418号)

## 中国银行业监督管理委员会关于中信银行李庆萍任职资格的批复（银监复[2014]418号）

中信银行：

你行《关于核准李庆萍行长任职资格的请示》（信银发〔2014〕983号）收悉。经审核，现批复如下：

**一、**核准李庆萍中信银行行长的任职资格。

**二、**你行应要求上述核准任职资格人员严格遵守中国银监会有关监管规定，并按要求及时报告履职情况。

**三、**你行应督促上述核准任职资格人员持续学习和掌握经济金融相关法律法规，熟悉任职岗位职责，忠实勤勉履职。

2014年7月2日
