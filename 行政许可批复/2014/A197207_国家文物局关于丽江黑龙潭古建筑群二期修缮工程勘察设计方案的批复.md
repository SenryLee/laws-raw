# 国家文物局关于丽江黑龙潭古建筑群二期修缮工程勘察设计方案的批复

## 国家文物局关于丽江黑龙潭古建筑群二期修缮工程勘察设计方案的批复（文物保函〔2014〕1318号）

云南省文物局：

你局《关于审批丽江黑龙潭古建筑群二期修缮工程勘察设计方案的请示》（云文物〔2014〕104号）收悉。经研究，我局批复如下：

**一、**原则同意所报黑龙潭古建筑群二期修缮勘察设计方案。

**二、**对该方案提出修改意见如下：

（一）勘察报告和修缮说明中应明确此次维修的对象范围为锁翠桥、五凤楼、龙神祠和得月楼文物建筑本体。

（二）修缮工程性质应为现状整修，须坚持“最小干预”原则，严格控制对文物本体不必要的干预。

（三）各单体建筑屋面维修说明应与总体工程做法说明相统一。

（四）进一步补充和完善修缮做法。揭瓦顺序应为自屋脊向下，局部揭顶可从翼角开始。盖瓦顺序为自下向上。建议采用石灰砂浆或石灰泥浆等传统材料砌筑基座条石。

（五）进一步细化墙体修缮工程做法。

（六）补充和完善施工设计图纸。修缮图纸应与勘察图纸分开编号，并在修缮图中标明修缮部位及修缮做法。重点单体建筑应放大比例尺，单独制图。

**三、**请你局指导有关单位，根据上述意见对所报方案进行修改、完善，经你局核准后实施。施工中应加强监督和管理，确保工程质量和文物、人员安全。

此复。

国家文物局

2014年6月9日
