# 国家文物局关于呈坎村古建筑群罗时根宅维修工程设计方案的批复

## 国家文物局关于呈坎村古建筑群罗时根宅维修工程设计方案的批复（文物保函〔2014〕885号）

安徽省文物局：

你局《关于审批呈坎村古建筑群罗时根宅维修工程设计方案的请示》（皖文物保〔2014〕167号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出以下完善意见：

（一）完善勘察部分：

1. 进一步补充地方传统工艺及建造做法的研究和说明，以保证维修后的传统乡土特色。

2. 具体说明砖、木、瓦等各材料构件的材质、规格要求，避免出现“相同材质”等表述；补充拟补配木构件的材质及含水率要求等；补充拟修复门、隔扇窗等的依据，补充拟恢复庑廊的设计依据。

3. 细化残损原因分析，完善残损评价及量化指标。

4. 补充虫害情况勘察，由专业部门协助制定相应的防治措施。

（二）完善部分维修措施：

1. 墙体裂缝灌浆加固应尽可能使用传统材料，并注意加固后缝隙外表面与原墙面的协调；

2. 补充梁、檩加固详图及天井恢复做法。

3. 补充细化墙体抹灰、室外院落排水系统、室内外地面铺装等的勘察及修缮做法。

（三）应结合该处民居建筑的特点，在明确其功能用途、展示利用方式的基础上，进一步完善维修方案设计，补充相关展示利用设计内容，并注意加强与保护规划、保护利用实施规划的协调，实现本体维修与展示利用的统筹考虑、有机结合。

（四）进一步补充、校核文本图纸。如，补充完善有关尺寸标注，补充现状图、设计图中梁架步架尺寸，以及瓦、椽望、地板等构件尺寸；修缮图纸名称不应为“修复图纸”等。

**三、**请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2014年5月30日
