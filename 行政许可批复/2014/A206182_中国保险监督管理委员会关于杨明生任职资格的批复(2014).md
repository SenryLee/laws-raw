# 中国保险监督管理委员会关于杨明生任职资格的批复(2014)

## 中国保险监督管理委员会关于杨明生任职资格的批复（保监许可〔2014〕150号）

中国人寿资产管理有限公司：

你公司《关于杨明生先生任职资格审核的请示》（国寿资发〔2013〕125号）收悉。经审核，杨明生符合《保险公司董事、监事和高级管理人员任职资格管理规定》和《保险资金运用管理暂行办法》的有关要求，核准杨明生担任你公司董事长的任职资格。

此复

中国保监会

2014年2月20日
