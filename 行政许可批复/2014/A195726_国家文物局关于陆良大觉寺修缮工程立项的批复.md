# 国家文物局关于陆良大觉寺修缮工程立项的批复

## 国家文物局关于陆良大觉寺修缮工程立项的批复（文物保函〔2014〕1834号）

云南省文物局：

你局《关于陆良大觉寺修缮工程立项的请示》（云文物〔2014〕58号）收悉。经研究，我局批复如下：

**一、**原则同意陆良大觉寺修缮工程立项。

**二、**在编制工程方案时，应注意以下方面：

（一）该工程属文物修缮工程，应遵循“不改变文物原状”、“最小干预”等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程内容和范围包括大雄宝殿（大殿）、天王殿（中殿）、山门殿（前殿）、文昌宫大殿、文昌宫后殿、凤山书院、钟楼、东厢房、西厢房、禅房、大觉寺塔（千佛塔）等十一处建筑和大觉寺常驻碑维修，以及保护范围内水、电等基础设施建设。

（三）加强现状勘察，查明拟修缮建筑具体残损及病害状况，制定有针对性的保护措施，尽可能多地保存建筑原状和所有历史信息。

（四）深入分析大觉寺塔倾斜、裂缝等成因，勘察沉降情况，提出相应保护措施。

（五）应制定科学详细的工程计划，分轻重缓急开展修缮工作，保证工程质量。

（六）明确拟修缮建筑的展示利用方式，并在方案设计中予以体现。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》，组织具有相应资质的专业单位编制　工程技术方案，并按照我局《关于印发〈全国重点文物保护单位文物保护工程申报审批管理办法（试行）〉通知》（文物保函〔2014〕64号）的要求履行相关审批程序。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

此复。

国家文物局

2014年6月6日
