# 国家文物局关于抚顺至通化高速公路清永陵建设控制地带内交警办公室和养护工区用房设计方案的批复

## 国家文物局关于抚顺至通化高速公路清永陵建设控制地带内交警办公室和养护工区用房设计方案的批复（文物保函〔2014〕325号）

辽宁省文物局：

你局《关于上报〈抚顺至通化高速公路清永陵建设控制地带内交警办公室和养护工区用房设计方案〉的请示》（辽文物保发〔2014〕2号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对所报方案提出完善意见如下：

（一）补充清永陵建设控制地带的管理规定。

（二）建议采用灰色为建筑主色调，并进一步弱化建筑的体量感和外观形式。

**三、**请你局组织有关单位，对所报方案进行修改、完善，经你局核准，按程序报有关部门批准后实施。

此复。

国家文物局

2014年4月16日
