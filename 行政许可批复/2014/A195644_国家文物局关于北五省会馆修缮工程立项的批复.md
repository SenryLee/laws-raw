# 国家文物局关于北五省会馆修缮工程立项的批复

## 国家文物局关于北五省会馆修缮工程立项的批复（文物保函〔2014〕1722号）

湖南省文物局：

你局《关于审批〈湖南省湘潭市北五省会馆修缮工程立项报告〉的请示》（湘文物报〔2014〕86号）收悉。经研究，我局批复如下：

**一、**同意北五省会馆修缮工程立项。

**二、**在编制工程方案时，应注意以下方面：

（一）该工程属文物修缮工程，应遵循“不改变文物原状”、“最小干预”等文物保护原则，保护文物的真实性和完整性。

（二）工程范围为山门、戏台、前殿、中殿（春秋阁）文物建筑。

（三）加强现状勘察，明确文物本体构成，查明拟修缮文物建筑具体残损及病害状况，分析病害产生的原因，制定有针对性的保护措施，保证工程质量。注意对琉璃瓦和脊饰的勘察，补配件要有具体构件要求。加强排水勘察及相关设计。

（四）加强对地方传统建筑营造工艺、材料和做法的勘察和研究总结，作为修缮设计的依据，并尽量按传统做法、传统工艺进行保养维护。

（五）对后期改造部分进行修复需补充设计依据。图纸需细化工程量标注。

（六）明确拟修缮建筑的用途和展示利用方式，并在方案设计中予以体现。

（七）细化经费估算，补充取费依据。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织具有相应资质的专业单位编制工程技术方案，委托我局认定的第三方咨询评估机构进行方案技术评审，并依据第三方咨询评估机构的评估结论进行审批。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

此复。

国家文物局

2014年6月6日
