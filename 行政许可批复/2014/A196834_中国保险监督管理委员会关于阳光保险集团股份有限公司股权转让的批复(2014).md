# 中国保险监督管理委员会关于阳光保险集团股份有限公司股权转让的批复(2014)

## 中国保险监督管理委员会关于阳光保险集团股份有限公司股权转让的批复（保监许可〔2014〕705号）

阳光保险集团股份有限公司：

你公司《关于公司股东转让股份的请示》（阳光保险〔2014〕28号）及相关补充材料收悉。经审核，同意深圳市神州通投资集团有限公司将持有的100，000，000股股份转让给广西德利投资集团有限公司。受让后，广西德利投资集团有限公司持有你公司100，000，000股股份，占总股本的1.49%；深圳市神州通投资集团有限公司持有你公司321，190，000股股份，占总股本的4.79%。

请你公司按照有关规定办理变更手续。

此复

中国保监会

2014年8月18日
