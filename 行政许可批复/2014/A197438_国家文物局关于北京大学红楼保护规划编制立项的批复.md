# 国家文物局关于北京大学红楼保护规划编制立项的批复

## 国家文物局关于北京大学红楼保护规划编制立项的批复（文物保函〔2014〕1799号）

北京市文物局：

你局《关于北京大学红楼保护规划立项的请示》（京文物〔2014〕573号）收悉。经研究，我局批复如下：

**一、**同意北京大学红楼保护规划编制立项。

**二、**在规划编制过程中，应注意以下问题：

（一）深化价值评估，特别是对文物建筑的历史价值和艺术价值的评估。

（二）应对文物建筑的残损状况进行准确评估，提出有针对性的保护措施。

（三）合理划定保护区划，严格控制文物建筑周边的建设项目，注意与北京市城市规划等相关规划的衔接。

（四）重视文物安防、消防、防雷、给排水等基础设施专项规划，确保文物安全。

（五）加强展示利用和管理规划。对文物使用单位进行规范管理，将文物保护与展示利用、爱国主义教育相结合。

**三、**请你局指导项目单位组织具有资质的规划编制单位，按照《国务院关于加强文化遗产保护的通知》、《全国重点文物保护单位保护规划编制审批办法》和《全国重点文物保护单位保护规划编制要求》的有关规定，做好北京大学红楼保护规划的编制工作。

**四、**规划编制完成并经你局初审同意后，请将规划文本、图纸及相应的电子文档等报我局审批。

此复。

国家文物局

2014年6月6日
