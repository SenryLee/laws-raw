# 中国银行业监督管理委员会关于兰州银行开办信用卡业务的批复

中国银行业监督管理委员会关于兰州银行开办信用卡业务的批复

（银监复[2014]306号）

兰州银行：

《兰州银行关于开办敦煌信用卡业务的请示》（兰银〔2014〕24号）收悉。经审核，现批复如下：

**一、**同意你行开办信用卡业务。

**二、**你行信用卡的发行和使用，应严格遵守《商业银行信用卡业务监督管理办法》等有关规定。

**三、**你行应加强信用卡业务管理，有效防范各类风险。

**四、**你行应定期向甘肃银监局报告信用卡业务经营管理情况。

2014年5月13日
