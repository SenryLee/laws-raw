# 中国证券监督管理委员会关于核准华西证券有限责任公司设立资产管理子公司的批复

## 中国证券监督管理委员会关于核准华西证券有限责任公司设立资产管理子公司的批复（证监许可〔2014〕620号）

华西证券有限责任公司：

你公司报送的《华西证券有限责任公司关于设立华西证券资产管理有限公司的请示》（华证〔2013〕422号）及相关文件收悉。根据《证券法》、《公司法》、《证券公司监督管理条例》、《证券公司业务范围审批暂行规定》（证监会公告〔2008〕42号）、《证券公司设立子公司试行规定》（证监会公告〔2012〕27号）等有关规定，经审核，现批复如下：

**一、**核准你公司设立华西证券资产管理有限公司（以下简称华西资管）。华西资管注册地为上海市，注册资本为人民币5亿元，业务范围为证券资产管理，股东名称及出资额、出资比例如下：

|  |  |  |
| --- | --- | --- |
| 股东名称 | 出资额（亿元） | 出资比例 |
| 华西证券有限责任公司 | 5 | 100% |

上述出资中，你公司的出资为现金出资。

**二、**我会对华西资管章程草案无异议。华西资管设立后，应当将股东制定的公司章程报住所地证监局核准。

**三、**你公司应当按照《公司法》、《证券法》、《证券公司监督管理条例》等法律、法规和有关规定的要求，完成华西资管组建工作，足额缴付出资，选举董事、监事，聘任高级管理人员。

**四、**核准你公司变更业务范围，减少证券资产管理业务。你公司应当认真落实证券资产管理业务了结计划安排和平稳处理现有客户相关事项的方案，做好证券资产管理业务清理和移交工作，平稳处理现有客户相关事项，确保客户合法权益不受损害，妥善安置员工，维护社会稳定。

**五、**你公司应当自本批复下发之日起6个月内完成工商变更登记和华西资管的工商设立登记工作，逾期未完成的，本批复自动失效。

你公司、华西资管应当自换领或取得营业执照之日起15日内，向我会申请换发或申请经营证券业务许可证。华西资管在取得经营证券业务许可证前，不得以该名称对外开展业务。

**六、**华西资管组建中如遇重大问题，须及时报告我会和你公司住所地、华西资管拟设地证监局。

中国证监会

2014年6月23日
