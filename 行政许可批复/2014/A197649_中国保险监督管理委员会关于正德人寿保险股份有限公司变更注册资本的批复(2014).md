# 中国保险监督管理委员会关于正德人寿保险股份有限公司变更注册资本的批复(2014)

## 中国保险监督管理委员会关于正德人寿保险股份有限公司变更注册资本的批复（2014）（保监许可〔2014〕888号）

正德人寿保险股份有限公司：

你公司关于变更注册资本的请示（正保发〔2014〕300号）及相关补充材料收悉。经审核，同意你公司注册资本变更为30亿元人民币。增资后，你公司股东持股数量和持股比例见附表。

请你公司按照有关规定办理变更手续。

此复

附表：正德人寿保险股份有限公司股权结构表（略）

中国保监会

2014年10月23日
