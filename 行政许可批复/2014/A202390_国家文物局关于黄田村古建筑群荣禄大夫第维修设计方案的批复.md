# 国家文物局关于黄田村古建筑群荣禄大夫第维修设计方案的批复

## 国家文物局关于黄田村古建筑群荣禄大夫第维修设计方案的批复（文物保函〔2014〕873号）

安徽省文物局：

你局《关于审批黄田村古建筑群荣禄大夫第维修设计方案的请示》（皖文物保〔2014〕165号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出以下完善意见：

（一）深化文物勘察：

1. 加强对建筑群原有形制、格局及地方传统工艺、建造做法的勘察、研究与保护，保证维修后的传统乡土特色。

2. 细化文物残损原因分析，制定有针对性的保护措施。补充文物残损及维修的量化说明。

3. 具体说明各材料构件的材质、规格，补充木材树种及含水率要求等。

4. 补充拟修复屏门、木窗等的依据。补充耳房恢复依据，若无充分依据，可做原址保护。

5. 补充院落排水系统、照壁地基下沉等问题的勘察、评估及相应治理措施。

（二）完善维修措施：

1. 进一步细化各项保护措施的具体做法和工艺要求。补充地面铺装形式说明，补充油灰三合土、灰浆的详细做法和配比说明。

2. 墙体裂缝修补等各项保护措施尽量采用传统材料和做法，不宜采用环氧树脂灌浆加固等现代工艺。

3. 建筑后窗全部封闭的做法不利于住户采光和日常使用，应补充说明与之相对应的规划要求并做相应调整。

4. 防虫防腐措施依据不足，应由具有相关资质的专业部门制定专项保护方案。

（三）应结合该处民居建筑的特点，在明确其功能用途、展示利用方式的基础上，进一步完善维修方案设计，补充相关展示利用设计内容，并注意加强与保护规划、保护利用实施规划的协调，实现本体维修与展示利用的统筹考虑、有机结合。

（四）完善设计文本和图纸。总平面图中应补充标高、尺寸标注，标明修缮范围；“修复图”的图纸名称不当，应予规范。

（五）进一步核定工程预算。

**三、**请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2014年5月31日
