# 中国保险监督管理委员会关于中再资产管理股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中再资产管理股份有限公司修改章程的批复（保监许可〔2014〕399号）

中再资产管理股份有限公司：

你公司关于修改章程的请示（中再资产发〔2014〕61号）收悉。经审查，核准你公司2013年度股东大会决议对章程做出的以下修改：

**一、**第十一条修改为：公司的注册资本为5亿元等值人民币。全部资本划分为等额股份，每股面值为人民币1元，股份总数为5亿股。

**二、**第十三条修改为：公司股份结构情况如下：

|  |  |  |
| --- | --- | --- |
| 股东名称 | 持有股份数（股） | 占总股本比例 |
| 中国再保险（集团）股份有限公司 | 350，000，000 | 70% |
| 中国大地财产保险股份有限公司 | 50，000，000 | 10% |
| 中国人寿再保险股份有限公司 | 50，000，000 | 10% |
| 中国财产再保险股份有限公司 | 50，000，000 | 10% |

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年5月7日
