# 中国保险监督管理委员会关于长城人寿保险股份有限公司股权转让的批复(2014)

## 中国保险监督管理委员会关于长城人寿保险股份有限公司股权转让的批复（保监许可〔2014〕676号）

长城人寿保险股份有限公司：

你公司《关于股东股权转让的请示》（长寿发〔2014〕126号）及相关补充材料收悉。经审核，同意北京庆云洲际科技有限公司将持有的194，444，444股股份转让给北京华融综合投资公司和北京金昊房地产开发有限公司。受让后，北京华融综合投资公司持有你公司347，631，858股股份，占总股本的19.64%；北京金昊房地产开发有限公司持有你公司326，912，586股股份，占总股本的18.47%；北京庆云洲际科技有限公司不再持有你公司股份。

请你公司按照有关规定办理变更手续。

此复

中国保监会

2014年8月1日
