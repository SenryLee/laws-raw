# 中国保险监督管理委员会关于张振堂任职资格的批复(保监许可[2014]787号)

## 中国保险监督管理委员会关于张振堂任职资格的批复（保监许可〔2014〕787号）

合众人寿保险股份有限公司：

你公司《关于张振堂任职资格审查的请示》（合保发〔2014〕438号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准张振堂担任你公司副总经理的任职资格。

此复

中国保监会

2014年9月15日
