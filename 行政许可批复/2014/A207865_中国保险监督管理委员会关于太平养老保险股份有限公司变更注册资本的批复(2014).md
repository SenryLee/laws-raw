# 中国保险监督管理委员会关于太平养老保险股份有限公司变更注册资本的批复(2014)

## 中国保险监督管理委员会关于太平养老保险股份有限公司变更注册资本的批复（保监许可〔2014〕26号）

太平养老保险股份有限公司：

你公司《关于增加注册资本金的请示》（太平养老〔2013〕221号）收悉。经审核，现批复如下：

**一、**同意你公司注册资本变更为2，000，000，000元人民币。增资后，中国太平保险控股有限公司持有1，999，800，000股，占比99.99%；龙璧工业区管理（深圳）有限公司持有200，000股，占比0.01%。

**二、**请你公司对公司章程作相应修改，并按照有关规定办理变更手续。

中国保监会

2014年1月7日
