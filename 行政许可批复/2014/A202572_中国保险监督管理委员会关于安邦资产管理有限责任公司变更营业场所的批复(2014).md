# 中国保险监督管理委员会关于安邦资产管理有限责任公司变更营业场所的批复(2014)

## 中国保险监督管理委员会关于安邦资产管理有限责任公司变更营业场所的批复（保监许可〔2014〕466号）

安邦资产管理有限责任公司：

你公司《关于变更经营场所的请示》（安邦资发〔2014〕19号）收悉。经审核，同意你公司营业场所由“北京市西城区平安里西大街28号楼11层01、09单元”变更为“北京市西城区金融街中心北楼金融大街9号写字楼5层501单元”。

请你公司按照有关规定，办理变更手续。

此复

中国保监会

2014年5月28日
