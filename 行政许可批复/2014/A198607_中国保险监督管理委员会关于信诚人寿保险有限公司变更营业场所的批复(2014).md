# 中国保险监督管理委员会关于信诚人寿保险有限公司变更营业场所的批复(2014)

## 中国保险监督管理委员会关于信诚人寿保险有限公司变更营业场所的批复（保监许可〔2014〕794号）

信诚人寿保险有限公司：

你公司关于变更营业场所的申请（信诚〔2014〕260号）收悉。经研究，批准你公司营业场所变更为“北京市朝阳区东三环中路1号环球金融中心办公楼东楼5层01、02、11－16号单元及16层01－10单元”。

请你公司持此批复办理有关变更手续。

此复

中国保监会

2014年9月18日
