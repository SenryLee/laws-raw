# 国家文物局关于明十三陵昭陵碑亭及明楼匾额修缮工程修改方案的批复

## 国家文物局关于明十三陵昭陵碑亭及明楼匾额修缮工程修改方案的批复（文物保函〔2014〕55号）

北京市文物局：

你局《关于明十三陵昭陵碑亭及明楼匾额修缮工程修改方案的请示》（京文物[2013]1278号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出意见如下：

（一）该工程应注意保存不同历史时期、具有历史价值的遗存。进一步细化碑亭现状勘察，明确病害原因并提出解决措施。

（二）补充匾额扫青贴金的做法说明，其做法应采用传统工艺和材料。

（三）进一步核准文字，补充工程概算。

**三、**请你局指导有关单位，根据上述意见对所报方案进行修改、完善，经你局核准后实施。施工中应加强监督和管理，确保工程质量和文物、人员安全。

此函复。

国家文物局

2014年1月15日
