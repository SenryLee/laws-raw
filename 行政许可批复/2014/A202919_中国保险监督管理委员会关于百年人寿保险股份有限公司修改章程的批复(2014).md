# 中国保险监督管理委员会关于百年人寿保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于百年人寿保险股份有限公司修改章程的批复（保监许可〔2014〕417号）

百年人寿保险股份有限公司：

你公司关于修改章程的请示（百保发〔2014〕192号）收悉。经审查，核准你公司2014年度股东大会决议对章程进行的以下修改：

**一、**第十七条第一款修改为：目前公司的股份总数为35.3亿股。公司发行的所有股份均为记名式人民币普通股，每股股票的票面金额为人民币壹元（RMB1.00元），由公司统一向股东出具持股证明。持股证明是公司签发的证明股东所持股份的合法有效凭证。

**二、**第十九条修改为：公司注册资本为35.3亿元人民币，公司注册资本为在公司登记机关登记的实收股本总额。
