# 中国保险监督管理委员会关于光大永明人寿保险有限公司变更注册资本的批复(2014)

## 中国保险监督管理委员会关于光大永明人寿保险有限公司变更注册资本的批复（保监许可〔2014〕702号）

光大永明人寿保险有限公司：

你公司《关于增加注册资本金有关事项的请示》（光保字〔2014〕200号）收悉。经审核，同意你公司注册资本变更为54亿元人民币。增资后，你公司股东出资额和出资比例见附表。

请你公司按照有关规定办理变更手续。

此复

附表：光大永明人寿保险有限公司股权结构表（略）

中国保监会

2014年8月13日
