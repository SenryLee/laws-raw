# 中国保险监督管理委员会关于华泰财产保险有限公司修改章程的批复(保监许可(2014)733号)

## 中国保险监督管理委员会关于华泰财产保险有限公司修改章程的批复（保监许可〔2014〕733号）

华泰财产保险有限公司：

你公司关于修改章程的请示（华财字〔2014〕331号）收悉。经审查，核准你公司2014年7月25日股东决定对章程做出的以下修改：

第三条修改为：公司住所为：上海市浦东新区康桥镇秀浦路68号1号楼五层F、G区。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年8月25日
