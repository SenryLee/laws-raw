# 中国保险监督管理委员会关于国泰财产保险有限责任公司资本保证金处置的批复(2014)

## 中国保险监督管理委员会关于国泰财产保险有限责任公司资本保证金处置的批复（保监许可〔2014〕819号）

国泰财产保险有限责任公司：

你公司《关于资本保证金处置的请示》及补正材料（国泰产险〔2014〕142号、238号）收悉。经审核，同意你公司变更存放于建设银行上海常熟路支行的700万美元资本保证金存款性质，该存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保监会

2014年9月29日
