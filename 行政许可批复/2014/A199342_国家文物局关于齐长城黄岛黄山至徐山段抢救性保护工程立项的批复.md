# 国家文物局关于齐长城黄岛黄山至徐山段抢救性保护工程立项的批复

## 国家文物局关于齐长城黄岛黄山至徐山段抢救性保护工程立项的批复（文物保函〔2014〕2509号）

山东省文物局：

你局《关于申请齐长城-黄岛黄山至徐山段抢救性保护工程立项的请示》（鲁文发[2014]522号）收悉。经研究，我局批复如下：

**一、**原则同意齐长城黄岛黄山至徐山段抢救性保护工程立项（长城认定编码：黄山段370284382101020013、报屋顶段370284382101020014、陡楼段370284382101020015、长城村段370284382101020016、扎营山段370211382105020003、东山村北山段370211382105020002、小珠山北山段370211382105020003、鹁鸽山段370211382105020004、徐山段370211382105020005）。

**二、**在编制工程技术方案时，应注意以下方面：

（一）该工程性质应定位为抢险加固工程。

（二）根据我局印发的《长城保护维修工作指导意见》，拟实施修缮的长城墙体长度原则上不超过3000延长米。鉴于此，该工程须根据相关长城保护状况，按照轻重缓急的原则，分段编制工程技术方案，并分阶段实施。

（三）应进行重点勘查和病害分析，并根据遗址残损情况，科学评估存在问题。

（四）该工程应遵循“不改变文物原状”和“最小干预”的原则，注意保存不同历史时期、具有历史价值的遗存。

（五）该工程应符合《齐长城遗址保护总体规划》相关要求。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》，组织具有相应资质的专业单位编制修缮工程技术方案，由你局初审同意后，报我局审批。

**四、**如需申请国家重点文物保护专项补助资金，请在修缮工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

此复。

国家文物局

2014年8月29日
