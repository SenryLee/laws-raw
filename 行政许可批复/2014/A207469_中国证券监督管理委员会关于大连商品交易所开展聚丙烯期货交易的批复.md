# 中国证券监督管理委员会关于大连商品交易所开展聚丙烯期货交易的批复

大连商品交易所：

你所《关于在大连商品交易所上市聚丙烯期货的请示》（大商所发〔2013〕141号）收悉。根据《期货交易管理条例》和《期货交易所管理办法》的有关规定，现批复如下：

**一、**同意你所组织聚丙烯期货交易。

**二、**聚丙烯期货合约具体挂牌时间在我会批复相关合约后，由你所根据市场状况及各项准备工作的进展情况确定。

请你所统筹安排，精心组织，加强沟通协调，完善监管制度和风险防范措施，制定应对预案，做好舆论引导工作，确保聚丙烯期货的顺利推出和平稳运行。

中国证监会

2014年1月15日
