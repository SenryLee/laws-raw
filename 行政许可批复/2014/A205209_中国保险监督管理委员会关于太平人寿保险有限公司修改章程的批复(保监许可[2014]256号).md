# 中国保险监督管理委员会关于太平人寿保险有限公司修改章程的批复(保监许可[2014]256号)

## 中国保险监督管理委员会关于太平人寿保险有限公司修改章程的批复（保监许可〔2014〕256号）

太平人寿保险有限公司：

你公司关于修改章程的请示（太平寿〔2014〕54号）收悉。经审查，核准你公司2014年股东会第一次临时会议特别决议对章程做出的以下修改：

**一、**第十三条修改为：公司注册资本：人民币100.3亿元。

**二、**第十五条中股东中国太平保险控股有限公司出资额修改为折合人民币75.3253亿元；股东金柏国际投资有限公司出资额修改为折合人民币12.48735亿元；股东荷兰富杰保险国际股份有限公司出资额修改为折合人民币12.48735亿元。

**三、**章程附件股权结构表修改为：

|  |  |  |
| --- | --- | --- |
| 股东名称 | 出资额（折人民币元） | 股权比例（%） |
| 中国太平保险控股有限公司 | 7，532，530，000.00元 | 75.10% |
| 金柏国际投资有限公司（Goldpark  International Investments Limited） | 1，248，735，000.00元 | 12.45% |
| 荷兰富杰保险国际股份有限公司（Ageas  Insurance International N.V.） | 1，248，735，000.00元 | 12.45% |
| 合计 | 10，030，000，000.00元 | 100% |

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年3月24日
