# 国家文物局关于丁氏故宅消防工程立项的批复

## 国家文物局关于丁氏故宅消防工程立项的批复（文物督函〔2014〕646号）

山东省文物局：

你局《关于申请丁氏故宅消防工程立项的请示》（鲁文发〔2014〕249号）收悉。经研究，我局批复如下：

**一、**同意丁氏故宅消防工程立项。

**二、**在工程方案编制过程中注意以下问题：

（一）要对工程涉及的每一座古建筑实施全面、详细勘察，明确现有消防设施现状，根据勘察情况，科学编制工程设计方案。

（二）根据丁氏故宅特点、所处环境、使用管理等情况，全面评估火灾风险，有针对性的选择适当、适度和有效的消防设施、设备。新建消防系统要与原有消防设施有机结合，避免重复建设、设备堆砌和防护过度。

（三）明确消防水源，合理测算消防用水量，充分论证自建消防水池的必要性；消防控制中心和泵房应充分利用现有建筑，如非必要，原则上不再新建。

（四）根据实际需求和工程规模合理编制工程概预算。

（五）明确工程实施中的文物保护要求和具体措施，消防设施建设、管线布设和设备安装方式等不得对文物本体及环境风貌造成破坏。

请你局督促指导建设单位依据文物保护、消防管理有关规定和标准要求，组织具有相应资质的设计单位编制工程方案，并按规定履行方案报批程序。

此复。

国家文物局

2014年5月12日
