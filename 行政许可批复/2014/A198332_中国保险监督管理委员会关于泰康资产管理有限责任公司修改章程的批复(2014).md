# 中国保险监督管理委员会关于泰康资产管理有限责任公司修改章程的批复(2014)

## 中国保险监督管理委员会关于泰康资产管理有限责任公司修改章程的批复（保监许可〔2014〕824号）

泰康资产管理有限责任公司：

你公司关于修改公司章程的请示（泰康资董发〔2014〕16号）及补充材料收悉。经审查，核准你公司2014年度第一次临时股东会决议对章程做出的以下修改：

**一、**第六条修改为：总经理为公司的法定代表人。

**二、**第八条修改为：公司章程原文本于2005年12月19日由公司股东会创立大会决议通过，以后历经修订。章程修改记录见本章程附件。本章程由公司股东会于2014年8月29日决议通过，并经有关国家主管机构批准后生效。本章程生效后即取代公司章程所有以前的文本。

本章程自生效之日起，即成为规范公司的组织与行为、公司与股东之间、股东与股东之间权利义务关系的具有法律约束力的文件，是确定公司与其他相关利益主体之间关系的基本规则以及保证这些规则得到具体执行的依据，对公司及其股东、董事和高级管理人员均有约束力。

**三、**第十一条修改为：公司股东各方为：

甲方：泰康人寿保险股份有限公司

住所：北京市复兴门内大街156号泰康人寿大厦

邮政编码：100031

法定代表人：陈东升

注册资本：2，852，197，070元人民币

经营范围：各类人民币、外币的人身保险业务，其中包括各类人寿保险、健康保险、意外伤害保险等保险业务；上述业务的再保险及共保业务；为境内外的保险机构代理保险、检验、理赔等业务；开展保险咨询业务；依照有关法规从事资金运用业务；经中国保监会批准的其他业务。

经营期限：持续经营

地税税务登记证号：110102100023816000

乙方：中诚信托有限责任公司

住所：北京市东城区安外大街2号

邮政编码：100013

法定代表人：邓红国

注册资本：2，456，666，700元人民币

经营范围：受托经营资金信托业务；受托经营动产、不动产及其他财产的信托业务；受托经营法律、行政法规允许从事的投资基金业务，作为投资基金或基金管理公司的发起人从事投资基金业务；受托经营公益信托业务；经营企业资产的重组、购并及项目融资、公司理财、财务顾问中介业务；受托经营国务院有关部门批准的国债、政策性银行债券、企业债券的承销业务；代理财产的管理、运用与处分；代保管业务；信用见证、资信调查及经济咨询业务；以银行存放、同业拆放、贷款、融资租赁或投资方式运用自有资金；以固有财产为他人提供担保；办理金融同业拆借业务。

经营期限：持续经营

地税税务登记证号：110101101219626000

**四、**第六十七条修改为：董事长行使下列职权：

（一）主持股东会；

（二）召集和主持董事会会议；

（三）督促、检查董事会决议的执行；

（四）签署董事会重要文件；

（五）董事会闭会期间，代表董事会监督公司管理层执行董事会决议的情况；

（六）向董事会提名管理层成员人选并对管理层成员的考核、报酬和奖惩事项提出意见；

（七）决定公司管理层成员的工作分工以及权限范围；

（八）决定公司员工的聘任、解聘、考核、报酬和奖惩事项；

（九）决定公司员工劳动、人事管理的有关事项；

（十）决定公司的具体规章；

（十一）签署公司发行的证券、重要合同和其他重要文件，或出具委托书委托其他代表签署该等文件；

（十二）决定公司的司法担保事项（即根据司法机关的要求并为公司利益而提供的担保），并在事后向股东会报告；

（十三）在发生特大自然灾害等不可抗力的紧急情况下，对公司事务行使符合法律规定和公司利益的特别处置权，并在事后向公司董事会和股东会报告；

（十四）公司章程或董事会授予的其他职权。

**五、**第一百一十六条修改为：公司管理层由公司首席执行官及由董事会任命的其他人员组成，负责公司日常经营管理的决策，由首席执行官领导工作。

**六、**第一百一十九条修改为：管理层下设投资管理委员会，由公司首席执行官、各专业投委会主席、资产管理部负责人等人员组成，负责自有资产和受托管理资产的战术性投资决策。

**七、**第一百二十条修改为：公司下设风险控制委员会，由公司董事长、首席执行官、首席投资官、首席风险官、财务负责人等人员组成。风险控制委员会制定和监督执行风险控制政策，负责公司投资全过程中的风险评估与防范，提出风险控制建议；制定控制投资风险的措施，并在市场发生重大变化的情况下，依据风险控制的要求对投资做出有效调整，从而降低投资风险，保证资产安全。

**八、**第一百二十一条修改为：公司高级管理人员包括董事长、首席执行官及由董事会任命的其他人员。

**九、**第一百二十二条修改为：非独立董事可受聘兼任公司高级管理人员。

**十、**第一百八十二条修改为：首席执行官对董事会负责，行使下列职权：

（一）行使法定代表人的职权；

（二）主持公司经营管理工作，组织实施董事会决议，向董事长和董事会报告工作；

（三）起草和组织实施公司年度经营计划和投资方案；

（四）组织落实公司管理层的决定；

（五）主持公司日常行政工作；

（六）负责协调子公司的日常经营管理；

（七）拟订公司内部管理机构设置方案；

（八）拟订公司的基本管理制度；

（九）拟订公司的具体规章；

（十）负责公司经营管理活动中向董事会、股东会提交的各项报告、方案、制度、规章、文件等的起草工作，在董事长批准后向董事会、股东会提交；

（十一）拟订公司管理层成员（首席执行官和董事会秘书除外）的经营考核指标、报酬和奖惩方案，在董事长批准后报董事会批准；

（十二）拟定聘任或者解聘除应由董事会决定聘任或者解聘以外的公司人员，以及上述人员的考核、报酬和奖惩事项；

（十三）拟定公司员工劳动、人事管理的有关事项；

（十四）在董事会授权范围内决定公司的其他事项；

（十五）公司章程、董事会或董事长授予的其他职权。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年9月30日
