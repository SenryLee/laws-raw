# 中国保险监督管理委员会关于中国再保险(集团)股份有限公司资本保证金处置的批复(2014)

## 中国保险监督管理委员会关于中国再保险（集团）股份有限公司资本保证金处置的批复（保监许可〔2014〕529号）

中国再保险（集团）股份有限公司：

你公司《关于中国再保险（集团）股份有限公司2亿元人民币资本保证金到期变更存款性质的请示》（中再发〔2014〕76号）收悉。经审核，同意你公司变更存放于招商银行北京大运村支行的2亿元人民币资本保证金存款的性质，该存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保监会

2014年6月17日
