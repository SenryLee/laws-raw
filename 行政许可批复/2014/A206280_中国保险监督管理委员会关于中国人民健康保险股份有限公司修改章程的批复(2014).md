# 中国保险监督管理委员会关于中国人民健康保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中国人民健康保险股份有限公司修改章程的批复（保监许可〔2014〕141号）

中国人民健康保险股份有限公司：

你公司关于修改章程的请示（人保健康发〔2014〕8号）收悉。经审查，核准你公司2013年第三次临时股东大会决议对章程做出的以下修改：

**一、**第十二条修改为：公司的注册资本为在公司登记机关登记的实收资本总额。公司的注册资本总额为人民币伍拾亿叁仟叁佰捌拾肆万壹仟肆佰陆拾柒元（RMB￥5，033，841，467），其中包括根据缴付日中国人民银行公布的基准汇率折算相当于人民币壹亿玖千万元（RMB￥190，000，000）的欧元。公司注册资本划分为等额股份，共伍拾亿叁仟叁佰捌拾肆万壹仟肆佰陆拾柒股，每股面值人民币壹元（RMB￥1），全部由股东认购。

**二、**第十三条第二款中公司股份结构表修改为：

|  |  |  |  |
| --- | --- | --- | --- |
| 股东名称 | 认购股份（股） | 持股比例 | 出资方式 |
| 中国人民保险集团股份有限公司 | 4，524，026，188 | 89.87% | 货币 |
| 首都机场集团公司 | 200，000，000 | 3.97% | 货币 |
| 德国健康保险股份公司（DKV Deutsche Krankenversicherung AG） | 190，000，000 | 3.78% | 货币 |
| 人保投资控股有限公司 | 119，815，279 | 2.38% | 货币 |

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年2月18日
