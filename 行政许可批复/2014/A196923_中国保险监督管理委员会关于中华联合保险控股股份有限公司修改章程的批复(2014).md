# 中国保险监督管理委员会关于中华联合保险控股股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中华联合保险控股股份有限公司修改章程的批复（保监许可〔2014〕700号）

中华联合保险控股股份有限公司：

你公司关于修改公司章程的请示（中华控股发〔2014〕94号）收悉。经审查，核准你公司2014年6月4日股东大会决议对章程做出的以下修改：

第十二条修改为：经国家保险监督管理部门及工商行政管理部门核准，公司的经营范围为：投资设立保险企业；监督管理控股投资企业的各种国内国际业务；国家法律法规允许的投资业务；与资金管理业务相关的咨询业务；经国家保险监督管理部门批准的其他业务。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年8月13日
