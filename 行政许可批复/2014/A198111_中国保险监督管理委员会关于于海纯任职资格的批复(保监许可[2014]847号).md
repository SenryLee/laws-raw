# 中国保险监督管理委员会关于于海纯任职资格的批复(保监许可[2014]847号)

## 中国保险监督管理委员会关于于海纯任职资格的批复（保监许可〔2014〕847号）

中华联合保险控股股份有限公司：

你公司《关于核准于海纯中华联合保险控股股份有限公司独立董事任职资格的请示》（中华控股发〔2014〕103号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》和《保险公司独立董事管理暂行办法》的有关要求，经审查，核准于海纯担任你公司独立董事的任职资格。

此复

中国保监会

2014年10月11日
