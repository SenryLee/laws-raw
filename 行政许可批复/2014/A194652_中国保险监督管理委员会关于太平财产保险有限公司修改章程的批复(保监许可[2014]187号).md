# 中国保险监督管理委员会关于太平财产保险有限公司修改章程的批复(保监许可[2014]187号)

## 中国保险监督管理委员会关于太平财产保险有限公司修改章程的批复（保监许可〔2014〕187号）

太平财产保险有限公司：

你公司关于修改章程的请示（太平财〔2014〕36号）收悉。经审查，核准你公司2013年第九次和第十次临时股东会决议对章程做出的以下修改：

**一、**第十一条修改为：公司注册资本：人民币4，070，000，000元。

**二、**第十二条修改为：股东的名称、出资方式及出资额如下：

股东名称：中国太平保险控股有限公司

出资方式：人民币或/和外汇现金

出资额：折合人民币4，069，593，000元

出资比例：99.99%

股东名称：龙璧工业区管理（深圳）有限公司

出资方式：人民币或/和外汇现金

出资额：折合人民币407，000元

出资比例：0.01%

**三、**第五十七条修改为：董事会下设立提名及薪酬委员会、审计委员会、风险管理委员会、投资决策委员会和发展规划委员会等五个专业委员会。

**四、**第五十八条修改为：提名及薪酬委员会、审计委员会、风险管理委员会、投资决策委员会和发展规划委员会分别由三名以上不在管理层任职的董事组成，委员会委员由董事长或三分之一以上董事提名，并由董事会以累计投票选举或更换。专业委员会主任委员由董事会在委员中选举产生。

**五、**公司章程附件股权结构表中中国太平保险控股有限公司出资额修改为4，069，593，000元；龙璧工业区管理（深圳）有限公司出资额修改为407，000元；合计出资额修改为4，070，000，000元。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年3月3日
