# 中国保险监督管理委员会关于汇丰人寿保险有限公司2014年度与汇丰人寿保险(国际)有限公司从事再保险关联交易的批复

## 中国保险监督管理委员会关于汇丰人寿保险有限公司2014年度与汇丰人寿保险（国际）有限公司从事再保险关联交易的批复（保监许可〔2014〕512号）

汇丰人寿保险有限公司：

《汇丰人寿保险有限公司关于2014年与关联企业汇丰人寿保险（国际）有限公司从事再保险分入业务的请示》（汇丰人寿发〔2013〕285号）及其补正材料收悉。经审核，同意你公司自批复之日起至2014年12月31日止与汇丰人寿保险（国际）有限公司从事再保险关联交易。

此复

中国保监会

2014年6月15日
