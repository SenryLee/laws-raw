# 国家文物局关于隆兴寺文物库房设计方案的批复

## 国家文物局关于隆兴寺文物库房设计方案的批复（文物保函〔2014〕1598号）

河北省文物局：

你局《关于正定文物库房设计方案的请示》（冀文物字〔2013〕365号）收悉，经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出以下修改完善意见：

（一）建议该库房设计应符合隆兴寺文物保护规划的要求，并根据入藏藏品的材质等特点，明确藏品保存环境需求。

（二）补充建筑内保温、部分库房通风、换气的相关设计内容。

（三）补充安防、消防等方面的设计内容。

（四）进一步明确建筑主体结构中梁、柱等的材质要求。

（五）该组建筑如无充分必要性和可行性，可不做彩画装饰。

请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局审核后实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2014年6月9日
