# 中国保险监督管理委员会关于中国人寿保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中国人寿保险股份有限公司修改章程的批复（保监许可〔2014〕568号）

中国人寿保险股份有限公司：

你公司关于修改公司章程的请示（国寿人险发〔2014〕330号）及补充材料收悉。经审查，核准你公司2013年度股东大会决议对章程做出的以下修改：

第一百二十三条修改为：公司设董事会，董事会由12名董事组成，设董事长1人，可以设副董事长1人。

董事会12名董事中，非执行董事至少1人且董事会成员中至少包括三分之一的独立董事。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年7月1日
