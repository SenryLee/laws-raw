# 中国保险监督管理委员会关于孙汉杰总精算师任职资格的批复(2014)

## 中国保险监督管理委员会关于孙汉杰总精算师任职资格的批复（保监许可〔2014〕519号）

中国平安人寿保险股份有限公司：

你公司《关于孙汉杰同志任职资格审查的请示》（平保寿发〔2014〕136号）收悉。经审核，孙汉杰符合《保险公司总精算师管理办法》和《中国保监会关于加强人身保险公司总精算师管理的通知》关于总精算师任职资格的有关要求，核准其总精算师的任职资格。

此复

中国保监会

2014年6月15日
