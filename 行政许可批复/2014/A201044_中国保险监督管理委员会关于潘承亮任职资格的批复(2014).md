# 中国保险监督管理委员会关于潘承亮任职资格的批复(2014)

## 中国保险监督管理委员会关于潘承亮任职资格的批复（保监许可〔2014〕569号）

长江财产保险股份有限公司：

你公司《关于潘承亮同志任职资格核准的请示》（长财险人〔2014〕90号）收悉。经审核，潘承亮符合《保险公司董事、监事和高级管理人员任职资格管理规定》和《保险公司内部审计指引（试行）》的有关要求，核准其担任你公司审计责任人的任职资格。

此复

中国保监会

2014年7月2日
