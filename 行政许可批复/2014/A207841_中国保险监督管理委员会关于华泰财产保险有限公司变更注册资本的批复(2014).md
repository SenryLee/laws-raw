# 中国保险监督管理委员会关于华泰财产保险有限公司变更注册资本的批复(2014)

## 中国保险监督管理委员会关于华泰财产保险有限公司变更注册资本的批复（保监许可〔2014〕24号）

华泰财产保险有限公司：

你公司《关于增加注册资本金的请示》（华财字〔2013〕356号）收悉。经审核，同意你公司注册资本变更为3，000，000，000元人民币。增资后，华泰保险集团股份有限公司出资额为3，000，000，000元，占比100%。

请你公司按照有关规定办理变更手续。

此复

中国保监会

2014年1月7日
