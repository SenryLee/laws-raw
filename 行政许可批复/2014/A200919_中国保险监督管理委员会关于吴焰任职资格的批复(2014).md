# 中国保险监督管理委员会关于吴焰任职资格的批复(2014)

## 中国保险监督管理委员会关于吴焰任职资格的批复（保监许可〔2014〕595号）

中国人民健康保险股份有限公司：

你公司《关于核准吴焰董事长任职资格的请示》（人保健康发〔2014〕187号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准吴焰担任你公司董事长的任职资格。

此复

中国保监会

2014年7月7日
