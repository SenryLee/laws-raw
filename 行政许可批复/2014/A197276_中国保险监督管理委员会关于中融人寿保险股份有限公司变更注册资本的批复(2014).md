# 中国保险监督管理委员会关于中融人寿保险股份有限公司变更注册资本的批复(2014)

## 中国保险监督管理委员会关于中融人寿保险股份有限公司变更注册资本的批复（保监许可〔2014〕494号）

中融人寿保险股份有限公司：

《关于中融人寿保险股份有限公司增资扩股的请示》（中融保报〔2014〕39号）及相关补充材料收悉。经审核，同意你公司注册资本变更为5亿元人民币。增资后，你公司股东持股数量和持股比例见附表。

请你公司按照有关规定办理变更手续。

此复

附表：中融人寿保险股份有限公司股权结构表（略）
