# 中国保险监督管理委员会关于中国财产再保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中国财产再保险股份有限公司修改章程的批复（保监许可〔2014〕112号）

中国财产再保险股份有限公司：

你公司关于修改章程的请示（中再产险发〔2014〕9号）收悉。经审查，核准你公司2014年第一次临时股东大会决议对章程做出的以下修改：

**一、**第十条修改为：公司的注册资本为人民币95.3225亿元。全部资本划分为等额股份，每股面值为人民币1元，股份总数为95.3225亿股。

**二、**第十二条修改为：公司股份结构情况如下：

|  |  |  |
| --- | --- | --- |
| 股东名称 | 持有股份数（股） | 占总股本比例 |
| 中国再保险（集团）股份有限公司 | 9，532，234，308 | 99.9998% |
| 上海怡达科技投资有限责任公司 | 15，692 | 0.0002% |

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年1月30日
