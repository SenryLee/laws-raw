# 中国保险监督管理委员会关于安邦财产保险股份有限公司资本保证金处置的批复(2014)

## 中国保险监督管理委员会关于安邦财产保险股份有限公司资本保证金处置的批复（保监许可〔2014〕737号）

安邦财产保险股份有限公司：

你公司《安邦财险关于1.62亿元资本保证金存款处置的请示》及补正材料（安邦产险发〔2014〕166号、188号）收悉。经审核，同意你公司将以下三笔资本保证金存款到期后转存至中国农业银行广东分行金穗路支行：

**一、**存放于中国工商银行深圳南山支行的5000万元人民币资本保证金存款。

**二、**存放于中国建设银行深圳分行营业部的5000万元人民币资本保证金存款。

**三、**存放于中国农业银行深圳布吉支行的6200万元人民币资本保证金存款。

请你公司在资本保证金存款存妥后10个工作日内，将《资本保证金存款协议》原件和背书后的存单复印件报我会备案。

此复

中国保监会

2014年8月25日
