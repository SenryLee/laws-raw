# 中国银行业监督管理委员会关于江苏银行和上海国际信托开办江苏银行2014年第一期信贷资产证券化项目的批复

## 中国银行业监督管理委员会关于江苏银行和上海国际信托开办江苏银行2014年第一期信贷资产证券化项目的批复（银监复[2014]397号）

江苏银行、上海国际信托：

《江苏银行股份有限公司和上海国际信托有限公司关于开展江苏银行2014年第一期信贷资产证券化业务的请示》（苏银发〔2014〕98号）收悉。经审核，现批复如下：

**一、**同意江苏银行股份有限公司（简称江苏银行）作为发起机构，上海国际信托有限公司（简称上海国际信托）作为受托机构，中央国债登记结算有限责任公司作为证券登记、托管、结算机构，开办江苏银行2014年第一期信贷资产证券化项目，项目总规模不超过22.909亿元人民币。

**二、**江苏银行和上海国际信托在开办上述业务，应严格遵守《金融机构信贷资产证券化试点监督管理办法》等有关规定，真实有效地设立信托，建立健全制度机制，将信贷资产证券化业务风险管理纳入全面风险管理体系。不得将本项目证券进行再证券化。

**三、**江苏银行作为发起机构和贷款服务机构，应严格按照有关规定进行风险自留，足额计提资本，做好会计处理，严格按照有关法规要求和交易文件约定履行职责。

**四、**江苏银行和上海国际信托在开办上述业务过程中，应就资产支持证券的资产池基础信息、风险状况、律师和会计师事务所的尽职审查意见、评级方法以及内部信用增级安排等事项及时、真实、充分地向投资者披露，充分揭示相关风险可能对资产支持证券信用等级和本息偿付造成的影响，并持续做好资产支持证券存续期间的信息披露工作。

**五、**江苏银行和上海国际信托应严格按照有关法规要求，办理证券登记、托管、结算等相关事宜。

**六、**江苏银行和上海国际信托应及时向监管机构报告业务开办过程中的重大事项及风险问题。

2014年6月25日
