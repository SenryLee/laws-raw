# 国家文物局关于七星岩摩崖石刻抢险加固保护工程立项的批复

## 国家文物局关于七星岩摩崖石刻抢险加固保护工程立项的批复（文物保函〔2014〕694号）

广东省文物局：

你局《关于七星岩摩崖石刻抢险加固保护工程项目立项的请示》（粤文物请〔2013〕65号）收悉。经研究，我局批复如下：

**一、**原则同意七星岩摩崖石刻抢险加固保护工程立项。

**二、**在编制工程方案时，应注意以下方面：

（一）该工程属文物抢险加固工程，应以消除岩体稳定性病害为主要内容，遵循“不改变文物原状”、“最小干预”等原则，保护文物及其历史环境的真实性和完整性。

（二）制定具体实施计划，认真开展文物测绘、地质勘察、环境监测、试验论证等前期工作。深入开展文物现状勘察评估，明确病害原因、威胁程度和发展情况，制定有针对性的治理方案和保护措施。

（三）应重视对岩体裂隙和渗水的治理。

（四）做好以往开展的摩崖石刻保护工作的总结，为工程方案制定和工程实施提供参考。

（五）进一步核定工程预算。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织具有相应资质的专业单位编制工程技术方案，委托我局认定的第三方咨询评估机构进行方案技术评审，并依据第三方咨询评估机构的评估结论进行审批。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

此复。

国家文物局

2014年5月16日
