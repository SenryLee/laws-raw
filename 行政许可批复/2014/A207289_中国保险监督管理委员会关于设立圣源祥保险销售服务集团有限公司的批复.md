# 中国保险监督管理委员会关于设立圣源祥保险销售服务集团有限公司的批复

## 中国保险监督管理委员会关于设立圣源祥保险销售服务集团有限公司的批复（保监许可〔2014〕74号）

河北圣源祥保险经纪有限公司：

你公司《关于河北圣源祥保险经纪有限公司更名为圣源祥保险销售服务集团有限公司的请示》收悉。经审核，现批复如下：

**一、**同意你公司设立圣源祥保险销售服务集团有限公司。

**二、**公司注册资本：人民币1亿元。其中，石家庄圣源祥投资有限公司出资6000万元，圣源祥保险代理有限公司出资1000万元，陈二国出资1500万元，段彦玲、贺善镖、李勇、袁春兰、段建新各出资300万元。

**三、**公司经营区域：中华人民共和国行政辖区（不含港、澳、台）。

**四、**公司住所：河北省石家庄市新华区新华路199号华海商务中心13层。

**五、**公司可经营下列业务：以保险代理公司及其他保险中介企业为主的投资、管理；对集团内部企业的支持性服务；国家法律法规允许的投资业务；经中国保监会批准的其他业务。

**六、**核准陈二国的董事长兼总经理的任职资格。

**七、**你公司须持本批复到河北保监局领取《保险代理集团公司法人许可证》，办理有关工商登记手续，并就名称变更事宜及时予以公告。

**八、**公司应依法经营，并遵守国家有关法律、法规和中国保监会的有关规章和规范性文件，相关内容可登录中国保监会网站查询。

中国保监会

2014年1月20日
