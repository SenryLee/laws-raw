# 国家文物局关于碧霞宫文物保护规划编制立项的批复

## 国家文物局关于碧霞宫文物保护规划编制立项的批复（文物保函〔2014〕1423号）

河南省文物局：

你局《关于碧霞宫文物保护规划立项的请示》（豫文物〔2014〕7号）收悉。经研究，我局批复如下：

**一、**原则同意碧霞宫文物保护规划编制立项。

**二、**在规划编制过程中应注意以下问题：

（一）深化文物勘察，准确评估文物本体和环境面临的主要问题，提出有针对性的规划思路。

（二）合理划定保护区划范围，明确相关管理要求，保护文物及其环境风貌。

（三）强化展示利用和安消防等专项规划的内容。

（四）进一步细化工作计划，核定经费预算，补充取费依据。

**三、**请你局指导当地人民政府组织具有资质的规划编制单位，按照《国务院关于加强文化遗产保护的通知》、《全国重点文物保护单位保护规划编制审批办法》和《全国重点文物保护单位保护规划编制要求》的有关规定，做好碧霞宫文物保护规划的编制工作。

**四、**规划编制完成并经你局初审同意后，请将规划文本、图纸及相应的电子文档等报我局审批。

此复。

国家文物局

2014年6月6日
