# 国家文物局关于云冈石窟第3窟危岩体抢险加固工程立项的批复

## 国家文物局关于云冈石窟第3窟危岩体抢险加固工程立项的批复（文物保函〔2014〕1609号）

山西省文物局：

你局《关于申请云冈石窟第3窟危岩体抢险加固工程立项的请示》（晋文物〔2014〕79号）收悉。经研究，我局批复如下：

**一、**原则同意云冈石窟第3窟危岩体抢险加固工程立项。

**二、**在编制工程技术方案时，应注意以下方面：

（一）工程性质应定位为抢险加固工程。

（二）工程范围应为云冈石窟第3窟危岩体。

（三）应遵循“不改变文物原状”和“最小干预”的原则，严格控制工程干预范围。

（四）进一步论证加固拟采取的灌浆、锚杆加固和挂网支护等措施的可行性。

（五）进一步评估、分析渗水处理所采取的裂隙封堵、排水沟等措施的效果。

（六）补充防渗处理材料的选择标准等内容。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》，组织具有相应资质的专业单位编制修缮工程技术方案，由你局初审同意后，报我局审批。

**四、**如需申请国家重点文物保护专项补助资金，请在修缮工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

此复。

国家文物局

2014年6月9日
