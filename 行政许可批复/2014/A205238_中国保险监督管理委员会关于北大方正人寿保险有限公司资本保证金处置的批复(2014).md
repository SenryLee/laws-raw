# 中国保险监督管理委员会关于北大方正人寿保险有限公司资本保证金处置的批复(2014)

## 中国保险监督管理委员会关于北大方正人寿保险有限公司资本保证金处置的批复（保监许可〔2014〕243号）

北大方正人寿保险有限公司：

你公司《北大方正人寿关于资本保证金转存的请示》（北大方正人寿发〔2014〕71号）收悉。经审核，同意你公司将存放于中国光大银行上海分行浦东支行的550万美元资本保证金存款转存至广发银行上海分行营业部。

请你公司在资本保证金存款存妥后10个工作日内，将《资本保证金存款协议》原件和背书后的存单复印件报我会备案。

此复

中国保监会

2014年3月24日
