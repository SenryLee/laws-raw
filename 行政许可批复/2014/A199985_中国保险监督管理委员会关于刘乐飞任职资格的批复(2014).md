# 中国保险监督管理委员会关于刘乐飞任职资格的批复(2014)

## 中国保险监督管理委员会关于刘乐飞任职资格的批复（保监许可〔2014〕667号）

新华人寿保险股份有限公司：

你公司《关于刘乐飞先生任职资格审核的请示》（新保发〔2014〕175号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准刘乐飞担任你公司董事的任职资格。

此复

中国保监会

2014年7月30日
