# 国家文物局关于洛阳涧西苏式建筑群整体修缮保护工程立项的批复

## 国家文物局关于洛阳涧西苏式建筑群整体修缮保护工程立项的批复（文物保函〔2014〕1440号）

河南省文物局：

你局《关于涧西苏式建筑群整体修缮保护工程立项的请示》（豫文物〔2014〕119号）收悉。经研究，我局批复如下：

**一、**同意洛阳涧西苏式建筑群整体保护修缮工程立项

**二、**在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于保护修缮工程。

（二）该工程实施范围为洛阳涧西苏式建筑群建筑、街坊及各类附属设施文物本体。

（三）开展文物勘察测绘和文物保存现状评估，对各类残损进行深入描述和量化说明，并准确掌握病害根源。详细记录文物建筑原有形制、结构、材料和构造工艺，为制定合理的保护措施提供科学依据。。

（四）坚持“最小干预”原则，严格控制对文物本体不必要的干预。

（五）明确拟修缮文物建筑的功能和展示利用方式，并在方案设计中予以体现。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》，组织具有相应资质的专业单位编制工程技术方案，并按照我局《关于印发〈全国重点文物保护单位文物保护工程申报审批管理办法（试行）〉通知》（文物保函〔2014〕64号）的要求履行相关审批程序。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

**五、**请你局指导地方人民政府，抓紧组织编制洛阳涧西苏式建筑群文物保护规划，厘清文物保护与城市发展之间的关系，完善管理机构和制度，提高管理水平，为做好洛阳涧西苏式建筑群的整体保护发挥切实指导作用。

此复。

国家文物局

2014年6月6日
