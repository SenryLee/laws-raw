# 中国保险监督管理委员会关于刘川等人任职资格的批复

## 中国保险监督管理委员会关于刘川等人任职资格的批复（保监许可〔2014〕207号）

中德安联人寿保险有限公司：

你公司关于刘川等人任职资格核准的申请材料（安联发〔2014〕004号、005号、006号、007号、013号、021号）收悉。经审查，刘川、袁琳、顾春燕、林毅、魏宗元、宋杰符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准刘川担任你公司上海分公司副总经理的任职资格，核准袁琳担任你公司四川分公司总经理助理的任职资格，核准顾春燕担任你公司江苏分公司总经理助理的任职资格，核准林毅担任你公司山东分公司总经理助理的任职资格，核准魏宗元担任你公司上海分公司总经理的任职资格，核准宋杰担任你公司江苏分公司副总经理（主持工作）的任职资格。

此复

中国保监会

2014年3月6日
