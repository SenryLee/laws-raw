# 中国保险监督管理委员会关于中华联合保险控股股份有限公司变更业务范围的批复

## 中国保险监督管理委员会关于中华联合保险控股股份有限公司变更业务范围的批复（保监许可〔2014〕620号）

中华联合保险控股股份有限公司：

你公司《关于经营范围增加咨询类业务的请示》（中华控股发〔2014〕53号）收悉。经研究，同意你公司在业务范围中增加“与资金管理业务相关的咨询业务”，业务范围变更为：投资设立保险企业；监督管理控股投资企业的各种国内国际业务；国家法律法规允许的投资业务；与资金管理业务相关的咨询业务；经中国保监会批准的其他业务。

请你公司按照有关规定办理变更手续。

此复

中国保监会

2014年7月15日
