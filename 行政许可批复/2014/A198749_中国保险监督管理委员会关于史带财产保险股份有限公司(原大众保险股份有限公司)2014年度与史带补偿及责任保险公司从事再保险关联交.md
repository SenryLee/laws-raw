# 中国保险监督管理委员会关于史带财产保险股份有限公司(原大众保险股份有限公司)2014年度与史带补偿及责任保险公司从事再保险关联交易的批复

## 中国保险监督管理委员会关于史带财产保险股份有限公司（原大众保险股份有限公司）2014年度与史带补偿及责任保险公司从事再保险关联交易的批复（保监许可〔2014〕784号）

史带财产保险股份有限公司：

你公司《关于大众保险股份有限公司与史带补偿及责任保险公司从事关联交易的请示》（大众保险〔2014〕250号）收悉。经审核，同意你公司自批复之日起至2014年12月31日止与史带补偿及责任保险公司从事再保险关联交易。

此复

中国保监会

2014年9月15日
