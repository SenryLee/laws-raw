# 中国保险监督管理委员会关于安华农业保险股份有限公司变更注册资本的批复(2014)

## 中国保险监督管理委员会关于安华农业保险股份有限公司变更注册资本的批复（保监许可〔2014〕902号）

安华农业保险股份有限公司：

《安华农业保险关于增加注册资本的请示》（安农险字〔2014〕103号）及相关补充材料收悉。经审核，同意你公司注册资本变更为10.575亿元人民币。增资后，你公司股东持股数量和持股比例见附表。

请你公司按照有关规定办理变更手续。
