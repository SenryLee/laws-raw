# 农业部关于变更广东省渔业捕捞许可签发人的批复(2014)

## 农业部关于变更广东省渔业捕捞许可签发人的批复（农渔发[2014]18号）

广东省海洋与渔业局：

你局《关于变更渔业捕捞许可签发人的请示》（粤海渔[2014]35号）收悉。经研究，同意将广东省渔业捕捞许可签发人变更为杨文葵，有效期至2015年12月31日。陈文的渔业捕捞许可签发人资格自发文之日起终止。

特此批复。

农业部

2014年4月10日
