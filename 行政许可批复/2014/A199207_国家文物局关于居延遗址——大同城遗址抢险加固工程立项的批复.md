# 国家文物局关于居延遗址——大同城遗址抢险加固工程立项的批复

## 国家文物局关于居延遗址--大同城遗址抢险加固工程立项的批复（文物保函〔2014〕2565号）

内蒙古自治区文物局：

你局《关于内蒙古阿拉善盟额济纳旗大同城遗址抢险加固维修工程立项的请示》（内文物发〔2014〕7号）收悉。经研究，我局批复如下：

**一、**原则同意大同城遗址内城城墙抢险加固工程立项和你局意见。

**二、**在编制工程方案时，应注意以下方面：

（一）应突出工程的抢险性质，仅对存在结构稳定性问题的内城城墙进行必要加固，并严格控制施工范围和强度。

（二）应进一步加强考古资料梳理和现状勘察，明确城墙的建造工艺、病害成因及分布范围等，为科学制定保护措施提供依据。

（三）应坚持最小干预原则，尽量采用物理加固措施和传统工艺做法，严格控制化学试剂的使用范围。同时，应明确内城墙本体监测的具体措施、技术要求和数据管理内容，严格控制监测器材的布设数量，避免过度监测。

（四）暂不同意开展外城墙和护城河遗迹加固、风沙侵蚀区域治理和环境监测项目，应在科学评估内城墙抢险加固工程实施效果基础上，进一步说明上述措施的必要性和可行性，另行编制立项报告，并按程序报批。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织具有相应资质的专业单位编制工程技术方案，委托我局认定的第三方咨询评估机构进行方案技术评审，并依据第三方咨询评估机构的评估结论进行审批。

**四、**如需申请国家重点文物保护专项补助资金，请在工程技术方案批复后，按照预算编制的相关规范要求，编制工程预算按程序报批。

**五、**请你局指导地方人民政府切实做好大同城遗址保护工作，加强专门管理机构建设、日常巡查和看护，确保文物安全。

此复。

国家文物局

2014年9月2日
