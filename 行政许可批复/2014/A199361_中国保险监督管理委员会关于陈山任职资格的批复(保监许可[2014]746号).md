# 中国保险监督管理委员会关于陈山任职资格的批复(保监许可[2014]746号)

## 中国保险监督管理委员会关于陈山任职资格的批复（保监许可〔2014〕746号）

北部湾财产保险股份有限公司：

你公司《关于核准陈山财务负责人任职资格的请示》（北保报〔2014〕155号）收悉。经审查，陈山符合《保险公司财务负责人任职资格管理规定》的有关要求，核准其财务负责人的任职资格。

此复

中国保监会

2014年8月29日
