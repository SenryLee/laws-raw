# 国家文物局关于大足石刻北山摩崖造像多基线数字近景摄影测绘项目立项的批复

## 国家文物局关于大足石刻北山摩崖造像多基线数字近景摄影测绘项目立项的批复（文物保函〔2014〕1600号）

重庆市文物局：

你局《关于大足石刻北山摩崖造像多基线数字近景摄影测绘立项的请示》（渝文物〔2014〕75号）收悉。经研究，我局批复如下：

**一、**原则同意大足石刻北山摩崖造像多基线数字近景摄影测绘项目立项。

**二、**在编制项目方案时，应注意以下方面：

（一）建议结合近景摄影工作，考虑对北山摩崖造像开展全面调查和评估，详细记录各个石窟的现状和存在问题，为下一步全面开展文物保护工作积累资料。

（二）尽可能降低测绘工作对文物本体和观众参观的干扰，提前做好有关预案和防护工作，确保文物和人员安全。

**三、**请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》，组织具有相应资质的专业单位进一步细化测绘项目方案，由你局初审同意后，报我局审批。

**四、**如需申请国家重点文物保护专项补助资金，请在测绘项目方案批复后，按照预算编制的相关规范要求，编制相关预算按程序报批。

此复。

国家文物局

2014年6月9日
