# 中国保险监督管理委员会关于华泰财产保险有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于华泰财产保险有限公司修改章程的批复（保监许可〔2014〕80号）

华泰财产保险有限公司：

你公司关于章程修改的请示（华财字〔2014〕12号）收悉。经审查，核准你公司对章程做出的以下修改：

**一、**第四条修改为：公司注册资本金为人民币3，000，000，000元。

**二、**第十三条修改为：股东的出资方式、出资额股东华泰保险集团股份有限公司以货币出资30亿元人民币，占公司注册资本的100%。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年1月21日
