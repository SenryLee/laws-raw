# 中国保险监督管理委员会关于生命人寿保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于生命人寿保险股份有限公司修改章程的批复（保监许可〔2014〕440号）

生命人寿保险股份有限公司：

你公司关于修改章程的请示（生保〔2014〕39号）及补正材料收悉。经审查，核准你公司2014年第一次临时股东大会决议对章程做出的以下修改：

**一、**第五十九条董事会执行委员会职权修改为：为提高公司决策效率，加强对公司及相关控股子公司的治理及管理，董事会设董事会执行委员会。董事会执行委员会受董事会委托在符合法律法规及本章程规定的前提下行使下列职权：

（1）统筹协调公司法人治理、重大决策、发展与改革、经营与管理以及公司股东大会、董事会等相关决策机构所作出的决策执行事宜；

（2）行使对公司及相关控股子公司的治理及管理职能；

（3）对公司及相关控股子公司的战略规划、治理与人才、督办监察等事项进行监控、评估、评价、考核、检查、调整、纠正及根据需要采取其他必要措施；

（4）对公司及相关控股子公司治理结构是否健全进行审查和评估，以保证财务报告、重大事项报告制度和内部控制等事项符合公司治理标准；

（5）决定公司内部管理机构的设置及岗位设置、人员编制和管理权限；

（6）决定及调整公司管理委员会委员人选，审批相关控股子公司总经理室成员的分工；

（7）根据公司股东大会、董事会审议通过的相关干部管理制度规定，决定公司及控股子公司相关干部的任免；

（8）审议批准公司计划和预算外且单笔金额不超过上年末总资产10%的重大资产买卖及重大投资等事项；

（9）听取公司及相关控股子公司治理及经营管理情况报告；

（10）根据授权或需要向董事会提交相关建议或报告；

（11）研究公司及相关控股子公司的设置方案，派至相关控股子公司的董事、监事及高级管理人员人选，听取相关派出人员的工作汇报；

（12）优化及完善公司及相关控股子公司不符合法律法规、监管规定以及不适当的规章制度及决定；

（13）对公司经营管理过程中违反法律法规以及股东大会、董事会及其执行委员会决议的行为进行纠正或处罚；

（14）在符合法律法规、监管规定及本章程相关规定的前提下，董事会执行委员会认为其他有必要审议或决策的事项；

（15）行使股东大会、董事会授予的其他职权。

**二、**第六十条第三款修改为：委员的任期与该届董事会的任期一致。各委员的工作分工安排由主任委员拟定方案后报董事会执行委员会审批。

**三、**第六十一条董事会执行委员会日常工作机构修改为：董事会执行委员会根据需要可设置战略规划、治理与人才、督办监察等日常工作机构，协助其履行相应职权。

**四、**第六十三条管理委员会职权修改为：

为统筹公司及控股子公司经营管理，提升管理效率，公司设立管理委员会。管理委员会根据董事会及其执行委员会授权在符合法律法规及本章程规定的前提下行使下列职权：

（1）行使对公司及相关控股子公司的经营管理职能；

（2）统筹管理公司及控股子公司内部的计划预算、企划督导、资产管理、人事管理、信息营运、财务资金、行政品牌、综合事务、风控合规、审计稽核等经营管理事务，加强公司及控股子公司内部的业务协同和资源共享；

（3）对相关控股子公司的内部管理机构的设置及岗位设置、人员编制和管理权限，以及对公司及相关控股子公司的经营管理制度及流程、经营管理过程及结果等事项进行监控、评估、评价、考核、检查、调整、纠正及根据需要采取其他必要措施；

（4）根据公司股东大会、董事会及其执行委员会审议通过的相关干部管理制度规定，批准或核准公司及控股子公司相关管理干部的任免；

（5）审议批准公司的重大制度，但有关法律法规、监管规定应由公司股东大会、董事会审议批准的制度除外；

（6）组织实施公司年度投资计划及资产配置方案；

（7）研究公司及相关控股子公司的重大经营决策，并向董事会及其执行委员会提出建议；前述“重大经营决策”包括公司的发展战略、经营方针、重大资产购置及对外投资、重要人事任免等事项；

（8）负责公司及相关控股子公司日常重大经营管理活动的监控，听取相关人员对公司及相关控股子公司日常重大经营管理情况的工作汇报；

（9）听取公司相关职能部门和人员就有关监管机构对公司及相关控股子公司监管意见的汇报，研究相关整改措施；

（10）行使股东大会、董事会及其执行委员会授予的其他职权。

**五、**第六十四条管理委员会的组成及产生修改为：管理委员会由五至七名委员组成，具体人数由董事会执行委员会根据公司实际情况决定。管理委员会委员可由公司董事及总经理助理（含）以上人员担任。

管理委员会设主任一名，副主任若干名。主任、副主任及其他委员由董事会执行委员会主任委员或任何两名委员提名，经董事会执行委员会全体委员过半数通过后产生。管理委员会委员的分工由其主任拟定方案后报董事会执行委员会审批。

管理委员会对董事会及其执行委员会负责，并向其报告工作。

董事会执行委员会可根据考核情况或需要对管理委员会委员进行调整。

**六、**第六十五条管理委员会工作细则修改为：管理委员会应制定完善的工作细则，并报董事会执行委员会审议批准。

**七、**删除第六十六条，其后顺延。

**八、**第六十六条（原第六十七条）公司管理组织架构修改为：为加强对控股子公司的管理，促进控股子公司规范运作、健康发展，公司管理组织架构应当兼顾寿险业务管理和对相关控股子公司的管理。

为明确对控股子公司的管理模式，规范管理流程，公司应制定控股子公司管理制度。

**九、**第六十七条（原第六十八条）寿险总经理室修改为：

公司设寿险总经理室，在公司管理组织架构下负责寿险业务日常经营管理活动。

寿险总经理室应制定完善的工作细则，并报管理委员会审议批准。

**十、**第一百一十条（原第一百一十一条）关联交易批准修改为：公司应按照法律法规、监管规定和本章程制定关联交易管理制度，并由股东大会审议通过。

公司股东大会、董事会及其他关联交易审批机构应当按照监管制度、本章程及公司关联交易管理制度的规定对关联交易进行审议批准。对关联交易进行表决或作出决定时，关联股东、关联董事及相关关联方应予以回避，但相关法律法规另有规定的除外。

独立董事应当对重大关联交易的公允性、内部审查程序执行情况以及对被保险人权益的影响进行审查。

**十一、**第一百一十一条（原第一百一十二条）关联交易审计和报告修改为：公司应当每年至少组织一次关联交易专项审计，并将审计结果报董事会和监事会。董事会应当每年向股东大会报告关联交易情况和关联交易管理制度执行情况。

请你公司依照有关规定办理变更事宜。
