# 中国保险监督管理委员会关于英国保柏金融公众有限公司北京代表处更换首席代表的批复(2014)

## 中国保险监督管理委员会关于英国保柏金融公众有限公司北京代表处更换首席代表的批复（保监许可〔2014〕643号）

英国保柏金融公众有限公司：

你公司关于更换北京代表处首席代表的申请材料收悉。经研究，批准张岫屏接替郑红担任英国保柏金融公众有限公司北京代表处首席代表。

此复

中国保监会

2014年7月22日
