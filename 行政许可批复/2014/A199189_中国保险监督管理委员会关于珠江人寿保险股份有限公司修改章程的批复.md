# 中国保险监督管理委员会关于珠江人寿保险股份有限公司修改章程的批复

## 中国保险监督管理委员会关于珠江人寿保险股份有限公司修改章程的批复（保监许可〔2014〕752号）

珠江人寿保险股份有限公司：

你公司《关于修改公司章程的请示》（珠寿发〔2014〕244号）及补充材料收悉。经审查，核准你公司2014年2月24日股东大会决议对章程做出的以下修改：

**一、**第五条修改为：公司注册资本为人民币13.5亿元整。

**二、**第六条修改为：公司股份总数13.5亿股，全部为普通股，每股面值为人民币壹元。

**三、**第十五条修改为：目前公司总股本为13.5亿股，公司股份结构见下表。公司股份结构表：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额（亿元） | 持股数量（亿股） | 持股比例（%） |
| 1 | 广东珠江投资控股集团有限公司 | 2.7 | 2.7 | 20 |
| 2 | 广东新南方集团有限公司 | 2.7 | 2.7 | 20 |
| 3 | 广东韩建投资有限公司 | 2.7 | 2.7 | 20 |
| 4 | 广州金融控股集团有限公司 | 2.7 | 2.7 | 20 |
| 5 | 广东珠光集团有限公司 | 1.5 | 1.5 | 11.11 |
| 6 | 广东粤财信托有限公司 | 1.2 | 1.2 | 8.89 |
| 合计 | | 13.5 | 13.5 | 100 |

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年9月2日
