# 中国保险监督管理委员会关于三星财产保险(中国)有限公司变更营业场所的批复(2014)

## 中国保险监督管理委员会关于三星财产保险（中国）有限公司变更营业场所的批复（保监许可〔2014〕174号）

三星财产保险（中国）有限公司：

你公司关于变更营业场所的申请材料（三星保发〔2014〕031号）收悉。经研究，批准你公司营业场所变更为“上海市虹桥路1438号20层01－04单元”。

请你公司按有关规定办理相应变更手续。

此复

中国保监会

2014年2月28日
