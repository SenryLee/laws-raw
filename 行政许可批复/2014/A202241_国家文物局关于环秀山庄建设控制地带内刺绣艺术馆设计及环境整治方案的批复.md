# 国家文物局关于环秀山庄建设控制地带内刺绣艺术馆设计及环境整治方案的批复

## 国家文物局关于环秀山庄建设控制地带内刺绣艺术馆设计及环境整治方案的批复（文物保函〔2014〕1178号）

江苏省文物局：

你局《关于审批环秀山庄建设控制地带内刺绣艺术馆设计及环境整治方案的请示》（苏文物保〔2014〕18号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**应进一步论证地下室开挖对环秀山庄、海棠亭及周边假山、树木的影响，并制订妥善的基坑围护止水方案、保护措施、沉降监测预警方案和应急预案。如无绝对把握，地下室应适当增加退让距离。

**三、**建议进一步细化完善方案设计，如避免大面积使用玻璃幕，檐口与墙体的细部交接关系可适当参考文物建筑做法等，使新建建筑整体风貌与环秀山庄、王鳌祠堂相协调。

**四、**建议进一步细化完善主入口车行空间设计。

请你局组织有关单位，根据上述意见对所报方案进行修改、完善，经你局核准后报有关部门批准实施。

此复。

国家文物局

2014年6月3日
