# 中国保险监督管理委员会关于招商信诺人寿保险有限公司变更注册资本的批复(2014)

## 中国保险监督管理委员会关于招商信诺人寿保险有限公司变更注册资本的批复（保监许可〔2014〕731号）

招商信诺人寿保险有限公司：

你公司关于增加注册资本的申请材料（招商信诺发〔2014〕199号）收悉。经研究，批准你公司注册资本从5亿元人民币变更为14.5亿元人民币。

请你公司持此批复办理有关变更手续。

此复

中国保监会

2014年8月22日
