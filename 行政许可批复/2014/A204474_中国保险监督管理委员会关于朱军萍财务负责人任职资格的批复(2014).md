# 中国保险监督管理委员会关于朱军萍财务负责人任职资格的批复(2014)

## 中国保险监督管理委员会关于朱军萍财务负责人任职资格的批复（保监许可〔2014〕319号）

中国大地财产保险股份有限公司：

你公司《关于审核朱军萍任职资格的请示》（大地财保发〔2014〕36号）收悉。经审查，朱军萍符合《保险公司财务负责人任职资格管理规定》的有关要求，核准其财务负责人的任职资格。

此复

中国保监会

2014年4月9日
