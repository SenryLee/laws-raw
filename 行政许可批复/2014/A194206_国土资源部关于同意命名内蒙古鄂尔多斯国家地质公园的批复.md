# 国土资源部关于同意命名内蒙古鄂尔多斯国家地质公园的批复

## 国土资源部关于同意命名内蒙古鄂尔多斯国家地质公园的批复（国土资函〔2014〕372号）

内蒙古自治区国土资源厅：

《关于内蒙古鄂尔多斯国家地质公园命名验收的请示》（内国土资发〔2014〕197号）收悉。部组织专家组对鄂尔多斯地质公园建设进行了实地验收，依据部相关文件要求及专家组验收意见，批复如下：

**一、**同意命名内蒙古鄂尔多斯国家地质公园。

**二、**内蒙古鄂尔多斯国家地质公园要遵循“在保护中开发，在开发中保护”的原则，做好园区内恐龙足迹化石、第四纪标准地层剖面、“河套人”古人类化石及活动遗址，以及河流、沙漠、湖泊地貌景观等地质遗迹资源的保护和开发利用，开展公众地学科普教育和科学研究，并按照国土资源部相关规定和国家地质公园建设指南要求，加强国家地质公园管理，完善国家地质公园建设，为促进地方资源、环境和经济的协调发展和生态文明建设做出贡献。

**三、**你厅要加强对内蒙古鄂尔多斯国家地质公园建设的指导，监督和检查地质公园及其主管部门按照国家相关法律规范开展各项活动。

2014年8月22日
