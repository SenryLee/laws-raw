# 中国保险监督管理委员会关于法国再保险公司北京分公司变更营业场所的批复(2014)

## 中国保险监督管理委员会关于法国再保险公司北京分公司变更营业场所的批复（保监许可〔2014〕870号）

法国再保险公司北京分公司：

你分公司关于变更营业场所的申请材料（法再北分行政〔2014〕第61号）收悉。经研究，批准你公司营业场所变更为“北京市朝阳区建国门外大街1号（一期）16号楼国贸写字楼1座12层05－06、15－20单元”。

请你公司按有关规定办理相应变更手续。

此复

中国保监会

2014年10月20日
