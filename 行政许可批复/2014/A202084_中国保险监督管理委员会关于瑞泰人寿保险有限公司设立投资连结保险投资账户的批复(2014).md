# 中国保险监督管理委员会关于瑞泰人寿保险有限公司设立投资连结保险投资账户的批复(2014)

## 中国保险监督管理委员会关于瑞泰人寿保险有限公司设立投资连结保险投资账户的批复（保监许可〔2014〕496号）

瑞泰人寿保险有限公司：

你公司《关于瑞泰人寿保险有限公司申请设立投资连结保险产品投资账户的请示》及相关补正材料（瑞泰人寿〔2014〕121号、149号）收悉。经研究，同意你公司设立家园稳健型投资账户和家园灵活型投资账户。

此复

中国保监会

2014年6月10日
