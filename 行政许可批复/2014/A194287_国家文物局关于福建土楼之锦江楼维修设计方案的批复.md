# 国家文物局关于福建土楼之锦江楼维修设计方案的批复

## 国家文物局关于福建土楼之锦江楼维修设计方案的批复（文物保函〔2014〕388号）

福建省文物局：

你局《关于报送全国重点文物保护单位福建土楼之锦江楼维修设计方案的请示》（闽文物字〔2013〕148号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出修改意见如下：

（一）进一步细化勘察。补充残损现状总体说明，核准病害类型及情况说明，明确屋面及墙体残损量，进一步核准残损记录表和图纸标注中的椽子规格等数据。补充勘察外环外檐墙开裂外闪情况，补充必要的基础和地基勘察报告，明确病害原因。

（二）应坚持不改变文物原状和最小干预的原则，进一步核准部分修缮措施。应按照当地传统做法解决屋面防排水问题，不应使用SBS卷材防水；夯土墙表面如无抹灰，不应铲除新做墙面抹灰，宜以现状保留为主；墙面不宜喷涂防水胶；屋面仅有雨渍而无其他问题的，宜现状保护。

（三）应注意保存不同历史时期、具有历史价值的遗存，尽可能利用原有构件，最大限度地保护遗产的真实性和完整性。木梁架、檩条、椽子、门窗、楼板、瓦材等建筑构件，应根据残损情况尽可能加以修补续用，避免大范围更换。

（四）外檐墙基础加固设计依据不足。应在明确外檐墙开裂歪闪原因的基础上，进一步论证基础加固采用加设钢筋混凝土圈梁和挑梁做法的必要性和合理性。如基础加固确有必要，应按照最小干预的原则选择加固措施，尽可能使用传统材料和工艺。

（五）补充细化部分修缮措施。细化说明墙体整体扶正和基础加固的工程措施、墙体裂缝灌黄泥石灰浆的材料比例和做法、外墙面抹灰做法、楼面保留部分与拆修部分的衔接做法、续用蚁蛀木构件的处理措施。

（六）补充说明防腐防虫处理的有效性。

（七）进一步补充完善相关设计图纸。现状与设计图中的墙体材质标注与维修做法不一致，应予核实；维修图纸应标注相关工程内容及范围。

**三、**请你局指导有关单位，根据上述意见对所报方案进行修改、完善，经你局核准后实施。施工中应加强监督和管理，确保工程质量和文物、人员安全。

此复。

国家文物局

2014年4月29日
