# 中国保险监督管理委员会关于中国人寿财产保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于中国人寿财产保险股份有限公司修改章程的批复（保监许可〔2014〕732号）

中国人寿财产保险股份有限公司：

你公司关于修改章程的请示（国寿财险发〔2014〕390号）收悉。经审查，核准你公司2014年第二次临时股东大会决议对章程进行的以下修改：

**一、**第五条修改为：公司注册资本为人民币一百五十亿元。

**二、**第十八条修改为：公司股份总数为一百五十亿股，全部为记名普通股，每股面值人民币一元。

**三、**第二十条修改为：公司股份结构表

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 股份总数 | 股东全称 | 持股数量（亿股） | 持股比例 | 备注 |
| 150亿股 | 中国人寿保险（集团）公司 | 90 | 60% | 2006年10月25日以现金方式出资认购公司股份6亿股；2008年6月13日以现金方式出资认购公司股份18亿股；2011年6月24日以现金方式出资认购公司股份24亿股；2014年6月11日以现金方式出资认购公司股份42亿股。 |
| 中国人寿保险股份有限公司 | 60 | 40% | 2006年10月26日以现金方式出资认购公司股份4亿股；2008年5月26日以现金方式出资认购公司股份12亿股；2011年6月24日以现金方式出资认购公司股份16亿股；2014年6月11日以现金方式出资认购公司股份28亿股。 |
