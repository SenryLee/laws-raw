# 中国保险监督管理委员会关于中国太平洋财产保险股份有限公司修改章程的批复(保监许可[2014]523号)

## 中国保险监督管理委员会关于中国太平洋财产保险股份有限公司修改章程的批复（保监许可〔2014〕523号）

中国太平洋财产保险股份有限公司：

你公司关于修改章程的请示（太保产〔2014〕93号）收悉。经审查，核准你公司2013年度股东大会决议对章程进行的以下修改：

第八十四条修改为：公司交纳所得税后的利润，按下列顺序分配：

1.弥补上一年度的亏损；

2.提取法定公积金；

3.提取总准备金；

4.提取农险利润准备金；

5.提取任意公积金；

6.支付股东股利。

公司法定公积金按照税后利润的百分之十提取，累计额为公司注册资本的百分之五十以上时，可以不再提取。提取法定公积金后，经股东大会决议，还可以从税后利润中提取任意公积金。

公司在弥补亏损和提取法定公积金之前，不向股东分配利润；公司依据财政机关规定提取的总准备金用于巨灾风险的补偿、农险利润准备金用于弥补农业大灾风险损失，不得用于股东利润分配、转增资本金。

公司偿付能力达不到监管要求时，不向股东分配利润。

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2014年6月16日
