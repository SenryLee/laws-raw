# 中国保险监督管理委员会关于利安人寿保险股份有限公司修改章程的批复(2014)

## 中国保险监督管理委员会关于利安人寿保险股份有限公司修改章程的批复（保监许可〔2014〕163号）

利安人寿保险股份有限公司：

你公司关于修改章程的请示（利保发〔2014〕10号）及补充材料收悉。经审查，核准你公司2014年第一次临时股东大会决议对章程做出的以下修改：

**一、**第十八条第二款修改为：公司注册资本金为人民币20亿元。

**二、**第十九条中“公司的股份总额为10亿股”修改为“公司的股份总额为20亿股”。
