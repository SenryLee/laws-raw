# 司法部关于取得法律职业资格证书C证的律师承办业务地域范围问题的批复

司复〔2018〕6号

贵州省司法厅：

你厅《关于持法律职业资格证书C证的执业律师执业范围有无限制问题的请示》（黔司呈〔2018〕5号）收悉。经研究，批复如下：

根据《律师法》第十条第二款规定，取得法律职业资格证书C证的律师承办业务不受地域限制，可以到本律师事务所所在的县（市、区）以外的地区办理业务。

此复。

司法部

2018年5月12日
