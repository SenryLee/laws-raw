# 国家文物局关于变更考古发掘资质证书的批复

文物保函〔2018〕498号

广东省文物局：

你局《关于变更广州市文物考古研究院考古发掘资质证书法定代表人的请示》（粤文物请〔2018〕10号）收悉。

经研究，我局同意变更广州市文物考古研究院考古发掘资质证书法定代表人为朱海仁，并更换《中华人民共和国考古发掘资质证书》。请你局通知有关单位，携原资质证书正、副本来我局办理更换手续。

国家文物局

2018年5月14日
