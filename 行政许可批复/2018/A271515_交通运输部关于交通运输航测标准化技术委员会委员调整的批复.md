# 交通运输部关于交通运输航测标准化技术委员会委员调整的批复

交科技函〔2018〕774号

交通运输测标准化技术委员会：

你委《关于申请调整航测标准化技术委员会委员的函》（航测标委〔2018〕4号）收悉。经研究，同意你委委员作以下调整：

一、解聘解曼莹副主任委员职务，解聘曾晖委员兼秘书长职务，解聘彭国均、李国成委员职务。

二、增补交通运输部水运局杨华雄为副主任委员，增补交通运输部海事局徐斌胜为委员兼秘书长，增补集美大学柯冉绚、天津海事局王欣、大连海事大学李颖、交通运输部天津水运工程科学研究院韩鸿胜为委员。

交通运输部
