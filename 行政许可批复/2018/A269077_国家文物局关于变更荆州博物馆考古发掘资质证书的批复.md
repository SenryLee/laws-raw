# 国家文物局关于变更荆州博物馆考古发掘资质证书的批复

文物保函〔2018〕1050号

湖北省文物局：

你局《关于变更荆州博物馆考古发掘资质证书的请示》（鄂文物〔2018〕35号）收悉。

经研究，我局同意变更荆州博物馆考古发掘资质证书法定代表人为王立静，并更换《中华人民共和国考古发掘资质证书》。请你局通知有关单位，携原资质证书正、副本来我局办理更换手续。

国家文物局

2018年8月29日
