# 国家文物局关于颐和园澄怀阁修缮项目的批复

文物保函〔2018〕1522号

北京市文物局：

你局《关于颐和园澄怀阁修缮工程方案的请示》（京文物〔2018〕1047号）收悉。经研究，我局原则同意所报颐和园澄怀阁修缮项目。

一、所报方案尚需作以下必要的修改和完善：

（一）应细化前期研究，补充澄怀阁的历史沿革、价值评估和历次修缮记录，突出与本次修缮直接相关的内容，为修缮设计提供依据。

（二）进一步完善现状勘察，量化残损程度，系统分析残损原因。补充勘察木望板铺设方式、原有铺地的材料及做法，明确现存水泥砖和花瓷砖的铺设时间；对料石驳岸歪闪和空洞、压面石和台帮变形、建筑西北角鼓闪、后檐台明石移位、大木构件拔榫、木挂檐板糟朽等情况，应加强现状勘察，补充残损位置、范围、量化数据和病因分析；补充湖水侵入造成西北侧檐柱下磉墩下沉的确实依据；补充后檐北侧墙体歪闪导致二层西廊北侧出现断裂通缝的依据，说明该部位的后檐墙与山墙之间的拉结情况；完善彩画现状勘察，说明1954年所绘彩画与原彩画的关系，规范彩画残损图纸表达。

（三）按照“最小干预”原则进一步细化保护措施，提高其针对性。砖石构件风化、碎裂而不影响结构或使用的，包括保存尚好的水泥砖等，宜现状保留；补充恢复方砖细墁地面、重做木楼板地面地仗油饰、采用锡背防水层的依据；补充说明外檐隔扇内侧做软硬博缝、室内装修恢复蓝绫子、重新烫蜡、恢复白樘箅子吊顶等措施的必要性和设计依据。

（四）进一步深化各类修缮措施说明。细化屋面做法，如望板铺设的做法说明；梁架产生拨榫的均应归安，露明构件不应采用两根U 形铁箍对梁箍扎的做法；应根据实际残损情况细化磉墩加固、驳岸石归安等隐蔽工程的修缮措施，宜采用传统材料和工艺；明确防腐、防虫、铁活防锈及刷漆的具体材料和操作方法；明确添配隔扇玻璃的材料要求。

（五）进一步论证所报彩画保护措施的必要性、依据，建议仅对彩画进行物理除尘，但不应采用莜面团进行除尘，不建议进行补绘、提色。

（六）进一步完善相关图纸，补充门窗、碧纱橱、隔扇、栏杆、楼梯、坐凳、倒挂楣子、挂檐等部位大样图，规范图面、标注以及专业术语表述。

（七）应明确展示利用功能定位，并结合后续功能需求，统筹考虑内装修、基础设施布线等相关设计。

二、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

三、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。施工中请加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

四、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

五、请你局切实加强管理，督促、指导相关单位做好保护后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

专此函复。

国家文物局

2018年12月4日
