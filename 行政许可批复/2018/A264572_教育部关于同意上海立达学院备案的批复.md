# 教育部关于同意上海立达学院备案的批复

教发函〔2018〕22号

上海市教育委员会：

《上海市教育委员会关于提请对以上海立达职业技术学院为基础组建上海立达学院予以备案的请示》（沪教委发〔2018〕64号）收悉。

根据《上海市人民政府关于同意以上海立达职业技术学院为基础组建上海立达学院的批复》（沪府〔2018〕19号）及《教育部关于对上海市拟实施教育综合改革试验有关问题意见的函》（教办函〔2003〕7号），经研究，同意对你市审批设立的上海立达学院（学校标识码为：4131012587）予以备案，首批设置财务管理、国际商务、产品设计、视觉传达设计、摄影等5个本科专业。同时建议你市撤销上海立达职业技术学院的建制。

专此。

教育部

2018年5月16日
