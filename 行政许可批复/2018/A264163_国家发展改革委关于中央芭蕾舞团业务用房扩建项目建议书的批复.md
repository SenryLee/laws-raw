# 国家发展改革委关于中央芭蕾舞团业务用房扩建项目建议书的批复

发改社会〔2018〕574号

文化和旅游部：

你部《关于报送中央芭蕾舞团业务用房扩建项目建议书的函》（文财务函〔2018〕39号）收悉。经研究，现批复如下：

一、原则同意所报中央芭蕾舞团业务用房扩建项目建议书。

二、项目总建筑面积按49433平方米控制，其中舞蹈业务用房14467平方米，交响乐团业务用房2807平方米，舞美业务用房6611平方米，合成排练场4534平方米，演员宿舍4213平方米，管理用房3185平方米，设备用房2540平方米，后勤保障用房1396平方米，地下车库及人防9680平方米。

三、项目总投资暂按87147万元控制，其中工程费用41219万元，其他费用4698万元，基本预备费3214万元，土地费用38016万元。全部由中央预算内投资解决。

四、请你部抓紧落实城市规划选址意见、土地预审、环境影响评价等相关手续，根据评审意见，进一步修改完善相关内容，并委托有资质的单位编写项目可行性研究报告，按程序报我委审批。

国家发展改革委

2018年4月16日
