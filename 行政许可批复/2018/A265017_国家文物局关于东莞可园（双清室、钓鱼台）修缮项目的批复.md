# 国家文物局关于东莞可园（双清室、钓鱼台）修缮项目的批复

文物保函〔2018〕576号

广东省文物局：

你局《关于全国重点文物保护单位东莞可园（双清室、钓鱼台）修缮工程勘察设计方案的请示》（粤文物审〔2018〕41号）收悉。经研究，我局批复如下：

一、原则同意东莞可园（双清室、钓鱼台）修缮项目和你局意见。

二、具体修改意见如下：

（一）完善现状勘察。补充说明并评估双清室在20世纪60年代及2002年的维修情况；细化分析钓鱼台的原有结构、材料和工艺，尽可能核实其原始地面做法。

（二）核实双清室吊顶的年代和价值，如属文物本体，且山墙通风口可基本满足梁架内部通风，则可不新设检修洞口；针对双清室屋顶木构件的虫蛀、糟朽等潜在病害，建议采取适当的应对技术措施。

（三）论证分析钓鱼台地面沉降、开裂与水土流失、不均匀沉降的关系，并采取针对性的应对措施。

（四）细化“铲除现有水泥砂浆地面重铺陶砖”的材料、规格、铺砌方法和构造技术要求等内容，补充必要的施工图。

（五）应结合对钓鱼台稳定性影响的评估结论，采取不同的植物根系处理措施。保留、出露的根系周边铺装宜随形设计。

三、具体方案由你局指导有关单位按照上述意见修改、完善，并经你局批准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2018年6月1日
