# 国家文物局关于云冈石窟第3窟危岩体加固项目的批复

文物保函〔2018〕251号

山西省文物局：

你局《关于审批云冈石窟第3窟危岩体加固工程设计方案的请示》（晋文物〔2017〕241号）收悉。经研究，我局批复如下：

一、原则同意云冈石窟第3窟危岩体加固项目和你局意见。

二、所报方案还须进一步修改、完善，主要意见如下：

（一）细化现状勘察。按照相关规范核实明确后室顶板50处危岩体划定的依据；进一步明确危岩体与周边岩体的空间关系和体量，论证危岩体破坏各结构面参数、稳定性计算模型及其参数选取的依据；补充评估暴雨情况下危岩体的稳定性；核实悬臂式危岩体稳定性计算应采用抗拉强度还是抗剪强度。

（二）严格控制工程规模和工程量，解决结构安全问题即可，避免过度干预。补充详细的工程量统计表。

（三）细化完善锚杆加固措施。应针对各危岩体的破坏模式、稳定程度深化锚固设计，明确各危岩体的锚固工程量、参数，注意持力层选择；应深化薄层危岩体锚杆的垫板设计和处理，必要时应核实岩体和垫板的抗剪强度，防止锚头对薄层岩体的冲切破坏。

（四）细化完善灌浆加固措施。明确裂缝粘结灌浆的质量检测指标；应在施工前进行粘结强度试验，并借鉴前期环氧树酯灌浆加固工程的经验，筛选浆质材料配合比和灌浆粘结工艺。

（五）补充细化其他加固设计及图纸。建议采用框架式结构进行预支撑；补充完善S-13至S-16图纸中支撑结构的详细说明，明确实施部位，论证其必要性和可靠性；明确拆除处理的具体做法及选择标准；补充暗梁设计详图，细化J19、J47暗梁支顶的材料及方法。

（六）核实设计说明，明确是否包括防渗排水治理内容。

（七）补充细化临时支撑结构顶部对文物本体的防护措施。补充施工过程中的安全监测，包括预支撑结构、锚杆、加固后岩体的受力和变形监测，优化方案中的监测内容及方法。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

国家文物局

2018年4月10日
