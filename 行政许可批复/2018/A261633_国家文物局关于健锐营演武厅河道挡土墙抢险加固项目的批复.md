# 国家文物局关于健锐营演武厅河道挡土墙抢险加固项目的批复

文物保函〔2018〕152号

北京市文物局：

你局《关于健锐营演武厅河道挡土墙抢险加固工程设计方案的请示》（京文物〔2017〕1764号）收悉。经研究，我局批复如下：

一、原则同意健锐营演武厅河道挡土墙抢险加固项目和你局意见。

二、具体修改意见如下：

（一）进一步细化现状勘察，加强健锐营演武厅与河道的关系说明。补充外侧挡土墙裂缝长度、深度、分布数量等标注；补充挡土墙本体及土体结合部位的剖面图；补充东、西河道挡土墙整体立面图和现状照片。

（二）对鼓闪、开裂严重的挡土墙，可采取择砌，不宜大面积拆除重砌，确实需要拆砌的，应做好临时支护措施；补充新砌挡土墙的相关数据；补充北岸拟恢复的毛石砌筑墙体的工程做法说明。

（三）建议对南岸挡土墙以南地面重点做好面层硬化、防渗和排水处理，不宜大范围开挖、扰动既有土体，并应明确地面排水走向；建议北岸5号段挡土墙以北重做的地面排水不宜向挡土墙方向排放，并应取消设置排水槽做法。

（四）补充拟在燃气表下部挡土墙增设牛腿支护的必要性说明及平面布置图。

（五）道路改造及北广场路面铺设与本次抢险加固无关，应予以取消。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

国家文物局
