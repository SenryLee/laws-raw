# 国家邮政局关于《中华人民共和国第十三届全国人民代表大会》纪念邮票图稿的批复

国邮复〔2018〕4号

中国邮政集团公司：

你公司关于报审《中华人民共和国第十三届全国人民代表大会》纪念邮票图稿的文（中国邮政函〔2018〕5号）收悉。根据我局审定的2018年纪特邮票发行计划，该纪念邮票一套1枚，邮票内容为：1. 中华人民共和国第十三届全国人民代表大会。发行日期为2018年3月5日。经审查，同意使用该图稿印制邮票。

此复。

国家邮政局

2018年1月18日
