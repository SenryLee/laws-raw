# 国家认证认可监督管理委员会关于智能语言教学广播系统是否属于强制性产品认证范围的批复

## 国家认证认可监督管理委员会关于智能语言教学广播系统是否属于强制性产品认证范围的批复（认证函[2006]94号）

广西壮族自治区质量技术监督局：

你局《关于请求确认湖南爱博公司的“智能语言教学广播系统”是否属于3C认证范围产品的请示》（桂质监报[2006]26号）收悉。“智能语言教学广播系统”（以下简称系统）不属于强制性认证目录范围内的产品。但该系统由豪华型一体化主机、播控专用液晶电脑、系统电源监护器等诸多设备组成，湖南爱博科技发展有限公司在生产/组装该系统时应采购通过CCC认证的设备。现将该系统的相关设备是否需要CCC认证明确如下：

|  |  |  |
| --- | --- | --- |
| 编号 | 货物名称 | 是否属于强制性产品认证范围 |
| 1 | 豪华型一体化主机 | 该主机具有内置式多媒体网络，内置式智能化VCD/DVD影碟等装置，属于《第一批实施强制性产品认证的产品目录》音视频设备中其他收录（放）音组合机，应经过强制性产品认证后，方可出厂、销售、进口或者在其他经营性活动中使用。 |
| 2 | 播控专用液晶电脑 | 该设备应由主机与液晶显示器两部分组成，这两部分属于目录内信息技术设备中，数字式数据处理设备及与计算机连用的显示设备，属于强制性产品认证范围。 |
| 3 | 网络管理器，系统电源监护器，多功能话筒及远程播音插口 | 上述设备依据现有的产品资料判定不属于《第一批实施强制性产品认证的产品目录》的范围。其中，系统电源监护器具有断路保护的功能，应选购经过强制性产品认证的断路器或熔断器组件。 |
| 4 | 智能教学单元 | 该单元由主控板，专业操作键盘，智能磁带卡座等组成。其中智能磁带卡座是具备自动放音，进带，倒带等功能的音视频播放、处理设备，属于《第一批实施强制性产品认证的产品目录》范围。 |
| 5 | 配套音箱，高性能智能音箱，豪华铝合金壁挂式智能音箱及全天候艺术假山/蘑菇智能音箱等 | 依据提供的资料判断上述音箱属于有源音箱（无源音箱不在强制性产品认证范围），属于《第一批实施强制性产品认证的产品目录》范围中36伏以上的，总输出功率在500W（有效值）以下的有源音箱，应经过强制性产品认证后，方可出厂、销售、进口或者在其他经营性活动中使用。 |

此复。

二○○六年六月七日
