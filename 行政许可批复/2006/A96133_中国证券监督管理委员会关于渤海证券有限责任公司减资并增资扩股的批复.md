# 中国证券监督管理委员会关于渤海证券有限责任公司减资并增资扩股的批复

## 中国证券监督管理委员会关于渤海证券有限责任公司减资并增资扩股的批复（证监机构字[2006]228号）

渤海证券有限责任公司：

你公司报送的《关于渤海证券有限责任公司调整注册资本的请示》（渤证[2006]72号）及有关文件收悉。经审核，现批复如下：

**一、**同意你公司减资并增资扩股的方案。即：先将注册资本由231716.63万元核减至92686.652万元，在此基础上再由现有股东和新股东向公司增资13亿元，上述增资完成后你公司注册资本增至222686.652万元人民币。

**二、**批准你公司此次增资中以下出资单位的股东资格、出资额：

```
股东名称　　　　　　　　　　　　　　　　　出资额（万元）

1、天津泰达股份有限公司　　　　　　　　　　　　60000

2、天津泰达投资控股有限公司　　　　　　　　　　40000

3、天津市财政投资管理中心　　　　　　　　　　　30000

合计

130000
```

**三、**你公司应聘请验资机构就减资、增资分别出具《验资报告》，并按股东实际缴纳的出资分别到工商登记机关办理变更登记，注册资本以《验资报告》验明的实缴资本为准。你公司应按照《关于证券公司增资扩股有关问题的通知》（证监发［2001］146号）的有关规定，在本批复下发之日起3个月内完成增资扩股工作，自全部增资资金到位并办理工商变更登记之日起30个工作日内，向我会申请换发《经营证券业务许可证》。

**四、**你公司可根据本批复修改公司章程。

**五、**你公司在减资、增资工作中如遇到重大问题，须及时报告我会及天津证监局。

附件：渤海证券有限责任公司此次减资并增资扩股后股东出资情况一览表（略）

二○○六年九月二十七日
