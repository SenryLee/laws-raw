# 中国银行业监督管理委员会关于潍坊市商业银行增资扩股有关事宜的批复

潍坊市商业银行：

你行《关于对融达信实业发展有限公司股东资格审查的请示》（潍商银发[2006]第207号）、《关于对黑龙江世纪华嵘投资管理有限公司股东资格审查的请示》（潍商银发[2006]第208号）和《关于对上海德莱科技有限公司股东资格审查的请示》（潍商银发[2006]第209号）收悉。根据《中资商业银行行政许可事项实施办法》等有关规定，现批复如下：

**一、**同意黑龙江世纪华嵘投资管理有限公司增持你行股份9000万股，受让山东海化集团有限公司持有的你行股份3000万股，增持并受让后股份合计1 61 98万股；同意融达信实业发展有限公司增持你行股份1 2300万股，受让山东海化集团有限公司持有的你行股份3000万股，受让潍坊亚星集团持有的你行700万股，增持并受让后股份合计1 8500万股；同意上海德莱科技有限公司增持你行股份1 700万股，受让潍坊亚星集团有限公司持有你行股份2300．3792万股，增持并受让后股份合计6500．3792万股。

**二、**你行应建立和完善资本补充机制，逐步拓宽资本补充渠道。按照科学、合理和分散原则，进一步合理调整股权结构。

**三、**你行应制定规范、公司的董事选举程序，董事应当具备履行职责所必需的专业知识和工作经验。

**四、**你行应充分发挥关联交易控制委员会的作用，严格控制关联交易。你行章程应当对重大关联交易和特别重大关联交易的标准做出规定。董事会会议做出的批准关联交易的决议应当由无重大利害关系的董事过半数通过。

二○○六年十二月二十七日
