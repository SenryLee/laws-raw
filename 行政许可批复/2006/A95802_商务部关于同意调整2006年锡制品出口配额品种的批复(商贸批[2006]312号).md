# 商务部关于同意调整2006年锡制品出口配额品种的批复(商贸批[2006]312号)

## 商务部关于同意调整2006年锡制品出口配额品种的批复（商贸批〔2006〕312号）

中国五矿集团公司：

《中国五矿集团关于申请调整锡材出口配额的请示》（〔2006〕中国五矿企字第276号）收悉。经研究，现批复如下：

同意将五矿有色金属股份有限公司2006年锡制品出口配额作如下调整：

单位：吨

```
┌───┬────────┬────┬─────────┐

│品种　│ 调整前配额数量 │ 调整　 │调整后配额数量　　│

├───┼────────┼────┼─────────┤

│锡锭　│ 1313　　　│ -500　 │813　　　　　│

├───┼────────┼────┼─────────┤

│锡制品│ 0　　　　　　　│ +500　 │ 500　　　　　　　│

└───┴────────┴────┴─────────┘
```

请你公司按照调整后的配额数量安排出口。

中华人民共和国商务部

二〇〇六年十月十一日
