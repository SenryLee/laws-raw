# 中国证券监督管理委员会关于日信证券有限责任公司股权变更的批复

## 中国证券监督管理委员会关于日信证券有限责任公司股权变更的批复（证监机构字[2006]70号）

日信证券有限责任公司：

你公司关于股权变更的申请及相关材料收悉。经审核，批准北京华联集团投资控股有限公司受让中国纺织机械（集团）有限公司持有的你公司25000万元股权（占出资总额41.67%）。

你公司可据此修改公司章程，并在本批复下发后1个月内，依法办理上述股权的变更手续。

二○○六年四月二十一日
