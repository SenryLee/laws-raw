# 商务部关于同意调整2006年锡制品出口配额品种的批复(商贸批[2006]204号)

## 商务部关于同意调整2006年锡制品出口配额品种的批复(商贸批〔2006〕204号)

云南省商务厅：

《云南省商务厅关于申请调整部分工业品出口配额的请示》（云商贸〔2006〕63号）收悉。经研究，现批复如下：

同意将云南锡业股份有限公司2006年焊锡出口配额作如下调整：

单位：吨

```
┌──────────┬──────────┬──────────┬──────────┐

│品种　　　　　　　　│调整前配额数量　　　│调整　　　　　　　　│调整后配额数量　　　│

├──────────┼──────────┼──────────┼──────────┤

│焊锡　　　　　　　　│4407　　　　　　　　│-600　　　　　　　　│3807　　　　　　　　│

├──────────┼──────────┼──────────┼──────────┤

│锡制品　　　　　　　│252　　　　　　│+600　　　　　　　　│852　　　　　　│

└──────────┴──────────┴──────────┴──────────┘
```

请你厅尽快将配额调整情况通知有关企业。

特此批复

中华人民共和国商务部

二○○六年七月二十五日
