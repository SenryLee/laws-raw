# 商务部关于同意将浙江康裕制药有限公司麻黄素出口经营资格划转到浙江普洛康裕制药有限公司的批复

## 商务部关于同意将浙江康裕制药有限公司麻黄素出口经营资格划转到浙江普洛康裕制药有限公司的批复（商产批[2006]18号）

浙江省外经贸厅：

《浙江省对外贸易经济合作厅关于麻黄素出口经营资格变更的请示》（浙外经贸机电[2006]224号）收悉。现批复如下：

同意浙江康裕制药有限公司将麻黄素出口经营资格划转到更名后的浙江普洛康裕制药有限公司。

特此批复

中华人民共和国商务部

二〇〇六年六月十六日
