# 中国证券监督管理委员会关于山西证券有限责任公司股权变更及增资扩股的批复

## 中国证券监督管理委员会关于山西证券有限责任公司股权变更及增资扩股的批复（证监机构字[2006]138号）

山西证券有限责任公司：

你公司关于股权变更及增资扩股的申请及相关材料收悉。经审查，现批复如下：

**一、**批准山西省国信投资（集团）公司受让你公司下列8家股东合计22120万元股权（占出资总额21.58%），明细如下：

```
中国网通集团山西省通信公司　　　　　　7000万元

阳泉信达投资管理公司　　　　　　　　　5600万元

太原晋太实业（集团）有限公司　　　　　3800万元

山西西山煤电股份有限公司　　　　　　　3000万元

山西省科技基金发展总公司　　　　　　　1500万元

山西省经贸资产经营有限责任公司　　　　1000万元

山西省吕梁市投资管理公司　　　　　160万元

长治市行政事业单位国有资产管理中心　　　60万元
```

你公司应在本批复下发之日起30个工作日内，依法办理上述股权的变更手续。

**二、**批准你公司增资扩股的方案，即山西省国信投资（集团）公司向你公司增加出资27880万元人民币，增资后你公司注册资本由102500万元增至130380万元。

你公司应按照《关于证券公司增资扩股有关问题的通知》（证监发[2001]146号）的有关规定，在本批复下发之日起3个月内完成增资扩股工作，向工商行政管理机构申请变更登记，并应自变更登记之日起30个工作日内，到我会换领《经营证券业务许可证》。

你公司可据此修改公司章程，并将变更后的公司章程报我会审核。你公司在增资扩股工作中如遇到重大问题，须及时报告我会。

附件：山西证券有限责任公司本次增资扩股后股东出资情况一览表（略）

二○○六年七月十日
