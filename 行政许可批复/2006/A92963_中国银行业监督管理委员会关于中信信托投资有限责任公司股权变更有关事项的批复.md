# 中国银行业监督管理委员会关于中信信托投资有限责任公司股权变更有关事项的批复

## 中国银行业监督管理委员会关于中信信托投资有限责任公司股权变更有关事项的批复（银监复[2006]457号）

中信信托投资有限责任公司：

《中信信托投资有限责任公司吸收中信资本控股有限公司投资入股申请书》（资托发字[2006]11号）收悉。现批复如下：

**一、**批准中国中信集团公司将持有的你公司20％的股权转让给中信资本控股有限公司。

**二、**股权变更后，你公司的股东构成、股权比例如下：

中国中信集团公司股权比例为60％。

中信资本控股有限公司股权比例为20％。

中信华东（集团）有限公司股权比例为20％。

**三、**请你公司按本批复修改公司章程中的有关内容，到工商行政管理部门办理相关手续，并将修改后的章程报银监会批准。

二○○六年十二月二十二日
