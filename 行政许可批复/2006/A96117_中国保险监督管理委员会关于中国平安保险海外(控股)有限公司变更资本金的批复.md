# 中国保险监督管理委员会关于中国平安保险海外(控股)有限公司变更资本金的批复

## 中国保险监督管理委员会关于中国平安保险海外（控股）有限公司变更资本金的批复（保监国际〔2006〕1019号）

中国平安保险（集团）股份有限公司：

你集团《关于向中国平安海外（控股）有限公司增资的请示》（平保发〔2006〕50号）收悉。

按照有关保险法规，经研究，现批准你集团向中国平安保险海外（控股）有限公司增资5亿港币，并根据国家外汇管理和香港金融监管的相关规定，开立帐户及进行资金划转。

此复

二○○六年九月二十七日
