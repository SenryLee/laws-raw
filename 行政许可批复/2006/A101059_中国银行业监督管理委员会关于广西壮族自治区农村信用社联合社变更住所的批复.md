# 中国银行业监督管理委员会关于广西壮族自治区农村信用社联合社变更住所的批复

## 中国银行业监督管理委员会关于广西壮族自治区农村信用社联合社变更住所的批复（银监复[2006]94号）

广西壮族自治区农村信用社联合社：

你联合社《关于广西壮族自治区农村信用社联合社办公地址变更的请示》（桂农信报[2005]17号）收悉。现批复如下：

**一、**同意广西壮族自治区农村信用社联合社住所由南宁市天桃路22号变更为南宁市锦春路20号。

**二、**请按照《金融许可证管理办法》的有关规定到广西银监局换发金融许可证，并到工商行政管理部门办理变更登记。

二00六年四月二十七日
