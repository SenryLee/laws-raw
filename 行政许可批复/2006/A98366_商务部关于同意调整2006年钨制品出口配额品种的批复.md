# 商务部关于同意调整2006年钨制品出口配额品种的批复

## 商务部关于同意调整2006年钨制品出口配额品种的批复(商贸批〔2006〕198号)

四川省商务厅：

《四川省商务厅关于调换钨制品出口配额的请示》（川商贸〔2006〕57号）收悉。经研究，现批复如下：

为鼓励高附加值产品出口，同意将自贡硬质合金进出口贸易有限责任公司2006年钨制品出口配额作如下调整：

单位：吨

```
┌────────┬────────┬────────┬────────┐

│　 品种　　│调整前配额数量　│调整　│调整后配额数量　│

├────────┼────────┼────────┼────────┤

│ 蓝色氧化钨│　　364　　│　-133　　　　　│　　231　　│

├────────┼────────┼────────┼────────┤

│　钨粉　　　　　│　　643　　│　+116　　　　　│　 759　　　　　│

│　　　　　　　　│　　　　　　　　│　　　　　　　　│　　　　　　　　│

└────────┴────────┴────────┴────────┘
```

请你厅尽快将配额调整情况通知有关企业。

特此批复

中华人民共和国商务部
