# 中国银行业监督管理委员会关于核准中国银行股份有限公司章程的批复(2006)

## 中国银行业监督管理委员会关于核准中国银行股份有限公司章程的批复（银监复[2006]81号）

中国银行：

你行《关于为境外发行上市目的修改我行公司章程的请示》（中银董[2006]6号）收悉。

根据《中华人民共和国公司法》、《中华人民共和国商业银行法》、《中华人民共和国银行业监督管理法》及其他法律法规的规定，兹核准《中国银行股份有限公司章程》（H股长章程）。

此复。

附件：《中国银行股份有限公司章程》（H股长章程）（略）

二00六年四月十二日
