# 商务部关于同意调整2006年钨制品出口配额品种的批复(商贸批[2006]177号)

湖南省商务厅：

《湖南省商务厅关于申请将氧化钨出口配额更换为碳化钨出口配额的请示》（湘商[2006]127号）收悉．经研究，现批复如下：

为鼓励高附加值产品出口，同意将株州硬质合金进出口公司2006年钨制品出口配额品种作如下调整：

单位：吨

```
┌────┬─────────┬─────┬─────────┐

│品种　　│调整前配额数量　　│　调整　　│调整后配额数量　　│

├────┼─────────┼─────┼─────────┤

│氧化钨　│　　694　　　│ -118.5　 │ 575.5　　　　　　│

├────┼─────────┼─────┼─────────┤

│钨粉　　│　　325　　　│　+100　　│　425　　　　│

└────┴─────────┴─────┴─────────┘
```

请你厅尽快将配额调整情况通知有关企业．

中华人民共和国商务部

二〇〇六年六月二十七日
