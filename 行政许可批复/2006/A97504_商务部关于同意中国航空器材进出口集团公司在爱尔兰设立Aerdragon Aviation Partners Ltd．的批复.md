# 商务部关于同意中国航空器材进出口集团公司在爱尔兰设立Aerdragon Aviation Partners Ltd．的批复

## 商务部关于同意中国航空器材进出口集团公司在爱尔兰设立Aerdragon　Aviation　Partners　Ltd．的批复（商合批〔2006〕610号）

中国航空器材进出口集团公司：

《关于在爱尔兰成立中外合资飞机租赁公司的请示》（中航材〔2006〕168号）悉。经研究，现批复如下：

**一、**同意你公司与Sinefinair B.V.和Lishui Aircraft Leasing Limited在爱尔兰合资设立“Aerdragon Aviation Partners Ltd.”。该境外企业投资总额和注册资本均为5000万美元，其中中国航空器材进出口集团公司以现金方式出资2500万美元，占50%股份，所需外汇通过人民币购汇方式解决；Sinefinair B.V.以现金方式出资1250万美元，占25%股份；Lishui Aircraft Leasing Limited以现金方式出资1250万美元，占25%股份。

**二、**该境外企业经营范围：开展飞机、发动机经营租赁业务，代表第三方管理飞机、发动机资产等。

**三、**接此批文后，请你公司到我部合作司领取《中国企业境外投资批准证书》。凭批准证书于1年内办理有关手续。

**四、**请你公司自领取批准证书起60天内，到外汇管理部门办理有关登记手续。

**五、**请选派政治素质好、熟悉业务、懂外语、具有开拓精神的同志赴国外开展工作。中方主要负责人抵达后，应持批准证书（复印件）向我驻爱尔兰使馆经商参处报到登记，中方派出人员须接受我使馆的领导。

**六、**企业在境外注册成立后，请督促其将注册文件报你公司备案，并按照《境外投资联合年检暂行办法》的规定，参加境外企业的年检工作。

中华人民共和国商务部

二○○六年八月十六日
