# 中国证券监督管理委员会关于华龙证券有限责任公司增资扩股、股权变更的批复

## 中国证券监督管理委员会关于华龙证券有限责任公司增资扩股、股权变更的批复(证监机构字[2006]271号)

华龙证券有限责任公司：

你公司报送的《华龙证券有限责任公司关于增资扩股和股权变更的申请报告》（华龙证券[2006]71号）及有关文件收悉。经审查，现批复如下：

**一、**批准你公司增资扩股的方案，即甘肃省人民政府国有资产监督管理委员会以现金增资50000万元，兰州市商业银行股份有限公司以债转股方式增资40000万元，甘肃省人民政府财政厅以债转股方式增资10000万元，上海九龙山股份有限公司以债转股方式增资4000万元，中国星火有限公司以债转股方式增资450万元，重庆江南财务顾问有限公司以债转股方式增资300万元。增资后你公司注册资本由50589万元增至155339万元。

**二、**批准你公司此次增资中以下出资单位的股东资格、出资额：

```
股东名称　　　　　　　　　　　　　　　　　出资额（万元）

1、甘肃省人民政府国有资产监督管理委员会　 50000

2、兰州市商业银行股份有限公司　　　　40000

合计

90000
```

**三、**批准甘肃省人民政府国有资产监督管理委员会受让以下单位持有的你公司股权数：

```
股东名称　　　　　　　　　　　　股权数（万股）

1、甘肃省人民政府财政厅　　　　　　　33100

2、甘肃长城电工集团有限责任公司　　　4000

3、甘肃省电力投资集团公司　　　　　　7700

4、酒泉钢铁（集团）有限责任公司　　　7000

5、酒钢机械制造公司　　　　　　　　　700

6、甘肃祁连山建材控股有限公司　　　　700

合计　　　　　　　　　　　　　　53200
```

**四、**兰州市商业银行股份有限公司应当自本批复下发之日起2年内，按照规定对所持你公司股份予以处分。

**五、**你公司应当自本批复下发之日起1个月内完成股权变更、增资扩股工作，向工商行政管理机关申请变更登记，并应自变更登记之日起30个工作日内，向我会申请换发《经营证券业务许可证》。

**六、**你公司可根据本批复修改公司章程。

**七、**你公司在增资扩股、股权变更工作中如遇到重大问题，须及时报告我会。

附件：华龙证券有限责任公司本次增资扩股、股权变更后股东出资情况一览表（略）

二○○六年十一月七日
