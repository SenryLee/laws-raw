# 中国保险监督管理委员会关于都邦财产保险股份有限公司大连等3家分公司机动车商业保险条款费率的批复

## 中国保险监督管理委员会关于都邦财产保险股份有限公司大连等3家分公司机动车商业保险条款费率的批复(保监产险〔2006〕1305号)

都邦财产保险股份有限公司：

你公司《关于报批机动车商业保险附加条款大连等三个地区费率的请示》（都邦发〔2006〕269号）及其补正材料收悉。经审核，批复如下：

**一、**同意你公司适用于大连、深圳、云南地区的机动车商业保险条款和费率。保险费率见附件，其他未尽之处适用于保监产险〔2006〕724号文件。

**二、**你公司应将保险条款、费率的内容完整准确地向社会公布。

附件：都邦财产保险股份有限公司适用于大连、深圳、云南地区的机动车商业保险费率表

二○○六年十一月二十九日
