# 中国证监会关于核准金科智慧服务集团股份有限公司境内未上市股份到境外上市的批复

## 关于核准金科智慧服务集团股份有限公司境内未上市股份到境外上市的批复

证监许可〔2021〕2681号

金科智慧服务集团股份有限公司：

你公司《关于H股公司境内未上市股份申请“全流通”的申请报告》（金科智慧服务红发〔2020〕339号）及相关文件收悉。根据《中华人民共和国证券法》《国务院关于股份有限公司境外募集股份及上市的特别规定》《H股公司境内未上市股份申请“全流通”业务指引》等有关规定，经审核，现批复如下：

一、核准你公司11名股东将合计5亿股境内未上市股份转为境外上市股份，相关股份转换完成后可在香港联合交易所上市。股东名称及转换数量为：

| --- | --- | --- |
| 序号 | 股东 | 核准转股数量 |
| 1 | 金科地产集团股份有限公司 | 341,604,375 |
| 2 | 天津恒业美好管理咨询合伙企业（有限合伙） | 50,516,464 |
| 3 | 北京融汇瑞光投资管理中心（有限合伙） | 17,185,005 |

| 7 | 天津金恒鸿鑫管理咨询合伙企业（有限合伙） | 2,774,750 |
| 8 | 天津卓越共赢金科管理咨询合伙企业（有限合伙） | 17,721,513 |

| 11 | 北京融汇阳光永晟投资管理中心（有限合伙） | 14,027,500 |
| 合计 | | 500,000,000 |

二、你公司应于所涉境内未上市股份在中国证券登记结算有限责任公司完成转登记后15个工作日内将相关情况书面报告我会。

三、本批复自核准之日起12个月内有效。

四、你公司在股份转换和上市过程中，应严格遵守境内外有关法律、法规和规则。

中国证监会
