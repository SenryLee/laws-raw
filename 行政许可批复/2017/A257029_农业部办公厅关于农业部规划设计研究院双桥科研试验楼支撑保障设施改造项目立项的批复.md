# 农业部办公厅关于农业部规划设计研究院双桥科研试验楼支撑保障设施改造项目立项的批复

农办计〔2017〕78号

农业部规划设计研究院：

《关于报送〈朝阳区双桥中路11号科研试验楼支撑保障设施改造项目可行性研究报告〉的函》（农规基函〔2017〕16号）收悉。经研究，批复如下。

原则同意农业部规划设计研究院双桥农业工程科研试验楼支撑保障设施改造项目立项。项目建设地点位于北京市朝阳区双桥中路11号，主要建设内容为改造科研试验楼2239.5平方米，其中一层建设农业部生物质工程中心和农业部遥感应用中心项目批复的职工食堂，二、三、四层建设科研试验用房。项目总投资436万元。资金来源为自筹资金。项目建设期为1年。

请据此批复，抓紧做好项目组织实施,并按照部门预算管理有关规定，将相应项目自筹资金纳入你院预算编报。

附件：农业部规划设计研究院双桥科研试验楼支撑保障设施改造项目招标投标事项核准表

农业部办公厅

2017年10月18日
