# 国家发展改革委关于气象信息化发展规划（2018-2022年）的批复

发改农经〔2017〕2085号

中国气象局：

你局《关于再次报送〈气象信息化发展规划（2018-2022年）〉的函》（中气函〔2017〕251号）收悉。经研究，现批复如下。

一、气象信息化是实现气象现代化的重要基础。为进一步发挥信息化对气象业务的支撑作用，提升气象监测预警能力，提高气象信息共享及应用水平，加快实现气象现代化，编制并组织实施《气象信息化发展规划（2018-2022年）》（以下简称《规划》）是必要的。

二、原则同意《规划》提出的发展目标和主要任务。以构建统筹集约、协同高效、开放共享、安全可靠的气象信息化体系为目标，主要任务包括提升气象信息基础设施水平、支撑气象预报向智能化发展、提高气象信息服务供给能力、构建整体化的信息安全体系、提高气象信息业务治理水平等。

三、请你局按照固定资产投资项目建设程序，区分轻重缓急，有序推进项目安排和前期工作。要按照《国务院办公厅关于印发政务信息系统整合共享实施方案的通知》（国办发〔2017〕39号）和《加快推进落实〈政务信息系统整合共享实施方案〉工作方案》（发改高技〔2017〕1529号）要求，在清理、整合、规范现有信息系统的基础上，科学谋划、统筹推进项目建设。要加强与《“十三五”国家政务信息化工程建设规划》的衔接，优化建设内容，积极研究通过国家数据共享交换平台等全国统一的政务信息化基础设施，以及充分利用社会资源满足业务需要的可行性，避免重复建设，切实提高政府投资效益。气象信息系统软件建设，要充分利用现有业务软件系统，注重通过功能延伸、模块拓展等方式满足业务需要，提高软件的通用性、兼容性和复用率。

国家发展改革委

2017年12月4日
