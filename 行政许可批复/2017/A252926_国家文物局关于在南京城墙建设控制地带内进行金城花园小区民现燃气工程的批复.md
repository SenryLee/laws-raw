# 国家文物局关于在南京城墙建设控制地带内进行金城花园小区民现燃气工程的批复

## 关于在南京城墙建设控制地带内进行金城花园小区民现燃气工程的批复

文物保函〔2017〕1020号

江苏省文物局：

你局《关于审批〈金城花园小区民现燃气工程方案设计〉的请示》（苏文物保〔2017〕88号）收悉。经研究，我局批复如下：

一、原则同意在南京城墙建设控制地带内进行金城花园小区民现燃气工程和你局意见。

二、对该工程提出以下意见：

（一）应严格遵守《中华人民共和国文物保护法》和《南京城墙保护条例》、《南京城墙保护规划》、《南京市历史文化名城保护规划》的有关要求，严格控制工程量和工程范围，尽量减少对文物本体安全和景观环境的影响。

（二）应评估天然气管道泄漏爆炸等突发情况的最大影响范围、程度以及对南京城墙的影响，并补充相关的文物保护措施和应急预案。

（三）合理确定调压箱的规模，并采用必要的绿化遮挡措施，尽量减少对文物的影响。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工中应加强监管，发现地下文物应立即停工并调整施工方案，确保工程质量和文物安全。

此复。

国家文物局

2017年5月24日
