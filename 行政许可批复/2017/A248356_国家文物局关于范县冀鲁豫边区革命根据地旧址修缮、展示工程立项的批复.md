# 国家文物局关于范县冀鲁豫边区革命根据地旧址修缮、展示工程立项的批复

## 关于范县冀鲁豫边区革命根据地旧址修缮、展示工程立项的批复

文物保函〔2017〕432号

河南省文物局：

你局《关于冀鲁豫边区革命根据地旧址（范县）保护展示利用工程立项的请示》（豫文物〔2017〕69号）收悉。经研究，我局批复如下：

一、同意范县冀鲁豫边区革命根据地旧址修缮工程、展示工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）根据《冀鲁豫边区革命根据地旧址（范县）文物保护规划》要求，就文物修缮工程和文物展示工程应分别编制技术方案，同步实施。

（二）工程范围为范县冀鲁豫边区革命根据地旧址文物建筑。

（三）关于修缮工程，应进一步加强文物现状勘察和评估，准确掌握病害及残损状况，结合建筑自身特点和原材料、原工艺，制定针对性修缮措施。应坚持“最小干预”原则，严格控制工程量，避免过度修缮。

（四）关于展示工程，应在深入评估现有条件和存在问题的基础上，明确展示目标和需求，丰富展示手段和内容，整体提升展示水平。恢复室内场景须有确凿历史依据；布设展示设施、设备不得对损坏文物本体，不得改变建筑原有结构、格局及历史风貌，其外观、色彩和体量应与文物及其环境相协调。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年3月3日
