# 国家文物局关于河南省龙源古建园林技术开发公司文物保护工程施工一级资质证书内容变更的批复

## 关于河南省龙源古建园林技术开发公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕855号

河南省文物局：

你局《关于河南省龙源古建园林技术开发公司文物保护工程施工一级资质证书内容变更的请示》（豫文物〔2017〕202号）收悉。

经研究，我局同意河南省龙源古建园林技术开发公司文物保护工程施工一级资质证书中的法定代表人由“秦曙光”变更为“常铁伟”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局

2017年7月20日
