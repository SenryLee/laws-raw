# 农业部关于广东省农垦总局阳江中心医院等7个社会公益性建设项目可行性研究报告的批复

农计发〔2017〕4号

广东省农垦总局：

你局报送的农垦社会公益性项目可行性研究报告及相关上报文件收悉。经研究，原则同意下列项目可行性研究报告。

1.阳江中心医院等4所医院医疗设备购置及院区设施建设项目，建设地点位于广东省阳江市阳春市阳江农垦中心医院、阳东区红五月农场医院、阳西县城桥平一路41号织篢农场医院、阳东区鸡山农场医院。主要建设内容为购置全自动生化分析仪、经颅磁刺激仪等医疗设备25台（套）；硬化地面7300平方米，建设挡土墙790立方米，改造院区道路、排污排水、电路等设施。总投资1265万元，其中中央预算内投资1015万元，地方投资250万元（详见附件1）。

2.茂名农垦医院大型医疗设备DSA购置项目，建设地点位于广东省茂名市高州市潘州东路36号。主要建设内容为购置数字减影血管造影X线机1套，改造机房、控制室、消毒间、候诊区、走廊、配电设备间等用房115.2平方米，完善配电设施。总投资1320万元，其中中央预算内投资1055万元，地方投资265万元（详见附件2）。

3.湛江垦区广前和湖光农场场部小城镇基础设施建设项目，建设地点位于广东省湛江市遂溪县广前农场、麻章区湖光农场场部。主要建设内容为新建次干道8900米，配套建设排水涵管1900米、排水沟6000米、涵洞100米；新建桥梁1座、水塔4座、水井2眼，改造供水管网3.5千米，购置安装饮水水泵5台、路灯495套。总投资1325万元，其中中央预算内投资1060万元，地方投资265万元（详见附件3）。

4.茂名垦区建设和红旗农场场部小城镇基础设施建设项目，建设地点位于广东省茂名市化州市建设农场场部、信宜市红旗农场场部。主要建设内容为新建主干道1804米、次干道2067米、人行道3608米、排水沟7742米，道路绿化3608米，安装路灯300套等。总投资910万元，其中中央预算内投资730万元，地方投资180万元（详见附件4）。

5.阳江垦区红十月和鸡山农场场部小城镇基础设施建设项目，建设地点位于广东省阳江市江城区红十月农场场部、阳东区鸡山农场场部。主要建设内容为新建主干道8600米、支道900米、人行道2000米，配套建设挡土墙2600立方米、涵桥1座、路灯260套等。总投资1000万元，其中中央预算内投资800万元，地方投资200万元（详见附件5）。

6.铜锣湖农场场部小城镇基础设施建设项目，建设地点位于广东省汕尾市陆丰市铜锣湖农场场部。主要建设内容为新建主干道路3400米、支道2000米、人行道6800米，配套建设道路绿化6800米，建设排水管道5200米、低压供电线2000米等。总投资990万元，其中中央预算内投资790万元，地方投资200万元（详见附件6）。

7.梅陇农场场部小城镇基础设施建设项目，建设地点位于广东省汕尾市海丰县梅陇农场场部。主要建设内容为新建主干道1000米、给水管道12000米，扩建主干道6800米，配套建设护坡3400立方米，道路绿化6000米等。总投资1225万元，其中中央预算内投资980万元，地方投资245万元（详见附件7）。

上述项目建设期均为2年，自投资计划下达之日起计算。

请据此批复，督促建设单位抓紧委托有资质的勘察设计单位编制项目初步设计报你局审批。请严格按照农业基本建设项目管理规定，做好项目组织实施工作，并按月在农业建设项目管理信息系统（http://ac.agri.gov.cn）和投资项目在线审批监管平台（国家重大建设项目库模块，http://kpp.ndrc.gov.cn）中填报实施进度等相关信息。

附件：1.广东农垦阳江中心医院等4所医院医疗设备购置及院区设施建设项目可行性研究报告批复表

2.广东农垦茂名农垦医院大型医疗设备DSA购置项目可行性研究报告批复表

3.广东农垦湛江垦区广前和湖光农场场部小城镇基础设施建设项目可行性研究报告批复表

4.广东农垦茂名垦区建设和红旗农场场部小城镇基础设施建设项目可行性研究报告批复表

5.广东农垦阳江垦区红十月和鸡山农场场部小城镇基础设施建设项目可行性研究报告批复表

6.广东农垦铜锣湖农场场部小城镇基础设施建设项目可行性研究报告批复表
