# 中国证监会关于核准青岛环球服装股份有限公司股票在全国中小企业股份转让系统公开转让的批复

## 关于核准青岛环球服装股份有限公司股票在全国中小企业股份转让系统公开转让的批复

证监许可〔2017〕847号

青岛环球服装股份有限公司：

《青岛环球服装股份有限公司关于公开转让股票的申请报告》（青环服〔2016〕第7号）及相关文件收悉。根据《公司法》、《证券法》和《非上市公众公司监督管理办法》（证监会令第96号）等有关规定，经审核，现批复如下：

核准你公司股票在全国中小企业股份转让系统公开转让，并将你公司纳入非上市公众公司监管。

中国证监会

2017年6月5日
