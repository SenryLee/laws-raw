# 国家文物局关于东交民巷使馆建筑群日本使馆旧址西花园东垂花门北廊道抢险方案的批复

文物保函〔2017〕1920号

北京市文物局：

你局《东交民巷使馆建筑群——日本使馆旧址（北京市政府）西花园东垂花门北廊道抢险工程的请示》（京文物〔2017〕1269号）收悉。经研究，我局批复如下：

一、原则同意所报方案。

二、对方案提出以下修改意见：

（一）深化廊道现状勘察，进一步分析和明确木构件腐烂、糟朽、坍塌的原因，根据勘察结果，制定相应措施。修缮过程中应尽量使用原有木构件，减少工程量。

（二）补充廊道顶部新做亚克力透明阳光板的设计依据和必要性、可行性说明。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年11月30日
