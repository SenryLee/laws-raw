# 国家文物局关于漳州府文庙整治工程立项的批复

## 关于漳州府文庙整治工程立项的批复

文物保函〔2017〕457号

福建省文物局：

你局《关于全国重点文物保护单位漳州府文庙泮池展示利用工程立项的请示》（闽文物字〔2016〕593号）收悉。经研究，我局批复如下：

一、同意漳州府文庙泮池整治工程立项。

二、在编制展示利用方案时，应注意以下方面：

（一）该工程属文物保护展示工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物的真实性，充分阐释与展示文物的价值和内涵。

（二）工程内容为漳州府文庙泮池整治。

（三）应加强前期研究，进一步梳理相关历史文献和考古成果，充分发掘文物历史价值，深化现状勘察，明确泮池水道特征和驳岸、池底等部位的原有砌筑方式、建筑材料等。

（四）以排除泮池安全隐患为主，尽可能利用原有石构件，合理确定构件更换、补配的具体数量和标准，严格控制工程量和工程强度。补充栏板、望柱等修复依据。

(五)应采用多种手段科学阐释漳州府文庙在儒家文化传播和地方文化发展中的价值、意义，促进文物保护利用与爱国主义教育、非物质文化遗产保护、中华传统文化创新发展等相结合，充分发挥文物保护利用的综合效益。

（六）环境整治工程应单独编制立项报告，并按程序另行报批。

（七）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案，并组织专家或委托专业机构进行方案技术评审，依据评估意见进行审批。

此复。

国家文物局
