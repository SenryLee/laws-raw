# 国家文物局关于解州关帝庙琉璃影壁修缮工程立项的批复

## 关于解州关帝庙琉璃影壁修缮工程立项的批复

文物保函〔2017〕550号

山西省文物局：

你局《关于申请解州关帝庙琉璃影壁、石牌坊抢险保护工程立项的请示》（晋文物〔2016〕216号）收悉。经研究，我局批复如下：

一、同意解州关帝庙琉璃影壁修缮工程立项。

二、对所报立项报告文本提出以下修改意见：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为解州关帝庙琉璃影壁文物本体。

（三）加强现状勘察和研究，明确文物主要病害类型、残损情况等，深入分析影壁倾斜、砖体开裂酥碱等病害原因，开展必要的工程地质详勘，客观评估历次修缮工程效果和影壁的结构稳定性，补充相关监测数据。

（四）补充地方建造工艺、传统做法、建筑材料和构造特征等研究和分析内容。

（五）应明确工程范围，严格控制工程量和工程强度。建议根据前期勘察结果，科学制定影壁纠偏和整体加固的具体设计思路和措施，研提多种工程技术方案，充分论证、比选，尽量避免整体重砌。影壁原有酥碱、开裂砖体应以局部替补为主，避免大规模更换；缺失构件补配应提供依据。

（六）根据工程量合理编制经费预算，确定取费项目，补充取费标准。

（七）应制定必要的安全措施和应急预案，确保文物和游客安全。同时，应加强施工过程记录和工程资料整理工作，工程结束后应及时将工程档案纳入文物“四有”档案，为文物日常养护和维修工作提供依据。

（八）暂不同意石牌坊抢险保护工程立项。应根据文物保存现状和病害程度，进一步明确修缮思路，另行报批。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案，组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年3月23日
