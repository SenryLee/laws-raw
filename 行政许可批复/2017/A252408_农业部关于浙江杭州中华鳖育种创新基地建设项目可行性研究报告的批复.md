# 农业部关于浙江杭州中华鳖育种创新基地建设项目可行性研究报告的批复

农计发〔2017〕102号

浙江省海洋与渔业局:

《浙江省海洋与渔业局关于上报农业部2016年现代种业提升工程等建设项目的请示》(浙海渔计〔2016〕6号)收悉。经研究，原则同意浙江杭州中华鳖育种创新基地建设项目可行性研究报告，现批复如下。

主要建设内容为建设种质资源保护库90亩、新品种选育培育温室3000平方米、新品种杂交选育池10亩，进排水系统1300米，购置仪器设备4台（套）（详见附件）。总投资994万元，其中中央预算内投资497万元，自有资金497万元。建设期2年。

请据此批复，抓紧委托有相应资质的勘察设计单位编制项目初步设计和概算，经你局审批后报我部备案。初步设计和概算编制要严格执行《关于党政机关停止新建楼堂馆所和清理办公用房的通知》（中办发〔2013〕17号）要求，不得将楼堂馆所等纳入项目建设内容。请切实履行好项目监管责任，督促项目建设单位严格按照农业基本建设项目管理规定，做好项目组织实施工作，每月28日之前通过农业建设项目管理信息系统（http://ac.argi.gov.cn）填报截至当月底项目进度、资金支出等相关信息。同时，按照国家发展改革委《关于做好农口中央预算内投资总结工作的通知》要求，请分别于次年1月3日和7月3日前，正式报送项目半年和全年总结，总结材料包括投资安排及到位情况、项目实施进展情况、监管措施、项目效益、存在的困难和问题、有关建议等内容。

同时，鉴于浙江省舟山三疣梭子蟹遗传育种中心建设项目实施地点相关规划调整，导致项目无法按期实施，依据《国家发展改革委关于加快调整2016年度中央预算内投资项目有关事项的通知》（发改电〔2017〕399号）要求，对该项目予以撤销，我部农计发〔2015〕78号文件附件3废止。请你局深入查找原因，切实加强项目储备和前期工作，举一反三，避免类似问题再次发生。

附件：浙江杭州中华鳖育种创新基地建设项目可行性研究报告批复表

农业部
