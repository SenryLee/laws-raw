# 国家文物局关于北镇庙碑亭、碑廊保护性设施建设工程的批复

## 关于北镇庙碑亭、碑廊保护性设施建设工程的批复

文物保函〔2017〕482号

辽宁省文物局：

你局《关于上报北镇庙石碑保护工程碑亭、碑廊方案的请示》（辽文物〔2016〕104号）收悉。经研究，我局批复如下：

一、原则同意所报北镇庙碑亭、碑廊保护性设施建设工程和你局意见。

二、对该方案提出以下修改完善意见：

（一）应加强前期勘察和研究，明确石碑保存现状、主要病害类型和病因，全面分析温湿度、光照、酸雨等对石碑安全的影响，为碑亭、碑廊的设计提供依据。补充评估拟建碑亭、碑廊对文物及其环境的影响。

（二）进一步搜集、整理碑亭的历史文献和影像资料，结合清代古建筑做法和当地营建工艺特点，细化碑亭设计方案，明确建筑比例、用材规格、屋面翼角生出、起翘等细节要求。同时，应充分考虑文物安全和防火问题，增加必要的设施设备，开展文物本体的病害监测工作。补充碑亭台基构件的保护要求。

（三）东、西两侧碑廊可采用轻钢结构，外观尽量简洁，并慎重选择颜色，与文物建筑环境相协调。应注意设施的通透性，建议取消门窗类维护结构。

（四）应统筹考虑碑亭、碑廊建设与周边道路、排水、环境绿化之间的衔接问题，研提具体处理措施。拟建碑亭、碑廊紧邻建筑遗址，应补充必要的施工要求和临时性遗址保护措施，确保施工过程中人员和文物安全。

三、请你局根据上述意见指导相关单位修改、完善方案，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2017年3月14日
