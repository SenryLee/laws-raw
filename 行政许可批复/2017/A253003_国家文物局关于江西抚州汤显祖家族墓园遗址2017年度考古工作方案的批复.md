# 国家文物局关于江西抚州汤显祖家族墓园遗址2017年度考古工作方案的批复

## 关于江西抚州汤显祖家族墓园遗址2017年度考古工作方案的批复

文物保函〔2017〕811号

江西省文物局：

你局《关于呈报〈江西抚州市临川区文昌里灵芝山汤显祖家族墓园考古调查、勘探与发掘项目 2017年工作方案〉的请示》（赣文物局字〔2017〕56号）收悉。经研究，我局批复如下：

一、原则同意所报抚州市临川区文昌里灵芝山汤显祖家族墓园2017年度考古工作方案和你局意见。

二、该方案应进行以下补充、完善：

（一）应以厘清汤显祖家族墓园范围、布局及相关附属建筑为目标，通过调查和勘探做好充分的数据信息采集工作。工作过程中，应注意对汤显祖家族墓园的建造与延续情况做深入的研究，以充分体现其对当地文化传统所起到的历史价值。

（二）发掘工作应在充分调查、勘探的基础上进行，发掘对象应为墓园内相关建筑和附属遗迹，不能涉及汤显祖墓葬本体。

（三）应进一步增强考古工作力量，细化工作方案和经费预算。

三、请你局指导有关单位，根据以上意见对抚州汤显祖家族墓园2017年度考古工作方案进行补充、完善，经你局核准后实施。请你局加强管理，确保工作质量和工地安全，遇有重要发现，应及时向我局报告。考古工作结束后，应向我局报告本年度工作情况。

国家文物局

2017年4月21日
