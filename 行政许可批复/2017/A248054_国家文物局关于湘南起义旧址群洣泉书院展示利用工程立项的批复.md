# 国家文物局关于湘南起义旧址群洣泉书院展示利用工程立项的批复

## 关于湘南起义旧址群洣泉书院展示利用工程立项的批复

文物保函〔2017〕381号

湖南省文物局：

你局《关于湘南起义旧址群——工农革命军第一军第一师第一团团部旧址洣泉书院展示利用工程立项的请示》（湘文物报〔2017〕11号）收悉。经研究，我局批复如下：

一、同意洣泉书院展示利用工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物展示利用工程。

（二）工程范围为洣泉书院文物建筑，其余与之相关的8处省级文物保护单位不在此列，应另行考虑。

（三）深入调查评估文物展示利用现状、前景及存在的问题，结合保护和管理的需要，制定切实可行的展示技术路线。

（四）应以文物本体原状展示为主，突出对文物价值和内涵的展示和阐释。相关设施、设备不得改变文物建筑内部结构、空间格局和历史风貌，其外观、体量应简约低调，于文物及其周边环境相协调。

（五）严格遵循文物保护原则，采取必要的措施确保文物安全。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制展示利用工程技术方案；由你局组织或委托专业评估机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月2日
