# 国家文物局关于新密市古城寨城址北城墙遗址本体保护工程立项的批复

## 关于新密市古城寨城址北城墙遗址本体保护工程立项的批复

文物保函〔2017〕704号

河南省文物局：

你局《关于新密市古城寨城址北城墙本体保护工程立项的请示》（豫文物〔2017〕43号）收悉。经研究，我局批复如下：

一、原则同意古城寨城址北城墙遗址本体保护工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状加固、消除安全隐患为主，注意控制工程规模、范围和强度，避免过度保护。应仅对存在安全稳定问题的城墙段落进行保护加固，其他已处于稳定状态的城墙段落不宜进行大规模干预，城墙遗址上部已残缺部分不再进行复原。

（二）切实做好前期勘察、研究和试验，对城墙遗址进行详细病害调查，查明病害类型及成因，评估病害对城墙的危害程度及城墙的稳定性，明确城墙遗址的建筑结构、材料和工艺等，为编制保护工程技术方案提供科学依据。

（三）工程措施和材料应当尽量符合传统工艺，可采用土坯砌补、支撑等物理方法减缓遗址本体的损坏，不宜采用化学保护方法，宜结合现状评估进行保护材料和技术的试验、筛选之后合理确定。

（四）应控制植被清除的范围，并防止植被清除过程中对遗址的损坏。城墙两侧治理应首先清退占压城墙遗址的农田，为工程实施提供保障。相关道路、排水、绿篱工程应避免对遗址环境风貌产生过度干扰和影响。

（五）应充分利用前期工程项目的资料和经验，如墙体形制和技法的研究、现场试验和材料的筛选等，避免重复工作。

（六）严格控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年4月10日
