# 国家文物局关于黄粱梦吕仙祠修缮工程立项的批复

## 关于黄粱梦吕仙祠修缮工程立项的批复

文物保函〔2017〕77号

河北省文物局：

你局《关于黄粱梦吕仙祠保护修缮工程立项的请示》（冀文物字〔2016〕243号）收悉。经研究，我局批复如下：

一、同意黄粱梦吕仙祠修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为山门、八仙阁、“蓬莱仙境”照壁、八角亭、午朝门、钟离殿、吕祖殿、卢生殿、东配殿、西配殿、碑廊等11座文物建筑及院落、围墙。不同意东行宫和西行宫等非文物建筑修缮工程。

（三）加强现状勘察，进一步明确文物建筑结构、主要病害类型、残损情况等，查找屋面漏雨、墙体酥碱开裂、木构件糟朽等病害原因，核准“蓬莱仙境”照壁构造，明确建筑历次修缮情况，在此基础上制定有针对性的修缮措施。

（四）应严格控制工程量和工程强度，明确工程范围，合理确定木构件更换、补配的具体数量和标准，避免过度维修。更换下的原构件应详细测绘、登记、评估价值，妥善保管；各类工程资料应由专人管理、建档，并在工程结束后纳入黄粱梦吕仙祠记录档案。八仙阁一层现有地面铺装不影响使用，建议保持现状。

（五）应加强地方建筑做法和传统工艺特色的研究分析，并注意在工程中采用原材料、原工艺。

（六）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（七）应根据工程量合理编制经费预算，补充、细化取费标准和依据。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年1月20日
