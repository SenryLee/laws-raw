# 国家文物局关于在北京鼓楼、钟楼建设控制地带内进行西城区鼓楼西大街35号翻改建工程的批复

## 关于在北京鼓楼、钟楼建设控制地带内进行西城区鼓楼西大街35号翻改建工程的批复

文物保函〔2017〕865号

北京市文物局：

你局《关于西城区鼓楼西大街35号翻改建工程方案的请示》（京文物〔2017〕244号）收悉。经研究，我局批复如下：

一、原则同意在全国重点文物保护单位北京鼓楼、钟楼建设控制地带内进行西城区鼓楼西大街35号翻改建工程和你局意见。

二、对该方案提出以下修改完善意见：

（一）该项目位于全国重点文物保护单位北京鼓楼、钟楼三类建设控制地带内，应严格遵守《中华人民共和国文物保护法》及《北京历史文化名城保护条例》、《北京历史文化名城保护规划》、《北京市旧城二十五片历史文化保护区保护规划》的有关要求，合理确定拟建房屋的规模、高度和外观样式，严格控制施工范围，妥善做好保护类建筑的保护工作，不宜建设地下室，尽量减少对文物本体和景观环境的影响。

（二）进一步深化方案设计，合理调整各屋顶举高与坡度，确保拟建房屋与历史文化街区景观风貌相协调。房屋单体设计图应与总图一致。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。请加强对工程的监管，确保文物及其环境安全。

此复。

国家文物局

2017年4月26日
