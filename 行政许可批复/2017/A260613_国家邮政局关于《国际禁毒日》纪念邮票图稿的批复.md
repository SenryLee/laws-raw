# 国家邮政局关于《国际禁毒日》纪念邮票图稿的批复

国邮复〔2017〕39号

中国邮政集团公司：

你公司关于报审《国际禁毒日》纪念邮票图稿的文（中国邮政函〔2017〕37号）收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套1枚，内容为：国际禁毒日。发行日期为2017年6月26日。经审查，同意使用该套图稿印制邮票。

此复。
