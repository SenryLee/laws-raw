# 国家知识产权局关于同意北京市建设中国汽车产业知识产权投资运营中心的批复

## 关于同意北京市建设中国汽车产业知识产权投资运营中心的批复

国知发管函字〔2017〕300号

北京市知识产权局：

《关于在北京建设中国汽车产业知识产权投资运营中心的请示》（京知局〔2017〕348号）收悉。现批复如下：

一、建设中国汽车产业知识产权投资运营中心，充分发挥国家平台综合服务资源和北汽集团汽车技术创新与产业投资优势，将知识产权融入汽车产业创新链、资本链和政策链，对于提升汽车产业创新发展层次，加快构建高精尖经济结构，推动我国自主品牌汽车走向世界具有重要意义。同意北汽集团产业投资有限公司对接国家知识产权运营公共服务平台，在北京建设中国汽车产业知识产权投资运营中心，原则同意建设方案。

二、要按照本批复精神，会同北汽集团加强对中国汽车产业知识产权投资运营中心的指导和支持，加大投入保障力度，健全管理运行机制，将运营中心打造成为“立足北京、示范全国、服务全球”的汽车产业知识产权投资运营平台，切实发挥服务行业、构建生态、引领发展的示范作用。

三、中国汽车产业知识产权投资运营中心要与国家知识产权运营公共服务平台建立标准化、一体化的业务体系，形成资源共享、业务协作机制。要加快建设汽车产业知识产权线上运营交易平台和线下投资运营联盟，以发明投资、协同创新为核心，打通知识产权投资和运营服务全链条，为加快培育发展汽车领域知识产权强企提供重要支撑。要加快设立汽车产业知识产权运营基金，投资孵化汽车产业高价值专利项目。要建立“投、贷、担、保、服”联动的知识产权投融资体系，拓宽汽车领域创新创业企业融资渠道。

四、要加强对中国汽车产业知识产权投资运营中心的日常监管和考核监督。有关重大事项按程序报告。

国家知识产权局

2017年12月29日
