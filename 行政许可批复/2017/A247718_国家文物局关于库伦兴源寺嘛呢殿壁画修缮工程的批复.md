# 国家文物局关于库伦兴源寺嘛呢殿壁画修缮工程的批复

## 关于库伦兴源寺嘛呢殿壁画修缮工程的批复

文物保函〔2017〕341号

内蒙古自治区文物局：

你局《关于库伦旗兴源寺嘛呢殿壁画抢救性保护修复方案的请示》（内文物发〔2016〕351号）收悉。经研究，我局批复如下：

一、原则同意所报库伦三大寺——兴源寺嘛呢殿壁画修缮工程和你局意见。

二、对该方案提出以下修改意见：

（一）进一步加强前期勘察和研究，明确壁画保护现状、病害类型、受损程度和病害发展趋势等，开展必要的环境监测工作，为制定有针对性的保护措施提供依据。

（二）坚持最小干预原则，严格控制工程范围和强度，完善工程做法，细化修缮措施。

1. 补充壁画颜料层加固处理具体措施。

2. 进一步论证采用石灰材料填补壁画缝隙的安全性，分析说明石灰材料同原有壁画基层材料在同一环境下的一致性和可靠性。

3. 补充灌浆材料选择的试验依据。灌浆材料不宜使用水硬性石灰。

（三）进一步完善文本和图纸，补充修改说明。

三、请你局根据上述意见指导相关单位修改、完善方案，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2017年2月22日
