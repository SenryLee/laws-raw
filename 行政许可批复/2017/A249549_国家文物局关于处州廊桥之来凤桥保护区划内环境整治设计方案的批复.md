# 国家文物局关于处州廊桥之来凤桥保护区划内环境整治设计方案的批复

## 关于处州廊桥之来凤桥保护区划内环境整治设计方案的批复

文物保函〔2017〕597号

浙江省文物局：

你局《关于要求再次审批在全国重点文物保护单位处州廊桥之来凤桥保护区划内实施环境整治工程项目的请示》（浙文物发〔2017〕25号）收悉。经研究，我局批复如下：

一、原则同意所报设计方案。

二、对方案提出以下修改意见：

（一）严格控制整治措施力度，注意保持来凤桥的历史环境风貌，避免过度人工化倾向。

（二）植被配置应突出本地化，并与当地景观相协调。方案中大面积使用小蓟作为菜园植被配置与当地乡土景观不符，建议调整。

（三）完善菜园边界设计，并做好场地排水设计。

（四）统筹考虑处州廊桥整体保护展示，加强各廊桥保护展示与环境整治内容的衔接。

（五）进一步规范设计图纸，图纸上应准确标识施工范围和区域及工程做法。

三、请你局指导有关单位，根据上述意见对方案进行修改和完善，经你局核准并报相关部门批准后实施。施工中请加强监管，确保文物安全。

此复。

国家文物局

2017年3月30日
