# 国家文物局关于雄安新区考古调查2018年度工作方案的批复

文物保函〔2017〕1583号

河北省文物局：

你局《关于呈报雄安新区遥感考古工作方案的请示》（冀文物字〔2017〕196号）和《关于呈报雄安新区考古遗址机载激光测绘调查方案的请示》（冀文物字〔2017〕198号）收悉。经研究，我局批复如下：

一、原则同意雄安新区考古调查2018年度工作方案。

二、该考古工作方案应进行以下必要的修改和完善：

（一）雄安新区2018年度考古调查工作应以机载激光测绘调查为主，工作范围限定为雄安新区中期发展区（200km）内，重点做好机载激光扫描、数字高程模型、数字正射影像、数字地表模型、数字线划图及考古遗址专题图绘制，为后续工作奠定基础。补充DLG数据的要素内容及精度要求。

（二）补充雄安新区历史遥感资料收集的内容，并结合考古工作需求开展必要的数据处理与分析。暂不开展专项遥感考古研究。

（三）应将工作成果纳入雄安新区考古数字化信息管理平台，实现雄安新区各考古和研究项目之间的数据共享。

（四）应加强组织协调，落实人员责任，严格执行工作计划，确保2018年12月底前完成相关工作任务。

三、请你局组织专业考古研究单位和相关业务单位，根据上述意见进一步修改完善工作方案，经你局核准后实施。实施中，应加强日常指导和监管，确保工作质量和人员、文物安全。

国家文物局

2017年9月1日
