# 国家文物局关于在楠溪江宗祠建筑群——谢氏大宗祠建设控制地带内进行周玉叶宅原址拆建项目的批复

## 关于在楠溪江宗祠建筑群——谢氏大宗祠建设控制地带内进行周玉叶宅原址拆建项目的批复

文物保函〔2016〕2130号

浙江省文物局：

你局《关于要求审批在全国重点文物保护单位楠溪江宗祠建筑群之谢氏大宗建设控制地带内进行周玉叶宅原址拆建项目的请示》（浙文物发〔2016〕329号）收悉。经研究，我局批复如下：

一、原则同意在楠溪江宗祠建筑群——谢氏大宗祠建设控制地带内进行周玉叶宅原址拆建项目和你局意见。

二、对所报方案提出如下修改完善意见：

（一）所报项目位于全国重点文物保护单位楠溪江宗祠建筑群——谢氏大宗祠建设控制地带内，须严格遵守《中华人民共和国文物保护法》和浙江省人民政府关于楠溪江宗祠建筑群的相关管理规定，以确保文物本体和历史环境安全为前提，合理兼顾民生改善。

（二）进一步细化方案设计，明确拟建房屋的色彩、屋面材料及外墙、门窗等具体做法。拟建房屋应采用地方传统建筑样式和工艺材料，屋顶为青瓦坡顶，整体色彩应以黑、白、灰为主，确保改建后的房屋与文物本体及周边风貌相协调。

（三）应制定房屋拆建过程中的文物安全保护措施和应急预案，确保文物和人员安全。

（四）补充谢氏大宗祠及周边环境现状照片、周玉叶宅现状照片、新建房屋效果图。

三、请你局指导地方人民政府结合文物保护和村镇建设发展需要，统筹考虑楠溪江宗祠建筑群文物保护、展示利用、环境整治等方面工作，落实保护区划管理规定和具体控制要求，确保文物安全和合理利用。

四、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。请加强对工程的监管，确保文物及其环境安全。

此复。

国家文物局

2017年1月4日
