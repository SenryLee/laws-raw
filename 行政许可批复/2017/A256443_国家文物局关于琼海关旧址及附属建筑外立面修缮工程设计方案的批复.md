# 国家文物局关于琼海关旧址及附属建筑外立面修缮工程设计方案的批复

文物保函〔2017〕1712号

海南省文物局：

你局《关于审核琼海关旧址及附属建筑外立面修缮工程设计方案的请示》（琼文发〔2017〕162号）收悉。经研究，我局批复如下：

一、原则同意所报方案。

二、对该方案提出以下修改意见：

（一）屋面瓦件不应使用现代彩钢瓦，建议订造机制的桔红色陶瓦。

（二）鉴于对旧址外廊原地面铺装材料及做法尚无修复依据，建议对现有大理石地面进行现状整修。

（三）非外廊处百叶窗恢复必要性不足，不宜实施。

（四）不得改变2#新建筑外立面造型，可对2#新建筑外立面进行颜色喷涂，但颜色不宜鲜艳，应与文物建筑相协调。

（五）不宜采用石灰＋水泥混合砂浆，应挖掘地方传统石灰粉刷添加适量有机物的配比。

（六）进一步细化修缮做法说明。包括：注明墙面仿石灰粉刷层的色调；绿色琉璃花格大样应标注厚度；线脚大样应有剖切图等。

三、请你局指导有关单位，根据上述意见对方案进行必要的修改和完善后实施。施工过程中应加强监管，确保文物安全和工程质量。

此复。

国家文物局

2017年10月9日
