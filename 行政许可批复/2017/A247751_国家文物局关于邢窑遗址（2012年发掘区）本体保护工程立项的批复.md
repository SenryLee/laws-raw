# 国家文物局关于邢窑遗址（2012年发掘区）本体保护工程立项的批复

## 关于邢窑遗址（2012年发掘区）本体保护工程立项的批复

文物保函〔2017〕166号

河北省文物局：

你局《关于内丘邢窑遗址（2012年发掘区）本体保护工程立项的请示》（冀文物字〔2016〕273号）收悉。经研究，我局批复如下：

一、原则同意邢窑遗址（2012年发掘区）本体保护工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状加固、消除安全隐患为主，注意控制工程规模、范围和强度，避免过度保护。

（二）切实做好前期勘察、研究和试验，加强对遗址本体病害和赋存地质环境的勘察，查明病害类型及成因，评估病害对遗址的危害程度及拟加固土体的稳定性，为编制保护工程技术方案提供科学依据。

（三）工程措施和材料应当尽量符合传统工艺，尽量采用土坯砌补、支撑等物理方法减缓遗址本体的损坏，不宜采用化学保护方法，保护材料和技术应进行前期室内实验和现场试验、筛选之后合理确定。

（四）严格控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年2月8日
