# 国家文物局关于在镇海堤保护范围和建设控制地带内进行福建省普通国省干线公路联十一线（莆田境）涵江江口至仙游枫亭段建设项目的批复

## 关于在镇海堤保护范围和建设控制地带内进行福建省普通国省干线公路联十一线（莆田境）涵江江口至仙游枫亭段建设项目的批复

文物保函〔2017〕577号

福建省文物局：

你局《关于全国重点文物保护单位镇海堤保护范围内建设项目的请示》（闽文物字〔2017〕63号）收悉。经研究，我局批复如下：

一、原则同意在全国重点文物保护单位镇海堤保护范围和建设控制地带内进行福建省普通国省干线公路联十一线（莆田境）涵江江口至仙游枫亭段建设项目和你局意见。

二、对该方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《镇海堤文物保护规划》以及福建省人民政府关于全国重点文物保护单位镇海堤保护范围和建设控制地带的相关管理规定，合理确定道路选线，严格控制工程量和工程范围，尽量减少对文物本体和景观风貌的影响。

（二）应充分考虑镇海堤结构强度和淤泥触变性问题，进一步开展结构强度检测评估，科学论证多种不利因素共同作用下，文物本体的安全稳定性，补充必要的防护、加固措施。建议适当加大桥墩与镇海堤的距离，确保施工和运营期间的文物安全。补充镇海堤保护区划的相关管理规定和控制要求。

（三）应综合考虑交通运输安全和景观保护需要，科学确定拟建桥梁的外观样式，研提多种比选方案，尽量减少对文物周边环境景观的影响。

（四）应充分考虑施工安全问题，制定必要的临时性文物保护措施和应急预案。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后报有关部门审批。请你局加强工程监管，指导有关单位切实做好施工过程中的文物安全监测工作，确保文物和人员安全。

此复。

国家文物局

2017年3月27日
