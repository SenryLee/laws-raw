# 农业部关于中国水产科学研究院长江水产研究所水生动物防疫综合实验室等3个建设项目可行性研究报告的批复

农计发〔2017〕96号

中国水产科学研究院:

你院报送的《关于申报水生动物防疫综合实验室（长江水产研究所）建设项目的请示》（水科基发〔2017〕55号）、《关于申报水生动物防疫综合实验室（珠江水产研究所）建设项目的请示》（水科基发〔2017〕56号）和《关于申报水生动物防疫专业试验基地（东海水产研究所）建设项目的请示》（水科基发〔2017〕57号）收悉。经研究，原则同意下列项目可行性研究报告。

中国水产科学研究院长江水产研究所水生动物防疫综合实验室建设项目，建设地点位于湖北省武汉市东湖新技术开发区，主要建设内容为扩建实验室2000平方米，购置实验台柜300延米，改造电镜室25平方米，开发远程诊断信息传输及实验设备在线管理系统1套，购置仪器设备31台。总投资2950万元，全部为中央预算内投资（详见附件1）。

中国水产科学研究院珠江水产研究所水生动物防疫综合实验室建设项目，建设地点位于广东省广州市荔湾区芳村，主要建设内容为改造实验室2826平方米，其中洁净区(万级)227.7平方米，半洁净区（30万级）88.8平方米，其他实验室2509.5平方米；购置仪器设备34台（套）。总投资2758万元，全部为中央预算内投资（详见附件2）。

中国水产科学研究院东海水产研究所水生动物防疫专业试验基地建设项目，建设地点位于浙江省宁波市宁海县三门湾现代渔业园区，主要建设内容为新建综合实验室1000平方米、试验车间1000平方米，室外池塘60亩，保温棚14亩，配套建设道路、给排水、污水处理、室外电气等设施；购置仪器设备42台（套）。总投资2623万元，全部为中央预算内投资（详见附件3）。

上述项目建设期均为2年，自投资计划下达之日起计算。

请据此批复，抓紧委托有资质的勘察设计单位编制项目初步设计报我部审批。请严格按照农业基本建设项目管理规定，做好项目组织实施工作，并按月在农业建设项目管理信息系统（http://ac.agri.gov.cn）和国家重大建设项目库（http://kpp.ndrc.gov.cn）中填报实施进度等相关信息。

附件：1.中国水产科学研究院长江水产研究所水生动物防疫综合实验室建设项目可行性研究报告批复表

2.中国水产科学研究院珠江水产研究所水生动物防疫综合实验室建设项目可行性研究报告批复表

3.中国水产科学研究院东海水产研究所水生动物防疫专业试验基地建设项目可行性研究报告批复表
