# 国家文物局关于大觉寺大悲坛后檐挡土墙修缮工程的批复

文物保函〔2017〕1939号

北京市文物局：

你局《关于大觉寺大悲坛后檐挡土墙修缮工程设计方案的请示》（京文物〔2017〕1489号）收悉。经研究，我局批复如下：

一、原则同意所报大觉寺大悲坛后檐挡土墙修缮项目和你局意见。

二、具体修改意见如下：

（一）应补充勘察当前内侧挡墙的稳定性，进一步明确上下两层护坡的结构关系，确保方案的可行性。

（二）应进一步论证单独拆砌下层护坡的可行性，同时补充施工期间对大殿后墙的防护措施。

（三）应加强工程措施的针对性，补充新砌筑毛石墙体的排水设计，明确重砌挡墙顶部的砌筑质量要求。

（四）规范方案文本，补充完善修缮设计图纸，提供清晰的图纸和说明。

（五）拆砌期间应注意核查墙体下部和内部是否存在早期有价值的砌体结构。如有重要发现，并及时调整设计方案，予以妥善保护。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年12月1日
