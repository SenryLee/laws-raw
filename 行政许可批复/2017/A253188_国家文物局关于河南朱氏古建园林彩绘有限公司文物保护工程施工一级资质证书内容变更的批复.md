# 国家文物局关于河南朱氏古建园林彩绘有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于河南朱氏古建园林彩绘有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕853号

河南省文物局：

你局《关于河南朱氏古建园林彩绘有限公司文物保护工程施工一级资质证书内容变更的请示》（豫文物〔2017〕203号）收悉。

经研究，我局同意河南朱氏古建园林彩绘有限公司文物保护工程施工一级资质证书中的注册资金由“630万元”变更为“5000万元”。请你局通知申请单位，携带资质证书副本到我局办理相关手续。

国家文物局

2017年7月20日
