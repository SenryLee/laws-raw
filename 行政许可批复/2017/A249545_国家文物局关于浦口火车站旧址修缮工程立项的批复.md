# 国家文物局关于浦口火车站旧址修缮工程立项的批复

## 关于浦口火车站旧址修缮工程立项的批复

文物保函〔2017〕588号

江苏省文物局：

你局《关于审批浦口火车站旧址修缮工程立项的请示》（苏文物保〔2017〕34号）收悉。经研究，我局批复如下：

一、同意浦口火车站旧址修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）工程范围为浦口火车站旧址文物建筑。

（三）强化现场勘察，准确掌握病害及残损情况，并对1972年改建车站大楼钢筋混凝土楼面工程进行总体评估, 同时结合今后的使用功能对建筑结构安全性进行检测，明确需加固的部位，在此基础上制定针对性保护措施。

（四）坚持“最小干预”原则，严格控制工程量，避免过度修缮。补充大楼木构件、雨廊重新涂刷色彩设计的历史依据。

（五）建筑外观风貌应尽可能依照历史照片加以复原。现有屋顶坡度过小，可考虑采用钢结构恢复原坡度，并恢复屋顶砖砌烟囱。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制修缮工程技术方案；由你局组织专家或委托专业机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月28日
