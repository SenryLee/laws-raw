# 国家文物局关于澍鹫寺塔修缮工程立项的批复

## 关于澍鹫寺塔修缮工程立项的批复

文物保函〔2017〕3号

河北省文物局：

你局《关于阳原澍鹫寺塔修缮保护工程立项的请示》（冀文物字〔2016〕267号）收悉。经研究，我局批复如下：

一、同意澍鹫寺塔修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属文物修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程内容为澍鹫寺塔文物建筑及院落地面修缮。

（三）加强现状勘察，明确文物保存现状、残损情况等，分析塔心柱残损、塔基酥碱等病害原因，客观评估历次修缮工程效果，在此基础上制定有针对性的修缮措施。

（四）应深入研究和分析地方建造工艺、传统做法、建筑材料和构造特征等，注意在维修中使用原工艺和原材料。

（五）坚持最小干预原则，以现状整修为主，严格控制工程量和工程范围。塔心柱宜采用墩接措施，减少塔体扰动。塔身修缮应尽量利用旧砖，并做好垮塌、风化酥碱部位剔补砖体之间的拉结，科学确定灌浆材料的类型、配比，确保材料性能符合加固要求，保证文物安全。同时，应综合考虑澍鹫寺塔的整体排水问题，明确散水修复的具体要求和做法。

（六）根据工程量合理编制经费预算，补充各单项费用取费依据。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案，并组织或委托第三方咨询评估机构进行方案技术评审，依据评估意见进行审批。

此复。

国家文物局

2017年1月6日
