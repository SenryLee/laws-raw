# 国家文物局关于白台寺彩绘泥塑保护修复工程的批复

## 关于白台寺彩绘泥塑保护修复工程的批复

文物保函〔2017〕342号

山西省文物局：

你局《关于审批新绛县白台寺彩绘泥塑保护修复方案的请示》（晋文物〔2016〕215号）收悉。经研究，我局批复如下：

一、原则同意所报白台寺彩绘泥塑保护修复工程和你局意见。

二、对该方案提出以下修改完善意见：

（一）进一步加强现状勘察，补充勘察并说明彩塑内部木骨架的保存情况，进一步调查木骨架构件之间连接的有效性，确保文物安全。

（二）进一步加强实验室和现场试验，合理确定回贴加固材料的具体使用浓度。

（三）坚持最小干预原则，严格控制工程范围和强度，明确各塑像修复的使用材料、工艺做法和操作流程等保护修复措施，增强修复方案的针对性。

1. 进一步细化残损佛台的修复材料和工艺做法要求，注意修复过程中避免携带可溶盐的水等有害物质侵入佛台和彩塑，确保塑像稳定性。

2. 灌浆加固应慎重，不得对不存在稳定性问题的空鼓部位进行灌浆处理。

3. 结合白台寺价值展示与阐释定位，进一步论证缺失塑像补塑的必要性、可行性和修复依据。在此基础上明确塑像缺失部分的局部补塑以及后期不当补塑彩绘的重塑范围，补塑和重塑应在充分考察当地同时期同类型塑像的基础上进行设计。

（四）应根据各塑像病害情况，进一步制定工作计划，明确工程分期。建议先行开展保存现状较差、病害严重的塑像的加固维修工作，及时总结和积累经验，评估加固、维修效果、调整工程措施，分期分批开展塑像加固、维修工作，确保工程质量和文物安全。

（五）进一步规范文本文字，细化病害调查图纸，补充修复设计图纸。

三、请你局根据上述意见指导相关单位修改、完善方案，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2017年2月22日
