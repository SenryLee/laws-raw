# 国家文物局关于寨英村古建筑群——裕国通商商号展示利用工程立项的批复

## 关于寨英村古建筑群——裕国通商商号展示利用工程立项的批复

文物保函〔2017〕479号

贵州省文物局：

你局《关于送审〈全国重点文物保护单位集中成片传统村落贵州松桃县寨英村古建筑群·西门街、何家坝巷展示工程立项报告〉的请示》（黔文物呈〔2017〕2号）收悉。经研究，我局意见如下：

一、同意寨英村古建筑群——裕国通商商号展示利用工程立项。

二、在编制展示利用方案时，应注意以下方面：

（一）该工程属文物展示利用工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物的真实性和完整性，充分阐释与展示文物的价值和内涵。

（二）工程内容为寨英村古建筑群裕国通商商号文物建筑展示利用。

（三）应加强前期研究，系统收集历史资料，深入研究文物价值内涵，根据《寨英村古建筑群保护规划》要求、文物建筑保存现状和寨英村整体展示利用定位，科学确定展示主题。

（四）应进一步明确展示方式和内容，注意突出徽派建筑与西南少数民族建筑文化相结合的营造特色，重点展现民风民俗和地域文化特征，并兼顾当地居民日常生活和文化活动需求。同时，应细化各单体建筑的展示方式，注意单体建筑展示与村落整体展示之间的衔接，采用多种展示方式和现代科技手段，增强展示的互动性、趣味性和科普性。

（五）展示工程施工中应充分考虑文物建筑的自身特点和承载力，严格控制文物建筑内部改造强度，不得随意拆改建筑结构。应严格执行有关消防安全的技术规范和导则，不得直接在梁、柱等可燃构件上敷设电气线路，合理设置新增设施设备。

（六）应科学确定游客承载量，明确管理主体，落实管理责任，制定必要的日常巡查、维护措施和应急预案，确保文物和人员安全。

（七）应根据工程量合理编制经费预算，补充各单项费用取费依据。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案，组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

四、暂不同意舒从明卫生所药铺、李财明民居、简昌友裁缝铺、王华平传统粉面馆、保和顺商号、曹家盐号、黄国清烟馆、万寿宫、福寿宫、方文奎民居等民居建筑展示利用工程。应根据《寨英村古建筑群保护规划》和维修工程进展，区分轻重缓急，增强寨英村古建筑群保护展示工作的计划性和科学性。建议现阶段重点考虑南门街、中街片区等已修缮文物建筑的展示利用，将文物保护展示与居民生活条件改善、旅游发展相结合，充分发挥文物保护的社会效益。

此复。

国家文物局

2017年3月14日
