# 国家文物局关于上高会战遗址二期修缮工程的批复

## 关于上高会战遗址二期修缮工程的批复

文物保函〔2017〕565号

江西省文物局：

你局《关于呈报〈上高会战遗址二期修缮工程立项报告〉的请示》（赣文物局字〔2017〕6号）收悉。经研究，我局批复如下：

一、同意上高会战遗址二期修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）工程范围为上高会战遗址11处文物建筑及院落。

（三）强化现场勘察，全面掌握各处建筑的病害及残损状况，并对一期修缮工程措施及效果进行评估，在此基础上制定针对性修缮措施。

（四）该旧址文物建筑多为祠堂和传统民居建筑，应深入研究其传统材料及工艺做法，为装修补配等措施提供设计依据。

（五）坚持最小干预原则，严格控制工程范围和工程量，避免过度修缮

（六）相关设计应兼顾文物的展示利用需求。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制修缮工程技术方案；由你局组织专家或委托专业评估机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月24日
