# 国家文物局关于在阳明洞保护范围和建设控制地带内实施玩易窝公园项目的批复

## 关于在阳明洞保护范围和建设控制地带内实施玩易窝公园项目的批复

文物保函〔2017〕1227号

贵州省文物局：

你局《关于在全国重点文物保护单位阳明洞保护范围内实施玩易窝公园项目的请示》（黔文物呈〔2017〕17号）收悉。经研究，我局批复如下：

一、原则同意在阳明洞保护范围和建设控制地带内实施玩易窝公园项目和你局意见。

二、对所报方案提出以下修改意见：

（一）应严格遵守《中华人民共和国文物保护法》和《阳明洞文物保护规划》关于保护范围和建设控制地带的相关管理规定，严格控制工程量和工程范围，尽量减少施工建设对文物本体和景观环境的影响，确保文物安全。

（二）应进一步优化方案设计，根据文物周围岩体状况、覆土深度等情况确定施工扰土深度，避免植被清理措施对玩易窝顶部岩体造成影响，确保文物本体安全。

（三）深入研究阳明洞的文化内涵，在《阳明洞文物保护规划》的指导下，注意保护范围内自然环境的保护，包括玩易窝及周边山形、水系、绿植和视线通廊等，避免过度人工化和现代景观园林化设计倾向。应进一步调整规划布局，服务设施不宜设置在保护范围内。

（四）应进一步规范文本与图纸，核实建设控制地带的具体范围。

三、请你局根据上述意见，组织相关单位对所报方案进行修改、完善，并经你局核准后按程序报相关部门批准实施。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案，确保文物本体和环境在公园项目实施工过程中不受破坏。请加强对工程的监管，确保文物及其环境安全。

此复。

国家文物局

2017年7月12日
