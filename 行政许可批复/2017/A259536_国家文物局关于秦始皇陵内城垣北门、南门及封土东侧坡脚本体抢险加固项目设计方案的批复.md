# 国家文物局关于秦始皇陵内城垣北门、南门及封土东侧坡脚本体抢险加固项目设计方案的批复

文物保函〔2017〕2042号

陕西省文物局：

你局《关于秦始皇陵内城垣北门、南门及封土东侧坡脚本体抢险加固工程设计方案的请示》（陕文物字〔2017〕210号）收悉。经研究，我局批复如下：

一、原则同意秦始皇陵内城垣北门、南门及封土东侧坡脚本体抢险加固项目设计方案。

二、该项目应坚持最小干预原则，严格控制工程量和施工范围。封土东侧边坡加固工程应进一步缩减工程量，仅对高差5米以上的边坡进行加固支护，并注意做好支护土体与遗址交接处的密闭处理，防止雨水下渗。同时，遗址现有植被清理应慎重，重点清除严重影响遗址稳定的高大树木，避免大规模干预造成安全隐患。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善后实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。同时，应组织专业考古研究单位进一步做好必要的考古工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好维修后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

国家文物局

2017年12月29日
