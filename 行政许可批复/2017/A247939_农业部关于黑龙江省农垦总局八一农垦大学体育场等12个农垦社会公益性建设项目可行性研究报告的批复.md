# 农业部关于黑龙江省农垦总局八一农垦大学体育场等12个农垦社会公益性建设项目可行性研究报告的批复

农计发〔2017〕2号

黑龙江省农垦总局:

《黑龙江省农垦总局关于呈报黑龙江垦区2017年社会公益事业基础设施建设项目可行性研究报告的请示》(黑垦局呈〔2016〕94号)收悉。经研究，原则同意下列项目可行性研究报告。

1.八一农垦大学体育场及附属设施改造工程建设项目，建设地点位于黑龙江省大庆市黑龙江八一农垦大学校园内。主要建设内容为改建体育场地18903平方米、标枪场地141平方米、撑杆跳场地77平方米、沙坑20平方米、铁球场地225平方米、校区道路3702平方米，改建供热管网2020米，新建路缘石1381米、坡道818平方米、排水沟894米，场地硬化面积1721平方米。总投资1040万元，其中中央预算内投资830万元，地方投资210万元（详见附件1）。

2.襄河农场场部小城镇基础设施建设项目，建设地点位于黑龙江省黑河市五大连池市襄河农场场部。主要建设内容为改造场部道路13100米。总投资1055万元，其中中央预算内投资845万元，地方投资210万元（详见附件2）。

3.八五一一农场场部供水工程建设项目，建设地点位于黑龙江省鸡西市密山市八五一一农场场部。主要建设内容为新建机井泵房3座、给水处理厂用房600平方米，敷设输水管线3940米，改建配水管网1785米，改造水塔1座等。安装给水设备和配电设施。总投资990万元，其中中央预算内投资790万元，地方投资200万元（详见附件3）。

4.牡丹江管理局局直小城镇基础设施建设项目，建设地点位于黑龙江省鸡西市密山市牡丹江管理局。主要建设内容为敷设给水管线3600米，新建2000立方米蓄水池1座，建设阀门井73个、给水变频柜和给水柜各2台、围墙2500米、路缘石2940米、排水沟2100米，平整场地2万平方米，改造道路面层6300平方米，拓宽道路2840平方米，安装路灯36套，监控系统一套。总投资1035万元，其中中央预算内投资825万元，地方投资210万元（详见附件4）。

5.江滨农场场部小城镇基础设施建设项目，建设地点位于黑龙江省鹤岗市萝北县江滨农场场部。主要建设内容为改造主干道3915米，建设人行道1370米，配套建设排水沟2885米，购置安装路灯24套。总投资1015万元，其中中央预算内投资810万元，地方投资205万元（详见附件5）。

6.宝泉岭管理局局直小城镇基础设施建设项目，建设地点位于黑龙江省鹤岗市萝北县宝泉岭管理局。主要建设内容为改造主干道路面1638米，建设人行道3044米，配套排水沟3044米，安装路灯45套。总投资1270万元，其中中央预算内投资1015万元，地方投资255万元（详见附件6）。

7.红兴隆管理局局直小城镇基础设施建设项目，建设地点位于黑龙江省双鸭山市友谊县红兴隆管理局。主要建设内容为改造主干道3111米，建设人行道2331米、路缘石2331米、排水沟2331米。总投资1685万元，其中中央预算内投资1350万元，地方投资335万元（详见附件7）。

8.胜利农场场部小城镇基础设施建设项目，建设地点位于黑龙江省双鸭山市饶河县胜利农场场部。主要建设内容为改造道路7200米，敷设排水管道1860米，建设雨水井80座、过路桥1座，安装路灯150套。总投资1005万元，其中中央预算内投资805万元，地方投资200万元（详见附件8）。

9.北兴农场场部小城镇基础设施建设项目，建设地点位于黑龙江省七台河市新兴区北兴农场场部。主要建设内容为改造场部道路7774米，建设人行道1619米。总投资1040万元，其中中央预算内投资830万元，地方投资210万元（详见附件9）。

10.查哈阳农场场部小城镇基础设施建设项目，建设地点位于黑龙江省齐齐哈尔市甘南县查哈阳农场场部。主要建设内容为改造道路4768米，建设过路圆涵10座。总投资1055万元，其中中央预算内投资845万元，地方投资210万元（详见附件10）。

11.嫩北农场场部小城镇基础设施建设项目，建设地点位于黑龙江省黑河市嫩江县嫩北农场场部。主要建设内容为新建供水管道4500米、道路3100米、蓄水池1座，打机井2眼，铺设输电线路12000米等。总投资950万元，其中中央预算内投资760万元，地方投资190万元（详见附件11）。

12.牡丹江管理局中心医院医疗设备购置项目，建设地点位于黑龙江省鸡西市密山市牡丹江管理局中心医院。主要建设内容为购置1.5T核磁共振成像系统、血管内超声及冠状动脉内血流储备分数测量系统。总投资1155万元，其中中央预算内投资925万元，地方投资230万元（详见附件12）。

上述项目建设期均为2年，自投资计划下达之日起计算。

请据此批复，督促建设单位抓紧委托有资质的勘察设计单位编制项目初步设计报你局审批。请严格按照农业基本建设项目管理规定，做好项目组织实施工作，并按月在农业建设项目管理信息系统（http://ac.agri.gov.cn）和投资项目在线审批监管平台（国家重大建设项目库模块，http://kpp.ndrc.gov.cn）中填报实施进度等相关信息。
