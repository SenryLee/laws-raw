# 国家文物局关于社稷坛（中山公园）棂星门修缮项目的批复

文物保函〔2017〕2006号

北京市文物局：

你局《社稷坛（中山公园）棂星门修缮工程方案的请示》（京文物〔2017〕1411号）收悉。经研究，我局批复如下：

一、原则同意社稷坛（中山公园）棂星门修缮项目和你局意见。

二、具体修改意见如下：

（一）应补充前期调研内容。进一步研究东棂星门南柱发生断裂的原因，并提出针对致因的具体措施。

（二）应补充地勘报告，科学评估地基承载力现状，并进一步论证采取注浆加固地基措施的依据和必要性。

（三）应进一步论证东、北棂星门拟拆卸预案，研究棂星门原组装工艺和连接方法，对于可能粘连的石构件应提出具体应对措施。

（四）应进一步论证加固方案的可行性和有效性，慎用以水硬性石灰为主的材料，及锚杆连接结构性裂隙，避免干预破坏。

（五）应针对棂星门下部铺设木楞与木地板所造成的积水问题提出具体措施。

（六）建议先针对东侧棂星门进行粘接加固工作，待取得相关经验后再展开对北棂星门等处的加固工作。应明确要求施工单位制定和细化相关修缮方案，以确保修缮的流程及技术的准确运用。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

国家文物局

2017年12月18日
