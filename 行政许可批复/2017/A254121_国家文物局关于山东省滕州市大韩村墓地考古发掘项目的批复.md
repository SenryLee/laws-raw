# 国家文物局关于山东省滕州市大韩村墓地考古发掘项目的批复

文物保函〔2017〕1369号

山东省文物局：

你局报送的山东省滕州市大韩村墓地考古发掘项目申请书（存档编号2017191010）收悉。经研究，我局批复如下：

一、原则同意大韩村墓地考古发掘项目。大韩村墓地墓葬数量众多，墓内随葬器物丰富，具有重要的历史、科学、艺术价值。请你局指导考古发掘单位制定详细的工作计划及出土文物保护预案，确保发掘工作科学、有序开展。如有重要考古发现，应及时向我局报告。

二、请你局加强管理，督促地方人民政府切实落实文物日常巡查和看护责任，确保大韩村墓地文物安全。

国家文物局

2017年8月8日
