# 农业部关于陕西省陕西齐峰果业有限责任公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕42号

陕西省农业厅：

《陕西省农业厅关于报送陕西省2017年数字农业建设试点项目可行性研究报告的报告》（陕农业计财〔2017〕9号）收悉。经研究，批复如下：

一、原则同意上报的陕西齐峰果业现代农业园区数字农业建设试点项目可行性研究报告。项目建设单位为陕西齐峰果业有限责任公司，建设地点为陕西省宝鸡市眉县、汉中市城固县。项目建设期2年。

二、项目建设内容：一是环境监测控制系统建设，包括气象及墒情监测系统、视频监控系统等；二是工厂化育苗系统建设，包括播种、嫁接、催芽、移栽等集约化育苗装置、育苗环境检测及控制系统等；三是生产过程管理系统建设，包括耕整、移栽、施肥、施药机具、水肥一体化系统、果树生理健康监测系统等；四是产品质量安全监控系统建设，包括生产过程质量管理设备、农产品质量追溯系统等；五是采后商品化处理系统建设，包括自动化清洗、分级、包装、扫码、信息采集等设备。

三、项目建设目标：项目建成后，形成猕猴桃生产关键环节数字化标准与规范，项目区猕猴桃亩均增产10%，优质果品率提高10%，亩均节水50%、节肥50%、节药30%、节省劳动力20个。

四、项目投资及来源：经评估核定，项目估算总投资2716万元，其中中央预算内投资按815万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你省申报后续数字农业建设试点项目的资格。
