# 国家邮政局关于《内蒙古自治区成立七十周年》纪念邮票图稿的批复

国邮复〔2017〕15号

中国邮政集团公司：

你公司关于报审《内蒙古自治区成立七十周年》纪念邮票图稿的文（中国邮政函〔2017〕10号）收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套3枚，内容分别为：1.守望相助；2.亮丽北疆；3.民族和谐。发行日期为2017年5月1日。经审查，同意使用该图稿印制邮票。

此复。

国家邮政局

2017年3月6日
