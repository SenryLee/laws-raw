# 国家文物局关于息烽集中营旧址修缮工程立项的批复

## 关于息烽集中营旧址修缮工程立项的批复

文物保函〔2017〕382号

贵州省文物局：

你局《关于送审〈贵州省息烽集中营旧址文物保护工程立项报告〉的请示》（黔文物呈〔2016〕96号）收悉。经研究，我局批复如下：

一、同意息烽集中营旧址修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）工程范围为息烽集中营旧址文物建筑。

（三）进一步研究相关历史信息，强化现场勘察，深入开展文物价值评估和保存现状评估，针对不同类型文物建筑准确掌握病害及残损情况,为制定有针对性的保护措施提供科学依据。

（四）坚持“最小干预”原则，严格控制工程量，对无碍建筑结构安全的残损构件应尽可能修补留用。

（五）相关设计应兼顾今后文物的展示利用需求。

（六）合理核减经费预算。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制修缮工程技术方案；由你局组织或委托专业机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月2日
