# 中国证监会关于核准青岛食品股份有限公司股票在全国中小企业股份转让系统公开转让的批复

## 关于核准青岛食品股份有限公司股票在全国中小企业股份转让系统公开转让的批复

证监许可〔2017〕1839号

青岛食品股份有限公司：

《青岛食品股份有限公司关于公司股票在全国中小企业股份转让系统挂牌公开转让的申请报告》（青食发〔2017〕28号）及相关文件收悉。根据《公司法》《证券法》和《非上市公众公司监督管理办法》（证监会令第96号）等有关规定，经审核，现批复如下：

核准你公司股票在全国中小企业股份转让系统公开转让，并将你公司纳入非上市公众公司监管。

中国证监会

2017年10月17日
