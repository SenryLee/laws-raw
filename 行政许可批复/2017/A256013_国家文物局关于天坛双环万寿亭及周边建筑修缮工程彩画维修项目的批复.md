# 国家文物局关于天坛双环万寿亭及周边建筑修缮工程彩画维修项目的批复

文物保函〔2017〕1644号

北京市文物局：

你局《天坛双环万寿亭及周边建筑修缮工程彩画维修方案的请示》（京文物〔2017〕1015号）收悉。经研究，我局批复如下：

一、原则同意所报天坛双环万寿亭及周边建筑彩画维修项目和你局意见。

二、对项目提出如下意见：

（一）进一步加强对原制作材料、工艺以及彩画形制内容等历史做法的研究，并据此完善措施内容。

（二）进一步细化方案，确保不同部位的彩画符合规制要求，如明、次间之分。建议只恢复连廊平梁枋彩画，举架不是原构架，不应施加彩绘。应绘制彩画小样，经论证认可后方可实施。

（三）补充对制作材料的要求。

三、具体工程方案由你局指导有关单位，按照上述意见进行修改、完善，经你局核准后实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求并做好施工组织管理，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年9月15日
