# 国家邮政局关于《“一带一路”国际合作高峰论坛》纪念邮票图稿的批复

国邮复〔2017〕25号

中国邮政集团公司:

你公司报审的《“一带一路”国际合作高峰论坛》纪念邮票图稿收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套1枚，内容为：“一带一路”国际合作高峰论坛。发行日期为2017年5月14日。经审查，同意使用该图稿（图稿复印件见附件）印制邮票。

此复。

附件：“一带一路”国际合作高峰论坛纪念邮票图稿复印件（略）
