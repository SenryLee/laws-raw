# 国家邮政局关于《外国音乐家（二)》纪念邮票图稿的批复

国邮复〔2017〕48号

中国邮政集团公司：

你公司关于报审《外国音乐家（二）》纪念邮票图稿的文（中国邮政函〔2017〕48号）收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套4枚，内容分别为：1.舒伯特；2.肖邦；3.李斯特；4.马勒。发行日期为2017年9月9日。经审查，同意使用该套图稿印制邮票。

此复。
