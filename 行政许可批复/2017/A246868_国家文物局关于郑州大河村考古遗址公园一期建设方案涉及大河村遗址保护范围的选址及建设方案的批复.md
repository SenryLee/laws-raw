# 国家文物局关于郑州大河村考古遗址公园一期建设方案涉及大河村遗址保护范围的选址及建设方案的批复

## 关于郑州大河村考古遗址公园一期建设方案涉及大河村遗址保护范围的选址及建设方案的批复

文物保函〔2017〕114号

河南省文物局：

你局《关于上报大河村考古遗址公园一期建设方案的请示》（豫文物〔2016〕328号）收悉。经研究，我局批复如下：

一、原则同意大河村考古遗址公园一期建设方案。

二、应进一步明确大河村考古遗址公园的定位，在确保文物安全和科学展示遗址价值与内涵的基础上，充分考虑其所处区位，积极承担城市功能，充分发挥社会效益。

三、大河村考古遗址公园建设中的保护性设施建设、展示游线安排及辅助展示、考古工作中心及库房建设、环境整治等工程均应进一步编制科学详细的初步设计和施工方案，经你局核准后实施。同时，应进一步严格控制各类建筑的规模、体量和高度，优化外观设计，并尽量降低配套展示及服务设施对遗址氛围和考古遗址公园景观的干扰，注意与遗址及其周边环境相协调。

四、请你局指导继续做好大河村遗址的考古及研究工作，进一步明确大河村遗址的聚落性质、功能布局、文化特点等，为后续展示利用和发挥社会效益奠定基础。

国家文物局

2017年1月23日
