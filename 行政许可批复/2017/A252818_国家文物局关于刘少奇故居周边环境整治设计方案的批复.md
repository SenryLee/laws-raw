# 国家文物局关于刘少奇故居周边环境整治设计方案的批复

## 关于刘少奇故居周边环境整治设计方案的批复

文物保函〔2017〕734号

湖南省文物局：

你局《关于审批〈刘少奇故居周边环境整治方案设计〉的请示》（湘文物报〔2016〕201号）收悉。经研究，我局批复如下：

一、原则同意所报设计方案。

二、对设计方案提出以下修改意见：

（一）在进一步研究的基础上，深化故居前坪复原专项设计。

（二）针对自然灾害治理内容，应进行具体的破坏因素及危害程度分析，科学编制滑坡治理、防涝等各项工程措施。

（三）补充说明排水系统整治措施设计思路，明确故居围墙内排水系统与院外新建、翻建排水沟走向的关系。

（四）缩减地被植物及乔木树种改良工程量，避免大规模植被改造处理及园林化设计倾向。

（五）针对道路、池塘驳岸的改造方案，需补充说明当地传统材料及做法。注意保持文物建筑的历史环境氛围，尽量控制增设人造景观。

（六）建议保留池塘常年水位以下的混凝土结构，仅对常年水位以上部分恢复传统石作塘基。

请你局指导有关单位进一步完善并深化设计方案，经你局核准并报相关部门批准后实施。施工中请加强监管，确保文物安全。

此复。

国家文物局

2017年4月12日
