# 国家邮政局关于同意仿印“军人贴用”等邮票图案制作贵金属制品的批复

国邮复〔2017〕31号

中国邮政集团公司济南市分公司：

根据《中华人民共和国邮政法实施细则》规定，按照《仿印邮票图案管理办法》规定程序，国家邮政局对你公司经山东省邮政管理局初审的有关仿印邮票图案及其制品的申请材料依法进行了审核。现批复如下：

一、同意你公司原色原大仿印1953年8月发行的“军人贴用”邮票（全套3枚）、1938年8月晋察冀边区临时邮政印制的“晋察冀边区抗战军人”纪念邮票（全套1枚）、1943年淮南交通总站发行的“‘稿’字” 邮票（全套1枚）、1945年10月山东解放区山东战时邮政总局发行的“中共八一建军纪念”邮票（全套1枚）等图案制作10克/枚纯银制品，制作数量为50000套（6枚/套）。承制单位为南京苏泉工贸有限公司。

原色原大仿印1953年8月发行的“军人贴用”邮票（全套3枚）、1938年8月晋察冀边区临时邮政印制的“晋察冀边区抗战军人”纪念邮票（全套1枚）、1943年淮南交通总站发行的“‘稿’字” 邮票（全套1枚）、1945年10月山东解放区山东战时邮政总局发行的“中共八一建军纪念”邮票（全套1枚）等图案制作30克/枚四方连纯银制品，制作数量为20000套（6枚/套）。承制单位为南京苏泉工贸有限公司。

二、仿印邮票图案制品或者其外包装上须标明下列各项：

（一）仿印单位名称、地址；

（二）审批机关和批准文号；

（三）制作数量；

（四）制作单位；

（五）印制单位；

（六）其他应当标明的有关事项。

三、仿印1953年8月发行的“军人贴用”邮票（全套3枚）、1938年8月晋察冀边区临时邮政印制的“晋察冀边区抗战军人”纪念邮票（全套1枚）、1943年淮南交通总站发行的“‘稿’字” 邮票（全套1枚）、1945年10月山东解放区山东战时邮政总局发行的“中共八一建军纪念”邮票（全套1枚）图案及其制品由山东省邮政管理局负责监制。你公司须持批准文件与承制企业按照国家有关规定签订印制合同，并在印制前将仿印邮票图案样品送监制单位——山东省邮政管理局（地址：山东省济南市纬二路168号）审签后方可正式生产。在仿印邮票图案制品发行前向国家邮政局（地址：北京市西城区北礼士路甲8号）送缴样品存档。不得转让获准仿印邮票图案的制作权和发行权。

四、此文件有效期截止到2018年4月26日，如在批文有效期内未进行仿印的，必须报国家邮政局备案，并将批准文件退回。

国家邮政局
