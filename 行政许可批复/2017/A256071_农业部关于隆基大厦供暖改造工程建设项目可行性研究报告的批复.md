# 农业部关于隆基大厦供暖改造工程建设项目可行性研究报告的批复

农计发〔2017〕112号

农业部机关服务局:

《关于报送隆基大厦供暖改造工程投资概算的函》（农服（机房）〔2017〕24号）收悉。经研究，批复如下。

原则同意隆基大厦供暖改造工程建设项目。项目建设地点为金宝街67号隆基大厦，主要建设内容为隆基大厦红线外供暖一次线改造，改造管线总长度106米。核定概算总投资240万元，资金来源全部为自筹资金。项目建设期为1年。

该项目不再批复初步设计，请据此批复，抓紧组织项目实施工作。要按照招投标事项核准表要求，做好有关招投标工作。请切实履行好项目监管责任，督促项目建设单位严格按照基本建设有关规定执行。

附件：隆基大厦供暖改造工程建设项目招标投标事项核准表

农业部

2017年9月17日
