# 中国证监会关于核准圣邦微电子（北京）股份有限公司首次公开发行股票的批复

## 关于核准圣邦微电子（北京）股份有限公司首次公开发行股票的批复

证监许可〔2017〕647号

圣邦微电子（北京）股份有限公司:

你公司报送的《圣邦微电子（北京）股份有限公司首次公开发行人民币普通股（A股）申请报告》（圣邦股份〔2015〕001号）及相关文件收悉。根据《公司法》、《证券法》和《首次公开发行股票并在创业板上市管理办法》（证监会令第123号）等有关规定，经审核，现批复如下：

一、核准你公司公开发行新股不超过1,500万股。

二、你公司本次发行股票应严格按照报送我会的招股说明书和发行承销方案实施。

三、本批复自核准发行之日起12个月内有效。

四、自核准发行之日起至本次股票发行结束前，你公司如发生重大事项，应及时报告我会并按有关规定处理。

中国证监会

2017年5月5日
