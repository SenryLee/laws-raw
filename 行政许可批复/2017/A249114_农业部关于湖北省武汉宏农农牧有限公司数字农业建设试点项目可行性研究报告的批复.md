# 农业部关于湖北省武汉宏农农牧有限公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕51号

湖北省农业厅：

《湖北省农业厅关于申报武汉宏农农牧有限公司全智能化蛋鸡产业园数字农业建设试点项目的请示》（鄂农计〔2017〕5号）收悉。经研究，批复如下：

一、原则同意上报的武汉宏农农牧有限公司全智能化蛋鸡产业园数字农业建设试点项目可行性研究报告。项目建设单位为武汉宏农农牧有限公司，建设地点为湖北省武汉市黄陂区。项目建设期2年。

二、项目建设内容：一是自动化精准环境控制系统建设，包括双纵、单纵蛋鸡智能环境控制系统等；二是数字化精准饲喂管理系统建设，包括数字化管理饮水、供料系统等；三是机械化自动产品收集系统建设，包括自动集蛋系统和鸡蛋分级包装系统等；四是无害化粪污处理系统建设，包括全程封闭连接带式自动清粪系统等。

三、项目建设目标：项目建成后，实现生产智能化、经营信息化、管理数据化和服务在线化，项目区蛋鸡数字化养殖总规模达到150万只，年新增产蛋量11250吨、新增有机肥产量2万吨。

四、项目投资及来源：经评估核定，项目估算总投资3619万元，其中中央预算内投资按1086万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你省申报后续数字农业建设试点项目的资格。
