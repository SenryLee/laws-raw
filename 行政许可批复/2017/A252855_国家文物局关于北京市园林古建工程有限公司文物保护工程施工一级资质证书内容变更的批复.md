# 国家文物局关于北京市园林古建工程有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于北京市园林古建工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕562号

北京市文物局：

你局《关于北京市园林古建工程有限公司文物保护工程施工资质证书法定代表人变更的请示》（京文物〔2017〕479号）收悉。

经研究，我局同意北京市园林古建工程有限公司文物保护工程施工一级资质证书中的法定代表人由“杨宝生”变更为“李辉坚”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局

2017年5月12日
