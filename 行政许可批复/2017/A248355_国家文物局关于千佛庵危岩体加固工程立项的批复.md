# 国家文物局关于千佛庵危岩体加固工程立项的批复

## 关于千佛庵危岩体加固工程立项的批复

文物保函〔2017〕412号

山西省文物局：

你局《关于申请隰县千佛庵土山体加固工程立项的请示》（晋文物〔2017〕4号）收悉。经研究，我局批复如下：

一、同意千佛庵土山体加固工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属保护性设施建设工程，应遵循“不改变文物原状”、“最小干预”等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程内容为千佛庵山门及大殿周边危岩体加固。

（三）应加强地质勘察，明确千佛庵南坡、北坡岩土层物理力学性质，分析地质灾害成因、类型及危害性，科学评估山体结构稳定性，补充历次加固工程效果，为制定有针对性的加固措施提供依据。

（四）应坚持最小干预原则，以局部危岩体治理为主，严格控制工程范围、规模与工程量，避免过度加固。应充分考虑当地岩土体松散特点，合理确定加固防护措施，以隐蔽工程为主，尽量减少对景观风貌的影响。补充必要的临时性文物保护、监测和景观协调措施。

（五）根据工程量核减经费预算，合理确定工程内容和取费项目，补充取费标准。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案，并组织专家或委托专业机构进行方案技术评审，依据评估意见进行审批。

此复。

国家文物局

2017年3月2日
