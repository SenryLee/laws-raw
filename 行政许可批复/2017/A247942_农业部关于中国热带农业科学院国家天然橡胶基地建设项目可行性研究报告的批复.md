# 农业部关于中国热带农业科学院国家天然橡胶基地建设项目可行性研究报告的批复

农计发〔2017〕7号

中国热带农业科学院:

《中国热带农业科学院关于上报国家天然橡胶基地胶园道路建设项目（第一期）可行性研究报告的请示》(热科院计〔2016〕351号)收悉。经研究，原则同意项目可行性研究报告。

建设地点位于海南省儋州市中国热带农业科学院院区基地，主要建设内容为建设胶园林间道路57千米,配套管涵87个、排水沟4900米、挡土墙855立方米、防护围栏5000米。总投资2830万元，全部为中央预算内投资（详见附件）。项目建设期为2年，自投资计划下达之日起计算。

请建设单位据此批复，抓紧委托有资质的勘察设计单位编制项目初步设计报我部审批。请严格按照农业基本建设项目管理规定，做好项目组织实施工作，并按月在农业建设项目管理信息系统（http://ac.agri.gov.cn）和投资项目在线审批监管平台（国家重大建设项目库模块，http://kpp.ndrc.gov.cn）中填报实施进度等相关信息。

附件：中国热带农业科学院国家天然橡胶基地建设项目可行性研究报告批复表

农业部

2017年2月8日
