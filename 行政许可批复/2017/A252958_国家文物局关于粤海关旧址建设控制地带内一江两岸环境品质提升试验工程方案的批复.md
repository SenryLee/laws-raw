# 国家文物局关于粤海关旧址建设控制地带内一江两岸环境品质提升试验工程方案的批复

## 关于粤海关旧址建设控制地带内一江两岸环境品质提升试验工程方案的批复

文物保函〔2017〕1094号

广东省文物局：

你局《关于在全国重点文物保护单位粤海关旧址建设控制地带内一江两岸环境品质提升试验工程方案的请示》（粤文物审〔2017〕38号）收悉。经研究，我局批复如下：

一、原则同意所报方案。

二、对该方案提出以下修改意见：

（一）清理文物建筑立面应主要对污渍严重部位进行清洗，不得损伤建筑本体，同时应考虑整体效果。

（二）建议人行道栏杆选用方案一黑色铸铁式样。

（三）文物建筑夜间照明项目应单独编制方案另行报批，方案应明确LED 灯具体的安装部位和安装方法。

三、请你局指导相关单位根据上述意见对方案进行修改完善，经你局核准后实施。工程施工期间，应加强对工程的监管，确保文物安全。

此复。

国家文物局

2017年6月16日
