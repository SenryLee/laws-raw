# 国家文物局关于北京市通州近代学校建筑群潞河中学人民楼、解放楼、潞友楼屋面防水抢险修缮项目的批复

文物保函〔2017〕1469号

北京市文物局：

你局《关于北京市通州近代学校建筑群潞河中学人民楼、解放楼、潞友楼屋面防水抢险修缮工程方案的请示》（京文物〔2017〕634号）收悉。经研究，我局批复如下：

一、原则同意所报方案。

二、对方案提出以下修改意见：

（一）深化文物现状勘察。进一步论证全部铲除屋面旧防水层的必要性；说明各楼现状排水系统，现有防水层的材料、工艺、制作时间及其时效性等；说明是否有雨水管及其与屋面、雨水口的构造方式与排水通畅情况；若室内存在漏水部位，应补充必要的残损照片，并做具体勘察。

（二）文物建筑屋面防水要求应补充执行楼房屋面防水规范或标准的要求。

（三）补充新做SBS 防水层的材料性能的可靠性分析。建议在SBS防水卷材之上增加适当的防护层，以防止防水卷材因日晒等原因老化速度过快，尽量延长防水层使用期。

（四）补充对文物建筑屋面排水口进行定期清理的措施。

（五）深化方案设计图纸表达，准确标注各部位屋面排水方向，绘制所有泛水做法部位和出水口部位的构造详图。

请你局组织相关单位按照上述意见对方案进行修改完善后，经你局核准后实施。施工过程中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2017年8月24日
