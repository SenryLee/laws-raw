# 农业部关于内蒙古自治区赤峰市草原防火基础设施建设等4个项目可行性研究报告的批复

农计发〔2017〕29号

内蒙古自治区农牧业厅：

《关于上报内蒙古自治区草原防火基础设施建设项目可行性研究报告的报告》（内农牧计报〔2016〕248号）收悉。经研究，批复如下。

一、原则同意你厅建设内蒙古自治区赤峰市草原防火基础设施建设项目。主要建设内容为建设林西县、翁牛特旗、巴林左旗草原防火站3个，草原火情监控站3个。主要建设内容包括建设草原防火物资储备库2250平方米和草原火情瞭望塔6座，安装物资储备架及安防监控设施3套；购置风力灭火机等扑火装备30套，通讯装备、取证装备和防火专用设备各3套（批），草原消防运兵车3辆、草原消防水罐车3辆；配备草原火情监控站前端预警监测系统6套，室内控制系统平台、应急传输系统各3套（详见附件1）。总投资2030万元，其中中央投资1845万元，地方投资185万元。建设期2年。

二、原则同意你厅建设内蒙古自治区锡林郭勒盟草原防火基础设施建设项目（二期）。主要建设内容为建设正蓝旗、锡林郭勒盟国家级草原自然保护区草原火情监控站2个，续建东乌珠穆沁旗、西乌珠穆沁旗、乌拉盖、锡林浩特市、多伦县、正蓝旗、阿巴嘎旗、锡林郭勒草原国家级自然保护区草原防火站8个。主要建设内容包括建设草原火情瞭望塔8座；购置风力灭火机等扑火装备24套，通讯装备、取证装备和防火专用设备各8套（批），草原防火运兵车8辆，草原灭火战车8辆；配备草原火情监控站前端预警监测系统10套，室内控制系统平台2套，应急传输系统16套（详见附件2）。总投资2060万元，其中中央投资1860万元，地方投资200万元。建设期2年。

三、原则同意你厅建设内蒙古自治区呼伦贝尔市草原防火基础设施建设项目。主要建设内容为建设扎赉诺尔区、鄂温克族自治旗、新巴尔虎左旗草原防火站3个，额尔古纳市、陈巴尔虎旗、满洲里市、新巴尔虎右旗草原火情监控站4个。主要建设内容包括建设草原防火物资储备库750平方米和草原火情瞭望塔8座，安装物资储备架及安防监控设施3套；购置风力灭火机等扑火装备45套，通讯装备、取证装备和防火专用设备各3套（批）、草原消防运兵车3辆、草原灭火战车3辆、草原消防水罐车3辆；配备草原火情监控站前端预警监测系统8套，室内控制系统平台、应急传输系统各4套（详见附件3）。总投资2189万元，其中中央投资1990万元，地方投资199万元。建设期2年。

四、原则同意你厅建设内蒙古自治区兴安盟草原防火基础设施建设项目。主要建设内容为建设扎赉特旗、科尔沁右翼前旗草原防火站2个，突泉县草原火情监控站1个。主要建设内容包括建设草原防火物资储备库750平方米和草原火情瞭望塔2座，安装物资储备架及安防监控设施2套；购置风力灭火机等扑火装备30套，通讯装备、取证装备和防火专用设备各2套(批)，草原消防运兵车2辆，草原灭火战车2辆，草原消防水罐车2辆；配备草原火情监控站前端预警监测系统2套，室内控制系统平台、应急传输系统各1套（详见附件4）。总投资1188万元，其中中央投资1080万元，地方投资108万元。建设期2年。

请据此批复，抓紧委托有相应资质的勘察设计单位编制项目初步设计和概算，经你单位审批后报我部备案。初步设计和概算编制要严格执行《关于党政机关停止新建楼堂馆所和清理办公用房的通知》（中办发〔2013〕17号）要求，不得将楼堂馆所等纳入项目建设内容。请切实履行好项目监管责任，督促项目建设单位严格按照农业基本建设项目管理规定，做好项目组织实施工作，每月28日之前通过农业建设项目管理信息系统（http://ac.argi.gov.cn）填报截至当月底项目进度、资金支出等相关信息。同时，按照国家发展改革委《关于做好农口中央预算内投资总结工作的通知》要求，请分别于当年7月3日和下年1月3日前，正式报送项目半年和全年总结，总结材料包括投资安排及到位情况、项目实施进展情况、监管措施、项目效益、存在的困难和问题、有关建议等内容。请督促省级草原防火管理机构按照《草原防火条例》要求，协调落实草原防火责任及其它保障条件，确保项目建成后切实发挥作用。

附件：1.内蒙古自治区赤峰市草原防火基础设施建设项目可行性研究报告批复表

2.内蒙古自治区锡林郭勒盟草原防火基础设施建设项目（二期）可行性研究报告批复表

3.内蒙古自治区呼伦贝尔市草原防火基础设施建设项目可行性研究报告批复表

4.内蒙古自治区兴安盟草原防火基础设施建设项目可行性研究报告批复表
