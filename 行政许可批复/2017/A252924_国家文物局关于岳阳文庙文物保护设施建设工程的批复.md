# 国家文物局关于岳阳文庙文物保护设施建设工程的批复

## 关于岳阳文庙文物保护设施建设工程的批复

文物保函〔2017〕710号

湖南省文物局：

你局《关于审批〈岳阳文庙文物保护设施建设工程方案〉的请示》（湘文物报〔2017〕34号）收悉。经研究，我局批复如下：

一、原则同意岳阳文庙文物保护设施建设工程和你局意见。

二、对所报方案提出如下修改完善意见：

（一）该工程位于全国重点文物保护单位岳阳文庙保护范围内，应严格遵守《中华人民共和国文物保护法》和湖南省人民政府关于岳阳文庙保护范围的相关管理规定，严格控制工程范围和工程强度，尽量减少施工建设对文物本体和景观环境的影响，确保文物安全。

（二）应加强历史研究，全面搜集文献和影像资料，分析、确定岳阳文庙的历史格局和院落风貌。明确庙墙位置，进一步论证原位恢复庙墙的可行性。

（三）进一步优化停车场设计，规模不宜过大，靠近庙墙处建议采用绿化种植过渡。

（四）保安亭等屋面材质、颜色应与文物建筑相协调，不宜使用黄色琉璃瓦。进一步论证管理用房选址的科学性。

（五）补充甬道、台阶的做法设计依据，说明原泮池周边地面铺装的材质、形制和材料，为科学确定环境整治措施提供依据。

（六）进一步论证义路坊建设的必要性，补充设计依据。

（七）应制定必要的临时性文物保护措施和应急预案，注意加强施工过程中的文物安全监测工作，及时发现隐患，确保文物和人员安全。

三、请你局根据上述意见，组织相关单位对所报方案进行修改、完善，并经你局核准后实施。请加强工程监管，确保文物安全。

此复。

国家文物局

2017年5月24日
