# 国家文物局关于南京城墙小桃园段抢险加固工程的批复

## 关于南京城墙小桃园段抢险加固工程的批复

文物保函〔2017〕736号

江苏省文物局：

你局《关于审批南京城墙小桃园局部坍塌段抢险维修方案的请示》（苏文物保〔2017〕75号）收悉。经研究，我局批复如下：

一、原则同意南京城墙小桃园段抢险加固工程和你局意见。

二、对该方案提出以下修改完善意见：

（一）应加强现状勘察和研究，核实坍塌部位、范围等，科学评估文物受损程度和墙体稳定性。同时，深入研究城墙的原有形制和做法，明确城墙构造、砌法和灰浆成分等，为制定有针对性的保护措施提供依据。

（二）系统梳理已实施的保护工程情况，客观评估历次修缮工程效果，分析城墙坍塌与2006年不当改造整治的关系。

（三）应坚持最小干预原则，严格控制工程范围和强度，细化工程做法和技术要求。

1. 应尽量保留原残墙和土芯，不宜采用抗滑桩，应进一步研究、完善加固措施并进行专家论证。保留残墙脚时，可采取短桩与残墙结合的处理形式。

2. 新老墙体连接部位应采取必要的防伸缩变形措施。

3. 不同意使用水硬性石灰。应根据传统工艺做法，合理控制材料强度，开展材料试验分析和效果评估。所用材料验证有效后，方可使用。

4. 城墙顶部维修不同意铺设钢筋混凝土板和防水卷材，应采用传统工艺做法，并妥善解决排水问题。

5. 科学评估车辆通行对城墙内侧山体的振动影响，明确车辆荷载标准，进一步校正边坡加固的结构强度，并细化边坡防排水措施。

（四）进一步控制工程规模，并根据工程量合理编制经费预算，进一步核减工程造价，补充各单项取费依据。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

四、请你局督促地方人民政府切实落实《南京城墙保护规划》要求，做好日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年4月12日
