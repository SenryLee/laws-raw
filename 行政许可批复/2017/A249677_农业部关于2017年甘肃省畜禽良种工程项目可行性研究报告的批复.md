# 农业部关于2017年甘肃省畜禽良种工程项目可行性研究报告的批复

农计发〔2017〕84号

甘肃省农牧厅：

《甘肃省农牧厅关于申报2017年现代种业提升工程畜禽良种储备项目的报告》(甘农牧计发〔2017〕2号)收悉。经研究，批复如下。

原则同意你厅2017年甘肃省畜禽良种工程甘肃省景泰县生猪育种创新基地、临洮县肉羊良种场、定西市安定区肉羊育种创新基地建设项目。主要建设内容为新建圈舍、隔离舍5248平方米、运动场4140平方米，改造圈舍13246平方米、运动场17760平方米，新建道路、粪污处理、围墙等场区配套工程；购置仪器设备84台（套、批、辆）；引种2批（详见附件1、2、3）。总投资3402万元，其中中央预算内投资1500万元，地方投资227万元，自有资金1675万元。建设期2年。

请据此批复，抓紧委托有相应资质的勘察设计单位编制项目初步设计和概算，经你单位审批后报我部备案。初步设计和概算编制要严格执行《关于党政机关停止新建楼堂馆所和清理办公用房的通知》（中办发〔2013〕17号）要求，不得将楼堂馆所等纳入项目建设内容。请切实履行好项目监管责任，督促项目建设单位严格按照农业基本建设项目管理规定，做好项目组织实施工作，每月28日之前通过农业建设项目管理信息系统（http://ac.argi.gov.cn）填报截至当月底项目进度、资金支出等相关信息。同时，按照国家发展改革委《关于做好农口中央预算内投资总结工作的通知》要求，请分别于当年7月3日和下年1月3日前，正式报送项目半年和全年总结，总结材料包括投资安排及到位情况、项目实施进展情况、监管措施、项目效益、存在的困难和问题、有关建议等内容。

附件：1.甘肃省景泰县生猪育种创新基地建设项目可行性研究报告批复表

2.甘肃省临洮县肉羊良种场建设项目可行性研究报告批复表

3.甘肃省定西市安定区肉羊育种创新基地建设项目可行性研究报告批复表

农业部

2017年4月13日
