# 国家文物局关于江苏省2017年度考古发掘报告出版计划的批复

## 关于江苏省2017年度考古发掘报告出版计划的批复

文物保函〔2017〕438号

江苏省文物局：

你局《关于审批江苏省考古研究所2017年度考古发掘报告出版立项的请示》（苏文物保〔2017〕51号）收悉。经研究，我局同意所报《宜兴蜀山窑考古发掘报告》、《邳州煎药庙考古发掘报告》、《徐州狮子山楚王陵考古发掘报告》、《大云山江都王陵考古发掘报告》4部考古发掘报告出版计划。

请按照《国家重点文物保护专项补助资金管理办法》的规定和我局有关要求，另行申请该4部考古报告的出版补助经费。

国家文物局

2017年3月2日
