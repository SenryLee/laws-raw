# 农业部关于兽药残留及违禁添加物检测重点实验室等3个建设项目可行性研究报告的批复

农计发〔2017〕12号

中国农业大学：

《中国农业大学关于提请审核〈农业部兽药残留及违禁添加物检测重点实验室建设项目可行性研究报告〉的请示》（中农大基字〔2016〕6号）《中国农业大学关于提请审核〈农业部玉米生物学与遗传育种重点实验室建设项目可行性报告〉的请示》(中农大基字〔2016〕7号)和《中国农业大学关于提请审核〈农业部动物流行病学与人畜共患病重点实验室建设项目可行性研究报告〉的请示》（中农大基字〔2016〕11号）收悉。经研究，批复如下。

一、农业部兽药残留及违禁添加物检测（研究）重点实验室建设项目

项目建设单位为中国农业大学。建设地点在北京市海淀区圆明园西路2号。主要建设内容包括：购置超高效液相色谱仪、三重四极杆质谱仪、四极杆-飞行时间串联质谱仪、多功能酶标仪、冷冻干燥机、倒置荧光显微镜、蛋白质相互作用工作站、蛋白质稳定性检测仪、蛋白质模拟软件、氮气发生器、多维样品混合器各1台（套）。总投资1288万元，其中仪器设备1214万元、工程建设其他费48.56万元、预备费25.44万元。资金来源全部为中央预算内投资。建设期为投资计划下达之日起两年。项目建成后，将有效提升农产品质量安全学科群在兽药及违禁添加物的代谢及残留分析领域的研究能力，创制新兽药2—4个，良好畜禽用药规范1—2套，获得申请（授权）专利及申报国家（行业）标准5—8项。仪器设备按照项目建设单位的共享方案，向学科群及社会开放，进一步提高科技资源利用效率。

二、农业部玉米生物学与遗传育种重点实验室建设项目

项目建设单位为中国农业大学。建设地点在北京市海淀区圆明园西路2号。主要建设内容包括：购置旋转光照明活细胞激光共聚焦超分辨率显微镜、高速分选型流式细胞仪、高通量蛋白提取定量工作站、透射电镜系统、高压液相色谱分析系统、种子油份水份分析测试仪各1台（套）,建设玉米生物学与遗传育种数据物联网系统。总投资1705万元，其中仪器设备1592万元、工程建设其他费79.92万元、预备费33.08万元。资金来源全部为中央预算内投资。建设期为投资计划下达之日起两年。项目建成后，将显著提升玉米作物学与遗传育种学科群在玉米作物学与遗传育种的理论研究和应用水平，通过玉米的系统创新与分子改良，获得重要性状明显改良的新种质120份以上，创制高效杂种优势利用新技术2—3项；组织区域性重点实验室、科学观测实验站及相关科研院所联合制定行业执行标准1—2个。按照项目建设单位的仪器设备共享方案，向学科群及社会开放，进一步提高科技资源利用效率。

三、农业部动物流行病学与人畜共患病重点实验室（病原生态学研究方向）建设项目

项目建设单位为中国农业大学。建设地点在北京市海淀区圆明园西路2号。主要建设内容包括：购置超高速冷冻离心机、蛋白纯化分析系统、多用电泳仪、活细胞工作站、激光共聚焦显微镜、荧光分光光度计、自动化工作站、多功能酶标仪、全自动核酸提取仪、荧光定量PCR仪、高通量微生物鉴定系统、微生物致病菌药敏鉴定系统、全封闭组织脱水机、组织包埋机、全自动多动能染色封片工作站、全自动轮转式切片机、冰冻切片机各1台（套）。总投资1367万元，其中仪器设备1289万元、工程建设其他费51.56万元、预备费26.44万元。资金来源全部为中央预算内投资。建设期为投资计划下达之日起两年。项目建成后，将提升动物疫病病原生物学学科群在动物流行病学领域的研究能力，研究5种以上重要动物疫病的病原流行病学及致病机制，研制重要动物疫病诊断试剂盒3—5个，开发疫苗2—3种。仪器设备按照项目建设单位的共享方案，向学科群及社会开放，进一步提高科技资源利用效率。

请据此批复,抓紧委托有相应资质的勘察设计单位编制项目初步设计和概算，3月15日前报我部审批。建设地点临近的项目应统筹规划设计，优化整体布局，避免重复建设。初步设计和概算编制要严格执行《关于党政机关停止新建楼堂馆所和清理办公用房的通知》（中办发〔2013〕17号）要求，不得将楼堂馆所等纳入项目建设内容。

请切实履行好项目监管责任，督促项目建设单位严格按照农业基本建设项目管理规定，做好项目组织实施工作，每月28日前通过农业建设项目管理信息系统（http://ac.agri.gov.cn）填报截至当月底项目进度、资金支出等相关信息。同时，按照国家发展改革委《关于做好农口中央预算内投资总结工作的通知》要求，请分别于当年7月3日和下年1月3日前，正式报送有关专项半年和全年总结，总结材料包括投资安排及到位情况、项目实施进展情况、监管措施、项目效益、存在的困难和问题、有关建议等内容。
