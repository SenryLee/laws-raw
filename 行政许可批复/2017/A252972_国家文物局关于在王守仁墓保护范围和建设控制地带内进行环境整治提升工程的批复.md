# 国家文物局关于在王守仁墓保护范围和建设控制地带内进行环境整治提升工程的批复

## 关于在王守仁墓保护范围和建设控制地带内进行环境整治提升工程的批复

文物保函〔2017〕1172号

浙江省文物局：

你局《关于上报全国重点文物保护单位王守仁墓环境整治方案的请示》（浙文物发〔2017〕138号）收悉。经研究，我局批复如下：

一、原则同意在王守仁墓的保护范围和建设控制地带内进行环境整治提升工程和你局意见。

二、对所报方案提出以下修改意见：

（一）应严格遵守《中华人民共和国文物保护法》和浙江省人民政府关于全国重点文物保护单位王守仁故居和墓保护范围和建设控制地带的相关管理规定，严格控制工程量和工程范围，尽量减少施工建设对文物本体和景观环境的影响，确保文物安全。

（二）应明确工程范围，进一步说明环境整治范围与文物保护区划之间的关系。

（三）应进一步优化方案设计，调整拟建建筑功能布局，控制建筑密度，建筑形式应采用当地传统建筑风格，不宜套用清代官式建筑做法；适当压缩祭祀广场面积，弱化地面铺装，避免景观环境过度人工化；细化神道两侧植被补种、更换及病害整治的具体要求，进一步核准工程量。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后按程序报有关部门批准实施。施工中请加强工程监管，确保文物及历史环境安全。

此复。

国家文物局

2017年7月5日
