# 国家文物局关于弹子石摩崖造像修缮工程（第一阶段）的批复

## 关于弹子石摩崖造像修缮工程（第一阶段）的批复

文物保函〔2017〕841号

重庆市文物局：

你局《关于审批重庆弹子石摩崖造像保护修复工程初步设计方案（第一阶段）的请示》（渝文物〔2017〕113号）收悉。经研究，我局批复如下：

一、原则同意所报弹子石摩崖造像修缮工程（第一阶段）和你局意见。

二、对该方案提出以下修改完善意见：

（一）应将研究工作贯穿保护工作实施的全过程，并以研究成果作为开展各项保护措施的依据。

1．以风化病害成因机理研究、风化病害加固治理技术研究工作为重点，开展砂岩风化病害治理技术等关键技术研究，在此基础上制定相关技术导则或指南。

2．加强工程全过程的档案记录，随时采集、整理相关数据和资料并进行科学分析研究，为工程报告的编制奠定基础。

3．结合工程实施，及时总结相关研究成果和工程经验，在保护理论、保护方法、保护技术等方面为重庆地区相关石窟保护工程提供示范和借鉴。

（二）应加强前期试验检测分析工作，科学制定前期试验方案，开展必要的现场试验和效果评估，并根据试验结论完善设计方案。

1．进一步说明本体保护材料筛选和工艺试验的具体位置和范围，明确试验标准和检验指标；筛选出的材料应经论证评估有效、安全后，方可使用。

2．补充灌浆材料中水硬性石灰的实验室及现场试验依据，科学确定在裂隙内、缺氧封闭环境下，浆液凝固的强度与时间等数据。

3．应针对岩体表层风化类型及病害的复杂性，在实验室和现场试验的基础上进一步调整、确定防风化材料的配比和工艺要求。

（三）应进一步调整工程重点，优先解决危岩体和砌体结构倾斜变形问题，排除险情，保证文物安全。同时，应坚持最小干预原则，严格控制工程范围和强度，明确工程使用材料、工艺做法和操作流程。

1．应根据弹子石砂岩性质，明确灌浆材料的成分、配比和粒径等参数，建议选择与当地岩体相近的岩石粉代替石英砂，以增强与砂岩的兼容性和外观协调性；不同意使用水泥勾缝砖石砌体，建议采用水硬性石灰；不影响文物本体稳定的裂缝不宜灌浆加固。

2．不同意五佛殿内石质佛像防风化工程。

3．进行植物根系清除和表面污染物清理措施应慎重，科学分析现有植被与岩体之间的关系，合理确定清除方法和操作要求，避免操作不当引发结构安全问题；不影响施工的植被可暂不清理。同时，进一步论证激光清洗措施的安全性，建议考虑多种比选方案。

（四）应充分考虑石质文物共生病害的复杂性，合理细化治理次序和工序，在病害治理后或重要工序结束后，及时进行效果评估，调整工程措施，确保文物安全和工程质量。

（五）应根据工程需要，进一步明确监测工作目标、重点和主要内容，强化监测工作与施工安全、工程效果评估之间的衔接，增强针对性。

（六）进一步规范文本与图纸，补充图例，删除与本方案无关内容。

三、请你局根据上述意见指导相关单位修改、完善方案，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。同时督促有关单位及时开展巡查监测工作，加强隐患排查，确保文物和人员安全。

此复。

国家文物局

2017年4月21日
