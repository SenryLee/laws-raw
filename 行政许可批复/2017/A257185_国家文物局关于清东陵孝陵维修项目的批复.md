# 国家文物局关于清东陵孝陵维修项目的批复

文物保函〔2017〕1773号

河北省文物局：

你局《关于呈报清东陵孝陵维修工程设计方案的请示》（冀文物字〔2017〕215号）收悉。经研究，我局批复如下：

一、原则同意所报清东陵孝陵维修项目和你局意见。

二、具体修改意见如下：

（一）暂不同意方城修缮内容。进一步论证锚杆加固措施，严格控制干预力度；进一步评估方案所提城台防水附加层做法的长期有效性，建议进行深入比对分析。同时应加强城台排水系统设计；对大面积鼓闪、酥碎等病害，应进一步深化勘察和评估，提出有针对性的修缮措施。方城修缮须修改完善后编制专项方案并组织专业论证后方可实施。

（二）细化完善部分修缮措施。论证陵寝门垂带下脚“置销固定”措施的必要性和过木加固措施的可行性，并进一步核实“过木加固图”剖面详图；宜根据残砖强度进一步细化干摆墙剔补的标准，不同强度的砖可采用针对性的修缮措施。

（三）进一步论证屋面瓦件脱釉处涂刷硅油（低温釉）做法的长期可靠性，并补充具体做法和要求。

（四）明确补配砖、瓦、木构件等的材料要求。

（五）施工中坚持最小干预原则，严格控制项目范围和干预程度，对不影响结构安全、排水和使用的风化碎裂的砖石构件，不得整体揭墁、更换；墙体抹灰褪色而无空鼓、剥落等病害的，应现状保留。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局核准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

此复。

国家文物局

2017年10月26日
