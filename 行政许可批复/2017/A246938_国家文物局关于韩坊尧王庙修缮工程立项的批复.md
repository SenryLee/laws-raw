# 国家文物局关于韩坊尧王庙修缮工程立项的批复

## 关于韩坊尧王庙修缮工程立项的批复

文物保函〔2017〕55号

山西省文物局：

你局《关于申请长子县韩坊尧王庙修缮工程立项的请示》（晋文物〔2016〕228号）收悉。经研究，我局批复如下：

一、同意韩坊尧王庙大殿修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为韩坊尧王庙山门、大殿文物建筑及院落。

（三）应加强现状勘察和研究，明确文物保存现状、主要病害类型、残损情况等，查找屋面漏雨、墙体开裂、木构架倾斜糟朽等病害原因，在此基础上制定有针对性的修缮措施。同时，分析、说明改砌和加砌墙体、外移门窗、后加吊顶的改造年代和现状，以及文物周边环境和东、西厢房遗址的保存情况。

（四）应严格控制工程量和工程强度，合理确定木构件更换、补配的具体数量和标准，明确壁画和东、西厢房遗址的保护措施，避免过度维修。更换下的原构件应详细测绘、登记、评估价值，妥善保管；各类工程资料应由专人管理、建档，并在工程结束后纳入韩坊尧王庙大殿记录档案。

（五）应加强地方建筑做法和传统工艺特色的研究分析，并注意在工程中采用原材料、原工艺。同时，应考虑文物建筑的使用功能和展示利用方式，并在方案设计中补充展示利用设计内容。

（六）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（七）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案；组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年1月13日
