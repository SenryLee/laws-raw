# 国家发展改革委关于西北区域人工影响天气能力建设项目可行性研究报告的批复

发改农经[2017]118号

中国气象局：

你局《关于报请审批〈西北区域人工影响天气能力建设可行性研究报告〉的函》（中气函[2016]176号）收悉。经研究，现批复如下：

一、原则同意所报西北区域人工影响天气能力建设可行性研究报告。该项目建成后将形成更加科学、统一协调的人工增雨（雪）作业体系，新增作业影响面积96万平方公里，有效提高西北区域人工影响天气作业水平和效率，为国家生态安全、水资源配置、抗旱救灾、森林防火等提供保障，项目建设是必要的。

二、该项目建设范围包括甘肃省、陕西省、青海省、宁夏自治区、新疆自治区、新疆生产建设兵团全境及内蒙古自治区阿拉善盟、巴彦淖尔市、乌海市、鄂尔多斯市。建设内容包括：飞机作业能力、飞机作业保障能力、地面作业能力、人影作业指挥系统和试验示范基地建设等五部分。具体建设规模为：购置并改装4架国家作业飞机，对地方8架作业飞机进行必要的改装；在西安阎良建设国家级作业飞机保障基地，在甘肃兰州、陕西榆林、青海平安、宁夏银川、新疆库尔勒和克拉玛依、内蒙古鄂尔多斯设立国家作业飞机驻地专业保障设施；更新列装移动高性能火箭作业装置897套，对1856套作业装备进行信息化改造，增设地面烟炉919部，配备必要的辅助作业设备和安全管理设施；建立区域、省、市、县、作业点五级人影作业指挥系统，包括硬件平台、应用软件、信息网络系统、可视会商系统和人影作业监控等；建设祁连山地形云、天山地形云人工增雨（雪）试验示范基地和六盘山区水源涵养地、红碱淖湿地、陕甘宁果业区、内蒙古巴彦淖尔试验示范点。工程建设期36个月。

三、经核定，工程总投资为114885万元。总投资中，中央预算内投资安排65135万元，主要用于国家作业飞机的购置与改装、飞机作业保障能力建设、试验示范基地建设、区域级人工影响天气中心建设；其余投资分别由内蒙古自治区负责安排2729万元、陕西省负责安排9569万元、甘肃省负责安排5511万元、青海省负责安排2090万元、宁夏自治区负责安排3032万元、新疆自治区负责安排24442万元、新疆生产建设兵团负责安排2377万元。

四、同意国家级人工影响天气中心西北区域中心作为该工程项目法人，负责工程的建设、管理、运行和维护。项目建设执行项目法人责任制、招标投标制、合同管理制、建设监理制和竣工验收制等制度。项目法人要按照招标投标法和相关规定，委托招标代理机构公开招标选择设计、施工、监理以及重要设备、材料供应单位，确保工程质量；切实落实运行维护经费，确保工程建设顺利进行并长期发挥效益。

要加强组织协调，借鉴吸收东北区域人工影响天气中心建设经验，建立人工影响天气作业调度运行决策机制，由西北区域中心统一协调指挥跨省区作业，做到统一调度、上下联动、区域联合。要充分依托气象业务系统，加强气象监测预报，结合生态安全、水资源配置、抗旱救灾、森林草原防火作业需求与人工影响天气作业能力，合理确定作业方案。

五、在初步设计阶段，要按照中国国际工程咨询公司的有关评估意见，进一步优化工程方案；结合现有设施情况，处理好本工程与其他已实施气象项目的关系，优化整合各类资源，避免重复建设，充分发挥工程效益；在实施中，要加强与有关省（区）和新疆生产建设兵团的沟通、协调与合作。请据此编制初步设计，投资概算经我委核定后，初步设计由你局审批，报我委备核。

国家发展改革委
