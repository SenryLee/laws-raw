# 国家文物局关于《十笏园工程报告》出版计划的批复

## 关于《十笏园工程报告》出版计划的批复

文物保函〔2017〕744号

山东省文物局：

你局《关于〈十笏园工程报告〉出版计划的请示》（鲁文发 〔2017〕37号）收悉。经研究，我局批复如下：

一、同意《十笏园工程报告》出版计划。

二、应进一步加强对该报告体例、内容、深度等的研究和工程档案资料的分析整理，提高报告的科学研究和规范化水平。报告内容应涵盖工程概况、勘察测绘及研究、工程设计及说明、工程实施报告等主要内容及相应图纸、照片、文件等。补充工程方案审批意见、方案修改情况说明、施工中方案调整情况说明、工程参与单位及负责人介绍、工程验收报告等内容。

三、建议报告成书采取平装方式，并合理调整经费预算。

四、如需申请工程报告出版补助经费，请你局按照财政部、国家文物局《国家重点文物保护专项补助资金管理办法》（财教〔2013〕116号）文件的规定和我局有关要求，按程序履行相关申请手续。

此复。

国家文物局

2017年4月12日
