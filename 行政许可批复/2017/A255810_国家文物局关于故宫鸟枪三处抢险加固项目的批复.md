# 国家文物局关于故宫鸟枪三处抢险加固项目的批复

文物保函〔2017〕1473号

北京市文物局：

你局《关于故宫鸟枪三处抢险加固工程保护方案的请示》（京文物〔2017〕839号）收悉。经研究，我局批复如下：

一、原则同意所报故宫鸟枪三处抢险加固项目和你局意见。

二、对该工程提出以下修改意见：

（一）应遵循“不改变文物原状”、“最小干预”等文物保护原则，进一步加强现状勘察和研究，核实建筑各部位残损程度和病害原因，明确屋面补配构件数量、范围和槛墙现状使用砖材规格、做法，为修缮设计提供依据。

（二）加强对原有建筑形制、材料、工艺、做法的分析研究，确保在维修中使用原工艺和原材料。明确槛墙、大木构架、屋面等部位的原始做法。

（三）应坚持最小干预原则，严格控制工程范围和强度，细化工程做法和技术要求。补充屋面苫背层、大木构架和彩画修缮措施的设计依据。

（四）应根据修缮后文物建筑使用功能，深化方案设计，妥善处理文物保护与日常使用的关系。统筹考虑所在庭院原有历史地面的保护展示问题。

（五）注意做好各类工程资料提取和档案留存工作。

（六）应做好修缮项目与监测工作的衔接。

（七）进一步校核文本与图纸，完善设计说明、修缮图纸及工程量标注，规范专业用语。

（八）补充必要的施工要求和临时性保护措施，确保施工过程中人员和文物安全。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善并经你局批准后组织实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年8月21日
