# 国家文物局关于天一总局旧址大厝抢险加固工程设计方案的批复

文物保函〔2017〕1802号

福建省文物局：

你局《关于天一总局旧址大厝抢险加固工程设计方案的请示》（闽文物字〔2017〕399号）收悉。经研究，我局批复如下：

一、原则同意所报方案。

二、对方案提出以下修改意见：

（一）进一步深化文物建筑现状勘察，查明建筑残损、排水及基础安全等问题。在图纸中应标注残损的具体范围，说明残损的程度。

（二）合理控制工程量，严格控制工程范围。

（三）根据临时性抢险加固工程特点，深化抢险加固措施说明，补充支撑、加固节点图，并完善细部尺寸标注。

（四）细化工程做法，补充砖、灰浆等材料要求及配比；灌浆灰浆采用“混合砂浆”不妥，不宜使用水泥。

（五）施工过程中应提出详细要求并完善应急预案，如有重点发现及时调整方案。

三、请你局指导有关单位，根据上述意见对方案进行必要的修改和完善后实施。施工过程中应加强监管，确保文物安全和工程质量。

此复。

国家文物局

2017年10月30日
