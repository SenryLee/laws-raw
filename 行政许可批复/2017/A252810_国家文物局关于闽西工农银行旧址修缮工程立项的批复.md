# 国家文物局关于闽西工农银行旧址修缮工程立项的批复

## 关于闽西工农银行旧址修缮工程立项的批复

文物保函〔2017〕717号

福建省文物局：

你局《关于闽西工农银行旧址群修缮工程立项的请示》（闽文物字〔2017〕109号）收悉。经研究，我局批复如下：

一、同意闽西工农银行旧址修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）工程范围为闽西工农银行旧址文物建筑。

（三）强化文物现状勘察评估，准确掌握建筑病害及残损情况，并对房屋结构安全性进行检测，在此基础上制定针对性修缮措施。

（四）坚持最小干预原则，严格控制工程范围和工程量，避免过度修缮。

（五）相关设计应兼顾文物展示利用需求。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制修缮工程技术方案；由你局组织或委托专业评估机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年4月11日
