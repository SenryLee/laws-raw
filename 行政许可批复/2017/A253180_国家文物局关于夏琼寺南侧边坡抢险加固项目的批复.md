# 国家文物局关于夏琼寺南侧边坡抢险加固项目的批复

## 关于夏琼寺南侧边坡抢险加固项目的批复

文物保函〔2017〕1254号

青海省文物管理局：

你局《关于夏琼寺临崖文物建筑地基山体抢险加固保护工程设计方案的请示》（青文物局〔2017〕65号）收悉。经研究，我局批复如下：

一、原则同意夏琼寺南侧边坡抢险加固项目和你局意见。

二、对该方案提出以下修改完善意见：

（一）应深化现状勘察研究和滑坡诱发原因分析，合理判定边坡滑移面范围，提供科学可靠的岩土层物理力学指标，完善边坡地质灾害危险性预测评估，补充说明崖体底部现状和照片。

（二）应坚持最小干预原则，进一步明确边坡加固的具体范围，校核锚杆长度、数量和锚固强度等，严格控制工程范围和规模，避免过度加固。

（三）优化加固设计方案，注意做好边坡截排水工作，进一步论证排水沟设置的科学性和必要性。充分考虑边坡外观对景观风貌的影响，采取必要后期处理措施。

（四）工程实施前应进行必要的预加固处理或临时性支护措施，确保文物和人员安全。

（五）进一步完善图纸。补充能准确反映裂隙、危岩体位置和规模的现状图纸，补充地质灾害图、地质剖面实测图、截排水工程布置图等。

三、请你局根据上述意见指导相关单位修改、完善方案，并按程序报相关部门批准实施。施工中请加强监管和监测，确保工程质量和文物安全。

此复。

国家文物局

2017年7月20日
