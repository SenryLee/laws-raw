# 国家文物局关于正定隆兴寺摩尼殿修缮项目的批复

文物保函〔2017〕1646号

河北省文物局：

你局《关于呈报正定隆兴寺摩尼殿修缮工程设计方案的请示》（冀文物字〔2017〕155号）收悉。经研究，我局批复如下：

一、原则同意所报正定隆兴寺摩尼殿修缮项目和你局意见。

二、具体修改意见如下：

（一）价值评估应针对摩尼殿而非整个隆兴寺，现状评估应补充对摩尼殿主要病害及其程度的评估。

（二）重点深化对屋面的补充勘察，明确焦渣背是否已严重风化，以及相应的残损范围，并根据勘察结论对屋面修缮的力度和范围做出有针对性的调整。

（三）修缮措施表应注意与残损现状记录表相对应。

（四）调整完善部分修缮措施和材料。扫缝灰材料不得使用水泥，宜使用白灰、细沙等传统材料；进一步论证石质构件的维修方法和材料，比对环氧树脂、石粉和水硬性石灰各自的特性和适用条件；原焦渣背与新做掺灰泥背搭接处宜涂刷石灰浆两道，不宜使用107胶水；应按照规范要求选用有效防腐药剂，不宜仅用桐油代替。

（五）砖石构件修缮应严格遵守“最小干预”原则，风化、碎裂而不影响结构、排水、人行等具体功能的，宜现状保留，并严格控制整体揭墁范围，避免对古建筑的外观造成较大改变。

（六）核实说明本项目未含立项批复中“摩尼殿及天王殿至毗卢殿院落甬路、部分地面铺装”修缮内容的原因。做好古建筑本体维修项目与壁画保护项目的衔接。

（七）明确项目实施中资料记录、留存和报告编制出版的要求。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，经你局核准后实施。请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保工程质量。

此复。

国家文物局

2017年9月14日
