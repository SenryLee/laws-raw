# 国家文物局关于在七桥瓮保护范围和建设控制地带内进行秦淮河干流整治工程的批复

## 关于在七桥瓮保护范围和建设控制地带内进行秦淮河干流整治工程的批复

文物保函〔2017〕8号

江苏省文物局：

你局《关于审批南京市秦淮区秦淮河干流整治工程方案的请示》（苏文物保〔2016〕276号）收悉。经研究，我局批复如下：

一、原则同意在全国重点文物保护单位七桥瓮保护范围和建设控制地带内进行秦淮河干流整治工程和你局意见。

二、对该方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》和江苏省人民政府关于全国重点文物保护单位七桥瓮保护范围和建设控制地带的相关管理规定，严格控制工程范围和工程强度，尽量减少对文物本体和景观环境的影响，确保文物安全。

（二）应加强前期勘察，明确七桥瓮的结构、基础形式、埋深以及文物保存现状。同时完善文物影响评估报告，深入论证整治工程对七桥瓮本体及景观风貌的影响，做到客观、准确、科学。

（三）在上述工作基础上进一步细化方案设计，补充、完善工程涉及七桥瓮保护区划范围内的具体工程措施，说明河道疏浚和堤岸加固的施工范围、操作流程和施工强度等，注意抗滑桩的尺度、色彩、材质与文物本体相协调。补充七桥瓮保护区划内两岸堤防、护岸改造以及河底清淤的设计图纸。

（四）施工过程中应严格保护文物，并充分考虑机械振动、开挖影响，制定必要的文物保护措施和应急预案。施工过程中应开展必要的文物安全监测工作，及时发现、妥善处理安全隐患。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工中应加强监管，发现地下文物应立即停工并调整施工方案，确保工程质量和文物安全。

此复。

国家文物局

2017年1月6日
