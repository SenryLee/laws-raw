# 国家文物局关于姜氏庄园甬道修缮工程立项的批复

## 关于姜氏庄园甬道修缮工程立项的批复

文物保函〔2016〕2121号

陕西省文物局：

你局《关于姜氏庄园甬道抢险加固工程立项的请示》（陕文物字〔2016〕180号）收悉。经研究，我局批复如下：

一、同意姜氏庄园甬道修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为姜氏庄园甬道。

（三）加强现状勘察，明确甬道保存现状、残损情况等，深入分析甬道拱顶砌体风化剥蚀、灰缝消失、盐析等原因，在此基础上制定有针对性的修缮措施。补充姜氏庄园的产权和现状使用状况、甬道现状地面排水情况。

（四）应深入研究和分析地方建造工艺、传统做法、建筑材料和构造特征等，进一步论证加固措施的必要性和可行性，注意在维修中使用原工艺、原做法和原材料，并尽量采用原有排水方式解决场地排水问题。

（五）坚持最小干预原则，根据病害分析结论，合理确定工程措施、方式和强度，严格控制工程量和工程范围。明确石构件更换标准和更换量，避免过度维修。合理确定材料检测分析的内容、取样标准和对象，保证检测结果科学、准确。

（六）补充施工中甬道的临时性保护措施和应急预案，确保文物及人员安全。

（七）加强与相关利益人的沟通、协调，保障工程顺利实施，确保维修效果。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案，并组织专家或委托第三方咨询评估机构进行方案技术评审，依据评估意见进行审批。

四、请你局指导有关单位切实加强姜氏庄园的日常保护和管理工作，抓紧编制《姜氏庄园保护规划》，妥善处理好文物保护与居民生产生活之间的关系。

此复。

国家文物局

2017年1月4日
