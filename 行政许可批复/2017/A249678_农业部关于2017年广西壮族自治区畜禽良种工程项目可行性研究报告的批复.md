# 农业部关于2017年广西壮族自治区畜禽良种工程项目可行性研究报告的批复

农计发〔2017〕81号

广西壮族自治区水产畜牧兽医局：

《广西壮族自治区水产畜牧兽医局关于2017年现代种业提升工程储备项目立项的请示》(桂渔牧计报〔2017〕1号)收悉。经研究，批复如下。

原则同意你局2017年广西壮族自治区畜禽良种工程贵港市港南区生猪育繁推一体化扩建和灵山县广西麻鸡种质资源保护场建设项目。主要建设内容为新建各类猪舍11530平方米，鸡舍5941平方米，建设饲料间、仓库、雨污分流等配套工程；购置仪器设备44台（套、批）；引种1批（详见附件1、2）。总投资2954万元，其中中央预算内投资1050万元，地方投资150万元，自有资金1754万元。建设期2年。

请据此批复，抓紧委托有相应资质的勘察设计单位编制项目初步设计和概算，经你单位审批后报我部备案。初步设计和概算编制要严格执行《关于党政机关停止新建楼堂馆所和清理办公用房的通知》（中办发〔2013〕17号）要求，不得将楼堂馆所等纳入项目建设内容。请切实履行好项目监管责任，督促项目建设单位严格按照农业基本建设项目管理规定，做好项目组织实施工作，每月28日之前通过农业建设项目管理信息系统（http://ac.argi.gov.cn）填报截至当月底项目进度、资金支出等相关信息。同时，按照国家发展改革委《关于做好农口中央预算内投资总结工作的通知》要求，请分别于当年7月3日和下年1月3日前，正式报送项目半年和全年总结，总结材料包括投资安排及到位情况、项目实施进展情况、监管措施、项目效益、存在的困难和问题、有关建议等内容。

附件：1.广西贵港市港南区生猪育繁推一体化扩建项目可行性研究报告批复表

2.广西壮族自治区灵山县广西麻鸡种质资源保护场建设项目可行性研究报告批复表

农业部
