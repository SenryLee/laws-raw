# 国家文物局关于梨树县白山乡岫岩村村民姜立仁住宅翻建项目涉及偏脸城城址保护范围选址的批复

## 关于梨树县白山乡岫岩村村民姜立仁住宅翻建项目涉及偏脸城城址保护范围选址的批复

文物保函〔2017〕1255号

吉林省文物局：

你局《关于对梨树县白山乡岫岩村村民姜立仁拟在偏脸城城址内翻建住宅的请示》（吉文物发〔2017〕120号）收悉。经研究，我局批复如下：

一、原则同意梨树县白山乡岫岩村村民姜立仁住宅翻建项目涉及偏脸城城址保护范围的选址方案。

二、该住宅翻建项目应坚持原址原规模建设，采用浅基础设计，严格控制基础开挖深度。同时，应注意建筑风貌与遗址及其周边环境相协调。

三、施工中，请你局组织专业机构做好全程监管，并督促有关人员切实做好项目施工过程中的文物保护工作，确保文物和人员安全。

国家文物局

2017年7月19日
