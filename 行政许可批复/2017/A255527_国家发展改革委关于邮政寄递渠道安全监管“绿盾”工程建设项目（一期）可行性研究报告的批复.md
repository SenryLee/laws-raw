# 国家发展改革委关于邮政寄递渠道安全监管“绿盾”工程建设项目（一期）可行性研究报告的批复

发改基础〔2017〕1626号

国家邮政局：

你局《关于报送邮政寄递渠道安全监管“绿盾”工程建设项目（一期）可行性研究报告的请示》（国邮函〔2017〕75号）及有关材料收悉。经研究，现批复如下。

一、为贯彻落实《国务院关于促进快递业发展的若干意见》和《“十三五”现代综合交通运输体系发展规划》有关要求，提升邮政行业安全监管能力，维护国家安全、公共安全和生产安全，保障邮政业持续健康发展，同意实施邮政寄递渠道安全监管“绿盾”工程（一期）。

二、本期工程主要建设内容包括：

（一）基础设施。改造国家邮政局机房（北京）4104平方米。新建异地灾备中心（合肥）6743平方米。建设和完善三级安全监控中心设施，其中改造国家邮政局安全监控中心468平方米；改造21个省级安全监控中心共1121平方米；设置356个地市级安全监控中心，并分别配置监控设备。

（二）业务应用系统。建设和完善运行监测、安全预警、行政执法、应急指挥、决策支持和公共服务等六类业务应用系统。

（三）信息技术支撑。云服务和大数据中心设置各类服务器966台、机柜120台；网络系统设置各类网络设备949台、视频联网设备6956台（套）、安检机联网设备7865台（套）、融合通信设备457台（套）；安全系统设置各类网络和信息安全设备845台（套）；运维系统设置综合运维管理系统2套；应用支持平台设置大数据应用支撑软件714套、云服务环境应用支撑软件1009套。

（四）安全保障能力。为357个地市级邮政管理部门配置移动执法装备760套，完善实名收寄、收寄验视、过机安检相关制度以及监控中心规则等标准规范16项。

三、你局作为项目法人，负责该项目的组织实施与管理。

四、项目总投资约6.98亿元，由我委安排中央预算内投资解决。

五、本项目勘察、设计、施工、监理和重要设备材料采购等均采用公开招标方式，招标组织形式为委托招标。

六、在后续阶段，要重点做好以下工作：

（一）进一步细化方案，注重数据分析和利用，采用新技术和新方法提升安全监管能力和水平，提高系统效能。项目初步设计编制完成并审核后，报送我委核定概算。

（二）加强与其他相关部门协调配合，落实跨部门信息共享和业务协同有关要求，并与邮政快递企业有效衔接，确保项目顺利实施，有效发挥效益。

（三）在项目实施中，对工程质量、资金使用和建设进度等加强全过程、全方位监管，确保项目如期竣工。

（四）根据安全监管能力建设和发展需要，研究实施下一期工程的必要性和具体建设内容。

国家发展改革委
