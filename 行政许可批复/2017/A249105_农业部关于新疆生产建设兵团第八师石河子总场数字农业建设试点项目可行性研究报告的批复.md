# 农业部关于新疆生产建设兵团第八师石河子总场数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕59号

新疆生产建设兵团农业局：

《关于上报新疆生产建设兵团数字农业建设试点项目的函》（兵农（市）发〔2017〕39号）收悉。经研究，批复如下：

一、原则同意上报的兵团国家优质棉数字农业建设项目试点可行性研究报告。项目建设单位为新疆生产建设兵团第八师石河子总场，建设地点为新疆生产建设兵团第八师石河子总场四分场。项目建设期2年。

二、项目建设内容：一是北斗时空服务基础设施建设，包括农用导航基站、农机北斗自动导航系统等；二是生产管理物联网及遥感应用，包括大田物联传感系统、棉花长势与冻害风灾遥感监测系统等；三是农业生产全程精准作业应用，包括犁地及深松质量监测系统、对行分层精准施肥机、大田水肥一体化智能滴灌设备、无人机精确植保、高强度残膜回收机具、棉花产量在线监测设备等；四是精细管理与综合集成应用示范，包括农机协同作业系统、农业生产管理系统、技术管理及示范平台等；五是示范区基础设施条件建设，包括农业项目区基础设施、农机具维修保养中心、数据服务中心等。

三、项目建设目标：项目建成后，将形成较为完备的棉花种植数字农业技术体系，形成可推广的区域数字农业发展模式，项目区节水20%以上、节肥30%以上、节药30%以上、节约劳动力50%以上。

四、项目投资及来源：经评估核定，项目估算总投资3619万元，其中中央预算内投资按1086万元控制，其余投资由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程、设计、监理以及技术支撑单位应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你单位申报后续数字农业建设试点项目的资格。
