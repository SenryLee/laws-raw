# 国家文物局关于南京城墙建设控制地带石鼓路（汉西门大街——罗廊巷）拓宽改造工程项目的批复

## 关于南京城墙建设控制地带石鼓路（汉西门大街——罗廊巷）拓宽改造工程项目的批复

文物保函〔2017〕135号

江苏省文物局：

你局《关于审批南京市秦淮区石鼓路（汉西门大街——罗廊巷）拓宽改造工程方案的请示》（苏文物保〔2016〕300号）收悉。经研究，我局批复如下：

一、原则同意在全国重点文物保护单位南京城墙建设控制地带内进行石鼓路（汉西门大街——罗廊巷）拓宽改造工程和你局意见。

二、对该方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》和《南京城墙保护规划》、《南京城墙保护条例》、《南京市历史文化名城保护规划》的有关要求，严格控制工程量和工程范围，尽量减少对文物本体和景观环境的影响。

（二）补充石鼓路拓宽区域考古发掘资料，明确地下遗存情况，并合理调整道路设计，确保与周边景观风貌相协调。

（三）应充分考虑施工振动对城墙安全的影响，制定必要的文物保护措施和应急预案。同时，应加强施工过程中的文物安全监测工作，及时发现隐患，确保文物和人员安全。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。请加强工程监管，确保工程质量和文物安全。

此复。

国家文物局

2017年1月24日
