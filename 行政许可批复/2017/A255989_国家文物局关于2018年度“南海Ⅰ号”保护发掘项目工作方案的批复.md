# 国家文物局关于2018年度“南海Ⅰ号”保护发掘项目工作方案的批复

文物保函〔2017〕1592号

广东省文物局：

你局《关于2018年度“南海Ⅰ号”保护发掘项目工作方案的请示》（粤文物请〔2017〕21号）收悉。经研究，我局批复如下：

一、原则同意所报2018年度“南海Ⅰ号”保护发掘项目工作方案和你局意见。

二、该工作方案应作以下必要的补充、完善：

（一）应进一步细化船体和出水文物保护措施，充分预估发掘过程中可能出现的病害问题，编制相应预案，增强工作的可行性和科学性。

1．发掘过程中应切实做好船体构件保湿防霉工作，并注意评估构件中连接用钉的保存状况，及时开展必要的加固和防腐处理，避免锈蚀加剧。

2．应根据材质分类存放金属文物，不同材质的金属文物不得混放。

3．进一步明确脱盐进度评估的具体标准，建议以氯离子浓度为指标进行全程监控。

（二）应加强发掘后船体安全稳定性评估，科学分析船体全部暴露后的病害影响，模拟验证船体收缩、变形、霉变、病虫害等各类病害发生的概率及危害程度，并在此基础上研究、制定相应的保护预案。

（三）应制定舱内及舷外船板支护方案，开展必要的实验室模拟和现场局部试验，并结合考古工作进度同步做好船体加固防护工作，确保船体安全和考古工作顺利进行。

（四）应进一步细化资料整理计划，明确具体时间要求、责任人员和成果形式等，保证考古发掘与保护资料及时刊布、共享。

三、请你局组织专业单位根据上述意见对方案进行修改和完善，修改后的方案经你局核准后实施，并报我局备案。考古发掘过程中遇有重要发现，应及时向我局报告。

四、请你局加强管理，协同国家文物局水下文化遗产保护中心做好人员和设备调遣、队伍组织协调、后勤保障工作，确保相关工作顺利开展和文物、人员安全。

国家文物局

2017年9月1日
