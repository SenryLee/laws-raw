# 国家文物局关于北京方亭工程监理有限公司文物保护工程监理甲级资质证书内容变更的批复

## 关于北京方亭工程监理有限公司文物保护工程监理甲级资质证书内容变更的批复

办保函〔2017〕537号

北京市文物局：

你局《关于北京方亭工程监理有限公司资质证书变更的请示》（京文物〔2017〕421号）收悉。

经研究，我局同意北京方亭工程监理有限公司文物保护工程监理甲级资质证书中的注册资金由“600万元”变更为“1200万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局

2017年5月8日
