# 国家文物局关于登封城隍庙大殿彩画修缮工程立项的批复

## 关于登封城隍庙大殿彩画修缮工程立项的批复

文物保函〔2017〕318号

河南省文物局：

你局《关于登封城隍庙大殿彩画保护修复立项的请示》（豫文物〔2016〕337号）收悉。经研究，我局批复如下：

一、同意登封城隍庙大殿彩画修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为登封城隍庙大殿彩画。

（三）应加强现状勘察，说明登封城隍庙大殿原彩画范围、形制特点和工艺技法，科学评估其年代及价值，深入分析病害产生原因、类型及影响因素，在此基础上确定工程实施。

（四）应开展必要的保存环境监测工作，系统获取、分析监测数据，明确文物所处环境的变化规律。

（五）应加强前期实验，做好小范围现场试验，并根据试验结果深化设计思路，确保保护措施的可靠性与可行性。

（六）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（七）应根据工程量合理编制经费预算，进一步细化各单项取费依据，补充取费标准。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案；组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年2月22日
