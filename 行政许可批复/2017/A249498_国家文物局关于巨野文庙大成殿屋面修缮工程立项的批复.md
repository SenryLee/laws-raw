# 国家文物局关于巨野文庙大成殿屋面修缮工程立项的批复

## 关于巨野文庙大成殿屋面修缮工程立项的批复

文物保函〔2017〕579号

山东省文物局：

你局《关于申请巨野文庙大成殿修缮工程立项的请示》（鲁文发〔2017〕16号）收悉。经研究，我局批复如下：

一、同意巨野文庙大成殿屋面修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属文物修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程内容为巨野文庙大成殿屋面修缮。

（三）加强现状勘察和研究，查明屋面瓦件大面积集中破损的原因，明确瓦件残损的数量和范围，客观评估2006年修缮工程效果，为科学制定工程措施提供依据。

（四）应深入研究和分析地方建造工艺、传统做法、建筑材料和构造特征等，注意在维修中使用原工艺和原材料。

（五）进一步细化屋面修缮措施和工程做法，严格控制工程量和工程强度，避免过度维修。更换下的瓦件应详细记录，评估其结构强度，并尽量使用。工程资料应由专人管理、建档，并在工程结束后纳入巨野文庙大成殿记录档案。

（六）暂不同意巨野文庙大成殿墙面、台基、石作等修缮工程。应勘查墙面、台基、石作的残损情况和原因，进一步明确修缮工程的必要性。

（七）根据工程量合理编制经费预算，确定取费项目，补充取费标准。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案，组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

四、请你局督促地方人民政府切实加强巨野文庙大成殿日常保养和岁修工作，落实管理维护责任，确保文物安全。

此复。

国家文物局

2017年3月27日
