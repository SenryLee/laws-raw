# 国家文物局关于景德镇御窑厂珠山南麓遗址保护房改造项目设计变更方案的批复

文物保函〔2017〕1968号

江西省文化厅：

你厅《关于呈报〈景德镇御窑厂遗址珠山南麓保护房抢救性改造建筑设计方案〉的请示》（赣文厅字〔2017〕207号）收悉。经研究，我局批复如下：

一、原则同意景德镇御窑厂珠山南麓遗址保护房改建项目设计变更方案和你厅意见。

二、所报方案尚需做以下必要的修改和完善：

（一）应进一步补充保护房屋顶结构和高度设计依据，论证屋顶大挑檐及隔热措施、选用工字钢的必要性，以及空间利用率的合理性。建议尽可能选用轻质材料和结构。

（二）补充散水设计、排水通道设计，并优化渗水井位置，尽可能避让窑址。

（三）说明设备间位置与参观视野的关系，尽可能东移以减少遮挡。

（四）补充通风设计的科学数据和分析研究支撑。

（五）补充建筑的正立面图、剖面图及屋顶平面图等相关图纸。

（六）补充项目施工中的文物保护预案。

四、具体项目方案由你厅根据上述意见指导相关单位修改、完善后实施。

五、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

六、施工中请你厅加强监管，及时开展检查，督促项目单位严格遵守相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

七、项目竣工后，由你厅按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，做好竣工验收工作。

八、请你厅切实加强管理，督促、指导相关单位做好后续相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

国家文物局

2017年12月7日
