# 国家文物局关于同盟国驻渝外交机构旧址群——法国领事馆旧址灰塑修缮工程立项的批复

## 关于同盟国驻渝外交机构旧址群——法国领事馆旧址灰塑修缮工程立项的批复

文物保函〔2017〕596号

重庆市文物局：

你局《关于审批全国重点文物保护单位同盟国驻渝外交机构旧址群——法国领事馆旧址灰塑修缮工程立项的请示》（渝文物〔2017〕12号）收悉。经研究，我局批复如下：

一、同意法国领事馆旧址灰塑修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）工程范围为法国领事馆旧址灰塑。

（三）灰塑保护具有一定特殊性，应在充分开展前期试验的基础上进行方案设计，确保修缮措施科学有效。

（四）在开展灰塑本体保护的同时，应将灰塑载体稳定性及屋面渗漏问题纳入考虑范畴，避免留下隐患。

（五）进一步明确是否清除后期涂刷材料、如何掌握清除程度等技术细节。

（六）广泛收集相关历史资料，为残损灰塑复原设计供科学依据，并注意保留外观的可识别性。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制修缮工程技术方案；由你局组织专家或委托专业机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月30日
