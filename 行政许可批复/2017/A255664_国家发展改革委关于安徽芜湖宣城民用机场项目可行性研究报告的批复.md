# 国家发展改革委关于安徽芜湖宣城民用机场项目可行性研究报告的批复

发改基础〔2017〕1677号

安徽省发展改革委:

报来《关于上报芜湖宣城民用机场建设工程可行性研究报告的请示》（皖发改基础〔2017〕474号）及有关材料均悉。经研究，现批复如下。

一、为贯彻落实国家长江经济带发展战略，完善你省综合交通运输体系，促进区域经济社会和旅游业发展，适应航空运输需求，同意新建安徽芜湖宣城民用机场。

二、本期工程按满足年旅客吞吐量120万人次、货邮吞吐量5000吨的目标设计，飞行区等级指标4C。主要建设内容：建设1条长2800米、宽45米的跑道，主、次降方向均设置I类精密进近系统，1条长1522米的局部平行滑行道和2条垂直联络道；建设1.5万平方米的航站楼和11个机位的站坪；配套建设空管、供油、供电、消防救援等设施。

三、项目总投资13.99亿元，其中：我委安排中央预算内投资2.67亿元，民航局安排民航发展基金5.3亿元，安徽省人民政府安排财政性资金0.3亿元，其余资金由芜湖市和宣城市人民政府按照9:1的比例安排财政性资金解决。

四、芜湖宣城机场建设投资有限公司作为项目法人，负责项目的组织实施与管理。

五、本项目勘察、设计、施工、监理和重要设备材料采购等均采用公开招标，招标组织形式为委托招标。

六、在后续阶段，重点做好以下工作：

（一）统筹机场总体规划、临空产业规划和通用航空的发展，加强机场及周边地区的规划控制，保护好机场净空和电磁环境。

（二）机场建设应体现节能环保要求，优化用能工艺，选用高效节能设备。

（三）切实落实各项风险防范化解措施，制定有效的应急处置预案，保障机场顺利实施。

（四）落实进场道路等配套工程的建设方案和投资主体，确保与机场工程同步建成。

国家发展改革委
