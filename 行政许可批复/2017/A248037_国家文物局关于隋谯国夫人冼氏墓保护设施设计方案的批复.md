# 国家文物局关于隋谯国夫人冼氏墓保护设施设计方案的批复

## 关于隋谯国夫人冼氏墓保护设施设计方案的批复

文物保函〔2017〕375号

广东省文物局：

你局《关于全国重点文物保护单位隋谯国夫人冼氏墓保护设施建设工程方案的请示》（粤文物请〔2016〕72号）收悉。经研究，我局批复如下：

一、原则同意隋谯国夫人冼氏墓保护设施建设工程方案。

二、所报方案应进一步简化围墙和大门的外观设计，不宜过于追求仿古形式，且应进一步缩小体量，降低高度，以满足功能需求为限；管理用房建筑外观应采用当地传统民居形式，檐口高度不得超过4米。

三、请你局指导方案设计单位，根据上述意见对所报方案做进一步修改和完善，并制定科学详细的初步设计和施工设计，经你局核准并完成相应的审批手续后实施。施工中，请你局加强监管，确保工程质量和文物安全。

国家文物局

2017年2月24日
