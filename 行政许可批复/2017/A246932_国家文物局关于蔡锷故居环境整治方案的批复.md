# 国家文物局关于蔡锷故居环境整治方案的批复

## 关于蔡锷故居环境整治方案的批复

文物保函〔2016〕2108号

湖南省文物局：

你局《关于审批〈蔡锷故居环境整治方案〉的请示》（湘 文物报〔2016〕202号）收悉。经研究，我局批复如下：

一、原则同意蔡锷故居环境整治工程方案。

二、该方案尚需进行以下修改和完善：

（一）深入调查研究蔡锷故居历史环境格局和构成，并对后期变化进行评估，合理确定环境整治原则，避免过度拆建和美化加工。

（二）进一步梳理工程内容，合理删减与文物保护展示无关或非必要的项目。水塘及蔡家桥的后期变迁无损文物价值，无须刻意恢复。建设控制地带内的道路调整改造、坟墓整治迁移、民居外观整治等不宜纳入本工程范畴。

（三）针对2010年维修不当的水井、祖坟等历史环境要素，如无确凿的历史证据，应暂予现状保留。

三、请你局指导有关单位，根据上述意见对方案进行必要的修改和完善后，经你局核准后实施。

此复。

国家文物局

2017年1月4日
