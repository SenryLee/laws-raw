# 国家文物局关于北镇庙鼓楼抢险维修工程的批复

## 关于北镇庙鼓楼抢险维修工程的批复

文物保函〔2017〕489号

辽宁省文物局：

你局《关于上报北镇庙鼓楼抢险工程维修方案的请示》（辽文物〔2017〕5号）收悉。经研究，我局批复如下：

一、原则同意所报北镇庙鼓楼抢险工程维修项目和你局意见。

二、对该方案提出以下修改意见：

（一）应切实加强前期勘察和研究，明确鼓楼的原有建筑形制、构造特点等，准确统计鼓楼受损部位、烧毁面积及烧毁构件数量，科学评估受损程度和建筑结构稳定性，为制定修缮措施提供依据。补充说明鼓楼一层保存现状。

（二）应深入研究和分析地方建造工艺、传统做法、建筑材料和构造特征等，注意在维修中使用原工艺和原材料。

（三）进一步完善工程做法，细化修缮措施，明确落架范围，在上述火灾损失评估基础上严格控制工程范围和强度，避免过度维修。更换下的瓦件、脊饰等构件应详细记录，评估其结构强度，并尽量使用。补充鼓楼一层抢险加固措施和二层彩画修复依据。

（四）施工过程中应采取必要的临时性支护措施，确保文物和人员安全。

（五）进一步完善文本和图纸。文本内容应详细说明地面和墙体清理、木构架和构件更换补配、屋面维修、油饰彩画新做的具体工艺技术和流程，并与设计图纸相对应。补充现状测绘图，标注失火受损范围。

三、请你局根据上述意见指导相关单位修改、完善方案，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

四、请你局切实加强管理，督促相关单位做好北镇庙的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年3月14日
