# 国家文物局关于在全国重点文物保护单位后街清真寺保护范围内进行基础设施建设项目的批复

## 关于在全国重点文物保护单位后街清真寺保护范围内进行基础设施建设项目的批复

文物保函〔2017〕976号

甘肃省文物局：

你局《关于开展后街清真寺基础设施建设项目的请示》（甘文局发〔2017〕79号）收悉。经研究，我局批复如下：

一、原则同意在后街清真寺保护范围内进行基础设施建设项目和你局意见。

二、对所报方案提出以下修改完善意见：

（一）该工程位于全国重点文物保护单位后街清真寺保护范围内，应严格遵守《中华人民共和国文物保护法》和甘肃省人民政府关于后街清真寺保护范围的相关管理规定，严格控制工程范围和工程强度，合理改善文物周边环境。

（二）应加强前期勘察和研究，全面搜集文献和影像资料，分析、确定后街清真寺的历史格局和院落风貌，进一步明确地面铺装、围墙、大门的样式和材质，为科学确定环境整治措施提供依据。补充现行保护范围边界和女寺现状使用情况分析。

（三）应结合历史研究成果，进一步深化、调整方案内容。

1. 大门应在方案二的基础上进一步优化方案设计，补充设计依据，建议采用拱门形式，符合当地传统风格，并进一步压缩体量，避免对文物造成压迫感。

2. 女寺应在方案一的基础上进一步优化方案设计，适当缩小建筑体量，深化建筑外观设计，确保与文物及景观风貌相协调。

3. 应进一步降低院墙与影壁墙的高度，建议根据当地传统做法，完善墙体形制和墙面设计。补充下肩做法依据。

4. 进一步明确碑廊的建筑形制和构造设计内容。

5. 院落铺装材料应采用传统样式及工艺做法。

（四）进一步明确地下管网工程开挖的具体工程措施和要求，严格避让建筑基础。

（五）建议适当配植当地绿植，降低新建建筑景观影响。

（六）应充分考虑施工对文物安全的影响，制定必要的文物保护措施和应急预案，并注意加强施工过程中的文物安全监测工作，及时发现、排除隐患，确保文物和人员安全。

（七）进一步完善文本和图纸，补充院落地面排水设计说明及总平面图。

三、请你局根据上述意见，组织相关单位对所报方案进行修改、完善，并经你局核准后实施。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。请加强对工程的监管，确保文物及其环境安全。同时，应向信众做好必要的项目说明、公示等工作，妥善处理工程实施与宗教活动的关系。

此复。

国家文物局

2017年5月12日
