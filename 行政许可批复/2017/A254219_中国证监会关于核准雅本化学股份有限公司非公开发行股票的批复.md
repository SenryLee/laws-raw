# 中国证监会关于核准雅本化学股份有限公司非公开发行股票的批复

## 关于核准雅本化学股份有限公司非公开发行股票的批复

证监许可〔2017〕1091号

雅本化学股份有限公司：

《雅本化学股份有限公司关于创业板非公开发行A股股票的申请报告》（雅本证〔2016〕006号）及相关文件收悉。根据《公司法》、《证券法》和《创业板上市公司证券发行管理暂行办法》（证监会令第100号）等有关规定，经审核，现批复如下：

一、核准你公司非公开发行不超过2亿股新股。

二、本次发行股票应严格按照报送我会的申请文件实施。

三、本批复自核准发行之日起6个月内有效。

四、自核准发行之日起至本次股票发行结束前，你公司如发生重大事项，应及时报告我会并按有关规定处理。

中国证监会

2017年6月29日
