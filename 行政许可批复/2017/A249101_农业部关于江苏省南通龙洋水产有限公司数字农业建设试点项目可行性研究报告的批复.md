# 农业部关于江苏省南通龙洋水产有限公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕47号

江苏省海洋与渔业局：

《江苏省海洋与渔业局关于推荐申报2017年数字农业建设试点项目的请示》（苏海计〔2017〕4号）收悉。经研究，批复如下：

一、原则同意上报的江苏中洋工厂化循环水数字农业建设试点项目可行性研究报告。项目建设单位为南通龙洋水产有限公司，建设地点为江苏省南通市海安县。项目建设期2年。

二、项目建设内容：一是在线监测系统建设，包括浮标水质监测系统、区域视频监控系统和水下视频监控系统等；二是生产过程管理系统建设，包括现场自动控制系统、手持式移动生产管理系统和生产运营管理系统等；三是综合管理保障系统建设，包括鱼病远程诊断系统和质量安全可追溯系统等；四是公共服务系统建设，包括公共信息资源库、疫情灾情监测预警系统、养殖渔情精准服务系统、机房物理环境建设等。

三、项目建设目标：项目建成后，将实现珍稀水产品生产经营的高效管理，示范引领智能化养殖新模式，项目区年养殖存池量提升80%，养殖周期时间缩短20%，水循环利用率达到90%，节约电源30%，鱼病发生率降低65%。

四、项目投资及来源：经评估核定，项目估算总投资3032万元，其中中央预算内投资按910万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你省申报后续数字农业建设试点项目的资格。
