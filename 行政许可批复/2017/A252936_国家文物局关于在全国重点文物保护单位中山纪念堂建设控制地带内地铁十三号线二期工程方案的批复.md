# 国家文物局关于在全国重点文物保护单位中山纪念堂建设控制地带内地铁十三号线二期工程方案的批复

## 关于在全国重点文物保护单位中山纪念堂建设控制地带内地铁十三号线二期工程方案的批复

文物保函〔2017〕1006号

广东省文物局：

你局《关于在全国重点文物保护单位中山纪念堂建设控制地带内地铁十三号线二期工程方案的请示》（粤文物请〔2017〕37号）收悉。经研究，我局批复如下：

一、同意所报选线方案。

二、对方案提出以下修改意见：

（一）应分析和借鉴已建成的2号地铁线的施工资料，进一步完善设计方案，提出注意事项和技术要求。

（二）侧穿中山纪念堂的列车振动影响应按照《古建筑防工业振动技术规范》中相应结构类型的控制标准进行设计和检测。该段路轨设计应采取轨道综合减振降噪措施，尽量减少对文物建筑的影响。

（三）进一步明确明挖法、矿山法和盾构法的施工段，加强施工管理，采取措施减小施工振动和机械振动。

（四）应采取有效措施防止降水引起的地面沉降。

三、请你局指导相关单位根据上述意见对方案进行修改完善，经你局核准后实施。工程施工期间，应加强对工程的监管，确保文物安全。

此复。

国家文物局

2017年5月22日
