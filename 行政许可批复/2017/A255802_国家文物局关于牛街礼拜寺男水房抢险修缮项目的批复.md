# 国家文物局关于牛街礼拜寺男水房抢险修缮项目的批复

文物保函〔2017〕1372号

北京市文物局：

你局《关于牛街礼拜寺男水房抢险修缮工程的请示》（京文物〔2017〕736号）收悉。经研究，我局批复如下：

一、原则同意牛街礼拜寺男水房修缮项目和你局意见。

二、对所报项目提出以下意见：

（一）应进一步加强现状勘察，明确具体工程量。

（二）应坚持最小干预原则，严格控制工程范围和强度，细化工程做法和技术要求。

1. 进一步论证南墙外侧砌筑隔水墙的必要性，建议保留南墙下肩既有水泥抹面，不宜剔除重抹。

2. 整修、加固外侧门窗，保持文物建筑原有风貌，根据使用需要可适当在内侧增加断桥铝门窗。不同意拆除破损门窗后直接更换为断桥铝门窗。

3. 上下水管尽量利用原有线路，注意新作管道不得破坏文物建筑基础和墙体。

4. 注意室内、室外地面做法的区别并尽可能采取传统做法。根据使用性质室内重铺地面应做防水处理；进一步明确室外散水做法，补充糙墁细作的具体要求和做法。

5. 大木梁架打箍加固建议使用铁板，不宜使用钢板。进一步明确室外大木地仗做法。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善并经你局批准后组织实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作，并充分听取利益相关者的意见。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好维修后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年8月8日
