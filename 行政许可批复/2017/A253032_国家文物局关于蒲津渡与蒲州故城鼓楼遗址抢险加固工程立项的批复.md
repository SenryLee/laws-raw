# 国家文物局关于蒲津渡与蒲州故城鼓楼遗址抢险加固工程立项的批复

## 关于蒲津渡与蒲州故城鼓楼遗址抢险加固工程立项的批复

文物保函〔2017〕956号

山西省文物局：

你局《关于申请永济市蒲津渡与蒲州故城遗址鼓楼抢险加固工程立项的请示》（晋文物〔2016〕227号）收悉。经研究，我局批复如下：

一、原则同意蒲津渡与蒲州故城鼓楼遗址抢险加固工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状加固为主，排除安全隐患为目的，做好鼓楼遗址的基址结构及表面加固，注意控制工程规模、范围和强度，避免过度保护。

（二）深化前期勘察、研究和试验，加强对鼓楼遗址拱券结构及夯土内部遗存的现状勘察，明确基址变形和结构失稳的程度及原因，为方案编制提供科学依据。

（三）加强考古和研究工作，明确鼓楼城台、原地面及周边排水设施形制，不同意在复原依据不足的情况下进行鼓楼遗址城台垛口、周边地面及散水的复原修复。

（四）应充分考虑基址外包砌砖与内部夯土墙之间的拉结问题，外包砌砖应尽量利用散落的原砌砖材料，避免形成修葺一新的效果。同时，不得大面积新增外包砌砖，应仅限于现有包砖部位和确实存在结构性风险的遗址部位。

（五）补充遗址表面防水措施，充分考虑遗址安全及后续维护措施。

（六）严格控制工程预算，进一步梳理并控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年5月9日
