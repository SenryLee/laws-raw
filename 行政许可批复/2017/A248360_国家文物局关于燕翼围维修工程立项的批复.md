# 国家文物局关于燕翼围维修工程立项的批复

## 关于燕翼围维修工程立项的批复

文物保函〔2017〕416号

江西省文物局：

你局《关于呈报〈燕翼围修缮工程立项报告〉的请示》（赣文物局字〔2017〕1号）收悉。经研究，我局批复如下：

一、同意燕翼围维修工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）该工程实施范围为燕翼围。

（三）深化现状勘察，分析病害原因，加强对燕翼围原有形制、材料、工艺的研究，制定有针对性的修缮措施。

（四）遵循“最小干预”原则，严格控制工程量。补充恢复围内正门门罩、房门、火枪眼和装修等的历史依据。

（五）正面墙体及右侧墙体脱盐处理措施必要性不足，应予以取消。

（六）注意对外墙上日军侵华战争所留机炮射击痕迹的保护。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织或委托专业机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月3日
