# 国家文物局关于成都市宏泰建筑有限责任公司文物保护工程施工一级资质证书内容变更的批复

## 关于成都市宏泰建筑有限责任公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕798号

四川省文物局：

你局《关于变更成都市宏泰建筑有限责任公司文物保护工程资质证书的请示》（川文物〔2017〕72号）收悉。

经研究，我局同意成都市宏泰建筑有限责任公司文物保护工程施工一级资质证书中的法定代表人由“曾全新”变更为“兰澜”，注册资金由“850万元”变更为“5000万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局

2017年6月27日
