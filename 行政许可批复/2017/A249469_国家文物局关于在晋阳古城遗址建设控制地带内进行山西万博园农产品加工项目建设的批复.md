# 国家文物局关于在晋阳古城遗址建设控制地带内进行山西万博园农产品加工项目建设的批复

## 关于在晋阳古城遗址建设控制地带内进行山西万博园农产品加工项目建设的批复

文物保函〔2017〕594号

山西省文物局：

你局《关于在晋阳古城遗址建设控制地带内进行山西万博园农产品加工项目建设的请示》（晋文物〔2017〕85号）收悉。经研究，我局批复如下：

一、原则同意山西万博园农产品加工基地建设项目涉及晋阳古城遗址建设控制地带的选址方案。

二、该建设项目应进一步严格控制建筑规模、体量和高度，建筑布局可考虑适当分散，避免出现大体量建筑，建筑高度以不高于12米为宜，建筑外观亦不宜采用明亮色彩。同时，建议在厂区东侧布设必要的绿化遮挡，以进一步减缓该建设项目对晋阳古城遗址景观环境的影响。

三、请你局组织专业考古研究单位在山西万博园农产品加工基地建设项目涉及晋阳古城遗址的拟建区域进一步开展全面的考古勘探和考古发掘工作，所需经费由建设单位承担。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

四、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，经你局核准后实施。

五、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促工程部门切实做好工程施工过程中的文物保护工作，确保文物安全。

国家文物局

2017年3月29日
