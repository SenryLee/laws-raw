# 国家文物局关于南京市扬子江大道快速化改造建设项目涉及龙江船厂遗址建设控制地带选址方案的批复

## 关于南京市扬子江大道快速化改造建设项目涉及龙江船厂遗址建设控制地带选址方案的批复

文物保函〔2017〕1214号

江苏省文物局：

你局《关于审批南京市扬子江大道快速化改造方案的请示》（苏文物保〔2017〕158号）收悉。经研究，我局批复如下：

一、原则同意南京市扬子江大道快速化改造建设项目涉及龙江船厂遗址建设控制地带的选址方案。

二、龙江船厂遗址是海上丝绸之路申遗工作的重要组成部分，应按照申报世界文化遗产要求，统筹考虑地方基础设施建设和文物保护问题。

三、所报方案应进行以下必要的修改和完善：

（一）应进一步调整现有设计方案，建议适当延长改造路段的长度，充分考虑龙江船厂遗址现存三条作塘的分布范围，为空间上连通遗址与夹江、全面展示遗址格局创造条件。

（二）建议考虑涉及龙江船厂遗址建设控制地带的改造路段机动车道全部采用隧道下穿方式，地面可保留非机动车道和人行道。同时，通过景观绿化、标识展示等方式增强龙江船厂遗址与夹江的联系，创建遗址与长江之间的展示、游憩空间。

（三）优化道路隧道端口等构筑物及道路周边景观工程的设计，注意体量、形式、色彩应与遗址环境相协调，尽量弱化现代道路设施对文物环境风貌的不利影响。

（四）加强工程实施前的考古工作，委托有资质的考古单位对扩大的工程范围进行充分考古勘探，发现地下文物遗存应立即停工，及时调整建设方案。

四、请你局组织专业考古研究单位，在该项目涉及龙江船厂遗址的拟建区域进一步开展全面的考古调查和发掘工作。请你局加强管理，确保工作质量和工地安全；遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。如需要开展考古发掘，应另行填报考古发掘申请书。

五、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，经你局核准后实施。

六、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促工程部门切实做好工程施工过程中的文物保护工作，确保文物安全。

此复。

国家文物局

2017年7月6日
