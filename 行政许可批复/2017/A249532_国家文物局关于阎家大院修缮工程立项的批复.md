# 国家文物局关于阎家大院修缮工程立项的批复

## 关于阎家大院修缮工程立项的批复

文物保函〔2017〕539号

山西省文物局：

你局《关于申请定襄县阎家大院修缮工程立项的请示》（晋文物〔2017〕3号）收悉。经研究，我局批复如下：

一、同意阎家大院修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）工程范围为阎家大院文物建筑。

（三）强化现场勘察，准确掌握病害及残损情况，明确建筑基础下沉原因，制定针对性保护措施。

（四）坚持“最小干预”原则，严格控制工程量。对无碍建筑结构安全的残损构件应尽可能修补留用。进一步研究并调整拆除水塔外围墙体的措施。

（五）细化项目实施计划，补充院内排水修整措施。

（六）相关设计应兼顾今后文物的展示利用需求。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制修缮工程技术方案；由你局组织专家或委托专业机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月21日
