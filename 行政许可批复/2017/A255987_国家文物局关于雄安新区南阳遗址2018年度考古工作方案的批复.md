# 国家文物局关于雄安新区南阳遗址2018年度考古工作方案的批复

文物保函〔2017〕1584号

河北省文物局：

你局《关于呈报容城南阳遗址（2018年）考古工作计划的请示》（冀文物字〔2017〕195号）收悉。经研究，我局批复如下：

一、原则同意雄安新区南阳遗址2018年度考古工作方案。

二、该考古工作方案应进行以下必要的修改和完善：

（一）应以南阳遗址及周边同时代遗存为重点，开展专项考古调查、勘探，核实勘探面积，采用普通勘探与重点勘探相结合的方式，重点探明该区域地下文物分布范围和保存情况，为后续工作提供依据。

（二）应根据考古勘探工作结果，进一步优化和调整考古发掘的具体位置，以城垣、城门、大型夯土建筑基址、大型墓葬为主，科学确定南阳遗址的分布范围、格局、年代和性质。发掘面积应控制在1000平方米以内，具体考古发掘项目应按程序另行填报考古发掘申请书。

（三）应增强考古发掘工作的计划性与前瞻性，充分采用实验室考古、三维激光扫描等现代科技手段，最大限度地获取遗址信息。同时，应进一步优化和完善文物保护预案，提出具有针对性的重要出土文物现场保护措施，确保文物安全。

（四）应加强考古工作成果的整合与应用，注意做好全部数据的电子化处理，并纳入雄安新区考古数字化信息管理平台，实现各考古和研究项目之间的的数据共享。

三、请你局组织专业考古研究单位，根据上述意见进一步修改完善工作方案，经你局核准后实施。实施中，请你局加强日常指导和监管，确保工作质量和人员、文物安全。

国家文物局

2017年9月1日
