# 国家文物局关于全州县湘江战役旧址四期修缮工程立项的批复

## 关于全州县湘江战役旧址四期修缮工程立项的批复

文物保函〔2017〕525号

广西壮族自治区文化厅：

你厅《关于报送全州县湘江战役旧址修缮工程四期立项报告的请示》（桂文物报〔2016〕2号）收悉。经研究，我局批复如下：

一、同意全州县湘江战役旧址四期修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）工程实施范围为红一军团宿营地，红一军团途经地，中央红军宿营地，红五军团三十四师伤员宿营地，红六、八、九军团途经地，红九军团宿营地等18处旧址文物建筑。

（三）进一步核查文物构成，所有拟修缮对象均应在已公布的全国重点文物保护单位湘江战役旧址范围内。

（四）在对前三期修缮工程措施和效果进行总结评估的基础上，对本期修缮工程涉及的各单体文物建筑逐一开展现场勘察测绘、文物保存现状评估以及建筑形制调研，根据具体情况分别制定针对性保护措施。

（五）坚持最小干预原则，严格控制工程量，避免过度修缮。鉴于多处建筑缺损严重，应科学把握残损构件的修补和更换原则，最大限度保护文物本体及各类历史信息的真实性和完整性。同时注意对文物原材料、原工艺的传承。

（六）本期工程拟修缮文物建筑数量较多，应根据轻重缓急原则、量力而行，合理确定实施计划，分期分类落实修缮任务，确保工程质量和文物安全。

三、请你厅指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制修缮工程技术方案；由你厅组织专家或委托专业机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月21日
