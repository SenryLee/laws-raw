# 国家文物局关于南京城墙建设控制地带内大桥南路积淹水片区改造工程项目的批复

## 关于南京城墙建设控制地带内大桥南路积淹水片区改造工程项目的批复

文物保函〔2017〕332号

江苏省文物局：

你局《关于审批大桥南路积淹水片区改造工程设计方案的请示》（苏文物保〔2016〕327号）收悉。经研究，我局批复如下：

一、原则同意在南京城墙建设控制地带内进行大桥南路积淹水片区改造工程和你局意见。

二、对该方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》和《南京城墙保护规划》、《南京城墙保护条例》、《南京市历史文化名城保护规划》的有关要求，严格控制工程量和工程范围，尽量减少对文物本体和地下遗存的影响。

（二）补充拟施工区域考古工作方案，组织专业机构开展必要的考古工作，明确拟施工区域城墙遗址的宽度、埋深及其他地下遗存分布等情况。补充工程范围内的地下文物分布图和考古报告。

（三）根据考古工作成果进一步调整方案设计，建议遗址区域采取顶管施工法，经考古勘探明确无遗存的区域可采取明挖法。应充分考虑施工对文物安全的影响，制定必要的文物保护措施和应急预案。同时，应加强施工过程中的文物安全监测工作，及时发现隐患，确保文物和人员安全。

（四）进一步完善文物影响评估报告，客观、准确的评估工程施工对城墙遗址及其他地下遗存的影响。

（五）完善项目施工段与南京城墙保护区划关系的相关图纸。补充拟施工区域现状照片。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。请加强工程监管，确保工程质量和文物安全。

此复。

国家文物局

2017年2月22日
