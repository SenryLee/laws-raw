# 国家文物局关于在延恩寺塔建设控制地带内移建国家环境空气质量自动监测站点的批复

## 关于在延恩寺塔建设控制地带内移建国家环境空气质量自动监测站点的批复

文物保函〔2017〕1019号

甘肃省文物局：

你局《关于在延恩寺塔建设控制地带内移建国家环境空气质量自动监测站点的请示》（甘文局发〔2017〕81号）收悉。经研究，我局批复如下：

一、原则同意在延恩寺塔建设控制地带内移建国家环境空气质量自动监测站点和你局意见。

二、对所报方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》和甘肃省人民政府关于全国重点文物保护单位延恩寺塔建设控制地带的相关管理规定，合理确定拟建建筑的规模、高度和外观样式，严格控制施工范围，尽量减少对文物本体和景观环境的影响，确保文物安全。

（二）应进一步降低拟建建筑高度，建议建筑层数压减为两层；建筑形制应简洁、朴素，不必采用仿古建筑；建议拟建建筑面向文物一侧种植高大树木，通过绿植降低建设项目对文物本体的景观影响。

（三）应充分考虑建设施工对延恩寺塔安全的影响，制定必要的文物保护措施和应急预案。补充说明拟建建筑基础挖深6.3米的必要性及相关工程预案。补充调整后的建筑设计图。

（四）应进一步完善文物影响评估报告，客观、准确、科学论证拟建建筑对文物本体和环境风貌的影响。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。请加强工程监管，并注意加强施工过程中的文物安全监测工作，及时发现隐患，确保文物和人员安全。

此复。

国家文物局

2017年5月24日
