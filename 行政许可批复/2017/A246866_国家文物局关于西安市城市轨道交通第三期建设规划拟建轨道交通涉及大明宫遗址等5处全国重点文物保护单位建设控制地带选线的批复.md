# 国家文物局关于西安市城市轨道交通第三期建设规划拟建轨道交通涉及大明宫遗址等5处全国重点文物保护单位建设控制地带选线的批复

## 关于西安市城市轨道交通第三期建设规划拟建轨道交通涉及大明宫遗址等5处全国重点文物保护单位建设控制地带选线的批复

文物保函〔2017〕99号

陕西省文物局：

你局《关于呈报西安市城市轨道交通第三期建设规划的请示》（陕文物字〔2016〕252号）收悉。经研究，我局批复如下：

一、原则同意西安市城市轨道交通第三期建设规划中拟建轨道交通涉及全国重点文物保护单位大明宫遗址、汉长安城遗址、丰镐遗址（镐京遗址）和西安城墙建设控制地带以及隋大兴唐长安城遗址的选线方案。涉及陕西省省级文物保护单位建设控制地带及其他不可移动文物的轨道交通选线方案，依法由你局审批。

二、在下一阶段工作中，请你局组织有资质的专业考古单位在涉及不可移动文物的轨道交通拟建区域进一步开展全面的考古调查、勘探和发掘工作，所需经费由建设单位承担。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

三、拟建轨道交通涉及上述不可移动文物的站位选址应在开展必要考古工作，并做好文物影响评估的基础上予以深化和优化，避免占压重要文物遗存，并充分考虑施工及后续运营震动的不良影响，确保文物安全。相关选址方案，应根据文物的保护级别，按程序另行报批。

四、应进一步优化拟建轨道交通涉及不可移动文物区段的方案设计和施工设计，采取必要的减震避震措施，并制定专门的文物保护方案，对所涉及文物做好有针对性的保护和防护，以确保文物安全，相关方案由你局核准。

国家文物局

2017年1月19日
