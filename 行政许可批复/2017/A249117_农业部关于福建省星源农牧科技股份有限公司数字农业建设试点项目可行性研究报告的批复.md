# 农业部关于福建省星源农牧科技股份有限公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕50号

福建省农业厅：

《福建省农业厅关于推荐上报2017年数字农业建设试点项目的请示》（闽农计〔2017〕38号）收悉。经研究，批复如下：

一、原则同意上报的福建省福清市数字农业建设试点项目可行性研究报告。项目建设单位为福建省星源农牧科技股份有限公司，建设地点为福建省福州市福清市。项目建设期2年。

二、项目建设内容：一是自动化精准环境控制系统建设，包括自动化通风系统、温控系统、空气过滤系统和环境监测系统等；二是数字化精准饲喂管理系统建设，包括电子识别系统、自动称量系统、精准上料系统、自动饮水系统等；三是无害化粪污处理系统建设，包括粪便厌氧发酵池、猪舍自动化改造等。

三、项目建设目标：项目建成后，实现饲养环境自动调节，粪污无害化处理和资源化利用，探索数字农业技术集成应用解决方案和产业化模式，项目区每头猪人工饲养成本节省25-30%，饲料转化率降至2.7，经产母猪产仔数增加至12头，母猪配种率提高到95%。

四、项目投资及来源：经评估核定，项目估算总投资2911万元，其中中央预算内投资按873万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你省申报后续数字农业建设试点项目的资格。
