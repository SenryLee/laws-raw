# 国家文物局关于辽宁大连庄河海域甲午沉舰遗址2017年度考古调查工作方案的批复

## 关于辽宁大连庄河海域甲午沉舰遗址2017年度考古调查工作方案的批复

文物保函〔2017〕906号

辽宁省文物局：

你局《关于上报〈2017年辽宁省大连庄河海域甲午沉舰调查工作方案〉的请示》（辽文物〔2017〕43号）收悉。经研究，我局批复如下：

一、原则同意所报庄河海域甲午沉舰遗址2017年度考古调查工作方案和你局意见。

二、该方案应进行以下补充、完善：

（一）适当调整工作目标，以现状调查测绘、搞清遗存基本状况为主，减少水下泥沙抽取的工作量。应充分利用有效工作时间，提高工作效率，尽可能缩短整体工作周期。

（二）进一步细化经费预算，切实核定技术设备和人员费用，并明列各项取费的具体标准依据。

（三）进一步加强与国家文物局水下文化遗产保护中心的沟通协调，明确工作队伍组成和职责分工。

三、请你局进一步加强与公安、边防、海洋、海事等相关部门沟通，督促有关单位依法取得此次水下工作区域的海域使用权或临时海域使用权，并注意水下考古工作过程中的环境保护问题，采取有效措施降低考古活动对海洋环境的影响。请你局加强监督、管理，确保工作顺利进行和人员、文物安全。

国家文物局

2017年4月28日
