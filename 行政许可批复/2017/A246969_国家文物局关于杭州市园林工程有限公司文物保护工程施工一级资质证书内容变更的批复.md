# 国家文物局关于杭州市园林工程有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于杭州市园林工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕37号

浙江省文物局：

你局《关于杭州市园林工程有限公司要求办理文物保护工程资质证书变更的请示》（浙文物发〔2016〕376号）收悉。

经研究，我局同意杭州市园林工程有限公司文物保护工程施工一级资质证书中的注册资金由“22900万元”变更为“32900万元”。请你局通知申请单位，携带资质证书副本到我局办理相关手续。

国家文物局

2017年1月20日
