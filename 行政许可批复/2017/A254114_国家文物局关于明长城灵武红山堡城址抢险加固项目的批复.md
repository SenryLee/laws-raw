# 国家文物局关于明长城灵武红山堡城址抢险加固项目的批复

文物保函〔2017〕1319号

宁夏回族自治区文物局：

你局《关于报送宁夏明长城红山堡城址抢险加固工程勘察设计方案的请示》（宁文物发〔2017〕55号）收悉。经研究，我局批复如下：

一、原则同意所报灵武市临河镇红山堡城址（长城认定编码：640181353102170003）保护加固工程勘察设计方案和你局意见。

二、对该方案提出如下修改意见：

（一）坚持最小干预原则，严格控制砌补支顶、凹槽填补等措施的实施范围和规模。应重新调整冲沟治理措施，以随形加固、维持现状稳定和保持原有排水功能为主，避免过度干预。

（二）进一步加强现状勘察和研究，深化墙体结构稳定性评估，分析土坯砌筑过程中可能存在的沉降问题，并深化施工要求；风化凹槽砌补支顶应尽量以夯筑修补为主；进一步细化墙顶排水系统的具体实施范围和做法。

（三）补充墙体原夯筑材料的配比构成分析试验数据、墙体根部夯土的可溶盐分析、改性黄胶泥的具体材料配比和土坯砖的质量控制标准等内容。

（四）加强图例与图纸标注的对应性，完善图纸工程量化标注，进一步补充土坯砌补、墙顶排水等加固节点的设计详图。

三、请你局指导有关单位，根据上述意见对所报方案进行修改、完善，经你局核准后实施。请切实加强工程监管，督促方案设计单位加强施工全过程技术指导，落实各方责任，确保工程质量和文物、人员安全。

国家文物局

2017年8月1日
