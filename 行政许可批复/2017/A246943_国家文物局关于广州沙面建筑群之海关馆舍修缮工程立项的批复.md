# 国家文物局关于广州沙面建筑群之海关馆舍修缮工程立项的批复

## 关于广州沙面建筑群之海关馆舍修缮工程立项的批复

文物保函〔2017〕56号

广东省文物局：

你局《关于全国重点文物保护单位沙面建筑群之海关馆舍修缮工程立项的请示》（粤文物请〔2016〕31号）收悉。经研究，我局批复如下：

一、同意广州沙面建筑群之海关馆舍修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质为文物修缮工程。

（二）工程范围为海关馆舍文物建筑。

（三）深入开展现状勘察，准确掌握病害性质、成因及残损范围、程度，同时调查记录拟修缮部位的原始建造工艺、材料，为制定有针对性的保护措施提供科学依据。

（四）坚持最小干预原则，严格控制工程规模和工程量，最大限度地保留文物建筑历史信息。

（五）应对2010年修缮工程中的白蚁病害防治措施和效果进行评估，并注意在本轮修缮中加以改进，确保工程质量。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年1月13日
