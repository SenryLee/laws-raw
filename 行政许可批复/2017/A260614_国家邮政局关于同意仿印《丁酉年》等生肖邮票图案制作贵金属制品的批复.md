# 国家邮政局关于同意仿印《丁酉年》等生肖邮票图案制作贵金属制品的批复

国邮复〔2017〕42号

中国邮政集团公司贵州省分公司：

根据《中华人民共和国邮政法实施细则》规定，按照《仿印邮票图案管理办法》规定程序，国家邮政局对你公司经贵州省邮政管理局初审的有关仿印邮票图案及其制品的申请材料依法进行了审核。现批复如下：

一、同意你公司单色原大（36×36毫米）仿印2017―1《丁酉年》（全套2枚）邮票图案制作2克/枚纯金制品，制作数量为5000套（1枚/套）。承制单位为厦门中天旭日投资实业有限公司。

同意你公司单色原大（36×36毫米）仿印2017―1《丁酉年》（全套2枚）邮票图案制作1克/枚纯金制品，制作数量为10000套（2枚/套）。承制单位为深圳市翠绿首饰股份有限公司。

同意你公司单色原大（36×36毫米）仿印2017―1《丁酉年》（全套2枚）邮票图案制作5克/枚纯金制品，制作数量为5000套（2枚/套）。承制单位为深圳市翠绿首饰股份有限公司。

同意你公司单色原大（36×36毫米）仿印2017―1《丁酉年》（全套2枚）邮票图案制作10克/枚纯银制品，制作数量为5000套（2枚/套）。承制单位为广州天晨包装制品有限公司。

同意你公司原色放大三分之一以上（60×60毫米）仿印2017―1《丁酉年》第一图邮票图案制作陶瓷制品，制作数量为500套（1枚/套）。承制单位为广州天晨包装制品有限公司。

同意你公司仿印2016―1《丙申年》（全套2枚）邮票图案制作纸制品，50ml规格，外盒正面原色缩小至(24×24毫米），外盒侧面原色缩小至(15.6×15.6毫米），酒瓶标原色缩小至(16.1×16.1毫米），制作数量为2655套（2枚/套）；500ml规格：外盒原色放大至(50.1×50.1毫米）,酒瓶标原色缩小至(22.1×22.1毫米），制作数量为2655套（2枚/套）。承制单位为贵州省茅台酒个性化定制营销有限公司。

同意你公司仿印2017―1《丁酉年》（全套2枚）邮票图案制作纸制品，50ml规格，外盒正面原色缩小至(24×24毫米），外盒侧面原色缩小至(15.6×15.6毫米），酒瓶标原色缩小至(16.1×16.1毫米），制作数量为2655套（2枚/套）；500ml规格：外盒原色放大至(50.1×50.1毫米）,酒瓶标原色缩小至(22.1×22.1毫米），制作数量为2655套（2枚/套）。承制单位为贵州省茅台酒个性化定制营销有限公司。

二、仿印邮票图案制品或者其外包装上须标明下列各项：

（一）仿印单位名称、地址；

（二）审批机关和批准文号；

（三）制作数量；

（四）制作单位；

（五）印制单位；

（六）其他应当标明的有关事项。

三、仿印2017―1《丁酉年》（全套2枚）、2016―1《丙申年》（全套2枚）邮票图案及其制品由贵州省邮政管理局负责监制。你公司须持批准文件与承制企业按照国家有关规定签订印制合同，并在印制前将仿印邮票图案样品送监制单位——贵州省邮政管理局（地址：贵州省贵阳市文昌北路231号）审签后方可正式生产。在仿印邮票图案制品发行前向国家邮政局（地址：北京市西城区北礼士路甲8号）送缴样品存档。不得转让获准仿印邮票图案的制作权和发行权。

四、此文件有效期截止到2018年5月18日，如在批文有效期内未进行仿印的，必须报国家邮政局备案，并将批准文件退回。

国家邮政局
