# 国家文物局关于中山古城遗址中山王厝墓保护展示工程立项的批复

## 关于中山古城遗址中山王厝墓保护展示工程立项的批复

文物保函〔2017〕414号

河北省文物局：

你局《关于中山古城遗址王厝墓保护展示工程立项的请示》（冀文物字〔2017〕17号）收悉。经研究，我局批复如下：

一、原则同意中山古城遗址中山王厝墓保护展示工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）坚持最小干预原则，严格控制工程量和工程范围，墓葬保护性设施的加固和改造应充分利用既有基础条件，在方案一设计思路的基础上进一步深化设计，避免重复建设，并注意控制后续维护成本；墓葬现存封土的整治应以现状加固为主，辅以小规模修整，不得大规模复原封土。

（二）切实做好前期勘察、研究和试验，对墓葬和现有保护性设施进行详细调查评估，分析稳定性和对墓葬的影响，为科学编制工程方案提供依据。墓葬本体保护应避免大规模工程干预，以确保墓葬稳定安全为限。

（三）现阶段在保护性设施改造的同时，做好王厝墓的本体展示即可。陵园及其他遗存的展示应在统筹考虑展示条件与前景的基础上进一步论证可行性与必要性，并按程序另行报批。

（四）严格控制工程预算，进一步梳理并控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年3月2日
