# 国家卫生计生委关于华中科技大学同济医学院附属梨园医院扩建工程初步设计和投资概算的批复

国卫规划函〔2017〕500号

华中科技大学同济医学院附属梨园医院：

你院《关于报请审批扩建工程初步设计和投资概算的请示》（梨园医院字〔2017〕77号）收悉。经研究，原则同意你院扩建工程初步设计和投资概算。该工程总建筑面积48,900平方米（地上建筑面积31,500平方米，地下建筑面积17,400平方米），其中，综合楼建筑面积16,900平方米（地上建筑面积11,500平方米，地下建筑面积5,400平方米），老年医学中心康复楼建筑面积32,000平方米（地上建筑面积20,000平方米，地下建筑面积12,000平方米）。工程概算总投资35,396万元，资金来源为申请中央预算内投资和医院自筹资金共同解决。

请你院按照国家有关规定，严格执行基本建设程序，落实项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计和投资概算，抓紧组织开展下一步工作。

此复。

国家卫生计生委

2017年12月29日
