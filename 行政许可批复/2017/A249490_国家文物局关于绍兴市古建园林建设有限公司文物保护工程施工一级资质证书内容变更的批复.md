# 国家文物局关于绍兴市古建园林建设有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于绍兴市古建园林建设有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕303号

浙江省文物局：

你局《关于绍兴市古建园林建设有限公司要求办理文物保护工程资质证书变更的请示》（浙文物发〔2017〕54号）收悉。

经研究，我局同意绍兴市古建园林建设有限公司文物保护工程施工一级资质证书中的经济性质由“全民所有制”变更为“有限责任公司”。请你局通知申请单位，携带资质证书副本到我局办理相关手续。

国家文物局

2017年3月23日
