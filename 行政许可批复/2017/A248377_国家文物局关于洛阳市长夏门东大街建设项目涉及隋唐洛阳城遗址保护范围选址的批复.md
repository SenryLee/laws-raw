# 国家文物局关于洛阳市长夏门东大街建设项目涉及隋唐洛阳城遗址保护范围选址的批复

## 关于洛阳市长夏门东大街建设项目涉及隋唐洛阳城遗址保护范围选址的批复

文物保函〔2017〕429号

河南省文物局：

你局《关于上报洛阳市长夏门东大街建设项目的请示》（豫文物〔2017〕13号）收悉。经研究，我局批复如下：

一、原则同意洛阳市长夏门东大街建设项目涉及隋唐洛阳城遗址保护范围的选址方案。

二、该道路建设工程应进一步优化设计，尽量采用传统设计，避免使用大型立交设施。同时，道路基础设施及地埋雨水管线等附属设施的布设应优化设计，注意确保地下文物遗存安全。

三、请你局组织专业考古研究单位在洛阳市长夏门东大街建设项目涉及隋唐洛阳城遗址的拟建区域进一步开展全面的考古勘探和发掘工作，所需经费由建设单位承担。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。考古发掘项目需另行填报考古发掘申请书。

四、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，经你局核准后实施。

五、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促工程部门切实做好工程施工过程中的文物保护工作，确保文物安全。

国家文物局

2017年3月2日
