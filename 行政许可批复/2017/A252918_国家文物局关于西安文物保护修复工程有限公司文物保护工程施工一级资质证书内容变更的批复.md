# 国家文物局关于西安文物保护修复工程有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于西安文物保护修复工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕635号

陕西省文物局：

你局《关于西安文物保护修复工程有限公司申请变更文物保护工程施工资质证书相关信息的请示》（陕文物字〔2017〕113号）收悉。

经研究，我局同意西安文物保护修复工程有限公司文物保护工程施工一级资质证书中的单位名称由“西安文物保护修复工程有限公司”变更为“陕西省文物保护工程有限公司”，单位地址由“陕西省西安市兴善寺东街12号”变更为“陕西省西安市高新区科技一路35号”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局

2017年5月24日
