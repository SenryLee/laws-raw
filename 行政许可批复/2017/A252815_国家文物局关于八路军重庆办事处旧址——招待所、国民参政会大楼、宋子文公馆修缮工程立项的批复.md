# 国家文物局关于八路军重庆办事处旧址——招待所、国民参政会大楼、宋子文公馆修缮工程立项的批复

## 关于八路军重庆办事处旧址——招待所、国民参政会大楼、宋子文公馆修缮工程立项的批复

文物保函〔2017〕749号

重庆市文物局：

你局《关于审批全国重点文物保护单位八路军重庆办事处旧址——招待所、国民参政会大楼、宋子文公馆修缮工程立项报告的请示》（渝文物〔2017〕9号）收悉。经研究，我局批复如下：

一、同意八路军重庆办事处旧址招待所、国民参政会大楼、宋子文公馆修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质为修缮工程。

（二）工程范围为招待所、国民参政会大楼、宋子文公馆文物建筑。水井、水坝整治内容不在本工程范畴。

（三）强化文物现状勘察，准确掌握各建筑的病害及残损情况，科学评估建筑整体结构稳定性，调查记录建筑特征及建造工艺、材料，为制定针对性保护措施提供科学依据。

（四）坚持最小干预原则，以现状修整、排除安全隐患为主，严格控制工程范围和工程量，避免对文物不必要的扰动。

（五）如存在蚁患，应同步采取虫害防治措施。

（六）相关设计应统筹考虑文物展示利用需求。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制修缮工程技术方案；由你局组织专家或委托专业评估机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年4月12日
