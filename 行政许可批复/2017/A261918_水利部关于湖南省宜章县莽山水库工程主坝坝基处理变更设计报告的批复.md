# 水利部关于湖南省宜章县莽山水库工程主坝坝基处理变更设计报告的批复

水规计〔2017〕272号

湖南省水利厅：

你厅《关于请求审批〈宜章县莽山水库工程主坝坝基处理变更设计报告〉的请示》（湘水建管〔2016〕63号）收悉。我部水利水电规划设计总院对随文上报的《湖南省宜章县莽山水库工程主坝坝基处理变更设计报告》进行审查，并提出了审查意见（见附件）。经研究，我部基本同意该审查意见。请你厅按照建设程序和审查意见要求，认真组织实施，严格控制建设规模和投资，确保工程质量，保障工程安全运行。

设计变更后增加的投资在原批准的湖南省宜章县莽山水库工程总概算内调剂解决，不足部分由湖南省协调解决。

附件：水规总院关于湖南省宜章县莽山水库工程主坝坝基处理变更设计报告审查意见的报告

水利部

2017年8月7日
