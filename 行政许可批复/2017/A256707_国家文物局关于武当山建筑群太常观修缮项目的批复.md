# 国家文物局关于武当山建筑群太常观修缮项目的批复

文物保函〔2017〕1753号

湖北省文物局：

你局《关于上报武当山建筑群太常观修缮工程勘察设计方案的请示》（鄂文物〔2017〕44号）收悉。经研究，我局批复如下：

一、原则同意所报武当山建筑群太常观修缮项目和你局意见。

二、具体修改意见如下：

（一）进一步细化现状勘测。补充对木材材种、砖瓦规格、屋面构造、墙面抹灰、砖墙砌筑、油饰等材料、做法的记录分析；应对水泥地面下的原地面做法进行局部揭露勘察；明确建筑台基开裂、柱础下沉的具体位置；补充墙体局部倾斜的量化数据及其稳定性评估；应核实木构件糟朽蛀蚀是否与前次修缮时含水率不达标有关。

（二）补充完善部分修缮设计。进一步论证建筑山面加大悬山长度的合理性，如无明确依据，应维持现状，并核实图纸标注、补充构造详图；核实院落排水设计，尤其是排水坡度设定，并补充墙体排水口的位置、高度和做法；补充应对墙体下碱潮气问题的措施。

（三）坚持最小干预原则，严格控制工程量和工程范围，对不影响结构安全、排水和使用的风化碎裂的砖石构件，不得整体揭墁、更换；结合墙体稳定性评估，论证局部拆砌做法的必要性，尽可能减少拆砌范围，可考虑采用整体纠偏做法；进一步论证使用红鸡翅木替换部分大木构件及使用松木替换椽望、装修的依据和必要性，如能采取有效的防潮防腐措施，不应替换材种。

（四）进一步细化完善部分工程措施。明确灌浆的具体对象和工程做法，补充相应标注；明确被水泥抹面覆盖的墙体、地面的修缮措施；明确油饰涂料的选材依据，应沿用传统材料和工艺；应做好木材含水率控制。

（五）规范完善图纸。补充总平面图尺寸标注；补充剖面图出檐尺寸；现状勘测和修缮设计图纸中的木构件残损应尽可能明确具体部位和数量；补充砖石材料规格尺寸及构造做法标注及相应详图。

（六）进一步明确后续使用功能，并与修缮工程做好衔接，避免二次施工对文物本体造成不必要的破坏。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局核准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、请你局督促、指导相关单位结合本次维修明确加建的东西配殿耳房整改处理措施，同时做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

七、请你局指导当地人民政府和文物部门，梳理、评估武当山近年来的文物保护修缮项目，在此基础上，根据相关规划和文物残损实际情况，拟定未来五年的文物保护修缮项目计划并上报我局，以指导后续工作的有序开展。

此复。

国家文物局
