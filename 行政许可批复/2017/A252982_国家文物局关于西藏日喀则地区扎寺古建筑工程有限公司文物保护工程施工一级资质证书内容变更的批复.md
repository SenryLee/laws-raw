# 国家文物局关于西藏日喀则地区扎寺古建筑工程有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于西藏日喀则地区扎寺古建筑工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕843号

西藏自治区文物局：

你局《关于申请变更文物保护工程施工单位名称和法人的请示》（藏文物字〔2017〕279号）收悉。

经研究，我局同意西藏日喀则地区扎寺古建筑工程有限公司文物保护工程施工一级资质证书中的单位名称由“西藏日喀则地区扎寺古建筑工程有限公司”变更为“西藏日喀则扎寺古建筑工程有限公司”，法定代表人由“索朗”变更为“旺久”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局

2017年7月17日
