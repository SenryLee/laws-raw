# 中国证监会关于核准中欧基金管理有限公司变更股权的批复

## 关于核准中欧基金管理有限公司变更股权的批复

证监许可〔2017〕1253号

中欧基金管理有限公司：

你公司报送的《中欧基金管理有限公司关于股权变更的申请报告》（中欧司字〔2017〕第219号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

一、核准意大利意联银行股份合作公司（Unione di Banche Italiane S.p.A.）将其持有的你公司10%股权转让给窦玉明、于洁、赵国英、卢纯青、方伊、关子阳、卞玺云、魏博、郑苏丹、曲径、黎忆海等11人，万盛基业投资有限责任公司将其持有的你公司1.7%股权转让给周玉雄、卢纯青等2人。转让完成后，你公司股权结构为：
