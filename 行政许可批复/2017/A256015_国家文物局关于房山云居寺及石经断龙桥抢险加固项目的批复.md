# 国家文物局关于房山云居寺及石经断龙桥抢险加固项目的批复

文物保函〔2017〕1649号

北京市文物局：

你局《关于房山云居寺断龙桥抢险加固工程补充设计方案的请示》（京文物〔2017〕702号）收悉。经研究，我局批复如下：

一、原则同意房山云居寺塔及石经——断龙桥抢险加固项目和你局意见。

二、对该项目提出以下修改完善意见：

（一）应遵循“不改变文物原状”等文物保护原则，进一步深化现状勘察和研究，明确断龙桥原桥梁形制、建筑材料、建造工艺和构造特征等。

（二）应坚持最小干预原则，进一步细化工程做法和技术要求。

1．应明确桥梁荷载标准，清除后期增加构筑物，降低桥面荷载。不同意按照长期运营标准评估桥承载能力，应逐步降低其承担的交通运营需求。

2．补充说明两个重砌桥墩新配石材种类、砌筑灰浆强度要求和配比等。

3．明确桥基具体加固部位，应只在薄弱部位或薄弱点进行打桩加固措施，不宜成片打桩。

4．进一步论证桥面上铺灰土垫层和沥青路面等做法的科学性，评估其影响，应在尽可能降低桥面荷载的基础上采取可逆的、切实有效的桥面保护措施。

5．不同意将河床条石海墁与桥基连为一体等改变文物原状的做法。

6．补充桥栏板样式设计依据，不同意没有历史依据的盲目复原。

（三）进一步规范图纸。补充桥基加固节点详图。

（四）建议结合文物保护规划编制，调整保持该桥现状维持市政交通功能的设计思想，研究交通改线的可行性，明确限定性的减负技术措施，以利于古桥长远保护。

三、具体方案由你局根据上述意见指导相关单位修改、完善并经你局核准后实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年9月14日
