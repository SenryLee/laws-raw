# 国家文物局关于在河南省文物保护单位具茨山岩画保护范围内进行森源禹州梨园沟120兆瓦光伏发电项目选址的批复

## 关于在河南省文物保护单位具茨山岩画保护范围内进行森源禹州梨园沟120兆瓦光伏发电项目选址的批复

文物保函〔2017〕1150号

河南省文物局：

你局《关于再次报批森源禹州梨园沟120兆瓦光伏发电项目选址方案的请示》（豫文物〔2017〕187号）收悉。经研究，我局批复如下：

一、原则同意在河南省文物保护单位具茨山岩画保护范围内进行森源禹州梨园沟120兆瓦光伏发电项目选址和你局意见。

二、对所报方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》和河南省人民政府关于具茨山岩画保护范围的相关管理规定，合理确定项目选址，严格控制工程范围和工程量，进一步压减铺设在保护范围内的光伏太阳能板数量，尽量减少对文物本体安全和景观风貌的影响。

（二）进一步完善方案设计，光伏板选址应尽量远离岩画，同时，应进一步优化外观设计，可采用分散布置、降低高度、简化固定形式、植被遮挡等方式，尽量减小景观影响。

（三）应充分考虑工程建设对文物的影响，制定必要的文物保护措施和应急预案。

三、请你局根据上述意见，组织相关单位对所报方案进行修改、完善，并经你局核准后按程序报有关部门批准实施。请加强对工程的监管，督促相关单位在项目实施中做好局部场地恢复工作。施工过程中如发现岩画，应及时调整方案设计，确保文物及其环境安全。

四、请你局督促地方人民政府请按照我局文物保函〔2014〕2734号文件要求，尽快组织编制具茨山岩画保护规划，根据遗存分布情况加强保护，进一步明确具茨山岩画的保护管理原则和措施，合理确定保护范围、建设控制地带和相关管理规定，同时整体考虑、统筹安排该区域的风、热资源利用问题，妥善处理文物保护与地方经济社会发展之间的关系。

此复。

国家文物局

2017年7月3日
