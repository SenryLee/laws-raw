# 农业部关于青海省青海凯峰农业科技股份有限公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕45号

青海省农牧厅：

《青海省农牧厅关于青海省互助县国家现代农业示范区设施园艺数字农业建设项目立项的请示》（青农发〔2017〕53号）收悉。经研究，批复如下：

一、原则同意上报的青海互助县国家现代农业示范区数字农业建设项目可行性研究报告。项目建设单位为青海凯峰农业科技股份有限公司，建设地点为青海省海东市互助县。项目建设期2年。

二、项目建设内容：一是环境监测控制系统建设，包括室外气象信息采集系统、温室环境监测调控系统、作物健康状况监测系统、果实品质监测系统等；二是工厂化育苗系统建设，包括智能催芽系统、嫁接机器人、育苗生产管理系统等；三是生产过程管理系统建设，包括生产管理及数据获取分析系统、设施环境机械、水肥药综合管理系统、专家远程服务系统等；四是产品质量安全监控系统建设，包括生产过程质量管理系统、质量追溯系统、设施病虫害监测预警系统等；五是采后商品化处理系统建设，包括自动化清洗、分级、包装、扫码、信息采集设备等。

三、项目建设目标：项目建成后，将推动青海省高冷地区数字农业技术广泛应用，项目区节省人工及化肥、农药、灌溉用水均在20%以上，采后商品化处理与贮藏保鲜减少损耗30%，亩均纯收入增加15%。

四、项目投资及来源：经评估核定，项目估算总投资2832万元，其中中央预算内投资按850万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你省申报后续数字农业建设试点项目的资格。
