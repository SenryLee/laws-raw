# 国家文物局关于湖北上津古城城墙、襄阳城墙、南漳山寨群及关陵抢险加固项目的批复

文物保函〔2017〕1954号

湖北省文物局：

你局《关于上津古城城墙受雨灾局部墙体坍塌有关情况的报告》（鄂文物文〔2017〕62号）和《关于部分全国重点文物保护单位因雨灾遭受险情有关情况的报告》（鄂文物文〔2017〕67号）收悉。经研究，我局批复如下：

一、同意开展上津古城城墙、襄阳城墙、南漳山寨群及关陵抢险加固项目。

二、项目范围限于所报险情部位。

三、请你局督促、指导相关单位，妥善做好临时支护工作，并对所报全国重点文物保护单位的灾情进行详细勘察，全面排查其险情隐患。在此基础上，根据《文物保护工程设计文件编制深度要求（试行）》、《关于进一步优化文物保护项目审批的通知（文物保发〔2016〕25号）》等的有关规定，针对上述4个项目的各类病害问题，分别编制抢险加固技术方案，由你局组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

四、在编制技术方案时，应督促编制单位重点做好对隐蔽部位的补充勘察，制订有针对性的修缮措施，并按照“最小干预”等文物保护原则，尽可能多地保留加固原有构件，避免过度干预。

五、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

六、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

七、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

八、请你局督促地方人民政府切实加强相关全国重点文物保护单位的日常保养和岁修工作，树立预防性保护理念，开展必要的专项技术监测和相应的防灾减灾工作，确保工程质量和文物安全。

专此函复。

国家文物局

2017年12月7日
