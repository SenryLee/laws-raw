# 国家文物局关于南昌紫金城址与铁河古墓群2017-2018年度考古调查计划的批复

## 关于南昌紫金城址与铁河古墓群2017-2018年度考古调查计划的批复

文物保函〔2017〕864号

江西省文物局：

你局《关于呈报〈江西南昌紫金城城址与铁河古墓群考古调查与勘探项目工作方案（2017年-2018年）〉的请示》（赣文物局字〔2017〕34号）收悉。经研究，我局批复如下：

一、原则同意所报南昌紫金城城址与铁河古墓群2017-2018年度考古调查工作计划和你局意见。

二、该方案应进行以下补充、完善：

（一）对紫金城城址与铁河古墓群考古调查进行总体和系统规划，进一步突出工作重点，明确实施步骤，紫金城城址首先应弄清小城范围内的遗迹及性状，铁河古墓群则应先探明历代海昏侯主墓及墓园遗迹。

（二）充分了解南方水网区域遗迹的分布特点，注意搞清地形、地貌及自然水系、人工水系与遗迹的关系。

（三）进一步补充、完善相关规划图纸等基础材料，完善考古地理信息系统建设，为长期开展工作奠定基础。考古工作结束后，应积极利用工作成果，为总体保护规划编制和保护工作提供科学依据。

三、请你局指导有关单位，根据以上意见对南昌紫金城城址与铁河古墓群2017-2018年度考古工作方案进行补充、完善，经你局核准后实施。请你局加强管理，确保工作质量和工地安全，遇有重要发现，应及时向我局报告。考古工作结束后，应向我局报告本年度工作情况。

国家文物局

2017年4月26日
