# 国家文物局关于俄界会议旧址、会宁红军会师旧址和南梁陕甘边区革命政府旧址保护规划的批复

## 关于俄界会议旧址、会宁红军会师旧址和南梁陕甘边区革命政府旧址保护规划的批复

文物保函〔2016〕2154号

甘肃省文物局：

你局《关于呈报俄界会议旧址保护规划的报告》（甘文局发〔2015〕324号）、《关于呈报修改后会宁红军会师旧址文物保护规划的报告》（甘文局发〔2016〕13号）、《关于呈报南梁陕甘边区革命政府旧址文物保护规划的报告》（甘文局发〔2015〕212号）收悉。经研究，我局批复如下：

一、原则同意所报俄界会议旧址、会宁红军会师旧址和南梁陕甘边区革命政府旧址保护规划。

二、对规划提出以下修改意见：

（一）关于俄界会议旧址保护规划，应进一步修改完善规划文本表达，校核规划图纸。

（二）关于会宁红军会师旧址保护规划

1．进一步明确西岩山、祖厉河与会师旧址的空间格局关系。补充祖厉河等红军行进路径重要历史环境的价值评估。

2．将祖厉河划入一类建设控制地带，取消三类建设控制地带。

3．细化建设控制地带的管理规定，补充新建建筑体量、色彩、建筑形制等方面的控制要求。二类建设控制地带内新建建筑的控制高度应适当降低。

4．增加保护措施的针对性，删除保护措施中文物建筑遗址复原内容。

5．补充防灾减灾专项规划。对城门前广场积水问题，应提出解决措施。

6．补充该规划与会宁城乡总体规划等相关规划的衔接内容。

7．进一步修改精简规划文本，补充完善规划图纸。

（三）关于南梁陕甘边区革命政府旧址保护规划

1．补充对旧址历次修缮情况评估，深化环境影响评估。

2．进一步明确建设控制地带的控制要求，应保护历史环境的真实性，避免相关规划措施对历史环境造成较大改变。如，平整场地、乡路，由土路变为水泥铺装等措施应慎重实施。

3．加强评估与措施的对应关系，增加保护措施的针对性。

4．展示分区应具有可操作性，注意突出重点。

5．补充该规划与村镇发展规划等相关规划的衔接内容。

6．进一步修改精简规划文本，补充完善规划图纸，注意图文的对应。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将经我局备案的俄界会议旧址、会宁红军会师旧址和南梁陕甘边区革命政府旧址保护规划报请甘肃省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城乡总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

此复。

国家文物局

2017年1月4日
