# 国家文物局关于久安背翰林祠保护规划的批复

## 关于久安背翰林祠保护规划的批复

文物保函〔2017〕169号

湖南省文物局：

你局《关于审批〈久安背翰林祠保护规划（修改）〉的请示》（湘文物报〔2016〕148号）收悉。经研究，我局批复如下：

一、原则同意所报久安背翰林祠保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

1．加强历史研究，完善价值评估，明确久安背翰林祠选址与周边山形水系、村落格局之间的关系。

2．深化现状评估，进一步分析久安背翰林祠与周边自然环境之间的景观视廊，客观评估现行保护区划与管理规定执行情况、已实施保护工程效果、安消防设施和服务设施使用情况等内容。

（二）关于保护区划与管理规定

应根据文物分布、景观格局特点和保护管理需要，结合地形地貌特征，科学确定保护区划，调整建设控制地带的西北边界，避免切割现有建筑；明确建设控制地带内的建筑高度、规模、体量和外观等具体控制指标；补充保护区划调整依据。

（三）关于保护措施

应针对现状评估结论，研提文物保护措施，明确保护工程的类别、内容和要求。

（四）关于环境整治和专项规划

1．应明确环境整治目标、范围和措施要求，区分文物环境、周边建筑和景观风貌的不同整治措施。

2．结合当地村民的文化生活需要，进一步细化久安背翰林祠展示利用定位，科学研提文物利用方式、内容、措施；同时，应合理确定功能分区，慎重考虑展示区域内现有居民拆迁的必要性，注重保持街巷肌理和文物与村庄的历史、空间关系。

3．深化管理规划，明确管理机构职责、文物日常使用和管理要求；补充祭祀活动的管理措施。

（五）补充所报规划与《九嶷山国家森林公园总体规划》的衔接内容。

（六）进一步规范文本和图纸，说明性内容应纳入规划说明，注意引用法规文件的时效性；调整保护区划图图纸表达方式，完善规划总图，补充规划范围地形图。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的久安背翰林祠保护规划报请湖南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体立项报告或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好久安背翰林祠的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

此复。

国家文物局

2017年2月7日
