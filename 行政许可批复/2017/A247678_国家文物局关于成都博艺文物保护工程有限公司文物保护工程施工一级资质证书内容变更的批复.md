# 国家文物局关于成都博艺文物保护工程有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于成都博艺文物保护工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕76号

四川省文物局：

你局《关于变更成都博艺文物保护工程有限公司文物保护工程资质证书的请示》（川文物〔2016〕144号）收悉。

经研究，我局同意成都博艺文物保护工程有限公司文物保护工程施工一级资质证书中的注册资金由“700万元”变更为“2000万元”。请你局通知申请单位，携带资质证书副本到我局办理相关手续。

国家文物局

2017年2月6日
