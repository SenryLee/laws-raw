# 国家文物局关于何园桂花厅修缮项目的批复

文物保函〔2017〕1483号

江苏省文物局：

你局《关于审批何园桂花厅抢修工程设计方案的请示》（苏文物保〔2017〕223号）收悉。经研究，我局批复如下：

一、原则同意所报何园桂花厅修缮项目和你局意见。

二、对该项目提出以下修改意见：

（一）应加强现状勘察和研究，明确文物建筑原有形制、材料、工艺和做法等，补充后墙外倾具体数据和拆砌范围，合理制定修缮措施。

（二）应坚持最小干预原则，准确界定工程性质，严格控制工程范围和强度，细化工程做法和技术要求。

1. 明确柱子墩接的工艺做法与技术要求；补充榫卯节点纠偏后的加固措施和屋脊在纠偏屋架时的保护措施。

2. 进一步论证在木板壁与后墙之间增加墙体的科学性和可行性，研提其它可选措施。

3. 进一步论证对开裂墙体进行锚杆加固措施的可操作性，补充具体的技术要求。

4. 不同意屋面采用水泥砂浆找平层和钢丝网屋面的做法。

（三）进一步校核文本与图纸，补充柱子拨正措施的具体施工方法示意图。

（四）补充必要的施工要求和临时性保护措施，确保施工过程中人员和文物安全。同时注意保护周边环境。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善并经你局批准后组织实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

国家文物局

2017年8月21日
