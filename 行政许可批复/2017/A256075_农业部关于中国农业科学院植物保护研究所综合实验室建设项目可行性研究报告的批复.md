# 农业部关于中国农业科学院植物保护研究所综合实验室建设项目可行性研究报告的批复

农计发〔2017〕107号

中国农业科学院：

《中国农业科学院关于报送植物保护研究所综合实验室建设项目可行性研究报告的请示》（农科院基建〔2017〕178号）收悉。经研究，批复如下。

原则同意你院植物保护研究所综合实验室建设项目。项目建设地点位于北京市圆明园西路2号，占地面积1267平方米，框架结构，主要建设内容为新建综合实验室6448平方米，配套建设给排水、消防、道路、热力、电力等室外工程。总投资2790万元，其中建筑安装工程费2313万元，工程建设其他费用350万元，预备费127万元。全部为中央预算内投资。项目建设期为3年，自投资计划下达之日起计算。

请据此批复，抓紧委托有资质的勘察设计单位编制项目初步设计和概算，经你院审核后报部审批。初步设计和概算编制要严格执行《关于党政机关停止新建楼堂馆所和清理办公用房的通知》（中办发〔2013〕17号）要求，不得将楼堂馆所等纳入项目建设内容。要按照招投标事项核准表要求，做好有关招投标工作。请切实履行好项目监管责任，督促项目建设单位严格按照农业基本建设项目管理规定，做好项目组织实施工作，并在农业建设项目管理信息系统（http://ac.agri.gov.cn）上，填报项目初步设计和建设进度等信息。

附件：中国农业科学院植物保护研究所综合实验室建设项目招标投标事项核准表

农业部

2017年9月3日
