# 国家文物局关于在秦安文庙保护范围内进行环境整治工程的批复

## 关于在秦安文庙保护范围内进行环境整治工程的批复

文物保函〔2017〕475号

甘肃省文物局：

你局《关于开展秦安文庙保护设施建设项目的请示》（甘文局发〔2017〕16号）收悉。经研究，我局批复如下：

一、原则同意秦安文庙环境整治工程和你局意见。

二、对所报方案提出如下修改完善意见：

（一）该工程位于全国重点文物保护单位秦安文庙保护范围内，应严格遵守《中华人民共和国文物保护法》和甘肃省人民政府关于秦安文庙保护范围的相关管理规定，严格控制工程范围和工程强度，合理改善文物周边环境。

（二）应加强历史研究，全面搜集文献和影像资料，分析、确定秦安文庙的历史格局和院落风貌，进一步明确地面铺装、围墙、大门的样式、材质，为科学确定环境整治措施提供依据。其中，大门样式和材质应根据文庙历史风貌特点和建筑规制要求，研提多种比选方案并组织专家论证，确保新建大门与文物建筑风貌和文化价值相符；场地铺装范围应做进一步调整，避免大面积硬化，同时核实铺装的砖石材质，采用传统青砖样式及工艺做法，不宜使用渗水砖铺砌文物建筑周边区域。

（三）绿化种植应突出庄严肃穆的历史氛围，尽量选用当地植物品种，避免景观园林化设计倾向。应充分考虑植被生长和日常养护对文物建筑安全的影响，保持必要的安全距离。

（四）进一步明确地下管网工程开挖与恢复的具体工程措施和要求，严格避让建筑基础。照明系统应统筹考虑文物管理与防火安全问题，细化照明设施安装位置、线路布设、安装措施和要求，确保电气设计符合国家相关法律法规和标准规范。

（五）应进一步深化文物影响评估报告内容，准确、客观地评估工程建设对文物本体及环境的影响，避免简单套用方案设计内容。

三、请你局根据上述意见，组织相关单位对所报方案进行修改、完善，并经你局核准后实施。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。请加强对工程的监管，确保文物及其环境安全。

此复。

国家文物局

2017年3月14日
