# 农业部办公厅关于中国热带农业科学院热带作物品种资源研究所国家热带牧草中期备份库建设项目初步设计和概算的批复

农办计〔2017〕64号

中国热带农业科学院:

《中国热带农业科学院关于报送中国热带农业科学院热带作物品种资源研究所国家热带牧草中期备份库建设项目初步设计与概算的请示》（热科院计〔2017〕208号）收悉。经研究，批复如下。

原则同意该项目初步设计。主要建设内容包括新建中期种子备份库1328.2平方米（含低温低湿系统），道路与场地硬化770平方米，配套照明、给排水、消防等室外工程；购置仪器设备16台（套/批）。核定概算总投资966万元，其中建筑安装工程费586.34万元，仪器设备购置费259.3万元，工程建设其他费用83.87万元，预备费36.49万元。资金来源全部为中央预算内投资（详见附件）。

请据此批复，按照农业基本建设项目管理规定，抓紧组织项目实施工作。要按照相关招标投标管理规定，认真做好招标投标工作。每月28日前通过农业建设项目管理信息系统（http://ac.agri.gov.cn）和国家重大建设项目库（http://kpp.ndrc.gov.cn），填报截至当月的项目进度、资金支出等相关信息。同时，按照《农业部办公厅关于完善建设项目管理信息系统数据 强化按月调度和定期总结工作的通知》（农办计〔2015〕48号）要求，分别于每年1月3日和7月3日前，报送项目全年和半年总结，包括投资安排及到位情况、项目实施进展情况、监管措施、项目效益、存在的困难和问题、有关建议等内容。项目建成后，项目建设单位要及时开展竣工验收工作，同时要按照本单位的仪器设备开放方案，向社会开放，进一步提高仪器设备利用效率。

附件：1.中国热带农业科学院热带作物品种资源研究所国家热带牧草中期备份库建设项目概算核定表

2.中国热带农业科学院热带作物品种资源研究所国家热带牧中期备份库建设项目仪器设备核定表
