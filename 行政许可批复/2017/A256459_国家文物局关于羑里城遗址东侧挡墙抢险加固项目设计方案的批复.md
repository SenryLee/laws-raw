# 国家文物局关于羑里城遗址东侧挡墙抢险加固项目设计方案的批复

文物保函〔2017〕1718号

河南省文物局：

你局《关于汤阴县羑里城遗址抢险加固设计方案的请示》（豫文物〔2017〕280号）收悉。经研究，我局意见如下：

一、原则同意羑里城遗址东侧挡墙抢险加固设计方案。暂不同意山门、二殿本体维修设计方案。

二、羑里城遗址东侧挡墙抢险加固设计方案应严格控制项目范围和工程量，补充必要的地勘资料，科学分析病害产生的原因；同时，进一步核算挡墙结构稳定性，明确挡墙地基处理做法，制订合理可行的保护措施，确保文物安全。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善后实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好维修后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

八、山门、二殿维修项目应进一步明确工程性质和实施的必要性，根据我局《关于进一步优化文物保护项目审批的通知》（文物保发〔2016〕25号）要求另行报批。

国家文物局

2017年10月9日
