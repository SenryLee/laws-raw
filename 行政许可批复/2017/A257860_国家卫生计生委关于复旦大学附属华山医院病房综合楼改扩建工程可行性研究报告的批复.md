# 国家卫生计生委关于复旦大学附属华山医院病房综合楼改扩建工程可行性研究报告的批复

国卫规划函〔2017〕429号

复旦大学附属华山医院：

你院《关于报请审批病房综合楼改扩建工程可行性研究报告的请示》（华办字〔2017〕52号）收悉。经研究，批复如下：

一、为改善医院医疗服务条件，满足发展需要，原则同意你院所报病房综合楼改扩建工程可行性研究报告。

二、工程建设地点位于上海市静安区乌鲁木齐中路12号复旦大学附属华山医院院内，6号楼西侧。

三、主要建设内容为住院、医技、教学及相关配套用房。工程总建筑面积31,209平方米，其中，地上建筑面积25,043平方米，地下建筑面积6,166平方米。

四、工程估算总投资38,225万元，资金来源为申请中央预算内投资和上海市市级建设财力以及医院自筹资金共同解决。

五、按照国家有关规定和项目建设单位指定，确定丁强同志为复旦大学附属华山医院病房综合楼改扩建工程责任人。

六、请根据工程招标投标事项核准意见（附表），按照《中华人民共和国招标投标法》，认真做好项目建设的招投标工作。

七、请你院认真执行基本建设程序，本着控制建设标准、节约国家投资的原则，严格按照批复的建设内容和面积、初步估算等，抓紧组织编制该工程初步设计和投资概算，报我委审批。

此复。

国家卫生计生委

2017年11月9日
