# 农业部关于浙江省舟山市定海华晟牧场有限公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕54号

浙江省农业厅：

《浙江省农业厅关于报送2017年数字农业建设试点项目可行性研究报告的函》（浙农函〔2017〕7号）、《浙江省农业厅关于要求变更生猪养殖数字农业建设试点项目建设单位名称的函》收悉。经研究，批复如下：

一、原则同意上报的浙江省舟山市定海华晟牧场数字农业建设试点项目可行性研究报告。项目建设单位为舟山市定海华晟牧场有限公司，建设地点为浙江省舟山市定海区。项目建设期2年。

二、项目建设内容：一是自动化精准环境控制系统建设，包括智能环境控制系统、场区监视系统和废气处理系统等；二是数字化精准饲喂管理系统建设，包括自动化喂水系统、自动化喂料系统等；三是无害化粪污处理系统建设，包括粪污收集设施、自动刮粪设施、污水处理系统等。

三、项目建设目标：项目建成后，实现生猪养殖智能化、经营信息化、管理数据化和服务在线化，打造零污染的绿色生产模式，项目区实现存栏基础母猪2500头，年出栏5万头生猪以上。

四、项目投资及来源：经评估核定，项目估算总投资3484万元，其中中央预算内投资按1045万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你省申报后续数字农业建设试点项目的资格。

农业部
