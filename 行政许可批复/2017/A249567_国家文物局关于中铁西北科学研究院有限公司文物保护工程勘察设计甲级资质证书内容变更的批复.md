# 国家文物局关于中铁西北科学研究院有限公司文物保护工程勘察设计甲级资质证书内容变更的批复

## 关于中铁西北科学研究院有限公司文物保护工程勘察设计甲级资质证书内容变更的批复

办保函〔2017〕405号

甘肃省文物局：

你局《关于变更中铁西北科学研究院有限公司资质证书相关信息的请示》（甘文局发〔2017〕60号）收悉。

经研究，我局同意中铁西北科学研究院有限公司文物保护工程勘察设计甲级资质证书中的法定代表人由“郑静”变更为“方建生”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局

2017年4月11日
