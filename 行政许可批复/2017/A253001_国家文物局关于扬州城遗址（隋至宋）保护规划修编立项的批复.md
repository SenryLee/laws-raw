# 国家文物局关于扬州城遗址（隋至宋）保护规划修编立项的批复

## 关于扬州城遗址（隋至宋）保护规划修编立项的批复

文物保函〔2017〕777号

江苏省文物局：

你局《关于扬州城遗址（隋至宋）保护规划修编立项的请示》（苏文物保〔2017〕40号）收悉。经研究，我局批复如下：

一、原则同意扬州城遗址保护规划修编立项。

二、在规划修编过程中应注意以下问题：

（一）应加强对原保护规划的评估，科学分析原保护规划的实施情况、效果和存在的主要问题，并针对原规划中确实不适应实际情况的部分进行调整和完善。原保护规划所提出的基本原则和整体策略若无重大缺陷，应予以继续坚持。

（二）应根据最新考古成果确定的遗存分布特点和保护管理需要，科学确定规划范围和划定保护区划，制定相应的管理规定和控制指标，注意增强区划措施的合理性和可操作性，不宜过于复杂。

（三）应在规划中明确扬州城遗址的定位，并对遗址的后续展示利用提出明确的指导意见，合理确定展示框架、展示内容以及重要展示节点，相关展示方式应注意可操作性和实效性。

（四）应注意与城乡规划、土地利用规划等相关规划的衔接，在确保文物安全的前提下协调处理好遗址保护与当地居民的生产生活、城乡建设及旅游开发之间的关系。

（五）进一步校核规划修编预算，建议根据遗址所处的区位情况，合理确定难度系数，严格控制预算。

三、请你局指导当地人民政府，组织具有资质的规划编制单位联合专业考古研究机构，根据上述意见，并按照《国务院关于进一步加强文物工作的指导意见》、《全国重点文物保护单位保护规划编制审批办法》和《全国重点文物保护单位保护规划编制要求》的有关规定，做好扬州城遗址保护规划的修编工作。

四、规划修编完成并经你局初审同意后，请将规划文本、图纸（一式两份）及相应的电子文档等报我局审批。

五、请你局指导地方人民政府做好扬州城遗址的保护工作，加强专门管理机构建设，加强日常巡查和监测，确保文物安全。

国家文物局

2017年4月17日
