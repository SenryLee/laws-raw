# 国家发展改革委关于新建湖南郴州民用机场项目可行性研究报告的批复

发改基础〔2017〕1888号

湖南省发展改革委：

你委《关于恳请审批〈湖南郴州民用机场可行性研究报告〉的请示》（湘发改﹝2017﹞246号）及有关材料均悉。经研究，现批复如下。

一、为完善区域综合交通运输体系，改善当地对外交通条件，满足航空运输发展需求，提升应急救援保障能力，促进区域经济社会协调发展，同意新建郴州民用机场。

二、本期工程按满足2025年旅客吞吐量55万人次、货邮吞吐量3000吨的目标设计，飞行区等级指标4C。主要建设内容包括：建设1条长2600米、宽45米的跑道，双向设置I类精密进近系统；建设6000平方米的航站楼及6个机位的站坪；配套建设空管、消防救援、供电、供油等设施。

三、项目总投资19.56亿元，其中我委安排中央预算内投资3.5亿元，民航局安排民航发展基金6.9亿元，你省安排省级基本建设投资专项资金0.5亿元、财政预算资金0.5亿元，其余投资由郴州市人民政府安排财政性资金解决。

四、郴州市交通建设投资有限责任公司作为项目法人，负责项目的组织实施与管理。

五、本项目勘察、设计、施工、监理和重要设备材料采购等均采用公开招标，招标组织形式为委托招标。

六、在后续阶段，重点做好以下工作：

（一）进一步优化工程设计方案，减少土石方工程量，节约工程投资。

（二）尽快开展机场总体规划编制工作，加强机场及周边地区的规划控制，保护好机场净空和电磁环境。

（三）落实高压线路拆改方案，同步建设场外道路等配套设施，确保机场建成后安全正常运营。

（四）统筹通用航空发展需要，研究在机场增设通用航空设施，拓展业务范围，兼顾区域通用航空运营服务综合保障。

（五）请督促有关单位切实落实各项风险防范化解措施，制定有效的应急处置预案，保障机场顺利实施。

国家发展改革委
