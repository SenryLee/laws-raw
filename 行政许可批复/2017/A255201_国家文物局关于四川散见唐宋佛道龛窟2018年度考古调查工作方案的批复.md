# 国家文物局关于四川散见唐宋佛道龛窟2018年度考古调查工作方案的批复

文物保函〔2017〕1604号

四川省文物局：

你局《关于〈四川散见唐宋佛道龛窟及古代石刻文字考古调查工作方案（2017—2021年度）〉的请示》（川文物〔2017〕43号）收悉。经研究，我局批复如下：

一、原则同意所报四川散见唐宋佛道龛窟2018年度考古调查工作方案。

二、该方案应进行以下补充、完善：

（一）四川唐宋佛教龛窟数量众多，保护管理情况复杂，应在第三次全国文物普查工作成果的基础上，进一步梳理拟工作区域内唐宋佛道龛窟的分布范围、位置、数量等，在此基础上做好调查及后续资料整理工作。

（二）应细化工作方案，以广元、巴中、资阳、南充四市的龛窟遗迹为主，重点调查、记录龛窟的类型、题材、时代、数量、保存现状等，并结合文献资料分析、确定龛窟的价值内涵和文化特征，研提下一阶段文物保护建议。

（三）应加强人员队伍组织，积极吸纳历史、宗教、地理、测绘等方面专家和科研机构，强化多学科合作研究，并注意采用现代科技手段，提高工作效率。

（四）应明确调查资料整理和成果出版计划，并注意做好相关测绘资料的保管、使用，确保资料安全。

（五）暂不同意古代石刻文字考古调查项目。

三、请你局指导有关单位，根据以上意见，完善四川散见唐宋佛道龛窟2018年度考古调查工作方案，报你局核准后实施。请你局加强管理，确保工作质量和工地安全，遇有重要发现，应及时向我局报告。考古工作结束后，应向我局提交年度工作情况报告，并研提下一阶段工作思路。

国家文物局

2017年9月5日
