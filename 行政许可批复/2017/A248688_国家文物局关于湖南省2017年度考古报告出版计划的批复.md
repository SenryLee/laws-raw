# 国家文物局关于湖南省2017年度考古报告出版计划的批复

## 关于湖南省2017年度考古报告出版计划的批复

文物保函〔2017〕498号

湖南省文物局：

你局《关于审批益阳罗家嘴楚汉墓葬出版立项的请示》（湘文物报〔2017〕25号）、《关于审批益阳黄泥湖楚墓出版立项的请示》（湘文物报〔2017〕26号）和《关于审批岳阳唐宋墓出版立项的请示》（湘文物报〔2017〕27号）收悉。经研究，我局同意所报《益阳罗家嘴楚汉墓葬》、《益阳黄泥湖楚墓》和《岳阳唐宋墓》3部考古发掘报告出版计划。

请按照《国家重点文物保护专项补助资金管理办法》的规定和我局有关要求，另行申请该考古报告的出版补助经费。

国家文物局

2017年3月16日
