# 国家卫生计生委关于西安交通大学医学院第一附属医院肿瘤病房综合楼工程初步设计和投资概算的批复

国卫规划函〔2017〕405号

西安交通大学医学院第一附属医院：

你院《关于报请审批肿瘤病房综合楼工程初步设计和投资概算的请示》（西交一院〔2017〕127号）收悉。经研究，原则同意你院肿瘤病房综合楼工程初步设计和投资概算，并按照国家有关规定和建设单位指定，确定施秉银同志为该工程责任人。该工程总建筑面积54,646平方米，其中，地上建筑面积30,881平方米，地下建筑面积23,765平方米。工程概算总投资38,481万元。资金来源为申请中央预算内投资和医院自筹资金共同解决。

请你院按照国家有关规定，严格执行基本建设程序，落实项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计和投资概算，抓紧组织开展下一步工作。

此复。

国家卫生计生委

2017年10月26日
