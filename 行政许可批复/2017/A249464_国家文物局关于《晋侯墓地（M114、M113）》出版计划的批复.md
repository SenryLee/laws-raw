# 国家文物局关于《晋侯墓地（M114、M113）》出版计划的批复

## 关于《晋侯墓地（M114、M113）》出版计划的批复

文物保函〔2017〕585号

山西省文物局：

你局《关于审批晋侯墓地（M114、M113）出版计划的请示》（晋文物〔2017〕97号）收悉。经研究，我局同意所报《晋侯墓地（M114、M113）》考古报告出版计划。

请按照《国家重点文物保护专项补助资金管理办法》的规定和我局有关要求，另行申请该考古报告的出版补助经费。

国家文物局

2017年3月28日
