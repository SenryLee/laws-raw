# 国家文物局关于药王山通元桥抢险加固工程的批复

文物保函〔2017〕2054号

陕西省文物局：

你局《关于上报药王山通元桥抢险加固工程设计方案的请示》（陕文物字〔2017〕236号）收悉。经研究，我局批复如下：

一、原则同意药王山通元桥抢险加固工程和你局意见。

二、具体修改意见如下：

（一）应结合桥体两端山体情况，进一步复核桥面重新设计的排水走向、排水端部出水位置，以及新增桥面排水沟的可行性与合理性。补充完善桥面工程设计图，明确桥面铺装材质及规格要求。

（二）应根据坍塌深度，采取补砌与锚固相结合的方式进行修补，以减少锚固深度及对原夯土的扰动深度，明确修补桥立面起始部位及现有夯土交接部位的技术处理要求。锚固前应做充分的拉拔试验，确保锚固牢固性。修补补砌部分可用特制规格的土坯砖，外观应随夯土作视觉处理。

（四）应结合顶部夯土与桥面砖砌构造的稳固联系，进一步明确桥面与夯土交接部位的做法，合理完善方案，统一图纸表达。

（五）应预估修缮后桥体使用情况，并测算桥面所受承载力，进一步确认桥面做法的合理性。

（六）应增加外露夯土表面的防风化和防渗处理。

（七）应进一步复核设计文本，确保文字和图纸的对应性和准确性。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

国家文物局

2017年12月26日
