# 国家文物局关于西蒋村马氏庄园保护规划的批复

## 关于西蒋村马氏庄园保护规划的批复

文物保函〔2017〕175号

河南省文物局：

你局《关于西蒋村马氏庄园保护规划的请示》（豫文物〔2016〕105号）收悉。经研究，我局批复如下：

一、原则同意所报西蒋村马氏庄园保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和评估

1．应加强历史研究，明确文物选址要素，进一步梳理保护对象，科学认定文物本体和附属文物。

2．梳理价值评估，厘清不同价值的层次关系，进一步提炼历史价值和艺术价值，补充评估马氏庄园在中国解放战争历史中的价值和地位。

3．进一步完善现状评估，补充现有保护区划执行、展示利用现状、旅游发展和周边区域建设情况等评估内容。

（二）关于保护区划与管理规定

应根据文物分布情况和保护管理需要，结合地形地貌和现有建构筑物合理划定保护范围与建设控制地带的具体边界，增强可操作性。建设控制地带南侧边界不宜切割现有建筑，并研提具体建筑高度、密度、体量、外观等控制要求。

（三）关于保护措施

应按照《文物保护工程管理办法》确定工程性质，进一步梳理、完善保护措施，合理进行工程分类，严格控制工程量和强度，避免过度维修。环境整治措施应纳入相应章节。

（四）关于环境整治和专项规划

1．应针对现状评估结论，细化专项规划内容。中洪街南段规划道路严重影响马氏庄园建筑格局的完整性，应予调整，保持街巷传统肌理；基础设施规划应与村镇发展相协调，补充北区排水措施；调整土地利用规划，完善用地类型分类。

2．应进一步完善展示利用规划，根据文物价值内涵明确展示目标，充实展示内容，细化展示措施，注重展示主题与古建筑群的相关性。

3．强化消防规划内容，明确消防设施设备的布设要求和巡护措施，确保文物安全。

4．考古和研究规划必要性和针对性不足，建议取消。

（五）加强所报规划与相关上位规划的衔接。

（六）规范文本和图纸表达，加强图文对应性，说明性内容应纳入规划说明。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的西蒋村马氏庄园保护规划报请河南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体立项报告或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好西蒋村马氏庄园的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

此复。

国家文物局

2017年2月7日
