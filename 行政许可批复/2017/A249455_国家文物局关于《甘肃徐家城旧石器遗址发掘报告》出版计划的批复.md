# 国家文物局关于《甘肃徐家城旧石器遗址发掘报告》出版计划的批复

## 关于《甘肃徐家城旧石器遗址发掘报告》出版计划的批复

文物保函〔2017〕559号

甘肃省文物局：

你局《关于申请徐家城旧石器遗址发掘报告出版经费的报告》（甘文物局发〔2017〕48号）收悉。经研究，我局同意所报《甘肃徐家城旧石器遗址发掘报告》出版计划。

请按照《国家重点文物保护专项补助资金管理办法》的规定和我局有关要求，另行申请该考古报告的出版补助经费。

国家文物局

2017年3月24日
