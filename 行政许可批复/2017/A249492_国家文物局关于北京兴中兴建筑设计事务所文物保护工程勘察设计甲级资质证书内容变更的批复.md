# 国家文物局关于北京兴中兴建筑设计事务所文物保护工程勘察设计甲级资质证书内容变更的批复

## 关于北京兴中兴建筑设计事务所文物保护工程勘察设计甲级资质证书内容变更的批复

办保函〔2017〕317号

北京市文物局：

你局《关于北京兴中兴建筑设计事务所注册资金变更的请示》（京文物〔2017〕233号）收悉。

经研究，我局同意北京兴中兴建筑设计事务所文物保护工程勘察设计甲级资质证书中的注册资金由“100万元”变更为“300万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局

2017年3月24日
