# 国家文物局关于江西樟树筑卫城遗址国字山墓地2017年度考古工作方案的批复

## 关于江西樟树筑卫城遗址国字山墓地2017年度考古工作方案的批复

文物保函〔2017〕867号

江西省文物局：

你局《关于呈报〈江西省樟树市国字山古墓葬考古调查、勘探、发掘2017年工作方案〉的请示》（赣文物局字〔2017〕57号）收悉。经研究，我局批复如下：

一、原则同意对江西樟树筑卫城遗址国字山墓地开展考古调查、勘探与小规模发掘工作，暂不同意对国字山墓地1号墓进行考古发掘。

二、国字山墓地考古工作方案应进行以下补充、完善：

（一）应对国字山墓葬及毗邻的筑卫城遗址进行大范围的区域考古调查，进一步掌握相关遗存分布情况和内在联系，为考古和研究工作奠定坚实基础。

（二）国字山墓地的考古工作应首先解决墓园遗迹的问题，充分把握墓地的格局和发展规律。考古发掘应以印证相关认识为目标的小范围发掘为主，不得进行大面积揭露。在开展考古工作前需做好充分的技术准备，制定重要遗迹遗物的临时性保护措施，加强多学科合作，保证考古工作的质量。

三、请你局协调指导支持中国社会科学院考古研究所和江西省文物考古研究院共同做好此次考古工作。

四、请你局指导有关单位，根据以上意见对樟树市筑卫城国字山墓地2017年度考古工作方案进行补充、完善，经你局核准后实施。请你局加强管理，确保工作质量和工地安全，遇有重要发现，应及时向我局报告。考古工作结束后，应向我局报告本年度工作情况。

国家文物局

2017年4月26日
