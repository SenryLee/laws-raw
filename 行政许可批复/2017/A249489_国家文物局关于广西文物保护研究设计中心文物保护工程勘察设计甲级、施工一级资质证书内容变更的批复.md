# 国家文物局关于广西文物保护研究设计中心文物保护工程勘察设计甲级、施工一级资质证书内容变更的批复

## 关于广西文物保护研究设计中心文物保护工程勘察设计甲级、施工一级资质证书内容变更的批复

办保函〔2017〕304号

广西壮族自治区文化厅：

你局《关于申请更换文物保护工程勘察设计、施工资质证书单位地址的请示》（桂文物报〔2017〕22号）收悉。

请研究，我局同意广西文物保护研究设计中心文物保护工程勘察设计甲级证书、施工一级资质证书中的单位地址由“广西南宁市纬武路160号”变更为“广西南宁市江南区白沙大道35号南国花园商城F2栋F2-7号”。请你局通知申请单位，携带资质证书副本到我局办理相关手续。

国家文物局

2017年3月23日
