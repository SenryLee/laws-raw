# 农业部关于北京市华都峪口禽业有限责任公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕49号

北京市农村工作委员会：

《北京市农村工作委员会关于推荐2017年数字农业建设试点项目的函》（京政农函〔2017〕7号）收悉。经研究，批复如下：

一、原则同意上报的北京市智慧蛋鸡物联互通模式建设项目可行性研究报告。项目建设单位为北京市华都峪口禽业有限责任公司，建设地点为北京市平谷区。项目建设期2年。

二、项目建设内容：一是自动化精准环境控制系统建设，包括鸡舍环境数据采集、控制系统等；二是自动化精准饲养设备改造升级，包括自动耗料检测系统、自动清粪系统、自动污水处理系统、自动集蛋系统等；三是信息管理系统建设，包括物流配送集成系统和大数据分析系统、数据处理中心设备购置等。

三、项目建设目标：项目建成后，实现蛋鸡自动化、数字化、智能化、机械化的现代养殖模式，项目区年可节约人工成本1618万元，增加企业年收入21600万元，父母代蛋种鸡全程产蛋率提高1%，受精率提高1%。

四、项目投资及来源：经评估核定，项目估算总投资3695万元，其中中央预算内投资按1109万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程、设计、监理以及技术支撑单位应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你市申报后续数字农业建设试点项目的资格。

农业部

2017年3月30日
