# 国家文物局关于在下霍护国灵贶王庙建设控制地带内进行文物保护设施建设项目的批复

## 关于在下霍护国灵贶王庙建设控制地带内进行文物保护设施建设项目的批复

文物保函〔2017〕1086号

山西省文物局：

你局《关于审批长子县下霍护国灵贶王庙文物保护设施建设项目设计方案的请示》（晋文物〔2017〕127号）收悉。经研究，我局批复如下：

一、原则同意在下霍护国灵贶王庙建设控制地带内实施文物保护设施建设项目和你局意见。

二、对该方案提出以下修改意见：

（一）该工程位于全国重点文物保护单位下霍护国灵贶王庙建设控制地带内，应严格遵守《中华人民共和国文物保护法》和山西省人民政府关于下霍护国灵贶王庙建设控制地带的相关管理规定，严格控制工程范围和工程强度，尽量减少施工建设对文物本体和景观环境的影响，确保文物安全。

（二）应优化方案设计，明确管理用房建筑形式，严格控制建筑规模和数量，建议仅修建一处管理用房。门窗形式建议采用单扇门和支摘窗。

（三）进一步论证停车场选址的科学性和必要性。

（四）大门及掖门南侧广场地面、山门前平台和甬路过渡平台不宜使用石材硬化，建议使用水泥方砖。

（五）不同意重砌红砖围墙，建议采用抹灰粉刷处理。

（六）绿化种植应以本地树种为主。

（七）防雷内容应按照程序另行报批。

（八）应制定必要的临时性文物保护措施和应急预案，注意加强施工过程中的文物安全监测工作，及时发现隐患，确保文物和人员安全。

（九）进一步规范文本和图纸，增强图纸和文本的对应性。

三、请你局根据上述意见，组织相关单位对所报方案进行修改、完善，并经你局核准后实施。请加强工程监管，确保文物安全。

此复。

国家文物局

2017年6月14日
