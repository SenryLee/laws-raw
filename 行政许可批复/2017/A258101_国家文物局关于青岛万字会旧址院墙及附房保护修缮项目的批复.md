# 国家文物局关于青岛万字会旧址院墙及附房保护修缮项目的批复

文物保函〔2017〕1877号

山东省文物局：

你局《关于上报青岛万字会旧址（院墙及附房）保护修缮工程设计方案的请示》（鲁文发〔2017〕94号）收悉。经研究，我局批复如下：

一、原则同意所报方案。

二、对方案提出以下修改意见：

（一）深化文物建筑历史原状的调查研究，进一步明确附属用房和围墙的文物原状。

（二）根据《近现代历史建筑结构安全性评估导则》等规范要求，对院墙及附房建筑结构进行安全评估，补充地基勘察，根据评估勘察结果制定相应加固措施。

（三）补充说明院墙周边排水情况，明确微生物滋生原因。

（四）进一步说明用混合砂浆从上至下铺灰、抹足、排实底瓦及筒瓦的材料配比和工艺流程。

（五）补充外墙涂料涂刷遍数和材料参数。

（六）进一步完善设计图纸。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年11月20日
