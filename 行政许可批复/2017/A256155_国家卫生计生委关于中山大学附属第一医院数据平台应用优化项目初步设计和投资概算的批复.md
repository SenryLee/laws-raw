# 国家卫生计生委关于中山大学附属第一医院数据平台应用优化项目初步设计和投资概算的批复

国卫规划函〔2017〕353号

中山大学附属第一医院：

你院《关于审批数据平台应用优化项目初步设计方案和投资概算的请示》（附一〔2017〕17号）收悉。经研究，原则同意你院数据平台应用优化项目初步设计和投资概算。该项目概算总投资1,000万元，全部由中央预算内投资解决。

请你院按照国家有关规定，严格执行基本建设程序，落实项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计和投资概算，抓紧组织开展下一步工作。

此复。

国家卫生计生委

2017年9月20日
