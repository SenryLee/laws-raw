# 国家文物局关于景东文庙白蚁防治工程立项的批复

## 关于景东文庙白蚁防治工程立项的批复

文物保函〔2017〕14号

云南省文物局：

你局《关于景东文庙白蚁危害治理工程立项的请示》（云文物〔2016〕194号）收悉。经研究，我局批复如下：

一、同意景东文庙白蚁防治工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属白蚁防治工程，应遵循不改变文物原状、最小干预等文物保护原则，合理确定工程范围和具体措施。

（二）工程内容为景东文庙——泗水牌坊、魁星阁、南北凉亭、钟鼓楼、棂星门、上下东厢房、上下西厢房、大成门、大成殿等文物建筑白蚁防治。

（三）加强前期勘察，进一步明确各文物建筑受损情况，准确核实蚁害范围、病害程度、受损构件数量、位置等，说明已开展修缮工程中的蚁害防治情况。

（四）应结合维修工程同步开展白蚁防治工作，细化各单体文物建筑的治理措施，注意开挖毒土屏障对文物建筑基础、排水系统、地面铺装的影响，补充必要的临时性保护措施，确保文物及人员安全。

（五）坚持防治结合的工作思路，注意在施工中培养相关文物部门和单位的白蚁监测能力，加强日常监测和预防措施，做到及时发现、及时治理。同时，认真完善、更新工程档案，评估工程效果，为今后的保护工作提供依据。

（六）应根据工程量实事求是编制经费预算，明确取费标准。

三、请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织专业力量编制工程技术方案，组织或委托第三方咨询评估机构进行方案技术评审，并依据第三方咨询评估机构的评估结论进行审核。

此复。

国家文物局

2017年1月6日
