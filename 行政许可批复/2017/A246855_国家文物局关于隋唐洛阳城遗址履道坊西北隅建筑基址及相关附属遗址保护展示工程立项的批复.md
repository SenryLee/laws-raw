# 国家文物局关于隋唐洛阳城遗址履道坊西北隅建筑基址及相关附属遗址保护展示工程立项的批复

## 关于隋唐洛阳城遗址履道坊西北隅建筑基址及相关附属遗址保护展示工程立项的批复

文物保函〔2016〕2126号

河南省文物局：

你局《关于再次上报隋唐洛阳城遗址履道坊白居易故居保护展示工程立项的请示》（豫文物〔2016〕298号）收悉。经研究，我局批复如下：

一、原则同意隋唐洛阳城遗址履道坊西北隅建筑基址及相关附属遗址保护展示工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，注意控制工程规模、范围和强度，减少对遗址的干预，避免过度保护展示。相关展示设施应具可逆性，不得损害遗址本体。

（二）加强考古工作和研究，进一步明确履道坊西北隅建筑基址及相关附属遗址的布局，加强遗址价值内涵的阐释和历史信息的提取，为遗址保护和模拟展示提供依据。涉及考古发掘的，应按要求另行填报考古发掘申请书。

（三）履道坊遗址现有占压建筑的拆除及清理等工作不宜纳入本次保护展示工程，应纳入地方人民政府工作计划有序实施。

（四）白居易纪念馆建设需结合考古工作进一步确认选址，避免占压地下重要文物遗存。相关建设方案应按程序另行报批。

（五）严格控制工程预算，进一步梳理并控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

四、请你局督促地方人民政府切实加强隋唐洛阳城遗址的保护和管理，做好日常巡查和看护，确保文物安全。

国家文物局

2017年1月4日
