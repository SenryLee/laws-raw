# 农业部关于重庆市重庆锦程实业有限公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕60号

重庆市农业委员会：

《重庆市农业委员会关于2017年数字农业建设试点项目的请示》（渝农文计[2017]3号）收悉。经研究，批复如下：

一、原则同意上报的重庆柑橘全产业链数字化示范项目可行性研究报告。项目建设单位为重庆锦程实业有限公司，建设地点为重庆市忠县。项目建设期2年。

二、项目建设内容：一是工厂化育苗系统建设，包括柑橘育苗基地物联网控制系统、育苗场智能化升级、品种展示示范基地和种子圃智慧管理系统等；二是生产过程管理系统建设，包括柑橘疫情、病虫害和熟期监控系统、柑橘产业大数据中心综合管理系统等；三是产品质量安全监控系统建设，包括柑橘产品溯源系统、电子销售管理系统等；四是采后商品化处理系统建设，包括加工生产数字化管理系统、NFC橙汁加工控制系统、数字物流管理系统、电子交易市场平台等。

三、项目建设目标：项目建成后，实现信息技术在柑橘产业中的广泛应用，形成数字农业技术集成应用解决方案和产业化模式，打造数字农业示范样板，项目区柑橘良种苗木基地节本增效0.4元/株，柑橘标准化果园年节省人工费250元/亩，年新增柑橘果品加工能力10万吨。

四、项目投资及来源：经评估核定，项目估算总投资3201万元，其中中央预算内投资按960万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你市申报后续数字农业建设试点项目的资格。

农业部
