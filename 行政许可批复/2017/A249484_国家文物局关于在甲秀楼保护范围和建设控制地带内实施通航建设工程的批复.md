# 国家文物局关于在甲秀楼保护范围和建设控制地带内实施通航建设工程的批复

## 关于在甲秀楼保护范围和建设控制地带内实施通航建设工程的批复

文物保函〔2017〕515号

贵州省文物局：

你局《关于在全国重点文物保护单位甲秀楼保护范围内实施通航建设工程的请示》（黔文物呈〔2017〕5号）收悉。经研究，我局批复如下：

一、原则同意在全国重点文物保护单位甲秀楼保护范围和建设控制地带内实施通航建设工程和你局意见。

二、对所报方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《贵州省贵阳文昌阁和甲秀楼文物保护规划》以及贵州省人民政府关于全国重点文物保护单位文昌阁和甲秀楼保护范围、建设控制地带的相关管理规定，严格控制新建设施的规模、体量和外观样式，确保与文物及周边景观风貌相协调。

（二）应进一步细化、完善设计方案。

1.船闸选址应尽可能避开保护范围。同时，应严格控制船闸控制房的高度、体量和规模，结合甲秀楼建筑样式调整船闸控制房的外观设计，确保其与文物及周边景观相协调。

2.说明南明河的水文特征、洪水期和枯水期的水位数据等，明确其通航水位和通航条件，说明对应净高的测算依据，研提浮玉桥船舶通行高度限制要求和具体管理措施。

3.进一步完善甲秀楼航道及船闸工程、浮玉桥保护工程、停靠点工程的施工范围、工程措施和施工强度，并充分考虑建设施工对文物安全的影响，制定必要的文物保护措施和应急预案。建议严格控制停靠点、防撞墩的规模，合理设计外观样式，尽量与文物及周边景观相协调。

4.补充船闸控制房外观设计图纸、甲秀楼保护区划的相关管理规定和控制要求。

（三）完善文物影响评估报告，深入论证工程建设及船舶通航对甲秀楼安全的影响，做到客观、准确、科学。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后报有关部门审批。请加强工程监管，并注意加强施工过程中的文物安全监测工作，及时发现、排除隐患，确保文物和人员安全。

四、请你局指导地方人民政府切实加强甲秀楼河段通航管理，严格按照《贵州省贵阳文昌阁和甲秀楼文物保护规划》的要求，科学确定船舶通航秩序和调度方式，确保浮玉桥及船舶通航安全。

此复。

国家文物局

2017年3月21日
