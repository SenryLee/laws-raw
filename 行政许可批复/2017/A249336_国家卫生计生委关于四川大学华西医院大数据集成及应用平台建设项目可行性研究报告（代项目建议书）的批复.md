# 国家卫生计生委关于四川大学华西医院大数据集成及应用平台建设项目可行性研究报告（代项目建议书）的批复

四川大学华西医院：

你院《关于报请审批四川大学华西医院大数据集成及应用平台建设项目可行性研究报告（代项目建议书）的请示》（川医院〔2016〕45号）收悉。经研究，批复如下：

一、为实现委属（管）医院295项业务监管核心指标数据的自动收集和上报，加强信息安全和远程医疗建设，同意你院大数据集成及应用平台建设项目立项，并原则同意所报项目可行性研究报告。

二、项目建设地点位于四川省成都市武侯区国学巷37号四川大学华西医院院内。

三、主要建设内容为医院信息集成、数据上报和远程医疗平台建设、相关软硬件设备购置以及加强信息化安全建设。

四、项目估算总投资2,999万元，资金来源为申请中央预算内投资和医院自筹资金共同解决。

五、按照国家有关规定和项目建设单位指定，确定李为民同志为四川大学华西医院大数据集成及应用平台建设项目责任人。

六、我委将通过公开招标方式选择若干家入围设计单位，你院根据实际需求并按照国家有关规定在入围单位中确定一家为项目初步设计和投资概算编制单位。

七、请你院严格按照国家有关规定，认真做好项目招投标工作。

八、请你院认真执行基本建设程序，落实项目法人责任制、项目招投标制，严格控制建设标准，在后续工作和项目实施过程中不得突破批复的建设投资，同时，根据批复的建设内容和投资，抓紧组织编制项目初步设计和投资概算，并报我委审批。

此复。

国家卫生计生委

2017年2月8日
