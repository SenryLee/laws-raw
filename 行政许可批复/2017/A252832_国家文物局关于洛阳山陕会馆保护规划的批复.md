# 国家文物局关于洛阳山陕会馆保护规划的批复

## 关于洛阳山陕会馆保护规划的批复

文物保函〔2017〕819号

河南省文物局：

你局《关于洛阳山陕会馆保护规划的请示》（豫文物〔2016〕186号）收悉。经研究，我局批复如下：

一、原则同意所报洛阳山陕会馆保护规划。

二、对该规划提出以下修改意见：

（一）关于文物认定和现状评估

1. 应明确文物构成和保护对象，补充调整依据；牌坊遗址应纳入遗址分类。

2. 深化价值评估，补充文物历史环境研究和商贸价值评估内容。

3. 加强现状评估，合理确定文物本体现状评估分级标准，增强针对性；补充现行保护区划、城市总体规划和历史文化名城保护规划等评估内容，分析相关控制要求实施效果，深入研究洛阳山陕会馆与洛阳城的关系。

（二）关于管理规定

调整保护区划管理规定，建设控制地带内新建建筑高度不宜超过9米，可进一步细化建设控制地带分类；明确建筑形制、高度、体量、密度等具体控制指标，加强历史环境保护。

（三）关于保护措施

进一步明确牌坊遗址的保护措施，增强针对性与可操作性。“文物监测措施”应纳入管理规划；“标志标识措施”应纳入展示规划。

（四） 关于环境整治和专项规划

1. 梳理环境整治措施，注意保持文物周边历史环境氛围，不同意新建广场。

2. 展示利用规划应根据价值和城市文化发展需要，明确展示利用主题、方式和内容，以会馆文化为重点，科学阐释文物价值内涵，注重发挥文物的公共文化服务功能。同时，应结合周边文物资源情况，统筹考虑区域展示线路设计和重要展示服务设施布置，增强展示效果。

（五）应根据文物保护管理需要，研提与《洛阳市城市总体规划》（2010-2020）、《洛阳市历史文化名城保护规划》（2010-2020）和《隋唐洛阳城保护规划》的具体衔接内容。

（六）进一步校核与规范文本和图纸，精简文本中的说明性文字。

三、请你局指导地方人民政府组织规划编制单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）的要求，将已经我局备案的洛阳山陕会馆保护规划报请河南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体立项报告或方案，并按程序报批。

六、请你局指导和协调地方人民政府在保护规划的指导下，进一步做好洛阳山陕会馆的各项保护、管理工作，妥善解决土地用途调整、环境整治等可能涉及的问题，切实保护文物本体及周边环境安全，确保规划顺利实施。

此复。

国家文物局

2017年4月20日
