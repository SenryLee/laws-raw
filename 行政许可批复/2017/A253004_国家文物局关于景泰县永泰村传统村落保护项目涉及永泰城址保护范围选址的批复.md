# 国家文物局关于景泰县永泰村传统村落保护项目涉及永泰城址保护范围选址的批复

## 关于景泰县永泰村传统村落保护项目涉及永泰城址保护范围选址的批复

文物保函〔2017〕835号

甘肃省文物局：

你局《关于呈报景泰县滩乡永泰村传统村落保护项目文物保护方案的报告》（甘文局发〔2017〕59号）收悉。经研究，我局批复如下：

一、原则同意景泰县永泰村传统村落保护项目涉及永泰城址保护范围的选址方案。

二、该建设项目应进一步优化方案设计，拟建停车场、观景平台、木栈道等的形式、材质等均应注意与永泰城址及其周边环境相协调，尽量采用当地传统建筑材料，不宜过于按照城市郊野公园或绿地的景观目标进行设计。同时，停车场、电瓶车换乘场等应进一步远离城址文物本体，并在面向城址的一面做好必要的绿化遮挡。

三、请你局组织专业考古研究单位在该项目涉及永泰城址的拟建区域进一步开展全面的考古工作，所需经费由建设单位承担。请你局加强管理，确保工作质量和工地安全，遇有重要发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。如需要开展考古发掘，应另行填报考古发掘申请书。

四、待考古工作结束后，请你局指导设计单位根据考古结果和文物保护的需要，进一步优化项目选址及建设方案，经你局核准后实施。

五、施工中，请你局组织专业机构做好对工程建设的全程监管，并督促工程部门切实做好工程施工过程中的文物保护工作，确保文物安全。

国家文物局

2017年4月21日
