# 国家邮政局关于《香港回归祖国二十周年》纪念邮票图稿的批复

国邮复〔2017〕40号

中国邮政集团公司：

你公司关于报审《香港回归祖国二十周年》纪念邮票图稿的文（中国邮政函〔2017〕32号）收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套3枚，内容分别为：1.龙腾香江；2.特区新颜；3.紫荆追梦。发行日期为2017年7月1日。经审查，同意使用该套图稿（图稿复印件见附件）印制邮票。

此复。

附件：“香港回归祖国二十周年”纪念邮票图稿复印件（略）
