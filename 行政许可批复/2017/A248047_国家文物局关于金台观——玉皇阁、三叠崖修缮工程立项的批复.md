# 国家文物局关于金台观——玉皇阁、三叠崖修缮工程立项的批复

## 关于金台观——玉皇阁、三叠崖修缮工程立项的批复

文物保函〔2017〕380号

陕西省文物局：

你局《关于金台观保护修缮工程立项的请示》（陕文物字〔2017〕8号）收悉。经研究，我局批复如下：

一、同意所报金台观——玉皇阁、三叠崖修缮工程立项。

二、在编制工程方案时，应注意以下方面：

（一）该工程属文物修缮工程，应遵循“不改变文物原状”、“最小干预”等原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为玉皇阁、三叠崖文物建筑及院落。

（三）加强现状勘察和研究，明确文物保存现状、主要病害类型、残损情况等，深入分析屋面漏雨、木构件糟朽、墙体风化等病害原因，在此基础上制定有针对性的修缮措施。

（四）应严格遵守最小干预原则，以现状整修为主，明确构件更换标准，尽可能保留原有构件，避免过度维修。补充踏步石及青砖地面原有形制和铺墁形式，严禁缺乏科学依据的盲目复原。院落环境应以现状保护为主,避免现代化园林设计倾向。

（五）根据工程量合理编制经费预算，进一步核减工程造价，补充取费标准。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案；组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

四、请你局督促地方人民政府，进一步明确金台观的管理责任，根据《古建筑保养维护规程》及时开展文物日常养护和岁修工作，确保文物安全。

此复。

国家文物局

2017年2月27日
