# 国家文物局关于老龙头遗址抢险加固工程立项的批复

## 关于老龙头遗址抢险加固工程立项的批复

文物保函〔2017〕562号

黑龙江省文物管理局：

你局《关于老龙头遗址抢险加固工程立项报告的请示》（黑文管字〔2017〕10号）收悉。经研究，我局批复如下：

一、原则同意老龙头遗址抢险加固工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状加固、消除安全隐患为主，做好老龙头遗址南部边坡防护加固、冲沟治理和场地排水，注意控制工程规模、范围和强度，避免过度干预。

（二）切实做好前期勘察、研究和试验，明确库勒河冲刷对遗址的危害程度，查清遗址南部边坡冲沟的汇水面积、汇水量和冲刷深度，合理确定暴雨重现期，为科学编制保护工程技术方案提供依据。

（三）边坡防护加固应充分考虑生态性防护措施。冲沟治理应随形整治，保持原有排水功能和径流方向，不宜取直或填平。场地排水应尽量避免大规模工程干预，以自然排水为主，人工截流沟渠为辅。

（四）应做好工程实施区域的自然地貌恢复和保障，与当地现有生态及景观环境相协调。

（五）严格控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年3月24日
