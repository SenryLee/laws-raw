# 教育部办公厅关于同意《纳米技术与精密工程》变更为英文刊的批复

教技厅函[2017]24号

天津大学：

《天津大学关于〈纳米技术与精密工程〉改为英文刊的申请》（天大校办〔2016〕192号）收悉。经研究，同意你校《纳米技术与精密工程》变更为英文刊。请尽快到新闻出版管理部门办理相关手续。

专此。

教育部办公厅

2017年3月4日
