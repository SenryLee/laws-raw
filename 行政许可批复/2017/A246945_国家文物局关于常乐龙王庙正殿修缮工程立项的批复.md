# 国家文物局关于常乐龙王庙正殿修缮工程立项的批复

## 关于常乐龙王庙正殿修缮工程立项的批复

文物保函〔2017〕59号

河北省文物局：

你局《关于涉县常乐龙王庙正殿保护修缮工程立项的请示》（冀文物字〔2016〕241号）收悉。经研究，我局批复如下：

一、同意常乐龙王庙正殿修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为常乐龙王庙正殿文物建筑。

（三）应加强现状勘察和历史研究，明确文物保存现状、主要病害类型、残损情况等，查找屋面局部下沉、木构件糟朽等病害原因，客观评估历次修缮工程效果，在此基础上制定有针对性的修缮措施。

（四）坚持最小干预原则，严格控制工程量和工程强度，明确构件更换标准，尽可能保留原有大木构件、椽子和望砖，避免过度维修。更换下的原构件应详细测绘、登记、评估价值，妥善保管；各类工程资料应由专人管理、建档，并在工程结束后纳入常乐龙王庙正殿记录档案。

（五）应加强地方建筑做法和传统工艺特色的研究分析，注意在工程中采用原材料、原工艺，如核实墙体抹砂子灰是否为原有做法等。同时，应考虑文物建筑的使用功能和展示利用方式，并在方案设计中予以体现。

（六）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（七）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。同时，按照实际情况调整项目实施计划。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案；组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年1月18日
