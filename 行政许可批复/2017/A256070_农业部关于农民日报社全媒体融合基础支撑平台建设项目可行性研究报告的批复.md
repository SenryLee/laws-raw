# 农业部关于农民日报社全媒体融合基础支撑平台建设项目可行性研究报告的批复

农计发〔2017〕111号

农民日报社：

《农民日报社关于报送全媒体融合基础支撑平台（中央厨房）建设项目可行性研究报告的请示》（农报社〔2017〕3号）收悉。经研究，批复如下。

原则同意全媒体融合基础支撑平台建设项目。项目建设地点位于北京市朝阳区惠新西街15号。主要建设内容为改造新闻指挥调度中心303平方米，机房96平方米；购置仪器设备76台（套、批），建设万兆骨干网络系统、报社云平台系统、网络安全防护及管理系统、存储系统、新闻采集系统、一卡通系统和历史数据整合等系统。总投资2270万元，全部为中央预算内投资。项目建设期为2年。

请据此批复，抓紧委托有资质的勘察设计单位编制项目初步设计和概算。初步设计和概算编制要严格执行《关于党政机关停止新建楼堂馆所和清理办公用房的通知》（中办发〔2013〕17号）要求，不得将楼堂馆所等纳入项目建设内容。要按照招投标事项核准表要求，做好有关招投标工作。请切实履行好项目监管责任，督促项目建设单位严格按照农业基本建设项目管理规定，做好项目组织实施工作，并在农业建设项目管理信息系统（http://ac.agri.gov.cn）上，填报项目初步设计和建设进度等信息。

附件：农民日报社全媒体融合基础支撑平台建设项目招标投标事项核准表

农业部

2017年9月14日
