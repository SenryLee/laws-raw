# 国家文物局关于兴隆山古建筑群壁画修缮工程立项的批复

## 关于兴隆山古建筑群壁画修缮工程立项的批复

文物保函〔2017〕60号

甘肃省文物局：

你局《关于兴隆山古建筑群壁画保护修复工程立项的报告》（甘文局发〔2016〕168号）收悉。经研究，我局批复如下：

一、同意兴隆山古建筑群壁画修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属文物修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物的真实性和完整性。

（二）工程内容为兴隆山古建筑群菩萨殿、佛殿、三进门楼、中门楼、前门楼、城隍庙、牛马王庙、关帝庙壁画修缮。不同意非文物建筑五圣宫壁画修缮。

（三）加强现状勘察与评估，深化病害类型、原因及影响因素分析，明确无量祖师殿文物建筑现状与壁画安全的关系，针对病害情况制定保护措施。

（四）应研究和总结地方传统工艺、材料和做法，并注意在施工过程中使用。同时,应考虑壁画的价值展示和阐释需要，并在方案中明确展示利用和防护措施，补充文物建筑和壁画展示设计内容。

（五）在施工过程中应做好相关记录工作，工程结束后相关资料应纳入全国重点文物保护单位记录档案。

三、请你局指导地方人民政府，加强兴隆山古建筑群的日常管理、巡查与维护工作，确保文物本体与环境安全。根据上述意见和《文物保护工程设计文件编制深度要求（试行）》，组织编制工程技术方案，由你局组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行初审同意后，报我局审批。

四、无量祖师殿壁画修缮工程应按照我局《关于兴隆山古建筑群无量祖师大殿和献殿修缮工程立项的批复》（文物保函〔2016〕341号）要求，组织有关单位抓紧实施。

此复。

国家文物局

2017年1月13日
