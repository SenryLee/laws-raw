# 国家文物局关于上坊孙吴墓本体保护工程立项的批复

## 关于上坊孙吴墓本体保护工程立项的批复

文物保函〔2017〕446号

江苏省文物局：

你局《关于审批上坊孙吴墓本体保护工程立项的请示》（苏文物保〔2016〕334号）收悉。经研究，我局批复如下：

一、原则同意上坊孙吴墓墓室本体保护工程立项，不同意墓圹复原加固工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状加固、消除安全隐患为主，做好砖室墓本体加固保护，并注意控制工程规模、范围和强度，避免过度保护。

（二）加强前期勘察、研究和试验，查明病害类型和成因，评估病害的危害程度，重点查清渗水来源和途径，为编制保护工程技术方案提供科学依据。

（三）工程措施和材料应当尽量符合传统工艺，保护材料和技术应结合现状评估进行试验、筛选之后合理确定。

（四）严格控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。同时，请你局指导地方人民政府做好上坊孙吴墓的日常维护工作，确保文物安全。

国家文物局

2017年3月7日
