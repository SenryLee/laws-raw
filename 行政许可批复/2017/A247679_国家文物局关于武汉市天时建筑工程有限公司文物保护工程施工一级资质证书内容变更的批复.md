# 国家文物局关于武汉市天时建筑工程有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于武汉市天时建筑工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕74号

湖北省文物局：

你局《关于武汉市天时建筑工程有限公司变更企业法定代表人的请示》（鄂文物文〔2017〕1号）收悉。

经研究，我局同意武汉市天时建筑工程有限公司文物保护工程施工一级资质证书中的法定代表人由“徐汉新”变更为“张红玉”。请你局通知申请单位，携带资质证书副本到我局办理相关手续。

国家文物局

2017年2月6日
