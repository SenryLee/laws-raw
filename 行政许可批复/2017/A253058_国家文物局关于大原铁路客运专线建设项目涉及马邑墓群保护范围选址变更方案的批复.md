# 国家文物局关于大原铁路客运专线建设项目涉及马邑墓群保护范围选址变更方案的批复

## 关于大原铁路客运专线建设项目涉及马邑墓群保护范围选址变更方案的批复

文物保函〔2017〕1108号

山西省文物局：

你局《关于大原铁路客运专线穿越马邑墓群的请示》（晋文物〔2017〕138号）收悉。经研究，我局批复如下：

一、原则同意变更后的大原铁路客运专线建设项目涉及马邑墓群保护范围的选址方案。请你局指导建设单位，按照我局《关于大原客运专线建设项目涉及马邑墓群保护范围选线方案的批复》（文物保函〔2016〕1072号）的要求，切实做好该建设项目的前期考古调查、勘探和发掘工作，合理优化项目选址及建设方案，确保文物安全。

二、变更后的大原铁路客运专线如涉及其他文物保护单位和不可移动文物的，应依法由相关文物行政部门另行审批。

国家文物局

2017年6月22日
