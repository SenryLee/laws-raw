# 农业部关于变更福建省渔业捕捞许可签发人的批复

农渔发〔2017〕17号

福建省海洋与渔业厅：

你厅《关于变更省级渔业捕捞许可签发人的函》（闽海渔函〔2017〕64号）收悉。经研究，同意将福建省渔业捕捞许可签发人变更为钟声，有效期至2020年12月31日。李涛的渔业捕捞许可签发人资格自发文之日起终止。

特此批复。

农业部

2017年3月28日
