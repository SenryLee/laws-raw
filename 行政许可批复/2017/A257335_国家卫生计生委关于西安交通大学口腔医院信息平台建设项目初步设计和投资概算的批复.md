# 国家卫生计生委关于西安交通大学口腔医院信息平台建设项目初步设计和投资概算的批复

国卫规划函〔2017〕372号

西安交通大学口腔医院：

你院《关于报请审批西安交通大学口腔医院信息平台建设项目初步设计方案和投资概算的请示》（西交口腔〔2017〕103号）收悉。经研究，原则同意你院信息平台建设项目初步设计和投资概算。该项目概算总投资1,466万元，其中，中央预算内投资1,000万元，其余资金由你院自筹解决。

请你院按照国家有关规定，严格执行基本建设程序，落实项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计和投资概算，抓紧组织开展下一步工作。

此复。

国家卫生计生委

2017年10月9日
