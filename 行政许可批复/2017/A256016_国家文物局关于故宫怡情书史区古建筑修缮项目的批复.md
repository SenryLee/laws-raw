# 国家文物局关于故宫怡情书史区古建筑修缮项目的批复

文物保函〔2017〕1656号

北京市文物局：

你局《关于故宫怡情书史区古建筑修缮工程设计方案的请示》（京文物〔2017〕840号）收悉。经研究，我局批复如下：

一、原则同意所报故宫怡情书史区古建筑修缮项目和你局意见。

二、具体修改意见如下：

（一）深化现状勘察。进一步论证残损定级；补充勘察井亭基础做法，深化分析其基础沉降的原因；补充对室外砖地面垫层和屋面隐蔽部位的勘察，详细记录其原做法，为修缮提供材料及做法依据。

（二）严格控制工程范围和工程量，尽可能利用原有构件。结合井亭补充勘察，进一步论证其干预力度，建议基础尽量采取局部找平、少拆动的修缮方法；不应将腐朽高度超过1/4柱高作为柱更换的统一标准，应综合柱残损部位、程度、范围等制定合理的剔补、墩接和更换标准；对不影响结构安全、排水和使用的风化碎裂的砖石构件，不得整体揭墁、更换。进一步论证井亭重点修复和落架重做基础的必要性，建议在局部开挖下沉部位基础、了解基础做法及埋深、地基等情况的基础上，研究优先采取局部找平、少拆动方式的可行性。

（三）细化工程做法，补充修缮方案设计总说明，明确技术路线。明确顺铺望板做法和里口木的修配要求，注意保留早期做法和原有构件；基于补充勘察，校核室外砖地面垫层的修缮设计；补充东西耳房明间与次间地面铺墁形式不同的设计依据；补充院落排水的设计要求；东配殿南抱厦博风板近墙部位宜装排水天沟和天沟滴水瓦。

（四）进一步规范完善图纸和文本。残损标注和修缮标注应清晰简明并量化；修缮设计图不应完全套用现状勘测图纸；注意核对剖面图与平面图的对应关系，补充标注轴线关系；院落平面图应标注控制点标高，局部无需画等高线；补充构造做法详图。放大装修剖面图比例，补充标注。

（五）明确该组建筑修缮后的使用功能，建议统筹考虑保护修缮和展示利用需求，避免二次施工。

（六）建议结合项目实施对天花上方梁架彩画进行详细勘测、记录和评估，并根据评估结论制定针对性保护措施,履行相应报批程序。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，经你局核准后实施。请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保工程质量。

此复。

国家文物局
