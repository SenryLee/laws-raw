# 国家文物局关于玉虚宫下院保护规划编制立项的批复

## 关于玉虚宫下院保护规划编制立项的批复

文物保函〔2017〕153号

山西省文物局：

你局《关于审批国保单位文物保护规划编制计划的请示》（晋文物〔2016〕82号）收悉。经研究，我局批复如下：

一、同意玉虚宫下院规划编制立项。

二、在规划编制过程中应注意以下问题：

（一）加强历史研究，深入分析玉虚宫下院的选址特征、空间格局及历史沿革，厘清玉虚宫下院与上院的关系及历史环境要素，科学评估玉虚宫下院的价值，明确文物构成和保护对象。

（二）科学评估文物保存现状和周边建设情况，梳理保护区划和管理规定执行中存在的问题，在此基础上明确规划目标和重点。

（三）应根据文物分布范围和保护管理需要，合理划定规划范围和保护区划，制定具有可操作性的管理规定和建设控制指标，严格控制文物周边建设强度，科学确定环境整治目标，保护文物周边区域的历史和自然景观。

（四）深入发掘玉虚宫下院的历史文化内涵，明确展示利用目标、方式和强度，研提多样化的展示方式，注意突出玉虚宫的文化内涵和建筑总体格局。同时，应合理控制利用强度，核定最大承载量，避免过度利用。

（五）应客观评估管理现状，进一步理顺管理机制，明确管理使用单位的责权关系。同时，应落实日常管理责任，做好日常养护、维修、巡查和监测工作，确保文物本体安全。

（六）加强与相关规划的衔接，确保规划的可操作性。

三、请你局指导当地人民政府组织专业机构，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）、《全国重点文物保护单位保护规划编制审批办法》和《全国重点文物保护单位保护规划编制要求》的有关规定，做好玉虚宫下院保护规划的编制工作。规划编制完成并经你局初审同意后，请将规划文本、图纸及相应的电子文档等报我局审批。

四、不同意李庄武庙、李庄文庙、古交千佛寺、石末宣圣庙、高平嘉祥寺、仙翁庙、长春观、兴梵寺、南阳村寿圣寺塔、乔寺碑楼、阳曲大王庙大殿等11处全国重点文物保护单位规划编制立项。请你局指导地方政府结合所在地村镇总体规划编制，统筹考虑文物保护的规划措施和要求，合理确定保护区划、管理规定和具体建设控制指标，确保文物及其周边环境安全。

此复。

国家文物局

2017年2月6日
