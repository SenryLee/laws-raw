# 国家文物局办公关于北京六建集团有限责任公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕1031号

北京市文物局：

你局《关于北京六建集团有限责任公司文物保护工程施工一级资质证书注册资本金变更的请示》（京文物〔2017〕1099号）收悉。

经研究，我局同意北京六建集团有限责任公司文物保护工程施工一级资质证书中的注册资金由“30000万元”变更为“50000万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2017年9月4日
