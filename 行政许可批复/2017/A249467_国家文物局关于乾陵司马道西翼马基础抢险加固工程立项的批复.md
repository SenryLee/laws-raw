# 国家文物局关于乾陵司马道西翼马基础抢险加固工程立项的批复

## 关于乾陵司马道西翼马基础抢险加固工程立项的批复

文物保函〔2017〕587号

陕西省文物局：

你局《关于乾陵司马道西翼马基础抢险加固工程立项的请示》（陕文物字〔2017〕20号）收悉。经研究，我局批复如下：

一、原则同意乾陵司马道西翼马基础抢险加固工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）加强现状勘察，细化西翼马基础的稳定性评价，查明危害及其成因，并补充相关图纸说明。

（二）建议结合西翼马基础抢险加固工程统筹考虑西翼马周围的环境整治。

（三）应充分考虑施工对文物安全的影响，制定好施工过程中的临时性保护措施。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年3月28日
