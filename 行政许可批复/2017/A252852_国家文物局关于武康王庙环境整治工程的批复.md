# 国家文物局关于武康王庙环境整治工程的批复

## 关于武康王庙环境整治工程的批复

文物保函〔2017〕939号

甘肃省文物局：

你局《关于开展武康王庙保护设施建设项目的请示》（甘文局发〔2017〕37号）收悉。经研究，我局批复如下：

一、原则同意武康王庙环境整治工程和你局意见。

二、对所报方案提出如下修改完善意见：

（一）该工程位于全国重点文物保护单位武康王庙保护范围和建设控制地带内，应严格遵守《中华人民共和国文物保护法》和甘肃省人民政府关于武康王庙保护区划的相关管理规定，以历史环境保护和文物安全为前提，合理改善文物及周边环境。

（二）应加强历史研究和考古工作，分析、确定武康王庙的历史格局和院落风貌，进一步明确道路组织、地面铺装及院门样式，为科学确定环境整治措施提供依据。

（三）应进一步调整方案设计，管护用房、展示厅、办公用房及卫生间宜采用传统四合院样式，同时，尽量减少设计面积体量，牌楼门缺乏历史依据和实用性，建议根据武康王庙历史风貌特点、建筑规制等调整设计；进一步调整道路组织及铺装，确保与文物建筑风貌和文化价值相符。补充武康王庙保护范围和建设控制地带的管理规定、具体控制指标。

（四）绿化种植应尽量选用本地植物品种，花池形式和布局应避免城市园林化设计倾向。

（五）补充说明西北部边坡加固与2015年已竣工验收武康王庙边坡防治工程的关系；如该工程确有必要，施工前应做好必要的临时性支护措施。

（六）文物影响评估报告内容应准确、客观、真实，科学研提方案调整建议，不应简单套用方案设计内容。

三、请你局指导当地人民政府组织专业机构，按照《关于武康王庙文物保护规划工作计划的批复》（文物保函〔2010〕622号）的要求，抓紧编制武康王庙保护规划，统筹考虑文物保护、展示利用、环境整治等方面工作。

四、请你局根据上述意见，组织相关单位对所报方案进行修改、完善，并经你局核准后实施。请加强对工程的监管，如有重要考古发现，应及时调整方案设计，确保文物及其环境安全。

国家文物局

2017年5月8日
