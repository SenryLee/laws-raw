# 国家文物局关于钓鱼城范家堰遗址保护展示工程立项的批复

## 关于钓鱼城范家堰遗址保护展示工程立项的批复

文物保函〔2017〕523号

重庆市文物局：

你局《关于钓鱼城范家堰等四处遗址本体加固与保护展示工程立项请示》（渝文物〔2017〕27号）收悉。经研究，我局批复如下：

一、原则同意钓鱼城范家堰遗址保护展示工程立项，暂不同意其余三处遗址保护展示工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状加固、消除安全隐患为主，将工程范围限定在范家堰遗址本体加固保护、标识展示、遗址区场地排水和小规模环境整治，并注意控制工程规模、范围和强度。

（二）切实做好前期勘察、研究和试验，对遗址进行详细病害调查，查明病害类型及成因，评估病害对遗址的危害程度，并在此基础上研提具有针对性的保护措施。遗址本体保护应尽量采用物理方法，确需采用化学方法的，应事先开展必要的前期试验，以检验所有材料的适用性。

（三）遗址展示应以遗存本体的露明展示为主，做好相关游线设计，辅以必要的标识解说即可，不必过多干预。

（四）遗址区场地排水应尽量避免大型工程干预，环境整治应仅限于遗址范围内不合理因素的清除，不得大量新建各类设施。

（五）严格控制工程预算，进一步梳理并控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年3月21日
