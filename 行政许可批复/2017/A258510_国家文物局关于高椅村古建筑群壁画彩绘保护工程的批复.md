# 国家文物局关于高椅村古建筑群壁画彩绘保护工程的批复

文物保函〔2017〕1945号

湖南省文物局：

你局《关于审批〈湖南高椅村古建筑群壁画彩绘保护工程勘察设计方案〉的请示》（湘文物报〔2017〕120号）收悉。经研究，我局批复如下：

一、原则同意所报高椅村古建筑群壁画彩绘保护项目和你局意见。

二、具体修改意见如下：

（一）应结合相关保护规划要求，明确高椅村壁画彩绘保护修复后的总体外观基调，以指导各项保护措施的设计。

（二）进一步完善部分检测分析工作。结露点监测和分析应选择当地结露季节进行；补充可溶盐分析，评估毛细水对壁画彩绘的影响，提出有针对性的处理措施。

（三）进一步完善部分保护措施。补充灌浆处理的实验室试验，评估灌浆材料、支撑体和地仗间的粘合力；地仗缺失较多部位修补可考虑用不同材料设多层地仗层；不宜使用水硬性石灰，应主要考虑使用原材料和做法；裂隙修补等易造成污染的操作应做好文物遮护。

（四）应结合本次保护项目对当地村民进行适当的培训，提高其对文物建筑及壁画彩绘价值的认识，培养文物保护意识和日常保养维护能力，推动村民对文物建筑及壁画彩绘的自觉保护。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年12月4日
