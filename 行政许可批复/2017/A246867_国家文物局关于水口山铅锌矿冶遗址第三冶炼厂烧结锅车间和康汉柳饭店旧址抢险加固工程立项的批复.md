# 国家文物局关于水口山铅锌矿冶遗址第三冶炼厂烧结锅车间和康汉柳饭店旧址抢险加固工程立项的批复

## 关于水口山铅锌矿冶遗址第三冶炼厂烧结锅车间和康汉柳饭店旧址抢险加固工程立项的批复

文物保函〔2017〕76号

湖南省文物局：

你局《关于水口山铅锌矿遗址之第三冶炼厂烧结锅车间和康汉柳饭店抢险加固工程立项的请示》（湘文物报〔2016〕213号）收悉。经研究，我局批复如下：

一、原则同意水口山铅锌矿冶遗址第三冶炼厂烧结锅车间和康汉柳饭店旧址抢险加固工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状加固、消除安全隐患为主，做好第三冶炼厂烧结锅车间和康汉柳饭店旧址的建筑结构和屋面抢险加固，避免建筑塌毁和漏雨，并注意控制工程规模、范围和强度，避免过度保护。

（二）切实做好前期勘察、研究和试验，开展历史资料搜集和研究，明确建筑结构、材料和工艺等，查明病害类型及成因，评估建筑结构的安全稳定性，为编制保护工程技术方案提供科学依据。

（三）工业设备保护不纳入本次抢险加固工程范围，待明确展示利用方式后统筹考虑。

（四）岩土工程勘察与三维激光扫描工作必要性不足，不应纳入前期工作内容。

（五）严格控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年1月19日
