# 农业部关于中国动物卫生与流行病学中心生物安全动物实验室建设项目可行性研究报告的批复

农计发〔2017〕97号

中国动物卫生与流行病学中心:

《关于请予审批<生物安全动物实验室改扩建项目可行性研究报告>的请示》（中动卫财基〔2017〕19号）收悉。经研究，批复如下。

中国动物卫生与流行病学中心生物安全动物实验室建设项目的建设地点位于山东省青岛市城阳区红岛街道，主要建设内容为改造生物安全动物实验室465平方米，购置仪器设备21台（套），总投资797万元，全部为中央预算内投资（详见附件），项目建设期2年，自投资计划下达之日起计算。

请据此批复，抓紧委托有资质的勘察设计单位编制项目初步设计报我部审批。请严格按照农业基本建设项目管理规定，做好项目组织实施工作，并按月在农业建设项目管理信息系统（http://ac.agri.gov.cn）和国家重大建设项目库（http://kpp.ndrc.gov.cn）中填报实施进度等相关信息。

附件：中国动物卫生与流行病学中心生物安全动物实验室建设项目可行性研究报告批复表

农业部
