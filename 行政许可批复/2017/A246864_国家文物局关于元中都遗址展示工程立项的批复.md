# 国家文物局关于元中都遗址展示工程立项的批复

## 关于元中都遗址展示工程立项的批复

文物保函〔2017〕61号

河北省文物局：

你局《关于元中都遗址保护展示设施工程立项的请示》（冀文物字〔2016〕236号）收悉。经研究，我局批复如下：

一、原则同意元中都遗址展示工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以维护遗址本体安全为出发点，注意控制工程规模、范围和强度，减少对遗址的干预，避免过度保护展示。相关展示设施应具可逆性，不得损害遗址本体。

（二）进一步梳理展示设计范围和内容，明确展示工程与保护工程之间的关系，并加强展示的系统性和整体性，做好整体形象提升。同时，应进一步注意所采取展示方式的适用性，避免盲目追求展示形式。

（三）加强考古工作和研究，加强遗址价值内涵的阐释，以增强对遗址展示设计的支撑。涉及考古发掘的，应按要求另行填报考古发掘申请书。

（四）进一步校核工程预算，控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年1月13日
