# 国家文物局关于羊角水堡岸坡加固工程立项的批复

## 关于羊角水堡岸坡加固工程立项的批复

文物保函〔2017〕133号

江西省文物局：

你局《关于呈报〈羊角水堡岸坡加固工程立项报告〉的请示》（赣文物局字〔2016〕214号）收悉。经研究，我局批复如下：

一、同意羊角水堡岸坡加固工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属保护性设施建设工程，应遵循“不改变文物原状”、“最小干预”等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程内容为羊角水堡临河城墙段岸坡加固。

（三）应加强现状勘察研究，明确岸坡地层岩性及岩土层物理力学性质，分析岸坡灾害成因、类型及危害性，科学评估坡体及临水城墙的结构稳定性，为制定加固措施提供依据并提高加固措施的针对性。

（四）应以现状加固为主，严格控制工程量和工程范围，合理确定加固措施及加固材料，有效解决临河段岸坡结构稳定问题，并确保加固后岸坡外观与周边环境相协调。

（五）充分考虑岸坡加固工程施工对羊角水堡城门城墙的安全影响，研提必要的临时性文物保护措施。

（六）根据工程量核实经费预算，合理确定工程内容和取费项目，补充取费标准。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案，并组织或委托第三方咨询评估机构进行方案技术评审，依据评估意见进行审批。

此复。

国家文物局

2017年1月24日
