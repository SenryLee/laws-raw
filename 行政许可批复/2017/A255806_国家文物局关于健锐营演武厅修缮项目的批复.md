# 国家文物局关于健锐营演武厅修缮项目的批复

文物保函〔2017〕1382号

北京市文物局：

你局《关于健锐营演武厅修缮工程方案的请示》（京文物〔2017〕830号）收悉。经研究，我局批复如下：

一、原则同意所报健锐营演武厅修缮工程和你局意见。

二、对该工程提出以下意见：

（一）应细化前期勘察与研究，明确文物建筑原有形制、建筑材料、工艺和做法等，深化文物残损程度及病害情况评估，为制定保护措施提供依据。

（二）坚持最小干预原则，严格控制工程范围和强度，细化工程做法和技术要求。

1．进一步探查拟修地面砖下垫层具体情况，按原有做法合理调整修缮措施。严格控制剔补及揭墁范围，非踩踏区域如不涉及排水问题，建议保持现状。

2．细化看城城台北侧外墙拆砌的具体做法及要求。

3．细化看城内马道石踏跺勾缝措施，对深度与宽度较大裂缝可先进行缝隙清掏和适度灌浆，再实施勾缝措施。

4．进一步论证开挖管沟直埋管线入地措施的科学性和可行性，建议对明铺管线采取局部支垫方式解决排水不畅问题，避免管沟开挖造成渗水。

（三）建议彩画修缮项目编制专项方案。加强现状勘察和研究，明确各文物建筑彩画规制、等级，新老彩画的具体分布范围、历次保护修缮情况和效果等内容。不同意没有历史依据的重绘。

（四）补充必要的施工要求和临时性保护措施，确保施工过程中人员和文物安全。

（五）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善并经你局批准后组织实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年8月9日
