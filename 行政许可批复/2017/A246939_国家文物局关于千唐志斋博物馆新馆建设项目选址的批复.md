# 国家文物局关于千唐志斋博物馆新馆建设项目选址的批复

## 关于千唐志斋博物馆新馆建设项目选址的批复

文物保函〔2017〕53号

河南省文物局：

你局《关于千唐志斋博物馆新馆建设项目选址的请示》（豫文物〔2016〕339号）收悉。经研究，我局批复如下：

一、原则同意千唐志斋博物馆新馆建设项目选址。

二、对所报方案提出以下修改完善意见：

（一）该项目选址位于千唐志斋石刻建设控制地带内，应严格遵守《中华人民共和国文物保护法》以及河南省人民政府关于千唐志斋建设控制地带的相关管理规定，合理确定博物馆新馆的规模、高度和外观样式，严格控制施工范围，尽量减少对文物本体和景观环境的影响，确保文物安全。

（二）应综合考虑文物保护和展示需要，合理确定新馆功能和展示主题，科学调整方案设计。应完善文物影响评估报告，深入论证拟建项目对文物本体和环境风貌的影响，做到客观、准确、科学。同时，根据文物影响评估报告进一步降低建筑高度，压缩建筑体量，研提多种比选方案，确保新馆与文物和周边景观风貌相协调。补充千唐志斋建设控制地带的管理规定和具体控制指标。

（三）应结合文物展示需要以及周边道路、基础设施情况，合理设计出入口，并按照国家相关规范要求，明确新馆的功能布局和展陈设计。

（四）补充必要的文物保护措施和应急预案。

（五）补充新馆立面图、景观视线分析图。

三、请你局指导相关单位根据上述意见对千唐志斋博物馆新馆建设项目方案进行修改和完善，经你局核准后报有关部门批准实施。工程施工期间，应指导当地文物部门加强对工程的监管，确保文物安全。

此复。

国家文物局

2017年1月13日
