# 国家文物局关于在潼川古城墙建设控制地带内进行佳松琅润园二期步行街项目地上部分的批复

## 关于在潼川古城墙建设控制地带内进行佳松琅润园二期步行街项目地上部分的批复

文物保函〔2017〕1022号

四川省文物局：

你局《关于报送〈潼川古城墙建设控制地带内进行佳松·琅润园二期步行街项目方案〉的请示》（川文物〔2017〕55号）收悉。经研究，我局批复如下：

一、原则同意在潼川古城墙建设控制地带内进行佳松·琅润园二期步行街项目地上部分和你局意见，不同意商业街地下汽车车库建设项目。

二、对所报方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、四川省人民政府关于潼川古城墙保护范围和建设控制地带的管理规定和《三台县历史文化名城保护规划》等的有关要求，合理确定拟新建建筑的规模、高度和外观样式，严格控制施工范围，尽量减少对文物本体和景观环境的影响。

（二）应深化方案设计内容，应进一步降低 B＃、C＃和D＃建筑檐口高度，建筑高度不得超过北侧城墙，并压缩建筑体量，减少对城墙景观风貌的影响。

（三）应充分考虑施工振动对周边城墙安全的影响，制定必要的文物保护措施和应急预案。同时，应注意加强施工过程中的文物安全监测工作，及时发现隐患，确保文物和人员安全。

（四）补充说明项目实施范围内历史建筑、传统民居和历史街巷等的有关情况，并在项目实施中注意妥善保护。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。请加强工程监管，确保文物安全。

四、请你局督促地方人民政府落实管理责任，尽快完成《潼川古城墙保护规划》编制工作，有序开展文物保护、环境整治、展示利用和旅游开放等工作，引导周边建设活动，妥善解决土地用途调整、拆建等可能涉及的问题，处理好文物保护利用、地方经济发展和民生改善之间的关系。

此复。

国家文物局

2017年5月24日
