# 国家文物局关于在黄陵庙保护范围和建设控制地带内进行文物库房建设项目的批复

## 关于在黄陵庙保护范围和建设控制地带内进行文物库房建设项目的批复

文物保函〔2017〕28号

湖北省文物局：

你局《关于在黄陵庙建设控制地带修建文物库房的请示》（鄂文物〔2016〕50号）收悉。经研究，我局批复如下：

一、原则同意在黄陵庙保护范围和建设控制地带内进行文物库房建设项目和你局意见。

二、对所报方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《黄陵庙文物保护规划》以及湖北省人民政府关于全国重点文物保护单位黄陵庙保护范围和建设控制地带的相关管理规定，合理确定拟建建筑的规模、高度和外观样式，严格控制施工范围，尽量减少对文物本体和景观环境的影响，确保文物安全。

（二）应调整方案设计，进一步降低建筑高度，压缩建筑体量，屋顶正脊高度不得超过9米，墙头高度不得超过10 米。同时，应减小建筑面阔，简化门楼形式，尽量降低新建建筑对文物本体的景观影响；不同意立面采用歇山形式门头设计样式。

（三）绿化种植应尽量采用地方树种，避免景观园林化设计倾向。同时，应考虑植被日常养护影响，与文物本体保持必要的安全距离。

（四）完善文物影响评估报告，客观、准确、科学论证拟建项目对文物本体和环境风貌的影响。

（五）应充分考虑建设施工对黄陵庙安全的影响，制定必要的文物保护措施和应急预案，并注意加强施工过程中的文物安全监测工作，及时发现隐患，确保文物和人员安全。改变地面高程时应充分考虑现状地形地貌特征，合理组织场地排水，尽量保持自然环境风貌，避免形成陡坎。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。请加强工程监管，确保文物及其环境安全。

此复。

国家文物局

2017年1月9日
