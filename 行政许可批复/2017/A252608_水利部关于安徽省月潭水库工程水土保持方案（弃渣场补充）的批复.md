# 水利部关于安徽省月潭水库工程水土保持方案（弃渣场补充）的批复

水保函〔2017〕84号

黄山市月潭水库建设投资有限公司：

你公司《关于申请审批〈安徽省月潭水库工程水土保持方案变更（弃渣场补充）报告〉的请示》（月潭公司〔2017〕7号）收悉。

安徽省月潭水库工程位于安徽省黄山市境内，水库总库容1．6亿立方米。2015年6月，我部以水保函〔2015〕242号文批复了该项目水土保持方案。根据工程建设实际，原批复的2＃弃渣场调整至大坝上游上琳溪。

我部水利水电规划设计总院对《安徽省月潭水库工程水土保持方案变更（弃渣场补充）报告》进行了技术审查，提出了审查意见（详见附件）。经研究，我部基本同意该项目水土保持方案（弃渣场补充）及弃渣场选址。下阶段工作中要严格按照技术规范，开展弃渣场工程设计；复核堆渣容量，查明水文地质条件，确定弃渣场防护措施，确保弃渣场工程安全。

其它仍按我部水保函〔2015〕242号文件要求开展水土流失防治工作。

附件：水规总院关于安徽省月潭水库工程水土保持方案变更（弃渣场补充）报告审查意见的报告（水总环移〔2017〕346号）（略）
