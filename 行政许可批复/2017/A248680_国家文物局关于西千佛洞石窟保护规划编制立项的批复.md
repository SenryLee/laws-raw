# 国家文物局关于西千佛洞石窟保护规划编制立项的批复

## 关于西千佛洞石窟保护规划编制立项的批复

文物保函〔2017〕496号

甘肃省文物局：

你局《关于西千佛洞石窟保护规划立项的报告》（甘文局发〔2016〕186号）收悉。经研究，我局批复如下：

一、同意莫高窟——西千佛洞石窟保护规划编制立项。

二、在规划编制过程中应注意以下问题：

（一）加强历史研究和现状勘察，明确保护对象和规划范围，分析西千佛洞石窟的洞窟形制、文物价值及其与世界文化遗产莫高窟的关系。同时，客观评估文物保存现状、保护管理情况和影响文物安全的主要自然人为因素，在此基础上研提科学、合理、有针对性的规划措施。

（二）应根据文物保护管理需要和周边地形地物特征，科学划定保护区划，制定具有可操作性的管理规定和具体控制指标，充分保护西千佛洞石窟及周边环境的真实性和完整性。

（三）合理确定西千佛洞石窟展示利用的目标、内容和措施，科学进行窟内参观步道系统设计及照明系统设计。同时，应严格控制利用强度，科学核定最大承载量。

（四）规划编制过程中应加强与已有相关规划的衔接，确保规划的可操作性。

（五）根据工作量合理编制经费预算，补充取费标准。

三、请你局指导当地人民政府组织专业机构，按照《国务院关于进一步加强文物工作的指导意见》（国发〔2016〕17号）、《全国重点文物保护单位保护规划编制审批办法》和《全国重点文物保护单位保护规划编制要求》的有关规定，做好西千佛洞石窟保护规划的编制工作。

四、规划编制完成并经你局初审同意后，请将规划文本、图纸及相应的电子文档等报我局审批。

此复。

国家文物局

2017年3月16日
