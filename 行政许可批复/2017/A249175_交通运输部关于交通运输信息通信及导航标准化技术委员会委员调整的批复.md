# 交通运输部关于交通运输信息通信及导航标准化技术委员会委员调整的批复

交科技函〔2017〕262号

交通运输信息通信及导航标准化技术委员会：

你委员会“关于调整信息通信导航标委会主任委员的请示”（信通导〔2017〕9号）收悉。经研究，同意你委员会委员作以下调整：

一、解聘岑晏青主任委员职务，解聘郑和平、王笑京副主任委员职务，解聘邹力、徐斌胜、杨建国、黄习刚、李佑钢、江帆委员职务。

二、增补中国交通通信信息中心曹德胜为主任委员，增补交通运输部海事局王泽龙为副主任委员，调整交通运输部公路科学研究院岑晏青为副主任委员，增补交通运输部科技司高翔、交通运输部海事局宁波、交通运输部规划研究院徐志远、深圳海事局程立民、北京市交通信息中心李民伟、中海电信有限公司支家茂为委员。

交通运输部

2017年4月6日
