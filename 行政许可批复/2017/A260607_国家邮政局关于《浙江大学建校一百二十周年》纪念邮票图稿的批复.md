# 国家邮政局关于《浙江大学建校一百二十周年》纪念邮票图稿的批复

国邮复〔2017〕18号

中国邮政集团公司：

你公司关于报审《浙江大学建校一百二十周年》纪念邮票图稿的文（中国邮政函〔2017〕19号）收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套1枚，内容为：浙江大学建校一百二十周年。发行日期为2017年5月21日。经审查，同意使用该图稿印制邮票。

此复。
