# 国家文物局关于乾陵东、西鹊台遗址环境整治工程立项的批复

## 关于乾陵东、西鹊台遗址环境整治工程立项的批复

文物保函〔2017〕563号

陕西省文物局：

你局《关于上报乾陵东、西鹊台遗址环境整治工程立项的请示》（陕文物字〔2017〕16号）收悉。经研究，我局批复如下：

一、原则同意乾陵东、西鹊台遗址环境整治工程立项。

二、在工程技术方案编制过程中应做好以下工作：

（一）应坚持最小干预原则，做好乾陵东、西鹊台遗址周边的土地平整、地表植被生态治理、场地排水和绿篱界护，严格控制工程规模、范围和强度，合理确定土地平整和地表植被生态治理范围，避免过度整治。

（二）做好前期勘察、评估和研究，补充东、西鹊台之间公路对遗址环境的影响评估，做好工程对乾陵遗址整体视线和景观环境的影响评估，为科学编制保护工程技术方案提供依据。

（三）应慎重采用植被清除措施，植被生态治理措施应考虑与遗址及自然景观相协调，避免人工园林化。

（四）场地排水应注意尽量避免大规模工程干预，以自然排水为主。

（五）进一步校核工程预算，严格控制规模和范围，核减工作量，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年3月24日
