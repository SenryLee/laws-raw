# 国家文物局关于广德寺建设控制地带内建设工程的批复

## 关于广德寺建设控制地带内建设工程的批复

文物保函〔2017〕733号

四川省文物局：

你局《关于报送〈广德寺建设控制地带建设工程设计方案〉的请示》（川文物〔2017〕7号）收悉。经研究，我局批复如下：

一、原则同意在广德寺建设控制地带内进行建设工程和你局意见。

二、对所报方案提出如下修改完善意见：

（一）小寮房距离文物本体过近，对文物影响较大，应根据《广德寺文物保护规划》要求，进一步说明选址依据和原因，尽量另行选址。

（二）细化道路系统规划，结合场地现状合理组织道路，并明确道路级别和建造材料、工艺等技术要求。

（三）根据广德寺使用需求和建筑布局，进一步完善给排水及燃气管线设计，合理确定管线走向，注意避让建筑基础。补充管道挖掘与恢复的具体措施和要求。

（四）深化供配电系统设计内容，细化变压器、照明、弱电等安装措施要求，确保电气设计符合国家相关法律法规和标准规范。

（五）绿化种植应以当地树种为主，注意营造庄严肃穆的寺庙氛围，避免现代化和景观园林化设计倾向。

（六）完善文物影响评估报告，客观评估拟建项目对文物安全和景观环境的影响，准确绘制视线通廊分析图。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后报有关部门审批。请你局加强工程监管，确保文物和人员安全。同时，请你局督促相关部门切实加强管理，确保已发掘遗址安全。

此复。

国家文物局

2017年4月12日
