# 中国证监会关于核准设立汇丰前海证券有限责任公司的批复

## 关于核准设立汇丰前海证券有限责任公司的批复

证监许可〔2017〕954号

前海金融控股有限公司、香港上海汇丰银行有限公司：

你们报送的《关于设立汇丰前海证券有限责任公司的申请》（深前金控发〔2015〕10号）及相关文件收悉。根据《证券法》、《公司法》、《证券公司监督管理条例》、《内地与香港关于建立更紧密经贸关系的安排》（CEPA）补充协议十、《外资参股证券公司设立规则》（证监会令第86号）、《证券公司业务范围审批暂行规定》（证监会公告〔2008〕42号）、《证券发行上市保荐业务管理办法》（证监会令第63号）等有关规定，经审核，现批复如下：

一、核准设立汇丰前海证券有限责任公司（以下简称汇丰前海证券）。汇丰前海证券注册地为深圳市，注册资本为人民币18亿元，业务范围为证券经纪、证券投资咨询、证券承销与保荐，股东名称及出资额、出资比例如下：

|  |  |  |  |
| --- | --- | --- | --- |
|  | 股东名称 | 出资额（亿元） | 出资比例 |
| 1 | 香港上海汇丰银行有限公司 | 9.18 | 51% |
| 2 | 前海金融控股有限公司 | 8.82 | 49% |
|  | 合计 | 18 | 100% |

上述出资中，股东的出资均为货币出资，其中香港上海汇丰银行有限公司以等值美元或者其他可自由兑换货币出资。

二、核准《香港上海汇丰银行有限公司和前海金融控股有限公司有关汇丰前海证券有限责任公司的合资合同》，我会对汇丰前海证券公司章程草案无异议。汇丰前海证券设立后，应当将股东会表决通过的公司章程报住所地证监局核准。

三、你们应当按照《公司法》、《证券法》、《证券公司监督管理条例》、CEPA补充协议十、《外资参股证券公司设立规则》、《关于实施〈外资参股证券公司设立规则〉和〈外资参股基金管理公司设立规则〉有关问题的通知》（证监发〔2002〕86号）等法律、法规和有关规定的要求，自本批复下发之日起30日内向商务部申领《外商投资企业批准证书》；完成汇丰前海证券组建工作，足额缴付出资，选举董事、监事，聘任高级管理人员。

四、你们应当自本批复下发之日起6个月内完成汇丰前海证券的工商设立登记工作；逾期未完成的，本批复自动失效。

汇丰前海证券应当自取得营业执照之日起15日内，向我会申请经营证券期货业务许可证。汇丰前海证券在取得经营证券期货业务许可证前，不得以该名称对外开展业务。

五、汇丰前海证券组建中如遇重大问题，须及时报告我会和汇丰前海证券拟设地证监局。

中国证监会

2017年6月19日
