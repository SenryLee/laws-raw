# 国家文物局关于2017年度广东（南海）海域水下考古调查工作方案的批复

文物保函〔2017〕1573号

广东省文物局：

你局《关于2017年度广东（南海）海域水下考古调查工作方案的请示》（粤文物请〔2017〕20号）收悉。经研究，我局批复如下：

一、原则同意所报2017年度广东（南海）海域水下考古调查工作方案和你局意见。

二、该方案应进行以下必要的补充、完善：

（一）应根据项目工作进度与时间安排，合理确定工作区域，根据实际情况调整调查范围，进一步细化调查的实施步骤和技术路线，确保工作质量。

（二）应科学总结和吸收该区域水下考古工作经验和成果，做好与上、下川岛海域调查工作的衔接。

（三）应制定详细的物探和潜水工作计划、出水文物保护方案、工作现场安全预案，切实加强紧急情况、突发事件的管控能力，确保人员与文物安全。

三、请你局指导有关单位，根据以上意见对2017年度广东（南海）海域水下考古调查工作方案进行补充、完善，经你局核准后实施。

四、请你局加强管理，确保工作质量和人员、文物安全。遇有重要发现，应及时向我局报告。考古工作结束后，应向我局报告本年度工作情况。

国家文物局

2017年9月1日
