# 国家文物局关于净光寺塔修缮工程立项的批复

## 关于净光寺塔修缮工程立项的批复

文物保函〔2017〕81号

陕西省文物局：

你局《关于净光寺塔修缮工程立项的请示》（陕文物字〔2016〕216号）收悉。经研究，我局批复如下：

一、同意净光寺塔修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属文物修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为净光寺塔文物建筑及院落。

（三）加强现状勘察，明确文物保存现状、塔体构造、残损情况等，分析塔身残损、塔基酥碱受潮等病害原因，客观评估2001年塔体纠偏加固工程效果，在此基础上优化调整修缮措施。补充2001年地勘资料和塔体纠偏后的文物变形监测资料。

（四）应深入研究和分析净光寺塔的建造工艺、传统做法、建筑材料和构造特征等，注意在维修中使用原工艺和原材料。

（五）应严格控制工程范围和工程量，以现状整修为主，合理确定砖石构件更换、补配的具体数量和标准，避免过度维修。应根据塔体现状，研究确定修补范围、技术要求和维修效果，并结合文物保护需要，统筹考虑场地排水和净光寺塔周围散水铺墁的具体要求和做法。论证再次地勘的必要性。

（六）规范文本和图纸，细化现状图和设计图标注。

（七）根据工程量合理编制经费预算，补充各单项费用取费依据，进一步核减地形测绘等前期勘察费用。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案，并组织或委托第三方咨询评估机构进行方案技术评审，依据评估意见进行审批。

此复。

国家文物局

2017年1月20日
