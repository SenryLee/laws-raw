# 中国证监会关于核准太平基金管理有限公司变更股权的批复

## 关于核准太平基金管理有限公司变更股权的批复

证监许可〔2017〕1297号

太平基金管理有限公司：

你公司报送的《太平基金管理有限公司关于变更重大事项的申请报告》（太平基金〔2016〕第168号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

一、核准太平资产管理有限公司认购你公司的新增注册资本。认购完成后，你公司股权结构为：

人民币 元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 太平资产管理有限公司 | 332,000,000 | 83% |
| 2 | 中原证券股份有限公司 | 34,000,000 | 8.5% |
| 3 | 安石投资管理有限公司 | 34,000,000 | 8.5% |
|  | 合计 | 400,000,000 | 100% |

二、你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2017年7月20日
