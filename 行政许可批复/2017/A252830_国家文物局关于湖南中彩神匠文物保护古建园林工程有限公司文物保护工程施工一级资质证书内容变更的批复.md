# 国家文物局关于湖南中彩神匠文物保护古建园林工程有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于湖南中彩神匠文物保护古建园林工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕484号

湖南省文物局：

你局《关于湖南中彩神匠文物保护古建园林工程有限公司变更文物保护工程施工一级资质证书公司名称等内容的请示》（湘文物报〔2017〕35号）收悉。

经研究，我局同意湖南中彩神匠文物保护古建园林工程有限公司文物保护工程施工一级资质证书中的单位名称由“湖南中彩神匠文物保护古建园林工程有限公司”变更为“湖南神匠古建园林工程有限公司”，注册资金由“600万元”变更为“2056万元”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局

2017年4月20日
