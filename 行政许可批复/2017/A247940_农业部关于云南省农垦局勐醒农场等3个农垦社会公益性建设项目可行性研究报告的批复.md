# 农业部关于云南省农垦局勐醒农场等3个农垦社会公益性建设项目可行性研究报告的批复

农计发〔2017〕3号

云南省农垦局:

《云南省农垦局关于2017年3个农垦公益性建设项目可行性研究报告的请示》(云垦局专报〔2016〕29号)收悉。经研究，原则同意下列项目可行性研究报告。

1.勐醒农场场部小城镇基础设施建设项目，建设地点位于云南省西双版纳傣族自治州勐腊县勐醒农场场部。主要建设内容为改造场部主干道1326米、支干道477米、建设人行道3890米，铺设给水管道5000米、消防管道3185米，安装路灯92套等。总投资945万元，其中中央预算内投资755万元，地方投资190万元（详见附件1）。

2.勐捧农场场部小城镇基础设施建设项目，建设地点位于云南省西双版纳傣族自治州勐腊县勐捧农场场部。主要建设内容为新建场部道路936米、人行道936米，改造道路800米，敷设给排水管道3331米，安装路灯52套等。总投资1030万元，其中中央预算内投资825万元，地方投资205万元（详见附件2）。

3.孟定农场场部小城镇基础设施建设项目，建设地点位于云南省临沧市耿马傣族佤族自治县孟定农场场部。主要建设内容为新建场部道路656米、人行道887米，拓宽道路227米，配套建设路灯106套、种植绿化树木640株、垃圾转运站1个、收集站5个，铺设给水管道8450米、污水管道4257米等。总投资995万元，其中中央预算内投资795万元，地方投资200万元（详见附件3）。

上述项目建设期均为2年，自投资计划下达之日起计算。

请据此批复，督促建设单位抓紧委托有资质的勘察设计单位编制项目初步设计报你局审批。请严格按照农业基本建设项目管理规定，做好项目组织实施工作，并按月在农业建设项目管理信息系统（http://ac.agri.gov.cn）和投资项目在线审批监管平台（国家重大建设项目库模块，http://kpp.ndrc.gov.cn）中填报实施进度等相关信息。

附件：1.云南农垦勐醒农场场部小城镇基础设施建设项目可行性研究报告批复表

2.云南农垦勐捧农场场部小城镇基础设施建设项目可行性研究报告批复表

3.云南农垦孟定农场场部小城镇基础设施建设项目可行性研究报告批复表
