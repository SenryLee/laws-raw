# 农业部关于吉林省吉林精气神有机农业股份有限公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕52号

吉林省农业委员会：

《吉林省农业委员会关于呈报2017年数字农业建设试点项目的函》（吉农计函〔2017〕6号）收悉。经研究，批复如下：

一、原则同意上报的吉林精气神有机农业股份有限公司数字农业建设试点项目可行性研究报告。项目建设单位为吉林精气神有机农业股份有限公司，建设地点为吉林省白山市抚松县。项目建设期2年。

二、项目建设内容：一是生产硬件设备购置，包括供热系统、自动饲喂系统、报警系统等；二是数字智能化养猪环境控制系统建设，包括温湿度监控系统、氨气监控系统、硫化氢监控系统等；三是数字化精准饲喂管理系统建设，包括数字化发情鉴定系统、妊娠诊断系统、仔猪饲喂系统等；四是粪污环保处理系统建设，包括猪群废弃物产量动态监控系统、废弃物养分数字化动态调控系统等。

三、项目建设目标：项目建成后，实现自动化、数字化、智能化、机械化现代养猪生产，项目区母猪配种率提高到90%，提高劳动生产率350%，商品育肥猪新增经济效益220元/头。

四、项目投资及来源：经评估核定，项目估算总投资3712万元，其中中央预算内投资按1114万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你省申报后续数字农业建设试点项目的资格。

农业部
