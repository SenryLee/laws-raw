# 国家文物局关于北海近代建筑——涠洲城仔教堂、盛塘天主堂修缮工程立项的批复

## 关于北海近代建筑——涠洲城仔教堂、盛塘天主堂修缮工程立项的批复

文物保函〔2017〕85号

广西壮族自治区文化厅：

你厅《关于报送北海近代建筑——涠洲城仔教堂修缮工程立项报告的请示》（桂文物报〔2016〕49号）、《关于报送北海近代建筑——涠洲盛塘天主堂修缮工程立项报告的请示》（桂文物报〔2016〕50号）收悉。经研究，我局批复如下：

一、同意涠洲城仔教堂、涠洲盛塘天主堂修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质为文物修缮工程。

（二）工程范围为涠洲城仔教堂、盛塘天主堂文物建筑。

（三）加强现状勘察，调查记录文物建筑原始形态、构造、材料等信息，全面评估后期局部拆改、材料更新对文物价值、建筑结构稳定性等方面的影响，在此基础上制定有针对性的保护措施。

（四）坚持“最小干预”和“不改变文物原装”原则，严格控制工程规模和工程量，避免过处修缮。

（五）方案应该兼顾文物今后的保护展示需求，同时针对工程竣工后的日常保护管理提出必要措施和要求。

三、请你厅指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你厅组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年1月20日
