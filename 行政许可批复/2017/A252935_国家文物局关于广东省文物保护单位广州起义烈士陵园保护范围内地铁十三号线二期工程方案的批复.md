# 国家文物局关于广东省文物保护单位广州起义烈士陵园保护范围内地铁十三号线二期工程方案的批复

## 关于广东省文物保护单位广州起义烈士陵园保护范围内地铁十三号线二期工程方案的批复

文物保函〔2017〕1011号

广东省文物局：

你局《关于在广东省文物保护单位广州起义烈士陵园保护范围内地铁十三号线二期工程方案的请示》（粤文物审〔2017〕36号）收悉。经研究，我局批复如下：

一、原则同意所报选线方案。

二、对选线方案提出以下修改意见：

（一）根据岩土层的物理力学性质及均匀性和文物本体对变形的敏感性，采取超常规的防护措施，确保文物的安全。

（二）在保护范围内采用盾构开挖施工时，应合理确定盾构推进的施工系数、质量标准和技术要求，正确设定平衡压力和推进速度，减少超挖与欠挖现象，控制好盾构姿态，加强同步和二次注浆，控制好注浆量和注浆压力，消除施工中影响文物安全的隐患。

（三）对在建设控制地带的车站采取暗挖矿山法施工时，应采取措施减少对隧道壁岩土层的扰动，根据地质条件、隧道断面，合理确定分部施工方法，做好临时支撑加固，必要时可结合新奥法加固岩土体，严禁超挖和欠挖，在岩石中施工时，应控制爆破药量，防止振动对文物的损坏。

（四）应对施工或运营期间的振动进行监测评估，轨道列车运行的振动影响可考虑按可感振动的尺度（不大于1mm/s）进行监测控制，不宜按古建筑砖砌体结构与木结构的容许振动速度限值标准（《古建筑防工业振动技术规范》GB/T 50452-2008）。该段路轨设计应采取轨道综合减振降噪措施，尽量减少对文物建筑的影响。

（五）应建立完整的监测系统，加大地表及文物本体变形监测频率，制定防灾预案，必要时对文物本体进行预加固处理。

（六）施工过程中如发现地下文物遗存，应立即停止施工并依法进行妥善处理。

三、请你局指导相关单位根据上述意见对方案进行修改完善，经你局核准后实施。工程施工期间，应加强对工程的监管，确保文物安全。

此复。

国家文物局

2017年5月22日
