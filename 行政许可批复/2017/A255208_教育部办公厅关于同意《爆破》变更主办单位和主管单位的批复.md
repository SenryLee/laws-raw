# 教育部办公厅关于同意《爆破》变更主办单位和主管单位的批复

教技厅函〔2017〕93号

武汉理工大学：

《武汉理工大学关于〈爆破〉杂志主办单位变更、主管单位变更、法定代表人变更的请示》（校科函〔2017〕37号）收悉。经研究，同意《爆破》的主办单位由湖北省爆破学会、武汉理工大学变更为武汉理工大学，主管单位由湖北省科学技术协会变更为中华人民共和国教育部。请尽快到新闻出版管理部门办理相关手续。

专此。

教育部办公厅

2017年8月22日
