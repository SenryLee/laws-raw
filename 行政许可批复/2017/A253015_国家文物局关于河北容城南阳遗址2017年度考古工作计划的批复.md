# 国家文物局关于河北容城南阳遗址2017年度考古工作计划的批复

## 关于河北容城南阳遗址2017年度考古工作计划的批复

文物保函〔2017〕879号

河北省文物局：

你局《关于呈报容城南阳遗址2017年考古工作计划的请示》（冀文物字〔2017〕83号）收悉。经研究，我局批复如下：

一、该项考古工作为进一步搞清容城南阳遗址性质、范围和布局，推进遗址保护利用提供重要基础支撑，对雄安新区的建设规划具有重要意义。请你局指导有关单位，尽快开展相关工作。

二、考古工作应以大面积调查、勘探为主，以小面积发掘为辅，发掘面积应控制在500平方米以内。发掘前应按规定填报考古发掘申请书。注意加强多学科合作研究。应考虑建立南阳遗址考古地理信息系统，为开展长期考古和保护工作奠定基础。

三、请你局加强人员队伍、工作经费和新闻宣传管理，协调地方政府和相关部门做好服务保障，确保考古工作顺利实施。考古工作中遇有重要发现，应及时向我局报告。

国家文物局

2017年4月28日
