# 国家文物局关于湖南大学早期建筑群——湖南大学二院、第七学生宿舍、第九学生宿舍修缮工程立项的批复

## 关于湖南大学早期建筑群——湖南大学二院、第七学生宿舍、第九学生宿舍修缮工程立项的批复

文物保函〔2017〕177号

湖南省文物局：

你局《关于湖南大学早期建筑群——湖南大学二院、第七学生宿舍、第九学生宿舍修缮工程立项的请示》（湘文物报〔2016〕190号）收悉。经研究，我局批复如下：

一、同意湖南大学二院、第七学生宿舍、第九学生宿舍修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质为文物修缮工程。

（二）工程范围为湖南大学二院、第七学生宿舍、第九学生宿舍文物建筑。

（三）深入开展现状勘察，准确掌握病害性质、成因及残损范围、程度，补充对各楼主体结构和木屋架的专项检测及评估，同时调查记录拟修缮部位的原始建造工艺、材料，为制定有针对性的保护措施提供科学依据。

（四）坚持最小干预原则，严格控制工程规模和工程量，最大限度地保留文物历史信息。

（五）明确文物今后的用途，建筑荷载控制、空间复原与改造等设计应充分考虑今后的使用需求。基础设施改造应与修缮工程同步实施，避免对文物的二次扰动。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年2月7日
