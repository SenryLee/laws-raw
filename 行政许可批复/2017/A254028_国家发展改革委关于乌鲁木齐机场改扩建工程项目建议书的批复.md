# 国家发展改革委关于乌鲁木齐机场改扩建工程项目建议书的批复

发改基础〔2017〕1480号

新疆自治区发展改革委：

报来《关于审核〈乌鲁木齐国际机场北区改扩建工程预可行性研究报告〉的请示》（新发改交通〔2017〕385号）及有关材料收悉。经研究，现批复如下：

一、为进一步加快乌鲁木齐国际航空枢纽建设，提升机场综合保障能力和服务水平，适应航空业务量快速增长需要，促进新疆地区经济社会协调发展，同意实施乌鲁木齐机场改扩建工程。

二、本期工程总体设计目标年为2030年，飞行区设施按满足2030年旅客吞吐量6300万人次、货邮吞吐量75万吨的目标一次建成，航站区按满足2025年旅客吞吐量4800万人次、货邮吞吐量55万吨的目标建设，预留发展条件。主要建设内容包括：

（一）机场工程：飞行区等级指标4F，在现有跑道（第一跑道）北侧1830米新建长3600米、宽60米的第二跑道，双向设置I类精密进近系统；在第二跑道北侧380米处新建长3200米、宽60米的第三跑道，主降方向设置Ⅲ类精密进近系统，次降方向设置I类精密进近系统；新建45万平方米的北区航站楼、180个机位的站坪，以及机务维修、消防救援等辅助生产生活设施，配套建设供电、给排水、供热、制冷、供气等设施，同步建设综合交通中心和停车楼。

（二）空管工程：新建1座塔台及2.77万平方米的业务用房和1.29万平方米的终端管制中心用房，更新1套二次雷达、新建2套场面监视雷达，配套建设管制、通信、导航、监视、气象等设施。

（三）供油工程：新建4个2万立方米的航油储罐、1座航空加油站、1座特种车辆加油站，以及机坪加油管线、场外输油管线、场外汽车加气加油站，扩建西山油库等。

三、项目总投资410.5亿元（暂含综合交通中心和停车楼投资），其中，机场工程383.9亿元，原则上由我委、民航局、新疆自治区政府和新疆机场集团有限公司共同筹措解决；空管工程18.3亿元，由民航局安排民航发展基金解决；供油工程8.3亿元，由中国航空油料集团公司筹措解决。具体资金安排在可行性研究阶段确定。

四、在后续阶段，要重点做好以下工作：

（一）积极与西部战区空军协调，抓紧推进空军昌吉机场搬迁以及周边空域调整工作，以满足本期扩建后机场空域使用需求。

（二）进一步优化机场地势设计方案以及机场、空管、供油工程建设方案，有效控制土方工程量和建设投资。

（三）完善机场集疏运系统规划，强化机场近远期与其他交通方式的有机衔接，明确城市轨道交通建设方案，论证城际铁路接入机场的必要性和可行性，研究论证综合交通中心和停车楼的建设规模和标准，确保机场及其集疏运系统同步建成，充分发挥机场综合交通枢纽作用。

（四）抓紧研究落实项目资金筹措方案，拓宽融资渠道，优化投资结构，为项目建设及后续进场运营提供必要的资金保障。
