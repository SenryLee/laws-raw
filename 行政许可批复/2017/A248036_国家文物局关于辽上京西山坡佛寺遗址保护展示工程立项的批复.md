# 国家文物局关于辽上京西山坡佛寺遗址保护展示工程立项的批复

## 关于辽上京西山坡佛寺遗址保护展示工程立项的批复

文物保函〔2017〕374号

内蒙古自治区文物局：

你局《关于辽上京西山坡佛寺遗址保护展示立项报告的请示》（内文物发〔2016〕302号）收悉。经研究，我局批复如下：

一、原则同意辽上京西山坡佛寺遗址保护展示工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，注意控制工程规模、范围和强度，减少对遗址的干预，避免过度展示。相关展示设施应简洁可逆，不得损害遗址本体。

（二）切实做好前期勘察、研究和试验，对遗址进行详细病害调查，查明病害类型及成因，评估病害对遗址的危害程度，为科学编制工程方案提供依据。

（三）展示方式宜选用模拟展示或标识展示，不同意对遗址进行覆罩展示。

（四）进一步加强遗址考古与研究工作，明确遗址形制，加强遗址功能研究和价值内涵的阐释，以增强对遗址展示设计的支撑。涉及考古发掘的内容需另行填报考古发掘申请书。

（五）严格控制工程预算，进一步梳理并控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局
