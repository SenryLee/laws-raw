# 国家文物局关于在省级文物保护单位新坡许氏宗祠保护范围内进行许志杰、许志锋、许云忠等三处房屋拆建项目的批复

## 关于在省级文物保护单位新坡许氏宗祠保护范围内进行许志杰、许志锋、许云忠等三处房屋拆建项目的批复

文物保函〔2017〕1233号

广东省文物局：

你局《关于在广东省文物保护单位新坡许氏宗祠保护范围内许志杰、许志锋、许云忠等三处房屋拆建工程方案的请示》（粤文物审〔2017〕69号）收悉。经研究，我局批复如下：

一、原则同意在新坡许氏宗祠保护范围内进行许志杰、许志锋、许云忠等三处房屋拆建项目和你局意见。

二、对所报方案提出如下修改完善意见：

（一）所报项目位于广东省文物保护单位新坡许氏宗祠保护范围内，须严格遵守《中华人民共和国文物保护法》和广东省人民政府关于新坡许氏宗祠的相关管理规定，以确保文物本体和历史环境安全为前提，合理兼顾民生改善。

（二）应根据保护区划管理规定和具体控制指标，进一步调整方案设计，拟新建房屋应按照原有建筑面积、高度进行拆建，采用地方传统建筑样式和工艺材料，整体色彩应与文物本体及周边风貌相协调。建议在不超过高度控制要求的前提下，尽量保持原有坡屋顶的建筑形制。

（三）应制定房屋拆建过程中的文物安全保护措施和应急预案，确保文物和人员安全。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后按程序报有关部门批准实施。请加强对工程的监管，确保文物及其环境安全。

此复。

国家文物局

2017年7月17日
