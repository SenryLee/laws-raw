# 国家文物局关于南昌西汉海昏侯墓园2号墓2017年度考古工作方案的批复

## 关于南昌西汉海昏侯墓园2号墓2017年度考古工作方案的批复

文物保函〔2017〕863号

江西省文物局：

你局《关于呈报〈江西南昌西汉海昏侯墓园2号墓2017年考古发掘工作方案〉的请示》（赣文物局字〔2017〕60号）收悉。经研究，我局批复如下：

一、原则同意所报南昌西汉海昏侯墓园2号墓2017年度考古工作方案和你局意见。

二、该方案应进行以下补充、完善：

（一）补充2号墓相关陵寝建筑遗迹的考古工作方案，注意进一步解决汉代诸侯陵寝制度等问题。

（二）完善信息记录方案，尽可能详细地记录好封土的形状、大小、夯筑方式、夯层等信息，完善各类考古制图的要求。

（三）充分吸取海昏侯墓考古发掘的经验，进一步细化出土文物保护方案，完善多学科参与的工作模式。

三、请你局指导有关单位，根据以上意见对南昌西汉海昏侯墓园2号墓2017年度考古工作方案进行补充、完善，经你局核准后实施。请你局加强管理，确保工作质量和工地安全，遇有重要发现，应及时向我局报告。考古工作结束后，应向我局报告本年度工作情况。

国家文物局

2017年4月26日
