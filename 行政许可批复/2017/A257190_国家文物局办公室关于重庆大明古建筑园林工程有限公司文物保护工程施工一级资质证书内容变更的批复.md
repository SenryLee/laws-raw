# 国家文物局办公室关于重庆大明古建筑园林工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕1200号

重庆市文物局：

你局《关于变更重庆大明古建筑园林工程有限公司资质证书内容的请示》（渝文物〔2017〕255号）收悉。

经研究，我局同意重庆大明古建筑园林工程有限公司文物保护工程施工一级资质证书中的单位地址由“重庆市沙坪坝区晒广坪69-5号”变更为“重庆市沙坪坝区晒光坪69-5号”，注册资金由“600万元”变更为“2000万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2017年10月25日
