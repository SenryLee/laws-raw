# 国家文物局关于高岭瓷土矿遗址1号矿洞周边滑坡和地面开裂区抢险加固工程立项的批复

## 关于高岭瓷土矿遗址1号矿洞周边滑坡和地面开裂区抢险加固工程立项的批复

文物保函〔2017〕917号

江西省文物局：

你局《关于呈报〈湖田古瓷窑址—高岭瓷土矿遗址1号矿洞周边与老厂沟抢险加固工程立项报告〉的请示》（赣文物局字〔2016〕201号）收悉。经研究，我局批复如下：

一、原则同意湖田古瓷窑址—高岭瓷土矿遗址1号矿洞周边滑坡和地面开裂区抢险加固工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以消除安全隐患为目的，做好1号矿洞周边滑坡和地面开裂区抢险加固，注意控制工程规模、范围和强度，避免过度保护。

（二）加强前期勘察、研究和试验，开展1号矿洞周边地质灾害调查和评估，查清区内地质灾害的类型、发育程度和破坏特征，了解1号洞采矿巷道和采空区的现状，明确地质灾害与1号矿洞的相关性，分析地质灾害的成因，为科学制定地质灾害治理措施提供依据。

（三）工程措施应注意与周边环境相协调，补充格构护坡措施对遗址环境的影响评估，可考虑采用隐蔽抗滑桩，工程技术措施应进行试验、筛选之后合理确定。

（四）1号矿洞口木亭、拦水坝的桥、亭的修复不属于抢险加固工程，不应纳入此次工程内容。

（五）严格控制工程预算，进一步梳理并控制工程规模和范围，核减测绘费用，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局
