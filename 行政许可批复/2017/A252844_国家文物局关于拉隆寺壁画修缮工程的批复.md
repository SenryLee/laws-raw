# 国家文物局关于拉隆寺壁画修缮工程的批复

## 关于拉隆寺壁画修缮工程的批复

文物保函〔2017〕892号

西藏自治区文物局：

你局《关于拉隆寺壁画修缮保护方案评审的请示》（藏文物字〔2017〕78号）收悉。经研究，我局批复如下：

一、原则同意所报拉隆寺壁画修缮工程和你局意见。

二、对该方案提出以下修改意见：

（一）应加强前期试验检测分析工作，补充灌浆材料试验检测数据，进一步明确筛选试验所确定的保护材料成分，根据地仗分析结果科学选择裂隙填补材料。

（二）坚持最小干预原则，严格控制工程范围和强度，完善工程做法，细化修缮措施。

1. 应针对藏式壁画特点，进一步加强保护措施适用性分析，确保措施的有效性和科学性；不宜采用喷涂粘合剂的方法检查起甲壁画加固效果。

2. 壁画揭取加固后，不宜采用背板悬挂方式，可考虑采用回贴保护方式。

3. 应在脱盐处理后进行裂缝填补，并注意隔绝毛细水上升，尽量减少毛细水对壁画安全的影响。

4. 补充微生物病害治理措施，壁画补色应注意可识别性。

（三）进一步明确工程分期，建议根据壁画病害程度、文物价值、绘制年代等综合确定现场试验修复区域，现阶段可先行开展措钦大殿一层东、西壁和二层壁画维修工作，排除险情，并进一步验证拟采用措施的有效性和安全性。同时，应根据修复效果评估结论和验收意见及时调整方案，确保工程质量。

（四）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，妥善处理维修保护与宗教活动管理等关系，保证文物日常维护的顺利开展。

（五）根据工程量合理编制经费预算，进一步核减工程造价，补充各单项取费依据。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2017年4月28日
