# 国家文物局关于未名湖燕园建筑——办公楼文物建筑修缮工程立项的批复

## 关于未名湖燕园建筑——办公楼文物建筑修缮工程立项的批复

文物保函〔2017〕747号

北京市文物局：

你局《关于未名湖燕园建筑——办公楼文物建筑修缮工程立项的请示》（京文物〔2016〕1792号）收悉。经研究，我局批复如下：

一、同意未名湖燕园建筑办公楼修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）工程范围为办公楼文物建筑。

（三）补充开展工程地质勘察和文物建筑结构安全鉴定，为制定保护措施提供科学依据。

（四）坚持最小干预原则，严格控制工程范围和工程量，并注意加强对建筑细部特征、各类型符号及特殊构件的保护。

（五）调整工程预算，剔除装修等非文物修缮费用。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制修缮工程技术方案；由你局组织专家或委托专业评估机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年4月12日
