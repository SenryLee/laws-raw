# 国家文物局关于乌鲁木齐陕西大寺大殿修缮工程立项的批复

## 关于乌鲁木齐陕西大寺大殿修缮工程立项的批复

文物保函〔2017〕79号

新疆维吾尔自治区文物局：

你局《关于报送〈陕西大寺大殿修缮工程立项报告〉的请示》（新文物保发〔2016〕158号）收悉。经研究，我局批复如下：

一、同意乌鲁木齐陕西大寺大殿修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为乌鲁木齐陕西大寺大殿文物建筑及院落。

（三）加强现状勘察和研究，明确文物保存现状、主要病害类型、残损情况等，查找屋面漏雨、木构件糟朽、台基不均匀沉降等病害原因，在此基础上制定有针对性的修缮措施。补充说明文物周边环境和现状地面排水情况。

（四）应加强当地建筑做法和传统工艺特色的研究分析，并注意在工程中采用原材料、原工艺。

（五）应严格控制工程量和工程强度，合理确定木构件更换、补配的具体数量和标准，避免过度维修。进一步细化工程措施，明确台基、院落地面修缮做法和要求，并结合台基、院落修缮，科学布设排水设施，避免影响文物安全。应兼顾乌鲁木齐陕西大寺日常使用和宗教活动需要，合理进行建筑内部空间设计，妥善处理文物保护与宗教活动需求的关系。

（六）更换下的原构件应详细测绘、登记、评估价值，妥善保管；各类工程资料应由专人管理、建档，并在工程结束后纳入乌鲁木齐陕西大寺大殿记录档案。

（七）应注意吸纳管理使用单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（八）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案；组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年1月20日
