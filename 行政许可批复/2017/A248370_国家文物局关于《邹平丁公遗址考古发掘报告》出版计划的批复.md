# 国家文物局关于《邹平丁公遗址考古发掘报告》出版计划的批复

## 关于《邹平丁公遗址考古发掘报告》出版计划的批复

文物保函〔2017〕420号

山东省文物局：

你局《关于申请邹平丁公遗址考古发掘报告出版立项的请示》（鲁文发〔2017〕14号）收悉。经研究，我局同意所报《邹平丁公遗址考古发掘报告》的出版计划。

请你局按照《国家重点文物保护专项补助资金管理办法》的规定和我局有关要求，另行申请该书的出版补助经费。

国家文物局

2017年3月2日
