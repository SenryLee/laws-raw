# 国家文物局关于塔虎城城墙遗址本体加固保护工程立项的批复

## 关于塔虎城城墙遗址本体加固保护工程立项的批复

文物保函〔2016〕2134号

吉林省文物局：

你局《关于塔虎城本体保护修缮工程立项的请示》（吉文物发〔2016〕214号）收悉。经研究，我局批复如下：

一、原则同意塔虎城城墙遗址本体加固保护工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，做好城墙遗址本体暴露部分的结构补夯和冻融防治，不同意深根系植被清理和绿化固土措施，暂缓开展展示利用工程，并注意控制工程规模、范围和强度，减少对遗址的干预，避免过度保护展示。

（二）切实做好前期勘察、研究和试验，对遗址进行详细病害调查，查明病害类型及成因，评估病害对遗址的危害程度，为科学编制工程方案提供依据。

（三）工程措施和材料应尽量符合传统工艺，尽量采用物理方法减缓文物本体的损坏，不宜采用化学保护方法。

（四）涉及考古发掘的内容，应按要求另行填报考古发掘申请书。

（五）进一步校核工程预算，控制工程规模和范围，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

四、请你局督促地方人民政府切实加强塔虎城的保护和管理，做好日常巡查和看护，确保文物安全。

国家文物局

2017年1月4日
