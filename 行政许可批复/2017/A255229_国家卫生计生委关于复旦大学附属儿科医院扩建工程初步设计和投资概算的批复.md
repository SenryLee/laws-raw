# 国家卫生计生委关于复旦大学附属儿科医院扩建工程初步设计和投资概算的批复

国卫规划函〔2017〕298号

复旦大学附属儿科医院：

你院《关于报请审批扩建工程初步设计和投资概算的请示》（复儿办〔2017〕65号）收悉。经研究，原则同意你院扩建工程初步设计和投资概算。该工程总建筑面积68,136平方米（地上建筑面积44,064平方米，地下建筑面积24,072平方米），其中，住院综合楼建筑面积57,443平方米（地上建筑面积34,996平方米，地下建筑面积22,447平方米），教学综合楼建筑面积10,206平方米（地上建筑面积8,581平方米，地下建筑面积1,625平方米），35KV降压站建筑面积487平方米。工程概算总投资64,672万元。资金来源为申请中央预算内投资、上海市市级建设财力资金和医院自筹资金共同解决。

请你院按照国家有关规定，严格执行基本建设程序，落实项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计和投资概算，抓紧组织开展下一步工作。

此复。

国家卫生计生委

2017年8月21日
