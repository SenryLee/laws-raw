# 农业部关于变更辽宁省渔业捕捞许可签发人的批复

农渔发〔2017〕26号

辽宁省海洋与渔业厅：

你厅《关于申请变更辽宁省渔业捕捞许可签发人及修改我省在中国渔政管理指挥系统中相关信息的请示》（辽海渔船字〔2017〕135号）收悉。根据《渔业捕捞许可管理规定》第三十八条，经研究，同意将辽宁省渔业捕捞许可签发人变更为刘林林，有效期至2020年12月31日。陈全玺的渔业捕捞许可签发人资格自发文之日起终止。

特此批复。

农业部

2017年5月23日
