# 国家文物局关于变更考古发掘资质证书的批复

文物保函〔2017〕1771号

安徽省文物局：

你局《关于变更安徽省考古研究所发掘资质证书的请示》（皖文物保〔2017〕80号）收悉。

经研究，我局同意变更安徽省文物考古研究所考古发掘资质证书法定代表人为邓峰，并更换《中华人民共和国考古发掘资质证书》。请你局通知有关单位，携原资质证书正、副本来我局办理更换手续。

国家文物局

2017年10月26日
