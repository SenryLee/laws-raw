# 国家文物局关于炳灵寺石窟何灌题记保护与展示项目的批复

文物保函〔2017〕1678号

甘肃省文物局：

你局《关于呈报炳灵寺石窟何灌题记保护与展示设计方案的报告》（甘文局发〔2017〕128号）收悉。经研究，我局批复如下：

一、原则同意所报炳灵寺石窟何灌题记保护与展示项目和你局意见。

二、对该项目提出以下意见：

（一）进一步加强现状勘察和研究。补充表面温度的监测数据，以评估现有防护设施的有效性，并为防护罩的设计提供依据。

（二）进一步论证、完善主要的保护加固技术措施。按照对1992年PS加固效果的评估，分析渗透深度的增加能否从根本上解决加固层与未加固层的性质差异及界面病害发展问题，再行审慎论证继续使用PS加固的合理性；进一步论证采用表面溶解吸收方法治理岩体内部微溶盐硫酸钙问题的有效性，建议和固盐思路进行比选；表面泥渍不仅富含硫酸钙，还改变岩石透气透水性质，建议考虑清除。

（三）补充详细的防护罩设计图纸，应防止上方泥水挂流到题刻表面，并与环境协调一致。

（四）注意做好各类工程资料提取和档案留存工作。

（五）应做好修缮项目与监测运营工作的衔接。

（六）补充必要的施工要求和临时性保护措施，确保施工过程中人员和文物安全。

（七）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护和监测的顺利开展。

三、具体方案由你局根据上述意见指导相关单位修改、完善并经你局批准后组织实施。

四、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物安全。

五、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

六、请你局切实加强管理，督促、指导相关单位做好题记保护后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年9月25日
