# 国家文物局关于何园读书楼、复道回廊修缮工程立项的批复

## 关于何园读书楼、复道回廊修缮工程立项的批复

文物保函〔2017〕526号

江苏省文物局：

你局《关于审批何园局部修缮工程立项的请示》（苏文物保〔2017〕32号）收悉。经研究，我局批复如下：

一、同意何园读书楼、复道回廊修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属文物修缮工程和白蚁防治工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程内容为何园读书楼、复道回廊修缮和院落白蚁防治。

（三）加强现状勘察和研究，明确文物主要病害类型、残损情况等，深入分析屋面漏雨、木构件糟朽、白蚁等病害原因，客观评估已实施的文物保护工程效果，进一步明确工程范围和修缮思路。补充说明何园文物建筑现状白蚁病害情况。

（四）应深入研究和分析地方建造工艺、传统做法、建筑材料和构造特征，注意在维修中使用原工艺和原材料。

（五）应明确工程范围，严格控制工程量和工程强度，明确木构件更换、补配的具体数量和标准，尽可能保留和使用原有构件；室内地砖不应全部更换。补充白蚁防治措施，做好虫害治理与文物修缮工程之间的衔接。各类工程资料应由专人管理、建档，并在工程结束后纳入何园记录档案。

（六）暂不同意牡丹厅、船厅、蝴蝶厅、桂花厅、赏月楼、楠木厅、祠堂等7座文物建筑修缮工程立项。应根据文物保存现状和病害程度，区分轻重缓急，有计划、分阶段开展文物建筑保护工作。

（七）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案，组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

四、排水系统整修工程应按照我局《关于何园修缮工程立项的批复》（文物保函〔2014〕1088号）要求，组织有关单位抓紧实施。

五、请你局督促地方人民政府切实加强何园日常保养和岁修工作，落实管理维护责任，确保文物安全。

专此函。

国家文物局

2017年3月21日
