# 国家文物局关于福庆寺藏经楼修缮工程立项的批复

## 关于福庆寺藏经楼修缮工程立项的批复

文物保函〔2017〕411号

河北省文物局：

你局《关于福庆寺藏经楼抢险加固工程立项的请示》（冀文物字〔2017〕15号）收悉。经研究，我局批复如下：

一、同意福庆寺藏经楼修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为福庆寺藏经楼文物建筑。

（三）深化现状勘察，进一步明确文物保存现状、主要病害类型、残损部位、残损程度等，深入分析屋面漏雨、墙体鼓闪、开裂等病害原因，客观评估2016年7月19日水灾的破坏程度，在此基础上制定有针对性的修缮措施。补充藏经楼基础稳定性评估内容。

（四）应严格控制工程量和工程强度，合理确定木构件更换、补配的具体数量和标准，修缮中尽量利用老旧构件，避免过度维修。加强对当地传统建造工艺和材料的调查研究，修缮中尽量采用当地传统材料和工艺。更换下的原构件应详细测绘、登记、评估价值，妥善保管；各类工程资料应由专人管理、建档，并在工程结束后纳入福庆寺记录档案。

（五）进一步做好藏经楼的支护措施，确保施工过程中文物和人员安全。

（六）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（七）应根据工程量合理编制经费预算，进一步细化各单项取费依据。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案；组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年3月2日
