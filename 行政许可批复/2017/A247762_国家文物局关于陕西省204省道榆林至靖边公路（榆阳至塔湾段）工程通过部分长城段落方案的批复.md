# 国家文物局关于陕西省204省道榆林至靖边公路（榆阳至塔湾段）工程通过部分长城段落方案的批复

## 关于陕西省204省道榆林至靖边公路（榆阳至塔湾段）工程通过部分长城段落方案的批复

文物保函〔2017〕201号

陕西省文物局：

你局《关于204省道榆林至靖边公路（榆阳至塔湾段）工程穿越长城方案的请示》（陕文物字〔2016〕266号）收悉。经研究，我局批复如下：

一、原则同意所报拟建204省道榆林至靖边公路（榆阳至塔湾段）工程在陕西省榆林市K31+867至K87+663.220区间以钢筋砼箱型通道方式通过明长城边墙壕至魏强村段长城（即所报四芦界明长城，长城认定编码：610823382101170014），以桥梁方式通过明长城边墙梁村至庞庄村段长城（即所报蟑螂塘明长城遗址，长城认定编码：610823382101170033）、战国秦长城李家洼村长城（即所报高家峁秦长城遗址，长城认定编码：610823382101020007）、战国秦长城响水塘村长城（即所报大阳湾秦长城遗址，长城认定编码：610823382101020020）和战国秦长城阎渠村长城（即所报红梁秦长城遗址，长城认定编码：610823382101020021）的方案。

考虑到拟建204省道榆林至靖边公路（榆阳至塔湾段）工程在前期建设过程中造成明长城长城峰村长城（即所报长城峰村明长城，长城认定编码：610802382101170063）及周边环境风貌破坏的相关责任单位和责任人已受到严肃处理，为避免国家资金损失，我局原则同意拟建公路工程以现状路基方式通过明长城长城峰村长城。你局应督促相关地方政府和单位务必尽快采取适当整改措施，对遭到破坏的长城遗址进行标识，对长城周边环境风貌进行修复，并树立长城保护标志、保护界桩、警示标识以及说明牌，对该段长城历史、价值、特征以及工程建设破坏长城及后期处理情况进行说明，以警示后人。

二、对该项目提出以下意见：

（一）应组织专业考古机构对拟建地下通道、桥梁等相关设施分布及施工区域作进一步的考古调查勘探。如有重要发现，必须调整项目选址方案。涉及考古发掘的，需另行填报考古发掘申请书。

（二）应根据考古工作结论，确定相关长城段落的墙体基础边界位置，并适当设置地下通道出入口、桥墩位置，尽可能加大桥梁跨径，补充详细的施工要求和临时保护措施，防止因施工造成长城受损。

（三）对于采取地下通道方式通过明长城边墙壕至魏强村段长城的方案，应最大限度加大通道埋深，补充开展现场试验，选取对长城及下部载体稳定性影响最小的施工措施，细化控制指标和施工组织要求，加强监测、管理，降低施工和运营对长城的影响。

（四）应简化地下通道出入口及桥梁形制、缩小体量、弱化色彩，并补充相关区域的环境风貌修复措施，以消弱工程建设造成的负面影响。

（五）应结合此次工程，设置长城保护标志、保护界桩以及警示标识。其中，保护标志牌、保护界桩、保护说明牌等应按照《长城“四有”工作指导意见》相关要求进行设计和设置。

三、请你局指导有关单位，根据上述意见对所报方案进行修改、完善，经你局核准后实施。请切实加强工程监管，督促方案设计单位加强施工全过程技术指导，落实各方责任，确保工程质量和文物、人员安全。

四、根据所报文物考古调查报告，拟建204省道榆林至靖边公路（榆阳至塔湾段）工程涉及顾兴庄遗址、圆疙瘩遗址、蜂峁遗址、王圪垯遗址、边墙壕遗址、老坟梁遗址、西阳坬遗址、灯杆梁遗址、灯杆梁战国墓群、杨虎台战国遗址、杨虎台遗址等多处古代遗址、墓群。请你局组织专业考古机构对上述遗址、墓群情况做进一步调查，编制保护方案，并依法履行报批程序。

此复。

国家文物局

2017年2月8日
