# 国家文物局关于北京孔庙崇圣门修缮项目的批复

文物保函〔2017〕2016号

北京市文物局：

你局《关于孔庙崇圣门及八字影壁修缮工程方案的请示（北京孔庙）》（京文物〔2017〕1488号）收悉。经研究，我局批复如下：

一、原则同意北京孔庙崇圣门修缮项目和你局意见。八字影壁项目应为日常保养维护，请你局指导北京孔庙保护管理机构按照有关规定做好相关工作。

二、具体修改意见如下：

（一）崇圣门主要问题是后檐飞椽糟朽和部分地仗残损，应补充瓦顶揭开后飞椽和望板可能面临的问题和针对措施，补充局部地仗修补措施，及对现有彩画的保护措施。在施工过程中，应按照最小干预的原则据实调整工程量，严格控制局部挑顶修缮的范围。

（二）进一步完善方案文本，规范图纸和标注，校核设计依据的具体版本。

三、北京孔庙崇圣门修缮项目具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

国家文物局

2017年12月21日
