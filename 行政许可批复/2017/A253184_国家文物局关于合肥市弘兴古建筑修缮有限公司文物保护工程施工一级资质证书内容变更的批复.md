# 国家文物局关于合肥市弘兴古建筑修缮有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于合肥市弘兴古建筑修缮有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕857号

安徽省文物局：

你局《关于申请变更合肥市弘兴古建筑修缮有限公司文物保护工程施工资质证书的请示》（皖文物保〔2017〕62号）收悉。

经研究，我局同意合肥市弘兴古建筑修缮有限公司文物保护工程施工一级资质证书中的注册资金由“603万元”变更为“3000万元”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局

2017年7月20日
