# 水利部关于引黄入冀补淀工程（河北段）中辛店橡胶坝、杨庄闸、冯庄闸、高庄节制闸设计变更报告的批复

水规计〔2017〕266号

河北省水利厅：

你厅《关于呈报＜引黄入冀补淀工程（河北段）中辛店橡胶坝、杨庄闸、冯庄闸、高庄节制闸设计变更报告＞的请示》（冀水规计[2017]41号）收悉。我部水利水电规划设计总院对随文上报的《引黄入冀补淀工程（河北段）中辛店橡胶坝、杨庄闸、冯庄闸、高庄节制闸设计变更报告》进行审查,并提出了审查意见（见附件）。经研究,我部基本同意该审查意见。

对于杨庄闸、冯庄闸、高庄节制闸拆除重建工程,请你厅按照建设程序和审查意见要求,认真组织实施,严格控制建设规模和投资,确保工程质量,保障工程安全运行。设计变更后增加的投资在原批准的引黄入冀补淀工程总概算内调剂解决,不足部分由河北省协调解决。

对于增建中辛店橡胶坝工程,根据《水利工程设计变更管理暂行办法》有关规定,请你厅督促项目法人抓紧按要求,在协调好有关各方意见后,办理设计变更审批手续。

附件：水规总院关于引黄入冀补淀工程（河北段）中辛店橡胶坝、杨庄闸、冯庄闸、高庄节制闸设计变更报告审查意见的报告

水利部

2017年7月25日
