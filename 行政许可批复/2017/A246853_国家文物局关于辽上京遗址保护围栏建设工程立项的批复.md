# 国家文物局关于辽上京遗址保护围栏建设工程立项的批复

## 关于辽上京遗址保护围栏建设工程立项的批复

文物保函〔2016〕2156号

内蒙古自治区文物局：

你局《关于辽上京遗址围封工程立项的请示》（内文物发〔2016〕290号）收悉。经研究，我局批复如下：

一、原则同意辽上京遗址保护围栏建设工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，在城墙和护城河遗址外开展辽上京遗址保护围栏的建设，注意控制工程规模、范围和强度，避免过度保护。

（二）地质勘察、安全风险评估、临时性安全监测等与围栏建设无关，不同意纳入围栏建设的前期工作。

（三）补充保护规划关于围栏建设的相关要求，围栏宜简洁实用，外观应与遗址及周边环境相协调，并注意控制建设成本。

（四）进一步校核工程预算，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

四、请你局督促地方人民政府切实加强辽上京遗址的保护和管理，做好日常巡查和看护，确保文物安全。

国家文物局

2017年1月4日
