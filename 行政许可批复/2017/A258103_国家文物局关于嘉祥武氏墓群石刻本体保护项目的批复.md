# 国家文物局关于嘉祥武氏墓群石刻本体保护项目的批复

文物保函〔2017〕1899号

山东省文物局：

你局《关于上报嘉祥武氏墓群石刻本体保护设计方案的请示》（鲁文发〔2017〕91号）收悉。经研究，我局批复如下：

一、原则同意所报嘉祥武氏墓群石刻本体保护项目和你局意见。

二、具体修改意见如下：

（一）补充完善现状勘察，进一步深化前期研究。应补充石刻的主要信息，包括价值、等级、保护修复历史、保存现状等；梳理分析各项病害，评估其发展情况和影响程度，找准急需处理的主要病害，突出保护措施的针对性。

（二）风化岩样成分分析、石刻基本物理特性检测应与同种新鲜石材对比，以判断风化产物成分、含量和风化程度。补充说明风化深度测试方法。

（三）完善前期监测工作，针对主要病害设置监测项，注意防止过度监测，侧重监测的时效性和专业性。对三种保存环境的微环境监测应持续一年，并包含污染物监测；补充石刻表面温度监测，以判定是否有冷凝现象；结合可溶盐分析判定是否有潮解现象；应对存在危险裂缝的石刻进行裂隙和变形监测。

（四）进一步研究、论证部分保护措施及其长期效果，同时应开展必要的前期试验，进一步论证拟采用材料和操作方法的科学性、有效性和安全性。如，审慎使用刚性框架加固石刻断裂区域，尽可能控制对文物外观的影响；修补、清理后的部位如不存在风化等问题，不得一律涂刷三遍硅酸乙酯加固材料；评估使用水硬性石灰和石粉的粘接断裂部位的效果，应考虑受力部位的耐久性；补充说明石刻脱盐处理的必要性和宣纸脱盐的有效性；审慎采用水硬性石灰作为灌浆材料，注意核实其可逆性；论证涂刷渗透加固表面粉化剥落病害部位的可行性，考虑是否需预加固；松散水泥剔除应注意评估剩余部分的稳定性。

（五）坚持最小干预原则，严格控制拟修缮石刻的数量，重点修缮病害严重、存在安全稳定性问题的石刻，进一步细化修缮措施，避免过度维修。不影响结构稳定性的石刻缺失部分，不宜修补。对拟实施的石刻也应科学、合理分期，选取病害严重的少部分石刻先行试验并经专业验收通过后，方可结合其余石刻保存状况评估、保护性设施保护效果评估等综合研究、分析后逐步推广。

（六）补充完善勘察设计图纸。补充相应的现状照片；补充必要的大样图；明确标示各断裂部位钻孔、植筋的位置、方向、孔径、材料和工艺等要求。

（七）展示阐释设计尽可能与本次保护工程相结合，应补充必要的图纸和文字说明；明确石刻文物临时保护的具体工作内容。

（八）应主要基于成熟的软硬件条件搭设数据工作平台，不得大规模购置设备、建设软件平台，满足数据存储和分析需求即可。

（九）按照上述要求核减预算经费并细化取费依据。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局核准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

此复。

国家文物局

2017年11月24日
