# 国家文物局关于南阳知府衙门文物保护设施建设项目的批复

## 关于南阳知府衙门文物保护设施建设项目的批复

文物保函〔2017〕11号

河南省文物局：

你局《关于南阳府衙抢救性文物保护设施建设项目设计方案的请示》（豫文物〔2016〕267号）收悉。经研究，我局批复如下：

一、原则同意南阳知府衙门文物保护设施建设项目和你局意见。

二、对所报方案提出如下修改完善意见：

（一）该工程位于全国重点文物保护单位南阳知府衙门保护范围和建设控制地带内，应严格遵守《中华人民共和国文物保护法》和河南省人民政府关于南阳知府衙门文物保护的相关规定要求，严格控制工程范围和工程强度，妥善保护文物，合理改善周边环境。

（二）加强前期勘察和研究，系统梳理相关历史文献资料，明确南阳知府衙门的空间格局和历史沿革。补充南阳知府衙门保护区划相关管理规定和具体控制要求。

（三）不同意全部拆换府衙内碎石板道路。应尽量维持现状，进行局部调平、加固、修补，并做好道路排水。

（四）给排水、电力等埋地线路铺设应注意避让建筑基础，保持适当距离，确保文物安全。

（五）绿化种植应尽量采用地方树种，注意营造历史氛围，避免现代化和景观园林化设计倾向。

（六）应进一步控制厕所建筑体量，降低建筑高度，檐口高度不得超过3.2米。校核厕所设计内容，避免前后矛盾。

（七）消防设施建设项目应按要求另行报批。

（八）进一步完善文本和图纸。应深化文物影响评估报告，深入论证拟建项目对文物本体和环境风貌的影响，做到客观、准确、科学。

三、请你局根据上述意见，组织相关单位对所报方案进行修改、完善，并经你局核准后实施。请加强对工程的监管，确保文物及其环境安全。

此复。

国家文物局

2017年1月6日
