# 国家卫生计生委转发国家发展改革委关于中国医学科学院病原生物学研究所新建工程初步设计方案和投资概算批复的通知

中国医学科学院：

现将《国家发展改革委关于中国医学科学院病原生物学研究所新建工程初步设计方案和投资概算的批复》（发改投资〔2017〕119号）转发你院。根据国家发展改革委批复，原则同意你院病原生物学研究所新建工程初步设计方案。核定工程总建筑面积43,144平方米，概算总投资36,965万元。所需投资由该委安排中央预算内投资解决。

请你院指导项目单位按照国家有关规定，严格执行基本建设程序，建立健全项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计方案和投资概算，抓紧组织开展下一步工作。特别要按照《中央预算内直接投资项目概算管理暂行办法》（发改投资〔2015〕482号）规定，加强全过程监督和概算管理，确保不突破批复的总投资概算。

国家卫生计生委

2017年2月13日
