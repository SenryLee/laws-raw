# 国家文物局关于龙华革命烈士纪念地和龙华塔建设控制地带内多媒体信息服务中心建设项目方案的批复

## 关于龙华革命烈士纪念地和龙华塔建设控制地带内多媒体信息服务中心建设项目方案的批复

文物保函〔2017〕1095号

上海市文物局：

你局《关于在全国重点文物保护单位龙华革命烈士纪念地建设控制地带内进行建设工程的请示》（沪文物〔2017〕45号）收悉。经研究，我局批复如下：

一、原则同意所报方案。

二、对该方案提出以下修改意见：

（一）补充龙华革命烈士纪念地和龙华塔建设控制地带内建设控制指标。进一步缩减新建建筑体量，适当降低建筑高度。

（二）进一步优化新建建筑形式设计，将建筑外立面色调予以适当调整，以弱化对龙华塔环境风貌的影响。

（三） 深化文物影响评估报告，补充龙华塔倾斜的相关监测数据，科学评估新建建筑产生的施工振动等对龙华塔的影响，提出可行的监测、防护措施，完善相关应急预案。

三、请你局指导相关单位根据上述意见对方案进行修改完善，经你局核准后实施。工程施工期间，应加强对工程的监管，确保文物安全。

此复。

国家文物局

2017年6月16日
