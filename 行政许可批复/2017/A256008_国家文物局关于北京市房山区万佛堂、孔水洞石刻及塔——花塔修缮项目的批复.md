# 国家文物局关于北京市房山区万佛堂、孔水洞石刻及塔——花塔修缮项目的批复

文物保函〔2017〕1591号

北京市文物局：

你局《关于房山区万佛堂、孔水洞——花塔修缮工程方案的请示》（京文物〔2017〕1017号）收悉。经研究，我局批复如下：

一、原则同意所报万佛堂、孔水洞石刻及塔——花塔修缮项目和你局意见。

二、对该项目提出以下修改意见：

（一）应遵循“不改变文物原状”、“最小干预”等文物保护原则，进一步加强现状勘察和研究，明确塔基现状情况，补充花塔塔体结构稳定性评估、历次修缮工程情况说明、盗洞相关情况说明和塔体周边场地的防、排水情况说明，并根据评估结论采取针对性的保护措施，确保塔体安全。

（二）应加强原有砌筑材料、工艺、做法的分析和研究，确保在维修中使用原工艺和原材料。

（三）应加强文物监测工作，并做好场地排水防渗设计。

（四）注意做好各类工程资料提取和档案留存工作。

（五）进一步校核文本与图纸，细化盗洞修缮说明和图纸。补充斗拱、栏杆、窗、券门等部位详图，进一步核实塔体高度。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善并经你局批准后组织实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

特此函复。

国家文物局

2017年8月31日
