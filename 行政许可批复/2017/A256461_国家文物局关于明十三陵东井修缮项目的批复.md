# 国家文物局关于明十三陵东井修缮项目的批复

文物保函〔2017〕1745号

北京市文物局：

你局《关于明十三陵东井修缮工程方案的请示》（京文物〔2017〕1143号）收悉。经研究，我局意见如下：

一、原则同意明十三陵东井修缮项目。

二、该设计方案应进一步深化现状勘察和分析，重点做好现有墓冢及周边防排水工作；合理确定改性灰土硬化地面和地表植被清理的范围和强度，避免过度整治；现有墓冢可采用绿篱隔离保护；补充现状总平面图，规范图纸表达。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善后实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好维修后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

国家文物局

2017年10月13日
