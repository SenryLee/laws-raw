# 国家文物局关于变更考古发掘资质证书的批复

文物保函〔2017〕2040号

山东省文物局：

你局《关于变更山东省文物考古研究所考古发掘证照的请示》（鲁文〔2017〕141号）收悉。经研究，我局同意为山东省文物考古研究院更换考古发掘资质证书，并变更证书登记单位名称及主管部门等信息。请你局通知有关单位，携原资质证书正、副本来我局办理更换手续。

国家文物局

2017年12月22日
