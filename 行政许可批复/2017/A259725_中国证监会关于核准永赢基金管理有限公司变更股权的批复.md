# 中国证监会关于核准永赢基金管理有限公司变更股权的批复

## 关于核准永赢基金管理有限公司变更股权的批复

证监许可〔2017〕2415号

永赢基金管理有限公司：

《永赢基金管理有限公司关于股权变更的申请报告》（永赢基金〔2017〕260号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

一、核准刘硕、周华睿、狄泽、钟菊秀、祁洁萍、张哲、周良子、陈遥、徐蔓青、余帅、蔡霖、田中甲、芦特尔、宋宜农、XXX宝、洪幼叶、毛慧、赵楠、华靓、沈望琦、陈佶、安福廷、李峻等23名自然人股东将所持你公司全部股权合计18.51%转让给利安资金管理公司（Lion Global Investors Limited）。

二、你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2017年12月27日
