# 国家文物局关于灌阳县湘江战役旧址四期修缮工程立项的批复

## 关于灌阳县湘江战役旧址四期修缮工程立项的批复

文物保函〔2017〕280号

广西壮族自治区文化厅：

你厅《关于报送灌阳县湘江战役旧址修缮工程四期立项报告的请示》（桂文物报〔2016〕60号）收悉。经研究，我局批复如下：

一、同意灌阳县湘江战役旧址四期修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）该工程实施范围包括红三十四师红军及伤员宿营地、红一纵红军宿营地、红五师宿营地旧址共计28处文物建筑。

（三）深入开展前期修缮工程实施情况及效果评估，总结经验教训，在此基础上对各单体文物建筑逐一进行现场勘察测绘、保存现状评估和病害分析，调查记录原材料和原工艺，为制定有针对性的修缮措施提供科学依据。

（四）遵循“最小干预”、“不改变文物原状”等原则，以现状整修为主，严格控制工程量和工程范围。

（五）注意辨识红军标语类文物遗存，并加以妥善保护。

（六）充分考虑文物建筑今后的展示利用需求。

三、请你厅指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你厅组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年2月23日
