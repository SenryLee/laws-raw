# 农业部关于内蒙古自治区海拉尔农牧场管理局3个社会公益性建设项目可行性研究报告的批复

农计发〔2017〕5号

内蒙古自治区海拉尔农牧场管理局:

《海拉尔农牧场管理局关于2017年农垦社会公益性基础设施建设项目可行性研究报告的请示》(海农局计字〔2016〕2号)收悉。经研究，原则同意下列项目可行性研究报告。

1.三河种马场中小学体育场和场部小城镇基础设施建设项目，建设地点位于内蒙古自治区呼伦贝尔市额尔古纳市三河种马场场部。主要建设内容为建设中小学生体育场4200平方米，配套建设污水处理、输变电设施等。总投资2045万元，其中中央预算内投资1635万元，地方投资410万元（详见附件1）。

2.上库力农场场部小城镇基础设施建设项目，建设地点位于内蒙古自治区呼伦贝尔市额尔古纳市上库力农场场部。主要建设内容为新建锅炉房900平方米，改造供热管网4300米，新建供热管网340米，购置30吨锅炉及配套设施1套；硬化路面50000平方米。总投资1410万元，其中中央预算内投资1130万元，地方投资280万元（详见附件2）。

3.特泥河农牧场场部中小学体育场建设项目，建设地点位于内蒙古自治区呼伦贝尔市陈巴尔虎旗特泥河农牧场场部。主要建设内容为建设中小学体育场5000平方米，配套室外工程。总投资2350万元，其中中央预算内投资1880万元，地方投资470万元（详见附件3）。

上述项目建设期均为2年，自投资计划下达之日起计算。

请据此批复，督促建设单位抓紧委托有资质的勘察设计单位编制项目初步设计报你局审批。请严格按照农业基本建设项目管理规定，做好项目组织实施工作，并按月在农业建设项目管理信息系统（http://ac.agri.gov.cn）和投资项目在线审批监管平台（国家重大建设项目库模块，http://kpp.ndrc.gov.cn）中填报实施进度等相关信息。

附件：1.内蒙古海拉尔垦区三河种马场中小学体育场和场部小城镇基础设施建设项目可行性研究报告批复表

2.内蒙古海拉尔垦区上库力农场场部小城镇基础设施建设项目可行性研究报告批复表

3.内蒙古海拉尔垦区特泥河农牧场场部中小学体育场建设项目可行性研究报告批复表

农业部
