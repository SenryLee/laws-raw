# 国家文物局关于公主寺塑像壁画保护项目的批复

## 关于公主寺塑像壁画保护项目的批复

文物保函〔2017〕1116号

山西省文物局：

你局《关于审批繁峙县公主寺塑像壁画保护方案的请示》（晋文物〔2017〕122号）收悉。经研究，我局批复如下：

一、原则同意所报公主寺塑像、壁画保护项目和你局意见。

二、对该工程提出以下修改意见：

（一）细化前期勘察，进一步核准空鼓等病害范围。

（二）加强前期试验检测分析工作，进一步明确和规范灌浆材料成分配比，补充塑像表面纸张加固的相关试验数据。

（三）坚持最小干预原则，严格控制工程范围和强度，完善保护修复工艺和材料等具体措施。

1. 应根据塑像表面蜡层性质，科学选择清除溶剂，注意控制脱蜡措施程度，避免造成文物二次伤害。

2. 灌浆和修缮材料应进行脱盐处理后使用，并注意在墙体砌筑过程中应尽量减少水用量，避免影响壁画。

3. 不同意须弥座等部位加固后使用Paraloid B72材料进行表面封护。

4. 应针对文物现状研提切实可行的防尘建议，在确保通风的情况下减少表面积尘。

（四）应做好文物建筑修缮与塑像壁画保护工程的衔接，完善防护措施和应急预案。

三、具体工程方案由你局根据上述意见，组织相关单位修改、完善并经你局批准后实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位结合项目实施提高人员保护水平和能力，做好修缮后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年6月26日
