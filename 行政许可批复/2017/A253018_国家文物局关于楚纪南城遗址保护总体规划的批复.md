# 国家文物局关于楚纪南城遗址保护总体规划的批复

## 关于楚纪南城遗址保护总体规划的批复

文物保函〔2017〕904号

湖北省文物局：

你局《关于呈报楚纪南故城保护总体规划的请示》（鄂文物〔2016〕40号）收悉。经研究，我局批复如下：

一、原则同意楚纪南故城保护总体规划。

二、雨台山墓群的保护区划应采用方案一。同时，建议进一步统一城址区、雨台山墓群和天星观墓群建设控制地带的分级标准和相应的管理规定，以增强可操作性。

三、请你局指导地方人民政府组织规划编制单位和专业考古研究单位，按照上述意见，对规划进行必要修改和完善后，于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

四、请你局按照《国务院关于进一步加强文物工作的指导意见》的要求，将经我局备案的楚纪南故城保护总体规划报请湖北省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展规划以及城市总体规划，积极组织有关部门逐步实施。

五、规划中涉及的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制订具体方案并按程序报批。

六、请你局指导和协调地方人民政府切实加强楚纪南故城的保护和管理工作，加强专门保护管理机构建设，完善专项管理法规，并提出具体实施步骤和保障措施，妥善解决土地用途调整、道路调整、居民搬迁以及环境整治等问题，确保规划的顺利实施。

国家文物局

2017年4月28日
