# 国家发展改革委关于贵州省遵义市保障性住房建设投资开发有限责任公司非公开发行遵义市银河片区保障性住房及配套设施建设项目收益债券核准的批复

发改企业债券〔2017〕217号

贵州省发展改革委：

你委《关于报请非公开发行2016年遵义市银河片区保障性住房及配套设施建设项目项目收益债券发行申请的请示》（黔发改财金〔2016〕988号）等有关申报材料收悉。经研究，根据《公司法》、《证券法》和《企业债券管理条例》，现批复如下。

一、同意遵义市保障性住房建设投资开发有限责任公司非公开发行项目收益债券不超过10亿元，所筹资金全部用于遵义市银河片区保障性住房及配套设施建设项目的投资建设。根据遵义市红花岗区发展改革局批复的贵州航天江南建筑设计院有限公司（工程咨询单位资格证书编号：工咨乙12920060028）和北京市市政工程设计研究总院有限公司（工程咨询单位资格证书编号：工咨甲10120070044）联合编制的项目可行性研究报告，银河片区保障性住房及配套设施建设项目总投资17.38亿元，总建筑面积60.21万平方米，税后内部收益率为10.31%，投资回收期4.21年，将于2017年12月完工。请你委督促遵义市保障性住房建设投资开发有限责任公司严格按照项目建设各项内容实施建设。

二、发行人遵义市保障性住房建设投资开发有限责任公司为遵义市银河片区保障性住房及配套设施建设项目实施主体，负责项目的投资、建设和运营。该公司应认真实施项目建设并进行项目运营，同时履行本期债券募集说明书及其他法律协议中约定的全部相关义务。

三、大公国际资信评估有限公司综合评定，本期债券的信用等级为AA。本期债券由遵义市国有资产投融资经营管理有限责任公司担任差额补偿人，当本期债券偿债资金账户内资金不足以偿还当期债券本息时，由差额补偿人承担差额补足义务。

四、本期债券由遵义市国有资产投融资经营管理有限责任公司提供全额无条件不可撤销连带责任保证担保。

五、遵义市保障性住房建设投资开发有限责任公司应在本期债券发行首日前5个工作日在监管银行开立募集资金使用专户、项目收入归集专户和偿债资金专户，保证项目运营收入封闭运行。项目建成后项目销售收入等与项目有关的运营收入全部划入项目收入归集专户。发行人授权监管银行在每个计息年度内不少于两次将项目收入从项目收入归集专户向偿债资金专户划转，作为偿债准备金，偿债准备金以待偿付的全部债券本息为限。

六、贵州银行股份有限公司遵义分行营业部是本期债券募集资金和偿债资金的监管银行，负责对募集资金使用专户和偿债资金专户进行全程严格监管，当偿债资金专户内资金不足以支付当年债券本息时，应按要求通知差额补偿人，及时启动差额补偿。贵州银行股份有限公司遵义分行营业部也是本期债券项目收入的监管银行，负责对项目收入归集专户进行全程严格监管，并按约定从收入归集专户向偿债资金专户划转偿债准备金。

七、本期债券期限为5年期，每年计息一次，固定利率，不计复利。本期债券通过中央国债登记结算有限责任公司簿记建档发行系统，按照公开、公平、公正原则，以市场化方式确定发行票面年利率。

本期债券附设分期还本条款，在债券存续期的第3、4、5个计息年度末分别按照发行总额30%、30%、40%的比例偿还债券本金。

八、本期债券由主承销商中国银河证券股份有限公司，分销商中航证券有限公司组成承销团，以余额包销的方式承销。

九、本期债券为实名制记账式，采用簿记建档、集中配售的方式，以非公开方式通过银行间市场向具备风险识别和承担能力的机构投资者发行，并在中央国债登记结算有限责任公司登记托管，存续期内不得转托管。发行时不得采用广告、公开劝诱和变相公开方式，每次发行时认购的机构投资者不超过二百人，单笔认购不少于500万元人民币。本期债券仅限于在机构投资者范围内转让。转让后，持有同次发行债券的机构投资者合计不得超过二百人。

十、本期债券应在本批复文件下达后24个月内一次或分期发行完毕，各期发行期限不超过10个工作日。

十一、在本期债券发行前，请你委督促发行人和主承销商按照有关规定进行信息披露。项目收益债券募集说明书等法律文件应通过适当渠道供潜在机构投资者查阅。发行人和承销机构在债券发行后三个月向投资者通报项目实施进展情况及募集资金使用专户、项目收入归集专户和偿债资金专户收支情况，此后每半年通报上述情况。

在本期项目收益债券存续期内，发行人应按交易场所的规定每年向投资者披露上一年度经审计的发行人和差额补偿人及担保人的财务报告。

十二、主承销商和发行人在本期债券发行期满后20个工作日内应向我委报送承销工作报告。

十三、在债券存续期内，项目建设、运营情况发生重大变化或发行人发生对债券持有人有重大影响的事项，按照规定或约定履行程序，并及时向投资者通报，以保障债券持有人的合法权益。

十四、请你委认真落实项目收益债券的各项监管责任，总结经验、规范运作，保证项目的顺利实施及债券资金借用管还的有序进行。

国家发展改革委

2017年5月19日
