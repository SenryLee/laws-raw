# 国家文物局关于新四军苏浙军区旧址之《苏南报》社旧址修缮工程立项的批复

## 关于新四军苏浙军区旧址之《苏南报》社旧址修缮工程立项的批复

文物保函〔2017〕32号

浙江省文物局：

你局《关于要求将全国重点文物保护单位新四军苏浙军区旧址之〈苏南报〉社旧址修缮工程项目予以立项的请示》（浙文物发〔2016〕269号）收悉。经研究，我局批复如下：

一、同意新四军苏浙军区旧址之《苏南报》社旧址修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物修缮工程。

（二）工程范围为《苏南报》社旧址文物建筑。

（三）加强文物现状勘察，补充建筑结构安全性检测。

（四）坚持最小干预原则，严格控制工程范围和工程量，避免过度修缮。进一步论证恢复已毁的后楼和连廊的必要性；复建设计须有充足的图片、资料等历史依据，同时注意可识别性。

（五）补充院落整治和排水设施维修内容。

（六）应统筹考虑文物今后的展示利用需求。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案；组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年1月9日
