# 国家文物局关于黄埔军校第二分校旧址白蚁综合治理工程立项的批复

## 关于黄埔军校第二分校旧址白蚁综合治理工程立项的批复

文物保函〔2017〕590号

湖南省文物局：

你局《关于黄埔军校第二分校旧址白蚁综合治理工程立项的请示》（湘文物报〔2017〕13号）收悉。经研究，我局批复如下：

一、同意黄埔军校第二分校旧址白蚁综合治理工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于文物白蚁综合治理工程。

（二）工程范围为黄埔军校第二分校旧址文物建筑。

（三）深化现场勘察，准确掌握白蚁病害的位置、范围,对其危害程度进行实事求是地科学评估。在此基础上根据国家对白蚁防治的规范要求，结合文物建筑的特点，制定科学合理、有针对性的工程措施。

（四）坚持最小干预原则，合理划定白蚁治理范围。严格控制药物投放剂量和面积，避免对人、畜及环境产生危害。若需在建筑周围动土，应采取必要保护措施，避免对建筑基础、排水系统及其他文物遗存造成破坏。

（五）补充工程结束后白蚁病害治理效果监测、评估和后续巩固措施。

三、请你局指导项目单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织专家或委托专业评估机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月28日
