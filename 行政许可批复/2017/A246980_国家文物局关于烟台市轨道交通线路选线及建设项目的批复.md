# 国家文物局关于烟台市轨道交通线路选线及建设项目的批复

## 关于烟台市轨道交通线路选线及建设项目的批复

文物保函〔2017〕140号

山东省文物局：

你局《关于报送烟台市轨道交通规划建设相关材料的请示》（鲁文发〔2016〕180号）收悉。经研究，我局批复如下：

一、原则同意所报轨道交通线路选线及建设项目。

二、对线路选线及项目建设提出以下修改意见：

（一）根据不同文物保护单位的特点、线路穿越与文物本体的空间位置，参考相关规范及文物影响评估报告的结论、建议，制定严格的文物保护措施和详细的施工方案，以确保烟台福建会馆等重要文物保护单位的安全。

（二）在穿越临近文物保护范围的工程段时，应根据岩土层的物理力学性质及均匀性和文物本体对变形的敏感性，合理确定盾构推进的施工系数、质量标准和技术要求，正确设定平衡压力和推进速度，减少超挖与欠挖现象，控制好盾构姿态，加强同步和二次注浆，控制好注浆量和注浆压力，消除施工中影响文物安全的隐患。

（三）穿过三十里堡汉墓群保护范围内的工程段，在施工中应尽可能减少场地占用，严格按相关施工规程和工艺的工法施工，避免对墓群保护范围的过大影响；如发现地下文物遗存，应立即停止施工并依法进行妥善处理。

（四）拟建轨道交通涉及上述不可移动文物的站位选址应在开展必要考古工作，并做好文物影响评估的基础上予以深化和优化，避免占压重要文物遗存。

（五）建立完整的监测系统，加大监测频率，制定纠偏、防塌及减振等防灾预案，必要时可对文物本体进行预加固处理。

（六）考虑在经过文物保护单位地段时减速运行，以减少列车运行振动对文物的影响。

三、请你局指导有关单位，根据上述意见修改完善文物保护选线方案和相关保护措施，确保文物安全。

此复。

国家文物局

2017年1月26日
