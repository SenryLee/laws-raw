# 国家文物局关于泥河湾遗址群小长梁遗址保护工程变更设计方案的批复

文物保函〔2017〕1381号

河北省文物局：

你局《关于呈报〈泥河湾遗址群—小长梁遗址保护方案〉（变更设计方案）的请示》（冀文物字〔2017〕125号）收悉。经研究，我局批复如下：

一、原则同意泥河湾遗址群小长梁遗址保护工程变更设计方案。

二、应在所报方案的基础上进一步深化设计，明确保护性设施的结构平面布置和立面布置方式，避让重要文物遗存；在开展地质勘察的基础上，比选分析“独立浅基础形式”与“人工成孔灌浆独立桩基（桩径800mm以内）”的优劣，优化确定合理的建筑基础形式。同时，建筑屋面截排水设施应尽量远离建筑边沿。

三、请你局指导方案设计单位根据上述意见进一步修改和完善所报方案，制定科学详细的初步设计方案，经你局核准并履行必要的审批手续后实施。施工中，请你局加强监管，确保工程质量和文物安全。

国家文物局

2017年8月9日
