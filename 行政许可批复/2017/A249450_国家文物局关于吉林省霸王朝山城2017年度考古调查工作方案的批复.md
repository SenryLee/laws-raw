# 国家文物局关于吉林省霸王朝山城2017年度考古调查工作方案的批复

## 关于吉林省霸王朝山城2017年度考古调查工作方案的批复

文物保函〔2017〕547号

吉林省文物局：

你局《关于开展吉林省高句丽山城遥感数据采集和区域考古调查工作的请示》（吉文物发〔2017〕11号）收悉。经研究，我局批复如下：

一、同意2017年对吉林省霸王朝山城开展遥感数据采集和区域考古调查试点工作。

二、工作方案应做以下补充、完善：

（一）对霸王朝山城的区位、交通、资源和相关遗存进行综合考察，探讨分布规律。尽可能坚持以相应自然地理区域的一次性覆盖的方式开展工作，避免工作的反复和重叠造成的时间和资源的浪费。

（二）以田野考古工作为基础，充分利用既往的考古成果，积极吸纳新的科学手段，通过新的视角认知遗存，发现问题，必要时应适度实施考古发掘以深化相关认识。

（三）注意把握遗存时空关系，在细化时间尺度的基础上探索遗存联系及文化面貌变化规律。

三、请你局指导有关单位，根据以上意见对所报工作方案进行补充、完善，经你局核准后实施。涉及考古发掘的内容，应另行填报考古发掘申请书。请你局加强管理,确保工作质量和工地安全，遇有重要发现，应及时向我局报告。年度考古工作结束后，应向我局提交工作情况报告。待霸王朝山城考古调查工作完成后，总结经验，合理规划其他遗址的相关考古工作，另行报批。

国家文物局

2017年3月21日
