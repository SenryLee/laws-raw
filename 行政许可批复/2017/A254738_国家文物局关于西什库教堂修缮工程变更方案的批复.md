# 国家文物局关于西什库教堂修缮工程变更方案的批复

文物保函〔2017〕1500号

北京市文物局：

你局《关于西什库教堂修缮工程方案设计变更的请示》（京文物〔2017〕625号）收悉。经研究，我局批复如下：

一、原则同意所报方案。

二、对方案提出以下修改意见：

（一）加强文物建筑原形制研究，深化构造做法的现状勘察，增加保护措施的依据和针对性。如补充屋顶正脊、垂脊做法的历史依据，说明油饰用混油和醇酸磁漆的不同原因，补充内墙涂料使用防碱防硝的原因等。

（二）石雕构件不宜采用铁箍加固，应尽可能多保留原材料做法和历史信息。屋面琉璃瓦的更换数量应严格进行控制并尽量减少更换。

（三）室内墙体上原有彩画的保护措施应制定专项保护方案。可选取较小区域进行保护试验后，再行实施彩画保护。

（四）严格控制工程规模和工程量变更，应进一步补充设计文件图纸，包括剖面图和大样图，补充说明文字表达的工程变更内容。

请你局组织相关单位对变更方案进行修改完善后，经你局核准后实施。施工过程中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2017年8月24日
