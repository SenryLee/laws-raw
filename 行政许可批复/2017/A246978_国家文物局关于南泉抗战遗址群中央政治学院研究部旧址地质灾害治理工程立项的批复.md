# 国家文物局关于南泉抗战遗址群中央政治学院研究部旧址地质灾害治理工程立项的批复

## 关于南泉抗战遗址群中央政治学院研究部旧址地质灾害治理工程立项的批复

文物保函〔2017〕84号

重庆市文物局：

你局《关于审批全国重点文物保护单位南泉抗战遗址群中央政治学院研究部旧址地质灾害治理立项的请示》（渝文物〔2016〕328号）收悉。经研究，我局批复如下：

一、同意中央政治学院研究部旧址地质灾害治理工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于地质灾害治理工程。

（二）该工程范围为中央政治学院研究部旧址保护范围内坡体。

（三）强化现场地质、水文勘察，准确研判灾害性质。若为边坡滑移，应区分整体滑移和局部滑塌，明确滑移面和滑坡分布范围；如果非滑坡，只是坡体土压力作用下产生的局部变形，则应另行制定加固措施。

（四）调查检测挡墙结构和强度，明确墙体鼓胀原因，评估墙体稳定性，采取必要的补强加固措施。对于没有挡墙处的滑移边坡，可采用抗滑桩或砌筑挡墙等措施消除隐患。

（五）坚持最小干预原则，严格控制工程范围和工程规模。同时做好对文物本体的安全防护。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案；由你局组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年1月20日
