# 国家邮政局关于《中华人民共和国第十三届运动会》纪念邮票图稿的批复

国邮复〔2017〕52号

中国邮政集团公司：

你公司关于报审《中华人民共和国第十三届运动会》纪念邮票图稿的文（中国邮政函〔2017〕50号）收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套2枚，内容分别为：1.竞技体育；2.群众体育。另发行1枚小全张。发行日期为2017年8月27日。经审查，同意使用该套图稿印制邮票。

此复。

国家邮政局

2017年7月25日
