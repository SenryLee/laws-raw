# 国家文物局关于在芋头侗寨古建筑群保护范围内进行基础设施改造与环境整治工程的批复

## 关于在芋头侗寨古建筑群保护范围内进行基础设施改造与环境整治工程的批复

文物保函〔2017〕1099号

湖南省文物局：

你局《关于审批在全国重点文物保护单位芋头侗寨古建筑群保护范围内进行基础设施改造工程的请示》（湘文物报〔2017〕46号）收悉。经研究，我局批复如下：

一、原则同意在芋头侗寨古建筑群保护范围内进行基础设施改造与环境整治工程和你局意见。

二、对所报方案提出以下修改意见：

（一）应严格遵守《中华人民共和国文物保护法》、《芋头侗寨古建筑群保护规划》以及湖南省人民政府关于全国重点文物保护单位芋头侗寨古建筑群保护范围的相关管理规定，严格控制工程量和工程范围，尽量减少施工建设对文物本体和景观环境的影响，确保文物安全。

（二）应结合原有给排水系统进一步完善方案设计，明确主道水沟和巷道沟的具体分布位置和与文物建筑的安全距离要求。进一步论证重新设计竹筒汇水系统的必要性。

（三）管道挖掘与恢复尽量采用人工开挖和分段施工模式，减少工作面，避免损害文物本体。补充狭窄街巷给排水、电力埋地敷设工程的文物安全影响评估和保障措施。

（四）村内道路应以现状整修为主，不宜进行大规模改造及将水泥路改造为石板路。

（五）不同意全部硬化村内水域河岸，建议保持河道原始状态，仅对部分失稳和坍塌地段进行整修。

（六）不同意在上寨龙脉鼓楼周边新增游客服务中心。

（七）消防、防雷工程应单独编制方案按程序另行报批。

（八）应制定必要的临时性文物保护措施和应急预案，注意加强施工过程中的文物安全监测工作，及时发现隐患，确保文物和人员安全。

（九）进一步完善文本和图纸，补充文物本体分布图、栏杆设计图、硬质驳岸设计图、道路铺装图等。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。督促相关单位在项目实施前充分征求村民等利益相关者的意见建议。施工中请加强工程监管，确保文物及历史环境安全。

四、请你局督促地方人民政府落实管理责任，按照《中华人民共和国文物保护法》、《芋头侗寨古建筑群保护规划》等的要求，有序开展文物保护、基础设施改造、环境整治、展示利用和旅游工作，科学引导周边建设与旅游活动，处理好文物保护利用、地方经济发展和民生改善之间的关系。

此复。

国家文物局

2017年6月16日
