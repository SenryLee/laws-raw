# 国家文物局关于隆尧唐祖陵保护展示工程立项的批复

## 关于隆尧唐祖陵保护展示工程立项的批复

文物保函〔2017〕570号

河北省文物局：

你局《关于隆尧唐祖陵保护展示工程立项的请示》（冀文物字〔2017〕22号）收悉。经研究，我局批复如下：

一、原则同意隆尧唐祖陵保护展示工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状保护为主，做好唐祖陵主陵区及神道范围内的文物本体保护展示工程，并注意控制工程规模、范围和强度，避免过度保护展示。

（二）应根据勘察评估结论进一步优化工程措施，合理确定主陵区覆土高度，明确泥浆灌注措施的有效性和必要性。

（三）植被清理措施应与展示方案相结合，建议仅对影响遗址环境和标识展示的植被进行调整，补种植被应考虑与遗址及环境相协调，避免人工园林化。

（四）遗址模拟及标识展示应以考古工作和研究成果为依据，同时应严格控制补做新夯土和局部整形措施的工程范围和工程量，避免过度展示。

（五）严格控制工程预算，进一步梳理并控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年3月27日
