# 国家卫生计生委转发国家发展改革委关于全民健康保障信息化工程一期项目初步设计方案和投资概算批复的通知

国家卫生计生委统计信息中心：

现将《国家发展改革委关于全民健康保障信息化工程一期项目初步设计方案和投资概算的批复》（发改投资〔2017〕126号）转发你中心。根据国家发展改革委批复，原则同意所报全民健康保障信息化工程一期项目初步设计方案。核定该项目概算总投资34,460万元，其中，我委30,962万元。所需投资全部由国家发展改革委安排中央预算内投资解决。

请你中心按照国家有关规定，严格执行基本建设程序，建立健全项目法人责任制、项目招投标制、工程建设监理制和合同管理制，本着控制建设标准、节约建设资金、确保工程质量的原则，严格按照批复的初步设计方案和投资概算，抓紧组织开展下一步工作。

国家卫生计生委

2017年2月13日
