# 国家文物局关于在大屯土司庄园保护范围和建设控制地带内进行基础设施建设与环境整治工程的批复

## 关于在大屯土司庄园保护范围和建设控制地带内进行基础设施建设与环境整治工程的批复

文物保函〔2017〕173号

贵州省文物局：

你局《关于在全国重点文物保护单位大屯土司庄园保护范围内实施抢救性文物保护设施建设项目的请示》（黔文物呈〔2016〕103号）收悉。经研究，我局批复如下：

一、原则同意在大屯土司庄园保护范围和建设控制地带内进行基础设施建设与环境整治工程和你局意见。

二、对所报方案提出如下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》和贵州省人民政府关于大屯土司庄园保护范围和建设控制地带的相关管理规定，严格控制工程量和工程范围，尽量减少施工建设对文物本体和景观环境的影响，确保文物安全。

（二）应开展专项地质勘察，明确文物所在区域泥石流、滑坡等自然灾害情况，科学论证修筑挡土墙、排水沟、截水沟及种植植被等措施的有效性，细化具体内容。挡土墙应尽量采用毛石干垒砌筑，突出地方传统营建技术特色；植被种植应采用当地品种，注意保持自然风貌，避免过度人工化。

（三）应充分考虑文物日常管理和展示利用需要，结合大屯土司庄园原有给排水系统进一步完善方案设计，合理确定给水管网和室外排水系统设计，统筹考虑山体雨水排放和污水处理问题，确保文物安全。

（四）应细化管道挖掘与恢复的具体措施和要求，尽量采用人工开挖和分段施工模式，减少工作面，避免损害文物本体。同时，应研提原石板地面修缮保护措施，注意施工过程中及时开展石板构件的编号、测绘工作，按照文物修缮程序进行拆除、归安，尽量恢复原有道路形态。

（五）应针对文物建筑特点，细化庄园内部照明、安消防设施用电设计内容，明确线路、设备安装措施和要求，确保电气设计符合国家相关法律法规和标准规范。

（六）暂不同意建设防护栏杆。应深入论证建设防护栏杆的必要性和紧迫性，补充栏杆形式设计依据，按程序另行报批。

（七）应制定必要的临时性文物保护措施和应急预案，注意加强施工过程中的文物安全监测工作，及时发现隐患，确保文物和人员安全。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工前应进行必要的考古工作，如有重要发现，应及时调整设计方案。请加强工程监管，确保文物及其环境安全。

此复。

国家文物局

2017年2月7日
