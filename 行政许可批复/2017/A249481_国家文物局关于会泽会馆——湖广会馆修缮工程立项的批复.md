# 国家文物局关于会泽会馆——湖广会馆修缮工程立项的批复

## 关于会泽会馆——湖广会馆修缮工程立项的批复

文物保函〔2017〕519号

云南省文物局：

你局《关于会泽会馆——湖广会馆建筑群保护修缮工程立项的请示》（云文物〔2017〕10号）收悉。经研究，我局批复如下：

一、同意会泽会馆——湖广会馆禹王宫、东岳宫大殿修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为会泽会馆——湖广会馆禹王宫和东岳宫大殿文物建筑。

（三）应加强现状勘察和研究，明确禹王宫、东岳宫大殿主要病害类型、残损情况等，深入分析墙体倾斜、木构件糟朽、虫蛀等病害原因，全面梳理近年来维修情况，客观评估不当改造影响和倾斜墙体稳定性，在此基础上制定有针对性的修缮措施。

（四）应深入研究和分析湖广地区建造工艺、传统做法、建筑材料和构造特征等，注意在维修中使用原工艺和原材料。

（五）应明确工程范围，严格控制工程量和工程强度，明确构件更换标准，尽可能保留和使用原有构件。

1. 倾斜墙体应整体纠偏，避免全部重砌。不同意全部重做东岳宫等文物建筑室内墙面。

2. 室内方砖地面应按照原地面形制恢复，补充禹王宫前石栏板的恢复依据。

3. 油饰应采用传统材料和做法，不同意使用现代油漆。

（六）规范文本和图纸，总平面图应标注拟修缮范围、历次修缮工程范围。

（七）暂不同意门楼、戏台、韦陀亭、东岳宫东西偏殿、寿佛殿、寿佛殿东西偏殿、寿佛殿东西天井书楼等10座文物建筑修缮工程立项。应根据文物保存现状和病害程度，区分轻重缓急，有计划、分阶段开展文物建筑保护工作。

（八）根据工程量合理编制经费预算，进一步核减工程造价，补充各单项取费依据。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案，组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年3月21日
