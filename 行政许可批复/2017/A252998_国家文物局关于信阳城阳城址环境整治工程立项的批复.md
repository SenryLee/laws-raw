# 国家文物局关于信阳城阳城址环境整治工程立项的批复

## 关于信阳城阳城址环境整治工程立项的批复

文物保函〔2017〕772号

河南省文物局：

你局《关于信阳城阳城址环境整治工程立项的请示》（豫文物〔2017〕46号）收悉。经研究，我局批复如下：

一、原则同意城阳城址环境整治工程立项。

二、在编制工程方案的过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状保护为主，将工程范围限定在城阳城址保护范围内，做好道路整治、地形恢复及绿化、垃圾清运等工程，并注意控制工程规模、范围和强度，避免过度整治。

（二）市政基础配套设施、占压遗址的建筑及构筑物拆除、村庄整治不得纳入城阳城址环境整治工程，应纳入当地人民政府的工作计划统筹考虑。

（三）环境整治总体上应注意保护遗址整体环境，维护和烘托遗址氛围，避免人工化和城市园林化的倾向。

（四）道路整治应最大化利用现状道路，严格控制成本，建议考虑沿历史路网格局布设的可能性，并与重要节点的展示相结合。地形整治应避免对历史地貌做大规模干预，仅限于对后期的无序扰动进行整治，固土绿化应选择本土物种，并注意控制规模与强度，确需实施的区域应与遗址不同遗迹的标识展示结合考虑。

（五）环境整治措施应符合《城阳城址保护总体规划》的相关要求，并与后期的展示工程相衔接。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年4月14日
