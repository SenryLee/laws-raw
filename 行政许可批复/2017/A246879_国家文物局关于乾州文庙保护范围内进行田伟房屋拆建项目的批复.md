# 国家文物局关于乾州文庙保护范围内进行田伟房屋拆建项目的批复

## 关于乾州文庙保护范围内进行田伟房屋拆建项目的批复

文物保函〔2016〕2136号

湖南省文物局：

你局《关于审批乾州文庙保护范围内田伟拆建房屋的请示》（湘文物报〔2016〕174号）收悉。经研究，我局批复如下：

一、原则同意在乾州文庙保护范围内进行田伟住宅拆建项目和你局意见。

二、对所报方案提出如下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》和湖南省人民政府关于乾州文庙保护范围的相关管理规定，以确保文物本体和历史环境安全为前提，合理兼顾民生改善。

（二）应准确核实田伟房屋的现状高度，根据乾州文庙保护范围和乾州历史文化名城的具体建设控制指标，合理调整方案设计，进一步降低新建房屋高度。拟新建房屋应尽量采用地方传统建筑式样，确保新建房屋与文物及周边景观风貌相协调。

（三）进一步完善文物影响评估报告，明确乾州文庙周边建设现状，客观评价拆建房屋对文物建筑和周边景观环境的影响，进行必要的视线分析，做到准确、科学、具有针对性。

（四）补充乾州文庙及周边环境现状照片、田伟房屋现状照片、新建房屋效果图。乾州文庙保护区划图应准确标明文物保护范围和建设控制地带，以及拟建房屋与文物的空间位置关系。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。请加强对工程的监管，确保文物及其环境安全。

四、请你局督促地方人民政府抓紧编制乾州文庙保护规划，明确文物周边的建设控制要求，统筹考虑文物保护、民生改善和城市建设发展之间的关系。

此复。

国家文物局

2017年1月4日
