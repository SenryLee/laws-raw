# 国家文物局关于吉林省2017年度考古报告出版计划的批复

## 关于吉林省2017年度考古报告出版计划的批复

文物保函〔2017〕419号

吉林省文物局：

你局《关于报送吉林省2017年度考古报告出版计划的请示》（吉文物发〔2017〕10号）收悉。经研究，我局同意所报《通化万发拔子遗址考古发掘报告》、《吉林东团山》、《自安山城》、《罗通山城》、《集安山城下墓区2016年清理报告》、《辉发城》的出版计划。

请你局按照《国家重点文物保护专项补助资金管理办法》的规定和我局有关要求，另行申请上述考古报告的出版补助经费。

国家文物局

2017年3月2日
