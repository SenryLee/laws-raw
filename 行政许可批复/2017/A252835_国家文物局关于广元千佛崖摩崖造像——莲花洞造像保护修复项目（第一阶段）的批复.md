# 国家文物局关于广元千佛崖摩崖造像——莲花洞造像保护修复项目（第一阶段）的批复

## 关于广元千佛崖摩崖造像——莲花洞造像保护修复项目（第一阶段）的批复

文物保函〔2017〕844号

四川省文物局：

你局《关于报送广元千佛崖摩崖造像莲花洞造像保护修复初步设计方案（第一阶段）的请示》（川文物〔2017〕44号）收悉。经研究，我局批复如下：

一、原则同意广元千佛崖摩崖造像——莲花洞造像保护修复项目（第一阶段）和你局意见。

二、对该初步设计方案提出以下修改完善意见：

（一）应将研究工作贯穿保护工作实施的全过程，并以研究成果作为开展各项保护措施的依据。深化现状勘察研究，进一步加强实验室和现场试验。

1．应选择综合病害严重、亟需保护的佛龛进行现场保护性试验，确定试验标准和检验指标，验证拟采用措施和试剂的有效性、安全性。

2．防风化加固材料试验应进一步延长监测周期，在小范围内选择不同风化类型开展一定周期的现场试验和评估，综合比对试验效果，为确定保护措施提供依据。

3．应注意表面附着颜料层的石质文物渗透加固问题，补充长期跟踪监测数据。

4．应补充必要的试剂可逆试验，确保试剂老化后可进行无害清理和再次保护处理。

（二）应坚持最小干预原则，严格控制工程范围及工程量，并根据文物保存现状和病害发展趋势，区分轻重缓急，分期分批开展保护工程。同时，应充分考虑莲花洞共生病害的特殊性和复杂性，合理细化治理次序和工序，适当延长各实施阶段的时间，并在分步治理和重要工序结束后及时评估治理效果，确保工程质量。

（三）应适当增加人工监测内容，合理确定监测点位的数量和布设位置，形成人工和自动化监测相结合的综合监测和效果评估体系。持续跟踪监测、分析评估保护效果，并根据评估结论及时调整、不断完善施工方案。

（四）应根据病害勘察和研究需要，进一步调整数字化和信息化措施，重点做好病害信息的采集、记录和分析工作，增强针对性。同时注意做好工程全过程的档案记录，为工程报告的编制奠定基础。

三、请你局根据上述意见指导相关单位修改、完善方案，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。同时，应指导文物管理使用单位参与文物保护工程的全过程，以利于文物的长期维护、保养和监测。

此复。

国家文物局
