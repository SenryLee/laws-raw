# 国家文物局关于魏长城——韩城市阿池村寨子及郝庄村段抢险加固项目方案的批复

文物保函〔2017〕1425号

陕西省文物局：

你局《关于上报魏长城——韩城市阿池村寨子及郝庄村抢险加固工程方案的请示》（陕文物字〔2017〕131号）收悉。经研究，我局批复如下：

一、原则同意所报魏长城—韩城市阿池村寨子及郝庄村段抢险加固项目设计方案，范围为魏长城——韩城市阿池村寨子及郝庄村段（长城认定编码：611100013）。

二、对该方案提出如下修改意见：

（一）应进一步完善设计方案，深化立面较陡、裂缝发育较重部位的稳定性评估，明确病害类型和发展趋势，采取有针对性的加固措施，有效消除安全隐患。

（二）细化工程措施实施范围和实施力度，严格控制工程量，避免过度干预。应充分论证植被清理的必要性和安全性，进一步细化清理范围、工程措施和步骤等，注意防止清除过程中、植被根系腐烂后引发遗址安全问题。建议选取局部段落进行试验评估，确定措施安全有效后再实施；不影响遗址本体稳定性的树根可不予清除。

（三）遗址顶部防排水应随形整治，不宜过度平整。遗址顶面的防护修复措施应注意与本体及周边环境相协调，不宜刷新和进行植被恢复。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善并经你局批准后组织实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好维修后相关文物的日常养护和巡查工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年8月14日
