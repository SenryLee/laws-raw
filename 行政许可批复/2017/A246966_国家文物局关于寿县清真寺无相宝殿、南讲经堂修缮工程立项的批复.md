# 国家文物局关于寿县清真寺无相宝殿、南讲经堂修缮工程立项的批复

## 关于寿县清真寺无相宝殿、南讲经堂修缮工程立项的批复

文物保函〔2017〕83号

安徽省文物局：

你局《关于批准寿县清真寺修缮工程立项的请示》（皖文物保〔2016〕138号）收悉。经研究，我局批复如下：

一、同意寿县清真寺无相宝殿、南讲经堂修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为无相宝殿、南讲经堂。暂不同意北讲经堂、北山海洞、大门及南北偏门、二道门及南北偏门、围墙等文物建筑及院落维修。

（三）应加强现状勘察和历史研究，明确文物保存现状、主要病害类型、残损情况等，查找屋面漏雨、墙体酥碱开裂、大木构件糟朽、漆皮脱落等病害原因，明确建筑历次修缮情况，在此基础上制定有针对性的修缮措施。

（四）应严格控制工程量和工程强度，合理确定木构件更换、补配的具体数量和标准，最大程度地保留文物建筑历史信息，避免过度维修。同时，应兼顾宗教活动需要，合理进行建筑内部功能设计，妥善处理文物保护与宗教活动的关系。更换下的原构件应详细测绘、登记、评估价值，妥善保管；各类工程资料应由专人管理、建档，并在工程结束后纳入寿县清真寺记录档案。

（五）应加强地方建筑做法和传统工艺特色的研究分析，并注意在工程中采用原材料、原工艺。

（六）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保障文物日常维护的顺利开展。

（七）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

四、教长室、男女澡堂、厨房和办公室等非文物建筑立面整治项目，请根据文物保护需要编制工程设计方案，由你局组织或委托第三方咨询评估机构进行方案技术评审，并经你局批准后实施。

此复。

国家文物局

2017年1月20日
