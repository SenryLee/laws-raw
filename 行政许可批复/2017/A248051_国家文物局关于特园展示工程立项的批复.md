# 国家文物局关于特园展示工程立项的批复

## 关于特园展示工程立项的批复

文物保函〔2017〕339号

重庆市文物局：

你局《关于审批全国重点文物保护单位特园展示利用工程立项报告的请示》（渝文物〔2017〕5号）收悉。经研究，我局批复如下：

一、同意特园展示工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质为文物展示工程。

（二）工程范围为特园文物建筑。

（三）结合文物价值和历史研究，强化工程前期调研，客观分析“特园”保存现状、展示需求和存在的问题，为有效提升文物展示水平奠定基础。

（四）关于复原展示内容，应充分考证其真实性，相关设计须有确凿历史依据。

（五）严格控制展示设施、设备的规模和体量，不得对文物建筑本体和历史空间格局造成破坏或改变，其外观和色彩应与文物及其环境相协调。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年2月23日
