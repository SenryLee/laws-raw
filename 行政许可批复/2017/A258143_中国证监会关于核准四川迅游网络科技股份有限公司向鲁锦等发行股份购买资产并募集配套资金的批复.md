# 中国证监会关于核准四川迅游网络科技股份有限公司向鲁锦等发行股份购买资产并募集配套资金的批复

## 关于核准四川迅游网络科技股份有限公司向鲁锦等发行股份购买资产并募集配套资金的批复

证监许可〔2017〕2081号

四川迅游网络科技股份有限公司：

《四川迅游网络科技股份有限公司发行股份及支付现金购买资产并募集配套资金暨关联交易报告书》及相关文件收悉。根据《公司法》《证券法》和《上市公司重大资产重组管理办法》（证监会令第127号）等有关规定，你公司发行股份购买资产并募集配套资金方案已经我会上市公司并购重组审核委员会审核通过，现批复如下：

一、核准你公司向鲁锦发行17,651,893股股份、向厦门允能天成投资管理合伙企业（有限合伙）发行8,849,557股股份、向宁波梅山保税港区优达投资合伙企业（有限合伙）发行5,436,156股股份、向上海钱沛创业投资中心（有限合伙）发行5,107,458股股份、向珠海横琴狮之吼科技中心（有限合伙）发行3,284,396股股份、向珠海横琴富坤创业投资中心（有限合伙）发行1,884,910股股份、向周江发行2,602,272股股份、向厦门允能天宇投资管理合伙企业（有限合伙）发行2,528,445股股份、向游涛发行2,227,968股股份、向深圳北辰大宇壹号投资中心（有限合伙）发行1,896,333股股份、向刘鹏娟发行1,152,091股股份、向霍小东发行1,568,504股股份、向朱菁发行954,874股股份、向魏建平发行868,818股股份、向重庆富坤新智能交通投资合伙企业（有限合伙）发行856,242股股份、向四川鼎祥股权投资基金有限公司发行681,616股股份、向郭飞发行502,184股股份、向深圳市深商兴业创业投资基金合伙企业（有限合伙）发行295,400股股份、向眉山鼎祥云帆创业投资基金合伙企业（有限合伙）发行295,400股股份、向珠海横琴堃铭创业投资中心（有限合伙）发行258,974股股份、向上海融玺创业投资管理有限公司发行236,338股股份、向中山天誉定增贰号股权投资管理中心（有限合伙）发行227,265股股份、向深圳前海云泰股权投资基金管理股份有限公司发行227,265股股份、向殷晓娟发行206,784股股份、向深圳市瑞然投资有限公司发行113,542股股份、向朱维发行88,615股股份、向蔡丽发行47,249股股份购买相关资产。

二、核准你公司非公开发行股份募集配套资金不超过67,300万元。

三、你公司本次发行股份购买资产并募集配套资金应当严格按照报送我会的方案及有关申请文件进行。

四、你公司应当按照有关规定及时履行信息披露义务。

五、你公司应当按照有关规定办理本次发行股份的相关手续。

六、本批复自下发之日起12个月内有效。

七、你公司在实施过程中，如发生法律、法规要求披露的重大事项或遇重大问题，应当及时报告我会。

中国证监会

2017年11月16日
