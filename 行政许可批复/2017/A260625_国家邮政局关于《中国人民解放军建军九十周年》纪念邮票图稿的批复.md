# 国家邮政局关于《中国人民解放军建军九十周年》纪念邮票图稿的批复

国邮复〔2017〕57号

中国邮政集团公司：

你公司关于报审《中国人民解放军建军九十周年》纪念邮票图稿的文（中国邮政函〔2017〕42号）收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套6枚，小型张1枚。内容分别为：1.陆军；2.海军；3.空军；4.火箭军；5.战略支援部队；6.武装警察部队。小型张：听党指挥。发行日期为2017年8月1日。经审查，同意使用根据我局意见修改后的图稿印制邮票。

此复。

国家邮政局

2017年7月19日
