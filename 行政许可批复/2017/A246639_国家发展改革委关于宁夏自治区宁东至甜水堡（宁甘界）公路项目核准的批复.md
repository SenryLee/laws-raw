# 国家发展改革委关于宁夏自治区宁东至甜水堡（宁甘界）公路项目核准的批复

发改基础[2017]120号

宁夏自治区发展改革委：

报来《关于申请核准银川至百色公路宁东至甜水堡（宁甘界）段项目的请示》（宁发改基础〔2016〕583号）及有关补充材料收悉。经研究，现就该项目核准事项批复如下：

一、为完善国家高速公路网络，深入推进西部大开发，促进沿线资源开发和区域经济社会协调发展，推动陕甘宁革命老区打赢脱贫攻坚战，同意建设宁夏自治区宁东至甜水堡（宁甘界）公路。

二、路线起自盐池县高沙窝镇（宁东能源化工基地东北侧），接已建的青银国家高速公路宁夏段，经马家滩、王乐井、冯记沟、大水坑、惠安堡，止于甜水堡镇（宁甘界），接拟建的银百国家高速公路甘肃段，全长约112.3公里。全线在高沙窝、高沙窝南、王乐井、冯记沟东、冯记沟、大水坑、萌城7处设置互通式立交。同步建设萌城互通连接线约5.4公里，以及必要的交通工程和沿线设施。

三、全线采用双向四车道高速公路标准建设，设计速度100公里/小时，路基宽度26米，桥涵设计汽车荷载等级公路-Ⅰ级。萌城互通连接线采用二级公路标准建设。其他技术指标应符合交通运输部颁发的《公路工程技术标准》（JTG B01-2014）中的有关规定。

四、该项目为政府与社会资本合作（PPP）项目，项目实施机构为宁夏回族自治区交通运输厅，社会资本方经公开招投标确定为宁夏交通投资有限公司、中交第二航务工程局有限公司、宁夏路桥工程股份有限公司组成的联合体，项目法人单位为上述联合体组建的宁夏银百高速公路建设管理有限公司。

五、项目估算总投资约为68.62亿元（静态投资约为66.15亿元）。其中，国家安排中央专项建设基金（车购税）19.29亿元作为投资补助，宁夏银百高速公路建设管理有限公司以自有资金出资14.8亿元作为资本金（约占总投资的21.6%），其余资金利用国内银行贷款解决。

本项目由宁夏银百高速公路建设管理有限公司负责项目建设、经营和养护管理。经营期内，收取车辆通行费作为投资回报。经营期满后，将本项目全部设施及相关资料无偿移交你省地方交通管理部门。你省有关部门要严格执行《公路法》、《收费公路管理条例》及其他相关法律法规规定，从严核定项目收费年限、收费标准。

六、请你委会同有关部门督促项目法人按照建设环境友好型、资源节约型公路的要求，通过加大新技术、新工艺、新材料、新理念的推广应用，优化设计，加强施工、运营期间的组织管理，把节能减排等工作落实到位。

七、在后续阶段要进一步做好以下工作：

（一）加强湿陷性黄土、泥石流和不稳定斜坡及采空区等不良地质的勘察，深化不良地质路段和特殊性岩土的处治方案。

（二）结合区域公路网及城镇规划，优化互通立交布设方案，进一步优化起点段线位和枢纽互通方案，做好与相关公路的衔接。

（三）采取切实措施保护沿线生态和环境，优化路线纵面设计，合理运用路线平纵指标，避免高填深挖。

八、请项目法人严格执行国家有关招标投标的规定，项目的勘察、设计、建筑安装工程、监理、重要设备和材料采购等全部实行公开招标，招标组织形式除勘察、设计为自行招标外，其它均为委托招标。

九、核准项目的相关文件分别是国土资源部《关于银川至百色公路宁东至甜水堡（宁甘界）段建设用地预审意见的复函》（国土资预审字〔2015〕160号）、宁夏回族自治区住房和城乡建设厅《建设项目选址意见书》（宁建选字第318号）、交通运输部《关于宁东至甜水堡（宁甘界）公路项目核准的意见》（交规划函〔2017〕49号）。

十、如需对本项目核准文件所规定的有关内容进行调整，请及时以书面形式向我委报告，并按照有关规定办理。

十一、请项目法人根据本核准文件，办理土地使用、资源利用、安全生产等相关手续。

十二、本核准文件有效期为2年，自发布之日起计算。在核准文件有效期内未开工建设项目，应在核准文件有效期届满30日前向我委申请延期。项目在核准文件有效期内未开工建设也未申请延期的，或虽提出延期申请但未获批准的，本核准文件自动失效。
