# 国家文物局关于昆仑关战役旧址护蒋洞抢险加固工程立项的批复

## 关于昆仑关战役旧址护蒋洞抢险加固工程立项的批复

文物保函〔2017〕447号

广西壮族自治区文化厅：

你厅《关于报送昆仑关战役旧址——桂南会战检讨会旧址护蒋洞抢险加固工程立项报告的请示》（桂文物报〔2017〕6号）收悉。经研究，我局批复如下：

一、同意护蒋洞抢险加固工程立项，实施范围为洞穴危岩体。

二、在编制工程技术方案时，应注意以下方面：

（一）详细调查危岩体的裂隙发育情况，查清裂隙的产状、裂隙的充填物及二次胶结程度，准确判定危岩体的破坏类型，分析危岩体对护蒋洞的危害性及危害程度，评估危岩体的稳定性。对不稳定的危岩体，应以现状加固、消除安全隐患为主，采取合理可行的危岩体加固措施。

（二）坚持最小干预原则，严格控制锚杆和灌浆加固的工程范围和工程量，不宜对已被钙质充填胶结的裂隙进行过度加固处理。

三、请你厅指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你厅组织或委托专业机构进行方案技术评审，并依据评审意见进行审批。

此复。

国家文物局

2017年3月9日
