# 国家文物局办公关于海南献林建筑安装工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕1030号

海南省文化广电出版体育厅：

你厅《关于海南献林建筑安装工程有限公司申请变更文物保护工程施工资质证书相关内容的请示》（琼文发〔2017〕168号）收悉。

经研究，我局同意海南献林建筑安装工程有限公司文物保护工程施工一级资质证书中的注册资金由“5000万元”变更为“15000万元”。请你厅通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2017年9月4日
