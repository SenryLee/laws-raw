# 国家文物局关于北京国文琰文化遗产保护中心有限公司文物保护工程勘察设计甲级资质证书内容变更的批复

## 关于北京国文琰文化遗产保护中心有限公司文物保护工程勘察设计甲级资质证书内容变更的批复

办保函〔2017〕536号

北京市文物局：

你局《关于北京国文琰文化遗产保护中心有限公司申请法定代表人变更的请示》（京文物〔2017〕434号）收悉。

经研究，我局同意北京国文琰文化遗产保护中心有限公司文物保护工程勘察设计甲级资质证书中的法定代表人由“魏青”变更为“项瑾斐”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局

2017年5月8日
