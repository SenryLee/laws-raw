# 国家文物局关于北海濠濮间修缮工程立项的批复

## 关于北海濠濮间修缮工程立项的批复

文物保函〔2017〕437号

北京市文物局：

你局《关于北海濠濮间修缮工程立项的请示》（京文物〔2016〕874号）收悉。经研究，我局批复如下：

一、同意北海濠濮间修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为宫门、云岫、崇椒室、曲桥、濠濮间、石坊、游廊等7座文物建筑及院落。

（三）应加强现状勘察，系统收集、整理文献资料、历史影像记录和历次修缮工程情况，进一步明确文物建筑的结构、主要病害类型、残损情况等，查找屋面漏雨、墙体酥碱、地面破碎等病害原因，在此基础上制定有针对性的修缮措施。

（四）应深入研究和分析北方官式园林建筑的建造工艺、传统做法、建筑材料和构造特征等，注意在维修中使用原工艺和原材料。

（五）应明确工程范围，严格控制工程量和工程强度。本次维修以现状整修为主。

1. 进一步细化工程措施，明确屋面修缮的具体要求和做法，分析和记录隐蔽部位的原始材料、构造及做法。大木构件、屋面瓦件、墙面砖等更换应慎重，科学制定构件更换标准和要求，明确具体补配数量，尽量使用原有构件，避免过度维修。

2. 应注意加强对山石、驳岸、水系等园林景观要素的保护，补充拟新做彩画、后期改建的散水、地面、墙体、吊顶、门窗等的恢复依据，严禁缺乏科学依据的盲目复原。

3. 更换下的原构件应详细测绘、登记、评估价值，妥善保管；各类工程资料应由专人管理、建档，并在工程结束后纳入北海及团城记录档案。

（六）结合工程实施，开展必要的专项测绘记录工作，为今后保护展示工作提供依据。同时，应明确文物修缮后的使用功能和展示利用方式，提供特色文化活动空间和多样化的公共文化服务。

（七）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（八）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案，组织专家或专业机构进行论证后，根据论证意见由你局进行审批。

此复。

国家文物局

2017年3月2日
