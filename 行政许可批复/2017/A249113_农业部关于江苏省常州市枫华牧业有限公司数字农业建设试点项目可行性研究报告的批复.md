# 农业部关于江苏省常州市枫华牧业有限公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕53号

江苏省农业委员会：

《江苏省农业委员会关于上报2017年数字农业建设试点项目可行性研究报告的请示》（苏农计〔2017〕6号）和《江苏省农业委员会关于上报2017年数字农业建设试点项目可行性研究报告的情况说明》收悉。经研究，批复如下：

一、原则同意上报的江苏省常州市枫华牧业有限公司数字农业建设试点项目可行性研究报告。项目建设单位为常州市枫华牧业有限公司，建设地点为江苏省常州市武进区。项目建设期2年。

二、项目建设内容：一是自动化精准环境控制系统建设，包括数字化管理平台、环境控制系统、空气过滤系统等；二是数字化精准饲喂管理系统建设，包括自动称量喂料系统、电子出入库称重计量系统、种猪自动饲喂测定系统等；三是粪污处理系统建设，包括污水处理及中水回用系统、节水冲洗设备等。

三、项目建设目标：项目建成后，实现生猪饲养环境自动调节，粪污无害化处理和资源化利用，项目区母猪产仔率和生猪成活率明显提高，年降低生产资料成本800万元。

四、项目投资及来源：经评估核定，项目估算总投资3110万元，其中中央预算内投资按933万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你省申报后续数字农业建设试点项目的资格。

农业部

2017年3月30日
