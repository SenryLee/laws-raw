# 国家文物局关于隆兴寺石质文物保护项目的批复

文物保函〔2017〕1636号

河北省文物局：

你局《关于呈报隆兴寺石质文物保护工程技术方案的请示》（冀文物字〔2017〕175号）收悉。经研究，我局批复如下：

一、原则同意所报隆兴寺石质文物保护项目和你局意见。

二、对项目提出如下意见：

（一）应严格遵守不改变文物原状、最小干预等文物保护原则，保护文物及其环境安全。建议结合对各石质文物所处微环境的勘察，进一步分析各石质文物主要病害及影响因素，并据此对各保护措施及材料配比做相应调整完善。

（二）对缺失部位的修复应以结构加固补强为主，不必强求全部补齐。

（三）对不需要清洗及保护加固的部位、区域，应进一步明确是否采取保护隔离措施。

（四）进一步论证、深化下陷石碑开挖、石碑包装防护、石碑移位吊装、地面硬化等措施的可靠性和可行性，补充相关测算依据。补充论证石碑抬升后基座的选材，应兼顾力学性能、安全性、耐候性和外观。建议石碑基础增加三七灰土，以加强其整体性及防水性能，并在夯土面上做泛水。

（五）应进一步论证搭设防护棚的必要性。进一步完善设计方案，优化构件和外观设计，使其尽可能简洁精细，并补充相关验算依据。如采用钢化玻璃棚顶，应考虑是否存在光辐射等问题。

（六）“乾隆礼大佛因题长句碑”、“乾隆礼大佛再叠旧作韵碑”、“敬叠皇考九言诗韵碑”等三通御碑本体保护与碑亭建设项目已向我局单独申报立项并获批准，不应纳入本项目范畴。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，经你局核准后实施。请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保工程质量。

专此函复。

国家文物局

2017年9月12日
