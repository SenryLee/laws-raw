# 国家文物局关于统万城西、南城壕遗址抢险加固工程立项的批复

## 关于统万城西、南城壕遗址抢险加固工程立项的批复

文物保函〔2017〕522号

陕西省文物局：

你局《关于上报统万城遗址西、南城壕抢险加固工程立项的请示》（陕文物字〔2017〕26号）收悉。经研究，我局批复如下：

一、原则同意统万城西、南城壕遗址抢险加固工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，以现状加固、消除安全隐患为主，做好城壕遗址坡面加固、周边冲沟整治及场地排水，注意控制工程规模、范围和强度，避免过度保护。

（二）切实做好前期勘察、研究和试验，查清城壕遗址及周边冲沟的汇水面积、汇水量和冲刷深度，合理确定暴雨重现期，明确对遗址的危害程度，为科学编制保护工程技术方案提供依据。

（三）遗址本体培土加固和生态固土措施应尽量采用当地土料和植被品种，并注意与当地现有生态及景观环境相协调，不得进行园林化种植。

（四）场地排水应注意尽量避免大规模工程干预，以疏导为主。

（五）严格控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年3月21日
