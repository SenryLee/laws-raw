# 国家文物局关于在大运河姚江水利航运设施压赛堰遗址建设控制地带内进行大庆南路北延二期工程项目的批复

## 关于在大运河姚江水利航运设施压赛堰遗址建设控制地带内进行大庆南路北延二期工程项目的批复

文物保函〔2017〕406号

浙江省文物局：

你局《关于上报大运河之浙东运河（宁波段）保护区划内实施大庆南路北延二期（环城北路-北环西路）工程项目的请示》（浙文物发〔2016〕352号）收悉。经研究，我局批复如下：

一、原则同意大庆南路北延二期工程和你局意见。

二、对所报方案提出以下修改意见：

（一）应严格遵守《中华人民共和国文物保护法》、《大运河遗产保护与管理总体规划》（2012-2030年）、《大运河浙江段遗产保护规划》（2012-2030年）、《大运河宁波段遗产保护规划》（2012-2030年）和浙江省人民政府关于全国重点文物保护单位大运河姚江水利航运设施压赛堰遗址保护区划的相关管理规定，尽量增加道路与文物本体之间的距离。

（二）应在方案一的基础上进一步优化设计，充分考虑压赛堰与大运河的空间关系，严格控制桥体体量，增大桥墩跨度，尽量不在河道中设置桥墩，减少对大运河与压赛堰遗址周边景观的影响。

（三）应在满足道桥建设规范要求、确保交通安全的基础上，合理缩小桥梁宽度，建议取消绿化隔离带、适当缩小人行道和辅路宽度，增加桥梁与遗址间的距离，并确保桥梁结构形式、外观等与周边环境相协调。补充压赛堰、拟建桥梁与大运河的位置关系图和设计效果图。

（四）研提道路建设期间文物本体保护措施和应急预案。

（五）深化文物影响评估，进一步说明道路施工对压赛堰遗址的影响。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后报有关部门批准实施。请你局加强工程监管，确保文物及其环境安全。

此复。

国家文物局

2017年3月1日
