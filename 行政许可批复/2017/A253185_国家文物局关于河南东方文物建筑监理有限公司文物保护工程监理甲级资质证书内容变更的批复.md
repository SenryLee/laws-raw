# 国家文物局关于河南东方文物建筑监理有限公司文物保护工程监理甲级资质证书内容变更的批复

## 关于河南东方文物建筑监理有限公司文物保护工程监理甲级资质证书内容变更的批复

办保函〔2017〕854号

河南省文物局：

你局《关于河南省东方文物建筑监理有限公司文物保护工程监理甲级资质证书内容变更的请示》（豫文物〔2017〕200号）收悉。

经研究，我局同意河南东方文物建筑监理有限公司文物保护工程监理甲级资质证书中的法定代表人由“张得水”变更为“郭绍卿”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局

2017年7月20日
