# 国家文物局关于鲁土司衙门旧址——雷坛寺壁画保护工程的批复

## 关于鲁土司衙门旧址——雷坛寺壁画保护工程的批复

文物保函〔2017〕871号

甘肃省文物局：

你局《关于呈报鲁土司衙门旧址壁画保护修复方案的报告》（甘文局发[2017]69号）收悉。经研究，我局批复如下：

一、原则同意所报鲁土司衙门旧址——雷坛寺壁画保护工程和你局意见。

二、对该方案提出以下修改意见：

（一）应加强前期试验检测分析工作，明确试验所用修复材料的具体成分和配比，补充地仗分析中纤维含量及种类鉴定内容。

（二）坚持最小干预原则，严格控制工程范围和强度，明确壁画修复的使用材料、工艺做法和操作流程。

1．明确灌浆材料的成分和配比。

2．高含盐量的无画面酥碱部位，可先清除疏松部分再进行加固处理，避免大量可溶盐封护地仗层内导致盐分遇水转移，引发新的病害。

3．应在实验室和现场试验的基础上，进一步确定修缮使用材料种类。

（三）暂不同意妙音寺和显教寺壁画修缮工程、木版画修缮工程。应根据壁画病害程度合理确定工期，分期分批开展壁画修缮工作，确保工程质量。同时，进一步论证木版画修缮的必要性和可行性。

（四）应切实做好工程档案记录和整理、归档，为文物日常养护和后续维修提供依据。

（五）应根据工程量合理核减预算，补充取费标准。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2017年4月28日
