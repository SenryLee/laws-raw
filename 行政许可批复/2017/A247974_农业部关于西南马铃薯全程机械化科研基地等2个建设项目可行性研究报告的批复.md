# 农业部关于西南马铃薯全程机械化科研基地等2个建设项目可行性研究报告的批复

农计发〔2017〕11号

重庆市农业委员会：

《重庆市农业委员会关于西南马铃薯全程机械化科研基地建设项目的请示》（渝农文〔2016〕12号）《重庆市农业委员会关于生猪健康养殖工程与装备科研基地建设项目的请示》（渝农文〔2016〕96号）收悉。经研究，批复如下。

一、西南马铃薯全程机械化科研基地建设项目。项目建设单位为重庆市农业科学院。建设地点在重庆市九龙坡区白市驿镇高峰寺村、九里村。主要建设内容包括：购置三维扫描仪、线切割机床、电火花加工机床、全自动马铃薯分级机、马铃薯收割机综合可靠性试验台、数字化土槽试验平台、通用变速箱综合试验台、震动噪声采集分析系统等仪器设备及农机具83台（套），完善田间工程。构建马铃薯农机研制、机械化作业、农机性能测试、检测等关键技术与装备集成平台。总投资1509万元，其中田间工程122.49万元、仪器设备1297.11万元、工程建设其他费58.77万元、预备费30.63万元。资金来源为中央预算内投资1372万元，地方投资137万元。建设期为投资计划下达之日起两年。项目建成后，将明显提高重庆市农业科学院在南方马铃薯全程机械化技术装备的研发能力，每年筛选试验适合机械作业的西南地区马铃薯适宜品种2—3个，集成组装马铃薯整地、种植、上土、田间管理、打秧、收获和残膜捡拾全程机械化技术装备5—10种，研究制定西南地区马铃薯全程机械化生产技术体系1—2套，编制技术规范1—2套。仪器设备按照项目建设单位的共享方案，向社会开放，进一步提高科技资源利用效率。

二、生猪健康养殖工程与装备科研基地建设项目。项目建设单位为重庆市畜牧科学院。建设地点在重庆市荣昌县广顺街道办事处高瓷村九社。主要建设内容包括：购置万能试验机、原子力显微镜、全自动纤维测定仪、母猪智能饲喂系统、生长育肥猪自动饲喂系统、臭气浓度监测仪、连续空气微生物基因组采样器等仪器设备44台（套），配套建设试验基地供配电、道路、排水（污水）沟等附属工程。构建生猪健康养殖工艺研发、环境调控监测、废弃物综合处理等技术集成和装备平台。总投资1492万元，其中田间工程40万元、建安工程30万元、仪器设备1331万元、工程建设其他费61.64万元、预备费29.36万元。资金来源为中央预算内投资1356万元，地方投资136万元。建设期为投资计划下达之日起两年。项目建成后，将显著提高重庆市畜牧科学院在养殖投入品、养殖工艺与装备、环境调控、废弃物处理与资源化利用等环节的技术与装备集成和创新能力，研发、优化生猪健康养殖设施设备2—4台（套），提供生猪福利化养殖设备性能指标数据200份，制定生猪健康养殖配套设备应用规程1—2套。仪器设备按照项目建设单位的共享方案，向社会开放，进一步提高科技资源利用效率。

请据此批复,抓紧委托有相应资质的勘察设计单位编制项目初步设计和概算，经你委审批后报我部备案。初步设计和概算编制要严格执行《关于党政机关停止新建楼堂馆所和清理办公用房的通知》（中办发[2013]17号）要求，不得将楼堂馆所等纳入项目建设内容。

请切实履行好项目监管责任，督促项目建设单位严格按照农业基本建设项目管理规定，做好项目组织实施工作，每月28日之前通过农业建设项目管理信息系统（http://ac.agri.gov.cn）填报截至当月底项目进度、资金支出等相关信息。同时，按照国家发展改革委《关于做好农口中央预算内投资总结工作的通知》要求，请分别于当年7月3日和下年1月3日前，正式报送项目半年和全年总结，总结材料包括投资安排及到位情况、项目实施进展情况、监管措施、项目效益、存在的困难和问题、有关建议等内容。
