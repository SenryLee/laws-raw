# 国家邮政局关于《科技创新》纪念邮票图稿的批复

国邮复〔2017〕56号

中国邮政集团公司：

你公司关于报审《科技创新》纪念邮票图稿的文（中国邮政函〔2017〕64号）收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套5枚，内容分别为：1. 500米口径球面射电望远镜；2.“墨子号”量子科学实验卫星；3.“探索一号”科考船；4.渤海粮仓科技示范工程；5.“神威﹒太湖之光”超级计算机。发行日期为2017年9月17日。经审查，同意使用该套图稿印制邮票。

此复。

国家邮政局

2017年7月19日
