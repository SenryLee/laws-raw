# 中国证监会关于核准华仁药业股份有限公司配股的批复

## 关于核准华仁药业股份有限公司配股的批复

证监许可〔2017〕2319号

华仁药业股份有限公司：

你公司报送的《关于2017年度向原股东配售股份的申请报告》（华仁药发字〔2017〕6号）相关文件收悉。根据《公司法》《证券法》和《创业板上市公司证券发行管理暂行办法》（证监会令第100号）等有关规定，经审核，现批复如下：

一、核准你公司向原股东配售197,221,027股新股。

二、本次发行股票应严格按照报送我会的配股说明书及发行公告实施。

三、本批复自核准发行之日起6个月内有效。

四、自核准发行之日起至本次股票发行结束前，你公司如发生重大事项，应及时报告我会并按有关规定处理。

中国证监会

2017年12月15日
