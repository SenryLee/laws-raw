# 农业部关于中国农业科学院上海兽医研究所综合实验室建设项目可行性研究报告的批复

农计发[2017]1号

中国农业科学院：

《中国农业科学院关于报送上海兽医研究所综合实验室建设项目可行性研究报告的请示》（农科院基建〔2016〕306号）收悉。经研究，原则同意该项目可行性研究报告。项目建设地点位于上海市闵行区，主要建设内容为新建综合实验室6502.5平方米，建设污水处理、给排水、电气、道路、绿化等室外配套工程；购置实验台400延米。总投资2900万元，全部为中央预算内投资。项目建设期为3年，自投资计划下达之日起计算。详见附件。

请据此批复，抓紧委托有资质的勘察设计单位编制项目初步设计报部审批。请严格按照农业基本建设项目管理规定，做好项目组织实施工作，并按月在农业建设项目管理信息系统（http://ac.agri.gov.cn）和投资项目在线审批监管平台（国家重大建设项目库模块，http://kpp.ndrc.gov.cn）中填报实施进度等相关信息。

附件：中国农业科学院上海兽医研究所综合实验室建设项目可行性研究报告批复表

农业部

2017年1月8日
