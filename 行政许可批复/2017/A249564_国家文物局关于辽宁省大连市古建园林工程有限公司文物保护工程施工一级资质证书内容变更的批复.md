# 国家文物局关于辽宁省大连市古建园林工程有限公司文物保护工程施工一级资质证书内容变更的批复

## 关于辽宁省大连市古建园林工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕403号

辽宁省文物局：

你局《关于辽宁省大连市古建园林工程有限公司办理文物保护工程施工资质单位名称、单位地址、注册资金变更手续的请示》（辽文物〔2017〕30号）收悉。

经研究，我局同意辽宁省大连市古建园林工程有限公司文物保护工程施工一级资质证书中的单位名称由“辽宁省大连市古建园林工程有限公司”变更为“大连市古建筑园林工程有限公司”，单位地址由“辽宁省大连市西岗区长白街7-1号”变更为“辽宁省瓦房店市瓦窝镇王家社区”，注册资金由“1200万元”变更为“1500万元”。请你局通知申请单位携带资质证书正、副本到我局办理相关手续。

国家文物局

2017年4月11日
