# 国家文物局关于《泗县、灵璧段运河考古发掘报告》出版立项的批复

## 关于《泗县、灵璧段运河考古发掘报告》出版立项的批复

文物保函〔2017〕488号

安徽省文物局：

你局《关于出版考古发掘报告的请示》（皖文物保〔2017〕31号）收悉。经研究，我局同意所报《泗县、灵璧段运河考古发掘报告》一书出版计划。

请按照《国家重点文物保护专项补助资金管理办法》的规定和我局有关要求，另行申请该考古报告的出版补助经费。

国家文物局

2017年3月15日
