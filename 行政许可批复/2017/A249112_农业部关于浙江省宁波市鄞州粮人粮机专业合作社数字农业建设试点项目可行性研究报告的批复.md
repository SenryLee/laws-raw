# 农业部关于浙江省宁波市鄞州粮人粮机专业合作社数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕58号

宁波市农业局：

《宁波市农业局关于申报农业部2017年数字农业建设试点项目的请示》（甬农〔2017〕25号）、《宁波市农业局关于申报农业部2017年数字农业建设试点项目的补充意见》收悉。经研究，批复如下：

一、原则同意上报的浙江省宁波市优质高效水稻数字农业技术集成示范项目可行性研究报告。项目建设单位为宁波市鄞州粮人粮机专业合作社，建设地点为宁波市海曙区。项目建设期2年。

二、项目建设内容：一是北斗精准时空服务基础设施建设，包括配置升级农机装备、北斗地基增强基站、农机高精度自动作业与精准导航系统等；二是农业生产过程管理系统建设，包括水田精准整理与作业系统、智能灌溉系统、播种监视系统、精准养分管理系统、病虫害防控系统等；三是精细管理及公共服务系统建设，包括农机具远程在线监测装置、农机监测与协同精密作业服务集成系统、农情监测与决策平台、培训展示系统等。

三、项目建设目标：项目建成后，将形成完整的水稻优质高效精准化种植技术体系，建立可持续发展的运行机制，项目区劳动力用工成本减少10%，节水10%，减少肥料施用8%，单产提高2%。

四、项目投资及来源：经评估核定，项目估算总投资2468万元，其中中央预算内投资按740万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程以及技术支撑单位等应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你市申报后续数字农业建设试点项目的资格。
