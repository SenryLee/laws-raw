# 国家文物局关于牛角寨石窟危岩体抢险加固一期保护工程的批复

## 关于牛角寨石窟危岩体抢险加固一期保护工程的批复

文物保函〔2017〕843号

四川省文物局：

你局《关于报送〈四川省眉山市牛角寨石窟危岩体抢险加固一期保护工程设计方案〉的请示》（川文物〔2017〕45号）收悉。经研究，我局批复如下：

一、原则同意牛角寨石窟危岩体抢险加固一期保护工程和你局意见。

二、对该方案提出以下修改完善意见：

（一）应将研究工作贯穿保护工作实施的全过程，并以研究成果作为开展各项保护措施的依据。

1．进一步加强牛角寨石窟价值研究。进一步深化现状勘察研究，建议使用无损设备详细勘察危岩体内部裂隙的走向和长度，客观评估危岩体发育程度和结构安全，在此基础上优化锚固方案。

2．开展石窟稳定性评估方法等关键技术研究，在此基础上制定四川地区石窟危岩体重大险情排查评估办法、抢险加固技术导则或指南。

3．加强工程全过程的档案记录，随时采集、整理相关数据和资料并进行科学分析研究，为工程报告的编制奠定基础。

4．结合工程实施，及时总结相关研究成果和工程经验，在保护模式、保护理论、保护方法、保护技术等方面为四川地区相关石窟保护工程提供示范和借鉴。

（二）不同意地震设防烈度由VI度调整为VII度。应根据《石质文物保护工程勘察规范》合理设置安全系数，避免过度干预。

（三）坚持最小干预原则，严格控制工程范围、工程强度和工程量。

1．应论证122处危岩体全部进行抢险加固的必要性和紧迫性，区分轻重缓急，现阶段重点解决影响文物和游客安全的危岩体问题，进一步核减工程量。

2．应严格限制锚固强度，合理确定锚杆数量、长度，避免过度加固。已采取措施嵌补凹槽的倾倒式岩体，现状较为稳定，不宜再进行锚杆加固。

3．嵌补加固时应处理地基并充填密实，防止沉降或滑移。脱离母岩的危岩体不宜采取灌浆方式充填后缘裂缝，可封堵岩体顶面裂缝。

（四）工程实施中，应加强对保护工作的定期评估和动态管理，持续跟踪监测、分析评估保护效果，根据评估结论及时调整、不断完善施工方案。

三、请你局根据上述意见指导相关单位修改、完善方案，经你局核准后实施。施工中请加强监管和监测，确保工程质量和文物安全。同时，应指导文物管理使用单位参与文物保护工程的全过程，以利于文物的长期维护、保养和监测。

此复。

国家文物局

2017年4月21日
