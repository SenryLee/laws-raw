# 国家文物局关于青莲阁迁移保护工程的批复

## 关于青莲阁迁移保护工程的批复

文物保函〔2017〕1179号

山东省文物局：

你局《关于上报兖州青莲阁迁移保护工程补充设计及相关材料的请示》（鲁文〔2017〕52号）收悉。经研究，我局批复如下：

一、原则同意所报青莲阁迁移保护工程和你局意见。

二、对所报工程提出如下意见：

（一）迁移保护方案需在方案二的基础上进一步修改完善，并进一步依法完善工程实施依据和可行性。

（二）应严格遵循文物保护原则实施整体迁移保护工程，全面保护青莲阁的文物价值和历史信息。迁移施工前，应补充木构件安全性鉴定评估，必要时可采取可逆的防护措施或进行适度修缮。

（三）应采取必要措施保护青莲阁原基址，并做好标识展示。

（四）迁移新址周边环境应尽量与青莲阁风貌相协调，不宜过度园林化，应结合文物展示利用适当进行优化设计。

三、请你局组织相关单位根据上述意见对方案进行修改、完善，经你局核准后依法报山东省人民政府批准。施工中应加强监管和动态监测，确保工程质量和文物安全。

此复。

国家文物局

2017年7月6日
