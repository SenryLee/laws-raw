# 国家文物局关于西交民巷近代银行建筑群中央银行北平分行旧址外立面修缮项目的批复

文物保函〔2017〕1864号

北京市文物局：

你局《关于西交民巷近代银行建筑群中央银行北平分行旧址外立面修缮工程设计方案的请示》（京文物〔2017〕1315号）收悉。经研究，我局批复如下：

一、原则同意所报方案。

二、对方案提出以下修改意见：

（一）补充2007年修缮项目范围及效果评估等内容。

（二）进一步深化文物建筑现状勘察，明确残损量；补充对建筑原材料、原工艺做法的勘查分析。

（三）选取建筑隐蔽部位对保护材料配比、实施工艺和清洗手段等进行实验分析，根据实验结论合理确定建筑修复材料和工艺后再行实施。

（四）补充工程量、具体施工工艺、材料做法、配比等内容。

（五）原构件不需进行防腐处理；刷防火涂料对原构件干预较大，应予取消。

（六）门头石鹰雕饰的恢复应慎重，需补充相应的文献依据。

（七）进一步完善设计图纸，补充主要维修部位详图；补充主要材质、工艺做法、维修数量标注。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前应督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强工程监管，及时开展工程检查，督促项目单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年11月16日
