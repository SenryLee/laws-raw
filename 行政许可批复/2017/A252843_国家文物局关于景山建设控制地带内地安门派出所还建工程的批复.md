# 国家文物局关于景山建设控制地带内地安门派出所还建工程的批复

## 关于景山建设控制地带内地安门派出所还建工程的批复

文物保函〔2017〕855号

北京市文物局：

你局《关于地安门派出所还建工程设计方案的请示》（京文物〔2017〕157号）收悉。经研究，我局批复如下：

一、原则同意在全国重点文物保护单位景山建设控制地带内进行地安门派出所还建工程和你局意见。

二、对该方案提出以下修改完善意见：

（一）该项目位于全国重点文物保护单位景山三类建设控制地带内，应严格遵守《中华人民共和国文物保护法》、《北京历史文化名城保护条例》、《北京历史文化名城保护规划》、《北京市旧城二十五片历史文化保护区保护规划》的有关要求，合理确定拟建建筑的高度、规模和外观样式，严格控制施工范围，不宜建设地下停车场，尽量减少对文物本体和景观环境的影响。

（二）应根据文物影响评估报告进一步补充、完善设计方案，明确现存文物建筑基址的保护措施和要求，按照文物保护原则开展庄士敦故居文物修缮工作，妥善处理好新建建筑与文物建筑之间的衔接关系。补充方案设计说明。

（三）应充分考虑工程建设对文物建筑的影响，制定施工中的文物保护措施和应急预案。

（四）依法妥善做好庄士敦故居修缮工作，确保文物安全。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。施工前应进行必要的考古工作，明确拟施工区域的地下文物分布情况，如有重要发现，应及时调整设计方案。请加强工程监管，确保文物安全。

此复。

国家文物局

2017年4月28日
