# 国家文物局关于通济渠商丘南关段遗址本体保护展示项目的批复

文物保函〔2017〕1687号

河南省文物局：

你局《关于报批通济渠商丘南关段遗址本体保护展示工程设计方案的请示》（豫文物（2017）227号）收悉。经研究，我局批复如下：

一、原则同意所报通济渠商丘南关段遗址本体保护展示项目和你局意见。

二、应在方案二的基础上进一步深化完善设计，具体修改意见如下：

（一）同意对遗址本体进行回填保护，并在其上方进行模拟展示，不同意另行建设新的保护性建筑。

（二）进一步论证回填前对遗址本体的保护加固措施，建议以清理表面杂物和生物为主。在未开展有效实验前，不得大范围使用化学加固手段。

（三）进一步细化回填的工程措施，如隔离层材料材质要求、回填材料的强度要求及具体工艺等。建议分层回填，并注意留足回填层自然沉降时间，防止出现大的沉陷变形。

（四）现有保护棚拆除应制定详细方案、工序搭接和相关预案，防止对文物本体造成新的破坏。

（五）进一步深化完善模拟展示设计。表面处理应尽可能接近遗址本体，并考虑后期运营维护成本。

（六）应统筹设计与周边环境的关系，可考虑利用地形变化展示运河遗址的空间感。景观环境设计应最大限度削弱人工化、公园化倾向，缩减广场规模，不得设置具象的景观小品。不宜恢复水系，避免对遗址本体的潜在威胁。

（七）进一步细化工程方案，规范文本和图纸，补充各类施工详图。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，经你局核准后实施。请切实加强协调和工程监管，督促项目管理单位和方案设计单位加强施工全过程指导，落实各方责任，确保工程质量。

此复。

国家文物局
