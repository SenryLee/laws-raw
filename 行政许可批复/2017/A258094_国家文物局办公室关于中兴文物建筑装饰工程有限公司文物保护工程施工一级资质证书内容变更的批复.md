# 国家文物局办公室关于中兴文物建筑装饰工程有限公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕1266号

北京市文物局：

你局《关于中兴文物建筑装饰工程有限公司文物保护施工资质证书单位地址变更的请示》（京文物〔2017〕1379号）收悉。

经研究，我局同意中兴文物建筑装饰工程有限公司文物保护工程施工一级资质证书中的单位地址由“北京市东城区交道口北头条76号M132房间”变更为“北京市怀柔区北房镇幸福西街1号301室”。请你局通知申请单位携带资质证书副本到我局办理相关手续。

国家文物局办公室

2017年11月15日
