# 国家文物局关于故宫西城墙（K0+330~K0+563段）修缮项目补充方案的批复

文物保函〔2017〕1768号

北京市文物局：

你局《关于故宫西城墙（K0+330～K0+563段）修缮工程补充方案的请示》（京文物〔2017〕1195号）收悉。经研究，我局批复如下：

一、原则同意所报补充方案及你局意见。

二、具体修改意见如下：

（一）补充说明原方案的审批及实施等情况、补充设计的原因和依据、现状勘察报告。

（二）建议对试验段工程进行总结，作为补充设计的重要依据，并在此基础上进一步完善相关工程措施，按照“最小干预”原则明确各项措施的实施范围，严格控制干预力度。

（三）进一步细化部分修缮措施，明确材料和工艺要求。细化城墙顶部海墁、宇墙、排水口、砖结构底部基础、散水等的维修做法，以及上述部位与周边已修缮部位的衔接做法；补充地面防水垫层做法的设计依据，审慎选择其用材，考虑长期耐候性；拉结金属杆件直径宜适当缩小，并应妥善考虑其安装方式及外观效果；明确补配材料的质量要求。

（四）明确增加的工程量，并补充工程预算。

三、请你局指导有关单位，按照上述意见对所报方案进行修改、完善，经你局核准后实施。请切实加强工程监管，督促方案设计单位加强施工全过程技术指导，落实各方责任，确保工程质量和文物、人员安全。

此复。

国家文物局

2017年10月20日
