# 国家文物局关于坡头泰山庙边坡抢险加固工程立项的批复

## 关于坡头泰山庙边坡抢险加固工程立项的批复

文物保函〔2017〕80号

山西省文物局：

你局《关于申请盂县坡头泰山庙护坡抢险加固工程立项的请示》（晋文物〔2016〕205号）收悉。经研究，我局批复如下：

一、同意坡头泰山庙东侧边坡抢险加固工程立项。

二、在编制工程方案时，应注意以下方面：

（一）工程应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程内容为坡头泰山庙东侧边坡抢险加固。

（三）加强现状勘察，查明工程地质条件、文物所在区域降水量和地表径流量、影响边坡稳定的主要原因等，科学评估边坡的结构稳定性，为制定工程措施提供依据。

（四）以现状加固为主，严格控制工程范围和规模。应进一步细化边坡设计，充分考虑荷载问题，合理确定边坡结构和技术措施。边坡夯土应加骨料夯实，放脚及坡度应随地形设计，边缘不宜砌筑围墙；防水砂浆上不宜铺墁青砖。

（五）充分考虑边坡外观对景观风貌的影响，采取必要的针对性处理措施。

三、请你局根据上述意见和《文物保护工程设计文件编制深度要求（试行）》、《全国重点文物保护单位文物保护工程申报审批管理办法（试行）》的有关规定，组织具有相应资质的专业单位编制工程技术方案，组织或者委托第三方咨询评估机构进行方案技术评审，并依据评估结论进行审批。

此复。

国家文物局

2017年1月20日
