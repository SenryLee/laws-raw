# 国家文物局关于乾陵东、西鹊台遗址本体加固保护工程立项的批复

## 关于乾陵东、西鹊台遗址本体加固保护工程立项的批复

文物保函〔2017〕423号

陕西省文物局：

你局《关于上报乾陵东、西鹊台遗址抢险加固保护工程立项的请示》（陕文物字〔2017〕15号）收悉。经研究，我局批复如下：

一、原则同意乾陵东、西鹊台遗址本体加固工程立项。

二、在工程方案编制过程中应注意以下几个方面：

（一）应坚持最小干预原则，做好乾陵东、西鹊台遗址本体的坑洞补填、裂隙加固等加固保护工程，以现状加固、消除安全隐患为主，注意控制工程规模、范围和强度，避免过度保护。同时，应注意尽量维持遗址现有风貌。

（二）切实做好前期勘察、研究和试验，查明遗址残损程度和范围，分析病害类型和成因，评估病害对遗址的危害程度及遗址的稳定性，明确遗址的建筑结构、材料和工艺等，为编制保护工程技术方案提供科学依据。

（三）工程措施和材料应当尽量符合传统工艺，可采用土坯砌补、支撑等物理方法减缓遗址本体的损坏，不得采用化学保护方法，保护材料和技术应结合现状评估进行试验、筛选之后合理确定。

（四）遗址表面植被清理应适度，对遗址保护工程有妨碍或对遗址有明显危害的植被可进行清理，不影响遗址本体安全的植被应适当修整保留。

（五）严格控制工程规模和范围，补充预算依据，科学编制预算。

三、请你局组织专业机构根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制工程技术方案，委托或组织专业机构进行方案技术评审，并依据评估结论进行审批。

国家文物局

2017年3月2日
