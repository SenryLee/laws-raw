# 国家文物局关于紫金庵罗汉塑像数字化勘察测绘工程立项的批复

## 关于紫金庵罗汉塑像数字化勘察测绘工程立项的批复

文物保函〔2017〕569号

江苏省文物局：

你局《关于审批紫金庵罗汉塑像数字化勘察测绘工程立项的请示》（苏文物保〔2017〕29号）收悉。经研究，我局批复如下：

一、同意紫金庵罗汉塑像数字化勘察测绘项目立项。

二、在编制工程技术方案时，应注意以下方面：

（一）应进一步明确项目的主要任务和目标，科学确定工程内容、工作量、工作分期、预期成果和主要精度指标等，利用数字化技术全面采集、记录文物的各类信息，为科学分析彩塑制作技术、使用材料和病害情况等提供依据。

（二）应针对塑像特点和保护工作需要，科学选择勘察测绘方式，明确精度要求。建议采用“色度数据采集”等多种检测手段，全面勘察、评估彩塑内部损伤、腐朽、后期修补等情况；文物重点部位活动性病害监测应注意结合传统与现代监测手段；进一步明确建筑沉降、开裂、歪闪、拔隼等病害监测与建筑载体稳定性评估的具体方法；影像采集分辨率以250-350dpi为宜。

（三）应明确项目成果体系，说明数字化勘察测绘成果与后续长期监测工作之间的衔接内容，补充数字化勘察测绘过程中的文物安全防护措施，确保文物及人员安全。

（四）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（五）根据工程量合理编制经费预算，确定取费项目，补充取费标准。

（六）应结合紫金庵罗汉塑像数字化勘察测绘项目，研究彩塑类文物数字化勘察测绘的技术要求和操作流程，全面总结工程经验，为制订相关技术标准提供依据。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的数字化工程技术方案，组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年3月27日
