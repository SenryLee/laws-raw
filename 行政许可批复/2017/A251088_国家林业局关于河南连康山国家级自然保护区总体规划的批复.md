# 国家林业局关于河南连康山国家级自然保护区总体规划的批复

林规发〔2017〕37号

河南省林业厅：

《河南省林业厅关于上报河南连康山国家级自然保护区总体规划的请示》（豫林计﹝2016﹞12号）收悉。经研究，现对《河南连康山国家级自然保护区总体规划（2016—2025年）》（以下简称《总体规划》）批复如下：

一、我局原则同意《总体规划》。河南连康山国家级自然保护区的建设管理要严格按照《总体规划》的指导思想、规划布局、功能区划、保护建设内容开展实施，有力提升完善自然保护区的基本功能，不断增强自然保护区的管理能力（具体批复详见附件）。

二、河南连康山国家级自然保护区要按照《森林法》、《野生动物保护法》、《自然保护区条例》、《全国主体功能区规划》、《国家级自然保护区总体规划审批管理办法》等法律法规有关要求，加强自然生态系统和野生动植物资源的保护，严格落实禁止开发区管控原则。

三、《总体规划》所需的建设资金，根据建设项目性质，需要中央投资扶持的，按照基本建设程序对工程建设项目单报单批；需要地方财政资金或贷款方式解决的，由你厅予以落实。除保护管理工程项目外，其他工程建设项目需另行履行报批手续。

特此批复。
