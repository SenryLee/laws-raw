# 农业部关于广东省农垦总局阳江垦区等2个天然橡胶基地建设项目可行性研究报告的批复

农计发〔2017〕6号

广东省农垦总局:

你局报送的农垦天然橡胶类项目可行性研究报告及相关上报文件收悉。经研究，原则同意下列项目可行性研究报告。

1.茂名垦区天然橡胶基地建设项目，建设地点位于广东省茂名市化州市建设农场、红峰农场、红阳农场、新华农场、新时代农场、和平农场，高州市团结农场、胜利农场、火星农场，电白区曙光农场、水丰农场。主要建设内容为新植胶园710亩，更新胶园4400亩，建设管护用房132套、总面积5940平方米，储胶池25座、总面积4000平方米。总投资2582万元，其中中央预算内投资2065万元，地方投资517万元（详见附件1）。

2.阳江垦区天然橡胶基地建设项目，建设地点位于广东省阳江市阳春市三叶农场、阳东区红五月农场、阳西县织篢农场、江城区红十月农场、阳东区鸡山农场。主要建设内容为更新胶园500亩，建设胶园林间道路21.5千米，新建胶园管护用房30套、总面积1500平方米，储胶池39座、总面积3900平方米。总投资1660万元，其中中央预算内投资1325万元，地方投资335万元（详见附件2）。

上述项目建设期均为2年，自投资计划下达之日起计算。

请据此批复，督促建设单位抓紧委托有资质的勘察设计单位编制项目初步设计报你局审批。请严格按照农业基本建设项目管理规定，做好项目组织实施工作，并按月在农业建设项目管理信息系统（http://ac.agri.gov.cn）和投资项目在线审批监管平台（国家重大建设项目库模块，http://kpp.ndrc.gov.cn）中填报实施进度等相关信息。

附件：1.广东农垦茂名垦区天然橡胶基地建设项目可行性研究报告批复表

2.广东农垦阳江垦区天然橡胶基地建设项目可行性研究报告批复表

农业部
