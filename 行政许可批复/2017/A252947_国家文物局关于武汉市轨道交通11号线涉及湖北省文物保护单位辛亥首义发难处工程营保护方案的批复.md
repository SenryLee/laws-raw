# 国家文物局关于武汉市轨道交通11号线涉及湖北省文物保护单位辛亥首义发难处工程营保护方案的批复

## 关于武汉市轨道交通11号线涉及湖北省文物保护单位辛亥首义发难处工程营保护方案的批复

文物保函〔2017〕1061号

湖北省文物局：

你局《关于申报武汉市轨道交通11号线涉及省级文物保护单位辛亥首义发难处工程营保护方案的请示》（鄂文物〔2017〕26号）收悉。经研究，我局批复如下：

一、原则同意所报选线方案。

二、对该方案提出以下修改意见：

（一）进一步优化选线方案，完善避让措施，尽可能远离文物保护范围。

（二）补充武汉已建地铁运行振动对相同距离文物建筑影响情况的监测结果，通过对比分析说明11号线地铁运行对文物本体影响符合《古建筑防工业振动技术规范》。

（三）适当加大埋深，并根据岩土层的物理力学性质及均匀性、文物本体的结构特征对变形的敏感性、线路穿越与文物本体的空间位置等，合理确定盾构的施工系数、质量标准和技术要求，正确设定平衡压力和推进速度，减少超挖与欠挖现象，控制好盾构姿态，加强同步和二次注浆，控制好注浆量和注浆压力，消除施工中影响文物安全的隐患，确保文物的安全。

（四）建立完整的监测系统，加大监测频率，制定纠偏、防塌及减振等防灾预案，必要时应对文物本体进行预加固。

三、请你局指导相关单位根据上述意见对方案进行修改完善，经你局核准后实施。工程施工期间，应加强对工程的监管，确保文物安全。

此复。

国家文物局

2017年6月5日
