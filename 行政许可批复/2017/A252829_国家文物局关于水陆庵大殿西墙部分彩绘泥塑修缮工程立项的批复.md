# 国家文物局关于水陆庵大殿西墙部分彩绘泥塑修缮工程立项的批复

## 关于水陆庵大殿西墙部分彩绘泥塑修缮工程立项的批复

文物保函〔2017〕806号

陕西省文物局：

你局《关于上报蓝田县水陆庵彩绘泥塑保护修复工程立项的请示》（陕文物字〔2017〕26号）收悉。经研究，我局批复如下：

一、同意水陆庵大殿西墙部分彩绘泥塑修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为水陆庵大殿西墙千人听经图区域南端80尊彩绘泥塑。

（三）应加强前期勘察和研究，明确彩绘泥塑的形制、工艺材料和技法，科学评估其年代及价值，深入分析病害产生原因、类型及影响因素，在此基础上制定有针对性的保护措施。补充说明彩绘泥塑支撑体的保存情况。

（四）全面总结水陆庵彩绘泥塑病害治理工作的已有经验成果，在此基础上细化保护措施，客观评价中德合作研究及水陆庵大殿东墙壁塑险情修复工程效果，为制定具体工程措施提供科学依据。

（五）坚持最小干预原则，以支撑体加固为主，科学制定具体工程措施和技术流程，严格控制工程范围、规模与工程量。补充墙体渗漏水和毛细水治理措施；不同意缺失塑像补塑和补贴所有饰金。

（六）应注意做好工程资料的记录工作，详细拍照、记录各关键工序和步骤，最大限度地保存历史信息。工程资料应由专人管理、建档，并在工程结束后纳入水陆庵记录档案。

（七）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（八）根据工程量合理编制经费预算，确定取费项目，补充取费标准。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案，组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

四、请你局督促地方人民政府切实加强水陆庵日常保养和岁修工作，加强文物监测，并根据当地气候条件、文物保存现状和病害程度，综合考虑水陆庵病害治理问题，区分轻重缓急，有计划、分阶段开展彩绘泥塑保护工作，确保工程质量和文物安全。

此复。

国家文物局

2017年4月19日
