# 国家文物局关于妙应寺白塔中路文物建筑修缮工程立项的批复

## 关于妙应寺白塔中路文物建筑修缮工程立项的批复

文物保函〔2016〕2153号

北京市文物局：

你局《关于妙应寺白塔中路木构建筑修缮工程立项的请示》（京文物〔2016〕1485号）收悉。经研究，我局批复如下：

一、同意妙应寺白塔中路文物建筑修缮工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属于文物修缮工程，应遵循不改变文物原状、最小干预等文物保护原则，保护文物及其历史环境的真实性和完整性。

（二）工程范围为妙应寺天王殿、大觉宝殿、七佛宝殿、具六神通殿、东西配殿、东西围房等文物建筑。山门、钟鼓楼等复建建筑的修缮工程不应纳入本项目。

（三）加强现状勘察和研究，结合工程实施开展全面测绘，明确文物建筑残损情况、原因和病害类型等，搜集、梳理历史文献和影像资料，根据不同建筑的残损现状制定有针对性的修缮措施。补充早期彩画的现状评估内容。

（四）应深入研究和分析地方建造工艺、传统做法、建筑材料和构造特征等，明确拟修缮文物建筑的历次修缮过程和营造做法，注意在维修中使用原工艺和原材料。

（五）应严格控制工程量和工程强度，合理确定大木构件更换、补配的具体数量和标准，避免过度维修。明确彩画保护与重绘措施，并注意可识别性。施工中应及时做好重要工艺、关键工序、隐蔽工程的记录；更换下的原构件应详细测绘、登记、评估价值，妥善保管；各类工程资料应由专人管理、建档，并在工程结束后纳入妙应寺白塔记录档案。

（六）应根据文物保存现状和病害发展趋势，合理确定具体施工计划和进度安排，区分轻重缓急，分期分批开展保护工程。同时，结合妙应寺白塔保护展示和管理需要，进一步明确拟修缮文物建筑的使用功能和定位，确保文物合理利用，并做好文物保护工程与展示利用工程之间的衔接。

（七）应注意吸纳管理单位人员参与项目实施，提高人员的保护水平和能力，保证文物日常维护的顺利开展。

（八）根据工程量和措施强度合理编制经费预算，进一步调减工程造价，补充取费标准。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案，组织或委托第三方咨询评估机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年1月4日
