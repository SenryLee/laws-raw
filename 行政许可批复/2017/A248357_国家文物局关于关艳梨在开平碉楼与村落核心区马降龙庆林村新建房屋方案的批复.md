# 国家文物局关于关艳梨在开平碉楼与村落核心区马降龙庆林村新建房屋方案的批复

## 关于关艳梨在开平碉楼与村落核心区马降龙庆林村新建房屋方案的批复

文物保函〔2017〕418号

广东省文物局：

你局《关于关艳梨在开平碉楼与村落核心区马降龙庆林村新建房屋方案的请示》（粤文物审〔2016〕166号）收悉。经研究，我局批复如下：

一、原则同意所报方案和你局初审意见。

二、请你局加强对项目实施的监管，确保文物安全以及新建建筑立面色彩、建筑外观、屋顶形式等与文物本体及其周边环境保持协调。

此复。

国家文物局

2017年3月3日
