# 国家文物局关于扬州市桑树脚地块考古发掘项目的批复

## 关于扬州市桑树脚地块考古发掘项目的批复

文物保函〔2017〕1073号

江苏省文物局：

你局关于扬州市桑树脚地块考古发掘项目申请书（存档编号2017176018）收悉。经研究，我局批复如下：

一、同意在扬州市邗江区桑树脚地块进行考古发掘。发掘过程中，应注意发现、并有重点地保护涉及中唐时期扬州开元寺、晚唐五代光孝院两处古代建筑的相关遗迹，为进一步明确该区域的文物分布情况和文物价值提供依据。请你局加强管理，确保工作质量和工地安全，如有重要考古发现，应及时向我局报告。

二、考古发掘结束后，请你局根据考古工作结果，指导地方政府和有关单位做好重要遗迹的保护工作，确保文物保护与城市建设的协调发展。

国家文物局

2017年6月12日
