# 国家文物局关于西安市古代建筑工程公司文物保护工程施工一级资质证书内容变更的批复

## 关于西安市古代建筑工程公司文物保护工程施工一级资质证书内容变更的批复

办保函〔2017〕154号

陕西省文物局：

你局《关于西安市古代建筑工程公司申请变更文物保护工程施工资质证书相关信息的请示》（陕文物字〔2017〕42号）收悉。

经研究，我局同意西安市古代建筑工程公司文物保护工程施工一级资质证书中的法定代表人由“王凯”变更为“高志军”。请你局通知申请单位，携带资质证书副本到我局办理相关手续。

国家文物局

2017年2月22日
