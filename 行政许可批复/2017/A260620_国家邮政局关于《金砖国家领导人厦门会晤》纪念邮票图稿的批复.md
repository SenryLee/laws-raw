# 国家邮政局关于《金砖国家领导人厦门会晤》纪念邮票图稿的批复

国邮复〔2017〕49号

中国邮政集团公司：

你公司关于报审《金砖国家领导人厦门会晤》纪念邮票图稿的文（中国邮政函〔2017〕45号）收悉。根据我局审定的2017年纪特邮票发行计划，该纪念邮票一套1枚，内容为：金砖国家领导人厦门会晤。发行日期为2017年8月19日。经审查，同意使用该套图稿（图稿复印件见附件）印制邮票。

此复。

附件：“金砖国家领导人厦门会晤”纪念邮票图稿复印件
