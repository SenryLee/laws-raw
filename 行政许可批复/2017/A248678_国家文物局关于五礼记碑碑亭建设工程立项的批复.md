# 国家文物局关于五礼记碑碑亭建设工程立项的批复

## 关于五礼记碑碑亭建设工程立项的批复

文物保函〔2017〕493号

河北省文物局：

你局《关于五礼记碑保护性设施建设工程立项的请示》（冀文物字〔2017〕24号）收悉。经研究，我局批复如下：

一、同意五礼记碑碑亭建设工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程属保护性设施建设工程，工程内容为五礼记碑碑亭建设。

（二）应全面加强现状勘察，明确五礼记碑的保存现状、主要病害类型、残损情况等，进一步研提适于石碑保存的温湿度、光照等环境控制指标，全面评估石碑的安全稳定性和工程建设影响，为碑亭设计提供依据。

（三）应进一步加强前期研究，全面收集同时期碑亭建筑的相关历史资料，明确碑亭的建筑形制、年代特征和风格样式。碑亭外观设计应从满足保护功能需求出发，尽量简洁、大方，与周边环境风貌相协调。

（四）应坚持最小干预原则，严格控制碑亭的规模和工程范围，细化具体工程措施、施工要求和五礼记碑的临时性保护措施，确保施工过程中的文物安全。

（五）应结合工程实施，系统评估1989年搬迁保护后五礼记碑的保存情况和加固构件的有效性，开展必要的监测分析，为今后做好五礼记碑的保护展示工作提供依据。

（六）应根据工程量合理编制经费预算，补充取费标准，进一步细化各单项取费依据。

三、请你局指导有关单位，根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，编制具体的修缮工程技术方案，组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年3月14日
