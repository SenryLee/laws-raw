# 国家文物局关于渌江书院展示利用工程立项的批复

## 关于渌江书院展示利用工程立项的批复

文物保函〔2017〕427号

湖南省文物局：

你局《关于渌江书院展示利用工程立项的请示》（湘文物〔2017〕16号）收悉。经研究，我局批复如下：

一、同意渌江书院展示工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质为文物展示工程。

（二）工程范围为渌江书院文物建筑。

（三）加强历史和价值研究，增加展示深度和广度。相关设计应突出文物价值和内涵，全面展示和阐释建筑初始规划及其后期演变，建筑风貌特点及构造、工艺，以及建筑与环境的相互关系等各方面内容。

（四）模拟室内场景须有相关历史依据；布设展示设施、设备不得破坏文物本体，不得改变建筑原有结构、格局及历史风貌，不得增加文物本体结构荷载，其外观、色彩和体量应与文物及其环境相协调，材质应符合防火要求。

（五）尽可能保持文物建筑的原有的相对空间关系，连廊和前檐等区域不宜增设围护。

（六）补充游客容量估算，合理确定服务设施规模、位置及参观路线、疏散方式等内容，完善交通与消防、逃生通道等管理要求。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年3月3日
