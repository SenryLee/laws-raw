# 国家文物局关于夏琼寺核心文物建筑区挡土墙抢险加固项目的批复

文物保函〔2017〕1364号

青海省文物管理局：

你局《关于夏琼寺核心文物建筑区挡土墙抢险加固工程设计方案的请示》（青文物局〔2017〕66号）收悉。经研究，我局批复如下：

一、原则同意夏琼寺核心文物建筑区挡土墙抢险加固项目和你局意见。

二、对该项目提出以下意见：

（一）应深化现状勘察和研究，明确挡土墙开裂、起鼓原因，准确评估挡墙和边坡稳定性。

（二）应坚持最小干预原则，在确保文物安全的基础上，严格控制并校核锚索地梁加固规模和工程量，并加固后挡墙的外观协调性，避免过度加固。

（三）应优化加固设计方案，根据墙体病害的发育范围和危险程度，提供针对性的加固措施，提高方案针对性和可操作性，如研究拆砌归安、锚索加固、裂缝灌浆等措施的可行性。如系边坡整体或局部滑移引发，建议采取抗滑桩加固措施。进一步完善地表排水系统设计，防止地表水下渗。

（四）工程实施前应进行必要的预加固处理或临时性支护措施，确保文物和人员安全。

三、具体工程方案由你局根据上述意见指导相关单位修改、完善并经你局核准后按程序报相关部门批准实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局

2017年8月7日
