# 国家邮政局关于2018年纪特邮票发行计划的批复

国邮复〔2017〕105号

你公司关于报审2018年纪特邮票发行计划的文（中国邮政函〔2017〕90号）收悉。经国家邮政局局长办公会议审定，2018年纪特邮票发行计划计32套，其中纪念邮票12套，特种邮票20套（见附件）。

此复。
