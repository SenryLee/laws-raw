# 中国证监会关于核准华夏基金管理有限公司变更股权的批复

## 关于核准华夏基金管理有限公司变更股权的批复

证监许可〔2017〕1523号

华夏基金管理有限公司：

你公司报送的《关于华夏基金管理有限公司股东变更的申请报告》（华基文〔2017〕554号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

一、核准南方工业资产管理有限责任公司将其持有的你公司7.8%股权分别转让给Power Corporation of Canada、Mackenzie Financial Corporation，山东省农村经济开发投资公司将其持有的你公司10%股权转让给Mackenzie Financial Corporation。转让完成后，你公司股权结构为：

人民币　万元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额 | 出资比例 |
| 1 | 中信证券股份有限公司 | 14,803.6 | 62.2% |
| 2 | Power Corporation of Canada | 3,308.2 | 13.9% |
| 3 | Mackenzie Financial Corporation | 3,308.2 | 13.9% |
| 4 | 青岛海鹏科技投资有限公司 | 2,380 | 10% |
|  | 合计 | 23,800 | 100% |

二、你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2017年8月18日
