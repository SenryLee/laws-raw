# 国家文物局关于清华大学物理楼工程设计方案的批复

## 关于清华大学物理楼工程设计方案的批复

文物保函〔2017〕576号

北京市文物局：

你局《关于清华大学物理楼工程设计方案的请示》（京文物〔2017〕159号）收悉。经研究，我局批复如下：

原则同意清华大学物理楼工程设计方案。鉴于拟建项目可能位于京西清代苑囿遗址占地范围内，施工前应对项目区域进行必要的考古工作，如有重要发现，应及时调整设计方案。

请你局指导有关单位进一步深化设计方案，经你局核准并报相关部门批准后实施。施工中请加强监管，确保文物安全。

此复。

国家文物局

2017年3月27日
