# 国家文物局关于洪江古建筑群建设控制地带内进行阮江路片区环境整治暨旅游配套（烟雨洪江）项目的批复

## 关于洪江古建筑群建设控制地带内进行阮江路片区环境整治暨旅游配套（烟雨洪江）项目的批复

文物保函〔2017〕331号

湖南省文物局：

你局《关于审批〈洪江古建筑群建设控制地带阮江路片区环境整治暨旅游配套（烟雨洪江）项目方案设计方案〉的请示》（湘文物报〔2016〕177号）收悉。经研究，我局批复如下：

一、原则同意在洪江古建筑群建设控制地带内进行阮江路片区环境整治暨旅游配套（烟雨洪江）项目和你局意见。

二、对所报方案提出以下修改完善意见：

（一）应严格遵守《中华人民共和国文物保护法》、《洪江古建筑群文物保护规划》以及湖南省人民政府关于全国重点文物保护单位洪江古建筑群建设控制地带的相关管理规定，严格控制新建建筑的密度、规模、高度和外观样式及施工范围，所报项目各类建设活动不得进入洪江古建筑群保护范围，尽量减少对文物本体的影响，确保文物安全，并确保与文物及周边景观风貌相协调。

（二）补充相关城市总体规划、控制性详细规划、《洪江古城保护与利用规划》以及《民国时期洪江地图》、《清代洪江街市全境图》等设计依据，完善项目实施的必要性与可行性分析。补充和深化现状研究，明确项目地段内现有建筑的建造年代、形制、价值及街巷格局等，综合评估与洪江古建筑群的关系和景观协调程度，根据评估结论科学确定环境整治的力度、范围和具体措施，不得大拆大建。特别是建设范围内的各级各类文物保护单位、未定级不可移动文物建筑不得拆除，应严格按照《中华人民共和国文物保护法》、《洪江古建筑群文物保护规划》等的相关要求进行妥善保护修缮。

（三）进一步细化方案设计，严格按照上述规划及洪江古建筑群建设控制地带的管理规定和控制要求，明确每栋新建建筑的高度、体量、外观样式及功能等。新建建筑应突出地域特色，采用地方传统建筑样式和工艺材料，不宜大规模使用马头墙，确保与洪江古建筑群风貌相协调。一类建设控制地带内建筑建议采用窨子屋组合形式和传统样式木构架，且高度不得超过3层。同时，项目区域与周边区域应有清晰区隔，避免新建建筑与历史环境相混淆。

（四）补充文物影响评估报告，深入论证拟建项目对文物本体和环境风貌的影响，做到客观、准确、科学。

（五）应充分考虑建设施工对文物安全的影响，制定必要的文物保护措施和应急预案，并注意加强施工过程中的文物安全监测工作，及时发现、排除隐患，确保文物和人员安全。

三、请你局根据上述意见，组织相关单位对方案进行修改、完善，经你局核准后实施。工程实施前应开展项目区域遗存调查。请加强工程监管，确保文物及其环境安全。

四、请你局督促地方人民政府落实管理责任，按照《中华人民共和国文物保护法》、《洪江古建筑群文物保护规划》等的要求，有序开展文物保护、环境整治、展示利用和旅游工作，科学引导周边建设与旅游活动，妥善解决土地用途调整、拆建等可能涉及的问题，处理好文物保护利用、地方经济发展和民生改善之间的关系。

此复。

国家文物局

2017年2月22日
