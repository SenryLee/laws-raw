# 国家文物局关于烟台福建会馆古建筑油饰彩画保护工程立项的批复

## 关于烟台福建会馆古建筑油饰彩画保护工程立项的批复

文物保函〔2017〕660号

山东省文物局：

你局《关于申请烟台福建会馆古建筑油饰彩画保护工程立项的请示》（鲁文发〔2017〕8号）收悉。经研究，我局批复如下：

一、同意烟台福建会馆古建筑油饰彩画保护工程立项。

二、在编制工程技术方案时，应注意以下方面：

（一）该工程性质属于修缮工程。

（二）该工程实施范围为烟台福建会馆古建筑油饰彩画。

（三）补充烟台福建会馆历史沿革、维修记录等资料，补充历史老照片、地方志、历史图档等有关信息。补充1981年重绘彩画的历史依据。

（四）深入开展文物勘察测绘和保存现状评估，准确掌握病害性质及根源，制定有针对性的修缮措施。

（五）调查记录油饰彩画的原始做法和材料、工艺，清理、补做地仗以及补绘彩画应采用传统方法。不宜采用化学材料做表面封护。

三、请你局指导项目单位根据上述意见和《文物保护工程设计文件编制深度要求（试行）》的有关规定，组织编制工程技术方案；由你局组织专家或委托专业机构进行方案技术评审，并依据评估意见进行审批。

此复。

国家文物局

2017年3月30日
