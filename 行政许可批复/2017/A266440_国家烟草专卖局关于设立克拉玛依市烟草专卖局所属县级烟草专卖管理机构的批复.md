# 国家烟草专卖局关于设立克拉玛依市烟草专卖局所属县级烟草专卖管理机构的批复

国烟人〔2017〕304号

新疆维吾尔自治区烟草专卖局：

《新疆维吾尔自治区烟草专卖局关于克拉玛依市烟草专卖局成立县（区）级烟草专卖管理机构的请示》（新烟人〔2017〕31号）收悉。根据《烟草行业机构编制管理办法》（国烟人〔2015〕187号），经研究，现批复如下：

一、同意设立克拉玛依市克拉玛依区烟草专卖局、克拉玛依市独山子区烟草专卖局、克拉玛依市白碱滩区烟草专卖局、克拉玛依市乌尔禾区烟草专卖局，负责各自辖区内的烟草专卖管理工作。

二、上述新设机构所需人员从系统内调剂解决，不得从系统外调入。

接此批复后，请你局按照有关规定及本批复办理相关事宜。

国家烟草专卖局

2017年10月31日
