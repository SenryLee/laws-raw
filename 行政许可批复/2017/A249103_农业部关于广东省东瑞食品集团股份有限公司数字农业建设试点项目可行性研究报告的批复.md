# 农业部关于广东省东瑞食品集团股份有限公司数字农业建设试点项目可行性研究报告的批复

农计发〔2017〕48号

广东省农业厅：

《广东省农业厅关于报送2017年数字农业建设试点项目申报材料的函》（粤农函〔2017〕186号）收悉。经研究，批复如下：

一、原则同意上报的广东省东瑞食品集团股份有限公司数字农业建设试点项目可行性研究报告。项目建设单位为东瑞食品集团股份有限公司，建设地点为广东省河源市东源县，项目建设期2年。

二、项目建设内容：一是自动化精准环境控制系统建设，包括温湿度、氨气、光照度、二氧化碳浓度控制系统等；二是数字化精准饲喂管理系统建设，包括传统猪舍改造，配置电子识别、自动称量、精准上料、自动饮水设备等；三是无害化粪污处理系统建设，包括自动翻堆设备、刮粪设备等。

三、项目建设目标：项目建成后，实现生猪精准饲喂与分级管理、粪污无害化处理和资源化利用，项目区养猪生产成本降低30元/头，废水产生量减少42%，废水排放量减少43%。

四、项目投资及来源：经评估核定，项目估算总投资4797万元，其中中央预算内投资按1439万元控制，其余由项目建设单位自筹解决。

五、本项目硬件设备及系统软件购置、应用软件系统开发、建安工程、设计、监理以及技术支撑单位应按照招投标法及有关规定通过公开招标确定。

六、请据此批复和项目评估报告，指导项目单位抓紧编制项目初步设计与概算报你单位审批，初步设计与概算及其批复应于6月底前报我部备案。

七、你单位及项目所在地县（市、区）政府要加强对项目实施的指导、支持和监督，确保项目早日建成运行、发挥效益。我部将对项目建设及运行情况进行投资绩效考核，对考核不合格和监管发现问题的，将严肃问责并取消你省申报后续数字农业建设试点项目的资格。

农业部
