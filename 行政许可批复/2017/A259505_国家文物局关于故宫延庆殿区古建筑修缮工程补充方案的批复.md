# 国家文物局关于故宫延庆殿区古建筑修缮工程补充方案的批复

文物保函〔2017〕2073号

北京市文物局：

你局《关于故宫延庆殿区古建筑修缮工程补充方案的请示》（京文物〔2017〕1337号）收悉。经研究，我局批复如下：

一、原则同意所报故宫延庆殿区古建筑修缮项目补充方案和你局意见。

二、具体修改意见如下：

（一）进一步细化屋面修缮措施。对不完全揭露灰背的建筑，应补充屋面灰背俯视图，并明确标注拟拆修部分和拟保留部分，以及屋面修缮做法相关说明；重做过垄脊灰背时应在其内加铺可搭两坡的长麻辫,以防止溜背；不宜按照现代做法重做天沟，应采用传统的铺铅板等做法。

（二）应进一步明确南大墙下碱的拆修范围，以及现有砌筑做法、增加暗拉接做法的具体要求，补充设计详图。

（三）不宜全部铲除重做室内抹灰层，无明显病害的可予以保留。

（四）不得全面翻修院落地面。进一步核实各建筑周边排水情况；应仅针对人行、排水等具体功能要求局部揭墁或剔补砖面；风化、碎裂地砖不影响使用的，不应更换。

（五）细化门钉除锈措施的要求，解决锈蚀发展隐患即可。

（六）细化用大白纸裱糊天花板的具体工艺做法。

三、具体方案由你局指导有关单位按照上述意见修改、完善并经你局批准后实施。

四、施工前请你局督促施工单位做好工地现场布置管理、岗前培训、围挡和支护等各项准备工作。

五、施工中请你局加强协调和工程监管，及时开展工程检查，督促项目管理单位和方案设计单位加强施工全过程指导，督促项目施工单位严格遵守文物保护工程相关法律法规、标准规范要求，做好施工组织管理，主动接受社会监督，确保工程质量和文物、人员安全。

六、工程竣工后，由你局按照《全国重点文物保护单位文物保护工程竣工验收管理暂行办法》的相关要求，严格做好工程竣工验收工作。

七、请你局切实加强管理，督促、指导相关单位做好修缮后相关文物的日常养护工作，及时发现和排除隐患，确保文物安全。

此复。

国家文物局

2017年12月28日
