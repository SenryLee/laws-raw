# 中国证券监督管理委员会关于核准华夏基金管理有限公司变更股权的批复

## 中国证券监督管理委员会关于核准华夏基金管理有限公司变更股权的批复（证监许可[2013]1089号）

华夏基金管理有限公司：

你公司报送的《关于股东变更及修改章程的申请》（华基文[2013]323号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

**一、**核准无锡市国联发展（集团）有限公司将其持有的你公司10%股权转让给中信证券股份有限公司。转让完成后，你公司股权结构为：

人民币　万元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额 | 出资比例 |
| 1 | 中信证券股份有限公司 | 14，042 | 59% |
| 2 | 南方工业资产管理有限责任公司 | 2，618 | 11% |
| 3 | 山东省农村经济开发投资公司 | 2，380 | 10% |
| 4 | POWER CORPORATION OF CANADA | 2，380 | 10% |
| 5 | 青岛海鹏科技投资有限公司 | 2，380 | 10% |
|  | 合计 | 23，800 | 100% |

**二、**你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2013年8月19日
