# 中国证券监督管理委员会关于核准江信基金管理有限公司变更股权的批复

## 中国证券监督管理委员会关于核准江信基金管理有限公司变更股权的批复（证监许可[2013]1270号）

江信基金管理有限公司：

你公司报送的《江信基金管理有限公司股权变更申请书》（江基司字[2013]2号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

**一、**核准中炬高新技术实业（集团）股份有限公司将其持有的你公司20%股权、恒生阳光集团有限公司将其持有的你公司5%股权转让给江西金麒麟投资有限公司。转让完成后，你公司股权结构为：

人民币　元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额 | 出资比例 |
| 1 | 国盛证券有限责任公司 | 49，000，000 | 49% |
| 2 | 恒生阳光集团有限公司 | 26，000，000 | 26% |
| 3 | 江西金麒麟投资有限公司 | 25，000，000 | 25% |
|  | 合计 | 100，000，000 | 100% |

**二、**你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2013年9月30日
