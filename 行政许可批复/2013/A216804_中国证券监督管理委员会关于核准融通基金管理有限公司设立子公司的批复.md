# 中国证券监督管理委员会关于核准融通基金管理有限公司设立子公司的批复

## 中国证券监督管理委员会关于核准融通基金管理有限公司设立子公司的批复（证监许可[2013]591号）

融通基金管理有限公司、北京银都新天地科技有限公司、北京八恺电气科技有限公司：

你们报送的《关于设立深圳市融通资本财富管理有限公司并申请特定客户资产管理业务资格的申请报告》（融通基金字[2013]59号）及相关文件收悉。根据《证券投资基金法》、《公司法》、《证券投资基金管理公司管理办法》（证监会令第84号）、《基金管理公司特定客户资产管理业务试点办法》（证监会令第83号）、《证券投资基金管理公司子公司管理暂行规定》（证监会公告[2012]32号）等有关规定，经审核，现批复如下：

**一、**核准融通基金管理有限公司设立子公司。子公司名称为深圳市融通资本财富管理有限公司，注册地为深圳市，注册资本为2000万元，业务范围为特定客户资产管理业务以及中国证监会许可的其他业务。核准子公司的股权结构为：

人民币 万元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 融通基金管理有限公司 | 1020 | 51％ |
| 2 | 北京银都新天地科技有限公司 | 490 | 24.5％ |
| 3 | 北京八恺电气科技有限公司 | 490 | 24.5％ |
|  | 合计 | 2000 | 100.00％ |

**二、**深圳市融通资本财富管理有限公司应当按照《公司法》等法律、法规和有关规定的要求，尽快向工商行政管理机关申请设立登记，领取营业执照并自领取营业执照之日起15日内，向我会及深圳证监局报告。

**三、**深圳市融通资本财富管理有限公司在取得工商行政管理机关颁发的营业执照后，到我会领取《特定客户资产管理业务资格证书》。

**四、**融通基金管理有限公司应当做好对深圳市融通资本财富管理有限公司的管理安排，与深圳市融通资本财富管理有限公司之间应当建立有效的风险隔离，不得进行损害基金份额持有人利益或者显失公平的关联交易，经营行为不得存在利益冲突。

**五、**深圳市融通资本财富管理有限公司应当按照诚实信用原则，认真履行职责，严格防范利益输送，切实加强公平交易管理，依法做好特定客户资产管理业务。

中国证监会

2013年4月23日
