# 中国保险监督管理委员会关于合众人寿保险股份有限公司修改章程的批复(2013)

## 中国保险监督管理委员会关于合众人寿保险股份有限公司修改章程的批复（保监许可〔2013〕27号）

合众人寿保险股份有限公司：

你公司关于修改章程的请示及补充材料（合保发〔2013〕182号）收悉。经审查，核准你公司对章程做出的以下修改：

**一、**第十条修改为：公司注册资本人民币278277万元，公司股本278277万股，股东认购股份和所占比例如下：

| --- | --- | --- |
| 股东名称 | 持有股份  　　（万股） | 持股比例 |
| 中发实业（集团）有限公司 | 55655.4 | 20.00% |
| 意大利联合圣保罗人寿股份有限公司（Intesa Sanpaolo Vita S.p.A.） | 55377.2605 | 19.90% |
| 斯迈特投资股份有限公司 | 52872.5826 | 19.00% |
| 太阳生命保险株式会社 | 14164.5548 | 5.09% |
| 湖北楚汉经贸有限公司 | 40423.5922 | 14.53% |
| 湖北德凡投资有限公司 | 40790.9995 | 14.66% |
| 北京天信杰投资有限公司 | 18992.6104 | 6.82% |
| 总计 | 278277 | 100% |

**二、**第三十九条修改为：公司设董事会。董事会由十一（11）名董事组成，设董事长一（1）人，副董事长一（1）人。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会
