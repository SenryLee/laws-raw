# 中国证监会关于核准东方基金管理有限责任公司变更股权及修改章程重要条款的批复

## 中国证监会关于核准东方基金管理有限责任公司变更股权及修改章程重要条款的批复（证监许可[2013]22号）

东方基金管理有限责任公司：

你公司报送的《关于股权变更和章程修改的申请》（东方[2012]122号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

**一、**核准中辉国华实业（集团）有限公司将其持有的你公司18%股权转让给东北证券股份有限公司。转让完成后，你公司股权结构为：

人民币 元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 东北证券股份有限公司 | 64，000，000 | 64％ |
| 2 | 渤海国际信托有限公司 | 18，000，000 | 18% |
| 3 | 河北省国有资产控股运营有限公司 | 18，000，000 | 18％ |
|  | 合计 | 100，000，000 | 100％ |

**二、**核准你公司对公司章程所作的修改。

**三、**你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2013年1月8日
