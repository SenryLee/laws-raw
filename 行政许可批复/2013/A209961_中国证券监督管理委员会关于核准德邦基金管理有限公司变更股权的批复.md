# 中国证券监督管理委员会关于核准德邦基金管理有限公司变更股权的批复

## 中国证券监督管理委员会关于核准德邦基金管理有限公司变更股权的批复（证监许可[2013]1516号）

德邦基金管理有限公司：

你公司报送的《德邦基金管理有限公司关于股权转让的申请报告》（德邦基金[2013]42号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金管理公司管理办法》（证监会令第84号）等有关规定，经审核，现批复如下：

**一、**核准西子联合控股有限公司将其持有的你公司21%股权转让给德邦证券有限责任公司。转让完成后，你公司股权结构为： 　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　人民币 元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 出资额 | 出资比例 |
| 1 | 德邦证券有限责任公司 | 84，000，000 | 70% |
| 2 | 浙江省土产畜产进出口集团有限公司 | 24，000，000 | 20% |
| 3 | 西子联合控股有限公司 | 12，000，000 | 10% |
|  | 合计 | 120，000，000 | 100% |

**二、**你公司及各股东应当按规定及时办理工商变更登记等相关事宜，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证监会

2013年11月28日
