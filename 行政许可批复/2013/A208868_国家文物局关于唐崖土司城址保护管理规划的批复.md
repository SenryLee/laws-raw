# 国家文物局关于唐崖土司城址保护管理规划的批复

## 国家文物局关于唐崖土司城址保护管理规划的批复（文物保函〔2013〕2280号）

湖北省文物局：

你局《关于呈报唐崖土司城遗址保护管理规划的请示》（鄂文物文[2013]217号）收悉。经研究，我局批复如下：

**一、**原则同意所报唐崖土司城址保护管理规划。

**二、**对该规划提出以下修改意见：

（一）关于系列遗产总体要求

建议补充对土司遗址三个遗产点的总体规划要求，明确土司遗址的总体价值、各遗产点在整体架构中的价值特色及对总体价值的支撑作用。应说明保护管理总体协调机制，发展策略及阐释展示的主题侧重、未来发展的功能定位等。

（二）关于遗产概述、价值及载体

1. 深入研究唐崖土司城址的特点，论述其在系列遗产申报中的地位。

2. 进一步细化唐崖土司城址的历史沿革，核准各历史时期表述。

3. 应进一步深化对遗址布局、形制的阐述，以必要的图表说明要塞选址及聚落发展历程。

4. 进一步核准文字描述。规划名应使用全国重点文物保护单位名称“唐崖土司城址”。

（三）关于保存现状、影响因素及综合管理现状评估

1. 应补充说明现有居民和覃氏土司的关系，补充对现存传统文化、制度和习俗的评估。

2. 应详细阐述利益相关者（包括各级政府、相关部门、单位及当地居民等）在保护管理体系中的地位和作用。

3. 应补充灾害因素对遗产的影响评估，并针对主要灾害制订规划措施。

（四）关于遗产区划及其管理规定

1. 应进一步论证缓冲区划定的合理性，既要满足遗产要素及环境景观的保护要求，又便于管理，具备可操作性。

2. 应使全国重点文物保护单位唐崖土司城址的建设控制地带与缓冲区相一致，以满足遗产管理的要求。因此，应对相关边界做出必要的调整。

3. 进一步细化缓冲区管理规定，补充对一类、二类和三类缓冲区在建设高度、体量和密度等方面的控制要求，并明确审批程序。

4. 根据遗址的实际情况，确定合理的扰土深度要求。

（五）关于保护措施和综合管理措施规划

1. 考虑到考古工作需要，对遗址占压物清理及后续工作提出建议，遗址保护措施应具备一定的灵活性。

2. 应补充对现存传统文化、制度和习俗，尤其是族群存续关系的保护措施。

3. 应完善保护管理机制及利益相关者协调措施，保障当地居民在遗产保护和管理中的知情权、参与权和分享权。

4. 应根据保护管理利用等工作的实际需求，合理测算遗产管理、展陈和旅游服务等设施所需建设面积，并在此基础上统筹考虑管理、旅游服务设施的建设。应充分利用或改造现有建筑，避免大拆大建。

5. 应补充完善旅游管理规划，对餐饮、住宿等相关发展压力做出预判并提出控制措施，对游客服务设施的布设提出规划要求。

6. 应对张王庙及墓葬周围的现代构筑物进行评估，并提出科学的整治措施。

7. 进一步明确皇城大道沿线建筑的整治措施，并补充论证新建尖山大桥至碗厂沟段旅游服务道路的必要性，近期应尽可能改造利用现有建筑和道路。

8. 补充电力通讯设施改造的选线建议。

9. 进一步论证遗产区边界设置围栏的必要性。可考虑结合界桩、界碑等形式，对遗产区进行保护和管理。

**三、**请你局督促、指导地方人民政府组织规划编制单位，按照上述意见对所报管理规划进行必要修改和完善，经你局核准后，报请湖北省人民政府予以公布，并纳入当地经济和社会发展计划以及咸丰县域总体规划，积极组织有关部门逐步实施。规划公布文件和规划文本、图纸及相关电子档案等材料应于2014年1月5日前报我局备案。

**四、**规划涉及的本体保护、展示、环境整治以及相关基础设施建设等项目，应按照轻重缓急原则，编制具体方案并按程序报批。

**五、**请你局和当地人民政府加强对唐崖土司城址保护和管理工作的指导，加强管理机构建设，完善专项管理法规，并提出具体实施措施、步骤和保证措施，妥善解决居民生活改善、土地用途调整和环境整治等问题，确保规划的顺利实施。

此复。

国家文物局

2013年12月23日
