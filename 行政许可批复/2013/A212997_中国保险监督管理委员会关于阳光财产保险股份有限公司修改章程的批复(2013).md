# 中国保险监督管理委员会关于阳光财产保险股份有限公司修改章程的批复(2013)

## 中国保险监督管理委员会关于阳光财产保险股份有限公司修改章程的批复（保监许可〔2013〕265号）

阳光财产保险股份有限公司：

你公司关于修改章程的请示（阳光产险〔2013〕243号）收悉。经审查，核准你公司2013年1月15日股东大会决议对章程做的以下修改：

**一、**第六条修改为：公司注册资本为人民币三十一亿八千万（3，180，000，000）元。

**二、**第十六条修改为：公司经批准的股份总额为三十一亿八千万（3，180，000，000）股普通股，每股面值人民币壹（1）元。

**三、**章程附件修改为：公司的股权结构为：

|  |  |  |  |
| --- | --- | --- | --- |
| 阳光财产保险股份有限公司股份结构表 | | | |
| 序号 | 股东全称 | 持有股份数 | 持股比例 |
| 1 | 阳光保险集团股份有限公司 | 3，047，475，349 | 95.83% |
| 2 | 阳光人寿保险股份有限公司 | 132，524，651 | 4.17% |
| 合计 | | 3，180，000，000 | 100% |

请你公司依照有关规定办理变更事宜。

此复

中国保监会

2013年9月6日
