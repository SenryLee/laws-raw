# 中国保险监督管理委员会关于法国再保险公司北京分公司2013年度与法国财产再保险公司(SCOR GLOBAL P&C SE)从事再保险关联交易的批复

## 中国保险监督管理委员会关于法国再保险公司北京分公司2013年度与法国财产再保险公司（SCOR　GLOBAL　P&C　SE）从事再保险关联交易的批复（保监产险〔2013〕155号）

法国再保险公司北京分公司：

你公司《关于2013年超赔分出关联交易的申请》（法再北分再保财〔2012〕第6号）及其补正材料收悉。经审核，同意你公司自发文之日起至2013年12月31日止与法国财产再保险公司（SCOR GLOBAL P&C SE）从事再保险关联交易。

此复
