# 中国保险监督管理委员会关于太平财产保险有限公司修改章程的批复(2013)

## 中国保险监督管理委员会关于太平财产保险有限公司修改章程的批复（保监发改〔2013〕181号）

太平财产保险有限公司：

你公司关于修改章程的请示（太平财〔2013〕6号）收悉。经审查，核准你公司2012年11月21日股东大会决议对章程做出的以下修改：

**一、**第十一条修改为：公司注册资本：人民币2，570，000，000元。

**二、**第十二条修改为：股东的名称、出资方式及出资额如下：

股东名称：中国太平保险控股有限公司（“中国太平控股”）

出资方式：外汇现金

出资额：折合人民币1，573，136，665元

出资比例：61.21%

股东名称：中国太平保险集团公司（“中国太平”）

出资方式：人民币或/和外汇现金

出资额：折合人民币996，863，335元

出资比例：38.79%

**三、**章程附件股权结构表修改为：

|  |  |  |  |
| --- | --- | --- | --- |
| 股东名称 | 出资额  （折人民币元） | 股权比例  （%） | 备注 |
| 中国太平保险控股有限公司 | 1，573，136，665 | 61.21 |  |
| 中国太平保险集团公司 | 996，863，335 | 38.79 |  |
| 合计 | 2，570，000，000 | 100 |  |

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

2013年2月21日
