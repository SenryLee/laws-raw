# 中国保险监督管理委员会关于日本东京海上日动火灾保险株式会社驻中国总代表处更换总代表的批复(2012)

## 中国保险监督管理委员会关于日本东京海上日动火灾保险株式会社驻中国总代表处更换总代表的批复（保监国际〔2012〕415号）

日本东京海上日动火灾保险株式会社：

你公司关于更换驻中国总代表处总代表的申请材料收悉，经研究，批准孔跃接替早坂靖志担任日本东京海上日动火灾保险株式会社驻中国总代表处总代表。

此复

中国保险监督管理委员会
