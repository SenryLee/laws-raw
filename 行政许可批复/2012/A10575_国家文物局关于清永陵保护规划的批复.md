# 国家文物局关于清永陵保护规划的批复

## 国家文物局关于清永陵保护规划的批复（文物保函〔2012〕1950号）

辽宁省文物局：

你局《关于上报清永陵保护规划的请示》（辽文物保发[2012]48号）收悉。经研究，我局批复如下 ：

**一、**原则同意所报清永陵保护规划。

**二、**对该规划提出以下修改意见：

（一）关于遗产概况

1. 进一步细化清永陵作为世界文化遗产的突出普遍价值标准，并明确价值载体。

2. 保护对象认定的阐述应与真实性评估图相对应。

3. 应补充牛羊院内房屋、冰窖遗址分布图，并提出明确的保护措施。

4. 应明确总管衙遗址、掌关防衙门遗址是否为该规划的保护对象，并据此对规划文本和图纸做相应调整。

5. 在现状图纸中准确标注下马碑、云龙袖壁等遗迹；应加强对陵界石、封堆等遗迹的调查和研究，搞清陵寝边界，并在遗址现状图中准确标注。

（二）进一步完善现状评估。

1. 补充东侧新建花园的详细文字说明和图纸。

2. 补充建筑残损情况评估图，对残损程度进行说明；补充存在安全问题的山体下城墙的有关图纸。

3.补充建设控制地带内南部高速公路出入口、服务区等项目的环境评估。

4. 补充道路交通现状评估的文字说明及图纸。

5. 完整性评估中应充分考虑与陵寝建设有关机构的情况，补充对风水环境的评估。

（三）进一步完善保护措施，针对文物本体和环境提出相应保护措施。

（四）关于保护管理规定

1. 应按照《文物保护法》的有关规定，进一步论证文物管理用房、博物馆、游客服务设施和停车场等项目选址，并对其可能对陵寝本体及环境产生的影响进行评估。

2. 应对建设控制地带内尤其是后堡、西堡两个村庄的建筑高度、体量、风格、色彩等提出明确的控制要求。

（五）清永陵管理机构的设置应注意整合相关资源。

（六）陵寝内不宜实施亮化工程，应对相关内容进行调整。

（七）进一步完善规划图纸，补充文物本体病害和周边建筑评估图，以及保护措施和环境整治等规划图。

（八）进一步核准文字，图纸表达应清晰、完整。

**三、**请你局指导地方人民政府组织有关单位，按照上述意见对规划进行必要修改和完善后，并于15个工作日内将经你局核准的规划文本图纸及相关电子档案等材料报我局备案。

**四、**请你局按照《国务院关于加强文化遗产保护的通知》的要求，将经我局备案的清永陵保护规划报请辽宁省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展计划以及城市总体规划，积极组织有关部门逐步实施。

**五、**规划中提出的本体保护和展示以及环境整治、相关基础设施建设等项目，实施前应编制具体方案并按程序报批。

**六、**请你局和当地人民政府加强对清永陵保护和管理工作的指导，加强管理机构建设，完善专项管理法规，并提出具体实施措施、步骤和保证措施，妥善解决居民搬迁、土地用途调整和环境整治等问题，确保规划的顺利实施。

此复。

国家文物局　　　

二〇一二年九月二十五日
