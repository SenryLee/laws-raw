# 中国保险监督管理委员会关于阳光保险集团股份有限公司变更注册资本的批复(2012)

## 中国保险监督管理委员会关于阳光保险集团股份有限公司变更注册资本的批复（保监发改〔2012〕888号）

阳光保险集团股份有限公司：

你公司《关于进一步优化阳光保险集团与阳光人寿股权关系的请示》（阳光保险〔2012〕48号）收悉。经审核，同意你公司注册资本变更为66.5059亿元人民币。变更后，你公司股东持股数量和持股比例见附表。

请你公司按照有关规定办理变更手续。

此复

中国保险监督管理委员会

二○一二年七月二十七日
