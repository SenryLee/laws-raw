# 中国证券监督管理委员会关于核准国金通用基金管理有限公司变更注册资本及修改章程的批复

## 中国证券监督管理委员会关于核准国金通用基金管理有限公司变更注册资本及修改章程的批复（证监许可[2012]1171号）

国金通用基金管理有限公司：

你公司报送的《关于国金通用基金公司增加注册资本、变更股东出资比例及修改公司章程等重大事项的申请报告》（国金基[2012]027 号）及相关文件收悉。根据《公司法》、《证券投资基金法》和《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由16000万元人民币增加到28000万元。其中，国金证券股份有限公司增加出资5880万元，苏州工业园区地产经营管理公司增加出资3060万元，广东宝丽华新能源股份有限公司增加出资3060万元。

你公司变更注册资本后，公司的股权结构为：

人民币　万元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 国金证券股份有限公司 | 13720 | 49％ |
| 2 | 苏州工业园区地产经营管理公司 | 5460 | 19.5 ％ |
| 3 | 广东宝丽华新能源股份有限公司 | 5460 | 19. 5％ |
| 4 | 中国通用技术（集团）控股有限责任公司 | 3360 | 12 ％ |
|  | 合计 | 28000 | 100％ |

**二、**核准你公司对公司章程所作的修改。

**三、**你公司应当按规定及时办理工商变更登记等相关事宜，并到我会换领《基金管理资格证书》，完善公司治理结构，维护公司及基金份额持有人的合法权益。

中国证券监督管理委员会

2012年8月31日
