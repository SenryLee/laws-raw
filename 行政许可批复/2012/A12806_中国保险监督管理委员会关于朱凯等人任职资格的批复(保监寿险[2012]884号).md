# 中国保险监督管理委员会关于朱凯等人任职资格的批复(保监寿险[2012]884号)

## 中国保险监督管理委员会关于朱凯等人任职资格的批复（保监寿险〔2012〕884号）

东吴人寿保险股份有限公司：

你公司关于朱凯等人任职资格的请示（东吴人寿〔2012〕16、18、20号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准朱凯担任你公司董事长的任职资格，核准钱程担任你公司总经理的任职资格，核准朱林一、杨森荣、胡波担任你公司独立董事的任职资格。

此复

中国保险监督管理委员会

二○一二年七月二十七日
