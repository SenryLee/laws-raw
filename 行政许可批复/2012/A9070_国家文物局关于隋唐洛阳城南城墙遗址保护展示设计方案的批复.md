# 国家文物局关于隋唐洛阳城南城墙遗址保护展示设计方案的批复

## 国家文物局关于隋唐洛阳城南城墙遗址保护展示设计方案的批复（文物保函〔2012〕2139号）

河南省文物局：

你局《关于报批隋唐洛阳城南城墙遗址保护展示设计方案的请示》（豫文物〔2012〕257号）收悉。经研究，我局批复如下：

**一、**原则同意沿用方案一的思路对C段城墙（定鼎门遗址东侧至龙门大道段）进行保护展示，暂不同意对A、B段城墙（定鼎门遗址西侧至厚载门遗址段）进行保护展示。

**二、**该方案尚需做以下必要的修改和完善：

（一）应加强对已有考古资料的研究，补充隋唐、五代至宋的城墙形制演变研究，并据此进一步优化方案设计，力求全面、真实的传达遗址信息。

（二）C段城墙的展示应注意与已有的定鼎门遗址保护展示工程相衔接，妥善处理衔接部位，并注意与已有保护工程的外观形象及周边景观相协调。

（三）应进一步整合拟建展示、文化、办公和管理设施以及基础服务设施点，严格控制各类设施的面积，仅保留必要的展示、管理和服务设施，不宜设置专门的学术报告厅和研究场所等。

（四）进一步开展不同保护展示思路的方案比选工作，考虑采用模拟展示或地表标识展示（非建筑标识）等其他方式对A、B段城墙进行展示的可能性，部分保存状况较好的遗迹，亦可考虑采用局部覆罩的方式。A、B段城墙遗址的保护展示方案应按程序另行报批。

**三、**请你局指导方案设计单位联合专业考古研究单位，根据上述意见对方案作进一步修改和完善后，制定科学详细的施工方案，经你局核准后实施。施工中，请你局加强监管，确保工程质量和文物安全。

国家文物局　　

二〇一二年十一月五日
