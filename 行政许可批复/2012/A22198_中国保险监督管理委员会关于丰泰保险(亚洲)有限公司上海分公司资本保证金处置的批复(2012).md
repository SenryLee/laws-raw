# 中国保险监督管理委员会关于丰泰保险(亚洲)有限公司上海分公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于丰泰保险（亚洲）有限公司上海分公司资本保证金处置的批复（保监财会〔2012〕12号）

丰泰保险（亚洲）有限公司上海分公司：

你公司《关于资本保证金处置的请示》（201111 / CIRC / WIASH－1263）收悉。经研究，同意你公司将存放于中国银行上海市东昌路支行的300万元人民币和存放于中国工商银行上海市证券大厦支行的700万元人民币资本保证金存款（合计1000万元）转存至中国工商银行上海市证券大厦支行。

请你公司在资本保证金存款存妥后10个工作日内，将《资本保证金存款协议》原件和背书后的存单复印件报我会。

此复

中国保险监督管理委员会

二○一二年一月五日
