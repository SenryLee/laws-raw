# 中国保险监督管理委员会关于法国再保险公司北京分公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于法国再保险公司北京分公司资本保证金处置的批复（保监财会〔2012〕446号）

法国再保险公司北京分公司：

你公司《关于资本保证金存款到期变更存款性质的请示》（法再北分财务〔2012〕第2号）收悉。经研究，同意你公司变更存放于中国银行北京大成大厦支行的101万欧元资本保证金存款的性质，该存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保险监督管理委员会

二○一二年四月十七日
