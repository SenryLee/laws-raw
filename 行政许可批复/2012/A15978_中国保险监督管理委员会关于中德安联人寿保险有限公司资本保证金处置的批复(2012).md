# 中国保险监督管理委员会关于中德安联人寿保险有限公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于中德安联人寿保险有限公司资本保证金处置的批复（保监财会〔2012〕575号）

中德安联人寿保险有限公司：

你公司《关于资本保证金到期变更存款性质的请示》（安联发〔2012〕28号）收悉。经研究，同意你公司变更存放于中国建设银行上海静安支行6笔合计2.8亿元人民币资本保证金存款的性质，上述存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保险监督管理委员会

二○一二年五月十五日
