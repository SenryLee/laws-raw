# 中国保险监督管理委员会关于中意人寿保险有限公司财务会计部门负责人的批复(2012)

## 中国保险监督管理委员会关于中意人寿保险有限公司财务会计部门负责人的批复（保监财会〔2012〕488号）

中意人寿保险有限公司：

你公司《关于核准中意人寿保险有限公司财务部门负责人任职资格的请示》（中意人寿〔2012〕58号）收悉。经审查，同意龚景荣担任中意人寿保险有限公司财务会计部门负责人。

此复

中国保险监督管理委员会

二○一二年四月二十七日
