# 文化部关于同意俄罗斯皇家芭蕾舞团到天津市演出的批复(2012)

## 文化部关于同意俄罗斯皇家芭蕾舞团到天津市演出的批复（文市函〔2012〕1940号）

天津市文化广播影视局：

津文广外〔2012〕73号请示收悉。

经研究，同意天津华乐文化艺术发展有限公司邀请俄罗斯皇家芭蕾舞团一行46人，于2012年12月12日至2013年1月12日到天津市等地演出。

此复。

2012年10月9日
