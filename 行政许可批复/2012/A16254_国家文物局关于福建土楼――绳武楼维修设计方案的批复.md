# 国家文物局关于福建土楼――绳武楼维修设计方案的批复

## 国家文物局关于福建土楼--绳武楼维修设计方案的批复（文物保函〔2012〕1091号）

福建省文物局：

你局《福建省文物局关于全国重点文物保护单位福建土楼--绳武楼维修设计方案的请示》（闽文物字[2012]61号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**具体修改、完善意见如下：

（一）补充、明确部分传统工艺做法，如屋面、夯土墙等。说明对某些部位拟采用“三合土夯实”做法的依据。

（二）补充细化部分保护措施的具体做法要求、施工流程等。

（三）屋面维修做法中，不宜在椽条及封檐板上选择沥青材料来进行防腐处理，建议选用传统桐油防腐。

（四）应补充残损量及相关修缮工程量等说明，在图纸中应完善量化标注。

（五）补充院落整体排水现状评估及排水设计，完善相关图纸内容。

（六） 方案中有关油饰彩画进行清洗、对地仗进行补强等内容，应由具有相应资质的设计单位进一步细化具体材料配比和工艺做法，另行编制方案报批。

请你局根据上述意见，组织相关单位对方案进一步修改、完善，报你局审核后实施。施工中请加强监管，确保文物安全。

此复。

国家文物局　　

二〇一二年五月八日
