# 中国保险监督管理委员会关于赵明浩等人任职资格的批复(2012)

## 中国保险监督管理委员会关于赵明浩等人任职资格的批复（保监资金〔2012〕823号）

华泰资产管理有限公司：

你公司《关于对公司拟任董事进行任职资格审查的申请》（华资字〔2011〕31号）、《关于对高峰等进行任职资格审查的申请》（华资字〔2012〕25号）收悉。经审核，王梓木、赵明浩、沈明远、王冠龙、Timothy A.Boroughs、高峰、刘屹、林锡东、尹嘉符合《保险公司董事、监事和高级管理人员任职资格管理规定》和《保险资金运用管理暂行办法》的有关要求，核准王梓木、赵明浩、沈明远、王冠龙、Timothy A.Boroughs担任你公司董事的任职资格，核准高峰、刘屹、林锡东担任你公司副总经理的任职资格，核准尹嘉担任你公司总经理助理的任职资格。

此复

中国保险监督管理委员会

二○一二年七月十八日
