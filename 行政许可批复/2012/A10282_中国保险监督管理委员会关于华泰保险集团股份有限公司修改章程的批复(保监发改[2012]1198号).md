# 中国保险监督管理委员会关于华泰保险集团股份有限公司修改章程的批复(保监发改[2012]1198号)

## 中国保险监督管理委员会关于华泰保险集团股份有限公司修改章程的批复（保监发改〔2012〕1198号）

华泰保险集团股份有限公司：

你公司关于修改章程的请示（华保字〔2012〕75号）收悉。经审查，核准你公司2012年8月10日和8月25日股东大会决议对章程附件股东名册进行的修改。

请你公司依照有关规定办理变更事宜。

此复

附件：华泰保险集团股份有限公司股东名册（略）

中国保险监督管理委员会
