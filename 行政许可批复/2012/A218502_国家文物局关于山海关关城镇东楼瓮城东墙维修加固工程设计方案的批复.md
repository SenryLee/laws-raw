# 国家文物局关于山海关关城镇东楼瓮城东墙维修加固工程设计方案的批复

## 国家文物局关于山海关关城镇东楼瓮城东墙维修加固工程设计方案的批复（文物保函〔2012〕927号）

河北省文物局：

你局《关于呈报山海关关城镇东楼瓮城东墙维修加固工程设计方案的请示》（冀文物字[2012]2号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出以下修改意见：

（一）根据墙体保护的实际需要确定并核减墙体拆砌的工程量。以满足城墙安全为限，尽可能不拆或少拆原有城墙，以最大程度减少对文物本体的直接扰动。

（二）明确拟实施墙体拆砌的具体位置、范围和补配新砖量，并应采取适当方式对补砌砖进行标示说明。

（三）妥善处理新旧砖连接处的结合问题，但不宜采用长度1.5米的钢锚杆加固，可考虑采用较细的L形螺纹钢筋构造拉接的方式，以减小干预程度。

（四）对于吐水嘴下部墙体，应进行适当防渗处理。

（五）进一步校核方案文本和图纸，明确标注保护措施的量化指标。

**三、**请你局指导相关单位，根据以上意见对方案进行深化、修改和完善，由你局核准后实施。请加强工程的监督管理，确保工程质量和文物安全。

此复。

国家文物局

二〇一二年四月十八日
