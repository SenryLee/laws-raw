# 中国银监会关于比利时富通银行有限公司关闭北京代表处的批复

## 中国银监会关于比利时富通银行有限公司关闭北京代表处的批复(银监复[2012]371号)

比利时富通银行有限公司：

你行首席执行官兼执行董事会与执行委员会主席Maxime Jadot签署的致我会的函收悉。

根据《中华人民共和国外资银行管理条例》（国务院令第478号）和《中华人民共和国外资银行管理条例实施细则》（中国银行业监督管理委员会令2006年第6号）的有关规定，兹批准比利时富通银行有限公司关闭北京代表处。请按照有关规定办理注销等相关手续。

二○一二年七月十二日
