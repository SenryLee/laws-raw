# 中国保险监督管理委员会关于中国太平洋财产保险股份有限公司修改章程的批复(2012)

## 中国保险监督管理委员会关于中国太平洋财产保险股份有限公司修改章程的批复（保监发改〔2012〕99号）

中国太平洋财产保险股份有限公司：

你公司关于修改章程的请示（太保产〔2011〕180号）收悉。经审查，核准你公司2011年9月19日股东大会决议对章程做出的以下修改：

**一、**第六条修改为：公司注册资本为人民币9，500，000，000元，实收资本为人民币9，500，000，000 元。

**二、**第十四条修改为：公司经批准发行的股份总数为9，500，000，000股，目前的股权结构如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股东名称 | 认购股份数（股） | 持股比例（%） |
| 1 | 中国太平洋保险（集团）股份有限公司 | 9，357，629，174 | 98.50136 |
| 2 | 申能（集团）有限公司 | 44，340，545 | 0.46674 |
| 3 | 上海国有资产经营有限公司 | 24，739，582 | 0.26042 |
| 4 | 上海海烟投资管理有限公司 | 44，216，702 | 0.46544 |
| 5 | 云南红塔集团有限公司 | 29，073，997 | 0.30604 |
| 合 计 | | 9，500，000，000 | 100 |

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

二〇一二年二月六日
