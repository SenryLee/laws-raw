# 中国银监会关于核准丁益任职资格的批复(2012)

## 中国银监会关于核准丁益任职资格的批复（银监复[2012]400号）

中国华能财务有限责任公司：

你公司《关于申请核准丁益同志任职资格的请示》（华财字〔2012〕14号）收悉。根据《非银行金融机构行政许可事项实施办法》（中国银监会令2007年第13号）等相关规定，核准丁益中国华能财务有限责任公司董事长的任职资格。

此复。

二○一二年七月二十四日
