# 中国保险监督管理委员会关于田满意法律责任人任职资格的批复(2012)

## 中国保险监督管理委员会关于田满意法律责任人任职资格的批复（保监寿险〔2012〕247号）

中宏人寿保险有限公司：

你公司《中宏人寿保险有限公司关于拟任法律责任人的核准请示》（中宏〔2012〕033号）收悉。根据《人身保险公司保险条款和保险费率管理办法》的有关要求，经审查，核准田满意担任你公司法律责任人的任职资格。

此复

中国保险监督管理委员会

二○一二年三月五日
