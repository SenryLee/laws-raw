# 中国保险监督管理委员会关于光大永明人寿保险有限公司修改章程的批复

## 中国保险监督管理委员会关于光大永明人寿保险有限公司修改章程的批复（保监发改〔2012〕747号）

光大永明人寿保险有限公司：

你公司关于修改章程的请示（光保字〔2012〕105号）收悉。经审查，核准你公司2011年12月26日股东会决议对章程做的如下修改：

**一、**第二条第二款修改为：公司的初始注册资本为两亿元人民币（RMB200，000，000），经过七次增资（详情如下），目前其注册资本为四十二亿元人民币（RMB4，200，000，000）。

（一）注册资本经保监会批准（批准文号：保监变审〔2003〕102号），于2003年8月由两亿元人民币（RMB200，000，000）增加至五亿元人民币（RMB500，000，000）；

（二）注册资本经保监会批准（批准文号：保监国际〔2006〕1487号），于2006年12月由五亿元人民币（RMB500，000，000）增加至六亿元人民币（RMB600，000，000）；

（三）注册资本经保监会批准（批准文号：保监国际〔2007〕549号），于2007年5月由六亿元人民币（RMB600，000，000）增加至九亿元人民币（RMB900，000，000）；

（四）注册资本经保监会批准（批准文号：保监国际〔2008〕1428号），于2008年11月由九亿元人民币（RMB900，000，000）增加至十二亿元人民币（RMB1，200，000，000）；

（五）注册资本经保监会批准（批准文号：保监国际〔2009〕1156号），于2009年11月由十二亿元人民币（RMB1，200，000，000）增加至十四亿九千九百四十万元人民币（RMB1，499，400，000）；

（六）注册资本经保监会批准（批准文号：保监国际〔2010〕874号），于2010年7月由十四亿九千九百四十万元人民币（RMB1，499，400，000）增加至三十亿元人民币（RMB3，000，000，000）；

（七）注册资本经保监会批准（批准文号：保监发改〔2012〕566号），于2012年5月由三十亿元人民币（RMB3，000，000，000）增加至四十二亿元人民币（RMB4，200，000，000）。

**二、**第十二条修改为：公司的注册资本为四十二亿元人民币（RMB 4，200，000，000）。

**三、**第十五条修改为：股份结构表（各股东的投资金额、该金额占注册资本的比例、出资方式以及出资日期）如下：

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 股东名称 | 出资金额（百万人民币） | 出资比例（%） | 出资方式 | 出资日期/最近  一次出资日期 | 备注 |
| 中国光大 | 2100 | 50% | 现金 | 2012年4月5日 |  |
| 永明人寿 | 1049.58 | 24.99% | 现金 | 2011年11月26日 | 2010年7月增资时，由于不同比例增资，股份比例从50%降至24.99%。未发生转让。 |
| 中国兵器 | 525.21 | 12.505% | 现金 | 2012年3月31日 | 2010年7月增资时的新增股东 |
| 鞍钢 | 525.21 | 12.505% | 现金 | 2012年3月31日 | 2010年7月增资时的新增股东 |
| 总计 | 4，200 | 100% |  |  |  |

请你公司依照有关规定办理变更事宜。
