# 文化部关于同意美国歌手费翔到江苏省演出的批复(文市函[2012]568号)

## 文化部关于同意美国歌手费翔到江苏省演出的批复（文市函〔2012〕568号）

江苏省文化厅：

苏文市（外）〔2012〕234号请示收悉。

经研究，同意江苏省演出公司邀请美国歌手费翔，于2012年5月7日到江苏省宿迁市演出。

此复。

二O一二年四月二十日
