# 中国保险监督管理委员会关于瑞泰人寿保险有限公司修改章程的批复(2012)

## 中国保险监督管理委员会关于瑞泰人寿保险有限公司修改章程的批复（保监国际〔2012〕457号）

瑞泰人寿保险有限公司：

你公司《关于瑞泰人寿保险有限公司修改公司章程的请示》（瑞泰人寿〔2012〕57号）收悉。经研究，批准你公司对章程进行相应修改。

请你公司据此办理有关变更手续。

此复

附件：瑞泰人寿保险有限公司章程（略）
