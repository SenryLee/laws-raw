# 中国保险监督管理委员会关于民生通惠资产管理有限公司变更营业场所(住所)的批复

## 中国保险监督管理委员会关于民生通惠资产管理有限公司变更营业场所（住所）的批复（保监发改〔2012〕1375号）

民生通惠资产管理有限公司：

你公司《关于申请变更营业场所（住所）的请示》（民资管发〔2012〕2号）及相关补充材料收悉。经审核，同意你公司营业场所（住所）由“上海市浦东新区陆家嘴西路99号万向大厦17层”变更为“上海市虹口区松花江路2601号1幢B区3楼”。

请你公司按照有关规定，办理变更手续。

此复

中国保险监督管理委员会

2012年11月28日
