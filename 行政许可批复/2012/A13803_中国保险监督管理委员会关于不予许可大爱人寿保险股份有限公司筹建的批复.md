# 中国保险监督管理委员会关于不予许可大爱人寿保险股份有限公司筹建的批复

## 中国保险监督管理委员会关于不予许可大爱人寿保险股份有限公司筹建的批复（保监发改〔2012〕759号）

德信控股集团有限公司、广源建设集团有限公司、汇孚集团有限公司、浙江方正房地产开发有限公司、浙江佳彩印务有限公司、马鞍山市黄河水处理工程有限公司、杭州东升铝幕墙装璜有限公司：

你们提交的《关于设立大爱人寿保险股份有限公司的请示》及相关补充材料收悉。经审核，存在以下问题：

**一、**发起人德信控股集团有限公司无自有资金出资，发起人浙江方正房地产开发有限公司、马鞍山市黄河水处理工程有限公司、杭州东升铝幕墙装璜有限公司自有资金不足以出资，不符合《保险公司股权管理办法》第七条“股东应当以来源合法的自有资金向保险公司投资”的要求。

**二、**发起人德信控股集团有限公司、浙江方正房地产开发有限公司短期偿债压力较大，不符合《保险公司股权管理办法》第十三条第一款“财务状况良好稳定”的要求。

经研究，决定不予许可大爱人寿保险股份有限公司筹建。

申请人对以上决定如有异议，可在本批复送达之日起60日内向中国保监会提出行政复议，或在3个月内向人民法院提起行政诉讼。

中国保险监督管理委员会

二○一二年七月二日
