# 文化部关于同意韩国歌手米娜到重庆市演出的批复(2012)

## 文化部关于同意韩国歌手米娜到重庆市演出的批复（文市函〔2012〕1194号）

重庆市文化广播电视局：

渝文广行文〔2012〕27号请示收悉。

经研究，同意重庆演出有限责任公司邀请韩国歌手米娜，于2012年7月14日、7月28日、8月12日到重庆市演出。

此复。

2012年7月12日
