# 中国保险监督管理委员会关于中国大地财产保险股份有限公司修改章程的批复(2012)

## 中国保险监督管理委员会关于中国大地财产保险股份有限公司修改章程的批复（保监发改〔2012〕51号）

中国大地财产保险股份有限公司：

你公司关于修改章程的请示（大地财保发〔2011〕435号）及补充材料收悉。经审查，核准你公司2011年9月20日股东大会决议对章程做出的以下修改：

**一、**第十三条 公司注册资本为人民币5，719，984，100元。公司全部资本划分为等额股份，每股面值为人民币1元，股份总数为5，719，984，100股。

**二、**第十五条 公司目前的注册资本为人民币5，719，984，100元，股份总数为5，719，984，100股，公司现有股东的名称、出资方式、出资额、认购的股份数的情况如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 股东名称 | 出资额  （人民币元） | 认购股份（股） | 占总股本  比例 | 出资  方式 |
| 1.中国再保险（集团）股份有限公司 | 5，277，236，328 | 5，277，236，328 | 92.26% | 货币 |
| 2.宁波市电力开发公司 | 266，040，750 | 266，040，750 | 4.65% | 货币 |
| 3.大唐国际发电股份有限公司 | 150，106，583 | 150，106，583 | 2.62% | 货币 |
| 4.北京松联科技有限公司 | 26，600，439 | 26，600，439 | 0.47% | 货币 |

**三、**增加一条作为第一百四十一条，内容为：公司对外担保行为应严格遵守中国保监会的监管规定，不得从事中国保监会监管规定禁止的担保行为。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

二〇一二年一月十二日
