# 中国保险监督管理委员会关于中煤财产保险股份有限公司财务会计部门负责人的批复(2012)

## 中国保险监督管理委员会关于中煤财产保险股份有限公司财务会计部门负责人的批复（保监财会〔2012〕979号）

中煤财产保险股份有限公司：

你公司《关于核准张国堂同志财务部门负责人任职资格的请示》（中煤财保〔2012〕96号）收悉。经审查，同意张国堂担任中煤财产保险股份有限公司财务会计部门负责人。

此复

中国保险监督管理委员会

2012年8月18日
