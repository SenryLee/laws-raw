# 中国保险监督管理委员会关于东京海上日动火灾保险(中国)有限公司变更营业场所的批复(2012)

## 中国保险监督管理委员会关于东京海上日动火灾保险（中国）有限公司变更营业场所的批复（保监国际〔2012〕597号）

东京海上日动火灾保险（中国）有限公司：

你公司《关于营业场所变更的请示》（TMNCH〔2012〕118号）收悉。经研究，批准你公司营业场所变更为“上海市浦东新区陆家嘴环路1000号恒生银行大厦38楼、29楼011室、41楼”。

请你公司尽快按有关规定办理相应变更手续。

此复

中国保险监督管理委员会

二○一二年五月二十二日
