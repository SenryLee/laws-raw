# 中国证券监督管理委员会关于核准招商银行股份有限公司境外上市外资股配股的批复(2012)

## 中国证券监督管理委员会关于核准招商银行股份有限公司境外上市外资股配股的批复（证监许可[2012]528号）

招商银行股份有限公司：

你公司报送的《招商银行关于境外上市外资股配股的请示》（招银发[2011]481号）及相关文件收悉。根据《证券法》、《国务院关于股份有限公司境外募集股份及上市的特别规定》等有关规定，经审核，现批复如下：

**一、**核准你公司向境外上市外资股股东配售不超过821，200，380股境外上市外资股，每股面值人民币1元，全部为普通股。

**二、**完成发行后15个工作日内，你公司应将本次配股的情况书面报告我会。

**三、**你公司在境外配股和上市过程中，应严格遵守境内外有关法律、法规和规则。

二○一二年四月十九日
