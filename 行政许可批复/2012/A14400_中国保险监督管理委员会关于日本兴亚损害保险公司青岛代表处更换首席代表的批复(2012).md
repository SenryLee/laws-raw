# 中国保险监督管理委员会关于日本兴亚损害保险公司青岛代表处更换首席代表的批复(2012)

## 中国保险监督管理委员会关于日本兴亚损害保险公司青岛代表处更换首席代表的批复（保监国际〔2012〕709号）

日本兴亚损害保险公司：

你公司关于更换青岛代表处首席代表的申请材料收悉。经研究，批准赵佳惠接替张斌担任日本兴亚损害保险公司青岛代表处首席代表。

此复

中国保险监督管理委员会
