# 中国保险监督管理委员会关于台湾富邦人寿保险股份有限公司北京代表处更换首席代表的批复(2012)

## 中国保险监督管理委员会关于台湾富邦人寿保险股份有限公司北京代表处更换首席代表的批复（保监国际〔2012〕350号）

台湾富邦人寿保险股份有限公司：

你公司关于更换北京代表处首席代表的申请材料收悉。经研究，批准高昭文接替翁正一担任台湾富邦人寿保险股份有限公司北京代表处首席代表。

此复

中国保险监督管理委员会
