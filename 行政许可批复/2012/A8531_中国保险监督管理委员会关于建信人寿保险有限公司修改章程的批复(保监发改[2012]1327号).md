# 中国保险监督管理委员会关于建信人寿保险有限公司修改章程的批复(保监发改[2012]1327号)

## 中国保险监督管理委员会关于建信人寿保险有限公司修改章程的批复（保监发改〔2012〕1327号）

建信人寿保险有限公司：

你公司关于修改章程的请示（建信人寿总报〔2012〕415号）收悉。经审查，核准你公司2012年9月13日股东会决议对章程做的如下修改：

**一、**第十条修改为：公司的注册资本为人民币肆拾肆亿玖仟伍佰柒拾捌万玖仟肆佰柒拾叁（4，495，789，473）元。

**二、**第十一条修改为：公司目前的股权结构为：

|  |  |  |
| --- | --- | --- |
| 股东名称 | 出资额（人民币） | 持股比例 |
| 中国建设银行股份有限公司  （“建设银行”） | 2，292，852，632 | 51.00% |
| 中国人寿保险股份有限公司（台湾）（“中寿”） | 894，662，105 | 19.90% |
| 全国社会保障基金理事会  （“社保基金”） | 641，605，263 | 14.27% |
| 中国建银投资有限责任公司  （“中国建投”） | 228，330，000 | 5.08% |
| 上海锦江国际投资管理有限公司（“锦江国际”） | 220，293，684 | 4.90% |
| 上海华旭投资有限公司  （“华旭投资”） | 218，045，789 | 4.85% |
| 合计 | 4，495，789，473 | 100% |

**三、**第七十三条第一款修改为：董事会由十名董事组成，其中独立董事三名，执行董事至少二名。七名非独立董事中，建设银行有权提名五名，中寿有权提名一名，社保基金有权提名一名。所提名的董事须符合有关法律法规规定的或审批机关要求的任职资格。具有提名权的股东承诺，只提名适合履行董事职责的人选担任董事职务。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

2012年11月16日
