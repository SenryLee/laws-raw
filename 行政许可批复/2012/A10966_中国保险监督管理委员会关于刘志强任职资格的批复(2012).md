# 中国保险监督管理委员会关于刘志强任职资格的批复(2012)

## 中国保险监督管理委员会关于刘志强任职资格的批复（保监产险〔2012〕1134号）

安华农业保险股份有限公司：

你公司《关于核准刘志强同志任职资格的请示》（安农险字〔2012〕85号）收悉。经审核，刘志强符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准其担任你公司总经理的任职资格。

此复

中国保险监督管理委员会

2012年9月14日
