# 文化部关于同意美国歌手费翔到浙江省演出的批复（文市函[2012]2130号）

## 文化部关于同意美国歌手费翔到浙江省演出的批复（文市函〔2012〕2130号）

浙江省文化厅：

浙文外〔2012〕576号请示收悉。

经研究，同意浙江国华演艺有限公司邀请美国歌手费翔，于2012年11月19日到浙江省兰溪市演出。

此复。
