# 国家文物局关于丝绸之路申报世界文化遗产甘肃段规划编制工作立项的批复

## 国家文物局关于丝绸之路申报世界文化遗产甘肃段规划编制工作立项的批复（文物保函〔2012〕1328号）

甘肃省文物局：

你局《关于申请丝绸之路申报世界文化遗产甘肃段规划编制立项的报告》（甘文局发[2012]147号）收悉。经研究，我局批复如下：

**一、**原则同意丝绸之路申报世界文化遗产甘肃段规划编制工作立项。

**二、**请你局指导地方人民政府，组织具有文物保护规划编制相关资质的专业单位，根据联合国教科文组织《保护世界文化和自然遗产公约》及其《操作指南》，我国《文物保护法》、《世界文化遗产保护管理办法》和《全国重点文物保护单位保护规划编制要求》，以及我局《关于推进丝绸之路申遗工作的通知》（文物保函[2012]342号）的相关要求，抓紧开展丝绸之路申报世界文化遗产甘肃段规划编制及相关前期工作，确保丝绸之路跨国系列申遗工作的顺利进行。

此复。

国家文物局　　

二〇一二年六月一日
