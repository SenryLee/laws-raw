# 中国保险监督管理委员会关于中华联合保险控股股份有限公司修改章程的批复(2012)

## 中国保险监督管理委员会关于中华联合保险控股股份有限公司修改章程的批复（保监发改〔2012〕257号）

中华联合保险控股股份有限公司：

你公司关于修改章程的请示（中华保险发〔2012〕3号）收悉。经审查，核准你公司2011年12月21日股东大会决议对章程做出以下修改：

**一、**第五条修改为：公司注册资本为人民币750000万元。

**二、**第十七条修改为：公司发行的股票，以人民币标明面值。公司发起设立时总股本为150000万股，每股面值为1元人民币。公司设立时由全体发起人于2005年12月31日认购公司发行的全部股份，其中发起人新疆生产建设兵团国有资产管理委员会以现金加净资产认购，其他发起人均为现金认购。向发起人新疆生产建设兵团国有资产管理委员会发行674，932，603股，占可发行普通股总数的44.9956%；向发起人新疆生产建设兵团投资中心（现更名为“新疆生产建设兵团投资有限责任公司”）发行300，000，000股，占可发行普通股总数的20%；向发起人新疆华联投资有限公司发行270，967，397股，占可发行普通股总数的18.0645%；向发起人乌鲁木齐国有资产经营有限公司发行100，000，000股，占可发行普通股总数的6.6667%；向发起人新疆生产建设兵团农业建设第二师发行20，000，000股，占可发行普通股总数的1.3333%；向发起人新疆生产建设兵团农三师国有资产经营有限公司发行15，000，000股，占可发行普通股总数的1.0000%；向发起人新疆昆仑神农股份有限公司发行5，000，000股，占可发行普通股总数的0.3333%；向发起人伊犁农四师国有资产投资有限责任公司发行30，000，000股，占可发行普通股总数的2.0000%；向发起人新疆生产建设兵团农六师国有资产监督管理委员会发行20，000，000股，占可发行普通股总数的1.3333%；向发起人新疆锦棉棉业股份有限公司发行10，000，000股，占可发行普通股总数的0.6667%；向发起人新疆天融投资（集团）有限公司（现更名为“石河子国有资产经营（集团）有限公司”）发行30，000，000股，占可发行普通股总数的2.0000%；向发起人昌吉市天隆商贸有限公司发行2，100，000股，占可发行普通股总数的0.1400%；向发起人新疆生产建设兵团农业建设第一师塔里木灌区水利管理处发行3，000，000股，占可发行普通股总数的0.2000%；向发起人新疆生产建设兵团农一师十六团发行3，000，000股，占可发行普通股总数的0.2000%；向发起人新疆生产建设兵团农一师十团发行3，000，000股，占可发行普通股总数的0.2000%；向发起人新疆生产建设兵团农一师三团发行3，000，000股，占可发行普通股总数的0.2000%；向发起人新疆生产建设兵团农业建设第一师沙井子灌区水利管理处发行2，000，000股，占可发行普通股总数的0.1333%；向发起人新疆生产建设兵团农一师一团发行3，000，000股，占可发行普通股总数的0.2000%；向发起人新疆生产建设兵团农一师七团发行5，000，000股，占可发行普通股总数的0.3333%。

**三、**第十八条修改为：公司总股本为 750000 万股，每股面值为1元人民币。其中中国保险保障基金有限责任公司持有6，861，432，603股，占公司已发行普通股总数的91.4858%；新疆生产建设兵团投资有限责任公司持有150，000，000股，占公司已发行普通股总数的2.0000%；新疆生产建设兵团国有资产监督管理委员会持有87，000，000股，占公司已发行普通股总数的1.1600%；伊犁农四师国有资产投资有限责任公司持有15，000，000股，占公司已发行普通股总数的0.2000%；石河子国有资产经营（集团）有限公司持有15，000，000股，占公司已发行普通股总数的0.2000%；新疆生产建设兵团农业建设第二师持有10，000，000股，占公司已发行普通股总数的0.1333%；新疆生产建设兵团农六师国有资产监督管理委员会持有10，000，000股，占公司已发行普通股总数的0.1333%；新疆生产建设兵团农三师国有资产经营有限公司持有7，500，000股，占公司已发行普通股总数的0.1000%；新疆锦棉棉业股份有限公司持有5，000，000股，占公司已发行普通股总数的0.0667%；新疆生产建设兵团农一师七团持有5，000，000股，占公司已发行普通股总数的0.0667%；新疆昆仑神农股份有限公司持有2，500，000股，占公司已发行普通股总数的0.0333%；新疆生产建设兵团农业建设第一师塔里木灌区水利管理处持有1，500，000股，占公司已发行普通股总数的0.0200%；新疆生产建设兵团农一师十六团持有1，500，000股，占公司已发行普通股总数的0.0200%；新疆生产建设兵团农一师十团持有1，500，000股，占公司已发行普通股总数的0.0200%；新疆生产建设兵团农一师三团持有1，500，000股，占公司已发行普通股总数的0.0200%；新疆生产建设兵团农一师一团持有1，500，000股，占公司已发行普通股总数的0.0200%；新疆生产建设兵团农业建设第一师沙井子灌区水利管理处持有1，000，000股，占公司已发行普通股总数的0.0133%；乌鲁木齐国有资产经营有限公司持有50，000，000股，占公司已发行普通股总数的0.6667%；昌吉市天隆商贸有限公司持有2，100，000股，占公司已发行普通股总数的0.0280%；新疆华联投资有限公司持有270，967，397股，占公司已发行普通股总数的3.6129%。
