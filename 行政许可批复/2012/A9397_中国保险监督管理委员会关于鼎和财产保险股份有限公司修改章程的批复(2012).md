# 中国保险监督管理委员会关于鼎和财产保险股份有限公司修改章程的批复(2012)

## 中国保险监督管理委员会关于鼎和财产保险股份有限公司修改章程的批复（保监发改〔2012〕1253号）

鼎和财产保险股份有限公司：

你公司关于修改章程的请示（鼎和保险发〔2012〕206号）收悉。经审查，核准你公司2012年9月10日股东大会决议将章程第二条第二款公司住所修改为“深圳市福田区金田路2030号卓越皇岗世纪中心1号楼13－14楼”。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

2012年10月29日
