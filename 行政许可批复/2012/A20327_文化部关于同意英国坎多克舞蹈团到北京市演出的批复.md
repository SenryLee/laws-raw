# 文化部关于同意英国坎多克舞蹈团到北京市演出的批复

## 文化部关于同意英国坎多克舞蹈团到北京市演出的批复（文市函〔2012〕197号　）

北京市文化局：

你局京文外发〔2012〕109号请示收悉。

经研究，同意北京云汉文化交流有限公司邀请英国坎多克舞蹈团一行19人，于2012年4月13日至25日到北京市演出舞蹈《无限》。

此复。

二O一二年二月二十一日
