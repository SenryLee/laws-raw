# 中国保险监督管理委员会关于中英人寿保险有限公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于中英人寿保险有限公司资本保证金处置的批复（保监财会〔2012〕2号）

中英人寿保险有限公司：

你公司《关于中英人寿保险有限公司处置资本保证金存款的请示》（中英人寿〔2011〕249号）收悉。经研究，同意你公司将原存放于中国工商银行福州阳光支行的1.49亿元人民币资本保证金存款分别转存至中国银行北京建国门外支行5000万元、中国银行北京学院路支行5000万元和中国银行成都沙湾支行4900万元。

请你公司在资本保证金存款存妥后10个工作日内，将《资本保证金存款协议》原件和背书后的存单复印件报我会。

此复

中国保险监督管理委员会

二○一二年一月四日
