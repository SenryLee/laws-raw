# 文化部关于同意美国歌手李玟、顺子等到四川省演出的批复

## 文化部关于同意美国歌手李玟、顺子等到四川省演出的批复（文市函〔2012〕1015号）

四川省文化厅：

川文〔2012〕90号请示收悉。

经研究，同意四川金手指文化传播有限公司邀请美国歌手李玟、顺子、吴欣云，新加坡歌手阿杜，日本歌手中孝介，韩国歌手崔东旭一行6人于2012年6月28日到四川省成都市演出。

此复。

二O一二年六月二十五日
