# 国土资源部关于同意命名山西陵川王莽岭国家地质公园的批复

## 国土资源部关于同意命名山西陵川王莽岭国家地质公园的批复（国土资函〔2012〕814号）

山西省国土资源厅：

《关于山西陵川王莽岭国家地质公园验收命名并揭碑开园的请示》（晋国土资发〔2012〕345号）收悉。部组织专家组对地质公园建设进行了实地验收，依据部相关文件要求及专家组验收意见，批复如下：

**一、**同意命名山西陵川王莽岭国家地质公园。

**二、**山西陵川王莽岭国家地质公园要以科学发展观为指导，遵循“保护中开发，开发中保护”的原则，做好园区内岩溶地貌景观等地质遗迹资源的保护和开发利用，开展公众地学科普教育和科学研究，并按照国土资源部相关规定和国家地质公园建设指南要求，加强公园管理，完善公园建设，为促进地方资源、环境和经济的协调发展做出贡献。

**三、**你厅要加强对山西陵川王莽岭国家地质公园建设的指导，监督和检查地质公园及其主管部门按照国家相关法律规范开展各项活动。

2012年10月16日
