# 文化部关于同意美国萨克斯演奏者KENNETH BRUCE GORELICK等到四川省演出的批复

## 文化部关于同意美国萨克斯演奏者KENNETH　BRUCE　GORELICK等到四川省演出的批复（文市函〔2012〕1825号）

四川省文化厅：

川文〔2012〕132号请示收悉。

经研究，同意深圳市聚橙网络技术有限公司邀请美国萨克斯演奏者KENNETH BRUCE GORELICK等一行9人，于2012年10月20日至2013年1月10日到四川省演出。

此复。
