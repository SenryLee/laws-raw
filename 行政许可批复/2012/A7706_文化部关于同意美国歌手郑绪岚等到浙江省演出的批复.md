# 文化部关于同意美国歌手郑绪岚等到浙江省演出的批复

## 文化部关于同意美国歌手郑绪岚等到浙江省演出的批复（文市函〔2012〕2363号）

浙江省文化厅：

浙文外〔2012〕658号请示收悉。

经研究，同意北京春夏秋冬文化发展有限公司邀请美国歌手郑绪岚、尼日利亚歌手郝歌（EMMANUEL ADIMABUA UWECHUE）、SKARF组合（新加坡LIU YILING、FERLYN WONG GILLEEN，韩国JEONG SOL、LEE JUYEONG）、五洲辣妹组合（乌干达KEISHA MARY MIREMBE、澳大利亚MARIE LOUISE SMURTHWAITE、加拿大LISA MARIE HOFFMAN、法国CLEMENCE LE BORGNE），于2012年12月5日到浙江省义乌市演出。

此复。

2012年12月4日
