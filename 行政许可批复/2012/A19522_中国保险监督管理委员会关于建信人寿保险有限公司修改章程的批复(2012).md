# 中国保险监督管理委员会关于建信人寿保险有限公司修改章程的批复(2012)

## 中国保险监督管理委员会关于建信人寿保险有限公司修改章程的批复（保监发改〔2012〕271号）

建信人寿保险有限公司：

你公司关于修改章程的请示（建信人寿总报〔2012〕55号）收悉。经审查，核准你公司2011年11月21日股东会决议对章程做的如下修改：

**一、**第十条修改为：公司的注册资本为人民币壹拾壹亿捌仟万（1，180，000，000）元。

**二、**第十一条修改为：公司目前的股权结构为：

|  |  |  |
| --- | --- | --- |
| 股东名称 | 出资额（人民币） | 持股比例 |
| 中国建设银行股份有限公司（“建设银行”） | 601，800，000 | 51% |
| 中国人寿保险股份有限公司（台湾）（“中寿”） | 234，820，000 | 19.9% |
| 中国建银投资有限责任公司（“中国建投”） | 228，330，000 | 19.35% |
| 上海锦江国际投资管理有限公司（“锦江国际”） | 57，820，000 | 4.9% |
| 上海华旭投资有限公司（“华旭投资”） | 57，230，000 | 4.85% |
| 合计： | 1，180，000，000 | 100% |

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

二○一二年三月八日
