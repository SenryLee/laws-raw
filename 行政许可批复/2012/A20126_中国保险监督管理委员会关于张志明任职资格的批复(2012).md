# 中国保险监督管理委员会关于张志明任职资格的批复(2012)

## 中国保险监督管理委员会关于张志明任职资格的批复（保监寿险〔2012〕194号）

信泰人寿保险股份有限公司：

你公司《关于张志明同志任职资格的请示》（信泰发〔2012〕25号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准张志明担任你公司总经理助理的任职资格。

此复

中国保险监督管理委员会

二○一二年二月二十七日
