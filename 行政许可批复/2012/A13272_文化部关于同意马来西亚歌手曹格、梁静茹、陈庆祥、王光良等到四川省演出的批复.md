# 文化部关于同意马来西亚歌手曹格、梁静茹、陈庆祥、王光良等到四川省演出的批复

## 文化部关于同意马来西亚歌手曹格、梁静茹、陈庆祥、王光良等到四川省演出的批复（文市函〔2012〕1226号）

四川省文化厅：

川文〔2012〕97号请示收悉。

经研究，同意四川省演出展览公司邀请马来西亚歌手曹格、梁静茹、陈庆祥、王光良、林凡、陈威全，于2012年8月11日到四川省成都市演出。

此复。

2012年7月16日
