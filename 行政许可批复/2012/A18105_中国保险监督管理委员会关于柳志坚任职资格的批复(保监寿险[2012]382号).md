# 中国保险监督管理委员会关于柳志坚任职资格的批复(保监寿险[2012]382号)

## 中国保险监督管理委员会关于柳志坚任职资格的批复（保监寿险〔2012〕382号）

中国平安人寿保险股份有限公司：

你公司《关于柳志坚任职资格审查的请示》（平保寿发〔2012〕63号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准柳志坚担任你公司董事的任职资格。

此复

中国保险监督管理委员会

二○一二年四月一日
