# 中国保险监督管理委员会关于柳海东担任精算责任人的批复(2012)

## 中国保险监督管理委员会关于柳海东担任精算责任人的批复（保监产险〔2012〕476号）

永诚财产保险股份有限公司：

你公司《关于聘任柳海东同志为永诚财产保险股份有限公司精算责任人的请示》（永总字〔2012〕115号）收悉。经审核，同意柳海东担任你公司精算责任人，王帆不再担任你公司精算责任人。

此复

中国保险监督管理委员会

二○一二年四月二十五日
