# 中国保险监督管理委员会关于建信人寿保险有限公司变更注册资本的批复(2012)

## 中国保险监督管理委员会关于建信人寿保险有限公司变更注册资本的批复（保监发改〔2012〕891号）

建信人寿保险有限公司：

你公司《关于建信人寿保险有限公司变更注册资本的请示》（建信人寿总报〔2012〕246号）及相关补充材料收悉。经审核，现批复如下：

**一、**同意你公司注册资本变更为4，495，789，473元人民币。其中，中国建设银行股份有限公司出资额为2，292，852，632元，出资比例为51.00%；中国人寿保险股份有限公司（台湾）出资额为894，662，105元，出资比例为19.90%；全国社会保障基金理事会出资额为641，605，263元，出资比例为14.27%；中国建银投资有限责任公司出资额为228，330，000元，出资比例为5.08%；上海锦江国际投资管理有限公司出资额为220，293，684元，出资比例为4.90%；上海华旭投资有限公司出资额为218，045，789元，出资比例为4.85%。

**二、**请你公司对公司章程作相应修改，并按照有关规定办理变更手续。

中国保险监督管理委员会

二○一二年七月二十七日
