# 中国证券监督管理委员会关于核准金元惠理基金管理有限公司变更注册资本及修改章程的批复

## 中国证券监督管理委员会关于核准金元惠理基金管理有限公司变更注册资本及修改章程的批复（证监许可[2012]1297号）

金元惠理基金管理有限公司：

你公司报送的《金元惠理基金管理有限公司关于增加注册资本、修改公司章程的请示》（金元惠理司发[2012]177号）及相关文件收悉。根据《公司法》、《证券投资基金法》和《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由15，000万元人民币增加到24，500万元。其中，金元证券股份有限公司增加出资4，845万元， 惠理基金管理香港有限公司增加出资4，655万元。

你公司变更注册资本后，公司的股权结构为：

人民币　 万 元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 金元证券股份有限公司 | 12，495 | 51 ％ |
| 2 | 惠理基金管理香港有限公司 | 12，005 | 49 ％ |
|  | 合计 | 24，5 0 0 | 100％ |

**二、**核准你公司对公司章程所作的修改。

**三、**你公司应当按规定及时办理工商变更登记等相关事宜，并到我会换领《基金管理资格证书 》， 完善公司治理结构，维护公司及基金份额持有人的合法权益 。

中国证券监督管理委员会

2012年9月27日
