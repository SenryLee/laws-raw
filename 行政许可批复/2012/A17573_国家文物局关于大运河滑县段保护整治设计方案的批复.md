# 国家文物局关于大运河滑县段保护整治设计方案的批复

## 国家文物局关于大运河滑县段保护整治设计方案的批复（文物保函〔2012〕854号）

河南省文物局：

你局《关于报批大运河申遗预备项目大运河滑县段环境保护整治设计方案的请示》（豫文物[2011]451号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出以下修改意见：

（一）各项保护、展示和整治措施中涉及交通、水利等事项的内容，应征求有关部门的意见。

（二）实施运河河道清淤、整治等工作，应组织考古专业机构进行先期考古调查和勘探，明确河道原有形制、结构等基本情况，在此基础上进一步深化清淤、整治方案。

（三）完善建筑整治措施。其中，建筑维修与建筑改造属不同类型，应予区分。同时，应明确建筑高度控制、立面整治等的具体措施和技术指标。

（四）细化植物配置方案及相应的图纸，明确实施位置、面积、植物种类等，并应避免过分园林化、景观化的倾向。

（五）应尽可能利用古镇现有建筑作为游客服务设施，不宜另行新建游客服务中心。

（六）进一步校核方案文本和图纸。

**三、**请你局组织相关单位，根据以上意见对方案进行修改完善，由你局核准后实施。请加强工程的监督管理，确保工程质量和文物安全。各保护整治项目实施前，应组织考古专业机构对相关区域进行考古调查、勘探和发掘，如遇重要发现，应及时上报并调整设计方案，避让重要的遗址遗迹，妥善保护各类历史信息。

此复。

国家文物局　　

二〇一二年四月十二日
