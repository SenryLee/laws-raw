# 国家文物局关于河南省2012年度考古报告出版工作计划的批复

## 国家文物局关于河南省2012年度考古报告出版工作计划的批复（文物保函〔2012〕1327号）

河南省文物局：

你局《关于对河南省2012年度考古调查、发掘报告整理出版工作进行立项的请示》（豫文物[2012]120号）收悉。经研究，我局同意你局所报《登封南洼：2004～2006年田野考古发掘报告》、《二里头--1999～2006年考古发掘报告》、《邙山陵墓群考古调查与勘测第一阶段考古报告》、《平顶山应国墓地》、《濮阳西水坡》、《温县盟书》、《伊川考古发掘报告》、《郑州小双桥--1999～2000年考古发掘报告》、《五女冢遗址考古发掘报告》、《偃师华润电厂考古报告》等十部考古发掘报告的出版计划。请你局按照财政部、国家文物局《国家重点文物保护专项补助经费使用管理办法》（财教〔2001〕351号）文件的规定和我局的有关要求，另行申请上述考古报告出版补助经费。

国家文物局　　　

二〇一二年五月二十三日
