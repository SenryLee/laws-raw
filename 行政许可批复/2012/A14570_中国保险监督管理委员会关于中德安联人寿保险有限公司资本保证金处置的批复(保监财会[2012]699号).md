# 中国保险监督管理委员会关于中德安联人寿保险有限公司资本保证金处置的批复(保监财会[2012]699号)

## 中国保险监督管理委员会关于中德安联人寿保险有限公司资本保证金处置的批复（保监财会〔2012〕699号）

中德安联人寿保险有限公司：

你公司《关于资本保证金到期变更存款性质的请示》（安联发〔2012〕92号）收悉。经研究，同意你公司变更以下6笔资本保证金存款的性质，以下6笔存款不再作为资本保证金存款，可由你公司依法处置：

**一、**存放于交通银行上海第一支行的9000万元人民币。

**二、**存放于中国建设银行上海静安支行的5笔合计1.9亿元人民币。

此复

中国保险监督管理委员会

二○一二年六月十三日
