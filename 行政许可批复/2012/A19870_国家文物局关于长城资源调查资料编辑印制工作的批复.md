# 国家文物局关于长城资源调查资料编辑印制工作的批复

## 国家文物局关于长城资源调查资料编辑印制工作的批复（文物保函〔2012〕391号）

辽宁省文物局：

你局《关于上报〈长城资源调查资料出版方案〉的请示》（辽文物保发〔2012〕18号）收悉。经研究，我局批复如下：

**一、**原则同意你局所报《长城资源调查资料出版方案》。

**二、**请你局联合长城资源调查项目组，做好长城资源调查资料编辑印制工作。相关工作应全面反映长城资源调查和认定工作所取得的成绩，科学、准确、详细地展示我国各时代长城的分布范围、走向、历史沿革、时代和地域特征、保护管理状况等重要成果。

**三、**请你局指导相关单位，严格按照《中华人民共和国保守国家秘密法》等法律法规的规定，做好相关长城资源调查资料保密工作，确保国家秘密安全。

**四、**请你局按照财政部、国家文物局《大遗址保护专项经费管理办法》（财教〔2005〕135号）文件的规定和我局的有关要求，另行申请长城资源调查资料编辑印制补助经费。

此复。

国家文物局　　

二〇一二年三月一日
