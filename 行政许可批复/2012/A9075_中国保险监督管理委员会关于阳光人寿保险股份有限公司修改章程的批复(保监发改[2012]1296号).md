# 中国保险监督管理委员会关于阳光人寿保险股份有限公司修改章程的批复(保监发改[2012]1296号)

## 中国保险监督管理委员会关于阳光人寿保险股份有限公司修改章程的批复（保监发改〔2012〕1296号）

阳光人寿保险股份有限公司：

你公司关于修改章程的请示（阳光人寿〔2012〕169号）收悉。经审查，核准你公司2012年3月23日股东大会决议对章程附件股权结构表做出的修改。

请你公司依照有关规定办理变更事宜。

此复

附件：阳光人寿保险股份有限公司股权结构表（略）

中国保险监督管理委员会

2012年11月5日
