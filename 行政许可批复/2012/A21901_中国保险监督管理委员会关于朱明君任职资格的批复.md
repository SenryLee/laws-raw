# 中国保险监督管理委员会关于朱明君任职资格的批复

## 中国保险监督管理委员会关于朱明君任职资格的批复（保监国际〔2012〕47号）

新光海航人寿保险有限责任公司：

你公司《关于朱明君任职资格的请示》（新光海航人〔2011〕75号）收悉。经审查，朱明君符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准其担任你公司朝阳支公司经理的任职资格。

此复

中国保险监督管理委员会

二○一二年一月十二日
