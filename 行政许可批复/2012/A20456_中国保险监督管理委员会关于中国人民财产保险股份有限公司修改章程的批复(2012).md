# 中国保险监督管理委员会关于中国人民财产保险股份有限公司修改章程的批复(2012)

## 中国保险监督管理委员会关于中国人民财产保险股份有限公司修改章程的批复（保监发改〔2012〕174号）

中国人民财产保险股份有限公司：

你公司关于修改公司章程的请示（人保财险董发〔2012〕1号）收悉。经审查，核准你公司董事会根据2011年6月24日股东大会决议授权对章程进行的以下修改：

**一、**第十六条第一款修改为：公司首次公开发行及超额配售选择权行使后，公司总股本为普通股11，141，800，000股。公司完成内资股与H股配股后，公司总股本为普通股12，255，980，000股，其中中国人民保险集团股份有限公司持有8，454，402，000股内资股，占总股本的69％，境外上市外资股（H股）股东持有3，801，578，000股，占总股本的31％。

**二、**第十六条第二款修改为：公司的股份结构如下表：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 股份类别 | 股东名称 | 持股数量 | 持股比例 | 锁定期 |
| 内资股 | 中国人民保险  　　集团股份有限公司 | 8，454，402，000 | 69% | 无 |
| H股 | 美国国际集团 | 1，213，341，800 | 9.9% | 2003.11.06－2008.11.05（公司首次公开发行及超额配售选择权行使后的1，103，038，000股） |
| H股 | 其他H股股东 | 2，588，236，200 | 21.1% | 无 |
|  | 合计 | 12，255，980，000 | 100% |  |

**三、**第十九条 公司的注册资本为人民币12，255，980，000元。公司发行新股后，公司注册资本根据实际发行情况作相应调整。公司的注册资本应到国家工商行政管理总局进行登记，并报中国保监会和国家证券监督管理机构备案。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

二〇一二年二月二十日
