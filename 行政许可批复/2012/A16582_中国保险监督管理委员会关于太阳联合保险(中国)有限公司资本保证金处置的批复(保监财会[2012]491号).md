# 中国保险监督管理委员会关于太阳联合保险(中国)有限公司资本保证金处置的批复(保监财会[2012]491号)

## 中国保险监督管理委员会关于太阳联合保险（中国）有限公司资本保证金处置的批复（保监财会〔2012〕491号）

太阳联合保险（中国）有限公司：

你公司《关于400万元资本保证金处置的请示》（太阳联合〔2012〕108号）收悉。经研究，同意你公司变更存放于中国银行上海金茂大厦支行的400万元人民币资本保证金存款的性质，该存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保险监督管理委员会

二○一二年五月三日
