# 中国保险监督管理委员会关于张琅担任精算责任人的批复(2012)

## 中国保险监督管理委员会关于张琅担任精算责任人的批复（保监产险〔2012〕883号）

中国人民财产保险股份有限公司：

你公司《关于核准精算责任人资格的请示》（人保财险发〔2012〕258号）收悉。经审核，同意张琅担任你公司精算责任人，徐德洪不再担任你公司精算责任人。

此复

中国保险监督管理委员会

二○一二年七月二十六日
