# 中国保险监督管理委员会关于和谐健康保险股份有限公司资本保证金处置的批复

## 中国保险监督管理委员会关于和谐健康保险股份有限公司资本保证金处置的批复（保监财会〔2012〕932号）

和谐健康保险股份有限公司：

你公司《关于和谐健康保险股份有限公司农行资本保证金处置的请示》（和谐健康发〔2012〕114号）收悉。经研究，同意你公司将存放于中国农业银行总行营业部的1.4亿元人民币资本保证金存款分别转存至中国工商银行成都航空路支行5000万元、中国建设银行成都第一支行5000万元和中国农业银行成都金牛支行营业部4000万元。

请你公司在资本保证金存款存妥后10个工作日内，将《资本保证金存款协议》原件和背书后的存单复印件报我会。

此复

中国保险监督管理委员会

二○一二年八月三日
