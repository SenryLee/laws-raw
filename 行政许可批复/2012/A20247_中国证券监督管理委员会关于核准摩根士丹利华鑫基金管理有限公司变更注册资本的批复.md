# 中国证券监督管理委员会关于核准摩根士丹利华鑫基金管理有限公司变更注册资本的批复

## 中国证券监督管理委员会关于核准摩根士丹利华鑫基金管理有限公司变更注册资本的批复（证监许可[2012]235号）

摩根士丹利华鑫基金管理有限公司：

你公司报送的《关于摩根士丹利华鑫基金管理有限公司增加注册资本及修改相关章程的报告》（摩根士丹利华鑫基金字[2011]058号）及相关文件收悉。根据《公司法》、《证券投资基金法》和《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由1亿元人民币增加到2.275亿元。其中，华鑫证券有限责任公司增加出资5，400万元，摩根士丹利国际控股公司增加出资5，100万元，深圳市招融投资控股有限公司增加出资1，500万元，深圳市中技实业（集团）有限公司增加出资750万元。

你公司变更注册资本后，公司的股权结构为：

人民币 万元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 华鑫证券有限责任公司 | 9，000 | 39.56 ％ |
| 2 | 摩根士丹利国际控股公司 | 8，500 | 37.363 ％ |
| 3 | 深圳市招融投资控股有限公司 | 2，500 | 10.989 ％ |
| 4 | 汉唐证券有限责任公司 | 1，500 | 6.593% |
| 5 | 深圳市中技实业（集团）有限公司 | 1，250 | 5.495% |
|  | 合计 | 22，750 | 100％ |

**二、**核准你公司所作的与变更公司注册资本、股东出资相关的公司章程修改。

**三、**你公司应当按规定及时办理工商变更登记等相关事宜，并到我会换领《基金管理资格证书》。

中国证券监督管理委员会

二〇一二年二月二十三日
