# 中国保险监督管理委员会关于周光平任职资格的批复(保监国际[2012]1067号)

## 中国保险监督管理委员会关于周光平任职资格的批复（保监国际〔2012〕1067号）

瑞泰人寿保险有限公司：

你公司关于周光平任职资格核准的申请材料（瑞泰人寿〔2012〕185号）收悉。经审查，周光平符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准其担任你公司浙江分公司总经理的任职资格。

此复

中国保监会

2012年8月31日
