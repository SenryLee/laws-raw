# 文化部关于同意美国歌手潘玮柏到上海市演出的批复(2012)

## 文化部关于同意美国歌手潘玮柏到上海市演出的批复（文市函〔2012〕1251号）

上海市文化广播影视管理局：

沪文广影视〔2012〕1180号请示收悉。

经研究，同意上海普杰文化传播有限公司与上海杰鑫文化传播有限公司共同邀请美国歌手潘玮柏，于2012年11月10日到上海市演出。

此复。
