# 中国保险监督管理委员会关于海康人寿保险有限公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于海康人寿保险有限公司资本保证金处置的批复（保监财会〔2012〕1394号）

海康人寿保险有限公司：

你公司《海康人寿保险有限公司关于资本保证金变更存放银行的请示》（海康人寿〔2012〕313号）收悉。经审核，同意你公司将存放于中国农业银行上海市长宁区定西路支行的2000万元人民币资本保证金存款转存至中国工商银行上海市鞍山路支行。

请你公司在资本保证金存款存妥后10个工作日内，将《资本保证金存款协议》原件和背书后的存单复印件报我会备案。

此复

中国保险监督管理委员会

2012年12月3日
