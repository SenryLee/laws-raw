# 民政部关于同意海南省民政厅修订五指山市和保亭黎族苗族自治县行政区划图的批复

民政部关于同意海南省民政厅修订五指山市和保亭黎族苗族自治县行政区划图的批复

（民函〔2012〕228号）

海南省民政厅：

你厅《关于修订五指山市和保亭黎族苗族自治县行政区划图的请示》（琼民〔2012〕41号）收悉。现批复如下：

同意你厅根据1986年《国务院关于广东省设立通什市的批复》（国函〔1986〕80号），对五指山市和保亭黎族苗族自治县行政区划图进行修订。

民 政 部

2012年7月16日
