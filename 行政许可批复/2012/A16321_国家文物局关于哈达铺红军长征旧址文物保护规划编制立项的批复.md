# 国家文物局关于哈达铺红军长征旧址文物保护规划编制立项的批复

## 国家文物局关于哈达铺红军长征旧址文物保护规划编制立项的批复（文物保函〔2012〕1103号）

甘肃省文物局：

你局《关于申请哈达铺红军长征旧址文物保护规划编制立项的报告》（甘文局发[2012]117号）收悉。经研究，我局批复如下：

**一、**同意所报规划编制立项。

**二、**在规划编制过程中应注意以下问题：

（一）根据哈达铺红军长征旧址的简介内容，进一步核定其作为全国重点文物保护单位的文物本体构成，新建和复建建筑不应列入本体构成。

（二）合理划定保护范围和建设控制地带，严格控制文物周边的建设项目，注意哈达铺上、下老街整体环境风貌的保护。

（三）统筹协调文物保护与红色旅游的关系，注意本规划与哈达铺城镇规划等相关规划的衔接。

**三、**请你局指导当地人民政府组织具有资质的规划编制单位，按照《国务院关于加强文化遗产保护的通知》、《全国重点文物保护单位保护规划编制要求》和《全国重点文物保护单位保护规划编制审批办法》的有关规定，做好哈达铺红军长征旧址文物保护规划的编制工作。

**四、**规划编制完成并经你局初审同意后，请将规划文本、图纸及相应的电子文档等上报我局审批。

此复。

国家文物局　　

二〇一二年五月八日
