# 中国保险监督管理委员会关于合众人寿保险股份有限公司修改章程的批复(2012)

## 中国保险监督管理委员会关于合众人寿保险股份有限公司修改章程的批复（保监发改〔2012〕354号）

合众人寿保险股份有限公司：

你公司关于修改章程的请示（合保发〔2012〕80号）收悉。经审查，核准你公司2012年1月5日股东大会决议对章程做的以下修改：

**一、**将第一条、第十条、第三十一条、第四十条中意大利欧利盛人寿股份有限公司（Eurizon Vita S.p.A.）修改为意大利联合圣保罗人寿股份有限公司（Intesa Sanpaolo Vita S.p.A.）。

**二、**第三条修改为：公司住所：中华人民共和国（“中国”）湖北省武汉市江汉区沿江一号MALL写字楼B座11F、12F。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

二○一二年三月二十九日
