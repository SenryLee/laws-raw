# 中国证券监督管理委员会关于核准中欧基金管理有限公司朱彦、黄桦基金行业高级管理人员任职资格的批复

## 中国证券监督管理委员会关于核准中欧基金管理有限公司朱彦、黄桦基金行业高级管理人员任职资格的批复（证监许可[2012]1231号）

中欧基金管理有限公司：

你公司报送的《中欧基金管理有限公司关于聘任朱彦先生担任公司分管市场副总经理的申请报告》（中欧人字[2012]第064 号）、《中欧基金管理有限公司关于聘任黄桦先生担任公司督察长的申请报告》（中欧人字[2012]第065号）及相关文件收悉。根据《证券投资基金法》、《证券投资基金行业高级管理人员任职管理办法》（证监会令第23号）等有关规定，经审核，现批复如下：

**一、**核准你公司朱彦（身份证号码：110105196807282134 ）、黄桦（身份证号码：310106196802042813 ）的基金行业高级管理人员任职资格。

**二、**我会对朱彦任你公司副总经理、黄桦任你公司督察长无异议。

中国证券监督管理委员会

2012年9月18日
