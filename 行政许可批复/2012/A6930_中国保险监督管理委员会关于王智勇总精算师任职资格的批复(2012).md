# 中国保险监督管理委员会关于王智勇总精算师任职资格的批复(2012)

## 中国保险监督管理委员会关于王智勇总精算师任职资格的批复（保监寿险〔2012〕1467号）

中邮人寿保险股份有限公司：

你公司《关于王智勇同志任职资格核准的请示》（中邮人寿〔2012〕218号）收悉。经审核，王智勇符合《保险公司总精算师管理办法》关于总精算师任职资格的有关要求，核准其总精算师的任职资格。

此复

中国保险监督管理委员会

2012年12月21日
