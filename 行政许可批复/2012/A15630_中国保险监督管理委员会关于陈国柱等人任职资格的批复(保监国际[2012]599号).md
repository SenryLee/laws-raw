# 中国保险监督管理委员会关于陈国柱等人任职资格的批复(保监国际[2012]599号)

## 中国保险监督管理委员会关于陈国柱等人任职资格的批复（保监国际〔2012〕599号）

新光海航人寿保险有限责任公司：

你公司关于陈国柱等人任职资格核准的申请材料（新光海航人〔2012〕24号）收悉。经审查，陈国柱、罗志中、马昕符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准陈国柱担任你公司总经理的任职资格，核准罗志中担任你公司副总经理的任职资格，核准马昕担任你公司总经理助理的任职资格。

此复

中国保险监督管理委员会

二○一二年五月二十二日
