# 国家文物局关于三坊七巷―朱紫坊建筑群之芙蓉园保护方案的批复

## 国家文物局关于三坊七巷-朱紫坊建筑群之芙蓉园保护方案的批复（文物保函〔2012〕1803号）

福建省文物局：

你局《关于三坊七巷--朱紫坊建筑群之芙蓉园保护方案的请示》（闽文物字[2012]138号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对方案提出如下修改意见：

（一）补充完善对木结构的稳定性评估内容，根据建筑的稳定情况合理确定残损等级。如现状稳定应以现状修缮为主。

（二）补充说明对残损木构件进行更换的控制标准，“腐朽一定程度要更换”的提法不科学，应尽量利用原构件，减少干预。

（三）进一步加强对原做法的勘察记录，补充门窗装修、雀替等补配和修复部分的设计依据。标注要替换的屏门、木栓、砖地面、条石地面、墙面等具体做法。

（四）未见木结构油饰做法，如有油饰应补充具体施工工艺和做法要求。

（五）进一步规范、完善图纸中建筑名称标注。图文注意对应一致。

请你局根据上述意见，组织相关单位进一步完善方案，经你局审核后实施。应注意该工程项目与总体保护工程的衔接。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局　　

二〇一二年六月一日
