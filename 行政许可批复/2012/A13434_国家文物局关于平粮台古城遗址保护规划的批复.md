# 国家文物局关于平粮台古城遗址保护规划的批复

## 国家文物局关于平粮台古城遗址保护规划的批复（文物保函〔2012〕1753号）

河南省文物局：

你局《关于再次报批周口平粮台古城遗址文物保护规划的请示》（豫文物〔2011〕437号）收悉。经研究，我局批复如下：

**一、**原则同意平粮台古城遗址保护规划和你局意见。

**二、**该规划尚需做以下必要的修改和完善：

（一）进一步开展现状勘察和已有考古资料的整理与研究工作，评估历史环境变迁以及区域水系与城址的关系，并注意平粮台古城遗址作为龙山时代城址的特性，分析城址规划特点和城内布局，明确保护对象和内容，为保护展示提供依据。

（二）进一步细化保护范围管理规定，减弱居民生产生活对遗址的不良影响；同时，应结合现有地形地貌及路网格局，进一步完善建设控制地带的划定，在区划图上闭合其南界，并进行分类管理，结合考古成果对周边村庄的发展提出指导性意见。应严格建设控制地带建筑檐口控高标准，根据遗址所在区域周边景观风貌控制的实际需求考虑建筑檐口高度。

（三）平粮台古城遗址的展示应根据考古工作的深度合理确定展示内容，以遗址格局展示为主，进一步优化遗址保护展示的思路，复原展示应慎重，充分评估其必要性和可行性。模拟展示则不必再建设保护棚。

（四）进一步调整功能布局，建议将博物馆和服务区设在遗址西南部待搬迁村庄的位置。同时，应补充评估遗址博物馆建设的必要性和可行性。若确有必要，应提出博物馆建筑面积、形体、色彩和高度等方面的控制要求，充分考虑建设和运营成本问题。

（五）进一步完善研究规划，对后续考古和研究工作提出要求。平粮台古城遗址的后续考古工作应重点做好考古资料整理和报告出版、遗址分布范围及城内布局确定以及各遗迹性质等，尤其要注意现有城址外尚有较大城垣遗迹的可能性。

（六）进一步规范游客容量的计算方法，科学核定游客容量。

（七）补充提出本规划与当地城乡建设规划相衔接的要求和具体内容。

（八）进一步规范文字和图纸，做到文图对应。

**三、**请你局指导地方人民政府组织规划编制单位和专业考古研究单位，按照上述意见，对规划进行必要修改和完善后，按照《国务院关于加强文化遗产保护的通知》的要求，报请河南省人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展计划以及城乡总体规划，积极组织有关部门逐步实施。规划由河南省人民政府批准公布后，请你局及时将规划公布文件及相关文本资料（含电子文本）报我局备案。

**四、**规划中涉及的文物保护与展示、遗址环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。

**五、**请你局和当地人民政府加强对平粮台古城遗址保护和管理工作的指导，加强专门管理机构建设，制订专项管理法规，并提出具体实施步骤和保障措施，妥善解决土地用途调整、村庄搬迁以及环境整治等问题，确保规划的顺利实施。

此复。

国家文物局
