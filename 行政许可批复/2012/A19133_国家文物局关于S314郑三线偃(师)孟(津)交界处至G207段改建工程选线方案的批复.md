# 国家文物局关于S314郑三线偃(师)孟(津)交界处至G207段改建工程选线方案的批复

## 国家文物局关于S314郑三线偃（师）孟（津）交界处至G207段改建工程选线方案的批复（文物保函〔2012〕335号）

河南省文物局：

你局《关于S314郑三线偃（师）孟（津）交界处至G207段改建工程拟穿全国重点文物保护单位邙山陵墓群的请示》（豫文物[2011]393号）收悉。经研究，我局批复如下：

**一、**原则同意你局关于S314郑三线偃（师）孟（津）交界处至G207段改建工程涉及邙山陵墓群建设控制地带选线方案的意见。

**二、**请你局组织专业考古研究单位在该工程拟建区域开展考古工作，所需经费由建设单位承担。如有重要考古发现，请组织研究提出处理意见和保护方案，并报我局批准后实施。请你局加强管理，确保考古工作质量和工地安全。

**三、**待考古工作结束后，请你局指导方案设计单位根据考古结果和文物保护的需要进一步修改完善工程选线方案，深化该工程对邙山陵墓群的文物影响评估，并由你局核准后实施。施工中应加强监管，确保文物安全。

**四、**请你局指导有关单位评估公路运营对文物保护和管理的影响，加强监测，制定相关措施，确保文物安全。

国家文物局　　

二〇一二年三月十五日
