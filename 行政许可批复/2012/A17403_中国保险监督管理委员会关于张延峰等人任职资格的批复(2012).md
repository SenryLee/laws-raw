# 中国保险监督管理委员会关于张延峰等人任职资格的批复(2012)

## 中国保险监督管理委员会关于张延峰等人任职资格的批复（保监国际〔2012〕435号）

中英人寿保险有限公司：

你公司关于张延峰等人任职资格核准的申请材料（中英人寿〔2012〕070、071号）收悉。经审查，张延峰、朱志刚符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准张延峰担任你公司厦门分公司副总经理（主持工作）的任职资格，核准朱志刚担任你公司厦门分公司副总经理的任职资格。

此复

中国保险监督管理委员会

二○一二年四月十六日
