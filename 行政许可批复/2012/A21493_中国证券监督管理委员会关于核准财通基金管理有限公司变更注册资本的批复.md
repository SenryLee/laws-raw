# 中国证券监督管理委员会关于核准财通基金管理有限公司变更注册资本的批复

## 中国证券监督管理委员会关于核准财通基金管理有限公司变更注册资本的批复（证监许可[2012]98号）

财通基金管理有限公司：

你公司报送的《财通基金管理有限公司关于增加注册资本及修改公司章程的申请报告 》（财通基金[2011]35号）及相关文件收悉。根据《公司法》、《证券投资基金法》和《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由1亿元人民币增加到2亿元。其中，财通证券有限责任公司增加出资4，000万元，杭州市工业资产经营投资集团有限公司增加出资3，000万元，浙江升华拜克生物股份有限公司增加出资3，000万元 。

你公司变更注册资本后，公司的股权结构为：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 财通证券有限责任公司 | 8，000 | 4 0 ％ |
| 2 | 杭州市工业资产经营投资集团有限公司 | 6， 000 | 3 0 ％ |
| 3 | 浙江升华拜克生物股份有限公司 | 6， 000 | 3 0 ％ |
|  | 合计 | 20，00 0 | 100％ |

**二、**核准你公司 所作的欲变更公司注册资本、股东出资相关的公司章程 修改。

**三、**你公司应当按规定及时办理工商变更登记等相关事宜，并到我会换领《基金管理资格证书 》。

中国证券监督管理委员会
