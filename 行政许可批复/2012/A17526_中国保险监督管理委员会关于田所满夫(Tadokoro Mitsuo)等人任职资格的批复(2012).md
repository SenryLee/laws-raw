# 中国保险监督管理委员会关于田所满夫(Tadokoro Mitsuo)等人任职资格的批复(2012)

## 中国保险监督管理委员会关于田所满夫（Tadokoro　Mitsuo）等人任职资格的批复（保监国际〔2012〕426号）

三井住友海上火灾保险（中国）有限公司：

你公司关于田所满夫等人任职资格核准的申请材料（三井住友保〔2012〕100、117号）收悉。经审查，田所满夫（Tadokoro Mitsuo）、尾之内藏夫（Onouchi Kurao）符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准上述两人担任你公司董事的任职资格。

此复

中国保险监督管理委员会

二○一二年四月十三日
