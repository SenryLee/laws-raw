# 中国保险监督管理委员会关于杨明生任职资格的批复(保监寿险[2012]644号)

## 中国保险监督管理委员会关于杨明生任职资格的批复（保监寿险〔2012〕644号）

中国人寿保险股份有限公司：

你公司《关于杨明生任职资格核准的请示》（国寿人险发〔2012〕220号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准杨明生担任你公司董事长的任职资格。

此复

中国保险监督管理委员会

二○一二年五月三十一日
