# 中国保险监督管理委员会关于刘振宇任职资格的批复(2012)

## 中国保险监督管理委员会关于刘振宇任职资格的批复（保监国际〔2012〕1285号）

恒安标准人寿保险有限公司：

你公司《恒安标准人寿关于申请董事任职资格核准的请示》（HASL司字〔2012〕213号）收悉。经研究，核准刘振宇担任恒安标准人寿保险有限公司董事的任职资格。

此复

中国保险监督管理委员会

2012年10月31日
