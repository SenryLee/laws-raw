# 中国保险监督管理委员会关于中融人寿保险股份有限公司修改章程的批复(保监发改[2012]770号)

## 中国保险监督管理委员会关于中融人寿保险股份有限公司修改章程的批复（保监发改〔2012〕770号）

中融人寿保险股份有限公司：

你公司关于修改章程的请示（中融保报〔2012〕66号）收悉。经审查，核准你公司2011年12月8日和2012年3月23日股东大会决议对章程做的如下修改：

**一、**第五条中公司住所修改为：北京市西城区丰盛胡同28号太平洋保险大厦17层。

**二、**对第二十三条的修改内容附后。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

二○一二年七月四日
