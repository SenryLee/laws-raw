# 中国证券监督管理委员会关于核准长安基金管理有限公司变更注册资本的批复

## 中国证券监督管理委员会关于核准长安基金管理有限公司变更注册资本的批复（证监许可[2012]1391号）

长安基金管理有限公司：

你公司报送的《关于新增股东、增加注册资本及修改公司章程的申请报告》（长安基金字[2012]55号）及相关文件收悉。根据《公司法》、《证券投资基金法》和《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由10000万元人民币增加到20000万元。其中，长安国际信托股份有限公司增加出资3100万元， 上海美特斯邦威服饰股份有限公司 增加出资3300万元，上海磐石投资有限公司认购出资3600万元 。

你公司变更注册资本后，公司的股权结构为：

人民币　万元

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 长安国际信托股份有限公司 | 8000 | 4 0 ％ |
| 2 | 上海美特斯邦威服饰股份有限公司 | 6600 | 33 ％ |
| 3 | 上海磐石投资有限公司 | 3600 | 1 8 ％ |
| 4 | 兵器装备集团财务有限责任公司 | 1800 | 9 ％ |
|  | 合计 | 20000 | 100％ |

**二、**核准你公司所作的与变更公司注册资本、股东出资相关的公司章程修改。

**三、**你公司应当按规定及时办理工商变更登记等相关事宜，并到我会换领《基金管理资格证书》。

中国证券监督管理委员会

二○一二年十月二十五日
