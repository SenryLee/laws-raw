# 国家文物局关于热瓦克佛寺遗址保护规划的批复

## 国家文物局关于热瓦克佛寺遗址保护规划的批复（文物保函〔2012〕1752号）

新疆维吾尔自治区文物局：

你局《关于报送〈新疆维吾尔自治区洛浦县热瓦克佛寺遗址文物保护规划〉的请示》（新文物项办发〔2011〕26号）收悉。经研究，我局批复如下：

**一、**原则同意《热瓦克佛寺遗址保护规划》和你局意见。

**二、**该规划尚需进行以下必要的修改和完善：

（一）应加强对以往考古工作成果的研究，在此基础上进一步明确保护对象，调整、完善遗址真实性和完整性评估的角度和内容，以热瓦克佛寺遗址和周边环境为主继续深化遗址价值评估和现状评估，力求科学、准确、客观。

（二）应根据考古研究成果、现状评估结论、遗址整体保护的实际需要，进一步调整保护范围与建设控制地带。建议在考古调查的基础上，依据地形地貌特征和文物分布现状划定保护区划的具体边界，增强可操作性。同时，应针对遗址保护管理需要，提出科学、合理的保护区划管理规定。

（三）应科学评估环境变化对遗址本体的影响，深化病害因素分析，在此基础上明确本体保护措施的具体内容。应提出保护加固、场地排水、安全防范、日常维护等措施的总体策略和要求，尽量减少对遗址本体和周边环境的人为干预和影响。

（四）应结合遗址所处区位、环境和水资源条件，以及遗址保护需要，统筹考虑遗址展示利用方式和强度，合理测算游客量，明确游客管理、控制的具体措施。进一步论证修建院墙东南廊架、佛塔保护建筑等措施的必要性和可行性，补充相关文物影响评估报告，并提出管理用房的功能、高度、外形等具体建设控制要求。不同意佛寺遗址本体覆罩保护的设计思路。

（五）应结合遗址保护展示的需要提出考古工作建议。考古工作规划应加强已有考古资料的整理和研究，在此基础上进一步开展全面、系统的考古工作，明确热瓦克佛寺遗址的范围、规模与布局，为制订保护方案提供科学依据。考古工作规划应由具有专业资质的考古研究单位另行制定，并按程序报批。

（六）进一步规范文字、图纸。遗址保护区划规划图应注明遗迹分布状况、地形地貌、交通线路，以及与周边村镇的关系等。

**三、**请你局指导地方人民政府，组织规划编制单位和专业考古研究单位，按照上述意见，对规划进行必要的修改和完善后，按照《国务院关于加强文化遗产保护的通知》的要求，报请自治区人民政府公布，并督促地方人民政府将其纳入当地经济和社会发展计划以及城乡建设发展规划，积极组织有关部门逐步实施。

**四、**本规划由新疆维吾尔自治区人民政府批准公布后，请你局及时将规划公布文件及相关文本资料（含电子文本）报我局备案。

**五、**规划中的文物保护与展示、环境整治、相关基础设施建设等项目，实施前应制定具体方案并按程序报批。涉及考古发掘项目的应按程序申请考古发掘申请书。

**六、**请你局和当地人民政府加强对热瓦克佛寺遗址保护和管理工作的指导，加强专门管理机构建设，制订专项管理法规，并提出具体实施措施、步骤和保障措施，妥善解决土地用途调整和环境治理等问题，确保规划顺利实施。

此复。

国家文物局
