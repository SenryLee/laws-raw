# 中国保险监督管理委员会关于石兴任职资格的批复(2012)

## 中国保险监督管理委员会关于石兴任职资格的批复（保监产险〔2012〕470号）

中国大地财产保险股份有限公司：

你公司《关于审核石兴任职资格的请示》（大地财保发〔2012〕77号）收悉。经审核，石兴符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准其担任你公司副总经理的任职资格。

此复

中国保险监督管理委员会

二○一二年四月二十五日
