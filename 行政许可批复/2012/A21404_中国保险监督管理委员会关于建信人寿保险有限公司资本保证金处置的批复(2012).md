# 中国保险监督管理委员会关于建信人寿保险有限公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于建信人寿保险有限公司资本保证金处置的批复（保监财会〔2012〕77号）

建信人寿保险有限公司：

你公司《关于资本保证金存款处置的请示》（建信人寿总报〔2012〕12号）收悉。经研究，同意你公司变更存放于中国工商银行上海证券大厦支行的1500万元人民币资本保证金存款的性质，该存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保险监督管理委员会

二〇一二年一月二十九日
