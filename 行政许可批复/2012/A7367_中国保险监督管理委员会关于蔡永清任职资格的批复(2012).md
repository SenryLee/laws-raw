# 中国保险监督管理委员会关于蔡永清任职资格的批复(2012)

## 中国保险监督管理委员会关于蔡永清任职资格的批复（保监国际〔2012〕1416号）

美国友邦保险有限公司江苏分公司：

你公司《美国友邦保险有限公司江苏分公司关于蔡永清先生高级管理人员任职资格核准的请示》（友苏发2012－266号）收悉。经审查，蔡永清符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准蔡永清担任美国友邦保险有限公司江苏分公司副总经理的任职资格。

此复

中国保险监督管理委员会

2012年12月12日
