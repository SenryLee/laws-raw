# 中国保险监督管理委员会关于泰康人寿保险股份有限公司变更注册资本的批复

## 中国保险监督管理委员会关于泰康人寿保险股份有限公司变更注册资本的批复（保监发改〔2012〕1421号）

泰康人寿保险股份有限公司：

你公司《关于增发股份并增加注册资本的请示》（泰康董发〔2012〕第044号）及相关补充材料收悉。经审核，现批复如下：

**一、**同意你公司注册资本变更为2，852，197，070元人民币（股权结构见附件）。

**二、**请你公司对公司章程作相应修改，并按照有关规定办理变更手续。

附件：泰康人寿保险股份有限公司股权结构表（略）

中国保险监督管理委员会

2012年12月12日
