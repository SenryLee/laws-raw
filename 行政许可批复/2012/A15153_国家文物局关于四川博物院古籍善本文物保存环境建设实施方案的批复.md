# 国家文物局关于四川博物院古籍善本文物保存环境建设实施方案的批复

## 国家文物局关于四川博物院古籍善本文物保存环境建设实施方案的批复（文物博函〔2012〕1255号）

四川省文物管理局：

《四川省文物管理局关于上报＜四川博物院古籍善本文物保存环境建设实施方案＞的请示》（川文物博[2012]30号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**请你局组织相关单位对古籍善本文物保存环境实施有效的监测和调控，防止或减缓环境因素对文物的破坏。

国家文物局　　　

二〇一二年五月三十一日
