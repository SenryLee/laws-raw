# 国家文物局关于三游洞摩崖监测工作方案的批复

## 国家文物局关于三游洞摩崖监测工作方案的批复（文物保函〔2012〕1333号）

湖北省文物局：

你局《关于申报三游洞摩崖监测工作方案的请示》（鄂文物发[2012]77号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出如下完善意见：

（一）建议增加水质监测内容，对降雨、地下水、岩体表面渗水、凝结水的水质进行长期监测。

（二）加强对监测结果的分析评估工作，及时形成监测报告，为今后保护工程的实施提供有效依据。

请你局根据上述意见，组织相关单位进一步完善监测方案，经你局核准后实施。监测工作中请加强监督、管理，确保文物安全。

此复。

国家文物局　　

二〇一二年五月二日
