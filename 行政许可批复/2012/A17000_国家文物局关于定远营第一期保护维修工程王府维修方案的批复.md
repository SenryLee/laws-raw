# 国家文物局关于定远营第一期保护维修工程王府维修方案的批复

内蒙古自治区文物局：

你局《关于上报定远营第一期保护维修工程王府维修方案的请示》（内文物发[2011]189号）收悉。经研究，我局批复如下：

**一、**原则同意所报维修方案。

**二、**对该方案提出以下修改意见：

（一）在设计说明中，应补充维修性质、保护原则、设计依据等内容。

（二）在现状勘察中补充对墙体原工艺做法的描述，再行确定墙体具体的维修方法。

（三）补充大木构架的现状勘察及残损评估，并提出相应的保护措施。

（四）进一步核对设计说明，修改完善图纸，使文字说明和图纸相一致。如：屋面护板灰、泥背尺寸应与图纸标注相一致；在总平面图补充东路寝宫的位置、指北针；实测图中建筑构件应按照比例正确绘制等。

（五）定远营王府彩画修复应单独编制方案，按程序另行报批。

请你局组织设计单位按照上述意见补充完善方案，由你局核准后实施。施工中请加强监管，确保工程质量和文物安全。

此复。

国家文物局　　　

二〇一二年四月二十四日
