# 中国保险监督管理委员会关于生命保险资产管理有限公司修改章程的批复

## 中国保险监督管理委员会关于生命保险资产管理有限公司修改章程的批复（保监发改〔2012〕615号）

生命保险资产管理有限公司：

你公司关于修改章程的请示（生保资发〔2012〕58号）收悉。经审查，核准你公司2012年4月23日股东会决议对章程做出的如下修改：

**一、**第一条修改为：生命保险资产管理有限公司（以下简称“本公司”或“公司”）是按照《中华人民共和国公司法》（以下简称《公司法》）、《中华人民共和国保险法》（以下简称《保险法》）、《保险资产管理公司管理暂行规定》和国家其他有关法律法规，经中国保险监督管理委员会（以下简称“中国保监会”）保监发改〔2011〕1101号文批准开业，并经工商行政管理机关登记于2011年7月15日成立的有限责任公司。

**二、**第十二条修改为：公司股东构成、各股东出资方式、出资额及出资比例如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 股东名称 | 出资方式 | 出资额（万元） | 出资比例 |
| 生命人寿保险股份有限公司 | 货币 | 9900 | 99% |
| 深圳市富德金融投资控股有限公司 | 货币 | 100 | 1% |
| 合 计 | | 10，000 | 100％ |

**三、**第三十二条修改为：公司召开股东会会议，公司股东、董事会、监事会有权以书面形式向股东会提出提案。

有提案权的机构可以在股东会会议召开十日前提出临时提案并书面提交召集人；召集人应当在收到提案后两日内发出股东会补充通知，并将该临时提案提交股东会审议。临时提案的内容应当属于股东会职权范围，并有明确议题和具体决议事项。

股东会原则上不得就会议通知和补充通知中未列明的提案作出决议。有提案权的机构因特殊事由提出但无法按规定发出股东会补充通知的临时提案，经公司全体股东一致同意，可以对该临时提案进行审议和表决。

**四、**第七十六条修改为：公司召开董事会会议，代表十分之一以上表决权的股东、监事会、董事会各专业委员会、董事长、总经理、三分之一以上董事、两名以上独立董事有权以书面形式向董事会提出提案。

具有提案权的机构或个人可以在董事会定期会议召开八日前提出临时提案并书面提交召集人；召集人应当在收到提案后两日内发出补充通知，并将该临时提案提交董事会会议审议。临时提案的内容应当属于董事会职权范围，并有明确议题和具体决议事项。

董事会会议原则上不得就会议通知及补充通知中未列明的提案作出决议。有提案权的机构或个人因特殊事由提出临时提案，经公司所有董事一致同意，可以对临时提案进行审议和表决。

**五、**第一百条修改为：监事会每年度至少召开一次会议，监事可以提议召开临时监事会会议。

公司召开监事会会议，代表十分之一以上表决权的股东、董事会、监事会主席、监事、总经理有权以书面形式向监事会提出提案。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

二○一二年五月二十三日
