# 文化部关于同意美国斯塔琳项目基金会演员到北京市演出的批复(2012)

## 文化部关于同意美国斯塔琳项目基金会演员到北京市演出的批复（文市函〔2012〕1177号）

北京市文化局：

京文外发〔2012〕514号请示收悉。

经研究，同意北京华艺文化艺术交流中心有限公司邀请美国斯塔琳项目基金会演员一行11人，于2012年7月10日至31日到北京市演出。

此复。

2012年7月10日
