# 国家文物局关于江西省2012年度考古报告出版工作计划的批复

## 国家文物局关于江西省2012年度考古报告出版工作计划的批复（文物保函〔2012〕1046号）

江西省文物局：

你局《关于申请江西＜万年仙人洞--吊桶环报告＞出版立项的请示》（赣文保字[2012]66号）、《关于申请＜江西纪年明墓＞出版经费的请示》（赣文保字[2012]68号）收悉。经研究，我局同意你局所报《万年仙人洞--吊桶环报告》、《江西纪年明墓》出版工作的计划。请你局审核有关考古报告前期整理出版经费的使用情况，并按照财政部、国家文物局《国家重点文物保护专项补助经费使用管理办法》（财教〔2001〕351号）文件的规定和我局的有关要求，另行申请上述两个考古报告的出版补助经费。

国家文物局　　

二〇一二年五月十八日
