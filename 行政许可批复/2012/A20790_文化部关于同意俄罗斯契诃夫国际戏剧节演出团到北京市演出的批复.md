# 文化部关于同意俄罗斯契诃夫国际戏剧节演出团到北京市演出的批复

## 文化部关于同意俄罗斯契诃夫国际戏剧节演出团到北京市演出的批复（文市函〔2012〕138号　）

北京市文化局：

你局京文外发〔2012〕64号请示收悉。

经研究，同意北京人民艺术剧院邀请俄罗斯契诃夫国际戏剧节演出团一行31人，于2012年3月13日至19日到北京市与该院合作演出莎士比亚戏剧《暴风雨》。

此复。

二○一二年二月十日
