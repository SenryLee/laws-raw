# 国家文物局关于龙门石窟研究保护中心建筑设计方案的批复

## 国家文物局关于龙门石窟研究保护中心建筑设计方案的批复（文物保函〔2012〕844号）

河南省文物局：

你局《关于报批洛阳龙门石窟研究保护中心建筑设计方案的请示》（豫文物〔2011〕361号）收悉。经研究，我局批复如下：

**一、**原则同意所报《龙门石窟研究保护中心建筑设计方案》。

**二、**该方案尚需进行以下必要的修改和完善：

（一）进一步缩减建筑体量、控制建筑高度。建议主体建筑以歇山顶代替庑殿顶，非主体建筑则可选择歇山、悬山、硬山等屋顶形制。

（二）鉴于该项目耗资巨大，建议主体建筑考虑以传统材料和工艺替代钢筋混凝土结构，以尽可能延长建筑使用寿命。屋面材料应尽可能选用布瓦或陶瓦，以降低工程造价。

（三）该建筑选址位于河畔低洼处，应补充地下水及伊河水、伊东渠水对该建筑的影响评估，并在相关设计中增加水患防御功能。

（四）进一步研究地下水位有关情况，论证设置地下库房的可行性，应充分考虑文物的存放安全，同时为文物的保存提供有利的环境空间。

**三、**请你局指导地方人民政府，组织设计单位根据上述意见对方案进行必要的修改和完善，经你局核准后实施。施工过程中应加强监管，确保工程质量。

此复。

国家文物局

二〇一二年四月十九日
