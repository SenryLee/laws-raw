# 中国保险监督管理委员会关于王超任职资格的批复(2012)

## 中国保险监督管理委员会关于王超任职资格的批复（保监国际〔2012〕1284号）

中航三星人寿保险有限公司：

你公司《关于中航三星人寿高级管理人员任职资格申报的请示》（中航三星人寿〔2012〕143号）收悉。经研究，核准王超担任中航三星人寿保险有限公司青岛分公司副总经理（主持工作）的任职资格。

此复

中国保险监督管理委员会
