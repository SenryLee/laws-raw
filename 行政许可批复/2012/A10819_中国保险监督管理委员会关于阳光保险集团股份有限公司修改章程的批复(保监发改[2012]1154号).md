# 中国保险监督管理委员会关于阳光保险集团股份有限公司修改章程的批复(保监发改[2012]1154号)

## 中国保险监督管理委员会关于阳光保险集团股份有限公司修改章程的批复（保监发改〔2012〕1154号）

阳光保险集团股份有限公司：

你公司关于修改章程的请示（阳光保险〔2012〕76号）收悉。经审查，核准你公司对章程进行的以下修改：

**一、**第六条修改为：公司注册资本为人民币六十六亿五千零五十九万元整。

**二、**对第二十条公司股权结构的修改详见附件。

请你公司依照有关规定办理变更事宜。

此复

附件：阳光保险集团股份有限公司股权结构表（略）

中国保险监督管理委员会

2012年9月19日
