# 国家文物局关于叶赫部城址保护规划编制立项的批复

## 国家文物局关于叶赫部城址保护规划编制立项的批复(文物保函〔2012〕1384号)

吉林省文物局：

你局《关于叶赫部城址保护规划立项的请示》（吉文物发〔2012〕35号）收悉。经研究，我局批复如下：

**一、**同意叶赫部城址保护规划编制立项和你局意见。

**二、**请你局指导地方人民政府组织规划编制单位联合专业考古研究机构，按照《国务院关于加强文化遗产保护的通知》、《全国重点文物保护单位保护规划编制审批办法》和《全国重点文物保护单位保护规划编制要求》的有关规定，开展叶赫部城址保护规划编制工作。应进一步加强前期调研，系统归纳、总结影响遗址本体和周边环境安全的主要因素，并根据工作量进一步核定经费预算。保护规划应注意文物本体与周边环境的整体保护，统筹考虑城址保护、农业生产和放牧、现代坟搬迁、村镇建设等问题，确保规划的科学性和可操作性。

**三、**请你局指导专业考古研究机构加强叶赫部城址考古调查和测绘工作，进一步搞清城址年代、分布范围、布局、内涵与变迁，注意城址使用过程，以及东城、西城和商间府城之间关系等问题，做好遗址价值和现状评估，为规划编制提供科学依据。

**四、**请你局督促地方人民政府加强叶赫部城址保护工作，做好专门管理机构建设、日常巡查和看护工作，妥善处理遗址保护与村镇建设发展之间的关系，确保文物安全。

此复。

国家文物局　　

二〇一二年六月八日
