# 中国保险监督管理委员会关于国泰人寿保险有限责任公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于国泰人寿保险有限责任公司资本保证金处置的批复（保监财会〔2012〕305号）

国泰人寿保险有限责任公司：

你公司《关于资本保证金处置的请示》（国泰人寿〔2012〕134号）收悉。经研究，同意你公司将存放于交通银行上海第一支行的600万美元资本保证金存款转存至华夏银行上海分行营业部。

请你公司在资本保证金存款存妥后10个工作日内，将《资本保证金存款协议》原件和背书后的存单复印件报我会。

此复

中国保险监督管理委员会

二○一二年三月十四日
