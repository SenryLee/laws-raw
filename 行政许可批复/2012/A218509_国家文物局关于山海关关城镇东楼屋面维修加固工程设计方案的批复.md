# 国家文物局关于山海关关城镇东楼屋面维修加固工程设计方案的批复

## 国家文物局关于山海关关城镇东楼屋面维修加固工程设计方案的批复（文物保函〔2012〕952号）

河北省文物局：

你局《关于呈报山海关关城镇东楼屋面维修加固工程设计方案的请示》（冀文物字[2012]4号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出以下修改意见：

（一）进一步深化镇东楼屋面保存现状分析，明确屋面瓦件破碎、漏水严重的原因，详细测绘屋面曲线，并对已往实施的保护措施进行评估，为完善有针对性的保护措施提供科学依据。

（二）明确瓦面残损量，尽可能保留原瓦件。对于确需替换的瓦件，应补充其形制、材料的具体要求，并采取适当方式进行标示说明。

（三）注意对木材防虫防腐药剂的正确使用，不宜使用不符合环保要求的CCA防腐剂。

（四）从镇东楼屋面安全角度考虑，不宜在檐口安装镁光灯，并补充避雷措施。

（五）进一步校核方案文本和图纸。

**三、**请你局组织相关单位，根据以上意见对方案进行深化、修改和完善，由你局核准后实施。请加强工程的监督管理，确保工程质量和文物安全。

此复。

国家文物局

二〇一二年四月十八日
