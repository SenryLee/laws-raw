# 中国保险监督管理委员会关于法国科法斯信用保险公司北京代表处更换首席代表的批复(2012)

## 中国保险监督管理委员会关于法国科法斯信用保险公司北京代表处更换首席代表的批复（保监国际〔2012〕806号）

法国科法斯信用保险公司：

你公司关于更换北京代表处首席代表的申请材料收悉。经研究，批准刘晓华接替宗思语担任法国科法斯信用保险公司北京代表处首席代表。

此复

中国保险监督管理委员会

二○一二年七月十六日
