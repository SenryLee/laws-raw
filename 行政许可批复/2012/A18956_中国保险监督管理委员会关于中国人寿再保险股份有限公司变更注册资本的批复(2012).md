# 中国保险监督管理委员会关于中国人寿再保险股份有限公司变更注册资本的批复(2012)

## 中国保险监督管理委员会关于中国人寿再保险股份有限公司变更注册资本的批复（保监发改〔2012〕310号）

中国人寿再保险股份有限公司：

你公司《关于中国人寿再保险股份有限公司增加注册资本金的申请》（中再寿险发〔2012〕18号）收悉。经审核，现批复如下：

**一、**同意你公司注册资本变更为5，720，000，000元人民币。其中，中国再保险（集团）股份有限公司持有5，719，986，445股，占比99.9998%；上海宜利实业发展有限公司持有13，555股，占比0.0002%。

**二、**请你公司对公司章程作相应修改，并按照有关规定办理变更手续。

中国保险监督管理委员会

二○一二年三月十九日
