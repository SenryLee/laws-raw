# 中国保监会关于中意人寿保险有限公司资本保证金处置的批复(保监财会[2012]1460号)

## 中国保监会关于中意人寿保险有限公司资本保证金处置的批复（保监财会〔2012〕1460号）

中意人寿保险有限公司：

你公司《中意人寿保险有限公司关于处置资本保证金存款的请示》（中意人寿〔2012〕168号）收悉。经审核，同意你公司变更存放于广东发展银行北京市知春路支行的830万美元资本保证金存款的性质，该存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保监会　

2012年12月20日
