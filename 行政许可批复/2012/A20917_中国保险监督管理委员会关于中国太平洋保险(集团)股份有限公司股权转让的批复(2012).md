# 中国保险监督管理委员会关于中国太平洋保险(集团)股份有限公司股权转让的批复(2012)

## 中国保险监督管理委员会关于中国太平洋保险（集团）股份有限公司股权转让的批复（保监发改〔2012〕112号）

中国太平洋保险（集团）股份有限公司：

你公司《关于中国太平洋保险（集团）股份有限公司股东单位上海海烟投资管理有限公司及上海烟草包装印刷有限公司股权转让的请示》（太保〔2011〕54号）收悉。经审核，现批复如下：

**一、**同意上海烟草包装印刷有限公司将持有的你公司47，124，930股股份转让给上海海烟投资管理有限公司。转让后，上海海烟投资管理有限公司持有你公司468，828，104股股份，上海烟草包装印刷有限公司不再持有你公司股份。

**二、**请你公司按照有关规定，办理相应变更手续。

中国保险监督管理委员会

二〇一二年二月八日
