# 中国保监会关于王建伟任职资格的批复

## 中国保监会关于王建伟任职资格的批复（保监产险〔2012〕1482号）

华安财产保险股份有限公司：

你公司《关于王建伟同志任职资格审查的请示》（华保报〔2012〕242号）收悉。经审核，王建伟符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准其担任你公司副总经理的任职资格。

此复

中国保监会　

2012年12月24日
