# 中国保险监督管理委员会关于长安责任保险股份有限公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于长安责任保险股份有限公司资本保证金处置的批复（保监财会〔2012〕197号）

长安责任保险股份有限公司：

你公司《关于资本保证金存款处置的请示》（长保发〔2012〕50号）收悉。经研究，批复如下：

**一、**同意你公司将存放于中国建设银行北京光明支行的3600万元人民币资本保证金存款转存至中国农业银行北京双井支行。

**二、**同意你公司将存放于中国建设银行北京天坛支行的3600万元人民币资本保证金存款转存至该行光明支行。

请你公司在资本保证金存款存妥后10个工作日内，将《资本保证金存款协议》原件和背书后的存单复印件报我会。

中国保险监督管理委员会

二〇一二年二月二十七日
