# 中国保险监督管理委员会关于新华资产管理股份有限公司修改章程的批复(2012)

## 中国保险监督管理委员会关于新华资产管理股份有限公司修改章程的批复（保监发改〔2012〕1242号）

新华资产管理股份有限公司：

你公司关于修改章程的请示及补充材料（新资发〔2011〕3号、12号、〔2012〕8号）收悉。经审查，核准你公司2011年4月15日、2011年10月11日和2012年5月21日股东大会决议对章程进行的修改。

请你公司依照有关规定办理变更事宜。

此复

附件：新华资产管理股份有限公司章程（略）
