# 文化部关于同意美国歌手费翔到安徽省演出的批复(文市函[2012]2435号)

## 文化部关于同意美国歌手费翔到安徽省演出的批复（文市函〔2012〕2435号）

安徽省文化厅：

皖文秘〔2012〕186号请示收悉。
