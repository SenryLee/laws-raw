# 中国保险监督管理委员会关于永安财产保险股份有限公司修改章程的批复(保监发改[2012]1237号)

## 中国保险监督管理委员会关于永安财产保险股份有限公司修改章程的批复（保监发改〔2012〕1237号）

永安财产保险股份有限公司：

你公司关于修改章程的请示（永保字〔2012〕295号）收悉。经审查，核准你公司2012年9月13日股东大会决议对章程附件股权结构表进行的修改。

请你公司依照有关规定办理变更事宜。

此复

附件：永安财产保险股份有限公司股份结构表（略）

中国保监会　

2012年10月19日
