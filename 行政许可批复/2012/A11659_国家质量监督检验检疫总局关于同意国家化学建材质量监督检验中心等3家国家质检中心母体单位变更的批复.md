# 国家质量监督检验检疫总局关于同意国家化学建材质量监督检验中心等3家国家质检中心母体单位变更的批复

## 国家质量监督检验检疫总局关于同意国家化学建材质量监督检验中心等3家国家质检中心母体单位变更的批复（2012年8月27日　国质检科函[2012]546号）

浙江省质检技术监督局：

《关于国家化学建材质量监督检验中心等国家质检中心母体单位名称变更的请示》（浙质[2012]24号）收悉。根据总局关于国家质检中心建设有关规定，经研究，同意将你局负责建设的国家化学建材质量监督检验中心、国家皮革质量监督检验中心（浙江）、国家电器安全质量监督检验中心（浙江）母体单位变更为浙江省质量检测科学研究院，并请你局按照有关规定向国家认监委办理相关变更手续。
