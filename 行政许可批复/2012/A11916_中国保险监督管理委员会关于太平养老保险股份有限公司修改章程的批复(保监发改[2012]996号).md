# 中国保险监督管理委员会关于太平养老保险股份有限公司修改章程的批复(保监发改[2012]996号)

## 中国保险监督管理委员会关于太平养老保险股份有限公司修改章程的批复（保监发改〔2012〕996号）

太平养老保险股份有限公司：

你公司关于修改章程的请示（太平养老〔2012〕106号）收悉。经审查，核准你公司2012年7月10日股东大会决议将章程第四条公司住所条款修改为：中国上海市浦东新区银城中路488号太平金融大厦25－26层，邮政编码：200120。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

2012年8月21日
