# 中国银行业监督管理委员会关于核准李光任职资格的批复

## 中国银行业监督管理委员会关于核准李光任职资格的批复（银监复[2012]728号）

中国农业发展银行：

你行《关于核准李光同志任职资格的个案申请》（农发银发〔2012〕192号）收悉。

根据《中资商业银行行政许可事项实施办法》等有关规定，现核准李光中国农业发展银行内部审计部总经理的任职资格。

此复。

2012年12月5日
