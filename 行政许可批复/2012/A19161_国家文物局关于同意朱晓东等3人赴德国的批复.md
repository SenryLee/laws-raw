# 国家文物局关于同意朱晓东等3人赴德国的批复

## 国家文物局关于同意朱晓东等3人赴德国的批复（文物办函〔2012〕289号）

中国文化遗产研究院、本局：办公室（外事联络司）：

你院《关于詹长法等三人赴德国柏林参加“丝路霓裳”中德合作项目第一次工作会议的请示》（文研外字[2012]19号）收悉。

经研究，同意我局办公室主任朱晓东、你院研究员詹长法、馆员王珊等3人于2012年4月22日至2012年4月28日，赴德国参加德国考古研究院举办的“丝路霓裳-中亚东部公元前十世纪至公元前后的服饰对话”项目全体成员单位第一次工作会议，在境外停留7天。上述人员的往返国际旅费及在德国期间食宿等费用均由德方承担。

请做好上述同志的出国政审和外事纪律教育工作。

国家文物局　　

二〇一二年三月十四日
