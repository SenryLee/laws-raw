# 中国保险监督管理委员会关于长城人寿保险股份有限公司股权转让的批复(2012)

## 中国保险监督管理委员会关于长城人寿保险股份有限公司股权转让的批复（保监发改〔2012〕833号）

长城人寿保险股份有限公司：

你公司《关于股东转让股权的请示》（长寿发〔2012〕60号）和《关于股东转让股权补充材料的请示》（长寿发〔2012〕86号）收悉。经审核，现批复如下：

**一、**同意南昌市政公用投资控股有限责任公司将所持有的你公司103，300，000股股份转让给北京金昊房地产开发有限公司。转让后，北京金昊房地产开发有限公司持有你公司271，153，846股股份，持股比例为17.37%，南昌市政公用投资控股有限责任公司不再持有你公司股份。

**二、**请你公司对公司章程作相应修改，并按照有关规定办理变更手续。

中国保险监督管理委员会

二○一二年七月十七日
