# 文化部关于同意英国阿库·汉姆舞蹈团到北京市演出的批复

## 文化部关于同意英国阿库·汉姆舞蹈团到北京市演出的批复（文市函〔2012〕186号　）

北京市文化局：

你局京文外发〔2012〕87号请示收悉。

经研究，同意北京云汉文化交流有限公司邀请英国阿库·汉姆舞蹈团一行12人，于2012年5月4日至23日到北京市等地演出。

此复。

二O一二年二月二十一日
