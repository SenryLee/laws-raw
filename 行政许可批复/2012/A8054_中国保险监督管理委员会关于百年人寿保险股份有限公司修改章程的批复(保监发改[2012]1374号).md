# 中国保险监督管理委员会关于百年人寿保险股份有限公司修改章程的批复(保监发改[2012]1374号)

## 中国保险监督管理委员会关于百年人寿保险股份有限公司修改章程的批复（保监发改〔2012〕1374号）

百年人寿保险股份有限公司：

你公司关于修改章程的请示（百保发〔2012〕244号）收悉。经审查，核准你公司2012年9月7日股东大会决议对章程做出的以下修改：

**一、**第二十七条修改为：除法律、行政法规另有规定的以外，公司的股份可以依法转让。变更出资人或者持有公司股份百分之五以上（含百分之五）的股东，应当报保监会批准。公司股份的转让，必须依照法律和保监会的相关规定进行。

**二、**第六十七条第二款修改为：董事会由十三名董事组成，其中股东董事九人，非股东董事四人，包括独立董事二人，执行董事二人。

请你公司依照有关规定办理变更事宜。

此复

中国保险监督管理委员会

2012年11月28日
