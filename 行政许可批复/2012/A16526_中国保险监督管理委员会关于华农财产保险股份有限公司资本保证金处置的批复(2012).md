# 中国保险监督管理委员会关于华农财产保险股份有限公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于华农财产保险股份有限公司资本保证金处置的批复（保监财会〔2012〕493号）

华农财产保险股份有限公司：

你公司《关于变更资本保证金存放银行的请示》（华农发〔2012〕38号）收悉。经研究，同意你公司将存放于中国民生银行总行营业部的5800万元人民币资本保证金存款中的4800万元人民币转存至中国农业银行北京西城区支行营业部。

请你公司在资本保证金存款存妥后10个工作日内，将《资本保证金存款协议》原件和背书后的存单复印件报我会。

此复

二○一二年五月三日
