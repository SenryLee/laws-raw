# 中国保险监督管理委员会关于泰康人寿保险股份有限公司股权转让的批复(2012)

## 中国保险监督管理委员会关于泰康人寿保险股份有限公司股权转让的批复（保监发改〔2012〕94号）

泰康人寿保险股份有限公司：

你公司《关于申请批准股东股权转让的请示》（泰康董发〔2011〕第067号）及相关补充材料收悉。经审核，现批复如下：

**一、**同意北京国际信托有限公司将所持有的你公司33，269，962股股份转让给中国嘉德国际拍卖有限公司，将30，000，000股股份转让给盈格兴业（北京）科技有限公司，中诚信托有限责任公司将所持有的你公司50，000，000股股份转让给尔富（北京）投资有限责任公司。转让后，中国嘉德国际拍卖有限公司持有你公司160，928，516股股份，占比18.8840%，尔富（北京）投资有限责任公司持有你公司50，000，000股股份，占比5.8672%，盈格兴业（北京）科技有限公司持有你公司30，000，000股股份，占比3.5203%，北京国际信托有限公司和中诚信托有限责任公司不再持有你公司股份。

**二、**请你公司对公司章程作相应修改，并按照有关规定办理变更手续。

中国保险监督管理委员会

二〇一二年二月六日
