# 中国保险监督管理委员会关于安邦人寿保险股份有限公司财务会计部门负责人的批复(2012)

## 中国保险监督管理委员会关于安邦人寿保险股份有限公司财务会计部门负责人的批复（保监财会〔2012〕487号）

安邦人寿保险股份有限公司：

你公司《关于对王琳财务会计部门负责人任职资格核准的请示》（安邦人寿发〔2012〕59号）收悉。经审查，同意王琳担任安邦人寿保险股份有限公司财务会计部门负责人。

此复

中国保险监督管理委员会
