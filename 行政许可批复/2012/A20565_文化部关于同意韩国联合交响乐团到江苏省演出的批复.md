# 文化部关于同意韩国联合交响乐团到江苏省演出的批复

## 文化部关于同意韩国联合交响乐团到江苏省演出的批复（文市函〔2012〕171号）

江苏省文化厅：

你厅苏文市（外）〔2012〕63号请示收悉。

经研究，同意江苏省演艺集团有限公司邀请韩国联合交响乐团一行91人，于2012年2月18日到江苏省南京市演出。

此复。

二O一二年二月十六日
