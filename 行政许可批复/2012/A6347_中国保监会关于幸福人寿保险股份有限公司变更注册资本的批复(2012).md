# 中国保监会关于幸福人寿保险股份有限公司变更注册资本的批复(2012)

## 中国保监会关于幸福人寿保险股份有限公司变更注册资本的批复（保监发改〔2012〕1518号）

幸福人寿保险股份有限公司：

你公司《关于增加注册资本金的请示》（幸福寿报〔2012〕176号）和《关于增加注册资本金请示的补充报告》（幸福寿报〔2012〕179号）收悉。经审核，现批复如下：

**一、**同意你公司注册资本变更为2，740，580，475元人民币（股权结构见附件）。

**二、**请你公司对公司章程作相应修改，并按照有关规定办理变更手续。

附件：幸福人寿保险股份有限公司股权结构表（略）

中国保监会　

2012年12月31日
