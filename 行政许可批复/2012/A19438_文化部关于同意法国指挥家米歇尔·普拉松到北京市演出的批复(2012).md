# 文化部关于同意法国指挥家米歇尔·普拉松到北京市演出的批复(2012)

## 文化部关于同意法国指挥家米歇尔·普拉松到北京市演出的批复（　文市函〔2012〕281号）

北京市文化局：

你局京文外发〔2012〕142号请示收悉。

经研究，同意中国交响乐团邀请法国指挥家米歇尔·普拉松于2012年3月12日至19日到北京市与该团合作演出。

此复。
