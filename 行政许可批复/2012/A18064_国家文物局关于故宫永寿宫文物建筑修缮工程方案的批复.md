# 国家文物局关于故宫永寿宫文物建筑修缮工程方案的批复

## 国家文物局关于故宫永寿宫文物建筑修缮工程方案的批复（文物保函〔2012〕1370号）

北京市文物局：

你局《关于故宫永寿宫文物建筑修缮工程方案的请示》（京文物 [2011]1026号）收悉。经研究，我局批复如下：

**一、**原则同意所报方案。

**二、**对该方案提出以下修改意见：

（一）应严格控制后殿明间等屋面局部揭瓦的范围，以部分屋面或檐头挑修为主，并应对挑修时原有灰背与新做灰背的技术处理做出明确说明，尽可能减少扰动范围。

（二）院内排水应明排与暗排相结合，找准明排出口，院内墁地时应注意排水的坡度及方向；对西墙的暗沟进行疏浚，确保排水畅通。

（三）补充对琉璃瓦件更换、修补的具体技术要求，尽可能留用原瓦件。补充望板刷桐油做法和麻刀灰比例的依据。

（四）进一步核准修缮措施表述和做法标注，前院东配殿前外檐下碱不应涂刷青灰色防水涂料，后院东、西配殿的下碱做法应明确。

（五）关于油饰彩画部分

1. 永寿宫建筑彩画保护应遵循“最小干预”的原则，正殿、前后院东西配殿椽望如无需更换，则应对彩画进行原状保护。

2. 上架斗拱、大木彩画及陡匾应做原状保护，仅作必要的除尘加固。因荞麦面除尘的方法易对彩画造成生物侵害，建议尽量使用其他物理除尘方法。

3. 补充油饰、彩画设计图纸。

4. 应做好施工前后及施工过程中的档案记录。

**三、**请你局组织有关单位，根据上述意见对方案进行修改、完善，并据此编制施工图设计，经你局核准后实施。施工中请加强监督和管理，确保工程质量和文物、人员安全。

此复。

国家文物局　　

二〇一二年四月五日
