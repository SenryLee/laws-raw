# 中国证券监督管理委员会关于核准天弘基金管理有限公司变更注册资本及修改章程的批复

## 中国证券监督管理委员会关于核准天弘基金管理有限公司变更注册资本及修改章程的批复（证监许可[2012]196号）

天弘基金管理有限公司：

你公司报送的《 关于同比例增加公司注册资本及修改公司章程的申请报告 》（天弘发字[2011]150 号）及相关文件收悉。根据《公司法》、《证券投资基金法》和《证券投资基金管理公司管理办法》（证监会令第22号）等有关规定，经审核，现批复如下：

**一、**核准你公司将注册资本由1亿元人民币增加到1.8 亿元。其中，天津信托有限责任公司增加出资3，840 万元，内蒙古君正能源化工股份有限公司增加出资2 ，880万元，芜湖高新投资有限公司增加出资1，280万元。

你公司变更注册资本后，公司的股权结构为：

| --- | --- | --- | --- |
| 序号 | 股 东 名 称 | 出资额 | 出资比例 |
| 1 | 天津信托有限责任公司 | 8，640 | 4 8 ％ |
| 2 | 内蒙古君正能源化工股份有限公司 | 6，48 0 | 36 ％ |
| 3 | 芜湖高新投资有限公司 | 2，88 0 | 16 ％ |
|  | 合计 | 18 ，00 0 | 100％ |

**二、**核准你公司对公司章程所作的修改。

**三、**你公司应当按规定及时办理工商变更登记等相关事宜，并到我会换领《基金管理资格证书 》， 完善公司治理结构，维护公司及基金份额持有人的合法权益 。

中国证券监督管理委员会
