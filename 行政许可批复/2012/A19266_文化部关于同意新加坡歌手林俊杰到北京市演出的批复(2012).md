# 文化部关于同意新加坡歌手林俊杰到北京市演出的批复(2012)

## 文化部关于同意新加坡歌手林俊杰到北京市演出的批复（文市函〔2012〕295号）

北京市文化局：

京文外发〔2012〕158号请示收悉。

经研究，同意上海唱游名门音乐演出制作有限公司邀请新加坡歌手林俊杰，于2012年3月18日至22日到北京市演出。

此复。

二O一二年三月十三日
