# 中国保险监督管理委员会关于中国大地财产保险股份有限公司变更注册资本的批复(2012)

## 中国保险监督管理委员会关于中国大地财产保险股份有限公司变更注册资本的批复（保监发改〔2012〕762号）

中国大地财产保险股份有限公司：

你公司《关于增加注册资本金的请示》（大地财保发〔2012〕241号）收悉。经审核，同意你公司注册资本变更为6，429，984，100元人民币。增资后，你公司股东持股数量和持股比例如下：（1）中国再保险（集团）股份有限公司持有5，932，279，721股，占总股本的92.26%；（2）宁波市电力开发公司持有299，063，382股，占总股本的4.65%；（3）大唐国际发电股份有限公司持有168，738，746股，占总股本的2.62%；（4）北京松联科技有限公司持有29，902，251股，占总股本的0.47%。

请你公司按照有关规定办理变更手续。

此复

中国保险监督管理委员会

二○一二年六月三十日
