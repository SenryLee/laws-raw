# 中国证券监督管理委员会关于核准设立广州广证恒生证券投资咨询有限公司的批复

## 中国证券监督管理委员会关于核准设立广州广证恒生证券投资咨询有限公司的批复（证监许可〔2012〕306号）

广州证券有限责任公司：

你公司报送的《合资证券投资咨询公司设立申请表》及相关文件收悉。根据《证券法》、《公司法》、《证券、期货投资咨询管理暂行办法》（证委发〔1997〕96号）、《外资参股证券公司设立规则》（证监会令第52号）、《证券公司设立子公司试行规定》（证监机构字〔2007〕345号）、《证券公司业务范围审批暂行规定》（证监会公告〔2008〕42号）和《〈内地与香港关于建立更紧密经贸关系的安排〉补充协议六》等有关规定，经审核，现批复如下：

**一、**核准你公司与恒生证券有限公司（Hang Seng Securities Limited，以下简称恒生证券）共同出资设立广州广证恒生证券投资咨询有限公司（以下简称广证恒生咨询公司），注册地在广东省广州市。在取得我会颁发的证券投资咨询业务资格证书前，不得以广证恒生咨询公司名义对外开展业务。

**二、**核准广证恒生咨询公司注册资本为44，680，000元人民币。各股东单位出资额和出资比例：

|  |  |  |  |
| --- | --- | --- | --- |
|  | 股东名称 | 出资额（元） | 出资比例 |
| （一） | 广州证券有限责任公司 | 29，935，600 | 67% |
| （二） | 恒生证券有限公司 | 14，744，400 | 33% |

上述出资中，你公司的出资为人民币现金，恒生证券的出资为等值美元现金。

**三、**广证恒生咨询公司可以经营下列业务：

证券投资咨询业务（仅限于发布证券研究报告）。

**四、**核准《广州广证恒生证券投资咨询有限公司合资经营合同》，我会对广证恒生咨询公司章程草案无异议。广证恒生咨询公司设立后，应当将股东会表决通过的公司章程报我会核准。

**五、**你公司与恒生证券应当按照《公司法》、《证券法》、《证券、期货投资咨询管理暂行办法》、《外资参股证券公司设立规则》、《关于实施〈外资参股证券公司设立规则〉有关问题的通知》（证监发〔2002〕86号）等法律、行政法规和有关规定的要求，在批复下发之日起30日内向商务部申领《外商投资企业批准证书》；在本批复下发之日起6个月内完成广证恒生咨询公司组建工作，足额缴付出资，选举董事、监事，聘任高级管理人员，并向工商行政管理机关申请设立登记，领取营业执照。

**六、**广证恒生咨询公司在组建完成，具有符合法律、行政法规及我会规定的高级管理人员和从业人员，并且符合公司开业要求后，可以按照《证券、期货投资咨询管理暂行办法》、《外资参股证券公司设立规则》及我会有关规定，向我会申请证券投资咨询业务资格证书。

**七、**核准你公司在广证恒生咨询公司取得证券投资咨询业务资格证书后，变更业务范围，将业务范围中“证券投资咨询业务”变更为“证券投资咨询业务（仅限于证券投资顾问业务）”。你公司应当根据本批复依法向工商行政管理机关申请变更登记，并向我会申请换发经营证券业务许可证。

你公司应当认真落实发布证券研究报告了结计划，做好清理、移交工作，平稳处理现有客户，确保客户合法权益不受损害，妥善安置员工，维护社会稳定。

**八、**广证恒生咨询公司组建中遇到重大问题，应当及时报告我会。

二○一二年三月九日
