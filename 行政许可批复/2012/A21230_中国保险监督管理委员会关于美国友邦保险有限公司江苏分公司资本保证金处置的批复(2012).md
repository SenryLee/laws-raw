# 中国保险监督管理委员会关于美国友邦保险有限公司江苏分公司资本保证金处置的批复(2012)

## 中国保险监督管理委员会关于美国友邦保险有限公司江苏分公司资本保证金处置的批复（保监财会〔2012〕93号）

美国友邦保险有限公司江苏分公司：

你公司《关于资本保证金处置的请示》（友苏发2012－029号）收悉。经研究，同意你公司变更存放于中国工商银行苏州分行营业部的41.53358万美元和18.03535万美元资本保证金存款的性质，上述两笔存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保险监督管理委员会

二〇一二年二月一日
