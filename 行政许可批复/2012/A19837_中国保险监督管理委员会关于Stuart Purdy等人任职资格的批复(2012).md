# 中国保险监督管理委员会关于Stuart Purdy等人任职资格的批复(2012)

## 中国保险监督管理委员会关于Stuart　Purdy等人任职资格的批复（保监国际〔2012〕223号）

太阳联合保险（中国）有限公司：

你公司《关于拟任董事会董事任职资格的请示》（太阳联合〔2012〕027号）收悉。经审查，Stuart Purdy、张嘉麟、Elliot Hill、Alfredo Alonso符合《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，核准Stuart Purdy担任你公司董事长的任职资格，核准张嘉麟、Elliot Hill、Alfredo Alonso担任你公司董事的任职资格。

此复

中国保险监督管理委员会

二○一二年三月二日
