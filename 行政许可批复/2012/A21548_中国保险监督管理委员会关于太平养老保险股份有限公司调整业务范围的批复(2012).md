# 中国保险监督管理委员会关于太平养老保险股份有限公司调整业务范围的批复(2012)

## 中国保险监督管理委员会关于太平养老保险股份有限公司调整业务范围的批复（保监发改〔2012〕76号）

太平养老保险股份有限公司：

你公司《关于经营长期健康保险业务的请示》（太平养老〔2011〕80号）及相关补充材料收悉。经研究，同意你公司在业务范围中增加“团体长期健康保险业务”。你公司可自2012年1月1日起，销售团体长期健康险相关产品。请你公司按照有关规定办理章程等变更手续，做好续期及相关服务，切实保护投保人和被保险人的利益。

此复

中国保险监督管理委员会

二〇一二年一月二十日
