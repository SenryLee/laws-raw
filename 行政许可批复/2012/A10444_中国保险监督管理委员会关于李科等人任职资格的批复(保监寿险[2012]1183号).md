# 中国保险监督管理委员会关于李科等人任职资格的批复(保监寿险[2012]1183号)

## 中国保险监督管理委员会关于李科等人任职资格的批复（保监寿险〔2012〕1183号）

阳光人寿保险股份有限公司：

你公司关于李科等人任职资格核准的请示（阳光人寿〔2012〕247号）收悉。根据《保险公司董事、监事和高级管理人员任职资格管理规定》的有关要求，经审查，核准李科、彭吉海、潘宏源担任你公司董事的任职资格。

此复

中国保险监督管理委员会

2012年9月28日
