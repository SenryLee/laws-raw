# 中国保险监督管理委员会关于中英人寿保险有限公司资本保证金处置的批复(保监财会[2012]339号)

## 中国保险监督管理委员会关于中英人寿保险有限公司资本保证金处置的批复（保监财会[2012]339号）

中英人寿保险有限公司：

你公司《关于中英人寿保险有限公司处置资本保证金存款的请示》（中英人寿〔2012〕047号）收悉。经研究，同意你公司变更存放于中国工商银行广州环城支行的四笔合计1272万美元资本保证金存款的性质，该存款不再作为资本保证金存款，可由你公司依法处置。

此复

中国保险监督管理委员会

二○一二年三月二十七日
