# 中国证券监督管理委员会关于核准设立摩根士丹利华鑫证券有限责任公司的批复

## 中国证券监督管理委员会关于核准设立摩根士丹利华鑫证券有限责任公司的批复（证监许可〔2010〕1947号）

华鑫证券有限责任公司：

你公司报送的《设立外资参股证券公司申请表》及相关文件收悉。根据《证券法》、《公司法》、《外资参股证券公司设立规则》（证监会令第52号）、《证券公司设立子公司试行规定》（证监机构字〔2007〕345号）、《证券公司业务范围审批暂行规定》（证监会公告〔2008〕42号）等有关规定，经审核，现批复如下：

**一、**核准你公司与Morgan Stanley Asia Limited（以下简称摩根士丹利亚洲）共同出资设立摩根士丹利华鑫证券有限责任公司（以下简称摩根士丹利华鑫证券），注册地在上海市。在取得我会颁发的经营证券业务许可证前，不得以摩根士丹利华鑫证券名义对外开展业务。

**二、**核准摩根士丹利华鑫证券注册资本为1，020，000，000元人民币。核准以下单位的股东资格、出资额和出资比例：

|  |  |  |  |
| --- | --- | --- | --- |
|  | 股东名称 | 出资额（元） | 出资比例 |
| （一） | 华鑫证券有限责任公司 | 680，000，000 | 66.7% |
| （二） | Morgan Stanley Asia Limited | 340，000，000 | 33.3% |

上述出资中，你公司的出资为人民币现金，摩根士丹利亚洲的出资为等值美元或者其他可自由兑换货币现金。

**三、**摩根士丹利华鑫证券可以经营下列业务：

（一）股票（包括人民币普通股、外资股）和债券（包括政府债券、公司债券）的承销与保荐；

（二）债券（包括政府债券、公司债券）的自营。

**四、**核准《Morgan Stanley Asia Limited和华鑫证券有限责任公司关于摩根士丹利华鑫证券有限责任公司的股东协议》，我会对摩根士丹利华鑫证券章程草案无异议。摩根士丹利华鑫证券设立后，应当将股东会表决通过的公司章程报我会核准。

**五、**你公司与摩根士丹利亚洲应当按照《公司法》、《证券法》、《证券公司监督管理条例》、《外资参股证券公司设立规则》、《关于实施〈外资参股证券公司设立规则〉有关问题的通知》（证监发〔2002〕86号）等法律、行政法规和有关规定的要求，在批复下发之日起30日内向商务部申领《外商投资企业批准证书》；在本批复下发之日起6个月内完成摩根士丹利华鑫证券组建工作，足额缴付出资，选举董事、监事，聘任高级管理人员，并向工商行政管理机关申请设立登记，领取营业执照。

**六、**摩根士丹利华鑫证券组建完成，具有符合法律、行政法规及我会规定的高级管理人员和从业人员，并且符合公司开业要求后，可以按照《外资参股证券公司设立规则》及我会有关规定，向我会申请经营证券业务许可证。

**七、**核准你公司在摩根士丹利华鑫证券取得经营证券业务许可证后，变更业务范围，减少证券承销与保荐业务和债券自营业务。你公司应当根据本批复依法向工商行政管理机关申请变更登记，并向我会申请换发经营证券业务许可证。

你公司应当认真落实证券承销与保荐业务和债券自营业务了结计划安排和平稳处理现有客户相关事项方案，做好证券承销与保荐业务和债券自营业务清理和移交工作，平稳处理现有客户相关事项，确保客户合法权益不受损害，妥善安置员工，维护社会稳定。

**八、**摩根士丹利华鑫证券组建中遇到重大问题，应当及时报告我会。

二○一○年十二月三十一日
