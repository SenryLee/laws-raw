# 法律法规原始数据库

本库保存法律法规和规范性文件的原始 Markdown 文本。一篇文件对应一份文本，正文按导出时的原样存放，没有做条文拆分、重复合并或效力整理。

## 文件怎么放

一级目录沿用导出时的分类，多数是效力等级或文件类型，例如「法律」「行政法规」「部门规范性文件」。分类下面按年份建文件夹，年份无法识别的放在 `unknown`。

文件名格式为 `编号_标题.md`。编号是导出时的文献编号，例如 `A193481`。

## 每篇里有什么

文件开头是属性，后面是标题和正文。常见字段如下。

| 字段 | 含义 |
| --- | --- |
| 标题 | 文件标题 |
| 文号 | 发文字号，不少文件没有 |
| 制定机关 | 公布或制定该文件的机关 |
| 效力等级 | 导出时标注的效力等级 |
| 时效性 | 导出时标注的效力状态，如现行有效、部分失效 |
| 主题分类 | 主题，部分文件没有 |
| 公布日期 | 公布日期 |
| 施行日期 | 施行日期 |
| 条数 | 导出时统计的条文数 |
| 完整性 | 全文或节选 |

这些字段不是每篇都齐。标题、条数、完整性基本都有；文号和主题分类缺得比较多。

## 使用时注意

交叉分类保持原目录名，例如「办法、规定」「行政法规、条例」，没有并回单一分类。

目录「部门规范性文件、党内规范性文件、国务院规」的名称在导出时被截断，库内仍用这个名字。

修改决定、旧文本和后来的文本可能同时在库里。时效性只表示导出当时的标注，不代表查阅时点的现行状态。

查找时先按分类和年份进入目录，再用标题、制定机关和公布日期核对。
