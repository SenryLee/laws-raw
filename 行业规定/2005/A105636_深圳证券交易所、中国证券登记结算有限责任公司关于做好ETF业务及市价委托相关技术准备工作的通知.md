# 深圳证券交易所、中国证券登记结算有限责任公司关于做好ETF业务及市价委托相关技术准备工作的通知

各会员单位：

为配合交易型开放式指数基金（ETF）业务及市价委托交易制度创新的推出，深交所和中国结算深圳分公司对《深圳证券交易所数据接口规范》进行了调整。现将有关事项公告如下：

**一、**交易数据接口规范相关调整

在证券信息库SJSXX.DBF中增加了ETF和非交易类开放式基金的证券级别定义，同时修订委托库SJSWT.DBF和回报库SJSHB.DBF，增加ETF申购、赎回的报盘及回报类业务数据，增加五种市价委托的报盘类业务数据及相应撤单回报数据，增加部分撤单原因定义，增加在大宗交易成交回报后的全天市场闭市标志，相应的接口规范定义简要说明如下：

1、证券信息库SJSXX.dbf

增加XXZQJB（字段28：证券级别） 定义：

‘E’ 交易型开放式指数基金（ETF）；

‘F’ 非交易型开放式基金（暂不交易，仅揭示基金净值及开放申购赎回业务）。

2、行情库SJSHQ.dbf

约定对非交易型开放式基金，HQZRSP（字段3：昨日收盘价）固定为1.000元。

3、委托库SJSWT.dbf

①ETF业务

ETF的申购、赎回等使用的代码与交易代码保持一致，通过WTYWLB（业务类别）来区分委托申报记录。若WTYWLB为“0B”、“0S”、“0C”，则分别表示ETF的正常买、正常卖和相应撤单指令的申报记录。若WTYWLB为“KB”、“KS”，则分别表示ETF的申购、赎回等指令的申报记录，WTWTSL（委托数量）为指令对应的ETF数量（以份为单位）；WTWTJG无意义，可填写任意值；其余字段填相应值。

②市价委托

增加“市价转限价”、“最优价格”、“立即成交并撤销”、“最优五档立即成交并撤销”、“全额成交或撤销”等五种市价委托的申报记录定义。

WTYWLB（业务类别）为‘YB’、‘YS’、“YC”，则分别表示“市价转限价”类市价买委托、卖委托、相应撤单的申报； WTYWLB（业务类别）为‘XB’、‘XS’、“XC”，则分别表示“最优价格”类市价买委托、卖委托、相应撤单的申报；WTYWLB（业务类别）为‘2B’、‘2S’，则分别表示“立即成交并撤销”类市价买委托、卖委托的申报；WTYWLB（业务类别）为‘VB’、‘VS’， 则分别表示“最优五档立即成交并撤销”类市价买委托、卖委托的申报；WTYWLB（业务类别）为‘WB’、‘WS’， 则分别表示“全额成交或撤销”类市价的买委托、卖委托的申报。WTWTJG（委托价格）无意义，填0。

以上市价申报将视情况分步推出，相关业务通知另行发布。

4、回报库SJSHB.dbf

增加ETF申购成功回报记录：HBZQDM（证券代码）＝ETF代码；HBYWLB（业务类别）＝‘KB’；HBCJSL（成交数量）＝申购数量；HBCJJG（成交价格）＝0。

增加ETF申购成功股份交付回报记录：HBZQDM（证券代码）＝成分股代码；HBYWLB（业务类别）＝‘KS’；HBCJSL（成交数量）＝需交付股票数量；HBCJJG（成交价格）＝0。

增加ETF赎回成功回报记录：HBZQDM（证券代码）＝ETF代码；HBYWLB（业务类别）＝‘KS’；HBCJSL（成交数量）＝赎回数量；HBCJJG（成交价格）＝0。

增加ETF赎回成功股份给付回报记录：HBZQDM（证券代码）＝成分股代码；HBYWLB（业务类别）＝‘KB’；HBCJSL（成交数量）＝需给付股票数量；HBCJJG（成交价格）＝0。

增加ETF申购/赎回撤单回报记录：HBZQDM（证券代码）＝ETF代码；HBYWLB（业务类别）＝‘KC’；HBCJSL（成交数量）＝撤单数量；HBCJJG（成交价格）＝0。

增加ETF申购/赎回允许现金替代或必须现金替代的资金交付/给付回报记录：HBZQDM（证券代码）＝成分股代码；HBYWLB（业务类别）＝‘ZB’/‘ZS’（ZB为投资者交付，基金公司获得现金；ZS为基金公司给付，投资者获得现金）；替代金额 ＝ HBCJSL（成交数量）× HBCJJG（成交价格）。

增加“立即成交并撤销”、“最优五档立即成交并撤销”、“全额成交或撤销”等三种市价委托未能成交部分的自动撤单或其他原因自动撤单回报记录，增加“最优价格”、“市价转限价”等两种市价委托的撤单回报记录。其中，HBYWLB（业务类别）＝‘2C’或‘VC’或‘WC’或‘XC’或‘YC’；HBCJSL（成交数量）＝撤销数量；HBCJJG（成交价格）＝0。

同时，在交易主机自动撤单含义表中增加以下撤单原因：

|  |  |  |
| --- | --- | --- |
| 32 | ETF申禁 | 当前禁止该ETF的申购业务 |
| 33 | ETF赎禁 | 当前禁止该ETF的赎回业务 |
| 35 | 申购不足 | 申购所需的组合证券份额不足 |
| 36 | 赎回不足 | 赎回时基金公司的组合证券份额不足 |
| 37 | 现金超限 | ETF申购时现金替代比例超限 |

另外，为了配合大宗交易成交通过SJSHB.DBF回报，将原市场闭市标志（HBCJJG ＝ -2.000）约定为集中竞价市场闭市标志，增加全天市场闭市标志（HBCJJG ＝ -3.000），大宗交易成交在前述两个闭市标志之间回报。未开展大宗交易业务或当日未发生大宗交易业务的用户，可以不等待-3.000标志。

**二、**股份结算接口规范相关调整

1、股份结算信息库SJSGF.dbf

增加业务类别L7，用于发送T-1日ETF申购/赎回的现金差额。GFZJJE（资金金额）字段：正数表示投资者应收资金，负数表示投资者应付资金。

增加业务类别L8，用于发送ETF申购/赎回业务的现金替代多退少补金额。记录中包含委托日期和成交号码，GFSFZH第18位表示委托日期，格式是CCYYMMDD，第9～17位表示委托当日的成交号码。GFZJJE字段：正数表示投资者应收资金，负数表示投资者应付资金。

业务类别W5（卖空代为补入），在接口规范Ver4.34中仅用于权证业务，本版中扩大适用范围，即适用于权证、ETF和实行DVP交收的其它产品。

ETF的网上发行采用连续认购方式（原用于LOF发行）。

2、股份结算对账库SJSDZ.dbf

T日的ETF交易应收（付）ETF份额在T＋1日记账；

T日的ETF申购/赎回应收（付）ETF份额在T＋1日记账，应收（付）组合证券在T日记账。

3、证券交易统计库SJSTJ.dbf

本库不包含ETF的申购、赎回数据。

**三、**资金结算接口规范相关调整

1、资金清算库SJSQS.dbf

T日通过本库发送ETF交易、申购、赎回业务所涉及的T＋1日应收（付）资金。T日SJSQS.dbf的清算资金将在T＋1日收市后进行交收，并反映在T＋1日晚发送的SJSZJ.dbf中。

业务类别00（交易清算数据），QSZQDH为’EF’表示ETF交易的应收（付）资金。

增加业务类别L4，用于ETF申购的现金替代资金清算，QSZQDH为ETF证券代码。买入金额字段表示现金替代资金。

增加业务类别L5，用于ETF赎回 的现金替代资金清算，QSZQDH为ETF证券代码。卖出金额字段表示现金替代资金。

增加业务类别L7，用于T-1日ETF申购/赎回现金差额清算，QSZQDH为ETF证券代码，买入金额字段为申购现金差额，卖出金额字段为赎回现金差额。

增加业务类别L8，用于ETF现金替代的多退少补资金清算，QSZQDH为ETF证券代码，买入金额为补款金额，卖出金额为退款金额。

2、资金结算信息库SJSZJ.dbf

本库根据ETF业务涉及的资金收付种类，增加不同的用途代号，具体解释如下：

C008　 ETF申购赎回的集中资金交收

G012　 ETF申购赎回监管规费

H036　 ETF申购赎回经手费

H037　 ETF组合证券过户费

I008　 ETF申购赎回结算风险基金

L001　 ETF现金替代的多退少补
