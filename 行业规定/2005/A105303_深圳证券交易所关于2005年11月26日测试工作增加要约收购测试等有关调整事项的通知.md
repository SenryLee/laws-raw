# 深圳证券交易所关于2005年11月26日测试工作增加要约收购测试等有关调整事项的通知

各会员单位：

根据本所2005年11月21日发布的《关于权证上市和ETF发行及网络投票结果回报等业务全网测试的通知》、《权证上市和ETF发行及网络投票结果回报等业务全网测试方案》，本所于2005年11月26日（周六）在进行交易系统应急演练测试的同时，进行相关业务测试，现将有关调整事项通知如下：

**一、**增加要约收购业务测试

2005年11月26日本所将开放要约收购测试环境，相关会员可进行下列两只证券要约收购的申报测试：

|  |  |  |
| --- | --- | --- |
| 证券代码 | 证券简称 | 收购编号 |
| 000763 | 锦州石化 | 990003 |
| 000817 | 辽河油田 | 990004 |

结算公司将根据要约收购申报的处理情况发送相应结算数据。

业务规范请参见本所发布的《上市公司要约收购业务指南》及相关技术文档。

**二、**权证测试调整

本所原计划对两只认沽权证产品038001（钢钒PGP1）、038002（万科HRP1）进行测试，现增加一只认购权证的测试，其参数见下表：
