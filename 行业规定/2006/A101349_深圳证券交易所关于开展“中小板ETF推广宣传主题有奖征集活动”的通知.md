# 深圳证券交易所关于开展“中小板ETF推广宣传主题有奖征集活动”的通知

各会员单位、证券营业部：

中小企业板指数ETF（以下简称中小板ETF）目前正在筹备中，为充分做好各项准备工作，使会员单位和广大投资者深入了解和关注中小企业板以及中小板ETF的特点，推动ETF知识的普及化和大众化，我所定于4月19日－4月28日会同华夏基金管理公司、深圳证券信息公司联合开展“中小板ETF推广宣传主题有奖征集活动”。现就有关事项通知如下：

**一、**主办单位：深圳证券交易所、华夏基金管理有限公司、深圳证券信息公司

**二、**征集内容

1．中小板ETF的推广主题（宣传口号）；

2．对中小板ETF的推广主题的诠释（不少于250字），诠释内容包括主题所体现的中小板ETF产品特点，主题针对了投资者的哪些投资需求等。

**三、**活动安排

1．推广主题征集时间为4月19日至4月28日；

2．征集结束后由主办单位选出20个入围作品，参与活动的各个证券公司投票从中评选出五大最佳宣传主题，由主办单位分别授予最佳宣传主题奖和优秀宣传主题奖；

3．活动奖励方案。为激发营业部参与的积极性，本次活动奖品价值总计约6万元并设置以下奖项，同一营业部多个作品获奖可累计。

|  |  |  |
| --- | --- | --- |
| 奖项名称 | 奖励单位 | 说明 |
| 最佳宣传主题奖 | 营业部（1个） | 选送作品评为第一名的营业部 |
| 优秀宣传主题奖 | 营业部（4个） | 选送作品评为2至5名的营业部 |
| 入围奖 | 营业部（15个） | 选送作品评为6至20名的营业部 |
| 最佳组织奖 | 证券公司（4个） | 入围主题数目最多的前4家证券公司 |

**四、**组织实施

请各会员单位重点做好以下工作：

1．内部转发本通知要求每个营业部至少提交一个参评作品；

2．要求各个营业部认真学习中小板指数相关资料（见附件），并指定专人负责汇总各营业部提交的参评作品。

**五、**推广主题投稿方式

各会员单位汇总营业部参评宣传主题作品后，填写附表汇总相关信息，以电子形式发送至华夏基金管理有限公司基金营销部。
