# 深圳证券交易所关于成份股编制方案变更及样本调整的公告

为了适应市场发展的需要，本所决定对深证成份指数编制方案作调整，决定对深证成份指数、成份A股指数、成份B股指数的功能定位及指数结构作以下变更：

深证成份指数将变更为仅包含40只A股样本的价格指数，不再包含B股成份股；成份A股指数保持总收益指数不变，指数样本与深证成份指数相同；成份B股指数变更为包含深圳市场10只B股的B股总收益指数；指数选样由按上市公司为单位选样变更为分别从深圳A股和B股市场单独选样。

本所同时还决定对深证成份指数样本、成份A股指数和成份B股指数分别作如下调整。现公告如下：

**一、**深证成份指数、成份A股指数，更换4只A股样本，调整后成份股数量保持40只不变：

调出：G威孚、G首钢、G长城、G佛照；

调入：G云铜、G西飞、G老窖、G燕啤。

**二、**成份B股指数：

调出：苏威孚B、粤佛照B；

调入：江铃B。

本次调整方案于2006年9月18日正式实施。

样本调整详细名单及指数相关资料参见本所网站（http：//www.szse.cn） 及巨潮指数网（http：//index.cninfo.com.cn）。

特此公告。
