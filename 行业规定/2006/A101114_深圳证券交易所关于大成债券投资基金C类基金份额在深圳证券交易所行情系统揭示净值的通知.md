# 深圳证券交易所关于大成债券投资基金C类基金份额在深圳证券交易所行情系统揭示净值的通知

各会员单位：

根据大成基金管理有限公司申请，经本所审核同意大成债券投资基金C类基金份额在本所行情发布系统揭示净值。

大成债券投资基金C类基金份额净值揭示简称为“大成债C”，代码为“160907”。每百份基金单位前一日净值在行情系统“前收盘”中反映。正式开始揭示净值的时间为2006年4月26日（星期三）。

特此通知

深圳证券交易所
