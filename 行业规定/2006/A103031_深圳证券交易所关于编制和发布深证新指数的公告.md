# 深圳证券交易所关于编制和发布深证新指数的公告

为了配合我国股权分置改革的推进，并适应广大投资者需求，向市场各类投资者提供观察完成股权分置改革的上市公司股价走势的基准尺度，并形成今后新的行业指数编制和发布的基准，本所决定于2006年2月16日起正式编制和发布深证新指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399100 | 深证新指数 | 新指数 | 2005年12月30日 | 1107.23 |

该指数之实时指数通过本所实时行情库发布，委托深圳证券信息有限公司编制、维护和管理。指数编制方案及相关指数信息参见巨潮指数网站http：//index.cninfo.com.cn。

特此公告。

深圳证券交易所
