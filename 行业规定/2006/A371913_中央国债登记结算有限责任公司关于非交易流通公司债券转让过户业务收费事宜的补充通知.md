# 中央国债登记结算有限责任公司关于非交易流通公司债券转让过户业务收费事宜的补充通知

各结算成员：

根据中国人民银行公告[2005]第30号和《非交易流通公司债券转让过户业务规则》规定，从2006年7月1日起结算成员在办理非交易流通公司债券转让过户时，转让双方应向中央国债登记结算有限责任公司支付相关费用。现将有关收费事宜通知如下：

一、非交易流通公司债券转让过户业务

1.　交易品种：协议转让（非交易流通公司债券过户）

2.　收费对象：结算双方

3.　结算方式：纯券过户

4.　收费标准：500元/笔

二、收费时间、缴款方式及查询方式按《中央国债登记结算有限责任公司业务收费办法》（以下简称《收费办法》）执行。

三、中央国债登记结算有限责任公司对上述收费标准进行调整时，通过《收费办法》予以公布。

本项业务收费自2006年7月1日起执行。

特此通知。
