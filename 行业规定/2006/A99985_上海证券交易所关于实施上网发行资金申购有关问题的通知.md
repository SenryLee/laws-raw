# 上海证券交易所关于实施上网发行资金申购有关问题的通知

*注：本篇法规已被：上海证券交易所关于废止部分业务规则的公告(第六批)（发布日期：2013年2月1日，实施日期：2013年2月1日）废止

## 上海证券交易所关于实施上网发行资金申购有关问题的通知（上证上字〔2006〕432号）

各会员单位：

为了进一步规范上网发行资金申购中的有关行为，做好新股发行工作，根据《沪市股票上网发行资金申购实施办法》（以下简称“《实施办法》”），现将有关事项通知如下。

**一、**对于在本所首次公开发行的上市公司可以向本所申请并采用逾千位A股股票代码即“601x x x”，本所按照证监会发行核准批文的先后顺序依次分配股票代码。与逾千位A股股票代码相关的辅助代码的设定与安排，参照本所《关于启用601x x x等代码段用于股票及相关辅助业务的通知》（上证交字［2006］5号）（见附件1）。

**二、**各会员单位应在T＋1日及时划付申购资金，确因银行汇划原因而造成申购资金不能及时入账的，应在T＋1日提供划款银行的划款凭证，并确保T＋2日上午申购资金入账，同时缴纳一天申购资金应冻结利息。

**三、**各会员单位不得透支申购股票，也不得为客户透支申购股票。本所将对存在透支申购的会员单位进行检查并依法处理，对申购中的透支申购视为无效申购，同时将透支的会员单位名单上报中国证监会。

**四、**如会员单位发生透支申购（即申购总额超过结算备付金余额）的情况，则透支部分确认为无效申购不予配号，具体办法如下：

1、会员单位在T＋1日下午四点前将资金不实的申购账号及其对应席位号告知本所上市公司部（报送电子文件和书面文件，见附件2），且上报的资金不实申购总额须与登记公司认可的透支总额相等，由本所逐一确认上述账号的申购为无效申购。

2、如会员单位未在规定时间内向本所报送申购账号、报送的材料不全或报送的资金不实申购总额与登记公司认可的透支总额不等，本所将依照《实施办法》的有关规定（第二条第4点）进行透支申购的处理。

3、进入处置程序的证券公司存在的客户交易结算资金缺口，由证券投资者保护基金根据有关政策经审核确认后陆续予以弥补；为保护投资者利益，根据有关政策对已经处置证券公司申购资金不足部分予以正常配号。

**五、**进行资金申购时，每一申购单位为1000股，申购数量不少于1000股，超过1000股的必须是1000股的整数倍，但最高不得超过当次社会公众股上网发行数量或者9999.9万股。本所个人投资者股票帐户（A字头证券账户）不允许进行重复申购，重复申购除第一次申购为有效申购外，其余申购由本所交易系统自动剔除。机构投资者账户（B、D字头证券账户）可以进行重复申购，但每次申购不得超过申购上限。

**六、**在新股上网发行资金申购中本所暂不收取发行经手费。经中国证监会批准（证监发字[2006]10号），《关于股票发行与认购方式的暂行规定》（证监发字[1996]423号）不再执行。因此，在新股上网发行资金申购中，本所不再接受主承销商委托按发行金额提取上网发行手续费。

**七、**各会员单位应安排下属营业部作好新股发行的宣传工作，提醒投资者依照《实施办法》的相关规定进行申购，并应在营业部显著位置公布新股申购日期、申购代码、申购程序等重要信息，并及时提醒投资者足额存入资金。以大同煤业为例，见附件3。

主承销商须严格按照《上海证券交易所首次公开发行新股发行和上市指引》作好新股发行工作，并按本通知要求做好上网发行信息披露工作。

附件3

举例：大同煤业发行的重要提示和申购程序

**一、**重要提示

1、发行数量：本次发行股份总量为28，000万股，其中网上定价发行数量为22，400万股，占发行总量的80%。

2、申购时间：2006年6月13日（周二），在本所正常交易时间（9：30-11：30，13：00-15：00）内进行。如遇重大突发事件或不可抗力因素影响本次发行，则按申购当日通知办理。

3、申购简称：“大同煤业”；申购代码：“780001”。

4、本次上网发行，参加申购的单一证券账户的委托申购数量不少于1000股，超过1000股的必须是1000股的整数倍。

5、证券账户每次申购的申购上限为9，999.9万股。

6、除机构投资者帐户外，单一证券帐户只能申购一次，一经申报不能撤单。重复申购除第一次申购为有效申购外，其余申购由本所交易系统自动剔除。

**二、**申购程序

1、办理开户登记

参加本次“大同煤业”股票上网定价发行的投资者须持有中国结算上海分公司的证券账户卡。尚未办理开户登记手续的投资者，必须在网上申购日，即2006年6月13日（T日）前（含申购日）办妥证券账户开户手续。

2、存入足额申购资金

由于本次上网定价发行采用资金申购方式，参与本次“大同煤业”网上申购的投资者，应在网上申购日（2006年6月13日，含该日）前在与本所联网的证券交易网点开立资金账户，并根据自己的申购量存入足额的申购资金。

3、申购手续

申购手续与在二级市场买入本所上市股票的方式相同，即：

（1）投资者当面委托时，填写好申购委托单的各项内容，持本人身份证、证券账户卡和资金账户卡（确认资金存款额必须大于或等于申购所需的款项）到申购者开户的与本所联网的各证券交易网点办理委托手续。柜台经办人员查验投资者交付的各项证件，复核无误后即可接受委托。

（2）投资者通过电话委托或其他自动委托方式时，应按各证券交易网点要求办理委托手续。

（3）投资者的申购委托一经接受，不得撤单。
