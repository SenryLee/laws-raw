# 深圳证券交易所关于在交易独立测试系统进行新股定价发行测试的通知

各会员单位、基金公司、软件开发商：

为了确保各相关单位新股发行技术准备工作的顺利进行，深圳证券交易所拟于2006年5月30日（周二）至6月2日（周五）每日下午13：30至16：30，在交易独立测试系统提供新股定价发行申报的测试环境，以方便各会员单位及软件开发商进行相关系统的测试。本轮测试只提供新股发行申报测试，不包括配号、中签流程。

新股定价发行相关测试参数见下表：

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 测试证券代码 | 证券简称 | 发行价格 | 发行量 | 最小申报单位 | 申报上限 |
| 002999 | 发行测试 | 6.780元 | 80，000，000股 | 500股 | 发行量 |

注： 1、申报数量必须为最小申报单位的整数倍。

2、上述参数仅限于测试。

未在本所交易独立测试系统开设测试用户的单位，可在本所网站上的“技术专栏” -＞“交易独立测试系统”栏目（http：//www.szse.cn/main/rules/duli/Catalog_1920.aspx）中查询相关测试用户申请流程和下载测试用户申请表。

测试咨询电话：0755-25918223

特此通知。
