## 中国外汇交易中心、全国银行间同业拆借中心关于外汇交易系统迁移有关事项的通知（中汇交发[2006]214号）

外汇市场会员：

感谢广大会员单位积极配合交易中心的大楼搬迁和系统迁移工作，认真参与三次模拟演练。目前交易系统迁移条件已基本具备，交易中心定于2006年8月7日（星期一）实现结售汇系统和外币买卖系统的迁移，现将有关事项通知如下：

2.具体操作

（1）设置防火墙

若你行交易机安装了防火墙，或者在访问交易系统前需通过防火墙设备，请于8月4日16：30前由本行技术人员在防火墙上开通下列端口，并检查路由器静态路由设置，以便正常访问外币买卖交易系统。

|  |  |
| --- | --- |
| ip地址 | 端口 |
| 200.31.52.18 | 443 |
| 200.31.50.32 | 80 |

若你行使用了外币买卖系统头寸管理工具，还需另开下列端口

|  |  |
| --- | --- |
| ip地址 | 端口 |
| 200.31.52.20 | 2222 |

（2）修改外币买卖系统头寸管理工具配置文件

请于8月4日头寸管理工具使用完成后修改该工具的配置文件，将服务地址指向新环境的服务器。具体步骤如下：

1、进入头寸管理工具所在机器，关闭头寸管理工具；

2、进入c：zssclientcfg目录，用记事本打开client.cfg文件；

3、将serverip＝200.31.32.20修改为serverip＝200.31.52.20并保存。
