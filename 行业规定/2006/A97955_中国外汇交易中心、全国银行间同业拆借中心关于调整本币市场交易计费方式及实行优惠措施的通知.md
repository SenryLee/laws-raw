# 中国外汇交易中心、全国银行间同业拆借中心关于调整本币市场交易计费方式及实行优惠措施的通知

## 中国外汇交易中心、全国银行间同业拆借中心关于调整本币市场交易计费方式及实行优惠措施的通知（中汇交发[2006]217号）

各交易成员：

根据《中国人民银行办公厅关于本币市场有偿服务的批复》（银办函【2005】484号）精神，全国银行间同业拆借中心（以下简称“交易中心”）在征询交易成员意见和报经中国人民银行备案后，定于2006年起调整本币市场交易计费方式并实行优惠措施。现通知如下：

**一、**从2006年起交易手续费以当年每个交易日发生的交易量为计费基数逐笔计费、按季收费。

**二、**按交易量分段实行手续费折扣累进优惠。具体优惠措施见下表：

交易手续费折扣累进优惠表

|  |  |  |
| --- | --- | --- |
| 交易种类 | 交易量区间（亿元） | 手续费优惠幅度（％） |
| 融资类交易1天品种 | 0～4000（含4000） | 0 |
| 4000～8000（含8000） | 10 |
| 8000～12000（含12000） | 20 |
| 12000～16000（含16000） | 30 |
| 16000～20000（含20000） | 40 |
| 20000以上 | 50 |
| 融资类交易2天及以上品种 | 0～4000（含4000） | 0 |
| 4000～8000（含8000） | 10 |
| 8000～12000（含12000） | 20 |
| 12000～16000（含16000） | 30 |
| 16000～20000（含20000） | 40 |
| 20000以上 | 50 |
| 买卖类交易 | 0～2000（含2000） | 0 |
| 2000～4000（含4000） | 10 |
| 4000～6000（含6000） | 20 |
| 6000～8000（含8000） | 30 |
| 8000～10000（含10000） | 40 |
| 10000以上 | 50 |

**三、**对单笔交易手续费实行封顶优惠。单笔交易手续费若超过1000元，则按1000元收取该笔交易的交易手续费。

**四、**在交易中心互联网交易系统推出前继续免收各交易成员的交易终端使用费，所有交易成员均按实际计费金额支付交易手续费。

**五、**自本通知公布之日起停止收取软件使用费、读卡器和IC卡成本费以及IC卡服务年费。

**六、**交易中心于每季度初计算各交易成员上季度的应付交易手续费额，并向交易成员发送付费通知单；交易成员于收到付费通知单的当月底前将应付费用汇至交易中心指定的银行账户；交易中心收到交易成员的应付款项后即向交易成员寄送发票。

交易成员应付手续费数额以交易中心收费通知单为准。

**七、**交易中心将对收费事宜提供相关咨询、查询服务。与费用支付有关事宜，请与交易中心财务部联系，联系人：徐国庆，联系电话：021-58555065，63298988转7863；与付费额计算有关事宜，请与交易中心市场二部联系，联系人：宗迎伟，杨晓烨，联系电话：021-68795301，68795382，63298988转7726、7972、7973。
