# 深圳证券交易所关于2018年端午节休市安排的通知

## 关于2018年端午节休市安排的通知

各市场参与人：

根据《关于2018年部分节假日休市安排的通知》（深证会〔2017〕416号），现将2018年端午节休市有关安排通知如下。

一、休市安排

6月16日（星期六）至6月18日（星期一）休市，6月19日（星期二）起照常开市。

二、清算交收

节假日期间清算交收事宜，按照中国证券登记结算有限责任公司的有关安排进行。

请各市场参与人据此安排好有关工作。

深圳证券交易所

2018年6月7日
