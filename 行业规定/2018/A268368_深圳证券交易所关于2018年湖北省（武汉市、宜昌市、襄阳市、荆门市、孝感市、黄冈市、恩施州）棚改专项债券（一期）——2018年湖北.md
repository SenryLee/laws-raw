# 深圳证券交易所关于2018年湖北省（武汉市、宜昌市、襄阳市、荆门市、孝感市、黄冈市、恩施州）棚改专项债券（一期）——2018年湖北省政府专项债券（四期）上市交易的通知

## 关于2018年湖北省（武汉市、宜昌市、襄阳市、荆门市、孝感市、黄冈市、恩施州）棚改专项债券（一期）——2018年湖北省政府专项债券（四期）上市交易的通知

各市场参与人：

2018年湖北省（武汉市、宜昌市、襄阳市、荆门市、孝感市、黄冈市、恩施州）棚改专项债券（一期）——2018年湖北省政府专项债券（四期）已发行结束，根据财政部有关规定，本期债券于2018年9月5日起在本所上市交易。

本期债券为7年期固定利率附息债，证券编码"106848",证券简称"湖北1809",票面利率3.98%,标准交易单位"10张",2025年9月3日到期还本并支付最后一期利息。
