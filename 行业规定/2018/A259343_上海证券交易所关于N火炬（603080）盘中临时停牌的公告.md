# 上海证券交易所关于N火炬（603080）盘中临时停牌的公告

## 关于N火炬（603080）盘中临时停牌的公告

上证公告（监察）〔2018〕001号

N火炬（603080）今日上午交易出现异常波动。根据《上海证券交易所交易规则》和《关于新股上市初期交易监管有关事项的通知》的有关规定，本所决定，自2018年01月03日09时31分开始暂停N火炬（603080）交易，自2018年01月03日10时01分起恢复交易。

本所提醒投资者注意交易风险，理性投资。

特此公告。

上海证券交易所

2018年01月03日
