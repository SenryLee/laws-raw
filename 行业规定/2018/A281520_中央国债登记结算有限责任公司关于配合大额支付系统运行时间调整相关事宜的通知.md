# 中央国债登记结算有限责任公司关于配合大额支付系统运行时间调整相关事宜的通知

## 关于配合大额支付系统运行时间调整相关事宜的通知

中债字〔2018〕12号

各结算成员：

根据《人民银行办公厅关于调整大额支付系统运行时间有关事项的通知》（银办发〔2017〕238号），自2018年1月22日起，大额支付系统运行时间调整为5×21小时运行。为配合新的大额支付系统运行时间，我公司对中央债券综合业务系统（以下简称债券系统）相关业务的受理时间进行相应调整，现通知如下：

一、银行间市场结算业务的受理时间

债券系统受理银行间市场结算业务的时间不变，仍为工作日9:00至17:00.

二、大额支付系统自动质押融资业务的受理时间

自2018年1月22日起，债券系统工作日受理大额支付系统自动质押融资业务的起始时间由（T日）8:30调整为前一日（T-1日）23:30,受理截止时间为（T日）20:30.成员如预计在工作日（T-1日）23:30至（T日）8:30期间办理大额支付系统自动质押融资业务，可于T-1日20:00前告知我公司并做好相关业务准备。

三、增加一次剩余债券结算资金自动退回时点

为完全满足人民银行对债券结算资金专户"零余额"的管理要求，自2018年1月22日起，债券系统将增加一次对债券结算资金专户剩余结算资金的自动退回处理，新增的自动退回时点为工作日的17:05,请各结算成员做好相关业务衔接。
