# 深圳证券交易所关于为“中建七局-中金2018年第一期应收账款资产支持专项计划”提供转让服务的公告

## 关于为“中建七局-中金2018年第一期应收账款资产支持专项计划”提供转让服务的公告

各相关单位：

根据中国国际金融股份有限公司申请，本所将自2018年12月5日起在综合协议交易平台为“中建七局-中金2018年第一期应收账款资产支持专项计划”（以下简称“中建七局2018年第一期”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“中建七局2018年第一期”的转让业务。

二、“中建七局2018年第一期”设立日期为2018年9月29日。优先级资产支持证券如下：证券简称“七局1优”，证券代码为“139190”，到期日为2021年6月22日，还本付息方式为按半年付息、到期一次还本。次级资产支持证券如下：证券简称“七局1次”，证券代码为“139191”，到期日为2021年6月22日，还本付息方式为劣后于优先级证券及差额支付承诺人获得剩余资金。

三、“七局1优”的单笔成交申报最低数量为10000份，“七局1次”的单笔成交申报最低数量为10000份。

四、对首次参加“中建七局2018年第一期”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“中建七局2018年第一期”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
