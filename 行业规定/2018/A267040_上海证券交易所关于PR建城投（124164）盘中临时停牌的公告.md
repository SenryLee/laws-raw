# 上海证券交易所关于PR建城投（124164）盘中临时停牌的公告

## 关于PR建城投（124164）盘中临时停牌的公告

上证公告（监察）〔2018〕94号

PR建城投（124164）今日上午交易出现异常波动。根据《上海证券交易所交易规则》和《上海证券交易所证券异常交易实时监控细则》的有关规定，本所决定，自2018年07月31日11时25分开始暂停PR建城投（124164）交易，自2018年07月31日13时25分起恢复交易。

本所提醒投资者注意交易风险，理性投资。恢复交易后，如该债券交易再次出现异常波动，本所可实施第二次盘中临时停牌，停牌时间持续至今日14时55分。

特此公告。

上海证券交易所

2018年07月31日
