# 中国期货业协会关于吸收福能商创贸易有限责任公司等3家机构成为协会会员的公告

## 关于吸收福能商创贸易有限责任公司等3家机构成为协会会员的公告

根据机构自愿申请，按照协会章程，经协会理事会审议，同意吸收福能商创贸易有限责任公司等3家机构成为协会会员（具体名单附后）。

特此公告。

中国期货业协会

二〇一八年四月十六日

附

## 3家新入会会员名单

|  |  |  |
| --- | --- | --- |
| **序号** | **公司名称** | **会员类型** |
| 1 | 上海福能商创贸易有限责任公司 | 普通会员 |
| 2 | 天示（上海）企业管理有限公司 | 普通会员 |
| 3 | 兴业银信资本管理有限公司 | 普通会员 |
