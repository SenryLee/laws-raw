# 深圳证券信息有限公司关于发布国证深圳创新引擎指数的公告

## 关于发布国证深圳创新引擎指数的公告

为了反映在深交所上市的深圳企业整体表现，为市场提供深圳上市企业的业绩基准与投资标的，深圳证券信息有限公司定于2018年7月31日发布国证深圳创新引擎指数。指数名称和代码如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 指数基日 | 基日点位 |
| 399050 | 国证深圳创新引擎指数 | 创新引擎 | 2012年12月31日 | 1000 |

深圳创新引擎指数以在深交所上市的深圳企业为选样空间，主要依据最近半年日均总市值、近三年平均研发投入、营业收入、净利润进行排名，选取50只股票作为样本股。指数采用自由流通市值加权计算，设置10%的个股权重上限，于每年1月、7月的第一个交易日进行样本股定期调整。

深圳创新引擎指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关深圳创新引擎指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
