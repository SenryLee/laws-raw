# 中国创盈市场服务有限公司关于深港通下的港股通股票名单调整的公告

## 关于深港通下的港股通股票名单调整的公告

因天誉置业（00059）开始并行买卖分拆股份、赣锋锂业（01772）在香港市场价格稳定期结束且相应A股上市满10个交易日，根据《深圳证券交易所深港通业务实施办法》的有关规定，港股通股票名单发生调整并自今日起生效，相关调整信息如下：

|  |  |  |
| --- | --- | --- |
| 代码 | 简称 | 调整方向 |
| 00059 | 天誉置业（新） | 调入 |
| 01772 | 赣锋锂业 | 调入 |
