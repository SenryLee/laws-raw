# 中央国债登记结算有限责任公司关于提示银行间债券市场金融债券发行人资产支持证券受托机构按时披露2017年度报告（受托机构报告）的通知

## 关于提示银行间债券市场金融债券发行人资产支持证券受托机构按时披露2017年度报告（受托机构报告）的通知

中债字〔2018〕42号

各银行间债券市场金融债券发行人、资产支持证券受托机构：

根据《全国银行间债券市场金融债券发行管理办法》（中国人民银行令〔2005〕第1号）《全国银行间债券市场金融债券发行管理操作规程》（中国人民银行公告〔2009〕第6号）《全国银行间债券市场金融债券信息披露操作细则》《保险公司发行资本补充债券有关事宜》（中国人民银行 中国保险监督管理委员会公告〔2015〕3号）《银行间市场发行绿色金融债券有关事宜》（中国人民银行公告〔2015〕第39号）《资产支持证券信息披露规则》（中国人民银行公告〔2005〕第14号）及其他相关政策规定，包括并不限于经批准在全国银行间债券市场发行并交易的政策性金融债券、一般性金融债券、商业银行次级债券、混合资本债券、二级资本债券、国际机构债券、政府支持机构债（参照金融债的信息披露）、非银行金融债券、保险公司资本补充债券、绿色金融债券等人民币债券发行人（见附件），应于2018年4月30日前通过中国债券信息网披露2017年年度报告、经审计的财务报表、审计报告等信息；资产支持证券受托机构应披露2017年度经审计的受托报告。

一、披露内容

（一）2017年度的经营情况说明、由注册会计师审计的财务报告以及涉及重大诉讼事项等内容的年度报告；

（二）鼓励发行人根据《全国银行间债券市场金融债券信息披露操作细则》规定的模板，提交EXCEL格式的财务数据电子版文件；

（三）以担保方式发行金融债的发行人，还应披露担保人2017年度的年度报告；

（四）混合资本债券发行人还应披露2018年第一季度的资产负债表、利润表及现金流量表和2018年第一季度跟踪评级信息；

（五）资本补充债券发行人应披露2017年的年度报告、审计报告和经审计的偿付能力报表；

（六）绿色金融债发行人应披露2017年度募集资金使用情况的年度报告和专项审计报告，以及2018年第一季度募集资金使用情况；

（七）资产支持证券受托机构应公布经注册会计师审计的2017年度受托机构报告；

（八）因特殊原因，发行人无法按时披露以上信息的，应向投资者披露延期公告说明。

二、披露方式

（一）发行人应使用"债券信息自助披露系统"披露上述信息；

（二）发行人2017年度经审计财务报告在"披露信息管理--财务报告-存续期"栏目下提交；EXCEL格式财务数据电子文件在"财务报表上传（excel）"栏目下提交。

三、文件格式

（一）年度报告应合并为一份PDF格式文件，并有发行人清晰公章；

（二）经审计财务报告，应有注册会计师签章；财务报表部分应有发行人公章；

（三）电子版文件的文件名应包含金融机构全称。
