# 深圳证券交易所关于支付2014年江西省地方政府债券（三期）利息有关事项的通知

## 关于支付2014年江西省地方政府债券（三期）利息有关事项的通知

各市场参与人：

2014年江西省地方政府债券（三期）将于2018年2月6日支付利息。为做好本期债券的利息支付工作，现将有关事项通知如下：

一、本期债券证券代码为“109138”，证券简称为“江西1403”，是2014年8月6日发行的10年期债券，票面利率为4.27％，每年支付2次利息，每百元面值债券本次可获利息2.135元。

二、本所从2018年1月29日至2018年2月5日停办本期债券的转托管及调帐业务。

三、本期债券付息债权登记日为2018年2月5日，凡于当日收市后持有本期债券的投资者，享有获得本次利息款项的权利，2018年2月6日除息交易。

四、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的本期债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
