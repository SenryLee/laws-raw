# 深圳证券交易所关于南京普天通信股份有限公司股票恢复上市的公告

## 关于南京普天通信股份有限公司股票恢复上市的公告

南京普天通信股份有限公司（以下简称“公司”）因2014年、2015年、2016年连续三个会计年度经审计的归属于上市公司股东的净利润为负值，公司股票自2017年5月11日起暂停上市。2018年5月2日，公司向本所提交了股票恢复上市的申请。

2018年7月20日，本所第九届上市委员会召开第192次工作会议，审议通过了公司股票恢复上市的申请。

根据本所《股票上市规则（2018年修订）》的相关规定及本所上市委员会的审议意见，本所决定公司股票自2018年8月15日起恢复上市。公司应当根据《关于同意南京普天通信股份有限公司股票恢复上市的决定》及时披露股票恢复上市公告，并按照规定做好股票恢复上市的有关工作。
