# 深圳证券交易所关于支付2017年记账式附息（二期）国债等五只债券利息有关事项的通知

## 关于支付2017年记账式附息（二期）国债等五只债券利息有关事项的通知

各市场参与人：

2017年记账式附息（二期）国债、2016年广东省政府一般债券（十六期）、2016年广东省政府专项债券（十二期）、2017年陕西省政府一般债券（八期）、2017年吉林省政府一般债券（四期）将于2018年1月19日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2017年记账式附息（二期）国债证券代码为“101702”，证券简称为“国债1702”，是2017年1月19日发行的3年期债券，票面利率为2.77％，每年支付1次利息，每百元面值债券本次可获利息2.77元。

二、2016年广东省政府一般债券（十六期）证券代码为“107178”，证券简称为“广东1616”，是2016年7月19日发行的10年期债券，票面利率为3.02％，每年支付2次利息，每百元面值债券本次可获利息1.51元。

三、2016年广东省政府专项债券（十二期）证券代码为“107181”，证券简称为“广东1619”，是2016年7月19日发行的10年期债券，票面利率为3.02％，每年支付2次利息，每百元面值债券本次可获利息1.51元。

四、2017年陕西省政府一般债券（八期）证券代码为“107833”，证券简称为“陕西1711”，是2017年7月19日发行的10年期债券，票面利率为3.9％，每年支付2次利息，每百元面值债券本次可获利息1.95元。

五、2017年吉林省政府一般债券（四期）证券代码为“107838”，证券简称为“吉林1704”，是2017年7月19日发行的10年期债券，票面利率为3.97％，每年支付2次利息，每百元面值债券本次可获利息1.985元。

六、本所从2018年1月11日至2018年1月18日停办上述债券的转托管及调帐业务。

七、上述债券付息债权登记日为2018年1月18日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2018年1月19日除息交易。

八、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
