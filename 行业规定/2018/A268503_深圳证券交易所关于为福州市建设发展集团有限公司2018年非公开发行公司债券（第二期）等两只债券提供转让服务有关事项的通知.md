# 深圳证券交易所关于为福州市建设发展集团有限公司2018年非公开发行公司债券（第二期）等两只债券提供转让服务有关事项的通知

## 关于为福州市建设发展集团有限公司2018年非公开发行公司债券（第二期）等两只债券提供转让服务有关事项的通知

各会员单位：

福州市建设发展集团有限公司2018年非公开发行公司债券（第二期）、 济南高新控股集团有限公司2018年非公开发行公司债券（第一期）定于2018年9月11日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、福州市建设发展集团有限公司2018年非公开发行公司债券（第二期）证券代码“114360”，证券简称“18榕建02”，发行总额18.2亿元，票面利率5.59%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、济南高新控股集团有限公司2018年非公开发行公司债券（第一期）证券代码“114363”，证券简称“18济高01”，发行总额10亿元，票面利率5.85%，债券期限6年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一八年九月七日
