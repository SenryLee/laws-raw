# 深圳证券交易所关于2017年云南省昆明市土地储备专项债券（二期）——2017年云南省政府专项债券（十二期）上市交易的通知

## 关于2017年云南省昆明市土地储备专项债券（二期）——2017年云南省政府专项债券（十二期）上市交易的通知

各市场参与人：

2017年云南省昆明市土地储备专项债券（二期）——2017年云南省政府专项债券（十二期）已发行结束，根据财政部有关规定，本期债券于2017年12月29日起在本所上市交易。

本期债券为3年期固定利率附息式国债（地方政府债），证券编码“106362”，证券简称“云南1723”，票面利率4.24％，标准交易单位“10张”，2020年12月27日到期还本并支付最后一期利息。
