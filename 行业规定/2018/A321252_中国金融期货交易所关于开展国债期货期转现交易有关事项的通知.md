# 中国金融期货交易所关于开展国债期货期转现交易有关事项的通知

## 关于开展国债期货期转现交易有关事项的通知

各会员单位：

我所将开展国债期货期转现交易，现将有关事项通知如下：

**一、**上线时间

自2019年1月2日（星期三）起，我所会员服务系统开始接受国债期货期转现交易的会员备案和机构备案；1月17日（星期四）起，完成备案程序的客户可以期转现交易方式开展国债期货交易。

**二、**适用合约

国债期货所有合约可以采用期转现交易方式。

**三、**交易手续费

国债期货期转现交易的交易手续费与集中交易方式标准一致。

各会员单位要认真做好开展国债期货期转现交易的各项准备工作，严格控制市场风险，确保国债期货期转现交易的顺利启动和平稳运行。

特此通知。

中国金融期货交易所

2018年12月28日
