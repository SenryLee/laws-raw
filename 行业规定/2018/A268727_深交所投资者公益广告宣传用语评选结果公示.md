# 深交所投资者公益广告宣传用语评选结果公示

为贯彻党的十九大精神，坚持以人民为中心的发展思想，迎接改革开放四十周年，落实中国证监会“理性投资，从我做起”投资者教育专项活动要求，在中国证监会投资者保护局指导下，深交所于2018年5月14日至25日之间，面向社会公众征集投资者教育公益广告宣传片用语。

征集工作得到了社会各界的积极响应和大力支持，共有636个参与主体贡献宣传用语，共计收到3192条。经广泛征求各方人士意见，活动共选出来自社会公众和会员单位的入围口号各5条。2018年深交所投资者教育公益广告将在入围口号基础上，进一步提炼形成宣传用语。在此，深交所对所有参与口号征集的主体表示感谢，并对入围者给予相应奖励。
