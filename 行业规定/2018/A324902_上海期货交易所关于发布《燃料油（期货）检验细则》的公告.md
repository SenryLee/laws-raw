# 上海期货交易所关于发布《燃料油（期货）检验细则》的公告

上海期货交易所公告〔2018〕22号

为规范燃料油实物交割的检验行为，根据《中华人民共和国进出口商品检验法》等有关法律法规和《上海期货交易所燃料油期货标准合约》《上海期货交易所燃料油期货交割实施细则》，燃料油期货指定检验机构（见附件2）对《燃料油（期货）检验细则》进行了相应修订，并已在上海期货交易所备案，现予以公布。

特此公告。

附件：1．燃料油（期货）检验细则

2．燃料油期货指定检验机构名单

上海期货交易所

2018年6月29日
