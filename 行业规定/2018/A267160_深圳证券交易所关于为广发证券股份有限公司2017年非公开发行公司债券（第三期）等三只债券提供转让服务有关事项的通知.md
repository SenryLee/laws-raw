# 深圳证券交易所关于为广发证券股份有限公司2017年非公开发行公司债券（第三期）等三只债券提供转让服务有关事项的通知

## 关于为广发证券股份有限公司2017年非公开发行公司债券（第三期）等三只债券提供转让服务有关事项的通知

各会员单位：

广发证券股份有限公司2017年非公开发行公司债券（第三期）、 深圳市海王生物工程股份有限公司2018年非公开发行公司债券（第一期）、 广西柳工集团有限公司2018年非公开发行公司债券（第二期）定于2018年8月7日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、广发证券股份有限公司2017年非公开发行公司债券（第三期）证券代码“114235”，证券简称“17广发05”，发行总额30亿元，票面利率5%，债券期限2年。

2、深圳市海王生物工程股份有限公司2018年非公开发行公司债券（第一期）证券代码“114353”，证券简称“18海王01”，发行总额8亿元，票面利率7%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

3、广西柳工集团有限公司2018年非公开发行公司债券（第二期）证券代码“114355”，证券简称“18柳工02”，发行总额3.5亿元，票面利率6.5%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所
