# 中国创盈市场服务有限公司关于深港通下的港股通股票名单调整的公告

## 关于深港通下的港股通股票名单调整的公告

因郑州银行（06196）相应A股上市满10个交易日，且其在香港市场价格稳定期已结束，根据《深圳证券交易所深港通业务实施办法》的有关规定，港股通股票名单发生调整并自今日起生效，相关调整信息如下：

|  |  |  |
| --- | --- | --- |
| 代码 | 简称 | 调整方向 |
| 06196 | 郑州银行 | 调入 |
