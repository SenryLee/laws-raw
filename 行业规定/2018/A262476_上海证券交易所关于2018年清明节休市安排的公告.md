# 上海证券交易所关于2018年清明节休市安排的公告

## 关于2018年清明节休市安排的公告

上证公告〔2018〕8号

根据《关于上海证券交易所2018年全年休市安排的通知》（上证公告〔2017〕26号），上海证券交易所现将2018年清明节休市安排通知如下：

4月5日（星期四）至4月7日（星期六）休市，4月9日（星期一）起照常开市。另外，4月8日（星期日）为周末休市。

请市场参与人据此安排有关工作。

上海证券交易所

二○一八年三月二十二日
