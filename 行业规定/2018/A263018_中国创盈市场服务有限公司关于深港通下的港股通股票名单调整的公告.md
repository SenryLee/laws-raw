# 中国创盈市场服务有限公司关于深港通下的港股通股票名单调整的公告

## 关于深港通下的港股通股票名单调整的公告

因京城机电股份在上海证券交易所上市的A股撤销风险警示、东北电气在深圳证券交易所上市的A股被实施风险警示，根据《深圳证券交易所深港通业务实施办法》的有关规定，港股通股票名单发生调整并自今日起生效，相关调整信息如下：

|  |  |  |
| --- | --- | --- |
| 代码 | 简称 | 调整方向 |
| 00187 | 京城机电股份 | 调入 |
| 00042 | 东北电气 | 调出 |
