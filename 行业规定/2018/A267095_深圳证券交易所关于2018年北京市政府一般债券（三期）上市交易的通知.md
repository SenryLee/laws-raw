# 深圳证券交易所关于2018年北京市政府一般债券（三期）上市交易的通知

## 关于2018年北京市政府一般债券（三期）上市交易的通知

各市场参与人：

2018年北京市政府一般债券（三期）已发行结束，根据财政部有关规定，本期债券于2018年8月3日起在本所上市交易。

本期债券为7年期固定利率附息债，证券编码“106681”，证券简称“北京1803”，票面利率3.53％，标准交易单位“10张”，2025年8月1日到期还本并支付最后一期利息。

特此通知
