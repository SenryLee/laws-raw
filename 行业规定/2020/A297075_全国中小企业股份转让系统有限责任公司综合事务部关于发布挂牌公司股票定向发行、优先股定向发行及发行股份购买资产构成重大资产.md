# 全国中小企业股份转让系统有限责任公司综合事务部关于发布挂牌公司股票定向发行、优先股定向发行及发行股份购买资产构成重大资产重组且发行后股东累计超过200人申请文件受理检查要点的通知

## 关于发布挂牌公司股票定向发行、优先股定向发行及发行股份购买资产构成重大资产重组且发行后股东累计超过200人申请文件受理检查要点的通知

股转系统办发〔2020〕138号

各市场参与人：

为提高挂牌公司股票定向发行、优先股定向发行及发行股份购买资产构成重大资产重组且发行后股东累计超过200人的申请文件受理工作透明度，全国中小企业股份转让系统有限责任公司制定了《挂牌公司股票定向发行申请文件受理检查要点》《挂牌公司优先股定向发行申请文件受理检查要点》和《挂牌公司发行股份购买资产构成重大资产重组且发行后股东累计超过200人申请出具自律监管意见文件的受理检查要点》，现予以公布，自公布之日起施行。

特此通知。

附件：1.挂牌公司股票定向发行申请文件受理检查要点

2.挂牌公司优先股定向发行申请文件受理检查要点

3.挂牌公司发行股份购买资产构成重大资产重组且发行后股东累计超过200人申请出具自律监管意见文件的受理检查要点

全国股转公司综合事务部（总经理办公室）

2020年11月20日

| 优先股定向发行发行申请文件受理检查要点 | |
| 申请材料目录 | 检查要点 |
| 文件形式要求 | 1、申请文件与中国证监会及全国股转公司规定的文件目录相符；  　　2、公司报送申请文件应提交原件一份，一份与书面文件一致的电子版光盘（word文件要求可编辑）；  　　3、本检查要点要求签字处，均应为本人亲笔签字；如由其他人代签，应同时提交授权书；法人授权书应加盖法人公章；  　　4、申请文件的封面和侧面应标明“XX公司优先股发行及挂牌申请文件”字样，扉页应标明挂牌公司法定代表人、董事会秘书或信息披露事务负责人，主办券商主管领导、项目负责人，以及相关中介机构项目负责人姓名、电话、传真等联系方式；  　　5、申请文件章与章之间、节与节之间应有明显的分隔标识，文件中的页码应与目录中的页码相符。申请文件应采用标准A4纸张双面印刷（需提供原件的历史文件除外）。  　　6、本检查要点要求提交的所有文件均应为原件且加盖骑缝章；发行人不能提供有关文件原件的，应当由律师鉴证并加盖律师事务所公章，或由出文单位盖章，以保证与原件一致；如原出文单位不再存续，由承继其职权的单位或作出撤销决定的单位出文证明文件的真实性。 |
| 1.优先股发行及挂牌申请登记表（豁免核准情形适用）  　　优先股发行申报及挂牌申请登记表（核准情形适用） | 1、按照指引附件制作；  　　2、全体董事签字并加盖发行人公章。 |
| 2.公司向全国股转公司提交的关于本次优先股发行及挂牌的申请报告（豁免核准情形适用）  　　公司向全国股转公司提交的申请出具关于本次定向发行优先股的自律监管意见的报告（核准情形适用） | 申请报告应当加盖发行人公章。 |
| 3. 公司关于本次发行的董事会决议 | 1.决议正文后，应当由参会董事签字，并加盖发行人公章；  　　2.未参会董事如授权其他董事表决，需出具授权委托书。 |
| 4. 公司关于本次发行的股东大会决议 | 1.决议正文后，应当由参与表决的股东签字或加盖发行人公章，参与表决的股东为非自然人的，应加盖公章；  　　2.股东委托代理人参加会议的，需出具授权委托书。 |
| 5.特定行业主管部门出具的监管意见（如有） | —— |
| 6.定向发行优先股说明书 | 一、材料扉页应载有声明：  　　“本公司及控股股东、实际控制人、全体董事、监事、高级管理人员承诺定向发行优先股说明书不存在虚假记载、误导性陈述或重大遗漏，并对其真实性、准确性、完整性承担个别和连带的法律责任。  　　本公司负责人和主管会计工作的负责人、会计机构负责人保证定向发行优先股说明书中财务会计资料真实、完整。  　　中国证监会、全国股份转让系统公司对本公司定向发行优先股所作的任何决定或意见，均不表明其对本公司优先股的价值或投资者的收益作出实质性判断或者保证。任何与之相反的声明均属虚假不实陈述。  　　根据《证券法》的规定，本公司经营与收益的变化，由本公司自行负责，由此变化引致的投资风险，由投资者自行负责。”  　　二、材料正文后依次附以下签字盖章页：  　　1、公司全体董事、监事、高级管理人员应在定向发行优先股说明书正文的尾页声明：  　　“本公司全体董事、监事、高级管理人员承诺本定向发行优先股说明书不存在虚假记载、误导性陈述或重大遗漏，并对其真实性、准确性、完整性承担个别和连带的法律责任。”  　　声明应由全体董事、监事、高级管理人员签名，并由公司加盖公章。  　　2、公司控股股东、实际控制人应在定向发行优先股说明书正文的尾页声明：  　　“本公司或本人承诺本定向发行优先股说明书不存在虚假记载、误导性陈述或重大遗漏，并对其真实性、准确性和完整性承担个别和连带的法律责任。”  　　声明应由控股股东、实际控制人签名，加盖公章。  　　（控股股东、实际控制人为国资、外资等相关主管部门的，不强制签名盖章）  　　3、主办券商应对公司定向发行优先股说明书的真实性、准确性、完整性进行核查，并在定向发行优先股说明书正文后声明：  　　“本公司已对定向发行优先股说明书进行了核查，确认不存在虚假记载、误导性陈述或重大遗漏，并对其真实性、准确性和完整性承担相应的法律责任。”  　　声明应由法定代表人、项目负责人签名，并由主办券商加盖公章。  　　4、为公司定向发行优先股提供服务的证券服务机构应在定向发行优先股说明书正文后声明：  　　“本机构及经办人员（经办律师、签字注册会计师、签字注册资产评估师、资信评级人员）已阅读定向发行优先股说明书，确认定向发行优先股说明书与本机构出具的专业报告（法律意见书、审计报告、资产评估报告或资产估值报告、资信评级报告等）无矛盾之处。本机构及经办人员对申请人在定向发行优先股说明书中引用的专业报告的内容无异议，确认定向发行优先股说明书不致因上述内容而出现虚假记载、误导性陈述或重大遗漏，并对其真实性、准确性和完整性承担相应的法律责任。”  　　声明应由经办人员及所在机构负责人签名，并由机构加盖公章。 |
