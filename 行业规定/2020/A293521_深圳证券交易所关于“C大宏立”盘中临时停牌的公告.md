# 深圳证券交易所关于“C大宏立”盘中临时停牌的公告

## 关于“C大宏立”盘中临时停牌的公告

“C大宏立”（300865）盘中成交价较开盘价首次上涨达到或超过30%，根据《深圳证券交易所创业板交易特别规定》等有关规定，本所自今日11时28分18秒起对该证券实施临时停牌，于13时08分19秒复牌。

本所郑重提示广大投资者注意投资风险，理性投资。

特此公告

深圳证券交易所

2020年08月26日
