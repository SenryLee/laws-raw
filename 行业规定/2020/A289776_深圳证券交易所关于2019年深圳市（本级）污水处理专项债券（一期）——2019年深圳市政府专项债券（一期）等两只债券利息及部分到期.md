# 深圳证券交易所关于2019年深圳市（本级）污水处理专项债券（一期）——2019年深圳市政府专项债券（一期）等两只债券利息及部分到期兑付有关事项的通知

## 关于2019年深圳市（本级）污水处理专项债券（一期）——2019年深圳市政府专项债券（一期）等两只债券利息及部分到期兑付有关事项的通知

各市场参与人：

2019年深圳市（本级）污水处理专项债券（一期）——2019年深圳市政府专项债券（一期）、2019年深圳市（福田区）公立医院专项债券（一期）——2019年深圳市政府专项债券（五期）将于2020年3月30日支付利息及部分到期兑付。为做好上述债券的利息支付及兑付工作，现将有关事项通知如下：

一、2019年深圳市（本级）污水处理专项债券（一期）——2019年深圳市政府专项债券（一期）证券代码为“104558”，证券简称为“深圳1902”，是2019年3月29日发行的3年期债券，票面利率为3%，每年支付1次利息，每百元面值债券本次利息及部分兑付款项共计103元。

二、2019年深圳市（福田区）公立医院专项债券（一期）——2019年深圳市政府专项债券（五期）证券代码为“104562”，证券简称为“深圳1906”，是2019年3月29日发行的7年期债券，票面利率为3.37%，每年支付1次利息，每百元面值债券本次利息及部分兑付款项共计103.37元。

三、从2020年3月20日起停办上述地方政府债的转托管及调帐业务。

四、上述债券付息及部分兑付债权登记日为2020年3月27日，凡于当日收市后持有上述债券的投资者，享有获得本次利息及部分兑付款项的权利。2020年3月30日除息交易。

五、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息及部分兑付款项后，将其划入各证券商的清算备付金账户，并由证券商将兑付资金及时划入各投资者的资金账户。

深圳证券交易所
