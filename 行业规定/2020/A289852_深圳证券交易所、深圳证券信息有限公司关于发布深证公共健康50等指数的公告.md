# 深圳证券交易所、深圳证券信息有限公司关于发布深证公共健康50等指数的公告

## 关于发布深证公共健康50等指数的公告

为反映深圳证券市场相关产业和区域上市公司的表现，助力资本市场服务实体经济，满足多元化指数投资工具需求，深圳证券交易所和深圳证券信息有限公司定于2020年5月8日发布深证公共健康50指数、深证长江经济带100指数、深证云科技50指数、深证生物医药50指数和深证消费电子50指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 指数基日 | 基日点位 |
| 399277 | 深证公共健康50指数 | 公共健康 | 2012年12月31日 | 1000 |
| 399278 | 深证长江经济带100指数 | 长江100 | 2012年12月31日 | 1000 |
| 399279 | 深证云科技50指数 | 云科技50 | 2012年12月31日 | 1000 |
| 399280 | 深证生物医药50指数 | 生物50 | 2012年12月31日 | 1000 |
| 399281 | 深证消费电子50指数 | 电子50 | 2012年12月31日 | 1000 |

上述指数均以深交所上市公司为选样范围，分别从公共健康产业、长江经济带、云科技产业、生物医药产业和消费电子产业的公司中，选取总市值排名靠前的相应数量股票作为样本股。指数采用自由流通市值加权，于每年6月、12月的第二个星期五的下一个交易日进行样本股定期调整。

相关指数均包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关深证公共健康50等五条指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
