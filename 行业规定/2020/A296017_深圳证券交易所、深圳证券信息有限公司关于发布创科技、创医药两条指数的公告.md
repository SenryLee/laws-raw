# 深圳证券交易所、深圳证券信息有限公司关于发布创科技、创医药两条指数的公告

## 关于发布创科技、创医药两条指数的公告

为体现深交所创业板市场相关产业上市公司的运行特征，深圳证券交易所和深圳证券信息有限公司定于2020年10月26日发布创业板科技指数、创业板医药卫生指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 指数基日 | 基日点位 |
| 399276 | 创业板科技指数 | 创科技 | 2012年12月31日 | 1000 |
| 399275 | 创业板医药卫生指数 | 创医药 | 2012年12月31日 | 1000 |

创业板科技指数和创业板医药卫生指数均以深交所创业板上市公司为选样范围。创业板科技指数从科技相关产业中选取50只研发投入高、基本面表现良好、流动性好的股票构成样本股。创业板医药卫生指数从医药卫生行业中选取50只市值大、流动性好的股票构成样本股。

上述指数均包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关两条指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
