# 深圳证券交易所、深圳证券信息有限公司关于发布深证创新100等指数的公告

## 关于发布深证创新100等指数的公告

为反映深圳证券市场科技创新公司的表现，促进指数化投资发展和创新，为投资者提供更丰富的指数化投资工具，深圳证券交易所和深圳证券信息有限公司定于2020年2月18日发布深证创新100指数、深证大数据50指数、深证机器人50指数、深证人工智能50指数和深证物联网50指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 指数基日 | 基日点位 |
| 399088 | 深证创新100指数 | 深创100 | 2012年12月31日 | 1000 |
| 399282 | 深证大数据50指数 | 大数据50 | 2012年12月31日 | 1000 |
| 399283 | 深证机器人50指数 | 机器人50 | 2012年12月31日 | 1000 |
| 399284 | 深证人工智能50指数 | AI 50 | 2012年12月31日 | 1000 |
| 399285 | 深证物联网50指数 | 物联网50 | 2012年12月31日 | 1000 |

以上指数均以深交所上市公司为选样范围。深证创新100指数基于企业属性、创新投入、创新产出、成长性、代表性五个维度，选取综合排名最高的100只股票。深证大数据50指数、深证机器人50指数、深证人工智能50指数和深证物联网50指数筛选业务领域分别属于大数据产业、机器人产业、人工智能产业和物联网产业的公司构成选样空间，按近半年日均总市值从高到低排序，筛选排名前50名的股票构成样本股。指数采用自由流通市值加权，于每年6月、12月的第二个星期五的下一个交易日进行样本股定期调整。

上述指数均包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关深证创新100等五条指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
