# 深圳证券交易所关于支付2017年河北省政府一般债券（一期）等三只债券利息有关事项的通知

## 关于支付2017年河北省政府一般债券（一期）等三只债券利息有关事项的通知

各市场参与人：

2017年河北省政府一般债券（一期）、2017年河北省政府一般债券（二期）、2017年河北省政府专项债券（一期）将于2020年3月10日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2017年河北省政府一般债券（一期）证券代码为“107531”，证券简称为“河北1701”，是2017年3月10日发行的5年期债券，票面利率为3.2％，每年支付1次利息，每百元面值债券本次可获利息3.2元。

二、2017年河北省政府一般债券（二期）证券代码为“107532”，证券简称为“河北1702”，是2017年3月10日发行的7年期债券，票面利率为3.35％，每年支付1次利息，每百元面值债券本次可获利息3.35元。

三、2017年河北省政府专项债券（一期）证券代码为“107533”，证券简称为“河北1703”，是2017年3月10日发行的5年期债券，票面利率为3.2％，每年支付1次利息，每百元面值债券本次可获利息3.2元。

四、从2020年3月2日至2020年3月9日停办上述地方政府债的转托管及调帐业务。

五、上述债券付息债权登记日为2020年3月9日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2020年3月10日除息交易。

六、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
