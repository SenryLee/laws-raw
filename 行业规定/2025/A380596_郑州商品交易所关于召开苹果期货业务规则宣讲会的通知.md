# 郑州商品交易所关于召开苹果期货业务规则宣讲会的通知

## 关于召开苹果期货业务规则宣讲会的通知

郑商函〔2025〕664号

各市场参与主体：

2025年8月29日，郑州商品交易所（以下简称郑商所）发布了《关于发布苹果期货业务细则修订案的公告》《关于发布苹果期货替代交割品升贴水的公告》。为进一步加强市场主体全面、深入理解本次苹果期货规则修订的要点和变化，促进苹果期货功能更好发挥，郑商所将通过线上会议的形式举办苹果期货业务规则宣讲会，现邀请有关产业企业、会员单位、相关个人等参会。具体通知如下：

一、会议议程

时间：2025年9月5日15:30-17:00

主题：苹果期货业务规则宣讲会

|  |  |  |
| --- | --- | --- |
| 时间 | 内容 | 宣讲部门 |
| 15:30-16:30 | 《郑州商品交易所鲜苹果期货业务细则》修订要点讲解 | 郑商所商品二部 |
| 16:30-17:00 | 交流答疑 |

二、参会方式

本次宣讲会采取线上腾讯会议的方式举办，参加线上会议方式如下：

方式一：通过PC端或手机端腾讯会议APP，输入会议号：436-999-365，直接参会。

方式二：扫描以下二维码参会

方式三：通过PC端浏览器方式，点击如下链接：https://meeting.tencent.com/dm/Ge0M0qmIUMQz，直接参会。

各相关单位和个人于会议期间均可登录（提前15分钟开放登录），进入会议后请按照“单位名称-姓名”修改昵称。
