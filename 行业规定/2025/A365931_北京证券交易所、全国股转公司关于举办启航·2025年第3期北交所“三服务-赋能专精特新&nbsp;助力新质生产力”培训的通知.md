# 北京证券交易所、全国股转公司关于举办启航·2025年第3期北交所“三服务-赋能专精特新&nbsp;助力新质生产力”培训的通知

## 关于举办启航·2025年第3期北交所“三服务-赋能专精特新 助力新质生产力”培训的通知

各市场主体：

为更好发挥资本市场专精特新中小企业培育功能，深入践行北交所、新三板“开门服务、直达服务、精准服务”的“三服务”理念，推动专精特新中小企业利用资本市场实现跨越式发展，在工业和信息化部中小企业局的支持下，北交所、全国股转公司联合重庆市委金融办、重庆市经信委、重庆证监局，于9月在重庆举办启航?2025年第3期北交所“三服务-赋能专精特新 助力新质生产力”培训，具体安排如下：

一、培训时间

2025年9月19日

二、培训地点

重庆大都会凯悦酒店（重庆市渝中区邹容路68号）。

三、培训对象

专精特新企业负责挂牌上市事宜的高级管理人员，每家单位限报2人。

四、培训议程

|  |  |  |  |
| --- | --- | --- | --- |
| 时间 | 课程内容 | 主讲人 | |
| 09:00-10:20 | 新“国九条”下北交所市场制度特点与优势 | | 北交所西南基地  相关负责人 |
| 10:30-11:30 | 新三板挂牌审查及融资并购制度解析 | | 全国股转公司  挂牌审查部业务骨干 |
| 13:30-14:30 | 北交所上市审核要点 | | 北交所  企业培训部业务骨干 |

| 15:30-16:00 | 北交所上市公司“面对面” | | 北交所上市公司相关负责人 |

六、培训费用

本次培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费及其他费用请学员自理。如需预订培训酒店住宿，请联系酒店李经理13635480249，并报“北交所培训”获取协议价格。

七、温馨提示

1、培训期间课务组不会组织与培训无关的活动，请学员注意个人财产安全和食品安全。

2、学员可带足名片，以便培训期间相互交流。

3、培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
