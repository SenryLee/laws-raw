# 全国股转公司关于举办护航·主办券商尽职调查指引解读专题培训的通知

## 关于举办护航·主办券商尽职调查指引解读专题培训的通知

各主办券商：

6月20日，全国股转公司正式发布《全国中小企业股份转让系统主办券商尽职调查工作指引》，为及时向相关市场主体传递规则要求，拟于7-8月举办两期主办券商培训，深入解读规则修订背景及具体内容。培训安排如下：

一、培训时间、地点

北京场培训时间：2025年7月18日

培训地点：中国职工之家饭店（北京市西城区复兴门外大街真武庙路1号）

广州场培训时间：2025年8月8日

培训地点：广州凯旋华美达大酒店（广州市越秀区广州大道中明月一路九号）

二、培训对象

主办券商从事推荐挂牌及质控、内核业务相关人员。

三、培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 护航·主办券商尽职调查指引解读专题培训 | | | |
| 时间 | | 课程主题 | 主讲部门 |
| 7月18日、  8月8日 | 09:30-11:30 | 《主办券商尽职调查工作指引》解读 | 全国股转公司  挂牌审查部 |

四、报名时间及方式

两场培训内容相同，鼓励学员选择就近参与培训。

本次培训需收集报名信息，请您扫码或点击链接进行报名。因培训名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、公司代码、报名人员信息及取消原因等）。报名成功后，如未参与培训或缺勤，相关情况将反馈任职公司。

报名截止时间：2025年7月11日（周五）17:00，过期或额满后报名不再受理，请尽早完成报名。

五、培训费用

培训不收取培训费。餐费、住宿费、交通费及其他费用请学员自理。学员如需预定培训酒店住宿，可自行联系中国职工之家饭店（北京场）贾经理13811637138，广州凯旋华美达大酒店（广州场）020-87372988转订房部，报“全国股转公司培训”获取优惠价格。

六、培训考勤及相关提示

1、课务组将进行考勤并形成培训记录，缺勤情况将反馈任职公司，请学员提前做好安排。

2、培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人信息安全并增强防范意识。

3、培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
