# 全国股转公司关于举办挂牌公司2025年半年报编制与披露培训的通知

## 关于举办挂牌公司2025年半年报编制与披露培训的通知

各市场主体：

为保障挂牌公司顺利开展2025年半年报编制与披露工作，提高半年报信息披露质量，全国股转公司拟于7月18日在线举办挂牌公司2025年半年报编制与披露培训。培训具体安排如下：

一、培训对象

基础层、创新层挂牌公司信息披露负责人、信披相关人员以及挂牌公司主办券商持续督导人员。

二、培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 挂牌公司2025年半年报编制与披露培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 7月18日（周五） | 14:00-15:00 | 挂牌公司2025年半年报编制与披露重点讲解 | 全国股转公司  挂牌公司管理一部  业务骨干 |
| 15:00-16:00 | 挂牌公司半年报编制工具使用及报送注意事项 | 中证股转科技公司  业务骨干 |

注：最终培训内容以实际课程安排为准

三、培训形式

本次培训采用线上直播讲解的模式，参会人员可通过直播链接参加培训，建议选择网络较好的地点以保证视频及语音的流畅。
