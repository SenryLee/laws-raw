# 中国结算关于2026年部分节假日休市期间证券资金清算交收安排的通知

各结算参与单位：

根据中国证监会关于2026年部分节假日放假和休市安排的相关通知精神和上海证券交易所、深圳证券交易所、全国中小企业股份转让系统、北京证券交易所、香港证券交易所等交易场所休市安排，现将2026年部分节假日休市期间资金清算交收安排通知如下。

一、元旦休市4天（含双休日，2026年1月1日至1月4日）

1. 2025年12月29日、12月30日、12月31日为新增港股通交易日。

2. 2025年12月31日发生的证券交易（仅属T+1交收的交易品种，以下同）和当日到期的债券通用质押式回购，资金清算日为2025年12月31日，资金交收日为2026年1月5日。

3. 2026年1月5日发生的证券交易和2026年1月1日至2026年1月5日到期的债券通用质押式回购，资金清算日为2026年1月5日，资金交收日为2026年1月6日。

4. 2025年12月29日、30日、31日发生的B股交易和退市B股交易，资金交收日分别为2026年1月5日、6日、7日。

二、春节休市10天（含双休日，2026年2月14日至2月23日）

1. 2026年2月12日、2月13日为新增港股通交易日。

2. 2026年2月13日发生的证券交易和当日到期的债券通用质押式回购，资金清算日为2026年2月13日，资金交收日为2026年2月24日。

3. 2026年2月24日发生的证券交易和2026年2月14日至2月24日到期的债券通用质押式回购，资金清算日为2026年2月24日，资金交收日为2026年2月25日。

4. 2026年2月11日、12日、13日发生的B股交易和退市B股交易，资金交收日分别为2026年2月24日、25日、26日。

三、清明节休市3天（含双休日，2026年4月4日至4月6日）

1. 2026年4月3日发生的证券交易和当日到期的债券通用质押式回购，资金清算日为2026年4月3日，资金交收日为2026年4月7日。

2. 2026年4月7日发生的证券交易和2026年4月4日至4月7日到期的债券通用质押式回购，资金清算日为2026年4月7日，资金交收日为2026年4月8日。

3. 2026年4月1日、2日、3日发生的沪市B股交易，资金交收日分别为2026年4月7日、8日、9日。2026年4月1日、2日、3日发生的深市B股交易和退市B股交易，资金交收日为2026年4月8日、8日、9日。

四、劳动节休市5天（含双休日，2026年5月1日至5月5日）

1. 2026年4月29日、4月30日为新增港股通交易日。

2. 2026年4月30日发生的证券交易和当日到期的债券通用质押式回购，资金清算日为2026年4月30日，资金交收日为2026年5月6日。

3. 2026年5月6日发生的证券交易和2026年5月1日至5月6日到期的债券通用质押式回购，资金清算日为2026年5月6日，资金交收日为2026年5月7日。

4. 2026年4月28日、29日、30日发生的B股交易和退市B股交易，资金交收日分别为2026年5月6日、7日、8日。

五、端午节休市3天（含双休日，2026年6月19日至6月21日）

1. 2026年6月18日发生的证券交易和当日到期的债券通用质押式回购，资金清算日为2026年6月18日，资金交收日为2026年6月22日。

2. 2026年6月22日发生的证券交易和2026年6月19日至6月22日到期的债券通用质押式回购，资金清算日为2026年6月22日，资金交收日为2026年6月23日。

3. 2026年6月16日、17日、18日发生的B股交易和退市B股交易，资金交收日分别为2026年6月22日、23日、24日。

六、中秋节休市3天（含双休日，2026年9月25日至9月27日）

1. 2026年9月23日、9月24日为新增港股通交易日。

2. 2026年9月24日发生的证券交易和当日到期的债券通用质押式回购，资金清算日为2026年9月24日，资金交收日为2026年9月28日。

3. 2026年9月28日发生的证券交易和2026年9月25日至9月28日到期的债券通用质押式回购，资金清算日为2026年9月28日，资金交收日为2026年9月29日。

4. 2026年9月22日、23日、24日发生的B股交易和退市B股交易，资金交收日分别为2026年9月28日、29日、30日。

七、国庆节休市7天（含双休日，2026年10月1日至10月7日）

1. 2026年9月29日、9月30日为新增港股通交易日。

2. 2026年9月30日发生的证券交易和当日到期的债券通用质押式回购，资金清算日为2026年9月30日，资金交收日为2026年10月8日。

3. 2026年10月8日发生的证券交易和2026年10月1日至10月8日到期的债券通用质押式回购，资金清算日为2026年10月8日，资金交收日为2026年10月9日。

4. 2026年9月28日、29日、30日发生的沪市B股交易，资金交收日分别为2026年10月8日、9日、13日。2026年9月28日、29日、30日发生的深市B股交易和退市B股交易，资金交收日分别为2026年10月8日、9日、12日。

八、2026年部分节假日港股通业务清算交收安排，见附件1。

九、2026年部分节假日港股通权益登记日安排，见附件2。

十、2026年美国公众假日（非美元清算日）期间沪市B股交收业务安排，见附件3。

十一、2026年度香港公众假日期间深市B股和全国股转系统退市B股业务交收安排，见附件4。

十二、2026年部分香港公众假期及美元非清算日沪市B转H业务特殊交易交收安排，见附件5。

十三、2026年度香港公众假日期间深市B转H业务交收安排，见附件6。

十四、2026年度香港公众假日期间H股“全流通”业务交收安排，见附件7。

请各参与单位据此做好工作安排。如遇临时调整，本公司另行通知。

4. 2026年度香港公众假日期间深市B股和全国股转系统退市B股业务交收安排

5. 2026年部分香港公众假期及美元非清算日沪市B转H业务特殊交易交收安排
