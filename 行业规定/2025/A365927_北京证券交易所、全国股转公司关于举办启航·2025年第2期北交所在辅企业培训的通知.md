# 北京证券交易所、全国股转公司关于举办启航·2025年第2期北交所在辅企业培训的通知

## 关于举办启航·2025年第2期北交所在辅企业培训的通知

各在辅企业：

为贯彻落实新“国九条”精神，及时传递最新监管政策，帮助在辅企业做好上市前准备工作，进一步提升企业上市质效，北京证券交易所、全国股转公司拟于8月28日在大连举办启航·2025年第2期北交所在辅企业培训，具体安排如下：

一、培训时间

2025年8月28日

二、培训地点

大连国际金融会议中心（大连市西岗区滨海西路68号）

三、培训对象

北交所在辅企业、拟上市企业的实际控制人、董事长、总经理、董事会秘书等，每家公司限报2人。

四、培训课程

|  |  |  |
| --- | --- | --- |
| 时间 | 课程内容 | 主讲部门 |
| 9:00-10:00 | 北交所最新政策解读及上市路径解析 | 北交所北方基地 |
| 10:00-11:00 | 北交所上市审核关注要点 | 北交所企业培训部 |
| 11:00-12:00 | 直联机制视角下挂牌上市衔接事项解读 | 全国股转公司  挂牌公司管理二部 |
| 13:30-15:00 | 北交所现场检查和现场督导关注要点 | 北交所监管执行部 |
| 15:00-16:00 | 在辅阶段持续监管重点关注事项 | 全国股转公司  挂牌公司管理一部 |

注：最终培训内容以实际课程安排为准

五、报名时间及方式

本次培训需收集报名信息，请您扫码或点击链接进行报名。请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、公司代码、报名人员信息及取消原因等）。报名成功后，未经请假缺席培训的人员，将影响后续培训资格。

报名截止时间：2025年8月26日（周二）中午12:00，过期或额满后报名不再受理，请务必尽早完成报名。

六、培训费用

本次培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费及其他费用请学员自理。如需预订培训酒店住宿，请联系酒店黄经理15942688467，并报“北交所培训”获取协议价格。

七、培训考勤

请学员本人参加培训，他人不得替代，请学员带好身份证，以便考勤时验证。

课务组每半天进行考勤并形成培训记录，请学员提前做好安排，保证全程参与。

八、温馨提示

1、培训期间课务组不会组织与培训无关的活动，请学员注意个人财产安全和食品安全。

2、培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。

九、联系方式

咨询时间：交易日 上午8:30-11:30；下午14:00-17:00。

咨询电话：010-63889551、010-63889802
