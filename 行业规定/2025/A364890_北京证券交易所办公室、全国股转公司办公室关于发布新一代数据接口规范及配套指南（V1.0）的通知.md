# 北京证券交易所办公室、全国股转公司办公室关于发布新一代数据接口规范及配套指南（V1.0）的通知

## 关于发布新一代数据接口规范及配套指南（V1.0）的通知

北证办发〔2025〕75号

各市场参与者：

为满足前期市场反馈的优化诉求，进一步优化市场服务，北京证券交易所和全国股转公司共同编制了《北京证券交易所、全国中小企业股份转让系统交易数据接口规范（二进制V1.0）》《北京证券交易所、全国中小企业股份转让系统行情数据接口规范（二进制V1.0）》《北京证券交易所、全国中小企业股份转让系统数据文件接口规范（V1.0）》《北京证券交易所、全国中小企业股份转让系统组播行情数据分发协议（V1.0）》《北京证券交易所市场参与者技术系统开发指南之债券现券交易业务（V1.0）》，现予以正式发布。

上述文档目前仅适用于北京证券交易所债券现券交易业务。请各市场参与者根据业务需要，按照上述文档要求在2025年9月底前做好参与市场测试的准备工作。如有疑问，请及时联系。咨询电话：400-626-3333。

附件：

1.北京证券交易所、全国中小企业股份转让系统交易数据接口规范（二进制V1.0）

2.北京证券交易所、全国中小企业股份转让系统行情数据接口规范（二进制V1.0）

3.北京证券交易所、全国中小企业股份转让系统数据文件接口规范（V1.0）

4.北京证券交易所、全国中小企业股份转让系统组播行情数据分发协议（V1.0）

5.北京证券交易所市场参与者技术系统开发指南之债券现券交易业务（V1.0）

北京证券交易所办公室 全国股转公司办公室

2025年8月12日
