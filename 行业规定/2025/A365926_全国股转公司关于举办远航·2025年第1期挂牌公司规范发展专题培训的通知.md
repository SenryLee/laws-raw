# 全国股转公司关于举办远航·2025年第1期挂牌公司规范发展专题培训的通知

## 关于举办远航·2025年第1期挂牌公司规范发展专题培训的通知

各挂牌公司：

为进一步强化挂牌公司高级管理人员的规范意识，推动完善公司治理，促进挂牌公司高质量发展，全国股转公司拟于8月21日在上海举办远航·2025年第1期挂牌公司规范发展专题培训。具体安排如下：

一、培训时间、地点

培训时间：2025年8月21日

培训地点：上海虹桥雅高美爵酒店（上海市长宁区仙霞路369号）

二、培训对象

挂牌公司实际控制人、董事长、总经理、董事会秘书、财务总监，每家公司限报2人。

三、培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 远航·2025年第1期挂牌公司规范发展专题培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 8月21日  （周四） | 09:00-10:00 | 挂牌公司持续监管情况及规范运作重点问题 | 全国股转公司  挂牌公司管理一部  业务骨干 |
| 10:10-11:40 | 穿透式监管下企业内控建设要点 | 会计师事务所  专家 |
| 13:30-14:30 | 新三板并购重组制度解读及审核关注点 | 全国股转公司  挂牌审查部  业务骨干 |
| 14:40-16:10 | 挂牌公司长期激励方案设计实务 | 咨询机构  专家 |

注：最终培训内容以实际课程安排为准

四、报名时间及方式

本次培训需收集报名信息，请您扫码或点击链接进行报名。请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、公司代码、报名人员信息及取消原因等）。

报名截止时间：2025年8月19日（周二）12:00，过期或额满后报名不再受理，请务必尽早完成报名。

五、培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费及其他费用请学员自理。如需预定培训酒店住宿请联系鲍经理13918825222，并报“全国股转公司培训”获取协议价。

六、培训考勤

必须学员本人参加培训，他人不得替代，请学员带好身份证，以便考勤时验证。

课务组每半天进行考勤并形成培训记录，缺勤情况将反馈监管机构，请学员提前做好安排，保证全程参与。

七、温馨提示

1、培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2、学员可带足名片，以便培训期间相互交流。

3、培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。

八、联系方式

咨询时间：交易日 上午8:30-11:30；下午14:00-17:00

咨询电话：010-63889551
