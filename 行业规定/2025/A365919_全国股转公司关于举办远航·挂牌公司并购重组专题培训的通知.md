# 全国股转公司关于举办远航·挂牌公司并购重组专题培训的通知

## 关于举办远航·挂牌公司并购重组专题培训的通知

各挂牌公司：

为更好落实二十届三中全会精神和新“国九条”对活跃并购重组市场的要求，帮助挂牌公司利用并购重组工具，提升并购重组能力，拓宽挂牌公司资本运作视野，全国股转公司拟于5月23日在线举办远航·挂牌公司并购重组专题培训。具体安排如下：

**一、**参会人员

挂牌公司实际控制人、董事长、总经理、董事会秘书、财务总监及负责公司资本运作工作相关人员，培训名额有限，额满截止。

**二、**培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| 远航·挂牌公司并购重组专题培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 5月23日  （周五） | 14:00-15:30 | 新三板并购重组制度解读及审核关注点 | 全国股转公司  挂牌审查部  业务骨干 |
| 15:30-17:00 | 并购重组市场发展趋势与交易方案设计 | 证券公司  专家 |

注：最终培训内容以实际课程安排为准

**三、**培训形式

本期培训采用“腾讯会议”线上直播讲解的模式，学员可通过会议码参加培训。会议码将于培训前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

**四、**报名方式及截止时间

本次培训需收集报名信息。请您扫描下方二维码或者点击链接进行报名，报名截止时间为5月22日17:00。
