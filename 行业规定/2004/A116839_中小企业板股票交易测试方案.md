# 中小企业板股票交易测试方案

深市各会员单位、证券营业部：

为使市场参与者能更详细地了解中小企业板股票的交易特别规定，深圳证券交易所、上海证券交易所将于2004年6月5日（周六）共同提供交易环境供会员及相关单位进行交易测试使用。请相关单位做好测试的准备工作。现将与深圳市场相关的测试方案通知如下：

**一、**参测单位

1、　深圳证券交易所

2、　上海证券交易所

3、　 深圳证券通信公司

4、　 深市各会员及下属证券营业部

5、　 各其他相关单位

**二、**测试内容

1、　 深市发行的中小企业板股票的上市挂牌、交易。包括：委托申报、集合竞价、连续竞价、成交回报、实时行情、收盘集合竞价等。其间，模拟沪市中签投资者向上证所委托卖出所认购的深市股票。

2、　 其它深市证券品种的交易业务。

**三、**测试步骤及时间

测试时间为2004年6月5日9：00至11：30。

|  |  |  |
| --- | --- | --- |
| 步骤 | 时间 | 测试项目 |
| 1 | 9：15至10：30 | 集合竞价阶段，其中：10：25进行集合竞价撮合。 |
| 2 | 10：30至11：30 | 连续竞价阶段，11：00至11：05模拟中午休市。 　　中小企业板股票收盘价由11：27至11：30的集合竞价产生。 |
| 3 | 11：30后 | 参测单位进行系统恢复。 |

**五、**测试前准备工作

1、　 现有系统6月4日收市后的数据备份。

2、　 各参测单位请按测试方案自行复制生成002401至002420的股份数据。

3、　 制定内部测试计划和操作流程。

**六、**测试说明

1、　 本次测试不包含配售发行

2、 为使参测者充分验证中小企业板股票的开盘集合竞价与主板股票的不同，本次测试特将集合竞价撮合时间推后到10：25。请参测单位抓紧时间进行相关测试。

3、 测试日10：20至10：25，模拟挂牌的中小企业板股票不得撤单（002420除外）。

4、 002420模拟停牌至10：45，该股票在开盘前不揭示可能成交价及成交量（即与主板其他股票一样）。

5、 测试日中小企业板股票的收盘集合竞价时间为11：27至11：30，其间允许撤单。

6、 测试日挂出的另两只证券“测试A”及“测试B”（代码为002441及002442）为深交所内部测试使用，会员及其他参测单位无需理会。

7、 测试完毕后，无任何股份及资金结算数据发送给会员。

**七、**其他

1、　 中小企业板股票的相关交易规则，请参阅《中小企业板块交易特别规定》。

2、 参测单位做好详细的系统和数据备份及恢复计划，并据此做好各项备份和恢复工作。

3、 测试结束后，各参测单位将测试中发现的问题以电子邮件方式报至深交所（ssegcb@szse.cn），并请注明单位名称、联系人和电话。

4、本次测试为深、沪交易所联合测试，上海证券交易所会员单位请按照上证所的相关测试方案进行沪市系统测试的相关技术与数据准备。
