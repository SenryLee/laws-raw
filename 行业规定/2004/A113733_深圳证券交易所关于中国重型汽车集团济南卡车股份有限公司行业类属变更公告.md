# 深圳证券交易所关于中国重型汽车集团济南卡车股份有限公司行业类属变更公告

根据上市公司的申请，经本所确认，从2004年10月28日起调整中国重型汽车集团济南卡车股份有限公司的行业类属，具体变更如下：

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 序号 | 公司名称 | 证券代码 | 证券简称 | 调整前行业类属 | 调整后行业类属 |
| 1 | 中国重型汽车集团济南卡车股份有限公司 | 000951 | *ST重汽 | C76 电器机械及器材制造业 | C75 交通运输设备制造业 |
