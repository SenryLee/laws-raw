# 深圳证券交易所关于成交量统计指标发布的测试方案

**一、**参测单位

1、深圳证券交易所

2、深圳证券通信公司

3、各会员单位(自愿)

4、深交所行情的其他用户(自愿

)

**二、**测试项目

LOFs的交易。

行情库中增加成交量统计指标，计算、发送、接收及揭示相关指标数据，检验周边系统的适应性。

**三、**测试时间及步骤

测试时间为2004年12月11日(周六)8：45至11：30。详细步骤如下表：

```
步骤 　　时间 　　　　　　　　　测试项目

1　 　　9：15至9：30　　　　　　证券交易的集合竞价阶段，其中：9：25进行集合竞价撮合。 　　交易测试，行情接收。

2　 　　9：30至11：30　　　交易连续竞价阶段，10：30至10：35模拟中午休市。　　　交易测试，行情接收。

3　11：30后

系统恢复
```

**四、**测试内容及数据准备

1、本次测试以2004年12月10日(周五)深市所有证券的收盘行情、收市后的股份数据作为起始数据。

2、本次测试增加2只专用证券，如下表所示：

```
证券代号 　　证券简称 　　测试内容约定

159999　 　　测试LOF1 　　1)模拟进行交易和各项非交易业务处理；

2)开盘参考价为1.000元，涨跌幅限制为10%；

3)其结算数据由2004年12月10日“深发展A”(000001)的流通股份数据复制生成。

169999　 　　测试LOF2 　　1)模拟进行交易和各项非交易业务处理；

2)开盘参考价为1.011元。涨跌幅限制为10%；

3)其结算数据由2004年12月10日“一汽轿车”(000800)的流通股份数据复制生成。
```

3、159999(测试LOF1)的股份数据由2004年12月10日(周五)收市清算后000001(深发展A)的流通股份数据复制生成。请券商自行复制。

4、169999(测试LOF2)的股份数据由2004年12月10日(周五)收市清算后000008(一汽轿车)的流通股份数据复制生成。请券商自行复制。

5、本次测试在行情及证券信息库中增加如下成交量统计指标记录：

**五、**注意事项

1、行情库中发布成交量统计指标数据将于12月13日(周一)正式实施。

2、本次测试将不发送任何结算数据，敬请留意。

3、有关成交量统计指标的说明，请参见2004年10月11日深交所发布的《关于在行情库中增加成交量统计指标的通知》。

4、有关LOFs业务的相关说明，请参看《深圳证券交易所上市开放式基金业务规则》。

5、各参测单位于测试前做好系统和数据环境的备份工作以及测试数据的准备工作。

6、请各参测单位依据深交所和中国结算深圳分公司相关通知及数据接口规范Ver4.31要求，认真参测。

7、测试中如发现异常现象，请及时报告深交所，也可发送电子邮件反馈测试情况，邮件信箱为ssegcb@szse.cn。请在邮件中着重说明以下信息：参测单位名称、席位代号、测试情况及联系方式等。

8、测试完成后，各参测单位应做好系统和数据恢复工作，保证下一交易日的正常交易。
