# 深市市值配售业务全网测试方案

## 深市市值配售业务全网测试方案（深圳证券交易所　中国结算深圳分公司　二○○四年二月十日）

深市各会员单位、证券营业部：

为保证深交所向二级市场投资者市值配售新股业务的顺利实施，深圳证券交易所、上海证券交易所和中国证券登记结算有限责任公司定于2004年2月14日（周六）联合进行沪深市场技术系统全网、全程模拟测试。现将与深圳市场相关的测试方案通知如下：

**一、**参测单位

1、 深圳证券交易所

2、 上海证券交易所

3、 中国结算深圳分公司

4、 深圳证券通信公司

5、 深市各会员及下属证券营业部

6、 各其他相关单位

**二、**测试内容

（一） 深市市值配售发行新股业务，包括：申购委托、配号、摇号抽签、放弃认购申报、新股款扣划等。

（二） 深市发行新股的上市挂牌交易、结算全过程，包括：委托申报、集合竞价、连续竞价、成交回报、实时行情、股份和资金结算等。其中，沪市中签投资者向上证所委托卖出所认购的深市股票。

（三） 其它深市证券品种的交易结算业务。

**三、**测试步骤及时间

测试时间为2004年2月14日9：00至18：00。

|  |  |  |
| --- | --- | --- |
| 步骤 | 时间 | 测试项目 |
| 1 | 9：15至11：00 | 证券交易、新股申购。其中： 　　9：15--9：30，集合竞价； 　　9：30--11：00，连续竞价。 |
| 2 | 11：00至13：00 | 结算公司进行配号、抽签、股份与资金结算处理 |
| 3 | 13：00至14：00 | 券商接收第一次结算数据SJSGF.dbf（包括配号、中签号码等业务）、SJSTJ.dbf和SJSZJ.dbf，并进行股份和资金的清算和对账 |
| 4 | 14：00至15：00 | 券商申报放弃认购数据 |
| 5 | 15：00至17：00 | 结算公司进行配售确认、新股登记及新股扣款等处理 |
| 6 | 17：00后 | 券商接受第二次结算数据SJSGF.dbf（包括配售确认、新股登记等业务）、 SJSZJ.dbf（包括新股扣款数据）和SJSDZ.dbf，并进行股份和资金的清算和对账 |

**四、**测试数据

（一） 以2004年2月13日（周五）深市所有证券的收盘行情、收市后的股份数据作为测试当天的起始数据。

（二） 交易证券：本次全网测试虚拟了3只已经按市值配售发行完毕的新股的交易，它们是：

1、 模拟证券上市首日交易情形：

证券代码：002001（上证所对应代理挂牌证券609001）

证券名称：交易测1

昨收价：11.12元

涨跌幅度：无涨跌幅度限制

2、 模拟证券非上市首日交易情形：

证券代码：002006、002008（上证所对应代理挂牌证券609006、609008）

证券名称：交易测2、交易测3

昨收价：5.00元、6.00元

涨跌幅度：10%

（三） 股份数据：全网测试时“交易测1”、“交易测2”及“交易测3”（代码为002001、002006、002008）的股份数据分别由2月13日收市清算后“深发展A”、“TCL集团”及“一汽轿车”（代码分别为000001、000100及000800）的股份数据复制而来，请各参测单位在测试前根据自有的数据按对应关系自行复制生成测试用股份数据。

（四） 新股发行：本次测试安排1只证券按市值配售发行。

1、 券简称为“配售申1”，证券代码为002995（上证所对应代理发行证券为739995），发行价为5.00元，申购上限为3万股，申购数量必须为1000股的整数倍，申购时间为2月14日9：15至11：00。

2、 中签率固定设置为1%，尾数为88的配号中签。

3、 测试当日，结算公司通过股份结算信息库SJSGF.DBF返回的新股发行相关数据（GFZQDM＝‘002995’）如下：

| --- | --- | --- |
| 时间 | 内容（GFYWLB） | 说明 |

| 配号数据（A2） | 模拟T日申购并获配号的记录 |

（五） 可配售股数：本次测试使用的“配售申1”（代码为002995）可配售数据，由券商根据2004年2月2日SJSGF.DBF中GFYWLB＝“A4”，GFZQDM＝“003444”的“国通配售”的可配售股数数据自行复制生成，结算公司不再发送。如有需要，券商可通过点击深圳双向报盘系统的文件处理功能框来申请获得2月2日的股份结算信息库SJSGF.DBF。

（六） 资金数据：本次测试以2月13日清算后的资金余额为准。2月14日9：15-11：00的测试数据，记帐日期为2月15日，该资金数据（SJSZJ.DBF）将于2月14日13：00-14：00通过交易结算和法人结算平台同时下发；2月14日14：00-15：00的测试数据，记帐日期为2月16日，该资金数据（SJSZJ.DBF）将于2月14日17：00后通过交易结算和法人结算平台同时下发。

（七） 2月14日共安排发送两次结算数据。13：00至14：00发送第一次结算数据，内容包括上午交易后的股份资金结算数据、新股配号数据、中签号码数据。17：00发送第二次结算数据，内容包括新股最终确认数据、新股登记明细数据和新股认购扣款数据。为了防止第二次结算数据将第一次的结算数据覆盖掉，各会员收到第一次结算数据后应及时处理并做相应的数据备份。

**五、**测试前准备工作

（一） 将现有系统2月13日收市后的数据备份。

（二） 各会员请按测试方案自行复制生成“交易测1”（代码为002001）、“交易测2”（代码为002006）、“交易测3”（代码为002008）的股份数据，以及“配售申1”（代码为002995）的可申购数据。

（三） 制定内部测试计划和操作流程。

**六、**测试要求

（一） 各参测单位必须做好详细的系统和数据备份及恢复计划，并据此做好各项备份和恢复工作。

（二） 测试结束后，各参测单位将测试中发现的问题以电子邮件方式报至深交所（ssegcb@szse.cn），并请注明单位名称、联系人和电话。

**七、**说明

本次测试为深、沪交易所联合测试，上海证券交易所会员单位请按照上证所的相关测试方案进行沪市系统的相关测试。

本次测试所采用的业务方案，请参看《深交所向二级市场投资者配售新股的实施办法》（测试用）。
