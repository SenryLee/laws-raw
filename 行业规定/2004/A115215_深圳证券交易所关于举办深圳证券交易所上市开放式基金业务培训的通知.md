# 深圳证券交易所关于举办深圳证券交易所上市开放式基金业务培训的通知

各会员单位、基金管理公司、托管银行、机构投资者：

经中国证监会批准，上市开放式基金业务规则与业务方案已获准实施。为便于各市场参与者了解、学习和掌握上市开放式基金业务规则及相关操作流程，我所定于8月19日（星期四）在深圳举行上市开放式基金业务培训，现将有关事项通知如下：

**一、**培训内容

1．　深圳证券交易所上市开放式基金业务运作方案、规则；

2． 上市开放式基金登记结算业务规则；

3．上市开放式基金业务相关技术操作要点及注意事项；

4．上市开放式基金的应用。

**二、**培训对象

1. 各会员单位经纪业务、技术负责人；

2. 基金管理公司产品开发、市场及技术负责人；

3. 各托管银行基金销售、技术负责人；

4. 各有关机构投资者。

**三、**培训时间

1．培训时间为2004年8月19日下午1：30至6：00

2．报到、领取培训材料时间为当日12：30-13：25，请提前办理报到手续。

**四、**培训地点

深圳市福田区福中三路市民中心多功能厅。

位置：深圳福田区莲花山南侧，市民中心中区行政服务大厅后面一楼。

**五、**培训费用

不收会务费，会务组安排晚餐，其他费用自理
