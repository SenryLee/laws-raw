# 全国股转公司综合事务部关于发布《全国中小企业股份转让系统摘牌证券服务专区技术开发指南（V1.0）》的通知

## 关于发布《全国中小企业股份转让系统摘牌证券服务专区技术开发指南（V1.0）》的通知

股转系统办发〔2021〕33号

各市场参与者：

为确保股东人数超200人终止挂牌公司股份转让服务顺利开展，全国中小企业股份转让系统有限责任公司（以下简称全国股转公司）根据挂牌公司股票终止挂牌相关业务安排，制定了《全国中小企业股份转让系统摘牌证券服务专区技术开发指南（V1.0）》，现予以正式发布。

请各市场参与者根据上述文档要求做好技术准备工作。文档内容如有调整，我司将发布更新通知。如有疑问，请及时联系。

特此通知。

联系方式： 400-626-3333
