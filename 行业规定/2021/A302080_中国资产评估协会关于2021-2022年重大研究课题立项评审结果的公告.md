# 中国资产评估协会关于2021-2022年重大研究课题立项评审结果的公告

## 中评协关于2021-2022年重大研究课题立项评审结果的公告

中评协公告〔2021〕11号

根据《中国资产评估协会关于征集2021-2022年重大研究课题承担单位的公告》（中评协公告〔2021〕9号），中国资产评估协会组织专家对符合重大研究课题申报要求的材料进行了立项评审，确定了5个重大研究课题的承担单位。现将评审结果公告如下：

2021-2022年中国资产评估协会

重大研究课题立项评审结果

|  |  |  |
| --- | --- | --- |
| **序号** | **课题名称** | **承担单位** |
| 1 | 公募REITs全流程的评估方法研究 | 北京国融兴华资产评估有限责任公司 |
| 2 | 机器学习技术在资产评估行业应用研究 | 北京中同华资产评估有限公司 |
| 3 | 生态产品价值评估目的、评估程序和评估方法研究 | 河北农业大学 |
| 4 | “十四五”时期健全我国知识产权评估体系研究 | 中南财经政法大学 |
| 5 | 碳交易体系中碳资产评估和定价研究 | 北京工商大学 |

特此公告。

中国资产评估协会
