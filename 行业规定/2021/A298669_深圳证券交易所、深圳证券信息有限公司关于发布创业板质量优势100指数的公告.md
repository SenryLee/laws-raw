# 深圳证券交易所、深圳证券信息有限公司关于发布创业板质量优势100指数的公告

## 关于发布创业板质量优势100指数的公告

为刻画创业板市场具有高质量发展特点企业的运行特征，深圳证券交易所和深圳证券信息有限公司定于2021年1月12日发布创业板质量优势100指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 指数基日 | 基日点位 |
| 399269 | 创业板质量优势100指数 | 创质量 | 2012年12月31日 | 1000 |

创业板质量优势100指数以深交所创业板上市公司为选样范围，选取100只基本面表现良好、流动性好的股票构成样本股。

指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。

特此公告。
