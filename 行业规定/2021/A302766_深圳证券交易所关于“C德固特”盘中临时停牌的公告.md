# 深圳证券交易所关于“C德固特”盘中临时停牌的公告

“C德固特”（300950）盘中成交价较开盘价首次上涨达到或超过30%，根据《深圳证券交易所创业板交易特别规定》等有关规定，本所自今日10时52分59秒起对该证券实施临时停牌，于11时03分00秒复牌。

本所郑重提示广大投资者注意投资风险，理性投资。
