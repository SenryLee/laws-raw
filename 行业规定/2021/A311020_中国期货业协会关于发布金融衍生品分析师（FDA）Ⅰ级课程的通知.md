# 中国期货业协会关于发布金融衍生品分析师（FDA）Ⅰ级课程的通知

## 关于发布金融衍生品分析师（FDA）Ⅰ级课程的通知

各会员单位：

为提升行业人才专业水平，加快推进金融知识纳入国民教育，协会启动了金融衍生品分析师（FDA）水平课程体系建设。课程分为Ⅰ、Ⅱ、Ⅲ级，包括内部控制与职业道德、经济学基础、期货及衍生品概述等应知应会课程及利率类衍生品、汇率类衍生品、信用类衍生品等提高课程。前期协会制作了金融衍生品分析师Ⅰ级课程（以下简称“系列课程”），已在协会网络培训平台以点播课程形式发布，具体通知如下：

一、授课讲师及课程内容

系列课程授课讲师有高校教授、监管部门及业内专家，专业理论知识深厚，行业实务经验丰富。本系列课程多为模块化短视频，每讲讲透一个知识点，共计6章126讲50.8学时，具体如下：

|  |  |  |  |
| --- | --- | --- | --- |
| **序号** | **章** | **讲** | **学时合计** |
| 1 | 法律法规与职业道德 | 19 | 7.5 |
| 2 | 微观经济学 | 27 | 11.7 |
| 3 | 金融市场与金融工具 | 21 | 9.7 |
| 4 | 期货及其他金融衍生品 | 18 | 8.7 |
| 5 | 中外期货市场 | 22 | 7.6 |
| 6 | 统计基础 | 19 | 5.6 |
| **总计** |  | **126** | **50.8** |

二、培训对象

系列课程面向广大金融行业从业人员，高校学生等有意向进入金融衍生品市场的人员亦推荐学习。

三、观看方式

登录协会网上后续培训平台，查看“FDA”栏目。网络培训平台地址：http://mooc.cfachina.org。

四、课程收费标准

课程收费参照2021年8月18日协会发布的《关于调整网络点播培训收费标准的公告》执行。
