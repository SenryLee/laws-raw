# 中国期货业协会关于吸收上海山金实业发展有限公司等3家机构为协会会员的公告

## 中国期货业协会公告

## 关于吸收上海山金实业发展有限公司等3家机构为协会会员的公告

根据《中国期货业协会章程》，经协会会长办公会2021年第15期会议审议，同意吸收上海山金实业发展有限公司等3家机构成为协会会员（具体名单附后）。

特此公告。

附

## 3家新入会会员名单

|  |  |  |
| --- | --- | --- |
| **序号** | **公司名称** | **会员类型** |
| 1 | 上海山金实业发展有限公司 | 普通会员 |
| 2 | 国网英大风险管理（深圳）有限公司 | 普通会员 |
| 3 | 财信风险管理有限公司 | 普通会员 |

中国期货业协会
