# 深圳证券交易所关于2019年四川省乡村振兴专项债券（九期）——2019年四川省政府专项债券（八十五期）上市交易的通知

## 关于2019年四川省乡村振兴专项债券（九期）——2019年四川省政府专项债券（八十五期）上市交易的通知

各市场参与人：

2019年四川省乡村振兴专项债券（九期）——2019年四川省政府专项债券（八十五期）已发行结束，根据财政部有关规定，本期债券于2019年6月6日起在本所上市交易。

本期债券为20年期固定利率附息债，证券编码“104636”，证券简称“四川1995”，票面利率3.9％，标准交易单位“10张”，2039年6月4日到期还本并支付最后一期利息。
