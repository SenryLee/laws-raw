# 深圳证券交易所关于支付2017年河南省政府一般债券（十二期）等四只债券利息有关事项的通知

## 关于支付2017年河南省政府一般债券（十二期）等四只债券利息有关事项的通知

各市场参与人：

2017年河南省政府一般债券（十二期）、2017年河南省政府专项债券（二十四期）、2018年新疆维吾尔自治区政府一般债券（二期）、2016年上海市政府一般债券（八期）将于2019年5月14日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2017年河南省政府一般债券（十二期）证券代码为“106218”，证券简称为“河南1735”，是2017年11月14日发行的10年期债券，票面利率为4.13％，每年支付2次利息，每百元面值债券本次可获利息2.065元。

二、2017年河南省政府专项债券（二十四期）证券代码为“106219”，证券简称为“河南1736”，是2017年11月14日发行的10年期债券，票面利率为4.08％，每年支付2次利息，每百元面值债券本次可获利息2.04元。

三、2018年新疆维吾尔自治区政府一般债券（二期）证券代码为“106440”，证券简称为“新疆1803”，是2018年5月14日发行的5年期债券，票面利率为3.48％，每年支付1次利息，每百元面值债券本次可获利息3.48元。

四、2016年上海市政府一般债券（八期）证券代码为“107460”，证券简称为“上海1608”，是2016年11月14日发行的10年期债券，票面利率为2.86％，每年支付2次利息，每百元面值债券本次可获利息1.43元。

五、从2019年5月6日至2019年5月13日停办上述地方政府债的转托管及调帐业务。

六、上述债券付息债权登记日为2019年5月13日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年5月14日除息交易。

七、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所

二○一九年四月二十五日
