# 深圳证券交易所关于中国中金财富证券有限公司会员名称变更的公告

## 关于中国中金财富证券有限公司会员名称变更的公告

中国中金财富证券有限公司在深圳证券交易所的会员名称由“中国中投证券有限责任公司”变更为“中国中金财富证券有限公司”。会员简称为：中金财富，会员编码为：000679。
