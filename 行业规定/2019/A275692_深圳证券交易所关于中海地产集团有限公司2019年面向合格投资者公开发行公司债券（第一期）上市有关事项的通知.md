# 深圳证券交易所关于中海地产集团有限公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

## 关于中海地产集团有限公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

各会员单位：

中海地产集团有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）、中海地产集团有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种二）定于2019年2月15日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、中海地产集团有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）证券代码“112845”，证券简称“19中海01”，发行总额20亿元，票面利率3.47%，债券期限6年，附第3年末发行人赎回选择权、票面利率调整选择权和投资者回售选择权。

2、中海地产集团有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种二）证券代码“112846”，证券简称“19中海02”，发行总额15亿元，票面利率3.75%，债券期限7年，附第5年末发行人赎回选择权、票面利率调整选择权和投资者回售选择权。

特此通知

深圳证券交易所
