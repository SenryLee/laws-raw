# 深圳证券交易所关于2019年吉林省市县级医疗机构基础设施建设项目专项债券（一期）——2019年吉林省政府专项债券（十六期）上市交易的通知

## 关于2019年吉林省市县级医疗机构基础设施建设项目专项债券（一期）——2019年吉林省政府专项债券（十六期）上市交易的通知

各市场参与人：

2019年吉林省市县级医疗机构基础设施建设项目专项债券（一期）——2019年吉林省政府专项债券（十六期）已发行结束，根据财政部有关规定，本期债券于2019年9月3日起在本所上市交易。

本期债券为10年期固定利率附息债，证券编码“105903”，证券简称“吉林1920”，票面利率3.55％，标准交易单位“10张”，2029年8月30日到期还本并支付最后一期利息。
