# 深圳证券交易所关于为湖南唐人神控股投资股份有限公司2019年非公开发行可交换公司债券提供转让服务有关事项的通知

## 关于为湖南唐人神控股投资股份有限公司2019年非公开发行可交换公司债券提供转让服务有关事项的通知

各会员单位：

湖南唐人神控股投资股份有限公司2019年非公开发行可交换公司债券定于2019年7月25日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

湖南唐人神控股投资股份有限公司2019年非公开发行可交换公司债券证券代码"117138",证券简称"19唐人EB",发行总额2亿元，票面利率2%,债券期限3年，附换股价格向下修正条款、赎回条款、回售条款。

深圳证券交易所

二○一九年七月二十三日
