# 深圳证券交易所关于2019年记账式附息（五期）国债上市交易的通知

## 关于2019年记账式附息（五期）国债上市交易的通知

各市场参与人：

2019年记账式附息（五期）国债已发行结束，根据财政部有关规定，本期债券于2019年5月27日起在本所上市交易。

本期债券为1年期固定利率附息债，证券编码“101985”，证券简称“国债1905”，票面利率2.65％，标准交易单位“10张”，2020年5月23日到期还本并支付最后一期利息。
