# 上海证券交易所关于同意广发证券股份有限公司为易方达中证800交易型开放式指数证券投资基金等四只基金提供一般流动性服务的公告

## 关于同意广发证券股份有限公司为易方达中证800交易型开放式指数证券投资基金等四只基金提供一般流动性服务的公告

上证公告（基金）〔2019〕265号

为促进易方达中证800交易型开放式指数证券投资基金(以下简称ZZ800ETF，基金代码:515810)、华宝中证医疗交易型开放式指数证券投资基金(以下简称医疗ETF，基金代码:512170)、富国中证消费50交易型开放式指数证券投资基金(以下简称消费50，基金代码:515650)和富国中证军工龙头交易型开放式指数证券投资基金（以下简称军工龙头，基金代码：512710）的市场流动性和平稳运行，根据《上海证券交易所上市基金流动性服务业务指引（2018年修订）》等相关规定，本所同意广发证券股份有限公司为ZZ800ETF、医疗ETF、消费50和军工龙头提供一般流动性服务。

特此公告。

上海证券交易所

二〇一九年十二月二十三日
