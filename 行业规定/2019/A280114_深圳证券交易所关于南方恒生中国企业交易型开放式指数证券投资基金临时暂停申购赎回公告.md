# 深圳证券交易所关于南方恒生中国企业交易型开放式指数证券投资基金临时暂停申购赎回公告

## 南方恒生中国企业交易型开放式指数证券投资基金临时暂停申购赎回公告

因港交所临时停市，经南方基金管理股份有限公司申请，南方恒生中国企业交易型开放式指数证券投资基金（简称：H股ETF、代码：159954）于2019年07月31日14时26分至收市实施临时暂停申购赎回，特此公告。

2019年07月31日
