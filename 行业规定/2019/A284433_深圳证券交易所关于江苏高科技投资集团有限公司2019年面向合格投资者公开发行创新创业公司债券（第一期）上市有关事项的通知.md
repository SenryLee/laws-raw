# 深圳证券交易所关于江苏高科技投资集团有限公司2019年面向合格投资者公开发行创新创业公司债券（第一期）上市有关事项的通知

## 关于江苏高科技投资集团有限公司2019年面向合格投资者公开发行创新创业公司债券（第一期）上市有关事项的通知

各会员单位：

江苏高科技投资集团有限公司2019年面向合格投资者公开发行创新创业公司债券（第一期）定于2019年9月6日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

江苏高科技投资集团有限公司2019年面向合格投资者公开发行创新创业公司债券（第一期）证券代码“112961”，证券简称“19苏投S1”，发行总额5亿元，票面利率3.84%，债券期限5年，附第3年末发行人票面利率调整选择权和投资者回售选择权。

特此通知

深圳证券交易所

二○一九年九月五日
