# 深圳证券交易所关于为大同煤矿集团有限责任公司非公开发行2019年公司债券（第二期） 提供转让服务有关事项的通知

## 关于为大同煤矿集团有限责任公司非公开发行2019年公司债券（第二期） 提供转让服务有关事项的通知

各会员单位：

大同煤矿集团有限责任公司非公开发行2019年公司债券（第二期）定于2019年7月5日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

大同煤矿集团有限责任公司非公开发行2019年公司债券（第二期）证券代码"114502",证券简称"19同煤02",发行总额17亿元，票面利率5.48%,债券期限3年，附第1年末、第2年末发行人调整票面利率选择权及投资者回售选择权。

深圳证券交易所
