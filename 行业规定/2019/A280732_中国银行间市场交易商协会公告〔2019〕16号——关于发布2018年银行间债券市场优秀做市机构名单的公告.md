# 中国银行间市场交易商协会公告〔2019〕16号——关于发布2018年银行间债券市场优秀做市机构名单的公告

〔2019〕16号

## 关于发布2018年银行间债券市场优秀做市机构名单的公告

为促进银行间债券市场做市业务规范发展，完善做市机构激励约束机制，按照《银行间债券市场做市业务指引》及《银行间债券市场做市业务评价指标体系》，在人民银行指导下，中国银行间市场交易商协会根据中国外汇交易中心提供的做市基础数据，综合各机构的做市表现和合规情况，评选出2018年度优秀综合做市机构、优秀利率债做市商、优秀利率债尝试做市机构、优秀信用债做市商及优秀信用债尝试做市机构五类奖项。现就优秀做市机构名单（按机构名称拼音排序，排名不分先后）公告如下。
