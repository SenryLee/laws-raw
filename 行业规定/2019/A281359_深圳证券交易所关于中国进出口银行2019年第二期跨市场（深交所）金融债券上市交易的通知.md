# 深圳证券交易所关于中国进出口银行2019年第二期跨市场（深交所）金融债券上市交易的通知

## 关于中国进出口银行2019年第二期跨市场（深交所）金融债券上市交易的通知

各市场参与人：

根据深圳证券交易所（以下简称"本所"）有关规定，中国进出口银行2019年第二期跨市场（深交所）金融债券（以下简称"本期债券"）将于2019年7月19日起在本所集中竞价系统上市，现将有关事项通知如下：

本期债券为2年期固定利率附息式债券，证券编码"108802",证券简称"进出1902",票面利率2.99%,每年支付一次利息；本期债券起息日为2019年7月17日，2021年7月17日到期还本并支付最后一期利息。

特此通知

深圳证券交易所

二○一九年七月十七日
