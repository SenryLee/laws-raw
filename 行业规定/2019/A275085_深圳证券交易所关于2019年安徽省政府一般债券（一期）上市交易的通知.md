# 深圳证券交易所关于2019年安徽省政府一般债券（一期）上市交易的通知

## 关于2019年安徽省政府一般债券（一期）上市交易的通知

各市场参与人：

2019年安徽省政府一般债券（一期）已发行结束，根据财政部有关规定，本期债券于2019年2月11日起在本所上市交易。

本期债券为7年期固定利率附息债，证券编码“104500”，证券简称“安徽1901”，票面利率3.37％，标准交易单位“10张”，2026年1月31日到期还本并支付最后一期利息。
