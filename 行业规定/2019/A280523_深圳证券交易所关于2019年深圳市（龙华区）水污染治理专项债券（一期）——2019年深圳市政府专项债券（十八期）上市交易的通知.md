# 深圳证券交易所关于2019年深圳市（龙华区）水污染治理专项债券（一期）——2019年深圳市政府专项债券（十八期）上市交易的通知

## 关于2019年深圳市（龙华区）水污染治理专项债券（一期）——2019年深圳市政府专项债券（十八期）上市交易的通知

各市场参与人：

2019年深圳市（龙华区）水污染治理专项债券（一期）——2019年深圳市政府专项债券（十八期）已发行结束，根据财政部有关规定，本期债券于2019年6月20日起在本所上市交易。

本期债券为5年期固定利率附息债，证券编码“105579”，证券简称“深圳1920”，票面利率3.34％，标准交易单位“10张”，附分期偿还本金条款，2024年6月18日偿还剩余本金并支付最后一期利息。
