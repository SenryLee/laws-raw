# 全国中小企业股份转让系统有限责任公司关于发布《全国中小企业股份转让系统2020年度主办券商执业质量专项评价指标及计算方法》的通知

## 关于发布《全国中小企业股份转让系统2020年度主办券商执业质量专项评价指标及计算方法》的通知

各主办券商：

为了鼓励主办券商积极履行社会责任，深入参与新三板全面深化改革工作，提高主办券商执业质量，全国中小企业股份转让系统有限责任公司制定了《全国中小企业股份转让系统2020年度主办券商执业质量专项评价指标及计算方法》，现予以发布。

特此通知。

附件：全国中小企业股份转让系统2020年度主办券商执业质量专项评价指标及计算方法

全国股转公司综合事务部（总经理办公室）

2019年12月31日

## 全国中小企业股份转让系统2020年度主办券商执业质量专项评价指标及计算方法

|| **专项评价维度** | **专项评价指标项** | **指标说明** | **计算方法** |
|  |  |  |  |
| --- | --- | --- | --- |
| 履行社会责任 | 推荐贫困地区企业挂牌家数 | 2020年度主办券商累计推荐注册地在贫困地区企业挂牌家数。 | 主办券商每推荐1家注册地在贫困地区企业挂牌项目，加0.5分；  该专项评价指标最高可加3分。 |
| 推动业务创新 | 推荐公开发行股票并在精选层挂牌公司家数 | 2020年度，主办券商累计推荐公开发行股票并在精选层挂牌公司家数。 | 对开展该项业务，且位于行业前5、10、20名的主办券商分别加分3、2、1分； 该专项评价指标最高可加3分。 |
| 推荐挂牌同时进入创新层公司家数 | 2020年度，主办券商累计推荐挂牌同时进入创新层公司家数。 | 对开展该项业务，且位于行业前5、10、20名的主办券商分别加分3、2、1分； 该专项评价指标最高可加3分。 |
| 加强业务协同 | 发行新三板产品参与认购公开发行的股票只数 | 主办券商及其子公司发行的新三板产品2020年度累计参与认购挂牌公司公开发行的股票只数。 | 对开展该项业务，且位于行业前5、10、20名的主办券商分别加分3、2、1分； 该专项评价指标最高可加3分。 |
