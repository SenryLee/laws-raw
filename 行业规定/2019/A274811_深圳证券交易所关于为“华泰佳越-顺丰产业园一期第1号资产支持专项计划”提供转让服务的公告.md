# 深圳证券交易所关于为“华泰佳越-顺丰产业园一期第1号资产支持专项计划”提供转让服务的公告

## 关于为“华泰佳越-顺丰产业园一期第1号资产支持专项计划”提供转让服务的公告

各相关单位：

根据华泰证券(上海）资产管理有限公司申请，本所将自2019年1月29日起在综合协议交易平台为“华泰佳越-顺丰产业园一期第1号资产支持专项计划”（以下简称“顺丰1号专项”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“顺丰1号专项”的转让业务。

二、“顺丰1号专项”设立日期为2018年12月11日。优先级资产支持证券如下：证券简称“顺丰01优”，证券代码为“119461”，到期日为2062年4月25日，还本付息方式为按年付息，到期还本。次级资产支持证券如下：证券简称“顺丰01次”，证券代码为“119462”，到期日为2062年4月25日，还本付息方式为每年获得不超过8%的期间收益，超过部分留存至每3年末分配83%。

三、“顺丰01优”的单笔成交申报最低数量为10000份，“顺丰01次”的单笔成交申报最低数量为10000份。

四、对首次参加“顺丰1号专项”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“顺丰1号专项”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
