# 上海证券交易所关于对2019年5月到期的上证50ETF认购期权合约解除开仓限制的公告

## 关于对2019年5月到期的上证50ETF认购期权合约解除开仓限制的公告

上证公告〔2019〕25号

截至2019年5月7日收盘，到期月份为2019年5月的未平仓上证50ETF认购期权合约数量为120.03万张，对应的合约标的总数为上证50ETF流通总量的67.81%，低于70%。根据《上海证券交易所、中国证券登记结算有限责任公司股票期权试点风险控制管理办法》第四十七条相关规定，上海证券交易所自2019年5月8日起对2019年5月到期的上证50ETF认购期权合约解除开仓限制，相关合约可以买入开仓和卖出开仓。

请投资者注意投资风险，谨慎参与期权交易。

特此公告。

上海证券交易所

二〇一九年五月七日
