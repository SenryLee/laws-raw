# 深圳证券交易所关于为启迪桑德环境资源股份有限公司2019年非公开发行绿色公司债券（第一期）等三只债券提供转让服务有关事项的通知

## 关于为启迪桑德环境资源股份有限公司2019年非公开发行绿色公司债券（第一期）等三只债券提供转让服务有关事项的通知

各会员单位：

启迪桑德环境资源股份有限公司2019年非公开发行绿色公司债券（第一期）、 长城证券股份有限公司2019年非公开发行公司债券（品种一）、 大同市经济建设投资有限责任公司2019年非公开发行公司债券定于2019年4月4日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、启迪桑德环境资源股份有限公司2019年非公开发行绿色公司债券（第一期）证券代码“114439”，证券简称“19启迪G1”，发行总额6亿元，票面利率6.6%，债券期限2年，附第1年末发行人调整票面利率选择权和投资者回售选择权。

2、长城证券股份有限公司2019年非公开发行公司债券（品种一）证券代码“114447”，证券简称“19长证01”，发行总额10亿元，票面利率4.2%，债券期限3年。

3、大同市经济建设投资有限责任公司2019年非公开发行公司债券证券代码“114451”，证券简称“19同经债”，发行总额10亿元，票面利率6.8%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一九年四月二日
