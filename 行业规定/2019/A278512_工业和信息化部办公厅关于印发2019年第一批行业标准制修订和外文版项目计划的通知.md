# 工业和信息化部办公厅关于印发2019年第一批行业标准制修订和外文版项目计划的通知

工信厅科函〔2019〕126号

有关单位：

根据工业通信业行业标准制修订工作总体安排，我部编制完成了2019年第一批行业标准制修订和外文版项目计划，现印发给你们，请认真组织落实。有关要求如下：

一、标准起草单位要注意做好标准制定与技术创新、试验验证、知识产权处置、产业化推进、应用推广的统筹协调。

二、有关行业协会（联合会）、标准化技术组织、标准化专业机构等主管单位要尽早安排，将文件及时转发至主要起草单位，并做好标准组织起草、征求意见和技术审查等工作，把好技术审查关。

三、部机关相关司局、相关地方行政主管部门要做好行业标准制修订、外文版研制过程的管理工作，确保标准的质量和水平。

四、计划执行过程中，如需对标准项目进行调整，请按有关规定办理。

附件：2019年第一批行业标准制修订和外文版项目计划

工业和信息化部办公厅

2019年5月31日
