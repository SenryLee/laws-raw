# 深圳证券交易所关于烟台中宠食品股份有限公司可转换公司债券上市交易的公告

## 关于烟台中宠食品股份有限公司可转换公司债券上市交易的公告

烟台中宠食品股份有限公司发行的194,240,000元可转换公司债券自2019年3月14日起在本所上市交易，证券简称为“中宠转债”，证券代码为“128054”，上市数量194.24万张。
