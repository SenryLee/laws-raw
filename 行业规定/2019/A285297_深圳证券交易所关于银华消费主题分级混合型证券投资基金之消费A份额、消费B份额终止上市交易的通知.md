# 深圳证券交易所关于银华消费主题分级混合型证券投资基金之消费A份额、消费B份额终止上市交易的通知

## 关于银华消费主题分级混合型证券投资基金之消费A份额、消费B份额终止上市交易的通知

各会员单位：

银华基金管理股份有限公司以通讯方式召开银华消费主题分级混合型证券投资基金份额持有人大会，并于2019年11月28日刊登了《关于银华消费主题分级混合型证券投资基金基金份额持有人大会表决结果暨决议生效公告》（以下简称“公告”）。根据公告，会议表决通过了《关于银华消费主题分级混合型证券投资基金转型有关事项的议案》（以下简称“议案”），该决议自2019年11月27日起生效。根据持有人大会通过的议案，银华基金管理股份有限公司向本所提交了终止上市的申请。

根据《深圳证券交易所证券投资基金上市规则》及其他有关规定，经审查，本所决定银华消费主题分级混合型证券投资基金之消费A份额（场内简称：消费A，证券代码：150047）和消费B份额（场内简称：消费B，证券代码：150048）自2019年12月26日起终止上市交易。
