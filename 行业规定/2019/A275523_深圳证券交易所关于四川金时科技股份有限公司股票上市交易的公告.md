# 深圳证券交易所关于四川金时科技股份有限公司股票上市交易的公告

## 关于四川金时科技股份有限公司股票上市交易的公告

四川金时科技股份有限公司人民币普通股股票将于2019年3月15日在本所上市。证券简称为“金时科技”，证券代码为“002951”。公司人民币普通股股份总数为405,000,000股，其中45,000,000股股票自上市之日起开始上市交易。
