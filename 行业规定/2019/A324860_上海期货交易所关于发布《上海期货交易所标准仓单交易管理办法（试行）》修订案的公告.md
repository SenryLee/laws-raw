# 上海期货交易所关于发布《上海期货交易所标准仓单交易管理办法（试行）》修订案的公告

上海期货交易所公告〔2019〕84号

为更好地服务实体经济，满足市场需求，促进期货市场功能发挥，我所对《上海期货交易所标准仓单交易管理办法（试行）》作了修订，具体涉及仓单交易商准入制度、交易制度、结算制度等内容，现予以公布，自2019年10月14日起施行。

特此公告。

附件：上海期货交易所标准仓单交易管理办法（试行）（修订案）

上海期货交易所

2019年10月14日
