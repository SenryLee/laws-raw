# 上海证券交易所关于2019年清明节休市安排的公告

## 关于2019年清明节休市安排的公告

上证公告〔2019〕15号

根据《关于上海证券交易所2019年全年休市安排的通知》（上证公告〔2018〕39号），上海证券交易所现将2019年清明节休市安排通知如下：

4月5日（星期五）至4月7日（星期日）休市，4月8日（星期一）起照常开市。

请市场参与人据此安排有关工作。

上海证券交易所

二〇一九年三月二十八日
