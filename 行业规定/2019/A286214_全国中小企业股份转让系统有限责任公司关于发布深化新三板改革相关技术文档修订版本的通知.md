# 全国中小企业股份转让系统有限责任公司关于发布深化新三板改革相关技术文档修订版本的通知

## 关于发布深化新三板改革相关技术文档修订版本的通知

各市场参与者：

为确保新三板改革相关举措顺利实施，全国股转公司根据深化新三板改革相关业务规则，修订了《全国中小企业股份转让系统市场参与者技术系统变更指南之交易业务（V1.3）》，现予以正式发布。请各市场参与者根据上述文档及时做好技术系统相关调整工作。如有情况，请随时联系我司。

特此通知。

联系方式：400-626-3333
