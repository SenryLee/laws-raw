# 深圳证券交易所关于天津中环半导体股份有限公司2019年面向合格投资者公开发行公司债券（第二期）上市有关事项的通知

## 关于天津中环半导体股份有限公司2019年面向合格投资者公开发行公司债券（第二期）上市有关事项的通知

各会员单位：

天津中环半导体股份有限公司2019年面向合格投资者公开发行公司债券（第二期）定于2019年8月19日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

天津中环半导体股份有限公司2019年面向合格投资者公开发行公司债券（第二期）证券代码“112824”，证券简称“19中环02”，发行总额6亿元，票面利率5.75%，债券期限6年,附第2、第4年末发行人调整票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所
