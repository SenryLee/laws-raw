# 深圳证券交易所关于广州产业投资基金管理有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种一）上市有关事项的通知

## 关于广州产业投资基金管理有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种一）上市有关事项的通知

各会员单位：

广州产业投资基金管理有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种一）定于2019年9月4日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

广州产业投资基金管理有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种一）证券代码“112955”，证券简称“19广基02”，发行总额10亿元，票面利率3.88%，债券期限5年,附第3年末发行人调整票面利率选择权和投资者回售选择权。
