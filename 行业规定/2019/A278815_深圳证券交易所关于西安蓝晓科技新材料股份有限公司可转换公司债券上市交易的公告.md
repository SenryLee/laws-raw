# 深圳证券交易所关于西安蓝晓科技新材料股份有限公司可转换公司债券上市交易的公告

## 关于西安蓝晓科技新材料股份有限公司可转换公司债券上市交易的公告

西安蓝晓科技新材料股份有限公司发行的340,000,000元可转换公司债券自2019年7月4日起在本所上市交易，证券简称为“蓝晓转债”，证券代码为“123027”，上市数量340万张。

深圳证券交易所

二〇一九年七月一日
