# 深圳证券交易所关于深圳拓邦股份有限公司可转换公司债券上市交易的公告

## 关于深圳拓邦股份有限公司可转换公司债券上市交易的公告

深圳拓邦股份有限公司发行的573,000,000元可转换公司债券自2019年4月8日起在本所上市交易，证券简称为“拓邦转债”，证券代码为“128058”，上市数量573万张。
