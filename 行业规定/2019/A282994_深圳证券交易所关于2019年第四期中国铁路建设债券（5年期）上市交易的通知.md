# 深圳证券交易所关于2019年第四期中国铁路建设债券（5年期）上市交易的通知

## 关于2019年第四期中国铁路建设债券（5年期）上市交易的通知

各市场参与人：

根据国家发展和改革委员会有关规定，2019年第四期中国铁路建设债券（5年期）将于2019年8月26日在本所上市交易，现将有关事项通知如下：

2019年第四期中国铁路建设债券（5年期）为5年期固定利率附息债，证券编码“111915”，证券简称“铁道1907”，票面利率3.35％，每年支付1次利息；本债券起息日为2019年8月22日，2024年8月22日到期还本并支付最后一期利息。

特此通知

深圳证券交易所

二○一九年八月二十二日
