# 深圳证券交易所、深圳证券信息有限公司关于发布深证民企发展指数的公告

## 关于发布深证民企发展指数的公告

为充分发挥深交所服务民营企业的特色和优势，反映存在股权质押情形的民营上市公司股价表现，丰富金融产品投资标的，支持民营企业健康发展，深圳证券交易所和深圳证券信息有限公司定于2019年3月5日发布深证民企发展指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **指数代码** | **指数名称** | **指数简称** | **指数基日** | **基日点位** |
| 399292 | 深证民企发展指数 | 民企发展 | 2014年6月30日 | 1000 |

深证民企发展指数从大股东质押股份比例大于60%的民营上市公司中，剔除基本面及股票流动性较差的公司，按整体质押率由大到小排序，选取500家公司作为样本股。指数采用自由流通市值加权，于每年6月、12月的第二个星期五的下一个交易日进行样本股定期调整。

深证民企发展指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关深证民企发展指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
