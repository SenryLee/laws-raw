# 深圳证券交易所关于启明星辰信息技术集团股份有限公司可转换公司债券上市交易的公告

## 关于启明星辰信息技术集团股份有限公司可转换公司债券上市交易的公告

启明星辰信息技术集团股份有限公司发行的1,045,000,000元可转换公司债券自2019年4月24日起在本所上市交易，证券简称为“启明转债”，证券代码为“128061”，上市数量10,450,000张。
