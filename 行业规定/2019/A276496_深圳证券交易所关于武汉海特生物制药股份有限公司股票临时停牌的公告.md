# 深圳证券交易所关于武汉海特生物制药股份有限公司股票临时停牌的公告

## 关于武汉海特生物制药股份有限公司股票临时停牌的公告

因武汉海特生物制药股份有限公司未能及时披露2018年年度报告，根据本所《创业板股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：海特生物，证券代码：300683）自2019年4月19日开市起停牌，待公司通过指定媒体披露相关公告后复牌，敬请投资者密切关注。

深圳证券交易所

2019年4月19日
