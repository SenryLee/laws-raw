# 深圳证券交易所关于支付2019年河北省政府一般债券（六期）等四只债券利息有关事项的通知

## 关于支付2019年河北省政府一般债券（六期）等四只债券利息有关事项的通知

各市场参与人：

2019年河北省政府一般债券（六期）、2019年天津市政府生态保护专项债券（六期）——2019年天津市政府专项债券（二十五期）、2015年湖北省政府一般债券（八期）、2015年浙江省政府一般债券（四期）将于2019年12月10日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2019年河北省政府一般债券（六期）证券代码为“105495”，证券简称为“河北1915”，是2019年6月10日发行的30年期债券，票面利率为4.15％，每年支付2次利息，每百元面值债券本次可获利息2.075元。

二、2019年天津市政府生态保护专项债券（六期）——2019年天津市政府专项债券（二十五期）证券代码为“105503”，证券简称为“天津1932”，是2019年6月10日发行的10年期债券，票面利率为3.49％，每年支付2次利息，每百元面值债券本次可获利息1.745元。

三、2015年湖北省政府一般债券（八期）证券代码为“109201”，证券简称为“湖北1508”，是2015年6月10日发行的10年期债券，票面利率为3.6％，每年支付2次利息，每百元面值债券本次可获利息1.8元。

四、2015年浙江省政府一般债券（四期）证券代码为“109205”，证券简称为“浙江1504”，是2015年6月10日发行的10年期债券，票面利率为3.59％，每年支付2次利息，每百元面值债券本次可获利息1.795元。

五、从2019年12月2日至2019年12月9日停办上述地方政府债的转托管及调帐业务。

六、上述债券付息债权登记日为2019年12月9日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年12月10日除息交易。

七、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所

二○一九年十一月二十六日
