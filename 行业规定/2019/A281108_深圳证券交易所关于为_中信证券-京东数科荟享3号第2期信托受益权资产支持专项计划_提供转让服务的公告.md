# 深圳证券交易所关于为"中信证券-京东数科荟享3号第2期信托受益权资产支持专项计划"提供转让服务的公告

## 关于为"中信证券-京东数科荟享3号第2期信托受益权资产支持专项计划"提供转让服务的公告

各相关单位：

根据中信证券股份有限公司申请，本所将自2019年7月5日起在综合协议交易平台为"中信证券-京东数科荟享3号第2期信托受益权资产支持专项计划"（以下简称"京东荟享3号2期"）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与"京东荟享3号2期"的转让业务。

二、"京东荟享3号2期"设立日期为2019年6月12日。优先级资产支持证券如下：证券简称"荟享032A",证券代码为"139727",到期日为2020年7月31日，还本付息方式为循环期按季付息；摊还期按月付息，按月过手摊还本金。次优先级资产支持证券如下：证券简称"荟享032B",证券代码为"139728",到期日为2020年7月31日，还本付息方式为循环期按季付息；摊还期按月付息，按月过手摊还本金。次级资产支持证券如下：证券简称"荟享032C",证券代码为"139729",到期日为2020年7月31日，还本付息方式为循环期不分配；摊还期在优先级本息兑付完毕后获得剩余收益。

三、"荟享032A"的单笔成交申报最低数量为10000份，"荟享032B"的单笔成交申报最低数量为10000份，"荟享032C"的单笔成交申报最低数量为10000份。

四、对首次参加"京东荟享3号2期"转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、"京东荟享3号2期"转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
