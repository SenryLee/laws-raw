# 深圳证券交易所关于支付2018年湖北省政府专项债券（一期）等两只债券利息有关事项的通知

## 关于支付2018年湖北省政府专项债券（一期）等两只债券利息有关事项的通知

各市场参与人：

2018年湖北省政府专项债券（一期）、2016年湖北省政府一般债券（二十期）将于2019年3月26日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年湖北省政府专项债券（一期）证券代码为“106398”，证券简称为“湖北1802”，是2018年3月26日发行的3年期债券，票面利率为3.82％，每年支付1次利息，每百元面值债券本次可获利息3.82元。

二、2016年湖北省政府一般债券（二十期）证券代码为“107327”，证券简称为“湖北1620”，是2016年9月26日发行的10年期债券，票面利率为2.77％，每年支付2次利息，每百元面值债券本次可获利息1.385元。

三、从2019年3月18日至2019年3月25日停办上述地方政府债的转托管及调帐业务。

四、上述债券付息债权登记日为2019年3月25日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年3月26日除息交易。

五、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所

二○一九年三月十二日
