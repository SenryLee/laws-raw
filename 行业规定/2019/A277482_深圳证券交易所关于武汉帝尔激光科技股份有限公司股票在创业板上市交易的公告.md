# 深圳证券交易所关于武汉帝尔激光科技股份有限公司股票在创业板上市交易的公告

## 关于武汉帝尔激光科技股份有限公司股票在创业板上市交易的公告

武汉帝尔激光科技股份有限公司人民币普通股股票将于2019年5月17日在本所创业板上市。证券简称为“帝尔激光”，证券代码为“300776”。公司人民币普通股股份总数为66,125,150股，其中16,536,000股股票自上市之日起开始上市交易。
