# 深圳证券交易所关于成都唐源电气股份有限公司股票在创业板上市交易的公告

## 关于成都唐源电气股份有限公司股票在创业板上市交易的公告

成都唐源电气股份有限公司人民币普通股股票将于2019年8月28日在本所创业板上市。证券简称为"唐源电气",证券代码为"300789".公司人民币普通股股份总数为45,982,759股，其中11,500,000股股票自上市之日起开始上市交易。
