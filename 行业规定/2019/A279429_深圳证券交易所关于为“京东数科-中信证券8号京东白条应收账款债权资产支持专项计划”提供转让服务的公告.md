# 深圳证券交易所关于为“京东数科-中信证券8号京东白条应收账款债权资产支持专项计划”提供转让服务的公告

## 关于为“京东数科-中信证券8号京东白条应收账款债权资产支持专项计划”提供转让服务的公告

各相关单位：

根据中信证券股份有限公司申请，本所将自2019年4月19日起在综合协议交易平台为“京东数科-中信证券8号京东白条应收账款债权资产支持专项计划”（以下简称“中信证券京东白条8号”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“中信证券京东白条8号”的转让业务。

二、“中信证券京东白条8号”设立日期为2019年3月28日。优先级资产支持证券如下：证券简称“京东08A1”，证券代码为“139549”，到期日为2020年7月10日，还本付息方式为循环期每季度付息，摊还期每月付息、过手还本。次优先级资产支持证券如下：证券简称“京东08B1”，证券代码为“139550”，到期日为2020年7月10日，还本付息方式为循环期每季度付息，摊还期每月付息、过手还本；证券简称“京东08中”，证券代码为“139551”，到期日为2020年7月10日，还本付息方式为循环期不分配，摊还期待优先级本息全部偿付完毕后付息并过手摊还本金。次级资产支持证券如下：证券简称“京东08次”，证券代码为“139552”，到期日为2020年7月10日，还本付息方式为期间不分配，到期获得剩余资金及资产。

三、“京东08A1”的单笔成交申报最低数量为10000份，“京东08B1”的单笔成交申报最低数量为10000份，“京东08中”的单笔成交申报最低数量为10000份，“京东08次”的单笔成交申报最低数量为10000份。

四、对首次参加“中信证券京东白条8号”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“中信证券京东白条8号”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
