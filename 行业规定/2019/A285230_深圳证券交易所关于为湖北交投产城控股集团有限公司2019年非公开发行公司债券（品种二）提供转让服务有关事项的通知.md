# 深圳证券交易所关于为湖北交投产城控股集团有限公司2019年非公开发行公司债券（品种二）提供转让服务有关事项的通知

## 关于为湖北交投产城控股集团有限公司2019年非公开发行公司债券（品种二）提供转让服务有关事项的通知

各会员单位：

湖北交投产城控股集团有限公司2019年非公开发行公司债券（品种二）定于2019年12月20日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

湖北交投产城控股集团有限公司2019年非公开发行公司债券（品种二）证券代码“114632”，证券简称“19产城02”，发行总额14.5亿元，票面利率4.89%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。
