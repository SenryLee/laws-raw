# 深圳证券交易所关于苏州中来光伏新材股份有限公司可转换公司债券上市交易的公告

## 关于苏州中来光伏新材股份有限公司可转换公司债券上市交易的公告

苏州中来光伏新材股份有限公司发行的1,000,000,000元可转换公司债券自2019年3月22日起在本所上市交易，证券简称为“中来转债”，证券代码为“123019”，上市数量1,000万张。

深圳证券交易所

二〇一九年三月二十日
