# 深圳证券交易所关于2019年江苏省土地储备专项债券（三期）——2019年江苏省政府专项债券（八期）上市交易的通知

## 关于2019年江苏省土地储备专项债券（三期）——2019年江苏省政府专项债券（八期）上市交易的通知

各市场参与人：

2019年江苏省土地储备专项债券（三期）——2019年江苏省政府专项债券（八期）已发行结束，根据财政部有关规定，本期债券于2019年7月3日起在本所上市交易。

本期债券为3年期固定利率附息债，证券编码"105632",证券简称"江苏1911",票面利率3.18%,标准交易单位"10张",2022年7月1日到期还本并支付最后一期利息。
