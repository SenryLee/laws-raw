# 深圳证券交易所关于深圳市锐明技术股份有限公司股票上市交易的公告

## 关于深圳市锐明技术股份有限公司股票上市交易的公告

深圳市锐明技术股份有限公司人民币普通股股票将于2019年12月17日在本所上市。证券简称为“锐明技术”,证券代码为“002970”。公司人民币普通股股份总数为86,400,000股，其中21,600,000股股票自上市之日起开始上市交易。
