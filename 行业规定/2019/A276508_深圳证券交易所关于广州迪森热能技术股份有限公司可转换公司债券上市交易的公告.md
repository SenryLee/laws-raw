# 深圳证券交易所关于广州迪森热能技术股份有限公司可转换公司债券上市交易的公告

## 关于广州迪森热能技术股份有限公司可转换公司债券上市交易的公告

广州迪森热能技术股份有限公司发行的600,000,000元可转换公司债券自2019年4月16日起在本所上市交易，证券简称为“迪森转债”，证券代码为“123023”，上市数量600万张。

深圳证券交易所

二〇一九年四月十二日
