# 深圳证券交易所关于为“首创-华通热力居民供暖收费收益权资产支持专项计划”提供转让服务的公告

## 关于为“首创-华通热力居民供暖收费收益权资产支持专项计划”提供转让服务的公告

各相关单位：

根据首创证券有限责任公司申请，本所将自2019年5月24日起在综合协议交易平台为“首创-华通热力居民供暖收费收益权资产支持专项计划”（以下简称“华通热力ABS”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“华通热力ABS”的转让业务。

二、“华通热力ABS”设立日期为2019年4月30日。优先级资产支持证券如下：证券简称“华通01”，证券代码为“139640”，到期日为2020年4月29日，还本付息方式为定期付息、到期一次还本；证券简称“华通02”，证券代码为“139641”，到期日为2021年4月29日，还本付息方式为定期付息、到期一次还本；证券简称“华通03”，证券代码为“139642”，到期日为2022年4月29日，还本付息方式为定期付息、到期一次还本；证券简称“华通04”，证券代码为“139643”，到期日为2023年4月29日，还本付息方式为定期付息、到期一次还本；证券简称“华通05”，证券代码为“139644”，到期日为2024年4月29日，还本付息方式为定期付息、到期一次还本；证券简称“华通06”，证券代码为“139645”，到期日为2025年4月29日，还本付息方式为定期付息、到期一次还本。

三、“华通01”的单笔成交申报最低数量为10000份，“华通02”的单笔成交申报最低数量为10000份，“华通03”的单笔成交申报最低数量为10000份，“华通04”的单笔成交申报最低数量为10000份，“华通05”的单笔成交申报最低数量为10000份，“华通06”的单笔成交申报最低数量为10000份。

四、对首次参加“华通热力ABS”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“华通热力ABS”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
