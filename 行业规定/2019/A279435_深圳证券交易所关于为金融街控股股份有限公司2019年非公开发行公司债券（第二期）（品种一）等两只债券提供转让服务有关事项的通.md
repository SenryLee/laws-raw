# 深圳证券交易所关于为金融街控股股份有限公司2019年非公开发行公司债券（第二期）（品种一）等两只债券提供转让服务有关事项的通知

## 关于为金融街控股股份有限公司2019年非公开发行公司债券（第二期）（品种一）等两只债券提供转让服务有关事项的通知

各会员单位：

金融街控股股份有限公司2019年非公开发行公司债券（第二期）（品种一）、 金融街控股股份有限公司2019年非公开发行公司债券（第二期）（品种二）定于2019年4月23日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、金融街控股股份有限公司2019年非公开发行公司债券（第二期）（品种一）证券代码“114458”，证券简称“19金控03”，发行总额4亿元，票面利率4.2%，债券期限4年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

2、金融街控股股份有限公司2019年非公开发行公司债券（第二期）（品种二）证券代码“114459”，证券简称“19金控04”，发行总额11亿元，票面利率4.37%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一九年四月十九日
