# 深圳证券交易所关于深圳市尚荣医疗股份有限公司可转换公司债券上市交易的公告

## 关于深圳市尚荣医疗股份有限公司可转换公司债券上市交易的公告

深圳市尚荣医疗股份有限公司发行的75,000万元可转换公司债券自2019年3月7日起在本所上市交易，证券简称为“尚荣转债”，证券代码为“128053”，上市数量750万张。

深圳证券交易所

二〇一九年三月六日
