# 深圳证券交易所关于河南清水源科技股份有限公司可转换公司债券上市交易的公告

## 关于河南清水源科技股份有限公司可转换公司债券上市交易的公告

河南清水源科技股份有限公司发行的490,000,000元可转换公司债券自2019年7月15日起在本所上市交易，证券简称为“清水转债”，证券代码为“123028”，上市数量490万张。

深圳证券交易所

二〇一九年七月十一日
