# 深圳证券交易所关于2018年记账式附息（十期）国债等两只债券到期兑付有关事项的通知

## 关于2018年记账式附息（十期）国债等两只债券到期兑付有关事项的通知

各市场参与人：

2018年记账式附息（十期）国债、2016年青岛市政府一般债券（一期）将于2019年5月17日到期兑付。为做好上述债券的本息兑付工作，现将有关事项通知如下：

一、2018年记账式附息（十期）国债证券代码为“101810”，证券简称为“国债1810”，是2018年5月17日发行的1年期债券，票面利率为3.02%，每年支付1次利息，每百元面值债券兑付可获本息103.02元。

二、2016年青岛市政府一般债券（一期）证券代码为“109958”，证券简称为“青岛1601”，是2016年5月17日发行的3年期债券，票面利率为2.7%，每年支付1次利息，每百元面值债券兑付可获本息102.7元。

三、从2019年5月9日起停办上述附息式国债、地方政府债的转托管及调帐业务。

四、上述债券兑付债权登记日为2019年5月16日，凡于当日收市后持有上述债券的投资者，享有获得本次兑付款项的权利。2019年5月17日上述债券摘牌。

五、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券兑付款项后，将其划入各证券商的清算备付金帐户，并由证券商将兑付资金及时划入各投资者的资金帐户。

深圳证券交易所

二○一九年四月三十日
