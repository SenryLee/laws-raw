# 深圳证券交易所关于青岛农村商业银行股份有限公司股票上市交易的公告

## 关于青岛农村商业银行股份有限公司股票上市交易的公告

青岛农村商业银行股份有限公司人民币普通股股票将于2019年3月26日在本所上市。证券简称为“青农商行”，证券代码为“002958”。公司人民币普通股股份总数为5,555,555,556股，其中555,555,556股股票自上市之日起开始上市交易。
