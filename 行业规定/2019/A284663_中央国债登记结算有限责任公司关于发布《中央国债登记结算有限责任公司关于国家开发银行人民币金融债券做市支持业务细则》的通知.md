# 中央国债登记结算有限责任公司关于发布《中央国债登记结算有限责任公司关于国家开发银行人民币金融债券做市支持业务细则》的通知

## 关于发布《中央国债登记结算有限责任公司关于国家开发银行人民币金融债券做市支持业务细则》的通知

中债字〔2019〕198号

各结算成员：

为规范国家开发银行人民币金融债券做市支持操作行为，促进债券市场健康发展，根据《全国银行间债券市场债券交易管理办法》（中国人民银行令〔2000〕第2号发布）、《银行间债券市场债券登记托管结算管理办法》（中国人民银行令〔2009〕第1号发布）、中国人民银行公告〔2013〕第12号等有关规定，中央国债登记结算有限责任公司制定了《中央国债登记结算有限责任公司关于国家开发银行人民币金融债券做市支持业务细则》，现予以发布。

特此通知。
