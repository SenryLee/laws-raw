# 深圳证券交易所关于华侨城集团有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）上市有关事项的通知

## 关于华侨城集团有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）上市有关事项的通知

各会员单位：

华侨城集团有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）定于2019年4月26日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

华侨城集团有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）证券代码“112886”，证券简称“19侨集01”，发行总额25亿元，票面利率3.93%，债券期限5年， 附第3年末发行人调整票面利率选择权和投资者回售选择权。

特此通知
