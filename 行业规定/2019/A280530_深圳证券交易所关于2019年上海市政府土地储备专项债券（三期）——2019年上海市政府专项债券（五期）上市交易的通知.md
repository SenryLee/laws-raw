# 深圳证券交易所关于2019年上海市政府土地储备专项债券（三期）——2019年上海市政府专项债券（五期）上市交易的通知

## 关于2019年上海市政府土地储备专项债券（三期）——2019年上海市政府专项债券（五期）上市交易的通知

各市场参与人：

2019年上海市政府土地储备专项债券（三期）——2019年上海市政府专项债券（五期）已发行结束，根据财政部有关规定，本期债券于2019年6月20日起在本所上市交易。

本期债券为5年期固定利率附息债，证券编码“105574”，证券简称“上海1907”，票面利率3.34％，标准交易单位“10张”，2024年6月18日到期还本并支付最后一期利息。
