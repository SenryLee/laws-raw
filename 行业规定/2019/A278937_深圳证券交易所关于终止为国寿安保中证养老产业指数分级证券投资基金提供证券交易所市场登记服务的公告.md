# 深圳证券交易所关于终止为国寿安保中证养老产业指数分级证券投资基金提供证券交易所市场登记服务的公告

## 关于终止为国寿安保中证养老产业指数分级证券投资基金提供证券交易所市场登记服务的公告

因国寿安保中证养老产业指数分级证券投资基金（简称“国寿养老”）已在深圳证券交易所终止申购和赎回，我公司根据有关规定已于2019年7月2日终止为其提供证券交易所市场的登记服务，并已于同日按合同约定终止我公司与国寿安保基金管理有限公司之间涉及“国寿养老”的场内证券登记合同关系。

我公司已将相应的基金登记数据移交给基金管理人国寿安保基金管理有限公司。对于“国寿养老”原由证券公司受理的司法协助冻结、质押登记等业务，请有关证券公司将数据及书面材料及时移交国寿安保基金管理有限公司，避免由此产生不必要的法律责任。

中国证券登记结算有限责任公司深圳分公司

二〇一九年七月二日
