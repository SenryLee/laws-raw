# 深圳证券交易所关于2018年记账式附息（二十六期）国债到期兑付有关事项的通知

## 关于2018年记账式附息（二十六期）国债到期兑付有关事项的通知

各市场参与人：

2018年记账式附息（二十六期）国债将于2019年11月22日到期兑付。为做好本期债券的本息兑付工作，现将有关事项通知如下：

一、本期债券证券代码为“101826”，证券简称为“国债1826”，是2018年11月22日发行的1年期债券，票面利率为2.41%，每年支付1次利息，每百元面值债券兑付可获本息102.41元。

二、从2019年11月14日起停办本期附息式国债的转托管及调帐业务。

三、本期债券兑付债权登记日为2019年11月21日，凡于当日收市后持有本期债券的投资者，享有获得本次兑付款项的权利。2019年11月22日本期债券摘牌。

四、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的本期债券兑付款项后，将其划入各证券商的清算备付金账户，并由证券商将兑付资金及时划入各投资者的资金账户。

深圳证券交易所
