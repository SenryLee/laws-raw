# 中国证券登记结算有限责任公司关于做好深市衍生品合约账户开户工作的通知

## 关于做好深市衍生品合约账户开户工作的通知

各期权经营机构：

为配合深圳证券交易所股票期权业务平稳推出，便于投资者参与深市股票期权交易，根据《中国证券登记结算有限责任公司关于深圳证券交易所股票期权试点结算业务实施细则》相关要求，现将投资者开立深市衍生品合约账户有关事项通知如下：

**一、**投资者申请开立深市衍生品合约账户，须符合参与深圳证券交易所股票期权业务的适当性管理要求，严格遵循自愿原则。各期权经营机构应当根据投资者真实意愿，为客户做好衍生品合约账户开立及销户业务。

**二、**各期权经营机构在取得深市衍生品合约账户配号开户权限（相关要求见《中国证券登记结算有限责任公司开户代理机构管理业务指南》，申请表见附件）后，可办理衍生品合约账户开户相关业务。

**三、**期权经营机构应要求客户按规则临柜办理深市衍生品合约账户开户业务。为方便投资者，对于已经开立沪市衍生品合约账户的投资者，可在开立沪市衍生品合约账户的期权经营机构，按照本公司非现场开户有关规定通过见证、网上等方式开立深市衍生品合约账户。

**四、**为进一步做好深市衍生品合约账户开户准备工作，各期权经营机构可为投资者办理预开户手续，开展投资者宣传教育，与投资者签署适当性管理相关文件,受理投资者深市衍生品合约账户开户申请等工作。自2019年12月9日起，本公司统一账户平台开始接收各期权经营机构发送的深市衍生品合约账户配号申请数据，并于当日日终反馈配号处理结果。

特此通知。

附件：开户代理业务权限申请表
