# 上海证券交易所关于聘任上海证券交易所第一届科技创新咨询委员会委员的公告

## 关于聘任上海证券交易所第一届科技创新咨询委员会委员的公告

上证公告〔2019〕18号

根据《关于在上海证券交易所设立科创板并试点注册制的实施意见》《科创板首次公开发行股票注册管理办法（试行）》和《上海证券交易所科技创新咨询委员会工作规则》等相关规定，经相关程序，决定聘任以下48人为上海证券交易所第一届科技创新咨询委员会委员（按姓氏笔画排序）：

丁健、王亚东、王晓秋、王海峰、毛军发、方滨兴、尹志尧、邓中翰、邓龙江、邓志东、石远凯、叶甜春、包凡、冯建峰、朱知寿、任忠鸣、刘多、刘啸东、李仲平、李进、李革、李蓬、何金良、沈南鹏、张卫、张永明、张旭、张江、张兴、张连山、张宏科、张磊、陆珏、林向红、欧阳明高、赵元富、姜澜、秦叔逵、夏宁邵、徐波、梅宏、康锐、彭练矛、蒋华良、蒋昌俊、谭蔚泓、戴晓虎、魏化震。
