# 深圳证券交易所关于为“申港-滨丽小城镇保障房信托受益权资产支持专项计划”提供转让服务的公告

## 关于为“申港-滨丽小城镇保障房信托受益权资产支持专项计划”提供转让服务的公告

各相关单位：

根据申港证券股份有限公司申请，本所将自2019年5月9日起在综合协议交易平台为“申港-滨丽小城镇保障房信托受益权资产支持专项计划”（以下简称“滨丽小城镇”）提供转让服务。现就有关事项公告如下：

一、 持有深圳A股证券账户和基金账户的合格投资者可以参与“滨丽小城镇”的转让业务。

二、 “滨丽小城镇”设立日期为2019年4月17日。优先级资产支持证券如下：证券简称“滨丽二01”，证券代码为“139574”，到期日为2020年1月25日，还本付息方式为定期付息、到期一次还本；证券简称“滨丽二02”，证券代码为“139575”，到期日为2021年1月25日，还本付息方式为定期付息、到期一次还本；证券简称“滨丽二03”，证券代码为“139576”，到期日为2022年1月25日，还本付息方式为定期付息、到期一次还本。

三、 “滨丽二01”的单笔成交申报最低数量为10000份，“滨丽二02”的单笔成交申报最低数量为10000份，“滨丽二03”的单笔成交申报最低数量为10000份。

四、 对首次参加“滨丽小城镇”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、 “滨丽小城镇”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
