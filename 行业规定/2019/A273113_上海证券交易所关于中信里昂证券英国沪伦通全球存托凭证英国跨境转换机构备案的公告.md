# 上海证券交易所关于中信里昂证券英国沪伦通全球存托凭证英国跨境转换机构备案的公告

## 关于中信里昂证券英国沪伦通全球存托凭证英国跨境转换机构备案的公告

上证公告〔2019〕2号

根据《上海证券交易所与伦敦证券交易所互联互通存托凭证上市交易暂行办法》《上海证券交易所与伦敦证券交易所互联互通存托凭证跨境转换业务指引》的相关规定，上海证券交易所对中信里昂证券英国（CLSA（UK））予以沪伦通全球存托凭证英国跨境转换机构备案。

特此公告。

上海证券交易所

二〇一九年一月九日
