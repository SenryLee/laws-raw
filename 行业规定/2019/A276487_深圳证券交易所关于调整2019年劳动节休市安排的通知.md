# 深圳证券交易所关于调整2019年劳动节休市安排的通知

## 关于调整2019年劳动节休市安排的通知

各市场参与人：

根据国务院办公厅和中国证监会有关通知要求，本所对《关于2019年部分节假日休市安排的通知》（深证会〔2018〕569号）中有关劳动节休市安排进行调整，现通知如下：

一、休市安排

5月1日（星期三）至5月4日（星期六）休市，5月6日（星期一）起照常开市。4月28日（星期日）和5月5日（星期日）为周末休市。

二、清算交收

节假日期间清算交收事宜，按照中国证券登记结算有限责任公司有关安排进行。

请各市场参与人据此安排好有关工作。

深圳证券交易所

2019年4月18日
