# 深圳证券交易所关于2019年深圳市（福田区）棚户区改造专项债券（一期）——2019年深圳市政府专项债券（二十一期）上市交易的通知

## 关于2019年深圳市（福田区）棚户区改造专项债券（一期）——2019年深圳市政府专项债券（二十一期）上市交易的通知

各市场参与人：

2019年深圳市（福田区）棚户区改造专项债券（一期）——2019年深圳市政府专项债券（二十一期）已发行结束，根据财政部有关规定，本期债券于2019年7月15日起在本所上市交易。

本期债券为7年期固定利率附息债，证券编码"104656",证券简称"深圳1923",票面利率3.44%,标准交易单位"10张",附赎回选择权条款，2026年7月11日到期还本并支付最后一期利息。
