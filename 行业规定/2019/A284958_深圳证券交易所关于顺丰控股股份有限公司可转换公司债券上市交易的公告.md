# 深圳证券交易所关于顺丰控股股份有限公司可转换公司债券上市交易的公告

## 关于顺丰控股股份有限公司可转换公司债券上市交易的公告

顺丰控股股份有限公司发行的5,800,000,000元可转换公司债券自2019年12月9日起在本所上市交易，证券简称为“顺丰转债”，证券代码为“128080”，上市数量5,800万张。

深圳证券交易所
