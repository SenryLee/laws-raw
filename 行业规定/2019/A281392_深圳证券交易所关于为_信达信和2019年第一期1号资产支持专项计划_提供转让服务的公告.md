# 深圳证券交易所关于为"信达信和2019年第一期1号资产支持专项计划"提供转让服务的公告

## 关于为"信达信和2019年第一期1号资产支持专项计划"提供转让服务的公告

各相关单位：

根据信达证券股份有限公司申请，本所将自2019年7月19日起在综合协议交易平台为"信达信和2019年第一期1号资产支持专项计划"（以下简称"信和01"）提供转让服务。现就有关事项公告如下：

一、 持有深圳A股证券账户和基金账户的合格投资者可以参与"信和01"的转让业务。

二、 "信和01"设立日期为2019年6月28日。优先级资产支持证券如下：证券简称"信和01A1",证券代码为"139779",到期日为2022年1月10日，还本付息方式为定期付息、过手还本。次优先级资产支持证券如下：证券简称"信和01A2",证券代码为"139780",到期日为2022年7月15日，还本付息方式为定期付息、过手还本；证券简称"信和01B",证券代码为"139781",到期日为2022年7月15日，还本付息方式为定期付息、过手还本；证券简称"信和01C",证券代码为"139782",到期日为2022年7月15日，还本付息方式为定期付息、过手还本。次级资产支持证券如下：证券简称"信和01次",证券代码为"139783",到期日为2022年7月15日，还本付息方式为定期支付期间收益，劣后于优先级产品获得剩余收益。

三、 "信和01A1"的单笔成交申报最低数量为10000份，"信和01A2"的单笔成交申报最低数量为10000份，"信和01B"的单笔成交申报最低数量为10000份，"信和01C"的单笔成交申报最低数量为10000份，"信和01次"的单笔成交申报最低数量为10000份。

四、 对首次参加"信和01"转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、 "信和01"转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
