# 深圳证券交易所关于华讯方舟股份有限公司股票临时停牌的公告

## 关于华讯方舟股份有限公司股票临时停牌的公告

华讯方舟股份有限公司称股东拟筹划控制权变更事项，根据本所《股票上市规则》和《深圳证券交易所上市公司信息披露指引第2号——停复牌业务》的有关规定，经公司申请，公司证券（证券简称：华讯方舟，证券代码：000687）于2019年7月24日开市起临时停牌，待公司通过指定媒体披露相关公告后复牌，敬请投资者密切关注。

深圳证券交易所
