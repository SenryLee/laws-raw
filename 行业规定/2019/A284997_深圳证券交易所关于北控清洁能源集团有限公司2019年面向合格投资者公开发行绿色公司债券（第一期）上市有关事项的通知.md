# 深圳证券交易所关于北控清洁能源集团有限公司2019年面向合格投资者公开发行绿色公司债券（第一期）上市有关事项的通知

## 关于北控清洁能源集团有限公司2019年面向合格投资者公开发行绿色公司债券（第一期）上市有关事项的通知

各会员单位：

北控清洁能源集团有限公司2019年面向合格投资者公开发行绿色公司债券（第一期）（品种二）定于2019年12月13日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

北控清洁能源集团有限公司2019年面向合格投资者公开发行绿色公司债券（第一期）（品种二）证券代码“149007”，证券简称“19北控PG”，发行总额5亿元，票面利率5.99%，债券期限3年,附第2年末发行人调整票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所
