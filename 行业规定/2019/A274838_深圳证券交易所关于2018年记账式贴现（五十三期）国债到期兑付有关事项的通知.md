# 深圳证券交易所关于2018年记账式贴现（五十三期）国债到期兑付有关事项的通知

## 关于2018年记账式贴现（五十三期）国债到期兑付有关事项的通知

各市场参与人：

2018年记账式贴现（五十三期）国债将于2019年2月18日到期兑付。为做好本期债券的本息兑付工作，现将有关事项通知如下：

一、本期债券证券代码为“108270”，证券简称为“贴债1853”，是2018年11月19日发行的91日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

二、从2019年2月1日起停办本期贴现式国债的转托管及调帐业务。

三、本期债券兑付债权登记日为2019年2月15日，凡于当日收市后持有本期债券的投资者，享有获得本次兑付款项的权利。2019年2月18日本期债券摘牌。

四、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的本期债券兑付款项后，将其划入各证券商的清算备付金帐户，并由证券商将兑付资金及时划入各投资者的资金帐户。

深圳证券交易所
