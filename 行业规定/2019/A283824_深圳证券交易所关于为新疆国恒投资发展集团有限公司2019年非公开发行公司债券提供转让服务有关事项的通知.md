# 深圳证券交易所关于为新疆国恒投资发展集团有限公司2019年非公开发行公司债券提供转让服务有关事项的通知

## 关于为新疆国恒投资发展集团有限公司2019年非公开发行公司债券提供转让服务有关事项的通知

各会员单位：

新疆国恒投资发展集团有限公司2019年非公开发行公司债券定于2019年11月11日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

新疆国恒投资发展集团有限公司2019年非公开发行公司债券证券代码“114596”，证券简称“19国恒01”，发行总额6.4亿元，票面利率7.5%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一九年十一月八日
