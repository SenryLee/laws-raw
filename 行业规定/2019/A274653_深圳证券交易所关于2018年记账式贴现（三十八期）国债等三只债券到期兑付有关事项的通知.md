# 深圳证券交易所关于2018年记账式贴现（三十八期）国债等三只债券到期兑付有关事项的通知

## 关于2018年记账式贴现（三十八期）国债等三只债券到期兑付有关事项的通知

各市场参与人：

2018年记账式贴现（三十八期）国债、2018年记账式贴现（五十期）国债、2018年记账式贴现（五十一期）国债将于2019年2月11日到期兑付。为做好上述债券的本息兑付工作，现将有关事项通知如下：

一、2018年记账式贴现（三十八期）国债证券代码为“108254”，证券简称为“贴债1838”，是2018年8月13日发行的182日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

二、2018年记账式贴现（五十期）国债证券代码为“108267”，证券简称为“贴债1850”，是2018年11月5日发行的91日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

三、2018年记账式贴现（五十一期）国债证券代码为“108269”，证券简称为“贴债1851”，是2018年11月12日发行的91日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

四、从2019年1月25日起停办上述贴现式国债的转托管及调帐业务。

五、上述债券兑付债权登记日为2019年2月1日，凡于当日收市后持有上述债券的投资者，享有获得本次兑付款项的权利。2019年1月31日上述债券摘牌。

六、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券兑付款项后，将其划入各证券商的清算备付金帐户，并由证券商将兑付资金及时划入各投资者的资金帐户。
