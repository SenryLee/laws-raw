# 深圳证券交易所关于深圳市亚泰国际建设股份有限公司可转换公司债券上市交易的公告

## 关于深圳市亚泰国际建设股份有限公司可转换公司债券上市交易的公告

深圳市亚泰国际建设股份有限公司发行的480,000,000元可转换公司债券自2019年5月14日起在本所上市交易，证券简称为“亚泰转债”，证券代码为“128066”，上市数量480万张。

深圳证券交易所

二〇一九年五月十三日
