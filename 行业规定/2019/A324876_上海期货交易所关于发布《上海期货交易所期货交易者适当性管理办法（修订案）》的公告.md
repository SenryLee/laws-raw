# 上海期货交易所关于发布《上海期货交易所期货交易者适当性管理办法（修订案）》的公告

上海期货交易所公告〔2019〕30号

为了切实维护投资者合法权益，防范市场风险，保障期货市场平稳、规范、健康发展，我所对《上海期货交易所期货交易者适当性管理办法》作了修订。上述修订已经我所理事会审议通过并报告中国证监会，现予以公布，自公布之日起施行。

英文文本见官方英文网站，仅供参考。如与中文文本不一致，以中文文本为准。

特此通知。
