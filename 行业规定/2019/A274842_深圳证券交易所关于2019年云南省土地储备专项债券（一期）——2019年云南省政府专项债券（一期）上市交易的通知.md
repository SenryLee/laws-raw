# 深圳证券交易所关于2019年云南省土地储备专项债券（一期）——2019年云南省政府专项债券（一期）上市交易的通知

## 关于2019年云南省土地储备专项债券（一期）——2019年云南省政府专项债券（一期）上市交易的通知

各市场参与人：

2019年云南省土地储备专项债券（一期）——2019年云南省政府专项债券（一期）已发行结束，根据财政部有关规定，本期债券于2019年1月31日起在本所上市交易。

本期债券为5年期固定利率附息债，证券编码“105185”，证券简称“云南1905”，票面利率3.34％，标准交易单位“10张”，2024年1月29日到期还本并支付最后一期利息。
