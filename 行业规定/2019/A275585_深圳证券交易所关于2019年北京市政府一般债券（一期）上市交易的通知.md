# 深圳证券交易所关于2019年北京市政府一般债券（一期）上市交易的通知

## 关于2019年北京市政府一般债券（一期）上市交易的通知

各市场参与人：

2019年北京市政府一般债券（一期）已发行结束，根据财政部有关规定，本期债券于2019年2月12日起在本所上市交易。

本期债券为3年期固定利率附息债，证券编码“105223”，证券简称“北京1901”，票面利率2.97％，标准交易单位“10张”，2022年2月1日到期还本并支付最后一期利息。
