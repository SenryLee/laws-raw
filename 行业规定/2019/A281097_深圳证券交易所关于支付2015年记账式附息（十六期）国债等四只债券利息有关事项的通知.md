# 深圳证券交易所关于支付2015年记账式附息（十六期）国债等四只债券利息有关事项的通知

## 关于支付2015年记账式附息（十六期）国债等四只债券利息有关事项的通知

各市场参与人：

2015年记账式附息（十六期）国债、2018年江苏省政府一般债券（四期）、2018年江苏省政府一般债券（五期）、2018年江苏省政府专项债券（三期）将于2019年7月16日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2015年记账式附息（十六期）国债证券代码为"101516",证券简称为"国债1516",是2015年7月16日发行的10年期债券，票面利率为3.51%,每年支付2次利息，每百元面值债券本次可获利息1.755元。

二、2018年江苏省政府一般债券（四期）证券代码为"106614",证券简称为"江苏1806",是2018年7月16日发行的5年期债券，票面利率为3.7%,每年支付1次利息，每百元面值债券本次可获利息3.7元。

三、2018年江苏省政府一般债券（五期）证券代码为"106615",证券简称为"江苏1807",是2018年7月16日发行的10年期债券，票面利率为3.93%,每年支付2次利息，每百元面值债券本次可获利息1.965元。

四、2018年江苏省政府专项债券（三期）证券代码为"106616",证券简称为"江苏1808",是2018年7月16日发行的3年期债券，票面利率为3.6%,每年支付1次利息，每百元面值债券本次可获利息3.6元。

五、从2019年7月8日至2019年7月15日停办上述附息式国债、地方政府债的转托管及调帐业务。

六、上述债券付息债权登记日为2019年7月15日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年7月16日除息交易。

七、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
