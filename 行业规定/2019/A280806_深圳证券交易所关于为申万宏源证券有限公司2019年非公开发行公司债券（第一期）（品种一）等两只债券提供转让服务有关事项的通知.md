# 深圳证券交易所关于为申万宏源证券有限公司2019年非公开发行公司债券（第一期）（品种一）等两只债券提供转让服务有关事项的通知

## 关于为申万宏源证券有限公司2019年非公开发行公司债券（第一期）（品种一）等两只债券提供转让服务有关事项的通知

各会员单位：

申万宏源证券有限公司2019年非公开发行公司债券（第一期）（品种一）、 金融街控股股份有限公司2019年非公开发行公司债券（第四期）（品种二）定于2019年7月1日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、申万宏源证券有限公司2019年非公开发行公司债券（第一期）（品种一）证券代码“114499”，证券简称“19申证07”，发行总额10亿元，票面利率3.9%，债券期限2年。

2、金融街控股股份有限公司2019年非公开发行公司债券（第四期）（品种二）证券代码“114504”，证券简称“19金控08”，发行总额10亿元，票面利率4.35%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。
