# 深圳证券交易所关于为福建漳龙集团有限公司2019年非公开发行公司债券（第二期）提供转让服务有关事项的通知

## 关于为福建漳龙集团有限公司2019年非公开发行公司债券（第二期）提供转让服务有关事项的通知

各会员单位：

福建漳龙集团有限公司2019年非公开发行公司债券（第二期）定于2019年4月29日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

福建漳龙集团有限公司2019年非公开发行公司债券（第二期）证券代码“114463”，证券简称“19漳龙02”，发行总额14亿元，票面利率5.15%，债券期限5年，附第3年末发行人调整票面利率选择权及投资者回售选择权。

深圳证券交易所

二○一九年四月二十五日
