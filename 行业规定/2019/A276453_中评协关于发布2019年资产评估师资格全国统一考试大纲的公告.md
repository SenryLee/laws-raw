# 中评协关于发布2019年资产评估师资格全国统一考试大纲的公告

中评协公告〔2019〕8号

根据《中华人民共和国资产评估法》和《人力资源社会保障部 财政部关于修订印发〈资产评估师职业资格制度暂行规定〉和〈资产评估师职业资格考试实施办法〉的通知》（人社部规〔2017〕7号）有关规定，中国资产评估协会组织制定了《2019年资产评估师资格全国统一考试大纲》，已经人力资源社会保障部、财政部审议通过，现予公告。

附件：《2019年资产评估师资格全国统一考试大纲》

中国资产评估协会

2019年4月19日
