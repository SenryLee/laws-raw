# 中国物业管理协会发展规划（2019—2023年）

（经中国物业管理协会第五次会员代表大会审议通过）

中国物业管理协会第五届理事会任期的2019-2023年，是全面贯彻落实十九大精神的重要时期，是“两个一百年”奋斗目标的历史交汇期；是满足人民群众对美好生活日益增长需要，深化供给侧结构性改革，推动物业管理行业高质量发展的关键时期；也是本会建立健全内部治理结构，充分激发内生动力和发展活力，大有作为的战略机遇期。为加强中国物业管理协会（以下简称“中国物协”）工作的前瞻性、战略性、系统性，依照《中国物业管理协会章程》，制定《中国物业管理协会发展规划（2019-2023年）》。

**一、**指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，全面落实创新、协调、绿色、开放、共享的发展理念，在中央和国家机关工委、民政部、住房和城乡建设部的领导下，以党建工作为统领，按照本会章程，秉承“务实 开放 服务 创新”的办会宗旨，强化自身建设，创新思路、真抓实干、锐意进取，积极发挥服务政府、服务社会、服务会员的作用，代表最广大会员单位的利益，营造有利于行业发展的社会环境和市场环境，为政府决策“建言献策”，为社会进步“添砖加瓦”，为会员发展“保驾护航”，把本会建设成为具有良好公信力、影响力和权威性的全国性行业协会，构建兼具生活性与生产性双重特征的现代物业服务体系，促进物业管理行业向现代服务业转型升级。

**二、**发展目标

（一）广泛性和代表性进一步增强。

扩大会员单位规模和覆盖面，积极发展管理规范、信用度高、经营效益好、社会责任感强的优秀物业服务企业，凝聚关联度高、品牌形象好的上下游企业成为会员单位，全面增强协会的广泛性和代表性。

（二）内部治理结构进一步健全。

建立健全法人治理结构，完善会员代表大会、理事会、监事会制度，落实民主选举、民主决策和民主管理，建立科学决策机制，健全内部监督机制，优化内部治理结构，推进协会持续健康发展。

（三）服务会员的能力进一步提升。

结合协会多维度资源优势，加强测评服务、信息服务、信用服务、法律服务、标准化建设服务等内容，提供面向中小型物业服务企业的普惠性基本服务和面向企业高质量发展的个性化定制服务，提高会员对协会的认可度、非会员对协会的向往度。

（四）引导行业发展的能力进一步增强。

引导行业转变发展方式，改善供需结构，推动行业向现代服务业转型升级；引导行业加强标准化建设，推动行业高质量发展的标准体系建设；引导行业整合资源，提高行业集中度，达到规模效应；引导行业加快技术创新和互联网应用，实现降本增效；引导行业服务社会，参与扶贫攻坚和乡村振兴，承担社会责任。

（五）桥梁纽带的作用进一步发挥。

加强行业专家人才队伍建设，为政府部门制定行政法规和产业政策提供有力的智力支持。通过各级两会提案、媒体舆论、内参报告等方式，充分反映行业诉求，为行业发展创造良好政策和市场环境，努力破解行业发展难题。

（六）业务国际化步伐进一步加快。

搭建与国际组织和企业的沟通平台，响应国家“一带一路”倡议，加强国际交流考察、业务合作、标准对接、国际会议等工作，为物业服务企业“走出去”创造良好环境，在开放竞争中拓展空间、提升水平，基本形成开放合作、互利共赢的对外业务交流新格局，努力塑造行业良好的国际形象。

**三、**工作原则

（一）坚持服务为本、协同发展。

坚持协会发展宗旨，为政府、行业和会员提供服务，贯彻落实党和国家的大政方针和政策法规，切实维护行业和会员合法权益，高度重视并主动服务中小企业发展，提升中小企业专业化发展能力，增强行业发展的凝聚力和创造力，团结动员全体会员单位推动物业管理行业持续健康发展。

（二）坚持质量至上、优质发展。

以市场需求为导向，顺应消费升级趋势，提升服务品质，充分尊重政府市场监管作用的发挥和市场在资源配置中的决定性作用。树立质量第一的意识，健全物业服务质量提升和管控体系，打造以标准、质量、品牌为核心的竞争优势，全面提高物业管理行业的发展质量和效率。

（三）坚持创新驱动、融合发展。

把发展基点放在创新上，营造良好创新环境，促进新技术、新产业、新业态、新模式蓬勃发展，增强发展新动能。以改革推动行业发展，顺应服务业发展规律，推动制度体系和发展环境系统性优化，最大限度激发市场活力，促进质量变革、效率变革、动力变革。推进物业服务业与不同领域产业经济间的深度融合，形成有利于提升行业核心竞争力的服务能力和服务模式。

（四）坚持生态文明、绿色发展。

绿色发展是建设生态文明、构建高质量现代化经济体系的必然要求。面对新时代生态文明建设和生态环境保护的新形势，要充分运用市场化手段，推动形成物业管理行业的绿色发展格局、产业结构和生产方式，不断满足人民群众日益增长的优美生态环境需要。

（五）坚持重点突破、特色发展。

深入研判行业发展趋势，集中力量破解关键领域和薄弱环节的发展难题，持续推动物业管理向现代物业服务业的转型升级。鼓励各地发挥比较优势、培育竞争优势，发展各具特色的服务形态，促进行业集中度的提升和整体实力的增强。

**四、**重点任务

（一）加强诚信自律，促进行业公平规范发展。

1.科学制定行规行约。完善《物业管理行业从业人员职业道德规范》和《中国物业管理协会会员诚信自律公约》，研究制定《物业管理行业信用信息管理办法》，明确行业各方主体的权利与义务，规范从业人员执业和会员单位经营的行为，营造诚信执业良好氛围，维护行业整体利益和会员单位合法权益。

2.加快信用体系建设。启动会员单位信用建设工作，与地方协会联合建设横向联动、纵向贯通、数据共享、业务协同的会员单位信用信息平台；与第三方信用服务机构合作，对会员单位的信用状况进行评估，完善会员信用评价机制，基本建立企业信用联合激励、惩戒机制；建立协会与政府间的信用信息互联共享，推进行业自律在社会信用体系建设中发挥积极作用。

3.健全行业调解组织体系。按照中办、国办《关于完善矛盾纠纷多元化解机制的意见》的有关要求，健全和完善行业内推行多元化纠纷调解工作的基础条件，建立民主协商和会员内部矛盾解决机制，组建调解仲裁专家队伍，引导设立行业纠纷调解和仲裁组织，畅通纠纷受理渠道，对涉及影响行业的重大法律事项及时组织调查，协助解决业内争议。

（二）建立会员动态管理，提升服务的广度和深度。

1.完善会员单位管理制度。修改完善《中国物业管理协会会员管理办法》，理顺协会各层级物业服务企业会员、供应商会员、专委会会员关系，明确协会对会员服务的职能和界限。健全会员单位信息数据库，及时、动态调整会员档案，丰富会员资料内容。对会员情况进行动态分析，建立会员单位积分管理制度，为提高服务的有效性、针对性提供指引。

2.完善会员单位需求反馈机制。以问题为导向，通过实地调研、召开座谈会、代表提案等形式，了解掌握会员在发展中的困难，维护会员合法权益，及时向国家有关部门反映会员诉求；建立畅通的会员沟通机制，帮助会员及时了解行业最新发展方向，理清发展思路，开拓经营眼界，探索解决行业发展中的热点、难点问题。

3.拓展服务内容赋能企业发展。着力丰富对会员单位的普惠服务内容，通过定期发送资料汇编、研究报告、期刊杂志和平台查询等方式，提供有关数据、信息共享服务，创新服务手段，提高服务的广度和深度。利用BIM、大数据、人工智能、5G等信息技术，搭建共享的“智慧物业”信息化平台建设，助力企业数字化转型。围绕居家养老、住房经纪、金融、教育、旅游、新零售等业主多元化需求，整合行业内外、社区线上线下的优质资源，赋能企业增值服务内容，形成差异化竞争优势。

（三）开展理论研究，提升行业建言献策能力。

1.明确重点研究领域。根据新时代对行业提出的新要求，动态关注行业与上下游产业、新经济之间的关系，加强对物业管理宏观发展趋势研究、物业管理转型升级前瞻性问题研究、物业管理行业法律法规和政策研究、物业管理改革与创新研究、绿色物业管理可持续发展研究、物业管理行业发展热点难点问题、物业管理供需形势与市场化分析等重点方向，持续深化开展研究工作。

2.多维度开展研究工作。整合行业多方研究力量，形成年度招标2-3个重点课题研究项目，秘书处开展3-5个行业发展热点难点问题专题调研，协会各所属机构每年开展不少于1项本领域专项研究，会员单位自主申报协会年度课题研究项目等多维度研究体系。分专业研究领域建立相对稳定、有前沿研究能力的专家队伍，作为协会重要的智力支持力量。

3.形成系列研究成果。逐步形成以反映行业发展情况为主的《物业管理行业发展报告》《物业管理党建工作报告》《物业管理创新发展报告》《物业管理社会责任报告》等年度报告系列；以行业前沿性问题、热点难点问题研究为主的《物业服务企业竞争力报告》《物业服务企业满意度调研报告》《绿色物业管理发展研究报告》《物业管理行业劳动力市场价格监测报告》等专题报告系列；以物业资讯、政策法规、年度事件盘点、行业大事记等形式为主的咨询产品系列。为政府部门、会员单位、科研机构和企业家提供决策参考服务。

4.加强研究成果转化。通过公开出版《中国物业管理行业年鉴》、汇编《物业管理课题研究优秀成果集》、举办专业学术研讨会、开发培训教育课程等转化方式，分享研究成果；建立与业界各级人大代表和政协委员、新闻媒体等特定群体的沟通交流渠道，共享成果，互通有无，使研究成果成为“两会”提案、媒体内参的重要支撑，提高成果建议的转化率。

（四）深化标准化建设，推动行业高质量发展。

1.做好标准顶层设计规划。发布《物业管理行业团体标准发展规划》，规范做好团体标准的立项、编制、审查、批准发布、出版发行和管理等环节，扎实推进团体标准研制工作；引导企业和行业从业人员提升对标准化工作的认知，将“标准化”管理思路，融入到物业管理日常工作中，发挥标准对行业规范化、专业化提升的价值。

2.提高标准的供给水平。配合做好《物业管理术语》《物业服务顾客满意度测评》《物业服务安全与应急处置》三项国家标准的编撰工作；在行业重点关注的服务质量评价、物业服务合同要素、企业诚信评价等方面开展团体标准立项和编撰工作，加大团体标准供给。

3.引领企业标准的制定实施。协助会员单位主动制定和实施先进标准，从企业标准化建设投入、标准化活动参与度、标准的经济社会效益等方面进行综合测评，开展企业标准化水平评价工作，培育一批企业标准“领跑者”，树立企业标准领先、协会引导、市场驱动、协同推进的标准化建设格局。

4.强化标准实施落地。通过标准宣贯会、专题培训班、远程教育等方式，加大标准的宣贯力度；以发布的团体标准作为主要依据，通过制定评定办法和细则，对物业服务企业、从业人员、物业管理项目等内容开展第三方服务认证和评价；在标准化课题研究、标准编写和业务培训过程中，发掘专家和骨干，组建行业标准化人才库；注重学习借鉴国外先进的标准化管理经验，促进国内外标准的相互转换，推动行业与国际标准的接轨。

（五）把握舆论导向，优化行业发展环境。

1.加强行业文化引领。进一步宣传和推广社会主义核心价值观，挖掘和广泛宣传践行“诚信服务、务实创新、专业规范、共治和谐”行业精神的人物事迹，激发和弘扬企业家精神和工匠精神。讲好行业故事，传播行业声音，阐释行业价值，逐步形成全行业认可的共同价值理念，增强从业人员的使命感、归属感、荣誉感和成就感。

2.明确“两网一微一刊”的定位。全国物业管理媒体协作网要凝聚行业媒体资源，创新运作方式，提升行业宣传和信息交流工作的整体水平；协会网站要逐步丰富栏目版块内容，搭建行业信息资料库和数据库，成为行业的信息查询平台；微信公众号继续发挥移动端优势，优化内容输出，成为行业的信息流量端口；《中国物业管理》杂志要提高办刊水平和发文质量，力争成为行业的核心期刊。努力把“两网一微一刊”办成行业的文化阵地和会员信息之窗。

3.做好行业舆情监测工作。注重加强舆情管理，通过专业理论学习、舆情应对实践，不断增强协会的政策把握能力、舆情研判能力、释疑解惑能力和回应引导能力；建立协会信息发布内容审核、舆情监测和回应机制，定期发布《物业管理行业舆情监测报告》；提高对行业热点事件、突发事件宣传报道的客观性和时效性，任命政治可靠、业务精通的新闻发言人，逐步建立协会新闻发布制度。

4.推动行业媒体深度融合发展。要主动抓住信息化的历史机遇，顺应新时代信息传播特点，增加原创优秀文章内容，提升内容创作质量，融合多媒体方式和多技术手段，提升传播效果。总结行业媒体建设和运作的经验，畅通信息沟通交流渠道，创新建立全国物业管理媒体协作网和社会主流媒体的融合传播平台。

（六）提升高质量人才供给，构建行业多层次人才队伍。

1.推动行业职业技能水平提升。在人力资源社会保障部和住房城乡建设部的指导下，举办中国技能大赛——全国物业管理行业职业技能竞赛，弘扬工匠精神，筑牢基础服务技能，提高我国物业管理行业职业技能水平，展示行业精益求精的专业形象和良好的精神风貌。

2.建设一批高水平产教融合实训基地。顺应我国职业教育改革趋势，带动企业、培训机构和职业院校建设一批资源共享，集实践教学、社会培训于一体的教育培训基地和物业设施设备实训基地。借鉴国外著名高等学府办学经验，探索国外实训基地运营模式，每年定期举办物业服务企业高级管理人员培训班，采用国内培训和国外进修相结合的学习模式，培养具有国际视野的行业高端人才。

3.推动终身职业技能培训制度。培育行业内外优秀的师资力量，开展普惠化和个性化的教育服务产品研发，现代远程教育与传统培训方式相结合的培训方式，助力行业人才在全职业生命周期内的持续成长；与地方物业管理协会和相关机构合作，开展全国物业承接查验与设施设备管理专业岗位师资培训，全国物业项目经理师资培训、岗位技能培训等工作；依托协会与国家开放大学合作建立的学分银行、学习成果认证中心（物业），以及现代物业服务和不动产管理学院，搭建职业教育和行业人才培养的“立交桥”。

（七）搭建专业服务平台，将传统服务做成精品项目。

1.搭建产业对接和交易平台。继续以国际视野和产业融合高度办好中国国际物业管理产业博览会，充分做好“展”与“会”的相互结合，优化一站式展销、高品质论坛和特色主题活动的紧密布局，交流与交易双轨并行，为国内国际上下游产业链的企业精准对接做好服务，为参展企业开拓中国市场、拓展国际发展提供新机遇，实现产业互利共赢、协同增长，打造独具品牌影响力的产业对接和交易平台。

2.搭建学习交流和展示平台。举办好中国物业管理创新发展论坛、理事会会议、协会工作座谈会、公益大讲堂、媒体工作交流会等品牌活动，邀请国内和国际知名专家和企业家，通过高层次、多维度的内容分享，为参会代表传递最新的行业资讯，帮助会员单位把握经济形势，摸清市场走向，助推企业发展。

3.搭建科学的行业测评平台。会同上海易居房地产研究院中国房地产测评中心和各地方物业管理行业协会，通过科学、公正、客观的评价指标体系、评价方法和专业分析研究，每年定期发布《物业服务企业发展指数测评报告》《上市物业服务企业测评报告》《物业服务企业品牌价值测评报告》《物业管理行业媒体影响力测评报告》等研究成果，全面、客观反映物业服务企业的综合实力、发展质量和品牌价值，激励优秀企业做大做强，培育知名品牌企业，发挥品牌企业的示范引领作用，加快推动行业向现代服务业转型升级。

（八）积极承担社会责任，行业形象和价值再升级。

1.推动社区消费扶贫实现精准。按照党中央、国务院决策部署，坚持精准扶贫精准脱贫基本方略，开展“社区的力量”消费扶贫攻坚战专项行动，以打通贫困地区和城市社区前后一公里为主要着力点，将公益助农与社区服务高度融合，建立前端贫困县域的优质农产品和终端业主需求的消费新途径，促进贫困人口稳定脱贫和贫困地区产业发展；在贫困集中地区积极开展用工扶贫实践，优先向建档立卡贫困户优先开放物业服务企业用工岗位，与已招聘建档立卡贫困户持续签署劳动合同，稳定就业；将乡村振兴融入脱贫攻坚，打造旅游扶贫为主的资产性收益共享农庄，将更多的城市居民带到乡村中，实现异地消费扶贫转化为就地消费扶贫。

2.助力城市社区治理的完善。

积极参与社区治理工作，建立健全社区共建共治共享机制，成为良好社区治理的助推器。探索“物业服务+养老服务”模式，争取行业参与社区治理的激励机制和政策支持。响应国家城市治理工作和乡村振兴战略，探索城市公共服务、乡镇公共服务，通过购买服务等方式承担起社会公共服务的职能，整合专业资源提升城乡公共服务质量、利用科技手段提升城乡管理效率，从硬件与软件着手推动城市的环境、经济、文明协同发展和可持续发展。

3.宣传推广绿色物业管理发展理念。按照《建筑节能与绿色建筑发展“十三五”规划》的要求，引导全行业推广绿色物业管理模式，积极做好垃圾分类、雨水收集、中水利用、车库及公共部位照明改造等节能减排工作；探索物业管理健康发展路径，让社区环境更优美清洁，为业主提供更加舒适健康的生活工作环境，设施设备运行更可靠安全、运营更高效，实现建筑物本体性能的提升；加强绿色理念的宣传推广，倡导广大业主简约适度、绿色低碳的行动自觉，逐步形成绿色行为准则、生活方式和价值取向。

**五、**推进措施

（一）加强党的建设。

以习近平新时代中国特色社会主义思想为指导，加强党建工作，提高政治站位，牢固树立“四个意识”，坚定“四个自信”，坚决做到“两个维护”。充分发挥党组织的战斗堡垒作用和党员的先锋模范作用，发挥党组织在协会重大事项决策中的政治核心作用，发挥党组织对地方物业协会党组织的辐射、带动、示范和引领作用。把党的建设作为推动行业发展、突破行业难点的关键，实现党建工作与行业、企业发展协同推进。

（二）强化组织领导。

协会各所属机构和理事单位要充分认识《中国物业管理协会发展规划》的地位和作用，结合自身实际，制订规划各重点任务和各项工作的分解与落实，明确职责分工、紧密协作配合，共同高质量推动规划落地实施，并对执行过程中出行的新情况，及时做好反馈和动态调整。

（三）完善制度建设。

按照建立现代社会组织的要求，坚持民主、公开办会，健全会员代表大会、理事会和常务理事会制度，建立监事会制度，建立和完善产权清晰、权责明确、运转协调、制衡有效的法人治理结构，形成职能定位更加清晰明确、服务体系更加健全科学、管理机制更加灵活高效、人力资源更加专业优秀的现代化社会组织体制。

(四)重视人才储备。

深化协会人事制度改革，全面提高协会负责人决策水平和协调行业发展的能力，加强协会内部专家型、管理型、复合型人才梯队建设，提高专业化水平；建立健全与岗位职责、工作业绩紧密关联的人才培养、评价、使用和激励制度，调动工作人员积极性、主动性、创造性，营造干事创业的良好氛围。

（五）加快数字化建设。

完善升级协会内网、外网管理系统，搭建基础信息、文件档案、研究资料和行业数据等数据库，加大力度推进协会数字化服务能力。注重运用移动互联、云计算、大数据等信息技术，以创新的思维构建行业横向联动、纵向贯通的信息化管理平台，推进和提高管理水平和效率。
