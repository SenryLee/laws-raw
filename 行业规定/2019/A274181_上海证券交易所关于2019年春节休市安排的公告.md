# 上海证券交易所关于2019年春节休市安排的公告

## 关于2019年春节休市安排的公告

上证公告〔2019〕4号

根据《关于上海证券交易所2019年全年休市安排的通知》（上证公告〔2018〕39号），上海证券交易所（以下简称本所）现将2019年春节休市有关安排通知如下。

一、休市安排：2月4日（星期一）至2月10日（星期日）休市，2月11日（星期一）起照常开市。另外，2月2日（星期六）、2月3日（星期日）为周末休市。

二、为保证春节后交易的正常进行，本所定于2019年2月10日（星期日）9:15-11:30进行交易系统连通性测试。

三、有关清算事宜将根据中国证券登记结算有限责任公司的安排进行。

请各市场参与者据此安排好有关工作。

上海证券交易所

二〇一九年一月二十四日
