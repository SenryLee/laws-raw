# 深圳证券交易所关于支付2018年第十一期中国铁路建设债券（5年期）等两只债券利息有关事项的通知

## 关于支付2018年第十一期中国铁路建设债券（5年期）等两只债券利息有关事项的通知

各市场参与人：

2018年第十一期中国铁路建设债券（5年期）、2018年第十一期中国铁路建设债券（20年期）将于2019年7月26日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年第十一期中国铁路建设债券（5年期）证券代码为"111905",证券简称为"铁道1821",是2018年7月25日发行的5年期债券，票面利率为4.09%,每年支付1次利息，每百元面值债券本次可获利息4.09元。

二、2018年第十一期中国铁路建设债券（20年期）证券代码为"111906",证券简称为"铁道1822",是2018年7月25日发行的20年期债券，票面利率为4.65%,每年支付1次利息，每百元面值债券本次可获利息4.65元。

三、从2019年7月18日至2019年7月25日停办上述铁道债的转托管及调帐业务。

四、上述债券付息债权登记日为2019年7月25日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年7月26日除息交易。

五、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所

二○一九年七月十二日
