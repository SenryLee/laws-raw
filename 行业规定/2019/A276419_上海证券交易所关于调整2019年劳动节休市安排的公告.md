# 上海证券交易所关于调整2019年劳动节休市安排的公告

## 关于调整2019年劳动节休市安排的公告

上证公告〔2019〕20号

根据国务院办公厅和中国证监会有关通知要求，上海证券交易所对《关于上海证券交易所2019年全年休市安排的通知》（上证公告〔2018〕39号）中的劳动节休市安排进行调整。现通知如下：

一、休市安排：5月1日（星期三）至5月4日（星期六）休市，5月6日（星期一）起照常开市。4月28日（星期日）和5月5日（星期日）为周末休市。

二、清算交收：节假日期间清算交收事宜，按照中国证券登记结算有限责任公司的有关安排进行。

请各市场参与人据此安排好有关工作。

上海证券交易所

二〇一九年四月十八日
