# 上海证券交易所关于东莞证券股份有限公司上市基金一般做市商业务资格的公告

## 关于东莞证券股份有限公司上市基金一般做市商业务资格的公告

上证公告〔2019〕58号

根据《上海证券交易所上市基金流动性服务业务指引（2018年修订）》等相关规定，东莞证券股份有限公司自2019年11月28日起获得上海证券交易所上市基金一般做市商业务资格。

特此公告。

上海证券交易所

二〇一九年十一月二十八日
