# 深圳证券交易所关于珠海和佳医疗设备股份有限公司公开发行2019年创新创业公司债券（面向合格投资者）（第一期）上市有关事项的通知

## 关于珠海和佳医疗设备股份有限公司公开发行2019年创新创业公司债券（面向合格投资者）（第一期）上市有关事项的通知

各会员单位：

珠海和佳医疗设备股份有限公司公开发行2019年创新创业公司债券（面向合格投资者）（第一期）定于2019年12月19日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

珠海和佳医疗设备股份有限公司公开发行2019年创新创业公司债券（面向合格投资者）（第一期）证券代码“149012”，证券简称“19和佳S1”，发行总额2.1亿元，票面利率7.5%，债券期限3年,附第2年末发行人调整票面利率选择权及投资者回售选择权。
