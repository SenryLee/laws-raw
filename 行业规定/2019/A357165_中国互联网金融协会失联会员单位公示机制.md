# 中国互联网金融协会失联会员单位公示机制

为完善会员资格管理制度，根据《中国互联网金融协会章程》、《中国互联网金融协会会员管理办法》等有关规定，制定本机制。

**一、**适用情形

通过会员单位在中国互联网金融协会（以下简称“协会”）会员管理系统中所预留的固定电话、手机号码、电子邮件等方式均无法在五个工作日内与其取得有效联系或协会认定的其他无法与其取得有效联系的情况。

**二、**具体步骤

第一、催告。协会通过上述方式无法与会员单位取得有效联系的，将在协会官网（www.nifa.org.cn）中发布催告通知，催促相关会员单位主动与协会联系。

第二、发布失联公告。如催告通知发出后10个工作日内，相关会员单位仍未与协会联系的，协会将在官网发布失联公告，将其认定为“失联”机构。

第三、取消会员资格。相关会员单位自失联公告发布之日起三个月仍未主动联系协会的，协会将在官网发布公告，宣布取消其会员资格。

本机制由协会负责解释，自发布之日起施行。
