# 中国广播电影电视社会组织联合会技术委员会关于2018年度广播影视科技创新奖获奖结果公示的通知

## 关于2018年度广播影视科技创新奖获奖结果公示的通知

中广电技字〔2019〕001号

各相关单位：

现将2018年度广播影视科技创新奖评奖结果进行公示。

2018年度广播影视科技创新奖共有获奖项目139个，其中，一等奖28个、二等奖42个、三等奖69个。此外，由贵州省广播电视信息网络股份有限公司等单位完成的“贵广网络万物互联智慧广电研究及应用”和江苏省广播电视总台完成的“荔枝云平台项目”两个项目获得2018年度广播影视科技创新奖突出贡献奖。评奖结果见附件。

上述评奖结果从2019年1月14日起在国家广播电视总局网站（http://www.nrta.gov.cn/）和中国广播电影电视社会组织联合会网站（http://www.carft.cn）进行公示，公示期为15个工作日，将于2019年2月1日结束。在公示期内，如对所公示项目有异议，可向中国广播电影电视社会组织联合会技术委员会提出书面意见，如需保密，请在书面意见中注明。在收到意见后，技术委员会将立即将相关意见通知转达给相应的单位和推荐部门。各相关单位和部门应在接到通知之日起的15个工作日内，针对所接收到的意见提出书面答复，如在期限内未答复，将视为放弃相应项目的获奖资格。公示期满后，中广联合会将正式颁布无异议的评审结果。
