# 深圳证券交易所关于2019年天津市政府城际铁路专项债券（一期）——2019年天津市政府专项债券（三十二期）上市交易的通知

## 关于2019年天津市政府城际铁路专项债券（一期）——2019年天津市政府专项债券（三十二期）上市交易的通知

各市场参与人：

2019年天津市政府城际铁路专项债券（一期）——2019年天津市政府专项债券（三十二期）已发行结束，根据财政部有关规定，本期债券于2019年7月12日起在本所上市交易。

本期债券为20年期固定利率附息债，证券编码"104660",证券简称"天津1938",票面利率3.81%,标准交易单位"10张",2039年7月10日到期还本并支付最后一期利息。
