# 中国国防工业企业协会关于发布2019年度国防科技工业企业管理创新获奖成果的通知

## 关于发布2019年度国防科技工业企业管理创新获奖成果的通知

各有关单位：

2019年参评的管理创新成果，经专家初审、函审、一等奖候选成果答辩及专家评审并经国防科技工业企业管理创新成果评审委员会审定，确定2019年度获奖成果363项，其中一等奖49项，二等奖140项，三等奖174项。经公示无异议，现予以发布。

附件：2019年度国防科技工业企业管理创新成果获奖项目名单

中国国防工业企业协会

2019年12月20日
