# 深圳证券交易所关于为中国电子信息产业集团有限公司2019年非公开发行可交换公司债券提供转让服务有关事项的通知

## 关于为中国电子信息产业集团有限公司2019年非公开发行可交换公司债券提供转让服务有关事项的通知

各会员单位：

中国电子信息产业集团有限公司2019年非公开发行可交换公司债券定于2019年12月31日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

中国电子信息产业集团有限公司2019年非公开发行可交换公司债券证券代码“117155”，证券简称“19中电E2”，发行总额12亿元，票面利率1%，债券期限3年，附换股价格向下修正条款、赎回条款、回售条款。

深圳证券交易所

二○一九年十二月三十日
