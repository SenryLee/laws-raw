# 上海证券交易所关于浙江杭可科技股份有限公司人民币普通股股票科创板上市交易的公告

## 关于浙江杭可科技股份有限公司人民币普通股股票科创板上市交易的公告

上证公告（股票）〔2019〕34号

浙江杭可科技股份有限公司A股股票将在本所科创板上市交易。该公司A股股本为40,100万股，其中3,678.5972万股于2019年7月22日起上市交易。证券简称为"杭可科技"，证券代码为"688006"。

特此公告。

上海证券交易所

二〇一九年七月十七日
