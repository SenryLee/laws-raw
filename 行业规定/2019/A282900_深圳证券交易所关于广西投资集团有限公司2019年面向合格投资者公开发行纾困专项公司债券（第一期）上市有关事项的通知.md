# 深圳证券交易所关于广西投资集团有限公司2019年面向合格投资者公开发行纾困专项公司债券（第一期）上市有关事项的通知

## 关于广西投资集团有限公司2019年面向合格投资者公开发行纾困专项公司债券（第一期）上市有关事项的通知

各会员单位：

广西投资集团有限公司2019年面向合格投资者公开发行纾困专项公司债券（第一期）定于2019年8月12日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

广西投资集团有限公司2019年面向合格投资者公开发行纾困专项公司债券（第一期）证券代码“112945”，证券简称“19桂纾01”，发行总额10亿元，票面利率3.89%，债券期限5年,附第3年末发行人调整票面利率选择权及投资者回售选择权。

特此通知

深圳证券交易所
