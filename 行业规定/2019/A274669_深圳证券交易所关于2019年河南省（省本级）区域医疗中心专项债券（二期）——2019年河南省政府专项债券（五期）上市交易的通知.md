# 深圳证券交易所关于2019年河南省（省本级）区域医疗中心专项债券（二期）——2019年河南省政府专项债券（五期）上市交易的通知

## 关于2019年河南省（省本级）区域医疗中心专项债券（二期）——2019年河南省政府专项债券（五期）上市交易的通知

各市场参与人：

2019年河南省（省本级）区域医疗中心专项债券（二期）——2019年河南省政府专项债券（五期）已发行结束，根据财政部有关规定，本期债券于2019年1月25日起在本所上市交易。

本期债券为5年期固定利率附息债，证券编码“105152”，证券简称“河南1906”，票面利率3.33％，标准交易单位“10张”，2024年1月23日到期还本并支付最后一期利息。
