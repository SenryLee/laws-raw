# 深圳证券交易所关于中原出版传媒投资控股集团有限公司2018年面向合格投资者公开发行可交换公司债券（第一期）上市有关事项的通知

## 关于中原出版传媒投资控股集团有限公司2018年面向合格投资者公开发行可交换公司债券（第一期）上市有关事项的通知

各会员单位：

中原出版传媒投资控股集团有限公司2018年面向合格投资者公开发行可交换公司债券（第一期）定于2019年1月11日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

中原出版传媒投资控股集团有限公司2018年面向合格投资者公开发行可交换公司债券（第一期）证券代码“120002”，证券简称“18中原EB”，发行总额6.2亿元，票面利率1.8%，债券期限5年。
