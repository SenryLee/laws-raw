# 深圳证券交易所关于为海亮集团有限公司2019年非公开发行可交换公司债券（第一期）提供转让服务有关事项的通知

## 关于为海亮集团有限公司2019年非公开发行可交换公司债券（第一期）提供转让服务有关事项的通知

各会员单位：

海亮集团有限公司2019年非公开发行可交换公司债券（第一期）定于2019年5月15日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

海亮集团有限公司2019年非公开发行可交换公司债券（第一期）证券代码“117133”，证券简称“19海亮E1”，发行总额8.924亿元，票面利率2%，债券期限3年，附换股价格向下修正条款、发行人赎回选择权和投资者回售选择权。

深圳证券交易所

二○一九年五月十三日
