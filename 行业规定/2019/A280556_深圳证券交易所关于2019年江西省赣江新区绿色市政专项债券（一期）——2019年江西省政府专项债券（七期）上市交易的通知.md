# 深圳证券交易所关于2019年江西省赣江新区绿色市政专项债券（一期）——2019年江西省政府专项债券（七期）上市交易的通知

## 关于2019年江西省赣江新区绿色市政专项债券（一期）——2019年江西省政府专项债券（七期）上市交易的通知

各市场参与人：

2019年江西省赣江新区绿色市政专项债券（一期）——2019年江西省政府专项债券（七期）已发行结束，根据财政部有关规定，本期债券于2019年6月21日起在本所上市交易。

本期债券为30年期固定利率附息债，证券编码“105583”，证券简称“江西1914”，票面利率4.11％，标准交易单位“10张”，附分期偿还本金条款，2049年6月19日偿还剩余本金并支付最后一期利息。
