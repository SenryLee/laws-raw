# 深圳证券交易所关于青岛惠城环保科技股份有限公司股票在创业板上市交易的公告

## 关于青岛惠城环保科技股份有限公司股票在创业板上市交易的公告

青岛惠城环保科技股份有限公司人民币普通股股票将于2019年5月22日在本所创业板上市。证券简称为“惠城环保”，证券代码为“300779”。公司人民币普通股股份总数为100,000,000股，其中25,000,000股股票自上市之日起开始上市交易。

深圳证券交易所

2019年5月20日
