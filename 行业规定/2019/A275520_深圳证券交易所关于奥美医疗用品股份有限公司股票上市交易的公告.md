# 深圳证券交易所关于奥美医疗用品股份有限公司股票上市交易的公告

## 关于奥美医疗用品股份有限公司股票上市交易的公告

奥美医疗用品股份有限公司人民币普通股股票将于2019年3月11日在本所上市。证券简称为“奥美医疗”，证券代码为“002950”。公司人民币普通股股份总数为422,176,938股，其中48,000,000股股票自上市之日起开始上市交易。
