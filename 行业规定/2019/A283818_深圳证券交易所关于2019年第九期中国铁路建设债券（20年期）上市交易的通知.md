# 深圳证券交易所关于2019年第九期中国铁路建设债券（20年期）上市交易的通知

## 关于2019年第九期中国铁路建设债券（20年期）上市交易的通知

各市场参与人：

2019年第九期中国铁路建设债券（20年期）已发行结束，根据国家发展和改革委员会有关规定，本期债券于2019年11月11日起在本所上市交易。

本期债券为20年期固定利率附息债，证券编码“111926”，证券简称“铁道1918”，票面利率4.16％，2039年11月7日到期还本并支付最后一期利息。

深圳证券交易所
