# 深圳证券交易所关于康龙化成（北京）新药技术股份有限公司股票在创业板上市交易的公告

## 关于康龙化成（北京）新药技术股份有限公司股票在创业板上市交易的公告

康龙化成（北京）新药技术股份有限公司人民币普通股股票将于2019年1月28日在本所创业板上市。证券简称为“康龙化成”,证券代码为“300759”。公司人民币普通股股份总数为656,293,575股，其中65,630,000股股票自上市之日起开始上市交易。
