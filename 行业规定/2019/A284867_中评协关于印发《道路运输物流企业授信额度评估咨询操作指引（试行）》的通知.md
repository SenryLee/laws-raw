# 中评协关于印发《道路运输物流企业授信额度评估咨询操作指引（试行）》的通知

中评协〔2019〕37号

各省、自治区、直辖市、计划单列市资产评估协会（注册会计师协会）：

为服务普惠金融，指导资产评估机构执行道路运输物流企业授信额度评估咨询业务，中国资产评估协会根据相关法律法规，参考《资产评估执业准则——企业价值》，制定了《道路运输物流企业授信额度评估咨询操作指引（试行）》，供资产评估机构执行道路运输物流企业授信额度评估咨询业务时参考，现予印发，自2020年1月1日起试行。

请各地方协会将《道路运输物流企业授信额度评估咨询操作指引（试行）》及时转发资产评估机构，组织学习和培训，并将执行过程中发现的问题及时上报中国资产评估协会。

附件：道路运输物流企业授信额度评估咨询操作指引（试行）

中国资产评估协会

2019年12月6日
