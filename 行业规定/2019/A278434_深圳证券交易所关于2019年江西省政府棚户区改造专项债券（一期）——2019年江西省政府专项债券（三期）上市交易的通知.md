# 深圳证券交易所关于2019年江西省政府棚户区改造专项债券（一期）——2019年江西省政府专项债券（三期）上市交易的通知

## 关于2019年江西省政府棚户区改造专项债券（一期）——2019年江西省政府专项债券（三期）上市交易的通知

各市场参与人：

2019年江西省政府棚户区改造专项债券（一期）——2019年江西省政府专项债券（三期）已发行结束，根据财政部有关规定，本期债券于2019年3月25日起在本所上市交易。

本期债券为5年期固定利率附息债，证券编码“105318”，证券简称“江西1908”，票面利率3.32％，标准交易单位“10张”，2024年3月21日到期还本并支付最后一期利息。
