# 上海证券交易所关于2019年上半年基金流动性分类结果的公告

## 关于2019年上半年基金流动性分类结果的公告

各市场参与人：

根据上海证券交易所上市基金流动性服务业务有关规定，上海证券交易所每半年对上市基金按流动性高低进行分类。在基金流动性服务季度评价时，按基金流动性分类划分不同的评价标准，流动性越高的类别评价标准越严格。现将2019年上半年流动性分类为“高”和“中”的基金名单予以公布。

特此公告。

附件：2019年上半年基金流动性分类结果
