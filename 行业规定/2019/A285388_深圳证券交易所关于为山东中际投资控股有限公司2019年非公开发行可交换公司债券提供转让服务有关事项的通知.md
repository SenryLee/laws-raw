# 深圳证券交易所关于为山东中际投资控股有限公司2019年非公开发行可交换公司债券提供转让服务有关事项的通知

## 关于为山东中际投资控股有限公司2019年非公开发行可交换公司债券提供转让服务有关事项的通知

各会员单位：

山东中际投资控股有限公司2019年非公开发行可交换公司债券定于2019年12月25日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

山东中际投资控股有限公司2019年非公开发行可交换公司债券证券代码“117154”，证券简称“19中际EB”，发行总额5亿元，债券期限3年，票面利率第1年3%、第2年5%、第3年10%，附赎回条款、回售条款、换股价格下修条款。

深圳证券交易所

二○一九年十二月二十四日
