# 郑州商品交易所关于发布《郑州商品交易所投资者教育专项工作管理办法（试行）》的公告

## 关于发布《郑州商品交易所投资者教育专项工作管理办法（试行）》的公告

〔2019〕41号

为提高投资者教育工作的效率和质量，保证投资者教育工作规范开展，郑州商品交易所制定了《郑州商品交易所投资者教育专项工作管理办法（试行）》，现予公布，自发布之日起施行。

特此公告。
