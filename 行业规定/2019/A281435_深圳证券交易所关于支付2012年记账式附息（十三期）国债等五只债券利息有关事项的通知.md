# 深圳证券交易所关于支付2012年记账式附息（十三期）国债等五只债券利息有关事项的通知

## 关于支付2012年记账式附息（十三期）国债等五只债券利息有关事项的通知

各市场参与人：

2012年记账式附息（十三期）国债、2017年四川省政府一般债券（十七期）、2017年四川省政府一般债券（十八期）、2017年四川省政府一般债券（十九期）、2017年四川省政府一般债券（二十期）将于2019年8月2日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2012年记账式附息（十三期）国债证券代码为"101213",证券简称为"国债1213",是2012年8月2日发行的30年期债券，票面利率为4.12%,每年支付2次利息，每百元面值债券本次可获利息2.06元。

二、2017年四川省政府一般债券（十七期）证券代码为"107860",证券简称为"四川1729",是2017年8月2日发行的3年期债券，票面利率为3.76%,每年支付1次利息，每百元面值债券本次可获利息3.76元。

三、2017年四川省政府一般债券（十八期）证券代码为"107861",证券简称为"四川1730",是2017年8月2日发行的5年期债券，票面利率为3.87%,每年支付1次利息，每百元面值债券本次可获利息3.87元。

四、2017年四川省政府一般债券（十九期）证券代码为"107862",证券简称为"四川1731",是2017年8月2日发行的7年期债券，票面利率为3.98%,每年支付1次利息，每百元面值债券本次可获利息3.98元。

五、2017年四川省政府一般债券（二十期）证券代码为"107863",证券简称为"四川1732",是2017年8月2日发行的10年期债券，票面利率为3.98%,每年支付2次利息，每百元面值债券本次可获利息1.99元。

六、从2019年7月25日至2019年8月1日停办上述附息式国债、地方政府债的转托管及调帐业务。

七、上述债券付息债权登记日为2019年8月1日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年8月2日除息交易。

八、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
