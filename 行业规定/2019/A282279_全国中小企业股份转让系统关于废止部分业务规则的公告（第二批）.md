# 全国中小企业股份转让系统关于废止部分业务规则的公告（第二批）

股转系统公告〔2019〕28号

为建立科学规范的全国中小企业股份转让系统业务规则体系，推动市场法制建设的不断完善，在2018年废止第一批业务规则基础上，我司对截至2018年12月31日公布的业务规则进行了全面清理。现将废止的业务规则目录予以公布。

特此公告。

附件：全国中小企业股份转让系统废止的业务规则目录（第二批）

全国中小企业股份转让系统有限责任公司

2019年1月11日
