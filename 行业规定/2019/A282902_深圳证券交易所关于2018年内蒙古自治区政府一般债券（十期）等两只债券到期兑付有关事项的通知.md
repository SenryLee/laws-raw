# 深圳证券交易所关于2018年内蒙古自治区政府一般债券（十期）等两只债券到期兑付有关事项的通知

## 关于2018年内蒙古自治区政府一般债券（十期）等两只债券到期兑付有关事项的通知

各市场参与人：

2018年内蒙古自治区政府一般债券（十期）、2016年湖南省政府一般债券（五期）将于2019年8月23日到期兑付。为做好上述债券的本息兑付工作，现将有关事项通知如下：

一、2018年内蒙古自治区政府一般债券（十期）证券代码为“106789”，证券简称为“内蒙1814”，是2018年8月23日发行的1年期债券，票面利率为3.32%，每年支付1次利息，每百元面值债券兑付可获本息103.32元。

二、2016年湖南省政府一般债券（五期）证券代码为“107260”，证券简称为“湖南1605”，是2016年8月23日发行的3年期债券，票面利率为2.43%，每年支付1次利息，每百元面值债券兑付可获本息102.43元。

三、从2019年8月15日起停办上述地方政府债的转托管及调账业务。

四、上述债券兑付债权登记日为2019年8月22日，凡于当日收市后持有上述债券的投资者，享有获得本次兑付款项的权利。2019年8月23日上述债券摘牌。

五、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券兑付款项后，将其划入各证券商的清算备付金账户，并由证券商将兑付资金及时划入各投资者的资金账户。

深圳证券交易所
