# 深圳证券交易所关于安福县海能实业股份有限公司股票在创业板上市交易的公告

## 关于安福县海能实业股份有限公司股票在创业板上市交易的公告

安福县海能实业股份有限公司人民币普通股股票将于2019年8月15日在本所创业板上市。证券简称为“海能实业”，证券代码为“300787”。公司人民币普通股股份总数为84,880,000股，其中21,220,000股股票自上市之日起开始上市交易。
