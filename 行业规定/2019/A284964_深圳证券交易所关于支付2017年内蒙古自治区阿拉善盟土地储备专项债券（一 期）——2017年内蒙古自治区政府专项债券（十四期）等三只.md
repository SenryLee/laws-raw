# 深圳证券交易所关于支付2017年内蒙古自治区阿拉善盟土地储备专项债券（一 期）——2017年内蒙古自治区政府专项债券（十四期）等三只债券利息有关事项的通知

## 关于支付2017年内蒙古自治区阿拉善盟土地储备专项债券（一期）——2017年内蒙古自治区政府专项债券（十四期）等三只债券利息有关事项的通知

各市场参与人：

2017年内蒙古自治区阿拉善盟土地储备专项债券（一期）—2017年内蒙古自治区政府专项债券（十四期）、2017年内蒙古自治区满洲里市土地储备专项债券（一期）—2017年内蒙古自治区政府专项债券（十五期）、2017年内蒙古自治区政府专项债券（十六期）将于2019年12月18日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2017年内蒙古自治区阿拉善盟土地储备专项债券（一期）—2017年内蒙古自治区政府专项债券（十四期）证券代码为“106359”，证券简称为“内蒙1724”，是2017年12月18日发行的5年期债券，票面利率为4.64％，每年支付1次利息，每百元面值债券本次可获利息4.64元。

二、2017年内蒙古自治区满洲里市土地储备专项债券（一期）—2017年内蒙古自治区政府专项债券（十五期）证券代码为“106360”，证券简称为“内蒙1725”，是2017年12月18日发行的5年期债券，票面利率为4.28％，每年支付1次利息，每百元面值债券本次可获利息4.28元。

三、2017年内蒙古自治区政府专项债券（十六期）证券代码为“106361”，证券简称为“内蒙1726”，是2017年12月18日发行的5年期债券，票面利率为4.2％，每年支付1次利息，每百元面值债券本次可获利息4.2元。

四、从2019年12月10日至2019年12月17日停办上述地方政府债的转托管及调帐业务。

五、上述债券付息债权登记日为2019年12月17日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年12月18日除息交易。

六、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所

二○一九年十二月四日
