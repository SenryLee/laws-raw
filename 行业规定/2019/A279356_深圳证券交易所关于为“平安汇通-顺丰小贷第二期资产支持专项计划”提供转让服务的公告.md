# 深圳证券交易所关于为“平安汇通-顺丰小贷第二期资产支持专项计划”提供转让服务的公告

## 关于为“平安汇通-顺丰小贷第二期资产支持专项计划”提供转让服务的公告

各相关单位：

根据深圳平安大华汇通财富管理有限公司申请，本所将自2019年4月15日起在综合协议交易平台为“平安汇通-顺丰小贷第二期资产支持专项计划”（以下简称“顺丰二期”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“顺丰二期”的转让业务。

二、“顺丰二期”设立日期为2019年3月27日。优先级资产支持证券如下：证券简称“顺丰2A”，证券代码为“139538”，到期日为2022年3月25日，还本付息方式为循环期定期付息；摊还期定期付息、过手还本。次优先级资产支持证券如下：证券简称“顺丰2B”，证券代码为“139539”，到期日为2022年3月25日，还本付息方式为循环期定期付息；摊还期定期付息、过手还本。

三、“顺丰2A”的单笔成交申报最低数量为10000份，“顺丰2B”的单笔成交申报最低数量为10000份。

四、对首次参加“顺丰二期”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“顺丰二期”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
