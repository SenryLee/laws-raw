# 深圳证券交易所关于厦门合兴包装印刷股份有限公司可转换公司债券上市交易的公告

## 关于厦门合兴包装印刷股份有限公司可转换公司债券上市交易的公告

厦门合兴包装印刷股份有限公司发行的595,750,000元可转换公司债券自2019年9月16日起在本所上市交易，证券简称为"合兴转债",证券代码为"128071",上市数量595.75万张。
