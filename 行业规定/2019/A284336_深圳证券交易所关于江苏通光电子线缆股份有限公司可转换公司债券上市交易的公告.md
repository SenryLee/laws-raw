# 深圳证券交易所关于江苏通光电子线缆股份有限公司可转换公司债券上市交易的公告

## 关于江苏通光电子线缆股份有限公司可转换公司债券上市交易的公告

江苏通光电子线缆股份有限公司发行的297,000,000元可转换公司债券自2019年11月28日起在本所上市交易，证券简称为“通光转债”，证券代码为“123034”，上市数量297万张。

深圳证券交易所

二〇一九年十一月二十六日
