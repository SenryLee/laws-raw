# 深圳证券交易所关于深圳市卓越商业管理有限公司公开发行2018年公司债券（第一期）（面向合格投资者）上市有关事项的通知

## 关于深圳市卓越商业管理有限公司公开发行2018年公司债券（第一期）（面向合格投资者）上市有关事项的通知

各会员单位：

深圳市卓越商业管理有限公司公开发行2018年公司债券（第一期）（面向合格投资者）定于2019年1月25日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

深圳市卓越商业管理有限公司公开发行2018年公司债券（第一期）（面向合格投资者）证券代码“112827”，证券简称“18卓越06”，发行总额30亿元，票面利率6.64%，债券期限3年,附第2年末发行人调整票面利率选择权和投资者回售选择权。
