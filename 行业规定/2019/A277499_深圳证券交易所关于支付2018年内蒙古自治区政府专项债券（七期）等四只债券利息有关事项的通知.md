# 深圳证券交易所关于支付2018年内蒙古自治区政府专项债券（七期）等四只债券利息有关事项的通知

## 关于支付2018年内蒙古自治区政府专项债券（七期）等四只债券利息有关事项的通知

各市场参与人：

2018年内蒙古自治区政府专项债券（七期）、2017年宁波市政府一般债券（八期）、2017年宁波市政府专项债券（六期）、2017年宁波市（本级）收费公路专项债券（一期）——2017年宁波市政府专项债券（十一期）将于2019年3月13日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年内蒙古自治区政府专项债券（七期）证券代码为“106876”，证券简称为“内蒙1822”，是2018年9月13日发行的10年期债券，票面利率为4.04％，每年支付2次利息，每百元面值债券本次可获利息2.02元。

二、2017年宁波市政府一般债券（八期）证券代码为“107991”，证券简称为“宁波1712”，是2017年9月13日发行的10年期债券，票面利率为3.93％，每年支付2次利息，每百元面值债券本次可获利息1.965元。

三、2017年宁波市政府专项债券（六期）证券代码为“107993”，证券简称为“宁波1714”，是2017年9月13日发行的10年期债券，票面利率为3.83％，每年支付2次利息，每百元面值债券本次可获利息1.915元。

四、2017年宁波市（本级）收费公路专项债券（一期）——2017年宁波市政府专项债券（十一期）证券代码为“107998”，证券简称为“宁波1719”，是2017年9月13日发行的10年期债券，票面利率为4.08％，每年支付2次利息，每百元面值债券本次可获利息2.04元。

五、从2019年3月5日至2019年3月12日停办上述地方政府债的转托管及调帐业务。

六、上述债券付息债权登记日为2019年3月12日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年3月13日除息交易。

七、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
