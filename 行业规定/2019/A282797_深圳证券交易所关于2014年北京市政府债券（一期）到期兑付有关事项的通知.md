# 深圳证券交易所关于2014年北京市政府债券（一期）到期兑付有关事项的通知

## 关于2014年北京市政府债券（一期）到期兑付有关事项的通知

各市场参与人：

2014年北京市政府债券（一期）将于2019年8月22日到期兑付。为做好本期债券的本息兑付工作，现将有关事项通知如下：

一、本期债券证券代码为“109150”，证券简称为“北京1401”，是2014年8月22日发行的5年期债券，票面利率为4%，每年支付1次利息，每百元面值债券兑付可获本息104元。

二、从2019年8月14日起停办本期地方政府债的转托管及调账业务。

三、本期债券兑付债权登记日为2019年8月21日，凡于当日收市后持有本期债券的投资者，享有获得本次兑付款项的权利。2019年8月22日本期债券摘牌。

四、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的本期债券兑付款项后，将其划入各证券商的清算备付金账户，并由证券商将兑付资金及时划入各投资者的资金账户。
