# 上海期货交易所关于修订《期货公司铜期权业务指南》和《期货公司天然橡胶期权业务指南》的通知

上期发〔2019〕146号

各有关单位：

为进一步加强适当性业务管理，规范相关业务流程，我所删除了《期货公司铜期权业务指南》和《期货公司天然橡胶期权业务指南》中涉及适当性的内容，开户机构落实交易所适当性要求按照《上海期货交易所期货交易者适当性制度操作指引》执行。修订后的《期货公司铜期权业务指南》和《期货公司天然橡胶期权业务指南》现予发布，自发布之日起实施。

特此通知。

附件：1.期货公司铜期权业务指南

2.期货公司天然橡胶期权业务指南

上海期货交易所

2019年5月31日
