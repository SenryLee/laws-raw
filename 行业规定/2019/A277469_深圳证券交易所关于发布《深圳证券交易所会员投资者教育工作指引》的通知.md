# 深圳证券交易所关于发布《深圳证券交易所会员投资者教育工作指引》的通知

## 关于发布《深圳证券交易所会员投资者教育工作指引》的通知

深证会〔2019〕127号

各会员及其他交易参与人：

为进一步规范会员的投资者教育工作，切实保障投资者合法权益，本所制定了《深圳证券交易所会员投资者教育工作指引》，现予以发布，自2019年5月15日起施行。其他交易参与人请参照执行。

特此通知

附件：深圳证券交易所会员投资者教育工作指引

深圳证券交易所

2019年5月15日
