# 深圳证券交易所关于发布深证中小创业质量等两条指数的公告

## 关于发布深证中小创业质量等两条指数的公告

为进一步丰富指数体系，提供指数化投资标的，深圳证券交易所和深圳证券信息有限公司定于2019年6月6日发布深证中小创业质量指数和深证投资级可转债及可交换债券指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 指数基日 | 基日点位 |
| 399294 | 深证中小创业质量指数 | 中小创Q | 2012年12月31日 | 1000 |
| 399290 | 深证投资级可转债及可交换债券指数 | 深转交债 | 2017年12月29日 | 100 |

深证投资级可转债及可交换债券指数以深市可转换公司债、可交换公司债为样本空间，选取主体评级不低于AA、存续规模不低于2亿元、剩余期限不低于15日的债券构成指数样本。指数以样本债券的发行量为权数，采用市场成交价格实时计算，样本每月定期调整两次。中小创业质量指数在深交所中小板和创业板上市的流动性较好、波动率较低的公司中，按公司营收增速和股息率等基本面指标加权排名，选取前50家公司作为样本股。指数采用自由流通市值加权，于每年6月、12月的第二个星期五的下一个交易日进行样本股定期调整。

中小创业质量指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关以上两条指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
