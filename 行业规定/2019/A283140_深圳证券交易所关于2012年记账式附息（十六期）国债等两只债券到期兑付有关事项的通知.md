# 深圳证券交易所关于2012年记账式附息（十六期）国债等两只债券到期兑付有关事项的通知

## 关于2012年记账式附息（十六期）国债等两只债券到期兑付有关事项的通知

各市场参与人：

2012年记账式附息（十六期）国债、2016年山东省政府一般债券（九期）将于2019年9月6日到期兑付。为做好上述债券的本息兑付工作，现将有关事项通知如下：

一、2012年记账式附息（十六期）国债证券代码为“101216”，证券简称为“国债1216”，是2012年9月6日发行的7年期债券，票面利率为3.25%，每年支付1次利息，每百元面值债券兑付可获本息103.25元。

二、2016年山东省政府一般债券（九期）证券代码为“107277”，证券简称为“山东1612”，是2016年9月6日发行的3年期债券，票面利率为2.45%，每年支付1次利息，每百元面值债券兑付可获本息102.45元。

三、从2019年8月29日起停办上述附息式国债、地方政府债的转托管及调帐业务。

四、上述债券兑付债权登记日为2019年9月5日，凡于当日收市后持有上述债券的投资者，享有获得本次兑付款项的权利。2019年9月6日上述债券摘牌。

五、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券兑付款项后，将其划入各证券商的清算备付金账户，并由证券商将兑付资金及时划入各投资者的资金账户。

深圳证券交易所

二○一九年八月二十三日
