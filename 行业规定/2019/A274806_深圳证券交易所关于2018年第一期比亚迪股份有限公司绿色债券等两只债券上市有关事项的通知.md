# 深圳证券交易所关于2018年第一期比亚迪股份有限公司绿色债券等两只债券上市有关事项的通知

## 关于2018年第一期比亚迪股份有限公司绿色债券等两只债券上市有关事项的通知

各会员单位：

2018年第一期比亚迪股份有限公司绿色债券,北京东方园林环境股份有限公司2019年面向合格投资者公开发行公司债券（第一期）定于2019年1月29日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、2018年第一期比亚迪股份有限公司绿色债券证券代码“111075”，证券简称“18亚迪G1”，发行总额10亿元，票面利率4.98%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、北京东方园林环境股份有限公司2019年面向合格投资者公开发行公司债券（第一期）证券代码“112842”，证券简称“19东林01”，发行总额5.2亿元，票面利率7.5%，债券期限2年，附第1年末发行人调整票面利率选择权和投资者回售选择权。
