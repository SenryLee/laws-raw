# 深圳证券交易所关于2019年中秋节休市安排的通知

## 关于2019年中秋节休市安排的通知

各市场参与人：

根据《关于2019年部分节假日休市安排的通知》（深证会〔2018〕569号），现将2019年中秋节休市有关安排通知如下。

一、休市安排

9月13日（星期五）至9月15日（星期日）休市，9月16日（星期一）起照常开市。

二、清算交收

节假日期间清算交收事宜，按照中国证券登记结算有限责任公司的有关安排进行。

请各市场参与人据此安排好有关工作。

深圳证券交易所

2019年9月5日
