# 深圳证券交易所关于四川德恩精工科技股份有限公司股票在创业板上市交易的公告

## 关于四川德恩精工科技股份有限公司股票在创业板上市交易的公告

四川德恩精工科技股份有限公司人民币普通股股票将于2019年5月31日在本所创业板上市。证券简称为“德恩精工”，证券代码为“300780”。公司人民币普通股股份总数为146,670,000股，其中36,670,000股股票自上市之日起开始上市交易。
