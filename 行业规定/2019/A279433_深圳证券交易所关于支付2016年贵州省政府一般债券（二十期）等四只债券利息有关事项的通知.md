# 深圳证券交易所关于支付2016年贵州省政府一般债券（二十期）等四只债券利息有关事项的通知

## 关于支付2016年贵州省政府一般债券（二十期）等四只债券利息有关事项的通知

各市场参与人：

2016年贵州省政府一般债券（二十期）、2016年贵州省政府专项债券（十二期）、2016年广西壮族自治区政府一般债券（二十期）、2016年广西壮族自治区政府专项债券（十二期）将于2019年5月7日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2016年贵州省政府一般债券（二十期）证券代码为“107425”，证券简称为“贵州1620”，是2016年11月7日发行的10年期债券，票面利率为2.87％，每年支付2次利息，每百元面值债券本次可获利息1.435元。

二、2016年贵州省政府专项债券（十二期）证券代码为“107429”，证券简称为“贵州1623”，是2016年11月7日发行的10年期债券，票面利率为2.81％，每年支付2次利息，每百元面值债券本次可获利息1.405元。

三、2016年广西壮族自治区政府一般债券（二十期）证券代码为“107433”，证券简称为“广西1620”，是2016年11月7日发行的10年期债券，票面利率为2.88％，每年支付2次利息，每百元面值债券本次可获利息1.44元。

四、2016年广西壮族自治区政府专项债券（十二期）证券代码为“107437”，证券简称为“广西1623”，是2016年11月7日发行的10年期债券，票面利率为2.88％，每年支付2次利息，每百元面值债券本次可获利息1.44元。

五、从2019年4月24日至2019年5月6日停办上述地方政府债的转托管及调帐业务。

六、上述债券付息债权登记日为2019年5月6日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年5月7日除息交易。

七、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所

二○一九年四月十八日
