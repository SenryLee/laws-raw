# 深圳证券交易所关于为京山京源科技投资有限公司2019年非公开发行可交换公司债券提供转让服务有关事项的通知

## 关于为京山京源科技投资有限公司2019年非公开发行可交换公司债券提供转让服务有关事项的通知

各会员单位：

京山京源科技投资有限公司2019年非公开发行可交换公司债券定于2019年5月10日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

京山京源科技投资有限公司2019年非公开发行可交换公司债券证券代码“117132”，证券简称“19京源E1”，发行总额2.4亿元，票面利率8%，债券期限3年，附赎回条款、回售条款、换股价格向下修正条款和换股价格向上修正条款。

深圳证券交易所

二○一九年五月八日
