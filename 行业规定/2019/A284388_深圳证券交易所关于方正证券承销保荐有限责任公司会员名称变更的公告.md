# 深圳证券交易所关于方正证券承销保荐有限责任公司会员名称变更的公告

## 关于方正证券承销保荐有限责任公司会员名称变更的公告

方正证券承销保荐有限责任公司在深圳证券交易所的会员名称由“中国民族证券有限责任公司”变更为“方正证券承销保荐有限责任公司”。会员简称为：方正承销保荐，会员编码为：000076。
