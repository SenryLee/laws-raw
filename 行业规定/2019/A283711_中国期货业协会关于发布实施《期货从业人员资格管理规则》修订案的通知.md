# 中国期货业协会关于发布实施《期货从业人员资格管理规则》修订案的通知

## 关于发布实施《期货从业人员资格管理规则》修订案的通知

各会员单位：

中国期货业协会第五届理事会第七次会议审议通过了《期货从业人员资格管理规则》修订案（详见附件），现予以发布实施。

特此通知。

中国期货业协会

2019年10月15日

附件：《期货从业人员资格管理规则》（修订）
