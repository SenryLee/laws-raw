# 深圳证券交易所关于中国南山开发（集团）股份有限公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

## 关于中国南山开发（集团）股份有限公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

各会员单位：

中国南山开发（集团）股份有限公司2019年面向合格投资者公开发行公司债券（第一期）定于2019年9月3日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

中国南山开发（集团）股份有限公司2019年面向合格投资者公开发行公司债券（第一期）证券代码“112953”，证券简称“19南集01”，发行总额5亿元，票面利率3.6%，债券期限5年, 附第3年末发行人赎回选择权、调整票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所
