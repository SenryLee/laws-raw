# 中央国债登记结算有限责任公司关于调整2019年年终中央债券综合业务系统受理业务时间的通知

中债字〔2019〕210号

各结算成员：

根据《中国人民银行支付结算司关于做好2019年年终决算日支付清算工作的通知》（银支付﹝2019﹞251号）及《关于做好2019年人民币跨境支付系统年终决算工作的通知》（跨境函﹝2019﹞264号），为了支持结算成员做好年终决算工作，配合支付系统顺利运行，中央国债登记结算有限责任公司（以下称“公司”）对12月31日中央债券综合业务系统（以下称“债券系统”）银行间市场结算业务的受理时间进行相应调整，具体如下：

一、12月31日债券系统受理业务的截止时间为20:15。若大额支付系统业务截止时间临时调整，公司将相应调整债券系统受理业务时间。

二、12月31日债券结算资金专户的剩余结算资金自动退回时点不变。

请各结算成员做好相关业务衔接。
