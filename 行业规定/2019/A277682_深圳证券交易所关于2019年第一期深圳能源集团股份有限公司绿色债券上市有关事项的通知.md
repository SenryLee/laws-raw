# 深圳证券交易所关于2019年第一期深圳能源集团股份有限公司绿色债券上市有关事项的通知

## 关于2019年第一期深圳能源集团股份有限公司绿色债券上市有关事项的通知

各会员单位：

2019年第一期深圳能源集团股份有限公司绿色债券定于2019年3月7日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

2019年第一期深圳能源集团股份有限公司绿色债券证券代码“111077”，证券简称“19深能G1”，发行总额16.5亿元，票面利率4.05%，债券期限10年，附第5年末发行人调整票面利率选择权和投资者回售选择权。
