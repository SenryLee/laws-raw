# 深圳证券交易所关于中国广核集团有限公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

## 关于中国广核集团有限公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

各会员单位：

中国广核集团有限公司2019年面向合格投资者公开发行公司债券（第一期）定于2019年12月6日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

中国广核集团有限公司2019年面向合格投资者公开发行公司债券（第一期）证券代码“149001”，证券简称“19广核01”，发行总额20亿元，票面利率3.50%，债券期限3年。
