# 全国中小企业股份转让系统有限责任公司关于发布要约收购业务技术变更指南及数据接口规范的通知

## 关于发布要约收购业务技术变更指南及数据接口规范的通知

股转系统办发〔2019〕66号

各市场参与者：

2019年6月14日，全国股转公司发布了《挂牌公司要约收购业务指引》及《关于实施要约回购制度的公告》，为顺利实施要约收购及要约回购业务，现发布《全国中小企业股份转让系统市场参与者技术系统变更指南之要约收购业务（V1.0）》及与之配套的《全国中小企业股份转让系统交易支持平台数据接口规范（V1.42）》，请各机构根据相关文档于2019年7月31日前做好技术准备。

附件1.全国中小企业股份转让系统市场参与者技术系统变更指南之要约收购业务（V1.0）

附件2.全国中小企业股份转让系统交易支持平台数据接口规范（V1.42）

全国中小企业股份转让系统有限责任公司

2019年6月28日
