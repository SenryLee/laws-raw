# 中国金融期货交易所关于股指期货跨品种双向持仓按照交易保证金单边较大者收取交易保证金的通知

## 关于股指期货跨品种双向持仓按照交易保证金单边较大者收取交易保证金的通知

各结算会员:

根据《中国金融期货交易所结算细则》的规定，自2019年6月3日（周一）结算时起，对沪深300股指期货、上证50股指期货和中证500股指期货的跨品种双向持仓，按照交易保证金单边较大者收取交易保证金。

特此通知。

中国金融期货交易所

2019年5月31日
