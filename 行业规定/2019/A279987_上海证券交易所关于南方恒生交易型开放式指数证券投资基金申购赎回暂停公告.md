# 上海证券交易所关于南方恒生交易型开放式指数证券投资基金申购赎回暂停公告

## 南方恒生交易型开放式指数证券投资基金申购赎回暂停公告

上证公告（基金）〔2019〕126号

根据南方基金股份管理有限公司申请，本所于2019年7月31日14:25至15：00暂停南方恒生交易型开放式指数证券投资基金的申购赎回业务，该基金申赎代码为513601。

上海证券交易所

2019年7月31日
