# 深圳证券交易所关于2017年记账式附息（十二期）国债等七只债券到期兑付有关事项的通知

## 关于2017年记账式附息（十二期）国债等七只债券到期兑付有关事项的通知

各市场参与人：

2017年记账式附息（十二期）国债、2016年浙江省政府一般债券（五期）、2016年新疆维吾尔自治区政府一般债券（九期）、2016年广东省政府一般债券（九期）、2016年宁夏回族自治区政府一般债券（五期）、2014年地方政府债券（二期）、2019年记账式贴现（十一期）国债将于2019年6月17日到期兑付。为做好上述债券的本息兑付工作，现将有关事项通知如下：

一、2017年记账式附息（十二期）国债证券代码为“101712”，证券简称为“国债1712”，是2017年6月15日发行的2年期债券，票面利率为3.62%，每年支付1次利息，每百元面值债券兑付可获本息103.62元。

二、2016年浙江省政府一般债券（五期）证券代码为“107069”，证券简称为“浙江1605”，是2016年6月15日发行的3年期债券，票面利率为2.65%，每年支付1次利息，每百元面值债券兑付可获本息102.65元。

三、2016年新疆维吾尔自治区政府一般债券（九期）证券代码为“107080”，证券简称为“新疆1609”，是2016年6月16日发行的3年期债券，票面利率为2.6%，每年支付1次利息，每百元面值债券兑付可获本息102.6元。

四、2016年广东省政府一般债券（九期）证券代码为“107087”，证券简称为“广东1609”，是2016年6月17日发行的3年期债券，票面利率为2.76%，每年支付1次利息，每百元面值债券兑付可获本息102.76元。

五、2016年宁夏回族自治区政府一般债券（五期）证券代码为“107094”，证券简称为“宁夏1605”，是2016年6月17日发行的3年期债券，票面利率为2.76%，每年支付1次利息，每百元面值债券兑付可获本息102.76元。

六、2014年地方政府债券（二期）证券代码为“109120”，证券简称为“地债1402”，是2014年6月16日发行的5年期债券，票面利率为3.99%，每年支付1次利息，每百元面值债券兑付可获本息103.99元。

七、2019年记账式贴现（十一期）国债证券代码为“108288”，证券简称为“贴债1911”，是2019年3月18日发行的91日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

八、从2019年6月6日起停办上述附息式国债、地方政府债、贴现式国债的转托管及调帐业务。

九、上述债券兑付债权登记日为2019年6月14日，凡于当日收市后持有上述债券的投资者，享有获得本次兑付款项的权利。2019年6月17日上述债券摘牌。

十、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券兑付款项后，将其划入各证券商的清算备付金帐户，并由证券商将兑付资金及时划入各投资者的资金帐户。
