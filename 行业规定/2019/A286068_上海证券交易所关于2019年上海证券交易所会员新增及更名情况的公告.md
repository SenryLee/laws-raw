# 上海证券交易所关于2019年上海证券交易所会员新增及更名情况的公告

## 关于2019年上海证券交易所会员新增及更名情况的公告

上证公告〔2019〕66号

根据《上海证券交易所章程》《上海证券交易所会员管理规则（2019年修订）》规定，上海证券交易所（以下简称本所）就2019年1-12月会员新增及更名情况公告如下：经本所理事会批准，接纳野村东方国际证券有限公司、摩根大通证券（中国）有限公司为本所会员；经会员申请，中国中投证券有限责任公司会员名称变更为中国中金财富证券有限公司，中国民族证券有限责任公司会员名称变更为方正证券承销保荐有限责任公司。

根据《上海证券交易所会员管理规则（2019年修订）》规定，从2020年开始，本所将对会员新设和会员名称变更登记的更新情况予以即时公告，不再统一于年末进行公告。

特此公告。

上海证券交易所

二〇一九年十二月三十一日
