# 中央国债登记结算有限责任公司关于发布《中债成员综合评定方案》的通知

## 关于发布《中债成员综合评定方案》的通知

各市场成员：

为进一步助力市场规范化发展，引导市场成员积极参与债券市场建设与创新，我公司制定了《中债成员综合评定方案》（详见附件），经公开征求市场成员意见，现予发布实施。

特此通知。

附件：《中债成员综合评定方案》

中央国债登记结算有限责任公司
