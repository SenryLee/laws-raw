# 上海期货交易所关于发布《上海期货交易所国产天然橡胶交割商品注册管理规定》修订案的公告

上海期货交易所公告〔2019〕100号

为加强对天然橡胶期货交割商品的管理，根据《上海期货交易所交割细则》及有关规定，我所对《上海期货交易所国产天然橡胶交割商品注册管理规定》进行了修订，优化并完善交割商品注册规定。

本规定自2019年11月4日起实施。2011年7月26日发布的《上海期货交易所国产天然橡胶交割商品注册管理规定》同时废止。

特此公告。

附件：上海期货交易所国产天然橡胶交割商品注册管理规定（修订案）

上海期货交易所

2019年11月4日
