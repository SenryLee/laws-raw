# 深圳证券交易所关于为“兴业圆融-广州开发区专利许可资产支持专项计划”提供转让服务的公告

## 关于为“兴业圆融-广州开发区专利许可资产支持专项计划”提供转让服务的公告

各相关单位：

根据兴证证券资产管理有限公司申请，本所将自2019年11月21日起在综合协议交易平台为“兴业圆融-广州开发区专利许可资产支持专项计划”（以下简称“广开专利”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“广开专利”的转让业务。

二、“广开专利”设立日期为2019年9月11日。优先级资产支持证券如下：证券简称“广开专优”，证券代码为“139928”，到期日为2023年9月26日，还本付息方式为按季度付息，摊还本金。

三、“广开专优”的单笔成交申报最低数量为10000份。

四、对首次参加“广开专利”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“广开专利”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
