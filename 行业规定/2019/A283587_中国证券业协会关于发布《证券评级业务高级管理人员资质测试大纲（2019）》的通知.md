# 中国证券业协会关于发布《证券评级业务高级管理人员资质测试大纲（2019）》的通知

## 关于发布《证券评级业务高级管理人员资质测试大纲（2019）》的通知

中证协发〔2019〕272号

各证券资信评级机构：

为持续做好证券评级业务高级管理人员资质测试工作，根据相关法律法规变化及证券评级业务发展情况，我会制定了《证券评级业务高级管理人员资质测试大纲（2019）》，现予发布，自2019年11月1日起施行。

附件：证券评级业务高级管理人员资质测试大纲（2019）

中国证券业协会

2019年9月27日
