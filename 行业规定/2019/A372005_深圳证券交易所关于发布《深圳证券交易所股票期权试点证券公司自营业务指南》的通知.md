# 深圳证券交易所关于发布《深圳证券交易所股票期权试点证券公司自营业务指南》的通知

深证会〔2019〕473号

各期权经营机构：

为便于证券公司参与深圳证券交易所股票期权业务，规范开展股票期权自营业务，防范业务风险，本所制定了《深圳证券交易所股票期权试点证券公司自营业务指南》。现予以发布，并自发布之日起施行。

特此通知

附件：深圳证券交易所股票期权试点证券公司自营业务指南
