# 深圳证券交易所关于易方达深证成指交易型开放式指数证券投资基金终止上市交易的通知

## 关于易方达深证成指交易型开放式指数证券投资基金终止上市交易的通知

各会员单位：

易方达基金管理有限公司以通讯方式召开了易方达深证成指交易型开放式指数证券投资基金份额持有人大会，并于2019年6月29日刊登了《易方达基金管理有限公司关于易方达深证成指交易型开放式指数证券投资基金基金份额持有人大会表决结果暨决议生效的公告》（以下简称“公告”）。根据公告，持有人大会于2019年6月28日表决通过了《关于易方达深证成指交易型开放式指数证券投资基金终止基金合同并终止上市有关事项的议案》（以下简称“议案”）。根据持有人大会通过的议案，易方达基金管理有限公司向本所提交了终止上市的申请。

根据《深圳证券交易所证券投资基金上市规则》第二十三条第（三）项的相关规定，经审查，本所决定易方达深证成指交易型开放式指数证券投资基金（证券简称：深成指EF，证券代码：159950）自2019年7月12日起终止上市交易。
