# 深圳证券交易所关于支付2018年记账式附息（一期）国债等七只债券利息有关事项的通知

## 关于支付2018年记账式附息（一期）国债等七只债券利息有关事项的通知

各市场参与人：

2018年记账式附息（一期）国债、2018年陕西省政府公开发行一般债券（十期）、2018年陕西省政府公开发行专项债券（六期）、2017年厦门市政府一般债券（四期）、2017年厦门市政府专项债券（二期）、2017年四川省政府一般债券（十六期）、2017年四川省政府专项债券（十二期）将于2019年1月18日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年记账式附息（一期）国债证券代码为“101801”，证券简称为“国债1801”，是2018年1月18日发行的5年期债券，票面利率为3.81％，每年支付1次利息，每百元面值债券本次可获利息3.81元。

二、2018年陕西省政府公开发行一般债券（十期）证券代码为“106619”，证券简称为“陕西1814”，是2018年7月18日发行的10年期债券，票面利率为4.09％，每年支付2次利息，每百元面值债券本次可获利息2.045元。

三、2018年陕西省政府公开发行专项债券（六期）证券代码为“106621”，证券简称为“陕西1816”，是2018年7月18日发行的10年期债券，票面利率为4.13％，每年支付2次利息，每百元面值债券本次可获利息2.065元。

四、2017年厦门市政府一般债券（四期）证券代码为“107821”，证券简称为“厦门1704”，是2017年7月18日发行的10年期债券，票面利率为3.88％，每年支付2次利息，每百元面值债券本次可获利息1.94元。

五、2017年厦门市政府专项债券（二期）证券代码为“107823”，证券简称为“厦门1706”，是2017年7月18日发行的10年期债券，票面利率为3.88％，每年支付2次利息，每百元面值债券本次可获利息1.94元。

六、2017年四川省政府一般债券（十六期）证券代码为“107827”，证券简称为“四川1724”，是2017年7月18日发行的10年期债券，票面利率为4％，每年支付2次利息，每百元面值债券本次可获利息2元。

七、2017年四川省政府专项债券（十二期）证券代码为“107831”，证券简称为“四川1728”，是2017年7月18日发行的10年期债券，票面利率为3.98％，每年支付2次利息，每百元面值债券本次可获利息1.99元。

八、从2019年1月10日至2019年1月17日停办上述附息式国债、地方政府债的转托管及调帐业务。

九、上述债券付息债权登记日为2019年1月17日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年1月18日除息交易。

十、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
