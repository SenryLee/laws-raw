# 深圳证券交易所关于支付2015年记账式附息（二期）国债等两只债券利息有关事项的通知

## 关于支付2015年记账式附息（二期）国债等两只债券利息有关事项的通知

各市场参与人：

2015年记账式附息（二期）国债、2015年广东省政府一般债券（八期）将于2019年1月22日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2015年记账式附息（二期）国债证券代码为“101502”，证券简称为“国债1502”，是2015年1月22日发行的7年期债券，票面利率为3.36％，每年支付1次利息，每百元面值债券本次可获利息3.36元。

二、2015年广东省政府一般债券（八期）证券代码为“109344”，证券简称为“广东1508”，是2015年7月22日发行的10年期债券，票面利率为3.53％，每年支付2次利息，每百元面值债券本次可获利息1.765元。

三、从2019年1月14日至2019年1月21日停办上述附息式国债、地方政府债的转托管及调帐业务。

四、上述债券付息债权登记日为2019年1月21日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年1月22日除息交易。

五、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
