# 上海证券交易所关于18凤祥02（143892）盘中临时停牌的公告

## 关于18凤祥02（143892）盘中临时停牌的公告

上证公告（监察）〔2019〕087号

18凤祥02（143892）今日下午交易出现异常波动。根据《上海证券交易所交易规则》和《上海证券交易所证券异常交易实时监控细则》的有关规定，本所决定，自2019年06月24日14时48分开始暂停18凤祥02（143892）交易，自2019年06月24日14时57分起恢复交易。

本所提醒投资者注意交易风险，理性投资。

上海证券交易所

2019年06月24日
