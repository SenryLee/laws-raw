# 深圳证券交易所关于为珠海赛纳打印科技股份有限公司2019年非公开发行可交换公司债券（第一期）等三只债券提供转让服务有关事项的通知

## 关于为珠海赛纳打印科技股份有限公司2019年非公开发行可交换公司债券（第一期）等三只债券提供转让服务有关事项的通知

各会员单位：

珠海赛纳打印科技股份有限公司2019年非公开发行可交换公司债券（第一期）、大族控股集团有限公司2019年非公开发行可交换公司债券（第一期）、北京久其科技投资有限公司2019年非公开发行可交换公司债券定于2019年4月10日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、珠海赛纳打印科技股份有限公司2019年非公开发行可交换公司债券（第一期）证券代码“117126”，证券简称“19赛纳E1”，发行总额15亿元，票面利率6.5%，债券期限2年，附换股价格向下修正条款和发行人赎回选择权。

2、大族控股集团有限公司2019年非公开发行可交换公司债券（第一期）证券代码“117127”，证券简称“19大族EB”，发行总额6.4亿元，票面利率1%，债券期限3年，附换股价格向下修正条款、发行人赎回选择权和投资者回售选择权。

3、北京久其科技投资有限公司2019年非公开发行可交换公司债券证券代码“117128”，证券简称“19科投EB”，发行总额4亿元，票面利率6%，债券期限3年，附换股价格向下修正条款、发行人赎回选择权和投资者回售选择权。

深圳证券交易所

二○一九年四月八日
