# 深圳证券交易所关于支付2018年云南省职业教育专项债券（一期）——2018年云南省政府专项债券（十三期）等三只债券利息有关事项的通知

## 关于支付2018年云南省职业教育专项债券（一期）——2018年云南省政府专项债券（十三期）等三只债券利息有关事项的通知

各市场参与人：

2018年云南省职业教育专项债券（一期）——2018年云南省政府专项债券（十三期）、2017年云南省政府一般债券（二期）、2017年云南省政府专项债券（二期）将于2019年9月20日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年云南省职业教育专项债券（一期）——2018年云南省政府专项债券（十三期）证券代码为“106965”，证券简称为“云南1823”，是2018年9月20日发行的7年期债券，票面利率为4.06％，每年支付1次利息，每百元面值债券本次可获利息4.06元。

二、2017年云南省政府一般债券（二期）证券代码为“107548”，证券简称为“云南1702”，是2017年3月20日发行的10年期债券，票面利率为3.79％，每年支付2次利息，每百元面值债券本次可获利息1.895元。

三、2017年云南省政府专项债券（二期）证券代码为“107550”，证券简称为“云南1704”，是2017年3月20日发行的10年期债券，票面利率为3.87％，每年支付2次利息，每百元面值债券本次可获利息1.935元。

四、从2019年9月11日至2019年9月19日停办上述地方政府债的转托管及调账业务。

五、上述债券付息债权登记日为2019年9月19日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年9月20日除息交易。

六、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
