# 深圳证券交易所关于重庆华森制药股份有限公司可转换公司债券上市交易的公告

## 关于重庆华森制药股份有限公司可转换公司债券上市交易的公告

重庆华森制药股份有限公司发行的300,000,000元可转换公司债券自2019年7月11日起在本所上市交易，证券简称为“华森转债”，证券代码为“128069”，上市数量300万张。
