# 深圳证券交易所关于为福建漳龙集团有限公司2019年非公开发行公司债券（第一期）等两只债券提供转让服务有关事项的通知

## 关于为福建漳龙集团有限公司2019年非公开发行公司债券（第一期）等两只债券提供转让服务有关事项的通知

各会员单位：

福建漳龙集团有限公司2019年非公开发行公司债券（第一期）、 甘肃省公路航空旅游投资集团有限公司2019年非公开发行可续期公司债券（第一期）定于2019年4月15日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、福建漳龙集团有限公司2019年非公开发行公司债券（第一期）证券代码“114452”，证券简称“19漳龙01”，发行总额6亿元，票面利率5%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、甘肃省公路航空旅游投资集团有限公司2019年非公开发行可续期公司债券（第一期）证券代码“114454”，证券简称“19甘公Y1”，发行总额12亿元，票面利率6.3%，附发行人续期选择权、递延支付利息权和发行人赎回选择权。

深圳证券交易所

二○一九年四月十一日
