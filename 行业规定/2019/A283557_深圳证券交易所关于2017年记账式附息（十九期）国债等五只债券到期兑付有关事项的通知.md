# 深圳证券交易所关于2017年记账式附息（十九期）国债等五只债券到期兑付有关事项的通知

## 关于2017年记账式附息（十九期）国债等五只债券到期兑付有关事项的通知

各市场参与人：

2017年记账式附息（十九期）国债、2016年宁波市政府一般债券（五期）、2016年宁波市政府专项债券（五期）、2014年地方政府债券（十二期）、2019年记账式贴现（二十三期）国债将于2019年9月16日到期兑付。为做好上述债券的本息兑付工作，现将有关事项通知如下：

一、2017年记账式附息（十九期）国债证券代码为“101719”，证券简称为“国债1719”，是2017年9月14日发行的2年期债券，票面利率为3.5%，每年支付1次利息，每百元面值债券兑付可获本息103.5元。

二、2016年宁波市政府一般债券（五期）证券代码为“107308”，证券简称为“宁波1605”，是2016年9月14日发行的3年期债券，票面利率为2.43%，每年支付1次利息，每百元面值债券兑付可获本息102.43元。

三、2016年宁波市政府专项债券（五期）证券代码为“107312”，证券简称为“宁波16Z5”，是2016年9月14日发行的3年期债券，票面利率为2.43%，每年支付1次利息，每百元面值债券兑付可获本息102.43元。

四、2014年地方政府债券（十二期）证券代码为“109157”，证券简称为“地债1412”，是2014年9月16日发行的5年期债券，票面利率为4.15%，每年支付1次利息，每百元面值债券兑付可获本息104.15元。

五、2019年记账式贴现（二十三期）国债证券代码为“108301”，证券简称为“贴债1923”，是2019年6月17日发行的91日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

六、从2019年9月5日起停办上述附息式国债、地方政府债、贴现式国债的转托管及调帐业务。

七、上述债券兑付债权登记日为2019年9月12日，凡于当日收市后持有上述债券的投资者，享有获得本次兑付款项的权利。2019年9月16日上述债券摘牌。

八、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券兑付款项后，将其划入各证券商的清算备付金账户，并由证券商将兑付资金及时划入各投资者的资金账户。
