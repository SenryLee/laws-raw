# 深圳证券交易所关于芜湖长信科技股份有限公司可转换公司债券上市交易的公告

## 关于芜湖长信科技股份有限公司可转换公司债券上市交易的公告

芜湖长信科技股份有限公司发行的1,230,000,000元可转换公司债券自2019年4月10日起在本所上市交易，证券简称为“长信转债”，证券代码为“123022”，上市数量1,230万张。

深圳证券交易所

二〇一九年四月九日
