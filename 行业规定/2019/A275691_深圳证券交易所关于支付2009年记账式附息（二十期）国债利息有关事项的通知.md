# 深圳证券交易所关于支付2009年记账式附息（二十期）国债利息有关事项的通知

## 关于支付2009年记账式附息（二十期）国债利息有关事项的通知

各市场参与人：

2009年记账式附息（二十期）国债将于2019年2月27日支付利息。为做好本期债券的利息支付工作，现将有关事项通知如下：

一、本期债券证券代码为“100920”，证券简称为“国债0920”，是2009年8月27日发行的20年期债券，票面利率为4％，每年支付2次利息，每百元面值债券本次可获利息2元。

二、从2019年2月19日至2019年2月26日停办本期附息式国债的转托管及调帐业务。

三、本期债券付息债权登记日为2019年2月26日，凡于当日收市后持有本期债券的投资者，享有获得本次利息款项的权利，2019年2月27日除息交易。

四、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的本期债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
