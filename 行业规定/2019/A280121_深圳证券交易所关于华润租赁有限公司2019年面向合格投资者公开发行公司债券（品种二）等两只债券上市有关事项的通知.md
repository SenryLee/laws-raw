# 深圳证券交易所关于华润租赁有限公司2019年面向合格投资者公开发行公司债券（品种二）等两只债券上市有关事项的通知

## 关于华润租赁有限公司2019年面向合格投资者公开发行公司债券（品种二）等两只债券上市有关事项的通知

各会员单位：

华润租赁有限公司2019年面向合格投资者公开发行公司债券（品种二），福建七匹狼集团有限公司2019年面向合格投资者公开发行公司债券（第一期）定于2019年5月23日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、华润租赁有限公司2019年面向合格投资者公开发行公司债券（品种二）证券代码“112897”，证券简称“19润租02”，发行总额8亿元，票面利率4.5%，债券期限3年。

2、福建七匹狼集团有限公司2019年面向合格投资者公开发行公司债券（第一期）证券代码“112900”，证券简称“19七狼01”，发行总额5亿元，票面利率5.99%，债券期限3年。

特此通知
