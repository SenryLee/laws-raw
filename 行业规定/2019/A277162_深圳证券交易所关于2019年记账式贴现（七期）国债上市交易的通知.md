# 深圳证券交易所关于2019年记账式贴现（七期）国债上市交易的通知

## 关于2019年记账式贴现（七期）国债上市交易的通知

各市场参与人：

2019年记账式贴现（七期）国债已发行结束，根据财政部有关规定，本期债券于2019年2月27日起在本所上市交易。

本期债券为91日期贴现式国债，证券编码“108284”，证券简称“贴债1907”，标准交易单位“10张”，2019年5月27日到期按面值偿还。

特此通知

深圳证券交易所

二○一九年二月二十五日
