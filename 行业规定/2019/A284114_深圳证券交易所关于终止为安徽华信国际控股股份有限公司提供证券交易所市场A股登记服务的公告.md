# 深圳证券交易所关于终止为安徽华信国际控股股份有限公司提供证券交易所市场A股登记服务的公告

## 关于终止为安徽华信国际控股股份有限公司提供证券交易所市场A股登记服务的公告

各市场参与主体：

因安徽华信国际控股股份有限公司A股（证券简称：华信退，证券代码：002018）已在深圳证券交易所终止上市，我公司自2019年11月5日起终止为其提供证券交易所市场的A 股登记服务，我公司与该公司之间的涉及证券交易所市场的A 股证券登记关系自同日起终止。

我公司根据有关规定已将相应的证券登记数据移交给安徽华信国际控股股份有限公司，其中包括持有人名册、我公司办理的冻结股份明细表、质押登记明细表、在证券公司的托管情况、股本结构表等。

原由证券公司受理的安徽华信国际控股股份有限公司的司法协助冻结、质押登记等业务，证券公司应当在安徽华信国际控股股份有限公司指定的股份转让服务机构开始为投资者办理股份确权之前，将相关数据及书面材料移交该转让服务机构，否则由此引起的一切法律责任由原受理的证券公司承担。

特此公告。

中国证券登记结算有限责任公司深圳分公司

二○一九年十一月五日
