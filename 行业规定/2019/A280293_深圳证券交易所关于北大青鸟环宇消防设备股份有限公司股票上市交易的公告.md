# 深圳证券交易所关于北大青鸟环宇消防设备股份有限公司股票上市交易的公告

## 关于北大青鸟环宇消防设备股份有限公司股票上市交易的公告

北大青鸟环宇消防设备股份有限公司人民币普通股股票将于2019年8月9日在本所上市。证券简称为“青鸟消防”，证券代码为“002960”。公司人民币普通股股份总数为240,000,000股，其中60,000,000股股票自上市之日起开始上市交易。
