# 深圳证券交易所关于国家开发银行2019年跨市场第一期金融债券上市交易的通知

## 关于国家开发银行2019年跨市场第一期金融债券上市交易的通知

各市场参与人：

国家开发银行2019年跨市场第一期金融债券已发行结束，根据深圳证券交易所（以下简称“本所”）有关规定，本期债券于2019年11月28日起在本所上市交易。

本期债券为3年期固定利率附息式债券，证券编码“108605”，证券简称“国开1901”，票面利率2.92％，2022年11月27日到期还本并支付最后一期利息。

特此通知

深圳证券交易所

二○一九年十一月二十六日
