# 中国滑雪协会关于印发滑雪项目初级教练员岗位培训专项技能考核标准的通知

各相关单位：

根据体育总局关于印发《体育教练员岗位培训管理暂行办法》（体规字〔2019〕1号）文件规定，结合体育总局科教司《关于初级教练员岗位培训专项技能考核工作有关事宜的通知》（体科字〔2019〕118号）的文件要求，现将滑雪项目初级教练员岗位培训专项技能考核标准公布如下：

一、达到滑雪项目运动员技术等级标准二级及以上者专项技能考核免考。

二、未能达到滑雪项目运动员技术等级标准二级及以上者，须按照国家体育总局职鉴指导中心、中国滑雪协会印发的《滑雪指导员国家职业技能鉴定考核实施细则（2017版）》以及《滑雪指导员国家职业资格培训工作手册（2017版）》要求，获得《社会体育指导员（滑雪）国家职业资格证书》“滑雪（中级）指导员”资格，可确认为滑雪项目初级教练员专项技能考核合格。

特此通知。

中国滑雪协会

2019年10月14日
