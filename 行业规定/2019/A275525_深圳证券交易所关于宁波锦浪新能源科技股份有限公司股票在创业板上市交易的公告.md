# 深圳证券交易所关于宁波锦浪新能源科技股份有限公司股票在创业板上市交易的公告

## 关于宁波锦浪新能源科技股份有限公司股票在创业板上市交易的公告

宁波锦浪新能源科技股份有限公司人民币普通股股票将于2019年3月19日在本所创业板上市。证券简称为“锦浪科技”，证券代码为“300763”。公司人民币普通股股份总数为79,999,952股，其中20,000,000股股票自上市之日起开始上市交易。
