# 深圳证券交易所关于为“鲁能集团-英大证券-济南贵和商业物业资产支持专项计划”提供转让服务的公告

## 关于为“鲁能集团-英大证券-济南贵和商业物业资产支持专项计划”提供转让服务的公告

各相关单位：

根据英大证券有限责任公司申请，本所将自2019年12月31日起在综合协议交易平台为“鲁能集团-英大证券-济南贵和商业物业资产支持专项计划”（以下简称“鲁能济南贵和专项计划”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“鲁能济南贵和专项计划”的转让业务。

二、“鲁能济南贵和专项计划”设立日期为2019年11月26日。优先级资产支持证券如下：证券简称“贵和优A”，证券代码为“119484”，到期日为2037年11月20日，还本付息方式为定期付息、分期定额还本。次优先级资产支持证券如下：证券简称“贵和优B”，证券代码为“119485”，到期日为2037年11月20日，还本付息方式为定期付息、到期一次还本。

三、“贵和优A”的单笔成交申报最低数量为10000份，“贵和优B”的单笔成交申报最低数量为10000份。

四、对首次参加“鲁能济南贵和专项计划”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“鲁能济南贵和专项计划”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
