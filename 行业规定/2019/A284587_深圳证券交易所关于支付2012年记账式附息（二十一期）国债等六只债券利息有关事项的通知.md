# 深圳证券交易所关于支付2012年记账式附息（二十一期）国债等六只债券利息有关事项的通知

## 关于支付2012年记账式附息（二十一期）国债等六只债券利息有关事项的通知

各市场参与人：

2012年记账式附息（二十一期）国债、2019年宁夏回族自治区政府一般债券（五期）、2019年重庆市政府一般债券（四期）、2019年重庆市政府专项债券（四期）、2017年陕西省政府一般债券（六期）、2017年河北省政府专项债券（四期）将于2019年12月13日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2012年记账式附息（二十一期）国债证券代码为“101221”，证券简称为“国债1221”，是2012年12月13日发行的10年期债券，票面利率为3.55％，每年支付2次利息，每百元面值债券本次可获利息1.775元。

二、2019年宁夏回族自治区政府一般债券（五期）证券代码为“105506”，证券简称为“宁夏1914”，是2019年6月13日发行的10年期债券，票面利率为3.47％，每年支付2次利息，每百元面值债券本次可获利息1.735元。

三、2019年重庆市政府一般债券（四期）证券代码为“105520”，证券简称为“重庆1907”，是2019年6月13日发行的30年期债券，票面利率为4.11％，每年支付2次利息，每百元面值债券本次可获利息2.055元。

四、2019年重庆市政府专项债券（四期）证券代码为“105521”，证券简称为“重庆1908”，是2019年6月13日发行的10年期债券，票面利率为3.47％，每年支付2次利息，每百元面值债券本次可获利息1.735元。

五、2017年陕西省政府一般债券（六期）证券代码为“107705”，证券简称为“陕西1708”，是2017年6月13日发行的10年期债券，票面利率为4.1％，每年支付2次利息，每百元面值债券本次可获利息2.05元。

六、2017年河北省政府专项债券（四期）证券代码为“107710”，证券简称为“河北1711”，是2017年6月13日发行的10年期债券，票面利率为4.07％，每年支付2次利息，每百元面值债券本次可获利息2.035元。

七、从2019年12月5日至2019年12月12日停办上述附息式国债、地方政府债的转托管及调帐业务。

八、上述债券付息债权登记日为2019年12月12日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年12月13日除息交易。

九、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
