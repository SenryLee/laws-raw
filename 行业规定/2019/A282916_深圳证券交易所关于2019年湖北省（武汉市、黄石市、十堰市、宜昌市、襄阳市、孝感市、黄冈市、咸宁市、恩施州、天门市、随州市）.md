# 深圳证券交易所关于2019年湖北省（武汉市、黄石市、十堰市、宜昌市、襄阳市、孝感市、黄冈市、咸宁市、恩施州、天门市、随州市）医疗卫生专项债券（二期）——2019年湖北省政府专项债券（十七期）上市交易的通知

## 关于2019年湖北省（武汉市、黄石市、十堰市、宜昌市、襄阳市、孝感市、黄冈市、咸宁市、恩施州、天门市、随州市）医疗卫生专项债券（二期）——2019年湖北省政府专项债券（十七期）上市交易的通知

各市场参与人：

2019年湖北省（武汉市、黄石市、十堰市、宜昌市、襄阳市、孝感市、黄冈市、咸宁市、恩施州、天门市、随州市）医疗卫生专项债券（二期）——2019年湖北省政府专项债券（十七期）已发行结束，根据财政部有关规定，本期债券于2019年8月14日起在本所上市交易。

本期债券为10年期固定利率附息债，证券编码“105826”，证券简称“湖北1926”，票面利率3.31％，标准交易单位“10张”，2029年8月12日到期还本并支付最后一期利息。
