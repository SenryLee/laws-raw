# 深圳证券交易所关于将郴州市金贵银业股份有限公司股票调出融资融券标的证券名单的公告

## 关于将郴州市金贵银业股份有限公司股票调出融资融券标的证券名单的公告

郴州市金贵银业股份有限公司股票（证券代码：002716）将自2019年10月9日起被本所实行其他风险警示，根据《深圳证券交易所融资融券交易实施细则（2019年修订）》相关规定，本所于2019年10月9日起将该股票调出融资融券标的证券名单。

特此公告

深圳证券交易所

2019年10月9日
