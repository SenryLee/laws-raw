# 深圳证券交易所关于2019年黑龙江省棚改专项债券（一期）——2019年黑龙江省政府专项债券（二期）上市交易的通知

## 关于2019年黑龙江省棚改专项债券（一期）——2019年黑龙江省政府专项债券（二期）上市交易的通知

各市场参与人：

2019年黑龙江省棚改专项债券（一期）——2019年黑龙江省政府专项债券（二期）已发行结束，根据财政部有关规定，本期债券于2019年5月6日起在本所上市交易。

本期债券为5年期固定利率附息债，证券编码“105436”，证券简称“龙江1905”，票面利率3.49％，标准交易单位“10张”，2024年4月29日到期还本并支付最后一期利息。
