# 深圳证券交易所关于创维数字股份有限公司可转换公司债券上市交易的公告

## 关于创维数字股份有限公司可转换公司债券上市交易的公告

创维数字股份有限公司发行的1,040,000,000元可转换公司债券自2019年05月16日起在本所上市交易，证券简称为“创维转债”，证券代码为“127013”，上市数量1,040万张。
