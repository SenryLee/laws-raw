# 深圳证券交易所关于武汉市江岸国有资产经营管理有限责任公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

## 关于武汉市江岸国有资产经营管理有限责任公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

各会员单位：

武汉市江岸国有资产经营管理有限责任公司2019年面向合格投资者公开发行公司债券（第一期）定于2019年1月30日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

武汉市江岸国有资产经营管理有限责任公司2019年面向合格投资者公开发行公司债券（第一期）证券代码“112843”，证券简称“19岸资01”，发行总额2.1亿元，票面利率4.35%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所

二○一九年一月二十八日
