# 深圳证券交易所关于山东英科医疗用品股份有限公司可转换公司债券上市交易的公告

## 关于山东英科医疗用品股份有限公司可转换公司债券上市交易的公告

山东英科医疗用品股份有限公司发行的470,000,000元可转换公司债券自2019年9月10日起在本所上市交易，证券简称为"英科转债",证券代码为"123029",上市数量470万张。

深圳证券交易所

二〇一九年九月九日
