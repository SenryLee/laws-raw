# 深圳证券交易所关于中航善达股份有限公司股票临时停牌的公告

## 关于中航善达股份有限公司股票临时停牌的公告

中航善达股份有限公司（以下简称“中航善达”）第一大股东中航国际控股股份有限公司拟筹划将其所持中航善达22.35%股份转让给招商局蛇口工业区控股股份有限公司（以下简称“招商蛇口”），中航善达拟筹划发行股份购买招商蛇口等持有的招商局物业管理有限公司100%股权。根据本所《股票上市规则》和《深圳证券交易所上市公司信息披露指引第2号——停复牌业务》的有关规定，经公司申请，公司证券（证券简称：中航善达，证券代码：000043）于2019年4月15日开市起临时停牌，待公司通过指定媒体披露相关公告后复牌，敬请投资者密切关注。

深圳证券交易所
