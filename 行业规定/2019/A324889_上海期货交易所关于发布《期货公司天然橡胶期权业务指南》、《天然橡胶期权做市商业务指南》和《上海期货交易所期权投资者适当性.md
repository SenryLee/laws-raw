# 上海期货交易所关于发布《期货公司天然橡胶期权业务指南》、《天然橡胶期权做市商业务指南》和《上海期货交易所期权投资者适当性制度操作指南》的通知

本篇法规中《上海期货交易所期权投资者适当性制度操作指南》已被2019年5月31日上海期货交易所关于发布的《上海期货交易所关于发布<上海期货交易所期货交易者适当性制度操作指引>的通知》（上期发〔2019〕145号）废止。

## 上海期货交易所关于发布《期货公司天然橡胶期权业务指南》、《天然橡胶期权做市商业务指南》和《上海期货交易所期权投资者适当性制度操作指南》的通知

上期发〔2019〕19号

各有关单位：

为进一步加强天然橡胶期权业务管理，规范相关业务流程，我所制定了《期货公司天然橡胶期权业务指南》、《天然橡胶期权做市商业务指南》和《上海期货交易所期权投资者适当性制度操作指南》，现予以发布。

特此通知。

2．天然橡胶期权做市商业务指南
