# 深圳证券交易所关于2019年第一期比亚迪股份有限公司绿色债券上市有关事项的通知

## 关于2019年第一期比亚迪股份有限公司绿色债券上市有关事项的通知

各会员单位：

2019年第一期比亚迪股份有限公司绿色债券定于2019年7月11日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

2019年第一期比亚迪股份有限公司绿色债券证券代码"111083",证券简称"19亚迪G1",发行总额10亿元，票面利率4.86%,债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所

二○一九年七月九日
