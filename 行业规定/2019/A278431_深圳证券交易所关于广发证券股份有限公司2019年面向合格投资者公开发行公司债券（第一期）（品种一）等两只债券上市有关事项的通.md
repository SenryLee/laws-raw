# 深圳证券交易所关于广发证券股份有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）等两只债券上市有关事项的通知

## 关于广发证券股份有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）等两只债券上市有关事项的通知

各会员单位：

广发证券股份有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一），天津中环半导体股份有限公司2019年面向合格投资者公开发行公司债券（第一期）定于2019年3月25日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、广发证券股份有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）证券代码“112857”，证券简称“19广发03”，发行总额78亿元，票面利率3.7%，债券期限3年。

2、天津中环半导体股份有限公司2019年面向合格投资者公开发行公司债券（第一期）证券代码“112860”，证券简称“19中环01”，发行总额4.5亿元，票面利率6%，债券期限6年，附第2年末、第4年末发行人调整票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所
