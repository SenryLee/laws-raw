# 深圳证券交易所关于2019年山西省政府棚户区改造专项债券（九期）——2019年山西省政府专项债券（二十二期）上市交易的通知

## 关于2019年山西省政府棚户区改造专项债券（九期）——2019年山西省政府专项债券（二十二期）上市交易的通知

各市场参与人：

2019年山西省政府棚户区改造专项债券（九期）——2019年山西省政府专项债券（二十二期）已发行结束，根据财政部有关规定，本期债券于2019年6月18日起在本所上市交易。

本期债券为10年期固定利率附息债，证券编码“105540”，证券简称“山西1931”，票面利率3.48％，标准交易单位“10张”，2029年6月14日到期还本并支付最后一期利息。
