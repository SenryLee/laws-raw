# 上海期货交易所关于发布《上海期货交易所期货交易者适当性制度操作指引》的通知

上期发〔2019〕145号

各有关单位：

为进一步加强交易者的适当性业务管理，规范相关业务流程，根据《上海期货交易所期货交易者适当性管理办法》，上海期货交易所制定了《上海期货交易所期货交易者适当性制度操作指引》（附件1），现予以发布，自发布之日起实施。原《上海期货交易所期权投资者适当性制度操作指南》同时废止。

其中，对于报备开通交易权限的交易编码要求，因相关系统有待调整，各期货公司会员可在填写《客户适当性品种权限信息表》（附件2）后，将该表格发送至client.shfe shfe.com.cn。待相关系统调整完成后，新的报备方式将另行通知。

英文文本见官方英文网站，仅供参考。如有与中文文本不一致，以中文文本为准。

特此通知。

附件：1．上海期货交易所期货交易者适当性制度操作指引

2．客户适当性品种权限信息表

上海期货交易所
