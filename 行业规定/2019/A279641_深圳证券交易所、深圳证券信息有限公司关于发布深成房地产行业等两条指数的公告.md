# 深圳证券交易所、深圳证券信息有限公司关于发布深成房地产行业等两条指数的公告

## 关于发布深成房地产行业等两条指数的公告

为了反映深证成指、中小创新指数样本中房地产行业公司的整体表现，进一步丰富行业指数体系，深圳证券交易所和深圳证券信息有限公司定于2019年7月23日发布深成房地产行业指数和中小创新房地产行业指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 指数基日 | 基日点位 |
| 971001 | 深成房地产行业指数 | 深成地产 | 2010年6月30日 | 1000 |
| 971002 | 中小创新房地产行业指数 | 中小地产 | 2011年12月30日 | 1000 |

深成房地产行业指数、中小创新房地产行业指数分别从深证成指、中小创新指数中筛选国证一级行业分类为“房地产”的上市公司作为指数样本。

指数包括纯价格指数和全收益指数，由深圳证券信息有限公司计算，通过信息商发布指数行情。

有关深成房地产行业指数、中小创新房地产行业指数的详细资料可参见国证指数网（www.cnindex.com.cn）。
