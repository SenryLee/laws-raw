# 中国证券登记结算有限责任公司上海分公司关于发布《中国证券登记结算有限责任公司上海分公司可交换公司债券登记结算业务指南》的通知

## 关于发布《中国证券登记结算有限责任公司上海分公司可交换公司债券登记结算业务指南》的通知

各市场参与主体：

为“简证便民、优化服务”，本公司对《中国证券登记结算有限责任公司上海分公司可交换公司债券登记结算业务指南》进行了修订。本次修订内容主要包括：

1.由于营业执照、组织机构代码证和税务登记证“三证合一”，删除可交换债券担保及信托专用证券账户和可交换债券质押专用证券账户在开立、注销时提交组织机构代码证的申请材料要求。

2.由于银监会、保监会合并，修订部分情形的批准单位。

3.调整开立相关专户时“辅助身份证明文件号码”填写规则。

现予发布，特此通知。

附件：中国证券登记结算有限责任公司上海分公司可交换公司债券登记结算业务指南

二○一九年一月二十五日
