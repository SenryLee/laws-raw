# 深圳证券交易所关于金科地产集团股份有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）上市有关事项的通知

## 关于金科地产集团股份有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）上市有关事项的通知

各会员单位：

金科地产集团股份有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）定于2019年3月27日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

金科地产集团股份有限公司2019年面向合格投资者公开发行公司债券（第一期）（品种一）证券代码“112866”，证券简称“19金科01”，发行总额20亿元，票面利率6.9%，债券期限4年，附第2年末发行人调整票面利率选择权和投资者回售选择权。
