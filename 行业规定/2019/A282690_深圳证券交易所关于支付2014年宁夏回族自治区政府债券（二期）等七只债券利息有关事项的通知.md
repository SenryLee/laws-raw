# 深圳证券交易所关于支付2014年宁夏回族自治区政府债券（二期）等七只债券利息有关事项的通知

## 关于支付2014年宁夏回族自治区政府债券（二期）等七只债券利息有关事项的通知

各市场参与人：

2014年宁夏回族自治区政府债券（二期）、2014年宁夏回族自治区政府债券（三期）、2015年辽宁省政府专项债券（一期）、2015年辽宁省政府专项债券（二期）、2015年辽宁省政府一般债券（六期）、2015年辽宁省政府一般债券（七期）、2015年辽宁省政府一般债券（八期）将于2019年8月12日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2014年宁夏回族自治区政府债券（二期）证券代码为“109140”，证券简称为“宁夏1402”，是2014年8月12日发行的7年期债券，票面利率为4.17％，每年支付1次利息，每百元面值债券本次可获利息4.17元。

二、2014年宁夏回族自治区政府债券（三期）证券代码为“109141”，证券简称为“宁夏1403”，是2014年8月12日发行的10年期债券，票面利率为4.26％，每年支付2次利息，每百元面值债券本次可获利息2.13元。

三、2015年辽宁省政府专项债券（一期）证券代码为“109385”，证券简称为“辽宁15Z1”，是2015年8月10日发行的5年期债券，票面利率为3.48％，每年支付1次利息，每百元面值债券本次可获利息3.48元。

四、2015年辽宁省政府专项债券（二期）证券代码为“109386”，证券简称为“辽宁15Z2”，是2015年8月10日发行的10年期债券，票面利率为3.99％，每年支付2次利息，每百元面值债券本次可获利息1.995元。

五、2015年辽宁省政府一般债券（六期）证券代码为“109388”，证券简称为“辽宁1506”，是2015年8月10日发行的5年期债券，票面利率为3.48％，每年支付1次利息，每百元面值债券本次可获利息3.48元。

六、2015年辽宁省政府一般债券（七期）证券代码为“109389”，证券简称为“辽宁1507”，是2015年8月10日发行的7年期债券，票面利率为3.75％，每年支付1次利息，每百元面值债券本次可获利息3.75元。

七、2015年辽宁省政府一般债券（八期）证券代码为“109390”，证券简称为“辽宁1508”，是2015年8月10日发行的10年期债券，票面利率为3.67％，每年支付2次利息，每百元面值债券本次可获利息1.835元。

八、从2019年8月2日至2019年8月9日停办上述地方政府债的转托管及调帐业务。

九、上述债券付息债权登记日为2019年8月9日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年8月12日除息交易。

十、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
