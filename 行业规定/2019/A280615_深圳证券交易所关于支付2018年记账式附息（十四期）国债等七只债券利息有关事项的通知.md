# 深圳证券交易所关于支付2018年记账式附息（十四期）国债等七只债券利息有关事项的通知

## 关于支付2018年记账式附息（十四期）国债等七只债券利息有关事项的通知

各市场参与人：

2018年记账式附息（十四期）国债、2017年安徽省政府一般债券（一期）、2017年安徽省政府一般债券（二期）、2017年安徽省政府专项债券（一期）、2017年安徽省政府专项债券（二期）、2018年第十期中国铁路建设债券（5年期）、2018年第十期中国铁路建设债券（20年期）将于2019年7月5日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年记账式附息（十四期）国债证券代码为“101814”，证券简称为“国债1814”，是2018年7月5日发行的3年期债券，票面利率为3.24％，每年支付1次利息，每百元面值债券本次可获利息3.24元。

二、2017年安徽省政府一般债券（一期）证券代码为“107741”，证券简称为“安徽1701”，是2017年7月5日发行的5年期债券，票面利率为3.85％，每年支付1次利息，每百元面值债券本次可获利息3.85元。

三、2017年安徽省政府一般债券（二期）证券代码为“107742”，证券简称为“安徽1702”，是2017年7月5日发行的7年期债券，票面利率为4.02％，每年支付1次利息，每百元面值债券本次可获利息4.02元。

四、2017年安徽省政府专项债券（一期）证券代码为“107743”，证券简称为“安徽1703”，是2017年7月5日发行的5年期债券，票面利率为3.88％，每年支付1次利息，每百元面值债券本次可获利息3.88元。

五、2017年安徽省政府专项债券（二期）证券代码为“107744”，证券简称为“安徽1704”，是2017年7月5日发行的7年期债券，票面利率为3.98％，每年支付1次利息，每百元面值债券本次可获利息3.98元。

六、2018年第十期中国铁路建设债券（5年期）证券代码为“111903”，证券简称为“铁道1819”，是2018年7月4日发行的5年期债券，票面利率为4.18％，每年支付1次利息，每百元面值债券本次可获利息4.18元。

七、2018年第十期中国铁路建设债券（20年期）证券代码为“111904”，证券简称为“铁道1820”，是2018年7月4日发行的20年期债券，票面利率为4.65％，每年支付1次利息，每百元面值债券本次可获利息4.65元。

八、从2019年6月27日至2019年7月4日停办上述附息式国债、地方政府债、铁道债的转托管及调帐业务。

九、上述债券付息债权登记日为2019年7月4日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年7月5日除息交易。

十、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
