# 上海证券交易所关于聘任上海证券交易所第一届科创板股票上市委员会委员的公告

## 关于聘任上海证券交易所第一届科创板股票上市委员会委员的公告

上证公告〔2019〕17号

根据《关于在上海证券交易所设立科创板并试点注册制的实施意见》《科创板首次公开发行股票注册管理办法（试行）》和《上海证券交易所科创板股票上市委员会管理办法》等相关规定，经相关程序，决定聘任以下38人为上海证券交易所第一届科创板股票上市委员会委员（按姓氏笔画排序）：

王笑、王颂、申屹、刘凡、汤哲辉、阳琨、苏启云、苏星、李文智、李明、张小义、张利国、张忠、张建伟、XXX泰、陈春艳、陈晓、陈瑛明、陈巍、林勇峰、易平、罗培新、周芊、周国良、屈先富、胡咏华、柳艺、祝小兰、袁同济、袁伟荣、徐军、郭雳、唐丽子、葛徐、韩贤旺、谢纪龙、管红、潘广标。

特此公告。
