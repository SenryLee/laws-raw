# 深圳证券交易所关于招商局蛇口工业区控股股份有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种一）等两只债券上市有关事项的通知

## 关于招商局蛇口工业区控股股份有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种一）等两只债券上市有关事项的通知

各会员单位：

招商局蛇口工业区控股股份有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种一）、招商局蛇口工业区控股股份有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种二）定于2019年7月24日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、招商局蛇口工业区控股股份有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种一）证券代码"112929",证券简称"19蛇口03",发行总额15亿元，票面利率4.13%,债券期限5年。

2、招商局蛇口工业区控股股份有限公司2019年面向合格投资者公开发行公司债券（第二期）（品种二）证券代码"112930",证券简称"19蛇口04",发行总额6亿元，票面利率3.58%,债券期限3年。

特此通知
