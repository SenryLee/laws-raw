# 深圳证券交易所关于支付2018年记账式附息（二期）国债等三只债券利息有关事项的通知

## 关于支付2018年记账式附息（二期）国债等三只债券利息有关事项的通知

各市场参与人：

2018年记账式附息（二期）国债、2016年上海市政府专项债券（四期）、2014年江苏省政府债券（三期）将于2019年1月25日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年记账式附息（二期）国债证券代码为“101802”，证券简称为“国债1802”，是2018年1月25日发行的3年期债券，票面利率为3.56％，每年支付1次利息，每百元面值债券本次可获利息3.56元。

二、2016年上海市政府专项债券（四期）证券代码为“107191”，证券简称为“上海16Z4”，是2016年7月25日发行的10年期债券，票面利率为2.81％，每年支付2次利息，每百元面值债券本次可获利息1.405元。

三、2014年江苏省政府债券（三期）证券代码为“109135”，证券简称为“江苏1403”，是2014年7月25日发行的10年期债券，票面利率为4.29％，每年支付2次利息，每百元面值债券本次可获利息2.145元。

四、从2019年1月17日至2019年1月24日停办上述附息式国债、地方政府债的转托管及调帐业务。

五、上述债券付息债权登记日为2019年1月24日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年1月25日除息交易。

六、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
