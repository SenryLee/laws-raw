# 深圳证券交易所关于支付2018年浙江省政府专项债券（一期）等五只债券利息有关事项的通知

## 关于支付2018年浙江省政府专项债券（一期）等五只债券利息有关事项的通知

各市场参与人：

2018年浙江省政府专项债券（一期）、2017年重庆市政府一般债券（五期）、2017年重庆市政府专项债券（五期）、2017年北京市政府专项债券（四期）、2015年湖南省政府一般债券（四期）将于2019年1月17日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年浙江省政府专项债券（一期）证券代码为“106617”，证券简称为“浙江1803”，是2018年7月17日发行的10年期债券，票面利率为3.62％，每年支付2次利息，每百元面值债券本次可获利息1.81元。

二、2017年重庆市政府一般债券（五期）证券代码为“107805”，证券简称为“重庆1707”，是2017年7月17日发行的10年期债券，票面利率为4.01％，每年支付2次利息，每百元面值债券本次可获利息2.005元。

三、2017年重庆市政府专项债券（五期）证券代码为“107808”，证券简称为“重庆1710”，是2017年7月17日发行的10年期债券，票面利率为4.01％，每年支付2次利息，每百元面值债券本次可获利息2.005元。

四、2017年北京市政府专项债券（四期）证券代码为“107811”，证券简称为“北京1709”，是2017年7月17日发行的10年期债券，票面利率为3.78％，每年支付2次利息，每百元面值债券本次可获利息1.89元。

五、2015年湖南省政府一般债券（四期）证券代码为“109326”，证券简称为“湖南1504”，是2015年7月17日发行的10年期债券，票面利率为3.5％，每年支付2次利息，每百元面值债券本次可获利息1.75元。

六、从2019年1月9日至2019年1月16日停办上述地方政府债的转托管及调帐业务。

七、上述债券付息债权登记日为2019年1月16日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年1月17日除息交易。

八、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
