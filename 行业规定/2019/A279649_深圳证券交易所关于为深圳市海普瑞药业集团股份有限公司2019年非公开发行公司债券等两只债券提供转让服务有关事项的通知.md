# 深圳证券交易所关于为深圳市海普瑞药业集团股份有限公司2019年非公开发行公司债券等两只债券提供转让服务有关事项的通知

## 关于为深圳市海普瑞药业集团股份有限公司2019年非公开发行公司债券等两只债券提供转让服务有关事项的通知

各会员单位：

深圳市海普瑞药业集团股份有限公司2019年非公开发行公司债券、 国元证券股份有限公司2019年非公开发行公司债券（第一期）定于2019年5月9日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、深圳市海普瑞药业集团股份有限公司2019年非公开发行公司债券证券代码“114455”，证券简称“19海普瑞”，发行总额7亿元，票面利率5.5%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、国元证券股份有限公司2019年非公开发行公司债券（第一期）证券代码“114464”，证券简称“19国元01”，发行总额33亿元，票面利率4.25%，债券期限3年。
