# 深圳证券交易所关于支付2017年辽宁省政府一般债券（一期）等七只债券利息有关事项的通知

## 关于支付2017年辽宁省政府一般债券（一期）等七只债券利息有关事项的通知

各市场参与人：

2017年辽宁省政府一般债券（一期）、2017年辽宁省政府一般债券（二期）、2017年辽宁省政府一般债券（三期）、2017年辽宁省政府一般债券（四期）、2017年山东省政府一般债券（六期）、2015年山东省政府专项债券（七期）、2015年山东省政府一般债券（十二期）将于2019年3月15日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2017年辽宁省政府一般债券（一期）证券代码为“107534”，证券简称为“辽宁1701”，是2017年3月15日发行的3年期债券，票面利率为3.13％，每年支付1次利息，每百元面值债券本次可获利息3.13元。

二、2017年辽宁省政府一般债券（二期）证券代码为“107535”，证券简称为“辽宁1702”，是2017年3月15日发行的5年期债券，票面利率为3.3％，每年支付1次利息，每百元面值债券本次可获利息3.3元。

三、2017年辽宁省政府一般债券（三期）证券代码为“107536”，证券简称为“辽宁1703”，是2017年3月15日发行的7年期债券，票面利率为3.48％，每年支付1次利息，每百元面值债券本次可获利息3.48元。

四、2017年辽宁省政府一般债券（四期）证券代码为“107537”，证券简称为“辽宁1704”，是2017年3月15日发行的10年期债券，票面利率为3.65％，每年支付2次利息，每百元面值债券本次可获利息1.825元。

五、2017年山东省政府一般债券（六期）证券代码为“107999”，证券简称为“山东1711”，是2017年9月15日发行的10年期债券，票面利率为4.05％，每年支付2次利息，每百元面值债券本次可获利息2.025元。

六、2015年山东省政府专项债券（七期）证券代码为“109479”，证券简称为“山东15Z7”，是2015年9月15日发行的10年期债券，票面利率为3.59％，每年支付2次利息，每百元面值债券本次可获利息1.795元。

七、2015年山东省政府一般债券（十二期）证券代码为“109483”，证券简称为“山东1512”，是2015年9月15日发行的10年期债券，票面利率为3.6％，每年支付2次利息，每百元面值债券本次可获利息1.8元。

八、从2019年3月7日至2019年3月14日停办上述地方政府债的转托管及调帐业务。

九、上述债券付息债权登记日为2019年3月14日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年3月15日除息交易。

十、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
