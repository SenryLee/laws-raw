# 深圳证券交易所关于广州越秀融资租赁有限公司2018年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

## 关于广州越秀融资租赁有限公司2018年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

各会员单位：

广州越秀融资租赁有限公司2018年面向合格投资者公开发行公司债券（第一期）定于2019年1月22日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

广州越秀融资租赁有限公司2018年面向合格投资者公开发行公司债券（第一期）证券代码“112830”，证券简称“18越租01”，发行总额10亿元，票面利率4.68%，债券期限5年,附第3年末发行人调整票面利率选择权、赎回选择权和投资者回售选择权。
