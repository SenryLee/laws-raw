# 深圳证券交易所关于为深圳市龙光控股有限公司2019年非公开发行公司债券（第一期）提供转让服务有关事项的通知

## 关于为深圳市龙光控股有限公司2019年非公开发行公司债券（第一期）提供转让服务有关事项的通知

各会员单位：

深圳市龙光控股有限公司2019年非公开发行公司债券（第一期）（品种一）、 深圳市龙光控股有限公司2019年非公开发行公司债券（第一期）（品种二）定于2019年8月15日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、深圳市龙光控股有限公司2019年非公开发行公司债券（第一期）（品种一）证券代码“114531”，证券简称“19龙控02”，发行总额5亿元，票面利率6.5%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、深圳市龙光控股有限公司2019年非公开发行公司债券（第一期）（品种二）证券代码“114532”，证券简称“19龙控03”，发行总额10亿元，票面利率6.2%，债券期限4年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一九年八月十三日
