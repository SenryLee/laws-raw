# 深圳证券交易所关于平安银行股份有限公司可转换公司债券上市交易的公告

## 关于平安银行股份有限公司可转换公司债券上市交易的公告

平安银行股份有限公司发行的26,000,000,000元可转换公司债券自2019年2月18日起在本所上市交易，证券简称为“平银转债”，证券代码为“127010”，上市数量26,000万张。
