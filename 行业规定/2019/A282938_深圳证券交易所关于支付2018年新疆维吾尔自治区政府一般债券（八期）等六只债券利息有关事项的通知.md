# 深圳证券交易所关于支付2018年新疆维吾尔自治区政府一般债券（八期）等六只债券利息有关事项的通知

## 关于支付2018年新疆维吾尔自治区政府一般债券（八期）等六只债券利息有关事项的通知

各市场参与人：

2018年新疆维吾尔自治区政府一般债券（八期）、2018年广西壮族自治区政府一般债券（五期）、2018年广西壮族自治区政府土地储备专项债券（一期）——2018年广西壮族自治区政府专项债券（七期）、2018年广西壮族自治区政府棚户区改造专项债券（一期）——2018年广西壮族自治区政府专项债券（八期）、2018年广西壮族自治区政府收费公路专项债券（一期）——2018年广西壮族自治区政府专项债券（九期）、国家开发银行在深圳证券交易所2018年跨市场第五期金融债券将于2019年8月29日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年新疆维吾尔自治区政府一般债券（八期）证券代码为“106829”，证券简称为“新疆1820”，是2018年8月29日发行的5年期债券，票面利率为3.83％，每年支付1次利息，每百元面值债券本次可获利息3.83元。

二、2018年广西壮族自治区政府一般债券（五期）证券代码为“106830”，证券简称为“广西1811”，是2018年8月29日发行的7年期债券，票面利率为3.99％，每年支付1次利息，每百元面值债券本次可获利息3.99元。

三、2018年广西壮族自治区政府土地储备专项债券（一期）——2018年广西壮族自治区政府专项债券（七期）证券代码为“106831”，证券简称为“广西1812”，是2018年8月29日发行的5年期债券，票面利率为3.83％，每年支付1次利息，每百元面值债券本次可获利息3.83元。

四、2018年广西壮族自治区政府棚户区改造专项债券（一期）——2018年广西壮族自治区政府专项债券（八期）证券代码为“106832”，证券简称为“广西1813”，是2018年8月29日发行的5年期债券，票面利率为3.87％，每年支付1次利息，每百元面值债券本次可获利息3.87元。

五、2018年广西壮族自治区政府收费公路专项债券（一期）——2018年广西壮族自治区政府专项债券（九期）证券代码为“106833”，证券简称为“广西1814”，是2018年8月29日发行的10年期债券，票面利率为4.25％，每年支付2次利息，每百元面值债券本次可获利息2.125元。

六、国家开发银行在深圳证券交易所2018年跨市场第五期金融债券证券代码为“108604”，证券简称为“国开1805”，是2018年8月29日发行的3年期债券，票面利率为3.6％，每年支付1次利息，每百元面值债券本次可获利息3.6元。

七、从2019年8月21日至2019年8月28日停办上述地方政府债的转托管及调账业务。

八、上述债券付息债权登记日为2019年8月28日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年8月29日除息交易。

九、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所

二○一九年八月十五日
