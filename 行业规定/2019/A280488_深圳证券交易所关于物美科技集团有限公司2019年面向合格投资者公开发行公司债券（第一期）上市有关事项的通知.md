# 深圳证券交易所关于物美科技集团有限公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

## 关于物美科技集团有限公司2019年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

各会员单位：

物美科技集团有限公司2019年面向合格投资者公开发行公司债券（第一期）定于2019年6月19日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

物美科技集团有限公司2019年面向合格投资者公开发行公司债券（第一期）证券代码“112874”，证券简称“19物美01”，发行总额5亿元，票面利率4.3%，债券期限3年， 附第1年末、第2年末发行人调整票面利率选择权、赎回选择权和投资者回售选择权。
