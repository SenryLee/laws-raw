# 深圳证券交易所关于支付2018年记账式附息（二十五期）国债等五只债券利息有关事项的通知

## 关于支付2018年记账式附息（二十五期）国债等五只债券利息有关事项的通知

各市场参与人：

2018年记账式附息（二十五期）国债、2018年江西省政府一般债券（九期）、2017年广东省政府一般债券（四期）、2017年广东省政府专项债券（三期）、2015年江苏省政府一般债券（四期）将于2019年11月19日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年记账式附息（二十五期）国债证券代码为“101825”，证券简称为“国债1825”，是2018年11月19日发行的50年期债券，票面利率为3.82％，每年支付2次利息，每百元面值债券本次可获利息1.91元。

二、2018年江西省政府一般债券（九期）证券代码为“105108”，证券简称为“江西1820”，是2018年11月19日发行的5年期债券，票面利率为3.61％，每年支付1次利息，每百元面值债券本次可获利息3.61元。

三、2017年广东省政府一般债券（四期）证券代码为“107644”，证券简称为“广东1704”，是2017年5月19日发行的10年期债券，票面利率为3.93％，每年支付2次利息，每百元面值债券本次可获利息1.965元。

四、2017年广东省政府专项债券（三期）证券代码为“107647”，证券简称为“广东1707”，是2017年5月19日发行的10年期债券，票面利率为3.93％，每年支付2次利息，每百元面值债券本次可获利息1.965元。

五、2015年江苏省政府一般债券（四期）证券代码为“109165”，证券简称为“江苏1504”，是2015年5月19日发行的10年期债券，票面利率为3.41％，每年支付2次利息，每百元面值债券本次可获利息1.705元。

六、从2019年11月11日至2019年11月18日停办上述附息式国债、地方政府债的转托管及调帐业务。

七、上述债券付息债权登记日为2019年11月18日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2019年11月19日除息交易。

八、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
