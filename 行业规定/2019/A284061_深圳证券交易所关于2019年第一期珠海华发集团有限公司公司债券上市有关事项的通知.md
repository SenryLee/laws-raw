# 深圳证券交易所关于2019年第一期珠海华发集团有限公司公司债券上市有关事项的通知

## 关于2019年第一期珠海华发集团有限公司公司债券上市有关事项的通知

各会员单位：

2019年第一期珠海华发集团有限公司公司债券定于2019年11月15日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

2019年第一期珠海华发集团有限公司公司债券证券代码“111086”，证券简称“19华发债”，发行总额10亿元，票面利率4.43%，债券期限10年，附第5年末发行人调整票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所
