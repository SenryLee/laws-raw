# 深圳证券交易所关于2019年湖南省政府一般债券（二期）上市交易的通知

## 关于2019年湖南省政府一般债券（二期）上市交易的通知

各市场参与人：

2019年湖南省政府一般债券（二期）已发行结束，根据财政部有关规定，本期债券于2019年3月26日起在本所上市交易。

本期债券为10年期固定利率附息债，证券编码“105321”，证券简称“湖南1902”，票面利率3.39％，标准交易单位“10张”，2029年3月22日到期还本并支付最后一期利息。
