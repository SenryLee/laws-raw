# 深圳证券交易所关于2009年记账式（三期）国债到期兑付有关事项的通知

## 关于2009年记账式（三期）国债到期兑付有关事项的通知

各市场参与人：

2009年记账式（三期）国债将于2019年3月12日到期兑付。为做好本期债券的本息兑付工作，现将有关事项通知如下：

一、本期债券证券代码为“100903”，证券简称为“国债0903”，是2009年3月12日发行的10年期债券，票面利率为3.05%，每年支付2次利息，每百元面值债券兑付可获本息101.525元。

二、从2019年3月4日起停办本期附息式国债的转托管及调帐业务。

三、本期债券兑付债权登记日为2019年3月11日，凡于当日收市后持有本期债券的投资者，享有获得本次兑付款项的权利。2019年3月12日本期债券摘牌。

四、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的本期债券兑付款项后，将其划入各证券商的清算备付金帐户，并由证券商将兑付资金及时划入各投资者的资金帐户。

深圳证券交易所
