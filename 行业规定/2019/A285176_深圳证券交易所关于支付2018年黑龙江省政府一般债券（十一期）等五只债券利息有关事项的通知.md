# 深圳证券交易所关于支付2018年黑龙江省政府一般债券（十一期）等五只债券利息有关事项的通知

## 关于支付2018年黑龙江省政府一般债券（十一期）等五只债券利息有关事项的通知

各市场参与人：

2018年黑龙江省政府一般债券（十一期）、2018年黑龙江省政府专项债券（十期）、2019年北京市政府专项债券（十期）、2019年北京市棚改专项债券（十一期）——2019年北京市政府专项债券（二十三期）、2016年安徽省政府一般债券（八期）将于2020年1月2日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2018年黑龙江省政府一般债券（十一期）证券代码为“105135”，证券简称为“龙江1820”，是2019年1月2日发行的5年期债券，票面利率为3.45％，每年支付1次利息，每百元面值债券本次可获利息3.45元。

二、2018年黑龙江省政府专项债券（十期）证券代码为“105136”，证券简称为“龙江1821”，是2019年1月2日发行的5年期债券，票面利率为3.45％，每年支付1次利息，每百元面值债券本次可获利息3.45元。

三、2019年北京市政府专项债券（十期）证券代码为“105636”，证券简称为“北京1918”，是2019年7月1日发行的10年期债券，票面利率为3.49％，每年支付2次利息，每百元面值债券本次可获利息1.745元。

四、2019年北京市棚改专项债券（十一期）——2019年北京市政府专项债券（二十三期）证券代码为“105649”，证券简称为“北京1931”，是2019年7月1日发行的10年期债券，票面利率为3.49％，每年支付2次利息，每百元面值债券本次可获利息1.745元。

五、2016年安徽省政府一般债券（八期）证券代码为“107154”，证券简称为“安徽1608”，是2016年7月1日发行的10年期债券，票面利率为3.1％，每年支付2次利息，每百元面值债券本次可获利息1.55元。

六、从2019年12月24日至2019年12月31日停办上述地方政府债的转托管及调帐业务。

七、上述债券付息债权登记日为2019年12月31日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2020年1月2日除息交易。

八、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
