# 深圳证券交易所关于为大同煤矿集团有限责任公司2019年非公开发行公司债券（第三期）（品种一）等两只债券提供转让服务有关事项的通知

## 关于为大同煤矿集团有限责任公司2019年非公开发行公司债券（第三期）（品种一）等两只债券提供转让服务有关事项的通知

各会员单位：

大同煤矿集团有限责任公司2019年非公开发行公司债券（第三期）（品种一）、 大同煤矿集团有限责任公司2019年非公开发行公司债券（第三期）（品种二）定于2019年8月13日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、大同煤矿集团有限责任公司2019年非公开发行公司债券（第三期）（品种一）证券代码“114536”，证券简称“19同煤03”，发行总额3亿元，票面利率5.6%，债券期限3年，附第2年末发行人调整票面利率选择权和债券持有人回售选择权。

2、大同煤矿集团有限责任公司2019年非公开发行公司债券（第三期）（品种二）证券代码“114537”，证券简称“19同煤04”，发行总额17亿元，票面利率5.19%，债券期限3年，附第1年末、第2年末发行人调整票面利率选择权和债券持有人回售选择权。

深圳证券交易所

二○一九年八月十二日
