# 深圳证券交易所关于苏州晶瑞化学股份有限公司可转换公司债券上市交易的公告

## 关于苏州晶瑞化学股份有限公司可转换公司债券上市交易的公告

苏州晶瑞化学股份有限公司发行的185,000,000元可转换公司债券自2019年9月26日起在本所上市交易，证券简称为“晶瑞转债”，证券代码为“123031”，上市数量185万张。
