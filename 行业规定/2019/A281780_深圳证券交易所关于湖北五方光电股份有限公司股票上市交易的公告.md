# 深圳证券交易所关于湖北五方光电股份有限公司股票上市交易的公告

## 关于湖北五方光电股份有限公司股票上市交易的公告

湖北五方光电股份有限公司人民币普通股股票将于2019年9月17日在本所上市。证券简称为"五方光电",证券代码为"002962".公司人民币普通股股份总数为201,600,000股，其中50,400,000股股票自上市之日起开始上市交易。
