# 深圳证券交易所关于力合科技（湖南）股份有限公司股票在创业板上市交易的公告

## 关于力合科技（湖南）股份有限公司股票在创业板上市交易的公告

力合科技（湖南）股份有限公司人民币普通股股票将于2019年11月6日在本所创业板上市。证券简称为“力合科技”，证券代码为“300800”。公司人民币普通股股份总数为80,000,000股，其中20,000,000股股票自上市之日起开始上市交易。

深圳证券交易所

2019年11月4日
