# 深圳证券交易所关于信达投资有限公司2019年面向合格投资者公开发行公司债券（品种一）等两只债券上市有关事项的通知

## 关于信达投资有限公司2019年面向合格投资者公开发行公司债券（品种一）等两只债券上市有关事项的通知

各会员单位：

信达投资有限公司2019年面向合格投资者公开发行公司债券（品种一）,信达投资有限公司2019年面向合格投资者公开发行公司债券（品种二）定于2019年8月30日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、信达投资有限公司2019年面向合格投资者公开发行公司债券（品种一）证券代码“112951”，证券简称“19投资01”，发行总额4亿元，票面利率3.89%，债券期限5年,附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、信达投资有限公司2019年面向合格投资者公开发行公司债券（品种二）证券代码“112952”，证券简称“19投资02”，发行总额6亿元，票面利率4.27%，债券期限5年。

特此通知

深圳证券交易所
