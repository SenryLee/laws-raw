# 深圳证券交易所关于广东光华科技股份有限公司可转换公司债券上市交易的公告

## 关于广东光华科技股份有限公司可转换公司债券上市交易的公告

广东光华科技股份有限公司发行的249,300,000元可转换公司债券自2019年1月9日起在本所上市交易，证券简称为“光华转债”，证券代码为“128051”，上市数量249.30万张。
