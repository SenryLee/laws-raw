# 深圳证券交易所关于支付2018年内蒙古自治区本级政府收费公路专项债券（一期）——2018年内蒙古自治区政府专项债券（六期）利息有关事项的通知

## 关于支付2018年内蒙古自治区本级政府收费公路专项债券（一期）——2018年内蒙古自治区政府专项债券（六期）利息有关事项的通知

各市场参与人：

2018年内蒙古自治区本级政府收费公路专项债券（一期）——2018年内蒙古自治区政府专项债券（六期）将于2019年3月5日支付利息。为做好本期债券的利息支付工作，现将有关事项通知如下：

一、本期债券证券代码为“106853”，证券简称为“内蒙1821”，是2018年9月5日发行的10年期债券，票面利率为4.05％，每年支付2次利息，每百元面值债券本次可获利息2.025元。

二、从2019年2月25日至2019年3月4日停办本期地方政府债的转托管及调帐业务。

三、本期债券付息债权登记日为2019年3月4日，凡于当日收市后持有本期债券的投资者，享有获得本次利息款项的权利，2019年3月5日除息交易。

四、中国证券登记结算有限责任公司深圳分公司在收到发行人划付的本期债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所
