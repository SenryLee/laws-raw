# 深圳证券交易所关于北京指南针科技发展股份有限公司股票在创业板上市交易的公告

## 关于北京指南针科技发展股份有限公司股票在创业板上市交易的公告

北京指南针科技发展股份有限公司人民币普通股股票将于2019年11月18日在本所创业板上市。证券简称为“指南针”，证券代码为“300803”。公司人民币普通股股份总数为404,999,999股，其中56,900,000股股票自上市之日起开始上市交易。
