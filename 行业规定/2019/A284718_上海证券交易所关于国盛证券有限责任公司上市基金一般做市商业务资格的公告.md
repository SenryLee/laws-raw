# 上海证券交易所关于国盛证券有限责任公司上市基金一般做市商业务资格的公告

## 关于国盛证券有限责任公司上市基金一般做市商业务资格的公告

上证公告〔2019〕61号

根据《上海证券交易所上市基金流动性服务业务指引（2018年修订）》等相关规定，国盛证券有限责任公司自2019年12月6日起获得上海证券交易所上市基金一般做市商业务资格。

特此公告。

上海证券交易所

二〇一九年十二月六日
