# 深圳证券交易所关于为北京海吉星医疗科技有限公司2012年中小企业私募债券等3只私募债券提供转让服务有关事项的通知

各会员单位：

北京海吉星医疗科技有限公司2012年中小企业私募债券、漳州发展水务集团有限公司2012年中小企业私募债券、浙江森禾园艺有限公司2012年中小企业私募债券（第一期）定于2013年2月28日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、北京海吉星医疗科技有限公司2012年中小企业私募债券证券代码“118049”，证券简称“12海吉星”，发行总额20，000万元，票面利率8.50%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、漳州发展水务集团有限公司2012年中小企业私募债券证券代码“118051”，证券简称“12漳水债”，发行总额15，000万元，票面利率8.2%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

3、浙江森禾园艺有限公司2012年中小企业私募债券（第一期）证券代码“118052”，证券简称“12森园01”，发行总额10，000万元，票面利率9.98%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所　　

二○一三年二月二十六日
