# 深圳证券信息有限公司关于发布苏州率先指数的公告

为进一步丰富指数化投资标的，满足市场投资管理的需要，深圳证券信息有限公司定于2013年12月12日发布苏州率先指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399410 | 苏州率先指数 | 苏州率先 | 2011年12月30日 | 1000 |

苏州率先指数以沪深A股市场中苏州地区上市公司为备选范围，采用日均流通市值比重与日均成交金额比重2：1进行加权排序，结合上市公司基本面情况，选取排名靠前的30只股票构成样本股。

指数采用自由流通市值进行加权计算，样本股权重上限为10%，每年1月份与7月份进行样本股定期调整。

苏州率先指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：// www.cnindex.com.cn）。
