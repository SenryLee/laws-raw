# 深圳证券交易所、深圳证券信息有限公司关于发布深证农业综合企业指数的公告

为反映深市农业相关上市公司的整体表现，进一步完善多层次指数体系，满足投资管理的需要，深圳证券交易所和深圳证券信息有限公司决定于2013年6月24日发布深证农业综合企业指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399669 | 深证农业综合企业指数 | 深证农业 | 2004年12月31日 | 1000 |

深证农业综合企业指数参照巨潮行业分类标准，从归属于农业相关细分行业的深市A股中，综合考虑流通市值规模和流动性，选取排名靠前的50只股票组成样本股。指数样本股每半年调整一次，实施日期为每年1月和7月的第一个交易日。

指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（www.cnindex.com.cn）。

特此公告。
