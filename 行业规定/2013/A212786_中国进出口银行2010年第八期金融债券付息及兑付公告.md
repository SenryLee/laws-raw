# 中国进出口银行2010年第八期金融债券付息及兑付公告

为保证1 0进出08 （100308）付息及兑付工作的顺利进行，方便投资者及时领取付息及兑付资金，现将有关事宜公告如下：

**一、**本期债券基本情况

1．发行人：中国进出口银行

2．债券名称：中国进出口银行2 01 0年第八期金融债券

3．债券简称：1 0进出08

4．债券代码：1 0 0 3 08

5．发行总额：14 6.7亿元人民币

6．债券利率：2. 77%

7．付息及兑付日：2 0 1 3年9月2 1日。由于9月2 1日为假日，按规定顺延至9月2 2日支付

**二、**付息、兑付办法

托管在中央国债登记结算有限责任公司的债券，其付息、兑付资金由中央国债登记结算有限责任公司划付至债券持有人指定的银行账户。债券付息或到期兑付日如遇法定节假日，则划付资金的时间相应顺延。债券持有人资金汇划路径变更，应在付息、兑付前将新的资金汇划路径及时通知中央国债登记结算有限责任公司。因债券持有人资金汇划路径变更未及时通知中央国债登记结算有限责任公司而不能及时收到资金的，发行人及中央国债登记结算有限责任公司不承担由此产生的任何损失。
