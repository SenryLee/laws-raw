# 中国期货业协会关于期货公司风险管理服务子公司业务试点备案结果的公告

根据《期货公司设立子公司开展以风险管理服务为主的业务试点工作指引》、《期货公司风险管理服务子公司业务试点备案工作规程（试行）》等相关规则规定，经审查，瑞达期货股份有限公司等两家公司提交的设立子公司开展以风险管理服务为主的业务试点的备案申请材料齐全，符合规定，现予以备案。具体名单如下：

|  |  |
| --- | --- |
| 备案公司 | 备案事项 |
| 瑞达期货股份有限公司 | 1.设立风险管理服务子公司2.试点业务：仓单服务、合作套保 |
| 申银万国期货有限公司 | 1.设立风险管理服务子公司2.试点业务：仓单服务、合作套保、基差交易 |

中国期货业协会

2013年5月23日
