# 深圳证券信息有限公司关于发布巨潮周期行业100、防御行业100指数的公告

为反映A股市场具有周期性行业特征、防御性行业特征公司的整体表现，提供更丰富的指数化投资标的，深圳证券信息有限公司决定于2013年10月28日起发布巨潮周期行业100指数、巨潮防御行业100指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399402 | 巨潮周期行业100指数 | 周期100 | 2004年12月31日 | 1000 |
| 399403 | 巨潮防御行业100指数 | 防御100 | 2004年12月31日 | 1000 |

基于巨潮行业分类标准，巨潮周期行业100指数和巨潮防御行业100指数分别在周期性行业和防御性行业范围内，使用过去半年的日均成交额和日均流通市值两个指标进行综合评分，挑选出代表性较强、流动性较好的100只股票构成指数的样本股。样本股按照自由流通市值进行加权计算，单个股票权重上限为10%。两只指数均为每半年定期调整一次，调整时间为每年 1月和7月的第一个交易日，每次样本调整数量不超过样本总数的20%。

巨潮周期行业100指数、巨潮防御行业100指数均包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。

指数编制方案及最新样本股名单参见巨潮指数网（http：//www.cnindex.com.cn）。

特此公告。
