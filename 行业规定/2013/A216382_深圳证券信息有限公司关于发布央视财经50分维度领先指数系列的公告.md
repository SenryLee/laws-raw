# 深圳证券信息有限公司关于发布央视财经50分维度领先指数系列的公告

为刻画“创新、成长、回报、治理、社会责任”五个维度优秀企业的市场表现，促进相关主题投资和指数化投资的进一步发展，深圳证券信息有限公司与中央电视台财经频道决定于2013年6月6日起发布央视财经50分维度领先指数系列。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399551 | 央视财经50  　　创新领先指数 | 央视创新 | 2010年6月30日 | 2563.07 |
| 399552 | 央视财经50  　　成长领先指数 | 央视成长 | 2010年6月30日 | 2563.07 |
| 399553 | 央视财经50  　　回报领先指数 | 央视回报 | 2010年6月30日 | 2563.07 |
| 399554 | 央视财经50  　　治理领先指数 | 央视治理 | 2010年6月30日 | 2563.07 |
| 399555 | 央视财经50  　　责任领先指数 | 央视责任 | 2010年6月30日 | 2563.07 |

央视财经50分维度领先指数系列是央视财经50指数体系的重要组成部分，由央视财经频道汇聚中国上市公司协会、中国注册会计师协会、大公国际资信评估有限公司以及五所著名高校的专家群体，从“创新、成长、回报、公司治理、社会责任”五个维度对上市公司进行评价，每个维度各选出50家A股公司构成样本股。

该指数系列采用自由流通市值进行加权计算，个股权重上限为6%。指数每年8月份进行样本股年度调整，每年2月份进行中期评估与调整。

指数编制方案及最新样本股名单等资料参见巨潮指数网（www.cnindex.com.cn）。
