# 深圳证券信息有限公司关于发布巨潮大中盘指数和巨潮中小盘指数的公告

为反映沪深A股不同规模上市公司的整体表现，提供更丰富的指数化投资标的，满足指数产品发展的需要，深圳证券信息有限公司定于2013年3月20日发布巨潮大中盘指数和巨潮中小盘指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399400 | 巨潮大中盘指数 | 大中盘 | 2002年12月31日 | 1000 |
| 399401 | 巨潮中小盘指数 | 中小盘 | 2002年12月31日 | 1000 |

巨潮大中盘指数样本股由巨潮大盘指数样本股和巨潮中盘指数样本股组合而成，巨潮中小盘指数样本股由巨潮中盘指数样本股和巨潮小盘指数样本股组合而成， 样本股数量分别为500和800。

两条指数均包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：// www.cnindex.com.cn）。

特此公告。
