# 全国银行间同业拆借中心关于配合做好本币交易系统升级相关事宜的通知

## 全国银行间同业拆借中心关于配合做好本币交易系统升级相关事宜的通知（中汇交发〔2013〕325号）

银行间本币市场成员：

为配合本币交易系统升级、支持后续业务上线，请贵单位按要求进行系统配置，现将有关事宜通知如下：

**一、**新增系统配置要求

（一）升级现有本币交易系统终端机IE版本至IE 8及以上，推荐IE 8；显示器支持1280*1024分辨率及以上，推荐1280*1024。

（二）请在防火墙上开通下列端口：

|  |  |  |
| --- | --- | --- |
| 目的端IP地址 | 端口/协议 | 备注 |
| 200.31.73.62 | TCP 443（https）  Ping | 应用服务 |
| 200.31.50.81 | UDP 53 | DNS服务 |

如市场成员因内部管理要求或网络地址转换限制，无法使用DNS配置，则请在本币交易系统终端机按如下步骤操作：

1、打开“C：\Windows\System32\drivers\etc\hosts”文件。

2、添加如下条目：

200.31.73.62 cdis.chinamoney.com.cn

注：如市场成员有内部地址转换，请用转换后的地址替换条目中数字部分。

3、保存“C：\Windows\System32\drivers\etc\hosts”文件。
