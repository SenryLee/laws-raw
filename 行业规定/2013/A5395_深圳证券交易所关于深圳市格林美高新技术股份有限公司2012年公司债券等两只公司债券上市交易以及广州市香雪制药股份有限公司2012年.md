# 深圳证券交易所关于深圳市格林美高新技术股份有限公司2012年公司债券等两只公司债券上市交易以及广州市香雪制药股份有限公司2012年非公开发行公司债券进行转让的通知

各会员单位：

深圳市格林美高新技术股份有限公司2012年公司债券、苏宁电器股份有限公司公开发行2012年公司债券（第一期）定于2013年1月24日起在本所集中竞价系统和综合协议交易平台上市交易，广州市香雪制药股份有限公司2012年非公开发行公司债券定于2013年1月24日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、深圳市格林美高新技术股份有限公司2012年公司债券证券代码“112142”，证券简称“12格林债”，发行总额8亿元，票面利率6.65%，债券期限8年，附第5年发行人上调票面利率选择权和投资者回售选择权。

2、苏宁电器股份有限公司公开发行2012年公司债券（第一期）证券代码“112138”，证券简称“12苏宁01”，发行总额45亿元，票面利率5.20%，债券期限5年。

3、广州市香雪制药股份有限公司2012年非公开发行公司债券证券代码“112132”，证券简称“12制药债”，发行总额5.40亿元，票面利率7.80%，债券期限5年，附第3年发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所　　

二○一三年一月二十三日
