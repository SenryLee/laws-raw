# 深圳证券交易所关于为龙岩北山煤矿有限责任公司2012年中小企业私募债券等3只私募债券提供转让服务有关事项的通知

各会员单位：

龙岩北山煤矿有限责任公司2012年中小企业私募债券、黑乳（北京）商贸有限公司2012年中小企业私募债券和广州南菱汽车股份有限公司2012年中小企业私募债券（第二期）定于2013年2月6日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、龙岩北山煤矿有限责任公司2012年中小企业私募债券证券代码“118041”，证券简称“12北矿债”，发行总额10，000万元，票面利率8.50%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、黑乳（北京）商贸有限公司2012年中小企业私募债券证券代码“118044”，证券简称“12黑乳债”，发行总额15，000万元，票面利率9.00%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

3、广州南菱汽车股份有限公司2012年中小企业私募债券（第二期）证券代码“118048”，证券简称“12南菱02”，发行总额3，710万元，票面利率9.50%，债券期限2年。

深圳证券交易所　

二○一三年二月四日
