# 上海证券交易所关于2012年长沙先导投资控股有限公司公司债券上市交易的公告

长沙先导投资控股有限公司发行的2012年长沙先导投资控股有限公司公司债券，将于2013年1月18日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12长先导”，证券代码为“124081”。债券上市后可进行质押式回购，质押券申报和转回代码为“103081”。

上海证券交易所　

二○一三年一月十七日
