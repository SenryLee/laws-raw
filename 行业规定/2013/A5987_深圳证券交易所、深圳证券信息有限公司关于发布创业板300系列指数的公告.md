# 深圳证券交易所、深圳证券信息有限公司关于发布创业板300系列指数的公告

为反映创业板市场的发展态势，进一步完善创业板指数体系，满足投资管理的需要，深圳证券交易所和深圳证券信息有限公司定于2013年1月7日发布创业板300与创业板风格指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399012 | 创业板300指数 | 创业300 | 2012年6月29日 | 1000 |
| 399667 | 创业板300成长指数 | 创业板G | 2012年6月29日 | 1000 |
| 399668 | 创业板300价值指数 | 创业板V | 2012年6月29日 | 1000 |

创业板300选取创业板中代表性较强、流动性较好的 300 家上市公司股票组成样本股。创业板风格指数以创业板300指数为母指数，根据样本股的成长因子排名，筛选前100只股票组成创业板300成长指数，根据样本股的价值因子排名，筛选前100只股票组成创业板300价值指数。

三条指数均包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//index.cninfo.com.cn）。
