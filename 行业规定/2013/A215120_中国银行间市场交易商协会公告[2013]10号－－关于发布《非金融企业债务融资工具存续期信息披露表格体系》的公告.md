# 中国银行间市场交易商协会公告[2013]10号－－关于发布《非金融企业债务融资工具存续期信息披露表格体系》的公告

## 中国银行间市场交易商协会公告（[2013]10号）

为进一步规范非金融企业在所发行债务融资工具存续期内的信息披露行为，提升市场信息披露质量，保护投资者合法权益，根据《银行间债券市场非金融企业债务融资工具管理办法》（中国人民银行令[2008]第1号）以及中国银行间市场交易商协会（以下简称交易商协会）《银行间债券市场非金融企业债务融资工具信息披露规则》（协会公告[2012]2号）等相关自律规定，交易商协会组织市场成员制定了《非金融企业债务融资工具存续期信息披露表格体系》（以下简称《存续期信息披露表格体系》）。《存续期信息披露表格体系》于2013年6月18日经交易商协会第二届债券专业委员会第四次会议审议通过，并于2013年6月27日经交易商协会第三届常务理事会第六次会议审议通过，现予发布，并就有关事项明确如下：

**一、**债务融资工具处于存续期的发行企业及提供专业服务的中介机构应按照有关自律规定和《存续期信息披露表格体系》要求，编制、披露存续期相关信息披露文件。

**二、**《存续期信息披露表格体系》是对存续期间相关事项信息披露的最低要求，不论本表格体系是否列明，凡是对企业偿债能力以及对投资者做出投资决策有重大影响的信息，均应予以披露。投资者应当独立判断投资价值，自行承担投资风险。

**三、**发行企业及其全体董事或具有同等职责的人员，应当保证所披露的信息真实、准确、完整、及时，并承担相应法律责任。中介机构及其指派的经办人员，应对所出具的专业报告和专业意见负责。

**四、**《存续期信息披露表格体系》由交易商协会秘书处负责解释。

**五、**《存续期信息披露表格体系》自2013年10月1日起施行。

附件：非金融企业债务融资工具存续期信息披露表格体系

中国银行间市场交易商协会

二○一三年七月十八日

附件：

非金融企业债务融资工具存续期信息披露表格体系

为促进存续期信息披露的标准化和规范化，进一步增强信息披露的可操作性，提升市场信息披露质量，协会依据《银行间债券市场非金融企业债务融资工具信息披露规则》、《银行间债券市场非金融企业债务融资工具持有人会议规程》等自律规定制定本《非金融企业债务融资工具存续期信息披露表格体系》（简称《存续期信息披露表格体系》）。

**一、**使用说明

（一）《存续期信息披露表格体系》内容

《存续期信息披露表格体系》为债务融资工具存续期间的发行企业、信用增进机构和主承销商、会计师事务所、律师事务所等相关中介机构有关事项的信息披露格式规范，包括PC表（存续期年度报告信息披露表）、PZ表（存续期重大事项信息披露表）、PB表（存续期变更已披露信息披露表）、PD表（兑付信息披露表）、PH表（持有人会议信息披露表）、PX表（存续期信用增进机构信息披露表）、PK表（存续期会计师事务所专项意见信息披露表）及PF表（存续期专项法律意见信息披露表）共8套子表格及相关使用说明文件，各子表格以后续管理（Post-registration Supervision & Administration）英文首字母及表格中文名称关键字拼音首字母组合命名。

（二）相关表格中的列示内容是对存续期间相关事项信息披露的最低要求，债务融资工具存续期内，企业、信用增进机构及相关中介机构应按有关法律法规和自律规范文件要求披露信息、出具专业意见，并对所披露的信息和所出具的专业意见承担相应法律责任。具体而言：

1、发行企业应依据《银行间债券市场非金融企业债务融资工具信息披露规则》、《银行间债券市场非金融企业债务融资工具持有人会议规程》，按照PC表、PZ表、PB表、PD表及PH表要求披露年度报告、重大事项、变更已披露信息、兑付信息及持有人会议等相关信息。

2、信用增进机构应依据《银行间债券市场非金融企业债务融资工具信息披露规则》，参照发行企业按照PC表、PZ表、PB表要求披露信息，并按照PX表要求披露个别特殊事项信息。

3、会计师事务所应遵守行业准则及《银行间债券市场非金融企业债务融资工具中介服务规则》，依据相关规定对企业进行审计，按照PK表要求对企业变更已披露经审计财务信息出具专项说明。

4、律师事务所应遵守行业准则及《银行间债券市场非金融企业债务融资工具中介服务规则》，在充分尽职调查的基础上，针对存续期内相关法律事项，参照PF表发表法律意见；出席债务融资工具持有人会议的律师，应依据《银行间债券市场非金融企业债务融资工具持有人会议规程》，按照PH表要求对持有人会议的合法合规性出具法律意见。

5、召集人组织召开债务融资工具持有人会议时，应依据《银行间债券市场非金融企业债务融资工具中介服务规则》、《银行间债券市场非金融企业债务融资工具持有人会议规程》，按照PH表要求披露持有人会议有关信息。

6、相关主体按照各表格要求披露信息时，应满足以下一般要求：

（1）引用的有关信息应保证内容真实、准确；

（2）文字清晰准确，表述规范，不得出现矛盾歧义，不得刊载任何祝贺性、广告性和恭维性词句；

（3）披露文件应采用盖章的PDF格式。

（三）债务融资工具以非公开定向方式发行，相关主体于发行协议中约定参照公开发行方式披露相关信息的，应按照本《存续期信息披露表格体系》的有关要求予以披露。

| 序号 | 内容 |
|
| PZ-0 | 公告主体及标题 |
| PZ-0-1 | 主体名称及相关债项--披露主体名称。 |
| PZ-0-2 | 公告标题--首行简明填写相关企业拟披露何种具体事项；披露事项如涉及债项的，应对债项相关信息予以明确。 |
| PZ-1 | 企业更名 |
| PZ-1-1 | （一）企业公告 |
| 1、适用范围 　　发行企业名称变更时，应按照本节要求披露信息。 |
| 2、披露时间 　　企业应当自更名工商登记办理完毕之日起两个工作日内披露相关信息。 |
| 3、公告内容 　　（1）更名原因； 　　（2）工商登记变更完成情况； 　　（3）企业名称变更情况，企业涉及的债项简称及代码变更情况； 　　（4）企业更名后债权债务关系承继情况； 　　（5）企业有关债务融资工具存续期内严格履行信息披露、还本付息等相关义务的承诺。 　　若为信用增进机构更名的，应说明信用增进义务的承继情况。 |
| PZ-1-2 | （二）信用增进机构承诺函 |
| 1、适用范围 　　若更名发行企业存续期的债务融资工具涉及信用增进，信用增进机构应按照本节要求披露承诺函。 |
| 2、披露时间 　　信用增进机构承诺函应在发行企业更名公告发布之日起两个工作日内披露。 |
| 3、公告内容 　　（1）发行企业名称变更情况。 　　（2）为更名前企业提供信用增进的情况，包括但不限于债务融资工具名称、担保金额、担保期限、担保约束条件及担保性质等。 　　（3）所提供的信用增进继续适用于更名后企业的承诺。 |
| PZ-2 | 企业变更经营方针、经营范围 |
| PZ-2 | 企业公告 |
| 1、适用范围 　　对企业生产经营有重大影响的经营方针、经工商部门核准的经营范围发生变化，应按照本节要求披露相关信息。 |
| 2、披露时间 　　企业变更经营方针，应当自决定变更经营方针之日起两个工作日内披露相关信息；企业变更经营范围，应自办理完毕经营范围的工商变更登记手续之日起两个工作日内披露相关信息。 |
| 3、公告内容 　　相关基本情况： 　　（1）企业经营方针、经营范围变更原因，原经营方针、经营范围及变更后经营方针、经营范围具体信息； 　　（2）变更相关程序进展。企业变更经营范围的，需说明企业《公司章程》修改情况，企业就有关项目向主管部门申请及批复情况，及企业向工商管理部门申请变更有关信息的情况。 |
| PZ-3 | 企业生产经营的外部条件发生重大变化 |
| PZ-3 | 企业公告 |
| 1、适用范围 　　企业生产经营外部条件发生重大变化，包括但不限于产业或行业政策变化、重大灾害、特许经营权变化等对企业生产经营造成重大不利影响时，应按照本节要求披露相关信息。 |
| 2、披露时间 　　企业应于知悉或应当知悉该生产经营外部条件发生变化起两个工作日内披露相关信息；相关生产经营外部条件变化趋势发生重大改变时，企业应于知悉或应当知悉该情况起两个工作日内，及时披露事项后续进展。 |
| 3、公告内容 　　相关基本情况： 　　（1）生产经营外部条件发生重大变化的原因、有关变化情况； 　　（2）若该外部条件重大变化具有持续性且发生重大进展，企业应披露该进展情况。 　　（3）管理层预计上述影响的持续时间。 　　影响分析： 　　该外部条件变化对企业生产经营、财务状况及偿债能力的影响； 　　应对措施： 　　企业针对该重大变化采取或将采取的应对措施和安排。 |
| PZ-4 | 重大合同 |
| PZ-4 | 企业公告 |
| 1、适用范围 　　企业签订资产交易等非日常生产经营合同、合同涉及的资产总额（同时存在账面值和评估值的，以高者为准）或合同的成交金额占企业净资产10％以上的，以及企业签订日常生产经营合同、合同的成交金额占企业营业收入50%以上的，应按照本节要求披露相关信息。 |
| 2、披露时间 　　企业应于有权决策机构批准和合同签订之日起两个工作日内披露相关信息；若合同履行过程中出现风险事件对企业产生重大影响的，企业应于知悉或应当知悉该影响起两个工作日内，及时披露事项后续进展。 |
| 3、公告内容 　　相关基本情况： 　　（1）合同主要内容，包括合同各方、交易标的、交易金额、交易具体安排等； 　　（2）企业内部有权决策机构决议情况；主管部门核准情况；合同履行情况。 　　影响分析： 　　（1）签订该重大合同对企业生产经营、财务状况及偿债能力的影响。 　　（2）本次重大合同执行可能面临的相关风险情况。 |
| PZ-5 | 企业资产抵押、质押 |
| PZ-5 | 企业公告 |
| 1、适用范围 　　企业发生将所属资产抵（质）押，单笔抵（质）押金额（同时存在账面值和评估值的，以高者为准）占企业净资产达到10%或抵（质）押资产总额（口径同上）累计占企业净资产超过50%之后进行的任何抵（质）押，应按照本节要求披露相关信息。 |
| 2、披露时间 　　企业应于相关资产抵（质）押手续办理完结之日起两个工作日内披露相关信息。 |
| 3、公告内容 　　相关基本情况： 　　（1）企业内部有权决策机构决议情况； 　　（2）抵（质）押协议基本情况，包括但不限于被担保债务的金额及其范围、抵（质）押物基本情况、抵（质）押期限以及与抵（质）押相关的其他情况。 　　如因向他人提供担保进行资产抵（质）押，应披露被担保人基本情况。 　　（3）抵（质）押物的评估、登记、保管等相关法律手续办理情况； 　　（4）累计资产抵（质）押情况：截止公告日，企业累计资产抵（质）押余额、占净资产比重等情况。 　　影响分析： 　　本次或累次抵（质）押对企业生产经营、财务状况及偿债能力的影响。 |
| PZ-6 | 企业资产出售、转让、划转 |
| PZ-6 | 企业公告 |
| 1、适用范围 　　企业对外出售、转让资产金额（同时存在账面值和评估值的，以高者为准）占企业净资产10%以上，或企业无偿划转资产的，应按照本节要求披露相关信息。 　　若资产无偿划转导致企业净资产减少10%以上的，应及时通知主承销商召集相关债务融资工具持有人会议。 |
| 2、披露时间 　　企业应于签订相关协议后两个工作日内披露相关信息；于企业内部有权决策机构决定、有关主管部门批复、资产过户登记等重大时点两个工作日内，及时披露事项后续进展。 |
| 3、公告内容 　　相关基本情况： 　　（1）资产交易方案主要内容，包括资产交易各方、交易标的、交易金额、资产交易具体安排等； 　　（2）企业内部有权决策机构决议情况；主管部门核准情况；交易执行重大进展或变化情况； 　　（3）相关资产产权过户登记或工商变更登记完成情况。 　　影响分析： 　　（1）本次资产交易事项对企业生产经营、财务状况及偿债能力的影响。 　　（2）该项资产交易执行可能面临的相关风险情况； |

| PZ-7 | 企业公告 |
| 1、适用范围 　　企业所属固定资产由于使用过程中的有形磨损和无形磨损致使该资产未达到正常使用年限而报废清理，报废资产金额（同时存在账面值和评估值的，以高者为准）占企业净资产5%以上的，应按照本节要求披露相关信息。 |

| 2、披露时间 　　企业应当自决定进行停顿或收到相关主管部门停顿通知之日起两个工作日内披露相关信息；于导致业务停顿事由消除之日起两个工作日内，及时披露事项后续进展。 |
| 3、公告内容 　　相关基本情况： 　　（1）企业业务介绍，主要或者全部业务陷入停顿的原因及起始时间，陷入停顿的业务情况概述； 　　（2）后续相关进展，如整改情况，相关主管部门的检查验收情况，业务恢复正常运营情况等。 　　影响分析： 　　（1）业务停顿对企业正常生产经营秩序的影响，预计损失及对企业偿债能力的影响； 　　（2）预计主要或者全部业务恢复正常运营的时间。 　　应对措施： 　　企业为降低、消除业务停顿影响采取的应对措施，应相关主管部门要求实施的整改措施等。 |
| PZ-24 | 企业对外提供重大担保 |
| PZ-24 | 企业公告 |
| 1、适用范围 　　企业为其他主体融资、履行合同提供担保，单笔担保金额（同时存在账面值和评估值的，以高者为准）占企业净资产10%以上或担保总额（口径同上）累计占企业净资产超过50%之后进行的任何对外担保，应按照本节要求披露相关信息。 |
| 2、披露时间 　　企业应于担保手续（提供保证的指签署保证合同之日，提供抵（质）押的指抵（质）押登记手续办理完毕之日，不涉及办理登记的，则为签署相关抵（质）押合同之日）办理完结之日起两个工作日内披露相关信息。 |
| 3、公告内容 　　相关基本情况： 　　（1）企业内部有权决策机构决议情况，相关手续办理情况； 　　（2）被担保人、担保受益人、反担保机构（若有）等担保事项相关各方，被担保人基本情况；担保金额、担保期限、担保方式、担保范围等担保要件以及共同担保、附加担保情况等担保协议主要内容。 　　（3）累计担保情况：截至公告日，企业累计对外担保余额、占净资产比重等情况，本年度最高对外担保限额，逾期担保总额（如有）。 　　影响分析： 　　本次或累计担保对企业生产经营、财务状况及偿债能力的影响。 |
| PZ-25 | 企业信息披露事务管理制度 |
| PZ-25 | 企业公告 |
| 1、适用范围 　　企业应当制定信息披露事务管理制度，经企业董事会或其他有权决策机构审议通过，并向市场公开披露其主要内容。 |
| 2、披露时间 　　企业应于披露债务融资工具首次发行文件时，披露事务管理制度主要内容，并于后续修订完成后、及时向市场披露制度更新情况。 |
| 3、公告内容 　　信息披露事务管理制度内容包括但不限于：  　　（1）明确企业应遵守的信息披露标准；  　　（2）未公开信息的传递、审核、披露流程；  　　（3）信息披露事务管理部门及其负责人在信息披露中的职责；  　　（4）董事和董事会、监事和监事会、高级管理人员等的报告、审议和披露的职责；  　　（5）董事、监事、高级管理人员履行职责的记录和保管制度；  　　（6）未公开信息的保密措施，内幕信息知情人的范围和保密责任；  　　（7）财务管理和会计核算的内部控制及监督机制；  　　（8）对外发布信息的申请、审核、发布流程；与投资者、中介服务机构、媒体等的信息沟通与制度；  　　（9）信息披露相关文件、资料的档案管理；  　　（10）涉及子公司的信息披露事务管理和报告制度；  　　（11）未按规定披露信息的责任追究机制，对违反规定人员的处理措施； 　　（12）重大事项的报告、传递、审核、披露程序； 　　（13）事务管理制度首次经企业董事会或其他有权决策机构审议通过的情况； 　　（14）事务管理制度的后续修订过程及修订内容，并经企业董事会或其他有权决策机构审议通过的情况。 |

| PZ-26 | 1、信息披露承诺--企业承诺所披露信息的真实、准确、完整、及时，并将按照银行间债券市场相关自律规则的规定，履行相关后续信息披露义务。 |
| 2、公告落款--企业全称、公章及披露时间 |

说明：

1、企业发生《银行间债券市场非金融企业债务融资工具信息披露规则》第九条、第二十条、第二十一条所规定的重大事项时，应按本表格的要求披露相关信息。信用增进机构应参照本表格要求披露重大事项信息。不论本表格是否明确规定，凡是可能影响企业偿债能力的其他重大事项，企业均应予以披露。

2、本表格各节“重大事项适用范围”中涉及的量化财务数据比较基准是关于该类事项重大程度的最低参考标准，企业发生相关事项时应予以充分评估，凡是可能影响偿债能力的事项均应予以披露。

3、本表格中涉及的量化财务数据比较基准，均为企业最近一年或一期经审计的合并口径财务报表数据。

4、企业发生的重大事项同时涉及本表格不同章节描述情形的，可于一份公告中说明事项情况，但需同时满足各类情形的公告内容要点。

5、若企业在其他媒体公开披露了与该重大事项有关的董事会决议文件、交易报告书或报告书摘要、法律意见书等文件，可在银行间债券市场披露相关链接并予以简要说明。

6、公告填写说明

（1）PZ0为公告主体及标题、PZ26为企业信息披露承诺及落款，PZ1-PZ25为各类企业拟披露重大事项信息的基本格式要求。企业发生重大事项后，应填写【PZ0＋ （PZ1-PZ25）＋ PZ26】表格相应内容。

（2）PZ1-PZ25表格包含事项各阶段披露内容，企业披露重大事项后，该重大事项出现可能对企业偿债能力产生较大影响的进展或变化的，应当在各时点起两个工作日内分别对应披露事项进展或变化情况、可能产生的影响等。

| PH-2 | 持有人会议决议公告 |

| PH-2 | 1、适用范围  　　根据《银行间债券市场非金融企业债务融资工具持有人会议规程》第二十七条规定，持有人会议召集人需披露会议决议公告文件的，应按本节要求披露相关信息。 |
| PH-2 | 2、披露时间  　　持有人会议召集人应于持有人会议表决截止日次一工作日披露会议决议公告。 |
| 3、公告内容  　　（1）持有人会议的基本信息  　　发行人名称、债项简称、会议名称、召集人、持有人会议召开时间、召开地点；  　　（2）会议参会情况  　　会议召开形式；本期债项持有人机构数目、出席持有人会议机构数目、参会形式、出席机构与发行人关联关系说明；参会机构持券金额以及占比；会议有效性；  　　（3）会议审议情况  　　同意、反对会议议案、以及放弃投票权的机构数目、持券金额、占本期债务融资工具出席会议机构持券金额的持券量比例；核对投票的有效性、确认表决的有效性；  　　（4）相关法律意见  　　出具法律意见书的律师及其所在的律师事务所；律师发表法律意见的范围及法律意见； |
| PH-3 | 持有人会议发行人答复 |
| PH-3 | 1、适用范围  　　根据《银行间债券市场非金融企业债务融资工具持有人会议规程》第二十八、第二十九条规定，发行企业需披露对持有人会议决议文件的答复公告文件的，应按本节要求披露相关信息。 |
| 2、披露时间  　　发行企业应于持有人会议表决截止日后四个工作日之内披露相关答复公告。 |
| 3、公告内容  　　发行人名称、债项简称、会议名称、会议时间、会议召开方式、会议议案；持有人参会及表决情况；会议决议情况；发行人对于会议决议是否同意的声明； |
| PH-4 | 持有人会议法律意见书 |
| PH-4 | 1、适用范围  　　根据《银行间债券市场非金融企业债务融资工具持有人会议规程》第十七条规定，律师应出具的法律意见书，应按照本节要求披露相关信息。 |
| 2、披露时间  　　相关律师应于会议表决截止日次一工作日随同会议决议公告一并披露其法律意见书。 |
| 3、法律意见内容  　　（1）会议的召集和召开  　　针对会议召集人、会议召开公告披露时间、披露渠道、公告内容概述；会议召开时间、地点、召开形式，明确表达上述事项法律意见，说明相关依据。  　　（2）本次会议出席人员的参会资格  　　针对本期债项持有人机构数目、出席会议的机构数目、参会形式、参会机构持券金额；出席机构与发行人关联关系、参会人员参会资格的有效性；参会人员持券金额占本期债务融资工具发行金额的比例，明确表达参会资格有效性、会议有效性的法律意见，说明相关依据。  　　（3）会议事项审议  　　针对会议审议内容；议案审议基本情况，包括议案与《持有人会议公告》中列明的审议事项是否一致、是否对议案进行更改或者修正、是否审议了议案中未列明事项；明确表达针对会议议案审议情况的法律意见，说明相关依据。  　　（4）会议的表决程序及表决结果  　　针对表决方式、收到表决票数、对应的持券金额、占本期债务融资工具出席会议机构持券金额的比例、表决票的有效性；同意、反对以及弃投票的数目、对应的持券金额、各自占本期债务融资工具出席会议机构持券金额的持券量比例；说明出具法律意见的法律或者规则依据、明确表达针对会议的表决程序及表决结果的法律意见。 |
