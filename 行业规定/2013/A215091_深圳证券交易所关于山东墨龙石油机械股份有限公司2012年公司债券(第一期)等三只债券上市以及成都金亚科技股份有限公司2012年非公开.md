# 深圳证券交易所关于山东墨龙石油机械股份有限公司2012年公司债券(第一期)等三只债券上市以及成都金亚科技股份有限公司2012年非公开发行公司债券(第一期)进行转让有关事项的通知

## 深圳证券交易所关于山东墨龙石油机械股份有限公司2012年公司债券（第一期）等三只债券上市以及成都金亚科技股份有限公司2012年非公开发行公司债券（第一期）进行转让有关事项的通知

各会员单位：

广东奥飞动漫文化股份有限公司2012年公司债券，广东南洋电缆集团股份有限公司2013年公司债券，山东墨龙石油机械股份有限公司2012年公司债券（第一期）定于2013年07月23日起在本所上市，并在集中竞价系统和综合协议交易平台同时挂牌交易，成都金亚科技股份有限公司2012年非公开发行公司债券（第一期）定于2013年07月23日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、成都金亚科技股份有限公司2012年非公开发行公司债券（第一期）证券代码“112185”，证券简称“12金亚01”，发行总额15000万元，票面利率8.400%，债券期限4年，债券存续期第二年末上调票面利率选择权、投资者回售选择权；

2、广东奥飞动漫文化股份有限公司2012年公司债券证券代码“112180”，证券简称“12奥飞债”，发行总额55000万元，票面利率5.200%，债券期限5年，债券存续期第三年末上调票面利率选择权、投资者回售选择权；

3、广东南洋电缆集团股份有限公司2013年公司债券证券代码“112179”，证券简称“13南洋债”，发行总额65000万元，票面利率6.000%，债券期限7年，债券存续期第五年末上调票面利率选择权、投资者回售选择权；

4、山东墨龙石油机械股份有限公司2012年公司债券（第一期）证券代码“112178”，证券简称“12墨龙01”，发行总额50000万元，票面利率5.200%，债券期限3年。

特此通知
