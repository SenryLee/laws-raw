# 深圳证券交易所、深圳证券信息有限公司关于发布深证信用债、公司债综合指数的公告

为进一步丰富和完善深证指数体系，推动指数化投资的不断发展与创新，深圳证券交易所和深圳证券信息有限公司决定于2013年4月15日通过行情系统发布深证信用债综合指数、深证公司债综合指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399301 | 深证信用债综合指数 | 深信用债 | 2008年12月31日 | 100 |
| 399302 | 深证公司债综合指数 | 深公司债 | 2008年12月31日 | 100 |

上述指数以在深圳证券交易所上市的债券为选样空间，从中选择企业债、公司债作为深证信用债综合指数样本，选择公司债作为深证公司债综合指数样本。指数样本债券信用级别为投资级以上，剩余期限超过一年，附息方式为固定利率付息和一次还本付息。样本债券每月调整一次。

指数编制方案及样本名单参见巨潮指数网（www.cnindex.com.cn）。

特此公告。
