# 深圳证券交易所关于为杭州建工混凝土有限公司2012年中小企业私募债券等3只私募债券提供转让服务有关事项的通知

各会员单位：

杭州建工混凝土有限公司2012年中小企业私募债券、杭州市设备安装有限公司2012年中小企业私募债券和润百计算机（上海）有限公司2012 年中小企业私募债券定于2013年5月8日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、杭州建工混凝土有限公司2012年中小企业私募债券证券代码“118076”，证券简称“12杭建工”，发行总额3，000万元，票面利率9.50%，债券期限3年，附第2年末发行人调整票面利率选择权及投资者回售权，若投资者回售债券后余额不足3000万元，发行人有权选择是否全额赎回债券。

2、杭州市设备安装有限公司2012年中小企业私募债券证券代码“118077”，证券简称“12杭设备”，发行总额7，000万元，票面利率9.50%，债券期限3年，附第2年末发行人调整票面利率选择权及投资者回售权，若投资者回售债券后余额不足7000万元，发行人有权选择是否全额赎回债券。

3、润百计算机（上海）有限公司2012 年中小企业私募债券证券代码“118056”，证券简称“12润百债”，发行总额5，000万元，票面利率9.50%，债券期限3年，附第二年末投资者回售选择权。

深圳证券交易所　

二○一三年五月七日
