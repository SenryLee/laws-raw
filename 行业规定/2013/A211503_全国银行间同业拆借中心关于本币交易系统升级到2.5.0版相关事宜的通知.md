# 全国银行间同业拆借中心关于本币交易系统升级到2.5.0版相关事宜的通知

## 全国银行间同业拆借中心关于本币交易系统升级到2.5.0版相关事宜的通知（中汇交发〔2013〕272号）

银行间本币市场成员：

为进一步完善本币交易系统功能，全国银行间同业拆借中心（以下简称“交易中心”）将于2013年10月18日发布本币交易系统2.5.0版本，现将有关事宜通知如下：

**一、**升级内容

此次升级，主要新增和调整以下功能：

1、现券市场新增请求报价交易方式；

2、调整做市报价功能，做市报价可匿名发送；

3、调整最优点击成交报价展示逻辑，只展示报价量高于系统设定最小量的点击成交报价；

4、调整现券单边点击成交报价权限管理，做市商和尝试做市机构可发送单边点击成交报价；

5、调整现券交易限额控制功能，增加现券交易员报价限额和单笔报价限额控制；

6、新增结算代理模块，为境外机构提供向本方结算代理人发起格式化意向委托和交易指令，并将交易指令上传至本币交易系统的功能。

**二、**升级时间和安排

1、10月18日（周五）17：00至19：00

本币市场成员确认当日所有交易和业务操作均已结束后，可进行新版客户端升级并确认版本号（打开前台或中后台，版本号显示为“2.5.0”即为升级成功，当日不能登录）。

2、10月20日（周日）9：00至11：00

本币市场成员需使用新版客户端进行登录验证（因本次为大版本升级。为保证不影响下一交易日工作，请务必进行此项操作）。

本币CSTP和CMDS会员需使用API接口进行登陆验证（本次升级不包含本币CSTP、CMDS接口，会员端请勿进行API开发包升级）。

**三、**本币交易系统客户端升级步骤

本次升级有三种方式可供选择：自动更新、手动更新、全量安装。客户端所有版本均可通过全量安装方式完成升级，其中2.4.2版本可通过自动更新或手动更新完成升级，具体步骤如下：

1、自动更新

自动更新开放时间为10月18日17：00以后：

（1）若有正在运行的DWS和MBO，请先退出程序；

（2）重新打开客户端，程序进行自动更新，完成后显示新版本的登录界面，版本号为2.5.0。

2、手动更新（较适合拨号用户）

（1）获取增量升级包安装程序，可通过互联网或专线网下载：

I.在互联网环境打开“中国货币网”中“培训与服务支持”-＞“技术支持”-＞“软件下载”：

下载DWS升级包：点击“DWS-2.5.0-Updates.exe”；

下载MBO升级包：点击“MBO-2.5.0-Updates.exe”。

II.在专线网环境打开http：//200.31.73.60/：

下载DWS安装包：点击“公告”标签，选择2.5.0更新程序的“交易前台”进行下载；

下载MBO安装包：点击“公告”标签，选择2.5.0更新程序的“交易中后台”进行下载。

（2）双击DWS-2.5.0-Updates.exe，安装DWS升级包；双击MBO-2.5.0-Updates.exe， 安装MBO升级包（如果有正在运行的DWS和MBO，请先退出程序）。DWS、MBO的升级包安装成功后登陆界面显示版本号均为2.5.0。

3、全量安装

（1）获取安装包程序，可通过互联网或专线网下载：

I. 在互联网环境打开“中国货币网”中“培训与服务支持”-＞“技术支持”-＞“软件下载”：

下载DWS升级包：点击“DWS-2.5.0.exe”；

下载MBO升级包：点击“MBO-2.5.0.exe”。

II. 在专线网环境打开http：//200.31.73.60/

下载DWS安装包：点击“交易前台”标签，选择“2.5.0”的DWS进行下载；

下载MBO安装包：点击“交易中后台”标签，选择“2.5.0”的MBO进行下载。

（2）分别卸载已安装的旧版本DWS和MBO，双击DWS-2.5.0.exe安装DWS客户端，双击MBO-2.5.0.exe安装MBO客户端。DWS、MBO安装成功后登陆界面显示版本号均为2.5.0。

**四、**关于结算代理行和委托机构使用结算代理模块相关要求

1、终端软硬件配置要求

|  |  |
| --- | --- |
| 屏幕分辨率 | 建议使用1280*1024及以上 |
| 浏览器 | 建议使用IE Explore 8及以上版本 |
| 证书管理器 | USB Key驱动及证书管理器 |

详细配置请参考结算代理行用户手册、境外委托机构用户手册。

2、获取USB Key驱动及证书管理器

在互联网打开页面：

http：//www.chinamoney.com.cn/fe/Info/3363300。

点击“CertManager_2.28i.exe”，下载CertManager_2. 28i.exe文件

具体请参考境外委托机构用户手册。

3、终端网络要求

使用结算代理模块需要连接专线网并正确解析结算代理模块服务器域名。如果结算代理行和境外委托机构的交易机在访问结算代理模块时需通过防火墙设备，请在防火墙上开通下列端口：

|  |  |  |  |
| --- | --- | --- | --- |
| 网络 | 目的端IP地址 | 端口 | 备注 |
| 专线网 | 200.31.73.61 | TCP 8002 | 结算代理应用服务 |
| 200.31.50.81 | UDP 53 | 域名解析服务 |

DNS服务器地址为200.31.50.81，具体请参考结算代理行用户手册、境外委托机构用户手册。

4、访问方式

结算代理行和境外委托机构访问结算代理模块方式：

（1）结算代理行登陆本币交易系统前台客户端，通过菜单登陆结算代理模块。使用结算代理模块前需要通过系统管理员为相关用户设置权限。

（2）境外委托机构用户在专线网环境下，通过IE浏览器访问https：//rmbmkt.chinamoney.com.cn：8002/rmbscm。

具体请参考结算代理行用户手册、委托机构用户手册。

**五、**注意事项

1、升级之前，请务必先检查交易机的软硬件配置是否满足系统安装要求（内存应至少为2GB，网络应至少符合推荐配置），详细配置要求请参考《新一代本币交易系统前台、中后台安装手册》中“配置需求说明”章节。

2、请按照本通知的操作步骤完成客户端系统升级。安装过程中无需重启，全部安装完毕重启一次即可。

3、安装客户端前请确认安装用户具有操作系统的系统管理员权限（对安装目录、Program Files\Common Files目录和注册表有写入权限）。

4、安装客户端结束前，若用户电脑装有防火墙，防火墙软件可能会有下列提示：“有程序试图添加未知的开机启动程序，是否允许”。开机启动项名称为“DWS Launcher”（或“MBO Launcher”）和“SyncClient”。建议用户选择允许此启动项的加入，以加快交易前台程序的启动速度。
