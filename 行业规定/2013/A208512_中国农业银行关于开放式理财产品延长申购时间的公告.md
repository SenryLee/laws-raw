# 中国农业银行关于开放式理财产品延长申购时间的公告

尊敬的投资者：

为满足客户理财需求，我行将于2013年12月31日（周二）当日延长开放式人民币理财产品的申购交易时间至17：50（赎回交易不改），欢迎广大投资者进行申购。

本次继续开放申购交易的理财产品明细如下：

|  |  |  |
| --- | --- | --- |
| 产品名称 | 当前预期收益率 | 产品类型 |
| “本利丰?天天利”2013年第1期开放式人民币理财产品 | 2.8% | 保本浮动收益 |
| “本利丰?天天利”2013年第2期开放式人民币理财产品 | 2.8% | 保本浮动收益 |
| “金钥匙?安心快线”天天利滚利第2期人民币理财产品 | 3.9% | 非保本浮动收益 |
| “金钥匙?安心快线”天天利滚利第3期人民币理财产品 | 3.9% | 非保本浮动收益 |
| “金钥匙?安心快线”私人银行天天利第2期开放式人民币理财产品 | 4.1-4.3% | 非保本浮动收益 |

此外，2014年1月1日（元旦）为法定节假日，所有开放式产品停止申购、赎回交易，2014年1月2日恢复申购、赎回交易。

特此公告。

中国农业银行

二〇一三年十二月三十日
