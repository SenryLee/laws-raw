# 中国工商银行股份有限公司关于终止两周滚动型、三周滚动型和四周滚动型法人人民币理财产品的通告

尊敬的客户：

由于近期我行新发行的14天、21天、28天增利型法人人民币理财产品与滚动型产品相比，具有预期收益更佳、投资更便捷和流动性更强等特点，能够满足购买滚动型产品客户的投资需求，因此根据产品说明书的约定及产品管理情况，我行决定于近期终止两支两周滚动型法人人民币理财产品（产品代码分别为0801CDQD、0901CDQD）、一支三周滚动型法人人民币理财产品（产品代码1001CDQE）和四支四周滚动型法人人民币理财产品（产品代码分别为0701CDQA、0801CDQA、0901CDQA、0902CDQA）。具体安排如下。

|  |  |  |
| --- | --- | --- |
| 产品代码 | 最新一周期到期日 | 产品终止时间 |
| 0701CDQA | 2013年11月18日 | 2013年11月19日起停止发售，2013年12月16日产品终止。 |
| 0801CDQA | 2013年11月18日 | 2013年11月19日起停止发售，2013年12月16日产品终止。 |
| 0801CDQD | 2013年11月10日 | 2013年11月11日起停止发售，2013年11月24日产品终止。 |
| 0901CDQA | 2013年12月2日 | 2013年12月3日起停止发售，2014年1月6日产品终止。 |
| 0902CDQA | 2013年12月2日 | 2013年12月3日起停止发售，2014年1月6日产品终止。 |
| 0901CDQD | 2013年11月21日 | 2013年11月22日起停止发售，2013年12月5日产品终止。 |
| 1001CDQE | 2013年11月19日 | 2013年11月20日起停止发售，2013年12月10日产品终止。 |

投资周期在终止日前的滚动型产品将正常兑付；设置了自动再投资的产品，将在终止日前一个周期结束日自动到期，本金及收益将按说明书约定于结束日次日到账。

仍有投资两周、三周、四周理财产品需求的客户，可购买我行14天、21天、28天增利型法人人民币理财产品（产品代码ZL14ZST、ZL21ZST、ZL28ZST），有关产品说明书的具体内容详见中国工商银行网站（www.icbc.com.cn）。欢迎广大客户购买。

特此通告。
