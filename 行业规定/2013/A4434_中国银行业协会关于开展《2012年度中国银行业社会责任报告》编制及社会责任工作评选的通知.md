# 中国银行业协会关于开展《2012年度中国银行业社会责任报告》编制及社会责任工作评选的通知

各会员单位：

为了全面展示中国银行业社会责任履行情况，推进我国银行业社会责任实践工作深入发展，提升中国银行业社会责任管理水平，中国银行业协会将在全行业组织开展《2012年度中国银行业社会责任报告》编制数据、素材收集和社会责任工作评选活动，报告编制的数据采集将与评选活动结合进行。

现请各会员单位从中国银行业协会网站“重要公告”栏中下载相关文件并完成填报工作。

具体说明及要求如下：

**一、**报送主体要求

1.此次活动由中国银行业协会各会员单位总行（总部）按系统统一组织，以法人为单位向中银协报送汇总统计数据，各单位分支机构不单独报送数据。

2.各省、市、区银行业协会（同业公会、以下简称地方协会）负责组织各地非中国银行业协会会员银行总行（主要指地方城市商业银行）参加此次活动。非中国银行业协会会员可以总行为单位向地方协会报送数据、推荐先进，地方协会负责搜集、转报中银协，地方协会不需对统计数据进行汇总。

3.同为中国银行业协会及地方协会的会员单位，申报材料由各单位总行直接向中银协报送。

4.各级会员单位辖属分支机构不单独参加先进评选推荐（“年度最佳社会责任特殊贡献网点奖”除外）。

**二、**报送材料要求

1.为简化材料报送程序，本次社会责任报告数据采集工作和2012年度中国银行业社会责任工作评选拟采用同一套表格进行一次性报送。

2.已发布2012年度社会责任报告的会员单位，可将报告作为申报材料附件上报，纸质版或电子版均可。

3.在填报案例、事迹类材料时，文字叙述要求简要、全面，详细介绍及图片资料（像素不低于1024×768）可作为附件一并上报，同时供编写行业社会责任报告的素材之用。

会员单位所报原始数据，将同时作为编制报告和参与评选的基本依据。

**三、**报送时间要求

所有材料须于2013年3月20日前报送电子版和纸质版，电子版发至邮箱：sunyi@china-cba.net，纸质材料需加盖公章邮寄至中国银行业协会自律部孙毅，逾期不报送材料的单　位，将视作自动放弃参评资格。

附件2

2012年度中国银行业社会责任工作评选活动方案

（中国银行业协会　　二○一三年二月）

企业履行社会责任是落实科学发展观的具体体现，是构建和谐社会、实现经济社会可持续发展的必然要求。银行业金融机构是我国金融行业的重要组成部分，是我国经济运行体系的核心参与者，银行业金融机构全面履行社会责任，对于提升行业整体素质和服务水平、增强核心竞争力，更好满足各利益相关方的期望及要求，促进经济社会发展，都具有重要的意义。

为进一步推进我国银行业社会责任实践工作深入发展，引导各机构秉承“责任银行和谐发展”的社会责任理念正确履行社会责任，提升中国银行业金融机构的责任影响力，中国银行业协会（以下简称中银协）决定组织开展2012年度中国银行业社会责任工作评选活动（以下简称评选活动）。

**一、**评选活动的组织领导

（一）中银协是评选活动的领导机构，负责组织实施评选活动、制定评选方案、确定评选标准、组建评审委员会、审议评选名单等工作。中银协自律部负责活动的组织安排、联络协调和评比表彰等各项日常工作。

（二）根据《中国银行业社会责任工作联席会议制度》，联席会议主席单位、副主席单位负责协助中银协组织各会员单位参与年度银行业社会责任评选工作，并制订评比方案、规范标准等。

（三）各会员单位负责组织参与本次评选活动。具体职责为：及时提交评选活动书面文字材料及信息统计表；配合开展社会责任工作评选活动的检查复审；在系统内开展评选活动的交流总结，收集整理相关意见建议等。

**二、**评选条件及奖项设置

（一）申报条件

凡中国银行业协会会员单位均可在规定时限内、按相关要求及标准申报评选材料。逾期不报送材料的单位，视作自动放弃参评资格。

（二）奖项设置

评选将依据会员单位的规模属性、业务特色等设置奖项7类。奖项设置分为综合类奖项、单项奖及特殊贡献奖项。具体奖项分为年度最具社会责任金融机构奖、年度最佳公益慈善贡献奖、年度最佳民生金融奖、年度最佳绿色金融奖、年度最佳社会责任实践案例奖、年度社会责任引领人物奖、年度社会责任特殊贡献网点奖。

（三）评选标准

1. 年度最具社会责任金融机构奖将对银行业金融机构社会责任履行情况进行综合考量，根据数据初评、专家复审两环节的得分排名情况进行评选。拟划分“大型银行类”、“股份制和城市商业银行类”、“农村金融机构及其他类”三大类别进行奖项评选。

2. 年度最佳公益慈善贡献奖拟颁发给积极参与社会公益活动与慈善事业，并产生良好社会效果的银行业金融机构。主要参考金融机构的年度公益投入、志愿者参与人数、公益创新等指标得分情况进行评选。

3. 年度最佳民生金融奖拟颁发给在服务“三农”、“小微”企业，支持保障性住房建设和文化产业发展，以及助学助业等方面做出杰出贡献的银行业金融机构。主要参考服务“三农”、小微企业，支持保障性安居工程建设、个人创业助学贷款及奖学金投放等指标得分情况进行评选。

4. 年度最佳绿色金融奖拟颁发给致力于保护生态环境，贯彻绿色信贷政策，降低自身运营环境影响的银行业金融机构。主要参考绿色信贷发放、绿色运营办公、环保培训及环保公益等指标得分情况进行评选。

5. 年度最佳社会责任实践案例奖拟颁发给在社会责任创新实践方面进行探索和创新，并取得行业领先项目经验的银行业金融机构，由会员单位自行推荐案例，经专家组审议确定。

6. 年度社会责任引领人物奖拟颁发给致力于推进行业社会责任发展并做出卓越贡献的行级领导。该奖项候选人由会员单位自荐，经专家组审议确定。

7. 年度最佳社会责任特殊贡献网点奖拟颁发给对老少边区金融服务做出特殊贡献的银行网点，以表彰他们克服恶劣工作环境，潜心服务基层群众的突出表现。该奖项候选网点由会员单位自荐，经专家组审议确定。

**三、**评比活动主要步骤

（一）标准制定

2013年1月中上旬，由中银协，联席会议主席单位、副主席单位会同监管机构、科研院所、社会责任领域培训机构和组织参考《中国银监会办公厅关于加强银行业金融机构社会责任的通知》、《中国银行业金融机构企业社会责任指引》和国际有关金融机构社会责任的标准与指南起草系列工作方案及规则标准，并广泛征求会员单位意见。

（二）准备部署

2013年2月下旬，中银协正式印发《2012年度中国银行业社会责任工作评选活动方案》及相关标准，启动2012年度中国银行业社会责任工作评选活动。各会员单位根据方案要求，认真搜集整理年度履行社会责任的统计数据与典型事例，并确定评选工作联系人。

（三）材料申报

2013年3月下旬，各会员单位须按要求完成申报，做好数据真实承诺，将电子及纸质文本寄送至中银协自律部。

（四）数据初评

2013年4月中上旬，中银协组织社会责任专家组对会员单位申报的材料进行初步汇总、筛选，计算各参评机构的评比得分。

（五）专家复审

2013年4月下旬，中银协组织社会责任专家、新闻媒体代表及社会公众代表在初审基础上开展复审工作，依据《2012年度中国银行业社会责任评优评分体系》对进入复审的参评单位提供的数据及文字材料进行客观评分，由专家、媒体代表及社会公众代表集体决议，在初评得分的基础上进行修正。

（六）终评审议

2013年5月，综合数据初评及专家复审结果，最终审定2012年度中国银行业社会责任获奖单位名单。

（七）总结表彰

中银协通过网站、报刊等媒体向银行业内和社会进行公告，印发表彰决定，于2013年6月组织2012年度中国银行业社会责任工作评选表彰活动。在中银协网站建立社会责任栏目，设立社会责任优秀实践专题，介绍获奖机构的先进事迹。

**四、**评选活动相关要求

（一）请各会员单位采取切实有效的工作措施，积极组织参与2012年度中国银行业社会责任工作评选活动，并通过此次活动进一步提升责任意识，深化责任理念，树立银行业良好的社会形象。

（二）请各会员单位结合本方案总体要求和自身实际，加强组织领导，积极推进评选活动的有效展开，确保活动取得实效。中银协将通过业内通报等方式对各会员单位评选活动开展情况进行综合评价。
