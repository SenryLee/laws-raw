# 上海证券交易所关于对会员公司、证券营业部、交易席位实行归口管理的通知

## 上海证券交易所关于对会员公司、证券营业部、交易席位实行归口管理的通知（上证会（98）字第049号　1998年5月4日）

各会员单位：

为进一步改善对会员的服务，提高工作效率，加强对会员及所属营业部日常运行情况的了解与监管，本所决定自1998年5月4日起，对会员公司、证券营业部、交易席位实行归口管理。现将有关事项通知如下：

**一、**本所会员部对会员公司、证券营业部、交易席位（包括A、B股席位、债券专用席位、通信站席位、交易中心席位）的新增、更名、转让、注销等实行归口管理，负责代理会员在涉及上述业务的相关部门（含登记公司、通信公司）直接办理有关事宜。

**二、**会员公司根据公司、证券营业部、交易席位等不同业务情况向归口管理部门会员部提出办理有关事宜的申请，并提交与所办事宜相关的文件（详见附件），会员部按会员公司的不同申请，审查申请文件是否齐备、并负责对会员的申请在本所相关部门协调办理。

**三、**本所相关业务部门自1998年5月4日起，不再另行接受会员公司及所属营业部的有关申请。在办理上述业务流程中不另收取有关文件，会员部在相关部门办妥有关手续后，负责向申请单位发出相应批复。

**四、**为保证会员资料的完整和准确，会员部于每年6月底和12月底对会员公司、证券营业部、交易席位资料进行核查，具体检查通知届时另发。

附件：

会员办理有关业务须提交的文件清单

**一、**会员公司

1. 申请成功本所会员

申请表、申请报告、有权部门批复

许可证、工商执照、公司章程及规章制度

法人代表与证券业务负责人简历。

内部机构设置及下属证券营业部一览表。

经审计的最近两年的财务报告。

2. 会员更名

申请表、申请报告、有权部门批复

许可证、工商执照、公司章程及规章制度

法人代表与证券业务负责人简历。

内部机构设置及下属证券营业部一览表。

经审计的最近两年的财务报告。

营业部清算授权书。

更名确认书。

3. 会员注销

申请报告、有权部门批复、证券或业部转让清单。

登记公司关于该会员无欠款的确认意见。

**二、**证券营业部

1. 新设营业部

会员公司申请、有权部门批复、许可证、工商执照、清算授权书、结算确认书、备付金帐户申请书。

2. 营业部更名

会员公司申请、有权部门批复、许可证、工商执照、清算授权书、结算确认书、变更确认书。

3. 转让营业部

会员公司申请、有权部门批复、许可证、工商执照、转让合同、协议，受让方、清算授权书、结算确认书、备付金帐户申请书。

4. 注销营业部

会员申请、有权部门批复、登记公司关于该营业部无未了结债务的确认意见。

**三、**交易席位

1. 新增席位：会员公司申请、会员公司交易席位申请表、使用该席位营业部的文件：包括有权部门批复、许可证、工商执照、交易员注册表、席位连通（变更）申请表、清算授权书、结算确认书、备付金帐户申请书。

2. 席位更名：会员公司申请、会员公司交易席位（变更）申请表、使用该席位营业部的有关文件：包括有权部门批复、许可证、工商执照、交易员注册表、席位连通（变更）申请表。会员营业部席位变更登记表、清算授权书、结算确认书、债券结算席位变更申请书。

3. 转让席位：双方会员公司申请，会员公司交易席位（变更）申请表、使用该席位营业部的有关文件：包括有权部门批复、许可证、工商执照、转让合同协议。交易员注册表、席位连通（变更）申请表。会员营业部席位变更登记表、清算授权书、结算确认书、债券结算席位变更申请书。

4. 注销席位：会员公司申请、会员公司交易席位（变更）申请表、有权部门批准该公司撤销批复、交易员注册表、席位连通（变更）申请表。会员营业部席位变更登记表。清算部关于该席位无欠库、无未到期回购业务的确认意见。
