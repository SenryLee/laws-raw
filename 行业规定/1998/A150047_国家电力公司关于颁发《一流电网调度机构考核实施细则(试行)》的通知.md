# 国家电力公司关于颁发《一流电网调度机构考核实施细则(试行)》的通知

## 国家电力公司关于颁发《一流电网调度机构考核实施细则（试行）》的通知（1998年4月22日　安运管[1998]28号）

为推动电网调度机构创一流工作顺利进行，使创一流工作的实施、考核及验收规范化，根据电力部颁发的《一流电网调度机构考核办法（试行）》，我部与国调中心制订了《一流电网调度机构考核实施细则（试行）》。现予颁布，自即日起试行。

本“细则”适用于网、省调度机构创一流的实施、考核及验收。

附件：《一流电网调度机构考核实施细则（试行）》

一流电网调度机构考核实施细则（试行）

**1总则**　1.1为使网、省电网调度机构创一流活动的实施、考核及验收工作科学化、规范化，确保创一流工作质量，特制订“一流电网调度机构考核实施细则”（以下简称细则）。

1.2本细则编制以部颁“一流电网调度机构考核办法”（以下简称办法）为主要依据，同时参考了国家电力公司颁发的“中国一流管理的电力公司考核标准（试行）”及发供电企业的创一流标准，结合我国调度机构现状及发展趋势，对办法中的必备条件进行了必要的补充、完善和进一步说明，对五项考核内容及评分规定进行了调整、补充和细化，明确了考核要求、验收程序和检查内容。

1.3本“细则”适用于网、省调度机构创一流的实施、考核及验收工作。原办法与细则不一致之处，以细则为准。

**2**一流电网调度机构的考核内容和标准

2.1考核内容

按安全工作、文明生产、设备运行、专业管理、技术进步五项内容进行考核，每项满分100分。

2.2标准

一流电网调度机构必须同时满足以下三个条件：

2.2.1必须是连续2年达标后的电网调度机构；

2.2.2必须具备第4款所列12项必备条件；

2.2.3五项考核内容每项得分均在90分及以上（考核内容见附件1）。

**3**一流电网调度机构的申报、考核与验收

3.1申报一流调度机构，必须是连续2年达标，再经过一流调度机构标准考核（一个完整日历年），自查合格。

3.2验收申请包括如下内容：

3.2.1验收申请报告；

3.2.2《一流电网调度机构申报（复核）表》（见附件2）；

3.2.3自查报告；

3.2.4主要考核指标完成情况的说明（包括计算方法）；

3.2.5其他必要的证明材料。

3.3验收申请报所属网（省）公司，网（省）公司组织考核后于4月底前报国家电力公司，由国家电力公司组织验收。

3.4一流电网调度机构的验收及命名工作每年进行一次。对已命名的一流电网调度机构的奖励由主管网（省）公司按有关规定执行。

3.5考核、验收工作要严肃认真、坚持标准、实事求是、客观公正。

3.6一流电网调度机构实行动态考核，定期复查。发现问题要及时研究，限期整改，仍达不到标准的，撤销一流电网调度机构称号。定期复查每年进行一次，由国家电力公司组织。

**4必备条**件的考评验收

4.1领导班子建设

领导班子坚持党的基本路线，坚持民主集中制原则，改革开拓，团结进取，廉政勤政，工作业绩显著。

4.1.1有领导班子成员年度工作考评制度并认真执行；

4.1.2坚持中心组学习制度，保证学习时间和学习质量；

4.1.3领导班子民主生活会制度化；

4.1.4认真执行中纪委关于领导干部廉洁自律的各项规定，连续3年领导班子成员无违法违纪事件；

4.1.5领导班子结构合理，有后备干部培养、管理和考核的计划及措施。

4.2精神文明和职工队伍建设

坚持两个文明一起抓，两手都要硬；坚持和改进思想政治工作，全面提高职工队伍整体素质。大力开展企业文化建设，造就一支有理想、有道德、有文化、有纪律、有强烈的社会责任感与主人翁意识的职工队伍；具有良好的社会形象。连续多次被评为省公司级及以上文明单位。

4.2.1有精神文明建设规划、年度工作计划及考核办法；

4.2.2认真开展思想政治工作，积极开展建设职工之家等项活动；

4.2.3发挥党支部的战斗堡垒作用和党员的先锋模范作用，开展创建双文明及评先创优活动；

4.2.4近期获得国家电力公司颁发的文明单位证书；

4.2.5考核年度本单位未发生造成重大社会影响的恶性事件。

4.3依法调度

认真贯彻执行《电力法》和《电网调度管理条例》。依法调度，坚持统一调度，分级管理的原则。服从上级调度指挥，不发生误调度和违反调度纪律的事件。

4.3.1在调度业务活动中无违法违纪行为，不发生违反调度纪律的事件；

4.3.2对所辖调度对象发生违反《条例》的事件立即制止，严肃处理，无姑息纵容的情况；

4.3.3本单位所制定的一切有关电网调度的规程、规定，均不与《条例》及其配套文件相抵触；

4.3.4按上级有关规定实行系统值班人员培训、考核、持证上岗制度；

4.3.5加强并网调度协议管理工作，与调度范围内的所有并网电厂签订调度协议，建立专门档案，并严格履行；

4.3.6有执行“三公”的具体措施和制度。

4.4现代化管理

加大现代化管理力度.现代化管理有显著进步并取得了明显效益，建成管理信息系统并达到实用。建立和完善企业标准化体系，颁发并执行了技术标准、管理标准和工作标准。

4.4.1有推广现代化管理的规划和计划，坚持实施并取得实效；

4.4.2建成包括办公自动化、档案资料、人事劳资、财务物资、调度生产及工程管理子系统的管理信息系统并达到实用，在企业管理各个领域发挥作用。

4.4.3按标准化工作有关规定开展工作，建立包括技术标准、管理标准和工作标准的三大标准体系，并颁布实施；

4.4.4建立并实施了量化管理考核制度，量化考核可操作性强。

4.5安全生产

保证电网安全稳定运行。考核年度内不发生本单位责任的主网稳定破坏、大面积停电事故；不发生本单位调度责任事故和生产责任事故；不发生生产人身伤亡事故；不发生本单位所属生产用建筑物的火灾事故；

4.5.1事故按《电业生产办故调查规程》有关条款进行统计考核；

4.5.2事故以相应的安监部门的认定为准。

4.6电网频率

保证电网频率合格，年责任频率合格率连续两年（含考核年）≥99.9%。

4.6.1频率允许偏差范围为±0.2Hz；频率统计采样周期为1秒。

4.6.2责任频率合格的计算

参照能源电（1990）389号文《关于颁发电力行业国家级标准（试行）的通知》中第九部分《电力调度国家级企业等级际准》中的规定执行，即：

年责任频率合格率K＝（年日历时间一年累计责任频率不合格时间）/年日历时间]×100%

4.6.3考核标准

4.6.3.1独立省网电网调度机构年责任频率合格率k≥99.9%

4.6.3.2跨省电网（含南方互联电网）中网调和各省（市、区）调度机构年责任频率合格率大于等于按全网年频率合格率考核标准分解到各网、省（市、区）调的目标值ki。ki＝[1-r（1-99.9%）]×100%

注：r为统调电力系数，计算公式为：

r＝网调、省（市、区）调统电力/全网统调电力

ki值由网局根据本网情况计算确定后下达，并报国调中心备案。

4.7电网电压

保证电网运行电压合格。调度范围内电网电压监测点年电压合格率≥99%。

4.7.1电压质量以电压监测点（即调度范围内全部220kv及以上母线电压）电压数据为依据。以不少于全部电压监测点80%的考核点、EMS采集的数据进行统计考核。考核点选择应能反映调度范围电网电压质量状况，并报上级调度部门认可。

4.7.2电网无功补偿度应满足有关规程要求。

4.7.3电压合格率的计算电压合格率的计算公式如下：

考核点日（月、年）电压合格率＝〔考核点日（月、年）累计电压合格时间/考核点日（月、年）累计运行时间〕×100%

全网电压合格率＝（∑考核点年电压合格率/考核点总数）×100%

4.7.4电压质量考核标准

4.7.4.1500（330）kv变电站500kv母线电压允许电压偏差为额定电压的0-10%。根据电网状况，个别母线电压允许偏差也可选择为额定电压的-3-5%；

4.7.4.2发电厂的500kv母线、发电厂和500（330）kv变电站的220kv母线电压允许电压偏差为额定的0-10%；

4.7.4.3220kv变电站220kv母线电压允许偏差范围内额定电压的-3-7%。根据电网状况，个别母线电压允许偏差也可选择为额定电压的±5%，但须经上级调度部门批准；

4.7.4.4考核点电压在允许偏差范围内每日偏差幅度不大于额定电压的5%。

4.7.4.5采样周期不大于1小时，用EMS数据编制软件自动完成电压合格率统计计算。

4.8网损管理

努力减小网损，考核年度网损率不高于前2年的平均值；保持网损降低系数≥0.008或考核年度网损率≤2.5%。

4.8.1网损是指所调度的输电网产生的损耗。以输电网关口电能计量装置的计量值，按照“进出网法进行统计和计算”。

网损率＝〔（输入电量一输出电量）/输入电量〕×100%

输入电量是发电厂上网电量、邻网输入电量和其他各类上网电量之和。

4.8.2各网、省局应按所调度电网范围设置关口电能计量装置。网损计量和统计以关口电能计量装置的数值为准。对发电厂上网电量要按照“关于明确发电厂供电量计量点的通知”（安生技[1996]94号文）的规定进行计量，跨省电网间和省间联络线的网损计量按现行有关协议和规定执行。

4.8.3当由于多发水电和新增远距离电源点等原因引起网损增加，可考虑对网损考核基准值（×）进行修正，但须报送详细计算报告，由上级主管部门核定。

4.9继电保护

保证电网继电保护和安全自动装置正确动作，220kv及以上电网继电保护正确动作率≥97.5%。

4.9.1继电保护年正确动作率＝（年正确动作次数/年动作总次数）×100%；

4.9.2220kv及以上电网继电保护装置：指100MW及以上发电机，50MVAR及以上调相机，电压为220kv及以上变压器、电抗器、电容器、母线和线路（含电缆）的保护装置，自动重合闸，备用设备及备用电源自动投入装置。

4.10电网调度自动化

调度自动化系统（EMS）SCADA/AGC通过实用化验收，并连续保持2年以上；EMS运行稳定；所辖地调度自动化系统100%通过实用化验收和复查。

4.10.1电网调度自动化系统（SCADA/AGC功能）实用化经上级主管部门复查（不超过2年）；考核年内每个月的各项指标均达到实用化要求。

4.10.2定期组织对所辖地区电网调度自动化实用化复查（复查周期≤3年）。

4.10.3AGC要求：调度范围内AGC机组可调容量占统调装机容量的8%；AGC功能年投运率≥70%，AGC控制年合格率≥99%。

4.10.4AGC功能说明：

4.10.4.1功能要求：

a.维持系统频率在规定值。

b.维持互联系统联络线净交换功率在规定值（按各网确定的值考核）。

4.10.4.2技术要求

a.对装机容量为300万千瓦以上的系统维持频率为50±0.1Hz（频率偏差≤0.Hz）；

b.在电力系统正常运行时，每10分钟内AGC应使系统区域控制偏差至少过零一次；.

c.在电力系统负荷发生波动后1分钟内，AGC应使区域控制偏差向减小方向变化。

4.10.4.3AGC年投运率＝（∑agc功能投运小时数/全年日历小时数）×100%。

∑AGC功能投运小时数：是指系统AGC功能投入，同时有50%以上的系统可调容量投入运行的时间。

AGC控制年合格率＝〔（全年AGC功能投运小时数-AGC不合格小时数）/全年AGC功能投运小时数〕×100%。

AGC不合格小时数：是指AGC功能投入时，连续超过技术要求中的规定值1分钟的累计时间。

4.10.4.4资料要求：有完整的AGC投运记录，包括参加AGC的机组（电厂）每天投入AGC控制的时间记录，主站端AGC功能的投运时间记录，以及相应AGC偏差变化曲线（每分钟1点）。

4.11电力通信

加快通信建设步伐，数字微波（光纤）通信电路覆盖率100%；

具备所辖通信网主干电路运行监视手段；调度系统通信站全部达标；不发生通信事故和障碍。

4.11.1数字微波（或光纤）覆盖全部所属地区电业局和主力发电厂；

4.11.2具备所辖通信网主干电路运行监视手段；

4.11.3按规划组建二级（或三级）数据传输网络。

4.11.4调度端逋信站连续2年不发生通信萝故和障碍；所辖通信系统连续2年无通信事故。

4.11.5所辖通信系统的通信站100%达标，并复查合格（复查周期为≤3年）。

4.12电力市场与商业化运营

开展了电力市场与商业化运营工作，建立了电能量自动计算系统并投入了实际运行。

4.12.1建立了电网电能量自动计量系统，该计量结果得到计量部门认可；

4.12.2在本公司的统一部署下开展了电力市场与商业化运营工作；

4.12.3开展了短期和超短期负荷预测工作。

**5**五项考核内容考评验收

考核内容及评分规定见附件1。

**6其他**　6.1申报单位应提供必备条件及考核指标等的有关资料、文件、记录及计算公式、结果等，以备验收时查阅。

6.2本细则由国家电力公司主管部门制订并负责解释。

注1：网损降低系数κ值按下式计算

```
K=（EX-100Y）/EX2
```

式中：Y--考核年度本调度机构完成的网损率；

X--网损率考核基准值；

E--电量增长修正系数

```
X=[(Ymin+4Ymax)/6]×100%

E=(0.3/a)+0.7a
```

Ymin、Ymid、Ymax分别为考核年前三年中本调度机构实际完成网损的小值、中值、大值（前三年中有两个值相同，则将相同Y值中的一个视为中间值代入）。

电量增长系数α＝考核年度输送电量/上年度输送电量

注：a超过1.10者，按1.10计算；
