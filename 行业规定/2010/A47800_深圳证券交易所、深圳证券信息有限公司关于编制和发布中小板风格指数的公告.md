# 深圳证券交易所、深圳证券信息有限公司关于编制和发布中小板风格指数的公告

为了更全面的反映中小板市场情况，向市场各类投资者提供更多的跟踪投资目标指数，推进指数基金产品以及丰富证券市场产品品种，深圳证券交易所决定于2010年5月24日起正式编制和发布中小板风格系列指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399602 | 中小300成长P | SME成长P | 2010年3月19日 | 1000 |
| 399603 | 中小300成长R | SME成长R | 2010年3月19日 | 1000 |
| 399604 | 中小300价值P | SME价值P | 2010年3月19日 | 1000 |
| 399605 | 中小300价值R | SME价值R | 2010年3月19日 | 1000 |

为了方便投资者参考，本次同步发布收益指数及价格指数，其中价格指数对样本股公司派息不作除权调整处理，任指数自然回落。

特此公告。
