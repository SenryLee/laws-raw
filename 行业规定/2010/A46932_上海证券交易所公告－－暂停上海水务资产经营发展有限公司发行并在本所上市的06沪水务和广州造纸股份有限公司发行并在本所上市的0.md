# 上海证券交易所公告－－暂停上海水务资产经营发展有限公司发行并在本所上市的06沪水务和广州造纸股份有限公司发行并在本所上市的08广纸债公告

## 上海证券交易所公告

上海水务资产经营发展有限公司和广州造纸股份有限公司2008年、2009年连续两年亏损，根据《中华人民共和国证券法》、《上海证券交易所公司债券上市规则》的有关规定，本所决定自2010年6月10日起暂停上海水务资产经营发展有限公司发行并在本所上市的06沪水务（证券代码120607）和广州造纸股份有限公司发行并在本所上市的08广纸债（证券代码122999）上市交易并不再接受质押券入库申报。

特此公告。

上海证券交易所　

二○一○年六月十日
