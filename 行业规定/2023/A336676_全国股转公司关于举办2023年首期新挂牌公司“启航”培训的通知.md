# 全国股转公司关于举办2023年首期新挂牌公司“启航”培训的通知

## 关于举办2023年首期新挂牌公司“启航”培训的通知

各市场主体：

为强化挂牌公司关键主体的规范意识，严格遵守证券市场监管要求，助力公司向公众公司转变，全国股转公司拟于6月19日-20日采用现场培训+线上直播的形式面向新挂牌公司举办2023年首期新挂牌公司“启航”培训。课程设计关注业务实操，培训内容主要涵盖公司治理、信息披露、合规交易、分层管理办法解读、股权激励等。具体安排如下：

**一、**参会人员

2022年7月15日至今新挂牌公司的实际控制人、董事长、总经理、董事会秘书或相关负责人。

**二、**培训形式及地点

本次培训采用现场培训+线上直播的形式，现场培训于北京市开展，每家单位限报2人，现场培训规模不超过80人，名额有限，先到先得。线上直播通过腾讯会议开展，规模不超过2000人。

**三、**培训安排

|  |  |  |
| --- | --- | --- |
| 时间 | | 内容 |
| 6月19日 | 9:00-9:20 | 开班仪式 |
| 9:20-10:30 | 治理规则解读及典型案例分析 |
| 10:30-11:40 | 信息披露规则解读及案例分析 |
| 14:00-15:00 | 挂牌公司日常业务办理 |
| 15:00-16:00 | 合规交易解读及案例分析 |
| 16:00-17:00 | 《分层管理办法》解读及进层注意事项 |
| 6月20日 | 9:00-10:00 | 股权激励规则讲解 |
| 10:00-11:30 | 股权激励方案设计实务 |

**四、**报名方式及截止时间

本次培训需收集报名信息，请您按照培训形式点击报名链接进行报名，报名截止时间为6月16日16:00。我们将在审核后将培训具体地点及腾讯会议直播码在会议前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

因培训名额有限，请您报名后准时参加，如无法参加请及时联系工作人员取消报名。培训报名成功后如未参与可能会影响后续培训资格。
