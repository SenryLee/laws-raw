# 全国中小企业股份转让系统有限责任公司关于举办第二十七期“全国股转系统大讲堂”——财务规范专题培训（新一代信息技术专场）的通知

## 关于举办第二十七期“全国股转系统大讲堂”——财务规范专题培训（新一代信息技术专场）的通知

为支持中小企业高质量发展，增强企业规范发展内生动力，提升企业“关键少数”的资本运营能力，拓宽运用资本市场创新发展的视野，全国股转公司拟按行业领域分期举办 “全国股转系统大讲堂”——财务规范专题培训，本期培训将于2023年3月27日在北京金融街举办，聚焦新一代信息技术领域。培训具体安排如下：

**一、**参会人员

新一代信息技术领域挂牌公司董事长、总经理、实际控制人、财务负责人、董事会秘书和相关业务人员，其他感兴趣的市场主体。

**二、**培训安排

|  |  |  |
| --- | --- | --- |
| 时间 | | 课程 |
| 3月27日  （周一） | 14:00-15:00 | 二级市场如何看待信息技术行业 |
| 15:00-16:00 | 企业上市财务准备重点关注事项 |
| 16:00-17:00 | 全面注册制下信息披露与会计准则实务运用重难点 |

备注:最终课表以实际课程安排为准。

**三、**培训形式

本期为现场培训，每家单位限报1-2人，现场活动名额有限，先到先得，额满为止。

**四、**报名方式及截止时间

本期培训采用问卷星收集报名信息。请您扫描下方二维码或者点击报名链接进行报名，报名截止时间为3月24日16:00。我们将在审核后将培训具体地点在会议前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

因现场培训名额有限，请您报名后准时参加，如无法参加请及时联系工作人员取消报名。现场培训报名成功后如未能参与可能会影响后续培训资格。
