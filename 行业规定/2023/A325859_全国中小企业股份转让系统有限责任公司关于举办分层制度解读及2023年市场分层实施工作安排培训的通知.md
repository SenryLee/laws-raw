# 全国中小企业股份转让系统有限责任公司关于举办分层制度解读及2023年市场分层实施工作安排培训的通知

## 关于举办分层制度解读及2023年市场分层实施工作安排培训的通知

为帮助挂牌公司及主办券商理解分层制度内容，了解2023年市场分层实施工作安排及注意事项，推动做好市场分层准备工作，全国股转公司拟于1月16日至9月30日举办分层制度解读及2023年市场分层实施工作安排视频培训。培训具体安排如下：

**一、**参会人员

挂牌公司董事长、总经理、董事会秘书或信息披露负责人；证券公司持续督导人员、保荐代表人或相关业务人员。

**二、**培训安排

|  |  |
| --- | --- |
| 时间 | 课程 |
| 1月16日-9月30日 | 分层制度解读及2023年市场分层实施工作安排 |

**三、**培训形式

本次培训为线上录播培训，参会人员可在全国股转公司官网“服务专区-培训园地”栏目（http://www.neeq.com.cn/investor_guide/train_area.html）在线学习相关课程，所有课程可24小时观看。

**四、**问题收集

如有与培训内容相关的问题，可扫描下方二维码填写问卷，培训过程中，工作人员将及时答复相关问题。
