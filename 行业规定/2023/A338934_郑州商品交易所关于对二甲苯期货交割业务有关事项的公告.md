# 郑州商品交易所关于对二甲苯期货交割业务有关事项的公告

## 郑州商品交易所公告

〔2023〕94号

## 关于对二甲苯期货交割业务有关事项的公告

经研究决定，现将指定对二甲苯期货质检机构和交割费用标准事项公告如下。

**一、**指定质检机构2家

通标标准技术服务有限公司和中国检验认证集团检验有限公司。

**二、**交割相关费用标准

（一）标准仓单仓储费标准

指定对二甲苯交割仓（厂）库收取仓储费标准为3元/吨·天。

（二）交割仓库出入库费标准

入库费12.5元/吨，出库费12.5元/吨，出入库费均由入库方支付。

（三）质检项目及收费标准

对二甲苯指定质检机构检验费用

|  |  |  |
| --- | --- | --- |
| 1.对二甲苯取样费用 | | |
| 1200元/船；700元/罐。 | | |
| 2.对二甲苯重量检验费用 | | |
| 0.4元/吨（岸罐鉴定，最低费用为1000元）；  0.6元/吨（船舱鉴定，含卸货后空仓鉴定，最低费用为1500元）。 | | |
| 3.对二甲苯品质检验费用 | | |
|  | 项目 | 费用（元/样） |
| 1 | 外观 | 50 |
| 2 | 纯度，%（质量分数） | 首项费用320。后续每增加一项费用增加160。全套800。 |
| 3 | 非芳烃含量，%（质量分数） |
| 4 | 甲苯含量，%（质量分数） |
| 5 | 乙苯含量，%（质量分数） |
| 6 | 间二甲苯含量，%（质量分数） |
| 7 | 邻二甲苯含量，%（质量分数） |
| 8 | 总硫含量，mg/kg | 600 |
| 9 | 颜色（铂-钴色号），号 | 150 |
| 10 | 酸洗比色 | 300 |
| 11 | 溴指数，mgBr/100g | 300 |

| 13 | 氯离子浓度，mg/kg | 600 |
| 备注：分项目检验的，按单项标价收费；1-13项指标全检的，费用为2400元/样。 | | |

通标标准技术服务有限公司差旅费标准为0元。中国检验认证集团检验有限公司差旅费标准为大连主港7000元,其余主港为0元，含一次差旅往返交通费、住宿费。差旅费标准可根据市场情况进行调整。

以上对二甲苯期货交割业务相关事项自2024年3月1日起实施。
