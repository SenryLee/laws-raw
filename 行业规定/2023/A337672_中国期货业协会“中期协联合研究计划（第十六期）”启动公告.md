# 中国期货业协会“中期协联合研究计划（第十六期）”启动公告

## “中期协联合研究计划（第十六期）” 启动公告

为全面深入贯彻落实党的二十大精神，以习近平新时代中国特色社会主义思想为指导，履行好《期货和衍生品法》赋予的“组织会员就期货行业的发展、运作及有关内容进行研究”的职责，联合行业和社会研究力量，助力中国特色现代期货市场建设和行业高质量发展，更好服务实体经济与国家发展战略，我协会即日启动“中期协联合研究计划（第十六期）”课题申报工作。现将有关事项说明如下：

**一、**研究方向和选题范围

本期联合研究计划以“建设中国特色现代期货市场，推动期货行业高质量发展”为主题，以引导包括期货公司在内的研究机构开展“立足我国实体特色和产业优势，促进中国特色现代期货市场建设与功能发挥”及“《期货和衍生品法》颁布后期货交易所和经营机构创新发展”研究为主要导向。申报单位可在下列拟定参考范围内选择选题进行申报，也可自行拟定与研究主题相关的其他题目进行申报。

|  |  |
| --- | --- |
| **研究方向** | **选题范围** |
| **（一）市场建设** | **建设中国特色现代期货市场研究**（包括但不仅限于：中国特色现代期货品种体系、交易制度、监管体系、交易者结构、高水平制度型对外开放研究，中国特色期货市场发展特点及经验总结研究等）；**场外市场定位与特色发展研究；中国特色商品指数体系建设与完善研究；期货价格相关理论研究**（包括但不仅限于：中国特色期货市场定价机制研究、宏观因素对期货价格影响研究、期货市场价格影响力研究、期现价格波动关系研究、期货合约期限结构影响因素研究等）；**期货市场功能研究**（包括但不仅限于：资源配置功能理论及实践研究、公募基金利用金融衍生品实证研究等）；**推动提升产业客户参与度研究**。 |
| **（二）服务实体** | **基于我国实体经济特色和产业优势，期货行业服务路径及效果研究**；**期货行业服务国家战略研究**（包括但不仅限于：服务稳产保供、乡村振兴、统一大市场建设、碳达峰碳中和、区域协调发展、绿色发展等研究）；**期货行业服务不同主体研究**（包括但不仅限于：服务中小微企业、产业链供应链重要参与者、新型农户、上市公司、国有企业等）；**期货市场服务实体经济路径及业务模式研究**（包括但不仅限于：“保险+期货”常态化机制化研究、含权贸易业务模式优化研究、场外衍生品业务创新研究等）；**期货市场服务实体经济评价体系及效果评估研究；发挥场外衍生品功能，服务实体经济问题研究**。 |
| **（三）公司发展** | **新形势下期货公司业务定位、发展战略与规划研究；加强期货公司基础功能建设，提升期货经营机构的专业能力、中介能力、服务能力研究；期货行业差异化特色化发展研究；期货公司双向开放研究；扩宽融资渠道，提升期货公司资本实力研究；新规则下期货公司业务调整与转型问题研究**（包括但不仅限于：期货公司与风险管理子公司、境外子公司协同发展研究，业务重构背景下风险管理公司定位和发展方向研究等）；**期货经营机构各类业务创新发展研究**（包括但不仅限于：境内经纪、交易咨询等传统业务创新发展研究，资产管理、衍生品交易、期货做市交易、期货保证金融资、期货自营、境外期货经纪等业务创新发展研究等）；**中国特色期货公司内部控制体系研究**（包括但不仅限于：期货公司风险监测、预警与处置机制研究，期货公司业务风险隔离和协同研究，期货公司仓单风险控制研究等）；**提升期货公司发展软实力研究**（包括但不仅限于：期货公司文化建设研究、党建业务融合发展研究、人才队伍建设研究、研究能力建设研究等）；**提升期货公司服务产业客户效果研究；期货公司涉外业务问题研究**（包括但不仅限于：外汇额度管理研究、跨境监管研究、涉外保证金监控研究等）；**期货公司层面场外市场规范问题研究。** |
| **（四）金融科技** | 期货市场监管数字化智能化发展研究；期货市场数字基础设施完善研究；金融科技（大数据、云计算、区块链、人工智能等）推动期货业务科技化智能化发展研究；期货公司信息技术支持和风控体系研究；期货公司智能风险管理平台建设研究；金融科技在财富管理智能投研/智能投顾领域的应用研究。 |
| **（五）监管自律** | 中国特色期货行业监管和自律管理研究；期货公司风险监管指标体系研究；现货背景贸易商等重要参与主体自律管理研究；推动期货行业业务创新与稳健发展研究；《期货与衍生品法》配套自律管理规则与制度体系完善研究；衍生品业务风险防控与规范发展问题研究。 |

**二、**实施流程和管理模式

本期研究计划实行“自主申报-课题评审-名单公示-证书发放”的课题管理模式，面向全社会，鼓励业内机构、高校、科研院所、实体企业等机构或单位就我国期货及衍生品市场创新、行业发展的重要理论与实践问题，围绕本公告发布的研究主题导向和选题范围进行课题申报、研究开展、成果提交。协会将遵循公开、公平、公正的基本原则，按照评审程序和评审标准，确定获得优秀、良好的课题，并将评审结果记入协会文化建设实施评估。

**三、**申报条件

1.课题申请人应当是协会会员，或其它金融机构、高校、科研院所、实体企业等机构或单位，可单独申报或联合申报，协会鼓励会员单位联合专业科研院所等单位共同开展研究，优势互补。

2.申请人课题组主要研究人员应当具有从事相关研究或实务工作的经历和较强的科研能力，且有充足的时间从事课题研究工作。课题申请人须指定课题负责人，且课题负责人未因学术不端或科研经费使用不当等受过任何处罚。

3.课题申请单位承担的往期联合研究计划课题须已全部结项。已获得其他研究项目资助的成果不得申请本计划。

4.申请参与本计划须首先完成意向申报环节，未申报课题不能进入后续评审流程。

**四、**意向申报方式（2023年8月20日前）

1.材料准备：

（1）单位统一社会信用代码

（2）《中期协联合研究计划申报书》word版和PDF版（PDF版申报书请务必加盖单位公章，否则申报无效）

2.申报方式。课题申请单位可于2023年8月20日前登录中国期货业协会研究管理系统（网址：http://yanjiu.cfachina.org/）进行在线申报，其他申报途径无效。

**五、**研究时间与成果提交（2023年12月22日前）

1.研究时间。课题申报成功后，请开始自主研究并按照《研究成果编写要求》撰写成果报告。

2.成果提交。请认真填写《中期协联合研究计划参评申请书》，并于2023年12月22日前，将《参评申请书》和课题最终报告（3-5万字为宜）的Word版和PDF版按照系统要求上传。参评申请书PDF版请务必加盖单位公章，否则申请无效。

3.提交要求。为保证专家评审客观、公正，课题评审将采取专家盲评方式，请在课题最终报告（包括word 版和PDF版）中隐去课题撰写单位所有信息，课题组信息请在《参评申请书》集中体现（课题最终报告的Word版和PDF不需要盖公章）。

**六、**课题评审及奖励情况

1.课题评审。协会聘请行业专家、学者组成专家评审委员会，严格按照《中期协联合研究计划课题管理办法》规定的评审流程和标准，对报送课题进行评审。评审程序分为形式审查、查重检测（不超过30%）、专家评审，根据成果价值、完备程度、难易程度、创新程度、文责情况等评审指标，评定参评课题的等级（优秀、良好、通过）并在协会官网予以公示。

2.奖励情况。由专家评出的优秀、良好课题记入协会文化建设实施评估，并向优秀、良好、通过的课题组颁发结题证书。课题报告将编纂成课题集进行宣传。

**七、**成果管理与推广

1.成果管理。协会对本计划课题进行持续性管理，如发现课题负责单位存在弄虚作假、抄袭剽窃等学术不端行为，协会有权撤销本计划结题证书。给协会造成名誉损害的，协会有权追究其法律责任并要求赔偿。涉及上述行为的课题负责单位、课题负责人和主要研究人员列入协会课题研究禁入名单，三年内不得参加协会组织的各类课题研究活动。

2.成果推广。联合研究计划课题成果著作权由协会和课题负责单位共有，课题负责单位和个人享有署名权。课题负责单位和个人在正式发表、出版相关成果或向有关领导、决策部门报送时，须在醒目位置注明“第XX期中期协联合研究计划课题”，并及时书面告知协会。

课题负责单位应采取各种积极措施加强对课题研究成果的宣传、推广和转化，充分发挥其在市场建设、行业发展、监管自律中的作用，以扩大本计划的社会影响力。
