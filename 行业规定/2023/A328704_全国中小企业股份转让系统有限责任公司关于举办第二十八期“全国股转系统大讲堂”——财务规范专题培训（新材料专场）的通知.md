# 全国中小企业股份转让系统有限责任公司关于举办第二十八期“全国股转系统大讲堂”——财务规范专题培训（新材料专场）的通知

## 关于举办第二十八期“全国股转系统大讲堂”——财务规范专题培训（新材料专场）的通知

为支持中小企业高质量发展，增强企业规范发展内生动力，提升企业“关键少数”的资本运营能力，拓宽运用资本市场创新发展的视野，全国股转公司拟按行业领域分期举办 “全国股转系统大讲堂”——财务规范专题培训，本期培训将于2023年5月19日举办，聚焦新材料领域。培训具体安排如下：

**一、**参会人员

新材料领域挂牌公司董事长、总经理、实际控制人、财务负责人、董事会秘书和相关业务人员，其他感兴趣的市场主体。

**二、**培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| 时间 | | 课程名称 | 授课嘉宾 |
| 5月19日  （周五） | 14:00-15:30 | 新材料行业概况及投资逻辑 | 申万宏源行业研究  首席分析师 |
| 15:30-17:00 | 新材料行业财务规范重难点分析 | 天职国际会计师事务所  合伙人 |

备注:最终课表以实际课程安排为准。

**三、**培训形式

本期培训采用“腾讯会议”线上直播讲解的模式，参会人员可通过会议码参加培训。会议码将于培训前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。
