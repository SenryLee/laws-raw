# 郑州商品交易所关于推进柜台系统升级的通知

## 关于推进柜台系统升级的通知

郑商函〔2023〕84号

各会员单位，各行情转发单位：

为做好六期交易系统的上线准备工作，郑州商品交易所对交易接口程序ZCEAPI接口规范进行了适应性调整（具体见《郑商所期货交易数据交换接口规范V3.9》）。根据六期交易系统上线前工作安排，请各单位联系软件开发商获取适配六期版本柜台系统，并于规定截止日期前升级完毕。现将有关事项通知如下。

**一、**接口主要变化情况

（一）前置端口分离

柜台系统应支持主中心、灾备中心独立配置对话流、私有流、广播流的地址和端口。

（二）精简对话流查询接口

保留6个对话流查询接口，并增加了使用限制，其他对话流查询接口待六期交易系统上线后不再支持。

|  |  |  |
| --- | --- | --- |
| 序号 | 保留的查询接口 | 使用限制 |
| 1 | 市场交易状态查询请求（PID）：0x0000D | 每个连接只可查询一次 |
| 2 | 合约查询请求（PID）：0x00005 | 只支持查询全部合约，每个连接只可查询一次 |
| 3 | 品种交易状态查询请求（PID）：0x0000E | 只支持查询全部品种，每个连接只可查询一次 |
| 4 | 组合合约查询请求（PID）：0x03015 | 只支持查询全部组合合约，每个连接只可查询一次 |
| 5 | 会员资金查询请求（PID）：0x00008 | 每个连接每秒只可查询一次 |
| 6 | 成交行情查询请求（PID）：0x00002 | 只支持查询全部合约，每个连接只可查询一次 |

**二、**升级时间要求

（一）新申请席位要求

2023年4月1日起，所有新申请席位必须使用适配六期版本柜台系统。

（二）现有席位要求

2023年7月1日前，各单位应结合自身实际情况，合理安排升级计划，将现有生产席位使用柜台系统升级完毕。

**三、**联系方式

联系电话：0371-65610536、65610671

特此通知。

郑州商品交易所
