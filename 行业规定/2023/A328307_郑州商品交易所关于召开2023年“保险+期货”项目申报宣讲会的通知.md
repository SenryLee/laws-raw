# 郑州商品交易所关于召开2023年“保险+期货”项目申报宣讲会的通知

## 关于召开2023年“保险+期货”项目申报宣讲会的通知

郑商函〔2023〕278号

各会员单位，保险公司，相关机构：

2023年4月21日，郑州商品交易所（以下简称郑商所）发布了《关于开展2023年“保险+期货”试点工作的通知》，为进一步明确试点建设工作思路和相关要求，解答各单位在项目申报过程中的疑问，帮助项目申报单位充分理解申报要求与“农险无忧”建设主题，郑商所将举办项目申报宣讲会，请有意向申报项目的各单位相关人员参加。具体通知如下：

**一、**会议议程

时间：2023年5月5日14:00-15:30

主题：2023年“保险+期货”项目申报宣讲会

|  |  |  |
| --- | --- | --- |
| 时间 | 内容 | 宣讲人 |
| 14:00-14:30 | 郑商所2023年“保险+期货”  试点项目申报讲解 | 郑商所商品二部  西艾力 |
| 14:30-15:30 | 项目申报交流答疑 | 郑商所商品二部胥敬华、边远、西艾力 |

**二、**参会方式

本次宣讲会采取线上腾讯会议的方式举办，参加线上会议方式如下：

方式一：通过PC端浏览器方式，点击如下链接：https://meeting.tencent.com/dm/s6nO4ByHfJmf，直接参会。

方式二：通过PC端或手机端腾讯会议APP，输入会议ID：106-365-894，直接参会。

各项目申报单位于会议期间均可登陆，进入腾讯会议后请按照“单位名称-姓名”修改昵称。

**三、**2023年项目申报通知群

为方便各项目申报单位及时获得郑商所相关工作安排，现将微信群二维码公布如下（5月3日前有效），请各项目申报单位按照“单位名称—姓名”发送进群申请。
