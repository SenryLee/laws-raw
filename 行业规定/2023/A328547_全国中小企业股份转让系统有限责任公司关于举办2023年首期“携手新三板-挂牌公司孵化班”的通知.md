# 全国中小企业股份转让系统有限责任公司关于举办2023年首期“携手新三板-挂牌公司孵化班”的通知

## 关于举办2023年首期“携手新三板-挂牌公司孵化班”的通知

各市场主体：

为辅导企业解决挂牌前规范性问题，提升拟挂牌企业规范运作水平，帮助企业顺利挂牌，全国股转公司拟于5月9日采用现场培训+线上直播的形式面向拟挂牌公司董事长、总经理或相关负责人举办2023年首期“携手新三板-挂牌公司孵化班”。课程设计关注业务实操，培训内容主要涵盖挂牌上市顶层设计、挂牌准入制度解读、公司规范性要求等。具体安排如下：

**一、**参会人员

拟挂牌公司董事长、总经理或相关负责人。

**二、**培训形式及地点

本次培训采用现场培训+线上直播的形式，现场培训于北京市西城区金融街开展，每家单位限报2人，现场培训规模不超过100人。线上直播通过腾讯会议开展，规模不超过2000人。

**三、**培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| “携手新三板-挂牌公司孵化班” | | | |
| 时间 | | 内容 | 主讲人 |
| 5月9日（周二） | 9:00-10:15 | 深化新三板改革 设立北交所的思路与主要制度安排 | 市场发展部  业务骨干 |
| 10:30-11:30 | 全面注册制背景下新三板挂牌准入制度解读 | 挂牌审查部  业务骨干 |
| 14:00-15:15 | 企业挂牌需解决的股权问题 | 德恒律师事务所  合伙人 |
| 15:30-16:30 | 企业挂牌需解决的财务问题 | 开源证券  投资银行总部  负责人 |

**四、**报名方式及截止时间

本次培训需收集报名信息，请您按照培训形式点击报名链接进行报名，报名截止时间为5月8日12:00。我们将在审核后将培训具体地点及腾讯会议直播码在会议前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

因培训名额有限，请您报名后准时参加，如无法参加请及时联系工作人员取消报名。培训报名成功后如未参与可能会影响后续培训资格。
