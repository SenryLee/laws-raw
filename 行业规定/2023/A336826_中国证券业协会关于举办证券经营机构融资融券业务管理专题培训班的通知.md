# 中国证券业协会关于举办证券经营机构融资融券业务管理专题培训班的通知

## 关于举办证券经营机构融资融券业务管理专题培训班的通知

中证协发〔2023〕129号

各会员单位:

为帮助证券经营机构准确理解融资融券业务风险管控要求,提升风险识别能力和流程管控的有效性、适应性,健全完善融资融券合规风险管理框架,保障业务平稳运行。根据2023年度面授培训计划,中国证券业协会定于7月13日在上海免费举办证券经营机构融资融券业务管理专题培训班。现将相关事项通知如下:

**一、**培训对象

培训对象为证券公司融资融券业务负责人、合规风控负责人、财务负责人及业务骨干,每家不超过3人,计划招生150人。

**二、**培训时间和地点

培训时间:2023年7月13日09:00-17:30

报到时间:2023年7月12日15:00-18:00

7月13日08:30-09:00

培训地点:上海远洋宾馆三楼多功能厅(上海市虹口区东大名路1171号)

**三、**培训内容及师资

培训内容包括:

(一)融资融券业务运行情况及监管要求;

(二)《融资融券担保物集中度指引》要求解读;

(三)全面注册制下两融规则修改及风险管理;

(四)北交所融资融券制度及业务要点;

(五)转融券市场化改革进展和信息交互平台建设;

(六)市场化转融资业务运行及发展情况;

(七)融资融券业务统计监测与数据报送。

培训师资为:中国证监会、上海证券交易所、深圳证券交易所、北京证券交易所、中国证券金融股份有限公司等单位相关业务负责人。

**四、**培训费用及食宿安排

本期培训免费,培训期间协会统一安排正餐。

需住宿学员请至少提前一周预定酒店,住宿费用自理。订房时请说明系参加“中证协融资融券培训班”的学员。学员也可根据个人情况自行安排食宿。

上海远洋宾馆预定电话: 柯经理,13918454590。
