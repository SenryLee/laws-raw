# 大连商品交易所关于调整焦煤期货合约手续费标准的通知

## 关于调整焦煤期货合约手续费标准的通知

大商所发〔2023〕169号

各会员单位：

经研究决定，自2023年5月4日交易时起，对焦煤期货合约手续费标准进行调整，具体如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 期货品种 | 调整前（成交金额的万分之X） | | 调整后（成交金额的万分之X） | |
| 非日内交易 | 日内交易 | 非日内交易 | 日内交易 |
| 焦煤 | 1 | 1.4 | 1 | 3 |

特此通知。

大连商品交易所

2023年4月25日
