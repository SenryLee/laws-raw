# 全国股转公司、北京证券交易所关于全国股转公司、北京证券交易所2023年委托课题研究申报的公告

## 全国股转公司　北京证券交易所公告

北证公告〔2023〕37号

## 关于全国股转公司 北京证券交易所2023年委托课题研究申报的公告

为联合社会各界研究力量，共同推进深化新三板改革、高质量建设北京证券交易所，全国股转公司、北京证券交易所即日起启动2023年委托课题研究申报工作。现将有关事项通知如下：

**一、**课题选题及研究方向

全国股转公司、北京证券交易所2023年委托课题研究共4项：

1. 北交所市场估值体系研究

本课题将深入研究成熟市场估值体系演进的背景、经验和不足，分析不同类型企业的估值逻辑和方法，特别是针对中小企业估值难点采取的适应性方法、考虑的特殊因素；对境内外主要交易所发行定价的流程、环节和主要参与主体进行对比分析，梳理主要的制度机制差异，评估由此带来的不同影响；系统评估北交所市场估值体系存在的问题及深层次原因，从定价环节、参与人、定价维度、估值方法等视角提出更好对创新型中小企业股票进行合理估值、优化北交所市场估值体系的思路和建议。

2. 中小市值股票指数化投资研究

本课题将系统梳理境外成熟市场中小市值股票指数化投资发展历程，并总结其成功经验；梳理我国中小市值股票指数化投资发展现状，分析主要产品结构、规模及投资行为特征，深入调研中小市值股票指数化投资存在的问题及背后原因；借鉴成熟市场经验，围绕更好引导社会资本投资北交所市场和新三板市场中小市值股票的目标，研究提出北交所市场和新三板市场持续构建指数和指数化投资体系的路径，包括构建指数体系、配套产品开发、培育指数投资生态等方面。

3. 新三板与私募市场合作对接研究

本课题将研究境外公开资本市场与私募市场合作对接的模式，包括运作模式、制度创新、产品对接、监管安排等各方面；系统研究梳理我国区域性股权市场、私募股权和创投基金市场、产权市场等私募市场发展趋势和制度特点，分析与新三板合作对接的动因、不足与原因；调研新三板与私募市场合作对接的堵点、难点，研究提出新三板与区域性股权市场、私募股权和创投基金市场、产权市场在挂牌、交易、投融资服务、并购重组等各环节合作对接的有效路径，包括但不限于制度对接、产品对接、技术对接、监管对接、服务对接等各方面，并论证其可行性。

4. 激发新三板并购重组市场活力研究

本课题将分析新三板成立十年来挂牌公司并购重组业务市场运行情况，深入分析市场变化原因，以及境外中小企业并购重组的现状及有效做法；深入了解挂牌公司并购重组的需求，结合实践需求找准挂牌公司并购重组制度安排的不足，包括品种供给、实施程序、中介机构等；围绕激励挂牌公司利用并购重组工具做大做强的目标，提出激发新三板并购重组市场活力的可行建议，包括监管制度优化、市场生态建设等。

**二、**申报要求

1. 课题申报需以单位名义进行，不接受个人名义申报。欢迎证券公司、基金管理公司、高等院校、科研院所、会计师事务所、律师事务所、银行、保险等进行申报。

2. 申报单位应根据实际需要，在课题经费范围内编制合理的经费预算。

3. 申报单位应保证课题研究人员符合以下条件：（1）具有从事相关研究或实务工作的经历；（2）具有较强的科研能力；（3）有充足的时间从事课题研究工作。

4. 申报单位须提交的材料包括：

（1）营业执照或事业单位法人证书复印件；

（2）《全国股转公司 北京证券交易所课题承接申请书》（见附件1）；

（3）经费预算明细表（见附件2）。

上述材料一式两份（以上材料均须加盖单位公章），请将纸质申请材料密封邮寄至北京市西城区金融大街丁26号金阳大厦南门，并将申请材料word版发送至课题管理邮箱（电子邮箱：keti@neeq.com.cn）。

5. 课题申报截止日为2023年5月12日24时。

**三、**其他说明

1. 全国股转公司将按照“公开征集、单位申报、集体评审、择优选取”的原则，对各单位提交的申报材料进行评审，择优确定课题承接方，并对名单进行公示。

2. 全国股转公司将与课题承接方签订相关研究协议。课题研究期限为签订协议之日起6个月，终期研究报告字数不少于5万字。

3. 每项课题经费15万元，分三期支付：签订协议后支付研究经费的20%；中期评审通过，支付研究经费的20%；结题评审为优秀、良好等级，支付全部剩余经费，结果为合格等级，支付研究经费的20%，结果为不合格等级的，不支付剩余经费。

4. 课题承接方应保证课题研究的科学性、规范性、创新性和实用性，研究成果不得侵犯任何第三方的知识产权或其他权利，符合国家有关保密规定和有关行业政策。
