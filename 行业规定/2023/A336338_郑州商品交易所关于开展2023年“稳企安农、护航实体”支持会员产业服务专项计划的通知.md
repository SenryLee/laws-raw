# 郑州商品交易所关于开展2023年“稳企安农、护航实体”支持会员产业服务专项计划的通知

## 关于开展2023年“稳企安农　护航实体”支持会员产业服务专项计划的通知

郑商函〔2023〕477号

各会员单位：

为深化期货服务实体经济功能，持续提升产业企业参与期货市场广度和深度，郑州商品交易所（以下简称郑商所）决定2023年继续开展“‘稳企安农 护航实体’——支持会员产业服务专项计划”（以下简称产业专项）。现将相关事项通知如下。

**一、**支持重点

支持会员单位开发服务产业企业，着力推动提升产业客户参与度。

一是提升产业企业期货参与度。重点企业、中小企业首次开立期货账户或首次开展期货交易，并达到一定持仓要求。

二是提升产业企业场内期权参与度。产业企业首次开通期权交易权限或首次开展期权交易，并达到一定持仓要求。

**二、**申请主体

期货公司，须以总部名义申请。

**三、**项目内容

产业专项包括三类项目。

（一）项目一：重点企业期货项目

1.服务对象

企业2023年首次开户或2022年在项目申请品种上无交易记录，且满足下列条件之一。

（1）符合规模标准的产业企业（规模标准见附件1）。

（2）上海证券交易所、深圳证券交易所、北京证券交易所的上市公司。

（3）省属（含各省、自治区、直辖市及计划单列市和新疆生产建设兵团）及以上国有企业（以国资委名单为准）。

期货公司风险管理公司不参与此项目。

2.项目品种

棉花、白糖、PTA、菜籽油、甲醇、玻璃、菜籽粕、锰硅、硅铁、苹果、尿素、纯碱、短纤、花生等14个期货品种。

3.考核要求及支持标准

考核期内，服务对象在项目申请品种上累计净持仓量[1]及持仓天数达到要求，给予期货公司相应标准资金支持。

同一家企业每个品种只能参与1个项目。

表1 项目一持仓要求及支持标准

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 期货  品种 | PTA、棉花、白糖、甲醇、菜籽油、菜籽粕 | 玻璃、硅铁、锰硅、短纤、纯碱 | 尿素、苹果、花生 | 持仓天数  要求 | 支持  标准 |
| 累计净持仓量（手） | 5000 | 4000 | 1500 | 累计不少于20个交易日 | 20万元 |
| 10000 | 8000 | 3000 | 25万元 |
| 20000 | 16000 | 6000 | 30万元 |

4.申请材料

申请材料包括重点企业期货项目备案表、企业确认函（见附件2、5），以及下列证明材料。

（1）符合规模标准的企业，需提供营业执照、能够证明企业规模的材料。

（2）上市公司、省属及以上国有企业，需提供营业执照、能够证明企业产业属性的材料（如贸易合同、发票等）。

（二）项目二：中小企业期货项目

1.服务对象

除重点企业之外的其他产业企业，企业为2023年首次开户或2022年在郑商所无交易记录。

期货公司风险管理公司不参与此项目。

2.项目品种

棉花、白糖、PTA、菜籽油、甲醇、玻璃、菜籽粕、锰硅、硅铁、苹果、红枣、尿素、纯碱、短纤、花生等15个期货品种。

3.考核要求及支持标准

考核期内，服务对象在项目申请品种上累计净持仓量及持仓天数达到要求，给予期货公司相应标准资金支持。

同一家企业同一时期只能参与1个项目。

表2 项目二持仓要求及支持标准

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 期货  品种 | PTA、棉花、白糖、甲醇、菜籽油、菜籽粕 | 玻璃、硅铁、锰硅、短纤、纯碱 | 尿素、苹果、红枣、花生 | 持仓天数  要求 | 支持  标准 |
| 累计净持仓量（手） | 3500 | 2500 | 1000 | 累计不少于20个交易日 | 6万元 |
| 7000 | 5000 | 2000 | 8万元 |
| 14000 | 10000 | 4000 | 10万元 |

4.申请材料

申请材料包括中小企业期货项目备案表、企业确认函、企业营业执照（见附件3、5），以及能够证明企业产业属性的材料（如贸易合同及发票等）。

（三）项目三：产业企业场内期权项目

1.服务对象

项目品种对应的产业企业，企业为2023年首次开通期权交易权限或2022年在项目申请期权品种上无交易记录。

2.项目品种

白糖、棉花、PTA、甲醇、菜籽粕、菜籽油、花生等7个期权品种。

3.考核要求及支持标准

考核期内，服务对象在项目申请期权品种上累计持仓量[2]及持仓天数达到要求，给予期货公司相应标准资金支持。

同一家企业每个品种只能参与1个项目。

表3 项目三持仓要求及支持标准

|  |  |  |  |
| --- | --- | --- | --- |
| 期权品种 | 白糖、棉花、PTA、甲醇、菜籽粕、  菜籽油、花生 | 持仓天数  要求 | 支持  标准 |
| 累计持仓量（手） | 4000 | 累计不少于20个交易日 | 10万元 |

4.申请材料

申请材料包括产业企业场内期权项目备案表、企业确认函、企业营业执照（见附件4、5），以及能够证明企业产业属性的材料（如贸易合同及发票等）。

**四、**项目申请、考核期及资金支持

（一）申请备案

郑商所自通知发布之日起接收项目申请，申请截止日期为2023年12月15日。

期货公司应通过会服系统填写并提交项目备案表（见附件2、3、4），对服务对象资质进行审查把关，并作出承诺声明，申请时须上传企业确认函（见附件5）、企业营业执照以及相关证明材料。

（二）考核期

自项目完成备案之日起，统计服务对象持仓量及持仓天数。考核期不超过1年。

（三）资金支持

完成备案且在考核期内达到考核要求的项目，郑商所通过手续费减收的方式给予期货公司支持。按月考核服务对象的持仓情况，单个项目支持额度之和不超过该项目的最高支持标准。
