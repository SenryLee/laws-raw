# 深圳证券交易所关于“C盟固利”盘中临时停牌的公告

## 关于“C盟固利”盘中临时停牌的公告

“C盟固利”（301487）盘中成交价较开盘价首次上涨达到或超过30%，根据《深圳证券交易所交易规则》等有关规定，本所自今日09时37分11秒起对该证券实施临时停牌，于09时47分12秒复牌。

本所郑重提示广大投资者注意投资风险，理性投资。
