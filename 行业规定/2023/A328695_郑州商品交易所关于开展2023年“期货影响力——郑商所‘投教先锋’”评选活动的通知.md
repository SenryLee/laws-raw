# 郑州商品交易所关于开展2023年“期货影响力——郑商所‘投教先锋’”评选活动的通知

## 关于开展2023年“期货影响力——郑商所‘投教先锋’”评选活动的通知

郑商函〔2023〕324号

各会员单位、地方期货业协会：

为凝聚多方力量进一步提升期货市场投资者教育工作的质量和影响力，鼓励原创投资者教育产品生产，打造行业投资者教育团队，培育、壮大期货市场投资者教育力量，郑州商品交易所（以下简称郑商所）将举办2023年“期货影响力——郑商所‘投教先锋’”评选活动。具体通知如下：

**一、**参评要求

（一）参与对象

由会员单位、地方期货业协会推荐报名参评团队（每家参评团队成员5人以内）。

（二）参评作品

1.形式：漫画、长图。

2.要求：每家参评团队提交的作品不少于2个主题，每个主题不少于2条作品，单条作品不低于10个画幅。参评作品应立意明确、形式活泼、通俗易懂、制作精良。

（三）作品主题

1.“保险+期货”、“商储无忧”、“点价交易”、“含权贸易”等市场各方创新运用期货工具，提升服务实体经济质效的案例。

2.PTA、甲醇等“中间产品”对大宗商品价格形成和传导机制的原理解析。

3.期货市场服务乡村振兴和农业产业发展。

4.市场风险解析。

5.郑商所上市品种期现货知识。

6.期货市场规则制度和政策法规解析。

**二、**相关安排

（一）时间安排

|  |  |
| --- | --- |
| 时间 | 事项 |
| 6月—8月 | 提交报名材料和作品 |
| 9月—10月 | 评选、展示入围作品 |
| 10月—11月 | 公布评选结果 |

（二）评选规则

1.由专家组根据报名作品评选出37个入围“投教先锋”评选的团队。

2.入围作品通过郑商所微信公众号、中国证券报“中证金牛座”客户端、新浪网等评选活动官方发布平台进行展示。

3.结合专家组意见和参评作品展示情况，综合评判确定评选结果。

（三）报名材料

1.活动报名表、知识产权承诺函及授权使用同意书、参评作品和对应的文案素材表（见通知附件）。知识产权承诺函及授权使用同意书应加盖机构公章。

2.主创团队人员视频展示（时长3分钟以内，介绍创作理念等）。

3.报名邮件主题命名格式为：机构名称+2023年“投教先锋”报名材料。

**三、**评选设置

根据综合评判结果，第1-12名团队获得2023年“郑商所‘投教先锋’”团队称号，第13-37名团队获得2023年“郑商所‘投教先锋’”提名团队称号。其中，对“投教先锋”团队给予每家30000元费用支持，对“投教先锋”提名团队给予每家15000元费用支持，用于后续开展投资者教育相关工作。
