# 全国中小企业股份转让系统有限责任公司关于举办第二十九期“全国股转系统大讲堂”——财务规范专题培训（先进制造专场）的通知

## 关于举办第二十九期“全国股转系统大讲堂”——财务规范专题培训（先进制造专场）的通知

为支持中小企业高质量发展，增强企业规范经营管理能力，提升企业“关键少数”的资本运营水平，拓宽其运用资本市场创新发展的视野，全国股转公司拟按行业领域分期举办 “全国股转系统大讲堂”——财务规范专题培训，本期培训将于2023年8月10日举办，聚焦先进制造业。培训具体安排如下：

**一、**参会人员

先进制造业挂牌公司董事长、总经理、实际控制人、财务负责人、董事会秘书和相关业务人员，其他感兴趣的市场主体。

**二、**培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| 时间 | | 课程名称 | 授课单位 |
| 8月10日  （周四） | 14:00-15:30 | 先进制造业概况及投资逻辑 | 广发证券 |
| 15:30-17:00 | 先进制造业财务规范重难点分析 | 天健会计师事务所 |

备注:最终课表以实际课程安排为准。

**三、**培训形式

本期培训采用“腾讯会议”线上直播讲解的模式，参会人员可通过会议码参加培训。会议码将于会议前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

**四、**报名方式及截止时间

本次培训需收集报名信息。请您扫描下方二维码或者点击报名链接进行报名，报名截止时间为8月9日12:00。
