# 北京证券交易所关于举办北交所上市公司信息披露管理机制调整培训的通知

## 关于举办北交所上市公司信息披露管理机制调整培训的通知

根据北交所信息披露管理机制调整安排，本所拟于近期将信息披露模式由券商协助披露切换到公司自主披露。为确保信息披露管理机制的平稳切换，提高上市公司信息披露质量，帮助上市公司掌握相关要求和系统操作流程，本所定于1月9日、10日针对已上市公司、已过会企业开展信息披露管理机制调整专项培训。

**一、**培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| 日期 | 培训内容 | 培训时间 | 主讲人 |
| 1月9日/10日上午 | 上市公司信息披露管理机制调整情况介绍 | 9:00-9:20 | 上市公司管理部 |
| 信息披露等业务办理指南及系统操作介绍 | 9:20-10:20 | 上市公司管理部 |
| 北交所发行人限售和解除限售登记业务介绍 | 10:20-11:00 | 中国结算北京分公司发行人业务部 |
| 1月9日/10日下午 | 上市公司信息披露监管要点解读 | 14:00-14:40 | 上市公司管理部 |
| 股权激励及股份变动制度解读 | 14:40-16:00 | 上市公司管理部 |
| 经验交流：上市公司信息披露业务实操分享 | 16:00-17:00 | 资深上市公司董秘 |
| 业务练习 | 17:00-17:30 | - |

注：1月9日、10日课程内容一致，公司可在报名时选择任意一天参加培训。

**二、**培训对象

1.培训对象：已上市公司和已过会企业董秘、证代等信披人员。

2.业务练习参与对象：全体参训学员。

**三、**培训/练习形式

本次培训采用线上讲解的模式，参会人员可通过访问培训链接参与培训。

培训链接将于培训前通过手机短信或邮件发送给报名人员，报名时请填写有效手机号码及邮箱。

培训结束后请培训对象在规定时间内通过扫描屏幕中的二维码完成线上业务练习。

**四、**报名方式及截止时间

本次活动需收集报名信息，以便发送培训链接。请您点击链接或扫码进行报名，报名截止时间为1月6日12:00。
