# 郑州商品交易所关于2023年1月“期货名家讲堂”视频讲座的通知

## 关于2023年1月“期货名家讲堂”视频讲座的通知

郑商函〔2023〕3号

各会员单位：

郑州商品交易所（以下简称郑商所）2023年1月“期货名家讲堂”视频讲座安排已确定。现通知如下。

**一、**时间安排

|  |  |
| --- | --- |
| 时间 | 主题 |
| 1月12日（周四）15:30-17:00 | 花生现货市场运行情况及期货应用 |
| 1月16日（周一）15:30-17:00 | 菜系基本面特征及期权运用 |
| 注：讲座当天下午14:30-15:20进行网络测试 | |

**二、**观看方式

视频讲座可通过以下方式观看。

（一）登录郑商所官网，点击首页左下角“视频培训”栏目观看。

（二）通过手机等移动端扫描下方二维码在线观看。

![43710c05797641f8b129135097116586_20230104111517469001.jpg](https://zk-img.faxin.cn//Uedit_Upload/2023-01-12-16-38-39_9412355_43710c05797641f8b129135097116586_20230104111517469001.jpg "43710c05797641f8b129135097116586_20230104111517469001.jpg")

（三）关注郑商所官方微信公众号“郑商所发布”，点击视频讲座提醒栏目观看。

**三、**注意事项

为方便及时了解视频讲座安排，请关注郑商所新浪官方微博“郑商所发布”、官方微信公众号“郑商所发布”及官方网站“衍生品学苑”栏目，每次讲座的主题、讲师等内容，郑商所将通过以上平台进行提醒，不再另行发文通知，请各会员单位注意查看。

如对视频讲座安排有任何疑问、意见和建议，请及时联系我们。联系电话：0371-65610559。

特此通知。
