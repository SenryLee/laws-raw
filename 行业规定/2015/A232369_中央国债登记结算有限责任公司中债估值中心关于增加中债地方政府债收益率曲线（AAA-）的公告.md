|  |  |  |
| --- | --- | --- |
| 中文名称 | 英文名称 | 曲线利率品种 |
| 中债地方政府债收益率曲线（AAA-） | ChinaBond Local Government Security Yield Curve （AAA-） | 到期、即期、远期 |

到期收益率曲线期限为：0-50年

即期收益率曲线期限为：0-50年

远期标准期限为N＝1，2，3，4，5；　 K＝1，2，3，4，5
