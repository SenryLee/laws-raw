# 中国石油和化学工业联合会关于开展2014年度联合会系统评选表彰工作的通知

联合会机关各部室，系统各单位：

2014年是实施“十二五”规划的关键一年，也是“十三五”规划的调研启动年。联合会系统各单位，深入学习贯彻党的十八大和十八届三、四中全会精神，认真开展党的群众路线教育活动，坚持“把协会当作事业来干”，以提高发展质量和效益为中心，稳中求进、开拓创新，扎实推进结构调整、创新驱动、生态文明建设、经济运行监测、国际交流与合作和自身建设等重点工作，为促进石油和化工行业持续健康发展作出了重要贡献。一年来，联合会系统各单位在服务企业、服务行业、服务政府工作中涌现出一批先进集体和先进个人。为树立典型，鼓励先进，弘扬正气，振奋精神，激励广大职工进一步发扬光荣传统，团结和凝聚力量，在向建设石油和化学工业强国中做出新的更优异的成绩，经研究决定，在联合会系统开展2014年度评选表彰工作。现将有关事项通知如下：

一、评选范围和表彰名额

(一)评选范围

1.先进单位。联合会机关部室、专业协会、企事业单位。

2.先进集体。联合会机关处，专业协会、企事业单位处(部、室)。

3.先进工作者。联合会机关和专业协会的专职工作人员，企事业单位在职员工。

(二)表彰名额

1.先进单位。按联合会系统单位的15%推荐。联合会机关以部室，专业协会、企事业单位以整体作为表彰单位。

2.先进集体。按各单位处(部、室)的20%推荐。联合会机关以处，专业协会、企事业单位以处(部、室)作为表彰集体。

3.先进工作者。根据单位人数，按以下4个档次推荐：20人及以下的单位推荐1人、21～100人的单位推荐1～2人、101～200人的单位推荐在职职工人数的3%、201人及以上的单位推荐在职职工人数的1.5%，作为表彰对象。

二、评选条件

(一)先进单位(集体)评选条件

1.坚持以邓小平理论、“三个代表”重要思想和科学发展观为指导，深入学习贯彻党的十八大和十八届三中全会精神，开展党的群众路线教育实践活动扎实有效;

2.在服务企业、行业和政府，保持行业经济平稳运行，推进“调结构、转方式”和化解过剩产能，促进行业健康可持续发展方面有新思路、新举措、新成效，取得较好的经济和社会效益;

3.在改革运行机制、优化组织结构、强化内部管理、提高管理水平，增强服务功能、开拓工作领域、提高经济效益，提高职工职业思想道德素质、工作技能、创新能力等方面成效突出;

4.在围绕“创新力、决策力、执行力、影响力”加强自身建设，维护工作大局，政令畅通、令行禁止方面，表现突出，成效显著;

5.领导班子坚强有力，团结协作，作风民主，决策科学，善于管理，勤政廉政，带头执行中央改进工作作风、密切联系群众八项规定，工作机构健全，规章制度完善，重视精神文明和文化建设，职工队伍素质良好，工作氛围和谐;

6.促进党的基层组织建设工作整体提升，在加强基层党组织班子建设、夯实党员干部队伍建设、完善基层党组织制度建设、推进学习型党组织建设、加强党的先进性建设，提升履职和服务能力等方面成绩突出。

(二)先进工作者评选条件

1.认真学习贯彻党的十八大和十八届三中、四中全会精神，以邓小平理论、“三个代表”重要思想和科学发展观为指导，坚决执行党的路线、方针、政策;

2.具有强烈的事业心、责任感，积极提高自身“创新力、决策力、执行力、影响力”，在开拓新的工作领域，扩大行业影响力方面成绩突出;

3.具有良好的职业道德和优良的工作作风，爱岗敬业、无私奉献、廉洁自律、群众基础好;

4.热爱协会工作，关心行业发展，在本职工作中做出显著成绩：

⑴在引导行业企业“调结构、转方式”和保持经济平稳运行、提高经济效益，贯彻宏观经济调控措施，促进科技创新、节能减排、责任关怀等工作中作出突出成绩;

⑵在组织和开展基础理论研究、关键共性技术攻关，应用推广新技术、新材料、新工艺，推进企业技术进步和自主创新等方面成绩突出;

⑶在本单位深化改革，强化管理，诚信经营，重视公益事业，履行社会责任等方面成绩突出;

⑷提高思想业务素质，增强履职能力，爱岗敬业、勇于创新，工作取得优异成绩;

⑸在党的建设、廉政建设、思想政治工作和精神文明建设、文化建设、人才培养和教育、维护职工合法权益等方面成绩突出;

⑹在其他方面做出突出成绩。领导干部还应考察所在单位各方面工作和贯彻中央改进工作作风、密切联系群众八项规定的情况。

三、评选原则和办法

(一)评选原则。坚持标准、保证质量，体现先进性、代表性、示范性;严格遵守推荐程序，公开、公平、公正;面向工作一线，表彰对象中，一线工作部门和人员不低于70%。

(二)评选办法。采取自下而上，上下结合的方法进行。由联合会机关、专业协会和企事业单位推荐，评选表彰领导小组办公室汇总、初审，评选表彰领导小组批准、表彰。具体程序：

1.先进单位。由联合会机关各部室、各专业协会和企事业单位填写《先进单位推荐表》，在联合会系统范围内提名推荐单位。评选表彰领导小组办公室汇总提名并进行初审，根据名额比例提出表彰候选单位建议名单，经评选表彰领导小组原则同意后，由表彰候选单位填写《先进单位审批表》。

2.先进集体。由联合会机关部室和各单位，在本部室、单位内按比例组织推荐，填写《先进集体审批表》，报评选表彰领导小组办公室汇总、初审。评选表彰领导小组进行评审，确定先进集体表彰名单。

3.先进工作者。联合会机关、专业协会和企事业单位，按分配名额比例，在本单位组织推荐先进工作者候选人，填写《先进工作者审批表》，报评选表彰领导小组办公室。评选表彰领导小组办公室对上报名单和材料进行汇总和初审，提出拟表彰人选建议名单。评选表彰领导小组进行评审，确定先进工作者表彰名单。

4.拟表彰先进集体和先进工作者，征求联合会纪检监察、财务审计部门的意见。

四、奖励办法

在联合会系统年终总结大会上对先进单位、集体和工作者进行表彰，颁发联合会系统荣誉证书，并在国家石油和化工网、中国石油和化工经济分析、中国化工报、石油和化工网视新媒体、石油和化工杂志刊载宣传。

对受到表彰的先进单位、集体和工作者给予适当的物质奖励，奖励标准和经费由各单位自行制定和筹集发放。

五、时间安排

2015年1月23日前各单位结合年终总结组织推荐，并将推荐结果报评选表彰领导小组办公室;2015年1月31日前汇总审批;2015年2月上旬召开联合会系统年终总结大会进行表彰。

六、组织领导

为做好评选表彰工作，成立联合会系统评选表彰领导小组，负责评选工作的组织领导。领导小组下设办公室，负责评选表彰的具体工作。办公室设在联合会人事部。

(一)领导小组

组长：李寿生

副组长：李润生、赵俊贵、周竹叶

成员：顾宗勤、张婉如、郝长江、张文雷、孙伟善、孙东民、阮新

(二)办公室

主任：阮新

成员：孙东民、刘献福、沙志华

七、工作要求

评选表彰工作对于鼓舞联合会系统各单位、广大职工深入学习贯彻党的十八大和十八届三中、四中全会精神，坚定信心、振奋精神、团结拼搏，全面加强联合会系统建设，推进各项工作上一个新的台阶，促进行业健康可持续发展意义重大。各单位要高度重视，加强领导，精心组织，密切配合，认真做好评选工作。要认真总结和宣传先进经验和事迹，充分发挥典型的示范、引导和激励作用，通过评选表彰工作，争创一流工作业绩、建设一流行业协会。
