# 中国期货业协会关于举办期货公司资产管理业务系列专题（视频）讲座的通知

## 关于举办期货公司资产管理业务系列专题（视频）讲座的通知

各会员单位：

为加强经验交流，提高相关人员的专业素质和技能，提升期货公司资产管理业务水平，同时，为增强风险控制和合规经营意识，进一步推动期货公司资产管理业务健康、快速发展，协会拟于7月起推出“创新大讲堂——期货公司资产管理业务系列专题（视频）讲座”。现将近期讲座安排通知如下：

一、讲座时间和内容

第一期

时间：2015年7月15日（周三）15：00-17：00

15：00-16：00 资产管理业务风险识别与风险控制

海通期货 姚弘

16：00-17：00 银行-期货FOF基金产品模式

海通期货 朱继米

第二期

时间：2015年7月21日（周二）15:00-17:00

15：00-16：00 资产管理业务基本业务模式与业务创新

永安资本 肖国平

16：00-17：00 资产管理业务合规经营与制度建设

永安期货 陈敏

二、参会对象

期货公司（已开展或拟开展业务）资产管理部门或资产管理子公司负责人及相关业务人员、合规部门负责人及合规管理人员。

三、参会方式

本次会议使用“好视通”视频会议系统，各参会单位请自行选取地点设置分会场，配备电脑、话筒、音箱、投影等设备（网络带宽最好在2兆以上）。

会议主会场设各地方协会，有兴趣到现场与主讲人进行互动交流的请与各地方协会联系（见下表），各分会场也可利用会议系统与主讲人进行语音或文字交流。

|  |  |  |  |
| --- | --- | --- | --- |
| **时间** | **地点** | **联系人** | **联系电话** |
| 7月15日 | 上海期货同业公会 | 陆敏华 | 021-68401088 |
| 7月21日 | 浙江期货行业协会 | 邱家律 | 0571-89916732 |

四、会议准备

为保障会议顺利进行，请各会员单位提前登录会议系统进行测试。首次使用“好视通”系统的会员单位请登陆各自的协会专用邮箱，参照相关邮件附件进行软件安装和测试。

视频会议统一测试时间为7月14日及20日09:00-17:00，请参会单位确定本单位参会人员及视频培训技术保障联系人，填写附件2中的统计表并于2015年7月14日17:00前发送至train@cfachina.org。请务必准时参加测试，如有疑问请联系协会技术部。

五、联系方式

技术事宜： 010-88086237/7081

参会事宜： 010-88087217/6853
