# 中国石油和化学工业联合会关于举办优秀调研报告评选活动的通知

联合会各部室，分支机构，代管专业协会，企事业单位：

为提高联合会系统调查研究、综合分析、文字表达能力，进一步加强联合会系统业务建设，增强服务能力，结合公文写作专题系列培训，举办优秀调研报告评选活动。具体通知如下：

一、评选内容

紧密结合联合会及本单位中心工作，突出三个主题：1、围绕宗旨，创新发展;2、围绕定位，科学指导;3、围绕地位，加强建设。突出结构调整、化解过剩产能、科技创新、安全环保、产业竞争力等问题。

二、参加对象

联合会系统全体员工，重点是中青年员工。

三、时间安排

1. 组稿。从通知下发起，各部室、分支机构、专业协会和企事业单位(以下简称“各部室、各单位”)，组织员工结合近三年的工作调研，撰写或修改调研报告。

2. 投稿。各部室、各单位对员工稿件进行筛选、修改后，于8月下旬至9月下旬统一投稿(公文写作重点培训对象必须投稿)。

3. 初评。9月下旬至10月上旬，联合会组织初评，确定进入决赛名单。进入决赛者10月中旬交稿件PPT。

4. 决赛。10月下旬，联合会以专题演讲形式进行决赛(参加决赛者每人不超过20分钟)，结合调研报告内容和现场表现评选出一、二、三名，根据各部室、各单位报送调研报告的数量和获奖情况评选出优秀组织单位。

四、奖励宣传

1. 对获得一、二、三等奖的调研报告和优秀组织单位分别给予奖励。

2. 在中国化工报社、国家石油和化工网宣传活动的组织和评选成果;优秀调研报告集结成册，印发各部室、各单位;选择部分优秀调研报告在联合会及各单位进行展示。

五、评选组织

1. 联合会成立领导小组，负责评选活动工作的组织领导。

组 长：李寿生常务副会长

成 员：各部室、有关单位负责人。

2. 联合会人事部、综合办负责评选组织的具体工作。
