# 深圳证券信息有限公司2015年2月关于发布中关村系列指数的公告

为表征中关村国家自主创新示范区A股上市公司的运行情况，进一步丰富指数化投资标的，满足市场投资管理的需要，深圳证券信息有限公司定于2015年2月5日发布中关村50和中关村A指。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399423 | 中关村50指数 | 中关村50 | 2008年12月31日 | 1000 |
| CN5069 | 中关村A股综合指数 | 中关村A指 | 2008年12月31日 | 1000 |

中关村50指数以沪深A股市场中注册地在中关村国家自主创新示范区内的上市企业为备选范围，采用日均总市值比重、日均自由流通市值比重与日均成交金额比重1:1:1进行加权排序，结合上市公司基本面情况，选取排名靠前的50只股票构成样本股。中关村A股指数以中关村内注册的所有A股上市公司为样本股，是反映中关村整体发展水平的综合指数。

指数采用自由流通市值进行加权计算，中关村50样本股权重上限为10%，每年1月份与7月份进行样本股定期调整。

以上指数包括纯价格指数和全收益指数，中关村50纯价格指数通过深交所行情系统发布实时行情数据，其余指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http:// www.cnindex.com.cn）。
