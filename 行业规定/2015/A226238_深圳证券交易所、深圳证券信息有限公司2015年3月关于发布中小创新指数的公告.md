# 深圳证券交易所、深圳证券信息有限公司2015年3月关于发布中小创新指数的公告

为了反映深圳市场不同规模特征股票的整体表现，向市场提供更丰富的分析工具和业绩基准，深圳证券交易所和深圳证券信息有限公司定于2015年3月24日发布中小创新指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399015 | 中小创新指数 | 中小创新 | 2011年12月30日 | 1000 |

中小创新指数选取深证1000指数样本股中，剔除深证成指样本股之后的500只股票构成指数样本股。当深证成指、深证1000指数调整样本股时，中小创新指数随之进行相应的样本调整。指数采用自由流通市值加权计算方法。

中小创新指数包括纯价格指数和全收益指数，纯价格指数通过深圳证券交易所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。指数编制方案及最新样本股名单参见国证指数网（http:// www.cnindex.com.cn）。
