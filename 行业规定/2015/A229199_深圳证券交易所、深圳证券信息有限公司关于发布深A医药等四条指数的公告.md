# 深圳证券交易所、深圳证券信息有限公司关于发布深A医药等四条指数的公告

## 关于发布深A医药等四条指数的公告

为反映深市医药卫生行业和互联网软件产业上市公司的整体表现，进一步满足指数化投资需求，深圳证券交易所和深圳证券信息有限公司定于2015年6月8日发布深A系列行业及行业等权4条指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **指数代码** | **指数名称** | **指数简称** | **基日** | **基点** |
| 399674 | 深A医药卫生指数 | 深A医药 | 2010年6月30日 | 1000 |
| 399675 | 深A软件与互联网指数 | 深A互联 | 2010年6月30日 | 1000 |
| 399676 | 深A医药卫生等权指数 | 深医药EW | 2010年6月30日 | 1000 |
| 399677 | 深A软件与互联网等权指数 | 深互联EW | 2010年6月30日 | 1000 |

依照国证行业分类标准，深A医药和深A互联指数，分别以深证A指样本股中归属医药卫生一级行业和软件与互联网二级行业的股票为备选范围，采用市值加权计算，每年1月与7月进行样本股定期调整；深医药EW和深互联EW指数，以上述两条指数分别为母指数，采用等权重方式加权计算。

深A医药和深A互联及相应等权指数均包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。指数编制方案及最新样本股名单参见国证指数网（http://www.cnindex.com.cn/）。

特此公告。
