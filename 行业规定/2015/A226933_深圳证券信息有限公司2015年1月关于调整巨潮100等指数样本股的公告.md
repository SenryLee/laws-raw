# 深圳证券信息有限公司2015年1月关于调整巨潮100等指数样本股的公告

鉴于宏源证券(000562)即将被申万宏源（000166）吸收合并而退市，深圳证券信息有限公司决定对巨潮100等指数的样本股进行调整，具体为：于2015年1月26日调入申万宏源，调出宏源证券。

本次调整涉及的指数如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 指数名称 | 序号 | 指数名称 |
| 1 | 巨潮1000指数 | 7 | 巨潮大中盘指数 |
| 2 | 巨潮300指数 | 8 | 巨潮周期100指数 |
| 3 | 巨潮100指数 | 9 | 国证保险证券指数 |
| 4 | 巨潮大盘指数 | 10 | 国证证券行业指数 |
| 5 | 巨潮Ａ股指数 | 11 | 新疆综合指数 |
| 6 | 巨潮1000金融 |  |  |

特此公告。
