# 中国测绘学会关于举办信息化测绘新技术培训班的报名通知

## 中国测绘学会关于举办信息化测绘新技术培训班的报名通知（测学发[2008]18号）

各测绘单位：

为了推动我国信息化测绘进程，推广和传播测绘高新技术，我会经与湖北、云南、广东等省学会协商，特邀武汉大学、中国测绘科学研究院的有关院士专家于今年8-12月份连续举办三期《信息化测绘新技术讲座》。具体事宜通知如下：

**一、**培训对象

培训对象主要是全国各级测绘管理部门领导、各级测绘资质单位业务负责人，以及测绘工程技术人员等。

**二、**时间及地点

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 时间 | 地点 | 合办单位 |
| 第1期 | 8月上旬 | 湖北省洪湖市 | 湖北省测绘学会 |
| 第2期 | 10月中旬 | 云南省昆明市 | 云南省测绘学会 |
| 第3期 | 12月中旬 | 广东省珠海市 | 广东省测绘学会 |

具体的时间地点以及乘车路线和是否安排接送站等，在我会收到《报名回执》后，将在办班前半个月通过传真、电子邮件和邮寄等方式确保通知到学员本人。

**三、**授课专家及讲课内容

|  |  |  |
| --- | --- | --- |
| No | 专家姓名 | 讲座题目 |
| 1 | 张继贤（院长、博士） | 关于信息化测绘支撑技术体系建设的报告 |
| 2 | 刘经南（校长、院士） | 连续运行卫星定位服务系统及实时动态测量技术 |
| 3 | 李德仁（院士） | 移动测量技术及其在空间信息服务中的应用 |
| 4 | 刘先林（院士） | 新型国产系列数码相机及其在测绘生产中的应用 |
| 5 | 张祖勋（院士） | 数字摄影测量网格与数字近景摄影测量 |
| 6 | 龚健雅（教授、博士） | 空间数据发布共享与互操手 |
| 7 | 李英成（研究员、博士） | 自主产权超轻型飞机低空数码遥感系统应用 |

**四、**说明事项

1、培训费用。对每期学员统一收取培训费780元/人，另根据具体情况收取会务费；学员食宿费自理。

2、颁证事宜。每期培训班结束，将颁发经国家人事部监制的《继续教育证书》。

3、报名要求。敬请学员务必于2008年5月31日之前，填写附后的《报名回执》，尽可能通过电子邮件或传真发给我会。
