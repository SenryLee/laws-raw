# 深圳证券交易所关于为北京中关村四环医药开发有限责任公司2012年中小企业私募债(第一期)等3只私募债券提供转让服务有关事项的通知

## 深圳证券交易所关于为北京中关村四环医药开发有限责任公司2012年中小企业私募债（第一期）等3只私募债券提供转让服务有关事项的通知

各会员单位：

北京中关村四环医药开发有限责任公司2012年中小企业私募债（第一期）、北京派特罗尔油田服务股份公司2012年中小企业私募债券（第一期）、湖北福星生物科技有限公司2012年中小企业私募债券定于2012年11月30日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、北京中关村四环医药开发有限责任公司2012年中小企业私募债（第一期）证券代码“118024”，证券简称“12四环01”，发行总额11，000万元，票面利率9.50%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、北京派特罗尔油田服务股份公司2012年中小企业私募债券（第一期）证券代码“118026”，证券简称“12派特01”，发行总额10，000万元，票面利率8.00%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

3、湖北福星生物科技有限公司2012年中小企业私募债券证券代码“118030”，证券简称“12福星债”，发行总额30，000万元，票面利率10.50%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。
