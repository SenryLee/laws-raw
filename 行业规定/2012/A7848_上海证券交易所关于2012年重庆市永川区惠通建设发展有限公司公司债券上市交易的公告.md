# 上海证券交易所关于2012年重庆市永川区惠通建设发展有限公司公司债券上市交易的公告

重庆市永川区惠通建设发展有限公司发行的2012年重庆市永川区惠通建设发展有限公司公司债券，将于2012年12月4日起在上海证券交易所交易 市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12永川惠”，证券代码为“122526”。债券上市后可进行质押式回购，质押券申 报和转回代码为“104526”。

上海证券交易所　

二○一二年十二月三日
