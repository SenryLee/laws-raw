# 中国质量协会供销合作系统分会关于表彰2012年度全国供销合作社系统“深入推广质量方法年”活动先进单位的决定

各省、自治区、直辖市、计划单列市、副省级省会城市、新疆生产建设兵团供销合作社质量管理机构，有关供销合作社及企事业单位：

为贯彻落实国家《质量发展纲要》，推进质量强国建设，党中央、国务院要求把推广先进质量管理方法作为提高企业质量管理水平的重要手段，常抓不懈。国家质量监督检验检疫总局、中共中央宣传部等21个部门联合印发了《关于开展2012年全国“质量月”活动的通知》，我会转发了通知并进行部署。

为表彰先进，鼓励和促进深入推广质量方法，结合2012年各地区各单位推荐的质量管理先进单位，深入推广质量管理方法的工作实际，经研究，决定授予中国供销集团等20个单位为：2012年度全国供销合作社系统“深入推广质量方法年”活动先进单位。现予以公布（见附件）。

希望受到表彰的单位再接再厉，努力深入推广质量方法，不断提高产品和服务质量。各地供销合作社应向先进单位学习，取长补短，共同提高，为在我国供销合作社系统推广先进质量方法，推进质量强社强企建设做出新的贡献。

为做好2012年度全国供销合作社系统深入推广质量方法活动先进单位的表彰、宣传工作，经中华全国供销合作总社及有关部门领导同意，拟于今年12月11日在深圳召开“2012年全国供销合作社系统追求卓越会议”（详情请见中国供销合作网http：//www.chinacoop.gov.cn/文件通知），对荣获2012年度全国供销合作社系统“深入推广质量方法年”活动先进单位颁发奖状，所在单位可向有功人员进行奖励。
