# 上海证券交易所关于2012年舟山市定海区国有资产经营有限公司公司债券上市交易的公告

舟山市定海区国有资产经营有限公司发行的2012年舟山市定海区国有资产经营有限公司公司债券，将于2012年10月22日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12定海债”，证券代码为“122554”。债券上市后可进行质押式回购，质押券申报和转回代码为“104554”。

上海证券交易所　

二○一二年十月十九日
