# 中国信托业协会关于中国银监会非银部授权中国信托业协会定期公布行业数据的公告

中国信托业协会关于中国银监会非银部授权中国信托业协会定期公布行业数据的公告

（2012年5月17日）

为了及时、真实地反映信托行业发展状况，避免媒体或社会各类研究机构因信息不足、报道失真而产生的偏差认识，指导行业科学健康发展。加强信托公司的同业交流，方便信托公司及时、准确地掌握行业状况，营造公开公平的信托市场环境，共同推进信托业的健康稳定发展。中国银监会非银行金融机构监管部委托中国信托业协会建立信托行业主要数据指标定期披露制度，每月中旬向社会公布信托业上月月度主要指标数据，每季后的第一个月末公布上一季季度主要指标数据。
