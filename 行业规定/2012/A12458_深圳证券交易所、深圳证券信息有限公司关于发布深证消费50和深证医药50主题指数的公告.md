# 深圳证券交易所、深圳证券信息有限公司关于发布深证消费50和深证医药50主题指数的公告

为反映深市不同主题上市公司的整体表现，提供更丰富的指数化投资标的，满足ETF等指数产品发展的需要，深圳证券交易所和深圳证券信息有限公司决定于2012年8月6日起发布深证消费50和深证医药50主题指数。

两条深证系列主题指数均以2004年12月31日作为基日，以1000点作为基点，具体代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399646 | 深证消费50指数 | 深消费50 | 2004年12月31日 | 1000 |
| 399647 | 深证医药50指数 | 深医药50 | 2004年12月31日 | 1000 |

深证主题指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单等资料参见巨潮指数网（http：//index.cninfo.com.cn）。

特此公告。
