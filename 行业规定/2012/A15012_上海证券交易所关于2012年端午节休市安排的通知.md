# 上海证券交易所关于2012年端午节休市安排的通知

各会员单位：

根据《关于2012年全年休市安排的通知》（上证交字〔2011〕52号），现将2012年端午节休市有关安排通知如下：6月22日（星期五）至6月24日（星期日）休市，6月25日（星期一）起照常开市。请各会员单位据此安排好有关工作。

上海证券交易所　

二○一二年六月四日
