# 上海证券交易所关于2012年浙江省政府债券(一期、二期)上市交易的通知

## 上海证券交易所关于2012年浙江省政府债券（一期、二期）上市交易的通知（上证债字〔2012〕365号）

各会员单位：

根据《财政部关于代理发行2012年浙江省政府债券（一期）有关事宜的通知》（浙财预执[2012]28号）、《财政部关于代理发行2012年浙江省政府债券（二期）有关事宜的通知》（浙财预执[2012]29号）和上海证券交易所（以下简称“本所”）有关规定，2012年浙江省政府债券（一期）和2012年浙江省政府债券（二期）（以下简称“本期债券”）将于2012年9月28日在本所竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期债券为固定利率债券，起息日为2012年9月24日，每年9月24日支付利息（逢节假日顺延，下同），到期日偿还本金并支付最后一次利息；本期债券的期限、票面利率和到期日如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 债券全称 | 期限 | 票面利率 | 到期日 |
| 2012年浙江省政府债券（一期） | 5年 | 3.3% | 2017年9月24日 |
| 2012年浙江省政府债券（二期） | 7年 | 3.47% | 2019年9月24日 |

**二、**本期债券于2012年9月28日起在本所竞价系统和固定收益证券综合电子平台上市，交易方式为现券和回购。

**三、**本期债券上市交易的现券证券简称、证券代码和出入库代码如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 债券全称 | 证券简称 | 证券代码 | 出入库代码 |
| 2012年浙江省政府债券（一期） | 12浙江01 | 130090 | 106090 |
| 2012年浙江省政府债券（二期） | 12浙江02 | 130091 | 106091 |
