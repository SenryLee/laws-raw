# 深圳证券交易所关于深圳市机场股份有限公司2012年公司债券(第一期)等六只公司债券上市交易有关事项的通知

## 深圳证券交易所关于深圳市机场股份有限公司2012年公司债券（第一期）等六只公司债券上市交易有关事项的通知

各会员单位：

深圳市机场股份有限公司2012年公司债券（第一期）、江西万年青水泥股份有限公司2012年公司债券（第一期）、2012年江苏联发纺织股份有限公司公司债券、江苏中泰桥梁钢构股份有限公司2012年公司债券、广东东方锆业科技股份有限公司2012年公司债券、神州学人集团股份有限公司2012年公司债券定于2012年11月20日起在本所集中竞价系统和综合协议交易平台上市交易，现将有关事项通知如下：

1、深圳市机场股份有限公司2012年公司债券（第一期）证券代码“112111”，证券简称“12深机01”，发行总额6亿元，票面利率4.99%，债券期限3年。

2、江西万年青水泥股份有限公司2012年公司债券（第一期）证券代码“112112”，证券简称“12江泥01”，发行总额5亿元，票面利率7.05%，债券期限5年。

3、2012年江苏联发纺织股份有限公司公司债券证券代码“112120”，证券简称“12联发债”，发行总额8亿元，票面利率6.20%，债券期限5年，附第3年发行人上调票面利率选择权和投资者回售选择权。

4、江苏中泰桥梁钢构股份有限公司2012年公司债券证券代码“112116”，证券简称“12中桥债”，发行总额2.5亿元，票面利率7.00%，债券期限5年，附第3年发行人上调票面利率选择权和投资者回售选择权。

5、广东东方锆业科技股份有限公司2012年公司债券证券代码“112110”，证券简称“12东锆债”，发行总额4.9亿元，票面利率7.46%，债券期限7年，附第5年发行人上调票面利率选择权和投资者回售选择权。

6、神州学人集团股份有限公司2012年公司债券证券代码“112117”，证券简称“12福发债”，发行总额4亿元，票面利率7.00%，债券期限6年，附第3年发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所
