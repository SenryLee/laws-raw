# 深圳证券信息有限公司关于发布巨潮华侨城文化产业指数的公告

为反映沪深两市文化产业上市公司的整体表现，凸显文化产业在国民经济中的重要地位，深圳证券信息有限公司定于2012年11月9日发布巨潮华侨城文化产业指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399397 | 巨潮华侨城文化产业指数 | OCT文化 | 2009年6月30日 | 1000 |

巨潮华侨城文化产业指数以沪深两市文化产业上市公司为备选样本，综合考虑市值规模、流动性等因素，选取前50只股票构成指数样本。指数每半年定期调整一次，调整时间为每年 1月和7月的第一个交易日，指数计算中对单个样本设置5%的权重上限。

巨潮华侨城文化产业指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//index.cninfo.com.cn）。
