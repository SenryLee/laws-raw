# 海峡两岸旅游交流协会公告2012年5号——关于暂停福建康泰国际旅行社有限公司赴台旅游业务和通报批评甘肃丝绸之路国际旅行社等3家旅行社的公告

## 海峡两岸旅游交流协会公告（2012年5号）

关于暂停福建康泰国际旅行社有限公司赴台旅游业务和通报批评甘肃丝绸之路国际旅行社等3家旅行社的公告

福建康泰国际旅行社有限公司的赴台旅游团于3月16日发生2名游客脱团滞留；甘肃丝绸之路国际旅行社的赴台旅游团于3月11日发生2名游客脱团滞留，其中1人已于3月21日返回大陆；重庆海外旅业（旅行社）集团有限公司的赴台旅游团于3月11日发生1名游客脱团滞留；湖南华天国际旅行社有限公司的赴台旅游团于3月15日发生1名游客脱团滞留。

依据有关规定，暂停福建康泰国际旅行社有限公司赴台旅游业务一个月（自2012年4月26日至2012年5月25日），暂停期满后按程序申请恢复；通报批评甘肃丝绸之路国际旅行社、重庆海外旅业（旅行社）集团有限公司和湖南华天国际旅行社有限公司。

77

我会重申，赴台旅游是一项意义和责任重大的旅游活动，各省（区、市）的旅游行政管理部门必须会同有关部门认真做好督促、检查、指导工作；各赴台旅游组团社必须严格执行赴台旅游的管理规定，切实采取措施加强对参团游客的审核和证件办理、团队运行管理等工作，保证赴台旅游的安全、质量、秩序和游客权益，维护赴台旅游的有序健康发展。
