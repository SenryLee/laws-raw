# 深圳证券交易所关于广东奥马电器股份有限公司股票上市交易的公告

广东奥马电器股份有限公司人民币普通股股票将于2012年4月16日在本所上市。证券简称为“奥马电器”，证券代码为“002668”。公司人民币普通股股份总数为165，350，000股，其中首次上网定价公开发行的33，100，000股股票自上市之日起开始上市交易。

深圳证券交易所　

二〇一二年四月十二日
