# 深圳证券交易所关于为中科恒源科技股份有限公司2012年中小企业私募债券提供转让服务有关事项的通知

各会员单位：

中科恒源科技股份有限公司2012年中小企业私募债券定于2012年8月31日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

中科恒源科技股份有限公司2012年中小企业私募债券证券代码“118015”，证券简称“12中科债”，发行总额10，000万元，票面利率9.50%，债券期限2年，附第18个月末投资者回售选择权。
