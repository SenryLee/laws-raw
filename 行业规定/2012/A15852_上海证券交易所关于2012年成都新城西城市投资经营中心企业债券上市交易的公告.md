# 上海证券交易所关于2012年成都新城西城市投资经营中心企业债券上市交易的公告

成都新城西城市投资经营中心发行的2012年成都新城西城市投资经营中心企业债券将于2012年5月17日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12蓉新城”，证券代码为“122715”。

上海证券交易所　

二○一二年五月十六日
