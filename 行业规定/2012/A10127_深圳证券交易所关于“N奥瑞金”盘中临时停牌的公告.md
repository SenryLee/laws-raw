# 深圳证券交易所关于“N奥瑞金”盘中临时停牌的公告

“N奥瑞金”（002701）盘中换手率达到或超过50％，根据本所《关于进一步完善首次公开发行股票上市首日盘中临时停牌制度的通知》等有关规定，本所自今日10时18分12秒起对该股实施临时停牌，于11时19分复牌。

本所郑重提示广大投资者注意投资风险，理性投资。

特此公告

深圳证券交易所

2012年10月11日
