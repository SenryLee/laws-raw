# 上海证券交易所关于鲁信创业投资集团股份有限公司2012年公司债券(第一期)上市交易的公告

## 上海证券交易所关于鲁信创业投资集团股份有限公司2012年公司债券（第一期）上市交易的公告

鲁信创业投资集团股份有限公司发行的鲁信创业投资集团股份有限公司2012年公司债券（第一期）将于2012年5月18日起在本所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12鲁信债”，证券代码为“122144”。上市后该债券可进行质押式回购，质押券申报和转回代码为“104144”。
