# 上海证券交易所关于公布2012年度公司治理专项奖评选结果的通知

各上市公司：

为鼓励上市公司加强董事会规范运作，提高信息披露质量，持续提升上市公司治理水平，树立公司治理典范，本所今年继续开展了上市公司治理专项奖评选活动。本年度上市公司治理专项奖共设置两项奖项，分别为“2012年度上市公司董事会奖”和“2012年度上市公司信息披露奖”。

评选工作开展后，经参选上市公司自愿申报参选、申报材料核实、本所评选工作小组初选、对外公示、专家委员会评议和本所总经理办公会议审定，现已评选确定各奖项的获奖公司10名。为了褒扬获奖公司各自在公司治理领域取得的突出成绩，推广、宣传他们的公司治理经验，发挥他们在公司治理建设方面的模范引领作用，现将评奖结果对外公布。各获奖上市公司可对本公司在公司治理实践中做出突出贡献的部门或者个人予以表彰和奖励。

完善的公司治理是上市公司规范运作和做优做强的基本保障。各上市公司应当积极学习和借鉴获奖公司在公司治理方面的先进经验与做法，进一步增强公司治理意识，加强公司治理建设，共同促进资本市场和实体经济的可持续发展。

上海证券交易所　　

二○一二年十二月十九日
