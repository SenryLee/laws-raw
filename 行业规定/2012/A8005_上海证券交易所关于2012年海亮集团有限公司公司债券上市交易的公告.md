# 上海证券交易所关于2012年海亮集团有限公司公司债券上市交易的公告

海亮集团有限公司发行的2012年海亮集团有限公司公司债券，将于2012年11月29日起在上海证券交易所交易市场竞价系统和固定收益证券综合 电子平台上市交易。该债券分两个品种，品种一为6年期，证券简称为“12海亮01 ”，证券代码为“122523”；品种二为7年期，证券简称为“12海 亮02”，证券代码为“122524”。债券上市后可进行质押式回购，其中品种一质押券申报和转回代码为“104523”，品种二质押券申报和转回代码为 “104524”。

上海证券交易所　　

二○一二年十一月二十八日
