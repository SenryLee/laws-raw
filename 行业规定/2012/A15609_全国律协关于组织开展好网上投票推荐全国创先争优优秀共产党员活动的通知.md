# 全国律协关于组织开展好网上投票推荐全国创先争优优秀共产党员活动的通知

各省、自治区、直辖市律师协会，新疆生产建设兵团律师协会：

按照中央部署和要求，今年“七一”前，中央组织部将专项表彰全国创先争优先进基层党组织、优秀共产党员和创先争优活动先进县（市、区、旗）党委，并开展网上投票推荐活动。为扩大广大律师的参与度，充分展示创先争优活动的丰硕成果，激励基层党组织和广大党员履职尽责创先进、立足岗位争优秀，以优异成绩迎接党的十八大胜利召开，全国律协号召各地律师协会组织广大律师开展好网上投票推荐全国创先争优优秀共产党员活动，现将有关事项通知如下：

**一、**活动内容

认真组织广大律师踊跃参加网上投票推荐活动。自5月21日至5月30日，要认真组织广大律师收听收看广播电视新闻，及时了解网上投票推荐活动的意义、内容和要求，认真学习全国创先争优优秀共产党员预备人选的先进事迹。要采取多种方式，对这次投票推荐活动进行广泛深入的宣传，动员和引导广大律师登录在人民网或者新华网开设的投票网页，踊跃参与投票推荐活动。要大力开展学习活动，在学习先进中创先争优。把开展网上投票推荐活动与学习全国创先争优优秀共产党员预备人选先进事迹结合起来，教育引导广大律师党员努力做人民满意的好党员、好律师。要把认真学习全国创先争优优秀共产党员预备人选赵春芳律师的先进事迹，与深入开展“万名律师党员为民服务百日”活动结合起来，通过学习赵春芳律师高尚的职业道德和感人事迹，增强广大律师党员为民服务自觉性，把党的优良传统在律师队伍中发扬光大。

**二、**几点要求

（一）高度重视网上投票推荐活动。各地律师协会要加强领导，精心组织，认真策划，周密部署，切实履行开展网上投票推荐全国创先争优优秀共产党员活动的指导职责；要紧密结合律师行业实际，将其作为创先争优活动的重要载体，采取有力措施，确保投票推荐活动在律师行业富有成效地开展。

（二）严格遵守网上投票推荐规则。为尽量减少废票，要让广大律师全面准确地了解投票推荐程序和规则，引导他们选择人民网或者新华网其中1个网站投票，明确对同一个人选在两个网站同时投票无效。这次网上投票推荐实行实名制，投票人参加投票须填写真实姓名和身份证号码，不填、错填或重填的选票无效。要严格遵守投票规则，坚持自愿投票原则，慎重、正确的投票。

（三）及时掌握网上投票推荐的舆情动态。要密切关注网上投票推荐的情况，及时了解掌握动向。注意收集整理广大律师对于网上投票推荐活动的体会、感言、评论以及意见建议，并及时报全国律协。

二〇一二年五月二十二日
