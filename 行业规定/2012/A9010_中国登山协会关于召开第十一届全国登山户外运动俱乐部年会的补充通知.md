# 中国登山协会关于召开第十一届全国登山户外运动俱乐部年会的补充通知

全国登山户外运动俱乐部及相关从业机构：

本次年会参会人员，分为正式代表和非正式代表，正式代表为委员、注册俱乐部代表（限1人），请在报名时缴纳800元会议费，年会组委会将为正式代表安排食宿及准备相关纪念品。除正式代表外其他为非正式代表，组委会将为非正式代表指定住宿宾馆，也可自行安排住宿，住宿及餐饮费用自理。

特此通知。

中国登山协会　　

二〇一二年十一月七日
