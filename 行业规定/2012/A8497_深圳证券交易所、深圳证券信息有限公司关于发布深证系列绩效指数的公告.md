# 深圳证券交易所、深圳证券信息有限公司关于发布深证系列绩效指数的公告

为反映深圳市场经营绩效良好的上市公司的整体表现，进一步满足指数化投资需求，深圳证券交易所和深圳证券信息有限公司定于2012年11月19日发布4条深证系列绩效指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399655 | 深证绩效指数 | 深证绩效 | 2002年12月31日 | 1000 |
| 399656 | 深证100绩效加权指数 | 100绩效 | 2002年12月31日 | 1000 |
| 399657 | 深证300绩效加权指数 | 300绩效 | 2004年12月31日 | 1000 |
| 399658 | 中小板指绩效加权指数 | 中小绩效 | 2006年12月29日 | 1000 |

深证绩效指数采用近三年的净资产收益率、总资产获现率以及净资产派现率数据，对上市公司经营绩效进行评分，在深圳市场上选取绩效评分较高的100家上市公司构成指数样本股。然后采用分层等权法进行加权计算，即依据绩效评分由高到低，以2：3：5的数量比例将指数样本股划分为3个层级，并以5：3：2的比例依次为各层级分配权重，同一层级内的股票权重相等。深证绩效指数在每年7月份调整样本股，每次调整比例不超过20%。

深证100绩效加权、深证300绩效加权与中小板指绩效加权指数分别采用深证100、深证300与中小板指的样本股，以上述分层等权法进行加权计算。

深证系列绩效指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//index.cninfo.com.cn）。
