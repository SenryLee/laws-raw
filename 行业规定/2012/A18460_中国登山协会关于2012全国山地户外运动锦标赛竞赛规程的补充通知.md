# 中国登山协会关于2012全国山地户外运动锦标赛竞赛规程的补充通知

各省、自治区、直辖市登山协会及户外运动俱乐部、大专院校和相关从业机构：

由国家体育总局批准，国家体育总局登山运动管理中心、浙江省体育局、温州市人民政府主办，温州市体育局承办的2012全国山地户外运动锦标赛将于2012年4月13日-15日在浙江省温州市举办。现将竞赛规程补充内容发给你们，请认真组织，作好参赛工作。

特此通知

附件：2012全国山地户外运动锦标赛竞赛规程补充内容

二〇一二年三月二十七日

竞赛规程（补充内容）

山地户外运动锦标赛经过几年的快速发展，已成为全国性的知名品牌赛事，中国登山协会为进一步推广户外运动在全国的普及发展，吸引更多的户外专业运动员参与此项赛事，增加比赛的激烈、精彩程度。借鉴以前办赛经验，考虑到全国各地参赛选手因水域分布原因而造成的水上皮划艇技能水平的差异，经组委会协商，特安排赛前皮划艇培训。
