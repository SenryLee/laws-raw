# 中国期货业协会关于变更利率及其衍生品市场培训日期的通知

各会员单位：

原定于11月举办的利率及其衍生品市场专项培训班日期因故推迟到12月18日至23日。报名截止日期将顺延至11月9日。培训班报到时间变更为：2012年12月17日15：00-21：00。培训费缴纳截止日期延至11月16日，原培训通知中其余内容不变。

已报名学员的信息有效，如有特殊情况需取消参加培训，请于11月16日前以书面形式说明原因并由所在单位加盖公章传真至010-88087060。如有疑问，请联系：010-88086646 张女士；010-88087217 朱先生。

特此通知。

中国期货业协会
