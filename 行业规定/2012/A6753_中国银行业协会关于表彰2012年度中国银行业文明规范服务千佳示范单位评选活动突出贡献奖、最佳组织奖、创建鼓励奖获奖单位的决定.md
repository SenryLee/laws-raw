# 中国银行业协会关于表彰2012年度中国银行业文明规范服务千佳示范单位评选活动突出贡献奖、最佳组织奖、创建鼓励奖获奖单位的决定

## 中国银行业协会关于表彰2012年度中国银行业文明规范服务千佳示范单位评选活动突出贡献奖、最佳组织奖、创建鼓励奖获奖单位的决定（银协发[2012]100号）

各会员单位：

2012年度中国银行业文明规范服务千佳示范单位评选活动开展以来，各会员银行扎实推动、大力支持，各地方银行业协会及时响应、严密部署，各银行业金融机构全员参与、积极创建，在完善服务管理、优化网点布局、增加服务设施、创新金融产品、梳理业务流程、加强制度保障、规范服务行为等方面均取得了明显的进步，诚信自律不断加强，服务文化不断深化，文明规范服务水平得到显著提升。

为表彰和鼓励在本年度创建评选活动中表现突出的会员银行、地方银行业协会及有关银行业金融机构，充分发挥先进典型的示范引领作用，经中国银行业协会自律工作委员会第三届常务委员会第四次会议审议通过，现决定授予中国农业银行等10家单位（名单见附件1）“2012年度中国银行业文明规范服务千佳示范单位评选活动突出贡献奖”，授予四川省银行业协会等10家单位（名单见附件2）“2012年度中国银行业文明规范服务千佳示范单位评选活动最佳组织奖”，授予中国银行长沙市望城坡支行等10家单位（名单见附件3）“2012年度中国银行业文明规范服务千佳示范单位评选活动创建鼓励奖”。

希望获奖单位珍惜荣誉，再接再厉，发挥模范表率作用，推广传播先进经验，不断改进和深化服务工作。希望各银行业金融机构认真学习、充分借鉴获奖单位的先进经验，认真践行行业服务规范，持续提升服务质量和效率，为推动中国银行业文明规范服务事业蓬勃发展，构建和谐金融环境做出新贡献。

附件：1. 2012年度中国银行业文明规范服务千佳示范单位评选活动突出贡献奖名单

2.2012年度中国银行业文明规范服务千佳示范单位评选活动最佳组织奖名单

3.2012年度中国银行业文明规范服务千佳示范单位评选活动创建鼓励奖名单

二O一二年十二月二十五日
