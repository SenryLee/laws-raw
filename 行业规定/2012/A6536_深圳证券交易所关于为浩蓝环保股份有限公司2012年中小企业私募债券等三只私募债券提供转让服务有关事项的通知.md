# 深圳证券交易所关于为浩蓝环保股份有限公司2012年中小企业私募债券等三只私募债券提供转让服务有关事项的通知

各会员单位：

浩蓝环保股份有限公司2012年中小企业私募债券、广东新大禹环境工程有限公司2012年中小企业私募债券、佛山市建通混凝土制品有限公司2012年中小企业私募债券定于2012年12月28日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、浩蓝环保股份有限公司2012年中小企业私募债券证券代码“118032”，证券简称“12浩蓝债”，发行总额5，000万元，票面利率10.00%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、广东新大禹环境工程有限公司2012年中小企业私募债券证券代码“118035”，证券简称“12新大禹”，发行总额5，000万元，债券期限2年，票面利率为基准利率与基本利差之和，基本利差为7.00%，基准利率为发行首日和其他各计息年度的起息日适用的中国人民银行公布的一年期整存整取定期储蓄存款利率。

3、佛山市建通混凝土制品有限公司2012年中小企业私募债券证券代码“118037”，证券简称“12建通债”，发行总额15，000万元，票面利率7.40%，债券期限3年。

深圳证券交易所　　

二○一二年十二月二十七日
