# 上海证券交易所关于2012年大秦铁路股份有限公司公司债券(第一期)上市交易的公告

## 上海证券交易所关于2012年大秦铁路股份有限公司公司债券（第一期）上市交易的公告

大秦铁路股份有限公司发行的2012年大秦铁路股份有限公司公司债券（第一期），将于2012年12月27日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12大秦债”，证券代码为“122214”。债券上市后可进行质押式回购，质押券申报和转回代码为“104214”。

上海证券交易所　　

二○一二年十二月二十六日
