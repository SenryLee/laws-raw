# 上海证券交易所关于2012年记账式贴现(七期)国债上市交易的通知

## 上海证券交易所关于2012年记账式贴现（七期）国债上市交易的通知

各会员单位：

根据《财政部关于2012年记账式贴现（七期）国债发行工作有关事宜的通知》（财库[2012]145号）和上海证券交易所（以下简称“本所”）有关规定，2012年记账式贴现（七期）国债（以下简称“本期国债”）将于2012年10月26日在本所集中竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期国债期限为91天，以低于票面金额的价格贴现发行，发行价格99.289元；本期国债起息日为2012年10月22日，2013年1月21日（节假日顺延）按面值偿还。

**二、**本期国债于2012年10月26日起在本所集中竞价系统和固定收益证券综合电子平台上市，交易方式为现券和回购。

**三、**本期国债上市交易的现券证券名称为“12贴债07”，证券代码为“020057”，出入库代码为“107057”。

上海证券交易所　　

二○一二年十月二十六日
