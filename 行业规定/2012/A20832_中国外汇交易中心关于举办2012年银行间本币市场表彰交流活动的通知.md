# 中国外汇交易中心关于举办2012年银行间本币市场表彰交流活动的通知

## 中国外汇交易中心关于举办2012年银行间本币市场表彰交流活动的通知（中汇交发〔2012〕24号）

银行间本币市场交易100强机构：

为表彰先进、促进交流，推动银行间本币市场持续健康发展，全国银行间同业拆借中心（以下简称“交易中心”）定于2012年3月2日至3日在海南省三亚市举办2012年银行间本币市场表彰交流活动。现将有关事项通知如下：

**一、**会议内容

（一）总结银行间本币市场交易发展情况，交流工作设想；

（二）表彰2011年度银行间本币市场获奖机构和个人；

（三）组织交易成员间的交流活动。

**二、**参会人员

请2011年度银行间本币市场交易100强机构委派一名代表参会（优秀交易主管等另行通知参会）。2011年度银行间本币市场交易100强名单请至“中国货币网”查询。（为保证办会质量，本此会议将严格控制参会人数。感谢配合！）

**三、**会议时间和地点

（一）会议时间：2012年3月2日至3日，会期两天，会议报到日为3月1日；

（二）会议地点：三亚万豪度假酒店（地址：海南省三亚市亚龙湾国家旅游度假区；电话：0898-88568888）。

**四、**会务费用

会务费用为每人3800元，往返交通费用自理。

本此会议由三亚万豪度假酒店代理收取会务费用、开具发票。

**五、**注意事项

（一）交易中心于报到日安排在三亚凤凰机场接机。乘坐其他交通工具以及因故早到和晚到的参会人员请自行前往酒店报到；

（二）请于2月22日12：00前将参会人员名单回执传真至交易中心市场二部。
