# 上海证券交易所关于上海交运集团股份有限公司2012年公司债券上市交易的公告

上海交运集团股份有限公司发行的上海交运集团股份有限公司2012年公司债券，将于2012年12月7日起在上海证券交易所交易市场竞价系统和固 定收益证券综合电子平台上市交易。该债券证券简称为“12沪交运”，证券代码为“122205”。债券上市后可进行质押式回购，质押券申报和转回代码为 “104205”。

上海证券交易所　

二○一二年十二月六日
