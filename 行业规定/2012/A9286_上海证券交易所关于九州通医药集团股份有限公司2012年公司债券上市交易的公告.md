# 上海证券交易所关于九州通医药集团股份有限公司2012年公司债券上市交易的公告

九州通医药集团股份有限公司发行的九州通医药集团股份有限公司2012年公司债券，将于2012年11月1日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12九州通”，证券代码为“122182”。债券上市后可进行质押式回购，质押券申报和转回代码为“104182”。

上海证券交易所　　

二○一二年十月三十一日
