# 中国林学会关于召开第四届中国森林保护学术大会的第一轮通知

各省、自治区、直辖市林业厅（局）、林学会，中国林学会各分会、专业委员会，各有关单位和专家：

中国森林保护学术大会自2006年8月首次在新疆召开以来，迄今成功举办了三届，已成为我国森林保护领域高层次的学术交流平台，有力促进了森林保护科技进步，为推进森林保护学科和森林保护事业的发展作出了积极贡献。为进一步加强森林保护学科的学术交流，推进我国森林保护学科和森林保护事业的健康发展，促进绿色增长，经研究，中国林学会定于2012年8月3～5日在哈尔滨市召开第四届中国森林保护学术大会。现就会议有关事项通知如下：

**一、**大会主题及主要议题

本次大会的主题是：绿色森保--实现森林有害生物的可持续控制。

大会的主要议题包括：

（一）有害生物分子生物学；

（二）森林有害生物生态控制；

（三）森林有害生物生物防治；

（四）森林有害生物化学防治及其防治机械化；

（五）林业外来有害生物。

**二、**大会组织单位

主办单位：中国林学会

承办单位：东北林业大学、中国林学会森林病理分会、中国林学会森林昆虫分会、黑龙江省林学会

协办单位：中国林科院、北京林业大学、南京林业大学、国家林业局森林病虫害防治总站。

**三、**大会时间及地点

大会时间：2012年8月3～5日，8月3日全天报到。

大会地点：东北林业大学，会议宾馆为东北林业大学专家公寓（三星）和哈尔滨理工大厦（四星级）。

**四、**报名及征文

（一）会议报名

参会代表需填写报名表（见附件），报名截止日期为2012年7月10日，请在截止日期前将报名表发电子邮件或传真至东北林业大学林学院。

（二）会议征文

征文内容：会议根据大会主题和主要议题面向社会征集论文。提交的论文需反映近年来我国森林有害生物领域的有关研究成果，包括新理论、新发现、新技术、新方法、新学术思想等。论文可以是研究论文或文献综述，摘要应不少于800字。

征文要求：论文格式按《林业科学》统一要求（见《林业科学》征稿启事）进行排版，论文或摘要的电子版发送给东北林业大学林学院，征文截止日期6月30日。
