# 中国证券登记结算有限责任公司关于2012年清明节休市期间证券资金清算交收安排的通知

各结算单位：

根据《关于2012年部分节假日休市期间证券资金清算交收安排的通知》，现将2012年清明节休市期间资金清算交收安排通知如下：

**一、**2012年3月30日发生的证券交易（B股除外）和当日到期的债券回购，资金清算日为2012年3月30日，资金交收日为2012年4月5日。

**二、**2012年4月5日发生的证券交易（B股除外）和年3月31日-4月5日到期的债券回购，资金清算日为2012年4月5日，资金交收日为2012年4月6日。

**三、**2012年3月28日、29日、30日发生的B股交易，上海市场资金交收日依次为2012年4月5日、6日、9日；深圳市场资金交收日依次为2012年4月5日、10日、10日。

中国证券登记结算有限责任公司

二○一二年三月二十三日
