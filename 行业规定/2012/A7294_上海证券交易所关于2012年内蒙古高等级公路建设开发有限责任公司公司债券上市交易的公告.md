# 上海证券交易所关于2012年内蒙古高等级公路建设开发有限责任公司公司债券上市交易的公告

内蒙古高等级公路建设开发有限责任公司发行的2012年内蒙古高等级公路建设开发有限责任公司公司债券，将于2012年12月14日起在上海证券 交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12蒙高路”，证券代码为“124002”。债券上市后可进行质押式回 购，质押券申报和转回代码为“103002”。

上海证券交易所　　

二○一二年十二月十三日
