# 深圳证券交易所关于江苏洋河酒厂股份有限公司股票临时停牌的公告(2012)

## 深圳证券交易所关于江苏洋河酒厂股份有限公司股票临时停牌的公告

江苏洋河酒厂股份有限公司于2012年8月22日召开股东大会，经公司申请，公司股票（证券简称：洋河股份，证券代码：002304）于2012年8月22日开市起停牌，待公司通过指定媒体披露股东大会决议公告后复牌，敬请投资者密切关注。

深圳证券交易所

2012年8月22日
