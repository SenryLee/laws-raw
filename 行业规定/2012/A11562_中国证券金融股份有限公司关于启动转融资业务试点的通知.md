# 中国证券金融股份有限公司关于启动转融资业务试点的通知

各试点证券公司：

经中国证监会批准，中国证券金融股份有限公司将于2012年8月30日起正式启动转融资业务试点。

请贵公司认真做好转融资交易相关操作流程、技术系统（包括交易、结算、监控系统等）、业务组织管理等准备工作，对账户管理、交易申报、清算交收等业务环节进行认真检查，确保业务顺利启动和安全运行，加强转融资业务的内控和风险管理，遇有问题及时妥善处理，并即时知会我公司。

特此通知。

中国证券金融股份有限公司

二○一二年八月二十九日
