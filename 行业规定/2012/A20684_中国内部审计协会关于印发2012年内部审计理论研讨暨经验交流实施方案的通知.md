# 中国内部审计协会关于印发2012年内部审计理论研讨暨经验交流实施方案的通知

## 中国内部审计协会关于印发2012年内部审计理论研讨暨经验交流实施方案的通知（中内协发〔2012〕6号）

各会员单位：

现将《中国内部审计协会2012年内部审计理论研讨暨经验交流实施方案》印发给你们，请结合实际情况认真组织实施。执行中如有问题，请与中国内部审计协会准则与学术部联系。

附件：中国内部审计协会2012年内部审计理论研讨暨经验交流实施方案

中国内部审计协会　

二○一二年二月十四日

附件：

中国内部审计协会2012年内部审计理论研讨暨经验交流实施方案

为了总结和交流实践中的先进经验，加强实务工作和理论研究的紧密结合，根据《中国内部审计协会2012年工作计划》，经协会研究，现对2012年内部审计理论研讨暨经验交流工作安排如下。

**一、**理论研讨暨经验交流的内容

2012年理论研讨暨经验交流的主题为“内部审计质量管理”。本题目要求立足内部审计实践，认真总结近年来内部审计机构在加强内部审计质量管理方面采取的各项措施或开展的各项工作，理论联系实际，深入研究实践中的成熟经验和遇到的问题，探讨今后如何更好地开展内部审计质量管理工作，进一步提升内部审计质量水平。

研讨的具体内容包括但不限于以下方面：内部审计质量管理的涵义和内容；内部审计质量管理方面的制度建设情况；内部审计质量管理的具体措施和方法；开展内部审计质量评估的做法及效果；内部审计质量管理工作对人员素质和能力的要求；内部审计质量管理存在的问题及解决途径等。论文题目可参考上述内容自定。

**二、**研讨组织要求

（一）为保证研讨交流活动的质量，各省、自治区、直辖市和计划单列市内部审计（师）协会，中国内部审计协会各分会，中央部门和直属机构较多的企事业单位，要广泛宣传，认真部署，组织多种形式的研讨与交流。

（二）各单位在开展研讨活动时要制定详细的研讨计划和实施方案，成立课题组，认真选题，深入调研，结合实际提出理论观点并加以分析论证，提交理论和实践意义较强的论文参加研讨和交流。

**三、**推荐论文和经验交流材料的要求

（一）各省、自治区、直辖市和计划单列市内部审计（师）协会，中国内部审计协会各分会，中央部门和直属机构较多的企事业单位要对推荐的论文或经验交流材料严格审核、把关，推荐论文数量不超过4篇（多报的论文将被退回），经验交流材料1篇；其他单位推荐论文或经验交流材料1篇。

（二）请各单位于2012年6月30日之前将论文报送中国内部审计协会准则与学术部。每份论文要求报送10份纸质材料和1份电子文档（发送电子邮件至sa.ciia@163.com）。

（三）论文具体要求可登录中国内部审计协会网站www.ciia.com.cn“学术”栏目查阅《中国内部审计协会论文评选办法》。

**四、**评选组织奖的要求

为鼓励各省、自治区、直辖市和计划单列市内部审计（师）协会，中国内部审计协会各分会，直属机构较多的中央部门和中央企事业单位积极组织开展研讨活动，中国内部审计协会设立组织奖，对严格组织、精心遴选、成果突出的单位予以表彰。参与评选的单位必须完整填写《优秀论文推荐表》（附后）并与论文一并报送。

**五、**研讨时间安排

本次理论研讨活动拟于2012年10月召开全国研讨会，具体时间和地点另行通知。
