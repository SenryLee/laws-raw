# 中国资产评估协会关于资产评估行业深入学习贯彻党的十八大精神的通知

## 中国资产评估协会关于资产评估行业深入学习贯彻党的十八大精神的通知（中评协[2012]227号）

各省、自治区、直辖市、计划单列市资产评估协会（注册会计师协会），各证券业评估机构：

党的十八大是在我国进入全面建成小康社会决定性阶段召开的一次十分重要的大会。这是一次高举旗帜的大会、继往开来的大会、团结奋进的大会。全面、深入、系统地学习宣传贯彻党的十八大精神，把思想统一到党的十八大精神上来，从新的历史起点出发，求真务实、开拓创新，更好地发挥评估行业的职能作用，为完成党的十八大确定的各项任务而努力奋斗，是当前和今后一个时期各级党组织和全体党员的首要政治任务。

根据中央国家机关工委和部党组要求，为深入贯彻落实《关于深入学习贯彻党的十八大精神的通知》（财党委[2012]78号）精神，中国资产评估协会结合《中国资产评估行业发展规划》，印发资产评估行业深入学习贯彻党的十八大精神的通知，请各地方协会和评估机构遵照执行。

**一、**充分认识学习宣传贯彻党的十八大精神的重大意义

胡锦涛同志所作的报告，高举中国特色社会主义伟大旗帜，分析了国际国内形势发展变化，回顾总结了过去五年的工作和党的十六大以来的奋斗历程及取得的历史性成就，确立了科学发展观的历史地位，提出了夺取中国特色社会主义建设新胜利的基本要求，确定了全面建成小康社会和全面深化改革开放的目标，对新的时代条件下推进中国特色社会主义事业作出了全面部署，对全面提高党的建设科学化水平提出了明确要求。报告描绘了全面建成小康社会、加快推进社会主义现代化的宏伟蓝图，为党和国家事业进一步发展指明了方向，是我们党团结带领全国各族人民夺取中国特色社会主义新胜利的政治宣言和行动指南，是马克思主义的纲领性文献。

财政作为党和政府履行职能的物质基础、体制保障、政策工具和监管手段，在国家政权中处于重要地位，资产评估行业作为财政部主管的现代中介服务行业，广泛深入参与我国社会、经济、生态、政治文化等领域的改革和发展，及时深入学习贯彻十八大精神关系到中央精神和时政政策的顺利实施，也关系到评估行业发展规划的顺利实施，希望各地方协会和评估机构深入学习贯彻党的十八大精神，把握十八大报告的精神实质。

**二、**全面准确地领会把握党的十八大基本精神

中国资产评估协会作为资产评估行业的管理者，是推动行业发展的重要力量，也是党在全行业贯彻方针政策的重要纽带和督导者。中评协党委组织全体党员干部紧紧围绕十八大主题，原原本本学习十八大报告和新修改的党章，结合行业发展规划，全面领会、准确把握党的十八大精神实质。

（一）全面准确地领会把握中国特色社会主义的丰富内涵和基本要求。充分认识中国特色社会主义是当代中国发展进步的根本方向，只有中国特色社会主义才能发展中国，全面建成小康社会、加快推进社会主义现代化、实现中华民族的伟大复兴，必须坚定不移走中国特色社会主义道路。充分认识建设中国特色社会主义的总依据是社会主义初级阶段，总布局是五位一体，总任务是实现社会主义现代化和中华民族伟大复兴，基本要求是必须坚持人民主体地位，必须坚持解放和发展社会生产力，必须坚持推进改革开放，必须坚持维护社会公平正义，必须坚持走共同富裕道路，必须坚持促进社会和谐，必须坚持和平发展，必须坚持党的领导。

（二）全面准确地领会把握科学发展观的历史地位和精神实质。深刻领会科学发展观是中国特色社会主义理论体系最新成果，开辟了当代马克思主义发展新境界，是中国共产党集体智慧的结晶，是指导党和国家全部工作的强大思想武器，同马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想一道，是党必须长期坚持的指导思想。更加自觉地把推动经济社会发展作为深入贯彻落实科学发展观的第一要义，更加自觉地把以人为本作为深入贯彻落实科学发展观的核心立场，更加自觉地把全面协调可持续作为深入贯彻落实科学发展观的基本要求，更加自觉地把统筹兼顾作为深入贯彻落实科学发展观的根本方法，把科学发展观贯彻到我国现代化建设全过程、体现到党的建设各方面。

（三）全面准确地领会把握过去五年的工作和党的十六大以来的奋斗历程及辉煌成就。全面把握党的十七大以来的五年是我们在中国特色社会主义道路上奋勇前进的五年，是我们经受住各种困难和风险考验、夺取全面建设小康社会新胜利的五年，各方面工作都取得新的重大成就。全面把握党的十六大以来我们党带领人民紧紧抓住和用好我国发展的重要战略机遇期，战胜一系列重大挑战，奋力把中国特色社会主义推进到新的发展阶段，巩固和发展了改革开放和社会主义现代化建设大局，提高了我国国际地位，彰显了中国特色社会主义的巨大优越性和强大生命力，增强了中国人民和中华民族的自豪感和凝聚力。

（四）全面准确地领会把握全面建成小康社会和全面深化改革开放的目标任务和总体布局。深刻领会要在党的十六大、十七大确立的全面建设小康社会目标的基础上努力实现新的要求：经济持续健康发展，人民民主不断扩大，文化软实力显著增强，人民生活水平全面提高，资源节约型、环境友好型社会建设取得重大进展。全面把握我国社会主义经济建设、政治建设、文化建设、社会建设、生态文明建设的总体部署，加快完善社会主义市场经济体制和加快转变经济发展方式，坚持走中国特色社会主义发展道路和推进政治体制改革，扎实推进社会主义文化强国建设，在改善民生和创新管理中加强社会建设，大力推进生态文明建设。

（五）全面准确地领会把握全面提高党的建设科学化水平的总体要求和根本任务。牢牢把握加强党的执政能力建设、先进性和纯洁性建设这条主线，坚持以人为本、执政为民，坚持解放思想、改革创新，坚持党要管党、从严治党，全面加强党的思想建设、组织建设、作风建设、反腐倡廉建设、制度建设，增强自我净化、自我完善、自我革新、自我提高能力，建设学习型、服务型、创新型的马克思主义执政党，确保党始终成为中国特色社会主义事业的坚强领导核心。务必增强忧患意识，始终保持清醒头脑；务必增强创新意识，始终保持奋发有为的精神状态；务必增强宗旨意识，始终把人民放在心中最高位置；务必增强使命意识，始终保持共产党人的政治本色。

**三、**紧密联系评估行业发展规划及工作实际，切实抓好党的十八大精神贯彻落实工作

评估行业要以高度的政治自觉和责任意识，紧密联系评估工作实际，紧密联系党员干部思想实际，把用党的十八大精神武装头脑、指导实践、推动工作作为学习宣传贯彻党的十八大精神的出发点和落脚点，作为衡量学习贯彻成效的重要标准。

（一）把思想认识切实统一到十八大精神上来，进一步增强做好评估工作的使命感和责任感。要引导党员干部毫不动摇地以邓小平理论、“三个代表”重要思想、科学发展观为指导，坚定不移沿着中国特色社会主义道路前进，努力为实现全面建成小康社会目标贡献智慧和力量；坚决维护中央权威，在思想上政治上行动上始终与党中央保持高度一致；坚决贯彻中央决策部署，做到讲政治、顾大局、守纪律；清醒认识科学发展观对评估工作的新要求，深入思考评估工作贯彻落实党的十八大精神的历史责任，明确目标任务，提高做好工作的主动性、自觉性。

（二）以改革创新精神，推动解决评估行业发展与改革中的突出问题。要认真总结评估行业改革与发展的成就与经验，落实科学发展观基本要求，进一步理清工作思路，明确近期的目标任务，把十八大精神转化为具体的政策措施，埋头苦干，扎实工作，扎实推进新形势下评估行业发展与改革，努力完成时代赋予的崇高使命。要对照十八大报告认真开展自查，重点查找、梳理思想认识上存在的差距，特别是认真查找不适应不符合科学发展观要求的突出问题，认真查找业务工作中存在的突出问题和薄弱环节，明确改进方向。

（三）落实先进性和纯洁性要求，要以思想理论建设为根本，以党性教育为核心，以道德建设为基础，着力用马克思主义最新成果武装党员干部头脑，指导实践，使广大党员、干部成为实践社会主义核心价值观的模范，成为正确对待和运用手中权力为民服务的模范，成为艰苦奋斗、负责敬业的模范。

（四）积极探索实践，全面提高党的建设科学化水平。要按照党的十八大对党的建设新要求，认真研究机关及评估行业党建新情况，采取新措施，建立新机制，以建设一流队伍、培养一流作风、创造一流业绩为目标，进一步创新工作载体、丰富活动内容与形式，不断提高党建工作水平。

**四、**精心组织，抓好落实

（一）各地方协会要按照通知要求，抓好落实工作，从本单位实际出发，紧紧围绕十八大报告主题，研究制订学习贯彻党的十八大精神的具体实施方案，并于2012年12月25日前报送中评协党办。同时，要迅速、真实、全面地把活动的最新进展情况、特色、学习体会等内容形成文字，及时报送中评协党办。

（二）各评估机构要在地方协会党组织领导下，积极有效地开展学习贯彻活动。同时，要及时总结学习宣传贯彻十八大精神中的经验、做法、问题，将有关情况报送地方协会党组织，证券业机构同时报送中国资产评估协会党办。

中国资产评估协会将采取刊物、报纸、网络等多种方式进行宣传，以促进学习交流，推动全行业深入学习贯彻党的十八大精神。
