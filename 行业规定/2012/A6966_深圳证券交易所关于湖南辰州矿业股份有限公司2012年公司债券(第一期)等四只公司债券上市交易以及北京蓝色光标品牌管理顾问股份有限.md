# 深圳证券交易所关于湖南辰州矿业股份有限公司2012年公司债券(第一期)等四只公司债券上市交易以及北京蓝色光标品牌管理顾问股份有限公司2012年公司债券(第一期)进行转让的通知

## 深圳证券交易所关于湖南辰州矿业股份有限公司2012年公司债券（第一期）等四只公司债券上市交易以及北京蓝色光标品牌管理顾问股份有限公司2012年公司债券（第一期）进行转让的通知

各会员单位：

湖南辰州矿业股份有限公司2012年公司债券（第一期）、辽宁华锦通达化工股份有限公司2012年公司债券、厦门合兴包装印刷股份有限公司2012年公司债券证券定于2012年12月24日起在本所集中竞价系统和综合协议交易平台上市交易，徐工集团工程机械股份有限公司2011年公司债券（第二期）定于2012年12月25日起在本所集中竞价系统和综合协议交易平台上市交易，北京蓝色光标品牌管理顾问股份有限公司2012年公司债券定于2012年12月24日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、湖南辰州矿业股份有限公司2012年公司债券（第一期）证券代码“112128”，证券简称“12辰矿01”，发行总额5亿元，票面利率5.70%，债券期限7年期，附第5年末发行人上调票面利率选择权和投资者回售选择权。

2、辽宁华锦通达化工股份有限公司2012年公司债券证券代码“112129”，证券简称“12辽通债”，发行总额27亿元，票面利率5.60%债券期限5年期。

3、厦门合兴包装印刷股份有限公司2012年公司债券证券代码“112134”，证券简称“12合兴债”，发行总额3亿元，票面利率6.25%，债券期限5年期，附第3年末发行人上调票面利率选择权和投资者回售选择权。

4、徐工集团工程机械股份有限公司2011年公司债券（第二期）证券代码“112124”，证券简称“11徐工02”，发行总额15亿元，票面利率4.89%，债券期限5年期，附第3年末发行人上调票面利率选择权和投资者回售选择权。

5、北京蓝色光标品牌管理顾问股份有限公司2012年公司债券（第一期）证券代码“112135”，证券简称：12蓝标01，发行总额2亿元，票面利率7.90%，债券期限3年期。
