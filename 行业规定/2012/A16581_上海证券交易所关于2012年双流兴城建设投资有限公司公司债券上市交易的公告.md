# 上海证券交易所关于2012年双流兴城建设投资有限公司公司债券上市交易的公告

双流兴城建设投资有限公司发行的2012年双流兴城建设投资有限公司公司债券将于2012年5月4日起在本所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券分为品种一和品种二，其中品种一证券简称为“12双流01”，证券代码为“122698”；品种二证券简称为“12双流02”，证券代码为“122699”。

上海证券交易所　

二○一二年五月三日
