# 深圳证券交易所关于北京湘鄂情股份有限公司2012年公司债券等七只公司债券上市交易有关事项的通知

各会员单位：

北京湘鄂情股份有限公司2012年公司债券、福建三钢闽光股份有限公司2011年公司债券（第二期）、安徽华茂纺织股份有限公司2012年公司债券、雅致集成房屋股份有限公司2012年公司债券发行的两只债券、张家港化工机械股份有限公司2012年公司债券、2012 年山西太钢不锈钢股份有限公司公司债券（第一期）定于2012年5月15日起在本所集中竞价系统和综合协议交易平台上市交易，现将有关事项通知如下：

1、北京湘鄂情股份有限公司2012年公司债券证券代码“112072”，证券简称“12湘鄂债”，发行总额4.8亿元，票面利率6.78%，债券期限5年，附第3年发行人上调票面利率选择权和投资者回售选择权。

2、福建三钢闽光股份有限公司2011年公司债券（第二期）证券代码“112073”，证券简称“11三钢02”，发行总额4亿元，票面利率6.88%，债券期限7年，附第5年发行人上调票面利率选择权和投资者回售选择权。

3、安徽华茂纺织股份有限公司2012年公司债券证券代码“112074”，证券简称“12华茂债”，发行总额8.4亿元，票面利率6.30%，债券期限5年，附第3年发行人赎回选择权、发行人上调票面利率选择权和投资者回售选择权。

4、雅致集成房屋股份有限公司2012年公司债券的两个品种：品种一证券代码“112075”，证券简称“12雅致01”，发行总额3亿元，票面利率6.50%，债券期限5年，附第3年发行人上调票面利率选择权和投资者回售选择权；品种二证券代码“112076”，证券简称“12雅致02”，发行总额5亿元，票面利率6.70%，债券期限7年，附第5年发行人上调票面利率选择权和投资者回售选择权。

5、张家港化工机械股份有限公司2012年公司债券证券代码“112077”，证券简称“12化机债”，发行总额7亿元，票面利率7.00%，债券期限5年，附第3年发行人上调票面利率选择权和投资者回售选择权。

6、2012 年山西太钢不锈钢股份有限公司公司债券（第一期）证券代码“112078”，证券简称“12太钢01”，发行总额25亿元，票面利率5.20%，债券期限5年。

深圳证券交易所
