# 上海证券交易所关于2012年濮阳市建设投资公司企业债券上市交易的公告

濮阳市建设投资公司发行的2012年濮阳市建设投资公司企业债券，将于2013年1月4日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12濮建投”，证券代码为“124046”。债券上市后可进行质押式回购，质押券申报和转回代码为“103046”。

上海证券交易所　　

二○一二年十二月三十一日
