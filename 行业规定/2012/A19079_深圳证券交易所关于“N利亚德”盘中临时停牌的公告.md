# 深圳证券交易所关于“N利亚德”盘中临时停牌的公告

“N利亚德”（300296）盘中成交价较开盘价首次上涨达到或超过10%，根据本所《关于完善首次公开发行股票上市首日盘中临时停牌制度的通知》等有关规定，本所自今日09时36分25秒起对该股实施临时停牌，于14时57分复牌。

本所郑重提示广大投资者注意投资风险，理性投资。

特此公告

深圳证券交易所　

二○一二年三月十五日
