# 中国银行业协会关于《中国银行业改革发展与风险防范案例选编》投票评选的公告

各会员单位：

由我会联合中国银监会党校和党委组织部共同组织编写的《中国银行业改革发展与风险防范案例选编》一书，参加了由中央组织部、新闻出版总署和国家图书馆联合举办的首次全国党员教育培训教材展示交流活动。经专家评审，已入围获奖教材，并在共产党员网站（www.12371.cn）上公布。

根据中央组织部通知，请各会员单位协助组织本单位党员于11月4日前访问http：//www.12371.cn/special/djpj/youxiu/349/index.shtml参与投票评选。
