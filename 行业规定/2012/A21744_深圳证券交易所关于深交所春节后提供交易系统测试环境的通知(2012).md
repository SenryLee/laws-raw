# 深圳证券交易所关于深交所春节后提供交易系统测试环境的通知(2012)

## 深圳证券交易所关于深交所春节后提供交易系统测试环境的通知

各会员单位：

为做好春节后的交易运行工作，我所拟于2012年1月29日提供交易系统测试环境，供会员及相关单位进行联机测试，检验长假后技术系统的准备情况。现将有关事项通知如下：

1.测试时间为2012年1月29日（星期日）09：30至11：30。其中，09：30至11：15为集中竞价交易时间，11：15至11：30为综合协议平台交易时间。

2.此次测试以2012年1月20日（星期五）深市所有证券的收盘行情、收市后的股份数据作为起始数据。

3.此次测试不发送任何结算数据及文件。

4.2012年1月29日中国结算深圳分公司实时开户生产系统暂停服务。

5.各参测单位测试前必须做好系统的备份，测试完成后，做好系统和数据的恢复工作，确保春节后首个交易日的交易正常安全进行。

6.本次测试的数据仅为模拟测试数据，不能作为生产环境任何交易、非交易等业务的依据。
