# 上海证券交易所关于2012年记账式附息(十八期)国债上市交易的通知

## 上海证券交易所关于2012年记账式附息（十八期）国债上市交易的通知（上证债字〔2012〕371号）

各会员单位：

根据《财政部关于2012年记账式附息（十八期）国债发行工作有关事宜的通知》（财库[2012]142号）和上海证券交易所（以下简称“本所”）有关规定，2012年记账式附息（十八期）国债（以下简称“本期国债”）将于2012年10月8日在本所集中竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下。

**一、**本期国债为固定利率附息债，期限为20年，票面利率为4.1%，利息每半年支付一次；本期国债起息日为2012年9月27日，每年3月27日、9月27日（节假日顺延，下同）支付利息，2032年9月27日偿还本金并支付最后一次利息。

**二、**本期国债于2012年10月8日起在本所集中竞价系统和固定收益证券综合电子平台上市，交易方式为现券和回购。

**三、**本期国债上市交易的现券证券名称为“12国债18”，证券代码为“019218”，出入库代码为“091043”。

上海证券交易所　　

二○一二年九月二十八日
