# 上海证券交易所关于开展上海证券交易所上市公司2012年度董事会奖和信息披露奖评选工作的通知

各上市公司：

为鼓励上海证券交易所（以下简称“本所”）上市公司加强董事会规范运作，提高信息披露水平，树立公司治理典范，本所将在上市公司中开展2012年度董事会奖和2012年度信息披露奖的评选工作。现将评选相关事项通知如下：

**一、**奖项设置

设置“上市公司2012年度董事会奖”和“上市公司2012年度信息披露奖”两个奖项，获奖名额各10家。

**二、**参选范围

“上市公司2012年度董事会奖”的参选范围为2012年7月2日后调整生效的本所上证公司治理板块的277家公司。

“上市公司2012年度信息披露奖”的参选范围为截至本通知发布之日，在本所挂牌上市满一周年的上市公司。

符合条件的上市公司，可同时申报两个奖项。

**三、**评选程序

（一）公司自愿申报参选

符合条件的上市公司可根据其实际情况，自愿申报参加评选，并按本所要求，编制公司参选报告。

（二）评选工作小组初选

申报截止后，由本所上市公司监管一部和二部牵头组成评选工作小组，根据日常监管情况核实参选公司的申报信息，排除虚假申报和存在不良监管记录的公司后，根据评选标准进行评分，每个奖项形成20家公司的初选名单。

（三）对外公示

本所在主要证券媒体上公示初选名单和专家委员会名单。其中，专家委员会的组成人数为11人，以本所上证公司治理专家咨询委员会的专家委员为主。

（四）专家委员会评选

本所组织专家委员会进行评选，以一般多数表决、匿名投票方式选出拟推荐获奖的公司名单。

（五）本所决定授奖

本所根据专家委员会的推荐名单，决定正式获奖名单，并于颁奖当日对外公示。

（六）颁奖

本所将于2012年12月召开的“第十一届中国公司治理论坛”上对获奖公司正式颁奖，予以表彰。

**四、**评选标准

评选标准请分别参见《上市公司2012年度董事会奖参选申报要求》（见附件1）和《上市公司2012年度信息披露奖参选申报要求》（见附件2）。

拟参加本次评选的公司，请按《上市公司2012年度董事会奖参选申报要求》或者《上市公司2012年度信息披露奖参选申报要求》逐项完成申报内容，编制参选报告，并于2012年10月19日17：00之前将电子文件通过本所上市公司专区“电子文件上传”入口，按公司实际申报奖项的类别，分别选择“年度董事会奖”或者“年度信息披露奖”类别，完成参选材料申报工作。

“年度信息披露奖”联系人：袁钰菲，电话：021-68805908。

附件1

上市公司2012年度董事会奖参选申报要求

**一、**申报说明

本次评选中，上海证券交易所（以下简称“本所”）除考察上市公司董事会的制度建设外，尤其注重对上市公司董事会实际运作、特色实践和典型案例的详细了解。为此，我们将评选标准分为4个部分：董事会制度建设、董事会实际运作情况、董事会特色实践、公司董事会典型案例。参选上市公司应根据下述细化的评选指标逐项核对公司情况，完成参选报告。参选报告不能仅以表格方式填写“是”或“否”，而应以完整报告方式，逐项说明参选公司董事会运作的具体情况。典型案例的内容应详实、充分、完整和有说服力。如有必要，可以附件形式专项说明公司董事会有特色、有成效的制度建设、实践做法和典型案例。

**二、**评选标准

（一）董事会制度建设

1.董事会人数及其构成情况：是否配备法律、财务、行业、管理等方面的专业人才，是否设立专门委员会，独立董事的设置是否合法；

2.董事会议事规则：是否有严格的会议通知程序、会议提案程序、会议召集程序、会议讨论规则、会议投票规则、会议记录制度；

3.董事会执行制度：是否有专门的监督制度和机构，督促落实董事会形成的决议；

4.董事会学习制度：是否有专门的学习制度，定期组织董事交流学习法律、财务、管理和资本市场等方面的专业知识。

（二）董事会实际运作情况

1.公司近三年主要经营业绩情况：是否稳定且可持续发展；

2.公司近三年在资本市场上的发展情况：是否通过再融资或者并购重组做大做强；

3.公司近三年信息披露情况：是否真实、准确、完整、及时、公平，是否通过信息披露使投资者得以全面了解公司情况，建立对公司发展的信心；

4.董事会的召开情况：会议的通知、召集、讨论、决议和记录是否遵守董事会议事规则；董事能否在会议上自主发表意见、独立董事是否客观独立地对重大事项发表了意见；是否存在单个董事一年超过两次缺席董事会会议的情况；

5.董事会与股东大会、监事会和管理层之间的协作监督情况：董事会是否严格遵循公司法和股东大会的授权；是否接受监事会的监督，是否及时向监事会通报重大事项；是否能有效督促管理层贯彻其决策、是否能保障管理层的高效运作；

6.董事会相对于公司控股股东、实际控制人的独立性：是否做到三分开、五独立；是否存在控股股东、实际控制人超越程序指挥董事会的情况；

7.董事会合法合规情况：公司近三年是否因违规信息披露、违规担保、资金占用、环保责任或者劳动关系等事项受过监管机构处分。

（三）董事会特色实践

1.公司重大项目是否有良好的民主决策机制，是否在提高效益的同时，能有效减少或者规避风险；

2.公司的内控机制是否完善，是否已构建符合公司行业特性的财务管理和风险管控机制；

3.公司是否建立合理的股权激励机制，是否充分调动核心管理人员和技术人员的工作积极性；

4.公司最近一年的实际现金分红水平如何，是否建立持续、稳定和可预期的现金分红机制，公司是否建立提升投资者回报的其他机制或形式；

5.公司在投资者权益保护和投资者关系管理方面，是否建立规范制度，是否取得特别成效、是否有特色做法；

6.公司在社会责任方面，是否建立规范制度，是否取得特别成效、是否有特色做法；

7.公司在关联交易和同业竞争方面，是否建立完备的关联交易管理制度，是否有减少关联交易和同业竞争的措施和计划；

8.公司在文化建设方面，是否建立和谐互助的工作环境，是否能促使员工将个人的职业发展融入于公司发展；

9.董事会的其他特色实践。

（四）2012年董事会典型案例

请列举公司在2012年度发生的一至两个公司董事会典型案例，案例的内容应详实、充分、完整和有说服力。对案例的具体要求如下：

1.合法合规，真实、准确、完整，不存在虚假记载、误导性陈述或者重大遗漏；

2.案例应实事求是地描述公司董事会运作的实际情况，反映该事项发生的企业内外部背景、董事会在其中发挥的作用和决策过程、该事项对公司的影响、市场各方反应等；

3.案例应具有一定的创新性、推广意义和市场影响力，对其他上市公司董事会运作具有借鉴意义；

4.案例可选取董事会决策或董事会各专业委员会运行的事项，也可选取公司在董事会指导下进行的事项，但必须突出董事会发挥的作用。

上市公司2012年度信息披露奖参选申报要求

**一、**申报说明

本次评选中，上海证券交易所（以下简称“本所”）除关注上市公司信息披露工作的制度建设外，尤其注重对上市公司信息披露的实际运作情况、特色实践和典型案例的详细了解。为此，我们将评选标准分为4个部分：公司信息披露制度建设、公司日常信息披露情况、公司信息披露特色实践和公司信息披露典型案例。参选上市公司应根据下述细化的评选指标逐项核对公司情况，完成参选报告。参选报告不能仅以表格方式填写“是”或“否”，而应以完整报告方式，逐项说明参选公司信息披露运作的具体情况，典型案例的内容应详实、充分、完整和有说服力。如有必要，可以附件形式专项说明公司信息披露有特色、有成效的制度建设、实践做法或者典型案例。

**二、**评选标准

（一）公司信息披露制度建设情况

1.公司信息披露事务管理制度：是否建立健全、有效、可行的信息披露事务管理制度，信息披露渠道是否通畅；

2.公司定期报告的披露：是否制定了严谨的定期报告编制、审议、披露程序；

3.公司临时报告的披露：是否制定了严谨的临时报告报送、审核、披露程序；

4.公司信息披露人员建设：是否按规定配备了具备资质的专职信息披露人员（包括董事会秘书和证券事务代表）；是否为董事会秘书履行职责提供便利的条件，赋予其履行信息披露职责的必要权限。

（二）公司日常信息披露情况

1.公司信息披露的合法合规情况：信息披露是否真实、准确、完整；是否存在虚假记载、误导性陈述或者重大遗漏；是否符合及时性、公平性原则；

2.公司董事、监事、高级管理人员履行信息披露职责情况：是否忠实、勤勉、尽责，保证信息披露的真实、准确、完整、及时、公平，不存在虚假记载、误导性陈述或者重大遗漏；

3.公司定期报告的披露情况：是否在规定的时间内完成定期报告的编制、审议和披露；是否存在未在规定时间内完成定期报告披露预约的情况；是否存在变更定期报告披露日期的情况；

4.公司信息披露独立性情况：公司是否能一贯保持信息披露的独立性，不为公司控股股东、实际控制人及其一致行动人等所操纵、控制；公司是否能有效督促公司控股股东、实际控制人及其一致行动人等相关信息披露义务人主动积极配合公司的信息披露，依法履行报告、公告义务；

5.公司董事会秘书信息披露工作尽责情况：是否全程管理信息披露事务；公司董事会秘书在日常沟通中是否积极、诚信；董事会秘书年度考核是否在优良以上；

6.公司及相关信息披露义务人、董事、监事、高级管理人员、董事会秘书、保荐机构合法合规情况：最近12个月内是否因违规信息披露、违规股票交易、诚信问题等受到监管部门的处分；

7.公司股价异动与传闻澄清情况：最近12个月公司是否因股价异动，或因市场传闻被要求澄清；澄清是否及时、准确、完整，是否发生内幕信息外泄；

8.公司公告内容与表达形式规范情况：最近12个月公司是否存在补充或更正公告；公司信息披露文稿是否经常存在文字错漏、在语言表达上是否严谨、准确、简练、易懂；

9.投资者与公司互动便利情况：公司是否设有专人负责与普通投资者的沟通、联系（接听电话、回复来信等）；普通投资者是否能方便地与公司进行沟通、联系以及反映有关情况。

（三）公司信息披露特色实践

1.信息披露制度及其执行方面：公司是否具有特色的执行手段或措施保证信息披露制度得到有效执行；是否能通过信息披露制度的有效执行促使公司进一步规范运作；

2.信息披露学习、培训方面：公司是否建立健全有特色的信息披露学习、培训制度，并且认真执行该两项制度；公司董事、监事、高级管理人员等是否主动定期或不定期参加信息披露法律法规等的学习和培训；

3.信息披露渠道方面：公司是否设有统一的信息披露渠道，是否有特色的做法保证信息得到公平、及时披露；

4.董事会秘书对公司信息掌握情况方面：公司是否有特色做法保证董事会秘书能在第一时间掌握公司的第一手信息；公司在启动、决策或实施有关事项之前是否先征询、听取董事会秘书信息披露方面的意见；董事会秘书是否全程参与或列席公司的各项重要活动；

5.现金分红及投资者回报的披露方面：公司是否在公司章程中披露了持续、稳定和可预期的现金分红政策，是否就现金分红与投资者建立了有效的沟通机制，是否对公司近三年的现金分红水平和投资者回报作出了公开、合理的说明；

6.与投资者关系方面：公司董事、监事、高级管理人员是否与投资者保持良好关系，主动走访投资者，在积极接待投资者调研或媒体采访的同时保持信息披露的公平；公司是否在定期报告或重要公告披露后举行公开说明会，由公司管理人员与各类投资者公开进行沟通；公开说明会是否采用互联网方式，以便于普通投资者参与；

7.公司信息披露工作的其他特色实践。

（四）公司信息披露典型案例

列举公司在2012年度发生的一至两个信息披露典型案例，案例的内容应详实、充分、完整和有说服力。对案例的具体要求如下：

1.合法合规，真实、准确、完整，不存在虚假记载、误导性陈述或者重大遗漏，并符合及时性、公平性原则；

2.通过该案例能反映出公司信息披露的概貌，包括通报、编制、审核、报送、披露等程序的运行情况，公司董事会秘书等信息披露人员的履职情况和对内、对外的沟通和协调情况，公司与投资者的互动情况，公告文稿的质量情况等；

3.包含能有效促进真实、准确、完整、及时和公平地披露信息的好做法、新做法，具有可供其他公司学习或者借鉴之处；

4.具有一定的创新性、推广意义和市场影响力，能够推动信息披露相关规则的健全或者完善；

5.案例可以是涉及多个业务环节的复杂、重大或者疑难事项（如重大资产重组、收购（要约收购）、发行股份、外资并购、重大合同等）的披露，也可以是能以小见大的小事项的披露。
