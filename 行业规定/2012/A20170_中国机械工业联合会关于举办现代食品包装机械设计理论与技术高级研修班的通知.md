# 中国机械工业联合会关于举办现代食品包装机械设计理论与技术高级研修班的通知

## 中国机械工业联合会关于举办现代食品包装机械设计理论与技术高级研修班的通知（中机联培[2012]64号）

各有关单位：

为加快我国食品和包装机械工业的发展，培训相关专业技术人才，提高我国食品和包装机械行业的技术水平，经人力资源和社会保障部批准，由中国机械工业联合会主办，河南省机械工程学会承办，河南科技大学协办的现代食品包装机械设计理论与技

术高级研修班将于3月份在郑州市举办。现将有关事宜通知如下：

**一、**研修课程主要内容

（一）发展食品装备制造业，支撑食品工业发展；

（二）食品与包装机械发展现状及趋势；

（三）绿色食品包装技术及设计理念；

（四）食品软包装发展趋势、结构设计与创新；

（五）现代机械设计优化设计理论与实践；

（六）农产品（食品）保鲜包装技术与装备研究开发进展、战略与实践。（研修具体课程安排请见附件1）。

**二、**研修人员及报名方式

（一）研修对象：参加研修人员为食品包装机械企业的技术骨干、大专院校（包括职业技术学院、学校）相关专业骨干教师及科研院所高级技术人才或高级技术管理人员。

（二）报名方式：参加研修人员填写报名回执（附后）并加盖单位印章，与3月15日前传真至河南省机械工程学会。

**三、**研修时间和地点

（一） 举办时间：研修班定于2012年3月25日-29日举办，3月25日全天报到。

（二） 报到地点：世纪星快捷酒店农业路店

地点：河南省郑州市农业路70号（农业路与经七路交叉口西10米河南博物院对面）。

（三） 乘车路线：

火车站路线：从火车站乘6、28、32、K39、39路公交车至农业路站下车，往东步行300米河南省博物院对面即到。

市内乘72路、42路、61路、30路公交车至河南省博物院站下车即到。

机场路线：乘机场大巴至民航大酒店，下车后打出租车到世纪星快捷酒店农业路店（车费约13元左右）。

**四、**其他事项

（一）请参加研修的人员每人撰写一篇与本专业、本领域有关的论文或学习体会（文字稿并附电子版），字数3000字左右，于研修班结束前提交。

（二）研修人员修完规定的课程后，经考核合格，颁发人力资源和社会保障部专业技术人员管理司《专业技术人员高级研修班结业证书》，记录相应培训学时，并计入《专业技术人员继续教育证书》。

（三）研修班不收培训费，学员往返交通费自理，食宿统一安排。报到时请交一张1寸近期免冠照片。
