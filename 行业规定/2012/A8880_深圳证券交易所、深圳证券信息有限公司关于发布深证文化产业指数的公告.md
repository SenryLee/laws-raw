# 深圳证券交易所、深圳证券信息有限公司关于发布深证文化产业指数的公告

为反映深市文化产业上市公司的整体表现，提供更丰富的指数化投资标的，满足ETF等指数产品发展的需要，深圳证券交易所和深圳证券信息有限公司定于2012年11月9日发布深证文化产业指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399654 | 深证文化产业指数 | 深证文化 | 2009年6月30日 | 1000 |

深证文化产业指数以深市文化产业上市公司为备选样本，综合考虑市值规模、流动性等因素，选取前50只股票构成指数样本。指数每半年定期调整一次，调整时间为每年 1月和7月的第一个交易日，指数计算中对单个样本设置5%的权重上限。

深证文化产业指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//index.cninfo.com.cn）。
