# 中国质量协会供销合作系统分会关于表彰2012年全国供销合作社系统优秀质量管理小组、质量信得过班组、质量管理小组活动优秀企业、卓越领导者、优秀推进者的决定

各省、自治区、直辖市、计划单列市、副省级省会城市、新疆生产建设兵团供销合作社质量管理机构，各有关企事业单位：

为贯彻落实国家《质量发展纲要》，推进质量强国强企建设，推动全国供销合作社系统群众性质量管理活动的开展，促进质量信得过班组建设，提高企业产品和服务质量，中国质量协会供销合作系统分会决定表彰浙江供销超市有限公司商品联采二次谈价攻关 QC小组等9个QC小组为2012年全国供销合作社系统优秀质量管理小组；表彰浙江供销超市有限公司城南店质量管理班组等7个班组为2012年全国供销合作社系统质量信得过班组；表彰浙江供销超市有限公司等6个企业为2012年全国供销合作社系统质量管理小组活动优秀企业；表彰浙江供销超市有限公司副总经理吴徳丰等6名同志为2012年全国供销合作社系统质量管理小组活动卓越领导者；表彰新疆农资（集团）有限责任公司和田配送中心经理吐尔逊?玉苏甫同志为2012年全国供销合作社系统质量管理小组活动优秀推进者。现予以公布（见附件1）。

希望受表彰的单位和个人再接再厉，不断创新，深入持久地开展质量管理活动，努力提高质量管理水平。希望全国供销合作社系统广大干部职工结合生产、经营实际，学习和借鉴受奖单位的经验，努力提高产品和服务质量。

附件2：

有关事宜说明

为做好获奖单位和个人的表彰、宣传、推广工作，特作如下说明：

表彰方式

经中华全国供销合作总社及有关部门领导同意，拟于今年12月11日在深圳召开“2012年全国供销合作社系统追求卓越会议”（详见中国供销合作网http：//www.chinacoop.gov.cn/文件通知），为荣获“2012年全国供销合作社系统优秀质量管理小组、质量信得过班组、质量管理小组活动优秀企业、卓越领导者、优秀推进者”颁发奖状、奖牌和证书。

宣传推广

1.为了加强宣传效果，扩大社会影响，提高获奖单位知名度，营造“质量兴企”的社会氛围，中国质量协会供销合作系统分会与相关部门通过中国供销合作网http：//www.chinacoop.gov.cn/向社会发布获奖单位和个人名单。

2.为大力推广经验，对获奖单位中的典型经验进行报道，为更多的单位开展质量管理创造条件。
