# 中国外汇交易中心关于非金融企业债务融资工具发行人披露2012年上半年财务报表情况的公告

## 中国外汇交易中心关于非金融企业债务融资工具发行人披露2012年上半年财务报表情况的公告（中汇交公告〔2012〕64号）

按照《银行间债券市场非金融企业债务融资工具管理办法》（中国人民银行令[2008]第1号）和《银行间债券市场非金融企业债务融资工具信息披露规则》（中国银行间市场交易商协会公告［2008］第2号）的有关规定， 截至2012年8月31日，银行间债券市场发行非金融企业债务融资工具（短期融资券、超短期融资券、中期票据和中小企业集合票据）的1503家发行人中，除299家所发行的非金融企业债务融资工具已兑付、3家企业的债券债务转移外，共有1201家发行企业及47家担保机构、债务承继机构应在2012年8月31日前通过中国货币网发布2012年上半年度财务报表。

**一、**具体资信披露情况如下：

（一）此次共收到1243家企业、担保公司及部分债券债务承继机构发送的2012年和上半年度母公司、集团合并财务报表；上市公司2012年上半年度报告或链接地址公告。

（二）在应披露的1201家企业，1200家全部披露了完整的2012年上半年度财务报表或2012年半年报，有1家机构没有披露2012年半年报。

（三）在299家非金融企业债务融资工具已到期的发行企业中，13家企业自愿披露了2012年上半年度财务报表。

（四）本次披露中，共有47家债券担保机构、债务承继机构，其中20家已作为债券发行人披露了2012年度上半年度财务报表，其余的27家担保机构也都按时披露了2012年上半年度财务报表。

（五）此次有3家新入市跨期发行的企业也在8月31日前提交了2012年上半年财务报表，分别是：滨化集团股份有限公司、无锡广播电视发展有限公司、滨海投资集团股份有限公司。

**二、**全国银行间同业拆借中心于2012年8月31日完成了非金融企业债务融资工具发行人的信息披露文件在中国货币网（www.chinamoney.com.cn）上的发布工作。具体已披露的企业名单见下表，下表中去除了已经兑付的企业：
