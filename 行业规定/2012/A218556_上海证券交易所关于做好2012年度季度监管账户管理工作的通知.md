# 上海证券交易所关于做好2012年度季度监管账户管理工作的通知

## 上海证券交易所关于做好2012年度季度监管账户管理工作的通知（上证监字〔2012〕7号）

各会员单位：

自2011年1月24日发布《关于改进季度监管账户发送工作的通知》（上证监字［2011］1号，以下简称“《通知》”）以来，上海证券交易所（以下简称“本所”）已连续5个季度向相关会员发送了5期季度监管账户，涉及84家（次）会员的556个（次）账户，其中包括460个（次）监管关注账户、115个（次）重点监控账户、1个限制交易账户，同时先后约见了4家（次）会员的相关高管谈话。

一年多来，上述84家（次）会员中的绝大部分都能够按照《通知》的要求，认真做好季度监管账户的核查，及时反馈核查结果，并对季度监管账户进行严格的监督管理，客户合规交易管理工作效果显著。少数核查、反馈工作不到位的会员在经本所督促后也明显改观。目前，会员主动与本所沟通客户交易行为合规管理工作的现象日益增多，会员与本所协同监管的效率不断提高。

为在2012年进一步做好季度监管账户的管理工作，现将有关事项通知如下。

**一、**关于异常交易行为类型的调整

为适应市场异常交易行为模式的不断发展变化，本所在分析总结2011年以来异常交易行为趋势的基础上，对《通知》附件中“异常交易行为类型及其主要特征”的有关内容进行了一些调整：一是增加了“涉嫌合谋影响证券价格”、“新股异常交易行为”两类异常交易行为；二是鉴于目前本所已无权证挂牌交易，将“权证过度回转交易”内容删除（详见附件）。

对于附件中“109-新股异常交易行为”，各会员应当结合本所《关于加强新股上市初期交易监管的通知》（上证监字〔2012〕4号）的要求，切实做好相关客户的投资者教育和风险提示工作，并告知本所可能对其账户采取盘中暂停账户当日交易等监管措施。

**二、**关于季度监管账户发送时间的调整

根据监管工作的实际需要，自本通知发布之日起，本所季度监管账户（包括监管关注账户、重点监控账户、限制交易账户）的发送时间统一调整为每季度前20个交易日内。会员反馈的时间保持不变，即监管关注账户、限制交易账户在账户名单发布后的5个交易日内反馈，重点监控账户在收到账户名单后的10个交易日内反馈。

实践证明，本所每季度初通过外部网站“会员专区”向相关会员定向发送季度监管账户的做法，不仅有利于促进会员客户交易行为合规管理工作的顺利开展，增强会员协同管理客户交易行为的积极性和针对性，同时也提升了本所市场监察工作的效率和效果。今后，本所将继续根据市场的发展变化和会员的反馈意见等，不定期地调整和完善异常交易行为的类型，优化季度监管账户的分类，及时将出现异常交易行为的账户定向发送给相关会员，以更好地发挥会员与本所协同监管的作用。

请各会员单位在2012年继续按照相关通知的要求，积极配合本所做好季度监管账户的管理工作，共同维护市场“三公”，促进证券市场健康稳定发展。

特此通知。
