# 深圳证券交易所关于为北京中实混凝土有限责任公司2012年中小企业私募债券等4只私募债券提供转让服务有关事项的通知

各会员单位：

北京中实混凝土有限责任公司 2012 年中小企业私募债券、内蒙古奈伦农业科技股份有限公司2012 年中小企业私募债券、青岛澳洋塑料制品有限公司2012年中小企业私募债券（第一期）、武汉医药（集团）股份有限公司2012年中小企业私募债券定于2012年12月7日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、北京中实混凝土有限责任公司 2012 年中小企业私募债券证券代码“118023”，证券简称“12中实债”，发行总额8，000万元，票面利率10.30%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、内蒙古奈伦农业科技股份有限公司2012 年中小企业私募债券证券代码“118028”，证券简称“12蒙农科”，发行总额25，000万元，票面利率9.95%，债券期限2年。

3、青岛澳洋塑料制品有限公司2012年中小企业私募债券（第一期）证券代码“118029”，证券简称“12澳洋01”，发行总额10，000万元，票面利率8.50%，债券期限1年。

4、武汉医药（集团）股份有限公司2012年中小企业私募债券证券代码“118031”，证券简称“12武医债”，发行总额8，000万元，票面利率9.80%，债券期限2年，附第1年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所
