# 深圳证券交易所、深圳证券信息有限公司关于发布深证低波动率、高贝塔系列指数的公告

为进一步丰富和完善深证指数体系，推动指数化投资的不断发展与创新，深圳证券交易所和深圳证券信息有限公司定于2012年12月20日发布深证低波动率、高贝塔系列指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399661 | 深证300低波动率指数 | S300低波 | 2006年12月29日 | 1000 |
| 399662 | 深证300高贝塔指数 | S300高贝 | 2006年12月29日 | 1000 |
| 399663 | 中小300低波动率指数 | 中小低波 | 2011年6月30日 | 1000 |
| 399664 | 中小300高贝塔指数 | 中小高贝 | 2011年6月30日 | 1000 |
| 399665 | 中创500低波动率指数 | 中创低波 | 2011年6月30日 | 1000 |
| 399666 | 中创500高贝塔指数 | 中创高贝 | 2011年6月30日 | 1000 |

该系列指数是基于市值母指数的风险策略指数，S300低波、S300高贝指数均以深证300指数为样本空间；中小低波、中小高贝指数均以中小300指数为样本空间；中创低波、中创高贝指数均以中创500指数为样本空间。

对于低波动率系列指数，基于各自样本空间的股票，按照最近一年日收益率的波动率升序排名，S300低波、中小低波分别选择排名前100的股票作为样本股，中创低波选择排名前200的股票作为样本股。样本股权重与其历史波动率的倒数成正比。

对于高贝塔系列指数，基于各自样本空间的股票，按照最近一年的贝塔值降序排名，S300高贝、中小高贝分别选择排名前100的股票作为样本股，中创高贝选择排名前200的股票作为样本股。样本股权重与其历史贝塔值成正比。

该系列指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//index.cninfo.com.cn）。
