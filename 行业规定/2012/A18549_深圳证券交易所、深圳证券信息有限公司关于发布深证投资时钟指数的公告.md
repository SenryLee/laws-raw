# 深圳证券交易所、深圳证券信息有限公司关于发布深证投资时钟指数的公告

为反映宏观经济周期与证券市场运行的有关情况，进一步满足投资管理的需要，深圳证券交易所和深圳证券信息有限公司定于2012年3月26日发布深证投资时钟指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399644 | 深证投资时钟指数 | 深证时钟 | 2006年12月29日 | 1000 |

深证投资时钟指数以深圳市场上市公司为选样范围，基于投资时钟理论编制。投资时钟理论认为，经济周期可划分为复苏、扩张、滞胀和收缩四个阶段，各阶段中的行业表现存在差异。投资时钟指数的主要构造步骤为：首先，通过量化的投资时钟模型，判断中国所处的经济周期阶段；其次，根据历史上相同经济周期阶段内的行业表现，分配各行业在指数中的权重；最后，在行业权重额度内，优先配置自由流通市值较大的股票，使样本股数达到100只。指数使用的量化投资时钟模型由色诺芬信息技术公司研发。

深证投资时钟指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//index.cninfo.com.cn）。
