# 深圳证券交易所关于南方金利定期开放债券型基金份额上市交易有关事项的通知

各会员单位：

为做好南方金利定期开放债券型基金的上市工作，现就有关事项通知如下：

1．南方金利定期开放债券型基金（证券简称：南方金利，证券代码：160128）2012年7月16日开始在我所上市交易。上市首日以上市首日前一交易日的基金份额净值作为开盘参考价，并以此为基准设置涨跌幅限制。自上市首日起，每日涨跌幅限制为10%。

2．根据南方基金管理有限公司申请，本所同意南方金利定期开放债券型基金自上市首日起在本所行情发布系统揭示净值。每百份基金单位前一交易日净值（经基金托管人复核）在行情系统“市盈率Ⅰ”中揭示。

特此通知

深圳证券交易所
