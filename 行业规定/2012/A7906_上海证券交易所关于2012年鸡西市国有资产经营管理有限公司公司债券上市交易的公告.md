# 上海证券交易所关于2012年鸡西市国有资产经营管理有限公司公司债券上市交易的公告

鸡西市国有资产经营管理有限公司发行的2012年鸡西市国有资产经营管理有限公司公司债券，将于2012年12月3日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12鸡国资”，证券代码为“124010”。债券上市后可进行质押式回购，质押券申报和转回代码为“103010”。

上海证券交易所　　

二○一二年十一月三十日
