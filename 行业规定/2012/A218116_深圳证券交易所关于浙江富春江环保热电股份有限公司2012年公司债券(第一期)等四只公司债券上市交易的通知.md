# 深圳证券交易所关于浙江富春江环保热电股份有限公司2012年公司债券(第一期)等四只公司债券上市交易的通知

## 深圳证券交易所关于浙江富春江环保热电股份有限公司2012年公司债券（第一期）等四只公司债券上市交易的通知

各会员单位：

浙江富春江环保热电股份有限公司2012年公司债券（第一期）、中利科技集团股份有限公司2011公司债券和湖北国创高新材料股份有限公司2012年公司债券定于2012年8月2日起在本所集中竞价系统和综合协议交易平台上市交易，浙江康盛股份有限公司2012年公司债券定于2012年8月2日起在本所综合协议交易平台上市交易，现将有关事项通知如下：

1、浙江富春江环保热电股份有限公司2012年公司债券（第一期）证券代码“112088”，证券简称“12富春01”，发行总额4亿元，票面利率6.70%，债券期限5年，附第3年发行人上调票面利率选择权和投资者回售选择权。

2、中利科技集团股份有限公司2011年公司债券代码“112094”，证券简称“11中利债”，发行总额8亿元，票面利率6.70%，债券期限5年。

3、浙江康盛股份有限公司2012年公司债券证券代码“112095”，证券简称“12康盛债”，发行总额2亿元，票面利率7.80%，债券期限5年，附第3年发行人上调票面利率和投资者回售选择权。

4、湖北国创高新材料股份有限公司2012年公司债券证券代码“112096”，证券简称“12国创债”，发行总额2.7亿元，票面利率6.20%，债券期限5年。

深圳证券交易所

二○一二年七月三十一日
