# 深圳证券交易所关于2012年浙江省政府债券(二期)上市交易的通知

## 深圳证券交易所关于2012年浙江省政府债券（二期）上市交易的通知

各会员单位：

2012年浙江省政府债券（二期）（以下简称“本期国债”）已发行结束，根据财政部通知，本期国债于2012年9月28日起在本所上市交易。

本期国债为7年期固定利率附息式国债（地方政府债），证券编码“109092”，证券简称“浙江1202”，票面利率3.47%，标准交易单位“10张”，2019年9月24日到期还本并支付最后一期利息。

特此通知
