# 上海证券交易所关于江中药业股份有限公司2012年公司债券上市交易的公告

江中药业股份有限公司发行的江中药业股份有限公司2012年公司债券，将于2012年12月27日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12江药债”，证券代码为“122170”。债券上市后可进行质押式回购，质押券申报和转回代码为“104170”。

上海证券交易所　　

二○一二年十二月二十六日
