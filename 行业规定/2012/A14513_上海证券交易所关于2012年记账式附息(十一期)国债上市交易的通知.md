# 上海证券交易所关于2012年记账式附息(十一期)国债上市交易的通知

## 上海证券交易所关于2012年记账式附息（十一期）国债上市交易的通知（上证债字〔2012〕218号）

各会员单位：

根据《财政部关于2012年记账式附息（十一期）国债发行工作有关事宜的通知》（财库[2012]64号）和上海证券交易所（以下简称“本所”）有关规定，2012年记账式附息（十一期）国债（以下简称“本期国债”）将于2012年6月20日在本所集中竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下。

**一、**本期国债为固定利率附息债，期限为1年，票面利率为2.15%，利息到期一次支付；本期国债起息日为2012年6月14日，2013年6月14日（节假日顺延）偿还本金并支付利息。

**二、**本期国债于2012年6月20日起在本所集中竞价系统和固定收益证券综合电子平台上市，交易方式为现券和回购。

**三、**本期国债上市交易的现券证券名称为“12国债11”，证券代码为“019211”，出入库代码为“091036”。

二○一二年六月十四日
