# 中国登山协会关于举办2012全国攀岩分站赛(怀集站)暨年度总决赛的通知

## 中国登山协会关于举办2012全国攀岩分站赛（怀集站）暨年度总决赛的通知

各省、自治区、直辖市体育局、登山协会、各行业体协、大专院校及相关俱乐部：

经国家体育总局批准，我协会定于2012年12月1日至3日在广东怀集县举办2012全国攀岩分站赛（怀集站）暨年度总决赛及2012年全国攀岩分站赛总排名颁奖活动。现将竞赛规程发给你们，请各参赛单位于2012年11月23日前将报名表以传真或电子邮件的方式发送至中国登山协会，过期不予报名。

另，2012全国攀岩分站赛（北京站）因场地原因取消。
