# 中国注册会计师协会关于召开证券资格会计师事务所2012年年报审计工作会议的通知

## 中国注册会计师协会关于召开证券资格会计师事务所2012年年报审计工作会议的通知（会协〔2012〕230号）

各省、自治区、直辖市注册会计师协会，各证券资格会计师事务所：

为学习贯彻党的十八大精神和财政部领导有关批示指示精神，深入推进行业诚信建设，指导证券所做好2012年年报审计工作，我会定于2012年12月20日召开证券资格会计师事务所2012年年报审计工作会议。现将有关事项通知如下：

**一、**会议时间及地点

会议时间：2012年12月20日（周四）全天。

上午9：00-12：00，下午13：30-16：00。

会议地点：中注协办公楼11层报告厅（地址：北京市海淀区西四环中路16号院2号楼）。

住宿地点：北京裕龙大酒店（海淀区阜成路40号，010－88815588）。会议为外地代表提供住宿。

京外人员报到时间：2011年12月19日。

京外人员报到地点：北京裕龙大酒店（海淀区阜成路40号，010－88815588）。

京内人员请于12月20日8：40在中注协办公楼11层报告厅报到。

**二、**会议内容

学习贯彻党的十八大精神和财政部领导有关批示指示精神，全面把握行业面临的新形势、新任务和新要求，系统总结2012年证券所执业质量监管工作，深入推进行业诚信建设，研究解决行业发展尤其是证券所发展存在的问题，全力推进证券所科学发展，提升上市公司2012年年报审计工作水平。

**三、**参会人员

各省（区市）注协分管监管工作的秘书长1人；各证券资格会计师事务所主任会计师和主管质量控制的合伙人各1人。

**四、**注意事项

请参会人员按照会议时间合理安排行程。

请于12月12日前将报名回执传真或发邮件至中注协业务监管部。
