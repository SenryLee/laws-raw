# 中国资产评估协会关于举办2012中国评估论坛的通知

## 中国资产评估协会关于举办2012中国评估论坛的通知（中评协[2012]194号）

各有关单位：

中国资产评估协会将于2012年11月22日在福建省厦门市举办“2012中国评估论坛”。现将有关事项通知如下：

**一、**主办单位：中国资产评估协会

**二、**论坛主题：品牌·价值·评估

分为两个分议题：

1、品牌价值与管理；

2、品牌价值与评估。

**三、**出席论坛领导及演讲嘉宾：

中纪委委员、中国资产评估协会会长贺邦靖将出席论坛并致辞。

本届论坛邀请了财政部、国家质量监督检验检疫总局有关司局领导、知名企业代表、院校研究机构代表、地方评估协会代表及评估机构代表等10多名嘉宾发表演讲。

**四、**论坛时间、地点：

1、时间：2012年11月22日，21日报到，23日返程。

2、地点：福建省厦门市湖滨南路99号厦门航空金雁酒店。

**五、**参会人员：

1、各省、自治区、直辖市、计划单列市资产评估协会（注册会计师协会）秘书长；

2、各证券评估资格资产评估机构负责人；

3、中国资产评估协会相关人员。

请有关单位接到通知后，组织相关人员参加会议，并于11月12日前将回执传真给我会。
