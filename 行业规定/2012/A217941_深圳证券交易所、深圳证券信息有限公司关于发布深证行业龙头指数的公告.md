# 深圳证券交易所、深圳证券信息有限公司关于发布深证行业龙头指数的公告

为反映深市A股各行业龙头公司的整体表现，向投资者提供更丰富的指数化投资标的，深圳证券交易所和深圳证券信息有限公司决定于2012年9月25日起发布深证行业龙头指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399653 | 深证行业龙头指数 | 深证龙头 | 2010年6月30日 | 1000 |

深证行业龙头指数以巨潮行业分类中的二级行业为基础，使用过去两年的平均营业收入、过去两年的平均净利润、过去半年的日均成交额和日均流通市值四个指标进行综合评分，从各二级行业中挑选出市场占有率高、经营业绩突出、流动性好的50只股票构成深证行业龙头指数的样本股。深证行业龙头指数每半年定期调整一次，调整时间为每年 1月和7月的第一个交易日，每次样本调整数量不超过样本总数的20%。

深证行业龙头指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//index.cninfo.com.cn）。
