# 中国法学会关于举办“中美知识产权司法审判研讨会”的通知

中国法学会各研究会，各省、自治区、直辖市法学会，新疆生产建设兵团法学会：

为全面深入了解中美两国的知识产权法律环境、审判制度与实践，增强两国知识产权领域专业人士的沟通，推动两国知识产权界的交流与合作，提高知识产权保护意识和能力，经批准，中国法学会定于2012年5月28-30日在北京举办“中美知识产权司法审判研讨会”，由中国知识产权法学研究会承办。

大会以“司法、诉讼、创新”为主题，将举办开幕式暨主题报告会，并分别通过大会、专题分会、模拟法庭等方式，对专利、商标、著作权等知识产权问题进行交流与研讨。

会议同时举办论文征集和评选活动，征文内容：围绕会议主题，对知识产权理论与实践中的热点、疑难问题进行探讨，对具有重大影响的案例进行评析以及对法条法规的解读与应用。大会将组织专家对征文进行评审，对优秀论文予以表彰，并由中国法学会颁发证书。

附件：

中美知识产权司法审判研讨会基本概况

**（一）**大会介绍

中美知识产权界高规格、高层次的盛会；

中美知识产权法官的一次思想碰撞；

中美企业界与司法界的深度交流

**（二）**大会背景

中国目前已经成为世界上经济增长最快的国家，同时也已经成为全球竞争最激烈的地区之一，而在多变的全球竞争中，知识产权无疑已经成为企业立于不败之地以及持续发展的根源动力。

“2012年中美知识产权司法审判研讨会”经中华人民共和国最高人民法院、中华人民共和国商务部、中华人民共和国国家知识产权局会签，由中国法学会主办的一次影响全球知识产权界的顶级盛会。大会聚焦知识产权领域法律应用主题“司法、诉讼、创新”，以强大的嘉宾阵容、鲜明的主题、极具实战性的内容、生动的会议形式以及权威媒体的独家解析，必将受到产业界与管理层的高度关注与广泛参与。通过主题报告会、大会、专题分会、座谈会、展览展示、模拟法庭等相关活动，为各界提供交流研讨、宣传推广、品牌展示的交流与合作平台。

本次大会是一次中美知识产权界的权威思想大碰撞，参加本次大会的有：美国联邦巡回上诉法院法官、美国专利商标局官员、美国知名律师、美国企业界代表、中国各地法官、学术界专家、知名企业代表、知名律师代表等众多中美知识产权界精英。

同时中国知识产权报商标周刊、人民网、腾讯网等全国财经商业媒体，都将聚焦本次盛会，对大会进行追踪报道。

与世界上最懂知识产权的人进行亲密接触，直面中美知识产权法官，在洞悉知识产权管理与发展内在玄机的同时，更有机会取得实实在在的收益。交流让企业的知识产权管理工作充满活力，选择正确的平台，与我们携手走进“2012年中美知识产权司法审判研讨会”。

**（三）**大会主题

司法　 诉讼　 创新

支持单位：最高人民法院知识产权审判庭

中国专利局

美国联邦巡回上诉法院

国际商标协会

承办单位：中国知识产权法学研究会

媒体推广：中国知识产权报商标周刊

**（五）**时间地点

大会时间：2012年5月28-30日

大会地点：北京　人民大学（主会场）　友谊宾馆（分会场）

**（六）**大会规模

此次大会将邀请中外法官、学者、业界人士、企业代表等众多知识产权界精英，必将成为中外知识产权领域高层次、高规格、高水平的权威活动。出席大会的代表有：

美方知识产权法官及其他知识产权官员、专家

美方律师代表

美方企业代表

中方知识产权法官

中方其他知识产权官员及法律研究机构负责人

中方专家学者

中方企业代表

中方律师代表及其他知识产权法律工作者

**（七）**主要活动

综合活动：开幕式　主题报告会　 大会（专利）

专题分会：商标　 版权　　专利　　商业秘密

展览展示：大会为赞助企业提供展区，展示企业主要成果

模拟法庭：此次大会就典型案例举办现场模拟法庭，让国内外业界更加了解中国司法审判和美国司法审判的真实过程。

**（八）**大会亮点

1、中美知识产权司法审判最高层次的交流：本次大会由中国法学会主办，并得到最高人民法院知识产权审判庭、中国专利局、美国联邦巡回上诉法院、美国专利商标局、美国联邦巡回上诉法院律师协会、国际商标协会的大力支持。

2、中美知识产权法学界最大的盛会：大会邀请到中美知识产权界政要官员、专家学者及企业的精英，并得到中国知识产权报商标周刊、人民法院报、腾讯网等媒体的大力支持。

3、内容和所涉及议题最为广泛：开幕式、主题报告会、大会、主题分会、展览展示、模拟法庭等丰富内容。
