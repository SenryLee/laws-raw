# 深圳证券交易所关于宜宾五粮液股份有限公司股票临时停牌的公告(2012)

## 深圳证券交易所关于宜宾五粮液股份有限公司股票临时停牌的公告

因媒体报道了宜宾五粮液股份有限公司相关事项，根据《深圳证券交易所股票上市规则》第12.4条的规定，经公司申请，本所将于2012年12月14日开市起对公司股票（证券简称：五粮液，证券代码：000858）进行临时停牌，待公司刊登相关公告后复牌。

深圳证券交易所

2012年12月14日
