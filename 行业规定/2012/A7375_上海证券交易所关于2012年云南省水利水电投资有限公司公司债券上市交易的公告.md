# 上海证券交易所关于2012年云南省水利水电投资有限公司公司债券上市交易的公告

云南省水利水电投资有限公司发行的2012年云南省水利水电投资有限公司公司债券，将于2012年12月12日起在上海证券交易所交易市场竞价系 统和固定收益证券综合电子平台上市交易。该债券证券简称为“12滇水投”，证券代码为“122570”。债券上市后可进行质押式回购，质押券申报和转回代 码为“104570”。

上海证券交易所　　

二○一二年十二月十一日
