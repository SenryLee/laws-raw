# 上海证券交易所关于2012年华能新能源股份有限公司公司债券上市交易的公告

华能新能源股份有限公司发行的2012年华能新能源股份有限公司公司债券，将于2012年12月3日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券分两个品种，品种一为3年期，证券简称为“12能新01”，证券代码为“122198”；品种二为5年期，证券简称为“12能新02”，证券代码为“122199”。债券上市后可进行质押式回购，其中品种一质押券申报和转回代码为“104198”，品种二质押券申报和转回代码为“104199”。

上海证券交易所　　

二○一二年十一月三十日
