# 中国期货业协会关于举办期货公司董事长、监事长和独立董事培训的通知

各会员单位：

根据《期货公司董事、监事和高级管理人员任职资格管理办法》有关规定的要求，为进一步提升期货公司的治理水平，中国期货业协会拟举办3期期货公司董事长、监事长和独立董事培训班。现将培训安排通知如下：

**一、**培训对象

期货公司董事长、监事长和独立董事

**二、**培训的主要内容

1. 中国期货市场新形势与期货公司治理

2. 期货公司分类监管与业务创新

3. 国外期货交易所的变革与中国期货交易所的体制创新

4. 期货行业的诚信建设

5. 国际期货公司的比较研究与中国期货公司的发展战略

6. 公司治理结构与内部控制

7. 东海、南海安全形势

培训期间，将安排高管围绕“期货市场发展新形势与业务创新”、“期货公司的市场定位与发展战略”、“期货公司的法人治理与内部控制”等议题进行讨论与交流。

**三、**培训师资

培训师资包括监管部门、交易所与协会领导；知名经济学家和著名商学院教授；大型金融机构专家；业内资深专家等。

**四、**培训时间及地点安排

培训班每期3天，共举办3期。培训班拟在海口、桂林、厦门分期举办。

**五、**培训报名及注意事项

1.请符合培训条件的人员根据个人情况在上述各期中任选一期报名。

2.每期培训上限160人。报名过时和各期名额满员情况下报名系统将自动关闭，因此而没有报名成功的学员可选择其他期次。

3.本次培训班采取网上报名的形式，协会不接收其他形式的报名。报名时请点击本通知下方报名通道报名。报名信息填报完成后，系统会提示您是否报名成功。因协会预订房间需支付订金，学员网上报名时请明确填写住宿需求。请报名人员填写《期货公司董事长、监事长和独立董事培训报名表》（见附件），加盖公章后于报到时交会务组。

4.由于每期培训人数有限，报名后不得改期，确有特殊情况需更改报名期数及住宿需求的，请于当期培训前10天以书面形式说明原因并由所在单位加盖公章传真至010-88087060。

**六、**培训考核及管理

培训考核采取提交论文考核的方式。每位学员就“期货市场发展新形势与业务创新”、“期货公司的市场定位与发展战略”、“期货公司的法人治理与内部控制”等主题任选题目提交一篇不少于3000字的学习论文，发送至yangxiongying@cfachina.org，经评审合格后发培训合格证，评审优秀的论文拟推荐媒体发表并汇编成册。论文提交时间为培训结束后15天内。

此次培训将列入中国期货业协会后续职业培训系列。
