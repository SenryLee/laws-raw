# 上海证券交易所关于2012年华盛江泉集团有限公司公司债券上市交易的公告

华盛江泉集团有限公司发行的2012年华盛江泉集团有限公司公司债券将于2012年3月29日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12江泉债”，证券代码为“122729”。上市后该债券可进行质押式回购，质押券申报和转回代码为“104729”。

上海证券交易所　　

二○一二年三月二十八日
