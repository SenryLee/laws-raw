# 深圳证券交易所关于西北永新化工股份有限公司股票临时停牌的公告

中国证券监督管理委员会将于近日审核公司重大资产置换及非公开发行股份购买资产暨关联交易事宜。根据《上市公司重大资产重组管理办法》等相关规定，因该事项存在重大不确定性，公司股票于2012年7月4日开市起停牌，待公司公告审核结果后复牌。

深圳证券交易所

2012年7月4日
