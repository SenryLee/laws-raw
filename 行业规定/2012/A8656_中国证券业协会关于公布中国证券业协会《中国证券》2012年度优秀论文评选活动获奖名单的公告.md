# 中国证券业协会关于公布中国证券业协会《中国证券》2012年度优秀论文评选活动获奖名单的公告

为引领证券市场研究发展，促进证券行业研究交流，中国证券业协会举办了《中国证券》2012年度优秀论文征文评选活动，经专家评选最终共有15篇论文获得优秀论文奖，现将优秀论文评选活动获奖名单予以公布（见附件）。

附件：中国证券业协会《中国证券》2012年度优秀论文评选活动获奖名单
