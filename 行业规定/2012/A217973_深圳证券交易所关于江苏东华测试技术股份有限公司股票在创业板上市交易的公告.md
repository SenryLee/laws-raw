# 深圳证券交易所关于江苏东华测试技术股份有限公司股票在创业板上市交易的公告

江苏东华测试技术股份有限公司人民币普通股股票将于2012年9月20日在本所创业板上市。证券简称为“东华测试”，证券代码为“300354”。公司人民币普通股股份总数为44，349，424股，其中首次公开发行的11，090，000股股票自上市之日起开始上市交易。
