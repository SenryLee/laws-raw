# 深圳证券交易所关于2012年昆明云内动力股份有限公司公司债券等三只公司债券上市交易的通知

各会员单位：

2012 年昆明云内动力股份有限公司公司债券、江苏舜天船舶股份有限公司2012年公司债券、南宁糖业股份有限公司2012年公司债券定于2012年10月23日起在本所集中竞价系统和综合协议交易平台上市交易，现将有关事项通知如下：

1、2012 年昆明云内动力股份有限公司公司债券证券代码“112107”，证券简称“12云内债”，发行总额10亿元，票面利率6.05%，债券期限6年，附第3年发行人上调票面利率和投资者回售选择权。

2、江苏舜天船舶股份有限公司2012年公司债券证券代码“112108”，证券简称“12舜天债”，发行总额7.8亿元，票面利率6.60%，债券期限7年，附第4年发行人上调票面利率和投资者回售选择权。

3、南宁糖业股份有限公司2012年公司债券证券代码“112109”，证券简称“12南糖债”，发行总额5.4亿元，票面利率7.25%，债券期限7年，附第5年发行人上调票面利率和投资者回售选择权。

深圳证券交易所　

二○一二年十月十九日
