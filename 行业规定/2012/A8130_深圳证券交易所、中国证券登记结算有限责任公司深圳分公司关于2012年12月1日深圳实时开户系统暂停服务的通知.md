# 深圳证券交易所、中国证券登记结算有限责任公司深圳分公司关于2012年12月1日深圳实时开户系统暂停服务的通知

各会员单位：

深圳证券交易所拟于2012年12月1日进行交易系统内部测试，届时深圳实时开户系统将暂停服务，相关事项通知如下：

1.2012年12月1日中国结算深圳分公司实时开户生产系统暂停服务；2012年12月2日恢复服务；

2.交易系统内部测试期间将模拟发送行情、成交等测试数据，会员单位不能以此作为生产环境任何交易、非交易和开户等业务的依据；
