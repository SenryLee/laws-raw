# 上海证券交易所关于2012年柳州东城投资开发有限公司公司债券上市交易的公告

柳州东城投资开发有限公司发行的2012年柳州东城投资开发有限公司公司债券将于2012年4月19日起在本所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12柳东债”，证券代码为“122726”。上市后该债券可进行质押式回购，质押券申报和转回代码为“104726”。

上海证券交易所　

二○一二年四月十八日
