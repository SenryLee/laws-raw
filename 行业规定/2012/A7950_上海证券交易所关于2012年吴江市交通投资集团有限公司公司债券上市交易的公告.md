# 上海证券交易所关于2012年吴江市交通投资集团有限公司公司债券上市交易的公告

吴江市交通投资集团有限公司发行的2012年吴江市交通投资集团有限公司公司债券，将于2012年11月30日起在上海证券交易所交易市场竞价系 统和固定收益证券综合电子平台上市交易。该债券证券简称为“12吴交投”，证券代码为“122506”。债券上市后可进行质押式回购，质押券申报和转回代 码为“104506”。

上海证券交易所　　

二○一二年十一月二十九日
