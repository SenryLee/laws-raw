# 上海证券交易所关于2012年重庆市南川区惠农投资有限公司公司债券上市交易的公告

重庆市南川区惠农投资有限公司发行的2012年重庆市南川区惠农投资有限公司公司债券，将于2012年12月21日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12渝惠农”，证券代码为“124009”。

上海证券交易所　　

二○一二年十二月二十日
