# 中国银行业协会关于表彰2012年服务小微企业及三农双十佳金融产品的决定

各省（市、自治区）银行业协会：

为深入贯彻落实党中央、国务院关于金融支持实体经济、扶持小微企业和三农的政策精神，继续推广地方金融机构在产品创新、特色服务等方面取得的成果，提高地方金融机构的品牌认知度和美誉度，践行地方金融机构立足地方、服务三农、服务微小的社会责任担当。中国银行业协会自今年年初面向全国地方金融机构开展了2012年服务小微企业及三农双十佳金融产品评选活动。在各地方银行业协会的大力支持和积极推动下，各银行业金融机构踊跃参与，共收到全国32个省（市）协会推荐上报的243家银行业金融机构的328个金融产品，产品具有广泛的社会基础和高度的实用性及推广价值。前期经过地方协会的初评和二审专家委员会评审及实地考察，22个省（市）50家银行业机构的50个产品进入终审。最终由终审专家委员会评选产生了2012年服务小微企业及三农十佳特优产品和十佳特色产品，并将在全国地方金融第十六次论坛上予以表彰。
