# 上海证券交易所关于2012年南京高新技术经济开发总公司企业债券上市交易的公告

南京高新技术经济开发总公司发行的2012年南京高新技术经济开发总公司企业债券，将于2012年11月19日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12宁高新”，证券代码为“122546”。债券上市后可进行质押式回购，质押券申报和转回代码为“104546”。

上海证券交易所　　

二○一二年十一月十五日
