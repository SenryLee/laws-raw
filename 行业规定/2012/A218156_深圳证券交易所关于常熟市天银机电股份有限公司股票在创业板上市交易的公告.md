# 深圳证券交易所关于常熟市天银机电股份有限公司股票在创业板上市交易的公告

常熟市天银机电股份有限公司人民币普通股股票将于2012年7月26日在本所创业板上市。证券简称为“天银机电”，证券代码为“300342”。公司人民币普通股股份总数为100，000，000股，其中首次公开发行的25，000，000股股票自上市之日起开始上市交易。

2012年7月24日
