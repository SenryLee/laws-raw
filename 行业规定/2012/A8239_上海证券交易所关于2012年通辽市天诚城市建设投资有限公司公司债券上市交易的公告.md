# 上海证券交易所关于2012年通辽市天诚城市建设投资有限公司公司债券上市交易的公告

通辽市天诚城市建设投资有限公司发行的2012年通辽市天诚城市建设投资有限公司公司债券，将于2012年11月23日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12通天诚”，证券代码为“122504”。

上海证券交易所　　

二○一二年十一月二十二日
