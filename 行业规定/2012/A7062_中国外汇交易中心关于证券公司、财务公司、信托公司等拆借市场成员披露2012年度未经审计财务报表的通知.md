# 中国外汇交易中心关于证券公司、财务公司、信托公司等拆借市场成员披露2012年度未经审计财务报表的通知

## 中国外汇交易中心关于证券公司、财务公司、信托公司等拆借市场成员披露2012年度未经审计财务报表的通知（中汇交发〔2012〕279号）

证券公司、财务公司、信托公司等同业拆借市场成员：

根据《同业拆借管理办法》（人民银行[2007]3号令）、《关于统一同业拆借市场中企业集团财务公司信息披露规范的有关事宜公告》（人民银行上海总部公告[2007]第4号）的相关规定和《中国外汇交易中心暨全国银行间同业拆借中心本币市场信息披露管理办法》（中汇交公告[2008]61号）的要求，经批准成为同业拆借市场成员的非银行金融机构中，81家证券公司需在2013年1月20日前披露2012年度未经审计资产负债表、利润表及净资本计算表；82家财务公司、40家信托公司、17家金融租赁公司、3家资产管理公司、7家汽车金融公司及6家保险公司需在2013年1月15日前披露2012年度资产负债表及利润表。

**一、**披露文件要求

信息披露文件应以不可修改的PDF格式，通过中国货币网的信息披露栏目里的“信息披露上传”界面上传，文件审核无误后将在信息披露栏目中的“集中信息披露”里展示。具体要求如下：

1、填报完成的财务报表中，需在资产负债表、利润表等报表左上方“填报单位”处加盖单位公章，证券公司提供的净资本计算表也应加盖单位公章。

2、加盖公章后的报表均统一转换成一个PDF格式的文件，扫描文件必须数字清楚，且报表必须旋转正面方便阅读。

3、电子版文件的文件名应包含金融机构全称、报表年度，报表文件名如：中信证券股份有限公司2012年未经审计财务报表。

4、资产负债表、净资本计算表、利润表须注明报表所属年度、记账币种和金额单位。

**二、**注意事项

1、已经在证券交易所上市的证券公司、信托公司、保险公司（下表用*表示），按规定可以豁免在银行间市场披露。

2、各家金融机构指定的负责上传信息披露事务的联系人如有变动，请及时与同业拆借中心货币网场务联系，办理变更手续。

3、如已发布的《市场成员基本情况表》中的内容发生了变化，请及时更新，并在提交2012年度未经审计财务报表时一起报送。

4、请各有关成员提前准备，尽早将信息披露文件通过货币网自助上传通道报送至同业拆借中心。

上报的资信文件请控制在30M以内，如上传系统出现问题导致不能上传时，请将文件通过Email方式报送，邮件地址：xinxi@chinamoney.com.cn，报送成功后请即电话确认，联系人：陈蔚，联系电话：021-50791761。
