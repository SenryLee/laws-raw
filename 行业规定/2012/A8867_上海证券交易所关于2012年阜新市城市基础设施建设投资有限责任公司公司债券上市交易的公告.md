# 上海证券交易所关于2012年阜新市城市基础设施建设投资有限责任公司公司债券上市交易的公告

阜新市城市基础设施建设投资有限责任公司发行的2012年阜新市城市基础设施建设投资有限责任公司公司债券，将于2012年11月12日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12阜城投”，证券代码为“122539”。债券上市后可进行质押式回购，质押券申报和转回代码为“104539”。

上海证券交易所　

二○一二年十一月九日
