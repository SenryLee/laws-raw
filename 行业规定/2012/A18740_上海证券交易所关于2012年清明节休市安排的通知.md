# 上海证券交易所关于2012年清明节休市安排的通知

## 上海证券交易所关于2012年清明节休市安排的通知（上证交字〔2012〕24号）

各会员单位：

根据《关于2012年全年休市安排的通知》（上证交字〔2011〕52号），现将2012年清明节休市有关安排通知如下：4月2日（星期一）至4月4日（星期三）休市，4月5日（星期四）起照常开市。另外，3月31日（星期六）、4月1日（星期日）为周末休市。请各会员单位据此安排好有关工作。

上海证券交易所　　

二○一二年三月二十二日
