# 深圳证券交易所关于广东金马旅游集团股份有限公司股票临时停牌的公告(2012)

## 深圳证券交易所关于广东金马旅游集团股份有限公司股票临时停牌的公告

因媒体报道了广东金马旅游集团股份有限公司的控股股东国网能源开发有限公司将转让给神华集团的相关信息，根据《深圳证券交易所股票上市规则》第12.4条的规定，经公司申请，本所将于2012年4月26日开市起对金马集团（证券代码为000602）进行临时停牌，待公司刊登相关公告后复牌。

深圳证券交易所　　

二〇一二年四月二十六日
