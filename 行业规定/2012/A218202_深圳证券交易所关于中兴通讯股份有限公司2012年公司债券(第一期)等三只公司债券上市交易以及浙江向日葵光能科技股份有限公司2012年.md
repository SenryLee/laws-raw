# 深圳证券交易所关于中兴通讯股份有限公司2012年公司债券(第一期)等三只公司债券上市交易以及浙江向日葵光能科技股份有限公司2012年非公开发行公司债券(第一期)进行转让的通知

## 深圳证券交易所关于中兴通讯股份有限公司2012年公司债券（第一期）等三只公司债券上市交易以及浙江向日葵光能科技股份有限公司2012年非公开发行公司债券（第一期）进行转让的通知

各会员单位：

中兴通讯股份有限公司2012年公司债券（第一期）、海南海药股份有限公司2012年公司债券和比亚迪股份有限公司2011年公司债券（第一期）定于2012年7月16日起在本所集中竞价系统和综合协议交易平台上市交易，浙江向日葵光能科技股份有限公司2012年非公开发行公司债券（第一期）定于2012年7月16日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、中兴通讯股份有限公司2012年公司债券（第一期）证券代码“112090”，证券简称“12中兴01”，发行总额60亿元，票面利率4.20%，债券期限3年。

2、海南海药股份有限公司2012年公司债券证券代码“112092”，证券简称“12海药债”，发行总额5亿元，票面利率5.20%，债券期限5年，附第3年发行人上调票面利率选择权和投资者回售选择权。

3、比亚迪股份有限公司2011年公司债券（第一期）证券代码“112093”，证券简称“11亚迪01”，发行总额30亿元，票面利率5.25%，债券期限5年，附第3年发行人上调票面利率选择权和投资者回售选择权。

4、浙江向日葵光能科技股份有限公司2012年非公开发行公司债券（第一期）证券代码“112091”，证券简称“12向日01”，发行总额3亿元，票面利率9.6%，债券期限5年，附第3年发行人上调票面利率和投资者回售选择权。

深圳证券交易所
