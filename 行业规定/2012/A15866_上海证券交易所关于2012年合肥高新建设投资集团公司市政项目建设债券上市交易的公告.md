# 上海证券交易所关于2012年合肥高新建设投资集团公司市政项目建设债券上市交易的公告

合肥高新建设投资集团公司发行的2012年合肥高新建设投资集团公司市政项目建设债券将于2012年5月17日起在本所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12合高新”，证券代码为“122684”。上市后该债券可进行质押式回购，质押券申报和转回代码为“104684”。

上海证券交易所　

二○一二年五月十六日
