# 中国质量协会供销合作系统分会关于召开2012年全国供销合作社系统追求卓越会议的通知

各省、自治区、直辖市及计划单列市、副省级省会城市、新疆生产建设兵团供销合作社质量管理机构，有关供销社及企事业单位：

为贯彻落实国家《质量发展纲要》，推进质量强国、强社、强企建设，传达贯彻国家质检总局、工信部、全国总工会、全国妇联、中国科协和中国质协联合举办“全国第34次质量管理小组代表会议”和“第十二届全国追求卓越大会”精神。宣传和分享荣获全国供销合作社系统质量奖、实施卓越绩效模式先进企业、优秀质量管理小组、质量信得过班组等的成功经验，引导和激励我国供销合作社系统广大企业开展质量管理小组活动、实践卓越绩效模式，不断创新和持续改进，提升国内国际竞争能力。经中华全国供销合作总社及有关部门领导同意，中国质量协会供销合作系统分会定于2012年12月中旬在深圳召开“2012年全国供销合作社系统追求卓越会议”。现将有关事宜通知如下：

**一、**会议内容与形式

（一）开幕式

1.领导讲话

2.举行2012年全国供销合作社系统质量奖颁奖仪式

3.对2012年全国供销合作社系统实施卓越绩效模式先进企业颁奖

4．表彰2012年度全国供销合作社系统优秀质量管理小组、质量信得过班组、质量管理小组活动优秀企业、卓越领导者、优秀推进者。

5.传达贯彻第十二届全国追求卓越大会、全国第34次质量管理小组代表会议精神。

6.总结交流各地供销合作社质量管理情况和经验，研究部署明年质量工作。

（二）高层论坛

2012年全国供销合作社系统质量奖、实施卓越绩效模式先进企业获奖企业高层领导对话。

（三）经验分享

有本年度全国供销合作社系统质量奖、实施卓越绩效模式先进企业、优秀质量管理小组、质量信得过班组、优秀企业等获奖单位专题进行经验交流。

（四）参观考察

具体时间、地点待征求参会代表意见后决定。

**二、**参会人员：

（一）各省、自治区、直辖市及计划单列市、副省级省会城市、新疆生产建设兵团供销合作社负责质量工作的领导和质量部门负责人。

（二）2012年全国供销合作社质量奖获奖、创奖企业和全国供销合作社系统实施卓越绩效模式先进企业的主要负责人和质量部门负责人

（三）2012年全国供销合作社系统优秀质量管理小组、质量信得过班组、质量管理小组活动先进企业的主要负责人和质量部门负责人。

（四）历年全国供销合作社系统质量奖获奖、确认、鼓励奖、创奖企业、实施卓越绩效模式先进企业、优秀质量管理小组、质量信得过班组、质量管理小组活动先进企业的高层领导及管理团队。

（五）会员企业高层领导和质量部门负责人。

（六）有意学习质量管理，实施卓越绩效模式的供销合作社及企事业单位领导和管理人员。

**三、**会议时间：

会议具体时间、地点另行通知。
