# 银行间市场清算所股份有限公司关于开展现券净额清算会员业务评价的通知

## 银行间市场清算所股份有限公司关于开展现券净额清算会员业务评价的通知（清算所发[2012]8号）

各现券净额清算会员：

为促进银行间债券市场现券交易净额清算（以下简称现券净额）业务发展，进一步提高清算效率，防范市场风险，银行间市场清算所股份有限公司（以下简称上海清算所）从2012年3月起对现券净额清算会员进行业务评价，具体如下：

**一、**评价指标

评价指标由净额清算绝对量指标、相对量指标、风险控制指标和其他指标构成。具体指标及含义为：

（一）净额清算金额：指实际纳入净额清算的现券交易金额之和；

（二）净额清算笔数：指实际纳入净额清算的现券交易总笔数；

（三）净额清算金额占比：指实际纳入净额清算的现券交易金额与该清算会员可纳入净额清算的全部现券交易总金额之比；

（四）净额清算笔数占比：指实际纳入净额清算的现券交易笔数与该清算会员可纳入净额清算的全部现券交易笔数之比；

（五）风控指标：为预置分数项，清算会员在现券净额清算业务中，如有违规违约情况则相应扣减分数；

（六）其他指标：为预置分数项，清算会员在评价期内业务开展如有异常情况则相应扣减分数。

**二、**权重及分值计算

（一）各指标的权重和预置分数见下表：

|  |  |  |  |
| --- | --- | --- | --- |
| 指标名称 | 分值 | | |
| 相对分 | 排名分 | 总分 |
| 净额清算金额 | 15 | 10 | 25 |
| 净额清算笔数 | 10 | 10 | 20 |
| 净额清算金额占比 | 10 | 5 | 15 |
| 净额清算笔数占比 | 10 | 5 | 15 |
| 风控指标 | - | - | 15 |
| 其他指标 | - | - | 10 |
| 合计 |  |  | 100 |

（二）相对分的计算方式为：

清算会员某项指标相对分＝（该清算会员该项指标统计数/所有清算会员该项指标最高值）×该指标相对分分值

（三）排名分的计算方式为：单项指标值最高的清算会员，该项指标得分为满分，其余清算会员的该项指标得分按单项排名依次递减，递减分值为“单项排名分满分值/清算会员总数”。其中，如清算会员评价期内工作日日均净额清算笔数少于1笔的，该清算会员的“净额清算笔数”及“净额笔数占比”的总分计为O分。计算结果四舍五入，保留小数点后1位。

（四）风控指标得分根据清算会员评价期内违规违约情况确定，发生一次资金结算或债券结算违约的，扣5分；发生一次保证金违约的，扣2分，直至0分。无违规违约的，得满分。其他指标由上海清算所根据各清算会员业务开展情况，遵循实事求是、公平、公正的原则进行内部评分，无异常情况则该项得满分。

**三、**实施

上海清算所每月月初发布上月清算会员评价情况。当月申请成为现券净额清算会员的，自次月起纳入评价。月度评价结果将作为上海清算所现券净额清算会员年度专项评优的依据，并在综合清算会员遴选、开展创新业务等方面予以优先考虑。
