# 深圳证券交易所关于2012年记账式附息(十八期)国债上市交易的通知

## 深圳证券交易所关于2012年记账式附息（十八期）国债上市交易的通知

各会员单位：

2012年记账式附息（十八期）国债（以下简称“本期国债”）已发行结束，根据财政部通知，本期国债于2012年10月8日起在本所上市交易。

本期国债为20年期固定利率附息式国债，证券编码“101218”，证券简称“国债1218”，票面利率4.10%，标准交易单位“10张”，2032年9月27日到期还本并支付最后一期利息。

特此通知
