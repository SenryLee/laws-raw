# 上海证券交易所关于2012年地方政府债券(九期、十期)上市交易的通知

## 上海证券交易所关于2012年地方政府债券（九期、十期）上市交易的通知（上证债字〔2012〕353号）

各会员单位：

根据《财政部关于代理发行2012年地方政府债券（九期）有关事宜的通知》（财库[2012]135号）、《财政部关于代理发行2012年地方政府债券（十期）有关事宜的通知》（财库[2012]136号 ）和上海证券交易所（以下简称“本所”）有关规定，2012年地方政府债券（九期）和2012年地方政府债券（十期）（以下简称“本期债券”）将于2012年9月21日在本所竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期债券为固定利率债券，起息日为2012年9月17日，每年9月17日支付利息（逢节假日顺延，下同），到期日偿还本金并支付最后一次利息；本期债券的期限、票面利率和到期日如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 债券全称 | 期限 | 票面利率 | 到期日 |
| 2012年地方政府债券（九期） | 3年 | 3.47% | 2015年9月17日 |
| 2012年地方政府债券（十期） | 5年 | 3.58% | 2017年9月17日 |

**二、**本期债券于2012年9月21日起在本所竞价系统和固定收益证券综合电子平台上市，交易方式为现券和回购。

**三、**本期债券上市交易的现券证券简称、证券代码和出入库代码如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 债券全称 | 证券简称 | 证券代码 | 出入库代码 |
| 2012年地方政府债券（九期） | 12地债09 | 130088 | 106088 |
| 2012年地方政府债券（十期） | 12地债10 | 130089 | 106089 |
