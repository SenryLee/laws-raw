# 深圳证券信息有限公司关于发布巨潮国元皖江30指数的公告

为反映安徽省经济发展与产业结构的特点，表征安徽细分行业龙头上市企业的运行趋势，满足区域投资的需要，深圳证券信息有限公司定于2012年12月18日发布巨潮国元皖江30指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399350 | 巨潮国元皖江30指数 | 皖江30 | 2010年6月30日 | 1000 |

巨潮国元皖江30指数由深圳证券信息有限公司与国元证券股份有限公司联合编制。该指数依据巨潮行业分类标准，采用营业收入、净利润、成交金额和流通市值四个指标对所有A股进行排名，选取安徽省在各细分行业处于全国前列的30家上市公司组成样本股。

巨潮国元皖江30指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//index.cninfo.com.cn）。
