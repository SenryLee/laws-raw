# 深圳证券交易所关于“N宜通世 ”盘中临时停牌的公告

“N宜通世 ”（300310）盘中换手率达到或超过50％，根据本所《关于完善首次公开发行股票上市首日盘中临时停牌制度的通知》等有关规定，本所自今日09时43分36秒起对该股实施临时停牌，于14时57分复牌。

本所郑重提示广大投资者注意投资风险，理性投资。

特此公告

深圳证券交易所　　

二〇一二年四月二十五日
