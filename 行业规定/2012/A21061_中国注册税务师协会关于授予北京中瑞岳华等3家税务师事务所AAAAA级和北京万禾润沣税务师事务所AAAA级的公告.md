# 中国注册税务师协会关于授予北京中瑞岳华等3家税务师事务所AAAAA级和北京万禾润沣税务师事务所AAAA级的公告

北京中瑞岳华税务师事务所有限公司（以下简称“北京中瑞岳华”）、江苏税联信税务师事务所有限公司（以下简称“江苏税联信”）申报了AAAAA级税务师事务所；尤尼泰（河北）税务师事务所有限公司、尤尼泰（湖南）税务师事务所有限公司、尤尼泰（贵州）税务师事务所有限公司（以下分别简称“尤尼泰＜河北＞”、“尤尼泰＜湖南＞”、“尤尼泰＜贵州＞”）申报了AAAAA级分支机构；北京万禾润沣税务师事务所有限公司（以下简称“北京万禾润沣”）申报了AAAA级税务师事务所。经中税协审核公示后，无异议，由常务理事书面审议批准，同意认定：

1、北京中瑞岳华和江苏税联信为AAAAA级税务师事务所；

2、尤尼泰（河北）、尤尼泰（湖南）、尤尼泰（贵州）为AAAAA级分支机构；

3、北京万禾润沣为AAAA级税务师事务所。

现予公告。

中国注册税务师协会

二○一二年二月六日
