# 中国银行业协会关于报送“2012年度银行服务改进情况材料”的通知

## 中国银行业协会关于报送“2012年度银行服务改进情况材料”的通知（2012年12月）

各会员银行：

《中国银行业服务改进情况报告》的相继发布，为促进银行业与社会各界的良性沟通起到了积极作用，逐步提高了金融消费者对银行业服务情况的认知度和满意度。为编写《2012年度中国银行业服务改进情况报告》，现请各会员单位报送服务改进情况材料。具体报送材料及要求如下：

**一、**2012年服务改进情况总结报告

请各会员单位报送一份本系统的“2012年服务改进情况总结报告”，报告内容涵盖服务基本情况改进、服务渠道改进情况、服务流程改进情况、产品与科技的创新情况、服务亮点展示和客户满意度提升情况等（详见附件1）。

**二、**《2012年度中国银行业服务改进情况报告》数据报送表

请各会员单位按照表格要求，认真填写数据报送表（详见附件2），表述简洁、内容完整。表格电子版请见中国银行业协会网站首页飘窗公告或重要公告栏。

**三、**视频资料

请各会员单位提供一段10-15分钟的视频资料，反映本单位2012年在改进服务质量、提升客户满意度等方面做出的工作及成绩。视频资料要清晰，可编辑，格式为MOV、MPG或MP4，尺寸以1920x1080为宜，也可以是1280x720或1024x576。

**四、**图片资料

请各会员单位提供反映本单位服务状况的图片5-30张，可以是一次事件的记录，或是反应新增设施、网点人员精神面貌的照片。图片要求主题突出、画面清晰，以对图像的简单描述作为文件名，像素不低于1024×768。

**五、**联络人信息表

请各行确定1-2名联络人，并报送2012年银行服务改进情况材料报送联络人信息表（附件3）。

总结报告、数据报送表需同时报送纸质材料（盖公章）及电子版，视频资料、图片资料及联络人信息表报送电子版即可；联络人信息表报送截止时间为2013年1月10日，总结报告、数据报送表、视频资料及图片资料报送截止时间为2013年1月15日。
