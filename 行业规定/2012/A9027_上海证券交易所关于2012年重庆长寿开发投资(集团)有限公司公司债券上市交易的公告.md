# 上海证券交易所关于2012年重庆长寿开发投资(集团)有限公司公司债券上市交易的公告

## 上海证券交易所关于2012年重庆长寿开发投资（集团）有限公司公司债券上市交易的公告

重庆长寿开发投资（集团）有限公司发行的2012年重庆长寿开发投资（集团）有限公司公司债券，将于2012年11月7日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12渝长开”，证券代码为“122544”。债券上市后可进行质押式回购，质押券申报和转回代码为“104544”。

上海证券交易所　

二○一二年十一月六日
