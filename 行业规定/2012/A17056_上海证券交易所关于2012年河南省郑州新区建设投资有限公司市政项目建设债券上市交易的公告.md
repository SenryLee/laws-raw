# 上海证券交易所关于2012年河南省郑州新区建设投资有限公司市政项目建设债券上市交易的公告

河南省郑州新区建设投资有限公司发行的2012年河南省郑州新区建设投资有限公司市政项目建设债券将于2012年4月24日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“12郑新债”，证券代码为“122711”。上市后该债券可进行质押式回购，质押券申报和转回代码为“104711”。

上海证券交易所　　

二○一二年四月二十三日
