# 中国登山协会关于举办2012中国云台山·九九国际登山挑战赛的补充通知

各省、自治区、直辖市登山协会及户外运动俱乐部、大专院校和相关从业机构：

由国家体育总局批准，国家体育总局登山运动管理中心、中国登山协会、河南省体育局、河南省旅游局、焦作市人民政府主办，焦作市体育局、修武县人民政府、焦作云台山旅游发展有限公司承办的2012·中国云台山九九国际登山挑战赛将于2012年9月9日在河南省焦作市修武县云台山举办。现将报到具体事宜发给你们，请做好参赛工作。

**一、**报到时间：2012年9月8日

**二、**报到地点：

（一） 男子青年组、女子青年组、女子中年组

七贤山庄度假酒店

地址：焦作市修武县七贤镇（原方庄镇）转盘向西（焦作方向）800米处；

（二） 男子中年组

云台度假酒店

地址：焦作市修武县七贤镇（原方庄镇）转盘西南角

**三、**报到时需提交个人体检证明、身份证复印件、报名费100元整、人身意外保险复印件。

**四、**报到时需领取号码布、运动员秩序册、纪念T恤、帽子、运动员证件（凭此证可免9-10日云台山景区门票）。

**五、**组委会将于9月8日下午14：00安排大巴在新乡火车站及郑州机场接站，如您需要乘坐大会大巴，请于9月4日前报组委会，以便我们将统计车辆安排。

（报到住宿）咨询热线：0391-7708001
