# 深圳证券交易所关于为重庆市涪陵区民用爆破器材专营有限公司2012年中小企业私募债券等3只私募债券提供转让服务有关事项的通知

各会员单位：

重庆市涪陵区民用爆破器材专营有限公司2012年中小企业私募债券、重庆永鹏网络科技股份有限公司2012年中小企业私募债券和中兴能源有限公司2012 年（第一期）中小企业私募债券定于2012年10月24日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、重庆市涪陵区民用爆破器材专营有限公司2012年中小企业私募债券证券代码“118017”，证券简称“12民爆债”，发行总额14，000万元，票面利率7.28%，债券期限1年。

2、重庆永鹏网络科技股份有限公司2012年中小企业私募债券证券代码“118019”，证券简称“12永鹏债”，发行总额3，000万元，票面利率10%，债券期限2.5年。

3、中兴能源有限公司2012 年（第一期）中小企业私募债券证券代码“118020”，证券简称“12中能01”，发行总额10，000万元，票面利率9.30%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所　　

二○一二年十月二十三日
