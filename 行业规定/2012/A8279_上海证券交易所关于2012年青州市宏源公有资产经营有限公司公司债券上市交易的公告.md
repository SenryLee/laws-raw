# 上海证券交易所关于2012年青州市宏源公有资产经营有限公司公司债券上市交易的公告

青州市宏源公有资产经营有限公司发行的2012年青州市宏源公有资产经营有限公司公司债券，将于2012年11月23日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券分两个品种，品种一为7年期，证券简称为“12青州01”，证券代码为“122516”；品种二为6年期，证券简称为“12青州02”，证券代码为“122517”。

上海证券交易所　　

二○一二年十一月二十二日
