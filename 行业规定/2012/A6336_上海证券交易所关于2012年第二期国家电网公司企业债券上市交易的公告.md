# 上海证券交易所关于2012年第二期国家电网公司企业债券上市交易的公告

国家电网公司发行的2012年第二期国家电网公司企业债券，将于2013年1月4日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券分两个品种，品种一为7年期，证券简称为“12国网03”，证券代码为“124063”；品种二为10年期，证券简称为“12国网04”，证券代码为“124064”。债券上市后可进行质押式回购，其中品种一质押券申报和转回代码为“103063”，品种二质押券申报和转回代码为“103064”。

上海证券交易所　　

二○一二年十二月三十一日
