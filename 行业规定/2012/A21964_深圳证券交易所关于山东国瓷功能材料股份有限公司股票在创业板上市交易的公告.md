# 深圳证券交易所关于山东国瓷功能材料股份有限公司股票在创业板上市交易的公告

山东国瓷功能材料股份有限公司人民币普通股股票将于2012年1月13日在本所创业板上市。证券简称为“国瓷材料”，证券代码为“300285”。公司人民币普通股股份总数为62，400，000股，其中首次上网定价公开发行的12，480，000股股票自上市之日起开始上市交易。
