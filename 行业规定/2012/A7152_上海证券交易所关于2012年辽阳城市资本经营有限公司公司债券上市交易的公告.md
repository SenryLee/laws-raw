# 上海证券交易所关于2012年辽阳城市资本经营有限公司公司债券上市交易的公告

辽阳城市资本经营有限公司发行的2012年辽阳城市资本经营有限公司公司债券，将于2012年12月18日起在上海证券交易所交易市场竞价系统和 固定收益证券综合电子平台上市交易。该债券证券简称为“12辽城经”，证券代码为“124020”。债券上市后可进行质押式回购，质押券申报和转回代码为 “103020”。

上海证券交易所　　

二○一二年十二月十七日
