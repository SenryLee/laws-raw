# 深圳证券交易所关于江西煌上煌集团食品股份有限公司股票上市交易的公告

江西煌上煌集团食品股份有限公司人民币普通股股票将于2012年9月5日在本所上市。证券简称为“煌上煌”，证券代码为“002695”。公司人民币普通股股份总数为123，876，522股，其中首次公开发行的30，980，000股股票自上市之日起开始上市交易。
