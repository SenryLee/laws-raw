# 中国登山协会关于2012年12月到期的从业资格证书的验审通知

登山及相关运动专业技术人员证书持有者：

为落实中国登山协会资格证书验审制度，规范资格证书的管理，使其更好地与社会体育指导员职鉴体系接轨，中国登山协会于即日起至2013年1月31日对已到期的相关资格证书进行验审。

请获得中国登山协会颁发的登山及相关运动专业技术人员资格证书（包括攀岩指导员、户外指导员、拓展指导员三大类别）且证书于2012年12月31日前到期的学员（见附件一），以及以往因故未参加证书验审且证书已过期的学员按规定提交如下验审材料：

一、资格证书验审登记表及验审报告（见附件二）；

二、已取得的资格证书原件；

证书丢失或其他原因需要补办新证书的学员，另需提交如下材料：

一、证书丢失证明（见附件三）

二、个人一寸彩色近照一张

验审材料按要求填好后请于2013年1月31日前邮寄至北京市东城区体育馆路9号，中国登山协会443房间，邮编：100763，收件人：赵玉燕。

中国登山协会将于收到验审材料后1个月内寄回验审通过者的资格证书，新的有效资格证书名单将于2013年2月发布，之后仍然按照资格管理的相关规定进行统一管理。请广大学员见本通知后相互转告并按期办理。

关于证书验审事宜，请咨询：010-67141415。
