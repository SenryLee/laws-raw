# 深圳证券交易所关于江苏省交通科学研究院股份有限公司股票在创业板上市交易的公告

江苏省交通科学研究院股份有限公司人民币普通股股票将于2012年1月10日在本所创业板上市。证券简称为“苏交科”，证券代码为“300284”。公司人民币普通股股份总数为240，000，000股，其中首次上网定价公开发行的48，000，000股股票自上市之日起开始上市交易。
