# 上海证券交易所调整部分收费标准的通知

各市场参与主体：

经中国证券监督管理委员会批准，从2012年6月1日起本所对部分收费标准作如下调整：

**一、**A股证券交易经手费收费标准由原按交易额0.11‰收取降为按0.087‰收取。

**二、**股票上市初费和上市年费按档收取，各档收费标准为：

|  |  |  |
| --- | --- | --- |
| 股本总额 | 上市初费标准（万元） | 上市年费标准（万元） |
| 2亿（含） | 30 | 5 |
| 2亿-4亿（含） | 45 | 8 |
| 4亿-6亿（含） | 55 | 10 |
| 6亿-8亿（含） | 60 | 12 |
| 8亿以上 | 65 | 15 |

收费标准中的股本总额由A股、B股构成，不包括H股，上市年费股本总额按上年末A股、B股总额计算。
