# 上海证券交易所关于2012年延安城市建设投资开发有限责任公司企业债券上市交易的公告

延安城市建设投资开发有限责任公司发行的2012年延安城市建设投资开发有限责任公司企业债券将于2012年5月3日起在本所交易市场竞价系统和固定收益证券综合电子平台上市交易，该债券证券简称为“12延城投”，证券代码为“122740”。上市后该债券可进行质押式回购，质押券申报和转回代码为“104740”。

上海证券交易所

二○一二年四月二十七日
