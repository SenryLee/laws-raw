# 中国总会计师协会关于赴台湾参加2012海峡两岸首席财务官论坛预报名的通知

## 中国总会计师协会关于赴台湾参加2012海峡两岸首席财务官论坛预报名的通知（中总协〔2012〕8号）

各地方总会计师协会（研究会）、各分会、各常务理事、理事及会员单位：

为进一步推动海峡两岸经贸关系和平稳定发展，密切两岸总会计师（CFO）、财务总监等企业财务负责人之间的交流与往来，我会继2010年首度与台湾同业协会——中华财务主持人协会在浙江杭州共同举办“2010海峡两岸首席财务官论坛”后，拟定于2012年9月在台北举办“2012海峡两岸首席财务官论坛”。这将是我会首次与台湾同业组织在台湾地区联合举办两岸财务高层论坛活动，是协会对台交流的又一次重要活动。本次论坛的主题拟定为：ECFA签订后及欧债风暴影响下，首席财务官之应对策略。届时我会将组团赴台参加本次活动。

为保证此次因公团组人员顺利完成赴台各项审批手续，我会现开始因公团组的预报名工作。我会将根据预报名情况报中国科协立项审批。有关预报名事项通知如下：

**一、** 论坛等活动的安排（拟）：

1、论坛举办时间：

9月10日，会议报到；

9月11日，论坛及交流活动。

2、会后交流活动

拜访台湾证交所，拜访中华财务主持人协会并与会员座谈等。

会议日程及具体行程待正式报名时一并下达。

**二、**预报名人员要求：

协会及各地方协会、分会所属会员单位的总会计师、财务主管及财会部门负责人。

**三、**出团时间及方式：

出发时间初步定为2012年9月9日，返回时间2012年9月16日，共计8天。所有人员在北京统一集中，由北京出发，直飞台北。

**四、**赴台费用说明：

参加论坛会议费、机票、团费等费用合计约为人民币每人14800元，费用标准及明细在正式报名时确定并予以说明。

**五、**预报名名额及时间：

预报名名额为30人，预报名截止日期3月9日。请按要求填写赴台预报名申请表（见附件），传真或发电子邮件至我会国际部。

**六、**联系方式：

联系人：叶婷婷、沈峻梅，

电话：010-88191866、88191834，传真：010-88191813，

电子邮件：cacfo@cacfo.com，

地址：北京市海淀区阜成路甲28号新知大厦1814A室中国总会计师协会国际部，邮编：100142。

附件：赴台湾参加2012海峡两岸首席财务官论坛预报名申请表
