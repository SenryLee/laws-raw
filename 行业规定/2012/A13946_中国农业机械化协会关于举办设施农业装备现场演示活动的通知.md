# 中国农业机械化协会关于举办设施农业装备现场演示活动的通知

## 中国农业机械化协会关于举办设施农业装备现场演示活动的通知（农机（协）[2012]22号）

各有关单位及个人：

为贯彻落实2012年中央一号文件精神，加快推进现代设施农业装备发展，根据协会工作安排，经农业部农业机械化管理司同意，决定于2012年8月1日在北京举办设施农业装备现场演示活动。现将有关事项通知如下：

**一、**活动时间和地点

时　　间：2012年8月1日，会期一天，7月31日报到。　　报到地点：北京京民大厦

地　　址：北京市朝阳区华严里10号电　　话：010-62020011

演示现场：北京市昌平区小汤山特菜基地。

**二、**组织单位

主办单位：中国农业机械化协会

协办单位：中国农机化导报、北京市农林科学院、北京市农业机械试验鉴定推广站、北京市农业技术推广站、浙江省台州市一鸣机械设备有限公司。

**三、**活动的主要内容

（一）专题报告会（8月1日上午在北京京民大厦）

1、我国设施农业发展现状与前景，设施装备补贴政策及相关情况

--农业部农业机械化管理司领导

2、设施水肥一体机关键技术及分析

--北京市农林科学院王秀博士

3、蔬菜育苗播种机核心技术探讨与应用

--北京农业机械试验鉴定推广站副站长秦贵

4、中国设施园艺未来发展展望

--农业部规划设计研究院设施农业研究所所长齐飞

（二）设施装备演示展示活动（8月1日下午在北京市小汤山特菜基地）

设施蔬菜育苗播种机现场演示；设施水肥一体机及各类设施植保机械，嫁接机和机器人现场演示；设施农业相关设备展示。

**四、**参加人员

农业部、部分省（区、市）农机管理局（办公室）有关领导出席活动。

参加人员有：中国农业机械化协会会员，各省（区、市）农机科研、推广、鉴定单位的专家；设施农业示范点的代表，各相关企业，农机专业大户、合作社代表。

**五、**其他事项

1、本次活动对中国农业机械化协会会员不收取会务费，其它与会人员收取会议资料、交通等会务费500元；食宿统一安排，费用自理。

2、活动不安排接站，请代表自行前往京民大厦。

3、为便于预定房间，请各位代表填写《参会回执表》（见附件），并于7月24日前发传真或邮件至中国农业机械化协会。
