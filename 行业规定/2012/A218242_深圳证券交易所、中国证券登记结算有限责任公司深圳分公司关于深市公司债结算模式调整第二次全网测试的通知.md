# 深圳证券交易所、中国证券登记结算有限责任公司深圳分公司关于深市公司债结算模式调整第二次全网测试的通知

各会员及其他相关单位：

为了确保深市公司债结算模式调整业务的顺利上线启用，深圳证券交易所联合中国结算深圳分公司在2012年6月30日第一次全网测试的基础上，定于2012年7月14日组织第二次全网测试，通过模拟公司债集中竞价交易、公司债协议交易、私募债份额转让以及结算处理过程，检验市场参与各方技术系统的正确性。

现将有关事项通知如下：

1、本次模拟测试的内容包括：

（1）公司债交易、私募债转让模拟测试；

（2）结算处理模拟测试。

请所有会员单位及与本次测试相关的单位认真组织测试，落实专人负责本次测试工作。测试方案见《深市公司债结算模式调整第二次全网测试方案》（可从深圳证券交易所网站www.szse.cn 之“技术专栏”处查阅）。

2、深市公司债结算模式调整的相关业务上线启用时间为2012年7月16日。

3、测试工作完成后，各会员单位应在2012年7月15日12：00之前登录本所“会员网上业务专区”首页“快速导航―在线调查表”栏目填写并提交《深市公司债结算模式调整第二次全网测试反馈表》；非会员用户请将填报好的反馈表发送至sseyxb@szse.cn。

登录本所“会员网上业务专区”需使用专用电子认证证书（Ekey），具体方法可询问各自单位负责每月技术月报的填报人员或负责会籍席位业务的人员。

4、2012年7月14日中国结算深圳分公司实时开户生产系统暂停服务；2012年7月15日恢复服务。

5、测试日的所有数据仅为技术测试使用，不可作为任何交易、非交易、实时开户等业务的依据。请会员及相关单位做好向投资者的宣传提示工作。
