# 上海证券交易所关于2012年地方政府债券(三期)上市交易的通知

## 上海证券交易所关于2012年地方政府债券（三期）上市交易的通知（上证债字〔2012〕252号）

各会员单位：

根据《关于发行2012年地方政府债券（三期）有关事宜的通知》（财库[2012]77号）和本所有关规定，2012年地方政府债券（三期）（以下简称“本期债券”）将于2012年7月16日在本所竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期债券为固定利率债券，期限为3年，票面利率为2.75%，利息每年支付一次；本期债券起息日为2012年7月10日，每年7月10日支付利息（逢节假日顺延，下同），2015年7月10日偿还本金并支付最后一次利息。

**二、**本期债券于2012年7月16日起在本所竞价系统和固定收益证券综合电子平台上市，交易方式为现券和回购。

**三、**本期债券上市交易的现券证券名称为“12地债03”，证券代码为“130078”，出入库代码为“106078”。

上海证券交易所　

二○一二年七月十三日
