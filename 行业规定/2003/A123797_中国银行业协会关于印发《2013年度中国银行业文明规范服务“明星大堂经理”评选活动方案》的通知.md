# 中国银行业协会关于印发《2013年度中国银行业文明规范服务“明星大堂经理”评选活动方案》的通知

## 中国银行业协会关于印发《2013年度中国银行业文明规范服务“明星大堂经理”评选活动方案》的通知（银协发[2013]53号）

2013年度中国银行业文明规范服务“明星大堂经理”评选活动方案

为树立文明规范服务先进个人典型，发挥文明规范服务先进个人的示范带头作用，进一步提高银行业营业网点厅堂服务水平，中国银行业协会（以下简称“中银协”）决定在全行业组织开展2013年度中国银行业文明规范服务“明星大堂经理”评选活动（以下简称“评选活动”）。

**一、**评选活动的组织领导

（一）中银协是评选活动的领导机构，负责组织实施评选活动、制定“明星大堂经理”候选个人推荐名额分配表、审核推荐申报材料、审议候选个人名单、组织专家评审等工作。中银协自律工作委员会办公室负责评选活动的组织安排、联络协调、检查验收和评选表彰等各项日常工作。

（二）各会员银行总行（以下简称“总行”）负责本系统评选活动的具体组织实施工作。具体职责为：组织和推动本系统经营机构积极参加评选活动；组织下属经营机构自荐、申报参加评选活动；组织开展“明星大堂经理”候选个人审核评测工作，确定本行“明星大堂经理”候选个人名单；上报“明星大堂经理”候选个人名单申报材料、检查验收报告等相关材料；配合开展审核测评工作；总结本行评选活动经验，收集整理意见和建议等。

（三）各地方银行业协会负责配合中银协开展本地区评选活动的现场评测等检查验收工作。

**二、**评选条件及评选数量

（一）文明规范服务“明星大堂经理”申报条件

1. 严格遵守《中国银行业营业网点大堂经理服务规范》（银协发【2009】136号）的各项规定，无违法、违纪、违规行为；

2. 政治素质较高，遵纪守法，正直诚信，品德高尚，切实贯彻“严格、规范、谨慎、诚信、创新”的“十字”行风；

3. 爱岗敬业，热爱大堂经理岗位，热爱银行事业，遵守本行员工行为准则，具有良好的职业道德；

4. 具有较强的事业心和责任感，主动且全面掌握银行业务知识，业务技能表现突出，具有较高的业务素质和工作能力，业务量考核位居本单位前列，能发挥示范表率作用；个人事迹突出，有学习和推广价值；

5. 具有一定的现场管理能力、观察能力和应变能力；有较强的亲和力及服务意识，具有良好的语言沟通能力，仪表端庄，形象大方，能够为客户提供热情、周到、优质、高效的服务，客户满意度较高；

6. 具有较强的资金安全和风险防范意识，遵守保密纪律，积极保护客户信息不泄漏给第三方，不进行任何误导客户的行为，不对同业的产品及服务进行不当的表述、评论；

7. 从事大堂经理工作岗位两年以上，用工性质不分正式和派遣制；普通话标准，具有一定的英语表达能力，熟练使用电脑办公软件，熟悉本行网上银行、电话银行、手机银行等业务流程；

8. 近两年内未发生各类案件、有效投诉及重大责任事故，业务差错率符合本行考核要求。

（二）文明规范服务“明星大堂经理”评选数量

1. 中银协参照《2012年度中国银行业服务改进情况报告》统计的大堂经理配备情况，并综合考虑各金融机构在全国各地区的覆盖水平，制定“2013年度中国银行业文明规范服务‘明星大堂经理’推荐名额分配表”（附件1）；

2.　各会员银行按照“2013年度中国银行业文明规范服务‘明星大堂经理’推荐名额分配表”中的分配数量，向中银协推荐“明星大堂经理”候选个人，全国范围内共计1000位；

3.　 根据申报材料审核、综合鉴定、专家评审、现场检查等情况综合评价，并提请自律工作委员会审议，最终评选出不超过1000名2013年度中国银行业文明规范服务“明星大堂经理”。

**三、**评选活动主要步骤

（一）准备部署阶段

2013年6月，中银协印发《2013年度中国银行业文明规范服务“明星大堂经理”评选活动方案》，正式启动2013年度中国银行业文明规范服务“明星大堂经理”评选活动。

（二）组织实施阶段

2013年6月至7月，各会员银行总行根据评选活动方案以多种多样的形式组织部署本系统内2013年度中国银行业文明规范服务“明星大堂经理”评选活动，根据2013年度中国银行业文明规范服务“明星大堂经理”评选活动笔试范围（笔试范围及出题要求，详见附件2）出题并组织笔试，组织下属经营机构自荐、申报、选拔“明星大堂经理”。

6月18日之前，各会员银行总行、各地方银行业协会确定评选工作联络员，并将联络员信息表（附件3）上报中银协自律工作委员会办公室备案。

7月22日至7月26日，各会员银行总行组建申报资料审核组，培训审核人员，开展申报资料审核工作。申报资料审核工作覆盖率为100%。

7月31日之前，各会员银行总行按照“2013年度中国银行业文明规范服务‘明星大堂经理’候选个人推荐名额分配表”中的分配数量，确定文明规范服务“明星大堂经理”候选个人名单，统一报送至中银协。申报材料主要包括：

1.2013年度中国银行业文明规范服务“明星大堂经理”申报表（附件4 ），每人一份，需加盖所在单位、省级管辖行和总行共三级公章报送纸质版，并同时报送电子版；

2.　2013年度中国银行业文明规范服务“明星大堂经理”候选个人现场服务照片每人1-2张，报送电子版即可；

3.　本行笔试试卷及答案，报送电子版即可；

4. 2013年度中国银行业文明规范服务“明星大堂经理”申报资料汇总表（附件5 ）， 需加盖公章报送纸质版，并同时报送电子版；

5.　 会员银行总行统一出具的2013年度中国银行业文明规范服务“明星大堂经理”评选推荐报告（附件6）， 需加盖公章报送纸质版，并同时报送电子版。

（三）检查审核阶段

2013年8月，中银协审核申报资料内容完整性。

2013年9月中旬，中银协制定检查方案，并将明星大堂经理候选个人名单按地区发给各地方银行业协会，由各地方银行业协会配合中银协开展现场评测工作，现场检查考核各会员银行推荐的明星大堂经理候选个人服务水平。

2013年10月下旬，中银协组织行业服务专家对部分候选大堂经理进行评审。评审对象由各会员银行择优推荐。专家评审主要以统一笔试、现场答辩、情景模拟等方式考察大堂经理的知识水平、服务技能、厅堂管理和应急处理等方面的能力，拟设置“微笑之星”、“魅力之星”、“财富之星”、“亲善之星”等奖项，每个奖项评选50名，共200名。

对发生下列情形之一的，将取消明星大堂经理候选资格，且不在该明星大堂经理候选人所属会员银行系统内增补，由中银协授权地方银行业协会推荐符合申报条件及明星大堂经理检查考核标准的辖属非中银协会员银行的优秀大堂经理参评：

1.评选期间离职或调离大堂经理岗位；

2.现场测评、专家评审环节未达到考核标准及相关要求的；

3.发生重大责任事故、业务差错、经营风险等，造成严重损失，被上级单位或有关部门查处的；

4.发生服务质量的重大投诉，或被新闻媒体曝光，造成严重负面影响，经调查情况属实的。

（四）产生审议阶段

2013年12月，确定服务“明星大堂经理”候选个人名单，提请中银协自律工作委员会审议“2013年度中国银行业文明规范服务‘明星大堂经理’名单”。

（五）总结表彰阶段

2014年1-3月，中银协通过网站、报刊等媒体向银行业内和社会进行公告，编辑出版《“明星闪耀大堂”（第二辑）》，组织开展2013年度中国银行业文明规范服务“明星大堂经理”表彰活动。

**四、**评选活动相关要求

（一）请各单位充分认识开展本次评选活动的重要意义，树立大局意识，加强组织领导，强化协调沟通，积极开展丰富多彩、形式多样的评选活动，确保评选活动在本单位各层面、各环节落到实处，以文明规范服务为标准，以先进典型的示范作用为导向，共同推进全行业大堂经理文明规范服务水平的全面提升。

（二）请各单位从本单位实际出发，周密部署，扎实推进，制订切实可行、公开公平的评选活动实施方案，严格审核、严格把关，确保评选活动取得实效，深化本地区或本系统文明规范服务意识。经举报核实、审查认定，如有申报情况不真实、被推荐人有重大投诉等情况，将取消该候选人参评资格，并业内通报。

（三）请各单位明确评选活动标准和时间安排，及时掌握各阶段工作进度，按时、高质量上报有关材料，相关报送情况将作为评选活动总结表彰的评奖依据。

**二、**出题要求

各会员银行在出题时，应注重试题的普及性、实用性和针对性，确保试题编撰有据，内容理解无争议，贴近从业人员工作实际。试题的要素应包括命题依据、难度级、题干、选项、正确答案。

（一）命题依据。拟制试题的出处，应具体到法规文件名称、具体法条，或者书名、章节及内容出处。

（二）试题难易程度。试题应分为易、中等、难三档，三种难易程度试题所占比例分别为40%、40%、20%。请根据难度标准，在每编制一道题后，直接注明难易度及题目的出处。

1. 易：考核单一知识点基本概念的记忆与理解；

2. 中等：考核单一知识点的实际应用、操作、计算与分析；

3. 难：考核多个知识点的综合应用与分析。

（三）试题类型。试题以客观题为主，包括填空题、单选题、多选题及判断题。建议题量为填空题20-30道、单选题30-50道、多选题30-50道、判断题20-30道。

1. 填空题。编写填空题时要明确答案范围，以防止模棱两可，确保只能有一个简单的正确答案。

2. 选择题。选择题由题干和备选答案两部分组成。题干可以问题的形式提出，也可以不完整陈述句的形式提出；备选答案由几个迷惑答案和 1 个（单项选择）或者多个（多项选择）正确答案组成。编写选择题应确保题干措辞正确，且包括解题所必须的全部条件，使考生在看到备选答案之前就能清楚地了解试题所提出的问题。提供的备选答案应为长短尽可能一致、内容相近的一组答案。

3. 判断题。判断题的题意必须全对或全错，不能含糊不清，文句应简单扼要。

（四）命题技巧及注意事项：

1. 选择项之间意思不重复，且存在合理逻辑关系，要有意义上的相近性；

2. 题干与选择项之间、选择项之间内容不会互相提示；

3. 语言描述不存在歧义，不会导致理解错误；

4. 正确答案和错误答案的顺序要乱续排列。

（五）样题

1.中国银行业协会在印发的《关于进一步完善残障人士银行服务的自律要求》中提出了（）等相关服务改进要求。

A、有残障人士窗口的银行网点安放便于视力障碍客户使用的密码输入器。

D、在有条件或有实际需要的营业网点设置盲人版业务介绍和指南。
