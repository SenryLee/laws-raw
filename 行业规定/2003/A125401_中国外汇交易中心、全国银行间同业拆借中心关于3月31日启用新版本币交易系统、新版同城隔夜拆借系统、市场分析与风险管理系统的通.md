# 中国外汇交易中心、全国银行间同业拆借中心关于3月31日启用新版本币交易系统、新版同城隔夜拆借系统、市场分析与风险管理系统的通知

## 中国外汇交易中心、全国银行间同业拆借中心关于3月31日启用新版本币交易系统、新版同城隔夜拆借系统、市场分析与风险管理系统的通知（中汇交发[2003]87号）

各交易成员：

交易中心新版本币交易系统、同城隔夜拆借系统、市场分析与风险管理系统（F系统）将于2003年3月31日启用，旧版系统同时停止使用。现将有关事项通知如下：

**一、**业务准备工作

2003年3月26日至29日每日9：00-16：30，新版系统服务器为各交易成员开启。在此期间，交易成员应做好以下准备工作：

（一）在交易子系统“内部管理”菜单下进行数据维护或核对确认。在现有“内部管理”菜单下，我们对不同的菜单项下内容进行了不同的处理，所作处理及交易成员应配合进行的有关工作包括：

1、将3月24日第五次全国模拟中交易成员维护的“交易员管理”、 “通讯录”项下内容保留，各首席交易员可修改、核对、确认有关内容，其中特别需核对本机构首席交易员权限并维护自身交易额度；

2、“成员间授信”、“总分行授权”、“帐户管理”资料由旧系统转入并替换第五次模拟交易成员自行维护的数据，各首席交易员需核对有关内容并根据自身需要进行增减；

3、已清空“小额交易管理”项下所有内容，请各首席交易员重新维护。

（二）请在“本方信息”菜单下核对本机构各项历史成交数据。

（三）请在“内部管理信息”菜单下对各项查询功能的查询结果进行核对。

**二、**技术准备工作

（一） 各交易成员需按下述要求准备好客户端配置：

1、操作系统：简体中文版Windows 2000 Professional，并已安装了Service Pack 2，也可选用简体中文版Windows XP（检查方法：鼠标左键点击【开始】，选择【设置】－＞【控制面板】，双击【系统】，在弹出的窗口中即可看到操作系统的版本）。

2、IE版本（此软件已内置在操作系统中）：中文版Microsoft Internet Explorer 5.5或以上版本（检查方法：打开IE，点击【帮助】菜单下的【关于Internet Explorer】，弹出框内即可看到版本信息）。

3、IE内置JAVA虚拟机版本（JVM）：Microsoft （R） VM for Java， 5.0 Release 5.0.0.3802或以上版本（检查方法：进入命令行窗口，在DOS命令提示符下键入：JVIEW。输出内容为Microsoft （R） VM for Java， 5.0 Release 5.0.0.3802或以上版本）。

4、IE配置：请点击IE（浏览器）中“工具”|“Internet 选项（O）…”菜单项， 选择“高级”标签，在“安全”一项中，请不要选择“检查发行商的证书是否撤销”。请使用IE5.0和6.0用户务必检查一下上述的设置，尤其是IE6.0的用户，由于在IE6.0中，该设置默认是选中的，请您去除该选中。

5、DNS配置：

为了使您能够使用域名地址http：//rmbtrade.chinamoney.com. cn：7001/trade登录新版本币交易系统和使用http：//fsystem. chinamoney.com.cn：7001登录F-系统，不管您是拨号还是专线用户，您必须对您使用的交易机的本地连接（专线用户）或拨号连接（拨号用户）属性中的域名服务器作如下设置。

使用专线的用户如下配置： 点击【开始】-＞【设置】-＞【控制面板】-＞【网络和拨号连接】-＞【本地连接】-＞【属性】-＞【Internet协议（TCP/IP）】-＞【属性】，在弹出的窗口中，选择【使用下面的DNS服务器地址】，在“首选DNS服务器”中输入200.31.10.16，在“备用DNS服务器”中输入200.31.10.17，按【确定】按钮。

使用Modem拨号的用户如下配置：点击【开始】-＞【设置】-＞【控制面板】-＞【网络和拨号连接】，选择【拨号连接】-＞点击右键，选择【属性】，在弹出的窗口中，选择【网络】，选择【Internet协议（TCP/IP）】-＞【属性】，在弹出的窗口中，选择【使用下面的DNS服务器地址】，在“首选DNS服务器”中输入200.31.10.16，在“备用DNS服务器”中输入200.31.10.17，按【确定】按钮。

7、对IP地址的特别说明

专线（不包括拨号）用户必须使用原本币交易系统交易机的IP地址，凡是模拟期间使用的由原本币交易机IP加20（如，原本币交易机地址为xxx.xxx.xxx.101，则新机器的IP地址为：xxx.xxx.xxx.121）的新增IP地址，在新版本币交易系统正式上线后，这些新增IP地址不再有效。如果交易员在IP地址使用上出现问题，请与中国外汇交易中心工程运行部联系，电话：021-63298988转3068，3069。

8、IC卡读卡器驱动程序安装。新版本币交易系统的登录必须使用IC卡，交易员必须安装交易中心指定的IC卡的驱动程序。

9、安装中国外汇交易中心的数字签名

交易员在新版本币交易系统中安装系统时，弹出安全警告设置窗口，则点击该窗口上的 “中国外汇交易中心”链接，弹出证书窗口后，请选择“证书路径”标签，选中“CFETSTCA Root”，再点击按钮【查看证书】后，弹出“证书导入向导”窗口，按提示，点击两次“下一步”后，弹出“根证书存储”窗口，点击“是”，系统提示“导入成功”，就完成了中国外汇交易中心的数字签名安装。如果在以后的登录过程中，系统再次弹出安全警告窗口，则您必须将该窗口上的“总是信任‘中国外汇交易中心[&A]的内容’”选中。

10、新版本币交易系统和F-系统所需补丁软件、驱动、文档下载

登录新版本币交易系统的交易机软硬件配置必须满足以上配置要求，具体要求见附件《新版本币交易系统客户端配置说明》。 若交易员发现交易机软件配置没有符合要求，可以在以下地方下载所需补丁和文档：

（1）新版本币交易系统http：//rmbtrade.chinamoney.com.cn： 7001/trade的登录界面上的【配置说明】中提供客户端配置说明；

（2）中国货币网互联网http：//www.chinamoney.com.cn 和内联网http：//200.31.6.168 中设立新版本币系统上线信息专栏，在该专栏中提供客户端配置所需的补丁和驱动下载，包括中文版Windows 2000 Service Pack 2、JAVA虚拟机（JVM）、IC卡驱动程序。在专栏中同时提供相关文档，包括《新版本币交易系统用户手册》（该手册中包括“全国银行间同业拆借中心电子商务安全证书使用手册”、“新版本币交易系统安装说明”）、《F-系统操作手册》、《新版隔夜拆借用户手册》和《新版本币交易系统常见问题解答》。

在第五次全国模拟演练中成功登录并使用交易系统的交易成员无需再做上述配置。

（三）安装交易系统

1、在浏览器Internet Explorer中，点击“工具”菜单，选中“Internet选项”，在“常规”页中---点击“设置”按钮---点击“查看对象”---请删除文件：rmbsecurity（如果该文件不存在，请直接转到第2步操作），关闭浏览器；

2．重新启动浏览器，访问新版本币交易系统主页：http：//rmbtrade.chinamoney.com.cn：7001/trade 或者http：//200.31.10.8：7001/trade 进入【安装系统】，按【卸载系统】按钮进行卸载，卸载成功后，请按【关闭窗口】按钮。再重新打开IE，进行安装登录。

（四）登录用户名和密码

1、登录交易系统请用交易中心下发的首席交易员用户名，初始密码为：888888；普通交易员登录请用本机构首席交易员赋予的用户名和初始密码。

2、登录隔夜拆借系统请用交易中心下发的用户名和初始密码

3、登录F系统用户名和密码与交易系统相同。

1、希望各单位高度重视新版本币系统的上线试运行，务必做好各项准备工作。

2、考虑到新版本币系统上线工作的需要，交易中心特意在“中国货币网”首页设立“新版本币系统上线信息专栏”，专门发布系统上线方面的动态信息、说明、通知、要求等，请各交易成员每日密切关注。
