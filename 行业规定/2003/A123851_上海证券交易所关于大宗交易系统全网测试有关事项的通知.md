# 上海证券交易所关于大宗交易系统全网测试有关事项的通知

各会员单位：

本所定于6月9日至6月13日进行大宗交易系统上线前全网测试，现将测试相关事项通知如下：

**一、**测试前准备工作

2003年6月6日前参加测试的会员营业部务必做好以下工作：

（一）按照大宗交易用户操作手册完成CA证书安装；

（二）确保安装证书的机器能够接入Internet，测试网址为 http：//61.152.172.80。

**二、**测试时间

测试日期为2003年6月9日-6月13日，其中6月12日为系统压力测试，要求各会员营业部必须参加。

测试时间为15：00至16：00。

|  |  |
| --- | --- |
| 测试时间 | 测试项目 |
| 15：00至15：30 | 大宗交易系统功能测试 |
| 15：30至16：00 | 大宗交易收盘后半小时，在大宗交易系统中下载过户数据（或用新单向卫星接收）进行成交数据校验测试 |

**三、**测试内容

（一）用户登录，包括用户CA认证、系统初始化等；

（二）交易报价，包括意向报价、意向报价撤单，成交申报、成交申报撤单等；

（三）商务交流，包括商务洽谈，商务论坛等；

（四）查询统计，包括意向报价查询，成交申报查询，股票信息查询，在线用户查询等；

（五）系统设置，包括密码修改，股票信息订阅，系统退出等；

（六）大宗交易过户数据校验。

（七）系统压力测试。

**四、**测试数据

（一）数据准备：本次测试以当日收市后的收盘行情、收市后的股份数据作为起始数据，各会员营业部可根据当天收市后实际持股数据进行意向报价和成交申报测试。

（二）本所通过过户数据库dgh?????.dbf（?????为席位号）返回大宗交易过户数据，该数据库与目前日间交易所用的过户数据库gh?????.dbf结构相同，会员营业部可在大宗交易系统中下载（或用新单向卫星接收）过户数据进行校验测试。

注意：该过户数据只作为测试校验使用，各会员收到数据后应及时校验处理。

**五、**测试要求

（一）各会员单位要高度重视此次测试工作，本次测试后，本所原则上不再另行组织同类测试。

（二）各会员单位应指定专人负责测试工作。本所将对所有参测单位进行信息统计，对无故不参加测试的会员，本所将根据有关规定进行处罚。对因不按规定参与测试而影响大宗交易业务的开展责任自负。

（三）6月12日（周四）的系统压力测试，所有已申请大宗交易资格并领取营业部CA证书的会员营业部必须全程参加，具体要求为集中时间登录系统、交易过程中多报价多成交、中途不得退场等。若本日压力测试情况与预期不符，本所将在次日卫星通知该周五再次进行压力测试。

（四）测试过程中，各参测单位应将测试中发现的问题填写测试问题反馈表，及时传真至：021-68800529，测试问题反馈表如附表所示。

**六、**联系电话

测试日本所现场联系电话： 021-68800030转9转5、021-58875514、021-58870093

现场传真： 021-68809992
