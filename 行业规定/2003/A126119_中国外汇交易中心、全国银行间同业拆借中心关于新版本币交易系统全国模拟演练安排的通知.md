# 中国外汇交易中心、全国银行间同业拆借中心关于新版本币交易系统全国模拟演练安排的通知

## 中国外汇交易中心、全国银行间同业拆借中心关于新版本币交易系统全国模拟演练安排的通知（中汇交发[2003]35号）

各交易成员：

交易中心新版本币交易系统的开发工作即将完成。为了保证系统顺利上线和稳定运行，交易中心拟安排三次全国模拟演练，具体演练日期将于近期在“中国货币网”上另行通知。现将有关事项通知如下：

**一、**参加演练的机构

已与全国银行间同业拆借中心交易系统联网的市场成员。

**二、**演练的总体要求

（一）客户端配置说明

1、操作系统：简体中文版Windows 2000 Professional，并已安装了Service Pack 2，也可选用简体中文版Windows XP（检查方法：鼠标左键点击【开始】，选择【设置】－＞【控制面板】，双击【系统】，在弹出的窗口中即可看到操作系统的版本）。如果操作系统不能满足配置，请交易员自行安装符合要求的操作系统版本。

2、IE版本（此软件已内置在操作系统中）：中文版Microsoft Internet Explorer 5.5或以上版本（检查方法：打开IE，点击【帮助】菜单下的【关于Internet Explorer】，弹出框内即可看到版本信息）。

3、IE内置JAVA虚拟机版本（JVM）：Microsoft （R） VM for Java， 5.0 Release 5.0.0.3802或以上版本（检查方法：进入命令行窗口，在DOS命令提示符下键入：JVIEW。输出内容为Microsoft （R） VM for Java， 5.0 Release 5.0.0.3802或以上版本）。

4、DNS配置：

使用专线的用户如下配置：点击【开始】-＞【设置】-＞【控制面板】-＞【网络和拨号连接】-＞【本地连接】-＞【属性】-＞【Internet协议（TCP/IP）】-＞【属性】，在弹出的窗口中，选择【使用下面的DNS服务器地址】，在“首选DNS服务器”中输入200.31.10.16，在“备用DNS服务器”中输入200.31.10.17，按【确定】按钮。

使用Modem拨号的用户如下配置：点击【开始】-＞【设置】-＞【控制面板】-＞【网络和拨号连接】，选择【拨号连接】-＞点击右键，选择【属性】，在弹出的窗口中，选择【网络】，选择【Internet协议（TCP/IP）】，接下来的配置同上。

6、对IP地址的特别说明

参加模拟的专线（不包括拨号）用户可以使用原本币交易系统交易机的IP地址，也可以使用新的交易机参加模拟，新机器的IP地址设置为原本币交易机IP加20（如，原本币交易机地址为xxx.xxx.xxx.101，则新机器的IP地址为：xxx.xxx.xxx.121），新增机器IP地址前面三部分保持不变。新增的IP地址只在模拟期间有效，新版本币交易系统正式上线后，新增IP地址不再有效，还是继续使用原本币交易系统交易机的IP地址。如果交易员在IP地址使用上出现问题，请与中国外汇交易中心工程运行部联系，电话：021-63298988转3068，3069。

7、IC卡驱动程序安装。交易员必须安装由交易中心指定的IC卡驱动程序。

8．新版本币交易系统所需补丁软件、驱动、文档下载

参加模拟的交易机软硬件配置必须满足以上配置要求，具体要求见附件一《新版本币交易系统客户端配置说明》。 如果交易员发现交易机软件配置没有符合要求，交易成员可以从2003年2月24日开始在以下地方下载所需补丁和文档：

http：//rmbtrade.chinamoney.com.cn：7001/trade（使用IC卡的交易系统登录地址）和http：//rmbtrade.chinamoney.com.cn：7001/nosecurity（不用IC卡的交易系统登录地址）、中国货币网互联网http：//www.chinamoney.com.cn/ 、中国货币网内联网http：//200.31.6.168/ 分别提供中文版Windows 2000 Service Pack 2、JAVA虚拟机（JVM）、IC卡驱动程序和《全国银行间同业拆借中心电子商务安全证书使用手册》（包括IC卡的用户责任书、IC卡的申请、安装使用说明）。

为了不影响新版本币交易系统的模拟演练，建议网络速度不够理想的用户去中国货币网上下载所需软件和文档。

注意：请市场成员务必在2003年2月27日前准备好客户端交易机环境。

（二）模拟演练的准备工作

1、请参加演练的首席交易员于演练时间开始时登录系统，登录地址如下：

交易系统（有IC卡的交易员请从以下地址登录）：

http：//rmbtrade.chinamoney.com.cn：7001/trade（交易系统（不使用IC卡的交易员请从以下地址登录））：

http：//rmbtrade.chinamoney.com.cn：7001/nosecurityF-系统（所有交易员请从以下地址登录）：

http：//fsystem.chinamoney.com.cn：7001（/注：在第三次演练时，所有交易员必须使用IC卡登录交易系统）。

2、进入交易系统登录画面后，首席交易员应使用在培训时下发的首席交易员用户名和密码。初始密码为：888888。F系统用户名和密码与交易系统相同。

3、首席交易员登录后应首先进入“内部管理”菜单，完成该菜单项下的数据设置工作。在其后的模拟演练中，新增的交易员即可登录系统。

第一次演练中由首席交易员设置内部管理数据，系统将保留到三次模拟演练结束，但不转入实际运行环境。在演练期间，成员可根据需要对内部管理数据进行修改和维护。

4、演练时的业务权限按照各成员真实权限设置。

（三）模拟演练的内容

新版本币交易子系统包括信用拆借、债券回购、债券买卖、债券分销、以及同城隔夜拆借系统五类市场业务。请参加演练的成员在各自市场业务权限范围内进行模拟交易，每类业务上应至少报价4笔，成交4笔。模拟演练还包括新版本币交易系统向F系统的切换，但F系统功能不在本次演练范围之中。

模拟演练中应完整测试各功能模块的实用性、及时性、容错性、功能与界面设计的合理性，着重进行内部管理设置、报价成交、信息查询等方面的模拟测试。具体操作请参照《本币交易系统（2003）版操作手册》和《F系统操作手册》。

在模拟演练的版本中，我们将旧版系统中的交易基础数据（如交易限额、帐户资料）及历史成交数据和历史行情转入新版系统，请参与演练的成员查验有关数据的正确性，一旦发现问题请立即向我们反映。

每次模拟的报价和成交数据，系统将予以保留，供成员供下一次演练时查验。

（四）模拟演练的注意事项

1、希望各单位高度重视新版本币系统的全国模拟演练工作，届时务必安排相关人员参加。

2、转入模拟演练环境中的场务基础数据（成员表、帐户表、限额表等）和历史交易数据（交易明细、交易行情等）截至2月13日为止。

3、考虑到新版本币系统全国模拟演练工作的需要，交易中心特意在“中国货币网”首页设立“新版本币交易系统全国模拟演练信息专栏”，专门发布全国模拟演练方面的动态信息、说明、通知、要求等，请各交易成员每天密切关注。

4、演练时遇到问题，请立即拨打现场值班电话：

业务支持：021-63298988转5311、5312、5209、5210，或021-63234456、63234457、63230324、63233413。

技术支持：021-63298988转3068、3069，或021-63234771、63215842、63215927。

中介业务：021-63211722。

5、请参加演练的成员在当日模拟演练完毕后，并选择以下两种方式之一，将“新版本币交易系统全国模拟演练情况反馈表”（见附件二）反馈至交易中心：

（1）填写书面反馈表格，并发送传真。传真电话：021-63298441、63234204、63616763、63238998。

（2）登录“中国货币网”，在“新版本币系统全国模拟演练信息专栏”中找出模拟演练情况反馈表，填写电子表格，进行网上提交。
