# 上海证券交易所关于做好申报中增加营业部代码相关技术准备工作的通知

## 上海证券交易所关于做好申报中增加营业部代码相关技术准备工作的通知（上证会字［2003］64号　2003年10月20日）

各会员单位：

由于部分会员采用了集中报盘的交易模式，致使本所现有的信息统计口径出现偏差。为切实解决这一问题，在充分征求部分会员和相应柜面系统开发商意见的基础上，本所决定，在交易申报中增加营业部代码。现将有关事项通知如下：

**一、**各会员单位必须按照《关于统一申报营业部代码的技术方案》（见附件）的要求于2003年12月底完成相关技术准备工作。为便于会员修改相关程序，可在本所网站www. sse. com.cn→会员专区→业务支持→技术支持查阅有关资料。

**二、**各会员单位的非营业场所（总部、国债部、国际部等）仍按原申报方式进行申报。

**三、**营业部代码由本所统一编制，以四字节数字字符型表示，代码使用区间为［1000，4843］。各会员营业部代码可查阅本所网站www. sse. com. cn→会员专区→会员信息→基本信息。

**四、**各会员单位技术准备就绪后，必须组织营业部进行测试工作。测试可在每周二、四常规测试时间进行。全网统一测试时间，本所将另行通知。

**五、**本所将视具体的测试情况，公布增加营业部代码的正式实施日期。

**六、**本所技术咨询电话：021-68802309。

特此通知。

附件：

关于统一申报营业部代码的技术方案

1. 上海证券交易所制订四字节长营业部代码

本所已经利用大宗交易系统的实施制订了一套新的营业部代码，证券系统所有的法定营业部都分配了一个四字节长的唯一代码，该代码的任何一个字节均为数值字符，使用区间为［1000，4843］。各会员营业部代码可通过本所网站www. sse. com.cn→会员专区→会员信息→基本信息查阅。

2. 申报表reff字段第1-2字节填写营业部代码的转换码

目前场外报盘程序数据接口规范中设计了委托与撤单表，表中有reff字段，数据类型为char（10），该字段的用途为卷商自定义。根据调查，目前该字段在券商柜面系统中一般被使用8字节以内。

本所规定，本方案实施以后，委托与撤单表reff字段第1-2字节应该填写营业部代码的转换码，该字段第3-10字节内容仍留券商自定义。其中，营业部代码的转换码仅用于报盘系统内部，不用于日常人工业务。

将本所分配的四字节长营业部代码转换为二字节长转换码的方法如下：

〈1〉定义int类型变量X，X被赋值为营业部代码对应的十进制数值，判断X是否处于［1000，4843］的区间，如果是，进入下面的步骤。

〈2〉定义int类型变量m，n计算m＝（X－1000）/62，n＝（X－1000）b。其中/是除法取整运算，%是除法取余运算。

〈3〉定义int类型变量p、q，计算p、q的公式如下：

if 0＜＝＜m＝9 then p＝m＋48

if 10＜＝＜m＝35 then p＝m＋55

if 36＜＝＜m＝61 then p＝m＋61

if 0＜＝＜m＝9 then q＝n＋48

if 10＜＝＜m＝35 then q＝n＋55

if 36＜＝＜m＝61 then q＝n＋61

〈4〉p、q分别作为转换码第一字节、第二字节的数值。

举例：某营业部四字节长代码为‘1400’，通过公式计算得p＝54，q＝83。因为字符‘6’、‘S’对应的ASCⅡ码值分别为54、83，所以二字节长营业部转换码为‘6S’。reff字段第1-2字节填写‘6S’。

3. 券商柜面系统的软件修改与全面测试

与reff字段内容填写相关的程序由券商组织柜面系统开发商修改，由于reff字段用途定义修改对券商的其他系统所产生的影响由券商自行组织修改。

由于本方案的实施而修改的系统，必须经过全面的测试方能投入正式运行。
