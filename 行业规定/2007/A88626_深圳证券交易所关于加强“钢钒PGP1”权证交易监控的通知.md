# 深圳证券交易所关于加强“钢钒PGP1”权证交易监控的通知

各会员单位：

“钢钒PGP1”（证券代码：038001）将于2007年4月25日停止交易，截止4月18日收市，该权证收盘价为0.730元。鉴于该权证根据Black-Scholes模型计算的理论价值为0，为防范市场风险，维护市场交易秩序，保护投资者合法权益，根据《深圳证券交易所权证暂行管理办法》和《深圳证券交易所交易规则》等规则的规定，本所将对该权证实施重点监控和风险控制措施。现就有关事项通知如下：

**一、**本所从2007年4月19日至4月24日，对“钢钒PGP1”的交易实施盘中价格上涨异常的实时风险提示和临时停牌制度：

1、在“钢钒PGP1”前收盘价在0.010元以上（含0.010元）的交易日， 当盘中价格较前收盘价涨幅达到50%时，本所发布风险提示；当盘中价格较前收盘价涨幅达到80%时，本所将对其实施临时停牌15分钟；复牌后盘中价格较前收盘价涨幅达到100%时，本所将对其实施临时停牌至14：57，恢复收盘集合竞价；

2、在“钢钒PGP1”前收盘价低于0.010元的交易日， 当盘中价格较前收盘价上涨0.005元时，本所发布风险提示；当盘中价格较前收盘价上涨0.008元时，本所将对其实施临时停牌15分钟；复牌后价格较前收盘价上涨0.010元时，本所将对其实施临时停牌至14：57，恢复收盘集合竞价。

临时停牌15分钟跨越收盘集合竞价开始时间14：57的，本所于14：57将其复牌，恢复收盘集合竞价。

临时停牌期间，投资者可以继续申报，也可以撤销申报。

**二、**本所将实时监控“钢钒PGP1”的市场交易，对蓄意操纵交易价格的投资者及相关会员单位将按照有关规定进行查处，必要时将限制相关帐户的权证交易。

**三、**各会员单位要严格按照《深圳证券交易所权证暂行管理办法》、《深圳证券交易所交易规则》和本通知的规定，做好相关规则和制度的宣传和风险教育工作，切实加强对投资者权证交易行为的规范和管理。
