# 中国外汇交易中心、全国银行间同业拆借中心关于公布《银行间外汇市场收费方案》的通知(2007)

## 中国外汇交易中心、全国银行间同业拆借中心关于公布《银行间外汇市场收费方案》的通知（中汇交发[2007]80号）

银行间外汇市场会员：

为适应银行间外汇市场发展需要，经国家外汇管理局批准（汇复〔2007〕107号），现公布调整后的《银行间外汇市场收费方案》。

该方案自2007年4月9日起执行，4月9日之前发生的交易费仍按照原收费标准执行。交易中心将于近日另行通知收取上述费用及2007年终端费。

附件：银行间外汇市场收费方案

二○○七年四月六日

附件：

银行间外汇市场收费方案

中国外汇交易中心（以下简称“交易中心”）根据有偿服务原则，综合考虑银行间外汇市场的发展历史、现状以及国际外汇市场惯例，修订银行间外汇市场收费方案（以下简称“本方案”）。

**一、**费用构成

银行间外汇市场的费用包括：

（一）交易终端费，交易终端是指外汇市场会员（含普通会员和做市商）为外汇交易目的连入由交易中心运行和维护的外汇交易系统的计算机和相关数据接口。交易终端费为固定费用，与交易量大小无关。

（二）交易（和清算）费，会员通过交易中心的系统进行银行间外汇交易、使用交易中心的集中清算服务时，应支付相应的费用；交易量越大，支付的交易（和清算）费越多。

（三）增值服务费，是会员选择使用由交易中心提供的交易辅助服务而支付的相应费用，目前主要为CSTP接口支持费和外汇市场数据接口信息服务费。

**二、**收费标准

（一）交易终端费

1、会员交易终端费的费率为：

|  |  |
| --- | --- |
| 第1台终端 | 3，000人民币元/月 |
| 第2台终端 | 2，000人民币元/月 |
| 第3台终端及以上 | 1，000人民币元/月 |

会员申请的终端数为可以同时接入系统的最大在线终端数。做市商为非做市目的连入交易系统，需支付会员交易终端费。

2、做市商为做市目的连入交易系统，需支付做市商终端费。做市商终端费的费率为：

|  |  |
| --- | --- |
| 外币对交易做市商 | 20，000人民币元/月 |
| 人民币外汇交易做市商 | 30，000人民币元/月 |
| 人民币外汇交易和外币对交易做市商 | 40，000人民币元/月 |

做市商终端费包括：

（1）交易中心向做市商提供为系统接入目的而使用的 FI/CPI API、SCS软件的连接使用费；

（2）交易中心向做市商提供为实时接收交易明细和数据核对目的而使用的CSTP API的连接使用费；

（3）交易中心向做市商提供的测试环境的日常软硬件维护费和提供测试技术支持的服务费。

（二）交易（和清算）费

不同的交易市场、交易方式、期限品种、成员身份和交易角色，适用不同的费率1。具体为：

|  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 交易市场 | 交易方式 | 期限品种 | | 普通会员 | | | 做市商 | |
| 人民币外汇市场 | 竞价 | 即期 | | 3.0/10000 | | | taker2 | maker2 |
| 1.0/10000 | 0.8/10000 |
| 询价 | 即期 | | taker2 | | maker2 | taker | maker |
| 0.10/10000 | | 0.10/10000 | 0.10/10000 | 0.10/10000 |
| 远期 | | 0.10/10000 | | | | |
| 掉 期 | 一般 |
| 一周以内3 | 0.01/10000 | | | | |
| 外币对 市场 | 竞价 | 即期 | | 0.20/10000 | | | taker | maker |
| 0.15/10000 | 0.10/10000 |
| 询价 | 即期 | | taker | maker | | taker | maker |
| 0.075/10000 | 0.050/10000 | | 0.050/10000 | 0.025/10000 |
| 远期 | | 0.050/10000 | | | | |
| 掉 期 | 一般 |
| 一周以内3 | 0.005/10000 | | | | |

说明：

1、 交易（和清算）费按成交量全额的一定比例收取，即：

交易（和清算）费＝成交量*适用费率

2、 竞价交易中，如A做市商点击其他做市商的报价，达成交易，则在该笔交易中，A做市商的角色为taker，报价做市商的角色为maker。询价交易中，普通会员也可以应答其他会员的询价，进行报价，如M会员向A做市商和N会员同时询价，结果和N会员达成交易，该笔交易中，M会员的角色为taker，N会员的角色为maker。

3、 一周以内的掉期交易在交易系统中会被自动确认和标记，是指远端交易在一周之内（含一周）的掉期交易，即远端交易的交割日没有超过标准一周掉期交割日的掉期交易。

（三）增值服务费

增值服务费仅向使用该项服务的会员收取，具体为：

1、CSTP接口支持费

CSTP为Customer Straight-Through Processing的缩写，通过该接口，会员可以直接下载本方历史交易数据。费率如下：

|  |  |
| --- | --- |
| CSTP API 连接使用费 | 1，000人民币元/月 |

2、外汇市场数据接口信息服务

具体收费方案请参见《外汇市场数据接口信息服务收费方案》。

**三、**优惠政策

（一）为活跃市场，促进交易，交易中心将区别情况对上述费用实行优惠。

（二）交易（和清算）费根据交易量实行累进折扣优惠。目前折扣率为：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 当期（季度）交易量（亿美元） | | | | 费率折扣 （%） |
| 人民币外汇即期竞价 | 人民币外汇即期询价－做市商 | 外币对即期竞价－会员 | 外币对即期竞价－做市商 |
| 0-1 | 0-50 | 0-1 | 0-20 | 0 |
| 1-2 | 50-100 | 1-5 | 20-40 | 10 |
| 2-3 | 100-200 | 5-10 | 40-80 | 20 |
| 3-4 | 200-300 | 10-50 | 80-120 | 30 |
| 4以上 | 300以上 | 50以上 | 120以上 | 40 |

注：交易中心将根据市场情况调整优惠标准。

（三）做市商终端费包含CSTP API连接使用费，做市商无需另行支付该增值服务费。

（四）新开设的交易品种在市场推广期可能采取除累进折扣优惠外的其他优惠措施。

**四、**缴费服务

1、交易终端费按月计算，每年年初一次性收取。会员新增交易终端以及新会员申请的终端，自该终端开通次月开始计算交易终端费，一次付清全年费用。做市商终端费自该做市商与交易中心签署的做市主协议生效的次月开始计算，一次付清全年费用。

2、交易（和清算）费按交易量逐笔计算，增值服务费按月计算，按季收取。

3、在每个季度结束的下一个月的月初，交易中心财务部向会员提供上一季度交易（和清算）费和增值服务费的费用清单，会员于当月缴清相关费用。

4、相关费用以人民币计收，具体如下：

（1）人民币外汇交易，交易系统根据成交价格自动以人民币为单位计算交易金额，并以此为基准计算人民币缴费金额；

（2）外币对交易，以每一季度最后一个交易日的人民币对外币中间价计算缴付等值人民币。

**五、**其他

1、本方案解释权归交易中心。

2、本方案自发布之日起生效，中汇交发[2005]361号公布的原收费方案同时废止。

3、会员单位与缴费相关的部门或联系人的信息发生变化，应事先书面通知交易中心财务部。
