# 中国农药发展与应用协会关于开展“放心农药经营单位”创建活动的通知

## 中国农药发展与应用协会关于开展“放心农药经营单位”创建活动的通知（中农药协[2009]11号）

各有关单位：

农业部及有关部委一直高度重视农药市场的监督管理工作，今年又相继在全国开展农产品质量安全整治暨农产品质量安全执法年活动和农药市场监管年活动。为配合行政管理部门做好农药市场的监管工作，引导农药经营单位依法经营，推动行业诚信建设，中国农药发展与应用协会从今年起在本协会会员单位及全国农药行业开展“放心农药经营单位”的创建活动。

**一、**开展“放心农药经营单位”创建活动的目的意义

农药经营是连接农药生产和使用的中心环节。对农药经营单位实行规范管理，有利于遏制假冒伪劣农药生产销售和保护农民的切身利益。目前全国农药经营单位成千上万，经营规模、经营条件、人员素质、经营的产品质量及经营的管理水平参差不齐。无证经营、超范围经营、转让证照、销售假冒伪劣农药及坑农害农事件经常发生。解决这些问题，需要在政府管理部门的主导下，集社会各方面的力量，采取多种形式齐抓共管。本协会开展的“放心农药经营单位”创建活动，就是其中的一种形式。其目的是通过这种广泛、持久、长效的活动机制，不断提高农药经营单位遵纪守法、依法诚信经营的自觉性及管理水平和经营水平，使农药经营单位一批又一批地步入放心农药经营单位这个行列，成为政府和农民信得过的农药经销单位。

**二、**“放心农药经营单位”的基本条件

（一）经营证照齐全，具备独立法人资格，注册资金在50万元以上，从事农药经营年限在三年以上；

（二）有固定的经营场所、设备、仓储等必要设施，符合农药产品存放、安全、配送等要求，店容、店貌整齐、整洁；

（三）经营人员具备相应的专业知识，有经县级以上农药管理部门培训取得的合格证或上岗证，熟悉农药知识，对农药的使用能够进行正确的技术指导；

（四）有一定的经营规模，年销售额在500万元以上；

（五）规章制度健全，并严格按制度办事。有完整的营销台帐制度，并进行电脑管理；

（六）诚信守法经营，在本店经营的农药包括经营的其它农资产品，最近三年无违法、违规的不良记录，在当地有很好的信誉度和影响力。

**三、**“放心农药经营单位”的申报及评选办法

（一）农药经营单位经过自查认为符合条件的，可自行申报；其主管单位或所在地农药监督管理部门也可推荐。申报时需填写《放心农药经营单位》申报表，并提供营业执照副本、法定代表人身份证、有关资质证书、规章制度等有关资料复印件及申请报告；

（二）上述申报材料在征得当地县（市）农药监督管理部门同意后，报所在省（市）农药监督管理部门或本协会省片召集人审查；

（三）本协会对申报材料经过初步审查认为符合“放心农药经营单位”基本条件的单位，将进行实地考察，在考察的基础上由协会组织评选委员会进行评选；

（四）对被评为“放心农药经营单位”的，在相关媒体和经营单位所在地进行公示；

（五）对经公示无异议的，由中国农药发展与应用协会在每年度举办的《中国农药高层论坛》上颁发“放心农药经营单位”证书和牌匾；

（六）对被评为“放心农药经营单位”的名单和突出事迹将在媒体上公布，并通报当地相关管理部门。

**四、**“放心农药经营单位”评选时间及监管办法

（一）“放心农药经营单位” 的创建活动，重在创建，贵在坚持。创建活动贯穿在常年工作当中。符合“放心农药经营单位”条件的，随时可以申报。协会每年集中考察、评审一次，时间一般为每年的下半年；

（二）对被评为“放心农药经营单位”的，要加强自律，珍惜荣誉，巩固和发展成果。如发生违法、违纪等问题，后果自负；

（三）协会对被评为“放心农药经营单位”的企业将加强监督和考核，每年进行年检，每三年进行一次复评，对不符合条件的，将收回证书和牌匾，并在相关媒体上公布；

（四）此项工作自本文发布之日起开始实施。希望广大农药经营单位积极参加，为规范、净化农药市场共同努力。在此项活动中如有问题和建议，请与本协会秘书处联系。
