# 深圳证券交易所、深圳证券信息有限公司关于发布深证新基建50指数的公告

## 关于发布深证新基建50指数的公告

为丰富深市特色系列指数，提供更多创新投资标的，深圳证券交易所和深圳证券信息有限公司定于2022年4月11日发布深证新基建50指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 指数基日 | 基日点位 |
| 399274 | 深证新基建50指数 | 深新基建 | 2012年12月31日 | 1000 |

深证新基建50指数从深市A股中，选取公司业务涉及5G、特高压、新能源汽车、工业互联网、人工智能等领域基础设施建设，总市值最大的50只股票作为样本股。指数于每年6月、12月进行样本股定期调整。指数采用自由流通市值加权，通过深交所行情系统计算并发布实时行情。

相关指数编制方案、样本股名单可访问国证指数网查询，网址为http://www.cnindex.com.cn。
