# 中国期货业协会关于吸收恒力恒新工贸（上海）有限公司等2家机构为协会会员的公告

## 关于吸收恒力恒新工贸（上海）有限公司等2家机构为协会会员的公告

根据《中国期货业协会章程》，经协会会长办公会2022年第4期会议审议，同意吸收恒力恒新工贸（上海）有限公司等2家机构成为协会会员，名单如下：

|  |  |  |
| --- | --- | --- |
| **序号** | **公司名称** | **会员类型** |
| 1 | 恒力恒新工贸（上海）有限公司 | 普通会员 |
| 2 | 上海云期鸿升实业有限公司 | 普通会员 |

特此公告。

中国期货业协会

2022年3月9日
