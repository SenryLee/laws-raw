# 中国期货业协会关于举办镍产业链分析及价格风险管理直播培训的通知

## 关于举办镍产业链分析及价格风险管理直播培训的通知

各会员单位：

当前有色金属镍价格波动剧烈，成为市场热点，为回应市场关注，增进从业人员与投资者对镍品种的了解，协会拟举办镍产业链分析及价格风险管理直播培训，现将有关事项通知如下：

一、培训对象

本次直播培训面向期货公司有色金属产业分析师、研究员及相关人员。镍生产、加工、消费企业，机构投资者及一般投资者亦可参加培训。

二、培训时间

2022年3月15日15:15-17:00

三、培训内容

|  |  |  |
| --- | --- | --- |
| **时间** | **主题** | **授课专家** |
| 15:15-15:40 | 镍：相信市场，静待回归 | 国投安信期货研究院有色金属组组长兼首席研究员  肖静 |
| 15:40-16:20 | 镍产业发展现状及后市展望 | 北京安泰科信息股份有限公司 镍钴锂部经理  陈瑞瑞 |
| 16:20-17:00 | 中国不锈钢产业发展格局及下游需求走势 | 中国特钢企业协会不锈钢分会秘书长  刘艳平 |

四、参会方式

本次培训采取视频直播的方式举办，主会场设在协会会议室。学员参加直播方式如下：

方式一：通过PC端浏览器方式，登录协会网上后续培训系统收看培训直播。网上后续培训系统地址：http://mooc.cfachina.org。在直播栏目下，选择本次直播培训，按时参加收看培训内容。

五、学时记录

此次网络直播培训列入中国期货业协会后续职业培训系列，全程参加直播培训且完成课后问卷任务的计为有效培训学时。

六、注意事项

各会员单位在疫情期间收看协会直播培训时要按照各地防疫要求，认真做好防护工作。
