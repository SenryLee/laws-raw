# 中国期货业协会关于发布金融衍生品分析师（FDA）Ⅰ级法律法规补充课程和Ⅱ级课程的通知

## 关于发布金融衍生品分析师（FDA）Ⅰ级法律法规补充课程和Ⅱ级课程的通知

各会员单位：

为提升行业人才专业水平，加快推进金融知识纳入国民教育，协会于去年启动并上线了金融衍生品分析师（FDA）FDAⅠ级课程，今年协会对FDAⅠ级法律法规课程进行了补充，并制作了金融衍生品分析师（FDA）Ⅱ级课程。上述课程已在协会网络培训平台以点播课程形式发布，具体通知如下：

**一、**FDAⅠ级补充课程情况

FDAⅠ级法律法规补充课程以现有Ⅰ级法律法规与职业道德课程为基础，整合网络培训平台课程资源，包含基础法律法规知识普及、法律法规解读、案例分析等丰富内容，共计50门课60.3学时，具体如下：

|  |  |  |  |
| --- | --- | --- | --- |
| **序号** | **章节名** | **讲** | **学时** |
| **1** | 法律法规概述 | 8 | 17 |
| **2** | 个人守法 | 12 | 9.1 |
| **3** | 公司自治 | 3 | 1.5 |
| **4** | 自律管理 | 3 | 3 |
| **5** | 行政监管 | 15 | 13.2 |
| **6** | 司法裁判 | 9 | 16.5 |
| **合计** |  | **50** | **60.3** |

**二、** FDAⅡ级课程情况

FDAⅡ级课程授课讲师均为高校教授，专业理论知识深厚。课程整体框架内容清晰完整，既有基础定价逻辑分析，也包括具体资产类别解读。其中宏观经济学、衍生品定价、统计与计量方法3章课程内容包含专业人员必须掌握的基础分析框架和方法，商品类、利率类、外汇类、权益类以及信用类这5章按大类资产划分的衍生品章节则突出对各类期货及衍生品的介绍分析和实际应用举例。课程多为模块化短视频，每讲讲透一个知识点，共计8章58.8学时，具体如下：

|  |  |  |  |
| --- | --- | --- | --- |
| **序号** | **章节名** | **讲** | **学时** |
| 1 | 宏观经济学 | 18 | 9.3 |
| 2 | 衍生品定价 | 16 | 8.6 |
| 3 | 商品类衍生品 | 21 | 10.8 |
| 4 | 利率类衍生品 | 22 | 4.1 |
| 5 | 外汇及其衍生品 | 19 | 7.8 |
| 6 | 权益类衍生品 | 17 | 7.7 |
| 7 | 信用类衍生品 | 13 | 5.5 |
| 8 | 统计与计量方法 | 16 | 5 |
| **合计** |  | **142** | **58.8** |

**三、**观看方式

登录协会网上后续培训平台，查看“FDA”栏目。网络培训平台地址：http://mooc.cfachina.org。
