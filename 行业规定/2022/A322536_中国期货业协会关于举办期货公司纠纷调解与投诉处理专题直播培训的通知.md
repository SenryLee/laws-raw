# 中国期货业协会关于举办期货公司纠纷调解与投诉处理专题直播培训的通知

## 关于举办期货公司纠纷调解与投诉处理专题直播培训的通知

为推进期货纠纷多元化解决机制建设，服务投保工作的全面开展，提高调解员纠纷调解处理能力，促进期货行业纠纷调解专业化、规范化，协会拟于2022年11月8日下午举办期货公司纠纷调解与投诉处理专题直播培训，现将培训相关事项通知如下。

**一、**培训对象

本次直播培训面向协会聘任的调解员、会员单位负责投诉处理、合规管理及客服行政等工作的相关人员。

**二、**直播培训时间、内容及师资

|  |  |  |
| --- | --- | --- |
| **时间** | **课程主题** | **主讲人** |
| 14:00-14:10 | 领导讲话 | 中国期货业协会  非会员理事、调解委员会主任  孙明福 |
| 14:10-15:30 | 期货强平纠纷主要类型及法律责任分析 | 北京金融法院  江锦莲 |
| 15:30-17:00 | 期货居间人纠纷法律责任分析 | 北京大成律师事务所  左青云 |

**三、**参会方式

本次培训采取视频直播的方式举办，学员参加直播方式如下：

方式一：通过PC端浏览器方式，登录协会知识服务平台收看培训直播。知识服务平台地址：http://mooc.cfachina.org。在直播栏目下，选择本次直播培训，按时参加收看培训内容。

方式二：通过移动端访问，微信扫描二维码，登录并进入直播。

![image.png](https://zk-img.faxin.cn//Uedit_Upload/2022-11-07-16-54-59_5051571_image.png "image.png")

**四、**学时记录

此次网络直播培训列入中国期货业协会后续职业培训序列，全程参加直播培训且完成课后问卷任务的计为有效培训学时。

**五、**注意事项

1.各会员单位和个人在疫情期间收看协会直播培训时，要按照各地防疫要求，认真做好防护工作。

2.在期货公司以外机构任职的调解员首次登录网络直播培训系统时需要进行注册。

**六、**联系方式

培训部：010-88087233，88086867
