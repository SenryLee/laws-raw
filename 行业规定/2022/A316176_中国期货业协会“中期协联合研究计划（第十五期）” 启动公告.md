# 中国期货业协会“中期协联合研究计划（第十五期）” 启动公告

## “中期协联合研究计划（第十五期）” 启动公告

为联合行业和社会力量，共同推进期货及衍生品理论和实证研究工作，我协会即日启动“中期协联合研究计划（第十五期）”申报工作。现将有关事项说明如下：

一、研究方向和选题范围

本期联合研究计划紧紧围绕服务实体经济、防控金融风险、深化金融改革三大任务，以努力打造一个规范、透明、开放、有活力、有韧性的资本市场，提升重要大宗商品的价格影响力为研究目标，采用“命题研究”的形式开展。课题申请人须根据自身研究优势在以下选题范围中选择方向自主申报课题并开展研究。

|  |  |
| --- | --- |
| **研究方向** | **选题范围** |
| **（一）期货市场功能发挥基础理论** | 后疫情时代期货市场在大宗商品全球产业链重构中的功能作用；期货市场定价机制完善研究；投资者结构与期货市场有效性关系研究；现货市场成熟度与期货市场发展程度研究；现货价格限定条件下期货市场功能发挥研究。 |
| **（二）期货市场服务实体经济实证研究** | 期货市场服务“保供稳价”总结及实证研究；期货市场服务农产品、能源、矿产等初级产品供给保障（包括但不限于原油、铁矿石、铜、大豆等）；不同类型实体企业参与期货市场问题、障碍及解决建议研究；企业套期保值会计准则应用程度、推广障碍及建议研究；成本上升在产业链中的传导机制及期货市场功能发挥研究（分品种、产业链）；期现价格相关性研究；期货品种集群效应（黑色产业链、油脂油粕、股指期货等）研究。 |
| **（三）期货经营机构发展及监管实践** | **公司发展：**发展中国特色期货经营机构体系的功能定位、业务版图规划及实现路径研究；期货公司清算风险救助研究；大宗商品场外衍生品交易商群体定位及功能作用研究；国内商品交易顾问（CTA）主体定位及发展建议研究。  **监管实践：**风险管理子公司会计准则研究；《期货公司期货投资咨询业务试行办法》具体修订及完善建议研究；期货市场操纵行为认定及相关法律问题研究；场外持仓限额、持仓合并制度研究；期货公司风险准备金管理研究；风险管理公司开展大宗商品融资类业务研究；含权贸易属性定位及规范发展研究（防范利用含权贸易变相开展场外期权；含权贸易客户筛选、合同框架设计、货物交收、票据开立等各业务流程规范、风险点梳理、风控指标设计及监管规则建议等）；期货经营机构与其从业人员违法违规行为的法律责任边界问题研究。 |
| **（四）金融科技应用** | 区块链、数据中心建设、智能化研报等在期货公司业务中应用研究。 |

二、实施流程和管理模式

本期研究计划实行“申报-评审-资助”的课题管理模式，面向全社会，鼓励业内机构、高校、科研院所、实体企业等机构或单位就我国期货及衍生品市场创新、行业发展的重要理论与实践问题，围绕本公告发布的研究方向和选题范围进行课题申报、研究开展、成果提交。协会将遵循公开、公平、公正的基本原则，按照评审程序和评审标准，对最终完成质量优异、符合条件的课题成果给予研究经费支持。请课题申报单位仔细阅读《中期协联合研究计划课题管理办法》（2020年修订）及相关附件，熟知课题申报流程和要求，按时进行课题申报。

三、申报条件

1.课题申请人应当是协会会员，或其它金融机构、高校、科研院所、实体企业等机构或单位，可单独申报或联合申报。

2.申请人课题组主要研究人员应当具有从事相关研究或实务工作的经历和较强的科研能力，且有充足的时间从事课题研究工作。课题申请人须指定课题负责人。

3.课题申请单位承担的往期联合研究计划课题须已全部结项。已获得其他研究项目资助的成果不得申请本计划。

4.申请参与本计划须首先完成课题申报，未申报课题不能进入后续评审流程。

5.本期课题采用“命题研究”的形式开展，原则上不接受超出本次公告选题范围外的课题申报。

四、申报方式

1.材料准备：

（1）单位统一社会信用代码

（2）《中期协联合研究计划申报书》word版和PDF版（PDF版申报书请务必加盖单位公章，否则申报无效）

2.申报方式。课题申请单位可于2022年4月18日前登录中国期货业协会研究管理系统（网址：http://yanjiu.cfachina.org/）进行在线申报，其他申报途径无效。

五、研究时间与成果提交

1.研究时间。课题申报成功后，请开始自主研究并按照《研究成果编写要求》撰写成果报告。

2.成果提交。请认真填写《中期协联合研究计划参评申请书》，并于2022年8月15日前，将《参评申请书》和课题最终报告的Word版和PDF版按照系统要求上传。参评申请书PDF版请务必加盖单位公章，否则申请无效。

3.提交要求。为保证专家评审客观、公正，课题评审将采取专家盲评方式，请在课题最终报告（包括word 版和PDF版）中隐去课题撰写单位所有信息，课题组信息请在《参评申请书》集中体现（课题最终报告的Word版和PDF不需要盖公章）。

六、课题评审及经费资助

1.课题评审。协会依据《办法》制定评审方案，聘请行业专家、学者组成专家评审委员会，严格按照《办法》规定的评审流程和标准，对报送课题进行评审。根据《办法》规定的课题重要程度和成果价值，评定参评课题的类别和等级。对评审通过的课题颁发课题结题证书，对获得优秀、良好等级的课题进行经费资助。

2.经费标准。本期课题资助标准为：一类课题10万元，二类课题5万元，三类课题3万元。获得优秀等级的课题按经费标准的120%进行资助；获得良好等级的课题按经费标准的100%进行资助。
