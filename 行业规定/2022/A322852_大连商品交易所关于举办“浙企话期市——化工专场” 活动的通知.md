# 大连商品交易所关于举办“浙企话期市——化工专场” 活动的通知

## 关于举办“浙企话期市——化工专场” 活动的通知

大商所发〔2022〕578号

各相关单位：

为持续做好产业培育工作，引导化工产业企业加深对风险管理业务的理解，大连商品交易所将于2022年11月22日至23日在线上举办“浙企话期市——化工专场”活动，就企业化工衍生品的实践应用和风险管理等进行介绍。具体安排通知如下：

**一、**活动时间

2022年11月22日（周二），15:00-16:20

2022年11月23日（周三），15:00-16:20

**二、**活动日程

|  |  |
| --- | --- |
| **2022年11月22日（周二）** | |
| 15:00-15:40 | 主旨演讲1：塑化贸易风险管理及衍生品应用  演讲嘉宾：宋仕威  浙江特产石化有限公司 研投总监 |
| 15:40-16:20 | 主旨演讲2：PVC期货在企业风险管理中的应用  演讲嘉宾：金黎  浙江物产氯碱化工有限公司 总经理 |
| **2022年11月23日（周三）** | |
| 15:00-15:40 | 主旨演讲1：期货市场套期保值功能在实体企业的运用场景分析  演讲嘉宾：季丰  浙江卫星石化股份有限公司 乙二醇销售部负责人 |
| 15:40-16:20 | 主旨演讲2：乙二醇贸易中的风险管理业务分享  演讲嘉宾：张涛  嘉悦物产集团有限公司 聚酯事业部 总经理 |
