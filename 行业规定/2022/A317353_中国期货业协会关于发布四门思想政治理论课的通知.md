# 中国期货业协会关于发布四门思想政治理论课的通知

## 关于发布四门思想政治理论课的通知

各会员单位：

为了帮助从业人员进一步学懂弄通习近平总书记关于金融工作重要论述、学习贯彻新发展理念，协会近期引进了国家行政学院音像出版社的四门网络课程并已在协会网络培训平台以点播课程形式发布，具体通知如下：

**一、**授课讲师及课程内容

本次上线课程共4门3.5学时，课程详细信息具体如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **序号** | **课程名称** | **学时** | **主讲人** | **课程简介** |
| 1 | 完善全球治理体系——百年未有之大变局的当务之急（上） | 1 | 张燕玲  中国银行原副行长 | 21世纪的多边主义要守正出新、面向未来，既要坚持多边主义的核心价值和基本原则，也要立足世界格局变化，着眼应对全球性挑战需要，在广泛协商、凝聚共识基础上改革和完善全球治理体系。本课程围绕布雷顿森林体系与美元霸权演变、数字经济时代的货币战争两个方面展开阐述。 |
| 2 | 完善全球治理体系——百年未有之大变局的当务之急（下） | 0.5 |
| 3 | 健全完善我国现代金融体系（上） | 1 | 陈道富  国务院发展研究中心  金融研究所副所长 | 《中华人民共和国国民经济和社会发展第十四个五年规划和2035年远景目标纲要》中指出，健全具有高度适应性、竞争力、普惠性的现代金融体系，构建金融有效支持实体经济的体制机制。本课程重点阐释了什么是现代金融体系，说明了建设现代化强国对金融体系的要求。 |
| 4 | 健全完善我国现代金融体系（下） | 1 |
| **合计** |  | **3.5** |  |  |

**二、**培训对象

系列培训课程面向期货从业人员和期货居间人。

**三、**观看方式

登录协会网上后续培训平台，查看“思想政治理论课”专题栏目。网络培训平台地址：http://mooc.cfachina.org。

四、课程收费标准

课程执行免费政策。
