# 全国中小企业股份转让系统有限责任公司办公室、北京证券交易所办公室关于举办全国股转公司、北交所董事会秘书规范执业视频培训的通知

## 关于举办全国股转公司、北交所董事会秘书规范执业视频培训的通知

为提升挂牌公司、上市公司董事会秘书执业水平，提高挂牌公司、上市公司规范运作水平，助推公司合规、快速发展，全国股转公司、北交所拟于近期举办董事会秘书规范执业视频培训。培训具体安排如下：

一、参会人员

挂牌公司、上市公司董事会秘书、信息披露负责人或其他相关人员。

二、培训安排

|  |  |
| --- | --- |
| 时间 | 课程 |
| 5月23日  -  6月10日 | 公众公司如何做好信息披露工作 |
| 公众公司如何提升公司财务信息披露质量（上） |
| 公众公司如何提升公司财务信息披露质量（下） |
| 从上市公司角度浅谈如何做好投资者关系管理 |
| 公众公司面临的媒体生态浅析及应对 |
| 公众公司舆情应对内部制度建设 |

三、培训形式

本次培训为线上录播培训，参会人员可在全国股转公司官网“服务专区-培训园地”栏目（http://www.neeq.com.cn/investor_guide/train_area.html）或北交所官网“服务-培训园地”栏目（http://www.bse.cn/investor_guide/train_area.html）

在线学习相关课程，所有课程可24小时观看。

四、问题收集

如有与培训内容相关的问题，可扫描下方二维码填写问卷，培训结束后，工作人员将及时答复相关问题：
