# 北京证券交易所办公室关于举办北交所上市公司投资者关系管理专项培训的通知

## 关于举办北交所上市公司投资者关系管理专项培训的通知

各市场主体：

为强化北交所上市公司投资者关系管理，帮助上市公司准确理解和掌握《上市公司投资者关系管理工作指引》的主要内容及便利投资者行权维权的举措，进而推动上市公司高质量发展，北交所拟于5月19日在线举办上市公司投资者关系管理专项培训。具体安排如下：

一、参会人员

北交所上市公司、投资者、保荐机构、挂牌公司及其他市场主体。

二、培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| 时间 | | 课程内容 | 主讲单位 |
| 5月19日  （周四） | 14:00-15:00 | 《上市公司投资者关系管理工作指引》解读 | 中国证监会投资者保护局 |
| 15:00-16:00 | 从持股行权工作看投资者关系管理 | 中证中小投资者服务中心 |
| 16:00-17:00 | 投资者与上市公司纠纷调解实务 | 中证中小投资者服务中心 |
| 注：最终培训内容以实际课程安排为准 | | | |

三、报名方式

本次培训采用“腾讯会议”在线讲解模式，参会人员可通过访问直播链接加入直播间参加培训。直播链接为：

https://meeting.tencent.com/l/4ZrHQF78eANw

四、温馨提示

1.请尽量通过电脑浏览器访问直播链接，注意选择网速较好地点以保障视频及语音的流畅性和清晰度。培训期间如出现卡顿、没有声音等情况，请尝试刷新页面或重新进入直播间；

2.本次培训不收取会议费；

3.遇有问题可咨询：400-626-3333。
