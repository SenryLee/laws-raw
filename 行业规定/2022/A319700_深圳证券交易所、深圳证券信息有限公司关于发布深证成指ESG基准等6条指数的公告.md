# 深圳证券交易所、深圳证券信息有限公司关于发布深证成指ESG基准等6条指数的公告

## 关于发布深证成指ESG基准等6条指数的公告

为完善ESG指数体系，扩展指数跟踪标的范围，深圳证券交易所和深圳证券信息有限公司定于2022年7月25日发布深证成指ESG基准指数、深证100ESG基准指数、创业板指ESG基准指数、深证成指ESG领先指数、深证100ESG领先指数、创业板指ESG领先指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 指数基日 | 基日点位 |
| 970026 | 深证成指ESG基准指数 | 深指ESG | 2018年6月29日 | 9379.47 |
| 970027 | 深证100ESG基准指数 | 100ESG | 2018年6月29日 | 3920.16 |
| 970028 | 创业板指ESG基准指数 | 创指ESG | 2018年6月29日 | 1606.71 |
| 970029 | 深证成指ESG领先指数 | 深指ESG领先 | 2018年6月29日 | 9379.47 |
| 970030 | 深证100ESG领先指数 | 100ESG领先 | 2018年6月29日 | 3920.16 |
| 970031 | 创业板指ESG领先指数 | 创指ESG领先 | 2018年6月29日 | 1606.71 |

深指ESG、100ESG和创指ESG分别以深证成指、深证100和创业板指样本股为样本空间，对选样空间按照所属国证一级行业及ESG评分从高到低排序，剔除行业内ESG评分排名后20%的股票，选取剩余股票构成指数样本股。

深指ESG领先、100ESG领先和创指ESG领先分别以深证成指、深证100和创业板指样本股为样本空间，对选样空间按照ESG评分从高到低排序，选取ESG评分靠前的一定数量股票作为样本股。深指ESG领先的样本数量为200只，100ESG领先、创指ESG领先的样本数量均为50只。

相关指数编制方案、样本股名单可访问国证指数网查询，网址为http://www.cnindex.com.cn。
