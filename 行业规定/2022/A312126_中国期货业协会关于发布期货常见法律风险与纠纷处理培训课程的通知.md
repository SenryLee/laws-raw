# 中国期货业协会关于发布期货常见法律风险与纠纷处理培训课程的通知

## 关于发布期货常见法律风险与纠纷处理培训课程的通知

各会员单位：

为推进期货纠纷多元化解决机制建设，服务投保工作的全面开展，提高调解员纠纷调解处理能力，促进期货行业纠纷调解专业化、规范化，保障学员学习质量，协会将12月7日举办的期货公司纠纷调解与投诉处理专题直播培训中的《期货常见法律风险与纠纷处理》部分制作为点播课程，于2022年1月6日在网络培训平台发布，欢迎市场各类参与机构及相关人员观看学习，具体通知如下：

一、课程内容

课程共计2学时，课程列表如下：

|  |  |  |  |
| --- | --- | --- | --- |
| **序号** | **课程名称** | **主讲人** | **学时** |
| 1 | 期货常见法律风险与纠纷处理 | 一德期货有限公司 张凡 | 2 |

二、培训对象

本次培训面向协会聘任的调解员、会员单位负责合规管理及投诉处理等工作的相关人员

三、观看方式

通过PC端浏览器方式，登录协会网上后续培训平台，搜索相应课程名称即可收看学习。网络培训平台地址：http://mooc.cfachina.org。

四、收费标准

课程收费参照2021年8月18日协会发布的《关于调整网络点播培训收费标准的公告》执行。

五、特别提醒

为进一步做好疫情防控期间向从业人员推送部分网络培训课程工作，同时引导培养从业人员及时主动的学习行为，保障学习质量，本课程实行“新发课程一个月内免费”的激励机制，从业人员在系列课程发布上线一个月之内完成选课学习，如选本课程时超出规定学时，仍享有免费学习机会。

特此通知。

中国期货业协会
