# 中国期货业协会关于开展期货和衍生品法宣传月暨期货和衍生品法系列课程公益普法学习活动的通知

## 关于开展期货和衍生品法宣传月暨期货和衍生品法系列课程公益普法学习活动的通知

各会员单位及其他各类市场参与者:

12月4日是国家宪法日和全国法制宣传日，为了进一步加强期货和衍生品法教育宣传工作，协会将于2022年12月开展期货和衍生品法宣传月暨期货和衍生品法系列课程公益普法学习活动。现将相关内容通知如下：

**一、**公益普法学习内容

期货和衍生品法系列公开课，共8讲、18.5学时。

|  |  |  |
| --- | --- | --- |
| **序号** | **课程名称** | **学时数** |
| 1 | 《期货和衍生品法》要点解读 | 1 |
| 2 | 《期货和衍生品法》衍生品交易制度解读、期货风险管理公司衍生品业务实践及未来展望 | 2.5 |
| 3 | 《期货和衍生品法》期货和衍生品结算业务解读 | 2.5 |
| 4 | 《期货和衍生品法》期货经营机构监管制度解读及期货交易者章节解读 | 2.5 |
| 5 | 《期货和衍生品法》期货交易和衍生品交易的一般规定及期货交易章节解读 | 2 |
| 6 | 《期货和衍生品法》跨境交易服务经验分享及跨境交易和监管协作章节解读 | 2.5 |
| 7 | 《期货和衍生品法》民事责任体系 | 2.5 |
| 8 | 《期货和衍生品法》实施后法律风险及防范及合规风控管理 | ;font-size: 19px">3 |

**二、**公益普法学习形式

系列课程在协会知识服务平台中以公开课方式推出，受众无需注册及登录平台账户、微信扫码后即可直接观看学习。
