# 深圳证券交易所、深圳证券信息有限公司关于发布深证中关村民企60指数的公告

## 关于发布深证中关村民企60指数的公告

为表征中关村国家自主创新示范区在深市上市的A股民营企业的运行情况，进一步丰富指数化投资标的，满足市场投资管理的需要，深圳证券交易所和深圳证券信息有限公司定于2017年1月10日发布深证中关村民企60指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **指数代码** | **指数名称** | **指数简称** | **基日** | **基日点位** |
| 399697 | 深证中关村民企60 | 中关村60 | 2008年12月31日 | 1000 |

深证中关村民企60指数以深市A股市场中注册地在中关村国家自主创新示范区内的民营上市企业为备选范围，采用日均总市值比重、日均自由流通市值比重与日均成交金额比重1:1:1进行加权排序，选取排名靠前的60只股票构成样本股。

指数采用自由流通市值进行加权计算，每年1月份与7月份进行样本股定期调整。

中关村60指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，收益指数通过国证指数网发布收盘行情数据。指数编制方案及最新样本股名单参见国证指数网（http:// www.cnindex.com.cn）。
