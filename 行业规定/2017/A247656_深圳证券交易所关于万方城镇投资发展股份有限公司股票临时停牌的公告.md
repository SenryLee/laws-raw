# 深圳证券交易所关于万方城镇投资发展股份有限公司股票临时停牌的公告

## 关于万方城镇投资发展股份有限公司股票临时停牌的公告

因万方城镇投资发展股份有限公司发生对股价可能产生较大影响、没有公开披露的重大事项，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：万方发展，证券代码：000638）自2017年3月3日开市起停牌，待公司刊登相关公告后复牌。

深圳证券交易所
