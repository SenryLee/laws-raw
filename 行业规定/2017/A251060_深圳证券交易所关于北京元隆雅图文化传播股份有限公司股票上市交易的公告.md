# 深圳证券交易所关于北京元隆雅图文化传播股份有限公司股票上市交易的公告

## 关于北京元隆雅图文化传播股份有限公司股票上市交易的公告

北京元隆雅图文化传播股份有限公司人民币普通股股票将于2017年6月6日在本所上市。证券简称为“元隆雅图”,证券代码为“002878”。公司人民币普通股股份总数为75,360,000股，其中首次公开发行的18,840,000股股票自上市之日起开始上市交易。
