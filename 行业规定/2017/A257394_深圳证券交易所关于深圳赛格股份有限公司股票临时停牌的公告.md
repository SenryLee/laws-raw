# 深圳证券交易所关于深圳赛格股份有限公司股票临时停牌的公告

## 关于深圳赛格股份有限公司股票临时停牌的公告

因控股股东深圳市赛格集团有限公司有针对深圳赛格股份有限公司的相关事宜正在商议，且该事项目前尚存在不确定性，根据《深圳证券交易所股票上市规则》的有关规定，经深圳赛格股份有限公司申请，该公司股票（证券简称：深赛 格，证券代码：000058；证券简称：深赛格B，证券代码：200058）自2017年11月13日开市起停牌，待公司刊登相关公告后复牌。
