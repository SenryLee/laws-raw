# 深圳证券交易所关于北京安达维尔科技股份有限公司股票在创业板上市交易的公告

## 关于北京安达维尔科技股份有限公司股票在创业板上市交易的公告

北京安达维尔科技股份有限公司人民币普通股股票将于2017年11月9日在本所创业板上市。证券简称为“安达维尔”,证券代码为“300719”。公司人民币普通股股份总数为168,000,000股，其中首次公开发行的42,000,000股股票自上市之日起开始上市交易。

2017年11月7日
