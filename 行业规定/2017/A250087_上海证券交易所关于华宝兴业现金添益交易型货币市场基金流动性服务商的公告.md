# 上海证券交易所关于华宝兴业现金添益交易型货币市场基金流动性服务商的公告

## 关于华宝兴业现金添益交易型货币市场基金流动性服务商的公告

上证公告（基金）〔2017〕033号

为促进华宝兴业现金添益交易型货币市场基金(以下简称"华宝添益")的市场流动性和平稳运行,根据《上海证券交易所上市基金流动性服务业务指引》的有关规定,经协商华宝兴业基金管理有限公司,我所同意东方证券股份有限公司为华宝添益（511990）流动性服务商。

特此公告。

上海证券交易所

2017年5月9日
