# 深圳证券交易所关于为惠州亿纬控股有限公司2017年非公开发行可交换公司债券提供转让服务有关事项的通知

## 关于为惠州亿纬控股有限公司2017年非公开发行可交换公司债券提供转让服务有关事项的通知

各会员单位：

惠州亿纬控股有限公司2017年非公开发行可交换公司债券定于2017年4月28日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

惠州亿纬控股有限公司2017年非公开发行可交换公司债券证券代码“117068”，证券简称“17亿纬E1”，发行总额8亿元，票面利率2%，债券期限1年，附换股价格修正条款和发行人赎回条款。

深圳证券交易所

二○一七年四月二十六日
