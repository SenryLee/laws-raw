# 深圳证券交易所关于华北高速公路股份有限公司股票临时停牌的公告

## 关于华北高速公路股份有限公司股票临时停牌的公告

因华北高速公路股份有限公司收到通知，根据证监会并购重组审核工作安排，近日将安排华北高速的并购重组上会，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：华北高速，证券代码：000916）自2017年10月12日开市起停牌，待公司收到并购重组委审核结果并公告后复牌。

深圳证券交易所

2017年10月12日
