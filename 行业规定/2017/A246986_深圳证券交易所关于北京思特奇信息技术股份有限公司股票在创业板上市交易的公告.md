# 深圳证券交易所关于北京思特奇信息技术股份有限公司股票在创业板上市交易的公告

## 关于北京思特奇信息技术股份有限公司股票在创业板上市交易的公告

北京思特奇信息技术股份有限公司人民币普通股股票将于2017年2月13日在本所创业板上市。证券简称为“思特奇”,证券代码为“300608”。公司人民币普通股股份总数为67,420,000股，其中首次公开发行的16,855,000股股票自上市之日起开始上市交易。
