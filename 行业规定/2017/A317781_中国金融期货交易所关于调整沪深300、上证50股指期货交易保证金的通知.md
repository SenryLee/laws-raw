# 中国金融期货交易所关于调整沪深300、上证50股指期货交易保证金的通知

各结算会员：

经研究决定，对沪深300、上证50股指期货交易保证金调整如下：

自2017年9月18日（星期一）结算时起，沪深300和上证50股指期货各合约交易保证金标准，由目前合约价值的20%调整为15%。

特此通知。

中国金融期货交易所

2017年9月15日
