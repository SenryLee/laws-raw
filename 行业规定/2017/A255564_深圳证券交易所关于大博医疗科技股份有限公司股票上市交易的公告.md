# 深圳证券交易所关于大博医疗科技股份有限公司股票上市交易的公告

## 关于大博医疗科技股份有限公司股票上市交易的公告

大博医疗科技股份有限公司人民币普通股股票将于2017年9月22日在本所上市。证券简称为“大博医疗”,证券代码为“002901”。公司人民币普通股股份总数为400,100,000股，其中首次公开发行的40,100,000股股票自上市之日起开始上市交易。
