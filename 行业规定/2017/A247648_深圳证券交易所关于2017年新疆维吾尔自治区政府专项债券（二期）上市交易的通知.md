# 深圳证券交易所关于2017年新疆维吾尔自治区政府专项债券（二期）上市交易的通知

## 关于2017年新疆维吾尔自治区政府专项债券（二期）上市交易的通知

各会员单位：

2017年新疆维吾尔自治区政府专项债券（二期）已发行结束，根据财政部通知，本期债券于2017年3月6日起在本所上市交易。

本期债券为7年期固定利率附息式国债（地方政府债），证券编码“107530”，证券简称“新疆1704”，票面利率3.54％，标准交易单位“10张”，2024年3月2日到期还本并支付最后一期利息。

特此通知

深圳证券交易所

二○一七年三月二日
