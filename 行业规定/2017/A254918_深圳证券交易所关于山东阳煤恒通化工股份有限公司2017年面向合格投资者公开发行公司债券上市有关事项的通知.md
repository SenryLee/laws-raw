# 深圳证券交易所关于山东阳煤恒通化工股份有限公司2017年面向合格投资者公开发行公司债券上市有关事项的通知

## 关于山东阳煤恒通化工股份有限公司2017年面向合格投资者公开发行公司债券上市有关事项的通知

各会员单位：

山东阳煤恒通化工股份有限公司2017年面向合格投资者公开发行公司债券定于2017年9月11日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

山东阳煤恒通化工股份有限公司2017年面向合格投资者公开发行公司债券证券代码“112559”，证券简称“17恒通债”，发行总额4.4亿元，票面利率6%，债券期限3年。

特此通知

深圳证券交易所

二○一七年九月七日
