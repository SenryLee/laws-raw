# 深圳证券交易所关于2017年吉林省政府一般债券（三期）上市交易的通知

## 关于2017年吉林省政府一般债券（三期）上市交易的通知

各会员单位：

2017年吉林省政府一般债券（三期）已发行结束，根据财政部通知，本期债券于2017年7月21日起在本所上市交易。

本期债券为7年期固定利率附息式国债（地方政府债），证券编码“107837”，证券简称“吉林1703”，票面利率4％，标准交易单位“10张”，2024年7月19日到期还本并支付最后一期利息。

特此通知
