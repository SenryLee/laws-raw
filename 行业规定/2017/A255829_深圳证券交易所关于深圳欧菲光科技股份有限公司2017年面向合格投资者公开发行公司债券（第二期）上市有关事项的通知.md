# 深圳证券交易所关于深圳欧菲光科技股份有限公司2017年面向合格投资者公开发行公司债券（第二期）上市有关事项的通知

## 关于深圳欧菲光科技股份有限公司2017年面向合格投资者公开发行公司债券（第二期）上市有关事项的通知

各会员单位：

深圳欧菲光科技股份有限公司2017年面向合格投资者公开发行公司债券（第二期）定于2017年10月9日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

深圳欧菲光科技股份有限公司2017年面向合格投资者公开发行公司债券（第二期）证券代码“112580”，证券简称“17欧菲02”，发行总额6亿元，票面利率5.57%，债券期限3年,附第2年末发行人调整票面利率选择权和投资者回售选择权。

特此通知
