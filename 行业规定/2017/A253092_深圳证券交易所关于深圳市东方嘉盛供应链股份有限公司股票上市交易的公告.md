# 深圳证券交易所关于深圳市东方嘉盛供应链股份有限公司股票上市交易的公告

## 关于深圳市东方嘉盛供应链股份有限公司股票上市交易的公告

深圳市东方嘉盛供应链股份有限公司人民币普通股股票将于2017年7月31日在本所上市。证券简称为“东方嘉盛”,证券代码为“002889”。公司人民币普通股股份总数为138,101,429股，其中首次公开发行的34,530,000股股票自上市之日起开始上市交易。
