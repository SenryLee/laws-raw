# 上海期货交易所关于上海国际能源交易中心发布《上海国际能源交易中心期货交易者适当性制度操作指南（暂行）》的通知

上期发〔2017〕98号

各相关单位：

为进一步明确投资者适当性制度业务操作要求，上海期货交易所子公司上海国际能源交易中心（以下简称能源中心）于2017年6月9日发布《上海国际能源交易中心期货交易者适当性制度操作指南（暂行）》。

开户机构落实能源中心适当性要求应按照该指南执行。

特此通知。

附件：上海国际能源交易中心期货交易者适当性制度操作指南（暂行）

上海期货交易所

2017年6月9日
