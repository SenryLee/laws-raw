# 深圳证券交易所关于昆明云内动力股份有限公司股票临时停牌的公告

## 关于昆明云内动力股份有限公司股票临时停牌的公告

因中国证监会上市公司并购重组审核委员会将于近期审核昆明云内动力股份有限公司的重大资产重组事项，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：云内动力，证券代码：000903）自2017年7月13日开市起停牌，待公司刊登审核结果公告后复牌。

深圳证券交易所

2017年7月13日
