# 深圳证券交易所关于为苏州协鑫新能源投资有限公司2017年非公开发行绿色公司债券（第二期）提供转让服务有关事项的通知

## 关于为苏州协鑫新能源投资有限公司2017年非公开发行绿色公司债券（第二期）提供转让服务有关事项的通知

各会员单位：

苏州协鑫新能源投资有限公司2017年非公开发行绿色公司债券（第二期）定于2017年12月29日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

苏州协鑫新能源投资有限公司2017年非公开发行绿色公司债券（第二期）证券代码“114265”，证券简称“17协鑫G2”，发行总额5.6亿元，票面利率7.5%，债券期限3年，附第2年末发行人调整票面利率选择权及投资者回售选择权。

深圳证券交易所

二○一七年十二月二十七日
