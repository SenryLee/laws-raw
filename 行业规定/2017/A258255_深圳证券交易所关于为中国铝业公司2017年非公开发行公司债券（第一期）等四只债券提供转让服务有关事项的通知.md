# 深圳证券交易所关于为中国铝业公司2017年非公开发行公司债券（第一期）等四只债券提供转让服务有关事项的通知

## 关于为中国铝业公司2017年非公开发行公司债券（第一期）等四只债券提供转让服务有关事项的通知

各会员单位：

中国铝业公司2017年非公开发行公司债券（第一期）、 广州合景房地产开发有限公司2017年非公开发行公司债券（第二期）（品种一）、广州合景房地产开发有限公司2017年非公开发行公司债券（第二期）（品种二）、 南京丰盛产业控股集团有限公司2017年非公开发行公司债券（第三期）定于2017年12月4日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、中国铝业公司2017年非公开发行公司债券（第一期）证券代码“114212”，证券简称“17中铝01”，发行总额10亿元，票面利率5.35%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

2、广州合景房地产开发有限公司2017年非公开发行公司债券（第二期）（品种一）证券代码“114244”，证券简称“17合景03”，发行总额8.4亿元，票面利率8%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

3、广州合景房地产开发有限公司2017年非公开发行公司债券（第二期）（品种二）证券代码“114245”，证券简称“17合景04”，发行总额21.6亿元，票面利率7.5%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

4、南京丰盛产业控股集团有限公司2017年非公开发行公司债券（第三期）证券代码“114253”，证券简称“17丰盛03”，发行总额2亿元，票面利率7.5%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年十一月三十日
