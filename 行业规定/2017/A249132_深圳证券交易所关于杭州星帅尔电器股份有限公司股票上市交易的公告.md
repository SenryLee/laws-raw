# 深圳证券交易所关于杭州星帅尔电器股份有限公司股票上市交易的公告

## 关于杭州星帅尔电器股份有限公司股票上市交易的公告

杭州星帅尔电器股份有限公司人民币普通股股票将于2017年4月12日在本所上市。证券简称为“星帅尔”,证券代码为“002860”。公司人民币普通股股份总数为75,978,680股，其中首次公开发行的15,200,000股股票自上市之日起开始上市交易。
