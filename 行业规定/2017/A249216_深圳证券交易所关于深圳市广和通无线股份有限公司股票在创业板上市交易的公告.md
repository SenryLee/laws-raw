# 深圳证券交易所关于深圳市广和通无线股份有限公司股票在创业板上市交易的公告

## 关于深圳市广和通无线股份有限公司股票在创业板上市交易的公告

深圳市广和通无线股份有限公司人民币普通股股票将于2017年4月13日在本所创业板上市。证券简称为“广和通”,证券代码为“300638”。公司人民币普通股股份总数为80,000,000股，其中首次公开发行的20,000,000股股票自上市之日起开始上市交易。
