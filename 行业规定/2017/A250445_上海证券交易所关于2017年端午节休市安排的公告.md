# 上海证券交易所关于2017年端午节休市安排的公告

## 关于2017年端午节休市安排的公告

上证公告〔2017〕12号

根据《关于上海证券交易所2017年全年休市安排的通知》（上证公告〔2016〕25号），上海证券交易所现将2017年端午节休市有关安排通知如下：

5月28日（星期日）至5月30日（星期二）休市，5月31日（星期三）起照常开市。另外，5月27日（星期六）为周末休市。

请市场参与人据此安排有关工作。

上海证券交易所

二○一七年五月十八日
