# 上海证券交易所关于N科林（603050）盘中临时停牌的公告

## 关于N科林（603050）盘中临时停牌的公告

上证公告（监察）〔2017〕036号

N科林（603050）今日上午交易出现异常波动。根据《上海证券交易所交易规则》和《关于新股上市初期交易监管有关事项的通知》的有关规定，本所决定，自2017年04月14日09时31分开始暂停N科林（603050）交易，自2017年04月14日10时01分起恢复交易。

本所提醒投资者注意交易风险，理性投资。

特此公告。

上海证券交易所

2017年04月14日
