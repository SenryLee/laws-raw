# 深圳证券交易所、深圳证券信息有限公司关于调整深证成指、中小板指、创业板指、深证100等指数样本股的公告

## 关于调整深证成指、中小板指、创业板指、深证100等指数样本股的公告

根据指数编制规则，深圳证券交易所和深圳证券信息有限公司决定于2018年1月第一个交易日对深证成指、深证100、中小板指、创业板指、中小创新等指数实施样本股定期调整。部分指数样本股调整名单见下表，其它深证指数样本股调整名单参见国证指数网（www.cnindex.com.cn）。

附件：深证成份指数样本股调整名单
