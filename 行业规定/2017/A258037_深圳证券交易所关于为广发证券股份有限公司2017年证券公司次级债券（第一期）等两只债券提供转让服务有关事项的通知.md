# 深圳证券交易所关于为广发证券股份有限公司2017年证券公司次级债券（第一期）等两只债券提供转让服务有关事项的通知

## 关于为广发证券股份有限公司2017年证券公司次级债券（第一期）等两只债券提供转让服务有关事项的通知

各会员单位：

广发证券股份有限公司2017年证券公司次级债券（第一期）、 广发证券股份有限公司2017年证券公司次级债券（第二期）定于2017年11月29日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、广发证券股份有限公司2017年证券公司次级债券（第一期）证券代码“118970”，证券简称“17广发C1”，发行总额35亿元，票面利率5.09%，债券期限3年。

2、广发证券股份有限公司2017年证券公司次级债券（第二期）证券代码“118971”，证券简称“17广发C2”，发行总额20亿元，票面利率5.1%，债券期限2年。
