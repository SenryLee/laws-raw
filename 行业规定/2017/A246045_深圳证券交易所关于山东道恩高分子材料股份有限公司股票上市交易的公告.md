# 深圳证券交易所关于山东道恩高分子材料股份有限公司股票上市交易的公告

## 关于山东道恩高分子材料股份有限公司股票上市交易的公告

山东道恩高分子材料股份有限公司人民币普通股股票将于2017年1月6日在本所上市。证券简称为“道恩股份”,证券代码为“002838”。公司人民币普通股股份总数为84,000,000股，其中首次公开发行的21,000,000股股票自上市之日起开始上市交易。
