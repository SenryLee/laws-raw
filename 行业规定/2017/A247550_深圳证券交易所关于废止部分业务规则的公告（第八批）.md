# 深圳证券交易所关于废止部分业务规则的公告（第八批）

为完善业务规则体系，根据《证券法》等法律法规，在2003年以来先后七次废止部分业务规则的基础上，本所对截至2017年2月26日期间公布的业务规则进行了全面清理。其中，已被修订、上位法规依据已废止以及因业务发展不再适用应予废止的业务规则共计20件。现将废止业务规则目录予以公布。
