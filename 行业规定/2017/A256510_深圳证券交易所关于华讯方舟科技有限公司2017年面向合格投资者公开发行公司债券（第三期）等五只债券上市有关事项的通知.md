# 深圳证券交易所关于华讯方舟科技有限公司2017年面向合格投资者公开发行公司债券（第三期）等五只债券上市有关事项的通知

## 关于华讯方舟科技有限公司2017年面向合格投资者公开发行公司债券（第三期）等五只债券上市有关事项的通知

各会员单位：

华讯方舟科技有限公司2017年面向合格投资者公开发行公司债券（第三期）,内蒙古蒙草生态环境（集团）股份有限公司2017年面向合格投资者公开发行绿色公司债券（第一期） ,创维数码控股有限公司2017年面向合格投资者公开发行公司债券（第一期）,广州越秀融资租赁有限公司2017年面向合格投资者公开发行公司债券（第一期）,北京昆仑万维科技股份有限公司2017年面向合格投资者公开发行创新创业公司债券（第一期）（品种一）定于2017年10月23日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、华讯方舟科技有限公司2017年面向合格投资者公开发行公司债券（第三期）证券代码“112572”，证券简称“17华讯03”，发行总额6.6亿元，票面利率7%，债券期限3年,附第2年末发行人调整票面利率选择权和投资者回售选择权。

2、内蒙古蒙草生态环境（集团）股份有限公司2017年面向合格投资者公开发行绿色公司债券（第一期） 证券代码“112579”，证券简称“17蒙草G1”，发行总额2.5亿元，票面利率5.5%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

3、创维数码控股有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112584”，证券简称“17创维P1”，发行总额20亿元，票面利率5.36%，债券期限5年，第3年末设发行人调整票面利率选择权和投资者回售权。

4、广州越秀融资租赁有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112587”，证券简称“17越租01”，发行总额14亿元，票面利率4.92%，债券期限5年，附存续期间第3个计息年度末发行人调整票面利率选择权、发行人赎回选择权和投资者回售选择权。

5、北京昆仑万维科技股份有限公司2017年面向合格投资者公开发行创新创业公司债券（第一期）（品种一）证券代码“112588”，证券简称“17万维S1”，发行总额2.4亿元，票面利率7%，债券期限5年，附第2个和第4个计息年度末发行人调整票面利率选择权及投资者回售选择权。
