# 深圳证券交易所关于北京科锐国际人力资源股份有限公司股票在创业板上市交易的公告

## 关于北京科锐国际人力资源股份有限公司股票在创业板上市交易的公告

北京科锐国际人力资源股份有限公司人民币普通股股票将于2017年6月8日在本所创业板上市。证券简称为“科锐国际”,证券代码为“300662”。公司人民币普通股股份总数为180,000,000股，其中首次公开发行的45,000,000股股票自上市之日起开始上市交易。
