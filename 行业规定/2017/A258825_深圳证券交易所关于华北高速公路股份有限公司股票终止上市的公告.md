# 深圳证券交易所关于华北高速公路股份有限公司股票终止上市的公告

## 关于华北高速公路股份有限公司股票终止上市的公告

根据中国证券监督管理委员会《关于核准招商局公路网络科技控股股份有限公司吸收合并华北高速公路股份有限公司的批复》（证监许可〔2017〕2126号），招商局公路网络科技控股股份有限公司换股吸收合并华北高速公路股份有限公司（以下简称“华北高速”）获得核准。本次换股吸收合并完成后，华北高速法人资格将被注销。华北高速据此向本所报送了股票终止上市的申请。

2017年12月15日，本所第九届上市委员会召开第134次工作会议，审议通过了华北高速股票终止上市的申请。

根据《深圳证券交易所股票上市规则（2014年修订）》第14.3.1条、第14.3.11条的有关规定，本所决定华北高速股票自2017年12月25日起终止上市。

本所要求华北高速按照相关规定，做好股票终止上市以及后续工作。

深圳证券交易所
