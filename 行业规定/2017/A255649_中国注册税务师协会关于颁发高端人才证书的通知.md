# 中国注册税务师协会关于颁发高端人才证书的通知

中税协秘发〔2017〕027号

各省、自治区、直辖市和计划单列市注册税务师协会：

根据《中国注册税务师行业发展规划（2014年-2017年）》专业人才队伍建设的要求，中税协于2014年起实施税务师行业高端人才培养计划。经过2014年级、2015年级两期培训，王成、蔡艳富等244名学员圆满完成预定学习任务并通过考核，中税协颁发“高端人才证书”。
