# 上海证券交易所关于2017年劳动节休市安排的公告

## 关于2017年劳动节休市安排的公告

上证公告〔2017〕9号

根据《关于上海证券交易所2017年全年休市安排的通知》（上证公告〔2016〕25号），上海证券交易所现将2017年劳动节休市有关安排通知如下：

4月29日（星期六）至5月1日（星期一）休市，5月2日（星期二）起照常开市。

请市场参与人据此安排有关工作。

上海证券交易所

二○一七年四月二十日
