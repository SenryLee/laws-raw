# 深圳证券交易所关于天水众兴菌业科技股份有限公司可转换公司债券上市交易的公告

## 关于天水众兴菌业科技股份有限公司可转换公司债券上市交易的公告

天水众兴菌业科技股份有限公司发行的920,000,000元可转换公司债券自2018年1月3日起在本所上市交易，证券简称为“众兴转债”，证券代码为“128026”，上市数量920万张。

深圳证券交易所

二〇一七年十二月二十七日
