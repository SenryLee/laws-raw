# 深圳证券交易所关于湖南科创信息技术股份有限公司股票在创业板上市交易的公告

## 关于湖南科创信息技术股份有限公司股票在创业板上市交易的公告

湖南科创信息技术股份有限公司人民币普通股股票将于2017年12月5日在本所创业板上市。证券简称为“科创信息”,证券代码为“300730”。公司人民币普通股股份总数为92,945,999股，其中首次公开发行的23,240,000股股票自上市之日起开始上市交易。

2017年12月1日
