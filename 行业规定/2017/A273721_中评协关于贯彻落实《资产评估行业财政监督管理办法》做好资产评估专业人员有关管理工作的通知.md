# 中评协关于贯彻落实《资产评估行业财政监督管理办法》做好资产评估专业人员有关管理工作的通知

中评协办〔2017〕69号

各省、自治区、直辖市、计划单列市资产评估协会（有关注册会计师协会）：

2017年6月1日，《资产评估行业财政监督管理办法》（财政部令第86号，以下简称86号令）正式实施，各省、自治区、直辖市、计划单列市资产评估协会及有关注册会计师协会要高度重视并切实做好86号令的贯彻实施工作，进一步加强资产评估专业人员自律管理，按照86号令的有关要求，做好资产评估专业人员有关管理工作，不断提升自律管理和服务水平。

中国资产评估协会正在积极研究制定资产评估专业人员管理办法，在有关办法正式出台前，资产评估师资格登记、会籍管理等有关工作暂按原有内容和程序办理。

特此通知。

二〇一七年六月一日
