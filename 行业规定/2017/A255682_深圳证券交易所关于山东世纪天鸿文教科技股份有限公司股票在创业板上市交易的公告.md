# 深圳证券交易所关于山东世纪天鸿文教科技股份有限公司股票在创业板上市交易的公告

## 关于山东世纪天鸿文教科技股份有限公司股票在创业板上市交易的公告

山东世纪天鸿文教科技股份有限公司人民币普通股股票将于2017年9月26日在本所创业板上市。证券简称为“世纪天鸿”,证券代码为“300654”。公司人民币普通股股份总数为93,350,000股，其中首次公开发行的23,350,000股股票自上市之日起开始上市交易。
