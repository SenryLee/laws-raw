# 深圳证券交易所关于浙江扬帆新材料股份有限公司股票在创业板上市交易的公告

## 关于浙江扬帆新材料股份有限公司股票在创业板上市交易的公告

浙江扬帆新材料股份有限公司人民币普通股股票将于2017年4月12日在本所创业板上市。证券简称为“扬帆新材”,证券代码为“300637”。公司人民币普通股股份总数为120,000,000股，其中首次公开发行的30,000,000股股票自上市之日起开始上市交易。
