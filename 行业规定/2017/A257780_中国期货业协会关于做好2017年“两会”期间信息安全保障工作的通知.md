# 中国期货业协会关于做好2017年“两会”期间信息安全保障工作的通知

## 关于做好2017年“两会”期间信息安全保障工作的通知

各期货公司：

根据中国证监会要求，为做好“两会”期间期货行业信息安全保障工作，现将有关事项通知如下：

一、高度重视“两会”期间信息安全保障工作。各期货公司应充分认识“两会”期间加强行业信息系统安全保障工作的重要性，按照“谁主管谁负责、谁运行谁负责”的原则，全面落实信息安全责任制，坚决防止重大信息安全事故的发生。

二、“两会”期间，各公司分管信息技术的领导和信息技术部门负责人应坚守岗位，通报联络人要保持通信联络畅通。应增加对信息系统的巡检巡查频率，除确有必要，不得对重要信息系统进行变更和升级。

三、加强信息安全突发事件的通报工作。发生信息安全事件，应按照《证券期货业信息安全事件报告与调查处理办法》规定的时间和路径要求，及时通报信息安全突发事件情况。

四、严格执行“两会”期间零报告制度。2017年3月3日至“两会”闭幕前。各公司应于每日15：30之前，通过协会行业信息管理平台安全信息填报功能中的“安全信息日报”页面，报送前一日（包括周末）15：00至当日15：00期间本公司信息系统运行情况。
