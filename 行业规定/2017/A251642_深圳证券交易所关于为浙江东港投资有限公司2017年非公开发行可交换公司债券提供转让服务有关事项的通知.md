# 深圳证券交易所关于为浙江东港投资有限公司2017年非公开发行可交换公司债券提供转让服务有关事项的通知

## 关于为浙江东港投资有限公司2017年非公开发行可交换公司债券提供转让服务有关事项的通知

各会员单位：

浙江东港投资有限公司2017年非公开发行可交换公司债券定于2017年6月26日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

浙江东港投资有限公司2017年非公开发行可交换公司债券证券代码“117076”，证券简称“17东港E1”，发行总额10亿元，票面利率1%，债券期限3年，附换股价格向下调整条款、发行人赎回条款和投资者回售条款。

深圳证券交易所

二○一七年六月二十二日
