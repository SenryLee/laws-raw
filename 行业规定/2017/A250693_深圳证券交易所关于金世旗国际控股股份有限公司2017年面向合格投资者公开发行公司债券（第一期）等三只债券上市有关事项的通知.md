# 深圳证券交易所关于金世旗国际控股股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等三只债券上市有关事项的通知

## 关于金世旗国际控股股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等三只债券上市有关事项的通知

各会员单位：

金世旗国际控股股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,金洲慈航集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,广州阳普医疗科技股份有限公司2017年面向合格投资者公开发行创新创业公司债券（第一期）定于2017年5月26日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、金世旗国际控股股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112497”，证券简称“17金旗01”，发行总额3亿元，票面利率5.7%，债券期限5年,本期债券存续期第1年末、第2年末附发行人赎回选择权；第3年末附发行人赎回选择权、上调票面利率选择权和投资者回售选择权。

2、金洲慈航集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112505”，证券简称“17金洲01”，发行总额5.2亿元，票面利率6.9%，债券期限3年，附债券存续期内的第2年末发行人调整票面利率选择权和投资者回售选择权。

3、广州阳普医疗科技股份有限公司2017年面向合格投资者公开发行创新创业公司债券（第一期）证券代码“112522”，证券简称“17阳普S1”，发行总额3亿元，票面利率5.65%，债券期限5年，第3年末附发行人调整票面利率选择权和投资者回售选择权。
