# 深圳证券交易所关于为歌尔集团有限公司2017年非公开发行可交换公司债券等两只债券提供转让服务有关事项的通知

## 关于为歌尔集团有限公司2017年非公开发行可交换公司债券等两只债券提供转让服务有关事项的通知

各会员单位：

歌尔集团有限公司2017年非公开发行可交换公司债券、北京蓝天瑞德环保技术股份有限公司2017年非公开发行创新创业可转换公司债券（第一期）定于2017年11月23日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、歌尔集团有限公司2017年非公开发行可交换公司债券证券代码“117102”，证券简称“17歌尔EB”，发行总额20亿元，票面利率0.1%，债券期限3年，附换股价格向下修正条款、回售条款和赎回条款。

2、北京蓝天瑞德环保技术股份有限公司2017年非公开发行创新创业可转换公司债券（第一期）证券代码“117103”，证券简称“蓝天转S1”，发行总额2,000万元，票面利率2%，债券期限3年，附加回售条款及转股条款。

深圳证券交易所

二○一七年十一月二十一日
