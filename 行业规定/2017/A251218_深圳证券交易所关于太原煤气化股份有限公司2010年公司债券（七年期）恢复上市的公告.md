# 深圳证券交易所关于太原煤气化股份有限公司2010年公司债券（七年期）恢复上市的公告

## 关于太原煤气化股份有限公司2010年公司债券（七年期）恢复上市的公告

根据《深圳证券交易所公司债券上市规则（2015年修订）》第7.2条的相关规定，经审查并根据本所上市委员会的审议意见，本所决定太原煤气化股份有限公司2010年公司债券（七年期）自2017年6月15日起在本所集中竞价系统和综合协议交易平台恢复上市，证券代码“112024”，证券简称“10煤气02”。根据《深圳证券交易所公司债券上市规则（2015年修订）》第2.2条规定，恢复上市后公司债券将实施投资者适当性管理。根据《关于为暂停上市公司债券提供转让服务的通知》第六条规定，暂停上市债券恢复上市的，本所对其提供的转让服务将自动终止。
