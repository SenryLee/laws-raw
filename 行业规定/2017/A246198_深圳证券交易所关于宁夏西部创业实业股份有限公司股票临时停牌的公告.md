# 深圳证券交易所关于宁夏西部创业实业股份有限公司股票临时停牌的公告

## 关于宁夏西部创业实业股份有限公司股票临时停牌的公告

因《银川晚报》、《宁夏第一财经》等媒体报道了涉及宁夏西部创业实业股份有限公司的相关事项，根据《深圳证券交易所股票上市规则》第12.4条的规定，经公司申请，本所将于2017年1月10日开市起对（证券简称：西部创业，证券代码：000557）进行临时停牌，待公司刊登相关公告后复牌。

深圳证券交易所

2017年1月10日
