# 深圳证券交易所关于支付2016年湖南省政府一般债券（八期）等五只债券利息有关事项的通知

## 关于支付2016年湖南省政府一般债券（八期）等五只债券利息有关事项的通知

各会员单位：

2016年湖南省政府一般债券（八期）、2015年厦门市政府一般债券（八期）、2015年厦门市政府专项债券（四期）、2015年宁波市政府专项债券（八期）、2015年宁波市政府一般债券（八期）将于2017年5月11日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2016年湖南省政府一般债券（八期）证券代码为“107454”，证券简称为“湖南1608”，是2016年11月11日发行的10年期债券，票面利率为2.95％，每年支付2次利息，每百元面值债券本次可获利息1.475元。

二、2015年厦门市政府一般债券（八期）证券代码为“109665”，证券简称为“厦门1508”，是2015年11月11日发行的10年期债券，票面利率为3.13％，每年支付2次利息，每百元面值债券本次可获利息1.565元。

三、2015年厦门市政府专项债券（四期）证券代码为“109667”，证券简称为“厦门15Z4”，是2015年11月11日发行的10年期债券，票面利率为3.13％，每年支付2次利息，每百元面值债券本次可获利息1.565元。

四、2015年宁波市政府专项债券（八期）证券代码为“109671”，证券简称为“宁波15Z8”，是2015年11月11日发行的10年期债券，票面利率为3.33％，每年支付2次利息，每百元面值债券本次可获利息1.665元。

五、2015年宁波市政府一般债券（八期）证券代码为“109701”，证券简称为“宁波1508”，是2015年11月11日发行的10年期债券，票面利率为3.33％，每年支付2次利息，每百元面值债券本次可获利息1.665元。

六、本所从2017年5月3日至2017年5月10日停办上述债券的转托管及调帐业务。

七、上述债券付息债权登记日为2017年5月10日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2017年5月11日除息交易。

八、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
