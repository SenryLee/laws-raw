# 深圳证券交易所关于为“华林证券-新和昌物业费信托受益权资产支持专项计划”提供转让服务的公告

## 关于为“华林证券-新和昌物业费信托受益权资产支持专项计划”提供转让服务的公告

各相关单位：

根据华林证券股份有限公司申请，本所将自2017年10月10日起在综合协议交易平台为“华林证券-新和昌物业费信托受益权资产支持专项计划”（以下简称“新和昌ABS”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“新和昌ABS”的转让业务。

二、“新和昌ABS”设立日期为2017年7月31日。优先级资产支持证券如下：证券简称“新和昌01”，证券代码为“116619”，到期日为2018年7月31日，还本付息方式为按年付息，专项计划成立后的第1个年度兑付日偿还本金；证券简称“新和昌02”，证券代码为“116620”，到期日为2019年7月31日，还本付息方式为按年付息，专项计划成立后的第2个年度兑付日偿还本金；证券简称“新和昌03”，证券代码为“116621”，到期日为2020年7月31日，还本付息方式为按年付息，专项计划成立后的第3个年度兑付日偿还本金；证券简称“新和昌04”，证券代码为“116622”，到期日为2021年8月2日，还本付息方式为按年付息，专项计划成立后的第4个年度兑付日偿还本金；证券简称“新和昌05”，证券代码为“116623”，到期日为2022年8月1日，还本付息方式为按年付息，专项计划成立后的第5个年度兑付日偿还本金。

三、“新和昌01”的单笔成交申报最低数量为10000份，“新和昌02”的单笔成交申报最低数量为10000份，“新和昌03”的单笔成交申报最低数量为10000份，“新和昌04”的单笔成交申报最低数量为10000份，“新和昌05”的单笔成交申报最低数量为10000份。

四、对首次参加“新和昌ABS”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“新和昌ABS”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
