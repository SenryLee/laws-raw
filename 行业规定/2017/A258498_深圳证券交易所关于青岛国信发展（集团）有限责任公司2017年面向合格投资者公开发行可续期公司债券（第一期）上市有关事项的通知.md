# 深圳证券交易所关于青岛国信发展（集团）有限责任公司2017年面向合格投资者公开发行可续期公司债券（第一期）上市有关事项的通知

## 关于青岛国信发展（集团）有限责任公司2017年面向合格投资者公开发行可续期公司债券（第一期）上市有关事项的通知

各会员单位：

青岛国信发展（集团）有限责任公司2017年面向合格投资者公开发行可续期公司债券（第一期）定于2017年12月12日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

青岛国信发展（集团）有限责任公司2017年面向合格投资者公开发行可续期公司债券（第一期）证券代码“112611”，证券简称“17青信Y1”，发行总额25.1亿元，票面利率5.7%，设发行人续期选择权、递延支付利息权及赎回选择权等条款。
