# 深圳证券交易所关于江苏中设集团股份有限公司股票上市交易的公告

## 关于江苏中设集团股份有限公司股票上市交易的公告

江苏中设集团股份有限公司人民币普通股股票将于2017年6月20日在本所上市。证券简称为“中设股份”,证券代码为“002883”。公司人民币普通股股份总数为53,333,500股，其中首次公开发行的13,333,500股股票自上市之日起开始上市交易。
