# 深圳证券交易所关于广东皮阿诺科学艺术家居股份有限公司股票上市交易的公告

## 关于广东皮阿诺科学艺术家居股份有限公司股票上市交易的公告

广东皮阿诺科学艺术家居股份有限公司人民币普通股股票将于2017年3月10日在本所上市。证券简称为“皮阿诺”,证券代码为“002853”。公司人民币普通股股份总数为62,136,600股，其中首次公开发行的15,600,000股股票自上市之日起开始上市交易。
