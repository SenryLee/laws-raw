# 深圳证券交易所关于宁波江丰电子材料股份有限公司股票在创业板上市交易的公告

## 关于宁波江丰电子材料股份有限公司股票在创业板上市交易的公告

宁波江丰电子材料股份有限公司人民币普通股股票将于2017年6月15日在本所创业板上市。证券简称为“江丰电子”,证券代码为“300666”。公司人民币普通股股份总数为218,760,000股，其中首次公开发行的54,690,000股股票自上市之日起开始上市交易。
