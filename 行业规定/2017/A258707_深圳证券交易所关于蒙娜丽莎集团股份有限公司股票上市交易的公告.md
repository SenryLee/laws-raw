# 深圳证券交易所关于蒙娜丽莎集团股份有限公司股票上市交易的公告

## 关于蒙娜丽莎集团股份有限公司股票上市交易的公告

蒙娜丽莎集团股份有限公司人民币普通股股票将于2017年12月19日在本所上市。证券简称为“蒙娜丽莎”,证券代码为“002918”。公司人民币普通股股份总数为157,720,000股，其中首次公开发行的39,430,000股股票自上市之日起开始上市交易。
