# 上海证券交易所关于银华交易型货币市场基金流动性服务商的公告

## 关于银华交易型货币市场基金流动性服务商的公告

上证公告（基金）〔2017〕038号

为促进银华交易型货币市场基金(以下简称"银华日利")的市场流动性和平稳运行,根据《上海证券交易所上市基金流动性服务业务指引》的有关规定,经协商银华基金管理股份有限公司,我所同意广发证券股份有限公司为银华日利（511880）流动性服务商。

特此公告。

上海证券交易所

2017年6月27日
