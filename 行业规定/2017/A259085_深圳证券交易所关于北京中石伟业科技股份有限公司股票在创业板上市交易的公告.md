# 深圳证券交易所关于北京中石伟业科技股份有限公司股票在创业板上市交易的公告

## 关于北京中石伟业科技股份有限公司股票在创业板上市交易的公告

北京中石伟业科技股份有限公司人民币普通股股票将于2017年12月27日在本所创业板上市。证券简称为“中石科技”,证券代码为“300684”。公司人民币普通股股份总数为86,870,000股，其中首次公开发行的21,720,000股股票自上市之日起开始上市交易。
