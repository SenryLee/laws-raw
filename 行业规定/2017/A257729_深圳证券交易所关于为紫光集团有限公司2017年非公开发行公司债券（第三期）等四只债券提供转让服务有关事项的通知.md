# 深圳证券交易所关于为紫光集团有限公司2017年非公开发行公司债券（第三期）等四只债券提供转让服务有关事项的通知

## 关于为紫光集团有限公司2017年非公开发行公司债券（第三期）等四只债券提供转让服务有关事项的通知

各会员单位：

紫光集团有限公司2017年非公开发行公司债券（第三期）、 大同煤矿集团有限责任公司2017年非公开发行公司债券（第三期）、大同煤矿集团有限责任公司2017年非公开发行公司债券（第四期）、 山东泰丰控股集团有限公司2017年非公开发行公司债券定于2017年11月21日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、紫光集团有限公司2017年非公开发行公司债券（第三期）证券代码“114209”，证券简称“17紫光04”，发行总额16亿元，票面利率5.8%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、大同煤矿集团有限责任公司2017年非公开发行公司债券（第三期）证券代码“114229”，证券简称“17同煤03”，发行总额40亿元，票面利率6.7%，债券期限5年，附第2年末和第4年末发行人调整票面利率选择权。

3、大同煤矿集团有限责任公司2017年非公开发行公司债券（第四期）证券代码“114230”，证券简称“17同煤04”，发行总额10亿元，票面利率6.7%，债券期限5年，附第2年末和第4年末发行人调整票面利率选择权。

4、山东泰丰控股集团有限公司2017年非公开发行公司债券证券代码“114249”，证券简称“17泰丰债”，发行总额4亿元，票面利率7.99%，债券期限7年，附第2年末、第4年末和第6年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年十一月十七日
