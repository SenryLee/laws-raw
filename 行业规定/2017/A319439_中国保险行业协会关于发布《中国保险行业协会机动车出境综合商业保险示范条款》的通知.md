# 中国保险行业协会关于发布《中国保险行业协会机动车出境综合商业保险示范条款》的通知

## 关于发布《中国保险行业协会机动车出境综合商业保险示范条款》的通知

中国保信，各财产保险公司,各省(市)保险行业协会、同业公会：

为贯彻落实《中国保监会关于深化商业车险条款费率管理制度改革的意见》精神，进一步完善商业车险示范条款体系，拓展商业车险保障范围，满足消费者多样化的保险需求，在中国保监会指导下，中国保险行业协会为做好中国境内注册机动车在境外约定区域内行驶的风险保障制度安排，组织力量通过认真研究和反复论证，并听取了行业公司和社会公众的多方意见，最终形成《中国保险行业协会机动车出境综合商业保险示范条款》。现将该示范条款印发，供各公司参考使用。

另外，该示范条款在按照《机动车商业保险条款编码规则》（中保协发〔2015〕186号）中无对应的序号，现将其序号定为04，请各公司在使用时予以注意。
