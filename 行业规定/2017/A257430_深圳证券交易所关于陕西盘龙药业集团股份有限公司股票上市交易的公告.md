# 深圳证券交易所关于陕西盘龙药业集团股份有限公司股票上市交易的公告

## 关于陕西盘龙药业集团股份有限公司股票上市交易的公告

陕西盘龙药业集团股份有限公司人民币普通股股票将于2017年11月16日在本所上市。证券简称为“盘龙药业”,证券代码为“002864”。公司人民币普通股股份总数为86,670,000股，其中首次公开发行的21,670,000股股票自上市之日起开始上市交易。
