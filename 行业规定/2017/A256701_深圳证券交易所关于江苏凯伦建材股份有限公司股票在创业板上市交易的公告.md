# 深圳证券交易所关于江苏凯伦建材股份有限公司股票在创业板上市交易的公告

## 关于江苏凯伦建材股份有限公司股票在创业板上市交易的公告

江苏凯伦建材股份有限公司人民币普通股股票将于2017年10月26日在本所创业板上市。证券简称为“凯伦股份”,证券代码为“300715”。公司人民币普通股股份总数为72,000,000股，其中首次公开发行的18,000,000股股票自上市之日起开始上市交易。
