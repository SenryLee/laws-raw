# 深圳证券交易所关于广州恒运企业集团股份有限公司股票临时停牌的公告

## 关于广州恒运企业集团股份有限公司股票临时停牌的公告

中国证监会上市公司并购重组委员会将于近日召开工作会议，审核广州越秀金融控股集团股份有限公司发行股份及支付现金购买资产并募集配套资金暨关联交易事项。因该事项同时涉及广州恒运企业集团股份有限公司重大资产出售，根据《深圳证券交易所股票上市规则》等有关规定，经广州恒运企业集团股份有限公司申请，该公司股票（证券简称：穗恒运Ａ，证券代码：000531）自2017年7月20日开市起停牌，待公司刊登相关公告后复牌。
