# 深圳证券交易所关于为云南省房地产开发经营（集团）有限公司2017年非公开发行公司债券等四只债券提供转让服务有关事项的通知

## 关于为云南省房地产开发经营（集团）有限公司2017年非公开发行公司债券等四只债券提供转让服务有关事项的通知

各会员单位：

云南省房地产开发经营（集团）有限公司2017年非公开发行公司债券、 简阳市水务投资发展有限公司2017年非公开发行公司债券（第二期）、平凉市城乡建设投资有限责任公司2017年非公开发行公司债券（第一期）、 海安县城建开发投资有限责任公司2017年非公开发行公司债券（第一期）定于2017年6月26日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、云南省房地产开发经营（集团）有限公司2017年非公开发行公司债券证券代码“114128”，证券简称“17省房债”，发行总额5亿元，票面利率5.6%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

2、简阳市水务投资发展有限公司2017年非公开发行公司债券（第二期）证券代码“114135”，证券简称“17简阳02”，发行总额9亿元，票面利率5.9%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

3、平凉市城乡建设投资有限责任公司2017年非公开发行公司债券（第一期）证券代码“114143”，证券简称“17平凉01”，发行总额10亿元，票面利率6.76%，债券期限3年。

4、海安县城建开发投资有限责任公司2017年非公开发行公司债券（第一期）证券代码“114150”，证券简称“17海发01”，发行总额10.8亿元，票面利率6.1%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所
