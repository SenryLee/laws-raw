# 深圳证券交易所关于万达集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等两只债券上市有关事项的通知

## 关于万达集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等两只债券上市有关事项的通知

各会员单位：

万达集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,深圳欧菲光科技股份有限公司2017年面向合格投资者公开发行公司债券（第一期）定于2017年3月24日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、万达集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112498”，证券简称“17万集01”，发行总额10.5亿元，票面利率6.5%，债券期限5年,附第3年发行人调整票面利率选择权和投资者回售选择权。

2、深圳欧菲光科技股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112499”，证券简称“17欧菲01”，发行总额10亿元，票面利率4.8%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所
