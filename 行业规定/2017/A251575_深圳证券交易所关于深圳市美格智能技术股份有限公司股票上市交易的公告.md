# 深圳证券交易所关于深圳市美格智能技术股份有限公司股票上市交易的公告

## 关于深圳市美格智能技术股份有限公司股票上市交易的公告

深圳市美格智能技术股份有限公司人民币普通股股票将于2017年6月22日在本所上市。证券简称为“美格智能”,证券代码为“002881”。公司人民币普通股股份总数为106,670,000股，其中首次公开发行的26,670,000股股票自上市之日起开始上市交易。
