# 上海证券交易所关于华夏快线交易型货币市场基金流动性服务商的公告

## 关于华夏快线交易型货币市场基金流动性服务商的公告

上证公告（基金）〔2017〕003号

为促进华夏快线交易型货币市场基金(以下简称"华夏快线")的市场流动性和平稳运行,根据《上海证券交易所上市基金流动性服务业务指引》的有关规定,经协商华夏基金管理有限公司,我所同意中国银河证券股份有限公司、招商证券股份有限公司为华夏快线（511650）流动性服务商。

特此公告。

上海证券交易所

2017年1月17日
