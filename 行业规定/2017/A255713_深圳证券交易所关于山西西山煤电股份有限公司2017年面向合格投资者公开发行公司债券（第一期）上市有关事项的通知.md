# 深圳证券交易所关于山西西山煤电股份有限公司2017年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

## 关于山西西山煤电股份有限公司2017年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

各会员单位：

山西西山煤电股份有限公司2017年面向合格投资者公开发行公司债券（第一期）定于2017年9月28日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

山西西山煤电股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112573”，证券简称“17西煤01”，发行总额22亿元，票面利率4.9%，债券期限5年,附第3年末发行人票面利率调整选择权和投资者回售选择权。

特此通知
