# 深圳证券交易所关于山东弘宇农机股份有限公司股票上市交易的公告

## 关于山东弘宇农机股份有限公司股票上市交易的公告

东弘宇农机股份有限公司人民币普通股股票将于2017年8月2日在本所上市。证券简称为“弘宇股份”,证券代码为“002890”。公司人民币普通股股份总数为66,670,000股，其中首次公开发行的16,670,000股股票自上市之日起开始上市交易。
