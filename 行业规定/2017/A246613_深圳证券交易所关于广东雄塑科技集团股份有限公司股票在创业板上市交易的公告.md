# 深圳证券交易所关于广东雄塑科技集团股份有限公司股票在创业板上市交易的公告

## 关于广东雄塑科技集团股份有限公司股票在创业板上市交易的公告

广东雄塑科技集团股份有限公司人民币普通股股票将于2017年1月23日在本所创业板上市。证券简称为“雄塑科技”,证券代码为“300599”。公司人民币普通股股份总数为304,000,000股，其中首次公开发行的76,000,000股股票自上市之日起开始上市交易。

深圳证券交易所

2017年1月19日
