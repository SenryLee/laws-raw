# 深圳证券交易所关于山东英科医疗用品股份有限公司股票在创业板上市交易的公告

## 关于山东英科医疗用品股份有限公司股票在创业板上市交易的公告

山东英科医疗用品股份有限公司人民币普通股股票将于2017年7月21日在本所创业板上市。证券简称为“英科医疗”,证券代码为“300677”。公司人民币普通股股份总数为97,239,307股，其中首次公开发行的24,309,827股股票自上市之日起开始上市交易。
