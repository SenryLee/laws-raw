# 深圳证券交易所关于支付2012年记账式附息（十六期）国债等五只债券利息有关事项的通知

## 关于支付2012年记账式附息（十六期）国债等五只债券利息有关事项的通知

各市场参与人：

2012年记账式附息（十六期）国债、2016年山东省政府一般债券（九期）、2016年山东省政府一般债券（十期）、2016年山东省政府一般债券（十一期）、2016年山东省政府一般债券（十二期）将于2017年9月6日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2012年记账式附息（十六期）国债证券代码为“101216”，证券简称为“国债1216”，是2012年9月6日发行的7年期债券，票面利率为3.25％，每年支付1次利息，每百元面值债券本次可获利息3.25元。

二、2016年山东省政府一般债券（九期）证券代码为“107277”，证券简称为“山东1612”，是2016年9月6日发行的3年期债券，票面利率为2.45％，每年支付1次利息，每百元面值债券本次可获利息2.45元。

三、2016年山东省政府一般债券（十期）证券代码为“107278”，证券简称为“山东1613”，是2016年9月6日发行的5年期债券，票面利率为2.6％，每年支付1次利息，每百元面值债券本次可获利息2.6元。

四、2016年山东省政府一般债券（十一期）证券代码为“107279”，证券简称为“山东1614”，是2016年9月6日发行的7年期债券，票面利率为2.88％，每年支付1次利息，每百元面值债券本次可获利息2.88元。

五、2016年山东省政府一般债券（十二期）证券代码为“107280”，证券简称为“山东1615”，是2016年9月6日发行的10年期债券，票面利率为2.89％，每年支付2次利息，每百元面值债券本次可获利息1.445元。

六、本所从2017年8月29日至2017年9月5日停办上述债券的转托管及调帐业务。

七、上述债券付息债权登记日为2017年9月5日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2017年9月6日除息交易。

八、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
