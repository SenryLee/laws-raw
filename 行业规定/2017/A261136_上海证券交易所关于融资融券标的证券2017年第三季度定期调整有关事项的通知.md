# 上海证券交易所关于融资融券标的证券2017年第三季度定期调整有关事项的通知

## 关于融资融券标的证券2017年第三季度定期调整有关事项的通知

上证发〔2017〕59号

各会员单位及其他市场参与人：

为促进融资融券业务健康长远发展，优化标的证券结构，根据《上海证券交易所融资融券交易实施细则》（以下简称《实施细则》）的相关规定及融资融券标的证券（以下简称标的证券）定期评估调整机制，上海证券交易所（以下简称本所）于每季度末对标的证券进行评估并视情况实施调整。现将2017年第三季度定期调整的有关事项通知如下：

根据《实施细则》等相关规定和测算结果，本所融资融券标的证券中的525只股票无需调整。

特此通知。

上海证券交易所

二○一七年九月二十九日
