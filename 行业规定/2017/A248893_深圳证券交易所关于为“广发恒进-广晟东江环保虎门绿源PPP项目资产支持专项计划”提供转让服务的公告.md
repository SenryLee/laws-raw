# 深圳证券交易所关于为“广发恒进-广晟东江环保虎门绿源PPP项目资产支持专项计划”提供转让服务的公告

## 关于为“广发恒进-广晟东江环保虎门绿源PPP项目资产支持专项计划”提供转让服务的公告

各相关单位：

根据广发证券资产管理（广东）有限公司申请，本所将自2017年4月7日起在综合协议交易平台为“广发恒进-广晟东江环保虎门绿源PPP项目资产支持专项计划”（以下简称“虎门绿源PPP”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“虎门绿源PPP”的转让业务。

二、“虎门绿源PPP”设立日期为2017年3月15日。优先级资产支持证券如下：证券简称“绿源优01”，证券代码为“116530”，到期日为2020年3月21日，还本付息方式为定期付息、分期定额还本；证券简称“绿源优02”，证券代码为“116531”，到期日为2023年3月21日，还本付息方式为定期付息、分期定额还本；证券简称“绿源优03”，证券代码为“116532”，到期日为2026年3月21日，还本付息方式为定期付息、分期定额还本；证券简称“绿源优04”，证券代码为“116533”，到期日为2029年3月21日，还本付息方式为定期付息、分期定额还本；证券简称“绿源优05”，证券代码为“116534”，到期日为2032年3月21日，还本付息方式为定期付息、分期定额还本。

三、“绿源优01”的单笔成交申报最低数量为10000份，“绿源优02”的单笔成交申报最低数量为10000份，“绿源优03”的单笔成交申报最低数量为10000份，“绿源优04”的单笔成交申报最低数量为10000份，“绿源优05”的单笔成交申报最低数量为10000份。

四、对首次参加“虎门绿源PPP”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“虎门绿源PPP”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
