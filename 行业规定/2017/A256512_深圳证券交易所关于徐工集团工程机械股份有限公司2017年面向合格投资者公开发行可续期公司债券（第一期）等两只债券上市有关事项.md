# 深圳证券交易所关于徐工集团工程机械股份有限公司2017年面向合格投资者公开发行可续期公司债券（第一期）等两只债券上市有关事项的通知

## 关于徐工集团工程机械股份有限公司2017年面向合格投资者公开发行可续期公司债券（第一期）等两只债券上市有关事项的通知

各会员单位：

徐工集团工程机械股份有限公司2017年面向合格投资者公开发行可续期公司债券（第一期）,万达集团股份有限公司2017年面向合格投资者公开发行公司债券（第三期）定于2017年10月23日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、徐工集团工程机械股份有限公司2017年面向合格投资者公开发行可续期公司债券（第一期）证券代码“112592”，证券简称“17徐工Y1”，发行总额27亿元，票面利率5.3%，债券期限50年,设发行人续期选择权、发行人递延支付利息权、发行人赎回选择权等特殊发行条款。

2、万达集团股份有限公司2017年面向合格投资者公开发行公司债券（第三期）证券代码“112594”，证券简称“17万集03”，发行总额5.5亿元，票面利率6.98%，债券期限5年，附第3年末发行人调整票面利率选择权和投资人回售选择权。

特此通知

深圳证券交易所
