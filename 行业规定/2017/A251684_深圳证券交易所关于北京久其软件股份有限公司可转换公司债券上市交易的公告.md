# 深圳证券交易所关于北京久其软件股份有限公司可转换公司债券上市交易的公告

## 关于北京久其软件股份有限公司可转换公司债券上市交易的公告

北京久其软件股份有限公司发行的780,000,000元可转换公司债券自2017年6月27日起在本所上市交易，证券简称为“久其转债”，证券代码为“128015”，上市数量780万张。

深圳证券交易所
