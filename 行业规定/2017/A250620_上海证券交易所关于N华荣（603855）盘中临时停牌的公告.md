# 上海证券交易所关于N华荣（603855）盘中临时停牌的公告

## 关于N华荣（603855）盘中临时停牌的公告

上证公告（监察）〔2017〕059号

N华荣（603855）今日上午交易出现异常波动。根据《上海证券交易所交易规则》和《关于新股上市初期交易监管有关事项的通知》的有关规定，本所决定，自2017年05月24日09时30分开始暂停N华荣（603855）交易，自2017年05月24日10时00分起恢复交易。

本所提醒投资者注意交易风险，理性投资。

特此公告。

上海证券交易所

2017年05月24日
