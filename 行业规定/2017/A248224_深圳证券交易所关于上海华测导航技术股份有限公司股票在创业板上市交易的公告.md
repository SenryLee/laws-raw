# 深圳证券交易所关于上海华测导航技术股份有限公司股票在创业板上市交易的公告

## 关于上海华测导航技术股份有限公司股票在创业板上市交易的公告

上海华测导航技术股份有限公司人民币普通股股票将于2017年3月21日在本所创业板上市。证券简称为“华测导航”,证券代码为“300627”。公司人民币普通股股份总数为119,200,000股，其中首次公开发行的29,800,000股股票自上市之日起开始上市交易。
