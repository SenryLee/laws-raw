# 深圳证券交易所关于为成都市新筑路桥机械股份有限公司2017年非公开发行公司债券（第一期）等三只债券提供转让服务有关事项的通知

## 关于为成都市新筑路桥机械股份有限公司2017年非公开发行公司债券（第一期）等三只债券提供转让服务有关事项的通知

各会员单位：

成都市新筑路桥机械股份有限公司2017年非公开发行公司债券（第一期）、 常德市经济建设投资集团有限公司2017年非公开发行公司债券、陕西旅游集团有限公司2017年非公开发行公司债券（第一期）定于2017年3月28日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、成都市新筑路桥机械股份有限公司2017年非公开发行公司债券（第一期）证券代码“114111”，证券简称“17新筑01”，发行总额3亿元，票面利率6.5%，债券期限3年，附第1年末、第2年末发行人上调票面利率选择权和投资者回售选择权。

2、常德市经济建设投资集团有限公司2017年非公开发行公司债券证券代码“114117”，证券简称“17常经债”，发行总额23.3亿元，票面利率5%，债券期限3年。

3、陕西旅游集团有限公司2017年非公开发行公司债券（第一期）证券代码“114125”，证券简称“17陕旅01”，发行总额6亿元，票面利率5.3%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年三月二十四日
