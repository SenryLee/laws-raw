# 中国银行间市场交易商协会公告〔2017〕23号——关于发布《非金融企业债务融资工具标准分销协议文本》的公告

## 中国银行间市场交易商协会公告

〔2017〕23号

## 关于发布《非金融企业债务融资工具标准分销协议文本》的公告

为进一步提升非金融企业债务融资工具发行分销效率、更好地发挥债务融资工具对实体经济发展的支持作用，依据《银行间债券市场非金融企业债务融资工具管理办法》（中国人民银行令〔2008〕第1号）及中国银行间市场交易商协会（以下简称“协会”）相关自律规则，协会制订了《非金融企业债务融资工具标准分销协议文本》（以下简称《标准分销协议》），经2017年8月29日交易商协会第五届常务理事会第三次会议审议通过，现予发布，供相关机构在非金融企业债务融资工具分销过程中签署使用。

本公告自2017年10月1日起正式实施。

附件：非金融企业债务融资工具标准分销协议文本

中国银行间市场交易商协会

2017年9月1日
