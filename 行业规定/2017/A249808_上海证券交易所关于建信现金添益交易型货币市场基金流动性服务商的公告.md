# 上海证券交易所关于建信现金添益交易型货币市场基金流动性服务商的公告

## 关于建信现金添益交易型货币市场基金流动性服务商的公告

上证公告（基金）〔2017〕029号

为促进建信现金添益交易型货币市场基金(以下简称"建信添益")的市场流动性和平稳运行,根据《上海证券交易所上市基金流动性服务业务指引》的有关规定,经协商建信基金管理有限责任公司,我所同意招商证券股份有限公司为建信添益（511660）流动性服务商。

特此公告。

上海证券交易所

2017年4月27日
