# 深圳证券交易所关于重庆华森制药股份有限公司股票上市交易的公告

## 关于重庆华森制药股份有限公司股票上市交易的公告

重庆华森制药股份有限公司人民币普通股股票将于2017年10月20日在本所上市。证券简称为“华森制药”,证券代码为“002907”。公司人民币普通股股份总数为400,060,000股，其中首次公开发行的40,060,000股股票自上市之日起开始上市交易。
