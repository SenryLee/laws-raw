# 深圳证券交易所关于为首钢总公司2017年非公开发行可交换公司债券（第一期）等三只债券提供转让服务有关事项的通知

## 关于为首钢总公司2017年非公开发行可交换公司债券（第一期）等三只债券提供转让服务有关事项的通知

各会员单位：

首钢总公司2017年非公开发行可交换公司债券（第一期）、 深圳市宝德投资控股有限公司2017年非公开发行可交换公司债券（第一期）、深圳市宝德投资控股有限公司2017年非公开发行可交换公司债券（第二期）定于2017年10月13日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、首钢总公司2017年非公开发行可交换公司债券（第一期）证券代码“117083”，证券简称“17首钢E1”，发行总额36亿元，票面利率1%，债券期限3年，附换股价格向下修正条款、赎回条款和回售条款。

2、深圳市宝德投资控股有限公司2017年非公开发行可交换公司债券（第一期）证券代码“117087”，证券简称“17宝德E1”，发行总额2.85亿元，票面利率6.5%，债券期限3年，附换股价格向下修正条款、发行人赎回条款。

3、深圳市宝德投资控股有限公司2017年非公开发行可交换公司债券（第二期）证券代码“117088”，证券简称“17宝德E2”，发行总额3.08亿元，票面利率6.5%，债券期限3年，附换股价格向下修正条款、发行人赎回条款。

深圳证券交易所

二○一七年十月十一日
