# 深圳证券交易所关于上海新时达电气股份有限公司可转换公司债券上市交易的公告

## 关于上海新时达电气股份有限公司可转换公司债券上市交易的公告

上海新时达电气股份有限公司发行的882,505,700元可转换公司债券自2017年12月4日起在本所上市交易，证券简称为“时达转债”，证券代码为“128018”，上市数量882.5057万张。

深圳证券交易所

二〇一七年十一月三十日
