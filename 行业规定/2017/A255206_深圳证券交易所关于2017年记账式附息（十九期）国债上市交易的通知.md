# 深圳证券交易所关于2017年记账式附息（十九期）国债上市交易的通知

## 关于2017年记账式附息（十九期）国债上市交易的通知

各市场参与人：

2017年记账式附息（十九期）国债已发行结束，根据财政部有关规定，本期债券于2017年9月18日起在本所上市交易。

本期债券为2年期固定利率附息式国债，证券编码“101719”，证券简称“国债1719”，票面利率3.5％，标准交易单位“10张”，2019年9月14日到期还本并支付最后一期利息。

特此通知

深圳证券交易所

二○一七年九月十四日
