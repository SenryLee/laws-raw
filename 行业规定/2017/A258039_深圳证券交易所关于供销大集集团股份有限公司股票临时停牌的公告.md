# 深圳证券交易所关于供销大集集团股份有限公司股票临时停牌的公告

## 关于供销大集集团股份有限公司股票临时停牌的公告

因供销大集集团股份有限公司发生对股价可能产生较大影响、没有公开披露的重大事项，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：供销大集，证券代码：000564）自2017年11月28日开市起停牌，待公司刊登相关公告后复牌。

深圳证券交易所
