# 深圳证券交易所关于山东共达电声股份有限公司股票临时停牌的公告

## 关于山东共达电声股份有限公司股票临时停牌的公告

由于山东共达电声股份有限公司于2017年4月12日披露的《山东共达电声股份有限公司实际控制人签署控股股权转让意向协议的公告》存在内容不够完整，可能误导投资者的投资决策，根据本所《股票上市规则》和《中小企业板上市公司规范运作指引》的有关规定，经公司申请，公司股票（证券简称：共达电声，证券代码：002655）于2017年4月12日开市起临时停牌，待公司通过指定媒体披露补充/更正公告后复牌，敬请投资者密切关注。

深圳证券交易所

2017年4月12日
