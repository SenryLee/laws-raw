# 深圳证券交易所关于深圳市金溢科技股份有限公司股票上市交易的公告

## 关于深圳市金溢科技股份有限公司股票上市交易的公告

深圳市金溢科技股份有限公司人民币普通股股票将于2017年5月15日在本所上市。证券简称为“金溢科技”,证券代码为“002869”。公司人民币普通股股份总数为117,800,000股，其中首次公开发行的29,520,000股股票自上市之日起开始上市交易。
