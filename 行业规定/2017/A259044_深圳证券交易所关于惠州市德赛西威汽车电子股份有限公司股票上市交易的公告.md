# 深圳证券交易所关于惠州市德赛西威汽车电子股份有限公司股票上市交易的公告

## 关于惠州市德赛西威汽车电子股份有限公司股票上市交易的公告

惠州市德赛西威汽车电子股份有限公司人民币普通股股票将于2017年12月26日在本所上市。证券简称为“德赛西威”,证券代码为“002920”。公司人民币普通股股份总数为550,000,000股，其中首次公开发行的100,000,000股股票自上市之日起开始上市交易。
