# 深圳证券交易所关于为雅安发展投资有限责任公司2017年非公开发行公司债券（第一期）等两只债券提供转让服务有关事项的通知

## 关于为雅安发展投资有限责任公司2017年非公开发行公司债券（第一期）等两只债券提供转让服务有关事项的通知

各会员单位：

雅安发展投资有限责任公司2017年非公开发行公司债券（第一期）、 国信证券股份有限公司2017年非公开发行公司债券（第一期）定于2017年11月1日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、雅安发展投资有限责任公司2017年非公开发行公司债券（第一期）证券代码“114206”，证券简称“17雅投01”，发行总额6亿元，票面利率7.2%，债券期限9年，附债券存续期第3个计息年度末、第6个计息年度末发行人调整票面利率选择权、发行人赎回选择权和投资者回售选择权。

2、国信证券股份有限公司2017年非公开发行公司债券（第一期）证券代码“114227”，证券简称“17国信04”，发行总额30亿元，票面利率4.83%，债券期限1年。

深圳证券交易所
