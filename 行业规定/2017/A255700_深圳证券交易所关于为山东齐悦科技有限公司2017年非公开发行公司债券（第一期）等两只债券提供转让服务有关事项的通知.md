# 深圳证券交易所关于为山东齐悦科技有限公司2017年非公开发行公司债券（第一期）等两只债券提供转让服务有关事项的通知

## 关于为山东齐悦科技有限公司2017年非公开发行公司债券（第一期）等两只债券提供转让服务有关事项的通知

各会员单位：

山东齐悦科技有限公司2017年非公开发行公司债券（第一期）、 武汉市江夏农业集团有限公司2017年非公开发行公司债券（第一期）定于2017年9月27日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、山东齐悦科技有限公司2017年非公开发行公司债券（第一期）证券代码“114184”，证券简称“17齐悦01”，发行总额1.5亿元，票面利率7.5%，债券期限1年。

2、武汉市江夏农业集团有限公司2017年非公开发行公司债券（第一期）证券代码“114202”，证券简称“17江夏01”，发行总额5亿元，票面利率6.75%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年九月二十五日
