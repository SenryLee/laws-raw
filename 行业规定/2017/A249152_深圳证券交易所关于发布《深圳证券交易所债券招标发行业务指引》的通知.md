# 深圳证券交易所关于发布《深圳证券交易所债券招标发行业务指引》的通知

## 关于发布《深圳证券交易所债券招标发行业务指引》的通知

深证会〔2017〕119号

各市场参与人：

为规范通过深圳证券交易所（以下简称“本所”）开展的债券招标发行业务，维护市场公平、公正、有序，保护各方合法权益，本所制定了《深圳证券交易所债券招标发行业务指引》，经中国证监会批准，现予以发布并施行。

特此通知

附件：深圳证券交易所债券招标发行业务指引

深圳证券交易所

2017年4月10日
