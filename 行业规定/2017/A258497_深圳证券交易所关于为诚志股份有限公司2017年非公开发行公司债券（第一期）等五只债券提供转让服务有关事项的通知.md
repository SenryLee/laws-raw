# 深圳证券交易所关于为诚志股份有限公司2017年非公开发行公司债券（第一期）等五只债券提供转让服务有关事项的通知

## 关于为诚志股份有限公司2017年非公开发行公司债券（第一期）等五只债券提供转让服务有关事项的通知

各会员单位：

诚志股份有限公司2017年非公开发行公司债券（第一期）、 深圳市彩生活服务集团有限公司2017年非公开发行公司债券（第一期）、 河南新野纺织股份有限公司2017年非公开发行公司债券（第一期）、 江苏徐工工程机械租赁有限公司2017年非公开发行公司债券（第二期）、 三胞集团有限公司2017年非公开发行公司债券（第三期）定于2017年12月12日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、诚志股份有限公司2017年非公开发行公司债券（第一期）证券代码“114251”，证券简称“17诚志债”，发行总额10亿元，票面利率5.8%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

2、深圳市彩生活服务集团有限公司2017年非公开发行公司债券 （第一期）证券代码“114258”，证券简称“17彩生01”，发行总额1.5亿元，票面利率7%，债券期限3年。

3、河南新野纺织股份有限公司2017年非公开发行公司债券（第一期）证券代码“114261”，证券简称“17新野02”，发行总额4亿元，票面利率7.78%，债券期限5年，附第2年末、第4年末发行人调整票面利率选择权和投资者回售选择权。

4、江苏徐工工程机械租赁有限公司2017年非公开发行公司债券（第二期）证券代码“114264”，证券简称“17徐工02”，发行总额1.8亿元，票面利率6.6%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

5、三胞集团有限公司2017年非公开发行公司债券（第三期）证券代码“114272”，证券简称“17三胞03”，发行总额4亿元，票面利率7.5%，债券期限3年，附第1年末、第2年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年十二月八日
