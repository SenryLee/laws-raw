# 深圳证券交易所关于传化智联股份有限公司股票临时停牌的公告

## 关于传化智联股份有限公司股票临时停牌的公告

由于传化智联股份有限公司于2017年6月30日披露的《关于取得第三方支付牌照的公告》内容不够完整，可能误导投资者的投资决策，根据本所《股票上市规则》和《中小企业板上市公司规范运作指引》的有关规定，经公司申请，公司股票（证券简称：传化智联，证券代码：002010）于2017年6月30日开市起临时停牌，待公司通过指定媒体披露补充公告后复牌，敬请投资者密切关注。

深圳证券交易所

2017年6月30日
