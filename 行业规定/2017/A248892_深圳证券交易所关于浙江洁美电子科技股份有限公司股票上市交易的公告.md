# 深圳证券交易所关于浙江洁美电子科技股份有限公司股票上市交易的公告

## 关于浙江洁美电子科技股份有限公司股票上市交易的公告

浙江洁美电子科技股份有限公司人民币普通股股票将于2017年4月7日在本所上市。证券简称为“洁美科技”,证券代码为“002859”。公司人民币普通股股份总数为102,280,000股，其中首次公开发行的25,570,000股股票自上市之日起开始上市交易。
