# 深圳证券交易所关于2017年广东省政府一般债券（九期）分销有关事项的通知

## 关于2017年广东省政府一般债券（九期）分销有关事项的通知

各市场参与人：

根据《关于2017年广东省政府一般债券（九期-十一期）发行有关事宜的通知》和深圳证券交易所（以下简称“本所”）的有关规定，现就承销商通过本所交易系统分销债券的有关事项通知如下：

2017年广东省政府一般债券（九期）（以下简称“本期债券”）通过本所交易系统挂牌分销，挂牌分销期为2017年8月14日，2017年8月16日起上市交易。

本期债券为固定利率债券，期限为3年，票面利率为3.57%,利息每年支付一次；本期债券起息日为2017年8月14日，每年8月14日支付利息（逢节假日顺延，下同），2020年8月14日偿还本金并支付最后一次利息。

本期债券采用场内挂牌和场外签订分销合同的方式分销。挂牌分销为承销商在本所交易系统挂牌卖出；协议分销为承销商同其他机构或个人投资者签订分销协议进行分销认购。

本期债券在本所挂牌分销时，由承销商自定价格进行分销；投资者认购申报单位为10张或10张的整数倍（1张为面值100元）。

在分销期内，承销商通过本所交易系统挂牌销售其所承销的本期债券，其所承销本期债券的证券简称由不超过8个字符组成：如“中山广03”表示由中山证券有限责任公司承销的本期债券，分销证券代码为“101675”，分销结束后统一转换成上市交易代码“107870”。

在分销期内，本所交易系统通过买卖盘揭示承销商挂牌数量，行情成交量一栏实时显示承销商累计销售数量。

在分销期内，投资者申报买入本期债券时免缴佣金，本所亦不向证券经营机构收取购买债券的经手费。

投资者须用证券账户（含基金帐户）申报买入。
