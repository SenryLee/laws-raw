# 中国期货业协会关于“金融期货投资者适当性知识测试”系统上线的通知

## 关于“金融期货投资者适当性知识测试”系统上线的通知

中期协字〔2017〕61号

各会员单位:

我协会即日起正式上线“金融期货投资者适当性知识测试”系统。各公司在对潜在金融期货投资者进行适当性评估时，应通过该系统测试其对金融期货基础知识、交易所交易规则等应知应会内容的掌握程度，并按照交易所要求做好测试人员身份审核、测试成绩标准审核、测试结果存档保存等工作。

“金融期货投资者适当性知识测试”系统的功能介绍和操作说明详见会员邮箱，请各公司组织相关业务人员认真学习以上材料，及时反馈相关问题，以保证知识测试的顺利开展。

特此通知。

中国期货业协会

二○一七年六月三十日
