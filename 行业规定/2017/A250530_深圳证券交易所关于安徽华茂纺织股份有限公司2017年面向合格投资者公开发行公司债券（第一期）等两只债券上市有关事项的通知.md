# 深圳证券交易所关于安徽华茂纺织股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等两只债券上市有关事项的通知

## 关于安徽华茂纺织股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等两只债券上市有关事项的通知

各会员单位：

安徽华茂纺织股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,游族网络股份有限公司2017年面向合格投资者公开发行公司债券（第一期）定于2017年5月22日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、安徽华茂纺织股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112512”，证券简称“17华茂01”，发行总额5.66亿元，票面利率5.42%，债券期限5年,附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、游族网络股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112514”，证券简称“17游族01”，发行总额4亿元，票面利率5.5%，债券期限3年，第2年末附发行人上调票面利率选择权及投资者回售选择权。

特此通知

深圳证券交易所
