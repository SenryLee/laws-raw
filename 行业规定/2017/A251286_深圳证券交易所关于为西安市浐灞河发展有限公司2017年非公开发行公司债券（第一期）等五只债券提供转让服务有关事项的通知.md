# 深圳证券交易所关于为西安市浐灞河发展有限公司2017年非公开发行公司债券（第一期）等五只债券提供转让服务有关事项的通知

## 关于为西安市浐灞河发展有限公司2017年非公开发行公司债券（第一期）等五只债券提供转让服务有关事项的通知

各会员单位：

西安市浐灞河发展有限公司2017年非公开发行公司债券（第一期）、 紫光集团有限公司2017年非公开发行公司债券（第二期）（品种一）、紫光集团有限公司2017年非公开发行公司债券（第二期）（品种二）、 北京晓程科技股份有限公司2017年非公开发行公司债券（第一期）、 江阴城市建设投资有限公司2017年非公开发行公司债券（第一期）定于2017年6月13日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、西安市浐灞河发展有限公司2017年非公开发行公司债券（第一期）证券代码“114119”，证券简称“17浐灞01”，发行总额5亿元，票面利率5.78%，债券期限3年。

2、紫光集团有限公司2017年非公开发行公司债券（第二期）（品种一）证券代码“114138”，证券简称“17紫光02”，发行总额37亿元，票面利率5.5%，债券期限3年。

3、紫光集团有限公司2017年非公开发行公司债券（第二期）（品种二）证券代码“114139”，证券简称“17紫光03”，发行总额7.5亿元，票面利率5.85%，债券期限5年。

4、北京晓程科技股份有限公司2017年非公开发行公司债券（第一期）证券代码“114151”，证券简称“17晓程01”，发行总额2亿元，票面利率6%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

5、江阴城市建设投资有限公司2017年非公开发行公司债券（第一期）证券代码“114166”，证券简称“17江阴01”，发行总额12亿元，票面利率5.7%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。
