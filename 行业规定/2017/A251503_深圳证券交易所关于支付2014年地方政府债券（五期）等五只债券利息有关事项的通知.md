# 深圳证券交易所关于支付2014年地方政府债券（五期）等五只债券利息有关事项的通知

## 关于支付2014年地方政府债券（五期）等五只债券利息有关事项的通知

各会员单位：

2014年地方政府债券（五期）、2015年陕西省政府一般债券（一期）、2015年陕西省政府一般债券（二期）、2015年陕西省政府一般债券（三期）、2015年陕西省政府一般债券（四期）将于2017年6月30日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2014年地方政府债券（五期）证券代码为“109126”，证券简称为“地债1405”，是2014年6月30日发行的5年期债券，票面利率为4.12％，每年支付1次利息，每百元面值债券本次可获利息4.12元。

二、2015年陕西省政府一般债券（一期）证券代码为“109268”，证券简称为“陕西1501”，是2015年6月30日发行的3年期债券，票面利率为2.87％，每年支付1次利息，每百元面值债券本次可获利息2.87元。

三、2015年陕西省政府一般债券（二期）证券代码为“109269”，证券简称为“陕西1502”，是2015年6月30日发行的5年期债券，票面利率为3.2％，每年支付1次利息，每百元面值债券本次可获利息3.2元。

四、2015年陕西省政府一般债券（三期）证券代码为“109270”，证券简称为“陕西1503”，是2015年6月30日发行的7年期债券，票面利率为3.53％，每年支付1次利息，每百元面值债券本次可获利息3.53元。

五、2015年陕西省政府一般债券（四期）证券代码为“109271”，证券简称为“陕西1504”，是2015年6月30日发行的10年期债券，票面利率为3.6％，每年支付2次利息，每百元面值债券本次可获利息1.8元。

六、本所从2017年6月22日至2017年6月29日停办上述债券的转托管及调帐业务。

七、上述债券付息债权登记日为2017年6月29日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2017年6月30日除息交易。

八、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
