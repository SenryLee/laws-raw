# 深圳证券交易所关于2017年青海省政府一般债券（十二期）上市交易的通知

## 关于2017年青海省政府一般债券（十二期）上市交易的通知

各市场参与人：

2017年青海省政府一般债券（十二期）已发行结束，根据财政部有关规定，本期债券于2017年11月29日起在本所上市交易。

本期债券为10年期固定利率附息式国债（地方政府债），证券编码“106309”，证券简称“青海1724”，票面利率4.3％，标准交易单位“10张”，2027年11月27日到期还本并支付最后一期利息。
