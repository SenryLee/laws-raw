# 深圳证券交易所关于为“招商创融-广田集团应收账款资产支持专项计划”提供转让服务的公告

## 关于为“招商创融-广田集团应收账款资产支持专项计划”提供转让服务的公告

各相关单位：

根据招商证券资产管理有限公司申请，本所将自2017年8月8日起在综合协议交易平台为“招商创融-广田集团应收账款资产支持专项计划”（以下简称“招商广田专项计划”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“招商广田专项计划”的转让业务。

二、“招商广田专项计划”设立日期为2017年6月7日。优先级资产支持证券如下：证券简称“17广田A1”，证券代码为“116575”，到期日为2018年6月7日，还本付息方式为每3个月付息，过手还本；证券简称“17广田A2”，证券代码为“116576”，到期日为2019年6月10日，还本付息方式为每3个月付息，过手还本。

三、“17广田A1”的单笔成交申报最低数量为10000份，“17广田A2”的单笔成交申报最低数量为10000份。

四、对首次参加“招商广田专项计划”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“招商广田专项计划”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
