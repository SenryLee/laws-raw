# 深圳证券交易所关于为苏州永福投资有限公司2017年非公开发行可交换公司债券提供转让服务有关事项的通知

## 关于为苏州永福投资有限公司2017年非公开发行可交换公司债券提供转让服务有关事项的通知

各会员单位：

苏州永福投资有限公司2017年非公开发行可交换公司债券定于2017年9月28日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

苏州永福投资有限公司2017年非公开发行可交换公司债券证券代码“117085”，证券简称“17永福E1”，发行总额1.35亿元，票面利率5%，债券期限2年，附换股价格向下修正条款、发行人赎回条款。

深圳证券交易所

二○一七年九月二十六日
