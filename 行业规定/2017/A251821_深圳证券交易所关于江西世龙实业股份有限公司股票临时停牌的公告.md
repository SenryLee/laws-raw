# 深圳证券交易所关于江西世龙实业股份有限公司股票临时停牌的公告

## 关于江西世龙实业股份有限公司股票临时停牌的公告

由于江西世龙实业股份有限公司于2017年6月29日披露的《关于间接股东股权变动的补充更正公告》存在内容不够完整和表述不够准确，可能误导投资者的投资决策，根据本所《股票上市规则》和《中小企业板上市公司规范运作指引》的有关规定，经公司申请，公司股票（证券简称：世龙实业，证券代码：002748）于2017年6月29日开市起临时停牌，待公司通过指定媒体披露补充更正公告后复牌，敬请投资者密切关注。

深圳证券交易所

2017年6月29日
