# 深圳证券交易所关于为广发证券股份有限公司2017年证券公司短期公司债券（第七期）等两只债券提供转让服务有关事项的通知

## 关于为广发证券股份有限公司2017年证券公司短期公司债券（第七期）等两只债券提供转让服务有关事项的通知

各会员单位：

广发证券股份有限公司2017年证券公司短期公司债券（第七期）、 广发证券股份有限公司2017年证券公司短期公司债券（第八期）定于2017年12月4日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、广发证券股份有限公司2017年证券公司短期公司债券（第七期）证券代码“117575”，证券简称“广发1707”，发行总额22亿元，票面利率5.07%，债券期限365日。

2、广发证券股份有限公司2017年证券公司短期公司债券（第八期）证券代码“117576”，证券简称“广发1708”，发行总额20亿元，票面利率4.95%，债券期限185日。
