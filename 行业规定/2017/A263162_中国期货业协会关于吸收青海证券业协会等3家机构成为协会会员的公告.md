# 中国期货业协会关于吸收青海证券业协会等3家机构成为协会会员的公告

## 关于吸收青海证券业协会等3家机构成为协会会员的公告

根据机构自愿申请，按照协会章程，经协会理事会审议，同意吸收青海证券业协会等3家机构成为协会会员（具体名单附后）。

特此公告。

中国期货业协会

二〇一七年十二月六日

附

## 3家新入会会员名单

|  |  |  |
| --- | --- | --- |
| **序号** | **公司名称** | **会员类型** |
| 1 | 青海证券业协会 | 联系会员 |
| 2 | 江西瑞奇资本管理有限公司 | 普通会员 |
| 3 | 华泰长城投资管理有限公司 | 普通会员 |
