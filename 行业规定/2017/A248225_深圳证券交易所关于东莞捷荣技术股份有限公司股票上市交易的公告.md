# 深圳证券交易所关于东莞捷荣技术股份有限公司股票上市交易的公告

## 关于东莞捷荣技术股份有限公司股票上市交易的公告

东莞捷荣技术股份有限公司人民币普通股股票将于2017年3月21日在本所上市。证券简称为“捷荣技术”,证券代码为“002855”。公司人民币普通股股份总数为240,000,000股，其中首次公开发行的60,000,000股股票自上市之日起开始上市交易。
