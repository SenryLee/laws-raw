# 深圳证券交易所关于浙江威星智能仪表股份有限公司股票上市交易的公告

## 关于浙江威星智能仪表股份有限公司股票上市交易的公告

浙江威星智能仪表股份有限公司人民币普通股股票将于2017年2月17日在本所上市。证券简称为“威星智能”,证券代码为“002849”。公司人民币普通股股份总数为86,666,700股，其中首次公开发行的21,666,700股股票自上市之日起开始上市交易。
