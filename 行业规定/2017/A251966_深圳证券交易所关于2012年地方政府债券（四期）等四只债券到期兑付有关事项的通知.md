# 深圳证券交易所关于2012年地方政府债券（四期）等四只债券到期兑付有关事项的通知

## 关于2012年地方政府债券（四期）等四只债券到期兑付有关事项的通知

各会员单位：

2012年地方政府债券（四期）、2014年地方政府债券（六期）、2017年记账式贴现（三期）国债、2017年记账式贴现（十七期）国债将于2017年7月17日到期兑付。为做好上述债券的本息兑付工作，现将有关事项通知如下：

一、2012年地方政府债券（四期）证券代码为“109080”，证券简称为“地债1204”，是2012年7月17日发行的5年期债券，票面利率为3.02%，每年支付1次利息，每百元面值债券兑付可获本息103.02元。

二、2014年地方政府债券（六期）证券代码为“109130”，证券简称为“地债1406”，是2014年7月15日发行的3年期债券，票面利率为4.15%，每年支付1次利息，每百元面值债券兑付可获本息104.15元。

三、2017年记账式贴现（三期）国债证券代码为“108158”，证券简称为“贴债1703”，是2017年1月16日发行的182日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

四、2017年记账式贴现（十七期）国债证券代码为“108173”，证券简称为“贴债1717”，是2017年4月17日发行的91日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

五、本所从2017年7月7日起停办上述债券的转托管及调帐业务。

六、上述债券兑付债权登记日为2017年7月12日，凡于当日收市后持有上述债券的投资者，享有获得本次兑付款项的权利。2017年7月13日上述债券摘牌。

七、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的上述债券兑付款项后，将其划入各证券商的清算备付金帐户，并由证券商将兑付资金及时划入各投资者的资金帐户。

深圳证券交易所
