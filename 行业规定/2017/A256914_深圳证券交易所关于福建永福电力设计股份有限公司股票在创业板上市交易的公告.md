# 深圳证券交易所关于福建永福电力设计股份有限公司股票在创业板上市交易的公告

## 关于福建永福电力设计股份有限公司股票在创业板上市交易的公告

福建永福电力设计股份有限公司人民币普通股股票将于2017年10月31日在本所创业板上市。证券简称为“永福股份”,证券代码为“300712”。公司人民币普通股股份总数为140,080,000股，其中首次公开发行的35,020,000股股票自上市之日起开始上市交易。
