# 深圳证券交易所关于为“招商资管-前海一方恒融第一期（4号）资产支持专项计划”提供转让服务的公告

## 关于为“招商资管-前海一方恒融第一期（4号）资产支持专项计划”提供转让服务的公告

各相关单位：

根据招商证券资产管理有限公司申请，本所将自2017年3月22日起在综合协议交易平台为“招商资管-前海一方恒融第一期（4号）资产支持专项计划”（以下简称“一方恒融一期4号”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“一方恒融一期4号”的转让业务。

二、“一方恒融一期4号”设立日期为2017年1月13日。优先级资产支持证券如下：证券简称“恒融4A1”，证券代码为“116496”，到期日为2017年11月2日，还本付息方式为到期一次性还本付息；证券简称“恒融4A2”，证券代码为“116497”，到期日为2017年11月9日，还本付息方式为到期一次性还本付息；证券简称“恒融4A3”，证券代码为“116498”，到期日为2017年11月16日，还本付息方式为到期一次性还本付息；证券简称“恒融4A4”，证券代码为“116499”，到期日为2017年11月23日，还本付息方式为到期一次性还本付息；证券简称“恒融4A5”，证券代码为“116500”，到期日为2017年11月30日，还本付息方式为到期一次性还本付息；证券简称“恒融4A6”，证券代码为“116501”，到期日为2017年12月7日，还本付息方式为到期一次性还本付息。

三、“恒融4A1”的单笔成交申报最低数量为10000份，“恒融4A2”的单笔成交申报最低数量为10000份，“恒融4A3”的单笔成交申报最低数量为10000份，“恒融4A4”的单笔成交申报最低数量为10000份，“恒融4A5”的单笔成交申报最低数量为10000份，“恒融4A6”的单笔成交申报最低数量为10000份。
