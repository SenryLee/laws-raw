# 深圳证券交易所关于为云南力帆骏马车辆有限公司2017年非公开发行公司债券（第二期）（品种一）等两只债券提供转让服务有关事项的通知

## 关于为云南力帆骏马车辆有限公司2017年非公开发行公司债券（第二期）（品种一）等两只债券提供转让服务有关事项的通知

各会员单位：

云南力帆骏马车辆有限公司2017年非公开发行公司债券（第二期）（品种一）、云南力帆骏马车辆有限公司2017年非公开发行公司债券（第二期）（品种二）定于2017年11月23日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、云南力帆骏马车辆有限公司2017年非公开发行公司债券（第二期）（品种一）证券代码“114250”，证券简称“17骏马02”，发行总额2亿元，票面利率9%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、云南力帆骏马车辆有限公司2017年非公开发行公司债券（第二期）（品种二）证券代码“114255”，证券简称“17骏马03”，发行总额2亿元，票面利率7.8%，债券期限3年，附第1年末及第2年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年十一月二十一日
