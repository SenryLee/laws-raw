# 深圳证券交易所关于青岛英派斯健康科技股份有限公司股票上市交易的公告

## 关于青岛英派斯健康科技股份有限公司股票上市交易的公告

青岛英派斯健康科技股份有限公司人民币普通股股票将于2017年9月15日在本所上市。证券简称为“英派斯”,证券代码为“002899”。公司人民币普通股股份总数为120,000,000股，其中首次公开发行的30,000,000股股票自上市之日起开始上市交易。
