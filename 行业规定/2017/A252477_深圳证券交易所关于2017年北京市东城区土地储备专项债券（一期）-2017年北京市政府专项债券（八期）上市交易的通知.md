# 深圳证券交易所关于2017年北京市东城区土地储备专项债券（一期）-2017年北京市政府专项债券（八期）上市交易的通知

## 关于2017年北京市东城区土地储备专项债券（一期）-2017年北京市政府专项债券（八期）上市交易的通知

各会员单位：

2017年北京市东城区土地储备专项债券（一期）-2017年北京市政府专项债券（八期）已发行结束，根据财政部通知，本期债券于2017年7月19日起在本所上市交易。

本期债券为5年期固定利率附息式国债（地方政府债），证券编码“107815”，证券简称“北京1713”，票面利率3.55％，标准交易单位“10张”，2022年7月17日到期还本并支付最后一期利息。
