# 深圳证券交易所关于浙江水晶光电科技股份有限公司可转换公司债券上市交易的公告

## 关于浙江水晶光电科技股份有限公司可转换公司债券上市交易的公告

浙江水晶光电科技股份有限公司发行的1,180,000,000元可转换公司债券自2017年12月12日起在本所上市交易，证券简称为“水晶转债”，证券代码为“128020”，上市数量1,180万张。

深圳证券交易所

二〇一七年十二月十一日
