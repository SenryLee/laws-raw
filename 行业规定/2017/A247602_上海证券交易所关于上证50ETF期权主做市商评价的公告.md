# 上海证券交易所关于上证50ETF期权主做市商评价的公告

## 关于上证50ETF期权主做市商评价的公告

上证公告〔2017〕5号

根据《上海证券交易所股票期权试点做市商业务指引》的相关规定，上海证券交易所（以下简称本所）上证50ETF期权主做市商在2017年1月21日至2017年2月20日期间的评价情况如下：光大证券股份有限公司、广发证券股份有限公司、中泰证券股份有限公司等3家证券公司的评价结果为AA；国泰君安证券股份有限公司、国信证券股份有限公司、海通证券股份有限公司、招商证券股份有限公司、中信建投证券股份有限公司、中信证券股份有限公司等6家证券公司的评价结果为A；华泰证券股份有限公司因部分合约报价价差过大，未满足本所的相关要求，评价结果为D。目前，华泰证券股份有限公司已经调整完善相关报价价差参数设置。

特此公告。

上海证券交易所

二○一七年二月二十八日
