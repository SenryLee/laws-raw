# 深圳证券交易所关于厦门国际港务股份有限公司2017年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

## 关于厦门国际港务股份有限公司2017年面向合格投资者公开发行公司债券（第一期）上市有关事项的通知

各会员单位：

厦门国际港务股份有限公司2017年面向合格投资者公开发行公司债券（第一期）定于2017年10月23日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

厦门国际港务股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112590”，证券简称“17厦港01”，发行总额5亿元，票面利率4.69%，债券期限5年,附第三年末发行人调整票面利率选择权及投资者回售选择权。

特此通知

深圳证券交易所

二○一七年十月十九日
