# 深圳证券交易所关于特一药业集团股份有限公司可转换公司债券上市交易的公告

## 关于特一药业集团股份有限公司可转换公司债券上市交易的公告

特一药业集团股份有限公司发行的354,000,000元可转换公司债券自2017年12月28日起在本所上市交易，证券简称为“特一转债”，证券代码为“128025”，上市数量354万张。
