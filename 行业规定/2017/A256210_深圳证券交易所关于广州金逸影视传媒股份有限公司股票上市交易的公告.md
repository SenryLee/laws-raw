# 深圳证券交易所关于广州金逸影视传媒股份有限公司股票上市交易的公告

## 关于广州金逸影视传媒股份有限公司股票上市交易的公告

广州金逸影视传媒股份有限公司人民币普通股股票将于2017年10月16日在本所上市。证券简称为“金逸影视”,证券代码为“002905”。公司人民币普通股股份总数为168,000,000股，其中首次公开发行的42,000,000股股票自上市之日起开始上市交易。
