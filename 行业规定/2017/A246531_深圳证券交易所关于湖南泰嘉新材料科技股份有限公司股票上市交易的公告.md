# 深圳证券交易所关于湖南泰嘉新材料科技股份有限公司股票上市交易的公告

## 关于湖南泰嘉新材料科技股份有限公司股票上市交易的公告

湖南泰嘉新材料科技股份有限公司人民币普通股股票将于2017年1月20日在本所上市。证券简称为“泰嘉股份”,证券代码为“002843”。公司人民币普通股股份总数为140,000,000股，其中首次公开发行的35,000,000股股票自上市之日起开始上市交易。
