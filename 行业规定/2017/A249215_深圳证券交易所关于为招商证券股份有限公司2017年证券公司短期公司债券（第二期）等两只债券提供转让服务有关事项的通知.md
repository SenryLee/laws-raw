# 深圳证券交易所关于为招商证券股份有限公司2017年证券公司短期公司债券（第二期）等两只债券提供转让服务有关事项的通知

## 关于为招商证券股份有限公司2017年证券公司短期公司债券（第二期）等两只债券提供转让服务有关事项的通知

各会员单位：

招商证券股份有限公司2017年证券公司短期公司债券（第二期）、招商证券股份有限公司2017年证券公司短期公司债券（第三期）定于2017年4月13日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、招商证券股份有限公司2017年证券公司短期公司债券（第二期）证券代码“117554”，证券简称“招商1702”，发行总额30亿元，票面利率4.48%，债券期限100日。

2、招商证券股份有限公司2017年证券公司短期公司债券（第三期）证券代码“117555”，证券简称“招商1703”，发行总额20亿元，票面利率4.6%，债券期限5个月。

深圳证券交易所
