# 深圳证券交易所关于山东丽鹏股份有限公司2017年面向合格投资者公开发行绿色公司债券（第一期）上市有关事项的通知

## 关于山东丽鹏股份有限公司2017年面向合格投资者公开发行绿色公司债券（第一期）上市有关事项的通知

各会员单位：

山东丽鹏股份有限公司2017年面向合格投资者公开发行绿色公司债券（第一期）定于2017年12月20日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

山东丽鹏股份有限公司2017年面向合格投资者公开发行绿色公司债券（第一期）证券代码“112623”，证券简称“17丽鹏G1”，发行总额2.5亿元，票面利率6.5%，债券期限5年,附第3年末发行人上调票面利率和投资者回售选择权。

特此通知

深圳证券交易所
