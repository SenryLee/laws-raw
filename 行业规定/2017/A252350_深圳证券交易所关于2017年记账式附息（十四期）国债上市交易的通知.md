# 深圳证券交易所关于2017年记账式附息（十四期）国债上市交易的通知

## 关于2017年记账式附息（十四期）国债上市交易的通知

各会员单位：

2017年记账式附息（十四期）国债已发行结束，根据财政部通知，本期债券于2017年7月17日起在本所上市交易。

本期债券为5年期固定利率附息式国债，证券编码“101714”，证券简称“国债1714”，票面利率3.47％，标准交易单位“10张”，2022年7月13日到期还本并支付最后一期利息。

特此通知
