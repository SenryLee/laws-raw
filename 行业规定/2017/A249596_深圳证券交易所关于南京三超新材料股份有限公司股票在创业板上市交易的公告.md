# 深圳证券交易所关于南京三超新材料股份有限公司股票在创业板上市交易的公告

## 关于南京三超新材料股份有限公司股票在创业板上市交易的公告

南京三超新材料股份有限公司人民币普通股股票将于2017年4月21日在本所创业板上市。证券简称为“三超新材”,证券代码为“300554”。公司人民币普通股股份总数为52,000,000股，其中首次公开发行的13,000,000股股票自上市之日起开始上市交易。
