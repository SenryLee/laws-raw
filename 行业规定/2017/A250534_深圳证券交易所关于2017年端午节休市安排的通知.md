# 深圳证券交易所关于2017年端午节休市安排的通知

## 关于2017年端午节休市安排的通知

各市场参与人：

根据《关于2017年部分节假日休市安排的通知》（深证会〔2016〕390号），现将2017年端午节休市有关安排通知如下。

一、休市安排

5月28日（星期日）至5月30日（星期二）休市，5月31日（星期三）起照常开市。5月27日（星期六）为周末休市。

二、节假日期间清算交收事宜按照中国证券登记结算有限责任公司的安排进行。

请各市场参与人据此安排好有关工作。

深圳证券交易所

2017年5月18日
