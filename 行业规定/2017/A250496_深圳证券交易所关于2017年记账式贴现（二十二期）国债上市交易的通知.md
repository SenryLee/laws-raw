# 深圳证券交易所关于2017年记账式贴现（二十二期）国债上市交易的通知

## 关于2017年记账式贴现（二十二期）国债上市交易的通知

各会员单位：

2017年记账式贴现（二十二期）国债已发行结束，根据财政部通知，本期债券于2017年5月17日起在本所上市交易。

本期债券为91日期贴现式国债，证券编码“108179”，证券简称“贴债1722”，标准交易单位“10张”，2017年8月14日到期按面值偿还。

特此通知

深圳证券交易所

二○一七年五月十五日
