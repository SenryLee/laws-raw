# 深圳证券交易所关于为东北证券股份有限公司2017年证券公司短期公司债券（第一期）等两只债券提供转让服务有关事项的通知

## 关于为东北证券股份有限公司2017年证券公司短期公司债券（第一期）等两只债券提供转让服务有关事项的通知

各会员单位：

东北证券股份有限公司2017年证券公司短期公司债券（第一期）、 招商证券股份有限公司2017年证券公司短期公司债券（第四期）（品种一）定于2017年4月28日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、东北证券股份有限公司2017年证券公司短期公司债券（第一期）证券代码“117556”，证券简称“东证1701”，发行总额16亿元，票面利率4.8%，债券期限179日。

2、招商证券股份有限公司2017年证券公司短期公司债券（第四期）（品种一）证券代码“117557”，证券简称“招商1704”，发行总额32.2亿元，票面利率4.8%，债券期限90日。
