# 上海证券交易所关于华泰紫金天天金交易型货币市场基金流动性服务商的公告

## 关于华泰紫金天天金交易型货币市场基金流动性服务商的公告

上证公告（基金）〔2017〕075号

为促进华泰紫金天天金交易型货币市场基金(以下简称"华泰天金")的市场流动性和平稳运行,根据《上海证券交易所上市基金流动性服务业务指引》的有关规定,经协商华泰证券（上海）资产管理有限公司,我所同意中国银河证券股份有限公司为华泰天金（511670）流动性服务商。

特此公告。

上海证券交易所

二〇一七年十一月十五日
