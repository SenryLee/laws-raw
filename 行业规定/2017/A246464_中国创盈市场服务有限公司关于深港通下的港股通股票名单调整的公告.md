# 中国创盈市场服务有限公司关于深港通下的港股通股票名单调整的公告

## 关于深港通下的港股通股票名单调整的公告

因中芯国际结束并行买卖合并股份，根据《深圳证券交易所深港通业务实施办法》的有关规定，深港通下的港股通股票名单发生调整并自今日起生效，相关调整信息如下：

|  |  |  |
| --- | --- | --- |
| 代码 | 简称 | 调整方向 |
| 02920 | 中芯国际（旧） | 调出 |
