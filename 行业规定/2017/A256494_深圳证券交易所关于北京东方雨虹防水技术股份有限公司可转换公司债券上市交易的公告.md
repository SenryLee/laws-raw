# 深圳证券交易所关于北京东方雨虹防水技术股份有限公司可转换公司债券上市交易的公告

## 关于北京东方雨虹防水技术股份有限公司可转换公司债券上市交易的公告

北京东方雨虹防水技术股份有限公司发行的1,840,000,000元可转换公司债券自2017年10月20日起在本所上市交易，证券简称为“雨虹转债”，证券代码为“128016”，上市数量1,840万张。

深圳证券交易所

二〇一七年十月十九日
