# 深圳证券交易所关于为郴州市百福投资集团有限公司2016年非公开发行公司债券（第一期）等七只债券提供转让服务有关事项的通知

## 关于为郴州市百福投资集团有限公司2016年非公开发行公司债券（第一期）等七只债券提供转让服务有关事项的通知

各会员单位：

郴州市百福投资集团有限公司2016年非公开发行公司债券（第一期）、镇江交通产业集团有限公司2016年非公开发行公司债券（第三期）、 绍兴市柯桥区城建投资开发集团有限公司2016年非公开发行公司债券（第一期）、 天津市宁河区兴宁建设投资集团有限公司2016年非公开发行公司债券（第一期）、金科地产集团股份有限公司2016年非公开发行公司债券（第二期）（品种一）、 金科地产集团股份有限公司2016年非公开发行公司债券（第二期）（品种二）、 金科地产集团股份有限公司2016年非公开发行公司债券（第二期）（品种三）定于2017年1月16日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、郴州市百福投资集团有限公司2016年非公开发行公司债券（第一期）证券代码“114021”，证券简称“16百福01”，发行总额23亿元，票面利率4.7%，债券期限6年，附第5年末发行人赎回选择权、发行人调整票面利率选择权和投资者回售选择权。

2、镇江交通产业集团有限公司2016年非公开发行公司债券（第三期）证券代码“114039”，证券简称“16镇交03”，发行总额25亿元，票面利率5.99%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

3、绍兴市柯桥区城建投资开发集团有限公司2016年非公开发行公司债券（第一期）证券代码“114052”，证券简称“16柯建01”，发行总额10亿元，票面利率3.88%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

4、天津市宁河区兴宁建设投资集团有限公司2016年非公开发行公司债券（第一期）证券代码“114071”，证券简称“16兴宁01”，发行总额10亿元，票面利率5.2%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

5、金科地产集团股份有限公司2016年非公开发行公司债券（第二期）（品种一）证券代码“118660”，证券简称“16金科03”，发行总额5.2亿元，票面利率6%，债券期限3年，附第1年末、第2年末发行人上调票面利率选择权和投资者回售选择权。

6、金科地产集团股份有限公司2016年非公开发行公司债券（第二期）（品种二）证券代码“118661”，证券简称“16金科04”，发行总额44亿元，票面利率6.7%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

7、金科地产集团股份有限公司2016年非公开发行公司债券（第二期）（品种三）证券代码“118662”，证券简称“16金科05”，发行总额4.8亿元，票面利率7.2%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。
