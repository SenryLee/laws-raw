# 深圳证券交易所关于第一创业摩根大通证券有限责任公司会员名称变更的公告

## 关于第一创业摩根大通证券有限责任公司会员名称变更的公告

原“第一创业摩根大通证券有限责任公司”在深圳证券交易所的会员名称变更为“第一创业证券承销保荐有限责任公司”。会员简称为：第一创业承销保荐，会员编码为：000690。
