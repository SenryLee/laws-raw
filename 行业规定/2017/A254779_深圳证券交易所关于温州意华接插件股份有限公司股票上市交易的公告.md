# 深圳证券交易所关于温州意华接插件股份有限公司股票上市交易的公告

## 关于温州意华接插件股份有限公司股票上市交易的公告

温州意华接插件股份有限公司人民币普通股股票将于2017年9月7日在本所上市。证券简称为“意华股份”,证券代码为“002897”。公司人民币普通股股份总数为106,670,000股，其中首次公开发行的26,670,000股股票自上市之日起开始上市交易。
