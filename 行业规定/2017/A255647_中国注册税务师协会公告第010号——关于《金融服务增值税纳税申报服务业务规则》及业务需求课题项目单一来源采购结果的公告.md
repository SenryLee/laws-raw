# 中国注册税务师协会公告第010号——关于《金融服务增值税纳税申报服务业务规则》及业务需求课题项目单一来源采购结果的公告

## 中国注册税务师协会公告

第010号

## 关于《金融服务增值税纳税申报服务业务规则》及业务需求课题项目单一来源采购结果的公告

为充分利用社会资源，提升税务师行业的执业水平，中税协于2017年2月28日发布了《金融服务增值税纳税申报服务业务规则》及业务需求编写课题项目的招标公告。截至投标申报截止日，此项目因投标单位数量未满足开标条件而流标。为提高课题项目采购效率和质量，根据《中华人民共和国政府采购法》和《中国注册税务师协会课题项目经费管理办法》有关规定，本课题项目采用单一来源采购方式。4月11日，我会根据课题项目要求通过谈判程序确定课题项目承担单位，现公告如下：

![1.png](https://zk-img.faxin.cn//Uedit_Upload/2017-09-26-11-23-19_9075377_1.png "1.png")

自本公告发布之日起五个工作日内，各有关当事人如有异议可以通过书面形式反馈至中税协，逾期将依法不予受理。公示期结束后，我会将与课题承担单位签订立项协议。
