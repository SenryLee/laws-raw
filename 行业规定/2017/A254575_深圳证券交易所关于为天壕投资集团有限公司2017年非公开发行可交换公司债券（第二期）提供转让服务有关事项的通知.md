# 深圳证券交易所关于为天壕投资集团有限公司2017年非公开发行可交换公司债券（第二期）提供转让服务有关事项的通知

## 关于为天壕投资集团有限公司2017年非公开发行可交换公司债券（第二期）提供转让服务有关事项的通知

各会员单位：

天壕投资集团有限公司2017年非公开发行可交换公司债券（第二期）定于2017年8月25日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

天壕投资集团有限公司2017年非公开发行可交换公司债券（第二期）证券代码“117089”，证券简称“17天壕E2”，发行总额1亿元，票面利率第一年1%、第二年2%、第三年3%，债券期限3年，附换股价格向下修正条款、发行人赎回条款和投资者回售条款。

深圳证券交易所

二○一七年八月二十三日
