# 深圳证券交易所关于江苏张家港农村商业银行股份有限公司股票上市交易的公告

## 关于江苏张家港农村商业银行股份有限公司股票上市交易的公告

江苏张家港农村商业银行股份有限公司人民币普通股股票将于2017年1月24日在本所上市。证券简称为“张家港行”,证券代码为“002839”。公司人民币普通股股份总数为1,807,526,665股，其中首次公开发行的180,760,000股股票自上市之日起开始上市交易。
