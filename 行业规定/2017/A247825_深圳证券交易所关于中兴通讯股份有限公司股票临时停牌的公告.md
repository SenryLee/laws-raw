# 深圳证券交易所关于中兴通讯股份有限公司股票临时停牌的公告

## 关于中兴通讯股份有限公司股票临时停牌的公告

因公司发生受到处罚的重大无先例事项，为保障投资者权益，充分与投资者进行沟通，经公司申请，公司股票（证券简称：中兴通讯，证券代码：000063）将于2017年3月8日开市起临时停牌，待公司充分与投资者沟通并刊登相关公告后复牌。

深圳证券交易所
