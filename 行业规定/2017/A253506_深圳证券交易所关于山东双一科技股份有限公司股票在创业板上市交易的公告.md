# 深圳证券交易所关于山东双一科技股份有限公司股票在创业板上市交易的公告

## 关于山东双一科技股份有限公司股票在创业板上市交易的公告

山东双一科技股份有限公司人民币普通股股票将于2017年8月8日在本所创业板上市。证券简称为“双一科技”,证券代码为“300690”。公司人民币普通股股份总数为69,340,000股，其中首次公开发行的17,340,000股股票自上市之日起开始上市交易。
