# 深圳证券交易所关于为“丰信2017年第一期资产支持专项计划”提供转让服务的公告

## 关于为“丰信2017年第一期资产支持专项计划”提供转让服务的公告

各相关单位：

根据上海东方证券资产管理有限公司申请，本所将自2017年10月20日起在综合协议交易平台为“丰信2017年第一期资产支持专项计划”（以下简称“丰信2017年第一期”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“丰信2017年第一期”的转让业务。

二、“丰信2017年第一期”设立日期为2017年8月22日。优先级资产支持证券如下：证券简称“17丰信1A”，证券代码为“116639”，到期日为2023年9月20日，还本付息方式为循环期内按半年付息，摊还期内按季付息和过手摊还本金。次优先级资产支持证券如下：证券简称“17丰信1B”，证券代码为“116640”，到期日为2023年9月20日，还本付息方式为循环期内按半年付息，摊还期内按季付息和过手摊还本金。

三、“17丰信1A”的单笔成交申报最低数量为10000份，“17丰信1B”的单笔成交申报最低数量为10000份。

四、对首次参加“丰信2017年第一期”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“丰信2017年第一期”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
