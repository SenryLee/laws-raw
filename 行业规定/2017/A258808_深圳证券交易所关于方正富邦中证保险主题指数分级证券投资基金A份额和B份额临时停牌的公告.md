# 深圳证券交易所关于方正富邦中证保险主题指数分级证券投资基金A份额和B份额临时停牌的公告

## 关于方正富邦中证保险主题指数分级证券投资基金A份额和B份额临时停牌的公告

因方正富邦中证保险主题指数分级证券投资基金2017年12月18日基金净值计算并披露错误，根据本所有关业务规则，经方正富邦基金管理有限公司申请，方正富邦中证保险主题指数分级证券投资基金A份额（简称：保险A、代码：150329）和B份额（简称：保险B、代码：150330）于2017年12月19日11:06至收市实施临时停牌，特此公告。

深圳证券交易所
