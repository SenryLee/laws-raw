# 中证机构间报价系统股份有限公司关于发布《机构间私募产品报价与服务系统私募产品注册规则（试行）》的通知

## 关于发布《机构间私募产品报价与服务系统私募产品注册规则（试行）》的通知

为规范机构间私募产品报价与服务系统私募产品的注册和管理，维护报价系统运行秩序，中证机构间报价系统股份有限公司制定了《机构间私募产品报价与服务系统私募产品注册规则（试行）》，并经中国证券业协会同意，现予正式发布，自发布之日起实施。

特此通知。

中证机构间报价系统股份有限公司

二〇一七年七月二十六日
