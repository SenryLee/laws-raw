# 深圳证券交易所关于2017年贵州省政府一般债券（一期）上市交易的通知

## 关于2017年贵州省政府一般债券（一期）上市交易的通知

各会员单位：

2017年贵州省政府一般债券（一期）已发行结束，根据财政部通知，本期债券于2017年3月28日起在本所上市交易。

本期债券为3年期固定利率附息式国债（地方政府债），证券编码“107564”，证券简称“贵州1701”，票面利率3.15％，标准交易单位“10张”，2020年3月24日到期还本并支付最后一期利息。

特此通知
