# 深圳证券交易所关于为青州市瑞通投资发展有限公司2017年非公开发行公司债券（第一期）等三只债券提供转让服务有关事项的通知

## 关于为青州市瑞通投资发展有限公司2017年非公开发行公司债券（第一期）等三只债券提供转让服务有关事项的通知

各会员单位：

青州市瑞通投资发展有限公司2017年非公开发行公司债券（第一期）、 海安县城建开发投资有限责任公司2017年非公开发行公司债券（第三期）、蚌埠投资集团有限公司2017年非公开发行公司债券（第一期）定于2017年9月18日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、青州市瑞通投资发展有限公司2017年非公开发行公司债券（第一期）证券代码“114186”，证券简称“17瑞通01”，发行总额5亿元，票面利率7.3%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、海安县城建开发投资有限责任公司2017年非公开发行公司债券（第三期）证券代码“114195”，证券简称“17海发03”，发行总额3.4亿元，票面利率7%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

3、蚌埠投资集团有限公司2017年非公开发行公司债券（第一期）证券代码“114197”，证券简称“17蚌资01”，发行总额5亿元，票面利率6.38%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年九月十四日
