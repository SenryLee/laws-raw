# 深圳证券交易所关于株洲飞鹿高新材料技术股份有限公司股票在创业板上市交易的公告

## 关于株洲飞鹿高新材料技术股份有限公司股票在创业板上市交易的公告

株洲飞鹿高新材料技术股份有限公司人民币普通股股票将于2017年6月13日在本所创业板上市。证券简称为“飞鹿股份”,证券代码为“300665”。公司人民币普通股股份总数为76,000,000股，其中首次公开发行的19,000,000股股票自上市之日起开始上市交易。
