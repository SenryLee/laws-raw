# 深圳证券交易所关于2017年记账式贴现（十二期）国债上市交易的通知

## 关于2017年记账式贴现（十二期）国债上市交易的通知

各会员单位：

2017年记账式贴现（十二期）国债已发行结束，根据财政部通知，本期债券于2017年3月15日起在本所上市交易。

本期债券为182日期贴现式国债，证券编码“108167”，证券简称“贴债1712”，标准交易单位“10张”，2017年9月11日到期按面值偿还。

特此通知

深圳证券交易所

二○一七年三月十三日
