# 深圳证券交易所关于华西证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等四只债券上市有关事项的通知

## 关于华西证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等四只债券上市有关事项的通知

各会员单位：

华西证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,国信证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,广发证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,浙江昆仑控股集团有限公司2017年面向合格投资者公开发行公司债券（第一期）定于2017年6月2日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、华西证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112513”，证券简称“17华股01”，发行总额13亿元，票面利率4.75%，债券期限5年,附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、国信证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112516”，证券简称“17国信01”，发行总额50亿元，票面利率4.39%，债券期限3年。

3、广发证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112520”，证券简称“17广发01”，发行总额60亿元，票面利率4.6%，债券期限3年。

4、浙江昆仑控股集团有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112521”，证券简称“17昆仑01”，发行总额4亿元，票面利率7.8%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。
