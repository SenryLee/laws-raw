# 深圳证券交易所关于深圳同兴达科技股份有限公司股票上市交易的公告

## 关于深圳同兴达科技股份有限公司股票上市交易的公告

深圳同兴达科技股份有限公司人民币普通股股票将于2017年1月25日在本所上市。证券简称为“同兴达”,证券代码为“002845”。公司人民币普通股股份总数为96,000,000股，其中首次公开发行的24,000,000股股票自上市之日起开始上市交易。
