# 深圳证券交易所关于2017年浙江省台州市土地储备专项债券（一期）——2017年浙江省政府专项债券（二十一期）上市交易的通知

## 关于2017年浙江省台州市土地储备专项债券（一期）——2017年浙江省政府专项债券（二十一期）上市交易的通知

各市场参与人：

2017年浙江省台州市土地储备专项债券（一期）——2017年浙江省政府专项债券（二十一期）已发行结束，根据财政部有关规定，本期债券于2017年9月5日起在本所上市交易。

本期债券为5年期固定利率附息式国债（地方政府债），证券编码“107949”，证券简称“浙江1728”，票面利率3.77％，标准交易单位“10张”，2022年9月1日到期还本并支付最后一期利息。
