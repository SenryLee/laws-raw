# 中国创盈市场服务有限公司关于2017年底及2018年深港通下的港股通交易日安排的通知

## 关于2017年底及2018年深港通下的港股通交易日安排的通知

各市场参与人：

根据《深圳证券交易所深港通业务实施办法》有关规定和深圳证券交易所（以下简称“深交所”）、香港联合交易所有限公司2017年、2018年的交易日安排，中国创盈市场服务有限公司（以下简称“本公司”）现将2017年底及2018年全年深港通下的港股通（以下简称“港股通”）交易日安排通知如下：

一、2017年12月28日（星期四）至2017年12月29日（星期五），本公司照常提供港股通服务。

二、2018年1月1日（星期一）至2018年12月26日（星期三），除下列节假日期间特别安排外，本公司将在深交所2018年A股交易日提供港股通服务：

（一）元旦：1月1日（星期一）不提供港股通服务，1月2日（星期二）起照常开通港股通服务。

（二）春节：2月13日（星期二）至2月21日（星期三）不提供港股通服务，2月22日（星期四）起照常开通港股通服务。另外，2月11日（星期日）、2月24日（星期六）为周末休市。

（三）香港耶稣受难节、复活节：3月30日（星期五）至4月2日（星期一）不提供港股通服务。

（四）清明节：4月3日（星期二）至4月7日（星期六）不提供港股通服务，4月9日（星期一）起照常开通港股通服务。另外，4月8日（星期日）为周末休市。

（五）劳动节：4月26日（星期四）至5月1日（星期二）不提供港股通服务，5月2日（星期三）起照常开通港股通服务。

（六）香港佛诞日：5月22日（星期二）不提供港股通服务，5月23日（星期三）起照常开通港股通服务。

（七）端午节：6月16日（星期六）至6月18日（星期一）不提供港股通服务，6月19日（星期二）起照常开通港股通服务。

（八）香港特别行政区成立纪念日翌日：7月2日（星期一）不提供港股通服务，7月3日（星期二）起照常开通港股通服务。

（九）中秋节：9月20日（星期四）至9月25日（星期二）不提供港股通服务，9月26日（星期三）照常开通港股通服务。

（十）国庆节：9月27日（星期四）至10月7日（星期日）不提供港股通服务，10月8日（星期一）起照常开通港股通服务。

（十一）香港重阳节：10月17日（星期三）不提供港股通服务，10月18日（星期四）起照常开通港股通服务。

（十二）香港圣诞节：12月24日下午（星期一）至12月26日（星期三）不提供港股通服务。

三、2018年12月27日（星期四）至12月28日（星期五）、12月31日（星期一）是否提供港股通服务，将待中国证监会关于2019年节假日放假和休市安排确定后由本公司另行通知。

四、港股通交易的清算交收事宜，根据中国证券登记结算有限责任公司的安排进行。

特此通知

中国创盈市场服务有限公司
