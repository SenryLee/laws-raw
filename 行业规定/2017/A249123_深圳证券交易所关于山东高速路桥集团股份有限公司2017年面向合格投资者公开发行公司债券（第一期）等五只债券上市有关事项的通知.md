# 深圳证券交易所关于山东高速路桥集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等五只债券上市有关事项的通知

## 关于山东高速路桥集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等五只债券上市有关事项的通知

各会员单位：

山东高速路桥集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,东江环保股份有限公司2017年面向合格投资者公开发行绿色公司债券（第一期）,四川科伦药业股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,山西证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）(品种一),山西证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）(品种二)定于2017年4月12日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、山东高速路桥集团股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112500”，证券简称“17山路01”，发行总额5亿元，票面利率5.05%，债券期限5年,附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、东江环保股份有限公司2017年面向合格投资者公开发行绿色公司债券（第一期）证券代码“112501”，证券简称“17东江G1”，发行总额6亿元，票面利率4.9%，债券期限3年，第2年末发行人上调票面利率选择权和投资者回售选择权。

3、四川科伦药业股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112502”，证券简称“17科伦01”，发行总额8亿元，票面利率4.89%，债券期限5年，第3年末附发行人上调票面利率选择权及投资者回售选择权。

4、山西证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）(品种一)证券代码“112503”，证券简称“17山证01”，发行总额15亿元，票面利率4.76%，债券期限3年。

5、山西证券股份有限公司2017年面向合格投资者公开发行公司债券（第一期）(品种二)证券代码“112504”，证券简称“17山证02”，发行总额5亿元，票面利率5.1%，债券期限5年。
