# 深圳证券交易所关于为珠海和佳医疗设备股份有限公司2017年非公开发行公司债券（第二期）等三只债券提供转让服务有关事项的通知

## 关于为珠海和佳医疗设备股份有限公司2017年非公开发行公司债券（第二期）等三只债券提供转让服务有关事项的通知

各会员单位：

珠海和佳医疗设备股份有限公司2017年非公开发行公司债券（第二期）、 淮安市国有联合投资发展集团有限公司2017年非公开发行公司债券（第二期）、常德市城市建设投资集团有限公司2017年非公开发行公司债券（第一期）定于2017年6月29日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、珠海和佳医疗设备股份有限公司2017年非公开发行公司债券（第二期）证券代码“114113”，证券简称“17和佳02”，发行总额0.6亿元，票面利率5%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、淮安市国有联合投资发展集团有限公司2017年非公开发行公司债券（第二期）证券代码“114168”，证券简称“17淮发02”，发行总额12亿元，票面利率5.8%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

3、常德市城市建设投资集团有限公司2017年非公开发行公司债券（第一期）证券代码“114173”，证券简称“17常德01”，发行总额6.5亿元，票面利率5.95%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年六月二十七日
