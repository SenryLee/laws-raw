# 深圳证券交易所关于深南电路股份有限公司股票上市交易的公告

## 关于深南电路股份有限公司股票上市交易的公告

深南电路股份有限公司人民币普通股股票将于2017年12月13日在本所上市。证券简称为“深南电路”,证券代码为“002916”。公司人民币普通股股份总数为280,000,000股，其中首次公开发行的70,000,000股股票自上市之日起开始上市交易。
