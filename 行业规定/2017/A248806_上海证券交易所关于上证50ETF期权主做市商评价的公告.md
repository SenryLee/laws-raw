# 上海证券交易所关于上证50ETF期权主做市商评价的公告

## 关于上证50ETF期权主做市商评价的公告

上证公告〔2017〕8号

根据《上海证券交易所股票期权试点做市商业务指引》的相关规定，上海证券交易所上证50ETF期权主做市商在2017年2月21日至2017年3月20日期间的评价情况如下：光大证券股份有限公司、广发证券股份有限公司、国泰君安证券股份有限公司、中泰证券股份有限公司、中信证券股份有限公司等5家证券公司的评价结果为AA，国信证券股份有限公司、海通证券股份有限公司、华泰证券股份有限公司、招商证券股份有限公司、中信建投证券股份有限公司等5家证券公司的评价结果为A。
