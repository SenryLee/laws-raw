# 深圳证券交易所关于2017年青海省政府专项债券（十期）上市交易的通知

## 关于2017年青海省政府专项债券（十期）上市交易的通知

各市场参与人：

2017年青海省政府专项债券（十期）已发行结束，根据财政部有关规定，本期债券于2017年10月17日起在本所上市交易。

本期债券为5年期固定利率附息式国债（地方政府债），证券编码“106083”，证券简称“青海1721”，票面利率3.95％，标准交易单位“10张”，2022年10月13日到期还本并支付最后一期利息。
