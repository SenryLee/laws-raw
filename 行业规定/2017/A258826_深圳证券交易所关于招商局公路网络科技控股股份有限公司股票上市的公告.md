# 深圳证券交易所关于招商局公路网络科技控股股份有限公司股票上市的公告

## 关于招商局公路网络科技控股股份有限公司股票上市的公告

招商局公路网络科技控股股份有限公司人民币普通股股票将于2017年12月25日起在本所上市。证券简称为“招商公路”，证券代码为“001965”。公司人民币普通股股份总数为6,178,211,497股，其中本次公开发行554,832,864股。本次公开发行的股票中554,813,630股自上市之日起开始上市交易。
