# 深圳证券交易所关于广州惠威电声科技股份有限公司股票上市交易的公告

## 关于广州惠威电声科技股份有限公司股票上市交易的公告

广州惠威电声科技股份有限公司人民币普通股股票将于2017年7月21日在本所上市。证券简称为“惠威科技”,证券代码为“002888”。公司人民币普通股股份总数为83,117,600股，其中首次公开发行的20,780,000股股票自上市之日起开始上市交易。
