# 深圳证券交易所关于广东凌霄泵业股份有限公司股票上市交易的公告

## 关于广东凌霄泵业股份有限公司股票上市交易的公告

广东凌霄泵业股份有限公司人民币普通股股票将于2017年7月11日在本所上市。证券简称为“凌霄泵业”,证券代码为“002884”。公司人民币普通股股份总数为77,470,000股，其中首次公开发行的19,370,000股股票自上市之日起开始上市交易。
