# 深圳证券交易所关于2017年四川省政府专项债券（十六期）上市交易的通知

## 关于2017年四川省政府专项债券（十六期）上市交易的通知

各市场参与人：

2017年四川省政府专项债券（十六期）已发行结束，根据财政部有关规定，本期债券于2017年10月26日起在本所上市交易。

本期债券为10年期固定利率附息式国债（地方政府债），证券编码“106140”，证券简称“四川1736”，票面利率4.13％，标准交易单位“10张”，2027年10月24日到期还本并支付最后一期利息。

特此通知

深圳证券交易所
