# 深圳证券交易所关于富国汇利回报分级债券型证券投资基金份额终止上市交易的通知

## 关于富国汇利回报分级债券型证券投资基金份额终止上市交易的通知

各会员单位：

富国基金管理有限公司以通讯方式召开富国汇利回报分级债券型证券投资基金份额持有人大会，于2017年12月4日审议通过了《关于富国汇利回报分级债券型证券投资基金变更基金合同等有关事项的议案》（以下简称“议案”）。根据议案，《富国汇利回报分级债券型证券投资基金基金合同》变更后不再保留汇利A和汇利B份额，基金管理人将向深圳证券交易所申请汇利A和汇利B份额的终止上市。富国基金管理有限公司已向本所提交关于汇利A、汇利B终止上市的申请。

根据《深圳证券交易所证券投资基金上市规则》第二十三条第一款第（三）项的相关规定，经审查，本所决定富国汇利回报分级债券型证券投资基金之A份额（证券简称：汇利A，证券代码：150020）和B份额（证券简称：汇利B，证券代码：150021）自2017年12月11日起终止上市交易。

特此通知
