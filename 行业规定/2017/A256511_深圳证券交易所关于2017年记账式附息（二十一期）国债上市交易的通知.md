# 深圳证券交易所关于2017年记账式附息（二十一期）国债上市交易的通知

## 关于2017年记账式附息（二十一期）国债上市交易的通知

各市场参与人：

2017年记账式附息（二十一期）国债已发行结束，根据财政部有关规定，本期债券于2017年10月23日起在本所上市交易。

本期债券为5年期固定利率附息式国债，证券编码“101721”，证券简称“国债1721”，票面利率3.73％，标准交易单位“10张”，2022年10月19日到期还本并支付最后一期利息。

特此通知

深圳证券交易所
