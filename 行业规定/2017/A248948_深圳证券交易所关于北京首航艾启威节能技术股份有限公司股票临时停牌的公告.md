# 深圳证券交易所关于北京首航艾启威节能技术股份有限公司股票临时停牌的公告

## 关于北京首航艾启威节能技术股份有限公司股票临时停牌的公告

由于北京首航艾启威节能技术股份有限公司于2017年4月7日披露的《关于与寰慧科技集团有限公司签署合资成立储能技术公司合作框架协议公告》存在内容不够完整，可能误导投资者的投资决策，根据本所《股票上市规则》和《中小企业板上市公司规范运作指引》的有关规定，经公司申请，公司股票（证券简称：首航节能，证券代码：002665）于2017年4月7日开市起临时停牌，待公司通过指定媒体披露补充公告后复牌，敬请投资者密切关注。

深圳证券交易所

2017年4月7日
