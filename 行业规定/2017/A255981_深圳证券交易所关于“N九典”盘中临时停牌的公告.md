# 深圳证券交易所关于“N九典”盘中临时停牌的公告

## 关于“N九典”盘中临时停牌的公告

“N九典”（300705）盘中成交价较开盘价首次上涨达到或超过10%，根据《关于完善首次公开发行股票上市首日交易机制有关事项的通知》等有关规定，本所自今日09时33分11秒起对该股实施临时停牌，于10时03分12秒复牌。

本所郑重提示广大投资者注意投资风险，理性投资。

特此公告

深圳证券交易所

2017年10月10日
