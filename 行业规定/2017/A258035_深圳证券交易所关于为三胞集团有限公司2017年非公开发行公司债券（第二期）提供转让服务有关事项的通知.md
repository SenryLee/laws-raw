# 深圳证券交易所关于为三胞集团有限公司2017年非公开发行公司债券（第二期）提供转让服务有关事项的通知

## 关于为三胞集团有限公司2017年非公开发行公司债券（第二期）提供转让服务有关事项的通知

各会员单位：

三胞集团有限公司2017年非公开发行公司债券（第二期）定于2017年11月29日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

三胞集团有限公司2017年非公开发行公司债券（第二期）证券代码“114224”，证券简称“17三胞02”，发行总额2亿元，票面利率7.5%，债券期限3年，附第1年末、第2年末发行人调整票面利率选择权以及投资者回售选择权。

深圳证券交易所

二○一七年十一月二十七日
