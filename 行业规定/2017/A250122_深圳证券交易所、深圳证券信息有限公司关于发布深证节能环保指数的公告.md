# 深圳证券交易所、深圳证券信息有限公司关于发布深证节能环保指数的公告

## 关于发布深证节能环保指数的公告

为反映深市节能环保产业相关上市公司的整体表现，向投资者提供更丰富的指数化投资标的，深圳证券交易所与深圳证券信息有限公司定于2017年4月28日发布深证节能环保指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399695 | 深证节能环保指数 | 深证节能 | 2010年6月30日 | 1000 |

深证节能环保指数以深市A股市场节能环保产业相关上市公司为备选范围，采用日均总市值比重、日均自由流通市值比重与日均成交金额比重1:1:1进行加权排序，结合上市公司基本面情况，选取排名靠前的100只股票构成样本股，数量不足则按实际数量选入。

指数采用等权重方式进行加权计算，每年1月与7月进行样本股及权重因子的定期调整。

深证节能环保指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关深证节能环保指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
