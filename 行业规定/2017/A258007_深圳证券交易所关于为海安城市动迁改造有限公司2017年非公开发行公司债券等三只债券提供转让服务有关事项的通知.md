# 深圳证券交易所关于为海安城市动迁改造有限公司2017年非公开发行公司债券等三只债券提供转让服务有关事项的通知

## 关于为海安城市动迁改造有限公司2017年非公开发行公司债券等三只债券提供转让服务有关事项的通知

各会员单位：

海安城市动迁改造有限公司2017年非公开发行公司债券、 腾邦集团有限公司2017年面向合格投资者非公开发行公司债券（第一期）、海安城市动迁改造有限公司2017年非公开发行公司债券（第二期）定于2017年11月27日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、海安城市动迁改造有限公司2017年非公开发行公司债券证券代码“114176”，证券简称“17海动迁”，发行总额4亿元，票面利率6.8%，债券期限5年，附第三年末发行人上调票面利率选择权和投资者回售选择权。

2、腾邦集团有限公司2017年面向合格投资者非公开发行公司债券（第一期）证券代码“114240”，证券简称“17腾邦02”，发行总额2亿元，票面利率7.5%，债券期限2年。

3、海安城市动迁改造有限公司2017年非公开发行公司债券（第二期）证券代码“114246”，证券简称“17动迁02”，发行总额4亿元，票面利率6.8%，债券期限5年，附第三年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年十一月二十三日
