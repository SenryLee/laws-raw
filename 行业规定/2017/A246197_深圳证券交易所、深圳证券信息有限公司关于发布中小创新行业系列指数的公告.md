# 深圳证券交易所、深圳证券信息有限公司关于发布中小创新行业系列指数的公告

## 关于发布中小创新行业系列指数的公告

为反映深圳市场中小市值与创业创新企业的行业特征，丰富深圳市场行业指数体系，深圳证券交易所与深圳证券信息有限公司定于2017年1月10日发布中小创新行业系列指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 价格指数  代码 | 指数名称 | 指数简称 | 基日 | 基日  点位 |
| CN5122 | 中小创新能源行业指数 | 中小能源 | 2011年12月30日 | 1000 |
| CN5123 | 中小创新原材料行业指数 | 中小材料 | 2011年12月30日 | 1000 |
| CN5124 | 中小创新工业行业指数 | 中小工业 | 2011年12月30日 | 1000 |
| CN5125 | 中小创新可选消费行业指数 | 中小可选 | 2011年12月30日 | 1000 |
| CN5126 | 中小创新主要消费行业指数 | 中小消费 | 2011年12月30日 | 1000 |
| CN5127 | 中小创新医药卫生行业指数 | 中小医药 | 2011年12月30日 | 1000 |
| CN5128 | 中小创新金融地产行业指数 | 中小金融 | 2011年12月30日 | 1000 |
| CN5129 | 中小创新信息技术行业指数 | 中小信息 | 2011年12月30日 | 1000 |
| CN5130 | 中小创新电信业务行业指数 | 中小电信 | 2011年12月30日 | 1000 |
| CN5131 | 中小创新公用事业行业指数 | 中小公用 | 2011年12月30日 | 1000 |

中小创新行业系列指数以中小创新指数样本股为样本空间，将中小创新样本股按国证行业分类标准进行分类，进入各自行业的全部股票形成相应行业指数的样本股。指数采用自由流通市值加权计算，每年1月和7月的第一个交易日进行样本股定期调整。

中小创新行业系列指数包括纯价格指数和全收益指数，纯价格指数和全收益指数均通过国证指数网（www.cnindex.com.cn）发布收盘行情数据。

有关中小创新行业系列指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
