# 中国注册税务师协会办公室关于印发《中国注册税务师协会2017年税务师继续教育培训计划》的通知

## 关于印发《中国注册税务师协会2017年税务师继续教育培训计划》的通知

中税协发〔2017〕010号

各省、自治区、直辖市和计划单列市注册税务师协会：

经会长专题会批准，现将教育培训委员会审议通过的《中国注册税务师协会2017年税务师继续教育培训计划》印发你们，请各地方税协做好相关宣传和组织工作。

附件：《中国注册税务师协会2017年税务师继续教育培训计划》

中国注册税务师协会办公室

2017年3月10日
