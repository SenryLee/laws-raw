# 中国创盈市场服务有限公司关于深港通下的港股通股票名单调整的公告

## 关于深港通下的港股通股票名单调整的公告

因中国天然气（代码00931）实施股份合并，根据《深圳证券交易所深港通业务实施办法》的有关规定，港股通股票名单发生调整并自今日起生效，相关调整信息如下：

|  |  |  |
| --- | --- | --- |
| 代码 | 简称 | 调整方向 |
| 02981 | 中国天然气 | 调入 |
| 00931 | 中国天然气 | 调出 |
