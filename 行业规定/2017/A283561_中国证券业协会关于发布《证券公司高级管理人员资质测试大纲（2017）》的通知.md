# 中国证券业协会关于发布《证券公司高级管理人员资质测试大纲（2017）》的通知

## 关于发布《证券公司高级管理人员资质测试大纲（2017）》的通知

中证协发〔2017〕143号

各会员单位：

为持续做好证券公司高级管理人员资质测试工作，根据近年来证券公司监管法律法规的变化情况，我会制定了《证券公司高级管理人员资质测试大纲（2017）》，现予发布，自2017年8月1日开始实施。

附件：《证券公司高级管理人员资质测试大纲（2017）》

中国证券业协会

2017年6月12日
