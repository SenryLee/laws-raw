# 深圳证券交易所关于发布《深圳证券交易所资产支持证券挂牌条件确认业务指引》的通知

## 关于发布《深圳证券交易所资产支持证券挂牌条件确认业务指引》的通知

各市场参与人：

为规范资产支持证券挂牌条件确认行为，进一步提高评审效率，本所对《深圳证券交易所资产支持证券挂牌条件确认业务指引》进行了修订。现予以发布，并自发布之日起施行。
