# 深圳证券交易所关于金龙羽集团股份有限公司股票上市交易的公告

## 关于金龙羽集团股份有限公司股票上市交易的公告

金龙羽集团股份有限公司人民币普通股股票将于2017年7月17日在本所上市。证券简称为“金龙羽”,证券代码为“002882”。公司人民币普通股股份总数为425,000,000股，其中首次公开发行的80,000,000股股票自上市之日起开始上市交易。
