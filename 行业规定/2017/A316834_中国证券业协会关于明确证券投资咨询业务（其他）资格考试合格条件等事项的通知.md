# 中国证券业协会关于明确证券投资咨询业务（其他）资格考试合格条件等事项的通知

## 关于明确证券投资咨询业务（其他）资格考试合格条件等事项的通知

中证协发〔2017〕166号

各证券资信评级机构：

2015年我会发布了《关于证券业从业人员资格考试测试制度改革有关问题的通知》（中证协发[2015]147号，简称147号文），对从业人员资格考试进行调整，调整前证券投资咨询业务（其他）资格考试由《证券市场基础知识》和《证券投资分析》组成，现就调整后的资格考试合格条件及执业证书申请条件通知如下：

一、关于资格考试合格条件

除入门资格考试外，还须通过147号文实施前的《证券投资分析》或147号文实施后的《发布证券研究报告业务》、《证券投资顾问业务》任一门专业科目，认定为证券投资咨询业务（其他）资格考试合格。

二、关于执业证书申请条件

根据《中华人民共和国证券法》、《证券、期货投资咨询管理暂行办法》、《证券业从业人员资格管理办法》、《证券业从业人员资格管理实施细则（试行）》的相关规定，申请证券投资咨询业务（其他）执业证书的，除资格考试合格外，还须满足以下条件：

（一）具有中华人民共和国国籍；

（二）大学本科以上学历；

（三）具有完全民事行为能力；

（四）具有从事证券业务2年以上的经历；

（五）已被机构聘用；

（六）未受过刑事处罚或与证券业务有关的严重行政处罚；

（七）不存在《中华人民共和国证券法》第一百三十二条规定的情形；

（八）未被中国证监会认定为证券市场禁入者，或者已过禁入期的；

（九）法律、行政法规和中国证监会规定的其他条件。

中国证券业协会
