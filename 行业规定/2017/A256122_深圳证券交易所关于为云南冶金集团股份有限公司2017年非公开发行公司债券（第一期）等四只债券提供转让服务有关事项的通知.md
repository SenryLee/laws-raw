# 深圳证券交易所关于为云南冶金集团股份有限公司2017年非公开发行公司债券（第一期）等四只债券提供转让服务有关事项的通知

## 关于为云南冶金集团股份有限公司2017年非公开发行公司债券（第一期）等四只债券提供转让服务有关事项的通知

各会员单位：

云南冶金集团股份有限公司2017年非公开发行公司债券（第一期）、 新疆机械研究院股份有限公司2017年非公开发行公司债券（第一期）、远东国际租赁有限公司2017年非公开发行公司债券（第三期）、 广东海印集团股份有限公司2017年非公开发行公司债券（第一期）定于2017年10月13日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、云南冶金集团股份有限公司2017年非公开发行公司债券（第一期）证券代码“114092”，证券简称“17云冶01”，发行总额10亿元，票面利率6.7%，债券期限3年，附第1年末、第2年末发行人调整票面利率选择权及投资者回售选择权。

2、新疆机械研究院股份有限公司2017年非公开发行公司债券（第一期）证券代码“114203”，证券简称“17新研01”，发行总额4亿元，票面利率8%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

3、远东国际租赁有限公司2017年非公开发行公司债券（第三期）证券代码“114207”，证券简称“17远东三”，发行总额12亿元，票面利率5.6%，债券期限5年，附第3年末发行人调整票面利率选择权及投资者回售选择权。

4、广东海印集团股份有限公司2017年非公开发行公司债券（第一期）证券代码“114216”，证券简称“17海印01”，发行总额4.5亿元，票面利率7%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所
