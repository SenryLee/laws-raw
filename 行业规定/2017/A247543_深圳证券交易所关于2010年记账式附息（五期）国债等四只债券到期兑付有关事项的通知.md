# 深圳证券交易所关于2010年记账式附息（五期）国债等四只债券到期兑付有关事项的通知

## 关于2010年记账式附息（五期）国债等四只债券到期兑付有关事项的通知

各会员单位：

2010年记账式附息（五期）国债、2014年记账式附息（四期）国债、2016年记账式贴现（四十二期）国债、2016年记账式贴现（五十四期）国债将于2017年3月13日到期兑付。为做好上述债券的本息兑付工作，现将有关事项通知如下：

一、2010年记账式附息（五期）国债证券代码为“101005”，证券简称为“国债1005”，是2010年3月11日发行的7年期债券，票面利率为2.92%，每年支付1次利息，每百元面值债券兑付可获本息102.92元。

二、2014年记账式附息（四期）国债证券代码为“101404”，证券简称为“国债1404”，是2014年3月13日发行的3年期债券，票面利率为3.66%，每年支付1次利息，每百元面值债券兑付可获本息103.66元。

三、2016年记账式贴现（四十二期）国债证券代码为“108139”，证券简称为“贴债1642”，是2016年9月12日发行的182日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

四、2016年记账式贴现（五十四期）国债证券代码为“108152”，证券简称为“贴债1654”，是2016年12月12日发行的91日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

五、本所从2017年3月3日起停办上述债券的转托管及调帐业务。

六、上述债券兑付债权登记日为2017年3月8日，凡于当日收市后持有上述债券的投资者，享有获得本次兑付款项的权利。2017年3月9日上述债券摘牌。

七、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的上述债券兑付款项后，将其划入各证券商的清算备付金帐户，并由证券商将兑付资金及时划入各投资者的资金帐户。
