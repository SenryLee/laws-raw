# 深圳证券交易所关于经纬纺织机械股份有限公司股票临时停牌的公告

## 关于经纬纺织机械股份有限公司股票临时停牌的公告

因经纬纺织机械股份有限公司(以下简称“公司”）拟披露附属公司与某上市公司的实际控制人签署合作协议，为保证公平信息披露，维护投资者利益，避免公司股价异常波动，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：经纬纺机，证券代码：000666）自2017年1月23日开市起停牌一天，待公司通过指定媒体披露相关公告后复牌。
