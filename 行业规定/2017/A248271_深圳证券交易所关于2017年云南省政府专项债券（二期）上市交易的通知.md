# 深圳证券交易所关于2017年云南省政府专项债券（二期）上市交易的通知

## 关于2017年云南省政府专项债券（二期）上市交易的通知

各会员单位：

2017年云南省政府专项债券（二期）已发行结束，根据财政部通知，本期债券于2017年3月22日起在本所上市交易。

本期债券为10年期固定利率附息式国债（地方政府债），证券编码“107550”，证券简称“云南1704”，票面利率3.87％，标准交易单位“10张”，2027年3月20日到期还本并支付最后一期利息。

特此通知
