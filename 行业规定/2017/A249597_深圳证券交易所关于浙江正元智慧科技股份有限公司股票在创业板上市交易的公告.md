# 深圳证券交易所关于浙江正元智慧科技股份有限公司股票在创业板上市交易的公告

## 关于浙江正元智慧科技股份有限公司股票在创业板上市交易的公告

浙江正元智慧科技股份有限公司人民币普通股股票将于2017年4月21日在本所创业板上市。证券简称为“正元智慧”,证券代码为“300645”。公司人民币普通股股份总数为66,666,667股，其中首次公开发行的16,666,667股股票自上市之日起开始上市交易。
