# 深圳证券交易所关于深圳能源集团股份有限公司2017年面向合格投资者公开发行绿色公司债券上市有关事项的通知

## 关于深圳能源集团股份有限公司2017年面向合格投资者公开发行绿色公司债券上市有关事项的通知

各会员单位：

深圳能源集团股份有限公司2017年面向合格投资者公开发行绿色公司债券定于2017年12月4日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

深圳能源集团股份有限公司2017年面向合格投资者公开发行绿色公司债券证券代码“112617”，证券简称“17深能G1”，发行总额10亿元，票面利率5.25%，债券期限5年,附第3个计息年度末发行人调整票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所
