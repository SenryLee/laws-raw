# 深圳证券交易所关于深圳市创新投资集团有限公司2017年面向合格投资者公开发行创新创业公司债券（第一期）上市有关事项的通知

## 关于深圳市创新投资集团有限公司2017年面向合格投资者公开发行创新创业公司债券（第一期）上市有关事项的通知

各会员单位：

深圳市创新投资集团有限公司2017年面向合格投资者公开发行创新创业公司债券（第一期）定于2017年12月29日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

深圳市创新投资集团有限公司2017年面向合格投资者公开发行创新创业公司债券（第一期）证券代码“112627”，证券简称“17创投S1”，发行总额5.5亿元，票面利率5.2%，债券期限5年。
