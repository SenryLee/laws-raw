# 深圳证券交易所关于快意电梯股份有限公司股票上市交易的公告

## 关于快意电梯股份有限公司股票上市交易的公告

快意电梯股份有限公司人民币普通股股票将于2017年3月24日在本所上市。证券简称为“快意电梯”,证券代码为“002774”。公司人民币普通股股份总数为334,800,000股，其中首次公开发行的83,700,000股股票自上市之日起开始上市交易。
