# 深圳证券交易所关于为广发证券股份有限公司2017年证券公司短期公司债券（第一期）等三只债券提供转让服务有关事项的通知

## 关于为广发证券股份有限公司2017年证券公司短期公司债券（第一期）等三只债券提供转让服务有关事项的通知

各会员单位：

广发证券股份有限公司2017年证券公司短期公司债券（第一期）、 广发证券股份有限公司2017年证券公司短期公司债券（第二期）、东北证券股份有限公司2017年证券公司短期公司债券（第二期）定于2017年6月22日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、广发证券股份有限公司2017年证券公司短期公司债券（第一期）证券代码“117559”，证券简称“广发1701”，发行总额30亿元，票面利率4.6%，债券期限270日。

2、广发证券股份有限公司2017年证券公司短期公司债券（第二期）证券代码“117561”，证券简称“广发1702”，发行总额45亿元，票面利率4.7%，债券期限240日。

3、东北证券股份有限公司2017年证券公司短期公司债券（第二期）证券代码“117563”，证券简称“东证1702”，发行总额12亿元，票面利率5.2%，债券期限340日。
