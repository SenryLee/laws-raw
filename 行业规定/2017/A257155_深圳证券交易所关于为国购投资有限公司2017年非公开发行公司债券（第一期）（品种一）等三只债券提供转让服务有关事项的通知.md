# 深圳证券交易所关于为国购投资有限公司2017年非公开发行公司债券（第一期）（品种一）等三只债券提供转让服务有关事项的通知

## 关于为国购投资有限公司2017年非公开发行公司债券（第一期）（品种一）等三只债券提供转让服务有关事项的通知

各会员单位：

国购投资有限公司2017年非公开发行公司债券（第一期）（品种一）、 三明市城市建设投资集团有限公司2017年非公开发行公司债券（第一期）、山东能源重型装备制造集团有限责任公司2017年非公开发行公司债券（第二期）定于2017年11月7日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、国购投资有限公司2017年非公开发行公司债券（第一期）（品种一）证券代码“114217”，证券简称“17国购01”，发行总额8亿元，票面利率8%，债券期限3年。

2、三明市城市建设投资集团有限公司2017年非公开发行公司债券（第一期）证券代码“114226”，证券简称“17明城01”，发行总额8亿元，票面利率6.18%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

3、山东能源重型装备制造集团有限责任公司2017年非公开发行公司债券（第二期）证券代码“114237”，证券简称“17山重02”，发行总额2亿元，票面利率7.1%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年十一月三日
