# 深圳证券交易所关于珠海英搏尔电气股份有限公司股票在创业板上市交易的公告

## 关于珠海英搏尔电气股份有限公司股票在创业板上市交易的公告

珠海英搏尔电气股份有限公司人民币普通股股票将于2017年7月25日在本所创业板上市。证券简称为“英搏尔”,证券代码为“300681”。公司人民币普通股股份总数为75,600,000股，其中首次公开发行的18,900,000股股票自上市之日起开始上市交易。
