# 深圳证券交易所关于浙江卫星石化股份有限公司股票临时停牌的公告

## 关于浙江卫星石化股份有限公司股票临时停牌的公告

由于浙江卫星石化股份有限公司于2017年9月4日披露的《关于签署〈年产400万吨烯烃综合利用示范产业园项目合作框架协议书〉的公告》内容不够完整，可能误导投资者的投资决策，根据本所《股票上市规则》和《中小企业板上市公司规范运作指引》的有关规定，经公司申请，公司股票（证券简称：卫星石化，证券代码：002648）于2017年9月4日开市起临时停牌，待公司通过指定媒体披露补充公告后复牌，敬请投资者密切关注。

深圳证券交易所

2017年9月4日
