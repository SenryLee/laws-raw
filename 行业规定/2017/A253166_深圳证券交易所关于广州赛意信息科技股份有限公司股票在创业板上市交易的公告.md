# 深圳证券交易所关于广州赛意信息科技股份有限公司股票在创业板上市交易的公告

## 关于广州赛意信息科技股份有限公司股票在创业板上市交易的公告

广州赛意信息科技股份有限公司人民币普通股股票将于2017年8月3日在本所创业板上市。证券简称为“赛意信息”,证券代码为“300687”。公司人民币普通股股份总数为80,000,000股，其中首次公开发行的20,000,000股股票自上市之日起开始上市交易。

深圳证券交易所

2017年8月1日
