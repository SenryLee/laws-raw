# 深圳证券交易所关于为北京金一文化发展股份有限公司2017年非公开发行公司债券（第二期）等两只债券提供转让服务有关事项的通知

## 关于为北京金一文化发展股份有限公司2017年非公开发行公司债券（第二期）等两只债券提供转让服务有关事项的通知

各会员单位：

北京金一文化发展股份有限公司2017年非公开发行公司债券（第二期）、山东能源重型装备制造集团有限责任公司2017年非公开发行公司债券（第一期）定于2017年8月22日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、北京金一文化发展股份有限公司2017年非公开发行公司债券（第二期）证券代码“114131”，证券简称“17金一02”，发行总额5.8亿元，票面利率8.2%，债券期限3年，附第1年末、第2年末发行人调整票面利率选择权和投资者回售选择权。

2、山东能源重型装备制造集团有限责任公司2017年非公开发行公司债券（第一期）证券代码“114175”，证券简称“17山重01”，发行总额2亿元，票面利率5.95%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。
