# 上海证券交易所南方原油证券投资基金申购赎回暂停公告

## 南方原油证券投资基金申购赎回暂停公告

上证公告（基金）〔2017〕053号

根据南方基金管理有限公司申请，本所于2017年8月23日13：00-15：00暂停南方原油证券投资基金的申购赎回业务，该基金证券代码为501018。

上海证券交易所

2017年8月23日
