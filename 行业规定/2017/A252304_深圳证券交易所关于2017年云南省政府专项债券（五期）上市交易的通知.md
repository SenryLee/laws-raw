# 深圳证券交易所关于2017年云南省政府专项债券（五期）上市交易的通知

## 关于2017年云南省政府专项债券（五期）上市交易的通知

各会员单位：

2017年云南省政府专项债券（五期）已发行结束，根据财政部通知，本期债券于2017年7月12日起在本所上市交易。

本期债券为5年期固定利率附息式国债（地方政府债），证券编码“107766”，证券简称“云南1712”，票面利率3.93％，标准交易单位“10张”，2022年7月10日到期还本并支付最后一期利息。

特此通知
