# 深圳证券交易所关于为惠州市硕贝德控股有限公司2017年非公开发行可交换公司债券提供转让服务有关事项的通知

## 关于为惠州市硕贝德控股有限公司2017年非公开发行可交换公司债券提供转让服务有关事项的通知

各会员单位：

惠州市硕贝德控股有限公司2017年非公开发行可交换公司债券定于2017年11月21日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

惠州市硕贝德控股有限公司2017年非公开发行可交换公司债券证券代码“117100”，证券简称“17硕控EB”，发行总额3亿元，票面利率3%，债券期限3年，附换股价格向下修正条款、赎回条款和回售条款。

深圳证券交易所

二○一七年十一月十七日
