# 深圳证券交易所关于为“平银-长城荣盛物业资产支持专项计划”提供转让服务的公告

## 关于为“平银-长城荣盛物业资产支持专项计划”提供转让服务的公告

各相关单位：

根据长城证券股份有限公司申请，本所将自2017年1月26日起在综合协议交易平台为“平银-长城荣盛物业资产支持专项计划”（以下简称“长城荣盛物业”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“长城荣盛物业”的转让业务。

二、“长城荣盛物业”设立日期为2016年11月24日。优先级资产支持证券如下：证券简称“16荣物01”，证券代码为“116422”，到期日为2017年11月24日，还本付息方式为按季付息、到期一次还本；证券简称“16荣物02”，证券代码为“116423”，到期日为2018年11月24日，还本付息方式为按季付息、到期一次还本；证券简称“16荣物03”，证券代码为“116424”，到期日为2019年11月24日，还本付息方式为按季付息、到期一次还本；证券简称“16荣物04”，证券代码为“116425”，到期日为2020年11月24日，还本付息方式为按季付息、到期一次还本；证券简称“16荣物05”，证券代码为“116426”，到期日为2021年11月24日，还本付息方式为按季付息、到期一次还本。

三、“16荣物01”的单笔成交申报最低数量为10000份，“16荣物02”的单笔成交申报最低数量为10000份，“16荣物03”的单笔成交申报最低数量为10000份，“16荣物04”的单笔成交申报最低数量为10000份，“16荣物05”的单笔成交申报最低数量为10000份。

四、对首次参加“长城荣盛物业”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“长城荣盛物业”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
