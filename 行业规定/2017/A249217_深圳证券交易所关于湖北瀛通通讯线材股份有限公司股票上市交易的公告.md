# 深圳证券交易所关于湖北瀛通通讯线材股份有限公司股票上市交易的公告

## 关于湖北瀛通通讯线材股份有限公司股票上市交易的公告

湖北瀛通通讯线材股份有限公司人民币普通股股票将于2017年4月13日在本所上市。证券简称为“瀛通通讯”,证券代码为“002861”。公司人民币普通股股份总数为122,698,400股，其中首次公开发行的30,680,000股股票自上市之日起开始上市交易。
