# 深圳证券交易所关于湖北华昌达智能装备股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等两只债券上市有关事项的通知

## 关于湖北华昌达智能装备股份有限公司2017年面向合格投资者公开发行公司债券（第一期）等两只债券上市有关事项的通知

各会员单位：

湖北华昌达智能装备股份有限公司2017年面向合格投资者公开发行公司债券（第一期）,浙江盾安人工环境股份有限公司2017年面向合格投资者公开发行公司债券（第一期）定于2017年6月20日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、湖北华昌达智能装备股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112508”，证券简称“17华昌01”，发行总额5亿元，票面利率5.96%，债券期限3年,附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、浙江盾安人工环境股份有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112525”，证券简称“17盾安01”，发行总额5亿元，票面利率6.8%，债券期限3年，附第2年末发行人赎回选择权、调整票面利率选择权和投资者回售选择权。

特此通知
