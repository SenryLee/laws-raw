# 深圳证券交易所关于西部航空有限责任公司2017年面向合格投资者公开发行公司债券（第一期）等两只债券上市有关事项的通知

## 关于西部航空有限责任公司2017年面向合格投资者公开发行公司债券（第一期）等两只债券上市有关事项的通知

各会员单位：

西部航空有限责任公司2017年面向合格投资者公开发行公司债券（第一期）,海航凯撒旅游集团股份有限公司2017年面向合格投资者公开发行公司债券定于2017年7月7日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、西部航空有限责任公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112517”，证券简称“17西航01”，发行总额7.8亿元，票面利率6.2%，债券期限5年,附第3年末发行人上调票面利率选择权及投资者回售选择权。

2、海航凯撒旅游集团股份有限公司2017年面向合格投资者公开发行公司债券证券代码“112532”，证券简称“17凯撒03”，发行总额7亿元，票面利率7.2%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

特此通知
