# 深圳证券交易所关于金科地产集团股份有限公司股票临时停牌的公告

## 关于金科地产集团股份有限公司股票临时停牌的公告

因相关媒体报道了金科地产集团股份有限公司的实际控制人可能涉及股权转让事宜，根据《深圳证券交易所股票上市规则》第12.4条的规定，经公司申请，本所将于2017年7月19日开市起对（证券简称：金科股份，证券代码：000656）进行临时停牌，待公司刊登相关公告后复牌。

深圳证券交易所

2017年7月19日
