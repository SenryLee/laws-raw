# 深圳证券交易所关于江苏金陵体育器材股份有限公司股票在创业板上市交易的公告

## 关于江苏金陵体育器材股份有限公司股票在创业板上市交易的公告

江苏金陵体育器材股份有限公司人民币普通股股票将于2017年5月9日在本所创业板上市。证券简称为“金陵体育”,证券代码为“300651”。公司人民币普通股股份总数为75,733,400股，其中首次公开发行的18,933,400股股票自上市之日起开始上市交易。
