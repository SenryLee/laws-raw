# 中国创盈市场服务有限公司关于香港联合交易所有限公司实施收市竞价交易时段第二阶段的通知

## 关于香港联合交易所有限公司实施收市竞价交易时段第二阶段的通知

各市场参与人：

香港联合交易所有限公司于2017年7月3日发布了《收市竞价交易时段第二阶段──确定实施日期及核实环节》的通告，将于2017年7月24日正式实施收市竞价交易第二阶段。第二阶段推出后，收市竞价交易时段证券的名单将加入恒生综合小型股指数成份股，全部深港通下港股通股票均将实施收市竞价交易制度。

请各市场参与人根据以下链接了解香港市场有关收市竞价交易时段的相关内容：

http://www.hkex.com.hk/chi/market/partcir/sehk/2017/Documents/CT05417C.pdf、

http://www.hkex.com.hk/chi/market/partcir/sehk/2017/Documents/CT04217C.pdf。

各证券公司应做好相关宣传和投资者教育工作，向投资者充分告知相关交易规则的变化。

特此通知

中国创盈市场服务有限公司

2017年7月7日
