# 深圳证券交易所关于为淮安市国有联合投资发展集团有限公司2017年非公开发行公司债券（第一期）等三只债券提供转让服务有关事项的通知

## 关于为淮安市国有联合投资发展集团有限公司2017年非公开发行公司债券（第一期）等三只债券提供转让服务有关事项的通知

各会员单位：

淮安市国有联合投资发展集团有限公司2017年非公开发行公司债券（第一期）、 贵阳市城市发展投资（集团）股份有限公司2017年非公开发行公司债券、沈阳合金投资股份有限公司2016年非公开发行公司债券定于2017年5月17日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、淮安市国有联合投资发展集团有限公司2017年非公开发行公司债券（第一期）证券代码“114134”，证券简称“17淮发01”，发行总额6亿元，票面利率5.49%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、贵阳市城市发展投资（集团）股份有限公司2017年非公开发行公司债券证券代码“114142”，证券简称“17贵城发”，发行总额5亿元，票面利率5.65%，债券期限5年，附第3年末发行人赎回选择权、发行人调整票面利率选择权和投资者回售选择权。

3、沈阳合金投资股份有限公司2016年非公开发行公司债券证券代码“118863”，证券简称“16合金债”，发行总额7亿元，票面利率7.5%，债券期限3年。

深圳证券交易所

二○一七年五月十五日
