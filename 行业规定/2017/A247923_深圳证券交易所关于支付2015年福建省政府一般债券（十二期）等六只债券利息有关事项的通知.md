# 深圳证券交易所关于支付2015年福建省政府一般债券（十二期）等六只债券利息有关事项的通知

## 关于支付2015年福建省政府一般债券（十二期）等六只债券利息有关事项的通知

各会员单位：

2015年福建省政府一般债券（十二期）、2015年福建省政府专项债券（四期）、2016年新疆维吾尔自治区政府一般债券（一期）、2016年新疆维吾尔自治区政府一般债券（二期）、2016年新疆维吾尔自治区政府一般债券（三期）、2016年新疆维吾尔自治区政府一般债券（四期）将于2017年3月23日支付利息。为做好上述债券的利息支付工作，现将有关事项通知如下：

一、2015年福建省政府一般债券（十二期）证券代码为“109527”，证券简称为“福建1512”，是2015年9月23日发行的10年期债券，票面利率为3.61％，每年支付2次利息，每百元面值债券本次可获利息1.805元。

二、2015年福建省政府专项债券（四期）证券代码为“109529”，证券简称为“福建15Z4”，是2015年9月23日发行的10年期债券，票面利率为3.61％，每年支付2次利息，每百元面值债券本次可获利息1.805元。

三、2016年新疆维吾尔自治区政府一般债券（一期）证券代码为“109831”，证券简称为“新疆1601”，是2016年3月23日发行的3年期债券，票面利率为2.52％，每年支付1次利息，每百元面值债券本次可获利息2.52元。

四、2016年新疆维吾尔自治区政府一般债券（二期）证券代码为“109832”，证券简称为“新疆1602”，是2016年3月23日发行的5年期债券，票面利率为2.72％，每年支付1次利息，每百元面值债券本次可获利息2.72元。

五、2016年新疆维吾尔自治区政府一般债券（三期）证券代码为“109833”，证券简称为“新疆1603”，是2016年3月23日发行的7年期债券，票面利率为3％，每年支付1次利息，每百元面值债券本次可获利息3元。

六、2016年新疆维吾尔自治区政府一般债券（四期）证券代码为“109834”，证券简称为“新疆1604”，是2016年3月23日发行的10年期债券，票面利率为3.02％，每年支付2次利息，每百元面值债券本次可获利息1.51元。

七、本所从2017年3月15日至2017年3月22日停办上述债券的转托管及调帐业务。

八、上述债券付息债权登记日为2017年3月22日，凡于当日收市后持有上述债券的投资者，享有获得本次利息款项的权利，2017年3月23日除息交易。

九、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的上述债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。
