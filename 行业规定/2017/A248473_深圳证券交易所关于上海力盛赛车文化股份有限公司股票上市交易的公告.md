# 深圳证券交易所关于上海力盛赛车文化股份有限公司股票上市交易的公告

## 关于上海力盛赛车文化股份有限公司股票上市交易的公告

上海力盛赛车文化股份有限公司人民币普通股股票将于2017年3月24日在本所上市。证券简称为“力盛赛车”,证券代码为“002858”。公司人民币普通股股份总数为63,160,000股，其中首次公开发行的15,800,000股股票自上市之日起开始上市交易。
