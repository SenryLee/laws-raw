# 深圳证券交易所关于2010年记账式附息（二十七期）国债等三只债券到期兑付有关事项的通知

## 关于2010年记账式附息（二十七期）国债等三只债券到期兑付有关事项的通知

各市场参与人：

2010年记账式附息（二十七期）国债、2012年地方政府债券（八期）、2017年记账式贴现（二十四期）国债将于2017年8月21日到期兑付。为做好上述债券的本息兑付工作，现将有关事项通知如下：

一、2010年记账式附息（二十七期）国债证券代码为“101027”，证券简称为“国债1027”，是2010年8月19日发行的7年期债券，票面利率为2.81%，每年支付1次利息，每百元面值债券兑付可获本息102.81元。

二、2012年地方政府债券（八期）证券代码为“109084”，证券简称为“地债1208”，是2012年8月20日发行的5年期债券，票面利率为3.38%，每年支付1次利息，每百元面值债券兑付可获本息103.38元。

三、2017年记账式贴现（二十四期）国债证券代码为“108180”，证券简称为“贴债1724”，是2017年5月22日发行的91日期债券，以贴现形式发行，到期按面值兑付。本次到期兑付，每百元面值国债可获得的本息为100元。

四、本所从2017年8月11日起停办上述债券的转托管及调帐业务。

五、上述债券兑付债权登记日为2017年8月16日，凡于当日收市后持有上述债券的投资者，享有获得本次兑付款项的权利。2017年8月17日上述债券摘牌。

六、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的上述债券兑付款项后，将其划入各证券商的清算备付金帐户，并由证券商将兑付资金及时划入各投资者的资金帐户。
