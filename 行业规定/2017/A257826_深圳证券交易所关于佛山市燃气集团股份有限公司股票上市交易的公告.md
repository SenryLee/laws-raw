# 深圳证券交易所关于佛山市燃气集团股份有限公司股票上市交易的公告

## 关于佛山市燃气集团股份有限公司股票上市交易的公告

佛山市燃气集团股份有限公司人民币普通股股票将于2017年11月22日在本所上市。证券简称为“佛燃股份”,证券代码为“002911”。公司人民币普通股股份总数为556,000,000股，其中首次公开发行的56,000,000股股票自上市之日起开始上市交易。
