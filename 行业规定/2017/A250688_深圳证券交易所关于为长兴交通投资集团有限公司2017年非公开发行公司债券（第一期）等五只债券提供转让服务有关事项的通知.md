# 深圳证券交易所关于为长兴交通投资集团有限公司2017年非公开发行公司债券（第一期）等五只债券提供转让服务有关事项的通知

## 关于为长兴交通投资集团有限公司2017年非公开发行公司债券（第一期）等五只债券提供转让服务有关事项的通知

各会员单位：

长兴交通投资集团有限公司2017年非公开发行公司债券（第一期）、 武汉蔡甸生态发展集团有限公司2017年非公开发行公司债券（第一期）、广东奥马电器股份有限公司2017年非公开发行公司债券（第二期）、 苏州市相城城市建设有限责任公司2017年非公开发行公司债券、 杭州高新技术产业开发区资产经营有限公司2017年非公开发行公司债券定于2017年5月26日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、长兴交通投资集团有限公司2017年非公开发行公司债券（第一期）证券代码“114127”，证券简称“17长交01”，发行总额8亿元，票面利率6%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、武汉蔡甸生态发展集团有限公司2017年非公开发行公司债券（第一期）证券代码“114132”，证券简称“17蔡生01”，发行总额4亿元，票面利率6.5%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

3、广东奥马电器股份有限公司2017年非公开发行公司债券（第二期）证券代码“114133”，证券简称“17奥马02”，发行总额4亿元，票面利率5.5%，债券期限3年，附第1年末、第2年末发行人上调票面利率选择权和投资者回售选择权。

4、苏州市相城城市建设有限责任公司2017年非公开发行公司债券证券代码“114149”，证券简称“17相城债”，发行总额5亿元，票面利率5.3%，债券期限3年。

5、杭州高新技术产业开发区资产经营有限公司2017年非公开发行公司债券证券代码“114152”，证券简称“17杭高新”，发行总额12亿元，票面利率4.9%，债券期限6年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年五月二十四日
