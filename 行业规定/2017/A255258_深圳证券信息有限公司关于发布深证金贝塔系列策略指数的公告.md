# 深圳证券信息有限公司关于发布深证金贝塔系列策略指数的公告

## 关于发布深证金贝塔系列策略指数的公告

为体现深市企业的价值和成长特色，向市场提供更丰富的策略指数投资标的，深圳证券信息有限公司与金贝塔网络金融科技有限公司定于2017年9月15日发布四条深证金贝塔系列策略指数。指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| CN5138 | 深证大盘红利指数 | 大盘红利 | 2008年12月31日 | 1000 |
| CN5139 | 深证稳进价值指数 | 稳进价值 | 2008年12月31日 | 1000 |
| CN5140 | 深证先锋成长指数 | 先锋成长 | 2008年12月31日 | 1000 |
| CN5141 | 深证优势价值指数 | 优势价值 | 2008年12月31日 | 1000 |

深证金贝塔系列策略指数通过分析股票估值与成长指标，结合市场交易数据，筛选综合排名靠前的股票组成样本股。指数样本股实施季度定期调整，样本调整实施时间定于每年2月、5月、8月、11月的第一个交易日。

深证金贝塔系列策略指数包括纯价格指数和全收益指数，纯价格指数和全收益指数均通过国证指数网（www.cnindex.com.cn）发布收盘行情数据。

有关深证金贝塔系列策略指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。

特此公告。
