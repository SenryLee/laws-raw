# 中国注册税务师协会秘书处关于继续免费提供法律法规库服务的通知

## 关于继续免费提供法律法规库服务的通知

中税协秘发〔2016〕083号

各省、自治区、直辖市和计划单列市注册税务师协会：

中国注册税务师协会法律法规库已上线两年，根据会员的使用需求和反馈建议，中税协已与北京威科亚太信息技术有限公司（以下简称“威科”）续签《中国注册税务师协会法律法规库服务合同》，2017年继续免费为会员提供法律法规库服务，并扩大了使用ID登录方式浏览法律法规库的使用权限。现将有关事项通知如下：

一、授权用户范围

（一）中税协团体会员（即，税务师事务所）；

（二）中税协指定的个人用户（即，税务师事务所在职人员，包括执业、非执业注册税务师/税务师和其他从业人员）；

（三）两级协会工作人员。

二、登录方式

（一）使用安全盘登录。通过中税协发放的安全盘登录中税协官网首页法律法规库栏目（http://cctaa.wkinfo.com.cn/），实现在线访问。

（二）使用ID方式登录。通过“行业管理系统”提供的个人用户账号登录中税协官网首页法律法规库栏目（http://cctaa.wkinfo.com.cn/）或通过登录“中税协信息服务平台”（http://www.ecctaa.com），实现在线访问。税务师事务所其他从业人员只能用ID方式登录，并由其所在税务师事务所通过“行业管理系统”添加人员信息并查询ID号。

（三）使用IP方式登录。如有需求，可直接联系中税协（业务准则部）或威科另行购买，费用由税务师事务所自行负担。

三、法律法规库内容

法律法规库由法规、新闻、案例（包括法院判例和实务案例）、专业解读（包括专业文章和财税专题）、智能图表、咨询问答和实务指南等七大版块构成。

四、注意事项

（一）请地方税协接此通知后及时告知本地区会员，以便会员尽早应用。

（二）使用法律法规库时，应认真阅读法规库中的版权声明、免责声明、服务条款和保密规定等使用条件和条款，以《注册税务师职业道德规范（试行）》为约束，高度重视与数据库相关的保密和知识产权等内容。

五、使用说明及培训课件

授权用户可随时登录中税协官网首页相应栏目（http://www.cctaa.cn/flfgzl/），查看法律法规库使用说明和培训课件。
