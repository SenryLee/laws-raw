# 深圳证券交易所关于江南模塑科技股份有限公司可转换公司债券上市交易的公告

## 关于江南模塑科技股份有限公司可转换公司债券上市交易的公告

江南模塑科技股份有限公司发行的813,660,000元可转换公司债券自2017年6月26日起在本所上市交易，证券简称为“模塑转债”，证券代码为“127004”，上市数量813.66万张。

深圳证券交易所

二○一七年六月二十二日
