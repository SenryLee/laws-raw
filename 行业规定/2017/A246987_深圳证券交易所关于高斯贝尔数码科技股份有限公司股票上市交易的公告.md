# 深圳证券交易所关于高斯贝尔数码科技股份有限公司股票上市交易的公告

## 关于高斯贝尔数码科技股份有限公司股票上市交易的公告

高斯贝尔数码科技股份有限公司人民币普通股股票将于2017年2月13日在本所上市。证券简称为“高斯贝尔”,证券代码为“002848”。公司人民币普通股股份总数为167,150,000股，其中首次公开发行的41,800,000股股票自上市之日起开始上市交易。
