# 中国创盈市场服务有限公司关于2017年香港耶稣受难节、复活节期间深港通下的港股通交易日安排的通知

## 关于2017年香港耶稣受难节、复活节期间深港通下的港股通交易日安排的通知

各市场参与人：

根据《关于2016年底及2017年深港通下的港股通交易日安排的通知》（中创盈〔2016〕4号），中国创盈市场服务有限公司现将2017年香港耶稣受难节、复活节期间深港通下港股通（以下简称“港股通”）交易日安排通知如下：

一、4月14日（星期五）至4月17日（星期一）不提供港股通服务，4月18日（星期二）起照常开通港股通服务。

二、港股通交易的清算交收事宜，按照中国证券登记结算有限责任公司的安排进行。

特此通知

中国创盈市场服务有限公司

2017年4月10日
