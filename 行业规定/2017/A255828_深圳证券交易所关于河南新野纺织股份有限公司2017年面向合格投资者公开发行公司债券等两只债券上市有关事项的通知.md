# 深圳证券交易所关于河南新野纺织股份有限公司2017年面向合格投资者公开发行公司债券等两只债券上市有关事项的通知

## 关于河南新野纺织股份有限公司2017年面向合格投资者公开发行公司债券等两只债券上市有关事项的通知

各会员单位：

河南新野纺织股份有限公司2017年面向合格投资者公开发行公司债券,中国航空技术深圳有限公司2017年面向合格投资者公开发行公司债券（第一期）定于2017年10月9日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、河南新野纺织股份有限公司2017年面向合格投资者公开发行公司债券证券代码“112555”，证券简称“17新野01”，发行总额3亿元，票面利率6.72%，债券期限5年,附第2年末和第4年末发行人调整票面利率选择权和投资者回售选择权。

2、中国航空技术深圳有限公司2017年面向合格投资者公开发行公司债券（第一期）证券代码“112586”，证券简称“17航技01”，发行总额4.5亿元，票面利率4.75%，债券期限3年。
