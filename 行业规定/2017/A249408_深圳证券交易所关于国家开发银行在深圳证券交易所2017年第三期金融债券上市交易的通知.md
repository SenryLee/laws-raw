# 深圳证券交易所关于国家开发银行在深圳证券交易所2017年第三期金融债券上市交易的通知

## 关于国家开发银行在深圳证券交易所2017年第三期金融债券上市交易的通知

各会员单位：

根据深圳证券交易所（以下简称“本所”）有关规定，国家开发银行在深圳证券交易所2017年第三期金融债券（以下简称“本期债券”）将于2017年4月19日在本所集中竞价系统上市，现将有关事项通知如下：

本期债券为1年期固定利率附息式债券，证券代码“108601”，证券简称“国开1703”，票面利率3.45%，每年支付一次利息；本期债券起息日为2017年4月18日， 2018年4月18日到期还本并支付最后一期利息。

特此通知

深圳证券交易所

二〇一七年四月十四日
