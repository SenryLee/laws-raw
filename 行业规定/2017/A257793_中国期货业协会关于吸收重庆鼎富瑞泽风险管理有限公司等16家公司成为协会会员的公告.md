# 中国期货业协会关于吸收重庆鼎富瑞泽风险管理有限公司等16家公司成为协会会员的公告

## 关于吸收重庆鼎富瑞泽风险管理有限公司等16家公司成为协会会员的公告

根据公司自愿申请，按照协会章程，经协会理事会审议，同意吸收重庆鼎富瑞泽风险管理有限公司等16家公司成为协会会员（具体名单附后）。

特此公告。

中国期货业协会

二〇一七年六月十三日
