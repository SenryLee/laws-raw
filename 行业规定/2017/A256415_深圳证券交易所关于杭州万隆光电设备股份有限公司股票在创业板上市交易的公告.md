# 深圳证券交易所关于杭州万隆光电设备股份有限公司股票在创业板上市交易的公告

## 关于杭州万隆光电设备股份有限公司股票在创业板上市交易的公告

杭州万隆光电设备股份有限公司人民币普通股股票将于2017年10月19日在本所创业板上市。证券简称为“万隆光电”,证券代码为“300710”。公司人民币普通股股份总数为68,614,000股，其中首次公开发行的17,500,000股股票自上市之日起开始上市交易。
