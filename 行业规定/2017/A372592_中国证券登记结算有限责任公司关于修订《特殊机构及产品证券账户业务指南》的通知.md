# 中国证券登记结算有限责任公司关于修订《特殊机构及产品证券账户业务指南》的通知

## 关于修订《特殊机构及产品证券账户业务指南》的通知

各市场参与主体：

为适应业务发展变化，提高业务办理效率，现对《特殊机构及产品证券账户业务指南》（简称《指南》）进行如下修订：

一、调整单一委托人产品账户命名方式

（一）修订了第2．2．4、2．2．5、2．5．2、2．5．3、2．5．4、2．5．5、2．5．6、2．10．2、2．12．2条，优化了基金、保险、期货单一委托人资管产品的证券账户命名方式。其中，基金（保险）单一委托人资管产品证券账户的命名方式调整为“基金（保险）资管公司简称－托管人简称－特定客户资产管理计划名称”。期货单一委托人资管产品证券账户的命名方式调整为“期货公司全称－特定客户资产管理计划名称”。

（二）《指南》实施后，对于申请新开户的，申请机构应在“产品简称”一栏填报委托人名称。对于存量账户，拟新增开立证券子账户的，申请机构应当主动申报属于同一产品的存量证券子账户号码。我公司将根据申请，按照调整后的命名方式新开一个一码通账户，并在该一码通账户下新开子账户和转挂申报的存量子账户。

对于存量的单一委托人产品账户，管理人或托管人可按新命名方式申请办理名称变更手续，也可不作名称变更。我公司不主动按新的命名方式进行名称调整。

二、部分开户申请材料的备案管理

（一）为了提高远程开户办理效率，避免重复提交材料，修订了第1．11条，明确申请机构可以向我公司账户管理部备案申请人业务资质、营业执照和法定代表人相关证明材料。备案完成后，远程申请开户时可不再重复提交。另外，增加了法定代表人证明书模板和授权委托书模板增加了附录28和附录29。

（二）申请机构可以通过邮寄方式进行材料备案。地址:北京市西城区太平桥大街17号中国结算账户管理部，邮编100033。

三、其它修订内容

（一）修订了第1．4条，明确了上市公司外国战略投资者证券账户业务是分市场受理。

（二）增加了第1．5条，补充了申请机构远程提交证券账户开户申请的相关内容。

（三）修订了第1．6条，明确了除产品托管人外，也可以由产品管理人申请产品证券账户注销。

修订后的《指南》将于2018年1月1日执行，特此通知。
