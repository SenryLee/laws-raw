# 深圳证券交易所关于中科院成都信息技术股份有限公司股票临时停牌的公告

## 关于中科院成都信息技术股份有限公司股票临时停牌的公告

中科院成都信息技术股份有限公司因近期股票价格涨幅较大，公司申请股票停牌核查，根据本所《创业板股票上市规则》的有关规定，公司股票（证券简称：中科信息，证券代码：300678）于2017年8月24日下午开市起停牌，待公司通过指定媒体披露核查结果后复牌，敬请投资者密切关注。

深圳证券交易所

2017年8月24日
