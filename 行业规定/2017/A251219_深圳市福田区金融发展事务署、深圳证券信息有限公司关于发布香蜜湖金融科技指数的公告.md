# 深圳市福田区金融发展事务署、深圳证券信息有限公司关于发布香蜜湖金融科技指数的公告

## 关于发布香蜜湖金融科技指数的公告

为了反映深市金融科技公司整体表现，提供金融科技产业的业绩基准与投资标的，深圳市福田区金融发展事务署与深圳证券信息有限公司定于2017年6月9日联合发布香蜜湖金融科技指数。

指数名称：香蜜湖金融科技指数

指数简称：金融科技

指数代码：399699

指数基日：2017年5月26日

基日点位：3000

香蜜湖金融科技指数以深交所上市公司为选样空间，选取金融科技领域（含分布式技术、互联技术、金融安全、互联网金融等）公司作为样本股。

香蜜湖金融科技指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关香蜜湖金融科技指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
