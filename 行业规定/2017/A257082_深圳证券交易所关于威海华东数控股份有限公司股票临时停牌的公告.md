# 深圳证券交易所关于威海华东数控股份有限公司股票临时停牌的公告

## 关于威海华东数控股份有限公司股票临时停牌的公告

威海华东数控股份有限公司拟披露重大事项，根据本所《股票上市规则》和《中小企业板上市公司规范运作指引》的有关规定，经公司申请，公司股票（证券简称：*ST东数，证券代码：002248）于2017年11月3日13：00起临时停牌，待公司通过指定媒体披露相关公告后复牌，敬请投资者密切关注。

深圳证券交易所

2017年11月3日
