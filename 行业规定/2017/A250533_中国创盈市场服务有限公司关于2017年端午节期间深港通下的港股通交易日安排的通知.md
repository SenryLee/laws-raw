# 中国创盈市场服务有限公司关于2017年端午节期间深港通下的港股通交易日安排的通知

## 关于2017年端午节期间深港通下的港股通交易日安排的通知

各市场参与人：

根据《关于2016年底及2017年深港通下的港股通交易日安排的通知》（中创盈〔2016〕4号），中国创盈市场服务有限公司现将2017年端午节期间深港通下港股通（以下简称“港股通”）交易日安排通知如下：

一、5月25日（星期四）至5月30日（星期二）不提供港股通服务，5月31日（星期三）起照常开通港股通服务。

二、港股通交易的清算交收事宜，按照中国证券登记结算有限责任公司的安排进行。

特此通知

中国创盈市场服务有限公司

2017年5月18日
