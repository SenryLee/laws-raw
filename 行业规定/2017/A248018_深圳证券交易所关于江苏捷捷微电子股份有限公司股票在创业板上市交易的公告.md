# 深圳证券交易所关于江苏捷捷微电子股份有限公司股票在创业板上市交易的公告

## 关于江苏捷捷微电子股份有限公司股票在创业板上市交易的公告

江苏捷捷微电子股份有限公司人民币普通股股票将于2017年3月14日在本所创业板上市。证券简称为“捷捷微电”,证券代码为“300623”。公司人民币普通股股份总数为93,600,000股，其中首次公开发行的23,600,000股股票自上市之日起开始上市交易。

2017年3月10日
