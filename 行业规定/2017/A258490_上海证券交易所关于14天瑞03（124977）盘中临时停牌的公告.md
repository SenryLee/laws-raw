# 上海证券交易所关于14天瑞03（124977）盘中临时停牌的公告

## 关于14天瑞03（124977）盘中临时停牌的公告

上证公告（监察）〔2017〕163号

14天瑞03（124977）今日上午交易出现异常波动。根据《上海证券交易所交易规则》和《上海证券交易所证券异常交易实时监控细则》的有关规定，本所决定，自2017年12月08日11时07分开始暂停14天瑞03（124977）交易，自2017年12月08日13时07分起恢复交易。

本所提醒投资者注意交易风险，理性投资。恢复交易后，如该债券交易再次出现异常波动，本所可实施第二次盘中临时停牌，停牌时间持续至今日14时55分。

特此公告。

上海证券交易所

2017年12月08日
