# 深圳证券交易所关于宁波中大力德智能传动股份有限公司股票上市交易的公告

## 关于宁波中大力德智能传动股份有限公司股票上市交易的公告

宁波中大力德智能传动股份有限公司人民币普通股股票将于2017年8月29日在本所上市。证券简称为“中大力德”,证券代码为“002896”。公司人民币普通股股份总数为80,000,000股，其中首次公开发行的20,000,000股股票自上市之日起开始上市交易。
