# 深圳证券交易所关于深圳麦格米特电气股份有限公司股票上市交易的公告

## 关于深圳麦格米特电气股份有限公司股票上市交易的公告

深圳麦格米特电气股份有限公司人民币普通股股票将于2017年3月6日在本所上市。证券简称为“麦格米特”,证券代码为“002851”。公司人民币普通股股份总数为177,725,147股，其中首次公开发行的44,500,000股股票自上市之日起开始上市交易。
