# 深圳证券交易所关于为远东国际租赁有限公司2017年非公开发行公司债券（第二期）等三只债券提供转让服务有关事项的通知

## 关于为远东国际租赁有限公司2017年非公开发行公司债券（第二期）等三只债券提供转让服务有关事项的通知

各会员单位：

远东国际租赁有限公司2017年非公开发行公司债券（第二期）、 冀中能源峰峰集团有限公司2017年非公开发行公司债券（第一期）、天津中环半导体股份有限公司2017年非公开发行公司债券（第二期）（品种一）定于2017年8月25日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、远东国际租赁有限公司2017年非公开发行公司债券（第二期）证券代码“114177”，证券简称“17远东二”，发行总额40亿元，票面利率5.58%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

2、冀中能源峰峰集团有限公司2017年非公开发行公司债券（第一期）证券代码“114189”，证券简称“17峰峰01”，发行总额5亿元，票面利率6%，债券期限5年，附第1、2、3、4年末发行人调整票面利率选择权和投资者回售选择权。

3、天津中环半导体股份有限公司2017年非公开发行公司债券（第二期）（品种一）证券代码“114192”，证券简称“17中环02”，发行总额2.5亿元，票面利率6.5%，债券期限5年，附第1、2、3、4年末发行人调整票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一七年八月二十三日
