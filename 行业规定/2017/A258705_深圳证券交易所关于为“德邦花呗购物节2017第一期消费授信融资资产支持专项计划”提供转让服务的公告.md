# 深圳证券交易所关于为“德邦花呗购物节2017第一期消费授信融资资产支持专项计划”提供转让服务的公告

## 关于为“德邦花呗购物节2017第一期消费授信融资资产支持专项计划”提供转让服务的公告

各相关单位：

根据德邦证券股份有限公司申请，本所将自2017年12月19日起在综合协议交易平台为“德邦花呗购物节2017第一期消费授信融资资产支持专项计划”（以下简称“花呗购物节2017第一期”）提供转让服务。现就有关事项公告如下：

一、持有深圳A股证券账户和基金账户的合格投资者可以参与“花呗购物节2017第一期”的转让业务。

二、“花呗购物节2017第一期”设立日期为2017年11月16日。优先级资产支持证券如下：证券简称“17双11A1”，证券代码为“116725”，到期日为2017年12月27日，还本付息方式为到期一次还本付息；证券简称“17双11A2”，证券代码为“116726”，到期日为2018年5月28日，还本付息方式为分期过手还本付息。次优先级资产支持证券如下：证券简称“17双11B”，证券代码为“116727”，到期日为2018年5月28日，还本付息方式为分期过手还本付息。次级资产支持证券如下：证券简称“17双11次”，证券代码为“116728”，到期日为2018年5月28日，还本付息方式为分配完优先级、次优先级本息后，获得所有剩余资产。

三、“17双11A1”的单笔成交申报最低数量为10000份，“17双11A2”的单笔成交申报最低数量为10000份，“17双11B”的单笔成交申报最低数量为10000份，“17双11次”的单笔成交申报最低数量为10000份。

四、对首次参加“花呗购物节2017第一期”转让业务的投资者，本所会员应当在其参与转让业务前，进行全面的相关业务规则介绍，充分揭示可能产生的风险，并要求其在参与转让业务前签署风险揭示书。

五、“花呗购物节2017第一期”转让及相关事宜适用《深圳证券交易所资产证券化业务指引》及其他相关规则。
