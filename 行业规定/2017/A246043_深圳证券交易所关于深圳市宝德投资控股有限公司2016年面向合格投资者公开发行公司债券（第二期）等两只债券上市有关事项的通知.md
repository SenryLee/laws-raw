# 深圳证券交易所关于深圳市宝德投资控股有限公司2016年面向合格投资者公开发行公司债券（第二期）等两只债券上市有关事项的通知

## 关于深圳市宝德投资控股有限公司2016年面向合格投资者公开发行公司债券（第二期）等两只债券上市有关事项的通知

各会员单位：

深圳市宝德投资控股有限公司2016年面向合格投资者公开发行公司债券（第二期）,远大医药（中国）有限公司2016年面向合格投资者公开发行公司债券（第一期）定于2017年1月6日起在本所集中竞价系统和综合协议交易平台同时交易，现将有关事项通知如下：

1、深圳市宝德投资控股有限公司2016年面向合格投资者公开发行公司债券（第二期）证券代码“112471”，证券简称“16宝德02”，发行总额4亿元，票面利率6.2%，债券期限5年,附第3年末发行人上调票面利率选择权和投资者回售选择权。

2、远大医药（中国）有限公司2016年面向合格投资者公开发行公司债券（第一期）证券代码“112486”，证券简称“16远大01”，发行总额1亿元，票面利率5.49%，债券期限5年，含第3年末发行人调整票面利率选择权和投资者回售选择权。

特此通知
