# 中国期货业协会关于发布实施《关于期货行业履行脱贫攻坚社会责任的意见》的通知

## 关于发布实施《关于期货行业履行脱贫攻坚社会责任的意见》的通知

各会员单位：

为进一步深入贯彻《中共中央 国务院关于打赢脱贫攻坚战的决定》（中发〔2015〕34号）和中央扶贫开发工作会议精神要求，细化落实中国证监会关于资本市场服务脱贫攻坚的战略部署，充分发挥期货行业服务国家脱贫攻坚战略的作用，中国期货业协会第四届理事会第十二次会议审议通过了《关于期货行业履行脱贫攻坚社会责任的意见》（以下简称《意见》），现予以发布实施。

请各会员单位认真学习、深刻领会《意见》的精神和内容，切实做好《意见》的贯彻落实工作。

## 关于期货行业履行脱贫攻坚社会责任的意见

消除贫困，改善民生，实现共同富裕，是社会主义的本质要求,是党的重要使命。当前，脱贫攻坚已经到了啃硬骨头、攻坚拔寨的冲刺阶段，打赢脱贫攻坚战需举全党全社会之力。为进一步深入贯彻《中共中央 国务院关于打赢脱贫攻坚战的决定》（中发〔2015〕34号）和中央扶贫开发工作会议精神要求，细化落实中国证监会关于资本市场服务脱贫攻坚的战略部署，充分发挥期货市场服务国家脱贫攻坚战略的作用，现就期货行业履行脱贫攻坚社会责任提出以下意见：

一、指导思想和总体要求

（一）指导思想

认真贯彻落实习近平总书记系列重要讲话精神，紧紧围绕中央提出的“五位一体”总体布局和“四个全面”战略布局，充分认识期货行业在脱贫攻坚战中应承担的政治责任与社会责任，提升行业服务脱贫攻坚的思想共识，汇聚全行业力量与智慧，以期货经营机构专业优势为依托，强化责任感、使命感和紧迫感，为服务国家脱贫攻坚战略做出应有的贡献。

（二）总体要求

全面把握资本市场服务国家脱贫攻坚战略的总体要求，鼓励期货经营机构热心参与扶贫事业，加强合作、优势互补，坚持因地制宜、分类施策，加快形成期货行业扶贫行动合力。充分发挥行业特有的风险管理专长，切实将扶贫工作与服务实体经济发展这一行业根本宗旨有效结合，形成期货行业扶贫特色，积极探索期货行业扶贫工作的长效机制。创新行业扶贫工作方法，丰富扶贫工作内容，多管齐下，多措并举，推动“精准脱贫”取得实效。通过建立和完善工作机制，强化考评，为期货经营机构助力脱贫攻坚创造良好的氛围。

二、鼓励积极参与，形成期货行业精准扶贫行动合力

（三）倡导结对搞帮扶

鼓励期货经营机构根据国务院扶贫开发领导小组办公室发布的《国家扶贫开发工作重点县和集中连片地区特殊困难地区县（合并）名单》，结合自身地缘特性、业务特点、人员优势及实际经营情况，合理选择帮扶对象，力争做到“机构联系到县、价格信息到乡、专业服务到村（或农民专业合作社）、帮扶效果到户”，开展精准扶贫。鼓励有条件的期货经营机构与贫困县或其所辖贫困乡（贫困村）结成对子，探索建立高管人员挂帅督导专项工作组等方式形成长效帮扶机制。期货经营机构应根据建档立卡贫困户的具体情况和实际需求，采取多种措施，帮助解决当地贫困人口在就业、就学、就医等方面的实际困难。期货业协会通过梳理贫困地区分布情况和需求特点，为期货经营机构选择帮扶对象提供帮助与引导。

（四）强化协作与配合

期货经营机构应加强与帮扶对象当地政府部门的合作，积极争取财政、税收等方面的政策优惠，推进工作联动。支持期货经营机构加强与保险及农村电商的合作，通过协同与配合，形成对帮扶对象支持的合力。鼓励期货经营机构参与股东单位、其他社会公益组织发起的扶贫活动，积极履行所担负的社会责任。鼓励期货经营机构发挥各自优势，开展联合扶贫工作，突出模范带头和示范作用。期货业协会应通过建立行业精准扶贫信息共享和经验交流机制，推动期货经营机构共享政策、信息、资源优势，发挥行业扶贫协同效应。

三、立足行业特色，发挥期货行业精准扶贫专业优势

（五）服务“三农”谋实效

期货经营机构应紧密结合国家关于农村农业改革政策精神和要求，充分发挥自身在价格管理、风险管理方面的专业优势，对贫困地区涉农主体进入期货市场开展套期保值业务进行培训，指导和扶持各类涉农主体利用期货市场降低生产经营风险。期货经营机构应积极探索建立农业补贴、涉农信贷、农业保险和农产品期货、场外期权等工具的联动机制，支持符合条件的贫困地区优先开展“保险+期货”试点，提高涉农企业、农民专业合作社等新型农业经营主体管理市场风险的能力。风险管理公司应以贫困地区实体经济需求为导向，运用风险管理专业知识，为涉农主体提供合作套保、仓单质押、仓单回购等专业定制化服务。

（六）助力产业结构优化

期货经营机构应积极落实国家有关“推进供给侧结构性改革”政策精神，贯彻国家“去产能、去库存、去杠杆、降成本、补短板”的有关要求，发挥期货市场价格发现和风险管理功能，帮助和引导贫困地区产业结构调整与企业转型升级。指导和帮助贫困地区实体企业利用期货及其他衍生工具管理价格、利率、汇率等风险，优化库存管理，锁定成本，提升盈利，改善企业生产经营，促进产业优化升级。

（七）强化期现对接与合作

鼓励期货经营机构利用其在现货领域积累的资源优势，结合贫困地区资源和产业特色，引导发达地区投资资金向贫困地区转移，努力促成发达地区与贫困地区的产业合作。鼓励期货经营机构与相关实体企业深化合作，探索在贫困地区联合建设期现结合典型的示范产业、示范基地和示范企业，为贫困地区企业利用风险管理工具改善经营方式、转换商业模式提供综合解决方案。鼓励期货经营机构与期货交易所加强合作，为贫困地区符合条件的仓储企业申请设立交割仓库提供必要的支持和帮助。鼓励风险管理公司做深做细业务内涵，结合贫困地区现货企业实际情况，运用企业易于理解和接受的期现结合创新业务模式，帮助与引导贫困地区现货企业直接或间接利用期货工具管理现货风险，提升企业的抗风险能力与盈利能力。

四、创新方式与内容，全面提升期货行业精准扶贫成效

（八）加大培训与宣传力度

支持期货经营机构在贫困地区开展以在校师生、从业人员、金融监管干部、企业管理人员、涉农主体等为主要对象的期货专业知识培训，提升贫困地区对期现业务的理解和认知水平，为贫困地区企业和客户利用期货市场管理风险提供智力帮扶，从而增强贫困地区脱贫致富的内生发展动力。支持期货经营机构结合贫困地区期货投资者特点，加强反洗钱、反欺诈、法制和诚信等方面的公益宣传和讲座，强化投资者教育，配合有关部门防范非法期货等违法金融活动，维护期货市场投资者合法权益。

（九）探索驻点帮扶路径

鼓励有条件的期货经营机构在贫困地区设立分支机构，选派有丰富经验的优秀人才任职，并以扶贫工作成效为重要考量完善考核激励机制，培育企业形成扶贫帮困的良好氛围，以更好地满足贫困地区的风险管理需求，改善贫困地区金融环境。鼓励期货经营机构及其分支机构在同等条件下，优先聘用贫困地区高校毕业生实习和就业，为贫困地区干部和金融人才提供挂职锻炼机会，并通过人才回流带动和帮助贫困地区实现精准脱贫。

（十）设立基金助力脱贫

鼓励有条件的期货经营机构参与设立扶贫基金、公益基金、慈善基金，在贫困地区开展形式多样的捐助和公益扶贫活动。期货业协会应建立相应机制，掌握上述基金的运作情况，并研究、推动行业扶贫基金的设立，支持期货行业精准扶贫工作的有效开展。

五、完善工作机制，保障期货行业精准扶贫落到实处

（十一）加强组织领导

期货业协会应设立期货行业扶贫工作机制，根据各期货经营机构报送的计划项目、公司自身实际对结对帮扶组合等有关情况进行统筹协调，并全力支持期货经营机构参与精准扶贫工作。期货经营机构应树立大局意识，强化责任担当意识，将精准扶贫工作纳入公司工作计划，订立明确的扶贫工作目标，明晰扶贫工作各级主体责任，细化执行和实施方案，加强扶贫工作督导，将扶贫工作情况纳入公司内部考核，建立正向激励制度，发挥基层党组织战斗堡垒作用。

（十二）完善考核体系

各期货经营机构应围绕具体投入、采取的措施、人员参与情况、专业帮扶落地情况以及受助对象脱贫实际定期向期货业协会报告扶贫工作开展情况，不得有信息造假、汇报不实。期货业协会应建立对期货经营机构扶贫工作进行巡查和评估的工作机制，针对各公司扶贫投入和实绩，进行定期和不定期的巡查，并进行综合评估，为分类评价提供公允的参考依据。期货业协会还应负责统一发布行业精准扶贫的社会责任报告。

（十三）营造良好环境

期货经营机构应不断强化对国家及证监会有关扶贫工作决策部署的内部学习、解读与宣讲，对扶贫工作有突出贡献的分支机构或个人给予公开表彰和奖励，定期向社会公布扶贫成效。期货业协会应通过座谈会、研讨会等形式总结行业扶贫经验并积极推广，树立行业精准扶贫、精准脱贫的先进典型，加大对行业优秀扶贫案例的对外宣传力度，营造全行业助力国家脱贫攻坚战略的良好氛围。
