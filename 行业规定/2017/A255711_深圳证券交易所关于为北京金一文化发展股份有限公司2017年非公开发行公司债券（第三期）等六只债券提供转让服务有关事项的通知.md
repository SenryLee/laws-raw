# 深圳证券交易所关于为北京金一文化发展股份有限公司2017年非公开发行公司债券（第三期）等六只债券提供转让服务有关事项的通知

## 关于为北京金一文化发展股份有限公司2017年非公开发行公司债券（第三期）等六只债券提供转让服务有关事项的通知

各会员单位：

北京金一文化发展股份有限公司2017年非公开发行公司债券（第三期）、 重庆福冠投资集团有限公司2017年非公开发行公司债券、长城证券股份有限公司2017年非公开发行公司债券（品种一）、 长城证券股份有限公司2017年非公开发行公司债券（品种二）、 河南华英农业发展股份有限公司2017年非公开发行公司债券（第一期）、河南华英农业发展股份有限公司2017年非公开发行公司债券（第二期）定于2017年9月28日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、北京金一文化发展股份有限公司2017年非公开发行公司债券（第三期）证券代码“114172”，证券简称“17金一03”，发行总额2.5亿元，票面利率9.3%，债券期限3年，附第1年末和第2年末发行人调整票面利率选择权和投资者回售选择权。

2、重庆福冠投资集团有限公司2017年非公开发行公司债券证券代码“114188”，证券简称“17福冠债”，发行总额2.2亿元，票面利率7.7%，债券期限3年，附第2年末发行人上调利率选择权和投资者回售选择权。

3、长城证券股份有限公司2017年非公开发行公司债券（品种一）证券代码“114198”，证券简称“17长证01”，发行总额22.2亿元，票面利率5%，债券期限3年。

4、长城证券股份有限公司2017年非公开发行公司债券（品种二）证券代码“114199”，证券简称“17长证02”，发行总额7.8亿元，票面利率5.08%，债券期限5年。

5、河南华英农业发展股份有限公司2017年非公开发行公司债券（第一期）证券代码“114222”，证券简称“17华英01”，发行总额0.5亿元，票面利率6.45%，债券期限3年，附第1、2年末发行人上调票面利率选择权和投资者回售选择权。

6、河南华英农业发展股份有限公司2017年非公开发行公司债券（第二期）证券代码“114223”，证券简称“17华英02”，发行总额3亿元，票面利率8%，债券期限2年。
