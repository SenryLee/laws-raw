# 深圳证券交易所关于为江苏徐工工程机械租赁有限公司2017年非公开发行公司债券（第一期）等五只债券提供转让服务有关事项的通知

## 关于为江苏徐工工程机械租赁有限公司2017年非公开发行公司债券（第一期）等五只债券提供转让服务有关事项的通知

各会员单位：

江苏徐工工程机械租赁有限公司2017年非公开发行公司债券（第一期）、 东旭集团有限公司2017年非公开发行公司债券（第二期）、远东国际租赁有限公司2017年非公开发行公司债券（第六期）、 广州合景房地产开发有限公司2017年非公开发行公司债券（第一期）（品种一）、 广州合景房地产开发有限公司2017年非公开发行公司债券（第一期）（品种二）定于2017年11月21日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、江苏徐工工程机械租赁有限公司2017年非公开发行公司债券（第一期）证券代码“114141”，证券简称“17徐工01”，发行总额6.2亿元，票面利率6.6%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

2、东旭集团有限公司2017年非公开发行公司债券（第二期）证券代码“114225”，证券简称“17东集02”，发行总额10亿元，票面利率7%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

3、远东国际租赁有限公司2017年非公开发行公司债券（第六期）证券代码“114228”，证券简称“17远东六”，发行总额28亿元，票面利率5.7%，债券期限5年，附第3年末发行人调整票面利率选择权及投资者回售选择权。

4、广州合景房地产开发有限公司2017年非公开发行公司债券（第一期）（品种一）证券代码“114231”，证券简称“17合景01”，发行总额10亿元，票面利率7.85%，债券期限5年，附第3年末发行人调整票面利率选择权和投资者回售选择权。

5、广州合景房地产开发有限公司2017年非公开发行公司债券（第一期）（品种二）证券代码“114232”，证券简称“17合景02”，发行总额20亿元，票面利率7.5%，债券期限3年，附第2年末发行人调整票面利率选择权和投资者回售选择权。
