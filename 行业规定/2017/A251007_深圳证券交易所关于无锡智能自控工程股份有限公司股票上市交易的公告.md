# 深圳证券交易所关于无锡智能自控工程股份有限公司股票上市交易的公告

## 关于无锡智能自控工程股份有限公司股票上市交易的公告

无锡智能自控工程股份有限公司人民币普通股股票将于2017年6月5日在本所上市。证券简称为“智能自控”,证券代码为“002877”。公司人民币普通股股份总数为122,240,000股，其中首次公开发行的30,560,000股股票自上市之日起开始上市交易。
