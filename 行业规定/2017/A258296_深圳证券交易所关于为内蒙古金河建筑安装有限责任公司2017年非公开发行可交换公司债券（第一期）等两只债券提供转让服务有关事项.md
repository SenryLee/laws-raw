# 深圳证券交易所关于为内蒙古金河建筑安装有限责任公司2017年非公开发行可交换公司债券（第一期）等两只债券提供转让服务有关事项的通知

## 关于为内蒙古金河建筑安装有限责任公司2017年非公开发行可交换公司债券（第一期）等两只债券提供转让服务有关事项的通知

各会员单位：

内蒙古金河建筑安装有限责任公司2017年非公开发行可交换公司债券（第一期）、深圳市宝德投资控股有限公司2017年非公开发行可交换公司债券（第三期）定于2017年12月5日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、内蒙古金河建筑安装有限责任公司2017年非公开发行可交换公司债券（第一期）证券代码“117082”，证券简称“17金河E1”，发行总额2亿元，票面利率：第一年0.5%、第二年0.8%、第三年15.2%，债券期限3年，附换股价格向下修正条款、换股价格向上修正条款、赎回条款和回售条款。

2、深圳市宝德投资控股有限公司2017年非公开发行可交换公司债券（第三期）证券代码“117099”，证券简称“17宝德E3”，发行总额1.89亿元，票面利率6.6%，债券期限1年，附换股价格向下修正条款和赎回条款。

深圳证券交易所

二○一七年十二月一日
