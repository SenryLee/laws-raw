# 国家电力公司关于颁发《中国一流电力公司考核标准(试行)》的通知

## 国家电力公司关于颁发《中国一流电力公司考核标准(试行)》的通知(1999年7月29日　国电发[1999]305号)

为了推进电力企业的“两个根本性转变”，适应社会主义市场经济体制的要求，国家电力公司决定：在巩固发、供电企业安全文明生产达标和创一流成果的基础上，继续深化创一流工作，努力创建一流电力公司。创建一流电力公司是电力企业适应市场要求，提高企业整体素质、不断加快电力发展的必然选择；是继续深化电力体制改革，加快现代企业制度建设，实现与国际先进管理水平接轨的内在需要；也是坚持以经济效益为中心，进一步降低成本，提高效率和效益，提高技术水平、经营水平、管理水平、服务水平，使企业更安全、更经济、更高效、更文明、更具竞争力的有效途径。创一流工作是企业管理的一项重要基础性工作。要把创一流工作与落实党中央关于改革、改组、改造和加强管理的要求紧密结合，扎扎实实做好工作。这项工作不是局部性、阶段性的工作，而是根本性、全局性、长远性的工作，具有重要的现实意义和深远的历史意义。

创建一流电力公司的指导思想是：高举邓小平理论的伟大旗帜，深入贯彻党的十五大精神，坚持两手抓、两手硬，以市场为导向，以安全文明生产为基础，以经济效益为中心，以改革为动力，以科技为先导，以优质服务为宗旨，以最大限度满足客户需求为目标，面向21世纪、面向国际，在实现中国一流电力公司的基础上，向国际一流电力公司迈进。

根据我国实际，创建一流电力公司，要分两步走。第一步，各电力公司经过2-3年的努力，达到中国一流电力公司标准；第二步，到2005年创国际一流电力公司取得突破，2010年在部分网省电力公司实现国际一流电力公司的基础上，国家电力公司实现创国际一流电力公司的目标。

为加快创建中国一流电力公司的步伐，努力赶超国际一流电力公司，现颁发《中国一流电力公司考核标准(试行)》(见附件)，各网省公司要认真学习标准，结合实际，制定规划，认真组织实施，把创一流电力公司工作扎扎实实地开展起来。

各网省公司在执行中遇到什么问题，请及时告国家电力公司发输电运营部。

中国一流电力公司考核标准(试行)

为了实现党中央提出的两个根本性转变，适应社会主义市场经济发展要求，依靠改革、改组、改造和加强管理，提高电力公司的科学管理水平和经济效益，更好地为国民经济和社会发展服务，根据国家电力公司关于创建中国一流电力公司的要求，特制订本考核标准。

**一、**必备条件

1.被考核的电力公司(以下简称公司)确立了以“更安全、更经济、更文明、更高效、更具竞争力”为目标，以依靠科技进步和提高劳动者素质为手段的改革与发展战略、中长期发展规划和近期实施计划，目标明确，措施具体，考核年度全面实现了改革与发展目标。重视电网建设和电源结构调整，认真落实国家电力公司关于限制小火电机组的部署，完成分年度停运中低压凝汽机组的计划任务。

2.坚持“安全第一”方针，考核年度和申报期内，不发生重大、特大人身死亡事故，包括发、供电生产、基建、多经系统的重大及以上人身死亡事故、重大火灾、电网瓦解、大面积停电、水电厂大坝和火电厂灰坝的垮坝、水电厂水淹厂房、核电站的核事故、基建重大质量事故和人员责任的重大及以上设备损坏事故。

3.坚持以经济效益为中心，全面完成公司的经营计划，完成中央和地方税收任务。考核年度公司实现无亏损经营。考核年度和申报期内不发生对社会造成重大影响、对生产力发展和国有资产保值增值造成重大损失的事件，不发生重大经营决策失误，不发生重大违纪事件。

4.深入开展达标、创一流工作，并取得显著成效。公司管理的(含代管)发、供电企业获得并保持部级安全文明生产达标的比例达到应达标企业的90%以上；公司调度机构获得并保持国家电力公司一流调度机构称号；公司所属发、供电企业至少有一个获得国家电力公司一流发、供电企业称号；“九五”期间及以后开工建设的发电厂、220kv及以上的输变电工程实现达标投产。

5.公司通过深化三项制度改革，实施人才工程，整体开展减人增效、下岗分流和再就业工作，建立了新的用人机制，实现了人员负增长和减人增效目标。在发展电力主导产业的同时，大力发展多种经营，培育新的经济増长点，按照纳入电力企业改革与发展战略的要求，统筹规划，合理布局，统一管理，使安置和经济效益均有显著提高。

6.认真贯彻党中央关于“改革、改组、改造和加强管理”的企业管理要求，确立管理是生产力的思想，建立了企业发展、经营管理、科技进步、人才培训、激励约束、监督管理和两手抓、两手硬等新机制，科学管理体系不断健全完善，企业管理水平和综合素质有了显著提高。

7.坚持“两手抓、两手都要硬”，物质文明建设与精神文明建设协调发展。公司领导班子坚持党的基本路线，坚持民主集中制，认真贯彻执行党和国家的各项方针政策。党政工关系协调，密切联系群众，团结进取，廉政勤政。具有较强的经营意识、法制意识和科技意识，德才兼备。领导班子成员无违法、违纪事件。公司获得并保持国家电力公司“双文明电力公司”称号或获得并保持了省(市)政府命名的“文明行业”称号。公司所属供电企业90%以上在优质服务、行风建设方面受到当地政府好评。

8.建立了完善的内部审计监督和约束机制，在考核期和申报期内，接受外部、各种稽查、审计、检查未发现重大违纪问题。

**二、**考核指标

中国一流电力公司考核指标共12部分，总标准分为1350分；另设一项加分指标(序号13，50分)，由申报公司提出加分申请，说明加分项目、加分理由及加分值，由国家电力公司认定，最高加分不超过50分。各项考核指标及标准分为：

**三、**适用范围

考核标准适用于国家电力公司系统的省电力公司和兼有省电力公司职能的集团公司(包括华能集团和华能国际)。

**四、**申报

1.申报条件

(1)具备所有必备条件；

(2)各项考核指标自查得分达到如下要求：不具备加分条件者，11项考核指标的得分率均≥80%；具备加分条件者，11项考核指标的得分率均≥75%，自查总分≥1030分(含国家电力公司认定的加分)。

2.申报资料

(1)填写《中国一流电力公司申报(复查)表》(见附表1)；

(2)中国一流电力公司自查报告：包括必备条件和各项考核指标的完成情况及自查评分；

(3)主要经济技术指标完成情况及计算依据；

(4)有关必备条件完成情况的证明材料。

上述材料均一式5份。

3.申报时间：

每年5月底之前向国家电力公司’申报。

**五、**考评验收与命名

1.“中国一流电力公司”由国家电力公司组织考评验收。

2.经考评验收，达到中国一流电力公司考核标准的电力公司，国家电力公司正式授予“中国一流电力公司”称号，并颁发奖牌和荣誉证书。

3.“中国一流电力公司”实行动态管理，不搞终身制。获得荣誉称号后，达不到考核标准要求的，国家电力公司提出限期整改要求，整改期满仍达不到要求的，将撤销其荣誉称号。

```
附录2：

电力科技三项指标统计计算方法(试行)

1.科技投入

电力企业的科技投入费用包括以下四部分：

(1)研究与开发费用(R&D)；

(2)中间试验及工业示范试验费用；

(3)科技成果转化及推广应用中的二次开发费用；

(4)在本单位科技部门立项的技改技措中属于技术进步部分的费用，此部分的费用比例由本单位科技部门报科教局核定。

2.科技投入产出比

科技项目按其产出效益形式的不同，分为可用货币计算的显性效益项目和难以用货币计算的隐性效益项目。如提高企业安全、环保和可靠性的科技项目即属于隐性效益项目，这类项目的科技投入产出暂不计算。

显性效益项目的科技投入产出比(RIO)的计算公式如下：

```
n

RIO= 1∶{ ∑　(Ei-Ci) ÷K}　　　(1)

i=1
```

式中：K为项目的总投资（入）（元）；

Ei，Ci分别为项目运行寿命内第i年的直接收效和运行成本（元）；

n为项目的运行寿命（年）。项目的运行寿命可参照原能源部对给类电力设备固定资产折旧年限的规定，以其规定的折旧年限的80%计算。

网省公司科技项目的投入产出比采用汇总方法计算，即所有显性项目的净收益与相应的总投入之和的比值即为该公司显性科技项目平均投入产出比。

3.科技进步贡献率

科技进步贡献率(Eα)采用增长速度议程(索洛余值法)计算，其计算公式如下：

```
Eα= (a/y)×100%　　　　(2)

α=y-ak-βi　　　　　　　　(3)
```

式中：α为技术进步速度(%)；

y为产出量增长速度(%)；

k为资产投入量增长速度(%)；

I为劳动人数增长速度(%)；

α为资金产出弹性系数，α取0.4；

β为劳动产出弹性系数，β取0.6。

产出量通过指标体系计算的工业增加值(前沿面工业增加值)来体现，计算步骤如下：

(1)前沿面销售收入＝不变售电价×[火电装机容量×火电等效可用系数×87.6×(1-水电厂用电率/100)-供热量×供热厂用电率]×(1-线损率/100)/107＋不变售热价×供热量/104

式中：不变电价和热价取1993年市场价格，单位为元/KKWh和元/MKJ

装机容量单位为万千瓦；

等效可用系数、厂用电率、线损率单位为%

供热量单位为万MKJ；

供热厂用电率单位为KWJ/MKJ。

(2)沿前面燃料成本＝不变标准煤单价×火电装机容量×火电等效可用系数×87.6×发电煤耗率/100＋供热量×供热煤耗率×10/108(亿元)。

式中：不变标准煤单价取1993年综合标煤单价，单位为元/吨；发电煤耗率单位为g/kWh；

供热煤耗率单位为kG/MKJ。

(3)前沿面工业增加值＝前沿面销售收入一前沿面燃料一成本销售费用一管理费用

增长速度(y，k，I)采用几何法(水平法)计算，基年选为1993年。例如1993年至1996年y的平均增长速度为：

```
Y= [(Y96/Y93)1/3 -1]×100%　　　　　　　(4)
```

资金投入量由固定资产原值与流动资金中的存货额之和来计算。其中，固定资产原值以1993年资产重估后的价值为基础，其后各年的固定资产原值新增部分应按基本建设价格上涨指数修正后加到前一年的原值中，作为这一年固定资产原值。

即：

```
Gt= Gt-1(Gt -Gt-1)×100%/价格指数(5)
```

流动资金的存货额主要指库存和在运燃料费，并按1993年标煤单价进行修正。

即：

```
Gt= Gt×1993年标煤单价/当年标煤单价
```

劳动人数取主业的劳动人数，即发供电和局本部人数之和，并应注意与1993年的统计口径一致。

在计算前沿面增加值、资金投入量、劳动力投入量时，必须注意数据统计口径的一致性。对已合资改制的企业，如其装机容量仍统计在电网内，则其相应的资产和劳动人数也应统计进来，如其资产只统计电网出资部分，则其容量和人数也只取电网出资比例的部分。剥离出主业的三产企业和试验研究、设计、修造企业，如其产值未统计到前沿面工业增加值中，则其人数和资产也不应计入。

科技进步贡献率的计算以1993年为计算基年，其他年份的产出和投入(包括销售费用和管理费用)均应根据当年度的物价上涨指数折算为1993年的不变价。
```
