# 国家电力公司关于颁发《超高压输变电企业一流企业考核标准(试行)》和《超高压输变电企业安全文明生产达标考核标准》的通知

## 国家电力公司关于颁发《超高压输变电企业一流企业考核标准（试行）》和《超高压输变电企业安全文明生产达标考核标准》的通知（1999年11月3日　国电发[1999]611号）

为了进一步提高超高压输变电企业安全生产、经济效益和整体素质，加强电网管理，保障电网安全、稳定、经济运行，国家电力公司决定在超高压输变电企业开展安全文明生产达标和创一流工作，现将《超高压输变电企业一流企业考核标准（试行）》和《超高压输变电企业安全文明生产达标考核标准（试行）》颁发给你们，自即日起实施。

附件1：

超高压输变电企业一流企业考核标准（试行）

为了进一步提高超高压输变电企业安全生产、经济效益和整体素质，在安全文明生产达标的基础上，加强两个文明建设，开展创建一流超高压输变电企业工作。根据原电力工业部电安生[1997]53号文的要求，结合超高压输变电企业的实际，特制定本考核标准。

**一、**必备条件

1.企业领导班子坚持党的基本路线，认真执行党和国家各项方针、政策和法律、法规。坚持民主集中制，全心全意依靠职工群众，推行厂务公开制度。党政关系协调，廉政务实，密切联系群众，无违法违纪事件。

2.坚持“两手抓、两手都要硬”的方针，两个文明建设协调发展，企业获得国家电力公司双文明单位，或经考核、验收符合国家电力公司双文明单位考核标准。

3.认真开展安全文明生产双达标工作，连续两年保持国家电力公司安全文明生产达标企业考核标准及称号。

4.考核年度和申报期内，企业未发生生产人身死亡事故或群伤事故；未发生特大事故；未发生本单位责任的主网稳定破坏、大面积停电重大事故；未发生企业责任的重大设备货故；未发生因电力运行事故而承担法律责任的案件。

5.主要技术指标先进：

所辖220kv及以上电压等级的变压器、断路器、输电线路的综合可用系数、强迫停运率应达到如下考核值：

5.1变压器

220kv及以上电压等级单台变压器可用系数

```

```

注：变压器综合可用系数计算公式见五、附录

5.2断路器

220kv及以上电压等级断路器综合强迫停运率≤5次/百台年。

5.3输电线路

220kv及以上电压等级输电线路综合可用系数≥98.50%。

注：断路器、输电线路综合强迫停运率、可用系数的具体算法详见《输变电设施可靠性统计评价规程》。

5.4不发生由500kv或330kv变电、输电责任事故引起的供电范围内220kv变电站全站停电事故。

6.坚持科技进步。生产调度自动化系统达到实用化标准和要求，并经上级有关单位验收合格。

7.提高科学管理水平，建成企业综合管理信息系统，经网、省（公司）验收合格投入应用。

8.实现减人增效目标，用人水平达到国家电力公司颁布的供电企业劳动定员标准的相应水平。分离人员组建的经济实体要实现独立核算、自负盈亏。

9.坚持优质服务，调度及相关单位满意率≥95%。

10.完成年度经营目标，企业不发生经营性亏损，并通过审计。考核年度和申报期内，不发生因企业行为引起的违反国家财经法规的重大事件。

**二、**考评内容及验收标准

1.考评内容和分值

（1）安全管理满分200分

（2）文明生产满分100分

（3）设备和生产管理满分200分

（4）节能管理满分100分

（5）科技进步满分100分

总分：700分

其中安全管理、设备和生产管理按工作实绩指标和工作质量指标两项考核。

2.验收标准

申报一流超高压输变电企业必须同时满足以下两个条件：

（1）具备所有必备条件；

（2）各项（分项）考评得分率均在90%及以上。

3.考核内容及评分规定见附件。

**三、**申报与验收命名

（一）申报

1.申报条件

（1）年供电量（含输送过境电量）在50亿千瓦时及以上的超高压输变电企业；

（2）申报企业必须同时具备十条必备条件，并通过自检达到五项考核内容的验收标准。

2.申报材料包括：

（1）填写《超高压输变电企业一流企业申报表》，一式5份。

（2）申报企业的《自检报告》，各项指标实绩及说明。

（3）其他必要的证明材料和基础材料。

（二）验收命名

1.企业自检合格申报后，由网（省）电力公司组织初检验收，并对申报材料进行审查，初检及审查合格后由网（省）电力公司于每年3月底以前向国家电力公司申报，同时上报一流企业的申报材料，由国家电力公司组织考核、命名。

2.一流超高压输变电企业的考核验收工作每年进行一次，对被命名的一流超高压输变电企业由国家电力公司颁发证书和奖牌，予以表彰奖励。具体奖励办法由主管网（省）电力公司自订。

3.考评、验收工作要严肃认真，坚持标准，实事求是，客观公正，要认真核实有关数据、资料、凭证的正确性、真实性和有效性。

4.一流超高压输变电企业实行动态考核，不搞终身制，各网（省）局（公司）对一流企业每年复核一次，发现达不到标准的，要限期整改，整改期满仍达不到标准的，由网（省）公司提出意见，按原申报验收程序报批，撤销其一流企业称号。

5.凡弄虚作假者，一经发现，在申报过程中取消申报资格。已审定的，由评审验收部门撤销其称号，并追究有关人员的责任，情节严重的给予相应的纪律处分。

**四、**本考核标准解释权属国家电力公司

```
∑某台变压器可用系数考核值×该变压器统计台年

某电压等级变压器综合可用系数（AFX）= -----------------------------------------------

∑某变压器统计台年
```

再计算出企业管辖范围内不同电压等级变压器的综合可用系数考核值：

```
∑AFX×该电压等级变压器统计百台年

变压器综合可用系数考核值（AF）= ---------------------------------------

∑该电压等级变压器统计百台年
```

注：公式中X系指220kV、330kV和500kV各电压等级

超高压输变电企业安全文明生产达标考核标准（试行）

为了促进超高压输变电企业安全、文明生产工作，提高劳动生产率和经济效益，根据原电力工业部《关于全面开展发供电企业安全、文明生产达标工作的决定》和《安全文明生产达标企业标准》特制订本考核标准。

**一、**必备条件

1.企业领导班子坚持党的基本路线，认真执行党和国家各项方针、政策和法律、法规。坚持民主集中制，全心全意依靠职工群众，推行厂务公开制度。党政关系协调，廉政务实，密切联系群众，无违法违纪事件。

2.考核年度和申报期内，企业未发生生产人身死亡事故或性质严重的群伤事故；未发生本企业责任的特大、重大设备事故和本单位责任的主网稳定破坏、大面积停电事故。

3.主要技术指标先进：

所辖220kv及以上电压等级的变压器、断路器、输电线路的综合可用系数（强迫停运率）应达到如下达标值：

3.1变压器

220kv及以上电压等级单台变压器可用系数

```

│电压等级（千伏）　　　　　　　　　　　　│无大修　　　　　　│有大修　　　　　　　│

├────────────────────┼─────────┼──────────┤

│330、500单相变　　　　　　　　　　　　　│99.00%　　　　　　│97.00%　　　　　　　│

├────────────────────┼─────────┼──────────┤

```

注：变压器综合可用系数计界公式见六·附录

3.2断路器

220kv及以上电压等级断路器强迫停运率≤7次/百台·年。

3.3输电线路

220kv及以上电压等级输电线路可用系数≥98.0%。

3.4不发生由500kv或是330kv变电、输电责任事故引起的所辖220kv变电站全站停电事故。

4.坚持科技进步。调度自动化系统达到实用化标准，并按规定验收合格。

5.考核年度获得省、地（市）级文明单位或者获得网（省）局双文明单位称号。

**二、**达标考评内容及验收标准

1.考评内容包括：安全管理；文明生产；设备和生产管理；节能与技术进步共四项。其中安全管理、设备和生产管理两项内容按工作实绩指标和工作质量两个部分考核。

2.达标验收标准：对四项考评内容均采用综合评分办法，每项考评满分分别为200分（或100分），各项（或分项）考评得分率均在85%以上者方可申报国家电力公司达标企业。

**三、**考核内容及评分规定

见附件。

**四、**达标申报与验收命名

（一）企业达标申报

1.申请国家电力公司达标的企业，必须具备五条必备条件，四项考评内容并自查合格。

2.申报材料应包括：

（1）填写统一的《超高压输变电企业安全文明生产达标申请表》（见附表）一式五份。

（2）申请企业的《自查报告》，各项指标实绩及计算说明。

（3）其他必要的证明材料和基础材料。

（二）企业达标验收

1.超高压输变电企业达标申报后由网（省）公司组织考评验收，报国家电力公司命名。必要时国家电力公司组织抽查验收。网（省）公司于每年3月底前将考评结果报国家电力公司。

2.超高压输变电企业达标的考评工作每年进行一次，在《中国电力报》公布结果，对达标企业予以表彰奖励，具体奖励办法由主管网（省）公司自订。

3.考评、评审验收工作要严肃认真，坚持标准，实事求是，客观公正，要认真核实有关数据、资料、凭证的正确性、真实性和有效性。

4.达标企业实行动态考核，不搞终身制。各网（省）公司对达标企业每年复核，发现达不到标准的，要及时研究，限期整改，到期考核仍达不到标准的，由网（省）公司提出意见，按原申报验收程序报批，撒销达标企业称号。

5.凡弄虚作假者，一经发现，在申报过程中的，取消申报资格；已审定的，由评审验收部门撤销称号并追究有关人员的责任，给予相应的纪律处分。
