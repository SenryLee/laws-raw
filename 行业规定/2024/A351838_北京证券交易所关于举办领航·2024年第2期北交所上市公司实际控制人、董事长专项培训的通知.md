# 北京证券交易所关于举办领航·2024年第2期北交所上市公司实际控制人、董事长专项培训的通知

## 关于举办领航·2024年第2期北交所上市公司实际控制人、董事长专项培训的通知

各上市公司：

为加强对上市公司实际控制人、董事长的规范引导，增强“关键少数”的“敬畏上市”意识，推动上市公司高质量发展，提升上市公司投资价值，北京证券交易所拟于9月26日在南京举办领航·2024年第2期北交所上市公司实际控制人、董事长专项培训。具体安排如下：

**一、**培训时间、地点

培训时间：2024年9月26日

培训地点：南京金鹰珠江壹号国际酒店（南京市玄武区珠江路1号）

**二、**培训对象

北交所上市公司、在审企业实际控制人、董事长，每家公司限报2人，培训名额有限，额满截止。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| **领航·2024年第****2****期北交所上市公司实际控制人、董事长专项培训** | | | |
| **时间** | | **课程内容** | **主讲人** |
| 9月26日  （周四） | 09:00-10:00 | 新“国九条”下上市公司监管情况及  监管政策解读 | 中国证监会  公众司专家 |
| 10:00-11:00 | 加强规范运作提高公司质量 | 北京证券交易所  上市公司管理部专家 |
| 11:00-12:00 | 上市公司如何做好公共关系管理 | 全景网专家 |

**四、**报名时间及方式

本次培训需收集报名信息，请您扫码或点击链接进行报名。请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、公司代码、报名人员信息及取消原因等）。报名成功后，未经请假缺席培训的人员，将被记入培训诚信档案并反馈监管机构。

报名截止时间：2024年9月24日（周二）12:00，过期或额满后报名不再受理，请务必尽早完成报名。

**五、**培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费、停车费及其他费用请学员自理。如需预定培训酒店住宿请联系俞经理18805140174，并报北交所获取协议价。

**六、**培训考勤

必须学员本人参加培训，他人不得替代，请学员带好身份证，以便考勤时验证。

课务组每半天进行考勤并形成培训记录，缺勤情况将反馈监管机构，请学员提前做好安排，保证全程参与。

**七、**温馨提示

1.培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
