# 北京证券交易所关于举办领航·2024年第3期北交所上市公司董事会秘书专项培训的通知

## 关于举办领航·2024年第3期北交所上市公司董事会秘书专项培训的通知

各上市公司：

为深入贯彻落实中央金融工作会议精神和《国务院关于加强监管防范风险推动资本市场高质量发展的若干意见》，强化上市公司董事会秘书的合规意识，提高上市公司信息披露质量和规范运作水平，助力上市公司高质量发展，北京证券交易所拟于7月18日在上海举办领航·2024年第3期北交所上市公司董事会秘书专项培训。具体安排如下：

**一、**培训时间、地点

培训时间：2024年7月18日

培训地点：上海虹桥雅高美爵酒店（仙霞路369号）

**二、**培训对象

北交所上市公司董事会秘书，培训名额有限，额满截止。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| **领航·2024年第3期北交所上市公司董事会秘书专项培训** | | | |
| **时间** | | **内容** | **主讲人** |
| 7月18日  （周四）  于上海 | 09:00-10:00 | 新“国九条”上市公司监管政策解读 | 中国证监会公众司  专家 |
| 10:00-11:00 | 上市公司信披违规处罚案例警示 | 中国证监会处罚委  专家 |
| 11:00-12:00 | 提升信披质量，做好半年报披露工作 | 北交所上市公司管理部  业务骨干 |
| 14:00-15:00 | 新《公司法》中上市公司治理重点问题解析 | 北交所法律事务部  业务骨干 |
| 15:00-16:30 | **行业研讨沙龙**  主题：数字经济行业研讨沙龙 | 行业专家主题分享 |
| 16:30-17:30 | 公司互动交流 |

注：最终培训内容以实际课程安排为准

**四、**报名时间及方式

本次培训需收集报名信息，请填写真实信息及有效联系方式，我们将在培训前通过手机短信将审核结果、培训具体地址发送至报名人员。因培训名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、证券代码、报名人员及取消原因等信息）。报名成功后，如未参与培训，相关情况将反馈任职公司并影响后续培训资格。

报名截止时间：2024年7月16日（周二）17:00，过期或额满后报名不再受理，请务必尽早完成报名。

**五、**培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费、停车费及其他费用请学员自理。如需预定培训酒店住宿请联系黄经理13482015805，并报北交所获取协议价。

**六、**培训考勤

课务组每半天进行考勤并形成培训记录，缺勤情况将反馈任职公司，请学员提前做好安排，保证全程参与。

**七、**温馨提示

1.培训期间课务组不会组织与培训无关的活动，请学员注意个人财产安全和食品安全。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。

**八、**联系方式
