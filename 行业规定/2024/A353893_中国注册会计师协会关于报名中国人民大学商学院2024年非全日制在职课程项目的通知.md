# 中国注册会计师协会关于报名中国人民大学商学院2024年非全日制在职课程项目的通知

各省、自治区、直辖市注册会计师协会，各会计师事务所，各相关单位：

为进一步贯彻落实《关于加强新时代注册会计师行业人才工作的指导意见》（财会〔2022〕21号）精神，培养行业和会计师事务所国际化发展管理人才，我会联合中国人民大学在“中国人民大学商学院2024年非全日制在职课程”开放企业管理专业和会计学专业报名通道，符合条件的人员可以免试入学，在职学习，考试压力分散，申硕成功后可获得中国人民大学管理学硕士学位（单证）。现将相关事项通知如下。

**一、**招生计划

（一）企业管理专业：计划招生200人。

（二）会计学专业：计划招生100人。

招生计划以教育部最终下达人数为准。

**二、**报名条件

（一）拥护《中华人民共和国宪法》，遵守法律、法规，能坚持在职学习者。

（二）大学本科毕业、并获得学士学位满三年，已获得硕士及以上学位者无年限要求。

（三）大专学历者，可参加课程班的学习，获得结业证书。

**三、**报名

（一）可选专业。

1.企业管理专业（含5个选修方向、每位学员选择一个方向攻读）。

|  |  |  |
| --- | --- | --- |
| **学科基础课**  **（11门必修）** | 管理学原理*、企业战略管理*、市场营销管理*、公司财务管理*、语言基础（英语）*  学术规范与论文写作、管理经济学、组织行为理论与研究方法、人力资源管理、企业会计、新时代中国特色社会主义理论与实践 | |
| **专业课**  **（五选一）** | 企业管理方向 | 运营管理、商法、商业模式设计与变革、资本市场理论与实务 |
| 人力资源管理方向 | 人员素质测评、劳动关系与劳动法、绩效与薪酬管理、人力资源开发与培训 |
| 财务金融方向 | 金融学、财务报表分析、税务筹划、企业集团财务管控 |
| 项目管理方向 | 项目管理、项目风险管理、质量管理、项目时间管理与成本管理 |
| 市场营销方向 | 消费者行为、品牌管理、市场研究、电子商务与数字化营销 |
| **注：其中标注*课程为全国统考所涉及的科目** | | |

2.会计学专业。

|  |  |
| --- | --- |
| **学科基础课**  **（11门必修）** | 管理学原理*、企业战略管理*、市场营销管理*、财务管理理论*、语言基础（英语）*  学术规范与论文写作、会计理论与方法、审计理论与方法、财务报表分析、会计准则理论与实务、新时代中国特色社会主义理论与实践 |
| **专业课** | 商业智能与管理会计、商业数据分析、Python、智能会计 |
| **注：其中标注*****课程为全国统考所涉及的科目** | |

（二）班级设立。

企业管理专业在线班（在线班）；

企业管理专业秋季班（北京面授）；

企业管理专业深圳班（深圳面授）；

企业管理专业华东班（苏州面授）；

会计学专业班（面授+在线）。

（三）报名时间。

报名时间自通知宣发之日起至2024年12月15日（周一至周五 9：00-16：00）。

（四）报名流程。

电话或微信咨询——报名资料提交初审——缴费报名——开学典礼——入班学习。

**四、**初审资料

学历、学位证书、身份证、在职证明扫描件，以人大商学院招生老师沟通结果为准。

**五、**录取学习

（一）学习方式。

1.面授与自学相结合，课程教学时间一年半。

2.每月1-2个周末上课，遇校内统一考试、寒暑假或节假日顺延。

（二）学费。

学费共计为59,800元。学员如为中国注册会计师协会会员、注册会计师行业从业人员，或者各级注册会计师协会在职工作人员，经中国注册会计师协会审核确认后，学费可减免至50,000元（行业相关报名人员整体人数需≥6人）。

（三）学时抵免。

如学员为中国注册会计师协会会员、注册会计师行业从业人员，或者各级注册会计师协会在职工作人员，可向所在地省级注册会计师协会申请抵免继续教育学时。

**六、**咨询及报名方式

人大商学院 陈老师：010-62515737，18800035986（同微信）。
