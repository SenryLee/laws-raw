# 全国股转公司关于举办远航·2024年第2期挂牌公司实际控制人、董事长专项培训的通知

## 关于举办远航·2024年第2期挂牌公司实际控制人、董事长专项培训的通知

各挂牌公司：

为向挂牌公司实际控制人、董事长传递最新监管政策，帮助其提升守法意识、规范意识，促进挂牌公司持续健康发展，全国股转公司拟于9月26日在北京举办远航·2024年第2期挂牌公司实际控制人、董事长专项培训。具体安排如下：

**一、**培训时间、地点

培训时间：2024年9月26日

培训地点：北京朝阳宾馆（北京市朝阳区小庄金台西路8号）

**二、**培训对象

挂牌公司实际控制人、董事长，每家公司限报2人，培训名额有限，额满截止。

**三、**培训课程

|  |  |  |
| --- | --- | --- |
| 时间 | 课程内容 | 主讲人 |
| 09:30-10:30 | 新“国九条”下挂牌公司监管政策解读 | 中国证监会公众司专家 |
| 10:30-11:30 | 挂牌公司信息披露、规范治理要求及监管重点解析 | 全国股转公司  挂牌公司管理一部  业务骨干 |
| 13:30-14:30 | 挂牌公司合规交易重点问题及违规案例分析 | 全国股转公司  挂牌公司管理一部  业务骨干 |
| 14:30-15:30 | 新《公司法》下实控人的角色与责任 | 全国股转公司  法律事务部  业务骨干 |
| 15:30-16:30 | 协同融合——产业链并购整合解析 | 中关村大河  并购重组研究院  院长 |

注：最终培训内容以实际课程安排为准

**四、**报名时间及方式

本次培训需收集报名信息，请填写真实信息及有效联系方式，我们将在培训前通过手机短信将审核结果、培训具体地址发送至报名人员。因名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、证券代码、报名人员信息及取消原因等）。

报名截止时间：2024年9月24日（周二）12:00，过期或额满后报名不再受理，请尽早完成报名。

**五、**培训费用

本次培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费、停车费及其他费用请学员自理。

**六、**培训考勤

请学员本人参加培训，他人不得替代，请学员带好身份证，以便考勤时验证。课务组将进行考勤并形成培训记录，未经请假缺席培训的学员将被记入培训诚信档案并反馈监管机构。

**七、**温馨提示

1.培训期间课务组不会组织与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
