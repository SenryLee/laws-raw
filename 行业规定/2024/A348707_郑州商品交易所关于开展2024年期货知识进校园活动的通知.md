# 郑州商品交易所关于开展2024年期货知识进校园活动的通知

## 关于开展2024年期货知识进校园活动的通知

郑商函〔2024〕250号

各投资者教育专项工作合作单位：

为传播期货期权知识，推动投资者教育纳入国民教育体系，推广第七届“郑商所杯”全国大学生金融模拟交易大赛（以下简称“郑商所杯”），规范开展郑州商品交易所（以下简称郑商所）期货知识进校园活动，现将有关事项通知如下。

**一、**总体要求

（一）投资者教育专项工作合作单位（以下简称合作单位）应根据《郑州商品交易所投资者教育专项工作管理办法》（以下简称《管理办法》）及本通知要求，积极与高校沟通，讲授期货期权知识，加强“郑商所杯”推广力度，规范举办活动。

（二）开展活动时，合作单位应遵循以下规范：

1.不使用有误导性、煽动性或诋毁性的语言；

2.不向学生收取费用，不对外泄露参加活动学生个人信息，不借“郑商所杯”为学生开通真实账户，不为“郑商所杯”设置额外门槛或要求；

3.不将郑商所作为活动主办方，但明确郑商所为活动支持单位。

**二、**活动安排

（一）活动高校范围

全国普通高校。

（二）活动时间

自本通知发布之日起，结束时间另行通知。

（三）举办步骤

1.发布实习信息

5月20日前，通过合作单位的衍生品学苑网站账号，发布2023年承诺的实习岗位信息（具体数量请各单位查询本单位留存资料）。未按要求发布实习岗位的，郑商所不再支持该合作单位开展本年期货知识进校园活动。

2.申报对接高校

5月20日前，通过衍生品学苑网站的对接高校申报系统填写并提交对接申报信息。

郑商所将参考历史活动效果、实习情况、申报时间等因素，在5月23日前确认对接关系，并在郑商所投教联系群（微信群）及“郑商所杯”联系群（钉钉群）公布。如确认对接关系后，因合作单位原因无法在对接高校举办活动等情况的，其他合作单位可再次申请与该高校对接。

3.举办活动

合作单位通过本单位的衍生品学苑网站账号，在“期货知识进校园”申报系统按照步骤提示申请、举办活动。

（四）活动形式

1.互动性学习活动

（1）主要方式

举办直播、讲座、上机模拟、研讨会等，为学生讲解期货知识，进行风险教育，答疑解惑。

（2）申报要求

每场线上活动观看人数不得少于100人；每场线下活动参加人数不得少于20人；申请“线上+线下”活动支持的,须同时满足线上及线下活动要求。

（3）场次要求

合作单位可在每所高校申请不超过4场活动。确有超额需求，需提前与郑商所沟通。

（4）活动主题

合作单位须结合学校培养方案及学生基础，以下表中所列主题开展活动。每场活动至少讲述1个主题，讲解内容以郑商所上市品种为例。申报其他主题，须提前与郑商所沟通。

表 2024年期货知识进校园知识普及主题

|  |  |  |
| --- | --- | --- |
| 序号 | 主题 | 备注 |
| 1 | 期货市场发展情况、相关法律法规及交易规则 | 必讲内容，讲师须理解相关内容 |
| 2 | 风险教育（包括风险揭示、风险识别、自我保护等） | 必讲内容，讲师须理解相关内容 |
| 3 | 企业运用期货工具管理风险案例（包括但不限于基差交易、套期保值、“保险+期货”等案例） | 必讲内容，讲师须有相关经验 |
| 4 | 商品期货投资研究框架及方法 | 可向有期货基础的学生讲授，讲师须理解相关内容 |
| 5 | 期权基本理论与策略应用 | 可向有期货基础的学生讲授，讲师须理解相关内容 |
| 6 | “郑商所杯”报名方法、软件下载及使用方法、比赛规则及评分指标 | 必讲课程，须与其他主题结合讲授 |
| 7 | 期货市场信息获取常用的平台和渠道 | 务必确保推荐平台合法正规，与其他主题结合讲授 |

（5）活动流程

①与高校沟通，确定举办主题、时间等，通过衍生品学苑进行活动申请；

②申请通过后，按申请内容举办活动；

③活动结束15个工作日内在衍生品学苑，按照《管理办法》要求及时上传审核材料（相关表格须加盖单位及高校印鉴）。

2.其他活动

根据实际情况，郑商所与具有项目承办资格的合作单位沟通，策划组织高校学生调研等其他活动，合作单位应按要求提交项目申请及总结等材料。

郑商所择优支持上述活动。
