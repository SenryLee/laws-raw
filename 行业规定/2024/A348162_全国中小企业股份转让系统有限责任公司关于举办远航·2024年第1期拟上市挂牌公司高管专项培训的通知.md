# 全国中小企业股份转让系统有限责任公司关于举办远航·2024年第1期拟上市挂牌公司高管专项培训的通知

## 关于举办远航·2024年第1期拟上市挂牌公司高管专项培训的通知

各挂牌公司：

为贯彻落实新“国九条”及配套政策，帮助拟上市公司树立正确“上市观”，准确把握审核监管要求，掌握上市进程中相关实务操作，引导符合条件的挂牌公司尽早实现规范上市，全国股转公司拟于5月24日在杭州举办远航·2024年第1期拟上市挂牌公司高管专项培训。具体安排如下：

一、培训时间及地点

1.培训时间：2024年5月24日

2.培训地点：浙江省杭州市西湖区三深国际中心（杭州市西湖区双龙街99号）

二、培训对象

拟申报北交所上市的挂牌公司下列人员：实际控制人、董事长、总经理、财务总监、董事会秘书或其他高级管理人员。每家公司限报2人，培训名额有限，额满截止。

三、培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 远航·2024年第1期拟上市挂牌公司高管专项培训 | | | |
| 时间 | | 内容 | 主讲人 |
| 5月24日（周五） | 09:00-10:00 | 新“国九条”严把发行上市准入关  监管政策解读 | 中国证监会  公众司专家 |
| 10:10-12:00 | 北交所发行上市审核重点解析 | 北京证券交易所  上市审核中心  业务骨干 |
| 14:00-15:30 | IPO财务及内控重点问题解析 | 毕马威会计师事务所  合伙人 |
| 15:40-17:00 | 高效衔接上市要求及持续监管　关注要点 | 全国股转公司  挂牌公司管理一部  业务骨干 |

注：最终培训内容以实际课程安排为准

1.报名时间：请于 2024年5月22日（周三）12:00前完成报名。培训名额有限，额满为止，请尽早完成报名。

2.报名方式：请扫码或点击链接进行报名。

五、培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿、交通及其他费用请自理。

六、培训考勤

请学员提前做好安排，保证全程参与。课务组将进行考勤并形成培训记录，未按计划参训、缺勤等情况将反馈任职公司，并影响后续培训资格。

七、温馨提示

1.培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
