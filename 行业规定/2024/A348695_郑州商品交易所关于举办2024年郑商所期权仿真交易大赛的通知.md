# 郑州商品交易所关于举办2024年郑商所期权仿真交易大赛的通知

## 关于举办2024年郑商所期权仿真交易大赛的通知

郑商函〔2024〕203号

各相关单位：

为进一步提升投资者期权交易操作能力及风险意识，帮助投资者了解如何使用期权工具，郑州商品交易所（以下简称郑商所）拟举办2024年郑商所期权仿真交易大赛，具体通知如下。

**一、**参与对象

有意愿组织参与并提交报名申请的会员单位。

**二、**参与方式

会员单位填写《2024年郑商所期权仿真交易大赛合作会员单位申请表》（见附件）并加盖单位印鉴，将电子版和盖章扫描版上传至衍生品学苑申报系统。系统通过后，即成为本次大赛合作方。

合作方应积极组织投教活动，普及期权基础知识，帮助投资者了解如何使用期权工具对冲风险，引导投资者注册仿真账户并进行仿真交易。合作方应做好与郑商所仿真交易系统的对接及测试。

**三、**时间安排

本次期权仿真交易大赛分为三个赛段，参评优秀合作方奖的合作单位可参与一个或多个赛段。

表1 大赛时间安排

|  |  |
| --- | --- |
| 阶段 | 具体日期 |
| 第一赛段 | 5月1日至6月30日 |
| 第二赛段 | 7月1日至8月31日 |
| 第三赛段 | 9月1日至10月31日 |

**四、**奖项设置

本次期权仿真交易大赛共设3个奖项。一是优秀合作方奖，每赛段结束后根据合作方参赛情况进行综合排名，评出一等奖1名、二等奖2名和三等奖3名；二是新品种（新工具）推广奖5名，对积极宣传并交易2022年（含）以来上市新品种（新工具）的期货公司给予奖励；三是优秀成长奖10名，对积极参与仿真大赛且成长较快的期货公司给予奖励。

表2 大赛奖项设置

|  |  |  |  |
| --- | --- | --- | --- |
| 时间 | 奖项 | 数量（个） | 奖励 |
| 每赛段评选  （共3个赛段） | 优秀合作方奖一等奖 | 1 | 1.证书；  2.费用支持1：50000元/个。 |
| 优秀合作方奖二等奖 | 2 | 1.证书；  2.费用支持：30000元/个。 |
| 优秀合作方奖三等奖 | 3 | 1.证书；  2.费用支持：20000元/个。 |
| 全期比赛  结束后 | 新品种（新工具）推广奖 | 5 | 1.证书；  2.费用支持：10000元/个。 |
| 优秀成长奖 | 10 | 1.证书；  2.费用支持：10000元/个。 |
| 共计 |  | | 66万元 |
| 各获奖单位将在郑商所年度优秀会员评选中给予加分。 | | | |

1.费用支持：票据金额，下同。

**五、**注意事项

郑商所有权对比赛过程及结果进行监督，确保比赛有序开展。对于存在异常交易等扰乱比赛秩序行为的合作方，郑商所有权取消其参与资格。
