# 北京证券交易所、全国股转公司关于举办2024年第3期北交所“三服务-赋能专精特新助力新质生产力”启航培训的通知

## 关于举办2024年第3期北交所“三服务-赋能专精特新 助力新质生产力”启航培训的通知

各市场主体：

为支持专精特新企业高质量发展，推动专精特新企业利用资本市场做优做强，在工业和信息化部中小企业局支持下，北京证券交易所、全国股转公司联合浙江省经信厅、浙江证监局于7月18日在杭州举办2024年第3期北交所“三服务-赋能专精特新 助力新质生产力”启航培训，具体安排如下：

一、培训时间、地点

培训时间：2024年7月18日

培训地点：杭州西溪宾馆（西湖区文二西路803号）

二、培训对象

拟挂牌上市的国家级专精特新“小巨人”企业董事长、总经理等负责挂牌上市事宜的高级管理人员，每家公司限报2人。

三、培训课程

|  |  |  |
| --- | --- | --- |
| **时间** | **课程内容** | **主讲人** |
| 09:00-10:00 | 浙江省支持专精特新企业高质量发展政策措施  解读 | 浙江省经信厅中小企业处负责人 |
| 10:00-11:00 | 高质量建设北交所  助力企业走专精特新发展之路 | 北交所华东基地  相关负责人 |
| 11:00-12:00 | 新三板挂牌审查制度及审核关注要点解析 | 全国股转公司挂牌审查部  相关负责人 |
| 14:00-15:00 | 提升专精特新企业投资价值的方法与路径 | 普华资本董事总经理 |
| 15:00-16:00 | 北交所上市流程介绍及规范性问题解析 | 财通证券投资银行委员会  主任 |
| 16:00-16:30 | 专精特新企业北交所上市经验分享 | 北交所上市公司  相关负责人 |

注：最终培训内容以实际课程安排为准

1、培训期间课务组不会组织与培训无关的活动，请学员注意个人财产安全和食品安全。
