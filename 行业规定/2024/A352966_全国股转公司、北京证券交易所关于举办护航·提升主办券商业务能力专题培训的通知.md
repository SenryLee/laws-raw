# 全国股转公司、北京证券交易所关于举办护航·提升主办券商业务能力专题培训的通知

## 关于举办护航·提升主办券商业务能力专题培训的通知

各主办券商（保荐机构）：

为深入贯彻落实党的二十届三中全会精神及《国务院关于加强监管防范风险推动资本市场高质量发展的若干意见》中关于推动证券服务机构高质量发展相关要求，加强证券行业能力建设，全国股转公司、北京证券交易所拟于11月20日在北京举办护航·提升主办券商业务能力专题培训，帮助主办券商（保荐机构）强化合规意识，进一步加强对北交所创新性信息披露要求的理解，并做好相关贯彻执行工作。具体安排如下：

**一、**培训时间、地点

培训时间：2024年11月20日

培训地点：北京朝阳宾馆（朝阳区小庄金台西路8号）

**二、**培训对象

主办券商（保荐机构）从事推荐挂牌、融资并购、发行上市及相关质控内核业务人员，培训名额有限，额满截止。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 护航·提升主办券商业务能力专题培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 11月20日于北京 | 09:00-10:00 | 证券从业人员职业道德与职业操守提升 | 中国证券业协会  专家 |
| 10:00-11:30 | 挂牌准入制度解读及挂牌审查常见问题解析 | 全国股转公司  挂牌审查部  业务骨干 |
| 14:00-15:30 | 融资并购制度解读及相关案例解析 |

| 16:30-17:30 | 《发行上市审核动态（创新性评价专刊）》解析 | 北交所上市审核中心  业务骨干 |

**四、**报名时间及方式

本次培训需收集报名信息，请您扫码或点击链接进行报名。因培训名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（取消说明内容需涵盖报名场次、公司名称、报名人员信息及取消原因等）。报名成功后，如未参与培训，相关情况将反馈任职公司并影响后续培训资格。

报名截止时间：2024年11月18日（周一）12:00，过期或额满后报名不再受理，请务必尽早完成报名。

**五、**培训费用

培训不收取培训费。餐费、住宿费、交通费、停车费及其他费用请学员自理。

**六、**培训考勤

课务组将进行考勤并形成培训记录，缺勤情况将反馈任职公司，请学员提前做好安排，保证全程参与。

1.培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人信息安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请勿录音录像及外传培训内容。
