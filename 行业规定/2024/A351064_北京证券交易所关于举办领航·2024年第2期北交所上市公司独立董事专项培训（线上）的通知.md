# 北京证券交易所关于举办领航·2024年第2期北交所上市公司独立董事专项培训（线上）的通知

## 关于举办领航·2024年第2期北交所上市公司独立董事专项培训（线上）的通知

各上市公司：

为更好贯彻落实《国务院办公厅关于上市公司独立董事制度改革的意见》《上市公司独立董事管理办法》，帮助上市公司独立董事理解制度改革要求，增强规范运作意识，提升风险识别能力，提高自身履职水平，北京证券交易所拟于8月20日在线举办领航·2024年第2期北交所上市公司独立董事专项培训。具体安排如下：

**一、**参会人员

北交所上市公司独立董事，参会情况将纳入培训学习记录。欢迎其他高级管理人员参加培训。

**二、**培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| **领航·2024年第2期北交所上市公司独立董事专项培训** | | | |
| **时间** | | **内容** | **主讲人** |
| 8月20日（周二） | 14:00-15:00 | 上市公司信息披露监管与独董规范履职 | 北交所上市公司管理部  业务骨干 |
| 15:00-16:30 | 新《公司法》下独董履职相关问题解析 | 律师事务所专家 |
| 16:30-17:30 | 独立董事履职分享 | 上市公司独立董事 |

注：最终培训内容以实际课程安排为准

**三、**培训形式

本期培训采用“腾讯会议”线上直播讲解的模式，学员可通过会议码参加培训。会议码将于培训前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

**四、**报名方式及截止时间

本次培训需收集报名信息。请您扫描下方二维码或者点击链接进行报名，报名截止时间为8月19日12:00。
