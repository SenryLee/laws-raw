# 北京证券交易所关于举办领航·上市公司市值管理专题培训的通知

## 关于举办领航·上市公司市值管理专题培训的通知

各上市公司：

为贯彻落实《国务院关于加强监管防范风险推动资本市场高质量发展的若干意见》及中国证监会发布的《上市公司监管指引第10号——市值管理》等文件指示精神，进一步引导上市公司关注自身投资价值，更好利用市值管理工具合理反映上市公司质量，切实提升投资者回报，北京证券交易所拟于12月12日在上海举办领航·上市公司市值管理专题培训。具体安排如下：

**一、**培训时间、地点

培训时间：2024年12月12日

培训地点：上海虹桥雅高美爵酒店（仙霞路369号）

**二、**培训对象

北交所上市公司控股股东、实际控制人及负责市值管理工作的高级管理人员，培训名额有限，额满截止。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| **领航·上市公司市值管理专题培训** | | | |
| **时间** | | **课程内容** | **主讲人** |
| 12月12日  （周四） | 09:00-10:30 | 上市公司市值管理新政解读及合规要点 | 国浩律师事务所  合伙人 |
| 10:30-12:00 | 上市公司股份回购业务实操解析 | 中信建投证券  部门总监 |
| 14:00-15:30 | 上市公司股权激励、员工持股计划方案设计 | 荣正咨询  副总经理 |
| 15:30-17:00 | 上市公司市值管理与投资者关系管理实务 | 中国上市公司协会  投关委委员 |

注：最终培训内容以实际课程安排为准

**四、**报名时间及方式

本次培训需收集报名信息，请填写真实信息及有效联系方式，我们将在培训前通过手机短信将审核结果、培训具体地址发送至报名人员。因培训名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、证券代码、报名人员信息及取消原因等）。报名成功后，如未参与培训，相关情况将反馈任职公司并影响后续培训资格。

报名截止时间：2024年12月10日（周二）12:00，过期或额满后报名不再受理，请务必尽早完成报名。

**五、**培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费及其他费用请学员自理。如需预定培训酒店住宿请联系黄经理13482015805，并报“北交所培训”获取协议价。

**六、**培训考勤

请学员提前做好安排，保证全程参与。课务组将进行考勤并形成培训记录，未按计划参训、缺勤等情况将反馈任职公司，并影响后续培训资格。

**七、**温馨提示

1.培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
