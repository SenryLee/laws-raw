# 中国创盈市场服务有限公司关于深港通下的港股通标的证券名单调整的公告

## 关于深港通下的港股通标的证券名单调整的公告

因恒生综合大型股指数、小型股指数成份股调整，根据《深圳证券交易所深港通业务实施办法》的有关规定，港股通标的证券名单发生调整并自2024年07月10日起生效，相关调整信息如下：

|  |  |  |
| --- | --- | --- |
| 代码 | 简称 | 调整方向 |
| 02007 | 碧桂园 | 调出 |
| 06606 | 诺辉健康 | 调出 |
