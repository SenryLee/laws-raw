# 全国股转公司、北京证券交易所关于新《公司法》解读系列视频课程上线的通知

## 关于新《公司法》解读系列视频课程上线的通知

各市场主体：

新《公司法》将于2024年7月1日起施行。此次《公司法》全面修改，对于优化公司治理机制、便利公司投融资、强化各方主体责任和加强投资者保护等具有重要意义。北京证券交易所、全国股转公司特联合北京市金杜法律研究院录制新《公司法》解读系列视频课程。

**一、**课程目录

|  |  |
| --- | --- |
| 第一部分 | 新《公司法》的立法导向和目标 |
| 第二部分 | 股份有限公司资本制度 |
| 第三部分 | 股份公司组织结构与公司治理 |
| 第四部分 | 董事、监事、高级管理人员的义务与责任 |
| 第五部分 | 控股股东、实际控制人的义务与责任 |
| 第六部分 | 股东权益保护 |
| 第七部分 | 新《公司法》对上市公司并购重组交易的影响 |
| 第八部分 | 新《公司法》中的其他重点制度 |

**二、**观看方式

系列视频课程面向全市场公开，登录“北交所官网-服务-培训园地”或“全国股转公司官网-服务专区-培训园地”栏目，点击“新《公司法》”相关课程即可观看学习。
