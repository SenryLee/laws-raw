# 北京证券交易所办公室、全国股转公司办公室关于提供北交所股票启用新证券代码号段业务验证测试环境的通知

## 关于提供北交所股票启用新证券代码号段业务验证测试环境的通知

北证办发〔2024〕86号

各市场参与者：

北京证券交易所（以下简称“北交所”）首只新代码股票拟于近期上市。为方便市场各方进行业务验证，北交所联合中国证券登记结算有限责任公司（以下简称“中国结算”）、深圳证券通信有限公司（以下简称“深证通”）提供北交所股票启用新证券代码号段业务验证测试环境，现将相关事项通知如下：

1．业务验证测试时间为2024年5月25日（周六），模拟两个交易日。第一个交易日（以下简称T日）模拟新代码股票上市前一日代码切换和新股到账，第二个交易日（以下简称T+1日）模拟新代码股票上市首日。

| --- | --- | --- |
| **测试时间** | **模拟业务场景** | **交易时间安排** |
| 9:15至12:00 | T日日间交易 | 9:15-9:30 模拟申报收单时段 |
| 9:30-10:30模拟上午交易时段 |
| 10:30-10:35模拟午间休市 |
| 10:35-11:30模拟下午交易时段 |
| 11:30-12:00模拟盘后大宗交易时段 |
| 12:00至16:00 | T日清算交收、代码切换 | 模拟日终及清算交收 |
| 16:15至18:00 | T+1日日间交易 | 16:15-16:30模拟申报收单时段 |
| 16:30-17:00模拟上午交易时段 |
| 17:00-17:05模拟午间休市 |
| 17:05-17:45模拟下午交易时段 |
| 17:45-18:00模拟盘后大宗交易时段 |
| 18:00至21:00 | T+1日清算交收 | 模拟日终及清算交收 |

2．开展北交所相关业务的证券公司、基金公司和提供北交所行情服务的信息商可参加本次验证测试，清算交收相关测试内容和要求参见中国结算发布的测试通知。测试过程中如发现异常现象，请于测试当日通过电话（010-63889800）或QQ群（338167838）与北交所联系。

3．证券信息、交易单元、账户、持仓等初始数据以2024年5月24日（周五）生产环境日终后数据为准。

4．测试期间产生的交易、行情数据均为模拟数据，不能作为生产环境任何交易、非交易业务依据。

5．各市场参与者应做好生产环境的保护和恢复工作，确保下一交易日生产系统的正确运行。
