# 中国证券投资基金业协会关于举办民营企业债券融资专题直播培训的通知

## 关于举办民营企业债券融资专题直播培训的通知

中基协字〔2024〕464号

各机构：

为积极落实《关于强化金融支持举措助力民营经济发展壮大的通知》等重大决策部署要求，发挥资产证券化业务助力企业盘活存量资产、拓宽融资渠道、促进经济转型的积极作用，引导证券期货经营机构在加强中小企业、民营企业金融服务方面持续发力，中国证券投资基金业协会定于2025年1月中旬举办民营企业债券融资专题直播培训。现就有关事项通知如下：

一、 培训时间、内容及授课专家

培训时间为2025年1月13日、14日15:00-17:00，内容包括上交所和深交所ABS融资审核政策及关注要点、资产证券化工具助力中小企业融资综合解决方案及案例分享、中小微企业ABS融资案例分享，邀请交易所相关业务负责人、行业机构专家及企业代表授课。

二、培训对象及参培方式

培训对象为证券公司、基金子公司、信托、保险资管子公司、基金托管机构、基金服务机构及民营企业相关业务人员，每家机构1-5人。

学员请于2025年1月12日之前登录从业人员管理平台（https://human.amac.org.cn/web/login.html），点击“培训管理”—“培训报名”进入报名系统，选择相应培训班报名并填报提交个人的相关报名信息。没有从业人员管理平台账号的学员请发送机构名称、姓名、手机号至培训邮箱进行报名。请务必填写参训学员本人正在使用的手机号。

本次培训将采取直播方式进行，学员报名成功后，在培训期间使用微信扫描下方二维码进入直播平台，或PC端浏览器输入链接（https://eseb.cn/1kkFX3MCr3G），登录“民营企业债券融资专题直播培训”页面，凭借报名手机号免费参加学习。

![image.png](https://zk-img.faxin.cn//Uedit_Upload/2025-09-07-21-02-12_6987105_image.png "image.png")

根据实际培训情况，全程参加直播培训的学员，培训学时将计入协会后续职业培训信息库，学员无需在线签到。
