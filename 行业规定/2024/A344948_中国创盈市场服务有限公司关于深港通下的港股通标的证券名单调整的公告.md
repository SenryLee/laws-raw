# 中国创盈市场服务有限公司关于深港通下的港股通标的证券名单调整的公告

## 关于深港通下的港股通标的证券名单调整的公告

因鼎丰集团汽车（06878）实施股份合并，根据《深圳证券交易所深港通业务实施办法》的有关规定，港股通标的证券名单发生调整并自2024年02月21日起生效，相关调整信息如下：

|  |  |  |
| --- | --- | --- |
| 代码 | 简称 | 调整方向 |
| 02923 | 鼎丰集团汽车 | 调入 |
| 06878 | 鼎丰集团汽车 | 调出 |
