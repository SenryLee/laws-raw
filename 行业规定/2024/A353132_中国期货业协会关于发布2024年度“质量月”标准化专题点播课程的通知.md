# 中国期货业协会关于发布2024年度“质量月”标准化专题点播课程的通知

## 关于发布2024年度“质量月” 标准化专题点播课程的通知

各会员单位：

全国“质量月”活动是在国家相关主管部门的倡导和部署下，每年9月在全国范围内开展的主题活动，旨在“增强质量意识，推进高质量发展”。为落实全国“质量月”活动要求，进一步提升证券期货业标准化意识，协会将9月27日举办2024年度“质量月”标准化专题直播培训的课程转点播，已于近期在协会网络培训平台以点播课程形式上线发布，具体发布情况如下：

**一、**培训对象

本次培训面向期货公司分管信息技术工作的高管人员、信息技术部门负责人、总部信息技术部人员等。

**二、**课程内容

|  |  |  |  |
| --- | --- | --- | --- |
| **序号** | **课程名称** | **学时** | **讲师** |
| 1 | 《证券期货业信息系统渗透测试指南》介绍 | 1 | 李佶  上交所技术公司 |
| 2 | 《证券期货业信息系统压力测试指南》介绍 | 1 | XXX  上交所技术公司 |
| 3 | 《期货公司数字化能力成熟度指引》介绍 | 1.5 | 马文婷  中信期货 |

**三、**观看方式

登录协会网上后续培训平台，搜索相应的课程名称，点击搜索结果中的课程链接即可收看学习。网络培训平台地址：http://mooc.cfachina.org。

特此通知。
