# 全国股转公司关于举办远航·2024年第2期新挂牌新进层公司高管专项培训的通知

## 关于举办远航·2024年第2期新挂牌新进层公司高管专项培训的通知

各挂牌公司：

为引导新挂牌公司树牢公众公司意识，帮助新进层公司更好适应创新层公司的监管要求，强化新挂牌新进层公司高级管理人员规范意识，推动挂牌公司规范发展，全国股转公司联合湖南证监局拟于11月在长沙举办远航·2024年第2期新挂牌新进层公司高管专项培训。具体安排如下：

**一、**培训时间及地点

1.培训时间：2024年11月14日

2.培训地点：长沙雅士亚豪生酒店（长沙市雨花区韶山北路258号）

**二、**培训对象

新挂牌、新进层公司实际控制人、董事长、总经理、董事会秘书或其他高级管理人员，以及主办券商、会计师事务所代表，每家公司限报2人。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 远航·2024年第2期新挂牌新进层公司高管专项培训 | | | |
| 时间 | | 内容 | 主讲人 |
| 11月14日  （周四） | 09:00-11:00 | 挂牌公司监管情况及合规运作  案例解析 | 全国股转公司挂牌公司  管理一部业务骨干 |
| 11:00-11:40 | 挂牌公司年报监管及日常监管案例解读 | 湖南证监局综合业务处  业务骨干 |
| 13:30-15:00 | 公众公司媒体关系管理与舆情应对处置建议 | 新京报编委、贝壳财经  总编辑 |
| 15:00-16:30 | 提升企业内部控制质量、防范财务风险的建议与措施 | 立信会计师事务所  合伙人 |

注：最终培训内容以实际课程安排为准

**四、**培训报名

1.报名时间：请于 2024年11月12日（周二）12:00前完成报名。培训名额有限，额满为止，请尽早完成报名。

2.报名方式：请扫码或点击链接进行报名。

报名二维码：

报名链接：https://wanlixing.wjx.cn/vm/YYvv3iJ.aspx

3.报名须知：请报名后准时参训，如无法参加请提交《取消说明》， 加盖公章并发送至peixun@neeq.com.cn（邮件正文列示取消说明内容，需涵盖报名场次、公司代码、报名人员信息及取消原因等）。

**五、**培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿、交通及其他费用请自理。

**六、**培训考勤

请学员提前做好安排，保证全程参与。课务组将进行考勤并形成培训记录，未按计划参训、缺勤等情况将反馈任职公司，并影响后续培训资格。

**七、**温馨提示

1.培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
