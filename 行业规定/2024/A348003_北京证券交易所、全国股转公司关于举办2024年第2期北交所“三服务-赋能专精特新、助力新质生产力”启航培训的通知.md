# 北京证券交易所、全国股转公司关于举办2024年第2期北交所“三服务-赋能专精特新、助力新质生产力”启航培训的通知

## 关于举办2024年第2期北交所“三服务-赋能专精特新 助力新质生产力”启航培训的通知

各市场主体：

为支持专精特新企业高质量发展，推动专精特新企业利用资本市场做优做强，在工业和信息化部中小企业局支持下，北京证券交易所、全国股转公司联合山东证监局、山东省委金融办、山东省工信厅于6月5日在济南举办2024年第2期北交所“三服务-赋能专精特新 助力新质生产力”启航培训，具体安排如下：

**一、**培训时间、地点

培训时间：2024年6月5日

培训地点：济南蓝海御华大饭店（济南市市中区经十路20591号）

**二、**培训对象

拟挂牌上市的国家级专精特新“小巨人”企业董事长、总经理等负责挂牌上市事宜的高级管理人员，每家公司限报2人。

**三、**培训课程

|  |  |  |
| --- | --- | --- |
| **时间** | **课程内容** | **主讲人** |
| 09:00-09:30 | 领导致辞 | 相关领导 |
| 09:40-10:20 | 国家促进中小企业专精特新发展政策解读 | 工信部直属事业单位  专家 |
| 10:20-11:00 | 高质量建设北交所 助力企业走专精特新  发展之路 | 北交所北方基地  相关负责人 |
| 11:00-12:00 | 新三板挂牌审查制度及审核关注要点解析 | 全国股转公司挂牌审查部  业务骨干 |
| 13:30-14:30 | 专精特新企业投资价值提升的方法与路径 | 金石投资执行总经理 |
| 14:30-15:30 | 北交所上市流程介绍及规范性问题解析 | 中泰证券投资银行业务  委员会主任 |
| 15:30-16:00 | 专精特新企业北交所上市经验分享 | 北交所上市公司  董事长 |

注：最终培训内容以实际课程安排为准
