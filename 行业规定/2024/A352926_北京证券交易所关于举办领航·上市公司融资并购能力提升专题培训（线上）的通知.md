# 北京证券交易所关于举办领航·上市公司融资并购能力提升专题培训（线上）的通知

## 关于举办领航·上市公司融资并购能力提升专题培训（线上）的通知

各上市公司：

为更好落实二十届三中全会精神和新“国九条”对活跃并购重组市场的要求，积极落实证监会《关于深化上市公司并购重组市场改革的意见》，帮助上市公司利用融资并购工具，提升融资并购能力，拓宽上市公司资本运作视野，北京证券交易所拟于10月22日在线举办领航·上市公司融资并购能力提升专题培训。具体安排如下：

**一、**参会人员

北交所上市公司实际控制人、董事长、总经理、董事会秘书、财务总监及负责公司资本运作工作相关人员。

**二、**培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| **领航·上市公司融资并购能力提升专题培训** | | | |
| **时间** | | **课程内容** | **主讲人** |
| 10月22日  （周二） | 14:00-15:00 | 北交所再融资制度解读 | 北交所上市审核中心  再融资审核部专家 |
| 15:00-16:00 | 北交所重大资产重组制度解读 |
| 16:00-17:30 | 并购重组交易方案设计与经典案例解析 | 中介机构专家 |

注：最终培训内容以实际课程安排为准

**三、**培训形式

本期培训采用“腾讯会议”线上直播讲解的模式，学员可通过会议码参加培训。会议码将于培训前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

**四、**报名方式及截止时间

本次培训需收集报名信息。请您扫描下方二维码或者点击链接进行报名，报名截止时间为10月21日12:00。
