# 郑州商品交易所关于开展2024年“稳企安农护航实体”产业开发服务项目的通知

## 关于开展2024年“稳企安农 护航实体”产业开发服务项目的通知

郑商函〔2024〕390号

各会员单位：

为进一步增强期货市场服务实体经济质效，鼓励期货公司发挥专业优势，引导产业企业利用期货衍生品工具管控风险，提升产业企业参与期货市场广度与深度，郑州商品交易所（以下简称郑商所）决定开展“2024年‘稳企安农 护航实体’产业开发服务项目”（以下简称产业开发项目）。现将相关事项通知如下。

**一、**支持重点

支持期货公司发挥专业优势，开发服务产业企业参与期货市场，着力提升产业客户参与度。

一是提升产业企业期货参与度。重点企业、中小企业首次开立期货账户或首次开展期货交易，并达到一定持仓要求。

二是提升产业企业场内期权参与度。产业企业首次开通期权交易权限或首次开展期权交易，并达到一定持仓要求。

**二、**申请主体

期货公司，须以总部名义申请。

**三、**项目内容

产业开发项目包含三类项目。

（一）重点企业期货项目

1.服务对象

项目品种对应的产业企业，企业为2024年首次开户或2023年在项目申请品种上无交易记录，且满足下列条件之一。

（1）符合规模标准的产业企业（规模标准见附件1）。

（2）上海证券交易所、深圳证券交易所、北京证券交易所的上市公司。

（3）地级市（含地区、自治州、盟）及以上国有控股企业，其中国有控股比例要求不少于51%。

2.项目品种

菜籽油、甲醇、玻璃、菜籽粕、硅铁、锰硅、棉纱、苹果、尿素、纯碱、短纤、花生、烧碱、对二甲苯等14个期货品种。

3.考核标准及支持标准

考核期内，服务对象在项目申请品种上累计净持仓量1及持仓天数达到要求，给予期货公司相应标准资金支持。

同一家企业每个品种只能参与1个项目。

表1 重点企业期货项目考核标准及支持标准

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 期货  品种 | 菜籽油、甲醇、菜籽粕 | 玻璃、硅铁、锰硅、纯碱、短纤 | 棉纱、苹果、尿素、花生、烧碱、对二甲苯 | 持仓天数  要求 | 支持  标准 |
| 累计净持仓量（手） | 6000 | 4000 | 2000 | 20个交易日 | 10万元 |
| 18000 | 12000 | 6000 | 30个交易日 | 20万元 |

4.申请材料

申请材料包括重点企业期货项目备案表、企业确认函（见附件2、5）、企业营业执照，以及下列证明材料。

（1）符合规模标准的企业需提供能够证明企业规模的材料。

（2）上市公司需提供能够证明企业产业属性的材料（如贸易合同及发票等）。

（3）地级市及以上国有控股企业需提供股权穿透图（加盖企业公章）、能够证明企业产业属性的材料（如贸易合同及发票等）。

合同、发票等证明材料的时间范围需在2023年1月1日至2024年6月30日间。

（二）中小企业期货项目

1.服务对象

除重点企业之外的项目品种对应的产业企业，企业为2024年首次开户或2023年在郑商所无交易记录。

2.项目品种

菜籽油、甲醇、玻璃、菜籽粕、硅铁、锰硅、棉纱、苹果、红枣、尿素、纯碱、短纤、花生、烧碱、对二甲苯等15个期货品种。

3.考核标准及支持标准

考核期内，服务对象在项目申请品种上累计净持仓量及持仓天数达到要求，给予期货公司相应标准资金支持。

同一家企业只能参与1个项目。

表2　中小企业期货项目考核标准及支持标准

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 期货  品种 | 菜籽油、甲醇、菜籽粕 | 玻璃、硅铁、锰硅、纯碱、短纤 | 棉纱、苹果、红枣、尿素、花生、烧碱、对二甲苯 | 持仓天数  要求 | 支持  标准 |
| 累计净持仓量（手） | 3000 | 2000 | 1000 | 20个交易日 | 5万元 |

4.申请材料

申请材料包括中小企业期货项目备案表、企业确认函（见附件3、5）、企业营业执照，以及能够证明企业产业属性的材料（如贸易合同及发票等）。

合同、发票等证明材料的时间范围需在2023年1月1日至2023年12月31日间。

（三）企业场内期权项目

1.服务对象

项目品种对应的产业企业，企业为2024年首次开通期权交易权限或2023年在申请期权品种上无交易记录。

2.项目品种

白糖、棉花、甲醇、PTA、菜籽粕、菜籽油、花生、烧碱、对二甲苯、纯碱、短纤、锰硅、硅铁、尿素、苹果、玻璃、红枣等17个期权品种。

3.考核标准及支持标准

考核期内，服务对象在项目申请期权品种上累计持仓量2及持仓天数达到要求，给予期货公司相应标准资金支持。

同一家企业只能参与1个项目。

表3　企业场内期权项目考核标准及支持标准

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 期权品种 | 白糖、棉花、甲醇、PTA、菜籽粕、菜籽油、花生 | 烧碱、对二甲苯、纯碱、短纤、锰硅、硅铁、  尿素、苹果、玻璃、红枣 | 持仓天数  要求 | 支持  标准 |
| 累计持仓量（手） | 2500 | 2000 | 20个交易日 | 5万元 |

4.申请材料

申请材料包括企业场内期权项目备案表、企业确认函（见附件4、5）、企业营业执照，以及能够证明企业产业属性的材料（如贸易合同及发票等）。

合同、发票等证明材料的时间范围需在2023年1月1日至2023年12月31日间。

**四、**项目流程

（一）合作单位申请

意向参与产业开发项目的期货公司根据《郑州商品交易所产业开发服务项目管理办法（试行）》要求，以总部名义向郑商所提出书面申请，申请截止日期为2024年7月22日。合作单位申请表及期货公司营业执照等申请材料需在截止日期前发送至scfzb@czce.com.cn。

（二）项目备案申请

郑商所自7月1日起通过会服系统接收项目申请，申请截止日期为2024年11月1日。

期货公司风险管理公司，不参与本次项目申请。

参加过郑商所2022年和2023年“‘稳企安农 护航实体’支持会员产业服务专项计划”期货项目并达标任意一档的产业企业，不参与本次期货项目申请。

参加过郑商所2022年和2023年“‘稳企安农 护航实体’支持会员产业服务专项计划”期权项目并达标任意一档的产业企业，不参与本次期权项目申请。

期货公司应对服务对象资质进行审查把关，对发票材料进行验真，通过会服系统填写并提交项目备案表等申请材料。

（三）考核期

自项目完成备案之日起，统计服务对象持仓量及持仓天数。考核期自备案之日起至2024年12月13日截止。

（四）资金支持

产业开发项目设置两次持仓考核节点，首次考核日期为2024年10月31日，第二次考核日期为2024年12月13日。郑商所于两次考核节点统计已备案项目持仓情况，生成支持额度，并通知期货公司开具合规发票，通过费用支付的方式给予支持，单个项目支持额度之和不超过该项目的最高支持标准。
