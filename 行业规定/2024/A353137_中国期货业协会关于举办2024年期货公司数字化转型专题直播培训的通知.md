# 中国期货业协会关于举办2024年期货公司数字化转型专题直播培训的通知

## 关于举办2024年期货公司数字化转型专题直播培训的通知

各会员单位：

为帮助期货公司提高数字化能力水平，提升行业科技管理能力，推动行业进行数字化转型，促进行业科技进步。协会于11月7日和11月8日面向全行业举办两场期货公司数字化转型专题直播培训。现将培训相关事项通知如下。

**一、**培训对象

本次培训面向各会员单位分管信息技术工作的高管人员、信息技术部门负责人、总部信息技术部人员等。

**二、**直播培训时间、内容及师资

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **序号** | **课程主题** | **授课内容** | **授课日期** | **授课时间** | **主讲单位** |
| 1 | 数字化转型专题 | 行业标准化与  科研工作介绍 | 11月7日 | 14:00-14:45 | 中证技术 |
| 2 | 数字化云原生  技术应用 | 14:45-15:30 | 中金所 |
| 3 | 双栈可靠架构系  统建设经验分享 | 15:30-16:15 | 中信期货 |
| 4 | 金融衍生品  综合服务平台  建设实践 | 16:15-17:00 | 南华期货 |
| 5 | AI大模型发展  及行业应用 | 11月8日 | 14:00-14:45 | 东吴证券 |
| 6 | 机构客户数智化  服务实践 | 14:45-15:30 | 物产中大  期货 |
| 7 | 期货公司一体化  运营管理建设 | 15:30-16:20 | 兴证期货 |

**三、**参会方式

本次培训采取视频直播的方式举办，学员参加直播方式如下：

方式一：通过PC端浏览器方式，登录协会网上后续培训系统收看培训直播。网上后续培训系统地址：http://mooc.cfachina.org。在直播栏目下，选择本次直播培训，按时参加收看培训内容。

方式二：通过移动端访问，微信扫描二维码，登录并进入直播。无需安装客户端、无需测试，正式培训时间内登录即可。
