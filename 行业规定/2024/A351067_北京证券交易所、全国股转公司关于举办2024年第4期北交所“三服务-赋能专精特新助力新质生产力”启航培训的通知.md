# 北京证券交易所、全国股转公司关于举办2024年第4期北交所“三服务-赋能专精特新助力新质生产力”启航培训的通知

## 关于举办2024年第4期北交所“三服务- 赋能专精特新 助力新质生产力”启航培训的通知

各市场主体：

为支持专精特新企业高质量发展，推动专精特新企业利用资本市场做优做强，在工业和信息化部中小企业局，广东省工业和信息化厅的支持下，北京证券交易所、全国股转公司联合广东证监局拟于9月11日在广州举办2024年第4期北交所“三服务-赋能专精特新 助力新质生产力”启航培训，具体安排如下：

**一、**培训时间、地点

培训时间：2024年9月11日

培训地点：广州凯旋华美达大酒店（越秀区广州大道中明月一路九号）

**二、**培训对象

拟挂牌上市的国家级专精特新“小巨人”企业董事长、总经理等负责挂牌上市事宜的高级管理人员，每家公司限报2人。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| **时间** | **课程内容** | **主讲人** | |
| 09:00-10:50 | 北交所市场最新发展情况与  发行上市重点关注问题 | | 北交所华南基地  副首席代表 |
| 10:50-12:10 | 新三板挂牌审查制度及审核关注要点解析 | | 全国股转公司挂牌审查部  业务骨干 |
| 12:10-12:30 | 互动交流 | | 北交所、全国股转公司  业务骨干 |
| 14:00-15:00 | 提升专精特新企业投资价值的方法与路径 | | 深圳同创伟业资产管理公司 董事总经理 |
| 15:00-16:00 | 企业税收筹划方案与建议 | | 毕马威中国  税务总监 |
| 16:00-16:30 | 专精特新企业北交所上市经验分享 | | 北交所上市公司  董事长 |

注：最终培训内容以实际课程安排为准

**六、**温馨提示

1、培训期间课务组不会组织与培训无关的活动，请学员注意个人财产安全和食品安全。

2、学员可带足名片，以便培训期间相互交流。

3、培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
