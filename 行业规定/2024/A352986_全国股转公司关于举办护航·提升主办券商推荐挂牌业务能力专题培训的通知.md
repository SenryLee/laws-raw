# 全国股转公司关于举办护航·提升主办券商推荐挂牌业务能力专题培训的通知

## 关于举办护航·提升主办券商推荐挂牌业务能力专题培训的通知

各主办券商：

为深入贯彻落实党的二十届三中全会精神及《国务院关于加强监管防范风险推动资本市场高质量发展的若干意见》中关于推动证券服务机构高质量发展相关要求，加强证券行业能力建设，全国股转公司拟于10月17日在上海举办护航·提升主办券商推荐挂牌业务能力专题培训，帮助主办券商强化合规意识，提高主办券商推荐挂牌执业质量，便利企业顺利挂牌，支持企业健康发展。具体安排如下：

**一、**培训时间、地点

培训时间：2024年10月17日

培训地点：上海虹桥雅高美爵酒店（仙霞路369号）

**二、**培训对象

主办券商从事推荐挂牌、融资并购及内核业务相关人员，培训名额有限，额满截止。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 护航·提升主办券商推荐挂牌业务能力专题培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 10月17日于上海 | 09:00-10:00 | 证券从业人员职业道德与职业操守提升 | 中国证券业协会  专家 |
| 10:00-11:30 | 挂牌准入制度解读及挂牌审查常见问题解析 | 全国股转公司  挂牌审查部  业务骨干 |
| 14:00-15:30 | 融资并购制度解读及相关案例解析 |
| 15:30-16:30 | 主办券商违规案例解析 | 全国股转公司  监管执行部  业务骨干 |
| 注：最终培训内容以实际课程安排为准 | | | |

**四、**报名时间及方式

本次培训需收集报名信息，请您扫码或点击链接进行报名。因培训名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（取消说明内容需涵盖报名场次、公司名称、报名人员信息及取消原因等）。报名成功后，如未参与培训，相关情况将反馈任职公司并影响后续培训资格。

报名截止时间：2024年10月14日（周一）12:00，过期或额满后报名不再受理，请务必尽早完成报名。

**五、**培训费用

培训不收取培训费。餐费、住宿费、交通费、停车费及其他费用请学员自理。

**六、**培训考勤

课务组将进行考勤并形成培训记录，缺勤情况将反馈任职公司，请学员提前做好安排，保证全程参与。

**七、**温馨提示

1.培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人信息安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
