# 全国中小企业股份转让系统有限责任公司关于举办远航·2024年第1期新挂牌新进层公司高管专项培训的通知

## 关于举办远航·2024年第1期新挂牌新进层公司高管专项培训的通知

各挂牌公司：

为进一步强化新挂牌新进层公司高级管理人员的合规意识和自律意识，推动完善公司治理，实现规范发展，全国股转公司拟于4月26日在南京举办远航·2024年第1期新挂牌新进层公司高管专项培训。具体安排如下：

**一、**培训时间及地点

1.培训时间：2024年4月26日

2.培训地点：江苏省南京市高投大厦（南京市鼓楼区虎踞路99号）

**二、**培训对象

2023年4月1日后新挂牌、新进层公司实际控制人、董事长、总经理、董事会秘书或其他高级管理人员，每家公司限报2人。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 远航·2024年第1期新挂牌新进层公司高管专项培训 | | | |
| 时间 | | 内容 | 主讲人 |
| 4月26日（周五） | 09:00-10:30 | 挂牌公司监管情况及合规运作  案例解析 | 挂牌公司管理一部  业务骨干 |
| 10:40-12:00 | 挂牌公司投资价值提升的有效途径 | 投资机构合伙人 |
| 14:00-15:50 | 新《公司法》中规范发展关注要点 | 金杜法律研究院院长 |
| 16:00-17:30 | 内部控制及财务风险防范 | 立信会计师事务所  合伙人 |

注：最终培训内容以实际课程安排为准

**四、**培训报名

1.报名时间：请于 2024年4月23日（周二）12:00前完成报名。培训名额有限，额满为止，请尽早完成报名。

2.报名方式：请扫码或点击链接进行报名。

**五、**培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿、交通及其他费用请自理。

**六、**培训考勤

请学员提前做好安排，保证全程参与。课务组将进行考勤并形成培训记录，未按计划参训、缺勤等情况将反馈任职公司，并影响后续培训资格。

**七、**温馨提示

1.培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
