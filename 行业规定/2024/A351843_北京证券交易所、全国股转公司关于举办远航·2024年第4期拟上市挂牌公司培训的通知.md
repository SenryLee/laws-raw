# 北京证券交易所、全国股转公司关于举办远航·2024年第4期拟上市挂牌公司培训的通知

## 关于举办远航·2024年第4期拟上市挂牌公司培训的通知

各挂牌公司：

为贯彻落实新“国九条”及资本市场“1+N”政策，帮助企业树立正确“上市观”，提升企业上市质效，北京证券交易所、全国股转公司将于10月22日在成都举办远航·2024年第4期拟上市挂牌公司培训，为拟上市企业提供面对面的“直达服务”。具体安排如下：

**一、**培训时间及地点

1.培训时间：2024年10月22日

2.培训地点：成都蓝海御华饭店（武侯区名都路166号）

**二、**培训对象

拟上市企业的实际控制人、董事长、总经理、董事会秘书、财务总监等，每家公司限报2人。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| **时间** | | **课程主题** | **主讲部门** |
| 10月22日 | 09:00-10:00 | 新“国九条”严把发行上市准入关  监管政策解读 | 中国证监会公众司 |
| 10:00-12:00 | 北交所发行上市审核重点解析 | 北交所上市审核中心  审核部 |
| 14:00-15:30 | 高效衔接上市的持续监管要点 | 挂牌公司管理一部 |
| 15:30-17:00 | 上市相关重点财务及内控问题 | 会计师事务所 |

注：最终培训内容以实际课程安排为准。

**四、**培训报名及费用

1.报名方式：请扫码或点击链接进行报名。

二维码：

![image.png](https://zk-img.faxin.cn//Uedit_Upload/2024-10-12-15-15-53_6184773_image.png "image.png")

链接：https://wanlixing.wjx.cn/vm/Qw7dx8r.aspx

2.截止时间：报名截至 2024年10月16日17:00。培训名额有限，请尽早完成报名。

3.报名确认：我们将在审核后通过手机短信将培训具体地址发送至报名人员，确认报名成功。

4.培训费用：培训不收取培训费，主办方提供培训当日午餐。住宿、交通及其他费用请学员自理。

**五、**培训考勤

1.请报名成功的学员提前做好安排，按时参训。如无法参训，请事先提交《取消说明》发送至peixun@neeq.com.cn。

2.培训现场将组织签到并形成出勤记录，未按计划参训、缺勤等情况将反馈报名企业，并影响后续培训资格。

**六、**注意事项

1.培训期间不会组织其他无关活动，课余时间请参训人员自行安排，注意保护个人安全并增强防范意识。

2.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
