# 全国股转公司关于举办远航·2024年第4期挂牌公司董事会秘书、财务总监专项培训的通知

## 关于举办远航·2024年第4期挂牌公司董事会秘书、财务总监专项培训的通知

各挂牌公司：

为深入贯彻二十届三中全会精神和《国务院关于加强监管防范风险推动资本市场高质量发展的若干意见》，强化挂牌公司董事会秘书、财务总监合规意识，帮助其更好掌握监管要求，提升执业水平，全国股转公司拟于11月21日在西安举办远航·2024年第4期挂牌公司董事会秘书、财务总监专项培训。具体安排如下：

**一、**培训时间、地点

培训时间：2024年11月21日

培训地点：西安大天瑞斯丽酒店（高新区团结南路10号）

**二、**培训对象

挂牌公司董事会秘书、财务总监，每家公司限报2人，培训名额有限，额满截止。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 远航·2024年第4期挂牌公司董事会秘书、财务总监专项培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 11月21日  （周四） | 09:00-10:00 | 新“国九条”下挂牌公司监管情况及规范运作要求 | 中国证监会公众司  专家 |
| 10:00-11:30 | 挂牌公司信息披露、规范治理重点问题讲解 | 全国股转公司  挂牌公司管理一部  业务骨干 |
| 13:30-15:00 | 新三板融资并购制度解读及相关案例解析 | 全国股转公司  挂牌审查部  业务骨干 |
| 15:00-16:30 | 挂牌公司财务规范与内控体系建设 | 会计师事务所  专家 |

注：最终培训内容以实际课程安排为准

**四、**报名时间及方式

本次培训需收集报名信息，请填写真实信息及有效联系方式，我们将在培训前通过手机短信将审核结果、培训具体地址发送至报名人员。因培训名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、证券代码、报名人员信息及取消原因等）。报名成功后，如未参与培训，相关情况将反馈任职公司并影响后续培训资格。

报名截止时间：2024年11月19日（周二）12:00，过期或额满后报名不再受理，请务必尽早完成报名。

**五、**培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费及其他费用请学员自理。如需预定培训酒店住宿请联系张经理13759923863，并报“参加全国股转公司培训”获取协议价。

**六、**培训考勤

请学员提前做好安排，保证全程参与。课务组将进行考勤并形成培训记录，未按计划参训、缺勤等情况将反馈任职公司，并影响后续培训资格。

**七、**温馨提示

1.培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
