# 郑州商品交易所关于开展2024年“期货影响力——郑商所‘投教先锋’”评选活动的通知

## 关于开展2024年“期货影响力——郑商所‘投教先锋’”评选活动的通知

郑商函〔2024〕255号

各会员单位、地方期货业协会：

为凝聚多方力量进一步提升期货市场投资者教育工作的质量和影响力，鼓励原创投资者教育产品生产，打造行业投资者教育团队，培育、壮大期货市场投资者教育力量，郑州商品交易所（以下简称郑商所）将举办2024年“期货影响力——郑商所‘投教先锋’”评选活动。具体通知如下：

**一、**参评要求

（一）参与对象

由会员单位、地方期货业协会推荐报名参评团队（每家参评团队成员6人以内）。

（二）参评作品

1.形式：短视频（每条１分钟之内）。

2.要求：每家提交作品不低于2个主题，共提交不低于4条短视频。

3.参评作品应立意明确、形式活泼、通俗易懂、制作精良。

（三）作品主题

1.识别和防范非法期货，倡导理性参与理念。

2.期货市场基础知识和政策法规，投资者适当性制度解读等。

3.郑商所上市品种规则制度、期现货知识等。

4.期货市场功能发挥案例。

各参评机构可根据各自投教工作情况，采用实景拍摄或动画制作等形式。亦可利用郑商所实体投教基地、相关投教场所等进行取景拍摄。

**二、**相关安排

（一）时间安排

|  |  |
| --- | --- |
| 时间 | 事项 |
| 5-7月 | 提交报名材料和参评作品 |
| 8-9月 | 评审、展示入围作品 |
| 10月 | 公布结果 |

（二）评选规则

1.由专家组根据报名作品评选出30个入围“投教先锋”评选的团队。

2.入围作品通过郑商所微信公众号、中国证券报“中证金牛座”客户端、新浪财经等评选活动官方发布平台进行展示。

3.结合专家组意见和参评作品展示情况，综合评判确定评选结果。

（三）报名材料

1.活动报名表（见通知附件）和参评作品。

2.主创团队人员视频展示（时长3分钟以内，介绍创作理念等）。

3.报名邮件主题格式为：机构名称+2024年“投教先锋”报名材料。

**三、**评选设置

根据综合评判结果，第1-10名团队获得2024年“郑商所‘投教先锋’”团队称号，第11-30名团队获得2024年“郑商所‘投教先锋’”提名团队称号。其中，对“投教先锋”团队给予每家30000元费用支持，对“投教先锋”提名团队给予每家13000元费用支持，用于后续开展投资者教育相关工作。
