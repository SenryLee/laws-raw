# 中国证券业协会关于发布“践行行业荣辱观提升职业道德水平”职业道德案例征集结果的公告

## 关于发布“践行行业荣辱观提升职业道德水平”职业道德案例征集结果的公告

各证券公司：

近期，协会对“践行行业荣辱观提升职业道德水平”职业道德案例征集活动结果进行了公示。现将征集结果公告如下：

|  |  |  |
| --- | --- | --- |
| **类别** | **数量** | **名单** |
| 职业道德准则 | 27家 | 爱建证券 财达证券 财通证券 东北证券 东方财富 东海证券 东吴证券　东亚前海　  国联证券　国投证券 国信证券 红塔证券 华创证券 华福证券 华龙证券 华泰证券  江海证券 麦高证券 世纪证券 万联证券 长城证券 长江证券 浙商证券 中信建投  中信证券 中原证券 中金公司 |
| 证券行业荣辱观 | 13家 | 渤海证券 东方证券 光大证券 广发证券 国金证券 国泰君安 国元证券 华金证券　  金元证券 申万宏源 湘财证券 银河证券 中航证券 |

为保证案例入库及展播等工作顺利开展，请名单中的公司在2024年1月25日前将选送的系列视频合并为1个视频文件（不超过1G、MP4格式、分辨率为1280*720），连同案例名称、简介一并发送至service sacedu.cn（可发送网盘下载链接）。

感谢各公司的积极参与和大力支持！

中国证券业协会

2024年1月18日
