# 北京证券交易所、资本市场学院关于举办领航·2024年第2期北交所上市公司财务总监专项培训的通知

## 关于举办领航·2024年第2期北交所上市公司财务总监专项培训的通知

各上市公司：

为深入贯彻二十届三中全会精神和《国务院关于加强监管防范风险推动资本市场高质量发展的若干意见》，积极落实中国证监会《关于加强上市公司监管的意见（试行）》等政策文件要求，加强对上市公司财务总监的规范引导，增强“关键少数”的“敬畏上市”意识，推动上市公司高质量发展，在中国证监会公众公司监管司的指导下，北京证券交易所联合资本市场学院拟于11月28日在深圳举办领航· 2024年第2期北交所上市公司财务总监专项培训。具体安排如下：

**一、**培训时间、地点

培训时间：2024年11月28日（周四）

培训地点：资本市场学院（深圳市南山区西丽街道沁园二路）

**二、**培训对象

北交所上市公司、在审企业财务总监。

**三、**课程安排

|  |  |  |  |
| --- | --- | --- | --- |
| **领航·2024年第2期北交所上市公司财务总监专项培训** | | | |
| **时间** | | **内容** | **主讲人** |
| 11月28日  （周四） | 09:00-10:00 | 新“国九条”上市公司监管政策解读 | 中国证监会  公众司专家 |
| 10:00-12:00 | 《会计法》修订解读 | 财政部  会计司专家 |
| 14:00-15:00 | 防范财务风险提高公司质量 | 北京证券交易所  上市公司管理部  业务骨干 |
| 15:00-16:30 | 北交所上市公司定期报告会计问题  案例分析 | 北京证券交易所  会计监管部  业务骨干 |

注：最终培训内容以实际课程安排为准

**四、**报名时间及方式

（一）报名时间

本次培训需收集报名信息，请您扫码或点击链接进行报名。请您报名后准时参加，报名成功后，未经请假缺席培训的人员，将被记入培训诚信档案并反馈任职公司。

报名截止时间：即日起至2024年11月25日（周一）17:00，过期或额满后报名不再受理，请学员务必尽早完成报名。

（二）报名方式（任选其一）

手机端：使用手机微信扫一扫功能，扫描资本市场学院学员平台小程序码（如下），点击“立即报名”登录资本市场学院报名系统（首次使用需进行注册），填写报名信息。

![image.png](https://zk-img.faxin.cn//Uedit_Upload/2024-11-14-15-17-09_4301841_image.png "image.png")

PC端：请登录资本市场学院官方网站http://www.ccmi.edu.cn/，进入“培训通知与在线报名”栏目，选择“2024年第7期（总第59期）上市公司财务总监培训（北交所专场）”报名通知，点击“我要报名”登录资本市场学院报名系统（首次使用需进行注册），填写报名信息。

学员报名审核、报名成功等状态可通过登录报名系统进行查看。

（三）注意事项

1.报名审核阶段（11月25日前）及报名成功后，如有信息审核确认、提醒信息发布等情况，工作组将通过邮箱及（或）手机电话、短信方式发送培训有关通知，请务必正确填写邮箱、注意查收邮件及接听电话（见文末“联系方式”）。

2.学员报名成功后，如有特殊情况不能出席，请及时以邮件方式告知课务组（peixun@neeq.com.cn，并抄送xiehz@ccmi.edu.cn）。未请假而无故缺席的学员，课务组将留存其培训记录并反馈任职公司。

**五、**培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费及其他费用请学员自理。学员可根据需求自行预订学院住宿，详见附件一：住宿预定指南。

**六、**培训考勤

必须学员本人参加培训，他人不得替代，请学员带好身份证，出入教室时请佩戴学员证，以便考勤时验证。

课务组每半天进行考勤并形成培训记录，缺勤情况将反馈任职公司，请学员提前做好安排，保证全程参与。

**七、**温馨提示

1. 请尽量于11月27日14:00-17:30报到，晚于17:30报到的学员可于11月28日8:20-8:50在教室门口办理报到手续。培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。

## 住宿预订指南

为便利学员参训，学员可选择是否在学院学员公寓住宿，费用自理。参训学员亦可在周边自行联系住宿。

预定价格：560元/天/间（单人大床房，含单早），以线上预订成功为准。

若学员行程有变，请于11月25日17:00前在线取消订房；11月27日（14:00之后）可前往学院C栋注册中心缴费入住。学院公寓数量及房型（单人单间）有限，将按订房先后顺序安排住宿，额满即止。

温馨提示：资本市场学院学员公寓不对外运营，仅对成功报名参训的学员开放，公寓有权拒绝非学员入住，请遵守学院规定。因自身原因出现未能成功预订房间、房费或担保费无法退回等情形，责任自负，与培训主办方无关。
