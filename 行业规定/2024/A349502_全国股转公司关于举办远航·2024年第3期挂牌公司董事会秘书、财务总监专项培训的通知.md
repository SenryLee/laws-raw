# 全国股转公司关于举办远航·2024年第3期挂牌公司董事会秘书、财务总监专项培训的通知

## 关于举办远航·2024年第3期挂牌公司董事会秘书、财务总监专项培训的通知

各挂牌公司：

为深入贯彻落实中央金融工作会议精神和《国务院关于加强监管防范风险推动资本市场高质量发展的若干意见》，强化挂牌公司董事会秘书、财务总监合规意识，帮助其更好掌握监管要求，提升执业水平，同时保障挂牌公司顺利开展2024年半年报编制与披露工作，全国股转公司拟于7月9日在郑州举办远航·2024年第3期挂牌公司董事会秘书、财务总监专项培训。具体安排如下：

**一、**培训时间、地点

培训时间：2024年7月9日

培训地点：郑州正方元国际酒店（郑东新区黄河南路86号）

**二、**培训对象

挂牌公司董事会秘书、财务总监，每家公司限报2人，培训名额有限，额满截止。

**三、**培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 远航·2024年第3期挂牌公司董事会秘书、财务总监专项培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 7月9日  （周二） | 09:00-10:00 | 新“国九条”下挂牌公司监管情况及规范运作要求 | 中国证监会公众司  专家 |
| 10:00-11:30 | 挂牌公司2024年半年报编制与信息披露、规范治理重点问题讲解 | 全国股转公司  挂牌公司管理一部  业务骨干 |
| 14:00-15:30 | 企业税务管理及税收优化 | 会计师事务所  专家 |
| 15:30-16:30 | 股权激励方案设计与案例分享 | 证券公司  专家 |

注：最终培训内容以实际课程安排为准

**四、**报名时间及方式

本次培训需收集报名信息，请填写真实信息及有效联系方式，我们将在培训前通过手机短信将审核结果、培训具体地址发送至报名人员。因培训名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、证券代码、报名人员信息及取消原因等）。报名成功后，如未参与培训，相关情况将反馈任职公司并影响后续培训资格。

报名截止时间：2024年7月5日（周五）17:00，过期或额满后报名不再受理，请务必尽早完成报名。

**五、**培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费及其他费用请学员自理。如需预定培训酒店住宿请联系刘经理18037339286，并报培训名称获取协议价。

**六、**培训考勤

课务组每半天进行考勤并形成培训记录，缺勤情况将反馈任职公司，请学员提前做好安排，保证全程参与。

**七、**温馨提示

1.培训期间课务组不会组织与培训无关的活动，请学员注意个人财产安全和食品安全。

2.学员可带足名片，以便培训期间相互交流。

3.培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
