# 北京证券交易所、全国股转公司关于举办远航·拟上市挂牌公司系列培训的通知

## 关于举办远航·拟上市挂牌公司系列培训的通知

各挂牌公司：

为贯彻落实新“国九条”及资本市场“1+N”政策，帮助企业树立正确“上市观”，提升企业上市质效，北京证券交易所、全国股转公司将举办拟上市挂牌公司系列培训，为拟上市企业提供面对面的“直达服务”，助力资本市场服务实体经济，促进新质生产力发展。具体安排如下：

**一、**场次安排

为更好地满足企业需求，拟分区域、多场次举办拟上市企业培训，每场培训时长为1天，具体计划如下：

|  |  |  |
| --- | --- | --- |
| 场次 | 地点 | 时间 |
| 第1场 | 北京（朝阳宾馆） | 8月30日 |
| 第2场 | 武汉（待定） | 9月中旬 |
| 第3场 | 成都（待定） | 10月中旬 |

**三、**培训报名

1、报名方式：上述3场培训，供拟上市企业选择报名。单场培训每家公司限报2人。

2、截止时间：北京场报名截至 2024年8月23日17:00。培训名额有限，请尽早完成报名。

武汉、成都场将另行发布报名通知，请持续关注。

3、北京场报名渠道：请扫码或点击链接进行报名。

4、报名确认：我们将在审核后通过手机短信将培训具体地址发送至报名人，确认报名成功。

**四、**培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿、交通及其他费用请学员自理。

**五、**培训考勤

1、请企业参训人员提前做好安排，按时参训。如无法参训，请事先提交《取消说明》，加盖公章并发送至peixun@neeq.com.cn（邮件正文列示取消说明内容，需涵盖报名场次、公司及报名人员信息、取消原因等）。

2、我们将形成培训出勤记录，未按计划参训、缺勤等情况将反馈报名企业，并影响后续培训资格。

**六、**注意事项

1、培训期间不会组织其他无关活动，课余时间请参训人员自行安排，注意保护个人安全并增强防范意识。

2、培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
