# 中国期货业协会关于举办2024年反垄断、反不正当竞争合规宣讲以及反洗钱业务培训的通知

## 关于举办2024年反垄断、反不正当竞争合规宣讲以及反洗钱业务培训的通知

各会员单位：

《关于加强监管防范风险促进期货市场高质量发展的意见》中强调应切实加强期货市场监管，有效防范期货市场风险，有力促进期货市场平稳运行和高质量发展。为加强期货经营机构增强反垄断、反不正当竞争合规意识，提升期货经营机构掌握金融反洗钱工作相关要求，协会联合北京期货商会将于11月15日面向全行业举办期货公司反垄断、反不正当竞争合规宣讲以及反洗钱专题直播培训。现将培训相关事项通知如下：

**一、**培训对象

本次培训面向各会员单位合规业务人员、法务业务人员、反洗钱业务人员等。

**二、**直播培训时间、内容及师资

|  |  |  |
| --- | --- | --- |
| **时间** | **主题** | **主讲嘉宾** |
| 9:30-11:30 | 期货行业反垄断、反不正当竞争合规宣讲 | 中国人民大学  法学院副教授黄尹旭 |
| 13:30-15:00 | 期货公司洗钱风险管理进阶之路 | 德勤中国 北京反洗钱中心合伙人董聪 |
| 15:00-16:00 | “风险为本”视角的反洗钱工作实践与价值创造探索 | 西部期货有限公司  反洗钱合规官闫海 |

**三、**参会方式

本次培训采取视频直播的方式举办，学员参加直播方式如下：

方式一：通过PC端浏览器方式，登录协会网上后续培训系统收看培训直播。网上后续培训系统地址：http://mooc.cfachina.org。在直播栏目下，选择本次直播培训，按时参加收看培训内容。

方式二：通过移动端访问，微信扫描二维码，登录并进入直播。无需安装客户端、无需测试，正式培训时间内登录即可。

此次网络直播培训列入中国期货业协会后续职业培训序列，全程参加直播培训且完成课后问卷任务的计为有效培训学时。
