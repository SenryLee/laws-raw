# 中国期货业协会关于举办2024年期货公司高级管理人员专题培训的通知

## 关于举办2024年期货公司高级管理人员专题培训的通知

各期货公司：

为了学习贯彻《关于加强监管防范风险促进期货市场高质量发展的意见》（以下简称《意见》），促进期货公司高管人员对公司发展定位和转型升级的深入思考，进一步提升期货公司高管人员的专业素质和期货公司服务实体经济的能力，根据《期货公司董事、监事和高级管理人员任职管理办法》的有关规定，协会与资本市场学院拟联合举办2024年期货公司高管人员专题培训班。具体事项通知如下：

**一、**培训对象

150家期货公司，每家（至多）2名高管参加，其中必须包含1名主要负责人（董事长或总经理）。

**二、**培训时间地点

培训时间：12月6日9:00-17:00

报到时间：12月6日7:50-8:50

培训地点：资本市场学院（深圳市南山区）B栋2楼报告厅

**三、**培训日程

|  |  |  |  |
| --- | --- | --- | --- |
| **日期** | **时间** | **课程名称** | **讲师** |
| 2024年  12月6日（周五） | 09:00-11:30 | 《关于加强监管防范风险促进期货  市场高质量发展的意见》宣讲解读 | 证监会期货  监管司 |
| 13:30-15:00 | 证券期货业科技监管情况介绍及  2024-2027行业信创试点政策解读 | 证监会科技  监管司 |
| 15:10-17:00 | 舆情管理及风险应对 | **纪莉**  武汉大学  新闻学院教授  博士生导师 |

**四、**培训费用及食宿安排

（一）本次培训免收培训费用，由中国期货业协会期货人才培养专项基金全额资助。住宿及交通费用学员自理。

（二）培训住宿：由于培训期间资本市场学院满房，建议在会场附近就近住宿（详见附近酒店参考）。酒店房间数量有限，请尽早预订，学员可根据个人情况自行安排住宿。

（三）培训用餐：6日为全天培训，为节省用餐时间，方便大家更好参加培训，协会免费提供6日中午的会议自助餐。

**五、**报名须知

（一）面授培训报名截止时间为11月29日12点，每家公司限报两人。过时或人满，系统将自动关闭。报名设有审核机制，请于29日15点后查看审核结果，审核通过后可预订机票住宿等。

（二）通过扫描通知下方的二维码进行报名。集体报名管理平台（登录账号为G*****_P01,密码忘记的可联系本公司自律服务系统管理员重置密码）报名操作仅需勾选机构内在职人员并确认培训人员各项信息准确无误。如培训人员部门、岗位等个人信息需修改更新，请先在自律服务系统内修改，集体报名管理平台将自动同步修改数据。

（三）由于个人原因不能按期参加面授培训的，请务必提前通知协会工作人员。

（四）本次培训学时列入中国期货业协会后续职业培训序列。
