# 全国股转公司关于举办挂牌公司2024年半年报编制与披露线上培训的通知

## 关于举办挂牌公司2024年半年报编制与披露线上培训的通知

各市场主体：

为保障挂牌公司顺利开展2024年半年报编制与披露工作，提高半年报信息披露质量，全国股转公司拟于7月12日在线举办挂牌公司2024年半年报编制与披露培训。培训具体安排如下：

**一、**培训对象

基础层、创新层挂牌公司信息披露负责人、信披相关人员以及挂牌公司主办券商持续督导人员。

**二、**课程安排

|  |  |  |  |
| --- | --- | --- | --- |
| 2024年半年报编制与披露培训（挂牌公司及主办券商专场） | | | |
| 时间 | | 课程内容 | 主讲人 |
| 7月12日（周五）  线上直播 | 09:00-10:00 | 创新层挂牌公司2024年半年报编制与披露  重点问题讲解 | 全国股转公司  挂牌公司管理一部  业务骨干 |
| 10:00-11:00 | 基础层挂牌公司2024年半年报编制与披露  重点问题讲解 | 全国股转公司  挂牌公司管理一部  业务骨干 |
| 14:00-15:00 | 挂牌公司半年报编制工具使用及报送注意事项 | 中证股转科技公司  业务骨干 |
| 15:00-16:00 | 新《公司法》中挂牌公司治理重点问题解析 | 全国股转公司  法律事务部  业务骨干 |

注：最终培训内容以实际课程安排为准

**三、**培训形式

本期培训采用“腾讯会议”线上直播讲解的模式，参会人员可通过会议码参加培训。会议码将于培训前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

本次培训需收集报名信息。请您扫描下方二维码或者点击报名链接进行报名，报名截止时间为7月11日12:00。
