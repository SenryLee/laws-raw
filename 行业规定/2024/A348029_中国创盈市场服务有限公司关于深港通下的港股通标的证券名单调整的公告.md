# 中国创盈市场服务有限公司关于深港通下的港股通标的证券名单调整的公告

## 关于深港通下的港股通标的证券名单调整的公告

因中集车辆（01839）撤回上市地位,根据《深圳证券交易所深港通业务实施办法》的有关规定，港股通标的证券名单发生调整并自2024年06月04日起生效，相关调整信息如下：

|  |  |  |
| --- | --- | --- |
| 代码 | 简称 | 调整方向 |
| 01839 | 中集车辆 | 调出 |
