# 郑州商品交易所关于召开2024年“保险+期货”项目申报宣讲会的通知

## 关于召开2024年“保险+期货”项目申报宣讲会的通知

郑商函〔2024〕340号

各相关单位：

2024年5月31日，郑州商品交易所（以下简称郑商所）发布了《关于开展2024年“保险+期货”试点工作的通知》，为进一步明确试点工作导向和相关要求，解答各单位在项目申报过程中的疑问，帮助项目申报单位充分全面理解“农险无忧”建设主题，郑商所将举办项目申报宣讲会，请有意向申报项目的各单位相关人员参加。具体通知如下：

**一、**会议议程

时间：2024年6月4日15:00-16:30

主题：2024年“保险+期货”项目申报宣讲会

|  |  |  |
| --- | --- | --- |
| 时间 | 内容 | 宣讲部门 |
| 15:00-15:40 | 郑商所2024年“保险+期货”  试点项目申报讲解 | 郑商所商品二部 |
| 15:40-16:30 | 项目申报交流答疑 |

**二、**参会方式

本次宣讲会采取线上腾讯会议的方式举办，参加线上会议方式如下：

方式一：通过PC端浏览器方式，点击如下链接：https://meeting.tencent.com/dm/FaBHpPpPHZ4J，直接参会。

方式二：通过PC端或手机端腾讯会议APP，输入会议号：471-838-678，直接参会。

各项目申报单位于会议期间均可登陆（提前15分钟开放登录），进入会议后请按照“单位名称-姓名”修改昵称。

**三、**2024年项目申报通知群

为方便各项目申报单位及时获得郑商所相关工作安排，现将微信群二维码公布如下（6月6日前有效），请各项目申报单位按照“单位名称—姓名”发送进群申请。
