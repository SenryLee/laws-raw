# 中国证券投资基金业协会关于融智聚力行稳致远——AI赋能基金运营交流会的通知

中基协字〔2026〕256号

各相关机构：

为推动基金行业数智化转型，促进人工智能（AI）技术在基金运营领域的有效应用，中国证券投资基金业协会（以下简称协会）拟于2026年8月11日下午在深圳举办“融智聚力　行稳致远——AI赋能基金运营交流会”。具体事项通知如下：

一、活动安排

（一）会议时间和地点

时间：2026年8月11日 13:30-17:00

地点：广东省深圳市福田区

（二）会议议程

|  |  |
| --- | --- |
| **会议议程** | |
| 13:30-14:00 | 签到 |
| 14:00-14:10 | 领导致辞 |
| **14:10-15:40 主题分享与问答环节:** | |
| 14:10-14:40 | **分享主题1：AI整体发展趋势** |
| 14:40-15:10 | **分享主题2：AI在金融行业发展趋势+银行AI建设及托管应用实践** |
| 15:10-15:40 | **分享主题3：AI大模型与代理式人工智能（Agentic AI）在重塑估值核算、风险管理等方面是如何做到从"人工密集型"到"技术密集型"的转变** |
| **15:40-16:00 中场休息** | |
| **16:00-17:00 交流环节** | |
| 16:00-16:05 | 主持人开场 |
| 16:05-16:20 | **交流话题1：基础设施与场景落地** |
| 16:20-16:35 | **交流话题2：风险管控与解决方案** |
| 16:35-16:50 | **交流话题3：组织协同与未来发展** |
| 16:50-17:00 | 现场交流及总结发言 |

二、报名事宜

本次活动范围面向银行托管业务条线、券商托管业务条线、公募基金和私募基金运营及IT业务条线，每家2个参会名额，请相关业务及IT条线负责人通过链接：https://www.wjx.top/vm/OtXO8tg.aspx#或扫描以下二维码完成线上报名，报名截止时间是2026年7月31日17：00。

![](https://zk-img.faxin.cn//Uedit_Upload/2026-11-03-16-45-58_521595_image.png)

由于活动场地限制等原因，会议名额有限，协会将根据实际情况确定最终参会机构，并向相应报名人员发送报名成功邮件（包含会议具体地点），请报名成功人员届时凭邮件信息参会。没有收到报名成功邮件的人员请关注协会后续相关活动。
