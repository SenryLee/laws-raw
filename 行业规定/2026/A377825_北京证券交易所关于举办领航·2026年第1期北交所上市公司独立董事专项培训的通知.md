# 北京证券交易所关于举办领航·2026年第1期北交所上市公司独立董事专项培训的通知

各上市公司：

为帮助上市公司独立董事了解最新监管政策，增强规范运作意识，提高履职水平，推动提高上市公司质量，北京证券交易所拟于4月17日在线举办领航·2026年第1期北交所上市公司独立董事专项培训。具体安排如下：

一、参会人员

北交所上市公司独立董事以及董事会其他成员。

二、培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| **领航·2026年第1期北交所上市公司独立董事专项培训** | | | |
| **时间** | | **内容** | **主讲人** |
| 4月17日  　　（周五） | 14:00-15:00 | 独董规范履职 | 北交所上市公司管理部业务骨干 |
| 15:00-16:30 | 《上市公司审计委员会工作指引》解读及相关案例解析 | 中国上市公司协会专家 |

注：最终培训内容以实际课程安排为准

三、培训形式

本期培训采用“腾讯会议”线上直播讲解的模式，学员可通过会议码参加培训。会议码将于培训前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

四、报名方式及截止时间

本次培训需收集报名信息。请您扫描下方二维码或者点击链接进行报名，报名截止时间为4月16日12:00。
