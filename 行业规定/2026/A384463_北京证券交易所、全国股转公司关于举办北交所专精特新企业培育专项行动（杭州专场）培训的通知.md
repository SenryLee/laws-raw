# 北京证券交易所、全国股转公司关于举办北交所专精特新企业培育专项行动（杭州专场）培训的通知

## 北京证券交易所关于举办北交所专精特新企业培育专项行动（杭州专场）培训的通知

为推动更多专精特新企业借力资本市场实现转型升级，北京证券交易所、全国股转公司联合浙江省经信厅、浙江省委金融办、浙江证监局等单位，开展专精特新企业培育专项行动，现就杭州专场培训通知如下：

一、培训时间

2026年8月28日（周五）

二、培训地点

杭州明豪voco酒店明悦厅（杭州市滨江区江南大道558号）

三、培训对象

（一）基本范围

具有挂牌上市意愿的专精特新中小企业。

（二）人员要求

参与人员应为企业实际控制人、董事长、总经理，或财务负责人、董秘等上市工作负责人，每家企业报名人数不超过2名。

| 9:30-11:00 | 北交所市场发展情况与最新审核动态 | | 北交所华东基地 　　相关负责人 |

| 14:30-15:30 | 北交所辅导监管常见问题及 　　注意事项解析 | | 浙江证监局 　　专家 |
