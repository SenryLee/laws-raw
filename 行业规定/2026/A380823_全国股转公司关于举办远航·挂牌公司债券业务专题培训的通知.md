# 全国股转公司关于举办远航·挂牌公司债券业务专题培训的通知

## 关于举办远航·挂牌公司债券业务专题培训的通知

各挂牌公司：

为帮助挂牌公司了解掌握公司债券的发行流程及业务规则，促进挂牌公司用好用足债券市场，全国股转公司拟于3月31日在线举办远航·挂牌公司债券业务专题培训，具体安排如下：

一、参会人员

挂牌公司实际控制人、董事长、总经理、董事会秘书、财务总监及负责公司资本运作工作相关人员。

二、培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 时间 | | 课程内容 | 主讲部门 |
| 3月31日  （周二） | 09:30-10:00 | 公司债券专项品种介绍 | 北京证券交易所  债券业务中心 |
| 10:00-11:00 | 公司债券融资实务操作分享 | 证券公司 |

注：最终培训内容以实际课程安排为准

三、培训形式

本次培训采用“腾讯会议”线上直播讲解的模式，请参会人员登录以下会议链接参加培训：

https://meeting.tencent.com/l/yE5FTlLJYoBv
