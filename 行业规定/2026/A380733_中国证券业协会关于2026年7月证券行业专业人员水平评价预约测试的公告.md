# 中国证券业协会关于2026年7月证券行业专业人员水平评价预约测试的公告

## 关于2026年7月证券行业专业人员水平评价预约测试的公告

按照2026年工作计划，中国证券业协会将于2026年7月9日（星期四）举办证券行业专业人员水平评价预约测试（下称测试），本次测试仅面向证券行业机构相关人员开放报考，具体事项公告如下：

一、测试时间及内容

（一）时间安排

测试日期：2026年7月9日（星期四）

报名交费时间：2026年6月25日（星期四）15时至7月2日（星期四）15时

退费截止时间：2026年7月2日（星期四）15时

准考证打印时间：2026年7月7日（星期二）15时

（二）测试费用

测试费用：61元/科/次；交费方式：网上交费。

（三）测试地点

测试地点为北京、石家庄、太原、长春、哈尔滨、上海、南京、杭州、合肥、福州、南昌、济南、郑州、武汉、长沙、广州、南宁、海口、重庆、成都、贵阳、昆明、兰州、乌鲁木齐、大连、青岛、深圳，详细地址以准考证为准。

提示：如遇报名后考区不能正常组织测试，协会将及时通知考生，并为考生办理退款。

（四）测试科目及范围

1、高级管理人员水平评价测试：

《证券公司高级管理人员水平评价测试》科目，参见《证券公司高级管理人员水平评价测试大纲（2024）》

《合规管理人员水平评价测试》科目，参见《证券公司合规管理人员水平评价测试大纲（2024）》

《证券评级业务高级管理人员资质测试》科目，参见《证券评级业务高级管理人员资质测试大纲（2024）》

2、从业人员专业能力水平评价测试的一般业务水平评价测试：

《证券市场基本法律法规》科目，参见《证券行业专业人员一般业务水平评价测试大纲（2025）》

《金融市场基础知识》科目，参见《证券行业专业人员一般业务水平评价测试大纲（2025）》

详见http://www.sac.net.cn/pxzx/pxzdydg/

（五）测试形式及测试题型

测试采取闭卷机考形式，题型为客观题，包括单选题、多选题、判断题、综合题，测试题量均为120题，试卷正确率达到60%以上，即达到该科目基本要求。高级管理人员水平评价测试、一般业务水平评价测试时间均为120分钟。

（六）测试场次安排

|  |  |  |
| --- | --- | --- |
| **测试场次** | **测试时间** | **测试科目** |
| 第1场 | 9:30-11:30 | 证券公司高级管理人员水平评价测试  证券评级业务高级管理人员资质测试 |
| 第2场 | 13:30-15:30 | 证券市场基本法律法规证券公司合规管理人员水平评价测试 |
| 第3场 | 16:00-18:00 | 金融市场基础知识 |

二、测试报名对象和报名方式

（一）报名对象

“证券公司高级管理人员水平评价测试”面向证券公司（含子公司）、证券投资咨询公司、证券财务顾问公司的拟任董事长、从事业务管理工作的其他董事和监事、高级管理人员。

“合规管理人员水平评价测试”面向证券公司（含子公司）的拟任高级管理人员。

“证券评级业务高级管理人员资质测试”面向证券评级公司的拟任董事长、从事业务管理工作的其他董事和监事、高级管理人员。

“从业人员专业能力水平评价测试的一般业务水平评价测试”面向证券公司（含子公司）的拟任董事长、从事业务管理工作的其他董事和监事、高级管理人员。

（二）报名方式

请拟报名的证券行业机构，预先将考生基本信息录入到测试报名系统中，考生方可登录报名系统完成报名流程。详见协会网站“考生服务>水平评价测试>水平评价测试报名”栏目。https://www.sac.net.cn/fwdt/ksfw/sppjcs/sppjcsbm/

三、测试咨询

如有疑问，请登录协会网站查询常见问题及解答，亦可通过网报平台在线咨询。
