# 中国证券业协会关于2026年9月注册国际投资分析师（CIIA）考试的注册、报名公告

## 关于2026年9月注册国际投资分析师（CIIA）考试的注册、报名公告

按照2026年工作计划，中国证券业协会将于2026年9月19日（星期六）举办2026年9月注册国际投资分析师（CIIA）考试，具体事项公告如下：

一、考试注册条件

（一）注册应具备的科目条件

满足以下3个考试科目系列要求之一的，即具备报考CIIA考试的科目条件：

1.系列一科目：通过《证券市场基础知识》、《证券交易》、《证券投资基金》、《证券投资分析》及《证券发行与承销》5个科目考试。

2.系列二科目：通过《金融市场基础知识》、《证券市场基本法律法规》、《证券投资基金基础知识（即基金从业人员资格考试科目二）》、《发布证券研究报告业务》（或《证券投资顾问业务》）4个科目考试。

3.组合系列科目：通过系列一科目中的1科以及以上的考生，需要通过系列二的相关对应科目（以满足系列二中全部4个科目）的对应要求。系列一与系列二科目的对应关系为：

（1）通过系列一中的《证券市场基础知识》、《证券交易》或《证券发行与承销》3个科目中的1科及以上的，可对应系列二中的《金融市场基础知识》。

（2）通过系列一中的《证券投资基金》科目，可对应系列二中的《证券投资基金基础知识》（即基金从业人员资格考试科目二）。

（3）通过系列一中的《证券投资分析》科目，可对应系列二中的《发布证券研究报告业务》（或《证券投资顾问业务》）。

（二）注册应具备的其他条件

1.本科及以上学历；

2.最近五年无不良行为记录；

3.品行端正，具有良好的职业道德;

4.具备满三年“投资”或“咨询”相关工作经验。

二、考试时间及内容

（一）时间安排

考 试 日 期：2026年9月19日（星期六）

报名交费时间：2026年7月20日（星期一）15时至8月20日（星期四）15时

准考证打印时间：2026年9月16日（星期三）15时

退费截止时间：2026年8月20日（星期四）15时

逾期报名系统关闭无法撤销注册或退考，相关费用亦无法退还。

（二）考试费用

1、注册费：每人600元

2、考试费：每人每卷2500元

（三）注册、报名网址

考试注册、报名网址： http://ciia.sac.net.cn

（四）考试地点

考试地点为北京、上海、深圳、西安、武汉和成都6个城市，详细地址以准考证为准。

提示：如遇报名后考区不能正常组织考试，协会将及时通知考生，并为考生办理退款。

（五）考试场次

|  |  |  |
| --- | --- | --- |
| 考试场次 | 考试时间 | 考试科目 |
| 第1场 | 9:00～12:00 | 试卷1 |
| 第2场 | 14:00～17:00 | 试卷2 |

（六）考试科目

考试试卷共分2卷。试卷1包括：经济学、公司财务、股票估值与分析、财务会计和财务报表分析；试卷2包括：固定收益证券估值与分析、衍生产品估值与分析、投资组合管理。

（七）考试资料

根据注册国际投资分析师协会的要求，本次考试沿用2024版考试大纲，使用2026版公式手册，下载网址：https://www.sac.net.cn/fwdt/ksfw/zcgjtzfx/。

考生可在中国财政经济出版社网上书店订购中国证券业协会组织编译的2024版CIIA考试教材（https://zgczjjcbs.tmall.com/）。

为方便考生参考，协会将向注册成功的考生开放近年考试试题，考生可登录报名系统可免费下载。

（八）考试形式

考试采用闭卷机考形式，题型为主观题，请已注册考生从报名系统下载机考软件实例，提前熟悉答题方式。考生可一次性报考一卷或两卷考试。考试语种为中文，每卷考试时间为3小时。

（九）考试有效期

目前CIIA考试的注册及考试成绩长期有效。

三、考试咨询

如有疑问,请登录协会网站查询常见问题及解答,亦可通过网报平台在线咨询。
