# 全国股转公司关于举办护航·2026年第1期主办券商持续督导业务培训的通知

各主办券商：

为帮助主办券商强化合规意识，提高持续督导执业质量，更好服务挂牌公司规范发展，全国股转公司拟于4月10日在北京举办护航·2026年第1期主办券商持续督导业务培训。具体安排如下：

一、培训时间、地点

时间：2026年4月10日

地点：北京中国职工之家饭店（北京市西城区复兴门外大街真武庙路1号）

二、培训对象

主办券商持续督导相关业务人员。

三、培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 护航·2026年第1期主办券商持续督导业务培训 | | | |
| 时间 | | 课程主题 | 主讲部门 |
| 4月10日 | 09:30-10:30 | 主办券商持续督导工作要点 | 全国股转公司 　　挂牌公司管理一部 |
| 10:45-11:15 | 合规交易督导要点 |
| 11:15-11:45 | 日常监管常见问题及注意事项 | 北京证监局 　　公司监管三处 |

| 15:15-16:30 | 退市公司持续督导要点 | 全国股转公司 　　代办转让服务部 |

注：最终培训内容以实际安排为准。

四、报名时间及方式

本次培训需收集报名信息，请填写真实信息及有效联系方式，我们将在培训前通过手机短信、邮件将审核结果、培训具体地址发送至报名人员。因培训名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、公司名称、报名人员信息及取消原因等）。报名成功后，如未参训或缺勤，相关情况将反馈任职公司。

报名截止时间：2026年4月3日（周五）17:00，培训名额有限，额满或过期则不再受理，请务必尽早完成报名。

报名二维码：

报名链接：https://neeqbse.wjx.cn/vm/Qp7dVfP.aspx

五、培训费用

培训不收取培训费。餐费、住宿费、交通费及其他费用请学员自理。学员如需预订培训酒店住宿，可自行联系北京中国职工之家饭店贾经理13811637138，并报“全国股转公司培训”获取协议价。

六、培训考勤

课务组将进行考勤并形成培训记录，缺勤情况将反馈任职公司，请学员提前做好安排，保证全程参与。

七、温馨提示

1、培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，请注意个人安全，增强防范意识。

2、培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。

八、联系方式

咨询时间：交易日　上午8:30-11:30；下午14:00-17:00。

咨询电话：010-63889551、010-63889802。
