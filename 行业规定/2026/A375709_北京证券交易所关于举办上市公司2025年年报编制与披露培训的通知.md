# 北京证券交易所关于举办上市公司2025年年报编制与披露培训的通知

## 关于举办上市公司2025年年报编制与披露培训的通知

各市场主体：

为保障上市公司顺利开展2025年年报编制与披露工作，提高年报信息披露质量，北京证券交易所拟于1月29日在线举办上市公司2025年年报编制与披露培训。培训具体安排如下：

一、培训对象

上市公司董事会秘书、证券事务代表、信披相关人员以及上市公司保荐机构持续督导人员。

二、培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| **上市公司2025年年报编制与披露培训** | | | |
| **时间** | | **课程内容** | **主讲人** |
| 1月29日  （周四） | 09:00-10:00 | 上市公司年报监管重点问题讲解 | 中国证监会专家 |
| 10:00-11:00 | 上市公司2025年年报编制与披露重点问题讲解 | 北京证券交易所  上市公司管理部  业务骨干 |
| 11:00-12:00 | 上市公司年报编制工具使用及报送注意事项 | 中证股转科技公司  业务骨干 |

注：最终培训内容以实际课程安排为准

三、培训形式

本次培训采用线上直播讲解的模式，参会人员可通过直播链接参加培训，建议选择网络较好的地点以保证视频及语音的流畅。

直播链接：https://meeting.tencent.com/l/VHXEidx01uYu

培训结束后，负责年报披露相关人员可通过“北交所官网-服务-培训服务平台-北证讲堂-公开课-规则解读专题培训-持续监管”栏目观看培训录播。（网址：https://edu.bse.cn/neeqedu/bse/course/detail/lesson/list.jspx?courseid=104）
