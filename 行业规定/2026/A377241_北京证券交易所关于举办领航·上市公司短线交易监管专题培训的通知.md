# 北京证券交易所关于举办领航·上市公司短线交易监管专题培训的通知

各上市公司：

为持续优化短线交易监管，切实维护市场秩序，帮助上市公司更好掌握中国证监会发布的《关于短线交易监管的若干规定》，北京证券交易所拟于3月18日在线举办领航·上市公司短线交易监管专题培训。具体安排如下：

一、参会人员

北交所上市公司控股股东、实际控制人、持股5%以上股东、董事、高级管理人员等有关主体。

二、培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| 时间 | | 课程内容 | 主讲人 |
| 3月18日  　　（周三） | 10:00-10:30 | 《关于短线交易监管的若干规定》解读 | 北交所上市公司管理部  　　业务骨干 |

注：最终培训内容以实际课程安排为准
