# 北京证券交易所、全国股转公司关于举办北交所专精特新企业培育专项行动（厦门专场）培训的通知

## 北京证券交易所关于举办北交所专精特新企业培育专项行动（厦门专场）培训的通知

为推动更多专精特新企业借力资本市场实现转型升级，北京证券交易所、全国股转公司联合厦门市委金融办、厦门证监局等单位，开展专精特新企业培育专项行动，现就厦门专场培训通知如下：

一、培训时间

2026年8月27日（周四）

二、培训地点

厦门天元酒店三楼天元AB厅（思明区环岛东路1813号中航紫金广场）

三、培训对象

（一）基本范围

具有挂牌上市意愿的专精特新中小企业。

（二）人员要求

参与人员应为企业实际控制人、董事长、总经理，或财务负责人、董秘等上市工作负责人，每家企业报名人数不限。

四、培训议程

|  |  |  |
| --- | --- | --- |
| 时间 | 内容 | 主讲人 |
| 09:00-10:30 | 企业上市路径规划与 　　北交所市场最新运行情况 | 北交所华南基地 　　相关负责人 |
| 10:30-12:00 | 股改重点及上市常见问题 　　应对方案 | 证券公司专家 |
| 12:00-12:20 | 互动交流 | — |
| 13:30-15:00 | 新三板市场功能及 　　服务专精特新企业政策介绍 | 全国股转公司 　　挂牌审查部业务骨干 |
| 15:10-15:30 | 厦门“专精特新”专板建设与新三板绿色通道政策解析 | 厦门两岸股权交易中心专家 |
| 15:30-16:30 | 拟上市企业纳税合规规划 | 会计师事务所税务专家 |

五、培训报名

（一）请有参与意向的企业扫描下方二维码报名，填写真实信息及有效联系方式，活动前将通过手机短信发送相关信息至报名人员。因名额有限，请企业通过审核后准时参加活动，如无法参加，请提前联系工作人员取消报名。报名截止时间为2026年8月26日（周三）17:00。

报名链接：https://neeqbse.wjx.cn/vm/rXYo0HK.aspx

（二）本次活动不收取任何费用，统一提供培训当日午餐。住宿、交通及其他费用请自理。

咨询时间：交易日　上午8:30-11:30；下午14:00-17:00。

咨询电话：010-63889802、010-63889551。
