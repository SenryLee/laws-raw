# 郑州商品交易所关于召开2026年“保险+期货”项目申报宣讲会的通知

## 关于召开2026年“保险+期货”项目申报宣讲会的通知

郑商函〔2026〕420号

各相关单位：

2026年4月30日，郑州商品交易所（以下简称郑商所）发布了《关于开展2026年“保险+期货”工作的通知》，为进一步明确工作导向和相关要求，解答各单位在项目申报过程中的疑问，郑商所拟举办项目申报宣讲会，请有意向申报项目的各单位相关人员参加。具体通知如下：

一、会议议程

时间：2026年5月6日15:00-16:30

主题：2026年“保险+期货”项目申报宣讲会

|  |  |  |
| --- | --- | --- |
| 时间 | 内容 | 宣讲部门 |
| 15:00-15:40 | 郑商所2026年“保险+期货”  项目申报讲解 | 郑商所商品二部 |
| 15:40-16:30 | 项目申报交流答疑 |

二、参会方式

本次宣讲会采取线上腾讯会议的方式举办，参加线上会议通过PC端或手机端腾讯会议APP，输入会议号929663916参会。

各项目申报单位于会议期间均可登录（提前15分钟开放登录），进入会议后请按照“单位名称-姓名”修改昵称。

特此通知。

郑州商品交易所
