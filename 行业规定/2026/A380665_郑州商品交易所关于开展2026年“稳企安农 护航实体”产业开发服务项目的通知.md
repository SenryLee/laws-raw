# 郑州商品交易所关于开展2026年“稳企安农 护航实体”产业开发服务项目的通知

## 关于开展2026年“稳企安农 护航实体”产业开发服务项目的通知

郑商函〔2026〕413号

各会员单位：

为更好发挥期货市场服务实体经济功能，有效激励期货公司发挥专业优势，引导产业企业利用期货市场进行风险管理，郑州商品交易所（以下简称郑商所）决定开展“2026年‘稳企安农 护航实体’产业开发服务项目”（以下简称产业开发服务项目）。现将相关事项通知如下。

一、支持重点

支持期货公司发挥专业优势，开发服务产业企业参与期货市场，着力提升产业客户期货参与度。

二、申请主体

期货公司，须以总部名义申请。

三、项目内容

产业开发服务项目包含两类项目。

（一）重点企业期货项目

1.服务对象

注册成立时间在2024年12月31日以前的项目品种对应的产业企业，企业为2026年首次开户或2025年在项目申请品种上无交易记录，且满足下列条件之一。

（1）符合规模标准的产业企业（规模标准见附件1）。

（2）上海证券交易所、深圳证券交易所、北京证券交易所的上市公司。

（3）地级市（含地区、自治州、盟）及以上国有控股企业，其中国有持股比例要求不少于50%；或国有持股比例未超过50%，但为第一大股东，并且通过股东协议、公司章程、董事会决议或其他协议安排能够对其实际支配的企业。

2.项目品种

菜籽油、甲醇、玻璃、菜籽粕、硅铁、锰硅、棉纱、苹果、红枣、尿素、纯碱、短纤、花生、烧碱、对二甲苯、瓶片、丙烯等17个期货品种。

3.考核标准及支持标准

考核期内，服务对象在项目申请品种上累计净持仓量1及持仓天数达到要求，给予期货公司相应标准资金支持。

同一家企业每个品种只能参与1个重点企业期货项目。

表1 重点企业期货项目考核标准及支持标准

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 期货  品种 | 菜籽油、甲醇、菜籽粕 | 玻璃、硅铁、锰硅、纯碱、短纤 | 棉纱、苹果、红枣、尿素、花生、烧碱、对二甲苯、瓶片、丙烯 | 持仓天数  要求 | 支持  标准 |
| 累计净持仓量（手） | 6000 | 4000 | 2000 | 20个交易日 | 10万元 |
| 18000 | 12000 | 6000 | 30个交易日 | 20万元 |

4.申请材料

申请材料包括重点企业期货项目备案表、企业确认函（见附件2、4）、企业营业执照，以及下列证明材料。

（1）符合规模标准的企业需提供能够证明企业规模的材料。

（2）上市公司需提供能够证明企业产业属性的材料（如贸易合同及发票等）。

（3）地级市及以上国有控股企业需提供股权穿透图（加盖企业公章）、能够证明企业产业属性的材料（如贸易合同及发票等）；对于国有持股比例未超过50%，但为第一大股东，并且通过股东协议、公司章程、董事会决议或其他协议安排能够对其实际支配的企业，需补充能证明国有股东对企业实际控制权的相关材料。

（4）集团分公司可申请重点企业期货项目，需补充集团公司业务授权说明，明确分公司期货业务开展资质，且说明集团公司及其他分公司未开展申请品种的期货业务。

（5）申请甲醇、烧碱、对二甲苯、丙烯等危险化学品品种，需提供在有效期内的危险化学品经营许可证。

合同、发票等证明材料的时间范围需在2024年1月1日至2025年12月31日间。

（二）中小企业期货项目

1.服务对象

注册成立时间在2024年12月31日以前的除重点企业之外的项目品种对应的产业企业，企业为2026年首次开户。

2.项目品种

甲醇、玻璃、硅铁、锰硅、棉纱、苹果、红枣、尿素、纯碱、短纤、花生、烧碱、对二甲苯、瓶片、丙烯等15个期货品种。

3.考核标准及支持标准

考核期内，服务对象在项目申请品种上累计净持仓量及持仓天数达到要求，给予期货公司相应标准资金支持。

同一法人名下企业仅可申请参与1个中小企业期货项目。

表2 中小企业期货项目考核标准及支持标准

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 期货  品种 | 甲醇 | 玻璃、硅铁、锰硅、纯碱、短纤 | 棉纱、苹果、红枣、尿素、花生、烧碱、对二甲苯、瓶片、丙烯 | 持仓天数  要求 | 支持  标准 |
| 累计净持仓量（手） | 3000 | 2000 | 1000 | 20个交易日 | 5万元 |

4.申请材料

申请材料包括中小企业期货项目备案表、企业确认函（见附件3、4）、企业营业执照，以及能够证明企业产业属性的材料（如贸易合同及发票等）。

申请甲醇、烧碱、对二甲苯、丙烯等危险化学品品种，需提供在有效期内的危险化学品经营许可证。

合同、发票等证明材料的时间范围需在2024年1月1日至2025年12月31日间。

四、项目流程

（一）合作单位申请

意向参与产业开发服务项目的期货公司根据《郑州商品交易所产业开发服务项目管理办法》（以下简称《管理办法》）要求，以总部名义向郑商所提出书面申请，申请截止日期为2026年5月15日。合作单位申请表及期货公司营业执照等申请材料需在截止日期前发送至scfzb@czce.com.cn。

（二）项目备案申请

郑商所自2026年5月11日起通过会服系统接收项目申请，申请截止日期为2026年10月16日。产业开发服务项目设置申请数量上限，当项目申请数量达到上限时，系统将自动关闭项目申请接收通道。

期货公司风险管理公司，不参与本次项目申请。2026年郑商所产融示范企业，不参与本次项目申请。

期货公司应对服务对象资质进行审查把关，对发票材料进行验真，通过会服系统填写并提交项目备案表等申请材料（产业属性证明材料要求通过会服系统另行通知）。根据审核需要，郑商所可对服务对象的申请品种现货业务情况等进行电话调研。

（三）考核期

自项目完成备案之日的下一个交易日起，统计服务对象持仓量及持仓天数。考核期自备案之日起至2026年12月11日截止。

对于已备案通过的项目，若自备案通过之日起的40个交易日内无申请品种持仓，系统将自动停止项目考核，并进行清退。

（四）资金支持

产业开发服务项目设置三次持仓考核节点，首次考核日期为2026年7月30日，第二次考核日期为2026年9月30日，第三次考核日期为2026年12月11日。郑商所于考核节点统计已备案项目持仓情况，生成支持额度，并通知期货公司开具合规发票，通过费用支付的方式给予支持，单个项目支持额度之和不超过该项目的最高支持标准。

五、监督管理

根据《管理办法》，合作单位应确保提交的各类申请材料真实、准确，不存在隐瞒、错报及误导等情况，严格按照备案内容运行项目。若发现项目存在违规违约行为或出现风险隐患，郑商所有权对合作单位采取取消项目备案、追回支持费用、终止合作协议等各项措施。
