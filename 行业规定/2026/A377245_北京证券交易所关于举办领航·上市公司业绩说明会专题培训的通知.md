# 北京证券交易所关于举办领航·上市公司业绩说明会专题培训的通知

各上市公司：

业绩说明会是上市公司和投资者沟通交流的重要渠道。为帮助上市公司做好业绩说明会相关工作，助力上市公司与投资者搭建顺畅沟通渠道，形成良好沟通机制，北京证券交易所拟于3月31日在线举办领航·上市公司业绩说明会专题培训。具体安排如下：

一、培训对象

北交所上市公司董事长、总经理、董事会秘书、财务总监、证券事务代表及其他信息披露工作人员。

二、培训安排

|  |  |  |  |
| --- | --- | --- | --- |
| 领航·上市公司业绩说明会专题培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 3月31日  　　（周二） | 14:30-15:30 | 如何召开高质量的业绩说明会 | 媒体专家 |
| 15:30-16:30 | 上市公司舆情管理与应对 |

注：最终培训内容以实际课程安排为准

三、培训形式

本期培训采用“腾讯会议”线上直播讲解的模式，学员可通过会议码参加培训。会议码将于培训前通过手机短信发送至报名人员，报名时请填写真实信息及有效联系方式。

四、报名方式及截止时间

本次培训需收集报名信息。请您扫描下方二维码或者点击链接进行报名，报名截止时间为3月30日12:00。
