# 全国股转公司关于举办远航·挂牌公司并购重组专题培训的通知

各挂牌公司：

为深入贯彻新“国九条”要求，进一步活跃并购重组市场，帮助挂牌公司借助并购重组工具实现高质量发展，全国股转公司拟于5月28日在苏州举办远航·挂牌公司并购重组专题培训。具体安排如下：

一、培训时间、地点

培训时间：2026年5月28日

培训地点：苏州日航酒店（苏州市虎丘区长江路368号）

二、培训对象

挂牌公司实际控制人、董事长、总经理、董事会秘书、财务总监及负责公司资本运作工作相关人员，培训名额有限，额满截止。

三、培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 远航·挂牌公司并购重组专题培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 5月28日 　　（周四） | 09:00-10:20 | 新三板并购重组解析 | 全国股转公司 　　挂牌审查部 　　业务骨干 |
| 10:20-11:30 | 并购重组与企业战略 | 研究机构 　　专家 |

注：最终培训内容以实际课程安排为准

四、报名时间及方式

本次培训需收集报名信息，请您扫码或点击链接进行报名。请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、公司代码、报名人员信息及取消原因等）。报名成功后，如未参与培训，相关情况将反馈任职公司并影响后续培训资格。

报名截止时间：2026年5月26日（周二）12:00，过期或额满后报名不再受理，请务必尽早完成报名。

报名二维码：

报名链接：https://neeqbse.wjx.cn/vm/Otg9kmZ.aspx

五、培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费及其他费用请学员自理。如需预定培训酒店住宿请联系陆经理18816291836，并报“全国股转公司培训”获取协议价。

六、培训考勤

请学员提前做好安排，保证全程参与。课务组将每半天进行考勤并形成培训记录，未按计划参训、缺勤等情况将反馈任职公司，并影响后续培训资格。

七、温馨提示

1、培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2、培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。
