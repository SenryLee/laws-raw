# 全国股转公司关于举办远航·2026年第1期挂牌公司实际控制人、董事长专项培训的通知

各挂牌公司：

为加强对挂牌公司实际控制人、董事长规范意识的引导，帮助其提升守法意识、合规意识，充分发挥“领航人”作用，促进挂牌公司高质量发展，全国股转公司拟于5月15日在北京举办远航·2026年第1期挂牌公司实际控制人、董事长专项培训。具体安排如下：

一、培训时间、地点

培训时间：2026年5月15日

培训地点：北京广州大厦酒店（北京市西城区西单横二条甲三号）

二、培训对象

挂牌公司实际控制人、董事长，每家公司限报2人，培训名额有限，额满截止。

三、培训课程

|  |  |  |  |
| --- | --- | --- | --- |
| 远航·2026年第1期挂牌公司实际控制人、董事长专项培训 | | | |
| 时间 | | 课程内容 | 主讲人 |
| 5月15日 　　（周五） | 09:30-10:30 | 挂牌公司监管情况及规范运作要求 | 中国证监会公众司专家 |
| 10:30-11:30 | 公众公司违法违规案例警示 | 中国证监会稽查局专家 |
| 14:00-15:30 | 挂牌公司规范运作要点解析 | 全国股转公司 　　挂牌公司管理一部业务骨干 |
| 15:30-16:30 | 十五五规划时期宏观经济形势分析及政策展望 | 中国财政科学研究院专家 |

注：最终培训内容以实际课程安排为准

四、报名时间及方式

本次培训需收集报名信息，请填写真实信息及有效联系方式。因培训名额有限，请您报名后准时参加，如无法参加请提前将取消说明加盖公章发送至peixun@neeq.com.cn（邮件正文请列示取消说明内容，需涵盖报名场次、公司代码、报名人员信息及取消原因等）。报名成功后，未经请假缺席培训的人员，将被记入培训诚信档案并反馈监管机构。

报名截止时间：2026年5月13日（周三）12:00，过期或额满后报名不再受理，请务必尽早完成报名。

报名二维码：

报名链接：https://neeqbse.wjx.cn/vm/rCdUnxh.aspx

五、培训费用

培训不收取培训费，主办方提供培训当日午餐。住宿费、交通费及其他费用请学员自理。如需预定培训酒店住宿请联系王经理13901380248，并报“全国股转公司培训”获取协议价。

六、培训考勤

必须学员本人参加培训，他人不得替代。课务组每半天进行考勤并形成培训记录，缺勤情况将反馈监管机构，请学员提前做好安排，保证全程参与。

七、温馨提示

1、培训期间课务组不会组织其他与培训无关的活动，课余时间请学员自行安排，注意保护个人安全并增强防范意识。

2、培训不提供纸质版讲义，请学员尊重授课讲师相关资料的知识产权，请勿外传。

八、联系方式
