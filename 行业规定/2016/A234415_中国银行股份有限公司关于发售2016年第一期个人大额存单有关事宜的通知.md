# 中国银行股份有限公司关于发售2016年第一期个人大额存单有关事宜的通知

尊敬的客户：

我行将于2016年3月1日起发售2016年第一期个人大额存单，并同步推出转让功能，现将有关事宜公告如下：

产品简介

个人大额存单是由我行发售的，面向个人客户的记账式大额存款凭证，是存款类金融产品，属一般性存款。

发售信息

本期发售人民币标准类固定利率大额存单，包括1个月、3个月、6个月、9个月、1年、18个月、2年、3年共计八款子产品，起点金额、年化利率具体如下：

|  |  |  |
| --- | --- | --- |
| 产品期限 | 起点金额 | 年化利率 |
| 1个月 | 30万元 | 1.53% |
| 3个月 | 30万元 | 1.54% |
| 6个月 | 30万元 | 1.82% |
| 9个月 | 30万元 | 2.09% |
| 1年 | 30万元 | 2.10% |
| 18个月 | 30万元 | 2.93% |
| 2年 | 30万元 | 2.94% |
| 3年 | 30万元 | 3.85% |

发售渠道

中国银行全辖各营业网点、网上银行和手机银行。

发售对象

凡在我行开立活期账户的个人客户均可持本人实名制有效身份证件到我行营业网点柜台或通过网上银行或手机银行购买，初次购买前请先行前往我行营业网点柜台进行签约。

产品优势

收益率高：本产品利率较同期限现有定期存款更具竞争力；

流动性好：本产品可办理全部/部分提前支取、质押贷款及存款证明，且允许在个人客户间转让。

安全性强：本产品保本保息，不存在本金和收益损失风险。

友情提示

本期产品提前支取采取靠档计息规则。

本期产品采用电子方式发售，存折和借记卡对账薄支持打印产品交易信息。

本期产品不可自动转存，到期一次还本付息。

本期产品额度有限，先到先得，售罄为止。

请您在签约前仔细阅读《中国银行股份有限公司个人大额存单产品客户须知》。

详情请咨询当地中国银行营业网点或95566客服电话。
