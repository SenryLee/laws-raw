# 深圳证券交易所、深圳证券信息有限公司关于发布深证创新系列指数的公告

## 关于发布深证创新系列指数的公告

为反映深圳市场创新型企业整体运行情况，推动上市公司通过创新发展做大做强，深圳证券交易所与深圳证券信息有限公司定于2016年12月1日发布深证创新系列指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399016 | 深证创新指数 | 深证创新 | 2012年12月31日 | 1000 |
| 399017 | 中小板创新指数 | SME创新 | 2012年12月31日 | 1000 |
| 399018 | 创业板创新指数 | 创业创新 | 2012年12月31日 | 1000 |

深证创新系列指数按照创新发展能力综合排名，分别从深圳市场、中小板、创业板A股公司中，选取前100名公司作为样本股。创新发展能力从创新资源、创新投入、创新绩效三个维度进行综合评价。

深证创新系列指数采用等权重进行计算，每年7月的第一个交易日进行样本股定期调整。指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关深证创新系列指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
