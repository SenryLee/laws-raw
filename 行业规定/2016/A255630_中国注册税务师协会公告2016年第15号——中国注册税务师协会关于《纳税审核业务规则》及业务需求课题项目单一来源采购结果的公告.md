# 中国注册税务师协会公告2016年第15号——中国注册税务师协会关于《纳税审核业务规则》及业务需求课题项目单一来源采购结果的公告

## 中国注册税务师协会公告

2016年第15号

## 中国注册税务师协会关于《纳税审核业务规则》及业务需求课题项目单一来源采购结果的公告

为充分利用社会资源，提升税务师行业的执业水平，中税协于2016年6月12日发布了《纳税审核业务规则》及业务需求编写课题项目的招标公告。至投标申报截止日期，此项目只有北京永大税务师事务所1家投标人递交了投标文件，因项目未满开标条件，此项目流标。为提高课题项目采购效率和质量，根据《中华人民共和国政府采购法》和《中国注册税务师协会课题项目经费管理办法》有关规定，本课题项目采用单一来源采购方式。7月20日，我会根据课题项目要求通过谈判程序确定课题项目承担单位，现公告如下：

|  |  |  |
| --- | --- | --- |
| 课题项目 | 承担单位 | 项目负责人 |
| 《纳税审核业务规则》及  业务需求编写 | 北京永大税务师事务所有限公司 | 王伟明（北京永大税务师事务所有限公司董事长） |

自本公告发布之日起五个工作日内，各有关当事人如有异议可以通过书面形式反馈至中税协，逾期将依法不予受理。公示期结束后，我会将与课题承担单位签订立项协议。
