# 深圳证券交易所、深圳证券信息有限公司关于发布创业300低波动率、高贝塔指数的公告

## 关于发布创业300低波动率、高贝塔指数的公告

为进一步丰富和完善创业板指数体系，刻画创业板市场风险收益特征，深圳证券交易所与深圳证券信息有限公司定于2016年12月20日发布创业300低波动率、高贝塔指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基点 |
| 399692 | 创业300低波动率指数 | 创业低波 | 2013年6月28日 | 1000 |
| 399694 | 创业300高贝塔指数 | 创业高贝 | 2013年6月28日 | 1000 |

创业300低波动率、高贝塔指数是以创业300指数为样本空间的风险策略指数。创业低波按照最近一年日收益率的波动率升序排名，选择排名前100的股票作为样本股，样本股权重与其历史波动率的倒数成正比。创业高贝指数按照最近一年的贝塔值降序排名，选择排名前100的股票作为样本股，样本股权重与其历史贝塔值成正比。指数于每年1月和7月的第一个交易日进行样本股定期调整。

创业300低波动率、高贝塔指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过国证指数网发布收盘行情数据。

有关创业300低波动率、高贝塔指数的详细资料可参见国证指数网（http://www.cnindex.com.cn）。
