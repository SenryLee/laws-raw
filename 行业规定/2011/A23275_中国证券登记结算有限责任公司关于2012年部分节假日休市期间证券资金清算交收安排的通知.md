# 中国证券登记结算有限责任公司关于2012年部分节假日休市期间证券资金清算交收安排的通知

各结算单位：

根据证监会《关于2012 年部分节假日放假和休市安排有关问题的通知》（证监办发[2011]103号）精神和沪深证券交易所休市安排，现将2012 年部分节假日休市期间资金清算交收安排通知如下：

**一、**元旦休市2天（2011年12月31日-2012年1月3日、双休日除外）

2011年12月30日发生的证券交易（B股除外）和当日到期的债券回购，资金清算日为2011年12月30日，资金交收日为2012年1月4日。

2012年1月4日发生的证券交易（B股除外）和2011年12月31日-2012年1月4日到期的债券回购，资金清算日为2012年1月4日，资金交收日为2012年1月5日。

2011年12月28日、29日、30日发生的B股交易，资金交收日依次为2012年1月4日、5日、6日。

**二、**春节休市5天（2012年1月21日-29日、双休日除外）

2012年1月20日发生的证券交易（B股除外）和当日到期的债券回购，资金清算日为2012年1月20日，资金交收日为2012年1月30日。

2012年1月30日发生的证券交易（B股除外）和2012年1月21日-30日到期的债券回购，资金清算日为2012年1月30日，资金交收日为2012年1月31日。

2012年1月18日、19日、20日发生的B股交易，资金交收日依次为2012年1月30日、1月31日、2月1日。

**三、**清明节休市3天（2012年3月31日-4月4日、双休日除外）

2012年3月30日发生的证券交易（B股除外）和当日到期的债券回购，资金清算日为2012年3月30日，资金交收日为2012年4月5日。

2012年4月5日发生的证券交易（B股除外）和2012年3月31日-4月5日到期的债券回购，资金清算日为2012年4月5日，资金交收日为2012年4月6日。

2012年3月28日、29日、30日发生的B股交易，上海市场资金交收日依次为2012年4月5日、6日、9日；深圳市场资金交收日依次为2012年4月5日、10日、10日。

**四、**劳动节休市2天（2012年4月28日-5月1日、双休日除外）

2012年4月27日发生的证券交易（B股除外）和当日到期的债券回购，资金清算日为2012年4月27日，资金交收日为2012年5月2日。

2012年5月2日发生的证券交易（B股除外）和2012年4月28日--5月2日到期的债券回购，资金清算日为2012年5月2日，资金交收日为2012年5月3日。

2012年4月25日、26日、27日发生的B股交易，资金交收日依次为2012年5月2日、3日、4日。

**五、**端午节休市1天（2012年6月22日-24日、双休日除外）

2012年6月21日发生的证券交易（B股除外）和当日到期的债券回购，资金清算日为2012年6月21日，资金交收日为2012年6月25日。

2012年6月25日发生的证券交易（B股除外）和2012年6月22日-25日到期的债券回购，资金清算日为2012年6月25日，资金交收日为2012年6月26日。

2012年6月19日、20日、21日发生的B股交易，资金交收日依次为2012年6月25日、26日、27日。

**六、**中秋节、国庆节休市5天（2012年9月29日-10月7日、双休日除外）

2012年9月28日发生的证券交易（B股除外）和当日到期的债券回购，资金清算日为2012年9月28日，资金交收日为2012年10月8日。

2012年10月8日发生的证券交易（B股除外）和2012年9月29日-10月8日到期的债券回购，资金清算日为2012年10月8日，资金交收日为2012年10月9日。

2012年9月26日、27日、28日发生的B股交易，上海市场资金交收日依次为2012年10月9日、10日、11日；深圳市场资金交收日为2012年10月8日、9日、10日。

**七、**2012年美国公众假日（非美元清算日）期间上海市场B股交收业务安排，见附表1。

**八、**2012年香港公众假日期间深圳市场B股交收业务安排，见附表2。
