# 深圳证券交易所、深圳证券信息有限公司关于编制和发布深证乐富基金系列指数的公告

为全面反映深市乐富基金及细分产品的二级市场整体走势，为市场及投资者提供更加丰富的基金投资参考依据，深圳证券交易所和深圳证券信息公司决定于2011年12月2日起正式发布深证乐富基金指数和深证ETF指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399103 | 深证乐富基金指数 | 乐富指数 | 2004年12月31日 | 1000 |
| 399306 | 深证ETF指数 | 深证ETF | 2010年12月31日 | 1000 |

深证乐富基金指数和深证ETF指数均为综合指数，样本分别包含在深市上市交易的全部基金和ETF。指数以基金份额为权数进行加权计算，不设权重上限，基金份额每月月初调整一次，新上市基金第二个交易日纳入指数计算。

指数编制方案及最新样本股名单等资料参见巨潮指数网（http：//index.cninfo.com.cn）。

特此公告。
