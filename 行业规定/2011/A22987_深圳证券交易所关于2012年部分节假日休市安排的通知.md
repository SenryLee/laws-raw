# 深圳证券交易所关于2012年部分节假日休市安排的通知

各会员单位：

根据中国证监会《关于2012年部分节假日放假和休市安排有关问题的通知》（证监办发[2011]103号），现将2012年部分节假日休市安排通知如下：

**一、**元旦：2012年1月1日（星期日）至1月3日（星期二）休市，1月4日（星期三）起照常开市。2011年12月31日（星期六）为周末休市。

**二、**春节：1月22日（星期日）至1月28日（星期六）休市，1月30日（星期一）起照常开市。1月21日（星期六）、1月29日（星期日）为周末休市。

**三、**清明节：4月2日（星期一）至4月4日（星期三）休市，4月5日（星期四）起照常开市。3月31日（星期六）、4月1日（星期日）为周末休市。

**四、**劳动节：4月29日（星期日）至5月1日（星期二）休市，5月2日（星期三）起照常开市。4月28日（星期六）为周末休市。

**五、**端午节：6月22日（星期五）至6月24日（星期日）休市，6月25日（星期一）起照常开市。

**六、**中秋节、国庆节：9月30日（星期日）至10月7日（星期日）休市，10月8日（星期一）起照常开市。9月29日（星期六）为周末休市。

节假日期间清算交收事宜按照中国证券登记结算有限责任公司的安排进行。

请各会员单位据此安排好有关工作。

深圳证券交易所　　

二○一一年十二月二十六日
