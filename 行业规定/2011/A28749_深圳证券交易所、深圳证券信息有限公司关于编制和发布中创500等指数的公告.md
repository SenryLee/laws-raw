# 深圳证券交易所、深圳证券信息有限公司关于编制和发布中创500等指数的公告

为进一步反映多层次资本市场蓬勃发展态势，刻画中小板和创业板共同的投资特征，提供更丰富的投资标的和分析工具，深圳证券交易所和深圳证券信息公司决定于2011年8月15日起正式发布中小板创业板500指数、中小板创业板400指数及中小板创业板500风格系列指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399624 | 中小板创业板400指数 | 中创400 | 2010年6月30日 | 1000 |
| 399625 | 中小板创业板500指数 | 中创500 | 2010年6月30日 | 1000 |
| 399626 | 中创500成长指数 | 中创成长 | 2010年6月30日 | 1000 |
| 399627 | 中创500价值指数 | 中创价值 | 2010年6月30日 | 1000 |

中创系列指数根据考察期内样本股的流通市值与成交金额综合排名，选取中小板和创业板中代表性较强、流动性较好的股票构成成份股。其中，排名第1～100的股票构成中创100指数成份股（2011年2月28日发布），排名第1～500的股票构成中创500指数成份股，排名第101～500的股票构成中创400指数成份股。在中创500指数样本股中，按成长因子由高到低进行排名，选取前1/3（166只）的样本构成中创成长指数；按价值因子由高到低进行排名，选取前1/3（166只）的样本构成中创价值指数。

指数编制方案及最新样本股名单等资料参见巨潮指数网（http：//index.cninfo.com.cn）。
