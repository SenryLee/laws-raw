# 深圳证券交易所、深圳证券信息有限公司关于发布深证等权重系列指数的公告

为了反映深圳市场核心指数在等权重维度下的收益表现，提供多元化的分析工具和业绩基准，深圳证券交易所和深圳证券信息公司决定于2011年10月28日发布深证100等权重指数、深证300等权重指数、中小板等权重指数和创业板等权重指数。

上述四条等权重指数分别以深证100、深证300、中小板指数和创业板指数为母指数，按等权重方式进行加权计算。指数代码、简称、基日和基点见下表：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399632 | 深证100等权重指数 | 深100 EW | 2002年12月31日 | 1000 |
| 399633 | 深证300等权重指数 | 深300 EW | 2004年12月31日 | 1000 |
| 399634 | 中小板等权重指数 | 中小板EW | 2006年12月29日 | 1000 |
| 399635 | 创业板等权重指数 | 创业板EW | 2010年9月30日 | 1000 |

指数编制方案及最新样本股名单等资料参见巨潮指数网（http：//index.cninfo.com.cn）。

特此公告。
