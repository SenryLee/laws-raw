# 深圳证券交易所、深圳证券信息有限公司关于发布深证装备等四条主题指数的公告

深圳证券交易所和深圳证券信息有限公司将于2011年11月15日起发布四条深证主题指数，分别为：深证装备指数、深证房地产指数、深证环保指数和深证大宗商品生产商指数。

四条深证主题指数均以2004年12月31日作为基日，以1000点作为基点，具体代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399636 | 深证装备指数 | 深证装备 | 2004年12月31日 | 1000 |
| 399637 | 深证房地产指数 | 深证地产 | 2004年12月31日 | 1000 |
| 399638 | 深证环保指数 | 深证环保 | 2004年12月31日 | 1000 |
| 399639 | 深证大宗商品生产商指数 | 深证大宗 | 2004年12月31日 | 1000 |

深证主题指数包括纯价格指数和全收益指数，纯价格指数通过深交所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单等资料参见巨潮指数网（http：//index.cninfo.com.cn）。
