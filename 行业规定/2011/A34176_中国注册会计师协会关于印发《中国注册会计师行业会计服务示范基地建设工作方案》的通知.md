# 中国注册会计师协会关于印发《中国注册会计师行业会计服务示范基地建设工作方案》的通知

## 中国注册会计师协会关于印发《中国注册会计师行业会计服务示范基地建设工作方案》的通知（会协[2011]19号）

为深入贯彻全国“两会精神”和国务院办公厅转发财政部《关于加快发展我国注册会计师行业的若干意见》（国办发[2009]56号），认真落实中注协“五代会”关于实施新业务拓展战略的要求，根据《会计师事务所服务经济社会发展新领域业务拓展工作方案》（会协[2010]16号）的总体安排以及《关于印发＜各地注协认领新业务领域拓展重点推动项目表＞的通知》（会协[2010]52号），2010年以来，中注协会同各地注协创新探索新业务领域拓展工作途径，一批新业务拓展会计服务示范基地已陆续启动建设。为统筹做好示范基地建设各项工作，我会制定了《中国注册会计师行业会计服务示范基地建设工作方案》，现予印发。

请有关地方结合实际，积极做好相关工作，对工作中遇到的问题，请及时反馈我会。

二Ｏ一一年四月十日

中国注册会计师行业会计服务示范基地

建设工作方案

为深入贯彻全国“两会精神”和国务院办公厅转发财政部《关于加快发展我国注册会计师行业的若干意见》（国办发[2009]56号，以下简称“国办56号文件”），认真贯彻中国注册会计师协会（以下简称中注协）“五代会”确立的新业务拓展战略，推动行业发展与经济社会发展相适应，创新探索新业务领域拓展方式途径，充分发挥行业对国家发展战略布局专业服务和促进作用，中注协会同地方注协和有关部门，积极创建会计服务示范基地。为指导会计服务示范基地建设，特制定本工作方案。

**一、**创建会计服务示范基地的必要性

（一）创建会计服务示范基地，是贯彻全国“两会精神”和国办56号文件，实施新业务拓展战略的重要创新举措之一。

全国两会通过《关于国民经济和社会发展第十二个五年规划纲要》描绘了未来五年我国经济社会发展的宏伟蓝图，明确提出要大力发展会计、审计、税务、工程咨询、认证认可、信用评估、经纪代理、管理咨询、市场调查等专业服务；加快发展项目策划、并购重组、财务顾问等企业管理服务。国办56号文件指出，力争通过5年左右的时间，实现会计师事务所的规模结构优化合理、执业领域大幅度拓展、执业环境显著改善、治理机制和管理制度更加科学、注册会计师队伍职业道德水平和专业胜任能力显著提高的目标。创建会计服务示范基地，以新业务拓展为总抓手，统筹推进行业人才、技术、组织架构、网络、市场、政策配套等系列措施，实现行业新的跨越式发展目标。

（二）创建会计服务示范基地，是创新行业新业务拓展的重要载体。

通过创建会计服务示范基地，有目的、有重点地推动调整服务结构、拓展非审计业务、提高服务产品信息技术价值含量，培育一批能够提供特殊领域、高端需求、高技术含量、高附加值“一特三高”专业服务的会计师事务所群体。探索加速专业集群产业化发展和行业发展转型升级的新路径。

（三）创建会计服务示范基地，是着力优化行业区域发展布局的重要途径。

围绕国家发展战略布局、结构调整方向、区域产业协调重点，有目的、有步骤、有重点地配置行业优势资源，协调推动行业产业化发展政策的配套，着力推动新业务领域拓展开发，优化行业区域发展总体布局，满足国家重点经济区域、产业、企业不断涌现的专业服务需要。

（四）创建会计服务示范基地，是提升行业服务功能和方式的重要探索。

通过示范基地，构建中注协、地方注协与政府（部门）、行业组织、重点企业等多方合作平台，依托行业综合评价结果，推荐执业质量过硬、治理机制科学、发展势头良好的会计师事务所进入示范基地，着力解决当前业务承接过程中存在的恶性压价、不规范投标、暗箱操作等问题。

**二、**示范基地建设的指导思想和工作目标

（一）指导思想。

深入贯彻落实科学发展观，全面贯彻全国“两会精神”和国办56号文件精神，围绕服务我国经济社会改革与发展、实现“十二五”规划目标，大力实施行业新业务拓展战略，提升行业服务经济社会发展的功能与作用，有重点地布局行业资源，实现行业发展与经济社会发展的协调统一。

（二）工作目标。

围绕行业服务经济社会的总体要求，在会计师事务所原有服务格局的基础上，着力服务于国家经济结构调整方向重点，服务于国家区域协调发展和产业布局，特别是西部大开发、东北老工业基地振兴、中部崛起、东部城市群建设、战略性新兴产业带发展、边境地区“桥头堡”建设等战略重点领域。拓展企业内部控制鉴证、企业战略管理、企业社会责任鉴证、投资绩效评价、“三农”专业服务等新业务领域服务。力争未来五年内，在国家重点经济区域、重点行业、重点园区、重点企业等积极培育创建30个左右会计服务示范基地。为促进会计服务示范基地建设，可在有条件的地区先行设立试点项目。

**三、**示范基地建设的合作分工

示范基地的合作分工，由合作协议加以明确。以下合作分工安排作为协议规定的参考。

（一）中注协的主要职责。

1.研究国家经济社会发展战略，统筹考虑行业发展布局，确定示范基地发展的方向重点，制定会计服务示范基地认定标准。

2.发布重点会计服务基地名单，对示范基地建设工作给予指导。

3.协助示范基地一方地方政府（或政府部门、行业组织、重点企业）实现发展战略目标，积极配合取得国家各类发展专项配套政策。

4.支持参与示范基地的会计师事务所确立做大做强、做精做专和国际化发展目标，会同相关方动态掌握示范基地专业服务需求，指导帮助会计师事务所服务重点战略、重点产业和重点企业发展，引导事务所发展“智库”功能，发挥战略咨询、投资引导、专业支持作用，着力服务区域发展战略，促进产业转型升级，降低企业发展成本，优化发展环境。

5.制定示范基地工作考核评价办法，对示范基地新业务拓展、人才培养、技术标准、管理制度、信息化服务水平、政策配套等情况，特别是新业务拓展工作创新、非审计业务项目拓展及业务增长情况进行考核。

6.制定专项补贴和奖励办法，对新业务拓展成效显著的示范基地给予专项补助和奖励。争取纳入国家相关发展规划和支持措施。

7.提供专业发展保障，优先保障示范基地所需要的业务标准指南的制定、专业人才的培养与培训、国内外专业发展的高端交流活动。

8.建设示范基地网上服务平台，统筹各方的信息管理工作。汇集示范基地活动信息以及企业、事务所的基本情况、特色优势产品，提供各类机构的网站链接，协助供给与需求的有效联系。

9.定期组织示范基地工作交流，推广成功做法经验。

10.在国家主要媒体上加大对示范基地的宣传力度。

11.合作协议规定的其他职责。

（二）地方注协的主要职责。

1.结合示范基地发展目标，组织会计师事务所进入示范基地，做好示范基地日常服务工作。

2. 组织会计师事务所研究示范基地专业服务需求，有针对性地提供各类专业支持服务。

3. 配套建立示范基地的人才培训措施，组织会计师事务所配合示范基地建设需要，开展各类专业研讨活动。

4. 组织供需双方见面会、促进会等业务交流促进活动。

5. 维护示范基地网上服务平台相关栏目。

6.配合中注协制定专项补助和奖励办法。

7.开展对示范基地的宣传推介工作。

8. 合作协议规定的其他职责。

（三）地方政府（部门、组织等）的主要职责。

1. 组织所在区域行业企业服务需求与会计师事务所服务供给对接。积极推动会计师事务所参与特色服务政策试点。

2. 为参与示范基地的会计师事务所提供办公购（租）房、人才引进、财税支持等扶持措施。

3. 组织供需双方见面会、促进会等业务交流促进活动。

4. 组织示范基地内各类企业和研究机构，就相关领域战略与会计服务支持开展专项研究。

5. 参与维护示范基地网上服务平台相关栏目。

6. 开展对示范基地的宣传推介工作。

7. 合作协议规定的其他职责。

**四、**示范基地的管理

由负责牵头的地方注协或者地方政府（部门、组织等）组建示范基地建设领导小组，负责示范基地的管理与协调工作，负责确定工作组的职责任务、组成人员、工作目标、年度工作计划，牵头研究落实相关配套政策，负责制定示范基地建设规划，确定建设任务，组织推荐会计师事务所进入示范基地。

工作组由地方注协和地方政府（部门、组织等）相关人员组成，负责示范基地的各项具体工作。

建立联席会议制度。联席会议成员由中注协、参与组建的各地方注协、地方政府（部门、组织等）等协议各方组成。定期交流示范基地建设进展情况，协调示范基地建设中遇到的问题，商议年度工作计划安排，讨论网上信息平台建设与维护，确定联合开展研究专题等事项。

试点项目的管理，可参照以上办法加以明确。
