# 中国登山协会关于2011年中国长城徒步大会的通知

各省、自治区、直辖市登山协会、户外运动俱乐部、大专院校及相关从业机构：

由国家体育总局登山运动管理中心、山东省体育局、河北省体育局、山东莱芜县、河北张北县、河北滦平县主办，中国长城国际徒步俱乐部、相关政府体育局、旅游局、文化局、文物局等承办，北京长城环球音乐文化发展有限责任公司、北京市长跑俱乐部、长城集邮协会、中国纺织品协会户外用品分会、北京公共经济管理研究院协办的2011年中国长城徒步大会将于2011年7月2日起在山东莱芜县、河北张北县和河北滦平县举行。现将活动规程发给你们，请认真组织，作好参赛工作。

特此通知。

2011年中国长城徒步大会规程

**一、**活动宗旨

（一）推行《全民健身计划纲要》深入贯彻落实《全民健身条例》，提高国民身体素质

（二）宣传保护长城，弘扬民族精神

（三）低碳、环保、绿色、徒步健身

（四）公益全民健身事业，构建和谐社会发展

**二、**批准单位： 国家体育总局

**三、**主办单位： 国家体育总局登山运动管理中心

山东省、河北省体育局

莱芜市、张北县及滦平县人民政府

**十、**参加办法：

（一）身体健康，有长走锻炼和中长跑训练者

（二）年龄限制：

（1）5、10公里项目年龄限13岁以上（1996年12月31日以前出生）；

（1） 凡参加徒步大会者，每人必须填写报名表和个人声明；

**十一、**徒步办法

（一） 参照国家体育总局登山运动管理中心徒步规则，制定长城国际徒步大会实施细则；

（二）裁判员和工作人员由组委会选派；

（三）裁判出分站的个人和团队成绩；裁判出整个活动三站的个人和团队成绩；

（四）长城徒步大会分个人徒步王和团体徒步王；

（五）徒步者必须佩带组委会的号签参加徒步活动，徒步者在徒步时按沿途设置的路标前进；

（六）团体徒步每队至少由8名徒步者组成，组委会按照徒步者全部完成规定最长徒步距离终点的人数计算（至少8人），作为评定团队徒步王的标准；

（七）个人徒步以个人在规定的时间内到达终点为准，其中以5公里、10公里、20公里的节点标志为准，每站经裁判员确认；

中国长城徒步大会各站关门时间

|  |  |  |  |
| --- | --- | --- | --- |
| 5公里 | 10公里 | 15公里 | 20公里及以上 |
| 2小时 | 3.5小时 | 5小时 | 6.5小时 |

（八）出发顺序采用徒步前准备会随机抽签决定。抽签顺序结束编印出发顺序表，徒步者按出发顺序表进行检录；

（九）个人或团队所有徒步者通过终点线后即徒步结束，徒步者依据场地标识前进，中途退场或超过规定徒步用时个人和团队均不计入成绩；

（十）徒步项目的关门时间根据徒步线路条件和长度待定；

（十一）全民徒步健身，请勿以跑代步；

（十二）参加徒步的人员必须穿户外运动装备和运动鞋。

根据自己条件可带如下用品：

1、鞋帽：轻便登山防滑鞋、护腿、帽子。

2、服装：户外服装、防风、防雨。

3、辅助工具：登山杖、眼镜、手套、手表、指南针、应急药品。

**十二、**奖励机制：

（一）个人奖项及奖励

1.个人参加任意一站，在规定的关门时间内到达最后终点，为分站“长城徒步王”；个人参加三站徒步活动并均在三站规定的关门时间内到达最后终点，为“2011中国长城（个人）徒步王”，将获得奖品和证书。

2、分站徒步王获得者，将自动成为中国长城国际徒步俱乐部普通会员，并免收一年会费；2011中国徒步王获得者，将自动成为中国长城国际徒步俱乐部VIP会员，并免收一年会费。

（二）团队奖项及奖励

1.团队参加任意一站，在规定的关门时间内全部队员到达最后终点，为分站的“长城徒步王”；团队参加三站徒步活动并均在三站规定的关门时间内全部队员到达最后终点，为“2011中国长城（团队）徒步王”，将获得奖品和证书。

2、分站长城徒步王，若具有专业户外资质的俱乐部或机构，将自动成为中国长城国际徒步俱乐部普通会员单位，并免收一年会费；2011中国长城徒步王，若具有专业户外资质的俱乐部或机构，将自动成为中国长城国际徒步俱乐部VIP会员单位，并免收一年会费。

（五）大礼包明细：

1.凡参加第一站活动人员，可获赠两夜免费帐篷宿营；

2.反光啪啪圈、活动背签、“中国长城徒步大会” 纪念文化衫一件、徒步手册及徒步地图；

3.长城景区门票；（雪野吕祖泉景区门票38元；金山岭景区门票50元；张北野狐岭军事要塞门票50元；）

4.可免费参加当晚的Hiking Life Music音乐专场派对活动；

5.组委特定制的专项户外保险，“中国长城徒步大会专项保险” ；

6.报名费的10%捐给地方长城保护机构用于长城的抢险加固。

**十三、**食宿安排：

本次大会按国际惯例，徒步人员食宿费用自理，活动组委会为徒步者只提供政策支持，酒店餐厅按当地政府协议价对参会人员开放，活动区域内提供帐篷宿营区和帐篷租赁服务。

在大会住宿区，大会将提供方便食品摊。

活动时间总长度为9个小时，所以饮食自带。

在活动服务区及关门点，大会提供饮水。
