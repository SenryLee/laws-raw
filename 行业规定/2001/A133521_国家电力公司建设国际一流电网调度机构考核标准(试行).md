# 国家电力公司建设国际一流电网调度机构考核标准(试行)

## 国家电力公司建设国际一流电网调度机构考核标准(试行)（2001年10月24日）

在电网调度机构中开展安全文明生产达标和创一流工作，是被实践所证明的、科学有效的企业管理活动。通过近年来坚持不懈的创一流工作，电网调度机构的管理水平、两个文明建设等各方面都发生了巨大变化，取得了显著成绩。当今世界，社会进步和科技发展日新月异，经济发展和竞争的全球不断加快，电力企业的改革与发展也必然面临新的挑战。国家电力公司面向新世纪，确立了建设“控股型、经营型、现代化、集团化管理的国际一流企业”的战略目标，着力于提高国家电力公司发展的整体素质，因此，建设国际一流的电网调度机构就成为实践这一战略的重要组成部分。与世界先进电网调度机构相比，我们还存在管理粗、用人多、技术装备水平不高等差距，这就需要电网调度机构瞄准世界先进水平，实施赶超战略，全面提高调度机构整体素质，努力建设国际一流电网调度机构。

国际一流电网调度机构应体现在以下几个方面：一流的管理：突出管理理念和思路的创新，积极引入国际先进标准，采用现代化管理方法，实现企业管理的规范化、制度化、标准化、科学化。一流的技术：达到世界先进电力调度技术水平，突出技术创新，积极采用新技术，如电网分析与控制技术、电力市场运营技术、调度自动化技术、现代通信技术、快速保护技术等。一流的服务：确保电网安全稳定运行，确保对用户的连续、可靠供电，为用户提供具有合格频率和电压的优质电能。坚持“三公”(公平、公正、公开)调度，为发电企业提供公平竞争环境、为用户提供优质服务。一流的装备：具有功能先进的现代化设备，主要包括继电保护及电网安全稳定控制系统、调度自动化系统、通信系统、电力市场技术支持系统、调度生产管理信息系统等一流的人才：具有一支整体素质高、结构合理的职工队伍，具有富于创新精神的、掌握高新技术和现代化管理方法的、具备国际技术交流

能力的复合型人才，能适应电力技术不断发展和市场竞争日益激烈的需要。

为指导建设国际一流电网调度机构的工作，加快建设国际一流电网调度机构的步伐，特制定本标准。

本标准适用于省级及以上电网调度机构。

1.必备条件

**1.1**领导班子坚持党的基本路线，坚持民主集中制原则，改革开拓、团结进取，廉洁勤政，连续3年无违法违纪事件发生。

坚持两个文明一起抓，两手都要硬，建成电力公司的文明窗口；坚持开展思想政治工作，全面提高职工队伍整体素质；大力开展企业文化建设，树立良好社会形象，连续3年未发生造成重大社会影响的恶性事件；获得并连续2年保持中国一流电网调度机构称号。

**1.2**考核年度和申报期内不发生主网稳定破坏、大面积停电事故；重要保电期间不发生220千伏及以上枢纽变电站全站停电事故；不发生本单位调度责任事故和生产责任事故；杜绝因继电保护计算整定错误和方式安排不当造成电网事故；无生产重伤及以上人身伤亡事故；不发生本单位所属生产场所的火灾事故。

**1.3**保证电网电能质量合格。运用自动发电控制(AGC)等项技术，具有区域控制误差(ACE)、电网频率、联络线功率的综合协调控制能力，责任频率合格率(按50±0.2HZ)连续2年(含考核年度)达到99.99％及以上或ACE符合有关规定；加强无功和电压的优化管理，电压合格率连续2年(合考核年度)达到99％及以上。

**1.4**建立起完善的技术标准、管理标准和工作标准体系，并能够在工作中严格执行；积极采用现代化管理方法对主要工作流程进行控制和执行。

**1.5**具有完善的调度生产管理信息系统。实现信息共享，实现专业管理现代化，实现办公自动化。

**1.6**220千伏及以上电网继电保护正确动作率≥98.5％。

**1.7**电网调度自动化系统(SCADA／AGC)达到实用化高档指标要求，负荷预测、状态估计、调度员潮流、在线安全分析、DTS达到实用；所辖下一级调度自动化系统100％通过实用化验收并定期通过了复查。

**1.8**光纤或数字微波通信电路覆盖率达100％；通信站100％达到标准通信站。

**1.9**建成覆盖主要调度对象的电力数据网络。

**1.10**根据“网厂分开，竞价上网”电力市场改革的要求建成技术支持系统，实现电力市场运营。开展“三公”调度，建立了调度信息公开网页。

**1.11**全面实现《全国电网调度系统“十五”发展计划纲要》中提出的“五化”要求。即主干通道光纤化，信息传输网络化，调度决策智能化，运行指标国际化和专业管理现代化。

2.考核指标(指标体系

)

**2.1**安全生产指标

2.1.1　连续实现10个安全生产100天周期。

2.1.2　两措(安措、反措)计划完成率100%。

2.1.3　两票(操作票、检修票)合格率100%。

2.1.4　220千伏及以上电网继电保护正确动作率≥99％。

2.1.5　电网安全自动装置正确动作率≥98%。

2.1.6　故障录波完好率≥98％。

2.1.7　故障信息远传完好率≥98％。

2.1.8　220千伏及以上电网线路主保护微机化率100％。

2.1.9　调度员潮流和在线安全分析应用率≥95％。

**2.2**电能质量标准

2.2.1　责任频率(按50±0.2HZ)合格率100％；

责任频率(按50±0.2HZ)合格率≥98％。

2.2.2　考核点电压合格率≥99.5%(考核点电压在允许偏差范围内每日偏差幅度不大于额定电压的5％)。

2.3　生产技术指标

**2.3.1**AGC机组可调容量占统调装机容量的比例≥20％；

2.3.2　AGC功能年投运率≥90%；

2.3.3　AGC控制年合格率≥99％。

**2.4**网损率≤2.5%或网损降低系统≥0.008。

2.3.5　连续3年平均水能利用提高率≥3％。

2.3.6　调度端通信运行率：

●微波≥99.99％；

●载波≥99.98％；

●光纤≥99.99％；

●交换设备≥99.99％；

2.3.7　所辖主通信电路运行率：

●微波≥99.99％；

●载波≥99.90％；

2.3.8　主干通信电路光纤覆盖率≥90%。

2.3.9　通信监控系统运行率≥99％。

2.3.10　所辖下一级调度自动化系统应用软件基本功能通过实用要求验收的比例≥70％。

2.3.11　状态估计：

●状态估计覆盖率100％；

●状态估计月可用率≥95％；

●遥测估计合格率≥95％；

单次状态估计计算时间≤10s。

2.3.12　调度员潮流：

●调度员潮流月合格率≥95％；

●调度员潮流计算结果误差≤2.5%；

●单次潮流计算时间≤10s。

2.3.13　负荷预测：

●超短期负荷预测准确率≥99％；

●日负荷预测准确率(按月统计)：

对用电负荷高于10000Mw的电网≥98%；

对用电负荷高于500OMw的电网≥96%；

对用电负荷低于5000MW的电网≥95％；

●日最高、最低负荷预测准确率：

对用电负荷高于10000MW的电网≥98％；

对用电负荷高于5000MW的电网≥96％；

对用电负荷低于5000MW的电网≥95%阮；

日最高、最低负荷预测月合格率≥90％。

2.3.14　报价处理系统年可用率≥99.75%。

2.3.15　交易管理系统年可用率≥99.95%。

2.3.16　即时信息系统年可用率≥99.75％。

2.3.17　电能量考核与结算系统年可用率≥99.75％。

2.3.18　电能量自动计量系统年可用率≥99.99%；

●关口计费计量点覆盖率100％；

●所辖电网内计量点投运率100%；

●计量点准确性认证(测试)合格率100％。

2.3.19　专业和管理人员计算机应用率100％。

2.3.20　仪表校验合格率100％。

2.3.21　科技计划完成率≥90％。

2.3.22　科技项目应用率≥90%。

2.3.23　年度国家级或行业级学术会议(或杂志)上发表论文篇数≥6。

2.3.24　运行设备消缺完成率100％。

2.3.25　重点技措完成率100％；

2.3.26　一般技措完成率≥80％。

2.3.27　职工培训率≥90％。

2.3.28值班人员持证上岗率100％。

3.评价内容

**3.1**一流的管理

3.1.1　推行了现代化管理，更新了管理观和思路，实现了管理创新；

3.1.2　重视发展战略研究，制定了本单位发展战略规划和近期实施计划；

3.1.3　采用先进的管理理念，实现了整体管理素质的全面提升；

3.1.4　建立了调度生产管理信息系统，实现了信息共享，实现了专业管理的现代化，实现了办公自动化；

3.1.5　实施了技术标准、管理标准、工作标准三大标准体系，具有严密的安全、培训、设备和标准化管理的内部管理网络，具有切实可行的内部管理制度，并取得了明显效果；

3.1.6　建立了完善的调度系统专业管理体系；

3.1.7　不断改善调度机构的工作环境和工作条件，做到场地净化，环境美化；实施定置管理，实现文明生产、文明办公；

3.1.8　重视企业文化建设，确立了企业精神、企业理念、企业道德，建立了企业文化体系，

增强了企业凝聚力；

3.1.9　塑造了良好的企业形象，企业在系统内外有着广泛的美誉度和信誉度，建成为电力公司的文明窗口，连续3年满足电力公司文明单位条件。

**3.2**一流的技术

3.2.1　建立了有效的科技进步机制，在科技创新方面有实绩，有成果、有效益；

3.2.2　调度中心总体技术装备水平达到国际先进水平；软件应用水平与国际先进调度机构保持同步；

3.2.3　充分利用EMS应用软件网络分析功能，使调度运行工作由经验型上升到分析型(智能型)；

3.2.4　电网安全稳定运行处于较高水平，特别是在事政预警、安全稳定控制和事故分析方面处于国际先进水平；

3.2.5　电网AGC和AVC功能得以成功应用，其控制水平、控制质量以及控制效果不断提高；

3.2.6　电力市场技术支持系统能适应电力市场交易的需要；

3.2.7　对电力数据网络安全、可靠，并在电力生产中得以广泛运用；

3.2.8　根据电网发展的客观要求，开展大电网互联和联络线控制技术研究以适应西电东送、南北互补和全国联网的需要。

**3.3**一流的服务

3.3.1　电网保持长周期的安全稳定运行；

3.3.2　精心安排运行方式，保证可靠供电，避免无计划的拉闸限电；

3.3.3　制定了保证电网频率和电压质量合格的具体办法并有效实施；

3.3.4　制定了“三公”调度实施办法和信息披露制度并严格执行。

**3.4**一流的装备

3.4.1　采取有效手段提高设备运行的可靠性；

3.4.2　继电保护及安全自动装置微机化率、主干通信电路光纤化率等指标不断提高；

3.4.3　在保证硬件设备先进的同时，着重挖掘软件设备的潜能，不断开发应用功能，充分提高设备利用率；

3.4.4　具有完善的设备管理制度，做好设备运行维护，提高了设备的生命周期；设备台帐、运行记录、消缺记录等资料、档案保存完整。

**3.5**一流的人才

3.5.1　制定了人才规划，可满足电力调度不断发展的需要；

3.5.2　实现了人员的优化配置，人员总量符合定编要求，人员结构(年龄结构、学历结构、

职称结构、专业结构)合理；

3.5.3　培养了一批具有创新精神的、掌握高新技术和现代化管理方法的、具有国际技术交流能力的复合型人才；

3.5.4　领导班子具有较强的组织能力和决策能力，在工作中有明显业绩；职工队伍具有奉献精神，能出色完成富有挑战性的工作任务。

4.考评标准

**4.1**评价标准

4.1.1　国际一流电网调度机构标准由必备条件、考核指标和评价内客三部分组成，对任一项必备条件不满足者实行评价否决；考核指标与评价内容进行评分，总分为1000分，其中考核指标700分，评价内容300分。

4.1.2　考核指标包括：

安全生产指标　300

电能质量指标　100

生产技术指标　300

4.1.3　评价内容包括一流的管理、一流的技术、一流的服务、一流的设备、一流的人才五

项，每项60分。

**4.2**评分办法

4.2.1　考核指标按考核标准具体评分(各项指标的考核评分标准另行制定)。

4.2.2　评价内容按优秀、良好、一般进行综合评价，优秀55～60分，良好48～54分，一

般36～47分。

4.2.3　考核指标总得分率均达到90％及以上、各项评价内容达到良好及以上为合格。

5.考评程序

**5.1**本单位自查

坚持高标准、严要求，对照标准，认真自查，全面达到本标准后，向主管电力公司提出申请。

**5.2**考核和申报

主管电力公司审核通过后报上一级(集团)公司或国电公司分公司，上一级公司会同其主管公司对申报单位进行考核，确认达到国电公司建设国际一流电网调度机构标准后，向国家电力公司提出申报。

**5.3**国电公司组织考核

国家电力公司组织和邀请国内(外)同行专家进行考核评价，并作出评审结论。

**5.4**国电公司命名

由国家电力公司正式命名。
