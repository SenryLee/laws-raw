# 上海证券交易所关于印发《关于按值配售新股业务的工作指引》的通知

*注：本篇法规已被：上海证券交易所关于废止部分业务规则的公告(第四批)（发布日期：2010年11月8日，实施日期：2010年11月8日）废止

## 上海证券交易所关于印发《关于按值配售新股业务的工作指引》的通知（上证交字［2000］8号　2000年2月25日）

各会员单位：

根据中国证监会《关于向二级市场投资者配售新股有关问题通知》（证监发行字［2000］5号），为确保按值配售新股办法的顺利实施，本所于2月14日至20日先后向各会员单位发送了《关于实施向二级市场投资者配售新股有关事项的通知》、《关于按值配售新股有关作程序及说明》、《关于为按值配售新股提供模拟申购环境的通知》、《关于必须参加按值配售模拟申购的通知》、《关于按值配售新股模拟申购有关业务要求的补充说明》、《关于按值配售新股T＋3缴款日上传放弃认购数据的技术操作说明》等文件（可在单向卫星上查收，文件名为PS000221. TXT）。

中国证监会于2月23日发布的关于向二级市场投资者配售新股事宜的《解惑答疑》，进一步明确了按值配售新股办法的有关业务操作要求。为便于会员单位进一步落实按值配售新股的准备工作，本所将上述六个文件的有关事项及证监会进一步明确的业务要求归并，整理成《关于按值配售新股业务的工作指引》（详见附件）印发给你们，请据此妥善落实有关技术准备和业务工作。

附件

关于按值配售新股业务的工作指引

**一、**T－2日

发行公司在指定报刊刊登《招股说明书》。各会员单位应认真研究发行公司的《招股说明书》，并向投资者做好咨询服务工作。本所根据前一个交易日的收盘价统计各投资者持有本所上市流通证券的市值，计算出各投资者可申购新股的数量，通过ZQY?????. DBF（肛码为737XXX）数据文件传送至各会员单位；如果每一股票帐户计算出可申购新股的数量大于规定的申购上限，可申购新股的数量则按规定的申购上限表示。

**二、**T－1日

发行公司在指定报刊刊登《发行公告》。各会员单位应认真研究发行公司的《发行公告》，并继续向投资者做好咨询工作；同时，向投资者提供可申购新股数量的查询服务。

**三、**T＋0日

投资者按照其可申购新股的数量（不大于规定的申购上限），或直接按照规定的申购上限自主委托申购新股。按值配售新股的申购代码为737XXX，申购方法同上网定价发行，但按规定投资者申购该部分新股时，不对其进行扣款和冻结资金。

当日闭市后，本所按规定确认有效申购，剔除无效申购，对每一股票帐户的有效申购进行连续配号，配号代码为747XXX，并将配号结果通过GH?????. DBF数据文件传送至各会员单位，方法同上网定价发行。

**四、**T＋1日

各会员单位须在交易场所的显著位置或采取其他有效方式向投资者公布配号结果。主承销商在指定报刊上公布中签率，并按规定组织摇号抽签。

当日闭市后，本所根据按值配售新股摇号抽签结果确认中签投资者，并将中签投资者的数据通过GH?????. DBF数据文件传送至各会员单位（代码为737XXX），各会员单位据此按规定收缴股款。

**五、**T＋2日

主承销商在指定报刊上公布抽签结果。各会员单位须在交易营业部的显著位置或采取其他有效方式向投资者公布中签结果；同时通知中签投资者应在其资金帐户中留有足额新股认购款项。中签的投资者无需到营业部再次填报任何指令，但其必须于当日准备好认购资金。

**六、**T＋3日

各会员单位应在正式开市前从中签投资者资金帐户中扣缴新股认购款。如有中签投资者认购资金不足，各会员单位将只对其资金能够认购的部分进行配售，余者视同放弃认购。向资金不足的投资者配售的新股，可以含有零股。各会员单位须将放弃认购的相关数据于当日14时前按规定的数据格式，通过参与人远程操作平台（PROP）报送登记公司。

具体要求如下：

1. 规定的数据格式：

| 5 | FQSL | Numeric | 12 | 放弃认购数量 |
| 6 | SGRQ | Character | 8 | 申购日期 |

G7文件数据结构：

|  |  |  |  |  |

2. 各营业部将中签投资者放弃认购处理的详细数据报送会员单位总部。报送方式和数据格式自定。

3. 会员单位总部在收到下属营业部报送的放弃认购详细数据后，登记公司法人结算的要求，汇总填报“放弃认购按值配售中签新股明细数据上报库”（以下简称G8数据文件）。并通过PROP平台，于T＋3日下午14∶00前上传登记公司。

4. 各会员单位上传给登记公司的G8数据文件全名应为：G8XXXXX. MDD。其中：××××X为各会员单位在登记公司的结算代码。MDD表示G8数据文件上传的日期，指T＋3日，其中M表示月份：M＝1，2，3，4，5，6，7，8，9，A，B，C（A＝10，B＝11，C＝12），DD表示日期。G8数据文件的模版已经放入各会员的PROP信箱中，文件名为G8. DBF.

5. 各会员单位在上传G8数据文件时，应使用安全版，也可使用简易版，但必须使用各自的PROP用户进行登录。

6. 登记公司在T＋3日下午14∶00后统一接收各会员单位上传的G8数据文件。每天只进行一次接收处理。若G8数据文件格式有误，则以G8XXXX. err为文件名返回。若G8数据文件格式正确，则以G8XXXXX. Ok为文件名返回。请注意，这两个数据文件名仅用以表述会员单位上传的G8数据文件格式是否正确，对G8数据文件的处理结果会在稍后发送的G7数据文件中表述。

7. 登记公司在接收G8数据文件后，即由系统自动进行处理，并将处理结果返回各会员单位的PROP信箱内。处理结果返回文件名为G7。G7数据文件的模版已经放入各会员的PROP信箱中，文件名为G7. DBF。各会员单位可用PROP中的文件传输功能下载G7数据文件，通过G7数据文件中的CLJG（处理说明）字段，了解登记公司对G8数据文件中每条记录的处理结果。在G7数据文件的CLJG字段中，对G8数据文件的主要处理说明如下：

（1）处理成功

（2）非法股东帐号

（3）会员代码错　指证券帐户所办理指定交易的席位不隶属于QSBH字段所表述的会员。

（4）申购日期错

（5）数量不足　指FQSL字段所表述的放弃认购数量大于实际中签数量。

（6）数量非法　指FQSL字段所表述的放弃认购数量不为正数或大于999999999。

（7）无此中签记录

（8）信箱会员代码不一致　指会员未使用自己的PROP用户登录，进行发送G8数据文件操作。

（9）营业部代码错　指证券帐户所办理指定交易的席位不隶属于在YYBDM字段所表述的证券营业部。

（10）帐号未指定　指证券帐户未在YYBDM字段所表述的证券营业部办理指定交易。

（11）QSBH与文件名不符　指QSBH中所填写的会员代码与G8数据文件中的会员代码不一致。

8. 各会员在填写G8数据文件时需注意：

（1）QSBH（会员代码）即指会员在登记公司的结算代码（或称清算编号），该字段中填写的会员代码必须与G8数据文件名中的结算会员代码一致。各会员可通过登记公司每天发送的F3资金清算文件中的QSBH（清算编号）字段获取。

（2）YYBDM（营业部代码）即指各证券营业部在登记公司的营业部代码（或称券商代码）。目前各营业部的代码长度为5位，在填写该字段时请左对齐。各会员可通过所属营业部接收的F2资金清算文件中的QSDM（券商代码）字段获取。YYBDM字段中填写的营业部代码必须隶属于QSBH字段所表述的会员。

（3）GDZH（股东帐号）必须真实有效，必须是在YYBDM字段所表述的营业部所属席位办理过指定交易手续。

（4）ZQDM（证券代码）即指按值配售新股的申购代码。以上交所2月19日的测试为例，证券代码为737888。

（5）FQSL（放弃认购数量）即指投资者放弃认购的实际数量，可以为零股，但必须为正数，也不能大于实际中签数量。举例：某投资人在新股按值配售中，中签5000股，但因资金等问题，放弃认购123股，在FQSL字段中应填写123。

（6）SGRQ（申购日期）即指新股按值配售的申购日期。其表述方式为YYYYMMDD。以上交所2月19日的测试为例，申购日期为20000219。

当日闭市后，登记公司对采用不同发行方式的同一新股的认购统一进行清算。

**七、**T＋4日

登记公司进行清算交割和股东登记，并将募集资金划入主承销商指定的帐户。主承销商包销投资者放弃认购的部分。

**八、**T＋5日

主承销商将募集资金划入发行公司指定帐户。

**九、**其他有关注意事项：

1. 当投资者申购沪、深两市的新股都已中签，但其认购资金不足时，证券营业部应按照时间优先的原则处理，即先将投资者的资金用于认购报单在先的新股，再用于认购报单在后的新股。

2. 根据本所《全面指定交易制度试行办法》的规定，投资者未履行交易交收责任，不得撤销指定交易。因此，对按值配售新股而言，只有在确认投资者已履行认购新股交易交收责任的情况下，才能为其办理撤销指定交易的手续。

3. T＋0日，对即时办理指定交易的投资者，在无法确认其可申购新股数量的情况下，可直接按照规定的申购上限申购新股。
