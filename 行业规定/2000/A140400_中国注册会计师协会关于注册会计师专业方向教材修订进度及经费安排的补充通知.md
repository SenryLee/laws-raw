# 中国注册会计师协会关于注册会计师专业方向教材修订进度及经费安排的补充通知

## 中国注册会计师协会关于注册会计师专业方向教材修订进度及经费安排的补充通知（会协字[2000]第80号　2000年5月14日）

各位主编、主审和编委会委员：

根据《注册会计师专业教育教材编审委员会会议纪要》(会协字[1999]250号)精神和《关于注册会计师专业方向教材修订进度及经费安排的通知》(会协字[2000]6号)要求，现将《计算机会计与审计》教材修订的有关事宜补充通知如下：

**一、** 关于《计算机会计与审计》教材的主编、主审人员

《计算机会计与审计》一书主编人员，采取招投标方式确定。共有四所院校(人民大学、中山大学、中南财经大学、西南财经大学)对该教材进行了投标。根据编委会的审核推荐意见，经研究确定，《计算机会计与审计》教材主编为王景新教授、副主编为张瑞君副教授，主审人员为财政部科研所杨周南教授、中山大学管理学院陈婉玲教授。

**二、** 关于《计算机会计与审计》教材进度安排

```
1．提交大纲　2000年5月

2．讨论大纲　2000年5月

3．主审审大纲2000年5月

4．提交初稿　2001年3月

5．讨论初稿　2001年3月

6．主审审初稿2001年4月

7．师资培训　2001年5月

8．提交第二稿2001年7月

9．总篡　　　2001年8月

10．定稿　　　　　2001年12月

11．出版　　　　　2002年2月
```

教材修订的同时，需同时提供学习指导书和教师用书。

**三、**关于教材资助经费和出版社

该教材资助经费和出版社，按《关于注册会计师专业方向教材修订进度及经费安排的通知》([2000]6号)执行。
