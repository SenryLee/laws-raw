# 中国进出口银行2014年第十期、第十一期、第十二期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年2月28日经过承销团竞标，发行了2014年第十期至第十二期金融债券。第十期至第十二期分别为3年期、2年期和5年期固定利率债券，票面利率分别为4.93%、4.8352%和5.1%，发行总额分别为60亿元、60亿元和70亿元，缴款日分别为2014年3月3日、3月4日和3月5日。欢迎境内商业银行、保险公司、农村信用合作联社和其他银行间债券市场成员积极参与债券分销。以上3期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通。
