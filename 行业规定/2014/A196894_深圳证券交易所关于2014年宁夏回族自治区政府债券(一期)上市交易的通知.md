# 深圳证券交易所关于2014年宁夏回族自治区政府债券(一期)上市交易的通知

## 深圳证券交易所关于2014年宁夏回族自治区政府债券（一期）上市交易的通知

各会员单位：

2014年宁夏回族自治区政府债券（一期）已发行结束，根据财政部通知，本期债券于2014年8月18日起在本所上市交易。

本期债券为5年期固定利率附息式国债（地方政府债），证券编码“109139”，证券简称“宁夏1401”，票面利率3.98%，标准交易单位“10张”，2019年8月12日到期还本并支付最后一期利息。
