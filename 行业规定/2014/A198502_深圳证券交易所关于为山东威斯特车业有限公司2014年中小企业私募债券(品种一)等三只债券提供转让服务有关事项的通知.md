# 深圳证券交易所关于为山东威斯特车业有限公司2014年中小企业私募债券(品种一)等三只债券提供转让服务有关事项的通知

## 深圳证券交易所关于为山东威斯特车业有限公司2014年中小企业私募债券（品种一）等三只债券提供转让服务有关事项的通知

各会员单位：

山东威斯特车业有限公司2014年中小企业私募债券（品种一）、山东威斯特车业有限公司2014年中小企业私募债券（品种二）、 山东威斯特车业有限公司2014年中小企业私募债券（品种三）定于2014年9月24日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、山东威斯特车业有限公司2014年中小企业私募债券（品种一）证券代码“118234”，证券简称“14舜意01”，发行总额9，000万元，票面利率8.2%，债券期限3年。

2、山东威斯特车业有限公司2014年中小企业私募债券（品种二）证券代码“118235”，证券简称“14舜意02”，发行总额9，000万元，票面利率8.2%，债券期限3年。

3、山东威斯特车业有限公司2014年中小企业私募债券（品种三）证券代码“118236”，证券简称“14舜意03”，发行总额12，000万元，票面利率8.2%，债券期限3年。

深圳证券交易所

二○一四年九月二十二日
