# 中国进出口银行2014年第三十七期和第三十八期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年6月16日经过承销团竞标，发行了2014年第三十七期和第三十八期金融债券。第三十七期债券为2年期固定利率金融债券，首场发行金额为60亿元，票面利率为4.45%。第三十八期债券为1年期贴现金融债券，首场发行金额为60亿元，中标价格为96.03元，参考收益率为4.1341%。

首场招标结束后，我行按照首场中标利率和价格向工商银行追加发行各15亿元当期债券，由工商银行在柜台债券市场向个人和非金融机构投资者进行分销。2014年6月16日至23日为银行间债券市场分销期，2014年6月17日至20日为商业银行柜台债券市场分销期，债券缴款日均为2014年6月23日。以上2期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通，柜台债持有人在债券上市后可通过工商银行柜台进行交易。
