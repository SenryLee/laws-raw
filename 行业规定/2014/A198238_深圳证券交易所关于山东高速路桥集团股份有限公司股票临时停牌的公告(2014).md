# 深圳证券交易所关于山东高速路桥集团股份有限公司股票临时停牌的公告(2014)

## 深圳证券交易所关于山东高速路桥集团股份有限公司股票临时停牌的公告

因山东高速路桥集团股份有限公司预计有重大事项发生，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：山东路桥，证券代码：000498）自2014年10月8日开市起停牌，待公司刊登相关公告后复牌。

深圳证券交易所

2014年10月8日
