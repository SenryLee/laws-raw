# 上海证券交易所关于2014年地方政府债券(十三期)上市交易的通知

## 上海证券交易所关于2014年地方政府债券（十三期）上市交易的通知

各市场参与人：

根据财政部《关于代理发行2014年地方政府债券（十三期）有关事宜的通知》（财库〔2014〕118号）和上海证券交易所（以下简称“本所”）有关规定，2014年地方政府债券（十三期）（以下简称本期债券）将于2014年9月30日在本所竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期债券为固定利率债券，期限为7年，票面利率为4.12%，利息每年支付一次；本期债券起息日为2014年9月25日，每年9月25日支付利息（逢节假日顺延，下同），2021年9月25日偿还本金并支付最后一次利息。

**二、**本期债券于2014年9月30日起在本所竞价系统和固定收益证券综合电子平台上市，交易方式为现券和质押式回购。

**三、**本期债券上市交易的现券证券名称为“14地债13”，证券代码为“130157”，质押券申报和转回代码为“106157”。

上海证券交易所

二〇一四年九月二十四日
