# 深圳证券交易所关于2014年记账式附息(十二期)国债上市交易的通知

## 深圳证券交易所关于2014年记账式附息（十二期）国债上市交易的通知

各会员单位：

2014年记账式附息（十二期）国债已发行结束，根据财政部通知，本期债券于2014年6月25日起在本所上市交易。

本期债券为10年期固定利率附息式国债，证券编码“101412”，证券简称“国债1412”，票面利率4％，标准交易单位“10张”，2024年6月19日到期还本并支付最后一期利息。

特此通知

深圳证券交易所
