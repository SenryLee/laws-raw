# 中国建筑业协会关于公布2014年中国建设工程鲁班奖（境外工程）入选工程名单的通知

各省、自治区、直辖市建筑业协会（联合会，施工行业协会）,有关行业建设协会，解放军工程建设协会，国资委管理的有关建筑业企业，有关单位：

根据《关于开展2014年中国建设工程鲁班奖（境外工程）评选活动的通知》（建协〔2014〕20号），并参照《中国建设工程鲁班奖（国家优质工程）评选办法》（建协〔2013〕24号）,经评审，赞比亚卢萨卡体育场、伊拉克艾哈代布油田地面建设EPCC项目等17项工程入选2014年中国建设工程鲁班奖（境外工程），现予以公布。

附件：2014年中国建设工程鲁班奖（境外工程）入选工程名单

中国建筑业协会

2014年12月30日
