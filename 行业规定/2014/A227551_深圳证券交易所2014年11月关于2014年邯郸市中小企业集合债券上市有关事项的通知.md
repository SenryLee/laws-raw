# 深圳证券交易所2014年11月关于2014年邯郸市中小企业集合债券上市有关事项的通知

各会员单位：

2014年邯郸市中小企业集合债券定于2014年11月25日起在本所综合协议交易平台挂牌交易，现将有关事项通知如下：

2014年邯郸市中小企业集合债券证券代码“111067”，证券简称“14邯中小”，发行总额2.58亿元，票面利率9.50%，债券期限6年，第3年末附发行人全额赎回权。

特此通知

深圳证券交易所

二○一四年十一月二十一日
