# 中国进出口银行资金营运部2014年第六期、第七期金融债券发行公告

2014年度中国进出口银行金融债券承销团成员：

根据《中国人民银行关于中国进出口银行2014年金融债券临时发行计划的批复》（银函〔2013〕407号），我行定于2014年2月13日14：00-15：00通过中国人民银行债券发行系统，招标发行2014年第六期、第七期金融债券。

**一、**第六期金融债券

第六期债券为我行2014年第二期3年期固定利率金融债的增发债券，票面利率为5.44%，发行金额不超过60亿元，发行价格通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。

**二、**第七期金融债券

第七期债券为我行2014年第三期5年期固定利率金融债的增发债券，票面利率为5.48%，发行金额不超过60亿元，发行价格通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。

发行办法详见中国债券信息网http：//www.chinabond.com.cn或中国货币网http：//www.chinamoney.com.cn。
