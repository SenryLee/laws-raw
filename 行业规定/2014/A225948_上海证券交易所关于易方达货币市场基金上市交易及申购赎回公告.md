# 上海证券交易所关于易方达货币市场基金上市交易及申购赎回公告

上证公告（基金）（2014）035号

易方达基金管理有限公司管理的3203434.00份易方达货币市场基金（代码：511800，证券简称：易货币）将于2014年12月8日起在本所市场上市交易，12月8日该基金正常放开申购、赎回。
