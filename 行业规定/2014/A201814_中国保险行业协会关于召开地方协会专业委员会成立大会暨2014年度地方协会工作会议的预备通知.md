# 中国保险行业协会关于召开地方协会专业委员会成立大会暨2014年度地方协会工作会议的预备通知

## 中国保险行业协会关于召开地方协会专业委员会成立大会暨2014年度地方协会工作会议的预备通知（中保协发〔2014〕247号）

各省级协会：

为探索新形势下行业自律的有效途径，促进保险行业协会职能作用发挥，加强中保协与地方协会的沟通联动，实现协会系统的工作交流、经验分享、共谋发展，现拟于2014年7月中旬召开地方协会专业委员会成立大会暨2014年度地方协会工作会议。现将有关事项通知如下：

**一、**会议时间

2014年7月中旬（会期一天）

**二、**会议地点

北京郊区

**三、**参会人员

（一）中保协领导；

（二）各省级协会专职会长/秘书长（可带一名助理）；

（三）中保协中层干部。

**四、**会议内容

（一）地方协会专业委员会成立大会；

（二）2014年度地方协会工作会议；

（三）经验交流会。

**五、**相关事项

（一）请各参会人员于2014年6月20日之前填写《参会回执》（附件1），以邮件形式发送至中保协联系人，并电话确认；

（二）请有意向在会上进行经验分享的省级协会于2014年6月20日前就其特色和亮点工作提交分享题目及情况摘要（300-500字），报送至中保协联系人；

（三）请各省级协会认真总结2014年上半年工作并形成书面材料，于2014年7月1日前以邮件形式发送至中保协联系人；

（四）本通知为预备通知，会议的具体时间和地点将在确定后另行通知。
