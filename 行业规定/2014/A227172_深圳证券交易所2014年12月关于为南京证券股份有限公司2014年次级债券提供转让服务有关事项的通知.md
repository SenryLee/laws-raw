# 深圳证券交易所2014年12月关于为南京证券股份有限公司2014年次级债券提供转让服务有关事项的通知

各会员单位：

南京证券股份有限公司2014年次级债券定于2014年12月30日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

南京证券股份有限公司2014年次级债券证券代码“118908”，证券简称“14南京债”，发行总额70,000万元，票面利率5.8%，债券期限4年，附第2年末发行人上调票面利率选择权及投资者回售选择权。

深圳证券交易所

二○一四年十二月二十六日
