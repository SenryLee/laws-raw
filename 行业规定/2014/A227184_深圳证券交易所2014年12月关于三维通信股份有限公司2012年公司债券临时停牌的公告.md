# 深圳证券交易所2014年12月关于三维通信股份有限公司2012年公司债券临时停牌的公告

三维通信股份有限公司2012年公司债券（证券代码：112168）因披露不定期跟踪评级信息实行风险警示的程序尚未办理完毕，经公司申请，本所将于2014年12月24日开市起对该公司债券停牌一天，12月25日复牌后实行风险警示。

深圳证券交易所

2014年12月24日
