# 深圳证券交易所、深圳证券信息有限公司关于调整部分指数发布方式和简称的公告

为进一步优化指数发布方式，深圳证券交易所和深圳证券信息有限公司决定于2014年1月2日对部分指数的发布方式和简称命名进行调整。

**一、**对于深证红利、深证治理等在深交所行情系统中同时发布价格指数和收益指数的16条指数，参照国际惯例，将其收益指数转移至巨潮指数网发布每日收盘行情，并提供历史数据下载；其价格指数继续通过深交所行情系统发布实时行情，指数代码和指数名称均保持不变。
