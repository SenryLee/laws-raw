# 深圳证券交易所关于2014年浙江省政府债券(二期)上市交易的通知

## 深圳证券交易所关于2014年浙江省政府债券（二期）上市交易的通知

各会员单位：

2014年浙江省政府债券（二期）已发行结束，根据财政部通知，本期债券于2014年8月26日起在本所上市交易。

本期债券为7年期固定利率附息式国债（地方政府债），证券编码“109148”，证券简称“浙江1402”，票面利率4.17％，标准交易单位“10张”，2021年8月20日到期还本并支付最后一期利息。

特此通知

深圳证券交易所
