# 深圳证券交易所、中国证券登记结算有限责任公司关于2014年11月1日开展交易报盘方式进行“中国结算网络服务”投资者网络服务身份认证业务全网测试的通知

各会员及相关单位：

为做好深圳市场交易报盘方式进行“中国结算网络服务”投资者网络服务身份认证业务相关技术准备工作，深圳证券交易所（简称“深交所”）和中国证券登记结算有限责任公司（简称“中国结算”）定于2014年11月1日组织全网测试，验证市场参与各方技术系统和业务功能的正确性。

现将相关测试事项通知如下：

**一、**本次测试的内容包括：

（一）网上用户注册及激活

1、个人投资者登录中国结算网站首页“登录|注册”-“投资者”栏目进行注册，并通过交易报盘方式进行激活；

2、机构投资者登录中国结算网站（地址同上）进行注册，并通过交易报盘方式进行激活；

（二）通过交易报盘方式进行投资者网上用户服务密码重置

**二、**测试时间为2014年11月1日8：30至14：00，测试期间将模拟1个完整交易日的交易。

**三、**请各参测单位认真组织测试，按照《2014年11月1日深圳市场交易报盘方式进行“中国结算网络服务”投资者网络服务身份认证业务全网测试方案》（可在深交所网站www.szse.cn“技术专栏”页面或中国结算网站www.chinaclear.cn“通知公告”页面查阅）等相关技术文档做好准备，落实专人负责本次测试工作。

**四、**各参测单位测试前务必做好系统环境和数据的备份工作。测试完成后，做好系统和数据的恢复工作，确保下一交易日（11月3日）的交易正常安全进行。

**五、**测试工作完成后，各会员单位应在2014年11月2日12：00之前登录深交所“会员网上业务专区”首页“快速导航―在线调查表”栏目填写并提交测试反馈表（测试反馈表参见测试方案之附件一）；非会员用户请将填报好的反馈表发送至sseyxb@szse.cn。

登录深交所“会员网上业务专区”需使用专用电子认证证书（Ekey），具体方法可询问各自单位负责每月技术月报的填报人员或负责会籍席位业务的人员。

**六、**测试当日的所有数据仅为技术测试使用，不能作为任何交易、非交易及开户等业务的依据。请会员及相关单位做好向投资者的宣传提示工作。

**七、**测试当日，D-COM生产系统不提供实时开户服务。

**八、**“中国结算网络服务”投资者网络服务身份认证相关技术系统及业务上线日期将另行通知。

附件二：

投资者通过交易报盘方式办理身份认证的主要流程

深交所为中国结算在交易系统中新增一个证券代码（369991，简称“中登认证”），专门用于投资者办理中国结算网络服务身份认证业务。主要流程说明如下：

（一）投资者登录中国结算网站，进入用户注册网页，填写姓名/名称、身份证明文件号码、证券账户号码、手机号码等信息，并自行设置网络服务密码。注册成功后，网站系统将通过短信向投资者填注的上述手机号发送一个8位数字校验号码。该校验号码与投资者证券账户号码、网络服务密码具有一一对应关系。

（二）交易时间内，投资者使用上述证券账户通过证券公司自助交易平台（如交易软件、电话委托交易系统等）以买入指令的方式，在证券代码、购买价格、委托数量等项下输入369991、1.000元（或2.000元）、校验号码等内容后，将买入指令提交至证券公司，详见下表：

|  |  |  |
| --- | --- | --- |
| 输入参数 | 密码激活指令 | 密码重置指令 |
| 证券代码 | 369991 | |
| 证券账户 | 投资者的深市证券账户代号 | |
| 业务类别 | 普通买入或新股申购（证券营业部不冻结投资者资金） | |
| 委托价格 | 1．000元 | 2．000元 |
| 委托数量 | 中国结算技术系统分配的8位数字校验号码 | |

（三）证券公司将投资者上述买入指令信息转发至深交所交易系统，再由深交所转发至中国结算进行处理。

（四）中国结算对接收到的投资者买入指令信息与投资者在中国结算网站注册的上述信息、网站系统以短信方式发送的校验号码等内容进行比对处理，比对无误的，当日激活投资者在中国结算网站设置的上述证券账户号码、校验号码所对应的网络服务密码。

（五）投资者可使用证券账户号码、网络服务密码登录中国结算网站办理证券持有查询、质押回购查询、投票等网络服务业务。

网络服务密码因遗忘等原因需进行重置的，其重置流程类似于上述做法。
