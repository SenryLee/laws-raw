# 深圳证券交易所2014年12月关于为北京讯鸟软件有限公司2014年中小企业私募债券提供转让服务有关事项的通知

各会员单位：

北京讯鸟软件有限公司2014年中小企业私募债券定于2014年12月4日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

北京讯鸟软件有限公司2014年中小企业私募债券证券代码“118262”，证券简称“14讯鸟债”，发行总额1,800万元，票面利率8.5%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权，附部分提前偿还条款，第一年末付息日偿还本金300万，第二年末付息日偿还债券本金500万元，最后一年利息随剩余本金的兑付一起支付。

深圳证券交易所

二○一四年十二月二日
