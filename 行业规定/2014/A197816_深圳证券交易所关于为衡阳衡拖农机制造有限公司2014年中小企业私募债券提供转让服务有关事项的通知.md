# 深圳证券交易所关于为衡阳衡拖农机制造有限公司2014年中小企业私募债券提供转让服务有关事项的通知

各会员单位：

衡阳衡拖农机制造有限公司2014年中小企业私募债券定于2014年10月22日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

衡阳衡拖农机制造有限公司2014年中小企业私募债券证券代码“118261”，证券简称“14衡拖债”，发行总额30，000万元，票面利率9.8%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所
