# 深圳证券交易所关于思美传媒股份有限公司股票上市交易的公告

思美传媒股份有限公司人民币普通股股票将于2014年1月23日在本所上市。证券简称为“思美传媒”，证券代码为“002712”。公司人民币普通股股份总数为85，319，509股，其中首次公开发行的21，329，878股股票自上市之日起开始上市交易。
