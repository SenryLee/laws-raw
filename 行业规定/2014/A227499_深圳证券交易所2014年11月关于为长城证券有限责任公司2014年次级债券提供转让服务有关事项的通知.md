# 深圳证券交易所2014年11月关于为长城证券有限责任公司2014年次级债券提供转让服务有关事项的通知

各会员单位：

长城证券有限责任公司2014年次级债券定于2014年11月28日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

长城证券有限责任公司2014年次级债券证券代码“118907”，证券简称“14长城债”，发行总额10亿元，票面利率6.4%，债券期限5年，附第3年末发行人赎回选择权。

深圳证券交易所

二○一四年十一月二十六日
