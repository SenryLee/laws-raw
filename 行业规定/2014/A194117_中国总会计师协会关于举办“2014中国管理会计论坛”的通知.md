# 中国总会计师协会关于举办“2014中国管理会计论坛”的通知

## 中国总会计师协会关于举办“2014中国管理会计论坛”的通知（中总协〔2014〕30号）

各地方总会计师协会、各分会，各会员单位及会员：

中国的经济发展在最近几年正面临着越来越多的挑战。随着资源衰减、环境恶化、外贸市场下滑和科技及竞争环境的急速变化，我国企业的生存和发展必须通过精细挖潜和以创新突破传统束缚的方式来实现。现代管理会计为中国企业迎接挑战提供了强有力的工具和方法。将管理会计从理论探讨和学术研究引入到企业实践是我们的使命和责任。为此，中国总会计师协会和中欧国际工商学院将共同举办“2014中国管理会计论坛”。论坛将聚集中外管理会计的专家学者和优秀从业人员共同为管理会计在中国企业的拓展出谋划策，在理论和实务间架起桥梁。

管理会计工作是财政部会计工作的重中之重。在协会第五次全国会员代表大会上楼继伟部长对管理会计工作提出了重要指示，要求加快培育我国管理会计人才，力争通过5-10年的努力，使我国管理会计跻身于世界先进水平行列。楼部长在为“中国总会计师协会中国管理会计系列讲座”的开篇讲座中，把加快发展中国特色管理会计上升到“促进我国经济转型升级、建立现代财政制度、推进国家治理体系和治理能力现代化”的高度来认识。举办好这次论坛是贯彻财政部党组工作要求和落实《财政部关于全面推进管理会计体系建设的指导意见》的重要体现。现将有关问题通知如下：

3、论坛举办的时间、地点、住宿安排
