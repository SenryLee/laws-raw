# 上海证券交易所关于2014年衢州市国有资产经营有限公司公司债券上市交易的公告

## 上海证券交易所关于2014年衢州市国有资产经营有限公司公司债券上市交易的公告（上证公告（债券）〔2014〕387号）

衢州市国有资产经营有限公司发行的2014年衢州市国有资产经营有限公司公司债券，将于2014年8月6日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“14衢国资”，证券代码为“124676”。债券上市后可进行质押式回购，质押券申报和转回代码为“103676”。

上海证券交易所

二〇一四年八月五日
