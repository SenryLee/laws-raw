# 上海证券交易所关于N晶方(603005)盘中临时停牌的公告

## 上海证券交易所关于N晶方（603005）盘中临时停牌的公告（上证公告（监察）〔2014〕013号）

N晶方（603005）今日上午交易出现异常波动。根据《上海证券交易所交易规则》和《关于进一步加强新股上市初期交易监管的通知》的有关规定，本所决定，自2014年02月10日09时30分开始暂停N晶方（603005）交易，自2014年02月10日14时55分起恢复交易。

本所提醒投资者注意交易风险，理性投资。

特此公告。

上海证券交易所

2014年2月10日
