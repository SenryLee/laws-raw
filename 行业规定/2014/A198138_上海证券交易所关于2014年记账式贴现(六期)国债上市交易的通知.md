# 上海证券交易所关于2014年记账式贴现(六期)国债上市交易的通知

## 上海证券交易所关于2014年记账式贴现（六期）国债上市交易的通知

各市场参与人：

根据《财政部关于2014年记账式贴现（六期）国债发行工作有关事宜的通知》（财库[2014]124号）和上海证券交易所（以下简称“本所”）有关规定，2014年记账式贴现（六期）国债（以下简称“本期国债”）将于2014年10月16日在本所竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期国债期限为91天，发行价格为99.116元 ；本期国债起息日为2014年10月13日， 2015年1月10日（节假日顺延）按面值偿还。

**二、**本期国债于2014年10月16日起在本所集中竞价系统和固定收益证券综合电子平台上市，交易方式为现券和质押式回购。

**三、**本期国债上市交易的现券证券名称为“14贴债06”，证券代码为“020072”，质押券申报和转回代码为“107072”。

上海证券交易所

二〇一四年十月十日
