# 中国农业银行关于调整个人网银“投资理财”菜单的公告

尊敬的客户：

您好！为向您提供高效、便捷的个人网上银行服务，我们结合业务分类和使用频率统计情况，将于4月24日对个人网银“投资理财”菜单进行如下调整：

调整前：

![](\upload\bff6475e-3a24-4eb3-925e-cd25b53576f6.bmp)

调整后：

![](\upload\9f6f0bdb-9fff-4505-a472-82e46f4c6ae0.bmp)

调整说明：

（1）按照功能属性相近原则，把“定活通”、“通知存款”和“双利丰”三个菜单整合为“储蓄业务”菜单，作为投资理财业务的第一个二级菜单。

（2）使用频率较高的“理财产品”和“基金”作为第二和第三个二级菜单。

（3）“记账式债券”和“储蓄国债”同属债券类业务，将其整合为“债券”，作为第四个二级菜单。同时，“记账式债券”名称改为“网上债券”。

（4）撤销“贵金属”一级菜单，其下的二级菜单“金交所代理”和“账户贵金属”同步移至“投资理财”菜单。

再次感谢您对我行个人网银一直以来的大力支持，我们也将继续关注您的感受，为使您获得更舒适的体验而不断努力。

中国农业银行

二〇一四年四月二十一日
