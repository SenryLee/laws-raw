# 中国农业银行关于“安心快线”开放式人民币理财产品调整预期收益率的公告

尊敬的投资者：

因市场情况发生变化，我行于2014年4月9日调整“金钥匙 安心快线”开放式人民币理财产品的预期收益率，具体调整方案见下表：

|  |  |  |
| --- | --- | --- |
| 产品名称 | 调整前收益率 | 调整后收益率 |
| “金钥匙·安心快线”天天利滚利第2期人民币理财产品 | 3.9% | 2.45% |
| “金钥匙·安心快线”天天利滚利第3期人民币理财产品 | 3.9% | 2.45% |
| “金钥匙·安心快线”私人银行天天利第2期开放式人民币理财产品 | [100，500）万元：4.10%  [500，5000）万元：4.20%  [5000，5000000]万元：4.30% | [100，500）万元：2.80%  [500，5000）万元：3.30%  [5000，5000000]万元：4.00% |

特此公告。

中国农业银行

二〇一四年四月三日
