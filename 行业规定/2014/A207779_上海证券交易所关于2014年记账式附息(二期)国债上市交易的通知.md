# 上海证券交易所关于2014年记账式附息(二期)国债上市交易的通知

## 上海证券交易所关于2014年记账式附息（二期）国债上市交易的通知

各市场参与人：

根据《财政部关于2014年记账式附息（二期）国债发行工作有关事宜的通知》（财库[2013]227号）和上海证券交易所（以下简称“本所”）有关规定，2014年记账式附息（二期）国债（以下简称“本期国债”）将于2014年1月15日在本所集中竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期国债为固定利率附息债，期限为1年，票面利率为4.04%，利息到期一次支付；本期国债起息日为2014年1月9日，2015年1月9日（节假日顺延）偿还本金并支付利息。

**二、**本期国债于2014年1月15日起在本所集中竞价系统和固定收益证券综合电子平台上市，交易方式为现券和质押式回购。

**三、**本期国债上市交易的现券证券名称为“14国债02”，证券代码为“019402”，质押券申报和转回代码为“091073”。

上海证券交易所

二〇一四年一月八日
