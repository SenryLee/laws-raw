# 深圳证券交易所关于浙江华策影视股份有限公司股票临时停牌的公告(2014)

## 深圳证券交易所关于浙江华策影视股份有限公司股票临时停牌的公告

因浙江华策影视股份有限公司未能按预定日期披露2013年年度报告，根据本所《创业板股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：华策影视，证券代码：300133）自2014年4月22日开市起停牌，待公司通过指定媒体披露相关公告后复牌，敬请投资者密切关注。

深圳证券交易所

2014年4月22日
