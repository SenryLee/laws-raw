# 上海证券交易所期权工作小组关于期权全真模拟交易环境临时调入标的证券的通知

期权全真模拟交易参与人：

为检验交易参与人在除权除息场景下的各项准备工作，根据《关于在期权全真模拟交易环境演练标的证券除权除息场景的通知》，在期权全真模拟交易环境临时新增哈高科（600095）作为演练标的并进行除权除息演练，哈高科分配方案及实施日以上市公司公告为准，测试结束后对该标的进行调出。

|  |  |  |  |
| --- | --- | --- | --- |
| 标的证券代码 | 标的名称 | 合约单位 | 首次挂牌日期 |
| 600095 | 哈高科 | 10000 | 2014年5月5日 |

注：5月5日新挂标的证券600095的到期月份为5月、6月、9月、12月的合约，所有新挂合约最后交易日、行权日、到期日调整为5月28日，行权交割日调整为5月29日。
