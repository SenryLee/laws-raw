# 中国金融期货交易所关于修订《中国金融期货交易所结算细则》和《中国金融期货交易所风险控制管理办法》的通知(2014)

## 中国金融期货交易所关于修订《中国金融期货交易所结算细则》和《中国金融期货交易所风险控制管理办法》的通知

为配合交易所保证金制度创新，本所修订了《中国金融期货交易所结算细则》和《中国金融期货交易所风险控制管理办法》。上述规则修订已经本所董事会执行委员会审议通过并报告中国证监会，现予以发布，并自2014年10月27日15：15起实施。
