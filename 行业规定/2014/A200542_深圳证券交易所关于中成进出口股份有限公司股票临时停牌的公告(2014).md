# 深圳证券交易所关于中成进出口股份有限公司股票临时停牌的公告(2014)

## 深圳证券交易所关于中成进出口股份有限公司股票临时停牌的公告

中成进出口股份有限公司实际控制人国家开发投资公司存在拟披露的重大事项，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：中成股份，证券代码：000151）自2014年7月14日开市起停牌，待公司刊登相关公告后复牌。
