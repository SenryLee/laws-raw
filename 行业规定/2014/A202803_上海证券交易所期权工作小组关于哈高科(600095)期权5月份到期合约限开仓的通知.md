# 上海证券交易所期权工作小组关于哈高科(600095)期权5月份到期合约限开仓的通知

## 上海证券交易所期权工作小组关于哈高科（600095）期权5月份到期合约限开仓的通知

因以下标的证券的到期月份的认购类型的未平仓合约（含备兑开仓）所对应的合约标的总数达到了限开仓要求，2014年05月23日，拟对以下标的、到期月份的认购期权合约限制开仓（包括卖出开仓与买入开仓，但不限制备兑开仓）。请投资者注意投资风险。

具体合约对应的标的证券与到期月份信息如下：

限开仓日期：2014年05月23日

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 标的股票代码 | 标的股票简称 | 到期月份 | 合约类型 | 限开仓原因（＞＝30%或限开仓未解除） |
| 600095 | 哈高科 | 2014年5月 | 认购 | ＞30% |

注：限开仓原因为”＞＝30%”表示未平仓合约（含备兑开仓）所对应的合约标的总数达到了流通股数的30%以上。

限开仓原因为“限开仓未解除”表示前一交易日该标的该月份合约为限开仓状态，当日该月标的未平仓合约（含备兑开仓）所对应的合约标的总数占流通股数的28%-30%之间，未达到解除限开仓条件。
