# 深圳证券交易所2014年12月关于为2014年东北证券股份有限公司次级债券提供转让服务有关事项的通知

各会员单位：

2014年东北证券股份有限公司次级债券定于2014年12月25日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

2014年东北证券股份有限公司次级债券证券代码“118910”，证券简称“14东北债”，发行总额20亿元，票面利率5.74%，债券期限5年，附第3年末发行人赎回选择权、发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一四年十二月二十三日
