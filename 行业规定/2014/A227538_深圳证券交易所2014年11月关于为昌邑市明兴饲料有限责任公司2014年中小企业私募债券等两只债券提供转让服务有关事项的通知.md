# 深圳证券交易所2014年11月关于为昌邑市明兴饲料有限责任公司2014年中小企业私募债券等两只债券提供转让服务有关事项的通知

各会员单位：

昌邑市明兴饲料有限责任公司2014年中小企业私募债券、北京天路通科技有限责任公司2014年中小企业私募债券定于2014年11月26日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、昌邑市明兴饲料有限责任公司2014年中小企业私募债券证券代码“118267”，证券简称“14明兴债”，发行总额6,000万元，票面利率9.35%，债券期限3年。

2、北京天路通科技有限责任公司2014年中小企业私募债券证券代码“118279”，证券简称“14天路通”，发行总额3,000万元，票面利率8.5%，债券期限3年，第二年末付息日支付债券本金1,000万元，最后一年利息随剩余本金一起支付。

深圳证券交易所

二○一四年十一月二十四日
