# 中国农业银行关于开放式人民币理财产品2014年端午假期开放日及清算日的公告

尊敬的投资者：

根据国务院办公厅假日安排，2014年5月31日（星期六）至6月2日（星期一）为端午节法定节假日。相应的，我行对开放式人民币理财产品的开放日及清算日调整如下：

2014年5月31日至6月2日暂停申购和赎回，从6月3日起恢复正常。

特此公告。

中国农业银行

二〇一四年五月二十九日
