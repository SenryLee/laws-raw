# 深圳证券交易所关于上海嘉麟杰纺织品股份有限公司2014年公司债券等两只债券上市以及北京三聚环保新材料股份有限公司2014年非公开发行公司债券进行转让有关事项的通知

各会员单位：

上海嘉麟杰纺织品股份有限公司2014年公司债券，深圳欧菲光科技股份有限公司2014年公司债券定于2014年4月21日起在本所集中竞价系统和综合协议交易平台同时挂牌交易，北京三聚环保新材料股份有限公司2014年非公开发行公司债券定于2014年4月21日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、上海嘉麟杰纺织品股份有限公司2014年公司债券证券代码“112202”，证券简称“14嘉杰债”，发行总额3亿元，票面利率7.5%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

2、深圳欧菲光科技股份有限公司2014年公司债券证券代码“112198”，证券简称“14欧菲债”，发行总额9亿元，票面利率7.9%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

3、北京三聚环保新材料股份有限公司2014年非公开发行公司债券证券代码“112200”，证券简称“14三聚债”，发行总额5亿元，票面利率8.5%，债券期限5年，附第3年末发行人赎回选择权和投资者回售选择权。

特此通知

深圳证券交易所

二○一四年四月十七日
