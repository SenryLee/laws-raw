# 深圳证券交易所关于中山公用事业集团股份有限公司2014年公司债券等三只债券上市有关事项的通知

各会员单位：

中山公用事业集团股份有限公司2014年公司债券，东江环保股份有限公司2014年公司债券（第一期）定于2014年9月10日起在本所集中竞价系统和综合协议交易平台同时挂牌交易，雏鹰农牧集团股份有限公司2014年公司债券定于2014年9月10日起在本所综合协议交易平台进行交易，现将有关事项通知如下：

1、中山公用事业集团股份有限公司2014年公司债券证券代码“112212”，证券简称“14中山债”，发行总额80000万元，票面利率5.75%，债券期限3年。

2、东江环保股份有限公司2014年公司债券（第一期）证券代码“112217”，证券简称“14东江01”，发行总额35000万元，票面利率6.50%，债券期限5年，附第3年末发行人上调票面利率选择权及投资者回售选择权。

3、雏鹰农牧集团股份有限公司2014年公司债券证券代码“112209”，证券简称“14雏鹰债”，发行总额80000万元，扣除上市前投资者回售的221.30万元后为79，778.70万元，票面利率8.80%，债券期限5年，附第3年末发行人上调票面利率选择权及投资者回售选择权。

特此通知

深圳证券交易所

二○一四年九月五日
