# 中国工商银行股份有限公司关于暂停受理部分网上支付跨行清算业务、跨行小额支付业务、全国支票影像交换业务和电子商业汇票业务的通告

尊敬的客户：

根据中国人民银行通知，2014年3月21日16：00至3月23日16：00，中国人民银行兰州城市处理中心将停止运行小额支付系统、网上支付跨行清算系统、全国支票影像交换系统；2014年3月21日20：00至3月23日20：00，兰州城市处理中心将停止运行电子商业汇票系统。届时，我行将暂停受理接收行为兰州银行的网上支付跨行清算业务；暂停受理接收行为甘肃省辖区内各银行业金融机构的跨行小额支付业务、全国支票影像交换业务和电子商业汇票业务；我行甘肃分行将暂停受理跨行小额支付业务、全国支票影像交换业务。

2014年3月21日15：30至3月22日8：00，中国人民银行将安排江苏银行等11家机构切换至第二代支付系统。届时，我行将暂停受理接收行为江苏银行、江苏省农村信用社联合社、南京银行、太仓农村商业银行、吴江农村商业银行、江阴农村商业银行、张家港农村商业银行、广州银行、广东南粤银行、宁波银行、湖州银行的跨行小额支付业务。

系统暂停运行给您带来不便，敬请谅解，建议您提前做好相关安排。如有任何疑问，请致电或发送短信至95588咨询。

特此通告。

中国工商银行股份有限公司

2014年3月20日
