# 对外承包工程商会关于2014年度对外承包工程企业与对外劳务合作企业信用等级评价结果公布

根据商务部、国资委联合发布的《商会协会行业信用建设工作指导意见》的要求，结合承包商会关于推进行业信用体系建设的工作部署，承包商会于2014年7月启动2014年度对外承包工程企业与对外劳务合作企业信用等级评价工作，经对外承包工程企业与对外劳务合作企业信用等级评审委员会第十次工作会议审议，2014年度信用等级初评、复审结果已经产生，并于2014年11月6日起至11月15日进行公示。

公示结束后，个别企业提出对信用等级公示结果进行复核的要求，经信用评估机构复核和评审评委员会审定，2014年企业信用等级评价结果公布如下：

附件：

1、2014年度对外承包工程初评企业信用等级评价结果.

2、2014年度对外承包工程复审企业信用等级评价结果.

3、2014年度对外劳务合作初评企业信用等级评价结果.

4、2014年度对外劳务合作复审企业信用等级评价结果.

对外承包工程商会

2014年12月5日
