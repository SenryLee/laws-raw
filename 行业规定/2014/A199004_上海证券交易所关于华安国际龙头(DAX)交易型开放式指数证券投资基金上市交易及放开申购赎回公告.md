# 上海证券交易所关于华安国际龙头(DAX)交易型开放式指数证券投资基金上市交易及放开申购赎回公告

## 上海证券交易所关于华安国际龙头（DAX）交易型开放式指数证券投资基金上市交易及放开申购赎回公告（上证公告（基金）[2014]028号）

华安基金管理有限公司管理的337，779，000.00份华安国际龙头（DAX）交易型开放式指数证券投资基金将于2014年9月5日起在本所市场上市交易及申购、赎回。

2014年9月5日
