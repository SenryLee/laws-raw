# 中国工商业联合会、中国互联网新闻中心关于召开中国互联网金融大会的通知

中商联零供委〔2014〕5号

各有关单位，会员单位：

互联网，正在全球范围掀起一场较有影响力的深刻变革。金融业也受到互联网的冲击和影响，竟而产生了一种全新的金融业态——“互联网金融”。互联网金融是指以依托于支付、云计算、社交网络以及搜索引擎等互联网工具，实现资金融通、支付和信息中介等业务的一种新兴金融。

李克强总理在2014年的政府工作报告中首次将互联网金融列入其中，要求促进互联网金融的发展；2014年7月5日，国务院发布了《关于金融支持经济结构调整和转型升级的指导意见》。面对互联网金融的快速发展，以余额宝、第三方支付等为代表的互联网金融在去年大幅增长，它的迅速崛起日趋影响着整个金融业。

2013年，全球众筹平台的筹资总额达到60亿美元，去年10月，世界银行《报告》预测：未来10年全球众筹市场规模将达到3000亿美元，中国市场将占到500亿美元；2014年上半年，国内众筹一共完成1423起项目，募集资金的额度将近2个亿。

互联网金融正以其新技术带来的新模式，新模式带来的显著客户价值和产业趋势，改变着金融业。金融业需要一个交流平台，形成共识，把握机遇，共同迎接和面对挑战。

为此，中国商业联合会、中国互联网新闻中心决定于2015年7月18日在北京联合主办“中国互联网金融大会”，并定期开展互联网金融的相关活动（方案详见附件1）。
