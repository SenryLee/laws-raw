# 中国期货业协会关于期货公司风险管理服务子公司业务试点备案结果的公告(2014)

## 中国期货业协会关于期货公司风险管理服务子公司业务试点备案结果的公告

根据《期货公司设立子公司开展以风险管理服务为主的业务试点工作指引（修订）》等相关规则规定，经审查，五矿期货有限公司、五矿产业金融服务（深圳）有限公司以及上海东证期货有限公司、东证润和资本管理有限公司提交的备案材料齐全，符合规定，现予以备案。具体内容如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 备案期货公司 | 备案事项 | 备案风险管理公司 | 备案事项 |
| 五矿期货有限公司 | 期货公司设立风险管理公司 | 五矿产业金融服务（深圳）有限公司 | 1.风险管理公司设立 |
| 2.试点业务：仓单服务、合作套保、基差交易、定价服务 |
| 上海东证期货有限公司 | 期货公司设立风险管理公司 | 东证润和资本管理有限公司 | 风险管理公司设立 |

中国期货业协会

二〇一四年十月二十九日
