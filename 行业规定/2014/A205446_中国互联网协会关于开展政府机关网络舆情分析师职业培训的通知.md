# 中国互联网协会关于开展政府机关网络舆情分析师职业培训的通知

各有关单位：

网络舆情的兴起和发展为民主政治的发展提供了新的平台，成为影响政府决策的新方式，成为政府与公众沟通的新渠道。同时，网络舆情的迅速发展也关系到地区的政治稳定，经济发展和文化繁荣。网络舆情应对能力正在成为党政机关执政能力的集中体现，不断提高应对网络舆情的能力和技巧，已成为各级党政机关施政过程中不可回避的重要课题。然而近年来因应对失当而导致舆情事件扩大化、复杂化的案例层见叠出、源源不断，充分反映出舆情应对工作已经向专业化方向发展，需要有针对性知识技能、丰富实践经验的专业人才加以应对。

有鉴于此，为更好地树立政府机关威信力和公信力，提高网络舆情管控人员舆情监测、分析、研判、疏引能力，提升网络舆情危机应对能力，掌握网络舆论主动权，推动网络舆情监控工作规范化、制度化、科学化发展，中国互联网协会与国家人力资源和社会保障部中国国家人事人才培训网在全国范围开展网络舆情分析师的培训、教学和考试工作。

现将有关培训事项通知如下：

**一、**课程目标

更新理念、开拓视野，完善知识结构，增强舆情管控人员舆情监测、分析、研判、疏引、危机应对实践经验。

认识转变：“谈舆色变”→“闻舆起舞”

方法转变：“遮遮掩掩”→“公开疏引”

效果转变：“扑火救急”→“整改提升”

**二、**组织实施

主管单位：人力资源和社会保障部中国高级公务员培训中心

施教单位：中国互联网协会

人力资源和社会保障部中国国家人事人才培训网

北京国工信部信息技术中心

**三、**培训对象

各级党政机构、行政事业单位部门的负责人；对外宣传、网络管理和舆情监测的有关部门负责人。

**四、**培训课程及授课模式

培训课程：7门课程＋考试　共计32学时（4天）

（一）政府机关网络问政、微博问政实践分析；

（二）新媒介素养；

（三）网络舆情理论分析和研判方法；

（四）网络舆情危机应对和管控；

（五）网络舆情引导案例分析及实务操作；

（六）建立健全新闻发言人制度与危机预警系统；

（七）专题研讨。

授课专家单位：

中宣部舆情信息局外交部新闻司

人民网舆情监测室新华网舆情监测分析中心

中国人民大学　　中国传媒大学

新浪政务微博　　上海交大危机管理研究中心

授课模式：

为了能够更全面的学习网络舆情知识，掌握相关技能，在学习方面，贯彻“理论学习＋实践练习”的模式，除了讲解理论知识外，还采用“在线模拟演练平台”，为学员提供仿真的舆论引导实操演练平台，让学员能够在短时间内学以致用，稳固学习效果。

（注）：学员培训时须自带笔记本电脑。
