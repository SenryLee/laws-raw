# 中国证券登记结算有限责任公司关于2014年春节休市期间证券资金清算交收安排的通知

各结算参与单位：

根据《关于2014年部分节假日休市期间证券资金清算交收安排的通知》，现将2014年春节休市期间资金清算交收安排通知如下：

**一、**2014年1月30日发生的证券交易（B股除外）和当日到期的债券回购，资金清算日为2014年1月30日，资金交收日为2014年2月7日。

**二、**2014年2月7日发生的证券交易（B股除外）和2014年1月31日-2月7日到期的债券回购，资金清算日为2014年2月7日，资金交收日为2014年2月10日。

**三、**2014年1月28日、29日、30日发生的B股交易，资金交收日依次为2014年2月7日、10日、11日。

请各结算单位据此安排好有关工作。

中国证券登记结算有限责任公司

二O一四年一月二十二日
