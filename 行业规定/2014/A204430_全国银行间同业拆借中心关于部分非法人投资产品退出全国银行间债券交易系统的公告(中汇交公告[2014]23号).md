# 全国银行间同业拆借中心关于部分非法人投资产品退出全国银行间债券交易系统的公告(中汇交公告[2014]23号)

## 全国银行间同业拆借中心关于部分非法人投资产品退出全国银行间债券交易系统的公告（中汇交公告〔2014〕23号）

根据中国人民银行有关规定及相关投资管理人的申请，2014年3月我中心共完成2只非法人投资产品的退市工作，上述投资产品为：

1.云南国际信托天富宝结构化集合资金信托

2.上海国际信托上海银行债券投资单一资金信托

特此公告。

全国银行间同业拆借中心
