# 上海证券交易所关于2014年常德市经济建设投资集团有限公司公司债券上市交易的公告

## 上海证券交易所关于2014年常德市经济建设投资集团有限公司公司债券上市交易的公告（上证公告（债券）〔2014〕148号）

常德市经济建设投资集团有限公司发行的2014年常德市经济建设投资集团有限公司公司债券，将于2014年4月18日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“14常德投”，证券代码为“124609”。债券上市后可进行质押式回购，质押券申报和转回代码为“103609”。

上海证券交易所

二〇一四年四月十七日
