# 2014年第四十七期和第四十八期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年8月1日经过承销团竞标，发行了2014年第四十七期和第四十八期金融债券。第四十七期债券为3年期固定利率金融债券，发行金额为60亿元，票面利率为4.6914%，债券缴款日为2014年8月5日。第四十八期债券为我行2014年第三十期金融债的增发债券，发行金额60亿元，期限7年，中标价格99.8725元，参考收益率为5.0678%，债券缴款日为2014年8月5日。欢迎境内商业银行、保险公司、农村信用合作联社和其他银行间债券市场成员积极参与债券分销。以上2期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通。
