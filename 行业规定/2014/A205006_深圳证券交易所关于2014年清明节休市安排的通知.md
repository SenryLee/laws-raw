# 深圳证券交易所关于2014年清明节休市安排的通知

各会员单位：

根据《关于2014年节假日休市安排的通知》（深证会〔2013〕157号），现将2014年清明节休市有关安排通知如下：

**一、**休市安排：4月5日（星期六）至4月7日（星期一）为节假日休市，4月8日（星期二）起照常开市。

**二、**节假日期间清算交收事宜按照中国证券登记结算有限责任公司的安排进行。

请各会员单位据此安排好有关工作。

深圳证券交易所

二○一四年三月二十八日
