# 深圳证券交易所关于支付2012年记账式附息(十七期)国债利息有关事项的通知(2014)

## 深圳证券交易所关于支付2012年记账式附息（十七期）国债利息有关事项的通知

各会员单位：

2012年记账式附息（十七期）国债将于2014年9月15日支付利息。为做好本期债券的利息支付工作，现将有关事项通知如下：

**一、**本期债券证券代码为“101217”，证券简称为“国债1217”，是2012年9月13日发行的3年期债券，票面利率为3.1％，每年支付1次利息，每百元面值债券本次可获利息3.1元。

**二、**本所从2014年9月4日至2014年9月12日停办本期债券的转托管及调帐业务。

**三、**本期债券付息债权登记日为2014年9月12日，凡于当日收市后持有本期债券的投资者，享有获得本次利息款项的权利，2014年9月15日除息交易。

**四、**中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的本期债券利息款项后，将其划入各证券商的清算备付金账户，并由证券商将付息资金及时划入各投资者的资金账户。

深圳证券交易所

二○一四年八月二十九日
