# 2014年第四十五期和第四十六期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年7月25日经过承销团竞标，发行了2014年第四十五期和第四十六期金融债券。第四十五期为6个月期贴现债券，发行金额60亿元，发行价格为97.93元，参考收益率为4.1930%，债券缴款日为2014年8月1日。第四十六期为我行2014年第四十四期金融债的增发债券，发行金额50亿元，期限5年，中标价格100.2507元，参考收益率为4.8907%，债券缴款日为2014年8月1日。欢迎境内商业银行、保险公司、农村信用合作联社和其他银行间债券市场成员积极参与债券分销。以上2期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通。
