# 深圳证券交易所2014年11月关于天弘丰利债券型证券投资基金（LOF）上市交易有关事项的通知

各会员单位：

天弘丰利债券型证券投资基金（LOF）（证券简称：天弘丰利，证券代码：164208）2014年12月3日开始在我所上市交易。上市首日以上市首日前一交易日的基金份额净值作为开盘参考价，并以此为基准设置涨跌幅限制。自上市首日起，每日涨跌幅限制为10%。
