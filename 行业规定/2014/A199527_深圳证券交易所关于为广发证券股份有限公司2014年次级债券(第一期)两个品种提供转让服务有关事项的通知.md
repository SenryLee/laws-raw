# 深圳证券交易所关于为广发证券股份有限公司2014年次级债券(第一期)两个品种提供转让服务有关事项的通知

## 深圳证券交易所关于为广发证券股份有限公司2014年次级债券（第一期）两个品种提供转让服务有关事项的通知

各会员单位：

广发证券股份有限公司2014年次级债券（第一期）两个品种定于2014年8月22日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、广发证券股份有限公司2014年次级债券（第一期）（品种一）证券代码“118904”，证券简称“14广发01”，发行总额300，000万元，票面利率5.7%，债券期限4年，附第2年末发行人赎回选择权。

2、广发证券股份有限公司2014次级债券（第一期）（品种二）证券代码“118905”，证券简称“14广发02”，发行总额300，000万元，票面利率5.9%，债券期限5年，附第3年末发行人赎回选择权。

深圳证券交易所

二○一四年八月二十日
