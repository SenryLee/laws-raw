# 中国农业发展银行2014年第二十二、三十、三十三期金融债券增发公告

根据《中国人民银行关于下达2014年中国农业发展银行人民币贷款计划及金融债券发行计划的通知》（银发〔2014〕49号）精神，农发行定于2014年5月19日下午，利用中国人民银行债券发行系统第三次增发2014年第二十二期、第三次增发2014年第三十期、增发2014年第三十三期固定利率（附息）金融债券分别不超过50亿元、50亿元、50亿元，总量不超过150亿元。本次增发的2014年第二十二期、第三十期和第三十三期债券为5年期、1年期、3年期固定利率（附息）债券，票面利率分别为5.25%、4.75%、4.83%。发行人对上述债券保留增发权利。农发行在发行后第二个工作日前发布发行情况公告。本次增发的2014年第二十二期债券缴款日为2014年5月22日，债券上市日期为2014年5月28日，上市后与农发行2014年第二十二期金融债券合并交易；本次增发的2014年第三十期债券缴款日为2014年5月23日，上市日为2014年5月27日，上市后与农发行2014年第三十期金融债券合并交易；本次增发的第三十三期债券缴款日为2014年5月22日，债券上市日期为2014年5月28日，上市后与农发行2014年第三十三期金融债券合并交易。

欢迎各商业银行、证券公司、保险公司、基金公司、农村信用社及中国人民银行许可的其他机构踊跃认购。
