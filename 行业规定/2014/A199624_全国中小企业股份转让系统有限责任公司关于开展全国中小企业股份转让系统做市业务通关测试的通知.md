# 全国中小企业股份转让系统有限责任公司关于开展全国中小企业股份转让系统做市业务通关测试的通知

## 全国中小企业股份转让系统有限责任公司关于开展全国中小企业股份转让系统做市业务通关测试的通知（股转系统公告[2014]86号）

各主办券商：

为确保全国中小企业股份转让系统有限责任公司（以下简称"本公司"）挂牌公司股票做市转让业务顺利上线，本公司定于2014年8月23日进行做市业务通关测试，以检验市场各方技术系统的上线准备情况。现将测试相关事项通知如下：

**一、**参测单位

（一）全国中小企业股份转让系统有限责任公司

（二）中国证券登记结算有限责任公司（以下简称"中国结算"）

（三）深圳证券通信有限公司（以下简称"深证通"）

（四）78家主办券商，其中47家为做市商（见附件1）

**二、**参测技术系统

（一）全国中小企业股份转让系统交易支持平台

（二）全国中小企业股份转让系统通信系统

（三）中国结算全国股份转让登记结算系统

（四）中国结算CCNET系统

（五）参测券商相关系统

**三、**测试时间

本次测试时间为2014年8月23日全天，模拟一个正常交易日的测试。

**四、**测试数据

本次测试的初始数据以8月22日清算后数据为准。

本次测试所用证券代码、证券账户、交易单元、托管单元、持仓数据、交易网关、行情小站均为8月25日上线真实数据。

**五、**测试内容

主要测试挂牌公司股票做市转让和协议转让、两网公司及退市公司股票竞价转让的日常交易和结算业务，包括申报和回报处理、行情接收和揭示、清算和交收等。

所有参测主办券商必须测试经纪业务测试场景，其中申请做市商的主办券商必须测试做市业务测试场景、自营业务测试场景；具体测试内容和测试场景见《全国中小企业股份转让系统做市业务通关测试方案》（附件2）和《全国中小企业股份转让系统做市业务通关测试场景》（附件3）。

**六、**测试工作要求

（一）切实做好做市业务技术系统和自营业务技术系统准备工作。所有参测做市商均应根据《全国中小企业股份转让系统交易支持平台数据接口规范（V1.0.1）》和《全国中小企业股份转让系统交易支持平台技术指引（V1.0）》的技术规范要求，彻底解决前期测试中发现的各类问题，确保做市业务技术系统和自营业务技术系统就绪。所有参加通关测试的做市商均需按照《关于做好实施做市转让方式有关准备工作的通知》的要求，于2014年8月21日17：00前提交相关材料。

（二）切实做好经纪业务技术系统准备工作。所有参测主办券商应完成经纪业务技术系统的升级改造，并按要求参与本次通关测试。

（三）务必使用最新版行情小站程序。深证通发布了最新版的行情小站程序，请参测券商从深证通网站下载并安装。下载地址： http：//www.ssscc.com.cn/main/xzzq/2014081230320.shtml 。

（四）认真做好测试准备工作。参测券商应认真学习《全国中小企业股份转让系统做市商做市业务管理规定（试行）》、《全国中小企业股份转让系统股票转让细则（试行）》并严格按照测试方案的要求，做好技术、数据、环境和人员方面的准备，周密组织，妥善安排，做好详尽的测试计划，确保测试工作有序推进。

（五）加强通关测试的组织协调工作。为保证测试效果，各主办券商在测试组织上应涵盖前后台、全流程，对自身技术系统和业务操作进行全面检验。必须由公司主要负责人负责本次通关测试工作，要求业务、技术等部门均参加测试，确保业务工作人员了解业务规则，熟悉业务操作。建议安排全部营业部参加测试。

（六）详细记录测试过程并做好反馈。测试过程中，各参测券商应详细记载测试现象与结果，检查其正确性。如发现异常现象，及时通过电话或QQ群与本公司沟通联系。测试当日，不论测试是否有问题，均须于当日20：00前，将电子版测试反馈表（附件5）发送至techservice@neeq.org.cn，并于8月24日上午12：00之前将加盖公章的测试反馈表（附件5）扫描件发送至techservice@neeq.org.cn。

（七）务必做好测试后的恢复工作。测试前认真做好生产系统数据备份，严格隔离生产和测试数据，测试完成后清理测试数据，确保下一交易日（8月25日）生产系统的正常运行。

（八）务必做好做市业务上线准备工作。本次通关测试成功完成后，做市业务将于8月25日正式上线，请各主办券商务必做好做市业务上线的各项准备工作。最终上线日期以本公司后续公告为准。

1　做市业务系统测试场景

|  |  |
| --- | --- |

| 【业务1】做市业务系统交易申报业务 | 1、测试做市业务系统只支持提交做市申报、做市商互报成交确认申报，不支持提交限价申报、定价申报、成交确认申报、互报成交确认申报。 　　2、测试做市申报和做市商互报成交确认申报合同序号、证券账户、证券代码、业务类别、申报价格（申报价格2）、申报数量（申报数量2）等申报要素填写是否符合数据接口规范的要求。 　　3、测试9：15前、11：30-13：00、15：30后全国股份转让系统不接收申报；测试9：15-9：30、9：30-11：30、13：00-15：00全国股份转让系统只接收做市申报并予以处理（包括不合格申报撤单返回以及撤单申报处理等），做市商互报成交确认申报直接撤单返回；测试15：00-15：30全国股份转让系统只接收做市商互报成交确认申报并予以处理（包括不合格申报撤单返回以及撤单申报处理等），做市申报直接撤单返回。 　　4、做市申报测试 　　1）　　　测试做市申报买卖股票无涨跌幅限制。 　　2）　　　测试做市申报卖出价格必须大于买入价格，且买卖相对价差不得大于5%，即（卖出价格-买入价格）/卖出价格≤5%。 　　3）　　　测试做市申报买卖价差等于最小价格变动单位时，即卖出价格-买入价格＝0.01，不受买卖相对价差不得大于5%的条款限制。 　　4）　　　测试做市买入申报数量是否必须是1000股或其整数倍；做市卖出申报要么是1000股或其整数倍，要么是全部股份一次性卖出。 　　5）　　　测试做市申报最小价格档位是否是0.01元。 　　6）　　　测试做市申报单笔申报最大数量不超过100万股。 　　7）　　　测试针对同一只做市股票，提交新的做市申报后，前笔做市申报是否自动撤单，撤单内容是否正确。 　　8）　　　测试做市申报主动撤单业务是否正常，全国股份转让系统返回的撤单内容是否正确。 　　9）　　　测试做市买入申报是否按要求冻结资金、做市卖出申报是否按要求冻结股份，成功撤单后是否正确解冻冻结的资金或股份。 　　10）　测试做市申报未通过检查自动撤单返回后，错误代码是否正确，错误原因是否清晰、明了。 　　5、　做市商互报成交确认申报测试 　　1） 测试对于当天有成交的挂牌公司做市转让股票，做市商互报成交确认申报的价格必须在该股票当日最高、最低成交价之间；若当日最高价＝当日最低价，做市商互报成交确认申报的价格就只能是等于当日最高价。 　　2） 测试对于有前收盘价但当天无成交的挂牌公司做市转让股票，做市商互报成交确认申报的价格不得高于前收盘价的110%且不低于前收盘价的90%。 　　3） 测试对于无前收盘价（为0）的挂牌公司做市转让股票，且当天无成交，不允许提交做市商互报成交确认申报。 　　4） 测试做市商互报成交确认买入申报数量可以是任意大于0且不大于1，000，000的整数；做市商互报成交确认卖出申报要么是1000股或其整数倍，要么是全部股份一次性卖出。  　　5） 测试做市商互报成交确认申报最小价格档位是否是0.01元。 　　6） 测试做市商互报成交确认申报单笔申报最大数量不超过100万股。 　　7） 测试做市互报成交确认申报约定号重复判断规则是否正确，约定号重复时是否予以撤单返回。约定号重复的判断规则为：对于两笔合同序号不同、证券账户号码和对手方证券账户号码完全相同的待撮合或已成交申报（不包括已撤单的申报），如果约定号相同，就判断为约定号重复，第二笔申报自动撤单，否则判断为约定号不重复，两笔申报均接收。测试做市商互报成交确认申报约定号应当小于100万。 　　8） 测试对于约定号相同、对手方证券账户号码相符的两笔互报成交确认申报，如果证券代码相同、申报价格相同、申报数量相同、买卖方向相反、对手方交易单元相符等五个条件中任一条件出现不符合的情形，两笔申报是否均立即撤单返回。 　　9） 测试做市商互报成交确认买入申报是否按要求冻结资金、做市商互报成交确认卖出申报是否按要求冻结股份，成功撤单后是否正确解冻冻结的资金或股份。 　　10）　　　测试做市商互报成交确认申报未通过检查自动撤单返回后，错误代码是否正确，错误原因是否清晰、明了。 |

| 【业务3】做市业务系统行情接收及揭示 | 1、 测试做市业务系统能够揭示挂牌公司做市转让股票证券信息、行情信息和做市申报信息，并且能够支持只显示其做市股票的行情信息和做市申报信息。 　　2、 检查证券信息（NQXX.DBF）显示的内容是否完整、准确，测试做市业务系统是否能够及时、准确地揭示做市业务开展时所需使用的信息，包括转让类型、转让状态、停牌标志、做市商数量等。 　　3、 测试做市业务系统是否能够及时、准确地揭示挂牌公司做市转让股票行情信息，包括但不限于证券代码、证券简称、前收盘价、今开盘价、最近成交价、最高价、最低价、涨跌、成交金额、成交数量及3档买卖盘信息。  　　4、 测试行情3档买卖盘信息是否只包括做市申报信息，不包含投资者限价申报、做市商互报成交确认申报信息。 　　5、 测试挂牌公司做市转让股票开盘价和收盘价是否无异常。 　　6、 测试做市业务系统是否能够及时、准确地揭示挂牌公司做市转让股票投资者最优10档申报价格和申报数量、做市商最优10笔申报价格和申报数量等信息。 　　7、 测试做市商互报成交确认申报达成的转让不纳入即时行情和指数的计算，成交价不纳入开盘价和收盘价计算范围，成交量在每个转让日做市商间转让结束后计入该股票成交总量。 　　8、 行情揭示系统能够正确处理挂牌公司做市转让股票在成交首日前（含当日）无前收盘价的情形，并且在成交首日不计算涨跌幅。 |
| 【业务9】做市业务系统前端控制或提醒 | 1、 测试做市业务系统只能够买卖允许其做市的挂牌公司做市转让股票。 　　2、 测试做市业务系统是否严格、自动执行买入申报冻结资金、卖出申报冻结股份指令并且执行正确。 　　3、 测试做市业务系统是否支持做市申报买入股份T＋0回转交易，做市商间互报成交确认申报买入股份当日不能卖出。 　　4、 测试做市业务系统是否不允许挂牌公司股票出现卖空情形。 　　5、 测试做市业务系统是否具有做市证券账户管理功能，并能有效控制每个做市证券账户允许做市的股票和允许做市的交易单元。 　　6、 测试做市业务系统是否具有严格控制做市申报相对买卖价差的功能。 　　7、 测试做市业务系统或风控系统是否能够控制并快速调整整体做市业务、单个做市业务人员或单只做市股票做市规模。 　　8、 测试做市业务系统是否具有做市股票进入豁免买入或者豁免卖出期间时的自动提醒功能。 　　9、 测试做市业务系统是否具有做市股票豁免买入或者豁免卖出期间，提交双向报价或豁免方向单向报价时的自动提醒功能。 　　10、 测试做市业务系统是否具有做市股票9：30前发布双向报价的自动提醒功能。 　　11、 测试做市业务系统是否具有前次做市申报撤销或其申报数量经成交后买卖两个方向或某一方向不足 1000 股时，5分钟内重新报价的自动提醒功能。 　　12、 测试做市业务系统是否具有每个转让日提供双向报价或豁免期单向报价总体时长（或时间占比）的自动提醒功能。 |
| 【业务10】全国股份转让系统前端控制 | 1、 测试全国股份转让系统是否只允许做市商交易其做市股票，并能够有效控制每个做市证券账户允许做市的股票和允许做市的交易单元。 　　2、 测试全国股份转让系统是否支持做市申报买入股份T＋0回转交易，做市商间互报成交确认申报买入股份当日不能卖出。 　　3、 测试全国股份转让系统是否不允许挂牌公司做市转让股票出现卖空情形，测试时主办券商端放开股票卖空限制或增加证券可用数量。 　　4、 测试做市业务系统是否具有严格控制做市申报相对买卖价差的功能。 |
