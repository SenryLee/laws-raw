# 2014年第五十七期和第五十八期金融债券发行结果公告

2014年度中国进出口银行金融债券承销团成员：

经中国人民银行批准，中国进出口银行于2014年9月5日经过承销团竞标，发行了2014年第五十七期和第五十八期金融债券。第五十七期债券为1年期固定利率金融债券，发行金额60亿元，票面利率为4.2564%，债券缴款日为2014年9月10日。第五十八期债券为5年期固定利率金融债券，发行金额60亿元，票面利率为4.89%，债券缴款日为2014年9月10日。欢迎境内商业银行、保险公司、农村信用合作联社和其他银行间债券市场成员积极参与债券分销。以上2期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通。
