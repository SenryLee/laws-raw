# 中国总会计师协会秘书处关于印发2014年下半年继续举办“管理会计人才培养综合能力提升研修班”的通知

## 中国总会计师协会秘书处关于印发2014年下半年继续举办“管理会计人才培养综合能力提升研修班”的通知（中总秘〔2014〕43号）

各地方总会计师协会（研究会），各分会；会员及会员单位；社会组织等有关单位：

2014年7月31日中国总会计师协会组织了“中国管理会计系列讲座”第一讲，财政部部长楼继伟亲自授课，楼部长要求我们要加快发展中国特色的管理会计，培养出我们自己的管理会计师，促进经济社会健康发展；争取3-5年内，建立起与我国社会主义市场经济体制相适应的会计体系，在全国培养一批管理会计师；通过5-10年的努力，基本建成中国特色的管理会计理论体系和指引体系；管理会计不仅是企业，包括事业单位；鼓励高等院校与会计师协会加强管理会计专业方向的建设和管理会计高端人才的培养、后续教育，为我国的管理会计发展建立人才储备。为贯彻财政部领导指示，培养造就一批精通战略财务规划等财务管理技能的高素质、复合型、国际化管理会计人才，中国总会计师协会决定2014年下半年继续举办“管理会计人才培养综合能力提升研修班”。

现将本专题培训方案予以印发。请各单位接到《通知》后，积极组织和做好参训人员的报名工作。

**一、**课程特色

国际视野，体系完善。将国际管理会计前沿理念及知识体系与我国实际相结合，探本求源、去伪存真，形成符合我国国情的中国特色的管理会计理论体系；从实用性需求出发，完善知识体系，交流研究建立中国管理会计人才能力框架。

国内特色，高端实用。以财政部关于“加强管理会计研究与人才培养”的系列论述为指导，结合国内企业的阶段性特点，通过理论、实战与案例的有效结合讲授，并通过互助式讨论、论坛、沙龙等辅助形式充分挖掘学员需求，解决学员难题。

师资权威，主线清晰。国家财政及相关主管部门的领导和研究人员、国家会计学院及各大财经院校的权威专家、业内著名的财务实战派专家组合授课，实现理论与实战的高效应用。

针对国内财务，助力财务转型。在完善管理会计知识体系的基础上，结合国内传统财务会计知识体系特点，精心设置三大模块，深入诠释管理会计的价值创造和能力培养路径，助力传统财务会计转型及财务团队整体能力提升。
