# 上海证券交易所关于2014年江苏省政府债券(三期)上市交易的通知

## 上海证券交易所关于2014年江苏省政府债券（三期）上市交易的通知

各市场参与人：

根据江苏省财政厅《关于发行2014年江苏省政府债券（三期）有关事项的通知》（苏财库[2014]25号）和上海证券交易所（以下简称“本所”）有关规定，2014年江苏省政府债券（三期）（以下简称本期债券）将于2014年7月31日在本所竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期债券为固定利率债券，期限为10年，票面利率为4.29%，利息每半年支付一次；本期债券起息日为2014年7月25日，每年1月25日、7月25日支付利息（逢节假日顺延，下同），2024年7月25日偿还本金并支付最后一次利息。

**二、**本期债券于2014年7月31日起在本所竞价系统和固定收益证券综合电子平台上市，交易方式为现券和质押式回购。

**三、**本期债券上市交易的现券证券名称为“14江苏03”，证券代码为“130134”，质押券申报和转回代码为“106134”。

上海证券交易所

二〇一四年七月二十四日
