# 深圳证券交易所关于为江苏广亚建设集团有限公司2014年中小企业私募债券提供转让服务有关事项的通知

各会员单位：

江苏广亚建设集团有限公司2014年中小企业私募债券定于2014年9月26日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、江苏广亚建设集团有限公司2014年中小企业私募债券证券代码“118250”，证券简称“14广亚债”，发行总额15，000万元，票面利率9.7%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一四年九月二十四日
