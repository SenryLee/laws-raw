# 全国中小企业股份转让系统有限责任公司关于中国证券业年鉴编辑委员会编辑出版《2014全国中小企业股份转让系统专辑》有关事项的通知

各主办券商、挂牌企业及相关机构：

为了全面、系统地记录我国多层次资本市场建设的重要成就，更好地记录和展示全国中小企业股份转让系统的发展历程，以及年度挂牌企业、市场各参与主体的良好市场形象，中国证券业年鉴编辑委员会拟编辑出版《2014全国中小企业股份转让系统专辑》，望相关单位积极参与。

请相关挂牌企业及主办券商向中国证券业年鉴编辑委员会协助提供以下材料：

**一、**公司图片（公司挂牌仪式、重要会议、活动、投资项目等）3-5张

；

**二、**公司动态资料（基本概况、业务范围、经营业绩、企业文化等）

；

**三、**公司董事长工作照及个人简历

；

**四、**其他（公司地址、联系方式、VI基本包、LOGO等）。
