# 2014年第五十三期和第五十四期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年8月21日经过承销团竞标，发行了2014年第五十三期和第五十四期金融债券。第五十三期债券为我行2014年第十七期金融债的增发债券，发行金额60亿元，期限1年，中标价格为102.11元，参考收益率为4.2546%，债券缴款日为2014年8月25日。第五十四期债券为我行2014年第五十期金融债的增发债券，发行金额60亿元，期限7年，中标价格为100.54元，参考收益率为5.0169%，债券缴款日为2014年8月25日。欢迎境内商业银行、保险公司、农村信用合作联社和其他银行间债券市场成员积极参与债券分销。以上2期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通。
