# 深圳证券交易所关于上海超日太阳能科技股份有限公司股票暂停上市的公告

上海超日太阳能科技股份有限公司2011年、2012年、2013年连续三个会计年度经审计的净利润为负值。根据《深圳证券交易所股票上市规则》第14.1.1条、第14.1.2条的规定，本所决定该公司股票自2014年5月28日起暂停上市。

上海超日太阳能科技股份有限公司在股票暂停上市期间，应当继续履行有关法规及《深圳证券交易所股票上市规则》规定的上市公司义务，做好信息披露工作。

深圳证券交易所
