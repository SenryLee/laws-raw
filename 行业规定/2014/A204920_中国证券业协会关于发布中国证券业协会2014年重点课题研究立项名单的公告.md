# 中国证券业协会关于发布中国证券业协会2014年重点课题研究立项名单的公告

中国证券业协会目前已顺利完成2014年重点课题研究申报立项工作，本次共有41家会员单位和19所高校等科研机构参与申报了66项课题。按照《中国证券业协会重点课题研究管理办法》，经过申报规范性、选题质量、研究人员能力与研究基础、研究提纲、预期研究成果和单位支持力度等方面的综合评议，确认41项重点课题研究项目立项，现将课题立项名单予以公布（见附件）。

附件：中国证券业协会2014年重点课题研究立项名单

中国证券业协会

2014年3月31日
