# 中国期货业协会关于开展防范非法期货活动的通知

各会员单位:

为了落实中国证监会《关于进一步加强和改进打击非法证券期货活动工作有关问题的通知》要求，推动行业做好防范非法期货工作，保护投资者合法权益，现就建立防范非法期货长效机制，近期开展以防范非法期货为主题的“12.4”法制宣传等事项通知如下：

一、充分认识开展防范非法期货活动的重要性

防范非法期货活动，是建设市场经济诚信文化，维护期货市场正常经营秩序，保护社会公众的合法利益的必然要求，是期货市场监管系统和有关方面共同的重要职责，需要各方的持续艰苦努力。

各会员单位要进一步深化对非法期货活动的危害性和防范非法期货活动重要性、持久性的认识，增强责任感和使命感，按照中国证监会和协会安排部署，积极贯彻落实，使防范非法期货工作取得新的成效。

二、开展防范非法期货活动的相关要求

（一）将防范非法期货活动融入投资者教育工作，纳入经营管理范围和业务流程。各会员单位在经营过程中要结合不同业务特点，在各个业务环节中把防范非法期货活动作为投资者教育的重要内容，充分揭示非法期货活动的特征和危害，不断提高投资者对非法期货活动的辨识和防范能力。

（二）创新业务与产品，提升服务质量，不断拓展合法期货覆盖面和影响力。9月16日，中国证监会发布了《关于进一步推进期货经营机构创新发展的意见》（以下简称《意见》），制定了今后一段时期推进期货经营机构创新发展的总体原则和具体措施。各会员单位要充分学习领会《意见》精神，按照《意见》要求，深入了解投资者需求，积极创新业务与产品，努力提升服务质量，不断扩大产品和服务的覆盖面、影响力，广开正路，压缩非法期货活动生存空间。

（三）建立非法期货信息监测和报送机制。各会员单位在日常经营和开展业务过程中，发现涉及非法期货活动的媒体信息或相关宣传，发现投资者受到非法期货活动蛊惑和侵害时，应当及时通过电子邮件（member@cfachina.org）向协会报告。

（四）通过各种渠道、载体加强有关防范非法期货活动宣传。各会员单位应当在营业场所电子屏、跑马灯、宣传栏等物理载体设置防范非法期货宣传标语和警示信息，增强公众防范意识；通过网站、微信、交易平台、内部刊物等各种自媒体介质、渠道开展宣传，提示公众和投资者远离非法期货。

三、今年“12.4”法制宣传日工作安排

开展“12.4”法制宣传是增强行业法制意识，提高期货市场法治水平的重要工作。在今年“12.4”法制宣传日活动中，各会员单位要将防范非法期货活动作为主题，通过公司网站、营业场所、交易平台等线上线下渠道和载体开展形式活泼、内容具体的全方位、立体化宣传。各联系会员应当对相关活动给予充分关注，尽快将协会“远离非法期货，保护自身权益”宣传单页转交辖区期货经营机构，要求其向目标投资者发放，及时汇总辖区情况，收集策划水平高、效果好的案例，于12月20日前向协会（member@cfachina.org）报送工作开展情况。

协会将在今后的专项检查中将会员单位落实防非宣传纳入检查范围。

特此通知。
