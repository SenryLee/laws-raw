# 中国银行业协会关于表彰“2013年度中国银行业普及金融知识万里行活动”先进单位的决定

## 中国银行业协会关于表彰“2013年度中国银行业普及金融知识万里行活动”先进单位的决定（银协发[2014]28号）

各会员单位：

为切实加强银行业消费者权益保护工作，进一步巩固和完善消费者教育服务工作长效机制，中国银行业协会于2 0 1 3年4月至7月组织开展了“2013年度中国银行业普及金融知识万里行活动”，各会员单位认真贯彻落实活动相关工作要求，相互配合，积极推动，组织开展了广受百姓欢迎的金融知识推广普及活动。

活动达到了强化公众金融素质，提高从业人员消费者权益保护意识，提升行业服务水平的目标，全面营造了学金融、懂金融、用金融的良好氛围，充分展示了银行业的良好社会形象。

根据《2 013年度中国银行业普及金融知识万里行活动方案》（银协发[2 013]6号）的要求，在对会员单位各阶段活动的总结

报送、组织保障、活动特色、社会反响等方面进行全面考量的基础上，最终评选出2 0 1 3年度中国银行业普及金融知识万里行活动先进单位2 0家。为引领银行业深化开展公众教育服务工作，树立典型，弘扬先进，进一步推动公众教育服务可持续发展，中国银行业协会决定授予中国工商银行等1 0家单位“最佳成效奖”、上海市银行同业公会等1 0家单位“最佳组织奖”，并颁发奖杯和证书，以示鼓励。

希望受到表彰的单位再接再厉，继续强化消费者保护理念，大力提升从业人员消费者保护意识，主动开展公众教育服务活动，努力倾听消费者服务需求，切实保护金融消费者权益，充分发挥示范带动作用，助推全行业公众教育服务工作长效机制建设，为广大银行消费者营造和谐的金融消费环境。
