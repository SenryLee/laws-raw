# 深圳证券交易所、深圳证券信息有限公司关于发布深证中高、中低等级信用债指数的公告

为刻画深市不同信用等级信用债的总体运行特征，进一步丰富和完善深证指数体系，推动指数化投资的不断发展与创新，深圳证券交易所与深圳证券信息有限公司于2014年9月25日发布深证中高、中低等级信用债指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399298 | 深证中高等级信用债指数 | 深信中高 | 2008年12月31日 | 100 |
| 399299 | 深证中低等级信用债指数 | 深信中低 | 2008年12月31日 | 100 |

上述指数以在深圳证券交易所上市非ST的企业债和公司债为样本空间，同时要求样本债券剩余期限超过一年，附息方式为固定利率付息或一次还本付息。深证中高等级信用债指数选取信用级别在AA＋及以上的投资级债券作为样本，深证中低等级信用债指数选取信用级别在AA＋及以下的投资级债券作为样本。指数采用债券发行量加权，每月的第一个交易日实施样本调整。

深证中高、中低等级信用债指数通过深交所行情系统发布实时行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//www.cnindex.com.cn）。
