# 中国环境保护产业协会关于发布《2014年国家鼓励发展的环境保护技术目录（工业烟气治理领域）》典型应用案例的通知

中环协〔2014〕75号

各省、自治区、直辖市、副省级城市环境保护产业协会，中国环境保护产业协会各专业委员会，各有关单位：

日前，为落实党中央、国务院对大气环境污染防治工作的要求，配合《大气污染防治行动计划》等政策文件的贯彻实施，环境保护部发布了《2014年国家鼓励发 展的环境保护技术目录（工业烟气治理领域）》（环境保护部公告 2014年 第71号），《2014年国家鼓励发展的环境保护技术目录（工业烟气治理领域）》（后文简称《目录》）所列技术是已经工程实践证明，技术指标先进、治理效 果可靠、经济可行的成熟技术。

受环境保护部委托，中国环境保护产业协会具体负责《目录》的技术筛选和《目录》编制工作，为便于各级环境保护行政主管部门和用户单位在污染治理工作中使用 《目录》，现将《目录》中所列技术的典型应用案例予以发布。本通知及附件可在中国环境保护产业协会官网（www.caepi.org.cn）的“技术服 务”栏目中查阅。其中，案例内容已经过申报单位书面确认，其真实性和有效性由申报单位负责。

附件：《2014年国家鼓励发展的环境保护技术目录（工业烟气治理领域）》典型应用案例

中国环境保护产业协会

2014年12月5日
