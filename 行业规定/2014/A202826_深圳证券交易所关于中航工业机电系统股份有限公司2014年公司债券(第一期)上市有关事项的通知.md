# 深圳证券交易所关于中航工业机电系统股份有限公司2014年公司债券(第一期)上市有关事项的通知

## 深圳证券交易所关于中航工业机电系统股份有限公司2014年公司债券（第一期）上市有关事项的通知

各会员单位：

中航工业机电系统股份有限公司2014年公司债券（第一期）定于2014年5月23日起在本所集中竞价系统和综合协议交易平台同时挂牌交易，现将有关事项通知如下：

中航工业机电系统股份有限公司2014年公司债券（第一期）证券代码“112201”，证券简称“14机电01”，发行总额7.5亿元，票面利率6.200%，债券深圳证券交易所期限5年，附第3年末发行人利率上调选择权和投资者回售选择权。

特此通知

二○一四年五月二十一日
