# 深圳证券交易所关于荣丰控股集团股份有限公司股票临时停牌的公告(2014)

## 深圳证券交易所关于荣丰控股集团股份有限公司股票临时停牌的公告

因荣丰控股集团股份有限公司筹划重大资产重组事项，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：荣丰控股，证券代码：000668）自2014年10月14日开市起停牌，待公司刊登相关公告后复牌。

深圳证券交易所

2014年10月14日
