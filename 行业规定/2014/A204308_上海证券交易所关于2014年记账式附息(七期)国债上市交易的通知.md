# 上海证券交易所关于2014年记账式附息(七期)国债上市交易的通知

## 上海证券交易所关于2014年记账式附息（七期）国债上市交易的通知

各会员单位：

根据《财政部关于2014年记账式附息（七期）国债发行工作有关事宜的通知》（财库〔2014〕27号）和上海证券交易所（以下简称“本所”）有关规定，2014年记账式附息（七期）国债（以下简称“本期国债”）将于2014年4月18日在本所竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期国债为固定利率附息债，期限为1年，票面利率为3.63%，利息到期一次支付；本期国债起息日为2014年4月14日，2015年4月14日（节假日顺延）偿还本金并支付利息。

**二、**本期国债于2014年4月18日起在本所竞价系统和固定收益证券综合电子平台上市，交易方式为现券和质押式回购。

**三、**本期国债上市交易的现券证券名称为“14国债07”，证券代码为“019407”，质押券申报和转回代码为“091078”。

上海证券交易所

二〇一四年四月十一日
