# 中国矿业权评估师协会、国土资源部矿产资源储量评审中心公告2014年第2号——关于数字采矿软件系统平台DIMINE V10.0矿产资源储量估算功能模块评审备案的公告

中国矿业权评估师协会、国土资源部矿产资源储量评审中心公告

（2014年第2号）

关于数字采矿软件系统平台DIMINE V10.0矿产资源储量估算功能模块评审备案的公告

根据《矿产资源储量估算软件评审办法（暂行）》（中国矿业权评估师协会公告2013年第6号），中国矿业权评估师协会和国土资源部矿产资源储量评审中心组织专家对长沙迪迈数码科技股份有限公司开发的数字采矿软件系统平台DIMINE V10.0矿产资源储量估算功能模块进行了评审，评审通过了数字采矿软件系统平台DIMINE V10.0的距离幂次反比法、普通克里格法资源储量估算方法估算功能模块，并已经国土资源部矿产资源储量司备案。

特此公告。

中国矿业权评估师协会

国土资源部矿产资源储量评审中心

2014年3月27日
