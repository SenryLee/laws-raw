# 上海证券交易所关于2014年桐庐县国有资产投资经营有限公司公司债券上市交易的公告

## 上海证券交易所关于2014年桐庐县国有资产投资经营有限公司公司债券上市交易的公告（上证公告（债券）〔2014〕397号）

桐庐县国有资产投资经营有限公司发行的2014年桐庐县国有资产投资经营有限公司公司债券，将于2014年8月8日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“14桐庐投”，证券代码为“124660”。

上海证券交易所

二〇一四年八月七日
