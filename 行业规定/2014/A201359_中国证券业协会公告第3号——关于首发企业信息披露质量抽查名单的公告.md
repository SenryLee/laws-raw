# 中国证券业协会公告第3号——关于首发企业信息披露质量抽查名单的公告

## 中国证券业协会公告（第3号）

关于首发企业信息披露质量抽查名单的公告

遵循公平、公正、公开原则，2014年6月20日，我会组织了首发企业信息披露质量抽查名单第二次抽签仪式。经监管部门代表、自律组织代表、行业代表和媒体代表共同见证，抽签结果为爱普香料集团股份有限公司。

特此公告。

中国证券业协会

2014年6月20日
