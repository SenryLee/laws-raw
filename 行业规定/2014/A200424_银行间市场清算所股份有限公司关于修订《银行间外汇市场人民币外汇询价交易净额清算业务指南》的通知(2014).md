# 银行间市场清算所股份有限公司关于修订《银行间外汇市场人民币外汇询价交易净额清算业务指南》的通知(2014)

## 银行间市场清算所股份有限公司关于修订《银行间外汇市场人民币外汇询价交易净额清算业务指南》的通知（清算所发〔2014〕59号）

人民币外汇询价交易净额清算会员：

因人民币外汇询价交易净额清算业务将新增对澳元/人民币询价即期交易的净额清算，我们对2013年4月11日发布的《银行间外汇市场人民币外汇询价交易净额清算业务指南》（清算所发〔2013〕17号）进行了修订。

本次修订主要是增加了澳元清算流程，修订后的业务指南自澳元/人民币询价即期交易净额清算业务正式上线之日起生效。
