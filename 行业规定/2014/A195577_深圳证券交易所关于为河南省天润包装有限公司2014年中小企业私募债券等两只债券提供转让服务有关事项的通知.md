# 深圳证券交易所关于为河南省天润包装有限公司2014年中小企业私募债券等两只债券提供转让服务有关事项的通知

各会员单位：

河南省天润包装有限公司2014年中小企业私募债券、云南三七科技有限公司2014年中小企业私募债券（第一期）定于2014年11月3日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、河南省天润包装有限公司2014年中小企业私募债券证券代码“118260”，证券简称“14天润债”，发行总额3，000万元，票面利率9.4%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

2、云南三七科技有限公司2014年中小企业私募债券（第一期）证券代码“118269”，证券简称“14三七01”，发行总额15，000万元，票面利率8.3%，债券期限1年。

深圳证券交易所

二○一四年十月三十日
