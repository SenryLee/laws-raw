# 中国工商银行股份有限公司关于销售国家开发银行2014年第十二期金融债券的公告

尊敬的客户：

我行将于2014年5月6日至2014年5月8日，通过电子银行渠道和境内营业网点面向个人和非金融机构客户，销售国家开发银行2014年第十二期金融债券。

本期债券简称14国开12，债券代码140212，为1年期固定利率债券，票面利率为4.50%，债券面值100元，到期一次性还本付息。债券起息日为2014年5月9日，上市交易日为2014年5月13日，付息兑付日为2015年5月9日。债券发行价格为100.00元/百元面值，客户认购债券数量为100元面值的整数倍。

本期债券限额发售，先买先得，售完即止。办理流程参见门户网站业务介绍和营业网点宣传海报、折页等。

欢迎广大客户认购。

中国工商银行股份有限公司

2014年05月04日
