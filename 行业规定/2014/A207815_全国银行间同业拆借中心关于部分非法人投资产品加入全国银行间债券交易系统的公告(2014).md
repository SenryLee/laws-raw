# 全国银行间同业拆借中心关于部分非法人投资产品加入全国银行间债券交易系统的公告(2014)

## 全国银行间同业拆借中心关于部分非法人投资产品加入全国银行间债券交易系统的公告（中汇交公告〔2014〕1号）

根据中国人民银行上海总部及其他分支机构关于非法人投资产品进入银行间债券市场的准入备案通知书及相关投资管理人的联网申请，2013年12月我中心共完成58只非法人投资产品的入市准备工作，从即日起，可参与我中心组织的债券交易。其中，证券投资基金41只、企业年金14只，保险产品3只，具体为：
