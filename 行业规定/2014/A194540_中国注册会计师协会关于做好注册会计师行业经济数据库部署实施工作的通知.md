# 中国注册会计师协会关于做好注册会计师行业经济数据库部署实施工作的通知

## 中国注册会计师协会关于做好注册会计师行业经济数据库部署实施工作的通知（会协〔2014〕10号）

各省、自治区、直辖市注册会计师协会：

为了方便证券资格会计师事务所查询使用经济数据信息，贯彻落实风险导向审计理念，提高执业质量，我会决定部署注册会计师行业经济数据库（以下简称“行业经济数据库”）。

行业经济数据库是指为支持注册会计师从事审计鉴证、管理咨询、资产评估及其他业务工作对数据的需求，而建立的集经济数据与分析工具于一体的经济数据库平台。其中，经济数据包含宏观经济数据、行业数据、公司数据、金融数据，以及与资本市场密切相关的其他数据。行业经济数据库项目启动以来，我会相继开展了需求调研、专家论证、产品试用、服务商选择等工作。通过竞争性谈判方式，确定浙江核新同花顺网络信息股份有限公司（以下简称同花顺公司）为2014年4月至2015年3月期间的行业经济数据库服务商。

为做好行业经济数据库部署实施工作，现将有关事项通知如下。

**一、**实施对象与方式

我会集中采购了1500个行业经济数据库端口账号，将免费提供给证券资格会计师事务所。如果满足不了需求，证券资格会计师事务所可在此次采购的服务期限内按协议价向同花顺公司购买。非证券资格会计师事务所，也可在此次采购的服务期限内向同花顺公司按协议价购买。通过谈判约定，会计师事务所购买每个行业经济数据库端口账号的协议价为1000元。

对1500个行业经济数据库端口账号，我会将根据证券资格会计师事务所2013年度的业务收入进行分配，初步分配方案如下：

|  |  |
| --- | --- |
| 事务所业务收入（亿元） | 分配账号数量（个） |
| 总额≥10 | 60 |
| 3≤总额＜10 | 40 |
| 1≤总额＜3 | 20 |

上述分配方案，将根据证券资格会计师事务所在财务报表管理系统里填报的2013年度收入进行确定。

行业经济数据库采取CS/BS结合方式部署，所有用户通过访问我会门户网站 （http：//www.cicpa.org.cn）左侧“知识系统”栏目，点击“经济数据库”链接进入行业经济数据库（首次登陆系统会提示安装行业经济数据库金融终端）。

**二、**实施步骤

（一）明确职责

我会会同同花顺公司制定行业经济数据库部署实施方案，监督指导同花顺公司及时完成行业经济数据库部署实施工作，并持续提供培训和后续服务。

地方注协指定行业经济数据库联系人（建议由信息技术部门同志担任），推动本地区会计师事务所对行业经济数据库的部署实施、使用和培训工作，协助会计师事务所完成自行购买行业经济数据库工作，并将购买数量反馈至我会信息技术部。

证券资格会计师事务所应当高度重视行业经济数据库部署实施工作，安排专人负责，配合同花顺公司完成部署实施和使用培训工作。其他会计师事务所，根据业务需求，做好行业经济数据库的购买与使用工作。

（二）核对信息

地方注协通知各事务所于2014年4月7日前，登录我会行业管理信息系统（会员版，http：//cmis.cicpa.org.cn）和财务报表管理系统（http：//cwbb.cicpa.org.cn），核实事务所基本信息，确保事务所名称、事务所代码、办公地址、联系人、联系电话、传真、电子邮箱、通讯地址及邮编等字段信息的准确无误。

（三）安装部署

同花顺公司按照时间节点部署行业经济数据库端口账号，在4月15日前，将行业经济数据库账号和密码免费分发给证券资格会计师事务所总所（总所根据实际情况自行为分所分配账号）。

（四）使用培训

同花顺公司按照要求开展行业经济数据库使用培训工作，以现场培训、视频教学、疑难解答热线电话和电子邮件等形式解决用户使用过程中遇到的问题。此外，4月30日前，同花顺公司必须针对每家证券资格会计师事务所完成至少1次现场使用操作培训。

（五）审核验收

证券资格会计师事务所应当在同花顺公司为本所完成我会免费分配的行业经济数据库端口账号安装与培训后一周内，将行业经济数据库部署情况上报我会。部署实施工作全面完成后，我会将开展行业经济数据库验收工作。使用过程中，将不定期召开行业经济数据库使用情况交流会，吸收事务所意见建议，推动同花顺公司持续改进产品和服务。

**三、**其他事项

1.各地方注协于3月28日前填写《注册会计师行业经济数据库地方注协联系人信息表》（附件1），以邮件或传真形式反馈我会信息技术部。

2.各证券资格会计师事务所于3月28日前填写《注册会计师行业经济数据库证券资格会计师事务所联系人信息表》（附件2），以邮件或传真形式反馈我会信息技术部。

3.各证券资格会计师事务所于4月25日前填写《注册会计师行业经济数据库部署实施情况统计表（附件3），以邮件或传真形式反馈我会信息技术部。
