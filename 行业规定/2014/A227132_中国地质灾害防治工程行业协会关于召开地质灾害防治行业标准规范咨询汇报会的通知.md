# 中国地质灾害防治工程行业协会关于召开地质灾害防治行业标准规范咨询汇报会的通知

中地灾防协发[2014]29号

各相关单位：

按照《2014年工作计划》和《标准规范组织实施方案》的要求，中国地质灾害防治工程行业协会（以下简称“协会”）定于2014年12月26-31日在广州、武汉召开2014年地质灾害防治工程行业标准规范编制工作咨询汇报会。现将相关事宜通知如下：

一、会议内容

本次会议主要是编制单位对拟2014年提交的标准规范编制工作进行汇报。同时，对2014年8、9月份标准规范咨询会期间专家针对各标准规范提出的问题修改情况进行审查。在此基础上，各专家对此次提交的标准规范文本进一步审查，为下一步的标准规范验收工作做好准备。

二、参会人员

咨询会的参会人员主要为评审专家、协会外聘专家、协会领导、组织单位、主编单位、参编单位、中国国土资源经济研究院及相关工作人员。

三、会议时间和地点安排

本次咨询会由协会主办，中国国土资源经济研究院、广东省地灾协会和湖北地质局协办，将在广东广州、湖北武汉召开，具体时间和地点安排见附件。

四、食宿安排

食宿统一安排，费用自理，会务组不统一收取。

五、其他

在汇报会上，各牵头主编单位要对拟2014年提交的标准规范进行汇报，汇报时间为15分钟，提问10分钟，专家座谈35分钟，专长组长总结10分钟。由组织单位指定一名专业技术人员对专家意见进行汇总，并将汇总后的意见发送相关主编单位和参编单位。

六、联系方式

本次咨询会的专家由协会秘书处负责组织联系，各地区规范编制单位由组织单位进行联系（各组织单位联系人见附件）。
