# 上海证券交易所关于2014年北京市石景山区国有资产经营公司企业债券上市交易的公告

## 上海证券交易所关于2014年北京市石景山区国有资产经营公司企业债券上市交易的公告（上证公告（债券）〔2014〕498号）

北京市石景山区国有资产经营公司发行的2014年北京市石景山区国有资产经营公司企业债券，将于2014年10月16日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“14石景山”，证券代码为“124910”。债券上市后可进行质押式回购，质押券申报和转回代码为“103910”。本期债券上市折扣系数为0.70，上市交易后折扣系数为0.70。

上海证券交易所

二〇一四年十月十五日
