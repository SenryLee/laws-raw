# 中国工商银行股份有限公司关于升级工银信用卡银联境外网络交易方式的公告

尊敬的客户：

为满足广大客户境外（含香港、澳门、台湾地区）用卡需要，配合银联境外网络信用卡受理改造，我行将于2014年6月1日升级信用卡在银联境外网络交易方式。届时，您使用我行带有银联标识的信用卡，在境外粘贴有“银联主标识＋仅支持签名Signature Only”标识（）的银联免输密网络商户消费时，将直接以签名方式确认交易，无需输入密码即可完成交易。

如您不同意我行上述调整内容，您可在2014年6月1日之前或之后通过我行电话银行（95588）、网上银行（www.icbc.com.cn）或发卡机构网点等渠道申请调整设置银联境外免输密网络交易限额。您所设置的限额是您通过银联网络消费时需要验证交易密码的限额，如交易金额大于您所设置的限额，须输入密码完成交易，若收单商户终端（POS机具）不支持输入密码可能导致您的交易失败。对于2014年6月1日之前已调整设置银联境外免输密网络交易限额的，不在本次升级范围之内。

如有疑问，请您及时致电客服热线95588咨询。

中国工商银行股份有限公司
