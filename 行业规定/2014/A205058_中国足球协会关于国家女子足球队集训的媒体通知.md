# 中国足球协会关于国家女子足球队集训的媒体通知

各有关媒体：

为备战2014年女足亚洲杯决赛阶段的比赛，按照计划，国家女子足球队将于2014年3月28日至4月12日组织集训，期间将出访美国，同美国国家女子足球队比赛2场，现将有关事宜通知如下：

**一、**训练时间、地点

时间：2014年3月28日至4月12日

地点：国家奥林匹克体育中心

**二、**报到时间、地点：

时间：2014年3月28日12时前

地点： 国家奥林匹克体育中心运动员公寓

地址：北京市朝阳区安定路1号

**三、**集训人员名单

副领队：黄中华（中国足协）

主教练：郝 伟（山东）

**四、**经费条件

集训、比赛期间的食宿、交通、保险等相关费用由中国足协负担。

**五、**集训相关要求

（一） 准时报到。不得无故迟到或不参加此次集训，如有伤病，须携带俱乐部队医证明，按时抵达集训地点报到，接受女足国家队队医检查和体检；如有特殊情况，请各有关单位提前书面请示中国足协国管部办公室，并按照具体批复执行。

（二） 参加集训的运动员报到时，须携带身份证、学习、训练等必备物品，请各单位务必通知到运动员本人。
