# 中国上市公司协会关于缴纳2014年度会费的通知

尊敬的会员：

根据《中国上市公司协会章程》及《中国上市公司协会会费标准及管理办法》的规定，现就2014年度会费缴纳事宜通知如下：

**一、**贵公司作为中国上市公司协会的会员单位，应于每年3月31日之前缴纳会费。

**二、**会费标准：会员年会费标准为1万/年；会员理事、会员监事为8万/年，会员常务理事为20万/年，会员副会长、会员副监事长为30万/年。
