# 深圳证券交易所关于为河南佳源乳业股份有限公司2014年中小企业私募债券提供转让服务有关事项的通知

各会员单位：

河南佳源乳业股份有限公司2014年中小企业私募债券定于2014年9月23日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

河南佳源乳业股份有限公司2014年中小企业私募债券证券代码“118253”，证券简称“14佳源债”，发行总额15，000万元，票面利率9.1%，债券期限2年，附第1年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一四年九月十九日
