# 中国建设银行股份有限公司关于变更我行微信银行公众帐号名称的公告

中国建设银行股份有限公司关于变更我行微信银行公众帐号名称的公告

尊敬的客户：

我行定于2014年4月11日将微信银行公众帐号名称由“建行电子银行”变更为“中国建设银行”，公众帐号号码（CCB_elutong）、二维码保持不变，原有各项服务均不受影响。感谢您长期以来给予我行工作的大力支持！

特此公告。

中国建设银行股份有限公司

二О一四年四月十一日
