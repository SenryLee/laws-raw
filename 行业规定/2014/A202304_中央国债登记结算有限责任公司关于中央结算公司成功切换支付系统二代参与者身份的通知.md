# 中央国债登记结算有限责任公司关于中央结算公司成功切换支付系统二代参与者身份的通知

各结算成员：

根据第二代支付系统参与机构推广工作安排，经人民银行支付结算司及清算总中心批准，我公司于2014年5月30日至6月2日实施了支付系统二代参与者身份切换，现已成功完成切换。

特此通知。

二〇一四年六月二日
