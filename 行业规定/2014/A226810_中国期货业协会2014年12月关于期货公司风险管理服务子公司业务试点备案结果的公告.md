# 中国期货业协会2014年12月关于期货公司风险管理服务子公司业务试点备案结果的公告

## 中国期货业协会关于期货公司风险管理服务子公司业务试点备案结果的公告

根据《期货公司设立子公司开展以风险管理服务为主的业务试点工作指引（修订）》等相关规则规定，经审查，国海良时资本管理有限公司提交的业务试点备案材料齐全，符合规定，现予以备案。具体内容如下：

|  |  |
| --- | --- |
| **备案公司** | **备案事项** |
| 国海良时资本管理有限公司 | 试点业务：仓单服务、基差交易、  合作套保、定价服务 |

中国期货业协会

2014年12月18日
