# 中国外汇交易中心、全国银行间同业拆借中心关于更换拨号认证服务器的通知

银行间外汇市场会员/本币市场成员：

中国外汇交易中心（以下简称“交易中心”）将于2014年10月31日晚更换电话拨号认证服务器，并将拨号用户数据迁移至新服务器。为了不影响下一个交易日的正常业务，请所有使用电话拨号接入交易中心的机构于11月1日或2日验证拨号可用性。

验证方法：使用目前在用的拨号用户名及密码拨号成功即可。

认证服务器更换后，拨号用户修改密码的网页地址有所更新，详见www.chinamoney.com.cn中国货币网/培训与服务支持/技术支持/技术资料栏目下的《中国外汇交易中心电话拨号用户修改密码使用说明》。

如有任何问题，请联系交易中心技术支持：021-68797878转6、13818324796.

特此通知。
