# 上海证券交易所关于2014年盐城市城南新区开发建设投资有限公司公司债券上市交易的公告

## 上海证券交易所关于2014年盐城市城南新区开发建设投资有限公司公司债券上市交易的公告（上证公告（债券）〔2014〕442号）

盐城市城南新区开发建设投资有限公司发行的2014年盐城市城南新区开发建设投资有限公司公司债券，将于2014年9月2日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“14盐城南”，证券代码为“124887”。债券上市后可进行质押式回购，质押券申报和转回代码为“103887”，本期债券上市折扣系数为0.70，上市交易后折扣系数为0.70。

上海证券交易所

二〇一四年九月一日
