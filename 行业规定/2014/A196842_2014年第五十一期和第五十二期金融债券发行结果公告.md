# 2014年第五十一期和第五十二期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年8月15日经过承销团竞标，发行了2014年第五十一期和第五十二期金融债券。第五十一期为我行2014年第四十四期金融债的增发债券，发行金额为60亿元，发行价格为100.56元，参考收益率为4.8736%，债券缴款日为2014年8月19日。第五十二期债券为1年期贴现金融债券，首场发行金额为60亿元，中标价格为95.87元，参考收益率为4.3079%。第五十二期债券首场招标结束后，我行按照首场中标价格向工商银行追加发行15亿元当期债券，由工商银行在柜台债券市场向个人和非金融机构投资者进行分销，2014年8月15日至22日为银行间债券市场分销期，2014年8月18日至21日为商业银行柜台债券市场分销期，债券缴款日为2014年8月22日。

以上2期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通，柜台债持有人在债券上市后可通过工商银行柜台进行交易。
