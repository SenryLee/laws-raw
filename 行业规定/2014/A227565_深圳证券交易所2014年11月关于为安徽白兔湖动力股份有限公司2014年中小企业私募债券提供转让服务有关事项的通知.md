# 深圳证券交易所2014年11月关于为安徽白兔湖动力股份有限公司2014年中小企业私募债券提供转让服务有关事项的通知

各会员单位：

安徽白兔湖动力股份有限公司2014年中小企业私募债券定于2014年11月24日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

安徽白兔湖动力股份有限公司2014年中小企业私募债券证券代码“118273”，证券简称“14白兔湖”，发行总额7,300万元，票面利率8.98%，债券期限2年，附第1年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一四年十一月二十日
