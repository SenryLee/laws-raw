# 深圳证券交易所2014年11月关于为青岛豪士诚贸易有限公司2014年中小企业私募债券（第一期）等两只债券提供转让服务有关事项的通知

各会员单位：

青岛豪士诚贸易有限公司2014年中小企业私募债券（第一期）、 青岛豪士诚贸易有限公司2014年中小企业私募债券（第二期）定于2014年11月20日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、青岛豪士诚贸易有限公司2014年中小企业私募债券（第一期）证券代码“118263”，证券简称“14青豪01”，发行总额26,500万元，票面利率10%，债券期限12月。

2、青岛豪士诚贸易有限公司2014年中小企业私募债券（第二期）证券代码“118264”，证券简称“14青豪02”，发行总额13,498万元，票面利率10%，债券期限12月。

深圳证券交易所

二○一四年十一月十八日
