# 中国金融期货交易所关于修订《中国金融期货交易所应急交易厅使用指引》的通知(2014)

## 中国金融期货交易所关于修订《中国金融期货交易所应急交易厅使用指引》的通知

各会员单位：

为进一步提高会员交易业务运行保障能力，维护市场正常交易秩序，我所对《中国金融期货交易所应急交易厅使用指引》进行了修订，删除第十七条关于应急交易终端使用费的规定。

修订后的《中国金融期货交易所应急交易厅使用指引》自2014年1月29日起实施。

特此通知。

附件：中国金融期货交易所应急交易厅使用指引（略）

中国金融期货交易所

二〇一四年一月二十九日
