# 全国银行间同业拆借中心关于部分非法人投资产品退出全国银行间债券交易系统的公告(中汇交公告[2014]41号)

## 全国银行间同业拆借中心关于部分非法人投资产品退出全国银行间债券交易系统的公告（中汇交公告〔2014〕41号）

根据中国人民银行有关规定及相关投资管理人的申请，2014年6月我中心共完成2只非法人投资产品的退市工作，上述投资产品为：

中融国际信托扩大内需主题投资资金信托

裕阳证券投资基金

特此公告。

全国银行间同业拆借中心
