# 深圳证券交易所2014年11月关于为北京电信易通信息技术股份有限公司2014年中小企业私募债券提供转让服务有关事项的通知

各会员单位：

北京电信易通信息技术股份有限公司2014年中小企业私募债券定于2014年11月27日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

北京电信易通信息技术股份有限公司2014年中小企业私募债券证券代码“118270”，证券简称“14易通债”，发行总额1,000万元，票面利率8%，债券期限2年。

深圳证券交易所

二○一四年十一月二十五日
