# 深圳证券交易所、深圳证券信息有限公司关于发布深市精选指数的公告

为了反映深圳市场领军企业的特色，进一步推动上市公司做优做强，促进信息披露透明度与规范运作水平的持续提升，深圳证券交易所和深圳证券信息有限公司定于2014年5月30日发布深市精选指数。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399013 | 深市精选指数 | 深市精选 | 2004年12月31日 | 1000 |

深市精选指数综合考察信息披露透明度、市值、流动性、营业收入与净利润等指标，从深市主板和中小板的上市公司中，严格筛选出符合标准的A股公司组成样本股。指数采用自由流通市值加权计算方法，自2015年起每年7月进行样本股定期调整。

深市精选指数包括纯价格指数和全收益指数，纯价格指数通过深圳证券交易所行情系统发布实时行情数据，全收益指数通过巨潮指数网发布收盘行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：// www.cnindex.com.cn）。
