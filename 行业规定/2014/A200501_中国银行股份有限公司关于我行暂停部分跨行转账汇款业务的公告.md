# 中国银行股份有限公司关于我行暂停部分跨行转账汇款业务的公告

中国银行股份有限公司关于我行暂停部分跨行转账汇款业务的公告

尊敬的客户：

按照中国人民银行的统一部署，我行总行大小额跨行汇款相关系统将于2014年7月25日-26日升级换代。在此期间，我行将暂停部分渠道的跨行汇款服务（包括汇出和汇入），届时将无法受理下表所述业务。具体安排如下：

业务类型暂停时间停业范围

|  |  |  |  |
| --- | --- | --- | --- |
| 所有渠道 | 定期借记、普通借记业务 | 17日15：00至26日8：00 | 总行 |
| 柜台 | 跨行转账汇款（通汇宝、批量代发薪） | 25日15：00至26日8：00 | 总行 |
| 网上银行（企业服务） | 跨行转账汇款（5万元人民币及以下） | 25日15：00至26日8：00 | 总行 |

注：

ATM渠道（取款机和存取款一体机）的银联卡跨行转账功能不受本次人行系统升级影响。

在上述公告停业时间内，如实际停业时间缩短，我行将正常处理客户提交的上述交易，相关交易均为有效交易。由此给您带来的不便，敬请谅解。如有任何问题或需任何帮助，敬请致电95566或亲临我行营业网点。

特此公告

中国银行股份有限公司
