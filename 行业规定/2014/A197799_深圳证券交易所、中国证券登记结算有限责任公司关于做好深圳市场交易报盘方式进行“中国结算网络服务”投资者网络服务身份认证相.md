# 深圳证券交易所、中国证券登记结算有限责任公司关于做好深圳市场交易报盘方式进行“中国结算网络服务”投资者网络服务身份认证相关技术准备工作的通知

各证券公司及相关单位：

为保护投资者合法权益，简化投资者现场办理身份认证的业务流程，便利投资者通过中国结算网站办理证券持有查询、质押回购查询、投票等网络服务业务，深圳证券交易所（以下简称“深交所”）和中国证券登记结算有限责任公司（以下简称“中国结算”）拟通过深市交易报盘方式为中国结算网络服务提供身份认证支持，设置相关网络服务密码，请各证券公司及相关单位于2014年10月24日前做好相关技术系统的准备工作。现将相关事项通知如下：

**一、**投资者通过交易报盘方式办理身份认证的主要流程

深交所为中国结算分配一个证券代码（369991，简称“中登认证”）并在交易所挂牌，专门用于投资者办理中国结算网络服务身份认证业务。主要流程说明如下：

（一）投资者登录中国结算网站，进入用户注册网页，填写姓名/名称、身份证明文件号码、证券账户号码、手机号码等信息，并自行设置网络服务密码。注册成功后，网站系统将通过短信向投资者填注的上述手机号发送一个9位数字校验号码。该校验号码与投资者证券账户号码、网络服务密码具有一一对应关系。

（二）交易时间内，投资者使用上述证券账户通过证券公司自助交易平台（如交易软件、电话委托交易系统等）以买入指令的方式，在证券代码、购买价格、委托数量等项下输入369991、1.000元、校验号码等内容后，将买入指令提交至证券公司（具体做法详见本通知第二条说明）。

（三）证券公司将投资者上述买入指令信息转发至深交所交易系统，再由深交所转发至中国结算进行处理。

（四）中国结算对接收到的投资者买入指令信息与投资者在中国结算网站注册的上述信息、网站系统以短信方式发送的校验号码等内容进行比对处理，比对无误的，当日激活投资者在中国结算网站设置的上述证券账户号码、校验号码所对应的网络服务密码。

（五）投资者可使用证券账户号码、网络服务密码登录中国结算网站办理证券持有查询、质押回购查询、投票等网络服务业务。

网络服务密码因遗忘等原因需进行重置的，其重置流程类似于上述做法。

上述交易报盘身份认证方式实现后，投资者无需至证券公司柜台即可在线办理身份认证。

**二、**深交所交易系统中关于369991证券的说明

为了配合中国结算完成网络服务用户的身份认证，深交所拟在证券信息库SJSXX.DBF、新证券信息库SJSXXN.DBF、行情库SJSHQ.DBF中长期挂牌一条记录，其证券代码为369991，证券简称为“中登认证”，昨收盘价为1.000元（无特别含义），证券简称前缀（新证券信息库SJSXXN.DBF的字段3：XXJCQZ）取值无特别含义。

投资者使用369991证券进行身份认证时，券商技术系统应当通过委托库SJSWT.DBF申报。投资者的委托报盘操作说明，详见下表：

|  |  |  |
| --- | --- | --- |
| 输入参数 | 密码激活指令 | 密码重置指令 |
| 证券代码 | 369991 | |
| 证券账户 | 投资者的深市证券账户代号 | |
| 业务类别 | 普通买入或新股申购（证券营业部不冻结资者资金） | |
| 委托价格 | 1．000元 | 2．000元 |
| 委托数量 | 中国结算技术系统分配的9位数字校验号码 | |

（1）深交所将及时转发投资者的委托指令给中国结算。至于申报指令是否合法，以中国结算最终确认结果为准。

（2）如果业务类别既不为“普通买入”，也不为“新股申购”，则申报指令无效，深交所交易系统将直接丢弃，既不回报，也不转发。

（3）若委托价格不为1．000或2．000之一，则申报指令无效，深交所交易系统将之自动撤单，并通过回报库SJSHB.DBF予以回报，撤单原因为“价格错误”。对于其他情形，仅转发，不予回报。

（4）有关校验号码等身份认证业务的详细情况，中国结算将另行通知。

**三、**深交所将联合中国结算择机组织业务仿真与全网测试，测试通知另行发布。
