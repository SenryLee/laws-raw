# 深圳证券交易所关于铁岭新城投资控股股份有限公司2014年公司债券上市有关事项的通知

各会员单位：

铁岭新城投资控股股份有限公司2014年公司债券定于2014年7月7日起在本所集中竞价系统和综合协议交易平台同时挂牌交易，现将有关事项通知如下：

铁岭新城投资控股股份有限公司2014年公司债券证券代码“112199”，证券简称“14铁岭债”，发行总额10亿元，票面利率8.450%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所
