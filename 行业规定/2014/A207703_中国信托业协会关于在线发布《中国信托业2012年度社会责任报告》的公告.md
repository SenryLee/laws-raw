# 中国信托业协会关于在线发布《中国信托业2012年度社会责任报告》的公告

中国信托业协会关于在线发布《中国信托业2012年度社会责任报告》的公告

为进一步推进信托行业社会责任工作，展现行业履行社会责任阶段性成果，提升行业良好社会形象，在中国银监会的指导下，在各会员单位的大力支持和配合下，协会组织编制了《中国信托业2012年度社会责任报告》，并于2013年中国信托业年会上正式发布。

本报告是中国信托业首次向社会发布的行业社会责任报告，也是我国金融领域第二份行业社会责任报告。为方便社会各方阅读，现将报告电子版在协会官方网站在线发布。真诚希望社会各方通过本报告进一步走近信托业、关注信托业、了解信托业，增进信托业与社会各方的沟通和交流，推动信托业在全面践行社会责任进程中实现快速健康可持续发展。

特此公告。
