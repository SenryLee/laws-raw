# 中国证券登记结算有限责任公司关于2014年劳动节休市期间证券资金清算交收安排的通知

各结算参与单位：

根据《关于2014年部分节假日休市期间证券资金清算交收安排的通知》，现将2014年劳动节休市期间资金清算交收安排通知如下：

**一、**2014年4月30日发生的证券交易（B股除外）和当日到期的债券回购，资金清算日为2014年4月30日，资金交收日为2014年5月5日。

**二、**2014年5月5日发生的证券交易（B股除外）和2014年5月1日-5日到期的债券回购，资金清算日为2014年5月5日，资金交收日为2014年5月6日。

**三、**上海市场2014年4月28日、29日发生的B股交易，资金交收日依次为2014年5月5日、6日。深圳市场2014年4月28日、29日、30日发生的B股交易，资金交收日依次为2014年5月5日、7日、7日。

请各结算单位据此安排好有关工作。

中国证券登记结算有限责任公司

二〇一四年四月二十五日
