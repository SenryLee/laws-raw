# 中国银行关于调整三级财富管理客户相关收费项目公告

中国银行关于调整三级财富管理客户相关收费项目公告

（2014年4月1日）

尊敬的贵宾客户：

感谢您对中国银行的支持与厚爱，为了让您能够更好的体验我行贵宾客户服务，我行将继续延长中银理财和中银财富的优惠期限至2015年3月31日，同时私人银行服务按照现有标准继续执行，具体项目参见附表。

如有疑问，敬请垂询中国银行各地分支机构，或拨打客户服务电话95566。

特此公告

附表1：理财和财富客户收费项目

|  |  |  |  |
| --- | --- | --- | --- |
| 业务类别 | 服务项目 | 服务功能 | 收费标准 |
|
| 1.中银理财服务 | 1.1 年费 | 向理财客户提供综合理财服务产生的服务年费 | 最高1000元/年 　　【暂免到2015年3月31日】 |
| 1.2 月结单 | 每月向客户提供资产对账单服务 | 最高20元/份 　　【暂免到2015年3月31日】 |
| 2.中银财富管理 | 2.1投资顾问服务费 | 投资顾问为财富客户提供的咨询顾问服务 | 300元/月 　　【暂免到2015年3月31日】 |
| 2.2投资组合管理费 | 投资顾问为财富客户的资产配置提供的全套组合管理服务 | 500元/月 　　【暂免到2015年3月31日】 |
| 2.3年费 | 向财富客户提供综合理财服务产生的服务年费 | 1500元/年 　　【暂免到2015年3月31日】 |
| 3.私人银行 | 3.1 投资顾问费 | 私人银行分部投资顾问直接或通过外部专业机构向客户提供涵盖金融、投资、税务、法律、实业的顾问咨询服务 | 不高于投资项目投入资金或资产现值的2% /年计收 |
| 3.2 见证及咨询手续费 | 私人银行分部向有跨境服务需求的私人银行客户提供我行海外私人银行与财富管理机构的见证开户服务，并联合全球客户经理提供海外见证开户的专业咨询服务 | 外部费用按实收取，不高于100元/次，涉及海外业务不高于500元/次。 |
| 3.3 资产管理费 | 私人银行分部针对签约客户全权委托管理的资产按年征收固定比率的资产管理费；同时，对超过基准水平的额外收益收取部分额外费用 | 日均余额500万元（含）以下最高收取1% 　　日均余额500-800万元（含）最高收取0.8% 　　日均余额800-5000万元（含）最高收取0.7% 　　日均余额5000万元以上最高收取0.5% |
| 3.4 私人银行综合账户管理费 | 针对客户开立的远程账户收取的管理费，该账户支持代客交易服务 | 不高于500元/年 |
| 3.5 托管费 | 向私人银行签约客户收取提供综合服务所产生的固定的资产托管费，按年计收 | 与客户议定，按照协议收取 |
| 3.6 私人银行产品代理收付费 | 私人银行分部引入或代售外部合作机构的专属个性化产品时，向客户收取的代销手续费 | 与客户议定，按照协议收取 |
