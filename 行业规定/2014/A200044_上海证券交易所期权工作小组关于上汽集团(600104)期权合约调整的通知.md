# 上海证券交易所期权工作小组关于上汽集团(600104)期权合约调整的通知

## 上海证券交易所期权工作小组关于上汽集团（600104）期权合约调整的通知

根据上市公司公告，上汽集团（600104）将于2014年7月30日除权除息。根据《上海证券交易所期权全真模拟交易规则》，本所将于2014年7月30日对所有以该证券为标的的期权合约进行调整，调整信息如下：

原有合约单位调整如下：

|  |  |  |
| --- | --- | --- |
| 序号 | 原合约单位 | 调整后合约单位 |
| 1 | 5000 | 5365 |

原有行权价调整如下表：

|  |  |  |
| --- | --- | --- |
| 序号 | 原行权价 | 调整后行权价 |
| 1 | 10.00 | 9.32 |
| 2 | 11.00 | 10.25 |
| 3 | 12.00 | 11.18 |
| 4 | 13.00 | 12.12 |
| 5 | 14.00 | 13.05 |
| 6 | 15.00 | 13.98 |
| 7 | 16.00 | 14.91 |
| 8 | 17.00 | 15.84 |
| 9 | 18.00 | 16.78 |
| 10 | 19.00 | 17.71 |
| 11 | 20.00 | 18.64 |

调整同日将新挂相关月份的标准化合约。

请投资者注意投资风险，备兑开仓持仓者请在除权除息日补足备兑证券。

上海证券交易所期权工作小组

2014年7月29日
