# 深圳证券交易所关于河北建投能源投资股份有限公司股票临时停牌的公告(2014)

## 深圳证券交易所关于河北建投能源投资股份有限公司股票临时停牌的公告

因中国证监会上市公司并购重组审核委员会将于近日审核河北建投能源投资股份有限公司重大资产重组事项，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：建投能源，证券代码：000600）自2014年1月16日开市起停牌，待公司收到相关审核结果并公告后复牌。

深圳证券交易所

2014年1月16日
