# 中国进出口银行2014年第十六期、第十七期、第十八期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年3月13日经过承销团竞标，发行了2014年第十六期至第十八期金融债券。第十六期为6个月期贴现债券，发行金额60亿元，发行价格97.88元，参考收益率为4.2965%，缴款日为2014年3月17日。第十七期和第十八期金融债券分别为1年期和5年期固定利率债券，发行金额均为70亿元，票面利率分别为4.55%和5.27%，缴款日分别为2014年3月18日和3月21日。欢迎境内商业银行、保险公司、农村信用合作联社和其他银行间债券市场成员积极参与债券分销。以上三期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通。
