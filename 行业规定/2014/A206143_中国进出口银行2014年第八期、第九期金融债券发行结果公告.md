# 中国进出口银行2014年第八期、第九期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年2月20日经过承销团竞标，发行了2014年第八期、第九期金融债券。第八期债券为我行2014年第五期金融债的增发债券，发行额60亿元，期限2年，中标价格100.3202元，参考收益率为5.1244%，债券缴款日为2014年2月21日。第九期债券为3年期固定利率投资人选择权债券（投资人可选择在2017年2月24日按100%面值向发行人全部或部分回售，或继续持有至2019年2月24日），发行额60亿元，票面利率为5.2613%，债券缴款日为2014年2月24日。欢迎境内商业银行、保险公司、农村信用合作联社和其他银行间债券市场成员积极参与债券分销。以上两期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通。
