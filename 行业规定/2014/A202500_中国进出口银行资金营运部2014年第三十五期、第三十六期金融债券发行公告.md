# 中国进出口银行资金营运部2014年第三十五期、第三十六期金融债券发行公告

2014年度中国进出口银行金融债券承销团成员：

根据《中国人民银行关于下达2014年中国进出口银行人民币贷款计划及金融债券发行计划的通知》（银发〔2014〕51号），我行定于2014年6月6日10：00-11：00通过中国人民银行债券发行系统，招标发行第三十五期、第三十六期金融债券。

**一、**第三十五期金融债券

第三十五期债券为3年期固定利率金融债，发行金额不超过60亿元，票面利率通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。

**二、**第三十六期金融债券（140330增发）

第三十六期债券为我行2014年第三十期7年期固定利率金融债的增发债券，票面利率为4.85%，发行金额不超过60亿元，发行价格通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。

发行办法详见中国债券信息网http：//www.chinabond.com.cn或中国货币网http：//www.chinamoney.com.cn。
