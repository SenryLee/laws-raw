# 深圳证券交易所关于深圳市海王生物工程股份有限公司股票临时停牌的公告(2014)

## 深圳证券交易所关于深圳市海王生物工程股份有限公司股票临时停牌的公告

因有关媒体报道了深圳市海王生物工程股份有限公司尚未披露的信息，可能对公司股价产生较大影响，根据《深圳证券交易所股票上市规则》第12.4条的规定，经公司申请，公司股票（证券简称：海王生物，证券代码：000078）于2014年3月6日开市起临时停牌，待公司刊登相关公告后复牌。

深圳证券交易所

2014年3月6日
