# 中国环境保护产业协会关于发布2014年国家重点环保实用技术及示范工程名录（第二批）的通知

中环协〔2014〕78号

各省、自治区、直辖市环境保护产业协会，各有关行业协会，中国环境保护产业协会各专业委员会，各有关单位：

经各省、自治区、直辖市环境保护产业协会，各专业委员会及各相关行业协会推荐，中国环境保护产业协会组织了2014年国家重点环境保护实用技术及示范工程（第二批）的评审和公示工作，现将2014年国家重点环境保护实用技术名录（第二批）和2014年国家重点环境保护实用技术示范工程名录（第二批）公布。

请各单位结合实际情况，认真组织好国家重点环境保护实用技术及示范工程的示范与推广，为“十二五”污染减排和改善环境质量做出贡献。

附件：

1.2014年国家重点环境保护实用技术名录（第二批）

2.2014年国家重点环境保护实用技术示范工程名录（第二批）

中国环境保护产业协会

2014年12月22日
