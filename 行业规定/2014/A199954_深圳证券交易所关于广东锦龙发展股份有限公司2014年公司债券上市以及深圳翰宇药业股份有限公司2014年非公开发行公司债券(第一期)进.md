# 深圳证券交易所关于广东锦龙发展股份有限公司2014年公司债券上市以及深圳翰宇药业股份有限公司2014年非公开发行公司债券(第一期)进行转让有关事项的通知

## 深圳证券交易所关于广东锦龙发展股份有限公司2014年公司债券上市以及深圳翰宇药业股份有限公司2014年非公开发行公司债券（第一期）进行转让有关事项的通知

各会员单位：

广东锦龙发展股份有限公司2014年公司债券定于2014年8月1日起在本所集中竞价系统和综合协议交易平台同时挂牌交易，深圳翰宇药业股份有限公司2014年非公开发行公司债券（第一期）定于2014年8月1日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

1、广东锦龙发展股份有限公司2014年公司债券证券代码“112207”，证券简称“14锦龙债”，发行总额3亿元，票面利率6.680%，债券期限3年。

2、深圳翰宇药业股份有限公司2014年非公开发行公司债券（第一期）证券代码“112205”，证券简称“14翰宇01”，发行总额2亿元，票面利率8.500%，债券期限5年，附第3年末发行人上调票面利率选择权及投资者回售选择权。

特此通知

深圳证券交易所
