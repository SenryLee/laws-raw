# 深圳证券交易所2014年11月关于深圳市科陆电子科技股份有限公司2014年公司债券（第一期）等三只债券上市有关事项的通知

各会员单位：

深圳市科陆电子科技股份有限公司2014年公司债券（第一期）,深圳市怡亚通供应链股份有限公司2014年公司债券,安徽省司尔特肥业股份有限公司2014年公司债券（第一期）定于2014年11月21日起在本所集中竞价系统和综合协议交易平台同时挂牌交易，现将有关事项通知如下：

1、深圳市科陆电子科技股份有限公司2014年公司债券（第一期）证券代码“112226”，证券简称“14科陆01”，发行总额2亿元，票面利率7.00%，债券期限5年,附第3年末发行人上调票面利率选择权及投资者回售选择权。

2、深圳市怡亚通供应链股份有限公司2014年公司债券证券代码“112228”，证券简称“14怡亚债”，发行总额11.5亿元，票面利率7.00%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

3、安徽省司尔特肥业股份有限公司2014年公司债券（第一期）证券代码“112230”，证券简称“14司尔01”，发行总额3亿元，票面利率6.50%，债券期限5年，附第3年末发行人上调票面利率选择权和投资者回售选择权。

特此通知

深圳证券交易所

二○一四年十一月十九日
