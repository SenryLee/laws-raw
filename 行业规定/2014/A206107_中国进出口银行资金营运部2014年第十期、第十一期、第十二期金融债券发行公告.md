# 中国进出口银行资金营运部2014年第十期、第十一期、第十二期金融债券发行公告

2014年度中国进出口银行金融债券承销团成员：

根据《中国人民银行关于中国进出口银行2014年金融债券临时发行计划的批复》（银函〔2013〕407号），我行定于2014年2月28日10：00-11：00通过中国人民银行债券发行系统，招标发行2014年第十期、第十一期、第十二期金融债券。

**一、**第十期金融债券

第十期债券为3年期固定利率金融债，发行金额不超过60亿元，票面利率通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。

**二、**第十一期金融债券

第十一期债券为2年期固定利率金融债，发行金额不超过60亿元，票面利率通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。

**三、**第十二期金融债券

第十二期债券为5年期固定利率金融债，发行金额不超过70亿元，票面利率通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。

发行办法详见中国债券信息网http：//www.chinabond.com.cn或中国货币网http：//www.chinamoney.com.cn。
