# 中国资产评估协会关于印发《中国资产评估协会会员入会(评审)流程》的通知

## 中国资产评估协会关于印发《中国资产评估协会会员入会（评审）流程》的通知（中评协[2014]13号）

各省、自治区、直辖市、计划单列市资产评估协会（注册会计师协会）：

为进一步加强对中国资产评估协会各类会员的管理和服务，规范会员入会（评审）流程，根据《中国资产评估协会会员管理办法》，中国资产评估协会对各类会员的入会（评审）程序进行梳理，制作了《中国资产评估协会会员入会（评审）流程》，现印发给你们，请遵照执行。

附件：中国资产评估协会会员入会（评审）流程

二○一四年一月十四日

附件：

中国资产评估协会会员入会（评审）流程

**一、**团体会员入会流程

（一）当然团体会员

1.　 资产评估机构在完成工商注册登记后，向所在地地方协会提交入会申请材料，包括：《中国资产评估协会当然团体会员入会申请表》（附表1）、所在省（自治区、直辖市）财政厅（局）关于同意设立资产评估机构批复文件及资产评估机构设立申请材料；

2.　 地方协会受理入会申请；

3.　 地方协会对申请材料核实无误后，将有关信息录入中国资产评估行业管理信息平台，报中评协；

4.　 中评协批准入会；

5.　 中评协授权地方协会颁发当然团体会员证书。

（二）特别团体会员

1.　 取得证券评估业务资格的资产评估机构，向中评协提交入会申请材料，包括：《中国资产评估协会特别团体会员入会申请表》（附表2）、《证券、期货相关业务评估资格证书》复印件；

2.　 中评协受理入会申请；

3.　 中评协将有关信息录入中国资产评估行业管理信息平台；

4.　 中评协对申请材料核实并批准入会；

5.　 中评协颁发特别团体会员证书。

（三）联系团体会员

1.　 申请单位提交入会申请材料，其中：国外及港澳台地区从事评估业务的机构，从事资产评估研究、教学的单位以及与资产评估行业相关的全国性社会团体、中央企事业单位，向中评协提交入会申请材料；与资产评估行业相关的地方性社会团体、地方企事业单位以及其他中介机构向所在地地方协会提交入会申请材料。申请材料包括：《中国资产评估协会联系团体会员入会申请表》（附表3）、法人营业执照或组织机构代码证复印件，国外及港澳台地区从事资产评估业务的机构需提交相关组织会员证书或资质证书复印件；

2.　 中评协或地方协会受理入会申请；

3.　 中评协或地方协会对申请材料进行审查，对符合条件的，批准入会；对不符合条件的，告知其原因；

4.　 中评协或地方协会将有关信息录入中国资产评估行业管理信息平台；

5.　 地方协会将批准入会的单位报中评协备案；

6.　 中评协或中评协授权地方协会颁发联系团体会员证书。

**二、**个人会员入会流程

（一）执业会员

1.已取得注册资产评估师执业资格的申请人

（1）申请人在提交注册申请材料申请办理注册资产评估师注册时，一并向所在地地方协会提交《中国资产评估协会注册资产评估师注册（入会）申请表》（附表4）；

（2）地方协会受理注册（入会）申请；

（3）地方协会对申请材料核实无误后，将有关信息录入中国资产评估行业管理信息平台，报中评协；

（4）中评协批准注册（入会）；

（5）中评协授权地方协会颁发执业会员证书（卡）。

2.资产评估机构的非注册资产评估师合伙人或股东

（1）申请人为资产评估机构非注册资产评估师，在设立资产评估机构或资产评估机构变更股东时，拟担任合伙人或股东的，向所在地地方协会提交入会申请材料，包括：《中国资产评估协会非注册资产评估师合伙人（股东）入会申请表》（附表5）、所在省（自治区、直辖市）财政厅（局）关于同意设立资产评估机构批复文件及资产评估机构设立申请材料或准予资产评估机构股东变更的决定及股东变更备案相关材料，申请人身份证复印件，要求提供复印件的材料，应同时提交原件备查；

（2）地方协会受理入会申请；

（3）地方协会对申请材料核实无误后，将有关信息录入中国资产评估行业管理信息平台，报中评协；

（4）中评协批准入会；

（5）中评协授权地方协会颁发执业会员证书（卡）。

（二）非执业会员

1.　 申请人提交入会申请材料，其中：申请人在中央国家机关及政府相关部门、中央企事业单位、全国性社会团体工作的，向中评协提交入会申请材料；申请人在除上述单位之外的单位工作的，向所在地地方协会提交入会申请材料。申请材料包括：《中国资产评估协会非执业会员入会申请表》（附表6）、《注册资产评估师执业资格证书》或依法认定批准文件复印件、申请人身份证复印件，要求提供复印件的材料，应同时提交原件备查；

2.　 中评协或地方协会受理入会申请；

3.　 中评协或地方协会对申请材料进行审查，对符合条件的，批准入会；对不符合条件的，告知其原因；

4.　 中评协或地方协会将有关信息录入中国资产评估行业管理信息平台；

5.　 地方协会将批准入会的人员报中评协备案；

6.　 中评协或中评协授权地方协会颁发非执业会员证书（卡）。

（三）见习会员

1.　 申请人向所在地地方协会提交入会申请材料，包括：《中国资产评估协会见习会员入会申请表》（附表7）、申请人所在资产评估机构出具的工作证明或高等院校出具的学生证明、申请人身份证复印件，取得注册资产评估师执业资格的人员需提交《注册资产评估师执业资格证书》复印件，要求提供复印件的材料，应同时提交原件备查；

2.　 地方协会受理入会申请；

3.　 地方协会对申请材料进行核实；

4.　 地方协会组织入会考试，其中，已经通过注册资产评估师考试或依法认定取得注册资产评估师执业资格的申请人，可以免予参加入会考试；

5.　 地方协会对通过入会考试的人员批准入会；

6.　 地方协会将有关信息录入中国资产评估行业管理信息平台；

7.　 中评协授权地方协会颁发见习会员证书（卡）。

（四）联系个人会员

1.　 申请人提交入会申请材料，其中：申请人在全国性资产评估研究、教学单位工作的，在特定行业提供专门化服务的，在国外及港澳台地区评估行业工作的，向中评协提交入会申请材料；申请人在地方性资产评估研究、教学单位工作的，在资产评估相关行业或部门工作的，向所在地地方协会提交入会申请材料。申请材料包括：《中国资产评估协会联系个人会员入会申请表》（附表8）、申请人身份证复印件、申请人工作单位出具的工作证明，在特定行业提供专门化服务的技术专家需提交相关资质证书，取得国外评估类专业资质、从事评估业务的国外及港澳台地区人员需提交相关组织会员证书或资质证书复印件，要求提供复印件的材料，应同时提交原件备查；

2.　 中评协或地方协会受理入会申请；

3.　 中评协或地方协会对申请材料进行审查，对符合条件的，批准入会；对不符合条件的，告知其原因；

4.　 中评协或地方协会将有关信息录入中国资产评估行业管理信息平台；

5.　 地方协会将批准入会的人员报中评协备案；

6.　 中评协或中评协授权地方协会颁发联系个人会员证书（卡）。

**三、**资深会员、名誉会员评审流程

（一）资深会员

1.　 申请人提交申请材料，其中：执业会员向所在地地方协会提交申请材料；在中央国家机关、政府相关部门、中央企事业单位、全国性社会团体以及资产评估研究或教学单位工作，或在特定行业提供专门化服务，或在国外及港澳台地区评估行业工作的非执业会员和联系个人会员，向中评协提交申请材料；其他非执业会员和联系个人会员，向所在地地方协会提交申请材料。申请材料包括：《中国资产评估协会资深会员申请表》（附表9），相关自述材料，评估专业论文、专业著作以及国家级、省部级、中评协研究课题的原件或复印件；

2.　 中评协或地方协会受理申请，对申请材料进行初审，确定初审合格者；

3.　 地方协会将初审合格者上报中评协；

4.　 中评协秘书处将初审合格者的有关材料，在中评协网站上进行公示；

5.　 中评协秘书处对初审合格者组织约请面谈；

6.　 中评协资深会员提名委员会对初审合格者进行审查，并向常务理事会推荐资深会员候选人；

7.　 中评协常务理事会审议通过后成为资深会员；

8.　 中评协将有关信息录入中国资产评估行业管理信息平台；

9.　 中评协颁发资深会员证书和资深会员徽章，并在中评协网站、刊物等媒体上予以公布。

（二）名誉会员

1. 中评协秘书处提名，提名范围包括：对资产评估行业做出重大贡献的社会人士、境内、外知名人士等；

2. 中评协常务理事会批准；

3. 中评协将有关信息录入中国资产评估行业管理信息平台；

4. 中评协颁发名誉会员证书。
