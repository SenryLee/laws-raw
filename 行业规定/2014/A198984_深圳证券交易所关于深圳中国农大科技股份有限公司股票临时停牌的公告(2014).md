# 深圳证券交易所关于深圳中国农大科技股份有限公司股票临时停牌的公告(2014)

## 深圳证券交易所关于深圳中国农大科技股份有限公司股票临时停牌的公告

因深圳中国农大科技股份有限公司正在筹划非公开发行股票事项，鉴于该事项尚存不确定性，为维护投资者利益，避免公司股价异常波动，根据《深圳证券交易所股票上市规则》的有关规定，经公司申请，该公司股票（证券简称：国农科技，证券代码：000004）自2014年9月9日开市起停牌，待公司刊登相关公告后复牌。

深圳证券交易所

2014年9月9日
