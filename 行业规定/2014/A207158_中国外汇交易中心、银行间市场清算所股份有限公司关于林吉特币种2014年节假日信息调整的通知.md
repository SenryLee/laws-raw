# 中国外汇交易中心、银行间市场清算所股份有限公司关于林吉特币种2014年节假日信息调整的通知

## 中国外汇交易中心、银行间市场清算所股份有限公司关于林吉特币种2014年节假日信息调整的通知（清算所发[2014]7号）

各银行间外汇市场会员：

根据中国银行马来西亚分行（外汇竞价业务清算行）通知，因马来西亚节假日临时调整，外汇交易币种林吉特2014年节假日相应变化，具体调整如下：

**一、**本次调整为：新增2月3日、7月15日为林吉特节假日：10月23日调整为工作日，10月22日调整为节假日。

**二、**调整后的林吉特2014年节假日为：1月1日、1月14日、1月17日、1月31日、2月1日、2月3日、5月1日、5月13日、7月15日、

7月28日、7月29日、8月31日、9月1日、9月16日、10月5日、10月6日、10月22日、10月25日、12月25日。

特此通知。
