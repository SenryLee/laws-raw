# 深圳证券交易所关于2014年地方政府债券(五期)上市交易的通知

## 深圳证券交易所关于2014年地方政府债券（五期）上市交易的通知

各会员单位：

2014年地方政府债券（五期）已发行结束，根据财政部通知，本期债券于2014年7月4日起在本所上市交易。

本期债券为5年期固定利率附息式国债（地方政府债），证券编码“109126”，证券简称“地债1405”，票面利率4.12％，标准交易单位“10张”，2019年6月30日到期还本并支付最后一期利息。

特此通知
