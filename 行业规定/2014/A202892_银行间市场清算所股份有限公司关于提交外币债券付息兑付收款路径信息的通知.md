# 银行间市场清算所股份有限公司关于提交外币债券付息兑付收款路径信息的通知

## 银行间市场清算所股份有限公司关于提交外币债券付息兑付收款路径信息的通知（清算所发〔2014〕38号）

各银行间债券市场成员：

为保障美元中票“13沪城投美元MTN001”首次付息及日后付息兑付工作的顺利开展，向境内外币债券投资人提供高效、快捷、安全的兑付服务，现就相关事项通知如下：

**一、**请该美元中票各投资人于6月中旬前向我公司提交《外币债券持有人付息兑付收款账户信息情况表》（见附件）。

**二、**今后，请持有外币债券的各投资人于付息兑付前一个月主动向我公司提交《外币债券持有人付息兑付收款账户信息情况表》。

若有任何疑问，请与我公司联系。

联系人：谢晨燕，021-63325290；胡颖，021-63325057。

特此通知。
