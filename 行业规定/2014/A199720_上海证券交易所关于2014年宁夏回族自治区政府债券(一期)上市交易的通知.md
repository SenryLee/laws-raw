# 上海证券交易所关于2014年宁夏回族自治区政府债券(一期)上市交易的通知

## 上海证券交易所关于2014年宁夏回族自治区政府债券（一期）上市交易的通知

各市场参与人：

根据宁夏回族自治区财政厅《关于发行2014年宁夏回族自治区政府债券（一期）有关事宜的通知》（宁财（库）发[2014]669号）和上海证券交易所（以下简称“本所”）有关规定，2014年宁夏回族自治区政府债券（一期）（以下简称本期债券）将于2014年8月18日在本所竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下：

**一、**本期债券为固定利率债券，期限为5年，票面利率为3.98%，利息每年支付一次；本期债券起息日为2014年8月12日，每年8月12日支付利息（逢节假日顺延，下同），2019年8月12日偿还本金并支付最后一次利息。

**二、**本期债券于2014年8月18日起在本所竞价系统和固定收益证券综合电子平台上市，交易方式为现券和质押式回购。

**三、**本期债券上市交易的现券证券名称为“14宁夏01”，证券代码为“130138”，质押券申报和转回代码为“106138”。

上海证券交易所

二〇一四年八月十一日
