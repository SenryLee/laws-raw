# 中国期货业协会公告2014年考试第5号——关于2014年度期货从业人员资格考试公告

## 中国期货业协会公告（2014年考试第5号）

关于2014年度期货从业人员资格考试公告

按照《中国期货业协会关于2014年期货从业人员资格考试公告（2014年考试第1号）》安排，中国期货业协会将于9月27日在全国36个城市举办2014年度第四次期货从业人员资格考试。考生可于8月5日登录中国期货业协会网站“期货从业人员资格考试网上报名”通道进行报名，报名截止时间为9月4日；准考证打印时间为9月22日至26日。考试成绩将于考试结束日起7个工作日内在协会网站发布。

特此公告。

中国期货业协会

二○一四年七月二十八日
