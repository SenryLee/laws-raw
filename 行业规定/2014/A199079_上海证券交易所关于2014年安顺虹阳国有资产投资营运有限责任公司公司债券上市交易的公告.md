# 上海证券交易所关于2014年安顺虹阳国有资产投资营运有限责任公司公司债券上市交易的公告

## 上海证券交易所关于2014年安顺虹阳国有资产投资营运有限责任公司公司债券上市交易的公告（上证公告（债券）〔2014〕456号）

安顺虹阳国有资产投资营运有限责任公司发行的2014年安顺虹阳国有资产投资营运有限责任公司公司债券，将于2014年9月5日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“14安经开”，证券代码为“124881”。

上海证券交易所

二〇一四年九月四日
