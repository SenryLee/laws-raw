# 中国煤炭建设协会关于公布2014年煤炭建设行业优秀、先进QC小组等的通知

中煤建协字[2014]83号

各有关单位：

2014年煤炭建设行业优秀、先进QC小组在各单位申报推荐的基础上，经中国煤炭建设协会组织成果发布和有关专家认真评选，从申报推荐、发布交流的80项成果中，评选出中煤矿山建设集团淮南工程处顾桥项目部QC小组等33个QC小组为2014年煤炭建设行业优秀QC小组（见附件一）、陕煤化建设集团韩城分公司土建八项目部QC小组等47个QC小组为2014年煤炭建设行业先进QC小组（见附件二），同时评选出中煤矿山建设集团有限责任公司等8家企业为2014年煤炭建设行业QC小组活动优秀企业（见附件三），现予以公布。

请各单位参照有关规定，继续积极推进企业QC小组活动，对优秀、先进QC小组及有关个人予以表彰和奖励，为提高煤炭建设工程质量和企业管理水平做出积极贡献。

中国煤炭建设协会将对获得2014年煤炭建设行业优秀QC小组、先进QC小组、QC小组活动优秀企业等分别颁发证书。

附件：

一、2014年煤炭建设行业优秀QC小组名单（33个）

二、2014年煤炭建设行业先进QC小组名单（47个）

三、2014年煤炭建设行业QC小组活动优秀企业名单（8家）
