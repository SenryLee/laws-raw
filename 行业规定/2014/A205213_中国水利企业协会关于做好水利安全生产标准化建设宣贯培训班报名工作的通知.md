# 中国水利企业协会关于做好水利安全生产标准化建设宣贯培训班报名工作的通知

## 中国水利企业协会关于做好水利安全生产标准化建设宣贯培训班报名工作的通知（中水企〔2014〕6号）

部直属有关单位，各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局，各有关单位：

为全面推进水利安全生产标准化评审工作，经水利部人事司备案同意，受安监司委托，中国水利企业协会拟在全国范围举办6期水利安全生产标准化建设宣贯培训班。现将具体事项通知如下：

**一、**培训对象

（一）水利生产经营单位（主要包括水利工程项目法人、水利水电施工企业、水利工程管理单位）的主要负责人、分管安全负责人以及安全生产管理工作人员；

（二）从事水利安全生产标准化咨询、管理和监督等工作的人员。

**二、**培训内容

（一）水利生产经营单位主要负责人法律风险专题讲座；

（二）《水利安全生产标准化评审管理暂行办法》、《实施细则》以及安全生产标准化建设概况与政策解读；

（三）《水利工程项目法人安全生产标准化评审标准（试行）》；

（四）《水利水电施工企业安全生产标准化评审标准（试行）》；

（五）《水利工程管理单位安全生产标准化评审标准（试行）》。

**三、**培训地点和时间

培训班按照评审类别进行，自愿参加，具体地点和时间另行通知。初步安排见附件1，学员可自行选择。每期培训班时间为6天（含报到和返程）。

**四、**培训收费和培训教材

（一）培训期间，食宿统一安排，培训费用每人每天450元，合计2700元/人（含食宿、培训、场地、资料等全部费用）。

（二）培训教材选用《水利安全生产标准化建设实施指南》、《水利水电施工企业安全生产标准化评审标准释义》、《水利工程管理单位安全生产标准化评审标准释义》〉和《水利工程项目法人安全生产标准化评审标准释义》等。

**五、**其他事项

（一）培训学习成果统一发《水利部培训登记证明》。

（二）请各单位统一填写报名回执表（见附件2）以传真或电子邮箱的形式发至中国水利企业协会。
