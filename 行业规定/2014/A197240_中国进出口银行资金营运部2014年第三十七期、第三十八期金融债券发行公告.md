# 中国进出口银行资金营运部2014年第三十七期、第三十八期金融债券发行公告

2014年度中国进出口银行金融债券承销团成员，柜台债券承办银行：

根据《中国人民银行关于下达2014年中国进出口银行人民币贷款计划及金融债券发行计划的通知》（银发〔2014〕51号）和《中国进出口银行与中国工商银行股份有限公司2014年商业银行柜台人民币金融债券分销协议》，我行定于2014年6月16日通过中国人民银行债券发行系统，招标发行2014年第三十七期和第三十八期金融债券。

中国工商银行（以下简称“工商银行”）是本次两期商业银行柜台人民币金融债券承办银行，首场招标结束后，我行将按首场中标结果向工商银行追加发行一定额度债券，由工商银行在柜台债券市场向个人和非金融机构投资者进行分销。

**一、**第三十七期金融债券（附息）

第三十七期债券（附息）为2年期固定利率附息债券，首场发行金额不超过60亿元（不含商业银行柜台分销额度），票面利率通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。首场招标结束后，我行将向工商银行追加发行总量不超过15亿元当期债券，由工商银行在柜台债券市场向个人和非金融机构投资者进行分销。

**二、**第三十八期金融债券（贴现）

第三十八期债券（贴现）为1年期贴现债券，首场发行金额不超过60亿元（不含商业银行柜台分销额度），发行价格通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。首场招标结束后，我行将向工商银行追加发行总量不超过15亿元当期债券，由工商银行在柜台债券市场向个人和非金融机构投资者进行分销。

发行办法详见中国债券信息网http：//www.chinabond.com.cn或中国货币网http：//www.chinamoney.com.cn。柜台债发行请详见中国进出口银行网站http：//www.eximbank.gov.cn和工商银行网站http：//www.icbc.com.cn。
