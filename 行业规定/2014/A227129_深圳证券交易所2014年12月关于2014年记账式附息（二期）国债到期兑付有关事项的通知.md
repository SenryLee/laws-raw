# 深圳证券交易所2014年12月关于2014年记账式附息（二期）国债到期兑付有关事项的通知

各会员单位：

2014年记账式附息（二期）国债将于2015年1月9日到期兑付。为做好本期债券的本息兑付工作，现将有关事项通知如下：

一、本期债券证券代码为“101402”，证券简称为“国债1402”，是2014年1月9日发行的1年期债券，票面利率为4.04%，每年支付1次利息，每百元面值债券兑付可获本息104.04元。

二、本所从2014年12月30日起停办本期债券的转托管及调帐业务。

三、本期债券兑付债权登记日为2015年1月6日，凡于当日收市后持有本期债券的投资者，享有获得本次兑付款项的权利。2015年1月7日本期债券摘牌。

四、中国证券登记结算有限责任公司深圳分公司在收到财政部拨付的本期债券兑付款项后，将其划入各证券商的清算备付金帐户，并由证券商将兑付资金及时划入各投资者的资金帐户。

深圳证券交易所

二○一四年十二月二十九日
