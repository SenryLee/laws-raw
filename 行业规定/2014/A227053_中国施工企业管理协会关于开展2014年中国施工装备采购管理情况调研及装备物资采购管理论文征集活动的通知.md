# 中国施工企业管理协会关于开展2014年中国施工装备采购管理情况调研及装备物资采购管理论文征集活动的通知

中施企协字〔2014〕59号

各关联协会、会员企业、相关单位：

管理创新是企业做大做强、可持续发展的重要基石，也是科学管理、节能增效的有效途径。为总结宣传各单位的成功经验和好的做法，并经协会平台及时分享，以便于互相学习，互利共赢，普遍提高施工企业工程设备的采购管理水平，探索工程设备采购管理的新思路、新模式，为施工企业工程设备的选型、采购、验收、管理、租赁等提供科学依据和有益借鉴，进一步促进设备物资管理的规范化、科学化、系统化，中国施工企业管理协会决定组织开展“2014年中国施工装备采购管理情况有奖调查”及“装备物资采购管理论文征集”活动。现将有关事项通知如下：

一、调研内容

主要针对施工企业工程装备的采购及管理模式、租赁模式、采购计划、闲置设备处置情况、以及对设备生产企业的意见建议等方面进行全面调研。

二、调研方式

本次调研采用网上填写问卷的方式进行，参与人员可登陆协会官网“调研专题”页面（http://www.cacem.com.cn/survey/2014/dc.php）在线填写，或通过发送邮件、传真、邮寄等方式参与。

为鼓励企业积极参与，此次活动采取有奖调查的方式进行，活动说明及调查问卷见附件。

三、论文征集

为了积极探索施工装备物资采购和管理的新模式、新方法、新规律，逐步实施装备物资专业化采购、科学规范管理及合理配置，特征集“装备物资采购管理”方面的论文，对入选的优秀论文进行免费宣传和推广，论文参考主题及征集活动说明见附件。

四、参与对象

施工企业分管设备物资采购管理的高层领导、部门负责人及项目经理等；关联协会分管领导和行业专家；设备物资生产流通企业高层领导及部门负责人。

五、活动时间

活动自2014年12月20日至2015年3月1日止，调查结果及调查报告将在2015年4月23日-24日举办的“施工企业设备物资采购管理模式创新实务交流研讨会”上进行发布。

六、联系方式

本次活动由中施企协（北京）咨询顾问有限公司承办，望各关联协会、会员企业、行业专家及有关单位积极参与。
