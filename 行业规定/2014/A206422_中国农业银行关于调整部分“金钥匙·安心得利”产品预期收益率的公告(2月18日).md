# 中国农业银行关于调整部分“金钥匙·安心得利”产品预期收益率的公告(2月18日)

## 中国农业银行关于调整部分“金钥匙·安心得利”产品预期收益率的公告（2月18日）

尊敬的投资者：

根据市场及投资运作情况，按照产品说明书相关约定“产品开放期及收益率发生变动时，在中国农业银行网站和中国农业银行网点发布相关信息公告”，中国农业银行对“金钥匙·安心得利·34天”人民币理财产品，中国农业银行对“金钥匙·安心得利·90天”人民币理财产品及中国农业银行对“金钥匙·安心得利·181天”人民币理财产品，具体调整方案见表1。

表1：收益率调整情况

|  |  |  |
| --- | --- | --- |
| 产品系列 | 调整前 | 调整后 |
| “金钥匙·安心得利·34天”人民币理财产品 | 5.15% | 5.00% |
| “金钥匙·安心得利·90天”人民币理财产品 | 5.50% | 5.20% |
| “金钥匙·安心得利·181天”人民币理财产品 | 5.55% | 5.40% |

调整说明：

新收益率于2014年2月18日（含）生效，即2月18日及以后的申购均采用新收益率，2月18日及以前已起息的申购不涉及调整，将维持原收益率至相应到期日。

特此公告。

中国农业银行
