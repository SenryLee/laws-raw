# 中国农业银行关于开放式人民币理财产品2014年春节假期开放期及清算日的公告

尊敬的投资者：

根据国务院办公厅假日安排，2014年1月26日（星期日）为工作日、1月31日（星期五）至2月6日（星期四）为法定节假日、2月8日（星期六）为工作日。相应的，我行对开放式人民币理财产品的开放期及清算日调整如下：

2014年1月26日、2月8日开放申购（部分已停止申购的产品除外）和赎回，1月31日至2月6日暂停申购和赎回，从2月10日起恢复正常。

特此公告。

中国农业银行

二○一四年一月二十六日
