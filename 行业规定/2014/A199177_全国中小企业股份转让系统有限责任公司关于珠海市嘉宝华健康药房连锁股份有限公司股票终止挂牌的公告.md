# 全国中小企业股份转让系统有限责任公司关于珠海市嘉宝华健康药房连锁股份有限公司股票终止挂牌的公告

## 全国中小企业股份转让系统有限责任公司关于珠海市嘉宝华健康药房连锁股份有限公司股票终止挂牌的公告（股转系统公告〔2014〕92号）

近期，珠海市嘉宝华健康药房连锁股份有限公司（证券简称：嘉宝华；证券代码：430679）由于与战略投资方实施并购整合的需要，经该公司股东大会审议，通过了申请终止其股票在全国中小企业股份转让系统挂牌的决议。目前，嘉宝华已就上述事项履行了相应程序，进行了信息披露，并向我司提交了股票终止挂牌的申请。根据《全国中小企业股份转让系统业务规则（试行）》的规定，我司现决定自2014年9月5日起终止其股票挂牌。

特此公告。

全国中小企业股份转让系统有限责任公司

2014年9月2日
