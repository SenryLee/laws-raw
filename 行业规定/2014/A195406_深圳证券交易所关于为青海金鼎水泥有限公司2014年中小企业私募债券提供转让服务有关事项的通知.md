# 深圳证券交易所关于为青海金鼎水泥有限公司2014年中小企业私募债券提供转让服务有关事项的通知

各会员单位：

青海金鼎水泥有限公司2014年中小企业私募债券定于2014年11月11日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

青海金鼎水泥有限公司2014年中小企业私募债券证券代码“118266”，证券简称“14金鼎债”，发行总额23，400万元，票面利率11.5%，债券期限3年，附第2年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一四年十一月七日
