# 中国注册会计师协会关于申报2014年会计师事务所信息化建设奖励的通知

## 中国注册会计师协会关于申报2014年会计师事务所信息化建设奖励的通知（会协[2014]50号）

各省、自治区、直辖市注册会计师协会：

根据《会计师事务所信息化建设奖励办法》，2014年会计师事务所信息化建设奖励申报时间为2014年9月15日至10月15日，请各地注协组织符合条件的会计师事务所进行申报。

中注协联系人：信息技术部　王廷梁，电话：010-88250303，tlwang@cicpa.org.cn 。

中国注册会计师协会
