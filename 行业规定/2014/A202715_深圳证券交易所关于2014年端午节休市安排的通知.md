# 深圳证券交易所关于2014年端午节休市安排的通知

各会员单位：

根据《关于2014年节假日休市安排的通知》（深证会〔2013〕157号），现将2014年端午节休市有关安排通知如下：

**一、**休市安排：5月31日（星期六）至6月2日（星期一）为节假日休市，6月3日（星期二）起照常开市。

**二、**节假日期间清算交收事宜按照中国证券登记结算有限责任公司的安排进行。

请各会员单位据此安排好有关工作。

深圳证券交易所

2014年5月23日
