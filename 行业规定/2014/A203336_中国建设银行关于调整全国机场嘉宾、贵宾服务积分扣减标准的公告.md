# 中国建设银行关于调整全国机场嘉宾、贵宾服务积分扣减标准的公告

因各地机场改造，服务价格普遍上涨，服务成本不断增长，为保证机场嘉宾和贵宾服务品质，自2014年6月1日起，建设银行将统一上调机场嘉宾服务和贵宾服务的积分扣减标准。为避免积分调整影响您的出行体验，请登录www.ccb.com网站或联系您的客户经理了解详情。

感谢您对建设银行长期以来的支持和关注，愿我们共同携手，以心相交、成其久远！

中国建设银行

2014年5月9日
