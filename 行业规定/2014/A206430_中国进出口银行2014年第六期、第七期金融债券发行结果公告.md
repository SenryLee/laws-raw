# 中国进出口银行2014年第六期、第七期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年2月13日经过承销团竞标，发行了2014年第六期、第七金融债券。第六期债券为我行2014年第二期金融债的增发债券，发行额60亿元，期限3年，中标价格100.48元，参考收益率为5.3047%，债券缴款日为2014年2月18日。第七期债券为我行2014年第三期金融债的增发债券， 发行额60亿元，期限5年，中标价格100.52元，参考收益率为5.4333%，债券缴款日为2014年2月19日。欢迎境内商业银行、保险公司、农村信用合作联社和其他银行间债券市场成员积极参与债券分销。以上两期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通。
