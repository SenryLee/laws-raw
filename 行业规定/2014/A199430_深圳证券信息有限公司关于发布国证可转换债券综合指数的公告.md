# 深圳证券信息有限公司关于发布国证可转换债券综合指数的公告

为刻画沪深交易所可转债市场的总体运行特征，进一步丰富和完善国证指数体系，推动指数化投资的不断发展与创新，深圳证券信息有限公司于2014年8月27日发布国证可转换债券综合指数，指数代码和名称如下：

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 指数代码 | 指数名称 | 指数简称 | 基日 | 基日点位 |
| 399413 | 国证可转换债券综合指数 | 国证转债 | 2011年12月31日 | 100 |

国证可转换债券综合指数以在深圳证券交易所和上海证券交易所上市的可转换公司债券为样本空间，选取面值余额不小于3千万元的债券组成指数样本。指数采用债券发行量加权计算，每月的第一个交易日实施样本调整。

国证可转换债券综合指数通过深交所行情系统发布实时行情数据。指数编制方案及最新样本股名单参见巨潮指数网（http：//www.cnindex.com.cn）。

特此公告。
