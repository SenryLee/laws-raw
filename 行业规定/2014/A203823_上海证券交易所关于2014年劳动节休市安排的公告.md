# 上海证券交易所关于2014年劳动节休市安排的公告

## 上海证券交易所关于2014年劳动节休市安排的公告（上证公告〔2014〕6号）

根据《关于上海证券交易所2014年全年休市安排的通知》（上证函〔2013〕269号），现将2014年劳动节休市有关安排通知如下：5月1日（星期四）至5月3日（星期六）休市，5月5日（星期一）起照常开市。另外，5月4日（星期日）为周末休市。

请各会员单位据此安排好有关工作。

上海证券交易所

二○一四年四月二十四日
