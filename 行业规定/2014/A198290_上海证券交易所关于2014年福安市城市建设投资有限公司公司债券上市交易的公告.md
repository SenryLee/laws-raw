# 上海证券交易所关于2014年福安市城市建设投资有限公司公司债券上市交易的公告

## 上海证券交易所关于2014年福安市城市建设投资有限公司公司债券上市交易的公告（上证公告（债券）〔2014〕491号）

福安市城市建设投资有限公司发行的2014年福安市城市建设投资有限公司公司债券，将于2014年10月8日起在上海证券交易所交易市场竞价系统和固定收益证券综合电子平台上市交易。该债券证券简称为“14安城投”，证券代码为“124919”。

上海证券交易所

二〇一四年九月三十日
