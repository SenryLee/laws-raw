# 中国总会计师协会关于2014年暑期举办“教育系统行政及事业单位财政改革最新政策全面解析及会计实务操作培训班”的通知

## 中国总会计师协会关于2014年暑期举办“教育系统行政及事业单位财政改革最新政策全面解析及会计实务操作培训班”的通知（中总协〔2014〕17号）

各地方总会计师协会（研究会），各分会，各会员单位；高等院校，各教育主管等有关单位：

2013年12月财政部印发了《中小学校会计制度》、《高等学校会计制度》， 2014年1月又相继印发《新旧高等学校会计制度有关衔接问题的处理规定》和《新旧中小学校会计制度有关衔接问题的处理规定》，新制度及规定的实施时间都是自2014年1月1日起施行。这也是财政部及教育部继2012年连续发布《事业单位财务规则》、《事业单位会计准则》、《行政事业单位内部控制规范（试行）》、《事业单位会计制度》、《高等学校财务制度》和《中小学校财务制度》等系列相关政策后的又一重要制度。为学习贯彻和全面落实财政改革中新制度的各项要求，提升教育系统会计人员服务质量和管理水平，中国总会计师协会决定在2014年暑期举办“教育系统行政及事业单位财政改革最新政策全面解析及会计实务操作培训班”。现将工作安排予以印发。

请各单位接到《通知》后，积极组织并做好参训人员的报名工作。
