# 中国电力企业联合会关于召开2014年度电力行业信用体系建设工作会议的通知

中电联科技（2014）270号

各有关单位：

为贯彻落实国家《社会信用体系建设规划纲要（2014—2020年）》精神，发布电力行业2014年度信用企业等级和《电力行业信用体系建设指导意见（2015-2020年）》，经研究决定召开2014年度电力行业信用体系建设工作会议，现将有关事项通知如下：

一、会议时间及地点：

（一）会议时间：2015年1月21日，20日报到。

（二）会议地点：中国电力投资集团公司高级培训中心(上海闵行区剑川路665号, 021-64357750)

二、会议内容

（一）介绍电力行业信用体系建设情况。

（二）发布2014年度电力行业信用企业等级。

（三）发布《电力行业信用体系建设指导意见（2015-2020年）》。

（四）会议邀请国家有关部委、各电力集团公司的领导和专家到会发言。

（五）信用企业交流经验。

三、参会人员

2014年度信用企业、地方电力行业协会负责人、其他单位代表。

四、其他事项

（一）本次会议的会务费为800元/人，食宿统一安排，费用自理。

（二）请年度行业信用企业务必派代表参加会议，确保标牌、证书能够及时领取。

（三）请参会代表于2015年1月16日前将会议回执(见附件1)发传真或电子邮件至联系人处，以便妥善安排会务事宜。
