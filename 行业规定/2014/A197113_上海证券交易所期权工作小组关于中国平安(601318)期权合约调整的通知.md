# 上海证券交易所期权工作小组关于中国平安(601318)期权合约调整的通知

## 上海证券交易所期权工作小组关于中国平安（601318）期权合约调整的通知

根据上市公司公告，中国平安（601318）将于2014年6月27日除权除息。根据《上海证券交易所期权全真模拟交易规则》，本所将于2014年6月27日对所有以该证券为标的的期权合约进行调整，调整信息如下：

原有合约单位由每张1000股调整为1011股。

原有行权价调整如下表：

|  |  |  |
| --- | --- | --- |
| 序号 | 原行权价 | 调整后行权价 |
| 1 | 30.00 | 29.67 |
| 2 | 32.50 | 32.15 |
| 3 | 35.00 | 34.62 |
| 4 | 37.50 | 37.09 |
| 5 | 40.00 | 39.56 |
| 6 | 42.50 | 42.04 |
| 7 | 45.00 | 44.51 |
| 8 | 47.50 | 46.98 |

调整同日将新挂相关月份的标准化合约。

请投资者注意投资风险，备兑开仓持仓者请在除权除息日补足备兑证券。

上海证券交易所期权工作小组

2014年6月26日
