# 中国证券登记结算有限责任公司关于统一账户平台上线安排的通知

各开户代理机构：

根据证券账户整合工作计划，中国结算统一账户平台将于十一期间上线。自10月1日起，中国结算沪、深分公司现有账户业务系统将停止对外服务。现将有关业务和技术安排通知如下。

**一、**关于统一账户平台上线安排

统一账户平台将分为两个阶段切换上线：

第一阶段为十一国庆长假期间，10月1日-2日，统一账户平台完成中国结算沪、深分公司存量账户数据迁移以及系统上线。10月6日将组织全市场进行通关测试。自10月8日起，进入统一账户平台上线过渡期，账户类数据将由统一账户平台生成，开户代理机构仍使用沪、深市场现有数据接口申报账户业务。

第二阶段，自今年11月份起，中国结算将组织开户代理机构分批完成统一账户平台新数据接口切换。为配合第二阶段切换，中国结算计划从10月份起组织开展统一账户平台新数据接口的仿真测试及全网测试。

为做好上述两个阶段的上线切换，请开户代理机构配合做好以下事项：

（1）在9月29日前，对通过沪市PROP远程电子化方式和深市开户代理机构网上管理系统申报的业务进行清理，终止无法办理的业务。

（2）请配合做好10月6日的通关测试（方案详见附件2）。

（3）请各开户代理机构在通关测试过程中通过新版开户代理机构网站系统逐项核实开户代理机构及网点信息，包括机构的名称、权限和代码，网点名称和代码（统一账户平台代码、原沪深网点代码）等关键信息，并向我公司报送信息核实确认书（见通关测试方案的附件二）。如核查中有不准确的项目，需及时与中国结算联系进行更正（联系人：张洋 010-50938731；吴越 010-50938667），否则将影响开户代理机构或网点正常办理证券账户业务。网点权限在统一账户平台系统初始化阶段按机构权限设置，开户代理机构可在统一账户平台上线后，结合自身管理的实际情况，对网点的权限进行设置。

（4）过渡期内，已有开户代理机构通过沪市原接口报送账户业务无需再申请开通PROP权限，但须确认网络已开放对上海分公司PROP服务器30021、30040-30045以及30072端口的访问。

（5）请配合做好10月下旬陆续开始的统一账户平台新数据接口仿真测试和全网测试， 具体测试及上线安排将另行通知。

**二、**关于账户业务安排

1、9月30日15：00至10月8日9：00的节假日期间，中国结算暂停受理账户业务申请。

2、9月30日15：00以前的开户费仍按照现有收费渠道及收费标准由中国结算沪、深分公司收取；自10月8日起，执行新的账户业务收费标准及收费渠道，具体详见中国结算前期发布的《关于调整开户费收取渠道有关问题的通知》及《证券账户业务指南》。

3、9月29日、30日，中国结算沪、深分公司暂停受理开户代理机构及其网点的新增、变更及终止业务。

4、自10月8日起，开户代理机构及其网点的新增、变更、终止有关业务以及证券账户冒开业务报送至中国结算总部账户管理部办理，开户代理机构可通过开户代理机构网站系统（中国结算网页-＞网上业务平台-＞开户代理机构业务-＞点击登入）办理开户代理机构及其网点的新增、变更、终止有关业务；原深市开户代理机构网上管理系统不再受理相关业务申请，但仍可登陆（中国结算网页-＞网上业务平台-＞开户代理机构业务-＞点击旧版登入）查询深市开户代理机构及其网点业务的历史记录。统一账户平台上线过渡期内，开户代理机构如新增或变更开户代理机构或网点，需同时提供沪、深市场原有开户代理机构及网点代码，以及新上线的开户代理机构管理系统启用的新开户代理机构及网点代码。

5、开户代理机构9月30日之前通过邮寄方式（以我公司收到时点为准）报送中国结算办理的证券账户关键信息双改、不合格账户解除限制业务依据修订前的现行账户业务有关规则办理；开户代理机构9月29日之前通过PROP远程电子化方式报送中国结算办理的账户关键信息双改、证券账户冒开、特殊法人机构开户业务依据修订前的现行账户业务有关规则办理，具体日期以系统记录为准。在9月30日之前未办结的，通过电话、传真等方式另行通知处理结果。自9月30日起，暂停通过PROP远程电子化方式受理上述三项账户业务。

6、自10月8日起，证券账户关键信息双改、不合格账户解除限制业务，以及统一账户平台上线过渡期内发生的风险处置休眠账户激活、账户解除挂失业务可寄送中国结算京、沪、深任意一地分公司通柜办理，原沪、深市场开户专用章可不分市场通用。

7、统一账户平台上线过渡期账户业务其他安排详见中国结算前期发布的《关于统一账户平台上线过渡期证券账户业务安排的通知》。

请各开户代理机构高度重视，认真配合做好统一账户平台上线的各项准备工作，并提前妥善做好可能出现的业务异常应急处置安排，确保账户业务平稳有序运行。如遇突发状况，请及时与中国结算联系。
