# 深圳证券交易所2014年12月关于为徐州申鑫建材市场管理有限公司2014年中小企业私募债券提供转让服务有关事项的通知

各会员单位：

徐州申鑫建材市场管理有限公司2014年中小企业私募债券定于2014年12月24日起在本所综合协议交易平台进行转让，现将有关事项通知如下：

徐州申鑫建材市场管理有限公司2014年中小企业私募债券证券代码“118289”，证券简称“14申鑫债”，发行总额8,000万元，票面利率10%，债券期限3年，附第1年末发行人上调票面利率选择权和投资者回售选择权及第2年末发行人上调票面利率选择权和投资者回售选择权。

深圳证券交易所

二○一四年十二月二十二日
