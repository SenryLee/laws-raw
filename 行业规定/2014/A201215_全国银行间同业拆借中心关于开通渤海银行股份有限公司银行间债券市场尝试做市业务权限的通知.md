# 全国银行间同业拆借中心关于开通渤海银行股份有限公司银行间债券市场尝试做市业务权限的通知

渤海银行股份有限公司：

你机构关于申请开通银行间债券市场尝试做市业务权限的材料收悉。

经审核通过，现为你机构开通尝试做市业务权限。请你机构按照《银行间债券市场尝试做市业务规程》，履行尝试做市义务，积极进行双边报价及请求回复。

特此通知。

全国银行间同业拆借中心

2014年6月24日
