# 2014年第五十五期和第五十六期金融债券发行结果公告

经中国人民银行批准，中国进出口银行于2014年8月29日经过承销团竞标，发行了2014年第五十五期和第五十六期金融债券。第五十五期债券为我行2014年第二十七期金融债的增发债券，发行金额60亿元，期限1年，中标价格为101.82元，参考收益率为4.2895%，债券缴款日为2014年9月2日。第五十六期债券为我行2014年第五十期金融债的增发债券，发行金额60亿元，期限7年，中标价格为100.979元，参考收益率为4.9595%，债券缴款日为2014年9月2日。欢迎境内商业银行、保险公司、农村信用合作联社和其他银行间债券市场成员积极参与债券分销。以上2期债券在缴款日后进行债权债务登记，并按规定在全国银行间债券市场上市流通。
