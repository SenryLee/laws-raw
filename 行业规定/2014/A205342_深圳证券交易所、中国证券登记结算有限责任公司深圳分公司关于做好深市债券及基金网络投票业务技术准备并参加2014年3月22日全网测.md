# 深圳证券交易所、中国证券登记结算有限责任公司深圳分公司关于做好深市债券及基金网络投票业务技术准备并参加2014年3月22日全网测试的通知

各会员及相关单位：

深市基金网络投票业务使用的投票代码区间为【369001， 369499】，深市债券等固定收益类证券网络投票业务使用的投票代码区间为【369501， 369899】，在各区间内顺序编码，可循环使用；在特定情形下，网络投票所对应的基础证券可能已从证券信息库SJSXX.DBF、新证券信息库SJSXXN.DBF摘牌。债券及基金网络投票业务的其他相关事宜均参照《深圳证券交易所上市公司股东大会网络投票实施细则（2014年修订）》执行。

为了确保深市债券及基金网络投票业务的顺利开展，请各会员及相关单位尽快完成相关业务的技术准备工作。深圳证券交易所（以下简称“深交所”）和中国证券登记结算有限责任公司深圳分公司（以下简称“中国结算深圳分公司”）定于2014年3月22日组织全网测试，主要通过模拟深市债券及基金网络投票等处理过程，检验市场参与各方技术系统的正确性。

测试当日，要求会员单位参加新通信灾备中心测试，具体事宜详见《配合新通信灾备中心启用进行用户小站配置修改通知》（该通知已通过单向卫星系统下发）。非上市公司股份转让市场（三板系统）使用原有生产系统。

请各会员单位协助模拟主板市场日常交易、非交易申报以及结算处理过程，非上市公司股份转让市场（三板系统）日常转让申报以及结算处理过程，检验相关系统的正确性。

现将相关测试事项通知如下：

**一、**本次测试的内容包括：

1.债券及基金网络投票。

2.主板市场日常交易、非交易的模拟测试。

3.非上市公司股份转让市场（三板系统）日常业务的模拟测试。

4.新通信灾备中心测试。

**二、**测试时间为2014年3月22日9：00至16：00，测试期间将模拟1个完整交易日的交易及1个结算日的结算业务。

**三、**请各会员及相关单位认真组织测试，按照《2014年3月22日深市债券及基金网络投票全网测试方案》（可在深交所网站www.szse.cn“技术专栏”页面查阅）等相关技术文档做好准备，落实专人负责本次测试工作。

**四、**各参测单位测试前务必做好系统环境和数据的备份工作。测试完成后，做好系统和数据的恢复工作，确保下一交易日（3月24日）的交易正常安全进行。

**五、**测试工作完成后，各会员单位应在2014年3月24日17：00之前登录本所“会员网上业务专区”首页“快速导航―在线调查表”栏目填写并提交测试反馈表（测试反馈表参见测试方案之附件）；非会员用户请将填报好的反馈表发送至sseyxb@szse.cn。

登录本所“会员网上业务专区”需使用专用电子认证证书（Ekey），具体方法可询问各自单位负责每月技术月报的填报人员或负责会籍席位业务的人员。

**六、**测试当日的所有数据仅为技术测试使用，不能作为任何交易、非交易及开户等业务的依据。请会员及相关单位做好向投资者的宣传提示工作。

**七、**测试当日，中国结算深圳分公司生产系统不提供实时开户服务。
