# 中国环境保护产业协会关于2014年国家重点环保实用技术及示范工程公示

中国环境保护产业协会组织了2014年国家重点环境保护实用技术及示范工程（第二批）的评审工作。经地方协会、专业委员会、行业协会推荐，专家评审及现场考察，共有20项技术列入2014年国家重点环境保护实用技术公示名录（第二批），25个项目列入国家重点环境保护实用技术示范工程公示名录（第二批），现予以公示7天。如有疑义，请在公示期内以书面材料与中国环境保护产业协会联系。
