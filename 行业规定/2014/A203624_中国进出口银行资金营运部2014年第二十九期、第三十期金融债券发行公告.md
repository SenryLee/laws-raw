# 中国进出口银行资金营运部2014年第二十九期、第三十期金融债券发行公告

2014年度中国进出口银行金融债券承销团成员：

根据《中国人民银行关于下达2014年中国进出口银行人民币贷款计划及金融债券发行计划的通知》（银发〔2014〕51号），我行定于2014年5月9日10：00-11：00通过中国人民银行债券发行系统，招标发行第二十九期、第三十期金融债券。

**一、**第二十九期金融债券（130322增发）

第二十九期债券为我行2013年第二十二期1年期固定利率金融债的增发债券，发行金额不超过70亿元，发行价格通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。

**二、**第三十期金融债券

第三十期债券为7年期固定利率金融债，发行金额不超过60亿元，票面利率通过中国进出口银行2014年全国银行间债券市场金融债券承销团竞标确定。

发行办法详见中国债券信息网http：//www.chinabond.com.cn或中国货币网http：//www.chinamoney.com.cn。
