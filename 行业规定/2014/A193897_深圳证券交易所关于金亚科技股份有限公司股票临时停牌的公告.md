# 深圳证券交易所关于金亚科技股份有限公司股票临时停牌的公告

公共传媒出现关于金亚科技股份有限公司的信息，可能对公司股票交易价格产生较大影响，根据本所《创业板股票上市规则》的有关规定，经公司申请，公司股票（证券简称：金亚科技，证券代码：300028）及其衍生品种（证券简称：12金亚01，证券代码：112185）于2014年9月26日开市起停牌，待公司通过指定媒体披露澄清公告后复牌，请投资者密切关注。

深圳证券交易所

2014年9月26日
