# 上海证券交易所关于2014年记账式附息(三期)国债上市交易的通知

## 上海证券交易所关于2014年记账式附息（三期）国债上市交易的通知

各市场参与人：

根据《财政部关于2014年记账式附息（三期）国债发行工作有关事宜的通知》（财库[2014]3号）和上海证券交易所（以下简称“本所”）有关规定，2014年记账式附息（三期）国债（以下简称“本期国债”）将于2014年1月22日在本所集中竞价系统和固定收益证券综合电子平台上市，现将有关事项通知如下。

**一、**本期国债为固定利率附息债，期限为7年，票面利率为4.44%，利息每年支付一次；本期国债起息日为2014年1月16日，每年1月16日（节假日顺延，下同）支付利息，2021年1月16日偿还本金并支付最后一次利息。

**二、**本期国债于2014年1月22日起在本所集中竞价系统和固定收益证券综合电子平台上市，交易方式为现券和回购。

**三、**本期国债上市交易的现券证券名称为“14国债03”，证券代码为“019403”，出入库代码为“091074”。

上海证券交易所

二〇一四年一月十五日
