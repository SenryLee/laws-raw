# 上海证券交易所期权工作小组关于期权合约限开仓演练的通知

为演练合约限开仓情形，在期权全真模拟交易环境做以下假定和限开仓相应操作：

1.假定2014年4月18日盘后检查中标的证券600104的2014年6月到期的认购合约达到了合约限开仓条件，即标的证券的相应到期月份的认购合约的未平仓合约（含备兑开仓）所对应的合约标的总股数达到了流通股数的30%以上，将在2014年4月21日对于标的证券600104的2014年6月到期的所有认购合约实施限开仓，但不限制备兑开仓。

具体限开仓的标的证券与到期月份信息如下：

限开仓日期：2014年04月21日

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 标的股票代码 | 标的股票简称 | 合约类型 | 到期月份 | 限开仓原因（＞30%或限开仓未解除） |
| 600104 | 上汽集团 | 认购 | 2014年6月 | ＞30% |

2.假定2014年4月21日盘后检查中标的证券600104的2014年6月到期的认购合约（含备兑开仓）所对应的合约标的总数占流通股数的比例不到30%，但仍在28%以上，不能解除合约限开仓，将在2014年4月22日对于标的证券600104的2014年6月到期的所有认购合约仍实施限开仓，但不限制备兑开仓。

具体限开仓的标的证券与到期月份信息如下：

限开仓日期：2014年04月22日

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 标的股票代码 | 标的股票简称 | 合约类型 | 到期月份 | 限开仓原因（＞30%或限开仓未解除） |
| 600104 | 上汽集团 | 认购 | 2014年6月 | 未到解除限开仓条件 |

3. 假定2014年4月22日盘后检查中标的证券600104的2014年6月到期的认购合约（含备兑开仓）所对应的合约标的总股数占流通股数的比例小于28%，需解除合约限开仓，将在2014年4月23日对于标的证券600104的2014年6月到期的所有认购合约解除限开仓。

请相关参与机构和投资者做好风险提示和风险管理工作，特此通知。

上海证券交易所期权工作小组

二〇一四年四月十八日
