# 中国铁路总公司、中国人民武装警察部队关于发布《铁路桥隧守护设施设计规定》的通知

## 中国铁路总公司、中国人民武装警察部队关于发布《铁路桥隧守护设施设计规定》的通知（2013年）

各铁路局，各铁路公司（筹备组），武警部队各总队：

现将《铁路桥隧守护设施设计规定》印发给你们，自2013年6月3日起施行。原铁道部、武警总部前发《铁路桥隧守护设施设计规定》（铁建函〔1998〕160号）同时废止。

铁路桥隧守护设施设计规定

## 第一章　总则

**第一条**　为保证铁路桥梁、隧道（简称桥隧）守护目标的安全，统一桥隧守护设施设计标准，根据《铁路法》和国务院、中央军委《关于印发＜中国人民武装警察部队内卫执勤任务范围规定＞的通知》（国发〔2012〕42号）制定本规定。

**第二条**　本规定适用于武警部队守护的国家铁路网中主要干线铁路重要位置上桥隧守护设施的设计。

**第三条**　铁路桥隧守护设施设计应符合因地制宜、节约用地、科学用兵、有利执勤、方便生活、确保安全等要求。

**第四条**　铁路桥隧守护设施包括营房建筑及配套的采暖通风、给水排水、供电照明、通信、现场监控等设施。

**第五条**　铁路桥隧守护设施建设、办公、生活用具及交通工具购置等费用，应纳入铁路工程项目建设投资。

**第六条**　铁路桥隧守护设施设计，除按本规定执行外，尚应符合国家现行有关标准的规定。

## 第二章　守护目标

**第七条**　主要干线铁路上重要位置的桥隧守护目标应符合下列规定：

1.横跨大江大河（湖、海），全长5000m以上的桥梁。

2.穿越主要山脉，长度15000m以上的陆地隧道及10000m以上越海（江、河、湖）隧道。

3.青藏铁路的重要桥梁、隧道。

4.其他需要守护的铁路，应考虑对重点桥梁、隧道进行守护，具体由有关部门评估后确定。

**第八条**　主要干线铁路、重要位置、大江大河、主要山脉等的范围应符合下列规定：

1.主要干线铁路：是指国家铁路网中I级铁路或旅客列车设计行车速度不小于120km/h的铁路。

2.重要位置：是指铁路桥隧一旦受到破坏，抢修困难的部位。

3.大江大河：是指松花江、海河、辽河、淮河、黄河、长江、珠江等七大水系。

4.主要山脉：是指大兴安岭、长白山、太行山、秦岭、昆仑山、祁连山等山脉。

## 第三章　营房建设标准

**第九条**　守护目标哨所设置应符合下列规定：

1.哨所应设在桥梁主桥和隧道的两端。

2.哨所要结构坚固，避风防雨，有良好的通视条件，外观应与周围环境协调一致，内部应备有执勤桌（台），偏僻哨所和其他有条件的哨所应在哨所周围安装护栏等防护设施。

3.桥隧两端应设置隔离护栏，有通风井的隧道应在通风井顶端设置封闭式护栏。

**第十条**　中队营区宜设在便于指挥和管理的守护目标处，方便哨兵上下岗及哨所与营区之间的相互瞭望，营区应设置围墙和通往哨所的通道。在执勤目标控制区域内应划定警戒线或设置警戒标志。

**第十一条**　大队部的设置可结合所管辖的中队营区综合考虑。

**第十二条**　应在营区便于指挥控制的位置设置勤务值班室。值班室要与各哨所、目标单位和重要部位的报警、监控设施沟通联络，值班室设置资料柜、桌椅等必要的办公用品。

**第十三条**　守护目标的哨所可按下列规定确定建筑面积：

1.设在守护目标两端的哨所，其建筑面积每处为10m2（两层建筑的底层面积另行计算）。

2.为便于执勤，可在适当位置设置待班间休室，建筑面积为40m2。

**第十四条**　守护房屋的建筑设计应根据守护用房的特点，并考虑必要的安全措施。

**第十五条**　中队部营房建筑面积应符合现行《武警内卫执勤部队营房建筑面积标准》和《武警基层中队“四配套”营房面积标准》，按下表配备。

中队部营房建筑面积和占地面积标准

|  |  |  |
| --- | --- | --- |
| 守护目标单位 | 建筑面积（m2〕 | 营区占地面积（亩） |
| 中队部 | 1320～1900 | 10～20 |

注：1.地形困难地区，可根据实际情况与武警部门协商后酌情减少营区占地面积。

2. 如有外设的驻守点，营房建筑面积一般按35 m2/人配备，其营区建筑面积和占地面积相应核减。

**第十六条**　大队部与中队部合设时，可在中队部营房建筑面积基础上增加660m2，增加占地面积10亩。

**第十七条**　中队营区应按单身宿舍标准设100m2的士官家属探亲用房，配备独立的卫生间。随军家属住房应按大队部5户，高原、边远地区中队部1～2户设置，每户建筑面积为54m2～72m2，配备独立的卫生间及厨房。

**第十八条**　附属房屋应符合下列规定：

1.越野车、客货两用车车库面积均为30m2。

2.给水排水、电力、采暖等辅助用房可根据具体情况，按国家有关标准规定配备。

## 第四章　附属设施建设标准

**第十九条**　通信设施设计标准应符合下列规定：

1.执勤哨所应安装电话单机、语音对讲系统，配备对讲机。哨所较多的执勤分队可以安装小型交换机。目标单位开设无线通信的，应在执勤部（分）队设立基地台，配备对讲机，实施联网通信。

2.守护电话配备标准为：哨所1台，每个守护目标一端的守护营区2台，中队部1～2台，大队部3台。同一守护目标的守护哨所，两端的守护营区、中队部之间均应设直通电话。必要时两通信站之间可设守护电话专用回线。

3.根据守护部队的特点，在守护中队与大队部（或上级部门）间有线通信难于保障时，可设置无线通信设备。

4.设游动哨的守护班、机动班各配备3台无线对讲机。

**第二十条**　报警设施分为哨所报警、营区报警。报警装置应配备干电池或蓄电池，便于停电时应急使用。报警设施设计标准应符合下列规定：

1.哨所报警：目标哨所应安装电铃或报警器，并与部队营区报警系统联网。

2.营区报警：执勤部队勤务值班室应安装电铃或报警显示器，能准确接收哨所、围墙报警器和目标单位发出的各种报警信号。

**第二十一条**　为确保目标和哨兵安全，应在哨所、勤务值班室和目标重要区、段安装电视监控设备，有条件时可利用铁路综合视频监控系统。

**第二十二条**　监控系统应对桥梁周围（桥两端、桥墩、维修梯等）、隧道两端及隧道内救援站等进行监视，并将监控图像接入中队（或大队）勤务值班室。

**第二十三条**　供电设施设计标准应符合下列规定：

1.桥隧守护设施应按二级负荷供电。

2.供电电源宜采用铁路电源。

**第二十四条**　照明系统包括哨所照明、警戒区照明和应急照明，照明系统设计标准应符合下列规定：

1.哨所照明：哨所内应安装照明灯，并在哨所周围适当位置配备照明设施。哨所应考虑探照灯接电条件。

2.警戒区照明：要按照既便于内部管理，又便于哨兵观察的原则，在制高点和警戒区重要地段安装照明设施。

3.守护目标及巡视通道应配备固定照明设施。守护目标及巡视通道照明应能在哨所就地控制，并应能在中队（或大队）勤务值班室集中控制。

4.应急照明：应在目标要害部位和哨所配置应急灯，保证停电后的照明。

**第二十五条**　营区给水排水工程设计标准应符合下列规定：

1.应充分利用所在地的既有给水排水设施。

2.生活用水量应符合《室外给水设计规范》（GB 50013）和《建筑给水排水设计规范》（GB 50015）等相关标准的规定。

3.生活饮用水水质应符合《生活饮用水卫生标准》（GB 5749）等相关标准的规定。当水质需要净化、淡化处理时，可选用便于管理和维修的简易设施；消毒处理宜选用紫外线、漂白粉（或漂白精）等简易材料；水处理设备不考虑备用。贮水设备容量不宜小于设计昼夜最大用水量。

4.污水排放应符合《污水综合排放标准》（GB 8978）等相关标准的规定及环保部门的要求。

**第二十六条**　营区暖通空调及卫生设备设计标准应符合下列规定：

1.根据当地气候特征，按现行国家及铁路行业标准配置暖通空调及卫生设备。

2.远离集中热源的哨所、驻守点宜采用电供暖。

3.应设置开水供应及生活热水供应设施。

## 第五章　其他设施

**第二十七条**　对执勤目标范围大，哨所距营区较远的部队，应根据守护任务需要配备自行车、电动车或汽车，满足哨兵上下哨和干部查勤需要。

**第二十八条**　为满足守护部队生活物资运输的需要，可按下列规定配备专用车辆：

1.中队部配轻型客货两用车、越野车各1辆。

2.大队部与中队部合设时增设越野车1辆。

**第二十九条**　根据守护部队兵力规模和执勤需要，为部队配备必要的办公用品、营具、炊具等，费用标准为：中队部25万元，大队部与中队部合设时增加15万元。

## 第六章　附则

**第三十条**　本规定由中国铁路总公司建设管理部和武警总部作战勤务部、基建营房部负责解释。

**第三十一条**　本规定自2013年6月3日起施行。
