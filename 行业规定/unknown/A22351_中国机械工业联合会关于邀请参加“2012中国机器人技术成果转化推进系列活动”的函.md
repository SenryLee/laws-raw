# 中国机械工业联合会关于邀请参加“2012中国机器人技术成果转化推进系列活动”的函

## 中国机械工业联合会关于邀请参加“2012中国机器人技术成果转化推进系列活动”的函（中机联展函[2012]34号）

各有关单位：

机器人是集多种学科为一体的高技术产业，是推动我国制造业产业升级换代、改善人民生活水平、适用于特殊工作环境的重要支撑技术，发展前景广阔。各大专院校和研究院所是我国机器人研究的主力军，经过20余年的技术沉淀，已经积累了一批技术水平高、适用性强、具有较高推广价值和产业化前景的技术和产品。

2009年中央政府提出发展七大战略性新兴产业，智能制造装备（含机器人）的产业化推进工作由此提上日程。工信部会同发改委、财政部，以编制智能制造装备产业发展规划为纲，通过实施“智能制造装备创新专项”来推动该产业的发展。

2010年下半年以来，中国机械工业联合会将发展智能制造装备作为机械工业转型升级的重要抓手，受国家工信部委托，中机联已经完成了“智能制造装备产业十二五发展规划”的编制工作，并将动员行业力量，群策群力，推动“智能制造装备创新专项”的实施，落实规划的具体工作部署。

机器人作为智能制造装备的重要组成部分，目前正处于产业发展的初期。为进一步摸清机器人技术和成果的现状，展示机器人产品和技术的发展，推动机器人产业化的进程，我会将针对大专院校、研究院所，举办2012中国机器人技术成果转化推进系列活动：

1、编辑2012年中国机器人技术成果汇编

2、2012中国机器人技术成果展暨成果洽谈对接会

活动具体安排见附件。

《2012年中国机器人技术成果汇编》实施细则

为落实智能制造装备产业十二五发展规划的各项工作部署，推进“智能制造装备创新专项”实施，促进我国机器人产业化发展的进程，我会现向国内大专院校和科研院所征集机器人技术、产品和专利的相关资料，编辑《2012年中国机器人技术成果汇编》，以形成机器人产业化推进工作的基础项目资源库。

**一、**征集对象和范围

征集范围：

国内大专院校和科研院所

征集对象：

工业机器人相关技术、产品和专利；

服务机器人的相关技术、产品和专利；

机器人成套技术、产品和专利；

机器人关键功能部件、关键技术和专利

**二、**征集条件

1、技术成果具有自主知识产权；

2、技术成果具有一定的产业转化条件

**三、**征集时间及方式

相关单位请填写《2012中国机器人技术成果征集表》，并于2012年4月30日前邮寄至中国机械工业联合会。

2012中国机器人技术成果展暨洽谈对接会实施细则

机器人是集多种学科为一体的高技术产业，是推动我国制造业产业升级换代、改善人民生活水平、适用于特殊工作环境的重要支撑技术，发展前景广阔。各大专院校和研究院所是我国机器人研究的主力军，经过20余年的技术沉淀，已经积累了一批技术水平高、适用性强、具有较高推广价值和产业化前景的技术和产品。为此，我会拟于2012年7月3-6日在“2012中国（上海）国际机器人展览会”期间，举办“2012中国机器人技术成果展洽谈对接会”，以进一步促进大专院校、研究院所的机器人成果向产业转移，推动我国机器人产业化进程。

**一、**组织架构

指导单位：

科学技术部高新技术发展及产业化司

工业和信息化部装备工业司

主办单位：

中国机械工业联合会

承办单位：

中国机械工业联合会、中机联华（北京）科技发展有限公司

**二、**活动时间、地点

2012年7月3-6日

上海·新国际博览中心

**三、**“2012中国机器人技术成果展及洽谈对接会”具体安排

1、展览规模

1000平方米

2、展示内容

大专院校和研究院所自有的机器人技术成果、专利、相关产品和项目，含工业机器人、服务机器人、仿生机器人、特种机器人等

3、活动形式

- 展览以实物、图片、影像等形式相结合的方式，展示近年来在机器人研究领域所取得的成果；

-　承办单位将设计标准特装展位供活动参与单位选择，标准特装展位分为3m×3m、3m×6m两种结构。

4、活动邀约对象

- 参展单位为从事机器人研究开发的国内大专院校和科研院所；

-　受众为国内机械工业骨干企业的高管、技术负责人和投资规划负责人。

5、活动流程

|  |  |
| --- | --- |
| 时间 | 工作安排 |
| 4月1日-4月30日 | 征集机器人技术和成果资料 　　邀请院校和院所参加本届活动 |
| 5月 | 编辑《2012年中国机器人技术成果汇编》 　　发布2012中国机器人技术成果展洽谈项目目录 |
| 6月 | 邀请机械行业骨干企业参与2012中国机器人技术成果展暨洽谈对接会，落实对接名单 |
| 7月3-6日 | 举行2012中国机器人技术成果展暨洽谈对接会 |

6、服务费用

本次活动费用为打包费用，按展位面积计价，标准如下

600元/平方米（含标准特装搭建费用、水电费、场地管理费等）

参展单位可获赠“2012中国机器人产业推进大会”代表名额
