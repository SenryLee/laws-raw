# 中国登山协会关于举办全国第八期高山技能培训班的通知

各地方登山协会、户外运动俱乐部、广大登山爱好者：

为更好地促进我国登山事业的发展，加强高山培训工作力度，提高登山者的安全意识同时满足广大登山爱好者的需求，中国登山协会定于2011年8月7日至8月20日在新疆博格达峰举办全国第八期高山技能培训班。

本次培训班旨在系统学习和掌握登山探险活动中的冰雪知识、技术操作并积累实践经验，培养和提高学员的登山安全和风险意识，并将所学到的知识技能运用到攀登4613峰的实际过程中，从而使知识和技能得到巩固和加强。

现将有关具体事宜通知如下：

**一、**培训时间及地点

培训时间：2011年8月7日－8月20日

培训地点：新疆博格达峰

**二、**报到时间及地点

报到时间：2011年8月6日，下午17：00前（星期六）

报到地点：新疆乌鲁木齐市（具体地点待报名确认后另行通知）

**三、**培训目标

了解高山环境及高山探险运动的常识和技能，具备基本的高山活动能力和安全技术操作能力。

**四、**课程价值

完成本次培训课程后，可获得以下收获：

1、了解高山环境特点及其危险识别；

2、掌握高山环保知识；

3、了解高海拔山峰攀登计划的制定；

4、了解高山病的有关知识，掌握常见高山病的预防和处理方法；

5、正确熟练使用高山装备和攀登绳结；

6、熟练掌握各种冰雪地形的保护与攀登技术；

7、熟练掌握冰川双人结组行进技术及冰雪地形的路线选择方法；

8、熟练掌握冰川裂缝自救与救援技术；

9、掌握高山营地选择、建设方法，具备营地生活管理能力；

10、掌握登山中架设路绳的方法；

11、攀登4613峰，实际运用所学的知识与技能；

**五、**培训对象

1、登山爱好者

2、有志从事高山探险的专业人员

**六、**报名时间及条件要求

报名时间：即日起至7月29日（请将报名表以电子邮件方式发到邮箱，符合报名条件者以递交日期先后顺序为准，额满为止）。

招生人数：16-20人

报名条件要求：

1、身体健康且年龄在18-55岁之间

2、基础技能培训合格者或持有中国登山协会培训证书者

3、具有一定高山经验和攀登基础者及获得过以往培训“优秀学员”称号者优先考虑

**七、**报名联系人及方式

联系人：赵玉燕

联系电话、传真：010-67141415

电子邮箱：cmainfo@126.com

**八、**相关费用

培训费：9800元/人

保险费：200元/人（可自理）

装备租用费：根据实际租用情况，详见附件2。

备注：培训费用包括培训费、活动费、山区环保与注册费、山区培训期间食宿费、乌鲁木齐市至训练场地的交通费、公用装备使用费、培训讲义费、证书工本费等；保险为登山专项保险，含意外伤害、医疗、救援、高原病、冻伤及猝死的保险费。

报名参加高山技能培训班的学员如符合以下条件之一者可享受培训费用8800元/人的优惠价：

1、在校应届本科大学生

2、参加过中国登山协会举办的攀冰培训班的学员

3、参加过中国登山协会举办的师资培训班并积极进行教学的户外教师

4、获得过中国登山协会举办的培训班“优秀学员”称号的学员

**九、**注意事项

1、参加本次培训的学员须身体健康，无心肺脑疾病、慢性病等以及其他不宜进行高海拔活动的障碍疾患（请咨询医生），本次培训活动海拔3500米-4600米

2、培训期间所需的个人装备学员须自备（部分可租用，详见附件2）

3、体能是进行登山活动的基础，希望欲参加培训的学员认真进行体能训练，以保证培训的顺利进行，并获得最大的培训收益

4、培训期间请遵守相关规定和尊重地方风俗习惯
