# 教育部办公厅、商务部办公厅关于举办“第二届中国大学生服务外包创新应用大赛”的通知

## 教育部办公厅、商务部办公厅关于举办“第二届中国大学生服务外包创新应用大赛”的通知（教高厅函[2011]34号）

有关省、直辖市教育厅（教委）、商务主管部门，有关部门（单位）教育司（局），教育部直属有关高等学校，各服务外包示范城市：

为深化落实《国务院办公厅关于鼓励服务外包产业加快发展的复函》（国办函〔2010〕69号）和《教育部 商务部关于加强服务外包人才培养工作若干意见》（教高〔2009〕5号）等文件精神，进一步创新和加快服务外包人才培养工作，教育部、商务部和无锡市人民政府在成功举办首届大赛的基础上，决定联合举办“第二届中国大学生服务外包创新应用大赛”（以下简称“大赛”）。现将有关事项通知如下：

**一、**大赛宗旨

搭建大学生服务外包创新应用能力展示平台，吸引更多人才关注服务外包产业；创新人才培养和人才评价体系，引导和促进高校加强服务外包人才培养；促进高校教育改革贴合新兴产业发展需求，为服务外包产业发展提供人才保障；提升社会对服务外包产业发展的关注度和重视度，为产业发展营造良好氛围；努力打造人才培养和产业发展互动融合、选才用才的典范。

**二、**大赛组织

大赛设组委会，组委会成员名单见附件1。

大赛委托无锡市商务局、无锡市教育局、清华大学国家服务外包人力资源研究院、江南大学承办。

**三、**参赛对象

下列范围高校（含示范性软件学院）自愿组建参赛队伍参加比赛：全国21个服务外包示范城市所在地全日制普通高校；国家示范性软件学院；浙江、江苏两省开展了服务外包专业试点工作的全日制普通高校。

参赛队员为在校本科生或研究生（含2011年应届毕业生）。以高校为单位报名，每校限1个参赛队，每队队员原则上不超过5人（其中本科生不少于3人，可增设指导老师1名）。

**四、**报名及大赛安排

（一）本次大赛通过网络报名，请参赛高校于2011年5月23日至6月5日，登录本届大赛专门网站http：//www.fwwb.org.cn/，按要求报名。

请参赛高校于2011年6月15日前将参加“第二届中国大学生服务外包创新应用大赛学校联系人信息表”发送至大赛组委会专门邮箱：fwwb20090909@163.com。（表格样式见附件2）

（二）大赛组委会将另行发布“第二届中国大学生服务外包创新应用大赛参赛指南”，有关详细安排见该参赛指南。

（三）本次大赛参赛团队成员的交通费由所在学校承担，在无锡参赛期间的食宿及费用由大赛秘书处负责。
