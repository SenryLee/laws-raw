# 国家海洋局北京教育培训中心关于举办2011年度海域使用论证业务培训班的通知

海域使用论证资质单位及有关单位：

为提高海域使用论证从业人员的业务水平，保证海域使用论证工作质量，根据海域使用论证工作安排，国家海洋局北京教育培训中心近期将在北京举办海域使用论证业务培训班，现将有关事项通知如下：

**一、**培训班次

|  |  |  |  |
| --- | --- | --- | --- |
| 班次 | 计划报到时间 | 计划培训时间 | 计划考试  时间 |
| 第一期海域使用论证业务培训班（高级班） | 11月28日 | 11月29-12月1日 | 12月2日 |
| 第二期海域使用论证业务培训班（初级班） | 12月5日 | 12月6-9日 | 12月10日 |
| 第三期海域使用论证业务培训班（高级班） | 12月12日 | 12月13-15日 | 12月16日 |

每期计划安排3个班，每班150人左右。

**二、**报名条件

参加海域使用论证业务培训考试的技术人员，应具备大专以上学历，2年以上相关工作经验。各单位根据海域使用论证工作需要，安排有关人员报名，其中：过去未参加论证业务培训班的技术人员，报名参加初级班；持有2008年以前颁发的岗位证书但需要重新培训的技术人员，报名参加高级班。

**三、**相关要求

1、本年度培训班采取网上报名的方式（http：//221.239.0.129：8080/px2011/Enrollment.asp），报名系统将于11月17日18：00开通，每期班报名人数额满即止。网上报名截止日期为11月23日16：30。

2、海域使用论证资质单位及相关单位应对报名信息进行确认，填写海域使用论证培训班报名确认表（见附件），加盖公章后于11月24、25日9：00-16：30传真至我中心（010-62492535）。

3、报名确认后，学员不得更改所报班次。

4、每期培训具体时间和地点，另行通知。
