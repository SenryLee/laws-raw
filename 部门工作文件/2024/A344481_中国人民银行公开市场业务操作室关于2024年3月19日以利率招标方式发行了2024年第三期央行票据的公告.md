# 中国人民银行公开市场业务操作室关于2024年3月19日以利率招标方式发行了2024年第三期央行票据的公告

## 公开市场业务交易公告

〔2024〕第55号

人民银行于本周二（3月19日）通过香港金融管理局债务工具中央结算系统（CMU）债券投标平台，以利率招标方式发行了2024年第三期央行票据。具体情况如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 发行量  （人民币） | 期限 | 中标利率 |
| 2024年第三期央行票据（香港） | 250亿元 | 6个月  （182天） | 2.73% |

中国人民银行公开市场业务操作室

二〇二四年三月十九日
