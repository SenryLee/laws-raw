# 中国人民银行公开市场业务操作室关于2024年9月6日人民银行以固定利率、数量招标方式开展了1415亿元逆回购操作的公告

## 公开市场业务交易公告

〔2024〕第179号

为维护银行体系流动性合理充裕，2024年9月6日人民银行以固定利率、数量招标方式开展了1415亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 7天 | 1415亿元 | 1.70% |
