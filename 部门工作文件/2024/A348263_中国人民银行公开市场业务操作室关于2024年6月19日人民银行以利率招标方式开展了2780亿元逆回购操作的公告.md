# 中国人民银行公开市场业务操作室关于2024年6月19日人民银行以利率招标方式开展了2780亿元逆回购操作的公告

## 公开市场业务交易公告

〔2024〕第119号

为对冲税期等因素的影响，维护银行体系流动性合理充裕，2024年6月19日人民银行以利率招标方式开展了2780亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 2780亿元 | 1.80% |
