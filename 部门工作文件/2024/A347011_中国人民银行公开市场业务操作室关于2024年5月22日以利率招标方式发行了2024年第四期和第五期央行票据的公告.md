# 中国人民银行公开市场业务操作室关于2024年5月22日以利率招标方式发行了2024年第四期和第五期央行票据的公告

## 公开市场业务交易公告

〔2024〕第100号

人民银行于本周三（5月22日）通过香港金融管理局债务工具中央结算系统（CMU）债券投标平台，以利率招标方式发行了2024年第四期和第五期央行票据。具体情况如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 发行量  （人民币） | 期限 | 中标利率 |
| 2024年第四期央行票据（香港） | 300亿元 | 3个月  （91天） | 2.75% |
| 2024年第五期央行票据（香港） | 200亿元 | 1年 | 2.70% |

中国人民银行公开市场业务操作室

二〇二四年五月二十二日
