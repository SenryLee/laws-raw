# 中国人民银行公开市场业务操作室关于2024年2月4日人民银行以利率招标方式开展了430亿元14天期逆回购操作的公告

## 公开市场业务交易公告

〔2024〕第25号

为维护春节前流动性平稳，2024年2月4日人民银行以利率招标方式开展了430亿元14天期逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 14天 | 430亿元 | 1.95% |
