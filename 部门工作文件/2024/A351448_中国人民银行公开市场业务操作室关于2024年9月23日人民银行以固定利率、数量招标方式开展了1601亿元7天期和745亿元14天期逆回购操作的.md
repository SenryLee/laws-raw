# 中国人民银行公开市场业务操作室关于2024年9月23日人民银行以固定利率、数量招标方式开展了1601亿元7天期和745亿元14天期逆回购操作的公告

## 公开市场业务交易公告

〔2024〕第189号

为维护季末银行体系流动性合理充裕，2024年9月23日人民银行以固定利率、数量招标方式开展了1601亿元7天期和745亿元14天期逆回购操作。其中，公开市场14天期逆回购操作利率为公开市场7天期逆回购操作利率加15个基点。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 7天 | 1601亿元 | 1.70% |
| 14天 | 745亿元 | 1.85% |
