# 中国人民银行公开市场业务操作室关于2024年7月25日人民银行以固定利率、数量招标方式开展了2351亿元逆回购操作和以利率招标方式开展2000亿元中期借贷便利（MLF）操作的公告

## 公开市场业务交易公告

〔2024〕第146号

为维护月末银行体系流动性合理充裕，2024年7月25日人民银行以固定利率、数量招标方式开展了2351亿元逆回购操作。此外，以利率招标方式开展2000亿元中期借贷便利（MLF）操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 7天 | 2351亿元 | 1.70% |

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 2000亿元 | 2.30% |

中国人民银行公开市场业务操作室

二〇二四年七月二十五日
