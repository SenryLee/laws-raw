# 中国人民银行公开市场业务操作室关于以利率招标方式发行了2024年第十期和第十一期央行票据的公告

## 公开市场业务交易公告

〔2024〕第230号

人民银行于本周三（11月20日）通过香港金融管理局债务工具中央结算系统（CMU）债券投标平台，以利率招标方式发行了2024年第十期和第十一期央行票据。具体情况如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 发行量  （人民币） | 期限 | 中标利率 |
| 2024年第十期央行票据（香港） | 300亿元 | 3个月  （91天） | 3.20% |
| 2024年第十一期央行票据（香港） | 150亿元 | 1年 | 2.60% |

中国人民银行公开市场业务操作室

二〇二四年十一月二十日
