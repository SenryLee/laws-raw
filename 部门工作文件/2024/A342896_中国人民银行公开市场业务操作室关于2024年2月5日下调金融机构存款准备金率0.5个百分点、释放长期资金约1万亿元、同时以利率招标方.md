# 中国人民银行公开市场业务操作室关于2024年2月5日下调金融机构存款准备金率0.5个百分点、释放长期资金约1万亿元、同时以利率招标方式开展了1000亿元逆回购操作的公告

## 公开市场业务交易公告

〔2024〕第26号

2024年2月5日,人民银行下调金融机构存款准备金率0.5个百分点,释放长期资金约1万亿元,同时以利率招标方式开展了1000亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 14天 | 1000亿元 | 1.95% |

二〇二四年二月五日
