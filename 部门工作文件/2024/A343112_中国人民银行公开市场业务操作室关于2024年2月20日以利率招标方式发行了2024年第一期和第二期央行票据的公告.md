# 中国人民银行公开市场业务操作室关于2024年2月20日以利率招标方式发行了2024年第一期和第二期央行票据的公告

## 公开市场业务交易公告

〔2024〕第34号

人民银行于本周二（2月20日）通过香港金融管理局债务工具中央结算系统（CMU）债券投标平台，以利率招标方式发行了2024年第一期和第二期央行票据。具体情况如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 发行量  （人民币） | 期限 | 中标利率 |
| 2024年第一期央行票据（香港） | 300亿元 | 3个月  （91天） | 3.04% |
| 2024年第二期央行票据（香港） | 150亿元 | 1年 | 2.79% |

中国人民银行公开市场业务操作室

二〇二四年二月二十日
