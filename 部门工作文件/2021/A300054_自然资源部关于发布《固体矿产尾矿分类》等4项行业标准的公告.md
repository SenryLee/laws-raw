# 自然资源部关于发布《固体矿产尾矿分类》等4项行业标准的公告

## 自然资源部公告

2021年第24号

## 自然资源部关于发布《固体矿产尾矿分类》等4项行业标准的公告

《固体矿产尾矿分类》等4项推荐性行业标准已通过全国自然资源与国土空间规划标准化技术委员会审查，现予批准、发布，自2021年6月1日起实施。标准编号及名称如下：

|  |  |
| --- | --- |
| DZ/T 0371-2021 | 固体矿产尾矿分类 |
| DZ/T 0372-2021 | 固体矿产选冶试验样品配制规范 |
| DZ/T 0373-2021 | 矿山固体废弃物资源化利用指标及计算方法 |
| DZ/T 0097-2021 | 工程地质调查规范（1:50 000）  (代替DZ/T 0097-1994中1:50 000部分) |

自然资源部

2021年4月9日
