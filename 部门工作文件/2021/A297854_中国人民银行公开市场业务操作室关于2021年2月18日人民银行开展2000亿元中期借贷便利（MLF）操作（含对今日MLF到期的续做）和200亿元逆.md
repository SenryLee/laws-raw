# 中国人民银行公开市场业务操作室关于2021年2月18日人民银行开展2000亿元中期借贷便利（MLF）操作（含对今日MLF到期的续做）和200亿元逆回购操作的公告

## 公开市场业务交易公告

[2021]第30号

春节后现金逐步回笼，2021年2月18日人民银行开展2000亿元中期借贷便利（MLF）操作（含对今日MLF到期的续做）和200亿元逆回购操作，维护银行体系流动性合理充裕。具体情况如下：

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 2000亿元 | 2.95% |

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 200亿元 | 2.20% |

中国人民银行公开市场业务操作室

二〇二一年二月十八日
