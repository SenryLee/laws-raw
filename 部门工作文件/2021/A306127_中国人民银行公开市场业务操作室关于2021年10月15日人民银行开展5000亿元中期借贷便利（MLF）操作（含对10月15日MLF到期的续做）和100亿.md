# 中国人民银行公开市场业务操作室关于2021年10月15日人民银行开展5000亿元中期借贷便利（MLF）操作（含对10月15日MLF到期的续做）和100亿元逆回购操作的公告

## 公开市场业务交易公告

[2021]第201号

为维护银行体系流动性合理充裕，2021年10月15日人民银行开展5000亿元中期借贷便利（MLF）操作（含对10月15日MLF到期的续做）和100亿元逆回购操作。具体情况如下：

## MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 5000亿元 | 2.95% |

## 逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 100亿元 | 2.20% |
