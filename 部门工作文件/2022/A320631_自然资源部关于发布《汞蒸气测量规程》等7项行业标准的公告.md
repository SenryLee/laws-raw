# 自然资源部关于发布《汞蒸气测量规程》等7项行业标准的公告

## 自然资源部公告

2022年第63号

## 关于发布《汞蒸气测量规程》等7项行业标准的公告

《汞蒸气测量规程》等7项行业标准已通过全国自然资源与国土空间规划标准化技术委员会审查，现予批准、发布，自2022年12月1日起实施。标准编号及名称如下：

|  |  |
| --- | --- |
| DZ/T 0003-2022 | 汞蒸气测量规程  （代替DZ/T 0003-1991） |
| DZ/T 0173-2022 | 大地电磁测深法技术规程  （代替DZ/T 0173-1997） |
| DZ/T 0407-2022 | 广域电磁法技术规程 |
| DZ/T 0408-2022 | 侧扫声呐测量技术规程 |
| DZ/T 0409-2022 | 陆域天然气水合物钻探技术规程 |
| DZ/T 0410-2022 | 地质钻探护壁堵漏技术规程 |
| DZ/T 0411-2022 | 浅层地下水连续多通道管监测井建设规程 |
