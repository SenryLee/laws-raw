# 中国人民银行公开市场业务操作室关于2022年1月27日以利率招标方式开展了2000亿元14天期逆回购操作的公告

## 公开市场业务交易公告

[2022]第18号

为维护春节前流动性平稳，2022年1月27日人民银行以利率招标方式开展了2000亿元14天期逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 14天 | 2000亿元 | 2.25% |

二〇二二年一月二十七日
