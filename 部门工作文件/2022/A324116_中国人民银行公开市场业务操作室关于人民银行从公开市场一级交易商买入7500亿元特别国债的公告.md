# 中国人民银行公开市场业务操作室关于人民银行从公开市场一级交易商买入7500亿元特别国债的公告

## 公开市场业务交易公告

〔2022〕第243号

2022年12月12日，人民银行以数量招标方式进行了公开市场业务现券买断交易，从公开市场一级交易商买入7500亿元特别国债。具体情况如下：

现券买断招标情况

|  |  |  |
| --- | --- | --- |
| 券种 | 买入价格（元） | 招标量（亿元） |
| 22特别国债 | 100 | 7500 |
