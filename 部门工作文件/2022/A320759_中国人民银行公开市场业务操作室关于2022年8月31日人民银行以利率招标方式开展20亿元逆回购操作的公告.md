# 中国人民银行公开市场业务操作室关于2022年8月31日人民银行以利率招标方式开展20亿元逆回购操作的公告

## 公开市场业务交易公告

〔2022〕第171号

为维护银行体系流动性合理充裕，2022年8月31日人民银行以利率招标方式开展了20亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 20亿元 | 2.00% |
