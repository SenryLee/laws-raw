# 中国人民银行公开市场业务操作室关于12月20日以利率招标方式发行了2023年第十二期央行票据的公告

## 公开市场业务交易公告

〔2023〕第250号

人民银行于本周三（12月20日）通过香港金融管理局债务工具中央结算系统（CMU）债券投标平台，以利率招标方式发行了2023年第十二期央行票据。具体情况如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 发行量  （人民币） | 期限 | 中标利率 |
| 2023年第十二期央行票据（香港） | 50亿元 | 6个月  （182天） | 2.80% |

中国人民银行公开市场业务操作室

二〇二三年十二月二十日
