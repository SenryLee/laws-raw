# 中国人民银行公开市场业务操作室关于2023年7月17日人民银行开展1030亿元中期借贷便利（MLF）操作和330亿元公开市场逆回购操作的公告

## 公开市场业务交易公告

〔2023〕第138号

为维护银行体系流动性合理充裕，2023年7月17日人民银行开展1030亿元中期借贷便利（MLF）操作和330亿元公开市场逆回购操作,充分满足了金融机构需求。具体情况如下：

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 1030亿元 | 2.65% |

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 330亿元 | 1.90% |

中国人民银行公开市场业务操作室

二〇二三年七月十七日
