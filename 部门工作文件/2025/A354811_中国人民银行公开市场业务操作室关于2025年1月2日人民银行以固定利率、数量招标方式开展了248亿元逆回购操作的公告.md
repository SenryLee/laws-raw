# 中国人民银行公开市场业务操作室关于2025年1月2日人民银行以固定利率、数量招标方式开展了248亿元逆回购操作的公告

## 公开市场业务交易公告

〔2025〕第1号

为保持银行体系流动性充裕，2025年1月2日人民银行以固定利率、数量招标方式开展了248亿元逆回购操作。具体情况如下：

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 操作利率 |
| 7天 | 248亿元 | 1.50% |
