# 中国人民银行公开市场业务操作室关于以固定数量、利率招标、多重价位中标方式开展14000亿元买断式逆回购操作的公告

## 公开市场买断式逆回购招标公告

[2025]第3号

为保持银行体系流动性充裕，2025年7月15日，中国人民银行将以固定数量、利率招标、多重价位中标方式开展14000亿元买断式逆回购操作。具体情况如下：

|  |  |
| --- | --- |
| **期限** | **操作量** |
| 3个月（91天） | 8000亿元 |
| 6个月（182天） | 6000亿元 |
