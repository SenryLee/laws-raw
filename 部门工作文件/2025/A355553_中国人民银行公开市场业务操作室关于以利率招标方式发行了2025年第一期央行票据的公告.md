# 中国人民银行公开市场业务操作室关于以利率招标方式发行了2025年第一期央行票据的公告

## 公开市场业务交易公告

〔2025〕第11号

中国人民银行于本周三（1月15日）通过香港金融管理局债务工具中央结算系统（CMU）债券投标平台，以利率招标方式发行了2025年第一期央行票据。具体情况如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 发行量  （人民币） | 期限 | 中标利率 |
| 2025年第一期央行票据（香港） | 600亿元 | 6个月  （182天） | 3.40% |

中国人民银行公开市场业务操作室

二〇二五年一月十五日
