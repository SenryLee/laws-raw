# 环境保护部公告2017年第18号——关于发布《环境空气 颗粒物中无机元素的测定 能量色散X射线荧光光谱法》等两项国家环境保护标准的公告

## 环境保护部公告

2017年第18号

## 关于发布《环境空气 颗粒物中无机元素的测定 能量色散X射线荧光光谱法》等两项国家环境保护标准的公告

为贯彻《中华人民共和国环境保护法》和《中华人民共和国大气污染防治法》，保护环境，保障人体健康，规范环境监测工作，现批准《环境空气 颗粒物中无机元素的测定 能量色散X射线荧光光谱法》等两项标准为国家环境保护标准，并予发布。

标准名称、编号如下：

一、《环境空气 颗粒物中无机元素的测定 能量色散X射线荧光光谱法》（HJ 829-2017）；

二、《环境空气 颗粒物中无机元素的测定 波长色散X射线荧光光谱法》（HJ 830-2017）。

以上标准自2017年7月1日起实施，由中国环境出版社出版，标准内容可在环境保护部网站（kjs.mep.gov.cn/hjbhbz/）查询。

特此公告。

环境保护部

2017年5月2日

附件1：《环境空气 颗粒物中无机元素的测定 能量色散X射线荧光光谱法》（HJ 829-2017）

附件2：《《环境空气 颗粒物中无机元素的测定 波长色散X射线荧光光谱法》（HJ 830-2017）
