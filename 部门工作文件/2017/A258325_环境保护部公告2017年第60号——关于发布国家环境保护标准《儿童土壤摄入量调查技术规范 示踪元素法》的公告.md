# 环境保护部公告2017年第60号——关于发布国家环境保护标准《儿童土壤摄入量调查技术规范 示踪元素法》的公告

## 环境保护部公告

2017年第60号

## 关于发布国家环境保护标准《儿童土壤摄入量调查技术规范 示踪元素法》的公告

为贯彻《中华人民共和国环境保护法》，推进环境健康风险管理，规范儿童土壤摄入量调查工作，现批准《儿童土壤摄入量调查技术规范 示踪元素法》为国家环境保护标准，并予发布。

标准名称、编号如下：

《儿童土壤摄入量调查技术规范 示踪元素法》（HJ 876-2017）。

本标准自发布之日起实施，由中国环境出版社出版，标准内容可在环境保护部网站（kjs.mep.gov.cn/hjbhbz/）查询。

特此公告。

环境保护部

2017年11月28日

附件：《儿童土壤摄入量调查技术规范 示踪元素法》（HJ 876-2017）
