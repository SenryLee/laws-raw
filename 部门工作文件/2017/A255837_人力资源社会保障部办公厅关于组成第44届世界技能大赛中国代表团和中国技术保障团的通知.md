# 人力资源社会保障部办公厅关于组成第44届世界技能大赛中国代表团和中国技术保障团的通知

人社厅函〔2017〕250号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局），国务院有关部门，有关行业组织、相关企业人事劳动保障工作机构：

2017年10月14日至19日，第44届世界技能大赛将在阿联酋XXX扎比举行，我国将派团参加47个项目的比赛。经人力资源社会保障部批准，第44届世界技能大赛中国代表团和中国技术保障团已经组成。希望全体同志珍惜荣誉，团结协作，尽职尽责，全力以赴，在第44届世界技能大赛中勇于拼搏，争创佳绩，为祖国和人民争光。

请各地人社部门、行业企业积极协调有关部门全力保障第44届世界技能大赛中国代表团和中国技术保障团顺利出国。

附件：1.第44届世界技能大赛中国代表团人员名单

2.第44届世界技能大赛中国技术保障团人员名单
