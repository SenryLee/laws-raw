# 环境保护部公告2017年第61号——关于发布国家环境保护标准《环境信息元数据规范》的公告

## 环境保护部公告

2017年第61号

## 关于发布国家环境保护标准《环境信息元数据规范》的公告

为贯彻《中华人民共和国环境保护法》，促进环境信息化工作，保障环境信息互联互通与共享，规范环境信息元数据标准建设，现批准《环境信息元数据规范》为国家环境保护标准，并予发布。

标准名称、编号如下：

《环境信息元数据规范》（HJ 720-2017）。

本标准自2018年1月1日起实施。自本标准实施之日起，《环境信息元数据规范》（HJ720-2014）废止。

本标准由中国环境出版社出版，标准内容可在环境保护部网站（kjs.mep.gov.cn/hjbhbz/）查询。

特此公告。

环境保护部

2017年11月28日

附件：《环境信息元数据规范》（HJ 720-2017）
