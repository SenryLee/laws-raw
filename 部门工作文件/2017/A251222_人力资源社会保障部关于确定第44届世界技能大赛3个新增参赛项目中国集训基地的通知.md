# 人力资源社会保障部关于确定第44届世界技能大赛3个新增参赛项目中国集训基地的通知

人社部函〔2017〕77号

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局），国务院有关部门，有关行业组织、相关企业人事劳动保障工作机构：

为做好第44届世界技能大赛备战工作，经研究，确定广东省轻工业技师学院等7家单位为第44届世界技能大赛3个新增参赛项目中国集训基地。

希望各集训基地认真履行职责，加强沟通配合，切实做好所承担项目集训工作的具体组织实施和管理，提供必需的保障和支持，为我国参赛选手在第44届世界技能大赛中取得优异成绩，为祖国争光作出应有的贡献。

附件：第44届世界技能大赛3个新增参赛项目中国集训基地名单

第44届世界技能大赛中国组委会

2017年5月27日

## 第44届世界技能大赛3个新增参赛项目中国集训基地名单

一、商品展示技术项目

1.广东省轻工业技师学院

2.上海工艺美术职业学院

二、货运代理项目

1.上海国际港务（集团）股份有限公司

2.广州市工贸技师学院

3.山东劳动技师学院

三、3D数字游戏艺术项目

1.深圳技师学院

2.北京市新媒体技师学院
