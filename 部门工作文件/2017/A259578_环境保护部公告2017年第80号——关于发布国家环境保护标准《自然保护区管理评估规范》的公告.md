# 环境保护部公告2017年第80号——关于发布国家环境保护标准《自然保护区管理评估规范》的公告

## 环境保护部公告

2017年第80号

## 关于发布国家环境保护标准《自然保护区管理评估规范》的公告

为贯彻落实《中华人民共和国环境保护法》和《中华人民共和国自然保护区条例》，规范我国自然保护区建设管理工作，提升我国自然保护区管理水平，现批准《自然保护区管理评估规范》为国家环境保护标准，并予发布。

标准名称、编号如下：

《自然保护区管理评估规范》（HJ 913-2017）。

以上标准自2018年3月1日起实施，由中国环境出版社出版，标准内容可在环境保护部网站（kjs.mep.gov.cn/hjbhbz/）查询。

特此公告。

环境保护部

2017年12月25日

附件：《自然保护区管理评估规范》（HJ 913-2017）
