# 环境保护部公告2017年第26号——关于发布国家环境保护标准《人体健康水质基准制定技术指南》和《湖泊营养物基准制定技术指南》的公告

## 环境保护部公告

2017年第26号

## 关于发布国家环境保护标准《人体健康水质基准制定技术指南》和《湖泊营养物基准制定技术指南》的公告

为贯彻《中华人民共和国环境保护法》，依据《国家环境基准管理办法（试行）》的要求，规范人体健康水质基准和湖泊营养物基准制定工作，现批准《人体健康水质基准制定技术指南》和《湖泊营养物基准制定技术指南》为国家环境保护标准，并予发布。

标准名称、编号如下：

《人体健康水质基准制定技术指南》（HJ 837-2017）。

《湖泊营养物基准制定技术指南》（HJ 838-2017）。

以上标准自2017年9月1日起实施，由中国环境出版社出版，标准内容可在环境保护部网站（kjs.mep.gov.cn/hjbhbz/）查询。

特此公告。

环境保护部

2017年6月9日

附件：1.《人体健康水质基准制定技术指南》（HJ 837-2017）

2.《湖泊营养物基准制定技术指南》（HJ 838-2017）
