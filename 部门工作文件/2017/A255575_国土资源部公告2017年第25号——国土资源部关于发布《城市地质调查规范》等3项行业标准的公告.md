# 国土资源部公告2017年第25号——国土资源部关于发布《城市地质调查规范》等3项行业标准的公告

## 国土资源部公告

2017年第25号

## 国土资源部关于发布《城市地质调查规范》等3项行业标准的公告

《城市地质调查规范》等3项推荐性行业标准已通过全国国土资源标准化技术委员会审查，现予批准、发布，于2017年11月1日起实施。编号及名称如下：

DZ/T 0306-2017 城市地质调查规范

DZ/T 0307-2017 地下水监测网运行维护规范

DZ/T 0308-2017 区域地下水质监测网设计规范

2017年9月7日
