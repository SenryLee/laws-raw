# 住房和城乡建设部公告第1483号——住房城乡建设部关于发布国家标准《多高层木结构建筑技术标准》的公告

## 住房和城乡建设部公告

第1483号

## 住房城乡建设部关于发布国家标准《多高层木结构建筑技术标准》的公告

现批准《多高层木结构建筑技术标准》为国家标准，编号为GB/T51226-2017，自2017年10月1日起实施。

本标准由我部标准定额研究所组织中国建筑工业出版社出版发行。

中华人民共和国住房和城乡建设部

2017年2月21日
