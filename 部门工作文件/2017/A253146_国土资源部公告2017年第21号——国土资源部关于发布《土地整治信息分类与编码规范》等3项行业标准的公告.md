# 国土资源部公告2017年第21号——国土资源部关于发布《土地整治信息分类与编码规范》等3项行业标准的公告

## 国土资源部公告

2017年第21号

## 国土资源部关于发布《土地整治信息分类与编码规范》等3项行业标准的公告

《土地整治信息分类与编码规范》等3项推荐性行业标准已通过全国国土资源标准化技术委员会审查，现予批准、发布，于2017年9月1日起实施。编号及名称如下：

TD/T 1050-2017 土地整治信息分类与编码规范

TD/T 1051-2017 土地整治项目基础调查规范

DZ/T 0171-2017 大比例尺重力勘查规范

《大比例尺重力勘查规范》（DZ/T 0171-1997）废止。

2017年7月28日
