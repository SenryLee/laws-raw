# 中华人民共和国住房和城乡建设部公告第1860号——住房城乡建设部关于发布行业产品标准《微滤水处理设备》的公告

## 中华人民共和国住房和城乡建设部公告

第1860号

## 住房城乡建设部关于发布行业产品标准《微滤水处理设备》的公告

现批准《微滤水处理设备》为城镇建设行业产品标准，编号为CJ/T169-2018，自2018年10月1日起实施。原《微滤水处理设备》CJ/T169-2002同时废止。

本标准在住房城乡建设部门户网站（www.mohurd.gov.cn）公开，并由住房城乡建设部标准定额研究所组织中国标准出版社出版发行。

中华人民共和国住房和城乡建设部

2018年3月8日
