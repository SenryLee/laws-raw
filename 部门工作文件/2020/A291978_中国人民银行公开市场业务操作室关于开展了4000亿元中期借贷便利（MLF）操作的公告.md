# 中国人民银行公开市场业务操作室关于开展了4000亿元中期借贷便利（MLF）操作的公告

## 公开市场业务交易公告

[2020]第136号

2020年7月15日，人民银行开展了4000亿元中期借贷便利（MLF）操作。此次MLF操作是对本月两次MLF到期和一次定向中期借贷便利（TMLF）到期的续做，其中TMLF续做可继续滚动，总期限为3年。今日无逆回购操作。具体情况如下：

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 4000亿元 | 2.95% |

中国人民银行公开市场业务操作室

二〇二〇年七月十五日
