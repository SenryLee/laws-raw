# 中国人民银行公开市场业务操作室关于开展7000亿元中期借贷便利（MLF）操作和500亿元逆回购操作的公告

## 公开市场业务交易公告

[2020]第160号

2020年8月17日，人民银行开展7000亿元中期借贷便利（MLF）操作。此次MLF操作是对本月两笔MLF到期的一次性续做，充分满足了金融机构需求。同时,今日开展500亿元逆回购操作。具体情况如下：

MLF操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 操作量 | 中标利率 |
| 1年 | 7000亿元 | 2.95% |

逆回购操作情况

|  |  |  |
| --- | --- | --- |
| 期限 | 中标量 | 中标利率 |
| 7天 | 500亿元 | 2.20% |

中国人民银行公开市场业务操作室

二〇二〇年八月十七日
