# 中国残联办公厅关于举办全国省级残联网站信息无障碍技术培训班和统计人员培训班的通知

中国残联办公厅关于举办全国省级残联网站信息无障碍技术培训班和统计人员培训班的通知

各省、自治区、直辖市残联，新疆生产建设兵团残联，黑龙江农垦总局残联：

根据《无障碍环境建设条例》及《中国残疾人事业“十二五”发展纲要》的总体要求，全国33个省级残联网站“十二五”期间要全部实现无障碍。截止2012年底，已有7个省级残联完成了网站无障碍建设，河北、山西、内蒙古、辽宁、吉林、黑龙江、浙江、福建、湖北、湖南、广西、海南、贵州、云南、陕西、新疆等16个省级残联明确将网站无障碍建设纳入2013或2014年度工作中。

2013年是“十二五”任务执行的关键时期，为加快推进省级残联系统网站无障碍建设，解决各地残联在推进网站无障碍建设过程中遇到的问题，向网站技术人员和项目执行单位进行针对性指导，经中国残联领导同意，决定举办省级残联网站无障碍技术培训班。

为了做好2013年度残疾人事业统计的布置和培训工作，按照工作安排，全国省级残联统计人员培训班也将于近期举办。考虑两个培训班会期接近，且部分省的参会人员可能存在重叠，为了方便地方参会人员，经中国残联领导同意，决定于同一地点安排培训。现就有关培训事项通知如下：

**一、**会议时间、地点

时间：2013年8月21日至30日。

其中：无障碍技术培训班于8月21日至25日举办，21日报道，25日撤离；统计培训班8月26日至30日举办，26日报道，30日撤离。

地点：山西省太原市（太原市迎泽大街108号，三晋国际饭店）。

**二、**参加人员

（一）无障碍技术培训班。

1．已纳入2013和2014年度工作的16家省级残联。

省级残联网站工作负责人及技术人员各1人，并带网站技术支持公司的技术人员1人参会。

2．其他省级残联。

省级残联网站技术人员1人参会，可根据自身情况带网站技术支持公司人员参会。

（二）统计培训班。

各省、自治区、直辖市残联，新疆生产建设兵团残联、黑龙江农垦总局残联统计人员各1人。

**三、**培训内容

（一）无障碍技术培训班。

1．深入讲解信息无障碍概念、发展及现状，分析残疾人需求。

2．地方残联网站无障碍测评情况详解。

3．我国网站无障碍建设技术标准讲解，技术点分析及解决方案。

4．按照我国标准开展网站无障碍技术培训，介绍网站无障碍合规性检测系统，并上机进行实际操作。

（二）统计培训班。

1．通报2012年统计工作情况。

2．布置2013年统计工作，针对2012年填报、审核中的突出问题和2013年统计指标的调整，讲解统计指标与填报要求。

3．布置2013年新开展台账填报工作。

4．网络版统计管理系统的软件操作上机培训。

5．各地统计工作交流。

**四、**有关要求与注意事项

1. 除已纳入2013和2014年度工作计划的16个省的网站技术支持公司人员外，参加无障碍技术培训班的其他公司人员会议期间的食宿费用需自理（具体费用另行通知）。

2. 请按规定确定相关人员按时参加培训，以保证本省工作任务的顺利开展。无关人员不得参加。提前抵达和推迟返程的有关费用自理。

3. 所有参加培训人员请自带笔记本电脑。

4. 请认真填写培训班回执（见附件1、2）于2013年8月14日前反馈至信息中心。若需要协助预订返程票，请务必在回执中说明，并提前将订票所需身份证号等信息通过传真或电子邮件发至中国残联信息中心。

5. 培训班不设接站。参加人员请参照培训地点交通提示（见附件3）自行前往培训地点。
