# 中国金融期货交易所关于举办第21期交易结算及风控业务培训班的通知

各会员单位：

为确保金融期货相关业务的顺利开展，协助会员单位培养合格的岗位操作及业务人员，兹定于2013年7月13日-14日在上海国家会计学院举办中国金融期货交易所第21期交易结算及风控业务培训班。

请各会员单位做好培训组织工作，以公司名义通过我所网站统一报名（中金所主页-业务专区－培训报名），经我所审核通过后，安排员工参加培训。

联系电话：021-50160804

附件：第21期交易结算及风控业务培训班方案

中国金融期货交易所　

二〇一三年六月二十七日

附件：

第21期交易结算及风控业务培训班方案

**一、**培训时间

2013年7月13-14日（周六及周日）

**二、**培训地点

上海国家会计学院（上海市青浦区蟠龙路200号）

**三、**培训对象

会员公司交易岗位、结算岗位及风控岗位的业务人员。

**四、**课程内容

|  |  |  |  |
| --- | --- | --- | --- |
| 时间 | | 内容 | 师资 |
| 周六  （13日） | 09：00-10：00 | 中金所会员、客户及交易管理 | 交易部 |
| 10：15-11：30 | 中金所风险控制制度 |
| 13：30-14：30 | 结算业务及细则介绍（1） | 结算部 |
| 14：45-16：30 | 结算业务及细则介绍（2） |
| 周日  （14日） | 09：00-10：00 | 国债期货基础知识（1） | 国债小组 |
| 10：15-11：30 | 国债期货基础知识（2） |
| 13：30-15：00 | 结业考试 | 中金所 |

**五、**培训费用

本次培训班不收取培训费。

**六、**报名方式

请各会员单位做好培训组织工作，以公司名义通过我所网站统一报名（中金所主页-业务专区－培训报名），经我所审核通过后，安排员工参加培训。

**七、**报到安排

培训前一天下午4：00开始，学员可在上海国家会计学院1号公寓注册中心，办理报到及领取培训资料等手续。

上海国家会计学院可安排食宿，费用标准为：单人间190元/间、自助早餐10元/人、自助午餐35元/人、自助晚餐35元/人，学员无需预订可在报到时办理，费用自理，咨询电话021－5016 0804。
