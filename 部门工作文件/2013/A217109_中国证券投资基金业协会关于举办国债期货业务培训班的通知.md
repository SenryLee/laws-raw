# 中国证券投资基金业协会关于举办国债期货业务培训班的通知

各会员机构：

根据行业需求，经研究，我会定于2013年4月18日在上海、4月23日在深圳、4月26日在北京与中国金融期货交易所联合举办国债期货业务培训班，现就培训有关事项通知如下：

**一、**培训时间和地点

此次培训共举办如下三期：

|  |  |  |  |
| --- | --- | --- | --- |
| 序号 | 报到时间 | 培训时间 | 培训地点 |
| 一期 | 4月18日  7：30-9：00 | 4月18日  9：00-17：00 | 上海中油阳光大酒店五楼阳光厅 |
| 二期 | 4月23日  7：30-9：00 | 4月23日  9：00-17：00 | 深圳马哥孛罗好日子酒店宴会厅A厅 |
| 三期 | 4月26日  7：30-9：00 | 4月26日  9：00-17：00 | 北京友谊宾馆贵宾楼报告厅 |

**二、**培训对象

基金管理公司债券型基金的基金经理及投研团队主管或骨干人员；基金管理公司及托管银行风控、稽核、清算等中后台业务主管或骨干人员，每家机构可报3-5名学员。

私募投资管理公司、保险资产管理公司、证券公司及证券资产管理公司等特别会员机构，每家机构可报3名学员。

**三、**培训主要内容及师资

（一）培训主要内容

海外国债期货市场发展情况介绍，国债期货合约、规则及仿真交易介绍，国债期货仿真交易经验分享，国债期货原理及交易实务等。

（二）培训师资

中金所国债小组及行业有关专家。
