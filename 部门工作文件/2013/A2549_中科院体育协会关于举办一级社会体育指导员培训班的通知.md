# 中科院体育协会关于举办一级社会体育指导员培训班的通知

院属各单位体协、工会：

根据院体协2013年度工作计划，加强对我院职工体育骨干和社会体育指导员的培训，为基层单位开展全民健身工作培养骨干力量，定于4月下旬在山东省威海市举办中科院体协2013年第一期一级社会体育指导员（组织管理）培训班，现将有关事宜通知如下：

**一、**培训时间、地点

时间：2013年4月22日至26日；报到时间：4月22日全天。

地点：威海电子宾馆（山东省威海市环海路十五号，联系电话：0631-5261201）

**二、**参加培训人员资格

1.可申请一级社会体育指导员的条件。凡在本单位职工体育工作管理岗位上工作满5年，并做出一定成绩的人员或各级群众体育组织和经过审批的体育锻炼站点的组织者。

2.可参加培训人员的条件。各单位需要培养的职工体育骨干人员（限2人）。

**三、**培训内容

1.国内外社会体育的发展状况；

2.不同人群体育健身的理念和方法；

3.群众体育活动的组织方法；

4.体育竞赛项目编排方法；

5.运动处方及要求开展健身活动的基本知识；

6.健身气功“八段锦”功法教学与考试。

**四、**要求

1.各单位报名参加培训的人员要做好培训准备，提前熟悉所培训的内容。本次培训班按照社会体育指导员培训大纲的要求进行考试，凡考试合格的学员统一颁发由国家体育总局制作的培训合格证书和一级社会体育指导员证书。

2. 请各单位于4月18日之前将加盖单位公章的纸质版报名表上报院体协秘书处，并将电子版报名表发送至指定邮箱：wzhang@cashq.ac.cn 。

**五、**经费

1.参加培训学员的交通费、住宿费（按照差旅标准）由各单位自理。

2.参加培训学员每人交纳资料费300元，其他费用由院体协负责。

**六、**未尽事宜另行通知

联系人：门东山、张 伟

电 话：62661236

传 真：62661234

E-mail：wzhang@cashq.ac.cn
