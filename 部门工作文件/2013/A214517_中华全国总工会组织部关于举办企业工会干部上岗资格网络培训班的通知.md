# 中华全国总工会组织部关于举办企业工会干部上岗资格网络培训班的通知

为满足广大新任企业工会干部上岗资格培训需求，提高企业工会干部工作能力和水平，按照《2011-2015年全国工会干部教育培训规划》要求，全总组织部即日起在全国工会干部教育培训网（http：//px.workercn.cn）举办“企业工会干部上岗资格网络培训班”。现将有关事项通知如下：

**一、**培训对象

新任企业工会专、兼职干部。

**二、**培训内容

|  |  |  |
| --- | --- | --- |
| 课程 | 授课教师 | 教师单位及职务 |
| 1、坚定不移走中国特色社会主义工会发展道路 | 李滨生 | 全国总工会书记处书记 |
| 2、劳动关系与民主管理 | 郭 军 | 全总民主管理部部长 |
| 3、贯彻实施《劳动合同法》的若干争议问题分析 | 姜 颖 | 中国劳动关系学院教授 |
| 4、工会劳动保护工作 | 孟燕华 | 中国劳动关系学院教授 |
| 5、平等协商集体合同制度 | 许晓军 | 中国劳动关系学院教授 |
| 6、企业工会工作条例 | 吴亚平 | 中国劳动关系学院教授 |
| 7、职工董事职工监事制度 | 杨冬梅 | 中国劳动关系学院教授 |
| 8、劳动争议调解仲裁法 | 杨冬梅 | 中国劳动关系学院教授 |

**三、**培训形式

学员自行或集体注册后参加网上视频课程学习。

**四、**报名方式

个人报名：学员在全国工会干部教育培训网注册后，申请加入培训班，待网站管理人员审核、确认后，正式编入班级学习。

集体报名：有关地方或部门、单位填写《委托全国工会干部教育培训网举办工会干部网络培训班申请表》，履行批准手续后，提交培训学员相关信息，发送至邮箱：

gjpx@workercn.cn 或2649526231@qq.com，待网站管理人员审核、导入、确认后，集体编入班级学习。

集体报名申请表下载：《委托全国工会干部教育培训网举办工会干部网络培训班申请表》

**五、**考试及证书发放

学员完成培训班所有课程学习后，参加网上考试，成绩合格者，可以按照程序申请并下载打印全总组织部授权发放的“工会干部上岗资格网络培训证书”。如需要中华全国总工会统一监制的“工会干部上岗资格培训证书”纸质版的学员，请与全国工会干部教育培训网联系。
