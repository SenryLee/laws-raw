# 中国资产评估协会关于举办《资产评估项目管理系统》操作培训班的通知

## 中国资产评估协会关于举办《资产评估项目管理系统》操作培训班的通知（中评协[2013]48号）

各资产评估机构：

中国资产评估协会（以下简称“中评协”）与国家知识产权局合作开发的《资产评估项目管理系统》已通过验收，开始在行业内全面推广使用。资产评估项目管理系统立足评估机构执业辅助和管理需求，具有科学化、规范化的特点。其主要功能包括： 业务约定书签订、项目组织实施、评估数据采集、撰写评估报告、评估报告审核、出具评估报告，归档及对评估机构人员的管理等。该系统规范了评估机构的作业流程，覆盖了资产评估项目管理、项目实施、项目存档的全过程，为机构执业和管理提供了科学、高效的辅助手段。

为使广大资产评估机构及行业从业人员全面了解并熟练使用该系统，中评协将于4月至6月分三批举办15期资产评估项目管理系统操作培训班。现将有关事项通知如下：

**一、**培训内容

1.资产评估项目管理系统的安装；

2.系统模块的设置与使用；

3.常用工具模块使用；

4.各项目管理模块的使用；

5.资产评估机构自行架设服务器时的相关操作（包括：网络布局、数据库软件的配置、服务软件的设置等）。

**二、**培训对象

每个资产评估机构选派2名人员参加，其中项目经理1名、信息管理员1名。

**三、**培训时间

每批培训共分5期，每期为一天，培训内容相同。

第一批：4月8、9、10、11、12日各一期；

第二批：5月3、4、5、6、7日各一期；

第三批：6月3、4、5、6、7日各一期。

**四、**培训地点

第一批：深圳市银湖度假村（深圳市罗湖区银湖路38号，电话：0755-82431111）；

第二批：江苏省镇江市碧榆园（江苏省镇江市竹林路88号，电话：0511-84430888）；

第三批：湖北省交通职工教育培训中心（湖北省宜昌市峡口风景区南津关路1号，电话：0717-8861868）。

**五、**培训费用

食宿费自理，免收培训费。

食宿费标准：深圳市银湖度假村300元/天.人；江苏省镇江市碧榆园400元/天.人；湖北省交通职工教育培训中心220元/天.人。

**六、**联系方式

中评协联系人：郝晋宏、孙小明；

联系电话：（010）88191861、88191812；

邮箱：xmglxt@cas.org.cn。

**七、**其他事项

1. 参加第一批和第三批培训的学员须自行携带笔记本电脑。

2. 各资产评估机构可根据自身情况，选择参加任意一期培训班，并将报名回执（见附件）以电子邮件方式发至中评协。

3. 第一批培训班报名截止日期为4月2日，第二批培训班报名截止日期为4月15日，第三批培训班报名截止日期为5月15日。

4. 每期培训班名额有限，按照报名先后，报满为止；报名人员选择的培训时间名额已满，将安排其他时间，并电话告之。

5. 报名后若有特殊情况需更改时间，请提前联系中评协。
