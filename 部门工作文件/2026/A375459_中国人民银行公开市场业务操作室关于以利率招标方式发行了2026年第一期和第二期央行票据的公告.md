# 中国人民银行公开市场业务操作室关于以利率招标方式发行了2026年第一期和第二期央行票据的公告

## 公开市场业务交易公告

[2026]第35号

人民银行于本周三（2月25日）通过香港金融管理局债务工具中央结算系统（CMU）债券投标平台，以利率招标方式发行了2026年第一期和第二期央行票据。具体情况如下：

|  |  |  |  |
| --- | --- | --- | --- |
| 期次 | 发行量  （人民币） | 期限 | 中标利率 |
| 2026年第一期央行票据（香港） | 300亿元 | 3个月  （91天） | 1.53% |
| 2026年第二期央行票据（香港） | 200亿元 | 1年 | 1.47% |

中国人民银行公开市场业务操作室

二〇二六年二月二十五日
