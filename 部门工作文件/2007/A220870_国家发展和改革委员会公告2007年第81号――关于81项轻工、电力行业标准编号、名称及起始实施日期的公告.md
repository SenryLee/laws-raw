# 国家发展和改革委员会公告2007年第81号――关于81项轻工、电力行业标准编号、名称及起始实施日期的公告

## 国家发展和改革委员会公告（2007年第81号）

国家发展改革委批准《啤酒玻璃瓶灌装生产线》等81项行业标准（标准编号、名称及起始实施日期见附件），其中轻工行业标准51项、电力行业标准30项，现予公布。

以上轻工行业标准由中国轻工业出版社出版，电力行业标准由中国电力出版社出版。
