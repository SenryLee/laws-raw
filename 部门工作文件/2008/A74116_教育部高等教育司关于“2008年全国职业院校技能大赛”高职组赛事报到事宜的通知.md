# 教育部高等教育司关于“2008年全国职业院校技能大赛”高职组赛事报到事宜的通知

## 教育部高等教育司关于“2008年全国职业院校技能大赛”高职组赛事报到事宜的通知（教高司函[2008]125号）

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

按照《关于“2008年全国职业院校技能大赛”高职组有关事项的通知》（教高司函[2008]84号，以下简称《通知》）要求，目前，各参赛队的报名工作已经全部完成，现就大赛报到事宜通知如下：

**一、**大赛报到事宜

高职组赛事的报到、接送工作均由天津市各赛事承办单位具体负责。

目前，大赛裁判委员会高职组赛事联络处已经将审核后的各地参赛队指导教师报名表、选手报名表、参赛回执发至各赛事具体承办单位。各赛事具体承办单位、报到时间、联系人、联系方式详见附件1。

**二、**展板制作活动

大赛期间，为展示、宣传和交流各省比赛专业的建设成绩和亮点，大赛将在高职组各比赛场地，向各参赛省提供统一的展板展示空间。各省可以在每个参赛项目比赛场地展示一块与本赛事项目为展示内容的展板，具体规格与要求详见附件2。

请各地及各参赛院校及时查阅中国高职高专教育网（网址http：//www.tech.net.cn/），“2008年全国职业院校技能大赛”栏目。有关高职组赛事的最新消息与安排将第一时间在此公布。

附件2：

展板规格与要求

展板的主要内容是展示、宣传和交流各地比赛专业的建设成绩和亮点，特别是突出专业建设中坚持工学结合、校企合作改革探索的成绩与收获，要求图文并茂、文字凝练、突出典型案例（一般不做办学条件等概况性介绍）。

规格与要求：

展板可以在各地制作完成后，携带或托运到天津，报到时提交给相关接受报到单位。也可以将电子文稿和照片（或设计好的展板模版）发给天津，委托相关广告公司完成设计、制作任务。具体规格要求为：

1. 尺寸：180cm x 120cm

2. 文字要求：600字左右（学院概况）格式WORD

3. 图片要求：JPG文件 单张图片大小不低于1M

4. 图片数量：6张左右

5. 提交方式：电子文件可以E-MAIL的方式直接发送到tj27352898@126.com或QQ：1009923933（传图请注明省份、学校名称及展示场地比赛项目名称）
