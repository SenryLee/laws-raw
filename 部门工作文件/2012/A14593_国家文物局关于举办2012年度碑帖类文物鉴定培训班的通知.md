# 国家文物局关于举办2012年度碑帖类文物鉴定培训班的通知

## 国家文物局关于举办2012年度碑帖类文物鉴定培训班的通知（办博函〔2012〕511号）

各有关省、自治区、直辖市文物局（文化厅），各国家文物进出境审核管理处：

为加强文物进出境审核专业人员队伍建设，进一步提高文物进出境审核鉴定业务水平，我局拟委托北京鲁迅博物馆承办文物进出境责任鉴定员碑帖类文物鉴定培训班，现将有关事项通知如下：

**一、**培训时间

2012年7月9日至23日，7月8日报到。

**二、**培训地点

北京北方长城宾馆（北京昌平区南口镇马坊一号208所院内）。

**三、**报到地点

北京鲁迅博物馆（北京市西城区阜成门外大街宫门口二条19号）。

**四、**培训内容

碑帖、拓片文物鉴定。

**五、**培训对象

各国家文物进出境审核管理处从事文物进出境审核工作的人员。

**六、**培训费用

培训期间食宿费用由我局承担，往返交通费用自理。

**七、**培训名额

请各相关省级文物行政主管部门组织各文物进出境审核机构及相关专业人员报名参加此次培训，每省（自治区、直辖市）报名人数不得超过2名。

请于7月5日前将报名表（附后）传真至我局博物馆与社会文物司（科技司）社会文物处。
