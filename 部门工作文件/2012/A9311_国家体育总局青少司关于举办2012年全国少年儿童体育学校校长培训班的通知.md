# 国家体育总局青少司关于举办2012年全国少年儿童体育学校校长培训班的通知

各省、自治区、直辖市体育局：

根据国家体育总局2012年培训工作计划，由体育总局青少司主办、体育总局教练员学院承办的全国少年儿童体育学校校长培训班定于11月在北京举办，现将有关事宜通知如下：

**一、**培训目的

了解我国少年儿童体育学校办学政策与发展趋势，交流体校训练工作与运动员文化教育经验，提高体校校长综合素质与科学治校能力。

**二、**培训对象

全国少年儿童体育学校校级管理干部100名。

**三、**培训时间及地点

（一）时间：2012年11月19日至23日。19日全天报到，20日至22日培训，23日12：00前离会。

（二）地点：国家体育总局教练员学院

地址：北京市海淀区信息路48号

**四、**考核与结业

根据培训期间听讲、笔记、讨论、出勤等情况进行综合考核。合格者将获体育总局教练员学院颁发的结业证书。

**五、**培训费用

培训费、食宿费由体育总局负担，往返交通费由学员所在单位负担。

**六、**报名程序

由各省（区、市）体育局根据名额分配表（见附件2）推荐少年儿童体育学校校级管理干部，填写报名表（见附件3），于11月15日之前报至国家体育总局教练员学院。

乘车路线

**（一）**　线路一：北京西站-北京体育大学

从“北京西站”乘坐320路、特6路公交车至“清华大学西门”下车，换乘公交车运通105、运通205、717、681至“北京体育大学”。

**（二）**　线路二：首都机场-北京体育大学

从“首都机场”乘坐机场快轨到“东直门”下车，换乘城铁13号线到“上地站”下车，出站后南行500米到北京体育大学北门。

**（三）**　线路三：北京站-北京体育大学

从“北京站”乘坐地铁2号线至“西直门站”下车，换乘城铁13号线至“上地站”，出站后南行500米到北京体育大学北门。

**（四）**　线路四：火车南站-北京体育大学

从火车南站乘坐地铁4号线至北京大学东门下车，换乘105、656路公交车至“北京体育大学”。
