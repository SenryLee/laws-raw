# 中国全球定位系统应用协会关于举办北斗卫星导航应用与车联网培训班的通知

## 中国全球定位系统应用协会关于举办北斗卫星导航应用与车联网培训班的通知（中定协〔2012〕26号）

各有关单位：

随着我国自主卫星导航系统的建立，促进了智能交通产业快速发展。智能运输系统是实现运输业的繁荣与可持续发展的先进技术，卫星导航信息服务对保障智能交通运输安全发挥着重要作用。为了提高交通运输生产的智能化程度，帮助交通运输管理部门、卫星导航系统软件提供商、地理信息服务商掌握北斗导航系统在车联网中的应用技术，中国全球定位系统技术应用协会决定在首届中国卫星导航与位置服务年会期间举办“北斗卫星导航应用与车联网”培训班，请各有关单位积极组织相关人员参加。现将具体情况通知如下：

**一、**研修内容

（一）北斗卫星导航系统应用产业现状与前景；

（二）北斗卫星导航系统建设与应用技术研究最新进展；

（三）北斗卫星导航系统在车联网中应用；

（四）智能交通与车联网；

（五）车联网发展；

（六）车联网应用的机制与策略；

**二、**参加对象

各海运、航空、铁路、公安交通部门的管理人员和技术骨干，各卫星导航技术与应用的相关科研院所，从事卫星导航设备生产和技术服务的企业相关从业人员。

**三、**时间及地点

时间：2012年9月22日-23日（21日报到）

地点：北京市（具体地点另行通知）

**四、**参加费用

培训费1800元/人，食宿统一安排，费用自理。欢迎培训结束后直接注册报名参加“首届中国卫星导航与位置服务年会”。

**五、**研修方式

本次培训班将邀请卫星导航行业的知名专家教授采取讲座、疑难问题解答、现场交流相结合的方式进行。

**六、**考核与结业

完整参加所有培训内容的学员，可获得中定协颁发的“北斗卫星导航应用与车联网”研修班证书。作为相关专业人员工作和继续教育的重要依据。

**七、**其他注意事项

1．请各单位根据实际情况转发下属单位，组织人员参加；

2. 学习期间相关事宜由主办方统一安排；

3. 参会代表请务必携带身份证或其他有效证件，并携带一寸免冠照片两张；

4. 报名参加研修班的人员，请8月17日前将报名回执表传真至报名处。届时根据报名回执表发报到通知，告知研修班具体报到地址、乘车路线等事项。

附件：北斗卫星导航应用与车联网培训班报名表
