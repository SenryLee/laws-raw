# 国家体育总局办公厅关于举办2012年冬季项目青少年体育教练员体能训练专项培训班的通知

河北、内蒙古、辽宁、吉林、黑龙江、新疆体育局：

根据国家体育总局2012年培训工作计划，由国家体育总局青少年体育司主办、国家体育总局教练员学院承办、黑龙江体育局协办的2012年冬季项目青少年体育教练员体能训练专项培训班定于4月23日-27日在黑龙江省哈尔滨市举办，现将有关事宜通知如下：

**一、**培训目的

学习冬季项目科学训练相关理论，了解现代运动训练发展动态，掌握现代青少年运动员体能训练的最新方法与手段，促进教练员训练观念更新，提高科学执教能力。

**二、**培训时间及地点

（一）时间：2012年4月23日-27日，23日报到，24日-26日培训，27日12：30前离会。

（二）地点：哈尔滨冰上基地综合楼一楼。

地址：黑龙江省哈尔滨市南岗区南通大街128号。

**三、**分配名额

河北省5人，内蒙古自治区10人，辽宁省15人，吉林省20人，黑龙江省35人，新疆维吾尔自治区15人。

**四、**培训对象

从事冬季项目业余训练的教练员，招生人数100人。

**五、**考核与结业

根据培训期间听讲、笔记、出勤等情况对学员进行综合考核。合格者将获得国家体育总局教练员学院颁发的结业证书。

**六、**报名程序

由单位推荐冬季项目的青少年体育教练员，填写报名表（见附件3），于4月17日之前报至国家体育总局教练员学院。

**七、**经费

培训费、食宿费由国家体育总局负担，往返交通费由学员所在单位负担。

**八、**其他事宜

请携带身份证等有效证件，学员一律凭身份证办理入学手续。
