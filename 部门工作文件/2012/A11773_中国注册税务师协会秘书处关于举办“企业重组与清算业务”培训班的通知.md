# 中国注册税务师协会秘书处关于举办“企业重组与清算业务”培训班的通知

## 中国注册税务师协会秘书处关于举办“企业重组与清算业务”培训班的通知（中税协秘发[2012]049号）

各省、自治区、直辖市和计划单列市注册税务师协会：

为帮助注册税务师、事务所从业人员熟练掌握企业重组与清算流程和相应的会计核算、相关法律和税收政策，掌握企业清算与企业重组业务的差别，提高应对企业清算的业务代理水平，规避清算业务的代理风险，中国注册税务师协会决定举办“企业重组与清算业务”培训班，培训报名将继续通过系统进行网上报名，现将有关事项通知如下：

**一、**培训内容及授课教师

1. 企业重组税收政策和案例解析（企业所得税、个人所得税）--辛连珠；

2. 企业清算税收政策解析--高金平；

3. 企业重组税收政策和案例解析（其他税种）--陈玉琢；

4. 企业重组与清算会计--赵建华；

5. 企业重组与清算相关法律知识（公司法、破产法等）--袁庚森。

**二、**培训时间

2012年9月24日-29日（9月24日报到，25日-28日全天上课，29日返程）。

**三、**培训地点

国家税务总局税务干部进修学院（江苏省扬州市扬子江北路515号）。

**四、**参加人员

税务师事务所所长、业务骨干。

**五、**收费标准

食宿费：1500元/人/期；培训费：950元/期（含教师授课费、讲义和教材费用、教室使用费用等）。

1. 本期培训班通过会员管理信息系统--面授培训报名管理子系统（试运行）进行网上报名，网址为：http：//is.cctaa.cn/odps/。

2. 请各地方协会按照培训班名额分配表（见附件）所列人数要求，积极做好参加培训人员的报名组织工作，要求报名参训人员无特殊原因，必须参加，不得缺席，不得随意换人。
