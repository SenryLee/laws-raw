# 农业部农业机械试验鉴定总站关于举办全国农机质量投诉工作培训班的通知(2012)

## 农业部农业机械试验鉴定总站关于举办全国农机质量投诉工作培训班的通知（农机鉴[2012]111号）

各省、自治区、直辖市农机质量投诉监督站：

为了规范全国农机质量投诉处理工作，依法处理农机用户投诉，进一步做好农机质量投诉工作，落实加强农业机械质量投诉监督管理工作的通知精神，切实维护广大农机用户及农机企业的合法权益，我站定于2012年8月6日～9日在新疆乌鲁木齐举办全国农机质量投诉工作培训班，现就有关事宜通知如下：

**一、**培训内容

（一） 通报2011年全国农机质量投诉情况；

（二） 解读《关于进一步加强农业机械质量投诉监督管理工作的通知》；

（三） 学习农机质量投诉受理和处理的相关知识；

（四） 进一步加强农机质量投诉监督工作的要求；

（五） 培训《农机质量投诉工作信息管理系统》；

（六） 农机质量投诉受理和处理经验交流。

**二、**参会人员

各省、自治区、直辖市农业机械质量投诉监督站具体负责质量投诉工作的人员，最多不超过2人，请勿超员。

**三、**时间和地点

培训时间：2012年8月6日报到，7日-8日培训，9日早餐后离会。

培训地点：新疆煤炭宾馆

饭店地址：新疆乌鲁木齐市友好南路458号

饭店电话：0991-4511933
