# 中国注册税务师协会秘书处关于举办2012年第二期A级、AA级税务师事务所所长培训班的通知

## 中国注册税务师协会秘书处关于举办2012年第二期A级、AA级税务师事务所所长培训班的通知（中税协秘发[2012]046号）

北京、天津、内蒙古、吉林、黑龙江、上海、江苏、浙江、宁波、安徽、厦门、江西、山东、青岛、湖北、湖南、深圳、广西、重庆、四川、贵州、云南、陕西、青海和新疆注册税务师协会：

为使税务师事务所所长掌握注册税务师执业准则，规范事务所人员执业行为。提高事务所的业务质量管理，具体掌握业务营销手段和市场开发的办法，拓展事务所的业务范围，以及通过管理类培训使事务所所长提升领导综合素质，提高管理效率。中国注册税务师协会决定举办2012年第二期A级、AA级税务师事务所所长培训班，培训报名将继续通过系统进行网上报名，现将有关事项通知如下：

**一、**培训内容及授课教师

1. 把握机遇 迎接挑战，全面提升注册税务师专业能力--王文彦；

2. 企业所得税纳税申报鉴证业务等三个指导意见解读--郭洪荣；

3. 税务师事务所的市场化业务分析--曲军；

4. 当前宏观经济形势及热点问题分析--曾志耕；

5. 国际会计师事务所的经营与管理--吴嘉源；

6. 税务师事务所的战略定位与谈判策略--李记有。

**二、**培训时间

2012年9月17日-22日（9月17日报到，18日-21日全天上课，22日返程）。

**三、**培训地点

西南财经大学财税培训中心二校区（国家检察官学院四川分院）。地址：四川省成都市麓山大道二段（麓山国际社区旁）。

**四、**参加人员

A级、AA级事务所所长（副所长）。

**五、**收费标准

食宿费：1400元/人/期；培训费：950元/期（含教师授课费、讲义和教材费用、教室使用费用等）。

**七、**报名方式

1. 本期培训班通过会员管理信息系统--面授培训报名管理子系统（试运行）进行网上报名，网址为：http：//is.cctaa.cn/odps/。

2. 执业与非执业注册税务师使用注册税务师安全盘（U key）登录该系统进行报名。从业人员由所属税务师事务所通过事务所安全盘（U key）进行报名。

3. 税务师事务所须对本所的培训班报名表审核后提交地方税协，地方税协确认后视为报名成功。具体操作方法详见系统首页的《面授培训报名管理子系统操作说明》。

如报名过程中遇到系统操作问题，请咨询中税协信息部。咨询电话：（010）68451149；咨询QQ：786496627。

**八、**具体要求

1. 根据中税协领导指示，2012年所有培训班报名参训的执业注册税务师必须完成网上个人信息采集方可报名，凡未完成者暂不应予以报名，请各地方协会在统计参训人员名单时严格把关，认真核对后上报中税协培训部。

2. 请各地方协会按照培训班名额分配表（见附件）所列人数要求，积极做好参加培训人员的报名组织工作，要求报名参训人员无特殊原因必须参加，不得缺席，不得随意换人。

本期培训班报名工作将于9月7日截止，届时系统将关闭本培训班的报名功能，凡逾期未报名的地区视为自动放弃。另外，本次培训班以地方税协通过系统确认的报名表为准，向西南财经大学财税培训中心报名的视为无效。

3. 9月17日报到当天有工作人员成都机场、成都火车东站和火车北站接站。请各地方协会将参加本期培训班人员的航班、车次信息汇总后于9月12日前告知西南财经大学财税培训中心联系人。逾期不报的视为不需接站，自行前往。如有提前报到的请按所给地址自行前往。往返机票（车票）请自理。

报到当天开通的接站电话：

（2）成都火车站接站人：13982227892

4. 请参加培训的人员携带有效身份证件，于报到时主动向工作人员出示，以便完成报到手续。

5. 非执业会员需交纳培训费。培训班结束后，中税协将统一发放《学时证明》。
