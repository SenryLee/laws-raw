# 国家体育总局武术中心关于举办2012年全国泰拳教练员、裁判员培训班的通知

各省、自治区、直辖市，总参军训部体育局，各行业体协，体育院校，俱乐部：

为进一步加强泰拳教练员、裁判员的队伍建设，培养后备力量，促进泰拳项目在我国的发展，国家体育总局武术运动管理中心定于2012年12月10-14日在广州南航碧花园举办全国泰拳教练员、裁判员培训班。邀请泰国专家进行授课，现将有关事宜通知如下：

**一、**报名条件：

1、思想品德优良，作风正派，身体健康，遵守教练员、裁判员守则。

2、遵守国家体育总局及武术运动管理中心有关赛风赛纪等管理规定。

3、教练员应具有一定的泰拳技术水平，精通泰拳竞赛规则和裁判法并能够准确熟练地运用。

4、裁判员应具有较高的泰拳裁判理论水平、丰富的实践经验和组织泰拳竞赛裁判工作的能力；掌握泰拳竞赛编排方法。

**二、**考试内容：

1、理论考试（泰拳竞赛规则、裁判法）。

2、技术考试。

**三、**考试方法：

本次考试将采用笔试、技术考试、实践评判等方法进行。

**四、**要　求：

请各单位推荐符合条件的裁判员并填写泰拳教练员、裁判员报名表，务必于2012年12月5日前报经国家体育总局武术运动管理中心训练竞赛三部审核并电话确认，逾期不予办理。地　址：北京市朝阳区安定路3号，邮编：100029
