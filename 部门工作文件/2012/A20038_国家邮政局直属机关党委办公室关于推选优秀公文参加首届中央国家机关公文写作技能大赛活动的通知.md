# 国家邮政局直属机关党委办公室关于推选优秀公文参加首届中央国家机关公文写作技能大赛活动的通知

各司局、直属各单位党支部（总支）：

近日，中央国家机关工委发出通知，为切实提高中央国家机关广大干部职工的写作技能，推动岗位建功、创先争优活动，以优异成绩迎接党的十八大胜利召开，将举办“当好主力军、迎接十八大、建功十二五” 首届中央国家机关公文写作技能大赛。根据工委统一部署，国家局办公室与机关党委将联合评比推选优秀公文参加大赛。现就有关事项通知如下：

**一、**活动主题

本次大赛的主题是“当好主力军、迎接十八大、建功十二五”。

**二、**竞赛时间

2012年3月至8月底

**三、**参赛人员

凡国家局机关各部门正式职工均可参赛

**四、**作品要求

（一）竞赛文种

共16个大类

1、请示报告类

2、信息简报类

3、通知通报类

4、决定决议类

5、调研报告类

6、计划方案类

7、领导讲话类

8、会议纪要类

9、总结报告类

10、指导意见类（包括汇报述职等）

11、工作规划类

12、规章制度类

13、公函类

14、经验材料类

15、学习体会类

16、贺词贺信类

（二）作者及作品成文期限

1、参赛作品的作者一般为个人或调研组、起草组，不以部门单位名义参赛，每篇作品须附上1000字左右的写作体会。

2、参赛的正式公文，成文时间为2011年1月1日至2012年3月31日期间。

（三）作品内容

紧紧围绕贯彻实施“十二五”规划进行撰写。领导讲话类的公文及题目，原则上以反映公文内容为主，不出现领导同志姓名。

（四）作品的基本要求

1、观点鲜明正确，充分体现党的路线方针政策。

2、格式规范统一，符合国家统一的标准公文写作格式。

3、内容结构完整、逻辑清晰。

4、行文生动流畅，文风端正。

5、事理交织辉映，论点准确，实例丰盈。

6、参赛公文一律不得涉密。

**五、**评比及奖励

工委对此次竞赛活动设立个人奖和集体奖，以个人奖为主。组成评审委员会评奖，奖项分别为优秀奖、单项奖和组织奖。

1、优秀奖：按规定名额上报的作品，一般授予优秀奖并授予证书。

2、单项一、二、三等奖：每类公文设一等奖5名，奖金2000元；二等奖10名，奖金1000元，三等奖15名，奖金500元。

3、组织奖：对入选单项奖较多的前10个部门实施奖励，奖金5000元。

为推选出好作品，国家局组成评选小组对各部门上报作品进行初选。评选小组人员组成：

组长：韩瑞林、张云峰

组员：沈鸿雁、杨永春、刘贵军、邓治国

**六、**实施步骤与阶段划分

第一阶段：安排部署阶段（2月25日-3月10日）。对竞赛活动作出部署。

第二阶段：创作写作阶段（3月11日-15日）。主要是个人进行公文写作或修改。

第三阶段：推选参赛作品阶段（3月16日-31日）。3月19日前各单位推荐优秀公文报办公室；23日前评选小组邀请有关专家一起评选参赛作品，至少评出16类公文各2篇共32篇，提交局领导同意，返回各单位；28日前入选作品作者撰写1000字左右的写作体会，报办公室；30日前机关党委将推选作品报中央国家机关工委。

第四阶段：评审表彰和成果推广阶段（4月1日-7月31日）。工委组织评审委员会对参赛作品进行评审，并召开颁奖大会进行奖励和表彰。之后网上举办“获奖公文作品展”，编撰出版《中央国家机关优秀公文选编》。

**七、**有关要求

1、首届中央国家机关公文写作技能大赛是开展岗位建功、创先争优的具体实践活动，各单位一定要高度重视，积极推荐作品参赛。

2、入选作品填写《公文写作技能大赛参赛作品登记表》，附1000字左右的写作体会。
