# 中国证券业协会关于举办2012年第三期保荐代表人面授培训班的通知

各保荐机构、律师事务所、会计师事务所：

根据中国证券业协会2012年培训班计划，中国证券业协会培训中心定于2012年9月6-7日在成都金牛宾馆举办第三期保荐代表人面授培训班。现将有关报名事项通知如下：

**一、**培训对象

1、各保荐机构按指定名额推选本公司的保荐代表人（名额详见附件1）。

2、本期培训班共为律师事务所、会计师事务所提供培训名额62人，报名额满为止。具体应为排名靠前的40家律师事务所及52家具有证券业务资格的会计师事务所（名单详见附件2）。

**二、**培训主要内容

1、新股发行制度改革讲解；

2、IPO审核中的问题；

3、首发企业财务相关问题；

4、上市公司再融资政策解读；

5、再融资财务审核的要点与问题；

6、创业板发行审核非财务问题；

7、创业板发行审核财务问题；

8、公司债券发行审核解析。

**三、**培训时间和地点

1、报到时间：2012年9月5日15：00－19：00。

报到地点：成都金牛宾馆-迎宾苑总台

2、培训时间：2012年9月6-7日。

培训地点：成都金牛宾馆娇子厅（成都市金牛区金泉路2号；电话：028-87306000）。

**四、**培训师资

中国证监会领导、证监会相关部门负责同志。

**五、**培训费用及食宿安排

1、培训费用1400元/人/2天，要求缴纳现金，但如异地条件允许，将同时提供刷卡缴费选择。

2、食宿安排： 食宿由成都金牛宾馆统一安排，住宿费：280元/天/单间-450元/天/单间；餐费：200元/天（早餐40元，午、晚餐80元），费用学员自理。

**六、**培训要求

参加培训的人员请提前安排好工作，认真学习，按时签字考勤，中途不得请假。

**七、**报名注意事项

1、请各单位按照要求，安排相应人员参加。

2、报名截止日为8月24日，过时及名额已满系统将自动关闭。

3、本期培训班将通过网上报名系统进行，协会不再接收其他形式报名。报名时请点击本通知下方“培训班网上报名”并通过报名系统填报单位及个人的相关报名信息，填报完成后，系统会提示是否报名成功。

4、上述应参训人员及已报名人员，如确有特殊情况不能参加，请于8月24日前以书面形式说明原因并加盖公章，传真至010-66290936，我们将视具体情况进行处理。

联系电话： 010-66290935　　66290932。

技术支持电话：13911331709。
