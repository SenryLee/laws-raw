# 农业部办公厅关于举办2012年全国水稻育插秧机械化技术培训班的通知

## 农业部办公厅关于举办2012年全国水稻育插秧机械化技术培训班的通知（农办机〔2012〕1号）

各有关省、自治区、直辖市及计划单列市农机（农业、农牧）局（厅、委、办）：

为做好水稻育插秧机械化示范项目建设工作，加快推进水稻生产全程机械化，定于2月中旬在广东省江门市召开2012年全国水稻育插秧机械化技术培训班。现将有关事宜通知如下：

**一、**主要内容

（一）总结交流2011年水稻育插秧机械化工作，研究部署2012年工作重点和主要任务。

（二）部署做好2012年水稻育插秧机械化示范项目工作。

（三）开展水稻机械化育插秧技术培训，参观机械化育插秧作业现场。

**二、**参加人员

（一）22个省（区、市）农机管理局分管水稻生产机械化的处室负责同志，2012年50个新建水稻育插秧机械化示范项目县农机管理局的主管人员各1名。名额分配见附件1。

（二）农业部农机推广总站有关负责同志，农业部水稻生产机械化专家组有关成员。

（三）部分水稻插秧机生产企业代表。

**三、**时间地点

时间：2012年2月16日～17日，会期两天，15日报到。

地点：广东省江门市逸豪酒店（广东省江门市迎宾大道118号，电话：0750-3928888）。

**四、**有关要求

（一）请各有关省（区、市）农机管理局对2011年水稻生产机械化工作情况进行总结，内容包括：基本情况、技术路线、主要做法、成效经验、存在问题、对策建议以及2012年计划目标等。以省为单位，组织辖区内新建项目县的参训人员报名，填报《培训班报名表》（附件2）。请于2月6日前，将上述总结材料和报名表以电子邮件发送至农业部农业机械化管理司生产管理处，联系人：李庆东，联系电话：010-59192814，电子邮箱：njhsglc@agri.gov.cn 。

（二）本次培训班的会务工作委托广东省农业厅农业机械化管理办公室负责。江门市离广州机场约100公里，有需要接站的参会人员，请提前预约。
