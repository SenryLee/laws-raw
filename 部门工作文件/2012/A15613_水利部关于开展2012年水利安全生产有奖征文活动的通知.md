# 水利部关于开展2012年水利安全生产有奖征文活动的通知

## 水利部关于开展2012年水利安全生产有奖征文活动的通知（办安监[2012]200号）

部直属各单位，各省、自治区、直辖市水利（水务）厅（局），各计划单列市水利（水务）局，新疆生产建设兵团水利局：

为贯彻落实《国务院办公厅关于继续深入扎实开展“安全生产年”活动的通知》（国办发〔2012〕14号）的精神，进一步加强安全生产宜传教育工作，在水利行业营造“科学发展、安全发展”和“关爱生命、关注安全”的舆论环境和氛围，促进水利安全生产和安全文化建设，根据《水利部办公厅关于开展水利系统安全生产月活动的通知》（办安益（2012）144号）的要求，经研究，决定2012年在全国水利系统开展以“人人关爱生命，人人关注安全”为主题的安全生产有奖征文活动.现将有关本项通知如下：

**一、**组织领导

本次有奖征文活动由水利部安全监督司主办，中国水利报社承办。征文活动成立组委会，组委会办公室设在中国水利报社，负责收集、评选征文稿件，颁发证书、奖金和汇编优秀征文等工作，

**二、**征文时间

2012年6月15日至7月30日。

**三、**征文内容和文章体栽要求

紧紧围绕“人人关爱生命，人人关注安全”的主题，贯彻“安全第一，预防为主，综合治理”的方针，宣传“以人为本、安全发展”的理念，通过深入开展“安全生产年”活动，围绕“一树立、三坚持、三强化”，抓好水利安全生产“三项行动”和“三项建设”，促进水利安全生产形势持续稳定向好，为水利又好又快发展提供坚实的安全保障。具体要求：

1.理论探讨。紧密联系本单位实际，有一定思想理论水平，反映落实安全责任制与加强亊故防范、创新体制机制与强化安全监管、加强安全保障能力建设与夯实安全基础工作、加强安全宜传教育与促进安全文化建设、安全生产形势分析与对策建议等方面的工作实践与经验总结的文章。

2.经验交流。贯彻落实国务院安全生产会议和文件精神、贯彻落实2012年水利安全生产工作要点的有力的措施，强化安全监管职能和队伍建设、安全生产规章制度建设、落实安全生产监管职责和主体责任、提髙安全生产监管水平等经验及取得的成绩的文章。

3.先进事迹，貼近基层、贴近群众、贴近生活，发生在自己身边的有关水利安全生产的先进亊迹和先进人物的文章。

4.警钟长鸣。生产安全事故的深刻教训等内容的文章。

5.认识体会。一线安全生产工作者及水利职工，从事安全生产工作的感悟和体会的文章。

6.征文要以纪实体写法，力求观点鲜明，语言流畅，内容充实，贴切实际，尤其欢迎故事性强的作品。要求字数控制在2000字以内。征文内容不能虚构，严禁抄袭。

**四、**征文评选和奖励

（―）由征文活动组委会办公室组织有关专家对征文稿件进行评选，评选出一、二、三等奖和优秀奖，颁发获奖证书和奖金。评选活动结束后，将汇编优秀征文。

1、一等奖5名，奖金各1000元；

2、二等奖20名，奖金各500元；

3、三等奖50名，奖金各300元；

4、优秀奖100名，奖金各100元，

（二）此次征文活动设组织奖20名，按照各单位稿件数量、单位有关负责人和专（兼）职安全生产监管人员摈稿情况、获奖稿件等次等进行评选，并颁发证书，

（三）征文来稿将在《中国水利报》和水利部网站选登。

**五、**活动要求

（―）各单位要高度重视此次征文活动，将组织征文工作作为开展“安全生产年”活动的一项重要内容，积极做好有关组织宜传工作。要根据水利特点和本地区、本单位实际，以各级领导、安全生产监督管理人员、一线生产施工作业人员等为重点，发动各级领导干部和广大职工踊跃参加，通过组织征文活动达到深入宣传安全生产，进一步提髙千部职工对安全生产重要性的认识和进章守纪自觉性，在全行业形成关注安全、关爱生命的浓厚氛围，促进水利安全生产工作。

（二）请于2012年7月30日前将征文稿件连同有奖征文作者基本情况（基本情况包括征文超目、作者单位、姓名、职务成职称、职业、联系电话、联系地址、邮编、电子邮箱地址和传真号码等；），发送电子邮件到中国水利报社，来信标题格式为作品题目十作者单位十作者姓名。
