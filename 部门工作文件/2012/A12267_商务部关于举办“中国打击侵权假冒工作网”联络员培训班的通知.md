# 商务部关于举办“中国打击侵权假冒工作网”联络员培训班的通知

各省、自治区、直辖市、计划单列市及新疆生产建设兵团打击侵权假冒工作领导小组办公室，全国打击侵权假冒工作领导小组成员单位：

为了落实全国打击侵犯知识产权和制售假冒伪劣商品工作领导小组第三次全体会议精神，共同办好中国打击侵权假冒工作网，兹定于8月30-31日在北京举办网站联络员培训班。现就有关事项通知如下：

**一、**培训时间

8月30-31日，30日报到，31日全天培训。

**二、**培训地点

北京温都水城酒店（北京市昌平区北七家镇王府街55号）

**三、**参加人员

（一）各省、自治区、直辖市、计划单列市、新疆生产建设兵团领导小组办公室负责信息宣传的处级干部1名；

（二）全国打击侵权假冒领导小组成员单位信息员；

（三）“中国打击侵权假冒工作网”编辑部工作人员。

**四、**培训内容

（一）通报中国打击侵权假冒工作网站开通以来的运行情况，对进一步做好网站的运行维护工作提出要求；

（二）听取联络员对于网站维护运行的意见、建议；

（三）专家讲解互联网信息传播的特点、网站新闻信息的技巧、宣传推广等知识。

**五、**培训费用及报名

京外人员交通费用自理，食宿费用由会议承担。

各单位参加培训人员名单请于8月23日下班前报送。
