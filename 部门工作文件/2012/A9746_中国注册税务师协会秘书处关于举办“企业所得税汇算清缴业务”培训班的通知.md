# 中国注册税务师协会秘书处关于举办“企业所得税汇算清缴业务”培训班的通知

## 中国注册税务师协会秘书处关于举办“企业所得税汇算清缴业务”培训班的通知（中税协秘发[2012]059号）

各省、自治区、直辖市和计划单列市注册税务师协会：

为帮助注册税务师熟练掌握企业所得税汇算清缴流程、所得税优惠管理与财产损失申报审批程序以及与企业所得税汇算清缴有关的法律法规，指导注册税务师更好地完成企业所得税汇算清缴代理工作，提高注册税务师企业汇算清缴的业务代理能力和水平，中国注册税务师协会决定举办“企业所得税汇算清缴业务”培训班，培训报名将继续通过系统进行网上报名，现将有关事项通知如下：

**一、**培训内容及授课教师

1. 企业所得税汇算清缴申报代理实务--陈玉琢；

2. 企业所得税优惠与资产损失管理--陈斌才；

3. 企业重组业务所得税申报管理--辛连珠；

4. 企业重组业务其他各税申报管理--高金平；

5. 涉税相关民商法律的适用--李文波。

**二、**培训时间

2012年11月28日-12月3日（11月28日报到，11月29日-12月2日全天上课，12月3日返程）。

**三、**培训地点

国家税务总局税务干部进修学院（江苏省扬州市扬子江北路515号）。

**四、**参加人员

税务师事务所所长、业务骨干。

**五、**收费标准

食宿费：1500元/人/期；

培训费：950元/期（含教师授课费、讲义和教材费用、教室使用费用等）。

**七、**报名方式

1. 本期培训班通过会员管理信息系统--面授培训报名管理子系统进行网上报名，网址为：http：//is.cctaa.cn/odps/。

2. 执业与非执业注册税务师使用注册税务师安全盘（U key）登录该系统进行报名。其他从业人员由所属税务师事务所通过事务所安全盘（U key）进行报名。

3. 税务师事务所须对本所的培训班报名表审核后提交地方税协，地方税协确认后视为报名成功。具体操作方法详见系统首页的《面授培训报名管理子系统操作说明》。

如报名过程中遇到系统操作问题，请咨询中税协信息部。咨询电话：（010）68451149；咨询QQ：786496627。

**八、**具体要求

1. 根据中税协领导指示，2012年所有培训班报名参训的执业注册税务师必须完成网上个人信息采集方可报名，凡未完成者暂不予以报名。

2. 请各地方协会按照培训班名额分配表（见附件）所列人数要求，积极做好参加培训人员的报名组织工作，要求报名参训人员无特殊原因必须参加，不得缺席，不得随意换人。

本期培训班报名工作将于11月21日截止，届时系统将关闭本培训班的报名功能，凡逾期未报名的地区视为自动放弃。另外，本次培训班以地方税协通过系统确认的报名表为准，向税务干部进修学院报名的视为无效。

3. 11月28日报到当天有工作人员在南京机场、南京火车站及火车南站、扬州火车站、镇江火车站及火车南站接站。请各地方协会将参加本期培训班人员的航班、车次信息汇总后于11月25日前告知税务干部进修学院联系人。逾期不报的视为不需接站，自行前往。如有提前报到的请按所给地址自行前往。往返机票（车票）请自理。
