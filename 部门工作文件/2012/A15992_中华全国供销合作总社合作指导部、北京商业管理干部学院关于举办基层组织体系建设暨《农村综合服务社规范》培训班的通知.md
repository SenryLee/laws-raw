# 中华全国供销合作总社合作指导部、北京商业管理干部学院关于举办基层组织体系建设暨《农村综合服务社规范》培训班的通知

各省（自治区、直辖市）、计划单列市、新疆生产建设兵团供销合作社，有关地、市、县供销合作社：

基层组织体系建设是中华全国供销合作总社（以下简称总社）2012年的重点工作。为了深入贯彻总社的战略部署，进一步加强系统工作指导，推进总社督办的重点工作，强化基层组织体系建设，总结交流各地基层经营服务网络的建设经验，引导各地推进综合服务社标准化建设，进一步加快专业合作社示范社建设步伐，总社合作指导部与北京商业管理干部学院决定分期分批举办基层组织体系建设暨《农村综合服务社规范》培训班。现将有关事宜通知如下：

**一、**培训宗旨

推动供销合作社基层组织体系建设，发挥《农村综合服务社规范》的标杆作用，夯实供销合作社在农村工作的基础。

**二、**培训内容

1、总社加强系统工作指导及基层组织体系建设的战略部署；

2、基层社改革发展与基层组织体系建设；

3、专业合作社示范社建设管理及发展经验；

4、农村综合服务社发展现状、存在问题及工作措施；

5、《农村综合服务社规范》主要框架和要求；

6、农村综合服务社的建设和管理；

7、供销合作社涉农项目申报及管理；

8、实地考察与经验交流。

**三、**培训方式

政策解读、专家讲授、典型经验剖析、交流研讨、实地考察。

**四、**培训师资

总社有关部门领导，《农村综合服务社规范》起草人，有关专家等。

**五、**培训对象

各级供销合作社主管主任及合作指导处或相关处室处长，社属企业经营管理人员，专业合作社、农村综合服务社（中心）及基层社负责人。

**六、**培训时间、地点

2012年6月27日至30日（27日报到），厦门市

**七、**培训费用

培训及资料费每人1000元，食宿统一安排，费用自理。

**八、**培训证书

请参加人员携带两张2寸免冠照片以办理培训结业证书。

**九、**报名及相关事宜

请各省（自治区、直辖市）、计划单列市供销合作社统一转发文件并组织报名，并由主管处长带队参加培训。各报名单位请将报名回执传真或发电子邮件至联系人处。
