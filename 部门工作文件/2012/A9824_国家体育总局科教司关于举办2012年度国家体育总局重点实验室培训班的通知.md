# 国家体育总局科教司关于举办2012年度国家体育总局重点实验室培训班的通知

各重点实验室：

为学习领会“全国科技创新大会”精神，进一步提高重点实验室的科技创新能力和管理水平，加强人才队伍建设，增进科研人员间的交流，促进各实验室更好的开展国家队科研攻关与科技服务工作，经研究，我司决定召开重点实验室管理、科研人员培训班，培训班由北京体育大学承办，有关事宜通知如下：

**一、**时间

2012年11月12－16日，12日报到，16日离会。

**二、**地点

北京体育大学科研中心。

**三、**培训内容

（一）介绍“协同创新”理念，企业与科研单位联合攻关，交叉学科研究成果等内容。

（二）介绍国家级重点实验室运行管理内容。

（三）介绍总局重点实验室评估指标研究情况。

（四）进行座谈研讨、实地参观。

**四、**培训人员

请各重点实验室主任和科研骨干1人参加培训。

**五、**培训经费

培训期间的培训费、食宿费、资料费等由培训班统一负担，差旅费自理。

**六、**报名报到

请于2012年10月31日前将参加培训人员报名表（附件1）加盖公章后传真至北京体育大学科研中心。

请于2012年11月12日至北京体育大学培训中心报到，地址：北京市海淀区信息路48号。联系人：汪蕾，联系电话及传真：010－62989211。

国家体育总局科教司

2012年10月18日
