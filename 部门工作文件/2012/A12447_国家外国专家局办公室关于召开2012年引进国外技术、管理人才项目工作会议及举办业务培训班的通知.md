# 国家外国专家局办公室关于召开2012年引进国外技术、管理人才项目工作会议及举办业务培训班的通知

各省、自治区、直辖市及副省级城市外国专家局，新疆生产建设兵团外国专家局，国务院有关部委、直属机构、集团公司引智归口管理部门：

为进一步加强引进国外技术、管理人才项目工作，我局定于2012年8月29日至31日在福建省福州市召开2012年引进国外技术、管理人才项目工作会议，举办业务培训班。主要内容为：总结近年来引进国外技术、管理人才项目工作情况；部署今明两年工作任务；交流工作经验，探讨如何做好引智项目，多出引智成果；进行引进国外技术、管理人才项目工作培训。安排交流发言的单位另行通知，现将有关事项通知如下：

**一、**会议日程： 2012年8月29日报到；8月30日会议；8月31日培训；9月1日离会。

**二、**会议地点、地址：福建省福州市五四路130号 闽江饭店

**三、**会议代表：各省、自治区、直辖市、副省级城市外国专家局及新疆生产建设兵团外国专家局各2人（局长1人，从事专家项目工作的同志1人）。国务院有关部门、直属机构引智归口管理部门各1人。集团公司专项引智归口管理部门1-2人。

**四、**会务安排：此次会议的会务工作委托福建省外国专家局承担。请将参会回执于8月20日之前传真至福建省外国专家局。

**五、**会议费用：会议期间的食宿、交通费用由国家外国专家局负担，差旅费由参会代表单位负担。
