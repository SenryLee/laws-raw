# 农业部农机监理总站关于举办农机事故预防与统计分析培训班的通知

## 农业部农机监理总站关于举办农机事故预防与统计分析培训班的通知（农机监（执）发〔2012〕4　号）

各省、自治区、直辖市及计划单列市农机安全监理站（所、队），新疆生产建设兵团农机监理站：

为加强农机事故预防与处理，提高事故统计报告和分析评估质量，按照农业部有关工作安排，定于2012年4月下旬在北京举办农机事故预防与统计分析培训班。现将有关事项通知如下：

**一、**培训内容

（一）事故应急管理与处置

（二）农机事故统计与分析

（三）交流农机事故统计与控制考核指标落实工作

（四）解读《农业机械实地安全检验办法》

**二、**参加人员

各省（区、市）农机安全监理站站长（所长）和事故统计人员。

**三、**时间、地点

时间： 4月24-25日，23日报到

地点：北京商务会馆

地址：北京市丰台区右安门外玉林里1号

电话：010-63292244

乘车路线：西站乘122路到大观园下车，南站乘458路到右安门西下车。

**四、**有关要求

请各单位于4月15日前将参训人员名单（见附件）、本地区2011年农机事故统计分析报告及2012年农机安全生产控制考核指标分解情况发电子邮件或传真至我站执法监管处。
