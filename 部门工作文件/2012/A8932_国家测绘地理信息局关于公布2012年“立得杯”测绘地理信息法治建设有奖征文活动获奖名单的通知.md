# 国家测绘地理信息局关于公布2012年“立得杯”测绘地理信息法治建设有奖征文活动获奖名单的通知

各省、自治区、直辖市测绘地理信息行政主管部门：

为庆祝《测绘法》修订颁布10周年，弘扬法治理念和法治文化，营造测绘地理信息事业发展的良好法治环境，按照2012年测绘法宣传日活动安排，今年6月国家测绘地理信息局组织开展了“立得杯”测绘地理信息法治建设有奖征文活动。活动得到了社会各界的积极响应和热情参与。

经专家评审委员会评议，评选出个人一等奖2名、二等奖3名，三等奖5名，鼓励奖10名，并根据组织参赛情况评定出优秀组织奖1名（名单见附件）。

所有获奖者将获得由国家测绘地理信息局颁发的证书和立得空间信息技术股份有限公司提供的奖品。中国测绘宣传中心将在《中国测绘报》选登部分获奖作品，并为所有参赛者赠送一本《科学发展 测绘先行--测绘地理信息工作十年回顾（2002-2012）》。

附件：2012年“立得杯”测绘地理信息法治建设有奖征文活动获奖名单
