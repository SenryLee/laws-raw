# 农业部农业机械化管理司关于举办全国农机化统计业务培训班的通知

## 农业部农业机械化管理司关于举办全国农机化统计业务培训班的通知（农机产[2012]39号）

各省、自治区、直辖市农机（农业、农牧）局（厅、委、办），新疆生产建设兵团农业局，各有关专家：

经研究，我司定于4月上旬在北京举办全国农机化统计业务培训班。现将有关事项通知如下。

**一、**时间及地点

1.时间：4月9日报到，4月10-12日开展农机化统计业务培训，4月13日返程。

2.地点：北京金码大酒店，地址：北京市海淀区学清路甲38号，总机：010-62328899，详见附件1。

**二、**参加人员

各省、自治区、直辖市农机（农业、农牧）局（厅、委、办）和新疆生产建设兵团农业局具体负责农机化统计工作的同志，各单位总人数不超过2人，农机化评价指标体系课题组专家。

**三、**培训内容

1.开展农机化统计业务知识培训，汇总审核2011年全国农机化统计年报数据；

2.交流全国农机化统计软件系统使用情况，征求进一步完善的意见和建议；

3.开展畜牧业、渔业、设施农业、农产品初加工、林果业机械化评价指标体系培训，征求完善意见和建议；

4.总结2011年全国农机化统计工作情况，部署2012年农机化统计工作。

**四、**有关要求

1.3月26日，我司将通过中国农业机械化信息网政务信息直报系统和统计员电子邮箱，下发《关于请进一步完善2011年全国农机化管理统计年报数据的通知》，请按通知要求查找异动原因，确认相关数据，研究发展趋势和特点。

2.3月31日前，各省要完成统计数据确认和异动原因查找工作。为确保统计数据质量，4月1日、5-6日，我司将与各省提前电话确认2011年统计数据，各省也可主动与我司联系。2011年农机化统计数据确认工作务必于4月12日前完成，培训结束后不再受理统计数据变更。

3.请携带2011年、2010年本地区农机化管理统计年报（包含市、县级农机化统计数据）参加培训，以便共同确认异动原因。要认真总结全国农机化统计软件系统使用情况，重点就使用中出现的问题与中软国际公司进行对接，有针对性地提出意见和建议，进一步完善软件系统。

4.请按要求派员参加培训，无特殊情况不得请假。参训人员要认真填写《学员回执》（见附件2），并于3月29日下班前报送我司产业发展处，以便安排食宿。
