# 交通运输部公告2012年第62号――关于公布第3批符合道路运输车辆卫星定位系统标准的系统平台的公告

## 交通运输部公告（2012年第62号）

关于公布第3批符合道路运输车辆卫星定位系统标准的系统平台的公告

根据《关于加强道路运输车辆动态监管工作的通知》（交运发〔2011〕80号）以及《关于认真贯彻〈道路运输车辆卫星定位系统平台技术要求〉和〈道路运输车辆卫星定位系统车载终端技术要求〉两项标准的通知》（交运发〔2011〕158号）的有关规定，内蒙古自治区道路运输动态监管平台等29个符合道路运输车辆卫星定位系统标准的系统平台已通过技术审查和公示程序，现予以公布。

详细信息请访问全国重点营运车辆联网联控信息服务网（http：//lwlk.mot.gov.cn/）。

交通运输部　

2012年12月10日
