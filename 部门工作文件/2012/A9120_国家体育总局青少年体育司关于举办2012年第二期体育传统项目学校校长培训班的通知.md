# 国家体育总局青少年体育司关于举办2012年第二期体育传统项目学校校长培训班的通知

各省、自治区、直辖市、新疆生产建设兵团体育局：

为全面落实科学发展观，贯彻实施《中共中央国务院关于加强青少年体育增强青少年体质的意见》、《全民健身条例》及《全民健身计划（2011-2015年）》，加强我国体育传统项目学校（以下简称“传统校”）组织建设和人才队伍建设，进一步提高传统校校长的知识水平和业务素质，不断推动传统校工作深入持久地开展，按照国家体育总局青少年体育司2012年的工作计划，决定举办2012年第二期体育传统项目学校校长培训班。现就有关事宜通知如下：

**一、**参加培训人员及要求

每省（区、市）参加培训人员为3人，其中：省、市级体育局主管部门具体负责人1人；传统校校长2人。参加培训工作是传统校评估、检查等工作的重要内容之一，各省（区、市）要认真组织，不得随意缺席。

**二、**培训内容

本次培训以“传统校的管理方式和运行模式探讨”为主题，将邀请国内著名的专家学者，以授课和互动交流的方式进行。传统校经验交流突出地域特色，邀请不同地域和不同发展水平的传统校校长交流经验。

授课主要内容：

（一）我国传统校发展的状况及今后的对策

（二）我国体育传统校的管理方式与运行模式-兼论传统校的实践与创新

（三）青少年体育、健康和文化

（四）传统校经验介绍

**三、**培训经费

参加培训人员旅费自理，培训期间食宿费、培训费由体育总局补贴。编外人员经报名核准，费用自理。

**四、**组织形式、培训时间及地点

主办单位：国家体育总局青少年体育司

承办单位：国家体育总局体育科学研究所

黑龙江省体育局

报到时间：2012年11月26日

报到地点：黑龙江省军区八一宾馆（哈尔滨市南岗区文庙街9号）

培训时间：2012年11月27日至11月30日

培训地点：黑龙江省军区八一宾馆
