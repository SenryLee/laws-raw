# 国家体育总局办公厅关于举办2012年全国中等体育运动学校校长培训班的通知

各省、自治区、直辖市体育局：

根据国家体育总局2012年培训工作计划，由国家体育总局青少司主办、体育总局教练员学院承办、北京什刹海体校协办的全国中等体育运动学校校长培训班定于5月21日-25日在北京举办，现将有关事宜通知如下：

**一、**培训目的

了解我国中等体育学校办学政策与发展趋势，交流体校训练工作与运动员文化教育经验，提高体校校长综合素质与科学治校能力。

**二、**培训对象

全国中等体育学校校级管理干部，招生人数100人。

**三、**培训时间及地点

（一）时间：2012年5月21日-25日。21日全天报到，22日-24日培训，25日12：00前离会。

（二）地点：什刹海体校国际公寓，地址：北京西城区地安门西大街57号，电话：010-83228766

**四、**培训内容

（一）我国基层业余训练工作现状与发展思路

（二）体育强国建设与竞技体育后备人才培养

（三）现代业余体育训练创新理念与实践成果

（四）现代体校管理科学治校理论与实践

（五）领导能力与领导艺术

（六）校长论坛

**五、**考核与结业

根据培训期间听讲、笔记、讨论、出勤等情况对学员进行综合考核。合格者将获得国家体育总局教练员学院颁发的结业证书。

**六、**培训费用

培训费、食宿费由国家体育总局负担，往返交通费由学员所在单位负担。

**七、**报名程序

由各省（区、市）体育局根据名额分配表（见附件2）推荐中等体育学校校级管理干部，填写报名表（见附件3），于5月1日之前报至国家体育总局教练员学院。
