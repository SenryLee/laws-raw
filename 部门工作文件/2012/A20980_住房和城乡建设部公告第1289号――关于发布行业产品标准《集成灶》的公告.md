# 住房和城乡建设部公告第1289号――关于发布行业产品标准《集成灶》的公告

## 住房和城乡建设部公告（第1289号）

关于发布行业产品标准《集成灶》的公告

现批准《集成灶》为城镇建设行业产品标准，编号为CJ/T386-2012，自2012年5月1日起实施。

本标准由我部标准定额研究所组织中国标准出版社出版发行。
