# 中华全国供销合作总社关于做好系统职业院校参加2012年全国职业院校技能大赛获奖情况统计的函

各省、自治区、直辖市及计划单列市供销合作社：

2012年全国职业院校技能大赛由教育部牵头，22个部门联合主办，中华全国供销合作总社是主办单位之一。本届大赛即将于6月29日在天津主赛场落下帷幕。供销合作社系统各职业院校积极参加了各个比赛项目，充分展示了供销合作社职业教育改革发展的成果，展现了系统职业院校及广大师生的风采。总社将对系统职业院校取得优异竞赛成绩的选手给予表彰。

请各省级供销合作社认真负责，统计好本省（区、市）系统各职业院校参加2012年全国职业院校技能大赛获奖情况，汇总后于2012年7月2日前，传真至总社科技教育部，或将电子版发送至wangzheng@chinacoop.gov.cn邮箱。
