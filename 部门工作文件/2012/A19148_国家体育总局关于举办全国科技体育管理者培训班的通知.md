# 国家体育总局关于举办全国科技体育管理者培训班的通知

## 国家体育总局关于举办全国科技体育管理者培训班的通知（航电模字〔2012〕72号）

各省、自治区、直辖市、计划单列市体育局办公室及有关单位：

为加快科技体育项目的普及，建立科学的培训体系，培养优秀的管理队伍，提高科技体育教学水平和管理能力，全国科技体育传统校创建试点工作协调办公室（以下简称：“全国科技体育协调办公室”）将举办管理者培训班，具体事宜通知如下：

**一、**时间地点

时间：2012年3月29日-30日，28日报到；

地点：浙江省宁波市

**二、**主办、承办单位

**四、**培训内容及效果

（一）综合：基层组织的建设与管理；活动的组织与管理、策划、包装；科技体育传统校标准手册解读。

（二）专项：以纸飞机和校园定向为主，同时兼有其他科技体育活动的成功案例。

（三）任务：接受培训的全国培训讲师团成员，按照中心要求到各分区执行相关的培训工作。

**五、**授课人员与内容

丁鹏：解读全国科技体育传统校标准手册；

张耀辉：如何搞好各种形式的培训；

洪仁伟：打造品牌赛事活动，提升自身影响力；

王雷：如何将模型活动与丰富校园文化相结合；

董屹立：如何将校园定向和测向运动与学校体育活动有机结合；

李正梅：培训总结。

**六、**经费

培训班全体人员在宁波期间的食宿由国家体育总局航空无线电模型运动管理中心（以下简称：“航电模中心”）支付，讲师团成员的往返差旅费按硬卧报销。
