# 农业部信息中心关于举办第十届农交会网络直播及农产品促销工作培训班的通知

## 农业部信息中心关于举办第十届农交会网络直播及农产品促销工作培训班的通知（农信息[2012]53号）

各省（自治区、直辖市）农业（农牧、农林）厅（委、局、办）、新疆生产建设兵团农业局信息中心：

为了进一步做好第十届中国国际农产品交易会网络直播及农产品促销宣传工作，展现三农工作成果，及时报道农交会精彩活动实况，展示各展团风采和产业化龙头企业形象，推动优质农产品品牌建设，农业部信息中心定于2012年9月25日-9月30日在北京举办第十届农交会网络直播及农产品促销工作培训班，并组织开展农交会网络宣传报道工作。现就有关事项通知如下：

**一、**主要内容

农交会网络宣传、农产品促销工作总结；贸易统计软件操作培训、数据统计，分析发布、信息采编处理培训；有关网络信息工作安排。

**二、**参加人员

各省（自治区、直辖市）农业（农牧、农林）厅（委、局、办）、新疆生产建设兵团农业局信息中心信息采编人员各1名。

**三、**时间地点

时间：9月24日报到，10月1日12点前离会

地点：北京市蟹岛绿色生态度假村（www.xiedao.com）

前台联系电话：010-84324200

**四、**有关要求

1.各省农业信息中心要高度重视此次培训和宣传报道工作，选派责任心强、新闻信息采编报道能力强的人员参加。

2.各省主要负责展团快报、展会掠影栏目。请各省预先收集整理本省参展企业、产品和有关参展工作的宣传报道内容和亮点。全国网上联播已获得远程信息采编权限的省份，目前即可通过WCM开展有关农交会的信息采编工作。其他省份应抓紧开通政务外网或卫星通讯网网上联播远程信息采编权限、开展农交会网络直播的信息宣传报道工作（有关事项请参照全国信息联播权限下放函件的要求或与我们联系）。未获得远程信息采编权限的可到北京进行信息采编。

3.为了加大网络宣传力度，请各省农业网站于9月15日前在首页显著位置，链接中国国际农产品交易会网站（http：//catf.agri.gov.cn/）

4.培训期间，信息采编报道人员直接参加农交会现场网络宣传报道工作，请自带数码相机，有条件者可以自带笔记本电脑或其他多媒体（如摄像机、录音笔等）。

5.本届农交会现场直播展台设在农展馆新馆广场展篷内科技展区，前来承担网络宣传报道工作的人员应注意着装，请工作人员着白色或浅色上衣，男士请佩领带，黑色或深色裤子。

**五、**其它事宜

1.代表往返路费自理，培训和农交会期间由农业部信息中心统一安排交通食宿。如农交会期间随本省展团活动、自行安排交通食宿者，请事前通知会务组。

2.请各省（自治区、直辖市）于9月15日前将参加人员回执用E-mail方式报部信息中心。

3.部信息中心在展馆统一准备32台计算机供各省信息采编人员使用。

4.本次培训班不安排接站，请代表按交通路线（见附件一）自行前往。
