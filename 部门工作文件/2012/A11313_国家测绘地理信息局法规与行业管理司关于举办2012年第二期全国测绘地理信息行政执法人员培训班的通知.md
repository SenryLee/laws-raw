# 国家测绘地理信息局法规与行业管理司关于举办2012年第二期全国测绘地理信息行政执法人员培训班的通知

## 国家测绘地理信息局法规与行业管理司关于举办2012年第二期全国测绘地理信息行政执法人员培训班的通知（测管函〔2012〕48号）

各省、自治区、直辖市测绘地理信息行政主管部门：

为贯彻落实《国务院关于加强法治政府建设的意见》中有关加强行政执法队伍建设的精神，全面提高测绘地理信息行政执法人员素质，进一步提升行政执法队伍的执法能力和水平，我司按照2012年培训计划定于10月份在湖南省举办全国测绘地理信息行政执法人员培训班，现将有关事宜通知如下。

**一、**培训对象

各级测绘地理信息行政主管部门行政执法人员。重点是轮岗、交流、调动到行政执法岗位，尚未取得执法证，以及取得执法证已满两年需注册的执法人员。每省名额5名，其中省级测绘地理信息行政主管部门1名（兼领队）。

**二、**培训内容

结合2012年度测绘地理信息行政执法工作的重点，邀请国家局和有关部门领导、专家及教授就有关测绘地理信息政策法规，维护国家测绘地理信息安全，GPS应用现状及监管措施，以及行政执法理论与查处测绘地理信息违法案件实务等内容做专题报告。

**三、**培训时间和地点

时 间：2012年10月17日－19日，16日报到，培训时间3天

地 点：蓉园宾馆（湖南省长沙市车站北路225号）

**四、**有关要求

（一）各省级测绘地理信息行政主管部门要高度重视测绘地理信息行政执法人员培训工作，认真组织好本行政区域内的执法人员参加培训，并做好带队工作。

（二）培训班统一安排食宿，费用自理。每位参加培训人员需交纳培训费1000元。

（三）各省级测绘地理信息行政主管部门请于9月25日前将参训人员报名回执（见附件）分别传真至我司执法监督处和湖南省国土资源厅测绘行业管理处。如需接站请提前与湖南省国土资源厅联系。
