# 国资委直属机关党委关于举办国资委直属机关2012年度党内统计培训班的通知

监事会党总支，研究中心、经济出版社、各直管协会、管理局系统各单位、部分京外企业在京单位党委：

2012年度党内统计工作即将开始，为认真做好今年的统计年报工作，经直属机关党委研究，拟举办国资委直属机关党内统计培训班，现将有关事项通知如下：

**一、**培训内容

讲解统计软件《全国党员管理信息系统（基层版）》的使用，讲解《2012年中国共产党党内统计年报表》及《2012年中央国家机关下发添加报表》的各项指标填报事项。

**二、**培训时间

2013年1月8～9日

**三、**培训地点

北京石油管理干部学院（路线图附后）

**四、**参训人员

各单位具体负责党内统计的干部。

**五、**有关要求

1.参加培训的学员须自带笔记本电脑，并在电脑上安装好《全国党员管理信息系统（基层版）》软件。

2.请参加培训的学员提前梳理在统计工作中遇到的问题，我们将进行汇总并在培训时安排答疑。

3.请参加培训人员认真填写报名回执，于2013年1月4日传真至国资委直属机关党委组织部，并请在报名回执中注明是否集体乘车。集体乘车人员请于1月8日上午10：00前到国资委西便门办公区北门集体乘车。
