# 中国残联办公厅关于举办全国残疾人状况监测2011年度工作总结会暨2012年度监测工作培训班的通知

## 中国残联办公厅关于举办全国残疾人状况监测2011年度工作总结会暨2012年度监测工作培训班的通知（残联厅函〔2012〕140号）

各省、自治区、直辖市残疾人联合会：

根据中国残联《关于做好2012年度全国残疾人状况监测工作的通知》（残联厅〔2012〕105号）的要求，经中国残联领导同志同意，定于2012年9月在四川省成都市举办“全国残疾人状况监测2011年度工作总结会暨2012年度监测工作培训班”。现将会议有关事宜通知如下：

**一、**时间和地点

时间：2012年9月18日至22日（18日报到，22日离会）。

地点：成都梨园祥丽雅阁酒店（地址：成都市人民北路一段一号，攀枝花大厦内；酒店联系人：梁建丽 18280276520）。

**二、**参会人员

中国残联党组分管领导，中国残联研究室负责同志，中国残联监测办相关专家。

各省、自治区、直辖市残联主管副理事长1名，监测工作相关业务骨干2名。

**三、**报名及回执

（一）请于9月11日中午12时前，将本省参会人员名单（见附件1）以电子邮件或传真至中国残联监测办公室。

（二）请认真填写参会人员回执（见附件2）。于9月14日下班前电子邮件或传真至四川省残联。

（三）报到当日（9月18日全天）会务组在成都市火车站、机场安排接站。

**四、**注意事项

（一）参会人员交通费自理，食宿由会议主办方统一承担。

（二）请严格按照会议通知要求的人数报名并准时参会，提前到会与推迟离会费用自理。

（三）参加培训人员务必携带U盘。
