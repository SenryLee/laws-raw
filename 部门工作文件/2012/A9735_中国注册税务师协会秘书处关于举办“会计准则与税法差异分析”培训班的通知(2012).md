# 中国注册税务师协会秘书处关于举办“会计准则与税法差异分析”培训班的通知(2012)

## 中国注册税务师协会秘书处关于举办“会计准则与税法差异分析”培训班的通知（中税协秘发[2012]058号）

各省、自治区、直辖市和计划单列市注册税务师协会：

为帮助注册税务师熟练掌握会计准则中的重难点内容，重点把握会计准则与税法的差异以及税务处理方法，提升解决新兴会计业务、高端会计业务的水平，进一步提高税务师事务所注册税务师及业务骨干的业务素质，促进税务师事务所业务工作整体水平的提高，中国注册税务师协会决定举办“会计准则与税法差异分析”培训班，培训报名将继续通过系统进行网上报名，现将有关事项通知如下：

**一、**培训内容及授课教师

1. 长期股权投资等5项准则与税法差异分析--赵建华；

2. 金融资产转移准则与税法差异分析--吕明；

3. 财务报告勾稽关系分析--石玮；

4. 合并财务报表准则与税法差异分析--石玮。

**二、**培训时间

2012年11月22日-27日（11月22日报到，23日-26日全天上课，27日返程）。

**三、**培训地点

国家税务总局税务干部进修学院（江苏省扬州市扬子江北路515号）。

**四、**参加人员

税务师事务所所长、业务骨干。

**五、**收费标准

食宿费：1500元/人/期；

培训费：950元/期（含教师授课费、讲义和教材费用、教室使用费用等）。

1. 本期培训班通过会员管理信息系统--面授培训报名管理子系统进行网上报名，网址为：http：//is.cctaa.cn/odps/。

2. 执业与非执业注册税务师使用注册税务师安全盘（U key）登录该系统进行报名。其他从业人员由所属税务师事务所通过事务所安全盘（U key）进行报名。

3. 税务师事务所须对本所的培训班报名表审核后提交地方税协，地方税协确认后视为报名成功。具体操作方法详见系统首页的《面授培训报名管理子系统操作说明》。

**八、**具体要求

1. 根据中税协领导指示，2012年所有培训班报名参训的执业注册税务师必须完成网上个人信息采集方可报名，凡未完成者暂不予以报名。

2. 请各地方协会按照培训班名额分配表（见附件）所列人数要求，积极做好参加培训人员的报名组织工作，要求报名参训人员无特殊原因必须参加，不得缺席，不得随意换人。

本期培训班报名工作将于11月15日截止，届时系统将关闭本培训班的报名功能，凡逾期未报名的地区视为自动放弃。另外，本次培训班以地方税协通过系统确认的报名表为准，向税务干部进修学院报名的视为无效。
