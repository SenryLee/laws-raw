# 中华人民共和国住房和城乡建设部公告2019年第292号——住房和城乡建设部关于发布行业标准《雷达法检测混凝土结构技术标准》的公告

## 中华人民共和国住房和城乡建设部公告

2019年第292号

## 住房和城乡建设部关于发布行业标准《雷达法检测混凝土结构技术标准》的公告

现批准《雷达法检测混凝土结构技术标准》为行业标准，编号为JGJ/T456-2019，自2020年3月1日起实施。

本标准在住房和城乡建设部门户网站（www.mohurd.gov.cn）公开，并由住房和城乡建设部标准定额研究所组织中国建筑出版传媒有限公司出版发行。

附件：雷达法检测混凝土结构技术标准

中华人民共和国住房和城乡建设部

2019年11月15日
