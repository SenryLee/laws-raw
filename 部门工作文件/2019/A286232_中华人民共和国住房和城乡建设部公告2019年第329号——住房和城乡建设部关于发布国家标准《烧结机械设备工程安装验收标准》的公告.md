# 中华人民共和国住房和城乡建设部公告2019年第329号——住房和城乡建设部关于发布国家标准《烧结机械设备工程安装验收标准》的公告

## 中华人民共和国住房和城乡建设部公告

2019年第329号

## 住房和城乡建设部关于发布国家标准《烧结机械设备工程安装验收标准》的公告

现批准《烧结机械设备工程安装验收标准》为国家标准，编号为GB/T50402-2019，自2020年3月1日起实施。原国家标准《烧结机械设备工程安装验收规范》（GB50402-2007）同时废止。

本标准在住房和城乡建设部门户网站（www.mohurd.gov.cn）公开，并由住房和城乡建设部标准定额研究所组织中国计划出版社出版发行。

附件：烧结机械设备工程安装验收标准（GB/T50402-2019）

中华人民共和国住房和城乡建设部

2019年11月22日
