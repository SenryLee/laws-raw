# 中华人民共和国住房和城乡建设部公告2019年第138号——住房和城乡建设部关于发布国家标准《太阳能供热采暖工程技术标准》的公告

## 中华人民共和国住房和城乡建设部公告

2019年第138号

## 住房和城乡建设部关于发布国家标准《太阳能供热采暖工程技术标准》的公告

现批准《太阳能供热采暖工程技术标准》为国家标准，编号为GB50495-2019，自2019年12月1日起实施。其中，第1.0.5、5.1.1、5.1.2、5.1.5、5.2.13条为强制性条文，必须严格执行。原《太阳能供热采暖工程技术规范》（GB50495-2009）同时废止。

本标准在住房和城乡建设部门户网站（www.mohurd.gov.cn）公开，并由住房和城乡建设部标准定额研究所组织中国建筑工业出版社出版发行。

中华人民共和国住房和城乡建设部

2019年5月24日
