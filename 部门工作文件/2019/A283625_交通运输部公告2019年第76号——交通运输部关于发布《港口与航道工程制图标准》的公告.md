# 交通运输部公告2019年第76号——交通运输部关于发布《港口与航道工程制图标准》的公告

## 交通运输部公告

2019年第76号

## 交通运输部关于发布《港口与航道工程制图标准》的公告

《港口与航道工程制图标准》为水运工程推荐性行业标准，标准代码为JTS/T 142-1—2019，自2019年12月31日起施行，由交通运输部水运局负责管理和解释。《港口与航道工程制图标准》（JTJ 206—96）同时废止。

特此公告。

交通运输部

2019年10月21日
