# 交通运输部公告2019年第49号——交通运输部关于发布现行水运工程行业标准《码头结构设计规范》（JTS167-2018）英文版的公告

本法规中的桩基设计部分与《交通运输部关于发布<水运工程桩基设计规范>的公告》（交通运输部公告2022第65号）不一致处，自2023年1月1日起按照《交通运输部关于发布<水运工程桩基设计规范>的公告》执行。

## 交通运输部关于发布现行水运工程行业标准《码头结构设计规范》（JTS 167-2018）英文版的公告

为加强水运工程行业标准对外交流，我部组织完成了水运工程行业标准《码头结构设计规范》（JTS 167-2018）英文版编制工作，现予发布。

标准英文版表述与中文版不一致时，以中文版为准。在使用过程中发现的问题和修改意见建议请反馈至中交第一航务工程勘察设计院有限公司（地址：天津市河西区洞庭路18号颐航大厦，邮政编码：300222，电子邮箱：fdine@fdine.com.cn），以便修订时参考。
