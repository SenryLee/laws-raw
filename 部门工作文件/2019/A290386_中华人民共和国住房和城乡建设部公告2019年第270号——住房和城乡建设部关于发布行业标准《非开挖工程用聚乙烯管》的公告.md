# 中华人民共和国住房和城乡建设部公告2019年第270号——住房和城乡建设部关于发布行业标准《非开挖工程用聚乙烯管》的公告

## 中华人民共和国住房和城乡建设部公告

2019年第270号

## 住房和城乡建设部关于发布行业标准《非开挖工程用聚乙烯管》的公告

现批准《非开挖工程用聚乙烯管》为城镇建设行业产品标准，编号为CJ/T358-2019，自2020年6月1日起实施。原《非开挖铺设用高密度聚乙烯排水管》（CJ/T358-2010）同时废止。

本标准在住房和城乡建设部门户网站（www.mohurd.gov.cn）公开，并由住房和城乡建设部标准定额研究所组织中国标准出版社出版发行。

中华人民共和国住房和城乡建设部

2019年10月28日

附件：非开挖工程用聚乙烯管
