# 中华人民共和国住房和城乡建设部公告2019年第309号——住房和城乡建设部关于发布行业标准《民用建筑修缮工程施工标准》的公告

## 中华人民共和国住房和城乡建设部公告

2019年第309号

## 住房和城乡建设部关于发布行业标准《民用建筑修缮工程施工标准》的公告

现批准《民用建筑修缮工程施工标准》为行业标准，编号为 JGJ/T112-2019，自2020年3月1日起实施。原行业标准《民用房屋修缮工程施工规程》（CJJ/T53-93）同时废止。

本标准在住房和城乡建设部门户网站（www.mohurd.gov.cn）公开，并由住房和城乡建设部标准定额研究所组织中国建筑出版传媒有限公司出版发行。

附件：民用建筑修缮工程施工标准（JGJ/T112-2019）

中华人民共和国住房和城乡建设部

2019年11月29日
