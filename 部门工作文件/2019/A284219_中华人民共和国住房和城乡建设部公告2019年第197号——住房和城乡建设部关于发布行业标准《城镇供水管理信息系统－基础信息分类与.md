# 中华人民共和国住房和城乡建设部公告2019年第197号——住房和城乡建设部关于发布行业标准《城镇供水管理信息系统－基础信息分类与编码规则》的公告

## 中华人民共和国住房和城乡建设部公告

2019年第197号

## 住房和城乡建设部关于发布行业标准《城镇供水管理信息系统　基础信息分类与编码规则》的公告

现批准《城镇供水管理信息系统　基础信息分类与编码规则》为城镇建设行业产品标准，编号为CJ/T541-2019，自2019年12月1日起实施。

本标准在住房和城乡建设部门户网站（www.mohurd.gov.cn）公开，并由住房和城乡建设部标准定额研究所组织中国标准出版社出版发行。

中华人民共和国住房和城乡建设部

2019年7月18日
