# 中华人民共和国住房和城乡建设部公告2019年第49号——住房和城乡建设部关于发布行业标准《多层钢丝缠绕改性聚乙烯耐磨复合管》的公告

## 中华人民共和国住房和城乡建设部公告

2019年第49号

## 住房和城乡建设部关于发布行业标准《多层钢丝缠绕改性聚乙烯耐磨复合管》的公告

现批准《多层钢丝缠绕改性聚乙烯耐磨复合管》为城镇建设行业产品标准，编号为CJ/T537-2019，自2019年9月1日起实施。

本标准在住房和城乡建设部门户网站（www.mohurd.gov.cn）公开，并由住房和城乡建设部标准定额研究所组织中国标准出版社出版发行。

中华人民共和国住房和城乡建设部

2019年3月4日

附件：多层钢丝缠绕改性聚乙烯耐磨复合管
