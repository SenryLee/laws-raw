# 交通运输部公告2014年第29号――关于发布《水运工程标准编写规定》(JTS101-2014)的公告

## 交通运输部公告（2014年第29号）

关于发布《水运工程标准编写规定》（JTS101-2014）的公告

现发布《水运工程标准编写规定》（以下简称《规定》）。本《规定》为强制性行业标准，编号为JTS101-2014，自发布之日起施行。《水运工程建设标准编写规定》（JTJ200-2001）同时废止。

本《规定》由交通运输部水运局和中国工程建设标准化协会水运专业委员会等单位编制完成，由交通运输部水运局负责管理和解释，由人民交通出版社出版发行。

特此公告。

交通运输部

2014年6月12日
