# 人力资源和社会保障部信息中心、中国高级公务员培训中心关于举办2014年全国社会保障卡建设培训班的通知

## 人力资源和社会保障部信息中心、中国高级公务员培训中心关于举办2014年全国社会保障卡建设培训班的通知（人训中函〔2014〕13号）

各省、自治区、直辖市及新疆生产建设兵团人力资源和社会保障厅（局）：

根据《人力资源社会保障部2014年度业务培训班计划的通知》（人社厅发〔2014〕12号）的安排，经报部人事司批准，部信息中心和高培中心拟于今年9月在广东省珠海市联合举办2014年全国社会保障卡建设培训班。现将有关事宜通知如下：

**一、**培训目的

近年来，全国社会保障卡发行和应用工作快速推进，各方面工作取得显著成效。为进一步促进各地明确社会保障卡建设的目标、任务和要求，推动社会保障卡工作快速、规范、安全地发展，确保“十二五”发行任务顺利完成，并做好由发行为主到发用并举的工作重点转变，加快推进社会保障卡广泛应用，组织这次社会保障卡建设培训班。

**二、**培训内容及形式

（一）培训内容

1． 金保工程二期总体设计暨社会保障卡总体情况和工作要求；

2.　社会保障卡加快推进应用的工作方案和典型案例；

3.　社会保障卡持卡人员基础信息库建设方案暨部署安排；

4.　社会保障卡发行服务流程及社银接口设计；

5.　社会保障卡质量及安全要求；

6.　社会保障卡发行、管理服务和应用经验交流；

7.　社会保障卡建设相关技术解决方案。

（二）培训形式

采取集中授课、经验交流等形式。

**三、**培训对象

各省、自治区、直辖市和新疆生产建设兵团（以下简称各省）及部分地市级人力资源社会保障部门负责社会保障卡建设的管理人员和业务骨干。

**四、**培训师资

人力资源社会保障部信息中心、部分地区人力资源社会保障部门及社会保障卡建设相关行业专家。

**五、**培训时间及地点

（一）时间：2014年9月23日-26日（22日报到）；

（二）地点：广东省珠海市。

**六、**培训费用

培训费用：1120元/人（不含食宿费用）。食宿统一安排，费用自理。

**七、**其他事项

（一）培训要求

请参加培训的同志落实部里有关培训管理的相关要求，遵守培训班纪律，认真学习，积极交流，切实提高培训质量。

（二）报名工作

请各省统一组织报名工作，于9月15日前将参加培训人员名单（报名表见附件）以传真或电子邮件形式报送部高培中心培训三处。报到具体事宜，另行通知。
