# 国家认证认可监督管理委员会办公室关于举办2014年度卫生注册主任评审员培训班的通知

## 国家认证认可监督管理委员会办公室关于举办2014年度卫生注册主任评审员培训班的通知（认办注函〔2014〕162号）

各直属检验检疫局：

为进一步加强卫生注册主任评审员队伍建设，提高对进出口食品生产企业的评审和监管水平，根据2014年培训计划，认监委将举办本年度主任评审员培训班，贵州出入境检验检疫局协助配合相关工作。现将有关事宜通知如下：

**一、**培训时间

2014年9月2日报到，3-5日培训。

**二、**培训对象

本次培训对象是针对各检验检疫局申请成为主任评审员以及认证处具体从事出口食品企业备案注册监管工作的人员，请各局按名额分配报名，于8月27日前将培训班报名表报送认监委注册部，并抄送贵州局认证处（名额分配及报名表见附件1）。

**三、**培训内容

本次培训我部主要对进口食品境外生产企业注册管理和赴外评审工作、出口欧盟等国家推荐工作程序、美国食品安全现代化法及配套法规的应对与借鉴等内容进行介绍，并外邀专家就出口欧盟、美国企业注册卫生基本要求以及出口食品生产企业HACCP认证的见证和确认审核方法等内容进行进一步的讲解（培训课程安排见附件3）。同时根据进口食品境外企业注册工作的发展需要，还组织部分具备赴外评审资格的主任评审员，进一步对进口食品境外生产企业注册管理工作进行深入学习，重点交流讨论进口注册赴外评审要点和经验等（指定人员参加，人员名单见附件2）。

**四、**培训方式

采取教师辅导、学员作业、集体研讨和教师答疑方式。

**五、**培训费用

培训人员的食宿等费用由认监委统一安排，国内交通费用由派员单位承担。

**六、**培训人员要求

参加培训的人员应提前预习和熟悉培训内容，在培训中应完成书面作业、参加集体讨论和培训考试等，完成培训任务。参训人员需带笔记本电脑和一寸彩色照片一张。

贵州省贵阳市喀斯特宾馆（贵阳市瑞金南路25号，电话0851-8196888）
