# 交通运输部人事教育司关于举办2014年全国交通局长培训班的通知

交通运输部人事教育司关于举办2014年全国交通局长培训班的通知

（人教教培〔2014〕40号）

各省、自治区、直辖市、新疆生产建设兵团交通运输厅（局、委），天津市交通运输和港口管理局：

为深入贯彻落实《2013-2017年全国干部教育培训规划》和2014年交通运输工作会议有关精神，不断推进基层交通运输领导干部队伍建设，根据《公路水路交通运输“十二五”教育与培训发展规划》（交科技发〔2011〕175号）和《交通运输部关于印发2014年度交通运输部支持西部地区和六盘山片区教育培训计划的通知》（交人教发〔2014〕83号）要求，现将2014年全国交通局长培训班计划安排通知如下：

**一、**培训对象

各市（地、州、盟）交通运输局长、县（区、市、旗）交通运输局长。

**二、**培训目标

通过开展面向基层一线交通运输局长的培训，提高交通运输局长履行岗位职责、依法行政以及面对新形势新任务开拓创新的能力，提升业务素质水平，进一步推动交通运输深化改革，推进“四个交通”发展。

**三、**培训内容

培训内容主要由宏观政策、业务素质和领导能力三个培训模块构成。

宏观政策模块：加快推进行政管理体制改革精神解读、新型城镇化中的交通引领、综合交通运输体系建设、智慧交通发展、低碳理念下的绿色交通建设、交通运输安全监督管理。

业务素质模块：《国家公路网规划》解读、农村公路建设与养护管理、交通筹融资体制改革、公路工程建设项目管理；道路运输市场监管、城市公交与城乡客运一体化、货运与物流管理、出租车管理、交通行政执法理论与案例解析。

领导能力模块：交通文化建设、交通廉政建设、交通突发事件应急管理与媒体应对、领导科学与艺术。

培训期间还将安排参观考察北京市交通运行协调指挥中心、交通运输部公路交通试验场、北京市综合客运枢纽站、北京市物流中心、北京市农村公路示范路等（培训重点课程安排见附件1）。

**四、**培训师资

培训班将邀请交通运输部相关业务司局和地方交通运输部门领导、行业科研院所专家以及中共中央党校、国家行政学院、国家安全生产监督管理总局等有关训机构和知名高校专家学者担任授课教师。

**五、**培训形式

（一）培训班采取理论讲授、交流研讨、案例教学、现场教学、参观考察等多种培训形式。

（二）交通局长论坛。培训班将围绕交通运输发展面临的热点难点问题组织研讨交流，提出解决交通运输发展问题的政策建议，形成的研讨成果将编辑成《交通局长之声》报送部领导及相关部门。

（三）经验交流。为交流推广地方交通运输行业管理经验，培训班将遴选学员优秀交流材料收入《交通运输局长》杂志。请参加培训的学员围绕本地推进“四个交通”发展的热点难点问题准备相关交流材料，并将电子版发送至：wtoffice@bjjtxy.bj.cn。

培训时间：培训班共举办8期，每期3个班次，其中地市级交通局长1个班次，县级交通局长2个班次，每期12天。具体时间安排如下表所示。

**七、**其他事项

（一）培训工作由我部统一组织，部人事教育司负责，部管理干部学院具体承办。各省级交通运输主管部门负责组织报名和学员选送工作。

（二）部承担参训学员培训费（包括食宿费），选派单位承担参训学员往返交通费。

（三）请各省级交通运输主管部门按照“2014年全国交通局长培训班名额分配表”（见附件2），统筹安排好全年学员送培工作，优先选派集中连片特困地区和新任职交通运输局长。报名报和学员信息登记表（见附件3和附件4）请于每期开班前15天传真至部管理干部学院。
