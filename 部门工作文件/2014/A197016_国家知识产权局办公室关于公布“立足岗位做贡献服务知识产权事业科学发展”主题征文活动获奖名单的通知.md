# 国家知识产权局办公室关于公布“立足岗位做贡献服务知识产权事业科学发展”主题征文活动获奖名单的通知

各省、自治区、直辖市、新疆生产建设兵团知识产权局；局机关各部门，专利局各部门，局直属各单位、各社会团体：

为庆祝建党93周年，深入贯彻落实党的十八大、十八届三中全会精神和习近平总书记系列讲话精神，充分发挥共产党员先锋模范作用，增强责任感使命感，进一步凝聚知识产权系统党员干事创业的热情和力量，引导党员在服务人民群众、促进知识产权事业科学发展的实践中建功立业，我局组织开展了“立足岗位做贡献服务知识产权事业科学发展”主题征文活动。经专家评审，共评选出35篇优秀征文奖和10个优秀组织奖。现将获奖名单公布如下：
