# 民政部办公厅关于举办2014年全国新任民政局长培训班的通知

民政部办公厅关于举办2014年全国新任民政局长培训班的通知

（民办函〔2014〕181号）

各省、自治区、直辖市民政厅（局），各计划单列市民政局，新疆生产建设兵团民政局：

为深入贯彻中央关于大规模培训干部、大幅度提高干部业务素质的要求，根据《全国民政人才中长期发展规划（2010-2020年）》及《民政部2014年度培训计划》（民办发〔2014〕16号）通知安排，定于2014年6月23日在部培训中心举办2014年全国新任民政局长培训班。现将有关事项通知如下：

**一、**培训对象

市（地）、县（区）近三年内新任职的民政局长（副局长），每省选派3人参加，各计划单列市民政局，新疆生产建设兵团选派1人参加。

**二、**培训内容

新时期民政工作走向；社会治理与民政理论；民政主要业务；民政局长的领导力和胜任力；领导者语言艺术；民政业务考察等。

**三、**培训时间、地点

时间：2014年6月23日（报到）-6月28日（返程）

地点：民政部培训中心

**四、**培训形式

采取理论授课、案例分析、互动交流、分组研讨、实地考察相结合的方式。

**五、**其他事项

（一）本次培训不收取培训费、食宿费、资料费，学员往返交通费由所在单位按规定报销。

（二）请各省民政厅（局）按照分配名额认真做好报名工作，填写《2014年全国新任民政局长培训班报名回执表》（见附件1），于6月10日前传真至民政部培训中心（010-61595419）并电话确认。
