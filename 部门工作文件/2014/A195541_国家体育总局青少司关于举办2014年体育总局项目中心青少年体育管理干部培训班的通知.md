# 国家体育总局青少司关于举办2014年体育总局项目中心青少年体育管理干部培训班的通知

各有关中心：

为提高青少年体育管理干部的工作能力和综合素质，根据国家体育总局2014年培训计划，定于11月下旬举办2014年体育总局项目中心青少年体育管理干部培训班。现将有关事宜通知如下。

**一、**培训时间和地点

时间：2014年11月27日至28日

地点：国家体育总局干部培训中心

**二、**培训形式

培训以专家授课为主，结合十八大及十八届三中全会深化改革的新要求，讲授青少年体育发展的最新态势及今后发展方向，专家和学员互动交流，以及参训学员围绕工作实际开展主题交流。

**三、**培训对象及要求

体育总局项目中心青少部或青少年体育工作相关处室青少年体育管理干部，每单位推荐2人参加培训。

参训人员以青少年体育工作领域或本领域的某一方面为主题，自拟标题、自选内容，认真总结本人在开展工作方面好的体会和方法，准备一篇2000字左右的发言材料，培训期间讨论使用。

**四、**培训经费

培训期间参训学员食宿费、培训费由体育总局负担。超出分配名额的人员费用自理。

**五、**报名报到

请参训人员填写报名表（附件2）于2014年11月18日前传真至国家体育总局干部培训中心。

参训人员可于2014年11月26日晚前往国家体育总局干部培训中心报到。
