# 国家中医药管理局办公室关于举办2014年全国中医养生保健素养调查培训班的通知

## 国家中医药管理局办公室关于举办2014年全国中医养生保健素养调查培训班的通知（国中医药办新函〔2014〕161号）

各省、自治区、直辖市卫生计生委（卫生厅局），中医药管理局：

为全面了解全国中医药科普知识进乡村、进社区、进家庭的情况，客观评价公民中医养生保健素养水平，确保2014年全国中医养生保健素养调查工作的顺利开展，国家中医药管理局办公室、国家卫生计生委宣传司定于2014年10月10日在北京举办2014年全国中医养生保健素养调查培训班。现将有关事项通知如下：

**一、**培训内容

（一）全国中医养生保健素养调查问卷讲解；

（二）全国中医养生保健素养调查抽样方案及现场调查方案讲解。

**二、**培训时间

2014年10月10日，会期1天，9日报到。

**三、**培训地点

北京京瑞大厦（北京市朝阳区东三环南路17号，电话010-67668866）。

**四、**培训人员

（一）各省、自治区、直辖市中医药管理部门文化建设工作负责人（限1人）；

（二）各省、自治区、直辖市健康教育专业机构项目执行负责人（限1人，该部分人员由国家卫生计生委另行通知）。

**五、**其他

（一）请各省（区、市）中医药管理部门汇总本地区参加培训的人员，并于9月29日前以传真或电子邮件形式反馈报名回执（见附件）；

（二）培训人员食宿费及差旅费由该省（区、市）卫生计生委、中医药管理部门统一从中医健康素养促进项目经费中列支；

（三）培训班不安排接送站，请自行前往培训地点。
