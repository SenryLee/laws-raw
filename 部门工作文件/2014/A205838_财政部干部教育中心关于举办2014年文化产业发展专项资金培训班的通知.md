# 财政部干部教育中心关于举办2014年文化产业发展专项资金培训班的通知

财政部干部教育中心关于举办2014年文化产业发展专项资金培训班的通知

为进一步加强文化产业发展专项资金管理，做好专项资金系统在线申报工作，根据《2014年财政部干部教育培训计划》的安排，财政部干部教育中心与文资办决定举办2014年文化产业发展专项资金培训班。现将有关事项通知如下：

**一、**培训内容

（一）财政支持文化产业发展相关政策；

（二）文化产业发展专项资金管理；

（三）文化产业发展专项资金后续监督使用；

（四）2014年文化产业发展专项资金申报系统。

**二、**培训对象

各省、自治区、直辖市、计划单列市财政厅（局）负责文化产业发展专项资金管理相关人员，每单位2人（含1名处级干部、1名经办人员）；中央各部门负责文化产业发展专项资金管理相关人员，每单位1人；部分财政部代表国务院履行出资人职责的中央文化企业负责文化产业发展专项资金管理相关人员；部内文资办、预算司、教科文司、监督检查局相关人员。

**三、**培训时间

2014年3月18日至19日，17日报到。

**四、**培训地点

河北财政干部培训中心涿州基地（河北省涿州市建设路410号）。

**五、**培训经费

培训费由财政部干部教育中心按标准统一核拨。

**六、**其他事项

（一）请各单位务必于3月12日前将填好的报名回执（见附件）传真至文资办，同时将到达北京的航班或车次提前电告河北财政干部培训中心涿州基地，以便接站。

（二）京内人员需乘车前往的，请于3月17日下午3点在位于三里河南三巷北口的金凤成祥糕点屋前集合，自行前往的请在报名回执备注栏中注明。

（三）联系人及电话：

1.财政部干部教育中心系统培训处董云，联系电话：010-68554092；

2.财政部文资办业务二处赵嘉、辛亮亮，联系电话：010-68553500、68553758（兼传真）；

3. 河北财政干部培训中心涿州基地文洁，联系电话：0312-6676690、6676689（传真）。
