# 科学技术部基础研究司关于举办基础研究管理培训班的通知

各省、自治区、直辖市、计划单列市科技厅（委、局），新疆生产建设兵团科技局，国务院相关部门科技主管单位：

在当前新的形势下，我国基础研究工作面临着深化科技体制改革、深入实施创新驱动发展战略和转变管理方式的重要任务。为适应新形势，进一步提升基础研究管理思路和能力，强化对国家重大科技政策措施的理解和执行，科技部基础研究司定于2014年11月5－7日在四川成都举办“基础研究管理培训班”，将对当前国际国内基础研究发展形势和我国科技相关政策、科技评价等内容开展集中培训。

本期培训班由科技部基础研究司主办、科技部基础研究管理中心协办，具体由四川大学全国干部教育培训基地承办。有关事项通知如下。

**一、**培训对象

各省、自治区、直辖市、计划单列市科技厅（委、局），新疆生产建设兵团科技局，国务院相关部门科技主管单位从事基础研究管理的工作人员，每单位报名2人。

**二、**培训主要内容

1. 介绍国际科学前沿发展态势和有可能引领未来科技发展的热点领域，以及我国优势学科发展情况。

2. 分析我国基础研究发展面临的形势和需求，以及我国基础研究发展现状和存在的问题。

3. 解读当前我国科技宏观政策、科技计划管理措施和经费管理相关规定。

4. 介绍国内外科技评价体系和方法，以及用文献计量学方法评价机构、人员的方法。

**三、**培训方式和师资

培训班将采取专题报告、互动讨论等教学形式，邀请国家有关部委科技管理人员、知名专家授课，并组织学员进行互动交流。

**四、**时间及地点

报到时间：2014年11月4日下午报到。

报到地点：岷山安逸大酒店（成都市春熙路东段一号，电话：028-86653666）。

培训时间：2014年11月5－7日。

离会时间：2014年11月8日上午。

培训地点：四川大学全国干部教育培训基地。

**五、**相关要求

1. 办班管理。认真贯彻落实中央八项规定和中组部关于在干部教育培训中进一步加强学员管理的要求，以及科技部关于改进工作作风的规定，在办班过程中加强对参训学员和工作人员的管理，严格遵守廉洁自律的各项规定，厉行勤俭节约，反对铺张浪费。各参训学员自行前往报到地点，本次培训不安排统一的接送。

2. 相关费用。培训班承办方承担学员食宿等培训费用，学员所在单位承担学员往返交通费用。

3. 学习材料提交。请培训学员提前做好调研工作，于培训班结束前，结合培训内容和本人工作实际，提交一份1000字以上的培训总结，主要包括对培训内容的理解、体会收获、意见建议等内容。

4. 培训证书颁发。学员圆满完成必修课程，颁发《基础研究管理培训班结业证书》。请学员报到时交2张1寸近期免冠照片。

5. 回执反馈日期。请各单位认真组织人员参加培训，并于10月24日前将加盖单位公章的学员报名回执（见附件1）传真至科技部基础研究管理中心，同时提交电子版。
