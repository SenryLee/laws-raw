# 商务部办公厅关于赴美国举办2014年电子商务创新应用模式及政策建设培训班的通知

## 商务部办公厅关于赴美国举办2014年电子商务创新应用模式及政策建设培训班的通知（商办电函[2014]547号）

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门：

为学习借鉴美国电子商务和信息化建设的先进经验和做法，提高电子商务工作质量，加强电子商务工作领域的交流与合作，促进经济发展和转型升级，经外专局批准，商务部拟于2014年9月份在美国举办电子商务创新应用模式及政策体系建设培训班。现将有关事项通知如下：

**一、**培训内容及方式

学习美国电子商务应用的创新模式、实现技术、实施方案与运行管理；电子商务网络项目开发的组织、可行性分析立项和功能实现的方法；分析电子商务在企业中的应用模式；电子商务环境建设以及政府在法律法规等方面对发展电子商务的规定等方面内容。

方式：集中授课、案例分析、研讨会、座谈会、实地考察。

**二、**培训时间

2014年9月在北京预培训1天，在美国培训21天。

**三、**参训人员

各省、自治区、直辖市、计划单列市及新疆生产建设兵团商务主管部门的负责同志或业务骨干。

总人数不超过25人。年龄在50岁以下，机关厅局级负责同志的年龄可适当放宽，但不超过55岁。

**四、**费用及其他事项

（一）费用。

参训人员在美的培训费、伙食费及公杂费由外专局资助；国际旅费、住宿费、签证费及国内交通费和预培训费用等由派员单位承担。

（二）报名要求。

为确保培训名额有效使用，请各单位严格按照要求选派培训人员，填写报名表（见附件）并加盖公章，于2014年7月11日前以传真和电子邮件形式报送至商务部。
