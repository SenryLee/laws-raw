# 环境保护部公告2014年第45号――关于发布《环境保护产品技术要求旋流除砂装置》国家环境保护标准的公告

## 环境保护部公告（2014年第45号）

关于发布《环境保护产品技术要求 旋流除砂装置》国家环境保护标准的公告

为贯彻《环境保护法》，保护环境，促进技术进步，现批准《环境保护产品技术要求 旋流除砂装置》标准为国家环境保护标准，并予发布。

标准名称、编号如下：

环境保护产品技术要求 旋流除砂装置 （HJ 2538-2014）

该标准自2014年9月1日起实施，由中国环境科学出版社出版，标准内容可在环境保护部网站（bz.mep.gov.cn）查询。

特此公告。

环境保护部

2014年6月20日
