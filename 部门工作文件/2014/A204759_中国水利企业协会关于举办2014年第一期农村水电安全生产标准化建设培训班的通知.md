# 中国水利企业协会关于举办2014年第一期农村水电安全生产标准化建设培训班的通知

## 中国水利企业协会关于举办2014年第一期农村水电安全生产标准化建设培训班的通知（中水企〔2014〕7号）

各省、自治区、直辖市水利（水务）厅（局），新疆生产建设兵团水利局农村水电局（处、中心），各有关单位：

为贯彻落实《农村水电站安全生产标准化达标评级实施办法（暂行）》，进一步规范农村水电安全生产标准化建设，经水利部人事司备案同意，受水利部农村水电及电气化发展局委托，定于2014年5月中旬举办2014年第一期农村水电安全生产标准化建设宣贯培训班.现将有关事项通知如下：

**一、**培训内容

1.《农村水电站安全生产标准化达标评级实施办法（暂行）》政策解读；

2.《农村水电站安全生产标准化评审标准》释义；

3.《农村水电站技术管理规程》（SL529-2011）。

**二、**培训对象

省级和巿、区、县水行政主管部门农村水电管理机构负责同志及具体工作人员；电站负责人及安全管理人员。

**三、**培训时间及地点

培训时间：2014年5月14日至5月17日，13日报到。

培训地点：浙江省温州市江心海景酒店（温州市鹿城区江心屿西园，电话：0577-88066666）。

**四、**培训方式

培训班邀请熟悉农村水电安全管理及标准化建设工作的主管部门同志和有关专家授课；培训采取专题讲座和实地考察相结合的方式进行。

**五、**有关事项

1.2014年将举办三期农村水电安全生产标准化建设培训班，请各单位认真组织，统筹安排培训人员；并于5月5日前以省为单位将第一期培训班报名回执表传真或电子邮件发至中国水利企业协会（每省份报名人数原则上不超过5人）。

2.实施考勤签到制度，培训结束后根据学习情况出具《水利部培训登记证明》。

3.培训期间，食宿统一安排，培训费用每人每天450元，合计2250元/人（含食宿、培训、场地、资料等全部费用）。
