# 环境保护部公告2014年第78号——关于发布国家环境保护标准《声环境功能区划分技术规范》的公告

## 环境保护部公告

2014年第78号

## 关于发布国家环境保护标准《声环境功能区划分技术规范》的公告

为贯彻《中华人民共和国环境保护法》和《中华人民共和国环境噪声污染防治法》，防治噪声污染，保护环境，指导、规范声环境功能区划分工作，现批准《声环境功能区划分技术规范》为国家环境保护标准，并由我部与国家质量监督检验检疫总局联合发布。

标准名称、编号如下：

声环境功能区划分技术规范（GB/T 15190-2014）

本标准自2015年1月1日起实施，由中国环境出版社出版，标准内容可在环境保护部网站（http://bz.mep.gov.cn）查询。

自本标准实施之日起，由原国家环境保护局批准、发布的《城市区域环境噪声适用区划分技术规范》（GB/T 15190-94）废止。

特此公告。

(此公告业经国家质量监督检验检疫总局田世宏会签)

环境保护部

2014年12月2日
