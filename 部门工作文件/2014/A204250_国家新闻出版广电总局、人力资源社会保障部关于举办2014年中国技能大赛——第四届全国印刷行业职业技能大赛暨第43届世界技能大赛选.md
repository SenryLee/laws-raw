# 国家新闻出版广电总局、人力资源社会保障部关于举办2014年中国技能大赛——第四届全国印刷行业职业技能大赛暨第43届世界技能大赛选拔赛的通知

国家新闻出版广电总局、人力资源社会保障部关于举办2014年中国技能大赛--第四届全国印刷行业职业技能大赛暨第43届世界技能大赛选拔赛的通知

（新广出函〔2014〕124号）

各省、自治区、直辖市及新疆生产建设兵团人力资源社会保障厅（局）、新闻出版广电局、印刷协会、报业协会：

为贯彻落实党的十八大和十八届三中全会精神，实施人才兴国战略，加强在职职工和在校学生的职业能力建设，加快选拔、培养、造就印刷领域高技能人才，促进我国印刷业快速发展，根据《人力资源社会保障部关于组织开展2014年中国技能大赛的通知》（人社部函〔2014〕42号）要求，国家新闻出版广电总局、人力资源社会保障部决定，共同举办2014年中国技能大赛--第四届全国印刷行业职业技能大赛暨第43届世界技能大赛选拔赛（以下简称“大赛”）。现将有关事项通知如下：

**一、**参赛工种（项目）

大赛设平版印刷工、平版制版工、印品整饰工三个工种。每个工种分别设立职工组和学生组两个组别。其中，平版印刷工增设一项卷筒纸报轮组。

第43届世界技能大赛选拔赛项目为印刷媒体技术。

**二、**参赛人员

印刷行业相关在职人员，在校（含应届毕业生）本科、专科、高职、高专、高级技校以及中专、技校（职高）学生。其中，参加第43届世界技能大赛印刷媒体技术项目选拔赛的须为1993年1月1日以后出生人员。

**三、**标准和命题

1.第四届全国印刷行业职业技能大赛职工组竞赛标准以《平版印刷工》、《平版制版工》、《印品整饰工》国家职业技能标准技师（国家职业资格二级）为基础；学生组以《平版印刷工》、《平版制版工》、《印品整饰工》国家职业技能标准高级工（国家职业资格三级）为基础，适当增加与行业相关的新知识、新技能等。竞赛项目由笔试和实际操作两部分组成。其中，职工组理论知识占30%、实际操作占70%；学生组理论知识占40%、实际操作占60%。竞赛试题将由组委会组织有关专家统一命制。

2.第43届世界技能大赛印刷媒体技术项目选拔赛与大赛平版印刷工学生组决赛同步进行，选拔赛以世界技能大赛印刷媒体技术项目有关技术要求为标准，由评判专家现场打分。

**四、**裁判员资格

大赛裁判员须参加由人力资源社会保障部等相关业务主管部门组织的培训，并达到相应要求的执裁水平。

**五、**组织保障

大赛由国家新闻出版广电总局、人力资源社会保障部主办，中国就业培训技术指导中心、中国印刷技术协会、中国报业协会承办。

1.大赛成立组织委员会（以下简称组委会）。组委会下设秘书处、评判委员会、监审组和学生组组委会。秘书处设在中国印刷技术协会，负责组委会日常组织协调工作；评判委员会负责大赛的技术标准、竞赛规则及决赛考题编制等工作；监审组负责大赛执裁程序、评判规则等监审工作；学生组组委会负责大赛学生组竞赛的计划安排、组织管理及竞赛方案设计等。

大赛分初赛、决赛两个阶段。初赛由各省（区、市）赛区组织，于2014年6月底前完成；全国总决赛由大赛组委会组织，于2014年9月底前举办，具体时间和地点另行通知。

2.第43届世界技能大赛印刷媒体技术项目选拔赛成立选拔赛工作组，工作组下设技术专家组。工作组主要负责选拔赛的计划安排、组织管理及集训基地选定等；技术专家组负责制定选拔赛标准、集训技术方案、组织集中集训等。选拔赛定于2014年5月举行。

**六、**奖励

（一）第四届全国印刷行业职业技能大赛

1.职工组

（1）获得每个工种总决赛前5名的选手，由人力资源社会保障部授予“全国技术能手”称号，颁发荣誉证书、奖章和奖牌，并由所属赛区人力资源社会保障部门核准后晋升技师职业资格，已具有技师职业资格的晋升为高级技师职业资格。同时，获得由大赛组委会颁发的“第四届全国印刷行业职业技能大赛一等奖”奖杯和荣誉证书。

（2）获得每个工种总决赛第6至20名的选手，由所属赛区人力资源社会保障部门核准后晋升高级工职业资格，已具有高级工职业资格的晋升为技师职业资格。同时，获得由大赛组委会颁发的“第四届全国印刷行业职业技能大赛二等奖”荣誉证书和奖牌。

（3）参加总决赛的其他选手，由大赛组委会颁发“第四届全国印刷行业职业技能大赛三等奖或优秀奖”荣誉证书和奖牌。

2.学生组

（1）获得每个工种总决赛前5名的选手，由所属赛区人力资源社会保障部门核准后晋升高级工职业资格，并由大赛组委会颁发“第四届全国印刷行业职业技能大赛一等奖”奖杯和荣誉证书。

（2）获得每个工种总决赛第6至20名的选手，由大赛组委会颁发“第四届全国印刷行业职业技能大赛二等奖”荣誉证书和奖牌。

（3）参加总决赛的其他选手，由大赛组委会颁发“第四届全国印刷行业职业技能大赛三等奖或优秀奖”荣誉证书和奖牌。

（二）第43届世界技能大赛选拔赛

获得世界技能大赛印刷媒体技术项目选拔赛前10名的选手，入围中国队集训，由世界技能大赛中国组委会秘书处颁发荣誉证书。

各赛区可参照本通知的有关规定制定本赛区具体奖励办法。

请各省（区、市）新闻出版广电局、人力资源社会保障部门会同相关部门成立本赛区组委会，并于5月31日前将名单报大赛组委会。各赛区组委会要按照大赛组委会统一部署做好本赛区各项赛事组织管理工作。
