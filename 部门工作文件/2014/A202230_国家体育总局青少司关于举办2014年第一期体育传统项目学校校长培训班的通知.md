# 国家体育总局青少司关于举办2014年第一期体育传统项目学校校长培训班的通知

各省、自治区、直辖市、新疆生产建设兵团体育局：

为全面落实科学发展观，贯彻实施《全民健身条例》及《全民健身计划（2011-2015年）》，加强我国体育传统项目学校（以下简称“传统校”）组织建设和人才队伍建设，进一步提高传统校校长的知识水平和业务素质，不断推动传统校工作深入持久地开展，按照体育总局青少年体育司2014年的工作计划，决定举办2014年第一期传统校校长培训班。现就有关事宜通知如下：

**一、**培训时间和地点

（一）培训时间：2014年6月23日-27日（23日报到，27日离会）

（二）培训地点：内蒙古呼伦贝尔市金融大酒店（呼伦贝尔市海拉尔区阿里河路32号）

**二、**培训内容

本次培训以“新时期体育传统校可持续发展探讨”为主题，将邀请国内著名的专家学者，以授课和互动交流的方式进行。传统校经验交流突出地域特色，邀请不同地域和不同发展水平的传统校校长交流经验。

授课主要内容包括：

（1）体育竞赛促进青少年全面发展

（2）体育运动、健康促进、幸福生活--青少年体育现状与未来趋势

（3）我国学校体育面临的陷阱、机遇与对策--解读体育传统项目学校新管理办法的特点

**三、**培训人员及要求

全国31个省、市、自治区及新疆生产建设兵团体育局各选派国家级或省级体育传统项目学校校长3名。参加培训工作是传统校评估、奖励等工作的重要内容之一，各省（区、市）要认真组织，不得随意缺席。

**四、**培训经费

参加培训人员旅费自理，培训期间食宿费、培训费由体育总局补贴。编外人员经报名核准，费用自理。

**五、**培训组织形式

主办单位：国家体育总局青少年体育司

承办单位：国家体育总局体育科学研究所

内蒙古自治区体育局

协办单位：呼伦贝尔市体育局

**六、**报名报到

请将参会人员报名表（见附件2）以及返程票预定表（见附件3）于2014年6月16日前传真至呼伦贝尔市体育局，电话/传真：（0470）8217138。

**七、**资料下载

相关培训资料讲义请登录www.qsnty.org自行下载。
