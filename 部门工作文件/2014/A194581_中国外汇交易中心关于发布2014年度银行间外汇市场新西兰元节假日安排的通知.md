# 中国外汇交易中心关于发布2014年度银行间外汇市场新西兰元节假日安排的通知

银行间外汇市场会员：

银行间外汇市场自2014年3月19日起开展人民币对新西兰元直接交易。现公布2014年度（自3月19日起）银行间外汇市场新西兰元节假日安排如下：

4月18日，4月21日，4月25日，6月2日，10月27日，12月25日，12月26日。

若涉及2014年临时调整节假日，将另行通知。

中国外汇交易中心

2014年3月18日
