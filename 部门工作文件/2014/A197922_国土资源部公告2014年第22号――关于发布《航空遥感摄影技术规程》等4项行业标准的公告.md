# 国土资源部公告2014年第22号――关于发布《航空遥感摄影技术规程》等4项行业标准的公告

国土资源部公告

（2014年第22号）

关于发布《航空遥感摄影技术规程》等4项行业标准的公告

《航空遥感摄影技术规程》等4项推荐性行业标准已通过全国国土资源标准化技术委员会审查，现予批准、发布，于2014年12月30日起实施。编号及名称如下：

DZ/T 0203-2014 《航空遥感摄影技术规程》

DZ/T 0264-2014 《遥感解译地质图制作规范（1：250000）》

DZ/T 0265-2014 《遥感影像地图制作规范（1：50000 / 1：250000）》

DZ/T 0266-2014《矿产资源开发遥感监测技术规范》

《航空遥感摄影技术规程》（DZ/T0203-1999）废止。

2014年10月16日
