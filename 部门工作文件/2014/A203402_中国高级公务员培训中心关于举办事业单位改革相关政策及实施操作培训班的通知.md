# 中国高级公务员培训中心关于举办事业单位改革相关政策及实施操作培训班的通知

## 中国高级公务员培训中心关于举办事业单位改革相关政策及实施操作培训班的通知（人训中函〔2014〕7号）

各有关单位：

根据《关于印发人力资源社会保障部2014年度业务培训班计划的通知》（人社厅发〔2014〕12号）的安排，并报部培训主管部门批准，中国高级公务员培训中心将于今年6月在北京举办事业单位改革相关政策及实施操作培训班。现将有关事项通知如下：

**一、**培训目的

本期培训班将以《事业单位人事管理条例》（以下简称《条例》）及配套政策法规为核心内容，为贯彻落实《条例》培养工作骨干。

**二、**培训对象

党政机关、企事业单位、社团组织及其他相关单位的有关领导和工作人员。

**三、**培训内容与师资

（一）《事业单位人事管理条例》及配套法规

1．《事业单位人事管理条例》制定过程、主要内容和重点、疑难问题解答及如何贯彻实施。

2．《条例》配套法规的有关情况。

（二）事业单位改革相关政策与热点问题

1．事业单位分类进展情况及下一步工作安排。

2.事业单位公开招聘有关文件解读、招聘工作实践中遇到的突出问题及典型案例分析、媒体应对技巧。

3．事业单位编外用人及劳务派遣的相关问题。

4. 事业单位工资政策及绩效工资实施问题。

5.事业单位人事争议处理（事业单位劳动人事争议仲裁疑难问题与案例、事业单位如何预防或应对劳动人事争议）。

（三）事业单位人事管理操作技术与典型经验

1．事业单位绩效量化考评及绩效工资操作技术。

2．人社部事业单位人事制度改革的典型做法。

以上内容由人力资源社会保障部事业单位人事管理司、工资福利司、调解仲裁管理司、人事司及中国人事科学院等机构的领导和专家主讲。

**四、**培训方式

培训将采取集中讲解政策法规与实施操作办法、疑难问题解答、案例分析、经验交流等方式进行。

**五、**时间与地点

6月10日至14日（9日学员报到）；北京。

**六、**培训费用

培训费1400元/人；食宿统一安排，费用自理。

**七、**报名工作

请按要求，组织本地区、本系统、本部门和所属各单位的有关人员报名，于5月30日前将报名表传真至高培中心。

报到等具体培训事宜，另行通知。
