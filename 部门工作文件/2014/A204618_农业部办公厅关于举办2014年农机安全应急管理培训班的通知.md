# 农业部办公厅关于举办2014年农机安全应急管理培训班的通知

## 农业部办公厅关于举办2014年农机安全应急管理培训班的通知（农办机[2014]10号）

各省、自治区、直辖市及计划单列市农机（农业、农牧）局（厅、委、办），新疆生产建设兵团农业局：

为落实中央领导关于安全生产的重要批示，贯彻《农业机械安全监督管理条例》、《农业机械事故处理办法》和《农业部关于进一步加强农业应急管理工作的意见》（农办发〔2013〕5号），强化农机事故应急管理，规范农机事故应急处理，提升农机事故应急救援能力，我部拟围绕农机安全生产形势任务、应急预案管理、突发事件应对处置、事故处理与救援等相关内容组织开展培训。现将有关事项通知如下：

**一、**培训时间

2014年4月23-24日（周三、周四）。

京外单位参训人员于4月22日下午报到，京内单位参训人员于4月23日上午8：00前自行前往农业部管理干部学院崇学大厦B座大堂办理报到手续。

**二、**培训地点

农业部管理干部学院（北京市昌平区霍营农业部管理干部学院）

**三、**参加人员

各省（区、市）、计划单列市及新疆生产建设兵团农机安全监理工作主管处长、站长及农机事故处理员代表，每个省份不超过3人。

**四、**培训内容

结合农机安全生产实际，采取形势分析、专题授课、拓展训练、分组讨论等方式，围绕农机安全生产形势任务、应急预案管理、突发事件应对处置、事故处理与救援等相关内容组织开展培训。

**五、**有关要求

请各地于4月16日下班前，将确认后的《培训报名回执》（见附件）电子版及纸质版分别报送至农业部农业机械化管理司安全监理处和农业部管理干部学院学员接待中心。
