# 中国高级公务员培训中心关于举办2014年办文办会办事能力提升培训班的通知

## 中国高级公务员培训中心关于举办2014年办文办会办事能力提升培训班的通知（人训中函[2014]2号）

各有关单位：

根据《关于印发人力资源社会保障部2014年度业务培训班计划的通知》（人社厅发〔2014〕12号）的安排，经报人社部主管部门批准，我中心将于今年4月下旬在厦门举办2014年办文办会办事能力提升培训班。现将有关事宜通知如下：

**一、**培训目的

通过学习公文写作及处理、会议管理、机关工作方法等专题，切实提升机关、企事业单位的办文办会办事能力，进而提高单位的行政管理水平。

**二、**培训对象

国家机关及企事业单位相关部门工作人员。

**三、**培训内容

（一）公文写作及处理

1．公文写作基本要求，常用公文格式，典型文种起草及领导讲话稿撰写

2．机关办文规则、流程及步骤

3．公文写作及处理中常见问题及解决方法

（二）会议的有效管理

1.会议的规划及筹备

2.会议的时间管理、工具管理

3.会议中的沟通与反馈技巧

4.会议突发事件应对

（三）机关工作方法及效能管理

1.机关传统工作方法与现代工作方法对比

2.办公效能管理

3.沟通与协调人际关系技巧

4.公务礼仪

**四、**培训方式

采用讲授与案例分析、互动交流等方式。

**五、**培训时间与地点

2014年4月22日-26日（4月21日报到），厦门。

**六、**培训费用

1400元/人，食宿统一安排，费用自理。

**七、**培训证书

培训结束后将为全勤学员颁发培训合格证书。

**八、**报名工作

请组织本系统、本部门和相关单位的有关人员报名，欢迎集体报名。请于4月11日前将报名表传真或发送电子表格至高培中心培训三处。报到等具体事宜，另行发文通知。
