# 中国高级公务员培训中心关于举办离退休人员待遇政策及管理服务培训班的通知(2014)

## 中国高级公务员培训中心关于举办离退休人员待遇政策及管理服务培训班的通知（人训中函〔2014〕12号）

各有关单位：

根据《关于印发人力资源社会保障部2014年度业务培训班计划的通知》（人社厅发〔2014〕12号）的安排，并报部培训主管部门批准，中国高级公务员培训中心将于今年8月在包头举办离退休人员待遇政策及管理服务培训班。现将有关事项通知如下：

**一、**培训目的

通过培训，了解离退休干部服务管理工作的发展趋势，深入理解新形势下离退休干部管理服务有关政策；学习和掌握离退休干部管理服务工作的重要方法；探讨工作中遇到的疑难问题及对策；提高业务素质和能力，培训工作骨干。

**二、**培训对象

机关、企事业单位和社团组织负责离退休管理服务工作的领导及有关骨干人员。

**三、**培训内容与师资

（一）我国离退休干部管理服务的政策

1．离退休人员待遇调整及特殊政策性问题的处理

2．离退休条件的政策规定及热点关注

3．我国离退休干部养老模式的变化

4．《事业单位人事管理条例》解读（包括工资福利和养老保险问题）

（二）迎接挑战，建设高素质专业化的老干部工作队伍

1．离退休工作发展趋势、挑战与机遇

2．老干部工作机构职能扩展和队伍建设问题

（三）离退休干部管理服务工作基础与操作实务

1．老年学和离退休干部管理服务工作基本知识

2．老干部工作者心理调适、职业生涯管理

3．离退休干部心理分析和情绪疏导

4．与老同志沟通的方式与语言艺术

5．“双高”、“空巢”老人现实困难分析及解决办法

以上内容将由人力资源和社会保障部工资福利司、法规司、中国人事科学研究院等机构有关领导和专家主讲。

**四、**培训方式

培训将采取集中授课、疑难问题解答、研讨交流等方式进行。

**五、**时间与地点

8月6日至11日（6日报到）；内蒙包头。

**六、**培训费用

培训费1400元/人；食宿统一安排，费用自理。

**七、**报名工作

请按要求，组织本地区、本系统、本部门和所属各单位的有关人员报名，于7月24日前将报名表传真至高培中心。

报到等具体培训事宜，另行通知。
