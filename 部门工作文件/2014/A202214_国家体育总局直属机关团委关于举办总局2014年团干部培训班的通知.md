# 国家体育总局直属机关团委关于举办总局2014年团干部培训班的通知

各直属团委、支部：

根据国家体育总局2014年培训工作计划，由总局直属机关团委主办、干部培训中心承办的团干部培训班拟于2014年7月在北京体育大学举办。现将有关事宜通知如下：

**一、**培训对象

各直属团委、支部负责人或青年工作负责人。

**二、**培训时间及地点

时间：2014年7月3日至4日。

地点：北京体育大学国家训练基地运动员公寓B座。

**三、**培训目的

进一步提高团干部的理论水平和综合素质，提升在新时期做好团工作的能力。

**四、**培训内容

（一）团干部理论素养

（二）如何开展团的工作，怎样做好团干部

（三）中央国家机关如何开展志愿服务

**五、**培训形式

全脱产培训，包括专题讲座、互动讨论等形式。

**六、**报名

请各单位选派1人参加培训，于6月20日前将报名表（见附件）传真至国家体育总局干部培训中心。

**七、**经费

学习期间培训费、食宿费由总局负担。

**八、**其他事宜

（一）报到时间及地点

7月3日上午7：40在总局机关楼门口统一发车，自行前往的学员请于当日上午9：00前到北京体育大学运动员公寓B座一层大厅报到。

（二）需携带物品

请参加培训班的学员携带本人身份证或复印件、1张近期免冠彩色二寸照片、洗漱用品和换洗服装，并自备记录本、笔等学习用品。

（三）培训准备

请参加培训班的学员提前梳理本部门本单位近年来团的工作开展情况和存在的困难，思考关于加强团员管理方面的意见建议以及对总局直属机关团的工作的建议。
