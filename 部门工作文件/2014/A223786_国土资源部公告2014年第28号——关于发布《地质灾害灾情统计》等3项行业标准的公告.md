# 国土资源部公告2014年第28号——关于发布《地质灾害灾情统计》等3项行业标准的公告

## 国土资源部公告

2014年第28号

## 关于发布《地质灾害灾情统计》等3项行业标准的公告

《地质灾害灾情统计》、《地下水监测井建设规范》、《区域地下水位监测网设计规范》等3项推荐性行业标准已通过全国国土资源标准化技术委员会审查，现予批准、发布，于2015年1月1日起实施。编号及名称如下：

DZ/T 0269-2014 《地质灾害灾情统计》

DZ/T 0270-2014 《地下水监测井建设规范》

DZ/T 0271-2014 《区域地下水位监测网设计规范》

2014年12月5日
