# 国家文物局关于举办国家文物进出境审核信息管理系统培训班的通知

## 国家文物局关于举办国家文物进出境审核信息管理系统培训班的通知（文物博函〔2014〕2534号）

各国家文物进出境审核管理处：

按照我局2014年度重点工作部署，国家文物进出境审核信息管理系统拟于今年年底正式上线使用。为确保各审核管理处业务人员正确使用该系统，我局将于近期举办国家文物进出境审核信息管理系统培训班。现就有关事宜通知如下：

**一、**培训内容

用户申报平台功能及操作讲解；审核平台功能及操作讲解；固定式读卡器和手持机功能及操作讲解。

**二、**培训方式

采用集中授课与实际操作相结合（请培训学员自带笔记本电脑和2012年下发的固定式读卡器、读卡器驱动光盘、电子标签若干）。

**三、**培训对象

各审核管理处文物进出境审核专业人员和系统维护人员。

**四、**培训时间

此次培训班分两期举办，具体时间安排如下：

第一期 9月15日至16日（9月14日下午报到，9月17日上午疏散）

第二期 9月18日至19日（9月17日下午报到，9月20日上午疏散）

**五、**培训地点

北京市朝阳区高原街甲2号文博大厦三层培训教室（报到及住宿地点：文博大厦鼎春德酒店）。

**六、**培训报名

各审核管理处每期报名1-2人，统一填写《国家文物进出境审核信息管理系统培训班报名回执表》（见附件），并于9月8日前发送至邮箱jcj@sach.gov.cn。

**七、**培训费用

学员食宿费用及相关培训费用由我局承担，往返交通费用由学员所在单位承担。

**八、**联系方式

国家文物局　吴旻　010-56792106

中国文物信息咨询中心　苑文会　13811242077

进出境系统技术支持QQ群：63289079
