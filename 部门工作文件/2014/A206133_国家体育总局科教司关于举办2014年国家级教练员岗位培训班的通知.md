# 国家体育总局科教司关于举办2014年国家级教练员岗位培训班的通知

## 国家体育总局科教司关于举办2014年国家级教练员岗位培训班的通知（体科字[2014]15号）

各省（自治区、直辖市）体育局，各运动项目管理中心：

根据国家体育总局2014年度培训工作计划，2014年国家级教练员岗位培训班将于3月至11月期间进行。本期培训班由国家体育总局科教司主办，国家体育总局教练员学院承办。现将有关事宜通知如下：

**一、**培训目的

国家级教练员岗位培训班是为具备高级教练员职称、具备申请国家级教练员资格的教练员举办的专门培训。通过培训，使广大高级教练员进一步明确岗位意识，丰富现代竞技运动理论知识，掌握现代竞技训练方法，增强管理能力，提高执教水平，促进我国高级教练员综合素质和科学训练水平的提高。

**二、**培训对象

拥有高级教练员岗位培训合格证书，具备高级教练员职称，符合申请国家级教练资格的各省、自治区、直辖市体育局及各运动项目管理中心所属专职教练员。

**三、**培训形式

（一）集中面授、听取专题报告和论文答辩

集中面授进行两次，论文答辩在第二次面授期间进行。

（二）在职自学、撰写论文

凡被确认录取的学员，在第一次面授和第二次面授之间，须在工作岗位上按规定阅读自学读书，并撰写两篇读书心得和一篇论文。论文要结合自己执教的运动项目的训练、竞赛实际，对如何进一步提高训练、竞赛水平，以及推动项目的可持续发展等问题进行深入思考和探讨，字数不得少于5000字。

**四、**培训时间和地点

（一）培训时间

2014年3月至11月，共分三个阶段：

第一阶段：3月24日-29日第一次集中面授，听取中美专家专题报告。

第二阶段：4月至10月，在职自学读书并撰写读书心得体会和论文（或专题报告）。

第三阶段：11月下旬，集中面授，听取中外专家相关专题报告，进行论文答辩。

（二）培训地点

待定。

**五、**考核与结业

（一）培训班学员须完成两次集中面授和自学阶段所有规定学习任务。读书心得通过审核、论文通过答辩及出勤符合规定者将获得国家体育总局颁发的国家级教练员岗位培训合格证书。两次集中面授学习累计缺课1天以上（含1天）的学员不能获得合格证书。

（二）该培训班根据学员读书心得、论文审核、答辩情况和出勤率的综合评定，采用末位淘汰制，其比例为5%。

（三） 该培训班的优秀论文，教练员学院将其发表在教练员学院专刊上。

**六、**报名程序

由国家体育总局各运动项目管理中心（或单项协会）、各省、市、自治区体育局推荐教练员，填写报名表（见附件），并附被推荐人高级教练员职称证书复印件，于3月5日之前报至国家体育总局教练员学院，经科教司批准后，于3月10日前发入学通知书。
