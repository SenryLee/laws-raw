# 住房和城乡建设部公告第416号――关于发布国家标准《矿物掺合料应用技术规范》的公告

住房和城乡建设部公告

（第416号）

关于发布国家标准《矿物掺合料应用技术规范》的公告

现批准《矿物掺合料应用技术规范》为国家标准，编号为GB/T51003-2014，自2015年2月1日起实施。

本规范由我部标准定额研究所组织中国建筑工业出版社出版发行。
