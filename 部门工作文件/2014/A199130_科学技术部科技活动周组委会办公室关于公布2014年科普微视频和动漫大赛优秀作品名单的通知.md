# 科学技术部科技活动周组委会办公室关于公布2014年科普微视频和动漫大赛优秀作品名单的通知

各有关单位：

为深入贯彻党的十八大精神，深入实施创新驱动发展战略，在全社会普及科学知识、弘扬科学精神，提高全民科学素养，按照《科技部 中央宣传部 中国科协关于举办2014年科技活动周的通知》（国科发政〔2014〕69号）部署，科技活动周组委会办公室组织开展了以“科学生活 创新圆梦”为主题的2014年优秀科普微视频和动漫大赛活动，该活动是全国科技活动周重大示范活动之一。

此项活动得到了社会各界的热情响应和积极参与，到作品征集截止日共收到参赛作品260余部，推荐作品形式多样、内容广泛、整体制作水平较高，集中反映了近年来科普微视频和动漫作品的发展成效。科技活动周组委会办公室组织了网络评选及专家评审。根据公众评选意见和专家评审意见综合产生参赛作品的最终评定结果，并在科技部网站和中国科普网进行了公示，最终确定了2014年科普微视频和动漫优秀作品33部（名单附后）。对评出的优秀作品将颁发荣誉证书以资鼓励，并向社会公开推荐。

附件：2014年科普微视频和动漫大赛优秀作品名单

科技活动周组委会办公室

2014年9月3日
