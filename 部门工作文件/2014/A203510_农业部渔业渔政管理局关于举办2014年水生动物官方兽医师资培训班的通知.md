# 农业部渔业渔政管理局关于举办2014年水生动物官方兽医师资培训班的通知

各省、自治区、直辖市及计划单列市、新疆生产建设兵团渔业主管厅（局）、水生动物卫生监督所、水产技术推广站（水生动物疫病预防控制机构），全国水产技术推广总站：

2010年新修订的《动物检疫管理办法》和《农业部关于贯彻落实＜动物检疫管理办法＞的通知》（农医发〔2010〕11号）明确水产苗种产地检疫及其监督工作由渔业主管部门实施以来，地方各级渔业主管部门和水生动物卫生监督机构认真组织执法监督和推动队伍建设，产地检疫和官方兽医制度逐步完善。为进一步提高水产苗种产地检疫监督执法水平，加快水生动物官方兽医队伍建设，我局决定举办2014年全国水生动物官方兽医师资培训班。现将有关事项通知如下。

**一、**培训内容

官方兽医制度和队伍建设，水产苗种产地检疫相关法规、检疫程序、相关标准及疫病诊断技术，检疫不合格动物处理规程等。培训将对学员进行考试，合格者颁发合格证书。

**二、**参加人员

各省、自治区、直辖市及计划单列市、新疆生产建设兵团（以下简称各省（区、市））渔业主管部门及其渔政监督管理机构（水生动物卫生监督机构）的官方兽医（或负责产地检疫执法监督的业务骨干），各省（区、市）水产技术推广机构（水生动物疫病预防控制机构）协助进行产地检疫的专业人员（名额分配见附件1）。参加培训人员要求具有在本辖区内开展水生动物官方兽医相关培训的基本能力。

**三、**培训时间和地点

培训分为北方班和南方班。

（一）北方班

时间：6月10-13日，9日报到。

地点：北京商务会馆（北京市南二环右安门外玉林里1号楼，大堂电话：010-63292244）。

（二）南方班

时间：6月24-27日，23日报到。

地点：南京望江楼宾馆（南京市下关区江边路2号，大堂电话：025-80851070）。

**四、**其他事项

各省（区、市）渔业主管部门要充分认识举办此次官方兽医培训班的重要意义，认真组织相关人员参加培训，并做好下一步开展省级水生动物官方兽医培训的准备工作。此次培训委托全国水产技术推广总站具体安排组织，北京市水产技术推广站和江苏省水生动物疫病预防控制中心协助组织。请参加培训人员于5月30日前将报名回执单（见附件2）发送至全国水产技术推广总站检疫与病害防治处邮箱（bfc712@163.com）。本次培训不安排接送站，请各位学员自行前往。
