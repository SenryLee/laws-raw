# 国土资源部公告2014年第24号――关于发布《生产项目土地复垦验收规程》等3项行业标准的公告

国土资源部公告

（2014年第24号）

关于发布《生产项目土地复垦验收规程》等3项行业标准的公告

《生产项目土地复垦验收规程》、《数字地质数据质量检查与评价》、《地质图书馆图书分类》等3项推荐性行业标准已通过全国国土资源标准化技术委员会审查，现予批准、发布，于2014年12月30日起实施。编号及名称如下：

TD/T1044-2014 《生产项目土地复垦验收规程》

DZ/T0268-2014 《数字地质数据质量检查与评价》

DZ/T0267-2014 《地质图书馆图书分类》

2014年10月23日
