# 农业部农业机械化技术开发推广总站关于举办2014年第一期农机推广骨干人员培训班的通知

## 农业部农业机械化技术开发推广总站关于举办2014年第一期农机推广骨干人员培训班的通知（农机推（体）发〔2014〕55号）

各省、自治区、直辖市及计划单列市农业（农机）厅（局、委），黑龙江省农垦总局，广东农垦总局，新疆生产建设兵团农业局：

为加强基层农机推广人才队伍建设，提高基层农机推广人员业务素质，提升推广服务能力，根据《农业部办公厅关于举办2014年农技推广骨干人才培训班的通知》（农办科〔2014〕14号）和农机化司的安排，总站拟定于9月上旬举办“2014年第一期农机推广骨干人员培训班”。现将有关事项通知如下：

**一、**时间地点

时间：2014年9月10日～15日，9月9日报到。

地点：江苏南京军区厨师培训基地（地址：南京市鼓楼区江边路2号，原下关区江边路2号，望江楼大酒店）

**二、**培训对象

《农业部办公厅关于举办2014年农技推广骨干人才培训班的通知》（农办科〔2014〕14号）确定的农机第1期报名人员（见附件1）。

**三、**培训内容

专题讲座、案例教学、专题研讨和现场教学等方式相结合，重点培训内容如下：

（一）我国农机化发展及农机推广工作的形势与任务；

（二）农机化技术推广试验示范与方法；

（三）农机标准化作业及管理；

（四）农机化技术推广项目管理；

（五）农机化技术推广人员素质与要求；

（六）推进农机农艺融合；

（七）信息化技术在农机化技术推广中的应用；

（八）农机推广工作评价方法；

（九）农机合作社现场考察与实训，参观现代农机企业。

**四、**有关要求

（一）请各单位组织参训学员于8月26日前将农技推广骨干人才信息表（见附件2）报送至农业部农机推广总站推广二处。

（二）每名参训学员需撰写农机推广专题交流材料1份，于开班前10天（2014年8月31日）将材料电子稿报送至农业部农机推广总站推广二处。专题交流材料内容要立足本地农机推广工作实际，有针对性地反映主要矛盾、突出问题、现实困难和经验成效，并提出对策建议。

（三）学员报到时交近期二寸免冠照片2张，培训合格后颁发农业专业技术人才知识更新工程培训证书。

（四）依据《农业部办公厅关于举办2014年度农技推广骨干人才培训班的通知》，本期培训班收取培训、教材、食宿等费用每人3000元，由农业部南京农业机械化研究所（全国农机化教育培训中心）统一开具发票。差旅费自理。

**五、**其他事项

（一）培训班由农业部农业机械化技术开发推广总站承办，全国农机化教育培训中心协办。

（二）报到地点，乘车路线

培训班不接站，请各位学员参考以下路线前往。

1.南京机场：禄口机场乘机场大巴到南京火车站下车，转乘10路公交车到中山码头下即到。

2.火车站：（1）南京站乘公交10路车到中山码头下车即到；（2）南京南站乘地铁1号线到鼓楼下，再转乘34路公交车到中山码头下车即到。

3.汽车站：（1）南京东站乘10路公交车到中山码头下车即到；（2）桥北汽车站乘150路公交车到热河路下车再转31路或34路到中山码头下车即到。
