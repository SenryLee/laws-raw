# 中国残疾人联合会办公厅关于举办2014年全国省级残联统计人员培训班的通知

## 中国残疾人联合会办公厅关于举办2014年全国省级残联统计人员培训班的通知（残联厅函〔2014〕196号）

各省、自治区、直辖市残联，新疆生产建设兵团残联，黑龙江垦区残联：

为了做好2014年度残疾人事业统计的布置和培训工作，经中国残联领导同志同意，定于2014年8月在陕西省西安市举办“全国省级残联统计人员培训班”。现就培训相关事宜通知如下：

**一、**培训时间、地点

培训时间：2014年8月25日至29日（25日报到，29日撤离）。

培训地点：陕西省西安市（西安市莲湖区 北大街199号近莲湖路，西安华山国际酒店）。

**二、**参加人员

各省、自治区、直辖市残联及新疆生产建设兵团残联，黑龙江垦区残联统计人员各1人。

**三、**培训内容

（一）通报2013年统计工作情况。

（二）布置2014年统计工作，针对2013年填报、审核中的突出问题和2014年统计指标的调整，讲解统计指标与填报要求。

（三）布置2014年新开展台账填报工作。

（四）统计管理系统的软件操作上机培训。

（五）各地统计工作交流。

**四、**有关要求

（一）请按规定确定有关人员按时参加培训，以保证本省（区、市）工作任务的顺利进行。无关人员不得参加，提前抵达和推迟返程的有关费用自理。

（二）请认真填写培训班回执（见附件）于2014年8月20日前反馈至中国残联信息中心。若需要协助预订返程票，请务必在回执中说明，并提前将订票所需身份证号等信息通过传真或电子邮件发至中国残联信息中心。

（三）培训班不设接站。参加人员请自行前往培训地点。
