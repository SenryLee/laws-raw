# 中国证券投资基金业协会关于举办2014年度基金管理公司年报审计培训班的通知

各基金管理公司及其子公司：

为进一步加强基金管理公司及其子公司年报披露工作，持续提升基金管理公司及其子公司信息报送质量，经商中国证监会会计部、基金部，我会定于2014年1月16日在北京举办“2014年度基金管理公司年报审计培训班”。现就培训有关事项通知如下：

**一、**培训时间和地点

（一）报到时间：2014年1月15日16：00-19：00。

（二）培训时间：2014年1月 16日9：00-17：00。

（三）培训地点：中国职工之家B座3层多功能厅（地址：北京市西城区真武庙路1号）。

**二、**培训对象

各基金管理公司及其子公司财务总监或财务负责人（限1-2人）。

**三、**培训主要内容及师资

（一）培训主要内容

First系统填报说明和子公司报备表要求；第三次全国经济普查相关问题通报；税务稽查问题分析与总结；基金公司审计问题讲解。

（二）培训师资

中国证监会会计部、基金部、会计师事务所有关专家。

**四、**培训费用及缴纳方式

（一）培训费800元/人（含16日自助午餐）。

（二）单位或个人报名时将培训费汇入我会以下账户：

收款人全称：中国证券投资基金业协会

开户行：中国建设银行北京月坛支行

账号：11001020500059088333

（三）学员汇款时请在备注栏注明单位名称，报到时领取培训费发票。

**五、**食宿安排

住宿费：460元/天/标间（含早餐），费用学员自理；培训期间提供16日自助午餐。

**六、**注意事项

（一）即日起开始报名，报名及汇款截止日期为2014年1月14日。

（二）培训班采取网上报名的方式。报名地址为：　　　　http：//person.amac.org.cn/trainbaoming/uclassselect。

（三）本次培训学时将计入中国证券投资基金业协会后续职业培训信息库。

（四）联系人：任慧凝　　电话：010-66578201
