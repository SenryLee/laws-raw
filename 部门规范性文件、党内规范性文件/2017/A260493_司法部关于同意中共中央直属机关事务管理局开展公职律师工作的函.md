# 司法部关于同意中共中央直属机关事务管理局开展公职律师工作的函

司发函〔2017〕289号

中共中央直属机关事务管理局：

你局《关于申请设立公职律师的函》收悉。经研究，同意在中直管理局开展公职律师工作，批准李令巍、李文仲、庄良渠、张秋实等4名同志为公职律师。

司法部

2017年11月24日
