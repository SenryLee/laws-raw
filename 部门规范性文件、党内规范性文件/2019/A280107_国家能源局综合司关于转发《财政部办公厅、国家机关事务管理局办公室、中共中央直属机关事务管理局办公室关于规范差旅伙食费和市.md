# 国家能源局综合司关于转发《财政部办公厅、国家机关事务管理局办公室、中共中央直属机关事务管理局办公室关于规范差旅伙食费和市内交通费收交管理有关事项的通知》的通知

## 国家能源局综合司关于转发《财政部办公厅国家机关事务管理局办公室 中共中央直属机关事务管理局办公室关于规范差旅伙食费和市内交通费收交管理有关事项的通知》的通知

各司，各派出能源监管机构，各直属事业单位，中电传媒：

为进一步贯彻落实中央八项规定精神，严肃财经纪律，根据《党政机关厉行节约反对浪费条例》《党政机关国内公务接待管理规定》《中央和国家机关差旅费管理办法》等规章制度，财政部办公厅就规范差旅伙食费和市内交通费收交管理印发了《财政部办公厅 国家机关事务管理局办公室 中共中央直属机关事务管理局办公室关于规范差旅伙食费和市内交通费收交管理有关事项的通知》（财办行〔2019〕104号）。现转发各部门、各单位，请遵照执行。

附件：财政部办公厅 国家机关事务管理局办公室 中共中央直属机关事务管理局办公室关于规范差旅伙食费和市内交通费收交管理有关事项的通知
