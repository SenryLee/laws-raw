# 最高人民法院办公厅关于刑事裁判涉财产部分执行可否收取诉讼费意见的复函

法办函〔2017〕19号

发展改革委办公厅：

你厅《关于商请明确人民法院可否收取刑事案件涉财产执行诉讼费有关问题的函》收悉。经研究，我院认为，刑事裁判涉财产部分执行不同于民事执行，人民法院办理刑事裁判涉财产部分执行案件，不应收取诉讼费。
