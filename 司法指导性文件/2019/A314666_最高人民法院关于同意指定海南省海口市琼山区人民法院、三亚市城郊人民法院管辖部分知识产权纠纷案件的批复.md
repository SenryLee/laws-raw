# 最高人民法院关于同意指定海南省海口市琼山区人民法院、三亚市城郊人民法院管辖部分知识产权纠纷案件的批复

## 最高人民法院关于同意指定海南省海口市琼山区人民法院三亚市城郊人民法院管辖部分知识产权纠纷案件的批复

法〔2019〕155号

海南省高级人民法院：

你院《关于指定部分基层人民法院管辖第一审一般知识产权案件的请示》（琼高法〔2019〕93号）收悉。经研究，批复如下：

一、同意指定海南省海口市琼山区人民法院管辖以下知识产权案件：发生在海南省海口市、三沙市、儋州市、洋浦经济开发区、文昌市、琼海市、澄迈县、屯昌县、临高县、定安县、琼中县、昌江县辖区内，诉讼标的额在200万元以下的第一审一般知识产权民事案件，专利、植物新品种、集成电路布图设计、技术秘密、计算机软件、涉及驰名商标认定和垄断纠纷案件除外；

二、同意指定海南省三亚市城郊人民法院管辖以下知识产权案件：发生在海南省三亚市、东方市、万宁市、五指山市、陵水县、保亭县、白沙县、乐东县辖区内，诉讼标的额在200万元以下的第一审一般知识产权民事案件，专利、植物新品种、集成电路布图设计、技术秘密、计算机软件、涉及驰名商标认定和垄断纠纷案件除外。

此复

最高人民法院

2019年6月20日
