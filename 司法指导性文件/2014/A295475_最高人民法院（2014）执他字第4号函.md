# 最高人民法院（2014）执他字第4号函

（2014年4月9日）

安徽省高级人民法院：

你院（2013）皖执他字第00146号《关于司法拍卖程序中竞买人资格审查问题的请示报告》收悉。经研究，答复如下：

设立中公司虽然不具有法人资格，但是可以从事设立公司所必需的民事行为。发起人为设立中公司购买财产，并以设立中公司名义参与司法拍卖的，不应仅以竞买人是设立中公司为由否定司法拍卖的效力。

此复
