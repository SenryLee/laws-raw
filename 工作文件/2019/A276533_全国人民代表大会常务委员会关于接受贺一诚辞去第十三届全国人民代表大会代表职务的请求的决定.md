# 全国人民代表大会常务委员会关于接受贺一诚辞去第十三届全国人民代表大会代表职务的请求的决定

（2019年4月23日第十三届全国人民代表大会常务委员会第十次会议通过）

根据《中华人民共和国澳门特别行政区选举第十三届全国人民代表大会代表的办法》第二十一条规定，第十三届全国人民代表大会常务委员会第十次会议决定：接受贺一诚辞去第十三届全国人民代表大会代表职务的请求。
