# 全国人民代表大会常务委员会关于批准《中华人民共和国和埃塞俄比亚联邦民主共和国关于民事和商事司法协助的条约》的决定

（2017年11月4日第十二届全国人民代表大会常务委员会第三十次会议通过）

第十二届全国人民代表大会常务委员会第三十次会议决定：批准2014年5月4日由中华人民共和国代表在亚的斯亚贝巴签署的《中华人民共和国和埃塞俄比亚联邦民主共和国关于民事和商事司法协助的条约》。
