# 全国人大常委会关于批准《上海合作组织成员国边防合作协定》的决定

## 全国人民代表大会常务委员会关于批准《上海合作组织成员国边防合作协定》的决定

（2017年4月27日第十二届全国人民代表大会常务委员会第二十七次会议通过）

第十二届全国人民代表大会常务委员会第二十七次会议决定：批准2015年7月10日由中华人民共和国代表在乌法签署的《上海合作组织成员国边防合作协定》。
